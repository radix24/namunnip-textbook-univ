9.1.2
진자의 주기는 정말 진폭과 무관할까?
단진동 · 근사의 조건

    

      

        
        

          
          
          

            
실제 주기 / 근사 주기
—

            
근사식 1 + θ₀²/16
—

            
차이
—

          

          
실선은 실제 진자, 점선은 \(\sin\theta\approx\theta\)로 바꾼 진자입니다. \(g/L=1\)인 상대값입니다.

        

      

      
    
        
  1. 질문그네를 더 높이 밀면 한 번 왕복하는 시간도 길어질까요?
    2. 
        
  2. 복원각을 라디안으로 재면 작은 각에서 \(\sin\theta\approx\theta\)입니다. \(\sin0.1=0.0998\)이므로 0.1 rad(약 6°)에서 차이는 0.2%입니다.
    3. 
        
  3. 설명되돌리는 힘 \(mg\sin\theta\)를 \(mg\theta\)로 바꾸면 운동 방정식이 \(\ddot\theta=-(g/L)\theta\)가 되어 단순 조화 진동입니다. 이때 주기 \(T_0=2\pi\sqrt{L/g}\)에는 진폭이 들어 있지 않습니다.
    4. 
        
  4. 연결진폭이 커지면 \(\sin\theta<\theta\)라 되돌리는 힘이 근사보다 약해지고, 그만큼 천천히 돌아와 주기가 길어집니다. 급수로 쓰면 \(T\approx T_0(1+\theta_0^2/16)\)입니다.
    5. 
        
  5. 적용진폭을 30°, 60°, 90°로 바꾸며 '실제 주기 / 근사 주기'를 읽어 보세요. 근사식과 1% 넘게 어긋나기 시작하는 진폭은 어디인가요?
    6. 
        
  6. 판단"진자의 주기는 진폭과 무관하다"는 진폭이 작을 때만 맞습니다. 90°면 약 18% 길어지고, 180°에 가까워지면 주기가 한없이 길어집니다.
    7.

3.4.2
평균 기울기와 같은 순간 기울기는 언제 꼭 있을까?
증명 · 평균값 정리

    

      
    
        
  1. 정리
    평균값 정리\(f\)가 \([a,b]\)에서 연속이고 \((a,b)\)에서 미분 가능하면 \(f'(c)=\dfrac{f(b)-f(a)}{b-a}\)인 \(c\in(a,b)\)가 있습니다.
    2. 
        
  2. 쓰는 것Rolle 정리: 양 끝값이 같으면 사이에 \(f'(c)=0\)인 점이 있습니다.
    3. 
        
  3. 아이디어\(f\)에서 두 끝점을 잇는 직선을 빼면 양 끝값이 같아져 Rolle 정리를 쓸 수 있습니다.
    4. 
        
  4. 증명
          
      
            
    1. \(g(x)=f(x)-f(a)-\dfrac{f(b)-f(a)}{b-a}(x-a)\)로 둡니다.직선을 빼서 끝값을 맞춤
      2. 
            
    2. \(g(a)=g(b)=0\)이고 \(g\)는 \([a,b]\)에서 연속, \((a,b)\)에서 미분 가능합니다.연속·미분 가능 함수의 합
      3. 
            
    3. Rolle 정리로 \(g'(c)=0\)인 \(c\)가 있고, \(g'(c)=f'(c)-\dfrac{f(b)-f(a)}{b-a}\)입니다.Rolle 정리
      4. 
          
    
        
    5. 
        
  5. 되짚기미분 가능 조건이 빠지면 성립하지 않습니다. \(f(x)=|x|\)는 \([-1,1]\)에서 평균 기울기가 0이지만 기울기가 0인 점이 없습니다.
    6.

5.2.2
사인의 세제곱과 코사인의 제곱을 곱한 함수는 어떻게 적분할까?
예제 · 삼각함수의 거듭제곱

    

      
    
        
  1. 문제\(\displaystyle\int\sin^3x\cos^2x\,dx\)를 구하세요.
    2. 
        
  2. 전략사인의 지수가 홀수이므로 사인 하나를 떼어 \(dx\)와 묶고, 나머지를 코사인으로 바꿔 \(u=\cos x\)로 치환합니다.
    3. 
        
  3. 풀이
          
      
            
    1. \(\sin^3x\cos^2x=(1-\cos^2x)\cos^2x\sin x\)\(\sin^2x+\cos^2x=1\)
      2. 
            
    2. \(u=\cos x\), \(du=-\sin x\,dx\)이면 \(\displaystyle\int(u^4-u^2)\,du\)치환적분
      3. 
            
    3. \(=\dfrac{\cos^5x}5-\dfrac{\cos^3x}3+C\)거듭제곱의 적분
      4. 
          
    
        
    4. 
        
  4. 검산답을 미분하면 \(-\cos^4x\sin x+\cos^2x\sin x=\sin x\cos^2x(1-\cos^2x)=\sin^3x\cos^2x\)입니다.
    5. 
        
  5. 판단두 지수가 모두 짝수이면 이 방법이 통하지 않습니다. 그때는 반각 공식으로 차수를 낮춥니다.
    6.
