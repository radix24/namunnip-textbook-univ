외부 칩과의 연결 예산

외부 지연 합산

출발점

입력 지연 = 외부 칩 t_cq + 보드 배선 지연입니다(4.3절).

문제 해결 전략 · 외부 → 제약 값
  1. 외부 칩 t_cq 3 ns, 보드 배선 1 ns.
  2. 클록 100 MHz, 내부 t_setup 0.2 ns.
  3. 입력 지연과 내부 예산.

set_input_delay 값과 내부 논리 예산은?

풀이

  1. 입력 지연 4 ns.
    합.
  2. 예산 10 − 4 − 0.2 = 5.8 ns.
    계산.
  3. 클록 스큐·지터 여유를 더 빼야 함.
    실무.

의미

보드 설계자와 칩 설계자가 이 값을 주고받아야 시스템이 동작합니다.

검산

3 + 1 = 4.
