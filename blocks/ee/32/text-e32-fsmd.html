데이터패스와 FSM 제어기로 나누어 설계

본문

소프트웨어로는 몇 줄이면 되는 최대공약수 계산을 전용 하드웨어로 만들고 싶다. while 반복과 if 판단은 하드웨어에서 어떤 부품이 맡을까? 계산하는 부분과 순서를 정하는 부분을 어떻게 나누어 설계할까? 그리고 그 하드웨어는 몇 클록 만에 답을 낼까?

먼저 알아야 할 것FSM(전전4 6단원), HDL(2.1절)을 쓴다.

3.1.1GCD

while (a ≠ b) { if (a > b) a −= b; else b −= a; }를 하드웨어로 만든다. 먼저 데이터패스에는 레지스터 a, b와 뺄셈기, 비교기(a = b, a > b), 멀티플렉서를 둔다. 처음 질문의 첫째 답은 반복과 판단을 이 부품들과 아래 제어기가 나눠 맡는 것이다.

그리고 제어기는 IDLE(입력 적재) → CALC(비교 결과에 따라 a 또는 b 갱신) → DONE의 세 상태를 가진 FSM이다(그림 1). 즉 비교기 결과가 FSM으로 가고, FSM은 어느 레지스터를 고칠지 정하는 제어 신호를 데이터패스로 보낸다. 처음 질문의 둘째 답이 이 나눔이다.

아래 Python 모형은 클록마다 상태와 레지스터를 갱신해 클록 수를 센다.

# 뺄셈 GCD 데이터패스 + FSM 제어기를 클록 단위로 흉내 낸 모형
def gcd_hw(a_in, b_in):
    state, a, b, cyc = "IDLE", 0, 0, 0
    while True:
        cyc += 1
        if state == "IDLE":            # start: 레지스터 적재
            a, b, state = a_in, b_in, "CALC"
        elif state == "CALC":          # 비교기 결과로 다음 동작 선택
            if a == b:   state = "DONE"
            elif a > b:  a = a - b     # a_sel = 뺄셈 결과
            else:        b = b - a
        else:
            return a, cyc
for x, y in [(48, 18), (21, 6), (17, 5)]:
    g, c = gcd_hw(x, y)
    print(f"gcd({x}, {y}) = {g}, 클록 {c}개")

실행 결과는 아래와 같다(Python 3.12에서 실제 실행).

gcd(48, 18) = 6, 클록 7개
gcd(21, 6) = 3, 클록 7개
gcd(17, 5) = 1, 클록 9개
예제 3.1.1

gcd(48, 18)의 7클록을 상태별로 나누어라. 뺄셈을 줄이는 개선은?

풀이. IDLE이 1클록, CALC에서 뺄셈 4번(30, 12, 12/6, 6/6)과 같음 판정 1클록, DONE이 1클록이다. 처음 질문의 셋째 답이 이 클록 수이다. 그리고 뺄셈 대신 나머지 연산(유클리드)이나 2의 거듭제곱을 이용하는 이진 GCD는 몇 번에 끝나지만, 데이터패스가 커진다. 따라서 면적과 클록 수의 절충이다.

즉 데이터패스와 FSM을 나누면 각각을 따로 검증하고 바꿀 수 있다. 그래서 같은 데이터패스에 다른 FSM을 붙여 다른 알고리즘을 실행하거나, 같은 FSM으로 폭이 다른 데이터패스를 제어할 수 있다.

한편 이런 구조는 CPU의 축소판이기도 하다. 그러므로 6장의 프로세서 설계도 레지스터와 ALU로 된 데이터패스와, 명령어에 따라 제어 신호를 내는 제어기로 나누어 만든다.

흔한 오해FSM에 연산을 넣으면 된다고 여기기 쉽다. 연산은 데이터패스에, 제어는 FSM에 두어야 재사용과 타이밍 분석이 쉽다. 또 클록 수가 적으면 빠르다고 생각하기 쉬운데, 한 클록의 지연(임계 경로)도 함께 봐야 한다.
마무리

설계는 데이터패스(레지스터, 연산기, mux)와 FSM(제어 신호)으로 나눈다. GCD의 FSM은 IDLE → CALC → DONE이다. 예제의 gcd(48, 18)은 7클록이다(실제 모형 실행).

3.1.2연습문제

기본

  1. gcd(10, 10)의 클록 수는(같은 모형)?
    답

    IDLE 1, CALC 1, DONE 1 = 3이다.

응용

  1. FSM의 출력이 아닌 데이터패스의 출력은?
    답

    비교기 결과(a = b, a > b)는 데이터패스에서 FSM으로 가는 상태 신호이다.

심화

  1. GCD 블록을 버스에 달려면 무엇이 더 필요한가?
    답

    입력·결과 레지스터와 start/done 상태 레지스터, 버스 인터페이스이다.
