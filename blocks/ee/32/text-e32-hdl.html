HDL로 조합과 순차 회로 기술

본문
이 절에서 배울 것
  • Verilog의 assign·always @(*)로 조합 회로를, always @(posedge clk)로 순차 회로를 기술한다.
  • 블로킹(=)과 논블로킹(<=) 대입을 구별해 쓴다.
  • 래치가 의도치 않게 생기는 경우를 피한다.
먼저 알아야 할 것
  • 디지털 논리 (전전4 5단원).

2.1.1두 예

// 4:1 멀티플렉서(조합)
module mux4 (input [1:0] sel, input [7:0] a, b, c, d, output reg [7:0] y);
  always @(*) begin
    case (sel)
      2'd0: y = a;
      2'd1: y = b;
      2'd2: y = c;
      default: y = d;      // 모든 경우를 덮어 래치를 막음
    endcase
  end
endmodule

// 사용 가능 신호가 있는 8비트 계수기(순차)
module counter (input clk, rst_n, en, output reg [7:0] q);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)  q <= 8'd0;
    else if (en) q <= q + 8'd1;   // 논블로킹 대입
  end
endmodule

조합 always 블록은 블로킹(=), 순차 블록은 논블로킹(<=)이 원칙입니다. 논블로킹은 같은 클록 가장자리의 대입을 모두 오른쪽 값으로 계산한 뒤 한꺼번에 바꿔, 하드웨어 플립플롭과 같이 동작합니다.

예제 2.1.1

순차 블록에 b = a; c = b;(블로킹)와 b <= a; c <= b;(논블로킹)를 쓰면 각각 어떤 회로가 되는가?

풀이. 블로킹은 c가 새 b(= a)를 받아 플립플롭 하나 거리(b, c가 같은 값)가 되고, 논블로킹은 c가 옛 b를 받아 a → b → c 두 단 시프트 레지스터가 됩니다. 시프트 레지스터를 의도했다면 논블로킹이 맞습니다.

흔한 오해(1) "HDL은 소프트웨어처럼 위에서부터 실행된다": 모든 always 블록이 동시에 동작하는 하드웨어 기술입니다. (2) "if에 else가 없어도 된다": 조합 블록에서 값이 정해지지 않는 경우가 있으면 래치가 생깁니다.
요약
  1. 조합: assign, always @(*), 블로킹.
  2. 순차: always @(posedge clk), 논블로킹.
  3. 모든 경우에 값 지정해 래치 방지.
