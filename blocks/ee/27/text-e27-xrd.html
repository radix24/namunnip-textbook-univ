X선 회절로 결정 확인

본문
이 절에서 배울 것
  • Bragg 조건 \(2d\sin\theta = n\lambda\)를 쓴다.
  • 면 간격에서 회절각을 계산한다.
  • X선 회절로 결정 방향과 품질을 확인하는 방법을 안다.
먼저 알아야 할 것
  • 면 간격 (1.3절), 결정 성장 (1.2절).

1.4.1면에서 반사되는 파동

간격 d인 평행 원자면에서 반사된 X선이 보강 간섭하려면 경로차 \(2d\sin\theta\)가 파장의 정수배여야 합니다. 시료를 돌리며 회절 봉우리 각도를 재면 면 간격과 방향을, 봉우리 폭으로 결정 품질을 알 수 있습니다.

예제 1.4.1

Cu Kα(λ = 1.5406 Å)로 Si (111) 면의 회절각 2θ는?

풀이. sinθ = 1.5406/(2 × 3.136) = 0.2457 → θ = 14.22°, 2θ = 28.44°. 측정 각이 조금 어긋나면 변형(격자 상수 변화)을 뜻하며, SiGe 층의 변형 측정에 씁니다.

흔한 오해(1) "모든 (hkl)에서 봉우리가 보인다": 다이아몬드 구조는 소멸 규칙으로 (100), (200) 등이 사라집니다. (2) "θ와 2θ는 같은 값": 장비는 보통 입사·검출 사이 각 2θ를 표시합니다.
요약
  1. 2d sinθ = nλ.
  2. Si (111), Cu Kα → 2θ = 28.44°.
  3. 봉우리 위치 → 간격·변형, 폭 → 품질.
