도펀트 이온화 에너지: 수소 모형

본문
이 절에서 배울 것
  • 도너 전자를 결정 속 수소 원자처럼 보는 모형을 안다.
  • \(E_d = 13.6\,\mathrm{eV}\cdot(m^*/m_0)/\varepsilon_r^2\)를 계산한다.
  • 실온에서 도펀트가 거의 모두 이온화되는 이유를 설명한다.
먼저 알아야 할 것
  • 띠 도표 (2.1절).

2.3.1느슨하게 묶인 전자

P 원자의 다섯째 전자는 양이온에 묶이지만, 결정의 유전율이 쿨롱 힘을 약하게 하고 유효 질량이 작아 결합 에너지가 수소의 13.6 eV보다 훨씬 작습니다. 이 값이 열에너지 kT(26 meV)와 비슷해 실온에서 대부분 전도띠로 올라갑니다.

예제 2.3.1

Si(ε_r = 11.7, m* = 0.26m₀)에서 수소 모형의 도너 이온화 에너지는? 측정값(P 약 45 meV, 확인 필요)과 비교하면?

풀이. E_d = 13.6 × 0.26/136.9 = 0.026 eV(26 meV). 측정값과 크기 정도가 맞아 모형이 쓸 만하며, 차이는 원자 근처에서 유전 상수 근사가 깨지기 때문입니다. 반경도 수소의 ε_r/(m*/m₀) = 45배(약 2.4 nm)로 커서 여러 격자를 걸칩니다.

흔한 오해(1) "도너 전자는 원자에 단단히 묶여 있다": 실온 열에너지로 쉽게 풀려납니다. (2) "저온에서도 모두 이온화": 수십 K 아래에서는 다시 묶입니다(동결).
요약
  1. E_d = 13.6(m*/m₀)/ε_r² eV.
  2. Si 모형 26 meV, 측정 약 45 meV(P).
  3. 실온 ≈ 완전 이온화, 저온 동결.
