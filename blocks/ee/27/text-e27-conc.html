도핑 농도에서 캐리어 농도와 Fermi 준위

본문
이 절에서 배울 것
  • 질량 작용 법칙 \(np = n_i^2\)과 전하 중성으로 n, p를 구한다.
  • Fermi 준위 위치 \(E_F - E_i = kT\ln(n/n_i)\), \(E_C - E_F = kT\ln(N_C/n)\)를 계산한다.
  • 보상 도핑(N_D와 N_A 모두 있음)을 다룬다.
먼저 알아야 할 것
  • 상태 밀도와 Fermi-Dirac 통계 (전전15 4단원).

3.1.1계산

완전 이온화와 \(N_D \gg n_i\)이면 \(n \approx N_D - N_A\), \(p = n_i^2/n\). Boltzmann 근사로

\[ n = n_ie^{(E_F - E_i)/kT} = N_Ce^{-(E_C - E_F)/kT}. \]
예제 3.1.1

N_D = 10¹⁶ cm⁻³ 실리콘(300 K)의 n, p, E_F − E_i, E_C − E_F(N_C = 2.8 × 10¹⁹)는?

풀이. n = 10¹⁶, p = 10⁴ cm⁻³. E_F − E_i = 0.02585 ln 10⁶ = 0.357 eV, E_C − E_F = 0.02585 ln 2800 = 0.205 eV. 여기에 N_A = 4 × 10¹⁵을 더 넣으면 n = 6 × 10¹⁵로 줄고 E_F가 조금 내려갑니다(보상). (실리콘 300 K, n_i = 10¹⁰ cm⁻³, ε_s = 11.7ε₀, kT/q = 0.02585 V로 계산. n_i는 1.0 × 10¹⁰과 1.5 × 10¹⁰이 함께 쓰여 교재마다 값이 조금 다릅니다.)

흔한 오해(1) "도핑하면 n과 p가 모두 는다": np = n_i²이라 소수 캐리어는 줄어듭니다. (2) "Fermi 준위는 전자가 있는 에너지": 점유 확률 1/2인 기준 에너지로, 띠틈 안에 있어도 됩니다.
요약
  1. n ≈ N_D − N_A, p = n_i²/n.
  2. E_F − E_i = kT ln(n/n_i), E_C − E_F = kT ln(N_C/n).
  3. 예: 10¹⁶ → 0.357 eV, 0.205 eV.
