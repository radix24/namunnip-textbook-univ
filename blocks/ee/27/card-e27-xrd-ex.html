SiGe 층의 격자 상수

봉우리 이동 → 조성

출발점

SiGe의 격자 상수는 조성에 따라 Si와 Ge 사이에서 거의 선형으로 변합니다(1.4절, Vegard 법칙).

문제 해결 전략 · 각도 → d → a → x
  1. Si a 5.431 Å, Ge 5.658 Å.
  2. (400) 봉우리 2θ = 68.6°(가상, 완화된 층 가정).
  3. a = 4d.

Ge 비율 x는?

풀이

  1. sin34.3° = 0.5635 → d = 1.367 Å → a = 5.468 Å.
    계산.
  2. x = (5.468 − 5.431)/(5.658 − 5.431) = 0.16.
    선형 보간.
  3. Ge 약 16%.
    결과.

의미

실제 변형 층은 면에 수직 방향 격자가 늘어나 보정이 필요합니다(확인 필요).

검산

1.5406/(2 × 0.5635) = 1.367.
