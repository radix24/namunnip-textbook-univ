양자화로 가속기 효율 높이기

본문
이 절에서 배울 것
  • 가중치와 활성값을 INT8로 양자화하는 방법(스케일, 영점)을 안다.
  • 비트 수에 따른 메모리와 연산 에너지 절감을 계산한다.
  • 정확도 손실과 그 대책(보정, 양자화 인식 학습)을 안다.
먼저 알아야 할 것
  • 가속기 구조 (4.1절).

4.3.132비트 → 8비트

실수 x를 \(q = \text{round}(x/s) + z\)(스케일 s, 영점 z)로 8비트 정수에 넣습니다. 메모리와 대역은 1/4, 곱셈기 면적·에너지는 수 분의 1에서 수십 분의 1입니다(45 nm에서 INT8 곱 약 0.2 pJ, FP32 곱 약 3.7 pJ, 확인 필요).

import numpy as np
rng = np.random.default_rng(1)
w = rng.normal(0, 0.05, 1000)                       # 가중치
s = np.abs(w).max() / 127                           # 대칭 양자화 스케일
q = np.clip(np.round(w / s), -127, 127).astype(np.int8)
err = w - q * s
print(f"스케일 {s:.6f}, 최대 오차 {np.abs(err).max():.6f}, 오차 RMS {np.sqrt((err ** 2).mean()):.6f}")
print(f"신호 대 양자화 잡음비 {10 * np.log10((w ** 2).mean() / (err ** 2).mean()):.1f} dB")
print("메모리:", w.astype(np.float32).nbytes, "바이트 →", q.nbytes, "바이트")

실행 결과(Python 3.12에서 실제 실행):

스케일 0.001477, 최대 오차 0.000735, 오차 RMS 0.000422
신호 대 양자화 잡음비 41.4 dB
메모리: 4000 바이트 → 1000 바이트
예제 4.3.1

위 결과에서 메모리 절감과 신호 대 양자화 잡음비는? 왜 이 정도 잡음으로 신경망 정확도가 크게 떨어지지 않는가?

풀이. 4000 → 1000바이트(1/4). 잡음비는 실행 결과의 값(약 40 dB대)입니다. 신경망은 많은 곱의 합이라 개별 오차가 평균되고, 학습된 모델이 작은 잡음에 둔감해 대체로 정확도 손실이 1% 안팎입니다(확인 필요: 모델마다). 손실이 크면 보정 자료로 스케일을 고르거나 양자화를 고려해 다시 학습합니다.

흔한 오해(1) "비트를 줄이면 정확도가 비례해 준다": 8비트까지는 손실이 작은 경우가 많습니다. (2) "한 스케일을 모든 층에 쓴다": 층·채널마다 범위가 달라 각각 정합니다.
요약
  1. q = round(x/s) + z, 대칭이면 z = 0.
  2. 메모리 1/4, 연산 에너지 크게 감소.
  3. 보정·양자화 인식 학습으로 손실 줄임.
