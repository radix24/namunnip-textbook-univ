큐잉 모델로 지연 추정

본문
이 절에서 배울 것
  • 요청이 무작위로 오는 서버를 M/M/1 큐로 모델링한다.
  • 평균 지연 \(W = 1/(\mu - \lambda)\)와 이용률 ρ = λ/μ를 계산한다.
  • 이용률이 1에 가까울수록 지연이 급증함을 보인다.
먼저 알아야 할 것
  • 처리량·지연 모델 (2.1절).

2.4.1바쁠수록 기다린다

요청이 초당 λ개(Poisson) 오고 서비스가 평균 1/μ초(지수 분포)면, 시스템 안 평균 시간 \(W = 1/(\mu - \lambda)\), 이용률 ρ = λ/μ. ρ가 0.5에서 0.9로 가면 지연이 5배가 됩니다.

mu = 1000.0                      # 초당 1000개 처리 가능
for lam in (500, 800, 900, 950, 990):
    W = 1 / (mu - lam)
    print(f"λ = {lam:4d}/s, 이용률 {lam / mu:.2f}: 평균 지연 {W * 1000:6.1f} ms")

실행 결과(Python 3.12에서 실제 실행):

λ =  500/s, 이용률 0.50: 평균 지연    2.0 ms
λ =  800/s, 이용률 0.80: 평균 지연    5.0 ms
λ =  900/s, 이용률 0.90: 평균 지연   10.0 ms
λ =  950/s, 이용률 0.95: 평균 지연   20.0 ms
λ =  990/s, 이용률 0.99: 평균 지연  100.0 ms
예제 2.4.1

추론 서버 처리 능력 1000개/s, 요청 800개/s의 평균 지연은? 평균 지연을 2 ms 이하로 하려면 처리 능력은?

풀이. W = 1/200 = 5 ms. 2 ms 이하: μ − 800 ≥ 500 → μ ≥ 1300개/s. 처리 능력을 30% 늘리면 지연이 60% 줄어, 이용률을 70~80% 아래로 두는 것이 지연에 유리합니다.

흔한 오해(1) "처리 능력이 요청보다 크면 지연은 작다": 이용률이 1에 가까우면 지연이 매우 커집니다. (2) "평균 지연만 보면 된다": 꼬리 지연은 훨씬 커서 따로 봐야 합니다.
요약
  1. W = 1/(μ − λ), ρ = λ/μ.
  2. ρ → 1이면 지연 급증.
  3. 예: 800/1000 → 5 ms, 2 ms에는 μ ≥ 1300.

2.4.2연습문제

기본

  1. μ = 100/s, λ = 50/s의 W는?
    답

    20 ms.

응용

  1. 같은 μ에서 λ = 90/s면?
    답

    100 ms.

심화

  1. 서버를 두 대로 늘려 각각 λ/2를 받으면(μ 같음) λ = 90의 지연은?
    답

    1/(100 − 45) = 18.2 ms.
