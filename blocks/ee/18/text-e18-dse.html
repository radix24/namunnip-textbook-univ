설계 공간 탐색

본문
이 절에서 배울 것
  • 설계 변수와 그 범위로 설계 공간을 정의한다.
  • 전수 탐색, 무작위 탐색, 탐욕 탐색의 비용과 품질을 비교한다.
  • 제약 조건을 만족하는 설계 중 목표가 가장 좋은 것을 고른다.
먼저 알아야 할 것
  • 파레토 최적 (3.1절), 모델 (2.2절).

3.2.1얼마나 많이 시험하나

변수 k개가 각각 m개 값을 가지면 설계가 mᵏ개라, 모델이 빨라야 전수 탐색이 가능합니다. 클 때는 무작위 표본, 한 변수씩 바꾸는 탐욕 탐색, 베이지안 최적화를 씁니다.

import itertools
best = None
for pe, buf, f in itertools.product([16, 32, 64, 128], [64, 128, 256], [0.5, 0.8, 1.0]):
    thr = min(pe * f, buf / 2) * 1.0                 # 처리량(GOPS): 연산 또는 대역 한계
    power = 0.01 * pe * f + 0.002 * buf + 0.1        # 전력(W)
    area = 0.05 * pe + 0.01 * buf                    # 면적(mm²)
    if power <= 1.0 and area <= 6.0:                 # 제약
        if best is None or thr > best[0]:
            best = (thr, pe, buf, f, round(power, 3), area)
print("설계 수:", 4 * 3 * 3)
print("제약 안 최고 처리량(GOPS, PE, 버퍼 KB, GHz, W, mm²):", best)

실행 결과(Python 3.12에서 실제 실행):

설계 수: 36
제약 안 최고 처리량(GOPS, PE, 버퍼 KB, GHz, W, mm²): (64.0, 64, 128, 1.0, 0.996, 4.48)
예제 3.2.1

위 장난감 모델에서 전수 탐색으로 찾은 설계는? 변수가 6개(값 10개씩)면 전수 탐색이 가능한가?

풀이. 36개 설계 중 제약을 만족하며 처리량이 가장 큰 것이 실행 결과의 설계입니다. 10⁶개는 모델이 1 ms면 약 17분이라 가능하지만, 시뮬레이션이 1분이면 2년이라 불가능해 표본 탐색을 씁니다.

흔한 오해(1) "모든 조합을 시험해야 최선": 모델이 비싸면 영리한 탐색으로 충분히 좋은 해를 찾습니다. (2) "제약은 나중에 확인": 탐색 중에 걸러야 시간을 아낍니다.
요약
  1. 설계 수 mᵏ.
  2. 전수·무작위·탐욕·베이지안 탐색.
  3. 제약 만족 + 목표 최적.
