FM의 변조 지수와 Carson 대역폭

본문
이 절에서 배울 것
  • FM 신호의 순간 주파수 \(f_c + k_fm(t)\)와 최대 주파수 편이 Δf를 안다.
  • 정현파 메시지 FM의 스펙트럼을 Bessel 함수 \(J_n(\beta)\)로 쓴다.
  • Carson 규칙 \(B \approx 2(\Delta f + W) = 2(\beta + 1)W\)로 대역폭을 어림한다.
먼저 알아야 할 것
  • 해석 신호와 순간 주파수 (1.2절), Fourier 급수 (전전6 3.1절), 이 절의 탐구 카드.

4.1.1순간 주파수

FM은 진폭을 일정하게 두고 순간 주파수를 메시지에 비례해 바꿉니다: \(f_i(t) = f_c + k_fm(t)\), \(s(t) = A_c\cos\left(2\pi f_ct + 2\pi k_f\int_0^tm(\tau)d\tau\right)\). 최대 편이 \(\Delta f = k_f\max|m|\), 변조 지수 \(\beta = \Delta f/W\)(정현파 메시지면 \(f_m\) 대신).

4.1.2Bessel 스펙트럼

\(m = \cos2\pi f_mt\)이면 \(s(t) = A_c\sum_{n=-\infty}^{\infty}J_n(\beta)\cos2\pi(f_c + nf_m)t\). 주파수 \(f_c \pm nf_m\)에 크기 \(|J_n(\beta)|\)인 선이 무한히 있지만, n이 β보다 커지면 빠르게 작아집니다. 진폭이 일정하므로 전체 전력은 β와 무관하게 \(A_c^2/2\)이고 \(J_0^2 + 2\sum J_n^2 = 1\)입니다.

예제 4.1.1

FM 방송: Δf = 75 kHz, W = 15 kHz. (가) β와 Carson 대역폭. (나) β = 5에서 \(J_0, \dots, J_3\). (다) 반송파 성분이 사라지는 β.

풀이. (가) β = 5, \(2(75 + 15) = 180\) kHz(채널 간격 200 kHz). (나) \(J_0 = -0.178\), \(J_1 = -0.328\), \(J_2 = 0.047\), \(J_3 = 0.365\). 전력의 98%를 담으려면 ±6개 측파(탐구 카드), 곧 180 kHz로 Carson과 같습니다. (다) \(J_0(\beta) = 0\)인 β ≈ 2.405. 이 성질로 스펙트럼 분석기에서 반송파가 사라지는 점을 찾아 Δf를 보정합니다.

β ≪ 1이면(협대역 FM) 측파가 ±f_m 한 쌍뿐이라 대역폭이 AM과 같은 2W입니다.

흔한 오해(1) "FM 대역폭은 2Δf다": 메시지 대역 W도 더해야 합니다(Carson). β가 작으면 2W가 지배합니다. (2) "변조하면 반송파 전력이 늘어난다": 전체 전력은 일정하고 반송파와 측파 사이에서 나뉠 뿐입니다.
요약
  1. 순간 주파수 \(f_c + k_fm(t)\), \(\beta = \Delta f/W\).
  2. 정현파 FM: \(J_n(\beta)\) 측파, 전력 합 1. \(J_0(2.405) = 0\).
  3. Carson: \(B \approx 2(\Delta f + W)\).

4.1.3연습문제

기본

  1. Δf = 5 kHz, W = 3 kHz FM 무전기의 Carson 대역폭은?
    답

    16 kHz.

응용

  1. β = 1의 반송파와 첫 측파 성분 크기는?
    답

    \(J_0(1) = 0.765\), \(J_1(1) = 0.440\).

심화

  1. \(J_0^2 + 2\sum J_n^2 = 1\)을 β = 1 값(J₀ 0.7652, J₁ 0.4401, J₂ 0.1149, J₃ 0.0196)으로 확인하라.
    답

    0.5855 + 2(0.1937 + 0.0132 + 0.0004) = 0.5855 + 0.4146 ≈ 1.000.
