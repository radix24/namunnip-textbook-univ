Hilbert 변환과 해석 신호

본문
이 절에서 배울 것
  • Hilbert 변환이 모든 주파수 성분의 위상을 90° 늦추는 필터임을 안다.
  • 해석 신호 \(x_a = x + j\hat x\)가 양의 주파수만 갖는 것을 확인한다.
  • 해석 신호의 크기로 포락선, 각으로 순간 위상과 주파수를 얻는다.
먼저 알아야 할 것
  • Fourier 변환 (전전6 4.1절), 복소 지수와 오일러 공식, 이 절의 탐구 카드.

1.2.190° 이동기

Hilbert 변환: \(\hat x(t) = x(t) * \frac{1}{\pi t}\), 주파수 영역에서 \(\hat X(f) = -j\,\mathrm{sgn}(f)X(f)\).

양의 주파수는 −90°, 음의 주파수는 +90° 돌리고 크기는 그대로입니다. 그래서 \(\cos\omega t \to \sin\omega t\), \(\sin\omega t \to -\cos\omega t\). 대역이 반송파보다 낮은 메시지 m(t)에 대해 \(\widehat{m(t)\cos\omega_ct} = m(t)\sin\omega_ct\)입니다(Bedrosian 정리).

1.2.2해석 신호

\(x_a(t) = x(t) + j\hat x(t)\)의 스펙트럼은 \(X(f)(1 + \mathrm{sgn}f)\): 양의 주파수는 2배, 음의 주파수는 0입니다. 실제 신호의 두 쪽 스펙트럼 중 한쪽만 남긴 복소 신호입니다.

  • 포락선 \(|x_a(t)|\), 순간 위상 \(\angle x_a(t)\), 순간 주파수 \(\frac{1}{2\pi}\frac{d}{dt}\angle x_a\).
  • \(\cos\omega_0t\)의 해석 신호는 \(e^{j\omega_0t}\): 크기 1, 위상이 일정하게 돈다.
예제 1.2.1

\(x(t) = (1 + 0.5\cos2\pi t)\cos2\pi\cdot20t\)의 Hilbert 변환, 해석 신호, 포락선을 구하라.

풀이. 메시지 대역(1 Hz)이 반송파(20 Hz)보다 낮으므로 \(\hat x = (1 + 0.5\cos2\pi t)\sin2\pi\cdot20t\), \(x_a = (1 + 0.5\cos2\pi t)e^{j2\pi\cdot20t}\), 포락선 \(1 + 0.5\cos2\pi t\)(최대 1.5, 최소 0.5). 탐구 카드에서 μ를 1보다 크게 하면 포락선이 메시지와 달라지는 것을 봅니다.

해석 신호는 SSB 변조(2.3절), 디지털 수신기의 I/Q 처리, 진동 분석의 포락선 검출에 쓰입니다.

흔한 오해(1) "Hilbert 변환은 시간을 1/4 주기 늦춘다": 모든 주파수의 위상을 같은 90° 돌리므로, 주파수마다 시간 지연이 다릅니다. (2) "포락선은 신호의 최댓값을 이은 선": 해석 신호의 크기로 정의되며, 반송파가 메시지보다 충분히 빠를 때 직관과 맞습니다.
요약
  1. \(\hat X = -j\,\mathrm{sgn}(f)X\): 모든 성분 90° 이동, cos → sin.
  2. 해석 신호 \(x + j\hat x\): 양의 주파수만.
  3. 포락선 = |x_a|, 순간 위상 = ∠x_a.

1.2.3연습문제

기본

  1. \(\sin(2\pi 50t)\)의 Hilbert 변환은?
    답

    \(-\cos(2\pi 50t)\).

응용

  1. \(x = \cos\omega_1t + \cos\omega_2t\)의 해석 신호는?
    답

    \(e^{j\omega_1t} + e^{j\omega_2t}\).

심화

  1. Hilbert 변환을 두 번 하면? 에너지는 어떻게 되는가?
    답

    \(-x(t)\)(직류 성분이 없을 때). 크기 응답이 1이라 에너지는 같습니다.
