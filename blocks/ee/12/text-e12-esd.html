에너지 스펙트럼 밀도와 전력 스펙트럼 밀도

본문
이 절에서 배울 것
  • 에너지 신호와 전력 신호를 구별한다.
  • 에너지 스펙트럼 밀도 \(|X(f)|^2\)와 Parseval 정리로 대역 안의 에너지를 계산한다.
  • 주기 신호와 랜덤 신호의 전력 스펙트럼 밀도를 구하고 대역폭을 정의한다.
먼저 알아야 할 것
  • Fourier 변환 (전전6 4.1절), PSD와 Wiener-Khinchin (전전11 5.1절).

1.1.1에너지 신호와 전력 신호

에너지 신호: \(E = \int|x(t)|^2dt\)가 유한(펄스 하나). 평균 전력은 0.

전력 신호: 평균 전력 \(P = \lim\frac1T\int_{-T/2}^{T/2}|x|^2dt\)가 유한하고 0이 아님(주기 신호, 랜덤 신호). 에너지는 무한.

에너지 신호는 에너지 스펙트럼 밀도(ESD) \(\Psi(f) = |X(f)|^2\)를, 전력 신호는 전력 스펙트럼 밀도(PSD) S(f)를 씁니다. Parseval 정리 \(\int|x|^2dt = \int|X(f)|^2df\)가 둘을 잇습니다.

1.1.2사각 펄스의 에너지 분포

예제 1.1.1

진폭 A = 1 V, 폭 T = 1 ms인 사각 펄스(1 Ω 기준). (가) 에너지, (나) ESD, (다) |f| ≤ 1/T(주엽) 안의 에너지 비율.

풀이. (가) \(E = A^2T = 1\) mJ. (나) \(X(f) = AT\,\mathrm{sinc}(fT)\)이므로 \(\Psi(f) = A^2T^2\mathrm{sinc}^2(fT)\). (다) \(\int_{-1/T}^{1/T}T^2\mathrm{sinc}^2(fT)df/T = \int_{-1}^{1}\mathrm{sinc}^2u\,du \approx 0.903\). 에너지의 90.3%가 ±1 kHz 안에 있어, 이 펄스로 디지털 신호를 보낼 때 필요한 대역폭을 대략 1/T로 잡는 근거가 됩니다.

1.1.3주기 신호의 PSD

주기 \(T_0\)인 신호의 Fourier 급수 계수 \(c_n\)이 있으면 PSD는 \(S(f) = \sum|c_n|^2\delta(f - nf_0)\): 전력이 고조파에 나뉘어 있습니다. 예: \(A\cos2\pi f_0t\)는 ±f₀에 \(A^2/4\)씩, 합 \(A^2/2\).

대역폭의 정의: 절대 대역폭(스펙트럼이 0이 아닌 범위), 3 dB 대역폭, 영점 간 대역폭, 전력 일정 비율(예: 99%)을 담는 대역폭 등. 같은 신호도 정의에 따라 값이 다르므로 함께 밝힌다.

흔한 오해(1) "ESD와 PSD는 같은 단위다": ESD는 J/Hz(V²·s/Hz), PSD는 W/Hz. (2) "사각 펄스의 대역폭은 1/T이다": 주엽만의 근사이고 실제 스펙트럼은 무한히 퍼집니다. (3) 양측 스펙트럼에서 대역 안 에너지를 구할 때 음의 주파수 쪽을 빠뜨리는 실수.
요약
  1. 에너지 신호 → ESD \(|X(f)|^2\), 전력 신호 → PSD.
  2. Parseval: 시간 영역 에너지 = 주파수 영역 에너지. 사각 펄스 주엽에 90.3%.
  3. 주기 신호 PSD = 고조파 위치의 델타, 크기 \(|c_n|^2\). 대역폭은 정의를 밝힌다.

1.1.4연습문제

기본

  1. \(x(t) = 2\cos(2\pi 100t) + \cos(2\pi 300t)\)의 평균 전력은?
    답

    2 + 0.5 = 2.5 W.

응용

  1. \(x(t) = e^{-at}u(t)\)(a > 0)의 에너지와 ESD는?
    답

    \(E = 1/(2a)\), \(\Psi = 1/(a^2 + (2\pi f)^2)\).

심화

  1. 예제의 펄스에서 영점 간 대역폭(양측)과 3 dB 대역폭(한쪽)을 비교하라.
    답

    영점 간 ±1 kHz(2 kHz). \(\mathrm{sinc}^2(fT) = 0.5\)는 fT ≈ 0.443, 약 443 Hz.
