영상 제거에 필요한 필터

필터 선택도

출발점

영상과 원하는 신호의 주파수 차이 2IF가 앞단 필터의 기준입니다(2.5절).

문제 해결 전략 · 2IF → 필터 차수
  1. 영상까지 거리 2IF.
  2. 필요한 영상 제거(dB)를 정한다.
  3. 필터 차수를 어림한다.

IF 10.7 MHz에서 영상(21.4 MHz 떨어짐)을 60 dB 막아야 한다. 대역폭 2 MHz(±1 MHz) 버터워스 대역 통과면 몇 차가 필요한가?

풀이

  1. 정규화 거리 21.4/1 ≈ 21.4배(반 대역폭 기준).
    주파수 비.
  2. 버터워스 감쇠 ≈ 20n log(21.4) = 26.6n dB.
    점근.
  3. 60 dB → n ≥ 2.3 → 3차.
    올림.

의미

IF를 455 kHz로 낮추면 영상이 0.91 MHz 떨어져 같은 필터로는 막을 수 없다.

검산

3차면 약 80 dB.
