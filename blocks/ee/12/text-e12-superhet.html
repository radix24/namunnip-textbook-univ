슈퍼헤테로다인 수신기와 영상 주파수

본문
이 절에서 배울 것
  • 국부 발진기로 수신 신호를 중간 주파수(IF)로 내리는 구조를 안다.
  • 영상 주파수 \(f_{img} = f_{RF} \pm 2f_{IF}\)를 계산한다.
  • IF 선택이 영상 제거와 선택도에 주는 절충을 안다.
먼저 알아야 할 것
  • 주파수 혼합(곱셈) (2.1절).

2.5.1같은 IF로 오는 두 주파수

RF 신호와 국부 발진 f_LO를 곱하면 차 주파수 |f_RF − f_LO|가 IF가 됩니다. f_LO = f_RF + f_IF이면 f_LO + f_IF도 같은 IF로 내려오므로, 이 영상 주파수를 혼합기 앞 필터로 막아야 합니다.

예제 2.5.1

FM 라디오 100 MHz, IF 10.7 MHz, 고측 국부 발진. f_LO와 영상 주파수는?

풀이. f_LO = 110.7 MHz, 영상 121.4 MHz. FM 대역(88~108 MHz) 밖이라 앞단 필터로 쉽게 막습니다. IF를 낮게 하면 좁은 IF 필터로 선택도가 좋아지지만 영상이 가까워져 막기 어려워, 두 번 내리는 이중 변환을 씁니다.

흔한 오해(1) "원하는 신호만 IF로 내려온다": 영상 주파수도 똑같이 내려옵니다. (2) "IF는 높을수록 좋다": 영상 제거는 쉬워지지만 IF 필터의 선택도가 나빠집니다.
요약
  1. IF = |f_RF − f_LO|.
  2. 영상 = f_RF ± 2IF(국부 발진 쪽).
  3. 예: 100 MHz, IF 10.7 → 영상 121.4 MHz.
