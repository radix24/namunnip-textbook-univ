잡음 지수와 Friis 식

본문

수신기는 저잡음 증폭기(LNA), 혼합기, IF 증폭기를 차례로 잇는다. 단마다 잡음을 조금씩 더하는데, 전체 잡음 성능은 각 단 잡음 지수의 단순한 합일까? 같은 부품을 순서만 바꿔 이으면 성능이 달라질까? 안테나와 LNA 사이의 케이블 1 m는 얼마나 손해일까?

먼저 알아야 할 것열잡음과 잡음 등가 대역폭(전전11 5.3절), dB 계산을 쓴다.

5.1.1잡음 지수

회로가 SNR을 얼마나 나쁘게 하는지는 잡음 지수 \(F = \dfrac{\text{SNR}_{in}}{\text{SNR}_{out}}\)로 나타낸다. 이때 입력 잡음은 290 K 열잡음을 기준으로 하며, dB로는 NF = 10 log F이다. 같은 양을 회로 잡음을 입력에 둔 저항의 온도로 환산한 것이 등가 잡음 온도 \(T_e = (F - 1)\times290\) K이다.

5.1.2Friis 식

이득 \(G_1, G_2, \dots\), 잡음 지수 \(F_1, F_2, \dots\)인 단을 이으면, 둘째 단의 잡음은 첫 단 이득으로 나누어 입력에 환산된다. 그래서 전체 잡음 지수는 단순한 합이 아니라 다음 Friis 식이며, 처음 질문의 첫째 답이 이것이다.

\[ F = F_1 + \frac{F_2 - 1}{G_1} + \frac{F_3 - 1}{G_1G_2} + \cdots. \]
예제 5.1.1

LNA(G 20 dB, NF 1 dB) → 혼합기(G −6 dB, NF 8 dB) → IF 증폭기(G 30 dB, NF 4 dB). 전체 NF와 \(T_e\)는? LNA와 혼합기 순서를 바꾸면?

풀이. 선형 값은 \(F_1 = 1.259\), \(G_1 = 100\), \(F_2 = 6.31\), \(G_2 = 0.251\), \(F_3 = 2.512\)이다. 그러면 \(F = 1.259 + 5.31/100 + 1.512/25.1 = 1.259 + 0.053 + 0.060 = 1.372\)이므로 NF 1.37 dB, \(T_e \approx 108\) K이다. 순서를 바꾸면 \(6.31 + 0.259/0.251 + 1.512/25.1 = 7.40\)으로 NF 8.69 dB가 되어 7 dB 넘게 나빠진다(그림 1). 처음 질문의 둘째 답이 이것이다.

한편 케이블이나 필터처럼 손실이 있는 수동 소자는 실온에서 이득 1/L, 잡음 지수 L이다. 그러므로 안테나와 LNA 사이 케이블 손실 1 dB가 전체 NF를 거의 1 dB 높인다. 처음 질문의 셋째 답이 이것이며, 위성 수신기가 LNA를 안테나 바로 뒤에 다는 이유이다.

흔한 실수dB 값을 Friis 식에 그대로 넣는 실수가 흔하며, 반드시 선형 값으로 계산한다. 잡음 지수가 큰 단은 어디에 있어도 같다는 생각도 틀리며, 앞 단 이득이 크면 뒤 단의 영향은 작아진다. 또 잡음 지수는 대역폭과 무관한 비율이고, 실제 잡음 전력은 \(kT_0FB\)처럼 대역폭을 곱해 구한다.
마무리

잡음 지수는 F = SNR_in/SNR_out(290 K 기준)이고, 등가 잡음 온도는 \(T_e = (F-1)290\)이다. 여러 단의 잡음 지수는 선형 값의 Friis 식 \(F = F_1 + (F_2-1)/G_1 + (F_3-1)/(G_1G_2) + \cdots\)로 구한다. 첫 단이 전체를 지배하므로 LNA를 맨 앞에 두고 앞쪽 손실을 줄인다.

5.1.3연습문제

기본

  1. NF 3 dB의 등가 잡음 온도는?
    답

    F ≈ 2이고, \(T_e \approx 290\) K이다.

응용

  1. 예제에서 LNA 이득을 10 dB로 낮추면 전체 NF는?
    답

    \(1.259 + 5.31/10 + 1.512/2.51 = 2.392\)이므로 약 3.79 dB이다.

심화

  1. 안테나와 예제 수신기 사이에 손실 2 dB 케이블(F = 1.585, G = 0.631)이 있으면 전체 NF는?
    답

    \(1.585 + (1.372 - 1)/0.631 = 2.175\)이므로 약 3.37 dB로, 2 dB 나빠진다.
