FM 스펙트럼: Bessel 함수의 선들

탐구 · 변조 지수와 Carson 대역폭

질문

FM의 변조 지수를 키우면 측파가 몇 개나 생길까요? 반송파 성분이 사라지는 경우도 있을까요?

준비

정현파 메시지 FM의 스펙트럼 선 크기 \(|J_n(\beta)|\)를 \(f_c + nf_m\) 위치(가로축은 \(f_m\) 단위)에 그립니다(4.1절). Bessel 함수는 적분식을 수치로 계산합니다. 주황 선의 폭이 Carson 대역폭이고, 출력 줄에 전력 98%를 담는 측파 수를 적습니다.

해 보기와 설명

  1. FM 방송β = 5, f_m = 15 kHz: Δf = 75 kHz, J₀ = −0.1776, J₁ = −0.3276, J₂ = 0.0466, J₃ = 0.3648. 전력 합 1.0000. Carson 180 kHz, 98% 대역 ±6개 측파 → 180 kHz(예제 4.1.1).
  2. 반송파 소멸β = 2.40 근처로 맞추면 가운데 선이 거의 0이 됩니다(J₀(2.405) = 0).
  3. 협대역β = 0.2면 J₀ = 0.990, J₁ = 0.0995로 측파 한 쌍만 보입니다. 대역폭이 AM과 같은 2f_m 근처입니다.
  4. 큰 ββ = 10이면 측파가 ±11개 근처까지 퍼집니다. Carson 대역폭이 β에 거의 비례해 커집니다.

연결과 적용

FM 방송(88~108 MHz)은 채널 간격 200 kHz에 β = 5를 쓰고, 무전기는 β가 1 근처인 좁은 FM을 씁니다. 같은 Bessel 스펙트럼이 위상 변조와 주파수 합성기의 잡음 분석에도 나옵니다.

흔한 오해

  • "FM 측파는 ±Δf까지만 있다." 이론상 무한히 있지만 크기가 빠르게 줄어 Carson 대역에 98% 정도가 들어갑니다.
  • "변조하면 전체 전력이 커진다." 진폭이 일정해 전력은 그대로이고, 반송파에서 측파로 나뉠 뿐입니다(전력 합 1).
