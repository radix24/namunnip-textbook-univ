광공진기의 미세도와 Q 인자

본문
이 절에서 배울 것
  • 투과율 \(T = 1/(1 + \frac{4R}{(1 - R)^2}\sin^2\frac\delta2)\)의 모양을 안다.
  • 미세도 \(F = \pi\sqrt R/(1 - R)\), 반치폭 δν = FSR/F를 계산한다.
  • Q = ν/δν와 광자 수명의 관계를 설명한다.
먼저 알아야 할 것
  • FSR (1.3절), 공진기의 Q (전전19 5.1절), 이 절의 탐구 카드.

1.4.1날카로움

거울 반사율 R이 클수록 빛이 많이 왕복해 공진 봉우리가 좁아집니다. 봉우리 간격(FSR)과 폭(δν)의 비가 미세도입니다.

\[ F = \frac{\pi\sqrt R}{1 - R}, \qquad \delta\nu = \frac{\text{FSR}}{F}, \qquad Q = \frac{\nu}{\delta\nu}. \]
예제 1.4.1

L = 1 mm 공기 공진기, R = 0.9와 0.99. F, δν, 1550 nm(193.4 THz)에서의 Q는?

풀이. R = 0.9: F = 29.8, δν = 5.03 GHz, Q = 3.85 × 10⁴. R = 0.99: F = 312.6, δν = 0.480 GHz, Q = 4.03 × 10⁵. 탐구 카드에서 R을 바꿔 봉우리가 좁아지는 것을 봅니다(FSR을 2.998 × 10⁸ m/s로 계산해 149.9 GHz).

Q가 크면 광자가 오래 머물고(광자 수명 τ = Q/(2πν)), 좁은 선폭의 필터·레이저·센서가 됩니다. 광통신의 파장 선택 필터와 레이저 공진기가 이 원리입니다.

흔한 오해(1) "반사율이 높으면 빛이 통과하지 못한다": 공진 주파수에서는 손실이 없다면 투과율 1입니다. (2) "미세도와 Q는 같다": Q = 모드 차수 × F 정도로 Q가 훨씬 큽니다.
요약
  1. F = π√R/(1 − R), δν = FSR/F, Q = ν/δν.
  2. R 0.9 → F 29.8, R 0.99 → F 312.6.
  3. Q가 크면 광자 수명이 길고 선폭이 좁다.
