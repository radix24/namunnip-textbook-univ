광섬유 감쇠와 dB 계산

본문
이 절에서 배울 것
  • 감쇠를 dB/km로 나타내고 길이에 곱한다.
  • dB와 전력 비, dBm과 mW를 오간다.
  • 파장별 손실 창(850, 1310, 1550 nm)을 안다.
먼저 알아야 할 것
  • 광섬유 (2.1절), 분산 (2.2절).

2.3.1곱 대신 덧셈

광섬유 손실은 Rayleigh 산란과 흡수로 생기며 1550 nm에서 약 0.2 dB/km로 가장 작습니다(확인 필요: 섬유마다). dB로 쓰면 길이에 곱하고 부품 손실은 더하면 됩니다. P(dBm) = 10log(P/1 mW).

예제 2.3.1

0.2 dB/km 광섬유 100 km의 손실과 남는 전력 비율은? 입력 0 dBm이면 출력은?

풀이. 20 dB → 1%(10⁻²). 출력 −20 dBm = 10 μW. 수신기 감도가 −28 dBm이면 여유 8 dB입니다. 더 멀리 가려면 광증폭기(EDFA)를 씁니다.

흔한 오해(1) "dB 손실은 길이에 지수적": dB 자체는 길이에 비례하고, 전력이 지수적으로 줄어듭니다. (2) "모든 파장의 손실이 같다": 1550 nm가 가장 작습니다.
요약
  1. 손실(dB) = α(dB/km) × L.
  2. P(dBm) = 10log(P/1 mW).
  3. 예: 0.2 × 100 = 20 dB → 1%.
