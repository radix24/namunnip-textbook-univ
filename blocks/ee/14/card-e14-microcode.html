마이크로명령 순서로 lw 실행하기

예제 · 다중 사이클 제어 저장소

먼저 예측

다중 사이클 CPU에서 lw 한 명령은 마이크로명령 몇 개로 실행될까요?

생각해 본 뒤 열기

인출, 해독, 주소 계산, 메모리 읽기, 레지스터 쓰기의 다섯 단계로 나눌 수 있습니다.

문제

다중 사이클 구현의 마이크로명령: ① 인출(IR ← Mem[PC], PC ← PC + 4) ② 해독·레지스터 읽기 ③ 주소 계산(ALU ← A + imm) ④ 메모리 읽기(MDR ← Mem[ALUOut]) ⑤ 쓰기(Reg[rd] ← MDR). (가) lw, sw, add, beq의 마이크로명령 순서와 사이클 수, (나) 비율 lw 25%, sw 10%, add 50%, beq 15%의 평균 CPI.

전략

  1. 모든 명령이 ①②를 공유.
  2. sw는 ③ 뒤 메모리 쓰기로 끝, add는 실행·쓰기, beq는 비교로 끝.

풀이

  1. lw ①②③④⑤ 5, sw ①②③ + 쓰기 4, add ①② + 실행 + 쓰기 4, beq ①② + 비교 3. 순서
  2. CPI = 0.25 × 5 + 0.1 × 4 + 0.5 × 4 + 0.15 × 3 = 4.1. 평균

의미

공유 단계(①②)는 제어 저장소에 한 번만 두고, ② 뒤에 opcode로 다음 마이크로 주소를 고르는 표(디스패치 표)로 갈라집니다. 이 구조가 복잡한 명령을 단계 수만 늘려 구현할 수 있게 합니다.

검산

1.25 + 0.4 + 2.0 + 0.45 = 4.1.

이해 확인

다중 사이클 클록 주기가 200 ps면 단일 사이클(800 ps, CPI 1)과 비교한 평균 명령 시간은?

답

4.1 × 200 = 820 ps로 단일 사이클(800 ps)과 비슷합니다. 파이프라인이 둘 다를 이깁니다.
