IEEE 754 부동소수점 덧셈

본문
이 절에서 배울 것
  • 단정밀도 형식(부호 1, 지수 8(바이어스 127), 가수 23비트)으로 수를 나타낸다.
  • 덧셈 순서(지수 맞추기 → 가수 더하기 → 정규화 → 반올림)를 따라간다.
  • 0.1처럼 2진으로 정확히 나타낼 수 없는 수의 오차를 안다.
먼저 알아야 할 것
  • 2진 소수, 2의 거듭제곱, 이 절의 탐구 카드.

3.2.1형식

값 \((-1)^s \times 1.f \times 2^{e - 127}\). 가수의 맨 앞 1은 저장하지 않습니다(숨은 비트). 지수 0과 255는 0·비정규 수, 무한대·NaN에 씁니다.

예: 0.75 = 1.1₂ × 2⁻¹ → s = 0, e = 126 = 01111110, f = 100…0 → 0x3F400000. −6.5 = −1.101₂ × 2² → 0xC0D00000.

3.2.2덧셈

  1. 지수가 작은 쪽의 가수를 차이만큼 오른쪽으로 옮겨 지수를 맞춘다.
  2. 가수를 더한다(부호가 다르면 뺀다).
  3. 결과를 1.xxx 꼴로 정규화하며 지수를 조정한다.
  4. 23비트로 반올림한다(가장 가까운 짝수로).
예제 3.2.1

0.75 + 1.5를 단정밀도로 따라가라.

풀이. 0.75 = 1.1 × 2⁻¹, 1.5 = 1.1 × 2⁰. 지수를 0에 맞추면 0.75 = 0.11 × 2⁰. 더하면 0.11 + 1.1 = 10.01 × 2⁰. 정규화 1.001 × 2¹ = 2.25. 반올림 필요 없음. 결과 0x40100000.

0.1은 2진으로 0.000110011…(무한 반복)이라 단정밀도 저장값은 0.100000001490…입니다. 단정밀도에서는 0.1 + 0.2가 우연히 0.3의 저장값과 같지만, 배정밀도에서는 0.30000000000000004로 0.3과 다릅니다. 탐구 카드에서 직접 확인합니다.

흔한 오해(1) "부동소수점 덧셈은 결합 법칙이 성립한다": (a + b) + c와 a + (b + c)가 반올림 때문에 다를 수 있습니다. (2) "부동소수점 값을 ==로 비교하면 된다": 오차 범위 안인지 비교해야 합니다. (3) 지수 차이가 24 이상이면 작은 수는 가수 밖으로 밀려 더해도 변하지 않습니다(1e8 + 1 = 1e8, 단정밀도).
요약
  1. 단정밀도: s(1) | e(8, 바이어스 127) | f(23), 값 \((-1)^s 1.f\, 2^{e-127}\).
  2. 덧셈: 지수 맞추기 → 더하기 → 정규화 → 반올림.
  3. 0.1은 정확히 표현 불가. 결합 법칙·== 비교에 주의.

3.2.3연습문제

기본

  1. 1.0의 단정밀도 16진 표현은?
    답

    0x3F800000.

응용

  1. −5.75(= −6.5 + 0.75)의 단정밀도 표현은?
    답

    −1.0111 × 2²: 0xC0B80000.

심화

  1. 단정밀도에서 16777216(2²⁴) + 1의 결과는? 이유는?
    답

    16777216. 가수 24비트(숨은 비트 포함)로 2²⁴ 근처에서는 간격이 2라 1을 더하면 짝수 쪽으로 반올림됩니다.
