TLB 적중률과 실효 접근 시간

예제 · 주소 변환 비용

먼저 예측

TLB 적중률이 99%에서 95%로 떨어지면 메모리 접근이 얼마나 느려질까요?

생각해 본 뒤 열기

실패 때마다 페이지 표를 한 번 더 읽어야 해서, 4%p 차이로 실효 시간이 약 4% 늘어납니다(캐시 없을 때).

문제

TLB 1사이클, 메모리 접근 100사이클, 단일 단계 페이지 표(TLB 실패 시 메모리 한 번 더), 캐시 없음. (가) TLB 적중률 99%와 95%의 실효 접근 시간, (나) 4단계 페이지 표(실패 시 4번 더 읽기)이면 99%에서?

전략

  1. 적중: TLB + 메모리.
  2. 실패: TLB + 표 읽기 + 메모리.

풀이

  1. (가) 99%: 0.99 × 101 + 0.01 × 201 = 102. 95%: 0.95 × 101 + 0.05 × 201 = 106. 단일 단계
  2. (나) 실패 시 1 + 400 + 100 = 501: 0.99 × 101 + 0.01 × 501 = 105. 4단계

의미

다단계 표는 메모리를 아끼지만 TLB 실패가 비싸집니다. 그래서 TLB를 키우고, 큰 페이지(2 MB 등)로 TLB 하나가 덮는 범위를 넓히며, 페이지 표 항목도 캐시에 들어가게 해 실제 손해를 줄입니다.

검산

99%: 99.99 + 2.01 = 102.0. 95%: 95.95 + 10.05 = 106.0. 4단계: 99.99 + 5.01 = 105.0.
