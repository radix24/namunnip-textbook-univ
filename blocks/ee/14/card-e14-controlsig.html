addi와 jal의 제어 신호 정하기

예제 · 표를 확장하기

먼저 예측

4.1절 표에 없는 addi와 jal의 제어 신호는 어떻게 정할까?

생각해 본 뒤 열기

각 명령이 데이터패스의 어느 경로를 쓰는지 따라가면 정해진다.

문제

4.1절의 단일 사이클 데이터패스에 jal을 위해 (가) 레지스터 쓰기 값 선택에 PC + 4 입력, (나) PC 선택에 PC + imm(점프) 입력을 추가했다. addi와 jal의 RegWrite, ALUSrc, MemRead, MemWrite, 쓰기 값 선택, PC 선택을 정하라.

전략

  1. addi: rs1 + 상수 → rd.
  2. jal: rd ← PC + 4, PC ← PC + imm.

풀이

  1. addi: RegWrite 1, ALUSrc 1(상수), MemRead 0, MemWrite 0, 쓰기 값 = ALU, PC = PC + 4. addi
  2. jal: RegWrite 1, ALUSrc X, MemRead 0, MemWrite 0, 쓰기 값 = PC + 4, PC = PC + imm(점프). jal

의미

새 명령을 넣으려면 필요한 경로(멀티플렉서 입력)를 더하고 제어 표에 줄을 추가한다. 하드와이어드 제어에서는 이 표가 곧 조합 회로의 진리표입니다(4.2절).

검산

jal의 ALU는 쓰이지 않거나 PC + imm 계산에 따로 쓰는 덧셈기를 쓴다. 메모리는 쓰지 않으므로 MemRead, MemWrite는 0이어야 합니다(X 아님: 쓰면 메모리를 망침).

이해 확인

MemWrite를 X로 두면 안 되는 이유는?

답

X가 1로 정해지면 의도치 않은 메모리 쓰기가 일어나므로, 상태를 바꾸는 신호는 반드시 0으로 정한다.
