2.1.1RISC-V 기본

RISC-V(RV32I)는 32비트 레지스터 32개(x0은 언제나 0)를 쓰고, 연산은 레지스터끼리만, 메모리는 load/store로만 접근합니다(load-store 구조).

  • 산술: add rd, rs1, rs2, sub, addi rd, rs1, imm(12비트 상수).
  • 메모리: lw rd, off(rs1)(주소 rs1 + off의 32비트 읽기), sw rs2, off(rs1).
  • 분기: beq rs1, rs2, L(같으면 L로), bne, blt, bge. 점프 jal rd, L, jalr.
  • 자리 옮김: slli rd, rs1, k(왼쪽 k비트 = 2ᵏ 곱).

2.1.2배열 합 반복문

예제 2.1.1

for (i = 0; i < n; i++) s += a[i];(int 배열, 4바이트)를 옮겨라. a의 시작 주소 x10, n은 x11, s는 x12(처음 0), i는 x5.

      addi x5, x0, 0        # i = 0
loop: bge  x5, x11, done    # i >= n 이면 끝
      slli x6, x5, 2        # x6 = i * 4 (바이트 주소 차)
      add  x6, x10, x6      # &a[i]
      lw   x7, 0(x6)        # a[i]
      add  x12, x12, x7     # s += a[i]
      addi x5, x5, 1        # i++
      jal  x0, loop         # 반복
done:

반복마다 7개 명령, n = 100이면 반복 부분 약 700개 + 마지막 검사. 주소를 i × 4로 매번 계산하는 대신 포인터를 4씩 늘리면 두 명령을 줄일 수 있습니다(컴파일러 최적화).

흔한 오해(1) "배열 a[i]의 주소는 a + i": 바이트 주소라 a + 4i(int)입니다. (2) "x0에 값을 쓸 수 있다": 써도 무시되고 늘 0입니다. 그래서 jal x0, L은 반환 주소를 버리는 단순 점프입니다. (3) 레지스터 수가 적어 지역 변수가 많으면 메모리(스택)에 넣고 빼야 합니다.
요약
  1. RV32I: 레지스터 32개(x0 = 0), load-store 구조.
  2. 배열 주소 = 시작 + 크기 × i(int는 slli 2).
  3. 반복문 = 조건 분기 + 몸체 + 무조건 점프.

기본

  1. f = g + h - 5(g x5, h x6, f x7)를 옮겨라.
    답

    add x7, x5, x6 / addi x7, x7, -5.

응용

  1. if (a == b) c = 1; else c = 2;(a x5, b x6, c x7)를 옮겨라.
    답

    bne x5, x6, else / addi x7, x0, 1 / jal x0, end / else: addi x7, x0, 2 / end:.

심화

  1. 예제를 포인터 방식으로 바꿔 반복당 명령 수를 줄여라.
    답

    x6 = x10, 끝 주소 x13 = x10 + 4n을 미리 계산. 반복: bge x6, x13, done / lw x7, 0(x6) / add x12, x12, x7 / addi x6, x6, 4 / jal x0, loop. 5개.
