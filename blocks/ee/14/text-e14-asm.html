고급 언어를 어셈블리로

본문

C로 쓴 한 줄짜리 반복문 for (i = 0; i < n; i++) s += a[i];를 CPU는 그대로 알아듣지 못한다. CPU가 실제로 실행하는 명령은 어떤 모양이고, 이 한 줄은 명령 몇 개로 바뀔까? 같은 일을 더 적은 명령으로 할 수는 없을까?

먼저 알아야 할 것2진수와 2의 보수(전전4 1.1절), C 같은 고급 언어의 반복문을 쓴다.

2.1.1RISC-V 기본

RISC-V(RV32I)는 32비트 레지스터 32개를 쓰며, 그 가운데 x0은 언제나 0이다. 연산은 레지스터끼리만 하고 메모리는 load와 store로만 접근하는데, 이런 짜임을 load-store 구조라 한다. 처음 질문의 첫째 답, 곧 CPU가 실제로 실행하는 명령은 이런 단순한 명령들이다.

산술 명령으로는 add rd, rs1, rs2와 sub가 있고, addi rd, rs1, imm은 12비트 상수를 더한다. 메모리 명령 lw rd, off(rs1)는 주소 rs1 + off에서 32비트를 읽고, sw rs2, off(rs1)는 그 주소에 쓴다.

이제 흐름을 바꾸는 명령을 보자. 분기 명령 beq rs1, rs2, L은 두 값이 같으면 L로 가며, bne, blt, bge도 같은 꼴이다. 무조건 점프로는 jal rd, L과 jalr이 있다. 한편 자리 옮김 slli rd, rs1, k는 왼쪽으로 k비트 옮겨 2ᵏ을 곱한다.

2.1.2배열 합 반복문

예제 2.1.1

for (i = 0; i < n; i++) s += a[i];(int 배열, 4바이트)를 옮겨라. a의 시작 주소 x10, n은 x11, s는 x12(처음 0), i는 x5.

      addi x5, x0, 0        # i = 0
loop: bge  x5, x11, done    # i >= n 이면 끝
      slli x6, x5, 2        # x6 = i * 4 (바이트 주소 차)
      add  x6, x10, x6      # &a[i]
      lw   x7, 0(x6)        # a[i]
      add  x12, x12, x7     # s += a[i]
      addi x5, x5, 1        # i++
      jal  x0, loop         # 반복
done:

풀이. 반복문은 조건 분기, 몸체, 되돌아가는 점프로 바뀐다(그림 1). 여기서 int는 4바이트이므로 a[i]의 주소는 시작 주소에 i × 4를 더한 값이고, 이 곱셈을 slli 2로 한다. 반복마다 7개 명령을 실행하므로 n = 100이면 반복 부분이 약 700개이고, 여기에 마지막 검사가 더해진다. 처음 질문의 둘째 답이 이것이다.

그런데 주소를 매번 i × 4로 계산할 필요는 없다. 포인터를 4씩 늘려 가면 slli와 주소 덧셈 두 명령을 줄일 수 있으며, 컴파일러의 최적화가 바로 이런 일을 한다. 처음 질문의 셋째 답이 이것이다(연습문제 3).

흔한 실수배열 주소를 시작 주소 + i로 계산하는 실수가 흔하다. 메모리 주소는 바이트 단위여서 int 배열이면 i에 4를 곱해야 한다. 그리고 레지스터에 쓴 값을 x0에 넣으면 버려진다는 점을 잊고 x0을 임시 레지스터로 쓰면 결과가 늘 0이 된다.
마무리

RV32I는 레지스터 32개(x0 = 0)와 load-store 구조를 쓴다. 배열 원소의 주소는 시작 주소에 원소 크기 × i를 더한 값이며, int는 slli 2로 4를 곱한다. 반복문은 조건 분기, 몸체, 무조건 점프로 옮긴다.

2.1.3연습문제

기본

  1. f = g + h - 5(g x5, h x6, f x7)를 옮겨라.
    답

    add x7, x5, x6 / addi x7, x7, -5의 두 명령이다.

응용

  1. if (a == b) c = 1; else c = 2;(a x5, b x6, c x7)를 옮겨라.
    답

    bne x5, x6, else / addi x7, x0, 1 / jal x0, end / else: addi x7, x0, 2 / end:로 옮긴다.

심화

  1. 예제를 포인터 방식으로 바꿔 반복당 명령 수를 줄여라.
    답

    x6 = x10과 끝 주소 x13 = x10 + 4n을 미리 계산해 두고, 반복은 bge x6, x13, done / lw x7, 0(x6) / add x12, x12, x7 / addi x6, x6, 4 / jal x0, loop의 5개 명령이다.
