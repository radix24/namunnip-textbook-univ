오버플로 검출과 부호 확장

본문
이 절에서 배울 것
  • 2의 보수 덧셈에서 오버플로를 부호 비트로 검출한다.
  • 부호 있는 수와 없는 수의 오버플로 차이를 안다.
  • 부호 확장과 0 확장을 구별한다.
먼저 알아야 할 것
  • 2의 보수 (전전4 1.1절), 정수 산술 (3.1절).

3.3.1같은 비트, 다른 해석

부호 있는 덧셈의 오버플로: 두 피연산자 부호가 같은데 결과 부호가 다를 때. 부호 없는 덧셈: 최상위 자리올림이 날 때. 하드웨어는 같은 덧셈기를 쓰고, 플래그로 둘을 구별합니다. 8비트 값을 32비트로 넓힐 때 부호 있는 수는 부호 비트를 복사하고(부호 확장), 부호 없는 수는 0을 채웁니다.

예제 3.3.1

8비트 100 + 50과 −100 + (−50)은? 0xF0을 32비트로 부호 확장, 0 확장하면?

풀이. 100 + 50 = 150은 8비트 부호 있는 범위(−128~127) 밖: 결과 비트 10010110 = −106(양 + 양 → 음, 오버플로). −150도 범위 밖: 01101010 = +106(오버플로). 0xF0(−16) 부호 확장 0xFFFFFFF0, 0 확장 0x000000F0(240).

흔한 오해(1) "자리올림이 나면 늘 오버플로": 부호 있는 연산에서는 부호 비교로 판정합니다. (2) "C의 정수 오버플로는 감싸서 돈다": 부호 있는 정수 오버플로는 정의되지 않은 동작입니다(부호 없는 것만 감쌈).
요약
  1. 부호 있는 오버플로: 같은 부호 + → 다른 부호.
  2. 부호 없는: 최상위 자리올림.
  3. 부호 확장(부호 복사) 대 0 확장.

3.3.2연습문제

기본

  1. 8비트 127 + 1의 부호 있는 결과는?
    답

    −128(오버플로).

응용

  1. 8비트 200 + 100(부호 없음)의 결과와 오버플로 여부는?
    답

    44, 자리올림 → 오버플로.

심화

  1. lb와 lbu 명령의 차이는?
    답

    바이트를 읽어 부호 확장(lb)과 0 확장(lbu).
