단일 사이클 데이터패스와 제어 신호

본문
이 절에서 배울 것
  • 명령 인출, 레지스터 읽기, ALU, 메모리, 쓰기로 이루어진 단일 사이클 데이터패스의 경로를 안다.
  • R형, lw, sw, beq의 제어 신호(RegWrite, ALUSrc, MemRead, MemWrite, MemtoReg, Branch)를 정한다.
  • 단일 사이클의 클록 주기가 가장 긴 명령(lw)에 묶이는 이유를 안다.
먼저 알아야 할 것
  • 명령 형식 (2.2절), 멀티플렉서와 레지스터 (전전4 4.2절).

4.1.1경로

PC → 명령 메모리 → 레지스터 파일(rs1, rs2 읽기) → ALU(두 번째 입력은 레지스터 또는 상수: ALUSrc) → 데이터 메모리(lw/sw) → 레지스터에 쓸 값 선택(ALU 결과 또는 메모리: MemtoReg) → 레지스터 쓰기(RegWrite). PC는 PC + 4 또는 분기 목표(Branch AND Zero).

명령RegWriteALUSrcMemReadMemWriteMemtoRegBranchALU 연산
R형(add)10(레지스터)000(ALU)0funct로 정함
lw11(상수)101(메모리)0덧셈
sw0101X0덧셈
beq0000X1뺄셈(Zero 검사)

X는 무관(그 값이 결과에 쓰이지 않음). 제어 장치는 opcode(와 funct)를 입력으로 이 표를 만드는 조합 회로입니다.

예제 4.1.1

단계 지연이 명령 메모리 200, 레지스터 읽기 100, ALU 200, 데이터 메모리 200, 레지스터 쓰기 100 ps일 때 각 명령의 필요 시간과 단일 사이클 클록 주기는?

풀이. R형 200 + 100 + 200 + 100 = 600, lw 800, sw 700, beq 500 ps. 모든 명령이 한 사이클이므로 주기는 가장 긴 lw의 800 ps(1.25 GHz). beq는 300 ps를 놀고 있습니다. 이 낭비를 없애는 것이 파이프라이닝(5단원)입니다.

흔한 오해(1) "sw는 레지스터에 쓰니 RegWrite = 1": 메모리에 쓰고 레지스터는 쓰지 않습니다. (2) "X는 0과 같다": 아무 값이어도 되는 것이라 회로를 단순하게 만드는 데 씁니다.
요약
  1. 경로: PC → 명령 메모리 → 레지스터 → ALU → 데이터 메모리 → 쓰기.
  2. 제어 신호표(R, lw, sw, beq).
  3. 단일 사이클 주기 = 가장 긴 명령(lw).

4.1.2연습문제

기본

  1. addi의 ALUSrc와 MemtoReg는?
    답

    ALUSrc 1(상수), MemtoReg 0(ALU).

응용

  1. 예제에서 프로그램의 명령 비율이 lw 25%, sw 10%, R형 50%, beq 15%라면 명령마다 필요 시간만큼만 쓰는 이상적 가변 주기와 단일 사이클의 평균 시간 비는?
    답

    가변 0.25×800 + 0.1×700 + 0.5×600 + 0.15×500 = 645 ps. 단일 800 ps. 1.24배 차이.

심화

  1. jal(점프 후 반환 주소를 rd에 저장)을 지원하려면 데이터패스에 무엇을 더해야 하는가?
    답

    PC + 4를 레지스터 쓰기 값으로 고를 수 있게 MemtoReg 멀티플렉서에 입력 추가, PC에 점프 목표(PC + imm)를 넣는 경로와 제어 신호(Jump).
