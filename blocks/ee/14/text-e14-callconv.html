함수 호출 규약과 스택 프레임

본문
이 절에서 배울 것
  • RISC-V 호출 규약(인자 a0~a7, 반환 a0, 피호출자 보존 s0~s11, ra)을 안다.
  • 함수 진입·종료 코드(프롤로그·에필로그)를 쓴다.

  • 어셈블리 변환 (2.1절).

2.3.1누가 무엇을 저장하나

호출자는 인자를 a 레지스터에 넣고 jal로 부르며, 복귀 주소는 ra에 들어갑니다. 피호출자는 쓸 s 레지스터와(다른 함수를 부르면) ra를 스택에 저장했다가 돌려놓습니다. 스택 포인터 sp는 16바이트 정렬을 지킵니다.

fact:  addi sp, sp, -16      # 프레임 확보
       sw   ra, 12(sp)       # 복귀 주소 저장
       sw   s0, 8(sp)        # 쓸 레지스터 저장
       mv   s0, a0           # n 보관
       li   t0, 1
       ble  a0, t0, base     # n <= 1이면 1
       addi a0, a0, -1
       jal  ra, fact         # fact(n-1)
       mul  a0, a0, s0       # n * fact(n-1)
       j    done
base:  li   a0, 1
done:  lw   s0, 8(sp)
       lw   ra, 12(sp)
       addi sp, sp, 16
       ret
예제 2.3.1

fact(10)을 부르면 스택이 최대 몇 바이트 쓰이는가? ra를 저장하지 않으면?

풀이. 호출 깊이 10, 프레임 16바이트 → 160바이트. ra를 저장하지 않으면 안쪽 jal이 ra를 덮어써 바깥 함수가 엉뚱한 곳으로 돌아가 무한 반복하거나 멈춥니다.

흔한 오해(1) "t 레지스터는 호출 뒤에도 남는다": 호출자 보존이라 피호출 함수가 바꿀 수 있습니다. (2) "스택은 위로 자란다": RISC-V와 대부분 시스템에서 낮은 주소 쪽으로 자랍니다.
요약
  1. 인자 a0~a7, 반환 a0, ra에 복귀 주소.
  2. 피호출자 보존 s0~s11, sp 16바이트 정렬.
  3. 예: fact(10) → 160바이트.
