CMOS 인버터의 전달 곡선 바꾸기

탐구 · 스위칭 문턱과 잡음 여유

질문

pMOS를 강하게 또는 약하게 만들면 인버터가 바뀌는 입력 전압과 잡음 여유는 어떻게 될까요?

준비

긴 채널 제곱 법칙(채널 길이 변조 λ = 0.05/V)으로 nMOS와 pMOS 전류가 같아지는 출력 전압을 이분법으로 구해 VTC를 그립니다(1.1절). 빨간 점은 V_in = V_out인 스위칭 문턱, 초록 점은 기울기 −1인 두 점입니다.

해 보기와 설명

  1. 처음 화면대칭(k_p = k_n): V_M 0.6 V, V_IL 0.520 V, V_IH 0.680 V, NM_L 0.446 V, NM_H 0.445 V(예제 1.1.1).
  2. pMOS 강하게k_p/k_n = 4면 V_M 0.7 V로 올라 NM_L 0.609 V, NM_H 0.32 V.
  3. pMOS 약하게k_p/k_n = 0.25면 V_M 0.501 V로 내려 NM_L 0.321 V, NM_H 0.609 V.
  4. 공식과 비교출력의 공식 V_M 값과 수치 V_M이 3자리까지 맞는지 확인합니다.

연결과 적용

표준 셀 라이브러리는 pMOS 폭을 nMOS의 약 2배로 두어 V_M을 V_DD/2 근처에 맞춥니다. 잡음 여유는 칩 안 전원 잡음과 결합 잡음에 대한 안전 범위입니다.

흔한 오해

  • "같은 폭이면 대칭이다." 홀 이동도가 작아 같은 폭의 pMOS는 약합니다(k_p/k_n ≈ 0.5).
  • "잡음 여유는 V_DD/2이다." 전이 구간의 폭만큼 줄어 대칭에서도 0.45 V(V_DD 1.2 V)입니다.
