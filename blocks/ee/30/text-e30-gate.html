정적 CMOS 게이트 설계와 크기 결정

본문
이 절에서 배울 것
  • 풀다운(nMOS)과 풀업(pMOS)을 쌍대 구조로 연결해 NAND, NOR, 복합 게이트를 만든다.
  • 기준 인버터(n 1, p 2)와 같은 구동 세기가 되도록 직렬 소자의 폭을 정한다.
  • NAND가 NOR보다 선호되는 이유를 안다.
먼저 알아야 할 것
  • 불 대수 (전전4 2단원), 등가 저항 (1.2절).

2.1.1쌍대 구조

출력이 0이어야 할 조건을 nMOS로 만듭니다(직렬 = AND, 병렬 = OR). pMOS는 그 쌍대(직렬 ↔ 병렬)로 연결합니다. 예: \(Y = \overline{AB}\)(NAND2)는 nMOS 두 개 직렬, pMOS 두 개 병렬.

2.1.2크기

기준 인버터를 nMOS 폭 1, pMOS 폭 2(이동도 비 2 가정)로 두고, 최악의 경로 저항이 같도록 직렬 소자를 키웁니다.

예제 2.1.1

NAND2, NOR2의 트랜지스터 폭과 입력 하나의 정전 용량(폭 합)은?

풀이. NAND2: nMOS 직렬 두 개라 각 2, pMOS 병렬이라 각 2 → 입력 정전 용량 4(인버터 3의 4/3배). NOR2: nMOS 병렬 각 1, pMOS 직렬 두 개라 각 4 → 입력 5(5/3배). NOR는 느린 pMOS가 직렬이라 커서, 같은 기능이면 NAND 구조를 선호합니다.

복합 게이트 \(Y = \overline{A(B + C)}\)는 nMOS A와 (B ∥ C)의 직렬, pMOS A ∥ (B, C 직렬)로 한 단에 만들어 게이트 수와 지연을 줄입니다.

흔한 오해(1) "정적 CMOS로 AND를 한 단에 만든다": 정적 CMOS 한 단은 반전 함수만 만듭니다(AND = NAND + 인버터). (2) "입력 수를 늘려도 괜찮다": 직렬이 길어져 지연이 급증해 보통 4입력 이하로 씁니다.
요약
  1. nMOS 직렬 = AND(→ 0), pMOS는 쌍대.
  2. NAND2: n 2, p 2(입력 4). NOR2: n 1, p 4(입력 5).
  3. NAND 선호, 복합 게이트로 단 수 감소.

2.1.3연습문제

기본

  1. NAND3의 nMOS 폭은?
    답

    각 3.

응용

  1. NOR3의 pMOS 폭과 입력 정전 용량은?
    답

    각 6, 입력 7.

심화

  1. Y = ¬(AB + C)의 nMOS 구조는?
    답

    (A, B 직렬) ∥ C.
