6T SRAM 셀의 읽기와 쓰기

본문
이 절에서 배울 것
  • 교차 결합 인버터 두 개와 접근 트랜지스터 두 개로 된 6T 셀 구조를 안다.
  • 읽기(비트선 미리 충전 후 방전)와 쓰기(비트선으로 강제)의 순서를 설명한다.
  • 읽기 안정성(셀 비)과 쓰기 가능성(풀업 비)의 크기 조건을 안다.
먼저 알아야 할 것
  • CMOS 인버터 (1.1절), 메모리 계층 (전전14 6단원).

5.1.1동작

읽기: 두 비트선 BL, BLB를 V_DD로 미리 충전하고 워드선을 켭니다. 0을 저장한 쪽 노드가 접근 트랜지스터와 풀다운 nMOS를 통해 그쪽 비트선을 조금 끌어내리고, 감지 증폭기가 작은 차이(약 100 mV)를 잡아 키웁니다.

쓰기: 한 비트선을 0, 다른 쪽을 V_DD로 강하게 몰고 워드선을 켜면, 0 쪽 비트선이 1을 저장한 노드를 끌어내려 래치를 뒤집습니다.

예제 5.1.1

읽기 때 0 노드 전압이 조금 오르는데, 이것이 반대쪽 인버터의 문턱(약 V_DD/2)을 넘으면 무슨 일이 생기는가? 이를 막는 크기 조건은?

풀이. 셀 값이 뒤집혀 읽다가 내용을 망칩니다(읽기 파괴). 풀다운 nMOS가 접근 트랜지스터보다 강해야 노드 전압이 낮게 유지되므로, 셀 비 β = (W/L)_풀다운/(W/L)_접근을 대략 1.2~2 이상으로 합니다(확인 필요: 공정마다). 반대로 쓰기에는 접근 트랜지스터가 풀업 pMOS를 이겨야 해서 풀업은 가장 약하게 만듭니다.

흔한 오해(1) "SRAM은 전원이 꺼져도 유지": 휘발성입니다(DRAM과 달리 새로 고침만 필요 없음). (2) "읽기는 셀에 영향이 없다": 읽기 때도 노드가 흔들려 안정성 조건이 필요합니다.
요약
  1. 6T: 교차 인버터 2 + 접근 2.
  2. 읽기: 미리 충전, 0 쪽 방전, 감지 증폭.
  3. 읽기 안정: 풀다운 > 접근. 쓰기: 접근 > 풀업.

5.1.2연습문제

기본

  1. 6T 셀의 트랜지스터 중 pMOS 수는?
    답

    2개.

응용

  1. 비트선을 미리 충전하는 이유는?
    답

    알려진 상태에서 시작해 작은 방전 차이만으로 빠르게 읽기 위해.

심화

  1. V_DD를 낮추면 SRAM이 먼저 실패하는 이유는?
    답

    잡음 여유가 줄어 소자 변이에 따라 읽기·쓰기 조건이 깨지기 쉽기 때문입니다.
