VLSI 설계 흐름

본문
이 절에서 배울 것
  • 사양 → RTL → 합성 → 배치·배선 → 검증 → 테이프아웃 단계를 안다.
  • 각 단계의 산출물(RTL, 네트리스트, 레이아웃 GDS)과 검사(시뮬레이션, STA, DRC/LVS)를 연결한다.
  • 앞 단계 수정이 뒤 단계보다 싸다는 원칙을 안다.
먼저 알아야 할 것
  • HDL (전전32 2단원), 타이밍 (3.1절).

6.1.1단계

  1. 사양·구조: 기능, 성능, 전력, 면적 목표.
  2. RTL 설계: Verilog/VHDL로 레지스터 사이 동작 기술 → 기능 시뮬레이션.
  3. 논리 합성: 표준 셀 라이브러리로 게이트 네트리스트 생성, 타이밍 제약 반영.
  4. 배치·배선: 셀 위치와 배선, 클록 트리 합성.
  5. 사인오프: 정적 타이밍 분석(STA), 전력·IR 강하, DRC(설계 규칙), LVS(레이아웃 대 회로도).
  6. 테이프아웃: GDS를 공정에 보냄.
예제 6.1.1

배치·배선 뒤 STA에서 셋업 위반 경로가 수천 개 나왔다. 어떤 순서로 대응하는가?

풀이. 작은 위반은 셀 크기 조정·버퍼 삽입 같은 국소 최적화로, 많은 경로가 크게 위반하면 합성 제약이나 RTL 구조(파이프라인 단 추가, 논리 재구성)로 거슬러 올라갑니다. 뒤 단계에서 찾은 문제일수록 고치는 비용이 커서, RTL 단계에서 타이밍을 어림하고 검증을 충분히 하는 것이 중요합니다. 마스크 제작 뒤 발견된 오류는 수십억 원의 재제작 비용이 듭니다(확인 필요: 공정마다).

흔한 오해(1) "시뮬레이션이 통과하면 칩이 동작": 타이밍, 전력, 제조 규칙은 별도 검증이 필요합니다. (2) "LVS와 DRC는 같다": DRC는 제조 규칙, LVS는 레이아웃이 회로도와 같은 연결인지 확인합니다.
요약
  1. 사양 → RTL → 합성 → P&R → 사인오프 → 테이프아웃.
  2. 검사: 시뮬레이션, STA, DRC, LVS.
  3. 앞 단계 수정이 훨씬 싸다.
