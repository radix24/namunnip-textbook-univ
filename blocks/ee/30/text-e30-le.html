논리적 노력으로 경로 지연 최소화

본문
이 절에서 배울 것
  • 단 지연 \(d = gh + p\)(논리적 노력, 전기적 노력, 기생 지연)를 쓴다.
  • 경로 노력 F = GBH와 최적 단 노력 \(\hat f = F^{1/N}\)를 계산한다.
  • 최소 지연 \(D = N\hat f + P\)와 각 단의 크기를 구한다.
먼저 알아야 할 것
  • 게이트 크기 (2.1절), 지연 모형 (1.2절).

2.2.1모형

인버터 지연 단위 τ로 단 지연 d = gh + p. 논리적 노력 g(인버터 1, NAND2 4/3, NOR2 5/3), 전기적 노력 h = C_out/C_in, 기생 지연 p(인버터 1, 2입력 게이트 2). 경로 전체 F = G·B·H(B는 분기 노력)이고, 모든 단의 노력 gh가 같을 때 지연이 최소입니다.

예제 2.2.1

인버터 → NAND2 → NOR2 경로, 분기 없음, 출력 부하가 첫 입력의 20배. 최소 지연과 각 단 노력은?

풀이. G = 1 × 4/3 × 5/3 = 2.22, F = 44.4, f̂ = 44.4^{1/3} = 3.54. P = 1 + 2 + 2 = 5. D = 3 × 3.54 + 5 = 15.6τ. 각 단 입력 정전 용량은 뒤에서부터 \(C_{in} = gC_{out}/\hat f\)로 정합니다(NOR2 입력 = 5/3 × 20/3.54 = 9.4 등).

최적 단 노력은 대략 4(f̂ ≈ 3.6~4)이므로, F가 크면 인버터를 더 넣어 단 수를 N ≈ log₄F로 맞추는 것이 빠릅니다.

흔한 오해(1) "게이트를 줄일수록 빠르다": 큰 부하를 한 단에 몰면 오히려 느립니다. (2) "g는 크기에 따라 바뀐다": 게이트 종류(구조)로 정해지고 크기와 무관합니다.
요약
  1. d = gh + p, F = GBH.
  2. f̂ = F^{1/N}, D = Nf̂ + P.
  3. 예: inv-NAND2-NOR2, H 20 → 15.6τ.

2.2.2연습문제

기본

  1. 인버터 하나가 부하 64를 몰 때(입력 1) 지연은?
    답

    64 + 1 = 65τ.

응용

  1. 인버터 3단으로 같은 부하 64를 몰면?
    답

    f̂ = 4, D = 12 + 3 = 15τ.

심화

  1. F = 256이면 대략 몇 단이 좋은가?
    답

    log₄256 = 4단.
