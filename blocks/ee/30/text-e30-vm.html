스위칭 문턱과 소자 크기 비

본문
이 절에서 배울 것
  • 인버터 스위칭 문턱 V_M을 두 트랜지스터 크기 비로 계산한다.
  • V_M = V_DD/2를 만드는 pMOS/nMOS 크기 비를 정한다.
  • V_M이 잡음 여유에 주는 영향을 안다.
먼저 알아야 할 것
  • 인버터 VTC (1.1절).

1.3.1두 전류가 같아지는 점

V_in = V_out = V_M에서 두 트랜지스터가 모두 포화이므로 전류를 같게 놓으면 \(V_M = \frac{V_{Tn} + r(V_{DD} - |V_{Tp}|)}{1 + r}\), \(r = \sqrt{k_p/k_n}\)입니다. 이동도가 작은 pMOS를 그 비만큼 넓히면 r = 1이 되어 V_M이 가운데 옵니다.

예제 1.3.1

V_DD = 1.8 V, V_Tn = |V_Tp| = 0.4 V. r = 1과 r = 0.5(pMOS를 nMOS와 같은 크기, 이동도 비 1/4)의 V_M은?

풀이. r = 1: (0.4 + 1.4)/2 = 0.9 V. r = 0.5: (0.4 + 0.7)/1.5 = 0.73 V로 낮아져, 높은 쪽 잡음 여유가 커지고 낮은 쪽은 줄어듭니다. 크기 비에 대해 V_M은 둔하게 변해 정확히 가운데가 아니어도 동작은 문제없습니다.

흔한 오해(1) "pMOS와 nMOS를 같은 크기로 하면 대칭": 이동도 차이 때문에 V_M이 낮아집니다. (2) "V_M이 조금만 어긋나도 오동작": 둔감해서 큰 문제가 아닙니다.
요약
  1. V_M = (V_Tn + r(V_DD − |V_Tp|))/(1 + r), r = √(k_p/k_n).
  2. r = 1 → V_DD/2(대칭 문턱).
  3. 예: r 0.5 → 0.73 V.
