벅 컨버터의 인덕터 전류 들여다보기

탐구 · 리플과 연속·불연속 전도

질문

인덕턴스, 주파수, 부하를 바꾸면 인덕터 전류의 리플과 동작 모드는 어떻게 바뀔까?

준비

이상적인 벅 컨버터의 인덕터 전류를 세 주기 동안 그립니다(3.2절). 점선은 부하(평균) 전류이다. 최소 전류가 0 아래로 내려가면 실제로는 불연속 전도가 되므로 곡선을 주황색으로 표시한다.

해 보기와 설명

  1. 처음 화면V_in 12 V, D 0.42: V_o = 5.04 V, ΔI = 0.5846 A(29.2%), 최대 2.2923 A, 최소 1.7077 A(예제 3.2.1).
  2. 주파수 낮추기f_s = 100 kHz면 ΔI = 2.9232 A로 5배. 최소 0.5384 A로 아직 연속 전도.
  3. 경부하I_o = 0.2 A면 최소 −0.0923 A가 되어 불연속 전도. 경계는 ΔI/2 = 0.2923 A.
  4. 입력 전압 바꾸기V_in = 24 V, D = 0.21이면 V_o는 같은 5.04 V지만 ΔI = 0.7963 A로 커집니다(입출력 차가 커서).

연결과 적용

스마트폰 충전기, CPU 전원(VRM), 전기차 12 V 컨버터가 모두 벅 계열이다. VRM은 여러 상을 엇갈려 돌려 리플을 상쇄한다.

흔한 오해

  • "인덕터를 키우면 출력 전압이 바뀐다." 연속 전도에서는 V_o = D·V_in으로 L과 무관하고, 리플만 줄어든다.
  • "경부하에서도 같은 식이 맞는다." 불연속 전도가 되면 출력 전압이 부하에 따라 달라진다.
