정류기 입력 전류의 고조파와 역률

본문
이 절에서 배울 것
  • 정류기 입력 전류가 사각파에 가까워 고조파를 포함함을 안다.
  • 역률 = 변위 역률 × 왜곡 역률 \((I_1/I)\cos\phi_1\)을 계산한다.
  • 능동 역률 보정(PFC) 회로의 필요성을 안다.
먼저 알아야 할 것
  • Fourier 급수 (전전6 3.1절), 위상 제어 정류 (2.1절).

2.2.1사각파 전류

큰 인덕턴스 부하의 단상 전파 정류기에서 입력 전류는 진폭 I_d의 사각파이며, α만큼 전압보다 늦습니다. Fourier 급수로 기본파 실효값 \(I_1 = \frac{2\sqrt2}{\pi}I_d = 0.9I_d\), 홀수 고조파 \(I_n = I_1/n\)입니다. 총 실효값은 I_d이므로

\[ \text{PF} = \frac{P}{V I} = \frac{I_1}{I}\cos\alpha = 0.9\cos\alpha,\qquad \text{THD} = \sqrt{(I/I_1)^2 - 1} = 48.3\%. \]
예제 2.2.1

α = 30°의 역률은? 3고조파 전류는 기본파의 몇 %인가?

풀이. PF = 0.9 × 0.866 = 0.78. 3고조파 33.3%. 역률이 낮으면 같은 전력에 큰 전류가 흘러 배선·변압기 손실이 늘고, 고조파는 계통 전압을 일그러뜨려 다른 기기에 영향을 줍니다. 그래서 규격(예: IEC 61000-3-2, 확인 필요)이 고조파를 제한하며, 노트북 충전기 이상 기기는 부스트 컨버터로 입력 전류를 정현파로 만드는 능동 PFC를 둡니다(역률 0.99 수준).

흔한 오해(1) "역률은 cos(전압-전류 위상차)": 정현파일 때만 맞고, 왜곡 전류에서는 I₁/I를 곱해야 합니다. (2) "콘덴서를 달면 역률이 좋아진다": 변위 역률은 보상되지만 고조파는 줄지 않습니다.
요약
  1. 사각파 전류: I₁ = 0.9I_d, I_n = I₁/n, THD 48.3%.
  2. PF = (I₁/I)cos φ₁ = 0.9cos α.
  3. 능동 PFC로 정현파 입력 전류.

2.2.2연습문제

기본

  1. α = 0의 역률은?
    답

    0.9.

응용

  1. 5고조파는 기본파의 몇 %인가?
    답

    20%.

심화

  1. PF 0.78, 10 kW 부하의 230 V 입력 실효 전류는?
    답

    10000/(230 × 0.78) ≈ 55.7 A.
