z-변환으로 차분방정식 풀기와 안정도

본문
이 절에서 배울 것
  • 차분방정식을 z-변환해 전달함수와 출력을 구한다.
  • 부분분수로 역변환해 계단 응답을 얻는다.
  • 모든 극이 단위원 안에 있으면 안정함을 판정한다.
먼저 알아야 할 것
  • z-변환과 극점 (전전6 7.2절), 부분분수 (전전6 7.3절).

2.1.1예

\(y[n] = 0.5y[n - 1] + x[n]\)을 z-변환하면 \(Y(z)(1 - 0.5z^{-1}) = X(z)\), \(H(z) = 1/(1 - 0.5z^{-1})\), 극은 z = 0.5.

예제 2.1.1

위 시스템의 단위 계단 응답을 구하라. 계수를 1.2로 바꾸면?

풀이. \(Y = \frac{1}{(1 - 0.5z^{-1})(1 - z^{-1})} = \frac{2}{1 - z^{-1}} - \frac{1}{1 - 0.5z^{-1}}\), \(y[n] = 2 - 0.5^n\)(n ≥ 0): 1, 1.5, 1.75, …로 2에 다가갑니다(직류 이득 H(1) = 2). 계수 1.2면 극이 단위원 밖이라 출력이 1.2ⁿ으로 발산합니다.

흔한 오해(1) "극이 음수면 불안정": 크기만 1보다 작으면 안정이며, 음수 극은 부호가 번갈아 바뀌는 응답을 줍니다. (2) "z-변환 안정 조건은 s-평면과 같다": 왼쪽 반평면이 아니라 단위원 안입니다.
요약
  1. 차분방정식 → H(z) → 부분분수 → y[n].
  2. 예: y = 0.5y[n−1] + x → 계단 응답 2 − 0.5ⁿ.
  3. 모든 극 |p| < 1이면 안정.

2.1.2연습문제

기본

  1. y[n] = −0.8y[n−1] + x[n]은 안정한가?
    답

    예(|−0.8| < 1).

응용

  1. y[n] = 0.9y[n−1] + x[n]의 직류 이득은?
    답

    10.

심화

  1. 극이 z = 0.9e^{±jπ/4}인 시스템의 임펄스 응답 모양은?
    답

    주파수 π/4로 진동하며 0.9ⁿ으로 줄어듭니다.
