창 함수법으로 FIR 저역 통과 필터 설계

본문

이상적인 저역 통과 필터는 차단 주파수 아래는 그대로, 위는 완전히 0으로 만든다. 그런데 그 임펄스 응답은 sinc 함수라 양쪽으로 끝없이 이어져, 실제로는 만들 수 없다. 끝없는 응답을 유한한 탭으로 자르면 무엇이 달라질까? 그리고 탭 수와 창 종류는 각각 무엇을 정할까?

먼저 알아야 할 것창 함수(3.1절)와 DTFT(전전6 5.1절)를 쓴다.

4.1.1실습

창 함수법은 이상적 저역 통과의 sinc 임펄스 응답을 가운데 N개만 자르고, 창을 곱해 잘린 끝을 부드럽게 한다. 아래는 f_s = 8 kHz, 차단 1 kHz, 31탭, Hamming 창으로 설계하고 0~3 kHz에서 크기를 계산한 것이다.

import numpy as np
fs, fc, N = 8000, 1000, 31                  # 표본화 8 kHz, 차단 1 kHz, 탭 31개
n = np.arange(N) - (N - 1) / 2
h = 2 * fc / fs * np.sinc(2 * fc / fs * n)  # 이상적 저역 통과 임펄스 응답을 자름
h *= np.hamming(N)                          # Hamming 창
h /= h.sum()                                # 직류 이득 1로 맞춤
print("가운데 계수 h[15] =", round(h[15], 4), " 대칭:", np.allclose(h, h[::-1]))
for f in (0, 500, 1000, 1500, 2000, 3000):
    H = np.sum(h * np.exp(-2j * np.pi * f / fs * np.arange(N)))
    print(f"{f:5d} Hz: |H| = {abs(H):.4f} ({20 * np.log10(abs(H) + 1e-12):7.1f} dB)")

실행 결과는 아래와 같다(Python 3.12에서 실제 실행).

가운데 계수 h[15] = 0.2507  대칭: True
    0 Hz: |H| = 1.0000 (    0.0 dB)
  500 Hz: |H| = 1.0031 (    0.0 dB)
 1000 Hz: |H| = 0.5006 (   -6.0 dB)
 1500 Hz: |H| = 0.0019 (  -54.5 dB)
 2000 Hz: |H| = 0.0011 (  -59.3 dB)
 3000 Hz: |H| = 0.0008 (  -61.8 dB)

계수가 대칭이라 선형 위상이다. 즉 모든 주파수가 같은 시간만큼 늦게 나와 파형 모양이 찌그러지지 않는다. 그리고 차단 주파수에서 −6 dB인 것은 창법의 특징이다.

1.5 kHz부터는 −54 dB 아래로 떨어져, Hamming 창의 저지 감쇠(약 −53 dB)와 맞는다(그림 1). 처음 질문의 첫째 답이 이 전이 대역과 유한한 감쇠이다. 한편 전이 폭은 대략 \(3.3f_s/N\)(Hamming)이라, 탭을 두 배로 하면 전이가 절반으로 좁아진다. 처음 질문의 둘째 답이 이 역할 분담, 곧 탭 수는 전이 폭을, 창은 저지 감쇠를 정한다는 것이다.

예제 4.1.1

전이 폭을 약 400 Hz로 줄이려면 Hamming 창으로 몇 탭이 필요한지 구하여라.

풀이. \(N \approx 3.3 \times 8000/400 = 66\)이므로, 대칭을 위해 67탭이다. 그런데 직사각형 창으로 자르면 같은 탭에서 전이는 좁지만 저지 감쇠가 약 −21 dB로 나쁘다.

그러므로 설계는 먼저 필요한 저지 감쇠로 창을 고르고, 그다음 필요한 전이 폭으로 탭 수를 정하는 순서로 한다.

흔한 오해탭을 늘리면 저지 감쇠도 깊어진다고 여기기 쉽다. 창법의 최대 감쇠는 창 종류가 정하고, 탭은 전이 폭을 정한다. 또 FIR은 늘 IIR보다 낫다고 생각하기 쉬운데, 선형 위상과 안정성은 장점이지만 같은 날카로움에 탭(연산)이 훨씬 많다.
마무리

창 함수법은 sinc를 자르고 창을 곱하며, 대칭 계수는 선형 위상을 준다. 실습의 31탭 Hamming은 1 kHz에서 −6 dB, 1.5 kHz 이상에서 −54 dB 아래이다(실제 계산). 탭 수는 전이 폭을, 창은 저지 감쇠를 정한다.

4.1.2연습문제

기본

  1. 31탭 대칭 FIR의 군지연은?
    답

    15표본이다.

응용

  1. f_s 48 kHz, 전이 1 kHz, Hamming의 탭 수 어림은?
    답

    약 158이다.

심화

  1. 고역 통과를 저역 통과 계수로 만드는 방법은?
    답

    δ[n − 15] − h[n](스펙트럼 반전) 또는 (−1)ⁿ을 곱해 주파수 이동이다.
