DPSK 부호화와 복호

차분 부호

출발점

정보 비트를 이전 위상과의 차이로 싣습니다(4.3절).

문제 해결 전략 · d_k = d_{k−1} ⊕ b_k
  1. 기준 비트 d₀ = 1.
  2. d_k = d_{k−1} XNOR b_k(1이면 위상 유지 규칙의 한 예).
  3. 수신: 이웃 기호 위상 비교로 b_k 복원.

정보 1, 0, 1, 1을 'b = 1이면 위상 유지, 0이면 180° 반전' 규칙으로 보낼 때 전송 위상열은(처음 0°)?

풀이

  1. 시작 0°.
    기준.
  2. 1 → 0°, 0 → 180°, 1 → 180°, 1 → 180°.
    차분.
  3. 수신: 이웃 위상 같음 → 1, 다름 → 0: 1, 0, 1, 1 복원.
    복호.

의미

채널이 전체 위상을 바꿔도(예: 90°) 이웃 사이 차이는 그대로라 복호에 영향이 없습니다.

검산

0°, 0°, 180°, 180°, 180°에서 차이: 같음, 다름, 같음, 같음.
