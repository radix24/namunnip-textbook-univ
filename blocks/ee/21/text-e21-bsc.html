이진 대칭 채널의 용량

본문
이 절에서 배울 것
  • 비트가 확률 p로 뒤집히는 이진 대칭 채널(BSC)을 모델링한다.
  • 용량 \(C = 1 - H(p)\)를 계산한다.
  • 경판정 복호와 연판정 복호의 정보 손실을 안다.
먼저 알아야 할 것
  • 엔트로피 (1.1절), Shannon 용량 (1.2절).

1.3.1뒤집힘이 정보를 깎는다

입력 비트가 확률 p로 뒤집혀 나오는 채널의 용량은 \(C = 1 - H(p)\) 비트/사용, \(H(p) = -p\log_2p - (1 - p)\log_2(1 - p)\). p = 0.5면 출력이 입력과 무관해 용량 0입니다.

예제 1.3.1

p = 0.1과 0.01인 BSC의 용량은? 1 Mb/s로 보낼 때 오류 없이 보낼 수 있는 정보율의 상한은?

풀이. H(0.1) = 0.469 → C = 0.531, 상한 531 kb/s. H(0.01) = 0.081 → C = 0.919, 919 kb/s. 10%의 비트 오류는 정보의 거의 절반을 앗아 갑니다. 복조기가 0/1만 내는 경판정은 신뢰도 정보를 버려, 같은 신호에서 연판정보다 약 2 dB 손해를 봅니다(확인 필요).

흔한 오해(1) "p = 0.9면 용량이 거의 0": 늘 뒤집으면 다시 뒤집어 읽으면 되어 C = 1 − H(0.9) = 0.531입니다. (2) "용량만큼은 부호 없이 보낼 수 있다": 부호화가 필요합니다(정보원·채널 부호화 정리).
요약
  1. BSC: C = 1 − H(p).
  2. 예: p 0.1 → 0.531, p 0.01 → 0.919.
  3. 경판정은 신뢰도 정보를 버림.

1.3.2연습문제

기본

  1. p = 0.5의 용량은?
    답

    0.

응용

  1. p = 0.2의 용량은?
    답

    1 − 0.722 = 0.278.

심화

  1. p = 0.01 채널에 부호율 0.95 부호를 쓰면 오류를 0에 가깝게 할 수 있는가?
    답

    아닙니다(0.95 > 용량 0.919).
