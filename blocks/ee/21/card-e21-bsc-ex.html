BPSK 경판정이 만든 BSC

Q 함수 → p → 용량

출발점

BPSK 비트 오류 확률이 BSC의 p가 됩니다(1.3절, 3.2절).

문제 해결 전략 · Eb/N0 → p → C
  1. p = Q(√(2E_b/N₀)).
  2. C = 1 − H(p).
  3. 비교.

E_b/N₀ = 0 dB(1)에서 BPSK 경판정 BSC의 p와 용량은?

풀이

  1. p = Q(√2) = Q(1.414) = 0.0786.
    Q 값.
  2. H(0.0786) = 0.397 → C = 0.603.
    용량.
  3. 부호율 0.6 이하 부호면 이론상 신뢰 전송 가능.
    의미.

의미

실제 부호는 이 한계에 가깝게 가려고 연판정을 씁니다.

검산

−0.0786log₂0.0786 − 0.9214log₂0.9214 = 0.288 + 0.109 = 0.397.
