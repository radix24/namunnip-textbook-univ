순환 부호와 CRC

본문
이 절에서 배울 것
  • 다항식 나눗셈(XOR 나눗셈)으로 CRC 검사 비트를 계산한다.
  • 수신 측이 나머지 0으로 오류를 검출하는 원리를 안다.
  • CRC가 검출하는 오류(버스트 길이 등)를 안다.
먼저 알아야 할 것
  • 선형 블록 부호 (5.1절), XOR.

5.3.1나머지를 붙인다

메시지 다항식에 \(x^r\)을 곱하고(r개 0을 붙이고) 생성 다항식 G로 나눈 나머지를 붙여 보내면, 받은 비트열 전체가 G로 나누어떨어집니다. 나머지가 0이 아니면 오류입니다. 길이 r 이하의 버스트 오류는 모두 검출합니다.

def crc(bits, gen):
    r = len(gen) - 1
    a = list(map(int, bits + "0" * r))
    g = list(map(int, gen))
    for i in range(len(bits)):
        if a[i]:
            for j in range(len(g)):
                a[i + j] ^= g[j]
    return "".join(map(str, a[-r:]))
msg, gen = "1101011011", "10011"         # 생성 다항식 x⁴ + x + 1
rem = crc(msg, gen)
print("CRC:", rem, " 보내는 비트열:", msg + rem)
print("수신 검사(오류 없음) 나머지:", crc(msg + rem, gen)[-4:] if False else crc((msg + rem)[:-4], gen) == rem)
bad = "1101111011" + rem                 # 한 비트 뒤집힘
print("오류 있는 수신의 재계산 CRC:", crc(bad[:-4], gen), "→ 받은 CRC와 다름:", crc(bad[:-4], gen) != rem)

실행 결과(Python 3.12에서 실제 실행):

CRC: 1110  보내는 비트열: 11010110111110
수신 검사(오류 없음) 나머지: True
오류 있는 수신의 재계산 CRC: 0100 → 받은 CRC와 다름: True
예제 5.3.1

위 메시지 1101011011, 생성 다항식 10011의 CRC는? 한 비트가 뒤집히면?

풀이. CRC 1110, 보내는 비트열 11010110111110. 한 비트가 뒤집히면 다시 계산한 CRC가 받은 것과 달라 오류를 검출합니다(실행 결과). 이더넷은 32비트 CRC로 프레임 오류를 거릅니다.

흔한 오해(1) "CRC는 오류를 고친다": 검출만 하고, 고치는 것은 재전송이나 정정 부호입니다. (2) "CRC는 모든 오류를 잡는다": 생성 다항식의 배수인 오류는 못 잡지만 확률이 2⁻ʳ 정도로 작습니다.
요약
  1. x^r M(x) mod G(x)를 붙임.
  2. 수신: 나머지 0이 아니면 오류.
  3. 예: 1101011011, 10011 → 1110.
