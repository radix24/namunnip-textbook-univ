정보원의 엔트로피

본문
이 절에서 배울 것
  • 기호 하나의 정보량 \(-\log_2p\)와 평균 정보량(엔트로피) \(H = -\sum p_i\log_2p_i\)를 계산한다.
  • 엔트로피가 무손실 압축의 한계(기호당 평균 비트 수의 하한)임을 안다.
  • Huffman 부호로 그 한계에 가까운 부호를 만든다.
먼저 알아야 할 것
  • 확률과 기댓값 (전전11 2.1절), 디지털 통신 개요 (전전12 6.1절).

1.1.1정보량과 엔트로피

드물게 일어나는 일일수록 알았을 때 얻는 정보가 많습니다. 확률 p인 기호의 정보량은 \(-\log_2p\) 비트, 정보원 전체의 평균이 엔트로피입니다.

\[ H(X) = -\sum_i p_i\log_2p_i\ \text{(비트/기호)}, \qquad 0 \le H \le \log_2M. \]

M개 기호가 모두 같은 확률일 때 최대 \(\log_2M\)이고, 하나만 확실하면 0입니다.

예제 1.1.1

기호 A, B, C, D의 확률이 1/2, 1/4, 1/8, 1/8이다. 엔트로피와 Huffman 부호의 평균 길이는?

풀이. \(H = \frac12 \cdot 1 + \frac14 \cdot 2 + 2 \cdot \frac18 \cdot 3 = 1.75\) 비트/기호. Huffman 부호 A = 0, B = 10, C = 110, D = 111의 평균 길이도 1.75로 한계와 같습니다(확률이 모두 2의 거듭제곱이라). 고정 길이 부호(2비트)보다 12.5% 짧습니다.

흔한 오해(1) "엔트로피는 기호 수로 정해진다": 확률 분포로 정해지며, 기호 수는 상한만 정합니다. (2) "압축하면 엔트로피보다 짧게 만들 수 있다": 무손실 압축의 평균 길이는 엔트로피 아래로 내려갈 수 없습니다(정보원 부호화 정리).
요약
  1. 정보량 −log₂p, 엔트로피 H = −Σp log₂p.
  2. 0 ≤ H ≤ log₂M. 무손실 압축의 하한.
  3. 예: 1/2, 1/4, 1/8, 1/8 → 1.75 비트, Huffman도 1.75.

1.1.2연습문제

기본

  1. 동전(앞뒤 1/2)의 엔트로피는?
    답

    1 비트.

응용

  1. 확률 0.9, 0.1인 이진 정보원의 엔트로피는?
    답

    약 0.469 비트.

심화

  1. 예제 정보원을 고정 길이로 부호화하면 낭비는 기호당 몇 비트인가?
    답

    2 − 1.75 = 0.25 비트.
