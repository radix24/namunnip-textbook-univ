Viterbi 첫 두 단계

가지 거리

출발점

받은 쌍과 각 가지 출력의 해밍 거리를 누적합니다(5.4절).

문제 해결 전략 · 누적 거리
  1. 상태 00에서 시작.
  2. 입력 0 → 출력 00, 입력 1 → 출력 11.
  3. 받은 쌍과의 거리를 더한다.

첫 받은 쌍이 10이면 두 가지(입력 0, 1)의 거리는? 둘째 받은 쌍 10을 받은 뒤 상태 10(입력 1 다음)에서 나가는 가지 출력은?

풀이

  1. 입력 0(00): 거리 1, 입력 1(11): 거리 1 → 동률.
    첫 단계.
  2. 상태 10에서 입력 0 → 출력 10, 입력 1 → 01.
    부호 규칙.
  3. 둘째 쌍 10과 거리 0, 2 → 1011 경로 쪽이 앞섬.
    누적.

의미

한 비트 오류(11 → 10)가 있어도 뒤의 쌍들이 올바른 경로를 골라낸다.

검산

상태 10은 u₋₁ = 1, u₋₂ = 0: 입력 0 → c₁ = 0 ⊕ 1 ⊕ 0 = 1, c₂ = 0 ⊕ 0 = 0.
