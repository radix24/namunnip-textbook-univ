  • 블록 부호 (5.1절), 코딩 이득 (5.2절).

5.4.1기억이 있는 부호

부호율 1/2, 구속 길이 3의 (7, 5)₈ 부호는 입력 비트와 앞의 두 비트로 두 출력을 냅니다: \(c_1 = u_k \oplus u_{k-1} \oplus u_{k-2}\), \(c_2 = u_k \oplus u_{k-2}\). 자유 거리 5라 경판정으로 2비트 오류까지 고칩니다. Viterbi 복호는 상태 4개의 트렐리스에서 받은 열과 해밍 거리가 가장 작은 경로를 동적 계획으로 찾습니다.

def encode(bits):
    s1 = s2 = 0; out = []
    for u in bits + [0, 0]:                      # 끝에 0 두 개로 상태를 비움
        out.append(f"{u ^ s1 ^ s2}{u ^ s2}")
        s2, s1 = s1, u
    return out
print("입력 1011 → 출력:", " ".join(encode([1, 0, 1, 1])))

실행 결과(Python 3.12에서 실제 실행):

입력 1011 → 출력: 11 10 00 01 01 11
예제 5.4.1

입력 1011의 (7, 5) 부호 출력은? 부호율과 꼬리 비트의 역할은?

풀이. 실행 결과 11 10 00 01 01 11(꼬리 0 두 개 포함). 부호율 1/2이지만 꼬리 때문에 실제로는 4/12. 꼬리는 상태를 0으로 돌려 복호기가 끝 상태를 알게 합니다. 긴 메시지에서는 꼬리의 몫이 작아집니다.

흔한 오해(1) "길쌈 부호는 블록마다 독립": 이전 비트를 기억해 연속된 열 전체로 복호합니다. (2) "Viterbi는 모든 경로를 다 비교한다": 상태마다 살아남는 경로 하나만 유지해 계산이 길이에 비례합니다.
요약
  1. (7, 5) 부호: c₁ = u ⊕ u₋₁ ⊕ u₋₂, c₂ = u ⊕ u₋₂.
  2. 자유 거리 5 → 경판정 2비트 정정.
  3. Viterbi: 상태별 최선 경로, 계산 ∝ 길이.
