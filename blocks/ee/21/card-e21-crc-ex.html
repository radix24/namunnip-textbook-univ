짧은 CRC 손으로 계산

XOR 나눗셈

출발점

작은 예로 나눗셈 과정을 따라갑니다(5.3절).

문제 해결 전략 · 단계별 XOR
  1. 메시지 뒤에 r개 0을 붙인다.
  2. 앞에서부터 1이면 생성 다항식을 XOR.
  3. 마지막 r비트가 CRC.

메시지 1011, 생성 다항식 1011(x³ + x + 1)의 CRC는?

풀이

  1. 1011000을 나눈다.
    0 세 개.
  2. 1011 ⊕ 1011 = 0000 → 남은 000.
    첫 XOR로 끝.
  3. CRC = 000.
    메시지가 생성 다항식의 배수.

의미

메시지 자체가 G의 배수면 CRC가 0이 된다. 다른 메시지로 다시 해 보면 0이 아닌 나머지가 나온다.

검산

1011 × x³ = 1011000 = (x³ + x + 1)·x³.
