디코더, 인코더, 멀티플렉서

본문

CPU 안에는 레지스터가 여럿 있는데 산술 장치의 입력은 하나뿐이다. 그 가운데 하나를 골라 보내는 회로가 필요하다. 그런데 이렇게 "번호로 하나를 고르는" 회로가 뜻밖에도 아무 논리 함수나 만들 수 있다고 한다. 고르는 일과 계산하는 일은 어떻게 연결될까?

먼저 알아야 할 것최소항과 SOP 표준형(2.1절)을 쓴다.

4.2.1디코더

n비트 입력을 받아 \(2^n\)개 출력 가운데 입력 번호에 해당하는 하나만 1로 만드는 회로를 n-to-\(2^n\) 디코더라 한다. 출력 \(D_k\)는 바로 최소항 \(m_k\)이다. 가령 2-to-4 디코더는 \(D_0 = A'B'\), \(D_1 = A'B\), \(D_2 = AB'\), \(D_3 = AB\)이다. 메모리 주소를 받아 그 칸만 활성화하는 주소 선택이나 7세그먼트 표시처럼, 번호로 하나를 고르는 곳에 쓴다.

디코더가 모든 최소항을 만들어 주므로, 함수의 최소항 출력들을 OR로 모으면 어떤 함수든 된다. 예를 들어 전가산기의 \(S = \Sigma m(1, 2, 4, 7)\)과 \(C_\text{out} = \Sigma m(3, 5, 6, 7)\)을 3-to-8 디코더 하나와 4입력 OR 두 개로 만든다.

4.2.2인코더

인코더는 디코더의 반대로, \(2^n\)개 입력 가운데 1인 것의 번호를 n비트로 낸다. 그런데 입력이 둘 이상 1이면 곤란하므로, 실제로는 번호가 큰 쪽이나 미리 정한 쪽을 우선하는 우선순위 인코더와 입력이 하나라도 있는지를 알리는 유효 비트 V를 쓴다(4.4절). 키보드의 눌린 키 찾기와 CPU의 여러 인터럽트 가운데 가장 급한 것 고르기(전전25)가 그 예이다.

4.2.3멀티플렉서

멀티플렉서(MUX)는 여러 입력 가운데 하나를 골라 출력으로 보내는 스위치이다. \(2^n\)개 데이터 입력 \(I_0, \dots\)와 n개 선택선이 있으며, 선택선이 S1 S0인 4:1 MUX의 식은 다음과 같다.

\[ Y = S_1'S_0'I_0 + S_1'S_0I_1 + S_1S_0'I_2 + S_1S_0I_3 \]

즉 선택선이 만드는 최소항이 해당 입력을 통과시키는 꼴이다. CPU 안에서 레지스터 여러 개 가운데 하나를 ALU로 보내는 일, 여러 센서를 ADC 하나로 차례로 읽는 일이 모두 멀티플렉서의 몫이다. 반대로 입력 하나를 고른 출력으로 보내는 것이 디멀티플렉서이며, 구조는 디코더와 같다.

4.2.4멀티플렉서로 함수 만들기

n변수 함수는 \(2^n\):1 MUX 하나로 된다. 변수를 선택선에 넣고, 데이터 입력에 진리표의 출력값 0 또는 1을 그대로 넣으면 되기 때문이다. 그런데 더 작은 \(2^{n-1}\):1 MUX로도 된다.

정리 4.2.1

n변수 함수 \(F(A, B, \dots, Z)\)는 앞의 n−1개 변수를 선택선에 넣은 \(2^{n-1}\):1 MUX로 구현할 수 있다. 각 데이터 입력은 마지막 변수 Z의 함수 0, 1, Z, Z' 가운데 하나이다.

증명.앞의 n−1개 변수 값을 하나 정하면, 곧 선택선이 입력 하나를 고르면 F는 Z만의 함수가 된다. 1변수 함수는 \(F(Z = 0)\)과 \(F(Z = 1)\)의 두 값으로 정해지므로, 00이면 0, 11이면 1, 01이면 Z, 10이면 Z'의 넷뿐이다. 그 함수를 해당 데이터 입력에 넣으면 모든 입력 조합에서 MUX 출력이 F와 같다. ∎

예제 4.2.2

다수결 함수 \(F(A,B,C) = \Sigma m(3, 5, 6, 7)\)을 4:1 MUX로 구현하여라(선택 A, B).

풀이. AB = 00이면 m0과 m1이 모두 0이므로 \(I_0 = 0\)이다. AB = 01이면 m2 = 0, m3 = 1이므로 \(I_1 = C\)이다. AB = 10이면 m4 = 0, m5 = 1이므로 \(I_2 = C\)이다. AB = 11이면 m6 = m7 = 1이므로 \(I_3 = 1\)이다(그림 1). 확인하면 A = 1, B = 0, C = 1일 때 \(I_2 = C = 1\)이 출력되고, 둘이 1이므로 F = 1로 맞는다.

처음 질문의 답이 이것이다. 메모리에 진리표를 적어 두고 입력으로 골라 읽으면 어떤 함수든 되며, 이 생각이 FPGA 순람표(7.2절)의 원리이다.

흔한 실수MUX로 함수를 만들 때 선택선에 넣은 변수의 순서가 데이터 입력 번호를 정한다. 선택선 A가 상위 S1인지 하위 S0인지 바꾸면 \(I_1\)과 \(I_2\)가 서로 바뀐다.
마무리

디코더의 출력은 최소항이어서 디코더와 OR로 어떤 함수든 만들 수 있고, 우선순위 인코더는 가장 우선인 1의 번호와 유효 비트를 낸다. 멀티플렉서는 선택선 최소항과 데이터 입력의 곱을 더한 스위치이며, n변수 함수는 앞 변수들을 선택선에, 마지막 변수의 함수 {0, 1, Z, Z'}를 데이터 입력에 넣은 \(2^{n-1}\):1 MUX로 만들 수 있다. 고르는 회로가 곧 계산하는 회로인 셈이다.

4.2.5연습문제

기본

  1. 3-to-8 디코더와 OR 하나로 \(F = \Sigma m(0, 3, 5)\)를 그리면 OR 입력은 몇 개인가?
    답

    D0, D3, D5의 3개이다.

응용

  1. \(F(A,B,C) = \Sigma m(1, 2, 4, 7)\)(홀수 패리티)을 4:1 MUX로 만들어라(선택 A, B).
    답

    \(I_0 = C\), \(I_1 = C'\), \(I_2 = C'\), \(I_3 = C\)이다.

심화

  1. 4:1 MUX 다섯 개로 16:1 MUX를 만드는 방법을 설명하여라.
    답

    첫 단의 4개가 하위 선택선 S1 S0으로 각각 4개 가운데 하나를 고르고, 둘째 단의 1개가 상위 선택선 S3 S2로 그 넷 가운데 하나를 고른다.
