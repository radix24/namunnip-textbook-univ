상태 최소화와 상태 할당

본문
이 절에서 배울 것
  • 같은 입력에 같은 출력과 같은(동치) 다음 상태를 갖는 두 상태를 합친다.
  • 분할 정제로 동치 상태를 찾는다.
  • 상태 할당(2진, 원-핫, 그레이)이 회로 크기에 주는 영향을 안다.
먼저 알아야 할 것
  • 상태도 설계 (6.1절).

6.3.1동치 상태 합치기

상태표에서 (1) 출력이 다른 상태끼리 나누고, (2) 각 묶음 안에서 다음 상태가 서로 다른 묶음으로 가는 상태를 다시 나누기를 바뀌지 않을 때까지 반복합니다. 같은 묶음에 남은 상태들은 밖에서 구별할 수 없으므로 하나로 합칩니다.

예제 6.3.1

Moore 기계 상태표: A(출력 0; x=0→A, x=1→B), B(0; A, C), C(1; A, D), D(1; A, D). 최소화하라.

풀이. 출력으로 {A, B}, {C, D}. x = 1의 다음 상태: A → B({A, B}), B → C({C, D})로 다른 묶음이라 A와 B를 나눕니다. C → D, D → D는 같은 묶음, x = 0은 모두 A라 C와 D는 동치입니다. 결과 A, B, C 세 상태(D를 C로 합침)이며 플립플롭이 2개로 충분합니다. 이 기계는 "1이 두 번 이상 연속" 검출기입니다.

상태 할당: 2진 할당은 플립플롭이 가장 적고(⌈log₂n⌉개), 원-핫(상태마다 플립플롭 하나)은 다음 상태 논리가 간단해 FPGA에서 흔히 씁니다.

흔한 오해(1) "출력이 같으면 합칠 수 있다": 다음 상태들도 동치여야 합니다. (2) "상태가 적을수록 회로가 항상 작다": 할당 방식에 따라 조합 논리가 더 커질 수 있습니다.
요약
  1. 출력으로 나누고, 다음 상태 묶음으로 계속 나눔(분할 정제).
  2. 예: A, B, C, D → A, B, C(C ≡ D).
  3. 할당: 2진(플립플롭 최소), 원-핫(논리 간단).

6.3.2연습문제

기본

  1. 상태 5개를 2진 할당하면 플립플롭 수는?
    답

    3개.

응용

  1. 같은 기계를 원-핫으로 하면?
    답

    5개.

심화

  1. 두 상태가 출력은 같고 다음 상태가 서로 상대방이면 합칠 수 있는가?
    답

    다른 조건이 같다면 예. 서로를 가리키는 것은 같은 묶음 안이라 구별되지 않습니다.
