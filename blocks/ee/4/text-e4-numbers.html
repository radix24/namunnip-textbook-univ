2진수, 16진수, 2의 보수

본문

컴퓨터의 덧셈 회로는 0과 1만 다룬다. 그런데 이 회로는 음수의 덧셈도, 뺄셈도 따로 회로 없이 해낸다. 부호를 나타내는 기호도 없는 비트열로 어떻게 음수를 적고, 어떻게 덧셈기 하나로 뺄셈까지 할 수 있을까?

먼저 알아야 할 것10진수 \(345 = 3\times10^2 + 4\times10 + 5\)처럼 자릿값의 뜻을 쓴다. 컴퓨터 안의 수 표현은 공통10 6.1절에서도 다룬다.

1.1.12진수를 쓰는 까닭

디지털 회로의 신호선은 전압의 높음(1)과 낮음(0) 두 상태만 구별한다. 전압이 잡음으로 조금 흔들려도 둘 중 어느 쪽인지는 틀리지 않으므로 잡음에 강하다. 그래서 수를 0과 1, 곧 2진수로 나타내며, 이 과목의 모든 회로는 결국 2진수를 다루는 기계이다.

1.1.2자릿값과 진법 바꾸기

2진수 \(b_{n-1}\cdots b_1b_0\)의 값은 \(\sum_k b_k2^k\)이다. 예를 들어 \(1011_2 = 8 + 2 + 1 = 11\)이다. 10진수를 2진수로 바꿀 때는 2로 계속 나눈 나머지를 아래에서 위로 읽는다. \(11 = 2\cdot5 + 1\), \(5 = 2\cdot2 + 1\), \(2 = 2\cdot1 + 0\), \(1 = 2\cdot0 + 1\)이므로 \(1011_2\)이다.

2진수는 길어서 읽기 어렵기 때문에 4비트씩 묶어 16진수 한 자리(0에서 9, A에서 F)로 쓴다. 가령 \(1101\,0110_2 = \text{D6}_{16} = 214\)이다. 4비트가 16진 한 자리에 대응한다는 것만 알면 바로 바꿀 수 있다. 회로 문서와 메모리 주소는 거의 늘 0x 접두어를 붙인 16진수로 쓴다.

1.1.3음수를 나타내는 법

n비트로 음수를 나타내는 방법 세 가지를 4비트에서 비교하자. 부호-크기 방식은 맨 앞 비트를 부호로 써서 \(-3 = 1011\)이다. 그런데 0이 \(0000\)과 \(1000\) 두 개이고, 덧셈 회로가 부호에 따라 따로 동작해야 한다. 1의 보수 방식은 모든 비트를 뒤집어 \(-3 = 1100\)인데, 역시 0이 두 개이다. 2의 보수 방식은 뒤집고 1을 더해 \(-3 = 1101\)이다. 0이 하나뿐이고 덧셈 회로 하나로 양수와 음수를 모두 처리한다.

정의 1.1.1 (2의 보수)

n비트 2의 보수에서 비트열 \(b_{n-1}\cdots b_0\)의 값은 \(-b_{n-1}2^{n-1} + \sum_{k=0}^{n-2}b_k2^k\)이다. 나타낼 수 있는 범위는 \(-2^{n-1}\)부터 \(2^{n-1} - 1\)까지이다.

정의를 풀어 읽으면 맨 앞 비트의 자릿값만 음수 \(-2^{n-1}\)이라는 뜻이다. 4비트에서 \(1101 = -8 + 4 + 1 = -3\)이고, 범위는 −8에서 7로 음수가 하나 더 많다.

그러면 뒤집고 1 더하기가 왜 부호를 바꿀까? \(x\)를 뒤집은 값은 모든 비트가 1인 수에서 뺀 \((2^n - 1) - x\)이고, 1을 더하면 \(2^n - x\)이다. n비트에서는 \(2^n\)이 넘쳐 버려지므로, 곧 \(2^n\)을 법으로 계산하므로 이것은 \(-x\)와 같다. 처음 질문의 답이 이것이다. 그래서 \(a - b = a + (\text{뒤집은 }b) + 1\)로 뺄셈을 덧셈기 하나로 한다(그림 1).

예제 1.1.2

8비트 2의 보수로 \(45 - 70\)을 계산하여라.

풀이. \(45 = 0010\,1101\), \(70 = 0100\,0110\)이고, \(-70\)은 뒤집은 \(1011\,1001\)에 1을 더한 \(1011\,1010\)이다. 더하면 \(0010\,1101 + 1011\,1010 = 1110\,0111\)이다. 맨 앞이 1이라 음수이고, 크기는 다시 뒤집고 1을 더해 \(0001\,1001 = 25\)이다. 따라서 답은 −25로 맞는다.

1.1.4오버플로

결과가 범위를 벗어나면 비트열은 틀린 값을 나타낸다. 4비트에서 \(5 + 4 = 9\)는 범위의 끝 7 밖이고, 비트로는 \(0101 + 0100 = 1001 = -7\)이 나온다.

정리 1.1.3 (오버플로 판정)

2의 보수 덧셈에서 오버플로는 같은 부호의 두 수를 더했는데 결과의 부호가 다를 때, 그리고 그 때만 일어난다. 회로로는 맨 앞 자리로 들어가는 올림수 \(c_{n-1}\)과 나가는 올림수 \(c_n\)이 다를 때이며, \(V = c_n \oplus c_{n-1}\)이다.

부호가 다른 두 수를 더하면 결과의 크기가 두 수 중 큰 것보다 작으므로 절대로 범위를 벗어나지 않는다. 같은 부호일 때만 위험하고, 그 때 결과의 부호가 바뀌면 넘친 것이다. 한편 맨 앞 비트에서 나가는 올림 \(c_n\)은 오버플로가 아니다. 예제 1.1.2처럼 올림이 버려져도 답은 맞을 수 있다.

1.1.5다른 부호, BCD와 그레이 코드

BCD는 10진수 한 자리를 4비트로 적는 부호로, \(59 = 0101\,1001\)이다. 계산기와 시계 표시처럼 10진수를 그대로 보여 줄 때 쓰며, 4비트 중 1010에서 1111은 쓰지 않는다. 그레이 코드는 이웃한 수가 한 비트만 다르게 만든 부호로, 3비트에서는 000, 001, 011, 010, 110, 111, 101, 100 순이다. 회전 위치 센서에서 두 비트가 동시에 바뀌다 생기는 순간 오류를 막고, 카르노 맵(3단원)의 칸 순서로 쓴다(1.2절).

흔한 오해"맨 앞 자리에서 올림이 나왔으니 오버플로"는 부호 없는 수에서만 맞다. 같은 비트 덧셈이라도 부호 없는 수의 넘침은 \(c_n\)으로, 부호 있는 수의 넘침은 \(c_n \oplus c_{n-1}\)로 판정한다.
마무리

2진수는 자릿값이 \(2^k\)이고 16진수 한 자리는 2진 4비트에 대응한다. 2의 보수는 맨 앞 자리의 자릿값을 \(-2^{n-1}\)로 두어 \(2^n\)을 법으로 수를 나타내므로, 뒤집고 1 더하기로 부호를 바꾸고 같은 덧셈기로 뺄셈까지 하며, 범위는 \(-2^{n-1}\)에서 \(2^{n-1} - 1\)이다. 같은 부호끼리 더해 부호가 바뀌면, 곧 \(c_n \oplus c_{n-1} = 1\)이면 오버플로이다.

1.1.6연습문제

기본

  1. \(\text{3F}_{16}\)과 \(-1\)을 8비트 2의 보수 2진수로 쓰고 10진수 값을 적어라.
    답

    \(0011\,1111 = 63\)이고, \(-1 = 1111\,1111\)이다.

  2. 4비트 2의 보수에서 \(-6 + (-3)\)을 계산하고 오버플로를 판정하여라.
    답

    \(1010 + 1101 = (1)0111\)이다. 결과 0111 = 7은 같은 음수끼리 더했는데 양수가 나온 것이므로 오버플로이다. 참값 −9는 범위 밖이다.

응용

  1. 8비트 2의 보수에서 \(-128\)의 부호를 바꾸면(뒤집고 1 더하기) 무엇이 나오는가? 왜인가?
    답

    \(1000\,0000\)을 뒤집으면 \(0111\,1111\), 1을 더하면 \(1000\,0000\)으로 다시 −128이다. +128은 범위 밖이라 나타낼 수 없기 때문이다.

심화

  1. 4비트 2의 보수 값을 8비트로 늘릴 때 앞에 무엇을 채워야 값이 같은가(부호 확장)? \(1011\)로 확인하여라.
    답

    맨 앞 비트를 복사해 채운다. \(1011 = -5\)는 \(1111\,1011 = -128 + 64 + 32 + 16 + 8 + 2 + 1 = -5\)가 된다.
