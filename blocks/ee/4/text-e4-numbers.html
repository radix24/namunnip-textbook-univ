2진수, 16진수, 2의 보수

본문
이 절에서 배울 것
  • 2진수와 16진수를 10진수와 서로 바꾼다.
  • 2의 보수로 음수를 나타내고, 덧셈 하나로 뺄셈까지 하는 이유를 안다.
  • 부호 있는 덧셈의 오버플로를 판정한다.
  • BCD와 그레이 코드가 어디에 쓰이는지 안다.
먼저 알아야 할 것
  • 자릿값의 뜻(10진수 \(345 = 3\times10^2 + 4\times10 + 5\)). 컴퓨터 안의 수 표현은 공통10 6.1절에서도 다룹니다.

1.1.1왜 2진수인가

디지털 회로의 신호선은 전압이 "높음(1)"과 "낮음(0)" 두 상태만 구별합니다. 전압이 잡음으로 조금 흔들려도 둘 중 어느 쪽인지는 틀리지 않으므로 잡음에 강합니다. 그래서 수를 0과 1, 곧 2진수로 나타냅니다. 이 단원의 모든 회로는 결국 2진수를 다루는 기계입니다.

1.1.2자릿값과 진법 바꾸기

2진수 \(b_{n-1}\cdots b_1b_0\)의 값은 \(\sum_k b_k2^k\)입니다. 예를 들어 \(1011_2 = 8 + 2 + 1 = 11\). 10진수를 2진수로 바꿀 때는 2로 계속 나눈 나머지를 아래에서 위로 읽습니다: \(11 = 2\cdot5 + 1\), \(5 = 2\cdot2 + 1\), \(2 = 2\cdot1 + 0\), \(1 = 2\cdot0 + 1\) → \(1011_2\).

2진수는 길어서 읽기 어렵기 때문에 4비트씩 묶어 16진수 한 자리(0~9, A~F)로 씁니다. \(1101\,0110_2 = \text{D6}_{16} = 214\). 4비트 = 16진 한 자리라는 대응만 알면 바로 바꿀 수 있습니다. 회로 문서와 메모리 주소는 거의 늘 16진수로 씁니다(0x 접두어).

1.1.3음수를 어떻게 나타낼까

n비트로 음수를 나타내는 방법 세 가지를 비교합니다(n = 4).

부호-크기: 맨 앞 비트가 부호. \(-3 = 1011\). 0이 \(0000\)과 \(1000\) 두 개이고, 덧셈 회로가 부호에 따라 따로 동작해야 한다.

1의 보수: 모든 비트를 뒤집는다. \(-3 = 1100\). 역시 0이 두 개.

2의 보수: 뒤집고 1을 더한다. \(-3 = 1101\). 0이 하나뿐이고, 덧셈 회로 하나로 양수·음수를 모두 처리한다.

정의 1.1.1 (2의 보수)

n비트 2의 보수에서 비트열 \(b_{n-1}\cdots b_0\)의 값은 \(-b_{n-1}2^{n-1} + \sum_{k=0}^{n-2}b_k2^k\)이다. 나타낼 수 있는 범위는 \(-2^{n-1}\)부터 \(2^{n-1} - 1\)까지이다.

정의를 풀어 읽으면, 맨 앞 비트의 자릿값만 음수 \(-2^{n-1}\)이라는 것입니다. 4비트에서 \(1101 = -8 + 4 + 1 = -3\). 범위는 −8 ~ 7로, 음수가 하나 더 많습니다.

"뒤집고 1 더하기"가 부호를 바꾸는 이유: \(x\)를 뒤집은 값은 \((2^n - 1) - x\)(모든 비트가 1인 수에서 뺀 것)이고, 1을 더하면 \(2^n - x\)입니다. n비트에서는 \(2^n\)이 넘쳐 버려지므로(모듈로 \(2^n\)) 이것은 \(-x\)와 같습니다. 그래서 \(a - b = a + (\text{뒤집은 }b) + 1\)로 뺄셈을 덧셈기 하나로 합니다.

예제 1.1.2

8비트 2의 보수로 \(45 - 70\)을 계산하여라.

풀이. \(45 = 0010\,1101\), \(70 = 0100\,0110\), \(-70\) = 뒤집기 \(1011\,1001\) + 1 = \(1011\,1010\). 더하면 \(0010\,1101 + 1011\,1010 = 1110\,0111\). 맨 앞이 1이라 음수이고, 크기는 다시 뒤집고 1 더해 \(0001\,1001 = 25\). 답 −25. 맞습니다.

1.1.4오버플로

결과가 범위를 벗어나면 비트열은 틀린 값을 나타냅니다. 4비트에서 \(5 + 4 = 9\)는 범위(7) 밖이고, 비트로는 \(0101 + 0100 = 1001 = -7\)이 나옵니다.

정리 1.1.3 (오버플로 판정)

2의 보수 덧셈에서 오버플로는 같은 부호의 두 수를 더했는데 결과의 부호가 다를 때, 그리고 그때만 일어난다. 회로로는 맨 앞 자리로 들어가는 올림수 \(c_{n-1}\)과 나가는 올림수 \(c_n\)이 다를 때다: \(V = c_n \oplus c_{n-1}\).

부호가 다른 두 수를 더하면 결과의 크기가 두 수 중 큰 것보다 작으므로 절대로 범위를 벗어나지 않습니다. 같은 부호일 때만 위험하고, 그때 결과의 부호가 바뀌면 넘친 것입니다. 맨 앞 비트로 나가는 올림(\(c_n\))은 오버플로가 아니라는 점에 주의하세요. 예제 1.1.2처럼 올림이 버려져도 답은 맞을 수 있습니다.

1.1.5다른 부호: BCD와 그레이 코드

BCD: 10진수 한 자리를 4비트로. \(59 = 0101\,1001\). 계산기와 시계 표시처럼 10진수를 그대로 보여 줄 때 쓴다. 4비트 중 1010~1111은 쓰지 않는다.

그레이 코드: 이웃한 수가 한 비트만 다르게 만든 부호. 0, 1, 3, 2, 6, 7, 5, 4 순(3비트: 000, 001, 011, 010, 110, 111, 101, 100). 회전 위치 센서에서 두 비트가 동시에 바뀌다 생기는 순간 오류를 막고, 카르노 맵(3단원)의 칸 순서로 쓴다.

주의"맨 앞 자리에서 올림이 나왔으니 오버플로"는 부호 없는 수에서만 맞습니다. 같은 비트 덧셈이라도 부호 없는 수의 넘침은 \(c_n\), 부호 있는 수의 넘침은 \(c_n \oplus c_{n-1}\)로 판정합니다.
요약
  1. 2진수는 자릿값 \(2^k\), 16진수 한 자리 = 2진 4비트.
  2. 2의 보수: 맨 앞 자리의 자릿값이 \(-2^{n-1}\). 부호 바꾸기는 뒤집고 1 더하기. 범위 \(-2^{n-1} \sim 2^{n-1} - 1\).
  3. 오버플로는 같은 부호끼리 더해 부호가 바뀔 때, 곧 \(c_n \oplus c_{n-1} = 1\).

1.1.6연습문제

기본

  1. \(\text{3F}_{16}\)과 \(-1\)을 8비트 2의 보수 2진수로 쓰고 10진수 값을 적어라.
    답

    \(0011\,1111 = 63\). \(-1 = 1111\,1111\).

  2. 4비트 2의 보수에서 \(-6 + (-3)\)을 계산하고 오버플로를 판정하여라.
    답

    \(1010 + 1101 = (1)0111\). 결과 0111 = 7, 같은 음수끼리 더했는데 양수가 나와 오버플로. 참값 −9는 범위 밖.

응용

  1. 8비트 2의 보수에서 \(-128\)의 부호를 바꾸면(뒤집고 1 더하기) 무엇이 나오는가? 왜인가?
    답

    \(1000\,0000\) → 뒤집기 \(0111\,1111\) → +1 → \(1000\,0000\), 다시 −128. +128은 범위 밖이라 나타낼 수 없다.

심화

  1. 4비트 2의 보수 값을 8비트로 늘릴 때 앞에 무엇을 채워야 값이 같은가(부호 확장)? \(1011\)로 확인하여라.
    답

    맨 앞 비트를 복사해 채운다. \(1011 = -5\) → \(1111\,1011 = -128 + 64 + 32 + 16 + 8 + 2 + 1 = -5\).
