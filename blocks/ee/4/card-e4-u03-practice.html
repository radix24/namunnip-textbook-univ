논리 최소화 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 답은 카르노 맵 카드로 검산할 수 있습니다.

  1. 개념카르노 맵의 행과 열을 00, 01, 10, 11 순서로 놓으면 무엇이 잘못되나요? [03-01]

    힌트 1

    01과 10은 몇 비트가 다른가요?

    힌트 2

    이웃한 칸이 한 비트만 달라야 묶음이 변수를 지웁니다.

    풀이

    01과 10이 이웃하게 되는데 두 비트가 달라, 그 둘을 묶으면 변수 하나가 지워지지 않습니다. 반대로 실제로 한 비트 차이인 00과 10(또는 01과 11)은 떨어져 있어 묶음을 놓칩니다.

  2. 계산\(F(A,B,C,D) = \Sigma m(0, 4, 8, 12, 3, 7, 11, 15)\)를 최소화하세요. [03-01]

    힌트 1

    0, 4, 8, 12는 CD = 00 열 전체.

    힌트 2

    3, 7, 11, 15는 CD = 11 열 전체.

    풀이

    \(F = C'D' + CD\)(C와 D가 같을 때). A, B는 사라집니다.

  3. 계산\(F = \Sigma m(2, 3, 6, 7, 10, 11, 14)\)의 최소 SOP와 최소 POS를 구하세요. [03-01]

    힌트 1

    2, 3, 6, 7, 10, 11, 14는 C = 1인 칸 중 15만 빠짐.

    힌트 2

    0을 묶으면: C = 0인 8칸과 15.

    풀이

    SOP: \(A'C + B'C + CD'\) (각 4칸). 0인 칸: C′(8칸) + ABCD(15) → \(F' = C' + ABD\), \(F = C(A' + B' + D')\). POS가 훨씬 간단합니다.

  4. 계산BCD 입력 ABCD가 3의 배수(0, 3, 6, 9)이면 1인 함수를 무관 조건을 써서 최소화하세요. [03-01]

    힌트 1

    X: 10~15.

    힌트 2

    9는 11(X)과, 3은 11(X)과 묶을 수 있나요?

    풀이

    1: 0, 3, 6, 9. 주항: 0의 이웃 칸 1, 2, 4, 8은 모두 0(X가 아님)이라 0은 혼자 \(A'B'C'D'\)로 남습니다. 3(0011)은 11(1011, X)과 \(B'CD\). 6(0110)은 14(X)와 \(BCD'\). 9(1001)는 11, 13, 15(X)와 \(AD\). \(F = A'B'C'D' + B'CD + BCD' + AD\).

  5. 판단학생이 \(\Sigma m(5, 7, 13)\)을 "5, 7, 13을 L자로 묶어 BD"라고 답했다. 무엇이 틀렸고 맞는 답은? [03-01]

    힌트 1

    묶음은 2의 거듭제곱 칸의 직사각형.

    힌트 2

    BD는 5, 7, 13, 15 네 칸.

    풀이

    3칸 L자 묶음은 안 됩니다. BD는 15도 덮는데 15는 0이라 틀린 식이 됩니다. 맞는 답: \(A'BD\)(5, 7) + \(BC'D\)(5, 13).

  6. 도전5변수 F(A,B,C,D,E)의 카르노 맵은 4변수 맵 두 장(A = 0, A = 1)으로 그립니다. 두 장의 같은 자리 칸은 왜 이웃이고, \(\Sigma m(5, 7, 13, 15, 21, 23, 29, 31)\)은 무엇으로 줄어드나요? [03-01]

    힌트 1

    같은 자리 칸은 A만 다릅니다.

    힌트 2

    5, 7, 13, 15는 A = 0 장의 CE = 11? 번호 = 16A + 8B + 4C + 2D + E.

    풀이

    같은 자리 칸은 A만 다르므로 이웃입니다. 5 = 00101, 7 = 00111, 13 = 01101, 15 = 01111: C = 1, E = 1이 공통(B, D는 바뀜). 21~31은 같은 패턴에 A = 1. 8칸 묶음 \(CE\).
