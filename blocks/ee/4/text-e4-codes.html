BCD와 그레이 코드

본문
이 절에서 배울 것
  • 10진 자리마다 4비트를 쓰는 BCD로 수를 나타낸다.
  • 이웃한 수가 한 비트만 다른 그레이 코드를 만들고 2진수와 서로 바꾼다.
  • 그레이 코드가 회전 인코더와 카르노 맵에 쓰이는 이유를 안다.
먼저 알아야 할 것
  • 2진수와 2의 보수 (1.1절), XOR.

1.2.1두 코드

BCD: 10진수 각 자리를 0000~1001로 따로 씁니다. 2026 → 0010 0000 0010 0110. 7세그먼트 표시와 계산기처럼 10진 자리를 다루는 곳에 편하지만 1010~1111을 쓰지 않아 비트를 낭비합니다.

그레이 코드: \(g = b \oplus (b \gg 1)\). 이웃한 수가 한 비트만 다르므로, 회전 인코더처럼 여러 비트를 동시에 읽을 때 경계에서 엉뚱한 값을 읽는 일이 없습니다.

for b in range(8):
    g = b ^ (b >> 1)
    back, x = 0, g
    while x:                       # 그레이 → 2진: 위쪽 비트를 차례로 XOR
        back ^= x; x >>= 1
    print(b, format(b, "03b"), "→ 그레이", format(g, "03b"), "→ 되돌림", back)
print("BCD 2026:", " ".join(format(int(c), "04b") for c in "2026"))

실행 결과(Python 3.12에서 실제 실행):

0 000 → 그레이 000 → 되돌림 0
1 001 → 그레이 001 → 되돌림 1
2 010 → 그레이 011 → 되돌림 2
3 011 → 그레이 010 → 되돌림 3
4 100 → 그레이 110 → 되돌림 4
5 101 → 그레이 111 → 되돌림 5
6 110 → 그레이 101 → 되돌림 6
7 111 → 그레이 100 → 되돌림 7
BCD 2026: 0010 0000 0010 0110
예제 1.2.1

2진수로 3(011)에서 4(100)로 넘어갈 때 센서가 세 비트를 조금씩 다른 순간에 읽으면 어떤 값이 잠깐 보일 수 있는가? 그레이 코드는?

풀이. 세 비트가 모두 바뀌므로 000~111 어느 값이든 잠깐 보일 수 있습니다(예: 111 = 7). 그레이 코드는 010 → 110으로 한 비트만 바뀌어 3 또는 4만 보입니다.

흔한 오해(1) "BCD 1001 + 0001 = 1010이 답": BCD에서는 10이 넘으면 6(0110)을 더해 자리올림을 맞춥니다(0001 0000). (2) "그레이 코드로 바로 더할 수 있다": 산술에는 2진수로 바꿔 씁니다.
요약
  1. BCD: 10진 자리마다 4비트, 7세그먼트·계산기.
  2. 그레이: g = b ⊕ (b ≫ 1), 이웃 수가 한 비트 차이.
  3. 회전 인코더와 카르노 맵 배치에 쓰임.
