카르노 맵으로 논리 최소화

본문

최소항 여덟 개짜리 식 \(\Sigma m(0, 2, 5, 7, 8, 10, 13, 15)\)를 불 대수로 줄이려면 어떤 항끼리 짝지을지 한참 들여다봐야 한다. 그런데 이 식은 사실 항 두 개짜리 \(B'D' + BD\)이다. 짝지을 항들이 한눈에 보이도록 진리표를 늘어놓는 방법이 있을까?

먼저 알아야 할 것최소항과 SOP 표준형, 흡수 법칙(2.1절), 그레이 코드(1.2절)를 쓴다.

3.1.1그림으로 줄이는 까닭

2.1절에서 \(A'BC + ABC = BC\)처럼, 한 변수만 다른 두 최소항은 합치면 그 변수가 사라진다(\(XA' + XA = X\))는 것을 보았다. 문제는 식이 길면 어떤 항끼리 짝지을지 눈에 잘 보이지 않는다는 것이다. 카르노 맵은 한 변수만 다른 최소항들이 그림에서 이웃하도록 진리표를 배열해, 짝짓기를 눈으로 하게 한다.

3.1.2맵의 배치

4변수 F(A, B, C, D)의 맵은 4×4 칸이다. 행은 AB, 열은 CD이고, 순서는 2진수 순서가 아니라 그레이 코드 순서 00, 01, 11, 10이다. 그래서 좌우나 상하로 이웃한 칸은 한 비트만 다르다. 게다가 맨 왼쪽 열 00과 맨 오른쪽 열 10, 맨 위 행과 맨 아래 행도 한 비트만 달라 이웃이다. 종이를 말아 원통처럼 생각하면 된다. 칸 번호는 \(m = 8A + 4B + 2C + D\)이다.

3.1.3묶기 규칙

1인 칸을 직사각형으로 묶되, 크기는 1, 2, 4, 8, 16칸처럼 2의 거듭제곱만 된다. \(2^k\)칸 묶음에서는 k개 변수가 사라지므로 묶음은 클수록 좋다. 또 모든 1이 적어도 한 번 묶여야 하며, 멱등 법칙 \(X + X = X\)에 따라 겹쳐 묶어도 된다. 그리고 묶음의 수는 가능한 한 적게 한다.

묶음 하나는 곱 항 하나가 된다. 묶음 안에서 값이 바뀌지 않는 변수만 남기며, 그 값이 1이면 그대로, 0이면 NOT으로 쓴다.

정의 3.1.1 (주항과 필수 주항)

주항은 더 크게 넓힐 수 없는 묶음이다. 어떤 1을 덮는 주항이 하나뿐이면 그 주항은 필수 주항이다.

그러므로 최소화는 이 순서로 한다. 먼저 모든 주항을 찾고, 필수 주항을 먼저 고른 뒤, 아직 덮이지 않은 1을 가장 적은 수의 주항으로 덮는다.

예제 3.1.2

\(F(A,B,C,D) = \Sigma m(0, 2, 5, 7, 8, 10, 13, 15)\)를 최소화하여라.

풀이. 맵에 찍으면 0, 2, 8, 10은 네 모서리, 5, 7, 13, 15는 가운데 2×2이다. 네 모서리는 좌우와 상하가 이어져 하나의 4칸 묶음이고, B = 0, D = 0이 공통이라 \(B'D'\)이다. 가운데 묶음은 B = 1, D = 1이라 \(BD\)이다. 둘 다 필수 주항이고 모든 1을 덮으므로 \(F = B'D' + BD\), 곧 B와 D가 같을 때 1인 XNOR이다. 처음 질문의 답이 그림 1이다.

3.1.4무관 조건

BCD 입력(0에서 9)처럼 어떤 입력 조합이 절대 들어오지 않으면, 그 칸의 출력은 0이든 1이든 상관없다. 이런 칸은 맵에 X로 적고, 묶음을 크게 만드는 데 도움이 되면 1로, 아니면 0으로 본다. 7세그먼트 디코더에서 10에서 15를 X로 두면 식이 크게 줄어드는 것이 그 예이다(3.2절).

예제 3.1.3

BCD 입력(ABCD, 0에서 9)이 5 이상이면 1인 함수를 최소화하여라.

풀이. 1은 5, 6, 7, 8, 9이고 X는 10에서 15이다. A = 1인 행 두 줄(8에서 15) 전체가 1 또는 X이므로 8칸 묶음 \(A\)가 된다. 또 5, 7, 13, 15(X 포함)는 \(BD\)이고, 6, 7, 14, 15는 \(BC\)이다. 따라서 \(F = A + BD + BC = A + B(C + D)\)이다. X를 쓰지 않으면 \(AB'C' + A'BD + A'BC\)로 훨씬 길다.

3.1.50을 묶으면 합의 곱

한편 0인 칸을 묶으면 \(F'\)의 최소 곱의 합을 얻고, 드 모르간 법칙으로 뒤집으면 F의 최소 합의 곱(POS)이 된다. 예제 3.1.2에서 0인 칸은 \(B'D + BD'\)로 묶이므로 \(F' = B'D + BD'\)이고 \(F = (B + D')(B' + D)\)이다. 어느 쪽이 게이트가 적은지 비교해 고른다.

변수가 5에서 6개를 넘으면 맵을 그리기 어려워, 컴퓨터가 퀸-매클러스키 방법이나 Espresso 같은 휴리스틱으로 최소화한다. 이 방법들도 한 비트 다른 항을 합치고, 주항을 찾고, 최소 덮개를 고르는 같은 원리이다.

흔한 실수3칸이나 6칸처럼 2의 거듭제곱이 아닌 묶음과 대각선 묶음은 안 된다. 묶음 안에서 사라지는 변수가 정확히 k개가 되려면 \(2^k\)칸 직사각형이어야 하기 때문이다.
마무리

카르노 맵은 그레이 순서 배치로 한 비트만 다른 칸을 이웃하게 만들며, 가장자리끼리도 이웃이다. 그래서 \(2^k\)칸 직사각형 묶음 하나가 k변수가 사라진 곱 항 하나가 되고, 묶음을 크게, 적게, 빠짐없이 고르되 필수 주항부터 고르면 최소 곱의 합을 얻는다. 무관 조건 X는 도움이 될 때만 1로 보고, 0을 묶어 드 모르간 법칙으로 뒤집으면 최소 POS를 얻는다.

3.1.6연습문제

기본

  1. \(F(A,B,C) = \Sigma m(0, 1, 2, 3, 6)\)을 최소화하여라.
    답

    \(A' + BC'\)이다. 0에서 3은 \(A'\) 4칸이고, 6은 2와 묶어 \(BC'\)이다.

응용

  1. \(F = \Sigma m(1, 3, 4, 5, 9, 11, 12, 13)\)을 최소화하여라.
    답

    \(B'D + BC'\)이다. 1, 3, 9, 11은 \(B'D\), 4, 5, 12, 13은 \(BC'\)이다.

심화

  1. \(F = \Sigma m(0, 1, 5, 7, 10, 14, 15)\)에서 주항을 모두 찾고, 필수 주항과 최소 식을 구하여라.
    답

    주항은 \(A'B'C'\)(0, 1), \(A'C'D\)(1, 5), \(A'BD\)(5, 7), \(BCD\)(7, 15), \(ABC\)(14, 15), \(ACD'\)(10, 14)이다. 0을 덮는 유일한 주항 \(A'B'C'\)와 10을 덮는 유일한 주항 \(ACD'\)가 필수 주항이다. 이 둘이 0, 1, 10, 14를 덮고, 남은 5, 7, 15를 주항 두 개로 덮는 방법이 \(A'BD + BCD\), \(A'BD + ABC\), \(A'C'D + BCD\)로 셋 있다. 예를 들어 \(F = A'B'C' + ACD' + A'BD + BCD\)이다. 모두 항 4개, 리터럴 12개여서 최소 식이 하나로 정해지지 않는다.
