시프트 레지스터

본문
이 절에서 배울 것
  • D 플립플롭을 이어 한 클록마다 비트가 옮겨 가는 시프트 레지스터를 설계한다.
  • 직렬 입력-병렬 출력(SIPO)과 병렬 입력-직렬 출력(PISO)의 쓰임을 안다.
  • 링 카운터와 존슨 카운터의 상태 순서를 구한다.
먼저 알아야 할 것
  • D 플립플롭 (5.1절), 카운터 (5.2절).

5.4.1한 칸씩 옮기기

D 플립플롭 Q₀ → Q₁ → Q₂ → Q₃을 같은 클록으로 이으면, 클록마다 입력 비트가 한 칸씩 이동합니다. 직렬로 들어온 비트를 4클록 뒤에 병렬로 읽으면(SIPO) 직렬 통신 수신, 병렬로 넣고 한 비트씩 내보내면(PISO) 송신에 씁니다(UART, SPI).

q = [0, 0, 0, 0]
for clk, bit in enumerate([1, 0, 1, 1], 1):     # 직렬 입력 1, 0, 1, 1
    q = [bit] + q[:-1]
    print(f"클록 {clk}: Q0..Q3 = {q}")
ring, john = [1, 0, 0, 0], [0, 0, 0, 0]
rs, js = [], []
for _ in range(8):
    rs.append("".join(map(str, ring))); js.append("".join(map(str, john)))
    ring = [ring[-1]] + ring[:-1]                   # 링: 마지막 비트를 처음으로
    john = [1 - john[-1]] + john[:-1]               # 존슨: 마지막 비트를 뒤집어 처음으로
print("링 카운터 :", rs[:4])
print("존슨 카운터:", js)

실행 결과(Python 3.12에서 실제 실행):

클록 1: Q0..Q3 = [1, 0, 0, 0]
클록 2: Q0..Q3 = [0, 1, 0, 0]
클록 3: Q0..Q3 = [1, 0, 1, 0]
클록 4: Q0..Q3 = [1, 1, 0, 1]
링 카운터 : ['1000', '0100', '0010', '0001']
존슨 카운터: ['0000', '1000', '1100', '1110', '1111', '0111', '0011', '0001']
예제 5.4.1

4비트 링 카운터와 존슨 카운터는 각각 몇 개의 상태를 도는가?

풀이. 링 카운터는 1 하나가 도는 4상태(1000, 0100, 0010, 0001), 존슨 카운터는 0000, 1000, 1100, 1110, 1111, 0111, 0011, 0001의 8상태(2n)입니다. 두 경우 모두 상태마다 두 비트 이하만 보면 해독할 수 있어 단계 신호 생성에 씁니다.

흔한 오해(1) "같은 클록이면 모든 비트가 한꺼번에 첫 칸으로 간다": 각 플립플롭이 클록 직전의 앞 칸 값을 잡으므로 한 칸씩만 이동합니다. (2) "링 카운터는 아무 초기값에서나 시작해도 된다": 1이 정확히 하나 들어 있게 초기화해야 합니다.
요약
  1. 시프트 레지스터: 클록마다 한 칸 이동.
  2. SIPO(수신), PISO(송신).
  3. 링 카운터 n상태, 존슨 카운터 2n상태.
