다수결 함수의 표준형

최소항 · 간소화

출발점

출력이 1인 줄의 최소항을 모으면 SOP 표준형이 됩니다(2.3절).

문제 해결 전략 · 진리표 → Σm → 간소화
  1. 세 입력 중 1이 두 개 이상인 줄을 찾는다.
  2. Σm으로 쓴다.
  3. 최소항을 짝지어 간단히 한다.

세 입력 A, B, C 중 두 개 이상이 1이면 1인 다수결 함수 M의 Σm과 최소식은?

풀이

  1. 1인 줄: 011, 101, 110, 111 → Σm(3, 5, 6, 7).
    1이 두 개 이상.
  2. 3 + 7 → BC, 5 + 7 → AC, 6 + 7 → AB(7을 세 번 씀).
    X + X = X.
  3. M = AB + BC + CA.
    최소식.

의미

다수결 함수는 전가산기의 자리올림 출력과 같고, 세 개의 같은 회로로 오류를 가리는 다중화 설계에 쓴다.

검산

011: BC = 1, 100: 세 항 모두 0. 여덟 줄을 모두 대입하면 진리표와 같다.
