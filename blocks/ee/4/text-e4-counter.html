레지스터와 동기식 카운터 설계

본문
이 절에서 배울 것
  • 플립플롭 n개로 된 레지스터와 시프트 레지스터를 안다.
  • 상태표 → 다음 상태 식 → 회로 순서로 동기식 카운터를 설계한다.
  • 리플 카운터와 동기식 카운터의 차이를 안다.
먼저 알아야 할 것
  • D·T 플립플롭 (5.1절), 카르노 맵 (3.1절).

5.2.1레지스터

D 플립플롭 n개가 같은 클록을 받으면 n비트 레지스터입니다. 모서리마다 n비트를 한꺼번에 저장합니다. 각 플립플롭의 D에 이웃 플립플롭의 Q를 이으면 시프트 레지스터가 되어 모서리마다 한 칸씩 밀립니다. 직렬 통신(UART, 디지털실험 카드)에서 비트를 하나씩 받아 바이트로 모으는 장치입니다.

5.2.2순차 회로 설계 절차

동기식 순차 회로는 "현재 상태 + 입력 → 다음 상태"를 정하는 조합 논리와, 그 다음 상태를 모서리마다 저장하는 플립플롭으로 이루어집니다. 그래서 설계는 결국 다음 상태를 만드는 조합 회로를 설계하는 일입니다.

  1. 상태 순서(또는 상태도)를 정하고 상태마다 2진 번호를 붙인다.
  2. 상태표: 현재 상태 → 다음 상태.
  3. 플립플롭 종류에 맞게 입력을 정한다. D면 \(D_i = Q_i^+\) 그대로.
  4. 각 \(D_i\)를 카르노 맵으로 최소화하고 회로를 그린다. 쓰지 않는 상태는 무관 조건으로 둘 수 있으나, 빠져나올 수 있는지 확인한다.
예제 5.2.1 (3비트 상향 카운터)

D 플립플롭 \(Q_2Q_1Q_0\)으로 0, 1, …, 7, 0, …을 세는 동기식 카운터를 설계하여라.

풀이. 다음 상태는 현재 + 1입니다. 상태표를 비트별로 보면

  • \(Q_0\)은 매번 뒤집힌다: \(D_0 = Q_0'\).
  • \(Q_1\)은 \(Q_0 = 1\)일 때 뒤집힌다: \(D_1 = Q_1 \oplus Q_0\).
  • \(Q_2\)는 \(Q_1Q_0 = 11\)일 때 뒤집힌다: \(D_2 = Q_2 \oplus Q_1Q_0\).

규칙: "아래 비트가 모두 1이면 뒤집힌다." 이것은 1을 더할 때 올림이 생기는 조건(4.1절 반가산기 연쇄)과 같습니다. n비트로 늘리면 \(D_k = Q_k \oplus (Q_{k-1}\cdots Q_0)\). T 플립플롭이면 \(T_k = Q_{k-1}\cdots Q_0\)로 더 간단합니다.

예제 5.2.2 (0~5를 세는 카운터)

\(Q_2Q_1Q_0\)이 0, 1, 2, 3, 4, 5, 0, …을 세게 하라. 6, 7은 쓰지 않는다.

풀이. 상태표(현재 → 다음): 000 → 001, 001 → 010, 010 → 011, 011 → 100, 100 → 101, 101 → 000, 110·111 → X. 각 비트를 3변수 카르노 맵에 옮겨(X 활용) 최소화합니다.

  • \(D_0\): 다음 상태의 \(Q_0\)은 현재 0, 2, 4에서 1. → \(D_0 = Q_0'\).
  • \(D_1\): 현재 1, 2에서 1(m1, m2), X: 6, 7. → \(D_1 = Q_2'Q_1'Q_0 + Q_1Q_0'\). (m1은 X와 묶이지 않음)
  • \(D_2\): 현재 3, 4에서 1(m3, m4), X: 6, 7. → \(D_2 = Q_1Q_0 + Q_2Q_0'\).

쓰지 않는 상태 점검: 전원을 켰을 때 110에 있으면 식에 넣어 \(D_0 = 1\), \(D_1 = 0 + 1 = 1\), \(D_2 = 0 + 1 = 1\) → 다음 상태 111. 111이면 \(D_0 = 0\), \(D_1 = 0 + 0 = 0\), \(D_2 = 1 + 0 = 1\) → 100. 100은 정상 상태이므로 두 클록 안에 정상 순환으로 들어옵니다. 빠져나오지 못하고 맴도는 고리(잠김)가 생기면 X를 다르게 정해야 합니다.

5.2.3리플 카운터

T 플립플롭(또는 \(Q'\)을 D에 이은 D 플립플롭)의 출력을 다음 플립플롭의 클록으로 쓰면 게이트 없이 카운터가 됩니다. 간단하지만 각 단이 앞 단의 지연을 기다려 바뀌므로, 0111 → 1000에서 0110, 0100, 0000 같은 틀린 값이 잠깐 나타납니다. 디코더로 상태를 읽으면 글리치가 생깁니다. 그래서 큰 회로에서는 모든 플립플롭이 같은 클록을 받는 동기식을 씁니다.

주의쓰지 않는 상태를 무관 조건으로 두면 식이 짧아지지만, 전원을 켠 직후나 잡음으로 그 상태에 들어갔을 때 어떻게 되는지 반드시 확인하세요. 예제 5.2.2처럼 정상 순환으로 돌아오는지 표로 따라가 봅니다.
요약
  1. 레지스터 = 같은 클록의 D 플립플롭들. 시프트 레지스터는 이웃 Q를 D로.
  2. 설계: 상태 번호 → 상태표 → \(D_i = Q_i^+\) → 카르노 맵 → 회로 → 쓰지 않는 상태 점검.
  3. 2진 상향 카운터: 아래 비트가 모두 1이면 뒤집힘. 리플 카운터는 간단하지만 중간 상태가 잠깐 나타난다.

5.2.4연습문제

기본

  1. 2비트 하향 카운터(3, 2, 1, 0, 3, …)의 D 입력 식을 구하여라.
    답

    \(D_0 = Q_0'\), \(D_1 = Q_1 \oplus Q_0'\)(\(Q_0 = 0\)일 때 뒤집힘).

응용

  1. 3비트 그레이 코드 카운터(000, 001, 011, 010, 110, 111, 101, 100)의 \(D_2\) 식을 구하여라.
    답

    다음 \(Q_2\)가 1인 현재 상태: 010, 110, 111, 101 → \(D_2 = Q_1Q_0' + Q_2Q_0\).

심화

  1. 50 MHz 클록으로 1 Hz 신호를 만들려면 0부터 몇까지 세고 되돌아가는 카운터가 필요한가? 몇 비트인가?
    답

    0 ~ 24 999 999에서 되돌아가며 끝에서 출력을 뒤집으면(반주기 25 000 000클록) 1 Hz 구형파. \(2^{25} = 33\,554\,432\)이므로 25비트.
