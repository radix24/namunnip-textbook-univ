레지스터와 동기식 카운터 설계

본문

디지털 시계의 초 단위는 0에서 5까지 세고 0으로 돌아가는 카운터로 10초 자리를 만든다. 3비트 플립플롭은 0에서 7까지 여덟 상태를 가지는데, 쓰지 않는 6과 7에 전원을 켜자마자 들어가 버리면 시계는 어떻게 될까? 카운터를 설계할 때 무엇을 정하고 무엇을 확인해야 할까?

먼저 알아야 할 것D 플립플롭과 T 플립플롭(5.1절), 카르노 맵(3.1절)을 쓴다.

5.2.1레지스터

D 플립플롭 n개가 같은 클록을 받으면 n비트 레지스터가 되어, 모서리마다 n비트를 한꺼번에 저장한다. 각 플립플롭의 D에 이웃 플립플롭의 Q를 이으면 시프트 레지스터가 되어 모서리마다 한 칸씩 밀린다. 직렬 통신(UART)에서 비트를 하나씩 받아 바이트로 모으는 장치가 이것이다(5.4절).

5.2.2순차 회로 설계 절차

동기식 순차 회로는 현재 상태와 입력으로 다음 상태를 정하는 조합 논리와, 그 다음 상태를 모서리마다 저장하는 플립플롭으로 이루어진다. 그러므로 설계는 결국 다음 상태를 만드는 조합 회로를 설계하는 일이다.

순서는 이렇다. 먼저 상태 순서나 상태도를 정하고 상태마다 2진 번호를 붙인다. 이어 현재 상태에서 다음 상태로 가는 상태표를 만들고, 플립플롭 종류에 맞게 입력을 정한다. D 플립플롭이면 \(D_i = Q_i^+\) 그대로이다. 그 다음 각 \(D_i\)를 카르노 맵으로 최소화해 회로를 그린다. 이 때 쓰지 않는 상태는 무관 조건으로 둘 수 있으나, 그 상태에서 빠져나올 수 있는지 확인해야 한다.

예제 5.2.1 (3비트 상향 카운터)

D 플립플롭 \(Q_2Q_1Q_0\)으로 0, 1, …, 7, 0, …을 세는 동기식 카운터를 설계하여라.

풀이. 다음 상태는 현재에 1을 더한 값이다. 상태표를 비트별로 보면 \(Q_0\)은 매번 뒤집히므로 \(D_0 = Q_0'\)이고, \(Q_1\)은 \(Q_0 = 1\)일 때 뒤집히므로 \(D_1 = Q_1 \oplus Q_0\)이며, \(Q_2\)는 \(Q_1Q_0 = 11\)일 때 뒤집히므로 \(D_2 = Q_2 \oplus Q_1Q_0\)이다.

즉 아래 비트가 모두 1이면 뒤집힌다는 규칙이며, 이는 1을 더할 때 올림이 생기는 조건(4.1절의 반가산기 연쇄)과 같다. n비트로 늘리면 \(D_k = Q_k \oplus (Q_{k-1}\cdots Q_0)\)이고, T 플립플롭이면 \(T_k = Q_{k-1}\cdots Q_0\)로 더 간단하다.

예제 5.2.2 (0에서 5를 세는 카운터)

\(Q_2Q_1Q_0\)이 0, 1, 2, 3, 4, 5, 0, …을 세게 하여라. 6과 7은 쓰지 않는다.

풀이. 상태표는 000에서 001, 001에서 010, 010에서 011, 011에서 100, 100에서 101, 101에서 000이고, 110과 111은 X이다. 각 비트를 3변수 카르노 맵에 옮겨 X를 활용해 최소화한다. 다음 상태의 \(Q_0\)은 현재 0, 2, 4에서 1이므로 \(D_0 = Q_0'\)이다. \(D_1\)은 현재 1, 2에서 1이고 X는 6, 7인데, m1은 X와 묶이지 않으므로 \(D_1 = Q_2'Q_1'Q_0 + Q_1Q_0'\)이다. \(D_2\)는 현재 3, 4에서 1이므로 X와 함께 묶어 \(D_2 = Q_1Q_0 + Q_2Q_0'\)이다.

이제 쓰지 않는 상태를 점검하자. 전원을 켰을 때 110에 있으면 식에 넣어 \(D_0 = 1\), \(D_1 = 0 + 1 = 1\), \(D_2 = 0 + 1 = 1\)이므로 다음 상태는 111이다. 111이면 \(D_0 = 0\), \(D_1 = 0 + 0 = 0\), \(D_2 = 1 + 0 = 1\)이므로 100이다. 100은 정상 상태이므로 두 클록 안에 정상 순환으로 들어온다(그림 1). 처음 질문의 답이 이 점검이다. 만약 빠져나오지 못하고 맴도는 고리, 곧 잠김이 생기면 X를 다르게 정해야 한다.

5.2.3리플 카운터

T 플립플롭, 또는 \(Q'\)을 D에 이은 D 플립플롭의 출력을 다음 플립플롭의 클록으로 쓰면 게이트 없이 카운터가 된다. 간단하지만 각 단이 앞 단의 지연을 기다려 바뀌므로, 0111에서 1000으로 갈 때 0110, 0100, 0000 같은 틀린 값이 잠깐 나타난다. 그래서 디코더로 상태를 읽으면 글리치가 생긴다. 따라서 큰 회로에서는 모든 플립플롭이 같은 클록을 받는 동기식을 쓴다.

흔한 실수쓰지 않는 상태를 무관 조건으로 두면 식이 짧아지지만, 전원을 켠 직후나 잡음으로 그 상태에 들어갔을 때 어떻게 되는지 반드시 확인해야 한다. 예제 5.2.2처럼 정상 순환으로 돌아오는지 표로 따라가 보자.
마무리

레지스터는 같은 클록을 받는 D 플립플롭들이고, 이웃의 Q를 D로 이으면 시프트 레지스터가 된다. 동기식 카운터는 상태 번호를 정하고 상태표에서 \(D_i = Q_i^+\)를 카르노 맵으로 최소화해 만들며, 2진 상향 카운터는 아래 비트가 모두 1일 때 뒤집힌다. 쓰지 않는 상태를 무관 조건으로 썼다면 그 상태가 정상 순환으로 돌아오는지 꼭 따라가 보고, 중간 값이 잠깐 보이는 리플 카운터는 큰 회로에 쓰지 않는다.

5.2.4연습문제

기본

  1. 2비트 하향 카운터(3, 2, 1, 0, 3, …)의 D 입력 식을 구하여라.
    답

    \(D_0 = Q_0'\)이고, \(Q_0 = 0\)일 때 뒤집히므로 \(D_1 = Q_1 \oplus Q_0'\)이다.

응용

  1. 3비트 그레이 코드 카운터(000, 001, 011, 010, 110, 111, 101, 100)의 \(D_2\) 식을 구하여라.
    답

    다음 \(Q_2\)가 1인 현재 상태는 010, 110, 111, 101이므로 \(D_2 = Q_1Q_0' + Q_2Q_0\)이다.

심화

  1. 50 MHz 클록으로 1 Hz 신호를 만들려면 0부터 몇까지 세고 되돌아가는 카운터가 필요한가? 몇 비트인가?
    답

    0에서 24 999 999까지 세고 되돌아가며 끝에서 출력을 뒤집으면, 반주기가 25 000 000클록인 1 Hz 구형파가 된다. \(2^{25} = 33\,554\,432\)이므로 25비트이다.
