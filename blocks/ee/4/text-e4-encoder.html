디코더와 우선순위 인코더

본문

키보드 컨트롤러와 프린터가 동시에 CPU를 부른다. CPU는 한 번에 하나만 처리할 수 있으니 누구의 요청을 먼저 들어줄지 정해야 한다. 여러 신호선이 한꺼번에 1이 되었을 때 가장 중요한 것의 번호 하나만 뽑아내는 회로는 어떻게 만들까?

먼저 알아야 할 것멀티플렉서와 디코더(4.2절), 표준형(2.3절)을 쓴다.

4.4.1디코더

2-to-4 디코더는 입력 \(A_1A_0\)의 각 조합에서 출력 하나만 1이 되며, \(Y_0 = \bar A_1\bar A_0\)부터 \(Y_3 = A_1A_0\)까지이다. 출력이 곧 최소항이므로, 원하는 최소항 출력을 OR로 묶으면 어떤 함수든 만들 수 있다. 메모리에서는 주소를 받아 한 줄(워드)만 선택하는 데 쓴다.

4.4.2우선순위 인코더

우선순위 인코더는 입력 \(D_3D_2D_1D_0\) 가운데 1인 가장 높은 번호를 2진수로 내고, 아무것도 1이 아니면 유효 출력 V를 0으로 한다. 식은 다음과 같다.

\[ Y_1 = D_3 + D_2, \qquad Y_0 = D_3 + \bar D_2D_1, \qquad V = D_3 + D_2 + D_1 + D_0 \]

\(Y_1\)은 번호가 2나 3일 때 1이어야 하므로 \(D_3\)이나 \(D_2\)가 1이면 1이다. 한편 \(Y_0\)은 번호가 3이거나 1일 때 1이어야 하는데, 번호가 1이 되려면 \(D_1\)이 1이고 그보다 높은 \(D_2\)가 0이어야 하므로 \(\bar D_2D_1\)이 들어간다. 처음 질문의 답이 이 회로이며, 높은 번호의 입력이 낮은 번호의 항을 막는 꼴로 우선순위가 정해진다.

예제 4.4.1

입력이 0110이면 출력은? 인터럽트 제어기에서 우선순위 인코더를 쓰는 이유는?

풀이. 가장 높은 1은 \(D_2\)이므로 Y = 10, V = 1이다. 검산하면 \(Y_1 = 0 + 1 = 1\), \(Y_0 = 0 + \bar 1\cdot1 = 0\)이다(그림 1). 여러 장치가 동시에 요청하면 가장 중요한 요청의 번호를 CPU에 알려야 하기 때문에 우선순위 인코더를 쓴다.

흔한 오해"보통 인코더도 여러 입력을 처리한다"는 틀리다. 단순 인코더는 입력이 하나만 1이라고 가정하므로 둘 이상이면 틀린 값을 낸다. 또 V 출력이 필요 없다고 생각하기 쉽지만, 입력이 모두 0인 경우와 \(D_0\)만 1인 경우가 둘 다 Y = 00이어서 둘을 구별하려면 V가 필요하다.
마무리

디코더의 출력은 최소항이어서 OR로 함수를 만들거나 메모리 주소를 선택하는 데 쓴다. 우선순위 인코더는 \(Y_1 = D_3 + D_2\), \(Y_0 = D_3 + \bar D_2D_1\)처럼 높은 입력이 낮은 입력을 막도록 만들어 1인 입력 가운데 가장 높은 번호만 내고, 유효 비트 V로 입력이 있는지를 알린다. 그래서 동시에 들어온 인터럽트 가운데 가장 급한 것을 고를 수 있다.

4.4.3연습문제

기본

  1. 3-to-8 디코더에서 입력 101이면 켜지는 출력은?
    답

    \(Y_5\)이다.

응용

  1. 디코더 하나와 OR 게이트로 \(F = \Sigma m(1, 2, 7)\)을 만들려면?
    답

    3-to-8 디코더의 \(Y_1\), \(Y_2\), \(Y_7\)을 OR한다.

심화

  1. 입력 0001과 0000을 우선순위 인코더 출력으로 구별하는 방법은?
    답

    둘 다 Y = 00이지만 V가 각각 1과 0으로 다르다.
