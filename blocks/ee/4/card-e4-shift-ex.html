직렬로 받은 바이트 읽기

SIPO · 비트 순서

출발점

SIPO 시프트 레지스터는 직렬 비트를 모아 병렬로 내줍니다(5.4절). 먼저 들어온 비트가 가장 멀리 이동한다.

문제 해결 전략 · 클록마다 한 칸
  1. 비트가 들어오는 순서를 적는다.
  2. 8클록 뒤 각 칸의 값을 구한다.
  3. 최상위 비트가 먼저 왔는지(MSB 먼저) 확인한다.

MSB 먼저 0, 1, 0, 0, 0, 0, 0, 1을 8비트 SIPO(Q₀ 입력 쪽)에 넣었다. 8클록 뒤 Q₇…Q₀과 그 값(16진수, ASCII)은?

풀이

  1. 처음 들어온 0이 Q₇, 마지막 1이 Q₀.
    8칸 이동.
  2. Q₇…Q₀ = 0100 0001 = 0x41.
    MSB 먼저.
  3. ASCII 'A'.
    65.

의미

UART는 LSB 먼저, SPI는 보통 MSB 먼저 보내므로 수신 쪽은 순서를 맞춰야 한다.

검산

0x41 = 65 = 64 + 1로, 1이 Q₆(64)과 Q₀(1)에 있어 맞다.
