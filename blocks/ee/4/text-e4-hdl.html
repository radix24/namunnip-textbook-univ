하드웨어 기술 언어(Verilog) 기초

본문
이 절에서 배울 것

7.1.1왜 글로 회로를 적나

게이트 수십 개는 그림으로 그릴 수 있지만, 수백만 개가 든 칩은 그릴 수 없습니다. 그래서 회로를 글로 적고, 컴퓨터가 그 글을 게이트로 바꾸게(합성) 합니다. 이 글이 하드웨어 기술 언어(HDL)이고, 대표가 Verilog와 VHDL입니다.

HDL은 프로그래밍 언어처럼 보이지만 뜻이 다릅니다. 프로그램은 위에서 아래로 한 줄씩 실행되지만, HDL의 각 문장은 동시에 존재하는 회로 조각입니다. assign y = a & b;는 "y에 a와 b의 AND를 계산해 넣어라"가 아니라 "y는 늘 a AND b인 도선이다"입니다.

7.1.2모듈과 조합 회로

회로 하나는 module로 적고, 입력·출력 포트를 선언합니다.

module mux2 (input  wire a, b, s,
             output wire y);
  assign y = s ? b : a;        // s=1이면 b, 0이면 a (4.2절 MUX)
endmodule

module fa (input wire a, b, cin, output wire s, cout);
  assign s    = a ^ b ^ cin;              // 4.1절 전가산기
  assign cout = (a & b) | (cin & (a ^ b));
endmodule

여러 비트는 벡터로: wire [3:0] x;는 4비트입니다. 4비트 가산기는 assign {cout, s} = a + b + cin; 한 줄로도 쓰고, 합성 도구가 알맞은 가산기 구조(리플, 캐리 예측)를 고릅니다.

조건이 많은 조합 회로는 always @* 블록에 적습니다. @*는 "블록 안에서 읽는 신호 중 하나라도 바뀌면"이라는 뜻으로, 조합 회로를 나타냅니다.

module dec7 (input wire [3:0] x, output reg [6:0] seg);
  always @* begin
    case (x)
      4'd0: seg = 7'b1111110;   4'd1: seg = 7'b0110000;
      4'd2: seg = 7'b1101101;   4'd3: seg = 7'b1111001;
      // … 4'd9까지
      default: seg = 7'b0000000;   // 모든 경우에 값을 준다
    endcase
  end
endmodule

7.1.3순차 회로

플립플롭은 always @(posedge clk)로 적고, 대입은 <=(비차단 대입)을 씁니다. 비차단 대입은 "모서리 순간의 오른쪽 값들을 모두 읽은 뒤 한꺼번에 저장"이라, 플립플롭 여럿이 동시에 바뀌는 실제 하드웨어와 같습니다.

module counter4 (input wire clk, rst, output reg [3:0] q);
  always @(posedge clk) begin
    if (rst) q <= 4'd0;          // 동기 리셋
    else     q <= q + 4'd1;      // 5.2절 동기식 카운터
  end
endmodule

FSM은 "상태 레지스터(순차)"와 "다음 상태·출력 논리(조합)"를 두 블록으로 나누어 적는 것이 관례입니다(6.1절 구조 그대로).

module det11 (input wire clk, rst, x, output wire z);
  localparam A = 1'b0, B = 1'b1;
  reg state, next;
  always @(posedge clk) state <= rst ? A : next;   // 상태 레지스터
  always @* begin                                   // 다음 상태
    case (state)
      A: next = x ? B : A;
      B: next = x ? B : A;
    endcase
  end
  assign z = (state == B) && x;    // 밀리 출력 (6.2절)
endmodule

7.1.4테스트벤치와 시뮬레이션

설계를 확인하려면 입력을 넣고 출력을 보는 또 하나의 모듈, 테스트벤치를 씁니다. 테스트벤치는 합성되지 않는 시뮬레이션 전용 코드라 시간 지연(#10)과 출력문($display)을 쓸 수 있습니다.

module tb;
  reg a = 0, b = 0, cin = 0;  wire s, cout;
  fa dut (.a(a), .b(b), .cin(cin), .s(s), .cout(cout));
  integer k;
  initial begin
    for (k = 0; k < 8; k = k + 1) begin
      {a, b, cin} = k;  #10;
      $display("%b %b %b -> s=%b cout=%b", a, b, cin, s, cout);
    end
    $finish;
  end
endmodule

무료 도구 Icarus Verilog로 iverilog -o sim fa.v tb.v, vvp sim을 실행하면 전가산기 진리표 8줄이 찍힙니다. 파형은 $dumpfile, $dumpvars로 저장해 GTKWave로 봅니다. 이 절의 실습 카드에서 따라 합니다.

7.1.5래치가 생기는 실수

always @* 블록에서 어떤 경우에 출력에 값을 주지 않으면, 합성 도구는 "그때는 이전 값을 유지하라"는 뜻으로 읽고 래치(5.1절)를 만듭니다. 조합 회로를 의도했는데 기억 소자가 생긴 것이라 타이밍이 망가집니다. 막는 방법: case 문에 default를 두거나, 블록 맨 앞에서 모든 출력에 기본값을 줍니다.

주의순차 블록에서 =(차단 대입)를 쓰면 위 줄의 결과를 아래 줄이 바로 읽어, 시프트 레지스터가 한 클록에 여러 칸 밀리는 것처럼 시뮬레이션될 수 있습니다. 규칙: 순차 블록은 <=, 조합 블록은 =.
요약
  1. HDL 문장은 동시에 존재하는 회로다. module, 포트, wire/reg, 벡터.
  2. 조합: assign 또는 always @*(모든 경우에 값). 순차: always @(posedge clk)와 <=.
  3. 테스트벤치로 입력을 넣고 결과를 확인한다. 값이 빠진 조합 블록은 래치가 된다.

7.1.6연습문제

기본

  1. 4비트 비교기(a > b이면 gt = 1)를 assign 한 줄로 써라.
    답

    assign gt = (a > b); (a, b는 wire [3:0])

응용

  1. 다음 코드에서 래치가 생기는 이유와 고치는 방법은? always @* if (en) y = d;
    답

    en = 0일 때 y에 값이 없어 이전 값을 유지해야 하므로 래치. else y = 1'b0;를 더하거나 블록 앞에 y = 1'b0;.

심화

  1. 4비트 시프트 레지스터 always @(posedge clk) begin q[0] = d; q[1] = q[0]; q[2] = q[1]; q[3] = q[2]; end를 시뮬레이션하면 무엇이 잘못되는가?
    답

    차단 대입이라 한 모서리에 d가 q[0]~q[3]까지 모두 복사된다. <=로 바꾸면 한 칸씩 밀린다(또는 q <= {q[2:0], d};).
