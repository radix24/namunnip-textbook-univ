프로그래머블 논리와 HDL 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념Verilog의 assign 두 줄의 순서를 바꿔도 회로가 같은 이유는? [07-01]

    힌트 1

    HDL 문장은 무엇을 나타내나요?

    힌트 2

    7.1.1.

    풀이

    assign은 실행 순서가 있는 명령이 아니라 늘 존재하는 도선 연결을 적은 것이므로, 적는 순서와 상관없이 같은 회로가 됩니다.

  2. 계산4-to-1 MUX를 Verilog always @*와 case 문으로 쓰세요. 입력 d[3:0], 선택 s[1:0], 출력 y. [07-01]

    힌트 1

    y는 reg로 선언.

    힌트 2

    모든 경우에 값을 주세요.

    풀이 
    always @* begin
  case (s)
    2'd0: y = d[0];  2'd1: y = d[1];
    2'd2: y = d[2];  default: y = d[3];
  endcase
end

    더 짧게는 assign y = d[s];.

  3. 계산2비트 주소, 3비트 출력 ROM으로 "입력 x의 제곱(0, 1, 4, 9)"을 만든다. ROM 내용을 쓰세요. [07-02]

    힌트 1

    9 = 1001은 4비트인데요?

    힌트 2

    출력 비트 수를 다시 정하세요.

    풀이

    9를 담으려면 출력 4비트가 필요합니다(3비트로는 0~7). 주소 0~3: 0000, 0001, 0100, 1001. 명세의 3비트가 부족하다는 것을 알아차리는 것까지가 문제입니다.

  4. 계산4입력 LUT에 \(F = AB + CD\)를 넣을 때 INIT 16진수 값(주소 = 8A + 4B + 2C + D, 비트 F가 최상위)을 구하세요. [07-02]

    힌트 1

    F = 1인 주소: CD = 11인 3, 7, 11, 15와 AB = 11인 12~15.

    힌트 2

    주소 15~12, 11~8, 7~4, 3~0을 각각 16진 한 자리로.

    풀이

    1인 주소: 3, 7, 11, 12, 13, 14, 15. 15~12: 1111 = F, 11~8: 1000 = 8, 7~4: 1000 = 8, 3~0: 1000 = 8. INIT = 0xF888.

  5. 판단학생의 코드 always @(posedge clk) begin b = a; c = b; end가 "a → b → c로 한 클록에 한 칸씩 밀리는 2단 레지스터"라고 했다. 맞나요? [07-01]

    힌트 1

    차단 대입 =은 바로 반영됩니다.

    힌트 2

    둘째 줄의 b는 새 값인가, 옛 값인가?

    풀이

    틀렸습니다. 차단 대입이라 둘째 줄의 b는 방금 바뀐 새 값(= a)이므로 c도 a가 되어 한 클록에 두 칸이 밀립니다(합성하면 b와 c가 같은 플립플롭 출력처럼 됨). b <= a; c <= b;로 써야 합니다.

  6. 도전FPGA 설계에서 타이밍 보고서가 "worst slack −0.8 ns"를 알렸다. 클록 제약은 100 MHz이다. 실제로 낼 수 있는 최대 클록은 대략 얼마이고, 고칠 방법 두 가지는? [07-02]

    힌트 1

    여유가 음수면 주기가 그만큼 모자랍니다.

    힌트 2

    5.3절, 4.3절.

    풀이

    필요한 주기 10.8 ns → 약 92.6 MHz. 방법: (1) 임계 경로 중간에 플립플롭을 넣어 나눈다(파이프라이닝), (2) 더 빠른 구조로 바꾼다(예: 리플 가산기를 캐리 예측 또는 FPGA 전용 캐리 체인으로). 클록을 낮추는 것도 한 방법이지만 목표를 포기하는 것입니다.
