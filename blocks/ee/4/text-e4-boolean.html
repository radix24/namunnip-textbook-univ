불 대수와 논리 게이트

본문

진리표를 보고 그대로 회로를 만들면 출력이 1인 줄마다 AND 게이트가 하나씩 필요하다. 그런데 같은 진리표를 게이트 두 개로 만들 수도 있다. 게이트를 줄이려면 식을 어떻게 다뤄야 할까? 0과 1만 있는 세계에도 일반 대수 같은 계산 규칙이 있을까?

먼저 알아야 할 것명제와 진리값, "그리고, 또는, 아니다"(고교 수학의 집합과 명제), 2진수(1.1절)를 쓴다.

2.1.1세 가지 기본 연산

디지털 회로가 하는 일은 결국 0과 1을 받아 0과 1을 내는 함수이다. 변수 값이 0 또는 1뿐인 이런 함수를 다루는 대수를 불(Boole) 대수라 한다. 기본 연산은 셋이다. AND \(A\cdot B\)(또는 \(AB\))는 둘 다 1일 때만 1이어서 직렬 스위치와 같고, OR \(A + B\)는 하나라도 1이면 1이어서 병렬 스위치와 같으며, NOT \(A'\)(또는 \(\bar A\))은 값을 뒤집는다.

여기서 \(+\)는 산술 덧셈이 아니어서 \(1 + 1 = 1\)이다. 이 밖에 자주 쓰는 게이트로 NAND \((AB)'\), NOR \((A + B)'\), 서로 다를 때 1인 XOR \(A \oplus B\), 같을 때 1인 XNOR가 있다. n개 입력의 함수는 진리표 \(2^n\)줄로 완전히 정해진다.

2.1.2불 대수의 법칙

변수가 0과 1뿐이므로 각 법칙은 진리표로 모든 경우를 확인하면 증명된다. 중요한 것을 짝으로 적자. 짝은 AND와 OR, 0과 1을 서로 바꾼 쌍대이다. 항등 법칙은 \(A + 0 = A\), \(A\cdot1 = A\)이고, 지배 법칙은 \(A + 1 = 1\), \(A\cdot0 = 0\)이다. 멱등 법칙은 \(A + A = A\), \(AA = A\)이고, 보원 법칙은 \(A + A' = 1\), \(AA' = 0\)이다.

교환, 결합, 분배 법칙 \(A(B + C) = AB + AC\)도 성립하는데, 일반 대수에는 없는 \(A + BC = (A + B)(A + C)\)도 성립한다는 점이 다르다. 또 흡수 법칙 \(A + AB = A\), \(A(A + B) = A\)와 드 모르간 법칙 \((A + B)' = A'B'\), \((AB)' = A' + B'\)이 식을 줄이는 데 자주 쓰인다.

정리 2.1.1 (합의 정리)

\(AB + A'C + BC = AB + A'C\).

증명.보원과 항등 법칙으로 \(BC = BC(A + A')\)이고, 분배 법칙으로 이는 \(ABC + A'BC\)이다. 그러면 \(AB + A'C + ABC + A'BC = AB(1 + C) + A'C(1 + B)\)이고, 지배와 항등 법칙으로 \(AB + A'C\)이다. ∎

\(BC\)항은 A가 1이면 \(AB\)가, A가 0이면 \(A'C\)가 이미 덮는 항이어서 필요 없다. 이런 남는 항을 찾는 눈을 기르는 것이 간단히 하기의 요령이며, 3단원의 카르노 맵이 이를 그림으로 해 준다.

예제 2.1.2

\(F = A'B'C + A'BC + AB'C + ABC'\)를 간단히 하여라.

풀이. 앞 두 항은 \(A'C(B' + B) = A'C\)이다. 셋째 항과 첫째 항은 \(B'C(A' + A) = B'C\)인데, 첫째 항을 두 번 쓸 수 있는 근거는 멱등 법칙 \(X = X + X\)이다. 따라서 \(F = A'C + B'C + ABC'\)이다. 그런데 \(A'C + B'C = (A' + B')C = (AB)'C\)이므로 \(F = (AB)'C + AB\,C'\), 곧 \(F = AB \oplus C\)이다. 처음 질문의 답이 그림 1로, 진리표로 확인하면 C와 AB가 다를 때 1인 함수와 같다.

2.1.3표준형

모든 변수가 그대로 또는 NOT으로 한 번씩 들어간 AND 항을 최소항 \(m_k\)라 하며, 진리표의 k번째 줄에서만 1이다. 예를 들어 3변수에서 \(m_5 = AB'C\)(101)이다. 출력이 1인 줄의 최소항을 OR한 \(F = \Sigma m(\cdots)\)를 곱의 합(SOP) 표준형이라 한다. 반대로 모든 변수가 들어간 OR 항을 최대항 \(M_k\)라 하며 k번째 줄에서만 0이다. 가령 \(M_5 = A' + B + C'\)이다. 출력이 0인 줄의 최대항을 AND한 \(F = \Pi M(\cdots)\)를 합의 곱(POS) 표준형이라 한다.

진리표가 있으면 표준형은 바로 쓸 수 있다. 표준형은 길지만 기계적으로 만들 수 있다는 것이 장점이고, 간단히 하는 출발점이다. 또 드 모르간 법칙으로 \(m_k' = M_k\)이므로, F의 최소항 번호와 최대항 번호는 서로 나머지이다(2.3절).

흔한 실수\((A + B)' = A' + B'\)라고 쓰는 실수가 가장 흔하다. 드 모르간 법칙은 뒤집으면 AND와 OR가 바뀐다는 것이다. 의심스러우면 \(A = 1\), \(B = 0\)을 넣어 보자. 왼쪽은 0인데 틀린 오른쪽은 1이 나온다.
마무리

불 대수는 0과 1만 있는 AND, OR, NOT의 대수로, \(1 + 1 = 1\)이고 \(A + BC = (A + B)(A + C)\)처럼 일반 대수와 다른 법칙도 있지만 모든 법칙은 진리표로 확인할 수 있다. 흡수, 드 모르간, 합의 정리로 식을 줄이면 같은 진리표를 더 적은 게이트로 만들 수 있으며, 그 출발점은 1인 줄의 최소항을 더한 SOP 표준형 \(\Sigma m\)이나 0인 줄의 최대항을 곱한 POS 표준형 \(\Pi M\)이다.

2.1.4연습문제

기본

  1. \(F = (A + B)(A + B')\)를 간단히 하여라.
    답

    분배 법칙의 쌍대로 \(A + BB' = A\)이다.

  2. \(F(A,B,C) = \Sigma m(1, 2, 6)\)을 POS 표준형으로 써라.
    답

    \(\Pi M(0, 3, 4, 5, 7)\)이다.

응용

  1. \(F = ((A + B')C)'\)를 드 모르간 법칙으로 NOT이 변수에만 붙게 바꾸어라.
    답

    \((A + B')' + C' = A'B + C'\)이다.

심화

  1. 합의 정리의 쌍대 \((A + B)(A' + C)(B + C) = (A + B)(A' + C)\)를 증명하여라.
    답

    쌍대 원리에 따라 원래 정리에서 AND와 OR, 0과 1을 바꾸면 성립한다. 직접 증명하려면 \(B + C = (B + C) + AA'\)로 같은 방법을 쓴다.
