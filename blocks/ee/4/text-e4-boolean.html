  • 명제와 진리값, "그리고·또는·아니다" (고교 수학, 집합과 명제).

2.1.1세 가지 기본 연산

디지털 회로가 하는 일은 결국 0과 1을 받아 0과 1을 내는 함수입니다. 변수 값이 0 또는 1뿐인 이런 함수를 다루는 대수를 불(Boole) 대수라 합니다. 기본 연산 셋을 한 줄씩 정의합니다.

AND \(A\cdot B\) (또는 \(AB\)): 둘 다 1일 때만 1. 직렬 스위치.

OR \(A + B\): 하나라도 1이면 1. 병렬 스위치.

NOT \(A'\) (또는 \(\bar A\)): 뒤집기.

여기서 \(+\)는 산술 덧셈이 아닙니다. \(1 + 1 = 1\)입니다. 이 밖에 자주 쓰는 게이트로 NAND \((AB)'\), NOR \((A + B)'\), XOR \(A \oplus B\)(서로 다를 때 1), XNOR(같을 때 1)가 있습니다. n개 입력의 함수는 진리표 \(2^n\)줄로 완전히 정해집니다.

2.1.2불 대수의 법칙

각 법칙은 변수가 0과 1뿐이므로 진리표로 모든 경우를 확인하면 증명됩니다. 중요한 것을 짝으로 적습니다(왼쪽과 오른쪽은 AND와 OR, 0과 1을 바꾼 쌍대).

  • 항등: \(A + 0 = A\), \(A\cdot1 = A\). 지배: \(A + 1 = 1\), \(A\cdot0 = 0\).
  • 멱등: \(A + A = A\), \(AA = A\). 보원: \(A + A' = 1\), \(AA' = 0\).
  • 교환, 결합, 분배: \(A(B + C) = AB + AC\), 그리고 일반 대수에는 없는 \(A + BC = (A + B)(A + C)\).
  • 흡수: \(A + AB = A\), \(A(A + B) = A\).
  • 드 모르간: \((A + B)' = A'B'\), \((AB)' = A' + B'\).
정리 2.1.1 (합의 정리)

\(AB + A'C + BC = AB + A'C\).

증명.\(BC = BC(A + A')\)(보원, 항등)\( = ABC + A'BC\)(분배). 그러면 \(AB + A'C + ABC + A'BC = AB(1 + C) + A'C(1 + B)\)(분배)\( = AB + A'C\)(지배, 항등). ∎

\(BC\)항은 "A가 1이면 AB가, A가 0이면 A'C가 이미 덮는" 항이라 필요 없습니다. 이런 남는 항을 찾는 눈을 기르는 것이 간단히 하기의 핵심이고, 3단원의 카르노 맵이 이를 그림으로 해 줍니다.

예제 2.1.2

\(F = A'B'C + A'BC + AB'C + ABC'\)를 간단히 하여라.

풀이. 앞 두 항: \(A'C(B' + B) = A'C\). 셋째 항과 첫째 항: \(B'C(A' + A) = B'C\). 그런데 첫째 항을 두 번 쓸 수 있는 근거는 멱등 \(X = X + X\)입니다. 따라서 \(F = A'C + B'C + ABC'\). 여기서 \(A'C + B'C = (A' + B')C = (AB)'C\)이므로 \(F = (AB)'C + AB\,C'\), 곧 \(F = AB \oplus C\). 진리표로 확인하면 C와 AB가 다를 때 1인 함수와 같습니다.

2.1.3표준형

최소항 \(m_k\): 모든 변수가 한 번씩(그대로 또는 NOT) 들어간 AND 항으로, 진리표의 k번째 줄에서만 1. 예: 3변수에서 \(m_5 = AB'C\)(101).

곱의 합(SOP) 표준형: 출력이 1인 줄의 최소항을 OR. \(F = \Sigma m(\cdots)\).

최대항 \(M_k\): 모든 변수가 들어간 OR 항으로, k번째 줄에서만 0. \(M_5 = A' + B + C'\).

합의 곱(POS) 표준형: 출력이 0인 줄의 최대항을 AND. \(F = \Pi M(\cdots)\).

진리표가 있으면 표준형은 바로 쓸 수 있습니다. 표준형은 길지만 기계적으로 만들 수 있다는 것이 장점이고, 간단히 하는 출발점입니다. \(m_k' = M_k\)(드 모르간)이므로 F의 최소항 번호와 최대항 번호는 서로 나머지입니다.

주의\((A + B)' = A' + B'\)라고 쓰는 실수가 가장 흔합니다. 드 모르간은 "뒤집으면 AND와 OR가 바뀐다"입니다. 의심스러우면 \(A = 1, B = 0\)을 넣어 보세요: 왼쪽 0, 틀린 오른쪽 1.
요약
  1. AND, OR, NOT과 진리표. 불 대수에서 \(1 + 1 = 1\), \(A + BC = (A + B)(A + C)\).
  2. 흡수, 드 모르간, 합의 정리로 식을 줄인다. 모든 법칙은 진리표로 확인할 수 있다.
  3. SOP 표준형 \(\Sigma m\)(1인 줄), POS 표준형 \(\Pi M\)(0인 줄).

2.1.4연습문제

기본

  1. \(F = (A + B)(A + B')\)를 간단히 하여라.
    답

    \(A + BB' = A\) (분배의 쌍대).

  2. \(F(A,B,C) = \Sigma m(1, 2, 6)\)을 POS 표준형으로 써라.
    답

    \(\Pi M(0, 3, 4, 5, 7)\).

응용

  1. \(F = ((A + B')C)'\)를 드 모르간으로 NOT이 변수에만 붙게 바꿔라.
    답

    \((A + B')' + C' = A'B + C'\).

심화

  1. 합의 정리의 쌍대 \((A + B)(A' + C)(B + C) = (A + B)(A' + C)\)를 증명하여라.
    답

    쌍대 원리: 원래 정리에서 AND↔OR, 0↔1을 바꾸면 성립한다. 직접 증명은 \(B + C = (B + C) + AA'\)로 같은 방법.
