5.3.1플립플롭의 세 시간

5.1절의 "모서리 순간의 D를 저장"은 이상화입니다. 실제 플립플롭은 모서리 앞뒤 짧은 시간 동안 D가 가만히 있어야 확실히 저장합니다.

셋업 시간 \(t_{su}\): 모서리 전에 D가 안정되어 있어야 하는 최소 시간.

홀드 시간 \(t_h\): 모서리 뒤에도 D가 그대로여야 하는 최소 시간.

클록-출력 지연 \(t_{cq}\): 모서리에서 Q가 바뀔 때까지 걸리는 시간.

이 창(모서리 \(-t_{su}\) ~ \(+t_h\)) 안에서 D가 바뀌면 플립플롭이 0과 1 사이의 중간 상태에 오래 머물 수 있습니다. 이를 준안정 상태라 하고, 언제 끝날지 확률로만 말할 수 있어 시스템 오류의 원인이 됩니다.

5.3.2두 플립플롭 사이의 경로

플립플롭 FF1의 출력이 조합 논리를 지나 FF2의 입력으로 가는 경로를 생각합니다. 조합 논리의 가장 긴 지연을 \(t_{pd}\), 가장 짧은 지연을 \(t_{cd}\)(오염 지연)라 합니다.

정리 5.3.1 (셋업·홀드 조건)

클록 주기 \(T\), FF2의 클록이 FF1보다 \(t_\text{skew}\)만큼 늦게 도착할 때

\[ \text{셋업: } t_{cq} + t_{pd} + t_{su} \le T + t_\text{skew}, \qquad \text{홀드: } t_{cq} + t_{cd} \ge t_h + t_\text{skew}. \]

증명.모서리 k(시각 0)에 FF1이 새 값을 내보내면, 그 값이 FF2 입력에 늦어도 \(t_{cq} + t_{pd}\)에 도착한다. FF2는 다음 모서리(시각 \(T + t_\text{skew}\))에 이 값을 받아야 하므로 그보다 \(t_{su}\) 전에 도착해야 한다: 셋업 조건. 한편 새 값이 가장 빨리 도착하는 때는 \(t_{cq} + t_{cd}\)이고, FF2는 같은 모서리 k(자기 시각 \(t_\text{skew}\))에서 이전 값을 저장하는 중이므로 \(t_\text{skew} + t_h\)까지는 이전 값이 남아 있어야 한다: 홀드 조건. ∎

셋업 조건에서 최대 클록 주파수가 나옵니다(스큐 0):

\[ f_\text{max} = \frac{1}{t_{cq} + t_{pd} + t_{su}}. \]

가장 긴 지연 경로를 임계 경로라 합니다. 회로를 빠르게 하려면 임계 경로를 줄여야 하고(캐리 예측, 4.3절), 줄이기 어려우면 중간에 플립플롭을 넣어 경로를 쪼갭니다(파이프라이닝, 전전14).

예제 5.3.2

\(t_{cq} = 0.8\) ns, \(t_{su} = 0.5\) ns, \(t_h = 0.3\) ns인 플립플롭 사이에 4비트 리플 캐리 가산기(게이트 지연 0.2 ns, 최악 9단, 최단 1단)가 있다. 최대 클록과 홀드 여유를 구하여라. 16비트(33단)로 늘리면?

풀이. 4비트: \(t_{pd} = 1.8\) ns, \(f_\text{max} = 1/(0.8 + 1.8 + 0.5) = 1/3.1\ \text{ns} \approx 323\) MHz. 홀드: \(0.8 + 0.2 = 1.0 \ge 0.3\), 여유 0.7 ns. 16비트: \(t_{pd} = 6.6\) ns, \(f_\text{max} = 1/7.9\ \text{ns} \approx 127\) MHz. 같은 플립플롭이라도 가운데 조합 논리가 클록을 정합니다.

5.3.3홀드 위반은 클록으로 못 고친다

홀드 조건에는 T가 없습니다. 그래서 홀드 위반은 클록을 느리게 해도 고쳐지지 않고, 빠른 경로에 지연 소자(버퍼)를 넣어야 합니다. 스큐가 크면 셋업에는 도움이 되지만 홀드를 위협합니다. 디지털실험의 타이밍 카드에서 스큐를 바꾸며 이 맞바꿈을 확인할 수 있습니다.

주의바깥에서 들어오는 신호(버튼, 다른 클록의 회로)는 우리 클록과 무관하게 바뀌어 셋업·홀드를 지킬 수 없습니다. 플립플롭 두 개를 이어 한 클록 기다리는 동기화기로 준안정 상태가 퍼질 확률을 줄입니다.
요약
  1. \(t_{su}\), \(t_h\): 모서리 앞뒤로 D가 가만히 있어야 하는 시간. 어기면 준안정.
  2. 셋업 \(t_{cq} + t_{pd} + t_{su} \le T + t_\text{skew}\) → \(f_\text{max}\). 홀드 \(t_{cq} + t_{cd} \ge t_h + t_\text{skew}\).
  3. 임계 경로가 클록을 정한다. 홀드 위반은 지연을 더해 고친다.

5.3.4연습문제

기본

  1. \(t_{cq} = 1\) ns, \(t_{pd} = 6\) ns, \(t_{su} = 1\) ns이면 \(f_\text{max}\)는?
    답

    125 MHz.

응용

  1. 위 회로를 가운데에서 둘로 나누어(각 3 ns) 플립플롭을 하나 더 넣으면 \(f_\text{max}\)는? 결과가 나오기까지 몇 클록이 걸리는가?
    답

    \(1/(1 + 3 + 1) = 200\) MHz. 2클록(대신 매 클록 새 입력을 받을 수 있다).

심화

  1. FF1의 출력이 바로 FF2의 입력으로 간다(\(t_{pd} = t_{cd} = 0\), 시프트 레지스터). \(t_{cq} = 0.4\) ns, \(t_h = 0.2\) ns일 때 허용되는 최대 스큐는?
    답

    홀드: \(0.4 \ge 0.2 + t_\text{skew}\) → \(t_\text{skew} \le 0.2\) ns.
