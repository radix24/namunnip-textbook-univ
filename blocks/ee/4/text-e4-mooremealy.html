무어 기계와 밀리 기계

본문

직렬로 들어오는 비트에서 1이 두 번 연속되면 알리는 회로를 만든다. 같은 일을 하는 회로를 상태 2개로도, 상태 3개로도 만들 수 있다고 한다. 상태가 적은 쪽이 늘 더 좋을까? 두 회로는 무엇이 다를까?

먼저 알아야 할 것FSM 설계 절차(6.1절)를 쓴다.

6.2.1출력이 나오는 곳

무어 기계는 출력이 현재 상태만의 함수여서 상태도에서 출력을 원 안에 적고, 출력은 클록 모서리에서만 바뀐다. 반면 밀리 기계는 출력이 현재 상태와 현재 입력의 함수여서 출력을 화살표 위에 "입력/출력"으로 적고, 입력이 바뀌면 모서리를 기다리지 않고 출력이 바뀐다. 두 방식은 같은 일을 할 수 있지만, 출력이 나오는 시점과 상태 수가 다르다.

6.2.2순서 검출기로 비교

예제 6.2.1

직렬 입력 x에서 "11"이 나타나면(겹침 허용) 출력 1을 내는 검출기를 무어와 밀리 방식으로 설계하여라.

풀이(밀리). 기억할 것은 직전 비트가 1이었는가이다. 상태는 A(직전 0 또는 시작)와 B(직전 1) 둘이다. A에서 0이면 출력 0으로 A, 1이면 출력 0으로 B로 가고, B에서 0이면 출력 0으로 A, 1이면 출력 1로 B에 머문다. 따라서 출력은 상태 B이고 지금 입력이 1일 때인 \(z = Bx\)이다. 플립플롭 하나(Q = 1이 B)로 \(Q^+ = x\), \(z = Qx\)이다.

풀이(무어). 출력이 상태에만 달려 있으므로 11을 방금 완성했다는 사실을 상태로 따로 둬야 한다. 상태는 A(직전 0), B(직전 1, 아직 11 아님), C(11 완성, 출력 1) 셋이다. A에서 1이면 B, B에서 1이면 C, C에서 1이면 C에 머물고, 어디서든 0이면 A로 간다. 상태가 3개이므로 플립플롭이 2개 든다(그림 1).

시점도 다르다. 입력이 0, 1, 1, 1, 0이면 밀리 출력은 둘째 1이 들어온 그 클록 동안, 곧 입력이 1인 동안 1이고, 무어 출력은 그 다음 클록부터 1이다. 즉 무어가 한 클록 늦다. 처음 질문의 답이 이것이다.

6.2.3무엇을 고를까

밀리 기계는 보통 상태가 하나 이상 적고 출력이 한 클록 빠르다. 하지만 입력이 클록과 무관하게 흔들리면 출력도 그대로 흔들려 글리치가 생기고, 출력이 다음 회로의 조합 경로에 바로 이어져 임계 경로가 길어진다. 반면 무어 기계는 출력이 플립플롭 뒤의 논리로만 정해지므로 모서리 사이에 안정적이다.

그래서 실무에서는 밀리 출력 뒤에 플립플롭을 하나 달아 등록된 출력으로 만드는 경우가 많다. 그러면 무어처럼 안정적이 되고, 시점은 무어와 같아진다.

흔한 실수무어 상태도의 화살표에는 입력만, 밀리 상태도의 화살표에는 "입력/출력"을 적는다. 섞어 쓰면 출력이 언제 바뀌는지 읽을 수 없게 된다.
마무리

무어 기계는 출력이 상태만의 함수여서 모서리에서만 바뀌고 안정적이며, 밀리 기계는 출력이 상태와 입력의 함수여서 입력에 바로 반응한다. 같은 기능이라면 밀리가 상태가 적고 한 클록 빠르지만 입력의 흔들림이 출력에 그대로 나오므로, 상태가 적다고 늘 좋은 것은 아니다. 밀리 출력에 플립플롭을 달면 단순함과 안정성을 함께 얻는 대신 한 클록 늦어진다.

6.2.4연습문제

기본

  1. 예제 6.2.1의 밀리 기계에 입력 1, 1, 0, 1, 1, 1을 넣었을 때 출력은?
    답

    0, 1, 0, 0, 1, 1이다.

응용

  1. "101" 검출기(겹침 허용)의 밀리 상태도를 그려라.
    답

    A(시작)에서 1/0이면 B, 0/0이면 A로 간다. B("1")에서 0/0이면 C, 1/0이면 B에 머문다. C("10")에서 1/1이면 B, 0/0이면 A로 간다. 상태는 3개이다.

심화

  1. 예제 6.2.1의 무어 기계에서 상태 할당 A = 00, B = 01, C = 11로 두고 다음 상태 식과 출력 식을 구하여라.
    답

    \(Q_0^+ = x\), \(Q_1^+ = xQ_0\)이고 출력은 \(z = Q_1\)이다. 10은 쓰지 않는 부호이다.
