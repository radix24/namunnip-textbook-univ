유한상태기계 설계 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념FSM의 "상태"를 한 문장으로 정의하고, 동전 자판기에서 동전을 넣은 순서가 상태에 들어가지 않는 이유를 쓰세요. [06-01]

    힌트 1

    6.1.1.

    힌트 2

    50 + 100과 100 + 50은 다음 동작이 다른가요?

    풀이

    상태는 미래 동작을 정하는 데 필요한 과거의 요약입니다. 자판기의 미래 동작은 지금까지의 금액에만 의존하고 넣은 순서와는 무관하므로, 순서는 상태에 넣을 필요가 없습니다.

  2. 계산입력 x를 받아 1의 개수를 3으로 나눈 나머지가 0이면 z = 1인 무어 기계를 2진 부호화(S0 = 00, S1 = 01, S2 = 10)로 설계하세요. [06-01]

    힌트 1

    x = 1이면 S0 → S1 → S2 → S0.

    힌트 2

    11은 무관 조건.

    풀이

    \(Q_1^+\) = 1인 경우: S1에서 x = 1, S2에서 x = 0 → \(Q_1^+ = Q_0x + Q_1x'\). \(Q_0^+\) = 1: S0에서 x = 1, S1에서 x = 0 → \(Q_0^+ = Q_1'Q_0'x + Q_0x'\). 출력 \(z = Q_1'Q_0'\). (11을 무관으로 쓰면 \(Q_0^+ = Q_1'x Q_0' + Q_0x'\)는 \(Q_1'Q_0'x\)를 \(Q_1'x\)로 줄일 수 없음: 01·x = 1이면 11로 가므로. 그대로 둡니다.)

  3. 계산"110" 검출기(겹침 없음)의 무어 상태도를 그리고 상태 수를 세세요. [06-02]

    힌트 1

    상태: 없음, "1", "11", "110 완성".

    힌트 2

    "11"에서 1이 더 오면?

    풀이

    S0 —1→ S1 —1→ S2 —0→ S3(출력 1). S1 —0→ S0, S2 —1→ S2(여전히 끝이 "11"), S0 —0→ S0. S3에서 겹침이 없으므로 처음부터: S3 —1→ S1, S3 —0→ S0. 상태 4개.

  4. 계산문제 3을 밀리 기계로 하면 상태가 몇 개인가요? 출력이 붙는 화살표는? [06-02]

    힌트 1

    "완성" 상태가 필요 없습니다.

    힌트 2

    S2에서 0이 들어오는 순간.

    풀이

    3개(S0, S1, S2). S2 —0/1→ S0(겹침 없음이라 처음으로). 나머지 화살표는 출력 0.

  5. 판단학생의 상태도에서 상태 S3은 x = 0에 대한 화살표만 있고 x = 1에 대한 화살표가 없다. 합성하면 어떤 일이 생길 수 있나요? [06-01]

    힌트 1

    그 칸의 다음 상태는 누가 정하나요?

    힌트 2

    HDL의 case 문에서 빠진 경우.

    풀이

    명세에 없는 전이라 합성 도구가 무관 조건처럼 임의로 정하거나, HDL에서 대입이 빠지면 값을 유지하려고 래치를 만듭니다. 예상치 못한 상태로 가거나 S3에 갇힐 수 있습니다. 모든 상태에서 모든 입력의 전이를 적어야 합니다.

  6. 도전상태표가 다음과 같다(현재 → x=0일 때/x=1일 때 다음 상태, 출력). A → A/B, 0. B → C/B, 0. C → A/D, 0. D → C/B, 1. E → A/D, 0. 같은 상태를 찾아 합치세요. [06-01]

    힌트 1

    출력이 같고 다음 상태 쌍이 같은 두 상태는?

    힌트 2

    C와 E.

    풀이

    C와 E는 출력 0, 다음 상태 A/D로 똑같아 합칩니다(E → C). 그러면 남은 상태 A, B, C, D 중 더 합칠 것이 있는지 봅니다: B와 D는 다음 상태는 같지만 출력이 달라 합칠 수 없습니다. 최소 4상태.
