다수결 회로를 NAND 칩 하나로

예제 · AND-OR를 NAND-NAND로

먼저 예측

입력 셋 중 둘 이상이 1이면 1을 내는 다수결 회로 \(F = AB + BC + CA\)를 NAND만으로 만들면 게이트가 몇 개 들까?

생각해 본 뒤 열기

AND 3개 + 3입력 OR 1개 = 4개였으므로, NAND-NAND로 바꾸면 2입력 NAND 3개와 3입력 NAND 1개, 모두 4개이다.

문제

\(F = AB + BC + CA\)를 NAND만으로 구현하라. 3입력 NAND가 없고 2입력 NAND 4개가 든 칩(74HC00) 두 개만 있다면 어떻게 하는가?

전략

  1. 곱의 합이 이미 최소이므로 그대로 NAND-NAND로 바꾼다(2.2.3).
  2. 3입력 NAND가 없으면 \((XYZ)' = ((XY)''Z)'\)처럼 2입력 NAND와 NOT으로 쪼갠다.

풀이

  1. \(F = \big((AB)'(BC)'(CA)'\big)'\). 첫째 단 NAND 3개, 둘째 단 3입력 NAND 1개. 드 모르간 두 번
  2. 3입력 NAND를 2입력으로: \(P = (AB)'\), \(Q = (BC)'\), \(R = (CA)'\)일 때 \((PQR)' = \big((PQ)\,R\big)'\). \(PQ\)는 NAND 뒤 NOT으로 만든다: \(U = (PQ)'\), \(U' = (UU)'\). AND = NAND + NOT
  3. 마지막: \(F = (U'R)'\). 게이트: P, Q, R(3개) + U + U' + F = 6개. 칩 두 개(8게이트)로 충분하다. 세기

의미

NAND-NAND 변환은 게이트 수를 늘리지 않지만, 입력 수가 맞는 게이트가 없으면 쪼개는 비용이 든다. 실제 칩 설계 도구는 셀 라이브러리(어떤 게이트가 있는지)에 맞춰 이런 변환을 자동으로 합니다(기술 매핑, 전전32).

검산

A = 1, B = 1, C = 0: P = 0이라 PQ = 0, U = 1, U' = 0, F = (0·R)' = 1. 맞음(둘이 1). A = 1, B = 0, C = 0: P = Q = R = 1, U = 0, U' = 1, F = (1·1)' = 0. 맞음.

이해 확인

\(F = A'B + C\)를 2입력 NAND만으로 만드는 데 몇 개가 드나요(\(A'\), \(C'\)은 없음)?

답

\(F = ((A'B)'C')'\). \(A'\) 1, \((A'B)'\) 1, \(C'\) 1, 마지막 1. 4개.

확인바꾸는 규칙
