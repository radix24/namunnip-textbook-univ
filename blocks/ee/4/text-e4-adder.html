가산기와 감산기

본문

CPU의 산술 장치는 덧셈과 뺄셈을 같은 회로로 한다. 1.1절에서 뺄셈을 덧셈으로 바꾸는 2의 보수를 배웠으니, 이제 실제 게이트로 그 회로를 만들 차례이다. 1비트 덧셈 회로를 어떻게 만들고, 그것을 이어 여러 비트를 어떻게 더할까? 뺄셈으로 바꾸는 스위치는 무엇일까?

먼저 알아야 할 것2의 보수와 오버플로(1.1절), 카르노 맵(3.1절)을 쓴다.

4.1.1조합 회로 설계 절차

조합 회로는 출력이 지금 입력만으로 정해지는, 곧 기억이 없는 회로이다. 따라서 설계는 늘 같은 순서로 한다. 명세를 읽고 입력과 출력에 이름을 붙인 뒤 진리표를 만든다. 이어 출력마다 카르노 맵이나 불 대수로 최소화하고, 끝으로 게이트 회로로 그려 진리표로 검산한다.

4.1.2반가산기와 전가산기

1비트 두 개를 더하는 반가산기는 입력 A, B와 출력 합 S, 올림 C를 가진다. 진리표가 (S, C) 순으로 00이면 00, 01이면 10, 10이면 10, 11이면 01이므로 바로 다음을 얻는다.

\[ S = A \oplus B, \qquad C = AB \]

그런데 여러 자리를 더하려면 아래 자리에서 올라온 올림도 더해야 하므로, 입력이 셋인 전가산기가 필요하다. 입력 \(A, B, C_\text{in}\)의 진리표에서 S는 1의 개수가 홀수일 때 1(패리티)이고, \(C_\text{out}\)은 둘 이상이 1일 때 1(다수결)이다.

\[ S = A \oplus B \oplus C_\text{in}, \qquad C_\text{out} = AB + C_\text{in}(A \oplus B) \]

\(C_\text{out}\)의 카르노 맵 결과는 \(AB + AC_\text{in} + BC_\text{in}\)이다. 그런데 위처럼 \(A \oplus B\)를 S와 함께 쓰도록 바꾸면 반가산기 두 개와 OR 하나로 전가산기를 만들 수 있다. 두 식이 같은 까닭은 \(A \oplus B = AB' + A'B\)이므로 \(C_\text{in}(A \oplus B) + AB\)를 전개하고 흡수하면 \(AB + AC_\text{in} + BC_\text{in}\)이 되기 때문이다.

4.1.3리플 캐리 가산기

전가산기 n개를 이어 i번째의 \(C_\text{out}\)을 i+1번째의 \(C_\text{in}\)에 넣으면 n비트 가산기가 된다. 맨 아래 \(C_0\)은 덧셈이면 0, 뺄셈이면 1이다. 즉 손으로 하는 세로 덧셈과 똑같다. 올림이 아래에서 위로 한 자리씩 물결처럼 전해지므로 리플 캐리라 부른다.

하지만 단점은 느리다는 것이다. 최악의 경우인 \(0111\cdots1 + 1\)에서는 올림이 n자리를 모두 지나야 하므로 지연이 n에 비례하여 약 \(2n + 1\)단이 된다. 4.3절에서 이를 개선한다.

4.1.4가감산기

1.1절에서 \(A - B = A + B' + 1\)이었다. 제어 신호 M을 두고 각 B비트를 \(B_i \oplus M\)으로 바꿔 넣고 \(C_0 = M\)으로 하면, M = 0이면 \(A + B\), M = 1이면 \(A + B' + 1 = A - B\)이다. 다시 말해 XOR가 M이 1일 때만 뒤집는 조건부 NOT 역할을 하는 셈이다. 처음 질문의 답이 그림 1이다. 오버플로는 1.1절 정리 1.1.3의 \(V = C_n \oplus C_{n-1}\)을 XOR 하나로 만든다.

예제 4.1.1

4비트 가감산기에 A = 0110(6), B = 1001(−7), M = 1을 넣었다. 각 자리의 B 입력, 올림, 결과, 오버플로를 구하여라.

풀이. M = 1이라 B를 뒤집어 0110이 들어가고 \(C_0 = 1\)이다. 이제 \(0110 + 0110 + 1\)을 자리마다 보면, 0자리는 0 + 0 + 1 = 1(올림 0), 1자리는 1 + 1 + 0 = 0(올림 1), 2자리는 1 + 1 + 1 = 1(올림 1), 3자리는 0 + 0 + 1 = 1(올림 0)이다. 결과는 1101 = −3이고 \(C_4 = 0\), \(C_3 = 1\)이므로 V = 1이다. 참값 6 − (−7) = 13은 범위 −8에서 7 밖이므로 오버플로가 맞다.

흔한 실수전가산기의 \(C_\text{out} = AB + C_\text{in}(A \oplus B)\)에서 \(A \oplus B\) 대신 \(A + B\)를 써도 같은 값이 나온다. A = B = 1이면 AB가 이미 1이기 때문이다. 그러나 S와 공유할 수 있는 것은 \(A \oplus B\)이므로, 게이트 수를 줄이려면 XOR 쪽을 쓴다.
마무리

반가산기는 \(S = A \oplus B\), \(C = AB\)이고, 아래 올림까지 더하는 전가산기는 \(S = A \oplus B \oplus C_\text{in}\), \(C_\text{out} = AB + C_\text{in}(A \oplus B)\)이다. 전가산기 n개를 올림으로 이으면 지연이 n에 비례하는 리플 캐리 가산기가 되고, B 입력에 \(B_i \oplus M\)을, 맨 아래 올림에 M을 넣으면 같은 회로가 뺄셈까지 하는 가감산기가 된다. 오버플로는 \(V = C_n \oplus C_{n-1}\)로 판정한다.

4.1.5연습문제

기본

  1. 전가산기의 진리표 8줄을 쓰고 S와 \(C_\text{out}\)의 최소항을 적어라.
    답

    입력 순서를 A, B, \(C_\text{in}\)으로 하면 \(S = \Sigma m(1, 2, 4, 7)\), \(C_\text{out} = \Sigma m(3, 5, 6, 7)\)이다.

응용

  1. 반감산기(A − B, 출력 차 D와 빌림 \(B_o\))의 식을 구하여라.
    답

    \(D = A \oplus B\), \(B_o = A'B\)이다.

심화

  1. 두 2비트 수 \(A_1A_0\), \(B_1B_0\)의 크기 비교기(A > B이면 1)를 4변수 카르노 맵으로 설계하여라.
    답

    \(F = A_1B_1' + A_0B_1'B_0' + A_1A_0B_0'\)이다. 윗자리가 크거나, 윗자리가 같고 아랫자리가 큰 경우를 묶은 것이다.
