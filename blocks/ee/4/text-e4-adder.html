가산기와 감산기

본문
이 절에서 배울 것
  • 반가산기와 전가산기의 진리표와 식을 유도한다.
  • 전가산기 n개로 리플 캐리 가산기를, XOR를 더해 가감산기를 만든다.
  • 조합 회로 설계 절차(명세 → 진리표 → 최소화 → 회로)를 익힌다.
먼저 알아야 할 것
  • 2의 보수와 오버플로 (1.1절), 카르노 맵 (3.1절).

4.1.1조합 회로 설계 절차

조합 회로는 출력이 지금 입력만으로 정해지는 회로입니다(기억이 없음). 설계는 늘 같은 순서로 합니다.

  1. 명세를 읽고 입력과 출력에 이름을 붙인다.
  2. 진리표를 만든다.
  3. 출력마다 카르노 맵이나 불 대수로 최소화한다.
  4. 게이트 회로로 그리고, 진리표로 검산한다.

4.1.2반가산기와 전가산기

1비트 두 개를 더하는 반가산기: 입력 A, B, 출력 합 S, 올림 C. 진리표 00 → 00, 01 → 10, 10 → 10, 11 → 01(S, C 순)에서 바로

\[ S = A \oplus B, \qquad C = AB. \]

여러 자리를 더하려면 아래 자리에서 올라온 올림도 더해야 하므로 입력이 셋인 전가산기가 필요합니다. 입력 \(A, B, C_\text{in}\)의 진리표에서 S는 1의 개수가 홀수일 때 1(패리티), \(C_\text{out}\)은 둘 이상이 1일 때 1(다수결)입니다.

\[ S = A \oplus B \oplus C_\text{in}, \qquad C_\text{out} = AB + C_\text{in}(A \oplus B). \]

\(C_\text{out}\)의 카르노 맵 결과는 \(AB + AC_\text{in} + BC_\text{in}\)인데, 위처럼 \(A \oplus B\)를 S와 함께 쓰도록 바꾸면 반가산기 두 개 + OR 하나로 전가산기를 만들 수 있습니다. 두 식이 같은 이유: \(A \oplus B = AB' + A'B\)이므로 \(C_\text{in}(A \oplus B) + AB\)를 전개하고 흡수하면 \(AB + AC_\text{in} + BC_\text{in}\)이 됩니다.

4.1.3리플 캐리 가산기

전가산기 n개를 이어 i번째의 \(C_\text{out}\)을 i+1번째의 \(C_\text{in}\)에 넣으면 n비트 가산기가 됩니다. 맨 아래 \(C_0\)은 0(덧셈) 또는 1(뺄셈). 손으로 하는 세로 덧셈과 똑같습니다. 올림이 아래에서 위로 한 자리씩 물결처럼 전해져 리플 캐리라 부릅니다. 단점은 느리다는 것입니다. 최악의 경우(\(0111\cdots1 + 1\)) 올림이 n자리를 모두 지나야 하므로 지연이 n에 비례합니다(디지털실험의 가산기 카드에서 약 \(2n + 1\)단). 4.3절에서 이를 개선합니다.

4.1.4가감산기

1.1절에서 \(A - B = A + B' + 1\)이었습니다. 제어 신호 M을 두고 각 B비트를 \(B_i \oplus M\)으로 바꿔 넣고 \(C_0 = M\)으로 하면, M = 0이면 \(A + B\), M = 1이면 \(A + B' + 1 = A - B\)입니다. XOR가 "M이 1일 때만 뒤집는" 조건부 NOT 역할을 합니다. 오버플로는 \(V = C_n \oplus C_{n-1}\)(1.1절 정리 1.1.3)을 XOR 하나로 만듭니다.

예제 4.1.1

4비트 가감산기에 A = 0110(6), B = 1001(−7), M = 1을 넣었다. 각 자리의 B 입력, 올림, 결과, 오버플로를 구하여라.

풀이. M = 1이라 B를 뒤집어 0110, \(C_0 = 1\). \(0110 + 0110 + 1\): 0자리 0 + 0 + 1 = 1(올림 0), 1자리 1 + 1 + 0 = 0(올림 1), 2자리 1 + 1 + 1 = 1(올림 1), 3자리 0 + 0 + 1 = 1(올림 0). 결과 1101 = −3, \(C_4 = 0\), \(C_3 = 1\), V = 1. 참값 6 − (−7) = 13은 범위(−8 ~ 7) 밖이라 오버플로가 맞습니다.

주의전가산기의 \(C_\text{out} = AB + C_\text{in}(A \oplus B)\)에서 \(A \oplus B\) 대신 \(A + B\)를 써도 같은 값이 나옵니다(A = B = 1이면 AB가 이미 1). 그러나 S와 공유할 수 있는 것은 \(A \oplus B\)이므로, 게이트 수를 줄이려면 XOR 쪽을 씁니다.
요약
  1. 반가산기 \(S = A \oplus B\), \(C = AB\). 전가산기 \(S = A \oplus B \oplus C_\text{in}\), \(C_\text{out} = AB + C_\text{in}(A \oplus B)\).
  2. 전가산기 n개 = 리플 캐리 가산기. 지연은 n에 비례.
  3. 가감산기: \(B_i \oplus M\), \(C_0 = M\). 오버플로 \(V = C_n \oplus C_{n-1}\).

4.1.5연습문제

기본

  1. 전가산기의 진리표 8줄을 쓰고 S와 \(C_\text{out}\)의 최소항을 적어라.
    답

    S = Σm(1, 2, 4, 7), \(C_\text{out}\) = Σm(3, 5, 6, 7) (입력 순서 A, B, \(C_\text{in}\)).

응용

  1. 반감산기(A − B, 출력 차 D와 빌림 \(B_o\))의 식을 구하여라.
    답

    \(D = A \oplus B\), \(B_o = A'B\).

심화

  1. 두 2비트 수 \(A_1A_0\), \(B_1B_0\)의 크기 비교기(A > B이면 1)를 4변수 카르노 맵으로 설계하여라.
    답

    \(F = A_1B_1' + A_0B_1'B_0' + A_1A_0B_0'\). (윗자리가 크거나, 윗자리가 같고 아랫자리가 큰 경우)
