올리기·내리기를 고르는 카운터

예제 · 입력이 있는 순차 회로 설계

먼저 예측

입력 U가 1이면 1씩 올리고 0이면 1씩 내리는 2비트 카운터에서, \(Q_0\)의 다음 값은 U에 따라 달라질까요?

생각해 본 뒤 열기

달라지지 않습니다. 올리든 내리든 맨 아래 비트는 매번 뒤집힙니다. 달라지는 것은 \(Q_1\)이 뒤집히는 조건입니다.

문제

입력 U(1: 올림, 0: 내림)가 있는 2비트 동기식 카운터 \(Q_1Q_0\)을 D 플립플롭으로 설계하여라.

문제 해결 전략

  1. 입력 U도 다음 상태를 정하므로, 상태표의 입력 열에 U를 넣는다(현재 상태 2비트 + U 1비트 = 8줄).
  2. \(D_1\), \(D_0\)을 3변수 카르노 맵으로 최소화한다.

풀이

  1. 상태표(U, \(Q_1Q_0\) → 다음): U = 1: 00 → 01, 01 → 10, 10 → 11, 11 → 00. U = 0: 00 → 11, 01 → 00, 10 → 01, 11 → 10. 명세
  2. \(D_0\): 다음 \(Q_0\)이 늘 현재 \(Q_0\)의 반대 → \(D_0 = Q_0'\). 상태표 비교
  3. \(D_1\): 올림이면 \(Q_0 = 1\)일 때, 내림이면 \(Q_0 = 0\)일 때 뒤집힌다. 뒤집는 조건 \(T_1 = UQ_0 + U'Q_0' = U \odot Q_0\)(XNOR). 따라서 \(D_1 = Q_1 \oplus (U \odot Q_0)\). 5.2.2의 "아래 비트" 규칙
  4. 카르노 맵으로 확인: 변수 순서 \(U, Q_1, Q_0\)으로 다음 \(Q_1\)이 1인 줄은 000, 011, 101, 110, 곧 \(D_1 = \Sigma m(0, 3, 5, 6)\). 1의 개수가 짝수인 줄이라 바둑판 모양이고 \(D_1 = (U \oplus Q_1 \oplus Q_0)'\)인데, 이는 \(Q_1 \oplus (U \odot Q_0)\)과 같다. 3.1절

의미

내릴 때는 "아래 비트가 모두 0이면 뒤집힘"(빌림 조건)입니다. 올림과 내림이 같은 구조에 XNOR 하나 차이라는 것이 가감산기(4.1절)와 닮았습니다. 엘리베이터 층 표시, 회전 손잡이(인코더)의 위치 세기가 이런 카운터입니다.

검산

U = 0, \(Q_1Q_0 = 00\): \(D_0 = 1\), \(T_1 = 0 \odot 0 = 1\), \(D_1 = 0 \oplus 1 = 1\) → 11. 맞음(0에서 내리면 3). U = 1, 01: \(D_0 = 0\), \(T_1 = 1\), \(D_1 = 1\) → 10. 맞음.
