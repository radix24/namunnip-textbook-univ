최소항·최대항과 표준형

본문

진리표가 주어졌을 때 그 함수를 식으로 적는 방법은 무수히 많다. 그런데 누가 적어도 똑같이 나오는, 진리표에서 기계적으로 바로 얻는 식이 있다면 비교와 검산이 쉬워질 것이다. 그런 표준 식은 어떻게 만들까?

먼저 알아야 할 것불 대수(2.1절)를 쓴다.

2.3.1두 표준형

3변수 함수의 진리표에서 출력이 1인 줄마다 그 줄에서만 1이 되는 곱, 곧 최소항을 만들어 더하면 SOP 표준형이다. 예를 들어 줄 101의 최소항은 \(A\bar BC\)이다. 반대로 출력이 0인 줄마다 그 줄에서만 0이 되는 합, 곧 최대항을 곱하면 POS 표준형이다. 줄 000의 최대항은 \(A + B + C\)이다. 처음 질문의 답이 이 두 표준형이며, 1인 줄 번호가 m이면 0인 줄 번호는 그 나머지이다.

최소항이 왜 한 줄에서만 1일까? 줄 101에서는 A = 1, B = 0, C = 1이므로 그대로 쓴 A와 C, 뒤집어 쓴 \(\bar B\)가 모두 1이 되어 곱이 1이다. 다른 줄에서는 세 인수 가운데 적어도 하나가 0이 되므로 곱이 0이다. 그러므로 1인 줄의 최소항을 모두 더하면 바로 그 줄들에서만 1인 함수, 곧 원래 함수가 된다. 최대항은 이를 뒤집은 것이다. 줄 000에서는 A, B, C가 모두 0이어서 \(A + B + C\)가 0이고, 다른 줄에서는 어느 하나가 1이어서 합이 1이다. 따라서 0인 줄의 최대항을 모두 곱하면 그 줄들에서만 0인 함수가 된다.

번호를 쓰는 약속도 알아 두자. 줄 번호는 ABC를 2진수로 읽은 값이어서, 3변수 함수는 \(m_0\)에서 \(m_7\)까지의 최소항을 가진다. 드 모르간 법칙으로 \(m_k' = M_k\)이므로 같은 번호의 최소항과 최대항은 서로의 NOT이다.

예제 2.3.1

\(F = \Sigma m(1, 3, 5, 6, 7)\)을 \(\Pi M\)으로 쓰고, SOP를 간단히 하여라.

풀이. 0인 줄은 0, 2, 4이므로 \(F = \Pi M(0, 2, 4) = (A + B + C)(A + \bar B + C)(\bar A + B + C)\)이다. 최소항 1, 3, 5, 7은 모두 C = 1이어서 \(C\)로 묶이고, 6과 7은 \(AB\)로 묶이므로 \(F = C + AB\)이다. POS 쪽도 \((A + C)(B + C) = C + AB\)(분배 법칙)로 같다.

흔한 오해"최대항은 0인 변수에 바(bar)를 붙인다"는 틀리다. 최대항에서는 그 줄에서 합이 0이 되도록 1인 변수에 바를 붙인다. 또 표준형이 곧 최소 회로라고 생각하기 쉬운데, 표준형은 간단히 하기 전의 출발점일 뿐이다.
마무리

SOP 표준형은 진리표에서 1인 줄의 최소항을 더한 것이고, POS 표준형은 0인 줄의 최대항을 곱한 것이어서, 진리표만 있으면 누구나 기계적으로 같은 식을 얻는다. \(\Sigma m\)의 나머지 번호가 \(\Pi M\)이며, 예를 들어 \(\Sigma m(1, 3, 5, 6, 7)\)은 간단히 하면 \(C + AB\)이다.

2.3.2연습문제

기본

  1. 2변수 XOR의 \(\Sigma m\) 표기는?
    답

    \(\Sigma m(1, 2)\)이다.

응용

  1. \(\Pi M(0, 7)\)인 3변수 함수의 \(\Sigma m\)은?
    답

    \(\Sigma m(1, 2, 3, 4, 5, 6)\)이다.

심화

  1. 줄 101의 최대항은?
    답

    \(\bar A + B + \bar C\)이다.
