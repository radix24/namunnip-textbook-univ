최소항·최대항과 표준형

본문
이 절에서 배울 것
  • 진리표에서 최소항의 합(SOP)과 최대항의 곱(POS)을 쓴다.
  • Σm과 ΠM 표기를 서로 바꾼다.
  • 표준형을 간단히 해 같은 함수임을 확인한다.
먼저 알아야 할 것
  • Boolean 대수 (2.1절).

2.3.1두 표준형

3변수 함수의 진리표에서 출력이 1인 줄마다 그 줄에서만 1이 되는 곱(최소항, 예: 101 → \(A\bar BC\))을 만들어 더하면 SOP, 출력이 0인 줄마다 그 줄에서만 0이 되는 합(최대항, 예: 000 → \(A + B + C\))을 곱하면 POS입니다. 1인 줄 번호가 m이면 0인 줄 번호는 그 나머지입니다.

예제 2.3.1

\(F = \Sigma m(1, 3, 5, 6, 7)\)을 ΠM으로 쓰고, SOP를 간단히 하라.

풀이. 0인 줄은 0, 2, 4 → \(F = \Pi M(0, 2, 4) = (A + B + C)(A + \bar B + C)(\bar A + B + C)\). 최소항 1, 3, 5, 7은 모두 C = 1이라 \(C\)로, 6, 7은 \(AB\)로 묶여 \(F = C + AB\). POS 쪽도 \((A + C)(B + C) = C + AB\)(분배)로 같습니다.

흔한 오해(1) "최대항은 0인 변수에 바(bar)를 붙인다": 최대항에서는 1인 변수에 바를 붙입니다(그 줄에서 합이 0이 되도록). (2) "표준형이 곧 최소 회로": 표준형은 간단히 하기 전의 출발점입니다.
요약
  1. SOP: 1인 줄의 최소항 합, POS: 0인 줄의 최대항 곱.
  2. Σm의 나머지 번호가 ΠM.
  3. 예: Σm(1, 3, 5, 6, 7) = C + AB.

2.3.2연습문제

기본

  1. 2변수 XOR의 Σm 표기는?
    답

    Σm(1, 2).

응용

  1. ΠM(0, 7)인 3변수 함수의 Σm은?
    답

    Σm(1, 2, 3, 4, 5, 6).

심화

  1. 줄 101의 최대항은?
    답

    \(\bar A + B + \bar C\).
