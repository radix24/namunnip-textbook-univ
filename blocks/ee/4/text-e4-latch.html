래치와 플립플롭

본문
이 절에서 배울 것
  • 되먹임으로 1비트를 기억하는 SR 래치의 동작을 진리표와 타이밍 도표로 그린다.
  • D 래치(수준 감지)와 D 플립플롭(모서리 감지)의 차이를 안다.
  • JK, T 플립플롭의 특성 방정식을 쓴다.
먼저 알아야 할 것
  • NOR·NAND 게이트 (2.2절), 게이트 전파 지연 (4.3절).

5.1.1기억은 되먹임에서

4단원의 조합 회로는 입력이 사라지면 출력도 사라집니다. 계산기가 앞의 결과를 기억하고, 컴퓨터가 다음 명령을 기억하려면 출력이 스스로를 유지하는 회로가 필요합니다. 방법은 출력을 입력으로 되돌리는 되먹임입니다. 가장 단순한 예는 NOT 두 개를 고리로 이은 것으로, 한쪽이 1이면 다른 쪽이 0이 되어 서로를 계속 붙잡습니다. 다만 이 고리는 값을 바꿀 입력이 없습니다.

5.1.2SR 래치

NOR 두 개를 교차로 이으면(각 NOR의 출력이 다른 NOR의 입력) 입력 S(set)와 R(reset)이 생깁니다. 출력 Q와 \(Q'\)(보통은 서로 반대).

S = 1, R = 0: Q = 1로 놓는다(set).

S = 0, R = 1: Q = 0으로 놓는다(reset).

S = 0, R = 0: 이전 Q를 그대로 유지한다(기억).

S = 1, R = 1: 두 출력이 모두 0이 되어 \(Q'\)이 Q의 반대가 아니게 되고, 둘을 동시에 0으로 내리면 어느 쪽이 될지 모른다(금지).

"기억" 줄을 확인합니다. S = R = 0이면 각 NOR는 NOT처럼 동작해(\((0 + x)' = x'\)) NOT 두 개의 고리가 되고, 마지막 값을 붙잡습니다. 같은 입력(00)에서 출력이 과거에 따라 다르다는 것, 이것이 순차 회로의 정의입니다.

5.1.3D 래치: 클록으로 문을 연다

금지 입력을 없애고 "언제 기억할지"를 정하려고, D(데이터)와 C(클록, enable)를 둡니다. \(S = DC\), \(R = D'C\)로 SR 래치를 구동하면

C = 1: Q = D. 출력이 입력을 그대로 따라간다(투명).

C = 0: Q 유지. 문이 닫힌다.

S와 R이 동시에 1이 될 수 없으니 금지 상태도 없습니다. 그런데 C = 1인 동안 내내 투명하다는 것이 문제입니다. 여러 래치를 이어 시프트 레지스터를 만들면, 클록이 1인 동안 데이터가 여러 단을 한꺼번에 통과해 버립니다(경주).

5.1.4D 플립플롭: 모서리에서만

정의 5.1.1 (상승 모서리 D 플립플롭)

클록이 0에서 1로 바뀌는 순간(상승 모서리)의 D 값을 Q에 저장하고, 그 밖의 모든 때에는 Q를 유지하는 기억 소자. 특성 방정식 \(Q^+ = D\)(\(Q^+\)는 다음 모서리 뒤의 Q).

구현은 D 래치 두 개를 앞뒤로 이은 주종(master-slave) 구조입니다. 앞 래치는 클록이 0일 때 투명해 D를 받아 두고, 클록이 1로 오르면 닫히는 동시에 뒤 래치가 열려 그 값을 출력으로 내보냅니다. 두 래치가 동시에 열리는 때가 없으므로 출력은 상승 모서리에서만 바뀝니다. 그래서 플립플롭 여러 개를 같은 클록으로 이어도 데이터가 한 클록에 정확히 한 단씩만 움직입니다.

예제 5.1.2

클록이 2칸마다 바뀌고(상승 모서리 시각 1, 5, 9, …에서 클록이 1로 오른다고 하자), D가 시각 0~3: 0, 3~7: 1, 7~8: 0, 8~12: 1이다. D 래치(클록 1에서 투명)와 D 플립플롭의 Q를 구하여라. (이 절의 래치·플립플롭 카드로 같은 실험을 할 수 있다.)

풀이. 클록이 1인 구간은 [1, 3), [5, 7), [9, 11). 래치: [1, 3)에서 D = 0을 따라 0, [5, 7)에서 D = 1, 7 이후 닫혀 1 유지, [9, 11)에서 D = 1. 플립플롭: 시각 1에 D = 0, 시각 5에 D = 1 저장, 시각 9에 D = 1. 차이는 D가 7~8에서 잠깐 0이 된 것인데, 그때 클록이 0이라 둘 다 영향을 받지 않았습니다. 만약 그 0이 클록 1 구간 안에 있었다면 래치는 따라 내려갔다 올라오지만 플립플롭은 모서리 순간 값만 봅니다.

5.1.5JK와 T 플립플롭

JK: SR에서 금지 입력 11을 "뒤집기"로 바꾼 것. \(Q^+ = JQ' + K'Q\).

T(toggle): T = 1이면 뒤집고 0이면 유지. \(Q^+ = T \oplus Q\). 카운터(5.2절)에 편리하다.

오늘날 칩 설계에서는 D 플립플롭 하나만 쓰고, JK나 T의 동작은 D 앞의 조합 논리로 만듭니다(예: \(D = T \oplus Q\)).

주의"래치"와 "플립플롭"을 섞어 쓰는 책도 있지만, 수준 감지(레벨이 1인 동안 투명)와 모서리 감지(순간만)는 타이밍이 완전히 다릅니다. HDL에서 실수로 래치가 만들어지는 경우(7.1절)를 피하려면 이 차이를 분명히 알아야 합니다.
요약
  1. 되먹임이 기억을 만든다. SR 래치: set, reset, 유지, 금지(11).
  2. D 래치는 클록 1인 동안 투명, D 플립플롭은 상승 모서리 순간의 D만 저장(\(Q^+ = D\)).
  3. 주종 구조가 모서리 동작을 만든다. JK \(Q^+ = JQ' + K'Q\), T \(Q^+ = T \oplus Q\).

5.1.6연습문제

기본

  1. NAND 두 개로 만든 SR 래치는 입력이 \(S'\), \(R'\)(낮을 때 동작)이다. 금지 입력은 무엇인가?
    답

    \(S' = R' = 0\)(두 출력이 모두 1).

응용

  1. JK 플립플롭의 특성표(J, K, Q → \(Q^+\))를 쓰고 특성 방정식을 카르노 맵으로 확인하여라.
    답

    00 유지, 01 리셋, 10 셋, 11 뒤집기. \(Q^+ = \Sigma m(1, 4, 5, 6)\)(J K Q 순) = \(JQ' + K'Q\).

심화

  1. D 플립플롭과 XOR 하나로 T 플립플롭을, D 플립플롭과 MUX로 "적재 가능(load enable)" 레지스터 1비트를 만들어라.
    답

    T: \(D = T \oplus Q\). 적재: \(D = \text{LD}\cdot X + \text{LD}'\cdot Q\)(2:1 MUX, LD = 1일 때만 새 값).
