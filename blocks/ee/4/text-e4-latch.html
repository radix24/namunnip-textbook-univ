래치와 플립플롭

본문

4단원의 회로는 입력이 사라지면 출력도 사라진다. 그런데 계산기는 앞의 결과를 기억하고 컴퓨터는 다음 명령을 기억한다. 게이트만으로 1비트를 붙잡아 두는 회로를 만들 수 있을까? 그리고 그 값을 언제 바꾸게 할지는 어떻게 정할까?

먼저 알아야 할 것NOR, NAND 게이트(2.2절), 게이트 전파 지연(4.3절)을 쓴다.

5.1.1기억은 되먹임에서

출력이 스스로를 유지하게 하는 방법은 출력을 입력으로 되돌리는 되먹임이다. 가장 단순한 예는 NOT 두 개를 고리로 이은 것으로, 한쪽이 1이면 다른 쪽이 0이 되어 서로를 계속 붙잡는다. 처음 질문의 첫째 답이 이것이다. 다만 이 고리에는 값을 바꿀 입력이 없다.

5.1.2SR 래치

NOR 두 개를 교차로 이어 각 NOR의 출력을 다른 NOR의 입력으로 넣으면, 입력 S(set)와 R(reset), 그리고 보통은 서로 반대인 출력 Q와 \(Q'\)이 생긴다. S = 1, R = 0이면 Q = 1로 놓고, S = 0, R = 1이면 Q = 0으로 놓는다. S = R = 0이면 이전 Q를 그대로 유지하여 기억한다. 그런데 S = R = 1이면 두 출력이 모두 0이 되어 \(Q'\)이 Q의 반대가 아니게 되고, 둘을 동시에 0으로 내리면 어느 쪽이 될지 모르므로 이 입력은 금지한다.

기억하는 경우를 확인해 보자. S = R = 0이면 각 NOR는 \((0 + x)' = x'\)으로 NOT처럼 동작하므로 NOT 두 개의 고리가 되어 마지막 값을 붙잡는다. 같은 입력 00에서 출력이 과거에 따라 다르다는 것, 이것이 순차 회로의 정의이다.

5.1.3D 래치, 클록으로 문을 연다

금지 입력을 없애고 언제 기억할지를 정하려고 D(데이터)와 C(클록, enable)를 둔다. \(S = DC\), \(R = D'C\)로 SR 래치를 구동하면, C = 1일 때 Q = D가 되어 출력이 입력을 그대로 따라가고(투명), C = 0일 때 Q를 유지하여 문이 닫힌다. S와 R이 동시에 1이 될 수 없으니 금지 상태도 없다.

하지만 C = 1인 동안 내내 투명하다는 것이 문제이다. 여러 래치를 이어 시프트 레지스터를 만들면 클록이 1인 동안 데이터가 여러 단을 한꺼번에 통과해 버리는데, 이를 경주라 한다.

5.1.4D 플립플롭, 모서리에서만

정의 5.1.1 (상승 모서리 D 플립플롭)

클록이 0에서 1로 바뀌는 순간(상승 모서리)의 D 값을 Q에 저장하고, 그 밖의 모든 때에는 Q를 유지하는 기억 소자이다. 특성 방정식은 \(Q^+ = D\)이며, \(Q^+\)는 다음 모서리 뒤의 Q이다.

구현은 D 래치 두 개를 앞뒤로 이은 주종(master-slave) 구조이다. 앞 래치는 클록이 0일 때 투명해 D를 받아 두고, 클록이 1로 오르면 닫히는 동시에 뒤 래치가 열려 그 값을 출력으로 내보낸다. 두 래치가 동시에 열리는 때가 없으므로 출력은 상승 모서리에서만 바뀐다. 그래서 플립플롭 여러 개를 같은 클록으로 이어도 데이터가 한 클록에 정확히 한 단씩만 움직인다. 처음 질문의 둘째 답이 이것이다.

예제 5.1.2

클록이 시각 1, 5, 9에서 0에서 1로 오르고 2칸 뒤에 내려간다. D는 시각 0에서 3까지 0, 3에서 7까지 1, 7에서 8까지 0, 8에서 12까지 1이다. D 래치(클록 1에서 투명)와 D 플립플롭의 Q를 구하여라.

풀이. 클록이 1인 구간은 [1, 3), [5, 7), [9, 11)이다. 래치는 [1, 3)에서 D = 0을 따라 0이고, [5, 7)에서 D = 1을 따라 1이며, 7 이후 닫혀 1을 유지하고, [9, 11)에서도 D = 1이다. 플립플롭은 시각 1에 D = 0, 시각 5에 D = 1, 시각 9에 D = 1을 저장한다. D가 7에서 8 사이에 잠깐 0이 되었지만 그 때 클록이 0이라 둘 다 영향을 받지 않았다(그림 1). 만약 그 0이 클록 1 구간 안에 있었다면 래치는 따라 내려갔다 올라오지만 플립플롭은 모서리 순간의 값만 본다.

5.1.5JK와 T 플립플롭

JK 플립플롭은 SR에서 금지 입력 11을 뒤집기로 바꾼 것으로, \(Q^+ = JQ' + K'Q\)이다. T(toggle) 플립플롭은 T = 1이면 뒤집고 0이면 유지하여 \(Q^+ = T \oplus Q\)이며, 카운터(5.2절)에 편리하다. 한편 오늘날 칩 설계에서는 D 플립플롭 하나만 쓰고, JK나 T의 동작은 \(D = T \oplus Q\)처럼 D 앞의 조합 논리로 만든다.

흔한 오해래치와 플립플롭을 섞어 쓰는 책도 있지만, 레벨이 1인 동안 투명한 수준 감지와 순간만 보는 모서리 감지는 타이밍이 완전히 다르다. HDL에서 실수로 래치가 만들어지는 경우(7.1절)를 피하려면 이 차이를 분명히 알아야 한다.
마무리

되먹임이 기억을 만들며, NOR 두 개의 SR 래치는 set, reset, 유지, 금지(11)의 네 입력을 가진다. D 래치는 클록이 1인 동안 투명하고, 주종 구조의 D 플립플롭은 상승 모서리 순간의 D만 저장하므로(\(Q^+ = D\)) 같은 클록으로 이어도 데이터가 한 단씩만 움직인다. JK는 \(Q^+ = JQ' + K'Q\), T는 \(Q^+ = T \oplus Q\)이며, 실제 설계에서는 D 플립플롭 앞의 논리로 만든다.

5.1.6연습문제

기본

  1. NAND 두 개로 만든 SR 래치는 입력이 낮을 때 동작하는 \(S'\), \(R'\)이다. 금지 입력은 무엇인가?
    답

    \(S' = R' = 0\)으로, 두 출력이 모두 1이 된다.

응용

  1. JK 플립플롭의 특성표(J, K, Q에서 \(Q^+\))를 쓰고 특성 방정식을 카르노 맵으로 확인하여라.
    답

    JK가 00이면 유지, 01이면 리셋, 10이면 셋, 11이면 뒤집기이다. J K Q 순으로 \(Q^+ = \Sigma m(1, 4, 5, 6) = JQ' + K'Q\)이다.

심화

  1. D 플립플롭과 XOR 하나로 T 플립플롭을, D 플립플롭과 MUX로 적재 가능(load enable) 레지스터 1비트를 만들어라.
    답

    T 플립플롭은 \(D = T \oplus Q\)이다. 적재 가능 레지스터는 2:1 MUX로 \(D = \text{LD}\cdot X + \text{LD}'\cdot Q\)를 넣어 LD = 1일 때만 새 값을 받는다.
