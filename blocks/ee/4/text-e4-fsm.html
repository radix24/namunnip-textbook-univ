유한상태기계 설계

본문

150원짜리 음료 자판기는 50원과 100원 동전을 받는다. 동전이 하나씩 들어올 때마다 지금까지 얼마가 들어왔는지 기억해야 음료를 내줄 때를 안다. 이렇게 입력에 따라 다음 행동이 달라지는 회로를, 카운터를 설계하던 방법으로 체계적으로 만들 수 있을까?

먼저 알아야 할 것동기식 카운터 설계(5.2절)를 쓴다.

6.1.1유한상태기계

5.2절의 카운터는 입력 없이, 또는 방향 입력 하나로 정해진 순서를 돌았다. 그러나 자판기, 신호등, 통신 규약 처리기는 입력에 따라 다음 행동이 달라진다. 이런 회로를 지금 어떤 상황인가(상태)와 입력이 오면 어디로 가는가(전이)로 설명한 것이 유한상태기계(FSM)이다.

상태는 미래 동작을 정하는 데 필요한 과거의 요약이며, 그 수가 유한하다. 전이는 클록 모서리에서 현재 상태와 입력이 다음 상태를 정하는 규칙이다. 출력은 현재 상태만으로 정해지거나(무어), 현재 상태와 입력으로 정해진다(밀리, 6.2절).

6.1.2설계 절차

설계는 이렇게 한다. 먼저 명세를 읽고 기억해야 할 것을 정해 상태로 삼는다. 이어 상태를 원으로, 전이를 입력 조건을 적은 화살표로 그리고, 출력은 원 안(무어)이나 화살표 위(밀리)에 적은 상태도를 그린다. 그 다음 상태마다 2진 부호를 정하는 상태 할당을 하고, 상태표에서 다음 상태 식과 출력 식을 카르노 맵으로 얻는다. 끝으로 플립플롭과 게이트로 그리고, 쓰지 않는 부호의 전이를 점검한다. 처음 질문의 답이 이 절차이다.

예제 6.1.1 (동전 자판기)

음료가 150원이고 50원(N)과 100원(D) 동전만 받는다. 거스름돈은 주지 않고, 150원 이상이 되면 음료를 내놓고(출력 V = 1) 처음으로 돌아간다. 한 클록에 동전은 최대 하나 들어온다. FSM을 설계하여라.

풀이. 기억할 것은 지금까지 넣은 금액이므로 상태는 S0(0원), S50(50원), S100(100원), S150(150원 이상, 음료)이다. S0에서는 N이면 S50, D면 S100으로 가고, S50에서는 N이면 S100, D면 S150으로 간다. S100에서는 N이든 D든 S150으로 가는데, D면 200원이지만 거스름이 없다. 동전이 없으면 모두 제자리이다. S150은 음료를 내놓고 다음 클록에 입력과 상관없이 S0으로 가며, 출력 V = 1은 S150에서만 나온다(무어, 그림 1).

상태 할당을 S0 = 00, S50 = 01, S100 = 10, S150 = 11로 하자. 입력은 N과 D 두 비트이고 동시에 1은 없다. 상태표에서 \(Q_1^+ = 1\)인 경우는 S0에서 D, S50에서 N 또는 D, S100에서 모든 입력이다. 따라서 \(Q_1^+ = Q_1'Q_0'D + Q_1'Q_0(N + D) + Q_1Q_0'\)이고, 앞 항과 끝 항을 \(Q_0'(Q_1 + Q_1'D) = Q_0'(Q_1 + D)\)로 합치면 다음과 같다.

\[ Q_1^+ = Q_1Q_0' + Q_0'D + Q_1'Q_0(N + D) \]

한편 \(Q_0^+ = 1\)인 경우는 S0에서 N, S50에서 동전 없음 또는 D(곧 N이 아님), S100에서 N 또는 D이다.

\[ Q_0^+ = Q_1'Q_0'N + Q_1'Q_0N' + Q_1Q_0'(N + D) \]

S150(11)에서는 두 식이 모두 0이 되어 다음 상태가 00이고, 출력은 \(V = Q_1Q_0\)이다. 검산해 보자. S50(\(Q_1Q_0 = 01\))에서 D가 들어오면(N = 0, D = 1) \(Q_1^+ = 0 + 0 + 1\cdot1 = 1\), \(Q_0^+ = 0 + 1\cdot1 + 0 = 1\)이므로 다음 상태가 11(S150)으로 상태표와 같다. 이렇게 상태마다 입력을 하나씩 넣어 보는 것이 가장 확실한 검산이다.

식이 복잡해 보이지만 실제 설계는 HDL로 상태표를 그대로 적고 합성 도구가 최소화하게 한다(7.1절). 그러므로 손 설계에서 중요한 것은 상태와 전이를 빠짐없이 정하는 일이다.

6.1.3상태 할당

2진 부호화는 상태 k개에 플립플롭 \(\lceil\log_2k\rceil\)개를 써서 플립플롭이 가장 적다. 원-핫 부호화는 상태마다 플립플롭을 하나씩 두고 늘 하나만 1로 하여, 플립플롭은 많지만 다음 상태 논리가 단순하고 빠르다. 플립플롭이 넉넉한 FPGA에서 흔히 쓴다. 그레이 부호화는 자주 오가는 상태끼리 한 비트만 다르게 해서, 전이 때 바뀌는 비트가 적어 글리치와 전력이 준다.

6.1.4상태 최소화

두 상태가 모든 입력에 대해 같은 출력을 내고 같은, 또는 서로 동치인 다음 상태로 간다면 하나로 합칠 수 있다. 처음 상태도를 그릴 때 생긴 쓸데없는 상태를 이렇게 지우면 플립플롭과 논리가 준다. 예를 들어 순서 검출기를 처음 그릴 때 "1을 하나 받음" 상태가 두 군데 따로 생겼다면, 이후 동작이 같으므로 합친다(6.3절).

흔한 실수모든 상태에서 모든 입력 조합의 전이를 정했는지 확인하자. 화살표가 빠진 칸은 회로에서 합성 도구가 임의로 고른 값으로 정해져 버리므로, 예상치 못한 상태로 가거나 멈춘다.
마무리

유한상태기계는 미래 동작에 필요한 과거의 요약을 상태로 삼고, 상태도로 모든 상태와 입력의 전이와 출력을 정한 회로이다. 명세에서 상태도, 상태 할당, 상태표, 카르노 맵 식, 회로로 나아가고 쓰지 않는 부호를 점검하는 절차를 밟으면 카운터처럼 체계적으로 설계된다. 할당은 플립플롭이 적은 2진, 논리가 단순한 원-핫, 전이 비트가 적은 그레이 가운데 고르고, 같은 동작의 상태는 합친다.

6.1.5연습문제

기본

  1. 상태가 10개인 FSM을 2진 부호화와 원-핫 부호화로 만들 때 플립플롭은 각각 몇 개인가?
    답

    각각 4개와 10개이다.

응용

  1. 버튼 입력 B가 1이 될 때마다 LED를 켜고 끄는(토글) FSM을 그려라. B를 계속 누르고 있어도 한 번만 바뀌어야 한다.
    힌트

    LED 상태 2개와 버튼이 눌린 채인지 2개를 곱해 상태 4개이다.

    답

    OFF_떼어짐에서 B면 ON_눌림, 거기서 B'이면 ON_떼어짐, 거기서 B면 OFF_눌림, 거기서 B'이면 OFF_떼어짐으로 간다. 눌린 채(B)면 같은 상태에 머문다. LED 출력은 ON 상태들에서 1이다.

심화

  1. 예제 6.1.1의 자판기를 거스름돈 50원(출력 C)을 주도록 바꾸어라. S100에서 D가 들어오면 어떻게 되는가?
    답

    상태 S200(음료와 거스름)을 추가하거나, S150으로 가면서 밀리 출력 C = 1을 낸다. 어느 쪽이든 S100에서 D가 들어오면 음료와 50원 거스름이 나온다.
