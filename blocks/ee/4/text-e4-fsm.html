유한상태기계 설계

본문
이 절에서 배울 것
  • 말로 된 명세에서 상태를 정하고 상태도를 그린다.
  • 상태 할당(2진, 원-핫, 그레이)을 하고 다음 상태·출력 식을 구한다.
  • 같은 동작을 하는 상태를 합쳐 상태 수를 줄인다.
먼저 알아야 할 것
  • 동기식 카운터 설계 (5.2절).

6.1.1유한상태기계란

5.2절의 카운터는 입력 없이(또는 방향 입력 하나로) 정해진 순서를 돌았습니다. 자판기, 신호등, 통신 규약 처리기는 입력에 따라 다음 행동이 달라집니다. 이런 회로를 "지금 어떤 상황인가"(상태)와 "입력이 오면 어디로 가는가"(전이)로 설명한 것이 유한상태기계(FSM)입니다.

상태: 미래 동작을 정하는 데 필요한 과거의 요약. 상태 수가 유한하다.

전이: 클록 모서리에서 (현재 상태, 입력) → 다음 상태.

출력: 현재 상태(무어) 또는 현재 상태와 입력(밀리)으로 정해진다(6.2절).

6.1.2설계 절차

  1. 명세를 읽고 기억해야 할 것이 무엇인지 정해 상태로 삼는다.
  2. 상태도: 상태를 원, 전이를 화살표(입력 조건 표시), 출력을 원 안(무어) 또는 화살표 위(밀리)에.
  3. 상태 할당: 상태마다 2진 부호를 정한다.
  4. 상태표 → 다음 상태 식, 출력 식(카르노 맵).
  5. 플립플롭과 게이트로 그리고, 쓰지 않는 부호의 전이를 점검한다.
예제 6.1.1 (동전 자판기)

음료가 150원이고 50원(N)과 100원(D) 동전만 받는다. 거스름돈은 주지 않고, 150원 이상이 되면 음료를 내놓고(출력 V = 1) 처음으로 돌아간다. 한 클록에 동전은 최대 하나 들어온다. FSM을 설계하여라.

풀이. 기억할 것은 지금까지 넣은 금액입니다. 상태 S0(0원), S50(50원), S100(100원), S150(150원 이상, 음료). 전이:

  • S0: N → S50, D → S100, 없음 → S0.
  • S50: N → S100, D → S150, 없음 → S50.
  • S100: N → S150, D → S150(200원이지만 거스름 없음), 없음 → S100.
  • S150: 음료를 내놓고 다음 클록에 S0(입력 무시). 출력 V = 1은 S150에서만(무어).

상태 할당 S0 = 00, S50 = 01, S100 = 10, S150 = 11. 입력은 N, D 두 비트(동시에 1은 없음). 다음 상태 비트가 1이 되는 경우를 상태표에서 모읍니다.

  • \(Q_1^+ = 1\): S0에서 D(→ 10), S50에서 N 또는 D(→ 10, 11), S100에서 모든 입력(→ 10, 11, 11). 따라서 \(Q_1^+ = Q_1'Q_0'D + Q_1'Q_0(N + D) + Q_1Q_0'\). 앞 항과 끝 항을 \(Q_0'(Q_1 + Q_1'D) = Q_0'(Q_1 + D)\)로 합치면 \(Q_1^+ = Q_1Q_0' + Q_0'D + Q_1'Q_0(N + D)\).
  • \(Q_0^+ = 1\): S0에서 N(→ 01), S50에서 동전 없음 또는 D(→ 01, 11), S100에서 N 또는 D(→ 11). S50의 "없음 또는 D"는 N이 아닌 경우이므로 \(Q_0^+ = Q_1'Q_0'N + Q_1'Q_0N' + Q_1Q_0'(N + D)\).
  • S150(11)에서는 두 식 모두 0이 되어 다음 상태가 00. 출력 \(V = Q_1Q_0\).

검산: S50(\(Q_1Q_0 = 01\))에서 D가 들어오면(N = 0, D = 1) \(Q_1^+ = 0 + 0 + 1\cdot1 = 1\), \(Q_0^+ = 0 + 1\cdot1 + 0 = 1\)로 다음 상태 11(S150)입니다. 상태표와 같습니다. 이렇게 상태마다 입력을 하나씩 넣어 보는 것이 가장 확실한 검산입니다.

식이 복잡해 보이지만 실제 설계는 HDL로 상태표를 그대로 적고 합성 도구가 최소화하게 합니다(7.1절). 손 설계에서 중요한 것은 상태와 전이를 빠짐없이 정하는 것입니다.

6.1.3상태 할당

2진 부호화: 상태 k개에 플립플롭 \(\lceil\log_2k\rceil\)개. 플립플롭이 가장 적다.

원-핫 부호화: 상태마다 플립플롭 하나, 늘 하나만 1. 플립플롭은 많지만 다음 상태 논리가 단순하고 빠르다. FPGA에서 흔하다(플립플롭이 넉넉함).

그레이 부호화: 자주 오가는 상태끼리 한 비트만 다르게. 전이 때 바뀌는 비트가 적어 글리치와 전력이 준다.

6.1.4상태 최소화

두 상태가 모든 입력에 대해 같은 출력을 내고 같은(또는 서로 동치인) 다음 상태로 간다면 하나로 합칠 수 있습니다. 처음 상태도를 그릴 때 생긴 쓸데없는 상태를 이렇게 지우면 플립플롭과 논리가 줄어듭니다. 예를 들어 순서 검출기(6.2절)를 처음 그릴 때 "1을 하나 받음" 상태가 두 군데 따로 생겼다면, 이후 동작이 같으므로 합칩니다.

주의모든 상태에서 모든 입력 조합의 전이를 정했는지 확인하세요. 화살표가 빠진 칸은 회로에서 무엇인가로 정해져 버리고(합성 도구가 임의로 고름), 예상치 못한 상태로 가거나 멈춥니다.
요약
  1. 상태 = 미래 동작에 필요한 과거의 요약. 상태도로 전이와 출력을 모두 정한다.
  2. 절차: 명세 → 상태도 → 할당 → 상태표 → 식 → 회로 → 쓰지 않는 부호 점검.
  3. 2진(플립플롭 최소), 원-핫(논리 단순), 그레이(전이 비트 최소). 같은 동작의 상태는 합친다.

6.1.5연습문제

기본

  1. 상태가 10개인 FSM을 2진 부호화와 원-핫 부호화로 만들 때 플립플롭은 각각 몇 개인가?
    답

    4개, 10개.

응용

  1. 버튼 입력 B가 1이 될 때마다 LED를 켜고 끄는(토글) FSM을 그려라. B를 계속 누르고 있어도 한 번만 바뀌어야 한다.
    힌트

    LED 상태 2개 × 버튼이 눌린 채인지 2개 = 상태 4개.

    답

    OFF_떼어짐 —B→ ON_눌림 —B'→ ON_떼어짐 —B→ OFF_눌림 —B'→ OFF_떼어짐. 눌린 채(B)면 같은 상태에 머문다. LED 출력은 ON_*에서 1.

심화

  1. 예제 6.1.1의 자판기를 거스름돈 50원(출력 C)을 주도록 바꿔라. S100에서 D가 들어오면 어떻게 되는가?
    답

    상태 S200(음료 + 거스름) 추가 또는 S150으로 가면서 밀리 출력 C = 1. S100에서 D → 음료와 50원 거스름.
