두 식이 같은지 진리표로 확인하기

탐구 · 불 식 계산기

질문

불 대수로 식을 간단히 한 뒤, 답이 맞는지 어떻게 확인할까요? 변수가 네 개 이하라면 진리표 16줄을 모두 비교하면 확실합니다.

준비

식은 변수 A, B, C, D와 다음 기호로 씁니다.

  • NOT: 변수나 괄호 뒤에 ' (예: A', (A+B)')
  • AND: 붙여 쓰거나 * (예: AB'C)
  • OR: +, XOR: ^, 상수 0, 1

두 식의 진리표를 나란히 만들고, 다른 줄은 빨갛게 표시합니다.

해 보기와 설명

  1. 본문 예제처음 두 식은 2.1절 예제 2.1.2의 원래 식과 답입니다. 모든 줄이 같고, 최소항이 Σm(1, 3, 5, 6)입니다.
  2. 법칙 확인단추를 눌러 드 모르간, 합의 정리, OR 쪽 분배법칙이 성립하는 것을 봅니다.
  3. 흔한 실수"흔한 실수" 단추는 \((A + B)' = A' + B'\)를 비교합니다. A와 B가 다른 두 줄에서 결과가 다릅니다.
  4. 직접 해 보기2.1절 연습문제의 답을 식 2에 적어 검산해 보세요.

연결과 적용

변수가 많아지면 진리표가 너무 커져(30변수면 10억 줄) 이 방법을 쓸 수 없습니다. 실제 칩 설계 도구는 BDD나 SAT 풀이기 같은 더 똑똑한 방법으로 두 회로가 같은지 증명합니다(등가성 검사, 전전32).

흔한 오해

  • "몇 줄 넣어 봐서 같으면 같은 식이다." 다른 줄이 하나만 있어도 다른 함수입니다. 변수가 적을 때는 모든 줄을 확인하세요.
