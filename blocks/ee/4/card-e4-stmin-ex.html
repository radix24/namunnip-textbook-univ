Mealy 기계의 동치 상태 찾기

분할 정제

출발점

출력과 다음 상태 묶음으로 나누기를 반복하면 동치 상태가 남습니다(6.3절).

문제 해결 전략 · 출력 표 → 다음 상태 표
  1. (x = 0, x = 1)의 출력 쌍으로 처음 묶음을 만든다.
  2. 다음 상태가 어느 묶음으로 가는지 보고 나눈다.
  3. 변화가 없으면 멈춘다.

Mealy 상태표: S0(x=0: S0/0, x=1: S1/0), S1(S0/0, S2/1), S2(S0/0, S2/1). 최소화하라.

풀이

  1. 출력 쌍: S0 (0, 0), S1 (0, 1), S2 (0, 1) → {S0}, {S1, S2}.
    출력으로 나눔.
  2. S1, S2의 다음 상태: x=0 둘 다 S0, x=1 둘 다 S2({S1, S2}) → 같은 묶음.
    더 나누지 않음.
  3. S1 ≡ S2: 상태 2개(S0, S1)로 줄어 플립플롭 1개.
    합침.

의미

줄인 기계는 '지난 입력이 1이었고 이번에도 1이면 1'을 내는, 연속 1 검출기입니다. 상태가 3 → 2로 줄어 플립플롭이 2개 → 1개가 됩니다.

검산

입력 0110을 원래 기계와 줄인 기계에 넣으면 둘 다 출력 0010을 냅니다.
