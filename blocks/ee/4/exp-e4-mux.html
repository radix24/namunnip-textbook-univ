4:1 멀티플렉서 하나로 3변수 함수 만들기

탐구 · 데이터 입력에 0, 1, C, C′

질문

3변수 함수는 256가지나 된다. 4:1 멀티플렉서 하나와 C의 NOT만 있으면 그 전부를 만들 수 있을까?

준비

아래 체크 상자 여덟 개가 진리표의 출력 \(F(m_0), \dots, F(m_7)\)입니다(번호 \(m = 4A + 2B + C\)). 선택선에 A, B를 넣으면 4.2절 정리 4.2.1에 따라 각 데이터 입력 \(I_k\)는 \(F(C = 0)\)과 \(F(C = 1)\)로 정해지는 0, 1, C, C′ 중 하나이다. 그림과 출력 줄이 그 값을 알려 준다.

해 보기와 설명

  1. 다수결처음 상태(3, 5, 6, 7)는 예제 4.2.2의 다수결 함수이다: \(I_0 = 0\), \(I_1 = C\), \(I_2 = C\), \(I_3 = 1\).
  2. 패리티1, 2, 4, 7만 켜면 \(I = C, C', C', C\)로, 연습문제 2의 답이다.
  3. 모든 함수어떤 조합을 골라도 데이터 입력은 넷 중 하나로 정해진다. 256가지 모두 구현된다.

연결과 적용

데이터 입력을 0/1로만 정하는 대신 메모리 비트로 바꾸면, 어떤 함수든 메모리 값만 바꿔 구현하는 FPGA의 순람표가 됩니다(7.2절의 LUT 카드).

흔한 오해

  • "n변수 함수에는 2ⁿ:1 MUX가 필요하다." 마지막 변수를 데이터 쪽으로 넘기면 절반 크기로 충분하다.
