편향-분산 트레이드오프

본문

직선 하나로 곡선 자료를 맞추면 늘 같은 방향으로 빗나가고, 고차 다항식으로 맞추면 자료를 조금만 바꿔도 곡선이 크게 출렁인다. 너무 단순한 모델과 너무 복잡한 모델은 서로 다른 방식으로 틀린다. 일부러 틀리게 만든 추정이 오히려 더 정확할 수도 있을까?

먼저 알아야 할 것기댓값과 분산(전전11 2.1절), 정규화(전전20 2.1절)를 쓴다.

1.2.1분해

같은 방식으로 다른 훈련 자료를 뽑아 학습할 때마다 예측 \(\hat f(x)\)가 달라진다. 그러면 예측 오차의 기댓값은 세 부분으로 나뉜다.

편향-분산 분해

\[ E[(y - \hat f)^2] = (E\hat f - f)^2 + \text{Var}(\hat f) + \sigma^2 \]

첫째 항이 편향의 제곱, 둘째 항이 분산, 셋째 항이 잡음 분산이다.

직선처럼 단순한 모델은 곡선을 따라가지 못해 편향이 크다. 반면 고차 다항식처럼 복잡한 모델은 자료마다 크게 흔들려 분산이 크다(그림 1). 처음 질문의 첫째 답이 이것이다. 따라서 전체 오차가 가장 작은 중간 복잡도를 고르는 것이 모델 선택이다.

예제 1.2.1

평균 μ = 1, 분산 4인 분포에서 n = 4개를 뽑아 μ를 \(\hat\mu = c\bar x\)로 추정한다. c = 1과 c = 0.5의 평균 제곱 오차는?

풀이. \(\text{Var}(\bar x) = 4/4 = 1\)이고, 편향은 \((c - 1)\mu\), 분산은 \(c^2\)이다. c = 1이면 0 + 1 = 1이고, c = 0.5이면 0.25 + 0.25 = 0.5이다. 즉 일부러 0 쪽으로 줄여 편향을 늘렸더니 분산이 4분의 1로 줄어, 전체 오차가 절반이 되었다. 처음 질문의 둘째 답이 이것이며, 리지 정규화가 하는 일도 이것이다.

이 예에서 최적의 c는 \(\mu^2/(\mu^2 + 1) = 0.5\)이다. 그런데 이 값을 정하려면 μ를 알아야 하므로, 실제로는 줄이는 정도를 검증 자료로 고른다(1.1절).

이 분해는 앙상블이 왜 효과적인지도 설명한다. 서로 다른 자료로 학습한 여러 모델의 예측을 평균하면, 편향은 그대로이지만 분산은 모델 수에 반비례해 줄어든다. 그래서 분산이 큰 깊은 결정 트리를 여러 개 평균하는 랜덤 포레스트가 잘 동작한다(6.4절).

실제로 모델 복잡도는 다항식 차수만이 아니다. 신경망의 층 수와 너비, 결정 트리의 깊이, 정규화 세기 λ, 학습을 멈추는 시점이 모두 복잡도를 조절한다. 따라서 이 값들은 모두 같은 원리로 검증 자료에서 고른다.

흔한 오해편향이 없는 추정이 언제나 낫다고 여기기 쉽다. 분산이 크면 편향 없는 추정의 전체 오차가 더 클 수 있다. 또 자료를 늘리면 편향이 준다고 생각하기 쉬운데, 자료를 늘리면 주로 분산이 줄고, 편향은 모델의 표현력으로 정해진다.
마무리

예측 오차는 편향² + 분산 + 잡음으로 나뉜다. 단순한 모델은 편향이, 복잡한 모델은 분산이 크다. 축소(정규화)는 편향을 조금 늘려 분산을 크게 줄인다.

1.2.2연습문제

기본

  1. 잡음 σ²는 모델을 바꿔 줄일 수 있는가?
    답

    아니다. 줄일 수 없는 오차이다.

응용

  1. 예제에서 c = 0.8의 평균 제곱 오차는?
    답

    0.04 + 0.64 = 0.68이다.

심화

  1. 훈련 오차와 검증 오차가 모두 크면 어느 쪽 문제인가?
    답

    편향(과소적합). 모델을 키우거나 특징을 늘린다.
