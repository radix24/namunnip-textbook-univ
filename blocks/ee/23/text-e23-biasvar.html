편향-분산 트레이드오프

본문
이 절에서 배울 것
  • 기대 제곱 오차가 편향² + 분산 + 잡음으로 나뉨을 안다.
  • 모델이 단순하면 편향, 복잡하면 분산이 커지는 이유를 설명한다.
  • 축소 추정량 예로 편향을 조금 늘려 전체 오차를 줄이는 계산을 한다.
먼저 알아야 할 것
  • 기댓값과 분산 (전전11 2.1절), 정규화 (전전20 2.1절).

1.2.1분해

같은 방식으로 다른 훈련 자료를 뽑아 학습할 때마다 예측 \(\hat f(x)\)가 달라집니다. 참값 f(x)와 잡음 분산 σ²에 대해

\[ E[(y - \hat f)^2] = \underbrace{(E\hat f - f)^2}_{\text{편향}^2} + \underbrace{\text{Var}(\hat f)}_{\text{분산}} + \sigma^2. \]

직선처럼 단순한 모델은 곡선을 따라가지 못해 편향이 크고, 고차 다항식처럼 복잡한 모델은 자료마다 크게 흔들려 분산이 큽니다. 전체 오차가 가장 작은 중간 복잡도를 고르는 것이 모델 선택입니다.

예제 1.2.1

평균 μ = 1, 분산 4인 분포에서 n = 4개를 뽑아 μ를 \(\hat\mu = c\bar x\)로 추정한다. c = 1과 c = 0.5의 평균 제곱 오차는?

풀이. \(\text{Var}(\bar x) = 4/4 = 1\). 편향 \((c - 1)\mu\), 분산 \(c^2\). c = 1: 0 + 1 = 1. c = 0.5: 0.25 + 0.25 = 0.5. 일부러 0 쪽으로 줄여(편향 증가) 분산을 4분의 1로 줄인 결과 전체 오차가 절반이 되었습니다. 리지 정규화가 하는 일이 이것입니다. (최적 c는 \(\mu^2/(\mu^2 + 1) = 0.5\)로, μ를 알아야 정할 수 있어 실제로는 검증 자료로 고릅니다.)

흔한 오해(1) "편향이 없는 추정이 언제나 낫다": 분산이 크면 전체 오차가 더 클 수 있습니다. (2) "자료를 늘리면 편향이 준다": 자료를 늘리면 주로 분산이 줄고, 편향은 모델의 표현력으로 정해집니다.
요약
  1. 오차 = 편향² + 분산 + 잡음.
  2. 단순 모델은 편향, 복잡 모델은 분산이 크다.
  3. 축소(정규화)는 편향을 조금 늘려 분산을 크게 줄인다.

1.2.2연습문제

기본

  1. 잡음 σ²는 모델을 바꿔 줄일 수 있는가?
    답

    아닙니다. 줄일 수 없는 오차입니다.

응용

  1. 예제에서 c = 0.8의 평균 제곱 오차는?
    답

    0.04 + 0.64 = 0.68.

심화

  1. 훈련 오차와 검증 오차가 모두 크면 어느 쪽 문제인가?
    답

    편향(과소적합). 모델을 키우거나 특징을 늘립니다.
