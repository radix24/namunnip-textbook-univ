선형회귀와 로지스틱 회귀의 최대가능도 유도

본문
이 절에서 배울 것
  • 가우시안 잡음 가정에서 최대가능도가 최소제곱과 같음을 유도한다.
  • 베르누이 모형에서 최대가능도가 교차 엔트로피 최소화와 같음을 유도한다.
  • 잡음 분산의 최대가능도 추정을 구한다.
먼저 알아야 할 것
  • 로그와 미분, 정규 분포 (전전11 2.1절), 로지스틱 회귀 (전전20 5.1절).

2.1.1선형회귀

\(y_i = w^Tx_i + \epsilon_i\), \(\epsilon_i \sim N(0, \sigma^2)\) 독립이면 로그 가능도는

\[ \log L = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i(y_i - w^Tx_i)^2. \]

w에 대해 최대화하는 것은 제곱 오차 합을 최소화하는 것과 같습니다. σ²로 미분해 0으로 두면 \(\hat\sigma^2 = \frac1n\sum(y_i - \hat w^Tx_i)^2\)(잔차 제곱 평균)입니다.

2.1.2로지스틱 회귀

\(P(y_i = 1) = p_i = \sigma(w^Tx_i)\)이면 \(L = \prod p_i^{y_i}(1 - p_i)^{1 - y_i}\), 음의 로그 가능도는 \(-\sum[y_i\log p_i + (1 - y_i)\log(1 - p_i)]\), 곧 교차 엔트로피입니다. 기울기는 \(\sum(p_i - y_i)x_i\)로 닫힌 해가 없어 경사하강으로 풉니다.

예제 2.1.1

동전을 10번 던져 앞면이 7번 나왔다. 앞면 확률 p의 최대가능도 추정은? 절편만 있는 로지스틱 회귀(\(p = \sigma(b)\))로 풀면 b는?

풀이. \(\log L = 7\log p + 3\log(1 - p)\), 미분 \(7/p - 3/(1 - p) = 0\) → p = 0.7. 로지스틱 회귀도 같은 가능도라 \(\sigma(b) = 0.7\), \(b = \ln(0.7/0.3) = 0.847\).

흔한 오해(1) "최소제곱은 가정 없는 방법": 가우시안 잡음 가정에서 최적(최대가능도)이며, 이상치가 많으면 다른 손실이 낫습니다. (2) "로지스틱 회귀에도 제곱 오차를 쓰면 된다": 시그모이드와 결합하면 비볼록이 되어 학습이 나빠집니다.
요약
  1. 가우시안 잡음 MLE = 최소제곱, σ̂² = 잔차 제곱 평균.
  2. 베르누이 MLE = 교차 엔트로피 최소화.
  3. 로지스틱은 닫힌 해가 없어 경사하강.

2.1.3연습문제

기본

  1. 20번 중 5번 성공의 p̂는?
    답

    0.25.

응용

  1. 잔차가 1, −1, 2, −2이면 σ̂²는?
    답

    (1 + 1 + 4 + 4)/4 = 2.5.

  1. 잡음이 라플라스 분포면 MLE는 어떤 손실인가?
