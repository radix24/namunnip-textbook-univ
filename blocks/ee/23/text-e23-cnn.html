합성곱 신경망으로 영상 분류

본문

32 × 32 컬러 사진 한 장은 숫자 3072개이다. 이것을 완전 연결 신경망에 넣으면 첫 층의 가중치만 수천만 개가 되어 금세 과적합한다. 그런데 합성곱 신경망은 훨씬 적은 가중치로 사진을 더 잘 분류한다. 무엇을 줄였길래 가능할까? 그리고 실제 학습은 어떤 순서로 돌릴까?

먼저 알아야 할 것역전파(4.1절), 2차원 합성곱(전전6 2.1절)을 쓴다.

4.2.1크기와 매개변수

합성곱 층은 K×K 크기의 작은 필터를 영상 위에서 밀며 같은 가중치로 곱해 더한다. 그래서 입력 C채널에 필터 N개를 쓰면 매개변수는 편향까지 \(K^2CN + N\)이고, 영상 크기와 무관하다. 처음 질문의 첫째 답이 이것이다.

합성곱 층의 크기

출력 크기는 (W − K + 2P)/S + 1이다(W 입력 크기, P 패딩, S 보폭). 매개변수는 \(K^2CN + N\)이다.

아래 코드는 32×32 컬러 영상용 작은 CNN의 층별 크기를 계산한다(그림 1).

# 32×32 컬러 영상을 받는 작은 CNN의 층별 출력 크기와 매개변수 수
def conv(h, w, c, k, n, s=1, p=0):
    ho, wo = (h - k + 2 * p) // s + 1, (w - k + 2 * p) // s + 1
    return ho, wo, n, k * k * c * n + n
layers = [("conv3x3,16,pad1", "c", 3, 16, 1), ("maxpool2", "p"), ("conv3x3,32,pad1", "c", 3, 32, 1), ("maxpool2", "p")]
h, w, c, total = 32, 32, 3, 0
for L in layers:
    if L[1] == "c":
        h, w, c, n = conv(h, w, c, L[2], L[3], 1, L[4]); total += n
    else:
        h, w, n = h // 2, w // 2, 0
    print(f"{L[0]:16s} → {h}×{w}×{c}, 매개변수 {n}")
fc = h * w * c * 10 + 10; total += fc
print(f"{'fc→10':16s} → 10, 매개변수 {fc}")
print("합계 매개변수:", total)
print("같은 입력을 완전 연결로 32×32×16에 잇는다면:", 32 * 32 * 3 * 32 * 32 * 16 + 32 * 32 * 16)

실행 결과(Python 3.12에서 실제 실행)는 다음과 같다.

conv3x3,16,pad1  → 32×32×16, 매개변수 448
maxpool2         → 16×16×16, 매개변수 0
conv3x3,32,pad1  → 16×16×32, 매개변수 4640
maxpool2         → 8×8×32, 매개변수 0
fc→10            → 10, 매개변수 20490
합계 매개변수: 25578
같은 입력을 완전 연결로 32×32×16에 잇는다면: 50348032

즉 합성곱 두 층의 매개변수는 5천 개 남짓인데, 같은 크기의 출력을 완전 연결로 만들면 5천만 개가 넘는다. 영상의 경계나 질감 같은 국소 패턴이 위치와 무관하게 나타난다는 성질을 구조에 넣은 덕분이다.

4.2.2학습 순서

PyTorch로 짜면 대략 다음과 같다(참고 코드, 자료 적재 부분 생략). 처음 질문의 둘째 답이 이것이다.

model = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(8 * 8 * 32, 10))
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for epoch in range(10):
    model.train()
    for x, y in train_loader:
        loss = nn.functional.cross_entropy(model(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
    model.eval()
    with torch.no_grad():
        acc = sum((model(x).argmax(1) == y).sum().item() for x, y in val_loader) / len(val_set)
    print(epoch, acc)

에폭마다 검증 정확도를 보고, 검증 정확도가 더 오르지 않으면 학습을 멈춘다(조기 종료). 또 뒤집기나 자르기 같은 자료 증강은 훈련 자료에만 적용한다.

흔한 오해층이 깊을수록 언제나 좋다고 여기기 쉽다. 자료가 적으면 깊은 모델은 과적합하므로, 큰 자료로 미리 학습한 모델을 가져와 미세 조정한다(전전33 4.1절). 또 검증할 때도 model.train() 상태로 두어도 된다고 생각하기 쉬운데, 드롭아웃과 배치 정규화가 다르게 동작하므로 eval()로 바꿔야 한다.
마무리

합성곱 층의 출력 크기는 (W − K + 2P)/S + 1, 매개변수는 K²CN + N이다. 가중치 공유로 매개변수가 수천 배 줄어든다(예제에서 5천 대 5천만). 학습은 손실, 최적화기, 에폭, 검증, 조기 종료의 순서로 돌린다.
