합성곱 신경망으로 영상 분류

본문
이 절에서 배울 것
  • 합성곱 층의 출력 크기 \((W - K + 2P)/S + 1\)과 매개변수 수를 계산한다.
  • 가중치 공유와 국소 연결이 매개변수를 줄이는 효과를 수치로 본다.
  • 작은 CNN의 학습 과정(손실, 최적화기, 에폭, 검증)을 코드로 구성한다.
먼저 알아야 할 것
  • 역전파 (4.1절), 2차원 합성곱 (전전6 2.1절).

4.2.1크기와 매개변수

입력 C채널, 필터 K×K를 N개 쓰면 매개변수는 \(K^2CN + N\)(편향)입니다. 영상 크기와 무관합니다(같은 필터를 모든 위치에 공유). 아래 코드는 32×32 컬러 영상용 작은 CNN의 층별 크기를 계산합니다.

# 32×32 컬러 영상을 받는 작은 CNN의 층별 출력 크기와 매개변수 수
def conv(h, w, c, k, n, s=1, p=0):
    ho, wo = (h - k + 2 * p) // s + 1, (w - k + 2 * p) // s + 1
    return ho, wo, n, k * k * c * n + n
layers = [("conv3x3,16,pad1", "c", 3, 16, 1), ("maxpool2", "p"), ("conv3x3,32,pad1", "c", 3, 32, 1), ("maxpool2", "p")]
h, w, c, total = 32, 32, 3, 0
for L in layers:
    if L[1] == "c":
        h, w, c, n = conv(h, w, c, L[2], L[3], 1, L[4]); total += n
    else:
        h, w, n = h // 2, w // 2, 0
    print(f"{L[0]:16s} → {h}×{w}×{c}, 매개변수 {n}")
fc = h * w * c * 10 + 10; total += fc
print(f"{'fc→10':16s} → 10, 매개변수 {fc}")
print("합계 매개변수:", total)
print("같은 입력을 완전 연결로 32×32×16에 잇는다면:", 32 * 32 * 3 * 32 * 32 * 16 + 32 * 32 * 16)

실행 결과(Python 3.12에서 실제 실행):

conv3x3,16,pad1  → 32×32×16, 매개변수 448
maxpool2         → 16×16×16, 매개변수 0
conv3x3,32,pad1  → 16×16×32, 매개변수 4640
maxpool2         → 8×8×32, 매개변수 0
fc→10            → 10, 매개변수 20490
합계 매개변수: 25578
같은 입력을 완전 연결로 32×32×16에 잇는다면: 50348032

합성곱 두 층의 매개변수는 5천 개 남짓인데, 같은 크기 출력을 완전 연결로 만들면 5천만 개가 넘습니다. 영상의 국소 패턴(경계, 질감)이 위치와 무관하게 나타난다는 성질을 구조에 넣은 덕분입니다.

4.2.2학습 순서

PyTorch로 짜면 대략 다음과 같습니다(참고 코드, 자료 적재 부분 생략).

model = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(8 * 8 * 32, 10))
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for epoch in range(10):
    model.train()
    for x, y in train_loader:
        loss = nn.functional.cross_entropy(model(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
    model.eval()
    with torch.no_grad():
        acc = sum((model(x).argmax(1) == y).sum().item() for x, y in val_loader) / len(val_set)
    print(epoch, acc)

에폭마다 검증 정확도를 보고, 검증 정확도가 더 오르지 않으면 멈춥니다(조기 종료). 자료 증강(뒤집기, 자르기)은 훈련 자료에만 적용합니다.

흔한 오해(1) "층이 깊을수록 언제나 좋다": 자료가 적으면 과적합하므로 사전 학습 모델(전전33 4.1절)을 씁니다. (2) "검증 때도 model.train() 상태로 두어도 된다": 드롭아웃·배치 정규화가 다르게 동작하므로 eval()로 바꿉니다.
요약
  1. 출력 크기 (W − K + 2P)/S + 1, 매개변수 K²CN + N.
  2. 가중치 공유로 매개변수가 수천 배 줄어든다(예: 5천 대 5천만).
  3. 손실·최적화기·에폭·검증·조기 종료.
