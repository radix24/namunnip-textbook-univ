결정 트리와 정보 이득

본문
이 절에서 배울 것
  • 특징 값으로 자료를 나누는 결정 트리의 구조를 안다.
  • 엔트로피 감소(정보 이득)로 가장 좋은 분할을 고른다.
  • 트리의 과적합과 가지치기, 앙상블(랜덤 포레스트)을 안다.
먼저 알아야 할 것
  • 엔트로피 (전전21 1.1절), 과적합 (1.2절).

3.3.1가장 깨끗하게 나누기

노드의 엔트로피 \(H = -\sum p_k\log_2p_k\). 분할 후 자식들의 가중 평균 엔트로피를 뺀 값이 정보 이득이며, 이득이 가장 큰 특징·문턱으로 나눕니다. 깊이 제한, 최소 표본 수, 가지치기로 과적합을 막고, 여러 트리를 평균한 랜덤 포레스트가 실무에서 강력합니다.

예제 3.3.1

양성 10, 음성 10인 노드를 분할 A(왼쪽 8+/2−, 오른쪽 2+/8−)와 분할 B(왼쪽 9+/1−, 오른쪽 1+/9−) 중 어느 것이 이득이 큰가?

풀이. 부모 H = 1. A: 자식 각 H(0.8) = 0.722 → 이득 0.278. B: 자식 각 H(0.9) = 0.469 → 이득 0.531. B가 더 깨끗하게 나눠 선택됩니다.

흔한 오해(1) "트리는 깊을수록 좋다": 훈련 자료를 외워 과적합합니다. (2) "트리는 특징 크기 조정이 필요": 문턱 비교만 해 표준화가 필요 없습니다.
요약
  1. H = −Σp log₂p, 이득 = H(부모) − 가중 H(자식).
  2. 예: 8/2 분할 0.278, 9/1 분할 0.531.
  3. 깊이 제한·가지치기·랜덤 포레스트.
