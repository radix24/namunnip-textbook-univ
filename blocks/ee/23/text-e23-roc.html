ROC 곡선과 AUC

본문

분류기는 보통 0과 1 사이의 점수를 내고, 그 점수가 문턱을 넘으면 양성이라고 판정한다. 그런데 문턱을 바꾸면 정밀도와 재현율이 모두 달라진다. 문턱 하나를 정하기 전에, 모델이 양성과 음성을 얼마나 잘 가려내는지 한 숫자로 요약할 수는 없을까?

먼저 알아야 할 것평가 지표(6.1절)를 쓴다.

6.3.1문턱을 훑기

모델이 낸 점수의 문턱을 높은 값에서 낮은 값으로 내리며, 거짓 양성 비율(FPR)과 참 양성 비율(TPR)을 점으로 찍으면 ROC 곡선이 된다(그림 1). 그리고 곡선 아래 넓이를 AUC라 한다. 처음 질문의 답이 이것이다.

AUC의 뜻

AUC는 무작위로 고른 양성 하나의 점수가 무작위로 고른 음성 하나의 점수보다 높을 확률과 같다.

즉 AUC는 문턱을 정하지 않고 모델의 순위 매기는 능력만 요약한다. 아래 코드는 점수 10개로 ROC 점과 AUC를 계산하고, 양성·음성 쌍의 비율과 비교한다.

scores = [0.95, 0.9, 0.8, 0.7, 0.6, 0.55, 0.4, 0.3, 0.2, 0.1]
labels = [1,    1,   0,   1,   1,   0,    0,   1,   0,   0]
P, N = sum(labels), len(labels) - sum(labels)
pts, tp, fp = [(0.0, 0.0)], 0, 0
for s, y in sorted(zip(scores, labels), reverse=True):
    tp += y; fp += 1 - y
    pts.append((fp / N, tp / P))
auc = sum((x2 - x1) * (y1 + y2) / 2 for (x1, y1), (x2, y2) in zip(pts, pts[1:]))
pairs = sum(1 for sp, yp in zip(scores, labels) if yp for sn, yn in zip(scores, labels) if not yn and sp > sn)
print("ROC 점(FPR, TPR):", [(round(a, 2), round(b, 2)) for a, b in pts])
print(f"AUC(사다리꼴) {auc:.3f}, 양성>음성 쌍 비율 {pairs / (P * N):.3f}")

실행 결과(Python 3.12에서 실제 실행)는 다음과 같다.

ROC 점(FPR, TPR): [(0.0, 0.0), (0.0, 0.2), (0.0, 0.4), (0.2, 0.4), (0.2, 0.6), (0.2, 0.8), (0.4, 0.8), (0.6, 0.8), (0.6, 1.0), (0.8, 1.0), (1.0, 1.0)]
AUC(사다리꼴) 0.800, 양성>음성 쌍 비율 0.800
예제 6.3.1

위 결과의 AUC와 그 뜻은?

풀이. 실행 결과에서 사다리꼴로 구한 AUC 0.8과, 양성 점수가 음성 점수보다 높은 쌍의 비율 0.8이 같다. 즉 무작위로 고른 양성·음성 쌍의 80%를 올바른 순서로 매긴다. 따라서 문턱 하나의 정확도와 달리, 문턱과 무관한 순위 능력을 요약한다.

그런데 실제 시스템은 결국 문턱 하나로 운영된다. 그러므로 AUC로 모델을 고른 뒤에는, 운영할 문턱에서의 정밀도와 재현율을 따로 확인하고 오류 비용(6.1절)에 맞춰 문턱을 정한다.

AUC는 점수의 크기가 아니라 순서만 본다. 그래서 점수에 단조 증가 함수를 씌워도 AUC는 변하지 않으며, 점수가 잘 보정된 확률인지는 따로 확인해야 한다.

또 곡선의 모양 자체도 정보를 준다. 왼쪽 위로 가파르게 솟는 곡선은 높은 점수 몇 개만으로 양성을 많이 찾는다는 뜻이므로, 상위 일부만 검사하는 선별 작업에 알맞다. 따라서 같은 AUC라도 쓰임새에 따라 더 나은 곡선이 다를 수 있다.

흔한 오해AUC가 높으면 어떤 문턱에서도 좋다고 여기기 쉽다. AUC는 곡선 전체의 평균이라, 운영할 문턱 근처의 성능은 따로 봐야 한다. 또 불균형 자료에도 ROC만으로 충분하다고 생각하기 쉬운데, 양성이 아주 드물면 PR 곡선이 모델 사이의 차이를 더 잘 보여 준다.
마무리

ROC 곡선은 문턱을 훑어 (FPR, TPR)을 찍은 것이다. AUC는 양성 점수가 음성 점수보다 높을 확률이다. 예제의 AUC는 0.8이며, 불균형 자료에는 PR 곡선을 함께 본다.
