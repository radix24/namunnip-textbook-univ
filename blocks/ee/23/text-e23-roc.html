ROC 곡선과 AUC

본문
이 절에서 배울 것
  • 판정 문턱을 바꾸며 참 양성률과 거짓 양성률의 곡선(ROC)을 그린다.
  • 곡선 아래 넓이(AUC)를 계산하고 해석한다.
  • 불균형 자료에서 PR 곡선과 비교한다.
먼저 알아야 할 것
  • 평가 지표 (6.1절).

6.3.1문턱을 훑기

모델이 낸 점수의 문턱을 높은 값에서 낮은 값으로 내리며 (FPR, TPR)을 찍으면 ROC 곡선입니다. AUC는 무작위 양성 하나의 점수가 무작위 음성 하나보다 높을 확률과 같습니다(무작위 0.5, 완벽 1).

scores = [0.95, 0.9, 0.8, 0.7, 0.6, 0.55, 0.4, 0.3, 0.2, 0.1]
labels = [1,    1,   0,   1,   1,   0,    0,   1,   0,   0]
P, N = sum(labels), len(labels) - sum(labels)
pts, tp, fp = [(0.0, 0.0)], 0, 0
for s, y in sorted(zip(scores, labels), reverse=True):
    tp += y; fp += 1 - y
    pts.append((fp / N, tp / P))
auc = sum((x2 - x1) * (y1 + y2) / 2 for (x1, y1), (x2, y2) in zip(pts, pts[1:]))
pairs = sum(1 for sp, yp in zip(scores, labels) if yp for sn, yn in zip(scores, labels) if not yn and sp > sn)
print("ROC 점(FPR, TPR):", [(round(a, 2), round(b, 2)) for a, b in pts])
print(f"AUC(사다리꼴) {auc:.3f}, 양성>음성 쌍 비율 {pairs / (P * N):.3f}")

실행 결과(Python 3.12에서 실제 실행):

ROC 점(FPR, TPR): [(0.0, 0.0), (0.0, 0.2), (0.0, 0.4), (0.2, 0.4), (0.2, 0.6), (0.2, 0.8), (0.4, 0.8), (0.6, 0.8), (0.6, 1.0), (0.8, 1.0), (1.0, 1.0)]
AUC(사다리꼴) 0.800, 양성>음성 쌍 비율 0.800
예제 6.3.1

위 결과의 AUC와 그 뜻은?

풀이. 실행 결과 AUC 0.8과 '양성 점수가 음성보다 높은 쌍의 비율' 0.8이 같습니다. 무작위로 고른 양성·음성 쌍의 80%를 올바른 순서로 매깁니다. 문턱 하나의 정확도와 달리 문턱과 무관한 순위 능력을 요약합니다.

흔한 오해(1) "AUC가 높으면 어떤 문턱에서도 좋다": 운영할 문턱 근처 성능은 따로 봐야 합니다. (2) "불균형 자료에도 ROC가 충분": 양성이 아주 드물면 PR 곡선이 차이를 더 잘 보여 줍니다.
요약
  1. 문턱을 훑어 (FPR, TPR).
  2. AUC = P(양성 점수 > 음성 점수).
  3. 예: 0.8. 불균형에는 PR 곡선.
