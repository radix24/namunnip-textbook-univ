최대 마진 분류기

본문
이 절에서 배울 것
  • 선형 분류 경계 wᵀx + b = 0과 마진 2/‖w‖를 정의한다.
  • 최대 마진 문제 \(\min\frac12\|w\|^2\), \(y_i(w^Tx_i + b) \ge 1\)을 세운다.
  • 서포트 벡터와 소프트 마진(C)의 역할을 안다.
먼저 알아야 할 것
  • 볼록 최적화와 쌍대 (전전20 3.2절, 4.2절), 점과 평면 사이 거리.

3.1.1마진

분리 가능한 자료를 나누는 직선은 무수히 많습니다. SVM은 두 집단의 가장 가까운 점까지의 거리(마진)가 가장 큰 경계를 고릅니다. 가까운 점에서 \(|w^Tx + b| = 1\)이 되도록 크기를 정하면 마진 폭은 \(2/\|w\|\)이므로

\[ \min_{w, b}\ \frac12\|w\|^2 \quad\text{s.t.}\quad y_i(w^Tx_i + b) \ge 1. \]

볼록 이차 계획 문제라 해가 하나이고, 해는 경계에 닿은 소수의 점(서포트 벡터)만으로 정해집니다.

예제 3.1.1

점 (0, 0)은 −1, (2, 2)는 +1이다. 최대 마진 경계와 마진 폭은?

풀이. 대칭성으로 w는 (1, 1) 방향, 경계는 두 점의 수직 이등분선 x₁ + x₂ = 2. 조건 \(w^T(2, 2) + b = 1\), \(b = -1\) → w = (0.5, 0.5), b = −1. 마진 폭 \(2/\|w\| = 2/0.707 = 2.83\)으로 두 점 사이 거리와 같습니다.

겹치는 자료에는 여유 변수 ξᵢ를 허용하고 \(C\sum\xi_i\)를 벌점으로 더합니다(소프트 마진). C가 크면 훈련 오류를 적게, 작으면 마진을 넓게 합니다.

흔한 오해(1) "모든 훈련 점이 경계를 정한다": 서포트 벡터만 정합니다(나머지 점을 지워도 같은 해). (2) "SVM은 확률을 낸다": 기본적으로 부호만 내며, 확률은 따로 보정해야 합니다.
요약
  1. 마진 폭 2/‖w‖, min ½‖w‖², yᵢ(wᵀxᵢ + b) ≥ 1.
  2. 해는 서포트 벡터로만 정해진다.
  3. 소프트 마진 C: 훈련 오류와 마진의 절충.
