계산 그래프로 보는 역전파

본문
이 절에서 배울 것
  • 연산을 노드로 나눈 계산 그래프에서 연쇄 법칙으로 기울기를 뒤에서부터 구한다.
  • 뉴런 하나(선형, 시그모이드, 제곱 손실)의 기울기를 손으로 계산한다.
  • 역전파의 비용이 순전파와 같은 차수임을 안다.
먼저 알아야 할 것
  • 연쇄 법칙(공통 미분), 로지스틱 회귀 기울기 (전전20 5.1절).

4.1.1연쇄 법칙을 그래프로

\(z = wx + b\), \(a = \sigma(z)\), \(L = \frac12(a - y)^2\). 순전파로 z, a, L을 계산해 저장한 뒤, 뒤에서부터 국소 미분을 곱해 갑니다.

\[ \frac{\partial L}{\partial a} = a - y,\quad \frac{\partial L}{\partial z} = \frac{\partial L}{\partial a}\sigma'(z) = (a - y)a(1 - a),\quad \frac{\partial L}{\partial w} = \frac{\partial L}{\partial z}x,\quad \frac{\partial L}{\partial b} = \frac{\partial L}{\partial z}. \]
예제 4.1.1

x = 2, y = 1, w = 0.5, b = 1에서 L과 ∂L/∂w, ∂L/∂b를 구하라.

풀이. z = 2, a = σ(2) = 0.8808, L = ½(0.1192)² = 0.00710. ∂L/∂a = −0.1192, σ' = a(1 − a) = 0.1050, ∂L/∂z = −0.01252, ∂L/∂w = −0.02503, ∂L/∂b = −0.01252. 음수라 w, b를 키우면 손실이 줄어듭니다.

층이 많아도 같은 방식입니다. 한 노드에서 여러 갈래로 나간 값은 돌아오는 기울기를 더합니다. 순전파의 중간값을 저장해 다시 쓰므로 전체 비용이 순전파의 몇 배 정도이고, 이것이 수백만 개 매개변수를 학습할 수 있는 이유입니다.

흔한 오해(1) "역전파는 학습 알고리즘이다": 기울기를 계산하는 방법이며, 갱신은 경사하강(또는 Adam)이 합니다. (2) "시그모이드를 깊게 쌓아도 기울기가 잘 전달된다": σ' ≤ 0.25가 곱해져 기울기가 사라질 수 있어 ReLU 등을 씁니다.
요약
  1. 순전파로 중간값 저장, 역방향으로 국소 미분 곱.
  2. 예: ∂L/∂w = −0.0250, ∂L/∂b = −0.0125.
  3. 갈래가 합쳐지면 기울기를 더한다. 비용은 순전파 수준.

4.1.2연습문제

기본

  1. σ(0)에서 σ'(0)은?
    답

    0.25.

응용

  1. 예제에서 y = 0이면 ∂L/∂b는?
    답

    0.8808 × 0.1050 ≈ 0.0925.

심화

  1. ReLU의 기울기는?
    답

    z > 0이면 1, z < 0이면 0.
