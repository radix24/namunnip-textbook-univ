차수를 올리면 학습 오차는 줄지만

탐구 · 편향-분산 트레이드오프

질문

다항식 차수를 올리면 학습 자료에는 점점 더 잘 맞습니다. 새 자료(검증 자료)에서도 그럴까요?

준비

참 곡선 \(\sin2\pi x\)에 잡음을 더한 학습 점 12개에 최소제곱 다항식을 맞추고, 같은 방식으로 만든 검증 점 60개로 오차를 잽니다(1.2절). 잡음은 고정한 난수열에 σ를 곱한 것이라, σ를 바꿔도 잡음의 모양은 같습니다.

해 보기와 설명

  1. 처음 화면3차: 학습 MSE 0.0125, 검증 MSE 0.0590. 차수 0~9 중 검증 MSE가 가장 작은 것이 3차입니다.
  2. 너무 단순1차면 학습 0.2024, 검증 0.2601로 둘 다 큽니다(편향, 과소적합).
  3. 너무 복잡9차면 학습 0.0070으로 더 작아지지만 검증 0.1082로 커집니다(분산, 과적합). 곡선이 점 사이에서 출렁입니다.
  4. 정규화9차에 λ = 0.01을 고르면 검증 MSE가 0.0689로 줄어듭니다. 잡음을 0.5로 키우면 모든 차수의 검증 오차가 커지고 바닥(잡음 분산 0.25 근처)에 가까워집니다.

연결과 적용

모델 크기, 정규화 세기, 학습을 멈출 시점을 검증 오차로 고르는 것이 모두 이 그림에서 나옵니다.

흔한 오해

  • "학습 오차가 작을수록 좋은 모델이다." 9차처럼 학습 오차가 가장 작아도 새 자료에서는 나쁠 수 있습니다.
  • "잡음이 크면 더 복잡한 모델이 필요하다." 잡음이 클수록 복잡한 모델은 잡음을 외워 손해가 커집니다.
