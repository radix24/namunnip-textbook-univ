EM 알고리즘 한 단계 계산

본문
이 절에서 배울 것
  • 가우스 혼합의 E 단계(책임도)와 M 단계(평균 갱신)를 손으로 계산한다.
  • 반복할수록 로그 가능도가 줄지 않음을 안다.
  • k-평균과의 차이를 수치로 본다.
먼저 알아야 할 것
  • k-평균과 GMM (5.1절), Bayes 정리.

5.3.1부드러운 할당

E 단계: 점 x가 성분 k에서 왔을 사후 확률 \(r_k(x) \propto \pi_kN(x;\mu_k,\sigma_k^2)\). M 단계: \(\mu_k = \sum r_k(x)x/\sum r_k(x)\). 둘을 번갈아 하면 로그 가능도가 단조 증가합니다.

import math
xs = [1.0, 2.0, 4.0, 5.0]
mu = [1.5, 4.5]; sig = 1.0; pi = [0.5, 0.5]
N = lambda x, m: math.exp(-(x - m) ** 2 / (2 * sig ** 2))
for it in range(3):
    r = [pi[0] * N(x, mu[0]) / (pi[0] * N(x, mu[0]) + pi[1] * N(x, mu[1])) for x in xs]
    mu = [sum(ri * x for ri, x in zip(r, xs)) / sum(r),
          sum((1 - ri) * x for ri, x in zip(r, xs)) / sum(1 - ri for ri in r)]
    print(f"반복 {it + 1}: 책임도 {[round(v, 4) for v in r]}, 평균 {[round(m, 4) for m in mu]}")

실행 결과(Python 3.12에서 실제 실행):

반복 1: 책임도 [0.9975, 0.9526, 0.0474, 0.0025], 평균 [1.5524, 4.4476]
반복 2: 책임도 [0.997, 0.9476, 0.0524, 0.003], 평균 [1.5585, 4.4415]
반복 3: 책임도 [0.9969, 0.947, 0.053, 0.0031], 평균 [1.5592, 4.4408]
예제 5.3.1

위 첫 반복에서 x = 2의 책임도와 갱신된 평균은? k-평균이었다면?

풀이. x = 2: 0.9526(성분 1). 평균 (1.552, 4.448)로 처음(1.5, 4.5)보다 조금 서로 가까워졌습니다(가운데 점들이 반대 성분에도 조금 기여). k-평균은 0/1로 나눠 (1.5, 4.5)에서 바로 멈춥니다.

흔한 오해(1) "EM은 전역 최적을 보장": 국소 최적이라 시작점에 따라 다릅니다. (2) "책임도는 0 아니면 1": 그것은 k-평균이고, EM은 확률로 나눕니다.
요약
  1. E: r_k ∝ π_kN(x; μ_k, σ²).
  2. M: μ_k = Σr x/Σr.
  3. 로그 가능도 단조 증가, 국소 최적.
