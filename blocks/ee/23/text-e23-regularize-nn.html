신경망 학습 안정화: 드롭아웃과 정규화 층

본문
이 절에서 배울 것
  • 드롭아웃이 학습 때 뉴런을 무작위로 끄고 출력을 보정하는 방식을 안다.
  • 배치 정규화가 층 입력 분포를 맞춰 학습을 빠르게 하는 원리를 안다.
  • 학습·추론 모드의 차이를 안다.
먼저 알아야 할 것
  • CNN 학습 (4.2절), 과적합 (1.2절).

4.4.1두 기법

드롭아웃: 학습 때 각 뉴런을 확률 p로 0으로 만들고 남은 출력을 1/(1 − p)배 해 기댓값을 맞춥니다. 여러 작은 망을 평균하는 효과로 과적합을 줄입니다. 배치 정규화: 미니배치의 평균·분산으로 층 입력을 표준화하고 학습 가능한 크기·이동을 곱합니다. 추론 때는 학습 중 모은 이동 평균을 씁니다.

예제 4.4.1

드롭아웃 p = 0.5인 층의 어떤 뉴런 출력이 2.0이다. 학습 때와 추론 때 다음 층으로 가는 값은?

풀이. 학습: 확률 0.5로 0, 0.5로 2.0/(1 − 0.5) = 4.0 → 기댓값 2.0. 추론: 드롭아웃 없이 2.0. 보정 덕분에 추론 때 따로 크기를 맞출 필요가 없습니다.

흔한 오해(1) "추론 때도 드롭아웃을 켠다": 기본은 끄며, 켜면 결과가 매번 달라집니다. (2) "배치 정규화는 배치 크기와 무관": 배치가 아주 작으면 통계가 흔들려 다른 정규화(층 정규화)를 씁니다.
요약
  1. 드롭아웃: 확률 p로 끄고 1/(1 − p) 보정.
  2. 배치 정규화: 미니배치 표준화 + 크기·이동.
  3. model.eval()로 추론 모드.
