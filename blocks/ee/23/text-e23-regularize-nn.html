신경망 학습 안정화: 드롭아웃과 정규화 층

본문

큰 신경망은 훈련 자료를 금세 외워 버리고, 층이 깊어질수록 학습이 불안정해진다. 학습 중에 뉴런을 무작위로 꺼 버리거나, 층마다 입력을 다시 표준화하면 이 문제가 줄어든다고 한다. 뉴런을 끄는 것이 어떻게 도움이 될까? 그리고 학습 때와 추론 때 이 층들은 어떻게 다르게 동작할까?

먼저 알아야 할 것CNN 학습(4.2절), 과적합(1.2절)을 쓴다.

4.4.1드롭아웃

드롭아웃은 학습 때 각 뉴런을 확률 p로 0으로 만들고, 남은 출력을 1/(1 − p)배 해 기댓값을 맞춘다(그림 1). 그러면 망이 특정 뉴런 몇 개에 기대 훈련 자료를 외우기 어렵다. 즉 매 단계 다른 작은 망을 학습하는 셈이어서, 여러 망을 평균하는 효과로 과적합을 줄인다. 처음 질문의 첫째 답이 이것이다.

예제 4.4.1

드롭아웃 p = 0.5인 층의 어떤 뉴런 출력이 2.0이다. 학습 때와 추론 때 다음 층으로 가는 값은?

풀이. 학습 때는 확률 0.5로 0, 확률 0.5로 2.0/(1 − 0.5) = 4.0이 되어 기댓값이 2.0이다. 한편 추론 때는 드롭아웃 없이 2.0을 그대로 보낸다. 따라서 학습 때 미리 보정해 둔 덕분에, 추론 때 따로 크기를 맞출 필요가 없다.

배치 정규화

\[ \hat x = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \qquad y = \gamma\hat x + \beta \]

\(\mu_B\), \(\sigma_B^2\)는 미니배치의 평균과 분산이고, γ와 β는 학습하는 크기와 이동이다.

배치 정규화는 층 입력을 미니배치 통계로 표준화해, 앞 층이 바뀌어도 다음 층이 받는 분포가 크게 흔들리지 않게 한다. 그러면 더 큰 학습률로도 안정하게 학습한다. 그리고 추론 때는 미니배치 통계 대신 학습 중 모아 둔 이동 평균을 쓴다. 처음 질문의 둘째 답이 이것이다.

그래서 두 층 모두 학습 모드와 추론 모드가 다르며, 코드에서는 model.train()과 model.eval()로 바꾼다. 이 전환을 잊으면 같은 모델이 검증 때 전혀 다른 결과를 낸다.

흔한 오해추론 때도 드롭아웃을 켜 두는 것이 기본이라고 여기기 쉽다. 기본은 끄며, 켜 두면 같은 입력에도 결과가 매번 달라진다. 또 배치 정규화는 배치 크기와 무관하다고 생각하기 쉬운데, 배치가 아주 작으면 통계가 흔들리므로 층 정규화 같은 다른 정규화를 쓴다.
마무리

드롭아웃은 확률 p로 뉴런을 끄고 1/(1 − p)로 보정한다. 배치 정규화는 미니배치로 표준화한 뒤 크기와 이동을 학습한다. 추론 때는 model.eval()로 바꿔 두 층을 추론 모드로 둔다.

기본

  1. p = 0.2 드롭아웃의 보정 배수는?
    답

    1.25이다.

    답

    1이다.
