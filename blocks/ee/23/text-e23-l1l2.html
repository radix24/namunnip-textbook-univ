L1, L2 정규화의 효과 비교

본문

특징이 수천 개인 회귀 모델을 만들었더니 모든 계수가 조금씩 0이 아닌 값을 가져, 어떤 특징이 중요한지 알 수 없었다. 벌점을 바꿨더니 대부분의 계수가 정확히 0이 되고 몇 개만 남았다. 같은 "계수를 작게 하라"는 벌점인데 왜 이렇게 다르게 동작할까?

먼저 알아야 할 것정규화 최소제곱(전전20 2.1절, 5.2절)을 쓴다.

2.2.11변수에서 보기

최소제곱 해가 a인 가장 간단한 경우, \(\min_w \frac12(w - a)^2 + \text{벌점}\)을 풀어 두 벌점을 비교한다.

L2와 L1 정규화의 1변수 해

L2 벌점 \(\frac\lambda2w^2\)의 해는 \(w = a/(1 + \lambda)\)로, 언제나 0이 아니고 비율로 줄어든다.

L1 벌점 \(\lambda|w|\)의 해는 \(w = \text{sign}(a)\max(|a| - \lambda, 0)\)(연판정 임계)으로, |a| ≤ λ면 정확히 0이다.

즉 L2는 비율로 줄이고, L1은 일정한 양만큼 깎는다(그림 1). 처음 질문의 답이 이것이다. 그래서 L1을 쓰면 작은 계수들이 0이 되어 희소한 모델이 나온다.

예제 2.2.1

λ = 1에서 a = 3, a = 0.5일 때 L1, L2 해는?

풀이. a = 3이면 L2 해는 1.5, L1 해는 2이다. 그리고 a = 0.5이면 L2 해는 0.25, L1 해는 0이다. 즉 큰 계수는 L1이 덜 줄이고, 작은 계수는 L1이 아예 없앤다.

그러므로 특징이 수천 개인데 일부만 의미 있을 때 L1(라쏘)이 중요한 특징만 남긴다. 그런데 서로 비슷한 특징이 여럿이면 L1은 그 가운데 하나만 고르는 경향이 있다. 이때는 L2를 섞은 엘라스틱넷을 쓴다.

두 벌점의 차이는 2차원 그림으로도 볼 수 있다. 제곱 오차의 등고선이 L2 벌점의 원과 만나는 점은 대개 축 위에 있지 않지만, L1 벌점의 마름모와는 꼭짓점, 곧 한 좌표가 0인 점에서 만나기 쉽다. 차원이 높을수록 이런 꼭짓점과 모서리가 많아져 희소한 해가 더 흔해진다.

실제 계산에서는 L1 문제를 좌표 하강법으로 푼다. 계수 하나만 남기고 나머지를 고정하면 위의 1변수 문제가 되므로, 각 계수에 연판정 임계를 번갈아 적용하면 된다. 따라서 1변수 해가 곧 라쏘 알고리즘의 핵심 단계이다.

흔한 오해L2도 λ를 충분히 키우면 계수가 0이 된다고 여기기 쉽다. L2 해는 0에 가까워질 뿐 정확히 0이 되지는 않는다. 또 특징의 단위는 상관없다고 생각하기 쉬운데, 벌점은 계수 크기에 걸리므로 특징을 표준화한 뒤 적용해야 한다.
마무리

L2 정규화의 해는 a/(1 + λ)로 비율만큼 준다. L1 정규화는 연판정 임계로, |a| ≤ λ면 0이 되어 희소한 해를 준다. 특징을 표준화한 뒤 적용하며, 엘라스틱넷은 둘을 섞는다.

2.2.2연습문제

기본

  1. λ = 2, a = −5의 L1 해는?
    답

    −3이다.

응용

  1. λ = 2, a = −5의 L2 해는?
    답

    −5/3 ≈ −1.67이다.

심화

  1. L1 벌점이 0에서 미분 불가능한 것이 왜 희소성을 만드는가?
    답

    0에서 기울기가 [−λ, λ] 구간이라, 자료 쪽 기울기 |a|가 λ보다 작으면 0이 최적점이 되기 때문이다.
