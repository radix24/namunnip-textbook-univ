L1, L2 정규화의 효과 비교

본문
이 절에서 배울 것
  • L2는 가중치를 비율로 줄이고, L1은 일정량을 빼서 작은 가중치를 0으로 만드는 것을 1변수 예로 보인다.
  • L1의 희소성이 특징 선택에 쓰임을 안다.
  • 두 정규화를 섞은 엘라스틱넷의 동기를 안다.
먼저 알아야 할 것
  • 정규화 최소제곱 (전전20 2.1절, 5.2절).

2.2.11변수에서 보기

최소제곱 해가 a인 가장 간단한 경우 \(\min_w \frac12(w - a)^2 + \text{벌점}\)을 풉니다.

  • L2 (\(\frac\lambda2w^2\)): \(w = a/(1 + \lambda)\). 언제나 0이 아니고 비율로 줄어든다.
  • L1 (\(\lambda|w|\)): \(w = \text{sign}(a)\max(|a| - \lambda, 0)\)(연판정 임계). |a| ≤ λ면 정확히 0.
예제 2.2.1

λ = 1에서 a = 3, a = 0.5일 때 L1, L2 해는?

풀이. a = 3: L2 1.5, L1 2. a = 0.5: L2 0.25, L1 0. 큰 계수는 L1이 덜 줄이고, 작은 계수는 L1이 아예 없앱니다. 특징이 수천 개인데 일부만 의미 있을 때 L1(라쏘)이 중요한 특징만 남깁니다. 서로 비슷한 특징이 여럿이면 L1은 그중 하나만 고르는 경향이 있어, L2를 섞은 엘라스틱넷을 씁니다.

흔한 오해(1) "L2도 충분히 크면 0이 된다": 0에 가까워질 뿐 정확히 0은 아닙니다. (2) "특징의 단위는 상관없다": 정규화 벌점은 계수 크기에 걸리므로 특징을 표준화한 뒤 적용합니다.
요약
  1. L2: a/(1 + λ), 비율 축소.
  2. L1: 연판정 임계, |a| ≤ λ면 0(희소).
  3. 특징 표준화 후 적용, 엘라스틱넷은 둘을 섞음.

2.2.2연습문제

기본

  1. λ = 2, a = −5의 L1 해는?
    답

    −3.

응용

  1. λ = 2, a = −5의 L2 해는?
    답

    −5/3 ≈ −1.67.

심화

  1. L1 벌점이 0에서 미분 불가능한 것이 왜 희소성을 만드는가?
    답

    0에서 기울기가 [−λ, λ] 구간이라, 자료 쪽 기울기 |a|가 λ보다 작으면 0이 최적점이 되기 때문입니다.
