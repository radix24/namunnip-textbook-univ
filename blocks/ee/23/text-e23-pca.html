PCA로 차원 줄이기

본문
이 절에서 배울 것
  • 자료를 평균 중심화하고 공분산 행렬의 고유벡터로 주성분을 구한다.
  • 고유값 비율(설명된 분산)로 남길 차원을 정한다.
  • NumPy로 PCA를 계산하고 결과를 해석한다.
먼저 알아야 할 것
  • 고유값과 SVD (전전16 4.1절, 5.1절), 공분산 (전전11 3.1절).

5.2.1절차

(1) 각 특징의 평균을 뺀다. (2) 공분산 \(C = X_c^TX_c/(n - 1)\)를 구한다. (3) 고유값이 큰 순서로 고유벡터를 고른다. (4) 자료를 그 방향에 정사영한다. 첫 주성분은 분산이 가장 큰 방향, 다음은 그와 직교하면서 남은 분산이 가장 큰 방향입니다.

예제 5.2.1(실습)

2차원 점 8개의 주성분을 계산하고 1차원으로 줄여라.

import numpy as np
X = np.array([[2.0, 1.9], [0.5, 0.7], [2.2, 2.6], [1.9, 2.2], [3.1, 3.0], [2.3, 2.7], [1.0, 1.1], [1.5, 1.6]])
Xc = X - X.mean(axis=0)
C = Xc.T @ Xc / (len(X) - 1)
w, V = np.linalg.eigh(C)
order = np.argsort(w)[::-1]; w, V = w[order], V[:, order]
if V[0, 0] < 0: V[:, 0] *= -1
print("공분산 행렬:\n", np.round(C, 4))
print("고유값:", np.round(w, 4))
print("첫째 주성분 방향:", np.round(V[:, 0], 4))
print("설명된 분산 비율:", np.round(w / w.sum(), 4))
z = Xc @ V[:, 0]
print("1차원 좌표(앞 3개):", np.round(z[:3], 4))

실행 결과(Python 3.12에서 실제 실행):

공분산 행렬:
 [[0.6527 0.6318]
 [0.6318 0.6507]]
고유값: [1.2835 0.0199]
첫째 주성분 방향: [0.7077 0.7066]
설명된 분산 비율: [0.9847 0.0153]
1차원 좌표(앞 3개): [ 0.0797 -1.8297  0.7158]

해석. 첫째 주성분 (0.71, 0.71)은 두 특징이 함께 커지는 방향이고, 분산의 98.5%를 설명합니다. 둘째 방향의 1.5%는 대부분 잡음으로 보고 버려도 정보 손실이 작습니다. 특징 단위가 다르면 먼저 표준화(분산 1)해야 단위가 큰 특징이 주성분을 독차지하지 않습니다.

흔한 오해(1) "PCA는 분류에 유용한 방향을 찾는다": 분산이 큰 방향일 뿐 레이블을 보지 않습니다. (2) "주성분의 부호에 의미가 있다": 고유벡터의 부호는 임의입니다(코드에서 맞춰 줌).
요약
  1. 중심화 → 공분산 → 고유벡터 → 정사영.
  2. 설명된 분산 비율로 차원 선택(예: 98.5%).
  3. 단위가 다르면 표준화 먼저. 레이블은 보지 않음.

5.2.2연습문제

기본

  1. 고유값 3, 1이면 첫 주성분의 설명된 분산은?
    답

    75%.

응용

  1. 공분산 [[2, 1], [1, 2]]의 첫 주성분 방향은?
    답

    (1, 1)/√2.

심화

  1. 100차원 자료의 고유값 누적 비율이 10개에서 95%라면 무엇을 뜻하는가?
    답

    자료가 대략 10차원 부분공간 근처에 있어 10차원으로 줄여도 분산 손실이 5%입니다.
