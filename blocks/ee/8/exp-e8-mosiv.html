출력 특성 곡선 위의 동작점

탐구 · 포화와 트라이오드를 가르는 부하선

질문

같은 MOSFET, 같은 게이트 전압이어도 드레인 저항을 바꾸면 동작 영역이 바뀐다. 그 경계는 그래프에서 어디일까?

준비

2.1절 예제 2.1.1의 회로입니다(\(k_n = 2\) mA/V², \(V_t = 0.5\) V, \(V_{DD} = 3\) V). 곡선은 \(v_{GS} = 0.7\)~1.2 V의 \(i_D\)-\(v_{DS}\) 특성, 점선 포물선 \(i_D = \frac12k_nv_{DS}^2\)는 트라이오드와 포화의 경계(\(v_{DS} = v_{OV}\)), 주황 점선은 부하선 \(i_D = (V_{DD} - v_{DS})/R_D\)이다. 교점(빨간 점)이 동작점이다.

해 보기와 설명

  1. 예제 (가)처음 화면: \(V_{DS} = 1.5\) V, \(I_D = 0.25\) mA, 포화. 동작점이 곡선의 평평한 부분에 있다.
  2. 예제 (나)\(R_D = 12\) kΩ: 부하선이 누워 교점이 경계 포물선 왼쪽(트라이오드)으로 간다. \(V_{DS} = 0.333\) V, \(I_D = 0.222\) mA.
  3. 게이트 전압\(R_D = 6\) kΩ에서 \(v_{GS} = 1.2\) V이면 \(I_D = 0.426\) mA, \(V_{DS} = 0.446\) V로 트라이오드, 0.8 V이면 0.090 mA, 2.46 V로 포화이다. 0.4 V에서는 차단이다.
  4. λλ = 0.1이면 포화 곡선이 오른쪽으로 올라가 기울어지고, 동작점이 \(V_{DS} = 1.304\) V, \(I_D = 0.283\) mA로 바뀝니다(2.1절 연습 4).

연결과 적용

증폭기로 쓰려면 동작점이 포화 영역의 가운데쯤에 있어야 신호가 오르내려도 트라이오드나 차단으로 넘어가지 않습니다(4단원). 디지털 스위치로 쓸 때는 반대로 트라이오드 깊숙이(낮은 \(V_{DS}\))와 차단 두 점만 쓴다.

흔한 오해

  • "게이트 전압을 올리면 언제나 증폭이 잘 된다." 전류가 늘어 \(R_D\)의 전압 강하가 커지면 \(V_{DS}\)가 줄어 트라이오드로 들어간다. 위 3번에서 1.2 V가 그 예이다.
