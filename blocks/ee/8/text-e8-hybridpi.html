BJT 소신호 모델: 하이브리드 π와 T 모델

본문
이 절에서 배울 것
  • 지수 관계를 동작점에서 선형화해 \(g_m = I_C/V_T\)를 유도한다.
  • \(r_\pi = \beta/g_m\), \(r_e = \alpha/g_m\), \(r_o = V_A/I_C\)를 정의하고 하이브리드 π 모델과 T 모델을 그린다.
  • BJT와 MOSFET의 소신호 변수를 비교한다.
먼저 알아야 할 것
  • BJT 전류식 (3.1절), MOSFET 소신호 모델 (2.3절).

3.2.1gm의 유도

구하려는 것: \(v_{be}\)가 \(i_c\)를 얼마나 바꾸는가. \(v_{BE} = V_{BE} + v_{be}\)를 넣으면 \(i_C = I_Se^{V_{BE}/V_T}e^{v_{be}/V_T} = I_Ce^{v_{be}/V_T}\)입니다. \(|v_{be}| \ll V_T\)이면 \(e^x \approx 1 + x\)로

\[ i_C \approx I_C + \frac{I_C}{V_T}v_{be}, \qquad g_m = \frac{I_C}{V_T}. \]

소신호 조건(BJT): \(|v_{be}| \ll V_T\) (보통 10 mV 이하). MOSFET(\(\ll 2V_{OV}\), 수십~수백 mV)보다 훨씬 좁다.

\(I_C = 1\) mA이면 \(g_m = 40\) mA/V입니다. 같은 1 mA의 MOSFET(\(V_{OV} = 0.2\) V)은 \(g_m = 10\) mA/V이므로, 같은 전류에서 BJT의 \(g_m\)이 몇 배 큽니다. 이것이 BJT가 저잡음·고이득 아날로그 회로에서 여전히 쓰이는 이유입니다. 대신 소신호 범위가 좁습니다.

3.2.2입력 저항과 출력 저항

MOSFET과 달리 BJT는 베이스 전류가 있으므로 베이스에서 본 입력 저항이 유한합니다. \(i_b = i_c/\beta = g_mv_{be}/\beta\)이므로

베이스 입력 저항 \(r_\pi = \dfrac{v_{be}}{i_b} = \dfrac{\beta}{g_m} = \dfrac{V_T}{I_B}\).

이미터 저항 \(r_e = \dfrac{v_{be}}{i_e} = \dfrac{\alpha}{g_m} = \dfrac{V_T}{I_E} \approx \dfrac1{g_m}\). 이미터에서 들여다본 저항.

출력 저항 \(r_o = V_A/I_C\). Early 효과에서.

관계 \(r_\pi = (\beta + 1)r_e\)를 기억하면 좋습니다. 이미터에 있는 저항은 베이스에서 보면 \(\beta + 1\)배로 커 보입니다(베이스 전류가 이미터 전류의 \(1/(\beta + 1)\)이기 때문). 이 "저항 반사 규칙"은 4단원에서 계속 씁니다.

3.2.3두 가지 등가회로

하이브리드 π 모델: B-E 사이 \(r_\pi\), C-E 사이 전류원 \(g_mv_\pi\)와 병렬 \(r_o\). 이미터가 접지된(공통 이미터) 회로에 편하다.

T 모델: 이미터 쪽에 \(r_e\), 컬렉터에 전류원 \(\alpha i_e\)(또는 \(g_mv_\pi\)), 베이스로는 \(i_b = i_e/(\beta + 1)\)이 흐름. 이미터에 저항이 달리거나 이미터로 신호가 들어가는 회로(공통 베이스, 이미터 폴로어)에 편하다.

둘은 같은 소자의 같은 표현이므로 어느 것을 써도 결과는 같습니다. 계산이 간단한 쪽을 고릅니다. MOSFET 모델은 \(\beta \to \infty\)(\(r_\pi \to \infty\))로 둔 경우와 같습니다.

예제 3.2.1

예제 3.1.1의 동작점(\(I_C = 0.9\) mA, β = 100)에서 \(g_m, r_\pi, r_e\)를 구하고, \(V_A = 50\) V일 때 \(r_o\)를 구하여라. \(R_E\)를 축전기로 바이패스하고 \(v_{be}\)에 직접 신호를 넣으면 컬렉터 전압 이득은?

풀이. \(g_m = 0.9/0.025 = 36\) mA/V, \(r_\pi = 100/36 = 2.78\) kΩ, \(r_e = 0.990/36 \approx 27.5\) Ω, \(r_o = 50/0.9 \approx 55.6\) kΩ. 공통 이미터 이득 \(-g_m(R_C \parallel r_o) = -36 \times (4.7 \parallel 55.6) = -36 \times 4.33 \approx -156\). 바이패스하지 않고 \(R_E = 3.3\) kΩ이 신호에도 있으면 이득은 약 \(-R_C/(r_e + R_E) \approx -1.4\)로 크게 줄어듭니다(4단원).

\(r_\pi\)가 2.78 kΩ이고 바이어스의 \(R_B = 33.3\) kΩ과 병렬이므로, 신호원이 보는 입력 저항은 약 2.57 kΩ입니다. MOSFET 증폭기의 수 MΩ과 대조적입니다.

흔한 오해(1) \(g_m = \beta/r_\pi\)를 \(g_m = r_\pi/\beta\)로 뒤집는 실수: 단위를 보면 \(g_m\)은 컨덕턴스(1/Ω)입니다. (2) "\(g_m\)이 β에 비례한다": \(g_m = I_C/V_T\)는 β와 무관합니다. β가 바꾸는 것은 \(r_\pi\)입니다. (3) 10 mV를 넘는 \(v_{be}\)에 소신호 이득을 그대로 쓰는 실수: 20 mV만 되어도 지수의 2차 항이 약 \(\frac12 \cdot 0.8 = 40\)%까지 커져 왜곡이 심합니다.
요약
  1. \(g_m = I_C/V_T\) (1 mA에서 40 mA/V). 소신호 조건 \(|v_{be}| \ll V_T\).
  2. \(r_\pi = \beta/g_m\), \(r_e = \alpha/g_m\), \(r_\pi = (\beta + 1)r_e\), \(r_o = V_A/I_C\).
  3. 하이브리드 π(공통 이미터)와 T 모델(이미터에 무언가 있을 때). MOSFET은 \(r_\pi = \infty\).

3.2.4연습문제

기본

  1. \(I_C = 0.25\) mA, β = 200일 때 \(g_m, r_\pi, r_e\)는?
    답

    10 mA/V, 20 kΩ, 약 99.5 Ω.

응용

  1. BJT의 고유 이득 \(g_mr_o\)를 \(V_A\)로 쓰고, \(V_A = 100\) V일 때 값을 구하여라. MOSFET(2.3절 연습 4)과 비교하여라.
    답

    \(g_mr_o = V_A/V_T = 4000\). MOSFET은 \(2/(\lambda V_{OV})\), 예: λ = 0.1, \(V_{OV} = 0.2\)이면 100. BJT가 훨씬 큽니다.

  2. 이미터에 100 Ω이 있을 때 베이스에서 본 저항(β = 100, \(r_e = 25\) Ω)은?
    답

    \((\beta + 1)(r_e + 100) = 101 \times 125 \approx 12.6\) kΩ.

심화

  1. \(v_{be} = V_p\cos\omega t\)일 때 \(i_c\)의 2차 고조파와 기본파의 비를 \(V_p/V_T\)로 구하고, 1% 왜곡의 \(V_p\)를 구하여라.
    답

    \(e^x \approx 1 + x + x^2/2\), \(x^2/2 = \frac{V_p^2}{4V_T^2}(1 + \cos2\omega t)\). 비 \(V_p/(4V_T)\). 1%면 \(V_p = 1\) mV. MOSFET(\(V_p/4V_{OV}\))과 같은 꼴에서 \(V_{OV}\) 자리에 \(V_T\)가 들어갑니다.
