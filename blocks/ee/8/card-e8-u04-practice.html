단일 트랜지스터 증폭기 연습 문제

문제 7 · 계산·설계·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산CS 증폭기: \(g_m = 3\) mA/V, \(R_D = 8\) kΩ, \(r_o = 40\) kΩ, \(R_L = 20\) kΩ, \(R_{sig} = 10\) kΩ, \(R_G = 2\) MΩ. \(G_v\)는? [04-01]

    힌트 1

    \(A_{vo} = -g_m(R_D \parallel r_o)\).

    힌트 2

    출력 분압 \(R_L/(R_L + R_{out})\).

    풀이

    \(R_D \parallel r_o = 6.67\) kΩ, \(A_{vo} = -20\). 입력 분압 \(2000/2010 = 0.995\), 출력 분압 \(20/26.67 = 0.75\). \(G_v \approx -14.9\). (같은 결과: \(-g_m(R_D \parallel r_o \parallel R_L) = -3 \times 5 = -15\)에 0.995.)

  2. 계산이미터 폴로어: \(I_C = 5\) mA, β = 100, \(R_L = 100\) Ω, \(R_{sig} = 5\) kΩ. \(R_{in}\), \(A_v\), \(R_{out}\), \(G_v\)는? [04-01]

    힌트 1

    \(r_e \approx 5\) Ω.

    힌트 2

    \(R_{in} = (\beta + 1)(r_e + R_L)\).

    풀이

    \(R_{in} = 101 \times 105 \approx 10.6\) kΩ, \(A_v = 100/105 = 0.952\), \(R_{out} = 5 + 5000/101 \approx 54.5\) Ω. \(G_v = \frac{10.6}{15.6} \times 0.952 \approx 0.647\).

  3. 계산CG 증폭기: \(g_m = 4\) mA/V, \(R_D = 5\) kΩ, 신호원 \(R_{sig} = 250\) Ω, \(R_L = \infty\). \(G_v\)는? [04-01]

    힌트 1

    \(R_{in} = 1/g_m = 250\) Ω.

    힌트 2

    입력 분압 1/2.

    풀이

    \(\frac12 \times 20 = +10\).

  4. 판단학생이 "이득 −50인 CE 단 뒤에 이득 0.95인 폴로어를 달면 이득이 줄어드니 손해다"라고 했다. 부하가 1 kΩ, CE의 \(R_C\)가 10 kΩ일 때 평가하여라. [04-02]

    힌트 1

    폴로어 없이 1 kΩ을 직접 달면 출력 분압은?

    힌트 2

    1/11.

    풀이

    폴로어 없이: \(-50 \times 1/11 \approx -4.5\). 폴로어(입력 저항이 충분히 크다고 보고) 있으면: \(-50 \times 0.95 \approx -47.5\). 폴로어가 10배 넘게 이득이다. 개방 이득만 보면 오판한다.

  5. 설계\(g_m = 2\) mA/V인 CS에 소스 저항을 남겨 \(A_{vo} = -5\)(\(R_D = 6\) kΩ)로 만들려면 \(R_S\)는? 이때 \(g_m\)의 ±20% 변화에 이득은 몇 % 변하는가? [04-01]

    힌트 1

    \(g_mR_D/(1 + g_mR_S) = 5\).

    힌트 2

    \(g_m = 1.6, 2.4\)에서 다시 계산.

    풀이

    \(12/(1 + 2R_S) = 5\) → \(R_S = 0.7\) kΩ. \(g_m = 1.6\): \(9.6/2.12 = 4.53\)(−9.4%), \(g_m = 2.4\): \(14.4/2.68 = 5.37\)(+7.5%). \(R_S\) 없이는 ±20% 그대로.

  6. 도전50 Ω 동축 케이블로 들어오는 신호를 받아 1 kΩ 부하에 이득 10 이상으로 보내야 한다. 구조와 대략의 \(g_m\), 저항을 제안하라. [04-02]

    힌트 1

    입력 저항을 50 Ω에 맞추면 반사가 없고 입력 분압은 1/2.

    힌트 2

    CG 뒤 폴로어.

    풀이

    CG(\(g_m = 20\) mA/V로 \(R_{in} = 50\) Ω) + 폴로어(\(g_m = 20\) mA/V, \(R_{out} = 50\) Ω). 필요한 이득: \(\frac12 \times A_{vo} \times \frac{1000}{1050} \ge 10\) → \(A_{vo} \ge 21\), \(R_D \ge 1.05\) kΩ. 예: \(R_D = 1.2\) kΩ이면 \(G_v \approx 11.4\). 큰 \(g_m\) 때문에 전류가 많이 듭니다(BJT면 0.5 mA로 \(g_m\) = 20 mA/V).

  7. 계산R = 5 kΩ, C = 2 μF의 f_L은? [04-03]

    힌트 1

    힌트 2

    풀이

    약 15.9 Hz.
