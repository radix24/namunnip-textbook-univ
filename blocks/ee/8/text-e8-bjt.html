본문

  • 다이오드 지수 모델 (1.1절), MOSFET 바이어스 (2.2절), Thevenin 등가 (전전3 3.2절).

3.1.1두 개의 pn 접합

BJT(쌍극성 접합 트랜지스터)는 n-p-n(또는 p-n-p) 세 층으로 된 소자로, 이미터(E), 베이스(B), 컬렉터(C) 세 단자가 있습니다. MOSFET보다 먼저 발명되었고(1947), 지금도 고주파·고정밀 아날로그 회로와 전력 회로에 씁니다. MOSFET이 게이트 "전압"으로 제어된다면, BJT는 베이스-이미터 "접합 전압"(따라서 작은 베이스 전류도 함께)으로 제어됩니다.

활성 영역: 베이스-이미터 접합 순방향(EBJ, \(v_{BE} \approx 0.7\) V), 베이스-컬렉터 접합 역방향(CBJ). 증폭에 쓰는 영역.

왜 컬렉터 전류가 생기는가: 순방향인 EBJ를 통해 이미터(고농도 n)의 전자가 베이스로 대량 주입됩니다. 베이스는 매우 얇고 도핑이 낮아서 전자 대부분이 재결합하기 전에 베이스를 건너 컬렉터 쪽 접합에 닿고, 역방향 CBJ의 전기장이 이들을 컬렉터로 쓸어 갑니다. 그래서 컬렉터 전류는 EBJ 전압으로 정해지고 컬렉터 전압과는 거의 무관합니다. 베이스로 들어가는 작은 전류는 베이스에서 재결합한 전자를 보충하는 정공과 베이스에서 이미터로 넘어가는 정공입니다.

3.1.2활성 영역의 전류식

\[ i_C = I_Se^{v_{BE}/V_T}, \qquad i_B = \frac{i_C}{\beta}, \qquad i_E = i_C + i_B = \frac{i_C}{\alpha}, \quad \alpha = \frac{\beta}{\beta + 1}. \]

공통 이미터 전류 이득 \(\beta\): 보통 50~300. 같은 형번이라도 소자마다, 온도와 전류에 따라 크게 다르다.

공통 베이스 전류 이득 \(\alpha\): 1보다 조금 작다(β = 100이면 0.990).

Early 효과: \(v_{CE}\)가 오르면 실효 베이스 폭이 줄어 \(i_C\)가 조금 는다. \(i_C = I_Se^{v_{BE}/V_T}(1 + v_{CE}/V_A)\). MOSFET의 \(\lambda\)와 같은 역할.

\(i_C\)는 \(v_{BE}\)의 지수함수이므로 1.1절 다이오드와 같은 규칙이 성립합니다: 전류 10배 ↔ \(v_{BE}\) 약 60 mV. 그래서 손 계산에서는 \(V_{BE} \approx 0.7\) V로 둡니다.

3.1.3세 영역의 판정

차단: EBJ가 꺼짐(\(v_{BE} <\) 약 0.5 V). 모든 전류 0.

활성: EBJ 켜짐, \(v_{CE} \ge\) 약 0.3 V(CBJ가 크게 순방향이 되지 않음). \(i_C = \beta i_B\).

포화: EBJ와 CBJ 모두 순방향. \(v_{CE} \approx 0.1\)~0.2 V로 떨어지고 \(i_C < \beta i_B\). 스위치가 꽉 켜진 상태(MOSFET의 트라이오드에 해당).

판정 방법은 MOSFET과 같습니다: 활성을 가정하고 풀어 \(V_{CE} \ge 0.3\) V인지 확인합니다. 아니면 포화로 가정하고 \(V_{CE} = 0.2\) V로 다시 풀어 \(I_C/I_B < \beta\)인지 확인합니다.

3.1.4바이어스: β에 둔감하게

β는 소자마다 2~4배까지 다를 수 있습니다. 베이스 전류를 저항 하나로 정하는 고정 바이어스(\(I_B = (V_{CC} - 0.7)/R_B\))는 \(I_C = \beta I_B\)라 β에 정비례합니다. 그래서 MOSFET의 소스 저항과 같은 되먹임을 씁니다.

네 저항 바이어스: 분압기 \(R_1, R_2\)로 베이스, 이미터 저항 \(R_E\), 컬렉터 저항 \(R_C\).

구하려는 것: \(I_E\). 분압기를 Thevenin 등가 \(V_{BB} = V_{CC}\frac{R_2}{R_1 + R_2}\), \(R_B = R_1 \parallel R_2\)로 바꾸면 베이스-이미터 고리의 KVL은 \(V_{BB} = I_BR_B + V_{BE} + I_ER_E\)이고, \(I_B = I_E/(\beta + 1)\)이므로

\[ I_E = \frac{V_{BB} - V_{BE}}{R_E + R_B/(\beta + 1)}. \]

\(R_E \gg R_B/(\beta + 1)\)이면 β가 분모에서 사라져 \(I_E \approx (V_{BB} - V_{BE})/R_E\)입니다. 이것이 설계 조건입니다(예: \(R_B\)를 \(R_E\)의 10배 이하로).

예제 3.1.1

\(V_{CC} = 12\) V, \(R_1 = 100\) kΩ, \(R_2 = 50\) kΩ, \(R_E = 3.3\) kΩ, \(R_C = 4.7\) kΩ. β = 50, 100, 200일 때 \(I_C\)와 \(V_{CE}\)를 구하고, 같은 \(I_C\)(β = 100에서 0.9 mA)를 내는 고정 바이어스와 비교하여라.

풀이. \(V_{BB} = 4\) V, \(R_B = 33.3\) kΩ. β = 100: \(I_E = \frac{3.3}{3.3 + 0.33} = 0.909\) mA, \(I_C = 0.900\) mA, \(V_C = 12 - 0.9 \times 4.7 = 7.77\) V, \(V_E = 3.00\) V, \(V_{CE} = 4.77\) V(활성).

β가 4배 범위로 변해도 네 저항 바이어스의 \(I_C\)는 β = 100 값의 −9%~+5% 안에 있지만, 고정 바이어스(\(R_B = 1.26\) MΩ)는 그대로 4배 변합니다. 고정 바이어스에서 β = 200이면 \(V_{CE} = 12 - 1.8 \times 4.7 = 3.5\) V로 줄고, \(R_E\)가 없으니 β가 더 크면 포화로 들어갈 수도 있습니다.

흔한 오해(1) "β가 크면 좋은 트랜지스터라 \(I_C\)를 β로 계산하면 된다": β는 믿을 수 없는 값이라 설계는 β에 둔감하게 해야 합니다. (2) BJT 포화를 MOSFET 포화와 혼동하기: BJT 포화는 증폭이 안 되는 영역입니다. (3) 베이스 전류를 무시하고 분압비로만 \(V_B\)를 계산하는 근사는 \(R_B \ll (\beta + 1)R_E\)일 때만 맞습니다. 예제에서는 \(R_B/(\beta + 1) = 0.33\) kΩ이 \(R_E\)의 10%라 \(I_E\)를 1.0 mA로 약 10% 크게 어림하게 됩니다.
요약
  1. 활성: \(i_C = I_Se^{v_{BE}/V_T}\), \(i_B = i_C/\beta\), \(i_E = i_C/\alpha\). \(V_{BE} \approx 0.7\) V.
  2. 활성 가정 → \(V_{CE} \ge 0.3\) V 확인. 아니면 포화(\(V_{CE} \approx 0.2\) V, \(i_C < \beta i_B\)).
  3. 네 저항 바이어스 \(I_E = (V_{BB} - V_{BE})/(R_E + R_B/(\beta + 1))\). \(R_E \gg R_B/(\beta + 1)\)이면 β에 둔감.

3.1.5연습문제

기본

  1. β = 150일 때 α는? \(I_C = 3\) mA이면 \(I_B\), \(I_E\)는?
    답

    α = 0.9934, \(I_B = 20\) μA, \(I_E = 3.02\) mA.

  2. 1 mA에서 \(V_{BE} = 0.70\) V인 BJT의 0.1 mA에서 \(V_{BE}\)는?
    답

    약 0.642 V.

응용

  1. \(V_{CC} = 5\) V, \(R_B = 43\) kΩ(베이스를 5 V에 연결), \(R_C = 1\) kΩ, β = 100. 영역과 \(I_C\)는?
    답

    \(I_B = 0.1\) mA, 활성 가정이면 \(I_C = 10\) mA, \(V_{CE} = -5\) V로 모순. 포화: \(I_C = (5 - 0.2)/1 = 4.8\) mA, \(I_C/I_B = 48 < 100\) 확인. 스위치로 켜진 상태.

심화

  1. 예제 3.1.1에서 \(R_1, R_2\)를 각각 10배(1 MΩ, 500 kΩ)로 하면 β = 50과 200 사이 \(I_C\) 변화는?
    답

    \(R_B = 333\) kΩ. β = 50: \(I_E = 3.3/(3.3 + 6.54) = 0.335\) mA, β = 200: \(3.3/(3.3 + 1.66) = 0.665\) mA. 두 배 차이로 β 둔감성이 사라집니다. 분압 저항을 너무 크게 하면 안 되는 이유입니다.
