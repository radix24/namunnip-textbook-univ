기타 픽업 앞단: BJT로 받을까 MOSFET으로 받을까

예제 · 신호원 저항과 입력 저항

먼저 예측

출력 저항이 약 100 kΩ인 기타 픽업을 공통 이미터 증폭기(\(I_C = 1\) mA, 개방 이득 −200)에 바로 연결하면 전체 이득은 얼마쯤일까요?

생각해 본 뒤 열기

약 −3에 불과합니다. 입력 저항이 2.5 kΩ이라 신호의 97% 이상이 픽업 내부 저항에서 사라집니다.

문제

신호원 \(R_{sig} = 100\) kΩ(가상의 수동 픽업), 다음 단 입력 \(R_L = 10\) kΩ. 후보: (A) CE 한 단(\(I_C = 1\) mA, β = 100, \(R_C = 5\) kΩ, \(R_E\) 바이패스), (B) CS 한 단(\(g_m = 2\) mA/V, \(R_D = 5\) kΩ, \(R_G = 1\) MΩ), (C) CC(이미터 폴로어, \(I_C = 1\) mA, 이미터 저항이 곧 부하) 뒤에 CE. 각 \(G_v\)를 구하고 고르라.

전략

  1. \(G_v = \frac{R_{in}}{R_{in} + R_{sig}}A_{vo}\frac{R_L}{R_L + R_{out}}\)을 각 후보에 적용한다.
  2. (C)는 폴로어의 입력 저항이 뒤 단의 입력 저항을 \(\beta + 1\)배로 키운다는 점을 쓴다.

풀이

  1. (A) \(r_\pi = 2.5\) kΩ, \(A_{vo} = -40 \times 5 = -200\), \(R_{out} = 5\) kΩ. \(G_v = \frac{2.5}{102.5}(-200)\frac{10}{15} \approx -3.25\). 입력 분압이 0.024
  2. (B) \(R_{in} = 1\) MΩ, \(A_{vo} = -10\), \(R_{out} = 5\) kΩ. \(G_v = \frac{1000}{1100}(-10)\frac{10}{15} \approx -6.06\). 입력 손실 9%
  3. (C) 뒤 CE의 \(r_\pi = 2.5\) kΩ이 폴로어의 부하. 폴로어 \(R_{in} = 101 \times (25 + 2500) \approx 255\) kΩ, 이득 \(\frac{2500}{2525} = 0.990\). \(G_v = \frac{255}{355}(0.990)(-200)\frac{10}{15} \approx -94.8\). 입력 저항을 키운 뒤 증폭

의미

같은 CE 단인데 앞에 폴로어를 하나 두었을 뿐으로 이득이 약 29배가 되었습니다. 폴로어가 큰 신호원 저항과 작은 입력 저항 사이의 "임피던스 변환기" 역할을 했기 때문입니다. 실제 기타 앞단(버퍼, 이펙터 입력)이 입력 저항 1 MΩ 정도로 만들어지는 이유입니다. MOSFET(또는 JFET) 한 단(B)도 입력은 좋지만 \(g_m\)이 작아 이득이 작으므로, 이득이 더 필요하면 (B) 뒤에 단을 더합니다.

검산

(C)에서 폴로어 입력 저항은 바이어스 저항과 병렬이 되므로 실제로는 더 작습니다(예: 바이어스 \(R_B = 470\) kΩ이면 \(255 \parallel 470 \approx 165\) kΩ, \(G_v\)는 약 −82). 바이어스 저항까지 넣는 것을 잊지 않아야 합니다.

이해 확인

(A)에서 β = 300인 BJT로 바꾸면 \(G_v\)는?

답

\(r_\pi = 7.5\) kΩ, \(\frac{7.5}{107.5}(-200)(0.667) \approx -9.3\). β를 키워도 입력 손실이 여전히 큽니다.

신호원 저항이 크고 부하 저항도 작은 경우, 이득 단과 폴로어를 어떻게 배치해야 하는가?
