MOSFET 소신호 모델: gm과 ro

본문

포화 영역의 MOSFET은 전류가 게이트 전압의 제곱으로 정해지는 비선형 소자이다. 그런데 증폭기를 설계할 때는 옴의 법칙처럼 "이득 = 몇 배"라는 한 숫자로 말한다. 비선형 소자에서 어떻게 일정한 이득이 나올까? 그 숫자는 신호가 얼마나 작을 때까지 믿을 수 있을까?

먼저 알아야 할 것MOSFET 전류식(2.1절), 바이어스(2.2절), 다이오드 소신호 \(r_d\)(1.1절), 중첩의 원리(전전3 3.1절), 종속 전원(전전3 1.2절)을 쓴다.

2.3.1작은 신호에서는 선형이다

포화 영역의 MOSFET은 제곱 법칙을 따르는 비선형 소자이다. 그러나 동작점 근처에서 아주 조금만 움직이면 곡선은 직선(접선)처럼 보인다. 이 직선 근사가 소신호 모델이며, 처음 질문의 첫째 답이 이것이다. 이 근사 덕분에 증폭기를 전전3의 선형 회로 해석법(마디 해석, Thevenin)으로 풀 수 있다.

표기는 전체량 \(v_{GS}\)를 직류 \(V_{GS}\)와 신호 \(v_{gs}\)의 합으로 쓴다. 대문자 첨자는 전체, 소문자 첨자는 신호이다.

2.3.2gm의 유도와 소신호 조건

\(v_{gs}\)가 \(i_d\)를 얼마나 바꾸는지 구해 보자. \(\lambda = 0\)인 포화 전류식에 \(v_{GS} = V_{GS} + v_{gs}\)를 넣고 전개하면 다음과 같다.

\[ i_D = \tfrac12k_n(V_{OV} + v_{gs})^2 = \underbrace{\tfrac12k_nV_{OV}^2}_{I_D} + \underbrace{k_nV_{OV}\,v_{gs}}_{\text{선형}} + \underbrace{\tfrac12k_nv_{gs}^2}_{\text{왜곡}}. \]

첫 항은 직류, 둘째 항은 신호에 비례하는 원하는 성분, 셋째 항은 제곱이라 고조파 왜곡을 만드는 성분이다. 셋째 항이 둘째 항보다 훨씬 작으려면 \(\frac12k_nv_{gs}^2 \ll k_nV_{OV}v_{gs}\), 곧 \(|v_{gs}| \ll 2V_{OV}\)이어야 한다. 이것이 소신호 조건이며, 보통 \(|v_{gs}| \le 0.2V_{OV}\) 정도를 쓴다. 처음 질문의 둘째 답이 이것이다.

기호 \(\partial\)(편미분)를 짚고 넘어가자. \(i_D\)는 \(v_{GS}\)와 \(v_{DS}\) 두 값에 따라 변한다. \(\partial i_D/\partial v_{GS}\)는 \(v_{DS}\)는 그대로 두고 \(v_{GS}\)만 조금 바꿀 때 \(i_D\)가 변하는 비율, 곧 다른 변수를 상수로 보고 하는 보통의 미분이다. 그래프로는 동작점 Q에서 \(i_D\)–\(v_{GS}\) 곡선의 접선 기울기이다. 가령 \(i_D = \frac12k_n(v_{GS} - V_t)^2\)을 \(v_{GS}\)로 미분하면 \(k_n(v_{GS} - V_t) = k_nV_{OV}\)이다.

전달 컨덕턴스는 \(g_m = \partial i_D/\partial v_{GS}\big|_Q = k_nV_{OV} = \dfrac{2I_D}{V_{OV}} = \sqrt{2k_nI_D}\)이다(그림 1). 출력 저항은 \(r_o = \partial v_{DS}/\partial i_D\big|_Q \approx \dfrac{1}{\lambda I_D} = \dfrac{V_A}{I_D}\)이고, \(V_A = 1/\lambda\)를 Early 전압이라 한다.

\(g_m\)의 세 표현은 설계에서 쓰임이 다르다. 전류를 정해 두면 \(g_m = 2I_D/V_{OV}\)이므로, 같은 전류라면 \(V_{OV}\)가 작을수록 \(g_m\)이 크지만 대신 소신호 범위가 좁다. 소자 크기를 정해 두면 \(g_m = \sqrt{2k_nI_D}\)이므로 전류의 제곱근으로만 는다.

왜곡의 크기도 구할 수 있다. \(v_{gs} = V_p\cos\omega t\)이면 \(\frac12k_nv_{gs}^2 = \frac14k_nV_p^2(1 + \cos2\omega t)\)이므로, 2차 고조파와 기본파의 비는 \(\frac{V_p}{4V_{OV}}\)이다. 예를 들어 \(V_{OV} = 0.5\) V에서 \(V_p = 50\) mV이면 2.5%이다.

2.3.3소신호 등가회로

MOS의 하이브리드 π 모델은 게이트 전류가 0이므로 게이트-소스 사이를 개방으로 두고, 드레인-소스 사이에 전압 제어 전류원 \(g_mv_{gs}\)와 병렬 \(r_o\)를 둔다. T 모델은 소스 쪽에 저항 \(1/g_m\)을 두고 게이트 전류 0을 유지한 등가 표현으로, 소스에 저항이 달린 회로에서 계산이 편하다(4단원).

해석 순서는 언제나 같다. 먼저 직류 해석에서 축전기는 개방, 신호원은 0으로 두고 동작점 \(I_D, V_{OV}\)를 구해 포화를 확인한다. 그다음 \(g_m\)과 \(r_o\)를 계산한다. 이어서 소신호 회로를 그리는데, 직류 전원은 0으로(전압원은 단락, 전류원은 개방), 큰 축전기는 단락으로 두고 트랜지스터를 모델로 바꾼다. 마지막으로 선형 회로로 이득과 저항을 구한다.

예제 2.3.1

예제 2.1.1 (가)의 회로(\(k_n = 2\) mA/V², \(V_t = 0.5\) V, \(V_{GS} = 1.0\) V, \(R_D = 6\) kΩ, \(V_{DD} = 3\) V)에서 게이트에 작은 신호 \(v_{gs}\)를 더했다. \(\lambda = 0\)과 \(\lambda = 0.1\) V⁻¹일 때의 전압 이득 \(v_d/v_{gs}\)를 구하여라. (\(\lambda = 0.1\)일 때 \(r_o\)는 \(\lambda = 0\)의 \(I_D\)로 어림)

풀이. 직류로는 \(I_D = 0.25\) mA, \(V_{OV} = 0.5\) V이고 \(V_{DS} = 1.5\) V라 포화이다. 따라서 \(g_m = 2 \times 0.25/0.5 = 1\) mA/V이다. 소신호 회로에서 전류원 \(g_mv_{gs}\)는 드레인 마디에서 \(R_D\)(\(V_{DD}\)는 교류 접지)와 \(r_o\)로 흐르므로 \(v_d = -g_mv_{gs}(R_D \parallel r_o)\)이다.

\(\lambda = 0\)이면 \(A_v = -g_mR_D = -6\) V/V이다. \(\lambda = 0.1\)이면 \(r_o = 1/(0.1 \times 0.25\text{ m}) = 40\) kΩ이고 \(R_D \parallel r_o = 5.22\) kΩ이므로 \(A_v \approx -5.2\) V/V이다.

음수는 입력이 오르면 출력이 내려간다(반전)는 뜻이다. 소신호 조건으로 입력은 첨두 0.1 V(\(0.2V_{OV}\)) 이하여야 하고, 그때 출력 진폭은 약 0.6 V로 \(V_{DS}\) 여유(1.5 − 0.5 = 1.0 V) 안에 들어온다.

흔한 실수\(g_m = k_nV_{GS}\)로 쓰는 실수가 흔한데, \(V_{GS}\)가 아니라 \(V_{OV} = V_{GS} - V_t\)이다. 소신호 회로에 직류 전원 \(V_{DD}\)를 그대로 두는 것도 실수이다. 신호에 대해 직류 전압원은 0 V(접지)이므로 \(R_D\)의 위쪽 끝이 접지가 된다. 또 소신호 모델의 이득을 큰 신호에 쓰면 안 된다. 입력이 \(V_{OV}\)에 견줄 만큼 크면 왜곡이 커지고, 출력이 트라이오드나 차단으로 들어가 잘린다.
마무리

동작점 둘레에서 전류는 \(i_D = I_D + g_mv_{gs} + \frac12k_nv_{gs}^2\)로 전개되며, 소신호 조건 \(|v_{gs}| \ll 2V_{OV}\)에서 둘째 항만 남고 2차 왜곡은 \(V_p/(4V_{OV})\)이다. 전달 컨덕턴스는 \(g_m = k_nV_{OV} = 2I_D/V_{OV} = \sqrt{2k_nI_D}\), 출력 저항은 \(r_o = 1/(\lambda I_D)\)이다. 직류 해석, \(g_m\)과 \(r_o\), 소신호 회로, 선형 해석의 순서로 풀며 공통 소스 이득은 \(-g_m(R_D \parallel r_o)\)이다.

2.3.4연습문제

기본

  1. \(I_D = 0.4\) mA, \(V_{OV} = 0.2\) V일 때 \(g_m\)은? \(\lambda = 0.05\) V⁻¹이면 \(r_o\)는?
    답

    \(g_m\)은 4 mA/V, \(r_o\)는 50 kΩ이다.

응용

  1. 같은 \(I_D = 0.25\) mA에서 \(g_m\)을 두 배로 하려면 \(V_{OV}\)와 \(k_n\)을 어떻게 바꿔야 하는가?
    답

    \(V_{OV}\)를 절반(0.25 V)으로 하고, \(k_n = 2I_D/V_{OV}^2\)는 네 배(8 mA/V², W/L 네 배)로 한다.

  2. 예제 2.3.1에서 2차 고조파 왜곡을 1% 이하로 하려면 입력 첨두를 얼마 이하로 해야 하는가?
    답

    \(V_p/(4 \times 0.5) \le 0.01\)이므로 \(V_p \le 20\) mV이다.

심화

  1. \(r_o\)만 남긴 이득 \(g_mr_o\)(고유 이득)을 \(V_{OV}\)와 \(\lambda\)로 쓰고, 고유 이득을 키우는 두 방법을 말하여라.
    답

    \(g_mr_o = \frac{2I_D}{V_{OV}}\cdot\frac{1}{\lambda I_D} = \frac{2}{\lambda V_{OV}}\)이다. \(V_{OV}\)를 낮추거나 L을 늘려 \(\lambda\)를 줄인다. 전류와 무관하다는 점이 중요하다(5단원 능동 부하).
