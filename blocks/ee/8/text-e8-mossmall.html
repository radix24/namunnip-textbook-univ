MOSFET 소신호 모델: gm과 ro

본문
이 절에서 배울 것
  • 동작점 근처에서 제곱 법칙을 1차 근사해 전달 컨덕턴스 \(g_m\)을 유도하고, 소신호 조건을 정량적으로 쓴다.
  • \(g_m\)의 세 표현 \(k_nV_{OV} = 2I_D/V_{OV} = \sqrt{2k_nI_D}\)과 출력 저항 \(r_o = 1/(\lambda I_D)\)을 안다.
  • 직류 해석과 소신호 해석을 분리하는 순서로 공통 소스 증폭기의 이득을 구한다.
먼저 알아야 할 것
  • MOSFET 전류식 (2.1절), 바이어스 (2.2절), 다이오드 소신호 \(r_d\) (1.1절), 중첩의 원리 (전전3 3.1절), 종속 전원 (전전3 1.2절).

2.3.1작은 신호에서는 선형이다

포화 영역의 MOSFET은 제곱 법칙을 따르는 비선형 소자입니다. 그러나 동작점 근처에서 아주 조금만 움직이면 곡선은 직선(접선)처럼 보입니다. 이 직선 근사가 소신호 모델이고, 이것 덕분에 증폭기를 전전3의 선형 회로 해석법(마디 해석, Thevenin)으로 풀 수 있습니다.

표기: 전체량 \(v_{GS}\) = 직류 \(V_{GS}\) + 신호 \(v_{gs}\). 대문자 첨자는 전체, 소문자 첨자는 신호입니다.

2.3.2gm의 유도와 소신호 조건

구하려는 것: \(v_{gs}\)가 \(i_d\)를 얼마나 바꾸는가. 포화 전류식에 \(v_{GS} = V_{GS} + v_{gs}\)를 넣고 전개합니다(\(\lambda = 0\)).

\[ i_D = \tfrac12k_n(V_{OV} + v_{gs})^2 = \underbrace{\tfrac12k_nV_{OV}^2}_{I_D} + \underbrace{k_nV_{OV}\,v_{gs}}_{\text{선형}} + \underbrace{\tfrac12k_nv_{gs}^2}_{\text{왜곡}}. \]

첫 항은 직류, 둘째 항은 신호에 비례하는 원하는 성분, 셋째 항은 제곱이라 고조파 왜곡을 만드는 성분입니다. 셋째 항이 둘째 항보다 훨씬 작으려면 \(\frac12k_nv_{gs}^2 \ll k_nV_{OV}v_{gs}\), 곧

소신호 조건: \(|v_{gs}| \ll 2V_{OV}\). 보통 \(|v_{gs}| \le 0.2V_{OV}\) 정도를 쓴다.

전달 컨덕턴스 \(g_m = \partial i_D/\partial v_{GS}\big|_Q = k_nV_{OV} = \dfrac{2I_D}{V_{OV}} = \sqrt{2k_nI_D}\).

출력 저항 \(r_o = \partial v_{DS}/\partial i_D\big|_Q \approx \dfrac{1}{\lambda I_D} = \dfrac{V_A}{I_D}\). \(V_A = 1/\lambda\)는 Early 전압.

세 표현은 설계에서 쓰임이 다릅니다. 전류를 정해 두면 \(g_m = 2I_D/V_{OV}\): 같은 전류라면 \(V_{OV}\)가 작을수록 \(g_m\)이 크다(대신 소신호 범위가 좁다). 소자 크기를 정해 두면 \(g_m = \sqrt{2k_nI_D}\): 전류의 제곱근으로만 는다.

왜곡의 크기. \(v_{gs} = V_p\cos\omega t\)이면 \(\frac12k_nv_{gs}^2 = \frac14k_nV_p^2(1 + \cos2\omega t)\)이므로 2차 고조파와 기본파의 비는 \(\frac{V_p}{4V_{OV}}\)입니다. \(V_{OV} = 0.5\) V에서 \(V_p = 50\) mV이면 2.5%.

2.3.3소신호 등가회로

하이브리드 π 모델(MOS): 게이트-소스 사이 개방(게이트 전류 0), 드레인-소스 사이에 전압 제어 전류원 \(g_mv_{gs}\)와 병렬 \(r_o\).

T 모델: 소스 쪽에 저항 \(1/g_m\)을 두고 게이트 전류 0을 유지한 등가 표현. 소스에 저항이 달린 회로에서 계산이 편하다(4단원).

해석 순서는 언제나 같습니다.

  1. 직류 해석: 축전기는 개방, 신호원은 0. 동작점 \(I_D, V_{OV}\)를 구하고 포화를 확인한다.
  2. 소신호 변수: \(g_m\), \(r_o\) 계산.
  3. 소신호 회로: 직류 전원은 0(전압원 단락, 전류원 개방), 큰 축전기는 단락, 트랜지스터를 모델로 바꾼다.
  4. 선형 회로로 이득과 저항을 구한다.
예제 2.3.1

예제 2.1.1 (가)의 회로(\(k_n = 2\) mA/V², \(V_t = 0.5\) V, \(V_{GS} = 1.0\) V, \(R_D = 6\) kΩ, \(V_{DD} = 3\) V)에서 게이트에 작은 신호 \(v_{gs}\)를 더했다. \(\lambda = 0\)과 \(\lambda = 0.1\) V⁻¹일 때의 전압 이득 \(v_d/v_{gs}\)를 구하여라. (\(\lambda = 0.1\)일 때 \(r_o\)는 \(\lambda = 0\)의 \(I_D\)로 어림)

풀이. 직류: \(I_D = 0.25\) mA, \(V_{OV} = 0.5\) V, 포화(\(V_{DS} = 1.5\) V). \(g_m = 2 \times 0.25/0.5 = 1\) mA/V. 소신호 회로: 전류원 \(g_mv_{gs}\)가 드레인 마디에서 \(R_D\)(\(V_{DD}\)는 교류 접지)와 \(r_o\)에 흐릅니다. \(v_d = -g_mv_{gs}(R_D \parallel r_o)\).

  • \(\lambda = 0\): \(A_v = -g_mR_D = -6\) V/V.
  • \(\lambda = 0.1\): \(r_o = 1/(0.1 \times 0.25\text{ m}) = 40\) kΩ, \(R_D \parallel r_o = 5.22\) kΩ, \(A_v \approx -5.2\) V/V.

음수는 입력이 오르면 출력이 내려간다(반전)는 뜻입니다. 소신호 조건으로 입력은 첨두 0.1 V(\(0.2V_{OV}\)) 이하여야 하고, 그때 출력 진폭은 약 0.6 V로 \(V_{DS}\) 여유(1.5 − 0.5 = 1.0 V) 안에 들어옵니다.

흔한 오해(1) \(g_m = k_nV_{GS}\)로 쓰는 실수: \(V_{GS}\)가 아니라 \(V_{OV} = V_{GS} - V_t\)입니다. (2) 소신호 회로에 직류 전원 \(V_{DD}\)를 그대로 두는 실수: 신호에 대해 직류 전압원은 0 V(접지)입니다. 그래서 \(R_D\)의 위쪽 끝이 접지가 됩니다. (3) 소신호 모델의 결과(이득)를 큰 신호에 쓰는 실수: 입력이 \(V_{OV}\)에 견줄 만큼 크면 왜곡이 커지고, 출력이 트라이오드나 차단으로 들어가 잘립니다.
요약
  1. \(i_D = I_D + g_mv_{gs} + \frac12k_nv_{gs}^2\). 소신호 조건 \(|v_{gs}| \ll 2V_{OV}\), 2차 왜곡 \(V_p/(4V_{OV})\).
  2. \(g_m = k_nV_{OV} = 2I_D/V_{OV} = \sqrt{2k_nI_D}\), \(r_o = 1/(\lambda I_D)\).
  3. 직류 해석 → \(g_m, r_o\) → 소신호 회로(직류원 0, 큰 C 단락) → 선형 해석. 공통 소스 이득 \(-g_m(R_D \parallel r_o)\).

2.3.4연습문제

기본

  1. \(I_D = 0.4\) mA, \(V_{OV} = 0.2\) V일 때 \(g_m\)은? \(\lambda = 0.05\) V⁻¹이면 \(r_o\)는?
    답

    4 mA/V, 50 kΩ.

응용

  1. 같은 \(I_D = 0.25\) mA에서 \(g_m\)을 두 배로 하려면 \(V_{OV}\)와 \(k_n\)을 어떻게 바꿔야 하는가?
    답

    \(V_{OV}\)를 절반(0.25 V)으로, \(k_n = 2I_D/V_{OV}^2\)는 네 배(8 mA/V², W/L 네 배).

  2. 예제 2.3.1에서 2차 고조파 왜곡을 1% 이하로 하려면 입력 첨두를 얼마 이하로 해야 하는가?
    답

    \(V_p/(4 \times 0.5) \le 0.01\) → \(V_p \le 20\) mV.

심화

  1. \(r_o\)만 남긴 이득 \(g_mr_o\)(고유 이득)을 \(V_{OV}\)와 \(\lambda\)로 쓰고, 고유 이득을 키우는 두 방법을 말하여라.
    답

    \(g_mr_o = \frac{2I_D}{V_{OV}}\cdot\frac{1}{\lambda I_D} = \frac{2}{\lambda V_{OV}}\). \(V_{OV}\)를 낮추거나 L을 늘려 \(\lambda\)를 줄인다. 전류와 무관하다는 점이 중요합니다(5단원 능동 부하).
