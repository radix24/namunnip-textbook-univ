사양에 맞는 증폭기 구조 고르기

본문
이 절에서 배울 것
  • 신호원 저항, 부하 저항, 이득, 선형성 요구에서 출발해 CS·CG·CD 중 무엇을 쓸지 정한다.
  • 두 단을 이을 때 앞단의 \(R_{out}\)과 뒷단의 \(R_{in}\)이 만드는 부하 효과를 계산한다.
  • 바이어스 결합 축전기와 바이패스 축전기의 역할과 크기 어림을 안다.
먼저 알아야 할 것
  • 세 기본 증폭기의 \(R_{in}, A_{vo}, R_{out}\) (4.1절), RC 고역 통과의 차단 주파수 (전전3 8.2절).

4.2.1질문 세 개로 고르기

  1. 신호원 저항이 큰가? 수백 kΩ 이상(압전 센서, 콘덴서 마이크, 고임피던스 탐침)이면 \(R_{in}\)이 큰 CS나 CD로 받는다. 50 Ω 안테나·케이블처럼 작으면 입력 저항을 신호원에 맞추기 쉬운 CG도 후보.
  2. 전압 이득이 필요한가? 필요하면 CS(또는 CE). 이득 대신 구동 능력이 필요하면 CD(또는 CC).
  3. 부하 저항이 작은가? 스피커, 케이블, 다음 단의 작은 입력 저항처럼 \(R_L\)이 작으면 마지막 단에 \(R_{out}\)이 작은 폴로어를 둔다.

그리고 선형성과 편차 둔감성이 중요하면 CS에 소스(이미터) 저항을 남깁니다(4.1.2). 한 단으로 모든 요구를 맞출 수 없으면 단을 잇습니다.

구조\(R_{in}\)전압 이득\(R_{out}\)주된 쓰임
CS / CE큼 / 중간큼(반전)큼주 증폭단
CG / CB작음큼(비반전)큼전류 버퍼, 저임피던스 입력, 고주파
CD / CC큼약 1작음전압 버퍼, 출력단

4.2.2두 단 잇기와 부하 효과

앞단의 출력은 뒷단의 신호원이므로 \(R_{out1}\)과 \(R_{in2}\)가 분압됩니다. 전체 이득은 각 단의 이득과 단 사이 분압의 곱입니다(6.3절에서 일반화).

예제 4.2.1

압전 진동 센서(\(R_{sig} = 1\) MΩ)의 신호를 \(R_L = 1\) kΩ 데이터 수집 장치에 이득 −20 이상으로 보내려 한다. MOSFET만 쓰고, CS 단은 \(g_m = 2\) mA/V, 폴로어 단은 \(g_m = 5\) mA/V로 둔다. (가) CS 한 단(\(R_D = 10\) kΩ)이면 이득은? (나) CS + CD는? (다) 사양을 맞추도록 \(R_D\)를 고쳐라. (바이어스 저항 \(R_G\)는 10 MΩ 이상으로 보고 무시)

풀이.

  • (가) CS 한 단: \(G_v = 1 \times (-20) \times \frac{1}{1 + 10} = -1.82\). \(R_{out} = 10\) kΩ이 1 kΩ 부하와 분압되어 이득 대부분을 잃습니다.
  • (나) CS → CD → 부하. CS 출력은 CD의 무한 입력 저항에 걸리므로 손실이 없고(\(-20\)), CD는 \(\frac{1}{1 + 0.2} = 0.833\). \(G_v = -20 \times 0.833 = -16.7\).
  • (다) \(-g_mR_D \times 0.833 \le -20\) → \(R_D \ge 12\) kΩ. 12 kΩ이면 −20.0. 바이어스에서 \(V_{DS}\) 여유가 충분한지 다시 확인해야 합니다(\(I_D\)를 유지하면 \(R_D\) 전압이 20% 늘어남).

입력 쪽은 CS 게이트의 큰 입력 저항 덕분에 1 MΩ 신호원에서도 손실이 없습니다. CE(BJT)로 받았다면 \(R_{in} = r_\pi\)가 수 kΩ이라 신호 대부분이 신호원 저항에서 사라졌을 것입니다.

4.2.3결합·바이패스 축전기

결합 축전기 \(C_C\): 단과 단, 신호원과 입력, 출력과 부하 사이에 두어 직류 바이어스가 서로 영향을 주지 않게 하고 신호만 통과시킨다. 신호 주파수에서 리액턴스가 연결된 저항보다 충분히 작아야 한다: \(\frac{1}{2\pi f_LC_C} \ll R\).

바이패스 축전기 \(C_S\): 소스(이미터) 저항과 병렬로 두어 직류에서는 \(R_S\)의 안정 효과를 유지하고, 신호에서는 단락해 이득을 되살린다. 소스 쪽에서 본 저항이 \(1/g_m\) 정도로 작아 가장 큰 축전기가 필요하다.

이 축전기들은 각각 고역 통과 필터를 만들어 증폭기의 낮은 차단 주파수 \(f_L\)을 정합니다. 예: CS 입력에서 \(R_G = 1\) MΩ이면 \(f_L = 20\) Hz를 위한 \(C_C \approx 8\) nF로 작지만, 바이패스는 \(1/g_m = 500\) Ω이면 약 16 μF가 필요합니다. 집적회로에서는 큰 축전기를 만들 수 없어 차동 구조(6단원)와 직접 결합을 씁니다. 주파수 응답은 전전13에서 자세히 다룹니다.

흔한 오해(1) "폴로어는 이득이 없으니 쓸모없다": 전압 이득은 1이지만 전류(전력) 이득이 크고, 무엇보다 부하 효과를 끊어 줍니다. (2) 단을 이을 때 각 단의 개방 이득을 그냥 곱하는 실수: 단 사이 분압을 빠뜨리면 예제 (가)처럼 열 배 넘게 틀릴 수 있습니다. (3) 바이패스 축전기를 입력 결합 축전기와 같은 크기로 고르는 실수: 들여다본 저항이 다르면 필요한 C도 수천 배 다릅니다.
요약
  1. 신호원 저항 → 입력 구조, 이득 요구 → CS, 작은 부하 → 출력에 폴로어.
  2. 단 사이 분압 \(R_{in2}/(R_{in2} + R_{out1})\)을 반드시 곱한다.
  3. 결합·바이패스 축전기: 직류 분리와 신호 단락. 들여다본 저항에 맞춰 크기를 정한다.

4.2.4연습문제

기본

  1. 50 Ω 안테나 신호를 받는 증폭기의 입력 저항을 50 Ω으로 맞추려면 어떤 구조가 쉬운가? \(g_m\)은?
    답

    CG, \(1/g_m = 50\) Ω → \(g_m = 20\) mA/V.

응용

  1. 예제 4.2.1 (나)에서 폴로어의 \(g_m\)을 2 mA/V로 줄이면 \(G_v\)는?
    답

    폴로어 \(1/(1 + 0.5) = 0.667\), \(G_v = -13.3\).

  2. \(R_S = 2\) kΩ을 \(g_m = 2\) mA/V 소자의 소스에서 바이패스해 \(f_L = 50\) Hz를 얻으려면 \(C_S\)는 대략?
    답

    소스에서 본 저항 \(R_S \parallel (1/g_m) = 400\) Ω, \(C_S \approx 1/(2\pi \cdot 50 \cdot 400) \approx 8\) μF.

심화

  1. CS 단 뒤에 폴로어 대신 같은 CS 단을 하나 더 이으면(두 번째 \(R_D\) = 1 kΩ, \(g_m = 20\) mA/V) 이득은? 장단점은?
    답

    \((-20) \times (-20 \times (1 \parallel 1)) = (-20)(-10) = +200\). 이득은 크지만 두 번째 단의 \(R_{out}\) = 1 kΩ이라 부하에 따라 크게 변하고, 큰 \(g_m\)을 위해 전류가 많이 듭니다.
