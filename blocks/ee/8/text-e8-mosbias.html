MOSFET 직류 바이어스: 소자 편차에 강한 동작점

본문
이 절에서 배울 것
  • 증폭기에 직류 동작점(바이어스)이 필요한 이유와 좋은 동작점의 조건을 안다.
  • 게이트 전압 고정 바이어스가 문턱 전압 편차에 약한 이유를 계산으로 보인다.
  • 분압 게이트 + 소스 저항 바이어스를 해석하고, 목표 전류에 맞게 설계한다.
  • 드레인-게이트 되먹임 바이어스와 전류원 바이어스를 안다.
먼저 알아야 할 것
  • MOSFET 동작 영역과 전류식 (2.1절), 분압 (전전3 2.1절).

2.2.1왜 바이어스가 필요한가

증폭하려는 신호는 마이크 출력처럼 0을 중심으로 수 mV 오르내립니다. 이것을 바로 게이트에 넣으면 대부분의 시간 동안 \(v_{GS} < V_t\)라 소자가 꺼져 있습니다. 그래서 먼저 직류 전압으로 소자를 포화 영역의 적당한 점(동작점, Q점)에 세워 두고, 신호는 그 위에 얹습니다. 좋은 동작점은 (1) 신호가 오르내려도 포화 영역을 벗어나지 않을 만큼 여유가 있고, (2) 온도나 소자 편차가 있어도 전류가 크게 바뀌지 않아야 합니다.

동작점(Q점): 신호가 없을 때의 직류 \(I_D\), \(V_{GS}\), \(V_{DS}\).

소자 편차: 같은 설계의 소자라도 \(V_t\)는 수십~100 mV, \(k_n\)은 수십 % 다를 수 있고 온도에 따라 변한다.

2.2.2게이트 전압 고정 바이어스의 문제

가장 단순한 방법은 분압기로 \(V_{GS}\)를 정해 주는 것입니다. 그런데 \(I_D = \frac12k_n(V_{GS} - V_t)^2\)에서 \(V_{OV}\)가 작으면 \(V_t\)의 작은 변화가 전류를 크게 바꿉니다.

예제 2.2.1

\(k_n = 2\) mA/V². \(V_{GS} = 1.0\) V로 고정했을 때, \(V_t\)가 0.5 V에서 0.6 V로 바뀌면 \(I_D\)는 몇 % 변하는가?

풀이. \(V_t = 0.5\): \(I_D = \frac12 \cdot 2 \cdot 0.5^2 = 0.25\) mA. \(V_t = 0.6\): \(I_D = \frac12 \cdot 2 \cdot 0.4^2 = 0.16\) mA. 36% 감소. 100 mV 편차에 전류가 1/3 넘게 바뀌어, 대량 생산하면 증폭기마다 이득과 동작점이 제각각이 됩니다.

2.2.3소스 저항으로 되먹임하기

소스와 접지 사이에 \(R_S\)를 넣고 게이트는 분압기로 \(V_G\)를 정합니다. 그러면 \(V_{GS} = V_G - I_DR_S\)입니다. 전류가 늘려고 하면 \(R_S\) 전압이 커져 \(V_{GS}\)가 줄고, 전류 증가를 되밀어냅니다(음의 되먹임).

구하려는 것: \(I_D\). 두 식 \(I_D = \frac12k_n(V_{GS} - V_t)^2\), \(V_{GS} = V_G - I_DR_S\)를 연립하면 \(V_{GS}\)(또는 \(V_{OV}\))에 대한 이차방정식이 됩니다. 두 근 중 \(V_{GS} > V_t\)인 쪽이 답입니다.

예제 2.2.2

\(V_G = 2\) V, \(R_S = 2\) kΩ, \(k_n = 2\) mA/V². \(V_t = 0.5\) V와 0.6 V에서 \(I_D\)를 구해 예제 2.2.1과 비교하여라.

풀이. \(V_t = 0.5\): \(V_{OV} = x\)라 두면 \(V_{GS} = 0.5 + x\), \(I_D = x^2\) (mA)이므로 \(2 = 0.5 + x + 2x^2\), \(2x^2 + x - 1.5 = 0\), \(x = \frac{-1 + \sqrt{1 + 12}}{4} = 0.651\) V. \(I_D = 0.424\) mA, \(V_{GS} = 1.151\) V. 같은 방법으로 \(V_t = 0.6\)이면 \(2x^2 + x - 1.4 = 0\), \(x = 0.623\), \(I_D = 0.388\) mA. 변화는 8.5%로, 고정 바이어스의 36%보다 4배 이상 작습니다.

\(R_S\)가 클수록 안정하지만, 그만큼 전원 전압을 \(R_S\)에 써서 드레인 쪽 여유가 줄어듭니다. 설계에서는 흔히 \(V_{DD}\)를 대략 \(V_S\), \(V_{DS}\), \(R_D\) 전압에 나눠 줍니다(예: 각 1/3).

2.2.4설계 순서

  1. 목표 \(I_D\)와 \(V_{OV}\)를 정한다(이득과 여유에서, 2.3절과 4단원).
  2. \(V_{GS} = V_t + V_{OV}\), \(k_n = 2I_D/V_{OV}^2\)로 W/L을 정한다.
  3. \(V_S\)를 정해 \(R_S = V_S/I_D\), \(V_G = V_S + V_{GS}\).
  4. 분압 저항은 게이트 전류가 0이므로 값을 크게(수백 kΩ~MΩ) 해 입력 저항을 높인다.
  5. \(R_D\)는 \(V_{DS} \ge V_{OV}\) + 신호 여유가 되도록.

드레인-게이트 되먹임 바이어스: 큰 저항으로 드레인을 게이트에 연결. \(V_{GS} = V_{DS}\)라 언제나 포화이고, 전류가 늘면 드레인 전압이 내려가 \(V_{GS}\)가 줄어든다.

전류원 바이어스: 소스에 정전류원(5단원의 전류 거울)을 달아 \(I_D\)를 직접 정한다. 집적회로의 표준 방법.

흔한 오해(1) 이차방정식의 다른 근(\(V_{GS} < V_t\))을 고르는 실수: 그 근에서는 소자가 꺼져 제곱 법칙이 성립하지 않습니다. (2) "게이트 분압 저항은 작을수록 좋다": 게이트 전류가 0이라 분압비만 맞으면 되고, 작으면 전력을 낭비하고 신호원의 부하가 됩니다. (3) \(R_S\)가 신호 이득도 줄인다는 점을 잊는 실수: 4단원에서 바이패스 축전기로 교류에서만 \(R_S\)를 단락시키는 방법을 봅니다.
요약
  1. 바이어스 = 신호 없을 때의 동작점. 포화 유지 여유와 편차 둔감성이 목표.
  2. 고정 \(V_{GS}\)는 \(V_t\) 편차에 약하다(예: 100 mV에 36%).
  3. 소스 저항 되먹임: \(V_{GS} = V_G - I_DR_S\), 이차방정식으로 풀고 \(V_{GS} > V_t\)인 근. 편차 영향이 크게 줄어든다.

2.2.5연습문제

기본

  1. \(V_{DD} = 5\) V를 1 MΩ과 1.5 MΩ으로 분압하면 \(V_G\)는?
    답

    \(5 \times 1.5/2.5 = 3\) V (1.5 MΩ이 접지 쪽일 때).

응용

  1. \(k_n = 1\) mA/V², \(V_t = 0.5\) V로 \(I_D = 0.5\) mA, \(V_S = 1\) V가 되게 설계하라. \(R_S\)와 \(V_G\)는?
    답

    \(V_{OV} = \sqrt{2 \times 0.5/1} = 1\) V, \(V_{GS} = 1.5\) V. \(R_S = 2\) kΩ, \(V_G = 2.5\) V.

  2. 문제 2의 설계에서 \(V_t\)가 0.6 V가 되면 \(I_D\)는?
    답

    \(2.5 = 0.6 + x + 2\cdot\frac12x^2\) → \(x^2 + x - 1.9 = 0\), \(x \approx 0.966\), \(I_D \approx 0.467\) mA(약 7% 감소).

심화

  1. 드레인-게이트 되먹임 바이어스(\(R_G\) 큼, \(V_{DD} = 5\) V, \(R_D = 10\) kΩ, \(k_n = 1\) mA/V², \(V_t = 0.5\) V)의 \(I_D\)와 \(V_D\)를 구하여라.
    답

    \(V_{GS} = V_D = 5 - 10I_D\), \(I_D = \frac12(V_D - 0.5)^2\). \(V_D = 5 - 5(V_D - 0.5)^2\)을 풀면 \(V_D \approx 1.35\) V, \(I_D \approx 0.365\) mA.
