MOS 차동 쌍: 차이만 증폭한다

본문

심전도 전극의 신호는 1 mV 남짓인데, 같은 전선에는 전원선에서 유도된 60 Hz 잡음이 그보다 수백 배 크게 실린다. 다행히 그 잡음은 두 가닥 전선에 거의 똑같이 실린다. 두 선의 차이만 키우고 공통으로 실린 것은 버리는 증폭기를 만들 수 있을까? 그런 증폭기는 얼마나 큰 차이까지 고르게 키울까?

먼저 알아야 할 것CS 증폭기와 소스 저항(4.1절), 전류 거울(5.1절), 중첩의 원리(전전3 3.1절)를 쓴다.

6.1.1왜 차동인가

센서 신호는 긴 전선을 지나며 전원선의 60 Hz나 주변 전자기 잡음을 받는데, 그 잡음은 두 가닥에 거의 같게 실린다. 그래서 두 선의 차이만 증폭하면 신호는 남고 잡음은 지워진다. 또 결합 축전기 없이 직류부터 증폭할 수 있고, 두 트랜지스터가 대칭이라 온도 변화가 서로 상쇄된다. 연산증폭기의 입력단과 USB, 이더넷 같은 고속 디지털 통신의 차동 신호가 모두 이 구조이다.

두 입력은 차동 입력 \(v_{id} = v_{G1} - v_{G2}\)와 공통 모드 입력 \(v_{icm} = \frac12(v_{G1} + v_{G2})\)로 나누며, 그러면 \(v_{G1} = v_{icm} + v_{id}/2\), \(v_{G2} = v_{icm} - v_{id}/2\)이다. 차동 쌍은 소스를 서로 묶은 같은 크기의 두 트랜지스터로, 묶인 소스에 꼬리 전류원 I를 달고 각 드레인에 부하 \(R_D\)를 단다. 처음 질문의 첫째 답이 이 구조이다.

6.1.2큰 신호 동작

\(v_{id}\)에 따라 꼬리 전류가 두 쪽에 어떻게 나뉘는지 구해 보자. 두 트랜지스터는 언제나 \(i_{D1} + i_{D2} = I\)를 지킨다. 공통 모드 입력만 있으면(\(v_{id} = 0\)) 대칭이라 각각 \(I/2\)이고, 이때의 과구동 전압은 \(I/2 = \frac12k_nV_{OV}^2\)에서 \(V_{OV} = \sqrt{I/k_n}\)이다.

\(v_{id}\)를 주면 두 제곱 법칙 식에서 공통 소스 전압을 소거해 \(\sqrt{i_{D1}} - \sqrt{i_{D2}} = \sqrt{k_n/2}\,v_{id}\)를 얻고, 이것을 합 조건과 연립하면 다음과 같다.

\[ i_{D1,2} = \frac I2 \pm \frac{I}{V_{OV}}\cdot\frac{v_{id}}{2}\sqrt{1 - \left(\frac{v_{id}/2}{V_{OV}}\right)^2}. \]

\(|v_{id}| \ll 2V_{OV}\)이면 \(i_{D1} \approx I/2 + g_m(v_{id}/2)\)이고, 여기서 \(g_m = I/V_{OV}\)는 각 트랜지스터의 \(2(I/2)/V_{OV}\)이다. \(|v_{id}| = \sqrt2V_{OV}\)이면 전류가 한쪽으로 모두 넘어가 \(i_{D1} = I\), \(i_{D2} = 0\)이 된다. 그 너머로는 한쪽이 꺼져 출력이 더 변하지 않으므로, 차동 쌍은 전류를 조종하는 스위치가 된다(그림 1). 처음 질문의 둘째 답이 이것이다.

한편 공통 모드 입력이 움직여도, 트랜지스터들이 포화인 범위 안에서는 묶인 소스 전압이 같이 움직일 뿐 전류 분배는 그대로이다. 이것이 공통 모드 제거의 원리이다.

6.1.3소신호: 반쪽 회로

먼저 차동 모드를 보자. \(v_{G1} = +v_{id}/2\), \(v_{G2} = -v_{id}/2\)이면 한쪽 전류가 늘어난 만큼 다른 쪽이 줄어 꼬리 전류는 일정하고, 묶인 소스 전압은 변하지 않는다(가상 접지). 그래서 각 쪽은 소스가 접지된 CS 증폭기이다.

\[ v_{d1} = -g_mR_D\frac{v_{id}}{2}, \quad v_{d2} = +g_mR_D\frac{v_{id}}{2}, \qquad A_d = \frac{v_{d2} - v_{d1}}{v_{id}} = g_mR_D. \]

한쪽 출력만 쓰면 이득은 \(g_mR_D/2\)이다.

다음은 공통 모드이다. 두 입력에 같은 \(v_{icm}\)을 주면 두 쪽이 똑같이 움직인다. 실제 꼬리 전류원은 유한한 출력 저항 \(R_{SS}\)를 가지므로, 이것을 \(2R_{SS}\) 두 개의 병렬로 쪼개 각 반쪽에 하나씩 준다. 그러면 각 반쪽은 소스 저항 \(2R_{SS}\)를 가진 CS이므로 다음과 같다.

\[ A_{cm} = \frac{v_{d1}}{v_{icm}} = -\frac{g_mR_D}{1 + 2g_mR_{SS}} \approx -\frac{R_D}{2R_{SS}}. \]

두 출력이 완전히 같으므로, 회로가 완벽히 대칭이면 차동 출력의 공통 모드 이득은 0이다.

예제 6.1.1

꼬리 전류 I = 0.4 mA, 각 트랜지스터의 \(V_{OV} = 0.2\) V, \(R_D = 5\) kΩ, 꼬리 전류원의 출력 저항 \(R_{SS} = 50\) kΩ. (가) \(k_n\), \(g_m\), (나) 차동 이득(차동 출력, 한쪽 출력), (다) 한쪽 출력의 공통 모드 이득, (라) 선형 범위의 끝 \(v_{id}\)를 구하여라.

풀이. (가) \(k_n = I/V_{OV}^2 = 0.4/0.04 = 10\) mA/V²이고 \(g_m = I/V_{OV} = 2\) mA/V이다. (나) \(A_d = 2 \times 5 = 10\)이고, 한쪽 출력은 5이다. (다) \(A_{cm} = -\frac{10}{1 + 200} \approx -0.0498\)이며, 근사로는 \(-5/100 = -0.05\)이다. (라) \(\sqrt2 \times 0.2 = 0.283\) V에서 전류가 모두 한쪽으로 넘어간다(그림 1). 소신호로 볼 수 있는 범위는 그 몇 분의 일인 수십 mV이다.

즉 한쪽 출력에서도 차동 신호는 5배, 공통 모드 신호는 0.05배가 되어, 둘의 비가 100(40 dB)이다. 이 비가 6.2절의 CMRR이다.

흔한 실수차동 쌍의 \(g_m\)을 꼬리 전류 I로 계산하는 실수가 흔하다. 각 트랜지스터는 \(I/2\)를 흘리므로 \(g_m = 2(I/2)/V_{OV} = I/V_{OV}\)이고, \(V_{OV}\)도 \(I/2\)에서의 값이다. 공통 모드 이득을 구할 때 꼬리 저항을 \(R_{SS}\) 그대로 각 반쪽에 주는 것도 실수이다. 두 반쪽이 나눠 쓰므로 \(2R_{SS}\)이다. 또 공통 모드 입력은 무한히 움직일 수 없다. 너무 높으면 입력 트랜지스터가 트라이오드로, 너무 낮으면 꼬리 전류원이 포화를 벗어나며, 그 사이를 입력 공통 모드 범위라 한다.
마무리

차동 쌍의 입력은 차동 성분 \(v_{id}\)와 공통 성분 \(v_{icm}\)으로 나누며, 두 전류는 언제나 \(i_{D1} + i_{D2} = I\)를 지킨다. 선형 범위의 끝은 \(|v_{id}| = \sqrt2V_{OV}\)이다. 차동 반쪽 회로에서는 소스가 가상 접지라 \(A_d = g_mR_D\)(한쪽 \(g_mR_D/2\)), \(g_m = I/V_{OV}\)이다. 공통 모드 반쪽 회로에서는 소스 저항이 \(2R_{SS}\)라 \(A_{cm} \approx -R_D/(2R_{SS})\)이다.

6.1.4연습문제

기본

  1. \(v_{G1} = 1.02\) V, \(v_{G2} = 0.98\) V일 때 \(v_{id}\)와 \(v_{icm}\)은?
    답

    \(v_{id}\)는 40 mV, \(v_{icm}\)은 1.00 V이다.

  2. 예제 6.1.1에서 \(v_{id} = 20\) mV일 때 \(i_{D1}\)(큰 신호 식)과 소신호 근사는?
    답

    근사로는 \(0.2 + 2 \times 0.01 = 0.220\) mA이고, 정확한 식으로는 \(0.2 + 2 \times 0.01 \times \sqrt{1 - 0.0025} = 0.21997\) mA로 거의 같다.

응용

  1. 같은 차동 쌍에서 \(v_{id} = 0.2\) V이면 \(i_{D1}\)은? 소신호 근사와 비교하여라.
    답

    정확한 식으로는 \(0.2 + 2 \times 0.1 \times \sqrt{1 - 0.25} = 0.373\) mA이고, 근사 \(0.2 + 0.2 = 0.4\) mA는 약 7% 크다. 신호 성분만 보면 0.173 대 0.2 mA로 13% 차이이며, 곧 한쪽으로 다 넘어가는 영역(0.283 V에서 0.4 mA)이다.

심화

  1. 선형 범위를 넓히려면 \(V_{OV}\)를 키워야 한다. 같은 꼬리 전류에서 \(V_{OV}\)를 두 배로 하면 차동 이득은 어떻게 되는가? 이 맞바꿈을 설명하여라.
    답

    \(g_m = I/V_{OV}\)가 절반이 되어 이득도 절반이 되고, 선형 범위는 두 배가 된다. 그래서 큰 신호를 다루는 단은 \(V_{OV}\)를 크게, 작은 신호의 이득단은 작게 설계한다.
