세 가지 기본 증폭기

본문

개방 이득이 −10인 증폭기와 +1인 증폭기가 있다. 숫자만 보면 앞의 것이 열 배 좋아 보인다. 그런데 스피커처럼 저항이 작은 부하를 달면 사정이 뒤집힐 수 있다. 증폭기의 내부가 아무리 복잡해도 바깥에서 몇 개의 숫자로 성능을 말할 수 있을까? 그리고 세 가지 기본 구조는 그 숫자가 어떻게 다를까?

먼저 알아야 할 것MOSFET 소신호 모델(2.3절), BJT 소신호 모델(3.2절), Thevenin 등가와 분압(전전3 3.2절)을 쓴다.

4.1.1증폭기를 세 숫자로 나타내기

증폭기 내부가 아무리 복잡해도, 바깥에서 보면 세 숫자로 충분하며 처음 질문의 첫째 답이 이것이다. 입력 저항 \(R_{in}\)은 입력 단자에서 들여다본 저항으로, 신호원 저항 \(R_{sig}\)와 분압되어 입력에 실제로 들어가는 신호를 정한다. 개방 전압 이득 \(A_{vo}\)는 부하가 없을 때의 \(v_o/v_i\)이다. 출력 저항 \(R_{out}\)은 입력 신호를 0으로 두고 출력에서 들여다본 저항으로, 부하 \(R_L\)과 분압된다.

그러면 신호원부터 부하까지의 전체 이득은 분압 두 번과 이득 한 번의 곱이다.

\[ G_v = \frac{v_o}{v_{sig}} = \frac{R_{in}}{R_{in} + R_{sig}}\cdot A_{vo}\cdot\frac{R_L}{R_L + R_{out}}. \]

따라서 좋은 전압 증폭기는 \(R_{in} \gg R_{sig}\), \(R_{out} \ll R_L\)이어야 앞뒤 손실이 없다. 이 식이 4.2절에서 증폭기 구조를 고르는 기준이 된다.

4.1.2공통 소스(CS) 증폭기

공통 소스 증폭기는 입력이 게이트, 출력이 드레인이고 소스가 교류 접지이며, 2.3절에서 이미 이득을 구했다. CS는 \(R_{in} = \infty\)(실제로는 바이어스 저항 \(R_G\)), \(A_{vo} = -g_m(R_D \parallel r_o)\), \(R_{out} = R_D \parallel r_o\)이다. BJT의 공통 이미터(CE)는 \(R_{in} = r_\pi\), \(A_{vo} = -g_m(R_C \parallel r_o)\), \(R_{out} = R_C \parallel r_o\)이다.

소스에 바이패스하지 않은 \(R_S\)를 남기면 어떻게 될까. T 모델로 \(i_d = v_i/(1/g_m + R_S)\)이므로 \(r_o\)를 무시하면 \(A_{vo} = -\frac{g_mR_D}{1 + g_mR_S}\)이다. 분모 \(1 + g_mR_S\)만큼 이득이 줄지만, \(g_mR_S \gg 1\)이면 \(A_{vo} \approx -R_D/R_S\)로 소자 변수와 무관해지고 왜곡도 같은 비율로 줄어든다. 이것이 음의 되먹임이다. BJT에서는 3.2절에서 본 것처럼 입력 저항도 \((\beta + 1)(r_e + R_E)\)로 커진다.

4.1.3공통 게이트(CG) 증폭기

공통 게이트 증폭기는 입력이 소스, 출력이 드레인이고 게이트가 교류 접지이다. 소스 전압을 \(v_i\)만큼 올리면 \(v_{gs} = -v_i\)이므로 드레인 전류가 \(g_mv_i\)만큼 줄어든다. \(R_D\)를 지나는 전류가 줄면 드레인 전압은 \(g_mv_iR_D\)만큼 오르므로, 출력은 입력과 같은 방향(비반전)이다. 또 입력 단자로 들어가는 신호 전류가 곧 그 \(g_mv_i\)이므로 입력 저항은 \(1/g_m\)이다.

그래서 \(r_o\)를 무시한 CG는 \(R_{in} = 1/g_m\), \(A_{vo} = +g_mR_D\), \(R_{out} = R_D\)이다. BJT의 공통 베이스(CB)는 \(R_{in} = r_e\), \(A_{vo} = +\alpha R_C/r_e = +g_mR_C\), \(R_{out} = R_C\)이다. 입력 저항이 수십~수백 Ω으로 매우 작아 전압 증폭기로는 부적합하지만, 전류를 받아 그대로 넘기는 전류 버퍼로 쓴다. 낮은 임피던스 신호원, 캐스코드, 전전13의 고주파 증폭기가 그 예이다.

4.1.4소스 폴로어(CD)

소스 폴로어는 입력이 게이트, 출력이 소스이고 드레인이 교류 접지이며, 출력이 입력을 거의 그대로 따라가서 폴로어라 부른다. \(r_o\)를 무시한 CD는 \(R_{in} = \infty\)이고, 부하 \(R_L\)에서 \(A_v = \frac{R_L}{R_L + 1/g_m}\)이므로 \(A_{vo} = 1\), \(R_{out} = 1/g_m\)이다. BJT의 이미터 폴로어(CC)는 \(R_{in} = (\beta + 1)(r_e + R_L)\), \(A_v = \frac{R_L}{R_L + r_e}\), \(R_{out} = r_e + \frac{R_{sig}}{\beta + 1}\)이다.

이득은 1보다 조금 작지만 입력 저항이 크고 출력 저항이 작으므로, 큰 저항의 신호원으로 작은 저항의 부하를 구동하는 전압 버퍼로 쓴다.

예제 4.1.1

\(g_m = 2\) mA/V인 MOSFET으로 세 구조를 만들었다(\(R_D = 5\) kΩ, \(r_o\) 무시). 부하 \(R_L = 10\) kΩ, 신호원 저항 \(R_{sig} = 1\) kΩ일 때 각 구조의 \(G_v\)를 구하여라. (폴로어는 \(R_D\) 없이 드레인을 \(V_{DD}\)에 연결)

풀이. 세 구조의 숫자와 전체 이득은 다음 표와 같다.

구조\(R_{in}\)\(A_{vo}\)\(R_{out}\)\(G_v\)
CS∞−105 kΩ\(1 \times (-10) \times \frac{10}{15} = -6.67\)
CG500 Ω+105 kΩ\(\frac{0.5}{1.5} \times 10 \times \frac{10}{15} = +2.22\)
CD∞1500 Ω\(1 \times 1 \times \frac{10}{10.5} = 0.952\)

CG는 개방 이득이 CS와 같은 크기인데도 입력 분압 때문에 전체 이득이 1/3로 줄었다. 한편 폴로어는 이득은 없지만 출력 저항이 500 Ω으로 작아, 부하가 1 kΩ으로 작아져도 \(G_v = 1/1.5 = 0.67\)을 유지한다. 반면 CS는 \(-10 \times 1/6 = -1.67\)로 급감한다(그림 1). 처음 질문의 둘째 답이 이것으로, 세 구조는 같은 소자로 세 숫자를 서로 다르게 맞바꾼 것이다.

흔한 오해개방 이득이 큰 구조가 언제나 낫다고 여기기 쉽지만, 신호원과 부하의 저항이 전체 이득을 크게 바꾸므로 세 숫자를 함께 보아야 한다. 출력 저항을 구할 때 입력 신호원을 그대로 두는 실수도 흔하다. \(v_{sig} = 0\)으로 단락하되 \(R_{sig}\)는 남기고, 출력에 시험 전원을 걸어 구한다. 이미터 폴로어의 \(R_{out}\)에 \(R_{sig}/(\beta + 1)\)이 나타나는 것이 그 때문이다. 또 폴로어의 이득은 \(R_L\)과 \(1/g_m\)의 분압이라 정확히 1이 아니라 1보다 작다.
마무리

증폭기는 입력 저항, 개방 전압 이득, 출력 저항의 세 숫자로 나타내며, 전체 이득은 \(G_v = \frac{R_{in}}{R_{in} + R_{sig}}A_{vo}\frac{R_L}{R_L + R_{out}}\)이다. CS는 ∞, \(-g_mR_D\), \(R_D\)이고, CG는 \(1/g_m\), \(+g_mR_D\), \(R_D\)이며, CD는 ∞, 1, \(1/g_m\)이다. BJT는 입력 저항이 각각 \(r_\pi\), \(r_e\), \((\beta + 1)(r_e + R_L)\)이다. 소스 저항을 남기면 \(A_{vo} = -g_mR_D/(1 + g_mR_S)\)로 이득을 내주고 안정성과 선형성을 얻는다.

4.1.5연습문제

기본

  1. \(g_m = 4\) mA/V, \(R_D = 10\) kΩ, \(r_o = 50\) kΩ인 CS의 \(A_{vo}\)와 \(R_{out}\)은?
    답

    \(R_D \parallel r_o = 8.33\) kΩ이므로 \(A_{vo} = -33.3\), \(R_{out} = 8.33\) kΩ이다.

  2. \(I_C = 2\) mA, β = 100 이미터 폴로어의 \(R_{out}\)은(\(R_{sig} = 10\) kΩ)?
    답

    \(r_e \approx 12.4\) Ω에 \(10000/101 = 99\) Ω을 더해 약 111 Ω이다.

응용

  1. \(g_m = 2\) mA/V, \(R_D = 10\) kΩ인 CS에 소스 저항 1 kΩ을 남기면 \(A_{vo}\)는? \(g_m\)이 3 mA/V로 50% 늘면?
    답

    \(-20/3 = -6.67\)이고, \(g_m\)이 늘면 \(-30/4 = -7.5\)로 12.5%만 증가한다. 소스 저항이 없을 때는 −20에서 −30으로 50% 증가한다.

심화

  1. CG 증폭기의 입력 저항을 \(r_o\)까지 넣어 구하면 \(R_{in} = \frac{r_o + R_D}{1 + g_mr_o}\)이다. \(R_D\)가 \(r_o\)에 견줄 만큼 크면(능동 부하, 5단원) 어떻게 되는가?
    답

    \(R_D = r_o\)이면 \(R_{in} \approx 2/g_m\)으로 두 배가 된다. \(R_D \to \infty\)면 \(R_{in}\)도 커지므로, CG의 입력 저항이 작다는 말은 \(R_D \ll r_o\)일 때만 맞다.
