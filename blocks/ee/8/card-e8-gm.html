같은 전류, 다른 과구동 전압: gm 설계

예제 · 이득 사양에서 W/L과 V_OV 정하기

먼저 예측

전류 0.2 mA만 쓸 수 있는 센서 증폭기에서 공통 소스 이득 −20을 얻으려 한다. \(R_D\)를 키우는 것 말고, 트랜지스터 쪽에서 바꿀 수 있는 것은 무엇일까?

생각해 본 뒤 열기

\(V_{OV}\)를 낮추면(W/L을 키우면) 같은 전류에서 \(g_m = 2I_D/V_{OV}\)가 커진다.

문제

\(V_{DD} = 1.8\) V, \(I_D = 0.2\) mA, 공통 소스 증폭기의 이득 \(|A_v| = g_mR_D = 20\)이 목표이다. \(k_n' = 400\) μA/V², \(V_t = 0.4\) V, \(\lambda = 0\). 드레인 직류 전압은 0.9 V로 둔다. (가) \(R_D\), (나) 필요한 \(g_m\)과 \(V_{OV}\), (다) W/L, (라) 포화 여유를 확인하여라.

전략

  1. \(R_D\)는 직류 조건(\(V_D\))에서 정해진다.
  2. 이득에서 \(g_m\), 전류에서 \(V_{OV} = 2I_D/g_m\).
  3. \(k_n = 2I_D/V_{OV}^2\)에서 W/L.

풀이

  1. \(R_D = (1.8 - 0.9)/0.2\text{ mA} = 4.5\) kΩ. 직류 KVL
  2. \(g_m = 20/4.5\text{ k} = 4.44\) mA/V, \(V_{OV} = 2 \times 0.2/4.44 = 0.09\) V. \(g_m = 2I_D/V_{OV}\)
  3. \(k_n = 2 \times 0.2/0.09^2 = 49.4\) mA/V², \(W/L = 49.4/0.4 \approx 123\). \(k_n = k_n'W/L\)
  4. \(V_{DS} = 0.9\) V ≥ \(V_{OV} = 0.09\) V로 포화 여유가 충분하다. 소신호 조건으로 입력 첨두는 약 \(0.2V_{OV} = 18\) mV 이하, 그때 출력 첨두 약 0.36 V. 확인

의미

같은 전류에서 이득을 얻으려면 \(V_{OV}\)를 작게, 소자를 크게 만든다. 그러나 \(V_{OV}\)가 0.1 V보다 작아지면 제곱 법칙이 잘 맞지 않고(약반전 영역, 지수 법칙에 가까워짐) \(g_m\)은 \(I_D/(nV_T)\) 근처에서 더 늘지 않습니다(확인 필요: n은 1.2~1.5 정도로 공정마다 다름). 또 W/L이 커지면 입력 정전 용량이 커져 고주파 성능이 나빠집니다(전전13). 이 예제의 \(V_{OV} = 0.09\) V는 그 경계에 있으므로 실제 설계에서는 시뮬레이터로 확인해야 한다.

검산

\(g_m = \sqrt{2k_nI_D} = \sqrt{2 \times 49.4 \times 0.2} = 4.44\) mA/V. \(g_mR_D = 4.44 \times 4.5 = 20\). 일치한다.
