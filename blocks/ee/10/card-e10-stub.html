25 Ω 부하를 단일 스텁으로 정합하기

예제 · 어드미턴스로 따라가는 설계

먼저 예측

50 Ω 선로에 25 Ω 부하를 달면 반사가 생깁니다. 단락된 선로 조각 하나로 반사를 없앨 수 있을까요?

생각해 본 뒤 열기

됩니다. 부하에서 적당히 떨어진 곳의 어드미턴스 실수부가 1/50 S가 되는 점에 스텁을 병렬로 달아 허수부를 지웁니다.

문제

Z₀ = 50 Ω, Z_L = 25 Ω, 주파수 1 GHz, 선로 속력 2×10⁸ m/s(λ = 20 cm). 병렬 단락 스텁 정합의 위치 d와 스텁 길이 \(l_s\)를 cm로 구하고, 정합 전후의 반사 전력을 비교하라.

전략

  1. 정규화 어드미턴스 \(y_L = Z_0/Z_L = 2\).
  2. \(y(d) = (y_L + jt)/(1 + jy_Lt)\)의 실수부 = 1에서 t.
  3. 단락 스텁 어드미턴스 \(-j\cot\beta l_s\).

풀이

  1. Re y(d) = 1: \(\frac{2(1 + t^2)}{1 + 4t^2} = 1\) → \(t^2 = 1/2\), t = 0.7071. 조건식
  2. βd = arctan 0.7071 = 0.6155 rad, d = 0.098λ = 1.96 cm. 이때 y = 1 − j0.7071. 위치
  3. 스텁은 +j0.7071: \(-\cot\beta l_s = 0.7071\), \(\beta l_s = \pi - \arctan1.414 = 2.186\) rad, \(l_s = 0.348\lambda = 6.96\) cm. 스텁 길이
  4. 정합 전 |Γ| = 1/3, 반사 11.1% → 정합 후 이 주파수에서 0. 결과

의미

다른 해(d = 0.402λ, \(l_s\) = 0.152λ)도 있으며, 부하에 가까운 위치와 짧은 스텁의 조합이 주파수 변화에 덜 민감합니다. 실제 설계에서는 Smith 도표나 회로 시뮬레이터로 두 해를 비교하고, 커넥터와 스텁 접합부의 영향을 측정으로 보정합니다.

검산

Re y(d) 실수부 식에 t² = 0.5를 넣으면 2 × 1.5/3 = 1. 허수부 \(\mathrm{Im}\,y = t(1 - y_L^2)/(1 + y_L^2t^2) = 0.7071 \times (-3)/3 = -0.7071\). 일치합니다.

이해 확인

같은 문제를 개방 스텁으로 하면 d = 0.098λ 해의 스텁 길이는?

답

개방 스텁 어드미턴스 \(j\tan\beta l\) = j0.7071: l = 0.098λ = 1.96 cm.
