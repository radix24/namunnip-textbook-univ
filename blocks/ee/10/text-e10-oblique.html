경사 입사의 반사 계수

본문
이 절에서 배울 것
  • 경사 입사에서 TE(수직 편광)와 TM(평행 편광)을 구별한다.
  • Fresnel 식으로 두 편광의 반사 계수를 계산한다.
  • TM 반사가 Brewster 각에서 0이 됨을 확인한다.
먼저 알아야 할 것
  • 수직 입사 반사 (3.1절), Snell 법칙 (3.2절).

3.3.1두 편광

비자성 매질에서 굴절률 n₁, n₂, 입사각 θ_i, 굴절각 θ_t일 때

\[ \Gamma_{TE} = \frac{n_1\cos\theta_i - n_2\cos\theta_t}{n_1\cos\theta_i + n_2\cos\theta_t}, \quad \Gamma_{TM} = \frac{n_2\cos\theta_i - n_1\cos\theta_t}{n_2\cos\theta_i + n_1\cos\theta_t}. \]
예제 3.3.1

공기에서 유리(n = 1.5)로 45° 입사할 때 두 편광의 반사 계수와 반사율은?

풀이. θ_t = sin⁻¹(sin45°/1.5) = 28.1°. Γ_TE = −0.303(반사율 9.2%), Γ_TM = 0.092(반사율 0.85%). TM이 훨씬 적게 반사되어, 물 표면 반사광이 TE 쪽으로 편광되고 편광 선글라스가 이를 막습니다.

흔한 오해(1) "반사율은 편광과 무관": 수직 입사가 아니면 크게 다릅니다. (2) "Brewster 각에서는 모든 빛이 투과": TM 성분만 반사가 0입니다.
요약
  1. Γ_TE, Γ_TM(Fresnel 식).
  2. 예: 45°, n = 1.5 → TE 9.2%, TM 0.85%.
  3. Γ_TM = 0이 Brewster 각.

3.3.2연습문제

기본

  1. 수직 입사(θ = 0)에서 두 계수의 크기는?
    답

    같음(|Γ| = 0.2, n = 1.5).

응용

  1. n = 1.5의 Brewster 각은?
    답

    tan⁻¹1.5 = 56.3°.

심화

  1. 입사각이 90°에 가까워지면 반사율은?
    답

    두 편광 모두 1에 가까워집니다(스치는 빛).
