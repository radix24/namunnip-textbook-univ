1/4 파장 변환기로 정합하기

본문
이 절에서 배울 것
  • 1/4 파장 선로의 입력 임피던스 \(Z_{in} = Z_1^2/Z_L\)을 유도한다.
  • 실수 부하를 정합하는 변환기 특성 임피던스 \(Z_1 = \sqrt{Z_0Z_L}\)를 구한다.
  • 주파수가 바뀔 때 정합이 깨지는 정도를 안다.
먼저 알아야 할 것
  • 입력 임피던스 (4.2절).

4.6.1임피던스 뒤집기

\(Z_{in} = Z_1\frac{Z_L + jZ_1\tan\beta l}{Z_1 + jZ_L\tan\beta l}\)에서 \(\beta l = \pi/2\)면 \(Z_{in} = Z_1^2/Z_L\)입니다. 그래서 \(Z_1 = \sqrt{Z_0Z_L}\)이면 입력이 Z₀가 되어 반사가 0입니다.

예제 4.6.1

50 Ω 선로에 100 Ω 부하를 1 GHz에서 정합하라. 변환기 Z₁과 길이(공기 선로)는?

풀이. Z₁ = √5000 = 70.7 Ω, 길이 λ/4 = 7.5 cm. 1.2 GHz에서는 길이가 0.3λ가 되어 반사 계수 크기가 약 0.1로 커집니다(정확한 계산은 입력 임피던스 식으로).

흔한 오해(1) "복소 부하도 바로 정합된다": 실수 부하만 바로 되고, 복소 부하는 먼저 선로로 실수 점까지 옮깁니다. (2) "넓은 대역에서 정합": 단일 단은 대역이 좁아 여러 단을 씁니다.
요약
  1. λ/4 선로: Z_in = Z₁²/Z_L.
  2. Z₁ = √(Z₀Z_L).
  3. 예: 50 ↔ 100 Ω → 70.7 Ω, 7.5 cm(1 GHz).
