전송선로 방정식과 특성 임피던스

본문
이 절에서 배울 것
  • 단위 길이 R, L, G, C로 전송선로를 모형화하고 전신 방정식을 유도한다.
  • 특성 임피던스 \(Z_0 = \sqrt{(R + j\omega L)/(G + j\omega C)}\)와 무손실 \(Z_0 = \sqrt{L/C}\)를 안다.
  • 동축 케이블과 평행 도선의 \(Z_0\)를 형상으로 계산한다.
먼저 알아야 할 것
  • 평면파 (1.1절), 정전 용량과 인덕턴스 (전전7 3.3절, 5.3절), KVL·KCL.

4.1.1분포 정수 모형

선로가 파장에 비해 길면 전압과 전류가 위치에 따라 달라 집중 소자 회로로 다룰 수 없습니다. 길이 Δz의 짧은 조각을 직렬 RΔz, LΔz와 병렬 GΔz, CΔz로 나타내고 KVL, KCL을 쓴 뒤 Δz → 0으로 보내면(페이저)

\[ \frac{dV}{dz} = -(R + j\omega L)I, \qquad \frac{dI}{dz} = -(G + j\omega C)V. \]

둘을 합치면 \(d^2V/dz^2 = \gamma^2V\), \(\gamma = \sqrt{(R + j\omega L)(G + j\omega C)}\)로 1.1절의 평면파와 같은 꼴입니다. 해 \(V = V_0^+e^{-\gamma z} + V_0^-e^{\gamma z}\), 진행파 하나의 전압/전류 비가 특성 임피던스입니다.

\[ Z_0 = \sqrt{\frac{R + j\omega L}{G + j\omega C}} \xrightarrow{\text{무손실}} \sqrt{\frac LC}, \qquad v = \frac{1}{\sqrt{LC}}. \]

4.1.2형상에서 Z₀

동축 케이블(내부 반지름 a, 외부 b, 유전체 ε_r): \(L = \frac{\mu}{2\pi}\ln\frac ba\), \(C = \frac{2\pi\epsilon}{\ln(b/a)}\)이므로

\[ Z_0 = \frac{60}{\sqrt{\epsilon_r}}\ln\frac ba\ \Omega. \]
예제 4.1.1

RG-58 동축(내부 도체 지름 0.81 mm, 유전체 지름 2.95 mm, 폴리에틸렌 ε_r = 2.25)의 Z₀, 속력, 1 m당 지연을 구하라.

풀이. \(\ln(1.475/0.405) = 1.293\), \(Z_0 = 40 \times 1.293 \approx 51.7\) Ω(공칭 50 Ω). 속력 \(c/1.5 = 2.0\times10^8\) m/s, 1 m당 5 ns. 측정 장비의 50 Ω 표준이 이 케이블에서 왔습니다.

흔한 오해(1) "Z₀는 선로 길이에 비례하는 저항이다": 단위 길이 값의 비로 정해지는 상수이고 길이와 무관합니다. 멀티미터로 잴 수 없습니다. (2) "짧은 선로에도 늘 전송선로 이론이 필요하다": 길이가 파장의 1/10보다 훨씬 짧으면(또는 신호 상승 시간이 왕복 지연보다 훨씬 길면) 집중 소자로 충분합니다.
요약
  1. 전신 방정식: \(dV/dz = -(R + j\omega L)I\), \(dI/dz = -(G + j\omega C)V\).
  2. \(Z_0 = \sqrt{(R + j\omega L)/(G + j\omega C)}\), 무손실 \(\sqrt{L/C}\), \(v = 1/\sqrt{LC}\).
  3. 동축 \(Z_0 = (60/\sqrt{\epsilon_r})\ln(b/a)\).

4.1.3연습문제

기본

  1. L = 250 nH/m, C = 100 pF/m 무손실 선로의 Z₀와 속력은?
    답

    50 Ω, 2×10⁸ m/s.

응용

  1. 공기 동축에서 Z₀ = 75 Ω이 되는 b/a는?
    답

    \(\ln(b/a) = 1.25\), b/a ≈ 3.49.

심화

  1. R = 0.1 Ω/m, G = 0, L = 250 nH/m, C = 100 pF/m, 100 MHz에서 Z₀의 허수부는 실수부에 비해 얼마나 작은가?
    답

    \(R/(\omega L) = 0.1/157 \approx 6.4\times10^{-4}\), Z₀ ≈ 50(1 − j3.2×10⁻⁴) Ω. 무손실 근사가 충분합니다.
