수직 입사의 반사 계수와 정재파비

본문
이 절에서 배울 것
  • 두 매질 경계에서 접선 성분의 연속 조건으로 반사·투과 계수를 구한다.
  • \(\Gamma = (\eta_2 - \eta_1)/(\eta_2 + \eta_1)\)와 반사 전력 비 \(|\Gamma|^2\)를 계산한다.
  • 정재파비 \(\text{SWR} = (1 + |\Gamma|)/(1 - |\Gamma|)\)와 최대·최소 위치를 안다.
먼저 알아야 할 것
  • 평면파와 고유 임피던스 (1.1절), 시변 경계 조건 (전전7 6.3절).

3.1.1반사 계수

매질 1(η₁)에서 경계 z = 0에 수직으로 들어온 파 \(E_0e^{-jk_1z}\)가 반사파 \(\Gamma E_0e^{jk_1z}\)와 투과파 \(\tau E_0e^{-jk_2z}\)를 만듭니다. 경계에서 E와 H의 접선 성분이 연속이어야 하므로 \(1 + \Gamma = \tau\), \((1 - \Gamma)/\eta_1 = \tau/\eta_2\)에서

\[ \Gamma = \frac{\eta_2 - \eta_1}{\eta_2 + \eta_1}, \qquad \tau = \frac{2\eta_2}{\eta_2 + \eta_1}. \]

반사 전력 비는 \(|\Gamma|^2\), 투과 전력 비는 \(1 - |\Gamma|^2\)입니다(τ²이 아님에 주의, 고유 임피던스가 다르므로).

3.1.2정재파

매질 1에서는 입사파와 반사파가 겹쳐 |E|가 위치에 따라 \(1 + |\Gamma|\)와 \(1 - |\Gamma|\) 사이를 오갑니다. 최대와 최소는 반 파장마다 반복되고 서로 4분의 1 파장 떨어집니다.

정재파비 \(\text{SWR} = \dfrac{|E|_{max}}{|E|_{min}} = \dfrac{1 + |\Gamma|}{1 - |\Gamma|}\). 반사가 없으면 1, 완전 반사면 무한대.

예제 3.1.1

공기에서 유리(ε_r = 4)로 수직 입사. Γ, τ, 반사 전력 비, SWR을 구하라. 완전 도체 벽이면?

풀이. η₂ = 188.4 Ω, \(\Gamma = (188.4 - 376.7)/(565.1) = -1/3\), τ = 2/3, 반사 전력 1/9 ≈ 11.1%, SWR = (4/3)/(2/3) = 2. 음의 Γ는 반사 전계가 뒤집힌다는 뜻이라 경계에서 |E|가 최소입니다. 완전 도체(η₂ = 0)면 Γ = −1, 모두 반사, SWR = ∞, 벽에서 E = 0.

흔한 오해(1) "투과 계수 τ가 1보다 크면 에너지가 늘어난 것이다": τ는 전계 비이고 전력 비는 \((\eta_1/\eta_2)|\tau|^2\)입니다. 공기 → 유리의 반대 방향이면 τ = 4/3이지만 전력 비는 8/9입니다. (2) SWR이 작을수록 반사가 작습니다(1이 이상적).
요약
  1. \(\Gamma = (\eta_2 - \eta_1)/(\eta_2 + \eta_1)\), \(\tau = 1 + \Gamma\).
  2. 반사 전력 \(|\Gamma|^2\), 투과 전력 \(1 - |\Gamma|^2\).
  3. SWR = \((1 + |\Gamma|)/(1 - |\Gamma|)\). 최대·최소 간격 λ/4.

3.1.3연습문제

기본

  1. 공기에서 물(ε_r = 81, 손실 무시)로 수직 입사할 때 Γ와 반사 전력 비는?
    답

    η₂ = 41.9 Ω, Γ = −0.8, 64%.

응용

  1. SWR = 3이면 |Γ|와 반사 전력 비는?
    답

    |Γ| = 0.5, 25%.

심화

  1. 유리에서 공기로(반대 방향) 수직 입사할 때 Γ, τ와 전력 보존을 확인하라.
    답

    Γ = +1/3, τ = 4/3. 투과 전력 비 \((\eta_1/\eta_2)\tau^2 = (188.4/376.7)(16/9) = 8/9\), 반사 1/9, 합 1.
