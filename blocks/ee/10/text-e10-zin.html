부하가 있는 선로의 입력 임피던스

본문
이 절에서 배울 것
  • 부하 반사 계수 \(\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)\)를 구한다.
  • 길이 l 선로의 입력 임피던스 \(Z_{in} = Z_0\frac{Z_L + jZ_0\tan\beta l}{Z_0 + jZ_L\tan\beta l}\)를 계산한다.
  • 4분의 1 파장 변환기, 단락·개방 스텁의 성질을 안다.
먼저 알아야 할 것
  • 전송선로 방정식 (4.1절), 정재파비 (3.1절), 이 절의 탐구 카드.

4.2.1입력 임피던스

부하 \(Z_L\)에서 \(V/I = Z_L\) 조건이 반사 계수 \(\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)\)를 정합니다. 부하에서 거리 l 떨어진 곳에서 본 임피던스는 입사파와 반사파의 위상이 βl씩 달라져

\[ Z_{in} = Z_0\frac{Z_L + jZ_0\tan\beta l}{Z_0 + jZ_L\tan\beta l}. \]

반 파장마다 같은 값이 반복되며, 정합(\(Z_L = Z_0\))이면 어디서나 \(Z_0\)입니다.

예제 4.2.1

Z₀ = 50 Ω 선로에 Z_L = 100 Ω. (가) Γ_L와 SWR, (나) l = λ/4와 λ/8에서의 Z_in.

풀이. (가) Γ = 50/150 = 1/3, SWR = 2. (나) λ/4: tan βl → ∞라 \(Z_{in} = Z_0^2/Z_L = 25\) Ω. λ/8: tan βl = 1, \(Z_{in} = 50\frac{100 + j50}{50 + j100} = 40 - j30\) Ω. 이 절의 탐구 카드에서 위치에 따른 전압 정재파를 볼 수 있습니다.

4.2.2특별한 길이

  • λ/4 변환기: \(Z_{in} = Z_0^2/Z_L\). 100 Ω 부하를 50 Ω에 맞추려면 \(Z_0 = \sqrt{50 \times 100} \approx 70.7\) Ω의 λ/4 선로를 넣는다.
  • 단락 스텁(Z_L = 0): \(Z_{in} = jZ_0\tan\beta l\). 길이로 원하는 리액턴스(인덕터·축전기)를 만든다.
  • 개방 스텁: \(Z_{in} = -jZ_0\cot\beta l\).
흔한 오해(1) "선로가 무손실이면 입력 임피던스는 부하와 같다": 길이에 따라 크게 바뀝니다(100 Ω → 25 Ω). (2) λ/4 변환기는 한 주파수에서만 정확합니다. 주파수가 바뀌면 길이가 λ/4가 아니게 됩니다.
요약
  1. \(\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)\).
  2. \(Z_{in} = Z_0(Z_L + jZ_0\tan\beta l)/(Z_0 + jZ_L\tan\beta l)\), 반 파장 주기.
  3. λ/4: \(Z_0^2/Z_L\). 스텁으로 리액턴스.

4.2.3연습문제

기본

  1. Z₀ = 50 Ω, Z_L = 50 Ω일 때 임의 길이의 Z_in은?
    답

    50 Ω.

응용

  1. Z₀ = 50 Ω 단락 스텁으로 1 GHz에서 +j50 Ω을 만들려면 길이는(속력 2×10⁸ m/s)?
    답

    tan βl = 1, βl = π/4, l = λ/8 = 0.2 m/8 = 25 mm.

심화

  1. Z_L = 25 Ω을 50 Ω 선로에 λ/4 변환기로 맞추려면 변환기의 Z₀는?
    답

    \(\sqrt{50 \times 25} \approx 35.4\) Ω.
