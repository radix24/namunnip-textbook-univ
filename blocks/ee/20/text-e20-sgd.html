4.3.1싸지만 시끄러운 기울기

손실이 표본 합 \(\frac1n\sum f_i(x)\)이면, 무작위 표본 i의 \(\nabla f_i\)는 전체 기울기의 불편 추정입니다. 계산이 n배 싸지만 잡음이 있어, 학습률을 점점 줄이거나 미니배치로 평균해 분산을 줄입니다.

import numpy as np
rng = np.random.default_rng(0)
n = 1000
x = rng.uniform(-1, 1, n); y = 2.0 * x + 1.0 + rng.normal(0, 0.1, n)
w = np.zeros(2)
for epoch in range(5):
    for i in rng.permutation(n):
        lr = 0.1 / (1 + 0.01 * epoch * n / 100)
        g = (w[0] + w[1] * x[i] - y[i]) * np.array([1.0, x[i]])
        w -= lr * g
    print(f"에폭 {epoch + 1}: 절편 {w[0]:.4f}, 기울기 {w[1]:.4f}")
A = np.c_[np.ones(n), x]
print("최소제곱 해:", np.round(np.linalg.lstsq(A, y, rcond=None)[0], 4))

실행 결과(Python 3.12에서 실제 실행):

에폭 1: 절편 0.9815, 기울기 2.0235
에폭 2: 절편 1.0047, 기울기 1.9613
에폭 3: 절편 0.9746, 기울기 1.9957
에폭 4: 절편 1.0311, 기울기 2.0267
에폭 5: 절편 0.9756, 기울기 1.9750
최소제곱 해: [0.9988 1.999 ]
예제 4.3.1

위 실행에서 SGD가 최소제곱 해에 가까워지는가? 학습률을 줄이지 않으면 어떻게 되는가?

풀이. 몇 에폭 만에 최소제곱 해(약 1.0, 2.0)에 가까워집니다. 학습률을 일정하게 두면 마지막까지 잡음만큼 해 주변에서 흔들려 정밀도가 제한됩니다. 딥러닝은 거대한 n 때문에 전체 기울기 계산이 불가능해 SGD 계열을 씁니다.

흔한 오해(1) "SGD는 경사하강보다 부정확해 쓸모없다": 같은 계산량에서 훨씬 빨리 좋은 해에 다가갑니다. (2) "미니배치는 클수록 좋다": 분산은 줄지만 계산이 늘고 일반화가 나빠지기도 합니다(확인 필요).
요약
  1. 표본 기울기 = 불편 추정, 계산 n배 절약.
  2. 잡음 → 학습률 감소·미니배치.
  3. 예: 5 에폭에 최소제곱 해 근처.
