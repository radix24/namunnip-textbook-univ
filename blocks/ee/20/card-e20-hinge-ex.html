SVM 한 단계 갱신

부분 기울기 하강

출발점

정규화 항과 힌지 항의 기울기를 더해 갱신합니다(5.3절).

문제 해결 전략 · w ← w − η(λw − yx)
  1. 여유를 계산한다.
  2. 여유 < 1이면 −yx를 더한다.
  3. η로 갱신한다.

w = (0, 0), b = 0, λ = 0.1, η = 0.5. 표본 x = (2, 1), y = −1로 한 번 갱신하면?

풀이

  1. 여유 0 < 1 → 힌지 기울기 −yx = (2, 1), b 기울기 −y = 1.
    벌점 활성.
  2. w ← (0, 0) − 0.5((0, 0) + (2, 1)) = (−1, −0.5), b = −0.5.
    갱신.
  3. 새 여유 −1 × (−2 − 0.5 − 0.5) = 3 ≥ 1.
    이제 만족.

의미

Pegasos 같은 SVM 학습 알고리즘이 이 갱신을 반복합니다(확인 필요: 세부 학습률).

검산

wᵀx + b = −2 − 0.5 − 0.5 = −3.
