선형계획의 쌍대성

본문

공장이 원료로 제품을 만들어 이익을 최대화하는 문제가 있다. 같은 원료를 사들이려는 사람이 "원료에 얼마를 쳐 주면 공장이 팔겠는가"를 묻는 문제를 세우면, 그 최솟값이 공장의 최대 이익과 정확히 같다. 이것이 쌍대성이다. 쌍대 변수는 제약 하나를 조금 풀 때 목적 함수가 얼마나 좋아지는지, 곧 자원의 그림자 가격이다.

먼저 알아야 할 것표준형과 단체법(6.1절), 라그랑주 쌍대 문제(4.2절)를 쓴다.

6.2.1쌍대 문제와 쌍대 정리

원문제 \(\max\mathbf c^{\mathsf T}\mathbf x\), \(A\mathbf x \le \mathbf b\), \(\mathbf x \ge 0\)의 쌍대 문제는 \(\min\mathbf b^{\mathsf T}\mathbf y\), \(A^{\mathsf T}\mathbf y \ge \mathbf c\), \(\mathbf y \ge 0\)이다. 원문제의 제약 하나가 쌍대 변수 하나가 되고, 원문제의 변수 하나가 쌍대 제약 하나가 된다. 허용해 \(\mathbf x\), \(\mathbf y\)에 대해 \(\mathbf c^{\mathsf T}\mathbf x \le (A^{\mathsf T}\mathbf y)^{\mathsf T}\mathbf x = \mathbf y^{\mathsf T}A\mathbf x \le \mathbf y^{\mathsf T}\mathbf b\)이므로 약쌍대성이 성립한다. 그리고 한쪽에 최적해가 있으면 다른 쪽에도 있고 최적값이 같다는 강쌍대성이 성립한다. 따라서 어떤 쌍대 허용해를 찾으면 원문제 최적값의 상한을 얻고, 두 값이 같으면 둘 다 최적임을 증명한 것이 된다.

6.2.2상보 여유와 그림자 가격

최적해에서 \(y_i(b_i - (A\mathbf x)_i) = 0\)과 \(x_j((A^{\mathsf T}\mathbf y)_j - c_j) = 0\)이 성립한다. 이것이 상보 여유 조건이다. 남는 자원(제약이 느슨한 것)의 그림자 가격은 0이고, 가격이 양수인 자원은 다 쓰인다. 또 \(y_i\)는 \(b_i\)를 1 늘릴 때 최적값이 늘어나는 양이다. 그러므로 자원을 더 살지 판단할 때 그 값을 쓴다. 단체법의 최종 단체표에서 여유 변수 열의 목적 함수 계수가 바로 이 쌍대 해이다.

예제 6.2.1

6.1절 예제(\(\max 3x_1 + 2x_2\), \(x_1 + x_2 \le 4\), \(x_1 + 3x_2 \le 6\))의 쌍대 문제를 쓰고 최적 쌍대 해를 구하여라.

풀이. 쌍대는 \(\min 4y_1 + 6y_2\), 제약 \(y_1 + y_2 \ge 3\), \(y_1 + 3y_2 \ge 2\), \(y \ge 0\)이다. 원문제 최적해 \(x = (4, 0)\)에서 둘째 제약은 \(4 < 6\)으로 느슨하므로 상보 여유로 \(y_2 = 0\)이다. 그리고 \(x_1 > 0\)이라 첫 쌍대 제약이 등식 \(y_1 + y_2 = 3\)이 되어 \(y_1 = 3\)이다. 그러면 쌍대 값은 \(4\times3 = 12\)로 원문제 최적값과 같다. 첫째 자원을 하나 더 얻으면 이익이 3 늘어난다.

마무리

선형계획의 쌍대 문제는 원문제의 제약과 변수를 맞바꾼 문제로, 원문제 허용해 값은 언제나 쌍대 허용해 값 이하이고 최적값은 같다. 상보 여유 조건은 느슨한 제약의 쌍대 변수가 0이고 양의 쌍대 변수를 가진 제약은 꽉 찬다는 것을 말한다. 쌍대 변수는 자원 한 단위의 그림자 가격이다.

6.2.3연습문제

기본

  1. 예제에서 첫째 자원이 4에서 5로 늘면 최적값은?
    답

    그림자 가격 3만큼 늘어 15 (\(x = (5, 0)\), 둘째 제약 \(5 \le 6\) 유지).

응용

  1. 원문제가 비유계이면 쌍대 문제는 어떤 상태인가?
    답

    약쌍대성 때문에 쌍대 허용해가 있을 수 없어 쌍대 문제는 허용해가 없다.
