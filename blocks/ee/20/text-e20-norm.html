노름, 내적, 직교 분해의 공학적 쓰임

본문
이 절에서 배울 것
  • 벡터 노름(ℓ₁, ℓ₂, ℓ∞)과 내적을 정의하고 신호의 크기·유사도에 쓴다.
  • 부분공간 정사영으로 벡터를 성분과 나머지로 직교 분해한다.
  • 상관(코사인 유사도)과 잡음 제거에 적용한다.
먼저 알아야 할 것
  • 선형대수 (전전16 3.1절).

1.1.1노름

\(\|x\|_2 = \sqrt{\sum x_i^2}\)(에너지), \(\|x\|_1 = \sum|x_i|\)(절댓값 합), \(\|x\|_\infty = \max|x_i|\)(최대). 신호 n개 표본의 실효값은 \(\|x\|_2/\sqrt n\).

코사인 유사도 \(\cos\theta = \frac{\langle x, y\rangle}{\|x\|\|y\|}\)는 크기와 무관한 모양의 닮음입니다(정합 필터, 패턴 인식).

예제 1.1.1

b = (1, 2, 2)를 a = (1, 1, 0) 방향 성분과 나머지로 나누고, 두 성분이 직교함을 확인하라.

풀이. 정사영 \(\frac{a^Tb}{a^Ta}a = \frac32(1, 1, 0) = (1.5, 1.5, 0)\). 나머지 (−0.5, 0.5, 2). 내적 −0.75 + 0.75 + 0 = 0. 노름 \(\|b\|^2 = 9 = 4.5 + 4.5\)(피타고라스).

측정 신호에서 알려진 간섭(예: 60 Hz 사인과 코사인이 펼치는 부분공간)의 정사영을 빼면 그 간섭을 제거할 수 있습니다.

흔한 오해(1) "노름은 하나뿐이다": 목적에 따라 다릅니다(ℓ₁은 희소성, ℓ∞는 최악값). (2) "내적 0이면 두 신호가 무관하다": 선형 상관이 없다는 뜻입니다.
요약
  1. ℓ₂ 에너지, ℓ₁ 절댓값 합, ℓ∞ 최대.
  2. 정사영 (aᵀb/aᵀa)a, 나머지와 직교, 피타고라스.
  3. 코사인 유사도, 간섭 부분공간 제거.

1.1.2연습문제

기본

  1. (3, −4)의 ℓ₁, ℓ₂, ℓ∞는?
    답

    7, 5, 4.

응용

  1. (1, 0, 1)과 (1, 1, 0)의 코사인 유사도는?
    답

    1/2.

심화

  1. 신호 x에서 직류 성분(모든 원소 같은 방향)을 정사영으로 빼는 것은 무엇과 같은가?
    답

    평균을 빼는 것과 같습니다.
