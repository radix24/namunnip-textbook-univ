행렬 노름과 조건수

본문
이 절에서 배울 것
  • 유도 노름 \(\|A\| = \max\|Ax\|/\|x\|\)를 정의하고 2-노름이 최대 특이값임을 안다.
  • 1-노름(열 합 최대), ∞-노름(행 합 최대)을 계산한다.
  • 조건수로 문제의 민감도를 판단한다.
먼저 알아야 할 것
  • 노름과 내적 (1.1절), SVD (전전16 5단원).

1.2.1가장 많이 늘이는 배율

\(\|A\|_2 = \sigma_{max}\), \(\|A\|_1 = \max_j\sum_i|a_{ij}|\), \(\|A\|_\infty = \max_i\sum_j|a_{ij}|\). 조건수 \(\kappa_2 = \sigma_{max}/\sigma_{min}\)은 입력 상대 오차가 출력에서 몇 배까지 커지는지의 상한입니다.

예제 1.2.1

A = [[3, 1], [1, 3]]의 1, ∞, 2-노름과 조건수는?

풀이. 열 합·행 합 최대 4 → ‖A‖₁ = ‖A‖∞ = 4. 대칭이라 특이값 = |고유값| = 4, 2 → ‖A‖₂ = 4, κ = 2. 조건이 좋은 행렬입니다.

흔한 오해(1) "노름은 원소의 최댓값": 유도 노름은 벡터를 늘이는 최대 배율입니다. (2) "대칭 행렬의 조건수는 고유값 비가 아니다": 대칭이면 |고유값| 비가 곧 2-노름 조건수입니다.
요약
  1. ‖A‖₂ = σ_max, ‖A‖₁ 열 합 최대, ‖A‖∞ 행 합 최대.
  2. κ₂ = σ_max/σ_min.
  3. 예: [[3,1],[1,3]] → 4, κ 2.
