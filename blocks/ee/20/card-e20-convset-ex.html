안테나 빔 제약의 볼록성

선형 제약 · 노름 제약

출발점

빔포밍 설계의 제약이 볼록 집합이면 볼록 최적화로 풉니다(3.3절).

문제 해결 전략 · 제약 종류 판정
  1. 원하는 방향 이득 = 1(선형 등식).
  2. 다른 방향 이득 |aᵢᴴw| ≤ ε(노름 제약).
  3. 교집합 → 볼록.

목표 방향 이득 1, 간섭 방향 이득 ≤ 0.1, 가중치 크기 ‖w‖ ≤ 2의 실현 가능 집합은 볼록인가?

풀이

  1. 등식 aᴴw = 1: 아핀 집합.
    볼록.
  2. |bᴴw| ≤ 0.1, ‖w‖ ≤ 2: 노름 공 꼴.
    볼록.
  3. 교집합 → 볼록, 2차 원뿔 계획으로 풂.
    결론.

의미

제약을 볼록하게 세우면 수십 개 안테나의 설계도 확실히 최적을 찾는다.

검산

|bᴴw| ≥ 0.1처럼 부등호가 반대면 볼록이 아니다.
