라그랑주 쌍대 문제

본문
이 절에서 배울 것
  • 라그랑주 함수에서 쌍대 함수 \(g(\lambda) = \inf_xL(x, \lambda)\)를 구한다.
  • 약한 쌍대성(\(g \le p^*\))과 볼록 문제의 강한 쌍대성을 안다.
  • 쌍대 변수가 제약의 가격(민감도)임을 해석한다.
먼저 알아야 할 것
  • KKT (2.2절), 볼록 표준형 (3.2절).

4.2.1쌍대 함수

min f₀(x) s.t. fᵢ(x) ≤ 0의 라그랑주 함수 \(L = f_0 + \sum\lambda_if_i\)(λ ≥ 0). 쌍대 함수 \(g(\lambda) = \min_xL(x, \lambda)\)는 언제나 원 문제 최솟값 p*의 아래 경계입니다(약한 쌍대성). 쌍대 문제 \(\max_{\lambda\ge0}g(\lambda)\)의 값 d*가 볼록 문제(약한 조건 하)에서 p*와 같습니다(강한 쌍대성).

예제 4.2.1

min x² s.t. x ≥ 1(곧 1 − x ≤ 0)의 쌍대 문제를 쓰고 풀라.

풀이. \(L = x^2 + \lambda(1 - x)\). x로 최소: x = λ/2, \(g(\lambda) = \lambda - \lambda^2/4\). λ = 2에서 최대 g = 1. 원 문제 최소 p* = 1(x = 1)과 같습니다. λ* = 2는 제약을 1에서 1 + ε로 조이면 비용이 약 2ε 늘어난다는 뜻(그림자 가격)입니다.

통신의 전력 할당(물 채우기), 네트워크 혼잡 제어, SVM 학습이 쌍대 문제로 풀립니다.

흔한 오해(1) "쌍대 문제는 언제나 원 문제와 같은 값": 볼록하지 않으면 간격(duality gap)이 생길 수 있습니다. (2) "쌍대 변수는 계산 도구일 뿐": 제약의 민감도라는 물리적 의미가 있습니다.
요약
  1. g(λ) = min_x L(x, λ) ≤ p*(약한 쌍대성).
  2. 볼록 문제: d* = p*(강한 쌍대성).
  3. λ* = 제약의 그림자 가격. 예: min x², x ≥ 1 → λ* = 2.

4.2.2연습문제

기본

  1. 예제에서 λ = 1의 g는?
    답

    0.75(p* = 1보다 작음).

응용

  1. min (x − 2)² s.t. x ≤ 1의 λ*와 p*는?
    답

    L = (x−2)² + λ(x − 1): x = 2 − λ/2, g = λ − λ²/4 … λ* = 2, p* = 1.

심화

  1. 강한 쌍대성이 깨지는 간단한 예를 들라.
    답

    비볼록 문제, 예: min −x² s.t. −1 ≤ x ≤ 1 류(목적이 오목). 쌍대값이 원 최솟값보다 작을 수 있습니다(확인 필요: 구체 계산).
