라그랑주 쌍대 문제

본문

제약이 있는 최적화 문제를 직접 풀기 어려울 때, 제약 대신 "제약을 어기면 값을 치르는" 가격을 붙여 다른 문제로 바꿀 수 있다. 그 가격을 잘 고르면 원래 문제의 답을 얻을 수 있을까? 그리고 그 가격은 어떤 뜻을 가질까?

먼저 알아야 할 것KKT(2.2절), 볼록 표준형(3.2절)을 쓴다.

4.2.1쌍대 함수

min f₀(x) s.t. fᵢ(x) ≤ 0의 라그랑주 함수는 \(L = f_0 + \sum\lambda_if_i\)(λ ≥ 0)이다. 이것을 x로 최소화한 \(g(\lambda) = \min_xL(x, \lambda)\)를 쌍대 함수라 한다. 쌍대 함수는 언제나 원 문제 최솟값 p*의 아래 경계인데, 이것을 약한 쌍대성이라 한다. 처음 질문의 첫째 답의 출발점이 이것이다.

그래서 가장 좋은 아래 경계를 찾는 쌍대 문제 \(\max_{\lambda\ge0}g(\lambda)\)를 푼다. 그 값 d*는 볼록 문제에서 약한 조건만 만족하면 p*와 같은데, 이것을 강한 쌍대성이라 한다(그림 1). 즉 볼록 문제라면 가격을 잘 골라 원래 답을 얻을 수 있다.

예제 4.2.1

min x² s.t. x ≥ 1(곧 1 − x ≤ 0)의 쌍대 문제를 쓰고 풀라.

풀이. 라그랑주 함수는 \(L = x^2 + \lambda(1 - x)\)이다. x로 최소화하면 x = λ/2이고, \(g(\lambda) = \lambda - \lambda^2/4\)이다. 이것은 λ = 2에서 최대 g = 1이 되며, 원 문제의 최솟값 p* = 1(x = 1)과 같다.

또 λ* = 2는 뜻이 있다. 제약을 x ≥ 1에서 x ≥ 1 + ε로 조이면 비용이 약 2ε 늘어난다는 것으로, 곧 제약의 그림자 가격이다. 처음 질문의 둘째 답이 이것이다. 이런 뜻 때문에 통신의 전력 할당(물 채우기), 네트워크 혼잡 제어, SVM 학습(5.3절)이 쌍대 문제로 풀린다.

한편 쌍대 문제는 원 문제보다 풀기 쉬울 때가 많다. 쌍대 함수는 원 문제가 볼록이 아니어도 언제나 오목하고, 변수 수가 제약 수와 같아 원 문제보다 작을 수 있기 때문이다.

흔한 오해쌍대 문제가 언제나 원 문제와 같은 값을 준다고 여기기 쉽다. 볼록하지 않은 문제에서는 d* < p*인 간격(duality gap)이 생길 수 있다. 또 쌍대 변수는 계산 도구일 뿐이라고 생각하기 쉬운데, 제약을 조금 바꿀 때 최적값이 얼마나 변하는지라는 물리적 뜻이 있다.
마무리

쌍대 함수 g(λ) = min_x L(x, λ)는 p* 이하이다(약한 쌍대성). 볼록 문제에서는 d* = p*이다(강한 쌍대성). λ*는 제약의 그림자 가격이며, 예를 들어 min x², x ≥ 1이면 λ* = 2이다.

4.2.2연습문제

기본

  1. 예제에서 λ = 1의 g는?
    답

    0.75로 p* = 1보다 작다.

응용

  1. min (x − 2)² s.t. x ≤ 1의 λ*와 p*는?
    답

    L = (x−2)² + λ(x − 1)에서 x = 2 − λ/2, g = λ − λ²/4이므로 λ* = 2, p* = 1이다.

심화

  1. 강한 쌍대성이 깨지는 간단한 예를 들라.
    답

    비볼록 문제가 그렇다. 예를 들어 min −x² s.t. −1 ≤ x ≤ 1 류(목적이 오목)이다. 쌍대값이 원 최솟값보다 작을 수 있다(구체 계산은 확인 필요).
