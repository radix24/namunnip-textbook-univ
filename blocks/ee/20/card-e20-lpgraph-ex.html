발전기 배분을 그래프로

꼭짓점 비교

출발점

전력 배분 LP도 2변수면 그래프로 풉니다(3.4절).

문제 해결 전략 · 꼭짓점 목록
  1. 제약: p₁ + p₂ = 100, 0 ≤ p₁ ≤ 60, 20 ≤ p₂ ≤ 80.
  2. 실현 가능 선분의 끝점.
  3. 비용 2p₁ + 3p₂ 비교.

위 제약에서 비용 2p₁ + 3p₂의 최소는?

풀이

  1. 선분 끝점 (60, 40), (20, 80).
    등식 위.
  2. 비용 240, 280.
    비교.
  3. p₁ = 60, p₂ = 40, 240.
    싼 발전기 최대.

의미

3.2절 예제(최소 출력 제약 없음)와 같은 답이며, p₂ ≥ 20 제약은 묶이지 않는다.

검산

2 × 60 + 3 × 40 = 240.
