두 측정의 절충

스칼라 예

출발점

스칼라에서 해가 가중 평균이 됨을 확인합니다(2.3절).

문제 해결 전략 · (a + μc)/(1 + μ)
  1. J₁ = (x − a)², J₂ = (x − c)².
  2. 미분 = 0.
  3. μ에 따른 해.

a = 10, c = 12일 때 μ = 1, 4의 해와 J₁, J₂는?

풀이

  1. x = (10 + 12μ)/(1 + μ).
    식.
  2. μ = 1: x = 11, J₁ = J₂ = 1.
    같은 가중.
  3. μ = 4: x = 11.6, J₁ = 2.56, J₂ = 0.16.
    J₂ 쪽으로.

의미

μ가 두 목표의 상대 중요도(또는 신뢰도 비)이다.

검산

(10 + 48)/5 = 11.6.
