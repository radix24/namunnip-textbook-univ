볼록 최적화 표준형

본문
이 절에서 배울 것
  • 볼록 최적화 표준형(볼록 목적, 볼록 부등식, 아핀 등식)을 안다.
  • 선형 계획(LP), 이차 계획(QP)으로 공학 문제를 쓴다.
  • 볼록하지 않은 문제를 볼록하게 바꾸는 기법(변수 변환, 완화)을 안다.
먼저 알아야 할 것
  • 볼록 함수 (3.1절).

3.2.1표준형

\[ \min f_0(x)\quad\text{s.t.}\quad f_i(x) \le 0\ (i = 1..m),\quad Ax = b, \]

f₀, fᵢ가 볼록이면 볼록 문제입니다.

  • LP: 목적과 제약이 모두 선형. 예: 발전기 출력 배분의 비용 최소화.
  • QP: 목적이 볼록 이차, 제약 선형. 예: 정규화 최소제곱, 포트폴리오.
예제 3.2.1

발전기 둘(비용 2원/kW, 3원/kW, 최대 60, 80 kW)로 수요 100 kW를 공급하는 최소 비용 배분을 LP로 쓰고 풀라.

풀이. min 2p₁ + 3p₂, s.t. p₁ + p₂ = 100, 0 ≤ p₁ ≤ 60, 0 ≤ p₂ ≤ 80. 싼 발전기를 최대로: p₁ = 60, p₂ = 40, 비용 240원. LP의 해는 실현 가능 영역의 꼭짓점에 있습니다.

볼록하지 않은 문제는 변수 변환(예: 기하 계획의 로그 변환), 완화(정수 제약을 연속으로), 근사(국소 선형화)로 볼록 문제로 만들어 풉니다.

흔한 오해(1) "등식 제약은 아무 함수나 된다": 볼록 문제의 등식은 아핀이어야 합니다. (2) "LP는 꼭짓점을 다 세면 된다": 꼭짓점이 지수적으로 많아 단체법·내점법을 씁니다.
요약
  1. 볼록 목적 + 볼록 부등식 + 아핀 등식.
  2. LP, QP. LP 해는 꼭짓점.
  3. 변환·완화로 볼록화.

3.2.2연습문제

기본

  1. min x² s.t. x ≥ 2의 해는?
    답

    x = 2.

응용

  1. 예제에서 수요가 150 kW면?
    답

    p₁ = 60, p₂ = 80은 140이라 불가능(제약 위반) → 실현 가능 해 없음.

심화

  1. 등식 제약 x² + y² = 1은 볼록 문제에 넣을 수 있는가?
    답

    아닙니다(아핀이 아님). x² + y² ≤ 1로 완화하면 볼록입니다.
