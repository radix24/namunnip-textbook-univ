운동량 방법과 Adam

본문

등고선이 길쭉한 골짜기에서 경사하강법은 골짜기 벽 사이를 오가며 바닥을 따라서는 아주 천천히 나아간다(4.1절). 공이 굴러 내려가듯 지난 걸음의 속도를 조금 이어받으면 나아질까? 딥러닝에서 흔히 쓰는 Adam은 무엇을 더 할까?

먼저 알아야 할 것경사하강과 조건수(4.1절), SGD(4.3절)를 쓴다.

4.4.1속도를 쌓기

운동량 방법은 \(v \leftarrow \beta v - \alpha\nabla f\), \(x \leftarrow x + v\)로 걸음을 정한다. 즉 지난 걸음의 β배를 이어받는다. 그러면 골짜기 바닥처럼 일관된 방향으로는 속도가 쌓이고, 벽 사이를 오락가락하는 방향은 서로 상쇄된다. 처음 질문의 첫째 답이 이것이다.

또 Adam은 기울기의 이동 평균(1차 적률)과 기울기 제곱의 이동 평균(2차 적률)을 함께 쓴다. 1차 적률은 운동량 역할을 하고, 2차 적률로 매개변수마다 보폭을 따로 정한다. 처음 질문의 둘째 답이 이것이다. 아래 코드는 조건수 100인 이차 함수에서 경사하강과 운동량 방법의 반복 수를 비교한다.

import numpy as np
k = 100.0                                   # f = x² + k y², 조건수 100
grad = lambda p: np.array([2 * p[0], 2 * k * p[1]])
def run(beta, alpha):
    p, v = np.array([10.0, 1.0]), np.zeros(2)
    for it in range(1, 20001):
        v = beta * v - alpha * grad(p); p = p + v
        if np.linalg.norm(p) < 1e-6:
            return it
    return None
print("경사하강(α 0.0099):", run(0.0, 0.0099), "번")
print("운동량(β 0.9, α 0.0099):", run(0.9, 0.0099), "번")
print("운동량(β 0.81, α 0.0164):", run(0.81, 0.0164), "번")

실행 결과(Python 3.12에서 실제 실행)는 다음과 같다.

경사하강(α 0.0099): 807 번
운동량(β 0.9, α 0.0099): 271 번
운동량(β 0.81, α 0.0164): 148 번
예제 4.4.1

조건수 100인 위 문제에서 경사하강과 운동량 방법의 반복 수를 비교하라.

풀이. 실행 결과처럼 운동량 방법이 수 배 적은 반복으로 수렴한다(그림 1). 이론적으로도 최적 매개변수에서 경사하강의 수축 비 (κ − 1)/(κ + 1)이, 운동량(Heavy-ball)에서는 \((\sqrt\kappa - 1)/(\sqrt\kappa + 1)\)로 좋아진다. κ = 100이면 0.98 대 0.82이다.

즉 운동량은 조건수 κ의 영향을 √κ로 줄인다. 그래서 등고선이 길쭉할수록 이득이 크다. 다만 β와 α를 함께 잘 골라야 하며, 실무에서는 β = 0.9 정도로 두고 α만 조정하는 경우가 많다.

운동량을 물리로 보면 이해가 쉽다. x는 공의 위치, v는 속도, −∇f는 경사가 주는 힘이고, β는 마찰로 속도가 조금씩 줄어드는 비율이다. 그래서 β가 1에 가까울수록 마찰이 작아 공이 멀리 굴러가고, 그만큼 최소점을 지나쳐 출렁이기도 쉽다.

흔한 오해운동량은 언제나 안정하다고 여기기 쉽다. β와 α가 크면 쌓인 속도 때문에 최소점을 지나쳐 진동하거나 발산한다. 또 Adam이 언제나 최선이라고 생각하기 쉬운데, 문제에 따라서는 SGD에 운동량을 더한 방법이 새 자료에 대한 성능, 곧 일반화가 더 좋은 경우도 있다(확인 필요).
마무리

운동량 방법은 v ← βv − α∇f, x ← x + v이다. 최적 매개변수에서 수축 비는 (√κ − 1)/(√κ + 1)이다. Adam은 매개변수마다 보폭을 적응적으로 정한다.

기본

응용
