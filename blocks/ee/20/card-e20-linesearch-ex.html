곡률이 다른 함수에서의 백트래킹

자동 보폭

출발점

같은 규칙이 곡률에 맞게 다른 보폭을 줍니다(4.5절).

문제 해결 전략 · 두 함수 비교
  1. f₁ = x², f₂ = 10x²에서 x = 1.
  2. 경사 방향과 Armijo 조건.
  3. 받아들여지는 t를 비교한다.

x = 1에서 f₁ = x²(Δx = −2)과 f₂ = 10x²(Δx = −20)의 백트래킹 t(c 0.3, β 0.5)는?

풀이

  1. f₁: t = 0.5 → x = 0, 0 ≤ 1 − 0.6 → 받아들임.
    t = 1은 x = −1로 실패.
  2. f₂: t = 1, 0.5, 0.25, 0.125(x = −1.5), 0.0625 → x = −0.25, f = 0.625 ≤ 10 − 7.5 = 2.5 → 받아들임.
    곡률이 커서 작게.
  3. t가 곡률에 맞춰 자동으로 1/10 정도로 줄어듦.
    결론.

의미

고정 보폭이라면 곡률이 큰 쪽에 맞춰 작게 잡아야 해 다른 곳에서 느립니다.

검산

f₂(−0.25) = 0.625.
