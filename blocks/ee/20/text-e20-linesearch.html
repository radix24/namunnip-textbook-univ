선탐색: 보폭을 자동으로

본문

경사하강법의 보폭은 너무 크면 발산하고 너무 작으면 느리다. 그런데 함수의 곡률을 미리 알지 못하면 알맞은 보폭을 정할 수 없다. 반복마다 보폭을 자동으로 정하되, 함수 값이 확실히 줄어드는 만큼만 받아들이는 방법은 없을까?

먼저 알아야 할 것경사하강(4.1절)을 쓴다.

4.5.1충분히 내려갈 때까지 줄이기

백트래킹 선탐색은 보폭 t = 1에서 시작해, 아래 Armijo 조건을 만족할 때까지 t ← βt(β ≈ 0.5)로 줄인다. 처음 질문의 답이 이 방법이다.

\[ f(x + t\Delta x) \le f(x) + ct\,\nabla f^T\Delta x \]

오른쪽은 기울기로 예상한 감소의 c배(c ≈ 0.3)만큼 줄어든 값이다. 즉 함수 값이 예상의 일정 비율 이상 줄어들 때만 그 보폭을 받아들인다(그림 1). 그래서 곡률을 몰라도 발산하지 않는 보폭을 자동으로 찾는다.

예제 4.5.1

f(x) = x², x = 3에서 경사 방향 Δx = −6, c = 0.3, β = 0.5. 받아들여지는 첫 t는?

풀이. f(x) = 9이고 ∇fᵀΔx = −36이다. t = 1이면 x = −3, f = 9인데, 기준값 9 − 10.8 = −1.8보다 커서 거절한다. t = 0.5이면 x = 0, f = 0으로 기준값 9 − 5.4 = 3.6보다 작아 받아들인다.

이 경우에는 한 번에 최소점에 간다. 그러나 이것은 우연이 아니라, 곡률이 다른 함수에서도 같은 절차로 안전한 보폭을 찾는다는 데 의미가 있다. 곡률이 크면 보폭이 더 많이 줄고, 작으면 1에 가까운 보폭이 그대로 받아들여진다.

또 c와 β는 결과에 크게 민감하지 않다. c가 너무 크면 거의 모든 보폭을 거절해 진척이 느리고, β가 너무 작으면 보폭이 지나치게 줄어든다. 그래서 보통 c는 0.01~0.3, β는 0.3~0.8 사이에서 고른다(확인 필요).

흔한 오해보폭은 작을수록 안전하고 좋다고 여기기 쉽다. 너무 작은 보폭은 발산하지 않을 뿐 진척이 느려, 같은 정확도에 훨씬 많은 반복이 든다. 또 선탐색은 비싸다고 생각하기 쉬운데, 함수 값을 몇 번 더 계산하면 되므로 기울기 계산보다 싼 경우가 많다.
마무리

Armijo 조건은 f(x + tΔx) ≤ f(x) + ct∇fᵀΔx이다. 백트래킹은 조건을 만족할 때까지 t ← βt로 줄인다. 예를 들어 f = x²를 x = 3에서 줄이면 t = 0.5가 받아들여진다.

4.5.2연습문제

기본

  1. c = 0이면 조건의 뜻은?
    답

    조금이라도 줄어들면 받아들인다는 뜻이다.

응용

  1. f = 4x², x = 1, Δx = −8, c 0.3, β 0.5의 첫 t는?
    답

    t = 0.125이다(t = 0.25에서는 x = −1로 f가 같고, 0.125에서 x = 0).

심화

  1. Newton 방향에서 t = 1이 자주 받아들여지는 이유는?
    답

    이차 근사가 정확해 한 걸음이 적절하기 때문이다.
