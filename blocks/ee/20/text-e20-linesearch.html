선탐색: 보폭을 자동으로

본문
이 절에서 배울 것
  • 충분한 감소(Armijo) 조건 \(f(x + t\Delta x) \le f(x) + ct\nabla f^T\Delta x\)를 안다.
  • 백트래킹으로 t를 β배씩 줄이며 조건을 만족하는 보폭을 찾는다.
  • 고정 보폭과 비교한 장점을 안다.
먼저 알아야 할 것
  • 경사하강 (4.1절).

4.5.1충분히 내려갈 때까지 줄이기

t = 1에서 시작해 Armijo 조건(c ≈ 0.3)을 만족할 때까지 t ← βt(β ≈ 0.5)로 줄입니다. 곡률을 몰라도 발산하지 않는 보폭을 자동으로 찾습니다.

예제 4.5.1

f(x) = x², x = 3에서 경사 방향 Δx = −6, c = 0.3, β = 0.5. 받아들여지는 첫 t는?

풀이. f(x) = 9, ∇fᵀΔx = −36. t = 1: x = −3, f = 9 ≤ 9 − 10.8? 아니오. t = 0.5: x = 0, f = 0 ≤ 9 − 5.4 = 3.6 → 받아들임. 이 경우 한 번에 최소점에 갑니다. 곡률이 다른 함수에서도 같은 절차로 안전한 보폭을 찾습니다.

흔한 오해(1) "보폭은 작을수록 안전하고 좋다": 너무 작으면 진척이 느립니다. (2) "선탐색은 비싸다": 함수 값 계산 몇 번이면 되어 기울기 계산보다 싼 경우가 많습니다.
요약
  1. Armijo: f(x + tΔx) ≤ f(x) + ct∇fᵀΔx.
  2. 백트래킹 t ← βt.
  3. 예: x² at 3 → t = 0.5.

4.5.2연습문제

기본

  1. c = 0이면 조건의 뜻은?
    답

    조금이라도 줄어들면 받아들임.

응용

  1. f = 4x², x = 1, Δx = −8, c 0.3, β 0.5의 첫 t는?
    답

    t = 0.125(t = 0.25에서 x = −1로 f 같음, 0.125에서 x = 0).

심화

  1. Newton 방향에서 t = 1이 자주 받아들여지는 이유는?
    답

    이차 근사가 정확해 한 걸음이 적절하기 때문입니다.
