최소제곱 분류기와 로지스틱 회귀

본문

센서 측정값 하나로 부품이 정상인지 불량인지 가르고 싶다. 최소제곱으로 선을 그어 나눌 수도 있지만, 이미 확실히 정상인 부품까지 선을 끌어당긴다. 대신 "불량일 확률"을 내놓는 분류기는 어떻게 만들고, 어떻게 학습시킬까?

먼저 알아야 할 것최소제곱(전전16 3.1절), 경사하강(4.1절), 볼록성(3.1절)을 쓴다.

5.1.1두 분류기

가장 간단한 것은 최소제곱 분류기이다. 레이블을 \(y_i = \pm1\)로 두고 \(\min\sum(w^Tx_i + b - y_i)^2\)을 푼 뒤, sign(wᵀx + b)로 판정한다. 그런데 이 방법은 경계에서 멀리 떨어져 이미 맞게 분류된 점까지 "±1에서 벗어났다"며 벌점을 받아, 경계가 그쪽으로 끌려간다.

반면 로지스틱 회귀는 확률을 모델로 삼는다. \(P(y = 1 \mid x) = \sigma(w^Tx + b)\)이고 \(\sigma(z) = 1/(1 + e^{-z})\)이다(그림 1). 처음 질문의 첫째 답이 이것이다. 레이블을 y ∈ {0, 1}로 두면 손실은 교차 엔트로피 \(-\sum[y_i\log p_i + (1 - y_i)\log(1 - p_i)]\)이며, 이것은 볼록이고 기울기가 \(\sum(p_i - y_i)x_i\)로 간단하다. 그래서 경사하강으로 학습한다. 처음 질문의 둘째 답이 이것이다.

예제 5.1.1

1차원 자료 x = 1, 2(레이블 0), x = 3, 4(레이블 1). w = 0, b = 0에서 시작해 보폭 0.5로 경사하강 한 번 한 뒤 (w, b)는?

풀이. 처음에는 모든 p = 0.5이다. 기울기는 \(\partial/\partial w = \sum(p_i - y_i)x_i = 0.5(1 + 2) - 0.5(3 + 4) = -2\), \(\partial/\partial b = 0.5 \times 2 - 0.5 \times 2 = 0\)이다. 따라서 w = 0 − 0.5 × (−2) = 1, b = 0이다.

다음 반복부터는 b가 음수로 움직여 경계 −b/w가 2.5 쪽으로 간다. 그런데 이 자료처럼 두 범주가 완전히 분리되면, 학습을 계속할수록 w가 끝없이 커져 확률이 0과 1로 치닫는다. 이것을 막는 것이 정규화이다(5.2절).

또 기울기 \(\sum(p_i - y_i)x_i\)를 보면 학습의 성질이 드러난다. 이미 맞게 분류되어 \(p_i\)가 \(y_i\)에 가까운 점은 기울기에 거의 기여하지 않고, 틀리거나 애매한 점이 주로 경계를 움직인다.

흔한 오해로지스틱 회귀는 이름처럼 회귀 방법이라고 여기기 쉽다. 실제로는 범주의 확률을 내는 분류기이다. 또 완전히 분리되는 자료면 학습이 금방 끝난다고 생각하기 쉬운데, 손실을 계속 줄이려 가중치가 무한히 커지려 하므로 정규화나 조기 종료가 필요하다.
마무리

최소제곱 분류기는 간단하지만 경계에서 먼 점에 끌린다. 로지스틱 회귀는 σ(wᵀx + b)로 확률을 내고, 교차 엔트로피 손실은 볼록이며 기울기는 Σ(p − y)x이다. 분리 가능한 자료에는 정규화가 필요하다.

5.1.2연습문제

기본

  1. σ(0)과 σ(2)는?
    답

    σ(0) = 0.5, σ(2) ≈ 0.881이다.

응용

  1. w = 1, b = −2.5에서 x = 3의 확률은?
    답

    σ(0.5) ≈ 0.622이다.

심화

  1. 로지스틱 손실의 헤세가 양의 준정부호인 이유는?
    답

    \(\sum p_i(1 - p_i)x_ix_i^T\)로 각 항이 양의 준정부호이기 때문이다.
