제약 최소제곱과 KKT

본문

발전기 여러 대의 출력 합은 수요와 정확히 같아야 하고, 필터의 특정 주파수 이득은 1로 고정해야 한다. 이렇게 조건이 붙은 최소제곱은 어떻게 풀까? 조건이 등식이 아니라 "이하"일 때는 무엇이 더 필요할까?

먼저 알아야 할 것정규화 최소제곱(2.1절), 라그랑주 승수(공통 다변수 미적분)를 쓴다.

2.2.1등식 제약

제약 Cx = d 아래에서 \(\|Ax - b\|^2\)를 최소화한다고 하자. 라그랑주 함수 \(L = \|Ax - b\|^2 + \nu^T(Cx - d)\)를 x와 ν로 미분해 0으로 두면, x와 ν에 대한 연립 1차방정식이 된다. 이것을 KKT 방정식이라 하며, 처음 질문의 첫째 답이다. 즉 등식 제약 최소제곱은 조금 커진 선형 방정식 하나를 푸는 일이다.

예제 2.2.1

\(\|x\|^2\)을 최소화하되 \(x_1 + x_2 = 1\). (A = I, b = 0)

풀이. KKT 방정식은 \(\begin{pmatrix} 2 & 0 & 1 \\ 0 & 2 & 1 \\ 1 & 1 & 0 \end{pmatrix}\begin{pmatrix} x_1 \\ x_2 \\ \nu \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\)이고, 풀면 x = (0.5, 0.5), ν = −1이다. 이 점은 원점에서 직선까지의 최단점이다(그림 1).

같은 꼴은 공학 곳곳에 나온다. 합이 일정할 때 손실을 최소로 하는 전력 분배, 특정 주파수의 이득을 고정한 채 나머지 오차를 줄이는 필터 설계가 그 예이다.

2.2.2부등식 제약(KKT 조건)

그런데 제약이 \(g(x) \le 0\)처럼 부등식이면 조건이 더 필요하다. 처음 질문의 둘째 답이 이것이다. 승수 μ는 0 이상이어야 하고, 원래 제약을 만족해야 하며, 기울기 조건이 성립해야 한다. 그리고 상보 여유 \(\mu g(x) = 0\)이 성립해야 하는데, 이것은 제약이 묶이지 않고 느슨하면 μ = 0이라는 뜻이다.

볼록 문제에서는 이 KKT 조건이 최적의 필요충분조건이다(4.2절). 그래서 해를 찾은 뒤 네 조건을 하나씩 확인하면, 그 해가 정말 최적인지 검증할 수 있다.

흔한 오해승수의 부호에는 의미가 없다고 여기기 쉽다. 부등식 제약에서는 μ ≥ 0이어야 하며, 승수는 제약을 조금 풀 때 목적 함수가 개선되는 비율, 곧 그림자 가격이다. 또 제약을 벌점 항으로 넣어도 같다고 생각하기 쉬운데, 벌점은 제약을 정확히 만족시키지 않고 벌점이 클 때만 가까워진다.
마무리

등식 제약 최소제곱은 KKT 선형 방정식으로 푼다. 예를 들어 x₁ + x₂ = 1 아래에서 ‖x‖²의 최소는 (0.5, 0.5)이다. 부등식 제약에는 μ ≥ 0과 상보 여유 μg = 0이 더 필요하다.

2.2.3연습문제

기본

  1. min ‖x‖², x₁ + x₂ + x₃ = 3의 해는?
    답

    (1, 1, 1)이다.

응용

  1. min (x − 3)², x ≤ 1의 해와 μ는?
    답

    x = 1이고, 기울기 조건 2(1 − 3) + μ = 0에서 μ = 4이다.

심화

  1. 문제 a에서 제약을 x ≤ 5로 바꾸면 μ는?
    답

    제약이 느슨해 x = 3, μ = 0이다.
