제약 최소제곱과 KKT

본문
이 절에서 배울 것
  • 등식 제약 \(Cx = d\)가 있는 최소제곱을 라그랑주 승수로 푼다.
  • KKT 선형 방정식 \(\begin{pmatrix} 2A^TA & C^T \\ C & 0 \end{pmatrix}\begin{pmatrix} x \\ \nu \end{pmatrix} = \begin{pmatrix} 2A^Tb \\ d \end{pmatrix}\)을 세운다.
  • 부등식 제약에서는 상보 여유 조건이 추가됨을 안다.
먼저 알아야 할 것
  • 정규화 최소제곱 (2.1절), 라그랑주 승수(공통 다변수 미적분).

2.2.1등식 제약

최소화 \(\|Ax - b\|^2\), 제약 \(Cx = d\). 라그랑주 함수 \(L = \|Ax - b\|^2 + \nu^T(Cx - d)\)를 x와 ν로 미분해 0으로 두면 위의 KKT 방정식(선형)이 됩니다.

예제 2.2.1

\(\|x\|^2\)을 최소화하되 \(x_1 + x_2 = 1\). (A = I, b = 0)

풀이. KKT: \(\begin{pmatrix} 2 & 0 & 1 \\ 0 & 2 & 1 \\ 1 & 1 & 0 \end{pmatrix}\begin{pmatrix} x_1 \\ x_2 \\ \nu \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\) → x = (0.5, 0.5), ν = −1. 원점에서 직선까지의 최단점입니다. 전력 분배(합이 일정할 때 손실 최소)나 필터 설계(특정 주파수 이득 고정)에 같은 꼴이 나옵니다.

2.2.2부등식 제약(KKT 조건)

\(g(x) \le 0\) 제약이면 승수 μ ≥ 0, 원 가능성, 기울기 조건, 그리고 상보 여유 \(\mu g(x) = 0\)(제약이 느슨하면 μ = 0)이 필요합니다. 볼록 문제에서는 이 조건이 최적의 필요충분조건입니다(4.2절).

흔한 오해(1) "승수의 부호는 의미가 없다": 부등식 제약에서는 μ ≥ 0이어야 하고, 승수는 제약을 조금 풀 때 목적 함수가 개선되는 비율(그림자 가격)입니다. (2) "제약을 벌점 항으로 넣으면 같다": 벌점은 제약을 정확히 만족시키지 않습니다.
요약
  1. 등식 제약 최소제곱 → KKT 선형 방정식.
  2. 예: min ‖x‖², x₁ + x₂ = 1 → (0.5, 0.5).
  3. 부등식: μ ≥ 0, 상보 여유 μg = 0.

2.2.3연습문제

기본

  1. min ‖x‖², x₁ + x₂ + x₃ = 3의 해는?
    답

    (1, 1, 1).

응용

  1. min (x − 3)², x ≤ 1의 해와 μ는?
    답

    x = 1, 기울기 2(1 − 3) + μ = 0 → μ = 4.

심화

  1. 문제 a에서 제약을 x ≤ 5로 바꾸면 μ는?
    답

    제약이 느슨해 x = 3, μ = 0.
