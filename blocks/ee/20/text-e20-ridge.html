정규화 최소제곱

본문

측정점 세 개에 직선을 맞췄더니 한 점이 유난히 커서 직선이 가파르게 기울었다. 자료가 적거나 행렬의 열이 거의 종속일 때, 최소제곱 해는 잡음에 크게 흔들린다. 해가 지나치게 커지지 않도록 붙잡아 두는 방법은 무엇이고, 그 대가는 무엇일까?

먼저 알아야 할 것최소제곱과 정규 방정식(전전16 3.1절), 기울기와 미분을 쓴다.

2.1.1유도

정규화 최소제곱은 잔차에 계수 크기의 벌점을 더한 \(J(x) = \|Ax - b\|^2 + \lambda\|x\|^2\)을 최소화한다. 처음 질문의 첫째 답이 이것이며, 리지 회귀라고도 한다. 기울기 \(2A^T(Ax - b) + 2\lambda x = 0\)에서 해는 다음과 같다.

\[ \hat x = (A^TA + \lambda I)^{-1}A^Tb. \]

λ > 0이면 \(A^TA + \lambda I\)는 언제나 양의 정부호라 가역이다. 그래서 A의 열이 거의 종속이어도 해가 안정하다. 또 SVD로 보면, 각 특이 방향의 계수를 \(\sigma_i^2/(\sigma_i^2 + \lambda)\)배로 줄인다. 즉 특이값이 작아 잡음을 크게 키우던 방향일수록 많이 줄어든다.

예제 2.1.1

t = 0, 1, 2에서 b = 6, 0, 0에 직선 C + Dt를 맞출 때 λ = 0, 1, 10의 해는?

풀이. λ = 0이면 보통 최소제곱 해 (5, −3)이다. λ = 1이면 \(\begin{pmatrix} 4 & 3 \\ 3 & 6 \end{pmatrix}x = (6, 0)\)에서 (2.4, −1.2)이다. λ = 10이면 (0.484, −0.097)이다(그림 1).

따라서 λ가 클수록 계수가 0 쪽으로 줄어 자료를 덜 따라간다. 처음 질문의 둘째 답이 이것이다. 그 대가로 학습 자료에 대한 오차는 커지므로, 적당한 λ는 학습에 쓰지 않은 검증 자료의 오차로 고른다(5.2절, 5.4절).

한편 실제 계산에서는 역행렬을 구하지 않는다. A 아래에 \(\sqrt\lambda I\)를 쌓은 행렬로 보통의 최소제곱을 풀면 같은 해가 나오며, 이 방법은 다목적 최소제곱(2.3절)으로 이어진다.

주의할 점이 하나 더 있다. 벌점 \(\lambda\|x\|^2\)은 모든 계수를 같은 기준으로 줄이므로, 변수의 단위가 다르면 결과가 단위 선택에 따라 달라진다. 예를 들어 길이를 m에서 mm로 바꾸면 그 계수는 1000분의 1이 되어 벌점의 영향을 거의 받지 않는다. 그래서 정규화하기 전에 각 변수를 평균 0, 표준편차 1로 맞추는 표준화를 먼저 한다.

흔한 오해정규화가 오차를 줄인다고 여기기 쉽다. 학습 자료에 대한 오차는 오히려 늘고, 줄어드는 것은 새 자료에 대한 오차, 곧 일반화 오차이다. 또 상수항(절편)까지 줄일지는 선택 사항이며, 보통 절편은 정규화하지 않는다. 자료 전체를 위아래로 옮기기만 해도 절편이 바뀌기 때문이다.
마무리

정규화 최소제곱의 해는 x̂ = (AᵀA + λI)⁻¹Aᵀb이고, λ > 0이면 언제나 유일하다. 특이 방향마다 계수를 σ²/(σ² + λ)배로 줄인다. λ는 검증 오차로 고른다.

2.1.2연습문제

기본

  1. A = I(단위), b = (2, 4), λ = 1의 해는?
    답

    b/(1 + λ) = (1, 2)이다.

응용

  1. 특이값 0.1인 방향의 계수는 λ = 0.01일 때 몇 배로 줄어드는가?
    답

    0.01/(0.01 + 0.01) = 0.5배이다.

심화

  1. λ → ∞의 해와 의미는?
    답

    0이다. 자료를 무시하고 가장 작은 해만 고른다.
