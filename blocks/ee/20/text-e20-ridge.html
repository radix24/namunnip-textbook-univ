정규화 최소제곱

본문
이 절에서 배울 것
  • 목적 \(\|Ax - b\|^2 + \lambda\|x\|^2\)의 해 \((A^TA + \lambda I)^{-1}A^Tb\)를 유도한다.
  • λ가 해의 크기와 오차의 절충을 정하는 것을 수치로 본다.
  • 나쁜 조건의 문제를 안정화하는 효과를 안다.
먼저 알아야 할 것
  • 최소제곱과 정규 방정식 (전전16 3.1절), 기울기와 미분.

2.1.1유도

\(J(x) = \|Ax - b\|^2 + \lambda\|x\|^2\)의 기울기 \(2A^T(Ax - b) + 2\lambda x = 0\)에서

\[ \hat x = (A^TA + \lambda I)^{-1}A^Tb. \]

λ > 0이면 \(A^TA + \lambda I\)는 언제나 가역(양의 정부호)이라, A의 열이 거의 종속이어도 해가 안정합니다. SVD로 보면 각 특이 방향의 계수를 \(\sigma_i^2/(\sigma_i^2 + \lambda)\)배로 줄입니다.

예제 2.1.1

t = 0, 1, 2에서 b = 6, 0, 0에 직선 C + Dt를 맞출 때 λ = 0, 1, 10의 해는?

풀이. λ = 0: (5, −3). λ = 1: \(\begin{pmatrix} 4 & 3 \\ 3 & 6 \end{pmatrix}x = (6, 0)\) → (2.4, −1.2). λ = 10: (0.484, −0.097). λ가 클수록 계수가 0 쪽으로 줄어 자료를 덜 따라갑니다. 적당한 λ는 검증 자료의 오차로 고릅니다(5.2절).

흔한 오해(1) "정규화는 오차를 줄인다": 학습 자료 오차는 늘고, 새 자료에 대한 오차(일반화)를 줄이는 것이 목적입니다. (2) 상수항(절편)까지 줄이는지 여부는 선택이며 보통 절편은 정규화하지 않습니다.
요약
  1. x̂ = (AᵀA + λI)⁻¹Aᵀb, λ > 0이면 언제나 해가 유일.
  2. 특이 방향마다 σ²/(σ² + λ)배 축소.
  3. λ는 검증 오차로 선택.

2.1.2연습문제

기본

  1. A = I(단위), b = (2, 4), λ = 1의 해는?
    답

    (1, 2): b/(1 + λ).

응용

  1. 특이값 0.1인 방향의 계수는 λ = 0.01일 때 몇 배로 줄어드는가?
    답

    0.01/(0.01 + 0.01) = 0.5배.

심화

  1. λ → ∞의 해와 의미는?
    답

    0. 자료를 무시하고 가장 작은 해만 선호합니다.
