함수로 프로그램 나누기

본문

회로 계산 프로그램에 병렬 저항 공식 \(R_1R_2/(R_1+R_2)\)이 열 번 나온다. 그런데 한 곳에 괄호를 잘못 쳤다면 열 곳을 다 뒤져야 할까? 같은 계산을 한 번만 쓰고 여러 번 부르는 방법은 무엇일까?

먼저 알아야 할 것Python 기본 문법(2.1절)과 고교 수학의 함수 \(y = f(x)\)를 쓴다.

2.2.1수학의 함수와 같은 생각

수학에서 \(f(x) = x^2\)은 입력 \(x\)를 받아 값 하나를 돌려준다. 프로그램의 함수도 같은 생각에서 출발한다. 다른 점은 입력이 여러 개일 수 있고, 값을 만드는 과정에 여러 문장을 쓸 수 있다는 것뿐이다. 병렬 저항을 함수로 만들어 보자.

def parallel(r1, r2):
    """두 저항의 병렬 합성 저항"""
    return r1 * r2 / (r1 + r2)

print(parallel(1000, 1000))     # 500.0
print(parallel(220, 330))       # 132.0

def 줄의 괄호 안 이름 r1, r2를 매개변수라 하고, 부를 때 넣은 값 1000, 1000을 인수라 한다. 함수를 부르면 그림 1처럼 인수가 매개변수에 담기고, 몸통이 실행된 뒤 return 뒤의 값이 부른 자리로 돌아온다. 따라서 parallel(1000, 1000)이라는 식 전체가 500.0이라는 값이 된다.

세 따옴표로 쓴 첫 줄은 설명 문자열(docstring)이다. 실행에는 영향이 없지만 help(parallel)로 읽을 수 있어서, 몇 달 뒤의 자신이나 동료가 함수의 뜻을 바로 안다.

2.2.2나누면 무엇이 좋은가

처음 질문으로 돌아가 보자. 공식을 열 번 쓰는 대신 함수를 열 번 부르면, 공식이 틀렸을 때 고칠 곳은 def 아래 한 줄뿐이다. 게다가 parallel(r1, r2)라는 이름은 식보다 뜻이 바로 읽힌다. 시험하기도 쉬워진다. 1 kΩ 두 개의 병렬은 500 Ω이라는 답을 이미 알고 있으므로, 함수 하나만 따로 불러 맞는지 확인할 수 있다.

또 함수 안에서 만든 변수는 함수 밖에서 보이지 않는다. 이를 지역 변수라 한다. 다시 말해 큰 프로그램을 함수로 나누면 각 부분이 자기 이름만 신경 쓰면 되므로, 다른 곳의 같은 이름과 부딪칠 걱정이 줄어든다.

예제 2.2.1

점수 리스트의 평균을 돌려주는 mean과, 평균을 등급으로 바꾸는 letter(score, cuts=(90, 80, 70, 60))을 설계하여라. letter(85.0)과 letter(85.0, cuts=(95, 85, 75, 65))의 결과는?

풀이. mean은 sum(xs) / len(xs)를 돌려주면 된다. letter는 A, B, C, D를 기준 점수와 차례로 짝지어, 점수가 기준 이상인 첫 등급을 돌려주고 모두 아니면 F를 돌려준다. 기본 기준에서는 85가 90에 못 미치고 80 이상이므로 B이다. 엄격한 기준에서도 85가 95에는 못 미치고 85 이상이므로 역시 B이다.

여기서 cuts=(90, 80, 70, 60)처럼 매개변수에 값을 미리 정해 두는 것을 기본값이라 한다. 대부분은 letter(m)처럼 짧게 부르고, 기준을 바꿀 때만 두 번째 인수를 준다.

흔한 오해함수 안에서 print하면 값을 돌려준 것이라고 착각하기 쉽다. 화면에 보일 뿐이어서 그 값을 다른 계산에 쓸 수 없고, 쓰려면 return해야 한다. 또 def는 함수를 만들기만 할 뿐 실행하지 않는다. 이름 뒤에 괄호를 붙여 불러야 몸통이 실행된다.
마무리

병렬 저항 공식을 def parallel(r1, r2)로 한 번만 써 두면 열 곳에서 부르더라도 고칠 곳은 한 줄이다. 함수는 인수를 매개변수에 담아 계산하고 값 하나를 돌려주는 상자이며, 안의 이름이 밖과 섞이지 않아 큰 프로그램을 나누어 짓고 하나씩 시험할 수 있게 해 준다.

2.2.3연습문제

기본

  1. def sq(x): return x * x일 때 sq(sq(3))은?
    답

    81.

응용

  1. 섭씨를 화씨로 바꾸는 함수 c2f(c)를 쓰고 c2f(36.5)를 구하여라.
    답

    return c * 9 / 5 + 32이고 결과는 97.7이다.

심화

  1. series(*rs)처럼 저항을 몇 개든 받는 직렬 합성 함수를 써라.
    답

    def series(*rs): return sum(rs). *rs는 넣은 값들을 튜플 하나로 묶어 받는다. 4.2절에서 쓴다.
