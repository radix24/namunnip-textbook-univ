함수로 프로그램 나누기

본문
이 절에서 배울 것
  • def로 함수를 정의하고, 매개변수와 반환값으로 자료를 주고받는다.
  • 같은 계산을 함수로 묶어 여러 곳에서 다시 쓴다.
  • 기본값 매개변수와 설명 문자열(docstring)로 함수를 쓰기 쉽게 만든다.
먼저 알아야 할 것
  • Python 기본 문법 (2.1절), 고교 수학의 함수 \(y = f(x)\).

2.2.1수학의 함수와 프로그램의 함수

수학에서 \(f(x) = x^2\)는 입력 x를 받아 값을 돌려줍니다. 프로그램의 함수도 같습니다. 다른 점은 입력이 여러 개일 수 있고, 계산 과정에 여러 문장이 들어갈 수 있다는 것입니다.

def parallel(r1, r2):
    """두 저항의 병렬 합성 저항"""
    return r1 * r2 / (r1 + r2)

print(parallel(1000, 1000))     # 500.0
print(parallel(220, 330))       # 132.0

매개변수: 함수 정의의 괄호 안 이름(r1, r2). 부를 때 넣은 값(인수)이 여기에 담긴다.

반환값: return 뒤의 값. return이 없으면 None을 돌려준다.

지역 변수: 함수 안에서 만든 변수는 함수 밖에서 보이지 않는다.

2.2.2왜 나누는가

  • 재사용: 병렬 계산이 열 번 나오면 식을 열 번 쓰는 대신 함수를 열 번 부른다. 식이 틀렸으면 한 곳만 고친다.
  • 읽기 쉬움: parallel(r1, r2)는 식보다 뜻이 바로 보인다.
  • 시험하기 쉬움: 함수 하나씩 답을 아는 값으로 확인할 수 있다(1 kΩ ∥ 1 kΩ = 500 Ω).
예제 2.2.1

점수 리스트의 평균을 돌려주는 함수 mean과, 평균을 등급으로 바꾸는 함수 letter(score, cuts=(90, 80, 70, 60))를 설계하라. letter(85.0)과 letter(85.0, cuts=(95, 85, 75, 65))의 결과는?

풀이. mean은 sum(xs) / len(xs). letter는 "A, B, C, D와 기준 점수를 차례로 짝지어, 점수가 기준 이상인 첫 등급을 돌려주고 모두 아니면 F". 기본 기준이면 85 ≥ 80으로 B, 엄격한 기준이면 85 ≥ 85로 역시 B입니다. 기본값 덕분에 대부분은 letter(m)처럼 짧게 부르고, 필요할 때만 기준을 바꿉니다. 이 절의 실습에서 실행 결과를 확인합니다.

흔한 오해(1) "함수 안에서 print하면 값을 돌려준 것이다": 화면에 보일 뿐 다른 계산에 쓸 수 없습니다. 쓰려면 return. (2) "함수를 정의하면 실행된다": def는 만들기만 하고, 이름 뒤에 괄호를 붙여 불러야 실행됩니다. (3) 리스트를 매개변수로 받아 함수 안에서 바꾸면 밖의 리스트도 바뀝니다(같은 리스트를 가리키므로).
요약
  1. def 이름(매개변수): … return 값.
  2. 재사용, 읽기, 시험이 쉬워진다. 고칠 곳이 한 곳.
  3. 기본값 매개변수로 자주 쓰는 경우를 짧게 부른다.

2.2.3연습문제

기본

  1. def sq(x): return x * x일 때 sq(sq(3))은?
    답

    81.

응용

  1. 섭씨를 화씨로 바꾸는 함수 c2f(c)를 쓰고 c2f(36.5)를 구하라.
    답

    return c * 9 / 5 + 32, 97.7.

심화

  1. series(*rs)처럼 저항을 몇 개든 받는 직렬 합성 함수를 쓰라.
    답

    def series(*rs): return sum(rs). *rs는 넣은 값들을 묶음(튜플)으로 받습니다. 4.2절 실습에서 씁니다.
