함수로 나눈 성적 처리

실습 · 함수, 기본값 매개변수, 재사용

목표

평균, 등급, 보고 문장을 각각 함수로 만들고 조합해 쓴다. 점수는 가상이다. 성취기준 [전전1-02-02].

준비

Python 3만 있으면 됩니다(추가 설치 없음). 아래 코드를 grades.py로 저장한다.

# 함수로 나눈 성적 처리 (가상 점수)
def mean(xs):
    """리스트의 평균"""
    return sum(xs) / len(xs)

def letter(score, cuts=(90, 80, 70, 60)):
    """점수를 등급으로. cuts는 A, B, C, D의 최저 점수"""
    for grade, cut in zip("ABCD", cuts):
        if score >= cut:
            return grade
    return "F"

def report(name, scores):
    m = mean(scores)
    return f"{name}: 평균 {m:.1f}, 최고 {max(scores)}, 등급 {letter(m)}"

students = {"가": [92, 85, 78], "나": [65, 70, 58], "다": [88, 91, 95]}
for name, scores in students.items():
    print(report(name, scores))

# 같은 함수를 기준만 바꿔 다시 쓰기(재사용)
print("엄격한 기준:", [letter(mean(s), cuts=(95, 85, 75, 65)) for s in students.values()])

절차

  1. 실행해 출력을 적는다.
  2. letter(79.99)와 letter(80)의 결과를 예측하고 확인한다.
  3. report가 평균을 소수 첫째 자리로 출력하는 부분을 찾아 둘째 자리로 바꿔 본다.

기대 결과

Python 3.12에서 실행한 출력이다.

가: 평균 85.0, 최고 92, 등급 B
나: 평균 64.3, 최고 70, 등급 D
다: 평균 91.3, 최고 95, 등급 A
엄격한 기준: ['B', 'F', 'B']
  • "가" 평균 85.0 → B, "나" 64.3 → D, "다" 91.3 → A(예제 2.2.1의 기본 기준).
  • 엄격한 기준(95, 85, 75, 65)에서는 "가" 85.0 → B(85 이상), "나" 64.3 → F, "다" 91.3 → B.
  • 절차 2: 79.99는 C, 80은 B입니다(경계값은 >=로 처리).
