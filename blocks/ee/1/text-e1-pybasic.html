Python 기본 문법으로 계산 문제 풀기

본문
이 절에서 배울 것
  • 변수, 수와 문자열, 리스트, 딕셔너리를 써서 자료를 담는다.
  • 조건문(if)과 반복문(for, while)으로 계산 순서를 만든다.
  • print와 f-문자열로 결과를 읽기 좋게 출력한다.
먼저 알아야 할 것
  • 고교 정보 교과의 기초(있으면 좋음). 없어도 이 절부터 시작할 수 있습니다. Python 3를 설치하거나 온라인 실행 환경을 씁니다.

2.1.1왜 Python인가

공학에서는 같은 계산을 값만 바꿔 여러 번 하거나, 자료 수천 개를 정리하는 일이 많습니다. Python은 문법이 짧고 읽기 쉬우며, 수치 계산(NumPy)과 그래프(Matplotlib) 도구가 풍부해 공학 계산의 표준처럼 쓰입니다.

2.1.2값을 담는 그릇

변수: 값에 붙인 이름. v = 5는 "v라는 이름으로 5를 가리켜라".

자료형: 정수(int) 3, 실수(float) 3.0, 문자열(str) "저항", 참거짓(bool) True.

리스트: 순서 있는 값의 줄 [1, 2, 3]. 0번부터 센다.

딕셔너리: 이름(키)으로 값을 찾는 표 {"냉장고": 40, "전등": 10}.

2.1.3흐름 만들기

v, r = 5, 220            # 전압 5 V, 저항 220 Ω
i = v / r                # 옴의 법칙
print(f"전류 {i * 1000:.1f} mA")       # 전류 22.7 mA

if i > 0.02:
    print("LED 정격 20 mA 초과: 저항을 키우세요")

for r in [220, 330, 470]:              # 여러 값으로 반복
    print(r, "Ω →", round(v / r * 1000, 1), "mA")

들여쓰기(보통 공백 4칸)가 문장의 묶음을 나타냅니다. if나 for 줄 끝의 콜론(:) 다음 줄부터 들여 쓴 부분이 그 안에서 실행됩니다.

예제 2.1.1

위 코드의 마지막 반복이 출력하는 세 줄을 예측하라.

풀이. 5/220 = 0.022727 A → 22.7 mA, 5/330 → 15.2 mA, 5/470 → 10.6 mA. 출력은 220 Ω → 22.7 mA, 330 Ω → 15.2 mA, 470 Ω → 10.6 mA입니다. print에 여러 값을 쉼표로 주면 공백 하나로 띄워 출력합니다.

흔한 오해(1) "=는 같다는 뜻이다": 오른쪽 값을 왼쪽 이름에 담는 대입입니다. 같은지 비교는 ==. (2) "7 / 2는 3이다": Python 3에서는 3.5이고, 몫만 원하면 7 // 2입니다. (3) 리스트의 첫 원소는 xs[1]이 아니라 xs[0]입니다.
요약
  1. 변수는 값의 이름. int, float, str, bool, 리스트, 딕셔너리.
  2. if로 갈래, for/while로 반복. 들여쓰기가 묶음을 정한다.
  3. f-문자열 f"{x:.1f}"로 자릿수를 정해 출력한다.

2.1.4연습문제

기본

  1. xs = [3, 1, 4, 1, 5]에서 xs[2], len(xs), sum(xs)는?
    답

    4, 5, 14.

응용

  1. 1부터 100까지 짝수의 합을 for 문으로 구하는 코드를 쓰라. 결과는?
    답

    s = 0 다음 for k in range(2, 101, 2): s += k. 결과 2550.

심화

  1. 딕셔너리 {"A": 3, "B": 7, "C": 5}에서 값이 가장 큰 키를 찾는 방법 두 가지는?
    답

    반복문으로 최댓값과 키를 갱신하거나, max(d, key=d.get). 결과 "B".
