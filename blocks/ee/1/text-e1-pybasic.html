Python 기본 문법으로 계산 문제 풀기

본문

5 V 전원에 LED를 달 때 저항을 220 Ω, 330 Ω, 470 Ω 가운데 무엇으로 해야 전류가 20 mA를 넘지 않을까? 계산기로 세 번 누르면 되는 일을 굳이 프로그램으로 쓰면 무엇이 달라질까?

먼저 알아야 할 것고교 정보 교과의 기초가 있으면 좋지만 없어도 된다. Python 3를 설치하거나 온라인 실행 환경을 쓴다.

2.1.1왜 프로그램으로 쓰는가

LED 문제는 옴의 법칙 \(I = V/R\) 하나로 풀린다. 저항이 셋이면 계산기로 충분하지만, 후보가 스물네 개로 늘거나 전원 전압을 바꿔 다시 따져야 하면 이야기가 달라진다. 프로그램은 계산의 순서 자체를 적어 두는 것이어서, 값만 바꾸면 같은 순서를 몇 번이든 다시 실행한다. Python은 문법이 짧고, 수치 계산(NumPy)과 그래프(Matplotlib) 도구가 넉넉해 공학 계산에 널리 쓰인다.

2.1.2이름과 값

프로그램의 첫 줄은 대개 값에 이름을 붙이는 일이다. v = 5라고 쓰면 \(v\)라는 이름이 5를 가리키게 된다. 수학의 등호와 달리 이것은 "같다"는 주장이 아니라 오른쪽 값을 왼쪽 이름에 담으라는 명령이고, 이를 대입이라 한다. 같은지 비교할 때는 ==를 쓴다.

값에는 종류가 있다. 3은 정수(int), 3.0은 실수(float), "저항"은 문자열(str), True는 참거짓(bool)이다. 이 종류를 자료형이라 한다. 여러 값을 순서대로 모은 [220, 330, 470]은 리스트이며, 2.3절에서 자세히 다룬다.

2.1.3되풀이와 갈래

이제 그림 1의 흐름을 코드로 옮겨 보자.

v = 5                                  # 전압 5 V
for r in [220, 330, 470]:              # 여러 값으로 반복
    i = v / r                          # 옴의 법칙
    print(r, "Ω →", round(i * 1000, 1), "mA")
    if i > 0.02:
        print("  LED 정격 20 mA 초과: 저항을 키워라")

for 줄은 리스트의 값을 하나씩 꺼내 \(r\)에 담고, 그 아래 들여 쓴 줄들을 매번 실행한다. 들여쓰기(보통 공백 4칸)가 어디까지가 반복의 몸통인지를 정하므로, Python에서 들여쓰기는 모양이 아니라 문법이다. if 줄도 마찬가지여서, 조건이 참일 때만 그 아래 들여 쓴 줄이 실행된다.

예제 2.1.1

위 코드가 출력하는 내용을 실행하기 전에 예측하여라.

풀이. \(5/220 = 0.02273\) A이므로 첫 줄은 220 Ω → 22.7 mA이고, 0.02를 넘으므로 경고가 한 줄 더 나온다. 이어서 \(5/330\)은 15.2 mA, \(5/470\)은 10.6 mA로 둘 다 경고가 없다. print에 값을 쉼표로 여러 개 주면 사이에 공백 하나를 넣어 출력한다. 따라서 처음 질문의 답은 330 Ω 이상이다.

여기서 전원을 3.3 V로 바꾸고 싶다면 첫 줄만 고치면 된다. 이것이 계산기와 프로그램의 차이이다. 출력 자릿수를 맞추고 싶으면 f-문자열 f"{i*1000:.1f} mA"를 쓰는데, 중괄호 안의 :.1f가 소수점 아래 한 자리를 뜻한다.

흔한 오해7 / 2가 3이라고 생각하는 경우가 있는데, Python 3에서는 3.5이고 몫만 원하면 7 // 2를 쓴다. 또 리스트의 첫 원소는 xs[1]이 아니라 xs[0]이다. 사람은 1부터 세지만 Python은 0부터 센다.
마무리

LED 저항 문제는 값을 이름에 담는 대입, 후보를 하나씩 꺼내는 for 반복, 20 mA를 넘는지 묻는 if 갈래로 짜면 330 Ω 이상이 답으로 나온다. 프로그램은 계산의 순서를 적어 두므로 전압이나 후보가 바뀌어도 한 줄만 고치면 다시 풀린다.
