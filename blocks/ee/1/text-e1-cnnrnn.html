CNN과 RNN: 영상과 순서 자료

본문

사진 속 고양이를 알아보는 일과, "나는 밥을 ___"의 빈칸을 채우는 일은 둘 다 신경망이 한다. 그런데 사진에서는 이웃한 화소가, 문장에서는 앞뒤 순서가 중요하다. 자료의 모양이 이렇게 다르면 신경망은 어떻게 달라져야 할까?

먼저 알아야 할 것사칙연산과 고교 수학의 함수, 리스트(2.3절)면 충분하며 행렬이나 미분은 쓰지 않는다.

6.1.1곱해서 더하고, 걸러 내보내기

신경망의 한 칸은 뉴런이라 부르는데, 하는 일은 단순하다. 입력 여러 개에 각각 가중치를 곱해 더하고, 그 합이 음수면 0으로 바꾸어 내보낸다. 입력이 2와 3이고 가중치가 0.5와 −1이면 \(2\times0.5 + 3\times(-1) = -2\)이므로 출력은 0이다. 학습이란 정답을 더 잘 맞히도록 이 가중치들을 조금씩 고치는 과정이다.

뉴런 하나는 별것 아니지만 수백만 개를 층으로 쌓으면 복잡한 일을 해낸다. 다만 뉴런을 어떻게 잇느냐는 자료의 모양에 맞춰야 한다. 그 두 가지 대표가 CNN과 RNN이다.

6.1.2CNN은 이웃을 본다

사진에서 경계나 무늬는 이웃한 몇 화소만 보아도 드러난다. 그래서 CNN은 3×3 같은 작은 가중치 표, 곧 필터를 영상의 한 자리에 겹치고, 겹친 칸끼리 곱해 모두 더한 값을 그 자리의 출력으로 삼는다. 이 계산을 합성곱이라 한다. 그림 1처럼 필터를 한 칸씩 밀며 모든 자리에서 되풀이하면 출력 지도가 하나 생긴다.

예제 6.1.1

3×3 영상 조각에서 왼쪽 열은 0, 가운데와 오른쪽 열은 1이다(세로 경계). 각 줄이 [−1 0 1]인 "세로 경계" 필터의 출력은? 영상이 모두 1이면?

풀이. 줄마다 \(0\times(-1) + 1\times0 + 1\times1 = 1\)이므로 세 줄을 더해 3이다. 모두 1이면 줄마다 \(-1 + 0 + 1 = 0\)이어서 합도 0이다. 다시 말해 이 필터는 왼쪽과 오른쪽이 다른 곳, 곧 세로 경계에서만 큰 값을 낸다. 영상 전체에 밀면 "세로 경계가 어디 있는가"를 보여 주는 지도가 된다.

CNN은 이런 필터 수십, 수백 개의 값을 사람이 정해 주지 않아도 자료에서 스스로 배운다. 층을 쌓으면 첫 층은 경계를, 다음 층은 경계를 조합한 모서리를, 그 위는 눈이나 바퀴 같은 부분을 찾아 결국 물체를 알아본다. 게다가 같은 필터를 모든 자리에 쓰므로 고양이가 사진의 어디에 있든 같은 방법으로 찾고, 배울 가중치 수도 적다.

6.1.3RNN은 순서를 기억한다

그런데 문장은 사정이 다르다. "나는 밥을 ___"의 빈칸은 바로 옆 글자가 아니라 앞에 온 단어 전체에 달려 있다. RNN은 입력을 하나씩 받으며 지금까지의 요약, 곧 기억 \(h\)를 고쳐 쓴다.

\[ h_{\text{새}} = \text{통과}\bigl(w \times x + u \times h_{\text{이전}}\bigr) \]

가령 \(w = 1\), \(u = 0.5\)이고 통과 함수가 값을 그대로 내보낸다고 하자. 입력 1, 0, 0, 1을 차례로 넣으면 \(h\)는 1, 0.5, 0.25, 1.125가 된다. 첫 입력의 흔적이 매번 절반씩 줄면서도 남아 있는 것이 보인다. 이 성질 덕분에 RNN은 음성 인식, 번역, 센서 시계열 예측에 쓰였다. 너무 먼 과거를 잊는 약점은 LSTM이 보완했고, 지금은 순서 전체를 한꺼번에 보는 트랜스포머가 생성 AI의 바탕이 되었다.

흔한 오해CNN이 사진을 통째로 외운다고 생각하기 쉽지만, 실제로는 작은 필터로 국소적인 모양을 찾고 그것을 조합한다. 신경망이 사람의 뇌와 같다는 말도 정확하지 않다. 곱셈과 덧셈의 연결에서 이름을 빌려왔을 뿐 작동 방식은 많이 다르다.
마무리

영상처럼 이웃이 중요한 자료에는 작은 필터를 모든 자리에 밀며 곱해 더하는 CNN이, 문장처럼 순서가 중요한 자료에는 기억 \(h\)를 차례로 넘기는 RNN이 맞는다. 둘 다 뉴런의 "곱해서 더하고 걸러 내보내기"를 쌓은 것이며, 차이는 뉴런을 자료의 모양에 맞추어 잇는 방법에 있다.

6.1.4연습문제

기본

  1. 입력 1, 2, 3, 가중치 0.2, 0.3, −0.1인 뉴런(음수는 0으로)의 출력은?
    답

    \(0.2 + 0.6 - 0.3 = 0.5\).

응용

  1. 8×8 영상에 3×3 필터를 한 칸씩 밀며(가장자리를 넘지 않게) 적용하면 출력 크기는?
    답

    한 방향으로 \(8 - 3 + 1 = 6\)자리이므로 6×6이다.

심화

  1. 예제의 RNN(\(w = 1\), \(u = 0.5\))에 입력 1, 1, 1, …을 계속 넣으면 \(h\)는 어디로 가는가?
    답

    1, 1.5, 1.75, 1.875, …로 2에 가까워진다. \(h = 1 + 0.5h\)의 해이며 등비급수의 합과 같은 계산이다.
