CNN과 RNN: 영상과 순서 자료

본문
이 절에서 배울 것
  • 신경망이 "곱해서 더하고, 조건에 따라 통과시키는" 계산을 여러 층 쌓은 것임을 안다.
  • CNN이 작은 필터를 영상의 모든 자리에 밀며 적용해 모양(경계, 무늬)을 찾는 방법을 계산으로 따라간다.
  • RNN이 앞의 결과를 기억해 순서 자료(문장, 음성, 센서 시계열)를 다루는 방법을 안다.
먼저 알아야 할 것
  • 사칙연산과 함수 개념(고교 수학), 리스트 (2.1절). 행렬이나 미분은 쓰지 않습니다.

6.1.1신경망의 한 칸

신경망의 기본 단위(뉴런)는 입력 여러 개에 각각 가중치를 곱해 더하고, 그 합이 0보다 작으면 0으로 바꿔(양수만 통과) 내보냅니다. 예: 입력 2, 3, 가중치 0.5, −1이면 \(2 \times 0.5 + 3 \times (-1) = -2\) → 0. 학습이란 정답을 잘 맞히도록 가중치를 조금씩 고치는 과정입니다.

자료의 모양에 따라 뉴런을 잇는 방법이 다릅니다. 영상은 이웃한 화소끼리 관계가 깊고, 문장은 앞뒤 순서가 중요합니다.

6.1.2CNN: 영상의 이웃을 본다

필터(커널): 3×3 같은 작은 가중치 표.

합성곱: 필터를 영상 위의 한 자리에 겹치고, 같은 칸끼리 곱해 모두 더한 값을 그 자리의 출력으로 삼는다. 필터를 한 칸씩 밀며 모든 자리에 반복한다.

예제 6.1.1

3×3 영상 조각이 왼쪽 열 0, 가운데 열 1, 오른쪽 열 1(세로 경계)이다. 필터 [−1 0 1]을 세 줄 쌓은 "세로 경계" 필터의 출력은? 영상이 모두 1이면?

풀이. 각 줄에서 \(0 \times (-1) + 1 \times 0 + 1 \times 1 = 1\), 세 줄 합 3. 모두 1이면 각 줄 \(-1 + 0 + 1 = 0\), 합 0. 왼쪽과 오른쪽이 다른 곳(세로 경계)에서만 큰 값이 나옵니다. 같은 필터를 영상 전체에 밀면 "세로 경계 지도"가 생깁니다. CNN은 이런 필터 수십~수백 개의 값을 자료로부터 스스로 배우고, 층을 쌓아 경계 → 모서리 → 눈·바퀴 같은 부분 → 물체로 점점 큰 모양을 알아봅니다.

장점은 같은 필터를 모든 자리에 쓰므로 고양이가 사진의 어디에 있어도 같은 방법으로 찾고, 가중치 수가 적다는 것입니다. 이 절의 탐구 카드에서 필터를 바꾸며 출력을 직접 봅니다.

6.1.3RNN: 순서를 기억한다

문장 "나는 밥을 ___"의 빈칸은 앞 단어들에 달려 있습니다. RNN은 입력을 하나씩 받으며, 지금까지의 요약(기억, h)을 갱신합니다.

\[ h_{\text{새}} = \text{통과}(w \times x + u \times h_{\text{이전}}) \]

예: w = 1, u = 0.5이고 통과 함수가 그대로 내보내면, 입력 1, 0, 0, 1에 대해 h = 1, 0.5, 0.25, 1.125. 오래된 입력의 영향이 점점 줄며 남아 있습니다. 음성 인식, 번역, 센서 시계열 예측에 쓰였고, 너무 먼 과거를 잊는 문제를 보완한 LSTM과, 순서 전체를 한꺼번에 보는 트랜스포머(생성 AI의 바탕)로 발전했습니다.

흔한 오해(1) "CNN은 사진을 통째로 외운다": 작은 필터로 국소적인 모양을 찾고 그것을 조합합니다. (2) "RNN은 모든 과거를 똑같이 기억한다": 위 예처럼 오래된 입력의 영향은 줄어듭니다. (3) "신경망은 사람 뇌와 같다": 곱셈과 덧셈의 연결에서 이름만 빌려왔고 작동 방식은 많이 다릅니다.
요약
  1. 뉴런: 가중치 곱의 합 → 통과 함수. 학습은 가중치 조정.
  2. CNN: 작은 필터를 모든 자리에 밀며 곱해 더한다. 영상의 이웃 관계.
  3. RNN: 기억 h를 갱신하며 순서 자료를 처리한다.

6.1.4연습문제

기본

  1. 입력 1, 2, 3, 가중치 0.2, 0.3, −0.1인 뉴런(음수는 0으로)의 출력은?
    답

    \(0.2 + 0.6 - 0.3 = 0.5\).

응용

  1. 8×8 영상에 3×3 필터를 한 칸씩 밀며(가장자리 넘지 않게) 적용하면 출력 크기는?
    답

    6×6. 한 방향으로 8 − 3 + 1 = 6자리.

심화

  1. 예제의 RNN(w = 1, u = 0.5)에 입력 1, 1, 1, 1, …을 계속 넣으면 h는 어디로 가는가?
    답

    1, 1.5, 1.75, 1.875, … → 2에 가까워집니다(\(h = 1 + 0.5h\)의 해). 등비급수 합과 같은 계산입니다.
