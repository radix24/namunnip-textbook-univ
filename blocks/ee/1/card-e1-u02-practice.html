  1. 계산x = 7; y = 2일 때 x / y, x // y, x % y, x ** y는? [02-01]

    나눗셈, 몫, 나머지, 거듭제곱.

    힌트 2

    Python 3의 /는 실수.

    풀이

    3.5, 3, 1, 49.

  2. 계산d = {"R1": 100, "R2": 220}에 d["R3"] = 330을 하고 sum(d.values())를 구하라. [02-01]

    힌트 1

    키 추가.

    힌트 2

    값만 더하기.

    풀이

    650.

  3. 구현1부터 n까지의 합이 처음으로 1000을 넘는 n을 while 문으로 구하라. [02-01]

    힌트 1

    합과 n을 함께 갱신.

    힌트 2

    조건은 합 ≤ 1000인 동안.

    풀이

    s, n = 0, 0 다음 while s <= 1000: n += 1; s += n. n = 45(합 1035).

  4. 구현저항 리스트를 받아 직렬과 병렬 합성 저항을 함께 돌려주는 함수를 쓰라. [02-02]

    힌트 1

    튜플로 두 값 반환.

    힌트 2

    return a, b.

    풀이

    def both(rs): return sum(rs), 1 / sum(1 / r for r in rs). both([100, 100]) → (200, 50.0).

  5. 판단학생이 함수 안에서 print(result)만 하고 return을 쓰지 않았다. y = f(3) + 1은 어떻게 되는가? [02-02]

    힌트 1

    return이 없으면?

    힌트 2

    None + 1.

    풀이

    f가 None을 돌려주므로 TypeError가 납니다. 값을 쓰려면 return해야 합니다.

  6. 도전기본값 매개변수 def add(x, xs=[])를 두 번 부르면 생기는 문제를 조사하라. [02-02]

    힌트 1

    기본값은 언제 만들어지나?

    힌트 2

    같은 리스트가 계속 쓰임.

    풀이

    기본값 리스트는 함수를 정의할 때 한 번만 만들어져 호출 사이에 공유됩니다. xs=None으로 두고 안에서 xs = []를 만드는 것이 관례입니다.

  7. 실습리스트 [3, 8, 1, 9]의 최댓값의 위치(인덱스)를 구하는 식은? [02-03]
