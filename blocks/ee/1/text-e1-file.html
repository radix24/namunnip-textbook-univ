파일을 읽고 쓰는 프로그램

본문
이 절에서 배울 것
  • with open으로 텍스트 파일을 쓰고 읽는다.
  • CSV(쉼표로 나눈 표) 파일을 줄 단위로 나눠 숫자로 바꾼다.
  • 인코딩(UTF-8)과 파일이 없을 때의 오류를 다룬다.
먼저 알아야 할 것
  • 리스트 (2.3절).

2.4.1쓰고 읽기

센서 기록, 실험 측정값처럼 프로그램이 끝나도 남아야 하는 자료는 파일에 저장합니다. with를 쓰면 블록이 끝날 때 파일이 자동으로 닫힙니다.

rows = [("시간", "전압"), (0, 0.00), (1, 3.16), (2, 4.32), (3, 4.75)]
with open("charge.csv", "w", encoding="utf-8") as f:
    for t, v in rows:
        f.write(f"{t},{v}\n")

volts = []
with open("charge.csv", encoding="utf-8") as f:
    next(f)                              # 첫 줄(제목) 건너뛰기
    for line in f:
        t, v = line.strip().split(",")
        volts.append(float(v))
print("읽은 전압:", volts, "최댓값:", max(volts))

실행 결과(Python 3.12에서 실제 실행):

읽은 전압: [0.0, 3.16, 4.32, 4.75] 최댓값: 4.75
예제 2.4.1

위 코드에서 float(v)를 빼면 max(volts)는 무엇을 비교하는가?

풀이. 파일에서 읽은 값은 문자열이라 사전 순서로 비교합니다. "10.5"와 "9.2"를 비교하면 "9.2"가 더 크다고 나오는 식의 잘못이 생기므로, 숫자로 바꾼 뒤 계산합니다. 큰 표는 csv 모듈이나 pandas를 쓰면 편합니다.

흔한 오해(1) "읽은 값은 자동으로 숫자": 항상 문자열입니다. (2) "인코딩은 신경 쓰지 않아도 된다": Windows 기본 인코딩이 달라 한글이 깨질 수 있어 encoding="utf-8"을 적습니다.
요약
  1. with open(파일, 모드, encoding=...)으로 열고 자동 닫기.
  2. CSV: strip → split(',') → float.
  3. 문자열 비교와 숫자 비교를 구별.
