거스름돈: 빠른 규칙과 모든 경우 확인

실습 · 알고리즘 검증

목표

탐욕법과 모든 경우 확인을 구현해 탐욕법이 맞는 경우와 틀리는 경우를 찾습니다. 성취기준 [전전1-03-01].

준비

Python 3만 있으면 됩니다(추가 설치 없음). 아래 코드를 change.py로 저장합니다.

# 거스름돈 문제를 단계로 나누기: 탐욕법과 모든 경우 확인
from itertools import product

def greedy(amount, coins):
    """큰 동전부터 가능한 만큼 쓴다"""
    used = []
    for c in sorted(coins, reverse=True):
        while amount >= c:
            amount -= c
            used.append(c)
    return used

def best(amount, coins):
    """동전마다 개수를 0부터 amount//c까지 모두 시도해 가장 적은 개수"""
    ranges = [range(amount // c + 1) for c in coins]
    best_n, best_combo = None, None
    for counts in product(*ranges):
        if sum(n * c for n, c in zip(counts, coins)) == amount:
            n = sum(counts)
            if best_n is None or n < best_n:
                best_n, best_combo = n, counts
    return best_n, dict(zip(coins, best_combo))

for amount, coins in [(760, [500, 100, 50, 10]), (8, [1, 4, 6]), (14, [1, 7, 10])]:
    g = greedy(amount, coins)
    n, combo = best(amount, coins)
    print(f"{amount}원, 동전 {coins}: 탐욕 {len(g)}개 {g} / 최소 {n}개 {combo}")

절차

  1. 실행해 출력을 적습니다.
  2. 동전 [1, 4, 6]으로 12원을 넣으면 두 방법의 결과는? 예측한 뒤 리스트에 추가해 확인합니다.
  3. 동전 [500, 100, 50, 10]으로 금액을 바꿔 가며 탐욕법이 틀리는 경우가 있는지 찾아봅니다.

기대 결과

Python 3.12에서 실행한 출력입니다.

760원, 동전 [500, 100, 50, 10]: 탐욕 5개 [500, 100, 100, 50, 10] / 최소 5개 {500: 1, 100: 2, 50: 1, 10: 1}
8원, 동전 [1, 4, 6]: 탐욕 3개 [6, 1, 1] / 최소 2개 {1: 0, 4: 2, 6: 0}
14원, 동전 [1, 7, 10]: 탐욕 5개 [10, 1, 1, 1, 1] / 최소 2개 {1: 0, 7: 2, 10: 0}
  • 760원: 두 방법 모두 5개(500, 100, 100, 50, 10).
  • 8원, 동전 1, 4, 6: 탐욕 3개(6 + 1 + 1), 최소 2개(4 + 4). 예제 3.1.1의 반례입니다.
  • 14원, 동전 1, 7, 10: 탐욕 5개, 최소 2개(7 + 7).

분석

  2. 우리나라 동전에서 탐욕법이 늘 맞는 이유를 "각 동전이 바로 아래 동전들로 만들 수 있는 최소 개수"로 설명해 보세요.
