용수철 실험 자료로 용수철 상수 구하기

최소제곱 · 기울기의 의미

출발점

직선 맞춤의 기울기는 두 양의 비례 상수입니다(5.2절). 훅의 법칙 F = kx에서 기울기가 용수철 상수이다.

문제 해결 전략 · 기울기 읽기
  1. 힘(N)을 세로, 늘어난 길이(m)를 가로로 둔다.
  2. np.polyfit(x, F, 1)로 기울기를 구한다.
  3. 단위를 확인한다.

늘어난 길이 0.02, 0.04, 0.06, 0.08 m에서 힘 0.41, 0.79, 1.22, 1.58 N을 쟀다. 용수철 상수는? (최소제곱 기울기를 손으로 구하라)

풀이

  1. x 평균 0.05, F 평균 1.0. Σ(x − x̄)(F − F̄) = (−0.03)(−0.59) + (−0.01)(−0.21) + (0.01)(0.22) + (0.03)(0.58) = 0.0394.
    공분산 꼴.
  2. Σ(x − x̄)² = 0.0009 + 0.0001 + 0.0001 + 0.0009 = 0.002.
    분산 꼴.
  3. k = 0.0394/0.002 = 19.7 N/m.
    기울기 = 공분산/분산.

의미

실험 자료에서 물리 상수를 얻는 표준 방법이다. 점이 많을수록 잡음의 영향이 줄어든다.

검산

각 점의 F/x: 20.5, 19.75, 20.3, 19.75 N/m로 평균 약 20, 맞춤값 19.7과 가깝다.
