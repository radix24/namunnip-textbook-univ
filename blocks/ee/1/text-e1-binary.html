2진수와 16진수로 수와 문자 나타내기

본문

컴퓨터 안에는 0과 1밖에 없는데, 173 같은 수나 '가' 같은 글자는 어떻게 저장될까? 그리고 프로그래머는 왜 0과 1을 길게 늘어놓는 대신 AD 같은 16진수를 즐겨 쓸까?

먼저 알아야 할 것거듭제곱과 Python 기초(2.1절)를 쓴다.

1.4.1자릿값

10진수 345는 \(3\times10^2 + 4\times10 + 5\)이다. 자리마다 10배씩 커지는 값이 붙어 있고, 각 자리에는 0~9 가운데 하나가 들어간다. 2진수도 규칙은 같고 밑만 2로 바뀐다. 각 자리의 값은 오른쪽부터 1, 2, 4, 8, …이고, 자리에는 0이나 1만 들어간다.

그림 1의 8칸에서 1이 들어간 자리의 값을 더하면 \(128 + 32 + 8 + 4 + 1 = 173\)이다. 거꾸로 173을 2진수로 바꾸려면 2로 나눈 나머지를 차례로 적고 거꾸로 읽으면 된다. 173, 86, 43, 21, 10, 5, 2, 1을 2로 나눈 나머지는 1, 0, 1, 1, 0, 1, 0, 1이고, 거꾸로 읽으면 10101101이다.

그런데 컴퓨터는 왜 하필 2진수를 쓸까? 칩 안의 전압은 잡음 때문에 조금씩 흔들린다. 열 단계를 구분하려면 그 흔들림이 아주 작아야 하지만, 높다와 낮다 두 단계만 구분하면 꽤 흔들려도 읽기가 틀리지 않는다.

1.4.216진수는 4비트의 줄임말

2진수는 길다. 32비트 주소를 0과 1로 쓰면 32자리가 된다. 그래서 4비트씩 끊어 한 글자로 쓰는데, 4비트는 0부터 15까지 16가지이므로 0~9 다음에 A(10)~F(15)를 붙인다. 이것이 16진수이다. 그림 1에서 10101101을 1010과 1101로 끊으면 각각 10과 13, 곧 A와 D이므로 173은 16진수로 AD이다.

여기서 16진수가 새로운 종류의 수가 아니라는 점을 기억하자. 같은 비트 열을 사람이 읽기 좋게 줄여 쓴 표기일 뿐이고, 한 자리가 정확히 4비트에 맞물리므로 바꾸는 데 계산이 거의 필요 없다. Python에서는 다음처럼 바로 확인할 수 있다.

n = 173
print(bin(n), hex(n), int("10101101", 2), int("AD", 16))
for bits in (1, 8, 16, 32):
    print(f"{bits}비트로 나타낼 수 있는 경우의 수: {2 ** bits}")
for ch in "A가":
    print(ch, "코드", ord(ch), "UTF-8 바이트", ch.encode("utf-8"))
0b10101101 0xad 173 173
1비트로 나타낼 수 있는 경우의 수: 2
8비트로 나타낼 수 있는 경우의 수: 256
16비트로 나타낼 수 있는 경우의 수: 65536
32비트로 나타낼 수 있는 경우의 수: 4294967296
A 코드 65 UTF-8 바이트 b'A'
가 코드 44032 UTF-8 바이트 b'\xea\xb0\x80'

위 출력은 Python 3.12에서 실제로 실행한 결과이다. 비트가 하나 늘 때마다 각 경우에 0과 1이 붙어 경우의 수가 두 배가 되므로, \(n\)비트로는 \(2^n\)가지를 나타낸다. 8비트, 곧 1바이트는 256가지이다.

1.4.3문자는 번호로 저장된다

글자도 결국 수로 저장된다. 글자마다 번호를 정한 표가 있어서, 영문자 A는 65번, 한글 '가'는 유니코드 44032번이다. 이 번호를 바이트로 바꾸는 방식이 UTF-8이다. 65는 1바이트에 들어가지만 44032는 1바이트(256가지)로도, 2바이트에 규칙용 비트를 뺀 자리로도 모자라서 3바이트를 쓴다. 따라서 한글 문서는 같은 글자 수의 영문 문서보다 파일이 더 크다.

흔한 오해1 KB가 언제나 1000바이트라고 생각하기 쉽다. 저장 장치 광고는 1000바이트를 쓰지만, 메모리와 운영체제는 1024바이트(KiB로 쓰기도 한다)를 쓰는 경우가 많아 표기를 확인해야 한다.
마무리

컴퓨터는 수를 자리마다 1, 2, 4, …의 값이 붙은 2진수로 저장하고, 173은 10101101이다. 16진수는 이 비트를 4개씩 묶어 한 글자로 쓴 줄임말이라 173을 AD로 짧게 적는다. 글자는 번호로 바뀌어 저장되며, 한글은 UTF-8에서 3바이트를 차지한다.
