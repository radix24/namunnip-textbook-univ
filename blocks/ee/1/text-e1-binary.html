2진수와 16진수로 수와 문자 나타내기

본문
이 절에서 배울 것
  • 10진수를 2진수, 16진수로 바꾸고 되돌린다.
  • n비트로 나타낼 수 있는 경우의 수 2ⁿ을 계산한다.
  • 문자가 코드(ASCII, 유니코드)로 저장되는 방식을 안다.
먼저 알아야 할 것
  • 거듭제곱(고교 수학), Python 기초 (2.1절).

1.4.1자릿값

10진수 345는 3×10² + 4×10 + 5입니다. 2진수는 자릿값이 1, 2, 4, 8, …이고, 16진수는 0~9와 A~F(10~15)를 쓰며 4비트가 한 자리입니다. 컴퓨터가 0과 1만 쓰는 것은 전압이 높다/낮다 두 상태가 잡음에 강하기 때문입니다.

n = 173
print(bin(n), hex(n), int("10101101", 2), int("AD", 16))
for bits in (1, 8, 16, 32):
    print(f"{bits}비트로 나타낼 수 있는 경우의 수: {2 ** bits}")
for ch in "A가":
    print(ch, "코드", ord(ch), "UTF-8 바이트", ch.encode("utf-8"))

실행 결과(Python 3.12에서 실제 실행):

0b10101101 0xad 173 173
1비트로 나타낼 수 있는 경우의 수: 2
8비트로 나타낼 수 있는 경우의 수: 256
16비트로 나타낼 수 있는 경우의 수: 65536
32비트로 나타낼 수 있는 경우의 수: 4294967296
A 코드 65 UTF-8 바이트 b'A'
가 코드 44032 UTF-8 바이트 b'\xea\xb0\x80'
예제 1.4.1

173을 손으로 2진수로 바꿔라. 16진수로는?

풀이. 2로 계속 나눈 나머지를 거꾸로 읽으면 173 → 1, 86 → 0, 43 → 1, 21 → 1, 10 → 0, 5 → 1, 2 → 0, 1 → 1: 10101101. 4비트씩 나누면 1010 = A, 1101 = D → AD. 위 실행 결과와 같습니다. 영문자 A는 1바이트(65), 한글 '가'는 UTF-8로 3바이트입니다.

흔한 오해(1) "16진수는 다른 종류의 수": 같은 수를 짧게 쓰는 표기일 뿐입니다. (2) "1 KB = 1000바이트로 늘 같다": 메모리에서는 1024바이트(KiB)를 쓰기도 해 표기를 확인합니다.
요약
  1. 2진수 자릿값 1, 2, 4, …, 16진수 한 자리 = 4비트.
  2. n비트 → 2ⁿ가지.
  3. 문자는 코드 번호로 저장(UTF-8에서 한글 3바이트).
