NumPy 배열로 반복 없이 계산하기

본문
이 절에서 배울 것
  • NumPy 배열의 원소별 연산(벡터화)을 쓴다.
  • linspace, arange로 시간 축을 만들고 신호를 한 번에 계산한다.
  • 반복문과 배열 연산의 속도 차이를 안다.
먼저 알아야 할 것
  • 사인파 그리기 (4.1절), 리스트 (2.3절).

4.3.1원소별 연산

리스트에 2를 곱하면 리스트가 두 번 이어지지만, NumPy 배열에 2를 곱하면 모든 원소가 두 배가 됩니다. 수천만 개 값도 C로 짠 내부 반복이 처리해 빠릅니다.

import numpy as np
R = np.array([100.0, 220.0, 470.0, 1000.0])     # 저항들
V = 5.0
I = V / R                                       # 각 저항에 5 V를 걸 때 전류
P = V * I
print("전류(mA):", np.round(I * 1000, 2))
print("전력(mW):", np.round(P * 1000, 1), "합계", round(P.sum() * 1000, 1), "mW")
t = np.linspace(0, 0.02, 5)                     # 0~20 ms를 5점으로
print("시간(ms):", t * 1000)
print("50 Hz 사인:", np.round(np.sin(2 * np.pi * 50 * t), 3))
print([1, 2] * 2, np.array([1, 2]) * 2)

실행 결과(Python 3.12에서 실제 실행):

전류(mA): [50.   22.73 10.64  5.  ]
전력(mW): [250.  113.6  53.2  25. ] 합계 441.8 mW
시간(ms): [ 0.  5. 10. 15. 20.]
50 Hz 사인: [ 0.  1.  0. -1. -0.]
[1, 2, 1, 2] [2 4]
예제 4.3.1

100 Ω 저항에 5 V를 걸 때의 전류와 전력이 위 결과와 맞는지 손으로 확인하라.

풀이. I = 5/100 = 0.05 A = 50 mA, P = 5 × 0.05 = 0.25 W = 250 mW. 배열 결과의 첫 원소와 같습니다. 50 Hz 사인은 0, 5, 10, 15, 20 ms에서 0, 1, 0, −1, 0(반올림 오차로 −0.0 따위가 보임)입니다.

흔한 오해(1) "리스트와 배열은 연산이 같다": 곱셈과 덧셈의 뜻이 다릅니다(위 마지막 줄). (2) "배열 연산 결과는 정확히 0이 나온다": 부동소수점 오차로 아주 작은 수가 남을 수 있어 반올림해 봅니다.
요약
  1. 배열 연산은 원소별(벡터화), 반복문보다 빠르다.
  2. linspace(시작, 끝, 개수)로 시간 축.
  3. 리스트 * 2는 이어 붙이기, 배열 * 2는 두 배.
