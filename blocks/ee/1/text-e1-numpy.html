NumPy 배열로 반복 없이 계산하기

본문

Python 리스트 [1, 2]에 2를 곱하면 [1, 2, 1, 2]가 된다. 그런데 공학 계산에서 원하는 것은 대개 [2, 4]이다. 저항 네 개에 각각 5 V를 걸 때의 전류를 반복문 없이 한 줄로 구하는 방법은 무엇일까?

먼저 알아야 할 것사인파 그리기(4.1절)와 리스트(2.3절)를 쓴다.

4.3.1원소별 연산

리스트는 아무 값이나 담는 범용 그릇이라서, 곱셈을 "그 리스트를 몇 번 되풀이하라"로 해석한다. 반면 NumPy 배열은 같은 종류의 수만 담는 대신, 덧셈, 곱셈, 나눗셈, sin 같은 연산을 그림 1처럼 원소마다 따로 적용한다. 이렇게 반복문 없이 배열 전체에 연산을 거는 방식을 벡터화라 한다.

그러면 처음 질문은 I = V / R 한 줄로 끝난다. \(R\)이 배열이므로 5를 각 원소로 나눈 새 배열이 나온다. 수가 수천만 개라도 사정이 같은데, 실제 반복은 NumPy 안에서 C로 짠 코드가 하므로 Python 반복문보다 수십 배 빠르다.

import numpy as np
R = np.array([100.0, 220.0, 470.0, 1000.0])     # 저항들
V = 5.0
I = V / R                                       # 각 저항에 5 V를 걸 때 전류
P = V * I
print("전류(mA):", np.round(I * 1000, 2))
print("전력(mW):", np.round(P * 1000, 1), "합계", round(P.sum() * 1000, 1), "mW")
t = np.linspace(0, 0.02, 5)                     # 0~20 ms를 5점으로
print("시간(ms):", t * 1000)
print("50 Hz 사인:", np.round(np.sin(2 * np.pi * 50 * t), 3))
print([1, 2] * 2, np.array([1, 2]) * 2)
전류(mA): [50.   22.73 10.64  5.  ]
전력(mW): [250.  113.6  53.2  25. ] 합계 441.8 mW
시간(ms): [ 0.  5. 10. 15. 20.]
50 Hz 사인: [ 0.  1.  0. -1. -0.]
[1, 2, 1, 2] [2 4]

위 출력은 Python 3.12에서 실제로 실행한 결과이다. 마지막 줄이 처음 질문의 두 결과를 나란히 보여 준다. 전력 P = V * I도 원소마다 곱해지고, P.sum()은 네 전력을 더해 441.8 mW를 낸다.

예제 4.3.1

100 Ω 저항에 5 V를 걸 때의 전류와 전력이 위 결과와 맞는지 손으로 확인하여라. 50 Hz 사인의 마지막 값이 -0.으로 나온 까닭은 무엇인가?

풀이. \(I = 5/100 = 0.05\) A, 곧 50 mA이고 \(P = 5\times0.05 = 0.25\) W, 곧 250 mW이다. 배열 결과의 첫 원소와 같다. 한편 \(t = 20\) ms에서 각은 \(2\pi\)이므로 sin은 수학적으로 0이다. 하지만 컴퓨터의 \(\pi\)는 근삿값이어서 \(\sin(2\pi)\)가 \(-2.4\times10^{-16}\) 같은 아주 작은 음수가 되고, 소수 셋째 자리에서 반올림하면 부호만 남아 -0.이 된다.

4.3.2배열로 생각하기

벡터화에 익숙해지면 "원소 하나에 무엇을 할까" 대신 "배열 전체에 무엇을 할까"로 생각하게 된다. 가령 저항 배열의 병렬 합성은 역수를 모두 더해 다시 역수를 취하는 것이므로 1 / np.sum(1 / R) 한 줄이다. 4.1절에서 시간 축 t에 sin을 한 번 걸어 신호 전체를 만든 것도 같은 생각이다.

조건을 거는 일도 배열 전체에 한 번에 할 수 있다. I > 0.02라고 쓰면 원소마다 참거짓을 담은 배열 [True, True, False, False]가 나오고, 이것을 R[I > 0.02]처럼 대괄호에 넣으면 조건을 만족하는 저항 100 Ω과 220 Ω만 골라진다. 2.1절에서 for와 if로 짰던 LED 검사가 이렇게 한 줄로 줄어든다. 그래서 측정값 수만 개를 다루는 실험 자료 처리에서는 반복문을 쓰기 전에 먼저 배열 연산으로 쓸 수 있는지를 생각해 보는 습관이 도움이 된다.

흔한 오해배열 연산의 결과가 수학 값과 정확히 같을 것이라 기대하기 쉽다. 위의 -0.처럼 부동소수점 오차로 아주 작은 수가 남으므로, 0인지 비교할 때는 == 0 대신 abs(x) < 1e-12처럼 허용 오차를 둔다.
마무리

NumPy 배열에 거는 연산은 원소마다 따로 적용되므로, 저항 네 개의 전류는 I = V / R 한 줄로 [50, 22.73, 10.64, 5] mA가 된다. 리스트의 곱셈이 이어 붙이기인 것과 다르며, 반복은 NumPy 안의 빠른 코드가 맡는다. 다만 결과에는 부동소수점 오차가 남을 수 있다.

  1. np.array([1, 2, 3]) ** 2의 결과는?
