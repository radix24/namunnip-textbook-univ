블록체인: 해시와 합의로 위조 막기

본문
이 절에서 배울 것
  • 해시 함수가 입력이 조금만 바뀌어도 전혀 다른 짧은 값을 내는 "디지털 지문"임을 안다.
  • 블록이 앞 블록의 해시를 담아 사슬을 이루므로 중간 기록을 고치면 뒤가 모두 깨지는 원리를 설명한다.
  • 작업 증명(채굴)과 합의가 위조를 비싸게 만드는 이유를 확률로 어림한다.
먼저 알아야 할 것
  • 확률의 곱셈(고교 확률과 통계), 16진수(고교 정보).

6.3.1해시: 디지털 지문

해시 함수: 어떤 길이의 자료든 정해진 길이의 값(해시)으로 바꾸는 계산. 같은 입력은 언제나 같은 해시, 한 글자만 바뀌어도 해시가 완전히 달라지고, 해시에서 원래 입력을 거꾸로 찾기는 사실상 불가능하다(암호용 해시의 성질).

비트코인이 쓰는 SHA-256의 해시는 256비트(16진수 64자리)입니다. 파일을 내려받은 뒤 해시를 비교해 변조 여부를 확인하는 데도 씁니다.

6.3.2사슬

각 블록에는 거래 기록, 앞 블록의 해시, 그리고 nonce라는 숫자가 들어 있습니다. 블록 2의 기록을 고치면 블록 2의 해시가 바뀌고, 블록 3에 적힌 "앞 블록 해시"와 맞지 않게 됩니다. 들키지 않으려면 블록 3, 4, …를 모두 다시 만들어야 합니다.

6.3.3작업 증명과 합의

블록을 만들려면 해시가 정해진 개수의 0으로 시작하도록 nonce를 바꿔 가며 시도해야 합니다(채굴). 16진수 한 자리가 0일 확률은 1/16이므로 0이 k자리로 시작할 확률은 \((1/16)^k\), 평균 시도 횟수는 \(16^k\)번입니다.

예제 6.3.1

해시가 0 네 자리로 시작해야 하고 컴퓨터가 1초에 해시를 100만 번 계산한다. 블록 하나를 만드는 평균 시간은? 사슬 끝에서 3번째 블록을 고치려면?

풀이. 평균 \(16^4 = 65{,}536\)번 → 약 0.066초. 3번째 블록부터 끝까지 3개를 다시 만들면 약 0.2초입니다. 이 예는 난이도가 낮아 쉽지만, 실제 비트코인은 전 세계 채굴자 전체가 평균 10분에 블록 하나를 찾도록 난이도를 맞춥니다(확인 필요: 난이도는 계속 조정됨). 그동안 정직한 참가자들은 계속 새 블록을 붙이므로, 위조자는 다른 모든 참가자보다 빨리 계산해야 따라잡을 수 있습니다.

합의: 참가자들이 "가장 많은 작업이 쌓인(가장 긴) 사슬"을 올바른 기록으로 받아들이는 규칙. 위조하려면 전체 계산 능력의 절반 이상을 가져야 해서(51% 공격) 비용이 매우 크다.

흔한 오해(1) "블록체인은 해킹이 불가능하다": 기록을 고치기 매우 비싸게 만든 것이고, 계산 능력이 한쪽에 몰리거나 지갑의 비밀 키가 유출되면 뚫립니다. (2) "블록체인 = 비트코인": 비트코인은 한 응용이고, 작업 증명 대신 다른 합의 방법(지분 증명 등)을 쓰는 블록체인도 있습니다. (3) 해시는 암호화가 아닙니다. 되돌려 원문을 얻을 수 없습니다.
요약
  1. 해시: 작은 변화에도 완전히 달라지는 고정 길이 지문.
  2. 블록이 앞 블록의 해시를 담아 사슬. 중간을 고치면 뒤가 깨진다.
  3. 작업 증명: 0 k자리면 평균 \(16^k\)번. 합의는 가장 긴 사슬.

6.3.4연습문제

기본

  1. 해시가 16진수 0 두 자리로 시작할 확률은?
    답

    1/256.

응용

  1. 난이도를 0 다섯 자리로 올리면 평균 시도 횟수는 네 자리의 몇 배인가?
    답

    16배(1,048,576번).

심화

  1. 위조자의 계산 능력이 전체의 10%이고, 정직한 쪽이 블록을 하나 만드는 동안 위조자가 블록을 하나 만들 확률을 대략 1/9로 보자. 위조자가 2블록 뒤처진 상태에서 정직한 쪽보다 두 블록을 연속으로 먼저 만들 확률을 어림하라.
    답

    대략 \((1/9)^2 \approx 1.2\%\)이고, 그동안 정직한 쪽이 앞서가면 더 작아집니다. 뒤처진 블록이 많을수록 확률이 거듭제곱으로 줄어 위조가 사실상 불가능해집니다(정확한 계산은 확인 필요).
