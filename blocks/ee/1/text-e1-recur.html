재귀로 문제를 나누어 풀기

본문
이 절에서 배울 것
  • 함수가 자기 자신을 부르는 재귀의 구조(기저 사례, 재귀 단계)를 안다.
  • 계승, 거듭제곱, 하노이 탑을 재귀로 쓴다.
  • 재귀 호출 수가 폭발하는 경우(피보나치)와 메모이제이션을 안다.
먼저 알아야 할 것
  • 함수 (2.2절), 문제 분해 (3.1절), 수학적 귀납법(고교 수학).

3.3.1두 부분

재귀 함수는 (1) 바로 답할 수 있는 가장 작은 경우(기저 사례)와 (2) 문제를 한 단계 작게 만들어 자기 자신을 부르는 경우로 이루어집니다. 수학적 귀납법과 같은 구조입니다.

def hanoi(n, a="A", b="B", c="C", moves=None):
    if moves is None:
        moves = []
    if n == 0:                       # 기저 사례
        return moves
    hanoi(n - 1, a, c, b, moves)     # 위의 n-1개를 B로
    moves.append((a, c))             # 가장 큰 원판을 C로
    hanoi(n - 1, b, a, c, moves)     # n-1개를 C로
    return moves

print("3개:", hanoi(3))
print("원판 수별 이동 횟수:", [len(hanoi(n)) for n in range(1, 8)])

calls = 0
def fib(n):
    global calls
    calls += 1
    return n if n < 2 else fib(n - 1) + fib(n - 2)
print("fib(20) =", fib(20), "호출 수", calls)

실행 결과(Python 3.12에서 실제 실행):

3개: [('A', 'C'), ('A', 'B'), ('C', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('A', 'C')]
원판 수별 이동 횟수: [1, 3, 7, 15, 31, 63, 127]
fib(20) = 6765 호출 수 21891
예제 3.3.1

하노이 탑의 이동 횟수가 \(2^n - 1\)임을 재귀 구조로 설명하라.

풀이. n개를 옮기려면 n−1개를 두 번 옮기고 큰 원판을 한 번 옮기므로 \(M_n = 2M_{n-1} + 1\), \(M_1 = 1\). 풀면 \(2^n - 1\): 실행 결과 1, 3, 7, 15, …, 127과 같습니다. 피보나치는 같은 값을 여러 번 다시 계산해 fib(20)에 21 891번이나 호출되므로, 한 번 구한 값을 딕셔너리에 저장하는 메모이제이션으로 약 40번(n마다 두 번 이내)으로 줄입니다.

흔한 오해(1) "기저 사례가 없어도 언젠가 멈춘다": 끝없이 불러 RecursionError가 납니다. (2) "재귀가 언제나 느리다": 하노이처럼 구조가 자연스러운 문제는 재귀가 가장 명확하고, 느린 것은 같은 계산을 반복할 때입니다.
요약
  1. 재귀 = 기저 사례 + 한 단계 작은 자기 호출.
  2. 하노이 이동 수 2ⁿ − 1.
  3. 중복 계산은 메모이제이션으로 줄인다.
