탐색과 정렬, 그리고 효율

본문
이 절에서 배울 것
  • 선형 탐색과 이진 탐색을 구현하고 비교 횟수를 센다.
  • 선택 정렬을 구현하고 비교 횟수 \(n(n-1)/2\)를 이해한다.
  • 자료가 2배, 10배가 될 때 각 방법의 횟수가 어떻게 늘어나는지 비교한다.
먼저 알아야 할 것
  • 반복문과 함수 (2.1절, 2.2절), 로그 \(\log_2\)(고교 수학 I).

3.2.1선형 탐색과 이진 탐색

선형 탐색: 처음부터 하나씩 비교. n개면 최악 n번.

이진 탐색: 정렬된 자료에서 가운데와 비교해 절반을 버리기를 반복. n개면 최악 약 \(\log_2 n + 1\)번.

절반을 버릴 수 있는 이유는 자료가 정렬되어 있어서 "가운데보다 크면 왼쪽 절반에는 없다"가 확실하기 때문입니다. 1024개에서 시작하면 512, 256, …, 1로 10번 줄여 1개가 남고, 그 1개를 비교하면 끝납니다.

예제 3.2.1

정렬된 자료 0, 2, 4, …, 2(n − 1)에서 마지막 값을 찾을 때 선형 탐색과 이진 탐색의 비교 횟수를 n = 10, 100, 1000에 대해 구하라.

풀이. 선형: 10, 100, 1000번. 이진: 구간 길이가 10 → 5 → 2 → 1처럼 줄어 4번, n = 100은 7번, n = 1000은 10번입니다(실습의 실행 결과와 같음). n이 100배가 되어도 이진 탐색은 6번만 늘었습니다.

3.2.2선택 정렬

가장 작은 값을 찾아 맨 앞과 바꾸고, 나머지에서 다시 가장 작은 값을 찾아 두 번째와 바꾸는 것을 반복합니다. 첫 번째 찾기에 n − 1번, 두 번째에 n − 2번, …을 비교하므로 합은

\[ (n-1) + (n-2) + \cdots + 1 = \frac{n(n-1)}{2} \]

(고교 수학의 등차수열 합)입니다. n = 1000이면 499,500번. 자료가 10배가 되면 약 100배가 됩니다. 더 빠른 정렬(병합 정렬 등, 약 \(n\log_2n\)번)은 데이터구조 5단원에서 배웁니다.

정렬에 큰 비용이 들어도, 한 번 정렬해 두고 탐색을 여러 번 하면 이진 탐색 덕분에 전체가 빨라집니다. 사전이 가나다순으로 되어 있는 이유입니다.

흔한 오해(1) "이진 탐색은 언제나 빠르다": 정렬되지 않은 자료에는 쓸 수 없고, 정렬 비용을 함께 따져야 합니다. (2) "컴퓨터가 빠르니 효율은 상관없다": n = 100만에서 선택 정렬은 약 5000억 번 비교라 몇 분 이상 걸릴 수 있고, 병합 정렬은 약 2000만 번입니다. (3) 비교 횟수는 입력에 따라 다릅니다. 선형 탐색은 찾는 값이 앞에 있으면 1번에 끝납니다.
요약
  1. 선형 탐색 최악 n번, 이진 탐색(정렬 필요) 약 \(\log_2n + 1\)번.
  2. 선택 정렬 비교 \(n(n-1)/2\)번. n이 10배면 약 100배.
  3. 횟수가 n에 따라 늘어나는 모양이 효율을 결정한다.

3.2.3연습문제

기본

  1. 정렬된 자료 100만 개에서 이진 탐색의 최대 비교 횟수는?
    답

    \(2^{20} \approx 10^6\)이므로 약 20번(정확히 20번).

응용

  1. 선택 정렬로 n = 2000을 정렬할 때 비교 횟수는? n = 1000의 몇 배인가?
    답

    1,999,000번, 약 4배.

심화

  1. 자료 n개에서 탐색을 m번 한다. 선형 탐색만 쓰는 것과, 선택 정렬 후 이진 탐색을 쓰는 것의 비교 횟수를 n = 1000, m = 2000으로 비교하라.
    답

    선형: 최악 2000 × 1000 = 200만. 정렬 후 이진: 499,500 + 2000 × 10 = 519,500. m이 클수록 정렬해 두는 쪽이 이깁니다.
