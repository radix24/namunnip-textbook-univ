리스트와 딕셔너리로 자료 다루기

본문
이 절에서 배울 것
  • 리스트로 순서 있는 자료를 저장하고 인덱스, 슬라이싱, 반복으로 다룬다.
  • 딕셔너리로 이름(키)에 값을 붙여 찾는다.
  • 합계, 평균, 최댓값과 개수 세기를 코드로 쓴다.
먼저 알아야 할 것
  • Python 기본 문법 (2.1절), 함수 (2.2절).

2.3.1두 그릇

리스트는 번호(0부터)로 꺼내는 줄 세운 상자, 딕셔너리는 이름표로 꺼내는 사물함입니다. 측정값 여러 개는 리스트, "부품 이름 → 개수" 같은 대응은 딕셔너리가 편합니다.

temps = [21.5, 22.0, 23.4, 22.8, 24.1]        # 한 시간마다 잰 온도
print("첫 값", temps[0], "마지막 값", temps[-1], "앞 세 개", temps[:3])
print("평균", round(sum(temps) / len(temps), 2), "최고", max(temps))

parts = ["저항", "LED", "저항", "축전기", "저항", "LED"]
count = {}
for p in parts:
    count[p] = count.get(p, 0) + 1
print(count)
print("저항은", count["저항"], "개")

실행 결과(Python 3.12에서 실제 실행):

첫 값 21.5 마지막 값 24.1 앞 세 개 [21.5, 22.0, 23.4]
평균 22.76 최고 24.1
{'저항': 3, 'LED': 2, '축전기': 1}
저항은 3 개
예제 2.3.1

위 코드에서 count.get(p, 0) + 1 대신 count[p] + 1을 쓰면 무슨 일이 생기는가?

풀이. 처음 나온 부품은 아직 키가 없어 KeyError가 납니다. get은 키가 없을 때 기본값 0을 돌려주므로 처음 본 부품도 셀 수 있습니다.

흔한 오해(1) "리스트 번호는 1부터": Python은 0부터 셉니다. (2) "b = a로 복사하면 따로 바뀐다": 같은 리스트를 가리키므로 b를 바꾸면 a도 바뀝니다(복사는 a.copy()).
요약
  1. 리스트: 순서·번호(0부터), 슬라이싱 a[i:j].
  2. 딕셔너리: 키 → 값, get(키, 기본값).
  3. sum, len, max로 요약값 계산.

2.3.2연습문제

기본

  1. temps[1:4]는?
    답

    [22.0, 23.4, 22.8].

응용

  1. 점수 딕셔너리 {'kim': 80, 'lee': 95}에서 가장 높은 사람의 이름을 구하는 식은?
    답

    max(d, key=d.get) → 'lee'.

심화

  1. 리스트에서 25 이상인 값만 모은 새 리스트를 한 줄로 쓰면?
    답

    [t for t in temps if t >= 25].
