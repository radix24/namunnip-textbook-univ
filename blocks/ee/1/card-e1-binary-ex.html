IP 주소를 2진수로 읽기

2진수 · 비트 수 · 경우의 수

출발점

IPv4 주소는 32비트이고, 사람이 읽기 쉽게 8비트씩 끊어 10진수 네 개로 씁니다(1.4절).

문제 해결 전략 · 8비트씩 바꾸기
  1. 점으로 나눈 각 수를 8비트 2진수로 바꾼다.
  2. 전체 비트 수로 가능한 주소 수 2ⁿ을 구한다.

192.168.0.1을 32비트 2진수로 쓰라. IPv4 주소는 모두 몇 개인가? IPv6(128비트)는 IPv4의 몇 배인가?

풀이

  1. 192 = 11000000, 168 = 10101000, 0 = 00000000, 1 = 00000001.
    128 + 64 = 192, 128 + 32 + 8 = 168.
  2. 2³² = 4 294 967 296개(약 43억).
    32비트.
  3. 2¹²⁸/2³² = 2⁹⁶ ≈ 7.9 × 10²⁸배.
    지수 법칙.

의미

주소가 약 43억 개뿐이라 IPv4가 모자라 IPv6가 도입되었다. 비트 수가 하나 늘 때마다 가짓수가 두 배가 되는 것이 2진 표현의 힘이다.

검산

8비트 최대값 11111111 = 255이므로 각 칸은 0~255이다. 192, 168 모두 범위 안이다.
