컴퓨팅 사고와 알고리즘 연습 문제

문제 7 · 계산·구현·판단·도전 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산정렬된 자료 4096개에서 이진 탐색의 최대 비교 횟수는? [03-02]

    힌트 1

    \(2^{12} = 4096\).

    힌트 2

    \(\log_2 n + 1\).

    풀이

    13번.

  2. 계산선택 정렬로 n = 50을 정렬할 때 비교 횟수는? [03-02]

    힌트 1

    \(n(n-1)/2\).

    힌트 2

    50 × 49/2.

    풀이

    1225번.

  3. 계산동전 1, 5, 12로 15원을 만드는 탐욕법과 최소 개수는? [03-01]

    힌트 1

    큰 것부터.

    힌트 2

    5를 세 번?

    풀이

    탐욕 12 + 1 + 1 + 1 = 4개, 최소 5 + 5 + 5 = 3개.

  4. 구현리스트에서 최댓값의 위치를 찾는 알고리즘을 의사코드로 쓰고 비교 횟수를 구하라. [03-02]

    힌트 1

    첫 원소를 후보로.

    힌트 2

    나머지와 하나씩 비교.

    풀이

    후보 = 0번. i = 1..n−1마다 xs[i] > xs[후보]면 후보 = i. 비교 n − 1번.

  5. 판단학생이 "탐욕법이 세 가지 예에서 맞았으니 언제나 맞는다"고 했다. 평가하세요. [03-01]

    힌트 1

    반례.

    힌트 2

    동전 1, 4, 6.

    풀이

    예가 맞는 것은 증명이 아닙니다. 8원(1, 4, 6) 같은 반례 하나로 틀림이 드러납니다. 모든 경우 확인으로 시험하거나 증명이 필요합니다.

  6. 도전숫자 맞히기 놀이(1~100, 크다/작다만 알려 줌)에서 최악의 경우 몇 번이면 반드시 맞히는가? 전략은? [03-02]

    힌트 1

    이진 탐색.

    힌트 2

    \(2^7 = 128\).

    풀이

    가운데를 부르는 이진 탐색으로 최악 7번.

  7. 실습재귀로 1부터 n까지 합을 구하는 함수를 쓰라. [03-03]

    힌트 1

    기저 사례 n == 0.

    힌트 2

    n + 합(n − 1).

    풀이

    def s(n): return 0 if n == 0 else n + s(n - 1).
