정현파 정상상태 해석 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념스위치를 켠 직후에는 페이저 해석이 맞지 않는 이유는 무엇인가요? [07-01]

    힌트 1

    전체 응답 = 자연 응답 + 강제 응답.

    힌트 2

    페이저는 어느 쪽만 다루나요?

    풀이

    페이저는 전원과 같은 주파수의 강제 응답(정상상태)만 나타냅니다. 켠 직후에는 특성근으로 정해지는 자연 응답(과도 응답)이 함께 있고, 이것이 \(e^{-\alpha t}\)로 충분히 사라진 뒤에야(약 \(5/\alpha\)) 페이저 결과와 같아집니다.

  2. 계산\(v(t) = 8\cos(200t - 30°) + 6\sin(200t + 60°)\)를 하나의 코사인으로 쓰세요. [07-01]

    힌트 1

    둘째 항을 코사인으로: \(\sin x = \cos(x - 90°)\).

    힌트 2

    \(8\angle{-30°} + 6\angle{-30°}\).

    풀이

    \(6\sin(200t + 60°) = 6\cos(200t - 30°)\). 같은 위상이라 바로 더해 \(14\cos(200t - 30°)\). 페이저 덧셈은 같은 주파수라서 가능합니다.

  3. 계산\(v_s = 100\cos(377t)\) V, 직렬 \(R = 30\ \Omega\), \(L = 0.106\) H. 정상상태 전류와 인덕터 전압의 진폭·위상을 구하세요. [07-01]

    힌트 1

    \(\omega L \approx 40\ \Omega\).

    힌트 2

    \(\mathbf Z = 30 + j40 = 50\angle53.1°\).

    풀이

    \(\mathbf I = 100/50\angle{-53.1°} = 2\angle{-53.1°}\) A, \(i = 2\cos(377t - 53.1°)\). \(\mathbf V_L = j40\times2\angle{-53.1°} = 80\angle36.9°\) V.

  4. 계산\(\omega = 10^4\) rad/s, \(\mathbf V_s = 5\angle0°\) V — 100 Ω — 단자 A, 단자 A–기준에 1 μF. 단자 A–기준의 노턴 등가를 구하세요. [07-02]

    힌트 1

    \(\mathbf Z_C = -j100\).

    힌트 2

    단락 전류는 축전기를 지나지 않습니다.

    풀이

    \(\mathbf I_\text{N} = 5/100 = 0.05\angle0°\) A. \(\mathbf Z_\text{Th} = 100\parallel(-j100) = \frac{-j10^4}{100 - j100} = 50 - j50\ \Omega\). 검산: \(\mathbf V_\text{Th} = \mathbf I_\text{N}\mathbf Z_\text{Th} = 2.5 - j2.5 = 3.54\angle{-45°}\), 분압 \(5\frac{-j100}{100 - j100}\)과 같음.

  5. 판단학생이 "\(\mathbf Z = 30 + j40\)이니 \(|\mathbf Z| = 70\ \Omega\)"이라고 했다. 무엇이 틀렸고, 이 실수로 전류를 몇 % 작게 계산하게 되나요? [07-02]

    힌트 1

    크기는 피타고라스.

    힌트 2

    50과 70의 비.

    풀이

    저항과 리액턴스는 90° 어긋난 성분이라 크기는 \(\sqrt{30^2 + 40^2} = 50\ \Omega\)입니다. 70으로 하면 전류를 \(50/70 \approx 0.71\)배, 곧 약 29% 작게 계산합니다.

  6. 도전RC 직렬 회로(\(R = 1\ \text{k}\Omega\), \(C = 1\ \mu\text{F}\))에서 축전기 전압이 전원보다 정확히 45° 늦는 주파수와, 그때 축전기 전압의 크기(전원의 몇 배)를 구하세요. [07-01]

    힌트 1

    \(\mathbf V_C/\mathbf V_s = \frac{1}{1 + j\omega RC}\).

    힌트 2

    각이 −45°이려면 \(\omega RC = 1\).

    풀이

    \(\omega = 1/RC = 1000\) rad/s(약 159 Hz), 크기 \(1/\sqrt2 \approx 0.707\)배. 이것이 RC 저역 통과 필터의 차단 주파수입니다(8.2절, 아날로그실험 오실로스코프 카드).
