병렬 RLC의 계단 응답: 인덕터 전류 구하기

예제 · 최종값과 초기 조건 정하기

먼저 예측

1 A 전류원을 \(t = 0\)에 병렬 RLC에 연결하면, 처음 순간 1 A는 R, L, C 중 어디로 갈까?

생각해 본 뒤 열기

인덕터 전류는 0에서 바로 바뀔 수 없고, 축전기 전압이 0이라 저항 전류도 0이다. 그래서 처음 순간 1 A는 모두 축전기로 간다.

문제

\(R = 500\ \Omega\), \(L = 0.1\) H, \(C = 0.1\ \mu\text{F}\)가 같은 두 마디 사이에 병렬로 있고, 처음 에너지는 0이다. \(t = 0\)에 1 mA 전류원을 연결한다. 인덕터 전류 \(i_L(t)\)를 구하여라.

문제 해결 전략

  1. 감쇠 유형: 병렬이므로 \(\alpha = 1/(2RC)\), \(\omega_0 = 1/\sqrt{LC}\).
  2. 최종값: 직류 정상 상태에서 인덕터 단락 → 모든 전류가 인덕터로.
  3. 초기 조건: \(i_L(0^+) = 0\), \(di_L/dt(0^+) = v_L(0^+)/L = v_C(0^+)/L = 0\).
  4. 최종값 + 자연 응답 꼴에 넣어 상수를 정한다.

풀이

  1. \(\alpha = 1/(2\times500\times10^{-7}) = 10^4\), \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\). \(\zeta = 1\), 임계감쇠. 6.1절
  2. 최종값 \(i_L(\infty) = 1\) mA. L 단락이면 R, C에는 전압 0
  3. \(i_L = 1 + (A_1 + A_2t)e^{-10^4t}\) mA. \(i_L(0) = 0\) → \(A_1 = -1\). 연속성
  4. \(\dot i_L(0) = A_2 - 10^4A_1 = 0\) → \(A_2 = -10^4\). \(v_C(0^+) = 0\)
  5. \(i_L(t) = 1 - (1 + 10^4t)e^{-10^4t}\) mA. 정리

의미

1 mA는 처음에 축전기로 들어가 전압을 세우고, 그 전압이 인덕터 전류를 키워 결국 모두 인덕터로 넘어간다. 임계감쇠라 넘침 없이 0.5 ms 만에 96% 도달한다. 같은 회로에서 \(R\)을 키우면(병렬이라 감쇠가 줄어) 인덕터 전류가 1 mA를 넘어 출렁인다.

검산

암페어로 쓰면 \(i_L = 10^{-3}[1 - (1 + 10^4t)e^{-10^4t}]\)이고, 미분하면 \(di_L/dt = 10^{-3}\cdot10^8\,t\,e^{-10^4t} = 10^5\,t\,e^{-10^4t}\) A/s이다. 따라서 \(v_C = L\,di_L/dt = 10^4\,t\,e^{-10^4t}\) V로, \(t = 0\)과 \(t \to \infty\)에서 0이고 \(t = 0.1\) ms에서 최대 \(e^{-1} \approx 0.37\) V이다. 0⁺에서 축전기 전류 \(C\,dv_C/dt(0) = 10^{-7}\times10^4 = 1\) mA로, 처음 1 mA가 모두 축전기로 간다는 예측과 같다.

바꿔 보기

\(R = 2\ \text{k}\Omega\)이면 \(\alpha = 2500\), \(\zeta = 0.25\)로 부족감쇠가 되어 인덕터 전류의 첫 봉우리는 약 1.44 mA입니다(6.2절의 넘침 식).
