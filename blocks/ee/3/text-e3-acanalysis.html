페이저 영역의 회로 해석

본문

7.1절에서 임피던스를 쓰면 직류 해석법이 교류에서도 그대로 통한다고 했다. 그런데 마디가 둘인 회로에서 연립방정식의 계수가 복소수가 되면 계산이 금세 엉킨다. 복소 연립방정식을 실수 없이 풀고, 답이 맞는지 확인하는 요령은 무엇일까?

먼저 알아야 할 것페이저와 임피던스(7.1절), 마디 해석(2.2절), 테브난 등가(3.2절)를 쓴다.

7.2.1복소수 계산 요령

페이저 해석은 방법이 직류와 같고 계산만 복소수이므로, 실수를 줄이는 요령을 먼저 정리하자. 더하기와 빼기는 직교형 \(a + jb\)로 한다. 가령 \((3 + j4) + (1 - j2) = 4 + j2\)이다. 반면 곱하기와 나누기는 극형식 \(r\angle\theta\)로 하는 편이 쉽다. 크기는 곱하거나 나누고, 각은 더하거나 빼면 된다.

두 형식 사이를 오갈 때는 \(r = \sqrt{a^2 + b^2}\), \(\theta = \arctan(b/a)\)를 쓰되 \(a\)가 음수면 180°를 더한다. 거꾸로는 \(a = r\cos\theta\), \(b = r\sin\theta\)이다. 또 직교형으로 나눌 때는 켤레를 곱해 \(\dfrac{1}{a + jb} = \dfrac{a - jb}{a^2 + b^2}\)로 분모를 실수로 만든다.

7.2.2페이저 마디 해석

예제 7.2.1

\(v_s = 10\cos(1000t)\) V 전원에서 10 Ω을 거쳐 마디 1에 닿는다. 마디 1과 기준 사이에 \(-j10\ \Omega\)(축전기 100 μF)이 있고, 마디 1에서 \(j5\ \Omega\)(5 mH)을 거쳐 마디 2에 닿으며, 마디 2와 기준 사이에 5 Ω이 있다. 마디 2 전압 \(v_2(t)\)를 구하여라.

풀이. 마디 1에서 나가는 전류의 합은 \(\frac{\mathbf V_1 - 10}{10} + \frac{\mathbf V_1}{-j10} + \frac{\mathbf V_1 - \mathbf V_2}{j5} = 0\)이다. \(\frac{1}{-j10} = j0.1\), \(\frac{1}{j5} = -j0.2\)이므로 \(\mathbf V_1(0.1 + j0.1 - j0.2) + j0.2\mathbf V_2 = 1\), 곧 \((0.1 - j0.1)\mathbf V_1 + j0.2\mathbf V_2 = 1\)이다.

마디 2에서는 \(\frac{\mathbf V_2 - \mathbf V_1}{j5} + \frac{\mathbf V_2}{5} = 0\)이므로 \(j0.2\mathbf V_1 + (0.2 - j0.2)\mathbf V_2 = 0\)이다. 따라서 \(\mathbf V_1 = \frac{-(0.2 - j0.2)}{j0.2}\mathbf V_2 = (1 + j)\mathbf V_2\)이다.

이를 첫 식에 넣으면 \((0.1 - j0.1)(1 + j)\mathbf V_2 + j0.2\mathbf V_2 = 1\)이다. 그런데 \((0.1 - j0.1)(1 + j) = 0.1 + j0.1 - j0.1 + 0.1 = 0.2\)이므로 \((0.2 + j0.2)\mathbf V_2 = 1\)이다. 그러므로 \(\mathbf V_2 = \frac{1}{0.2828\angle45°} = 3.54\angle{-45°}\) V이고 \(v_2(t) = 3.54\cos(1000t - 45°)\) V이다.

이제 검산하자. \(\mathbf V_1 = (1 + j)\mathbf V_2 = 1.414\angle45°\times3.54\angle{-45°} = 5\angle0°\) V이다. 전원 쪽 전류는 \((10 - 5)/10 = 0.5\) A, 축전기 전류는 \(5/(-j10) = j0.5\), 인덕터 가지 전류는 \(\mathbf V_2/5 = 0.707\angle{-45°} = 0.5 - j0.5\)이다. 뒤의 둘을 더하면 0.5로, 그림 1처럼 KCL이 맞는다. 처음 질문의 답은 이 두 가지이다. 계산은 형식을 골라 가며 하고, 답은 KCL로 검산한다.

7.2.3교류 테브난 등가

3.2절의 논리는 임피던스로도 그대로 성립한다. 두 단자로 본 선형 교류 회로는 페이저 전압원 \(\mathbf V_\text{Th}\)와 직렬 임피던스 \(\mathbf Z_\text{Th}\)로 바꿀 수 있다. \(\mathbf Z_\text{Th}\)는 독립 전원을 끄고 본 임피던스이며, 종속 전원이 있으면 시험 전원을 쓴다. 다만 \(\mathbf Z_\text{Th}\)는 그 주파수에서만 성립한다.

예제 7.2.2

예제 7.2.1에서 5 Ω을 부하로 보고, 나머지 회로를 마디 2와 기준 사이 단자에서 본 테브난 등가를 구하여라. 부하 전압이 예제 7.2.1과 같은지 확인하여라.

풀이. 5 Ω을 떼어 개방하면 \(j5\)에 전류가 없으므로 \(\mathbf V_\text{Th} = \mathbf V_1\)이고, 이는 10 V를 10 Ω과 \(-j10\)으로 분압한 값이다. 곧 \(10\frac{-j10}{10 - j10} = 10\frac{1\angle{-90°}}{1.414\angle{-45°}} = 7.07\angle{-45°}\) V이다. 전원을 끄면 \(\mathbf Z_\text{Th} = j5 + 10\parallel(-j10) = j5 + \frac{-j100}{10 - j10} = j5 + (5 - j5) = 5\ \Omega\)이다. 따라서 부하 5 Ω의 전압은 \(7.07\angle{-45°}\times\frac{5}{10} = 3.54\angle{-45°}\) V로 같다.

테브난 임피던스가 이 주파수에서 우연히 순수 저항 5 Ω이 되었다. 인덕터의 리액턴스가 RC 부분의 용량성 리액턴스를 지웠기 때문이다. 이런 조합을 일부러 만드는 것이 임피던스 정합(8.1절, 전전19)이다.

흔한 실수교류 회로에서 직렬 임피던스의 크기는 각 크기의 합이 아니다. \(|10 - j10| = 14.1\)이지 20이 아니다. 크기를 더하고 싶어지면 직교형으로 바꿔 더한 뒤 크기를 구하자.
마무리

페이저 마디 해석은 컨덕턴스 대신 어드미턴스 \(1/\mathbf Z\)로 직류와 같은 식을 세우는 일이어서, 더하기는 직교형으로, 곱하기와 나누기는 극형식으로 하면 복소 연립방정식도 깔끔하게 풀리고, 답은 가지 전류를 다시 구해 KCL로 검산한다. 교류 테브난 등가 \(\mathbf V_\text{Th}\), \(\mathbf Z_\text{Th}\)도 같은 방법으로 구하되, 한 주파수에서만 성립한다.

7.2.4연습문제

기본

  1. \((3 + j4)(1 - j)\)와 \(\frac{10\angle30°}{2 + j2}\)를 계산하여라.
    답

    \(3 - j3 + j4 + 4 = 7 + j\)이고, \(\frac{10\angle30°}{2.83\angle45°} = 3.54\angle{-15°}\)이다.

응용

  1. 예제 7.2.1에서 \(\omega = 500\) rad/s로 바꾸면 테브난 임피던스는? (같은 소자, 100 μF와 5 mH)
    답

    \(\mathbf Z_C = -j20\), \(\mathbf Z_L = j2.5\)이다. \(10\parallel(-j20) = \frac{-j200}{10 - j20} = 8 - j4\)이므로 \(\mathbf Z_\text{Th} = 8 - j1.5\ \Omega\)이다.

심화

  1. 예제 7.2.1의 회로를 망 해석으로 풀어 \(\mathbf V_2\)가 같음을 확인하여라. 망 1은 전원, 10 Ω, \(-j10\)이고 망 2는 \(-j10\), \(j5\), 5 Ω이며, 둘 다 시계 방향이다.
    힌트

    망 1은 \((10 - j10)\mathbf I_1 + j10\mathbf I_2 = 10\), 망 2는 \(j10\mathbf I_1 + (5 - j5)\mathbf I_2 = 0\).

    답

    망 2에서 \(\mathbf I_1 = -\frac{5 - j5}{j10}\mathbf I_2 = (0.5 + j0.5)\mathbf I_2\)이다. 망 1에 넣으면 \((10 - j10)(0.5 + j0.5)\mathbf I_2 + j10\mathbf I_2 = (10 + j10)\mathbf I_2 = 10\)이므로 \(\mathbf I_2 = 0.707\angle{-45°}\) A, \(\mathbf V_2 = 5\mathbf I_2 = 3.54\angle{-45°}\) V로 같다.
