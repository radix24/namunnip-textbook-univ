이상적 연산증폭기와 기본 증폭기

본문
이 절에서 배울 것
  • 연산증폭기를 VCVS 모형으로 보고, 이득이 무한대에 가까울 때 두 가지 이상 조건(가상 단락, 입력 전류 0)이 나오는 이유를 안다.
  • 반전, 비반전, 전압 폴로어, 가산, 차동 증폭기의 이득을 마디 해석으로 구한다.
  • 음의 되먹임이 있어야 가상 단락을 쓸 수 있음을 안다.
먼저 알아야 할 것
  • 종속 전원(VCVS) (1.2절), 마디 해석 (2.2절).

4.1.1연산증폭기는 무엇인가

연산증폭기(op amp)는 트랜지스터 수십 개를 칩 하나에 넣은 증폭기로, 단자가 다섯 개입니다. 비반전 입력 \(v_+\), 반전 입력 \(v_-\), 출력 \(v_o\), 그리고 양·음 전원(예: ±12 V)입니다. 회로도에서는 전원 단자를 흔히 생략하지만, 출력은 전원 전압을 넘을 수 없다는 것을 늘 기억해야 합니다.

동작을 한 줄로 쓰면 VCVS입니다.

\[ v_o = A\,(v_+ - v_-). \]

열린 루프 이득 \(A\)는 \(10^5 \sim 10^6\)으로 매우 큽니다. 두 입력 사이에 1 mV만 차이가 나도 출력은 100 V가 되어야 하는데, 전원이 ±12 V라면 출력은 거기서 막힙니다(포화). 그래서 연산증폭기를 홀로 쓰지 않고, 출력의 일부를 반전 입력으로 되돌리는 음의 되먹임을 걸어 씁니다.

4.1.2이상 조건이 나오는 까닭

되먹임이 걸린 회로에서 출력이 전원 범위 안의 유한한 값에 머문다면 \(v_+ - v_- = v_o/A\)입니다. \(A \to \infty\)이면 이 값은 0으로 갑니다. 여기에 실제 연산증폭기의 입력 저항이 매우 크다(MΩ ~ TΩ)는 사실을 더하면 두 조건을 얻습니다.

가상 단락: \(v_+ = v_-\). 두 입력이 도선으로 이어지지 않았는데도 같은 전압이 된다.

입력 전류 0: \(i_+ = i_- = 0\). 입력 단자로는 전류가 들어가지 않는다.

"가상"이라는 말에 주의하세요. 진짜 단락이라면 두 입력 사이로 전류가 흐를 수 있지만, 여기서는 전압만 같고 전류는 0입니다. 그리고 이 조건은 음의 되먹임이 있을 때만 성립합니다. 되먹임이 없거나 양의 되먹임이면 출력이 포화되어 \(v_+ \ne v_-\)입니다(비교기, 슈미트 트리거).

4.1.3반전 증폭기

입력 \(v_i\) — \(R_1\) — 반전 입력, 반전 입력 — \(R_f\) — 출력, 비반전 입력은 접지입니다.

가상 단락으로 \(v_- = v_+ = 0\)(가상 접지). 반전 입력 마디에서 KCL(입력 전류 0):

\[ \frac{v_i - 0}{R_1} + \frac{v_o - 0}{R_f} = 0 \quad\Longrightarrow\quad \frac{v_o}{v_i} = -\frac{R_f}{R_1}. \]

이득은 저항 비로만 정해지고, 연산증폭기의 \(A\)나 온도에 거의 영향을 받지 않습니다. 이것이 되먹임의 가장 큰 이득입니다. 입력에서 본 저항은 \(R_1\)입니다(가상 접지까지의 저항).

4.1.4비반전 증폭기와 전압 폴로어

입력 \(v_i\)를 비반전 입력에, 출력 — \(R_f\) — 반전 입력 — \(R_1\) — 접지로 연결합니다. \(v_- = v_i\)이고, 반전 입력 마디는 출력을 \(R_f\)와 \(R_1\)로 나눈 분압이므로

\[ v_i = \frac{R_1}{R_1 + R_f}v_o \quad\Longrightarrow\quad \frac{v_o}{v_i} = 1 + \frac{R_f}{R_1}. \]

입력이 연산증폭기 입력 단자에 바로 들어가므로 입력 저항이 사실상 무한대입니다. \(R_f = 0\), \(R_1 = \infty\)로 하면 이득 1의 전압 폴로어(버퍼)가 됩니다. 전압은 키우지 않지만, 앞 회로에서 전류를 거의 빼지 않고 뒤 부하를 대신 구동하므로 2.1절의 분압기 부하 문제를 해결합니다.

4.1.5가산 증폭기와 차동 증폭기

가산 증폭기: 반전 입력에 \(v_1\)–\(R_1\), \(v_2\)–\(R_2\), … 를 모으면 가상 접지 마디의 KCL로

\[ v_o = -R_f\Big(\frac{v_1}{R_1} + \frac{v_2}{R_2} + \cdots\Big). \]

각 입력이 가상 접지로 전류를 따로 보내므로 서로 간섭하지 않습니다. 음향 믹서와 디지털-아날로그 변환기(가중 저항형)가 이 원리입니다.

차동 증폭기: \(v_1\) — \(R_1\) — 반전 입력 — \(R_2\) — 출력, \(v_2\) — \(R_1\) — 비반전 입력 — \(R_2\) — 접지. 중첩(3.1절)으로 \(v_1\)만 있으면 반전 증폭 \(-\frac{R_2}{R_1}v_1\), \(v_2\)만 있으면 비반전 입력 전압이 \(\frac{R_2}{R_1 + R_2}v_2\)이고 이것이 \(1 + \frac{R_2}{R_1}\)배 되므로 \(\frac{R_2}{R_1}v_2\). 합치면

\[ v_o = \frac{R_2}{R_1}(v_2 - v_1). \]

두 입력의 차이만 증폭하고, 둘에 똑같이 섞인 잡음(공통 모드)은 지웁니다. 휘트스톤 다리 센서(2.2절 카드)의 출력을 읽는 데 씁니다.

예제 4.1.1

\(v_1 = 0.2\) V, \(v_2 = -0.5\) V를 가산 증폭기(\(R_1 = 10\ \text{k}\Omega\), \(R_2 = 20\ \text{k}\Omega\), \(R_f = 50\ \text{k}\Omega\), 전원 ±12 V)에 넣었다. 출력과 출력이 포화되지 않는지 확인하여라.

풀이. \(v_o = -50(0.2/10 - 0.5/20) = -50(0.02 - 0.025) = 0.25\) V. 전원 범위 안이라 포화되지 않습니다. 가상 접지로 들어가는 전류는 \(0.02 - 0.025 = -0.005\) mA이고, 이 전류가 \(R_f\)를 지나 \(0.25\) V를 만듭니다.

4.1.6이득이 유한하면

\(A\)가 유한할 때 반전 증폭기를 다시 풀면(\(v_- = -v_o/A\)를 KCL에 넣어)

\[ \frac{v_o}{v_i} = -\frac{R_f}{R_1}\cdot\frac{1}{1 + \frac{1 + R_f/R_1}{A}}. \]

\(A = 10^5\), \(R_f/R_1 = 100\)이면 둘째 인수는 약 \(0.999\)로 오차 0.1%입니다. 이상 조건이 좋은 근사인 이유이고, 동시에 큰 이득을 원할수록 오차가 커진다는 것도 보여 줍니다. 이득이 주파수에 따라 떨어지는 효과는 아날로그실험의 연산증폭기 카드에서 봅니다.

주의가상 단락을 쓸 때 "반전 입력이 접지와 같으니 거기로 전류가 빠져나간다"고 생각하면 틀립니다. 입력 전류는 0이므로 \(R_1\)로 들어온 전류는 모두 \(R_f\)로 갑니다. 반대로 출력 단자로는 연산증폭기가 필요한 만큼 전류를 내보내거나 받아들이므로, 출력 마디에는 KCL을 쓰지 않습니다(출력 전류는 미지수).
요약
  1. 연산증폭기는 \(v_o = A(v_+ - v_-)\), \(A\)는 매우 크다. 음의 되먹임이 있으면 가상 단락 \(v_+ = v_-\)와 입력 전류 0.
  2. 반전 \(-R_f/R_1\), 비반전 \(1 + R_f/R_1\), 폴로어 1, 가산 \(-R_f\sum v_k/R_k\), 차동 \(\frac{R_2}{R_1}(v_2 - v_1)\).
  3. 입력 마디에서만 KCL을 쓴다. 출력 전류는 연산증폭기가 정한다. 출력은 전원 범위를 넘지 못한다.

4.1.7연습문제

기본

  1. 반전 증폭기 \(R_1 = 2.2\ \text{k}\Omega\), \(R_f = 47\ \text{k}\Omega\)에 0.1 V를 넣으면 출력은?
    답

    \(-47/2.2\times0.1 \approx -2.14\) V.

  2. 비반전 증폭기로 이득 11을 만드는 저항 쌍 하나를 들어라.
    답

    \(R_f = 100\ \text{k}\Omega\), \(R_1 = 10\ \text{k}\Omega\).

응용

  1. 차동 증폭기(\(R_1 = 10\ \text{k}\Omega\), \(R_2 = 100\ \text{k}\Omega\))에 \(v_1 = 2.000\) V, \(v_2 = 2.005\) V가 들어온다. 출력은? 두 입력에 똑같이 0.1 V 잡음이 더해지면?
    답

    \(10\times0.005 = 0.05\) V. 잡음은 차이에 영향을 주지 않으므로 그대로 0.05 V(저항이 정확히 맞을 때).

심화

  1. 비반전 증폭기를 유한 이득 \(A\)로 다시 풀어 \(\frac{v_o}{v_i} = \frac{A}{1 + A\beta}\), \(\beta = \frac{R_1}{R_1 + R_f}\)임을 보여라. \(A\beta \gg 1\)이면 어떻게 되는가?
    힌트

    \(v_- = \beta v_o\), \(v_o = A(v_i - \beta v_o)\).

    답

    \(v_o(1 + A\beta) = Av_i\). \(A\beta \gg 1\)이면 \(1/\beta = 1 + R_f/R_1\). \(A\beta\)를 루프 이득이라 하며 되먹임 이론(전전13)의 중심 개념이다.
