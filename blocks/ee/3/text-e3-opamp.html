이상적 연산증폭기와 기본 증폭기

본문

연산증폭기의 이득은 수십만 배이지만 칩마다 두세 배씩 다르고 온도에 따라서도 변한다. 그런데 이 칩에 저항 두 개를 붙이면 이득이 정확히 10.0배인 증폭기가 된다. 들쭉날쭉한 부품으로 어떻게 정확한 회로를 만들 수 있을까?

먼저 알아야 할 것종속 전원 VCVS(1.2절)와 마디 해석(2.2절)을 쓴다.

4.1.1연산증폭기는 VCVS이다

연산증폭기는 트랜지스터 수십 개를 칩 하나에 넣은 증폭기이다. 단자는 비반전 입력 \(v_+\), 반전 입력 \(v_-\), 출력 \(v_o\), 그리고 양과 음의 전원(가령 ±12 V)으로 다섯 개이다. 회로도에서는 전원 단자를 흔히 생략하지만, 출력이 전원 전압을 넘을 수 없다는 사실은 늘 기억해야 한다. 동작은 VCVS 하나로 쓸 수 있다.

\[ v_o = A\,(v_+ - v_-) \]

열린 루프 이득 \(A\)는 \(10^5\)에서 \(10^6\) 정도로 매우 크다. 그래서 두 입력이 1 mV만 달라도 출력은 100 V가 되어야 하는데, 전원이 ±12 V라면 출력은 거기서 막힌다. 이를 포화라 한다(그림 2). 따라서 연산증폭기를 홀로 쓰지 않고, 출력의 일부를 반전 입력으로 되돌리는 음의 되먹임을 걸어 쓴다.

4.1.2이상 조건이 나오는 까닭

되먹임이 걸린 회로에서 출력이 전원 범위 안의 유한한 값에 머문다고 하자. 그러면 \(v_+ - v_- = v_o/A\)이고, \(A \to \infty\)이면 이 값은 0으로 간다. 여기에 실제 연산증폭기의 입력 저항이 MΩ에서 TΩ에 이를 만큼 크다는 사실을 더하면 두 조건을 얻는다. 하나는 가상 단락 \(v_+ = v_-\)이고, 다른 하나는 입력 전류 \(i_+ = i_- = 0\)이다.

"가상"이라는 말에 주의하자. 진짜 단락이라면 두 입력 사이로 전류가 흐를 수 있지만, 여기서는 전압만 같고 전류는 0이다. 또한 이 조건은 음의 되먹임이 있을 때만 성립한다. 되먹임이 없거나 양의 되먹임이면 출력이 포화되어 \(v_+ \ne v_-\)이며, 비교기와 슈미트 트리거가 이렇게 동작한다.

4.1.3반전 증폭기

그림 1처럼 입력 \(v_i\)를 \(R_1\)을 거쳐 반전 입력에 넣고, 반전 입력과 출력 사이에 \(R_f\)를 달며, 비반전 입력은 접지한다. 가상 단락으로 \(v_- = v_+ = 0\)이므로 반전 입력은 가상 접지가 된다. 입력 전류가 0이라는 조건으로 반전 입력 마디의 KCL을 쓰면 다음을 얻는다.

\[ \frac{v_i - 0}{R_1} + \frac{v_o - 0}{R_f} = 0 \quad\Longrightarrow\quad \frac{v_o}{v_i} = -\frac{R_f}{R_1} \]

이득에 \(A\)가 없다. 이득은 저항 비로만 정해지므로 연산증폭기의 이득이 두세 배 변해도, 온도가 바뀌어도 거의 그대로이다. 처음 질문의 답이 이것이며, 되먹임이 주는 가장 큰 선물이다. 한편 입력에서 본 저항은 가상 접지까지의 저항 \(R_1\)이다.

4.1.4비반전 증폭기와 전압 폴로어

이번에는 입력 \(v_i\)를 비반전 입력에 넣고, 출력에서 \(R_f\)를 거쳐 반전 입력, 다시 \(R_1\)을 거쳐 접지로 잇는다. 가상 단락으로 \(v_- = v_i\)이고, 반전 입력 마디는 출력을 \(R_f\)와 \(R_1\)로 나눈 분압이다.

\[ v_i = \frac{R_1}{R_1 + R_f}v_o \quad\Longrightarrow\quad \frac{v_o}{v_i} = 1 + \frac{R_f}{R_1} \]

입력이 연산증폭기 입력 단자에 바로 들어가므로 입력 저항이 사실상 무한대이다. \(R_f = 0\), \(R_1 = \infty\)로 하면 이득 1의 전압 폴로어(버퍼)가 된다. 폴로어는 전압을 키우지 않지만 앞 회로에서 전류를 거의 빼지 않고 뒤 부하를 대신 구동하므로, 2.1절에서 본 분압기의 부하 문제를 해결한다.

4.1.5가산 증폭기와 차동 증폭기

반전 입력에 여러 입력을 저항을 하나씩 거쳐 모으면 가산 증폭기가 된다. 가상 접지 마디의 KCL로 다음을 얻는다.

\[ v_o = -R_f\Big(\frac{v_1}{R_1} + \frac{v_2}{R_2} + \cdots\Big) \]

각 입력은 0 V인 가상 접지로 전류를 따로 보내므로 서로 간섭하지 않는다. 음향 믹서와 가중 저항형 디지털-아날로그 변환기가 이 원리이다.

예제 4.1.1

\(v_1 = 0.2\) V, \(v_2 = -0.5\) V를 가산 증폭기(\(R_1 = 10\ \text{k}\Omega\), \(R_2 = 20\ \text{k}\Omega\), \(R_f = 50\ \text{k}\Omega\), 전원 ±12 V)에 넣었다. 출력을 구하고 포화되지 않는지 확인하여라.

풀이. \(v_o = -50(0.2/10 - 0.5/20) = -50(0.02 - 0.025) = 0.25\) V이고, 전원 범위 안이라 포화되지 않는다. 가상 접지로 들어가는 전류는 \(0.02 - 0.025 = -0.005\) mA이며, 이 전류가 \(R_f\)를 지나 0.25 V를 만든다.

차동 증폭기는 두 입력의 차이를 증폭한다. \(v_1\)을 \(R_1\)을 거쳐 반전 입력에, 반전 입력과 출력 사이에 \(R_2\)를 달고, \(v_2\)는 \(R_1\)과 \(R_2\)의 분압을 거쳐 비반전 입력에 넣는다. 중첩(3.1절)으로 풀면, \(v_1\)만 있을 때는 반전 증폭으로 \(-\frac{R_2}{R_1}v_1\)이다. \(v_2\)만 있을 때는 비반전 입력 전압 \(\frac{R_2}{R_1 + R_2}v_2\)가 \(1 + \frac{R_2}{R_1}\)배 되어 \(\frac{R_2}{R_1}v_2\)이다. 합치면 다음과 같다.

\[ v_o = \frac{R_2}{R_1}(v_2 - v_1) \]

그러므로 두 입력에 똑같이 섞인 잡음, 곧 공통 모드는 지워진다. 휘트스톤 다리 센서(2.2절)의 출력을 읽을 때 이 회로를 쓴다.

4.1.6이득이 유한하면

이상 조건이 얼마나 좋은 근사인지 확인해 보자. \(A\)가 유한하면 \(v_- = -v_o/A\)이므로, 이를 반전 증폭기의 KCL에 넣어 다시 풀면 다음을 얻는다.

\[ \frac{v_o}{v_i} = -\frac{R_f}{R_1}\cdot\frac{1}{1 + \frac{1 + R_f/R_1}{A}} \]

\(A = 10^5\), \(R_f/R_1 = 100\)이면 둘째 인수는 약 0.999로 오차가 0.1%이다. 다시 말해 이상 조건은 훌륭한 근사이지만, 큰 이득을 원할수록 오차가 커진다. 이득이 주파수에 따라 떨어지는 효과는 아날로그실험의 연산증폭기 절에서 다룬다.

흔한 실수가상 단락을 쓸 때 "반전 입력이 접지와 같으니 거기로 전류가 빠져나간다"고 생각하면 틀린다. 입력 전류는 0이므로 \(R_1\)로 들어온 전류는 모두 \(R_f\)로 간다. 반대로 출력 단자로는 연산증폭기가 필요한 만큼 전류를 내보내거나 받아들이므로, 출력 마디에는 KCL을 쓰지 않는다. 출력 전류는 미지수로 남는다.
마무리

연산증폭기는 이득이 매우 큰 VCVS \(v_o = A(v_+ - v_-)\)여서 홀로는 포화되지만, 음의 되먹임을 걸면 가상 단락 \(v_+ = v_-\)와 입력 전류 0이라는 두 조건이 성립한다. 이 조건으로 입력 마디에 KCL을 쓰면 반전 \(-R_f/R_1\), 비반전 \(1 + R_f/R_1\), 폴로어 1, 가산, 차동 증폭기의 이득이 모두 저항 비로만 정해지므로, 들쭉날쭉한 칩으로도 정확한 증폭기를 만들 수 있다.

4.1.7연습문제

기본

  1. 반전 증폭기 \(R_1 = 2.2\ \text{k}\Omega\), \(R_f = 47\ \text{k}\Omega\)에 0.1 V를 넣으면 출력은?
    답

    \(-47/2.2\times0.1 \approx -2.14\) V이다.

  2. 비반전 증폭기로 이득 11을 만드는 저항 쌍 하나를 들어라.
    답

    \(R_f = 100\ \text{k}\Omega\), \(R_1 = 10\ \text{k}\Omega\)이다.

응용

  1. 차동 증폭기(\(R_1 = 10\ \text{k}\Omega\), \(R_2 = 100\ \text{k}\Omega\))에 \(v_1 = 2.000\) V, \(v_2 = 2.005\) V가 들어온다. 출력은? 두 입력에 똑같이 0.1 V 잡음이 더해지면?
    답

    \(10\times0.005 = 0.05\) V이다. 잡음은 차이를 바꾸지 않으므로, 저항이 정확히 맞는다면 출력은 그대로 0.05 V이다.

심화

  1. 비반전 증폭기를 유한 이득 \(A\)로 다시 풀어 \(\frac{v_o}{v_i} = \frac{A}{1 + A\beta}\), \(\beta = \frac{R_1}{R_1 + R_f}\)임을 보여라. \(A\beta \gg 1\)이면 어떻게 되는가?
    힌트

    \(v_- = \beta v_o\), \(v_o = A(v_i - \beta v_o)\).

    답

    \(v_o(1 + A\beta) = Av_i\)이다. \(A\beta \gg 1\)이면 이득은 \(1/\beta = 1 + R_f/R_1\)로 간다. \(A\beta\)를 루프 이득이라 하며, 되먹임 이론(전전13)의 중심 개념이다.
