s-영역 회로 해석

본문

RLC 회로의 과도 응답을 구하려고 미분방정식을 세우고 초기 조건을 넣어 푸는 일은 번거롭다. Laplace 변환을 쓰면 인덕터와 축전기도 저항처럼 "임피던스"가 되고, 초기 조건은 전원 하나로 바뀐다. 그러면 회로 해석이 대수 계산이 된다.

먼저 알아야 할 것1차 회로(5.1절), 2차 회로(6.1절), 정현파 정상상태의 임피던스(7.1절)를 쓴다.

10.1.1소자의 s-영역 모형

Laplace 변환 \(F(s) = \int_0^\infty f(t)e^{-st}dt\)의 미분 성질은 \(\mathcal L\{f'\} = sF(s) - f(0^-)\)이다. 그러므로 인덕터의 \(v = L\,di/dt\)는 \(V(s) = sLI(s) - Li(0^-)\)가 되고, 축전기의 \(i = C\,dv/dt\)는 \(V(s) = I(s)/(sC) + v(0^-)/s\)가 된다. 따라서 인덕터는 임피던스 \(sL\)에 초기 전류만큼의 전압원을, 축전기는 \(1/sC\)에 초기 전압의 계단 전압원을 직렬로 단 것과 같다(그림 1). 이렇게 바꾼 회로에 KVL, KCL, 마디 해석을 그대로 쓰면 미지수가 \(s\)의 유리식으로 나온다. 마지막으로 부분분수 전개로 시간 영역으로 되돌린다.

10.1.2예: 직렬 RLC 회로

직렬 RLC 회로에서 \(t = 0\)에 스위치를 닫아 직류 전압 \(V_0\)를 건다. 처음 전류와 축전기 전압이 0이면 \(I(s) = \frac{V_0/s}{R + sL + 1/sC} = \frac{V_0/L}{s^2 + (R/L)s + 1/LC}\)이다. 분모의 근이 극점이고, 극점의 위치가 응답의 모양을 정한다. 두 근이 음의 실수이면 과감쇠, 겹치면 임계감쇠, 복소켤레이면 미감쇠 진동이다. 따라서 \(s\)-영역에서는 미분방정식을 풀지 않고도 응답의 종류를 바로 알 수 있다.

예제 10.1.1

\(R = 4\) Ω, \(L = 1\) H, \(C = 1/3\) F인 직렬 RLC 회로에 \(t = 0\)에 \(V_0 = 6\) V를 걸었다(초기값 0). 전류 \(i(t)\)를 구하여라.

풀이. \(I(s) = \frac{6}{s^2 + 4s + 3} = \frac{6}{(s + 1)(s + 3)} = \frac{3}{s + 1} - \frac{3}{s + 3}\)이다. 그러므로 \(i(t) = 3(e^{-t} - e^{-3t})\) A이다. 극점이 −1, −3의 음의 실수라 과감쇠이고, 처음 0에서 오르다 다시 0으로 줄어 축전기가 다 충전되면 전류가 멈춘다.

마무리

Laplace 변환으로 인덕터와 축전기는 \(sL\), \(1/sC\)의 임피던스가 되고, 초기 조건은 직렬 전압원으로 들어간다. 이렇게 바꾼 회로를 저항 회로처럼 해석하고 부분분수 전개로 시간 영역 응답을 얻는다. 분모의 극점 위치가 과감쇠, 임계감쇠, 미감쇠를 정한다.

10.1.3연습문제

기본

  1. 예제에서 \(R = 2\) Ω으로 바꾸면 극점은 어디이고 응답은 어떤 종류인가?
    답

    \(s^2 + 2s + 3 = 0\), \(s = -1 \pm j\sqrt2\). 미감쇠 진동.

응용

  1. 처음 2 V로 충전된 1 F 축전기를 1 Ω 저항에 연결했다. s-영역 등가회로로 방전 전류를 구하여라.
    답

    \(I(s) = (2/s)/(1 + 1/s) = 2/(s + 1)\), \(i(t) = 2e^{-t}\) A.
