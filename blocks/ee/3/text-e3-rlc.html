RLC 회로의 미분방정식과 감쇠 유형

본문

저항과 축전기만 있는 회로의 전압은 출렁이지 않고 매끄럽게 0으로 간다. 그런데 같은 회로에 코일 하나를 더하면 전압이 양과 음을 오가며 출렁이기도 하고, 저항값을 바꾸면 출렁임이 사라지기도 한다. 출렁일지 말지는 무엇으로 정해질까?

먼저 알아야 할 것축전기, 인덕터와 연속성(5.1절), 1차 회로(5.2절), 이차방정식의 근의 공식, 그리고 복소수와 오일러 공식 \(e^{j\theta} = \cos\theta + j\sin\theta\)(공통1 8.8절)를 쓴다. 전기공학에서는 전류 \(i\)와 헷갈리지 않게 허수 단위를 \(j\)로 쓴다.

6.1.1방정식 세우기

축전기와 인덕터가 함께 있으면 에너지가 두 소자 사이를 오갈 수 있으므로, 1차 회로에 없던 진동이 생긴다. 전원 없는 직렬 RLC 회로에서 출발하자. 고리를 도는 전류 \(i\)에 대해 KVL과 축전기 관계는 다음과 같다.

\[ Ri + L\frac{di}{dt} + v_C = 0, \qquad i = C\frac{dv_C}{dt} \]

둘째 식을 첫째 식에 넣어 \(v_C\) 하나로 쓰면 다음 2계 미분방정식이 된다.

\[ LC\frac{d^2v_C}{dt^2} + RC\frac{dv_C}{dt} + v_C = 0 \quad\Longleftrightarrow\quad \frac{d^2v_C}{dt^2} + 2\alpha\frac{dv_C}{dt} + \omega_0^2v_C = 0 \]

여기서 \(\alpha = \dfrac{R}{2L}\)은 감쇠 계수, \(\omega_0 = \dfrac{1}{\sqrt{LC}}\)는 공진 각주파수이다. 한편 R, L, C가 같은 두 마디 사이에 있는 병렬 RLC는 마디 전압 \(v\)에 KCL을 써서 같은 꼴을 얻으며, 이 때 \(\alpha = \dfrac{1}{2RC}\)이다. 그러므로 병렬에서는 R이 클수록 감쇠가 작다.

6.1.2특성방정식과 세 경우

1차 회로의 해가 지수였으니 \(v = Ae^{st}\)로 놓아 보자. 미분하면 \(s\)가 곱해지므로 \(Ae^{st}(s^2 + 2\alpha s + \omega_0^2) = 0\)이고, 곧 다음 특성방정식을 얻는다.

\[ s^2 + 2\alpha s + \omega_0^2 = 0, \qquad s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2} \]

근이 두 개이면 방정식이 선형이라 \(A_1e^{s_1t} + A_2e^{s_2t}\)도 해이고, 두 상수는 초기 조건 둘, 곧 \(v_C(0)\)과 \(i_L(0)\)에서 나오는 \(dv_C/dt(0)\)로 정한다. 근호 안의 부호에 따라 세 경우로 나뉘며, 감쇠비 \(\zeta = \alpha/\omega_0\)로 판정하면 편리하다. 처음 질문의 답이 이 감쇠비이다.

\(\zeta > 1\)이면 서로 다른 두 음의 실근이 나와 \(v = A_1e^{s_1t} + A_2e^{s_2t}\)이고, 출렁임 없이 천천히 0으로 간다. 이를 과감쇠라 한다. \(\zeta = 1\)이면 중근 \(s = -\alpha\)가 나와 \(v = (A_1 + A_2t)e^{-\alpha t}\)이고, 출렁임 없이 가장 빨리 0으로 간다. 이를 임계감쇠라 한다. \(\zeta < 1\)이면 켤레 복소근 \(s = -\alpha \pm j\omega_d\)(\(\omega_d = \sqrt{\omega_0^2 - \alpha^2}\))가 나와 \(v = e^{-\alpha t}(B_1\cos\omega_dt + B_2\sin\omega_dt)\)이고, 줄어들며 진동한다. 이를 부족감쇠라 한다.

부족감쇠의 해가 실수 함수가 되는 과정은 오일러 공식으로 본다. \(e^{(-\alpha + j\omega_d)t} = e^{-\alpha t}(\cos\omega_dt + j\sin\omega_dt)\)이므로, 두 켤레 근의 해를 더하고 빼면 \(e^{-\alpha t}\cos\omega_dt\)와 \(e^{-\alpha t}\sin\omega_dt\)가 나온다. 따라서 이 둘의 일차결합으로 실수 해를 쓴다. 또 임계감쇠의 \(te^{-\alpha t}\)는 중근일 때 두 번째 독립 해가 필요해서 나오며, 대입하면 실제로 방정식을 만족한다(연습 2).

예제 6.1.1

직렬 RLC에서 \(L = 10\) mH, \(C = 1\ \mu\text{F}\)이다. \(R = 50\ \Omega\), 200 Ω, 400 Ω 각각에서 감쇠 유형과 근을 구하여라.

풀이. \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\) rad/s이고 \(\alpha = R/(2L) = 50R\)이다. \(R = 50\)이면 \(\alpha = 2500\), \(\zeta = 0.25\)로 부족감쇠이고, \(\omega_d = \sqrt{10^8 - 6.25\times10^6} \approx 9682\) rad/s이므로 근은 \(-2500 \pm j9682\)이다. \(R = 200\)이면 \(\alpha = 10^4 = \omega_0\)로 임계감쇠이고 중근은 \(-10^4\)이다. \(R = 400\)이면 \(\alpha = 2\times10^4\), \(\zeta = 2\)로 과감쇠이고, 근은 \(-2\times10^4 \pm \sqrt{4\times10^8 - 10^8}\), 곧 −2679와 −37321이다.

임계 저항은 \(R = 2\sqrt{L/C} = 200\ \Omega\)이다. 그런데 과감쇠에서는 두 근 중 크기가 작은 쪽(−2679)이 응답을 지배하므로, 그림 1처럼 오히려 임계감쇠보다 느리게 끝난다.

6.1.3초기 조건으로 상수 정하기

예제 6.1.2

예제 6.1.1의 \(R = 50\ \Omega\) 회로에서 축전기가 \(v_C(0) = 10\) V, 인덕터 전류가 \(i(0) = 0\)이다. \(v_C(t)\)를 구하여라.

풀이. \(v_C = e^{-2500t}(B_1\cos9682t + B_2\sin9682t)\)에 \(t = 0\)을 넣으면 \(B_1 = 10\)이다. 둘째 조건은 \(i = C\,dv_C/dt\)이므로 \(dv_C/dt(0) = i(0)/C = 0\)이다. 미분해 \(t = 0\)을 넣으면 \(-2500B_1 + 9682B_2 = 0\)에서 \(B_2 \approx 2.58\)이다. 따라서 다음과 같다.

\[ v_C(t) = e^{-2500t}\big(10\cos9682t + 2.58\sin9682t\big)\ \text{V} \]

진동 주기 \(2\pi/\omega_d \approx 0.65\) ms마다 진폭이 \(e^{-2500\times0.00065} \approx 0.20\)배로 줄어든다. 첫 번째 골은 반 주기 뒤에 \(-10e^{-2500\times0.000324} \approx -4.4\) V로, 그림 1의 파란 곡선과 같다. 축전기와 인덕터가 에너지를 주고받는 동안 저항이 조금씩 열로 빼앗아 가는 모습이다.

흔한 실수둘째 초기 조건을 "아무 회로에서나 \(dv_C/dt(0) = 0\)"이라고 쓰면 틀린다. \(dv_C/dt(0) = i_C(0^+)/C\)이고, \(i_C(0^+)\)는 \(0^+\) 회로(5.1절)를 풀어 구한다. 연속인 것은 \(v_C\)와 \(i_L\)이지 그 도함수가 아니다.
마무리

RLC 회로는 \(\ddot x + 2\alpha\dot x + \omega_0^2x = 0\)을 따르며(직렬 \(\alpha = R/2L\), 병렬 \(\alpha = 1/2RC\), \(\omega_0 = 1/\sqrt{LC}\)), 특성방정식의 근이 감쇠비 \(\zeta = \alpha/\omega_0\)에 따라 두 실근, 중근, 켤레 복소근으로 갈리므로 응답도 과감쇠, 임계감쇠, \(\omega_d\)로 출렁이는 부족감쇠로 갈린다. 두 상수는 \(x(0)\)과 \(\dot x(0)\)으로 정하고, \(\dot x(0)\)은 \(i_C(0^+)/C\)나 \(v_L(0^+)/L\)에서 구한다.

6.1.4연습문제

기본

  1. 병렬 RLC, \(R = 1\ \text{k}\Omega\), \(L = 0.1\) H, \(C = 0.1\ \mu\text{F}\)의 \(\alpha\), \(\omega_0\), 감쇠 유형은?
    답

    \(\alpha = 1/(2RC) = 5000\), \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\)이다. \(\zeta = 0.5\)이므로 부족감쇠이다.

응용

  1. \(x = te^{-\alpha t}\)가 \(\alpha = \omega_0\)일 때 \(\ddot x + 2\alpha\dot x + \alpha^2x = 0\)을 만족함을 대입으로 확인하여라.
    답

    \(\dot x = (1 - \alpha t)e^{-\alpha t}\), \(\ddot x = (-2\alpha + \alpha^2t)e^{-\alpha t}\)이다. 더하면 \([-2\alpha + \alpha^2t + 2\alpha - 2\alpha^2t + \alpha^2t]e^{-\alpha t} = 0\)이다.

심화

  1. 부족감쇠 직렬 RLC에서 \(R \to 0\)이면 응답은 어떻게 되는가? 에너지 관점에서 설명하여라.
    답

    \(\alpha \to 0\), \(\omega_d \to \omega_0\)이므로 줄지 않는 진동 \(v_C = V_0\cos\omega_0t\)가 된다. 에너지가 \(\frac12Cv^2\)과 \(\frac12Li^2\) 사이를 오가며 합이 일정한 LC 진동이다(공통4의 LC 회로).
