연산증폭기 회로 설계

본문
이 절에서 배울 것
  • 요구 이득, 입력 저항, 출력 범위에서 회로 구조와 저항 값을 정한다.
  • 저항 값의 크기를 정하는 기준(전류, 잡음, 입력 바이어스 전류)을 안다.
  • \(v_o = av_1 + bv_2 + c\) 꼴의 선형 식을 연산증폭기로 만든다.
먼저 알아야 할 것
  • 기본 증폭기 다섯 가지 (4.1절).

4.2.1설계는 해석의 거꾸로

해석은 회로가 주어지면 출력을 구하는 일이고 답이 하나입니다. 설계는 원하는 동작이 주어지면 회로를 고르는 일이고 답이 여럿입니다. 그래서 설계에는 순서가 필요합니다.

  1. 구조 고르기: 부호(반전이 필요한가), 입력 수, 입력 저항 요구로 반전·비반전·가산·차동 중에서 고른다.
  2. 비 정하기: 이득 공식에서 저항 비를 정한다.
  3. 크기 정하기: 비를 유지하며 실제 값을 1 kΩ ~ 1 MΩ 범위에서 고른다.
  4. 점검: 출력이 전원 범위 안인가, 출력 전류가 연산증폭기 한계(수십 mA) 안인가, 표준 저항 값으로 오차가 얼마인가.

4.2.2저항 크기의 기준

같은 이득 10이라도 \(1\ \Omega/10\ \Omega\)과 \(1\ \text{M}\Omega/10\ \text{M}\Omega\)은 다릅니다.

너무 작으면: 되먹임 저항으로 흐르는 전류 \(v_o/R_f\)가 커져 연산증폭기 출력 전류 한계를 넘고, 앞단 회로에 큰 부하가 된다(반전 증폭기 입력 저항 = \(R_1\)).

너무 크면: 저항의 열 잡음이 커지고, 실제 연산증폭기의 작은 입력 전류(바이어스 전류, nA~pA)가 큰 저항에 흘러 출력에 오차 전압을 만들며, 주변의 기생 용량과 함께 대역폭이 줄어든다.

그래서 보통 수 kΩ ~ 수백 kΩ을 씁니다. 저항은 E12, E24 같은 표준 값(예: 1.0, 1.2, 1.5, 1.8, 2.2, 2.7, 3.3, 3.9, 4.7, 5.6, 6.8, 8.2 × 10ⁿ)으로만 팔리므로, 비를 표준 값의 조합으로 맞춥니다.

예제 4.2.1

마이크 출력(진폭 20 mV, 내부 저항 2 kΩ)을 진폭 2 V로 키우고 싶다. 부호는 상관없고 전원은 ±5 V이다. 회로를 설계하여라.

풀이. 이득 크기 100이 필요합니다. 반전 증폭기라면 마이크 내부 저항 2 kΩ이 \(R_1\)과 직렬로 더해지므로, \(R_1 = 10\ \text{k}\Omega\)이면 실효 입력 저항 12 kΩ, \(R_f = 1.2\ \text{M}\Omega\)이 필요해 너무 큽니다. 비반전 증폭기로 하면 입력 저항이 사실상 무한대라 내부 저항이 이득에 영향을 주지 않습니다. \(1 + R_f/R_1 = 100\) → \(R_f/R_1 = 99\). \(R_1 = 1\ \text{k}\Omega\), \(R_f = 100\ \text{k}\Omega\)(표준 값)이면 이득 101, 오차 1%. 출력 진폭 2.02 V는 ±5 V 전원의 출력 한계(약 ±3.5 V) 안입니다.

4.2.3선형 식 만들기

센서 신호를 ADC 입력 범위에 맞추려면 "키우고 옮기는" 일이 자주 필요합니다. 일반적인 목표는 \(v_o = av_1 + bv_2 + c\)입니다.

  • 계수가 모두 음수면 가산 증폭기 하나로 됩니다: \(R_f/R_k = |a|, |b|, \dots\), 상수 \(c\)는 고정 전압(예: −5 V 전원)을 저항을 거쳐 넣어 만듭니다.
  • 양수 계수가 있으면 반전 가산기 뒤에 이득 −1 반전기를 하나 더 달거나, 차동 증폭기를 씁니다.
예제 4.2.2

온도 센서 출력 \(v_s\)가 0 °C에서 0.5 V, 100 °C에서 1.5 V(10 mV/°C)이다. 이것을 0 ~ 3.3 V(0 ~ 100 °C)로 바꾸는 식을 세우고 회로를 설계하여라. ±5 V 전원을 쓸 수 있다.

풀이. 목표 \(v_o = 3.3\frac{v_s - 0.5}{1.0} = 3.3v_s - 1.65\). 계수 \(a = 3.3\)은 양수, 상수 −1.65 V. 1단: 반전 가산기 \(v_x = -(R_f/R_1)v_s - (R_f/R_2)(-5)\)로 \(v_x = -3.3v_s + 1.65\)를 만듭니다. \(R_f = 33\ \text{k}\Omega\), \(R_1 = 10\ \text{k}\Omega\)(3.3배), \(R_f/R_2 = 1.65/5 = 0.33\) → \(R_2 = 100\ \text{k}\Omega\). 2단: 이득 −1 반전기(10 kΩ, 10 kΩ)로 \(v_o = 3.3v_s - 1.65\). 검산: \(v_s = 0.5\)이면 \(1.65 - 1.65 = 0\), \(v_s = 1.5\)이면 \(4.95 - 1.65 = 3.3\) V. 1단 출력은 −3.3 ~ 0 V로 전원 범위 안입니다.

주의설계에서 가장 흔한 실수는 출력 범위 점검을 잊는 것입니다. 단일 전원(0 V와 +5 V)으로 동작하는 연산증폭기는 음의 출력을 낼 수 없어, 반전 증폭기를 그냥 쓰면 출력이 0 V에 붙어 버립니다. 이때는 입력에 직류 기준 전압을 더해 동작점을 전원 가운데로 옮깁니다.
요약
  1. 설계 순서: 구조 → 저항 비 → 저항 크기 → 출력 범위·전류·표준 값 점검.
  2. 입력 저항이 중요하면 비반전, 부호를 바꾸거나 여러 입력을 더하려면 반전 가산기.
  3. \(av_1 + bv_2 + c\)는 가산기(상수는 고정 전압 입력)와 반전기 조합으로 만든다.

4.2.4연습문제

기본

  1. 이득 −4.7, 입력 저항 22 kΩ인 반전 증폭기의 저항을 정하여라.
    답

    \(R_1 = 22\ \text{k}\Omega\), \(R_f = 103.4\ \text{k}\Omega\). 표준 값 100 kΩ이면 −4.55(오차 3%), 또는 E24의 110 kΩ과 비교.

응용

  1. \(v_o = -(2v_1 + 0.5v_2)\)를 만드는 가산기를 설계하여라(\(R_f = 20\ \text{k}\Omega\)).
    답

    \(R_1 = 10\ \text{k}\Omega\), \(R_2 = 40\ \text{k}\Omega\)(39 kΩ 표준이면 0.513배).

  2. \(v_o = 5(v_2 - v_1)\)를 차동 증폭기로 만들되, 각 입력에서 본 저항이 10 kΩ 이상이 되게 하여라.
    답

    \(R_1 = 10\ \text{k}\Omega\), \(R_2 = 50\ \text{k}\Omega\)(또는 47 kΩ + 3 kΩ). \(v_2\) 쪽 입력 저항은 \(R_1 + R_2 = 60\ \text{k}\Omega\), \(v_1\) 쪽은 \(v_2\)에 따라 달라지지만 \(v_2 = 0\)이면 10 kΩ.

심화

  1. 예제 4.2.2를 연산증폭기 하나로 만들 수 있는가? 차동 증폭기 꼴로 시도하여라.
    힌트

    \(v_o = \frac{R_2}{R_1}(v_2 - v_1)\)에서 \(v_2 = v_s\), \(v_1\)에 고정 전압을 넣으면?

    답

    \(R_2/R_1 = 3.3\), \(v_1 = 0.5\) V(기준 전압)이면 \(v_o = 3.3(v_s - 0.5)\). 0.5 V는 5 V를 분압해 만들되, 분압기의 테브난 저항이 \(R_1\)에 더해지므로 그만큼 \(R_1\)을 줄이거나 버퍼를 둔다.
