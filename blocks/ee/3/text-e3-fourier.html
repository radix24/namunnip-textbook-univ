비정현 주기 입력과 Fourier 급수 해석

본문

컴퓨터 클록은 구형파이고, 기타 소리도 사인파가 아니다. 그런데 7, 8단원의 페이저와 임피던스는 사인파 하나에만 쓸 수 있었다. 사인파가 아닌 주기 신호를 RC 필터에 넣으면 출력은 어떤 모양이 될까? 페이저를 쓸 길이 있을까?

먼저 알아야 할 것중첩(3.1절), 페이저 해석(7.2절), 평균 전력과 실효값(8.1절), Fourier 급수의 계수 공식(공통8 6.1절)을 쓴다. 같은 학기라면 아래에서 쓰는 만큼 다시 설명한다.

9.3.1주기 신호는 사인파들의 합

페이저와 주기 신호 사이에 다리를 놓는 것이 Fourier 급수이다. 주기가 \(T\)이고 기본 각주파수가 \(\omega_0 = 2\pi/T\)인 신호는 다음과 같이 쓸 수 있다.

\[ f(t) = a_0 + \sum_{n=1}^{\infty}\big(a_n\cos n\omega_0t + b_n\sin n\omega_0t\big) \]

계수는 \(a_0 = \frac1T\int_0^Tf\,dt\)(평균), \(a_n = \frac2T\int_0^Tf\cos n\omega_0t\,dt\), \(b_n = \frac2T\int_0^Tf\sin n\omega_0t\,dt\)이다. 이 공식은 서로 다른 \(n\)의 사인과 코사인을 곱해 한 주기 적분하면 0이 된다는 직교성에서 나온다. \(n\omega_0\) 성분은 \(n\)차 고조파라 한다.

예제 9.3.1 (구형파)

한 주기의 앞 절반은 \(+V\), 뒤 절반은 \(-V\)인 구형파의 Fourier 급수를 구하여라.

풀이. 평균이 0이므로 \(a_0 = 0\)이다. 또 원점에 대해 홀함수, 곧 \(t \to -t\)이면 부호가 바뀌는 함수이므로 코사인 항도 0이다. 사인 계수는 \(b_n = \frac2T\Big[\int_0^{T/2}V\sin n\omega_0t\,dt - \int_{T/2}^{T}V\sin n\omega_0t\,dt\Big] = \frac{2V}{n\pi}(1 - \cos n\pi)\)이므로, \(n\)이 짝수면 0이고 홀수면 \(\frac{4V}{n\pi}\)이다. 따라서 다음과 같다.

\[ f(t) = \frac{4V}{\pi}\Big(\sin\omega_0t + \frac13\sin3\omega_0t + \frac15\sin5\omega_0t + \cdots\Big) \]

고조파 진폭이 \(1/n\)로 천천히 줄어든다. 날카로운 모서리를 만들려면 높은 주파수가 많이 필요하다는 뜻이며, 그림 1에서 다섯 번째 고조파까지 더해도 모서리 근처가 출렁이는 것이 그 때문이다.

9.3.2고조파마다 페이저로 푼다

회로가 선형이면 중첩이 성립하므로, 각 고조파를 따로 넣어 정상상태 응답을 구하고 더하면 된다. 처음 질문의 답이 이것이다. 다만 고조파마다 주파수가 다르므로 임피던스를 고조파마다 다시 계산해야 한다. 순서는 이렇다. 입력을 Fourier 급수로 쓴 뒤, 직류 성분은 C를 개방, L을 단락으로 두고 푼다. \(n\)차 고조파는 \(\omega = n\omega_0\)에서 전달함수 \(H(jn\omega_0)\)를 구해 진폭을 \(|H|\)배하고 위상을 \(\angle H\)만큼 바꾼다. 끝으로 시간 함수로 바꾸어 모두 더하며, 페이저끼리 더하지 않는다.

예제 9.3.2

±1 V, 1 kHz 구형파를 차단 주파수 1 kHz인 RC 저역 통과 필터에 넣었다. 출력의 1차, 3차, 5차 고조파 진폭을 구하여라.

풀이. \(|H(f)| = 1/\sqrt{1 + (f/1\,\text{kHz})^2}\)이다. 1차는 입력 \(4/\pi = 1.273\)에 \(|H| = 0.707\)을 곱해 0.900 V, 위상 −45°이다. 3차는 입력 0.424에 \(|H| = 1/\sqrt{10} = 0.316\)을 곱해 0.134 V, −71.6°이다. 5차는 입력 0.255에 \(|H| = 0.196\)을 곱해 0.050 V, −78.7°이다. 그림 2처럼 높은 고조파가 많이 깎이므로 출력은 모서리가 둥근, 사인파에 가까운 모양이 된다.

9.3.3실효값과 평균 전력

서로 다른 주파수의 곱은 평균이 0이므로, 비정현 신호의 제곱 평균은 각 성분의 제곱 평균의 합이다. 평균 전력도 같다.

\[ V_\text{rms}^2 = a_0^2 + \sum_n\frac{a_n^2 + b_n^2}{2}, \qquad P = V_0I_0 + \sum_n\frac{V_nI_n}{2}\cos\theta_n \]

곧 평균 전력은 같은 주파수끼리만 만들어진다. 3.1절에서 전력은 중첩되지 않는다고 했지만, 주파수가 다른 성분끼리는 교차 항의 평균이 0이어서 예외적으로 더할 수 있다.

확인해 보자. 구형파 ±V의 실효값은 분명히 \(V\)이다. 급수로 계산하면 \(\sum_{n\ \text{홀수}}\frac{1}{2}\big(\frac{4V}{n\pi}\big)^2 = \frac{8V^2}{\pi^2}\sum\frac{1}{n^2} = \frac{8V^2}{\pi^2}\cdot\frac{\pi^2}{8} = V^2\)으로 같다. 여기서 \(1 + \frac19 + \frac1{25} + \cdots = \frac{\pi^2}{8}\)을 썼다.

흔한 실수고조파 페이저 \(\mathbf V_1\)과 \(\mathbf V_3\)을 더해 하나의 페이저로 만들면 안 된다. 주파수가 다르면 회전 속도가 달라서, 같은 순간의 화살표라는 페이저의 전제가 깨진다. 반드시 시간 함수로 바꾼 뒤 더한다.
마무리

주기 신호는 Fourier 급수로 직류와 고조파 사인파들의 합이 되므로, 선형 회로에서는 고조파마다 \(H(jn\omega_0)\)로 페이저 해석을 하고 시간 함수로 바꾸어 더하면 정상상태 응답을 얻는다. 구형파는 홀수 고조파 \(4V/(n\pi)\)로 이루어지며, 실효값의 제곱과 평균 전력은 서로 다른 주파수의 교차 항이 평균 0이어서 성분별로 더한다.

9.3.4연습문제

기본

  1. \(v(t) = 3 + 4\cos100t + 3\sin300t\) V의 실효값은?
    답

    \(\sqrt{9 + 8 + 4.5} = \sqrt{21.5} \approx 4.64\) V이다.

응용

  1. 위 전압을 2 Ω 저항과 1 mH 인덕터 직렬에 걸었다. 평균 전력은?
    답

    직류는 인덕터가 단락이라 \(9/2 = 4.5\) W이다. 100 rad/s에서는 \(|Z| = |2 + j0.1| \approx 2.0025\), 전류 진폭 1.998이므로 \(\frac12\times1.998^2\times2 \approx 3.99\) W이다. 300 rad/s에서는 \(|Z| = |2 + j0.3| = 2.022\), 전류 1.484이므로 \(\frac12\times1.484^2\times2 \approx 2.20\) W이다. 합은 약 10.7 W이다.

심화

  1. 0과 V를 오가는 듀티 50% 구형파의 Fourier 급수는 ±V/2 구형파와 어떤 관계인가? 직류 성분과 1차 고조파 진폭을 구하여라.
    답

    0/V 구형파는 \(V/2\)에 ±V/2 구형파를 더한 것이다. 직류는 \(V/2\), 1차 고조파 진폭은 \(\frac{4}{\pi}\cdot\frac V2 = \frac{2V}{\pi}\)이다.
