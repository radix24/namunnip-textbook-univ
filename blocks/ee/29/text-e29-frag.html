IP 단편화와 MTU

본문
이 절에서 배울 것
  • 링크 MTU보다 큰 데이터그램이 단편으로 나뉘는 방식을 안다.
  • 단편의 길이, 오프셋(8바이트 단위), 플래그를 계산한다.
  • 경로 MTU 탐색과 IPv6의 차이를 안다.
먼저 알아야 할 것
  • IP 주소 (4.1절).

4.3.1잘라 보내고 끝에서 붙이기

IPv4 라우터는 MTU보다 큰 데이터그램을 데이터 부분이 8바이트 배수가 되게 나누고, 오프셋(8바이트 단위)과 “더 있음” 플래그를 붙입니다. 재조립은 목적지에서만 합니다. 단편 하나만 잃어도 전체를 다시 보내야 해, 보통 경로 MTU 탐색으로 단편화를 피하고 IPv6는 라우터 단편화를 없앴습니다.

예제 4.3.1

총 4000바이트(헤더 20) 데이터그램을 MTU 1500 링크로 보낼 때 단편들의 데이터 길이와 오프셋은?

풀이. 데이터 3980바이트 → 1480, 1480, 1020바이트. 오프셋 0, 185, 370(1480/8 = 185), 플래그 1, 1, 0. 각 단편은 헤더 20바이트를 더해 1500, 1500, 1040바이트입니다.

흔한 오해(1) "오프셋은 바이트 단위": 8바이트 단위입니다. (2) "중간 라우터가 재조립한다": 목적지에서만 합니다.
요약
  1. 단편 데이터 = 8의 배수(마지막 제외).
  2. 오프셋 = 바이트/8, 마지막만 플래그 0.
  3. 예: 3980 → 1480, 1480, 1020; 0, 185, 370.
