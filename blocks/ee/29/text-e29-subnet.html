서브넷 주소 계산

본문
이 절에서 배울 것
  • CIDR 표기 a.b.c.d/n에서 네트워크 주소, 브로드캐스트 주소, 호스트 수를 계산한다.
  • 주어진 블록을 여러 서브넷으로 나눈다.
  • 최장 접두사 일치로 전달 경로를 고른다.
먼저 알아야 할 것
  • 2진수와 비트 연산 (전전4 1단원), IP 계층 (1.2절).

4.1.1계산

/n은 앞 n비트가 네트워크 부분이라는 뜻입니다. 호스트 비트 h = 32 − n, 쓸 수 있는 호스트 주소 \(2^h - 2\)(네트워크·브로드캐스트 제외). 네트워크 주소는 호스트 비트를 모두 0, 브로드캐스트는 모두 1로 한 것입니다.

예제 4.1.1

192.168.10.0/24를 같은 크기 서브넷 4개로 나눠라. 192.168.10.77이 속한 서브넷의 네트워크·브로드캐스트 주소는?

풀이. 2비트를 더 빌려 /26: .0, .64, .128, .192, 각 호스트 62개. 77 = 0100 1101(2진)에서 앞 2비트 01 → .64 서브넷, 브로드캐스트 .127.

라우터는 전달표에서 목적지와 가장 길게 일치하는 접두사의 항목을 고릅니다. 예: 10.0.0.0/8과 10.1.0.0/16이 모두 있으면 10.1.2.3은 /16 쪽으로 갑니다.

흔한 오해(1) "/26이면 호스트 64개": 네트워크·브로드캐스트를 빼 62개입니다. (2) "서브넷은 아무 경계에서 시작해도 된다": 블록 크기의 배수에서 시작해야 합니다.
요약
  1. /n: 호스트 2^{32−n} − 2개.
  2. 네트워크(호스트 비트 0), 브로드캐스트(모두 1).
  3. 예: .77/26 → .64 ~ .127. 최장 접두사 일치.
