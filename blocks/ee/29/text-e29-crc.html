CRC 오류 검출 계산

본문
이 절에서 배울 것
  • 생성 다항식으로 나눈 나머지를 CRC로 붙이는 방식을 안다.
  • 모듈로-2 나눗셈으로 CRC를 계산한다.
  • CRC가 검출하는 오류(버스트 길이 ≤ r 등)를 안다.
먼저 알아야 할 것
  • 링크 계층 (5.1절).

5.2.1나머지를 붙이기

데이터 D 뒤에 r개의 0을 붙여 r + 1비트 생성자 G로 모듈로-2(XOR) 나눗셈을 하고, 나머지 R을 붙여 보냅니다. 받는 쪽은 전체를 G로 나눠 나머지가 0이 아니면 오류로 판정합니다. 길이 r 이하의 버스트 오류는 모두 검출됩니다.

def rem(bits, gen):
    b = [int(x) for x in bits]; g = [int(x) for x in gen]
    for i in range(len(b) - len(g) + 1):
        if b[i]:
            for j in range(len(g)):
                b[i + j] ^= g[j]
    return "".join(map(str, b[-(len(g) - 1):]))
D, G = "101110", "1001"
R = rem(D + "000", G)
print("CRC:", R, "/ 보내는 비트:", D + R)
print("받은 쪽 나머지(오류 없음):", rem(D + R, G))
print("한 비트 오류(101010011) 나머지:", rem("101010011", G))

실행 결과(Python 3.12에서 실제 실행):

CRC: 011 / 보내는 비트: 101110011
받은 쪽 나머지(오류 없음): 000
한 비트 오류(101010011) 나머지: 100
예제 5.2.1

D = 101110, G = 1001(r = 3)의 CRC는? 한 비트가 바뀌면?

풀이. 실행 결과 R = 011, 보내는 비트 101110011. 오류 없으면 나머지 000, 한 비트가 바뀐 101010011은 나머지가 0이 아니라 검출됩니다. 이더넷은 32비트 CRC를 씁니다.

흔한 오해(1) "CRC는 오류를 고친다": 검출만 하고 재전송으로 해결합니다. (2) "CRC는 모든 오류를 잡는다": 생성자의 배수 꼴 오류는 놓칩니다(확률 매우 낮음).
요약
  1. D·2^r를 G로 나눈 나머지 R.
  2. 예: 101110, 1001 → 011.
  3. 버스트 ≤ r 모두 검출.
