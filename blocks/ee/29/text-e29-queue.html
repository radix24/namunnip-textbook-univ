큐잉 지연: M/M/1 모형

본문
이 절에서 배울 것
  • 트래픽 세기 ρ = λ/μ와 큐잉 지연의 관계를 안다.
  • M/M/1 평균 체류 시간 \(T = 1/(\mu - \lambda)\)를 계산한다.
  • Little 법칙 \(N = \lambda T\)를 쓴다.
먼저 알아야 할 것
  • 전송·전파·큐잉 지연 (1.1절).

1.4.1ρ가 1에 가까워지면

패킷이 평균 λ개/s로 무작위로 오고 링크가 μ개/s를 처리하면(M/M/1), 평균 체류 시간 \(T = 1/(\mu - \lambda)\)로 ρ → 1에서 급격히 커집니다. 평균 대기 패킷 수는 Little 법칙 \(N = \lambda T\)입니다.

예제 1.4.1

μ = 1000 패킷/s, λ = 800 패킷/s의 평균 체류 시간과 대기 패킷 수는? λ = 950이면?

풀이. ρ = 0.8: T = 5 ms, N = 4. ρ = 0.95: T = 20 ms, N = 19. 부하가 19% 늘었는데 지연은 4배가 되어, 링크를 90% 넘게 쓰지 않도록 여유를 둡니다.

흔한 오해(1) "부하에 비례해 지연이 는다": ρ → 1에서 폭발적으로 늘어납니다. (2) "ρ > 1이어도 큐가 언젠가 비워진다": 계속 쌓여 결국 버려집니다.
요약
  1. ρ = λ/μ, T = 1/(μ − λ).
  2. N = λT(Little).
  3. 예: 0.8 → 5 ms, 0.95 → 20 ms.

    답
