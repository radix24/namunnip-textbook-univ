웹 페이지 첫 접속 시간

DNS + HTTP

출발점

첫 접속은 DNS 조회가 HTTP 앞에 붙습니다(2.3절, 2.2절).

문제 해결 전략 · 합
  1. DNS 빈 캐시 92 ms(예제).
  2. 서버 RTT 20 ms, 지속 파이프라인 객체 10개.
  3. 60 ms(2.2절).

첫 접속과 두 번째 접속 시간은?

풀이

  1. 첫: 92 + 60 = 152 ms.
    합.
  2. 두 번째(DNS 캐시): 2 + 60 = 62 ms.
    캐시.
  3. 브라우저 DNS 미리 조회(prefetch)로 더 줄임.
    대책.

의미

DNS 지연은 작은 페이지 첫 접속에서 상당한 몫입니다.

검산

92 + 60 = 152.
