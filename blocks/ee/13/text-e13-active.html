2차 능동 필터 설계

본문
이 절에서 배울 것
  • 2차 저역 통과의 표준형 \(\omega_0^2/(s^2 + (\omega_0/Q)s + \omega_0^2)\)과 Q의 뜻을 안다.
  • Sallen-Key와 다중 궤환(MFB) 회로로 원하는 \(f_0\), Q를 만드는 부품값을 정한다.
  • 고차 필터를 2차 단의 직렬로 나누는 방법을 안다.
먼저 알아야 할 것
  • 필터 차수 (4.1절), Sallen-Key 실험 (전전9 5.1절).

4.2.1표준형

2차 저역 통과 \(H(s) = \frac{K\omega_0^2}{s^2 + (\omega_0/Q)s + \omega_0^2}\). Q = 0.707이면 버터워스, Q가 크면 \(f_0\) 근처에 봉우리. 고차 버터워스는 각 2차 단의 Q가 다른 단을 이어 만듭니다(4차: Q = 0.541과 1.307, 확인 필요: 표에서 확인).

4.2.2Sallen-Key(이득 1, 같은 R)

\(f_0 = \frac{1}{2\pi R\sqrt{C_1C_2}}\), \(Q = \frac12\sqrt{C_1/C_2}\)(\(C_1\)은 되먹임, \(C_2\)는 접지 쪽). Q가 축전기 비만으로 정해져 부품 오차에 덜 민감합니다.

예제 4.2.1

\(f_0\) = 2 kHz 버터워스(Q = 0.707) Sallen-Key를 C₂ = 10 nF로 설계하라.

풀이. \(C_1 = 4Q^2C_2 = 2C_2 = 20\) nF. \(\sqrt{C_1C_2} = 14.14\) nF, \(R = 1/(2\pi \times 2000 \times 14.14\text{ n}) \approx 5.63\) kΩ(표준값 5.6 kΩ이면 \(f_0\) ≈ 2.01 kHz). 연산증폭기의 이득-대역폭 곱은 \(f_0\)의 100배 이상(200 kHz 이상)으로 고릅니다.

다중 궤환(MFB) 회로는 반전 이득을 갖고 높은 Q를 만들기 쉬우며, 대역 통과 필터로 자주 씁니다.

흔한 오해(1) "Q가 큰 단을 앞에 둬야 한다": 봉우리 때문에 앞단에서 포화할 수 있어 보통 낮은 Q 단을 앞에 둡니다. (2) "부품값을 계산대로 고르면 끝": 표준값과 허용 오차로 \(f_0\), Q가 몇 % 달라지므로 민감도를 확인합니다.
요약
  1. 표준형 \(K\omega_0^2/(s^2 + (\omega_0/Q)s + \omega_0^2)\), 버터워스 Q = 0.707.
  2. Sallen-Key(같은 R, 이득 1): \(f_0 = 1/(2\pi R\sqrt{C_1C_2})\), \(Q = \frac12\sqrt{C_1/C_2}\).
  3. 고차 = 2차 단의 직렬, 낮은 Q 단을 앞에.

4.2.3연습문제

기본

  1. Q = 0.5 Sallen-Key의 C₁/C₂는?
    답

    1(같은 값).

응용

  1. C₁ = 47 nF, C₂ = 10 nF, R = 10 kΩ의 f₀와 Q는?
    답

    \(f_0 = 1/(2\pi \times 10^4 \times 21.7\text{ n}) \approx 734\) Hz, \(Q = 0.5\sqrt{4.7} \approx 1.08\).

심화

  1. 예제 필터에서 \(f_0\)에서의 이득과 위상은?
    답

    이득 Q = 0.707(−3 dB), 위상 −90°.
