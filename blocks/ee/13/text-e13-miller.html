Miller 정리와 입력 극점

본문

MOSFET의 게이트-드레인 용량 \(C_{gd}\)는 0.5 pF로 게이트-소스 용량 2 pF보다 작다. 그런데 공통 소스 증폭기의 고주파 특성은 오히려 이 작은 용량이 좌우한다고 한다. 어떻게 작은 축전기가 큰 축전기보다 더 큰 영향을 줄까? 그 효과를 손으로 어림하는 간단한 방법은 없을까?

먼저 알아야 할 것공통 소스 증폭기와 소신호 모델(전전8 4.1절), RC 극점(전전3 8.2절)을 쓴다.

1.1.1Miller 정리

전압 이득이 \(V_2 = AV_1\)인 두 마디 사이에 임피던스 Z가 걸려 있다고 하자. Z를 지나는 전류는 \((V_1 - V_2)/Z = V_1(1 - A)/Z\)이므로, 입력에서 보면 접지로 \(Z/(1 - A)\)를 단 것과 같다. 출력 쪽도 같은 방법으로 \(Z/(1 - 1/A)\)이다. 이것이 Miller 정리로, 다리처럼 걸친 소자를 두 개의 접지 소자로 바꿔 준다. 처음 질문의 둘째 답이 이것이다.

축전기 C에 적용하면 입력에서 \(C(1 - A)\)로 보인다. 그래서 반전 증폭기(A = −|A|)에서는 \(C(1 + |A|)\)가 되어, 작은 \(C_{gd}\)가 이득만큼 커진다. 이를 Miller 효과라 하며, 처음 질문의 첫째 답이 이것이다(그림 1). 입력 전압이 조금 변해도 축전기 양 끝의 전압 차가 \((1 + |A|)\)배로 크게 변해, 그만큼 큰 충전 전류가 흐르기 때문이다.

1.1.2입력 극점

공통 소스 증폭기의 입력 마디에는 \(C_{gs}\)와 Miller 용량이 병렬로 보인다. 그래서 입력 용량과 입력 극점은 다음과 같다.

\[ C_{in} = C_{gs} + C_{gd}(1 + g_mR_L'), \qquad f_{p,in} = \frac{1}{2\pi R_{sig}C_{in}}. \]
예제 1.1.1

\(g_m\) = 4 mA/V, \(R_L'\) = 5 kΩ, \(C_{gs}\) = 2 pF, \(C_{gd}\) = 0.5 pF, \(R_{sig}\) = 10 kΩ. 중간 대역 이득, \(C_{in}\), 입력 극점은?

풀이. 이득은 −20이다. \(C_{in} = 2 + 0.5 \times 21 = 12.5\) pF이므로 \(C_{gd}\)의 몫(10.5 pF)이 \(C_{gs}\)보다 5배 크다. 극점은 \(1/(2\pi \times 10\text{ k} \times 12.5\text{ p}) \approx 1.27\) MHz이다. 정확한 계산(1.2절)의 −3 dB 1.21 MHz와 약 5% 차이이다.

그러므로 공통 소스 증폭기의 대역폭을 넓히려면 \(C_{gd}\)가 받는 이득을 줄여야 한다. 신호원 저항 \(R_{sig}\)를 낮추거나, 1.3절의 캐스코드처럼 \(C_{gd}\) 양 끝의 전압 이득을 작게 만드는 구조를 쓴다.

흔한 오해Miller 정리로 구한 출력 극점도 정확하다고 여기기 쉽다. 하지만 이득 A를 중간 대역 값으로 고정한 근사여서, 고주파에서 A가 변하는 효과(극점 분리)를 놓친다. 그래서 입력 극점, 곧 주극점 어림에만 믿을 만하다. \(C_{gd}\)는 작으니 무시해도 된다는 생각도 틀리며, 이득이 크면 입력 용량을 지배한다.
마무리

Miller 정리는 다리로 걸친 Z를 입력의 \(Z/(1 - A)\)와 출력의 \(Z/(1 - 1/A)\)로 바꾼다. 반전 증폭기에서는 \(C_{gd}\)가 입력에서 \((1 + |A|)\)배로 보인다. 공통 소스 증폭기의 입력 극점은 \(f_{p,in} = 1/(2\pi R_{sig}[C_{gs} + C_{gd}(1 + g_mR_L')])\)이다.

1.1.3연습문제

기본

  1. 이득 −50, \(C_{gd}\) = 0.2 pF의 Miller 입력 용량은?
    답

    10.2 pF이다.

응용

  1. 예제에서 \(R_{sig}\)를 1 kΩ으로 줄이면 입력 극점은?
    답

    12.7 MHz로 10배가 된다.

심화

  1. 비반전 이득 +0.9(소스 폴로어)에서 \(C_{gs}\)는 입력에서 몇 배로 보이는가?
    답

    \(C_{gs}(1 - 0.9) = 0.1C_{gs}\)이다. 폴로어의 입력 용량이 작은 이유가 이것이다.
