Miller 정리와 입력 극점

본문
이 절에서 배울 것
  • 입출력 사이에 걸친 임피던스를 입력 쪽과 출력 쪽 접지 임피던스로 나누는 Miller 정리를 안다.
  • 반전 증폭기의 \(C_{gd}\)가 입력에서 \((1 + |A|)\)배로 보이는 이유를 설명한다.
  • Miller 입력 용량으로 입력 극점을 어림한다.
먼저 알아야 할 것
  • 공통 소스 증폭기와 소신호 모델 (전전8 4.1절), RC 극점 (전전3 8.2절).

1.1.1Miller 정리

전압 이득 \(V_2 = AV_1\)인 두 마디 사이에 임피던스 Z가 걸려 있으면, Z를 지나는 전류 \((V_1 - V_2)/Z = V_1(1 - A)/Z\)는 입력에서 접지로 \(Z/(1 - A)\)를 단 것과 같습니다. 출력 쪽도 같은 방법으로 \(Z/(1 - 1/A)\)입니다.

축전기 C에 적용하면 입력에서 \(C(1 - A)\)로 보입니다. 반전 증폭기(A = −|A|)이면 \(C(1 + |A|)\): 작은 \(C_{gd}\)가 이득만큼 커집니다(Miller 효과).

1.1.2입력 극점

공통 소스 증폭기의 입력 마디에는 \(C_{gs}\)와 Miller 용량이 병렬로 보여

\[ C_{in} = C_{gs} + C_{gd}(1 + g_mR_L'), \qquad f_{p,in} = \frac{1}{2\pi R_{sig}C_{in}}. \]
예제 1.1.1

\(g_m\) = 4 mA/V, \(R_L'\) = 5 kΩ, \(C_{gs}\) = 2 pF, \(C_{gd}\) = 0.5 pF, \(R_{sig}\) = 10 kΩ. 중간 대역 이득, \(C_{in}\), 입력 극점은?

풀이. 이득 −20. \(C_{in} = 2 + 0.5 \times 21 = 12.5\) pF로 \(C_{gd}\)의 몫(10.5 pF)이 \(C_{gs}\)보다 5배 큽니다. 극점 \(1/(2\pi \times 10\text{ k} \times 12.5\text{ p}) \approx 1.27\) MHz. 정확한 계산(1.2절)의 −3 dB 1.21 MHz와 약 5% 차이입니다.

흔한 오해(1) "Miller 정리로 구한 출력 극점도 정확하다": 이득 A를 중간 대역 값으로 고정한 근사라, 고주파에서 A가 변하는 효과(극점 분리)를 놓칩니다. 입력 극점(주극점) 어림에만 믿을 만합니다. (2) "C_gd는 작으니 무시해도 된다": 이득이 크면 입력 용량을 지배합니다.
요약
  1. Miller: Z → 입력 \(Z/(1 - A)\), 출력 \(Z/(1 - 1/A)\).
  2. 반전 증폭기: \(C_{gd}\)가 입력에서 \((1 + |A|)\)배.
  3. \(f_{p,in} = 1/(2\pi R_{sig}[C_{gs} + C_{gd}(1 + g_mR_L')])\).

1.1.3연습문제

기본

  1. 이득 −50, \(C_{gd}\) = 0.2 pF의 Miller 입력 용량은?
    답

    10.2 pF.

응용

  1. 예제에서 \(R_{sig}\)를 1 kΩ으로 줄이면 입력 극점은?
    답

    12.7 MHz(10배).

심화

  1. 비반전 이득 +0.9(소스 폴로어)에서 \(C_{gs}\)는 입력에서 몇 배로 보이는가?
    답

    \(C_{gs}(1 - 0.9) = 0.1C_{gs}\). 폴로어 입력 용량이 작은 이유입니다.
