트랜스임피던스 증폭기의 입력 저항

예제 · 병렬-병렬 궤환

먼저 예측

포토다이오드 전류를 전압으로 바꾸는 증폭기의 입력은 왜 거의 0 Ω처럼 보일까요?

생각해 본 뒤 열기

출력 전압을 저항으로 입력 마디에 되돌려 전류로 혼합(병렬-병렬)하므로 입력 저항이 (1 + Aβ)배 줄어듭니다.

문제

반전 연산증폭기(열린 루프 이득 A = 10⁴, 입력 저항 무한, 출력 저항 100 Ω)에 궤환 저항 R_f = 100 kΩ을 걸어 전류 입력 트랜스임피던스 증폭기를 만들었다. (가) 이상적 트랜스임피던스, (나) 입력 마디에서 본 저항, (다) 출력 저항, (라) 입력 1 μA의 출력.

전략

  1. 병렬-병렬: 입력·출력 저항 모두 ÷(1 + Aβ).
  2. β = −1/R_f(전류/전압), Aβ의 크기는 A.
  3. 입력 저항 ≈ R_f/(1 + A).

풀이

  1. (가) \(V_o/I_{in} = -R_f = -100\) kΩ. 이상적
  2. (나) \(R_f/(1 + A) \approx 100\text{k}/10001 \approx 10\) Ω. 입력 저항 감소
  3. (다) 출력 저항 100/(1 + A) ≈ 0.01 Ω(대략). 출력 저항 감소
  4. (라) −0.1 V. 출력

의미

입력 저항이 작아 포토다이오드 양 끝 전압이 거의 일정하게 유지되므로, 다이오드 정전 용량이 충방전되지 않아 응답이 빨라집니다. 광 수신기와 전류 측정의 기본 구조입니다.

검산

1 μA × 100 kΩ = 0.1 V, 부호 반전. 입력 마디 전압은 0.1 V/10⁴ = 10 μV로 거의 0(가상 접지).

이해 확인

A가 10³이면 입력 저항은?

답

약 100 Ω.
