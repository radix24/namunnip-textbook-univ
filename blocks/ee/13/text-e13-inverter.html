CMOS 인버터의 전달 특성

본문

CMOS 인버터는 트랜지스터 두 개로 된 가장 단순한 논리 게이트이다. 입력을 0 V에서 1.8 V로 천천히 올리면 출력은 어디에서, 얼마나 가파르게 뒤집힐까? 그 뒤집히는 점은 무엇이 정할까? 그리고 가만히 있을 때 전력을 거의 쓰지 않는 CMOS 칩이 왜 그토록 뜨거워질까?

먼저 알아야 할 것MOSFET 동작 영역(전전8 2.1절), 디지털 논리(전전4 2.1절)를 쓴다.

6.3.1전달 특성

입력이 0 V이면 PMOS가 켜지고 NMOS가 꺼져 출력이 \(V_{DD}\)이다. 입력이 \(V_{DD}\)이면 반대로 출력이 0 V이다. 그런데 중간에서 두 트랜지스터가 모두 포화하는 좁은 구간이 있어, 출력이 가파르게 떨어진다(그림 1). 이 구간의 기울기가 이득이며, 기울기가 클수록 잡음 여유가 크다. 처음 질문의 첫째 답이 이것이다.

입력과 출력이 같아지는 점을 스위칭 문턱 \(V_M\)이라 한다. 이 점에서는 두 트랜지스터가 모두 포화이고 전류가 같으므로 \(\frac{k_n}{2}(V_M - V_{tn})^2 = \frac{k_p}{2}(V_{DD} - V_M - |V_{tp}|)^2\)이다. 그래서 \(r = \sqrt{k_n/k_p}\)라 하면 다음을 얻으며, 처음 질문의 둘째 답이 이것이다.

\[ V_M = \frac{V_{DD} - |V_{tp}| + rV_{tn}}{1 + r}. \]
예제 6.3.1

\(V_{DD}\) = 1.8 V, \(V_{tn} = |V_{tp}|\) = 0.4 V이다. (가) \(k_n = k_p\), (나) \(k_n = 2k_p\)일 때 \(V_M\).

풀이. (가) r = 1이므로 \(V_M = (1.8 - 0.4 + 0.4)/2 = 0.9\) V로 가운데이다. (나) r = 1.414이므로 \(V_M = (1.4 + 0.566)/2.414 = 0.814\) V이다. 즉 NMOS가 강하면 문턱이 아래로 내려간다. 정공 이동도가 전자보다 작아(약 1/2~1/3, 확인 필요), 대칭으로 만들려면 PMOS 폭을 NMOS의 2~3배로 한다.

6.3.2전력

정지 상태에서는 한쪽 트랜지스터가 꺼져 전류가 흐르지 않으므로, 누설을 빼면 정적 전력이 거의 0이다. 하지만 출력이 바뀔 때마다 부하 용량을 충방전하므로 동적 전력 \(P = \alpha CV_{DD}^2f\)를 쓴다(α는 활동 비율). 수십억 개의 게이트가 GHz로 바뀌면 이 전력이 수십 W에 이르며, 처음 질문의 셋째 답이 이것이다. 그래서 전압을 낮추면 제곱으로 전력이 줄어, 칩의 공급 전압이 세대마다 낮아졌다.

흔한 오해CMOS가 전력을 안 쓴다고 여기기 쉽지만, 스위칭 때와 누설로 전력을 쓰며 고성능 칩의 큰 전력 대부분이 동적 전력이다. \(V_M\)이 언제나 \(V_{DD}/2\)라는 생각도 틀리며, 두 트랜지스터의 세기 비로 정해진다.
마무리

CMOS 인버터는 입력이 낮으면 \(V_{DD}\), 높으면 0을 내며 중간에서 가파르게 뒤집힌다. 스위칭 문턱은 \(V_M = (V_{DD} - |V_{tp}| + rV_{tn})/(1 + r)\), \(r = \sqrt{k_n/k_p}\)이다. 정적 전력은 거의 0이고, 동적 전력은 \(\alpha CV_{DD}^2f\)이다.

6.3.3연습문제

기본

  1. C = 10 fF, V_DD = 1 V, f = 1 GHz, α = 0.1이면 동적 전력은?
    답

    1 μW이다.

응용

  1. V_DD를 1.2 V에서 0.9 V로 낮추면 동적 전력은 몇 배인가?
    답

    \((0.9/1.2)^2 = 0.5625\)배가 된다.

심화

  1. 예제 (나)에서 V_M을 0.9 V로 되돌리려면 k_p를 얼마로 해야 하는가?
    답

    \(k_p = k_n\)(r = 1)이어야 하므로 PMOS 폭을 두 배로 키운다.
