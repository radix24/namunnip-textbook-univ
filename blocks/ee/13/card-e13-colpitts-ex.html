FM 대역 국부 발진기

C 역산

출발점

원하는 주파수에서 직렬 C를 구합니다(5.2절).

문제 해결 전략 · f → C_s → C₁, C₂
  1. C_s = 1/((2πf)²L).
  2. C₁ = C₂면 각 2C_s.
  3. 기생 정전 용량을 고려한다.

L = 0.1 μH로 100 MHz를 만들려면 C₁ = C₂는? 기생 5 pF가 C₂에 병렬로 붙으면?

풀이

  1. C_s = 1/((2π × 10⁸)² × 10⁻⁷) = 25.3 pF → C₁ = C₂ = 50.7 pF.
    직렬 절반.
  2. C₂ = 55.7 pF면 C_s = 26.5 pF → f = 97.7 MHz.
    기생 효과.
  3. 트리머로 맞춤.
    실무.

의미

고주파에서는 기생 정전 용량이 주파수를 크게 바꿔 조정 소자가 필요합니다.

검산

50.7 × 55.7/106.4 = 26.5 pF.
