인버터를 대칭으로 만드는 PMOS 폭

예제 · 스위칭 문턱 맞추기

먼저 예측

NMOS와 PMOS를 같은 크기로 만들면 인버터의 스위칭 문턱이 가운데일까?

생각해 본 뒤 열기

아니다. 정공 이동도가 작아 PMOS가 약하므로 문턱이 아래로 내려간다.

문제

V_DD = 1.8 V, V_tn = |V_tp| = 0.4 V, 공정 상수 μ_nC_ox = 300 μA/V², μ_pC_ox = 100 μA/V². NMOS W/L = 1. (가) PMOS W/L = 1일 때 V_M, (나) V_M = 0.9 V가 되는 PMOS W/L.

전략

  1. r = √(k_n/k_p).
  2. V_M = (V_DD − |V_tp| + rV_tn)/(1 + r).
  3. 대칭은 k_n = k_p.

풀이

  1. (가) k_n = 300, k_p = 100 μA/V², r = √3 = 1.732. V_M = (1.4 + 0.693)/2.732 = 0.766 V. 약한 PMOS
  2. (나) k_p = k_n 필요: PMOS W/L = 3. 폭 3배

의미

PMOS를 3배로 키우면 면적과 입력 용량이 늘어 속도·전력에 영향을 준다. 실제 설계는 지연 시간(상승·하강의 균형)과 면적을 함께 보며 1.5~3배 사이에서 고른다.

검산

r = 1이면 V_M = (1.4 + 0.4)/2 = 0.9 V. 일치한다.

이해 확인

PMOS W/L = 2이면 V_M은?

답

k_p = 200, r = √1.5 = 1.225, V_M = (1.4 + 0.49)/2.225 ≈ 0.849 V.
