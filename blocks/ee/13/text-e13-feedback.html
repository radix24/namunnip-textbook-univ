궤환 구조와 폐루프 특성

본문
이 절에서 배울 것
  • 음의 궤환의 폐루프 이득 \(A_f = A/(1 + A\beta)\)와 감도 감소를 안다.
  • 네 가지 궤환 구조(직렬-병렬 등)를 출력 감지와 입력 혼합 방식으로 판별한다.
  • 궤환이 입출력 저항을 \((1 + A\beta)\)배 바꾸는 방향을 정한다.
먼저 알아야 할 것
  • 연산증폭기 회로 (전전3 4.1절), 증폭기 입출력 저항 (전전8 4.1절).

2.1.1폐루프 이득

출력의 일부 βx_o를 입력에서 빼면 \(x_o = A(x_s - \beta x_o)\), 곧

\[ A_f = \frac{A}{1 + A\beta} \approx \frac1\beta \quad (A\beta \gg 1). \]

루프 이득 Aβ가 크면 폐루프 이득은 정밀한 수동 소자(β)로만 정해지고, 트랜지스터의 A가 변해도 \(\frac{dA_f}{A_f} = \frac{1}{1 + A\beta}\frac{dA}{A}\)로 둔해집니다. 대역폭도 \((1 + A\beta)\)배 넓어지고(1극점 증폭기), 비선형 왜곡도 줄어듭니다. 대가는 이득 감소입니다.

2.1.2네 구조와 저항

구조(입력 혼합–출력 감지)안정화하는 이득입력 저항출력 저항
직렬–병렬(전압 증폭기)전압/전압× (1 + Aβ)÷ (1 + Aβ)
병렬–직렬(전류 증폭기)전류/전류÷×
직렬–직렬(트랜스컨덕턴스)전류/전압××
병렬–병렬(트랜스임피던스)전압/전류÷÷

규칙: 입력에서 직렬(전압으로 혼합)이면 입력 저항 증가, 병렬(전류로 혼합)이면 감소. 출력에서 전압을 감지(병렬)하면 출력 저항 감소, 전류를 감지(직렬)하면 증가.

예제 2.1.1

연산증폭기(A = 10⁴, 입력 저항 1 MΩ, 출력 저항 100 Ω)로 비반전 증폭기, β = 0.1. 폐루프 이득, 입력·출력 저항, A가 20% 줄 때 \(A_f\) 변화는?

풀이. 직렬–병렬. \(1 + A\beta = 1001\). \(A_f = 10^4/1001 = 9.990\). 입력 저항 약 1 GΩ, 출력 저항 약 0.1 Ω. A가 8000이 되면 \(A_f = 8000/801 = 9.988\)로 0.02% 변화(A는 20%).

흔한 오해(1) "궤환은 이득을 키운다": 음의 궤환은 이득을 줄이는 대신 정밀도, 대역폭, 선형성, 저항 특성을 얻습니다. (2) "모든 궤환은 입력 저항을 키운다": 혼합 방식에 따라 반대입니다(반전 증폭기의 가상 접지는 병렬 혼합으로 입력 저항이 매우 작아진 결과).
요약
  1. \(A_f = A/(1 + A\beta) \approx 1/\beta\). 감도 \(1/(1 + A\beta)\)배.
  2. 직렬 혼합 → \(R_{in}\) 증가, 병렬 혼합 → 감소.
  3. 전압 감지 → \(R_{out}\) 감소, 전류 감지 → 증가.

2.1.3연습문제

기본

  1. A = 1000, β = 0.01이면 \(A_f\)는?
    답

    1000/11 ≈ 90.9.

응용

  1. A가 ±10% 변할 때 A_f를 ±0.1% 안으로 하려면 Aβ는?
    답

    \(1 + A\beta \ge 100\), Aβ ≈ 99 이상.

심화

  1. 반전 증폭기의 입력(가상 접지 마디)에서 본 저항이 작은 이유를 궤환 구조로 설명하라.
    답

    출력 전압을 저항으로 되돌려 입력 마디에 전류로 혼합(병렬–병렬)하므로, 그 마디의 저항이 \((1 + A\beta)\)배 줄어 거의 0이 됩니다.
