C_gd 하나가 대역폭을 정한다

탐구 · Miller 근사와 정확한 응답

질문

게이트-드레인 사이의 작은 축전기 0.5 pF가 왜 대역폭을 크게 줄일까요? Miller 근사는 얼마나 맞을까요?

준비

공통 소스 증폭기(\(g_m\) = 4 mA/V, \(R_L'\) = 5 kΩ, \(C_{gs}\) = 2 pF, \(C_L\) = 1 pF)의 정확한 2극점 전달 함수(파랑)와 Miller 입력 극점 하나로 근사한 응답(주황 점선)을 Bode 크기로 비교합니다(1.1절, 1.2절).

해 보기와 설명

  1. 처음 화면Miller 입력 용량 12.5 pF, 극점 1.273 MHz, 정확한 −3 dB 1.213 MHz. 둘째 극점 119 MHz로 Miller식 출력 극점(21.2 MHz)보다 훨씬 높습니다(예제 1.2.1).
  2. C_gd 줄이기C_gd를 0.1 pF로 줄이면 입력 용량이 4.1 pF로 줄어 대역이 약 3배 넓어집니다. 캐스코드(1.3절)가 하는 일입니다.
  3. R_sig 줄이기R_sig를 1 kΩ으로 줄이면 입력 극점이 10배 높아져, 출력 쪽 극점이 대역을 정하기 시작합니다.
  4. 영점고주파 끝(수 GHz)에서 크기가 다시 평평해지는 것은 우반면 영점 \(g_m/C_{gd}\) 때문입니다.

연결과 적용

광대역 증폭기(광 수신기의 트랜스임피던스 증폭기, RF 저잡음 증폭기)는 Miller 효과를 줄이려 캐스코드나 차동 구조를 쓰고, 신호원 저항을 작게 합니다.

흔한 오해

  • "C_gd는 C_gs보다 작으니 무시해도 된다." 이득 배만큼 커져 입력 용량을 지배합니다.
  • "Miller 근사로 모든 극점을 구할 수 있다." 주극점만 잘 맞고, 둘째 극점은 극점 분리로 크게 달라집니다.
