공통 소스 증폭기의 고역 차단 주파수

본문
이 절에서 배울 것
  • 공통 소스 증폭기의 고주파 등가 회로에서 정확한 전달 함수를 구한다.
  • 분모 계수 \(b_1\)로 주극점을 어림하는 방법(개방 시정수의 합)을 쓴다.
  • Miller 근사와 정확한 해의 차이(극점 분리, 우반면 영점)를 안다.
먼저 알아야 할 것
  • Miller 정리 (1.1절), 2차 다항식의 근.

1.2.1정확한 전달 함수

입력 마디와 출력 마디에 KCL을 쓰면(신호원 \(R_{sig}\), 부하 \(R_L'\), \(C_{gs}\), \(C_{gd}\), \(C_L\))

\[ \frac{V_o}{V_{sig}} = \frac{-g_mR_L'(1 - sC_{gd}/g_m)}{1 + b_1s + b_2s^2}, \quad b_1 = R_{sig}[C_{gs} + C_{gd}(1 + g_mR_L')] + R_L'(C_L + C_{gd}). \]

\(b_2 = R_{sig}R_L'(C_{gs}C_{gd} + C_{gs}C_L + C_{gd}C_L)\). 두 극점이 멀리 떨어져 있으면 주극점은 \(\omega_{p1} \approx 1/b_1\)입니다. \(b_1\)은 각 축전기마다 다른 축전기를 떼고 본 저항과의 곱(개방 시정수)을 더한 것과 같아, 큰 회로에서도 대역폭을 빨리 어림하는 데 씁니다.

예제 1.2.1

1.1절 예제의 값과 \(C_L\) = 1 pF로 \(b_1\), 주극점 어림, 정확한 두 극점과 영점을 구하라.

풀이. \(b_1 = 10\text{k} \times 12.5\text{p} + 5\text{k} \times 1.5\text{p} = 132.5\) ns → \(1/(2\pi b_1) = 1.20\) MHz. 정확한 극점 1.213 MHz와 119 MHz(−3 dB 1.213 MHz). Miller로 어림한 출력 극점 \(1/(2\pi R_L'(C_L + C_{gd})) = 21\) MHz보다 둘째 극점이 훨씬 높은데, \(C_{gd}\)가 두 극점을 서로 밀어내기 때문입니다(극점 분리, 2.3절의 보상 원리). 영점 \(g_m/(2\pi C_{gd}) = 1.27\) GHz는 우반면이라 위상을 더 늦춥니다.

흔한 오해(1) "출력 극점은 R_L'와 C_L만으로 정해진다": C_gd를 통한 결합으로 크게 달라집니다. (2) "−3 dB 주파수는 언제나 가장 낮은 극점이다": 두 극점이 가까우면 더 낮아집니다(같은 두 극점이면 0.64배).
요약
  1. 정확한 2극점 식, \(b_1\) = 개방 시정수의 합.
  2. 주극점 ≈ \(1/(2\pi b_1)\). 예제 1.20 MHz(정확 1.21 MHz).
  3. 극점 분리로 둘째 극점이 높아지고, 우반면 영점 \(g_m/C_{gd}\).

1.2.3연습문제

기본

  1. \(b_1\) = 50 ns이면 주극점 어림은?
    답

    약 3.18 MHz.

응용

  1. 예제에서 \(C_L\)을 10 pF로 키우면 \(b_1\)과 주극점 어림은?
    답

    \(b_1 = 125 + 52.5 = 177.5\) ns, 약 0.90 MHz.

심화

  1. 두 극점이 같은 주파수 \(f_p\)일 때 −3 dB 주파수는?
    답

    \((1 + (f/f_p)^2) = \sqrt2\)에서 \(f = f_p\sqrt{\sqrt2 - 1} \approx 0.644f_p\).
