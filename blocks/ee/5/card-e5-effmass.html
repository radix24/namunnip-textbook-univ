코사인 띠의 유효 질량

예제 · E-k 곡선의 곡률에서 m*

먼저 예측

띠의 바닥과 꼭대기에서 유효 질량의 부호는 어떻게 다를까요?

생각해 본 뒤 열기

바닥은 위로 볼록(곡률 양수, m* > 0), 꼭대기는 아래로 볼록(곡률 음수, m* < 0)입니다. 꼭대기의 빈자리를 양의 질량을 가진 정공으로 다룹니다.

문제

원자 간격 a = 0.5 nm인 1차원 결정에서 띠가 \(E(k) = E_0 - 2t\cos(ka)\), t = 1 eV이다. (가) 띠 폭, (나) 띠 바닥 k = 0의 유효 질량, (다) 꼭대기 \(k = \pi/a\)의 유효 질량, (라) \(k = \pi/2a\)에서 일어나는 일을 구하여라.

전략

  1. \(m^* = \hbar^2/(d^2E/dk^2)\)(3.3절).
  2. \(d^2E/dk^2 = 2ta^2\cos(ka)\).
  3. k = 0과 \(\pi/a\)에서 cos가 ±1.

풀이

  1. 띠 폭: \(E\)는 \(E_0 - 2t\)부터 \(E_0 + 2t\)까지, 4t = 4 eV. cos의 범위
  2. k = 0: \(m^* = \hbar^2/(2ta^2) = (1.055\times10^{-34})^2/(2 \times 1.602\times10^{-19} \times 2.5\times10^{-19}) = 1.39\times10^{-31}\) kg = \(0.152m_0\). 곡률 \(2ta^2\)
  3. \(k = \pi/a\): 곡률 \(-2ta^2\), \(m^* = -0.152m_0\). 이 근처의 빈 상태를 \(+0.152m_0\)인 정공으로 다룬다. cos π = −1
  4. \(k = \pi/2a\): 곡률 0, \(m^*\)가 무한대로 발산. 포물선 근사가 의미를 잃는 곳이다. cos(π/2) = 0

의미

띠가 넓을수록(t가 클수록, 이웃 원자와 겹침이 클수록) 유효 질량이 작아집니다. 원자 궤도가 많이 겹치는 s 궤도 띠는 가볍고, 겹침이 작은 d 띠는 무겁습니다. 결정 방향마다 원자 간격과 겹침이 달라 유효 질량이 방향에 따라 다른 이유도 같습니다.

검산

바닥 근처에서 \(E \approx E_0 - 2t + ta^2k^2\)이므로 \(\hbar^2k^2/2m^* = ta^2k^2\), \(m^* = \hbar^2/2ta^2\). 같은 결과입니다.

이해 확인

t를 0.25 eV로 줄이면(겹침이 작은 띠) 바닥의 유효 질량은?

답

t에 반비례해 4배, \(0.61m_0\). 띠 폭도 1 eV로 줄어듭니다.
