도핑 농도와 Fermi 준위

탐구 · 띠 그림에서 E_F가 움직인다

질문

도너를 10배 더 넣으면 Fermi 준위는 얼마나 올라갈까요? 같은 n형 Si를 데우면 Fermi 준위는 어디로 갈까요?

준비

Si에 도너(또는 억셉터)를 넣고 전하 중성과 \(np = n_i^2\)을 함께 풀어 \(n = N/2 + \sqrt{N^2/4 + n_i^2}\)(n형)을 구하고, \(E_F - E_i = kT\ln(n/n_i)\)(3.1절 MB 근사)로 띠 그림에 \(E_F\)를 그립니다. 불순물은 모두 이온화되었다고 가정하고, \(n_i(T)\)는 진성 운반자 탐구와 같은 모형입니다.

해 보기와 설명

  1. 예제 확인처음 화면(n형 \(10^{16}\), 300 K): \(n = 10^{16}\), \(p = 10^4\), \(E_F - E_i = 0.357\) eV, \(E_c - E_F \approx 0.203\) eV(예제 4.1.1).
  2. 농도 올리기\(10^{18}\)이면 0.476 eV, \(E_c - E_F = 0.084\) eV. 10배마다 \(kT\ln10 = 0.060\) eV씩 오릅니다. \(10^{19}\)에서는 \(E_c - E_F = 0.024\) eV로 3kT 안에 들어와 축퇴 경고가 뜹니다.
  3. p형p형 \(10^{17}\)이면 \(p = 10^{17}\), \(n = 10^3\), \(E_F - E_i = -0.417\) eV로 가전자대 쪽으로 내려갑니다.
  4. 데우기n형 \(10^{16}\)을 500 K로 데우면 \(E_F - E_i = 0.189\) eV, 600 K에서 0.102 eV로 가운데로 내려옵니다. 600 K에서 \(p = 2.0\times10^{14}\)으로 소수 운반자가 크게 늘었습니다.

연결과 적용

pn 접합(전전8 1단원)에서 양쪽의 Fermi 준위가 같아지도록 띠가 휘는 것이 내장 전위이고, 그 크기는 두 쪽 \(E_F - E_i\)의 차이 \(\frac{kT}{e}\ln\frac{N_AN_D}{n_i^2}\)입니다. MOSFET의 문턱 전압도 기판 도핑의 \(E_F\) 위치로 정해집니다. 반도체물성(전전27 3.1절)에서 이온화하지 않는 저온 영역까지 다룹니다.

흔한 오해

  • "Fermi 준위는 도너 준위에 있다." 보통 도핑과 실온에서는 도너 준위보다 아래, 띠 간격 안의 어딘가에 있고 농도에 따라 움직입니다.
  • "도핑 농도를 두 배로 하면 E_F가 두 배 올라간다." 로그 관계라 \(kT\ln2 = 18\) meV만 오릅니다.
