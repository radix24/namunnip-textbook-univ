왼쪽 1/4에서 발견될 확률

확률 밀도 적분

출발점

확률은 |ψ|²의 구간 적분입니다(2.3절). sin²을 (1 − cos)/2로 바꿔 적분합니다.

문제 해결 전략 · 삼각 함수 적분
  1. \(\sin^2u = (1 - \cos2u)/2\).
  2. u = πx/L로 치환한다.
  3. 구간 0~L/4를 넣는다.

무한 우물 바닥 상태에서 0 ≤ x ≤ L/4에서 발견될 확률은?

풀이

  1. \(P = \frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac2\pi\int_0^{\pi/4}\sin^2u\,du\).
    치환.
  2. \(\int_0^{\pi/4}\sin^2u\,du = \frac\pi8 - \frac14\).
    반각 공식.
  3. \(P = \frac14 - \frac1{2\pi} = 0.091\).
    약 9%.

의미

벽 근처에서는 ψ가 0에 가까워 고전 값 25%보다 훨씬 적게 발견됩니다.

검산

왼쪽 1/4 + 가운데 절반 + 오른쪽 1/4 = 0.091 + 0.818 + 0.091 = 1로 맞습니다.
