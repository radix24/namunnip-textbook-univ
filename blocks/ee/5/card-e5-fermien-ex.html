나트륨의 Fermi 에너지

자유 전자 모형

출발점

원자 하나가 전자 하나를 내놓는 금속이면 전자 밀도 = 원자 밀도입니다(3.5절).

문제 해결 전략 · 밀도 → E_F
  1. 체심 입방 a = 0.429 nm, 원자 2개.
  2. n = 2/a³.
  3. E_F 식에 넣는다.

나트륨(체심 입방, a = 0.429 nm, 원자당 전자 1개)의 Fermi 에너지는?

풀이

  1. n = 2/(4.29×10⁻¹⁰)³ = 2.53×10²⁸ m⁻³.
    단위 세포 2개.
  2. (3π²n)^{2/3} = (7.49×10²⁹)^{2/3} = 8.24×10¹⁹ m⁻².
    거듭제곱.
  3. E_F = (1.055×10⁻³⁴)² × 8.24×10¹⁹/(2 × 9.11×10⁻³¹) = 5.0×10⁻¹⁹ J ≈ 3.1 eV.
    식 대입.

의미

알칼리 금속은 전자 밀도가 낮아 E_F가 구리의 절반 정도입니다(실측 약 3.2 eV, 확인 필요).

검산

구리와의 비: (2.53/8.47)^{2/3} = 0.447, 7.03 × 0.447 = 3.1 eV.
