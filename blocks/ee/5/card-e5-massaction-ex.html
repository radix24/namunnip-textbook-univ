보상 도핑

질량 작용 · 전하 중성

출발점

도너와 억셉터가 함께 있으면 서로 상쇄해 알짜 도핑이 다수 운반자를 정합니다(4.3절).

문제 해결 전략 · 알짜 도핑 → 질량 작용
  1. N_D − N_A로 알짜 도핑을 구한다.
  2. 다수 운반자 = 알짜 도핑.
  3. 소수 운반자 = n_i²/다수.

N_D = 5×10¹⁶, N_A = 2×10¹⁶ cm⁻³. n, p와 형은?

풀이

  1. 알짜 N_D − N_A = 3×10¹⁶ → n형.
    도너가 많음.
  2. n = 3×10¹⁶ cm⁻³.
    다수.
  3. p = 10²⁰/(3×10¹⁶) = 3.3×10³ cm⁻³.
    질량 작용.

의미

집적 회로 공정에서는 이미 도핑된 영역 위에 반대 형 이온을 넣어 형을 뒤집습니다(보상).

검산

np = 3×10¹⁶ × 3.33×10³ = 10²⁰ = n_i².
