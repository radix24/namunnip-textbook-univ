파동 함수와 확률 해석

본문
이 절에서 배울 것
  • 파동 함수의 절댓값 제곱을 확률 밀도로 해석한다.
  • 정규화 조건 \(\int|\psi|^2dx = 1\)을 적용한다.
  • 무한 우물에서 구간 안에 있을 확률을 계산한다.
먼저 알아야 할 것
  • 무한 우물 (2.1절), 적분(고교 미적분).

2.3.1확률 밀도

Schrödinger 방정식의 해 ψ(x) 자체는 측정되지 않고, \(|\psi|^2dx\)가 전자를 x와 x + dx 사이에서 발견할 확률입니다. 전체 확률이 1이 되도록 상수를 정하는 것이 정규화입니다. 폭 L 무한 우물의 해는 \(\psi_n = \sqrt{2/L}\sin(n\pi x/L)\)입니다.

예제 2.3.1

바닥 상태(n = 1) 전자가 우물의 가운데 1/3(L/3 ~ 2L/3)에서 발견될 확률은? n = 2이면?

풀이. \(P = \int_{L/3}^{2L/3}\frac2L\sin^2\frac{\pi x}{L}dx = \frac13 + \frac{\sqrt3}{2\pi} = 0.609\). 고전 입자라면 어디나 같은 확률이라 1/3입니다. n = 2는 가운데에 마디가 있어 \(\frac13 - \frac{\sqrt3}{4\pi} = 0.196\)으로 가운데에서 덜 발견됩니다.

흔한 오해(1) "ψ가 음수인 곳은 확률이 음수": 확률은 |ψ|²로 언제나 0 이상입니다. (2) "전자가 우물 속을 왕복하며 위치가 정해져 있다": 측정 전에는 확률 분포로만 말할 수 있습니다.
요약
  1. |ψ|²dx = 발견 확률, 정규화 ∫|ψ|² = 1.
  2. 무한 우물 ψ_n = √(2/L) sin(nπx/L).
  3. 예: n = 1 가운데 1/3에서 0.609(고전 1/3).

2.3.2연습문제

기본

  1. ψ = A sin(πx/L)(0~L)을 정규화하는 A는?
    답

    √(2/L).

응용

  1. n = 1에서 왼쪽 절반(0~L/2)에 있을 확률은?
    답

    1/2(대칭).

심화

  1. n이 매우 크면 가운데 1/3에 있을 확률은?
    답

    1/3에 가까워집니다(고전 극한).
