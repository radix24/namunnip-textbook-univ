합금 조성으로 띠 간격 맞추기

본문
이 절에서 배울 것
  • 합금 반도체의 띠 간격이 조성에 따라 대략 선형(Vegard 법칙)으로 변함을 안다.
  • AlₓGa₁₋ₓAs의 띠 간격 \(E_g \approx 1.424 + 1.247x\)로 조성을 정한다.
  • 격자 정합과 직접→간접 전환을 고려한다.
먼저 알아야 할 것
  • 화합물 반도체 (5.1절).

5.4.1섞으면 사이 값

GaAs와 AlAs를 섞은 AlₓGa₁₋ₓAs는 x < 0.45에서 직접 띠 간격 \(E_g \approx 1.424 + 1.247x\) eV(확인 필요: 계수는 문헌마다 조금 다름)이고, 격자 상수가 거의 같아 GaAs 위에 결함 없이 쌓을 수 있습니다. x > 0.45에서는 간접 띠 간격이 되어 발광이 약해집니다.

예제 5.4.1

x = 0.3의 띠 간격과 발광 파장은?

풀이. E_g = 1.424 + 0.374 = 1.798 eV → 690 nm(빨강). 적색 LED와 레이저 포인터, 그리고 GaAs 양자 우물의 장벽층에 씁니다. 더 넓은 범위는 InGaN(청~녹), InGaAsP(광통신 1.3~1.55 μm)를 씁니다.

흔한 오해(1) "아무 조성이나 아무 기판에 키울 수 있다": 격자 상수가 맞지 않으면 결함이 생깁니다. (2) "조성을 늘리면 계속 직접 띠 간격": 일정 조성에서 간접으로 바뀝니다.
요약
  1. E_g(x) ≈ 1.424 + 1.247x(AlGaAs, x < 0.45).
  2. 예: x = 0.3 → 1.80 eV, 690 nm.
  3. 격자 정합, 직접→간접 전환.

5.4.2연습문제

기본

  1. x = 0.1의 E_g는?
    답

응용

    답
