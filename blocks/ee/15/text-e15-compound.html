화합물 반도체의 띠 간격과 응용

본문
이 절에서 배울 것
  • III-V, II-VI 화합물 반도체의 띠 간격과 직접·간접 여부를 안다.
  • 합금 조성에 따른 띠 간격과 격자 상수(Vegard 법칙, 휨)를 계산한다.
  • 격자 정합과 응용(광통신, LED, 고속·전력 소자)을 연결한다.
먼저 알아야 할 것
  • 직접·간접 띠 간격 (전전5 4.2절), 발광 소재 (전전5 5.2절).

5.1.2합금

두 화합물을 섞은 \(A_xB_{1-x}C\)의 격자 상수는 조성에 대해 거의 직선(Vegard 법칙), 띠 간격은 \(E_g(x) = xE_g^A + (1 - x)E_g^B - bx(1 - x)\)로 휨(b)이 있습니다.

예제 5.1.1

(가) Al_xGa_{1-x}As(x < 0.45)의 띠 간격 근사 \(1.424 + 1.247x\) eV로 x = 0.3의 E_g와 발광 파장. (나) In_xGa_{1-x}N에서 GaN 3.4, InN 0.7, b = 1.4 eV(확인 필요)로 x = 0.2의 E_g와 파장.

풀이. (가) 1.798 eV, 약 690 nm(적색). (나) \(0.2 \times 0.7 + 0.8 \times 3.4 - 1.4 \times 0.16 = 0.14 + 2.72 - 0.224 = 2.636\) eV, 약 470 nm(청색). 실제 청색 LED의 InGaN 조성이 이 근처입니다.

기판과 격자 상수가 다르면 결함(전위)이 생겨 발광 효율과 수명이 떨어지므로, InP 기판 위에는 격자가 맞는 In₀.₅₃Ga₀.₄₇As를 씁니다.

흔한 오해(1) "합금의 띠 간격은 단순 평균이다": 휨 때문에 대부분 더 작습니다. (2) "띠 간격만 맞으면 어떤 기판에도 키울 수 있다": 격자 정합이 품질을 좌우합니다(GaN은 격자가 맞는 기판이 없어 사파이어 위에 버퍼층으로 키움).
요약
  1. GaAs 1.42, InP 1.34, InGaAs 0.75, GaN 3.4 eV(직접), SiC·GaP 간접.
  2. Vegard: 격자 상수 선형. \(E_g(x) = xE_A + (1-x)E_B - bx(1-x)\).
  3. 격자 정합이 결정 품질과 소자 수명을 정한다.

5.1.3연습문제

기본

  1. Al₀.₁Ga₀.₉As의 띠 간격 근사는?
    답

    1.549 eV.

응용

  1. 1.55 μm 빛을 흡수하려면 띠 간격이 얼마 이하여야 하는가?
    답

    1240/1550 = 0.8 eV 이하.

심화

  1. 예제 (나)의 식으로 띠 간격 2.34 eV(530 nm, 초록)를 내는 InGaN 조성 x를 구하라.
    답

    \(3.4 - 2.7x - 1.4x(1-x) = 2.34\) → \(1.4x^2 - 4.1x + 1.06 = 0\), x ≈ 0.29.
