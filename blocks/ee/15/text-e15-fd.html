Fermi-Dirac 분포로 점유와 운반자 농도 구하기

본문
이 절에서 배울 것
  • 상태 밀도와 Fermi 분포의 곱을 적분해 전자 농도를 구한다.
  • 비축퇴 조건에서 \(n = N_ce^{-(E_c - E_F)/kT}\)와 \(N_c\)의 크기를 안다.
  • Fermi 준위가 띠 가까이 오면(축퇴) Boltzmann 근사가 틀리는 정도를 계산한다.
먼저 알아야 할 것
  • 상태 밀도 (4.1절), Fermi-Dirac 분포 입문 (전전5 3.1절), 이 절의 탐구 카드.

4.2.1적분

\[ n = \int_{E_c}^{\infty}g(E)f(E)dE. \]

\(E_c - E_F \gg kT\)이면 f를 \(e^{-(E - E_F)/kT}\)로 바꿔 적분할 수 있어

\[ n = N_ce^{-(E_c - E_F)/kT}, \qquad N_c = 2\left(\frac{2\pi m^*kT}{h^2}\right)^{3/2}. \]

\(N_c\)는 "띠 바닥 kT 안에 몰아 놓은 실효 상태 수"로, Si 300 K에서 약 \(2.8\times10^{19}\) cm⁻³, GaAs(m* = 0.067)에서 \(4.4\times10^{17}\) cm⁻³입니다.

예제 4.2.1

Si 300 K, \(E_c - E_F\) = 0.2, 0.05, 0 eV일 때 적분값과 Boltzmann 근사를 비교하라.

풀이. 탐구 카드 수치 적분: 0.2 eV에서 \(1.229\times10^{16}\) vs \(1.230\times10^{16}\)(0.1% 차이). 0.05 eV(약 2kT)에서 \(3.88\times10^{18}\) vs \(4.07\times10^{18}\)(5% 과대). 0 eV(E_F = E_c)에서 \(2.15\times10^{19}\) vs \(2.82\times10^{19}\)(31% 과대). 도핑이 약 10¹⁹ cm⁻³ 근처로 높아져 E_F가 띠 끝 몇 kT 안에 오면 정확한 Fermi 적분을 써야 합니다(축퇴 반도체).

분포의 봉우리는 띠 바닥에서 kT/2 위에 있습니다(√E와 지수의 곱). 전자는 띠 바닥 근처 수 kT 안에 몰려 있어, 띠 끝의 유효 질량 근사가 잘 맞는 이유가 됩니다.

흔한 오해(1) "N_c는 전도대의 전체 상태 수다": 실효값이며 온도의 3/2제곱에 비례합니다. (2) "Boltzmann 근사는 E_F가 띠 간격 안에만 있으면 맞는다": 띠 끝에서 3kT 이상 떨어져야 몇 % 안으로 맞습니다.
요약
  1. \(n = \int g f dE\). 비축퇴: \(N_ce^{-(E_c-E_F)/kT}\).
  2. \(N_c = 2(2\pi m^*kT/h^2)^{3/2}\): Si 2.8×10¹⁹, GaAs 4.4×10¹⁷ cm⁻³(300 K).
  3. E_F가 띠 끝 몇 kT 안이면 Boltzmann이 과대(E_F = E_c에서 31%).

4.2.3연습문제

기본

  1. Si 300 K에서 \(E_c - E_F\) = 0.3 eV이면 n은?
    답

    \(2.8\times10^{19}e^{-11.6} \approx 2.6\times10^{14}\) cm⁻³.

응용

  1. 600 K에서 Si의 N_c는?
    답

    \(2.8\times10^{19} \times 2^{1.5} \approx 7.97\times10^{19}\) cm⁻³.

심화

  1. GaAs에 n = 10¹⁸ cm⁻³을 도핑하면 E_F는 전도대 바닥 위인가 아래인가?
    답

    N_c = 4.4×10¹⁷ < n이라 Boltzmann식으로는 E_F가 E_c 위(축퇴). 정확한 Fermi 적분이 필요합니다.
