기댓값과 연산자

본문
이 절에서 배울 것
  • 위치·운동량·에너지의 기댓값을 파동함수로 계산한다.
  • 운동량 연산자 \(\hat p = -i\hbar\,d/dx\)를 쓴다.
  • 중첩 상태의 에너지 기댓값과 측정 확률을 구한다.
먼저 알아야 할 것
  • Schrödinger 방정식 (1.1절), 확률 해석 (1.2절).

1.3.1평균은 적분으로

\(\langle A\rangle = \int\psi^*\hat A\psi\,dx\). 위치는 x를 곱하고, 운동량은 \(-i\hbar\,d/dx\)를 작용합니다. 에너지 고유 상태들의 중첩 \(\psi = \sum c_n\psi_n\)에서 에너지를 재면 E_n이 \(|c_n|^2\)의 확률로 나오고, 기댓값은 \(\sum|c_n|^2E_n\)입니다.

예제 1.3.1

무한 우물에서 \(\psi = (\psi_1 + \psi_2)/\sqrt2\)일 때 에너지 측정값과 확률, 기댓값은? 바닥 상태의 ⟨x⟩와 ⟨p⟩는?

풀이. E₁(1/2), E₂ = 4E₁(1/2) → ⟨E⟩ = 2.5E₁. 바닥 상태 ⟨x⟩ = L/2(대칭), ⟨p⟩ = 0(실수 파동함수는 왼쪽·오른쪽 운동이 같음). 그러나 ⟨p²⟩ = 2mE₁ ≠ 0이라 운동량이 0인 것은 아닙니다.

흔한 오해(1) "기댓값은 한 번 측정했을 때 나오는 값": 많이 잰 평균이며, 2.5E₁은 한 번도 나오지 않습니다. (2) "⟨p⟩ = 0이면 멈춰 있다": 양쪽 방향으로 움직이는 확률이 같을 뿐입니다.
요약
  1. ⟨A⟩ = ∫ψ*Âψ dx, p̂ = −iħ d/dx.
  2. 중첩: E_n이 |c_n|² 확률로.
  3. 예: (ψ₁ + ψ₂)/√2 → ⟨E⟩ = 2.5E₁.
