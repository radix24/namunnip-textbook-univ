얇은 장벽의 투과: 계단 두 개를 잇기

예제 · 구간별 해와 경계 조건 네 개

먼저 예측

두께 d인 사각 장벽을 넘는 문제는 미지수가 몇 개이고 조건은 몇 개일까요?

생각해 본 뒤 열기

세 구간에 미지수 다섯 개(입사파 계수를 1로)와 경계 두 곳의 조건 네 개가 있어 비(투과 계수)가 정해집니다.

문제

높이 V₀, 두께 d인 장벽(0 < x < d)에 E < V₀인 전자가 왼쪽에서 들어온다. 세 구간의 해와 경계 조건을 세우고, 미지수와 조건의 개수를 세라. d → ∞이면 어떻게 되는가?

전략

  1. 왼쪽: 입사 + 반사, 장벽 안: 늘고 주는 지수 둘, 오른쪽: 투과만.
  2. x = 0, x = d에서 ψ, ψ' 연속.

풀이

  1. x < 0: \(e^{jkx} + re^{-jkx}\). 0 < x < d: \(Ce^{\kappa x} + De^{-\kappa x}\). x > d: \(te^{jkx}\). 구간별 해
  2. 미지수 r, C, D, t 넷, 조건(두 경계 × ψ, ψ') 넷 → 유일하게 정해짐. 개수
  3. 풀면 \(|t|^2 = [1 + V_0^2\sinh^2(\kappa d)/(4E(V_0 - E))]^{-1}\). 결과
  4. d → ∞이면 C = 0이어야 하고 계단 문제(1.1절)와 같아져 |t| → 0, 전반사. 극한

의미

다층 구조(양자 우물, 초격자, 공명 터널링 다이오드)도 같은 방법으로 층마다 해를 쓰고 경계마다 이어, 2×2 전달 행렬을 곱해 계산합니다.

검산

V₀ = 2 eV, E = 1 eV, d = 1 nm(자유 전자)이면 |t|² ≈ 1.42×10⁻⁴(전전5 2.2절 탐구 카드와 같은 값).
