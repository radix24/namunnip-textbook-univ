파동함수의 확률 해석

본문
이 절에서 배울 것
  • \(|\psi|^2\)를 확률 밀도로 해석하고 규격화 조건을 쓴다.
  • 위치의 기댓값과 구간 확률을 적분으로 계산한다.
  • 측정과 불확정성 원리의 뜻을 안다.
먼저 알아야 할 것
  • Schrödinger 방정식 (1.1절), 정적분(고교 미적분).

1.2.1Born 해석

확률 밀도: \(|\psi(x)|^2dx\)는 전자를 x와 x + dx 사이에서 발견할 확률.

규격화: \(\int|\psi|^2dx = 1\)(어딘가에는 반드시 있다).

기댓값: \(\langle x\rangle = \int x|\psi|^2dx\). 같은 상태를 많이 준비해 위치를 잴 때의 평균.

예제 1.2.1

폭 L 무한 우물의 바닥 상태 \(\psi = A\sin(\pi x/L)\). (가) A, (나) 0 ≤ x ≤ L/4에서 발견할 확률, (다) ⟨x⟩.

풀이. (가) \(\int_0^LA^2\sin^2(\pi x/L)dx = A^2L/2 = 1\) → \(A = \sqrt{2/L}\). (나) \(\frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac14 - \frac{1}{2\pi} \approx 0.0908\). 고전 입자(고르게 분포)라면 0.25인데, 바닥 상태는 벽 근처에 잘 없습니다. (다) 대칭이라 L/2.

1.2.2측정과 불확정성

측정하면 확률 분포에 따라 하나의 값이 나오고, 상태가 그 결과에 맞게 바뀝니다. 위치가 좁게 정해진 파동함수는 여러 파수(운동량)의 합이어야 하므로 \(\Delta x\Delta p \ge \hbar/2\). 우물에 가둔 전자의 바닥 에너지가 0이 아닌 이유(영점 에너지)이기도 합니다.

흔한 오해(1) "ψ 자체가 확률이다": 확률은 |ψ|²이고 ψ는 복소수일 수 있습니다. (2) "기댓값이 가장 자주 나오는 값이다": 평균일 뿐, 1번 들뜬 상태는 가운데(기댓값 L/2)에서 확률이 0입니다.
요약
  1. |ψ|²dx = 확률. ∫|ψ|²dx = 1.
  2. ⟨x⟩ = ∫x|ψ|²dx. 구간 확률 = 구간 적분.
  3. Δx Δp ≥ ħ/2 → 영점 에너지.

1.2.3연습문제

기본

  1. 바닥 상태에서 L/4 ≤ x ≤ 3L/4에서 발견할 확률은?
    답

    1 − 2 × 0.0908 = 0.818.

응용

  1. n = 2 상태 \(\sqrt{2/L}\sin(2\pi x/L)\)에서 0 ≤ x ≤ L/4의 확률은?
    답

    1/4(대칭과 반주기 적분).

심화

  1. Δx ≈ 1 nm로 가둔 전자의 Δp 최솟값과 그에 해당하는 운동 에너지 어림은?
    답

    Δp ≥ ħ/(2 × 1 nm) = 5.27×10⁻²⁶ kg·m/s, \(E \approx (\Delta p)^2/2m \approx 1.5\times10^{-21}\) J ≈ 9.5 meV.
