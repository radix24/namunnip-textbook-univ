들뜬 상태의 확률 분포

예제 · 규격화와 구간 확률

먼저 예측

무한 우물의 n = 2 상태에서 전자를 우물 가운데에서 찾을 확률은?

생각해 본 뒤 열기

가운데(x = L/2)에서 확률 밀도가 0이라, 가운데 근처의 확률은 작다.

문제

폭 L 무한 우물의 n = 2 상태 \(\psi = \sqrt{2/L}\sin(2\pi x/L)\). (가) 규격화 확인, (나) 3L/8 ≤ x ≤ 5L/8에서의 확률, (다) 바닥 상태의 같은 구간 확률과 비교.

전략

  1. \(\int\sin^2(ax)dx = x/2 - \sin(2ax)/(4a)\).
  2. 구간 확률 = 구간 적분.

풀이

  1. (가) \(\frac2L \cdot \frac L2 = 1\). 규격화
  2. (나) \(\frac2L\left[\frac x2 - \frac{L\sin(4\pi x/L)}{8\pi}\right]_{3L/8}^{5L/8} = \frac14 - \frac{1}{4\pi}[\sin(5\pi/2) - \sin(3\pi/2)] = \frac14 - \frac{1}{2\pi} \approx 0.0908\). n = 2
  3. (다) n = 1: \(\frac14 + \frac{1}{2\pi}[\sin(3\pi/4) - \sin(5\pi/4)]/\,\cdot\) 계산하면 \(\frac14 + \frac{\sqrt2}{2\pi} \approx 0.475\). n = 1

의미

같은 구간이라도 상태에 따라 확률이 5배 넘게 다르다. 양자 우물 레이저에서 전자와 정공 파동함수가 겹치는 정도(겹침 적분)가 발광 세기를 정하는 것과 같은 계산이다.

검산

n = 1: \(\frac2L\int\sin^2(\pi x/L)dx\) over [3L/8, 5L/8] = \(\frac14 + \frac{1}{2\pi}(\sin\frac{3\pi}{4}\cdot2)\)… = 0.25 + 0.225 = 0.475.

이해 확인

n = 2 상태에서 0 ≤ x ≤ L/2의 확률은?

답

1/2(대칭).
