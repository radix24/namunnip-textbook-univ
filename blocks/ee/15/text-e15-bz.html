역격자와 Brillouin 영역

본문
이 절에서 배울 것
  • 1차원 격자 a의 첫째 Brillouin 영역 \(-\pi/a < k \le \pi/a\)를 안다.
  • 띠 하나에 들어가는 상태 수가 2N(N: 단위 세포 수)임을 보인다.
  • 띠가 꽉 차면 전류가 흐르지 않는 이유를 설명한다.
먼저 알아야 할 것
  • Kronig-Penney 모형 (3.1절), Bloch 정리.

3.3.1k가 갈 수 있는 곳

주기 a인 결정에서 k와 k + 2π/a는 같은 상태라, k는 길이 2π/a 구간(첫째 Brillouin 영역) 안에서만 셉니다. 길이 L = Na인 결정에 주기 경계 조건을 쓰면 k 간격이 2π/L이라 영역 안에 N개, 스핀까지 2N개 상태가 들어갑니다.

예제 3.3.1

단위 세포에 가전자 2개인 1차원 결정의 띠는 어떻게 채워지는가? 1개면?

풀이. 가전자 2N개가 띠 하나(2N 상태)를 꽉 채워 절연체·반도체가 됩니다. 1개면 띠의 절반만 차서 금속입니다. 꽉 찬 띠에서는 +k와 −k 전자가 짝을 이뤄 전계를 걸어도 알짜 전류가 0입니다.

흔한 오해(1) "k는 무한히 클 수 있다": 결정에서는 Brillouin 영역 밖이 안쪽과 같습니다. (2) "전자가 많으면 늘 금속": 띠를 정확히 채우면 절연체입니다.
요약
  1. 첫째 Brillouin 영역 |k| ≤ π/a.
  2. 띠당 상태 2N.
  3. 꽉 찬 띠는 전류 0.

3.3.2연습문제

기본

  1. a = 0.5 nm의 영역 끝 k는?
    답

    6.28×10⁹ m⁻¹.

응용

  1. N = 1000 셀 결정에서 띠 하나의 상태 수는?
    답

    2000.

심화

  1. 실리콘이 가전자 4개인데 반도체인 이유는(단위 세포 원자 2개)?
    답

    세포당 가전자 8개가 띠 4개를 꽉 채우기 때문입니다.
