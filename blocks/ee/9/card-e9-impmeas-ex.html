인덕터의 등가 저항 재기

크기 · 위상 · Q

출발점

실제 인덕터는 선 저항이 있어 위상이 90°보다 작습니다(2.4절).

문제 해결 전략 · 위상 → R, X → Q
  1. |Z|와 φ를 잰다.
  2. R = |Z|cos φ, X = |Z|sin φ.
  3. Q = X/R.

10 kHz에서 인덕터 |Z| = 630 Ω, 전압이 전류보다 85° 앞선다. L, 직렬 저항, Q는?

풀이

  1. X = 630 sin85° = 627.6 Ω → L = 627.6/(2π × 10⁴) = 10.0 mH.
    유도 리액턴스.
  2. R = 630 cos85° = 54.9 Ω.
    직렬 저항.
  3. Q = 627.6/54.9 = 11.4.
    X/R.

의미

위상이 90°에서 조금만 벗어나도 R이 크게 달라져, 위상 측정의 정밀도가 Q 측정을 좌우한다.

검산

√(627.6² + 54.9²) = 630 Ω.
