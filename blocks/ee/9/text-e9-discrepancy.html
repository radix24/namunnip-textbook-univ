측정값과 설계값이 다를 때

본문
이 절에서 배울 것
  • 설계값과 측정값의 차이를 직류 동작점, 소자 변동, 계기와 발생기, 모델 근사로 나누어 찾는다.
  • 여러 원인의 효과를 곱해 차이를 설명하는 "오차 예산"을 세운다.
  • 다음 측정으로 원인을 하나씩 확인하는 순서를 정한다.
먼저 알아야 할 것
  • 공통 이미터 증폭기 (4.1절), 계기의 부하 효과 (1.2절), 출력 저항 \(r_o\) (전전8 2.3절).

4.2.1직류부터, 그다음 교류

증폭기의 이득은 동작점 전류에 비례하므로(\(g_m = I_C/V_T\)), 이득이 틀리면 먼저 직류 전압 \(V_B, V_E, V_C\)를 재어 실제 전류를 구합니다. 직류가 맞는데 이득만 다르면 교류 쪽(축전기, 부하, 계기)을 의심합니다.

원인확인 방법대표 크기
동작점 전류가 다름(β, \(V_{BE}\), 저항 허용 오차)\(V_E/R_E\) 또는 \((V_{CC} - V_C)/R_C\)수~수십 %
발생기 출력 저항과 입력 저항의 분압베이스에서 직접 입력 진폭 재기1~수 %
트랜지스터 출력 저항 \(r_o\)(Early 효과)\(R_C \parallel r_o\)로 계산수 %
계기·다음 단의 부하×10 프로브로 바꿔 비교0.1~수 %
측정 주파수가 중간 대역 밖주파수를 바꿔 이득이 평평한지 확인경우에 따라 큼

4.2.2오차 예산

예제 4.2.1

4.1절 회로(설계 \(I_C\) = 1 mA, \(R_E\) 우회, 설계 이득 −217)의 측정 이득이 −172였다. 측정 \(V_C\) = 7.24 V. 발생기 출력 저항 50 Ω, 입력 저항 2.21 kΩ, \(V_A\) = 100 V(가정), 출력은 ×1 프로브(1 MΩ)로 쟀다. 차이를 설명하라.

풀이. 실제 \(I_C = (12 - 7.24)/5.6 = 0.85\) mA이므로 이득은 설계의 0.85배. 입력 분압 \(2.21/(2.21 + 0.05) = 0.978\). \(r_o = 100/0.001 = 100\) kΩ로 \(R_C \parallel r_o = 5.30\) kΩ, 0.947배(전류가 0.85 mA면 \(r_o\)는 더 커지지만 근사). 프로브 \(5.6 \parallel 1000\) kΩ, 0.994배. 곱하면 \(217 \times 0.85 \times 0.978 \times 0.947 \times 0.994 \approx 170\)으로 측정 172와 약 1% 안에서 맞습니다. 가장 큰 원인은 동작점 전류이므로, 다음으로 \(V_B\)와 \(V_E\)를 재어 전류가 줄어든 이유(β가 작은지, \(V_{BE}\)가 큰지)를 확인합니다.

이처럼 원인마다 "몇 배"를 어림해 곱하면, 설명되지 않고 남는 차이가 얼마인지 보입니다. 남는 차이가 크면 아직 찾지 못한 원인(배선 실수, 다른 부품)이 있다는 신호입니다.

흔한 오해(1) "트랜지스터가 불량이다"를 먼저 의심하는 것: 대부분은 동작점이나 측정 방법 때문입니다. (2) "차이를 % 하나로 보고하면 된다": 원인별 크기를 보여야 다음 설계에 쓸 수 있습니다. (3) 여러 원인을 더하는 실수: 이득처럼 곱으로 작용하는 양은 비율을 곱합니다(작을 때는 % 합으로 근사 가능).
요약
  1. 직류 동작점을 먼저 재고, 그다음 교류 경로(발생기, \(r_o\), 부하, 주파수)를 본다.
  2. 원인별 배율을 곱한 오차 예산으로 측정값을 설명한다.
  3. 설명되지 않는 차이는 배선·부품 실수의 신호다.

4.2.3연습문제

기본

  1. 설계 이득 −100, 측정 −92이면 상대 차이는?
    답

    −8%.

응용

  1. 입력 저항 1 kΩ인 증폭기를 50 Ω 발생기로 구동할 때 입력 분압 비는?
    답

    1000/1050 ≈ 0.952(약 −4.8%).

심화

  1. 예제에서 프로브를 ×10(10 MΩ)으로 바꾸면 측정 이득은 얼마나 바뀌는가?
    답

    \(5.6 \parallel 10000\) kΩ로 배율 0.99944. 0.994에서 0.9994로, 이득이 약 0.5% 커집니다.
