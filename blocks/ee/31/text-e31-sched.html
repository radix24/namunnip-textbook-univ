스케줄링 알고리즘과 평균 대기 시간

본문
이 절에서 배울 것
  • FCFS, SJF, 라운드 로빈(RR)의 동작을 Gantt 도표로 그린다.
  • 각 알고리즘의 평균 대기 시간을 계산한다.
  • 응답 시간과 처리율의 절충, 시간 할당량의 선택을 안다.
먼저 알아야 할 것
  • 프로세스 개념(이 절에서 정리).

2.1.1세 알고리즘

FCFS: 온 순서대로. SJF: 실행 시간이 가장 짧은 것부터(평균 대기 최소). RR: 시간 할당량 q씩 돌아가며.

예제 2.1.1

P1(24), P2(3), P3(3)가 시각 0에 P1, P2, P3 순으로 도착했다. FCFS, SJF, RR(q = 4)의 평균 대기 시간은?

풀이. FCFS: 대기 0, 24, 27 → 17. SJF: P2, P3, P1 → 0, 3, 6 → 3. RR: P1 0–4, P2 4–7, P3 7–10, P1 10–30. 대기 P1 = 10 − 4 = 6, P2 = 4, P3 = 7 → 5.67. 긴 작업 하나가 앞에 서면 짧은 작업들이 오래 기다리는 호위 효과가 FCFS의 약점입니다.

SJF는 실행 시간을 미리 알아야 해 실제로는 과거 실행 시간으로 추정합니다. RR은 q가 너무 크면 FCFS가 되고, 너무 작으면 문맥 교환 비용이 커집니다.

흔한 오해(1) "RR이 언제나 평균 대기가 가장 작다": 응답성은 좋지만 평균 대기는 SJF가 최소입니다. (2) "SJF는 공정하다": 긴 작업이 계속 밀리는 기아가 생길 수 있어 노화(aging)를 씁니다.
요약
  1. FCFS, SJF(평균 대기 최소), RR(응답성).
  2. 예: 17, 3, 5.67.
  3. q 선택: 크면 FCFS, 작으면 문맥 교환 비용.

2.1.2연습문제

기본

  1. 예제에서 P2, P3, P1 순 FCFS의 평균 대기는?
    답

    3(SJF와 같음).

응용

  1. RR q = 2면 P2의 대기 시간은?
    답

    P1 0–2, P2 2–4, P3 4–6, P1 6–8, P2 8–9 … P2 대기 = 2 + 4 = 6.

심화

  1. 대화형 시스템에서 q를 정하는 기준은?
    답

    대부분의 짧은 상호 작용이 한 번에 끝날 만큼 크고, 문맥 교환 비용보다 충분히 크게.
