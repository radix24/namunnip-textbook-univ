응답 시간 분석

정확한 판정

출발점

가장 낮은 우선순위 작업의 최악 응답 시간을 반복 계산합니다(2.5절).

문제 해결 전략 · R = C + Σ⌈R/T_j⌉C_j
  1. 작업 (1, 4), (1, 5), (3, 10).
  2. 가장 낮은 작업 3: C = 3.
  3. R₀ = 3에서 반복.

작업 3의 최악 응답 시간과 판정은?

풀이

  1. R = 3 + ⌈3/4⌉ + ⌈3/5⌉ = 5.
    1회.
  2. R = 3 + ⌈5/4⌉ + ⌈5/5⌉ = 6 → 다시 3 + 2 + 2 = 7 → 3 + 2 + 2 = 7 수렴.
    반복.
  3. 7 ≤ 10 → 마감 지킴.
    판정.

의미

충분 조건을 넘는 작업 집합도 이 분석으로 확인할 수 있다.

검산

⌈7/4⌉ = 2, ⌈7/5⌉ = 2.
