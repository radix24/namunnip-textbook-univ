실시간 스케줄링: RMS와 EDF

본문
이 절에서 배울 것
  • 주기 작업의 이용률 \(U = \sum C_i/T_i\)를 계산한다.
  • Rate Monotonic의 충분 조건 \(U \le n(2^{1/n} - 1)\)을 쓴다.
  • EDF는 U ≤ 1이면 스케줄 가능함을 안다.
먼저 알아야 할 것
  • 스케줄링 알고리즘 (2.1절).

2.5.1마감을 지키는 순서

RMS는 주기가 짧은 작업에 높은 고정 우선순위를 줍니다. n개 작업의 이용률이 \(n(2^{1/n} - 1)\)(n = 3이면 0.780, n → ∞면 0.693) 이하면 모든 마감을 지킵니다(충분 조건). EDF는 마감이 가까운 작업을 먼저 해 U ≤ 1이면 됩니다.

예제 2.5.1

작업 (C, T) = (1, 4), (1, 5), (3, 10) ms. 이용률과 RMS 판정은?

풀이. U = 0.25 + 0.2 + 0.3 = 0.75 ≤ 0.780 → RMS로 스케줄 가능. U가 0.78과 1 사이면 RMS는 정밀 분석(응답 시간 분석)이 필요하고, EDF는 가능합니다. 자동차·항공 제어 소프트웨어가 이런 분석을 거칩니다.

흔한 오해(1) "U ≤ 1이면 RMS도 늘 가능": RMS는 더 낮은 한계가 있습니다. (2) "RMS 한계를 넘으면 불가능": 충분 조건이라 넘어도 가능할 수 있습니다.
요약
  1. U = ΣC_i/T_i.
  2. RMS: U ≤ n(2^{1/n} − 1)이면 가능.
  3. EDF: U ≤ 1.
