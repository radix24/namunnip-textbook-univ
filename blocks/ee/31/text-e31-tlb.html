TLB와 유효 메모리 접근 시간

본문
이 절에서 배울 것
  • 페이지 테이블을 거치면 메모리 접근이 두 번 필요함을 안다.
  • TLB 적중률로 유효 접근 시간(EAT)을 계산한다.
  • TLB 도달 범위와 큰 페이지의 효과를 안다.
먼저 알아야 할 것
  • 페이징 (4.1절), 다단계 페이지 테이블 (4.2절).

4.3.1주소 변환 캐시

가상 주소를 바꾸려면 페이지 테이블을 읽어야 하므로 접근이 두 배가 됩니다. 최근 변환을 담는 TLB가 적중하면 바로 물리 주소를 얻습니다. \(\mathrm{EAT} = h(t_{TLB} + t_m) + (1 - h)(t_{TLB} + 2t_m)\)(1단계 테이블).

예제 4.3.1

t_m = 100 ns, t_TLB = 1 ns, 적중률 98%의 EAT는? TLB가 없으면?

풀이. 0.98 × 101 + 0.02 × 201 = 103 ns, TLB 없이 200 ns. 4단계 페이지 테이블이면 실패 때 접근이 5번이라 적중률이 더 중요합니다. 항목 64개, 4 KB 페이지의 TLB 도달 범위는 256 KB로, 큰 자료는 2 MB 큰 페이지를 쓰면 실패가 줄어듭니다.

흔한 오해(1) "페이징은 공짜": TLB 실패마다 테이블 접근이 더해집니다. (2) "TLB는 데이터 캐시": 주소 변환만 담습니다.
요약
  1. EAT = h(t_TLB + t_m) + (1 − h)(t_TLB + 2t_m).
  2. 예: 98% → 103 ns.
  3. 도달 범위 = 항목 × 페이지 크기.

4.3.2연습문제

기본

    답

    111 ns.

응용
