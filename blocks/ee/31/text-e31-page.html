페이지 교체 알고리즘의 페이지 부재 수

본문
이 절에서 배울 것
  • FIFO, LRU, OPT(최적) 교체를 참조열에 적용한다.
  • 프레임 수에 따른 페이지 부재 수를 계산한다.
  • Belady의 이상 현상과 LRU 근사(클록 알고리즘)를 안다.
먼저 알아야 할 것
  • 가상 메모리 (전전14 6단원).

4.1.1세 알고리즘

FIFO: 가장 먼저 들어온 페이지를 내보냄. LRU: 가장 오래 쓰지 않은 페이지. OPT: 앞으로 가장 늦게 쓰일 페이지(미래를 알아야 해 비교 기준으로만 씀).

예제 4.1.1

참조열 7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2, 1, 2, 0, 1, 7, 0, 1에서 프레임 3개와 4개의 페이지 부재 수.

ref = [7,0,1,2,0,3,0,4,2,3,0,3,2,1,2,0,1,7,0,1]
def fifo(r, n):
    f, q, c = set(), [], 0
    for p in r:
        if p not in f:
            c += 1
            if len(f) == n: f.remove(q.pop(0))
            f.add(p); q.append(p)
    return c
def lru(r, n):
    f, c = [], 0
    for p in r:
        if p in f: f.remove(p)
        else:
            c += 1
            if len(f) == n: f.pop(0)
        f.append(p)
    return c
def opt(r, n):
    f, c = [], 0
    for i, p in enumerate(r):
        if p in f: continue
        c += 1
        if len(f) == n:
            nxt = [r[i+1:].index(x) if x in r[i+1:] else 99 for x in f]
            f.pop(nxt.index(max(nxt)))
        f.append(p)
    return c
for n in (3, 4): print(n, "프레임: FIFO", fifo(ref, n), "LRU", lru(ref, n), "OPT", opt(ref, n))

실행 결과(Python 3.12에서 실제 실행):

3 프레임: FIFO 15 LRU 12 OPT 9
4 프레임: FIFO 10 LRU 8 OPT 8

LRU는 OPT에 가깝고 FIFO보다 낫습니다. LRU를 정확히 구현하려면 참조마다 시각을 기록해야 해 비싸므로, 참조 비트를 돌며 확인하는 클록(두 번째 기회) 알고리즘으로 근사합니다. FIFO는 프레임을 늘렸는데 부재가 늘어나는 Belady 이상이 생길 수 있습니다(예: 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5에서 3프레임 9번, 4프레임 10번).

흔한 오해(1) "프레임을 늘리면 어떤 알고리즘이든 부재가 준다": FIFO는 아닐 수 있습니다(LRU, OPT는 보장). (2) "OPT를 구현할 수 있다": 미래 참조를 알 수 없어 비교 기준입니다.
요약
  1. FIFO, LRU, OPT.
  2. 예(3프레임): 15, 12, 9(실제 계산).
  3. 클록 알고리즘으로 LRU 근사, FIFO의 Belady 이상.
