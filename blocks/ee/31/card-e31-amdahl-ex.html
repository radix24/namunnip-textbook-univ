출발점

직렬 부분 감소와 코어 증가를 비교합니다(2.4절).

문제 해결 전략 · 두 안 비교
  1. 현재 p = 0.8, N = 4.
  2. 안 A: 코어 8개로.
  3. 안 B: p를 0.9로(코드 개선).

현재와 두 안의 가속은?

풀이

  1. 현재: 1/(0.2 + 0.2) = 2.5.
    계산.
  2. A: 1/(0.2 + 0.1) = 3.33.
    계산.
  3. B: 1/(0.1 + 0.225) = 3.08.
    계산.

의미

이 경우 둘이 비슷해, 비용이 싼 쪽을 고르거나 둘 다 합니다(p 0.9, N 8이면 4.7).

검산

1/(0.1 + 0.1125) = 4.7.
