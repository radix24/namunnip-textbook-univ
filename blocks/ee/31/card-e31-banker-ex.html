요청 승인 판정

가정 후 안전 검사

출발점

요청을 들어줬다고 가정하고 안전 검사를 합니다(3.4절).

문제 해결 전략 · 요청 → 가정 → 검사
  1. 위 상태에서 P1이 (1, 0, 2) 요청.
  2. 요청 ≤ Need(1, 2, 2), 요청 ≤ Work(3, 3, 2) 확인.
  3. 가정 후 Work (2, 3, 0), P1 할당 (3, 0, 2), Need (0, 2, 0).

승인해도 되는가?

풀이

  1. Work (2, 3, 0)으로 P1(Need 0, 2, 0) 가능 → Work (5, 3, 2).
    1단계.
  2. 이어 P3 → (7, 4, 3), P0 → (7, 5, 3), P2, P4 가능.
    계속.
  3. 안전 → 승인.
    판정.

의미

이 요청을 승인한 뒤 P0이 (0, 2, 0)을 요청하면 Work (2, 1, 0)으로 아무도 끝낼 수 없어 불안전하므로 미뤄진다.

검산

3 − 1 = 2, 3 − 0 = 3, 2 − 2 = 0.
