적률 생성 함수로 적률 구하기

본문

부품의 고장 간격이 지수 분포를 따를 때 평균과 분산을 구하려면 \(\int x\lambda e^{-\lambda x}dx\)와 \(\int x^2\lambda e^{-\lambda x}dx\)를 부분 적분으로 따로 풀어야 한다. 적분을 한 번만 해 두고 미분만으로 모든 적률을 꺼낼 수는 없을까? 독립인 두 값의 합의 분포도 그렇게 쉽게 구할 수 있을까?

먼저 알아야 할 것기댓값(2.1절)과 지수 함수의 미분을 쓴다.

2.4.1미분하면 적률

적률 생성 함수는 \(M(s) = E[e^{sX}]\)로 정의한다. \(e^{sX} = 1 + sX + s^2X^2/2 + \cdots\)로 펼치고 기댓값을 취하면 \(s^n\)의 계수에 \(E[X^n]/n!\)이 들어간다. 그래서 \(s = 0\)에서 미분하면 \(M'(0) = E[X]\), \(M''(0) = E[X^2]\)처럼 적률이 차례로 나온다. 처음 질문의 첫째 답이 이것이다(그림 1).

독립인 \(X\), \(Y\)의 합은 \(E[e^{s(X+Y)}] = E[e^{sX}]E[e^{sY}]\)이므로 \(M_{X+Y} = M_XM_Y\)이다. 즉 밀도끼리의 컨벌루션 대신 생성 함수의 곱셈으로 합의 분포를 다룰 수 있으며, 처음 질문의 둘째 답이 이것이다. 한편 특성 함수 \(\Phi(\omega) = E[e^{j\omega X}]\)는 어떤 분포에서나 존재하며, PDF의 Fourier 변환이다.

가우시안 \(N(\mu, \sigma^2)\)의 생성 함수는 \(e^{\mu s + \sigma^2s^2/2}\)이다. 그러므로 독립 가우시안 둘을 더하면 지수 안의 평균과 분산이 각각 더해질 뿐 꼴은 그대로여서, 합도 가우시안이라는 사실이 한 줄로 나온다.

예제 2.4.1

지수 분포(λ)의 \(M(s) = \lambda/(\lambda - s)\)에서 평균과 분산은?

풀이. \(M' = \lambda/(\lambda - s)^2\)이므로 E[X] = 1/λ이다. \(M'' = 2\lambda/(\lambda - s)^3\)이므로 E[X²] = 2/λ²이고, 분산은 2/λ² − 1/λ² = 1/λ²이다. 가령 평균 고장 간격이 1000시간이면 표준 편차도 1000시간이다.

여기서 필요한 적분은 \(M(s)\)를 구할 때 한 번뿐이다. \(\int_0^\infty \lambda e^{-(\lambda - s)x}dx = \lambda/(\lambda - s)\)이며, \(s < \lambda\)일 때만 수렴한다. 그 뒤로는 미분만 하면 되고, 세 번째, 네 번째 적률도 같은 식에서 바로 나온다. 또 독립인 지수 변수 두 개의 합은 생성 함수가 \(\lambda^2/(\lambda - s)^2\)이 되어, 감마 분포라는 것을 곧바로 알 수 있다.

흔한 오해생성 함수를 계산 요령일 뿐이라고 여기기 쉽지만, 생성 함수가 같으면 분포도 같으므로 합의 분포를 알아내는 데 쓴다. 모든 분포에 \(M(s)\)가 있다는 생각도 틀리다. 꼬리가 두꺼운 분포는 \(M(s)\)가 0 밖에서 발산할 수 있어 특성 함수를 쓴다. 가령 Cauchy 분포는 평균조차 없어서 \(M(s)\)가 \(s = 0\)에서만 유한하지만, 특성 함수 \(e^{-|\omega|}\)는 잘 정의된다.
마무리

적률 생성 함수 \(M(s) = E[e^{sX}]\)를 \(s = 0\)에서 미분하면 \(M'(0) = E[X]\), \(M''(0) = E[X^2]\)를 얻는다. 독립인 값의 합은 생성 함수의 곱으로 다룬다. 특성 함수는 PDF의 Fourier 변환이며 언제나 존재한다.

2.4.2연습문제

기본

  1. 베르누이(p)의 M(s)는?
    답

    1 − p + pe^s이다.

응용

  1. Poisson(λ)의 M(s) = e^{λ(e^s − 1)}에서 평균은?
    답

    λ이다.

심화

  1. 독립 Poisson λ₁, λ₂ 합의 분포는?
    답

    생성 함수의 곱이 e^{(λ₁ + λ₂)(e^s − 1)}이므로 Poisson(λ₁ + λ₂)이다.
