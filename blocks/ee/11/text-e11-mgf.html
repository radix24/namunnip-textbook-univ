적률 생성 함수로 적률 구하기

본문
이 절에서 배울 것
  • 적률 생성 함수 \(M(s) = E[e^{sX}]\)와 특성함수를 정의한다.
  • 미분해 평균과 분산을 구한다.
  • 독립 합의 생성 함수가 곱이 됨을 쓴다.
먼저 알아야 할 것
  • 기대값 (2.1절), 지수 함수 미분.

2.4.1미분하면 적률

\(M(s) = E[e^{sX}]\)이면 \(M'(0) = E[X]\), \(M''(0) = E[X^2]\). 독립인 X, Y의 합은 \(M_{X+Y} = M_XM_Y\)라, 합의 분포를 곱셈으로 다룰 수 있습니다. 특성함수 \(\Phi(\omega) = E[e^{j\omega X}]\)는 언제나 존재하며 PDF의 Fourier 변환입니다.

예제 2.4.1

지수 분포(λ)의 \(M(s) = \lambda/(\lambda - s)\)에서 평균과 분산은?

풀이. \(M' = \lambda/(\lambda - s)^2\) → E[X] = 1/λ. \(M'' = 2\lambda/(\lambda - s)^3\) → E[X²] = 2/λ², 분산 1/λ². 평균 고장 간격 1000시간이면 표준편차도 1000시간입니다.

흔한 오해(1) "생성 함수는 계산 요령일 뿐": 같은 생성 함수면 같은 분포라 분포를 알아내는 데 씁니다. (2) "모든 분포에 M(s)가 있다": 꼬리가 두꺼우면 없을 수 있어 특성함수를 씁니다.
요약
  1. M(s) = E[e^{sX}], M'(0) = E[X], M''(0) = E[X²].
  2. 독립 합: 생성 함수의 곱.
  3. 특성함수 = PDF의 Fourier 변환.
