Wiener-Khinchin 정리와 전력 스펙트럼 밀도

본문

잡음 전압을 스펙트럼 분석기에 넣으면 주파수마다 높이가 다른 곡선이 나온다. 그런데 잡음은 잴 때마다 파형이 달라서, 파형 하나의 Fourier 변환은 매번 다르다. 그렇다면 분석기가 보여 주는 곡선은 무엇이며, 시간 영역의 어떤 양에서 나온 것일까?

먼저 알아야 할 것WSS와 자기상관(4.2절), Fourier 변환(전전6 4.1절)을 쓴다.

5.1.1정리

랜덤 신호는 표본마다 달라 신호 자체의 Fourier 변환은 의미가 없지만, 주파수별 평균 전력은 의미가 있다. Wiener-Khinchin 정리는 이 주파수별 전력, 곧 전력 스펙트럼 밀도(PSD)가 자기상관의 Fourier 변환이라고 말한다. 처음 질문의 답이 이것이다.

\[ S_X(f) = \int_{-\infty}^{\infty}R_X(\tau)e^{-j2\pi f\tau}d\tau, \qquad R_X(0) = \int_{-\infty}^{\infty}S_X(f)df = E[X^2]. \]

여기서 \(S(f)\)는 음의 주파수까지 포함한 양측 PSD이며, 실제 신호에서는 짝함수이고 0 이상이다. 그래서 \(f_1\)~\(f_2\) 대역의 전력은 양·음 주파수를 합쳐 \(2\int_{f_1}^{f_2}S(f)df\)이다. 스펙트럼 분석기는 긴 기록의 \(|X(f)|^2/T\)를 평균해 이 값을 어림한다.

예제 5.1.1

(가) 무작위 위상 정현파 \(R = \frac{A^2}{2}\cos2\pi f_0\tau\)의 PSD. (나) \(R(\tau) = e^{-a|\tau|}\)(무작위 전신 신호, a = 2α)의 PSD와, |f| ≤ a/(2π) 대역에 든 전력의 비율.

풀이. (가) \(S(f) = \frac{A^2}{4}[\delta(f - f_0) + \delta(f + f_0)]\)이므로, 전력 \(A^2/2\)가 ±f₀에 반씩 놓인다. (나) \(S(f) = \frac{2a}{a^2 + (2\pi f)^2}\)이고 넓이는 R(0) = 1이다. ω = 2πf로 바꾸면 \(\frac{1}{2\pi}\int_{-a}^{a}\frac{2a}{a^2 + \omega^2}d\omega = \frac{1}{\pi}\cdot2\arctan1 = 0.5\)이다. 즉 전력의 절반이 |ω| ≤ a에 있다(그림 1). 상관 시간 1/a가 짧을수록 스펙트럼이 넓다.

이 반비례 관계는 Fourier 변환의 일반 성질에서 온다. 시간 영역에서 폭이 좁은 함수는 주파수 영역에서 넓게 퍼지므로, 빠르게 뒤집히는 전신 신호는 고주파 성분을 많이 품는다. 극단으로 상관이 τ = 0에서만 있는 \(R = \delta(\tau)\)는 모든 주파수에 고른 백색 스펙트럼이 된다(5.3절).

흔한 오해PSD를 신호의 Fourier 변환의 크기로 여기기 쉽지만, 랜덤 신호의 PSD는 자기상관의 변환이다. 다만 긴 시간 평균한 \(|X(f)|^2/T\)와는 같아진다. 양측 PSD와, 양의 주파수만 쓰고 2배 한 단측 PSD를 섞는 실수도 흔하므로 잡음 표에서 \(N_0\)와 \(N_0/2\)를 확인한다. 또 시간이 짧게 닮을수록, 곧 R이 좁을수록 스펙트럼은 넓으며 그 반대가 아니다.
마무리

PSD는 자기상관의 Fourier 변환 \(S_X(f) = \mathcal F\{R_X(\tau)\}\)이고, 그 넓이가 R(0), 곧 평균 전력이다. 정현파는 델타 한 쌍, \(e^{-a|\tau|}\)는 \(2a/(a^2 + (2\pi f)^2)\)이 된다. 좁은 상관은 넓은 스펙트럼에 대응하며, 양측과 단측 PSD를 구별해야 한다.

5.1.2연습문제

기본

  1. R(τ) = 4δ(τ)의 PSD는?
    답

    S(f) = 4로 모든 주파수에서 일정한 백색이다.

응용

  1. R(τ) = e^{−1000|τ|}의 PSD가 f = 0의 절반이 되는 주파수는?
    답

    \((2\pi f)^2 = 1000^2\)이므로 f ≈ 159 Hz이다.

심화

  1. S(f) = 1(|f| ≤ B), 0(그 밖)인 프로세스의 자기상관과, 서로 무상관인 시간 간격은?
    답

    \(R(\tau) = 2B\,\mathrm{sinc}(2B\tau) = \sin(2\pi B\tau)/(\pi\tau)\)이고, τ = k/(2B)(k ≠ 0)에서 0이다. 즉 나이퀴스트 간격의 표본이 서로 무상관이다.
