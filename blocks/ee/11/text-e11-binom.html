이항 분포와 Poisson 근사

본문

비트 오류율이 1000분의 1인 링크로 1000비트짜리 패킷을 보낸다. 그러면 패킷마다 딱 한 비트씩 틀릴까? 오류가 하나도 없을 확률, 둘 이상일 확률은 얼마이며, 1비트를 고치는 부호를 붙이면 패킷이 얼마나 더 살아남을까?

먼저 알아야 할 것독립과 베르누이 시행(1.1절)을 쓴다.

1.3.1몇 개 틀리나

비트마다 독립적으로 확률 \(p\)로 틀리면, \(n\)비트 중 틀린 개수 \(K\)는 이항 분포를 따른다. \(k\)개가 틀리는 확률은 틀릴 자리를 고르는 가짓수에 각 배치의 확률을 곱한 것이다.

\[ P(K = k) = \binom nk p^k(1 - p)^{n-k}. \]

그런데 비트 오류율 \(p = 10^{-3}\), 패킷 1000비트처럼 \(n\)이 크고 \(p\)가 작으면 \(\binom nk\)를 직접 계산하기 번거롭다. 이때 이항 분포는 \(\lambda = np\)인 Poisson 분포 \(e^{-\lambda}\lambda^k/k!\)로 잘 근사된다. 아래 계산이 두 분포를 나란히 비교한다.

from math import comb, exp, factorial
n, p = 1000, 1e-3
for k in range(4):
    b = comb(n, k) * p**k * (1 - p)**(n - k)
    q = exp(-n * p) * (n * p)**k / factorial(k)
    print(f"k={k}: 이항 {b:.5f}, Poisson {q:.5f}")

실행 결과(Python 3.12에서 실제 실행)는 다음과 같으며, 넷째 자리까지 거의 같다(그림 1).

k=0: 이항 0.36770, Poisson 0.36788
k=1: 이항 0.36806, Poisson 0.36788
k=2: 이항 0.18403, Poisson 0.18394
k=3: 이항 0.06128, Poisson 0.06131
예제 1.3.1

비트 오류율 10⁻³, 1000비트 패킷에서 오류가 없을 확률과, 1비트 정정 부호로 패킷이 살아남을 확률은?

풀이. P(0) = 0.368, P(1) = 0.368이므로 1비트를 정정하면 P(K ≤ 1) = 0.736이다. 즉 부호 없이 패킷의 63%를 잃던 것이 26%로 줄어든다. 그래도 네 개 중 하나를 잃으므로 더 강한 부호가 필요하다. 처음 질문의 답이 이것이다.

근사가 잘 맞는 이유도 간단히 볼 수 있다. \(np = \lambda\)를 고정하고 \(n\)을 키우면 \((1 - p)^{n} = (1 - \lambda/n)^n\)이 \(e^{-\lambda}\)로 가고, \(\binom nk p^k\)는 \(\lambda^k/k!\)에 가까워진다. 그래서 개별 사건은 드물지만 기회가 아주 많은 경우, 가령 일정 시간 동안 도착하는 패킷 수나 칩의 결함 수가 모두 Poisson 분포를 따른다.

Poisson 분포는 평균과 분산이 모두 \(\lambda\)이다. 그러므로 평균이 1인 경우 표준 편차도 1이어서, 오류 개수가 평균 근처에 몰려 있지 않고 0, 1, 2에 넓게 퍼진다.

흔한 오해오류율이 10⁻³이면 1000비트에 꼭 하나가 틀린다고 여기기 쉽다. 하지만 평균이 1일 뿐이며, 0개일 확률도 37%이다. Poisson 근사를 언제나 쓸 수 있다는 생각도 틀리며, \(p\)가 작고 \(n\)이 클 때만 정확하다.
마무리

독립 비트 \(n\)개 중 틀린 개수는 이항 분포 \(\binom nk p^k(1 - p)^{n-k}\)를 따른다. \(n\)이 크고 \(p\)가 작으면 \(\lambda = np\)인 Poisson 분포로 근사하며, \(\lambda = 1\)이면 P(0) = P(1) = 0.368이다.

기본

    답

    6/16 = 0.375이다.

응용

  1. λ = 2인 Poisson에서 P(0)은?
    답

심화

  1. 이항 분포의 평균과 분산은?
    답

    평균은 np, 분산은 np(1 − p)이다.
