저항의 열잡음

본문
이 절에서 배울 것
  • 저항의 열잡음 전압 \(v_{rms} = \sqrt{4kTRB}\)를 계산한다.
  • 열잡음이 백색이고 가우시안임을 안다.
  • 정합된 저항이 내놓는 잡음 전력 kTB를 쓴다.
먼저 알아야 할 것
  • 백색 잡음과 잡음 등가 대역폭 (5.3절).

5.4.14kTRB

저항 속 전자의 열운동이 만드는 잡음 전압의 PSD는 4kTR(V²/Hz)로 주파수에 거의 무관합니다. 정합 부하에 전달되는 잡음 전력은 kTB로 저항값과 무관하며, 290 K에서 −174 dBm/Hz입니다.

import math
k, T = 1.381e-23, 290
for R, B in [(1e3, 1e6), (1e6, 1e6), (50, 20e3)]:
    v = math.sqrt(4 * k * T * R * B)
    print(f"R = {R:g} Ω, B = {B:g} Hz: v_rms = {v * 1e6:.3f} μV")
print("kTB(1 Hz) =", round(10 * math.log10(k * T * 1 / 1e-3), 1), "dBm")

실행 결과(Python 3.12에서 실제 실행):

R = 1000 Ω, B = 1e+06 Hz: v_rms = 4.002 μV
R = 1e+06 Ω, B = 1e+06 Hz: v_rms = 126.569 μV
R = 50 Ω, B = 20000 Hz: v_rms = 0.127 μV
kTB(1 Hz) = -174.0 dBm
예제 5.4.1

1 kΩ 저항, 대역 1 MHz의 열잡음 실효 전압은? 1 μV 신호를 증폭할 때 의미는?

풀이. √(4 × 1.381×10⁻²³ × 290 × 10³ × 10⁶) = 4.0 μV. 1 μV 신호보다 잡음이 4배 커서, 대역을 줄이거나 신호원 저항을 낮춰야 합니다.

흔한 오해(1) "잡음은 증폭기만 만든다": 저항 하나도 잡음원입니다. (2) "저항을 키우면 잡음 전력이 커진다": 전압은 √R로 커지지만 정합 전달 전력 kTB는 같습니다.
요약
  1. v_rms = √(4kTRB).
  2. 정합 잡음 전력 kTB, −174 dBm/Hz(290 K).
  3. 예: 1 kΩ, 1 MHz → 4.0 μV.
