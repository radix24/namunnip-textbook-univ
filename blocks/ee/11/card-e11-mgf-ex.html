가우시안 합의 분포

생성 함수의 곱

출발점

독립 합의 생성 함수는 곱입니다(2.4절). 가우시안은 \(M(s) = e^{\mu s + \sigma^2s^2/2}\).

문제 해결 전략 · 곱 → 지수 합
  1. 두 생성 함수를 곱한다.
  2. 지수의 μ와 σ² 항을 모은다.
  3. 같은 꼴이면 가우시안.

독립인 X ~ N(1, 4), Y ~ N(2, 9)의 합 X + Y의 분포는?

풀이

  1. M_X M_Y = e^{s + 2s²} · e^{2s + 4.5s²}.
    곱.
  2. = e^{3s + 6.5s²}.
    지수 합.
  3. N(3, 13): 평균 3, 분산 13.
    가우시안 꼴.

의미

독립 잡음 여러 개가 더해져도 가우시안이 유지되어 통신 잡음 해석이 간단해진다.

검산

분산은 더해지지만 표준편차는 √13 ≈ 3.61로 2 + 3이 아니다.
