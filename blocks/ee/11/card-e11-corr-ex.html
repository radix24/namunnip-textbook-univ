차동 측정이 잡음을 줄이는 원리

공분산 · 차의 분산

출발점

두 측정의 차의 분산은 Var + Var − 2Cov라, 같은 잡음이 함께 들어오면 상쇄됩니다(3.3절).

문제 해결 전략 · 공통 잡음 + 독립 잡음
  1. X = S + N_c + N₁, Y = N_c + N₂로 둔다.
  2. X − Y의 분산을 구한다.
  3. 단일 측정과 비교한다.

공통 잡음 분산 1, 각 채널 독립 잡음 분산 0.01. X 하나의 잡음 분산과 X − Y의 잡음 분산은?

풀이

  1. X 잡음: 1 + 0.01 = 1.01.
    공통 + 독립.
  2. X − Y: 공통이 상쇄되어 0.01 + 0.01 = 0.02.
    Cov = 1을 두 번 뺌.
  3. 잡음 전력 약 50배 감소.
    차동의 이득.

의미

차동 증폭기(CMRR)와 차동 신호(USB, 이더넷)가 공통 잡음에 강한 이유입니다.

검산

Var(X − Y) = 1.01 + 1.01 − 2 × 1 = 0.02.
