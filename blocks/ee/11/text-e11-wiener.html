Wiener 필터의 원리

본문
이 절에서 배울 것
  • 잡음 섞인 관측에서 원래 신호를 평균 제곱 오차(MSE)가 가장 작게 추정하는 문제를 세운다.
  • 직교 원리(오차가 관측과 무상관)로 최적 선형 추정기를 구한다.
  • 주파수 영역 Wiener 필터 \(H = S_X/(S_X + S_N)\)의 뜻을 안다.
먼저 알아야 할 것
  • 공분산 (3.1절), PSD와 LTI (5.2절), 정합 필터와의 비교 (6.1절).

6.2.1한 개의 값부터

관측 Y = X + N(X, N 독립, 평균 0, 분산 \(\sigma_X^2, \sigma_N^2\))에서 \(\hat X = aY\)로 X를 추정합니다. 구하려는 것: \(E[(X - aY)^2]\)를 가장 작게 하는 a.

a로 미분해 0으로 두면 \(E[(X - aY)Y] = 0\): 오차가 관측과 무상관이어야 합니다(직교 원리). 그래서

\[ a = \frac{E[XY]}{E[Y^2]} = \frac{\sigma_X^2}{\sigma_X^2 + \sigma_N^2}, \qquad \text{MSE} = \frac{\sigma_X^2\sigma_N^2}{\sigma_X^2 + \sigma_N^2}. \]
예제 6.2.1

\(\sigma_X^2 = 4\), \(\sigma_N^2 = 1\). (가) 최적 a와 MSE, (나) 관측을 그대로 쓰면(a = 1) MSE, (다) 아무것도 안 보고 0으로 추정하면?

풀이. (가) a = 0.8, MSE = 4/5 = 0.8. (나) MSE = E[N²] = 1. (다) MSE = E[X²] = 4. 최적 추정은 관측을 조금 줄여(0.8배) 잡음의 영향을 덜어 그대로 쓰는 것보다 낫습니다. 신호가 잡음보다 훨씬 크면 a → 1, 훨씬 작으면 a → 0입니다.

6.2.2주파수 영역

WSS 신호와 잡음이 독립일 때, 같은 생각을 주파수마다 적용하면 비인과 Wiener 필터는

\[ H(f) = \frac{S_X(f)}{S_X(f) + S_N(f)}. \]

신호가 강한 주파수는 통과(H ≈ 1), 잡음이 강한 주파수는 억제(H ≈ 0)합니다. 사진의 잡음 제거, 음성 향상, 통신의 채널 등화에 쓰입니다. 실시간(인과) 필터나 적응 필터(LMS)는 이 원리를 바탕으로 합니다.

정합 필터(6.1절)는 "펄스가 있는지 판정"을 위해 한 시각의 SNR을 최대로 하고, Wiener 필터는 "파형 전체를 복원"하기 위해 MSE를 최소로 합니다. 목적이 다르면 최적 필터도 다릅니다.

흔한 오해(1) "잡음이 섞인 관측을 그대로 쓰는 것이 편향이 없어 최선이다": MSE로는 약간 줄여 쓰는 것이 낫습니다(편향과 분산의 절충). (2) "Wiener 필터는 신호를 몰라도 된다": 신호와 잡음의 PSD(통계)를 알아야 합니다. 모르면 측정으로 추정하거나 적응 필터를 씁니다.
요약
  1. 직교 원리: 오차와 관측은 무상관.
  2. 스칼라: \(a = \sigma_X^2/(\sigma_X^2 + \sigma_N^2)\), MSE \(= \sigma_X^2\sigma_N^2/(\sigma_X^2 + \sigma_N^2)\).
  3. 주파수 영역: \(H = S_X/(S_X + S_N)\). 정합 필터와 목적이 다르다.

6.2.3연습문제

기본

  1. \(\sigma_X^2 = \sigma_N^2 = 1\)이면 최적 a와 MSE는?
    답

    0.5, 0.5.

응용

  1. 관측이 두 개 \(Y_1 = X + N_1\), \(Y_2 = X + N_2\)(잡음 독립, 분산 1, \(\sigma_X^2 = 4\))일 때 대칭성으로 \(\hat X = b(Y_1 + Y_2)\)의 최적 b와 MSE는?
    답

    \(E[(X - bS)S] = 0\), S = Y₁ + Y₂: \(E[XS] = 8\), \(E[S^2] = 16 + 2 = 18\), b = 4/9. MSE = 4 − 8b = 4 − 32/9 = 4/9.

심화

  1. 어떤 주파수에서 SNR(\(S_X/S_N\))이 9이면 Wiener 필터 이득과 그 주파수의 오차 PSD 비율은?
    답

    H = 0.9, 오차 PSD = \(S_XS_N/(S_X+S_N) = 0.9S_N\).
