Wiener 필터의 원리

본문

잡음 섞인 관측 Y = X + N에서 원래 신호 X를 되살리고 싶다. 관측값을 그대로 X의 추정값으로 쓰면 치우침이 없으니 가장 좋은 선택일까? 일부러 관측을 조금 줄여 쓰는 편이 평균 제곱 오차를 더 작게 만들 수도 있을까? 신호의 주파수마다 잡음의 세기가 다르면 어떻게 할까?

먼저 알아야 할 것공분산(3.1절), PSD와 LTI(5.2절), 정합 필터(6.1절)를 쓴다.

6.2.1한 개의 값부터

관측 \(Y = X + N\)에서 \(X\)와 \(N\)은 독립이고, 평균 0, 분산 \(\sigma_X^2, \sigma_N^2\)이라 하자. \(\hat X = aY\)로 \(X\)를 추정할 때, 평균 제곱 오차 \(E[(X - aY)^2]\)를 가장 작게 하는 \(a\)를 찾는다.

\(a\)로 미분해 0으로 두면 \(E[(X - aY)Y] = 0\)이다. 즉 최적일 때 오차가 관측과 무상관이어야 하며, 이를 직교 원리라 한다. 그래서 다음을 얻는다.

\[ a = \frac{E[XY]}{E[Y^2]} = \frac{\sigma_X^2}{\sigma_X^2 + \sigma_N^2}, \qquad \text{MSE} = \frac{\sigma_X^2\sigma_N^2}{\sigma_X^2 + \sigma_N^2}. \]
예제 6.2.1

\(\sigma_X^2 = 4\), \(\sigma_N^2 = 1\). (가) 최적 a와 MSE, (나) 관측을 그대로 쓰면(a = 1) MSE, (다) 아무것도 안 보고 0으로 추정하면?

풀이. (가) a = 0.8, MSE = 4/5 = 0.8이다. (나) MSE = E[N²] = 1이다. (다) MSE = E[X²] = 4이다(그림 1). 따라서 관측을 조금 줄여(0.8배) 잡음의 영향을 덜어 내는 편이 그대로 쓰는 것보다 낫다. 처음 질문의 첫째, 둘째 답이 이것이다. 신호가 잡음보다 훨씬 크면 a → 1, 훨씬 작으면 a → 0이 된다.

6.2.2주파수 영역

WSS 신호와 잡음이 독립일 때, 같은 생각을 주파수마다 적용하면 비인과 Wiener 필터를 얻는다. 처음 질문의 셋째 답이 이것이다.

\[ H(f) = \frac{S_X(f)}{S_X(f) + S_N(f)}. \]

이 필터는 신호가 강한 주파수는 통과시키고(H ≈ 1), 잡음이 강한 주파수는 억제한다(H ≈ 0). 그래서 사진의 잡음 제거, 음성 향상, 통신의 채널 등화에 쓰이며, 실시간(인과) 필터와 적응 필터(LMS)도 이 원리를 바탕으로 한다.

정합 필터(6.1절)와 비교하면 목적이 다르다. 정합 필터는 펄스가 있는지 판정하려고 한 시각의 SNR을 최대로 하고, Wiener 필터는 파형 전체를 복원하려고 MSE를 최소로 한다. 즉 목적이 다르면 최적 필터도 달라진다.

흔한 오해잡음이 섞인 관측을 그대로 쓰는 것이 편향이 없어 최선이라고 여기기 쉽다. 하지만 MSE로 보면 약간 줄여 쓰는 편이 나으며, 이는 편향과 분산의 절충이다. Wiener 필터는 신호를 몰라도 된다는 생각도 틀리다. 신호와 잡음의 PSD, 곧 통계는 알아야 하며, 모르면 측정으로 추정하거나 적응 필터를 쓴다.
마무리

최적 선형 추정에서는 오차와 관측이 무상관이라는 직교 원리가 성립한다. 한 개의 값이면 \(a = \sigma_X^2/(\sigma_X^2 + \sigma_N^2)\), MSE는 \(\sigma_X^2\sigma_N^2/(\sigma_X^2 + \sigma_N^2)\)이다. 주파수 영역의 Wiener 필터는 \(H = S_X/(S_X + S_N)\)이며, 정합 필터와 목적이 다르다.

6.2.3연습문제

기본

  1. \(\sigma_X^2 = \sigma_N^2 = 1\)이면 최적 a와 MSE는?
    답

    a = 0.5, MSE = 0.5이다.

응용

  1. 관측이 두 개 \(Y_1 = X + N_1\), \(Y_2 = X + N_2\)(잡음 독립, 분산 1, \(\sigma_X^2 = 4\))일 때 대칭성으로 \(\hat X = b(Y_1 + Y_2)\)의 최적 b와 MSE는?
    답

    S = Y₁ + Y₂로 두고 \(E[(X - bS)S] = 0\)을 쓴다. \(E[XS] = 8\), \(E[S^2] = 16 + 2 = 18\)이므로 b = 4/9이고, MSE = 4 − 8b = 4 − 32/9 = 4/9이다.

심화

  1. 어떤 주파수에서 SNR(\(S_X/S_N\))이 9이면 Wiener 필터 이득과 그 주파수의 오차 PSD 비율은?
    답

    H = 0.9이고, 오차 PSD는 \(S_XS_N/(S_X+S_N) = 0.9S_N\)이다.
