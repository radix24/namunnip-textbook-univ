AM 신호는 WSS인가

예제 · 평균과 자기상관 조건 확인

먼저 예측

메시지가 WSS여도 반송파를 곱한 AM 신호가 WSS가 아닐 수 있을까요?

생각해 본 뒤 열기

반송파 위상이 고정이면 자기상관이 시간에 따라 출렁여 WSS가 아닙니다. 위상이 무작위면 WSS입니다.

문제

메시지 M(t)는 평균 0, 자기상관 \(R_M(\tau)\)인 WSS. (가) \(X(t) = M(t)\cos\omega_ct\), (나) \(Y(t) = M(t)\cos(\omega_ct + \Theta)\), Θ ~ 균일(0, 2π), M과 독립. 각각 WSS인지 판정하라.

전략

  1. 평균부터.
  2. 곱을 합으로: cos A cos B = ½[cos(A − B) + cos(A + B)].

풀이

  1. (가) 평균 0. \(R_X = R_M(\tau)\cos\omega_ct\cos\omega_c(t+\tau) = \frac{R_M(\tau)}{2}[\cos\omega_c\tau + \cos(2\omega_ct + \omega_c\tau)]\). t에 의존 → WSS 아님(주기 정상). (가)
  2. (나) 평균 0. Θ 평균을 내면 \(\cos(2\omega_ct + \omega_c\tau + 2\Theta)\) 항이 사라져 \(R_Y = \frac{R_M(\tau)}{2}\cos\omega_c\tau\) → WSS. (나)
  3. (나)의 PSD는 \(\frac14[S_M(f - f_c) + S_M(f + f_c)]\): 메시지 스펙트럼이 ±f_c로 옮겨진다. PSD

의미

(가)처럼 통계가 주기적으로 변하는 신호를 주기 정상(cyclostationary)이라 하며, 시간 평균한 자기상관을 쓰면 (나)와 같은 결과가 나옵니다. 통신 신호의 스펙트럼을 계산할 때 무작위 위상을 넣는 이유입니다.

검산

(나)에서 τ = 0이면 \(R_Y(0) = R_M(0)/2\): AM 신호 전력은 메시지 전력의 절반(cos²의 평균 1/2)입니다.

이해 확인

M(t)가 상수 1(랜덤 아님)이고 위상이 무작위면 Y(t)의 자기상관은?

답

\(\frac12\cos\omega_c\tau\): 4.1절의 무작위 위상 정현파.
