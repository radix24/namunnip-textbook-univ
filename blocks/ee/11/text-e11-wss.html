광의 정상성(WSS) 판정

본문
이 절에서 배울 것
  • 광의 정상(WSS)의 두 조건(평균 일정, 자기상관이 시간 차만의 함수)을 판정한다.
  • WSS 자기상관의 성질(R(0) 최대, 짝함수)을 안다.
  • 에르고딕성(시간 평균 = 앙상블 평균)의 뜻과 측정에서의 쓰임을 안다.
먼저 알아야 할 것
  • 평균과 자기상관 (4.1절), 이 절의 예제는 4.1절 탐구 카드로 확인할 수 있습니다.

4.2.1정의

광의 정상(WSS): (1) \(m_X(t) = \mu\)(상수), (2) \(R_X(t, t + \tau) = R_X(\tau)\)(t와 무관).

강정상: 모든 결합 분포가 시간 이동에 불변. WSS보다 강한 조건. 가우시안 프로세스는 WSS면 강정상.

WSS의 자기상관은 짝함수 \(R(-\tau) = R(\tau)\)이고, \(|R(\tau)| \le R(0) = E[X^2]\)(평균 전력)입니다.

예제 4.2.1

다음이 WSS인지 판정하라. (가) \(X(t) = \cos(\omega_0t + \Theta)\), Θ ~ 균일(0, 2π). (나) Θ ~ 균일(0, π/2). (다) \(X(t) = A\cos\omega_0t + B\sin\omega_0t\), A, B 독립, 평균 0, 분산 σ².

풀이. (가) 4.1절: 평균 0, \(R = \frac12\cos\omega_0\tau\) → WSS. (나) \(E[X(t)] = \frac{2}{\pi}\int_0^{\pi/2}\cos(\omega_0t + \theta)d\theta = \frac{2}{\pi}[\sin(\omega_0t + \pi/2) - \sin\omega_0t]\)로 t에 따라 변해 WSS가 아닙니다(4.1절 탐구 카드의 0.634와 −0.642). (다) 평균 0. \(R = E[A^2]\cos\omega_0t\cos\omega_0(t+\tau) + E[B^2]\sin\omega_0t\sin\omega_0(t+\tau) = \sigma^2\cos\omega_0\tau\)(교차항은 독립·평균 0이라 사라짐) → WSS.

4.2.2에르고딕성

실험실에서는 표본 경로 하나를 오래 측정할 뿐, 앙상블을 모을 수 없습니다. 시간 평균이 앙상블 평균과 같아지는 프로세스를 에르고딕이라 하며, 이때 한 번의 긴 측정으로 평균, 자기상관, 스펙트럼(5장)을 추정할 수 있습니다. 예제 (가)는 평균에 대해 에르고딕이지만, 4.1절 연습의 \(A\cos\omega_0t\)(A 랜덤)처럼 표본마다 진폭이 다르면 한 경로의 시간 평균으로 A의 분포를 알 수 없습니다.

흔한 오해(1) "평균이 일정하면 WSS": 자기상관 조건도 필요합니다. (2) "WSS면 표본 경로가 일정하다": 통계가 시간에 따라 변하지 않는다는 뜻이지 신호는 계속 변합니다. (3) 실제 신호는 엄밀히 WSS가 아니어도, 관찰 구간에서 통계가 거의 일정하면 WSS로 다룹니다(음성은 수십 ms 단위로).
요약
  1. WSS: 평균 상수, R이 τ만의 함수.
  2. R은 짝함수, R(0) = 평균 전력이 최대.
  3. 에르고딕이면 한 경로의 시간 평균으로 통계를 추정할 수 있다.

4.2.3연습문제

기본

  1. R(τ) = 3e^{−|τ|} + 1인 WSS 프로세스의 평균 전력은?
    답

    R(0) = 4.

응용

  1. X(t) = Y(t)cos ω₀t(Y는 WSS, 평균 0, Θ 없음)는 WSS인가?
    답

    \(R = R_Y(\tau)\cos\omega_0t\cos\omega_0(t+\tau)\)로 t에 의존해 WSS가 아닙니다. 무작위 위상을 더하면 WSS가 됩니다.

심화

  1. R(τ) = cos τ + 2인 WSS에서 \(|R(\tau)| \le R(0)\)을 확인하고, 평균의 크기를 어림하라.
    답

    R(0) = 3이 최대. τ가 커져도 상수 2가 남는 것은 평균이 0이 아님을 뜻하며, \(\mu^2 = 2\)로 볼 수 있습니다(주기 성분 제외).
