균일 분포를 더하면 종 모양이 된다

탐구 · 중심극한정리 모의 실험

질문

평평한 균일 분포 몇 개를 더하면 가우시안처럼 보일까요? 꼬리 확률까지 맞을까요?

준비

균일(0, 1) n개의 합을 20,000번 뽑아 평균 0, 분산 1로 표준화한 히스토그램(연보라)과 표준 정규 밀도(빨강)를 비교합니다. 꼬리 확률 P(|z| > 2)와 4차 모멘트(정규 분포면 3)도 적습니다. 난수는 매번 같은 씨앗을 쓰므로 결과가 재현됩니다.

해 보기와 설명

  1. n = 1평평한 사각형이고 |z|의 최대가 √3 ≈ 1.73이라 |z| > 2인 비율이 0, 4차 모멘트 1.80입니다.
  2. 처음 화면 n = 3이미 종 모양에 가깝지만 꼬리 비율 0.0404로 정규(0.0455)보다 작고, 4차 모멘트 2.58입니다.
  3. n = 12꼬리 0.0454, 4차 모멘트 2.93으로 정규와 거의 같습니다(예제 3.2.1). n = 30에서는 0.0457, 3.03.
  4. n = 2삼각형 분포가 나옵니다(꼬리 0.0348, 모멘트 2.44). 두 균일 분포의 합의 밀도는 사각형끼리의 컨볼루션입니다(신호및시스템).

연결과 적용

합의 밀도가 원래 밀도를 거듭 컨볼루션한 것이고, 컨볼루션을 반복하면 어떤 모양이든 가우시안으로 수렴한다는 것이 중심극한정리의 다른 얼굴입니다. 열잡음, 측정 오차의 평균, 많은 사용자의 간섭 합이 가우시안으로 모형화되는 근거입니다.

흔한 오해

  • "n이 크면 각 표본이 가우시안이 된다." 가우시안에 가까워지는 것은 합(또는 평균)의 분포입니다.
  • "모양이 비슷하면 꼬리도 맞는다." n = 3에서 보듯 모양은 비슷해도 꼬리 확률은 아직 다릅니다.
