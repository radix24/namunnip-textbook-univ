최소 평균제곱 선형 추정

본문
이 절에서 배울 것
  • 관측 Y로 X를 \(\hat X = aY + b\)로 추정할 때 평균제곱오차를 최소화하는 a, b를 구한다.
  • 직교 원리(오차와 관측이 무상관)를 안다.
  • 잡음 섞인 측정에서 신호를 추정한다.
먼저 알아야 할 것
  • 공분산 (3.3절), Wiener 필터 (6.2절).

6.3.1직교 원리

\(E[(X - aY - b)^2]\)를 a, b로 미분해 0으로 두면 \(a = \text{Cov}(X, Y)/\text{Var}Y\), \(b = E[X] - aE[Y]\). 최적일 때 오차 \(X - \hat X\)는 관측 Y와 무상관(직교)입니다. Wiener 필터는 이것을 신호 전체로 넓힌 것입니다.

예제 6.3.1

Y = X + N, X와 N은 독립, 평균 0, Var X = 1, Var N = 0.25. 최적 a와 최소 평균제곱오차는?

풀이. Cov(X, Y) = 1, Var Y = 1.25 → a = 0.8. 오차 분산 = Var X − a·Cov = 1 − 0.8 = 0.2. 측정값을 그대로 쓰면(a = 1) 오차 0.25인데, 신호와 잡음의 비에 맞춰 조금 줄여 쓰면 0.2로 작아집니다.

흔한 오해(1) "측정값을 그대로 쓰는 것이 최선": 잡음이 있으면 줄여(축소) 쓰는 것이 낫습니다. (2) "선형 추정이 언제나 최적": 가우시안일 때만 모든 추정 중 최적입니다.
요약
  1. a = Cov(X, Y)/Var Y, b = E[X] − aE[Y].
  2. 오차 ⟂ 관측(직교 원리).
  3. 예: SNR 4 → a = 0.8, 오차 0.2.

6.3.2연습문제

기본

  1. Var N = 0이면 a는?
    답

    1.

응용

  1. Var X = Var N = 1이면 a와 오차는?
    답

    0.5, 0.5.

심화

  1. SNR이 매우 낮으면 추정은?
    답

    a → 0으로 평균 E[X]에 가까워집니다.
