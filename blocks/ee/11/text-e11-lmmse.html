최소 평균제곱 선형 추정

본문

온도 센서의 읽음 Y에는 잡음이 섞여 있고, 우리는 그것으로 실제 온도 X를 추정하려 한다. 추정을 aY + b 꼴의 직선으로 제한할 때 가장 좋은 a와 b는 무엇일까? 그 최적 추정의 오차에는 어떤 특별한 성질이 있어서, 그 성질만으로 답을 곧바로 얻을 수 있을까?

먼저 알아야 할 것공분산(3.3절), Wiener 필터(6.2절)를 쓴다.

6.3.1직교 원리

평균 제곱 오차 \(E[(X - aY - b)^2]\)를 \(a\), \(b\)로 각각 미분해 0으로 두면 처음 질문의 첫째 답을 얻는다. 기울기는 \(a = \mathrm{Cov}(X, Y)/\mathrm{Var}Y\)이고, 절편은 \(b = E[X] - aE[Y]\)이다. 이것이 선형 최소 평균 제곱 오차(LMMSE) 추정이다.

이때 오차 \(X - \hat X\)는 관측 \(Y\)와 무상관, 곧 직교한다. 처음 질문의 둘째 답이 이것으로, 미분 대신 "오차는 관측과 직교한다"는 조건 하나만 세워도 같은 \(a\)가 나온다. 기하학적으로는 \(E[XY]\)를 내적으로 보고 \(X\)를 \(Y\) 위로 정사영한 것이며, 수선이 가장 짧은 거리이므로 오차가 최소이다(그림 1). 6.2절의 Wiener 필터는 이 원리를 신호 전체로 넓힌 것이다.

예제 6.3.1

Y = X + N, X와 N은 독립, 평균 0, Var X = 1, Var N = 0.25. 최적 a와 최소 평균제곱오차는?

풀이. Cov(X, Y) = 1, Var Y = 1.25이므로 a = 0.8이다. 오차 분산은 Var X − a·Cov = 1 − 0.8 = 0.2이다. 측정값을 그대로 쓰면(a = 1) 오차가 0.25인데, 신호와 잡음의 비에 맞춰 조금 줄여 쓰면 0.2로 작아진다.

오차 분산 0.2는 피타고라스 정리로도 읽을 수 있다. 그림 1의 직각 삼각형에서 빗변 \(X\)의 길이 제곱 1은 정사영 \(aY\)의 길이 제곱 \(0.8^2 \times 1.25 = 0.8\)과 오차의 길이 제곱의 합이다. 그러므로 오차의 길이 제곱은 1 − 0.8 = 0.2이다. 일반적으로는 최소 오차 분산이 \((1 - \rho^2)\mathrm{Var}X\)이며, 여기서 \(\rho^2 = 1/1.25 = 0.8\)이다(3.3절).

흔한 오해측정값을 그대로 쓰는 것이 최선이라고 여기기 쉽지만, 잡음이 있으면 줄여 쓰는 축소 추정이 낫다. 선형 추정이 언제나 최적이라는 생각도 틀리다. 선형 추정은 직선 중에서만 최적이며, X와 Y가 결합 가우시안일 때만 모든 추정 가운데 최적이다.
마무리

LMMSE 추정의 기울기는 \(a = \mathrm{Cov}(X, Y)/\mathrm{Var}Y\), 절편은 \(b = E[X] - aE[Y]\)이다. 최적일 때 오차는 관측과 직교하며, 기하학적으로는 정사영이다. 신호 대 잡음 비가 4이면 a = 0.8, 오차 분산은 0.2이다.

6.3.2연습문제

기본

  1. Var N = 0이면 a는?
    답

    1이다.

응용

  1. Var X = Var N = 1이면 a와 오차는?
    답

    a = 0.5, 오차 분산 0.5이다.

심화

  1. SNR이 매우 낮으면 추정은?
    답

    a → 0이 되어 추정값이 평균 E[X]에 가까워진다.
