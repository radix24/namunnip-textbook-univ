공분산, 상관 계수, 독립

본문
이 절에서 배울 것
  • 공분산 \(\text{Cov}(X, Y) = E[XY] - E[X]E[Y]\)와 상관 계수 ρ를 계산한다.
  • 독립이면 무상관이지만 그 역은 성립하지 않음을 예로 보인다.
  • 합의 분산 \(\text{Var}(X + Y) = \text{Var}X + \text{Var}Y + 2\text{Cov}\)를 쓴다.
먼저 알아야 할 것
  • 결합분포 (3.1절).

3.3.1선형 관계의 세기

\(\rho = \text{Cov}(X, Y)/(\sigma_X\sigma_Y)\), −1 ≤ ρ ≤ 1. ρ = 0(무상관)은 선형 관계가 없다는 뜻이고, 독립보다 약한 조건입니다.

예제 3.3.1

X가 −1, 0, 1을 같은 확률로 갖고 Y = X²이다. 공분산은? 독립인가?

풀이. E[X] = 0, E[XY] = E[X³] = 0 → Cov = 0(무상관). 그러나 X를 알면 Y가 정해지므로 독립이 아닙니다. 가우시안 결합 분포일 때만 무상관이 독립과 같습니다.

흔한 오해(1) "상관 0이면 관계가 없다": 비선형 관계는 있을 수 있습니다. (2) "분산은 항상 더해진다": 상관이 있으면 2Cov가 더해지거나 빠집니다.
요약
  1. Cov = E[XY] − E[X]E[Y], ρ ∈ [−1, 1].
  2. 독립 ⇒ 무상관, 역은 거짓(가우시안 예외).
  3. Var(X + Y) = VarX + VarY + 2Cov.

3.3.2연습문제

기본

  1. Var X = 4, Var Y = 9, ρ = 0.5의 Cov는?
    답

    3.

응용

  1. 같은 경우 Var(X + Y)는?
    답

    4 + 9 + 6 = 19.

심화

  1. X − Y의 분산은?
    답

    4 + 9 − 6 = 7.
