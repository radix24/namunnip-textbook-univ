랜덤변수의 함수의 분포

본문

잡음 전압을 제곱 검파기에 넣으면 출력은 전압의 제곱이다. 입력 전압의 분포를 알 때 출력의 분포는 어떻게 될까? 입력이 −1에서 1 사이에 고르게 퍼져 있으면 제곱한 값도 0에서 1 사이에 고르게 퍼질까?

먼저 알아야 할 것대표 분포(2.1절), 미분과 합성 함수의 미분(미적분)을 쓴다.

2.2.1CDF부터

\(Y = g(X)\)의 분포를 구하는 가장 안전한 방법은 누적분포 \(F_Y(y) = P(Y \le y) = P(g(X) \le y)\)를 \(X\)의 사건으로 바꿔 구한 뒤 미분하는 것이다. 사건만 바르게 옮기면 함수가 어떤 모양이든 실수할 일이 적다.

\(g\)가 단조 증가이면 \(F_Y(y) = F_X(g^{-1}(y))\)이고, 미분하면 \(f_Y(y) = f_X(x)\left|\dfrac{dx}{dy}\right|\)(단 \(x = g^{-1}(y)\))이다. 여기서 \(|dx/dy|\)는 \(x\)의 작은 구간이 \(y\)에서 얼마나 늘어나거나 줄어드는지를 보정한다. 확률, 곧 넓이는 변하지 않으므로 구간이 늘면 밀도는 줄고 구간이 줄면 밀도는 커진다.

2.2.2예: 선형, 제곱

선형 변환 \(Y = aX + b\)이면 \(f_Y(y) = \frac{1}{|a|}f_X\left(\frac{y - b}{a}\right)\)이다. 모양은 그대로이고 위치와 폭만 바뀌므로, 가우시안의 선형 변환은 다시 가우시안이다. 증폭기 이득과 직류 오프셋을 거친 잡음이 여전히 가우시안인 까닭이 이것이다.

제곱 \(Y = X^2\)은 단조가 아니어서 한 \(y\)에 두 근 \(\pm\sqrt y\)가 대응한다. 그래서 \(F_Y(y) = P(-\sqrt y \le X \le \sqrt y)\)에서 출발하면 \(f_Y(y) = \frac{f_X(\sqrt y) + f_X(-\sqrt y)}{2\sqrt y}\)(\(y > 0\))을 얻는다. 처음 질문의 답이 이 식이다(그림 1).

예제 2.2.1

잡음 전압 X ~ N(0, σ²)를 제곱 검파기(Y = X²)에 넣는다. (가) Y의 밀도, (나) E[Y], (다) X가 균일(−1, 1)이면 Y의 밀도와 P(Y ≤ 0.25).

풀이. (가) \(f_Y(y) = \frac{1}{\sqrt{2\pi\sigma^2 y}}e^{-y/(2\sigma^2)}\)(\(y > 0\))이며, 자유도 1인 카이제곱 분포의 σ² 배이다. (나) \(E[Y] = E[X^2] = \sigma^2\)이므로 검파기 출력의 평균이 곧 잡음 전력이다. (다) \(f_X = 1/2\)이므로 \(f_Y(y) = \frac{1/2 + 1/2}{2\sqrt y} = \frac{1}{2\sqrt y}\)(\(0 < y < 1\))이다. 그러면 \(P(Y \le 0.25) = P(|X| \le 0.5) = 0.5\)이고, 밀도로 적분해도 \(\int_0^{0.25}\frac{dy}{2\sqrt y} = \sqrt{0.25} = 0.5\)로 같다.

흔한 실수\(f_Y(y) = f_X(g^{-1}(y))\)로 쓰고 기울기 보정 \(|dx/dy|\)를 빠뜨리는 실수가 흔하며, 그러면 넓이가 1이 되지 않는다. 단조가 아닌 함수에서 한 근만 쓰는 것도 틀리며, \(X^2\)에서는 \(\pm\sqrt y\) 두 근을 모두 더한다. 또 \(E[g(X)]\)는 \(g(E[X])\)와 다르다. 예제에서 \(E[X] = 0\)이지만 \(E[X^2] = \sigma^2\)이다.
마무리

랜덤변수의 함수의 분포는 CDF로 바꿔 구하고 미분하는 것이 가장 안전하다. 단조 함수이면 \(f_Y = f_X|dx/dy|\)이고, 근이 여러 개이면 모두 더한다. 기댓값은 함수를 통과하지 않아서 \(E[g(X)] \ne g(E[X])\)이다.

2.2.3연습문제

기본

  1. X ~ N(0, 1)일 때 Y = 2X + 3의 분포는?
    답

    N(3, 4)이다.

응용

  1. X가 균일(0, 1)일 때 Y = −ln X의 분포는?
    답

    \(P(Y \le y) = P(X \ge e^{-y}) = 1 - e^{-y}\)이므로 지수(1)이다. 균일 난수로 지수 난수를 만드는 방법이 이것이다.

심화

  1. X ~ N(0, σ²)를 반파 정류(Y = max(X, 0))하면 Y의 분포와 E[Y]는?
    답

    P(Y = 0) = 1/2인 점 질량과, y > 0에서 가우시안 밀도의 절반이 합쳐진 분포이다. \(E[Y] = \sigma/\sqrt{2\pi} \approx 0.399\sigma\)이다.
