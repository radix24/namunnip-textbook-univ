결합 가우시안과 선형 변환

본문
이 절에서 배울 것
  • 두 랜덤변수의 공분산과 상관계수의 뜻을 안다.
  • 가우시안 랜덤 벡터의 선형 결합이 다시 가우시안이며, 평균과 공분산을 계산한다.
  • 무상관이면 독립이라는 가우시안만의 성질과 그 쓰임을 안다.
먼저 알아야 할 것
  • 대표 분포 (2.1절), 행렬 곱 (전전16 1.1절 또는 공통2).

3.1.1공분산

공분산 \(\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)]\). 같이 커지면 양, 반대로 움직이면 음.

상관계수 \(\rho = \mathrm{Cov}(X, Y)/(\sigma_X\sigma_Y)\), −1 ≤ ρ ≤ 1.

공분산 행렬 \(\mathbf K\): 대각선은 각 변수의 분산, 나머지는 공분산.

3.1.2선형 변환

\(\mathbf Y = \mathbf A\mathbf X + \mathbf b\)이면 \(E[\mathbf Y] = \mathbf A\boldsymbol\mu + \mathbf b\), \(\mathbf K_Y = \mathbf A\mathbf K_X\mathbf A^T\)입니다. X가 결합 가우시안이면 Y도 결합 가우시안이라, 평균과 공분산만으로 분포가 완전히 정해집니다. 두 변수만 볼 때는 행렬 없이

\[ \mathrm{Var}(aX + bY) = a^2\sigma_X^2 + b^2\sigma_Y^2 + 2ab\,\mathrm{Cov}(X, Y) \]

로 계산할 수 있습니다.

예제 3.1.1

두 안테나의 잡음 \(N_1, N_2\)가 평균 0, 분산 각각 1, 상관계수 ρ인 결합 가우시안이다. 합 \(S = N_1 + N_2\)와 차 \(D = N_1 - N_2\)의 분산과 공분산을 구하고, ρ = 0, 0.5, −0.5일 때 비교하라.

풀이. Var(S) = 1 + 1 + 2ρ = 2 + 2ρ, Var(D) = 2 − 2ρ, Cov(S, D) = Var(N₁) − Var(N₂) = 0. ρ = 0: 둘 다 2. ρ = 0.5: S는 3, D는 1(잡음이 닮으면 빼서 줄일 수 있음, 차동 신호의 원리). ρ = −0.5: S는 1, D는 3. S와 D는 공분산이 0인 결합 가우시안이므로 독립입니다.

흔한 오해(1) "무상관이면 언제나 독립이다": 결합 가우시안일 때만 그렇습니다. X ~ N(0, 1)과 X²는 무상관이지만 독립이 아닙니다. (2) "각각 가우시안이면 결합 가우시안이다": 각 변수가 가우시안이어도 결합 분포는 아닐 수 있습니다. (3) 분산의 합은 공분산이 0일 때만 단순 합입니다.
요약
  1. Cov, ρ. 공분산 행렬의 대각선은 분산.
  2. \(\mathbf Y = \mathbf A\mathbf X + \mathbf b\): 평균 \(\mathbf A\boldsymbol\mu + \mathbf b\), 공분산 \(\mathbf A\mathbf K\mathbf A^T\), 여전히 가우시안.
  3. 결합 가우시안에서 무상관 ⇔ 독립.

3.1.3연습문제

기본

  1. X, Y가 독립이고 분산 4, 9이면 Var(2X − Y)는?
    답

    16 + 9 = 25.

응용

  1. 예제에서 ρ = 0.8이면 S와 D의 분산은?
    답

    3.6, 0.4.

심화

  1. X ~ N(0, 1), Y = X², Cov(X, Y)를 구하고 독립인지 판정하라.
    답

    Cov = E[X³] − E[X]E[X²] = 0. 그러나 Y가 X로 정해지므로 독립이 아닙니다.
