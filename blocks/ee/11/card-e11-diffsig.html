차동 신호가 공통 잡음을 지우는 원리

예제 · 가우시안 벡터의 선형 변환

먼저 예측

두 선에 같은 잡음이 섞이면, 두 선의 차를 받는 것이 왜 유리할까요?

생각해 본 뒤 열기

공통 잡음은 차에서 지워지고, 서로 다른 잡음만 남습니다.

문제

두 선의 전압 \(V_1 = s + N_1\), \(V_2 = -s + N_2\). 잡음은 평균 0, 분산 \(\sigma^2\), 상관계수 ρ인 결합 가우시안. 차 \(D = V_1 - V_2\)의 신호 성분, 잡음 분산, SNR을 한 선만 받을 때(\(V_1\))와 비교하라. ρ = 0.9이면?

전략

  1. D = 2s + (N₁ − N₂).
  2. Var(N₁ − N₂) = 2σ² − 2ρσ².

풀이

  1. D의 신호 2s, 잡음 분산 \(2\sigma^2(1 - \rho)\). SNR \(= 4s^2/(2\sigma^2(1-\rho)) = \frac{2}{1-\rho}\cdot\frac{s^2}{\sigma^2}\). 선형 변환
  2. 한 선: SNR \(s^2/\sigma^2\). 비교
  3. ρ = 0: 2배(3 dB), ρ = 0.9: 20배(13 dB). 수치

의미

잡음이 두 선에 닮게 들어갈수록(ρ → 1) 차동 수신의 이득이 커집니다. 꼬임쌍선(이더넷), USB, 차동 증폭기(전전8 6단원)가 이 원리를 씁니다. 결과 D도 가우시안이라 오류 확률을 Q 함수로 바로 구할 수 있습니다.

검산

ρ = 1이면 잡음 분산 0으로 완전히 지워집니다. ρ = −1이면 4σ²로 오히려 커집니다.

이해 확인

ρ = 0.5일 때 차동 수신의 SNR 이득은?

답

2/(1 − 0.5) = 4배, 약 6 dB.
