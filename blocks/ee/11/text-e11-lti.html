LTI 시스템을 지난 랜덤 신호

본문
이 절에서 배울 것
  • WSS 입력이 LTI 시스템을 지나면 출력도 WSS이고 평균이 \(\mu H(0)\)임을 안다.
  • 출력 PSD \(S_Y(f) = |H(f)|^2S_X(f)\)로 출력 전력을 계산한다.
  • RC 저역 통과 필터가 백색 잡음을 거르는 양을 계산한다.
먼저 알아야 할 것
  • PSD (5.1절), 주파수 응답 (전전6 4.3절), RC 필터 (전전3 8.2절).

5.2.1입출력 관계

출력 \(Y(t) = \int h(s)X(t - s)ds\)의 평균은 \(\mu_Y = \mu_X\int h = \mu_XH(0)\)이고, 자기상관을 계산해 Fourier 변환하면

\[ S_Y(f) = |H(f)|^2S_X(f). \]

위상은 전력에 영향이 없고 크기 응답의 제곱만 들어갑니다. 출력 전력은 \(\int|H(f)|^2S_X(f)df\).

예제 5.2.1

양측 PSD \(N_0/2\)인 백색 잡음을 RC 저역 통과 필터(\(|H|^2 = 1/(1 + (f/f_c)^2)\), \(f_c = 1/(2\pi RC)\))에 넣는다. 출력 전력은? \(N_0/2 = 5\times10^{-9}\) V²/Hz, \(f_c\) = 10 kHz이면 출력 잡음의 실효값은?

풀이. \(P = \frac{N_0}{2}\int\frac{df}{1 + (f/f_c)^2} = \frac{N_0}{2}\cdot\pi f_c = \frac{N_0}{4RC}\). 수치: \(5\times10^{-9} \times \pi \times 10^4 = 1.571\times10^{-4}\) V², 실효값 12.5 mV. 차단 주파수를 반으로 줄이면 전력도 반, 실효값은 \(1/\sqrt2\)배입니다.

흔한 오해(1) "\(S_Y = H(f)S_X(f)\)": 전력이므로 |H|²입니다. (2) "필터의 −3 dB 대역폭으로 잡음 전력을 계산하면 된다": 1차 RC는 −3 dB 대역보다 π/2배 넓은 잡음 등가 대역폭을 써야 정확합니다(5.3절). (3) 출력 평균은 직류 이득 H(0)만 곱해집니다.
요약
  1. WSS 입력 → WSS 출력, \(\mu_Y = \mu_XH(0)\).
  2. \(S_Y = |H|^2S_X\). 위상은 전력과 무관.
  3. RC + 백색: 출력 전력 \(N_0/(4RC)\).

5.2.2연습문제

기본

  1. 이득 10인 이상 증폭기(모든 주파수)에 PSD 1e−9 V²/Hz 백색 잡음을 넣으면 출력 PSD는?
    답

    1e−7 V²/Hz(|H|² = 100).

응용

  1. 예제에서 RC를 두 배로 하면 출력 실효값은?
    답

    \(1/\sqrt2\)배, 약 8.86 mV.

심화

  1. 평균 2 V, 공분산 무시할 수 있는 입력을 H(0) = 0인 고역 통과 필터에 넣으면 출력 평균은?
    답

    0. 직류 성분이 걸러집니다(결합 축전기).
