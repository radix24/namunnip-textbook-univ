랜덤 프로세스의 평균과 자기상관

본문
이 절에서 배울 것
  • 랜덤 프로세스를 시간마다의 랜덤변수 모음이자 표본 경로의 모음으로 이해한다.
  • 평균 함수 \(m(t)\)와 자기상관 함수 \(R(t_1, t_2) = E[X(t_1)X(t_2)]\)를 계산한다.
  • 무작위 위상 정현파와 무작위 전신 신호의 자기상관을 구한다.
먼저 알아야 할 것
  • 결합 분포와 공분산 (3.1절), 삼각함수 곱을 합으로(고교 수학), 이 절의 탐구 카드.

4.1.1두 가지 시각

랜덤 프로세스 X(t)는 실험 한 번마다 시간 함수 하나(표본 경로)가 나오는 것입니다. 시각 t를 고정하면 X(t)는 랜덤변수이고, 실험 결과를 고정하면 보통의 시간 함수입니다. 평균과 상관은 같은 시각에서 수많은 표본 경로를 평균하는 앙상블 평균으로 정의합니다.

평균 함수 \(m_X(t) = E[X(t)]\).

자기상관 \(R_X(t_1, t_2) = E[X(t_1)X(t_2)]\). 두 시각의 값이 얼마나 닮았는가.

4.1.2무작위 위상 정현파

예제 4.1.1

\(X(t) = A\cos(\omega_0t + \Theta)\), A와 ω₀는 상수, Θ ~ 균일(0, 2π). 평균과 자기상관을 구하라.

풀이. \(E[X(t)] = \frac{A}{2\pi}\int_0^{2\pi}\cos(\omega_0t + \theta)d\theta = 0\)(한 주기 적분). 곱을 합으로 바꾸면 \(X(t)X(t + \tau) = \frac{A^2}{2}[\cos\omega_0\tau + \cos(2\omega_0t + \omega_0\tau + 2\Theta)]\)이고 둘째 항의 평균이 0이므로

\[ R_X(t, t + \tau) = \frac{A^2}{2}\cos\omega_0\tau. \]

t에 의존하지 않고 시간 차 τ만의 함수입니다(4.2절의 WSS). τ = 0에서 \(A^2/2\)로 평균 전력과 같습니다. 탐구 카드에서 표본 2000개로 τ = 0.5일 때 t = 0과 0.25의 값이 −0.519, −0.481(이론 −0.5)로 나옵니다.

Θ가 균일(0, π/2)처럼 한쪽으로 치우치면 평균이 t에 따라 변하고(카드에서 t = 0에 0.634, t = 0.25에 −0.642) 자기상관도 t에 의존합니다.

4.1.3무작위 전신 신호

±1 사이를 포아송 시각(비율 α)에 뒤집히는 신호는 \(R(\tau) = e^{-2\alpha|\tau|}\)입니다. τ 동안 짝수 번 뒤집히면 같고 홀수 번이면 반대인 확률의 차이로 구합니다. 오래 떨어진 두 값은 서로 닮지 않습니다(상관이 0으로).

흔한 오해(1) "자기상관은 한 표본 경로에서 시간 평균으로 구한다": 정의는 앙상블 평균입니다. 둘이 같아지는 성질이 에르고딕성입니다. (2) "평균이 0이면 자기상관도 0": 무작위 위상 정현파는 평균 0이지만 \(R(0) = A^2/2\)입니다.
요약
  1. 프로세스 = 시각마다의 랜덤변수 = 표본 경로의 모음.
  2. \(m(t) = E[X(t)]\), \(R(t_1, t_2) = E[X(t_1)X(t_2)]\)(앙상블 평균).
  3. 무작위 위상 정현파: \(R = (A^2/2)\cos\omega_0\tau\). 전신 신호: \(e^{-2\alpha|\tau|}\).

4.1.4연습문제

기본

  1. 예제에서 A = 2이면 R(0)과 평균 전력은?
    답

    2, 2 W(1 Ω 기준).

응용

  1. X(t) = A cos ω₀t, A ~ N(0, 1)(위상 고정)의 평균과 자기상관은?
    답

    평균 0, \(R(t_1, t_2) = \cos\omega_0t_1\cos\omega_0t_2\). 시각 차만의 함수가 아닙니다.

심화

  1. 무작위 전신 신호(α = 100 /s)에서 상관이 1/e로 줄어드는 시간 차는?
    답

    \(2\alpha\tau = 1\), τ = 5 ms.
