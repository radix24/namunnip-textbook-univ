심박 변이도 지표 계산

본문
이 절에서 배울 것
  • RR 간격 열에서 평균 심박수, SDNN, RMSSD를 계산한다.
  • 시간 영역 지표의 의미(전체 변동, 박동 간 변동)를 안다.
  • 측정 길이와 이상 박동 제거의 필요를 안다.
먼저 알아야 할 것
  • R 피크 검출 (6.1절).

6.3.1간격의 흔들림

SDNN은 RR 간격의 표준편차(전체 변동), RMSSD는 이웃 간격 차이의 제곱 평균 제곱근(박동 간 빠른 변동, 부교감 신경 활동 반영)입니다.

import statistics as st, math
rr = [812, 798, 845, 870, 822, 790, 805, 860, 885, 830]      # ms
hr = 60000 / st.mean(rr)
sdnn = st.stdev(rr)
d = [b - a for a, b in zip(rr, rr[1:])]
rmssd = math.sqrt(sum(x * x for x in d) / len(d))
print(f"평균 RR {st.mean(rr):.1f} ms, 평균 심박수 {hr:.1f} bpm")
print(f"SDNN {sdnn:.1f} ms, RMSSD {rmssd:.1f} ms")

실행 결과(Python 3.12에서 실제 실행):

평균 RR 831.7 ms, 평균 심박수 72.1 bpm
SDNN 32.2 ms, RMSSD 38.4 ms
예제 6.3.1

위 결과에서 평균 심박수와 두 지표는? 이상 박동 하나(RR 400 ms)가 섞이면 어떻게 되는가?

풀이. 실행 결과의 값이 각 지표입니다. 400 ms 같은 조기 박동이 섞이면 SDNN과 RMSSD가 크게 부풀어 해석이 틀리므로, 이상 박동을 먼저 걸러 냅니다(NN 간격). 짧은 기록(수십 박동)은 장기 기록(24시간)과 직접 비교하지 않습니다.

흔한 오해(1) "HRV가 크면 나쁘다": 휴식 시 큰 HRV는 대체로 건강한 자율 신경 조절을 뜻합니다(확인 필요: 상황별). (2) "심박수와 HRV는 같은 정보": 평균과 변동은 다른 정보입니다.
요약
  1. SDNN = RR 표준편차, RMSSD = 이웃 차이의 RMS.
  2. 평균 심박수 = 60000/평균 RR(ms).
  3. 이상 박동 제거 후 계산.

6.3.2연습문제

기본

    80 bpm.

응용

  1. RR 800, 810, 790의 RMSSD는?
    답

    √((100 + 400)/2) ≈ 15.8 ms.

심화

  1. RMSSD가 SDNN보다 빠른 변동에 민감한 이유는?
    답
