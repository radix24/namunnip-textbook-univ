60 Hz 노치 필터 설계

본문
이 절에서 배울 것
  • 단위원 위 영점과 그 안쪽 극점으로 디지털 노치 필터를 설계한다.
  • 극점 반지름 r로 노치 폭 ≈ (1 − r)f_s/π를 정한다.
  • 노치가 ECG 성분을 왜곡하는 정도를 안다.
먼저 알아야 할 것
  • 극·영점과 주파수 응답 (전전6 7단원), 전원 잡음 (4.2절).

4.4.1영점은 60 Hz 위에

\(H(z) = \frac{1 - 2\cos\omega_0z^{-1} + z^{-2}}{1 - 2r\cos\omega_0z^{-1} + r^2z^{-2}}\), \(\omega_0 = 2\pi f_0/f_s\). r이 1에 가까울수록 노치가 좁습니다(−3 dB 폭 ≈ (1 − r)f_s/π).

import numpy as np
fs, f0, r = 500.0, 60.0, 0.95
w0 = 2 * np.pi * f0 / fs
b = [1, -2 * np.cos(w0), 1]
a = [1, -2 * r * np.cos(w0), r * r]
for f in (10, 50, 55, 60, 65, 70, 120):
    z = np.exp(1j * 2 * np.pi * f / fs)
    H = np.polyval(b[::-1], 1 / z) / np.polyval(a[::-1], 1 / z)
    print(f"{f:4d} Hz: {20 * np.log10(abs(H) + 1e-15):7.1f} dB")
print("계수 b =", np.round(b, 4), " a =", np.round(a, 4))

예제 4.4.1

위 필터(f_s = 500 Hz, r = 0.95)의 노치 폭과, 10 Hz와 120 Hz에서의 영향은?

풀이. 폭 ≈ 0.05 × 500/π ≈ 8 Hz. 실행 결과 60 Hz에서 크게 감쇠하고 10 Hz·120 Hz에서는 0 dB 근처라 ECG 주성분은 거의 그대로입니다. 고조파(120 Hz)는 따로 노치를 더합니다. 전원이 50 Hz인 나라에서는 f₀를 바꿉니다.

흔한 오해(1) "노치를 좁게 할수록 좋다": 전원 주파수가 조금만 흔들려도 놓치고, 시간 응답(울림)이 길어집니다. (2) "노치 필터가 모든 잡음을 없앤다": 60 Hz 근처만 줄입니다.
요약
  1. 영점 e^{±jω₀}, 극 re^{±jω₀}.
  2. 폭 ≈ (1 − r)f_s/π.
  3. 예: r 0.95, 500 Hz → 약 8 Hz 폭.
