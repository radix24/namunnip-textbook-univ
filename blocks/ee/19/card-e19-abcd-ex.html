π형 감쇠기 해석

ABCD 곱

출발점

병렬-직렬-병렬 연결을 행렬 곱으로 풉니다(3.3절).

문제 해결 전략 · 세 행렬 곱
  1. 병렬 R₁, 직렬 R₂, 병렬 R₁의 ABCD.
  2. 곱한다.
  3. S₂₁(dB)을 구한다.

Z₀ = 50, 병렬 R₁ = 96.2 Ω, 직렬 R₂ = 71.2 Ω, 병렬 R₁의 π형 감쇠기 감쇠량은?

풀이

  1. Y = 1/96.2 = 0.0104 S.
    병렬.
  2. 곱: A = D = 1 + 71.2 × 0.0104 = 1.740, B = 71.2, C = 0.0104(2 + 0.740) = 0.0285.
    행렬 곱.
  3. 분모 1.740 + 1.424 + 1.425 + 1.740 = 6.33 → S₂₁ = 0.316 → −10 dB.
    10 dB 감쇠기.

의미

표준 감쇠기 값표가 이 계산에서 나옵니다(S₁₁ ≈ 0으로 정합).

검산

S₁₁ 분자 1.740 + 1.424 − 1.425 − 1.740 ≈ 0.
