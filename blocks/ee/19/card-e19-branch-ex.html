평형 증폭기의 입력 반사

반사가 격리로

출발점

두 증폭기의 반사가 같으면 입력 포트에서 상쇄되어 격리 포트로 갑니다(6.3절).

문제 해결 전략 · 왕복 위상
  1. 각 증폭기 반사 Γ.
  2. 두 반사가 입력에서 180° 차이로 만남.
  3. 입력 반사 0.

각 증폭기의 |Γ| = 0.5(SWR 3)인데 평형 구성의 입력 SWR은(두 증폭기가 같다면)?

풀이

  1. 두 경로 반사는 각각 90°를 두 번 지나 180° 차.
    위상.
  2. 입력에서 상쇄 → |Γ_in| ≈ 0, SWR ≈ 1.
    결론.
  3. 반사 전력은 격리 포트의 50 Ω 부하로.
    흡수.

의미

잡음 정합(반사가 큰 상태)과 입력 정합을 동시에 얻는 LNA 기법이다.

검산

두 증폭기가 다르면 차이만큼 반사가 남는다.
