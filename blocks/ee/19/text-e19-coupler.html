방향성 결합기의 결합도와 방향성

본문
이 절에서 배울 것
  • 방향성 결합기의 네 포트(입력, 통과, 결합, 격리)를 안다.
  • 결합도, 방향성, 격리도를 dB로 정의하고 서로의 관계 I = C + D를 쓴다.
  • 반사 측정(SWR 미터, VNA)에 결합기를 쓰는 원리를 안다.
먼저 알아야 할 것
  • S 파라미터 (3.1절), dB 계산.

6.2.1정의

입력(1)에 넣은 전력 대부분은 통과(2)로 가고, 일부가 결합 포트(3)로, 이상적으로는 격리 포트(4)에는 가지 않습니다.

결합도 C = 10log(P₁/P₃) dB. 방향성 D = 10log(P₃/P₄) dB. 격리도 I = 10log(P₁/P₄) = C + D.

예제 6.2.1

C = 20 dB, D = 30 dB 결합기에 1 W를 넣었다. 결합 포트와 격리 포트의 전력, 격리도는?

풀이. 결합 1 W/100 = 10 mW. 격리 I = 50 dB → 10 μW. 통과는 대략 1 − 0.01 = 0.99 W(삽입 손실 약 0.04 dB, 내부 손실 무시).

결합기를 반대 방향으로 하나 더 두면 반사파만 따로 떼어 낼 수 있어, 송신기의 SWR 미터와 VNA의 반사 측정에 씁니다. 방향성이 나쁘면 입사파가 섞여 작은 반사를 잴 수 없어, 측정 가능한 최소 반사 손실은 대략 방향성 정도입니다.

흔한 오해(1) "결합도가 클수록 결합이 강하다": dB 값이 클수록 결합이 약합니다(20 dB는 1%). (2) "격리 포트는 쓰지 않으니 아무렇게나 둔다": 정합 부하로 끝내야 방향성이 유지됩니다.
요약
  1. C = P₁/P₃, D = P₃/P₄, I = C + D (dB).
  2. 예: C 20, D 30 → 결합 10 mW, 격리 10 μW(1 W 입력).
  3. 반사 측정의 정밀도는 방향성이 한계.

6.2.2연습문제

기본

  1. C = 10 dB면 결합 포트 전력 비율은?
    답

    10%.

응용

  1. C = 20, I = 45 dB면 방향성은?
    답

    25 dB.

심화

  1. 방향성 25 dB 결합기로 반사 손실 30 dB인 부하를 재면 어떤 문제가 생기는가?
    답

    새어 들어온 입사파(−25 dB 수준)가 실제 반사파(−30 dB)보다 커서 측정값이 크게 틀립니다.
