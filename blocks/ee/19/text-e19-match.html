L형 정합 회로와 1/4 파장 변환기

본문
이 절에서 배울 것
  • 두 리액턴스 소자로 실수 부하를 Z₀에 맞추는 L형 회로를 설계한다.
  • Q = √(R_high/R_low − 1)로 소자값을 정하고 대역폭과의 관계를 안다.
  • 1/4 파장 변환기의 Z₀ = √(Z_inZ_L)과 대역 한계를 안다.
먼저 알아야 할 것
  • Smith 도표 (1.1절), 공진과 Q (전전3 8.3절), 단일 스텁 정합 (전전10 4.3절).

4.1.1L형 정합

큰 저항 쪽에 병렬 소자, 작은 저항 쪽에 직렬 소자를 둡니다. 두 저항이 \(R_H\), \(R_L\)이면

\[ Q = \sqrt{\frac{R_H}{R_L} - 1}, \qquad X_s = QR_L, \qquad X_p = \frac{R_H}{Q}. \]
예제 4.1.1

100 MHz에서 200 Ω 부하를 50 Ω 전원에 맞춰라(직렬 인덕터, 병렬 축전기).

풀이. Q = √3 = 1.732. 직렬 X = 86.6 Ω → L = 86.6/(2π × 10⁸) = 137.8 nH. 병렬 X = 200/1.732 = 115.5 Ω → C = 1/(2π × 10⁸ × 115.5) = 13.8 pF(부하 쪽 병렬). 대역폭은 대략 f/Q로 넓지 않습니다. 비가 크면 Q가 커져 대역이 좁아지므로 여러 단으로 나눕니다.

1/4 파장 변환기: \(Z_1 = \sqrt{Z_0R_L} = \sqrt{50 \times 200} = 100\) Ω, 길이 λ/4. 설계 주파수에서만 정확하고, 여러 단을 이어(Chebyshev 변환기) 대역을 넓힙니다.

흔한 오해(1) "L형 소자는 아무 쪽에 둬도 된다": 병렬 소자는 큰 저항 쪽이어야 해가 있습니다. (2) "정합은 모든 주파수에서 된다": 리액턴스 소자가 주파수에 따라 바뀌어 대역이 제한됩니다(Bode-Fano 한계).
요약
  1. L형: Q = √(R_H/R_L − 1), X_s = QR_L, X_p = R_H/Q.
  2. 예: 200 → 50 Ω @ 100 MHz: 137.8 nH, 13.8 pF.
  3. λ/4 변환기 Z₁ = √(Z₀R_L), 단일 주파수.
