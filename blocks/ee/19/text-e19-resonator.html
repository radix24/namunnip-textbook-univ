공진기의 Q와 대역폭

본문
이 절에서 배울 것
  • 무부하 Q(Q_u), 외부 Q(Q_e), 부하 Q(Q_L)의 관계 \(1/Q_L = 1/Q_u + 1/Q_e\)를 안다.
  • Q와 반전력 대역폭 BW = f₀/Q_L을 계산한다.
  • 선로·공동 공진기의 손실이 Q를 정하는 원리를 안다.
먼저 알아야 할 것
  • 공진과 Q (전전3 8.3절, 전전9 2.3절), 표피 깊이 (전전10 1.2절).

5.1.1세 가지 Q

Q = ω₀ × (저장 에너지)/(평균 손실 전력). 공진기 자체 손실(도체, 유전체)만 따진 것이 무부하 Q_u, 외부 회로로 빠져나가는 전력으로 정한 것이 외부 Q_e이고, 측정되는 부하 Q는 두 손실을 합한 것입니다.

\[ \frac{1}{Q_L} = \frac{1}{Q_u} + \frac{1}{Q_e}, \qquad \text{BW} = \frac{f_0}{Q_L}. \]
예제 5.1.1

1 GHz 공진기, Q_u = 200, Q_e = 50. Q_L과 대역폭은? 결합을 약하게 해 Q_e = 2000으로 하면?

풀이. \(1/Q_L = 0.005 + 0.02 = 0.025\), Q_L = 40, BW = 25 MHz. Q_e = 2000이면 Q_L ≈ 182, BW ≈ 5.5 MHz로 좁아지지만, 외부로 나가는 신호도 약해져 삽입 손실이 커집니다. 임계 결합(Q_e = Q_u)에서 전원과 정합됩니다.

금속 공동 공진기는 표피 깊이 안의 전류 손실이 작아 Q_u가 수천~수만, 마이크로스트립 공진기는 수십~수백입니다(확인 필요: 구조·재료별).

흔한 오해(1) "측정한 Q가 공진기 자체의 Q다": 외부 결합 손실이 포함된 Q_L입니다. (2) "결합을 강하게 하면 좋다": 대역이 넓어지는 대신 선택도가 떨어집니다.
요약
  1. Q = ω₀W/P_loss. 1/Q_L = 1/Q_u + 1/Q_e.
  2. BW = f₀/Q_L. 예: 200, 50 → 40, 25 MHz.
  3. 임계 결합 Q_e = Q_u에서 정합.

5.1.2연습문제

기본

  1. f₀ = 2.4 GHz, Q_L = 100의 대역폭은?
    답

    24 MHz.

응용

  1. Q_u = 500, Q_L = 100이면 Q_e는?
    답

    1/100 − 1/500 = 0.008 → 125.

심화

  1. Q_u = 1000 공진기로 BW 2 MHz(f₀ = 1 GHz) 필터를 만들 때 Q_e는?
    답

    Q_L = 500, 1/Q_e = 0.002 − 0.001, Q_e = 1000(임계 결합).
