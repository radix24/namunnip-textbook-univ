S₂₁로 공진기의 Q 재기

본문
이 절에서 배울 것
  • 투과형 공진기의 S₂₁ 3 dB 대역폭으로 부하 Q_L을 잰다.
  • 공진점 투과량에서 무부하 Q_u를 계산한다.
  • 결합 세기에 따른 측정 오차를 안다.
먼저 알아야 할 것
  • 공진기 Q (5.1절).

5.4.1대역폭과 깊이

Q_L = f₀/Δf₋₃dB. 투과형에서 공진점 |S₂₁(f₀)|이 작을수록 결합이 약해 Q_L이 Q_u에 가깝고, \(Q_u = Q_L/(1 - |S_{21}(f_0)|)\)(대칭 결합)입니다.

예제 5.4.1

f₀ = 2.4 GHz, 3 dB 대역폭 6 MHz, 공진점 S₂₁ = −6 dB. Q_L과 Q_u는?

풀이. Q_L = 400, |S₂₁| = 0.5 → Q_u = 400/0.5 = 800. 결합이 강하면(S₂₁ → 0 dB) 분모가 작아져 작은 측정 오차가 Q_u를 크게 흔들므로, 약한 결합(S₂₁ −20 dB 이하)에서 재는 것이 정확합니다.

흔한 오해(1) "재는 Q가 곧 공진기 Q": 외부 결합이 포함된 Q_L입니다. (2) "대역폭은 −6 dB 지점": 최대값 대비 −3 dB 지점입니다.
요약
  1. Q_L = f₀/Δf₃dB.
  2. Q_u = Q_L/(1 − |S₂₁(f₀)|).
  3. 예: 400, −6 dB → Q_u 800.

5.4.2연습문제

기본

응용
