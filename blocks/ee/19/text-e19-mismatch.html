SWR, 반사 손실, 불일치 손실

본문
이 절에서 배울 것
  • |Γ|에서 SWR, 반사 손실(RL), 불일치 손실(ML)을 서로 바꾼다.
  • 안테나 사양의 SWR 2 : 1이 뜻하는 전력 손실을 계산한다.
  • dB 값의 부호 관례를 정리한다.
먼저 알아야 할 것
  • Smith 도표와 Γ (1.1절).

1.2.1같은 것을 세 숫자로

\(\text{SWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}\), \(\text{RL} = -20\log|\Gamma|\) dB, 부하로 전달되지 못하는 손실 \(\text{ML} = -10\log(1 - |\Gamma|^2)\) dB.

예제 1.2.1

SWR 2 : 1인 안테나의 |Γ|, 반사 손실, 불일치 손실은?

풀이. |Γ| = 1/3, RL = 9.5 dB, ML = −10log(8/9) = 0.51 dB(전력의 11%가 반사). 많은 안테나 사양이 SWR 2 이하를 기준으로 하는 이유는 손실이 0.5 dB 정도로 작기 때문입니다(확인 필요: 응용마다).

흔한 오해(1) "SWR 2면 전력의 절반을 잃는다": 11%만 반사됩니다. (2) "반사 손실이 클수록 나쁘다": RL은 클수록(반사가 작을수록) 좋습니다.
요약
  1. SWR = (1 + |Γ|)/(1 − |Γ|).
  2. RL = −20log|Γ|, ML = −10log(1 − |Γ|²).
  3. SWR 2 → |Γ| 1/3, RL 9.5 dB, ML 0.51 dB.
