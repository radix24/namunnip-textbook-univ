Smith 도표로 임피던스와 반사 계수 바꾸기

본문
이 절에서 배울 것
  • 정규화 임피던스와 반사 계수의 관계 \(\Gamma = (z - 1)/(z + 1)\)로 Smith 도표의 점을 읽는다.
  • 선로를 따라 이동할 때 |Γ|가 일정한 원 위를 도는 것으로 입력 임피던스를 구한다.
  • 어드미턴스 읽기와 SWR, 반사 손실을 도표에서 얻는다.
먼저 알아야 할 것
  • Smith 도표 입문 (전전10 4.3절), 입력 임피던스 (전전10 4.2절), 이 절의 탐구 카드.

1.1.1점 하나에 담긴 정보

Smith 도표의 한 점은 정규화 임피던스 z = r + jx이자 반사 계수 Γ(원점에서의 거리와 각)입니다. 원점까지의 거리 |Γ|에서 SWR = (1 + |Γ|)/(1 − |Γ|), 반사 손실 −20 log|Γ| dB를 바로 얻습니다. 점을 원점에 대해 대칭으로 옮기면(180° 회전) 정규화 어드미턴스 y = 1/z가 됩니다.

부하에서 전원 쪽으로 거리 l만큼 가면 \(\Gamma(l) = \Gamma_Le^{-j2\beta l}\): 같은 반지름 원을 시계 방향으로 \(720°\times l/\lambda\) 돕니다.

예제 1.1.1

Z₀ = 50 Ω 선로에 Z_L = 25 + j50 Ω. (가) Γ_L, SWR. (나) 전원 쪽으로 0.1λ 떨어진 곳의 입력 임피던스.

풀이. (가) z = 0.5 + j1, \(\Gamma = (-0.5 + j1)/(1.5 + j1) = 0.0769 + j0.615 = 0.620\angle82.9°\), SWR = 4.27. (나) 0.1λ면 2βl = 720° × 0.1 = 72°만큼 시계 방향으로: 0.620∠10.9°. \(z_{in} = (1 + \Gamma)/(1 - \Gamma) = 3.70 + j1.41\), \(Z_{in} = 184.8 + j70.3\) Ω. 탐구 카드에서 이동 거리를 바꿔 원을 따라 도는 모습을 봅니다.

흔한 오해(1) "선로를 지나면 |Γ|가 변한다": 무손실 선로에서는 각만 바뀌고 크기는 그대로입니다(손실이 있으면 안쪽으로 나선을 그림). (2) 전원 쪽과 부하 쪽 이동 방향(시계/반시계)을 헷갈리는 실수. 도표 가장자리의 "wavelengths toward generator" 눈금을 확인합니다.
요약
  1. 점 = z = Γ. |Γ|에서 SWR, 반사 손실. 180° 대칭 = 어드미턴스.
  2. 전원 쪽 l 이동 = 시계 방향 720° × l/λ.
  3. 예: z = 0.5 + j1 → |Γ| 0.62, SWR 4.27.

1.1.2연습문제

기본

  1. z = 1 + j0의 위치와 SWR은?
    답

    원점, 1.

응용

  1. |Γ| = 0.33의 반사 손실은?
    답

    약 9.6 dB.

심화

  1. z = 2(실수)에서 전원 쪽으로 0.25λ 가면 z는?
    답

    180° 돌아 0.5(λ/4 변환).
