Smith 도표 위에서 선로 따라 돌기

탐구 · 부하에서 전원 쪽으로

질문

선로 길이를 바꾸면 입력 임피던스는 Smith 도표에서 어떻게 움직일까요?

준비

정규화 부하 z_L = r + jx를 Smith 도표에 찍고(파란 점), 전원 쪽으로 l(파장 단위) 이동한 입력점(빨간 점)과 그 경로를 그립니다(1.1절). 격자는 r = 0, 0.5, 1, 2, 5 원과 x = ±0.5, ±1, ±2, ±5 호입니다.

해 보기와 설명

  1. 처음 화면z = 0.5 + j1: Γ = 0.620∠82.9°, SWR 4.27. 0.1λ 이동 후 z_in = 3.70 + j1.41(184.8 + j70.3 Ω)(예제 1.1.1).
  2. 반 바퀴l = 0.25λ면 180° 돌아 z_in = 1/z_L(λ/4 변환기).
  3. 한 바퀴l = 0.5λ면 제자리로 돌아옵니다.
  4. 정합r = 1, x = 0이면 원점에 머물러 어디서나 z = 1.

연결과 적용

RF 회로 설계 도구와 VNA 화면이 측정한 S₁₁을 이 도표로 보여 줍니다. 정합 회로 설계(4.1절)는 점을 원점으로 옮기는 작도입니다.

흔한 오해

  • "이동 거리에 비례해 임피던스가 커진다." 원 위를 돌 뿐이라 반 파장마다 같은 값이 반복됩니다.
  • "Smith 도표는 반사 계수만 보여 준다." 같은 점에서 임피던스, 어드미턴스, SWR을 함께 읽습니다.
