ABCD 행렬과 연쇄 연결

본문

필터는 직렬 인덕터, 병렬 축전기, 선로 조각을 차례로 이은 사다리 회로이다. 소자 하나하나의 S 파라미터를 알아도, 여러 개를 이었을 때 전체 S₂₁은 어떻게 구할까? S 행렬끼리 곱하면 될 것 같은데, 정말 그럴까?

먼저 알아야 할 것S 파라미터(3.1절), 행렬 곱(전전16 1단원)을 쓴다.

3.3.1곱하면 연결

ABCD 행렬은 출력 쪽 전압과 전류로 입력 쪽 전압과 전류를 나타낸다. 식으로는 \(\begin{pmatrix} V_1 \\ I_1 \end{pmatrix} = \begin{pmatrix} A & B \\ C & D \end{pmatrix}\begin{pmatrix} V_2 \\ I_2 \end{pmatrix}\)이다. 그래서 블록을 이으면 앞 블록의 출력이 다음 블록의 입력이 되어, 연쇄 연결은 행렬을 순서대로 곱하는 일이 된다(그림 1). 처음 질문의 첫째 답이 이것이다.

기본 소자의 ABCD는 간단하다. 직렬 임피던스 Z는 [[1, Z], [0, 1]], 병렬 어드미턴스 Y는 [[1, 0], [Y, 1]]이다. 전체 행렬을 구한 뒤에는 Z₀ 계에서 \(S_{21} = \frac{2}{A + B/Z_0 + CZ_0 + D}\), \(S_{11} = \frac{A + B/Z_0 - CZ_0 - D}{A + B/Z_0 + CZ_0 + D}\)로 한 번만 바꾸면 된다.

예제 3.3.1

직렬 50 Ω(Z₀ = 50)의 S₂₁, S₁₁을 ABCD로 구하라. 3.1절 결과와 같은가?

풀이. A = 1, B = 50, C = 0, D = 1이므로 분모는 1 + 1 + 0 + 1 = 3이다. 따라서 S₂₁ = 2/3, S₁₁ = (1 + 1 − 0 − 1)/3 = 1/3으로, 3.1절 결과와 같다.

즉 소자 하나에서는 별 이득이 없지만, 소자가 여럿이면 행렬을 곱한 뒤 마지막에 한 번만 바꾸면 되어 필터 해석(5.2절)이 훨씬 편해진다. 또 선로 조각의 ABCD는 [[cos βl, jZ₀ sin βl], [j sin βl/Z₀, cos βl]]이므로, 집중 소자와 선로를 섞은 회로도 같은 방법으로 다룬다.

흔한 오해S 행렬도 곱하면 연쇄 연결이 된다고 여기기 쉽다. 처음 질문의 둘째 답이 이것이다. S 행렬은 각 포트의 들어가는 파와 나오는 파를 섞어 놓은 것이라, 앞 블록의 출력 파가 다음 블록의 입력 파와 바로 맞물리지 않는다. 그래서 ABCD나 T 행렬로 바꿔 곱한 뒤 다시 S로 돌린다. 또 ABCD 원소가 모두 무차원이라고 생각하기 쉬운데, B는 Ω, C는 S 단위이다.
마무리

직렬 소자의 ABCD는 [[1, Z], [0, 1]], 병렬 소자는 [[1, 0], [Y, 1]]이다. 연쇄 연결은 행렬 곱이다. 전체를 구한 뒤 S₂₁ = 2/(A + B/Z₀ + CZ₀ + D)로 바꾼다.

3.3.2연습문제

기본

  1. 병렬 Y = 0.02 S(Z₀ 50)의 S₂₁은?
    답

    2/(1 + 1 + 1) = 2/3이다.

응용

  1. 길이 0인 선로의 ABCD는?
    답

    단위 행렬이다.

심화

  1. 상반 2포트의 ABCD 성질은?
    답

    AD − BC = 1이다.
