ABCD 행렬과 연쇄 연결

본문
이 절에서 배울 것
  • 2포트의 ABCD 행렬을 정의하고 연쇄 연결은 행렬 곱임을 안다.
  • 직렬·병렬 소자와 선로의 ABCD를 쓴다.
  • ABCD에서 S₂₁, S₁₁로 바꾼다.
먼저 알아야 할 것
  • S 파라미터 (3.1절), 행렬 곱 (전전16 1단원).

3.3.1곱하면 연결

\(\begin{pmatrix} V_1 \\ I_1 \end{pmatrix} = \begin{pmatrix} A & B \\ C & D \end{pmatrix}\begin{pmatrix} V_2 \\ I_2 \end{pmatrix}\). 직렬 Z: [[1, Z], [0, 1]], 병렬 Y: [[1, 0], [Y, 1]]. 연쇄 연결은 순서대로 곱합니다. Z₀ 계에서 \(S_{21} = \frac{2}{A + B/Z_0 + CZ_0 + D}\), \(S_{11} = \frac{A + B/Z_0 - CZ_0 - D}{A + B/Z_0 + CZ_0 + D}\).

예제 3.3.1

직렬 50 Ω(Z₀ = 50)의 S₂₁, S₁₁을 ABCD로 구하라. 3.1절 결과와 같은가?

풀이. A = 1, B = 50, C = 0, D = 1 → 분모 3, S₂₁ = 2/3, S₁₁ = 1/3로 같습니다. 여러 소자를 이으면 행렬을 곱한 뒤 한 번만 바꾸면 되어 필터 해석에 편합니다.

흔한 오해(1) "S 행렬도 곱하면 연쇄": S는 곱으로 이어지지 않아 ABCD(또는 T 행렬)로 바꿔 곱합니다. (2) "ABCD 원소는 모두 무차원": B는 Ω, C는 S 단위입니다.
요약
  1. 직렬 [[1, Z], [0, 1]], 병렬 [[1, 0], [Y, 1]].
  2. 연쇄 = 행렬 곱.
  3. S₂₁ = 2/(A + B/Z₀ + CZ₀ + D).

3.3.2연습문제

기본

  1. 병렬 Y = 0.02 S(Z₀ 50)의 S₂₁은?
    답

    2/(1 + 1 + 1) = 2/3.

응용

  1. 길이 0인 선로의 ABCD는?
    답

    단위 행렬.

심화

  1. 상반 2포트의 ABCD 성질은?
    답

    AD − BC = 1.
