무손실·상반 회로망의 S 행렬

본문
이 절에서 배울 것
  • 상반 회로망(수동, 비자성)에서 S가 대칭(S₁₂ = S₂₁)임을 안다.
  • 무손실 회로망에서 S가 유니터리(\(S^HS = I\))임을 전력 보존으로 설명한다.
  • 이 성질로 측정값의 타당성을 검사하고 불가능한 소자를 판별한다.
먼저 알아야 할 것
  • S 파라미터 (3.1절), 정규 직교 (전전16 3.2절).

3.2.1두 성질

상반성: 저항, 축전기, 인덕터, 선로만으로 된 회로망은 \(S = S^T\). 페라이트(자화된) 소자나 증폭기는 상반이 아니다.

무손실: 들어간 전력이 모두 나오므로 \(\sum_i|b_i|^2 = \sum_i|a_i|^2\), 곧 \(S^HS = I\). 각 열의 크기 제곱 합이 1이고, 서로 다른 열은 직교.

예제 3.2.1

50 Ω 계에서 직렬 리액턴스 jX = j50 Ω의 S₁₁, S₂₁과 무손실 조건을 확인하라.

풀이. \(S_{11} = jX/(jX + 2Z_0) = j50/(100 + j50)\), \(|S_{11}|^2 = 2500/12500 = 0.2\). \(S_{21} = 100/(100 + j50)\), \(|S_{21}|^2 = 0.8\). 합 1로 무손실입니다.

무손실 상반 3포트가 세 포트 모두 정합될 수 없다는 정리(그래서 Wilkinson 분배기는 저항을 넣어 손실을 허용, 6.1절)도 이 성질에서 나옵니다.

흔한 오해(1) "|S₁₁|² + |S₂₁|² = 1이면 언제나 무손실": 포트 2에서 들어간 경우의 열(|S₁₂|² + |S₂₂|²)도 1이고 열끼리 직교해야 합니다. (2) 측정된 수동 회로망의 |S₂₁|이 1을 넘으면 측정 오류(보정)입니다.
요약
  1. 상반: S = Sᵀ. 무손실: SᴴS = I.
  2. 열의 크기 제곱 합 = 1, 열끼리 직교.
  3. 무손실 상반 3포트는 모두 정합될 수 없다.

3.2.2연습문제

기본

  1. |S₁₁| = 0.6인 무손실 2포트의 |S₂₁|은?
    답

    0.8.

응용

  1. S₁₂ = 0.5, S₂₁ = 0.7인 수동 소자는 상반인가?
    답

    아닙니다(비상반, 페라이트 소자 등).

심화

  1. 측정된 수동 필터의 |S₁₁|² + |S₂₁|² = 0.9면 무엇을 뜻하는가?
    답

    10%가 소자 안에서 손실(저항, 유전 손실, 복사).
