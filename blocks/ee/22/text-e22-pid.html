PID 제어기 각 항의 역할

본문
이 절에서 배울 것
  • 비례(P), 적분(I), 미분(D) 항이 응답에 주는 효과를 안다.
  • 1차 플랜트에서 P와 PI 제어의 정상상태 오차를 비교한다.
  • 미분 항의 잡음 문제와 적분 와인드업을 안다.
먼저 알아야 할 것
  • 정상상태 오차 (3.2절), 2차 시스템 (2.1절).

4.3.1세 항

\[ u(t) = K_pe + K_i\int e\,dt + K_d\dot e, \qquad C(s) = K_p + \frac{K_i}{s} + K_ds. \]
  • P: 오차에 비례. 반응을 빠르게 하지만 형 0 플랜트의 계단 오차를 없애지 못한다.
  • I: 오차의 누적. 원점 극점을 더해 계단 오차를 0으로. 위상이 늦어 넘침·진동이 늘 수 있다.
  • D: 오차의 변화율. 감쇠를 더해 넘침을 줄인다. 고주파 잡음을 키우므로 필터를 붙인다.
예제 4.3.1

플랜트 \(1/(s + 1)\), 단위 궤환. (가) P 제어 K_p = 9의 계단 오차와 시상수. (나) PI \(9 + 9/s\)이면?

풀이. (가) 폐루프 \(9/(s + 10)\), 최종값 0.9 → 오차 0.1, 시상수 0.1 s. (나) \(C G = 9(s + 1)/(s(s + 1)) = 9/s\)(영점이 플랜트 극점을 상쇄), 폐루프 \(9/(s + 9)\), 오차 0, 시상수 0.111 s. 적분 항이 오차를 없앴습니다.

구동기가 포화되었는데도 적분이 계속 쌓이면(와인드업) 큰 넘침이 생겨, 포화 시 적분을 멈추는 장치를 씁니다. 실무에서는 Ziegler-Nichols 같은 경험 규칙으로 시작해 조정합니다.

흔한 오해(1) "이득을 모두 키우면 좋아진다": 넘침, 잡음, 불안정으로 이어집니다. (2) "D 항은 미래를 예측한다": 현재 기울기로 짧게 외삽할 뿐입니다.
요약
  1. P 속도, I 정상상태 오차 제거, D 감쇠.
  2. 예: 1/(s+1), P 9 → 오차 0.1; PI 9 + 9/s → 0.
  3. D 잡음 필터, I 와인드업 방지.

4.3.2연습문제

기본

  1. P 제어 K_p = 19면 예제의 계단 오차는?
    답

    0.05.

응용

  1. PI 제어기의 극점과 영점은(K_p = 2, K_i = 4)?
    답

    극점 0, 영점 −2.

심화

  1. 센서 잡음이 큰 시스템에서 D 항을 어떻게 다루는가?
    답

    저역 통과 필터를 붙이거나(K_ds/(τs + 1)) 측정값에만 미분(설정값 미분 제외)을 적용합니다.
