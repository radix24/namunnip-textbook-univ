블록선도 간략화와 Mason 공식

본문
이 절에서 배울 것
  • 직렬·병렬·궤환 결합 규칙으로 블록선도를 간략화한다.
  • 음의 궤환 폐루프 전달함수 G/(1 + GH)를 유도한다.
  • 신호 흐름도에서 Mason 공식으로 전달함수를 구한다.
먼저 알아야 할 것
  • 전달함수 (1.1절), 연립 방정식.

1.2.1세 규칙

직렬은 곱 \(G_1G_2\), 병렬은 합 \(G_1 + G_2\), 음의 궤환은

\[ T(s) = \frac{Y}{R} = \frac{G}{1 + GH}. \]

(E = R − HY, Y = GE에서 Y를 풀면 됩니다.) 복잡한 그림은 합산점과 분기점을 옮겨 이 세 꼴로 만듭니다.

1.2.2Mason 공식

\[ T = \frac{\sum_kP_k\Delta_k}{\Delta}, \quad \Delta = 1 - \sum L_i + \sum L_iL_j - \cdots \]

P_k는 순방향 경로 이득, L_i는 루프 이득, L_iL_j는 서로 닿지 않는 루프 쌍의 곱, Δ_k는 경로 k에 닿지 않는 루프만으로 만든 Δ입니다.

예제 1.2.1

R에서 G₁, G₂를 거쳐 Y로 가는 경로가 있고, G₂ 주위의 루프(−H₂)와 전체를 감싸는 루프(−H₁)가 있다. 전달함수는?

풀이. P₁ = G₁G₂, L₁ = −G₂H₂, L₂ = −G₁G₂H₁(두 루프는 G₂를 공유해 닿음). Δ = 1 + G₂H₂ + G₁G₂H₁, Δ₁ = 1. \(T = \frac{G_1G_2}{1 + G_2H_2 + G_1G_2H_1}\). 블록선도로 안쪽 루프를 먼저 줄여도 같은 결과입니다.

흔한 오해(1) "루프 이득에 부호를 빼먹는다": 음의 궤환 루프 이득은 −GH입니다. (2) "닿는 루프 쌍도 곱해 더한다": 서로 노드를 공유하지 않는 루프 쌍만 셉니다.
요약
  1. 직렬 곱, 병렬 합, 궤환 G/(1 + GH).
  2. Mason: T = ΣP_kΔ_k/Δ.
  3. Δ에는 서로 닿지 않는 루프 조합만.

1.2.3연습문제

기본

  1. G = 10/(s + 1), H = 1의 폐루프 전달함수는?
    답

    10/(s + 11).

응용

  1. 양의 궤환이면 폐루프 전달함수는?
    답

    G/(1 − GH).

심화

  1. 예제에서 H₂ = 0이면 결과는?
    답

    G₁G₂/(1 + G₁G₂H₁)(단순 궤환).
