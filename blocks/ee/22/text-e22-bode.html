Bode 선도 점근선 그리기

본문
이 절에서 배울 것
  • 극점·영점마다 꺾이는 직선으로 크기 선도를 그린다.
  • 적분기(−20 dB/dec), 1차 극점(꺾인 뒤 −20 dB/dec)의 기울기를 쓴다.
  • 점근선과 정확한 값으로 이득 교차 주파수와 위상 여유를 구한다.
먼저 알아야 할 것
  • 주파수 응답 (전전6 8단원), 위상 여유 (5.2절).

5.3.1직선으로 어림

\(G = \frac{100}{s(s + 10)}\)는 저주파에서 \(10/s\)(−20 dB/dec, ω = 1에서 20 dB), ω = 10에서 꺾여 −40 dB/dec입니다. 위상은 −90°에서 시작해 꺾임 주파수에서 −135°, 고주파에서 −180°.

예제 5.3.1

위 G의 점근선으로 이득 교차 주파수를 어림하고, 정확한 값과 위상 여유를 구하라.

풀이. 점근선: ω = 10에서 20log(10/10) = 0 dB → ω_c ≈ 10. 정확한 값 |G(jω)| = 1에서 ω_c = 7.86 rad/s(꺾임 근처라 점근선이 3 dB 높음). 위상 −90 − tan⁻¹(0.786) = −128.2° → 위상 여유 51.8°.

흔한 오해(1) "점근선이 정확한 값": 꺾임 주파수에서 3 dB 차이가 납니다. (2) "위상도 직선이다": 꺾임 주파수의 0.1~10배에 걸쳐 완만히 변합니다.
요약
  1. 적분기 −20 dB/dec, 극점마다 −20 dB/dec 추가.
  2. 꺾임에서 실제는 −3 dB.
  3. 예: 100/(s(s + 10)) → ω_c 7.86, PM 51.8°.
