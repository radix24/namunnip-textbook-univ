근궤적으로 진상·지상 보상기 설계

본문

근궤적을 그렸더니 원하는 극점이 궤적 위에 없다. 이득 K만 바꿔서는 도저히 그 자리에 극점을 놓을 수 없다면, 궤적 자체를 옮길 수는 없을까? 그리고 응답 모양은 마음에 드는데 정상상태 오차만 크다면 무엇을 덧붙여야 할까?

먼저 알아야 할 것근궤적(4.1절), 정상상태 오차(3.2절)를 쓴다.

4.2.1진상 보상

원하는 극점 s_d가 궤적 위에 없다는 것은, s_d에서 개루프의 각이 −180°가 아니라는 뜻이다. 그렇다면 보상기 \((s + z)/(s + p)\)를 붙여 모자라는 각을 채우면 된다. 영점이 극점보다 원점에 가까우면(z < p) 보상기는 양의 각을 보태는데, 이것이 진상 보상기이다. 처음 질문의 첫째 답이 이것이다.

진상 보상기의 각 조건

보상기가 채울 각은 −180° − ∠G(s_d)이다. 영점과 극점의 위치는 \(\angle(s_d + z) - \angle(s_d + p)\)가 이 각이 되도록 정하고, 이득은 크기 조건으로 정한다.

예제 4.2.1

\(G = 1/(s(s + 2))\)에서 ζ = 0.5, ω_n = 4(극점 −2 ± j3.464)를 얻는 진상 보상기를 설계하라.

풀이. s_d에서 ∠G = −(120° + 90°) = −210°이므로 30°가 부족하다. 보상기 영점을 −2에 두어 플랜트 극점을 지우면, 남은 각 조건은 \(120° + \angle(s_d + p) = 180°\)이다. 따라서 \(\angle(s_d + p) = 60°\)이고 \(p - 2 = 3.464/\tan60° = 2\), 곧 p = 4이다. 이득은 K = |s_d||s_d + 4| = 4 × 4 = 16이다.

즉 \(C(s) = 16(s + 2)/(s + 4)\)이고, 폐루프는 \(s^2 + 4s + 16\)으로 원하는 극점과 맞다(그림 1). 그 결과 정착 시간 근사가 4 s에서 2 s로 줄었다.

4.2.2지상 보상

응답 모양은 좋고 정상상태 오차만 크다면 지상 보상을 쓴다. 처음 질문의 둘째 답이 이것이다. 원점 가까이에 영점과 극점을 붙여 두면(예를 들어 z/p = 10), 원하는 극점 근처에서는 두 각이 거의 상쇄되어 궤적이 거의 그대로이다. 그런데 s = 0에서는 보상기 이득이 z/p배가 되므로 K_v가 커져 정상상태 오차가 줄어든다.

흔한 오해극점-영점 상쇄는 언제나 안전하다고 여기기 쉽다. 불안정한 극점을 영점으로 상쇄하면 입출력만 보면 괜찮아 보여도 내부 신호가 발산한다. 또 진상은 오차를, 지상은 과도 응답을 고친다고 반대로 기억하기 쉬운데, 진상은 과도 응답을, 지상은 정상상태 오차를 개선한다.
마무리

보상기가 채울 각은 −180° − ∠G(s_d)이다. 진상(z < p)은 각을 더해 궤적을 왼쪽으로 옮기며, 예제에서는 C = 16(s+2)/(s+4)로 s² + 4s + 16을 얻는다. 지상은 궤적을 거의 그대로 두고 K_v만 키운다.

4.2.3연습문제

기본

  1. 보상기 (s + 1)/(s + 10)은 진상인가 지상인가?
    답

    진상(영점이 원점에 더 가까움)이다.

응용

  1. 지상 보상기 (s + 0.1)/(s + 0.01)은 K_v를 몇 배로 하는가?
    답

    10배이다.

심화

  1. 예제 보상 후 경사 입력 정상상태 오차는?
    답

    K_v = lim s·16(s+2)/((s+4)s(s+2)) = 4 → 0.25이다.
