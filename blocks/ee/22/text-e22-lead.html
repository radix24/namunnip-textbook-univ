근궤적으로 진상·지상 보상기 설계

본문
이 절에서 배울 것
  • 원하는 극점에서의 각 부족분을 계산한다.
  • 진상 보상기 \(K(s + z)/(s + p)\), p > z로 부족분을 채워 궤적을 끌어온다.
  • 지상 보상기로 과도 응답을 유지하며 정상상태 오차를 줄인다.
먼저 알아야 할 것
  • 근궤적 (4.1절), 정상상태 오차 (3.2절).

4.2.1진상 보상

원하는 극점 s_d가 궤적 위에 없으면, 개루프의 각이 −180°에서 모자라는 만큼 보상기가 양의 각(영점이 극점보다 원점에 가까움)으로 채웁니다.

예제 4.2.1

\(G = 1/(s(s + 2))\)에서 ζ = 0.5, ω_n = 4(극점 −2 ± j3.464)를 얻는 진상 보상기를 설계하라.

풀이. s_d에서 ∠G = −(120° + 90°) = −210°: 30° 부족. 보상기 영점을 −2에 두어 플랜트 극점을 지우면, 남은 각 조건 \(120° + \angle(s_d + p) = 180°\) → \(\angle(s_d + p) = 60°\), \(p - 2 = 3.464/\tan60° = 2\), p = 4. K = |s_d||s_d + 4| = 4 × 4 = 16. \(C(s) = 16(s + 2)/(s + 4)\), 폐루프 \(s^2 + 4s + 16\)으로 맞습니다. 정착 시간 근사가 4 s에서 2 s로 줄었습니다.

4.2.2지상 보상

원점 가까이에 영점과 극점을 붙여 두면(z/p = 10 등) 원하는 극점 근처의 각은 거의 그대로이고, 저주파 이득만 z/p배 늘어 K_v가 커집니다(정상상태 오차 감소).

흔한 오해(1) "극점-영점 상쇄는 늘 안전": 불안정 극점을 상쇄하면 내부적으로 불안정합니다. (2) "진상은 오차, 지상은 과도 응답": 반대로, 진상은 과도 응답, 지상은 정상상태 오차를 개선합니다.
요약
  1. 각 부족분 = −180° − ∠G(s_d).
  2. 진상(z < p)이 각을 더해 궤적을 왼쪽으로.
  3. 예: C = 16(s+2)/(s+4) → s² + 4s + 16. 지상은 K_v만 키움.

4.2.3연습문제

기본

  1. 보상기 (s + 1)/(s + 10)은 진상인가 지상인가?
    답

    진상(영점이 원점에 더 가까움).

응용

  1. 지상 보상기 (s + 0.1)/(s + 0.01)은 K_v를 몇 배로 하는가?
    답

    10배.

심화

  1. 예제 보상 후 경사 입력 정상상태 오차는?
    답

    K_v = lim s·16(s+2)/((s+4)s(s+2)) = 4 → 0.25.
