  1. 계산A = [[0, 1], [−4, −4]], B = [0; 1], C = [1 0]의 전달함수는? [06-01]

    힌트 1

    힌트 2

    풀이

    1/(s² + 4s + 4).

  2. 계산A = diag(−1, −3), B = [1; 1]은 가제어인가? [06-02]

    힌트 1

    힌트 2

    풀이

    예([B AB] = [[1, −1], [1, −3]], 행렬식 −2).

  3. 계산문제 1의 시스템에서 극점 −5, −5의 K는? [06-03]

    힌트 1

    s² + 10s + 25.

    힌트 2

    풀이

    K = (21, 6).

  4. 개념가관측성이 관측기 설계에 필요한 이유는? [06-02]
