전기·기계 시스템의 전달함수

본문
이 절에서 배울 것
  • RLC 회로와 질량-스프링-감쇠기의 미분방정식을 세운다.
  • 초기 조건 0의 Laplace 변환으로 전달함수 G(s) = Y(s)/U(s)를 얻는다.
  • 전기·기계 시스템의 대응(L ↔ m, R ↔ b, 1/C ↔ k)을 안다.
먼저 알아야 할 것
  • Laplace 변환 (전전6 7.1절), RLC 회로 (전전3 7.1절), 뉴턴 운동 법칙.

1.1.1두 시스템

질량-스프링-감쇠기: 힘 u, 변위 y에서 \(m\ddot y + b\dot y + ky = u\). 모든 초기 조건이 0이면 \(\frac{d}{dt} \to s\)로 바꿔

\[ G(s) = \frac{Y(s)}{U(s)} = \frac{1}{ms^2 + bs + k}. \]

직렬 RLC: 입력 전압, 출력 축전기 전압이면 \(LC\ddot v_C + RC\dot v_C + v_C = v_{in}\), \(G(s) = \frac{1}{LCs^2 + RCs + 1}\). 두 식의 꼴이 같아, 기계 시스템을 회로로 흉내 낼 수 있습니다.

예제 1.1.1

m = 1 kg, b = 2 N·s/m, k = 5 N/m. 전달함수, 극점, 1 N 일정한 힘을 줄 때의 최종 변위는?

풀이. \(G = 1/(s^2 + 2s + 5)\), 극점 \(-1 \pm j2\)(감쇠 진동). 최종값 정리 \(y(\infty) = \lim_{s\to0}sG(s)\frac1s = G(0) = 0.2\) m(= 힘/k). 감쇠비는 2.1절의 꼴과 비교해 \(\omega_n = \sqrt5\), \(\zeta = 1/\sqrt5 \approx 0.447\)입니다.

흔한 오해(1) "전달함수는 초기 조건까지 담는다": 초기 조건 0의 입출력 관계만 담습니다. (2) "전달함수가 같으면 같은 물리 시스템": 꼴이 같아도 물리량은 다릅니다(그래서 대응이 유용).
요약
  1. m ÿ + b ẏ + k y = u → 1/(ms² + bs + k).
  2. RLC: 1/(LCs² + RCs + 1). L↔m, R↔b, 1/C↔k.
  3. 최종값 G(0) × 계단 크기.

1.1.2연습문제

기본

  1. RC 저역 통과(입력 v_in, 출력 v_C)의 전달함수는?
    답

    1/(RCs + 1).

응용

  1. m = 2, b = 4, k = 8의 극점은?
    답

    s² + 2s + 4 = 0 → −1 ± j1.73.
