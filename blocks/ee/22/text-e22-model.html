전기·기계 시스템의 전달함수

본문

자동차 서스펜션과 라디오의 RLC 회로는 생김새도 재료도 전혀 다르다. 그런데 둘의 응답을 그래프로 그리면 똑같이 출렁이다 가라앉는다. 서로 다른 두 시스템을 같은 식 하나로 다룰 수 있을까? 그 식에서 응답의 모양과 최종값을 바로 읽어 낼 수 있을까?

먼저 알아야 할 것Laplace 변환(전전6 7.1절), RLC 회로(전전3 7.1절), 뉴턴 운동 법칙을 쓴다.

1.1.1두 시스템

질량-스프링-감쇠기에서 힘을 u, 변위를 y라 하면 \(m\ddot y + b\dot y + ky = u\)이다. 모든 초기 조건이 0이면 Laplace 변환으로 미분이 s의 곱셈으로 바뀌어, 출력과 입력의 비가 s의 유리함수가 된다. 이것을 전달함수라 한다.

질량-스프링-감쇠기와 직렬 RLC의 전달함수

\[ G(s) = \frac{Y(s)}{U(s)} = \frac{1}{ms^2 + bs + k} \]

\[ G(s) = \frac{V_C(s)}{V_{in}(s)} = \frac{1}{LCs^2 + RCs + 1} \]

직렬 RLC 회로에서 입력을 전원 전압, 출력을 축전기 전압으로 잡으면 \(LC\ddot v_C + RC\dot v_C + v_C = v_{in}\)이다. 즉 두 식의 꼴이 같아, L은 m, R은 b, 1/C은 k에 대응한다(그림 1). 처음 질문의 첫째 답이 이것이며, 그래서 기계 시스템을 회로로 흉내 내어 실험할 수 있다.

전달함수의 분모를 0으로 하는 s, 곧 극점이 응답의 모양을 정한다. 극점의 실수부는 감쇠의 빠르기를, 허수부는 진동 주파수를 준다. 또 최종값 정리에 따라 계단 입력의 최종 출력은 G(0)에 계단 크기를 곱한 값이다. 처음 질문의 둘째 답이 이것이다.

예제 1.1.1

m = 1 kg, b = 2 N·s/m, k = 5 N/m. 전달함수, 극점, 1 N 일정한 힘을 줄 때의 최종 변위는?

풀이. \(G = 1/(s^2 + 2s + 5)\)이고, 극점은 \(-1 \pm j2\)이므로 감쇠 진동한다. 최종값 정리로 \(y(\infty) = \lim_{s\to0}sG(s)\frac1s = G(0) = 0.2\) m이며, 이것은 힘/k와 같다. 한편 2.1절의 꼴과 비교하면 \(\omega_n = \sqrt5\), \(\zeta = 1/\sqrt5 \approx 0.447\)이다.

흔한 오해전달함수가 초기 조건까지 담는다고 여기기 쉽다. 전달함수는 초기 조건이 0일 때의 입출력 관계만 담는다. 또 전달함수가 같으면 같은 물리 시스템이라고 생각하기 쉬운데, 꼴이 같아도 물리량은 다르다. 바로 그 점 때문에 대응 관계가 유용하다.
마무리

\(m\ddot y + b\dot y + ky = u\)의 전달함수는 1/(ms² + bs + k)이다. 직렬 RLC는 1/(LCs² + RCs + 1)로, L↔m, R↔b, 1/C↔k가 대응한다. 계단 입력의 최종값은 G(0)에 계단 크기를 곱한 값이다.

1.1.2연습문제

기본

  1. RC 저역 통과(입력 v_in, 출력 v_C)의 전달함수는?
    답

    1/(RCs + 1)이다.

응용

  1. m = 2, b = 4, k = 8의 극점은?
    답

    s² + 2s + 4 = 0 → −1 ± j1.73이다.

심화

  1. DC 모터(각속도 출력)의 전달함수가 1차인 근사는 어떤 가정에서 나오는가?
    답

    전기자 인덕턴스를 무시해 전기 시상수가 기계 시상수보다 훨씬 짧다고 볼 때 성립한다.
