가제어성과 가관측성

본문
이 절에서 배울 것
  • 가제어성 행렬 \(\mathcal C = [B\ AB\ \cdots]\)의 계수로 가제어성을 판정한다.
  • 가관측성 행렬 \(\mathcal O = [C; CA; \cdots]\)로 가관측성을 판정한다.
  • 불가제어·불관측 모드가 전달함수에서 상쇄로 나타남을 안다.
먼저 알아야 할 것
  • 행렬의 계수 (전전16 2.1절), 상태방정식 (6.1절).

6.2.1판정

n차 시스템이 가제어(입력으로 상태를 어디로든 옮길 수 있음)일 필요충분조건은 \(\text{rank}[B\ AB\ \cdots\ A^{n-1}B] = n\), 가관측(출력으로 초기 상태를 알 수 있음)은 \(\text{rank}[C; CA; \cdots; CA^{n-1}] = n\)입니다.

예제 6.2.1

(가) 6.1절의 시스템. (나) \(A = \text{diag}(-1, -2)\), \(B = (1, 0)^T\), \(C = (1, 1)\).

풀이. (가) AB = (1, −3), \(\mathcal C = \begin{pmatrix} 0 & 1 \\ 1 & -3 \end{pmatrix}\), 행렬식 −1 ≠ 0 → 가제어. CA = (0, 1), \(\mathcal O = I\) → 가관측. (나) AB = (−1, 0), \(\mathcal C\)의 둘째 행이 0 → 계수 1, 불가제어. 입력이 x₂에 닿지 않아 −2 모드를 바꿀 수 없습니다. 전달함수 \(1/(s + 1)\)에 −2가 보이지 않습니다.

흔한 오해(1) "전달함수가 안정이면 내부도 안정": 숨은 불가제어·불관측 모드가 불안정할 수 있습니다. (2) "가제어면 어떤 궤적이든 따라간다": 상태를 옮길 수 있다는 뜻이며 입력 크기 제한은 따로 봅니다.
요약
  1. 가제어: rank[B AB …] = n.
  2. 가관측: rank[C; CA; …] = n.
  3. 숨은 모드는 전달함수에서 상쇄됨.

6.2.2연습문제

기본

  1. A = [[0, 1], [0, 0]], B = [0; 1]은 가제어인가?
    답

    예([B AB] = [[0, 1], [1, 0]], 계수 2).

응용

  1. 같은 A, C = [0 1]은 가관측인가?
    답

    아닙니다(CA = [0 0]).

심화

  1. 문제 a의 시스템에서 무엇을 알 수 없는가?
    답

    위치 x₁(속도만 측정되어 초기 위치를 알 수 없음).
