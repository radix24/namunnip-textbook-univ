사양을 만족하는 극점 영역

본문
이 절에서 배울 것
  • 넘침 사양을 ζ의 하한(원점을 지나는 두 직선 사이 영역)으로 바꾼다.
  • 정착 시간 사양을 실수부의 상한(수직선 왼쪽)으로 바꾼다.
  • 상승 시간(ω_n) 사양을 원 바깥 영역으로 바꾸고 세 영역을 겹친다.
먼저 알아야 할 것
  • 2차 시스템 지표 (2.1절).

2.2.1세 조건

  • 넘침 ≤ M: ζ ≥ ζ_min → 극점이 음의 실수축과 이루는 각 ≤ cos⁻¹ζ_min(쐐기 영역).
  • 정착 ≤ t_s: \(\zeta\omega_n \ge 4/t_s\) → Re(s) ≤ −4/t_s(수직선 왼쪽).
  • 상승 ≤ t_r: \(\omega_n \ge 1.8/t_r\)(근사) → 반지름 ω_n 원 바깥.
예제 2.2.1

넘침 10% 이하, 2% 정착 2 s 이하의 영역을 구하고, 극점 −2 ± j2가 만족하는지 보라.

풀이. ζ ≥ 0.591 → 각 ≤ 53.8°. Re(s) ≤ −2. 극점 −2 ± j2는 각 45°(ζ = 0.707), 실수부 −2로 둘 다 경계 안(정착은 경계선 위). 넘침 4.3%, 정착 근사 2 s입니다. 이 영역은 2차 시스템 근사이므로 다른 극점·영점이 멀리 있을 때(지배 극점) 쓸 수 있습니다.

흔한 오해(1) "극점이 왼쪽으로 멀수록 좋다": 빠르지만 큰 제어 입력(포화)과 잡음 민감성을 부릅니다. (2) "영점은 무시해도 된다": 지배 극점 근처의 영점은 넘침을 크게 바꿉니다.
요약
  1. 넘침 → ζ 하한 → 쐐기 영역.
  2. 정착 → Re(s) ≤ −4/t_s.
  3. 상승 → ω_n 하한 → 원 바깥. 지배 극점 가정.

2.2.2연습문제

기본

  1. 정착 1 s 이하의 실수부 조건은?
    답

    Re(s) ≤ −4.

응용

  1. 넘침 5% 이하의 각 조건은?
    답

    ζ ≥ 0.69 → 각 ≤ 46.4°.

심화

  1. 극점 −1 ± j3은 예제 영역에 드는가?
    답

    아닙니다(ζ = 0.316, 실수부 −1).
