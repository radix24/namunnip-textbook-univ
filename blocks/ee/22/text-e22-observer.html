상태 관측기 설계

본문
이 절에서 배울 것
  • 출력만 잴 수 있을 때 상태를 추정하는 Luenberger 관측기를 안다.
  • 오차 동역학 \(\dot e = (A - LC)e\)의 극점을 L로 배치한다.
  • 관측기 극점을 제어 극점보다 빠르게 두는 이유를 안다.
먼저 알아야 할 것
  • 극점 배치 (6.3절), 가관측성 (6.2절).

6.4.1모델 + 출력 보정

\(\dot{\hat x} = A\hat x + Bu + L(y - C\hat x)\). 추정 오차 e = x − x̂는 \(\dot e = (A - LC)e\)로 줄어들므로, 가관측이면 L로 이 극점을 원하는 곳에 둡니다(제어기 극점 배치의 쌍대). 보통 제어 극점보다 2~5배 빠르게 둡니다.

예제 6.4.1

A = [[0, 1], [−2, −3]], C = [1, 0]. 관측기 극점을 −10, −10에 두는 L은?

풀이. A − LC = [[−l₁, 1], [−2 − l₂, −3]], 특성 다항식 s² + (3 + l₁)s + (3l₁ + 2 + l₂). 목표 s² + 20s + 100 → l₁ = 17, l₂ = 100 − 2 − 51 = 47. L = (17, 47). 6.3절 제어 극점(−2 ± j2)보다 약 5배 빨라 추정이 먼저 수렴합니다.

흔한 오해(1) "관측기 극점은 빠를수록 좋다": 측정 잡음을 크게 증폭합니다. (2) "관측기는 정확한 모델이 없어도 된다": 모델 오차만큼 추정이 틀립니다(칼만 필터는 잡음까지 고려).
요약
  1. x̂' = Ax̂ + Bu + L(y − Cx̂), e' = (A − LC)e.
  2. 예: 극점 −10, −10 → L = (17, 47).
  3. 제어 극점보다 2~5배 빠르게.

6.4.2연습문제

기본

  1. 오차 동역학 행렬은?
    답

    A − LC.

응용

  1. 관측기 극점을 −5, −5로 하는 L(같은 A, C)은?
    답

    l₁ = 7, l₂ = 25 − 2 − 21 = 2.

심화

  1. 분리 원리의 뜻은?
    답

    제어기 극점과 관측기 극점을 따로 설계해도 전체 극점이 두 집합의 합이 됩니다.
