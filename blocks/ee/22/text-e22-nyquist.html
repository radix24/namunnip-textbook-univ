Nyquist 판별법

본문
이 절에서 배울 것
  • 개루프 주파수 응답 L(jω)의 Nyquist 선도를 그린다.
  • Z = N + P(Z: 오른쪽 폐루프 극점, N: −1 둘레 시계 방향 횟수, P: 오른쪽 개루프 극점)를 쓴다.
  • 이득 여유와 위상 여유를 선도에서 읽는다.
먼저 알아야 할 것
  • 주파수 응답 (전전6 8.1절), 복소수 크기와 각, Routh (3.1절).

5.1.1판별

폐루프 특성 방정식 1 + L(s) = 0의 근은 L(s)가 −1이 되는 곳입니다. s가 오른쪽 반평면을 한 바퀴 돌 때 L(s)가 −1을 감는 횟수로 오른쪽 근의 수를 셉니다(편각 원리).

\[ Z = N + P. \]

개루프가 안정(P = 0)이면 Nyquist 선도가 −1을 감싸지 않아야 안정합니다.

예제 5.1.1

\(L = K/(s + 1)^3\). 안정한 K 범위와 K = 2일 때 이득 여유는?

풀이. 위상이 −180°인 ω: 3tan⁻¹ω = 180° → ω = √3. 그때 크기 \(K/(1 + 3)^{3/2} = K/8\). −1을 감싸지 않으려면 K/8 < 1 → K < 8(Routh로도 같음). K = 2면 선도가 −0.25를 지나 이득 여유 1/0.25 = 4(12 dB): 이득을 4배까지 늘릴 수 있습니다.

흔한 오해(1) "Nyquist는 Bode와 다른 정보": 같은 L(jω)을 극좌표로 그린 것입니다. (2) "개루프가 불안정하면 폐루프도 불안정": P > 0이어도 N = −P(반시계로 감음)이면 안정합니다.
요약
  1. Z = N + P. P = 0이면 −1을 감싸지 않아야 안정.
  2. 위상 −180° 주파수에서 |L| < 1.
  3. 예: K/(s+1)³ → K < 8, K = 2의 이득 여유 12 dB.

5.1.2연습문제

기본

  1. 이득 여유 6 dB는 이득을 몇 배까지 늘릴 수 있다는 뜻인가?
    답

    2배.

응용

  1. L = K/(s(s + 1)(s + 2))의 위상 −180° 주파수는?
    답

    √2 rad/s(Routh 결과와 같음).

심화

  1. 개루프 극점 1개가 오른쪽에 있을 때 안정하려면 N은?
    답

    N = −1(반시계 한 번).
