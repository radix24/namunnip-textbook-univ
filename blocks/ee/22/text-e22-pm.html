위상 여유 사양으로 보상기 설계

본문
이 절에서 배울 것
  • 이득 교차 주파수에서의 위상 여유 PM = 180° + ∠L(jω_c)를 계산한다.
  • 2차 시스템에서 PM과 ζ의 근사 관계(ζ ≈ PM/100)를 쓴다.
  • 진상 보상기의 최대 위상 \(\sin\phi_m = (1 - \alpha)/(1 + \alpha)\)로 여유를 보탠다.
먼저 알아야 할 것
  • Nyquist와 여유 (5.1절), Bode 선도 (전전6 8.1절), 진상 보상 (4.2절).

5.2.1위상 여유와 감쇠

|L(jω_c)| = 1인 이득 교차 주파수에서 위상이 −180°에서 떨어진 정도가 위상 여유입니다. 2차 시스템에서 PM이 30°, 45°, 60°이면 ζ는 대략 0.3, 0.42, 0.6입니다(근사 ζ ≈ PM/100, PM ≤ 60°).

예제 5.2.1

\(L = K/(s(s + 1))\). PM = 45°가 되는 K는? 이를 60°로 올리려면?

풀이. 위상 \(-90° - \tan^{-1}\omega = -135°\) → ω_c = 1. \(K = |j(j + 1)| = \sqrt2 = 1.414\). PM 60°는 ω_c를 \(\tan^{-1}\omega = 30°\), ω_c = 0.577로 낮춰 \(K = 0.577\sqrt{1.333} = 0.667\)로 얻을 수 있지만 응답이 느려집니다. 대신 진상 보상기로 15°에 여유분 5°를 더해 약 20°를 보태면 ω_c를 지키며 여유를 늘립니다: \(\sin20° = (1 - \alpha)/(1 + \alpha)\) → α ≈ 0.49, 보상기의 두 꺾임 주파수 가운데(기하 평균)를 새 교차 주파수에 둡니다.

흔한 오해(1) "위상 여유만 크면 충분": 이득 여유와 교차 주파수(속도)도 함께 봅니다. (2) "진상 보상기는 이득을 바꾸지 않는다": 고주파 이득이 1/α배 늘어 교차 주파수가 올라가므로 반복 조정이 필요합니다.
요약
  1. PM = 180° + ∠L(jω_c), |L(jω_c)| = 1.
  2. ζ ≈ PM/100.
  3. 예: K/(s(s+1)), PM 45° → K = 1.414. 진상 sinφ_m = (1−α)/(1+α).

5.2.2연습문제

기본

  1. PM 45°면 넘침은 대략?
    답

    ζ ≈ 0.42 → 약 23%.

응용

  1. α = 0.1인 진상 보상기의 최대 위상은?
    답

    sin⁻¹(0.9/1.1) ≈ 54.9°.

심화

  1. 지연 시간 T가 있으면 위상 여유는 어떻게 바뀌는가?
    답

    ω_cT 라디안만큼 줄어듭니다(e^{−sT}의 위상).
