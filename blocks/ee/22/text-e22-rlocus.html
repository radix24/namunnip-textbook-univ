근궤적 그리기와 이득 선택

본문
이 절에서 배울 것
  • K를 0에서 ∞로 바꿀 때 폐루프 극점의 자취(근궤적)의 규칙을 안다.
  • 실수축 위 구간, 점근선, 이탈점을 구한다.
  • 원하는 극점에서 크기 조건으로 K를 계산한다.
먼저 알아야 할 것
  • 2차 지표와 극점 영역 (2.1절, 2.2절), 이 절의 탐구 카드(근궤적).

4.1.1규칙

\(1 + KG(s) = 0\)의 근은 각 조건 \(\angle G(s) = 180°(2k + 1)\)과 크기 조건 \(K = 1/|G(s)|\)를 만족합니다.

  1. 개루프 극점에서 시작해 영점(또는 무한대)에서 끝난다.
  2. 실수축 위에서 오른쪽에 극점과 영점이 홀수 개인 구간이 궤적.
  3. 점근선: 각 \(180°(2k + 1)/(n - m)\), 중심 \((\sum p - \sum z)/(n - m)\).
  4. 이탈점: \(dK/ds = 0\).
예제 4.1.1

\(G = 1/(s(s + 2))\). 근궤적을 그리고 ζ = 0.5가 되는 K를 구하라.

풀이. 실수축 [−2, 0], 점근선 ±90°, 중심 −1, 이탈점 s = −1(K = 1). 이후 Re = −1인 수직선을 따라 위아래로. ζ = 0.5(각 60°)인 점: −1 ± j1.732. \(K = |s||s + 2| = 2 \times 2 = 4\). 폐루프 \(s^2 + 2s + 4\): ω_n = 2, ζ = 0.5로 맞습니다. 탐구 카드에서 다른 개루프로도 확인합니다.

흔한 오해(1) "근궤적은 개루프 극점의 움직임": 폐루프 극점의 자취입니다. (2) "이득을 바꾸면 정착 시간도 바뀐다": 이 예에서는 수직선 위를 움직여 실수부(정착)가 고정되고 넘침만 바뀝니다.
요약
  1. 각 조건 ∠G = ±180°, 크기 조건 K = 1/|G|.
  2. 실수축 구간, 점근선, 이탈점.
  3. 예: 1/(s(s+2)), ζ 0.5 → K = 4.

4.1.2연습문제

기본

  1. G = 1/(s + 1)의 근궤적은?
    답

    −1에서 왼쪽 실수축을 따라 −∞.

응용

  1. G = 1/(s(s + 1)(s + 2))의 점근선 각과 중심은?
    답

    ±60°, 180°; 중심 −1.

심화

  1. 문제 a에서 허수축과 만나는 K는(3.1절)?
    답

    K = 6, s = ±j1.414.
