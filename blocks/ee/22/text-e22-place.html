상태 궤환으로 극점 배치

본문
이 절에서 배울 것
  • 상태 궤환 u = −Kx + r의 폐루프 \(A - BK\)를 쓴다.
  • 제어기 표준형에서 계수 비교로 K를 구한다.
  • 가제어이면 극점을 임의로 배치할 수 있음을 알고, 관측기의 필요성을 안다.
먼저 알아야 할 것
  • 상태방정식 (6.1절), 가제어성 (6.2절), 극점 영역 (2.2절).

6.3.1계수 비교

u = −Kx를 넣으면 \(\dot x = (A - BK)x\). 원하는 극점의 특성 다항식과 \(\det(sI - A + BK)\)를 같게 놓아 K를 풉니다.

예제 6.3.1

6.1절의 시스템(\(A = \begin{pmatrix} 0 & 1 \\ -2 & -3 \end{pmatrix}\), B = (0, 1))에서 폐루프 극점을 −2 ± j2에 두는 K는?

풀이. 원하는 다항식 \((s + 2)^2 + 4 = s^2 + 4s + 8\). \(A - BK = \begin{pmatrix} 0 & 1 \\ -2 - k_1 & -3 - k_2 \end{pmatrix}\), 특성 다항식 \(s^2 + (3 + k_2)s + (2 + k_1)\). 비교: k₁ = 6, k₂ = 1, K = (6, 1). ζ = 0.707, 넘침 4.3%, 정착 약 2 s(2.2절의 영역 안).

모든 상태를 측정할 수 없으면 관측기(추정기)로 상태를 추정해 궤환합니다. 극점 배치와 관측기 설계는 분리해서 할 수 있습니다(분리 원리).

흔한 오해(1) "극점을 아주 왼쪽에 두면 언제나 좋다": K가 커져 입력이 포화되고 잡음에 민감해집니다. (2) "상태 궤환은 출력 궤환과 같다": 모든 상태가 필요하며, 출력만 쓰면 극점을 임의로 배치할 수 없습니다.
요약
  1. u = −Kx → A − BK.
  2. 제어기 표준형: 특성 다항식 계수 비교.
  3. 예: 극점 −2 ± j2 → K = (6, 1). 관측기와 분리 원리.

6.3.2연습문제

기본

  1. 같은 시스템에서 극점을 −3, −4에 두는 K는?
    답

    s² + 7s + 12 → k₁ = 10, k₂ = 4.

응용

  1. K = (0, 0)의 폐루프 극점은?
    답

    −1, −2(개루프 그대로).

심화

  1. 예제 6.2.1(나)처럼 불가제어인 시스템에서 −2 모드를 옮길 수 있는가?
    답

    아닙니다. 불가제어 모드는 상태 궤환으로 움직이지 않습니다.
