상태방정식과 전달함수

본문

전달함수는 입력과 출력 하나씩의 관계만 담는다. 그런데 드론은 프로펠러 네 개로 위치와 자세 여섯 가지를 함께 다루고, 초기 상태에서 출발하는 응답도 알아야 한다. 시스템 안의 모든 변수를 한꺼번에 다루는 식은 무엇일까? 그 식과 지금까지 쓴 전달함수는 어떻게 이어질까?

먼저 알아야 할 것행렬과 역행렬(전전16 1.1절), 고유값(전전16 4.1절), 전달함수(1.1절)를 쓴다.

6.1.1상태와 행렬

상태는 현재 값만 알면 앞으로의 응답을 모두 정할 수 있는 최소한의 변수 묶음이다. 예를 들어 \(\ddot y + 3\dot y + 2y = u\)에서 \(x_1 = y\), \(x_2 = \dot y\)로 두면, 2차 방정식이 1차 연립 방정식 두 개가 된다(그림 1).

\[ \dot x = \begin{pmatrix} 0 & 1 \\ -2 & -3 \end{pmatrix}x + \begin{pmatrix} 0 \\ 1 \end{pmatrix}u, \qquad y = \begin{pmatrix} 1 & 0 \end{pmatrix}x \]

상태방정식과 전달함수

상태방정식은 \(\dot x = Ax + Bu\), \(y = Cx + Du\)이다.

전달함수는 \(G(s) = C(sI - A)^{-1}B + D\)이다.

처음 질문의 첫째 답이 이것이다. 입력과 출력이 여러 개여도 B와 C의 열과 행만 늘리면 되고, 초기 조건과 내부 변수도 함께 다룬다.

예제 6.1.1

위 시스템의 전달함수를 \(C(sI - A)^{-1}B\)로 구하고 A의 고유값과 비교하라.

풀이. \(sI - A = \begin{pmatrix} s & -1 \\ 2 & s + 3 \end{pmatrix}\)이고, 행렬식은 \(s^2 + 3s + 2\)이다. 그러면 \((sI - A)^{-1}B = \frac{1}{s^2 + 3s + 2}\begin{pmatrix} 1 \\ s \end{pmatrix}\)이므로 \(G = 1/(s^2 + 3s + 2)\)이다. 즉 A의 고유값 −1, −2가 극점과 같다. 처음 질문의 둘째 답이 이것이다.

그런데 같은 전달함수에 상태방정식은 여러 개 있다. 좌표 변환 x = Tz로 상태를 바꿔 잡아도 입출력 관계는 그대로이기 때문이다. 위의 꼴은 특성 다항식의 계수가 A의 마지막 행에 그대로 들어가 있어, 제어기 표준형이라 한다(6.3절).

상태방정식은 시간 영역에서 바로 풀 수도 있다. 해는 \(x(t) = e^{At}x(0) + \int_0^te^{A(t-\tau)}Bu(\tau)\,d\tau\)이며, 첫째 항이 초기 조건의 응답, 둘째 항이 입력의 응답이다. 그러므로 전달함수로는 볼 수 없던 초기 조건의 영향도 같은 식 안에서 다룬다. 또 행렬 지수 함수 \(e^{At}\)의 모양은 A의 고유값이 정하므로, 고유값의 실수부가 모두 음수이면 상태가 0으로 줄어든다.

실제 수치 해석과 시뮬레이션 프로그램도 대부분 상태방정식을 쓴다. 1차 연립 방정식이라 Runge-Kutta 같은 적분법을 바로 적용할 수 있기 때문이다.

흔한 오해상태 변수가 하나로 정해진다고 여기기 쉽다. 상태는 좌표 선택에 따라 무수히 많다. 또 A의 고유값이 언제나 모두 전달함수의 극점으로 보인다고 생각하기 쉬운데, 극점-영점 상쇄가 있으면 일부가 전달함수에서 사라진다(6.2절).
마무리

상태방정식은 ẋ = Ax + Bu, y = Cx + Du이다. 전달함수는 G(s) = C(sI − A)⁻¹B + D이다. 상쇄가 없으면 A의 고유값이 곧 극점이다.

6.1.2연습문제

기본

  1. ÿ + 5ẏ + 6y = u의 제어기 표준형 A는?
    답

    [[0, 1], [−6, −5]]이다.

응용

  1. A = [[−1, 0], [0, −4]], B = [1; 1], C = [1 1]의 G는?
    답

    1/(s + 1) + 1/(s + 4)이다.

심화

  1. 좌표 변환 x = Tz 후의 A'는?
    답

    T⁻¹AT(고유값 불변)이다.
