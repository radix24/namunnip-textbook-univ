상태방정식과 전달함수

본문
이 절에서 배울 것
  • 미분방정식을 상태방정식 \(\dot x = Ax + Bu\), \(y = Cx + Du\)로 쓴다.
  • \(G(s) = C(sI - A)^{-1}B + D\)로 전달함수를 구한다.
  • A의 고유값이 전달함수의 극점임을 확인한다.
먼저 알아야 할 것
  • 행렬과 역행렬 (전전16 1.1절), 고유값 (전전16 4.1절), 전달함수 (1.1절).

6.1.1상태와 행렬

\(\ddot y + 3\dot y + 2y = u\)에서 \(x_1 = y\), \(x_2 = \dot y\)로 두면

\[ \dot x = \begin{pmatrix} 0 & 1 \\ -2 & -3 \end{pmatrix}x + \begin{pmatrix} 0 \\ 1 \end{pmatrix}u, \qquad y = \begin{pmatrix} 1 & 0 \end{pmatrix}x. \]
예제 6.1.1

위 시스템의 전달함수를 \(C(sI - A)^{-1}B\)로 구하고 A의 고유값과 비교하라.

풀이. \(sI - A = \begin{pmatrix} s & -1 \\ 2 & s + 3 \end{pmatrix}\), 행렬식 \(s^2 + 3s + 2\), \((sI - A)^{-1}B = \frac{1}{s^2 + 3s + 2}\begin{pmatrix} 1 \\ s \end{pmatrix}\). \(G = 1/(s^2 + 3s + 2)\). A의 고유값 −1, −2가 극점과 같습니다.

같은 전달함수에 상태방정식은 여러 개(좌표 변환 \(x = Tz\))가 있으며, 위의 꼴을 제어기 표준형이라 합니다. 상태방정식은 다입력·다출력과 초기 조건, 내부 변수를 함께 다룰 수 있습니다.

흔한 오해(1) "상태 변수는 하나로 정해진다": 좌표 선택에 따라 무수히 많습니다. (2) "A의 고유값은 언제나 모두 극점으로 보인다": 극점-영점 상쇄가 있으면 일부가 전달함수에서 사라집니다(6.2절).
요약
  1. ẋ = Ax + Bu, y = Cx + Du.
  2. G(s) = C(sI − A)⁻¹B + D.
  3. A의 고유값 = 극점(상쇄 없을 때).

6.1.2연습문제

기본

  1. ÿ + 5ẏ + 6y = u의 제어기 표준형 A는?
    답

    [[0, 1], [−6, −5]].

응용

  1. A = [[−1, 0], [0, −4]], B = [1; 1], C = [1 1]의 G는?
    답

    1/(s + 1) + 1/(s + 4).

심화

  1. 좌표 변환 x = Tz 후의 A'는?
    답

    T⁻¹AT(고유값 불변).
