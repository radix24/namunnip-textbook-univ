2차 시스템의 극점과 과도 응답

본문
이 절에서 배울 것
  • 표준형 \(\omega_n^2/(s^2 + 2\zeta\omega_ns + \omega_n^2)\)의 극점을 ζ, ω_n으로 쓴다.
  • 넘침, 첨두 시간, 상승 시간, 정착 시간을 ζ, ω_n과 연결한다.
  • 극점의 실수부·허수부·각도가 각 지표를 정하는 것을 해석한다.
먼저 알아야 할 것
  • 전달함수와 극점 (1.1절), Laplace 역변환 (전전6 7.3절), 이 절의 탐구 카드.

2.1.1극점과 지표

0 < ζ < 1이면 극점 \(-\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}\). 실수부가 감쇠 속도, 허수부(\(\omega_d\))가 진동 주파수, 원점에서의 각 \(\cos^{-1}\zeta\)가 넘침을 정합니다.

\[ M_p = e^{-\pi\zeta/\sqrt{1 - \zeta^2}}, \quad t_p = \frac{\pi}{\omega_d}, \quad t_s \approx \frac{4}{\zeta\omega_n}\ (2\%). \]
예제 2.1.1

ω_n = 1 rad/s에서 ζ = 0.3, 0.5, 0.7, 1의 계단 응답 지표를 비교하라(수치 측정).

ζ를 키우면 넘침이 줄지만 상승이 느려집니다. 정착 시간 근사 4/(ζω_n)은 ζ = 0.5에서 8 s로 측정값 8.08 s와 가깝고, ζ = 0.7에서는 5.71 s 대 5.98 s로 조금 어긋납니다(근사는 포락선 기준). ω_n을 두 배로 하면 모든 시간이 절반이 됩니다. 탐구 카드에서 직접 바꿔 봅니다.

흔한 오해(1) "넘침은 ω_n에 따라 달라진다": ζ만으로 정해집니다. (2) "ζ = 1이 가장 빠르다": 넘침 없는 것 중에서는 빠르지만, 약간의 넘침을 허용하면 더 빨리 정착합니다. 같은 방법으로 재면 ζ = 0.8(넘침 1.5%)의 2% 정착이 3.754 s로 ζ = 1(5.832 s)보다 짧습니다.
요약
  1. 극점 −ζω_n ± jω_d. 각 cos⁻¹ζ가 넘침, 실수부가 정착.
  2. M_p = e^{−πζ/√(1−ζ²)}, t_p = π/ω_d, t_s ≈ 4/(ζω_n).
  3. ζ 0.5: 16.3%, ζ 0.7: 4.6%(ω_n = 1).
