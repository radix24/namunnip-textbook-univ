시스템 형과 정상상태 오차

본문
이 절에서 배울 것
  • 개루프의 원점 극점 수(시스템 형)를 센다.
  • 위치·속도·가속도 오차 상수 K_p, K_v, K_a로 정상상태 오차를 구한다.
  • 적분기가 오차를 없애는 원리를 최종값 정리로 설명한다.
먼저 알아야 할 것
  • 최종값 정리 (1.1절), 폐루프 (1.2절).

3.2.1오차 상수

단위 궤환에서 \(E = R/(1 + G)\). 최종값 정리로

입력오차형 0형 1형 2
계단1/(1 + K_p), K_p = G(0)유한00
경사1/K_v, K_v = lim sG∞유한0
포물선1/K_a, K_a = lim s²G∞∞유한
예제 3.2.1

\(G = K/(s(s + 1)(s + 2))\)(형 1)에서 K = 4일 때 단위 경사 입력의 정상상태 오차는? (3.1절에서 안정)

풀이. \(K_v = \lim_{s\to0}sG = K/2 = 2\), 오차 0.5. 오차를 0.2로 줄이려면 K = 10이 필요하지만 K < 6이라 불안정해집니다. 정확도와 안정도의 충돌이며, 지상 보상기(4.2절)나 PI 제어(4.3절)로 해결합니다.

흔한 오해(1) "최종값 정리는 언제나 쓸 수 있다": 폐루프가 안정할 때만 씁니다. (2) "이득을 키우면 오차가 0이 된다": 형 0에서 계단 오차는 1/(1 + K)로 줄 뿐 0이 되지 않습니다.
요약
  1. 형 = 개루프 원점 극점 수.
  2. 계단 1/(1 + K_p), 경사 1/K_v, 포물선 1/K_a.
  3. 적분기(형 증가)가 오차를 없앤다. 안정도와 교환.
