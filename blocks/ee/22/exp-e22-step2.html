감쇠비와 고유 주파수로 계단 응답 빚기

탐구 · 2차 시스템의 과도 응답 지표

질문

극점을 옮기면 계단 응답의 넘침과 정착 시간은 어떻게 바뀔까요?

준비

\(G(s) = \omega_n^2/(s^2 + 2\zeta\omega_ns + \omega_n^2)\)의 단위 계단 응답을 0 ~ 12/ω_n초 동안 그리고, 넘침·첨두 시간·상승 시간(10~90%)·2% 정착 시간을 그래프에서 수치로 잽니다(2.1절). 점선은 최종값 1과 ±2% 띠입니다.

해 보기와 설명

  1. 처음 화면ζ = 0.5, ω_n = 1: 넘침 16.3%, 첨두 3.628 s, 상승 1.636 s, 정착 8.076 s(예제 2.1.1의 표).
  2. ω_n 두 배ω_n = 2면 넘침은 16.3% 그대로, 시간은 모두 절반(첨두 1.814 s, 정착 4.038 s).
  3. ζ = 0.7넘침 4.6%, 정착 5.978 s로 ζ = 0.5보다 빨리 정착합니다.
  4. ζ = 0.8넘침 1.5%, 정착 3.754 s. 넘침이 ±2% 띠 안에 머물러 가장 빨리 정착하는 근처입니다.
  5. ζ ≥ 1넘침이 사라지고, ζ = 1에서 정착 5.832 s. ζ = 2면 너무 느려 12 s 창 안에 정착하지 않습니다.

연결과 적용

서보 모터, 드론 자세 제어, 하드 디스크 헤드처럼 빠르면서 넘침이 작아야 하는 시스템은 보통 ζ ≈ 0.6 ~ 0.8을 목표로 설계합니다.

흔한 오해

  • "감쇠를 키울수록 빨라진다." 넘침은 줄지만 ζ ≈ 0.8을 넘으면 오히려 정착이 느려집니다(ζ = 1에서 5.832 s).
  • "넘침은 ω_n으로 줄일 수 있다." 넘침은 ζ만의 함수입니다. ω_n은 시간 축 척도만 바꿉니다.
