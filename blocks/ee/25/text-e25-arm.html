ARM 어셈블리로 반복문과 함수 호출

본문
이 절에서 배울 것
  • 비교·조건 분기로 반복문을 작성한다.
  • BL/BX LR과 PUSH/POP으로 함수 호출과 레지스터 보존을 한다.
  • AAPCS 호출 규약(인자 R0~R3, 피호출자 보존 R4~R11)을 지킨다.
먼저 알아야 할 것
  • 어셈블리 기초 (1.2절), 스택 (전전2 3단원).

6.1.1함수 안에서 다른 함수 부르기

1부터 n까지 제곱의 합을 구하는 함수가 square를 부르는 예입니다.

square: MUL   r0, r0, r0       @ r0 = r0 * r0
        BX    lr

sumsq:  PUSH  {r4, r5, lr}     @ 쓸 피호출자 보존 레지스터와 복귀 주소 저장
        MOV   r4, r0           @ r4 = n (호출을 건너 살아남아야 함)
        MOVS  r5, #0           @ r5 = 합
loop:   CMP   r4, #0
        BEQ   done
        MOV   r0, r4
        BL    square           @ lr이 덮어써짐 → 앞에서 저장해 둔 이유
        ADD   r5, r5, r0
        SUBS  r4, r4, #1
        B     loop
done:   MOV   r0, r5
        POP   {r4, r5, pc}     @ 저장한 lr을 pc로 꺼내 복귀
예제 6.1.1

sumsq(3)의 결과와, PUSH에 lr을 넣지 않았다면 생기는 일은?

풀이. 9 + 4 + 1 = 14. lr을 저장하지 않으면 BL square가 lr을 덮어써, 마지막에 sumsq를 부른 곳이 아니라 루프 안으로 돌아가 무한 반복하거나 엉뚱한 곳으로 갑니다. 다른 함수를 부르지 않는 잎 함수(square)는 lr을 저장할 필요가 없습니다.

흔한 오해(1) "R0~R3은 함수 호출 뒤에도 그대로": 호출자 보존 레지스터라 피호출 함수가 마음대로 바꿉니다. (2) "PUSH 순서는 쓴 순서대로": 레지스터 목록은 번호 순으로 저장됩니다.
요약
  1. CMP + 조건 분기로 반복.
  2. BL은 lr에 복귀 주소, 중첩 호출이면 lr을 PUSH.
  3. AAPCS: 인자 R0~R3, R4~R11 보존.

6.1.2연습문제

기본

  1. sumsq(4)의 결과는?
    답

    30.

응용

  1. square가 r4를 썼다면 무엇을 해야 하는가?
    답

    PUSH/POP으로 r4를 보존해야 합니다(피호출자 보존).

심화

  1. POP {pc}가 복귀가 되는 이유는?
    답

    저장해 둔 lr 값(복귀 주소)이 pc에 들어가기 때문입니다.
