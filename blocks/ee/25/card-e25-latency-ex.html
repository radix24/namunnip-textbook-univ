모터 제어 인터럽트 예산

주기 · 부하율

출발점

주기 인터럽트의 실행 시간 합이 주기보다 충분히 작아야 합니다(2.3절).

문제 해결 전략 · 부하율 = 실행/주기
  1. PWM 주기 인터럽트 20 kHz(50 μs).
  2. ISR 실행 18 μs, 통신 ISR 평균 5 μs/주기.
  3. 부하율.

CPU 부하율과 남는 시간은?

풀이

  1. (18 + 5)/50 = 46%.
    부하율.
  2. 남는 27 μs가 메인 루프 몫.
    여유.
  3. 최악에 통신 ISR이 몰리면 줄어듦.
    주의.

의미

제어 ISR은 가장 높은 우선순위에 두고 실행 시간을 측정해 예산을 관리한다.

검산

23/50 = 0.46.
