타이머로 PWM 만들기

본문

마이크로컨트롤러의 디지털 핀은 0 V와 3.3 V 두 값만 낼 수 있다. 그런데도 LED 밝기를 부드럽게 바꾸고 모터 속도를 조절할 수 있는 것은, 핀을 빠르게 켰다 껐다 하며 켜진 시간의 비율을 바꾸기 때문이다. 타이머로 이런 PWM 신호를 만들려면 어떤 값을 설정할까? 그리고 주파수와 세밀함은 어떻게 맞바뀔까?

먼저 알아야 할 것타이머 인터럽트(2.2절), 주변 장치(4.1절)를 쓴다.

4.4.1세고, 비교하고

카운터가 0부터 ARR까지 세고 다시 시작하면, PWM 주파수는 \(f = f_{clk}/((PSC + 1)(ARR + 1))\)이다. 그리고 카운터가 비교 값 CCR보다 작을 때 출력이 1이면, 듀티는 CCR/(ARR + 1)이다(그림 1). 처음 질문의 첫째 답이 이 두 값이다.

즉 단계 수 ARR + 1이 듀티 분해능이다. 그런데 클록이 정해져 있으면 주파수를 높일수록 단계 수가 준다. 처음 질문의 둘째 답이 이 맞바꿈이다.

예제 4.4.1

타이머 클록 72 MHz, 분주 없음, PWM 20 kHz의 ARR과 듀티 분해능은? 듀티 25%의 CCR은?

풀이. ARR + 1 = 72 MHz/20 kHz = 3600이므로 ARR = 3599이고, 분해능은 log₂3600 ≈ 11.8비트이다. 그리고 듀티 25%의 CCR은 900이다. 따라서 주파수를 높이면 단계 수가 줄어 분해능이 떨어지며, 200 kHz면 360단계뿐이다.

한편 모터 구동에서는 PWM 주파수를 사람이 듣는 범위(약 20 kHz) 위로 올려 소음을 줄인다. 그러나 주파수가 너무 높으면 스위칭 손실이 커지므로, 전력전자 설계와 함께 정한다.

그리고 듀티를 바꿀 때 CCR을 주기 중간에 고치면 한 주기가 찌그러질 수 있다. 그래서 타이머는 새 값을 다음 주기 시작에 반영하는 미리 적재 기능을 둔다.

또한 여러 채널이 같은 카운터를 쓰면 주파수는 같고 듀티만 채널마다 다르게 줄 수 있다. 예를 들어 RGB LED의 세 색은 한 타이머의 세 채널로 각각 밝기를 정한다.

흔한 오해PWM 주파수와 분해능을 따로 정할 수 있다고 여기기 쉽다. 클록이 정해져 있으면 둘은 서로 반비례한다. 또 ARR이 곧 주기의 카운트 수라고 생각하기 쉬운데, 0부터 세므로 주기는 ARR + 1이다.
마무리

PWM 주파수는 f = f_clk/((PSC + 1)(ARR + 1))이다. 듀티는 CCR/(ARR + 1)이다. 72 MHz에서 20 kHz는 ARR 3599, 약 11.8비트이다.

4.4.2연습문제

기본

  1. 72 MHz, ARR 999, PSC 0의 PWM 주파수는?
    답

    72 kHz이다.

응용

  1. 같은 설정에서 듀티 40%의 CCR은?
    답

    400이다.

심화

  1. LED 밝기 PWM 주파수를 몇 Hz 이상으로 하나?
    답

    깜빡임이 안 보이도록 수백 Hz 이상이다(기준마다 다르므로 확인 필요).
