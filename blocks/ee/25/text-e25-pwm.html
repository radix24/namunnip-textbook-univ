타이머로 PWM 만들기

본문
이 절에서 배울 것
  • 타이머 클록, 분주비, 자동 재장전 값으로 PWM 주파수를 정한다.
  • 비교 값으로 듀티비를 정하고 듀티 분해능을 계산한다.
  • 서보 모터처럼 정해진 펄스 폭 신호를 만든다.
먼저 알아야 할 것
  • 타이머 인터럽트 (2.2절), 주변 장치 (4.1절).

4.4.1세고, 비교하고

카운터가 0부터 ARR까지 세고 다시 시작하면 PWM 주파수 \(f = f_{clk}/((PSC + 1)(ARR + 1))\). 카운터가 비교 값 CCR보다 작을 때 출력 1이면 듀티 = CCR/(ARR + 1). 단계 수 ARR + 1이 듀티 분해능입니다.

예제 4.4.1

타이머 클록 72 MHz, 분주 없음, PWM 20 kHz의 ARR과 듀티 분해능은? 듀티 25%의 CCR은?

풀이. ARR + 1 = 3600 → ARR = 3599, 분해능 약 11.8비트. CCR = 900. 주파수를 높이면 단계 수가 줄어 분해능이 떨어지는 절충이 있습니다(200 kHz면 360단계).

흔한 오해(1) "PWM 주파수와 분해능을 따로 정할 수 있다": 클록이 정해져 있으면 서로 반비례합니다. (2) "ARR은 주기 카운트 수": 0부터 세므로 주기는 ARR + 1입니다.
요약
  1. f = f_clk/((PSC + 1)(ARR + 1)).
  2. 듀티 = CCR/(ARR + 1).
  3. 예: 72 MHz, 20 kHz → ARR 3599, 11.8비트.

4.4.2연습문제

기본

  1. 72 MHz, ARR 999, PSC 0의 PWM 주파수는?
    답

    72 kHz.

응용

  1. 같은 설정에서 듀티 40%의 CCR은?
    답

    400.

심화

  1. LED 밝기 PWM 주파수를 몇 Hz 이상으로 하나?
    답

    깜빡임이 안 보이도록 수백 Hz 이상(확인 필요: 기준마다).
