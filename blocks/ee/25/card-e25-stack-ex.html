인터럽트까지 고려한 스택 크기

최악 경로 합

출발점

스택 크기는 가장 깊은 호출 경로에 인터럽트 프레임을 더해 잡습니다(1.4절, 2.1절).

문제 해결 전략 · 경로별 합
  1. main 경로 최대 600바이트.
  2. 인터럽트 진입 자동 저장 32바이트 + ISR 사용 120바이트.
  3. 중첩 인터럽트 2단계.

필요한 스택 크기와 여유 50%를 둔 값은?

풀이

  1. ISR 한 단계 152바이트, 2단계 304바이트.
    인터럽트.
  2. 합 904바이트.
    최악.
  3. 여유 50%로 약 1.4 KB.
    할당.

의미

정적 분석 도구(호출 그래프)와 실행 중 감시 값 확인을 함께 씁니다.

검산

600 + 2 × (32 + 120) = 904.
