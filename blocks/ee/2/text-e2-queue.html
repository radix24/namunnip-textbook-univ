큐, 원형 큐, 덱

본문
이 절에서 배울 것
  • 큐 ADT(enqueue, dequeue)와 FIFO의 뜻을 안다.
  • 배열로 큐를 만들 때 앞을 당기는 비용을 피하려고 나머지 연산으로 감아 도는 원형 큐를 구현한다.
  • 가득 참과 비어 있음을 구별하는 방법, 덱(양쪽 끝)의 쓰임을 안다.
먼저 알아야 할 것
  • 스택 (2.2절), 배열 비용 (2.1절), 나머지 연산과 클래스 (공통10 3.3절).

2.3.1큐 ADT

큐: 뒤(rear)에서 넣고(enqueue) 앞(front)에서 빼는(dequeue) 리스트. 먼저 들어간 것이 먼저 나온다(FIFO).

프린터 대기열, 네트워크 패킷 버퍼, 키보드 입력 버퍼, 그래프의 너비 우선 탐색(7단원)이 큐입니다. 하드웨어에서도 UART 수신 버퍼, 오디오 샘플 버퍼처럼 고정 크기 원형 버퍼(링 버퍼)를 많이 씁니다.

Python 리스트로 pop(0)을 쓰면 앞을 당기느라 O(n)입니다. 배열을 쓰면서도 O(1)에 빼려면 앞의 위치를 움직이면 됩니다.

2.3.2원형 큐

구하려는 것: 크기 고정 배열에서 enqueue와 dequeue가 모두 O(1)인 큐. front 위치와 원소 수 size를 기억하고, 끝에 닿으면 처음으로 감아 돕니다(나머지 연산).

class CircularQueue:
    def __init__(self, cap):
        self.buf = [None] * cap
        self.front = 0          # 맨 앞 원소의 위치
        self.size = 0

    def enqueue(self, x):
        if self.size == len(self.buf):
            raise OverflowError("가득 참")
        rear = (self.front + self.size) % len(self.buf)
        self.buf[rear] = x
        self.size += 1

    def dequeue(self):
        if self.size == 0:
            raise IndexError("비어 있음")
        x = self.buf[self.front]
        self.buf[self.front] = None
        self.front = (self.front + 1) % len(self.buf)
        self.size -= 1
        return x
예제 2.3.1

용량 4인 원형 큐에 10, 20, 30을 넣고 둘을 뺀 뒤 40, 50, 60을 넣으면 배열의 모습과 front는? 70을 더 넣으면?

풀이. 10, 20, 30이 칸 0~2. 두 번 빼면 front = 2, size = 1(30만 남음). 40은 칸 3, 50은 (2 + 2) % 4 = 칸 0, 60은 칸 1로 감아 돕니다. 배열은 [50, 60, 30, 40], front = 2, size = 4(가득 참). 70은 "가득 참" 오류. 이후 네 번 빼면 30, 40, 50, 60 순서로 나옵니다(실습 카드에서 확인).

2.3.3가득 참과 비어 있음

front와 rear 두 위치만 기억하면 front = rear가 "비어 있음"과 "가득 참" 둘 다일 수 있어 구별되지 않습니다. 해결 방법은 (1) 위 코드처럼 size를 따로 둔다, (2) 한 칸을 일부러 비워 두어 (rear + 1) % cap = front를 가득 참으로 정한다, 두 가지입니다. 하드웨어 버퍼는 (2)를 많이 씁니다(읽는 쪽과 쓰는 쪽이 서로 다른 변수만 바꾸므로 동기화가 쉬움).

덱(deque): 양쪽 끝 모두에서 넣고 뺄 수 있는 리스트. 원형 배열이나 이중 연결 리스트로 O(1). Python의 collections.deque.

흔한 오해(1) "원형 큐는 원형으로 생긴 메모리를 쓴다": 메모리는 보통의 배열이고, 나머지 연산으로 끝과 처음을 이을 뿐입니다. (2) rear를 (rear + 1)로만 늘리고 % cap을 빠뜨리는 실수: 배열 범위를 넘습니다. (3) 가득 찼을 때 자동으로 덮어쓰게 만들면(오래된 자료 버림) 오디오 같은 곳에서는 맞지만, 명령 큐에서는 자료를 잃습니다. 어떤 정책인지 명시해야 합니다.
요약
  1. 큐: 뒤에서 넣고 앞에서 뺌, FIFO. 리스트 pop(0)은 O(n).
  2. 원형 큐: front + size를 % cap으로 감아 돌려 둘 다 O(1).
  3. 가득 참/비어 있음 구별: size 변수 또는 한 칸 비우기. 양쪽 끝은 덱.

2.3.4연습문제

기본

  1. 용량 5, front = 3, size = 4인 원형 큐의 다음 enqueue 위치는?
    답

    (3 + 4) % 5 = 2.

응용

  1. "한 칸 비우기" 방식에서 용량 8 배열에 최대 몇 개 넣을 수 있는가? 원소 수를 front와 rear로 구하는 식은?
    답

    7개. 원소 수 = (rear − front + cap) % cap.

  2. 최근 1000개 센서 값의 이동 평균을 매 표본마다 O(1)로 갱신하는 방법은?
    답

    크기 1000 원형 버퍼와 현재 합을 유지. 새 값을 넣을 때 가장 오래된 값을 빼고 새 값을 더한 뒤 1000으로 나눔(전전6의 이동 평균 필터).

심화

  1. 원형 큐를 동적으로 키우려면(가득 차면 두 배) 단순히 배열 뒤에 칸을 붙이면 안 되는 이유와 올바른 방법은?
    답

    감아 돈 원소들(front 앞쪽에 있는 뒤쪽 원소들)의 순서가 깨집니다. 새 배열에 front부터 size개를 순서대로 복사하고 front = 0으로 둡니다.
