점근 표기: O, Ω, Θ

본문

알고리즘 A는 연산을 \(100n\log_2 n\)번, B는 \(n^2\)번 한다. \(n = 100\)이면 A가 66,000번, B가 10,000번으로 B가 빠르다. 그러면 B가 더 좋은 알고리즘일까? 계수 100 같은 숫자는 버리고 무엇을 보아야 할까?

먼저 알아야 할 것연산 횟수 세기(1.1절)와 고교 수학의 극한, 로그의 성질(공통1)을 쓴다.

1.2.1증가율만 남기기

1.1절의 \(\frac{n(n - 1)}{2}\)과 \(3n^2 + 5n\)은 계수와 낮은 차수 항이 다르지만, \(n\)이 커지면 둘 다 \(n^2\)처럼 늘어난다. 계수는 컴퓨터와 언어에 따라 바뀌지만, 증가율은 알고리즘 자체의 성질이다. 그래서 증가율만 남기고 나머지를 버리는 말을 쓰는데, 이것이 점근 표기이다.

정의 1.2.1 (O, Ω, Θ)

양의 상수 \(c\)와 \(n_0\)가 있어 모든 \(n \ge n_0\)에서 \(f(n) \le c\,g(n)\)이면 \(f(n) = O(g(n))\)이라 한다(위 한계). 같은 조건에서 \(f(n) \ge c\,g(n)\)이면 \(f(n) = \Omega(g(n))\)이라 한다(아래 한계). 둘 다 성립해 \(c_1 g(n) \le f(n) \le c_2 g(n)\)이면 \(f(n) = \Theta(g(n))\)이라 한다.

정의의 두 부분이 무엇을 버리는지 보자. 상수 \(c\)는 계수를 버리고, \(n_0\)는 작은 \(n\)에서 일어나는 일을 버린다. 그림 1에서 \(n_0\)보다 오른쪽만 보고, 세로로 몇 배 늘리거나 줄이는 것은 상관하지 않겠다는 뜻이다. 또 "="를 쓰지만 실제로는 "속한다"는 뜻이어서 \(n = O(n^2)\)은 맞는 느슨한 위 한계이고, \(n^2 = O(n)\)은 틀리다.

1.2.2정의로 보이기, 극한으로 판정하기

예제 1.2.1

\(f(n) = 3n^2 + 5n + 2 = \Theta(n^2)\)임을 \(c\)와 \(n_0\)를 찾아 보여라.

풀이. 위 한계부터 보자. \(n \ge 1\)이면 \(5n \le 5n^2\)이고 \(2 \le 2n^2\)이므로 \(f(n) \le 10n^2\)이다. 따라서 \(c = 10\), \(n_0 = 1\)로 \(O(n^2)\)이다. 아래 한계는 모든 항이 양수이므로 \(f(n) \ge 3n^2\)에서 \(c = 3\)으로 충분하다. 그러므로 \(n \ge 1\)에서 \(3n^2 \le f(n) \le 10n^2\)이고 \(f(n) = \Theta(n^2)\)이다.

매번 상수를 찾기는 번거로우므로 극한을 쓰기도 한다. \(\lim_{n\to\infty} f(n)/g(n) = L\)이 0이 아닌 유한한 값이면 \(\Theta\)이고, 0이면 \(f\)가 더 느리게 자라 \(f = O(g)\)이며, 무한대이면 더 빠르게 자라 \(f = \Omega(g)\)이다. 가령 \(\lim \frac{\log n}{n} = 0\)이므로 \(\log n = O(n)\)이다.

1.2.3증가율의 사다리

자주 만나는 증가율을 느린 것부터 늘어놓으면 다음과 같다.

표기이름예\(n = 10^6\)일 때 연산 수
\(O(1)\)상수배열 인덱싱1
\(O(\log n)\)로그이진 탐색약 20
\(O(n)\)선형최댓값 찾기10⁶
\(O(n\log n)\)선형 로그병합 정렬약 2×10⁷
\(O(n^2)\)이차모든 쌍 비교10¹²
\(O(2^n)\)지수모든 부분집합(\(n = 60\)이면 이미 10¹⁸)

1초에 10⁹번 연산하는 컴퓨터라면 \(n = 10^6\)에서 \(n\log n\)은 0.02초, \(n^2\)은 1000초, 곧 약 17분이다. 자료가 커질수록 알고리즘의 차수가 하드웨어의 속도보다 훨씬 큰 차이를 만든다.

예제 1.2.2

처음 질문의 A(\(100n\log_2 n\))와 B(\(n^2\))에서, 어느 \(n\)부터 A가 빠른가?

풀이. 양변을 \(n\)으로 나누면 \(100\log_2 n < n\)이 되는 \(n\)을 찾으면 된다. \(n = 512\)이면 \(100\times9 = 900 > 512\)이고, \(n = 1024\)이면 \(1000 < 1024\)이다. 따라서 대략 \(n \approx 1000\)부터 A가 빠르다(정확히는 997 근처). 그림 1의 교차점이 이것이다. 처음 질문에 답하면, \(n = 100\)에서 B가 빠른 것은 계수 덕분이고, 큰 입력에서는 증가율이 낮은 A가 이긴다. 실제 정렬 라이브러리가 작은 구간에서만 \(O(n^2)\)이지만 상수가 작은 삽입 정렬로 바꾸는 까닭도 여기에 있다.

흔한 오해O는 최악 경우, Ω는 최선 경우라고 생각하기 쉽다. 하지만 이 표기는 함수의 한계를 말할 뿐이어서, 최악이든 평균이든 최선이든 어느 경우의 함수에나 쓸 수 있다. 삽입 정렬의 최악 경우는 \(\Theta(n^2)\), 최선 경우는 \(\Theta(n)\)이다. 또 \(\log_2 n\)과 \(\log_{10} n\)은 상수배 차이라 점근 표기에서는 로그의 밑을 쓰지 않는다.
마무리

\(n = 100\)에서 B가 빠른 것은 A의 계수 100 때문이며, 증가율을 비교하면 \(n^2\)이 \(n\log n\)보다 빨리 자라 \(n \approx 1000\)부터는 A가 이긴다. 점근 표기 O, Ω, Θ는 상수 \(c\)로 계수를, \(n_0\)로 작은 입력을 버리고 증가율만 남기며, 큰 \(n\)에서는 차수가, 작은 \(n\)에서는 상수가 빠르기를 정한다.

1.2.4연습문제

기본

  1. \(5n^3 - 100n^2 + 7\)은 어떤 Θ인가?
    답

    \(\Theta(n^3)\).

  2. \(\log(n^2)\)과 \(\log n\)의 관계는?
    답

    \(\log(n^2) = 2\log n\)이므로 같은 \(\Theta(\log n)\)이다.

응용

  1. \(n^2 \ne O(n)\)임을 귀류법으로 보여라.
    답

    \(c\), \(n_0\)가 있어 \(n^2 \le cn\)이라면 \(n \le c\)가 모든 \(n \ge n_0\)에서 성립해야 하지만, \(n = \max(n_0, c + 1)\)에서 모순이다.

심화

  1. \(2^{n+1} = O(2^n)\)인가? \(2^{2n} = O(2^n)\)인가?
    답

    앞은 \(2\cdot2^n\)이므로 \(c = 2\)로 성립한다. 뒤는 \(2^{2n}/2^n = 2^n \to \infty\)이므로 성립하지 않는다. 지수의 계수는 상수배가 아니다.
