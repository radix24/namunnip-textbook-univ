점근 표기: O, Ω, Θ

본문
이 절에서 배울 것
  • O, Ω, Θ의 정의를 상수 c와 n₀로 쓰고, 주어진 함수가 어느 집합에 속하는지 증명한다.
  • 자주 나오는 증가율의 순서 \(1 < \log n < n < n\log n < n^2 < 2^n < n!\)을 안다.
  • 점근 표기로 두 알고리즘을 비교하고, 작은 n에서는 상수가 중요할 수 있음을 안다.
먼저 알아야 할 것
  • 연산 횟수 세기 (1.1절), 극한과 로그의 성질(고교 수학, 공통1).

1.2.1왜 대략만 보는가

1.1절의 \(\frac{n(n - 1)}{2}\)과 \(3n^2 + 5n\)은 계수와 낮은 차수 항이 다르지만, n이 커지면 둘 다 n²처럼 늘어납니다. 계수는 컴퓨터와 언어에 따라 바뀌지만, 증가율은 알고리즘 자체의 성질입니다. 점근 표기는 이 증가율만 남기는 언어입니다.

O(빅오, 위 한계): \(f(n) = O(g(n))\) ⇔ 양의 상수 c와 \(n_0\)가 있어 모든 \(n \ge n_0\)에서 \(f(n) \le c\,g(n)\).

Ω(빅오메가, 아래 한계): \(f(n) \ge c\,g(n)\) (\(n \ge n_0\)).

Θ(빅세타, 꽉 낀 한계): O이면서 Ω. \(c_1g(n) \le f(n) \le c_2g(n)\).

"=" 기호를 쓰지만 실제로는 "속한다"는 뜻입니다. \(n = O(n^2)\)은 맞지만(느슨한 위 한계), \(n^2 = O(n)\)은 틀립니다.

1.2.2정의로 증명하기

예제 1.2.1

\(f(n) = 3n^2 + 5n + 2 = \Theta(n^2)\)임을 c와 \(n_0\)를 찾아 보여라.

풀이. 위 한계: \(n \ge 1\)이면 \(5n \le 5n^2\), \(2 \le 2n^2\)이므로 \(f(n) \le 10n^2\). c = 10, \(n_0 = 1\). 아래 한계: 모든 항이 양수라 \(f(n) \ge 3n^2\). c = 3. 따라서 \(3n^2 \le f(n) \le 10n^2\) (\(n \ge 1\)), Θ(n²)입니다.

극한으로 판정. \(\lim_{n\to\infty}f(n)/g(n) = L\)이 0이 아닌 유한한 값이면 Θ, 0이면 f가 더 느리게 자람(\(f = O(g)\), Θ는 아님), ∞이면 더 빠르게 자람(\(f = \Omega(g)\)). 예: \(\lim\frac{\log n}{n} = 0\)이므로 \(\log n = O(n)\).

1.2.3증가율의 사다리

표기이름예n = 10⁶일 때 연산 수
\(O(1)\)상수배열 인덱싱1
\(O(\log n)\)로그이진 탐색약 20
\(O(n)\)선형최댓값 찾기10⁶
\(O(n\log n)\)선형 로그병합 정렬약 2×10⁷
\(O(n^2)\)이차모든 쌍 비교10¹²
\(O(2^n)\)지수모든 부분집합(n = 60이면 이미 10¹⁸)

초당 10⁹번 연산하는 컴퓨터라면 n = 10⁶에서 \(n\log n\)은 0.02초, n²은 1000초(약 17분)입니다. 자료가 커질수록 알고리즘의 차수가 하드웨어 속도보다 훨씬 중요합니다.

예제 1.2.2

알고리즘 A는 \(100n\log_2n\)번, B는 \(n^2\)번 연산한다. 어느 n부터 A가 빠른가?

풀이. \(100\log_2n < n\)이 되는 n. n = 512면 \(100 \times 9 = 900 > 512\), n = 1024면 1000 < 1024. 대략 n ≈ 1000부터 A가 빠르고(정확히는 997 근처), 그보다 작은 입력에서는 차수가 높은 B가 빠릅니다. 그래서 실제 정렬 라이브러리는 작은 구간에서 삽입 정렬(\(O(n^2)\), 작은 상수)로 바꿉니다.

흔한 오해(1) "O는 최악 경우, Ω는 최선 경우": 표기는 함수의 한계일 뿐이고, 어느 경우(최악·평균·최선)의 함수에든 쓸 수 있습니다. 예: 삽입 정렬의 최악 경우는 Θ(n²), 최선 경우는 Θ(n). (2) 로그의 밑: \(\log_2n\)과 \(\log_{10}n\)은 상수배 차이라 점근 표기에서 밑을 쓰지 않습니다. (3) "O(n) 알고리즘은 언제나 O(n²) 알고리즘보다 빠르다": 큰 n에서만 보장되고, 상수에 따라 작은 n에서는 반대일 수 있습니다.
요약
  1. O(위), Ω(아래), Θ(둘 다). 상수 c, \(n_0\)로 정의하거나 비의 극한으로 판정.
  2. \(1 < \log n < n < n\log n < n^2 < 2^n\).
  3. 큰 n에서는 차수가, 작은 n에서는 상수가 결정한다.

1.2.4연습문제

기본

  1. \(5n^3 - 100n^2 + 7\)은 어떤 Θ인가?
    답

    Θ(n³).

  2. \(\log(n^2)\)과 \(\log n\)의 관계는?
    답

    \(\log(n^2) = 2\log n\), 같은 Θ(log n).

응용

  1. \(n^2 \ne O(n)\)임을 귀류법으로 보여라.
    답

    c, \(n_0\)가 있어 \(n^2 \le cn\)이라면 \(n \le c\)가 모든 \(n \ge n_0\)에서 성립해야 하지만, \(n = \max(n_0, c + 1)\)에서 모순.

심화

  1. \(2^{n+1} = O(2^n)\)인가? \(2^{2n} = O(2^n)\)인가?
    답

    앞은 예(\(2 \cdot 2^n\), c = 2). 뒤는 아니오(\(2^{2n}/2^n = 2^n \to \infty\)). 지수의 계수는 상수배가 아닙니다.
