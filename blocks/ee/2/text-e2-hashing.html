해시 테이블: 체이닝과 개방 주소법

본문
이 절에서 배울 것
  • 사전 ADT를 평균 O(1)에 구현하는 해시 테이블의 생각(키 → 해시 함수 → 칸 번호)을 안다.
  • 충돌을 연결 리스트로 모으는 체이닝과, 빈 칸을 찾아가는 개방 주소법(선형 조사)을 비교한다.
  • 적재율 α = n/m에 따른 평균 탐색 비용 식을 쓰고, 실제로 센 값과 비교한다.
먼저 알아야 할 것
  • Python 딕셔너리 (공통10 2.2절), 연결 리스트 (2.1절), 나머지 연산, 기댓값(고교 확률).

6.1.1키로 바로 칸을 찾기

균형 탐색 트리는 O(log n)에 키를 찾습니다. 순서(범위 검색)가 필요 없고 "이 키가 있나, 값이 무엇인가"만 알면 되면 더 빠를 수 있습니다. 키를 정수로 바꿔 배열 칸 번호로 쓰면 O(1)입니다.

해시 함수 h(k): 키를 0~m−1의 칸 번호로 바꾸는 함수. 같은 키는 늘 같은 번호, 서로 다른 키는 고르게 흩어지는 것이 좋다. 예: 정수 키 \(h(k) = k \bmod m\)(m은 소수).

충돌: 서로 다른 키가 같은 칸에 가는 것. 칸 수보다 가능한 키가 훨씬 많으므로 피할 수 없다(비둘기집 원리).

적재율 α = n/m: 저장한 키 수 / 칸 수.

6.1.2체이닝

각 칸에 리스트를 두고, 같은 칸에 온 키를 그 리스트에 모읍니다. 해시 함수가 키를 고르게 흩는다면(단순 균등 해싱 가정) 각 리스트의 평균 길이는 α입니다.

  • 실패한 탐색(없는 키): 그 칸의 리스트를 끝까지, 평균 α번 비교.
  • 성공한 탐색: 평균 약 \(1 + \alpha/2\)번.

α가 커져도 서서히 느려질 뿐이고, α > 1(칸보다 키가 많음)도 가능합니다.

6.1.3개방 주소법(선형 조사)

모든 키를 배열 안에 직접 넣고, 칸이 차 있으면 다음 칸(i + 1, i + 2, …)을 차례로 봅니다. 참조가 없어 메모리를 덜 쓰고 연속된 칸을 훑어 캐시에 유리하지만, 차 있는 칸이 덩어리(군집)를 이루어 α가 1에 가까워지면 급격히 느려집니다. Knuth가 구한 평균 조사 횟수의 근사식(표가 크고 해시가 고르다고 가정)은 다음과 같습니다.

\[ \text{성공} \approx \frac12\left(1 + \frac{1}{1 - \alpha}\right), \qquad \text{실패} \approx \frac12\left(1 + \frac{1}{(1 - \alpha)^2}\right). \]

α = 1이면 더 넣을 수 없으므로, 보통 α가 0.5~0.7을 넘으면 표를 두 배로 키우고 모든 키를 다시 넣습니다(재해싱, 분할상환 O(1), 1.3절과 같은 원리). 삭제할 때는 칸을 비우면 뒤쪽 키를 못 찾게 되므로 "지워짐" 표시(묘비)를 남깁니다.

예제 6.1.1

칸 1009개 표에 무작위 정수 키를 적재율 0.25, 0.5, 0.75, 0.9만큼 넣고, 저장된 키(성공)와 없는 키(실패) 500개의 평균 조사 횟수를 세어 이론과 비교하라(실습 카드의 코드).

풀이. 실행 결과(시드 7):

α체이닝 성공 / 실패이론 \(1 + \alpha/2\) / α선형 조사 성공 / 실패이론
0.251.10 / 0.241.13 / 0.251.17 / 1.371.17 / 1.39
0.51.23 / 0.521.25 / 0.51.49 / 2.411.5 / 2.5
0.751.38 / 0.751.38 / 0.752.65 / 9.292.5 / 8.5
0.91.47 / 0.891.45 / 0.95.49 / 34.825.5 / 50.5

체이닝은 α = 0.9에서도 1.5번 안팎이지만, 선형 조사는 실패한 탐색이 수십 번으로 치솟습니다. α = 0.9의 실패 탐색은 군집의 크기에 크게 좌우되어 표마다 값이 많이 흔들립니다(이론값은 큰 표의 평균).

흔한 오해(1) "해시 테이블은 언제나 O(1)": 평균입니다. 모든 키가 한 칸으로 가면(나쁜 해시 함수나 일부러 만든 입력) O(n)입니다. Python은 문자열 해시에 실행마다 바뀌는 무작위 값을 섞어 이런 공격을 막습니다. (2) m을 2의 거듭제곱으로 하고 \(k \bmod m\)을 쓰면 키의 낮은 비트만 보게 되어, 짝수만 들어오는 키가 절반의 칸만 씁니다. 소수 m이나 잘 섞는 해시 함수를 씁니다. (3) 개방 주소법에서 삭제한 칸을 그냥 비우는 실수.
요약
  1. 키 → h(k) → 칸. 충돌은 피할 수 없고, 적재율 α = n/m이 성능을 정한다.
  2. 체이닝: 성공 ≈ 1 + α/2, 실패 ≈ α. α가 커도 완만.
  3. 선형 조사: 성공 ≈ ½(1 + 1/(1 − α)), 실패 ≈ ½(1 + 1/(1 − α)²). α를 0.5~0.7 아래로 유지(재해싱).

6.1.4연습문제

기본

  1. m = 7, \(h(k) = k \bmod 7\)인 체이닝 표에 10, 22, 31, 4, 15, 28, 17을 넣으면 각 칸의 리스트는?
    답

    칸 0: 28. 칸 1: 22, 15. 칸 3: 10, 31, 17. 칸 4: 4. 나머지 빈칸.

응용

  1. 같은 키를 선형 조사(m = 7)로 넣으면 배열은?
    답

    10→3, 22→1, 31→3 차서 4, 4→4 차서 5, 15→1 차서 2, 28→0, 17→3, 4, 5 차서 6. [28, 22, 15, 10, 31, 4, 17].

  2. 선형 조사에서 실패 탐색의 평균 조사를 3번 이하로 하려면 α는 얼마 이하여야 하는가?
    답

    \(\frac12(1 + 1/(1 - \alpha)^2) \le 3\) → \((1 - \alpha)^2 \ge 0.2\), \(\alpha \le 0.553\).

심화

  1. 23명이 있으면 생일이 같은 쌍이 있을 확률이 50%를 넘는다. 이것으로 m칸 해시 표에 키를 넣을 때 첫 충돌이 대략 언제 생기는지 어림하라.
    답

    약 \(\sqrt{\pi m/2}\)번째 키 근처(m = 365면 약 24). m = 1009면 약 40개만 넣어도 충돌이 생길 가능성이 큽니다. 충돌 처리가 필수인 이유입니다.
