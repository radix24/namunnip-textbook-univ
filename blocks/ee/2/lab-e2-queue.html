원형 큐를 클래스로 구현하기

실습 · 나머지 연산으로 감아 돌기

목표

2.3절의 원형 큐를 구현하고, 감아 도는 순간과 가득 참 처리를 출력으로 확인한다. 성취기준 [전전2-02-03].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 queue_lab.py로 저장한다.

class CircularQueue:
    def __init__(self, cap):
        self.buf = [None] * cap
        self.front = 0          # 맨 앞 원소의 위치
        self.size = 0

    def enqueue(self, x):
        if self.size == len(self.buf):
            raise OverflowError("가득 참")
        rear = (self.front + self.size) % len(self.buf)
        self.buf[rear] = x
        self.size += 1

    def dequeue(self):
        if self.size == 0:
            raise IndexError("비어 있음")
        x = self.buf[self.front]
        self.buf[self.front] = None
        self.front = (self.front + 1) % len(self.buf)
        self.size -= 1
        return x

q = CircularQueue(4)
for x in [10, 20, 30]:
    q.enqueue(x)
print(q.dequeue(), q.dequeue())          # 10 20
for x in [40, 50, 60]:
    q.enqueue(x)
print(q.buf, "front =", q.front, "size =", q.size)
try:
    q.enqueue(70)
except OverflowError as e:
    print("오류:", e)
print([q.dequeue() for _ in range(4)])

절차

  1. 실행해 출력을 적는다.
  2. 두 번째 줄(배열의 모습)을 종이에 칸을 그려 손으로 따라가며 확인한다.
  3. 용량을 4에서 3으로 바꾸고 결과를 예측한 뒤 실행한다.

기대 결과

Python 3.12에서 실행한 출력이다.

10 20
[50, 60, 30, 40] front = 2 size = 4
오류: 가득 참
[30, 40, 50, 60]
  • 처음 두 번 빼면 10, 20(먼저 넣은 순서).
  • 40, 50, 60을 넣은 뒤 배열 [50, 60, 30, 40], front = 2, size = 4: 50과 60이 칸 0, 1로 감아 돌았습니다(예제 2.3.1).
  • 70은 "가득 참" 오류. 이후 꺼내는 순서는 30, 40, 50, 60.
  • 용량 3이면 40, 50까지만 들어가고 60을 넣을 때 "가득 참" 오류가 나서 프로그램이 멈춥니다(try로 감싸지 않았기 때문).

분석

  1. enqueue와 dequeue가 O(1)인 이유를 Python 리스트의 pop(0)과 비교해 설명하자.
  2. front 대신 rear(다음에 넣을 자리)를 저장하도록 바꾸면 어떤 식이 바뀌나요?
