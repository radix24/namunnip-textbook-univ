힙은 트리이면서 배열이다

탐구 · 최소 힙의 push와 pop

질문

힙을 배열로 저장하면서도 트리처럼 위아래로 자리를 바꿀 수 있는 이유는 무엇일까요?

준비

위는 힙을 트리로, 아래는 같은 힙을 배열(작은 숫자는 인덱스)로 그린 것입니다. 값을 정해 push하거나 pop하면 자리를 바꾼 칸이 주황으로 표시됩니다. 처음 화면은 3.3절 예제 3.3.1의 결과입니다.

해 보기와 설명

  1. 예제 확인[1, 3, 2, 5, 9, 8]. 인덱스 i의 자식은 2i + 1, 2i + 2입니다. 3(인덱스 1)의 자식은 인덱스 3, 4의 5와 9입니다.
  2. poppop을 누르면 1이 나오고, 마지막 8이 뿌리로 올라가 자식 중 작은 2와 바꿉니다: [2, 3, 8, 5, 9](3.3절 연습 2).
  3. push4를 push하면 끝에 붙은 뒤 부모와 비교하며 올라갑니다. 교환 횟수는 높이 이하입니다.
  4. 정렬pop을 계속 누르면 값이 작은 순서로 나옵니다. 힙 정렬(5단원)이 이것입니다.

연결과 적용

Python의 heapq, C++의 priority_queue, 운영체제의 타이머 관리가 이 배열 힙입니다. 7단원 Dijkstra 알고리즘에서 다시 씁니다.

흔한 오해

  • "힙의 배열은 정렬되어 있다" 부모와 자식 사이만 정렬되어 있습니다. [1, 3, 2, 5, 9, 8]처럼 형제나 사촌 사이는 순서가 없습니다.
