AVL 트리와 회전

본문
이 절에서 배울 것
  • 균형 인자(왼쪽 높이 − 오른쪽 높이)가 모든 노드에서 −1, 0, 1인 AVL 트리를 정의한다.
  • BST 성질을 지키며 높이를 바꾸는 회전(왼쪽, 오른쪽)을 그린다.
  • 삽입 후 불균형의 네 경우(LL, RR, LR, RL)를 판정하고 한 번 또는 두 번의 회전으로 고친다.
먼저 알아야 할 것
  • 이진 탐색 트리와 높이 (3.2절), 중위 순회 (3.1절).

4.1.1높이를 지키는 조건

3.2절에서 BST의 연산은 O(h)이고, 정렬된 순서로 넣으면 h = n − 1이 되었습니다. 균형 탐색 트리는 삽입·삭제 때마다 모양을 조금 고쳐 h = O(log n)을 보장합니다. 가장 먼저 나온 방법(1962)이 AVL 트리입니다.

균형 인자: 노드의 왼쪽 부분 트리 높이 − 오른쪽 부분 트리 높이(빈 트리 높이 −1).

AVL 트리: 모든 노드의 균형 인자가 −1, 0, 1인 BST.

왜 높이가 O(log n)인가: 높이 h인 AVL 트리의 최소 노드 수 \(N(h)\)는 한쪽이 높이 h − 1, 다른 쪽이 h − 2일 때라 \(N(h) = N(h - 1) + N(h - 2) + 1\)입니다. 이것은 피보나치처럼 자라 \(N(h) \ge \phi^h\) 정도(φ ≈ 1.618)이므로 \(h \le 1.44\log_2n\) 정도입니다.

4.1.2회전

오른쪽 회전(노드 y, 왼쪽 자식 x): x가 올라가 새 뿌리가 되고, y는 x의 오른쪽 자식이 된다. x의 원래 오른쪽 부분 트리 B는 y의 왼쪽으로 옮긴다.

왼쪽 회전: 거울상.

회전 전후 모두 중위 순서가 (A) x (B) y (C)로 같으므로 BST 성질이 지켜집니다. 바뀌는 것은 참조 세 개뿐이라 O(1)이고, x 쪽 부분 트리가 한 층 올라가고 y 쪽이 한 층 내려갑니다.

def rot_right(y):
    x = y.left
    y.left, x.right = x.right, y
    fix(y); fix(x)          # 높이 다시 계산(아래부터)
    return x

4.1.3삽입 후 고치기

BST처럼 넣은 뒤, 넣은 자리에서 뿌리로 올라오며 높이를 고치고 처음으로 균형이 깨진 노드 z에서 고칩니다. 새 키가 z의 어느 쪽 손자 아래 들어갔느냐로 네 경우가 나뉩니다.

  • LL(왼쪽 자식의 왼쪽): z에서 오른쪽 회전 한 번.
  • RR(오른쪽 자식의 오른쪽): z에서 왼쪽 회전 한 번.
  • LR(왼쪽 자식의 오른쪽): 왼쪽 자식에서 왼쪽 회전 → z에서 오른쪽 회전.
  • RL(오른쪽 자식의 왼쪽): 오른쪽 자식에서 오른쪽 회전 → z에서 왼쪽 회전.

고친 뒤 그 부분 트리의 높이가 삽입 전과 같아지므로, 삽입 한 번에 회전은 많아야 두 번(한 경우)입니다.

예제 4.1.1

빈 AVL 트리에 10, 20, 30, 40, 50, 25를 차례로 넣는 과정의 회전을 쓰고 최종 트리를 그려라.

풀이.

  • 10, 20, 30: 10의 균형 인자 −2, 새 키가 오른쪽의 오른쪽(RR) → 10에서 왼쪽 회전: 20(10, 30).
  • 40, 50: 30이 −2(RR) → 30에서 왼쪽 회전: 20(10, 40(30, 50)).
  • 25: 30의 왼쪽에 들어감. 20이 −2, 새 키가 오른쪽 자식 40의 왼쪽(RL) → 40에서 오른쪽 회전, 20에서 왼쪽 회전: 30(20(10, 25), 40(·, 50)), 높이 2.

실습 코드로 확인하면 회전 기록이 RR, RR, RL 순서이고 전위 순회가 30, 20, 10, 25, 40, 50입니다. 또 1~1023을 차례로 넣으면 BST라면 높이 1022가 될 것을 AVL은 높이 9(최소와 같음)로 지킵니다.

흔한 오해(1) LR 경우에 z에서 오른쪽 회전 한 번만 하면 균형이 맞지 않고 반대쪽으로 기웁니다. 먼저 자식에서 반대 방향으로 돌려 LL 모양으로 만든 뒤 돌립니다. (2) 회전 후 높이를 위쪽 노드부터 다시 계산하면 틀립니다. 아래로 내려간 노드(y)를 먼저 고칩니다. (3) "AVL 트리는 완전 이진 트리다": 균형 인자 ±1을 허용하므로 완전 트리보다 최대 약 44% 높을 수 있습니다.
요약
  1. AVL: 모든 노드의 균형 인자 ∈ {−1, 0, 1} → h ≤ 약 1.44 log₂n.
  2. 회전은 O(1)이고 중위 순서(BST 성질)를 지킨다.
  3. 삽입 후 처음 깨진 노드에서 LL·RR(한 번), LR·RL(두 번) 회전.

4.1.4연습문제

기본

  1. 3, 2, 1을 차례로 넣으면 어떤 회전이 일어나는가?
    답

    3이 +2, LL → 3에서 오른쪽 회전: 2(1, 3).

응용

  1. 30, 10, 20을 차례로 넣으면?
    답

    30이 +2, 새 키 20은 왼쪽 자식 10의 오른쪽(LR) → 10에서 왼쪽 회전, 30에서 오른쪽 회전: 20(10, 30).

  2. 높이 4인 AVL 트리의 최소 노드 수는? (N(0) = 1, N(1) = 2)
    답

    N(2) = 4, N(3) = 7, N(4) = 12.

심화

  1. AVL 삭제에서는 회전이 O(log n)번 일어날 수 있다. 삽입과 다른 이유는?
    답

    삭제 후 회전으로 고친 부분 트리의 높이가 하나 줄 수 있어, 위쪽 조상에서 다시 불균형이 생길 수 있습니다. 삽입은 고친 뒤 높이가 원래대로라 위로 전파되지 않습니다.
