  • 방향 비순환 그래프(DAG)에서 선후 관계를 지키는 순서(위상 순서)를 정의한다.

  • 그래프 표현과 BFS (7.1절), 큐 (2.3절).

7.4.1Kahn 알고리즘

과목 선수 관계, 빌드 순서, 회로의 신호 계산 순서처럼 "A가 B보다 먼저"인 관계는 방향 간선 A → B로 나타냅니다. 들어오는 간선이 없는(진입 차수 0) 노드부터 꺼내고, 그 노드에서 나가는 간선을 지우며 새로 진입 차수가 0이 된 노드를 큐에 넣습니다. 모든 노드를 꺼내면 그 순서가 위상 순서이고, 남는 노드가 있으면 순환이 있는 것입니다. 시간은 O(V + E)입니다.

from collections import deque
def topo(n, edges):
    adj = [[] for _ in range(n)]; indeg = [0] * n
    for a, b in edges:
        adj[a].append(b); indeg[b] += 1
    q = deque(v for v in range(n) if indeg[v] == 0); order = []
    while q:
        v = q.popleft(); order.append(v)
        for w in adj[v]:
            indeg[w] -= 1
            if indeg[w] == 0:
                q.append(w)
    return order if len(order) == n else None      # None이면 순환

names = ["회로이론", "전자회로1", "신호및시스템", "전자회로2", "통신이론", "제어공학"]
edges = [(0, 1), (0, 2), (1, 3), (2, 4), (2, 5)]
print([names[v] for v in topo(6, edges)])
print("순환 추가:", topo(6, edges + [(4, 0)]))

실행 결과(Python 3.12에서 실제 실행):

['회로이론', '전자회로1', '신호및시스템', '전자회로2', '통신이론', '제어공학']
순환 추가: None
예제 7.4.1

위 과목 그래프에서 위상 순서는 하나뿐인가?

풀이. 아닙니다. 회로이론 다음에 전자회로1과 신호및시스템 중 어느 것을 먼저 해도 됩니다. Kahn 알고리즘은 큐에 들어간 순서에 따라 그중 하나를 줍니다. 통신이론 → 회로이론 간선을 더하면 순환이 생겨 None을 돌려줍니다.

흔한 오해(1) "모든 방향 그래프에 위상 순서가 있다": 순환이 없을 때만 있습니다. (2) "DFS 방문 순서가 곧 위상 순서": DFS가 끝나는 순서를 거꾸로 해야 위상 순서가 됩니다.
요약
  1. 위상 순서: 모든 간선 A → B에서 A가 앞.
  2. Kahn: 진입 차수 0인 노드부터 꺼내고 간선 제거, O(V + E).
  3. 꺼낸 노드가 V개보다 적으면 순환.
