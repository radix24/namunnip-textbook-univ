위상 정렬

본문

회로이론을 들어야 전자회로1과 신호및시스템을 들을 수 있고, 신호및시스템을 들어야 통신이론과 제어공학을 들을 수 있다. 여섯 과목을 이 조건을 모두 지키는 순서로 늘어놓는 방법은 무엇일까? 그리고 조건끼리 서로 물고 물리면 어떻게 알아챌까?

먼저 알아야 할 것그래프 표현과 BFS(7.1절), 큐(2.3절)를 쓴다.

7.4.1들어오는 화살표가 없는 것부터

"A가 B보다 먼저"라는 관계는 방향 간선 \(A \to B\)로 나타낸다. 과목의 선수 관계, 빌드 순서, 회로에서 신호를 계산하는 순서가 모두 그렇다. 모든 간선 \(A \to B\)에서 \(A\)가 앞에 오도록 정점을 늘어놓는 것을 위상 정렬이라 한다.

어디서부터 시작할까? 들어오는 간선이 없는 정점, 곧 진입 차수가 0인 정점은 무엇보다 먼저 와도 아무 조건을 어기지 않는다. 그림 1의 회로이론이 그렇다. 그러면 회로이론을 꺼내고 거기서 나가는 간선을 지운다. 그렇게 하면 전자회로1과 신호및시스템의 진입 차수가 0이 되어 다음 후보가 된다. 이렇게 진입 차수가 0인 정점을 큐에 넣고, 하나씩 꺼내며 나가는 간선을 지우고, 새로 진입 차수가 0이 된 정점을 큐에 넣기를 되풀이하는 방법이 Kahn 알고리즘이다. 정점과 간선을 한 번씩 다루므로 \(O(V + E)\)이다.

from collections import deque
def topo(n, edges):
    adj = [[] for _ in range(n)]; indeg = [0] * n
    for a, b in edges:
        adj[a].append(b); indeg[b] += 1
    q = deque(v for v in range(n) if indeg[v] == 0); order = []
    while q:
        v = q.popleft(); order.append(v)
        for w in adj[v]:
            indeg[w] -= 1
            if indeg[w] == 0:
                q.append(w)
    return order if len(order) == n else None      # None이면 순환
names = ["회로이론", "전자회로1", "신호및시스템", "전자회로2", "통신이론", "제어공학"]
edges = [(0, 1), (0, 2), (1, 3), (2, 4), (2, 5)]
print([names[v] for v in topo(6, edges)])
print("순환 추가:", topo(6, edges + [(4, 0)]))
['회로이론', '전자회로1', '신호및시스템', '전자회로2', '통신이론', '제어공학']
순환 추가: None

위 출력은 Python 3.12에서 실제로 실행한 결과이다. 첫 줄이 처음 질문의 순서이다.

7.4.2고리가 있으면

둘째 줄은 통신이론에서 회로이론으로 가는 간선을 더한 경우이다. 그러면 회로이론, 신호및시스템, 통신이론이 고리를 이루어 셋 모두 진입 차수가 0이 되는 일이 없다. 따라서 큐가 비었을 때 꺼낸 정점이 \(V\)개보다 적고, 코드는 None을 돌려준다. 다시 말해 Kahn 알고리즘은 정렬과 고리 검사를 한 번에 한다. 고리가 있는 그래프에는 위상 순서가 아예 없기 때문이다.

예제 7.4.1

위 과목 그래프에서 위상 순서는 하나뿐인가?

풀이. 아니다. 회로이론 다음에 전자회로1과 신호및시스템은 둘 다 진입 차수가 0이 되므로 어느 것을 먼저 해도 된다. 마찬가지로 통신이론과 제어공학의 순서도 바꿀 수 있다. Kahn 알고리즘은 큐에 들어간 순서에 따라 그 가운데 하나를 줄 뿐이다.

흔한 오해DFS로 방문한 순서가 곧 위상 순서라고 생각하기 쉽다. 위상 순서가 되는 것은 DFS가 각 정점의 처리를 끝내는 순서를 거꾸로 한 것이다. 방문 순서는 아직 선수 과목을 다 보지 않은 과목을 먼저 내놓을 수 있다.
마무리

여섯 과목은 들어오는 화살표가 없는 과목부터 꺼내고 그 과목에서 나가는 화살표를 지우기를 되풀이하는 Kahn 알고리즘으로 \(O(V + E)\)에 늘어놓을 수 있다. 조건이 서로 물고 물리는 고리가 있으면 진입 차수가 0이 되지 않는 정점이 남아, 꺼낸 정점이 \(V\)개보다 적은 것으로 알아챈다.
