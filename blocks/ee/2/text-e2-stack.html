스택: 괄호 검사와 후위 표기 계산

본문

계산기에 3 + 4 * (2 - 1) / 2를 넣으면 곱셈과 괄호를 먼저 처리해 5를 낸다. 사람은 우선순위를 눈으로 보고 판단하지만, 프로그램은 왼쪽부터 한 글자씩 읽을 뿐이다. 한 번 훑어 읽으면서 계산 순서를 바로잡는 데 필요한 것은 무엇일까?

먼저 알아야 할 것배열과 연결 리스트(2.1절), Python 딕셔너리(공통10 2.2절)를 쓴다.

2.2.1가장 최근 것을 먼저 꺼내는 리스트

한쪽 끝, 곧 top에서만 넣고(push) 빼는(pop) 리스트를 스택이라 한다. 접시를 쌓듯 나중에 들어간 것이 먼저 나오므로 LIFO라고도 부른다. Python 리스트의 끝을 top으로 쓰면 append와 pop()이 분할상환 \(O(1)\)이다. 맨 앞을 top으로 쓰면 \(O(n)\)이 되므로 반드시 끝을 쓴다. 함수 호출에서 되돌아갈 곳을 쌓아 두는 것, 브라우저의 뒤로 가기, 편집기의 실행 취소가 모두 스택이다.

2.2.2괄호 검사

문자열의 괄호 (), [], {}가 올바르게 짝지어졌는지 검사해 보자. 닫는 괄호는 아무 여는 괄호와 짝이 되는 것이 아니라, 가장 최근에 열리고 아직 닫히지 않은 괄호와 짝이 되어야 한다. 그렇다면 필요한 것은 가장 최근 것을 꺼내는 구조, 곧 스택이다.

def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False      # 짝이 없거나 종류가 다름
    return not stack              # 남은 여는 괄호가 있으면 실패

이 코드는 세 가지 실패를 모두 잡는다. "(a[b)c]"는 종류가 엇갈렸고, "((x)"는 여는 괄호가 남았으며, "x)"는 닫는 괄호가 먼저 왔다. 각 문자를 한 번씩만 보므로 \(O(n)\)이다.

2.2.3후위 표기와 그 계산

보통 쓰는 3 + 4처럼 연산자가 피연산자 사이에 오는 표기를 중위 표기라 한다. 중위 표기는 우선순위와 괄호가 있어야 계산 순서가 정해진다. 반면 연산자를 피연산자 뒤에 쓰는 후위 표기 3 4 +는 괄호 없이 적힌 순서만으로 계산 순서가 정해진다.

후위 표기의 계산은 그림 1처럼 스택 하나로 끝난다. 왼쪽부터 읽으며 수는 push하고, 연산자를 만나면 두 수를 pop해 계산한 결과를 다시 push한다. 다 읽은 뒤 남은 하나가 답이다. 이 때 빼기와 나누기에서는 먼저 꺼낸 값이 오른쪽 피연산자라는 점을 지켜야 한다.

그러면 중위 표기를 후위 표기로는 어떻게 바꿀까? 이번에는 연산자를 스택에 쌓는다. 수는 바로 출력하고, 연산자는 쌓되 새 연산자보다 우선순위가 높거나 같은 연산자를 먼저 꺼내 출력한다. "같은" 것까지 꺼내는 까닭은 \(8 - 3 - 2\)를 왼쪽부터 계산하기 위해서이다. 여는 괄호는 그냥 쌓고, 닫는 괄호를 만나면 여는 괄호가 나올 때까지 꺼낸다.

예제 2.2.1

3 + 4 * ( 2 - 1 ) / 2를 후위 표기로 바꾸고 계산하여라.

풀이. 변환하면 3 4 2 1 - * 2 / +가 된다. 이것을 그림 1처럼 계산하면, 3, 4, 2, 1을 쌓은 뒤 −에서 \(2 - 1 = 1\), *에서 \(4\times1 = 4\), 2를 쌓고 /에서 \(4/2 = 2.0\), +에서 \(3 + 2.0 = 5.0\)이다. 처음 질문의 답은 스택이다. 한 번 훑으며 변환할 때는 연산자를 기다리게 하는 데, 계산할 때는 피연산자를 기다리게 하는 데 쓴다. 이 절의 실습 카드에서 코드로 같은 결과를 확인한다.

흔한 실수빈 스택에서 pop하는 경우를 처리하지 않는 실수가 많다. 괄호 검사에서 닫는 괄호가 먼저 오면 빈 스택에서 꺼내게 된다. 후위 계산에서 \(a - b\)를 \(b - a\)로 계산하는 실수도 흔하다. 먼저 꺼낸 값이 \(b\)이다. 변환할 때 같은 우선순위의 연산자를 꺼내지 않으면 \(8 - 3 - 2\)가 \(8 - (3 - 2) = 7\)로 계산된다. 정답은 3이다.
마무리

왼쪽부터 한 번 훑으면서 계산 순서를 바로잡는 데 필요한 것은 가장 최근 것을 먼저 꺼내는 스택이다. 괄호 검사는 여는 괄호를 쌓았다가 닫는 괄호에서 꺼내 짝을 맞추고, 후위 표기의 계산은 수를 쌓았다가 연산자에서 두 개를 꺼내며, 중위에서 후위로의 변환은 우선순위가 높거나 같은 연산자를 먼저 꺼낸다.

2.2.4연습문제

기본

  1. 후위 표기 5 1 2 + 4 * + 3 -를 계산하여라.
    답

    \(1 + 2 = 3\), \(3\times4 = 12\), \(5 + 12 = 17\), \(17 - 3 = 14\).

응용

  1. ( 1 + 2 ) * ( 3 + 4 )의 후위 표기와 값은?
    답

    1 2 + 3 4 + *이고 값은 21이다.

  2. 스택 두 개로 큐(먼저 넣은 것이 먼저 나옴)를 만드는 방법과 분할상환 비용은?
    답

    넣을 때는 스택 A에 push한다. 꺼낼 때 B가 비었으면 A를 모두 B로 옮긴 뒤 B에서 pop한다. 각 원소가 한 번씩만 옮겨지므로 분할상환 \(O(1)\)이다.

심화

  1. 거듭제곱 ^는 오른쪽 결합이다(2^3^2 = 2^9). 변환 알고리즘을 어떻게 고쳐야 하는가?
    답

    ^에 대해서는 우선순위가 같은 연산자는 꺼내지 않고 더 높은 것만 꺼낸다. 그러면 2 3 2 ^ ^가 되어 오른쪽부터 계산된다.
