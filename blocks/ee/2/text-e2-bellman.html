Bellman-Ford와 음의 간선

본문

간선 무게가 음수일 수 있는 그래프에서 Dijkstra는 먼저 확정한 정점을 고치지 못해 틀린 답을 낸다. 확정이라는 생각을 버리고, 모든 간선을 몇 번이고 다시 살펴보면 어떨까? 몇 번이면 충분하고, 끝없이 줄어드는 경우는 어떻게 알아챌까?

먼저 알아야 할 것Dijkstra 알고리즘과 완화(7.3절)를 쓴다.

7.5.1완화를 되풀이하기

7.3절에서 모든 최단 경로 알고리즘은 완화 \(d[v] \leftarrow \min(d[v], d[u] + w)\)를 어떤 순서로 하느냐의 차이라고 했다. Bellman-Ford는 순서를 고민하지 않는다. 모든 간선을 한 번씩 완화하는 일을 통째로 되풀이할 뿐이다.

그러면 몇 번 되풀이하면 될까? 음의 고리가 없다면 최단 경로는 같은 정점을 두 번 지날 까닭이 없으므로 간선을 많아야 \(V - 1\)개 지난다. 그런데 모든 간선을 한 번 완화할 때마다 최단 경로의 간선이 적어도 하나씩 앞에서부터 바로잡힌다. 따라서 \(V - 1\)번이면 모든 최단 경로가 완성되고, 음의 간선이 있어도 정확하다. 비용은 \(O(VE)\)로 Dijkstra보다 느리다.

그런데 \(V - 1\)번을 하고도 한 번 더 했을 때 값이 줄어드는 간선이 있다면 무슨 뜻일까? 간선이 \(V\)개 이상인 경로가 더 짧다는 것이고, 그런 경로는 반드시 고리를 품는다. 다시 말해 돌수록 짧아지는 음의 고리가 있다. 처음 질문의 두 답이 이것이다. \(V - 1\)번이면 충분하고, \(V\)번째에도 줄어들면 음의 고리이다.

import heapq
E = [("s", "a", 4), ("s", "b", 5), ("b", "a", -3), ("a", "c", 3), ("c", "t", 2), ("b", "t", 6)]
V = ["s", "a", "b", "c", "t"]
INF = float("inf")
def bellman(src):
    d = {v: INF for v in V}; d[src] = 0
    for _ in range(len(V) - 1):
        for u, v, w in E:
            if d[u] + w < d[v]:
                d[v] = d[u] + w
    neg = any(d[u] + w < d[v] for u, v, w in E)
    return d, neg
def dijkstra(src):
    adj = {v: [] for v in V}
    for u, v, w in E:
        adj[u].append((v, w))
    d = {v: INF for v in V}; d[src] = 0; done = set(); pq = [(0, src)]
    while pq:
        du, u = heapq.heappop(pq)
        if u in done:
            continue
        done.add(u)
        for v, w in adj[u]:
            if v not in done and du + w < d[v]:   # 확정된 노드는 다시 고치지 않음
                d[v] = du + w; heapq.heappush(pq, (d[v], v))
    return d
print("Bellman-Ford:", bellman("s"))
print("Dijkstra    :", dijkstra("s"))
Bellman-Ford: ({'s': 0, 'a': 2, 'b': 5, 'c': 5, 't': 7}, False)
Dijkstra    : {'s': 0, 'a': 4, 'b': 5, 'c': 7, 't': 9}

위 출력은 Python 3.12에서 실제로 실행한 결과이다. 음의 고리는 없으므로 False가 나왔다.

예제 7.5.1

위 그래프에서 Dijkstra가 a의 거리를 틀리게 구하는 과정을 설명하여라.

풀이. s에서 출발하면 a(4)와 b(5)가 후보이고, 더 가까운 a를 먼저 확정한다. 나중에 b를 지나 a로 가는 경로 \(5 + (-3) = 2\)를 발견해도 a는 이미 확정되어 고치지 않는다. 그 결과 a 4, c 7, t 9로 틀린다. 반면 Bellman-Ford는 확정 없이 모든 간선을 다시 보므로 a 2, c 5, t 7로 맞힌다. Dijkstra의 가정, 곧 "확정한 정점으로 더 짧게 오는 길은 나중에 나오지 않는다"가 음의 간선에서 깨지기 때문이다.

흔한 오해음의 고리가 있어도 최단 거리가 정해진다고 생각하기 쉽지만, 고리를 돌수록 길이가 계속 줄어들어 최단 거리 자체가 정의되지 않는다. 그래서 Bellman-Ford는 답 대신 "음의 고리가 있다"를 알려 준다.
마무리

Bellman-Ford는 확정을 하지 않고 모든 간선의 완화를 \(V - 1\)번 되풀이한다. 최단 경로는 간선을 많아야 \(V - 1\)개 지나므로 이것으로 충분하며, 음의 간선이 있어도 정확하다. \(V\)번째에도 값이 줄어들면 음의 고리가 있다는 뜻이고, 비용은 \(O(VE)\)이다.

7.5.2연습문제

기본

  1. 노드 5개, 간선 6개인 그래프에서 Bellman-Ford의 완화 횟수는?
    답

    \((5 - 1)\times6 = 24\)번이다.

응용

  1. 예제에서 b → a의 무게를 −1로 바꾸면 a의 최단 거리는?
    답

    \(\min(4, 5 - 1) = 4\)이다.

심화

  1. 통화 환율 그래프에서 음의 고리는 무엇을 뜻하는가?
    답

    무게를 \(-\log(\text{환율})\)로 두면, 음의 고리는 돌수록 돈이 늘어나는 차익 거래 기회이다.
