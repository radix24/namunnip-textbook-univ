복잡도 분석 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산i = 1; while i < n: for j in range(i): x += 1; i *= 2의 x 증가 횟수는? [01-01]

    힌트 1

    i = 1, 2, 4, …에서 안쪽이 i번.

    힌트 2

    등비합.

    풀이

    \(1 + 2 + 4 + \cdots + 2^k\) (\(2^k < n\)) \(< 2n\). Θ(n). 바깥이 log n번이라 n log n으로 착각하기 쉽습니다.

  2. 계산\(T(n) = 3T(n/3) + n\), \(T(1) = 1\)을 재귀 트리로 풀어라. [01-01]

    힌트 1

    각 층의 일의 합은?

    힌트 2

    층 수 \(\log_3n + 1\).

    풀이

    층마다 n, 층 수 \(\log_3n + 1\) → \(n\log_3n + n\), Θ(n log n).

  3. 증명\(\log(n!) = \Theta(n\log n)\)을 보여라. [01-02]

    힌트 1

    위: \(n! \le n^n\).

    힌트 2

    아래: 뒤쪽 절반의 곱 \(\ge (n/2)^{n/2}\).

    풀이

    \(\log n! \le n\log n\). \(\log n! \ge \frac n2\log\frac n2 = \frac n2(\log n - 1) \ge \frac n4\log n\) (n ≥ 4). 따라서 Θ(n log n). 5단원 정렬 하한에서 씁니다.

  4. 판단학생이 "\(n^{100}\)은 \(2^n\)보다 크므로 다항식이 지수보다 느리게 자란다는 말은 틀렸다"고 했다. 평가하세요. [01-02]

    힌트 1

    점근 표기는 n → ∞의 비교.

    힌트 2

    \(\lim n^{100}/2^n\).

    풀이

    작은 n에서는 \(n^{100}\)이 크지만 극한은 0이므로 \(n^{100} = O(2^n)\)입니다. 교차점은 n ≈ 1000 근처(\(100\log_2n = n\)). 점근 비교는 충분히 큰 n에서의 이야기입니다.

  5. 계산두 배 전략 동적 배열(처음 용량 1)에 append를 100번 하면 총 복사 횟수와 마지막 용량은? [01-03]

    힌트 1

    용량 1, 2, 4, …, 64에서 다 참.

    힌트 2

    1 + 2 + … + 64.

    풀이

    127번, 용량 128.

  6. 도전동적 배열이 꽉 차면 두 배로, 원소가 용량의 절반 이하가 되면 절반으로 줄인다. 경계에서 append와 pop을 번갈아 하면 어떤 일이 생기는가? 해결책은? [01-03]

    힌트 1

    용량 8, 원소 8에서 append → 용량 16, 원소 9. 그다음 pop 두 번?

    힌트 2

    1/4 규칙.

    풀이

    원소 9(용량 16)에서 pop으로 8이 되면 절반이라 용량 8로 줄이며 복사, 다시 append하면 16으로 복사… 매 연산 O(n)으로 무너집니다. 원소가 용량의 1/4 이하일 때 절반으로 줄이면 늘린 직후와 줄인 직후 모두 절반이 비어 있어 분할상환 O(1)이 유지됩니다.
