BFS, DFS, 최소 신장 트리, Dijkstra 한 번에

실습 · 인접 리스트 그래프

목표

7단원의 알고리즘을 같은 그래프에 모두 적용하고, 음의 간선에서 Dijkstra가 틀리는 것을 Bellman-Ford와 비교해 확인합니다. 성취기준 [전전2-07-03].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 graph_lab.py로 저장합니다.

import heapq
from collections import deque

# 무방향 가중 그래프: (u, v, 무게)
edges = [("A", "B", 4), ("A", "C", 1), ("B", "C", 2), ("B", "D", 5),
         ("C", "D", 8), ("D", "E", 3), ("F", "G", 6)]
adj = {}
for u, v, w in edges:
    adj.setdefault(u, []).append((v, w))
    adj.setdefault(v, []).append((u, w))
for x in adj:
    adj[x].sort()                       # 이웃을 이름 순으로(결과를 정해진 순서로)

def bfs(s):
    dist, q = {s: 0}, deque([s])
    while q:
        u = q.popleft()
        for v, _ in adj[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def dfs(s, seen, order):
    seen.add(s); order.append(s)
    for v, _ in adj[s]:
        if v not in seen:
            dfs(v, seen, order)
    return order

print("BFS 간선 수 거리(A에서):", bfs("A"))
print("DFS 방문 순서(A에서):", dfs("A", set(), []))
seen, comps = set(), []
for x in sorted(adj):
    if x not in seen:
        comps.append(dfs(x, seen, []))
print("연결 성분:", comps)

def kruskal():
    parent = {x: x for x in adj}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    tree = []
    for u, v, w in sorted(edges, key=lambda e: e[2]):
        ru, rv = find(u), find(v)
        if ru != rv:                    # 고리를 만들지 않으면 채택
            parent[ru] = rv
            tree.append((u, v, w))
    return tree

def prim(s):
    seen, tree, pq = {s}, [], [(w, s, v) for v, w in adj[s]]
    heapq.heapify(pq)
    while pq:
        w, u, v = heapq.heappop(pq)
        if v in seen:
            continue
        seen.add(v); tree.append((u, v, w))
        for x, wx in adj[v]:
            if x not in seen:
                heapq.heappush(pq, (wx, v, x))
    return tree

k = kruskal()
print("Kruskal:", k, "합", sum(w for *_, w in k))
p = prim("A")
print("Prim(A 성분):", p, "합", sum(w for *_, w in p))

def dijkstra(g, s):
    dist, pq = {s: 0}, [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue                    # 이미 더 짧은 길을 찾은 낡은 항목
        for v, w in g.get(u, []):
            if d + w < dist.get(v, float("inf")):
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

print("Dijkstra(A):", dijkstra(adj, "A"))

# 음의 간선이 있는 방향 그래프
neg = {"S": [("A", 2), ("B", 5)], "A": [("C", 4)], "B": [("A", -4)], "C": []}
def dijkstra_once(g, s):                 # 꺼낸 정점은 다시 고치지 않는 교과서형
    dist, done, pq = {s: 0}, set(), [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if u in done:
            continue
        done.add(u)
        for v, w in g[u]:
            if v not in done and d + w < dist.get(v, float("inf")):
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

def bellman_ford(g, s):
    dist = {x: float("inf") for x in g}; dist[s] = 0
    for _ in range(len(g) - 1):
        for u in g:
            for v, w in g[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
    return dist

print("음의 간선, Dijkstra:", dijkstra_once(neg, "S"))
print("음의 간선, Bellman-Ford:", bellman_ford(neg, "S"))

절차

  1. 실행해 출력을 적습니다.
  2. Dijkstra 결과의 각 거리가 어떤 경로에서 나왔는지 종이에 표시합니다(7.3절 예제 7.3.1).
  3. 음의 간선 그래프에서 B → A의 무게를 −2로 바꾸면 두 알고리즘의 결과가 어떻게 되는지 예측하고 확인합니다.

  • BFS(간선 수): A 0, B·C 1, D 2, E 3. DFS 순서 A, B, C, D, E. 연결 성분 {A, B, C, D, E}, {F, G}.

  • 절차 3: −2이면 S → B → A가 3으로 S → A(2)보다 길어져 두 알고리즘이 같은 답(A 2, C 6)을 냅니다. 음의 간선이 있다고 늘 틀리는 것은 아닙니다.
