스택으로 괄호 검사기와 계산기 만들기

실습 · Python 리스트를 스택으로

목표

2.2절의 괄호 검사, 중위 → 후위 변환, 후위 계산을 직접 구현하고 결과를 확인합니다. 성취기준 [전전2-02-02].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 stack_lab.py로 저장합니다.

def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

def to_postfix(expr):
    prec = {"+": 1, "-": 1, "*": 2, "/": 2}
    out, ops = [], []
    for tok in expr.split():
        if tok.isdigit():
            out.append(tok)
        elif tok == "(":
            ops.append(tok)
        elif tok == ")":
            while ops[-1] != "(":
                out.append(ops.pop())
            ops.pop()
        else:
            while ops and ops[-1] != "(" and prec[ops[-1]] >= prec[tok]:
                out.append(ops.pop())
            ops.append(tok)
    while ops:
        out.append(ops.pop())
    return " ".join(out)

def eval_postfix(post):
    st = []
    for tok in post.split():
        if tok.isdigit():
            st.append(int(tok))
        else:
            b, a = st.pop(), st.pop()
            st.append({"+": a + b, "-": a - b, "*": a * b, "/": a / b}[tok])
    return st.pop()

for s in ["(a[b]{c})", "(a[b)c]", "((x)", "{[()()]}"]:
    print(s, balanced(s))
e = "3 + 4 * ( 2 - 1 ) / 2"
p = to_postfix(e)
print(p, "=", eval_postfix(p))
print(to_postfix("( 1 + 2 ) * ( 3 + 4 )"), "=", eval_postfix(to_postfix("( 1 + 2 ) * ( 3 + 4 )")))

절차

  1. python stack_lab.py를 실행해 출력을 적습니다.
  2. balanced에 "x)", ""(빈 문자열)을 넣어 결과를 예측한 뒤 확인합니다.
  3. to_postfix("8 - 3 - 2")의 결과와 값을 확인하고, 같은 우선순위에서 꺼내는 조건 >=를 >로 바꾸면 어떻게 되는지 봅니다.

기대 결과

Python 3.12에서 실행한 출력입니다.

(a[b]{c}) True
(a[b)c] False
((x) False
{[()()]} True
3 4 2 1 - * 2 / + = 5.0
1 2 + 3 4 + * = 21
  • 괄호 검사: 엇갈림 (a[b)c]와 남은 여는 괄호 ((x)가 False입니다.
  • 3 + 4 * ( 2 - 1 ) / 2 → 3 4 2 1 - * 2 / +, 값 5.0(예제 2.2.1). 나눗셈이 실수 나눗셈이라 5.0으로 나옵니다.
  • ( 1 + 2 ) * ( 3 + 4 ) → 1 2 + 3 4 + *, 값 21.
  • 절차 3: >=이면 8 3 - 2 - = 3, >로 바꾸면 8 3 2 - - = 7로 틀립니다(오른쪽부터 계산됨).
