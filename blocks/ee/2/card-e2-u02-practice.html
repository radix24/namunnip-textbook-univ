선형 구조 연습 문제

문제 6 · 개념·구현·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념정렬된 배열과 정렬된 연결 리스트에서 값 x를 찾는 비용은 각각? [02-01]

    힌트 1

    이진 탐색에는 무엇이 필요한가요?

    힌트 2

    가운데 원소에 O(1)로 가야 함.

    풀이

    배열 O(log n)(이진 탐색), 연결 리스트 O(n)(가운데로 바로 갈 수 없어 정렬되어 있어도 차례로 따라감).

  2. 구현이중 연결 리스트에서 노드 p를 지우는 코드를 쓰라(머리·꼬리 경계 무시). [02-01]

    힌트 1

    앞 노드의 next와 뒤 노드의 prev를 바꿈.

    힌트 2

    두 줄.

    풀이

    p.prev.next = p.next; p.next.prev = p.prev. O(1). 머리 앞·꼬리 뒤에 가짜 노드(보초)를 두면 경계 처리가 필요 없습니다.

  3. 계산후위 표기 2 3 4 * + 5 -를 스택으로 계산하며 각 단계의 스택 내용을 쓰라. [02-02]

    힌트 1

    수는 push.

    힌트 2

    *에서 3, 4를 꺼냄.

    풀이

    [2] → [2,3] → [2,3,4] → * [2,12] → + [14] → [14,5] → − [9]. 답 9.

  4. 판단학생이 큐를 Python 리스트로 만들며 append로 넣고 pop(0)으로 뺐다. 10만 개를 넣고 빼는 데 몇 분이 걸렸다. 원인과 해결책은? [02-03]

    힌트 1

    pop(0)의 비용은?

    힌트 2

    deque.

    풀이

    pop(0)은 뒤 원소를 모두 당겨 O(n), 전체 O(n²)(약 50억 번 이동). collections.deque의 popleft()(O(1))나 원형 큐를 씁니다.

  5. 계산용량 6 원형 큐(size 방식)에서 enqueue a, b, c, d, dequeue 3번, enqueue e, f, g, h를 하면 배열과 front는? [02-03]

    힌트 1

    dequeue 후 front = 3, size = 1.

    힌트 2

    rear = (front + size) % 6.

    풀이

    e는 칸 4, f는 칸 5, g는 칸 0, h는 칸 1. 배열 [g, h, None, d, e, f], front = 3, size = 5.

  6. 도전스택에서 push, pop과 함께 "현재 최솟값"을 O(1)에 알려 주는 구조를 설계하라. [02-02]

    힌트 1

    최솟값도 스택처럼 변한다.

    힌트 2

    (값, 그때까지의 최솟값) 쌍을 push.

    풀이

    각 원소와 함께 "그 원소를 넣은 시점의 최솟값 = min(새 값, 아래 원소의 최솟값)"을 저장. top의 두 번째 값이 현재 최솟값. pop하면 자동으로 이전 최솟값으로 돌아갑니다. 모두 O(1).
