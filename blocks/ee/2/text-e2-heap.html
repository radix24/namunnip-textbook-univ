힙과 우선순위 큐

본문
이 절에서 배울 것
  • 우선순위 큐 ADT(insert, extract-min)와 이진 힙(완전 이진 트리 + 힙 성질)을 안다.
  • 힙을 배열에 담고 부모·자식 인덱스를 \((i - 1)//2\), \(2i + 1\), \(2i + 2\)로 계산한다.
  • 위로 올리기(sift-up)와 아래로 내리기(sift-down)로 삽입·삭제를 O(log n)에 구현하고, 배열 전체를 O(n)에 힙으로 만드는 이유를 안다.
먼저 알아야 할 것
  • 이진 트리 (3.1절), 배열 (2.1절), 등비급수.

3.3.1우선순위 큐

우선순위 큐: 원소마다 우선순위가 있고, 꺼낼 때는 언제나 우선순위가 가장 높은(값이 가장 작은) 것이 나오는 ADT.

운영체제의 작업 스케줄러, 사건 시뮬레이션, 7단원의 Dijkstra 최단 경로가 우선순위 큐를 씁니다. 정렬된 배열로 만들면 꺼내기는 O(1)이지만 넣기가 O(n), 정렬되지 않은 배열이면 반대입니다. 둘 다 O(log n)으로 하는 것이 힙입니다.

3.3.2이진 힙

완전 이진 트리: 마지막 층을 빼고 꽉 차 있고, 마지막 층은 왼쪽부터 채운 이진 트리. 높이 \(\lfloor\log_2n\rfloor\).

최소 힙 성질: 모든 노드의 키 ≤ 자식의 키. 그래서 뿌리가 최솟값. (형제끼리의 순서는 정하지 않는다.)

배열 표현: 레벨 순서로 배열에 담으면 빈칸이 없고, 인덱스 i의 부모 \((i - 1)//2\), 자식 \(2i + 1\), \(2i + 2\). 참조가 필요 없다.

3.3.3삽입과 꺼내기

삽입(sift-up): 배열 끝(완전 트리의 다음 자리)에 붙이고, 부모보다 작으면 자리를 바꾸며 올라간다. 최대 높이만큼, O(log n).

최솟값 꺼내기(sift-down): 뿌리를 꺼내고 마지막 원소를 뿌리로 옮긴 뒤, 두 자식 중 작은 쪽보다 크면 자리를 바꾸며 내려간다. O(log n).

예제 3.3.1

빈 최소 힙에 5, 3, 8, 1, 9, 2를 차례로 넣을 때 배열의 변화를 쓰고, 모두 꺼낸 순서를 구하라.

풀이. 5 → [5]. 3: 부모 5보다 작아 교환 → [3, 5]. 8 → [3, 5, 8]. 1: 끝(인덱스 3)의 부모 5와 교환, 다시 부모 3과 교환 → [1, 3, 8, 5]. 9 → [1, 3, 8, 5, 9]. 2: 인덱스 5의 부모(인덱스 2) 8과 교환, 부모 1보다는 큼 → [1, 3, 2, 5, 9, 8]. 꺼내면 1, 2, 3, 5, 8, 9로 정렬된 순서가 나옵니다(이것이 5단원의 힙 정렬). 실습 카드의 코드 출력과 같습니다.

3.3.4배열을 한꺼번에 힙으로: O(n)

원소 n개를 하나씩 넣으면 O(n log n)이지만, 배열 뒤쪽 절반(잎들)은 이미 힙이므로 잎이 아닌 마지막 노드부터 뿌리까지 거꾸로 sift-down하면 됩니다(heapify). 높이 h인 노드는 많아야 h번 내려가는데, 높이 h인 노드는 약 \(n/2^{h+1}\)개뿐이라 총 \(\sum_h\frac{n}{2^{h+1}}h < n\)입니다. 대부분의 노드가 잎 근처에 있어 조금만 내려가기 때문입니다. Python의 heapq.heapify가 이 방법입니다.

Python에서는 heapq 모듈이 리스트를 최소 힙으로 다룹니다. (우선순위, 이름) 튜플을 넣으면 우선순위가 같을 때 이름을 비교하므로, 넣은 순서를 지키려면 (우선순위, 일련번호, 이름)처럼 순번을 끼웁니다.

흔한 오해(1) "힙은 정렬된 배열이다": 부모와 자식 사이의 순서만 보장합니다. 예제의 [1, 3, 2, 5, 9, 8]은 정렬되어 있지 않습니다. (2) "힙에서 아무 값이나 O(log n)에 찾을 수 있다": 탐색은 O(n)입니다. 힙은 최솟값 전용입니다. (3) 꺼낼 때 뿌리를 지우고 두 자식 중 작은 것을 올리는 방식은 트리 모양(완전성)을 깨뜨립니다. 마지막 원소를 뿌리로 옮기는 것이 핵심입니다.
요약
  1. 최소 힙: 완전 이진 트리 + 부모 ≤ 자식. 배열 인덱스로 부모 \((i - 1)//2\), 자식 \(2i + 1, 2i + 2\).
  2. 삽입은 sift-up, 꺼내기는 끝 원소를 뿌리로 옮겨 sift-down. 둘 다 O(log n).
  3. heapify는 O(n). 우선순위 큐의 표준 구현.

3.3.5연습문제

기본

  1. 배열 [2, 5, 3, 9, 6, 4]는 최소 힙인가? 인덱스 4의 부모는?
    답

    예(2 ≤ 5, 3; 5 ≤ 9, 6; 3 ≤ 4). 인덱스 4(값 6)의 부모 인덱스 1(값 5).

응용

  1. 예제 3.3.1의 힙 [1, 3, 2, 5, 9, 8]에서 최솟값을 한 번 꺼낸 뒤의 배열은?
    답

    8을 뿌리로: [8, 3, 2, 5, 9]. 자식 3, 2 중 2와 교환 → [2, 3, 8, 5, 9].

  2. n개 중 가장 큰 k개를 찾는 데 크기 k인 최소 힙을 쓰는 방법과 비용은?
    답

    힙이 k개가 될 때까지 넣고, 이후 새 원소가 힙의 최솟값보다 크면 최솟값을 꺼내고 넣음. O(n log k). 정렬(O(n log n))보다 k가 작을 때 유리.

심화

  1. heapify의 총 이동이 n 미만임을 \(\sum_{h\ge0}h/2^{h+1} = 1\)로 보여라.
    답

    높이 h 노드 수 ≤ \(\lceil n/2^{h+1}\rceil\), 각 h번 이동. 합 \(\le n\sum h/2^{h+1} = n\). 따라서 O(n).
