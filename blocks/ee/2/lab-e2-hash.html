두 가지 해시 테이블을 만들고 조사 횟수 재기

실습 · 체이닝과 선형 조사

목표

6.1·6.2절의 체이닝 표와 선형 조사 표를 구현하고, 적재율에 따른 평균 조사 횟수를 재어 이론과 비교한다. 성취기준 [전전2-06-02].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 hash_lab.py로 저장한다.

import random

class ChainHash:
    def __init__(self, m):
        self.t = [[] for _ in range(m)]
    def put(self, k, v):
        b = self.t[hash(k) % len(self.t)]
        for i, (kk, _) in enumerate(b):
            if kk == k:
                b[i] = (k, v); return
        b.append((k, v))
    def get(self, k):
        b = self.t[hash(k) % len(self.t)]
        probes = 0
        for kk, v in b:
            probes += 1
            if kk == k:
                return v, probes
        return None, probes

class LinearHash:
    def __init__(self, m):
        self.keys = [None] * m
        self.vals = [None] * m
    def put(self, k, v):
        m, i = len(self.keys), hash(k) % len(self.keys)
        while self.keys[i] is not None and self.keys[i] != k:
            i = (i + 1) % m                     # 다음 칸으로(선형 조사)
        self.keys[i], self.vals[i] = k, v
    def get(self, k):
        m, i, probes = len(self.keys), hash(k) % len(self.keys), 1
        while self.keys[i] is not None:
            if self.keys[i] == k:
                return self.vals[i], probes
            i = (i + 1) % m
            probes += 1
        return None, probes

random.seed(7)
m = 1009                                        # 소수 크기 표
universe = random.sample(range(10**6), 2 * m)
for alpha in (0.25, 0.5, 0.75, 0.9):
    n = int(alpha * m)
    keys, absent = universe[:n], universe[m:m + 500]
    row = []
    for cls in (ChainHash, LinearHash):
        h = cls(m)
        for k in keys:
            h.put(k, k * 2)
        hit = sum(h.get(k)[1] for k in keys) / n
        miss = sum(h.get(k)[1] for k in absent) / len(absent)
        assert all(h.get(k)[0] == k * 2 for k in keys)
        row.append(f"{cls.__name__} 성공 {hit:.2f} 실패 {miss:.2f}")
    print(f"적재율 {alpha}: " + " | ".join(row))

절차

  1. 실행해 출력을 적습니다(시드 7).
  2. 각 줄의 값을 6.1절 이론식(체이닝 1 + α/2와 α, 선형 조사 ½(1 + 1/(1 − α))와 ½(1 + 1/(1 − α)²))과 표로 비교한다.
  3. m = 1009를 m = 1024로 바꾸고, 키를 모두 짝수(k * 2)로 만들어 다시 실행해 결과가 어떻게 되는지 본다.

기대 결과

Python 3.12에서 실행한 출력이다.

적재율 0.25: ChainHash 성공 1.10 실패 0.24 | LinearHash 성공 1.17 실패 1.37
적재율 0.5: ChainHash 성공 1.23 실패 0.52 | LinearHash 성공 1.49 실패 2.41
적재율 0.75: ChainHash 성공 1.38 실패 0.75 | LinearHash 성공 2.65 실패 9.29
적재율 0.9: ChainHash 성공 1.47 실패 0.89 | LinearHash 성공 5.49 실패 34.82
  • 체이닝은 성공 1.10~1.47, 실패 0.24~0.89로 이론과 거의 같다.
  • 선형 조사는 α = 0.9에서 성공 5.49(이론 5.5), 실패 34.82(이론 50.5)로 급격히 나빠진다. 실패 탐색은 군집 크기에 민감해 표마다 흔들린다.
  • 절차 3: Python 정수의 hash(k)는 k 자신이므로 크기 1024 표에 짝수 키만 넣으면 짝수 칸만 쓴다. 같은 방식으로 실행하면 체이닝의 실패 탐색이 α = 0.25에서 0.52, α = 0.9에서 1.73으로 약 두 배가 됩니다(실제 적재율이 두 배인 것과 같음). 선형 조사는 빈 홀수 칸이 덩어리를 끊어 주어 덜 나빠집니다(α = 0.9에서 실패 27.91).
