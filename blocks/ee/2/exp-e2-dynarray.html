append를 천 번 하면 복사는 몇 번?

탐구 · 동적 배열의 용량 전략

질문

동적 배열이 다 차면 더 큰 공간으로 전부 복사한다. 용량을 두 배씩 늘리는 것과 일정량씩 늘리는 것은 얼마나 다를까?

준비

처음 용량 1인 동적 배열에 append를 n번 하면서, 다 찰 때마다 정한 전략으로 용량을 늘리고 그때까지의 원소를 모두 복사한다고 센다. 파랑: 선택한 전략의 누적 복사, 회색 점선: 두 배 전략, 연한 점선: 2n 직선.

해 보기와 설명

  1. 두 배1000번에 재할당 10번, 총 복사 1023번(한 번당 1.02번). 가장 큰 한 번의 복사는 512개이다. 계단 모양이 2n 직선 아래에 있다.
  2. 1.5배재할당 17번, 총 복사 2137번(한 번당 2.14번). 비율이 작을수록 복사는 늘지만 남는 메모리는 줄어든다.
  3. 10칸씩재할당 100번, 총 복사 49,600번(한 번당 49.6번). 포물선으로 늘어나 n에 비례하는 분할상환 비용이 된다. k = 1이면 499,500번이다.

연결과 적용

Python 리스트, C++ vector, Java ArrayList가 모두 일정 비율로 늘린다. 크기를 미리 알면 처음부터 그만큼 잡아(예: [None] * n) 재할당을 피한다.

흔한 오해

  • "두 배 전략이면 append가 늘 빠르다" 평균은 O(1)이지만 재할당이 일어나는 그 한 번은 512개를 복사한다. 지연이 고르게 필요한 곳에서는 문제가 된다.
