이진 트리와 네 가지 순회

본문

폴더 하나의 전체 크기를 구하려면 하위 폴더의 크기를 먼저 알아야 하고, 목차를 출력하려면 제목을 먼저 쓰고 그 아래를 써야 한다. 같은 트리를 돌아다니는데 왜 방문하는 순서가 달라야 할까? 트리의 노드를 빠짐없이 한 번씩 방문하는 방법은 몇 가지일까?

먼저 알아야 할 것재귀(1.1절), 연결 리스트의 노드(2.1절), 큐(2.3절)를 쓴다.

3.1.1트리와 이진 트리

트리는 노드와 간선으로 된 계층 구조이다. 맨 위 하나를 뿌리라 하고, 뿌리가 아닌 노드는 부모가 정확히 하나여서 고리가 생기지 않는다. 자식이 없는 노드는 잎이다. 뿌리에서 어떤 노드까지의 간선 수를 그 노드의 깊이라 하고, 뿌리에서 가장 깊은 잎까지의 간선 수를 트리의 높이라 한다. 노드 하나짜리 트리의 높이는 0이고, 빈 트리는 −1로 둔다.

이 가운데 각 노드의 자식이 왼쪽과 오른쪽 둘 이하인 트리를 이진 트리라 한다. 높이가 \(h\)인 이진 트리에는 노드가 많아야 \(1 + 2 + \cdots + 2^h = 2^{h+1} - 1\)개 들어간다. 거꾸로 말하면 노드 \(n\)개를 담는 이진 트리의 높이는 적어도 \(\lfloor\log_2 n\rfloor\)이다. 파일 시스템의 폴더, 컴파일러가 만드는 수식 트리, 3.2절의 탐색 트리, 3.3절의 힙이 모두 트리이다.

3.1.2깊이 우선 순회 세 가지

각 노드에서 할 일은 세 가지이다. 자기 자신을 방문하고, 왼쪽 부분 트리를 돌고, 오른쪽 부분 트리를 돈다. 이 셋의 순서 가운데 "자기 자신을 언제 방문하는가"만 바꾸면 세 순회가 나온다.

def preorder(t):  return [] if t is None else [t.key] + preorder(t.left) + preorder(t.right)
def inorder(t):   return [] if t is None else inorder(t.left) + [t.key] + inorder(t.right)
def postorder(t): return [] if t is None else postorder(t.left) + postorder(t.right) + [t.key]

그러면 자신을 먼저 방문하는 전위 순회는 위에서부터 구조를 그대로 옮기므로 트리 복사나 목차 출력에 쓴다. 자신을 왼쪽과 오른쪽 사이에 방문하는 중위 순회는 3.2절의 이진 탐색 트리에서 키를 정렬된 순서로 낸다. 자신을 마지막에 방문하는 후위 순회는 자식을 먼저 처리해야 하는 일에 맞는다. 처음 질문의 폴더 크기 계산이 그렇고, 메모리 해제와 수식 트리의 계산(2.2절의 후위 표기)도 그렇다.

따라서 세 순회 모두 노드를 한 번씩 방문하므로 \(O(n)\)이다. 다만 위 코드처럼 리스트를 이어 붙이면 그 비용이 더 들 수 있고, 결과 리스트 하나에 append하도록 쓰면 \(O(n)\)이 된다.

3.1.3레벨 순회

한편 깊이 0, 1, 2, …의 순서로, 같은 층 안에서는 왼쪽부터 방문하는 순회도 있다. 이 때는 먼저 발견한 노드를 먼저 처리해야 하므로 2.3절의 큐를 쓴다.

from collections import deque
def levelorder(t):
    out, q = [], deque([t] if t else [])
    while q:
        n = q.popleft()
        out.append(n.key)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)
    return out
예제 3.1.1

50, 30, 70, 20, 40, 60, 80, 35를 차례로 이진 탐색 트리에 넣어 만든 트리(3.2절의 규칙)의 네 순회와 높이를 구하여라.

풀이. 트리는 그림 1과 같다. 이제 전위 순회는 뿌리 50에서 시작해 왼쪽 부분 트리를 다 돈 뒤 오른쪽으로 가므로 50, 30, 20, 40, 35, 70, 60, 80이다. 중위 순회는 20, 30, 35, 40, 50, 60, 70, 80으로 정렬되어 나온다. 후위 순회는 20, 35, 40, 30, 60, 80, 70, 50으로 뿌리가 마지막이다. 레벨 순회는 50, 30, 70, 20, 40, 60, 80, 35이다. 가장 긴 길은 50, 30, 40, 35이므로 높이는 3이다. 이 결과는 실습 카드의 코드 출력과 같다.

흔한 오해전위와 후위 순회만 알면 트리를 되살릴 수 있다고 생각하기 쉽다. 일반 이진 트리는 중위 순회가 함께 있어야 하나로 정해진다(전위와 중위, 또는 후위와 중위). 또 레벨 순회를 큐 대신 스택으로 구현하면 깊이 우선 순회가 되어 버린다. 재귀 순회는 높이만큼 호출이 쌓이므로, 한쪽으로 길게 치우친 트리에서는 Python의 재귀 한도(기본 1000)를 넘을 수 있다.
마무리

트리를 빠짐없이 도는 깊이 우선 순회는 자기 자신을 언제 방문하느냐에 따라 전위, 중위, 후위 세 가지이고, 여기에 큐로 층별로 도는 레벨 순회가 더해져 네 가지이다. 폴더 크기처럼 자식이 먼저 필요하면 후위를, 목차처럼 위부터 써야 하면 전위를 쓰며, 모두 \(O(n)\)이다.

3.1.4연습문제

기본

  1. 수식 트리 *( +(3, 4), −(5, 2) )의 후위 순회와 값은?
    답

    3 4 + 5 2 − *이고 값은 21이다.

응용

  1. 전위 A B D E C F, 중위 D B E A F C인 이진 트리를 그려라.
    답

    전위의 첫째인 A가 뿌리이다. 중위에서 A 왼쪽은 D B E, 오른쪽은 F C이다. 왼쪽 부분은 전위 B D E이므로 B(D, E), 오른쪽은 전위 C F, 중위 F C이므로 C(F, ·)이다.

  2. 트리의 노드 수와 높이를 재귀로 구하는 함수를 써라.
    답

    size(t) = 0 if t is None else 1 + size(t.left) + size(t.right), height(t) = -1 if t is None else 1 + max(height(t.left), height(t.right)). 둘 다 후위 순회 꼴이다.

심화

  1. 재귀 없이 스택으로 중위 순회를 구현하는 방법을 설명하여라.
    답

    현재 노드에서 왼쪽으로 내려가며 모두 push한다. 더 내려갈 수 없으면 pop해 방문하고 그 노드의 오른쪽 자식으로 옮겨 되풀이한다. 스택이 비고 현재 노드도 없으면 끝난다.
