AVL 트리 삽입과 네 가지 회전 구현하기

실습 · 높이를 저장하는 노드

목표

4.1절의 AVL 삽입을 높이 필드와 두 회전 함수로 구현하고, 회전 기록과 최종 높이를 확인한다. 성취기준 [전전2-04-01].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 avl_lab.py로 저장한다.

class Node:
    def __init__(self, key):
        self.key, self.left, self.right, self.h = key, None, None, 0

def h(t): return t.h if t else -1
def fix(t): t.h = 1 + max(h(t.left), h(t.right))
def bal(t): return h(t.left) - h(t.right)

def rot_right(y):              # 왼쪽이 무거울 때
    x = y.left
    y.left, x.right = x.right, y
    fix(y); fix(x)
    return x

def rot_left(x):               # 오른쪽이 무거울 때
    y = x.right
    x.right, y.left = y.left, x
    fix(x); fix(y)
    return y

def insert(t, key, log):
    if t is None:
        return Node(key)
    if key < t.key:
        t.left = insert(t.left, key, log)
    else:
        t.right = insert(t.right, key, log)
    fix(t)
    b = bal(t)
    if b > 1 and key < t.left.key:
        log.append(f"{t.key}: LL → 오른쪽 회전"); return rot_right(t)
    if b < -1 and key > t.right.key:
        log.append(f"{t.key}: RR → 왼쪽 회전"); return rot_left(t)
    if b > 1:
        log.append(f"{t.key}: LR → 왼쪽 회전 후 오른쪽 회전")
        t.left = rot_left(t.left); return rot_right(t)
    if b < -1:
        log.append(f"{t.key}: RL → 오른쪽 회전 후 왼쪽 회전")
        t.right = rot_right(t.right); return rot_left(t)
    return t

def pre(t): return [] if t is None else [t.key] + pre(t.left) + pre(t.right)

root, log = None, []
for k in [10, 20, 30, 40, 50, 25]:
    root = insert(root, k, log)
print("회전 기록:", log)
print("전위:", pre(root), "높이:", root.h)

root, log = None, []
for k in range(1, 1024):
    root = insert(root, k, log)
print("1~1023을 차례로 넣은 AVL 높이:", root.h, "회전 수:", len(log))

절차

  1. 실행해 출력을 적는다.
  2. 첫 줄의 회전 기록을 종이에 그린 트리와 한 단계씩 맞춰 봅니다(4.1절 예제 4.1.1).
  3. range(1, 1024)를 range(1, 1025)로 바꾸면 높이가 어떻게 되는지 예측하고 확인한다.

기대 결과

Python 3.12에서 실행한 출력이다.

회전 기록: ['10: RR → 왼쪽 회전', '30: RR → 왼쪽 회전', '20: RL → 오른쪽 회전 후 왼쪽 회전']
전위: [30, 20, 10, 25, 40, 50] 높이: 2
1~1023을 차례로 넣은 AVL 높이: 9 회전 수: 1013
  • 회전 기록: 10에서 RR, 30에서 RR, 20에서 RL. 최종 전위 30, 20, 10, 25, 40, 50, 높이 2.
  • 1~1023(2¹⁰ − 1개)을 차례로 넣으면 높이 9로 가능한 최소이고, 회전은 1013번이다. 보통 BST였다면 높이 1022이다.
  • 1024개면 높이 10이 됩니다(⌊log₂1024⌋ = 10).

분석

  1. rot_right에서 fix(y)를 fix(x)보다 먼저 해야 하는 이유는?
  2. 삽입 함수는 재귀로 뿌리까지 올라오며 매번 fix를 부른다. 한 번 삽입의 비용이 O(log n)인 이유를 높이로 설명하자.
