그래프 표현과 DFS, BFS

본문
이 절에서 배울 것
  • 그래프 G = (V, E)의 용어(방향·무방향, 가중치, 연결 성분)와 인접 행렬·인접 리스트 표현의 비용을 안다.
  • 깊이 우선 탐색(DFS, 재귀·스택)과 너비 우선 탐색(BFS, 큐)을 구현하고 O(V + E)임을 보인다.
  • BFS로 간선 수 기준 최단 거리를, DFS로 연결 성분과 위상 정렬을 구한다.
먼저 알아야 할 것
  • 스택과 큐 (2.2절, 2.3절), 트리 순회 (3.1절), 딕셔너리.

7.1.1그래프와 표현

도시와 도로, 회로의 소자와 배선, 인터넷의 라우터, 웹 페이지와 링크처럼 "무엇과 무엇이 이어져 있다"는 관계는 모두 그래프입니다.

그래프: 정점 집합 V와 간선 집합 E. 간선에 방향이 있으면 방향 그래프, 무게(거리, 비용)가 있으면 가중 그래프.

인접 행렬: V × V 표, (u, v) 칸에 간선 유무(또는 무게). 메모리 O(V²), 간선 확인 O(1).

인접 리스트: 정점마다 이웃 목록. 메모리 O(V + E), 이웃을 모두 보는 데 차수만큼.

실제 그래프는 대부분 간선이 V²보다 훨씬 적어(희소) 인접 리스트를 씁니다. 예: 정점 100만 개, 평균 이웃 10개면 인접 행렬은 10¹²칸(약 1 TB 비트 행렬도 125 GB), 인접 리스트는 약 2000만 항목입니다.

7.1.2DFS와 BFS

DFS는 갈 수 있는 데까지 깊이 들어갔다가 막히면 돌아와 다른 길을 갑니다(재귀 또는 스택). BFS는 시작점에서 가까운 정점부터 층별로 넓혀 갑니다(큐). 둘 다 방문 표시로 같은 정점을 두 번 처리하지 않습니다.

from collections import deque
def bfs(adj, s):
    dist, q = {s: 0}, deque([s])
    while q:
        u = q.popleft()
        for v, _ in adj[u]:
            if v not in dist:           # 처음 발견
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def dfs(adj, s, seen, order):
    seen.add(s); order.append(s)
    for v, _ in adj[s]:
        if v not in seen:
            dfs(adj, v, seen, order)
    return order

각 정점은 한 번 꺼내지고, 각 간선은 (무방향이면 양쪽에서 한 번씩) 한 번 검사되므로 O(V + E)입니다.

BFS의 최단 거리: 가중치가 없으면 BFS가 처음 발견할 때의 층 번호가 간선 수 기준 최단 거리다. 가까운 층을 모두 처리한 뒤에야 다음 층으로 가기 때문이다.

연결 성분: 아직 방문하지 않은 정점에서 DFS(또는 BFS)를 시작할 때마다 새 성분 하나.

예제 7.1.1

간선 A–B, A–C, B–C, B–D, C–D, D–E, F–G인 무방향 그래프(이웃은 이름 순)에서 A로부터의 BFS 거리, A에서 시작한 DFS 방문 순서, 연결 성분을 구하라.

풀이. BFS: A 0, B·C 1, D 2(B를 거쳐), E 3. DFS: A → B(A의 첫 이웃) → C(B의 이웃 중 처음 보는 것) → D(C의 이웃) → E. 성분: {A, B, C, D, E}, {F, G} 두 개. 실습 카드의 코드 출력과 같습니다.

7.1.3위상 정렬

위상 정렬: 고리가 없는 방향 그래프(DAG)에서 모든 간선 u → v에 대해 u가 v보다 앞에 오도록 정점을 늘어놓는 것. 선수 과목 순서, 빌드 순서, 회로의 신호 계산 순서(전전4의 정적 타이밍 분석)가 그 예다.

DFS가 정점의 처리를 끝내는 순서(후위)를 거꾸로 하면 위상 정렬이 됩니다. 또는 들어오는 간선이 없는 정점을 큐에 넣고 하나씩 빼며 그 정점에서 나가는 간선을 지우는 방법(Kahn 알고리즘)도 O(V + E)입니다.

흔한 오해(1) BFS에서 꺼낼 때 방문 표시를 하면 같은 정점이 큐에 여러 번 들어가 비용이 늘어납니다. 넣을 때(처음 발견할 때) 표시합니다. (2) "DFS로도 최단 거리를 구할 수 있다": 먼 길로 먼저 도착할 수 있어 일반적으로 틀립니다. (3) 재귀 DFS는 긴 경로(정점 수천 개 이상)에서 재귀 한도를 넘을 수 있어, 큰 그래프에서는 스택으로 씁니다.
요약
  1. 인접 리스트(O(V + E))가 희소 그래프의 표준. 인접 행렬은 O(V²).
  2. DFS(스택·재귀), BFS(큐), 둘 다 O(V + E). BFS는 무가중 최단 거리.
  3. 연결 성분: 새 시작점마다 하나. DAG의 위상 정렬: DFS 종료 순서의 역순.

7.1.4연습문제

기본

  1. 정점 5개, 간선 7개 무방향 그래프의 인접 리스트 항목 수의 합은?
    답

    14(간선마다 양쪽에 한 번씩).

응용

  1. 과목 선수 관계 수학 → 회로, 수학 → 신호, 회로 → 전자, 신호 → 통신, 전자 → 통신의 위상 정렬 하나를 쓰라.
    답

    수학, 회로, 전자, 신호, 통신(다른 순서도 가능: 수학, 신호, 회로, 전자, 통신).

  2. 격자 미로(칸은 정점, 이웃 칸은 간선)에서 출발점부터 도착점까지 가장 적게 움직이는 경로를 찾는 방법은?
    답

    BFS. 각 칸에 "어디서 왔는지"를 기록하면 도착점에서 거꾸로 따라가 경로를 얻습니다.

심화

  1. 무방향 그래프에 고리가 있는지 DFS로 판정하는 방법은?
    답

    DFS 중 이미 방문한 정점으로 가는 간선을 만났는데 그 정점이 바로 직전 부모가 아니면 고리입니다. O(V + E).
