최소 힙과 heapq로 작업 스케줄러 만들기

실습 · 배열 힙의 sift-up과 sift-down

목표

3.3절의 최소 힙을 직접 구현해 배열의 변화를 확인하고, 표준 라이브러리 heapq로 우선순위 작업 큐를 만듭니다. 성취기준 [전전2-03-03].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 heap_lab.py로 저장합니다.

class MinHeap:
    def __init__(self):
        self.a = []

    def push(self, x):
        a = self.a
        a.append(x)
        i = len(a) - 1
        while i > 0 and a[(i - 1) // 2] > a[i]:      # 부모보다 작으면 위로
            p = (i - 1) // 2
            a[i], a[p] = a[p], a[i]
            i = p

    def pop(self):
        a = self.a
        top = a[0]
        last = a.pop()
        if a:
            a[0] = last
            i = 0
            while True:                              # 자식 중 작은 쪽과 바꾸며 아래로
                l, r, m = 2 * i + 1, 2 * i + 2, i
                if l < len(a) and a[l] < a[m]: m = l
                if r < len(a) and a[r] < a[m]: m = r
                if m == i: break
                a[i], a[m] = a[m], a[i]
                i = m
        return top

h = MinHeap()
for x in [5, 3, 8, 1, 9, 2]:
    h.push(x)
    print("push", x, "->", h.a)
print("pop 순서", [h.pop() for _ in range(6)])

import heapq
tasks = []
for pri, name in [(3, "로그 저장"), (1, "센서 읽기"), (2, "화면 갱신"), (1, "비상 정지")]:
    heapq.heappush(tasks, (pri, name))
print([heapq.heappop(tasks)[1] for _ in range(4)])

절차

  1. 실행해 출력을 적습니다.
  2. push 2 단계에서 2가 인덱스 5에서 인덱스 2로 올라간 과정을 부모 인덱스 \((i - 1)//2\)로 따라갑니다.
  3. 작업 목록에 (2, "알림")을 추가해 꺼내는 순서를 예측하고 확인합니다.

기대 결과

Python 3.12에서 실행한 출력입니다.

push 5 -> [5]
push 3 -> [3, 5]
push 8 -> [3, 5, 8]
push 1 -> [1, 3, 8, 5]
push 9 -> [1, 3, 8, 5, 9]
push 2 -> [1, 3, 2, 5, 9, 8]
pop 순서 [1, 2, 3, 5, 8, 9]
['비상 정지', '센서 읽기', '화면 갱신', '로그 저장']
  • push 단계의 배열이 예제 3.3.1과 같고, 마지막 힙은 [1, 3, 2, 5, 9, 8]입니다.
  • pop 순서 1, 2, 3, 5, 8, 9: 정렬된 순서입니다.
  • 작업은 우선순위 1인 둘이 먼저 나옵니다. 둘 사이의 순서는 이름 문자열의 비교로 정해져 "비상 정지"가 "센서 읽기"보다 먼저입니다(넣은 순서와 무관). 절차 3에서 (2, "알림")과 (2, "화면 갱신")도 이름 순서("알림"이 먼저)로 나옵니다.
