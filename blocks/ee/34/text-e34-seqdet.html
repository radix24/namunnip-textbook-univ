순서 검출기: 무어와 밀리

본문
이 절에서 배울 것
  • 검출할 순서의 앞부분과 맞은 길이를 상태로 하는 설계법을 쓴다.
  • 같은 순서(1011)를 무어 기계(상태 5개)와 밀리 기계(상태 4개)로 설계한다.
  • 겹침 허용과 출력 시점의 차이를 타이밍도로 설명한다.
먼저 알아야 할 것
  • Moore와 Mealy 기계 (전전4 6.2절).

3.2.1상태 = 맞은 길이

1011을 찾을 때 상태 0, 1, 2, 3은 "입력의 끝이 순서의 앞부분 '', '1', '10', '101'과 맞음"입니다. 틀린 비트가 오면 처음으로 가는 것이 아니라, 지금까지의 입력 끝부분 중 순서의 앞부분과 맞는 가장 긴 길이로 갑니다. 예: 상태 2('10')에서 0이 오면 '100'의 끝 중 '1011'의 앞부분과 맞는 것이 없으므로 상태 0, 상태 3('101')에서 0이 오면 '1010'의 끝 '10'이 맞으므로 상태 2.

밀리: 상태 3에서 1이 오면 그 전이에서 출력 1. 겹침을 허용하면 '1011'의 끝 '1'이 다음 순서의 시작이 되어 상태 1로 갑니다. 상태 4개.
무어: '1011'을 다 맞은 상태 4를 더 두고 그 상태 동안 출력 1. 상태 4에서 0이 오면 '10'과 맞으므로 상태 2, 1이 오면 상태 1. 상태 5개.

예제 3.2.1

입력 1011011(클록 0~6), 겹침 허용. 두 기계의 출력이 1인 클록은?

풀이. 무어 기계의 상태는 클록 0~7 시작에서 0, 1, 2, 3, 4, 2, 3, 4입니다. 밀리는 1011이 끝나는 클록 3과 6에서 바로 출력 1. 무어는 상태 4에 있는 클록 4와 7에 출력 1로 한 클록 늦고, 한 클록 동안 꼬박 나옵니다. 두 번째 1011은 첫 번째의 마지막 '1'을 다시 써서 찾았습니다(겹침).

3.2.2실습에서 확인할 것

  • 입력을 스위치로 한 비트씩 넣고 클록을 버튼(디바운스, 4.2절)으로 주면 상태 변화를 LED로 하나씩 볼 수 있다.
  • 밀리 출력은 입력이 바뀌는 순간 클록과 상관없이 바뀔 수 있다. 클록 사이에 입력 스위치를 흔들면 출력이 잠깐 1이 되는 것을 볼 수 있다(글리치). 다음 단이 동기식이면 문제없지만 LED나 비동기 회로에 바로 쓰면 주의.
흔한 오해(1) "틀린 비트가 오면 상태 0으로 가면 된다": 1011에서 '101' 다음 0이면 '10'까지는 맞으므로 상태 2로 가야 놓치지 않습니다. (2) "겹침 허용 여부는 설계와 무관하다": 검출 직후의 다음 상태가 달라집니다(허용 안 하면 상태 0).
요약
  1. 상태 = 입력 끝이 순서 앞부분과 맞은 가장 긴 길이.
  2. 밀리 4상태, 검출 클록에 바로 1. 무어 5상태, 한 클록 늦게 한 클록 동안 1.
  3. 1011011: 밀리 클록 3, 6. 무어 4, 7(겹침 허용).

3.2.3연습문제

기본

  1. 순서 110의 밀리 기계에 필요한 상태 수는?
    답

    3개(0, 1, 2).

응용

  1. 1011 검출기(겹침 허용 안 함)에 1011011을 넣으면 밀리 출력 1인 클록은?
    답

    클록 3만. 검출 후 상태 0으로 가서 다음 '011'로는 1011이 완성되지 않습니다.

심화

  1. 1011 무어 검출기의 상태 4에서 0과 1이 올 때의 다음 상태를 겹침 허용으로 정하고 이유를 쓰라.
    답

    0 → '10110'의 끝 '10' → 상태 2. 1 → '10111'의 끝 '1' → 상태 1.
