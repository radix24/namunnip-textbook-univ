7세그먼트 디코더를 카르노 맵으로

본문

디지털 시계나 전자레인지의 숫자는 일곱 개의 막대를 켜고 꺼서 0부터 9를 나타낸다. 입력 4비트가 어떤 숫자인지에 따라 막대마다 켤지 말지를 정하는 회로가 7세그먼트 디코더이다. 막대 하나를 켜는 식은 얼마나 짧게 만들 수 있을까? 그리고 표시기 종류에 따라 연결은 어떻게 달라질까?

먼저 알아야 할 것카르노 맵(전전4 3.1절)을 쓰고, 이 절의 실습 카드와 함께 본다.

1.3.1진리표와 무관 조건

입력 D C B A(D가 최상위)로 0~9를 표시한다. 예를 들어 막대 a(위)는 1과 4에서만 꺼진다.

그런데 입력 10~15는 BCD에서 나오지 않으므로, 출력을 0이든 1이든 상관없는 무관 조건(X)으로 둔다. 따라서 무관 칸을 묶음을 키우는 데 쓰면 식이 짧아진다. 처음 질문의 첫째 답이 이 방법이다.

1.3.2막대 a의 최소식

예제 1.3.1

막대 a의 최소 곱의 합을 구하고, 0~9에서 맞는지 확인하여라.

풀이. 1인 칸은 0, 2, 3, 5, 6, 7, 8, 9이고, 무관은 10~15이다. 묶음은 D(8~15, 무관 포함 8칸), B(2, 3, 6, 7, 10, 11, 14, 15의 8칸), CA(5, 7, 13, 15), C'A'(0, 2, 8, 10, 맵 네 귀퉁이)이다(그림 1). 그래서 아래와 같다.

\[ a = D + B + CA + C'A'. \]

확인하면, 1(0001)은 D = B = 0, C = 0이라 CA = 0, A = 1이라 C'A' = 0이므로 a = 0이다. 그리고 4(0100)는 C = 1, A = 0이라 CA = C'A' = 0이므로 0이다. 나머지 여덟 숫자는 네 항 중 하나가 1이다. 실습 카드에서 다른 막대도 같은 방법으로 구하고 카드의 답과 비교한다.

1.3.3표시기 연결

공통 음극 표시기는 LED의 음극을 모두 접지에 묶어, 막대 신호가 1(High)일 때 켜진다. 반면 공통 양극 표시기는 양극을 VCC에 묶어 신호가 0일 때 켜지므로, 위 식의 반대(NOT)를 내보내야 한다. 처음 질문의 둘째 답이 이 차이이다.

그리고 막대마다 전류 제한 저항이 필요하다. 예를 들어 5 V, LED 순방향 전압 약 2 V(확인 필요: 색에 따라 다름), 330 Ω이면 \((5 - 2)/330 \approx 9\) mA이다. 그런데 저항을 공통 단자 하나에만 달면 켜진 막대 수에 따라 밝기가 바뀌므로, 막대마다 단다.

흔한 오해무관 조건은 0으로 두어야 안전하다고 여기기 쉽다. BCD 입력만 들어온다면 무관으로 두어 식을 줄이는 것이 보통이며, 10~15가 들어올 수 있다면 그때 표시할 모양을 정해야 한다. 또 공통 양극 표시기에 공통 음극용 디코더를 연결해도 된다고 생각하기 쉬운데, 그러면 숫자가 반전되어 보인다.
마무리

BCD 0~9 진리표를 쓰고 10~15는 무관 조건으로 둔다. 막대 a = D + B + CA + C'A'(D 최상위)이다. 공통 음극은 1에서, 공통 양극은 0에서 켜지며, 막대마다 저항(약 9 mA)을 단다.

1.3.4연습문제

기본

  1. 막대 g(가운데)가 꺼지는 숫자는?
    답

    0, 1, 7이다.

응용

  1. 막대 e(왼쪽 아래)가 켜지는 숫자는? 최소식은?
    답

    0, 2, 6, 8. 무관 조건을 쓰면 \(e = C'A' + BA'\)(D 최상위, A 최하위)이다.

심화

  1. 3.3 V 출력 FPGA로 순방향 전압 2.0 V, 목표 5 mA인 막대를 켤 때 저항은?
    답

    \((3.3 - 2.0)/0.005 = 260\) Ω, 가까운 표준값 270 Ω이다.
