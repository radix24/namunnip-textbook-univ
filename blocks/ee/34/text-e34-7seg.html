7세그먼트 디코더를 카르노 맵으로

본문
이 절에서 배울 것
  • BCD 입력 0~9에 대한 7세그먼트 각 막대의 진리표를 만든다.
  • 10~15를 무관 조건으로 써서 카르노 맵으로 막대마다 최소 곱의 합을 구한다.
  • 공통 음극·공통 양극 표시기의 차이와 전류 제한 저항을 계산한다.
먼저 알아야 할 것
  • 카르노 맵 (전전4 3.1절), 이 절의 실습 카드.

1.3.1진리표와 무관 조건

입력 D C B A(D가 최상위)로 0~9를 표시합니다. 막대 a(위)는 1과 4에서만 꺼집니다. 입력 10~15는 BCD에서 나오지 않으므로 출력을 0이든 1이든 상관없는 무관 조건(X)으로 둡니다. 무관 칸을 묶음을 키우는 데 쓰면 식이 짧아집니다.

1.3.2막대 a의 최소식

예제 1.3.1

막대 a의 최소 곱의 합을 구하고, 0~9에서 맞는지 확인하라.

풀이. 1인 칸: 0, 2, 3, 5, 6, 7, 8, 9, 무관: 10~15. 묶음: D(8~15, 무관 포함 8칸), B(2, 3, 6, 7, 10, 11, 14, 15의 8칸), CA(5, 7, 13, 15), C'A'(0, 2, 8, 10, 맵 네 귀퉁이). 그래서

\[ a = D + B + CA + C'A'. \]

확인: 1(0001)은 D = B = 0, C = 0이라 CA = 0, A = 1이라 C'A' = 0 → a = 0. 4(0100)는 C = 1, A = 0이라 CA = C'A' = 0 → 0. 나머지 여덟 숫자는 네 항 중 하나가 1입니다. 실습 카드에서 다른 막대도 같은 방법으로 구하고 카드의 답과 비교합니다.

1.3.3표시기 연결

공통 음극은 LED의 음극을 모두 접지에 묶어, 막대 신호가 1(High)일 때 켜집니다. 공통 양극은 양극을 VCC에 묶어 신호가 0일 때 켜지므로 위 식의 반대(NOT)를 내보내야 합니다. 막대마다 전류 제한 저항이 필요합니다: 5 V, LED 순방향 전압 약 2 V(확인 필요: 색에 따라 다름), 330 Ω이면 \((5 - 2)/330 \approx 9\) mA. 저항을 공통 단자 하나에만 달면 켜진 막대 수에 따라 밝기가 바뀌므로 막대마다 답니다.

흔한 오해(1) "무관 조건은 0으로 두어야 안전하다": BCD 입력만 들어온다면 무관으로 두어 식을 줄이는 것이 보통입니다. 10~15가 들어올 수 있다면 그때 표시할 모양을 정해야 합니다. (2) 공통 양극 표시기에 공통 음극용 디코더를 연결하면 숫자가 반전되어 보입니다.
요약
  1. BCD 0~9 진리표, 10~15는 무관 조건.
  2. 막대 a = D + B + CA + C'A'(D 최상위).
  3. 공통 음극은 1에서, 공통 양극은 0에서 켜짐. 막대마다 저항(약 9 mA).

1.3.4연습문제

기본

  1. 막대 g(가운데)가 꺼지는 숫자는?
    답

    0, 1, 7.

응용

  1. 막대 e(왼쪽 아래)가 켜지는 숫자는? 최소식은?
    답

    0, 2, 6, 8. 무관 조건을 쓰면 \(e = C'A' + BA'\)(D 최상위, A 최하위).

심화

  1. 3.3 V 출력 FPGA로 순방향 전압 2.0 V, 목표 5 mA인 막대를 켤 때 저항은?
    답

    \((3.3 - 2.0)/0.005 = 260\) Ω, 가까운 표준값 270 Ω.
