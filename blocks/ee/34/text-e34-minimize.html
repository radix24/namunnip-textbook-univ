FSM 상태 최소화

본문
이 절에서 배울 것
  • 출력과 다음 상태가 같은 등가 상태를 찾는다.

  • 최소화 후 동작이 같은지 시뮬레이션으로 확인한다.
먼저 알아야 할 것
  • FSM 설계 (3.1절), 무어·밀리 기계 (3.2절).

3.3.1같은 일을 하는 상태 합치기

두 상태가 같은 출력을 내고, 모든 입력에서 다음 상태도 같거나 서로 등가면 하나로 합칠 수 있습니다. 상태 표를 비교해 분할을 반복하는 방법이 체계적이며, 상태가 2ⁿ 경계 아래로 줄면 플립플롭이 하나 줄어듭니다.

예제 3.3.1

상태 표(무어): A: 출력 0, 다음(0/1) = A/B. B: 0, C/B. C: 0, A/D. D: 1, C/E. E: 1, C/E. 합칠 상태와 최소화 후 플립플롭 수는?

풀이. D와 E는 출력 1이 같고 다음 상태가 C/E로 같아 등가 → 합쳐 D/E를 D로. 결과 4상태(A, B, C, D)로 플립플롭 3 → 2개. A, B, C는 출력은 같지만 다음 상태가 서로 달라 합칠 수 없습니다(확인: C는 입력 1에서 출력 1 상태로 감).

흔한 오해(1) "출력이 같으면 합칠 수 있다": 다음 상태까지 등가여야 합니다. (2) "최소화하면 늘 회로가 작아진다": 부호화에 따라 논리는 커질 수도 있습니다.
요약
  1. 등가: 같은 출력 + 등가인 다음 상태.
  2. 예: D ≡ E → 5 → 4상태.
  3. 플립플롭 3 → 2.

3.3.2연습문제

기본

  1. 상태 9개를 8개로 줄이면 이진 플립플롭 수는?
    답

    4 → 3.

응용

  1. 출력이 다른 두 상태는 등가일 수 있나?
    답

    없습니다.

심화

  1. 최소화 뒤 시뮬레이션이 필요한 이유는?
    답

    손 계산 실수로 동작이 바뀌지 않았는지 확인하려고.
