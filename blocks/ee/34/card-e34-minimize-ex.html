중복 상태 찾기

출발점

처음 설계에는 중복 상태가 생기기 쉽습니다(3.3절).

문제 해결 전략 · 표 비교
  1. '101' 검출 무어 기계를 6상태로 그림(가상).
  2. S4, S5가 출력 0, 다음 상태 둘 다 S1/S2.
  3. 합친 뒤 상태 수.

최소화 결과와 플립플롭 수 변화는?

풀이

  1. S4 ≡ S5 → 5상태.
    합침.
  2. 5상태도 3비트 필요 → 플립플롭 수 그대로.
    비트.
  3. 더 찾으면 정석 4상태가 됨(확인해 보기).
    심화.

의미

상태 수를 줄여도 2ⁿ 경계를 넘지 않으면 플립플롭은 그대로지만 논리는 단순해진다.

검산

⌈log₂5⌉ = 3.
