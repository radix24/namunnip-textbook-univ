FPGA로 PWM 만들기

본문
이 절에서 배울 것
  • N비트 카운터와 비교기로 PWM을 만든다.
  • PWM 주파수와 듀티 분해능을 계산한다.
  • LED 밝기와 서보 제어에 맞는 설정을 고른다.
먼저 알아야 할 것
  • 카운터 (2.1절), 클록 분주기 (2.3절).

4.5.1카운터와 비교

N비트 카운터가 0~2ᴺ − 1을 돌고, 카운터 < duty일 때 출력 1이면 듀티 = duty/2ᴺ, 주파수 = f_clk/2ᴺ입니다. 비트를 늘리면 분해능이 좋아지고 주파수는 낮아집니다.

reg [7:0] cnt;
always @(posedge clk) cnt <= cnt + 1;
assign pwm = (cnt < duty);    // duty: 0..255
예제 4.5.1

50 MHz, 8비트의 PWM 주파수와 분해능은? duty = 64의 듀티비는?

풀이. 195.3 kHz, 1/256 단계, 64/256 = 25%. LED 밝기에는 충분하지만 서보(50 Hz, 1~2 ms)에는 분주기로 카운터 속도를 낮추고 비트를 늘려야 합니다(전전25 4.4절).

흔한 오해(1) "duty = 255면 100%": 이 구조에서는 255/256이 최대입니다. (2) "PWM 주파수는 높을수록 좋다": 구동 소자 스위칭 손실이 커집니다.
요약
  1. f_PWM = f_clk/2ᴺ, 듀티 = duty/2ᴺ.
  2. 예: 50 MHz, 8비트 → 195 kHz, 25%.
  3. 비트 ↑ 분해능 ↑ 주파수 ↓.

4.5.2연습문제

기본

  1. 50 MHz, 10비트의 주파수는?
    답

    약 48.8 kHz.

응용

  1. 100% 듀티를 내려면?
    답

    비교를 ≤로 바꾸거나 별도 조건을 둡니다.

심화

  1. LED 밝기 단계가 낮은 쪽에서 거칠게 보이는 이유는?
    답

    눈의 밝기 감각이 로그적이라 낮은 듀티 단계 차이가 크게 느껴집니다.
