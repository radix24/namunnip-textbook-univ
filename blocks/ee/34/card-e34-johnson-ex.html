쓰지 않는 상태 탈출

자기 수정

출발점

4비트 존슨의 쓰지 않는 상태 0100 등에서 빠져나오게 설계합니다(2.4절).

문제 해결 전략 · 상태 추적
  1. 4비트 존슨, 잘못된 상태 0100에서 시작.
  2. 다음 상태 = 마지막 비트를 반전해 왼쪽에 넣고 오른쪽으로 시프트.
  3. 8번 진행.

정상 순환으로 돌아오나?

풀이

  1. 0100 → 1010 → 1101 → 0110 → 1011 → 0101 → 0010 → 1001 → 0100.
    8상태 다른 고리.
  2. 정상 순환과 만나지 않음.
    판정.
  3. 되먹임에 수정 논리를 넣거나 리셋으로 초기화.
    대책.

의미

4비트에서 16 − 8 = 8개 쓰지 않는 상태가 또 하나의 고리를 이룬다.

검산

왼쪽 비트 = 이전 마지막 비트 반전.
