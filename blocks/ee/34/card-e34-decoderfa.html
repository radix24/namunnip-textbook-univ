3-8 디코더 하나로 전가산기 만들기

예제 · 최소항을 모으는 설계

먼저 예측

74HC138(출력 활성 Low) 한 개와 게이트 몇 개로 전가산기를 만들 수 있을까?

생각해 본 뒤 열기

디코더 출력이 최소항이므로, 합과 올림수의 최소항 출력을 NAND로 모으면 된다.

문제

입력 A, B, \(C_{in}\)을 74HC138의 선택 입력(C, B, A 핀; A가 최하위)에 \(A\), \(B\), \(C_{in}\) 순서로 넣는다고 하자(최소항 번호 = \(4A + 2B + C_{in}\)). 출력 \(\overline{Y_0}\)~\(\overline{Y_7}\)은 활성 Low이다. (가) S와 \(C_{out}\)의 최소항, (나) 필요한 게이트, (다) 입력 1, 1, 0에서 각 출력의 값을 구하라.

전략

  1. 진리표에서 S = 1, \(C_{out}\) = 1인 행의 번호를 적는다.
  2. 활성 Low 출력의 OR는 NAND(드모르간: \(Y_a + Y_b = \overline{\overline{Y_a}\cdot\overline{Y_b}}\)).
  3. 74HC138의 허용 입력(G1 = 1, G2A = G2B = 0)을 잊지 않는다.

풀이

  1. (가) S = Σm(1, 2, 4, 7), \(C_{out}\) = Σm(3, 5, 6, 7). 진리표
  2. (나) 4입력 NAND 두 개(74HC20 한 개): S = NAND(\(\overline{Y_1}, \overline{Y_2}, \overline{Y_4}, \overline{Y_7}\)), \(C_{out}\) = NAND(\(\overline{Y_3}, \overline{Y_5}, \overline{Y_6}, \overline{Y_7}\)). 드모르간
  3. (다) 1, 1, 0은 최소항 6. \(\overline{Y_6}\) = 0, 나머지 1. S의 NAND 입력은 모두 1 → S = 0. \(C_{out}\)의 NAND에 0이 하나 → \(C_{out}\) = 1. 1 + 1 + 0 = 10
  4. 허용 핀: G1을 VCC에, G2A, G2B를 접지에. 배선

의미

디코더와 OR(또는 NAND)는 진리표를 그대로 회로로 옮기는 가장 직접적인 방법이다. 함수가 여러 개여도 디코더 하나를 공유할 수 있어, 출력이 많은 작은 함수(예: 7세그먼트의 일곱 막대)에 쓰기 좋다. 입력이 많아지면 디코더 출력 수가 2ⁿ으로 늘어 카르노 맵 최소화(1.3절)나 FPGA의 LUT가 유리하다.

검산

입력 8가지를 모두 넣어 S, \(C_{out}\)이 1비트 덧셈과 같은지 확인한다. 예: 0, 1, 1(최소항 3) → S = 0, \(C_{out}\) = 1. 1, 1, 1(7) → S = 1, \(C_{out}\) = 1.

이해 확인

같은 디코더로 "세 입력 중 정확히 하나만 1"인 함수를 만들려면?

답
