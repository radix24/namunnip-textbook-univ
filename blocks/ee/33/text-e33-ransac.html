2.5.1틀린 짝을 견디는 추정

호모그래피 H(3×3, 자유도 8)는 정합 4쌍으로 구할 수 있습니다. 정합에 틀린 짝(이상치)이 섞이면 RANSAC이 무작위로 4쌍을 뽑아 H를 만들고 맞는 짝 수를 세는 일을 반복합니다. 정상치 비율 w, 성공 확률 p에 필요한 반복 \(N = \log(1 - p)/\log(1 - w^s)\).

예제 2.5.1

정상치 50%, s = 4, p = 0.99의 반복 횟수는? 정상치 70%면?

풀이. N = ln0.01/ln(1 − 0.0625) = 71.4 → 72번. 70%면 17번. 정상치 비율이 낮으면 반복이 급격히 늘어, 정합 단계에서 비율 검사로 틀린 짝을 미리 줄입니다.

흔한 오해(1) "점이 많을수록 RANSAC이 느려진다": 반복 수는 표본 크기 s와 w로 정해집니다. (2) "RANSAC 결과는 늘 같다": 무작위라 실행마다 조금 다를 수 있습니다.
요약
  1. H: 8자유도, 4쌍.
  2. N = log(1 − p)/log(1 − w^s).
  3. 예: w 0.5 → 72, 0.7 → 17.
