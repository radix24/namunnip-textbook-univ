렌즈 왜곡과 보정

본문
이 절에서 배울 것
  • 방사 왜곡 \(x_d = x(1 + k_1r^2 + k_2r^4)\)을 안다.
  • 왜곡 계수로 화소 이동량을 계산한다.
  • 왜곡 보정이 측정·정합에 필요한 이유를 안다.
먼저 알아야 할 것
  • 내부 행렬 (1.2절).

1.3.1직선이 휘어 보이는 이유

실제 렌즈는 중심에서 멀수록 상을 안쪽(통 왜곡, k₁ < 0)이나 바깥쪽(바늘꽂이 왜곡, k₁ > 0)으로 옮깁니다. 정규화 좌표에서 \(x_d = x(1 + k_1r^2)\)(고차 무시). 보정으로 k₁, k₂를 구해 영상을 펴면 직선이 다시 곧아집니다.

예제 1.3.1

k₁ = −0.1, 정규화 점 (0.3, 0.4), f_px = 2000. 왜곡된 위치와 화소 이동량은?

풀이. r² = 0.25 → 배율 0.975 → (0.2925, 0.39). 이동 (0.0075, 0.01) × 2000 = (15, 20)화소, 거리 25화소. 영상 가장자리에서 이 정도 오차면 거리 측정이나 영상 이어 붙이기가 크게 틀어집니다.

흔한 오해(1) "왜곡은 싼 렌즈에만 있다": 광각 렌즈는 거의 모두 큰 왜곡이 있습니다. (2) "가운데 점도 왜곡된다": r = 0이면 이동이 없습니다.
요약
  1. x_d = x(1 + k₁r² + k₂r⁴).
  2. k₁ < 0 통, > 0 바늘꽂이.
  3. 예: 25화소 이동.

1.3.2연습문제

기본

  1. r = 0.2, k₁ = −0.1의 배율은?
    답

    0.996.

응용

  1. 같은 점에서 f_px 2000이면 r 방향 이동은?
    답

    1.6화소.

심화

  1. 어안 렌즈에 이 모형이 부족한 이유는?
    답
