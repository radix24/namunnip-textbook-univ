색 공간과 회색조 변환

본문
이 절에서 배울 것
  • RGB를 밝기 Y = 0.299R + 0.587G + 0.114B로 바꾼다.
  • HSV가 색 기반 분할에 편리한 이유를 안다.
  • 조명 변화에 강한 색 표현을 고른다.
먼저 알아야 할 것
  • 영상의 형성 (1.1절).

1.4.1눈이 느끼는 밝기

사람 눈은 초록에 가장 민감해 회색조 변환에서 G 가중치가 큽니다(BT.601 계수). HSV는 색상(H)을 밝기와 분리해, “빨간 공 찾기”처럼 색으로 나눌 때 조명이 바뀌어도 H 범위를 그대로 쓸 수 있습니다.

예제 1.4.1

화소 (R, G, B) = (200, 100, 50)의 회색조 값은? 단순 평균과 비교하면?

풀이. Y = 59.8 + 58.7 + 5.7 = 124.2, 평균 116.7. 파란 성분이 많은 화소는 평균보다 Y가 훨씬 어둡게 나옵니다. 이 화소는 H = 60 × (100 − 50)/150 = 20°(주황)입니다.

흔한 오해(1) "회색조는 세 채널 평균": 눈의 감도에 맞춘 가중 합을 씁니다. (2) "HSV면 조명과 완전히 무관": 아주 어둡거나 채도가 낮으면 H가 불안정합니다.
요약
  1. Y = 0.299R + 0.587G + 0.114B.
  2. HSV: 색상 분리 → 색 기반 분할.
  3. 예: (200, 100, 50) → 124.2.
