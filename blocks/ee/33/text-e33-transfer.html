사전 학습 모델의 전이 학습

본문
이 절에서 배울 것
  • 대규모 자료로 학습한 특징 추출부를 재사용하는 이유를 안다.
  • 몸통을 고정하고 머리만 학습하는 단계와 미세 조정 단계를 구별한다.
  • 새 분류층의 매개변수 수와 학습률 선택을 계산·판단한다.
먼저 알아야 할 것
  • CNN (전전23 4.2절), 자료 수집 (3.1절).

4.1.1두 단계

ImageNet 같은 큰 자료로 학습한 CNN의 앞쪽 층은 경계·질감 같은 일반 특징을 압니다. 마지막 분류층만 우리 클래스 수로 바꿔

  1. 특징 추출: 몸통을 고정하고 새 머리만 학습(자료가 적을 때).
  2. 미세 조정: 뒤쪽 몇 층을 풀고 작은 학습률(예: 10분의 1)로 함께 학습(자료가 더 있을 때).
model = torchvision.models.resnet18(weights="IMAGENET1K_V1")
for p in model.parameters():
    p.requires_grad = False                      # 1단계: 몸통 고정
model.fc = nn.Linear(model.fc.in_features, 5)    # 공구 5종
opt = torch.optim.Adam(model.fc.parameters(), lr=1e-3)
# ... 학습 후 2단계: layer4를 풀고 lr=1e-4로 미세 조정
예제 4.1.1

ResNet-18의 마지막 특징 차원은 512다. 5클래스 머리의 매개변수 수는? 전체 모델(약 1170만 개, 확인 필요)과 비교하면?

풀이. 512 × 5 + 5 = 2565개로 전체의 약 0.02%. 클래스당 수십 장으로도 학습이 가능한 이유입니다. 입력 영상은 사전 학습 때와 같은 크기·정규화(평균·표준편차)로 맞춥니다.

흔한 오해(1) "미세 조정은 처음부터 큰 학습률로": 좋은 특징을 망가뜨리므로 작게 합니다. (2) "사전 학습 자료와 전혀 다른 영역(예: 열화상)에도 그대로 잘 된다": 차이가 크면 더 많은 층을 다시 학습해야 합니다.
요약
  1. 몸통 재사용 + 새 머리.
  2. 1단계 고정·머리 학습, 2단계 작은 학습률 미세 조정.
  3. 예: 512 × 5 + 5 = 2565 매개변수.
