히스토그램 평활화

본문
이 절에서 배울 것
  • 영상 밝기 히스토그램과 누적 분포를 계산한다.
  • 누적 분포로 밝기를 다시 매겨 대비를 늘린다.
  • 국소 평활화(CLAHE)의 필요를 안다.
먼저 알아야 할 것
  • 필터링 (2.1절).

2.3.1고르게 펴기

밝기 값 k를 \(s_k = \mathrm{round}((L - 1)\cdot\mathrm{CDF}(k))\)로 바꾸면 많이 몰린 밝기 구간이 넓게 퍼져 대비가 커집니다. 영상 전체에 하나의 변환을 쓰면 일부 영역이 지나치게 밝아질 수 있어 작은 구역마다 하는 CLAHE를 씁니다.

img = [52, 55, 61, 59, 79, 61, 76, 61, 62, 59, 55, 104, 94, 85, 59, 71]
L = 256
vals = sorted(set(img))
n = len(img)
cdf, c = {}, 0
for v in vals:
    c += img.count(v); cdf[v] = c / n
mapping = {v: round((L - 1) * cdf[v]) for v in vals}
print("변환표:", mapping)
out = [mapping[v] for v in img]
print("원래 범위:", min(img), "~", max(img), "/ 평활화 후:", min(out), "~", max(out))

실행 결과(Python 3.12에서 실제 실행):

변환표: {52: 16, 55: 48, 59: 96, 61: 143, 62: 159, 71: 175, 76: 191, 79: 207, 85: 223, 94: 239, 104: 255}
원래 범위: 52 ~ 104 / 평활화 후: 16 ~ 255
예제 2.3.1

위 16화소(52~104 범위)를 평활화한 결과 범위는?

풀이. 실행 결과 최솟값 52는 CDF 1/16 → 16, 최댓값 104는 255로 바뀌어 대비가 크게 늘었습니다. 가장 많은 값(59, 61 각 3개)은 간격이 크게 벌어집니다.

흔한 오해(1) "평활화는 늘 영상을 좋게 만든다": 잡음도 함께 키우고 자연스럽지 않을 수 있습니다. (2) "결과 히스토그램이 완전히 평평하다": 이산 값이라 근사적으로만 고릅니다.
요약
  1. s_k = round((L − 1)·CDF(k)).
  2. 몰린 구간을 넓게 폄.
  3. CLAHE: 구역별 + 기울기 제한.

2.3.2연습문제

기본

  1. 모든 화소가 같은 값이면 평활화 결과는?
    답

    모두 255(CDF 1).

응용

  1. CDF(k) = 0.5인 값은 몇으로 바뀌나(L = 256)?
    답

    128(반올림 127.5).

심화

  1. 의료 X선 영상에 CLAHE를 쓰는 이유는?
    답

    부위마다 밝기가 달라 국소 대비를 따로 키워야 해서.
