가상 환경에서 비전 기술이 쓰이는 방식

본문
이 절에서 배울 것
  • 가상 환경에서 합성 자료(정답 라벨 자동 생성)를 만드는 방법을 안다.
  • 도메인 무작위화와 sim-to-real 간극을 설명한다.
  • AR(증강 현실)에서 특징 추적과 깊이로 가상 물체를 고정하는 원리를 안다.
먼저 알아야 할 것
  • 특징점 (2.2절), 전이 학습 (4.1절), 3D 스캔 (5.2절).

5.3.1두 방향

가상 → 학습: 게임엔진에서 스캔한 물체를 여러 배경·조명·자세로 배치해 렌더링하면, 상자·분할 마스크·깊이 같은 정답 라벨이 자동으로 나옵니다. 사람이 라벨을 붙이기 어려운 자료(정밀 분할, 깊이)에 유리합니다.

렌더링 영상은 실제와 질감·잡음·조명이 달라(sim-to-real 간극) 그대로 학습하면 실제에서 성능이 떨어집니다. 색, 질감, 조명, 카메라 위치를 크게 무작위로 바꿔(도메인 무작위화) 모델이 "실제도 그 변형 중 하나"로 보게 하거나, 적은 실제 자료로 미세 조정합니다.

비전 → 가상: AR은 카메라 영상의 특징점을 추적해 카메라 자세를 실시간 추정(SLAM)하고, 평면·깊이를 찾아 가상 물체를 실제 바닥에 고정합니다. 깊이 정보로 실제 물체 뒤에 가상 물체를 가리는(가림) 처리도 합니다.

예제 5.3.1(가상 결과)

합성 자료 1만 장으로만 학습한 공구 검출기가 실제 사진에서 mAP 0.45, 실제 사진 200장으로 미세 조정 후 0.78이었다. 실제 사진 200장만으로 학습했을 때 0.60이었다면 무엇을 알 수 있는가?

풀이. 합성 자료만으로는 간극이 크지만, 합성 사전 학습 + 적은 실제 자료가 실제 자료만보다 낫습니다. 라벨 비용이 큰 문제에서 합성 자료가 가치 있는 이유입니다(수치는 설명용 가상값).

흔한 오해(1) "합성 자료면 실제 자료가 필요 없다": 검증과 미세 조정에는 실제 자료가 필요합니다. (2) "AR 물체가 흔들리는 것은 그래픽 문제": 대개 자세 추정(특징 추적) 오차 때문입니다.
요약
  1. 가상 렌더링 → 자동 라벨 합성 자료.
  2. sim-to-real 간극, 도메인 무작위화, 실제 자료 미세 조정.
  3. AR: SLAM으로 자세 추정, 깊이로 가림.

5.3.2연습문제

기본

  1. 합성 자료의 가장 큰 장점은?
    답

    정답 라벨이 자동으로 정확히 나옵니다.

응용

  1. 도메인 무작위화의 뜻은?
    답

    렌더링 조건을 크게 무작위로 바꿔 실제 영상을 변형 중 하나로 보게 하는 것.

심화

  1. 질감 없는 흰 벽 앞에서 AR 물체가 떠다니는 이유는?
    답

    추적할 특징점이 적어 자세 추정이 불안정하기 때문입니다.
