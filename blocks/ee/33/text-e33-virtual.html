가상 환경에서 비전 기술이 쓰이는 방식

본문

게임엔진 속 가상 세계와 카메라로 보는 실제 세계는 두 방향으로 이어진다. 가상 세계에서 렌더링한 영상으로 비전 모델을 학습시킬 수도 있고, 카메라 영상을 분석해 실제 공간 위에 가상 물체를 띄울 수도 있다. 가상 영상으로 학습하면 무엇이 좋고 무엇이 모자랄까? 그리고 AR은 가상 물체를 어떻게 실제 바닥에 고정할까?

먼저 알아야 할 것특징점(2.2절), 전이 학습(4.1절), 3D 스캔(5.2절)을 쓴다.

5.3.1두 방향

가상에서 학습으로 가는 방향부터 보자. 게임엔진에서 스캔한 물체를 여러 배경·조명·자세로 배치해 렌더링하면, 상자·분할 마스크·깊이 같은 정답 라벨이 자동으로 나온다. 그래서 사람이 라벨을 붙이기 어려운 자료(정밀 분할, 깊이)에 유리하다. 처음 질문의 첫째 답 가운데 좋은 점이 이것이다.

그런데 렌더링 영상은 실제와 질감·잡음·조명이 달라(sim-to-real 간극), 그대로 학습하면 실제에서 성능이 떨어진다. 그래서 색, 질감, 조명, 카메라 위치를 크게 무작위로 바꿔(도메인 무작위화) 모델이 "실제도 그 변형 중 하나"로 보게 하거나, 적은 실제 자료로 미세 조정한다.

비전에서 가상으로 가는 방향도 있다. AR은 카메라 영상의 특징점을 추적해 카메라 자세를 실시간 추정(SLAM)하고, 평면·깊이를 찾아 가상 물체를 실제 바닥에 고정한다. 처음 질문의 둘째 답이 이것이다. 그리고 깊이 정보로 실제 물체 뒤에 가상 물체를 가리는(가림) 처리도 한다.

예제 5.3.1(가상 결과)

합성 자료 1만 장으로만 학습한 공구 검출기가 실제 사진에서 mAP 0.45, 실제 사진 200장으로 미세 조정 후 0.78이었다. 실제 사진 200장만으로 학습했을 때 0.60이었다면 무엇을 알 수 있는지 설명하여라.

풀이. 합성 자료만으로는 간극이 크지만, 합성 사전 학습과 적은 실제 자료를 함께 쓰면 실제 자료만보다 낫다(그림 1). 그러므로 라벨 비용이 큰 문제에서 합성 자료가 가치 있다(수치는 설명용 가상값).

즉 합성 자료는 실제 자료를 대신하기보다 보완한다. 따라서 흔히 많은 합성 자료로 먼저 학습하고, 적은 실제 자료로 다듬고, 실제 자료로만 평가하는 순서를 쓴다.

한편 AR에서 가상 물체가 실제 세계에 붙어 보이려면, 카메라 자세 추정이 매 프레임 정확하고 빨라야 한다. 예를 들어 초당 60프레임이면 한 프레임에 17 ms 안에 추적을 끝내야 한다.

흔한 오해합성 자료면 실제 자료가 필요 없다고 여기기 쉽다. 검증과 미세 조정에는 실제 자료가 필요하다. 또 AR 물체가 흔들리는 것은 그래픽 문제라고 생각하기 쉬운데, 대개 자세 추정(특징 추적) 오차 때문이다.
마무리

가상 렌더링은 라벨이 자동으로 붙은 합성 자료를 만든다. sim-to-real 간극은 도메인 무작위화와 실제 자료 미세 조정으로 줄인다. AR은 SLAM으로 자세를 추정하고 깊이로 가림을 처리한다.
