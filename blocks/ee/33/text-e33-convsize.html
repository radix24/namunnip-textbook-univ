합성곱 층의 출력 크기와 매개변수 수

본문
이 절에서 배울 것
  • 출력 크기 \((W - K + 2P)/S + 1\)을 계산한다.
  • 합성곱 층 매개변수 수 \(K^2C_{in}C_{out} + C_{out}\)을 계산한다.
  • 완전 연결 층과 매개변수 수를 비교한다.
먼저 알아야 할 것
  • 딥러닝 비전 (4.1절).

4.3.1가중치를 나눠 쓰기

합성곱은 같은 작은 커널을 영상 전체에 돌려 써서 매개변수가 입력 크기와 무관합니다. 출력 크기 \((W - K + 2P)/S + 1\), 매개변수 \(K^2C_{in}C_{out} + C_{out}\)(편향 포함).

예제 4.3.1

224×224×3 입력에 3×3, 64채널, 패딩 1, 보폭 1 합성곱의 출력 크기와 매개변수 수는? 같은 입력을 64개 뉴런 완전 연결 층에 넣으면?

풀이. 출력 224×224×64, 매개변수 3·3·3·64 + 64 = 1792. 완전 연결은 150528 × 64 + 64 ≈ 963만 개로 5000배 이상입니다. 다음 3×3, 128채널 층은 73,856개입니다.

흔한 오해(1) "층이 깊으면 매개변수가 늘 많다": 합성곱은 채널 수가 더 좌우합니다. (2) "출력 크기는 입력과 같다": 패딩과 보폭에 따라 줄어듭니다.
요약
  1. 출력 = (W − K + 2P)/S + 1.
  2. 매개변수 = K²C_inC_out + C_out.
  3. 예: 1792 vs 완전 연결 963만.
