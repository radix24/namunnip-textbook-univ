임펄스 응답으로 읽는 인과성과 안정성

본문
이 절에서 배울 것
  • LTI 시스템이 인과적일 조건 \(h(t) = 0\) (\(t < 0\))을 유도한다.
  • BIBO 안정의 필요충분조건 \(\int|h|\,dt < \infty\) (이산은 \(\sum|h[n]| < \infty\))을 증명한다.
  • FIR과 IIR, 무기억, 가역 성질을 임펄스 응답으로 판정한다.
먼저 알아야 할 것
  • 시스템 성질의 정의 (1.2절), 컨볼루션 (2.1절), 등비급수의 수렴 (고교 수학).

2.2.1LTI이면 h가 모든 것을 말한다

1.2절에서는 성질을 입출력 식으로 판정했습니다. LTI 시스템은 \(h\) 하나로 완전히 정해지므로, 나머지 성질도 \(h\)만 보고 판정할 수 있어야 합니다. 이 절은 그 조건을 하나씩 유도합니다. 이산시간으로 설명하고 연속시간 식을 함께 적습니다.

2.2.2인과성

구하려는 것: \(y[n]\)이 미래 입력 \(x[k]\) (\(k > n\))에 의존하지 않을 조건.

\(y[n] = \sum_k x[k]h[n - k]\)에서 \(k > n\)인 항의 계수는 \(h[n - k]\), 곧 음수 번째 \(h\)입니다. 이 항들이 모든 입력에 대해 사라지려면 \(h[m] = 0\) (\(m < 0\))이어야 합니다. 거꾸로 이 조건이면 합이 \(k \le n\)까지만 남습니다.

LTI 인과 조건: \(h[n] = 0\) (\(n < 0\)), \(h(t) = 0\) (\(t < 0\)). "임펄스를 넣기 전에는 반응하지 않는다."

2.2.3BIBO 안정성

정리 2.2.1

LTI 시스템이 BIBO 안정일 필요충분조건은 \(S = \sum_n|h[n]| < \infty\) (연속: \(\int|h(t)|dt < \infty\))이다.

충분성. \(|x[n]| \le B\)이면 삼각부등식으로 \(|y[n]| = |\sum_k h[k]x[n - k]| \le \sum_k|h[k]|\,B = SB\). 출력이 \(SB\)로 유계입니다.

필요성. \(S = \infty\)인데도 안정이라고 가정하고 모순을 찾습니다. 유계 입력 \(x[k] = \text{sgn}(h[-k])\)(값은 −1, 0, 1)을 넣으면 \(y[0] = \sum_k h[k]x[-k] = \sum_k|h[k]| = \infty\). 유계 입력에 무한한 출력이 나왔으므로 불안정입니다. ∎

필요성의 증명이 "가장 나쁜 입력"을 만들어 보인다는 점을 기억하세요. 각 순간 입력의 부호를 \(h\)와 맞춰 모든 항이 같은 방향으로 쌓이게 한 것입니다.

예제 2.2.1

\(h[n] = a^nu[n]\)인 시스템의 인과성과 안정성을 a에 따라 판정하여라. 또 \(h(t) = e^{-2t}u(t)\)와 \(h(t) = u(t)\)는?

풀이. \(n < 0\)에서 0이므로 인과입니다. \(\sum_{n \ge 0}|a|^n\)은 등비급수로, \(|a| < 1\)이면 \(\frac{1}{1 - |a|}\)로 수렴하고 \(|a| \ge 1\)이면 발산합니다. 따라서 \(|a| < 1\)일 때만 안정. 예: \(a = 0.5\)이면 \(S = 2\)이므로 \(|x| \le 1\)인 입력에 대해 \(|y| \le 2\)가 보장됩니다. 연속시간: \(\int_0^\infty e^{-2t}dt = 0.5\)로 안정. \(u(t)\)(적분기)는 \(\int_0^\infty 1\,dt = \infty\)로 불안정. 실제로 계단 입력을 넣으면 출력이 \(t\)로 끝없이 커집니다.

2.2.4그 밖의 성질

무기억: \(h[n] = K\delta[n]\). 지금 입력에 상수를 곱하는 것뿐이다.

가역: \(h * h_{\text{inv}} = \delta\)인 \(h_{\text{inv}}\)가 있다. 예: 누산기 \(h = u[n]\)의 역은 차분기 \(\delta[n] - \delta[n - 1]\).

FIR(유한 임펄스 응답): \(h\)가 유한 개의 표본에서만 0이 아니다. 계수가 유한하면 항상 안정이다.

IIR(무한 임펄스 응답): \(h\)가 끝없이 이어진다. 되먹임(2.3절)이 있으면 대개 IIR이고, 안정성을 따로 확인해야 한다.

흔한 오해"\(h(t) \to 0\)이면 안정"은 틀립니다. \(h(t) = \frac{1}{t+1}u(t)\)는 0으로 가지만 \(\int_0^\infty\frac{dt}{t+1} = \infty\)라 불안정입니다. 크기가 줄어드는 것만이 아니라 넓이가 유한해야 합니다. 또 BIBO 불안정이 "모든 입력에서 출력이 발산"을 뜻하지는 않습니다. 발산하는 유계 입력이 하나라도 있으면 불안정입니다.
요약
  1. LTI 인과 ⇔ \(h = 0\) (음의 시간).
  2. LTI BIBO 안정 ⇔ \(\sum|h| < \infty\) (\(\int|h| < \infty\)). 필요성은 \(x = \text{sgn}(h[-k])\)로 증명.
  3. 무기억 ⇔ \(h = K\delta\). FIR은 늘 안정, IIR은 확인 필요.

2.2.5연습문제

기본

  1. \(h[n] = (0.8)^{|n|}\)은 인과인가? 안정인가?
    답

    \(n < 0\)에서 0이 아니므로 비인과. \(\sum = 1 + 2\cdot\frac{0.8}{0.2} = 9\)로 안정.

  2. \(h(t) = e^{t}u(-t)\)는?
    답

    비인과(음의 시간에서 0이 아님), \(\int_{-\infty}^0e^t dt = 1\)로 안정.

응용

  1. \(h[n] = (0.5)^nu[n]\)에 \(|x| \le 3\)인 입력을 넣을 때 \(|y|\)의 최댓값의 상한은? 그 상한에 닿는 입력은?
    답

    \(3 \times 2 = 6\). \(x[n] = 3\)(상수)이면 정상 상태에서 \(y \to 6\)(h가 모두 양수라 부호 맞추기가 상수 입력).

심화

  1. \(h(t) = \frac{\sin t}{t}\)인 시스템(이상 저역 통과 필터)이 BIBO 안정이 아님을 보여라.
    힌트

    \(\int|\sin t/t|dt\)를 반주기 구간별로 아래에서 어림.

    답

    구간 \([k\pi, (k+1)\pi]\)에서 \(|\sin t/t| \ge |\sin t|/((k+1)\pi)\)이고 \(\int|\sin| = 2\)이므로 \(\int \ge \sum\frac{2}{(k+1)\pi} = \infty\)(조화급수). 이상 필터는 실제로 만들 수 없는 이유 중 하나입니다(8단원).
