임펄스 응답으로 읽는 인과성과 안정성

본문

어떤 디지털 필터의 임펄스 응답을 재 보니 시간이 지날수록 줄어들었다. 그렇다면 이 필터는 어떤 유계 입력에도 출력이 끝없이 커지지 않는다고 장담할 수 있을까? 임펄스 응답만 보고 시스템이 안정한지, 미래를 보지 않는지 판정할 수 있을까?

먼저 알아야 할 것시스템 성질의 정의(1.2절), 컨볼루션(2.1절), 고교 수학의 등비급수 수렴을 쓴다.

2.2.1LTI이면 h가 모든 것을 말한다

1.2절에서는 성질을 입출력 식으로 판정했다. 그런데 LTI 시스템은 \(h\) 하나로 완전히 정해지므로, 나머지 성질도 \(h\)만 보고 판정할 수 있어야 한다. 이 절은 그 조건을 하나씩 유도하며, 이산시간으로 설명하고 연속시간 식을 함께 적는다.

2.2.2인과성

구하려는 것은 \(y[n]\)이 미래 입력 \(x[k]\) (\(k > n\))에 의존하지 않을 조건이다. \(y[n] = \sum_k x[k]h[n - k]\)에서 \(k > n\)인 항의 계수는 \(h[n - k]\), 곧 음수 번째 \(h\)이다. 따라서 이 항들이 모든 입력에 대해 사라지려면 \(h[m] = 0\) (\(m < 0\))이어야 하고, 거꾸로 이 조건이면 합이 \(k \le n\)까지만 남는다.

즉 LTI 시스템이 인과적일 조건은 \(h[n] = 0\) (\(n < 0\)), 연속시간에서는 \(h(t) = 0\) (\(t < 0\))이다. 임펄스를 넣기 전에는 반응하지 않는다는 뜻이다.

2.2.3BIBO 안정성

정리 2.2.1

LTI 시스템이 BIBO 안정일 필요충분조건은 \(S = \sum_n|h[n]| < \infty\) (연속시간에서는 \(\int|h(t)|dt < \infty\))이다.

충분성. \(|x[n]| \le B\)이면 삼각부등식으로 \(|y[n]| = |\sum_k h[k]x[n - k]| \le \sum_k|h[k]|\,B = SB\)이다. 따라서 출력이 \(SB\)로 유계이다.

필요성. \(S = \infty\)인데도 안정이라고 가정하고 모순을 찾는다. 값이 −1, 0, 1인 유계 입력 \(x[k] = \text{sgn}(h[-k])\)를 넣으면 \(y[0] = \sum_k h[k]x[-k] = \sum_k|h[k]| = \infty\)이다. 유계 입력에 무한한 출력이 나왔으므로 불안정이다. ∎

필요성의 증명이 가장 나쁜 입력을 만들어 보인다는 점을 기억하자. 각 순간 입력의 부호를 \(h\)와 맞춰 모든 항이 같은 방향으로 쌓이게 한 것이다.

예제 2.2.1

\(h[n] = a^nu[n]\)인 시스템의 인과성과 안정성을 a에 따라 판정하여라. 또 \(h(t) = e^{-2t}u(t)\)와 \(h(t) = u(t)\)는?

풀이. \(n < 0\)에서 0이므로 인과적이다. \(\sum_{n \ge 0}|a|^n\)은 등비급수로, \(|a| < 1\)이면 \(\frac{1}{1 - |a|}\)로 수렴하고 \(|a| \ge 1\)이면 발산한다. 따라서 \(|a| < 1\)일 때만 안정하다(그림 1). 예를 들어 \(a = 0.5\)이면 \(S = 2\)이므로 \(|x| \le 1\)인 입력에 대해 \(|y| \le 2\)가 보장된다. 연속시간에서는 \(\int_0^\infty e^{-2t}dt = 0.5\)이므로 안정하다. 그러나 적분기 \(u(t)\)는 \(\int_0^\infty 1\,dt = \infty\)로 불안정하며, 실제로 계단 입력을 넣으면 출력이 \(t\)로 끝없이 커진다.

2.2.4그 밖의 성질

무기억 시스템은 \(h[n] = K\delta[n]\)으로, 지금 입력에 상수를 곱하는 것뿐이다. 또 \(h * h_{\text{inv}} = \delta\)인 \(h_{\text{inv}}\)가 있으면 가역이며, 예를 들어 누산기 \(h = u[n]\)의 역은 차분기 \(\delta[n] - \delta[n - 1]\)이다.

한편 \(h\)가 유한 개의 표본에서만 0이 아닌 시스템을 FIR(유한 임펄스 응답)이라 하며, 계수가 유한하면 항상 안정하다. 반면 \(h\)가 끝없이 이어지는 IIR(무한 임펄스 응답) 시스템은 되먹임(2.3절)이 있을 때 흔히 생기고, 안정성을 따로 확인해야 한다.

흔한 오해"\(h(t) \to 0\)이면 안정"은 틀리다. \(h(t) = \frac{1}{t+1}u(t)\)는 0으로 가지만 \(\int_0^\infty\frac{dt}{t+1} = \infty\)라 불안정하다. 처음 질문에 장담할 수 없는 이유가 이것으로, 크기가 줄어드는 것만이 아니라 넓이가 유한해야 한다. 또 BIBO 불안정이 모든 입력에서 출력이 발산한다는 뜻은 아니며, 발산하는 유계 입력이 하나라도 있으면 불안정이다.
마무리

LTI 시스템은 음의 시간에서 \(h = 0\)일 때 인과적이고, \(\sum|h| < \infty\)(연속시간에서는 \(\int|h| < \infty\))일 때 BIBO 안정하다. 안정 조건의 필요성은 부호를 맞춘 입력 \(x = \text{sgn}(h[-k])\)로 증명한다. 무기억 시스템은 \(h = K\delta\)이고, FIR 시스템은 늘 안정하지만 IIR 시스템은 안정성을 따로 따져야 한다.

2.2.5연습문제

기본

  1. \(h[n] = (0.8)^{|n|}\)은 인과인가? 안정인가?
    답

    \(n < 0\)에서 0이 아니므로 비인과이다. \(\sum = 1 + 2\cdot\frac{0.8}{0.2} = 9\)이므로 안정하다.

  2. \(h(t) = e^{t}u(-t)\)는?
    답

    음의 시간에서 0이 아니므로 비인과이고, \(\int_{-\infty}^0e^t dt = 1\)이므로 안정하다.

응용

  1. \(h[n] = (0.5)^nu[n]\)에 \(|x| \le 3\)인 입력을 넣을 때 \(|y|\)의 최댓값의 상한은? 그 상한에 닿는 입력은?
    답

    상한은 \(3 \times 2 = 6\)이다. h가 모두 양수라 부호를 맞춘 입력이 상수이므로, \(x[n] = 3\)이면 정상 상태에서 \(y \to 6\)이다.

심화

  1. \(h(t) = \frac{\sin t}{t}\)인 시스템(이상 저역 통과 필터)이 BIBO 안정이 아님을 보여라.
    힌트

    \(\int|\sin t/t|dt\)를 반주기 구간별로 아래에서 어림한다.

    답

    구간 \([k\pi, (k+1)\pi]\)에서 \(|\sin t/t| \ge |\sin t|/((k+1)\pi)\)이고 \(\int|\sin| = 2\)이므로, \(\int \ge \sum\frac{2}{(k+1)\pi} = \infty\)(조화급수)이다. 이것이 이상 필터를 실제로 만들 수 없는 이유 중 하나이다(8단원).
