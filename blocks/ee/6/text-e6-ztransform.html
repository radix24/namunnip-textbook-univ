Z-변환과 단위원

본문

디지털 필터 설계 프로그램은 z평면이라는 그림에 ×와 ○를 몇 개 찍어 보여 준다. 점 몇 개가 필터의 무엇을 말해 주는 것일까? 그 위치만 보고 필터가 안정한지, 어느 주파수를 키우고 어느 주파수를 지우는지 읽어 낼 수 있을까?

먼저 알아야 할 것차분 방정식과 특성근(2.3절), DTFT(5.1절), Laplace 변환의 ROC(7.1절)를 쓴다.

7.2.1정의와 ROC

3.2절에서 \(z^n\)이 이산 LTI 시스템의 고유함수이고 고윳값이 \(H(z) = \sum h[k]z^{-k}\)임을 보았다. 이 합을 아무 수열에 쓴 것이 Z-변환이다.

\[ X(z) = \sum_{n=-\infty}^{\infty}x[n]\,z^{-n}, \qquad z = re^{j\omega}. \]

식의 합이 절대 수렴하는 z의 집합이 ROC이며, 수렴은 \(|z| = r\)에만 달려 있으므로 두 원 사이의 원환 모양이다. 또 \(|z| = 1\)인 단위원에서 \(z = e^{j\omega}\)를 넣으면 DTFT가 되므로, ROC가 단위원을 포함하면 DTFT가 존재한다.

즉 Laplace의 s평면에서 허수축이 하던 일을 z평면에서는 단위원이 한다. 실제로 \(z = e^{sT}\)로 대응하면 허수축이 단위원으로, 왼쪽 반평면이 단위원 안쪽으로 옮겨 간다.

예제 7.2.1

\(x[n] = a^nu[n]\)의 Z-변환과 ROC, 극점과 영점을 구하여라.

풀이. \(\sum_{n\ge0}(az^{-1})^n = \frac{1}{1 - az^{-1}} = \frac{z}{z - a}\)이다. 등비급수가 수렴하려면 \(|az^{-1}| < 1\), 곧 \(|z| > |a|\)이므로 ROC는 반지름 \(|a|\)인 원의 바깥이다. 극점은 \(z = a\), 영점은 \(z = 0\)이다. 7.1절과 마찬가지로 \(-a^nu[-n-1]\)도 같은 식이고 ROC만 \(|z| < |a|\)이다.

7.2.2차분 방정식에서 H(z)로

Z-변환에서 한 칸 지연은 \(z^{-1}\)을 곱하는 것, 곧 \(x[n - k] \leftrightarrow z^{-k}X(z)\)이며, 블록도의 \(z^{-1}\) 상자가 이 뜻이다. 또 컨볼루션은 곱 \(x * h \leftrightarrow X(z)H(z)\)이 된다. 그래서 차분 방정식 \(\sum a_ky[n-k] = \sum b_kx[n-k]\)의 양변을 변환하면 \(Y\sum a_kz^{-k} = X\sum b_kz^{-k}\)이므로 다음을 얻는다.

\[ H(z) = \frac{Y(z)}{X(z)} = \frac{b_0 + b_1z^{-1} + \cdots + b_Mz^{-M}}{a_0 + a_1z^{-1} + \cdots + a_Nz^{-N}}. \]

식의 분모에 \(z^N\)을 곱하면 \(a_0z^N + a_1z^{N-1} + \cdots + a_N\)으로 2.3절의 특성 방정식과 같다. 곧 특성근이 H(z)의 극점이다.

7.2.3안정성: 극점이 단위원 안에

인과이면 ROC는 가장 바깥 극점의 바깥이고, 안정이면 ROC가 단위원을 포함해야 한다. 둘을 합치면 인과 이산 LTI 시스템은 모든 극점이 단위원 안(\(|p_i| < 1\))에 있을 때 안정하며, 이는 2.3절의 "모든 특성근 \(|r_i| < 1\)"과 같은 말이다. 처음 질문의 첫째 답이 이것이다.

예제 7.2.2

\(y[n] = 0.9y[n-1] - 0.81y[n-2] + x[n] + x[n-2]\)의 \(H(z)\), 극점, 영점을 구하고 안정성과 주파수 응답의 모양을 설명하여라.

풀이. \(H(z) = \frac{1 + z^{-2}}{1 - 0.9z^{-1} + 0.81z^{-2}} = \frac{z^2 + 1}{z^2 - 0.9z + 0.81}\)이다. 영점은 \(z = \pm j\)로 단위원 위의 \(\omega = \pm\pi/2\) 방향에 있다. 극점은 \(z = \frac{0.9 \pm \sqrt{0.81 - 3.24}}{2} = 0.45 \pm 0.779j\)로 크기 \(\sqrt{0.81} = 0.9\), 각 \(\pm60°\) (\(\pm\pi/3\))이다. 모든 극점이 단위원 안이므로 인과 시스템으로 안정하다.

주파수 응답 \(|H(e^{j\omega})|\)는 단위원 위의 점 \(e^{j\omega}\)에서 영점까지 거리의 곱을 극점까지 거리의 곱으로 나눈 것이다. 그래서 \(\omega\)가 극점 방향(\(\pi/3\)) 근처일 때 분모가 작아져 봉우리가 생기고, 영점 방향(\(\pi/2\))에서는 정확히 0이 된다(그림 1). 처음 질문의 둘째 답이 이 거리 읽기이다. 수치로 보면 \(\omega = 0\)에서 \(|H| = \frac{2}{|1 - 0.9 + 0.81|} = \frac{2}{0.91} \approx 2.20\)이며, 이 절의 탐구 카드에서 극점과 영점을 옮기며 확인할 수 있다.

흔한 오해연속시간의 기준(\(\text{Re} < 0\))을 그대로 써서 "극점 0.5 + 0.9j는 실수부가 양수라 불안정"이라 하면 틀리다. 이산시간의 기준은 크기이며, 이 극점은 \(|p| = 1.03 > 1\)이라 불안정한 것이다. 또 극점이 단위원 위(\(|p| = 1\))이면 안정이 아니다(누산기의 극점 z = 1). \(H(z)\)를 \(z^{-1}\)의 식으로 둔 채 극점을 찾으면 \(z = 0\)의 극점과 영점을 빠뜨리기 쉬우므로, z의 양의 거듭제곱으로 바꿔서 찾자.
마무리

Z-변환은 \(X(z) = \sum x[n]z^{-n}\)이고 ROC는 원환이며, 단위원에서 DTFT가 된다. 지연은 \(z^{-1}\)의 곱, 컨볼루션은 곱이므로 차분 방정식의 전달함수 \(H(z)\)는 계수 다항식의 비이고, 특성근이 곧 극점이다. 인과 시스템은 모든 극점이 \(|p| < 1\)일 때 안정하며, 주파수 응답의 크기는 단위원 위의 점에서 영점과 극점까지 거리의 비로 읽는다.

7.2.4연습문제

기본

  1. \(\{1, 2, 3\}\) (n = 0, 1, 2)의 Z-변환과 ROC는?
    답

    \(1 + 2z^{-1} + 3z^{-2}\)이고 ROC는 \(z = 0\)을 뺀 전체이다.

  2. \(H(z) = \frac{1}{1 - 1.2z^{-1}}\)인 인과 시스템은 안정한가?
    답

    극점 1.2가 단위원 밖이라 불안정하다.

응용

  1. \(y[n] - 0.5y[n-1] = x[n] - x[n-1]\)의 H(z), 극점과 영점, \(|H|\)의 \(\omega = 0, \pi\) 값을 구하고 필터 종류를 말하여라.
    답

    \(\frac{1 - z^{-1}}{1 - 0.5z^{-1}}\)이고 영점은 1, 극점은 0.5이다. \(\omega = 0\)에서 0, \(\omega = \pi\)에서 \(2/1.5 \approx 1.33\)이므로 직류를 막는 고역 통과이다.

심화

  1. 극점 \(0.95e^{\pm j\pi/4}\)인 2차 공진기의 차분 방정식(분자 1)을 쓰고, 봉우리가 생기는 주파수를 \(f_s = 8\) kHz에 대해 Hz로 구하여라.
    답

    분모는 \((1 - pz^{-1})(1 - p^*z^{-1}) = 1 - 2(0.95)\cos(\pi/4)z^{-1} + 0.9025z^{-2}\)이므로 \(y[n] = 1.3435y[n-1] - 0.9025y[n-2] + x[n]\)이다. 봉우리는 대략 \(\omega \approx \pi/4\)이므로 \(f = \frac{\pi/4}{2\pi}\times8000 = 1000\) Hz이다(근사).
