유계 입력으로 발산시키기: 가장 나쁜 입력 찾기

예제 · 안정 판정과 출력 상한

먼저 예측

임펄스 응답이 \(h[n] = (-0.5)^nu[n]\)인 시스템에 \(|x| \le 1\)인 입력을 넣을 때, 출력이 가장 크게 될 수 있는 값은 얼마일까? 상수 입력 \(x = 1\)일 때의 출력과 같을까?

생각해 본 뒤 열기

상한은 \(\sum|h| = 2\)이고, 상수 입력의 정상 상태 출력은 \(\sum h = 2/3\)뿐이다. 상한에 닿으려면 부호가 번갈아 바뀌는 입력이 필요하다.

문제

\(h[n] = (-0.5)^nu[n]\)인 시스템의 인과성과 안정성을 판정하고, \(|x[n]| \le 1\)일 때 \(|y[n]|\)의 상한과 그 상한에 (극한에서) 닿는 입력을 구하여라.

전략

  1. 인과: \(n < 0\)에서 h가 0인가.
  2. 안정: \(\sum|h|\)를 등비급수로 계산한다.
  3. 상한에 닿는 입력: 정리 2.2.1의 증명처럼 \(x[n - k]\)의 부호를 \(h[k]\)의 부호와 맞춘다.

풀이

  1. \(u[n]\)이 곱해져 있어 \(n < 0\)에서 0이므로 인과. 2.2.2
  2. \(\sum_{n\ge0}|(-0.5)^n| = \sum 0.5^n = \frac{1}{1 - 0.5} = 2 < \infty\)이므로 BIBO 안정이고, \(|y| \le 2\). 정리 2.2.1
  3. 시각 \(n_1\)에서 \(y[n_1] = \sum_k h[k]x[n_1 - k]\). \(h[k]\)의 부호는 \((-1)^k\)이므로 \(x[n_1 - k] = (-1)^k\), 곧 \(x[m] = (-1)^{n_1 - m}\)이면 모든 항이 \(|h[k]|\)가 된다. 부호 맞추기
  4. 이 입력을 오래전부터 넣으면 \(y[n_1] = \sum_{k\ge0}0.5^k \to 2\). 부호가 매번 바뀌는 입력 \(x[n] = (-1)^n\)이 그것이다(어느 n에서든 \(|y| \to 2\)). 상한 달성

의미

음의 계수 되먹임(\(y[n] = -0.5y[n-1] + x[n]\))은 번갈아 바뀌는 신호, 곧 가장 높은 이산 주파수 \(\omega = \pi\)를 키운다. (앞으로 배울 내용이니 지금은 결론만 보아도 된다) 3단원의 방법으로 주파수 응답을 구하면 \(H(e^{j\omega}) = \frac{1}{1 + 0.5e^{-j\omega}}\)이고, \(\omega = \pi\)에서 \(\frac{1}{1 - 0.5} = 2\), \(\omega = 0\)에서 \(\frac{1}{1.5} = 2/3\)이다. 고역 통과 성격의 시스템이라 상수(가장 낮은 주파수)가 가장 나쁜 입력이 아닌 것이다. 5단원 DTFT에서 다시 본다.

검산

되풀이 계산 \(y[n] = -0.5y[n-1] + x[n]\)에 \(x = 1, -1, 1, -1, \dots\)를 넣으면 \(y = 1, -1.5, 1.75, -1.875, 1.9375, \dots\)로 크기가 2에 다가간다. 상수 입력 1을 넣으면 \(y = 1, 0.5, 0.75, 0.625, \dots \to 2/3\).

이해 확인

\(h(t) = e^{-t}\cos(t)\,u(t)\)는 BIBO 안정인가? \(\int|h|\)의 상한을 하나 구하여라.

답

\(|h| \le e^{-t}\)이므로 \(\int_0^\infty|h|dt \le 1\). 안정.
