시스템의 성질: 선형, 시불변, 인과, 안정

본문

어제 녹음한 노래를 오늘 같은 증폭기에 넣으면 어제와 똑같이 증폭되어 나올 것이다. 그런데 소리를 라디오 반송파에 실어 보내는 변조기는 그렇지 않다. 시스템이 "언제 넣어도 같은 일을 한다"는 것은 어떻게 확인할까? 또 그런 성질을 따지는 것이 왜 그렇게 중요할까?

먼저 알아야 할 것신호의 시간 이동(1.1절), 회로의 중첩 원리(전전3 3.1절)를 쓴다.

1.2.1왜 성질을 따지는가

시스템 하나하나를 따로 공부하면 끝이 없다. 대신 "이 시스템은 선형이고 시불변이다" 같은 성질만 알면, 다음 단원부터 나올 컨볼루션, Fourier 변환, Laplace 변환 같은 강력한 도구를 한꺼번에 쓸 수 있다. 처음 질문의 둘째 답이 이것이며, 그래서 새 시스템을 만나면 가장 먼저 성질을 판정한다. 표기는 연속시간으로 쓰지만 이산시간에도 그대로 적용된다.

1.2.2여섯 가지 성질의 정의

각 시각의 출력이 같은 시각의 입력에만 의존하면 무기억(memoryless) 시스템이다. 저항 \(v = Ri\)는 무기억이고, 축전기 \(v = \frac1C\int i\,dt\)는 기억이 있다. 출력이 현재와 과거의 입력에만 의존하여 미래를 보지 않으면 인과(causal) 시스템이며, 실시간으로 동작하는 물리 시스템은 모두 인과적이다. 또 유계인 입력(\(|x| \le B\))에 대해 출력도 언제나 유계이면 안정(BIBO stable)하다고 한다.

입력을 \(t_0\)만큼 늦추면 출력도 똑같이 \(t_0\)만큼 늦어질 뿐 모양이 같으면 시불변(time-invariant)이다. 가산성 \(T\{x_1 + x_2\} = T\{x_1\} + T\{x_2\}\)과 동차성 \(T\{ax\} = aT\{x\}\)이 모두 성립하면 선형(linear)이며, 한 줄로 \(T\{ax_1 + bx_2\} = aT\{x_1\} + bT\{x_2\}\)이다. 끝으로 출력에서 입력을 유일하게 되살릴 수 있으면 가역(invertible)이다. 예를 들어 \(y = 2x\)는 가역이지만, \(y = x^2\)는 부호를 잃으므로 가역이 아니다.

1.2.3판정하는 방법

구하려는 것은 주어진 식이 각 성질을 만족하는지이며, 증명할 때와 부정할 때 방법이 다르다. 성립을 보일 때는 임의의 \(x_1, x_2, a, b, t_0\)에 대해 정의의 등식을 일반적으로 보여야 한다. 반면 성립하지 않음을 보일 때는 등식이 깨지는 구체적인 입력 하나, 곧 반례를 찾으면 끝이다.

시불변 판정에서는 두 출력을 따로 계산해 비교한다. 하나는 입력을 먼저 늦춘 \(x_2(t) = x(t - t_0)\)을 시스템에 넣은 출력 \(y_2(t)\)이고, 다른 하나는 원래 출력을 나중에 늦춘 \(y(t - t_0)\)이다. 둘이 모든 경우에 같으면 시불변이다(그림 1). 처음 질문의 첫째 답이 이 비교이며, 식에서 t가 입력 밖에 따로 나타나거나(\(t\,x(t)\)처럼) 입력의 시간 인자가 \(x(2t)\)처럼 바뀌면 대개 시변이다.

선형 판정에는 빠른 점검법이 있다. 동차성에서 a = 0으로 두면 입력 0에 대한 선형 시스템의 출력은 반드시 0이다. 그래서 \(y = 2x + 3\)은 \(x = 0\)일 때 \(y = 3\)이므로 선형이 아니며, 이런 것을 증분 선형이라 한다.

예제 1.2.1

다음 시스템의 성질(무기억, 인과, 안정, 시불변, 선형)을 판정하여라. (가) \(y(t) = t\,x(t)\) (나) \(y[n] = x[n] + x[n-1]\) (다) \(y(t) = x(2t)\) (라) \(y(t) = e^{x(t)}\)

풀이. (가)는 같은 시각만 쓰므로 무기억이고 인과적이다. 그러나 \(x = 1\)(유계)이면 \(y = t\)가 무한히 커지므로 불안정하다. 시불변을 점검하면 \(x_2 = x(t - t_0)\)일 때 \(y_2 = t\,x(t - t_0)\)인데 \(y(t - t_0) = (t - t_0)x(t - t_0)\)이어서 다르므로 시변이다. 한편 \(t(ax_1 + bx_2) = a\,tx_1 + b\,tx_2\)이므로 선형이다.

(나)는 과거 값 \(x[n-1]\)을 쓰므로 기억이 있고, 미래는 쓰지 않으므로 인과적이다. 또 \(|y| \le 2B\)로 안정하고, 시불변이며 선형이다. 이것이 2단원에서 다룰 LTI 시스템인 이동 평균이다.

(다)는 \(y(1) = x(2)\)처럼 미래 값을 쓰므로 비인과이고 기억이 있다. 유계 입력이면 출력도 유계라 안정하고 선형이다. 그런데 \(y_2 = x_2(2t) = x(2t - t_0)\)이고 \(y(t - t_0) = x(2t - 2t_0)\)이어서 다르므로 시변이다. (라)는 무기억이고 인과적이며, \(|x| \le B\)이면 \(y \le e^B\)라 안정하고 시불변이다. 그러나 \(x = 0\)이면 \(y = 1\)이므로 비선형이다.

1.2.4LTI 시스템이 중심인 이유

선형이고 시불변인 시스템을 LTI 시스템이라 한다. 저항, 인덕터, 축전기, 연산증폭기로 만든 회로와 대부분의 필터, 통신 채널이 근사적으로 LTI이다. LTI 시스템은 임펄스 하나에 대한 응답만 알면 모든 입력에 대한 응답을 알 수 있고(2단원), 복소 지수 입력에 대해 같은 주파수의 복소 지수를 내놓는다(3단원). 이 과목의 나머지는 거의 이 두 사실에서 나온다.

흔한 오해"식에 t가 들어 있으면 시변이다"는 반만 맞다. \(y(t) = \int_{-\infty}^{t}x(\tau)d\tau\)는 적분 한계에 t가 있지만, 적분 변수를 바꾸어 확인하면 시불변이다. 반대로 "선형 미분방정식이면 선형 시스템이다"도 초기 조건이 0일 때만 맞다. 초기 전압이 남은 축전기 회로는 입력 0에서도 출력이 있으므로 엄밀히는 선형이 아니다.
마무리

시스템의 기본 성질은 무기억, 인과(미래를 쓰지 않음), BIBO 안정(유계 입력에 유계 출력), 시불변(늦춘 입력에 늦춘 출력), 선형(중첩), 가역이다. 성립은 일반적으로 보이고 부정은 반례 하나로 보이며, 시불변은 입력을 먼저 늦춘 출력과 출력을 나중에 늦춘 것을 비교해 판정한다. 선형이면 입력 0에 출력 0이고, 선형이며 시불변인 LTI 시스템이 이 과목의 중심이다.

1.2.5연습문제

기본

  1. \(y[n] = x[-n]\)은 인과적인가? 시불변인가?
    답

    \(y[-3] = x[3]\)이라 비인과이다. \(x[n - n_0]\)을 넣으면 \(x[-n - n_0]\)이고 \(y[n - n_0] = x[-n + n_0]\)이어서 다르므로 시변이다.

  2. \(y(t) = x(t)\cos(\omega_c t)\)(변조기)는 선형인가? 시불변인가?
    답

    선형이지만, 코사인의 위상이 입력과 함께 늦춰지지 않으므로 시변이다.

응용

  1. \(y[n] = \sum_{k=-\infty}^{n}x[k]\)(누산기)가 BIBO 안정이 아님을 반례로 보여라.
    답

    \(x[n] = u[n]\)(유계 1)이면 \(y[n] = n + 1\)로 무한히 커진다.

심화

  1. 가산성은 만족하지만 동차성은 만족하지 않는 시스템의 예를 들어라. (힌트: 복소수 입력)
    답

    \(y = \text{Re}\{x\}\)이다. 더하기는 그대로지만 \(a = j\)이면 \(\text{Re}\{jx\} \ne j\,\text{Re}\{x\}\)이다.
