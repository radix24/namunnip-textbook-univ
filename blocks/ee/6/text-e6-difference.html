미분·차분 방정식으로 표현한 시스템

본문

디지털 필터는 "지금 출력은 지난 출력 몇 개와 입력 몇 개를 섞은 것"이라는 계산 규칙 한 줄로 만든다. 이 규칙만 보고, 임펄스를 넣었을 때 출력이 서서히 사라질지, 출렁이며 사라질지, 아니면 끝없이 커질지 미리 알 수 있을까?

먼저 알아야 할 것BIBO 안정 조건(2.2절), 고교 수학의 수열 점화식과 이차방정식의 근의 공식을 쓴다. 연속시간 미분방정식과 비교하는 문장은 공통8(2단원)과 RLC 회로(전전3 6.1절)를 배운 뒤 다시 읽어도 된다.

2.3.1차분 방정식은 계산 절차다

디지털 필터, 이자 계산, 이동 평균은 지금 출력이 지난 출력 몇 개와 입력 몇 개의 가중합이라는 식으로 정의된다.

\[ \sum_{k=0}^{N}a_k\,y[n - k] = \sum_{k=0}^{M}b_k\,x[n - k]. \]

식만으로는 출력이 하나로 정해지지 않으므로, 입력이 처음 0이 아니게 되는 시점 전에는 출력도 0이라는 초기 휴지(initial rest) 조건을 함께 둔다. 이 조건이 있어야 시스템이 LTI이고 인과적이다. 우변 계산에 지난 출력 \(y[n-k]\)이 쓰이면(\(N \ge 1\)) 되먹임(재귀)이 있다고 하며, 임펄스 응답이 무한히 이어지는 IIR이 된다. 반면 \(N = 0\)이면 \(y[n] = \sum b_kx[n-k]\)이고 임펄스 응답이 곧 계수 \(h[n] = b_n\)인 FIR이다.

그리고 블록도로는\(z^{-1}\)로 표시하는 한 칸 저장소인 지연 소자, 곱셈기, 덧셈기만 쓰면 된다. 연속시간의 미분 방정식은 지연 대신 적분기를 써서 같은 모양으로 그린다.

2.3.2되풀이 계산으로 임펄스 응답 구하기

예제 2.3.1

\(y[n] - 0.5y[n - 1] = x[n] + x[n - 1]\)의 임펄스 응답 \(h[n]\)을 n = 0에서 4까지 구하고, 일반식을 추측하여라.

풀이. \(x = \delta\)이고 초기 휴지로 \(h[-1] = 0\)이다. \(h[n] = 0.5h[n-1] + \delta[n] + \delta[n-1]\)을 차례로 쓰면 \(h[0] = 0 + 1 + 0 = 1\), \(h[1] = 0.5 + 0 + 1 = 1.5\)이고, 이어서 \(h[2] = 0.75\), \(h[3] = 0.375\), \(h[4] = 0.1875\)이다. n ≥ 1에서 매번 절반이 되므로 \(h[n] = \delta[n] + 3(0.5)^n u[n - 1]\)로 쓸 수 있으며, \(n = 1\)이면 \(3 \times 0.5 = 1.5\)로 맞는다. 즉 이 계산은 컴퓨터가 하는 일 그대로이다.

2.3.3닫힌 식: 특성근

구하려는 것은 되풀이 없이 쓴 \(h[n]\)의 일반식이다. 미분방정식에서 \(e^{st}\)를 시도했듯, 차분 방정식에서는 \(r^n\)을 시도한다. 우변에 입력이 \(x[n - M]\)까지 있으므로 \(n > M\)에서는 입력 임펄스가 지나가 우변이 0이다. 그러면 \(h\)는 동차 방정식 \(\sum a_k h[n-k] = 0\)을 만족하고, \(h[n] = r^n\)을 넣으면 다음을 얻는다.

\[ a_0r^N + a_1r^{N-1} + \cdots + a_N = 0 \quad(\text{특성 방정식}). \]

식의 근 \(r_1, \dots, r_N\)이 서로 다르면 \(h[n] = \sum c_ir_i^n\)이고, 계수 \(c_i\)는 되풀이로 구한 첫 몇 값에 맞춘다.

이것은 안정성과 바로 이어진다. \(\sum|h| < \infty\)가 되려면 모든 항 \(r_i^n\)이 줄어들어야 하므로, 근이 복소수여도 크기로 판정하여 모든 특성근이 \(|r_i| < 1\)이어야 한다. 처음 질문의 답이 이 판정이다. 연속시간 미분 방정식에서는 \(e^{s_it}\)가 줄어들려면 \(\text{Re}(s_i) < 0\)이며, 7단원에서 이 근들이 Z-변환과 Laplace 변환의 극점으로 다시 나타난다.

예제 2.3.2

\(y[n] - y[n-1] + 0.5y[n-2] = x[n]\)의 특성근과 안정성, 임펄스 응답의 모양을 구하여라.

풀이. 특성 방정식 \(r^2 - r + 0.5 = 0\)에서 \(r = \frac{1 \pm \sqrt{1 - 2}}{2} = 0.5 \pm 0.5j\)이다. 크기가 \(|r| = \sqrt{0.5} \approx 0.707 < 1\)이므로 안정하다. 또 복소 공액근이라 \(h[n]\)은 \(0.707^n\)으로 줄어드는 진동이며, 각이 \(\angle r = 45°\)이므로 8표본마다 한 번 진동한다. 되풀이로 확인하면 \(h = 1, 1, 0.5, 0, -0.25, -0.25, -0.125, 0, \dots\)로, \(n = 3\)과 \(n = 7\)에서 0을 지나며 부호가 바뀐다(그림 1).

복소수 \(a + bj\)를 좌표평면의 점 (a, b)로 그리면, 원점까지의 거리 \(|r| = \sqrt{a^2 + b^2}\)가 크기이고 양의 가로축에서 잰 각이 \(\angle r\)이다. \(0.5 + 0.5j\)는 (0.5, 0.5)이므로 크기 \(\sqrt{0.5}\), 각 45°이다. 복소수끼리 곱하면 크기는 곱해지고 각은 더해지므로, \(r^n\)은 크기가 \(0.707^n\)으로 줄면서 매번 45°씩 돈다. 그래서 360°/45° = 8표본에 한 바퀴가 진동 주기이다. 직접 \((0.5 + 0.5j)^2 = 0.5j\)(크기 0.5, 각 90°)를 계산해 확인해 보자.

결국 이것은 RLC 회로의 부족 감쇠 응답(전전3 6단원)과 같은 현상을 이산시간에서 본 것이다.

흔한 실수계수 \(a_k\)의 부호를 옮기며 틀리기 쉽다. \(y[n] - 0.5y[n-1]\)을 되풀이 식으로 쓰면 \(y[n] = +0.5y[n-1] + \cdots\)이다. 또 초기 조건을 0이 아닌 값으로 두고 LTI 시스템의 응답이라 부르면 안 되는데, 초기 휴지가 아니면 입력 0에도 출력이 있어 선형이 아니기 때문이다. 특성근의 크기가 정확히 1이면(예를 들어 누산기의 \(r = 1\)) 안정하지 않다.
마무리

선형 상수계수 차분 방정식에 초기 휴지 조건을 두면 인과 LTI 시스템이 되며, 되먹임이 있으면 IIR, 없으면 \(h = b_n\)인 FIR이다. 임펄스 응답은 되풀이 계산으로 구하거나 특성근 \(r_i\)의 합 \(\sum c_ir_i^n\)으로 닫힌 식을 구한다. 모든 \(|r_i| < 1\)이면 안정하고(연속시간에서는 \(\text{Re}\,s_i < 0\)), 근이 복소수이면 응답은 감쇠 진동이다.

2.3.4연습문제

기본

  1. 3점 이동 평균 \(y[n] = \frac13(x[n] + x[n-1] + x[n-2])\)의 임펄스 응답은?
    답

    \(h = \{1/3, 1/3, 1/3\}\) (n = 0, 1, 2)인 FIR이다.

  2. \(y[n] = 1.1y[n-1] + x[n]\)은 안정인가?
    답

    \(r = 1.1\)로 \(|r| > 1\)이라 불안정하다(\(h = 1.1^n u[n]\)).

응용

  1. \(y[n] - 0.75y[n-1] + 0.125y[n-2] = x[n]\)의 임펄스 응답을 닫힌 식으로 구하여라.
    힌트

    근은 0.5와 0.25이다. \(h[0] = 1\), \(h[1] = 0.75\)에 맞춘다.

    답

    \(h[n] = (2(0.5)^n - (0.25)^n)u[n]\)이다. n = 0이면 1, n = 1이면 \(1 - 0.25 = 0.75\)로 맞는다.

심화

  1. 원금에 매달 0.5% 이자가 붙고 매달 x[n]원을 넣는 통장 잔액 y[n]을 차분 방정식으로 쓰고, 이 시스템이 BIBO 안정이 아닌 이유를 설명하여라.
    답

    \(y[n] = 1.005y[n-1] + x[n]\)이다. 특성근 1.005가 1보다 커서 매달 같은 금액(유계 입력)만 넣어도 잔액이 끝없이 커지며, 저축자에게는 반가운 불안정이다.
