Fourier 변환의 성질과 컨볼루션 정리

본문

시정수가 다른 두 RC 필터를 이어 붙였을 때 출력을 구하려면 2단원에서는 컨볼루션 적분을 경우를 나눠 풀어야 했다. 주파수 영역으로 옮겨 가면 이 적분이 더 쉬운 계산으로 바뀔까? 바뀐다면 무엇으로 바뀌고, 다시 시간 영역으로는 어떻게 돌아올까?

먼저 알아야 할 것기본 변환쌍(4.1절), 컨볼루션(2.1절), 부분분수(고교 수학, 공통8 5.1절)를 쓴다.

4.2.1성질이 필요한 이유

모든 신호의 변환을 적분으로 구하는 것은 번거롭다. 대신 몇 개의 기본쌍(4.1절)과 "신호를 이렇게 바꾸면 변환은 저렇게 바뀐다"는 성질 몇 개를 알면 대부분의 변환을 조립할 수 있다. 아래에서 \(x \leftrightarrow X(j\omega)\)라 쓴다.

성질시간 영역주파수 영역
선형성\(ax_1 + bx_2\)\(aX_1 + bX_2\)
시간 이동\(x(t - t_0)\)\(e^{-j\omega t_0}X(j\omega)\)
주파수 이동(변조)\(e^{j\omega_0t}x(t)\)\(X(j(\omega - \omega_0))\)
척도\(x(at)\)\(\frac{1}{|a|}X(j\omega/a)\)
미분\(dx/dt\)\(j\omega X\)
적분\(\int_{-\infty}^tx\,d\tau\)\(\frac{X}{j\omega} + \pi X(0)\delta(\omega)\)
쌍대성\(X(jt)\)\(2\pi x(-\omega)\)

표에서 시간 이동은 크기 스펙트럼을 그대로 두고 위상만 \(-\omega t_0\) 더하며, 주파수 이동은 스펙트럼 전체를 \(\omega_0\)만큼 옮긴다(4.3절). 쌍대성에 따라 펄스와 sinc가 짝이므로 sinc와 펄스도 짝이다. 또 Parseval 관계 \(\int|x|^2dt = \frac{1}{2\pi}\int|X|^2d\omega\)는 에너지를 어느 영역에서 재도 같다는 뜻이다.

시간 이동의 증명 하나를 보면 나머지도 같은 방식이다. \(\int x(t - t_0)e^{-j\omega t}dt\)에서 \(\sigma = t - t_0\)로 치환하면 \(e^{-j\omega t_0}\int x(\sigma)e^{-j\omega\sigma}d\sigma\)가 된다.

4.2.2컨볼루션 정리

정리 4.2.1

\(y = x * h\)이면 \(Y(j\omega) = X(j\omega)H(j\omega)\)이다. 쌍대로, \(x(t)p(t) \leftrightarrow \frac{1}{2\pi}X * P\)이다.

구하려는 것은 \(Y\)를 X와 H로 쓰는 것이다. 정의에 컨볼루션을 넣고 적분 순서를 바꾼다.

\[ Y = \int\Big[\int x(\tau)h(t - \tau)d\tau\Big]e^{-j\omega t}dt = \int x(\tau)\Big[\int h(t - \tau)e^{-j\omega t}dt\Big]d\tau. \]

식의 안쪽 괄호는 시간 이동 성질로 \(e^{-j\omega\tau}H(j\omega)\)이다. H는 \(\tau\)와 무관하므로 밖으로 나오고, 남은 \(\int x(\tau)e^{-j\omega\tau}d\tau = X\)이다. ∎

이것은 3.2절의 고유함수 성질을 모든 신호로 넓힌 결과이다. 입력을 주파수 성분 X로 쪼개고, 성분마다 H를 곱하고, 다시 모은다. 처음 질문의 답이 이것으로, 시간 영역의 어려운 컨볼루션이 주파수 영역의 곱셈이 된다.

예제 4.2.1

\(h(t) = e^{-2t}u(t)\)인 시스템에 \(x(t) = e^{-t}u(t)\)를 넣을 때 출력을 주파수 영역에서 구하여라.

풀이. 먼저 변환하면 \(X = \frac{1}{1 + j\omega}\), \(H = \frac{1}{2 + j\omega}\)이고, 곱하면 \(Y = \frac{1}{(1 + j\omega)(2 + j\omega)}\)이다. 이제 역변환을 위해 표에 있는 꼴로 쪼갠다. \(v = j\omega\)로 두면 \(\frac{1}{(1 + v)(2 + v)} = \frac{A}{1 + v} + \frac{B}{2 + v}\)에서, \(v = -1\)을 대입해 \(A = \frac{1}{2 - 1} = 1\), \(v = -2\)를 대입해 \(B = \frac{1}{1 - 2} = -1\)이다. 따라서 \(y(t) = (e^{-t} - e^{-2t})u(t)\)이다.

검산하면 2.1절 연습 4의 공식 \(\frac{e^{-at} - e^{-bt}}{b - a}\)에 a = 1, b = 2를 넣은 것과 같다. 또 수치로 보면 \(y\)는 \(t = \ln 2 \approx 0.693\)에서 최댓값 \(0.5 - 0.25 = 0.25\)이다(그림 1).

4.2.3필터링의 그림

정리에서 \(|Y| = |X||H|\), \(\angle Y = \angle X + \angle H\)이다. 그림으로는 입력 스펙트럼에 필터의 크기 응답을 덮어씌우는 일이며, 예를 들어 이상 저역 통과 필터 \(H = 1\) (\(|\omega| < W\))를 쓰면 W 위의 성분이 완전히 사라진다. 이 절의 예제 카드에서 두 펄스의 컨볼루션을 이 방법으로 확인한다.

흔한 실수\(\frac{1}{(1 + j\omega)(2 + j\omega)}\)의 역변환을 부분분수 없이 \(e^{-t}\cdot e^{-2t}\)로 쓰는 실수가 흔하다. 주파수 영역의 곱은 시간 영역의 곱이 아니라 컨볼루션이다. 또 곱셈 정리의 \(\frac{1}{2\pi}\)를 빠뜨리기 쉬운데, f를 쓰면 없다. "시간 이동은 스펙트럼을 바꾸지 않는다"는 말도 크기에 대해서만 맞고, 위상은 \(-\omega t_0\)만큼 바뀐다.
마무리

Fourier 변환의 성질에서 시간 이동은 위상 \(e^{-j\omega t_0}\), 변조는 주파수 이동, 미분은 \(j\omega\)의 곱, 척도는 반비례로 나타나며, 쌍대성과 Parseval 관계가 성립한다. 컨볼루션 정리에 따라 컨볼루션은 곱 \(Y = XH\)가 되고, 반대로 곱은 \(\frac1{2\pi}\)을 곱한 컨볼루션이 된다. 그래서 LTI 시스템의 출력은 변환하고, 곱하고, 부분분수로 쪼개 표로 역변환하는 순서로 구한다.

4.2.4연습문제

기본

  1. \(e^{-(t-2)}u(t - 2)\)의 변환은?
    답

    \(\frac{e^{-j2\omega}}{1 + j\omega}\)이다.

  2. \(\frac{\sin 3t}{\pi t}\)의 변환을 쌍대성(또는 4.1절 연습 3)으로 구하여라.
    답

    \(|\omega| < 3\)에서 1, 그 밖에서 0이다.

응용

  1. \(h = e^{-t}u(t)\), \(x = e^{-t}u(t)\)일 때 \(Y\)와 \(y(t)\)를 구하여라.
    답

    \(Y = \frac{1}{(1 + j\omega)^2}\)이므로 \(y = te^{-t}u(t)\)이다(4.1절 연습 4).

심화

  1. Parseval로 \(\int_{-\infty}^{\infty}\frac{\sin^2 t}{t^2}dt\)를 구하여라.
    힌트

    \(\frac{\sin t}{t} \leftrightarrow \pi\) (\(|\omega| < 1\))이다.

    답

    \(\frac{1}{2\pi}\int_{-1}^{1}\pi^2d\omega = \pi\)이다.
