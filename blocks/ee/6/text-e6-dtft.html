이산시간 Fourier 변환(DTFT)

본문

센서 값을 네 개씩 평균 내면 잡음이 줄어든다. 그런데 평균이 어떤 주파수는 그대로 통과시키고 어떤 주파수는 완전히 지우는지 알 수 있을까? 또 수열에서는 \(\cos(0.1\pi n)\)과 \(\cos(2.1\pi n)\)이 같은 수열이라는데, 그렇다면 이산시간의 "주파수"는 무엇을 뜻할까?

먼저 알아야 할 것연속시간 Fourier 변환(4.1절), DTFS(3.1절), 등비급수의 합 공식을 쓴다.

5.1.1정의

컴퓨터 안의 신호는 수열 \(x[n]\)이다. 연속시간 변환의 적분을 합으로 바꾸면 이산시간 Fourier 변환(DTFT)이 된다.

\[ X(e^{j\omega}) = \sum_{n=-\infty}^{\infty}x[n]\,e^{-j\omega n}, \qquad x[n] = \frac{1}{2\pi}\int_{2\pi}X(e^{j\omega})\,e^{j\omega n}\,d\omega. \]

식의 이산 각주파수 \(\omega\)는 단위가 [rad/표본]으로, 표본 사이에 위상이 얼마나 도는가를 뜻한다. 또 \(X(e^{j\omega})\)라는 표기는 7단원의 Z-변환 \(X(z)\)를 단위원 \(z = e^{j\omega}\) 위에서 잰 것이라는 뜻이다.

DTFT가 보통의 함수로 존재하려면 \(\sum|x[n]| < \infty\)이면 충분하다. 이것은 2.2절의 안정 조건 \(\sum|h| < \infty\)와 같으므로, 안정한 시스템은 언제나 주파수 응답 \(H(e^{j\omega})\)를 가진다.

5.1.2왜 주기 \(2\pi\)인가

구하려는 것은 \(X(e^{j(\omega + 2\pi)})\)와 \(X(e^{j\omega})\)의 관계이다. n이 정수라 \(e^{-j2\pi n} = 1\)이므로 각 항의 지수에서 \(e^{-j(\omega + 2\pi)n} = e^{-j\omega n}e^{-j2\pi n} = e^{-j\omega n}\)이다. 따라서 모든 항이 같아 \(X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})\)이다.

물리적으로 보면, 정수 n에서만 보면 \(\cos(0.1\pi n)\)과 \(\cos(2.1\pi n)\)은 같은 수열이다. 즉 이산시간에는 \(2\pi\)보다 큰 주파수가 따로 없으므로 \(-\pi < \omega \le \pi\) 한 구간만 보면 된다. 처음 질문의 둘째 답이 이것이다. 그 구간에서 \(\omega \approx 0\)(또는 \(2\pi\)의 정수배)은 천천히 변하는 낮은 주파수이고, \(\omega = \pi\)는 \((-1)^n = e^{j\pi n}\), 곧 매 표본마다 부호가 바뀌는 가장 빠른 신호이다.

표본화 주기가 \(T_s\)이면 연속 주파수 Ω(rad/s)와 \(\omega = \Omega T_s\)로 연결된다. 따라서 \(\omega = \pi\)가 표본화 주파수의 절반에 해당하며, 6단원에서 다시 본다.

5.1.3기본 DTFT 계산

예제 5.1.1

\(x[n] = a^nu[n]\) (\(|a| < 1\))의 DTFT를 구하고, \(a = 0.5\)일 때 \(\omega = 0\)과 \(\omega = \pi\)에서의 크기를 구하여라.

풀이. 공비의 크기 \(|a| < 1\)이라 등비급수가 수렴하므로 \(X = \sum_{n\ge0}(ae^{-j\omega})^n = \frac{1}{1 - ae^{-j\omega}}\)이다. \(a = 0.5\)이면 \(\omega = 0\)에서 \(\frac{1}{0.5} = 2\), \(\omega = \pi\)에서 \(\frac{1}{1.5} \approx 0.667\)이다. 즉 양의 a는 저역 통과이고, \(a = -0.5\)이면 값이 뒤바뀌어 고역 통과가 된다.

예제 5.1.2

L점 이동 평균 \(h[n] = \frac1L\) (\(0 \le n \le L - 1\))의 주파수 응답 크기를 구하고, L = 4일 때 영점을 찾아라.

풀이. 유한 등비합으로 \(H = \frac1L\sum_{n=0}^{L-1}e^{-j\omega n} = \frac1L\cdot\frac{1 - e^{-j\omega L}}{1 - e^{-j\omega}}\)이다. 분자와 분모에서 반각 지수를 묶어 내면 \(\frac{e^{-j\omega L/2}(e^{j\omega L/2} - e^{-j\omega L/2})}{e^{-j\omega/2}(e^{j\omega/2} - e^{-j\omega/2})}\)이므로 다음과 같다.

\[ |H(e^{j\omega})| = \frac{1}{L}\left|\frac{\sin(\omega L/2)}{\sin(\omega/2)}\right|, \qquad \angle H = -\omega\frac{L - 1}{2}. \]

식은 \(\omega = 0\)에서 1이어서 직류를 그대로 통과시키고, 영점은 \(\sin(\omega L/2) = 0\), 곧 \(\omega = 2\pi k/L\) (k ≠ 0)이다. L = 4이면 \(\omega = \pi/2, \pi\)이므로 한 주기 4표본인 진동은 4점 평균으로 정확히 지워진다(그림 1). 처음 질문의 첫째 답이 이것이다. 또 위상이 \(-1.5\omega\)로 직선이라 모든 성분이 똑같이 1.5표본 늦어지는데, 이를 선형 위상이라 한다(8단원).

흔한 오해"\(\omega\)를 키우면 더 높은 주파수"는 \(\pi\)까지만 맞다. \(\omega = 1.9\pi\)는 \(-0.1\pi\)와 같은 낮은 주파수이다. 또 수열이 이산이라 변환도 이산이라고 생각하기 쉬운데, DTFT는 \(\omega\)에 대해 연속 함수이다. 이산이 되는 것은 신호가 주기일 때(DTFS)나 다음 절의 DFT이다. 연속 Fourier 변환과 혼동해 \(X(j\omega)\)라 쓰면 주기성이 사라진 것처럼 보이므로 \(X(e^{j\omega})\) 표기를 지키자.
마무리

DTFT는 \(X(e^{j\omega}) = \sum x[n]e^{-j\omega n}\)이고 역변환은 \(2\pi\) 한 주기의 적분이다. n이 정수이므로 DTFT는 \(2\pi\) 주기이며, \(\omega \approx 0\)이 저주파, \(\omega = \pi\)가 가장 높은 주파수이다. 기본 쌍은 \(a^nu[n] \leftrightarrow \frac1{1 - ae^{-j\omega}}\)이고, L점 이동 평균은 \(|H| = \frac{|\sin(\omega L/2)|}{L|\sin(\omega/2)|}\)로 \(\omega = 2\pi k/L\)에서 영점을 가진다.

5.1.4연습문제

기본

  1. \(x = \delta[n] + 2\delta[n-1] + \delta[n-2]\)의 DTFT와 \(\omega = 0, \pi/2, \pi\)에서의 크기는?
    답

    \(X = 1 + 2e^{-j\omega} + e^{-j2\omega} = e^{-j\omega}(2 + 2\cos\omega)\)이므로 크기는 4, 2, 0이다.

  2. \(\cos(0.3\pi n)\)과 같은 수열이 되는 \(\cos(\omega n)\)을 \(\pi < \omega < 3\pi\)에서 모두 찾아라.
    답

    \(\omega = 1.7\pi\)(\(= 2\pi - 0.3\pi\))와 \(2.3\pi\)이다.

응용

  1. \(y[n] = x[n] - x[n-1]\)(차분기)의 \(|H|\)를 구하고 어떤 필터인지 말하여라.
    답

    \(|1 - e^{-j\omega}| = 2|\sin(\omega/2)|\)이다. \(\omega = 0\)에서 0, \(\pi\)에서 2이므로 고역 통과이다.

심화

  1. \(x[n] = (-1)^na^nu[n]\)의 DTFT가 \(X(e^{j(\omega - \pi)})\)임을 보이고, 이것으로 저역 통과 필터를 고역 통과로 바꾸는 방법을 설명하여라.
    답

    \((-1)^n = e^{j\pi n}\)이므로 주파수 이동 성질로 \(\pi\)만큼 이동한다. 그래서 임펄스 응답에 \((-1)^n\)을 곱하면 응답 곡선이 \(\pi\)만큼 옮겨 저역 통과가 고역 통과가 된다.
