DFT: DTFT를 N점에서 표본화하기

본문

컴퓨터로 소리의 스펙트럼을 그리면 연속 곡선이 아니라 점 1024개가 나온다. 이 점들은 앞 절의 DTFT 곡선과 어떤 관계일까? 또 데이터 뒤에 0을 잔뜩 붙여 점을 더 촘촘히 찍으면 가까이 붙은 두 음도 더 잘 구별할 수 있을까?

먼저 알아야 할 것DTFT(5.1절), DTFS(3.1.4절), 컨볼루션 합(2.1절)을 쓴다.

5.2.1왜 DFT가 필요한가

DTFT는 \(\omega\)의 연속 함수라서 컴퓨터가 그대로 다룰 수 없고, 무한히 긴 수열의 합이라 계산도 끝나지 않는다. 그래서 컴퓨터에서 쓰려면 유한한 길이의 신호만, 유한한 개수의 주파수에서만 계산해야 하며, 그 결과가 DFT이다.

\[ X[k] = \sum_{n=0}^{N-1}x[n]\,e^{-j2\pi kn/N}, \quad k = 0, \dots, N-1, \qquad x[n] = \frac1N\sum_{k=0}^{N-1}X[k]\,e^{j2\pi kn/N}. \]

식의 각 k를 DFT 빈(bin)이라 하며, 이산 주파수 \(\omega_k = 2\pi k/N\)에 해당한다. 표본화 주파수 \(f_s\)로 표본화한 신호라면 실제 주파수는 \(f_k = kf_s/N\)이고, 이웃한 빈 사이의 간격 \(\Delta f = f_s/N\)은 관측 시간 \(T = N/f_s\)의 역수이다. 또 실수 x이면 \(X[N - k] = X[k]^*\)이므로 \(k > N/2\)인 빈은 음의 주파수에 해당한다.

5.2.2DFT와 DTFT, DTFS의 관계

구하려는 것은 같은 수열에 대한 세 변환이 어떻게 연결되는가이다. \(x[n]\)이 \(0 \le n \le N-1\)에서만 0이 아니면 DTFT의 합도 그 구간뿐이므로 다음이 성립한다.

\[ X(e^{j\omega})\big|_{\omega = 2\pi k/N} = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N} = X[k]. \]

곧 DFT는 DTFT 곡선을 \(2\pi/N\) 간격으로 찍은 N개의 점이며, 처음 질문의 첫째 답이 이것이다. 또 DTFS 계수 식과 비교하면 \(X[k] = N a_k\)이므로, DFT는 x를 주기 N으로 반복한 신호의 Fourier 급수이기도 하다. 이 두 번째 해석 때문에 DFT의 세계에서는 신호가 언제나 주기 N으로 반복된 것처럼 행동한다.

예제 5.2.1

\(x = \{1, 1, 1, 1\}\)의 4점 DFT와 8점 DFT(뒤에 0 네 개를 채움)를 구하고 DTFT와 비교하여라.

풀이. DTFT는 5.1절 예제 5.1.2에서 L = 4로 두고 크기를 4배 한 것이므로 \(|X(e^{j\omega})| = \left|\frac{\sin 2\omega}{\sin(\omega/2)}\right|\)이다. 이 곡선은 \(\omega = 0\)에서 4이고, \(\omega = \pi/2, \pi, 3\pi/2\)에서 0이다.

4점 DFT는 \(\omega_k = 0, \pi/2, \pi, 3\pi/2\)에서 찍으므로 \(X = \{4, 0, 0, 0\}\)이다. 영점만 찍혀 마치 직류만 있는 것처럼 보이지만, 주기 4로 반복하면 실제로 상수 1이므로 맞는 답이다. 반면 8점 DFT는 \(\omega_k = k\pi/4\)에서 찍는다. k = 1이면 \(|X| = \frac{\sin(\pi/2)}{\sin(\pi/8)} \approx 2.613\), k = 2이면 0, k = 3이면 \(\frac{|\sin(3\pi/2)|}{\sin(3\pi/8)} \approx 1.082\)이다. 즉 같은 DTFT 곡선의 점이 더 촘촘히 보인다(그림 1).

수열 뒤에 0을 붙여 N을 늘리는 것을 영 채우기라 한다. 영 채우기를 해도 DTFT 곡선은 바뀌지 않고 찍는 점만 촘촘해진다. 그래서 가까운 두 주파수를 구별하는 능력, 곧 해상도는 실제 관측 길이로 정해지며 영 채우기로 늘지 않는다. 처음 질문의 둘째 답이 이것이다.

5.2.3순환 컨볼루션

DFT끼리의 곱 \(X[k]H[k]\)의 역DFT는 선형 컨볼루션이 아니라 순환 컨볼루션이다. 두 신호를 주기 N으로 반복된 것으로 보므로, 선형 컨볼루션의 끝부분이 앞으로 감겨 들어오기 때문이다. 따라서 길이 \(L_x\), \(L_h\)인 두 수열을 \(N \ge L_x + L_h - 1\)로 영 채우기한 뒤 DFT를 곱해야 순환 컨볼루션이 선형 컨볼루션과 같아진다.

예를 들어 2.1절 예제의 \(\{1, 2, 3\} * \{1, 1\} = \{1, 3, 5, 3\}\)을 N = 3으로 하면 마지막 3이 맨 앞으로 감겨 \(\{4, 3, 5\}\)가 나온다. 반면 N = 4 이상이면 올바른 \(\{1, 3, 5, 3\}\)이 나온다. 이것이 긴 신호를 FFT로 필터링하는 방법(overlap-add)의 바탕이다.

흔한 오해"영 채우기로 해상도가 좋아진다"는 생각은 틀리다. 곡선을 더 촘촘히 볼 뿐 붙어 있는 두 봉우리를 갈라 주지는 못하므로, 해상도를 높이려면 더 오래 관측해야 한다. 또 DFT 결과를 그대로 그리면 \(k > N/2\) 쪽이 높은 주파수처럼 보이지만 실제로는 음의 주파수이다. 빈 사이 주파수의 정현파는 한 빈에 모이지 않고 여러 빈으로 퍼지는데, 이를 누설이라 한다(8.2절).
마무리

N점 DFT는 \(X[k] = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}\)이고, 빈 k는 실제 주파수 \(f_k = kf_s/N\)에 해당하며 빈 간격은 \(f_s/N\)이다. DFT는 DTFT를 \(2\pi k/N\)에서 찍은 값이고, 주기 반복 신호의 DTFS 계수에 N을 곱한 것이기도 하다. 영 채우기는 표본 간격만 줄이며, DFT의 곱은 순환 컨볼루션에 대응해 \(N \ge L_x + L_h - 1\)일 때 선형 컨볼루션과 같다.

5.2.4연습문제

기본

  1. \(\{1, 0, -1, 0\}\)의 4점 DFT를 구하여라.
    답

    \(X[k] = 1 - e^{-j\pi k} = 1 - (-1)^k\)이므로 \(\{0, 2, 0, 2\}\)이다.

  2. \(f_s = 8\) kHz, N = 1024이면 빈 간격과 빈 100의 주파수는?
    답

    빈 간격은 7.8125 Hz, 빈 100은 781.25 Hz이다.

응용

  1. \(\{1, 2\}\)와 \(\{1, -1, 1\}\)을 DFT로 선형 컨볼루션하려면 N은 최소 얼마인가? 결과는?
    답

    N ≥ 4이고 결과는 \(\{1, 1, -1, 2\}\)이다.

심화

  1. N점 DFT를 정의대로 계산하면 복소 곱셈이 몇 번 필요한가? N = 1024일 때 FFT(약 \(\frac N2\log_2N\)번)와 비교하여라.
    답

    \(N^2 = 1{,}048{,}576\)번 대 \(512 \times 10 = 5120\)번으로 약 200배 차이이다(5.3절).
