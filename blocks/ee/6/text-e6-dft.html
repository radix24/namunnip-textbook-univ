DFT: DTFT를 N점에서 표본화하기

본문
이 절에서 배울 것
  • N점 DFT를 정의하고, 길이 N인 수열의 DTFT를 \(\omega_k = 2\pi k/N\)에서 잰 값임을 보인다.
  • 영 채우기(zero padding)가 해상도가 아니라 표본 간격만 바꾼다는 것을 안다.
  • DFT의 곱이 순환 컨볼루션에 대응함을 알고, 선형 컨볼루션을 얻는 길이 조건을 쓴다.
먼저 알아야 할 것
  • DTFT (5.1절), DTFS (3.1.4절), 컨볼루션 합 (2.1절).

5.2.1왜 DFT가 필요한가

DTFT는 \(\omega\)의 연속 함수라서 컴퓨터가 그대로 다룰 수 없고, 무한히 긴 수열의 합이라 계산도 끝나지 않습니다. 컴퓨터에서 쓰려면 (1) 유한한 길이의 신호만, (2) 유한한 개수의 주파수에서만 계산해야 합니다. 그 결과가 DFT입니다.

\[ X[k] = \sum_{n=0}^{N-1}x[n]\,e^{-j2\pi kn/N}, \quad k = 0, \dots, N-1, \qquad x[n] = \frac1N\sum_{k=0}^{N-1}X[k]\,e^{j2\pi kn/N}. \]

DFT 빈(bin) k: 이산 주파수 \(\omega_k = 2\pi k/N\). 표본화 주파수 \(f_s\)로 표본화한 신호라면 실제 주파수 \(f_k = kf_s/N\).

주파수 간격 \(\Delta f = f_s/N\): 이웃한 빈 사이의 간격. 관측 시간 \(T = N/f_s\)의 역수.

대칭: 실수 x이면 \(X[N - k] = X[k]^*\). \(k > N/2\)인 빈은 음의 주파수에 해당한다.

5.2.2DFT와 DTFT, DTFS의 관계

구하려는 것: 같은 수열에 대한 세 변환이 어떻게 연결되는가. \(x[n]\)이 \(0 \le n \le N-1\)에서만 0이 아니면 DTFT의 합도 그 구간뿐이므로

\[ X(e^{j\omega})\big|_{\omega = 2\pi k/N} = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N} = X[k]. \]

곧 DFT는 DTFT 곡선을 \(2\pi/N\) 간격으로 찍은 N개의 점입니다. 또 DTFS 계수 식과 비교하면 \(X[k] = N a_k\)이므로, DFT는 x를 주기 N으로 반복한 신호의 Fourier 급수이기도 합니다. 이 두 번째 해석 때문에 DFT의 세계에서는 신호가 언제나 "주기 N으로 반복"된 것처럼 행동합니다.

예제 5.2.1

\(x = \{1, 1, 1, 1\}\)의 4점 DFT와 8점 DFT(뒤에 0 네 개를 채움)를 구하고 DTFT와 비교하여라.

풀이. DTFT는 5.1절 예제 5.1.2에서 L = 4, 크기 4배: \(|X(e^{j\omega})| = \left|\frac{\sin 2\omega}{\sin(\omega/2)}\right|\), \(\omega = 0\)에서 4, \(\omega = \pi/2, \pi, 3\pi/2\)에서 0.

  • 4점 DFT: \(\omega_k = 0, \pi/2, \pi, 3\pi/2\) → \(X = \{4, 0, 0, 0\}\). 영점만 찍혀 마치 직류만 있는 것처럼 보입니다(주기 4로 반복하면 실제로 상수 1이므로 맞는 답).
  • 8점 DFT: \(\omega_k = k\pi/4\). k = 1이면 \(|X| = \frac{\sin(\pi/2)}{\sin(\pi/8)} \approx 2.613\), k = 2이면 0, k = 3이면 \(\frac{|\sin(3\pi/2)|}{\sin(3\pi/8)} \approx 1.082\). 같은 DTFT 곡선의 점이 더 촘촘히 보입니다.

영 채우기: 수열 뒤에 0을 붙여 N을 늘린다. DTFT 곡선은 바뀌지 않고, 찍는 점만 촘촘해진다. 가까운 두 주파수를 구별하는 능력(해상도)은 실제 관측 길이로 정해지며 영 채우기로 늘지 않는다.

5.2.3순환 컨볼루션

DFT끼리의 곱 \(X[k]H[k]\)의 역DFT는 선형 컨볼루션이 아니라 순환 컨볼루션입니다. 두 신호를 주기 N으로 반복된 것으로 보므로, 선형 컨볼루션의 끝부분이 앞으로 감겨 들어옵니다.

선형 컨볼루션 조건: 길이 \(L_x\), \(L_h\)인 두 수열을 \(N \ge L_x + L_h - 1\)로 영 채우기한 뒤 DFT를 곱하면 순환 컨볼루션이 선형 컨볼루션과 같다.

예: 2.1절 예제의 \(\{1, 2, 3\} * \{1, 1\} = \{1, 3, 5, 3\}\). N = 3으로 하면 마지막 3이 맨 앞으로 감겨 \(\{4, 3, 5\}\)가 나오고, N = 4 이상이면 올바른 \(\{1, 3, 5, 3\}\)이 나옵니다. 긴 신호를 FFT로 필터링하는 방법(overlap-add)의 바탕입니다.

흔한 오해(1) "영 채우기로 해상도가 좋아진다": 곡선을 더 촘촘히 볼 뿐, 붙어 있는 두 봉우리를 갈라 주지는 못합니다. 해상도를 높이려면 더 오래 관측해야 합니다. (2) DFT 결과를 그대로 그리면 \(k > N/2\) 쪽이 높은 주파수처럼 보이지만 실제로는 음의 주파수입니다. (3) 빈 사이 주파수의 정현파는 한 빈에 모이지 않고 여러 빈으로 퍼집니다(누설, 8.2절).
요약
  1. \(X[k] = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}\). 빈 k ↔ \(f_k = kf_s/N\), 간격 \(f_s/N\).
  2. DFT = DTFT를 \(2\pi k/N\)에서 찍은 값 = 주기 반복 신호의 DTFS × N.
  3. 영 채우기는 표본 간격만 줄인다. DFT 곱 ↔ 순환 컨볼루션, \(N \ge L_x + L_h - 1\)이면 선형과 같다.

5.2.4연습문제

기본

  1. \(\{1, 0, -1, 0\}\)의 4점 DFT를 구하여라.
    답

    \(X[k] = 1 - e^{-j\pi k} = 1 - (-1)^k\): \(\{0, 2, 0, 2\}\).

  2. \(f_s = 8\) kHz, N = 1024이면 빈 간격과 빈 100의 주파수는?
    답

    7.8125 Hz, 781.25 Hz.

응용

  1. \(\{1, 2\}\)와 \(\{1, -1, 1\}\)을 DFT로 선형 컨볼루션하려면 N은 최소 얼마인가? 결과는?
    답

    N ≥ 4. \(\{1, 1, -1, 2\}\).

심화

  1. N점 DFT를 정의대로 계산하면 복소 곱셈이 몇 번 필요한가? N = 1024일 때 FFT(약 \(\frac N2\log_2N\)번)와 비교하여라.
    답

    \(N^2 = 1{,}048{,}576\)번 대 \(512 \times 10 = 5120\)번, 약 200배 차이(5.3절).
