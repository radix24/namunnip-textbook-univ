임펄스 응답과 컨볼루션

본문
이 절에서 배울 것
  • LTI 시스템의 출력이 입력과 임펄스 응답의 컨볼루션임을 유도한다.
  • 컨볼루션 합(이산)을 표로, 컨볼루션 적분(연속)을 "뒤집기-밀기-곱하기-넓이"로 계산한다.
  • 교환·결합·분배 법칙과 그 시스템적 의미(직렬·병렬 연결)를 안다.
먼저 알아야 할 것
  • 임펄스와 체 성질 (1.1절), 선형·시불변 (1.2절).

2.1.1임펄스 하나만 알면 된다: 컨볼루션 합의 유도

구하려는 것: LTI 시스템에 임의의 입력 \(x[n]\)을 넣었을 때의 출력. 이산시간에서 먼저 보입니다. 이산이 더 직관적이기 때문입니다.

임펄스 응답 \(h[n]\): 입력이 \(\delta[n]\)일 때의 출력.

1단계(입력 쪼개기). 어떤 수열이든 크기가 다른 임펄스를 줄 세운 것입니다: \(x[n] = \sum_k x[k]\,\delta[n - k]\). 예를 들어 \(x = \{2, 1\}\)(n = 0, 1)은 \(2\delta[n] + 1\delta[n - 1]\)입니다.

2단계(시불변). \(\delta[n - k]\)를 넣으면 \(h[n - k]\)가 나옵니다.

3단계(선형). 계수 \(x[k]\)를 곱하고 더한 입력에는 같은 계수로 곱하고 더한 출력이 나옵니다.

\[ y[n] = \sum_{k=-\infty}^{\infty}x[k]\,h[n - k] \equiv (x * h)[n]. \]

각 단계가 LTI의 어느 성질을 썼는지가 중요합니다. 선형만, 또는 시불변만 성립하면 이 식이 성립하지 않습니다. 연속시간에서는 체 성질 \(x(t) = \int x(\tau)\delta(t - \tau)d\tau\)로 같은 논리를 따라 컨볼루션 적분을 얻습니다.

\[ y(t) = \int_{-\infty}^{\infty}x(\tau)\,h(t - \tau)\,d\tau = (x * h)(t). \]

2.1.2컨볼루션 합을 표로 계산하기

예제 2.1.1

\(x[n] = \{1, 2, 3\}\)(n = 0, 1, 2), \(h[n] = \{1, 1\}\)(n = 0, 1)일 때 \(y = x * h\)를 구하여라.

풀이. 2.1.1의 생각대로, 각 입력 표본이 h를 자기 위치에 자기 크기로 한 번씩 내놓고 그것을 더합니다.

n = 0123
\(x[0]h[n]\) = 1·{1,1}11
\(x[1]h[n-1]\) = 2·{1,1}22
\(x[2]h[n-2]\) = 3·{1,1}33
y[n]1353

확인 두 가지: 길이는 \(3 + 2 - 1 = 4\), 합은 \((\sum x)(\sum h) = 6 \times 2 = 12 = 1 + 3 + 5 + 3\). 이 방법은 다항식 곱셈 \((1 + 2z + 3z^2)(1 + z)\)과 똑같습니다(7단원 Z-변환의 예고).

2.1.3컨볼루션 적분: 구간 나누기

연속시간에서는 같은 일을 적분으로 합니다. 이 절의 탐구 카드로 그림을 먼저 보고 오면 좋습니다. 핵심은 t의 범위에 따라 두 그래프가 겹치는 구간이 바뀌므로 경우를 나누는 것입니다.

예제 2.1.2

\(x(t) = u(t)\), \(h(t) = e^{-at}u(t)\) (\(a > 0\))일 때 \(y = x * h\)를 구하여라. (RC 회로의 계단 응답)

풀이. \(y(t) = \int x(\tau)h(t - \tau)d\tau\)에서 \(x(\tau) = u(\tau)\)는 \(\tau > 0\)에서만, \(h(t - \tau)\)는 \(t - \tau > 0\), 곧 \(\tau < t\)에서만 0이 아닙니다.

  • \(t < 0\): 두 조건 \(\tau > 0\), \(\tau < t\)를 동시에 만족하는 \(\tau\)가 없으므로 \(y = 0\).
  • \(t > 0\): 겹치는 구간은 \(0 < \tau < t\). \(y(t) = \int_0^t e^{-a(t - \tau)}d\tau = e^{-at}\cdot\frac{e^{at} - 1}{a} = \frac{1}{a}(1 - e^{-at})\).

따라서 \(y(t) = \frac1a(1 - e^{-at})u(t)\). 수치 확인: \(a = 1\)이면 \(y(1) = 1 - e^{-1} \approx 0.632\), \(y(\infty) = 1\). RC 회로(\(a = 1/RC\))의 계단 응답 \(1 - e^{-t/RC}\)와 같은 모양입니다(크기 \(1/a\)는 h의 넓이). 이 결과는 \(h = dy_{\text{step}}/dt\), 곧 임펄스 응답이 계단 응답의 미분이라는 일반 관계도 보여 줍니다.

2.1.4컨볼루션의 성질

교환 \(x * h = h * x\): 입력과 시스템의 역할을 바꿔도 출력이 같다. 계산할 때 더 간단한 쪽을 뒤집는다.

결합 \((x * h_1) * h_2 = x * (h_1 * h_2)\): 직렬로 이은 두 LTI 시스템은 임펄스 응답 \(h_1 * h_2\)인 시스템 하나와 같고, 순서를 바꿔도 된다.

분배 \(x * (h_1 + h_2) = x * h_1 + x * h_2\): 병렬 연결은 임펄스 응답을 더한 것.

항등 \(x * \delta = x\), \(x * \delta(t - t_0) = x(t - t_0)\): 임펄스는 컨볼루션의 1, 늦춘 임펄스는 지연기.

흔한 오해(1) 컨볼루션을 "두 신호를 곱한 것"으로 착각하는 경우가 있습니다. 곱은 각 시각끼리, 컨볼루션은 겹친 넓이입니다. (2) 적분 변수와 시간을 섞어 \(\int x(t)h(t - \tau)d\tau\)로 쓰는 실수가 흔합니다. 적분 안에서 t는 고정된 상수, 움직이는 것은 \(\tau\)입니다. (3) 경우를 나눌 때 경계(\(t = 0\), \(t = 1\) 같은 곳)를 빠뜨리지 않도록, 그래프를 그려 겹치기 시작·끝나는 순간을 먼저 찾으세요.
요약
  1. 입력을 임펄스의 합으로 쪼개고, 시불변과 선형을 차례로 쓰면 \(y = x * h\).
  2. 이산: 표(다항식 곱셈), 길이 \(N_x + N_h - 1\), 합의 곱 확인. 연속: 뒤집기-밀기-곱하기-넓이, 겹치는 구간별로 경우를 나눈다.
  3. 교환·결합(직렬)·분배(병렬), \(x * \delta = x\).

2.1.5연습문제

기본

  1. \(\{1, -1\} * \{1, 1, 1\}\)을 구하여라(둘 다 n = 0에서 시작).
    답

    \(\{1, 0, 0, -1\}\). 합 확인 \(0 \times 3 = 0\).

  2. \(x(t) * \delta(t - 3)\)은?
    답

    \(x(t - 3)\).

응용

  1. \(x(t) = h(t) = u(t) - u(t - 1)\)일 때 \(y = x * h\)를 구간별로 구하여라.
    답

    \(t < 0\): 0, \(0 \le t < 1\): t, \(1 \le t < 2\): \(2 - t\), \(t \ge 2\): 0. 높이 1, 밑변 0~2인 삼각형(탐구 카드의 직사각형 * 직사각형).

심화

  1. \(e^{-at}u(t) * e^{-bt}u(t)\)를 \(a \ne b\)와 \(a = b\)인 경우로 나눠 구하여라.
    답

    \(a \ne b\): \(\frac{e^{-at} - e^{-bt}}{b - a}u(t)\). \(a = b\): \(te^{-at}u(t)\)(앞 식에서 \(b \to a\) 극한과 같음).
