임펄스 응답과 컨볼루션

본문

계곡에서 손뼉을 한 번 치면 메아리가 몇 번에 걸쳐 작아지며 돌아온다. 손뼉 한 번에 대한 이 응답만 알고 있다면, 노래를 부를 때 계곡이 돌려줄 소리 전체도 미리 계산할 수 있을까? 임의의 입력을 넣었을 때의 출력을 임펄스 하나의 응답으로 구하는 방법은 무엇일까?

먼저 알아야 할 것임펄스와 체 성질(1.1절), 선형과 시불변(1.2절)을 쓴다.

2.1.1임펄스 하나만 알면 된다: 컨볼루션 합의 유도

구하려는 것은 LTI 시스템에 임의의 입력 \(x[n]\)을 넣었을 때의 출력이다. 이산시간이 더 직관적이므로 먼저 이산시간에서 보인다. 입력이 \(\delta[n]\)일 때의 출력을 임펄스 응답 \(h[n]\)이라 한다.

먼저 입력을 쪼갠다. 어떤 수열이든 크기가 다른 임펄스를 줄 세운 것이어서 \(x[n] = \sum_k x[k]\,\delta[n - k]\)로 쓸 수 있다. 예를 들어 \(x = \{2, 1\}\)(n = 0, 1)은 \(2\delta[n] + 1\delta[n - 1]\)이다. 다음으로 시불변성에 따라 \(\delta[n - k]\)를 넣으면 \(h[n - k]\)가 나온다. 끝으로 선형성에 따라 계수 \(x[k]\)를 곱하고 더한 입력에는 같은 계수로 곱하고 더한 출력이 나온다.

\[ y[n] = \sum_{k=-\infty}^{\infty}x[k]\,h[n - k] \equiv (x * h)[n]. \]

식의 각 단계가 LTI의 어느 성질을 썼는지가 중요하다. 선형만, 또는 시불변만 성립하면 이 식이 성립하지 않는다. 처음 질문의 답이 이 식이며, 연속시간에서도 체 성질 \(x(t) = \int x(\tau)\delta(t - \tau)d\tau\)로 같은 논리를 따라 컨볼루션 적분을 얻는다.

\[ y(t) = \int_{-\infty}^{\infty}x(\tau)\,h(t - \tau)\,d\tau = (x * h)(t). \]

2.1.2컨볼루션 합을 표로 계산하기

예제 2.1.1

\(x[n] = \{1, 2, 3\}\)(n = 0, 1, 2), \(h[n] = \{1, 1\}\)(n = 0, 1)일 때 \(y = x * h\)를 구하여라.

풀이. 2.1.1의 생각대로, 각 입력 표본이 h를 자기 위치에 자기 크기로 한 번씩 내놓고 그것을 더한다.

n = 0123
\(x[0]h[n]\) = 1·{1,1}11
\(x[1]h[n-1]\) = 2·{1,1}22
\(x[2]h[n-2]\) = 3·{1,1}33
y[n]1353

결과는 두 가지로 확인한다. 길이는 \(3 + 2 - 1 = 4\)이고, 합은 \((\sum x)(\sum h) = 6 \times 2 = 12 = 1 + 3 + 5 + 3\)이다(그림 1). 또 이 방법은 다항식 곱셈 \((1 + 2z + 3z^2)(1 + z)\)과 똑같으며, 7단원 Z-변환의 예고이다.

2.1.3컨볼루션 적분: 구간 나누기

연속시간에서는 같은 일을 적분으로 하며, 이 절의 탐구 카드로 그림을 먼저 보고 오면 좋다. 요점은 t의 범위에 따라 두 그래프가 겹치는 구간이 바뀌므로 경우를 나누는 것이다.

예제 2.1.2

\(x(t) = u(t)\), \(h(t) = e^{-at}u(t)\) (\(a > 0\))일 때 \(y = x * h\)를 구하여라. (RC 회로의 계단 응답)

풀이. \(y(t) = \int x(\tau)h(t - \tau)d\tau\)에서 \(x(\tau) = u(\tau)\)는 \(\tau > 0\)에서만, \(h(t - \tau)\)는 \(t - \tau > 0\), 곧 \(\tau < t\)에서만 0이 아니다. 그래서 \(t < 0\)이면 두 조건을 동시에 만족하는 \(\tau\)가 없어 \(y = 0\)이다. 반면 \(t > 0\)이면 겹치는 구간은 \(0 < \tau < t\)이므로 \(y(t) = \int_0^t e^{-a(t - \tau)}d\tau = e^{-at}\cdot\frac{e^{at} - 1}{a} = \frac{1}{a}(1 - e^{-at})\)이다.

따라서 \(y(t) = \frac1a(1 - e^{-at})u(t)\)이다. 수치로 확인하면 \(a = 1\)일 때 \(y(1) = 1 - e^{-1} \approx 0.632\), \(y(\infty) = 1\)이다. 이것은 RC 회로(\(a = 1/RC\))의 계단 응답 \(1 - e^{-t/RC}\)와 같은 모양이며, 크기 \(1/a\)는 h의 넓이이다. 또 이 결과는 임펄스 응답이 계단 응답의 미분, 곧 \(h = dy_{\text{step}}/dt\)라는 일반 관계도 보여 준다.

2.1.4컨볼루션의 성질

컨볼루션은 교환 법칙 \(x * h = h * x\)를 만족하므로 입력과 시스템의 역할을 바꿔도 출력이 같고, 계산할 때는 더 간단한 쪽을 뒤집는다. 또 결합 법칙 \((x * h_1) * h_2 = x * (h_1 * h_2)\)에 따라 직렬로 이은 두 LTI 시스템은 임펄스 응답 \(h_1 * h_2\)인 시스템 하나와 같고 순서를 바꿔도 된다. 분배 법칙 \(x * (h_1 + h_2) = x * h_1 + x * h_2\)는 병렬 연결이 임펄스 응답을 더한 것임을 뜻한다. 끝으로 \(x * \delta = x\), \(x * \delta(t - t_0) = x(t - t_0)\)이므로 임펄스는 컨볼루션의 1이고, 늦춘 임펄스는 지연기이다.

흔한 오해컨볼루션을 두 신호를 곱한 것으로 착각하는 경우가 있다. 곱은 각 시각끼리 하는 것이고, 컨볼루션은 뒤집어 민 두 그래프가 겹친 넓이이다. 또 적분 변수와 시간을 섞어 \(\int x(t)h(t - \tau)d\tau\)로 쓰는 실수가 흔한데, 적분 안에서 t는 고정된 상수이고 움직이는 것은 \(\tau\)이다. 경우를 나눌 때는 경계(\(t = 0\), \(t = 1\) 같은 곳)를 빠뜨리지 않도록 그래프를 그려 겹치기 시작하고 끝나는 순간을 먼저 찾자.
마무리

입력을 임펄스의 합으로 쪼개고 시불변성과 선형성을 차례로 쓰면 LTI 시스템의 출력은 \(y = x * h\)이다. 이산 컨볼루션은 표, 곧 다항식 곱셈으로 계산하며 길이 \(N_x + N_h - 1\)과 합의 곱으로 확인한다. 연속 컨볼루션은 뒤집기, 밀기, 곱하기, 넓이 구하기의 순서로 겹치는 구간별로 경우를 나누어 계산한다. 컨볼루션은 교환, 결합(직렬 연결), 분배(병렬 연결) 법칙을 만족하고 \(x * \delta = x\)이다.

2.1.5연습문제

기본

  1. \(\{1, -1\} * \{1, 1, 1\}\)을 구하여라(둘 다 n = 0에서 시작).
    답

    \(\{1, 0, 0, -1\}\)이다. 합을 확인하면 \(0 \times 3 = 0\)이다.

  2. \(x(t) * \delta(t - 3)\)은?
    답

    \(x(t - 3)\)이다.

응용

  1. \(x(t) = h(t) = u(t) - u(t - 1)\)일 때 \(y = x * h\)를 구간별로 구하여라.
    답

    \(t < 0\)이면 0, \(0 \le t < 1\)이면 t, \(1 \le t < 2\)이면 \(2 - t\), \(t \ge 2\)이면 0이다. 높이 1, 밑변이 0에서 2인 삼각형으로, 탐구 카드의 직사각형과 직사각형의 컨볼루션이다.

심화

  1. \(e^{-at}u(t) * e^{-bt}u(t)\)를 \(a \ne b\)와 \(a = b\)인 경우로 나눠 구하여라.
    답

    \(a \ne b\)이면 \(\frac{e^{-at} - e^{-bt}}{b - a}u(t)\)이다. \(a = b\)이면 \(te^{-at}u(t)\)로, 앞 식에서 \(b \to a\) 극한과 같다.
