Fourier 변환과 기본 변환쌍

본문

Fourier 급수는 같은 모양이 끝없이 되풀이되는 주기 신호만 쪼갤 수 있었다. 그런데 손뼉 한 번, 데이터 펄스 하나처럼 한 번만 일어나는 신호에도 주파수 성분이 있을까? 있다면 펄스를 짧게 만들수록 스펙트럼은 어떻게 바뀔까?

먼저 알아야 할 것Fourier 급수(3.1절), 주파수 응답(3.2절), 수학 쪽의 Fourier 적분(공통9 1.1절)을 쓴다.

4.1.1급수에서 변환으로

Fourier 급수는 주기 신호에만 쓸 수 있다. 펄스 하나나 음성 한 마디처럼 주기가 없는 신호를 다루려면, 그것을 주기가 무한히 긴 주기 신호로 보면 된다.

구하려는 것은 주기 T → ∞일 때 급수가 무엇이 되는가이다. 3.1절 사각파에서 \(T a_k = \frac{2\sin(k\omega_0T_1)}{k\omega_0}\)였다. \(\omega = k\omega_0\)로 쓰면 \(Ta_k = \frac{2\sin(\omega T_1)}{\omega}\)로, T와 무관한 곡선 위의 점들이다. 그래서 T가 커지면 점 사이 간격 \(\omega_0 = 2\pi/T\)가 좁아져 곡선 전체를 촘촘히 채운다. 이 포락선 곡선이 Fourier 변환이고, 급수의 합은 적분이 된다.

\[ X(j\omega) = \int_{-\infty}^{\infty}x(t)\,e^{-j\omega t}\,dt, \qquad x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)\,e^{j\omega t}\,d\omega. \]

식의 Fourier 변환 \(X(j\omega)\)는 신호에 각주파수 \(\omega\)의 성분이 밀도로 얼마나 들어 있는가를 나타내며, 단위는 [x의 단위 × 초]이다. 처음 질문의 첫째 답이 이것이다. 역변환은 모든 주파수의 복소 지수를 \(X(j\omega)\,d\omega/2\pi\)의 비율로 더해 신호를 되살린다. 그리고 \(|X(j\omega)|\)(크기)와 \(\angle X(j\omega)\)(위상)를 \(\omega\)의 함수로 그린 것을 스펙트럼이라 한다.

3.2절의 \(H(j\omega)\)는 임펄스 응답 h의 Fourier 변환이었다. 또 주파수를 Hz로 쓰고 싶으면 \(\omega = 2\pi f\)로 바꾸어, \(2\pi\)가 사라진 대칭형 \(X(f) = \int x e^{-j2\pi ft}dt\), \(x = \int Xe^{j2\pi ft}df\)를 쓴다. 교재마다 쓰는 형태가 달라 계수 \(2\pi\)가 어디 붙는지 늘 확인해야 한다.

4.1.2기본 변환쌍 유도

예제 4.1.1 (직사각 펄스)

\(|t| < T_1\)에서 1, 그 밖에서 0인 펄스의 변환을 구하여라.

풀이. 적분 구간은 펄스가 있는 곳뿐이므로 \(X(j\omega) = \int_{-T_1}^{T_1}e^{-j\omega t}dt = \frac{e^{j\omega T_1} - e^{-j\omega T_1}}{j\omega} = \frac{2\sin(\omega T_1)}{\omega}\)이다. \(\omega = 0\)에서 값은 극한으로 펄스의 넓이 \(2T_1\)이고, 첫 영점은 \(\omega = \pi/T_1\)이다. 예를 들어 \(T_1 = 0.5\)(폭 1)이면 \(X(0) = 1\), 첫 영점은 \(\omega = 2\pi\), 곧 \(f = 1\) Hz이다. 그리고 폭을 두 배로 하면 첫 영점은 절반의 주파수로 온다(그림 1).

이 결과는 sinc 함수 \(\text{sinc}(u) = \frac{\sin\pi u}{\pi u}\)로 \(X = 2T_1\,\text{sinc}(\omega T_1/\pi)\)라고도 쓴다. 다만 교재마다 sinc에 \(\pi\)를 넣는 방식이 다르므로 정의를 먼저 확인해야 한다.

예제 4.1.2 (지수 신호)

\(x(t) = e^{-at}u(t)\), \(a > 0\)의 변환과 크기, 위상을 구하여라.

풀이. \(a > 0\)이라 위끝에서 0이 되므로 \(X = \int_0^\infty e^{-(a + j\omega)t}dt = \frac{1}{a + j\omega}\)이다. 크기는 \(|X| = \frac{1}{\sqrt{a^2 + \omega^2}}\), 위상은 \(\angle X = -\arctan(\omega/a)\)이며, \(\omega = a\)에서 크기가 최댓값 \(1/a\)의 \(1/\sqrt2\)이고 위상이 −45°이다. 즉 RC 회로와 같은 꼴이다. 반면 \(a \le 0\)이면 적분이 발산해 Fourier 변환이 없으며, 7단원 Laplace 변환이 이 경우를 다룬다.

임펄스는 체 성질로 \(\delta(t) \leftrightarrow 1\)이므로 모든 주파수를 같은 세기로 담는다. 거꾸로 상수 1의 변환은 일반 적분으로는 발산한다. 그러나 역변환 식에 \(X = 2\pi\delta(\omega)\)를 넣으면 \(\frac{1}{2\pi}\cdot2\pi = 1\)이 나오므로 \(1 \leftrightarrow 2\pi\delta(\omega)\)로 받아들인다. 같은 방법으로 다음을 얻는다.

\[ e^{j\omega_0t} \leftrightarrow 2\pi\delta(\omega - \omega_0), \qquad \cos\omega_0t \leftrightarrow \pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]. \]

식에 따라 주기 신호의 변환은 Fourier 급수 계수 자리에 \(2\pi a_k\) 크기의 임펄스를 놓은 것, 곧 \(X(j\omega) = \sum_k2\pi a_k\,\delta(\omega - k\omega_0)\)이다. 이로써 급수와 변환이 하나의 틀로 묶였다.

4.1.3시간 폭과 주파수 폭

예제 4.1.1에서 본 것처럼, 신호가 시간에서 좁을수록 스펙트럼은 넓게 퍼진다. 척도 성질 \(x(at) \leftrightarrow \frac{1}{|a|}X(j\omega/a)\)가 이것을 정확히 말해 주며, 처음 질문의 둘째 답이 이것이다. 극단적인 두 경우가 시간 폭이 0이고 스펙트럼이 평평한 임펄스와, 시간 폭이 무한하고 스펙트럼이 한 점인 상수이다. 그래서 빠른 데이터 펄스를 보내려면 넓은 대역폭이 필요하다.

흔한 오해\(X(j\omega)\)의 값을 그 주파수의 진폭으로 읽으면 안 된다. 밀도라서 단위가 [V·s]이고, 실제 성분은 좁은 주파수 구간에 대해 적분해야 나온다. 또 \(1 \leftrightarrow 2\pi\delta(\omega)\)의 \(2\pi\)를 빠뜨리는 실수가 많은데, f를 쓰는 형태에서는 \(1 \leftrightarrow \delta(f)\)라 \(2\pi\)가 없다. 끝으로 \(e^{at}u(t)\) (\(a > 0\))의 변환을 \(\frac{1}{-a + j\omega}\)로 쓰면 안 되며, 이 경우 적분이 발산해 변환이 존재하지 않는다.
마무리

Fourier 변환 \(X(j\omega) = \int x\,e^{-j\omega t}dt\)와 역변환 \(x = \frac1{2\pi}\int X\,e^{j\omega t}d\omega\)는 급수에서 주기를 무한히 늘린 극한으로 얻는다. 기본 변환쌍은 직사각 펄스와 \(2\sin(\omega T_1)/\omega\), \(e^{-at}u(t)\)와 \(1/(a + j\omega)\), \(\delta\)와 1, 1과 \(2\pi\delta(\omega)\), \(\cos\omega_0t\)와 \(\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]\)이다. 척도 성질에 따라 시간에서 좁은 신호는 주파수에서 넓다.

4.1.4연습문제

기본

  1. \(\delta(t - 3)\)의 변환과 그 크기, 위상은?
    답

    \(e^{-j3\omega}\)이며 크기는 1, 위상은 \(-3\omega\)이다.

  2. \(e^{-2|t|}\)의 변환을 구하여라.
    답

    \(\frac{1}{2 + j\omega} + \frac{1}{2 - j\omega} = \frac{4}{4 + \omega^2}\)로, 실수이고 짝함수이다.

응용

  1. \(X(j\omega) = 1\) (\(|\omega| < W\)), 0 (그 밖)의 역변환을 구하여라.
    답

    \(x(t) = \frac{1}{2\pi}\int_{-W}^{W}e^{j\omega t}d\omega = \frac{\sin Wt}{\pi t}\)이다. 이것은 이상 저역 통과 필터의 임펄스 응답으로 비인과이다(2.2절 연습 4).

심화

  1. \(te^{-at}u(t)\)의 변환을 \(\frac{d}{d\omega}X(j\omega) \leftrightarrow -jt\,x(t)\)로 구하여라.
    답

    \(\frac{d}{d\omega}\frac{1}{a + j\omega} = \frac{-j}{(a + j\omega)^2}\)이므로 \(tx \leftrightarrow j\frac{dX}{d\omega} = \frac{1}{(a + j\omega)^2}\)이다.
