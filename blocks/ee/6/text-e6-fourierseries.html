주기 신호의 Fourier 급수

본문

신시사이저는 사인파 몇 개를 겹쳐 바이올린 소리도, 각진 사각파 소리도 만든다. 날카로운 모서리를 가진 사각파가 정말 매끈한 사인파들의 합일까? 그렇다면 각 사인파를 얼마만큼씩 섞어야 하고, 몇 개면 충분할까?

먼저 알아야 할 것실수형 Fourier 급수(공통8 6.1절), 오일러 공식(공통9 3.1절)을 쓴다. 회로에서 비정현 입력을 급수로 나눈 경험(전전3 9.3절)이 있으면 좋다.

3.1.1왜 복소 지수로 쪼개는가

2단원에서는 입력을 임펄스로 쪼갰다. 이 단원은 입력을 복소 지수 \(e^{j\omega t}\)로 쪼개는데, 그 이유는 3.2절에서 증명할 사실 때문이다. LTI 시스템은 \(e^{j\omega t}\)를 넣으면 같은 \(e^{j\omega t}\)에 복소수 \(H(j\omega)\)를 곱한 것을 내놓는다. 그러면 입력을 복소 지수로 쪼개 놓기만 하면 출력은 각 성분에 곱셈 하나씩만 하면 되므로, 컨볼루션 적분이 곱셈으로 바뀐다.

3.1.2급수와 계수 공식

기본 주기를 \(T\), 기본 각주파수를 \(\omega_0 = 2\pi/T\)라 하자. k가 정수인 \(e^{jk\omega_0t}\)를 고조파라 하며, 모두 주기 T로 반복한다. k = ±1이 기본파이고 |k| = 2, 3, …이 2, 3, … 고조파이다. 각 고조파의 복소 진폭을 Fourier 급수 계수 \(a_k\)라 하며, 크기는 그 주파수 성분의 세기, 편각은 위상이다.

\[ x(t) = \sum_{k=-\infty}^{\infty}a_k\,e^{jk\omega_0t}, \qquad a_k = \frac1T\int_T x(t)\,e^{-jk\omega_0t}\,dt. \]

계수 공식은 직교성에서 나온다. 구하려는 것은 \(a_k\) 하나이므로, 급수 양변에 \(e^{-jn\omega_0t}\)를 곱하고 한 주기 적분한다. 오른쪽의 각 항은 \(\int_Te^{j(k - n)\omega_0t}dt\)인데, \(k \ne n\)이면 정수 바퀴를 도는 복소 지수의 적분이라 0이고 \(k = n\)이면 T이다. 그래서 \(a_n\) 하나만 살아남아 \(\int_Tx\,e^{-jn\omega_0t}dt = T\,a_n\)이 된다. 처음 질문의 "얼마만큼씩"에 대한 답이 이 공식이다.

실수 신호이면 \(a_{-k} = a_k^*\)이므로, 짝을 묶어 \(x(t) = a_0 + \sum_{k\ge1}2|a_k|\cos(k\omega_0t + \angle a_k)\)로도 쓴다. 공통8의 실수형 \(a_0 + \sum(a_n\cos n\omega_0t + b_n\sin n\omega_0t)\)와 비교하면, 이 절의 복소 계수는 실수형 계수로 \(a_k = (a_n - jb_n)/2\) (k = n ≥ 1)이다. 같은 글자 a를 두 뜻으로 쓰니 주의하자.

예제 3.1.1

주기 T, 한 주기 안에서 \(|t| < T_1\)이면 1, 나머지는 0인 사각파의 계수를 구하고, \(T_1 = T/4\)(듀티 50%)일 때 \(a_0, a_1, a_2, a_3\)을 수치로 적어라.

풀이. \(a_0\)는 평균이므로 \(a_0 = \frac{2T_1}{T}\)이다. \(k \ne 0\)이면 다음과 같다.

\[ a_k = \frac1T\int_{-T_1}^{T_1}e^{-jk\omega_0t}dt = \frac{1}{T}\cdot\frac{e^{jk\omega_0T_1} - e^{-jk\omega_0T_1}}{jk\omega_0} = \frac{\sin(k\omega_0T_1)}{k\pi}. \]

식의 마지막 단계에서 \(\frac{e^{j\theta} - e^{-j\theta}}{2j} = \sin\theta\)와 \(T\omega_0 = 2\pi\)를 썼다. \(T_1 = T/4\)이면 \(\omega_0T_1 = \pi/2\)이므로 \(a_k = \frac{\sin(k\pi/2)}{k\pi}\)이고, \(a_0 = 0.5\), \(a_1 = 1/\pi \approx 0.318\), \(a_2 = 0\), \(a_3 = -1/(3\pi) \approx -0.106\)이다. 즉 짝수 고조파가 모두 사라지고 홀수 고조파가 \(1/k\)로 줄어든다(그림 1). 신호가 짝함수라 계수가 모두 실수라는 점도 보자.

3.1.3Parseval 관계와 수렴

평균 전력은 각 고조파 전력의 합이어서 \(\frac1T\int_T|x|^2dt = \sum_k|a_k|^2\)이며, 이를 Parseval 관계라 한다. 위 사각파의 평균 전력은 \(0.5\)이다. 직류 \(a_0^2 = 0.25\)와 기본파 \(2|a_1|^2 \approx 0.203\)을 더하면 이미 \(0.453\), 약 91%이다. 남은 9%가 날카로운 모서리를 만드는 고조파들이며, 처음 질문의 "몇 개면 충분한가"는 이 비율로 판단한다.

그러면 급수는 언제 원래 신호로 수렴할까? 한 주기에서 절대 적분 가능하고 극대, 극소, 불연속점이 유한 개이면(Dirichlet 조건) 급수가 연속점에서 \(x(t)\)로, 불연속점에서 좌우 극한의 평균으로 수렴한다. 다만 불연속점 근처에서는 부분합이 뛰는 크기의 약 9%만큼 넘쳐 오르고, 항을 늘려도 넘침의 높이는 줄지 않고 폭만 좁아진다. 이것이 Gibbs 현상이며, 이 절의 탐구 카드에서 항 수를 늘리며 직접 확인할 수 있다.

3.1.4이산시간 Fourier 급수

주기 N인 수열 \(x[n]\)에도 같은 생각이 통한다. 차이는 \(e^{jk(2\pi/N)n}\)이 k에 대해 주기 N이라 서로 다른 고조파가 N개뿐이라는 점이다.

\[ x[n] = \sum_{k=0}^{N-1}a_k\,e^{jk(2\pi/N)n}, \qquad a_k = \frac1N\sum_{n=0}^{N-1}x[n]\,e^{-jk(2\pi/N)n}. \]

식은 무한 급수가 아니라 유한 합이므로 수렴 문제가 없고, 컴퓨터로 정확히 계산된다. 5단원의 DFT가 바로 이 식이며 1/N의 위치만 다르다. 예를 들어 \(x = \{1, 0, 0, 0\}\)(N = 4)이면 모든 \(a_k = 1/4\)이다.

흔한 오해음의 주파수 \(k < 0\)를 물리적으로 없는 것으로 버리면 안 된다. 실수 신호는 \(\pm k\) 한 쌍이 합쳐 코사인 하나를 이루므로, 진폭 A인 코사인의 계수는 \(A/2\) 두 개이다. 그래서 높이 1 사각파의 기본파 진폭은 \(a_1\)이 아니라 \(2|a_1| = 2/\pi \approx 0.64\)이다. 또 Gibbs 넘침은 계산 실수가 아니라, 불연속 신호를 연속 함수의 유한 합으로 나타낼 때 생기는 본질적 현상이다.
마무리

주기 신호는 \(x = \sum a_ke^{jk\omega_0t}\)로 쪼개지고, 계수 \(a_k = \frac1T\int_Tx\,e^{-jk\omega_0t}dt\)는 고조파의 직교성으로 유도된다. 듀티 50% 사각파는 \(a_k = \sin(k\pi/2)/(k\pi)\)로 홀수 고조파만 \(1/k\)로 줄어들며, 실수 신호는 \(a_{-k} = a_k^*\)이다. 평균 전력은 \(\sum|a_k|^2\)(Parseval)이고, 불연속점에서는 약 9%의 Gibbs 넘침이 남는다. 이산시간 Fourier 급수는 N개 계수의 유한 합으로 DFT로 이어진다.

3.1.5연습문제

기본

  1. \(x(t) = 3 + 4\cos(2t) + 2\sin(6t)\)의 \(\omega_0\)와 0이 아닌 \(a_k\)를 모두 적어라.
    답

    \(\omega_0 = 2\)이다. \(a_0 = 3\), \(a_{\pm1} = 2\), \(a_3 = 1/j = -j\), \(a_{-3} = j\)이다.

  2. 위 신호의 평균 전력을 Parseval로 구하여라.
    답

    \(9 + 2\cdot4 + 2\cdot1 = 19\)이다. \(3^2 + 4^2/2 + 2^2/2 = 19\)로 확인된다.

응용

  1. 주기 \(2\pi\), 한 주기 \(-\pi < t < \pi\)에서 \(x = t\)인 톱니파의 \(a_k\)를 구하여라.
    힌트

    홀함수라 \(a_0 = 0\)이다. 부분적분을 쓴다.

    답

    \(a_k = \frac{j(-1)^k}{k}\) (\(k \ne 0\))이다. 불연속이 있으면 크기가 \(1/k\)로 줄어든다.

심화

  1. 주기 2인 삼각파(사각파를 적분한 모양)의 계수가 \(1/k^2\)로 줄어드는 이유를, 미분과 계수의 관계 \(\frac{dx}{dt} \leftrightarrow jk\omega_0a_k\)로 설명하여라.
    답

    삼각파를 미분하면 계수가 \(1/k\) 정도인 사각파이므로, 삼각파 계수는 사각파 계수를 \(jk\omega_0\)로 나눈 \(1/k^2\) 정도이다. 신호가 매끄러울수록 계수가 빨리 줄어든다.
