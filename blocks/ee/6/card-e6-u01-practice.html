신호와 시스템의 기초 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(x(t) = u(t) - u(t - 3)\)일 때 \(y(t) = x(-t/2 + 1)\)이 1인 구간을 구하세요. [01-01]

    힌트 1

    x가 1인 구간은 \(0 \le \tau < 3\)입니다.

    힌트 2

    \(0 \le -t/2 + 1 < 3\)을 t에 대해 풀 때 음수로 나누면 부등호가 바뀝니다.

    풀이

    \(-1 \le -t/2 < 2\) → \(-4 < t \le 2\). 특징점 대입으로 확인: \(\tau = 0 \to t = (0 - 1)/(-1/2) = 2\), \(\tau = 3 \to t = -4\). 폭 3이 6으로 늘고 반전되었습니다.

  2. 계산\(\int_{-\infty}^{\infty}(t^2 + 1)\,\delta(3 - t)\,dt\)와 \(\int_{-2}^{1}e^{t}\delta(t - 2)\,dt\)를 구하세요. [01-01]

    힌트 1

    \(\delta(3 - t) = \delta(t - 3)\)(짝함수).

    힌트 2

    임펄스가 적분 구간 안에 있는지 보세요.

    풀이

    첫째: \(3^2 + 1 = 10\). 둘째: 임펄스 위치 \(t = 2\)가 구간 \([-2, 1]\) 밖이므로 0.

  3. 개념\(x[n] = \cos(3\pi n/5) + \sin(\pi n/4)\)의 기본 주기를 구하세요. [01-01]

    힌트 1

    각 항의 주기: \(2\pi m/\omega_0\)가 정수가 되는 가장 작은 값.

    힌트 2

    첫째 항 \(\omega_0/2\pi = 3/10\), 둘째 항 \(1/8\).

    풀이

    첫째 항 주기 10, 둘째 항 주기 8. 합의 주기는 최소공배수 40.

  4. 판단\(y(t) = x(t)\,u(t)\)에 대해 학생이 "u(t)가 시간에 따라 바뀌니 시변이고, 곱이 있으니 비선형"이라고 했다. 두 판단을 각각 평가하세요. [01-02]

    힌트 1

    선형은 입력에 대한 성질입니다. u(t)는 입력이 아닙니다.

    힌트 2

    시변 판정은 \(x(t - t_0)u(t)\)와 \(x(t - t_0)u(t - t_0)\)를 비교.

    풀이

    시변: 맞습니다(두 식이 다름, 예: \(x = 1\)이면 \(u(t)\)와 \(u(t - t_0)\)). 비선형: 틀렸습니다. \((ax_1 + bx_2)u = a\,x_1u + b\,x_2u\)이므로 선형입니다. 입력끼리의 곱이 아니라 정해진 함수와의 곱은 선형입니다.

  5. 계산\(y[n] = \sum_{k=n-2}^{n+2}x[k]\)의 무기억, 인과, 안정, 시불변, 선형을 판정하세요. [01-02]

    힌트 1

    합에 들어가는 입력의 시각은 n − 2부터 n + 2까지.

    힌트 2

    \(|y|\)는 많아야 몇 B?

    풀이

    기억 있음, 비인과(\(x[n+1], x[n+2]\) 사용), 안정(\(|y| \le 5B\)), 시불변(합의 범위가 n과 함께 움직임), 선형.

  6. 도전어떤 시스템에 \(x_1 = u(t)\)를 넣으면 \(y_1 = (1 - e^{-t})u(t)\), \(x_2 = u(t - 1)\)를 넣으면 \(y_2 = (1 - e^{-(t-1)})u(t-1)\)이 나왔다. 이 시스템이 LTI라고 가정할 때 \(x = u(t) - u(t - 1)\)의 출력을 구하고, 위 두 관측만으로 LTI임을 증명할 수 없는 이유를 설명하세요. [01-02]

    힌트 1

    LTI이면 선형으로 \(y = y_1 - y_2\).

    힌트 2

    "성립"을 보이려면 모든 입력에 대해 보여야 합니다.

    풀이

    \(y = (1 - e^{-t})u(t) - (1 - e^{-(t-1)})u(t - 1)\): \(0 \le t < 1\)에서 \(1 - e^{-t}\), \(t \ge 1\)에서 \((e - 1)e^{-t}\). 두 관측은 시불변과 맞지만, 다른 입력(예: 크기 2인 계단)에서 무슨 일이 일어나는지 알려 주지 않으므로 성질을 증명하지 못합니다. 관측은 반례(부정)에는 충분하지만 증명에는 부족합니다.
