부분분수 전개로 역변환하기

본문
이 절에서 배울 것
  • 유리 함수를 1차 항들의 합으로 쪼개는 부분분수 전개를 하고, 계수를 덮개 방법(cover-up)으로 구한다.
  • 각 항을 ROC에 맞는 기본쌍으로 역변환한다(Laplace와 Z 모두).
  • 중근, 복소 공액 극점, 분자 차수가 높은 경우를 처리한다.
먼저 알아야 할 것
  • Laplace 변환의 ROC (7.1절), Z-변환 (7.2절), 공통8의 부분분수 역변환 (공통8 5.1절).

7.3.1왜 쪼개는가

시스템 출력은 \(Y = XH\)처럼 곱으로 얻어지고, 결과는 대개 다항식의 비입니다. 변환표에는 \(\frac{1}{s + a}\), \(\frac{1}{1 - az^{-1}}\) 같은 1차 항만 있습니다. 그래서 복잡한 유리 함수를 1차 항의 합으로 쪼개고, 각 항을 표에서 찾아 더합니다(선형성).

진분수: 분자의 차수가 분모보다 낮은 유리 함수. 아니면 먼저 다항식 나눗셈으로 몫을 떼어 낸다.

덮개 방법: 단순 극점 \(p_i\)의 계수 \(A_i = (s - p_i)X(s)\big|_{s = p_i}\). 분모에서 그 인수를 "가리고" 나머지에 \(s = p_i\)를 넣는다.

7.3.2Laplace 역변환

예제 7.3.1

\(X(s) = \frac{s + 5}{(s + 1)(s + 3)}\), ROC \(\text{Re}(s) > -1\)의 역변환을 구하여라.

풀이. 진분수이므로 \(\frac{A}{s + 1} + \frac{B}{s + 3}\)로 둡니다.

  • \(A\): \((s + 1)\)을 가리고 \(s = -1\): \(\frac{-1 + 5}{-1 + 3} = 2\).
  • \(B\): \((s + 3)\)을 가리고 \(s = -3\): \(\frac{-3 + 5}{-3 + 1} = -1\).

ROC가 두 극점(−1, −3)의 오른쪽이므로 두 항 모두 오른쪽 신호로 역변환합니다: \(x(t) = (2e^{-t} - e^{-3t})u(t)\). 검산: \(t = 0^+\)에서 \(x = 1\)이고, 초기값 정리 \(\lim_{s\to\infty}sX(s) = 1\)과 맞습니다.

ROC가 극점 사이일 때. 같은 X에 ROC \(-3 < \text{Re}(s) < -1\)이면, 극점 −3의 항은 ROC가 그 오른쪽이므로 오른쪽 신호 \(-e^{-3t}u(t)\), 극점 −1의 항은 ROC가 그 왼쪽이므로 왼쪽 신호 \(-2e^{-t}u(-t)\)입니다. 극점마다 ROC가 어느 쪽인지를 따로 봅니다.

7.3.3중근과 복소 극점

중근: \((s - p)^2\)이 있으면 \(\frac{A_1}{s - p} + \frac{A_2}{(s - p)^2}\). \(A_2\)는 덮개 방법, \(A_1\)은 \((s - p)^2X\)를 미분해 \(s = p\)를 넣는다. 역변환 \(\frac{1}{(s + a)^2} \leftrightarrow te^{-at}u(t)\).

복소 공액 극점: 실수 신호이면 계수도 공액 쌍이다. 두 항을 합쳐 \(2|A|e^{\sigma t}\cos(\omega t + \angle A)\)로 쓰거나, 분모를 완전제곱 \((s + \alpha)^2 + \beta^2\)으로 만들어 \(e^{-\alpha t}\cos\beta t\), \(e^{-\alpha t}\sin\beta t\) 쌍을 쓴다.

7.3.4Z 역변환

Z-변환은 \(z^{-1}\)의 식으로 두고 \(\frac{A}{1 - pz^{-1}}\) 꼴로 쪼개면 기본쌍 \(p^nu[n]\)을 바로 씁니다. 덮개 방법은 \(A_i = (1 - p_iz^{-1})X(z)\big|_{z = p_i}\)입니다.

예제 7.3.2

\(H(z) = \frac{1}{(1 - 0.5z^{-1})(1 - 0.25z^{-1})}\), 인과 시스템의 임펄스 응답을 구하여라.

풀이. \(A = \frac{1}{1 - 0.25/0.5} = \frac{1}{0.5} = 2\) (\(z = 0.5\)에서 \(z^{-1} = 2\)), \(B = \frac{1}{1 - 0.5/0.25} = \frac{1}{-1} = -1\). 인과이므로 \(h[n] = (2(0.5)^n - (0.25)^n)u[n]\). 2.3절 연습 3(특성근으로 푼 같은 시스템)의 답과 같습니다. 검산: \(h[0] = 1\), \(h[1] = 1 - 0.25 = 0.75\).

짧은 수열이 필요할 때는 긴 나눗셈(분자를 분모로 \(z^{-1}\)의 거듭제곱 순서로 나눔)으로 \(h[0], h[1], \dots\)를 차례로 얻을 수도 있습니다. 2.3절의 되풀이 계산과 같은 일입니다.

흔한 오해(1) 분자 차수가 분모 이상인데 바로 쪼개면 계수가 맞지 않습니다. 먼저 나눗셈으로 몫(임펄스와 그 미분, Z에서는 유한 수열)을 떼어 내세요. (2) 덮개 방법은 단순 극점에만 씁니다. 중근의 낮은 차수 계수는 미분이 필요합니다. (3) ROC를 보지 않고 모든 항을 \(u(t)\)로 역변환하는 실수가 흔합니다. ROC가 극점의 왼쪽이면 그 항은 왼쪽 신호입니다.
요약
  1. 진분수로 만들고 → 1차 항으로 쪼개고(덮개 방법) → 표로 역변환.
  2. 극점마다 ROC가 오른쪽이면 오른쪽 신호(\(u(t)\), \(u[n]\)), 왼쪽이면 왼쪽 신호.
  3. 중근은 \(te^{-at}\), \(np^n\) 꼴, 복소 쌍은 감쇠 코사인으로 합친다.

7.3.5연습문제

기본

  1. \(\frac{3}{s(s + 3)}\), ROC \(\text{Re}(s) > 0\)의 역변환은?
    답

    \(\frac1s - \frac{1}{s + 3}\) → \((1 - e^{-3t})u(t)\).

응용

  1. \(\frac{s + 2}{(s + 1)^2}\), 인과 신호의 역변환을 구하여라.
    답

    \(\frac{1}{s + 1} + \frac{1}{(s + 1)^2}\) → \((e^{-t} + te^{-t})u(t)\).

  2. \(\frac{s + 1}{s^2 + 2s + 5}\), 인과 신호의 역변환은?
    답

    \((s + 1)^2 + 4\)이므로 \(e^{-t}\cos2t\,u(t)\).

심화

  1. \(X(z) = \frac{1}{1 - 2.5z^{-1} + z^{-2}}\)의 ROC가 \(0.5 < |z| < 2\)일 때 \(x[n]\)을 구하여라.
    답

    극점 2와 0.5. \(\frac{1}{(1 - 2z^{-1})(1 - 0.5z^{-1})}\): \(A = \frac{1}{1 - 0.25} = \frac43\)(극점 2), \(B = \frac{1}{1 - 4} = -\frac13\)(극점 0.5). ROC가 0.5의 바깥이라 \(-\frac13(0.5)^nu[n]\), 2의 안쪽이라 \(-\frac43 2^nu[-n-1]\). \(x[n] = -\frac13(0.5)^nu[n] - \frac43 2^nu[-n-1]\). ROC가 단위원을 포함하므로 안정(비인과).
