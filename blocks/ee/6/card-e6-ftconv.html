이상 저역 통과 필터를 지난 펄스

예제 · 곱셈으로 출력의 스펙트럼과 에너지 구하기

먼저 예측

폭 1 s 직사각 펄스를 차단 주파수 1 Hz(\(2\pi\) rad/s)인 이상 저역 통과 필터에 통과시키면, 펄스 에너지의 몇 %가 남을까? 절반? 90%?

생각해 본 뒤 열기

약 90%이다. 펄스 스펙트럼의 주봉우리(첫 영점이 정확히 1 Hz)에 에너지 대부분이 있기 때문이다.

문제

\(x(t) = 1\) (\(|t| < 0.5\)), 0 (그 밖), \(H(j\omega) = 1\) (\(|\omega| < 2\pi\)), 0 (그 밖). (가) 출력 스펙트럼 \(Y(j\omega)\)를 쓰고, (나) 입력과 출력의 에너지를 비교하여라.

전략

  1. 시간 영역 컨볼루션(펄스 * sinc) 대신 \(Y = XH\)를 쓴다.
  2. 에너지는 Parseval로 주파수 영역에서 잰다.

풀이

  1. 예제 4.1.1에서 \(T_1 = 0.5\): \(X = \frac{2\sin(\omega/2)}{\omega}\). 기본쌍
  2. \(Y = XH = \frac{2\sin(\omega/2)}{\omega}\) (\(|\omega| < 2\pi\)), 0 (그 밖). 주봉우리만 남고 옆엽이 모두 잘린다. 컨볼루션 정리
  3. 입력 에너지: 시간 영역에서 \(\int|x|^2dt = 1\). 정의
  4. 출력 에너지: \(E_y = \frac{1}{2\pi}\int_{-2\pi}^{2\pi}\frac{4\sin^2(\omega/2)}{\omega^2}d\omega\). \(u = \omega/2\pi\)로 바꾸면 \(\int_{-1}^{1}\text{sinc}^2(u)\,du\)이고, 수치 적분하면 약 0.903. Parseval

의미

입력 에너지의 약 90.3%가 주봉우리에 있다. 출력은 원래 펄스와 비슷하지만 모서리가 둥글고, 모서리 근처에서 약 9% 넘쳐 오르는 물결(Gibbs, 3.1절)이 생긴다. 대역폭이 "첫 영점까지"인 채널로 펄스를 보내면 에너지는 거의 전해지지만 모양은 무너지기 시작한다. 통신에서 펄스 모양과 대역폭을 함께 설계하는 이유이다.

검산

\(\int_{-\infty}^{\infty}\text{sinc}^2(u)du = 1\)이므로 차단 주파수를 무한히 키우면 출력 에너지가 입력 에너지 1로 돌아간다. 차단 주파수를 0.5 Hz로 줄이면 \(\int_{-0.5}^{0.5}\text{sinc}^2 \approx 0.774\)로 줄어든다.

이해 확인

같은 펄스를 2초 늦춘 \(x(t - 2)\)를 넣으면 출력 에너지는?

답

같습니다(약 0.903). 시간 이동은 \(|X|\)를 바꾸지 않으므로 Parseval 적분이 그대로이다. 출력도 2초 늦어질 뿐이다.
