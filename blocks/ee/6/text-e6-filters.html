필터의 크기 응답과 위상 응답

본문

교과서의 이상 저역 통과 필터는 차단 주파수 아래는 그대로, 위는 완전히 0으로 만든다. 그런데 왜 실제로는 그런 필터를 만들 수 없을까? 그리고 "3 kHz부터는 100분의 1 이하로 줄여라" 같은 요구를 받으면 필터를 얼마나 복잡하게 만들어야 할까?

먼저 알아야 할 것주파수 응답(3.2절), 극점과 안정성(7.1절), Bode 선도(전전3 8.2절)를 쓴다.

8.1.1이상 필터

이상 저역 통과 필터는 \(|\omega| < \omega_c\)에서 \(H = 1\), 나머지에서 0이다. 고역 통과는 그 반대이고, 대역 통과는 한 구간만 1, 대역 저지는 한 구간만 0이다.

이상 저역 통과의 임펄스 응답은 \(h(t) = \frac{\sin\omega_ct}{\pi t}\)이다(4.1절 연습 3). 이것은 \(t < 0\)에서도 0이 아니어서 비인과이고, \(\int|h| = \infty\)라 BIBO 안정도 아니다(2.2절 연습 4). 처음 질문의 첫째 답이 이것이며, 그래서 실제 필터는 이상 필터를 얼마나 잘 근사하는가로 설계한다.

8.1.2실제 필터의 사양

실제 필터의 사양은 세 구간으로 쓴다. 통과 대역 \(0 \le \omega \le \omega_p\)에서는 크기가 1 근처, 곧 허용 리플 \(\delta_p\)(또는 최대 감쇠 \(A_p\) dB) 안에 있어야 한다. 저지 대역 \(\omega \ge \omega_s\)에서는 크기가 \(\delta_s\) 이하, 곧 최소 감쇠가 \(A_s\) dB 이상이어야 한다. 그 사이의 전이 대역 \(\omega_p < \omega < \omega_s\)에는 조건이 없지만, 좁을수록 높은 차수가 필요하다.

예를 들어 6.2절의 오디오 앤티에일리어싱 필터는 "20 kHz까지 감쇠 0.1 dB 이하, 24 kHz부터 감쇠 90 dB 이상" 같은 사양이 된다(값은 예시).

8.1.3Butterworth 필터

구하려는 것은 통과 대역에서 가능한 한 평평한 크기 응답이며, n차 Butterworth 저역 통과 필터의 크기는 다음과 같다.

\[ |H(j\omega)| = \frac{1}{\sqrt{1 + (\omega/\omega_c)^{2n}}}. \]

식은 \(\omega = \omega_c\)에서 언제나 \(1/\sqrt2\), 곧 −3 dB이다. 또 \(\omega \ll \omega_c\)에서는 \(1 - \frac12(\omega/\omega_c)^{2n}\)으로 \(\omega = 0\)에서 \(2n - 1\)번째 도함수까지 0이므로 최대로 평탄하고, \(\omega \gg \omega_c\)에서는 \(-20n\) dB/decade로 줄어든다(그림 1).

극점은 반지름 \(\omega_c\)인 원 위에 각 \(\frac{\pi}{2n}(2k + n - 1)\) 간격으로 고르게 놓이며, 인과이고 안정하도록 그중 왼쪽 반평면의 n개를 쓴다. 예를 들어 n = 2이면 극점은 \(\omega_ce^{\pm j3\pi/4}\)이고 \(H(s) = \frac{\omega_c^2}{s^2 + \sqrt2\omega_cs + \omega_c^2}\)이다.

예제 8.1.1

\(\omega_c = 1\) kHz(차단 주파수를 Hz로)인 Butterworth 저역 통과 필터로 3 kHz에서 40 dB 이상 줄이려면 차수가 얼마여야 하는가?

풀이. 40 dB 감쇠는 \(|H| \le 0.01\), 곧 \(1 + 3^{2n} \ge 10^4\)이다. \(3^{2n} \ge 9999\)이므로 \(2n \ge \log_3 9999 \approx 8.38\), \(n \ge 4.19\)이고, 차수는 정수라 n = 5이다. 확인하면 n = 5에서 \(3^{10} = 59049\)이므로 \(|H| = 1/\sqrt{59050} \approx 0.0041\), 약 −47.7 dB이다. 반면 n = 4이면 \(3^8 = 6561\)로 약 −38.2 dB여서 모자란다(그림 1). 처음 질문의 둘째 답이 이 계산이다.

8.1.4위상 응답과 군지연

주파수 응답의 위상에서 \(\tau_g(\omega) = -\frac{d\angle H}{d\omega}\)를 군지연이라 하며, 그 주파수 근처의 좁은 대역 신호, 곧 포락선이 늦어지는 시간이다. 위상이 \(\angle H = -\omega t_0\)처럼 선형이면 \(\tau_g = t_0\)로 모든 주파수가 똑같이 늦어지므로, 파형 모양이 지연만 되고 일그러지지 않는다(4.2절 시간 이동).

그러나 Butterworth 같은 IIR 필터는 위상이 선형이 아니어서 차단 주파수 근처의 성분이 더 오래 늦어지고, 사각파를 넣으면 출력에 울림(링잉)이 생긴다. 반면 대칭 계수를 가진 FIR 필터는 5.1절 이동 평균의 \(-\omega(L - 1)/2\)처럼 정확히 선형 위상이 된다. 그래서 파형 모양이 중요한 심전도나 데이터 통신에는 선형 위상 FIR을, 적은 계산으로 가파른 크기 응답이 필요할 때는 IIR을 많이 쓴다.

흔한 오해"차단 주파수 위는 모두 0이 된다"는 생각은 틀리다. Butterworth의 차단 주파수에서 크기는 0.707이고, 위로 갈수록 서서히 줄어든다. 또 크기 응답이 1이면 신호가 그대로 나온다고 생각하기 쉽지만, 위상이 비선형이면 크기가 모두 1이어도 파형이 바뀐다(전역 통과 필터). 차수를 무작정 높이면 크기는 가팔라지지만 군지연이 커지고 차단 주파수 근처의 링잉이 심해진다.
마무리

이상 필터는 비인과이고 불안정하여 만들 수 없으므로, 실제 필터는 통과 대역, 저지 대역, 전이 대역의 사양으로 근사한다. Butterworth 필터는 \(|H| = 1/\sqrt{1 + (\omega/\omega_c)^{2n}}\)로 \(\omega_c\)에서 −3 dB이고 저지 대역에서 −20n dB/decade로 떨어지므로, 요구 감쇠로부터 필요한 차수를 구한다. 군지연은 \(-d\angle H/d\omega\)이며, 대칭 FIR처럼 위상이 선형이면 파형이 일그러지지 않는다.

8.1.5연습문제

기본

  1. 3차 Butterworth(\(\omega_c = 1\))의 \(\omega = 2\)에서 크기를 dB로 구하여라.
    답

    \(1/\sqrt{1 + 64} \approx 0.124\)이므로 약 −18.1 dB이다.

  2. 지연기 \(e^{-j\omega t_0}\)의 군지연은?
    답

    모든 주파수에서 같은 \(t_0\)이다.

응용

  1. 1차 RC 저역 통과 \(H = \frac{1}{1 + j\omega\tau}\)의 군지연을 구하고, \(\omega = 0\)과 \(\omega = 1/\tau\)에서의 값을 비교하여라.
    답

    \(\angle H = -\arctan\omega\tau\)이므로 \(\tau_g = \frac{\tau}{1 + (\omega\tau)^2}\)이다. \(\omega = 0\)에서 \(\tau\), \(\omega = 1/\tau\)에서 \(\tau/2\)로 주파수마다 지연이 달라 위상이 비선형이다.

심화

  1. 통과 대역 끝(\(\omega_p = 0.9\omega_c\))에서 감쇠가 1 dB 이하가 되려면 Butterworth 차수는 얼마 이상이어야 하는가? n을 늘리면 \(\omega_p\)에서의 감쇠는 어떻게 되는가?
    답

    \(|H(0.9\omega_c)|^2 = 1/(1 + 0.81^n)\)이다. n이 커질수록 \(0.81^n \to 0\)이라 감쇠가 줄어들어, n = 1이면 약 2.6 dB, n = 4이면 약 1.6 dB, n = 6이면 약 1.08 dB이고 n = 7에서 약 0.89 dB로 처음 1 dB 아래가 된다. 즉 차수를 높이면 통과 대역이 더 평평해지고 저지 대역은 더 가팔라진다.
