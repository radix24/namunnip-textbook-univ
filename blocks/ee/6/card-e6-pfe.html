디지털 필터의 계단 응답을 Z-변환으로

예제 · 곱하고, 쪼개고, 표로 돌아가기

먼저 예측

\(y[n] = 0.5y[n-1] + 0.5x[n]\)(직류 이득 1인 1차 저역 통과)에 계단 \(u[n]\)을 넣으면 출력은 1에 다가갑니다. 몇 번째 표본에서 0.9를 처음 넘을까요?

생각해 본 뒤 열기

\(y[n] = 1 - 0.5^{n+1}\)이므로 n = 3에서 0.9375로 처음 넘습니다.

문제

위 시스템의 계단 응답 \(y[n]\)을 Z-변환과 부분분수로 구하고, 되풀이 계산으로 검산하여라.

전략

  1. \(H(z)\)를 차분 방정식에서 바로 쓴다(7.2.2).
  2. \(U(z) = \frac{1}{1 - z^{-1}}\) (\(|z| > 1\))과 곱한다.
  3. \(\frac{A}{1 - z^{-1}} + \frac{B}{1 - 0.5z^{-1}}\)로 쪼개 덮개 방법으로 계수를 구하고, 인과이므로 모두 \(u[n]\)으로 돌아간다.

풀이

  1. \(Y(1 - 0.5z^{-1}) = 0.5X\) → \(H(z) = \frac{0.5}{1 - 0.5z^{-1}}\). 지연 ↔ \(z^{-1}\)
  2. \(Y(z) = \frac{0.5}{(1 - z^{-1})(1 - 0.5z^{-1})}\), ROC \(|z| > 1\). 컨볼루션 ↔ 곱
  3. \(A\): \(z = 1\)(\(z^{-1} = 1\)): \(\frac{0.5}{1 - 0.5} = 1\). \(B\): \(z = 0.5\)(\(z^{-1} = 2\)): \(\frac{0.5}{1 - 2} = -0.5\). 덮개 방법
  4. \(y[n] = (1 - 0.5\cdot0.5^n)u[n] = (1 - 0.5^{n+1})u[n]\). \(p^nu[n]\) 쌍

의미

계단 응답 = 최종값(직류 이득 \(H(1) = 1\)에서 오는 항 A) + 과도 항(시스템 극점 0.5에서 오는 항 B). 입력의 극점(z = 1)이 정상 상태를, 시스템의 극점이 과도 상태를 만듭니다. 극점이 0에 가까울수록 과도 항이 빨리 사라집니다. 연속시간 RC 회로의 \(1 - e^{-t/RC}\)와 같은 구조입니다.

검산

되풀이: \(y[0] = 0.5\), \(y[1] = 0.25 + 0.5 = 0.75\), \(y[2] = 0.375 + 0.5 = 0.875\), \(y[3] = 0.9375\). 식: \(1 - 0.5 = 0.5\), \(1 - 0.25 = 0.75\), \(1 - 0.125 = 0.875\), \(1 - 0.0625 = 0.9375\). 일치합니다.

이해 확인

같은 시스템에 \(x[n] = (-1)^nu[n]\)을 넣은 출력의 정상 상태 진폭은?

답

입력 극점 \(z = -1\)에서 \(|H(-1)| = \frac{0.5}{1 + 0.5} = \frac13\). 정상 상태 \(\frac13(-1)^n\). 부분분수로는 \(A = \frac{0.5}{1 - 0.5(-1)} = \frac13\)(극점 −1), \(B = \frac{0.5}{1 - (-2)} = \frac16\)(극점 0.5).
