DFT는 DTFT 위의 점이다

탐구 · 영 채우기가 바꾸는 것과 바꾸지 않는 것

질문

1이 4개인 수열의 4점 DFT는 {4, 0, 0, 0}이다. 그렇다면 이 수열에는 직류만 있는 걸까? 0을 채워 N을 키우면 무엇이 보일까?

준비

\(x[n] = 1\) (\(0 \le n \le L - 1\))의 DTFT 크기 \(\left|\frac{\sin(\omega L/2)}{\sin(\omega/2)}\right|\)를 회색 점선으로, N점 DFT의 크기를 파랑 점으로 그린다. 가로축은 \(0 \le \omega < 2\pi\)이다. N이 L보다 작으면 N = L로 둔다.

해 보기와 설명

  1. N = L = 4|X| = 4, 0, 0, 0. 점이 모두 DTFT의 꼭대기와 영점에만 찍혔다. 주기 4로 반복하면 상수이므로 맞는 답이지만, 곡선의 모양은 보이지 않는다.
  2. N = 8|X| = 4, 2.613, 0, 1.082, 0, …(예제 5.2.1). 같은 곡선의 점이 두 배로 촘촘하다.
  3. N = 64점이 곡선을 거의 그대로 그린다. 그러나 주봉우리의 폭(첫 영점 \(2\pi/L\))은 N = 4일 때와 같다. 영 채우기는 해상도를 바꾸지 않는다.
  4. L을 바꾸기N = 64로 두고 L을 4에서 16으로 늘리면 주봉우리가 좁아진다. 해상도를 바꾸는 것은 신호의 실제 길이이다.

연결과 적용

스펙트럼 분석기 프로그램의 "FFT 크기"를 키우는 설정에는 두 종류가 있다. 더 긴 녹음을 쓰는 것(해상도 향상)과 0을 채우는 것(보간)이다. 실습 카드(5.3절)에서 숫자로 확인한다.

흔한 오해

  • "DFT 값이 0인 빈에는 성분이 없다." 빈 사이의 DTFT는 0이 아닐 수 있다. N = 4의 결과가 그 예이다.
