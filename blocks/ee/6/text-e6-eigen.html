복소 지수는 LTI 시스템의 고유함수다

본문

회로이론에서는 정현파를 RC 회로에 넣으면 같은 주파수의 정현파가 크기와 위상만 바뀌어 나온다는 것을 페이저로 계산했다. 이것은 RC 회로라서 생기는 우연일까, 아니면 모든 선형 시불변 시스템에서 성립하는 사실일까? 성립한다면 직류와 여러 주파수가 섞인 입력의 출력은 어떻게 구할까?

먼저 알아야 할 것컨볼루션(2.1절), Fourier 급수(3.1절), 페이저(전전3 7.1절)를 쓴다.

3.2.1고유함수라는 말

행렬 A에 대해 \(A\mathbf{v} = \lambda\mathbf{v}\)이면 \(\mathbf{v}\)를 고유벡터라 했다. 방향은 그대로이고 크기만 \(\lambda\)배 된다. 시스템에서도 같은 말을 써서, 시스템을 통과해도 모양이 그대로이고 상수배만 되는 입력 \(\phi\), 곧 \(T\{\phi\} = \lambda\phi\)인 입력을 고유함수라 한다. 그 상수 \(\lambda\)는 고윳값이며 복소수일 수 있다.

정현파를 RC 회로에 넣으면 같은 주파수의 정현파가 나오고 크기와 위상만 바뀐다는 것을 회로이론에서 보았다. 이 절은 그 사실이 회로만이 아니라 모든 LTI 시스템에서 성립함을 증명하며, 처음 질문의 첫째 답이 이것이다.

3.2.2증명

정리 3.2.1

임펄스 응답이 h(t)인 LTI 시스템에 \(x(t) = e^{st}\)를 넣으면, 적분이 수렴하는 한 \(y(t) = H(s)e^{st}\)이다. 여기서 \(H(s) = \int_{-\infty}^{\infty}h(\tau)e^{-s\tau}d\tau\)이다. 이산시간에서는 \(x[n] = z^n\)이면 \(y[n] = H(z)z^n\), \(H(z) = \sum_kh[k]z^{-k}\)이다.

구하려는 것은 출력이 입력의 상수배라는 사실이다. 컨볼루션의 교환 법칙으로 h를 움직이지 않는 쪽에 둔다.

\[ y(t) = \int_{-\infty}^{\infty}h(\tau)\,x(t - \tau)\,d\tau = \int_{-\infty}^{\infty}h(\tau)\,e^{s(t - \tau)}\,d\tau. \]

지수 법칙 \(e^{s(t - \tau)} = e^{st}e^{-s\tau}\)에서 \(e^{st}\)는 적분 변수 \(\tau\)와 무관하므로 적분 밖으로 나온다.

\[ y(t) = e^{st}\int_{-\infty}^{\infty}h(\tau)\,e^{-s\tau}\,d\tau = H(s)\,e^{st}. \]

식의 \(H(s)\)는 t에 의존하지 않는 상수이므로 \(e^{st}\)는 고유함수이고 \(H(s)\)는 고윳값이다. 이산시간도 합으로 똑같이 하면 된다. ∎

증명에서 쓴 것은 컨볼루션 표현, 곧 LTI라는 사실과 지수 법칙 둘뿐이다. 그래서 비선형이나 시변 시스템에서는 성립하지 않는다. 예를 들어 \(y = x^2\)에 \(e^{j\omega t}\)를 넣으면 \(e^{j2\omega t}\)가 나와 주파수가 바뀐다.

\(s = j\omega\)로 둔 고윳값 \(H(j\omega) = \int h(t)e^{-j\omega t}dt\)를 주파수 응답이라 하며, 이것은 h의 Fourier 변환이다(4단원). 또 일반 복소수 s에 대한 고윳값 \(H(s)\)는 전달함수라 하며, h의 Laplace 변환이다(7단원).

3.2.3주기 입력의 출력

입력이 \(x(t) = \sum a_ke^{jk\omega_0t}\)이면 선형성으로 각 항이 따로 고윳값을 곱받는다.

\[ y(t) = \sum_k a_kH(jk\omega_0)\,e^{jk\omega_0t}, \qquad b_k = H(jk\omega_0)\,a_k. \]

즉 출력도 같은 주기 T의 주기 신호이고, Fourier 계수는 입력 계수에 그 주파수에서의 주파수 응답을 곱한 것이다. 시스템은 새로운 주파수를 만들지 못하고, 있는 주파수의 크기와 위상만 바꾼다.

실수 정현파에도 바로 쓸 수 있다. h가 실수이면 \(H(-j\omega) = H(j\omega)^*\)이므로, \(\cos\omega t = \frac12(e^{j\omega t} + e^{-j\omega t})\)를 넣으면 다음과 같다.

\[ y(t) = |H(j\omega)|\cos(\omega t + \angle H(j\omega)). \]
예제 3.2.1

\(h(t) = e^{-t}u(t)\)인 시스템(시정수 1 s인 RC 저역 통과)에 \(x(t) = 1 + \cos t + \cos 10t\)를 넣었을 때 출력을 구하여라.

풀이. 먼저 주파수 응답은 \(H(j\omega) = \int_0^\infty e^{-t}e^{-j\omega t}dt = \frac{1}{1 + j\omega}\)이다. 각 주파수에서 값을 구하면, \(\omega = 0\)에서 \(H = 1\)이라 직류는 그대로 1이다. \(\omega = 1\)에서는 \(H = \frac{1}{1 + j}\)이므로 \(|H| = 1/\sqrt2 \approx 0.707\), \(\angle H = -45°\)이다. 또 \(\omega = 10\)에서는 \(|H| = 1/\sqrt{101} \approx 0.0995\), \(\angle H = -\arctan 10 \approx -84.3°\)이다.

따라서 \(y(t) = 1 + 0.707\cos(t - 45°) + 0.0995\cos(10t - 84.3°)\)이고, 높은 주파수 성분이 약 1/10로 줄었다(그림 1). 처음 질문의 둘째 답이 이것으로, 컨볼루션 적분을 직접 하지 않고 곱셈 세 번으로 끝났다. 전전3의 페이저 계산 \(\frac{1}{1 + j\omega RC}\)와 같은 결과이다.

흔한 오해"사인파는 LTI 시스템의 고유함수"라고 하면 엄밀히는 틀리다. \(\sin\omega t\)를 넣으면 \(|H|\sin(\omega t + \angle H)\)가 나와 위상이 바뀌므로 상수배가 아니며, 고유함수는 복소 지수이다. 또 고유함수 성질은 \(-\infty\)부터 계속된 입력에 대한 것이다. \(t = 0\)에 켠 \(\cos(\omega t)u(t)\)에는 과도 응답이 붙고, 그것이 사라진 정상 상태에서만 위 식이 맞는다.
마무리

LTI 시스템에 복소 지수 \(e^{st}\)를 넣으면 \(H(s)e^{st}\)가 나오고, \(H(s) = \int h(\tau)e^{-s\tau}d\tau\)이며, 증명에는 컨볼루션과 지수 법칙만 쓴다. \(s = j\omega\)로 둔 주파수 응답 \(H(j\omega)\)로 주기 입력의 출력 계수는 \(b_k = H(jk\omega_0)a_k\)가 된다. 실수 정현파는 크기가 \(|H|\)배, 위상이 \(\angle H\)만큼 바뀔 뿐 새 주파수는 생기지 않는다.

3.2.4연습문제

기본

  1. 지연기 \(y(t) = x(t - t_0)\)의 \(H(j\omega)\)를 구하여라.
    답

    \(e^{j\omega(t - t_0)} = e^{-j\omega t_0}e^{j\omega t}\)이므로 \(H = e^{-j\omega t_0}\)이다. 크기는 1이고 위상은 주파수에 비례하는 \(-\omega t_0\)이다.

  2. \(y[n] = \frac12(x[n] + x[n-1])\)의 \(H(e^{j\omega})\)와 \(\omega = 0, \pi\)에서의 크기는?
    답

    \(H = \frac12(1 + e^{-j\omega})\)이므로 \(|H(0)| = 1\), \(|H(\pi)| = 0\)인 저역 통과이다.

응용

  1. 예제 3.2.1의 시스템에 3.1절의 사각파(\(T = 2\pi\), 듀티 50%)를 넣으면 출력의 기본파 진폭은?
    답

    입력 기본파 진폭은 \(2|a_1| = 2/\pi \approx 0.637\)이고 \(\omega_0 = 1\)에서 \(|H| = 0.707\)이므로 약 0.450이다.

심화

  1. \(y = x^2\)에 \(\cos\omega t\)를 넣어 나오는 주파수를 구하고, 이것이 3.2.3의 "새 주파수가 생기지 않는다"와 모순되지 않는 이유를 설명하여라.
    답

    \(\cos^2 = \frac12 + \frac12\cos2\omega t\)이므로 직류와 \(2\omega\)가 생긴다. 이 시스템은 비선형이라 정리 3.2.1의 가정을 만족하지 않으므로 모순이 아니다. 비선형 증폭기의 고조파 왜곡이 이 현상이다.
