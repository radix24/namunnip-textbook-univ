세 좌표계와 벡터 성분 변환

본문
이 절에서 배울 것
  • 직교 좌표 \((x, y, z)\), 원통 좌표 \((\rho, \phi, z)\), 구 좌표 \((r, \theta, \phi)\)의 정의와 단위 벡터를 안다.
  • 단위 벡터의 내적 표로 한 좌표계의 벡터 성분을 다른 좌표계로 바꾼다.
  • 각 좌표계의 길이·넓이·부피 요소를 쓰고, 문제의 대칭에 맞는 좌표계를 고른다.
먼저 알아야 할 것
  • 고교 평면벡터와 삼각함수, 정적분. 공간벡터·내적·외적은 아래 상자에서 설명하고, 자세한 내용은 공통2 (1.1절, 좌표계의 겹적분은 6.5절).
고교 수학만 배웠다면 먼저 읽기

이 과목은 공간(3차원)의 벡터를 씁니다. 고교 수학의 평면벡터에 축 하나를 더했다고 생각하면 됩니다.

  • 공간벡터: 서로 수직인 세 방향의 단위 벡터 \(\mathbf a_x, \mathbf a_y, \mathbf a_z\)(길이 1, 굵은 글씨는 벡터)를 써서 \(\mathbf A = A_x\mathbf a_x + A_y\mathbf a_y + A_z\mathbf a_z\)로 나타낸다. 크기는 피타고라스 정리를 두 번 써서 \(|\mathbf A| = \sqrt{A_x^2 + A_y^2 + A_z^2}\).
  • 내적 \(\mathbf A\cdot\mathbf B = A_xB_x + A_yB_y + A_zB_z = |\mathbf A||\mathbf B|\cos\theta\): 같은 방향 성분끼리 곱해 더한 수(스칼라). 한 벡터를 다른 벡터 방향으로 내린 그림자 길이와 관계있어, "어떤 방향의 성분"을 뽑을 때 쓴다. 예: \((3, 4, 0)\cdot\mathbf a_x = 3\). 수직이면 0.
  • 외적 \(\mathbf A\times\mathbf B\): 두 벡터에 모두 수직인 벡터. 크기는 두 벡터가 만드는 평행사변형의 넓이 \(|\mathbf A||\mathbf B|\sin\theta\), 방향은 오른손 네 손가락을 A에서 B 쪽으로 감을 때 엄지 방향. \(\mathbf a_x\times\mathbf a_y = \mathbf a_z\). 힘의 모멘트나 자기력 \(q\mathbf v\times\mathbf B\)에 쓴다.
  • 미소 요소와 적분: \(dv\), \(dS\), \(dL\)은 아주 작은 부피·넓이·길이 조각이고, 적분은 "작은 조각마다 값을 곱해 모두 더하기"(고교 정적분과 같은 생각)이다. 겹적분 기호가 나와도 대칭 덕분에 대부분 고교 정적분 하나로 줄어든다.

1.1.1왜 좌표계를 바꾸는가

전자기학의 문제는 대칭을 가진 경우가 많습니다. 긴 도선이나 동축 케이블은 축 둘레로 대칭이고, 점전하나 구형 도체는 중심에서 모든 방향이 같습니다. 대칭에 맞는 좌표계를 쓰면 장(field)이 좌표 하나의 함수가 되어 적분과 미분이 크게 쉬워집니다. 예를 들어 무한 직선 전하의 전계는 원통 좌표에서 \(\mathbf E = \frac{\rho_L}{2\pi\epsilon_0\rho}\mathbf a_\rho\) 한 줄이지만, 직교 좌표로는 \(\frac{\rho_L}{2\pi\epsilon_0}\frac{x\mathbf a_x + y\mathbf a_y}{x^2 + y^2}\)입니다.

1.1.2세 좌표계

원통 좌표 \((\rho, \phi, z)\): \(x = \rho\cos\phi\), \(y = \rho\sin\phi\), \(z = z\). \(\rho\)는 z축까지의 거리(구 좌표의 r과 다름).

구 좌표 \((r, \theta, \phi)\): \(x = r\sin\theta\cos\phi\), \(y = r\sin\theta\sin\phi\), \(z = r\cos\theta\). \(\theta\)는 +z축에서 잰 극각(0~π), \(\phi\)는 방위각(0~2π).

단위 벡터: 그 좌표만 조금 늘릴 때 점이 움직이는 방향. 직교 좌표의 \(\mathbf a_x, \mathbf a_y, \mathbf a_z\)는 어디서나 같지만, \(\mathbf a_\rho, \mathbf a_\phi, \mathbf a_r, \mathbf a_\theta\)는 위치에 따라 방향이 바뀐다.

세 좌표계 모두 단위 벡터가 서로 수직인 오른손계입니다: \(\mathbf a_\rho \times \mathbf a_\phi = \mathbf a_z\), \(\mathbf a_r \times \mathbf a_\theta = \mathbf a_\phi\).

1.1.3성분 변환: 내적 표

구하려는 것: 직교 좌표 성분 \((A_x, A_y, A_z)\)를 아는 벡터의 원통 성분 \(A_\rho\). 어떤 단위 벡터 방향의 성분은 그 단위 벡터와의 내적이므로 \(A_\rho = \mathbf A\cdot\mathbf a_\rho = A_x(\mathbf a_x\cdot\mathbf a_\rho) + A_y(\mathbf a_y\cdot\mathbf a_\rho) + A_z(\mathbf a_z\cdot\mathbf a_\rho)\). 필요한 것은 단위 벡터끼리의 내적뿐입니다.

·\(\mathbf a_\rho\)\(\mathbf a_\phi\)\(\mathbf a_z\)
\(\mathbf a_x\)\(\cos\phi\)\(-\sin\phi\)0
\(\mathbf a_y\)\(\sin\phi\)\(\cos\phi\)0
\(\mathbf a_z\)001
·\(\mathbf a_r\)\(\mathbf a_\theta\)\(\mathbf a_\phi\)
\(\mathbf a_x\)\(\sin\theta\cos\phi\)\(\cos\theta\cos\phi\)\(-\sin\phi\)
\(\mathbf a_y\)\(\sin\theta\sin\phi\)\(\cos\theta\sin\phi\)\(\cos\phi\)
\(\mathbf a_z\)\(\cos\theta\)\(-\sin\theta\)0

표는 외울 필요 없이 그림에서 얻을 수 있습니다. 예를 들어 \(\mathbf a_\phi\)는 xy 평면에서 \(\mathbf a_\rho\)를 90° 돌린 방향이라 \((-\sin\phi, \cos\phi, 0)\)입니다.

예제 1.1.1

점 P(x, y, z) = (1, 1, √2)에서 벡터 \(\mathbf A = 2\mathbf a_x - \mathbf a_y + 3\mathbf a_z\)의 원통 성분과 구 성분을 구하여라.

풀이. 먼저 P의 좌표: \(\rho = \sqrt2\), \(\phi = 45°\), \(r = \sqrt{1 + 1 + 2} = 2\), \(\theta = \arccos(\sqrt2/2) = 45°\).

  • 원통: \(A_\rho = 2\cos45° - \sin45° = 0.707\), \(A_\phi = -2\sin45° - \cos45° = -2.121\), \(A_z = 3\).
  • 구: \(A_r = \sin45°(2\cos45° - \sin45°) + 3\cos45° = 0.5 + 2.121 = 2.621\), \(A_\theta = \cos45°(2\cos45° - \sin45°) - 3\sin45° = 0.5 - 2.121 = -1.621\), \(A_\phi = -2.121\).

검산: 크기는 좌표계와 무관해야 합니다. \(|\mathbf A|^2 = 4 + 1 + 9 = 14\), 원통 \(0.5 + 4.5 + 9 = 14\), 구 \(6.87 + 2.63 + 4.5 = 14.0\). 일치합니다.

1.1.4미소 요소

적분을 하려면 좌표를 조금 바꿀 때의 길이, 넓이, 부피가 필요합니다. 각도 좌표는 길이가 아니므로 반지름을 곱해야 합니다.

원통: \(d\mathbf L = d\rho\,\mathbf a_\rho + \rho\,d\phi\,\mathbf a_\phi + dz\,\mathbf a_z\), \(dv = \rho\,d\rho\,d\phi\,dz\).

구: \(d\mathbf L = dr\,\mathbf a_r + r\,d\theta\,\mathbf a_\theta + r\sin\theta\,d\phi\,\mathbf a_\phi\), \(dv = r^2\sin\theta\,dr\,d\theta\,d\phi\). 구면의 넓이 요소 \(dS = r^2\sin\theta\,d\theta\,d\phi\).

확인: 반지름 a인 구의 겉넓이 \(\int_0^{2\pi}\int_0^\pi a^2\sin\theta\,d\theta\,d\phi = 4\pi a^2\).

흔한 오해(1) "\(\mathbf a_\rho\)는 상수 벡터라 적분 밖으로 꺼낼 수 있다": 위치에 따라 방향이 바뀌므로, 적분하기 전에 직교 성분으로 바꾸거나 대칭으로 상쇄되는지 확인해야 합니다(2.1절). (2) 구 좌표의 \(\theta\)와 원통 좌표의 \(\phi\)를 섞는 실수: 물리·공학에서는 \(\theta\)가 극각, \(\phi\)가 방위각입니다(일부 수학 교재는 반대). (3) 점의 좌표 변환(\(x \to \rho, \phi\))과 벡터 성분의 변환은 별개입니다. 성분 변환에는 그 점의 \(\phi, \theta\)가 들어갑니다.
요약
  1. 원통 \((\rho, \phi, z)\), 구 \((r, \theta, \phi)\). 곡선 좌표의 단위 벡터는 위치마다 다르다.
  2. 성분 변환 = 단위 벡터와의 내적. 표 두 개로 충분하다. 크기는 보존된다.
  3. \(dv = \rho\,d\rho\,d\phi\,dz\), \(r^2\sin\theta\,dr\,d\theta\,d\phi\). 대칭에 맞는 좌표계를 고른다.

1.1.5연습문제

기본

  1. 점 \((\rho, \phi, z) = (2, 120°, -1)\)의 직교 좌표는?
    답

    \((-1, \sqrt3, -1)\).

  2. \(\mathbf a_\rho\)를 \(\phi = 90°\)에서 직교 단위 벡터로 쓰면?
    답

    \(\mathbf a_y\).

응용

  1. \(\mathbf B = \frac{1}{\rho}\mathbf a_\phi\)(직선 전류의 자계 모양)를 직교 성분으로 쓰라.
    답

    \(\frac{-y\mathbf a_x + x\mathbf a_y}{x^2 + y^2}\).

심화

  1. 원뿔 \(\theta = 30°\), \(0 \le r \le 2\)의 옆면 넓이를 구 좌표의 넓이 요소로 구하여라.
    답

    \(\theta\) 고정 면의 넓이 요소 \(r\sin\theta\,dr\,d\phi\). \(\int_0^{2\pi}\int_0^2 r\sin30°\,dr\,d\phi = 2\pi \times 0.5 \times 2 = 2\pi\).
