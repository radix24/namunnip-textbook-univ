1.2.1세 미분 연산의 뜻

기울기 \(\nabla V\): 스칼라장 V가 가장 빨리 증가하는 방향과 그 증가율. 전위에서 전계를 얻는 \(\mathbf E = -\nabla V\)(2.3절).

발산 \(\nabla\cdot\mathbf D = \lim_{\Delta v \to 0}\frac{\oint\mathbf D\cdot d\mathbf S}{\Delta v}\): 한 점 둘레의 작은 부피에서 나가는 단위 부피당 선속. 샘(양)과 흡입구(음)를 잰다. 정전계에서 \(\nabla\cdot\mathbf D = \rho_v\)(전하가 선속의 샘).

회전 \(\nabla\times\mathbf H\): 한 점 둘레의 작은 고리를 도는 단위 넓이당 순환(소용돌이). 정자계에서 \(\nabla\times\mathbf H = \mathbf J\)(전류가 순환의 원인).

정의가 극한으로 되어 있어서, 직교 좌표에서는 작은 정육면체로 \(\nabla\cdot\mathbf D = \frac{\partial D_x}{\partial x} + \frac{\partial D_y}{\partial y} + \frac{\partial D_z}{\partial z}\)를 얻고, 곡선 좌표에서는 면의 넓이가 위치에 따라 달라 다음 공식이 됩니다.

\[ \nabla\cdot\mathbf D = \frac1\rho\frac{\partial(\rho D_\rho)}{\partial\rho} + \frac1\rho\frac{\partial D_\phi}{\partial\phi} + \frac{\partial D_z}{\partial z} = \frac{1}{r^2}\frac{\partial(r^2D_r)}{\partial r} + \frac{1}{r\sin\theta}\frac{\partial(\sin\theta D_\theta)}{\partial\theta} + \frac{1}{r\sin\theta}\frac{\partial D_\phi}{\partial\phi}. \]

원통 좌표에서 \(\phi\) 성분만 있는 \(\mathbf H = H_\phi(\rho)\mathbf a_\phi\)의 회전은 \(\nabla\times\mathbf H = \frac1\rho\frac{d(\rho H_\phi)}{d\rho}\mathbf a_z\)입니다. 이 두 꼴(구 대칭의 발산, 축 대칭의 회전)이 이 과목에서 가장 자주 쓰입니다.

1.2.2발산 정리와 Stokes 정리

\[ \oint_S\mathbf D\cdot d\mathbf S = \int_V\nabla\cdot\mathbf D\,dv, \qquad \oint_C\mathbf H\cdot d\mathbf L = \int_S(\nabla\times\mathbf H)\cdot d\mathbf S. \]

뜻은 정의에서 바로 나옵니다. 큰 부피를 작은 부피들로 쪼개면, 이웃한 작은 부피 사이의 면에서 나가고 들어오는 선속이 상쇄되어 바깥 껍질의 선속만 남습니다. 고리도 마찬가지입니다. 전자기학에서는 이 두 정리로 Maxwell 방정식의 적분형(Gauss, Ampère)과 미분형을 오갑니다(6.2절).

예제 1.2.1

\(\mathbf D = 5r^2\,\mathbf a_r\) mC/m²일 때 반지름 4 m인 구에 대해 발산 정리의 양변을 계산하고, 그 안의 전하를 구하여라.

풀이. 왼쪽(면 적분): 구면에서 \(\mathbf D\)는 면에 수직이고 크기가 일정 \(5 \times 16 = 80\) mC/m². 넓이 \(4\pi \times 16 = 64\pi\) m². 선속 \(80 \times 64\pi = 5120\pi\) mC. 오른쪽(부피 적분): \(\nabla\cdot\mathbf D = \frac{1}{r^2}\frac{d}{dr}(5r^4) = 20r\). \(\int_0^4 20r\cdot4\pi r^2dr = 80\pi\cdot\frac{4^4}{4} = 5120\pi\) mC. 일치합니다. Gauss 법칙으로 안의 전하는 \(5120\pi\) mC ≈ 16.1 C(가상의 큰 값)입니다.

예제 1.2.2

\(\mathbf H = 2\rho\,\mathbf a_\phi\) A/m일 때 반지름 a인 원 둘레의 순환을 두 방법으로 구하고, 전류 밀도를 구하여라.

풀이. 선적분: \(d\mathbf L = a\,d\phi\,\mathbf a_\phi\), \(\oint = \int_0^{2\pi}2a\cdot a\,d\phi = 4\pi a^2\). 면적분: \(\nabla\times\mathbf H = \frac1\rho\frac{d}{d\rho}(2\rho^2)\mathbf a_z = 4\mathbf a_z\), \(\int 4\,dS = 4\pi a^2\). 일치합니다. \(\mathbf J = \nabla\times\mathbf H = 4\mathbf a_z\) A/m²: 균일한 전류가 흐르는 도선 내부의 자계 모양입니다(4.2절).

흔한 오해(1) 곡선 좌표의 발산을 직교 좌표처럼 \(\partial D_r/\partial r\)로만 쓰는 실수: \(\mathbf D = \mathbf a_r/r^2\)(점전하)의 발산은 원점 밖에서 0인데, \(\partial D_r/\partial r = -2/r^3\)으로 잘못 나옵니다. (2) 발산이 0이면 선속도 0이라는 오해: 원점에 점전하가 있으면 발산이 원점에서만 무한대(델타 함수)라, 원점을 둘러싼 면의 선속은 0이 아닙니다. (3) Stokes 정리의 면 방향은 고리 방향과 오른손 규칙으로 맞춥니다.
요약
  1. 기울기: 가장 빠른 증가. 발산: 단위 부피당 나가는 선속. 회전: 단위 넓이당 순환.
  2. 구 대칭: \(\nabla\cdot\mathbf D = \frac{1}{r^2}\frac{d(r^2D_r)}{dr}\). 축 대칭: \(\nabla\times\mathbf H = \frac1\rho\frac{d(\rho H_\phi)}{d\rho}\mathbf a_z\).
  3. 발산 정리(선속 ↔ 샘), Stokes 정리(순환 ↔ 회전). 전하·전류와 연결된다.

1.2.3연습문제

기본

  1. \(\mathbf D = x^2\mathbf a_x + y\mathbf a_y\)의 발산은?
    답

    \(2x + 1\).

  2. \(V = x^2y\)의 기울기를 (1, 2, 0)에서 구하여라.
    답

    \(2xy\mathbf a_x + x^2\mathbf a_y = 4\mathbf a_x + \mathbf a_y\).

응용

  1. \(\mathbf D = \frac{Q}{4\pi r^2}\mathbf a_r\)의 발산이 \(r > 0\)에서 0임을 보이고, 반지름 R인 구의 선속을 구하여라.
    답

    \(\frac{1}{r^2}\frac{d}{dr}\frac{Q}{4\pi} = 0\). 선속 \(\frac{Q}{4\pi R^2}\cdot4\pi R^2 = Q\)(R과 무관).

심화

  1. 한 변 1 m 정육면체(0 ≤ x, y, z ≤ 1)에서 \(\mathbf D = xy\,\mathbf a_x + z\,\mathbf a_z\)의 선속을 발산 정리로 구하고, 여섯 면의 면적분으로 확인하여라.
    답

    \(\nabla\cdot\mathbf D = y + 1\), \(\int(y + 1)dv = 1.5\). 면: x = 1 면 \(\int y\,dy\,dz = 0.5\), x = 0 면 0, z = 1 면 1, z = 0 면 0, y 면 0. 합 1.5.
