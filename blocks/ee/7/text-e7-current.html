정상 전류

본문

정전기학에서는 전하가 멈춰 있었다. 이제 전하가 일정하게 흐르는 경우를 보자. 회로에서는 저항을 \(V = IR\)로 썼지만, 전자기학에서는 도체 속 각 점의 전류 밀도와 전계를 다룬다. 모양이 복잡한 도체의 저항은 어떻게 구하고, 도체 안에 넣은 전하는 왜 순식간에 사라질까?

먼저 알아야 할 것Gauss 법칙과 전위(2.2절, 2.3절), 정전용량(3.2절)을 쓴다.

3.5.1전류 밀도와 연속 방정식

전류 밀도 \(\mathbf J\)는 단위 넓이를 지나는 전류로, 넓이에 대해 적분하면 전류 \(I = \int\mathbf J\cdot d\mathbf S\)이다. 도체 속에서는 Ohm 법칙의 점 형식 \(\mathbf J = \sigma\mathbf E\)가 성립한다(\(\sigma\)는 전도도). 전하는 생기거나 사라지지 않으므로, 닫힌 면을 빠져나가는 전류는 안의 전하가 줄어드는 비율과 같다. 미분 꼴로 쓰면 연속 방정식 \(\nabla\cdot\mathbf J = -\partial\rho/\partial t\)이다. 그러므로 정상 상태에서는 \(\nabla\cdot\mathbf J = 0\)이다. 이것이 KCL의 장 형식이다.

3.5.2저항 계산과 이완 시간

모양이 복잡한 도체의 저항은 두 전극 사이에 전압 \(V\)를 걸고 전계를 구한 뒤 \(I = \int\sigma\mathbf E\cdot d\mathbf S\)로 전류를 구해 \(R = V/I\)로 얻는다. 같은 모양의 정전용량과 비교하면 편리하다. 전극 사이 매질의 \(\varepsilon\)을 \(\sigma\)로 바꾸기만 하면 같은 계산이므로 \(RC = \varepsilon/\sigma\)이다. 이제 도체 안에 전하 \(\rho_0\)을 넣었다고 하자. 연속 방정식에 \(\mathbf J = \sigma\mathbf E\)와 \(\nabla\cdot\mathbf E = \rho/\varepsilon\)을 넣으면 \(\partial\rho/\partial t = -(\sigma/\varepsilon)\rho\)이고, \(\rho = \rho_0e^{-t/\tau}\), \(\tau = \varepsilon/\sigma\)이다. 이 이완 시간이 구리에서 \(10^{-19}\) s 정도라 도체 안의 전하는 순식간에 표면으로 옮겨 간다.

예제 3.5.1

반지름 \(a\)와 \(b\)인 동축 전극 사이를 전도도 \(\sigma\)인 매질이 채운다(길이 \(L\)). 지름 방향 저항을 구하여라.

풀이. 같은 모양의 정전용량은 \(C = 2\pi\varepsilon L/\ln(b/a)\)이다. 그러므로 \(R = \varepsilon/(\sigma C) = \frac{\ln(b/a)}{2\pi\sigma L}\)이다. 직접 계산해도 반지름 \(r\)에서 \(J = I/2\pi rL\), \(E = J/\sigma\)를 \(a\)에서 \(b\)까지 적분해 같은 결과를 얻는다. 동축 케이블 절연체의 누설 저항이 이렇게 계산된다.

마무리

정상 전류는 전류 밀도 \(\mathbf J = \sigma\mathbf E\)와 연속 방정식 \(\nabla\cdot\mathbf J = -\partial\rho/\partial t\)로 다루며, 정상 상태에서는 \(\nabla\cdot\mathbf J = 0\)이다. 저항은 전계와 전류의 적분으로 구하고, 같은 모양에서 \(RC = \varepsilon/\sigma\)이다. 도체 안의 전하는 이완 시간 \(\varepsilon/\sigma\)로 사라진다.

3.5.3연습문제

기본

  1. 바닷물(\(\sigma = 4\) S/m, \(\varepsilon \approx 80\varepsilon_0\))의 이완 시간은?
    답

    \(80\times8.85\times10^{-12}/4 \approx 1.8\times10^{-10}\) s.

응용

  1. 평행판 축전기에 누설이 있는 유전체(\(\sigma\))를 채웠다. 충전된 축전기가 스스로 방전하는 시간 상수를 구하여라.
    답

    \(RC = \varepsilon/\sigma\). 판 넓이와 간격에 무관하다.
