평행판, 동축, 구형 축전기의 정전용량

본문

동축 케이블의 사양서에는 "100 pF/m"처럼 길이당 정전용량이 적혀 있고, 회로 기판의 넓은 구리면도 작은 축전기가 된다. 두 도체의 모양과 간격, 사이를 채운 재료만 알면 정전용량을 계산할 수 있을까? 지구만 한 공은 정전용량이 얼마나 될까?

먼저 알아야 할 것축전기 입문(공통4 4.1절), Gauss 법칙(2.2절), 전위차(2.3절), 경계 조건(3.1절)을 쓴다.

3.2.1정전용량을 구하는 절차

두 도체에 \(+Q\), \(-Q\)를 주었을 때 두 도체 사이 전위차 \(V_0\)에 대한 비 \(C = Q/V_0\)를 정전용량이라 한다. 이 값은 도체의 모양, 간격, 유전체로만 정해지고 Q와 무관하며, 처음 질문의 첫째 답이 이것이다.

계산 절차는 일정하다. 먼저 한 도체에 +Q, 다른 도체에 −Q를 준다. 다음으로 Gauss 법칙으로 두 도체 사이의 \(\mathbf D\)를 구하고 \(\mathbf E = \mathbf D/\epsilon\)로 바꾼다. 그리고 −Q 도체에서 +Q 도체까지 \(V_0 = -\int\mathbf E\cdot d\mathbf L\)을 적분한다. 끝으로 \(C = Q/V_0\)를 구하는데, Q가 약분되는지 확인하면 검산이 된다.

3.2.2세 가지 기본 모양

넓이 A, 간격 d인 평행판에서는 가장자리 효과를 무시하면 판 사이 \(D = Q/A\), \(E = Q/(\epsilon A)\), \(V_0 = Ed\)이다.

\[ C = \frac{\epsilon A}{d}. \]

식처럼 평행판은 넓고 가까울수록 크다. 안 반지름 a, 바깥 b, 길이 L인 동축에서는 \(D_\rho = \frac{Q}{2\pi\rho L}\), \(V_0 = \frac{Q}{2\pi\epsilon L}\ln\frac ba\)이다.

\[ C = \frac{2\pi\epsilon L}{\ln(b/a)}. \]

또 동심구(a < b)에서는 \(D_r = \frac{Q}{4\pi r^2}\), \(V_0 = \frac{Q}{4\pi\epsilon}\left(\frac1a - \frac1b\right)\)이다.

\[ C = \frac{4\pi\epsilon ab}{b - a}, \qquad b \to \infty:\ C = 4\pi\epsilon a\ (\text{고립 구}). \]
예제 3.2.1

(가) 넓이 1 cm², 간격 0.1 mm, \(\epsilon_r = 4\)인 평행판, (나) a = 0.45 mm, b = 1.47 mm, \(\epsilon_r = 2.25\)(폴리에틸렌)인 동축 케이블의 단위 길이당 정전용량, (다) 지구(반지름 6370 km)를 고립 구로 볼 때의 정전용량을 구하여라.

풀이. (가)는 \(C = \frac{4 \times 8.854\times10^{-12} \times 10^{-4}}{10^{-4}} \approx 35.4\) pF이다. (나)는 \(C/L = \frac{2\pi \times 2.25 \times 8.854\times10^{-12}}{\ln(1.47/0.45)} = \frac{1.252\times10^{-10}}{1.184} \approx 106\) pF/m로, 흔한 50 Ω 동축 케이블의 사양(100 pF/m 근처)과 비슷한 크기이다(실제 치수는 제조사 사양서로 확인 필요).

(다)는 \(4\pi\epsilon_0 \times 6.37\times10^6 \approx 709\) μF이다(그림 1). 즉 행성 크기여도 1 mF가 안 되며, 처음 질문의 둘째 답이 이것이다. 그만큼 패럿은 매우 큰 단위이다.

3.2.3여러 유전체

유전체 층이 판과 평행하여 전계가 경계에 수직이면, D가 층마다 같고 전압이 나뉜다. 그래서 직렬 축전기처럼 \(\frac1C = \frac{d_1}{\epsilon_1A} + \frac{d_2}{\epsilon_2A}\)이다. 반면 층이 판에 수직이어서 전계가 경계에 평행하면, E가 같고 넓이가 나뉘므로 병렬 축전기처럼 \(C = \frac{\epsilon_1A_1 + \epsilon_2A_2}{d}\)이다.

예를 들어 넓이 1 cm²에 \(\epsilon_r\) = 2와 6인 층이 각 0.05 mm이면, 각 35.4 pF와 106.2 pF의 직렬이므로 26.6 pF이다. 이때 3.1절 연습 3처럼 유전율이 작은 층에 전계가 세 배 몰린다.

흔한 오해"전압을 올리면 정전용량이 커진다"는 생각은 틀리다. Q도 같은 비율로 커질 뿐 C는 모양과 재료로만 정해진다. 또 동축 공식의 \(\ln(b/a)\)를 \(b/a\)나 \(b - a\)로 쓰는 실수가 흔한데, 전계가 \(1/\rho\)이기 때문에 로그가 나온다. 평행판 공식은 판이 간격보다 훨씬 넓을 때 맞으며, 판이 작으면 가장자리 전계(fringing) 때문에 실제 C가 더 크다.
마무리

정전용량은 두 도체에 ±Q를 가정하고, Gauss 법칙으로 전계를 구해 적분으로 전위차 \(V_0\)를 얻은 뒤 \(C = Q/V_0\)로 구한다. 평행판은 \(\epsilon A/d\), 동축은 \(2\pi\epsilon L/\ln(b/a)\), 동심구는 \(4\pi\epsilon ab/(b - a)\), 고립 구는 \(4\pi\epsilon a\)이다. 여러 유전체가 있으면 판과 평행한 층은 직렬, 판에 수직인 층은 병렬로 계산한다.

3.2.4연습문제

기본

  1. 반지름 10 cm 금속 구의 고립 정전용량과, 1 kV로 대전했을 때 전하는?
    답

    정전용량은 약 11.1 pF이고 전하는 11.1 nC이다.

응용

  1. 공기 동축선(a = 1 mm)에서 C/L = 50 pF/m가 되려면 b는?
    답

    \(\ln(b/a) = 2\pi\epsilon_0/(50\text{ p}) = 1.113\)이므로 \(b \approx 3.04\) mm이다.

  2. 평행판의 절반 넓이만 \(\epsilon_r = 3\) 유전체로 채우면(판에 수직인 경계) 정전용량은 빈 경우의 몇 배인가?
    답

    병렬이므로 \(1 \times 0.5 + 3 \times 0.5 = 2\)배이다.

심화

  1. 동축선에서 바깥 도체를 고정하고 안 도체 반지름 a를 바꿀 때, 정해진 전압에서 안 도체 표면의 전계가 가장 작아지는 a/b를 구하여라.
    힌트

    \(E(a) = \frac{V_0}{a\ln(b/a)}\)를 a에 대해 최소화한다.

    답

    \(a\ln(b/a)\)가 최대가 되어야 하므로 미분해 \(\ln(b/a) - 1 = 0\), 곧 \(b/a = e\)이다. 절연 파괴에 가장 강한 고전압 동축선의 설계 조건이다.
