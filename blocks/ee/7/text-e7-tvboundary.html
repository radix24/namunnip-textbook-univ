시변장의 경계 조건

본문
이 절에서 배울 것
  • Maxwell 방정식의 적분형으로 시변장의 경계 조건 네 개를 유도하고, 정적인 경우와 같은 꼴임을 안다.
  • 완전 도체 표면의 조건(\(E_t = 0\), \(B_N = 0\), \(H_t = K\), \(D_N = \rho_S\))으로 표면 전류와 전하를 구한다.
  • 두 유전체 경계에서 접선 E·H 연속, 법선 D·B 연속을 전자기파 문제에 적용한다.
먼저 알아야 할 것
  • 정전계·정자계 경계 조건 (3.1절, 5.1절), Maxwell 방정식 (6.2절).

6.3.1유도: 시간 미분 항은 사라진다

구하려는 것: 시변장에서 경계 양쪽 장의 관계. 3.1절처럼 경계를 가로지르는 작은 직사각형 고리(높이 Δh → 0)에 Faraday 법칙을 쓰면

\[ (E_{t1} - E_{t2})\Delta w = -\frac{d}{dt}\int\mathbf B\cdot d\mathbf S. \]

오른쪽 면적은 \(\Delta w\Delta h\)이고 Δh → 0이면 (B가 유한한 한) 0이 됩니다. 그래서 정적인 경우와 같은 \(E_{t1} = E_{t2}\)입니다. Ampère-Maxwell 법칙에서도 \(\partial\mathbf D/\partial t\) 항이 같은 이유로 사라지고, 두 Gauss 법칙은 원래 시간 미분이 없습니다.

성분조건근거
접선 E\(E_{t1} = E_{t2}\)Faraday
접선 H\(\mathbf a_{N12}\times(\mathbf H_1 - \mathbf H_2) = \mathbf K\)Ampère-Maxwell
법선 D\(D_{N1} - D_{N2} = \rho_S\)Gauss
법선 B\(B_{N1} = B_{N2}\)자기 Gauss

(\(\mathbf a_{N12}\)는 영역 2에서 1로 향하는 법선.) 유한한 도전율의 두 매질 사이에는 면전류 K가 없고(전류가 0 두께에 몰릴 수 없음), 보통 자유 면전하도 없습니다.

6.3.2완전 도체

완전 도체(\(\sigma \to \infty\)): 내부에 시변장이 들어갈 수 없다(\(\mathbf E = 0\)이고, Faraday 법칙으로 시변 \(\mathbf B\)도 0). 실제 금속은 고주파에서 표피 깊이가 매우 얇아 이 근사가 잘 맞는다.

도체 쪽 장이 0이므로 바깥 표면의 조건은

\[ E_t = 0, \quad B_N = 0, \quad \mathbf a_N\times\mathbf H = \mathbf K, \quad D_N = \rho_S. \]

곧 도체 표면에서 전계는 수직, 자계는 평행이고, 표면 자계의 크기가 표면 전류 밀도, 표면 전계가 표면 전하 밀도를 알려 줍니다.

예제 6.3.1

공기 중에서 진폭 \(E_0 = 1\) V/m인 평면파가 완전 도체 평판(z = 0)에 수직으로 들어와 완전히 반사된다. 표면에서 합성 자계는 입사파 자계 \(H_0 = E_0/\eta_0\)의 두 배이다(\(\eta_0 \approx 377\) Ω). 표면 전류 밀도의 진폭은?

풀이. 표면 합성 자계 \(2H_0 = 2/377 \approx 5.31\) mA/m, 이것이 접선 방향이므로 \(K = 5.31\) mA/m(전계와 같은 방향으로 흐름). 표면에서 접선 전계는 0(입사파와 반사파가 상쇄)입니다. 이 표면 전류가 반사파를 만드는 원천이고, 안테나 반사판과 전자파 차폐의 원리입니다(전전10).

6.3.3두 유전체의 경계

K = 0, \(\rho_S = 0\)이면 접선 E, 접선 H, 법선 D, 법선 B가 모두 연속입니다. 전자기파가 유리 표면에 닿을 때 이 네 조건이 반사파와 투과파의 진폭(Fresnel 식)과 Snell 법칙을 정합니다. 수직 입사에서 반사 계수는 \(\Gamma = \frac{\eta_2 - \eta_1}{\eta_2 + \eta_1}\)(\(\eta = \sqrt{\mu/\epsilon}\))이며, 예를 들어 공기에서 \(\epsilon_r = 4\) 유리로 들어가면 \(\eta_2 = \eta_0/2\)이라 \(\Gamma = -1/3\), 전력의 1/9(약 11%)가 반사됩니다. 유도는 전전10에서 합니다.

흔한 오해(1) "시변장이면 경계 조건도 달라진다": 꼴은 정적인 경우와 같습니다. 달라지는 것은 장 자체입니다. (2) 완전 도체 표면에서 자계가 0이라는 오해: 법선 B가 0이고, 접선 H는 표면 전류만큼 있습니다. (3) 유한 도전율 도체에도 면전류 K를 쓰는 실수: 그때는 전류가 표피 깊이 안에 체적 전류로 흐릅니다.
요약
  1. 시변 경계 조건은 정적인 경우와 같은 꼴: \(E_t\) 연속, \(H_t\)는 K만큼, \(D_N\)은 \(\rho_S\)만큼, \(B_N\) 연속.
  2. 완전 도체: \(E_t = 0\), \(B_N = 0\), \(K = \mathbf a_N\times\mathbf H\), \(\rho_S = D_N\).
  3. 유전체 경계: 네 성분 모두 연속 → 반사·투과(Fresnel).

6.3.4연습문제

기본

  1. 완전 도체 표면(법선 \(\mathbf a_z\)) 바로 위에서 \(\mathbf H = 0.2\mathbf a_x\) A/m이다. 표면 전류는?
    답

    \(\mathbf K = \mathbf a_z\times0.2\mathbf a_x = 0.2\mathbf a_y\) A/m.

응용

  1. 완전 도체 표면 바로 위의 전계가 \(\mathbf E = 50\cos\omega t\,\mathbf a_z\) V/m이면 표면 전하 밀도는?
    답

    \(\rho_S = \epsilon_0 \times 50\cos\omega t \approx 0.443\cos\omega t\) nC/m².

  2. 공기에서 \(\epsilon_r = 9\) 유전체로 수직 입사할 때 반사 계수와 반사 전력 비율은?
    답

    \(\eta_2 = \eta_0/3\), \(\Gamma = (1/3 - 1)/(1/3 + 1) = -0.5\), 전력 25%.

심화

  1. 완전 도체 표면에서 \(E_t = 0\)과 Faraday 법칙만으로 \(B_N\)의 시변 성분이 0임을 보여라.
    답

    표면에 놓인 작은 고리에 Faraday 법칙: \(\oint\mathbf E\cdot d\mathbf L = 0\)(고리 위 접선 E가 0) \(= -\frac{d}{dt}\int B_NdS\). 모든 작은 고리에서 성립하므로 \(\partial B_N/\partial t = 0\).
