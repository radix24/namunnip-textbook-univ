인덕턴스와 자기 에너지

본문
이 절에서 배울 것
  • 인덕턴스를 쇄교 자속 \(L = N\Phi/I\)와 자기 에너지 \(W_H = \frac12LI^2 = \frac12\int\mathbf B\cdot\mathbf H\,dv\) 두 가지로 정의하고 계산한다.
  • 동축선의 단위 길이당 외부 인덕턴스 \(\frac{\mu}{2\pi}\ln\frac ba\)와 내부 인덕턴스 \(\frac{\mu}{8\pi}\)를 유도한다.
  • 동축선의 L과 C로 특성 임피던스와 전파 속도를 구한다.
먼저 알아야 할 것
  • 인덕턴스 입문 (공통4 7.2절), 동축선의 자계 (4.2절), 동축선의 정전용량 (3.2절), 자기 회로 (5.2절).

5.3.1두 가지 정의

쇄교 자속 \(\Lambda = N\Phi\): 회로의 각 감김을 지나는 자속을 모두 더한 것.

인덕턴스 \(L = \Lambda/I\) [H]: 단위 전류당 쇄교 자속. 모양과 재료로만 정해진다.

에너지 정의: 전류 I가 만든 자계에 저장된 에너지 \(W_H = \frac12\int\mathbf B\cdot\mathbf H\,dv = \frac12\int\mu H^2dv\)가 \(\frac12LI^2\)와 같도록 \(L = 2W_H/I^2\).

두 정의는 같은 값을 주지만, 도체 안쪽처럼 전류의 일부만 감싸는 자속이 있으면 쇄교 계산이 헷갈리므로 에너지 정의가 편합니다.

5.3.2동축선의 인덕턴스

외부 인덕턴스(두 도체 사이의 자속). 4.2절에서 \(a < \rho < b\)의 \(B = \frac{\mu I}{2\pi\rho}\). 길이 l, 폭 \(b - a\)인 직사각형 면을 지나는 자속은

\[ \Phi = \int_0^l\int_a^b\frac{\mu I}{2\pi\rho}d\rho\,dz = \frac{\mu Il}{2\pi}\ln\frac ba, \qquad \frac{L_{ext}}{l} = \frac{\mu}{2\pi}\ln\frac ba. \]

내부 인덕턴스(안 도체 속 자속, 전류 균일, 저주파). 에너지로 구합니다: \(H = \frac{I\rho}{2\pi a^2}\)이므로 \(W_H = \frac{\mu}{2}\int_0^a\left(\frac{I\rho}{2\pi a^2}\right)^22\pi\rho l\,d\rho = \frac{\mu I^2l}{16\pi}\), \(L_{int}/l = \frac{\mu}{8\pi}\). 반지름과 무관하게 0.05 μH/m(\(\mu_0\))입니다. 고주파에서는 전류가 표면으로 몰려(표피 효과, 전전10) 내부 인덕턴스가 거의 사라집니다.

예제 5.3.1

(가) a = 1 mm, b = 4 mm 공기 동축선의 단위 길이당 외부·내부 인덕턴스, (나) 3.2절 예제의 폴리에틸렌 동축선(a = 0.45 mm, b = 1.47 mm, \(\epsilon_r = 2.25\), C = 105.7 pF/m)의 외부 인덕턴스, 특성 임피던스 \(Z_0 = \sqrt{L/C}\), 전파 속도 \(1/\sqrt{LC}\)를 구하여라.

풀이.

  • (가) \(L_{ext} = 2\times10^{-7}\ln4 \approx 0.277\) μH/m, \(L_{int} = 0.05\) μH/m.
  • (나) \(L = 2\times10^{-7}\ln(1.47/0.45) \approx 0.237\) μH/m. \(Z_0 = \sqrt{0.237\times10^{-6}/105.7\times10^{-12}} \approx 47.3\) Ω, 속도 \(\approx 2.0\times10^8\) m/s(빛의 2/3, \(1/\sqrt{\epsilon_r} = 1/1.5\)).

고주파에서는 외부 인덕턴스만 쓰므로 \(Z_0 = \frac{1}{2\pi}\sqrt{\frac{\mu}{\epsilon}}\ln\frac ba\)이고, 공기 동축(가)은 \(60\ln4 \approx 83.2\) Ω입니다. 50 Ω 케이블의 치수가 이 식으로 정해집니다(전전10 전송선로).

5.3.3솔레노이드와 상호 인덕턴스

긴 솔레노이드(N회, 길이 l, 단면 A): \(B = \mu NI/l\), \(\Lambda = NBA\), \(L = \frac{\mu N^2A}{l}\). 예: N = 200, l = 10 cm, 반지름 1 cm 공기 코일이면 \(L \approx 158\) μH. 두 회로 사이에서는 한쪽 전류가 다른 쪽에 만드는 쇄교 자속으로 상호 인덕턴스 \(M_{12} = \Lambda_{12}/I_1\)를 정의하며, 늘 \(M_{12} = M_{21}\)입니다(전전3 9.1절의 결합 인덕터).

흔한 오해(1) "인덕턴스는 코일에만 있다": 곧은 도선, 동축선, 회로 기판의 배선 고리도 모두 인덕턴스가 있고, 고속 회로에서는 nH 단위의 이 기생 인덕턴스가 중요합니다. (2) 내부 인덕턴스를 구할 때 안쪽 자속에 N = 1을 그대로 곱하는 실수: 반지름 \(\rho\) 안쪽 자속은 전류의 \(\rho^2/a^2\)만 감싸므로 그 비율을 곱해야 합니다(에너지 방법이 이를 자동으로 처리). (3) 동축선 특성 임피던스를 \(L/C\)로 쓰는 실수: 제곱근입니다.
요약
  1. \(L = N\Phi/I = 2W_H/I^2\), \(W_H = \frac12\int\mu H^2dv\).
  2. 동축: 외부 \(\frac{\mu}{2\pi}\ln\frac ba\), 내부(저주파) \(\frac{\mu}{8\pi}\). 솔레노이드 \(\mu N^2A/l\).
  3. \(Z_0 = \sqrt{L/C}\), 속도 \(1/\sqrt{LC} = c/\sqrt{\epsilon_r}\).

5.3.4연습문제

기본

  1. 예제 5.3.1 (가) 동축선 10 m에 2 A가 흐를 때 저장 자기 에너지(내부 포함)는?
    답

    \(L = 10 \times 0.327 = 3.27\) μH, \(W = \frac12 \times 3.27\times10^{-6} \times 4 \approx 6.5\) μJ.

응용

  1. \(Z_0 = 50\) Ω인 공기 동축선의 b/a는?
    답

    \(60\ln(b/a) = 50\) → \(b/a = e^{0.833} \approx 2.30\).

  2. 토로이드(N = 300, 단면 직사각형: 높이 h = 1 cm, 안 반지름 2 cm, 바깥 3 cm, \(\mu_r = 1\))의 인덕턴스는?
    답

    \(\Phi = \int_a^b\frac{\mu NI}{2\pi\rho}h\,d\rho\), \(L = \frac{\mu N^2h}{2\pi}\ln\frac ba = 2\times10^{-7} \times 9\times10^4 \times 0.01 \times 0.405 \approx 73\) μH.

심화

  1. 평행 2선(반지름 a, 중심 간격 d ≫ a)의 단위 길이당 외부 인덕턴스가 \(\frac{\mu}{\pi}\ln\frac da\)임을 두 도선 사이 평면의 자속으로 보여라.
    답

    한 도선의 자계 \(\frac{\mu I}{2\pi x}\)를 a부터 d − a까지 적분하면 \(\frac{\mu I}{2\pi}\ln\frac{d - a}{a}\). 두 도선이 같은 방향으로 더해져 두 배, \(d \gg a\)에서 \(\frac{\mu}{\pi}\ln\frac da\).
