벡터 퍼텐셜과 자속

본문
이 절에서 배울 것
  • \(\mathbf B = \nabla\times\mathbf A\)로 정의한 벡터 퍼텐셜을 안다.
  • 자속을 \(\Phi = \oint\mathbf A\cdot d\mathbf l\)로 구한다.
  • 자계가 0인 곳에서도 A가 0이 아닐 수 있음을 솔레노이드로 보인다.
먼저 알아야 할 것
  • Stokes 정리 (1.2절), Ampère 법칙 (4.2절).

4.3.1정의와 자속

자계는 발산이 0이므로 어떤 벡터의 회전으로 쓸 수 있습니다: \(\mathbf B = \nabla\times\mathbf A\). Stokes 정리로 면을 지나는 자속은 그 둘레를 따른 A의 선적분입니다.

\[ \Phi = \int_S\mathbf B\cdot d\mathbf S = \oint_C\mathbf A\cdot d\mathbf l, \qquad \mathbf A(\mathbf r) = \frac{\mu_0}{4\pi}\int\frac{\mathbf J\,dv'}{|\mathbf r - \mathbf r'|}. \]
예제 4.3.1

반지름 a = 1 cm, 단위 길이당 1000회, 전류 1 A인 긴 솔레노이드. 안의 B와 자속, 바깥 r = 2 cm에서 A의 크기는?

풀이. \(B = \mu_0nI = 1.257\times10^{-3}\) T, \(\Phi = B\pi a^2 = 3.95\times10^{-7}\) Wb. 바깥에서는 B = 0이지만, 반지름 r인 원을 따라 \(\oint\mathbf A\cdot d\mathbf l = 2\pi rA_\phi = \Phi\)이므로 \(A_\phi = \Phi/(2\pi r) = 3.14\times10^{-6}\) Wb/m입니다.

A는 자계가 없는 곳에서도 0이 아니어서, 양자역학에서는 전자가 B = 0인 영역만 지나도 간섭 무늬가 A에 따라 바뀝니다(Aharonov-Bohm 효과, 확인 필요: 실험 세부).

흔한 오해(1) "B = 0이면 A = 0": 위 예처럼 아닙니다. (2) "A는 하나로 정해진다": 어떤 함수의 기울기를 더해도 같은 B를 주므로, 보통 \(\nabla\cdot\mathbf A = 0\)(쿨롱 게이지)으로 정합니다.
요약
  1. B = ∇ × A, Φ = ∮A·dl.
  2. A = (μ₀/4π)∫J dv'/R(전위와 같은 꼴).
  3. 솔레노이드 밖: B = 0, A_φ = Φ/(2πr).

4.3.2연습문제

기본

  1. 자속 4 × 10⁻⁷ Wb, r = 0.1 m 원 위의 A_φ는?
    답

    약 6.37 × 10⁻⁷ Wb/m.

응용

  1. A = B₀x ŷ의 B는?
    답

    ∇ × A = B₀ ẑ(균일 자계).

심화

  1. A = −(B₀y/2) x̂ + (B₀x/2) ŷ도 같은 B를 주는가?
    답

    예, B₀ ẑ로 같습니다(게이지가 다름).
