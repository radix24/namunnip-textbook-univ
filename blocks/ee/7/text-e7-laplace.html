Poisson·Laplace 방정식으로 전위 구하기

본문

실제 장치에서 우리가 정하는 것은 도체의 전하가 아니라 전원에 연결한 전극의 전압이다. 전극 표면에 전하가 어떻게 퍼질지는 미리 알 수 없다. 전압만 주어졌을 때 그 사이 공간의 전위를 어떻게 구할 수 있을까? 컴퓨터는 이런 문제를 어떤 규칙으로 풀까?

먼저 알아야 할 것Gauss 법칙 미분형(2.2절), 전위(2.3절), 정전용량(3.2절), 상미분방정식(공통8 1.1절)을 쓴다.

3.3.1왜 미분방정식으로 바꾸는가

지금까지는 전하 분포를 알고 전계를 구했다. 그러나 실제 문제에서는 전원에 연결된 전극의 전압처럼 도체의 전위가 주어지고, 도체 표면의 전하 분포는 모른다. 그래서 이때는 전위가 만족하는 미분방정식을 경계 조건과 함께 푼다.

구하려는 것은 V가 만족하는 방정식이다. 균일한 \(\epsilon\)에서 \(\nabla\cdot\mathbf D = \rho_v\)에 \(\mathbf D = \epsilon\mathbf E = -\epsilon\nabla V\)를 넣으면 다음을 얻는다.

\[ \nabla^2V = -\frac{\rho_v}{\epsilon}\ (\text{Poisson}), \qquad \rho_v = 0:\ \nabla^2V = 0\ (\text{Laplace}). \]

식의 라플라시안은 직교 좌표에서 \(\frac{\partial^2V}{\partial x^2} + \frac{\partial^2V}{\partial y^2} + \frac{\partial^2V}{\partial z^2}\)이다. 원통 좌표에서 \(\rho\)에만 의존하면 \(\frac1\rho\frac{d}{d\rho}\left(\rho\frac{dV}{d\rho}\right)\), 구 좌표에서 r에만 의존하면 \(\frac1{r^2}\frac{d}{dr}\left(r^2\frac{dV}{dr}\right)\)이다.

여기서 유일성 정리가 중요하다. 영역 경계의 전위(또는 법선 전계)가 정해지면 Laplace, Poisson 방정식의 해는 하나뿐이다. 그래서 추측, 대칭, 영상법 등 어떤 방법으로든 방정식과 경계 조건을 만족하는 해를 찾으면 그것이 답이며, 처음 질문의 첫째 답이 이것이다.

3.3.21차원 Laplace 문제

V가 좌표 하나에만 의존하면 상미분방정식을 두 번 적분하고, 두 경계 조건으로 적분 상수 둘을 정한다. 평행판(\(V(0) = 0\), \(V(d) = V_0\))은 \(V'' = 0\)이므로 \(V = V_0x/d\)이고, 전계는 \(E = -V_0/d\)로 +x 쪽 판에서 −x 쪽으로 향한다. 동축(\(V(a) = V_0\), \(V(b) = 0\))은 \(\frac{d}{d\rho}(\rho V') = 0\)에서 \(V = A\ln\rho + B\)이므로 \(V = V_0\frac{\ln(b/\rho)}{\ln(b/a)}\)이다. 또 동심구(\(V(a) = V_0\), \(V(b) = 0\))는 \(r^2V'\)이 상수이므로 \(V = V_0\frac{1/r - 1/b}{1/a - 1/b}\)이다.

이 전위에서 도체 표면의 \(D_N = \rho_S\)를 구하고 넓이를 곱해 Q를 얻으면, \(C = Q/V_0\)가 3.2절과 같은 결과로 나온다. 예를 들어 동축에서 \(E_\rho(a) = \frac{V_0}{a\ln(b/a)}\)이고 \(Q = \epsilon E_\rho(a)\cdot2\pi aL\)이므로 \(C = \frac{2\pi\epsilon L}{\ln(b/a)}\)이다.

3.3.3Poisson 문제: 공간 전하가 있을 때

예제 3.3.1

간격 d = 1 cm인 평행판 사이(\(\epsilon_0\))에 균일한 공간 전하 \(\rho_v = 1\) μC/m³가 있다. \(V(0) = 0\), \(V(d) = 100\) V일 때 \(V(x)\), 가운데 전위, 두 판에서의 전계를 구하여라.

풀이. \(V'' = -\rho_v/\epsilon_0\)를 두 번 적분하면 \(V = -\frac{\rho_v}{2\epsilon_0}x^2 + Ax + B\)이다. \(V(0) = 0\)에서 B = 0이고, \(V(d) = 100\)에서 \(A = \frac{100 + \rho_vd^2/(2\epsilon_0)}{d}\)이다. \(\rho_vd^2/(2\epsilon_0) = 5.65\) V이므로 \(A = 10{,}565\) V/m이다. 그러면 가운데 전위는 \(V(d/2) = 50 + \rho_vd^2/(8\epsilon_0) = 51.41\) V로, 전하가 없을 때의 50 V보다 높다.

전계 \(E = -V'\)은 x = 0에서 \(-10{,}565\) V/m, x = d에서 \(-9{,}435\) V/m이다. 두 값의 차이 \(\rho_vd/\epsilon_0 = 1130\) V/m가 사이 전하의 몫이며, Gauss 법칙과 일치한다. 반도체 pn 접합의 공핍 영역, 곧 이온화된 도펀트가 공간 전하인 영역이 바로 이 Poisson 문제이고, 전전15와 전전27에서 접합 전위와 공핍 폭을 이렇게 구한다.

3.3.42차원 문제와 수치 해법

전위가 두 좌표에 의존하면 변수 분리(Fourier 급수)로 풀 수 있지만, 모양이 복잡하면 수치 해법이 실용적이다. Laplace 방정식을 격자에서 차분으로 쓰면 다음과 같다.

\[ V_{i,j} = \frac14\left(V_{i+1,j} + V_{i-1,j} + V_{i,j+1} + V_{i,j-1}\right) \]

식은 각 점의 전위가 이웃 네 점의 평균이라는 뜻이다. 그래서 경계 값을 고정하고 내부 점을 이 평균으로 되풀이해 바꾸면(이완법) 해로 수렴하며, 처음 질문의 둘째 답이 이 규칙이다. 예를 들어 정사각형 홈의 윗변만 \(V_0\)이고 나머지 세 변이 0이면 가운데 전위는 정확히 \(V_0/4\)이다(그림 1). 네 변을 돌아가며 \(V_0\)로 둔 네 문제를 합하면 모든 변이 \(V_0\)인 문제, 곧 어디서나 \(V_0\)인 해가 되기 때문이다. 이 절의 탐구 카드에서 이완이 이 값에 다가가는 모습을 본다.

흔한 오해"Laplace 방정식이 성립하면 전계가 0이다"는 생각은 틀리다. 전하가 없을 뿐 전위의 2차 도함수 합이 0이라는 뜻이며, 평행판 사이에도 전계는 있다. 또 원통이나 구 좌표의 라플라시안을 \(V''\)로 쓰면 면적이 반지름에 따라 커지는 효과(\(\rho\), \(r^2\))가 빠진다. 한편 Laplace 방정식의 해에는 평균 성질 때문에 내부 극대나 극소가 없으므로, 전하 없는 공간 안에 전하를 안정하게 가둘 수 없다(Earnshaw 정리).
마무리

전위는 Poisson 방정식 \(\nabla^2V = -\rho_v/\epsilon\)과, 전하가 없으면 Laplace 방정식 \(\nabla^2V = 0\)을 만족하며, 경계 조건이 해를 하나로 정한다. 1차원 해는 평행판에서 선형, 동축에서 \(\ln\rho\), 동심구에서 \(1/r\)이고, 표면의 D로 Q를 구하면 정전용량을 다시 얻는다. 격자에서는 각 점이 이웃의 평균이므로 이완법으로 수치 해를 구한다.

3.3.5연습문제

기본

  1. 동축선(a = 1 mm, b = 5 mm, 안 도체 10 V, 바깥 0 V)에서 \(\rho = 2\) mm의 전위는?
    답

    \(10\ln(5/2)/\ln5 = 10 \times 0.916/1.609 \approx 5.69\) V이다.

응용

  1. 동심구(a = 1 cm, b = 3 cm, 안 100 V, 바깥 0 V)의 r = 2 cm 전위와 r = a의 전계는?
    답

    \(V = 100\frac{50 - 33.3}{100 - 33.3} = 25\) V이다. \(V = A/r + B\)에서 \(A = 100/(100 - 33.3) = 1.5\) V·m이므로 \(E(a) = A/a^2 = 15{,}000\) V/m이다.

  2. 예제 3.3.1에서 \(\rho_v\)를 얼마로 하면 x = 0의 전계가 0이 되는가?
    답

    A = 0이어야 하므로 \(100 + \rho_vd^2/(2\epsilon_0) = 0\)에서 \(\rho_v = -2\epsilon_0 \times 100/d^2 \approx -17.7\) μC/m³(음전하)이다.

심화

  1. 정사각형 홈에서 윗변 \(V_0\), 왼쪽 변 \(2V_0\), 나머지 0일 때 가운데 전위를 유일성과 중첩으로 구하여라.
    답

    각 변 하나만 \(V_0\)인 문제의 가운데 값이 \(V_0/4\)이므로 \(V_0/4 + 2V_0/4 = 0.75V_0\)이다.
