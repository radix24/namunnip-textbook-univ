직교 신호 만들기

정규직교화 · 신호

출발점

표본 벡터로 나타낸 신호도 Gram-Schmidt로 직교 기저를 만들 수 있습니다(3.3절, 전전21 3.1절).

문제 해결 전략 · 신호 공간 기저
  1. 두 신호를 표본 벡터로 쓴다.
  2. 첫 신호를 정규화한다.
  3. 둘째에서 첫째 성분을 빼고 정규화한다.

s₁ = (1, 1, 1, 1), s₂ = (1, 1, 0, 0)로 정규직교 기저를 만들고 s₂의 좌표를 구하라.

풀이

  1. φ₁ = (1, 1, 1, 1)/2.
    ‖s₁‖ = 2.
  2. φ₁ᵀs₂ = 1 → v = (0.5, 0.5, −0.5, −0.5), φ₂ = v(‖v‖ = 1).
    빼기.
  3. s₂ = 1·φ₁ + 1·φ₂ → 좌표 (1, 1).
    신호 공간의 점.

의미

통신 수신기는 이렇게 만든 기저로 받은 신호를 몇 개의 숫자(좌표)로 줄여 판정한다.

검산

1·(0.5, 0.5, 0.5, 0.5) + (0.5, 0.5, −0.5, −0.5) = (1, 1, 0, 0).
