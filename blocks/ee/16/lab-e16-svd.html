SVD로 가상 영상 압축하기

실습 · 순위 k 근사와 저장량

목표

64×64 가상 영상의 SVD로 순위 k 근사를 만들고 상대 오차와 저장량을 비교합니다. 성취기준 [전전16-05-01].

준비

NumPy가 필요합니다(pip install numpy). 아래 코드를 svd_compress.py로 저장합니다.

# SVD로 영상 압축하기: 순위 k 근사의 오차와 저장량
import numpy as np

# 64×64 가상 영상: 부드러운 그라데이션 + 원 + 가로 줄무늬 + 약한 잡음
n = 64
y, x = np.mgrid[0:n, 0:n] / n
img = 0.5 * x + 0.3 * y
img += 0.8 * (((x - 0.6) ** 2 + (y - 0.4) ** 2) < 0.04)
img += 0.2 * np.sin(2 * np.pi * 8 * y)
rng = np.random.default_rng(0)
img += 0.02 * rng.standard_normal((n, n))

U, s, Vt = np.linalg.svd(img)
print("가장 큰 특이값 5개:", np.round(s[:5], 3))
total = np.sum(s ** 2)
for k in (1, 2, 5, 10, 20):
    Ak = (U[:, :k] * s[:k]) @ Vt[:k, :]
    err = np.linalg.norm(img - Ak) / np.linalg.norm(img)
    energy = np.sum(s[:k] ** 2) / total
    store = k * (n + n + 1)
    print(f"k = {k:2d}: 상대 오차 {err:.4f}, 에너지 {energy * 100:6.2f}%, 저장 수 {store:5d} (원본 {n * n}, 비율 {store / (n * n):.3f})")

# 오차 = 버린 특이값들의 제곱합의 제곱근(Eckart-Young)
k = 5
print("k = 5 오차 검산:", round(float(np.sqrt(np.sum(s[k:] ** 2)) / np.linalg.norm(img)), 4))

절차

  1. 실행해 표를 적습니다.
  2. k = 1과 k = 2의 상대 오차 차이가 큰 이유를 둘째 특이값으로 설명합니다.
  3. 잡음 세기 0.02를 0.2로 키우면 표가 어떻게 바뀔지 예측하고 확인합니다.
