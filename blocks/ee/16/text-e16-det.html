행렬식과 가역성

본문
이 절에서 배울 것
  • 행렬식의 세 기본 성질(단위 행렬 1, 행 교환 시 부호 반전, 각 행에 선형)을 안다.
  • 삼각 행렬의 행렬식이 대각 원소의 곱임을 이용해 소거로 계산한다.
  • det A ≠ 0 ⇔ 가역 ⇔ Ax = 0의 해가 0뿐임을 연결한다.
먼저 알아야 할 것
  • LU 분해 (1.1절).

1.2.1성질과 계산

행렬식은 (1) det I = 1, (2) 두 행을 바꾸면 부호가 바뀜, (3) 한 행에 대해 선형인 함수로 정해집니다. 여기서 "한 행의 배수를 다른 행에서 빼도 값이 그대로", "det AB = det A det B", "삼각 행렬은 대각 곱"이 나옵니다. 그래서 소거로 U를 만들면 \(\det A = \pm(\text{피벗의 곱})\)(행 교환 횟수만큼 부호).

예제 1.2.1

1.1절 예제 A의 행렬식과, 세 번째 행을 첫 행 + 둘째 행으로 바꾼 행렬의 행렬식은?

풀이. 피벗 2, −8, 1 → det A = −16. 셋째 행이 앞 두 행의 합이면 소거에서 셋째 행이 모두 0이 되어 피벗이 0 → det = 0, 가역이 아닙니다. 이때 Ax = 0에 0 아닌 해가 있습니다(열들이 일차 종속).

기하적으로 |det A|는 단위 정사각형(정육면체)이 A로 옮겨진 평행사변형(평행육면체)의 넓이(부피)입니다. 0이면 공간이 납작해집니다(5.1절 탐구 카드).

흔한 오해(1) "det(A + B) = det A + det B": 성립하지 않습니다. (2) "행렬식이 작으면 거의 특이하다": 크기는 단위에 따라 바뀌므로, 거의 특이한지는 조건수(가장 큰 특이값/가장 작은 특이값)로 판단합니다.
요약
  1. det = ±피벗의 곱(소거로 계산).
  2. det A ≠ 0 ⇔ 가역 ⇔ 열이 일차 독립.
  3. |det| = 부피 배율. 특이성 판단은 조건수로.

1.2.3연습문제

기본

  1. \(\begin{pmatrix} 3 & 1 \\ 6 & 2 \end{pmatrix}\)의 행렬식과 가역성은?
    답

    0, 가역 아님(둘째 행 = 2 × 첫 행).

응용

  1. det A = 4인 3×3에서 det(2A)와 det(A⁻¹)는?
    답

    2³ × 4 = 32, 1/4.

심화

  1. det(AB) = det A det B를 써서 직교 행렬 Q(QᵀQ = I)의 행렬식이 ±1임을 보이라.
    답

    det Qᵀ det Q = (det Q)² = 1.
