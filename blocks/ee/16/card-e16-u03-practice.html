직교성 연습 문제

문제 8 · 계산·개념·판단·도전 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산점 (0, 0), (1, 1), (2, 1)에 맞춘 직선 C + Dt는? [03-01]

    힌트 1

    AᵀA = [[3,3],[3,5]], Aᵀb = (2, 3).

    힌트 2

    풀이

    D = 0.5, C = 1/6.

  2. 계산(1, 2) 방향으로 b = (3, 1)의 정사영은? [03-01]

    힌트 1

    (aᵀb/aᵀa)a.

    힌트 2

    풀이

    (5/5)(1, 2) = (1, 2).

  3. 계산(1, 1)과 (1, 2)를 Gram-Schmidt하면? [03-02]

    힌트 1

    q₁ = (1,1)/√2.

    힌트 2

    풀이

    q₂ = (−1, 1)/√2.

  4. 개념QR로 최소제곱을 풀면 정규 방정식보다 좋은 점은? [03-02]

    힌트 1

    조건수.

    힌트 2

    풀이

    AᵀA를 만들면 조건수가 제곱되어 오차가 커지지만, QR은 그것을 피합니다.

  5. 판단학생이 측정 10개에 9차 다항식을 맞춰 오차 0을 얻고 좋은 모형이라 했다. 평가하세요. [03-01]

    힌트 1

    과적합.

    힌트 2

    풀이

    잡음까지 맞춘 것이라 새 자료에는 크게 틀립니다. 낮은 차수와 검증 자료로 평가해야 합니다.

  6. 도전센서 출력 v = a·x + b를 x = 0, 1, 2, 3에서 v = 0.1, 1.1, 1.9, 3.1로 쟀다. 최소제곱 a, b는? [03-01]

    힌트 1

    평균 이용.

    힌트 2

    풀이

    x 평균 1.5, v 평균 1.55. a = Σ(x−x̄)(v−v̄)/Σ(x−x̄)² = 4.9/5 = 0.98, b = 1.55 − 1.47 = 0.08.

  7. 계산a₁ = (2, 0, 0), a₂ = (1, 3, 0)의 q₂는? [03-03]

    힌트 1

    힌트 2

    풀이

    (0, 1, 0).

  8. 계산R(45°)(1, 0)은? [03-04]

    힌트 1

    힌트 2

    풀이

    (0.707, 0.707).
