조건수와 수치 오차

본문
이 절에서 배울 것
  • 조건수 \(\kappa(A) = \|A\|\|A^{-1}\|\)의 뜻을 안다.
  • 자료의 작은 오차가 해에서 κ배까지 커질 수 있음을 수치로 보인다.
  • 나쁜 조건의 원인(거의 평행한 열)과 대책을 안다.
먼저 알아야 할 것
  • 역행렬 (1.3절), 노름.

1.4.1작은 흔들림, 큰 변화

\(\frac{\|\delta x\|}{\|x\|} \le \kappa(A)\frac{\|\delta b\|}{\|b\|}\). 두 식이 거의 같은 직선이면(열이 거의 평행) κ가 커서, 측정 오차가 해를 크게 흔듭니다.

import numpy as np
A = np.array([[1.0, 1.0], [1.0, 1.0001]])
print("조건수:", round(np.linalg.cond(A)))
for b in ([2.0, 2.0001], [2.0, 2.0002]):
    print("b =", b, "→ x =", np.round(np.linalg.solve(A, b), 6))

실행 결과(Python 3.12에서 실제 실행):

조건수: 40002
b = [2.0, 2.0001] → x = [1. 1.]
b = [2.0, 2.0002] → x = [0. 2.]
예제 1.4.1

위에서 b의 둘째 성분이 0.0001(상대 0.005%) 바뀌었을 때 해는 얼마나 바뀌었는가?

풀이. 해가 (1, 1)에서 (0, 2)로 바뀌어 상대 변화가 100% 정도입니다. κ ≈ 4×10⁴이라 0.005% × 4×10⁴ = 200%까지 커질 수 있다는 한계와 맞습니다. 측정 기반 모형(최소제곱)에서 열을 정규화하거나 정규화(전전20 2.1절)로 조건을 개선합니다.

흔한 오해(1) "수치 오차는 컴퓨터 정밀도 문제일 뿐": 문제 자체(κ)가 오차를 키웁니다. (2) "행렬식이 작으면 조건이 나쁘다": 크기 조정에 따라 바뀌어 기준이 아니고, κ로 판단합니다.
요약
  1. κ = ‖A‖‖A⁻¹‖, 상대 오차 증폭 상한.
  2. 예: κ 4×10⁴ → 0.005% 변화가 해를 100% 바꿈.
  3. 원인: 거의 평행한 열. 대책: 정규화·재설계.
