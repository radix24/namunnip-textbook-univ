최소제곱으로 자료에 모형 맞추기

본문
이 절에서 배울 것
  • 해가 없는 Ax = b에서 오차 제곱합을 최소로 하는 x̂을 정규 방정식 \(A^TA\hat{\mathbf x} = A^T\mathbf b\)로 구한다.
  • 기하적으로 b를 열공간에 정사영한 것임을 안다.
  • 직선·다항식 맞춤과 측정 자료(센서 보정)에 적용한다.
먼저 알아야 할 것
  • 네 부분공간과 직교 (2.1절), 공분산과 평균 (전전11 3.1절).

3.1.1정규 방정식

측정이 모형보다 많으면 Ax = b(m > n)는 보통 해가 없습니다. \(\|A\mathbf x - \mathbf b\|^2\)을 최소로 하는 x̂는 오차 \(\mathbf e = \mathbf b - A\hat{\mathbf x}\)가 열공간과 직교할 때, 곧 \(A^T\mathbf e = 0\)일 때입니다.

\[ A^TA\hat{\mathbf x} = A^T\mathbf b, \qquad \mathbf p = A\hat{\mathbf x} = A(A^TA)^{-1}A^T\mathbf b. \]
예제 3.1.1

시각 t = 0, 1, 2의 측정 b = 6, 0, 0에 직선 b = C + Dt를 맞춰라.

풀이. \(A = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \end{pmatrix}\), \(A^TA = \begin{pmatrix} 3 & 3 \\ 3 & 5 \end{pmatrix}\), \(A^T\mathbf b = (6, 0)\). 풀면 C = 5, D = −3. 맞춘 값 5, 2, −1, 오차 1, −2, 1(합 0, 제곱합 6). 오차 벡터가 두 열 (1,1,1), (0,1,2)와 직교함을 확인할 수 있습니다.

센서 보정(입력-출력 직선의 기울기와 오프셋), 다항식 맞춤, 채널 추정이 모두 같은 계산입니다. \(A^TA\)가 거의 특이하면(다항식 차수가 높을 때) 오차가 커지므로 QR(3.2절)로 풉니다.

흔한 오해(1) "최소제곱 직선은 모든 점을 지난다": 오차 제곱합이 최소일 뿐입니다. (2) "차수를 높이면 언제나 좋은 모형이다": 측정 잡음까지 맞추는 과적합이 생깁니다. (3) 수직 거리의 제곱합이지 점과 직선의 수직 거리(전체 최소제곱)가 아닙니다.
요약
  1. \(A^TA\hat x = A^Tb\): 오차가 열공간에 직교.
  2. b의 열공간 정사영 \(p = A\hat x\).
  3. 직선·다항식 맞춤, 센서 보정. 조건이 나쁘면 QR.

3.1.2연습문제

기본

  1. 점 (0, 1), (1, 3), (2, 5)에 맞춘 직선은?
    답

    모두 직선 위에 있어 b = 1 + 2t, 오차 0.

응용

  1. 예제에서 오차 (1, −2, 1)이 열 (1,1,1), (0,1,2)와 직교함을 확인하라.
    답

    1 − 2 + 1 = 0, 0 − 2 + 2 = 0.

심화

  1. 상수 모형 b = C(모든 측정의 평균)을 정규 방정식으로 유도하라.
    답

    A = (1, …, 1)ᵀ, \(A^TA = m\), \(A^Tb = \sum b_i\), C = 평균.
