계수와 해의 존재·유일성

본문
이 절에서 배울 것
  • 계수 r로 Ax = b의 해가 없음, 하나, 무수히 많음을 판정한다.
  • \(\text{rank}[A\mid b]\)와 rank A를 비교한다.
  • 자유 변수 수 n − r과 해 공간을 안다.
먼저 알아야 할 것
  • 네 기본 부분공간 (2.1절).

2.4.1세 경우

m×n 행렬 A의 계수가 r일 때: \(\text{rank}[A\mid b] > r\)이면 해가 없고(b가 열 공간 밖), 같으면 해가 있으며 n − r개의 자유 변수만큼 해가 퍼집니다(r = n이면 유일).

예제 2.4.1

A = [[1, 2, 3], [2, 4, 6], [1, 1, 1]]. 계수는? b = (6, 12, 3)과 (6, 11, 3)의 해는?

풀이. 둘째 행이 첫째의 2배라 r = 2. b = (6, 12, 3)은 둘째 성분이 첫째의 2배라 열 공간 안 → 자유 변수 3 − 2 = 1개, 해 직선(예: x = (0, 3, 0) + t(1, −2, 1)). b = (6, 11, 3)은 모순(2 × 6 ≠ 11) → 해 없음(최소제곱으로 근사).

흔한 오해(1) "식이 변수만큼 있으면 해가 하나": 계수가 모자라면 아닙니다. (2) "해가 없으면 문제가 잘못": 측정 자료에서는 흔하며 최소제곱으로 풉니다(3.1절).
요약
  1. r = rank A, rank[A|b] > r → 해 없음.
  2. 같으면 해 있음, 자유 변수 n − r.
  3. r = n이면 유일.

2.4.2연습문제

기본

  1. 3×3 행렬 계수 3이면 Ax = b의 해는?
    답

    모든 b에 대해 하나.

응용

  1. 2×4 행렬(계수 2)의 해 공간 차원은?
    답

    2(자유 변수).

심화

  1. 회로에서 계수가 모자란 노드 방정식이 생기는 경우는?
    답

    기준(접지) 노드를 정하지 않아 방정식이 서로 종속일 때.
