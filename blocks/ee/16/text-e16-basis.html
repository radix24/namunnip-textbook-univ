기저 변환과 좌표

본문

같은 화살표도 어떤 자를 대느냐에 따라 좌표가 달라진다. 가로세로 격자 대신 비스듬한 두 벡터를 기준으로 삼으면 벡터 (3, 1)의 좌표는 무엇이 될까? 또 같은 변환이 기준을 바꾸면 더 단순한 행렬이 될 수도 있을까?

먼저 알아야 할 것선형변환의 행렬(2.2절)을 쓴다.

2.3.1좌표는 기저에 따라

기저 벡터를 열로 모은 행렬을 P라 하자. 새 기저로 쓴 좌표가 c이면, 그 벡터는 \(x = c_1\mathbf b_1 + c_2\mathbf b_2 + \cdots = Pc\)이다. 그러므로 표준 좌표 x에서 새 좌표는 \(c = P^{-1}x\)로 구한다. 처음 질문의 첫째 답이 이것이다.

변환도 기저에 따라 행렬이 달라진다. 같은 선형변환이 표준 기저에서 A이면, 새 기저에서는 새 좌표를 표준 좌표로 바꾸고(P), 변환하고(A), 다시 새 좌표로 돌아오므로(P⁻¹) \(P^{-1}AP\)이다. 이렇게 기저만 바꾼 두 행렬을 닮은 행렬이라 한다.

특히 고유벡터를 기저로 고르면 변환이 각 기저 방향을 늘이기만 하므로 대각 행렬이 된다(4.1절). 처음 질문의 둘째 답이 이것으로, 기준을 잘 고르면 변환이 가장 단순해진다.

예제 2.3.1

기저 b₁ = (1, 1), b₂ = (1, −1)에서 v = (3, 1)의 좌표는? 이 기저에서 x축 반사 [[1, 0], [0, −1]]의 행렬은?

풀이. P = [[1, 1], [1, −1]]이므로 c = P⁻¹v = (2, 1)이고, 실제로 v = 2b₁ + b₂이다(그림 1). 또 P⁻¹AP = [[0, 1], [1, 0]]인데, x축 반사가 b₁ = (1, 1)을 (1, −1) = b₂로, b₂를 b₁로 보내기 때문이다. 즉 이 기저에서 반사는 두 좌표를 맞바꾸는 변환이다.

신호 처리의 Fourier 변환도 같은 생각이다. 시간 표본으로 된 신호를 정현파 기저의 좌표로 바꾸는 기저 변환이며, 이 기저에서는 선형 시불변 시스템이 대각 행렬처럼 각 주파수 성분을 따로 곱하기만 한다.

흔한 실수새 좌표를 구할 때 c = Px로 곱하는 실수가 흔하다. P는 새 좌표를 표준 좌표로 바꾸는 행렬이어서, 거꾸로 표준 좌표에서 새 좌표로 가려면 P⁻¹을 곱해야 한다. 기저가 정규직교이면 P⁻¹ = Pᵀ이므로 각 좌표를 기저 벡터와의 내적으로 바로 얻는다(연습문제 3).
마무리

표준 좌표와 새 좌표는 x = Pc, c = P⁻¹x로 바꾼다. 기저를 바꾼 변환 행렬은 닮은 행렬 P⁻¹AP이다. 고유벡터를 기저로 하면 대각화되며, Fourier 변환도 기저 변환이다.

2.3.2연습문제

기본

  1. 기저 (2, 0), (0, 3)에서 (4, 6)의 좌표는?
    답

    (2, 2)이다.

응용

  1. 닮음 행렬은 무엇이 같은가?
    답

    고유값, 행렬식, 대각합이 같다.

심화

  1. 정규직교 기저에서 좌표를 구하는 간단한 방법은?
    답

    P⁻¹ = Pᵀ이므로 c_i = b_iᵀx로 내적만 하면 된다.
