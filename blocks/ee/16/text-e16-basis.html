기저 변환과 좌표

본문
이 절에서 배울 것
  • 같은 벡터를 다른 기저에서 좌표로 나타낸다.
  • 기저 행렬 P로 좌표 변환 \(x = Pc\), \(c = P^{-1}x\)를 쓴다.
  • 선형변환의 행렬이 \(P^{-1}AP\)로 바뀜을 안다.
먼저 알아야 할 것
  • 선형변환의 행렬 (2.2절).

2.3.1좌표는 기저에 따라

기저 벡터를 열로 모은 P에 대해 표준 좌표 x와 새 좌표 c는 \(x = Pc\)입니다. 같은 선형변환이 표준 기저에서 A면 새 기저에서는 \(P^{-1}AP\)입니다. 고유벡터를 기저로 고르면 대각 행렬이 됩니다(4.1절).

예제 2.3.1

기저 b₁ = (1, 1), b₂ = (1, −1)에서 v = (3, 1)의 좌표는? 이 기저에서 x축 반사 [[1, 0], [0, −1]]의 행렬은?

풀이. P = [[1, 1], [1, −1]], c = P⁻¹v = (2, 1)(v = 2b₁ + b₂). P⁻¹AP = [[0, 1], [1, 0]](b₁과 b₂를 맞바꿈). 신호 처리의 Fourier 변환도 '정현파 기저로의 좌표 변환'입니다.

흔한 오해(1) "좌표가 바뀌면 벡터가 바뀐다": 같은 벡터를 다른 자로 잴 뿐입니다. (2) "새 기저의 행렬은 PAP⁻¹": 순서가 P⁻¹AP입니다(정의에 따라 확인).
요약
  1. x = Pc, c = P⁻¹x.
  2. 변환 행렬: P⁻¹AP(닮음).
  3. 고유 기저 → 대각화, Fourier = 기저 변환.

2.3.2연습문제

기본

  1. 기저 (2, 0), (0, 3)에서 (4, 6)의 좌표는?
    답

    (2, 2).

응용

  1. 닮음 행렬은 무엇이 같은가?
    답

    고유값, 행렬식, 대각합.

심화

  1. 정규직교 기저에서 좌표를 구하는 간단한 방법은?
    답

    c_i = b_iᵀx(P⁻¹ = Pᵀ).
