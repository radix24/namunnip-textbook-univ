화학 반응식 맞추기

영공간

출발점

균형 맞춘 계수는 원자 보존 행렬의 영공간입니다(2.4절).

문제 해결 전략 · Ax = 0
  1. 원소별 보존식을 행렬로 쓴다.
  2. 계수와 자유 변수 수를 구한다.
  3. 가장 작은 정수 해를 고른다.

aCH₄ + bO₂ → cCO₂ + dH₂O의 계수를 구하라.

풀이

  1. C: a = c, H: 4a = 2d, O: 2b = 2c + d.
    보존식 3개, 변수 4개.
  2. 계수 3 → 자유 변수 1개.
    해 직선.
  3. a = 1: c = 1, d = 2, b = 2.
    CH₄ + 2O₂ → CO₂ + 2H₂O.

의미

영공간의 차원이 1이라 비율만 정해지고, 정수로 맞추는 것은 화학의 관례이다.

검산

O: 2 × 2 = 2 × 1 + 2.
