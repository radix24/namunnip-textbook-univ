원이 타원이 되는 모습으로 보는 고유값과 특이값

탐구 · 2×2 행렬 하나를 손으로 바꾸기

질문

행렬은 단위 원을 어떤 모양으로 바꿀까? 고유벡터와 특이값은 그 그림의 어디에 있을까?

준비

2×2 행렬의 네 원소를 바꾸며 단위 원(회색 점선)의 상(파란 타원)을 그린다. 실수 고유값이 있으면 고유벡터 직선과 λ배 화살표(빨강, 주황)를, 특이값은 타원의 긴·짧은 반지름으로 출력합니다(4.2절, 5.1절).

해 보기와 설명

  1. 처음 화면\(\begin{pmatrix} 3 & 0 \\ 4 & 5 \end{pmatrix}\): 고유값 5, 3, 특이값 6.708, 2.236, det 15(예제 5.1.1). 고유벡터 방향과 타원 축이 다르다.
  2. 대칭 행렬a = 2, b = c = 1, d = 2로 하면 고유값 3, 1이 특이값과 같고, 고유벡터가 타원의 축과 일치합니다(4.2절).
  3. 회전a = 0, b = −1, c = 1, d = 0(90° 회전): 원이 그대로 원, 특이값 1, 1, 고유값 ±j(복소수).
  4. 특이a = 1, b = 2, c = 2, d = 4: det 0, 원이 선분으로 납작해지고 특이값 5, 0.

연결과 적용

PCA(공분산의 고유벡터), 영상 압축(SVD), 진동 해석(고유 진동수), 통신의 MIMO 채널(특이값 = 병렬 부채널 이득)이 모두 이 그림으로 해석된다.

흔한 오해

  • "고유벡터는 타원의 축 방향이다." 대칭 행렬일 때만이고, 일반적으로 축 방향은 특이벡터이다.
  • "det가 크면 원이 크게 늘어난다." det는 넓이 배율일 뿐, 한 방향으로 늘고 다른 방향으로 줄어도 같을 수 있다.
