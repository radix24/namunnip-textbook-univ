양정치 행렬의 판정

본문
이 절에서 배울 것
  • \(x^TAx > 0\)(모든 x ≠ 0)인 대칭 행렬을 양정치라 한다.
  • 고유값, 피벗, 선행 주소행렬식으로 판정한다.
  • 에너지·공분산·최적화에서의 의미를 안다.
먼저 알아야 할 것
  • 대칭 행렬 (4.2절).

4.3.1세 가지 시험

대칭 A가 양정치 ⇔ 모든 고유값 > 0 ⇔ 소거의 모든 피벗 > 0 ⇔ 왼쪽 위 k×k 행렬식이 모두 > 0. 이차형식 \(x^TAx\)가 그릇 모양이라 최솟값이 하나입니다.

예제 4.3.1

[[2, −1], [−1, 2]]와 [[1, 2], [2, 1]]은 양정치인가?

풀이. 첫째: 고유값 1, 3(모두 양), 행렬식 2, 3 > 0 → 양정치. 둘째: 고유값 3, −1 → 부정치(안장 모양). 공분산 행렬, 질량·강성 행렬, 회로의 컨덕턴스 행렬은 양(준)정치입니다.

흔한 오해(1) "원소가 모두 양수면 양정치": 둘째 예처럼 아닙니다. (2) "대각 원소가 양수면 충분": 필요하지만 충분하지 않습니다.
요약
  1. xᵀAx > 0 ⇔ 고유값 > 0 ⇔ 피벗 > 0 ⇔ 주소행렬식 > 0.
  2. 예: [[2,−1],[−1,2]] 양정치, [[1,2],[2,1]] 아님.
  3. 그릇 모양 → 유일한 최소.

4.3.2연습문제

기본

  1. [[4, 2], [2, 3]]은 양정치인가?
    답

    예(4 > 0, 12 − 4 = 8 > 0).

응용

  1. [[1, a], [a, 1]]이 양정치인 a의 범위는?
    답

    |a| < 1.

심화

  1. AᵀA는 언제 양정치인가?
    답

    A의 열이 선형 독립일 때.
