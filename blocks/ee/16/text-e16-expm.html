행렬 지수와 연립 미분방정식

본문
이 절에서 배울 것
  • \(\dot x = Ax\)의 해 \(x(t) = e^{At}x(0)\)를 안다.
  • 대각화로 \(e^{At} = Pe^{\Lambda t}P^{-1}\)를 계산한다.
  • 고유값의 실수부로 안정성을 판정한다.
먼저 알아야 할 것
  • 대각화 (4.1절), 지수 함수.

4.4.1모드의 합

A = PΛP⁻¹이면 \(e^{At} = Pe^{\Lambda t}P^{-1}\)이고, 해는 고유 모드 \(e^{\lambda_it}\)의 선형 결합입니다. 모든 고유값의 실수부가 음수면 해가 0으로 수렴합니다(제어공학의 안정성).

예제 4.4.1

A = [[0, 1], [−2, −3]], x(0) = (1, 0)의 해와 t = 1에서의 값은?

풀이. 고유값 −1, −2. 해 x₁ = 2e^{−t} − e^{−2t}, x₂ = −2e^{−t} + 2e^{−2t}(x₂ = ẋ₁). t = 1: (0.600, −0.465). 두 모드 모두 감쇠해 안정합니다. 2차 미분방정식 ẍ + 3ẋ + 2x = 0과 같은 계입니다.

흔한 오해(1) "e^{At}는 원소마다 지수를 취한 것": 대각 행렬일 때만 그렇습니다. (2) "고유값 하나만 음수면 안정": 모두 음수(실수부)여야 합니다.
요약
  1. x(t) = e^{At}x(0), e^{At} = Pe^{Λt}P⁻¹.
  2. 모든 Re λ < 0 → 안정.
  3. 예: λ = −1, −2 → (0.600, −0.465) at t = 1.

4.4.2연습문제

기본

  1. A = diag(−1, −3)의 e^{At}는?
    답

    diag(e^{−t}, e^{−3t}).

응용

  1. 고유값 ±j2이면 해의 모양은?
    답

    주파수 2 rad/s의 감쇠 없는 진동.

심화

  1. A = [[0, 1], [0, 0]]의 e^{At}는?
    답

    [[1, t], [0, 1]](대각화 불가).
