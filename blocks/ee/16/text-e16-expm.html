행렬 지수와 연립 미분방정식

본문

스칼라 미분방정식 \(\dot x = ax\)의 해는 \(x(t) = e^{at}x(0)\)이다. 그렇다면 변수가 여럿인 연립 미분방정식 \(\dot{\mathbf x} = A\mathbf x\)의 해도 "행렬의 지수 함수" \(e^{At}\)로 쓸 수 있을까? 그런 지수는 어떻게 계산하고, 해가 0으로 줄어드는지는 무엇으로 판단할까?

먼저 알아야 할 것대각화(4.1절), 지수 함수를 쓴다.

4.4.1모드의 합

스칼라 지수 함수의 급수 \(e^{at} = 1 + at + (at)^2/2! + \cdots\)에 a 대신 행렬 A를 넣으면 행렬 지수 \(e^{At}\)가 된다. 이것을 미분하면 \(Ae^{At}\)이므로, \(\dot{\mathbf x} = A\mathbf x\)의 해는 \(\mathbf x(t) = e^{At}\mathbf x(0)\)이다. 처음 질문의 첫째 답이 이것이다.

계산은 대각화로 한다. A = PΛP⁻¹이면 \(A^k = P\Lambda^kP^{-1}\)이어서 급수 전체가 \(e^{At} = Pe^{\Lambda t}P^{-1}\)이 되고, \(e^{\Lambda t}\)는 대각에 \(e^{\lambda_it}\)를 놓은 행렬이다. 그래서 해는 고유 모드 \(e^{\lambda_it}\)의 일차결합이다.

그러므로 모든 고유값의 실수부가 음수이면 모든 모드가 줄어들어 해가 0으로 수렴한다. 제어공학에서 시스템의 안정성을 고유값의 위치로 판단하는 이유가 이것이며, 처음 질문의 둘째 답이다.

예제 4.4.1

A = [[0, 1], [−2, −3]], x(0) = (1, 0)의 해와 t = 1에서의 값은?

풀이. 고유값은 −1, −2이다. 초기값을 두 모드로 나누면 해는 x₁ = 2e^{−t} − e^{−2t}, x₂ = −2e^{−t} + 2e^{−2t}이고, x₂ = ẋ₁이다. t = 1에서는 (0.600, −0.465)이다(그림 1). 두 모드가 모두 감쇠하므로 안정하다.

이 계는 2차 미분방정식 ẍ + 3ẋ + 2x = 0과 같다. 위치와 속도를 상태 변수로 삼으면 고차 미분방정식이 1차 연립 방정식이 되고, 특성 방정식 s² + 3s + 2 = 0의 근이 곧 A의 고유값이다.

고유값이 복소수이면 모드도 진동한다. 고유값이 \(\sigma \pm j\omega\)이면 \(e^{\lambda t} = e^{\sigma t}(\cos\omega t \pm j\sin\omega t)\)이어서, 실수부 σ는 커지거나 줄어드는 빠르기를, 허수부 ω는 진동의 각주파수를 정한다. 그래서 고유값을 복소평면에 찍어 보면 계가 어떻게 움직일지 한눈에 알 수 있다.

흔한 실수\(e^{At}\)를 성분마다 지수를 취한 행렬로 계산하는 실수가 흔하다. 행렬 지수는 급수로 정의되므로, 대각 행렬이 아니면 성분별 지수와 전혀 다르다. 또 대각화되지 않는 행렬, 예를 들어 [[0, 1], [0, 0]]은 급수가 끊겨 \(e^{At} = I + At\)가 되고 해에 t에 비례하는 항이 나타난다(연습문제 3).
마무리

연립 미분방정식의 해는 x(t) = e^{At}x(0)이고, e^{At} = Pe^{Λt}P⁻¹로 계산한다. 해는 고유 모드 \(e^{\lambda_it}\)의 결합이며, 모든 Re λ < 0이면 안정하다. 예를 들어 λ = −1, −2인 계는 t = 1에서 (0.600, −0.465)이다.

4.4.2연습문제

기본

  1. A = diag(−1, −3)의 e^{At}는?
    답

    diag(e^{−t}, e^{−3t})이다.

응용

  1. 고유값 ±j2이면 해의 모양은?
    답

    주파수 2 rad/s의 감쇠 없는 진동이다.

심화

  1. A = [[0, 1], [0, 0]]의 e^{At}는?
    답

    [[1, t], [0, 1]]이다(대각화 불가).
