Gram-Schmidt 정규직교화

본문
이 절에서 배울 것
  • 선형 독립인 벡터들에서 정사영을 빼 정규직교 기저를 만든다.
  • 3차원 예를 손으로 계산한다.
  • QR 분해와의 관계를 안다.
먼저 알아야 할 것
  • 정사영 (3.1절), QR 분해 (3.2절).

3.3.1빼고 정규화

\(q_1 = a_1/\|a_1\|\). 다음 벡터에서 앞 q들 방향 성분을 빼고 정규화합니다: \(v_2 = a_2 - (q_1^Ta_2)q_1\), \(q_2 = v_2/\|v_2\|\). 뺀 계수들이 QR 분해의 R 원소입니다.

예제 3.3.1

a₁ = (1, 1, 0), a₂ = (1, 0, 1)을 정규직교화하라.

풀이. q₁ = (1, 1, 0)/√2. q₁ᵀa₂ = 1/√2 → v₂ = (1, 0, 1) − (1/2)(1, 1, 0) = (0.5, −0.5, 1), ‖v₂‖ = √1.5 → q₂ = (0.408, −0.408, 0.816). q₁ᵀq₂ = 0.289 − 0.289 = 0 확인. R = [[√2, 1/√2], [0, √1.5]].

흔한 오해(1) "순서를 바꿔도 같은 결과": 첫 벡터 방향이 고정되므로 순서에 따라 기저가 달라집니다. (2) "고전 Gram-Schmidt는 수치적으로 안전": 열이 거의 평행하면 직교성을 잃어 수정 Gram-Schmidt나 Householder를 씁니다.
요약
  1. q₁ = a₁/‖a₁‖, v_k = a_k − Σ(q_iᵀa_k)q_i.
  2. 예: q₂ = (0.408, −0.408, 0.816).
  3. 계수 = R, A = QR.

3.3.2연습문제

기본

    답

응용

  1. a₁ = (1, 0), a₂ = (1, 1)의 q₂는?
    답

심화

  1. 선형 종속인 벡터를 넣으면 어떤 일이 생기는가?
    답

    v가 0이 되어 정규화할 수 없습니다.
