의사역행렬과 최소 노름 해

본문
이 절에서 배울 것
  • SVD로 의사역행렬 \(A^+ = V\Sigma^+U^T\)를 정의한다.
  • 해가 무수히 많을 때 노름이 가장 작은 해 \(A^T(AA^T)^{-1}b\)를 구한다.
  • 해가 없을 때 최소제곱 해와의 관계를 안다.
먼저 알아야 할 것
  • SVD (5.1절), 최소제곱 (3.1절).

5.3.1하나로 정하는 규칙

A⁺b는 (1) 해가 없으면 최소제곱 해, (2) 해가 많으면 그중 노름이 가장 작은 해를 줍니다. 행이 독립이면 \(A^+ = A^T(AA^T)^{-1}\), 열이 독립이면 \((A^TA)^{-1}A^T\)입니다.

예제 5.3.1

x₁ + x₂ = 2의 최소 노름 해는? x₁ + 2x₂ = 5는?

풀이. A = [1, 1]: A⁺ = (1, 1)/2 → x = (1, 1), 노름 √2(해 직선에서 원점에 가장 가까운 점). A = [1, 2]: AAᵀ = 5 → x = (1, 2)/5 × 5 = (1, 2). 로봇 팔처럼 관절이 목표보다 많을 때 가장 적게 움직이는 해를 고르는 데 씁니다.

흔한 오해(1) "의사역행렬은 근사 역행렬": 정해진 규칙(최소제곱, 최소 노름)을 만족하는 유일한 행렬입니다. (2) "작은 특이값도 그대로 뒤집는다": 잡음이 커지므로 작은 σ는 0으로 자르기도 합니다(정규화).
요약
  1. A⁺ = VΣ⁺Uᵀ.
  2. 행 독립: Aᵀ(AAᵀ)⁻¹ → 최소 노름 해.
  3. 열 독립: (AᵀA)⁻¹Aᵀ → 최소제곱 해.

5.3.2연습문제

기본

  1. 2x₁ = 4의 A⁺b는?
    답

    2.

응용

  1. x₁ + x₂ + x₂ … x₁ + x₂ + x₃ = 3의 최소 노름 해는?
    답

    (1, 1, 1).

심화

  1. A가 가역이면 A⁺는?
    답

    A⁻¹.
