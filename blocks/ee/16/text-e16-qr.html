Gram-Schmidt와 QR 분해

본문

최소제곱을 정규 방정식으로 풀면 \(A^TA\)를 만들어야 하는데, 이 행렬은 원래 A보다 훨씬 예민해질 수 있다고 한다. A를 직교하는 열과 삼각 행렬로 쪼개면 이 문제를 피할 수 있다는데, 어떻게 쪼갤까? 쪼개면 최소제곱은 얼마나 간단해질까?

먼저 알아야 할 것최소제곱과 정사영(3.1절), 내적을 쓴다.

3.2.1Gram-Schmidt

A의 열들을 서로 직교하는 단위 벡터로 바꾸는 방법이 Gram-Schmidt이다. 첫 벡터를 정규화하고, 다음 벡터에서 앞 방향들의 성분(정사영)을 빼고 정규화하기를 되풀이한다. 곧 \(\mathbf u_2 = \mathbf a_2 - (\mathbf q_1^T\mathbf a_2)\mathbf q_1\), \(\mathbf q_2 = \mathbf u_2/\|\mathbf u_2\|\)이다.

이때 \(\mathbf a_2 = (\mathbf q_1^T\mathbf a_2)\mathbf q_1 + \|\mathbf u_2\|\mathbf q_2\)이므로, 각 열은 그때까지 만든 q들로만 쓰인다. 그래서 뺀 계수들을 모으면 위 삼각 R이 되고, A = QR이다(그림 1). 처음 질문의 첫째 답이 이것이다.

예제 3.2.1

\(\mathbf a_1 = (1, 1, 0)\), \(\mathbf a_2 = (1, 0, 1)\)로 Q와 R을 구하라.

풀이. \(\|\mathbf a_1\| = \sqrt2\)이므로 \(\mathbf q_1 = (1, 1, 0)/\sqrt2\)이다. \(\mathbf q_1^T\mathbf a_2 = 1/\sqrt2\)이므로 \(\mathbf u_2 = (1, 0, 1) - \frac12(1, 1, 0) = (\frac12, -\frac12, 1)\)이다. \(\|\mathbf u_2\| = \sqrt{1.5} = 1.2247\)이므로 \(\mathbf q_2 = (0.408, -0.408, 0.816)\)이다.

따라서 \(R = \begin{pmatrix} 1.4142 & 0.7071 \\ 0 & 1.2247 \end{pmatrix}\)이다. NumPy의 qr은 부호가 반대로 나올 수 있지만 같은 분해이다.

이제 최소제곱 \(A^TA\hat x = A^Tb\)에 A = QR을 넣으면 \(Q^TQ = I\)이므로 \(R^TR\hat x = R^TQ^Tb\), 곧 \(R\hat x = Q^Tb\)로 단순해진다. 처음 질문의 둘째 답이 이것으로, 삼각 방정식을 뒤로 대입해 풀면 된다. 또 \(A^TA\)를 만들지 않으므로 조건수가 제곱되는 문제도 피한다. 실제 계산은 수치적으로 더 안정한 Householder 반사(3.4절)로 QR을 만든다.

흔한 실수Gram-Schmidt에서 원래 벡터 a 대신 이미 직교화한 u를 쓰거나, 정규화를 빠뜨리고 다음 단계로 넘어가는 실수가 흔하다. 빼는 성분은 \((\mathbf q_i^T\mathbf a_k)\mathbf q_i\)처럼 단위 벡터 q로 계산해야 한다. 또 손계산에서는 맞아도 컴퓨터에서는 반올림 오차로 q들이 조금씩 직교성을 잃으므로, 실무에서는 수정 Gram-Schmidt나 Householder를 쓴다.
마무리

Gram-Schmidt는 앞 방향 성분을 빼고 정규화해 열을 정규직교화한다. 그 결과 A = QR이고, 최소제곱은 \(R\hat x = Q^Tb\)로 풀린다. Q는 길이와 각을 보존해 수치적으로 안정하며, 실제 계산은 Householder로 한다.

3.2.3연습문제

기본

  1. (3, 4)를 정규화하면?
    답

    (0.6, 0.8)이다.

응용

  1. (1, 0)과 (1, 1)로 Gram-Schmidt를 하면?
    답

    q₁ = (1, 0), u₂ = (0, 1), q₂ = (0, 1)이다.

심화

  1. 예제 A로 b = (1, 2, 3)의 최소제곱 해를 QR로 구하라.
    답

    \(Q^Tb = (3/\sqrt2, (0.5 - 1 + 3)/1.2247) = (2.121, 2.041)\). R x̂ = Qᵀb: x₂ = 2.041/1.2247 = 1.667, x₁ = (2.121 − 0.7071 × 1.667)/1.4142 = 0.667이다.
