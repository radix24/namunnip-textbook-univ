마커스 곡선 위의 네 점

마커스 식 · 활성화 에너지 · 역전 영역

출발점

ΔG°를 바꿔 가며 마커스 식에 넣으면 활성화 에너지가 포물선을 그립니다. 꼭짓점(ΔG° = −λ)을 지나면 다시 커집니다.

재배열 에너지 λ = 100 kJ/mol인 계에서 ΔG° = 0, −50, −100, −150 kJ/mol일 때 ΔG‡를 구하고, ΔG° = 0과 −50의 속도 비(25 °C)를 구하여라.

풀이

  1. ΔG° = 0: \(\Delta G^\ddagger = 100/4 = 25\) kJ/mol.
  2. ΔG° = −50: \(25\times(1 - 0.5)^2 = 6.25\) kJ/mol. ΔG° = −100: \(25\times0 = 0\).
    내리막일수록 작아집니다.
  3. ΔG° = −150: \(25\times(1 - 1.5)^2 = 6.25\) kJ/mol.
    −100보다 내리막인데 다시 커졌습니다(역전 영역).
  4. 속도 비(0 대 −50): \(e^{(25 - 6.25)/2.479} = e^{7.56} \approx 1.9\times10^3\).
    RT = 2.479 kJ/mol.

의미

50 kJ/mol 더 내리막인 반응이 약 2000배 빠르지만, −150 kJ/mol은 −50과 같은 장벽을 가집니다. 마커스가 1956년에 예측한 이 역전 영역은 1984년에야 실험으로 확인되었고(1992 노벨상), 광합성 반응 중심에서 분리된 전하가 다시 합쳐지는 매우 내리막 반응이 느린 이유가 됩니다.

검산

식은 ΔG° = −λ에 대해 대칭인 포물선이므로, −50과 −150(−100에서 각각 50 떨어짐)의 ΔG‡가 같아야 하고 둘 다 6.25입니다.
