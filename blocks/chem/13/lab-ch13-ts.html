흡수띠 세 개를 한 번에 설명하는 Δo와 B 찾기

실습 · Tanabe-Sugano 도표(d³), 네펠라욱세틱 비

목표

Cr(III) 착물 세 가지의 관측 흡수띠에 맞도록 Δo와 Racah 매개변수 B를 직접 조절해, d³ Tanabe-Sugano 도표에서 띠를 할당하고 네펠라욱세틱 비를 비교합니다. 성취기준 [화학13-03-01].

준비

d³ 팔면체 착물의 스핀 허용 띠는 ⁴A₂g에서 ⁴T₂g, ⁴T₁g(F), ⁴T₁g(P)로 가는 세 개입니다. x = Δo/B일 때 세 상태의 에너지는

\[ E(^4T_{2g}) = \Delta_o, \qquad E(^4T_{1g}) = 7.5B + 1.5\Delta_o \mp \tfrac12\sqrt{225B^2 - 18B\Delta_o + \Delta_o^2} \]

입니다. 그림은 E/B 대 Δo/B의 Tanabe-Sugano 도표이고, 점선 세로선이 지금 고른 Δo/B, 색 점이 예측 띠, 검은 가로 막대가 관측 띠입니다. 점과 막대가 겹치면 맞은 것입니다.

맞추는 순서: 첫 띠는 Δo 자체이므로 Δo를 먼저 첫 띠에 맞추고, 그다음 B를 움직여 둘째 띠를 맞춥니다. 셋째 띠는 예측으로 확인합니다.

절차

  1. [Cr(H₂O)₆]³⁺, Δo = 17400 cm⁻¹, B = 918(자유 이온 값)에서 예측 띠와 관측 띠의 차이를 기록한다.
  2. B를 줄여 둘째 띠의 차이가 거의 0이 되는 값을 찾고, 그때 셋째 띠 예측을 관측과 비교한다.
  3. [Cr(NH₃)₆]³⁺(첫 띠 21550)와 [CrCl₆]³⁻(첫 띠 13200)로 같은 맞춤을 하고 β를 비교한다.

기대 결과

  • 자유 이온 B = 918로는 Δo/B = 19.0, 예측 띠 17400, 25829, 40141 cm⁻¹로 둘째·셋째 띠가 관측보다 1229, 2341 cm⁻¹ 높습니다. 착물 속에서는 전자 반발이 자유 이온보다 작다는 뜻입니다.
  • B = 729로 줄이면 Δo/B = 23.9, 예측 17400, 24603, 38532 cm⁻¹로 둘째 띠가 3 cm⁻¹ 안에서 맞고, 셋째 띠는 관측 37800보다 732 cm⁻¹(2%) 높습니다. β = 0.794입니다.
  • [Cr(NH₃)₆]³⁺는 Δo = 21550, B = 657에서 둘째 띠 28496(관측 28500), β = 0.716이고 셋째 띠는 46009 cm⁻¹로 예측됩니다. [CrCl₆]³⁻는 Δo = 13200, B = 558에서 둘째 띠 18700, β = 0.608입니다.

분석

  1. Δo 순서(Cl⁻ < H₂O < NH₃)와 β 순서(Cl⁻ < NH₃ < H₂O)가 같은가요? 두 계열이 각각 무엇을 재는지 설명해 보세요.
  2. 셋째 띠의 예측이 2% 어긋나는 원인으로 무엇을 생각할 수 있을까요? (모형의 근사, 겹치는 다른 흡수)
  3. B를 고정하고 Δo만 바꾸면 세 띠가 도표 위에서 어떻게 움직이나요? 강한 장 리간드로 바꿀 때의 스펙트럼 변화를 예측해 보세요.
