항 기호와 Tanabe-Sugano 도표로 흡수띠 할당하기

본문
이 절에서 배울 것
  • dⁿ 자유 이온의 바닥 항을 정하고, 팔면체 장에서 어떤 상태로 갈라지는지 안다.
  • Tanabe-Sugano 도표의 축(Δo/B, E/B)과 읽는 법을 익힌다.
  • d³ 착물의 두 흡수띠에서 Δo와 Racah 매개변수 B를 구한다.
  • 네펠라욱세틱 비 β로 금속-리간드 결합의 공유성을 판단한다.
먼저 알아야 할 것
  • 항 기호 (화학6 3.3절), UV-Vis로 Δo 구하기 (화학11 3.1절), 팔면체 MO (2.1절).

3.1.1왜 띠가 여러 개인가

d¹ 착물은 전자가 t₂g에서 eg로 뛰는 띠 하나만 보입니다(화학11 3.1절). 그런데 d³ [Cr(H₂O)₆]³⁺는 띠가 셋(17400, 24600, 37800 cm⁻¹)입니다. 전자가 여럿이면 같은 오비탈 배치에서도 전자끼리의 반발에 따라 에너지가 다른 상태(항)가 여러 개 생기기 때문입니다. 그래서 오비탈이 아니라 상태의 에너지를 봐야 합니다.

3.1.2자유 이온의 항에서 팔면체 상태로

d³ 자유 이온의 바닥 항은 훈트 규칙으로 ⁴F(스핀 다중도 4, 전체 궤도 각운동량 L = 3), 그다음 같은 스핀의 항이 ⁴P입니다. 이 항들이 팔면체 장에서 갈라집니다.

  • ⁴F → ⁴A₂g(바닥) + ⁴T₂g + ⁴T₁g(F)
  • ⁴P → ⁴T₁g(P)

스핀 선택 규칙(스핀 다중도가 같아야 함) 때문에 바닥 ⁴A₂g에서 세 개의 ⁴T 상태로 가는 전이만 세게 보입니다. 이것이 세 띠입니다.

Racah 매개변수 B: 전자끼리 반발의 크기를 나타내는 값(cm⁻¹). 자유 이온 ⁴F와 ⁴P의 간격이 15B다. 자유 Cr³⁺에서 B = 918 cm⁻¹.

3.1.3Tanabe-Sugano 도표

가로축은 Δo/B, 세로축은 바닥 상태를 0으로 놓은 각 상태의 E/B입니다. 두 축을 B로 나누었기 때문에, 같은 dⁿ이면 금속과 리간드가 달라도 도표 하나로 다룰 수 있습니다. 착물의 Δo/B 위치에 세로선을 긋고, 그 선이 각 곡선과 만나는 높이가 흡수띠 에너지(×B)입니다.

d³에서는 곡선이 식으로 주어집니다. x = Δo/B일 때

식 3.1.1 (d³ 팔면체)

\[ E(^4T_{2g}) = \Delta_o, \qquad E(^4T_{1g}) = 7.5B + 1.5\Delta_o \mp \tfrac12\sqrt{225B^2 - 18B\Delta_o + \Delta_o^2} \]

− 부호가 ⁴T₁g(F), + 부호가 ⁴T₁g(P).

예제 3.1.1

[Cr(H₂O)₆]³⁺의 띠 17400, 24600 cm⁻¹에서 Δo와 B를 구하고 셋째 띠를 예측하시오.

첫 띠가 곧 Δo = 17400 cm⁻¹입니다. 둘째 띠 24600을 식 3.1.1(− 부호)에 넣고 B를 바꿔 가며 맞추면 B = 729 cm⁻¹(Δo/B = 23.9)입니다. 이 값으로 셋째 띠는 38530 cm⁻¹로 예측되어, 관측 37800 cm⁻¹와 2% 안에서 맞습니다. 이 절의 실습 카드에서 B를 움직여 직접 맞춰 볼 수 있습니다.

3.1.4네펠라욱세틱 효과

네펠라욱세틱 비 β: 착물의 B를 자유 이온의 B로 나눈 값(β = B/B₀ < 1). "구름이 퍼진다"는 뜻으로, 금속 d 전자가 리간드 쪽으로 퍼질수록(공유성이 클수록) 전자 반발이 줄어 β가 작다.

[Cr(H₂O)₆]³⁺는 β = 729/918 = 0.794, [Cr(NH₃)₆]³⁺(21550, 28500 cm⁻¹)는 B = 657, β = 0.716, [CrCl₆]³⁻(13200, 18700 cm⁻¹)는 B = 558, β = 0.608입니다. 크고 부드러운 리간드일수록 공유성이 커서 β가 작습니다. Δo의 순서(분광화학 계열)와 β의 순서(네펠라욱세틱 계열)는 서로 다른 정보입니다.

흔한 오해"가장 낮은 띠는 언제나 Δo다"는 d¹, d³, d⁸(팔면체)에서만 맞습니다. d²는 첫 띠가 Δo보다 작게 나타나므로 도표로 맞춰야 합니다. 또 Tanabe-Sugano 도표의 세로축은 바닥 상태를 언제나 0에 둡니다. d⁴~d⁷에서는 Δo/B가 커지면 바닥 상태 자체가 바뀌어(고스핀 → 저스핀) 도표에 꺾이는 세로선이 있습니다.
요약
  1. 전자가 여럿이면 오비탈 대신 상태(항)의 에너지로 띠를 할당한다.
  2. d³: ⁴A₂g → ⁴T₂g(= Δo), ⁴T₁g(F), ⁴T₁g(P). 스핀 허용 띠 셋.
  3. Tanabe-Sugano: Δo/B 세로선과 곡선의 교점 × B = 띠 에너지.
  4. β = B/B₀: 작을수록 공유성 큼. [Cr(H₂O)₆]³⁺ 0.794.

3.1.5연습문제

기본

  1. d² 자유 이온의 바닥 항은? 팔면체에서 어떤 상태로 갈라지는가?
    답

    ³F. 팔면체에서 ³T₁g(바닥) + ³T₂g + ³A₂g로 갈라지고, ³P는 ³T₁g(P)가 된다.

응용

  1. 어떤 Cr(III) 착물의 첫 띠가 16000 cm⁻¹, Δo/B = 24라면 B와 β는?
    답

    Δo = 16000, B = 16000/24 = 667 cm⁻¹, β = 667/918 = 0.73.

심화

  1. [Cr(NH₃)₆]³⁺에서 셋째 띠(⁴T₁g(P))가 관측되지 않는 이유를 예측값과 다른 흡수의 위치로 추론하시오.
    답

    B = 657, Δo = 21550으로 식 3.1.1에 넣으면 셋째 띠는 약 46000 cm⁻¹(217 nm)로 자외선 깊숙이 있다. 그 영역에는 훨씬 센 전하 이동 띠와 리간드 자체의 흡수가 있어 약한 d-d 띠가 묻힌다.
