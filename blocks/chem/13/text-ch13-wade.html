Wade 규칙

본문
이 절에서 배울 것
  • 클러스터 골격 전자쌍 수를 센다.
  • 골격 전자쌍 수로 closo, nido, arachno 구조를 정한다.
  • 카보레인과 금속 클러스터로 규칙을 넓힌다.
먼저 알아야 할 것
  • 3중심 2전자 결합과 보레인 (1.1절).

1.4.1골격 전자쌍 세기

보레인 클러스터의 꼭짓점 B−H 단위는 바깥으로 향한 B−H 결합에 전자 둘을 쓰고, 남은 원자가 전자(B 3 + H 1 − 2 = 2)를 골격 결합에 내놓습니다. 여기에 다리 수소나 추가 수소(각 1), 음전하(각 1)를 더합니다.

규칙 1.4.1 (골격 전자 수)

BH 단위 2, CH 단위 3, 추가 H 1, 음전하 1씩. 골격 전자쌍 = (합)/2.

1.4.2구조 정하기

꼭짓점이 n개인 클러스터에서

골격 전자쌍구조모양
n + 1closo삼각형 면으로 된 닫힌 다면체(n = 6 팔면체, 12 정이십면체)
n + 2nido(둥지)꼭짓점이 n + 1개인 closo 다면체에서 꼭짓점 하나를 뺀 모양
n + 3arachno(거미줄)꼭짓점 둘을 뺀 모양

꼭짓점 수가 같아도 전자가 많을수록 더 열린 구조가 됩니다. 전자가 많으면 결합성 오비탈이 아닌 곳까지 채워져 다면체를 닫아 둘 수 없기 때문입니다.

1.4.3카보레인과 금속 클러스터

CH 단위는 BH보다 전자를 하나 더 내놓아 BH⁻와 같은 역할을 합니다. 그래서 [B₁₂H₁₂]²⁻와 C₂B₁₀H₁₂는 같은 정이십면체 closo 구조이고, 카보레인은 전하가 없어 매우 안정한 중성 분자입니다. 금속 카보닐 단위도 전자를 세어 같은 규칙을 쓸 수 있습니다(골격 전자쌍 규칙, Wade-Mingos 규칙).

흔한 오해"꼭짓점 수가 같으면 구조도 같다"가 아닙니다. 골격 전자 수가 구조를 정합니다. B₅H₉(nido)와 [B₅H₅]²⁻(closo 쌍삼각뿔이 될 것으로 예측)는 꼭짓점이 같아도 모양이 다릅니다. 또 바깥쪽 B−H 결합의 전자는 골격 전자에 넣지 않습니다.
요약
  1. BH 2, CH 3, 추가 H 1, 음전하 1. 골격 전자쌍 = 합/2.
  2. n + 1 closo, n + 2 nido, n + 3 arachno.
  3. CH ≈ BH⁻. C₂B₁₀H₁₂와 [B₁₂H₁₂]²⁻는 같은 closo 정이십면체.

1.4.4연습문제

기본

  1. [B₆H₆]²⁻의 골격 전자쌍 수와 구조는?
    답

    6 × 2 + 2 = 14, 7쌍 = n + 1. closo 팔면체.

응용

  1. B₅H₉의 구조는?
    답

    5 × 2 + 4 = 14, 7쌍 = n + 2. nido(팔면체에서 꼭짓점 하나를 뺀 사각뿔).

심화

  1. B₄H₁₀의 구조를 예측하고, 이를 closo 다면체와 연결하시오.
    답

    4 × 2 + 6 = 14, 7쌍 = n + 3. arachno. 꼭짓점 6개인 팔면체에서 두 꼭짓점을 뺀 나비 모양입니다.
