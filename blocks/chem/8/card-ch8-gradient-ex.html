두 화합물을 한 등용매 조건으로 가를 수 있나

선형 용매 세기 모형 · 머무름 인자 · 구배의 필요

출발점

각 화합물의 log k를 φ의 직선으로 놓고, k가 1~10인 φ 범위가 겹치는지 보면 등용매로 가능한지 판단할 수 있다.

화합물 A는 log k_w = 3.0, S = 4, 화합물 B는 log k_w = 1.5, S = 3이다. φ = 0.30과 0.60에서 두 화합물의 k를 구하고, 둘 다 1 ≤ k ≤ 10이 되는 등용매 조성이 있는지 판단하여라.

풀이

  1. φ = 0.30: A \(\log k = 3.0 - 1.2 = 1.8\), k = 63. B \(\log k = 1.5 - 0.9 = 0.6\), k = 4.0.
    A는 너무 늦게 나온다.
  2. φ = 0.60: A \(\log k = 0.6\), k = 4.0. B \(\log k = -0.3\), k = 0.50.
    B는 거의 머무르지 않는다.
  3. A가 k ≤ 10이려면 \(3.0 - 4\varphi \le 1\), φ ≥ 0.50. B가 k ≥ 1이려면 \(1.5 - 3\varphi \ge 0\), φ ≤ 0.50.
  4. 두 조건이 φ = 0.50 한 점에서만 겹칩니다(A k = 10, B k = 1). 실제로는 여유가 없으므로 φ를 0.30에서 0.60으로 올리는 구배가 알맞다.
    경계값에서는 B가 앞쪽 불순물과, A는 넓은 봉우리로 고생한다.

의미

두 화합물만으로도 등용매 조건이 거의 없을 만큼 머무름 차이가 크다. 성분이 여럿이면 더 심해진다. 구배를 쓰면 B는 초반의 약한 용매(φ ≈ 0.3, k ≈ 4)에서, A는 후반의 강한 용매(φ ≈ 0.6, k ≈ 4)에서 각각 알맞은 머무름으로 나온다.

검산

φ = 0.50에서 A는 \(\log k = 3.0 - 2.0 = 1.0\), k = 10, B는 \(1.5 - 1.5 = 0\), k = 1로 경계 계산과 맞다.
