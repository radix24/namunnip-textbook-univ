크로마토그래피 이론 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념van Deemter 식의 세 항 가운데 모세관 GC에는 없는 항과 그 이유는? [04-01]

    힌트 1

    모세관 GC의 관 안에는 충전 입자가 있나요?

    힌트 2

    다중 경로.

    풀이

    A항(소용돌이 확산). 모세관 GC는 관 벽에 정지상을 얇게 입힌 빈 관이라 입자 사이로 여러 길을 지나는 일이 없습니다(골레이 식 H = B/u + Cu).

  2. 계산H = 1.5 + 6.0/u + 1.5u (μm, u는 mm/s)일 때 u_opt, H_min과, u = 1.0과 4.0 mm/s의 H를 구하시오. [04-01]

    힌트 1

    u_opt = √(B/C).

    힌트 2

    √4 = 2.

    풀이

    u_opt = √(6.0/1.5) = 2.0 mm/s, H_min = 1.5 + 2√9 = 7.5 μm. u = 1.0: 1.5 + 6.0 + 1.5 = 9.0 μm. u = 4.0: 1.5 + 1.5 + 6.0 = 9.0 μm. 이 경우 최적의 절반과 두 배가 같은 H를 주므로, 시간이 덜 드는 빠른 쪽을 고릅니다.

  3. 개념같은 HPLC 관에서 분자량이 큰 단백질은 작은 분자보다 최적 유속이 느리고 H가 크다. 이유를 확산 계수로 설명하시오. [04-01]

    힌트 1

    큰 분자의 확산 계수는?

    힌트 2

    B ∝ D, C ∝ 1/D.

    풀이

    큰 분자는 확산 계수 D가 작습니다. B ∝ D는 작아지고 물질 전달 항 C ∝ 1/D는 커지므로 u_opt = √(B/C) ∝ D로 느려지고, 빠른 유속에서 C항 때문에 H가 크게 늡니다. 그래서 단백질 분리에는 기공이 크거나 비다공성인 입자, 낮은 유속을 씁니다.

  4. 계산t_R = 6.00 min, 반높이 너비 3.53 s인 봉우리의 N은? (w½ = 2.35σ) [04-02]

    힌트 1

    σ = w½/2.35.

    힌트 2

    N = (t_R/σ)².

    풀이

    σ = 3.53/2.35 = 1.50 s, t_R = 360 s, N = (360/1.50)² ≈ 5.7×10⁴. (5.54(t_R/w½)²로도 약 5.8×10⁴로 거의 같은 값.)

  5. 계산α = 1.08, k = 5에서 R_s = 1.5에 필요한 N과, H = 8 μm 관의 길이는? [04-02]

    힌트 1

    N = 16R_s²(α/(α − 1))²((1 + k)/k)².

    힌트 2

    (1.08/0.08)² = 182.25, (6/5)² = 1.44.

    풀이

    N = 36 × 182.25 × 1.44 = 9450. L = 9450 × 8 μm = 7.6 cm.

  6. 판단한 학생이 5 cm 짜리 UHPLC 관을 오래된 HPLC 장치(굵고 긴 연결관)에 달았더니 관 제조사가 보증한 N의 절반밖에 나오지 않았다. 관 불량이라고 결론 내렸다. 평가하시오. [04-02]

    힌트 1

    짧은 관의 봉우리 σ는 작습니다.

    힌트 2

    분산의 덧셈.

    풀이

    관 불량이 아닐 수 있습니다. 짧은 관의 봉우리는 원래 좁아서, 장치의 관 밖 넓어짐(연결관, 주입기, 검출기 셀)의 분산이 더해지면 상대적으로 크게 넓어집니다. 관 밖 분산이 관 자체 분산과 같으면 N은 절반이 됩니다. 연결관을 짧고 가늘게, 셀을 작게 바꾸거나, 관 없이 연결해 관 밖 분산을 재어 빼 봅니다.
