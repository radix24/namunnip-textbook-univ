분리능과 단 높이 계산

본문

새로 산 짧은 UHPLC 관은 이론단 수가 22500이라는데, 실제 장비에 달아 재 보니 18000밖에 안 나왔다. 관이 불량일까? 또 선택성 1.05인 두 물질을 완전히 가르려면 관이 얼마나 길어야 하고, 분석은 몇 분이나 걸릴까?

먼저 알아야 할 것반 디미터 식(4.1절)과 분리능과 퍼넬 식(화학3 5.1절)을 쓴다.

4.2.1표준 편차로 쓰는 N과 H

가우스 모양 봉우리의 너비는 표준 편차 \(\sigma\)로 나타내며, 바탕 너비는 \(w \approx 4\sigma\), 반높이 너비는 \(w_{1/2} \approx 2.35\sigma\)이다. 시간 단위의 \(\sigma_t\)로 쓰면 이론단 수와 단 높이는 다음과 같다.

식 4.2.1 (이론단 수와 단 높이) \[N = \left(\frac{t_R}{\sigma_t}\right)^2, \qquad H = \frac{L}{N} = \frac{\sigma_L^2}{L}\]

\(\sigma_L\)은 봉우리가 관 끝에 이를 때 퍼진 폭을 길이 단위로 쓴 표준 편차이다.

바탕 너비로 쓴 \(N = 16(t_R/w)^2\)와 같은 식이며, \(w = 4\sigma\)이므로 \(16 = 4^2\)이다.

4.2.2넓어짐은 분산으로 더해진다

봉우리를 넓히는 원인들이 서로 독립이면, 표준 편차가 아니라 분산이 더해진다.

\[\sigma_\mathrm{전체}^2 = \sigma_\mathrm{관}^2 + \sigma_\mathrm{주입}^2 + \sigma_\mathrm{연결관}^2 + \sigma_\mathrm{검출기}^2 + \cdots\]
예제 4.2.1

머무름 시간 300 s인 봉우리에서 관 자체의 넓어짐은 \(\sigma\) = 2.0 s이고, 주입기·연결관·검출기 셀의 관 밖 넓어짐이 \(\sigma\) = 1.0 s이다. 관 자체의 \(N\)과 실제로 관찰되는 \(N\)을 비교하여라.

풀이. 관 자체는 \(N = (300/2.0)^2 = 22500\)이다. 그런데 관찰되는 폭은 \(\sigma = \sqrt{2.0^2 + 1.0^2} = 2.24\) s이므로 \(N = (300/2.24)^2 = 18000\)이다. 관 밖 넓어짐만으로 단 수가 20% 줄었으며, 처음 질문의 첫째 답이 이것이다. 관은 불량이 아니다. 짧고 좁은 관일수록 관 자체의 \(\sigma\)가 작아 관 밖 넓어짐의 비중이 커지므로, 연결관을 짧고 가늘게, 검출기 셀을 작게 한다.

4.2.3목표 분리능에서 거꾸로

그러면 \(R_s = 1.5\)를 얻는 데 필요한 \(N\)과 관 길이는 얼마일까? 퍼넬 식(화학3 5.1절)을 \(N\)에 대해 풀면 다음과 같다.

식 4.2.2 (필요 이론단 수) \[N_\mathrm{필요} = 16R_s^2\left(\frac{\alpha}{\alpha - 1}\right)^2\left(\frac{1 + k}{k}\right)^2\]
예제 4.2.2

\(\alpha\) = 1.05, \(k\) = 4인 두 물질을 \(R_s\) = 1.5로 분리하려 한다. 필요한 \(N\)은? 4.1절 예제의 관(\(H\) = 12.0 μm, \(u_\mathrm{opt}\) = 2.0 mm/s)으로는 관 길이가 얼마여야 하며, 둘째 봉우리는 언제 나오는가?

풀이. \(N = 16\times2.25\times(1.05/0.05)^2\times(5/4)^2 = 16\times2.25\times441\times1.5625 = 24800\)이다. 따라서 \(L = NH = 24800\times12.0\) μm = 29.8 cm이다. 불감 시간은 \(t_M = L/u = 298/2.0 = 149\) s이고, 둘째 봉우리는 \(t_R = t_M(1 + k) = 745\) s, 곧 약 12분에 나온다. 처음 질문의 둘째 답이 이것이다. 그런데 \(\alpha\)를 1.10으로 올릴 수 있다면 \((\alpha/(\alpha - 1))^2\)이 441에서 121로 줄어, \(N\) 6800, 관 8.2 cm, 약 3.4분이면 된다. 즉 선택성을 높이는 것이 시간을 가장 크게 줄인다.

흔한 오해넓어짐의 표준 편차를 더하기 쉽지만 분산, 곧 제곱을 더한다. 예제 4.2.1에서 2.0 + 1.0 = 3.0 s로 계산하면 \(N\)을 크게 과소평가한다. 또 분리능을 두 배로 하려면 관이 두 배가 아니라 네 배 필요하다(\(R_s \propto \sqrt N\)). 그리고 \(N\)은 \(k\)에 따라 물질마다 조금씩 다르므로, 관의 \(N\)을 말할 때는 어떤 물질로 쟀는지 함께 쓴다.
마무리

이론단 수는 \(N = (t_R/\sigma_t)^2 = 16(t_R/w)^2\)이고 단 높이는 \(H = L/N = \sigma_L^2/L\)이다. 독립인 넓어짐은 분산으로 더해지므로, 처음 질문의 짧은 관처럼 관 밖 넓어짐이 관찰되는 \(N\)을 크게 깎는다. 목표 분리능에 필요한 이론단 수는 \(16R_s^2(\alpha/(\alpha - 1))^2((1 + k)/k)^2\)이고 \(L = NH\), \(t_R = (L/u)(1 + k)\)이며, \(\alpha\)를 조금만 키워도 필요한 \(N\)과 시간이 크게 준다.

4.2.4연습문제

기본

  1. 25 cm 관에서 t_R = 8.0 min, σ_t = 4.0 s인 봉우리의 N과 H는?
    답

    t_R = 480 s, N = (480/4.0)² = 14400. H = 250 mm/14400 = 0.0174 mm = 17.4 μm.

응용

  1. 관 자체의 σ = 1.5 s인데 관찰된 σ가 2.5 s였다. 관 밖 넓어짐의 σ는?
    답

    √(2.5² − 1.5²) = √4.0 = 2.0 s. 관 자체보다 커서 장치 연결을 점검해야 한다.

심화

  1. α = 1.02, k = 3에서 R_s = 1.5에 필요한 N을 구하고, H = 10 μm인 관으로 가능한지 판단하시오.
    답

    N = 16 × 2.25 × (1.02/0.02)² × (4/3)² = 36 × 2601 × 1.778 = 1.66×10⁵. 관 길이 1.66 m로, 보통 HPLC 관(5~25 cm)으로는 어렵다. α를 키우는 조건을 찾아야 한다.
