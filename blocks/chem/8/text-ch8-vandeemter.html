van Deemter 식과 최적 유속

본문

HPLC 분석을 빨리 끝내려고 유속을 두 배로 올렸더니 봉우리가 넓어져 분리가 나빠졌다. 그렇다고 유속을 아주 느리게 했더니 이번에도 봉우리가 넓어졌다. 빠르게 해도 느리게 해도 나빠진다면, 봉우리를 가장 좁게 만드는 유속이 따로 있는 것일까?

먼저 알아야 할 것단 이론과 이론단 수(화학1 7.2절), 크로마토그램의 기본 수(화학3 5.1절), 확산(일반화학)을 쓴다.

4.1.1단 높이 H

관 길이를 이론단 수로 나눈 값 \(H = L/N\)을 단 높이라 한다. 봉우리가 관을 따라 이동하며 퍼지는 정도, 곧 길이당 분산 \(H = \sigma^2/L\)이기도 하며, 작을수록 관이 효율적이다. 봉우리가 퍼지는 까닭은 같은 분자들이 관을 지나는 동안 서로 다른 운명을 겪기 때문이며, 그 원인을 셋으로 나눈 것이 반 디미터 식이다.

4.1.2세 가지 원인

식 4.1.1 (반 디미터 식) \[H = A + \frac{B}{u} + Cu\]

\(u\)는 이동상의 선속도이다.

먼저 \(A\)항은 소용돌이 확산, 곧 다중 경로이다. 충전 입자 사이로 분자마다 짧은 길과 긴 길을 지나 도착 시간이 흩어진다. 유속과 거의 무관하며 입자가 작고 고를수록 작고, 빈 모세관 GC에는 없다. 다음으로 \(B/u\)항은 세로 확산이다. 봉우리 안의 분자가 진한 가운데에서 묽은 앞뒤로 확산해 퍼지므로, 관 안에 오래 있을수록, 곧 유속이 느릴수록 커진다. \(B\)는 이동상 속 확산 계수에 비례한다.

셋째로 \(Cu\)항은 물질 전달이다. 분자가 정지상에 들어갔다 나오는 데 시간이 걸려, 그동안 이동상의 분자는 앞서 간다. 그래서 유속이 빠를수록 평형을 따라가지 못해 커지며, 입자나 정지상 막이 얇을수록 작다. 처음 질문의 답이 이 두 항이다. 느리면 \(B/u\)가, 빠르면 \(Cu\)가 봉우리를 넓힌다.

4.1.3최적 유속

그러므로 \(H\)가 가장 작은 유속이 있다. \(dH/du = -B/u^2 + C = 0\)에서 다음을 얻는다.

식 4.1.2 (최적 유속과 최소 단 높이) \[u_\mathrm{opt} = \sqrt{B/C}, \qquad H_\mathrm{min} = A + 2\sqrt{BC}\]
예제 4.1.1

어떤 HPLC 관에서 \(A\) = 2.0 μm, \(B\) = 10 μm·mm/s, \(C\) = 2.5 μm·s/mm이다. 최적 유속과 최소 단 높이, 15 cm 관의 최대 이론단 수를 구하고, 유속을 4 mm/s로 두 배 올리면 \(N\)이 어떻게 되는지 구하여라.

풀이. \(u_\mathrm{opt} = \sqrt{10/2.5} = 2.0\) mm/s이고 \(H_\mathrm{min} = 2.0 + 2\sqrt{25} = 12.0\) μm이다. 따라서 \(N = 150000/12.0 = 12500\)이다. 4 mm/s에서는 \(H = 2.0 + 2.5 + 10.0 = 14.5\) μm이므로 \(N = 10340\)으로 17% 줄어든다. 그런데 시간은 절반이 되므로, 분리에 여유가 있으면 최적보다 조금 빠르게 흘리는 것이 실용적이다. 곡선이 최적점의 빠른 쪽에서 완만할수록, 곧 \(C\)가 작을수록 이 선택이 유리하다.

4.1.4기체 대 액체, 큰 입자 대 작은 입자

GC에서는 기체 속 확산 계수가 액체보다 약 10⁴배 커서 \(B\)가 크고, 정지상과 이동상 사이 물질 전달도 빠르다. 그래서 최적 유속이 수십 cm/s로 수 mm/s인 HPLC보다 훨씬 빠르고, 수십 m의 긴 모세관으로 수십만 단을 얻는다. 반면 HPLC는 확산이 느려 \(B\)항은 거의 문제가 되지 않고 \(C\)항이 지배한다. 그러므로 입자를 5 μm에서 2 μm 아래로 줄이면 \(A\)와 \(C\)가 모두 줄어 \(H\)가 작아지고, 빠른 쪽에서도 곡선이 평평해진다. 이것이 UHPLC이다. 다만 압력이 입자 지름의 제곱에 반비례해 커져 고압 펌프가 필요하다.

흔한 오해유속이 느릴수록 분리가 좋다는 생각은 최적 유속보다 느린 쪽에서는 틀리다. 세로 확산 때문에 오히려 나빠진다. 또 \(H\)가 큰 관이 좋은 관이 아니라 작을수록 좋다(\(N = L/H\)). 그리고 최적 유속은 분석물과 이동상의 확산 계수에 따라 다르므로, 한 번 정한 값이 모든 분석에 최적인 것은 아니다.
마무리

단 높이 \(H = L/N = \sigma^2/L\)은 작을수록 관이 효율적이며, 반 디미터 식 \(H = A + B/u + Cu\)의 다중 경로, 세로 확산, 물질 전달 세 항의 합이다. 처음 질문처럼 느리면 세로 확산이, 빠르면 물질 전달이 봉우리를 넓히므로 \(u_\mathrm{opt} = \sqrt{B/C}\)에서 \(H_\mathrm{min} = A + 2\sqrt{BC}\)가 된다. GC는 확산이 빨라 최적 유속이 높고, HPLC는 \(C\)항이 지배해 작은 입자가 유리하다.

4.1.5연습문제

기본

  1. A = 1.0 mm, B = 20 mm²/s, C = 0.05 s(GC 충전관, u는 mm/s)일 때 u_opt와 H_min은?
    답

    u_opt = √(20/0.05) = 20 mm/s, H_min = 1.0 + 2√(20 × 0.05) = 3.0 mm.

응용

  1. 예제 4.1.1의 관에서 유속을 0.5 mm/s로 낮추면 H와 N은? 최적보다 느린 쪽이 손해인 이유는?
    답

    H = 2.0 + 20 + 1.25 = 23.25 μm, N = 6450으로 거의 절반. 관에 오래 머물러 세로 확산이 커지고 시간도 네 배 걸린다.

심화

  1. 입자 지름을 절반으로 줄이면 A ∝ d_p, C ∝ d_p²이 된다고 하자(B는 그대로). 예제 4.1.1에서 새 u_opt와 H_min을 구하시오.
    답

    A = 1.0 μm, C = 0.625 μm·s/mm. u_opt = √(10/0.625) = 4.0 mm/s, H_min = 1.0 + 2√6.25 = 6.0 μm. 단 높이가 절반, 최적 유속이 두 배라 같은 관 길이에서 두 배의 단 수를 두 배 빠르게 얻는다(압력은 약 네 배 이상).
