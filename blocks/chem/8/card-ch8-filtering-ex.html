5점 이동 평균이 잡음과 좁은 봉우리에 주는 효과

이동 평균 · √n · 봉우리 일그러짐

출발점

이동 평균은 잡음과 신호를 가리지 않고 평균합니다. 잡음에서는 이득이, 좁은 봉우리에서는 손실이 생깁니다.

(가) 바탕 잡음 다섯 점 0.12, −0.05, 0.08, −0.11, 0.03의 5점 평균을 구하고, 표준 편차 0.10인 백색 잡음이 5점 평균으로 얼마가 되는지 쓰시오. (나) 한 점짜리 봉우리 0, 0, 10, 0, 0과 반높이 너비가 약 10점인 넓은 봉우리에 같은 거르기를 쓰면 높이가 어떻게 되는지 비교하여라.

풀이

  1. (가) 평균 \((0.12 - 0.05 + 0.08 - 0.11 + 0.03)/5 = 0.014\).
    흔들리던 값이 0 근처로 모입니다.
  2. 표준 편차는 \(0.10/\sqrt5 = 0.045\)가 됩니다.
    서로 독립인 잡음 다섯 개의 평균.
  3. (나) 한 점 봉우리의 가운데 값은 \((0 + 0 + 10 + 0 + 0)/5 = 2\)가 되어 높이가 1/5로 줄고 다섯 점으로 퍼집니다.
    창이 봉우리보다 훨씬 넓습니다.
  4. 반높이 너비 10점인 봉우리는 창(5점) 안에서 값이 거의 일정해 높이가 몇 %만 줄어듭니다.
    창이 너비의 절반이면 일그러짐이 작습니다.

의미

같은 거르기가 넓은 봉우리에는 거의 공짜로 S/N을 2.2배 올려 주고, 좁은 봉우리는 망가뜨립니다. 그래서 창의 크기는 봉우리 너비에 맞춰 정하고, 가장 좁은 봉우리를 기준으로 삼습니다. 모양을 더 잘 지켜야 하면 같은 창의 사비츠키-골레이 거르기를 씁니다.

검산

거른 신호의 넓이는 이동 평균이 보존해야 합니다. 한 점 봉우리 10은 다섯 점 2씩으로 퍼져 넓이가 여전히 10입니다. 높이는 줄고 넓이는 그대로라는 것이 이동 평균의 성질입니다.
