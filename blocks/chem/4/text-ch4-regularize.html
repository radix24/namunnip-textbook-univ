정규화: 릿지와 라소

본문

분자 30개로 기술자 20개를 넣은 선형 모형을 맞췄더니 훈련 자료에서는 거의 완벽한데, 가중치가 +50과 −49처럼 서로 상쇄하는 큰 값들로 가득하다. 새 분자에서는 예측이 엉망이다. 가중치가 이렇게 커지지 않도록 손실 함수에 무엇을 더하면 될까?

먼저 알아야 할 것선형 회귀(3.1절), 교차검증과 과적합(3.2절), 특성 표준화(1.4절)를 쓴다.

3.6.1큰 가중치와 과적합

특성이 많고 자료가 적으면 모형은 잡음까지 맞추려고 서로 상쇄하는 큰 가중치를 만든다. 처음 질문의 +50, −49가 그런 예이다. 이런 모형은 훈련 자료에서는 잘 맞지만 입력이 조금만 달라져도 예측이 크게 흔들린다. 그래서 손실에 가중치 크기의 벌점을 더해 이런 해를 막으며, 이것을 정규화라 한다.

3.6.2릿지와 라소

식 3.6.1 (릿지와 라소)

\[ \text{릿지: } \mathcal L = \sum_i (y_i - \hat y_i)^2 + \lambda\sum_j w_j^2, \qquad \text{라소: } \mathcal L = \sum_i (y_i - \hat y_i)^2 + \lambda\sum_j |w_j| \]

두 벌점은 다르게 작용한다. 릿지는 모든 가중치를 0 쪽으로 조금씩 줄이며, 상관된 특성들에 가중치를 고르게 나눈다. 반면 라소는 작은 가중치를 정확히 0으로 만들어 쓸모없는 특성을 스스로 빼므로, 특성 선택이 함께 된다. 그림 1이 이 차이를 보여 준다.

예제 3.6.1

원점을 지나는 특성 하나의 모형 \(\hat y = wx\)에서 \(\sum x_i^2 = 10\), \(\sum x_iy_i = 10\)이다. 릿지 해를 \(\lambda = 0, 10, 90\)에서 구하여라.

풀이. 손실 \(\sum(y_i - wx_i)^2 + \lambda w^2\)을 \(w\)로 미분해 0으로 두면 \(w = \sum x_iy_i/(\sum x_i^2 + \lambda)\)이다. 따라서 \(\lambda = 0\)이면 \(w = 1\), 10이면 0.5, 90이면 0.1이다. \(\lambda\)가 분모에 더해져 가중치가 줄어드는 것이 바로 보이며, 아무리 커져도 0이 되지는 않는다.

벌점은 가중치의 크기에 걸리므로, 특성의 단위가 다르면 불공평해진다. 그러므로 정규화 전에 특성을 표준화하며(1.4절), 절편은 보통 벌점에서 뺀다.

3.6.3λ 고르기

\(\lambda = 0\)이면 보통 회귀이고, \(\lambda\)가 매우 크면 모든 가중치가 0이 되어 평균만 예측한다. 그 사이 어딘가에서 검증 오차가 가장 작다. 그래서 \(\lambda\)를 0.001, 0.01, 0.1, 1, 10처럼 로그 간격으로 바꿔 가며 교차검증 오차를 그리고, 가장 작은 곳이나 그보다 표준 오차 하나만큼 단순한 쪽을 고른다. 시험 자료는 \(\lambda\)를 고르는 데 쓰지 않는다.

흔한 오해정규화하면 훈련 오차가 줄어든다고 생각하기 쉽지만, 훈련 오차는 오히려 늘어나고 줄어드는 것은 새 자료에서의 오차이다. 또 라소가 0으로 만든 특성이 활성과 관계없다는 뜻은 아니다. 다른 상관된 특성이 같은 정보를 대신 가져갔을 수 있다.
마무리

처음 질문의 서로 상쇄하는 큰 가중치는 과적합의 신호이며, 손실에 가중치 크기의 벌점을 더하는 정규화로 막는다. 릿지 벌점 \(\lambda\sum w^2\)은 가중치를 고르게 줄이고, 라소 벌점 \(\lambda\sum|w|\)는 일부를 정확히 0으로 만들어 특성을 고른다. 정규화 전에는 특성을 표준화하고, \(\lambda\)는 로그 간격의 교차검증으로 고르며 시험 자료는 쓰지 않는다.

3.6.4연습문제

기본

  1. 특성 하나, 원점을 지나는 모형에서 Σxy = 20, Σx² = 8이다. λ = 0, 2, 8일 때 릿지 가중치는?
    답

    2.50, 2.00, 1.25.

응용

  1. 같은 자료에서 라소의 해는 w > 0일 때 \(w = (\sum xy - \lambda/2)/\sum x^2\)이다. λ = 8일 때 w와, w가 0이 되는 λ는?
    답

    w = (20 − 4)/8 = 2.00. λ ≥ 40에서 0.

심화

  1. 분자량(단위 g/mol, 값 수백)과 logP(값 수 단위)를 표준화하지 않고 릿지에 넣으면 어느 특성의 가중치가 더 강하게 줄어드는가?
    답

    분자량은 값이 커서 같은 효과에 작은 가중치면 되므로 벌점이 거의 걸리지 않고, logP는 큰 가중치가 필요해 벌점을 크게 받아 더 강하게 줄어듭니다. 단위 때문에 벌점이 불공평해지므로 표준화가 필요합니다.
