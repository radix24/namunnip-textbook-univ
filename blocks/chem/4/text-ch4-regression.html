기술자로 물성을 예측하는 회귀 모형

본문
이 절에서 배울 것
  • 지도학습의 구성(입력 특성, 목표값, 모형, 손실, 평가)을 회귀 문제로 정리한다.

  • 경사 하강법 (1.2절), 분자 기술자 (2.2절), 최소제곱 직선 (화학1 1.4절).

3.1.1지도학습의 구성

지도학습: 입력(특성)과 정답(목표값)이 짝지어진 자료로, 입력에서 정답을 내는 함수를 배우는 것.

회귀: 목표값이 연속적인 수(끓는점, 용해도, 결합 에너지).

분류: 목표값이 범주(독성 있음/없음, 활성/비활성).

한 문제를 세우려면 다섯 가지를 정합니다. (1) 무엇을 예측하나(목표값과 단위), (2) 무엇을 입력으로 쓰나(기술자, 지문), (3) 어떤 모형(선형, 결정나무, 신경망), (4) 무엇을 줄이나(손실), (5) 어떻게 평가하나(3.2절).

3.1.2선형 회귀와 평가 지표

메테인부터 데케인까지(C1~C10) 끓는점을 탄소 수 n 하나로 예측해 봅시다. 최소제곱 직선은 \(\hat y = -159.37 + 35.54\,n\)입니다.

RMSE: \(\sqrt{\frac1N\sum(\hat y - y)^2}\). 목표값과 같은 단위의 "대표적인 오차 크기".

결정 계수 R²: \(1 - \sum(\hat y - y)^2/\sum(y - \bar y)^2\). 평균값 하나로 예측할 때보다 오차 제곱합이 얼마나 줄었는지. 1이면 완벽, 0이면 평균과 같음.

직선 모형은 R² = 0.972로 좋아 보이지만 RMSE는 17.33 °C입니다. 탄소 하나당 끓는점 차이가 20~70 °C인 것을 생각하면 크고, 잔차(실제 − 예측)를 그려 보면 양 끝은 예측보다 낮고 가운데는 높은 활 모양입니다. 실제 관계가 직선이 아니라는 신호입니다. R²가 높다는 것만으로 모형이 맞다고 할 수 없고, 잔차의 무늬를 봐야 합니다(화학1의 검량선과 같음).

3.1.3특성 공학: 화학을 입력에 넣기

끓는점은 분자 사이의 런던 분산력에 달려 있고, 분산력은 분자의 표면적과 관련이 있습니다. 곧은 사슬 알케인의 표면적은 대략 길이에 비례하지만, 끓는점은 사슬이 길어질수록 덜 오릅니다. 그래서 n 대신 \(\sqrt n\)을 특성으로 써 봅니다.

특성R²RMSE (°C)운데케인 예측 (실제 196 °C)
n0.97217.33231.6
ln n0.97914.99166.9
n^(2/3)0.9957.61211.6
√n0.9992.51200.9

매개변수 수는 똑같이 둘(기울기, 절편)인데, 특성 하나만 바꿔 RMSE가 7분의 1로 줄고 자료 밖 예측도 5 °C 이내로 맞습니다. 3.2절에서 볼 고차 다항식(매개변수 다섯 개)보다도 낫습니다. 화학 지식으로 고른 특성이 모형을 복잡하게 하는 것보다 효과적일 때가 많다는 것이 화학 AI의 중요한 교훈입니다.

import math
N = list(range(1, 11))
Y = [-161.5, -88.6, -42.1, -0.5, 36.1, 68.7, 98.4, 125.7, 150.8, 174.1]

def ols(xs, ys):                          # 최소제곱 직선 (절편, 기울기)
    mx, my = sum(xs) / len(xs), sum(ys) / len(ys)
    a = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / sum((x - mx) ** 2 for x in xs)
    return my - a * mx, a

F = [math.sqrt(n) for n in N]
b, a = ols(F, Y)
print(round(b, 2), round(a, 2), round(b + a * math.sqrt(11), 1))   # -309.93 154.01 200.9

3.1.4분류와 결정나무

로지스틱 회귀: 선형 결합 \(z = \mathbf w\cdot\mathbf x + b\)를 시그모이드 \(\sigma(z) = 1/(1 + e^{-z})\)에 넣어 0~1의 확률로 바꾼 분류 모형. 손실은 교차 엔트로피 \(-[y\ln p + (1 - y)\ln(1 - p)]\)를 쓴다.

결정나무: "logP > 3인가?", "방향족 고리가 있는가?" 같은 예/아니오 질문을 나무 모양으로 이어 분류·회귀하는 모형. 해석이 쉽지만 깊어지면 과적합하기 쉬워, 여러 나무를 평균한 랜덤 포레스트를 많이 쓴다.

랜덤 포레스트와 원형 지문의 조합은 신약 후보의 활성 분류에서 지금도 강력한 기준선입니다. 신경망을 쓰기 전에 이런 단순한 모형으로 먼저 기준 성능을 잡는 것이 좋은 습관입니다.

흔한 오해"R²가 0.97이면 아주 좋은 모형"은 문제에 따라 다릅니다. 알케인 끓는점처럼 단순한 경향이 뚜렷한 자료에서는 평범한 값이고, RMSE와 잔차 무늬가 더 많은 것을 알려 줍니다. 또 "모형을 복잡하게 할수록 좋아진다"도 아닙니다. 같은 매개변수 수에서 특성을 잘 고르는 것이 먼저입니다. 그리고 훈련 자료로 계산한 R²는 새 자료에 대한 성능을 과대평가합니다(3.2절).
요약
  1. 지도학습: 목표값, 특성, 모형, 손실, 평가를 정한다. 회귀는 연속값, 분류는 범주.
  2. RMSE는 오차의 크기(단위 있음), R²는 평균 대비 개선. 잔차 무늬로 모형의 맞음새를 본다.
  3. 알케인 끓는점: n 대신 √n 특성으로 RMSE 17.33 → 2.51 °C. 화학 지식을 특성에 넣는다.
  4. 분류는 로지스틱 회귀(시그모이드, 교차 엔트로피), 결정나무·랜덤 포레스트.

3.1.5연습문제

기본

  1. 예측 오차가 2, −1, −3, 2(°C)일 때 RMSE는?
    답

    √((4 + 1 + 9 + 4)/4) = √4.5 = 2.12 °C.

응용

  1. √n 모형 \(\hat y = -309.93 + 154.01\sqrt n\)으로 도데케인(C12)의 끓는점을 예측하고 실제값 216 °C와 비교하시오.
    답

    √12 = 3.464, 예측 −309.93 + 533.5 = 223.6 °C. 실제보다 약 8 °C 높다. 자료 범위에서 멀어질수록 오차가 커지는 외삽의 한계가 보인다.

심화

  1. 로지스틱 회귀에서 z = 2.0인 분자의 활성 확률은? 실제로 비활성(y = 0)이라면 이 샘플의 교차 엔트로피 손실은?
    답

    σ(2) = 1/(1 + e⁻²) = 0.881. y = 0이므로 손실 = −ln(1 − 0.881) = −ln 0.119 = 2.13. 자신 있게 틀린 예측일수록 손실이 크게 매겨진다.
