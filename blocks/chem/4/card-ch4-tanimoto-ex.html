세 분자 가운데 가장 닮은 짝 고르기

타니모토 계수 · 비트 세기 · 해석

출발점

타니모토 계수는 공통 비트를 합집합 비트로 나눈 값이다. 짝마다 a, b, c를 세어 계산한다.

짧은 지문에서 분자 A의 켜진 비트가 {1, 3, 4, 7, 9, 12}, B가 {1, 3, 5, 7, 12, 15, 18}, C가 {2, 4, 9, 10}이다. 세 짝의 타니모토 계수를 구하고 가장 닮은 짝을 고르시오.

풀이

  1. A, B: a = 6, b = 7, 공통 {1, 3, 7, 12}로 c = 4. \(T = 4/(6 + 7 - 4) = 0.444\).
    합집합은 9비트이다.
  2. A, C: a = 6, b = 4, 공통 {4, 9}로 c = 2. \(T = 2/8 = 0.250\).
  3. B, C: 공통 비트 없음, \(T = 0\).
    공통 조각이 하나도 없다.
  4. 가장 닮은 짝은 A와 B(0.444)이다.
    C는 A와 조각 두 개를 공유하지만 B와는 하나도 공유하지 않는다.

의미

A는 B와도 C와도 조각을 공유해 셋 가운데 "가운데" 분자이다. 유사도 검색으로 A와 닮은 분자를 찾으면 B가 먼저, C가 다음에 나온다. 그러나 이 순서가 활성의 순서와 같다는 보장은 없다. 활성 절벽이 있다면 가장 닮은 B가 전혀 다른 활성을 가질 수도 있다.

검산

T는 대칭이어야 하므로 T(A, B) = T(B, A)이고, 식에서 a와 b를 바꿔도 값이 같다. 또 c ≤ min(a, b)라 T ≤ min(a, b)/max(a, b)인데, A, B는 6/7 = 0.857 이하, A, C는 4/6 = 0.667 이하로 계산값이 그 안에 있다.
