행렬 곱과 기울기를 코드로

본문

메테인부터 뷰테인까지 네 알케인의 끓는점을 탄소 수 하나로 예측하는 직선을 만들고 싶다. 분자 네 개, 숫자 몇 개뿐인데 왜 화학 AI 교재는 행렬부터 꺼낼까? 그리고 직선이 얼마나 틀렸는지, 어느 쪽으로 고쳐야 할지는 어떻게 숫자로 알 수 있을까?

먼저 알아야 할 것파이썬 리스트와 반복문(공통10 2.1절, 2.3절), 함수(공통10 3.1절), 고교 미분(다항함수의 도함수, 수학II)과 합의 기호 Σ(수학I)를 쓴다. 행렬과 편미분은 고교 과정에 없으므로 이 절에서 처음부터 설명한다.

1.1.1왜 화학 AI에 행렬이 나오나

기계 학습 모형은 숫자의 표를 받아 숫자를 내놓는 함수이다. 분자 여러 개의 성질을 예측하려면, 분자마다 숫자 몇 개를 뽑아 한 줄에 놓고 분자를 줄마다 쌓은 표를 만든다. 이 표가 설계 행렬 \(X\)이다. 여기서 숫자를 줄(행)과 칸(열)에 맞춰 직사각형으로 늘어놓은 표를 행렬이라 하며, 줄이 \(n\)개, 열이 \(m\)개면 \(n\times m\) 행렬이라 하고 \(A_{ij}\)는 \(i\)번째 줄, \(j\)번째 열의 숫자이다. 열이 하나뿐인 \(n\times1\) 행렬은 숫자를 세로로 늘어놓은 목록으로, 굵은 글씨 \(\mathbf w\), \(\mathbf y\)로 쓰고 벡터라고도 부른다.

표의 한 줄은 샘플, 곧 분자 하나이다. 표의 한 열은 특성 또는 기술자로, 탄소 수, 분자량, 극성 표면적처럼 분자에서 계산한 숫자이다. 가중치 \(\mathbf w\)는 모형이 학습으로 정하는 숫자들이며, 선형 모형에서는 특성마다 하나씩 곱하는 계수이다. 그러면 선형 모형의 예측은 각 샘플에서 특성과 가중치를 곱해 더한 것이고, 모든 샘플을 한꺼번에 쓰면 행렬 곱 \(\hat{\mathbf y} = X\mathbf w\)가 된다. 4단원의 신경망도 이런 행렬 곱을 여러 번 쌓은 것이므로, 행렬 곱은 화학 AI의 가장 기본 연산이다. 처음 질문의 첫째 답이 이것이다.

1.1.2행렬 곱을 직접 구현하기

\(n\times m\) 행렬 A와 \(m\times p\) 행렬 B의 곱 C(\(n\times p\))는 \(C_{ij} = \sum_k A_{ik}B_{kj}\)로 정의한다. 곧 A의 \(i\)번째 줄과 B의 \(j\)번째 열을 짝지어 곱해 더하므로, A의 열 수와 B의 행 수가 같아야 한다. 여기서 Σ는 \(k\)를 1부터 \(m\)까지 바꾸며 더하라는 뜻이다.

손으로 한 번 해 보자. A = [[1, 2], [3, 4]], B = [[5], [6]]이면 C의 첫째 줄은 A의 첫째 줄 (1, 2)와 B의 열 (5, 6)을 짝지어 1×5 + 2×6 = 17이고, 둘째 줄은 3×5 + 4×6 = 39이다. 따라서 C = [[17], [39]]이며, 2×2에 2×1을 곱해 2×1이 나왔다. 줄마다 짝지어 곱해 더하기가 행렬 곱의 전부이고, 이것이 특성과 가중치를 곱해 더한 것과 같은 계산이다.

def matmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    assert len(A[0]) == m, "A의 열 수와 B의 행 수가 같아야 합니다"
    C = [[0.0] * p for _ in range(n)]
    for i in range(n):
        for j in range(p):
            for k in range(m):
                C[i][j] += A[i][k] * B[k][j]
    return C

X = [[1, 1], [1, 2], [1, 3], [1, 4]]   # 첫 열은 절편용 1, 둘째 열은 탄소 수
w = [[-200.0], [60.0]]                 # [절편, 기울기]
print(matmul(X, w))                    # [[-140.0], [-80.0], [-20.0], [40.0]]

X는 메테인부터 뷰테인까지 네 알케인(4×2), w는 2×1이라 결과는 4×1, 곧 네 분자의 예측 끓는점이다. 첫 열을 모두 1로 둔 것은 절편 \(b\)를 행렬 곱 안에 넣는 요령으로, 그림 1처럼 \(b\times1 + a\times n_C\)가 된다. 실제 프로그램에서는 NumPy의 X @ w가 같은 일을 훨씬 빠르게 하며, 세 겹 반복문은 원리를 보려고 쓴 것이다.

1.1.3손실 함수

좋은 가중치를 찾으려면 모형이 얼마나 틀렸는지를 숫자 하나로 나타내야 한다. 가장 흔한 것이 평균 제곱 오차(MSE) \(L = \frac1N\sum_i (\hat y_i - y_i)^2\)로, 예측과 실제의 차이를 제곱해 평균한 값이며 0이면 완벽하다. 제곱을 쓰는 이유는 양과 음의 오차가 상쇄되지 않게 하고 미분하기 쉽게 하기 위해서이다. 예를 들어 실제 끓는점(메테인 −161.5, 에테인 −88.6, 프로페인 −42.1, 뷰테인 −0.5 °C)과 위 예측을 비교하면 \(L = 666.22\) °C²이다.

1.1.4기울기 유도

이제 가중치를 조금 바꿀 때 손실이 얼마나 바뀌는지, 곧 \(\partial L/\partial b\)와 \(\partial L/\partial a\)를 구한다. 이 방향을 알아야 손실을 줄이는 쪽으로 가중치를 움직일 수 있다(1.2절). 변수가 여럿인 함수에서 나머지 변수는 상수로 묶어 두고 한 변수로만 미분하는 것을 편미분이라 한다. \(\partial L/\partial a\)는 \(b\)는 그대로 두고 \(a\)만 조금 바꿀 때 \(L\)이 바뀌는 빠르기이며, 계산 방법은 고교에서 배운 미분과 똑같다. 가령 \(f(a, b) = a^2 b + 3b\)라면 \(\partial f/\partial a = 2ab\), \(\partial f/\partial b = a^2 + 3\)이다.

예측 \(\hat y_i = b + a x_i\)를 넣으면 손실의 각 항은 \((b + a x_i - y_i)^2\)이다. 고교 미분의 \(\{(\text{일차식})^2\}' = 2\times(\text{일차식})\times(\text{일차식의 기울기})\)를 쓰면, 안쪽 일차식의 기울기는 \(b\)에 대해 1, \(a\)에 대해 \(x_i\)이므로 다음을 얻는다.

\[ \frac{\partial L}{\partial b} = \frac2N\sum_i(\hat y_i - y_i), \qquad \frac{\partial L}{\partial a} = \frac2N\sum_i(\hat y_i - y_i)\,x_i \] 
n_c = [1, 2, 3, 4]
y = [-161.5, -88.6, -42.1, -0.5]      # 메테인~뷰테인 끓는점 (°C)

def loss(b, a):
    return sum((b + a * x - t) ** 2 for x, t in zip(n_c, y)) / len(y)

def grad(b, a):
    N = len(y)
    gb = sum(2 * (b + a * x - t) for x, t in zip(n_c, y)) / N
    ga = sum(2 * (b + a * x - t) * x for x, t in zip(n_c, y)) / N
    return gb, ga

print(round(loss(-200, 60), 2), grad(-200, 60))   # 666.22 (46.35, 133.5) 근처

두 기울기가 모두 양수이므로 \(b\)와 \(a\)를 줄이면 손실이 줄어든다. 처음 질문의 둘째 답이 이것이다. 또 기울기 \(a\) 쪽(133.5)이 더 큰 것은 탄소 수가 큰 샘플일수록 오차에 \(x_i\)가 곱해져 영향이 커지기 때문이다. 실제 출력은 부동소수점 때문에 46.349999999999994처럼 보일 수 있다(공통10 6.1절).

1.1.5수치 미분으로 검산

손으로 유도한 기울기가 맞는지는 중심 차분 \(\dfrac{L(a+h) - L(a-h)}{2h}\)로 확인한다.

h = 1e-5
print((loss(-200, 60 + h) - loss(-200, 60 - h)) / (2 * h))   # 133.50000003...

해석적 값 133.5와 소수 일곱째 자리까지 맞는다. 기울기 코드를 새로 짤 때마다 이렇게 검산하는 습관은 신경망의 역전파(4.1절)를 디버깅할 때도 그대로 쓰인다.

흔한 오해행렬 곱을 같은 자리끼리 곱하는 것으로 생각하기 쉽다. 그것은 원소별 곱(NumPy의 *)이고, 행렬 곱은 줄과 열의 내적(@)이다. 또 기울기가 크면 손실이 크다는 것도 틀린다. 기울기는 손실이 바뀌는 빠르기이며, 최솟값에서는 손실이 0이 아니어도 기울기는 0이다. 그리고 수치 미분의 \(h\)를 1e−15처럼 너무 작게 잡으면 반올림 오차 때문에 오히려 틀린 값이 나온다.
마무리

화학 자료는 샘플을 줄로, 특성을 열로 놓은 설계 행렬 \(X\)이고, 선형 모형의 예측은 행렬 곱 \(\hat{\mathbf y} = X\mathbf w\)이며 절편은 1의 열로 넣는다. 행렬 곱 \(C_{ij} = \sum_k A_{ik}B_{kj}\)는 A의 열 수와 B의 행 수가 같아야 한다. 처음 질문의 직선이 얼마나 틀렸는지는 MSE 손실 \(L = \frac1N\sum(\hat y - y)^2\)으로, 어느 쪽으로 고칠지는 기울기 \(\partial L/\partial a = \frac2N\sum(\hat y - y)x\)로 알며, 해석적 기울기는 중심 차분으로 검산한다.

1.1.6연습문제

기본

  1. 10개 분자, 특성 5개짜리 설계 행렬 X에 가중치를 곱해 예측을 얻으려면 w의 크기와 결과의 크기는?
    답

    w는 5×1, 결과는 10×1(분자마다 예측 하나). 절편을 1의 열로 넣으면 X는 10×6, w는 6×1.

응용

  1. 본문의 자료와 (b, a) = (−200, 50)에서 손실과 ∂L/∂a의 부호를 구하고, a를 늘려야 하는지 줄여야 하는지 쓰시오.
    답

    예측 −150, −100, −50, 0. 오차 11.5, −11.4, −7.9, 0.5. L = (132.25 + 129.96 + 62.41 + 0.25)/4 = 81.22. ∂L/∂a = 2/4 × (11.5 − 22.8 − 23.7 + 2.0) = −16.5 < 0이므로 a를 늘려야 손실이 준다.

심화

  1. 손실을 평균 절대 오차 \(\frac1N\sum|\hat y - y|\)로 바꾸면 ∂L/∂a는 어떻게 되는가? 오차가 정확히 0인 점에서 어떤 문제가 있는가?
    답

    \(\frac1N\sum \mathrm{sign}(\hat y_i - y_i)\,x_i\). 오차 크기와 무관하게 부호만 쓴다. 오차가 0인 점에서 절댓값은 미분 불가능해 기울기가 정의되지 않는다(실제 코드에서는 0으로 둔다). 이상치에 덜 민감한 대신 최솟값 근처에서 수렴이 거칠다.
