본문

  • 골격 구조식 (화학2 1.1절), R/S와 E/Z (화학2 4.1절), 파이썬 문자열과 딕셔너리 (공통10 2.2절).

2.1.1컴퓨터에게 분자를 알려 주기

화학자는 구조식을 그림으로 그리지만, 컴퓨터에 수백만 개 분자를 저장하고 검색하려면 글자로 바꿔야 합니다. 가장 널리 쓰는 방법이 SMILES(Simplified Molecular-Input Line-Entry System)입니다. 화합물 데이터베이스(PubChem, ChEMBL)와 화학 AI 자료 대부분이 SMILES로 분자를 저장합니다.

2.1.2SMILES 규칙

  • 원자: 원소 기호. 유기 원소(B, C, N, O, P, S, F, Cl, Br, I)는 수소를 쓰지 않아도 원자가에 맞춰 붙는다. CCO는 CH₃CH₂OH, 에탄올.
  • 결합: 단일 결합은 생략, 이중 결합 =, 삼중 결합 #. C=C는 에틸렌, C#N은 HCN.
  • 가지: 괄호. CC(=O)O는 아세트산(둘째 C에 =O와 O가 붙음). CC(C)C는 아이소뷰테인.
  • 고리: 고리를 여는 원자와 닫는 원자에 같은 숫자. C1CCCCC1은 사이클로헥세인.
  • 방향족: 소문자. c1ccccc1은 벤젠, c1ccncc1은 피리딘.
  • 대괄호 원자: 전하, 수소 수, 동위원소, 유기 원소 밖의 원자. [NH4+], [O-], [13CH4], [Na+].
  • 입체: 이중 결합 배치는 /, \. C/C=C/C는 (E)-2-뷰텐, C/C=C\C는 (Z). 사면체 입체 중심은 @, @@(뒤에 오는 이웃을 앞 원자 쪽에서 볼 때 반시계·시계 방향). L-알라닌은 N[C@@H](C)C(=O)O.

2.1.3한 분자, 여러 SMILES

에탄올은 CCO, OCC, C(O)C로 모두 쓸 수 있습니다. 어느 원자에서 시작해 어떤 순서로 걷느냐에 따라 문자열이 달라지기 때문입니다. 그대로 두면 같은 분자가 자료에 여러 번 들어가 중복을 찾지 못합니다. 그래서 프로그램(RDKit 등)이 정해진 규칙으로 하나를 고른 정규 SMILES를 만들어 비교합니다. 반대로 기계 학습에서는 일부러 여러 SMILES를 만들어 자료를 늘리기도 합니다(자료 증강).

2.1.4분자는 그래프다

원자를 점, 결합을 선으로 보면 분자는 그래프이고, SMILES는 이 그래프를 한 줄 문자열로 펼친 것입니다. 그래프를 컴퓨터가 계산할 수 있는 인접 행렬과 원자 특성 행렬로 쓰는 방법은 2.4절에서 다룹니다.

2.1.5코드로 SMILES 읽기

실무에서는 RDKit의 Chem.MolFromSmiles로 SMILES를 분자 객체로 바꿉니다(2.2절). 원리를 보기 위해, 정규식으로 SMILES를 토큰으로 나눠 무거운 원자를 세는 짧은 코드를 써 봅시다.

import re
TOKEN = re.compile(r"Cl|Br|\[[^\]]+\]|[BCNOPSFI]|[bcnops]|\(|\)|=|#|/|\\|\d|%\d\d")

def heavy_atoms(smiles):
    counts = {}
    for t in TOKEN.findall(smiles):
        if t[0] == "[":
            sym = re.match(r"\[(\d*)([A-Z][a-z]?|[a-z]+)", t).group(2)
        elif t[0].isalpha():
            sym = t
        else:
            continue                      # 괄호, 결합 기호, 고리 숫자
        sym = sym.capitalize()            # 방향족 c → C
        counts[sym] = counts.get(sym, 0) + 1
    return counts

print(heavy_atoms("CC(=O)Oc1ccccc1C(=O)O"))       # {'C': 9, 'O': 4}
print(heavy_atoms("Cn1cnc2c1c(=O)n(C)c(=O)n2C"))  # {'C': 8, 'N': 4, 'O': 2}

아스피린 C₉H₈O₄, 카페인 C₈H₁₀N₄O₂의 무거운 원자 수와 맞습니다. Cl과 Br을 C보다 먼저 맞추게 한 것이 중요합니다. 그렇지 않으면 "Cl"을 "C"와 "l"로 잘못 자릅니다. 수소 수를 세려면 원자가와 결합 차수, 방향족성을 따져야 해서 훨씬 복잡해지므로, 이런 일은 검증된 라이브러리에 맡깁니다.

흔한 오해"SMILES가 다르면 다른 분자"가 아닙니다. 같은 분자에 여러 SMILES가 있으므로 정규화해 비교합니다. 또 소문자 c를 쓰려면 고리 전체가 방향족이어야 합니다. c1ccccc1은 벤젠이지만 c1cccc1(다섯 개)은 올바른 방향족 구조가 아니어서 오류가 납니다. 그리고 입체 기호를 빼면 거울상 이성질체나 E/Z 이성질체가 구별되지 않습니다. 약물 자료에서는 이 차이가 활성을 바꿀 수 있습니다.
요약
  1. SMILES: 원자 기호, = #, 괄호 가지, 숫자 고리, 소문자 방향족, [ ] 특수 원자, / \ @ 입체.
  2. 한 분자에 여러 SMILES. 비교에는 정규 SMILES.
  3. 분자 = 그래프(원자 꼭짓점, 결합 변). 인접 행렬은 그래프 신경망의 입력.
  4. 파싱과 수소 계산은 RDKit 같은 라이브러리로 한다.

2.1.6연습문제

기본

  1. 다음 SMILES가 나타내는 분자 이름은? (가) CC(C)O, (나) C1CCOC1, (다) OC(=O)c1ccccc1
    답

    (가) 2-프로판올, (나) 테트라하이드로퓨란(THF), (다) 벤조산.

응용

  1. (Z)-2-뷰텐, 사이클로펜탄온, 아닐린의 SMILES를 쓰시오.
    답

    C/C=C\C, O=C1CCCC1, Nc1ccccc1.

심화

  1. 프로판산 CCC(=O)O의 무거운 원자 그래프 인접 행렬(결합 차수 포함)을 쓰시오. 원자 순서는 SMILES 순서로 한다.
    답

    원자 C1, C2, C3, O4(=O), O5(−OH). 결합 C1−C2(1), C2−C3(1), C3=O4(2), C3−O5(1). 행렬 행 순서대로 [0,1,0,0,0], [1,0,1,0,0], [0,1,0,2,1], [0,0,2,0,0], [0,0,1,0,0].
