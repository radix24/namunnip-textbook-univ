SMILES와 분자 그래프

본문

PubChem에는 1억 개가 넘는 화합물이 들어 있다. 구조식 그림을 그대로 저장하면 어떤 두 분자가 같은지조차 컴퓨터가 판단하기 어렵다. 분자를 한 줄 글자로 바꿀 수 있다면 어떤 규칙이 필요하고, 같은 분자는 늘 같은 글자가 될까?

먼저 알아야 할 것골격 구조식(화학2 1.1절), R/S와 E/Z(화학2 4.1절), 파이썬 문자열과 딕셔너리(공통10 2.2절)를 쓴다.

2.1.1컴퓨터에게 분자를 알려 주기

화학자는 구조식을 그림으로 그리지만, 컴퓨터에 수백만 개 분자를 저장하고 검색하려면 글자로 바꿔야 한다. 가장 널리 쓰는 방법이 SMILES(Simplified Molecular-Input Line-Entry System)이다. PubChem, ChEMBL 같은 화합물 데이터베이스와 화학 AI 자료 대부분이 SMILES로 분자를 저장한다.

2.1.2SMILES 규칙

SMILES는 그림 1처럼 분자 그래프를 한 원자에서 시작해 걸으며 원소 기호를 적는다. B, C, N, O, P, S, F, Cl, Br, I 같은 유기 원소는 수소를 쓰지 않아도 원자가에 맞춰 붙으므로, CCO는 CH₃CH₂OH, 곧 에탄올이다. 나머지 규칙은 다음 표와 같다.

규칙표기예
결합단일 결합은 생략, 이중 =, 삼중 #C=C 에틸렌, C#N 사이안화 수소
가지괄호CC(=O)O 아세트산, CC(C)C 아이소뷰테인
고리여는 원자와 닫는 원자에 같은 숫자C1CCCCC1 사이클로헥세인
방향족소문자c1ccccc1 벤젠, c1ccncc1 피리딘
대괄호 원자전하, 수소 수, 동위원소, 유기 원소 밖의 원자[NH4+], [O-], [13CH4], [Na+]
이중 결합 배치/, \C/C=C/C (E)-2-뷰텐, C/C=C\C (Z)
사면체 입체 중심@, @@ (뒤 이웃을 앞 원자 쪽에서 볼 때 반시계·시계)N[C@@H](C)C(=O)O L-알라닌

규칙을 몇 번 써 보면 익숙해진다. 아세톤은 CC(=O)C, 아세트산 에틸은 CCOC(C)=O, 톨루엔은 Cc1ccccc1, 아스피린은 CC(=O)Oc1ccccc1C(=O)O, 카페인은 Cn1cnc2c1c(=O)n(C)c(=O)n2C이다.

2.1.3한 분자, 여러 SMILES

그런데 에탄올은 CCO, OCC, C(O)C로 모두 쓸 수 있다. 어느 원자에서 시작해 어떤 순서로 걷느냐에 따라 문자열이 달라지기 때문이다. 그대로 두면 같은 분자가 자료에 여러 번 들어가 중복을 찾지 못한다. 그래서 RDKit 같은 프로그램이 정해진 규칙으로 하나를 고른 정규 SMILES를 만들어 비교한다. 처음 질문의 둘째 답이 이것이다. 반대로 기계 학습에서는 일부러 여러 SMILES를 만들어 자료를 늘리기도 하며, 이것을 자료 증강이라 한다.

2.1.4분자는 그래프다

원자를 점, 결합을 선으로 보면 분자는 그래프이고, SMILES는 이 그래프를 한 줄 문자열로 펼친 것이다. 그래프를 컴퓨터가 계산할 수 있는 인접 행렬과 원자 특성 행렬로 쓰는 방법은 2.4절에서 다룬다.

2.1.5코드로 SMILES 읽기

실무에서는 RDKit의 Chem.MolFromSmiles로 SMILES를 분자 객체로 바꾼다(2.2절). 여기서는 원리를 보기 위해, 정규식으로 SMILES를 토큰으로 나눠 무거운 원자를 세는 짧은 코드를 써 보자.

import re
TOKEN = re.compile(r"Cl|Br|\[[^\]]+\]|[BCNOPSFI]|[bcnops]|\(|\)|=|#|/|\\|\d|%\d\d")

def heavy_atoms(smiles):
    counts = {}
    for t in TOKEN.findall(smiles):
        if t[0] == "[":
            sym = re.match(r"\[(\d*)([A-Z][a-z]?|[a-z]+)", t).group(2)
        elif t[0].isalpha():
            sym = t
        else:
            continue                      # 괄호, 결합 기호, 고리 숫자
        sym = sym.capitalize()            # 방향족 c → C
        counts[sym] = counts.get(sym, 0) + 1
    return counts

print(heavy_atoms("CC(=O)Oc1ccccc1C(=O)O"))       # {'C': 9, 'O': 4}
print(heavy_atoms("Cn1cnc2c1c(=O)n(C)c(=O)n2C"))  # {'C': 8, 'N': 4, 'O': 2}

결과는 아스피린 C₉H₈O₄, 카페인 C₈H₁₀N₄O₂의 무거운 원자 수와 맞는다. 이때 Cl과 Br을 C보다 먼저 맞추게 한 것이 중요하다. 그렇지 않으면 Cl을 C와 l로 잘못 자른다. 한편 수소 수를 세려면 원자가와 결합 차수, 방향족성을 따져야 해서 훨씬 복잡해지므로, 이런 일은 검증된 라이브러리에 맡긴다.

흔한 오해SMILES가 다르면 다른 분자라고 생각하기 쉽지만, 같은 분자에 여러 SMILES가 있으므로 정규화해 비교한다. 또 소문자 c를 쓰려면 고리 전체가 방향족이어야 한다. c1ccccc1은 벤젠이지만 c1cccc1처럼 다섯 개만 쓰면 올바른 방향족 구조가 아니어서 오류가 난다. 그리고 입체 기호를 빼면 거울상 이성질체나 E/Z 이성질체가 구별되지 않는데, 약물 자료에서는 이 차이가 활성을 바꿀 수 있다.
마무리

SMILES는 분자 그래프를 걸으며 원소 기호를 적은 문자열로, 결합은 =와 #, 가지는 괄호, 고리는 숫자, 방향족은 소문자, 특수 원자는 대괄호, 입체는 /, \, @로 나타낸다. 처음 질문처럼 한 분자에 여러 SMILES가 가능하므로, 같은 분자인지 비교할 때는 정규 SMILES를 쓴다. 분자는 원자를 꼭짓점, 결합을 변으로 하는 그래프이며, 파싱과 수소 계산은 RDKit 같은 라이브러리로 한다.

2.1.6연습문제

기본

  1. 다음 SMILES가 나타내는 분자 이름은? (가) CC(C)O, (나) C1CCOC1, (다) OC(=O)c1ccccc1
    답

    (가) 2-프로판올, (나) 테트라하이드로퓨란(THF), (다) 벤조산.

응용

  1. (Z)-2-뷰텐, 사이클로펜탄온, 아닐린의 SMILES를 쓰시오.
    답

    C/C=C\C, O=C1CCCC1, Nc1ccccc1.

심화

  1. 프로판산 CCC(=O)O의 무거운 원자 그래프 인접 행렬(결합 차수 포함)을 쓰시오. 원자 순서는 SMILES 순서로 한다.
    답

    원자 C1, C2, C3, O4(=O), O5(−OH). 결합 C1−C2(1), C2−C3(1), C3=O4(2), C3−O5(1). 행렬 행 순서대로 [0,1,0,0,0], [1,0,1,0,0], [0,1,0,2,1], [0,0,2,0,0], [0,0,1,0,0].
