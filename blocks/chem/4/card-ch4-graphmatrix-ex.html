에탄올과 다이메틸 에터를 행렬로 쓰고 이웃 모으기

인접 행렬 · 원자 특성 행렬 · AX

출발점

분자식이 같은 두 이성질체도 인접 행렬과 원자 특성이 다르면 AX가 달라집니다. 원소 원-핫(C, N, O)과 수소 수를 특성으로 씁니다.

에탄올(CCO, 원자 순서 C1, C2, O3)과 다이메틸 에터(COC, 원자 순서 C1, O2, C3)의 인접 행렬 A와 원자 특성 행렬 X(열: C, N, O, 수소 수)를 쓰고 AX를 구해 두 분자가 구별되는지 보여라.

풀이

  1. 두 분자 모두 사슬 세 원자라 \(A = \begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix}\).
    인접 행렬만으로는 두 분자가 같습니다.
  2. 에탄올 X: C1 (1, 0, 0, 3), C2 (1, 0, 0, 2), O3 (0, 0, 1, 1). 에터 X: C1 (1, 0, 0, 3), O2 (0, 0, 1, 0), C3 (1, 0, 0, 3).
    원자의 종류와 수소 수가 다릅니다.
  3. 에탄올 AX: 1행 = X₂ = (1, 0, 0, 2), 2행 = X₁ + X₃ = (1, 0, 1, 4), 3행 = X₂ = (1, 0, 0, 2).
    각 원자가 이웃의 특성을 더해 받습니다.
  4. 에터 AX: 1행 = (0, 0, 1, 0), 2행 = (2, 0, 0, 6), 3행 = (0, 0, 1, 0).
    가운데 산소가 탄소 둘과 수소 여섯을 이웃으로 받습니다.

의미

에터에서는 탄소가 산소를 이웃으로 받고(1행의 O 성분 1), 에탄올에서는 끝 탄소가 탄소만 받습니다. 이 차이를 행마다 더하면(합 풀링) 에탄올 (3, 0, 1, 8), 에터 (2, 0, 2, 6)으로 분자 전체의 벡터도 달라집니다. 한 번의 이웃 모으기로 이성질체가 구별되는 것이고, 4.2절의 탐구 카드는 이 계산을 여러 층 되풀이합니다.

검산

A의 행 합(1, 2, 1)은 각 원자의 무거운 원자 이웃 수와 같아야 하고, 두 분자 모두 맞습니다. 또 원자 순서를 바꿔 에탄올을 O, C, C로 적어도 AX의 행이 같은 방식으로 뒤섞일 뿐 행들의 모임은 같습니다.
