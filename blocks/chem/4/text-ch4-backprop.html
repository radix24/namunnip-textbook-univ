다층 신경망의 순전파와 역전파

본문
이 절에서 배울 것
  • 퍼셉트론과 다층 신경망의 구조(층, 가중치, 활성화 함수)를 안다.
  • 작은 신경망의 순전파를 손으로 계산한다.
  • 연쇄 법칙으로 역전파를 유도하고, 수치 미분으로 검산한다.
  • 활성화 함수가 비선형이어야 하는 이유를 설명한다.
먼저 알아야 할 것
  • 행렬 곱과 기울기 (1.1절), 경사 하강법 (1.2절), 로지스틱 회귀 (3.1절).

4.1.1퍼셉트론에서 다층 신경망으로

뉴런(단위): 입력의 가중합에 편향을 더한 \(z = \mathbf w\cdot\mathbf x + b\)를 활성화 함수 f에 넣어 \(h = f(z)\)를 내는 계산 단위. 시그모이드를 쓰면 3.1절의 로지스틱 회귀와 같다.

은닉층: 입력과 출력 사이의 뉴런 층. 앞 층의 출력이 다음 층의 입력이 된다.

활성화 함수: 시그모이드 \(\sigma(z) = 1/(1+e^{-z})\), tanh, ReLU \(\max(0, z)\) 등. 비선형이어야 한다.

왜 비선형이어야 할까요? 활성화 함수가 선형이면 층을 아무리 쌓아도 행렬 곱의 곱은 다시 행렬 하나(\(W_2W_1\mathbf x = W\mathbf x\))라 선형 모형 하나와 같습니다. 비선형 함수를 끼워야 층을 쌓을수록 복잡한 함수를 표현할 수 있습니다. 은닉층이 하나라도 뉴런이 충분히 많으면 임의의 연속 함수를 원하는 만큼 가깝게 근사할 수 있다는 것이 알려져 있습니다(보편 근사 정리).

4.1.2순전파: 손으로 계산하기

입력 하나, 은닉 뉴런 둘(시그모이드), 출력 하나(선형)인 신경망을 봅시다. x = 0.5, 정답 y = 1.0, 가중치 \(W_1 = (0.4, -0.6)\), \(b_1 = (0.1, 0.2)\), \(W_2 = (0.7, 0.3)\), \(b_2 = 0.05\), 손실 \(L = (\hat y - y)^2\).

  1. 은닉층 입력: \(z_1 = 0.4 \times 0.5 + 0.1 = 0.3\), \(z_2 = -0.6 \times 0.5 + 0.2 = -0.1\).
  2. 은닉층 출력: \(h_1 = \sigma(0.3) = 0.5744\), \(h_2 = \sigma(-0.1) = 0.4750\).
  3. 출력: \(\hat y = 0.7 \times 0.5744 + 0.3 \times 0.4750 + 0.05 = 0.5946\).
  4. 손실: \(L = (0.5946 - 1)^2 = 0.1643\).

4.1.3역전파: 연쇄 법칙을 뒤에서부터

구하려는 것: 모든 가중치에 대한 ∂L/∂w. 경사 하강법(1.2절)으로 갱신하려면 이것이 필요합니다.

출력 쪽부터 한 단계씩 거꾸로 곱해 갑니다. 각 단계는 "바로 뒤 값에 대한 기울기 × 이 단계의 국소 미분"입니다.

  1. \(\partial L/\partial\hat y = 2(\hat y - y) = -0.8108\).
  2. 출력층 가중치: \(\partial L/\partial W_{2,j} = (\partial L/\partial\hat y)\,h_j\) → (−0.4657, −0.3851). \(\partial L/\partial b_2 = -0.8108\).
  3. 은닉층 출력: \(\partial L/\partial h_j = (\partial L/\partial\hat y)\,W_{2,j}\).
  4. 시그모이드 통과: \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\)이므로 \(\partial L/\partial z_j = (\partial L/\partial h_j)\,h_j(1 - h_j)\).
  5. 은닉층 가중치: \(\partial L/\partial W_{1,j} = (\partial L/\partial z_j)\,x\) → (−0.0694, −0.0303).
import math
sig = lambda z: 1 / (1 + math.exp(-z))
x, y = 0.5, 1.0
W1, b1, W2, b2 = [0.4, -0.6], [0.1, 0.2], [0.7, 0.3], 0.05

def forward(W1, b1, W2, b2):
    h = [sig(W1[j] * x + b1[j]) for j in range(2)]
    yhat = sum(W2[j] * h[j] for j in range(2)) + b2
    return h, yhat, (yhat - y) ** 2

h, yhat, L = forward(W1, b1, W2, b2)
g = 2 * (yhat - y)                                  # dL/dyhat
dW2 = [g * h[j] for j in range(2)]
dz = [g * W2[j] * h[j] * (1 - h[j]) for j in range(2)]
dW1 = [dz[j] * x for j in range(2)]

eps = 1e-6                                          # 수치 미분 검산
num = (forward([W1[0] + eps, W1[1]], b1, W2, b2)[2]
       - forward([W1[0] - eps, W1[1]], b1, W2, b2)[2]) / (2 * eps)
print(round(dW1[0], 6), round(num, 6))              # -0.06937 -0.06937

역전파와 수치 미분이 같은 값을 줍니다. 학습률 0.5로 모든 가중치를 한 번 갱신하면 손실이 0.1643에서 0.0623으로 줄어듭니다.

역전파가 중요한 이유는 효율입니다. 가중치가 백만 개일 때 수치 미분은 순전파를 이백만 번 해야 하지만, 역전파는 순전파 한 번과 거꾸로 한 번이면 모든 기울기를 얻습니다. 중간값(h, z)을 순전파 때 저장해 두었다가 다시 쓰기 때문입니다. PyTorch 같은 라이브러리는 이 과정을 자동으로 합니다(자동 미분).

흔한 오해"역전파는 학습 알고리즘"이라기보다 기울기를 계산하는 방법입니다. 학습(갱신)은 그 기울기로 경사 하강법을 하는 것입니다. 또 "층이 깊을수록 무조건 좋다"도 아닙니다. 시그모이드를 여러 층 쌓으면 σ′ ≤ 0.25가 계속 곱해져 앞쪽 층의 기울기가 사라지는 문제(기울기 소실)가 생깁니다. 그래서 은닉층에는 주로 ReLU를 씁니다. 그리고 가중치를 모두 0으로 시작하면 은닉 뉴런들이 똑같이 학습되어 하나인 것과 같아지므로, 작은 무작위 값으로 시작합니다.
요약
  1. 뉴런: \(h = f(\mathbf w\cdot\mathbf x + b)\). 층을 쌓은 것이 다층 신경망. 활성화는 비선형이어야 한다.
  2. 순전파: 입력에서 출력까지 차례로 계산하고 중간값을 저장한다.
  3. 역전파: 출력에서 거꾸로 연쇄 법칙을 곱해 모든 ∂L/∂w를 한 번에 얻는다. 수치 미분으로 검산한다.
  4. 깊은 시그모이드 망은 기울기 소실. ReLU, 무작위 초기화.

4.1.4연습문제

기본

  1. 입력 10개, 은닉층 32개, 출력 1개인 신경망의 가중치와 편향은 모두 몇 개인가?
    답

    10 × 32 + 32 + 32 × 1 + 1 = 385개.

응용

  1. 본문 예에서 \(\partial L/\partial b_{1,2}\)(둘째 은닉 뉴런의 편향)를 구하시오.
    답

    \(\partial L/\partial z_2 = -0.8108 \times 0.3 \times 0.4750 \times 0.5250 = -0.0607\). 편향의 국소 미분은 1이므로 −0.0607. (∂L/∂W₁,₂ = −0.0607 × 0.5 = −0.0303과 맞는다.)

심화

  1. 은닉층의 활성화 함수를 항등 함수 f(z) = z로 바꾸면, 본문 신경망이 \(\hat y = \alpha x + \beta\) 꼴이 됨을 보이고 α와 β를 가중치로 쓰시오.
    답

    \(\hat y = W_{2,1}(W_{1,1}x + b_{1,1}) + W_{2,2}(W_{1,2}x + b_{1,2}) + b_2\). α = \(W_{2,1}W_{1,1} + W_{2,2}W_{1,2}\) = 0.28 − 0.18 = 0.10, β = \(W_{2,1}b_{1,1} + W_{2,2}b_{1,2} + b_2\) = 0.07 + 0.06 + 0.05 = 0.18. 은닉층이 있어도 직선 하나와 같다.
