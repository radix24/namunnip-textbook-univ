다층 신경망의 순전파와 역전파

본문

가중치가 백만 개인 신경망을 경사 하강법으로 학습시키려면, 걸음마다 백만 개의 편미분이 필요하다. 가중치 하나씩 조금 바꿔 손실을 다시 계산하는 수치 미분으로는 순전파를 이백만 번 해야 한다. 이 많은 기울기를 한 번에 얻는 방법이 있을까?

먼저 알아야 할 것행렬 곱과 기울기(1.1절), 경사 하강법(1.2절), 로지스틱 회귀(3.1절)를 쓴다.

4.1.1퍼셉트론에서 다층 신경망으로

입력의 가중합에 편향을 더한 \(z = \mathbf w\cdot\mathbf x + b\)를 활성화 함수 \(f\)에 넣어 \(h = f(z)\)를 내는 계산 단위를 뉴런이라 한다. 예를 들어 활성화 함수로 시그모이드를 쓰면 3.1절의 로지스틱 회귀와 같다. 한편 입력과 출력 사이의 뉴런 층을 은닉층이라 하며, 앞 층의 출력이 다음 층의 입력이 된다. 활성화 함수로는 시그모이드 \(\sigma(z) = 1/(1+e^{-z})\), tanh, ReLU \(\max(0, z)\) 등을 쓴다.

왜 활성화 함수는 비선형이어야 할까? 선형이면 층을 아무리 쌓아도 행렬 곱의 곱은 다시 행렬 하나(\(W_2W_1\mathbf x = W\mathbf x\))라 선형 모형 하나와 같다. 따라서 비선형 함수를 끼워야 층을 쌓을수록 복잡한 함수를 표현할 수 있다. 실제로 은닉층이 하나라도 뉴런이 충분히 많으면 임의의 연속 함수를 원하는 만큼 가깝게 근사할 수 있다는 것이 알려져 있으며, 이것을 보편 근사 정리라 한다.

4.1.2순전파, 손으로 계산하기

예제 4.1.1

그림 1처럼 입력 하나, 은닉 뉴런 둘(시그모이드), 출력 하나(선형)인 신경망에서 \(x = 0.5\), 정답 \(y = 1.0\), 가중치 \(W_1 = (0.4, -0.6)\), \(b_1 = (0.1, 0.2)\), \(W_2 = (0.7, 0.3)\), \(b_2 = 0.05\), 손실 \(L = (\hat y - y)^2\)이다. 순전파로 손실을 구하여라.

풀이. 은닉층 입력은 \(z_1 = 0.4\times0.5 + 0.1 = 0.3\), \(z_2 = -0.6\times0.5 + 0.2 = -0.1\)이다. 다음으로 은닉층 출력은 \(h_1 = \sigma(0.3) = 0.5744\), \(h_2 = \sigma(-0.1) = 0.4750\)이다. 따라서 출력은 \(\hat y = 0.7\times0.5744 + 0.3\times0.4750 + 0.05 = 0.5946\)이고, 손실은 \(L = (0.5946 - 1)^2 = 0.1643\)이다.

4.1.3역전파, 연쇄 법칙을 뒤에서부터

이제 모든 가중치에 대한 \(\partial L/\partial w\)를 구한다. 출력 쪽부터 한 단계씩 거꾸로 곱해 가며, 각 단계는 바로 뒤 값에 대한 기울기에 이 단계의 국소 미분을 곱한 것이다. 먼저 \(\partial L/\partial\hat y = 2(\hat y - y) = -0.8108\)이다. 출력층 가중치의 기울기는 \(\partial L/\partial W_{2,j} = (\partial L/\partial\hat y)\,h_j\)이므로 \((-0.4657, -0.3851)\)이고, \(\partial L/\partial b_2 = -0.8108\)이다.

그다음 은닉층 출력의 기울기는 \(\partial L/\partial h_j = (\partial L/\partial\hat y)\,W_{2,j}\)이다. 시그모이드를 통과할 때는 \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\)이므로 \(\partial L/\partial z_j = (\partial L/\partial h_j)\,h_j(1 - h_j)\)이다. 마지막으로 은닉층 가중치의 기울기는 \(\partial L/\partial W_{1,j} = (\partial L/\partial z_j)\,x\)이므로 \((-0.0694, -0.0303)\)이다.

import math
sig = lambda z: 1 / (1 + math.exp(-z))
x, y = 0.5, 1.0
W1, b1, W2, b2 = [0.4, -0.6], [0.1, 0.2], [0.7, 0.3], 0.05

def forward(W1, b1, W2, b2):
    h = [sig(W1[j] * x + b1[j]) for j in range(2)]
    yhat = sum(W2[j] * h[j] for j in range(2)) + b2
    return h, yhat, (yhat - y) ** 2

h, yhat, L = forward(W1, b1, W2, b2)
g = 2 * (yhat - y)                                  # dL/dyhat
dW2 = [g * h[j] for j in range(2)]
dz = [g * W2[j] * h[j] * (1 - h[j]) for j in range(2)]
dW1 = [dz[j] * x for j in range(2)]

eps = 1e-6                                          # 수치 미분 검산
num = (forward([W1[0] + eps, W1[1]], b1, W2, b2)[2]
       - forward([W1[0] - eps, W1[1]], b1, W2, b2)[2]) / (2 * eps)
print(round(dW1[0], 6), round(num, 6))              # -0.06937 -0.06937

보다시피 역전파와 수치 미분이 같은 값을 준다. 학습률 0.5로 모든 가중치를 한 번 갱신하면 손실이 0.1643에서 0.0623으로 줄어든다.

처음 질문의 답이 역전파의 효율에 있다. 가중치가 백만 개일 때 수치 미분은 순전파를 이백만 번 해야 하지만, 역전파는 순전파 한 번과 거꾸로 한 번이면 모든 기울기를 얻는다. 순전파 때 중간값 \(h\), \(z\)를 저장해 두었다가 다시 쓰기 때문이다. 물론 오늘날 PyTorch 같은 라이브러리는 이 과정을 자동으로 하며, 이것을 자동 미분이라 한다.

흔한 오해역전파를 학습 알고리즘으로 부르기 쉽지만, 정확히는 기울기를 계산하는 방법이고 학습은 그 기울기로 경사 하강을 하는 것이다. 그리고 층이 깊을수록 무조건 좋은 것도 아니다. 시그모이드를 여러 층 쌓으면 \(\sigma' \le 0.25\)가 계속 곱해져 앞쪽 층의 기울기가 사라지므로, 은닉층에는 주로 ReLU를 쓴다. 그리고 가중치를 모두 0으로 시작하면 은닉 뉴런들이 똑같이 학습되어 하나인 것과 같아지므로, 작은 무작위 값으로 시작한다.
마무리

뉴런은 \(h = f(\mathbf w\cdot\mathbf x + b)\)를 계산하고, 이것을 층으로 쌓은 것이 다층 신경망이며 활성화 함수는 비선형이어야 한다. 순전파는 입력에서 출력까지 차례로 계산하며 중간값을 저장하고, 역전파는 출력에서 거꾸로 연쇄 법칙을 곱해 모든 \(\partial L/\partial w\)를 한 번에 얻는다. 처음 질문의 백만 개 기울기도 순전파와 역전파 한 번씩이면 되며, 새로 짠 역전파는 수치 미분으로 검산한다.

4.1.4연습문제

기본

  1. 입력 10개, 은닉층 32개, 출력 1개인 신경망의 가중치와 편향은 모두 몇 개인가?
    답

    10 × 32 + 32 + 32 × 1 + 1 = 385개.

응용

  1. 본문 예에서 \(\partial L/\partial b_{1,2}\)(둘째 은닉 뉴런의 편향)를 구하시오.
    답

    \(\partial L/\partial z_2 = -0.8108 \times 0.3 \times 0.4750 \times 0.5250 = -0.0607\). 편향의 국소 미분은 1이므로 −0.0607. (∂L/∂W₁,₂ = −0.0607 × 0.5 = −0.0303과 맞는다.)

심화

  1. 은닉층의 활성화 함수를 항등 함수 f(z) = z로 바꾸면, 본문 신경망이 \(\hat y = \alpha x + \beta\) 꼴이 됨을 보이고 α와 β를 가중치로 쓰시오.
    답

    \(\hat y = W_{2,1}(W_{1,1}x + b_{1,1}) + W_{2,2}(W_{1,2}x + b_{1,2}) + b_2\). α = \(W_{2,1}W_{1,1} + W_{2,2}W_{1,2}\) = 0.28 − 0.18 = 0.10, β = \(W_{2,1}b_{1,1} + W_{2,2}b_{1,2} + b_2\) = 0.07 + 0.06 + 0.05 = 0.18. 은닉층이 있어도 직선 하나와 같다.
