릿지와 라소가 가중치를 줄이는 모습

릿지 · 라소 · 정규화 세기

출발점

원점을 지나는 특성 하나의 모형이라면 릿지와 라소의 해를 손으로 구할 수 있다. λ에 따라 가중치가 어떻게 줄어드는지 비교한다.

자료 (x, y) = (1, 2.1), (2, 3.9), (3, 6.2)에 \(\hat y = wx\)를 맞춘다. (가) 보통 최소 제곱, (나) 릿지 λ = 1, 14, (다) 라소 λ = 10의 가중치를 구하고, 라소에서 w가 0이 되는 λ를 구하여라.

풀이

  1. \(\sum xy = 2.1 + 7.8 + 18.6 = 28.5\), \(\sum x^2 = 14\).
    두 합만 있으면 된다.
  2. (가) \(w = 28.5/14 = 2.036\).
    손실을 w로 미분해 0.
  3. (나) 릿지 \(w = 28.5/(14 + \lambda)\): λ = 1에서 1.900, λ = 14에서 1.018.
    λ가 Σx²와 같아지면 가중치가 절반으로 줄어든다.
  4. (다) 라소 \(w = (28.5 - \lambda/2)/14\): λ = 10에서 1.679. \(\lambda \ge 57\)이면 w = 0.
    절댓값 벌점의 기울기는 크기와 관계없이 λ로 일정해, 어느 λ에서 정확히 0이 된다.

의미

릿지는 λ를 아무리 키워도 w가 0에 가까워질 뿐 0이 되지 않지만, 라소는 유한한 λ에서 정확히 0이 된다. 특성이 많을 때 라소가 기여가 작은 특성부터 차례로 0으로 만들어 "쓰는 특성"을 고르는 이유이다. 이 자료는 y ≈ 2x로 잡음이 작아 정규화가 필요 없지만, 자료가 적고 특성이 많을수록 λ의 이득이 커진다.

검산

λ → 0이면 두 해 모두 보통 최소 제곱 2.036으로 돌아가고, λ가 커질수록 줄어든다. 또 릿지 λ = 14에서 \(28.5/28 = 1.018\)은 정확히 보통 해의 절반(1.018)이다.
