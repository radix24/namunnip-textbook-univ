분자를 그래프로 다루는 신경망

본문
이 절에서 배울 것
  • 보통의 신경망에 분자를 그대로 넣기 어려운 이유(크기가 다름, 원자 순서)를 안다.
  • 메시지 전달(이웃 정보 모으기)과 읽어내기(그래프 전체 요약)의 아이디어를 설명한다.
  • 한 번의 메시지 전달을 인접 행렬로 손 계산하고, 구조 이성질체를 구별하는 것을 확인한다.
  • 그래프 신경망과 원형 지문의 관계, 한계를 안다.
먼저 알아야 할 것
  • 분자 그래프와 인접 행렬 (2.1절), 원형 지문 (2.2절), 다층 신경망 (4.1절).

4.2.1왜 그래프 신경망인가

4.1절의 신경망은 길이가 정해진 입력 벡터를 받습니다. 분자를 그대로 넣으려 하면 두 문제가 생깁니다. 원자 수가 분자마다 다르고, 같은 분자라도 원자에 번호를 붙이는 순서가 여러 가지라 순서를 바꾸면 입력이 달라집니다. 지문(2.2절)은 이 문제를 고정된 규칙으로 해결했습니다. 그래프 신경망(GNN)은 같은 문제를 "학습되는 규칙"으로 해결합니다.

원자 특성 벡터 h_v: 원자 v의 정보를 담은 벡터. 처음에는 원소 종류(원-핫), 전하, 방향족 여부, 붙은 수소 수 등.

메시지 전달: 각 원자가 이웃 원자의 벡터를 모아(합 또는 평균) 자기 벡터를 새로 고치는 단계. 한 번 할 때마다 한 결합 더 먼 정보까지 담긴다.

읽어내기(풀링): 모든 원자의 벡터를 합하거나 평균해 분자 전체의 벡터 하나로 만드는 단계. 그 벡터를 보통의 신경망에 넣어 물성을 예측한다.

4.2.2메시지 전달 식

식 4.2.1 (단순한 메시지 전달 한 단계)

\[ \mathbf h_v^{(t+1)} = f\!\left(W_\mathrm{self}\,\mathbf h_v^{(t)} + W_\mathrm{nb}\sum_{u\in N(v)}\mathbf h_u^{(t)}\right) \]

N(v)는 v와 결합한 원자들, W는 학습되는 가중치 행렬, f는 활성화 함수. 모든 원자가 같은 W를 공유한다.

행렬로 쓰면 모든 원자를 한꺼번에 갱신할 수 있습니다. 원자 벡터를 줄로 쌓은 행렬 H와 인접 행렬 A로, 이웃의 합은 \(AH\)입니다. W를 항등 행렬, f를 항등 함수로 단순화하면 \(H' = (I + A)H\)가 됩니다.

원자 번호 순서를 바꿔도 각 원자가 받는 이웃의 합은 그대로이고, 읽어내기의 합도 순서와 무관합니다. 그래서 GNN의 예측은 원자 순서에 관계없이 같습니다. 분자에 꼭 필요한 성질입니다.

4.2.3손으로 해 보기: 에탄올과 다이메틸 에터

구하려는 것: 분자식이 같은(C₂H₆O) 두 구조 이성질체가 메시지 전달 뒤 다른 벡터를 갖는지.

무거운 원자만 보고, 원자 특성을 원-핫 [C인가, O인가]로 둡니다. 메시지 전달 전에 읽어내기(합)를 하면 두 분자 모두 [2, 1]로 같습니다. 원자 수만 세는 것과 같기 때문입니다.

  • 에탄올 C₁−C₂−O₃: \(H' = (I + A)H\)에서 C₁ = [1,0] + [1,0] = [2,0], C₂ = [1,0] + [1,0] + [0,1] = [2,1], O₃ = [0,1] + [1,0] = [1,1]. 합 [5, 2].
  • 다이메틸 에터 C₁−O₂−C₃: C₁ = [1,0] + [0,1] = [1,1], O₂ = [0,1] + [1,0] + [1,0] = [2,1], C₃ = [1,1]. 합 [4, 3].

한 번의 메시지 전달로 두 이성질체의 벡터가 달라졌습니다. "O 옆에 C가 몇 개인가", "C 옆에 O가 있는가" 같은 이웃 정보가 들어갔기 때문입니다. 실제 GNN은 W를 학습해 이 정보 가운데 예측에 쓸모 있는 조합을 스스로 찾습니다. 끓는점(에탄올 78 °C, 다이메틸 에터 −24 °C)처럼 O−H 수소 결합에 크게 좌우되는 성질을 예측하려면 이런 이웃 정보가 꼭 필요합니다.

4.2.4원형 지문과의 관계, 그리고 한계

원형 지문(2.2절)도 "각 원자에 자기와 이웃의 정보를 합친 새 이름을 붙이기"를 반지름만큼 반복합니다. GNN은 이 이름 붙이기를 고정된 해시 대신 학습되는 신경망으로 바꾼 것으로 볼 수 있습니다. 그래서 자료가 많으면 과제에 맞는 표현을 배워 지문보다 나을 수 있지만, 자료가 적으면 지문 + 랜덤 포레스트 같은 단순한 방법이 비슷하거나 더 낫기도 합니다(3.2절의 과적합).

한계도 있습니다. 메시지 전달을 t번 하면 t개 결합 안의 정보만 봅니다. 기본 GNN은 일부 서로 다른 그래프(예: 고리 크기가 다른 어떤 분자들)를 구별하지 못하고, 결합 그래프만으로는 입체 구조(거울상 이성질체, 3차원 모양)를 모릅니다. 그래서 결합 특성, 입체 표시, 3차원 좌표를 더 넣은 변형들이 쓰입니다.

흔한 오해"GNN은 분자의 3차원 구조를 본다"가 기본형에서는 아닙니다. 결합 연결(2차원 그래프)만 봅니다. 또 "메시지 전달을 많이 할수록 좋다"도 아닙니다. 너무 많이 하면 모든 원자의 벡터가 비슷해져(과평활) 구별력이 떨어집니다. 그리고 원자 순서에 무관하다는 성질은 합·평균 같은 순서 무관 연산을 써서 얻는 것입니다. 원자 벡터를 순서대로 이어 붙이면 이 성질이 깨집니다.
요약
  1. 분자는 크기와 원자 순서가 제각각이라 그래프로 다룬다.
  2. 메시지 전달: \(\mathbf h_v \leftarrow f(W_s\mathbf h_v + W_n\sum_{u\in N(v)}\mathbf h_u)\). 행렬로는 AH. 읽어내기는 합·평균.
  3. 한 번의 전달로 에탄올 [5,2]와 다이메틸 에터 [4,3]이 구별된다.
  4. 원형 지문의 학습판. 자료가 적으면 과적합, 기본형은 3차원·입체 정보가 없다.

4.2.5연습문제

기본

  1. 프로페인 C₁−C₂−C₃의 원자 특성을 모두 [1]로 둘 때, \(H' = (I + A)H\)를 한 번 하면 각 원자의 값과 합은?
    답

    C₁ = 1 + 1 = 2, C₂ = 1 + 2 = 3, C₃ = 2. 합 7. 가운데 원자가 이웃이 많아 값이 크다.

응용

  1. 1-프로판올 CCCO와 2-프로판올 CC(C)O를 원-핫 [C, O]로 두고 메시지 전달 한 번 뒤 읽어내기(합) 벡터를 구해 비교하시오.
    답

    1-프로판올: C₁ [2,0], C₂ [3,0], C₃ [2,1], O [1,1] → 합 [8, 2]. 2-프로판올(C₁, C₂ 가운데, C₃, O가 C₂에 붙음): C₁ [2,0], C₂ [3,1], C₃ [2,0], O [1,1] → 합 [8, 2]. 같다! 한 번의 단순 합 전달로는 이 두 이성질체를 구별하지 못한다. 전달을 한 번 더 하거나 원자 특성에 붙은 수소 수(CH₂와 CH 구별)를 넣으면 구별된다.

심화

  1. 2번에서 메시지 전달을 두 번 하면 두 분자를 구별하는지 확인하시오.
    답

    두 번째 전달 \(H'' = (I + A)H'\). 1-프로판올: C₁ = [2,0] + [3,0] = [5,0], C₂ = [3,0] + [2,0] + [2,1] = [7,1], C₃ = [2,1] + [3,0] + [1,1] = [6,2], O = [1,1] + [2,1] = [3,2] → 합 [21, 5]. 2-프로판올: C₁ = [2,0] + [3,1] = [5,1], C₃ = [5,1], C₂ = [3,1] + [2,0] + [2,0] + [1,1] = [8,2], O = [1,1] + [3,1] = [4,2] → 합 [22, 6]. 달라져 구별된다. 두 결합 떨어진 정보가 필요했던 것이다.
