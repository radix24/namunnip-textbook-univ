감응 인자를 구한 뒤 미지 농도 계산하기

내부 표준법 · 감응 인자 · 묽힘 보정

출발점

내부 표준법은 두 단계입니다. 농도를 아는 X와 S의 혼합물로 감응 인자를 구하고, 미지 시료에 S를 넣어 잰 넓이 비로 X를 구합니다. 마지막에 묽힘을 거꾸로 보정합니다.

X 0.0837 M과 S 0.0666 M을 섞은 표준의 봉우리 넓이가 A_X = 423, A_S = 347이었다. 미지 시료 10.0 mL에 0.146 M S 10.0 mL를 넣어 25.0 mL로 묽힌 용액에서 A_X = 553, A_S = 582였다. 원래 미지 시료의 [X]를 구하여라.

풀이

  1. 감응 인자: \(F = (423/0.0837)/(347/0.0666) = 5054/5210 = 0.970\).
    같은 농도에서 X가 S보다 3% 작은 넓이를 냅니다.
  2. 묽힌 용액의 [S] = \(0.146\times10.0/25.0 = 0.0584\) M.
    S도 함께 묽혀졌습니다.
  3. 묽힌 용액의 [X] = \(\dfrac{A_X[\mathrm{S}]}{F A_S} = \dfrac{553\times0.0584}{0.970\times582} = 0.0572\) M.
    식 5.3.1을 [X]에 대해 정리.
  4. 원래 미지 시료: \(0.0572\times25.0/10.0 = 0.143\) M.
    10.0 mL가 25.0 mL로 묽혀졌습니다.

의미

계산에는 넓이의 비만 들어갑니다. 미지 시료를 주입할 때 1 μL 대신 0.9 μL가 들어갔더라도 553과 582가 함께 10% 작아져 결과는 같습니다. 그래서 내부 표준법은 수동 주입 GC처럼 주입 부피가 흔들리는 장치에서 정밀도를 크게 올립니다.

검산

미지 용액의 넓이 비 553/582 = 0.950과 표준의 넓이 비 423/347 = 1.219를 비교하면, 미지 용액의 [X]/[S] = 0.950/0.970 = 0.980, 즉 [X] = 0.980 × 0.0584 = 0.0572 M으로 같은 값입니다.
