분리 실험 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산t_M = 1.50 min, 두 물질의 t_R = 8.10, 8.70 min이다. k₁, k₂, α를 구하시오. [05-01]

    힌트 1

    k = (t_R − t_M)/t_M.

    힌트 2

    α = k₂/k₁.

    풀이

    k₁ = 6.60/1.50 = 4.40, k₂ = 7.20/1.50 = 4.80, α = 1.091.

  2. 계산1번의 두 봉우리 바탕 너비가 0.36, 0.40 min이다. R_s를 구하고 분리가 충분한지 판단하시오. [05-01]

    힌트 1

    R_s = 2Δt_R/(w₁ + w₂).

    힌트 2

    기준 1.5.

    풀이

    R_s = 2 × 0.60/0.76 = 1.58. 1.5 이상이라 바탕선까지 분리되었다.

  3. 계산머무름 시간 12.0 min, 바탕 너비 0.60 min인 봉우리의 N과, 관 길이 25 cm일 때 단 높이 H = L/N은? [05-01]

    힌트 1

    N = 16(t_R/w)².

    힌트 2

    H는 단위를 mm나 μm로.

    풀이

    N = 16 × 20² = 6400. H = 250 mm/6400 = 0.039 mm = 39 μm.

  4. 개념α = 1.02인 두 물질을 R_s = 1.5로 분리하려면 k₂ = 5에서 N이 얼마나 필요한가? 현실적인가? [05-01]

    힌트 1

    퍼넬 식을 N에 대해 풀어라.

    힌트 2

    (α − 1)/α = 0.0196, k/(1 + k) = 0.833.

    풀이

    √N = 4 × 1.5/(0.0196 × 0.833) = 367, N ≈ 1.35×10⁵. 보통 HPLC 관(1만~2만)으로는 어렵고, 정지상·이동상을 바꿔 α를 키우는 편이 현실적이다.

  5. 계산H⁺형 양이온 교환 수지에 KCl 용액 25.00 mL를 흘리고 나온 용액을 0.1000 M NaOH로 적정해 18.40 mL가 들었다. KCl 농도는? [05-02]

    힌트 1

    K⁺ 하나가 붙을 때 H⁺ 하나가 나온다.

    힌트 2

    나온 H⁺ 몰수 = NaOH 몰수.

    풀이

    H⁺ = 1.840 mmol = K⁺ 몰수. KCl 농도 = 1.840/25.00 = 0.07360 M.

  6. 판단두 봉우리가 겹친다(R_s = 0.8). 학생 A는 관을 두 배 길이로, 학생 B는 이동상의 유기 용매 비율을 낮춰 k를 1.2에서 4로 올리자고 했다(α는 그대로). 어느 쪽이 더 효과적인가? [05-01]

    힌트 1

    R_s ∝ √N, R_s ∝ k/(1 + k).

    힌트 2

    각 방법으로 R_s가 몇 배 되나요?

    풀이

    A: √2 = 1.41배 → R_s ≈ 1.13, 시간 두 배. B: k/(1 + k)가 0.545에서 0.800으로 1.47배 → R_s ≈ 1.17. 비슷하지만 B는 관을 바꾸지 않고, 분석 시간 증가도 대개 더 적다. 둘 다 1.5에는 못 미치므로 α를 바꾸는 방법(다른 정지상, 다른 유기 용매)도 함께 검토한다.

  7. 계산광천수 50.00 mL를 H⁺형 수지에 통과시킨 용액을 0.02000 M NaOH로 적정했더니 18.25 mL가 들었다. 광천수의 총 양이온 농도(meq/L)는? [05-02]

    힌트 1

    나온 H⁺ mmol = meq.

    힌트 2

    부피로 나눈다.

    풀이

    H⁺ 0.3650 mmol = 0.3650 meq, 0.3650/0.05000 L = 7.30 meq/L.

  8. 계산내부 표준 S의 감응 인자 F = 1.20(X 기준)이다. S 0.0500 M을 넣은 시료에서 A_X = 360, A_S = 250이면 [X]는? [05-03]

    힌트 1

    \(A_X/[\mathrm{X}] = F A_S/[\mathrm{S}]\).

    힌트 2

    [X]에 대해 정리.

    풀이

    [X] = 360 × 0.0500/(1.20 × 250) = 0.0600 M.
