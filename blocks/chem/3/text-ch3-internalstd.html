크로마토그래피의 내부 표준법

본문

GC 주사기로 시료 1 μL를 넣을 때마다 실제 들어간 양은 몇 %씩 다르다. 같은 시료를 세 번 주입했는데 봉우리 넓이가 100, 95, 103으로 흔들린다면 어느 값을 믿어야 할까? 주입량의 흔들림을 결과에서 지울 방법이 있을까?

먼저 알아야 할 것크로마토그램의 네 가지 수(5.1절), 검량선법(4.1절)을 쓴다.

5.3.1왜 내부 표준인가

GC 주사기로 1 μL를 넣을 때 실제 들어간 부피는 몇 % 흔들린다. 추출이나 농축 같은 시료 준비 중에도 분석물이 조금씩 사라진다. 그래서 봉우리 넓이를 바로 검량선에 넣으면 이 흔들림이 그대로 결과에 들어간다.

이때 시료에 없는 다른 물질, 곧 내부 표준 S를 정해진 양만큼 모든 시료와 표준에 넣고, 분석물 넓이 자체 대신 분석물과 S의 넓이 비로 정량하는 방법을 내부 표준법이라 한다. 주입 부피가 5% 적으면 그림 1처럼 두 봉우리가 함께 5% 작아지므로 넓이 비는 그대로이다. 처음 질문의 흔들림은 이렇게 지운다.

5.3.2감응 인자와 계산

그런데 검출기는 물질마다 같은 농도에도 다른 넓이를 낸다. 그 차이를 감응 인자 \(F\)로 나타낸다.

식 5.3.1 (내부 표준법)

\[ \frac{A_X}{[\mathrm{X}]} = F\,\frac{A_S}{[\mathrm{S}]} \]

먼저 X와 S의 농도를 아는 혼합물로 \(F\)를 구한다. 다음에 미지 시료에 S를 알려진 농도로 넣어 잰 \(A_X\), \(A_S\)와 \(F\)로 [X]를 구한다. 표준을 여러 개 만들어 \(A_X/A_S\) 대 \([\mathrm{X}]/[\mathrm{S}]\)의 검량선을 그리면 그 기울기가 \(F\)이다.

예제 5.3.1

X 0.0837 M과 S 0.0666 M이 든 혼합물에서 넓이가 \(A_X = 423\), \(A_S = 347\)이었다. 미지 시료 10.0 mL에 0.146 M S 10.0 mL를 섞어 25.0 mL로 묽혀 쟀더니 \(A_X = 553\), \(A_S = 582\)였다. 미지 시료의 [X]는?

풀이. \(F = (423/0.0837)/(347/0.0666) = 5054/5210 = 0.970\)이다. 묽힌 용액의 [S]는 \(0.146\times10.0/25.0 = 0.0584\) M이다. 따라서 \([\mathrm X] = A_X/(F\cdot A_S/[\mathrm S]) = 553/(0.970\times582/0.0584) = 0.0572\) M이고, 미지 시료는 2.5배 묽혔으므로 0.143 M이다.

5.3.3좋은 내부 표준

내부 표준은 아무것이나 쓸 수 없다. 먼저 시료에 원래 없어야 한다. 또 분석물과 화학적으로 비슷해야 시료 준비에서 같은 비율로 손실되므로, 동족체나 동위원소 표지 화합물이 이상적이다. 봉우리는 분석물과 완전히 분리되면서도 너무 멀지 않은 곳에 나와야 하고, 분석물과 비슷한 넓이가 되도록 넣는다.

예를 들어 질량 분석 검출기에서는 중수소나 ¹³C로 표지한 분석물 자체를 내부 표준으로 쓰는 일이 많다. 화학적으로 거의 같아 손실과 이온화 효율까지 같이 따라가면서도 질량으로 구별되기 때문이다.

흔한 오해내부 표준을 넣으면 검량이 필요 없다고 생각하기 쉽지만, 감응 인자 \(F\)를 표준 혼합물로 먼저 구해야 한다. 또 내부 표준은 추출 전, 곧 시료 준비의 맨 앞에 넣어야 손실까지 보정한다. 주입 직전에 넣으면 주입 부피만 보정한다.
마무리

내부 표준법은 시료에 없는 물질 S를 모든 용액에 같은 양만큼 넣고, 분석물과 S의 넓이 비로 정량해 주입 부피와 시료 손실의 흔들림을 상쇄한다. 처음 질문의 100, 95, 103으로 흔들린 넓이도 S와의 비로 보면 같은 값이 된다. 계산은 \(A_X/[\mathrm{X}] = F\,A_S/[\mathrm{S}]\)를 쓰며, 감응 인자 \(F\)는 표준 혼합물로 먼저 구한다. 좋은 내부 표준은 분석물과 비슷하면서 분리되는 물질이고, 시료 준비의 처음에 넣는다.

5.3.4연습문제

기본

  1. X 0.0500 M, S 0.0400 M 혼합물에서 넓이가 A_X = 500, A_S = 380이었다. 감응 인자 F는?
    답

    F = (500/0.0500)/(380/0.0400) = 10000/9500 = 1.053.

응용

  1. 기본 문제의 F로, S를 0.0300 M 넣은 미지 시료에서 A_X = 420, A_S = 300이었다. [X]는?
    답

    [X] = A_X[S]/(F A_S) = 420 × 0.0300/(1.053 × 300) = 0.0399 M.

심화

  1. 주입 부피가 2% 적게 들어갔다면 외부 검량선법과 내부 표준법의 결과는 각각 어떻게 되는가?
    답

    외부 검량선법은 넓이가 2% 작아져 결과도 2% 작게 나온다. 내부 표준법은 두 넓이가 함께 2% 작아져 비가 그대로이므로 영향이 없다.
