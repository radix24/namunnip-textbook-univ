용액화학과 활동도 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념Ag⁺나 Cl⁻와 반응하지 않는 KNO₃를 넣었는데 AgCl의 용해도가 커진다. 이온 구름의 그림으로 이유를 설명하시오. [02-01]

    힌트 1

    2.1절 첫 소절을 보세요. Ag⁺ 둘레에는 어떤 전하의 이온이 더 많이 모이나요?

    힌트 2

    둘러싼 이온이 전하를 가리면 Ag⁺와 Cl⁻가 서로 끄는 힘은 어떻게 되나요?

    풀이

    Ag⁺ 둘레에는 음이온(NO₃⁻ 등)이, Cl⁻ 둘레에는 양이온(K⁺ 등)이 조금 더 많이 모여 이온 구름을 만듭니다. 이 구름이 이온의 전하를 일부 가려 Ag⁺와 Cl⁻가 서로 끄는 힘이 약해지고, 다시 결합해 고체로 돌아가려는 경향이 줄어듭니다. 그래서 더 많이 녹습니다. 이 효과를 활동도 계수(1보다 작음)로 나타내면, \(K_{sp} = [\mathrm{Ag^+}][\mathrm{Cl^-}]\gamma_{\mathrm{Ag}}\gamma_{\mathrm{Cl}}\)이 일정하므로 γ가 작아질수록 농도의 곱은 커집니다.

  2. 계산0.020 M MgCl₂와 0.010 M Na₂SO₄를 함께 녹인 용액의 이온 세기를 구하시오. [02-01]

    힌트 1

    이온마다 농도와 전하를 표로 정리하세요. Cl⁻는 0.040 M, Na⁺는 0.020 M입니다.

    힌트 2

    \(\mu = \frac12\sum c_iz_i^2\). 전하 2인 이온은 4를 곱합니다.

    풀이

    Mg²⁺ 0.020 M(\(z^2 = 4\)), Cl⁻ 0.040 M, Na⁺ 0.020 M, SO₄²⁻ 0.010 M(\(z^2 = 4\)).

    \(\mu = \frac12(0.020\times4 + 0.040 + 0.020 + 0.010\times4) = \frac12(0.18) = 0.090\) M.

  3. 계산이온 세기 0.050 M에서 Mg²⁺(α = 800 pm)의 활동도 계수를 구하고, 이 용액에 Mg²⁺가 0.010 M 있을 때 활동도를 구하시오. [02-01]

    힌트 1

    확장 Debye-Hückel 식(정리 2.1.4)에 \(z = 2\), \(\sqrt\mu = 0.224\)를 넣으세요.

    힌트 2

    분자 \(-0.51\times4\times0.224 = -0.456\), 분모 \(1 + 800\times0.224/305 = 1.587\).

    풀이

    \(\log\gamma = -0.456/1.587 = -0.287\), \(\gamma = 0.516\).

    활동도 \(\mathcal A = 0.010\times0.516 = 0.0052\) M. 농도의 절반쯤만 "활동"합니다.

  4. 계산CaCO₃를 물에 포화시켰다. CO₃²⁻는 물과 반응해 HCO₃⁻와 H₂CO₃가 된다. 전하 균형과 질량 균형을 쓰고, 미지수와 식의 개수를 세시오(CO₂ 기체의 출입은 없다고 본다). [02-02]

    힌트 1

    미지수는 Ca²⁺, CO₃²⁻, HCO₃⁻, H₂CO₃, H⁺, OH⁻입니다.

    힌트 2

    평형식은 \(K_{sp}\), H₂CO₃의 \(K_{a1}, K_{a2}\), \(K_w\) 네 개입니다.

    풀이

    전하 균형: \(2[\mathrm{Ca^{2+}}] + [\mathrm{H^+}] = 2[\mathrm{CO_3^{2-}}] + [\mathrm{HCO_3^-}] + [\mathrm{OH^-}]\).

    질량 균형: \([\mathrm{Ca^{2+}}] = [\mathrm{CO_3^{2-}}] + [\mathrm{HCO_3^-}] + [\mathrm{H_2CO_3}]\) (녹은 Ca와 탄산 형태는 1:1).

    미지수 6개, 식은 평형식 4개 + 균형식 2개 = 6개로 풀 수 있습니다.

  5. 판단한 학생이 "CaF₂가 산성에서 더 잘 녹으니, AgCl도 산성에서 더 잘 녹는다"고 썼다. 이 주장을 평가하시오. [02-03]

    힌트 1

    2.3절: CaF₂가 산성에서 더 녹는 까닭은 F⁻가 무엇과 반응하기 때문인가요?

    힌트 2

    HCl은 강산입니다. Cl⁻가 H⁺와 결합해 HCl 분자로 남을까요?

    풀이

    CaF₂는 F⁻가 약산 HF의 짝염기라 H⁺와 결합해 HF가 되고, 용해 평형에서 F⁻가 빠져나가 더 녹습니다. Cl⁻는 강산 HCl의 짝염기라 물속에서 H⁺와 결합하지 않으므로 AgCl의 용해 평형은 pH의 영향을 받지 않습니다. 주장은 틀렸습니다. (산을 넣으면 이온 세기가 커지는 효과는 있지만, 그것은 pH가 아니라 이온 세기의 효과이며 어떤 염을 넣어도 생깁니다.)

  6. 계산pH 2.50으로 고정한 용액에서 SrF₂(\(K_{sp} = 2.9\times10^{-9}\))의 용해도를 구하고, 중성에서의 용해도와 비교하시오. HF의 \(K_a = 6.8\times10^{-4}\), 활동도 계수는 1로 둔다. [02-03]

    힌트 1

    예제 2.3.2와 같습니다. 먼저 F⁻로 남는 비율 \(K_a/(K_a + [\mathrm{H^+}])\)를 구하세요.

    힌트 2

    \([\mathrm{H^+}] = 10^{-2.50} = 3.16\times10^{-3}\) M, 비율 0.177. \(K_{sp} = s(2s\times0.177)^2\).

    풀이

    질량 균형 \(2[\mathrm{Sr^{2+}}] = [\mathrm{F^-}] + [\mathrm{HF}]\)과 \(K_a\) 식에서 \([\mathrm{F^-}] = 2s\times0.177\).

    \(K_{sp} = 4s^3(0.177)^2 = 0.1253s^3\)이므로 \(s = (2.9\times10^{-9}/0.1253)^{1/3} = 2.8\times10^{-3}\) M.

    중성에서는 \(s = (2.9\times10^{-9}/4)^{1/3} = 9.0\times10^{-4}\) M이므로 약 3.2배 더 녹습니다.
