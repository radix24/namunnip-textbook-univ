체계적 평형 처리로 용해도 구하기

본문
이 절에서 배울 것
  • 여러 평형이 얽힌 문제를 여섯 단계(반응, 전하 균형, 질량 균형, 평형식, 개수 세기, 풀기)로 푼다.
  • 음이온이 산-염기 반응을 하는 염(CaF₂ 등)의 용해도가 pH에 따라 바뀌는 것을 계산한다.
  • 근사를 쓸 때와 그 근사를 확인하는 방법을 안다.
먼저 알아야 할 것
  • 활동도와 평형 상수 (2.1절), 전하·질량 균형 (2.2절).

2.3.1산성 비에 석회암이 녹는 이유

CaF₂(형석)의 용해도곱은 \(3.2\times10^{-11}\)입니다. 일반화학식으로 계산하면 \(s = (K_{sp}/4)^{1/3} = 2.0\times10^{-4}\) M입니다. 그런데 산성 용액에 넣으면 훨씬 많이 녹습니다. F⁻ 이온이 H⁺와 결합해 HF가 되면, 용해 평형 \(\mathrm{CaF_2(s) \rightleftharpoons Ca^{2+} + 2F^-}\)에서 F⁻가 빠져나가 르샤틀리에 원리에 따라 더 녹기 때문입니다. 석회암(CaCO₃)이 산성 비에 녹는 것도 같은 이유입니다. 이렇게 평형 두 개 이상이 얽히면 "녹은 양 = s" 같은 간단한 관계가 깨지므로 체계적으로 식을 세워야 합니다.

2.3.2여섯 단계

방법 2.3.1 (체계적 평형 처리)
  1. 반응: 일어나는 모든 평형 반응을 적는다(물의 이온화 포함).
  2. 전하 균형을 쓴다.
  3. 질량 균형을 쓴다(넣은 물질마다, 또는 화학식의 비로).
  4. 각 반응의 평형식을 쓴다(정확히 하려면 활동도 계수를 넣는다).
  5. 미지수와 식의 개수를 센다. 같으면 풀 수 있다.
  6. 푼다. 손으로는 근사를 쓰고 마지막에 확인하거나, 컴퓨터(스프레드시트)로 수치 계산한다.

왜 이렇게 형식을 갖추나 하면, 복잡한 문제에서 사람이 가장 자주 하는 실수가 "식 하나를 빼먹는 것"이기 때문입니다. 단계를 따르면 빠짐없이 세울 수 있고, 5단계에서 개수가 맞지 않으면 무언가 빠졌다는 신호가 됩니다.

2.3.3pH가 고정된 용액에서 CaF₂의 용해도

예제 2.3.2

pH 3.00으로 맞춘 완충 용액에서 CaF₂의 용해도를 구하여라. \(K_{sp} = 3.2\times10^{-11}\), HF의 \(K_a = 6.8\times10^{-4}\). 활동도 계수는 1로 둔다.

풀이. 여섯 단계를 차례로 밟습니다.

  1. 반응: \(\mathrm{CaF_2(s) \rightleftharpoons Ca^{2+} + 2F^-}\), \(\mathrm{HF \rightleftharpoons H^+ + F^-}\), \(\mathrm{H_2O \rightleftharpoons H^+ + OH^-}\).
  2. 전하 균형: 완충 용액의 이온들이 끼어들어 정확히 쓸 수 없습니다. 대신 pH가 주어졌으므로 \([\mathrm{H^+}] = 1.0\times10^{-3}\) M이 하나의 식 역할을 합니다.
  3. 질량 균형: \(2[\mathrm{Ca^{2+}}] = [\mathrm{F^-}] + [\mathrm{HF}]\).
  4. 평형식: \(K_{sp} = [\mathrm{Ca^{2+}}][\mathrm{F^-}]^2\), \(K_a = [\mathrm{H^+}][\mathrm{F^-}]/[\mathrm{HF}]\).
  5. 미지수 \([\mathrm{Ca^{2+}}], [\mathrm{F^-}], [\mathrm{HF}]\) 3개, 식(질량 균형, \(K_{sp}\), \(K_a\)) 3개.
  6. 풀기: \(K_a\) 식에서 \([\mathrm{HF}] = [\mathrm{H^+}][\mathrm{F^-}]/K_a\)를 질량 균형에 넣으면

\[ 2[\mathrm{Ca^{2+}}] = [\mathrm{F^-}]\left(1 + \frac{[\mathrm{H^+}]}{K_a}\right) \quad\Rightarrow\quad [\mathrm{F^-}] = 2[\mathrm{Ca^{2+}}]\cdot\frac{K_a}{K_a + [\mathrm{H^+}]} \]

분수 \(K_a/(K_a + [\mathrm{H^+}])\)는 플루오린 중 F⁻ 형태로 있는 비율로, pH 3.00에서 \(6.8\times10^{-4}/(6.8\times10^{-4} + 1.0\times10^{-3}) = 0.405\)입니다. 녹은 양을 \(s = [\mathrm{Ca^{2+}}]\)로 두면 \([\mathrm{F^-}] = 2s(0.405)\)이고

\[ K_{sp} = s\,(2s\times0.405)^2 = 4s^3(0.164) \quad\Rightarrow\quad s = \left(\frac{3.2\times10^{-11}}{4\times0.164}\right)^{1/3} = 3.7\times10^{-4}\ \mathrm M \]

중성에서의 \(2.0\times10^{-4}\) M보다 약 1.8배 더 녹습니다. 같은 계산을 pH 2.00에서 하면 F⁻ 비율이 0.064로 떨어져 \(s = 1.3\times10^{-3}\) M, 중성의 6배가 됩니다.

이 결과는 일반 규칙으로 이어집니다. 음이온이 약산의 짝염기인 염(F⁻, CO₃²⁻, PO₄³⁻, S²⁻, OH⁻)은 산성에서 더 잘 녹습니다. 반대로 Cl⁻, Br⁻처럼 강산의 짝염기인 음이온은 H⁺와 결합하지 않으므로 AgCl의 용해도는 pH와 무관합니다.

2.3.4pH가 정해지지 않은 경우: Mg(OH)₂

예제 2.3.3

Mg(OH)₂(\(K_{sp} = 7.1\times10^{-12}\))를 순수한 물에 포화시켰을 때의 용해도와 pH를 구하여라.

풀이. 반응은 \(\mathrm{Mg(OH)_2(s) \rightleftharpoons Mg^{2+} + 2OH^-}\)와 물의 이온화입니다. 전하 균형 \(2[\mathrm{Mg^{2+}}] + [\mathrm{H^+}] = [\mathrm{OH^-}]\), 평형식 \(K_{sp} = [\mathrm{Mg^{2+}}][\mathrm{OH^-}]^2\), \(K_w = [\mathrm{H^+}][\mathrm{OH^-}]\)로 미지수 3개, 식 3개입니다.

용액이 염기성일 것이므로 근사: \([\mathrm{H^+}] \ll 2[\mathrm{Mg^{2+}}]\)라 보고 \([\mathrm{OH^-}] = 2[\mathrm{Mg^{2+}}] = 2s\)로 둡니다. 그러면 \(K_{sp} = 4s^3\), \(s = 1.2\times10^{-4}\) M, \([\mathrm{OH^-}] = 2.4\times10^{-4}\) M, pH = 10.38입니다.

확인: \([\mathrm{H^+}] = 10^{-10.38} = 4\times10^{-11}\) M은 \(2[\mathrm{Mg^{2+}}] = 2.4\times10^{-4}\) M보다 훨씬 작으므로 근사가 맞습니다. 근사를 쓸 때는 이렇게 버린 항이 남긴 항보다 충분히(보통 5% 미만으로) 작은지 마지막에 꼭 확인합니다.

흔한 오해"용해도 = \((K_{sp}/4)^{1/3}\)"은 녹은 이온이 다른 반응을 하지 않을 때만 맞습니다. CaF₂, CaCO₃, 금속 황화물처럼 음이온이 물이나 산과 반응하는 염은 이 식이 실제보다 작은 값을 줍니다. 또 이온 세기가 크면 2.1절의 활동도 효과도 더해집니다. 정확한 값이 필요하면 활동도 계수를 넣고 이온 세기를 다시 계산하는 일을 몇 번 되풀이합니다(반복 계산).

식이 많아지면 손으로 풀기보다 스프레드시트의 "목표값 찾기"나 Python으로 \([\mathrm{H^+}]\)를 바꿔 가며 전하 균형이 맞는 값을 찾는 편이 빠릅니다. QURI의 적정 곡선 카드들([화학1-03-02] 등)도 이 방법으로 전하 균형식을 수치로 풉니다.

요약
  1. 체계적 평형 처리: 반응 → 전하 균형 → 질량 균형 → 평형식 → 개수 세기 → 풀기.
  2. pH가 주어지면 [H⁺]가 식 하나를 대신하고, 전하 균형은 쓰지 않아도 된다.
  3. 약산의 짝염기를 음이온으로 가진 염은 산성에서 더 잘 녹는다. 그 정도는 음이온으로 남는 비율 \(K_a/(K_a + [\mathrm{H^+}])\)로 계산한다.
  4. 근사를 쓰면 버린 항이 충분히 작은지 끝에 확인한다.

2.3.5연습문제

기본

  1. CaF₂를 0.010 M NaF 용액(중성)에 넣었을 때의 용해도를 구하시오(공통 이온 효과, HF 생성은 무시).
    답

    \([\mathrm{F^-}] \approx 0.010\) M이므로 \(s = 3.2\times10^{-11}/(0.010)^2 = 3.2\times10^{-7}\) M. 순수한 물의 약 600분의 1.

응용

  1. 예제 2.3.2와 같은 방법으로 pH 4.00에서 CaF₂의 용해도를 구하시오.
    힌트

    F⁻ 비율 \(6.8\times10^{-4}/(6.8\times10^{-4} + 1.0\times10^{-4}) = 0.872\).

    답

    \(s = (3.2\times10^{-11}/(4\times0.872^2))^{1/3} = 2.2\times10^{-4}\) M. pH 4에서는 F⁻가 대부분 남아 중성과 거의 같다.

  2. Fe(OH)₃(\(K_{sp} = 1.6\times10^{-39}\))를 pH 3.00으로 맞춘 용액에 넣었을 때 녹아 있는 Fe³⁺ 농도를 구하시오.
    답

    \([\mathrm{OH^-}] = 10^{-11}\)이므로 \([\mathrm{Fe^{3+}}] = 1.6\times10^{-39}/10^{-33} = 1.6\times10^{-6}\) M.

심화

  1. 예제 2.3.2에서 활동도 계수를 넣으면 용해도는 커지는가 작아지는가? 완충 용액의 이온 세기가 0.050 M이고 γ(Ca²⁺) = 0.485, γ(F⁻) = 0.81이라 할 때 다시 계산하시오. (Ka 식의 HF는 중성이라 γ = 1, H⁺는 pH로 활동도가 주어진 것으로 본다.)
    힌트

    \(K_{sp} = [\mathrm{Ca^{2+}}]\gamma_{\mathrm{Ca}}([\mathrm{F^-}]\gamma_\mathrm{F})^2\). \(K_a = \mathcal A_{\mathrm{H^+}}[\mathrm{F^-}]\gamma_\mathrm{F}/[\mathrm{HF}]\)이므로 F⁻ 비율은 \(K_a/(K_a + \mathcal A_{\mathrm{H^+}}\gamma_\mathrm{F})\)로 바뀝니다.

    답

    F⁻ 비율 \(6.8\times10^{-4}/(6.8\times10^{-4} + 1.0\times10^{-3}\times0.81) = 0.456\). \(s^3 = K_{sp}/(4\times0.456^2\times0.485\times0.81^2) = 3.2\times10^{-11}/0.265\), \(s = 4.9\times10^{-4}\) M. 활동도 효과로 더 녹는다(활동도 계수 1일 때 \(3.7\times10^{-4}\) M).
