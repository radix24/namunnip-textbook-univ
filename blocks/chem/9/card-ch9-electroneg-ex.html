염소의 전기음성도를 두 척도로 구하기

폴링 척도 · 멀리컨 척도 · 비교

출발점

폴링 척도는 결합 에너지 자료에서, 멀리컨 척도는 원자의 이온화 에너지와 전자 친화도에서 출발한다. 같은 원소를 두 방법으로 계산해 비교한다.

D(H−Cl) = 431, D(H−H) = 436, D(Cl−Cl) = 242 kJ/mol, Cl의 IE = 12.97 eV, EA = 3.61 eV이다. 염소의 전기음성도를 (가) 폴링 척도(χ_H = 2.20)와 (나) 멀리컨 척도(폴링 환산)로 구하고 표값 3.16과 비교하여라.

풀이

  1. (가) 평균 \((436 + 242)/2 = 339\), \(\Delta = 431 - 339 = 92\) kJ/mol.
    HCl 결합이 평균보다 92 kJ/mol 강하다.
  2. \(|\chi_\mathrm{Cl} - \chi_\mathrm H| = 0.102\sqrt{92} = 0.98\), \(\chi_\mathrm{Cl} = 3.18\).
    Cl이 H보다 전기음성이라 더한다.
  3. (나) \(\mathrm{IE} + \mathrm{EA} = 16.58\) eV, \(\chi_M = 8.29\) eV.
  4. 폴링 환산 \(0.187\times16.58 + 0.17 = 3.27\).
    표값 3.16보다 0.11 크다.

의미

두 방법이 서로 다른 자료에서 출발했는데도 3.18과 3.27로 표값 3.16 근처에 모인다. 전기음성도가 "결합에서 전자를 끄는 힘"이라는 한 가지 성질을 서로 다른 각도에서 잰 것이기 때문이다. 소수점 첫째 자리의 차이는 척도의 정의 차이이므로, 같은 표의 값끼리 비교해야 한다.

검산

\(\Delta\)가 양수여야 폴링 식을 쓸 수 있는데(이종 결합이 더 강함) 92로 양수이다. 또 Cl의 결과(3.18)가 F(3.98)보다 작고 H(2.20)보다 커 주기적 경향과 맞다.
