지표표와 환원 공식

본문

물 분자의 IR 스펙트럼에는 신축과 굽힘 진동 띠가 세 개 보인다. 원자 세 개는 3×3 = 9개의 운동 방향을 가지는데, 그 가운데 진동은 몇 개이고 각각 IR과 라만에서 보일까? 분자를 실제로 흔들어 보지 않고, 대칭만으로 이것을 셀 수 있을까?

먼저 알아야 할 것점군 결정(2.1절), 좌표 \((x, y, z)\)의 부호 바꾸기, 진동 분광의 선택 규칙(화학6 5.2절)을 쓴다.

2.2.1조작이 좌표를 바꾸는 방식과 지표

대칭 조작은 점의 좌표 \((x, y, z)\)를 다른 좌표로 옮기는 규칙이다. 물 분자가 속한 \(C_{2v}\)에서 \(C_2\)(\(z\)축 둘레 180° 회전)는 \((x, y, z)\)를 \((-x, -y, z)\)로, \(\sigma_v(xz)\)는 \((x, -y, z)\)로 바꾼다(그림 1). 조작 하나를 숫자 하나로 요약하려면, 좌표 하나하나가 그대로 남으면 +1, 부호만 바뀌면 −1, 다른 좌표로 바뀌면 0을 매겨 더한다. 이 합을 그 조작의 지표라 한다.

그러면 \(C_2\)는 \(-1 - 1 + 1 = -1\), \(\sigma_v(xz)\)는 \(1 - 1 + 1 = 1\), 아무것도 하지 않는 \(E\)는 3이다. 회전각이 \(\theta\)인 회전에서는 축 방향이 +1, 축에 수직인 두 방향이 합쳐 \(2\cos\theta\)를 내므로 지표가 \(1 + 2\cos\theta\)이고, \(C_3\)은 \(1 + 2\cos120° = 0\)이다. 또 회전한 뒤 축에 수직인 거울로 비추는 회전 반사 \(S_n\)은 축 방향이 뒤집혀 \(-1 + 2\cos\theta\)이고, 반전 \(i\)는 −3이다. 이 규칙을 숫자의 표, 곧 행렬로 쓰면 지표는 그 대각합이지만, 이 절에서는 행렬 계산 없이 지표만 쓰면 충분하다.

군의 각 조작이 좌표, 오비탈, 결합 같은 대상을 어떻게 옮기는지 적은 규칙의 묶음을 표현이라 하며, 여기서는 조작마다 지표 하나씩을 적은 줄로 나타낸다. 더 작은 블록으로 나눌 수 없는 표현을 기약 표현이라 하고, 1차원은 A나 B, 2차원은 E, 3차원은 T로 적는다. 반면 기약 표현 여러 개의 합으로 나뉘는 표현을 가약 표현이라 하며, 분자의 진동이나 오비탈 집합이 만드는 표현은 대부분 가약이다.

2.2.2지표표 읽기

점군마다 기약 표현과 그 지표를 모은 지표표가 있다. 아래는 \(C_{2v}\)의 지표표이다.

C₂ᵥEC₂σᵥ(xz)σᵥ′(yz)1차2차
A₁1111zx², y², z²
A₂11−1−1R_zxy
B₁1−11−1x, R_yxz
B₂1−1−11y, R_xyz

맨 위 줄은 조작의 류, 왼쪽 열은 기약 표현, 가운데는 지표이고, 오른쪽 두 열은 그 표현과 같은 대칭을 가진 함수이다. 예를 들어 \(p_z\) 오비탈은 \(A_1\)처럼, \(p_x\)는 \(B_1\)처럼 변한다. 그런데 \(x\), \(y\), \(z\)와 같은 표현의 진동은 쌍극자를 바꾸므로 IR 활성이고, 2차 함수와 같은 표현의 진동은 분극률을 바꾸므로 라만 활성이다.

2.2.3환원 공식

가약 표현 \(\Gamma\) 안에 기약 표현 \(i\)가 몇 번 들어 있는지는 다음 공식으로 센다.

식 2.2.1 (환원 공식) \[n_i = \frac1h\sum_R g_R\,\chi_i(R)\,\chi_\Gamma(R)\]

\(h\)는 군의 차수(조작의 총수), \(g_R\)은 류 \(R\)에 속한 조작 수, \(\chi_i\)는 기약 표현의 지표, \(\chi_\Gamma\)는 가약 표현의 지표이다.

즉 두 지표 줄을 같은 류끼리 곱하고 류의 조작 수를 곱해 모두 더한 뒤 \(h\)로 나눈다. 이것이 되는 까닭은 지표표의 서로 다른 두 줄을 이렇게 곱해 더하면 늘 0이 되고, 같은 줄끼리는 \(h\)가 되기 때문이다. 예를 들어 \(A_1\)과 \(B_1\)은 \(1 - 1 + 1 - 1 = 0\)이다. 그래서 다른 기약 표현의 몫은 모두 사라지고 \(i\)의 몫만 남는다.

예제 2.2.1

H₂O(분자 평면 \(xz\))의 3N 표현을 구하고 진동 모드의 대칭을 구하여라.

풀이. 각 조작에서 움직이지 않는 원자 수는 \(E\) 3, \(C_2\) 1(O), \(\sigma_v(xz)\) 3, \(\sigma_v'(yz)\) 1이다. 움직이지 않는 원자 하나의 기여는 그 원자의 세 방향에 지표를 매긴 합으로 \(E\) 3, \(C_2\) −1, \(\sigma\) 1이므로 \(\Gamma_{3N} = (9, -1, 3, 1)\)이다. 환원 공식으로 \(n(A_1) = (9 - 1 + 3 + 1)/4 = 3\), \(n(A_2) = (9 - 1 - 3 - 1)/4 = 1\), \(n(B_1) = (9 + 1 + 3 - 1)/4 = 3\), \(n(B_2) = (9 + 1 - 3 + 1)/4 = 2\)이다. 따라서 \(\Gamma_{3N} = 3A_1 + A_2 + 3B_1 + 2B_2\)이고 합은 9이다.

여기서 병진(\(z, x, y \to A_1 + B_1 + B_2\))과 회전(\(R_z, R_y, R_x \to A_2 + B_1 + B_2\))을 빼면 \(\Gamma_{\text{진동}} = 2A_1 + B_1\)이다. 처음 질문의 답이 이것으로, 진동은 세 개이고 모두 IR과 라만에서 활성이다. 실제 물의 진동은 대칭 신축 3657 cm⁻¹(\(A_1\)), 굽힘 1595 cm⁻¹(\(A_1\)), 비대칭 신축 3756 cm⁻¹(\(B_1\))이다. 이 절의 탐구 카드에서 NH₃, BF₃, CH₄까지 같은 계산을 할 수 있다.

흔한 오해환원 공식에서 류의 크기 \(g_R\)을 빼먹어도 된다고 생각하기 쉽지만, 그것은 \(C_{2v}\)처럼 모든 류가 조작 하나인 군에서만 우연히 맞는다. \(C_{3v}\)(\(2C_3\), \(3\sigma_v\))에서는 꼭 곱해야 한다. 또 결과가 정수가 아니면 지표를 잘못 구한 것이다. 그리고 축퇴 표현(E, T)의 진동 하나는 모드 두세 개이지만 스펙트럼에서는 띠 하나로 보인다.
마무리

지표는 조작에서 좌표마다 그대로 +1, 뒤집힘 −1, 다른 좌표로 0을 매긴 합이고, 회전은 \(1 + 2\cos\theta\)이다. 지표표는 류와 기약 표현으로 지표와 기저 함수를 정리하며, 환원 공식 \(n_i = \frac1h\sum g_R\chi_i\chi_\Gamma\)로 가약 표현을 나눈다. 처음 질문의 물 분자는 \(\Gamma_{3N}\)에서 병진과 회전을 빼 \(2A_1 + B_1\)의 세 진동을 가지며, \(x\), \(y\), \(z\)와 같은 대칭은 IR, 2차 함수와 같은 대칭은 라만에서 활성이다.

2.2.4연습문제

기본

  1. C₂ᵥ에서 지표가 (4, 0, 2, 2)인 가약 표현을 환원하시오.
    답

    A₁: (4 + 0 + 2 + 2)/4 = 2, A₂: (4 + 0 − 2 − 2)/4 = 0, B₁: (4 − 0 + 2 − 2)/4 = 1, B₂: (4 − 0 − 2 + 2)/4 = 1. Γ = 2A₁ + B₁ + B₂.

응용

  1. C₃ᵥ(E, 2C₃, 3σᵥ; A₁ 1 1 1, A₂ 1 1 −1, E 2 −1 0)에서 NH₃의 세 N−H 결합 벡터가 만드는 표현(지표 3, 0, 1)을 환원하시오. 이것은 N−H 신축 진동의 대칭이다.
    답

    h = 6. A₁: (3 + 0 + 3 × 1)/6 = 1, A₂: (3 + 0 − 3)/6 = 0, E: (6 + 0 + 0)/6 = 1. N−H 신축 = A₁ + E(대칭 신축 하나, 축퇴된 비대칭 신축 한 쌍).

심화

  1. Td에서 CH₄의 네 C−H 결합 벡터의 표현(지표 4, 1, 0, 0, 2; 류 E, 8C₃, 3C₂, 6S₄, 6σd)을 환원하고, C−H 신축 가운데 IR 활성인 것을 고르시오.
    답

    h = 24. A₁: (4 + 8 + 0 + 0 + 12)/24 = 1. T₂: (12 + 0 + 0 + 0 + 12)/24 = 1. 나머지 0. C−H 신축 = A₁ + T₂. IR 활성은 T₂(약 3019 cm⁻¹)뿐이고, A₁(2917 cm⁻¹)은 라만에서만 보인다.
