지표표와 환원 공식

본문
이 절에서 배울 것
  • 대칭 조작을 행렬로 나타내고, 그 대각합(지표)이 표현을 대표한다는 것을 안다.
  • 지표표의 구성(류, 기약 표현, 지표, 기저 함수)을 읽는다.
  • 가약 표현을 환원 공식으로 기약 표현의 합으로 나눈다.
  • 3N 표현에서 진동 모드의 대칭을 구한다.
먼저 알아야 할 것
  • 점군 결정 (2.1절), 행렬 곱과 대각합 (공통 선형대수), 진동 분광의 선택 규칙 (화학6 5.2절).

2.2.1조작을 행렬로

대칭 조작은 좌표를 바꾸는 선형 변환이므로 행렬로 쓸 수 있습니다. C₂ᵥ에서 C₂(z축)는 (x, y, z)를 (−x, −y, z)로, σᵥ(xz)는 (x, −y, z)로 바꿉니다. 행렬의 대각합(대각 원소의 합)을 지표라 하고, C₂는 −1 − 1 + 1 = −1, σᵥ(xz)는 1 − 1 + 1 = 1입니다.

표현: 군의 각 조작에 행렬을 짝지은 것. 조작의 곱셈 관계를 행렬의 곱이 그대로 따른다.

기약 표현: 더 작은 블록으로 나눌 수 없는 표현. 점군마다 몇 개로 정해져 있고 지표표에 실려 있다. 1차원은 A·B, 2차원은 E, 3차원은 T.

가약 표현: 기약 표현 여러 개의 합으로 나뉘는 표현. 분자의 진동, 오비탈 집합이 만드는 표현은 대부분 가약이다.

2.2.2지표표 읽기

C₂ᵥEC₂σᵥ(xz)σᵥ′(yz)1차2차
A₁1111zx², y², z²
A₂11−1−1R_zxy
B₁1−11−1x, R_yxz
B₂1−1−11y, R_xyz

맨 위 줄은 조작의 류, 왼쪽 열은 기약 표현, 가운데는 지표, 오른쪽 두 열은 그 표현과 같은 대칭을 가진 함수(기저)입니다. 예를 들어 p_z 오비탈은 A₁, p_x는 B₁처럼 변합니다. x, y, z와 같은 표현의 진동은 쌍극자를 바꾸므로 IR 활성, 2차 함수와 같은 표현의 진동은 분극률을 바꾸므로 라만 활성입니다.

2.2.3환원 공식

구하려는 것: 가약 표현 Γ 안에 기약 표현 i가 몇 번 들어 있는지 \(n_i\).

식 2.2.1 (환원 공식)

\[ n_i = \frac1h\sum_R g_R\,\chi_i(R)\,\chi_\Gamma(R) \]

h는 군의 차수(조작의 총수), g_R은 류 R에 속한 조작 수, χ_i는 기약 표현의 지표, χ_Γ는 가약 표현의 지표.

기약 표현의 지표들이 서로 직교하는 벡터처럼 행동하므로(대 직교 정리), 가약 표현의 지표 벡터를 각 기약 표현 방향으로 "투영"한 것이 이 공식입니다.

예제 2.2.1

H₂O(분자 평면 xz)의 3N 표현을 구하고 진동 모드의 대칭을 구하여라.

풀이. 각 조작에서 움직이지 않는 원자 수는 E 3, C₂ 1(O), σᵥ(xz) 3(평면 안), σᵥ′ 1(O). 원자 하나의 기여(x, y, z 행렬의 지표)는 E 3, C₂ −1, σ 1이므로 Γ₃N = (9, −1, 3, 1).

  • n(A₁) = (9 − 1 + 3 + 1)/4 = 3
  • n(A₂) = (9 − 1 − 3 − 1)/4 = 1
  • n(B₁) = (9 + 1 + 3 − 1)/4 = 3
  • n(B₂) = (9 + 1 − 3 + 1)/4 = 2

Γ₃N = 3A₁ + A₂ + 3B₁ + 2B₂(합 9 = 3N). 병진(z, x, y → A₁ + B₁ + B₂)과 회전(R_z, R_y, R_x → A₂ + B₁ + B₂)을 빼면 Γ진동 = 2A₁ + B₁. 세 진동 모두 IR(z 또는 x)과 라만에서 활성입니다. 실제 물의 진동은 대칭 신축 3657(A₁), 굽힘 1595(A₁), 비대칭 신축 3756 cm⁻¹(B₁)입니다(화학6 5.2절).

이 절의 탐구 카드NH₃, BF₃, CH₄까지 같은 계산을 하고 IR·라만 활성 띠 수를 비교하는 카드가 이 절에 있습니다.
흔한 오해"환원 공식에서 류의 크기 g_R을 빼먹어도 된다"는 C₂ᵥ처럼 모든 류가 조작 하나인 군에서만 우연히 맞습니다. C₃ᵥ(2C₃, 3σᵥ)에서는 꼭 곱해야 합니다. 또 결과가 정수가 아니면 지표를 잘못 구한 것입니다. 그리고 축퇴 표현(E, T)의 진동 하나는 모드 두세 개지만 스펙트럼에서는 띠 하나로 보입니다.
요약
  1. 조작 = 행렬, 지표 = 대각합. 지표표: 류 × 기약 표현, 기저 함수.
  2. n_i = (1/h)Σ g_R χ_i(R) χ_Γ(R). 결과는 정수여야 한다.
  3. Γ₃N 지표 = (움직이지 않는 원자 수) × (원자 하나의 기여). 진동 = Γ₃N − 병진 − 회전.
  4. x, y, z 대칭 → IR 활성, 2차 함수 대칭 → 라만 활성. H₂O: 2A₁ + B₁.

2.2.4연습문제

기본

  1. C₂ᵥ에서 지표가 (4, 0, 2, 2)인 가약 표현을 환원하시오.
    답

    A₁: (4 + 0 + 2 + 2)/4 = 2, A₂: (4 + 0 − 2 − 2)/4 = 0, B₁: (4 − 0 + 2 − 2)/4 = 1, B₂: (4 − 0 − 2 + 2)/4 = 1. Γ = 2A₁ + B₁ + B₂.

응용

  1. C₃ᵥ(E, 2C₃, 3σᵥ; A₁ 1 1 1, A₂ 1 1 −1, E 2 −1 0)에서 NH₃의 세 N−H 결합 벡터가 만드는 표현(지표 3, 0, 1)을 환원하시오. 이것은 N−H 신축 진동의 대칭이다.
    답

    h = 6. A₁: (3 + 0 + 3 × 1)/6 = 1, A₂: (3 + 0 − 3)/6 = 0, E: (6 + 0 + 0)/6 = 1. N−H 신축 = A₁ + E(대칭 신축 하나, 축퇴된 비대칭 신축 한 쌍).

심화

  1. Td에서 CH₄의 네 C−H 결합 벡터의 표현(지표 4, 1, 0, 0, 2; 류 E, 8C₃, 3C₂, 6S₄, 6σd)을 환원하고, C−H 신축 가운데 IR 활성인 것을 고르시오.
    답

    h = 24. A₁: (4 + 8 + 0 + 0 + 12)/24 = 1. T₂: (12 + 0 + 0 + 0 + 12)/24 = 1. 나머지 0. C−H 신축 = A₁ + T₂. IR 활성은 T₂(약 3019 cm⁻¹)뿐이고, A₁(2917 cm⁻¹)은 라만에서만 보인다.
