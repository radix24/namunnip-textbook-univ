분자 대칭과 점군 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 개념NH₃, BF₃, CH₄의 점군을 흐름도로 정하시오(이 단원의 자기 점검). [02-01]

    힌트 1

    주축과 그에 수직인 C₂가 있나요?

    힌트 2

    CH₄는 C₃ 축이 여러 개이다.

    풀이

    NH₃: C₃, 수직 C₂ 없음, σᵥ 3개 → C₃ᵥ. BF₃: C₃, 수직 C₂ 3개, σₕ → D₃ₕ. CH₄: C₃가 4개인 고대칭 → Td.

  2. 개념[PtCl₄]²⁻(평면 사각형)와 [NiCl₄]²⁻(사면체)의 점군은? [02-01]

    힌트 1

    평면 사각형의 주축은 평면에 수직인 C₄.

    힌트 2

    분자 평면은 σₕ.

    풀이

    [PtCl₄]²⁻: C₄, 수직 C₂ 4개, σₕ → D₄ₕ. [NiCl₄]²⁻: Td.

  3. 계산C₂ᵥ에서 지표 (3, 1, 3, 1)인 표현을 환원하시오. [02-02]

    힌트 1

    h = 4, 모든 류의 크기 1.

    힌트 2

    A₁: (3 + 1 + 3 + 1)/4.

    풀이

    A₁ 2, A₂ 0, B₁ 1, B₂ 0 → 2A₁ + B₁.

  4. 계산BF₃의 세 B−F 결합 벡터의 표현(D₃ₕ: E 3, 2C₃ 0, 3C₂ 1, σₕ 3, 2S₃ 0, 3σᵥ 1)을 환원하고 B−F 신축 진동의 IR 활성을 판정하시오. [02-02]

    힌트 1

    h = 12, 류 크기 1, 2, 3, 1, 2, 3.

    힌트 2

    A₁′과 E′만 0이 아니다.

    풀이

    A₁′: (3 + 0 + 3 + 3 + 0 + 3)/12 = 1, E′: (6 + 0 + 0 + 6 + 0 + 0)/12 = 1, 나머지 0. B−F 신축 = A₁′ + E′. IR 활성은 E′(약 1450 cm⁻¹)뿐, A₁′ 대칭 신축은 라만에서만 보인다.

  5. 개념CHCl₃와 CCl₄ 가운데 극성 분자는? 점군으로 근거를 쓰시오. [02-03]

    힌트 1

    각 점군은?

    힌트 2

    극성 점군 목록.

    풀이

    CHCl₃(C₃ᵥ)는 극성 점군이라 C−H 축 방향의 쌍극자가 있다. CCl₄(Td)는 고대칭이라 비극성이다.

  6. 판단한 학생이 "1,3-다이클로로알렌 ClHC=C=CHCl은 입체 중심 탄소가 없으므로 카이랄이 아니다"라고 썼다. 평가하시오. [02-03]

    힌트 1

    알렌의 양 끝 치환기는 같은 평면에 있나요?

    힌트 2

    점군을 정하고 Sₙ이 있는지 보아라.

    풀이

    틀렸다. 알렌 양 끝의 치환기 평면은 서로 수직이라, 1,3-다이클로로알렌은 가운데 탄소를 지나는 C₂ 축 하나만 있는 C₂ 점군이다. 거울면·반전 중심·Sₙ이 없으므로 카이랄이고, 실제로 거울상 이성질체가 있다. 카이랄성은 입체 중심이 아니라 대칭으로 판정한다.
