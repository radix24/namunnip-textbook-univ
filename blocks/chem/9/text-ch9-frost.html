라티머 도표와 프로스트 도표

본문
이 절에서 배울 것
  • 라티머 도표에서 이웃하지 않은 두 화학종 사이의 표준 전위를 계산한다.
  • 라티머 도표를 프로스트 도표로 바꾸어 그린다.
  • 프로스트 도표로 가장 안정한 산화수, 산화제·환원제의 세기, 불균등화와 반불균등화를 판정한다.
먼저 알아야 할 것
  • 표준 전위와 자유 에너지 ΔG° = −nFE° (화학1 5.1절).

6.1.1라티머 도표

라티머 도표: 한 원소의 화학종을 산화수가 높은 것부터 왼쪽에 늘어놓고, 이웃한 쌍의 표준 환원 전위를 화살표 위에 적은 도표.

산성 용액의 망가니즈:

MnO₄⁻ (+7) —0.56→ MnO₄²⁻ (+6) —2.26→ MnO₂ (+4) —0.95→ Mn³⁺ (+3) —1.51→ Mn²⁺ (+2) —(−1.18)→ Mn (0)

구하려는 것: 이웃하지 않은 두 화학종 사이의 전위(예: MnO₄⁻/Mn²⁺). 전위는 더할 수 없지만 자유 에너지는 더할 수 있습니다. ΔG° = −nFE°이므로 전자 수로 가중 평균합니다.

식 6.1.1 (이웃하지 않은 쌍의 전위)

\[ E^\circ = \frac{n_1E_1^\circ + n_2E_2^\circ + \cdots}{n_1 + n_2 + \cdots} \]

MnO₄⁻ → Mn²⁺(전자 5개): (1 × 0.56 + 2 × 2.26 + 1 × 0.95 + 1 × 1.51)/5 = 7.54/5 = 1.51 V. 과망가니즈산 적정의 기준 반응(화학1 5.2절) 전위와 같습니다.

6.1.2프로스트 도표

프로스트 도표: 가로축에 산화수 N, 세로축에 N·E°(그 화학종과 원소(산화수 0) 사이 쌍의 전위 × N)를 그린 도표. 세로축은 원소 대비 자유 에너지를 F로 나눈 값이다.

라티머 도표에서 원소부터 차례로 n × E°를 쌓아 올리면 됩니다. 망가니즈: Mn 0, Mn²⁺ 2 × (−1.18) = −2.36, Mn³⁺ −2.36 + 1.51 = −0.85, MnO₂ −0.85 + 0.95 = 0.10, MnO₄²⁻ 0.10 + 2 × 2.26 = 4.62, MnO₄⁻ 4.62 + 0.56 = 5.18 V.

읽는 법은 다음과 같습니다.

  • 가장 낮은 점이 그 조건에서 열역학적으로 가장 안정한 산화 상태다(망가니즈는 Mn²⁺).
  • 두 점을 잇는 선의 기울기가 그 쌍의 표준 전위다. 기울기가 가파를수록 높은 쪽은 강한 산화제다(MnO₄⁻).
  • 어떤 점이 이웃 두 점을 잇는 선보다 위에 있으면 불균등화한다: 2Mn³⁺ → Mn²⁺ + MnO₂.
  • 두 점을 잇는 선보다 아래에 사이의 점이 있으면, 두 바깥 화학종이 만나 가운데 화학종이 된다(반불균등화): 2MnO₄⁻ + 3Mn²⁺ + 2H₂O → 5MnO₂ + 4H⁺.
예제 6.1.1

Cu²⁺/Cu⁺ = 0.153 V, Cu⁺/Cu = 0.521 V이다. 구리의 프로스트 도표를 그리고 Cu⁺가 물에서 안정한지 판정하고, 불균등화 평형 상수를 구하여라.

풀이. Cu 0, Cu⁺ 1 × 0.521 = 0.521, Cu²⁺ 0.521 + 0.153 = 0.674 V. Cu와 Cu²⁺를 잇는 선은 N = 1에서 0.337이고, Cu⁺(0.521)는 그보다 위에 있어 불균등화합니다: 2Cu⁺ → Cu + Cu²⁺, E° = 0.521 − 0.153 = 0.368 V, K = 10^(0.368/0.05916) = 1.7×10⁶. 수용액에서 Cu⁺는 CuI처럼 침전하거나 착물을 이루어야만 남아 있습니다.

이 절의 탐구 카드망가니즈, 철, 구리, 산소의 프로스트 도표를 그려 불균등화를 판정하고 평형 상수를 계산하는 카드가 이 절에 있습니다.
흔한 오해"라티머 도표의 전위를 그냥 더하면 이웃하지 않은 쌍의 전위"가 아닙니다. 전자 수로 가중해야 합니다(자유 에너지를 더함). 또 "불균등화 = 반응이 빠르다"도 아닙니다. 도표는 열역학만 알려 주며, 과산화 수소처럼 느린 경우가 많습니다. 그리고 도표는 pH에 따라 다릅니다. 염기성 도표는 산성과 모양이 달라, 산성에서 불균등화하는 MnO₄²⁻도 진한 염기에서는 안정합니다.
요약
  1. 라티머 도표: 이웃 쌍의 전위. 이웃하지 않은 쌍은 E° = Σn_iE_i°/Σn_i.
  2. 프로스트 도표: N·E° 대 N(= ΔG°/F). 원소부터 n·E°를 쌓는다.
  3. 가장 낮은 점이 가장 안정, 기울기는 전위, 볼록이면 불균등화, 오목이면 반불균등화.
  4. Mn²⁺ 안정, Mn³⁺·MnO₄²⁻ 불균등화(산성). Cu⁺ 불균등화(K 1.7×10⁶).

6.1.3연습문제

기본

  1. Fe³⁺/Fe²⁺ = 0.77 V, Fe²⁺/Fe = −0.44 V에서 Fe³⁺/Fe의 전위는?
    답

    (1 × 0.77 + 2 × (−0.44))/3 = −0.037 V.

응용

  1. O₂/H₂O₂ = 0.695 V, H₂O₂/H₂O = 1.776 V(산성)이다. 프로스트 도표 값을 구하고 H₂O₂가 불균등화하는지 판정하시오.
    답

    O₂ 0, H₂O₂(N = −1) −0.695, H₂O(N = −2) −0.695 − 1.776 = −2.471 V. H₂O와 O₂를 잇는 선은 N = −1에서 −1.236이고 H₂O₂(−0.695)는 그보다 위라 불균등화한다(2H₂O₂ → 2H₂O + O₂). (O₂/H₂O = 1.229 V로 계산하면 −2.458 V로 같은 결론)

심화

  1. 예제 6.1.1에서 Cu⁺를 I⁻와 함께 두면 CuI(Ksp = 1×10⁻¹²)로 침전한다. Cu²⁺/CuI와 CuI/Cu의 전위를 구하고 이 조건에서 Cu(I)이 안정해지는 이유를 쓰시오([I⁻] = 1 M).
    답

    [Cu⁺] = Ksp/[I⁻] = 10⁻¹² M. CuI/Cu: 0.521 + 0.05916 log 10⁻¹² = −0.189 V. Cu²⁺/CuI: 0.153 − 0.05916 log 10⁻¹² = 0.863 V. 이제 Cu(I)의 산화 쪽 전위(0.863)가 환원 쪽(−0.189)보다 훨씬 커서, 프로스트 도표에서 CuI 점이 이웃을 잇는 선보다 아래로 내려가 불균등화하지 않는다. 침전이 Cu(I)을 안정화한다.
