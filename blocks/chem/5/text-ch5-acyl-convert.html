카르복실산 유도체 사이의 변환 경로

본문
이 절에서 배울 것
  • 반응성 순서에 따라 유도체를 서로 바꾸는 경로를 고른다(아래로는 바로, 위로는 카르복실산·산 염화물을 거쳐).
  • 카르복실산을 산 염화물로 활성화하는 시약(SOCl₂)을 안다.
  • 유도체를 수소화물(LiAlH₄, DIBAL-H)과 그리냐르 시약으로 환원·변환한 생성물을 예측한다.
  • 나이트릴의 가수분해와 환원을 쓴다.
먼저 알아야 할 것
  • 반응성 순서 (5.1절), 사면체 중간체 메커니즘 (5.2절), 그리냐르 반응 (4.3절).

5.3.1내리막은 바로, 오르막은 돌아서

5.1절의 반응성 순서를 계단으로 그리면 맨 위에 산 염화물, 그 아래 산 무수물, 에스터, 아마이드, 맨 아래 카복실레이트가 있습니다. 친핵성 아실 치환은 계단을 내려가는 방향(더 안정한 유도체 쪽)으로만 잘 진행합니다.

  • 산 염화물 + RCO₂⁻ → 산 무수물
  • 산 염화물 + ROH (피리딘) → 에스터
  • 산 염화물 + 2 R₂NH → 아마이드
  • 산 무수물 + ROH → 에스터 + RCO₂H (아스피린 합성: 살리실산 + 아세트산 무수물)
  • 산 무수물 + 2 R₂NH → 아마이드
  • 모든 유도체 + H₂O (산 또는 염기) → 카르복실산(카복실레이트)

계단을 오르려면(예: 아마이드 → 에스터) 먼저 가수분해로 카르복실산까지 내려간 다음, 카르복실산을 맨 위 산 염화물로 끌어올리고 다시 내려옵니다.

반응 5.3.1 (카르복실산의 활성화)

\[ \mathrm{RCO_2H} + \mathrm{SOCl_2} \longrightarrow \mathrm{RCOCl} + \mathrm{SO_2}\uparrow + \mathrm{HCl}\uparrow \]

OH가 SOCl₂와 반응해 좋은 이탈기(클로로설파이트)로 바뀐 뒤 Cl⁻가 아실 치환한다. 부산물이 기체라 평형이 오른쪽으로 간다. 옥살릴 염화물 (COCl)₂도 쓴다.

산과 아민을 섞으면 아마이드가 아니라 암모늄 카복실레이트 염이 먼저 생깁니다(산-염기 반응이 빠름). 그래서 아마이드는 보통 산 염화물을 거치거나, 펩타이드 합성처럼 DCC 같은 결합 시약으로 OH를 활성화해 만듭니다.

5.3.2수소화물 환원

출발 물질LiAlH₄ (후 H₃O⁺)DIBAL-H (−78 °C)NaBH₄
산 염화물1차 알코올알데하이드1차 알코올
에스터1차 알코올 + R′OH알데하이드거의 반응 안 함
카르복실산1차 알코올—반응 안 함
아마이드아민 (C=O → CH₂)—반응 안 함
나이트릴1차 아민 RCH₂NH₂알데하이드 (가수분해 후)반응 안 함

에스터를 LiAlH₄로 환원하면 왜 알데하이드에서 멈추지 않을까요? 첫 H⁻가 첨가한 사면체 중간체에서 R′O⁻가 떨어지면 알데하이드가 생기는데, 알데하이드는 에스터보다 반응성이 커서(4단원) 남아 있는 LiAlH₄와 바로 반응해 1차 알코올이 됩니다. DIBAL-H를 −78 °C에서 1당량만 쓰면 사면체 중간체가 알루미늄에 붙은 채 안정하게 머물다가, 후처리 때 무너져 알데하이드가 남습니다.

아마이드는 특이합니다. 사면체 중간체에서 떨어지는 것이 질소가 아니라 산소(알루미늄에 붙은 O)여서 이미늄 이온이 생기고, 그것이 다시 환원되어 아민이 됩니다. 결과적으로 C=O가 CH₂로 바뀝니다.

5.3.3그리냐르 시약과 에스터

에스터에 그리냐르 시약을 넣으면 LiAlH₄와 같은 이유로 두 번 첨가합니다. 첫 R⁻가 첨가·제거해 케톤이 생기고, 케톤이 에스터보다 반응성이 커서 둘째 R⁻가 바로 첨가합니다. 결과는 같은 R 두 개가 붙은 3차 알코올입니다.

\[ \mathrm{R'CO_2Et} + 2\,\mathrm{RMgBr} \;\xrightarrow{\;\text{후 } \mathrm{H_3O^+}\;}\; \mathrm{R'R_2COH} \]

그래서 역합성에서 "카비놀 탄소에 같은 기가 두 개 붙은 3차 알코올"을 보면 에스터 + 그리냐르 2당량을 떠올립니다. 케톤에서 멈추고 싶으면 반응성이 약한 유기 구리 시약(R₂CuLi)을 산 염화물에 쓰거나, 바인렙 아마이드를 씁니다.

5.3.4나이트릴

나이트릴은 SN2(할로젠화 알킬 + CN⁻, 화학2 5단원)로 쉽게 만들 수 있어 탄소 하나를 늘리는 데 씁니다.

  • 산 또는 염기 수용액에서 가열 → 아마이드를 거쳐 카르복실산(RCH₂Br → RCH₂CN → RCH₂CO₂H).
  • LiAlH₄ → 1차 아민 RCH₂NH₂.
  • 그리냐르 시약 첨가 후 가수분해 → 케톤 (이민 음이온이 한 번만 첨가되어 멈춤).
예제 5.3.1

N,N-다이에틸벤즈아마이드에서 벤조산 메틸을 만들어라. 아마이드에 메탄올을 바로 넣으면 왜 안 되는가?

풀이. 아마이드 → 에스터는 계단을 오르는 방향이라, 메톡사이드(pKa 16의 짝염기)가 다이에틸아마이드 음이온(pKa 약 36의 짝염기)을 밀어낼 수 없습니다. 경로: (1) H₃O⁺, 가열(또는 NaOH, 가열 후 산성화) → 벤조산 + 다이에틸아민. (2) 피셔 에스터화(CH₃OH 과량, H₂SO₄) → 벤조산 메틸. 또는 (2′) SOCl₂ → 벤조일 염화물, (3′) CH₃OH, 피리딘 → 벤조산 메틸.

예제 5.3.2

벤조산 에틸에 CH₃MgBr 과량을 넣고 산 처리한 생성물과, 같은 에스터를 DIBAL-H(1당량, −78 °C)로 처리한 생성물을 쓰시오.

풀이. CH₃MgBr 과량: 첫 첨가·제거로 아세토페논이 생기고 둘째 CH₃가 첨가해 2-페닐-2-프로판올 C₆H₅C(OH)(CH₃)₂가 됩니다. DIBAL-H: 벤즈알데하이드 C₆H₅CHO.

흔한 오해"에스터 + 그리냐르 1당량 → 케톤"은 실제로 잘 되지 않습니다. 생긴 케톤이 에스터보다 빨리 반응해 3차 알코올과 남은 에스터의 혼합물이 됩니다. 또 "NaBH₄로 카르복실산을 알코올로 환원"할 수 없습니다. 산은 NaBH₄와 산-염기 반응만 하고, 환원에는 LiAlH₄나 BH₃가 필요합니다. 그리고 아마이드를 LiAlH₄로 환원하면 알코올이 아니라 아민이 됩니다.
요약
  1. 반응성 계단을 내려가는 변환은 바로 된다. 오르려면 카르복실산까지 내려간 뒤 SOCl₂로 산 염화물을 만든다.
  2. LiAlH₄: 에스터·산 → 1차 알코올, 아마이드 → 아민, 나이트릴 → 1차 아민. DIBAL-H(−78 °C): 에스터 → 알데하이드.
  3. 에스터 + 그리냐르 2당량 → 같은 R 두 개의 3차 알코올.
  4. 나이트릴: 가수분해 → 카르복실산, 환원 → 아민, 그리냐르 → 케톤.

5.3.5연습문제

기본

  1. 프로판오일 염화물과 다음의 반응 생성물을 쓰시오: (가) 에탄올/피리딘, (나) 다이메틸아민 2당량, (다) 물.
    답

    (가) 프로판산 에틸, (나) N,N-다이메틸프로판아마이드, (다) 프로판산(+ HCl).

응용

  1. 1-브로모뷰테인에서 펜탄산과 1-펜탄아민을 각각 만드는 방법을 쓰시오.
    답

    NaCN(SN2) → 펜탄나이트릴 CH₃(CH₂)₃CN. 펜탄산: H₃O⁺, 가열. 1-펜탄아민: LiAlH₄, 다음 물 처리. (펜탄산은 그리냐르 + CO₂로도 가능)

심화

  1. 3-에틸-3-펜탄올 (CH₃CH₂)₃COH를 에스터와 그리냐르 시약으로 만드는 방법을 쓰고, 케톤 + 그리냐르 방법과 비교하시오.
    답

    프로판산 에틸 + CH₃CH₂MgBr 2당량(이상), 후 H₃O⁺. 또는 탄산 다이에틸 (EtO)₂CO + CH₃CH₂MgBr 3당량으로 세 에틸을 모두 붙일 수 있다. 케톤 방법은 3-펜탄온 + CH₃CH₂MgBr 1당량. 세 기가 같으면 에스터·탄산 에스터 방법이 출발 물질이 간단하다.
