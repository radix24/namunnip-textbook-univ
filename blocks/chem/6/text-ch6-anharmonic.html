진동 스펙트럼: 선택 규칙과 비조화성

본문
이 절에서 배울 것
  • 적외선 흡수와 라만 산란의 선택 규칙을 구별한다.
  • 실제 결합의 퍼텐셜이 조화 진동자에서 벗어나는 이유(비조화성)와 그 결과(준위 간격 감소, 배음, 해리)를 설명한다.
  • 비조화 진동자 식으로 기본음과 배음의 위치, 해리 에너지를 어림한다.
  • 다원자 분자의 기준 진동 수를 센다.
먼저 알아야 할 것
  • 조화 진동자 (2.2절), 선택 규칙과 전이 쌍극자 (5.1절).

5.2.1IR 스펙트럼이 말해 주는 것

유기화학에서 카보닐(1700 cm⁻¹ 근처), O−H(3300 cm⁻¹ 근처) 같은 작용기를 IR로 찾을 수 있는 것은, 결합마다 힘 상수와 환산 질량이 달라 진동수가 다르기 때문입니다. 이 절은 진동 스펙트럼의 규칙을 정리하고, 실제 결합이 용수철과 다르게 행동하는 점(비조화성)을 다룹니다.

5.2.2IR과 라만의 선택 규칙

적외선(IR) 흡수: 진동하면서 쌍극자 모멘트가 변해야 한다. 조화 근사에서 Δv = ±1.

라만 산란: 강한 단색광을 비추면 대부분은 같은 진동수로 산란되지만, 일부는 분자 진동 에너지만큼 진동수가 바뀌어 산란된다. 진동하면서 분극률(전자 구름이 늘어나는 정도)이 변해야 한다.

두 규칙은 서로 보완합니다. CO₂의 대칭 신축(두 O가 동시에 바깥으로)은 쌍극자가 0으로 남아 IR에서는 안 보이지만 분극률이 변해 라만에서 보입니다. 비대칭 신축(2349 cm⁻¹)과 굽힘(667 cm⁻¹)은 쌍극자가 변해 IR에서 보입니다. 대칭 중심이 있는 분자에서는 IR과 라만에서 보이는 진동이 서로 겹치지 않습니다(상호 배제 규칙).

5.2.3비조화성

실제 결합을 아주 많이 늘이면 결국 끊어집니다. 그런데 조화 퍼텐셜 \(\tfrac12kx^2\)은 끝없이 올라가 결합이 절대 끊어지지 않는 용수철입니다. 실제 퍼텐셜은 평형 근처에서만 포물선에 가깝고, 늘어나는 쪽은 완만해져 해리 에너지 \(D_e\)에서 평평해지며, 줄어드는 쪽은 핵 반발로 가파르게 올라갑니다. 이런 모양을 잘 흉내 내는 함수가 모스 퍼텐셜 \(V = D_e(1 - e^{-a x})^2\)입니다.

비조화 퍼텐셜에서 진동 준위는 다음과 같습니다(파수 단위).

식 5.2.1 (비조화 진동자의 준위)

\[ G(v) = \tilde\nu_e\left(v + \tfrac12\right) - \tilde\nu_ex_e\left(v + \tfrac12\right)^2 \]

\(\tilde\nu_ex_e\)는 비조화 상수로 \(\tilde\nu_e\)보다 훨씬 작은 양수이다.

결과로 세 가지가 달라집니다.

  • 준위 간격이 위로 갈수록 줄어든다: 간격 \(G(v+1) - G(v) = \tilde\nu_e - 2\tilde\nu_ex_e(v+1)\).
  • 배음이 약하게 나타난다: 선택 규칙이 엄격하지 않아 Δv = ±2, ±3(배음)도 약하게 흡수됩니다. 위치는 기본음의 정수배보다 조금 낮습니다.
  • 해리: 준위가 점점 촘촘해지다가 해리 에너지에서 끝납니다. 실제로 결합을 끊는 데 드는 에너지는 바닥 진동 상태에서 잰 \(D_0 = D_e - G(0)\)입니다.
예제 5.2.2

H³⁵Cl의 \(\tilde\nu_e = 2990.9\) cm⁻¹, \(\tilde\nu_ex_e = 52.8\) cm⁻¹이다. 기본음(0 → 1), 첫째 배음(0 → 2), 둘째 배음(0 → 3)의 위치를 구하여라.

풀이. \((G(0) = 1482.2)\), \(G(1) = 4367.6\), \((G(2) = 7147.2)\), \(G(3) = 9821.4\) cm⁻¹. 기본음 2885.3, 첫째 배음 5665.0, 둘째 배음 8339.1 cm⁻¹입니다. 실험값(2886, 5668, 8347 cm⁻¹)과 잘 맞습니다. 첫째 배음이 기본음의 두 배(5770.6)보다 105.6 cm⁻¹ 낮은 것이 비조화성의 증거입니다.

모스 퍼텐셜이라고 보면 해리 에너지를 \(D_e \approx \tilde\nu_e^2/(4\tilde\nu_ex_e) = 42\,400\) cm⁻¹로 어림할 수 있고, \(D_0 = D_e - G(0) \approx 40\,900\) cm⁻¹ ≈ 489 kJ/mol입니다. 실제 HCl의 결합 해리 에너지(약 427 kJ/mol)보다 크게 나오는데, 높은 준위로 갈수록 실제 간격이 모스 식보다 빨리 줄어들기 때문입니다. 어림법의 한계를 보여 주는 예입니다.

5.2.4다원자 분자의 기준 진동

원자가 N개인 분자는 진동이 3N − 6개(직선 분자는 3N − 5개)이고, 각각의 IR·라만 활성은 쌍극자와 편극률의 변화로 판단합니다. H₂O와 CO₂의 예는 5.3절에 있습니다.

흔한 오해"IR에서 안 보이는 진동은 없는 진동"이 아닙니다. CO₂의 대칭 신축처럼 쌍극자 변화가 없는 진동은 라만으로 봅니다. 또 "배음은 기본음의 정확히 두 배"는 조화 근사의 결과이고, 실제로는 비조화성 때문에 조금 낮습니다.
요약
  1. IR은 쌍극자 변화, 라만은 분극률 변화가 필요하다. 대칭 중심이 있으면 서로 배제한다.
  2. 실제 결합은 비조화: \(G(v) = \tilde\nu_e(v + \tfrac12) - \tilde\nu_ex_e(v + \tfrac12)^2\), 위로 갈수록 간격이 준다.
  3. 비조화성 때문에 배음이 약하게 보이고, 기본음의 정수배보다 조금 낮다.
  4. 기준 진동 수: 비선형 3N − 6, 선형 3N − 5.

5.2.5연습문제

기본

  1. NH₃, C₂H₂(선형), C₆H₆의 기준 진동 수는?
    답

    NH₃ 6, C₂H₂ 7, C₆H₆ 30.

응용

  1. CO의 기본음이 2143 cm⁻¹, 첫째 배음이 4260 cm⁻¹이다. \(\tilde\nu_e\)와 \(\tilde\nu_ex_e\)를 구하시오.
    힌트

    기본음 = \(\tilde\nu_e - 2\tilde\nu_ex_e\), 첫째 배음 = \(2\tilde\nu_e - 6\tilde\nu_ex_e\).

    답

    두 식을 풀면 \(\tilde\nu_ex_e = (2\times2143 - 4260)/2 = 13\) cm⁻¹, \(\tilde\nu_e = 2143 + 26 = 2169\) cm⁻¹.

심화

  1. 비조화 진동자의 준위 간격이 0이 되는 v를 구하는 방법으로 HCl의 해리 직전 진동 양자수를 어림하시오.
    답

    \(\tilde\nu_e - 2\tilde\nu_ex_e(v+1) = 0\)에서 \(v + 1 = 2990.9/105.6 = 28.3\), 곧 약 v = 27까지 묶인 준위가 있다고 어림된다(모스 모형의 결과).
