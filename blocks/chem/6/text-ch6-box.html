슈뢰딩거 방정식과 상자 속 입자

본문

당근의 주황색을 내는 β-카로틴은 탄소 사슬을 따라 이중 결합이 열한 개 번갈아 놓인 분자이고, 사슬이 짧은 뷰타다이엔은 색이 없이 자외선만 흡수한다. 공액 사슬이 길어질수록 왜 더 긴 파장의 빛을 흡수할까? 사슬 위의 전자를 상자에 갇힌 파동으로 보면 답이 나올까?

먼저 알아야 할 것물질파와 불확정성(1.2절), 2계 미분 \((\sin kx)'' = -k^2\sin kx\)와 정적분(고교 미적분, 더 자세히는 공통1 미분적분학)을 쓴다.

2.1.1파동을 다루는 방정식

1단원에서 전자가 파동처럼 행동한다는 것을 보았다. 기타 줄의 진동을 파동 방정식으로 다루듯, 전자의 파동에도 그것을 다스리는 방정식이 있어야 한다. 1926년 슈뢰딩거가 제안한 방정식이 그것이며, 이 방정식의 해를 파동함수 \(\psi\)라 부른다. 이 절에서는 벽 사이에 갇힌 입자라는 가장 단순한 경우를 처음부터 끝까지 풀어, 에너지가 왜 양자화되는지 직접 본다.

2.1.2시간에 무관한 슈뢰딩거 방정식

식 2.1.1 (1차원 슈뢰딩거 방정식) \[-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi\]

왼쪽의 첫째 항은 파동함수가 얼마나 급하게 휘는지로 나타낸 운동 에너지이고, 둘째 항은 위치 에너지 \(V(x)\)이다. 둘의 합이 전체 에너지 \(E\)와 같다는 에너지 보존을 파동의 언어로 쓴 것이다. 우리가 구하려는 것은 이 식을 만족하면서 물리적으로 말이 되는 함수, 곧 유한하고 연속이며 한 값만 갖는 \(\psi\)와 그때의 \(E\)이다. 이런 해는 특정한 \(E\)에서만 존재하며, 이것이 양자화의 원인이다.

파동함수의 뜻은 보른이 정했다. \(|\psi(x)|^2dx\)는 입자를 \(x\)와 \(x + dx\) 사이에서 발견할 확률이다. 그래서 전체 공간에서 적분하면 1이어야 하며, \(\int|\psi|^2dx = 1\)이 되도록 \(\psi\)의 크기를 정하는 것을 정규화라 한다.

2.1.3상자 속 입자 풀기

길이 \(a\)인 상자 안(\(0 < x < a\))에서는 \(V = 0\)이고, 벽과 바깥은 \(V = \infty\)라고 하자. 입자는 벽 밖으로 나갈 수 없으므로 바깥에서 \(\psi = 0\)이고, \(\psi\)가 연속이어야 하므로 벽에서도 \(\psi(0) = \psi(a) = 0\)이다. 이것이 경계 조건이다.

먼저 상자 안에서 방정식은 \(\psi'' = -k^2\psi\), \(k^2 = 2mE/\hbar^2\)이다. 두 번 미분하면 자기 자신의 음수배가 되는 함수이므로 일반해는 \(\psi = A\sin kx + B\cos kx\)이다. 다음으로 \(\psi(0) = 0\)에서 \(B = 0\)이다. 그리고 \(\psi(a) = 0\)에서 \(A\sin ka = 0\)인데, \(A = 0\)이면 입자가 없으므로 \(\sin ka = 0\), 곧 \(ka = n\pi\)(\(n = 1, 2, 3, \dots\))이다. \(n = 0\)은 \(\psi = 0\)이 되어 뺀다. 마지막으로 \(k = n\pi/a\)를 \(k^2 = 2mE/\hbar^2\)에 넣으면 에너지가 나온다.

결과 2.1.2 (상자 속 입자) \[E_n = \frac{n^2h^2}{8ma^2}, \qquad \psi_n(x) = \sqrt{\frac2a}\sin\frac{n\pi x}{a}, \qquad n = 1, 2, 3, \dots\]

계수 \(\sqrt{2/a}\)는 \(\int_0^a\sin^2(n\pi x/a)dx = a/2\)에서 정규화로 나온다. 양자화가 생긴 이유는 경계 조건이다. 그림 1처럼 상자의 양 끝이 마디가 되도록 반파장의 정수배만 들어갈 수 있어, 기타 줄의 배음처럼 허용되는 파동이 띄엄띄엄 정해진다.

결과에서 몇 가지를 읽을 수 있다. 먼저 가장 낮은 에너지 \(E_1 = h^2/8ma^2\)도 0이 아니며, 이것을 영점 에너지라 한다. 갇힌 입자는 정지할 수 없으며 불확정성 원리와도 맞는다. 다음으로 에너지 간격은 \(1/ma^2\)에 비례하므로 상자가 작을수록, 입자가 가벼울수록 커진다. 1 nm 상자 속 전자는 \(E_1 = 0.38\) eV로 화학적으로 의미 있는 크기이다. 또 \(\psi_n\)에는 상자 안에 마디가 \(n - 1\)개 있고, 마디가 많을수록 에너지가 높다.

한편 확률 분포도 고전 입자와 다르다. \(n = 1\)에서는 가운데에서 발견될 확률이 가장 크며, 가운데 1/3 구간에서 찾을 확률이 61%이다. 고전 입자라면 어디서나 같아 1/3이었을 것이다. 다만 \(n\)이 커지면 분포가 고르게 되어 고전적 결과에 다가가며, 이것을 대응 원리라 한다.

2.1.4공액 분자에 적용하기

뷰타다이엔 CH₂=CH−CH=CH₂의 π 전자 4개는 탄소 사슬 전체에 퍼져 움직인다. 이 전자들을 길이 \(a\)인 1차원 상자에 갇힌 입자로 보자. 한 준위에 두 개씩 채우면 \(n = 1, 2\)가 차고, 빛을 흡수하면 전자 하나가 \(n = 2\)에서 \(3\)으로 올라간다.

\[\Delta E = E_3 - E_2 = \frac{5h^2}{8m_ea^2}, \qquad \lambda = \frac{8m_eca^2}{5h}\]
예제 2.1.1

뷰타다이엔의 상자 길이를 578 pm(C−C, C=C 결합 길이의 합에 양 끝 반 결합씩을 더한 값)로 놓고 흡수 파장을 구하여라.

풀이. \(\lambda = 8(9.109\times10^{-31})(2.998\times10^8)(578\times10^{-12})^2/(5\times6.626\times10^{-34}) = 2.20\times10^{-7}\) m, 곧 220 nm이다. 실험값 217 nm와 아주 가깝다.

그러면 처음 질문에도 답할 수 있다. \(\pi\) 전자가 \(N\)개이면 흡수는 \(n = N/2\)에서 \(N/2 + 1\)로의 전이이므로 \(\lambda = 8m_eca^2/(h(N + 1))\)이다. 사슬 길이 \(a\)는 \(N\)에 거의 비례하므로 \(\lambda\)도 대략 \(N\)에 비례해 늘어난다. 공액이 길수록 긴 파장을 흡수하고, 충분히 길면 흡수가 가시광으로 들어와 색이 생긴다. 다만 긴 사슬에서는 모형이 과대 예측한다. 헥사트라이엔(전자 6개, \(a \approx 867\) pm)은 약 354 nm로 예측되지만 실험값은 약 258 nm이다. 시아닌 염료로 이 모형을 직접 맞춰 보는 실습 카드가 이 절에 있다.

흔한 오해\(n = 0\)이면 에너지가 0인 상태가 될 것 같지만 그런 상태는 없다. \(n = 0\)이면 \(\psi = 0\)이라 입자 자체가 없다. 또 입자가 마디에서 갑자기 사라졌다 나타난다고 생각하기 쉽지만, 파동함수는 입자의 궤적이 아니라 발견 확률의 분포이다. 마디를 지나가는 입자라는 그림 자체가 맞지 않는다.
마무리

슈뢰딩거 방정식은 운동 에너지와 위치 에너지의 합이 전체 에너지라는 것을 파동으로 쓴 것이고, \(|\psi|^2\)은 확률 밀도이다. 상자 속 입자에서는 경계 조건 \(\psi(0) = \psi(a) = 0\)이 에너지를 \(E_n = n^2h^2/8ma^2\)로 양자화하며, 영점 에너지가 있고 \(\psi_n\)의 마디는 \(n - 1\)개이다. 공액 분자의 π 전자를 상자에 넣으면 \(\lambda = 8m_eca^2/(h(N+1))\)로 흡수 파장을 어림할 수 있어, 처음 질문처럼 사슬이 길수록 긴 파장을 흡수한다.

2.1.5연습문제

기본

  1. 1 nm 상자 속 전자의 n = 1 → 2 전이에 해당하는 빛의 파장은?
    답

    ΔE = 3E₁ = 1.13 eV, λ = 1240/1.13 = 1100 nm(근적외선).

  2. ψ₂의 마디는 상자의 어디에 있는가(양 끝 제외)?
    답

    x = a/2.

응용

  1. 상자 길이를 두 배로 하면 E₁과 흡수 파장은 어떻게 바뀌는가?
    답

    E는 1/4, 같은 전이의 파장은 4배.

심화

  1. n = 1 상태에서 입자를 0 ≤ x ≤ a/4에서 발견할 확률을 적분으로 구하시오.
    힌트

    \(\int \sin^2u\,du = u/2 - \sin2u/4\).

    답

    \(\frac2a\int_0^{a/4}\sin^2(\pi x/a)dx = \frac14 - \frac1{2\pi} = 0.091\). 고전적 값 0.25보다 작다(벽 근처에서 ψ가 작음).
