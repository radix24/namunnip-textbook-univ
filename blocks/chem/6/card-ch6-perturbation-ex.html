상자 가운데에 걸린 섭동은 어느 준위를 더 올리나

1차 섭동 · 기대값 · 파동함수 모양

출발점

1차 보정은 섭동이 걸린 구간에서 그 상태를 발견할 확률에 비례합니다. 파동함수가 어디에 몰려 있는지가 결과를 정합니다.

길이 L인 상자의 가운데 1/3(L/3 ~ 2L/3)에만 상수 섭동 \(V_0\)가 걸렸다. n = 1과 n = 2 상태의 1차 에너지 보정을 구하여라.

풀이

  1. \(E_n^{(1)} = V_0\int_{L/3}^{2L/3}\frac2L\sin^2\frac{n\pi x}{L}dx\), \(\int\sin^2kx\,dx = \frac x2 - \frac{\sin2kx}{4k}\).
    가운데 구간에서 입자를 발견할 확률에 \(V_0\)를 곱합니다.
  2. n = 1: \(\frac2L\left[\frac L6 - \frac{L}{4\pi}\left(\sin\frac{4\pi}3 - \sin\frac{2\pi}3\right)\right] = \frac13 + \frac{\sqrt3}{2\pi} = 0.609\).
    사인 값 −0.866과 0.866의 차이 −1.732.
  3. n = 2: \(\frac2L\left[\frac L6 - \frac{L}{8\pi}\left(\sin\frac{8\pi}3 - \sin\frac{4\pi}3\right)\right] = \frac13 - \frac{\sqrt3}{4\pi} = 0.196\).
    사인 값 0.866과 −0.866의 차이 +1.732.
  4. 따라서 \(E_1^{(1)} = 0.609V_0\), \(E_2^{(1)} = 0.196V_0\).
    바닥 상태가 세 배 넘게 크게 올라갑니다.

의미

n = 1 파동함수는 상자 가운데에 봉우리가 있어 가운데 섭동을 많이 느끼고, n = 2는 가운데에 마디가 있어 거의 느끼지 않습니다. 이 때문에 두 준위의 간격(전이 에너지)이 \(0.413V_0\)만큼 줄어듭니다. 공액 사슬 가운데에 전자를 끄는 원자를 넣으면 흡수 파장이 바뀌는 것을 이런 식으로 어림할 수 있습니다.

검산

섭동이 상자 전체에 균일하게 퍼져 있다면 확률이 정확히 1/3이어야 합니다. 두 결과의 평균은 아니지만, n이 커질수록 \(|\psi|^2\)가 고르게 퍼져 1/3에 다가가야 하고, 사인 항의 크기가 \(1/n\)로 줄어 그렇게 됩니다.
