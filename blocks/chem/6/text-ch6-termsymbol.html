원자의 항 기호

본문
이 절에서 배울 것
  • 같은 전자 배치에서도 에너지가 다른 여러 상태(항)가 생기는 이유를 안다.
  • 전체 궤도 각운동량 L, 전체 스핀 S, 전체 각운동량 J로 항 기호 \({}^{2S+1}L_J\)를 쓴다.
  • 훈트 규칙으로 바닥 항을 정한다.
먼저 알아야 할 것
  • 양자수 l, mₗ, mₛ와 파울리 원리 (3.1절, 3.2절).
  • 전자 배치와 훈트 규칙 (공통5 전자 배치).

3.3.11s²2s²2p², 하지만 상태는 여러 개

탄소의 전자 배치는 1s²2s²2p²입니다. 그런데 p 오비탈 세 개에 전자 둘을 넣는 방법은 스핀까지 따지면 15가지이고, 이들은 전자끼리의 반발과 스핀 상호작용 때문에 에너지가 같지 않습니다. 원자 분광학에서 보이는 선들, 그리고 전이 금속 착물의 색(무기화학2의 Tanabe-Sugano 도표)을 이해하려면 이 상태들을 구별하는 이름이 필요합니다. 그것이 항 기호입니다.

3.3.2항 기호의 구성

열린 껍질(전자가 다 차지 않은 부껍질)의 전자들의 각운동량을 더합니다. 꽉 찬 부껍질은 합이 0이라 무시합니다.

전체 궤도 각운동량 L: 각 전자의 mₗ을 더한 \(M_L\)의 최댓값으로 정해진다. L = 0, 1, 2, 3을 S, P, D, F로 쓴다(전자 하나의 s, p, d, f와 같은 순서).

전체 스핀 S: 각 전자의 mₛ을 더한 \(M_S\)의 최댓값. \(2S + 1\)을 다중도라 하고 왼쪽 위에 쓴다(1 홑겹, 2 두겹, 3 세겹).

전체 각운동량 J: L과 S가 합쳐진 것으로 \(|L - S|, \dots, L + S\)의 값을 가지며 오른쪽 아래에 쓴다.

예를 들어 \({}^3P_0\)는 S = 1(세겹), L = 1(P), J = 0인 상태입니다. 수소 바닥 상태(1s¹)는 L = 0, S = 1/2, J = 1/2이라 \({}^2S_{1/2}\)입니다.

3.3.3훈트 규칙으로 바닥 항 구하기

규칙 3.3.1 (훈트 규칙, 바닥 항)
  1. S가 가장 큰 항이 가장 낮다(전자를 홀전자로 같은 스핀에 둔다).
  2. S가 같으면 L이 가장 큰 항이 낮다.
  3. 부껍질이 절반 미만이면 J가 가장 작은 것, 절반을 넘으면 J가 가장 큰 것이 낮다.

바닥 항만 필요할 때는 다음 순서가 빠릅니다. ① 열린 부껍질의 오비탈을 mₗ이 큰 것부터 늘어놓고, ② 전자를 먼저 모두 같은 스핀(위)으로 하나씩, 남으면 아래 스핀으로 다시 큰 mₗ부터 채운 뒤, ③ \(M_S\)의 합으로 S, \(M_L\)의 합으로 L을 읽고, ④ 규칙 3으로 J를 정합니다.

예제 3.3.2

탄소(2p²), 질소(2p³), 산소(2p⁴)의 바닥 항을 구하여라.

풀이. p 오비탈의 mₗ은 +1, 0, −1입니다.

  • C(2p²): +1과 0에 위 스핀 하나씩. S = 1, \(M_L = 1\), L = 1. 절반 미만이라 J = |L − S| = 0. 바닥 항 \({}^3P_0\).
  • N(2p³): 세 오비탈에 위 스핀 하나씩. S = 3/2, \(M_L = 0\), L = 0. J = 3/2. 바닥 항 \({}^4S_{3/2}\).
  • O(2p⁴): 위 스핀 셋 + 아래 스핀 하나(+1에). S = 1, \(M_L = 1\), L = 1. 절반을 넘어 J = L + S = 2. 바닥 항 \({}^3P_2\).

p²에서 생기는 모든 항은 \({}^3P\), \({}^1D\), \({}^1S\)입니다(15개 상태 = 9 + 5 + 1). 바닥 항이 \({}^3P\)라는 것이 탄소가 홀전자 둘을 가진 상태를 선호한다는 사실, 그리고 산소 분자의 상자성과도 이어집니다.

J에 따른 갈라짐(스핀-궤도 결합)은 가벼운 원자에서는 작고 무거운 원자에서 큽니다. 소듐 가로등의 노란빛이 589.0 nm와 589.6 nm 두 선(D선)으로 나뉘는 것은 3p 들뜬 상태가 \({}^2P_{3/2}\)와 \({}^2P_{1/2}\)로 갈라졌기 때문입니다. 4.3절 [화학2-04-03]의 편광계가 쓰는 "나트륨 D선"이 바로 이 빛입니다.

흔한 오해항 기호의 S(전체 스핀)와 L = 0을 뜻하는 글자 S를 헷갈리기 쉽습니다. \({}^4S_{3/2}\)에서 왼쪽 위 4는 다중도(S = 3/2), 가운데 S는 L = 0입니다. 또 꽉 찬 부껍질(1s², 2s²)을 계산에 넣지 않는 이유는 그 합이 언제나 L = 0, S = 0이기 때문입니다.
요약
  1. 같은 배치에서도 전자 반발과 스핀 때문에 에너지가 다른 항들이 생긴다.
  2. 항 기호 \({}^{2S+1}L_J\): L은 S, P, D, F, 다중도 2S + 1, J = |L − S| … L + S.
  3. 훈트 규칙: S 최대 → L 최대 → 절반 미만이면 J 최소, 넘으면 J 최대.
  4. C ³P₀, N ⁴S₃/₂, O ³P₂.

3.3.4연습문제

기본

  1. B(2p¹)와 F(2p⁵)의 바닥 항은?
    답

    B: ²P₁/₂(절반 미만, J 최소). F: ²P₃/₂(절반 초과, J 최대).

응용

  1. Ti(3d²)의 바닥 항을 구하시오(d 오비탈 mₗ = +2 … −2).
    답

    +2와 +1에 위 스핀: S = 1, L = 3(F), J = |3 − 1| = 2. ³F₂.

  2. Fe²⁺(3d⁶)의 바닥 항은?
    답

    위 스핀 다섯(+2…−2) + 아래 스핀 하나(+2). S = 2, M_L = 2, L = 2(D). 절반 초과 J = 4. ⁵D₄.

심화

  1. p² 배치에서 생기는 상태가 15개임을 세고, ³P, ¹D, ¹S의 축퇴도 합이 15임을 확인하시오.
    답

    오비탈-스핀 자리 6개에서 전자 2개를 고르는 경우 6C2 = 15. 항의 축퇴도 (2S+1)(2L+1): ³P 3×3 = 9, ¹D 1×5 = 5, ¹S 1. 합 15.
