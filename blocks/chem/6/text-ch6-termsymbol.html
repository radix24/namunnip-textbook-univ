원자의 항 기호

본문

탄소의 전자 배치는 1s²2s²2p² 하나뿐이지만, 탄소 원자의 스펙트럼에는 이 배치에서 나온 서로 다른 에너지의 상태가 여럿 보인다. 배치가 같은데 에너지가 왜 다를까? 그 가운데 가장 낮은 상태는 어떻게 고르고, 어떤 이름으로 부를까?

먼저 알아야 할 것양자수 \(l\), \(m_l\), \(m_s\)와 파울리 원리(3.1절, 3.2절), 전자 배치와 훈트 규칙(공통5 전자 배치)을 쓴다.

3.3.1배치는 하나, 상태는 여럿

탄소의 전자 배치는 1s²2s²2p²이다. 그런데 p 오비탈 세 개에 전자 둘을 넣는 방법은 스핀까지 따지면 15가지이다. 이들은 전자끼리의 반발과 스핀 상호작용 때문에 에너지가 같지 않으며, 처음 질문의 여러 상태가 이것이다. 원자 분광학에서 보이는 선들과 전이 금속 착물의 색(무기화학2의 다나베-스가노 도표)을 이해하려면 이 상태들을 구별하는 이름이 필요하며, 그것이 항 기호이다.

3.3.2항 기호의 구성

항 기호를 만들 때는 열린 껍질, 곧 전자가 다 차지 않은 부껍질의 전자들의 각운동량만 더한다. 꽉 찬 부껍질은 합이 \(L = 0\), \(S = 0\)이라 무시한다.

먼저 전체 궤도 각운동량 \(L\)은 각 전자의 \(m_l\)을 더한 \(M_L\)의 최댓값으로 정해진다. \(L = 0, 1, 2, 3\)을 대문자 S, P, D, F로 쓰며, 전자 하나의 s, p, d, f와 같은 순서이다. 다음으로 전체 스핀 \(S\)는 각 전자의 \(m_s\)를 더한 \(M_S\)의 최댓값이다. \(2S + 1\)을 다중도라 하며 기호의 왼쪽 위에 쓴다. 다중도 1은 홑겹, 2는 두겹, 3은 세겹 상태이다. 마지막으로 전체 각운동량 \(J\)는 \(L\)과 \(S\)가 합쳐진 것으로 \(|L - S|, \dots, L + S\)의 값을 가지며 오른쪽 아래에 쓴다.

예를 들어 \({}^3P_0\)는 \(S = 1\)(세겹), \(L = 1\)(P), \(J = 0\)인 상태이다. 또 수소 바닥 상태 1s¹은 \(L = 0\), \(S = 1/2\), \(J = 1/2\)이라 \({}^2S_{1/2}\)이다.

3.3.3훈트 규칙으로 바닥 항 구하기

규칙 3.3.1 (훈트 규칙, 바닥 항)

첫째, \(S\)가 가장 큰 항이 가장 낮다. 둘째, \(S\)가 같으면 \(L\)이 가장 큰 항이 낮다. 셋째, 부껍질이 절반 미만이면 \(J\)가 가장 작은 것이, 절반을 넘으면 \(J\)가 가장 큰 것이 낮다.

바닥 항만 필요할 때는 다음 순서가 빠르다. 먼저 열린 부껍질의 오비탈을 \(m_l\)이 큰 것부터 늘어놓는다. 다음으로 전자를 모두 같은 스핀(위)으로 하나씩 채우고, 남으면 아래 스핀으로 다시 큰 \(m_l\)부터 채운다. 그러면 \(M_S\)의 합으로 \(S\)를, \(M_L\)의 합으로 \(L\)을 읽을 수 있고, 마지막으로 셋째 규칙으로 \(J\)를 정한다.

예제 3.3.1

탄소(2p²), 질소(2p³), 산소(2p⁴)의 바닥 항을 구하여라.

풀이. p 오비탈의 \(m_l\)은 +1, 0, −1이며, 그림 1처럼 채운다. 탄소는 +1과 0에 위 스핀이 하나씩 들어가 \(S = 1\), \(M_L = 1\)이므로 \(L = 1\)이다. 부껍질이 절반 미만이라 \(J = |L - S| = 0\)이고, 바닥 항은 \({}^3P_0\)이다. 질소는 세 오비탈에 위 스핀이 하나씩 들어가 \(S = 3/2\), \(M_L = 0\)이므로 \(L = 0\)이고 \(J = 3/2\)이다. 그래서 바닥 항은 \({}^4S_{3/2}\)이다. 산소는 위 스핀 셋에 더해 아래 스핀 하나가 +1에 들어가 \(S = 1\), \(M_L = 1\)이므로 \(L = 1\)이다. 절반을 넘으므로 \(J = L + S = 2\)이고, 바닥 항은 \({}^3P_2\)이다.

한편 p²에서 생기는 모든 항은 \({}^3P\), \({}^1D\), \({}^1S\)이며, 상태 수는 \(9 + 5 + 1 = 15\)로 앞의 15가지와 맞는다. 바닥 항이 \({}^3P\)라는 것은 탄소가 홀전자 둘을 가진 상태를 선호한다는 사실, 그리고 산소 분자의 상자성과도 이어진다.

\(J\)에 따른 갈라짐을 스핀-궤도 결합이라 하며, 가벼운 원자에서는 작고 무거운 원자에서 크다. 예를 들어 소듐 가로등의 노란빛은 589.0 nm와 589.6 nm 두 선으로 나뉘는데, 3p 들뜬 상태가 \({}^2P_{3/2}\)와 \({}^2P_{1/2}\)로 갈라졌기 때문이다. 화학2의 편광계(화학2 4.3절)가 쓰는 소듐 D선이 바로 이 빛이다.

흔한 오해항 기호의 \(S\)(전체 스핀)와 \(L = 0\)을 뜻하는 글자 S를 헷갈리기 쉽다. \({}^4S_{3/2}\)에서 왼쪽 위의 4는 다중도로 \(S = 3/2\)을 뜻하고, 가운데의 S는 \(L = 0\)을 뜻한다. 또 꽉 찬 부껍질 1s²나 2s²를 계산에 넣지 않는 것은 그 합이 언제나 \(L = 0\), \(S = 0\)이기 때문이다.
마무리

같은 전자 배치에서도 전자 반발과 스핀 때문에 에너지가 다른 항들이 생기며, 처음 질문의 탄소 상태들이 이것이다. 항 기호 \({}^{2S+1}L_J\)에서 \(L\)은 S, P, D, F로 쓰고 \(J\)는 \(|L - S|\)부터 \(L + S\)까지이다. 훈트 규칙에 따라 \(S\)가 크고, 다음으로 \(L\)이 크며, 절반 미만이면 \(J\)가 작고 넘으면 \(J\)가 큰 항이 바닥 항이어서 탄소 \({}^3P_0\), 질소 \({}^4S_{3/2}\), 산소 \({}^3P_2\)이다.

3.3.4연습문제

기본

  1. B(2p¹)와 F(2p⁵)의 바닥 항은?
    답

    B: ²P₁/₂(절반 미만, J 최소). F: ²P₃/₂(절반 초과, J 최대).

응용

  1. Ti(3d²)의 바닥 항을 구하시오(d 오비탈 mₗ = +2 … −2).
    답

    +2와 +1에 위 스핀: S = 1, L = 3(F), J = |3 − 1| = 2. ³F₂.

  2. Fe²⁺(3d⁶)의 바닥 항은?
    답

    위 스핀 다섯(+2…−2) + 아래 스핀 하나(+2). S = 2, M_L = 2, L = 2(D). 절반 초과 J = 4. ⁵D₄.

심화

  1. p² 배치에서 생기는 상태가 15개임을 세고, ³P, ¹D, ¹S의 축퇴도 합이 15임을 확인하시오.
    답

    오비탈-스핀 자리 6개에서 전자 2개를 고르는 경우 6C2 = 15. 항의 축퇴도 (2S+1)(2L+1): ³P 3×3 = 9, ¹D 1×5 = 5, ¹S 1. 합 15.
