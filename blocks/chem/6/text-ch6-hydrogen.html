수소 원자의 오비탈과 지름 분포

본문
이 절에서 배울 것
  • 수소 원자의 에너지 준위와 세 양자수(n, l, mₗ)의 뜻과 허용 범위를 안다.
  • 파동함수를 지름 부분과 각 부분으로 나누어 읽는다.
  • 지름 분포 함수 \(r^2R^2\)로 전자를 발견할 가능성이 가장 큰 거리를 구하고, 마디의 수를 센다.
  • 전자의 스핀과 넷째 양자수를 안다.
먼저 알아야 할 것
  • 슈뢰딩거 방정식, 확률 밀도, 기대값 (2.1절, 2.3절), 보어 모형 (1.1절).
  • s, p, d 오비탈의 모양 (공통5 원자 오비탈).

3.1.1정확히 풀리는 유일한 원자

수소 원자는 전자가 하나뿐이라 슈뢰딩거 방정식을 정확히 풀 수 있는 유일한 원자입니다. 그 해인 수소 오비탈(1s, 2p, 3d …)이 모든 원자의 전자 배치와 화학 결합을 설명하는 언어가 됩니다. 일반화학에서 오비탈의 모양을 배웠다면, 이 절은 그 모양이 어디서 나오고 "전자가 어디쯤 있는가"를 수로 어떻게 말하는지 다룹니다.

3.1.2에너지와 양자수

핵(전하 +e)과 전자 사이의 위치 에너지 \(V = -e^2/(4\pi\varepsilon_0r)\)를 3차원 슈뢰딩거 방정식에 넣고 구면 좌표(r, θ, φ)로 풀면, 파동함수가 \(\psi_{nlm}(r,\theta,\phi) = R_{nl}(r)Y_{lm}(\theta,\phi)\)로 나뉘고 에너지는 다음과 같습니다.

결과 3.1.1 (수소 원자의 에너지)

\[ E_n = -\frac{m_ee^4}{8\varepsilon_0^2h^2}\cdot\frac{1}{n^2} = -\frac{2.18\times10^{-18}\ \mathrm J}{n^2} = -\frac{13.6\ \mathrm{eV}}{n^2} \]

보어 모형과 같은 에너지입니다. 다른 점은 상태를 세 양자수로 지정한다는 것입니다.

주양자수 n = 1, 2, 3, …: 에너지와 오비탈의 크기를 정한다.

각운동량 양자수 l = 0, 1, …, n − 1: 오비탈의 모양(s, p, d, f)과 각운동량의 크기 \(\sqrt{l(l+1)}\hbar\)를 정한다.

자기 양자수 mₗ = −l, …, +l: 각운동량의 z 성분 \(m_l\hbar\), 곧 오비탈의 방향을 정한다.

수소에서는 에너지가 n에만 의존하므로 2s와 2p는 같은 에너지입니다. 한 n에는 \(n^2\)개의 오비탈이 있습니다. 전자가 여럿인 원자에서는 이 축퇴가 풀려 2s가 2p보다 낮아집니다(3.2절).

3.1.3지름 분포 함수

"1s 전자는 핵에서 얼마나 떨어져 있을까?"에 답하려면 확률 밀도 |ψ|²만 보면 안 됩니다. 1s의 |ψ|²는 핵(r = 0)에서 가장 크지만, 반지름 r인 껍질의 부피는 \(4\pi r^2dr\)로 r이 클수록 커지기 때문입니다. 두 효과를 곱한 것이 지름 분포 함수입니다.

정의 3.1.2 (지름 분포 함수)

\(P(r)\,dr = r^2R_{nl}^2(r)\,dr\)은 전자를 핵에서 r과 r + dr 사이의 얇은 껍질에서 발견할 확률이다.

예제 3.1.3

수소 1s 오비탈 \(R_{10} = 2a_0^{-3/2}e^{-r/a_0}\)에서 전자를 발견할 가능성이 가장 큰 거리를 구하여라. \(a_0 = 52.9\) pm(보어 반지름)이다.

풀이. \(P(r) \propto r^2e^{-2r/a_0}\). 미분해 0으로 두면 \(2re^{-2r/a_0} - \frac{2}{a_0}r^2e^{-2r/a_0} = 0\), 곧 \(r = a_0 = 52.9\) pm입니다. 보어 모형의 첫 궤도 반지름과 같은 값이 "가장 가능성 큰 거리"로 다시 나왔습니다. 다만 전자는 그 거리에만 있지 않고 넓게 퍼져 있어, 반지름 a₀ 안에서 발견될 확률은 32%에 불과합니다. 평균 거리 ⟨r⟩은 1.5a₀입니다.

3.1.4마디

오비탈에는 전자가 발견될 확률이 0인 마디가 있습니다. 상자 속 입자처럼 마디가 많을수록 에너지가 높습니다.

  • 지름 마디(구 모양): n − l − 1개. 2s는 1개(r = 2a₀), 3s는 2개, 2p는 0개.
  • 각 마디(평면이나 원뿔): l개. p는 평면 1개, d는 2개.
  • 전체 마디: n − 1개.

2s의 지름 분포는 안쪽에 작은 봉우리, 바깥(r ≈ 5.2a₀)에 큰 봉우리가 있습니다. 2p는 봉우리 하나(r = 4a₀)입니다. 2s의 안쪽 봉우리 덕분에 2s 전자는 핵 가까이 "침투"해, 다전자 원자에서 2s가 2p보다 핵의 끌림을 더 많이 느낍니다. 이것이 다전자 원자의 오비탈 에너지 순서(s < p < d)의 원인입니다.

3.1.5스핀

슈뢰딩거 방정식에서 나오지 않는 넷째 성질이 전자의 스핀입니다. 슈테른-게를라흐 실험에서 은 원자 빔이 자기장에서 두 갈래로 나뉜 것이 그 증거입니다. 전자는 스핀 양자수 s = 1/2을 가지며, z 성분은 \(m_s = +\tfrac12\)(위, α) 또는 \(-\tfrac12\)(아래, β) 두 가지입니다. 그래서 한 오비탈에 전자가 두 개까지 들어가고(3.2절의 파울리 원리), NMR이 핵의 스핀을 이용하듯 ESR은 전자 스핀을 이용합니다.

흔한 오해"1s 전자는 핵에 가장 많이 있다"와 "1s 전자는 a₀ 거리에 가장 많이 있다"는 둘 다 맞지만 묻는 것이 다릅니다. 앞의 것은 단위 부피당 확률(|ψ|²), 뒤의 것은 거리당 확률(r²R²)입니다. 또 오비탈 그림의 경계면은 "전자가 그 안에 갇혀 있다"가 아니라 "그 안에서 발견될 확률이 90%"쯤인 면입니다.
요약
  1. 수소 에너지 \(E_n = -13.6\ \mathrm{eV}/n^2\), 상태는 n, l, mₗ(그리고 mₛ)로 지정한다.
  2. 지름 분포 함수 \(r^2R^2\)는 거리별 발견 확률이다. 1s의 최대는 a₀ = 52.9 pm.
  3. 지름 마디 n − l − 1, 각 마디 l, 전체 n − 1. 침투가 큰 s가 다전자 원자에서 낮아진다.
  4. 전자 스핀은 ±½ 두 상태.

3.1.6연습문제

기본

  1. n = 3일 때 가능한 l, mₗ 조합과 오비탈 수를 쓰시오.
    답

    l = 0(1개), 1(3개), 2(5개), 모두 9개(= n²).

  2. 4d와 5f의 지름 마디와 각 마디 수는?
    답

    4d: 지름 1, 각 2. 5f: 지름 1, 각 3.

응용

  1. He⁺(Z = 2)의 1s 오비탈에서 가장 가능성 큰 거리와 바닥 상태 에너지는? (수소꼴 원자에서 \(E_n = -13.6Z^2/n^2\) eV, 거리는 a₀/Z로 줄어듦)
    답

    r = a₀/2 = 26.5 pm, E₁ = −54.4 eV.

심화

  1. 1s 전자가 반지름 a₀ 안에 있을 확률이 \(1 - 5e^{-2}\)임을 적분으로 보이시오.
    힌트

    \(\int_0^{a_0}4a_0^{-3}r^2e^{-2r/a_0}dr\)에서 x = 2r/a₀로 바꾸면 \(\tfrac12\int_0^2x^2e^{-x}dx\).

    답

    \(\int_0^2x^2e^{-x}dx = 2 - 10e^{-2}\)이므로 확률 = \(1 - 5e^{-2} = 0.323\).
