섞인 액체를 끓이면 증기는 어떤 조성인가?

탐구 · 이성분계 끓는점 도표, 지렛대 규칙, 공비 혼합물

목표

벤젠-톨루엔 혼합물의 온도-조성(T-x-y) 도표를 라울 법칙으로 그리고, 두 상이 공존하는 영역에서 지렛대 규칙으로 액체와 기체의 양을 구합니다. 두 액체의 상호작용이 이상에서 벗어나면 공비 혼합물이 생기는 것도 봅니다. 성취기준 [화학10-04-03], [화학10-04-02].

준비

라울 법칙: 이상 용액에서 성분 i의 부분 압력은 \(p_i = x_iP_i^*\)입니다. \(x_i\)는 액체 속 몰분율, \(P_i^*\)는 순수한 i의 증기압입니다.

끓는점(거품점) 곡선: 전체 압력 \(x_1P_1^*(T) + x_2P_2^*(T)\)이 바깥 압력 P와 같아지는 온도. 파란 선입니다.

이슬점 곡선: 그 온도에서 처음 생긴 증기의 조성 \(y_1 = x_1P_1^*/P\). 빨간 선입니다. 휘발성이 큰 벤젠이 증기에 더 많으므로 빨간 선이 오른쪽에 있습니다.

지렛대 규칙: 전체 조성 z인 계가 두 선 사이 온도에 있으면 액체(조성 x)와 기체(조성 y)로 나뉘고, 기체의 몰 비율은 \((z - x)/(y - x)\)입니다.

증기압은 안트완(Antoine) 식 \(\log_{10}P^*(\mathrm{mmHg}) = A - B/(T + C)\)로 계산합니다(벤젠 A 6.90565, B 1211.033, C 220.79; 톨루엔 A 6.95464, B 1344.8, C 219.482; T는 °C).

Margules 매개변수 A: 비이상 정도. 활동도 계수 \(\gamma_1 = e^{A x_2^2}\), \(\gamma_2 = e^{A x_1^2}\)로 \(p_i = x_i\gamma_iP_i^*\)이 됩니다. A > 0은 두 분자가 서로를 싫어하는 경우입니다. 실제 벤젠-톨루엔은 거의 이상 용액이므로 A를 바꾸는 것은 가상의 계입니다.

질문

벤젠 40% 혼합물을 천천히 가열하면 몇 °C에서 끓기 시작하고, 그때 처음 나오는 증기는 벤젠이 몇 %일까요? 이 증기를 모아 다시 끓이면 어떻게 될까요?

복원

  1. 760 mmHg, A = 0에서 순수 벤젠과 순수 톨루엔의 끓는점을 기록한다.
  2. z = 0.40에서 끓기 시작하는 온도를 읽고, T를 그 온도에 맞춰 기체 조성 y를 읽는다.
  3. T를 95.0 °C와 98.0 °C로 두고 상태, 액체·기체 조성, 지렛대 규칙의 비율을 기록한다.
  4. 압력을 300 mmHg로 낮춰 두 끓는점이 어떻게 바뀌는지 본다(감압 증류).
  5. 압력을 760으로 되돌리고 A를 1.5로 올려 공비점이 생기는지 본다. A를 −1.0으로도 해 본다.

설명

760 mmHg에서 순수 벤젠은 80.1 °C, 순수 톨루엔은 110.6 °C에서 끓습니다. 벤젠 40% 혼합물은 95.1 °C에서 끓기 시작하고, 그 바로 위인 95.5 °C에서 처음 나오는 증기는 벤젠이 약 61%입니다. 휘발성이 큰 벤젠이 증기에 더 많이 들어가므로, 이 증기를 모아 다시 끓이면 벤젠이 더 진해집니다. 이것을 되풀이하는 것이 분별 증류입니다.

처음 값 T = 95.0 °C는 끓는점(95.1 °C) 바로 아래라 모두 액체입니다. 98.0 °C로 올리면 두 상이 공존해 액체는 x = 0.313, 기체는 y = 0.527이 되고, 지렛대 규칙으로 기체가 40.6%, 액체가 59.4%입니다. 전체 조성은 z = 0.40 그대로이지만 액체는 톨루엔 쪽으로, 기체는 벤젠 쪽으로 갈라집니다. 혼합물은 101.3 °C 근처에서 모두 증발합니다.

300 mmHg로 낮추면 두 끓는점이 52.7 °C, 80.9 °C로 내려가고 z = 0.40은 66.2 °C에서 끓기 시작합니다. 열에 약한 물질을 낮은 온도에서 증류하는 감압 증류의 원리입니다.

A = 1.5(두 분자가 서로를 싫어함)로 하면 증기압이 라울 법칙보다 커져 x = y ≈ 0.82, 78.5 °C에 순수 벤젠보다 낮은 최저 공비점이 생깁니다. 공비점에서는 증기와 액체의 조성이 같아 증류로 더 진하게 만들 수 없습니다. A = −1.0(서로 끌어당김)이면 증기압이 낮아져 끓는점이 오르고, 이 계에서는 x ≈ 0.07, 110.8 °C에 순수 톨루엔보다 조금 높은 최고 공비점이 생깁니다.

연결

분별 증류탑은 "끓여서 증기를 모아 다시 끓이기"를 탑 안의 여러 단에서 되풀이합니다. 크로마토그래피의 단 이론([화학8-04-01])이 이 증류 단의 생각을 빌려 온 것입니다. 상규칙 \(F = C - P + 2\)에서 압력을 고정하면 \(F = C - P + 1\)이고, 이성분 두 상 영역에서는 F = 1이라 온도를 정하면 두 상의 조성이 모두 정해집니다.

적용

에탄올-물은 최저 공비점(약 95.6 질량% 에탄올, 78.2 °C)을 가집니다. 이 장치의 A > 0 결과를 참고해, 보통 증류로는 순수 에탄올을 얻을 수 없는 이유를 설명해 보세요.
