1.2.1엔탈피

대부분의 화학 반응은 대기압(일정 압력)에서 일어납니다. 이때 계가 받은 열 q_p에는 부피 변화의 일이 섞여 있어 ΔU와 다릅니다. 그래서 새 상태 함수를 정의합니다.

엔탈피: H = U + pV. 일정 압력에서 부피 변화의 일 외에 다른 일이 없으면 ΔH = q_p.

증명: 일정 압력에서 ΔU = q_p − pΔV이므로 q_p = ΔU + pΔV = Δ(U + pV) = ΔH. 열량계로 잰 일정 압력의 열이 곧 엔탈피 변화입니다. 일정 부피 열량계(봄베)에서는 q_V = ΔU를 재고, ΔH = ΔU + Δ(pV) ≈ ΔU + Δn_gas RT로 바꿉니다.

열용량: C_V = (∂U/∂T)_V, C_p = (∂H/∂T)_p.

이상 기체는 H = U + nRT이므로 C_p − C_V = nR입니다. 일정 압력에서 가열하면 팽창하는 일에 에너지 일부가 쓰여 같은 온도 상승에 열이 더 필요하기 때문입니다. 단원자 기체 C_V,m = 3/2 R, C_p,m = 5/2 R.

1.2.2헤스 법칙과 생성 엔탈피

표준 생성 엔탈피 ΔfH°: 1 bar에서 가장 안정한 형태의 원소들로부터 화합물 1 mol을 만들 때의 엔탈피 변화. 원소의 ΔfH° = 0.

H가 상태 함수라 반응 엔탈피는 경로와 무관하므로(헤스 법칙)

\[ \Delta_rH^\circ = \sum\nu\,\Delta_fH^\circ(\text{생성물}) - \sum\nu\,\Delta_fH^\circ(\text{반응물}) \]

예: CH₄ + 2O₂ → CO₂ + 2H₂O(g): (−393.5) + 2(−241.8) − (−74.8) = −802.3 kJ/mol.

1.2.3키르히호프 법칙

구하려는 것: 298 K의 표 값으로 다른 온도의 반응 엔탈피. 반응물을 T₁에서 T₂로 데워 반응시키는 길과, T₁에서 반응시킨 뒤 생성물을 T₂로 데우는 길은 처음과 끝이 같으므로 엔탈피 변화가 같습니다.

식 1.2.1 (키르히호프 법칙)

\[ \Delta_rH^\circ(T_2) = \Delta_rH^\circ(T_1) + \int_{T_1}^{T_2}\Delta_rC_p^\circ\,dT, \qquad \Delta_rC_p^\circ = \sum\nu C_p(\text{생성물}) - \sum\nu C_p(\text{반응물}) \]

예제 1.2.1

N₂ + 3H₂ → 2NH₃의 ΔrH°(298.15 K) = −92.22 kJ/mol이다. C_p,m(J/(K·mol))이 NH₃ 35.06, N₂ 29.12, H₂ 28.82로 온도에 무관하다고 보고 500 K의 반응 엔탈피를 구하여라.

풀이. ΔrC_p = 2(35.06) − 29.12 − 3(28.82) = −45.46 J/(K·mol). ΔrH°(500) = −92.22 + (−45.46 × 201.85)/1000 = −101.4 kJ/mol. 기체 분자 수가 줄어드는 반응(4 → 2)이라 생성물의 열용량 합이 작고, 온도가 오를수록 더 발열적으로 됩니다. 하버 공정(약 700 K)의 열 설계에 쓰는 계산입니다. 넓은 온도 범위에서는 C_p = a + bT + c/T²처럼 온도에 따라 바뀌는 식을 적분합니다.

흔한 오해"ΔH와 ΔU는 늘 크게 다르다"가 아닙니다. 고체와 액체만의 반응은 부피 변화가 작아 거의 같고, 기체 몰수가 바뀌는 반응에서만 Δn_gas RT(298 K에서 몰당 2.48 kJ)만큼 다릅니다. 또 키르히호프 법칙은 그 온도 구간에서 상변화가 없을 때만 그대로 쓸 수 있습니다. 물이 끓는 100 °C를 지나면 증발 엔탈피를 더해야 합니다.
요약
  1. H = U + pV, 일정 압력의 열 q_p = ΔH. 봄베 열량계는 ΔU, ΔH = ΔU + Δn_gas RT.
  2. 이상 기체 C_p − C_V = nR.
  3. 헤스 법칙: ΔrH° = Σν ΔfH°(생성물) − Σν ΔfH°(반응물).
  4. 키르히호프: ΔrH°(T₂) = ΔrH°(T₁) + ∫ΔrC_p dT. 암모니아 합성 500 K에서 −101.4 kJ/mol.

1.2.4연습문제

기본

  1. 벤조산 연소(C₆H₅COOH(s) + 15/2 O₂ → 7CO₂ + 3H₂O(l))에서 봄베로 잰 ΔU가 −3226 kJ/mol이다. 298 K의 ΔH는?
    답

    Δn_gas = 7 − 7.5 = −0.5. ΔH = −3226 + (−0.5)(8.314 × 298.15)/1000 = −3227 kJ/mol.

응용

  1. H₂(g) + ½O₂(g) → H₂O(g)의 ΔrH°(298 K) = −241.82 kJ/mol이다. C_p,m: H₂O(g) 33.58, H₂ 28.82, O₂ 29.36 J/(K·mol)로 1000 K의 값을 구하시오.
    답

    ΔrC_p = 33.58 − 28.82 − 14.68 = −9.92 J/(K·mol). ΔrH°(1000) = −241.82 − 9.92 × 701.85/1000 = −248.8 kJ/mol.

심화

  1. 이원자 이상 기체 1 mol을 300 K에서 400 K로 일정 압력과 일정 부피에서 각각 가열할 때 필요한 열을 구하고 차이를 설명하시오(C_V,m = 5/2 R).
    답

    일정 부피: q = C_VΔT = 2.5 × 8.314 × 100 = 2079 J. 일정 압력: q = C_pΔT = 3.5 × 8.314 × 100 = 2910 J. 차이 831 J = RΔT는 일정 압력에서 팽창하며 한 일이다.
