자유 에너지, 기본 방정식, 맥스웰 관계식

본문
이 절에서 배울 것
  • 헬름홀츠 에너지 A와 깁스 에너지 G를 정의하고, 일정 T·V 또는 T·p에서 자발성의 기준이 됨을 보인다.
  • 네 기본 방정식(dU, dH, dA, dG)을 쓴다.
  • 교차 미분의 대칭으로 맥스웰 관계식을 유도한다.
  • 맥스웰 관계식으로 측정하기 어려운 양(엔트로피의 압력 의존성, 내부 압력)을 측정 가능한 양으로 바꾼다.
먼저 알아야 할 것
  • 제1·2법칙 (1.1절, 2.1절), 편미분과 완전 미분 (공통2).

3.1.1계만 보고 자발성을 판단하기

2.1절의 기준 ΔS_전체 ≥ 0은 주위까지 따져야 해서 불편합니다. 일정 온도·압력이라는 실험실 조건에서 계의 양만으로 판단할 수 있게 새 상태 함수를 만듭니다.

헬름홀츠 에너지: A = U − TS. 일정 T, V에서 자발 과정은 dA ≤ 0.

깁스 에너지: G = H − TS. 일정 T, p에서 자발 과정은 dG ≤ 0.

이유: 일정 T, p에서 계가 받은 열 dq = dH이고, 주위의 엔트로피 변화는 −dH/T입니다. ΔS_전체 = dS − dH/T ≥ 0에 −T를 곱하면 dH − TdS ≤ 0, 곧 dG ≤ 0. 깁스 에너지 감소는 "주위까지 포함한 엔트로피 증가"를 계의 언어로 바꾼 것입니다. 또 −ΔG는 그 과정에서 얻을 수 있는 최대의 비팽창 일(전기 일 등)입니다(전지의 ΔG = −nFE).

3.1.2네 기본 방정식

가역 과정에서 dq = TdS, dw = −pdV이므로 dU = TdS − pdV. 정의를 미분하면 나머지가 나옵니다.

식 3.1.1 (닫힌 계의 기본 방정식)

\[ dU = TdS - pdV,\quad dH = TdS + Vdp,\quad dA = -SdT - pdV,\quad dG = -SdT + Vdp \]

각 함수의 "자연 변수"가 보입니다. 예를 들어 G는 T와 p의 함수이고, \((\partial G/\partial T)_p = -S\), \((\partial G/\partial p)_T = V\)입니다.

3.1.3맥스웰 관계식

구하려는 것: 실험으로 재기 어려운 엔트로피의 변화를 재기 쉬운 p, V, T의 관계로 바꾸기.

상태 함수의 완전 미분 dz = M dx + N dy에서는 교차 미분이 같습니다: \((\partial M/\partial y)_x = (\partial N/\partial x)_y\). 이것을 네 기본 방정식에 적용하면

식 3.1.2 (맥스웰 관계식)

\[ \left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial p}{\partial S}\right)_V,\quad \left(\frac{\partial T}{\partial p}\right)_S = \left(\frac{\partial V}{\partial S}\right)_p,\quad \left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V,\quad \left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p \]

뒤의 두 식이 특히 쓸모 있습니다. 엔트로피가 부피·압력에 따라 어떻게 변하는지를, 상태 방정식(p-V-T 관계)이나 열팽창 계수만으로 알 수 있습니다.

예제 3.1.1

물(V_m = 18.07 cm³/mol, 열팽창 계수 α = 2.07×10⁻⁴ K⁻¹)을 25 °C에서 1 bar에서 100 bar로 압축할 때 몰 엔트로피 변화를 구하여라.

풀이. \((\partial S/\partial p)_T = -(\partial V/\partial T)_p = -\alpha V\). = −2.07×10⁻⁴ × 18.07×10⁻⁶ = −3.74×10⁻⁹ J/(K·mol·Pa). Δp = 99×10⁵ Pa이므로 ΔS = −0.037 J/(K·mol). 액체는 압축해도 엔트로피가 거의 변하지 않습니다(기체라면 −R ln 100 = −38 J/(K·mol)).

3.1.4내부 압력

dU = TdS − pdV를 등온에서 dV로 나누고 맥스웰 관계식을 쓰면 열역학적 상태 방정식을 얻습니다.

\[ \left(\frac{\partial U}{\partial V}\right)_T = T\left(\frac{\partial p}{\partial T}\right)_V - p \]

이상 기체(p = nRT/V)는 오른쪽이 0이라, U가 부피와 무관하다는 1.1절의 사실이 증명됩니다. 반데르발스 기체 \((p + an^2/V^2)(V - nb) = nRT\)에서는 \((\partial U/\partial V)_T = an^2/V^2\)로, 분자 사이 인력(a) 때문에 팽창하면 내부에너지가 늘어납니다(N₂, V_m = 1 L에서 1.37 bar에 해당).

흔한 오해"ΔG < 0이면 반응이 빨리 일어난다"가 아닙니다. ΔG는 방향(평형까지 갈 수 있는가)만 말하고 빠르기는 말하지 않습니다(7단원). 또 맥스웰 관계식은 외우기보다 기본 방정식에서 매번 교차 미분으로 만드는 것이 실수가 적습니다. 그리고 G의 자발성 기준은 일정 T와 p일 때만 성립합니다.
요약
  1. A = U − TS(일정 T, V), G = H − TS(일정 T, p). 자발 과정에서 감소. −ΔG = 최대 비팽창 일.
  2. dU = TdS − pdV, dH = TdS + Vdp, dA = −SdT − pdV, dG = −SdT + Vdp.
  3. 맥스웰: (∂S/∂V)_T = (∂p/∂T)_V, (∂S/∂p)_T = −(∂V/∂T)_p.
  4. (∂U/∂V)_T = T(∂p/∂T)_V − p: 이상 기체 0, 반데르발스 an²/V².

3.1.5연습문제

기본

  1. dA = −SdT − pdV에서 맥스웰 관계식 하나를 유도하시오.
    답

    M = −S, N = −p이므로 (∂(−S)/∂V)_T = (∂(−p)/∂T)_V, 곧 (∂S/∂V)_T = (∂p/∂T)_V.

응용

  1. 이상 기체에서 (∂S/∂V)_T = nR/V를 맥스웰 관계식으로 보이고, 등온 팽창의 ΔS = nR ln(V₂/V₁)을 유도하시오.
    답

    (∂S/∂V)_T = (∂p/∂T)_V = ∂(nRT/V)/∂T = nR/V. V₁에서 V₂까지 적분하면 ΔS = nR ln(V₂/V₁)(2.1절과 같음).

심화

  1. 반데르발스 기체의 (∂S/∂V)_T를 구하고, 같은 부피 변화에서 이상 기체보다 엔트로피 변화가 큰지 작은지 판단하시오.
    답

    p = nRT/(V − nb) − an²/V²이므로 (∂p/∂T)_V = nR/(V − nb). ΔS = nR ln[(V₂ − nb)/(V₁ − nb)]. 분자 자체 부피만큼 쓸 수 있는 공간이 작아, 같은 V₂/V₁에서 비율 (V₂ − nb)/(V₁ − nb)가 더 커서 엔트로피 변화가 이상 기체보다 크다.
