합성과 분석을 묶어 구조를 제안하는 보고서

본문
이 절에서 배울 것
  • 무기 합성 보고서의 구성과 각 부분에 들어갈 내용을 안다.
  • 수득률, 분광, 자기, 전도도, 원소 분석 자료를 한 표로 정리한다.
  • 여러 근거가 하나의 구조로 모이는지 논증하고, 오차와 한계를 쓴다.
먼저 알아야 할 것
  • 이 과목의 1~3단원, 실험 노트와 보고서 (화학7 5.1절), 분석 보고서 (화학3 6.1절).

4.1.1보고서의 뼈대

  1. 요약: 무엇을 만들었고(화학식), 수득률은 얼마이며, 어떤 근거로 구조를 정했는지 3~4문장.
  2. 서론: 화합물의 의미(예: 치환 불활성, 이성질체), 합성 전략.
  3. 실험: 시약의 양(g, mmol), 조건, 관찰(색 변화, 기체 발생). 다른 사람이 그대로 따라 할 수 있게, 과거형 수동태 또는 평서문으로.
  4. 결과: 수득량, 수득률, 겉모습, 그리고 분석 자료 표.
  5. 논의: 자료가 제안한 구조와 맞는지, 다른 후보는 왜 아닌지, 오차의 원인.
  6. 결론과 참고문헌.

4.1.2자료 표: 근거를 한눈에

[Co(NH₃)₅Cl]Cl₂를 예로, 각 측정이 무엇을 보여 주는지 열을 하나 더 둡니다.

4.1.3논의: 다른 후보를 지우기

좋은 논의는 "맞는다"보다 "다른 것이 아니다"를 보입니다. 후보를 나열하고 근거로 하나씩 지웁니다.

  • [Co(NH₃)₆]Cl₃: 3:1 전해질(전도도 약 400)이고 N이 31.4%여야 함 → 맞지 않음.
  • [Co(NH₃)₅(H₂O)]Cl₃: 3:1 전해질, N 26.1% → 전도도로 지움.
  • [Co(NH₃)₄Cl₂]Cl: 1:1 전해질(약 120), N 24.0% → 지움.
  • Co(II) 착물: 상자성이어야 함 → 반자성이므로 지움.

전도도는 "몇 개의 이온으로 나뉘는가"를, 원소 분석은 "몇 개의 NH₃인가"를, 자기성은 "산화수와 스핀"을 따로 알려 주므로, 셋이 함께 한 구조로 모일 때 결론이 단단해집니다.

4.1.4오차와 한계 쓰기

  • 수치마다 불확도나 반복 측정 범위를 적습니다(전도도 260 ± 8).
  • 수득률 손실의 원인을 구체적으로(여과액의 색으로 판단한 용해 손실).
  • 측정이 구별하지 못하는 것을 솔직히 씁니다. 예: 전도도는 2:1 전해질임을 보이지만, 어느 Cl이 배위했는지 직접 보이지는 않는다(단결정 X선 구조가 가장 직접적인 근거).
흔한 오해"자료를 많이 붙이면 좋은 보고서"가 아닙니다. 각 자료가 구조의 어느 부분을 뒷받침하는지 연결하지 않으면 근거가 되지 못합니다. 또 기대값과 다른 결과를 감추거나 "실험 오차"라고만 쓰는 것은 좋지 않습니다. 차이의 크기와 가능한 원인을 구체적으로 씁니다.
요약
  1. 요약-서론-실험-결과-논의-결론, 실험은 재현할 수 있게.
  2. 자료 표에 "무엇을 뒷받침하나" 열을 둔다.
  3. 후보 구조를 근거로 하나씩 지운다. 전도도·원소 분석·자기성이 서로 다른 정보를 준다.
  4. 불확도와 측정의 한계를 구체적으로.

4.1.5연습문제

기본

  1. [Co(NH₃)₄Cl₂]Cl의 N 함량 기대값은? (M = 233.4 g/mol)
    답

    4 × 14.007/233.4 = 24.0%.

응용

  1. 합성한 시료의 몰 전도도가 410 S·cm²/mol, N 31.2%, 반자성이다. 어떤 화합물로 제안하겠는가?
    답

    [Co(NH₃)₆]Cl₃. 3:1 전해질, N 기대값 31.4%(6 × 14.007/267.5), 저스핀 Co(III).

심화

  1. 원소 분석 N이 26.9%(기대 27.96%)로 나왔다. 가능한 원인 두 가지와, 각각을 확인할 측정을 쓰시오.
    답

    ① 물이 남음(무게가 늘어 N 비율이 줄어듦): 더 말린 뒤 다시 분석하거나 열무게 분석. ② 아쿠아 착물 [Co(NH₃)₅(H₂O)]Cl₃(N 26.1%)가 섞임: 전도도(3:1 쪽으로 커짐)와 UV-Vis 띠 위치로 확인.
