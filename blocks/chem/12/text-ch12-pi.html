아미노산의 쯔비터이온과 등전점

본문
이 절에서 배울 것
  • 아미노산이 물과 고체에서 쯔비터이온으로 있는 이유를 pKa로 설명한다.
  • pH에 따라 우세한 화학종과 알짜 전하를 정한다.
  • 곁사슬이 이온화하는 아미노산을 포함해 등전점을 계산한다.
  • 등전점으로 전기 영동과 이온 교환 분리를 예측한다.
먼저 알아야 할 것
  • 다양성자산과 분율 (화학1 3.2절), pKa와 산도 (화학2 2.3절).

2.1.1쯔비터이온

α-아미노산은 같은 탄소(α 탄소)에 아미노기와 카복실기가 붙어 있습니다. 카복실기의 pKa(약 2)는 아미노기 짝산(−NH₃⁺)의 pKa(약 9~10)보다 훨씬 작으므로, 중성 근처에서는 카복실기가 양성자를 내놓고 아미노기가 받아 H₃N⁺−CHR−COO⁻가 됩니다. 한 분자 안에 양전하와 음전하가 함께 있는 이 형태를 쯔비터이온이라 합니다.

그래서 아미노산은 분자량에 비해 녹는점이 매우 높고(글라이신은 약 233 °C에서 분해) 물에 잘 녹으며 유기 용매에 잘 녹지 않습니다. 이온 결정처럼 행동하기 때문입니다.

2.1.2pH와 화학종

글라이신(pKa₁ = 2.34, pKa₂ = 9.60)을 예로 듭니다. pH가 pKa보다 낮으면 그 기는 양성자를 가진 쪽, 높으면 잃은 쪽이 우세합니다(헨더슨-하셀바흐 식).

  • pH < 2.34: H₃N⁺−CH₂−COOH, 전하 +1
  • 2.34 < pH < 9.60: H₃N⁺−CH₂−COO⁻, 전하 0
  • pH > 9.60: H₂N−CH₂−COO⁻, 전하 −1

2.1.3등전점

등전점 pI: 아미노산의 평균 알짜 전하가 0이 되는 pH. 전기장에서 움직이지 않는다.

구하려는 것: 전하 0 형태가 가장 많고 +1과 −1 형태의 양이 같아지는 pH. 이것은 전하 0 형태를 사이에 둔 두 pKa의 평균입니다.

식 2.1.1

\[ \mathrm{pI} = \tfrac12(\mathrm{p}K_a + \mathrm{p}K_a'), \quad \text{두 pKa는 전하 0 형태가 생기고 없어지는 단계} \]

요령은 낮은 pH(모두 양성자가 붙은 상태)에서 출발해 pKa를 작은 것부터 하나씩 지날 때마다 전하를 1씩 빼는 것입니다.

예제 2.1.1

글라이신, 아스파트산(1.88, 3.65(곁사슬 COOH), 9.60), 라이신(2.18, 8.95, 10.53(곁사슬 NH₃⁺))의 pI는?

글라이신: +1 → (2.34) → 0 → (9.60) → −1. pI = (2.34 + 9.60)/2 = 5.97.

아스파트산: 낮은 pH에서 +1(NH₃⁺, COOH 둘 다 중성). +1 → (1.88) → 0 → (3.65) → −1 → (9.60) → −2. pI = (1.88 + 3.65)/2 = 2.77.

라이신: 낮은 pH에서 +2(NH₃⁺ 둘). +2 → (2.18) → +1 → (8.95) → 0 → (10.53) → −1. pI = (8.95 + 10.53)/2 = 9.74.

산성 곁사슬(Asp, Glu)은 pI가 낮고, 염기성 곁사슬(Lys, Arg, His)은 pI가 높습니다. 히스티딘의 이미다졸(pKa 6.00)은 생리 pH 근처에서 양성자를 주고받을 수 있어 효소 활성 부위에 자주 나옵니다(4단원).

2.1.4분리에 쓰기

  • 전기 영동: pH < pI이면 알짜 전하가 양이라 음극으로, pH > pI이면 양극으로 이동한다. pH 6.0 완충액에서 Asp(pI 2.77)는 양극으로, Lys(9.74)는 음극으로, Gly(5.97)는 거의 움직이지 않는다.
  • 등전점 전기 영동: pH 기울기가 있는 겔에서 단백질이 자기 pI 위치에 멈춘다.
  • 이온 교환 크로마토그래피: 양이온 교환 수지는 pH < pI인(양전하) 아미노산을 붙잡는다.
흔한 오해"pI에서는 아미노산이 전하가 없는 H₂N−CHR−COOH 형태로 있다"가 아닙니다. pI에서 주된 형태는 전하 +1과 −1을 함께 가진 쯔비터이온이고, 알짜 전하가 0일 뿐입니다. 또 아스파트산의 pI를 세 pKa의 평균으로 내는 실수가 흔합니다. 전하 0 형태 양옆의 두 pKa만 씁니다.
요약
  1. 중성 근처에서 아미노산은 쯔비터이온 H₃N⁺−CHR−COO⁻.
  2. pKa를 작은 것부터 지날 때마다 전하가 1씩 준다.
  3. pI = 전하 0 형태 양옆 두 pKa의 평균. Gly 5.97, Asp 2.77, Lys 9.74.
  4. pH < pI → 양전하(음극으로), pH > pI → 음전하(양극으로).

2.1.5연습문제

기본

  1. 글루탐산(2.19, 4.25(곁사슬), 9.67)의 pI는?
    답

    (2.19 + 4.25)/2 = 3.22.

응용

  1. 히스티딘(1.82, 6.00(곁사슬 이미다졸륨), 9.17)의 pI와, pH 7.4에서 알짜 전하의 부호는?
    답

    낮은 pH에서 +2, (1.82) +1, (6.00) 0, (9.17) −1. pI = (6.00 + 9.17)/2 = 7.59. pH 7.4 < pI이므로 알짜 전하는 아주 작은 양수.

심화

  1. 글라이신의 pH 5.97에서 양이온 형태와 음이온 형태의 비율을 각각 구하시오. pI에서 쯔비터이온이 몇 %인가?
    답

    [H₂Gly⁺]/[HGly] = 10^(2.34 − 5.97) = 2.3×10⁻⁴, [Gly⁻]/[HGly] = 10^(5.97 − 9.60) = 2.3×10⁻⁴. 두 이온 형태가 각각 0.023%로 같고, 쯔비터이온이 약 99.95%다.
