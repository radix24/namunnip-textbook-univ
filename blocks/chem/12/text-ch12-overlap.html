조각 겹치기로 서열 정하기

본문
이 절에서 배울 것
  • 트립신과 키모트립신이 자르는 자리를 안다.
  • 두 효소의 조각 묶음을 겹쳐 전체 서열을 이어 붙인다.
  • N 말단 분석과 조성 자료로 결과를 점검한다.
먼저 알아야 할 것
  • Edman 분해와 조각 겹치기 (3.2절).

3.5.1효소가 자르는 자리

시약자르는 자리예외
트립신Lys, Arg의 C 쪽(뒤)다음 잔기가 Pro면 자르지 않음
키모트립신Phe, Tyr, Trp의 C 쪽다음 잔기가 Pro면 자르지 않음
브로민화 사이안(BrCN)Met의 C 쪽

Edman 분해는 한 번에 30~50잔기 정도만 읽을 수 있으므로, 긴 사슬은 효소로 잘라 조각마다 서열을 읽고 이어 붙입니다.

3.5.2겹치기

한 효소의 조각만으로는 조각들의 순서를 알 수 없습니다. 자르는 자리가 다른 두 번째 효소로 같은 사슬을 자르면, 그 조각들이 첫 번째 조각들의 경계를 가로지르므로 서로 겹치는 부분을 맞춰 순서를 정할 수 있습니다.

  1. N 말단 잔기(Edman이나 생어 시약)로 시작 조각을 정한다.
  2. 한 효소의 조각 끝 잔기가 그 효소의 규칙에 맞는지 확인한다(트립신 조각은 C 말단 조각을 빼면 Lys나 Arg로 끝난다).
  3. 두 번째 효소 조각이 어느 경계를 덮는지 찾아 잇는다.
  4. 전체 조성이 아미노산 분석 결과와 맞는지 점검한다.

3.5.3질량 분석

오늘날에는 효소 조각들의 질량을 질량 분석기로 재고, 조각을 다시 깨뜨린 MS/MS 스펙트럼으로 서열을 읽는 방법이 주로 쓰입니다. 겹치기 논리는 그대로입니다.

흔한 오해"트립신 조각은 모두 Lys나 Arg로 끝난다"가 아닙니다. 원래 사슬의 C 말단 조각은 아무 잔기로나 끝날 수 있고, 그것이 C 말단을 알려 주는 단서입니다. 또 Lys-Pro처럼 Pro 앞에서는 자르지 않는다는 예외를 잊으면 조각 수가 맞지 않습니다.
요약
  1. 트립신: Lys·Arg 뒤, 키모트립신: Phe·Tyr·Trp 뒤(Pro 앞 제외), BrCN: Met 뒤.
  2. 두 효소의 조각을 겹쳐 순서를 정한다. N 말단과 조성으로 점검.
  3. 규칙에 맞지 않는 끝을 가진 조각이 C 말단 조각이다.

3.5.4연습문제

기본

  1. Gly-Arg-Ala-Phe-Lys-Pro-Ser를 트립신으로 자르면 조각은?
    답

    Gly-Arg, Ala-Phe-Lys-Pro-Ser(Lys 뒤가 Pro라 자르지 않음).

응용

  1. 같은 펩타이드를 키모트립신으로 자르면?
    답

    Gly-Arg-Ala-Phe, Lys-Pro-Ser.

심화

  1. 트립신 조각 둘(Val-Lys, Ser-Tyr-Ala)과 키모트립신 조각 둘(Val-Lys-Ser-Tyr, Ala)이 나왔다. 서열과 N·C 말단은?
    답

    Val-Lys-Ser-Tyr-Ala. N 말단 Val, C 말단 Ala(Lys/Arg로 끝나지 않는 트립신 조각).
