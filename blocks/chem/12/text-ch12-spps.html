펩타이드 결합과 고상 펩타이드 합성

본문
이 절에서 배울 것
  • 펩타이드 결합이 평면이고 회전이 제한되는 이유를 공명으로 설명한다.
  • 원하는 순서로 펩타이드를 만들려면 왜 보호기와 활성화가 필요한지 안다.
  • Fmoc 고상 합성의 한 순환(탈보호, 활성화·결합, 세척)을 설명한다.
  • 단계 수율이 전체 수율에 미치는 영향을 계산한다.
먼저 알아야 할 것
  • 공명 (화학2 1.2절), 아실 치환 반응성 (화학5 5.1절), 아미노산의 구조 (2.1절).

3.1.1펩타이드 결합

한 아미노산의 COOH와 다른 아미노산의 NH₂가 물을 잃고 이어진 아마이드 결합이 펩타이드 결합입니다. 질소의 비공유 전자쌍이 C=O와 공명하므로 C−N 결합이 이중 결합 성질을 약 40% 가지고, 결합 길이(1.33 Å)가 보통 C−N(1.47 Å)보다 짧습니다. 그래서

  • C−N 둘레로 자유롭게 돌지 못하고, Cα−C(=O)−N(H)−Cα 여섯 원자가 한 평면에 놓인다.
  • 거의 모두 trans 배치(두 Cα가 반대쪽)다. 프롤린 앞에서만 cis가 조금 나타난다.

펩타이드 사슬은 N 말단(자유 NH₃⁺)에서 C 말단(자유 COO⁻) 방향으로 씁니다. Ala-Gly는 Ala가 N 말단입니다.

3.1.2왜 보호기와 활성화가 필요한가

구하려는 것: Ala와 Gly를 섞어 Ala-Gly 하나만 만드는 방법. 그냥 섞어 가열하면 Ala-Ala, Ala-Gly, Gly-Ala, Gly-Gly와 더 긴 사슬이 모두 생깁니다. 두 문제를 풀어야 합니다.

  • 선택성: Ala의 NH₂와 Gly의 COOH를 막아(보호기) 원하는 짝만 반응하게 한다.
  • 반응성: COOH는 그대로는 아민과 잘 반응하지 않는다(산-염기 반응으로 염이 됨). 카보다이이미드(DCC, DIC)나 HBTU 같은 결합 시약으로 COOH를 활성 에스터로 바꾼다(화학5 5.1절의 반응성 순서에서 위쪽으로 올림).

Fmoc: 아미노기 보호기. 약한 염기(DMF 속 20% 피페리딘)로 떼어진다.

tBu, Boc, Trt: 곁사슬 보호기. 강한 산(TFA)으로 떼어진다. Fmoc와 떼는 조건이 달라 서로 영향을 주지 않는다(직교 보호).

3.1.3고상 합성(메리필드 방법)

첫 아미노산의 C 말단을 녹지 않는 수지 알갱이에 붙여 두고, C → N 방향으로 하나씩 붙입니다. 반응이 끝나면 걸러 씻기만 하면 되므로, 시약을 크게 과량 써서 반응을 끝까지 몰 수 있고 자동화가 쉽습니다. 1984년 노벨 화학상(메리필드).

  1. 탈보호: 피페리딘으로 사슬 끝의 Fmoc를 뗀다.
  2. 세척: 피페리딘과 부산물을 씻어 낸다.
  3. 활성화·결합: 다음 Fmoc-아미노산(3~5당량)을 결합 시약으로 활성화해 넣는다.
  4. 세척 후 1로 돌아간다.
  5. 절단: 끝나면 TFA로 수지에서 떼어 내며 곁사슬 보호기도 한꺼번에 뗀다.

3.1.4단계 수율이 전부를 정한다

한 잔기를 붙이는 순환의 수율이 y이면, 길이 n인 펩타이드는 순환을 n − 1번 거치므로 목표 사슬의 비율은 yⁿ⁻¹입니다.

예제 3.1.1

순환 수율 99%로 20잔기, 50잔기를 만들면 목표 펩타이드는 몇 %인가? 98%라면?

0.99¹⁹ = 82.6%, 0.99⁴⁹ = 61.1%. 98%이면 0.98¹⁹ = 68.1%, 0.98⁴⁹ = 37.2%. 순환 수율 1%p 차이가 50잔기에서는 두 배 가까운 차이가 됩니다. 나머지는 잔기 하나가 빠진 결실 서열 등으로, 목표물과 성질이 매우 비슷해 정제가 어렵습니다. 그래서 결합하지 못한 사슬 끝을 아세트산 무수물로 막는 캐핑을 하기도 합니다.

흔한 오해"고상 합성은 생체처럼 N → C 방향으로 만든다"가 아닙니다. 수지에 C 말단을 붙이고 C → N으로 늘립니다(리보솜은 N → C). 또 "결합 시약만 있으면 보호기는 필요 없다"도 틀립니다. 활성화된 COOH는 아무 아민과도 반응하므로, 막아 두지 않은 아미노기가 있으면 순서가 섞입니다. 그리고 활성화한 아미노산은 α 탄소의 라셈화가 일어날 수 있어 첨가제(HOBt 등)로 억제합니다.
요약
  1. 펩타이드 결합은 공명으로 평면, 대부분 trans.
  2. 보호기(선택성)와 활성화(반응성)가 순서대로 만드는 열쇠. Fmoc(염기)과 tBu(산)는 직교.
  3. 고상 합성: 탈보호-세척-결합-세척 반복, 마지막에 TFA로 절단.
  4. 전체 수율 = yⁿ⁻¹. 99%·50잔기 61%, 98%·50잔기 37%.

3.1.5연습문제

기본

  1. Fmoc 고상 합성으로 Ala-Gly-Phe(N → C)를 만들 때 수지에 처음 붙이는 아미노산과 넣는 순서는?
    답

    C 말단 Phe를 먼저 수지에 붙이고, Gly, Ala 순서로 넣는다.

응용

  1. 30잔기 펩타이드를 목표 비율 80% 이상으로 얻으려면 순환 수율이 최소 얼마여야 하는가?
    답

    y²⁹ ≥ 0.80 → y ≥ 0.80^(1/29) = 0.9923, 곧 99.2% 이상.

심화

  1. Boc/Bn 전략(Boc는 TFA로, 곁사슬 Bn과 수지 결합은 HF로 뗌)과 Fmoc/tBu 전략을 "직교성" 관점에서 비교하시오.
    답

    Fmoc/tBu는 염기와 산이라는 전혀 다른 조건으로 떼므로 완전히 직교한다. Boc/Bn은 둘 다 산으로 떼고 산의 세기 차이(TFA와 HF)에 기대므로, 반복되는 TFA 처리에서 곁사슬 보호기가 조금씩 떨어질 수 있다. 대신 Boc 전략은 응집이 심한 서열에서 유리할 때가 있다. 독성이 큰 HF를 쓰지 않는 점도 Fmoc 전략이 널리 쓰이는 이유다.
