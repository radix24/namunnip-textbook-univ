펩타이드 결합과 고상 펩타이드 합성

본문

알라닌과 글라이신을 섞어 가열하면 Ala-Gly만 생기지 않고 Gly-Ala, Ala-Ala, Gly-Gly와 더 긴 사슬까지 뒤섞인다. 원하는 순서대로 아미노산을 하나씩 정확히 이어 붙이려면 무엇이 필요할까? 그리고 수십 개를 이을 때 매번 정제하지 않고 끝낼 방법은 없을까?

먼저 알아야 할 것공명(화학2 1.2절), 아실 치환 반응성(화학5 5.1절), 아미노산의 구조(2.1절)를 쓴다.

3.1.1펩타이드 결합

한 아미노산의 COOH와 다른 아미노산의 NH₂가 물을 잃고 이어진 아마이드 결합을 펩타이드 결합이라 한다. 질소의 비공유 전자쌍이 C=O와 공명하므로 C−N 결합이 이중 결합 성질을 약 40% 가지며, 결합 길이(1.33 Å)도 보통 C−N(1.47 Å)보다 짧다. 그래서 C−N 둘레로 자유롭게 돌지 못하고, Cα−C(=O)−N(H)−Cα 여섯 원자가 한 평면에 놓인다. 또 두 Cα가 반대쪽에 있는 trans 배치가 거의 전부이고, 프롤린 앞에서만 cis가 조금 나타난다. 펩타이드 사슬은 N 말단(자유 NH₃⁺)에서 C 말단(자유 COO⁻) 방향으로 쓰며, Ala-Gly는 Ala가 N 말단이다.

3.1.2왜 보호기와 활성화가 필요한가

Ala와 Gly에서 Ala-Gly 하나만 만들려면 두 문제를 풀어야 한다. 먼저 선택성이다. Ala의 NH₂와 Gly의 COOH를 보호기로 막아 원하는 짝만 반응하게 한다. 다음으로 반응성이다. COOH는 그대로는 아민과 산-염기 반응으로 염이 될 뿐 잘 결합하지 않는다. 그래서 카보다이이미드(DCC, DIC)나 HBTU 같은 결합 시약으로 COOH를 활성 에스터로 바꾸어, 화학5 5.1절의 반응성 순서에서 위쪽으로 올린다. 처음 질문의 첫째 답이 이 두 가지이다.

아미노기 보호기로는 Fmoc를 쓰며, DMF 속 20% 피페리딘 같은 약한 염기로 떼어진다. 곁사슬 보호기로는 tBu, Boc, Trt를 쓰며, TFA 같은 강한 산으로 떼어진다. 둘은 떼는 조건이 달라 서로 영향을 주지 않으며, 이것을 직교 보호라 한다.

3.1.3고상 합성(메리필드 방법)

고상 합성은 첫 아미노산의 C 말단을 녹지 않는 수지 알갱이에 붙여 두고, C → N 방향으로 하나씩 붙인다. 반응이 끝나면 걸러 씻기만 하면 되므로, 시약을 크게 과량 써서 반응을 끝까지 몰 수 있고 자동화가 쉽다. 처음 질문의 둘째 답이 이것이며, 메리필드는 이 방법으로 1984년 노벨 화학상을 받았다.

한 순환은 네 단계이다(그림 1). 먼저 피페리딘으로 사슬 끝의 Fmoc를 떼고, 피페리딘과 부산물을 씻어 낸다. 다음으로 다음 Fmoc-아미노산 3~5당량을 결합 시약으로 활성화해 넣고, 다시 씻어 첫 단계로 돌아간다. 모두 붙이면 TFA로 수지에서 떼어 내며, 곁사슬 보호기도 한꺼번에 뗀다. 예를 들어 Ala-Gly-Phe를 만들려면 C 말단 Phe를 먼저 수지에 붙이고, Gly, Ala 순서로 넣는다.

3.1.4단계 수율이 전부를 정한다

그런데 순환마다의 결합 수율이 곱해지므로, 긴 펩타이드일수록 목표 사슬의 비율이 급격히 줄고 잔기 하나가 빠진 결실 서열이 쌓인다. 그 계산과 캐핑, 조각 연결 같은 대처는 3.4절에서 다룬다.

흔한 오해고상 합성도 생체처럼 N → C 방향으로 만든다고 생각하기 쉽지만, 수지에 C 말단을 붙이고 C → N으로 늘린다. 리보솜은 N → C이다. 또 결합 시약만 있으면 보호기가 필요 없다는 생각도 틀렸다. 활성화된 COOH는 아무 아민과도 반응하므로, 막아 두지 않은 아미노기가 있으면 순서가 섞인다. 그리고 활성화한 아미노산은 α 탄소가 라셈화될 수 있어 HOBt 같은 첨가제로 억제한다.
마무리

펩타이드 결합은 공명으로 평면이고 대부분 trans이다. 처음 질문처럼 원하는 순서로 이으려면 보호기로 선택성을, 결합 시약으로 반응성을 확보하며, Fmoc(염기)와 tBu(산)는 직교 보호기이다. 고상 합성은 수지에 C 말단을 붙여 탈보호, 세척, 결합, 세척을 되풀이하고 마지막에 TFA로 떼어 내므로 단계마다 정제할 필요가 없다.

3.1.5연습문제

기본

  1. Fmoc 고상 합성으로 Ala-Gly-Phe(N → C)를 만들 때 수지에 처음 붙이는 아미노산과 넣는 순서는?
    답

    C 말단 Phe를 먼저 수지에 붙이고, Gly, Ala 순서로 넣는다.

응용

  1. 30잔기 펩타이드를 목표 비율 80% 이상으로 얻으려면 순환 수율이 최소 얼마여야 하는가?
    답

    y²⁹ ≥ 0.80 → y ≥ 0.80^(1/29) = 0.9923, 곧 99.2% 이상.

심화

  1. Boc/Bn 전략(Boc는 TFA로, 곁사슬 Bn과 수지 결합은 HF로 뗌)과 Fmoc/tBu 전략을 "직교성" 관점에서 비교하시오.
    답

    Fmoc/tBu는 염기와 산이라는 전혀 다른 조건으로 떼므로 완전히 직교한다. Boc/Bn은 둘 다 산으로 떼고 산의 세기 차이(TFA와 HF)에 기대므로, 반복되는 TFA 처리에서 곁사슬 보호기가 조금씩 떨어질 수 있다. 대신 Boc 전략은 응집이 심한 서열에서 유리할 때가 있다. 독성이 큰 HF를 쓰지 않는 점도 Fmoc 전략이 널리 쓰이는 이유다.
