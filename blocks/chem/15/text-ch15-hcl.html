HCl 진동-회전 스펙트럼 분석

본문
이 절에서 배울 것
  • FTIR로 얻은 HCl 기체 스펙트럼에서 P가지와 R가지 선에 J 번호를 붙인다.
  • 조합 차이로 B₀, B₁을 구하고, 결합 길이와 진동-회전 짝지음 상수 α를 계산한다.
  • 기본 띠와 배음으로 비조화 상수와 힘 상수를 구한다.
먼저 알아야 할 것
  • 강체 회전자와 회전 분광 (화학6 5.1절), 비조화 진동자 (화학6 5.2절).

3.1.1스펙트럼의 모양

HCl 기체를 10 cm 셀에 넣고 FTIR로 2600~3100 cm⁻¹을 찍으면, 띠 중심(약 2886 cm⁻¹)의 양쪽으로 선이 고르게 늘어서 있고 가운데에는 선이 없습니다. 진동이 한 단계 올라가며(v = 0 → 1) 회전 양자수가 ΔJ = ±1로 바뀌어야 하기 때문입니다.

  • R가지(ΔJ = +1, 높은 쪽): R(0), R(1), …
  • P가지(ΔJ = −1, 낮은 쪽): P(1), P(2), …

각 선이 두 개로 갈라져 보이는 것은 H³⁵Cl과 H³⁷Cl(약 3:1)의 동위원소 효과입니다. 무거운 H³⁷Cl의 선이 조금 낮은 쪽에 약하게 붙습니다.

3.1.2조합 차이

v = 0과 v = 1의 회전 상수 B₀, B₁이 조금 다르므로(진동하면 평균 결합이 길어져 B₁ < B₀), 선 간격이 일정하지 않습니다. 두 B를 따로 구하는 요령은 같은 위 준위나 같은 아래 준위를 공유하는 두 선의 차이를 쓰는 것입니다.

식 3.1.1 (조합 차이)

\[ R(J-1) - P(J+1) = 4B_0\left(J + \tfrac12\right), \qquad R(J) - P(J) = 4B_1\left(J + \tfrac12\right) \]

첫 식은 v = 1의 같은 준위로 올라가는 두 선이라 v = 0의 B₀만 남고, 둘째 식은 같은 아래 준위에서 출발하는 두 선이라 B₁만 남습니다. 여러 J에 대해 왼쪽을 J + ½에 대해 그리면 기울기가 4B입니다.

예제 3.1.1

H³⁵Cl의 조합 차이 맞춤에서 B₀ = 10.439, B₁ = 10.132 cm⁻¹를 얻었다. 결합 길이 r₀와 평형 결합 길이 r_e는?

B = h/(8π²cμr²)에서 μ(H³⁵Cl) = 1.6266×10⁻²⁷ kg. r₀ = 1.284 Å(바닥 진동 상태의 평균). α = B₀ − B₁ = 0.307 cm⁻¹, B_e = B₀ + α/2 = 10.593 cm⁻¹이므로 r_e = 1.275 Å입니다. 진동의 평균이 섞인 r₀가 r_e보다 조금 깁니다. 화학6 5.1절의 실습 카드에서 이 맞춤을 직접 해 볼 수 있습니다.

3.1.3비조화성과 힘 상수

기본띠와 배음의 위치로 비조화 상수와 조화 진동수를 구하고, 힘 상수 \(k = 4\pi^2c^2\mu\omega_e^2\)와 해리 에너지의 어림을 얻습니다. 계산은 3.3절에 있습니다.

흔한 오해"선 간격이 2B로 일정하다"는 강체 회전자 근사입니다. 실제로는 B₁ < B₀ 때문에 R가지 간격이 위로 갈수록 좁아지고 P가지는 넓어집니다. 또 띠 중심 2886 cm⁻¹을 그대로 넣어 얻은 힘 상수는 평형 힘 상수가 아닙니다. 비조화 보정이 필요합니다.
요약
  1. P가지(ΔJ = −1), R가지(+1), 가운데 빈자리, 동위원소 짝 선.
  2. 조합 차이: R(J−1) − P(J+1) = 4B₀(J + ½), R(J) − P(J) = 4B₁(J + ½).
  3. B₀ 10.439, B₁ 10.132 → r₀ 1.284 Å, B_e 10.593 → r_e 1.275 Å.
  4. 기본 띠 + 배음 → ν̃_e = 2990.0, ν̃_ex_e = 52.0 cm⁻¹, k_e = 516 N/m.

3.1.4연습문제

기본

  1. R(0) = 2906.2, P(2) = 2843.6 cm⁻¹이다. 조합 차이로 B₀를 구하시오.
    답

    두 선은 모두 v = 1, J = 1 준위로 올라가므로 R(0) − P(2) = 4B₀(1 + ½) = 6B₀. B₀ = 62.6/6 = 10.43 cm⁻¹.

응용

  1. DCl의 환산 질량은 HCl의 약 1.94배다. 띠 중심은 대략 몇 cm⁻¹로 옮겨 가는가?
    답

    ν̃ ∝ 1/√μ이므로 2886/√1.94 = 2072 cm⁻¹ 근처(실측 약 2091 cm⁻¹, 비조화 차이).

심화

  1. B₀ = 10.439 cm⁻¹일 때 300 K에서 가장 센 회전선의 J를 어림하시오.
    답

    J_max ≈ √(kT/2hcB) − ½ = √(208.5/20.88) − ½ = 3.16 − 0.5 ≈ 2.7, 곧 J = 3 근처(R(3), P(3) 부근이 가장 셈).
