HCl의 비조화 상수와 해리 에너지 어림

모스 준위 · 배음 · Birge-Sponer

출발점

기본띠와 배음 위치 두 개로 ω_e와 ω_ex_e를 정하고, 모스 식으로 우물 깊이를 어림해 실험값과 비교합니다.

H³⁵Cl의 기본띠가 2885.3 cm⁻¹, 첫 배음이 5665.0 cm⁻¹이다. (가) ω_e와 ω_ex_e, (나) 모스 D_e와 D₀(eV)를 구하고 (다) 실험값 D₀ = 4.43 eV와 비교하여라. (1 eV = 8065.5 cm⁻¹)

풀이

  1. (가) \(\omega_e - 2\omega_ex_e = 2885.3\), \(2\omega_e - 6\omega_ex_e = 5665.0\). 첫 식의 2배에서 둘째 식을 빼면 \(2\omega_ex_e = 105.6\), \(\omega_ex_e = 52.8\), \(\omega_e = 2990.9\) cm⁻¹.
  2. (나) \(D_e = 2990.9^2/(4\times52.8) = 42\,360\ \mathrm{cm^{-1}} = 5.25\) eV.
  3. \(G(0) = 2990.9/2 - 52.8/4 = 1482.3\ \mathrm{cm^{-1}}\), \(D_0 = 40\,880\ \mathrm{cm^{-1}} = 5.07\) eV.
  4. (다) 실험 4.43 eV보다 14% 큽니다.
    모스 외삽의 전형적인 과대평가.

의미

배음이 기본띠의 두 배(5770.6)보다 105.6 cm⁻¹ 낮다는 작은 차이에서 결합이 해리 쪽으로 평평해지는 정도를 읽어 냈습니다. 모스 식은 낮은 준위를 잘 맞추지만 해리 한계 근처를 과대평가해, 진동 자료만으로 얻은 해리 에너지는 규모를 알려 주는 어림값으로 씁니다.

검산

구한 상수로 기본띠를 다시 계산하면 2990.9 − 105.6 = 2885.3, 배음은 5981.8 − 316.8 = 5665.0으로 두 자료가 모두 맞습니다.
