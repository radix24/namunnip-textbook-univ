스타이렌-MMA 공중합의 조성과 공비점

메이요-루이스 식 · 공비 조성 · 조성 표류

출발점

반응성 비를 식에 넣어 순간 조성을 구하고, 두 반응성 비가 모두 1보다 작으면 공비 조성을 찾습니다.

스타이렌(1)과 메틸 메타크릴레이트(2)의 라디칼 공중합에서 r₁ = 0.52, r₂ = 0.46이다. (가) f₁ = 0.50일 때 F₁, (나) 공비 조성, (다) f₁ = 0.20에서 시작해 높은 전환율까지 중합할 때 생기는 일을 설명하여라.

풀이

  1. (가) 분자 \(0.52\times0.25 + 0.25 = 0.380\), 분모 \(0.130 + 0.50 + 0.46\times0.25 = 0.745\), \(F_1 = 0.510\).
    1 : 1에 가깝습니다.
  2. (나) \(f_1 = (1 - 0.46)/(2 - 0.52 - 0.46) = 0.54/1.02 = 0.529\).
    이 조성에서는 F₁ = f₁.
  3. (다) f₁ = 0.20: 분자 \(0.52\times0.04 + 0.16 = 0.181\), 분모 \(0.021 + 0.32 + 0.294 = 0.635\), \(F_1 = 0.285\). 공중합체에 스타이렌이 단량체보다 많이 들어갑니다.
    f₁이 공비점보다 작으면 F₁ > f₁.
  4. 그래서 남은 단량체에서 스타이렌이 줄어 f₁이 점점 작아지고, 나중에 생기는 사슬은 MMA가 더 많아집니다(조성 표류).

의미

r₁r₂ = 0.24로 교대 경향이 조금 있어 공비점 근처에서 조성이 고르게 유지됩니다. 공비점에서 먼 조성으로 높은 전환율까지 가면 처음과 끝의 사슬 조성이 달라 투명도나 물성이 고르지 않으므로, 공업에서는 더 빨리 소모되는 단량체를 반응 중에 조금씩 보충해 조성을 맞춥니다.

검산

f₁ = 0.529를 식에 넣으면 분자 \(0.52\times0.280 + 0.249 = 0.395\), 분모 \(0.146 + 0.498 + 0.102 = 0.746\), F₁ = 0.529로 f₁과 같아 공비 조성이 맞습니다.
