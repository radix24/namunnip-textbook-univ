수평균 분자량과 무게평균 분자량

본문
이 절에서 배울 것
  • 고분자 시료가 하나의 분자량이 아니라 분포를 가지는 이유를 안다.
  • 수평균 Mn과 무게평균 Mw를 정의대로 계산한다.
  • 분산도 Mw/Mn으로 분포의 넓이를 판단하고, 단계 중합의 Flory 분포 값을 안다.
  • 당량비가 맞지 않을 때 얻을 수 있는 최대 중합도를 계산한다.
먼저 알아야 할 것
  • 사슬 중합과 단계 중합 (1.1절), 평균과 합의 기호 (화학1 1.2절).

1.2.1왜 평균이 둘인가

중합은 무작위 과정이라 한 시료 안에 길이가 다른 사슬이 섞여 있습니다. 분자량 Mᵢ인 사슬이 Nᵢ개 있을 때 "평균"을 내는 방법이 두 가지입니다.

식 1.2.1

\[ M_n = \frac{\sum N_iM_i}{\sum N_i}, \qquad M_w = \frac{\sum N_iM_i^2}{\sum N_iM_i} = \sum w_iM_i \]

wᵢ는 질량 분율. Mn은 사슬 하나하나를 똑같이 세는 평균, Mw는 질량(무거운 사슬)에 가중한 평균이다.

무거운 사슬은 질량이 커서 Mw에 더 크게 기여하므로 언제나 Mw ≥ Mn이고, 모든 사슬이 같으면 둘이 같습니다.

분산도 Đ = Mw/Mn. 1이면 모든 사슬 길이가 같고, 클수록 분포가 넓다.

1.2.2계산 연습

예제 1.2.1

분자량 10000인 사슬 100개와 100000인 사슬 100개가 섞인 시료의 Mn, Mw, Đ는?

Mn = (100 × 10⁴ + 100 × 10⁵)/200 = 55000. Mw = (100 × 10⁸ + 100 × 10¹⁰)/(100 × 10⁴ + 100 × 10⁵) = 1.01×10¹²/1.1×10⁷ = 91800. Đ = 1.67.

같은 두 고분자를 질량으로 반반 섞으면 가벼운 사슬의 개수가 열 배 많아지므로 Mn = 1/(0.5/10⁴ + 0.5/10⁵) = 18200, Mw = 0.5 × 10⁴ + 0.5 × 10⁵ = 55000, Đ = 3.0입니다. "반반"이 개수인지 질량인지에 따라 답이 크게 다릅니다.

1.2.3재는 방법

  • Mn: 사슬 수를 세는 방법. 말단기 분석(NMR로 끝 작용기 세기), 삼투압.
  • Mw: 질량에 민감한 방법. 정적 광산란(큰 분자가 빛을 더 많이 산란).
  • 분포 전체: 크기 배제 크로마토그래피(GPC). 큰 사슬이 기공에 덜 들어가 먼저 나온다. 표준 시료로 맞춘 상대 분자량을 준다.

1.2.4단계 중합의 분포와 당량비

단계 중합에서 사슬 길이 분포는 Flory(최확) 분포를 따르고, 분산도는 Đ = 1 + p입니다. 전환율이 1에 가까우면 Đ → 2입니다. 사슬 중합은 종결 방식에 따라 1.5~2이고, 리빙 중합(종결 없이 모든 사슬이 동시에 자람)은 1.1보다 작게도 됩니다.

두 단량체(A−A와 B−B)의 몰수 비가 r = N_A/N_B < 1로 맞지 않으면, 적은 쪽이 다 반응해도 사슬 끝이 많은 쪽 작용기로 막혀 더 자라지 못합니다.

식 1.2.2

\[ X_n = \frac{1 + r}{1 + r - 2rp}, \qquad p \to 1 \text{에서 } X_n \to \frac{1 + r}{1 - r} \]

r = 0.99면 최대 Xn = 199, r = 0.98이면 99입니다. 당량을 1%만 틀려도 중합도가 200 아래로 묶입니다. 반대로 이를 이용해 단관능 단량체를 조금 넣어 분자량을 일부러 조절합니다.

흔한 오해"분자량이 큰 고분자 시료의 Mn과 Mw는 거의 같다"가 아닙니다. Đ가 2인 시료는 Mw가 Mn의 두 배입니다. 또 GPC가 주는 분자량은 대개 폴리스타이렌 표준 기준의 상대값이라, 모양이 다른 고분자에서는 실제와 다를 수 있습니다.
요약
  1. Mn = ΣNᵢMᵢ/ΣNᵢ(개수 평균), Mw = ΣwᵢMᵢ(질량 평균), Mw ≥ Mn.
  2. Đ = Mw/Mn. 단계 중합 1 + p(→ 2), 리빙 중합은 1에 가까움.
  3. 개수 혼합과 질량 혼합은 평균이 크게 다르다.
  4. 당량비 r이면 최대 Xn = (1 + r)/(1 − r).

1.2.5연습문제

기본

  1. 분자량 20000인 사슬 3개와 40000인 사슬 1개의 Mn과 Mw는?
    답

    Mn = (60000 + 40000)/4 = 25000. Mw = (3 × 4×10⁸ + 16×10⁸)/(100000) = 28000. Đ = 1.12.

응용

  1. 단계 중합에서 p = 0.995일 때 Xn, Đ는? 반복 단위 질량이 113 g/mol이면 Mn과 Mw는?
    답

    Xn = 200, Đ = 1.995. Mn ≈ 22600, Mw ≈ 45100 g/mol.

심화

  1. 나일론-6,6을 만들면서 Xn을 100으로 제한하려면 당량비 r을 얼마로 해야 하는가(p = 1까지 반응한다고 가정)?
    답

    (1 + r)/(1 − r) = 100에서 r = 99/101 = 0.980. 다이아민을 약 2% 과량으로 넣으면 된다(또는 아세트산 같은 단관능 산을 조금 넣는다).
