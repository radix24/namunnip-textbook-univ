수평균 분자량과 무게평균 분자량

본문

같은 폴리스타이렌 시료의 분자량을 삼투압으로 재면 5만이 나오고, 광산란으로 재면 10만이 나온다. 둘 중 하나가 틀린 것이 아니다. 한 시료 안에 길이가 다른 사슬이 섞여 있다면, 분자량의 평균은 어떻게 내야 하고 왜 값이 둘이나 될까?

먼저 알아야 할 것사슬 중합과 단계 중합(1.1절), 평균과 합의 기호(화학1 1.2절)를 쓴다.

1.2.1왜 평균이 둘인가

중합은 무작위 과정이어서 한 시료 안에 길이가 다른 사슬이 섞여 있다. 분자량 \(M_i\)인 사슬이 \(N_i\)개 있을 때 평균을 내는 방법은 두 가지이다.

식 1.2.1

\[ M_n = \frac{\sum N_iM_i}{\sum N_i}, \qquad M_w = \frac{\sum N_iM_i^2}{\sum N_iM_i} = \sum w_iM_i \]

\(w_i\)는 질량 분율이다. \(M_n\)은 사슬 하나하나를 똑같이 세는 평균이고, \(M_w\)는 질량에 가중해 무거운 사슬을 더 크게 센 평균이다.

앞의 것을 수평균 분자량, 뒤의 것을 무게평균 분자량이라 한다. 무거운 사슬은 질량이 커서 \(M_w\)에 더 크게 기여하므로 언제나 \(M_w \ge M_n\)이고, 모든 사슬이 같을 때만 둘이 같다(그림 1). 처음 질문의 답이 이것이다. 삼투압은 분자 수를 세어 \(M_n\)을 주고, 광산란은 질량에 가중된 \(M_w\)를 준다. 이 둘의 비 \(Đ = M_w/M_n\)을 분산도라 하며, 1이면 모든 사슬 길이가 같고 클수록 분포가 넓다.

1.2.2계산 연습

예제 1.2.1

분자량 10000인 사슬 100개와 100000인 사슬 100개가 섞인 시료의 \(M_n\), \(M_w\), \(Đ\)를 구하여라.

\(M_n = (100 \times 10^4 + 100 \times 10^5)/200 = 55000\)이다. 또 \(M_w = (100 \times 10^8 + 100 \times 10^{10})/(100 \times 10^4 + 100 \times 10^5) = 1.01\times10^{12}/1.1\times10^7 = 91800\)이므로 \(Đ = 1.67\)이다.

같은 두 고분자를 질량으로 반반 섞으면 가벼운 사슬의 개수가 열 배 많아진다. 그래서 \(M_n = 1/(0.5/10^4 + 0.5/10^5) = 18200\), \(M_w = 0.5 \times 10^4 + 0.5 \times 10^5 = 55000\), \(Đ = 3.0\)이다. 반반이 개수인지 질량인지에 따라 답이 크게 다르다.

1.2.3재는 방법

분자량은 말단기 분석과 삼투압(\(M_n\)), 광산란(\(M_w\)), 점도(\(M_v\)), GPC(분포 전체)로 잰다. 각 방법이 주는 평균과 절대·상대 측정의 구별은 1.6절에서 다룬다.

1.2.4단계 중합의 분포와 당량비

단계 중합에서 사슬 길이 분포는 Flory 분포, 곧 최확 분포를 따르고 분산도는 \(Đ = 1 + p\)이다. 그러므로 전환율이 1에 가까우면 \(Đ \to 2\)이다. 한편 사슬 중합은 종결 방식에 따라 1.5~2이고, 종결 없이 모든 사슬이 동시에 자라는 리빙 중합은 1.1보다 작게도 된다.

두 단량체 A−A와 B−B의 몰수 비가 \(r = N_A/N_B < 1\)로 맞지 않으면, 적은 쪽이 다 반응해도 사슬 끝이 많은 쪽 작용기로 막혀 더 자라지 못한다.

식 1.2.2

\[ X_n = \frac{1 + r}{1 + r - 2rp}, \qquad p \to 1 \text{에서 } X_n \to \frac{1 + r}{1 - r} \]

예를 들어 \(r = 0.99\)이면 최대 \(X_n = 199\)이고, \(r = 0.98\)이면 99이다. 당량을 1%만 틀려도 중합도가 200 아래로 묶인다. 반대로 이것을 이용해 단관능 단량체를 조금 넣어 분자량을 일부러 조절하기도 한다.

흔한 오해분자량이 큰 고분자 시료에서는 \(M_n\)과 \(M_w\)가 거의 같다고 생각하기 쉽지만, \(Đ = 2\)인 시료는 \(M_w\)가 \(M_n\)의 두 배이다. 또 GPC가 주는 분자량은 대개 폴리스타이렌 표준을 기준으로 한 상대값이어서, 모양이 다른 고분자에서는 실제와 다를 수 있다.
마무리

수평균 \(M_n = \sum N_iM_i/\sum N_i\)는 개수로 센 평균이고, 무게평균 \(M_w = \sum w_iM_i\)는 질량으로 센 평균이며 언제나 \(M_w \ge M_n\)이다. 처음 질문의 두 값은 삼투압이 \(M_n\)을, 광산란이 \(M_w\)를 재기 때문에 다르다. 분산도 \(Đ = M_w/M_n\)은 단계 중합에서 \(1 + p\)로 2에 다가가고, 당량비가 \(r\)이면 최대 \(X_n = (1 + r)/(1 - r)\)이다.

1.2.5연습문제

기본

  1. 분자량 20000인 사슬 3개와 40000인 사슬 1개의 Mn과 Mw는?
    답

    Mn = (60000 + 40000)/4 = 25000. Mw = (3 × 4×10⁸ + 16×10⁸)/(100000) = 28000. Đ = 1.12.

응용

  1. 단계 중합에서 p = 0.995일 때 Xn, Đ는? 반복 단위 질량이 113 g/mol이면 Mn과 Mw는?
    답

    Xn = 200, Đ = 1.995. Mn ≈ 22600, Mw ≈ 45100 g/mol.

심화

  1. 나일론-6,6을 만들면서 Xn을 100으로 제한하려면 당량비 r을 얼마로 해야 하는가(p = 1까지 반응한다고 가정)?
    답

    (1 + r)/(1 − r) = 100에서 r = 99/101 = 0.980. 다이아민을 약 2% 과량으로 넣으면 된다(또는 아세트산 같은 단관능 산을 조금 넣는다).
