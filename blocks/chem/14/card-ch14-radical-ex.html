스타이렌 벌크 중합의 속도와 사슬 길이

정상 상태 · 중합 속도 · 동역학 사슬 길이

출발점

속도 상수와 농도를 식 1.4.1에 넣습니다. 제곱근 안을 먼저 계산하면 두 식에 같은 묶음이 나옵니다.

k_p = 340 L mol⁻¹ s⁻¹, k_t = 6.0×10⁷ L mol⁻¹ s⁻¹, k_d = 2.0×10⁻⁵ s⁻¹, f = 0.60, [M] = 8.0 M, [I] = 0.010 M이다. R_p, ν, 그리고 재결합 정지를 가정한 X_n을 구하여라. [I]를 0.040 M으로 늘리면 어떻게 되는가?

풀이

  1. \(fk_d[\mathrm I] = 0.60\times2.0\times10^{-5}\times0.010 = 1.2\times10^{-7}\ \mathrm{M\,s^{-1}}\).
    라디칼 생성 속도의 절반.
  2. \(R_p = 340\times8.0\times(1.2\times10^{-7}/6.0\times10^7)^{1/2} = 2720\times4.47\times10^{-8} = 1.2\times10^{-4}\ \mathrm{M\,s^{-1}}\).
    한 시간에 단량체의 약 5%가 소모됩니다.
  3. \(\nu = 2720/(2\times(1.2\times10^{-7}\times6.0\times10^7)^{1/2}) = 2720/(2\times2.68) = 507\), \(X_n = 1014\).
    분자량 약 10만 g/mol(스타이렌 104 g/mol).
  4. [I]를 4배로: R_p 2배(2.4×10⁻⁴), ν 절반(254), X_n 507.
    속도와 분자량의 맞바꿈.

의미

개시제를 네 배 넣어 중합을 두 배 빠르게 했지만 고분자의 분자량이 절반이 되었습니다. 원하는 분자량이 정해져 있으면 개시제 양은 그것으로 정해지고, 빠르기는 단량체 농도나 다른 방법으로 맞춰야 합니다. 실제 고분자 공정이 개시제를 아주 조금만 쓰는 이유입니다.

검산

단위를 확인합니다. \((\mathrm{M\,s^{-1}}/(\mathrm{M^{-1}s^{-1}}))^{1/2} = \mathrm M\)이 라디칼 농도이고, 여기에 k_p[M](s⁻¹)를 곱하면 R_p는 M s⁻¹입니다. ν는 무차원이어야 하고 분자와 분모가 모두 M s⁻¹이라 맞습니다.
