코시-리만 방정식과 라플라스 방정식

본문

3.3절에서는 차분몫을 여러 방향으로 계산해서 미분 가능한지 확인했다. 함수마다 이렇게 하기는 번거롭다. 실수부 \(u\)와 허수부 \(v\)의 편도함수만 보고 해석적인지 바로 판정할 수는 없을까? 그리고 해석함수의 \(u\)와 \(v\)에는 어떤 특별한 성질이 있을까?

먼저 알아야 할 것복소 도함수(3.3절)와 편도함수(미분적분학(2) 4.2절)를 쓴다.

3.4.1두 방향에서 같아야 한다

도함수는 모든 방향에서 같아야 한다. 가로 방향(\(\Delta z = \Delta x\))으로 구하면 \(f' = u_x + iv_x\)이고, 세로 방향(\(\Delta z = i\Delta y\))으로 구하면 \(f' = \frac{1}{i}(u_y + iv_y) = v_y - iu_y\)이다. 둘이 같으려면 실수부끼리, 허수부끼리 같아야 하며, 이것이 처음 질문의 판정법이다.

정리 3.4.1 (코시-리만 방정식)

\(f = u + iv\)가 해석적이면 \(u_x = v_y\), \(u_y = -v_x\)이다. 거꾸로 \(u, v\)의 편도함수가 연속이고 이 식을 만족하면 \(f\)는 해석적이며 \(f' = u_x + iv_x\)이다.

예제 3.4.2

\(f(z) = z^2\)과 \(f(z) = \bar z\)에 코시-리만 방정식을 적용하여라.

풀이. \(z^2\)이면 \(u = x^2 - y^2\), \(v = 2xy\)이므로 \(u_x = 2x = v_y\), \(u_y = -2y = -v_x\)이다. 성립하므로 해석적이다. 반면 \(\bar z\)이면 \(u = x\), \(v = -y\)이므로 \(u_x = 1 \ne v_y = -1\)이다. 따라서 해석적이 아니며, 3.3절의 결과와 같다.

3.4.2라플라스 방정식

코시-리만 방정식을 한 번 더 미분하면 \(u_{xx} = v_{yx}\), \(u_{yy} = -v_{xy}\)이므로, 더하면 0이다.

정리 3.4.3

해석함수의 실수부와 허수부는 라플라스 방정식 \(\nabla^2u = u_{xx} + u_{yy} = 0\)을 만족한다(조화함수).

처음 질문의 특별한 성질이 이것이며, 복소해석이 물리와 공학에서 중요한 까닭이다. 2차원의 정상 상태 온도, 정전기 퍼텐셜, 이상 유체의 흐름은 모두 라플라스 방정식을 만족하므로, 해석함수 하나를 찾으면 이런 문제의 해를 얻는다(6단원). 또 코시-리만 방정식에서 \(\nabla u\cdot\nabla v = u_xv_x + u_yv_y = 0\)이므로, 그림 1처럼 \(u\)와 \(v\)의 등고선은 직각으로 만난다.

한편 주어진 조화함수 \(u\)에 대해 \(u + iv\)가 해석적이 되는 \(v\)를 켤레 조화함수라 하고, 코시-리만 방정식을 적분해 구한다.

예제 3.4.4

\(u = x^2 - y^2 - y\)가 조화함수임을 확인하고 켤레 조화함수 \(v\)를 구하여라.

풀이. \(u_{xx} + u_{yy} = 2 - 2 = 0\)이므로 조화함수이다. \(v_y = u_x = 2x\)에서 \(v = 2xy + h(x)\)이고, \(v_x = 2y + h' = -u_y = 2y + 1\)에서 \(h = x\)이다. 따라서 \(v = 2xy + x\), \(f = u + iv = z^2 + iz\)이다. 그림 1에서 \(z^2 + iz\)를 고르면 이 \(u\)와 \(v\)의 등고선이 그려진다.

마무리

편도함수가 연속일 때 \(f\)가 해석적일 필요충분조건은 코시-리만 방정식 \(u_x = v_y\), \(u_y = -v_x\)이며, 처음 질문의 판정을 편도함수만으로 끝낸다. 해석함수의 \(u\)와 \(v\)는 조화함수(\(\nabla^2u = 0\))이고, 두 등고선은 직각으로 만난다.

3.4.3연습문제

기본

  1. \(f = e^x(\cos y + i\sin y)\)가 해석적임을 코시-리만 방정식으로 보여라.
    답

    \(u_x = e^x\cos y = v_y\), \(u_y = -e^x\sin y = -v_x\).

응용

  1. \(u = xy\)의 켤레 조화함수를 구하여라.
    답

    \(v_y = y\), \(v = \frac{y^2}{2} + h(x)\), \(v_x = h' = -x\). \(v = \frac{y^2 - x^2}{2}\). (\(f = -\frac i2z^2\))
