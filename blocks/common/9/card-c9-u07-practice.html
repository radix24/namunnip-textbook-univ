복소 적분과 등각사상 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

특이점을 먼저 찾고 경로 안에 있는지 확인하세요.

  1. 계산\(\oint_{|z - 1| = 1}\frac{dz}{z^2 - 1}\)을 구하세요. [07-02]

    힌트 1

    특이점 ±1 중 원 \(|z - 1| = 1\) 안에 있는 것은?

    힌트 2

    \(z = 1\)은 중심, \(z = -1\)은 거리 2.

    풀이

    \(z = 1\)만 안. \(\text{Res} = \frac{1}{2z}\big|_1 = \frac12\). 적분 \(\pi i\).

  2. 개념\(\oint_{|z|=1}\frac{e^z}{z}dz = 2\pi i\)를 이용해 \(\int_0^{2\pi}e^{\cos\theta}\cos(\sin\theta)\,d\theta\)를 구하세요. [07-01, 07-02]

    힌트 1

    07-01 절: \(z = e^{i\theta}\)로 매개화.

    힌트 2

    \(\frac{dz}{z} = i\,d\theta\), \(e^{e^{i\theta}} = e^{\cos\theta}(\cos(\sin\theta) + i\sin(\sin\theta))\).

    풀이

    \(2\pi i = \int_0^{2\pi}e^{e^{i\theta}}i\,d\theta\). 양변을 \(i\)로 나눠 실수부를 비교: \(\int_0^{2\pi}e^{\cos\theta}\cos(\sin\theta)\,d\theta = 2\pi\). 실수 방법으로는 매우 어려운 적분입니다.

  3. 계산\(\displaystyle\int_{-\infty}^\infty\frac{dx}{x^4 + 1}\)을 구하세요. [07-03]

    힌트 1

    위 반평면 극 \(e^{i\pi/4}\), \(e^{3i\pi/4}\).

    힌트 2

    유수 \(\frac{1}{4z^3} = \frac{z}{4z^4} = -\frac z4\) (\(z^4 = -1\)).

    풀이

    유수 합 \(-\frac14(e^{i\pi/4} + e^{3i\pi/4}) = -\frac14\cdot i\sqrt2\). 적분 \(= 2\pi i\cdot\left(-\frac{i\sqrt2}{4}\right) = \frac{\pi\sqrt2}{2} = \frac{\pi}{\sqrt2} \approx 2.22\).

  4. 판단한 학생이 \(\oint_{|z|=1}\frac{dz}{\bar z}\)를 "\(\frac1z\)처럼 \(2\pi i\)"라고 했습니다. 맞나요? [07-01]

    힌트 1

    단위원 위에서 \(\bar z = \frac1z\).

    힌트 2

    그러면 \(\frac{1}{\bar z} = z\).

    풀이

    틀렸습니다. 원 위에서 \(\frac{1}{\bar z} = z\)이므로 \(\oint z\,dz = 0\). \(\frac{1}{\bar z}\)는 해석적이지 않아 유수 정리를 그대로 쓸 수 없고, 경로 위에서의 값으로 계산해야 합니다.

  5. 계산\(w = z^2\)이 제1사분면을 어디로 보내는지 쓰고, 이를 이용해 제1사분면에서 \(\phi = 0\) (\(x\)축), \(\phi = 0\) (\(y\)축)이면서 \(\phi = 2xy\)가 조화함수임을 설명하세요. [07-04]

    힌트 1

    \(w = r^2e^{2i\theta}\): 각도가 2배.

    힌트 2

    \(\text{Im}\,w = 2xy\).

    풀이

    제1사분면 → 위 반평면. 위 반평면에서 \(\Phi = \text{Im}\,w\)는 조화이고 실수축(경계)에서 0. 되돌리면 \(\phi = \text{Im}(z^2) = 2xy\), 두 축에서 0. 직각 모서리 근처 흐름의 유선 \(xy = \)상수(쌍곡선)가 이것입니다.

  6. 판단"\(\oint_{|z|=3}\frac{dz}{z^2 + 1} = 2\pi i(\text{Res}(i) + \text{Res}(-i)) = 2\pi i\left(\frac{1}{2i} - \frac{1}{2i}\right) = 0\)이니 \(\frac{1}{z^2 + 1}\)은 원 안에서 해석적이다." 결론이 맞나요? [07-02]

    힌트 1

    Cauchy 정리의 거꾸로가 성립하나요?

    힌트 2

    특이점 \(\pm i\)는 원 안에 있습니다.

    풀이

    계산은 맞지만 결론은 틀렸습니다. \(\pm i\)에 극이 있어 해석적이지 않습니다. 적분이 0인 것은 두 유수가 우연히 상쇄되었기 때문입니다. "해석적이면 적분 0"의 거꾸로 "적분 0이면 해석적"은 하나의 경로로는 성립하지 않습니다(모든 경로에서 0이면 해석적: 모레라 정리).
