아주 긴 막대의 가운데만 데우면 열은 어떻게 퍼질까?

실습 · 무한 막대의 열방정식

목표

끝이 없는 막대에서는 경계 조건이 없으므로 푸리에 급수 대신 푸리에 적분으로 열방정식 \(u_t = c^2u_{xx}\)을 풉니다. 가운데 길이 2만 온도 1로 데운 막대의 온도가 시간에 따라 어떻게 퍼지는지 보고, 열의 총량이 보존되는 것을 확인합니다. 성취기준 [공통9-02-06].

준비

  • 처음 온도 \(f(x) = 1\) (\(|x| < 1\)), 0 (그 밖). 점선이 처음 온도입니다.
  • 푸리에 적분 풀이를 정리하면 \(u(x, t) = \displaystyle\int_{-\infty}^\infty f(v)\frac{e^{-(x - v)^2/4c^2t}}{2c\sqrt{\pi t}}\,dv\)이고, 이 \(f\)에서는 오차 함수로 \(u = \tfrac12\left[\operatorname{erf}\dfrac{1 + x}{2c\sqrt t} + \operatorname{erf}\dfrac{1 - x}{2c\sqrt t}\right]\)입니다.
  • \(\operatorname{erf}(z) = \dfrac2{\sqrt\pi}\int_0^ze^{-s^2}ds\)는 정규분포의 누적 확률과 같은 함수입니다.

절차

  1. \(c = 1\)에서 \(t = 0, 0.1, 1, 4\)일 때 \(u(0, t)\), \(u(2, t)\), 총량을 기록합니다.
  2. \(t = 1\)에서 \(c\)를 2로 올리면 무엇이 \(t = 4\), \(c = 1\)과 같아지는지 봅니다.

기대 결과

  • \(c = 1\), \(t = 1\): \(u(0, 1) = \operatorname{erf}(0.5) = 0.5205\), \(u(2, 1) = 0.2228\). 열의 총량은 언제나 2입니다.
  • 시간이 지나면 꼭대기는 낮아지고 옆으로 넓어지며, 모양은 정규분포의 종 모양에 가까워집니다. 처음의 뾰족한 모서리는 \(t > 0\)이 되자마자 매끈해집니다.
  • \(u\)는 \(c\sqrt t\)로만 정해지므로 \(c = 2,\ t = 1\)과 \(c = 1,\ t = 4\)의 그래프가 똑같습니다.

분석

  1. \(t\)가 아주 작아도 \(x = 5\)에서 \(u\)가 0보다 조금 큽니다. 열이 무한히 빠르게 전해진다는 이 모형의 한계를 말해 보세요.
  2. 푸리에 변환으로 보면 \(\hat u(w, t) = \hat f(w)e^{-c^2w^2t}\)입니다. 높은 진동수(뾰족한 부분)가 먼저 사라지는 이유를 설명해 보세요.

더 해 보기
