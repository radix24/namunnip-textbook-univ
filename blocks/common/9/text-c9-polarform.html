복소수의 극형식, 거듭제곱과 거듭제곱근

본문
이 절에서 배울 것
  • 복소수를 \(r(\cos\theta + i\sin\theta)\)로 쓰고, 곱셈을 "거리는 곱, 각은 합"으로 이해한다.
  • 드무아브르 공식으로 거듭제곱과 \(n\)제곱근을 구한다.
먼저 알아야 할 것
  • 복소평면 (3.1절), 극좌표 (공통1 7.3절), 오일러 공식 (8.8절).

3.2.1극형식

복소평면의 점을 극좌표로 쓰면 \(z = r(\cos\theta + i\sin\theta) = re^{i\theta}\)입니다. \(r = |z|\)를 절댓값, \(\theta = \arg z\)를 편각이라 합니다. 편각은 \(2\pi\)의 정수배만큼 차이 나도 같은 점을 나타내므로 값이 여러 개입니다. \(-\pi < \theta \le \pi\)인 것을 주값 \(\text{Arg}\,z\)라 합니다.

곱셈은 지수법칙으로 \(z_1z_2 = r_1r_2e^{i(\theta_1 + \theta_2)}\): 절댓값은 곱하고 편각은 더합니다. 그래서 \(i = e^{i\pi/2}\)를 곱하는 것은 원점 둘레로 90° 돌리는 것입니다.

3.2.2거듭제곱과 거듭제곱근

정리 3.2.1 (드무아브르 공식)

\((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\), 곧 \(z^n = r^ne^{in\theta}\).

거꾸로 \(w^n = z\)인 \(w\)(\(n\)제곱근)는 절댓값이 \(\sqrt[n]r\), 편각이 \(\frac{\theta + 2k\pi}{n}\) (\(k = 0, 1, \dots, n - 1\))입니다. 편각에 \(2\pi\)를 더한 것도 같은 \(z\)이므로, 그것을 \(n\)으로 나누면 서로 다른 \(n\)개의 근이 생깁니다. 이 근들은 원 위에 정\(n\)각형의 꼭짓점으로 고르게 놓입니다.

예제 3.2.2

\(z^3 = 1\)의 근을 모두 구하여라.

풀이. \(1 = e^{i0}\)이므로 근은 \(e^{2k\pi i/3}\), \(k = 0, 1, 2\): \(1\), \(-\frac12 + \frac{\sqrt3}{2}i\), \(-\frac12 - \frac{\sqrt3}{2}i\). 단위원 위의 정삼각형 꼭짓점입니다.

요약
  1. \(z = re^{i\theta}\). 곱셈: 절댓값 곱, 편각 합.
  2. \(z^n = r^ne^{in\theta}\). \(n\)제곱근은 \(n\)개, 정\(n\)각형 꼭짓점.

3.2.3연습문제

기본

  1. \((1 + i)^8\)을 계산하여라.
    답

    \(1 + i = \sqrt2e^{i\pi/4}\). \(16e^{2\pi i} = 16\).

  2. \(i\)의 제곱근을 구하여라.
    답

    \(e^{i\pi/4}\), \(e^{i5\pi/4}\): \(\pm\frac{1 + i}{\sqrt2}\).
