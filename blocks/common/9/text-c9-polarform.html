복소수의 극형식, 거듭제곱과 거듭제곱근

본문

\(z^3 = 1\)의 근은 실수 범위에서는 1 하나뿐이지만, 복소수 범위에서는 셋이다. 나머지 두 근은 어디에 있을까? 3.1절의 \(x + iy\) 꼴로는 곱셈과 거듭제곱의 그림이 잘 보이지 않는데, 복소수를 다른 방식으로 쓰면 곱셈이 간단한 그림이 되지 않을까?

먼저 알아야 할 것복소평면(3.1절), 극좌표(미분적분학(1) 7.3절), 오일러 공식(8.8절)을 쓴다.

3.2.1극형식

처음 질문의 다른 방식은 극좌표이다. 복소평면의 점을 극좌표로 쓰면 \(z = r(\cos\theta + i\sin\theta) = re^{i\theta}\)이며, 이것을 극형식이라 한다. \(r = |z|\)를 절댓값, \(\theta = \arg z\)를 편각이라 한다. 그런데 편각은 \(2\pi\)의 정수배만큼 차이 나도 같은 점을 나타내므로 값이 여러 개이다. 그래서 \(-\pi < \theta \le \pi\)인 것을 주값 \(\text{Arg}\,z\)라 한다.

곱셈은 지수법칙으로 \(z_1z_2 = r_1r_2e^{i(\theta_1 + \theta_2)}\)이다. 즉 절댓값은 곱하고 편각은 더한다. 그러므로 \(i = e^{i\pi/2}\)를 곱하는 것은 원점 둘레로 90° 돌리는 것이다.

3.2.2거듭제곱과 거듭제곱근

정리 3.2.1 (드무아브르 공식)

\((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\), 곧 \(z^n = r^ne^{in\theta}\).

거꾸로 \(w^n = z\)인 \(w\), 곧 \(n\)제곱근은 절댓값이 \(\sqrt[n]r\), 편각이 \(\frac{\theta + 2k\pi}{n}\)(\(k = 0, 1, \dots, n - 1\))이다. 편각에 \(2\pi\)를 더한 것도 같은 \(z\)이므로, 그것을 \(n\)으로 나누면 서로 다른 \(n\)개의 근이 생기기 때문이다. 이 근들은 원 위에 정\(n\)각형의 꼭짓점으로 고르게 놓인다.

예제 3.2.2

\(z^3 = 1\)의 근을 모두 구하여라.

풀이. \(1 = e^{i0}\)이므로 근은 \(e^{2k\pi i/3}\)(\(k = 0, 1, 2\)), 곧 \(1\), \(-\frac12 + \frac{\sqrt3}{2}i\), \(-\frac12 - \frac{\sqrt3}{2}i\)이다. 처음 질문의 두 근은 단위원 위에서 1과 함께 정삼각형의 꼭짓점을 이룬다. 그림 1의 처음 상태가 이 예제이며, \(n\)을 바꾸면 정다각형의 꼭짓점 수가 바뀐다.

마무리

극형식 \(z = re^{i\theta}\)로 쓰면 곱셈은 절댓값을 곱하고 편각을 더하는 것이며, \(z^n = r^ne^{in\theta}\)이다. 처음 질문의 근처럼 \(n\)제곱근은 \(n\)개이고, 원 위에서 정\(n\)각형의 꼭짓점으로 고르게 놓인다.

3.2.3연습문제

기본

  1. \((1 + i)^8\)을 계산하여라.
    답

    \(1 + i = \sqrt2e^{i\pi/4}\). \(16e^{2\pi i} = 16\).

  2. \(i\)의 제곱근을 구하여라.
    답

    \(e^{i\pi/4}\), \(e^{i5\pi/4}\): \(\pm\frac{1 + i}{\sqrt2}\).
