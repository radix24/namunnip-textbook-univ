등각사상으로 Laplace 방정식 문제를 단순한 영역으로 옮기기

해석함수 = 각도 보존 · 조화성 보존 · w = z² · w = log z

원리

  • 등각: 해석함수 \(w = f(z)\)는 \(f'(z_0) \ne 0\)인 점에서 두 곡선 사이의 각도를 보존합니다(06-01 카드: 작은 도형을 회전·확대만 함).
  • 조화성 보존: \(\Phi(w)\)가 \(w\)평면에서 조화함수이면 \(\phi(z) = \Phi(f(z))\)도 \(z\)평면에서 조화함수입니다(\(\Phi\)를 해석함수의 실수부로 쓰고 합성하면 해석함수이므로, 06-02 카드).
  • 방법: 복잡한 영역을 단순한 영역(반평면, 띠, 원판)으로 옮기는 해석함수를 찾고, 단순한 영역에서 Laplace 문제를 푼 뒤 되돌린다. 경계값은 경계와 함께 옮겨집니다.
먼저 예측

두 도체 판이 직각으로 붙어 한쪽은 0 V, 다른 쪽은 100 V일 때(사이가 약간 떨어져 절연됨), 사이 공간의 등전위선은 어떤 모양일까요?

예측 확인

꼭짓점에서 퍼져 나가는 반직선들입니다. 전위는 각도에 비례합니다.

(가) 제1사분면(\(x > 0\), \(y > 0\))에서 \(\phi = 0\) (양의 \(x\)축), \(\phi = 100\) (양의 \(y\)축)인 조화함수를 구하세요. (나) 띠 \(0 < y < \pi\)에서 \(\phi = 0\) (\(y = 0\)), \(\phi = 1\) (\(y = \pi\))인 해와 비교하세요.

풀이

  1. \(w = \log z = \ln r + i\theta\)는 제1사분면(\(0 < \theta < \frac\pi2\))을 띠 \(0 < \text{Im}\,w < \frac\pi2\)로 옮긴다. 양의 \(x\)축(\(\theta = 0\))은 \(\text{Im}\,w = 0\), 양의 \(y\)축은 \(\text{Im}\,w = \frac\pi2\).
    로그는 각도를 높이로 바꾼다(06-03 카드).
  2. 띠에서 아래 0, 위 100인 조화함수는 높이에 비례하는 일차함수: \(\Phi = \frac{100}{\pi/2}\text{Im}\,w = \frac{200}{\pi}\text{Im}\,w\).
    \(\nabla^2\) of 일차함수 = 0. 경계에서 맞음.
  3. 되돌리면 \(\phi = \frac{200}{\pi}\theta = \frac{200}{\pi}\arctan\frac yx\).
    조화성 보존.
  4. (나) 띠는 이미 단순한 영역: \(\phi = \frac y\pi\). (가)는 \(\log z\)로 (나)와 같은 꼴(높이 \(\frac\pi2\))로 옮겨 푼 것.
    등각사상이 문제를 이미 아는 문제로 바꿨다.

의미

등전위선 \(\theta = \)상수(꼭짓점에서 나가는 반직선)와 전기력선 \(r = \)상수(원호)가 직교합니다(06-02 카드). 비행기 날개 둘레의 흐름을 원기둥 둘레 흐름으로 옮기는 주코프스키 변환 \(w = z + \frac1z\)이 등각사상의 고전적 응용으로, 초기 항공 공학에서 양력을 계산하는 데 쓰였습니다.

검산

\(\arctan\frac yx\)의 Laplacian: \(\theta\)는 극좌표에서 \(\frac{1}{r^2}\theta_{\theta\theta} = 0\), \(r\)에 의존하지 않아 지름 항도 0(1-01 카드의 극좌표 Laplacian). 양의 \(x\)축(\(\theta = 0\))에서 0, \(y\)축(\(\theta = \frac\pi2\))에서 100.

흔한 오해

  • 임계점에서 각도 보존: \(f'(z_0) = 0\)인 점에서는 각도가 보존되지 않습니다. \(w = z^2\)은 원점에서 각을 2배로 만들어, 직각(제1사분면)을 평각(위 반평면)으로 폅니다. 이것을 이용해 사분면 문제를 반평면 문제로 옮길 수도 있습니다.
