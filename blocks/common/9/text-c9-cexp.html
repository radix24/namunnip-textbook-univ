복소 지수함수, 삼각함수, 쌍곡선 함수

본문

실수에서 \(\cos x\)는 언제나 −1과 1 사이에 있으므로 \(\cos x = 5\)는 해가 없다. 그런데 복소수 \(z\)에 대해서는 \(\cos z = 5\)인 \(z\)가 무수히 많다. 지수함수와 삼각함수를 복소수로 넓히면 무엇이 그대로이고 무엇이 달라질까?

먼저 알아야 할 것오일러 공식(미분적분학(1) 8.8절)과 코시-리만 방정식(3.4절)을 쓴다.

3.5.1지수함수

정의 3.5.1 (복소 지수함수)

\(z = x + iy\)일 때 \(e^z = e^x(\cos y + i\sin y)\).

\(y = 0\)이면 실수 \(e^x\)이고, \(x = 0\)이면 오일러 공식이다. 그리고 3.4절 연습문제처럼 해석적이며 \((e^z)' = e^z\), \(e^{z_1 + z_2} = e^{z_1}e^{z_2}\)이 성립한다. 이것이 처음 질문의 "그대로인 것"이다.

반면 달라지는 점도 있다. 먼저 \(|e^z| = e^x\), \(\arg e^z = y\)이므로 허수부가 회전을, 실수부가 크기를 정한다. 다음으로 주기가 \(2\pi i\)이어서 \(e^{z + 2\pi i} = e^z\)이다. 그래서 역함수인 로그가 여러 값을 갖는다(3.6절). 끝으로 \(e^z\)는 결코 0이 아니다. 그림 1에서 \(y\)를 \(-\pi\)부터 \(\pi\)까지 움직이면 점이 원을 한 바퀴 돌며, 이것이 주기 \(2\pi i\)이다.

3.5.2삼각함수와 쌍곡선 함수

오일러 공식에서 \(\cos x = \frac{e^{ix} + e^{-ix}}{2}\), \(\sin x = \frac{e^{ix} - e^{-ix}}{2i}\)이므로, 이 식으로 복소 삼각함수를 정의한다.

\[\cos z = \frac{e^{iz} + e^{-iz}}{2}, \quad \sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cosh z = \frac{e^z + e^{-z}}{2}, \quad \sinh z = \frac{e^z - e^{-z}}{2}\]

미분 공식과 덧셈정리는 실수와 같다. 그런데 정의를 비교하면 \(\cos iz = \cosh z\), \(\sin iz = i\sinh z\)이므로, 삼각함수와 쌍곡선 함수가 사실은 같은 함수이다. 그래서 실수에서는 \(|\sin x| \le 1\)이지만, 복소수에서는 \(\cosh\)처럼 얼마든지 커질 수 있다.

예제 3.5.2

\(\cos z = 5\)를 풀어라.

풀이. \(e^{iz} = t\)로 놓으면 \(t + \frac1t = 10\), 곧 \(t^2 - 10t + 1 = 0\)이므로 \(t = 5 \pm\sqrt{24} \approx 9.899, 0.101\)이다. 그러면 \(iz = \ln t + 2n\pi i\)이므로 \(z = 2n\pi \mp 2.292i\)이다(\(\ln9.899 \approx 2.292\)). 즉 처음 질문의 방정식은 실수해는 없지만 복소수해는 무수히 많다.

마무리

\(e^z = e^x(\cos y + i\sin y)\)는 해석적이고 지수법칙이 그대로이지만, 주기 \(2\pi i\)를 가지며 0이 되지 않는다. \(\cos z, \sin z\)는 \(e^{\pm iz}\)로 정의되고 \(\cos iz = \cosh z\)이므로, 처음 질문처럼 크기에 제한이 없다.
