복소 지수함수, 삼각함수, 쌍곡선 함수

본문
이 절에서 배울 것
  • \(e^z\), \(\cos z\), \(\sin z\), \(\cosh z\)를 정의하고 성질을 안다.
  • 실수와 달라지는 점(주기, 크기에 제한 없음)을 이해한다.
먼저 알아야 할 것
  • 오일러 공식 (공통1 8.8절), 코시-리만 방정식 (3.4절).

3.5.1지수함수

정의 3.5.1 (복소 지수함수)

\(z = x + iy\)일 때 \(e^z = e^x(\cos y + i\sin y)\).

\(y = 0\)이면 실수 \(e^x\), \(x = 0\)이면 오일러 공식입니다. 3.4절 연습문제처럼 해석적이고 \((e^z)' = e^z\), \(e^{z_1 + z_2} = e^{z_1}e^{z_2}\)이 성립합니다. 실수와 다른 점은 다음과 같습니다.

  • \(|e^z| = e^x\), \(\arg e^z = y\). 허수부가 회전, 실수부가 크기를 정한다.
  • 주기가 \(2\pi i\)이다: \(e^{z + 2\pi i} = e^z\). 그래서 역함수(로그)가 여러 값을 갖는다(3.6절).
  • \(e^z\)는 결코 0이 아니다.

3.5.2삼각함수와 쌍곡선 함수

오일러 공식에서 \(\cos x = \frac{e^{ix} + e^{-ix}}{2}\), \(\sin x = \frac{e^{ix} - e^{-ix}}{2i}\)이므로, 이 식으로 복소 삼각함수를 정의합니다.

\[\cos z = \frac{e^{iz} + e^{-iz}}{2}, \quad \sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cosh z = \frac{e^z + e^{-z}}{2}, \quad \sinh z = \frac{e^z - e^{-z}}{2}.\]

미분 공식과 덧셈정리는 실수와 같습니다. 정의를 비교하면 \(\cos iz = \cosh z\), \(\sin iz = i\sinh z\)로, 삼각함수와 쌍곡선 함수가 사실은 같은 함수입니다. 실수에서는 \(|\sin x| \le 1\)이지만 복소수에서는 제한이 없습니다.

예제 3.5.2

\(\cos z = 5\)를 풀어라.

풀이. \(e^{iz} = t\)로 놓으면 \(t + \frac1t = 10\), \(t^2 - 10t + 1 = 0\), \(t = 5 \pm\sqrt{24} \approx 9.899, 0.101\). \(iz = \ln t + 2n\pi i\)이므로 \(z = 2n\pi \mp 2.292i\) (\(\ln9.899 \approx 2.292\)). 실수해는 없지만 복소수해는 무수히 많습니다.

요약
  1. \(e^z = e^x(\cos y + i\sin y)\): 해석적, 주기 \(2\pi i\), 0이 아님.
  2. \(\cos z, \sin z\)는 \(e^{\pm iz}\)로 정의. \(\cos iz = \cosh z\). 크기 제한이 없다.
