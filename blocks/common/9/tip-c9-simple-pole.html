단순극의 유수는 \(\frac{p(a)}{q'(a)}\)로 바로 구한다

요령 · 유수

언제 쓰는가

분모를 인수분해하기 번거롭거나 극이 여러 개인 유리함수, 삼각함수 분수의 유수를 구할 때이다.

요령

  1. 극을 찾고 차수 확인
    \(f = \frac pq\)에서 \(q(a) = 0\), \(q'(a) \ne 0\), \(p(a) \ne 0\)이면 단순극이다.
  2. 공식 하나
    \(\text{Res}_{z=a}f = \frac{p(a)}{q'(a)}\). 분모를 미분해 넣기만 하면 된다.
  3. 경로 안의 것만 더한다
    \(\oint_C f\,dz = 2\pi i\sum(\text{경로 안 유수})\).
  4. 차수가 높으면
    \(m\)차 극이면 \(\frac{1}{(m - 1)!}\lim\frac{d^{m-1}}{dz^{m-1}}[(z - a)^mf]\)를 쓴다.

흔한 실수

  • \(\frac{1}{z^2 + 1}\)의 \(z = i\) 유수를 \(\frac{1}{i}\)로 쓰는 것. 분모 미분 \(2z\)를 넣어 \(\frac{1}{2i}\)이다.
  • 2차 극에 단순극 공식을 쓰는 것.

바로 풀어보기

\(\displaystyle\oint\frac{z}{z^2 + 1}dz\)를 (가) \(|z| = 2\) (나) \(|z - i| = 1\) 경로(반시계)에서 구하여라.

답과 풀이

답: (가) \(2\pi i\) (나) \(\pi i\)

극은 \(\pm i\)이고 \(\text{Res} = \frac{z}{2z} = \frac12\)로 둘 다 같다.

(가) 두 극이 모두 안에 있어 \(2\pi i\left(\frac12 + \frac12\right) = 2\pi i\). (나) \(i\)만 안에 있어(\(-i\)는 중심에서 거리 2) \(\pi i\)이다.

이 요령으로 풀리는 문제

  • 급수와 유수 적분 단원 연습 1번, 2번, 6번
영상 콘티 · 40초
  1. 0~5초\(\frac{z}{z^2 + 1}\)과 두 극 \(\pm i\)가 복소평면에 찍힌다.유수를 빨리 구하는 법.
  2. 5~13초분모 \(z^2 + 1\)에 미분 기호가 씌워져 \(2z\)가 되고, 분자 \(z\) 아래로 들어간다.분모를 미분해서 나눈다.
  3. 13~21초\(\frac{z}{2z}\)가 약분되어 \(\frac12\)이 두 극 옆에 깃발로 꽂힌다.두 극 모두 유수 \(\frac12\).
  4. 21~31초큰 원이 두 깃발을 모두 감싸 \(2\pi i\cdot1\), 작은 원 \(|z - i| = 1\)은 깃발 하나만 감싸 \(\pi i\)가 된다.경로 안의 것만 더한다.
  5. 31~40초\(\frac{1}{i}\)로 쓴 답이 나타나 \(2\)가 빠졌다는 표시와 함께 X가 그어진다.분모 미분을 잊지 않는다.
