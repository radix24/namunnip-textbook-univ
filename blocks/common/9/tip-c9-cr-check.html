해석함수인지는 \(u\)와 \(v\)로 나눠 코시-리만 두 식을 확인하고, \(\bar z\)나 \(|z|\)가 보이면 먼저 의심한다

요령 · 코시-리만 방정식

언제 쓰는가

주어진 복소함수가 어디서 미분 가능하고 어디서 해석적인지 판정하는 문제입니다.

요령

  1. \(u\)와 \(v\)로 쓴다
    \(z = x + iy\)를 넣어 \(f = u(x, y) + iv(x, y)\)로 정리합니다.
  2. 두 식을 확인
    \(u_x = v_y\)와 \(u_y = -v_x\)를 모두 만족하는 점의 집합을 구합니다.
  3. 점과 영역을 구별
    두 식이 성립하는 곳이 선이나 점뿐이면 그곳에서 미분 가능할 뿐, 해석적(열린 영역에서 미분 가능)이지는 않습니다.
  4. 빠른 신호
    \(\bar z\), \(|z|\), \(\text{Re}\,z\)가 섞인 함수는 대개 해석적이 아닙니다. \(z\)만의 다항식, 지수, 삼각함수의 조합은 해석적입니다.

흔한 실수

  • \(x^2 + iy^2\)처럼 '다항식이니 해석적'이라고 판단하는 것. \(z\)의 다항식이어야 합니다.
  • 한 점에서 CR 방정식이 성립하니 해석적이라고 하는 것.

바로 풀어보기

\(f(z) = x^2 + y^2 + 2ixy\)가 미분 가능한 점과 해석적인 영역을 구하세요.

답과 풀이

답: 실수축(\(y = 0\)) 위에서만 미분 가능, 해석적인 곳은 없음

\(u = x^2 + y^2\), \(v = 2xy\)입니다. \(u_x = 2x = v_y\)는 언제나 성립하지만, \(u_y = 2y\)와 \(-v_x = -2y\)가 같으려면 \(y = 0\)이어야 합니다.

실수축은 열린 영역을 포함하지 않으므로 어디서도 해석적이 아닙니다. 실제로 \(f = |z|^2 + (z^2 - \bar z^2)/2\)처럼 \(\bar z\)가 섞여 있습니다.

이 요령으로 풀리는 문제

  • 복소수와 복소함수 단원 연습 1번, 2번, 3번, 5번
영상 콘티 · 40초
  1. 0~5초\(f = x^2 + y^2 + 2ixy\)가 나타나고 '다항식이니 해석적?' 말풍선이 뜹니다.정말 그럴까요?
  2. 5~13초식이 실부 \(u\)와 허부 \(v\) 두 상자로 나뉩니다.\(u\)와 \(v\)로 나눕니다.
  3. 13~22초첫째 CR 식 \(u_x = v_y\) 저울은 수평, 둘째 식 \(u_y = -v_x\) 저울은 \(2y\)와 \(-2y\)로 기웁니다.두 식을 모두 봅니다.
  4. 22~31초복소평면 전체가 회색이 되고 실수축만 초록 선으로 남습니다.둘 다 성립하는 곳은 실수축뿐.
  5. 31~40초초록 선 둘레에 작은 원판을 그려 보지만 원판은 선 밖으로 삐져나와 '해석적 아님' 도장이 찍힙니다.선 위의 미분 가능성은 해석성이 아닙니다.
