편미분방정식 모델링 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

식을 세우기 전에 모형의 가정을 한 줄로 적어라.

  1. 계산줄 위에 공기 저항(속도에 비례, 단위 길이당 \(-\gamma u_t\))이 있을 때 파동방정식은 어떻게 바뀌나요? [02-02]

    힌트 1

    02-02 절의 4단계에 힘을 하나 더한다.

    힌트 2

    조각에 작용하는 저항 \(-\gamma u_t\Delta x\).

    풀이

    \(\rho u_{tt} = Tu_{xx} - \gamma u_t\), 곧 \(u_{tt} + \frac\gamma\rho u_t = c^2u_{xx}\) (감쇠 파동방정식, 전신 방정식). 공통8 3-01의 감쇠 진동을 줄 전체로 늘린 것이다.

  2. 계산막대 안에서 단위 부피당 일정한 열 \(Q\) (W/m³)가 생깁니다(전류에 의한 줄열). 열방정식은? [02-05]

    힌트 1

    02-05 절의 에너지 수지에 "안에서 생긴 열"을 더한다.

    힌트 2

    \(\rho cu_t = ku_{xx} + Q\).

    풀이

    \(u_t = \alpha^2u_{xx} + \frac{Q}{\rho c}\). 양 끝 0 ℃이면 정상 상태 \(ku'' = -Q\), \(u = \frac{Q}{2k}x(L - x)\): 가운데가 가장 뜨거운 포물선.

  3. 개념열방정식과 파동방정식은 각각 초기 조건이 몇 개 필요한가요? 그 이유를 시간 미분의 차수로 설명하여라. [02-01]

    힌트 1

    02-01 절.

    힌트 2

    상미분방정식에서 \(n\)계면 초기값 \(n\)개.

    풀이

    열방정식은 \(u_t\) (1계)라 처음 온도 분포 하나, 파동방정식은 \(u_{tt}\) (2계)라 처음 모양과 처음 속도 두 개. 줄을 같은 모양으로 놓아도 처음에 튕기는지(속도)에 따라 운동이 다르다.

  4. 판단한 학생이 "양 끝이 단열된 막대에 처음 온도가 \(u(x, 0) = x\) (\(0 \le x \le 1\))이면 오래 지나 막대 전체가 0 ℃가 된다"고 했다. 맞나요? [02-01]

    힌트 1

    단열이면 열이 빠져나갈 수 있나요?

    힌트 2

    총 열량 \(\int_0^1u\,dx\)가 보존된다.

    풀이

    틀렸다. 열이 빠져나가지 않아 평균 온도가 보존되므로 \(\int_0^1x\,dx = \frac12\), 곧 막대 전체가 0.5 ℃가 된다. 0 ℃로 가는 것은 양 끝을 0 ℃로 고정한(Dirichlet) 경우이다. 확인: \(\frac{d}{dt}\int u\,dx = \alpha^2\int u_{xx}dx = \alpha^2[u_x]_0^1 = 0\).

  5. 계산길이 0.65 m, 장력 80 N, 선밀도 \(1.2\times10^{-3}\) kg/m인 줄의 파속과 기본 진동수를 구하세요(양 끝 고정). [02-02]

    힌트 1

    \(c = \sqrt{T/\rho}\).

    힌트 2

    기본 진동수 \(\frac{c}{2L}\).

    풀이

    \(c = \sqrt{66667} = 258\) m/s, \(f_1 = \frac{258}{1.30} = 199\) Hz (G3 근처). 4단원의 변수분리로 이 식을 유도한다.

  6. 판단"열방정식은 시간을 거꾸로 돌려도 똑같이 성립하니, 지금의 온도 분포에서 1시간 전 분포를 정확히 계산할 수 있다." 맞나요? [02-05, 02-01]

    힌트 1

    \(t \to -t\)로 바꾸면 \(u_t = -\alpha^2u_{xx}\)가 된다.

    힌트 2

    Fourier 성분 \(e^{-n^2\alpha^2t}\)를 거꾸로 돌리면?

    풀이

    틀렸다. 시간을 뒤집으면 부호가 바뀌어 다른 방정식이 된다. 각 성분 \(e^{-n^2t}\)를 거꾸로 돌리면 \(e^{n^2t}\)로 높은 진동수일수록 폭발적으로 커져, 지금의 아주 작은 측정 오차가 과거 추정에서 엄청나게 커집니다(잘 놓이지 않은 문제). 열의 확산은 비가역이다.
