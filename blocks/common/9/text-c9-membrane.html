직사각형 막의 진동과 이중 푸리에 급수

본문
이 절에서 배울 것
  • 2차원 파동방정식 \(u_{tt} = c^2(u_{xx} + u_{yy})\)을 세 변수로 변수분리해 푼다.
  • 고유 진동수와 마디선을 이해하고, 이중 푸리에 급수로 계수를 구한다.
먼저 알아야 할 것
  • 변수분리와 푸리에 급수 해 (2.3절), 이중적분 (공통2 6단원).

2.7.1막의 방정식

가로 \(a\), 세로 \(b\)인 직사각형 틀에 팽팽하게 당긴 막(북 가죽)의 높이 \(u(x, y, t)\)는 줄의 경우를 2차원으로 넓힌 식을 만족합니다.

\[u_{tt} = c^2(u_{xx} + u_{yy}), \qquad u = 0 \text{ (테두리)}.\]

\(u = F(x, y)G(t)\), 다시 \(F = H(x)Q(y)\)로 나누면 \(H'' + k^2H = 0\), \(Q'' + p^2Q = 0\), \(G'' + \lambda^2G = 0\) (\(\lambda^2 = c^2(k^2 + p^2)\))이 됩니다. 테두리 조건에서 \(k = \frac{m\pi}{a}\), \(p = \frac{n\pi}{b}\)이므로

\[F_{mn} = \sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}, \qquad \lambda_{mn} = c\pi\sqrt{\frac{m^2}{a^2} + \frac{n^2}{b^2}}.\]

\((m, n)\) 고유 진동에서는 막이 \(m \times n\)개의 칸으로 나뉘어 이웃한 칸이 반대 방향으로 움직이고, 칸 사이의 선(마디선)은 움직이지 않습니다. 진동수 \(\lambda_{mn}\)은 일반적으로 기본 진동수의 정수배가 아니므로, 북소리는 현악기처럼 조화롭게 들리지 않습니다. 정사각형 막에서는 \((1, 2)\)와 \((2, 1)\)처럼 다른 모양이 같은 진동수를 가지기도 합니다.

2.7.2이중 푸리에 급수

처음 모양이 \(f(x, y)\)이고 처음 속도가 0이면 \(u = \sum_m\sum_nB_{mn}\cos\lambda_{mn}t\,F_{mn}\)이고, \(t = 0\)에서 \(f = \sum\sum B_{mn}\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}\)입니다(이중 푸리에 급수). 직교성을 두 방향으로 쓰면

\[B_{mn} = \frac{4}{ab}\int_0^b\int_0^af(x, y)\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}\,dx\,dy.\]
요약
  1. 세 변수로 변수분리 → 고유함수 \(\sin\frac{m\pi x}{a}\sin\frac{n\pi y}{b}\), 진동수 \(\lambda_{mn}\).
  2. 계수는 이중 푸리에 급수(이중적분)로 구한다.

2.7.3연습문제

기본
