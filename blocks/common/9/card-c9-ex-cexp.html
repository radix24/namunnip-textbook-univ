코사인 값이 1보다 클 수 있을까?

예제 · 복소 지수함수와 삼각함수

\(e^{1 + i\pi/2}\), \(\cos i\), \(\sin\left(\tfrac\pi2 + i\right)\)를 구하고, \(e^z = -1\)과 \(\cos z = 2\)의 해를 모두 구하세요.

전략

\(e^{x + iy} = e^x(\cos y + i\sin y)\)이고, 삼각함수는 \(\cos z = \dfrac{e^{iz} + e^{-iz}}2\), \(\sin z = \dfrac{e^{iz} - e^{-iz}}{2i}\)로 정의합니다. 방정식은 \(e^z\)의 크기와 각으로 나누어 풉니다.

풀이

  1. \(e^{1 + i\pi/2} = e(\cos\tfrac\pi2 + i\sin\tfrac\pi2) = ei \approx 2.718i\).
    오일러 공식.
  2. \(\cos i = \dfrac{e^{-1} + e^{1}}2 = \cosh1 \approx 1.543\).
    \(iz = i\cdot i = -1\).
  3. \(\sin(x + iy) = \sin x\cosh y + i\cos x\sinh y\)이므로 \(\sin(\tfrac\pi2 + i) = \cosh1 \approx 1.543\).
    덧셈 정리.
  4. \(e^z = -1\): \(e^x = 1\), \(y = \pi + 2k\pi\), 곧 \(z = (2k + 1)\pi i\). \(\cos z = 2\): \(w = e^{iz}\)로 \(w + 1/w = 4\), \(w = 2 \pm\sqrt3\), \(iz = \ln(2 \pm\sqrt3) + 2k\pi i\), \(z = 2k\pi \mp i\ln(2 + \sqrt3) \approx 2k\pi \mp 1.317i\).
    \(\ln(2 - \sqrt3) = -\ln(2 + \sqrt3)\).

의미

실수에서는 \(|\cos x| \le 1\)이지만 복소수에서는 \(\cos(iy) = \cosh y\)라 한없이 커집니다. 복소 삼각함수는 쌍곡선 함수와 같은 함수를 90° 돌려 본 것입니다. 또 \(e^z\)는 주기 \(2\pi i\)를 가지므로 \(e^z = w\)의 해가 무수히 많고, 이것이 복소 로그가 여러 값인 이유입니다(3.6절).

검산

\(\cos^2z + \sin^2z = 1\)은 복소수에서도 성립합니다. \(z = i\): \(\cosh^21 + (i\sinh1)^2 = \cosh^21 - \sinh^21 = 1\). 맞습니다.

바꿔 보기

\(|e^{iy}| = 1\)이므로 \(e^{iy}\)는 단위원 위를 돌고, \(e^x\)가 크기를 정합니다. \(e^z\)는 수평선을 원점에서 나가는 반직선으로, 수직선을 원으로 옮깁니다(6.3절).

이해 확인

\(\sin z = 0\)의 해가 실수 \(k\pi\)뿐임을 보이세요.

답

\(\sin x\cosh y = 0\)과 \(\cos x\sinh y = 0\). \(\cosh y \ge 1\)이므로 \(\sin x = 0\), 그러면 \(\cos x = \pm1\)이라 \(\sinh y = 0\), \(y = 0\).
