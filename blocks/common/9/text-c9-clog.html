복소 로그와 일반 거듭제곱

본문

실수에서는 음수의 로그가 없었다. 그런데 복소수에서는 \(\ln(-1) = \pi i\)이고, \(i^i\)는 놀랍게 보일 만큼 실수이다. 게다가 \(\ln(-1)\)의 값은 하나가 아니라 무수히 많다. 복소 로그는 왜 여러 값을 가지며, 그중 하나를 골라 함수로 쓰려면 무엇을 포기해야 할까?

먼저 알아야 할 것복소 지수함수(3.5절)와 극형식과 편각(3.2절)을 쓴다.

3.6.1로그는 지수의 역함수

\(e^w = z\)인 \(w\)를 \(\ln z\)라 한다. \(z = re^{i\theta}\), \(w = u + iv\)로 놓으면 \(e^ue^{iv} = re^{i\theta}\)이므로 \(e^u = r\), \(v = \theta + 2n\pi\)이다. 따라서 다음과 같다.

\[\ln z = \ln|z| + i\arg z = \ln r + i(\theta + 2n\pi), \quad n = 0, \pm1, \pm2, \dots\]

처음 질문의 까닭이 여기 있다. \(e^z\)의 주기가 \(2\pi i\)이기 때문에(3.5절) 로그의 값이 \(2\pi i\)씩 차이 나며 무수히 많다. 그래서 편각의 주값을 쓴 것을 로그의 주값 \(\text{Ln}\,z = \ln|z| + i\,\text{Arg}\,z\)(\(-\pi < \text{Arg}\,z \le \pi\))라 한다.

예제 3.6.1

\(\ln(-1)\)과 \(\ln i\)를 구하여라.

풀이. \(-1 = e^{i\pi}\)이므로 \(\ln(-1) = i(\pi + 2n\pi)\)이고 주값은 \(\pi i\)이다. 실수에서는 음수의 로그가 없었지만 복소수에서는 있다. 또 \(i = e^{i\pi/2}\)이므로 \(\ln i = i\left(\frac\pi2 + 2n\pi\right)\)이고 주값은 \(\frac{\pi i}{2}\)이다.

그런데 주값을 고르는 대가가 있다. \(\text{Ln}\,z\)는 편각이 \(\pi\)에서 \(-\pi\)로 뛰는 음의 실수축을 뺀 영역에서만 해석적이며, 그 영역에서 \((\text{Ln}\,z)' = \frac1z\)이다. 이 음의 실수축을 자른 선(branch cut)이라 부른다. 처음 질문의 "포기해야 할 것"이 이 선 위의 연속성이다. 그림 1에서 점을 180° 넘게 돌리면 주값이 \(\pi\)에서 \(-\pi\)로 떨어진다.

3.6.2일반 거듭제곱

\(z^c = e^{c\ln z}\)로 정의한다. 그런데 로그가 여러 값을 가지므로 \(z^c\)도 일반적으로 여러 값이다.

예제 3.6.2

\(i^i\)를 구하여라.

풀이. \(i^i = e^{i\ln i} = e^{i\cdot i(\pi/2 + 2n\pi)} = e^{-\pi/2 - 2n\pi}\)이다. 즉 값이 모두 실수이며, 주값은 \(e^{-\pi/2} \approx 0.2079\)이다.

마무리

\(\ln z = \ln|z| + i(\text{Arg}\,z + 2n\pi)\)는 지수함수의 주기 \(2\pi i\) 때문에 값이 무수히 많으며, 처음 질문처럼 하나를 골라 주값 \(\text{Ln}\,z\)로 쓰면 자른 선 위에서 연속성을 잃는다. \(z^c = e^{c\ln z}\)도 여러 값을 가질 수 있다.
