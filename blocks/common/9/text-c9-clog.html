복소 로그와 일반 거듭제곱

본문
이 절에서 배울 것
  • 복소 로그가 여러 값을 갖는 이유를 알고 주값 \(\text{Ln}\,z\)를 구한다.
  • \(z^c = e^{c\ln z}\)로 일반 거듭제곱을 계산한다.
먼저 알아야 할 것
  • 복소 지수함수 (3.5절), 극형식과 편각 (3.2절).

3.6.1로그는 지수의 역함수

\(e^w = z\)인 \(w\)를 \(\ln z\)라 합니다. \(z = re^{i\theta}\), \(w = u + iv\)로 놓으면 \(e^ue^{iv} = re^{i\theta}\)이므로 \(e^u = r\), \(v = \theta + 2n\pi\)입니다.

\[\ln z = \ln|z| + i\arg z = \ln r + i(\theta + 2n\pi), \quad n = 0, \pm1, \pm2, \dots\]

\(e^z\)의 주기가 \(2\pi i\)이기 때문에(3.5절) 로그의 값이 \(2\pi i\)씩 차이 나며 무수히 많습니다. 편각의 주값을 쓴 것을 주값 \(\text{Ln}\,z = \ln|z| + i\,\text{Arg}\,z\) (\(-\pi < \text{Arg}\,z \le \pi\))라 합니다.

예제 3.6.1

\(\ln(-1)\)과 \(\ln i\)를 구하여라.

풀이. \(-1 = e^{i\pi}\): \(\ln(-1) = i(\pi + 2n\pi)\), 주값 \(\pi i\). 실수에서는 음수의 로그가 없었지만 복소수에서는 있습니다. \(i = e^{i\pi/2}\): \(\ln i = i\left(\frac\pi2 + 2n\pi\right)\), 주값 \(\frac{\pi i}{2}\).

\(\text{Ln}\,z\)는 음의 실수축(편각이 \(\pi\)에서 \(-\pi\)로 뛰는 곳)을 뺀 영역에서 해석적이고 \((\text{Ln}\,z)' = \frac1z\)입니다. 음의 실수축을 "자른 선"(branch cut)이라 부릅니다.

3.6.2일반 거듭제곱

\(z^c = e^{c\ln z}\)로 정의합니다. 로그가 여러 값을 가지므로 \(z^c\)도 일반적으로 여러 값입니다.

예제 3.6.2

\(i^i\)를 구하여라.

풀이. \(i^i = e^{i\ln i} = e^{i\cdot i(\pi/2 + 2n\pi)} = e^{-\pi/2 - 2n\pi}\). 모두 실수입니다! 주값은 \(e^{-\pi/2} \approx 0.2079\).

요약
  1. \(\ln z = \ln|z| + i(\text{Arg}\,z + 2n\pi)\): 값이 무수히 많다. 주값 \(\text{Ln}\,z\).
  2. \(z^c = e^{c\ln z}\)도 여러 값을 가질 수 있다.
