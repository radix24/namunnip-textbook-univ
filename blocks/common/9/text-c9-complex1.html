복소수와 복소평면

본문
이 절에서 배울 것
  • 복소수의 사칙연산과 켤레복소수를 다시 정리한다.
  • 복소수를 평면의 점(벡터)으로 보고 덧셈과 절댓값을 그림으로 이해한다.
먼저 알아야 할 것
  • 복소수 \(i^2 = -1\)과 사칙연산 (고교 수학), 벡터의 덧셈 (공통1 9.2절).

3.1.1복소수의 계산

복소수 \(z = x + iy\)에서 \(x = \text{Re}\,z\)를 실수부, \(y = \text{Im}\,z\)를 허수부라 합니다. 계산은 \(i^2 = -1\)만 기억하면 다항식처럼 합니다.

  • 덧셈: \((x_1 + iy_1) + (x_2 + iy_2) = (x_1 + x_2) + i(y_1 + y_2)\).
  • 곱셈: \((x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)\).
  • 켤레: \(\bar z = x - iy\). \(z\bar z = x^2 + y^2\)은 언제나 0 이상의 실수.
  • 나눗셈: 분모의 켤레를 분자와 분모에 곱한다. \(\frac{z_1}{z_2} = \frac{z_1\bar z_2}{|z_2|^2}\).
예제 3.1.1

\(z_1 = 8 + 3i\), \(z_2 = 9 - 2i\)일 때 \(z_1z_2\)와 \(\frac{z_1}{z_2}\)를 구하여라.

풀이. \(z_1z_2 = 72 - 16i + 27i - 6i^2 = 78 + 11i\). \(\frac{z_1}{z_2} = \frac{(8 + 3i)(9 + 2i)}{81 + 4} = \frac{66 + 43i}{85}\).

3.1.2복소평면

\(z = x + iy\)를 평면의 점 \((x, y)\)에 대응시키면 복소수를 그림으로 볼 수 있습니다. 가로축이 실수축, 세로축이 허수축인 이 평면을 복소평면이라 합니다.

  • 덧셈은 벡터의 덧셈(평행사변형)과 같다.
  • \(|z| = \sqrt{x^2 + y^2}\)은 원점까지의 거리, \(|z_1 - z_2|\)는 두 점 사이의 거리.
  • 켤레 \(\bar z\)는 실수축에 대한 대칭점.
  • 삼각부등식 \(|z_1 + z_2| \le |z_1| + |z_2|\).

그래서 \(|z - 2| < 1\)은 "2에서 거리 1 미만", 곧 중심 2, 반지름 1인 원판의 안쪽입니다. 복소함수에서 영역을 말할 때 이런 식을 계속 씁니다.

요약
  1. 계산은 \(i^2 = -1\)로, 나눗셈은 켤레를 곱한다.
  2. 복소평면: 덧셈은 벡터 합, \(|z|\)는 거리, \(\bar z\)는 대칭.

3.1.3연습문제

기본

  1. \(\frac{1 + i}{1 - i}\)을 계산하여라.
    답

    \(\frac{(1 + i)^2}{2} = \frac{2i}{2} = i\).

  2. \(|z + i| \le 2\)는 복소평면에서 어떤 영역인가?
    답

    중심 \(-i\), 반지름 2인 닫힌 원판.
