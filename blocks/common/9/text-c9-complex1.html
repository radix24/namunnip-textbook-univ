복소수와 복소평면

본문

고교에서 복소수는 \(i^2 = -1\)을 쓰는 계산 규칙으로 배웠다. 그런데 복소수 하나는 실수 두 개로 이루어지므로, 평면 위의 점으로 볼 수도 있다. 복소수를 점으로 보면 덧셈, 절댓값, 켤레는 각각 어떤 그림이 될까?

먼저 알아야 할 것복소수 \(i^2 = -1\)과 사칙연산(고교 수학)과 벡터의 덧셈(미분적분학(1) 9.2절)을 쓴다.

3.1.1복소수의 계산

복소수 \(z = x + iy\)에서 \(x = \text{Re}\,z\)를 실수부, \(y = \text{Im}\,z\)를 허수부라 한다. 계산은 \(i^2 = -1\)만 기억하면 다항식처럼 한다. 덧셈은 \((x_1 + iy_1) + (x_2 + iy_2) = (x_1 + x_2) + i(y_1 + y_2)\)이고, 곱셈은 \((x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)\)이다.

또 \(\bar z = x - iy\)를 켤레복소수라 하며, \(z\bar z = x^2 + y^2\)은 언제나 0 이상의 실수이다. 그래서 나눗셈은 분모의 켤레를 분자와 분모에 곱해 \(\frac{z_1}{z_2} = \frac{z_1\bar z_2}{|z_2|^2}\)로 계산한다.

예제 3.1.1

\(z_1 = 8 + 3i\), \(z_2 = 9 - 2i\)일 때 \(z_1z_2\)와 \(\frac{z_1}{z_2}\)를 구하여라.

풀이. \(z_1z_2 = 72 - 16i + 27i - 6i^2 = 78 + 11i\)이다. 또 \(\frac{z_1}{z_2} = \frac{(8 + 3i)(9 + 2i)}{81 + 4} = \frac{66 + 43i}{85}\)이다.

3.1.2복소평면

처음 질문처럼 \(z = x + iy\)를 평면의 점 \((x, y)\)에 대응시키면 복소수를 그림으로 볼 수 있다. 가로축이 실수축, 세로축이 허수축인 이 평면을 복소평면이라 한다.

그러면 덧셈은 벡터의 덧셈, 곧 평행사변형의 대각선과 같다. 또 \(|z| = \sqrt{x^2 + y^2}\)은 원점까지의 거리이고, \(|z_1 - z_2|\)는 두 점 사이의 거리이다. 켤레 \(\bar z\)는 실수축에 대한 대칭점이다. 그리고 삼각형의 두 변의 합이 나머지 한 변보다 길므로 삼각부등식 \(|z_1 + z_2| \le |z_1| + |z_2|\)가 성립한다. 그림 1에서 \(z_2\)를 움직이면 이 관계를 모두 볼 수 있다.

그래서 \(|z - 2| < 1\)은 "2에서 거리 1 미만", 곧 중심 2, 반지름 1인 원판의 안쪽이다. 복소함수에서 영역을 말할 때 이런 식을 계속 쓴다.

마무리

복소수 계산은 \(i^2 = -1\)로 하고, 나눗셈은 분모의 켤레를 곱한다. 처음 질문처럼 복소평면에서 보면 덧셈은 벡터 합, \(|z|\)는 거리, \(\bar z\)는 실수축 대칭이며, 이 그림으로 원판 같은 영역을 식으로 나타낸다.

3.1.3연습문제

기본

  1. \(\frac{1 + i}{1 - i}\)을 계산하여라.
    답

    \(\frac{(1 + i)^2}{2} = \frac{2i}{2} = i\).

  2. \(|z + i| \le 2\)는 복소평면에서 어떤 영역인가?
    답

    중심 \(-i\), 반지름 2인 닫힌 원판.
