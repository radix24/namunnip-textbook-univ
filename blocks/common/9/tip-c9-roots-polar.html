복소수의 거듭제곱근과 로그는 극형식으로 바꾸고 각에 \(2\pi k\)를 더한다

요령 · 거듭제곱근

언제 쓰는가

\(z^n = w\)의 해를 모두 구하거나, 복소 로그·복소 거듭제곱의 값을 구하는 문제이다.

요령

  1. 극형식으로
    \(w = re^{i\theta}\). 각은 그림을 그려 사분면을 확인하고 정한다.
  2. \(2\pi k\)를 붙인다
    \(w = re^{i(\theta + 2\pi k)}\)로 써 두면 숨은 해가 드러난다.
  3. \(n\)제곱근
    \(z_k = r^{1/n}e^{i(\theta + 2\pi k)/n}\), \(k = 0, 1, \dots, n - 1\). 해는 원 위에 같은 간격으로 \(n\)개이다.
  4. 로그는 무한히 많은 값
    \(\log w = \ln r + i(\theta + 2\pi k)\). 주값은 \(-\pi < \theta \le \pi\)인 것 하나이다.

흔한 실수

  • 실수처럼 해를 하나만 구하는 것.
  • \(-8i\)의 각을 \(\frac{3\pi}{2}\)와 \(-\frac\pi2\) 사이에서 헷갈려 주값을 잘못 쓰는 것. 해 집합은 같지만 주값은 \(-\frac\pi2\)이다.

바로 풀어보기

\(z^3 = -8i\)의 해를 모두 구하여라.

답과 풀이

답: \(\sqrt3 - i\), \(2i\), \(-\sqrt3 - i\)

\(-8i = 8e^{i(-\pi/2 + 2\pi k)}\)이므로 \(z_k = 2e^{i(-\pi/6 + 2\pi k/3)}\)이다.

\(k = 0\): \(2e^{-i\pi/6} = \sqrt3 - i\). \(k = 1\): \(2e^{i\pi/2} = 2i\). \(k = 2\): \(2e^{i7\pi/6} = -\sqrt3 - i\). 검산: \((2i)^3 = -8i\).

이 요령으로 풀리는 문제

  • 복소수와 복소함수 단원 연습 4번, 6번
영상 콘티 · 40초
  1. 0~5초복소평면 위 \(-8i\)에 점이 찍힌다.세제곱해서 이 점이 되는 수는?
  2. 5~13초원점에서 그 점까지 화살표가 그려지고 길이 8, 각 \(-\frac\pi2\)가 표시된다.극형식으로 바꾼다.
  3. 13~22초화살표가 한 바퀴, 두 바퀴 더 돌아도 같은 점에 닿으며 각에 \(+2\pi\), \(+4\pi\)가 붙는다.각에는 \(2\pi k\)가 숨어 있다.
  4. 22~32초세 각이 각각 3으로 나뉘어, 반지름 2인 원 위에 120° 간격으로 점 세 개가 찍힌다.나누면 원 위에 같은 간격으로 퍼진다.
  5. 32~40초세 점이 각각 세제곱되며 모두 \(-8i\)로 날아가 겹친다.세 개 모두 해이다.
