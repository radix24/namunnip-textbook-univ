등각사상

본문
이 절에서 배울 것
  • 복소함수를 \(z\)평면에서 \(w\)평면으로 옮기는 사상으로 본다.
  • \(f'(z_0) \ne 0\)인 점에서 해석함수가 각의 크기와 방향을 보존함(등각)을 안다.
먼저 알아야 할 것
  • 극형식과 곱셈의 회전 (3.2절), 해석함수 (3.3절).

6.1.1사상으로 보기

3.3절에서 말한 것처럼 \(w = f(z)\)는 그래프를 그릴 수 없으므로, \(z\)평면의 곡선이나 영역이 \(w\)평면의 어디로 옮겨지는지(사상, mapping)를 봅니다.

예제 6.1.1

\(w = z^2\)은 1사분면과 원 \(|z| = 2\)를 어디로 옮기는가?

풀이. 극형식 \(z = re^{i\theta}\)에서 \(w = r^2e^{2i\theta}\): 거리는 제곱, 각은 두 배입니다.

  • 1사분면(\(0 < \theta < \frac\pi2\)) → \(0 < \arg w < \pi\), 곧 위쪽 반평면.
  • 원 \(|z| = 2\) → 원 \(|w| = 4\) (두 바퀴 감는다).

6.1.2각을 보존한다

\(z_0\) 근처에서 \(f(z) \approx f(z_0) + f'(z_0)(z - z_0)\)입니다. \(z_0\)에서 나가는 작은 화살표 \(z - z_0\)는 \(f'(z_0)\)을 곱한 화살표로 옮겨지는데, 복소수의 곱셈은 "크기 \(|f'(z_0)|\)배, 회전 \(\arg f'(z_0)\)"입니다(3.2절). \(z_0\)에서 나가는 모든 화살표가 같은 각만큼 돌아가므로, 두 곡선 사이의 각은 그대로 유지됩니다.

정리 6.1.2

\(f\)가 해석적이고 \(f'(z_0) \ne 0\)이면 \(w = f(z)\)는 \(z_0\)에서 두 곡선이 이루는 각의 크기와 방향을 보존한다(등각사상).

\(f'(z_0) = 0\)인 점(임계점)에서는 성립하지 않습니다. 예제 6.1.1의 \(w = z^2\)은 \(z = 0\)에서 \(f' = 0\)이고, 실제로 직각(1사분면의 모서리)이 평각(반평면)으로 두 배가 되었습니다.

예제 6.1.3

\(w = z^2\)으로 직선 \(x = 1\)과 \(y = 1\)의 상을 구하고, 교점에서 각을 비교하여라.

풀이. \(u = x^2 - y^2\), \(v = 2xy\). \(x = 1\): \(u = 1 - y^2\), \(v = 2y\)에서 \(u = 1 - \frac{v^2}{4}\). \(y = 1\): \(u = x^2 - 1\), \(v = 2x\)에서 \(u = \frac{v^2}{4} - 1\). 두 포물선이 \(w = 2i\)(곧 \(z = 1 + i\)의 상)에서 만납니다. 기울기 \(\frac{du}{dv}\)가 \(-1\)과 \(1\)이므로 직각으로 만나며, 원래 두 직선이 직각이었던 것과 같습니다.

요약
  1. 복소함수는 평면에서 평면으로의 사상으로 본다.
  2. 해석적이고 \(f' \ne 0\)이면 각을 보존한다. 국소적으로 \(|f'|\)배 확대, \(\arg f'\) 회전.

6.1.3연습문제

기본

  1. \(w = iz\)는 어떤 사상인가?
    답

    원점 둘레로 90° 회전.

  2. \(w = z^3\)이 등각이 아닌 점은?
    답

    \(f' = 3z^2 = 0\)인 \(z = 0\).
