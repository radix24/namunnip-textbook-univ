특이점 근처에서는 음의 거듭제곱까지 써야 할까?

예제 · 로랑 급수

\(f(z) = \dfrac1{z(z - 1)}\)을 (가) \(0 < |z| < 1\) (나) \(|z| > 1\)에서 \(z\)의 거듭제곱 급수로 전개하여라.

전략

부분분수 \(f = \dfrac1{z - 1} - \dfrac1z\)로 나눈 뒤, \(\dfrac1{z - 1}\)을 등비급수로 쓴다. 등비급수는 공비의 절댓값이 1보다 작아야 하므로, \(|z| < 1\)이면 \(z\)를, \(|z| > 1\)이면 \(1/z\)을 공비로 잡는다.

풀이

  1. \(\dfrac1{z(z - 1)} = \dfrac1{z - 1} - \dfrac1z\).
    부분분수.
  2. (가) \(\dfrac1{z - 1} = -\dfrac1{1 - z} = -\sum_{n\ge0}z^n\)이므로 \(f = -\dfrac1z - 1 - z - z^2 - \cdots\).
    공비 \(z\), \(|z| < 1\).
  3. (나) \(\dfrac1{z - 1} = \dfrac1z\cdot\dfrac1{1 - 1/z} = \sum_{n\ge0}z^{-n-1}\)이므로 \(f = \dfrac1{z^2} + \dfrac1{z^3} + \cdots\).
    공비 \(1/z\), \(|z| > 1\). \(1/z\) 항은 지워짐.

의미

같은 함수라도 영역(고리)에 따라 전개가 다르다. (가)의 음의 거듭제곱 부분 \(-1/z\)이 주부이고, \(1/z\)의 계수 \(-1\)이 \(z = 0\)에서의 유수이다. 유수 하나만 알면 \(z = 0\)을 도는 적분이 \(2\pi i\cdot(-1)\)입니다(5.4절).

검산

(나)에서 \(z = 2\): \(f(2) = \tfrac12\), 급수 \(\tfrac14 + \tfrac18 + \cdots = \tfrac12\). (가)에서 \(z = \tfrac12\): \(f = -4\), 급수 \(-2 - 1 - \tfrac12 - \tfrac14 - \cdots = -2 - 2 = -4\). 맞다.

바꿔 보기

\(z = 1\) 근처(\(0 < |z - 1| < 1\))에서 전개하려면 \(w = z - 1\)로 두고 \(\dfrac1{z} = \dfrac1{1 + w} = \sum(-w)^n\)을 쓴다. 그러면 \(f = \dfrac1w - 1 + w - \cdots\), \(z = 1\)에서의 유수는 1이다.

이해 확인

\(\dfrac{e^z}{z^2}\)의 \(z = 0\) 근처 로랑 급수의 처음 세 항과 유수를 구하여라.

답

\(\dfrac1{z^2} + \dfrac1z + \dfrac12 + \cdots\), 유수 1.
