경계값이 0이 아니면 정상 상태를 먼저 빼서 경계를 0으로 만든다

요령 · 비동차 경계 조건

언제 쓰는가

막대의 양 끝 온도가 0이 아닌 상수로 유지되는 열방정식 문제이다. 그대로 변수분리하면 고유함수가 경계 조건을 만족하지 않아 막힌다.

요령

  1. 정상 상태를 구한다
    시간이 지나도 변하지 않는 해 \(u_s(x)\)는 \(u_s'' = 0\)이므로 양 끝 값을 잇는 직선이다.
  2. 빼서 새 문제
    \(v = u - u_s\)로 두면 \(v\)의 경계값은 0이고, 처음 값은 \(u(x, 0) - u_s(x)\)이다.
  3. \(v\)를 변수분리
    보통의 사인 급수로 푼다.
  4. 다시 더한다
    \(u = u_s + v\). 시간이 지나면 \(v \to 0\)이라 \(u \to u_s\)이다.

흔한 실수

  • 처음 값에서 정상 상태를 빼지 않고 원래 처음 값으로 계수를 구하는 것.
  • 정상 상태를 양 끝 온도의 평균인 상수로 두는 것.

바로 풀어보기

\(u_t = u_{xx}\) (\(0 < x < 1\)), \(u(0, t) = 20\), \(u(1, t) = 50\), \(u(x, 0) = 20\)을 풀어라. \(t = 0.05\)에서 가운데 온도를 어림하여라.

답과 풀이

답: \(u = 20 + 30x + \sum\frac{60(-1)^n}{n\pi}e^{-n^2\pi^2t}\sin n\pi x\). 가운데는 약 23.4

정상 상태 \(u_s = 20 + 30x\). \(v = u - u_s\)의 처음 값은 \(-30x\)이고, \(b_n = 2\int_0^1(-30x)\sin n\pi x\,dx = \frac{60(-1)^n}{n\pi}\)이다.

\(x = \frac12\), \(t = 0.05\): 정상 상태 35에 \(n = 1\) 항 \(-\frac{60}{\pi}e^{-0.493} \approx -11.7\)을 더하고, \(n = 3\) 항(+0.08)은 아주 작아 약 23.4이다.

이 요령으로 풀리는 문제

  • 편미분방정식(모형) 단원 연습 4번
영상 콘티 · 45초
  1. 0~5초막대 왼쪽 끝은 20, 오른쪽 끝은 50으로 고정되고, 처음에는 막대 전체가 20이다.끝이 0이 아니면 어떻게 풀까?
  2. 5~13초고유함수 사인 곡선을 그대로 대 보지만 오른쪽 끝에서 50에 닿지 못해 X가 뜬다.그대로는 경계를 맞출 수 없다.
  3. 13~22초양 끝을 잇는 직선 \(20 + 30x\)가 그려지고 '정상 상태' 이름표가 붙는다.먼저 오래 뒤의 모습을 구한다.
  4. 22~32초온도 곡선에서 직선을 빼자 양 끝이 0으로 내려앉은 곡선 \(-30x\)이 남는다.빼면 경계가 0이 된다.
  5. 32~45초\(v\)가 사인 급수로 풀려 점점 납작해지고, 다시 직선 위에 얹혀 \(u\)가 직선으로 다가가는 모습이 재생된다.풀고 나서 다시 더한다.
