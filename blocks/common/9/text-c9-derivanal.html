해석함수의 도함수

본문
이 절에서 배울 것
  • 해석함수는 몇 번이든 미분 가능하다는 것과 그 공식을 안다.
  • \(\oint\frac{f}{(z - z_0)^{n+1}}dz\) 꼴의 적분을 계산한다.
먼저 알아야 할 것
  • 코시 적분 공식 (4.3절).

4.4.1공식

코시 적분 공식 \(f(z_0) = \frac{1}{2\pi i}\oint\frac{f(z)}{z - z_0}dz\)를 \(z_0\)으로 미분하면, 적분 안에서 \(\frac{1}{z - z_0}\)만 미분되어 \(\frac{1}{(z - z_0)^2}\)이 됩니다. 계속 미분하면

정리 4.4.1

\(f\)가 해석적이면 모든 계의 도함수가 존재하고 해석적이며

\[f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C\frac{f(z)}{(z - z_0)^{n+1}}dz.\]

실수 함수는 한 번 미분 가능해도 두 번 미분 가능하다는 보장이 없습니다(공통1 2.1절 심화 문제의 \(x^2\sin\frac1x\)). 복소함수는 한 번 미분 가능하면 끝없이 미분 가능합니다. 복소 미분 가능성이 그만큼 강한 조건이라는 뜻입니다.

예제 4.4.2

단위원에서 \(\oint\frac{\cos z}{z^3}dz\)를 구하여라.

풀이. \(n = 2\), \(z_0 = 0\), \(f = \cos z\). \(\oint = \frac{2\pi i}{2!}f''(0) = \pi i\cdot(-\cos0) = -\pi i\).

이 공식에서 리우빌 정리(복소평면 전체에서 해석적이고 유계인 함수는 상수)와 대수학의 기본정리(모든 다항식은 복소수 근을 가진다)가 나옵니다. 고교에서 사실로만 배운 대수학의 기본정리가 여기서 증명됩니다(교재 14.4절).

요약
  1. 해석함수는 무한히 미분 가능하다.
  2. \(\oint\frac{f}{(z - z_0)^{n+1}}dz = \frac{2\pi i}{n!}f^{(n)}(z_0)\).
