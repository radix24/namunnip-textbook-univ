복소수의 곱셈과 나눗셈은 평면에서 무엇을 할까?

예제 · 복소수의 사칙연산

\(z_1 = 3 + 4i\), \(z_2 = 1 - 2i\)일 때 \(z_1 + z_2\), \(z_1z_2\), \(z_1/z_2\), \(|z_1|\), \(\bar z_1\)을 구하여라.

전략

덧셈과 곱셈은 \(i^2 = -1\)만 기억하면 다항식처럼 계산한다. 나눗셈은 분모의 켤레 \(\bar z_2\)를 위아래에 곱해 분모를 실수 \(|z_2|^2\)로 만든다.

풀이

  1. \(z_1 + z_2 = 4 + 2i\).
    실수부끼리, 허수부끼리.
  2. \(z_1z_2 = 3 - 6i + 4i - 8i^2 = 11 - 2i\).
    분배법칙과 \(i^2 = -1\).
  3. \(\dfrac{z_1}{z_2} = \dfrac{(3 + 4i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \dfrac{3 + 6i + 4i - 8}{5} = -1 + 2i\).
    \(z_2\bar z_2 = |z_2|^2 = 5\).
  4. \(|z_1| = \sqrt{9 + 16} = 5\), \(\bar z_1 = 3 - 4i\).
    크기는 원점까지의 거리, 켤레는 실수축 대칭.

의미

덧셈은 평면 벡터의 덧셈과 같고, 곱셈은 크기를 곱하고 각을 더한다. \(|z_1z_2| = 5\sqrt5 = |z_1||z_2|\)인 것을 확인해 보자. 그래서 \(i\)를 곱하면 90° 회전입니다(3.2절).

검산

\((-1 + 2i)(1 - 2i) = -1 + 2i + 2i - 4i^2 = 3 + 4i = z_1\). 맞다.

바꿔 보기

\(z\bar z = |z|^2\)은 언제나 실수이고 0 이상이다. 그래서 \(\dfrac1z = \dfrac{\bar z}{|z|^2}\)로 역수를 구한다.

이해 확인

\(\dfrac{1}{i}\)과 \(\dfrac{2 + i}{2 - i}\)를 구하여라.

답

\(-i\). \(\dfrac{(2 + i)^2}{5} = \dfrac{3 + 4i}5\).
