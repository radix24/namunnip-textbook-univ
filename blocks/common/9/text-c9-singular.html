  • 로랑 급수와 주부 (5.2절).

5.3.1특이점의 종류

\(f\)가 \(z_0\)에서는 해석적이지 않지만 그 둘레(\(0 < |z - z_0| < R\))에서는 해석적일 때 \(z_0\)을 고립 특이점이라 합니다. 로랑 급수의 주부(음의 거듭제곱 부분)를 보고 셋으로 나눕니다.

종류주부예
제거 가능 특이점없음\(\frac{\sin z}{z} = 1 - \frac{z^2}{3!} + \cdots\)
\(m\)위 극\(\frac{1}{(z - z_0)^m}\)까지 유한개\(\frac{e^z}{z^2}\): 0이 2위 극
본질적 특이점무한히 많음\(e^{1/z}\): 0

각 종류의 행동은 뚜렷이 다릅니다.

  • 제거 가능: \(f(z_0)\)을 극한값으로 정의하면 해석적이 된다. 사실상 특이점이 아니다.
  • 극: \(z \to z_0\)일 때 \(|f(z)| \to \infty\). 1위 극을 단순극이라 한다.
  • 본질적 특이점: 다가가는 방향에 따라 극한이 제멋대로다. 예를 들어 \(e^{1/z}\)은 양의 실수축으로 다가가면 \(\infty\), 음의 실수축으로 다가가면 0.

5.3.2영점과 극

\(f(z_0) = 0\)이고 \(f(z) = (z - z_0)^mg(z)\), \(g(z_0) \ne 0\)으로 쓸 수 있으면 \(z_0\)을 \(m\)위 영점이라 합니다. 미분으로 판정하면 \(f(z_0) = f'(z_0) = \cdots = f^{(m-1)}(z_0) = 0\), \(f^{(m)}(z_0) \ne 0\)입니다.

정리 5.3.1

\(z_0\)이 \(h\)의 \(m\)위 영점이면 \(\frac{1}{h}\)은 \(z_0\)에서 \(m\)위 극을 갖는다.

그래서 유리함수의 극은 분모의 근에서 찾고, 위수는 근의 중복도입니다.

예제 5.3.2

\(f(z) = \frac{z + 1}{z^2(z - 2)^3}\)과 \(g(z) = \frac{1}{\sin z}\)의 특이점과 위수를 구하여라.

풀이. \(f\): 0이 2위 극, 2가 3위 극(분자는 이 점들에서 0이 아님). \(g\): \(\sin z = 0\)인 \(z = n\pi\)에서 \((\sin z)' = \cos n\pi \ne 0\)이므로 1위 영점, 따라서 \(g\)는 \(n\pi\)에서 단순극입니다.

요약
  1. 주부가 없음 / 유한 / 무한 → 제거 가능 / 극 / 본질적.
  2. \(m\)위 영점의 역수는 \(m\)위 극.

5.3.3연습문제

기본

  1. \(\frac{1}{z^2 + 1}\)의 극과 위수는?
    답

    \(\pm i\), 모두 단순극.

  2. \(\frac{1 - \cos z}{z^2}\)의 0은 어떤 특이점인가?
    답

    \(\frac{1}{2!} - \frac{z^2}{4!} + \cdots\). 제거 가능.
