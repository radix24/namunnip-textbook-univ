지수함수와 삼각함수의 사상

본문

원통형 관 속의 열 문제는 둥근 경계 때문에 풀기 어렵고, 직사각형 판의 문제는 비교적 쉽다. 둥근 영역을 직사각형이나 띠로, 띠를 반평면으로 펴 주는 함수가 있다면 어려운 문제를 쉬운 문제로 바꿀 수 있다. 지수함수와 사인 함수는 각각 어떤 영역을 어떤 영역으로 옮길까?

먼저 알아야 할 것복소 지수·삼각함수(3.5절), 복소 로그(3.6절), 등각사상(6.1절)을 쓴다.

6.3.1지수함수

\(w = e^z = e^xe^{iy}\)에서 \(|w| = e^x\), \(\arg w = y\)이다. 즉 실수부는 거리, 허수부는 각도가 된다. 그러므로 세로선 \(x = c\)는 원 \(|w| = e^c\)로 가고, 가로선 \(y = c\)는 원점에서 나가는 반직선 \(\arg w = c\)로 간다.

영역으로 보면 처음 질문의 답이 나온다. 띠 \(0 < y < \pi\)는 위쪽 반평면으로, 띠 \(-\pi < y \le \pi\)는 0을 뺀 평면 전체로 한 번씩 간다. 또 직사각형 \(a < x < b\), \(0 < y < \pi\)는 반 고리 \(e^a < |w| < e^b\), \(\text{Im}\,w > 0\)으로 간다. \(e^z\)의 도함수는 0이 아니므로 어디서나 등각이며, 가로선과 세로선이 직각으로 만나듯 반직선과 원도 직각으로 만난다.

역함수 \(w = \text{Ln}\,z\)는 반대로 움직인다. 즉 위쪽 반평면을 띠 \(0 < \text{Im}\,w < \pi\)로, 고리를 직사각형으로 펴 준다. 그래서 원형 영역의 문제를 직사각형 문제로 바꿀 때 쓴다.

예제 6.3.1

띠 \(0 < y < \frac\pi2\)는 \(w = e^z\)에 의해 어디로 가는가?

풀이. 각이 \(0 < \arg w < \frac\pi2\)이고 거리는 모든 양수이므로 1사분면으로 간다. 그림 1의 가로선 가운데 \(y < \frac\pi2\)인 것들이 1사분면의 반직선이 되는 것을 볼 수 있다.

6.3.2사인 함수

\(\sin z = \sin x\cosh y + i\cos x\sinh y\)이다. 반무한 띠 \(-\frac\pi2 < x < \frac\pi2\), \(y > 0\)은 \(w = \sin z\)에 의해 위쪽 반평면으로 옮겨진다. 이때 띠의 경계, 곧 두 세로 반직선과 밑변이 실수축 전체로 펼쳐진다. 그런데 끝점 \(z = \pm\frac\pi2\)에서는 \((\sin z)' = \cos z = 0\)이라 등각이 아니며, 실제로 직각 모서리가 평각으로 펴진다. 그림 1에서 \(\sin z\)를 고르면 이 모서리(빨강)가 \(w = \pm1\)로 가는 것이 보인다.

마무리

\(e^z\)는 세로선을 원으로, 가로선을 반직선으로, 띠를 반평면으로 옮기고, \(\text{Ln}\,z\)는 그 반대로 편다. \(\sin z\)는 반무한 띠를 반평면으로 옮기며, 처음 질문처럼 이런 사상으로 둥근 영역과 반평면, 띠 사이를 오간다.

6.3.3연습문제

기본

  1. \(w = e^z\)는 직선 \(x = 0\)을 어디로 보내는가?
    답

    단위원 \(|w| = 1\).

  2. \(w = \text{Ln}\,z\)는 고리 \(1 < |z| < e\)를 어디로 보내는가?
    답

    직사각형 \(0 < u < 1\), \(-\pi < v \le \pi\).
