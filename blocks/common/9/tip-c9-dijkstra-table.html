다익스트라는 확정된 꼭짓점에서 나가는 변만 보고, 표 한 줄에 하나씩 확정한다

요령 · 다익스트라 알고리즘

언제 쓰는가

가중치가 음이 아닌 그래프에서 한 출발점으로부터의 최단 경로를 손으로 구하는 문제이다.

요령

  1. 표를 만든다
    꼭짓점마다 '지금까지 아는 거리'와 '바로 앞 꼭짓점' 칸을 둔다. 출발점은 0, 나머지는 \(\infty\).
  2. 가장 작은 것을 확정
    확정되지 않은 꼭짓점 가운데 거리가 가장 작은 하나를 확정한다.
  3. 그 점에서 나가는 변만 갱신
    확정한 점을 거쳐 가는 길이 더 짧으면 거리와 앞 꼭짓점을 고친다.
  4. 경로는 거꾸로
    도착점에서 '앞 꼭짓점'을 따라 거슬러 올라가면 최단 경로이다.

흔한 실수

  • 처음 발견한 거리를 바로 확정하는 것. 더 짧은 우회로가 나중에 나올 수 있다.
  • 음수 가중치가 있는 그래프에 그대로 쓰는 것.

바로 풀어보기

변 A–B 4, A–C 1, B–C 2, B–D 1, C–D 5, D–E 3, C–E 8(무방향)인 그래프에서 A에서 E까지 최단 경로와 거리를 구하여라.

답과 풀이

답: A–C–B–D–E, 거리 7

A(0) 확정 → C 1, B 4. C(1) 확정 → B는 \(1 + 2 = 3\)으로 줄고, D 6, E 9. B(3) 확정 → D는 \(3 + 1 = 4\)로 줄어든다.

D(4) 확정 → E는 \(4 + 3 = 7\)로 줄어든다. E(7) 확정. 앞 꼭짓점을 거슬러 E ← D ← B ← C ← A이다. 직접 A–B로 가는 변(4)보다 C를 거치는 길(3)이 짧았다.

이 요령으로 풀리는 문제

  • 그래프와 조합 최적화 단원 연습 2번, 3번, 5번
영상 콘티 · 45초
  1. 0~5초꼭짓점 다섯 개와 가중치가 적힌 변이 있는 그래프, 옆에 빈 표가 있다.A에서 E까지 가장 짧은 길은?
  2. 5~13초A가 초록으로 확정되고 A에서 나가는 두 변을 따라 B 4, C 1이 표에 적힌다.확정된 점에서 나가는 변만 본다.
  3. 13~22초가장 작은 C가 확정되고, C를 거친 B까지의 거리 3이 4를 지우고 들어간다.더 짧으면 고친다.
  4. 22~32초B, D, E가 차례로 확정되며 표의 거리 칸이 3, 4, 7로 채워진다.한 번에 하나씩 확정한다.
  5. 32~40초E에서 '앞 꼭짓점' 화살표를 따라 D, B, C, A로 거슬러 오르며 경로가 굵게 칠해진다.경로는 거꾸로 읽는다.
  6. 40~45초처음 적힌 B 4를 바로 확정했다면 생겼을 더 긴 경로가 점선으로 나와 X가 된다.서둘러 확정하지 않는다.
