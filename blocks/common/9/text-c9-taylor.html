복소 테일러 급수와 수렴 반지름

본문
이 절에서 배울 것
  • 복소 거듭제곱급수가 원 안에서 수렴한다는 것과 수렴 반지름을 안다.
  • 해석함수를 테일러 급수로 전개하고, 수렴 반지름이 가장 가까운 특이점까지의 거리임을 이용한다.
먼저 알아야 할 것
  • 거듭제곱급수와 수렴 반지름 (공통1 8.6절), 테일러 급수 (8.8절), 해석함수의 도함수 (4.4절).

5.1.1복소 거듭제곱급수

\(\sum_{n=0}^\infty a_n(z - z_0)^n\) 꼴의 급수를 복소 거듭제곱급수라 합니다. 실수에서 수렴 "구간"이던 것이 복소평면에서는 수렴 "원판"이 됩니다. 곧 어떤 \(R\)이 있어서 \(|z - z_0| < R\)이면 수렴하고 \(|z - z_0| > R\)이면 발산합니다. \(R\)을 구하는 방법(비 판정법)은 공통1과 같습니다.

\[R = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right| \quad (\text{극한이 있을 때}).\]

가장 기본적인 예는 등비급수입니다.

\[\frac{1}{1 - z} = 1 + z + z^2 + \cdots = \sum_{n=0}^\infty z^n, \quad |z| < 1.\]

5.1.2테일러 급수

정리 5.1.1 (테일러 정리)

\(f\)가 \(z_0\)을 중심으로 하는 원판 \(|z - z_0| < R\)에서 해석적이면, 그 원판 전체에서

\[f(z) = \sum_{n=0}^\infty\frac{f^{(n)}(z_0)}{n!}(z - z_0)^n.\]

실수에서 익힌 급수가 그대로 복소수로 옮겨집니다.

  • \(e^z = \sum\frac{z^n}{n!}\), 모든 \(z\).
  • \(\sin z = z - \frac{z^3}{3!} + \frac{z^5}{5!} - \cdots\), 모든 \(z\).
  • \(\cos z = 1 - \frac{z^2}{2!} + \frac{z^4}{4!} - \cdots\), 모든 \(z\).

이 정리에서 중요한 결과가 나옵니다. 테일러 급수는 \(f\)가 해석적인 가장 큰 원판에서 수렴하므로, 수렴 반지름은 \(z_0\)에서 가장 가까운 특이점(해석적이지 않은 점)까지의 거리입니다.

예제 5.1.2

실수 함수 \(\frac{1}{1 + x^2}\)은 모든 실수에서 매끄러운데, 0을 중심으로 한 테일러 급수 \(1 - x^2 + x^4 - \cdots\)는 왜 \(|x| < 1\)에서만 수렴하는가?

풀이. 복소수로 보면 \(\frac{1}{1 + z^2}\)은 \(z = \pm i\)에서 분모가 0입니다. 원점에서 \(\pm i\)까지 거리가 1이므로 수렴 반지름은 1입니다. 실수축만 봐서는 보이지 않던 이유가 복소평면에서 드러납니다.

예제 5.1.3

\(\frac{1}{z}\)을 \(z_0 = 1\)을 중심으로 전개하고 수렴 반지름을 구하여라.

풀이. \(\frac1z = \frac{1}{1 + (z - 1)} = \sum_{n=0}^\infty(-1)^n(z - 1)^n\) (등비급수에 \(-(z - 1)\)을 넣음). 특이점 0까지 거리가 1이므로 \(R = 1\).

요약
  1. 복소 거듭제곱급수는 원판 \(|z - z_0| < R\)에서 수렴한다.
  2. 해석함수는 테일러 급수로 나타나고, \(R\)은 가장 가까운 특이점까지의 거리.
  3. 등비급수에 대입하는 방법으로 전개를 빨리 구한다.

5.1.3연습문제

기본

  1. \(\sum\frac{z^n}{2^n}\)의 수렴 반지름은?
    답

    \(R = 2\). (합은 \(\frac{1}{1 - z/2}\))

  2. \(\frac{1}{z - 3}\)을 0 중심으로 전개할 때 수렴 반지름은?
    답

    특이점 3까지의 거리, 3.

응용

  1. \(\frac{1}{1 + z^2}\)을 \(z_0 = 1\)을 중심으로 전개할 때 수렴 반지름은?
    답

    1에서 \(\pm i\)까지 거리 \(\sqrt2\).
