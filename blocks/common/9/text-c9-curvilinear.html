기울기, 발산, 회전과 곡선좌표

본문
이 절에서 배울 것
  • 기울기, 발산, 회전, 라플라시안을 직교좌표에서 다시 정리한다.
  • 원통좌표와 구면좌표에서의 공식을 쓴다.
먼저 알아야 할 것
  • 기울기 벡터 (공통2 4.5절), 회전과 발산 (7.5절), 극좌표 (공통1 7.3절).

이 단원은 요람의 과목 개요에 있지만 2026학년도 진도표에는 없습니다. 2–6단원에서 쓰는 도구를 복습하는 용도로 둡니다.

9.1.1직교좌표 복습

\(\nabla = \left(\frac{\partial}{\partial x}, \frac{\partial}{\partial y}, \frac{\partial}{\partial z}\right)\)로 쓰면 다음과 같습니다.

  • 기울기 \(\nabla f\): 가장 빨리 증가하는 방향과 그 비율. 스칼라 → 벡터.
  • 발산 \(\nabla\cdot\mathbf F = P_x + Q_y + R_z\): 한 점에서 퍼져 나가는 양. 벡터 → 스칼라.
  • 회전 \(\nabla\times\mathbf F\): 한 점에서 소용돌이치는 정도와 축. 벡터 → 벡터.
  • 라플라시안 \(\nabla^2f = \nabla\cdot\nabla f = f_{xx} + f_{yy} + f_{zz}\).

9.1.2원통좌표와 구면좌표

원형 막(2.7절), 원판(6.5절), 공 모양의 문제는 원통좌표 \((r, \theta, z)\)나 구면좌표 \((\rho, \theta, \phi)\)가 편합니다. 이때 공식에 \(r\)이나 \(\rho\) 같은 인수가 붙는 이유는, 각도가 \(d\theta\) 변할 때 실제로 움직이는 거리가 \(r\,d\theta\)이기 때문입니다.

원통좌표 (단위벡터 \(\mathbf e_r, \mathbf e_\theta, \mathbf e_z\)):

\[\nabla f = f_r\mathbf e_r + \frac1rf_\theta\mathbf e_\theta + f_z\mathbf e_z,\] \[\nabla\cdot\mathbf F = \frac1r(rF_r)_r + \frac1r\frac{\partial F_\theta}{\partial\theta} + \frac{\partial F_z}{\partial z},\] \[\nabla^2f = \frac1r(rf_r)_r + \frac{1}{r^2}f_{\theta\theta} + f_{zz}.\]

구면좌표에서 \(f\)가 \(\rho\)에만 의존하면

\[\nabla^2f = \frac{1}{\rho^2}\left(\rho^2f_\rho\right)_\rho.\]
예제 9.1.1

(가) \(\mathbf F = r\mathbf e_r\)(원통좌표)의 발산 (나) \(f = \ln r\)의 라플라시안 (다) \(f = \frac1\rho\)의 라플라시안을 구하여라.

풀이. (가) \(\frac1r(r^2)_r = 2\). 직교좌표로 \(\mathbf F = (x, y, 0)\)이고 발산 2와 같습니다. (나) \(\frac1r\left(r\cdot\frac1r\right)_r = 0\). 6.4절에서 쓴 동심원 사이의 퍼텐셜입니다. (다) \(\frac{1}{\rho^2}\left(\rho^2\cdot\left(-\frac{1}{\rho^2}\right)\right)_\rho = 0\) (\(\rho \ne 0\)). 점전하의 퍼텐셜 \(\frac1\rho\)이 라플라스 방정식을 만족한다는 뜻입니다.

요약
  1. 기울기·발산·회전·라플라시안은 \(\nabla\)로 쓴다.
  2. 곡선좌표 공식에는 거리 인수 \(r\), \(\rho\)가 붙는다.

9.1.3연습문제

기본

  1. \(f = r^2\)(원통좌표)의 라플라시안은?
    답

    \(\frac1r(2r^2)_r = 4\). (직교좌표 \(x^2 + y^2\)과 일치)

  2. \(f = \rho^2\)(구면좌표)의 라플라시안은?
    답

    \(\frac{1}{\rho^2}(2\rho^3)_\rho = 6\).
