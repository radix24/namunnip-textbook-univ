변수분리 풀이는 경계 조건, 고유함수, 시간 부분, 초기 조건의 순서를 지킨다

요령 · 변수분리

언제 쓰는가

유한한 막대나 줄에서 열방정식이나 파동방정식을 경계 조건과 초기 조건으로 푸는 문제입니다.

요령

  1. \(u = X(x)T(t)\)
    곱의 꼴을 넣어 \(\frac{X''}{X} = \frac{T'}{kT} = -\lambda\)처럼 두 상미분방정식으로 가릅니다.
  2. 경계 조건으로 고유함수
    \(X\)의 방정식에 경계 조건을 넣어 0이 아닌 해가 생기는 \(\lambda\)만 고릅니다. 양 끝이 0이면 \(X_n = \sin\frac{n\pi x}{L}\)입니다.
  3. 시간 부분
    열방정식은 \(e^{-k\lambda_nt}\), 파동방정식은 \(\cos\), \(\sin\)으로 진동합니다.
  4. 초기 조건으로 계수
    \(u(x, 0)\)을 고유함수의 합으로 나타냅니다. 이미 사인 몇 개의 합이면 적분 없이 계수를 읽습니다.

흔한 실수

  • 초기 조건을 경계 조건보다 먼저 넣어 고유함수를 정하지 못하는 것.
  • 열방정식의 지수에 \(k\lambda_n\) 대신 \(\lambda_n\)만 넣어 확산 계수를 빠뜨리는 것.

바로 풀어보기

\(u_t = 2u_{xx}\) (\(0 < x < \pi\)), \(u(0, t) = u(\pi, t) = 0\), \(u(x, 0) = 3\sin x - \sin4x\)를 푸세요.

답과 풀이

답: \(u = 3e^{-2t}\sin x - e^{-32t}\sin4x\)

경계 조건에서 \(X_n = \sin nx\), \(\lambda_n = n^2\)이고 시간 부분은 \(e^{-2n^2t}\)입니다.

초기 조건이 이미 \(n = 1\)과 \(n = 4\)의 사인 합이므로 계수는 3과 \(-1\)입니다. \(n = 4\) 항은 \(e^{-32t}\)로 훨씬 빨리 사라져, 잠시 뒤에는 \(3e^{-2t}\sin x\) 모양만 남습니다.

이 요령으로 풀리는 문제

  • 편미분방정식(풀이) 단원 연습 1번, 2번, 6번
  • 편미분방정식(모형) 단원 연습 3번
영상 콘티 · 45초
  1. 0~5초막대 위의 온도 곡선 \(3\sin x - \sin4x\)가 울퉁불퉁하게 그려집니다.이 온도는 어떻게 변할까요?
  2. 5~13초\(u\)가 \(X(x)\)와 \(T(t)\) 두 조각으로 갈라지는 애니메이션.공간과 시간을 나눕니다.
  3. 13~22초막대 양 끝이 0에 고정되고, 그 조건을 만족하는 사인 곡선 \(\sin x\), \(\sin2x\), \(\sin3x\), \(\sin4x\)가 줄지어 나타납니다.경계 조건이 고유함수를 정합니다.
  4. 22~31초처음 곡선이 \(3\sin x\)와 \(-\sin4x\) 두 성분으로 분해됩니다.초기 조건을 고유함수로 나눕니다.
  5. 31~45초시간이 흐르며 \(\sin4x\) 성분은 순식간에 납작해지고 \(\sin x\) 성분은 천천히 줄어듭니다.높은 모드일수록 빨리 사라집니다.
