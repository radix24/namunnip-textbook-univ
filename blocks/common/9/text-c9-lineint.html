복소평면의 선적분

본문
이 절에서 배울 것
  • 경로를 \(z(t)\)로 나타내 복소 선적분 \(\int_Cf(z)\,dz\)를 계산한다.
  • 가장 중요한 적분 \(\oint\frac{dz}{z - z_0} = 2\pi i\)를 구한다.
먼저 알아야 할 것
  • 선적분 (공통2 7.2절), 매개변수 곡선 (공통1 7.1절), 복소 지수 (3.5절).

4.1.1정의와 계산

복소평면의 곡선 \(C\)를 \(z(t) = x(t) + iy(t)\), \(a \le t \le b\)로 나타내면, 복소 선적분은 공통2의 선적분처럼 곡선을 잘게 나누어 \(f(z)\Delta z\)를 더한 것의 극한입니다. 계산은 매개변수로 바꾸어 합니다.

정리 4.1.1 \[\int_Cf(z)\,dz = \int_a^bf(z(t))\,\dot z(t)\,dt, \qquad \dot z = \frac{dz}{dt}.\]

또 \(f\)가 해석적이고 \(F' = f\)인 \(F\)가 있으면, 기본정리처럼 \(\int_Cf\,dz = F(z_1) - F(z_0)\)으로 끝점만 보면 됩니다(경로와 무관).

예제 4.1.2 (가장 중요한 적분)

단위원 \(C\)를 시계 반대 방향으로 한 바퀴 도는 경로에서 \(\oint_C\frac{dz}{z}\)를 구하여라.

풀이. \(z(t) = e^{it}\), \(0 \le t \le 2\pi\), \(\dot z = ie^{it}\).

\[\oint_C\frac{dz}{z} = \int_0^{2\pi}\frac{ie^{it}}{e^{it}}dt = \int_0^{2\pi}i\,dt = 2\pi i.\]

0이 아닙니다! \(\frac1z\)의 "부정적분" \(\ln z\)는 한 바퀴 돌면 \(2\pi i\)만큼 다른 값이 되기 때문입니다(3.6절). 같은 계산으로, 중심이 \(z_0\)인 원에서 \(\oint\frac{dz}{(z - z_0)^m}\)은 \(m = 1\)이면 \(2\pi i\), 다른 정수 \(m\)이면 0입니다. 이 결과가 4단원과 5단원 전체의 바탕입니다.

예제 4.1.3

\(\int_C\bar z\,dz\)를 (가) 0에서 \(1 + i\)까지의 선분 (나) 0 → 1 → \(1 + i\)를 따라 구하여라.

풀이. (가) \(z = t + it\), \(\dot z = 1 + i\). \(\int_0^1(t - it)(1 + i)dt = \int_0^12t\,dt = 1\). (나) 0→1: \(z = t\), \(\int_0^1t\,dt = \frac12\). 1→\(1 + i\): \(z = 1 + it\), \(\int_0^1(1 - it)i\,dt = i + \frac12\). 합 \(1 + i\). 경로에 따라 값이 다릅니다. \(\bar z\)가 해석적이지 않기 때문입니다.

요약
  1. \(\int_Cf\,dz = \int f(z(t))\dot z\,dt\).
  2. \(\oint\frac{dz}{z - z_0} = 2\pi i\), 다른 거듭제곱은 0.
  3. 해석적이지 않으면 경로에 따라 값이 달라질 수 있다.

4.1.2연습문제

기본

  1. \(\int_Cz\,dz\)를 0에서 \(1 + i\)까지의 선분에서 구하고, 부정적분으로 확인하여라.
    답

    \(\int_0^1(1 + i)^2t\,dt = \frac{(1 + i)^2}{2} = i\). \(\left[\frac{z^2}{2}\right]_0^{1+i} = i\).
