달랑베르 해

본문

아주 긴 줄의 가운데를 집어 올렸다 놓으면, 봉우리가 둘로 갈라져 양쪽으로 같은 속력으로 퍼져 나간다. 2.3절의 푸리에 급수 해로는 이 모습이 잘 보이지 않는다. 파동방정식의 해를 "움직이는 모양"으로 직접 쓸 수는 없을까?

먼저 알아야 할 것파동방정식(2.2절)과 다변수 연쇄법칙(미분적분학(2) 4.4절)을 쓴다.

2.4.1새 변수로 바꾸기

\(v = x + ct\), \(w = x - ct\)로 변수를 바꾸면 연쇄법칙으로 \(u_{tt} = c^2u_{xx}\)가 \(u_{vw} = 0\)으로 단순해진다. 이 식은 \(w\)로 적분하고 \(v\)로 적분하면 바로 풀린다.

정리 2.4.1 (달랑베르 해)

파동방정식의 일반해는 \(u(x, t) = \phi(x + ct) + \psi(x - ct)\)이다(\(\phi, \psi\)는 임의의 두 번 미분 가능한 함수).

처음 질문의 움직이는 모양이 이것이다. \(\psi(x - ct)\)는 모양 \(\psi\)가 속력 \(c\)로 오른쪽으로 이동하는 파동이다. 시각 \(t\)에 \(x\)에서 보는 값이 처음 \(x - ct\)에 있던 값이기 때문이다. 마찬가지로 \(\phi(x + ct)\)는 왼쪽으로 이동한다. 그래서 \(c\)가 파동의 속력이다.

2.4.2초기 조건 맞추기

\(u(x, 0) = f(x)\), \(u_t(x, 0) = g(x)\)를 넣어 정리하면 다음 공식을 얻는다.

\[u(x, t) = \frac12[f(x + ct) + f(x - ct)] + \frac{1}{2c}\int_{x - ct}^{x + ct}g(s)\,ds\]

처음 속도가 0이면(\(g = 0\)) 처음 모양 \(f\)가 반으로 나뉘어 왼쪽과 오른쪽으로 같은 속력으로 퍼져 나간다. 처음 질문의 줄이 바로 이 모습이다.

예제 2.4.2

\(c = 1\), \(f(x) = \frac{1}{1 + x^2}\), \(g = 0\)일 때 \(u(x, t)\)는?

풀이. 공식에 넣으면 \(u = \frac12\left[\frac{1}{1 + (x + t)^2} + \frac{1}{1 + (x - t)^2}\right]\)이다. 그러므로 \(t = 5\)이면 \(x = \pm5\)에 높이 약 \(\frac12\)인 봉우리 두 개가 있다. 그림 1에서 \(t\)를 0부터 올리면 하나였던 봉우리가 갈라져 멀어진다.

양 끝이 고정된 유한한 줄에서는, 2.3절의 푸리에 급수 해를 삼각함수 공식으로 정리하면 같은 꼴이 된다. 다만 두 파동이 끝에서 반사되어 되돌아온다.
마무리

파동방정식의 일반해는 \(u = \phi(x + ct) + \psi(x - ct)\)로, 처음 질문의 움직이는 모양 그대로 왼쪽과 오른쪽으로 가는 두 파동의 합이다. 초기 조건을 넣으면 \(u = \frac12[f(x + ct) + f(x - ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct}g\)이다.
