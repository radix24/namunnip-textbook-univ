등각사상으로 푸는 열 문제와 퍼텐셜 문제

본문

넓은 금속판의 두 가장자리를 하나는 0 °C, 다른 하나는 100 °C로 유지하면, 오래 지나 판 안의 온도가 더 변하지 않는 상태에 이른다. 가장자리가 직각으로 꺾여 있으면 그 온도 분포를 어떻게 구할까? 반평면에서 이미 아는 답을 다른 모양의 영역으로 옮겨 쓸 수는 없을까?

먼저 알아야 할 것조화함수와 해석함수(3.4절), 등각사상(6.1절), 열방정식(2.5절)을 쓴다.

6.4.1라플라스 방정식이 나오는 곳

열방정식 \(u_t = c^2\nabla^2u\)에서 시간이 충분히 지나 온도가 변하지 않으면(정상 상태) \(u_t = 0\)이므로 \(\nabla^2u = 0\)이다. 전하가 없는 곳의 정전기 퍼텐셜, 소용돌이 없는 이상 유체의 속도 퍼텐셜도 같은 식을 만족한다. 그래서 2차원에서는 이 문제들이 모두 "경계값이 주어진 조화함수 찾기"가 된다.

해석함수 \(F = \Phi + i\Psi\)를 복소 퍼텐셜이라 부른다. \(\Phi\)가 상수인 곡선은 등퍼텐셜선, 곧 같은 온도의 선(등온선)이다. 반면 \(\Psi\)가 상수인 곡선은 흐름선으로, 열이나 전기력선이 지나가는 길이다. 그리고 3.4절에서 본 것처럼 두 곡선족은 서로 직각으로 만난다.

6.4.2등각사상을 쓰는 이유

정리 6.4.1

\(\Phi\)가 \(w\)평면에서 조화함수이고 \(w = f(z)\)가 해석적이면, \(\Phi(f(z))\)는 \(z\)평면에서 조화함수이다.

처음 질문의 "옮겨 쓰기"가 이 정리로 가능하다. 풀이 순서는 이렇다. 먼저 주어진 영역을 반평면이나 띠 같은 단순한 영역으로 옮기는 등각사상을 찾는다. 다음으로 단순한 영역에서 조화함수를 구한다. 끝으로 사상의 식을 대입해 원래 영역으로 되돌린다.

예제 6.4.2

위쪽 반평면에서, 양의 실수축의 온도가 0, 음의 실수축의 온도가 100일 때 정상 상태 온도를 구하여라.

풀이. \(\text{Ln}\,z = \ln r + i\theta\)는 해석적이므로 \(\theta = \text{Arg}\,z\)는 조화함수이다. 그러므로 \(\theta = 0\)(양의 실수축)과 \(\theta = \pi\)(음의 실수축)에서 경계값을 맞추면 다음과 같다.

\[T = \frac{100}{\pi}\,\text{Arg}\,z\]

등온선은 원점에서 나가는 반직선이며, 가령 \(z = i\)에서 \(T = 50\)이다.

예제 6.4.3

1사분면에서, 양의 \(x\)축의 온도가 0, 양의 \(y\)축의 온도가 100일 때 정상 상태 온도를 구하여라.

풀이. \(w = z^2\)이 1사분면을 위쪽 반평면으로 옮기며(6.1절), 양의 \(x\)축은 양의 실수축, 양의 \(y\)축은 음의 실수축으로 간다. 그러므로 예제 6.4.2의 답에 대입하면 다음을 얻는다.

\[T = \frac{100}{\pi}\text{Arg}(z^2) = \frac{200}{\pi}\text{Arg}\,z\]

확인해 보면 \(y\)축(\(\text{Arg}\,z = \frac\pi2\))에서 100, \(x\)축에서 0이다. 이것이 처음 질문의 직각 판의 온도이며, 그림 1에서 점을 같은 각으로 멀리 옮겨도 온도는 그대로이다.

마무리

정상 상태 온도와 퍼텐셜은 라플라스 방정식의 해, 곧 조화함수이다. 해석함수로 옮겨도 조화함수는 조화함수이므로, 처음 질문처럼 단순한 영역에서 풀고 사상으로 되돌린다. 반평면의 기본해는 \(\text{Arg}\,z\)의 일차식이다.

6.4.3연습문제

기본

  1. 두 동심원 \(r = 1\) (퍼텐셜 0)과 \(r = e\) (퍼텐셜 100) 사이의 퍼텐셜을 구하여라. (힌트: \(\ln r = \text{Re}\,\text{Ln}\,z\)도 조화함수)
    답

    \(\Phi = 100\ln r\).

응용

  1. 예제 6.4.3에서 \(z = 1 + i\)의 온도는?
    답

    \(\text{Arg} = \frac\pi4\). \(\frac{200}{\pi}\cdot\frac\pi4 = 50\).
