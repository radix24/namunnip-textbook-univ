변수분리와 푸리에 급수로 파동방정식 풀기

본문

기타 줄을 처음에 어떤 모양으로 당겼다 놓든, 줄은 기본음과 그 정수배인 배음들이 섞인 소리를 낸다. 편미분방정식인 파동방정식을, 우리가 이미 풀 줄 아는 상미분방정식들로 나누어 풀 수는 없을까? 그리고 처음 모양은 그 풀이의 어디에 들어갈까?

먼저 알아야 할 것파동방정식(2.2절), 스투름-리우빌 문제와 반구간 사인 급수(고등미적분학(1) 6.3절, 6.2절)를 쓴다.

2.3.1문제

길이 \(L\)인 줄의 양 끝이 고정되어 있고, 처음 모양 \(f(x)\)로 당겼다가 처음 속도 \(g(x)\)로 놓았다고 하자.

\[u_{tt} = c^2u_{xx}, \quad u(0, t) = u(L, t) = 0, \quad u(x, 0) = f(x), \quad u_t(x, 0) = g(x)\]

2.3.21단계, 변수분리

처음 질문의 나누는 방법은 해를 "위치만의 함수 × 시간만의 함수" \(u = F(x)G(t)\)로 놓는 것이다. 넣으면 \(FG'' = c^2F''G\)이고, 양변을 \(c^2FG\)로 나누면 다음과 같다.

\[\frac{G''}{c^2G} = \frac{F''}{F}\]

왼쪽은 \(t\)만의 식, 오른쪽은 \(x\)만의 식인데 언제나 같으므로, 둘 다 같은 상수 \(-k^2\)여야 한다. 그래서 상미분방정식 두 개가 된다.

\[F'' + k^2F = 0, \qquad G'' + c^2k^2G = 0\]

2.3.32단계, 경계 조건에서 고유함수로

\(u(0, t) = u(L, t) = 0\)에서 \(F(0) = F(L) = 0\)이다. 이것은 고등미적분학(1) 6.3절의 고유값 문제이고, 0이 아닌 해는 \(k = \frac{n\pi}{L}\)일 때 \(F_n = \sin\frac{n\pi x}{L}\)뿐이다. 그러면 \(G'' + \lambda_n^2G = 0\)(\(\lambda_n = \frac{cn\pi}{L}\))에서 \(G_n = B_n\cos\lambda_nt + B_n^*\sin\lambda_nt\)이다.

해 \(u_n = (B_n\cos\lambda_nt + B_n^*\sin\lambda_nt)\sin\frac{n\pi x}{L}\)을 줄의 \(n\)번째 고유 진동이라 한다. \(n = 1\)이 기본음, \(n = 2, 3, \dots\)이 배음이고, 진동수 \(\frac{\lambda_n}{2\pi} = \frac{cn}{2L}\)은 기본 진동수의 정수배이다. 그래서 현악기의 소리가 조화롭게 들린다.

2.3.43단계, 중첩과 초기 조건에서 푸리에 급수로

중첩 원리로 모든 고유 진동을 더한다.

\[u(x, t) = \sum_{n=1}^\infty(B_n\cos\lambda_nt + B_n^*\sin\lambda_nt)\sin\frac{n\pi x}{L}\]

처음 모양은 여기에 들어간다. \(t = 0\)이면 \(u(x, 0) = \sum B_n\sin\frac{n\pi x}{L} = f(x)\), 곧 \(B_n\)은 \(f\)의 반구간 사인 급수 계수이다. 마찬가지로 \(u_t(x, 0) = g\)에서 \(B_n^*\)을 정한다.

\[B_n = \frac2L\int_0^Lf(x)\sin\frac{n\pi x}{L}dx, \qquad B_n^* = \frac{2}{cn\pi}\int_0^Lg(x)\sin\frac{n\pi x}{L}dx\]
예제 2.3.1

\(L = \pi\), \(c = 1\), \(f(x) = \sin x + 0.5\sin3x\), \(g = 0\)이면?

풀이. \(f\)가 이미 사인 급수이므로 \(B_1 = 1\), \(B_3 = 0.5\)이고 나머지는 0이다. 따라서 \(u = \cos t\sin x + 0.5\cos3t\sin3x\)이며, 기본음과 셋째 배음이 섞인 진동이다. 그림 1의 처음 상태가 이 해이고, \(t\)를 움직이면 셋째 배음이 세 배 빠르게 오르내린다.

마무리

\(u = FG\)로 놓으면 상수 \(-k^2\)로 두 상미분방정식이 되어, 처음 질문처럼 편미분방정식을 아는 문제로 나눌 수 있다. 경계 조건이 고유함수 \(\sin\frac{n\pi x}{L}\)과 고유 진동수 \(\frac{cn}{2L}\)을 정하고, 처음 모양은 중첩한 뒤 반구간 사인 급수의 계수로 들어간다.

2.3.5연습문제

기본
