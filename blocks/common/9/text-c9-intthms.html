9.2.1세 정리

정리식뜻
그린\(\oint_C(P\,dx + Q\,dy) = \iint_D(Q_x - P_y)\,dA\)평면 영역의 회전 합 = 경계를 도는 양
스토크스\(\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot\mathbf n\,dA\)곡면의 회전 합 = 경계를 도는 양
발산\(\oiint_S\mathbf F\cdot\mathbf n\,dA = \iiint_V\nabla\cdot\mathbf F\,dV\)안에서 생긴 양 = 겉면으로 나가는 양

모두 미적분의 기본정리 \(\int_a^bf'\,dx = f(b) - f(a)\)를 높은 차원으로 넓힌 것입니다. 이 책에서는 코시 적분 정리(4.2절)를 그린 정리로 설명했고, 열방정식과 라플라스 방정식은 발산 정리로 유도됩니다.

9.2.2계산 예

예제 9.2.1 (그린)

반지름 \(a\)인 원 \(C\)(시계 반대 방향)에서 \(\oint_C(-y\,dx + x\,dy)\)를 구하여라.

풀이. \(Q_x - P_y = 1 - (-1) = 2\). \(2\times\pi a^2 = 2\pi a^2\). 일반적으로 이 적분은 넓이의 2배입니다.

예제 9.2.2 (발산)

\(\mathbf F = (x, y, z)\)가 반지름 \(a\)인 구면을 지나 나가는 선속을 구하여라.

풀이. \(\nabla\cdot\mathbf F = 3\). \(3\cdot\frac43\pi a^3 = 4\pi a^3\). 직접 계산해도 구면 위에서 \(\mathbf F\cdot\mathbf n = a\)이므로 \(a\cdot4\pi a^2 = 4\pi a^3\)으로 같습니다.

예제 9.2.3 (스토크스)

\(\mathbf F = (-y, x, 0)\)에 대해, 단위 반구면 \(z \ge 0\)을 지나는 \(\nabla\times\mathbf F\)의 선속을 구하여라.

풀이. 경계는 단위원이므로 선적분으로 바꿉니다. 예제 9.2.1에서 \(a = 1\): \(2\pi\). (같은 경계를 가진 평면 원판에서 \(\nabla\times\mathbf F = (0, 0, 2)\)를 적분해도 \(2\cdot\pi = 2\pi\).) 경계가 같으면 곡면 모양과 무관합니다.

요약
  1. 그린·스토크스: 회전의 면적분 = 경계 선적분. 발산: 발산의 부피적분 = 겉면 선속.
  2. 계산이 쉬운 쪽으로 바꾸어 푼다.

9.2.3연습문제

기본

  1. \(\mathbf F = (x^2, 0, 0)\)이 단위 정육면체 \([0, 1]^3\)의 겉면을 지나 나가는 선속은?
    답

    \(\nabla\cdot\mathbf F = 2x\). \(\int_0^12x\,dx = 1\).

  2. 단위원에서 \(\oint(y\,dx)\)는? (시계 반대 방향)
    답

    \(Q_x - P_y = -1\). \(-\pi\).
