그린, 발산, 스토크스 정리 복습

본문

그린 정리, 스토크스 정리, 발산 정리는 미분적분학(2)에서 따로따로 배웠다. 그런데 이 책에서는 코시 적분 정리를 그린 정리로 설명했고, 열방정식은 발산 정리로 유도된다. 세 정리를 하나의 틀로 묶어 볼 수는 없을까? 그리고 어느 쪽으로 바꾸어 계산하는 것이 편할까?

먼저 알아야 할 것그린 정리(미분적분학(2) 7.4절), 스토크스 정리(8.3절), 발산 정리(8.4절)를 쓴다.

9.2.1세 정리

정리식뜻
그린\(\oint_C(P\,dx + Q\,dy) = \iint_D(Q_x - P_y)\,dA\)평면 영역의 회전 합 = 경계를 도는 양
스토크스\(\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot\mathbf n\,dA\)곡면의 회전 합 = 경계를 도는 양
발산\(\oiint_S\mathbf F\cdot\mathbf n\,dA = \iiint_V\nabla\cdot\mathbf F\,dV\)안에서 생긴 양 = 겉면으로 나가는 양

처음 질문의 하나의 틀은 "안쪽의 미분 = 경계의 적분"이다. 세 정리는 모두 미적분의 기본정리 \(\int_a^bf'\,dx = f(b) - f(a)\)를 높은 차원으로 넓힌 것이다. 이 책에서는 코시 적분 정리(4.2절)를 그린 정리로 설명했고, 열방정식과 라플라스 방정식은 발산 정리로 유도된다.

9.2.2계산 예

예제 9.2.1 (그린)

반지름 \(a\)인 원 \(C\)(시계 반대 방향)에서 \(\oint_C(-y\,dx + x\,dy)\)를 구하여라.

풀이. \(Q_x - P_y = 1 - (-1) = 2\)이므로 적분은 \(2\times\pi a^2 = 2\pi a^2\)이다. 일반적으로 이 적분은 넓이의 2배이다. 그림 1에서 각을 돌리면 쌓인 값이 지나온 부채꼴 넓이의 두 배로 따라간다.

예제 9.2.2 (발산)

\(\mathbf F = (x, y, z)\)가 반지름 \(a\)인 구면을 지나 나가는 선속을 구하여라.

풀이. \(\nabla\cdot\mathbf F = 3\)이므로 선속은 \(3\cdot\frac43\pi a^3 = 4\pi a^3\)이다. 직접 계산해도 구면 위에서 \(\mathbf F\cdot\mathbf n = a\)이므로 \(a\cdot4\pi a^2 = 4\pi a^3\)으로 같다.

예제 9.2.3 (스토크스)

\(\mathbf F = (-y, x, 0)\)에 대해, 단위 반구면 \(z \ge 0\)을 지나는 \(\nabla\times\mathbf F\)의 선속을 구하여라.

풀이. 경계가 단위원이므로 선적분으로 바꾼다. 그러면 예제 9.2.1에서 \(a = 1\)인 경우이므로 \(2\pi\)이다. 같은 경계를 가진 평면 원판에서 \(\nabla\times\mathbf F = (0, 0, 2)\)를 적분해도 \(2\cdot\pi = 2\pi\)이다. 즉 경계가 같으면 곡면 모양과 무관하다. 처음 질문의 둘째 물음처럼, 반구면 대신 계산이 쉬운 경계나 원판을 고른 것이다.

마무리

그린과 스토크스 정리는 회전의 면적분을 경계 선적분으로, 발산 정리는 발산의 부피적분을 겉면 선속으로 바꾸며, 처음 질문처럼 모두 "안쪽의 미분 = 경계의 적분"이라는 하나의 틀이다. 계산할 때는 둘 가운데 쉬운 쪽으로 바꾸어 푼다.

9.2.3연습문제

기본

  1. \(\mathbf F = (x^2, 0, 0)\)이 단위 정육면체 \([0, 1]^3\)의 겉면을 지나 나가는 선속은?
    답

    \(\nabla\cdot\mathbf F = 2x\). \(\int_0^12x\,dx = 1\).

  2. 단위원에서 \(\oint(y\,dx)\)는? (시계 반대 방향)
    답

    \(Q_x - P_y = -1\). \(-\pi\).
