코시 적분 공식

본문

\(\oint\frac{e^z}{z - 2}dz\)처럼 분모에 \((z - z_0)\)가 있는 적분은 \(z_0\)에서 해석적이지 않으므로 코시 정리로 0이라 할 수 없다. 그렇다고 매번 매개변수로 계산하기는 번거롭다. 경로를 \(z_0\) 둘레로 줄이면 무엇이 남을까?

먼저 알아야 할 것코시 적분 정리와 경로 변형(4.2절)과 \(\oint\frac{dz}{z - z_0} = 2\pi i\)(4.1절)를 쓴다.

4.3.1공식

정리 4.3.1 (코시 적분 공식)

\(f\)가 단순연결 영역 \(D\)에서 해석적이고, \(C\)가 \(z_0\)을 둘러싼 \(D\) 안의 닫힌 경로(시계 반대 방향)이면

\[\oint_C\frac{f(z)}{z - z_0}dz = 2\pi if(z_0).\]

처음 질문처럼 경로를 \(z_0\) 둘레의 아주 작은 원으로 줄여 보자(4.2절). 그 원 위에서 \(f(z) \approx f(z_0)\)이므로 적분은 \(f(z_0)\oint\frac{dz}{z - z_0} = 2\pi if(z_0)\)에 가까워진다. 원을 줄일수록 정확해지는데, 적분값은 원의 크기와 무관하므로 정확히 같다. 즉 남는 것은 \(2\pi if(z_0)\)이다.

이 공식이 뜻하는 바는 크다. 경로 위의 값만으로 안쪽 점의 값 \(f(z_0)\)가 정해지므로, 해석함수는 경계에서의 값이 안쪽을 모두 결정한다. 라플라스 방정식의 해(조화함수)가 경계값으로 정해지는 것과 같은 현상이다(6.5절).

예제 4.3.2

\(z = 2\)를 둘러싼 경로에서 \(\oint\frac{e^z}{z - 2}dz\)를 구하여라.

풀이. \(f = e^z\), \(z_0 = 2\)이므로 \(2\pi ie^2\)이다. 즉 적분을 실제로 하지 않고 \(e^z\)의 값 하나로 끝난다.

예제 4.3.3

원 \(|z - i| = 1\)에서 \(\oint\frac{dz}{z^2 + 1}\)을 구하여라.

풀이. \(\frac{1}{z^2 + 1} = \frac{1}{(z - i)(z + i)}\)이고, 원 안에 있는 특이점은 \(i\)뿐이다(\(-i\)는 중심 \(i\)에서 거리 2). 그러므로 \(f = \frac{1}{z + i}\)로 놓으면 \(2\pi i\cdot\frac{1}{2i} = \pi\)이다. 그림 1의 처음 상태가 이 예제이며, 반지름을 2보다 크게 하면 \(-i\)도 안에 들어와 두 기여가 상쇄된다.

정리하면, 요령은 원 안의 특이점에 해당하는 인수 \((z - z_0)\)만 남기고, 나머지를 모두 \(f\)로 보는 것이다.

마무리

\(f\)가 해석적이고 \(z_0\)이 경로 안쪽에 있으면 \(\oint\frac{f}{z - z_0}dz = 2\pi if(z_0)\)이며, 처음 질문처럼 경로를 줄이면 이 값이 남는다. 계산할 때는 경로 안의 특이점 인수만 남기고 나머지를 \(f\)로 본다.

4.3.2연습문제

기본

  1. 단위원에서 \(\oint\frac{\cos z}{z}dz\)는?
    답

    \(2\pi i\cos0 = 2\pi i\).

  2. 원 \(|z| = 3\)에서 \(\oint\frac{z^2}{z - 1}dz\)는?
    답

    \(2\pi i\cdot1 = 2\pi i\).
