코시 적분 공식

본문
이 절에서 배울 것
  • \(\oint\frac{f(z)}{z - z_0}dz = 2\pi if(z_0)\)를 써서 적분을 계산한다.
먼저 알아야 할 것
  • 코시 적분 정리와 경로 변형 (4.2절), \(\oint\frac{dz}{z - z_0} = 2\pi i\) (4.1절).

4.3.1공식

정리 4.3.1 (코시 적분 공식)

\(f\)가 단순연결 영역 \(D\)에서 해석적이고, \(C\)가 \(z_0\)을 둘러싼 \(D\) 안의 닫힌 경로(시계 반대 방향)이면

\[\oint_C\frac{f(z)}{z - z_0}dz = 2\pi if(z_0).\]

이유: 경로를 \(z_0\) 둘레의 아주 작은 원으로 줄이면(4.2절), 그 원 위에서 \(f(z) \approx f(z_0)\)이므로 적분은 \(f(z_0)\oint\frac{dz}{z - z_0} = 2\pi if(z_0)\)에 가까워집니다. 원을 줄일수록 정확해지고, 적분값은 원의 크기와 무관하므로 정확히 같습니다.

놀라운 점: 경로 위의 값만으로 안쪽 점의 값 \(f(z_0)\)가 정해집니다. 해석함수는 경계에서의 값이 안쪽을 모두 결정합니다. 라플라스 방정식의 해(조화함수)가 경계값으로 정해지는 것과 같은 현상입니다(6.5절).

예제 4.3.2

\(z = 2\)를 둘러싼 경로에서 \(\oint\frac{e^z}{z - 2}dz\)를 구하여라.

풀이. \(f = e^z\), \(z_0 = 2\): \(2\pi ie^2\).

예제 4.3.3

원 \(|z - i| = 1\)에서 \(\oint\frac{dz}{z^2 + 1}\)을 구하여라.

풀이. \(\frac{1}{z^2 + 1} = \frac{1}{(z - i)(z + i)}\). 원 안에 있는 특이점은 \(i\)뿐입니다(\(-i\)는 중심 \(i\)에서 거리 2). \(f = \frac{1}{z + i}\)로 놓으면 \(2\pi i\cdot\frac{1}{2i} = \pi\).

요령: 원 안의 특이점에 해당하는 인수 \((z - z_0)\)만 남기고, 나머지를 모두 \(f\)로 봅니다.

요약
  1. \(\oint\frac{f}{z - z_0}dz = 2\pi if(z_0)\) (\(f\) 해석적, \(z_0\)은 안쪽).
  2. 경로 안의 특이점 인수만 남기고 나머지를 \(f\)로 본다.

4.3.2연습문제

기본

  1. 단위원에서 \(\oint\frac{\cos z}{z}dz\)는?
    답

    \(2\pi i\cos0 = 2\pi i\).

  2. 원 \(|z| = 3\)에서 \(\oint\frac{z^2}{z - 1}dz\)는?
    답

    \(2\pi i\cdot1 = 2\pi i\).
