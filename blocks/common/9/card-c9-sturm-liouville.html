Sturm-Liouville 고유값 문제의 고유함수는 왜 직교하는가

(py′)′ + qy + λwy = 0 · 무게 함수 · 직교성 증명
정리

\([a, b]\)에서 \((p(x)y')' + q(x)y + \lambda w(x)y = 0\) (\(p > 0\), \(w > 0\))에 양 끝에서 Dirichlet, Neumann 또는 Robin 조건을 준 문제(Sturm-Liouville 문제)에서, 서로 다른 고유값 \(\lambda_m \ne \lambda_n\)의 고유함수 \(y_m, y_n\)은 무게 \(w\)에 대해 직교한다:

\[\int_a^by_m(x)y_n(x)w(x)\,dx = 0.\]

쓰는 것

  • 부분적분(공통1 6-01). 곱의 미분.
  • 경계 조건이 동차(0이 들어간 꼴)라는 것.

아이디어

두 고유함수의 방정식을 엇갈려 곱해 빼면, 미분 항이 하나의 완전미분 \((p(y_my_n' - y_ny_m'))'\)로 묶입니다. 그것을 적분하면 경계값만 남는데, 경계 조건이 그것을 0으로 만듭니다. 그러면 \((\lambda_m - \lambda_n)\int y_my_nw = 0\)만 남습니다.

증명

  1. \((py_m')' + qy_m = -\lambda_mwy_m\), \((py_n')' + qy_n = -\lambda_nwy_n\).
    고유함수의 정의.
  2. 첫 식에 \(y_n\), 둘째 식에 \(y_m\)을 곱해 빼면 \(y_n(py_m')' - y_m(py_n')' = (\lambda_n - \lambda_m)wy_my_n\).
    \(qy_my_n\) 항이 상쇄된다.
  3. 왼쪽 \(= \left[p(y_ny_m' - y_my_n')\right]'\).
    곱의 미분으로 확인: \((py_m')'y_n + py_m'y_n' - (py_n')'y_m - py_n'y_m'\). 가운데 두 항이 상쇄.
  4. \([a, b]\)에서 적분: \(\left[p(y_ny_m' - y_my_n')\right]_a^b = (\lambda_n - \lambda_m)\int_a^bwy_my_n\,dx\).
    미적분의 기본정리.
  5. Dirichlet(\(y = 0\))이면 괄호의 두 항이 모두 0. Neumann(\(y' = 0\))도 마찬가지. Robin \(y' = -hy\)이면 \(y_n(-hy_m) - y_m(-hy_n) = 0\). 어느 경우든 왼쪽은 0.
    두 고유함수가 같은 경계 조건을 만족한다.
  6. \(\lambda_n \ne \lambda_m\)이므로 \(\int_a^bwy_my_n\,dx = 0\).
    양변을 \(\lambda_n - \lambda_m \ne 0\)으로 나눔.

되짚기와 예

  • 사인: \(p = 1\), \(q = 0\), \(w = 1\), \([0, L]\), Dirichlet: 고유함수 \(\sin\frac{n\pi x}{L}\). 정리가 2-01 카드의 직교성을 다시 줍니다.
  • Legendre: \(((1 - x^2)y')' + n(n + 1)y = 0\)은 \(p = 1 - x^2\), \(w = 1\)인 꼴. 양 끝 \(x = \pm1\)에서 \(p = 0\)이라 경계항이 저절로 사라지고(특이 Sturm-Liouville), \(P_n\)들이 직교합니다(공통8 7-03).
  • Bessel: \(w = x\)인 꼴이라 \(\int xJ(\alpha_ix)J(\alpha_jx)dx = 0\), 무게 \(x\)가 붙습니다(원판의 넓이 요소 \(r\,dr\)에서 옴).
  • 가정이 깨지면: 경계 조건이 동차가 아니거나(\(y(0) = 1\)) 주기 조건이 아닌 다른 조건이면 경계항이 남아 직교성이 깨질 수 있습니다.

더 나아가 이 문제의 고유값은 모두 실수이고, \(\lambda_1 < \lambda_2 < \cdots \to \infty\)로 늘어서며, 고유함수들로 웬만한 함수를 급수 전개할 수 있습니다(완비성, 증명은 함수해석). 이것이 변수분리법이 늘 통하는 이유입니다.

직접 써 보기

\(y'' + \lambda y = 0\), \(y'(0) = y'(\pi) = 0\)의 고유값과 고유함수를 구하고 직교성을 확인하세요.

답안

\(\lambda_n = n^2\) (\(n = 0, 1, 2, \dots\)), \(y_n = \cos nx\). \(\lambda = 0\)도 고유값(\(y = 1\)): Neumann에서는 상수가 허용됩니다. \(\int_0^\pi\cos mx\cos nx\,dx = 0\) (\(m \ne n\)). 코사인 반구간 급수가 여기서 나옵니다.
