일차분수변환

본문
이 절에서 배울 것
  • 일차분수변환이 평행이동, 회전·확대, 역수의 합성임을 안다.
  • 원과 직선을 원과 직선으로 옮기는 성질로 영역을 옮긴다.
먼저 알아야 할 것
  • 등각사상 (6.1절).

6.2.1정의와 구성

정의 6.2.1 (일차분수변환) \[w = \frac{az + b}{cz + d}, \quad ad - bc \ne 0.\]

뫼비우스 변환이라고도 합니다. \(w' = \frac{ad - bc}{(cz + d)^2} \ne 0\)이므로 어디서나 등각입니다. \(c \ne 0\)이면 나눗셈을 해서 다음 네 단계의 합성으로 쓸 수 있습니다.

  1. 평행이동 \(z + \frac dc\).
  2. 역수 \(\frac{1}{(\cdot)}\).
  3. 회전·확대 (복소수 곱하기).
  4. 평행이동.

평행이동과 회전·확대는 도형의 모양을 바꾸지 않습니다. 역수 \(w = \frac1z\)은 원과 직선을 원 또는 직선으로 옮깁니다(직선은 "반지름이 무한한 원"으로 봅니다). 따라서

정리 6.2.2

일차분수변환은 원과 직선을 원 또는 직선으로 옮긴다. 또 서로 다른 세 점을 원하는 세 점으로 보내는 일차분수변환이 단 하나 있다.

\(\infty\)도 하나의 점으로 생각하면 편리합니다. \(w = \frac{az + b}{cz + d}\)는 \(z = -\frac dc\)를 \(\infty\)로, \(\infty\)를 \(\frac ac\)로 보냅니다.

6.2.2반평면을 원판으로

예제 6.2.3

\(w = \frac{z - i}{z + i}\)가 위쪽 반평면 \(\text{Im}\,z > 0\)을 단위원판 \(|w| < 1\)로 옮김을 보여라.

풀이. \(|w| = \frac{|z - i|}{|z + i|}\)는 \(z\)에서 \(i\)까지 거리와 \(-i\)까지 거리의 비입니다.

  • 실수축 위의 \(z\)는 \(i\)와 \(-i\)에서 같은 거리이므로 \(|w| = 1\): 실수축 → 단위원.
  • 위쪽 반평면의 \(z\)는 \(i\)에 더 가까우므로 \(|w| < 1\): 안쪽.
  • 확인: \(z = i \to w = 0\) (중심).

이런 변환은 반평면에서 푼 문제의 답을 원판의 답으로 바꾸는 데 씁니다(6.4절).

요약
  1. \(w = \frac{az + b}{cz + d}\): 이동, 역수, 회전·확대의 합성. 어디서나 등각.
  2. 원·직선 → 원·직선. 세 점으로 결정된다.

6.2.3연습문제

기본

  1. \(w = \frac{z - i}{z + i}\)는 \(z = 0, 1, \infty\)를 어디로 보내는가?
    답

    \(-1\), \(\frac{1 - i}{1 + i} = -i\), \(1\). 모두 단위원 위.

  2. \(w = \frac1z\)은 원 \(|z| = 2\)를 어디로 보내는가?
    답

    원 \(|w| = \frac12\).
