주기 함수의 Fourier 계수 구하기

직교성 · aₙ, bₙ 공식 · 사각파 · 문제 해결 전략

식의 출처

주기 \(2L\)인 함수를 \(f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right)\)로 쓰려 한다. 핵심은 직교성: \(\int_{-L}^L\cos\frac{m\pi x}{L}\cos\frac{n\pi x}{L}dx = 0\) (\(m \ne n\)), \(\sin\)끼리도 마찬가지, \(\sin\)과 \(\cos\)은 언제나 0. 양변에 \(\cos\frac{n\pi x}{L}\)을 곱해 적분하면 다른 항이 모두 사라져

\[a_n = \frac1L\int_{-L}^Lf(x)\cos\frac{n\pi x}{L}dx, \qquad b_n = \frac1L\int_{-L}^Lf(x)\sin\frac{n\pi x}{L}dx.\]

공통2 1-01의 정사영 \(\frac{\mathbf a\cdot\mathbf b}{\mathbf a\cdot\mathbf a}\)과 같은 구조이다: 함수를 "직교 기저 함수" 방향으로 정사영한 성분이 계수이다.

문제 해결 전략 · Fourier 급수
  1. 주기 \(2L\)과 한 주기에서의 식을 적는다. 그래프를 그린다.
  2. 기함수면 \(a_n = 0\) (사인 급수), 우함수면 \(b_n = 0\) (코사인 급수). 계산이 반으로 준다(공통1 5-04).
  3. 계수 적분은 부분적분, \(\cos n\pi = (-1)^n\), \(\sin n\pi = 0\)을 쓴다.
  4. 불연속점에서 급수는 좌우 극한의 평균으로 수렴함을 기억한다(공통8-06-01 카드).
  5. 몇 항의 부분합을 그려 원래 함수와 비교한다.

주기 \(2\pi\)인 사각파 \(f(x) = -1\) (\(-\pi < x < 0\)), \(1\) (\(0 < x < \pi\))의 Fourier 급수를 구하여라.

풀이

  1. \(f\)는 기함수이므로 \(a_n = 0\) (\(a_0\) 포함).
    기함수 × 우함수(\(\cos\)) = 기함수, 대칭 구간 적분 0.
  2. \(b_n = \frac1\pi\int_{-\pi}^\pi f\sin nx\,dx = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2}{n\pi}(1 - \cos n\pi) = \frac{2}{n\pi}(1 - (-1)^n)\).
    기함수 × 기함수 = 우함수라 2배.
  3. \(n\) 짝수: \(b_n = 0\). 홀수: \(b_n = \frac{4}{n\pi}\).
    \(1 - (-1)^n\)이 0 또는 2.
  4. \(f(x) = \frac4\pi\left(\sin x + \frac{\sin3x}{3} + \frac{\sin5x}{5} + \cdots\right)\).
    홀수 배음만.

의미

사각파는 기본 진동수의 홀수 배음을 \(\frac1n\) 세기로 섞은 것이다. 클라리넷 소리가 홀수 배음이 강한 것(공통3 6-03의 닫힌 관), 디지털 신호(0과 1의 사각파)를 보내려면 넓은 주파수 대역이 필요한 이유가 이것이다. 계수가 \(\frac1n\)로 천천히 줄어드는 것은 함수가 불연속이기 때문입니다(매끄러울수록 계수가 빨리 줄어듦).

검산

\(x = \frac\pi2\)를 넣으면 \(1 = \frac4\pi\left(1 - \frac13 + \frac15 - \cdots\right)\), 곧 \(1 - \frac13 + \frac15 - \cdots = \frac\pi4\). 공통1 8-05의 \(\arctan1\) 급수(라이프니츠 급수)와 일치한다.
