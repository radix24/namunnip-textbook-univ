리스트, 딕셔너리, 반복문으로 자료 처리

본문

여러 조가 낸 중력 가속도 측정값이 뒤섞인 목록으로 들어왔다. 조별로 모아 평균을 내려면, 포트란처럼 조마다 배열을 미리 만들어 두어야 할까? 파이썬에서는 반복문 몇 줄로 끝나는 이 일을 어떤 도구로 짧게 쓸까? 그리고 수 계산을 많이 할 때는 왜 리스트 대신 다른 배열을 쓸까?

먼저 알아야 할 것리스트, 딕셔너리, 반복문(전자계산(1) 2.1절~2.3절)과 포트란 배열(1.3절)을 쓴다.

3.2.1리스트 컴프리헨션

"각 원소에 무엇을 해서 새 리스트를 만든다"는 반복문은 한 줄로 쓸 수 있으며, 이것을 리스트 컴프리헨션이라 한다. 함께 쓰는 zip은 두 목록을 짝지어 묶고, enumerate는 번호와 원소를 함께 준다.

T_c = [20.1, 24.8, 29.2, 33.0]
T_k = [t + 273.15 for t in T_c]             # 모두 바꾸기
hot = [t for t in T_c if t > 25]            # 조건에 맞는 것만
pairs = list(zip([0, 30, 60, 90], T_c))      # [(0, 20.1), (30, 24.8), ...]
for i, (t, T) in enumerate(pairs):
    print(i, t, T)

포트란의 암시적 do [(0.01_dp*i, i = 0, 100)]과 비슷한 생각이다.

3.2.2딕셔너리로 모으기

예제 3.2.1

여러 조의 측정값 [("A", 9.71), ("B", 9.85), ("A", 9.78), ("B", 9.80), ("A", 9.83)]을 조별로 모아 평균을 구하여라.

풀이. 처음 질문의 답은 조 이름을 키로 하는 딕셔너리이다. 조가 몇 개인지 미리 알 필요가 없다.

data = [("A", 9.71), ("B", 9.85), ("A", 9.78), ("B", 9.80), ("A", 9.83)]
groups = {}
for team, g in data:
    groups.setdefault(team, []).append(g)    # 없으면 빈 리스트를 만들고 추가
for team, vals in sorted(groups.items()):
    print(team, len(vals), round(sum(vals) / len(vals), 3))
# A 3 9.773
# B 2 9.825

setdefault(team, [])는 그 키가 있으면 리스트를 꺼내고, 없으면 빈 리스트를 넣은 뒤 꺼낸다. 그림 1에서 값을 하나씩 처리하면 A조와 B조의 리스트가 자라는 것을 볼 수 있다. 다 모으면 A조는 3개, 평균 9.773이고 B조는 2개, 평균 9.825이다.

3.2.3리스트와 NumPy 배열

파이썬 리스트는 아무 자료형이나 섞어 담을 수 있다. 그 대신 수 계산에는 느리고, [1, 2] * 2가 [1, 2, 1, 2](반복)가 되는 것처럼 수학 연산을 하지 않는다. 그래서 과학 계산에는 포트란 배열처럼 같은 자료형을 이어 담는 NumPy 배열을 쓴다.

import numpy as np
x = np.array([1.0, 2.0, 3.0])
print(x * 2)            # [2. 4. 6.]   원소마다 곱하기
print(np.sin(x).sum())  # 배열 전체 연산 (포트란과 비슷)
A = np.array([[1, 2], [3, 4]])
print(A @ A)            # 행렬 곱 (포트란의 matmul)
print(A[0, 1])          # 2  (인덱스는 0부터, 행 우선)

NumPy 배열 연산은 안에서 C로 만든 코드가 돌아, 파이썬 반복문보다 수십 배 이상 빠른 경우가 많다(5.4절에서 비교).

마무리

리스트 컴프리헨션 [식 for x in 묶음 if 조건]과 zip, enumerate로 반복을 짧게 쓴다. 처음 질문의 조별 모으기는 setdefault나 get으로 딕셔너리에 붙여 나가면 조의 수를 몰라도 된다. 수 계산에는 원소마다 연산하고 @로 행렬을 곱하는 NumPy 배열을 쓴다.
