잡음 섞인 붕괴 자료 맞추기

실습 · 로그 변환과 최소제곱

목표

\(y = 10e^{-0.5t}\)에 잡음을 섞은 가짜 실험 자료를 만들어, \(\ln y\)를 직선으로 맞춘 결과가 참값에 얼마나 가까운지, 그냥 직선을 맞추면 어떻게 되는지 비교합니다. 성취기준 [공통11-05-03].

준비

빨간 점이 자료, 파란 곡선이 로그 변환으로 맞춘 지수 함수, 회색 점선이 그냥 맞춘 직선입니다. 잡음은 각 점에 곱하는 상대 오차의 표준편차입니다. "새 자료"를 누르면 같은 조건에서 잡음만 새로 뽑습니다.

절차

  1. 잡음 0%에서 맞춘 \(A\), \(k\)가 참값(10, 0.5)과 같은지 확인한다.
  2. 잡음 5%와 20%에서 "새 자료"를 여러 번 눌러 \(k\)가 얼마나 흔들리는지 본다.
  3. 점 수를 늘려 같은 일을 한다.
  4. 세로축 로그 눈금을 켜서 자료가 직선으로 보이는지 본다.

기대 결과

  • 잡음이 없으면 \(A = 10\), \(k = 0.5\), \(R^2 = 1\)이 정확히 나온다.
  • 잡음이 크면 \(k\)가 크게 흔들리고, 점 수가 많을수록 덜 흔들린다.
  • 그냥 직선은 \(R^2\)이 낮고, \(t = 6\)에서 음수를 예측하기도 한다.
  • 로그 눈금에서는 지수 자료가 직선 둘레에 흩어져 보인다.

분석

  1. 로그 눈금에서 \(t\)가 큰(\(y\)가 작은) 점들이 더 많이 흩어져 보이는 경우가 있습니다. 같은 상대 잡음이라도 0 근처에서 잘라 낸 값이 로그에서 크게 벗어나는 이유를 말해 보세요.
  2. 공통7의 회귀 카드에서 배운 \(R^2\)의 뜻으로, 그냥 직선의 \(R^2\)이 낮은 이유를 설명해 보세요.
