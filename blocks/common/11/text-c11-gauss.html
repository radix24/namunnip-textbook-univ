가우스 소거로 연립방정식 풀기

본문

전기 회로의 키르히호프 방정식, 화학 반응식의 계수 맞추기, 최소제곱 맞춤은 모두 연립일차방정식 \(A\mathbf{x} = \mathbf{b}\)가 된다. 미지수가 셋이면 손으로 풀지만, 천 개라면? 손으로 하던 소거법을 프로그램으로 옮길 때 무엇을 더 조심해야 할까?

먼저 알아야 할 것행렬과 연립방정식(미분적분학(2) 2.1절)과 포트란 배열과 서브루틴(1.3절, 2.1절)을 쓴다.

5.1.1알고리즘

처음 질문처럼 손으로 하던 소거법을 그대로 프로그램으로 옮긴다. 알고리즘은 두 단계이다. 먼저 전진 소거에서는 \(k = 1, \dots, n-1\)열마다, \(k\)행 아래의 각 행 \(i\)에서 \(m = a_{ik}/a_{kk}\)배한 \(k\)행을 빼서 \(a_{ik}\)를 0으로 만든다. 이때 \(b_i\)도 함께 바꾼다. 그러면 위 삼각 행렬이 되므로, 다음 후진 대입에서 마지막 행부터 \(x_i = \left(b_i - \sum_{j>i} a_{ij}x_j\right)/a_{ii}\)로 답을 구한다.

예제 5.1.1

\(2x + y - z = 8\), \(-3x - y + 2z = -11\), \(-2x + y + 2z = -3\)을 풀어라.

풀이. 위 알고리즘에 부분 피벗팅(5.1.2절)을 더한 포트란 서브루틴은 다음과 같다.

subroutine gauss(A, b, x)
  real(dp), intent(inout) :: A(:, :), b(:)
  real(dp), intent(out)   :: x(:)
  integer :: n, i, k, p
  real(dp) :: m
  n = size(b)
  do k = 1, n - 1
    p = maxloc(abs(A(k:n, k)), dim=1) + k - 1     ! 부분 피벗팅
    if (p /= k) then
      A([k, p], :) = A([p, k], :)                  ! 두 행 맞바꾸기
      b([k, p]) = b([p, k])
    end if
    do i = k + 1, n
      m = A(i, k) / A(k, k)
      A(i, k:n) = A(i, k:n) - m * A(k, k:n)
      b(i) = b(i) - m * b(k)
    end do
  end do
  do i = n, 1, -1
    x(i) = (b(i) - sum(A(i, i+1:n) * x(i+1:n))) / A(i, i)
  end do
end subroutine gauss

그림 1에서 단계를 넘기며 따라가 보자. 1열에서 절댓값이 가장 큰 −3이 2행에 있으므로 먼저 1행과 2행을 바꾼다. 이어서 2행과 3행에서 1열을 지우면 2열 아래쪽에 \(\frac13\)과 \(\frac53\)이 남는다. 다시 더 큰 \(\frac53\)이 있는 행을 위로 올리고 3행을 지우면 마지막 행이 \(\frac15 z = -\frac15\)가 된다. 그러므로 \(z = -1\)이고, 위로 올라가며 \(y = 3\), \(x = 2\)를 얻는다.

파이썬에서는 같은 알고리즘을 NumPy로 쓰거나, 검증된 라이브러리 numpy.linalg.solve(A, b)를 쓴다. 이 함수는 안에서 LAPACK이라는 포트란 라이브러리를 부른다.

5.1.2부분 피벗팅

처음 질문의 "더 조심할 것"이 이것이다. \(a_{kk}\)가 0이면 나눌 수 없고, 0은 아니어도 아주 작으면 \(m\)이 커져 반올림 오차가 크게 불어난다. 그래서 \(k\)열의 \(k\)행 아래에서 절댓값이 가장 큰 원소가 있는 행을 \(k\)행과 바꾼 뒤 소거한다(위 코드의 maxloc). 이것을 부분 피벗팅이라 한다. 예를 들어 \(10^{-20}x + y = 1\), \(x + y = 2\)를 피벗팅 없이 배정도로 풀면 \(x = 0\)이 나오지만, 행을 바꾸면 올바른 \(x \approx 1\)을 얻는다. 아래 실습 카드에서 단계마다 행렬이 바뀌는 모습을 더 볼 수 있다.

5.1.3계산량

전진 소거의 곱셈 수는 약 \(\frac{n^3}{3}\), 후진 대입은 \(\frac{n^2}{2}\)이다. 따라서 \(n\)이 10배 커지면 시간은 약 1000배가 된다. 처음 질문의 미지수 천 개라면 곱셈이 약 \(3\times10^8\)번이라 컴퓨터로는 금방이지만, 만 개가 되면 천 배가 걸린다. 한편 같은 \(A\)에 \(\mathbf{b}\)만 바꿔 여러 번 풀 때는 소거 과정을 저장해 두는 LU 분해를 쓴다.

마무리

가우스 소거는 전진 소거로 위 삼각 행렬을 만든 뒤 후진 대입으로 답을 구한다. 처음 질문처럼 프로그램으로 옮길 때는 열마다 절댓값이 가장 큰 원소를 피벗으로 올리는 부분 피벗팅을 해야 반올림 오차가 불어나지 않는다. 계산량은 약 \(n^3/3\)이므로 \(n\)이 10배면 시간은 약 1000배이다.
