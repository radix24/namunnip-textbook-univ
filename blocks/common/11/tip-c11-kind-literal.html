포트란 실수 계산은 정수 나눗셈과 단정도 상수부터 의심하고, 상수에 _dp를 붙인다

요령 · 포트란의 수와 정밀도

언제 쓰는가

포트란 결과가 0이 나오거나, 배정도 변수에 넣었는데 소수 여덟째 자리쯤부터 값이 이상할 때이다.

요령

  1. 정수끼리 나누면 정수
    2/3은 0이다. 실수 변수에 넣어도 이미 0이 된 뒤이다.
  2. 상수의 정밀도
    2.0은 단정도(약 7자리)이다. real(dp) 변수에 넣어도 앞 계산이 단정도로 이루어진다.
  3. _dp를 붙인다
    integer, parameter :: dp = kind(1.0d0)를 두고 상수를 2.0_dp로 쓴다.
  4. 출력 자릿수로 확인
    print '(F20.16)', a처럼 자릿수를 넉넉히 찍어 몇 자리까지 맞는지 본다.

흔한 실수

  • real(dp) :: a로 선언했으니 a = 2.0/3도 배정도로 계산될 것이라 보는 것.
  • implicit none 없이 써서 오타 변수가 정수로 몰래 만들어지는 것.

바로 풀어보기

real(dp) :: a일 때 a = 2/3, a = 2.0/3, a = 2.0_dp/3의 결과를 소수 16자리로 예측하여라.

답과 풀이

답: 0.0, 0.6666666865348816, 0.6666666666666666

2/3은 정수 나눗셈이라 0이다. 2.0/3은 단정도로 계산된 0.6666667을 배정도로 옮긴 값이라 여덟째 자리부터 틀린다. 2.0_dp/3만 배정도로 계산되어 16자리까지 맞다. 상수 하나의 꼬리표가 결과의 정밀도를 정한다.

이 요령으로 풀리는 문제

  • 포트란 기초 단원 연습 1번, 2번, 6번
영상 콘티 · 40초
  1. 0~5초a = 2/3, a = 2.0/3, a = 2.0_dp/3 세 줄이 나란히 실행 버튼 옆에 놓인다.셋 다 같은 값일까?
  2. 5~13초첫 줄의 2와 3 위에 'integer' 꼬리표가 붙고 결과 0이 떨어진다.정수끼리 나누면 0.
  3. 13~23초둘째 줄 2.0에 '단정도 7자리' 꼬리표가 붙고, 결과가 배정도 상자로 옮겨질 때 뒷자리가 엉뚱한 숫자로 채워진다.상수가 단정도면 계산도 단정도이다.
  4. 23~32초셋째 줄 2.0_dp에 '배정도 16자리' 꼬리표가 붙고 6이 끝까지 이어진다.상수에 _dp를 붙인다.
  5. 32~40초세 결과가 소수 16자리 눈금 위에 겹쳐 놓여 어디서부터 갈라지는지 보인다.자릿수를 넉넉히 찍어 확인한다.
