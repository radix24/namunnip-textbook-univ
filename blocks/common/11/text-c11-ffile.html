포트란 파일 입출력

본문

실험실 기록계가 시각과 온도를 수천 줄 담은 파일을 남겼다. 이 파일을 포트란으로 끝까지 읽고, 켈빈으로 바꾼 결과를 열을 맞춰 새 파일에 쓰려면 어떻게 해야 할까? 몇 줄인지 모를 때 "파일 끝"은 어떻게 알아챌까?

먼저 알아야 할 것파이썬 파일 처리(전자계산(1) 3.2절)와 포트란 배열(1.3절)을 쓴다.

2.2.1장치 번호

포트란은 파일을 장치 번호(unit)에 연결해 다룬다. print *와 read *는 화면과 키보드에 연결된 기본 장치이다. 그리고 newunit=을 쓰면 비어 있는 번호를 저절로 골라 준다.

integer :: u, ios, n
real(dp) :: t, T_c
real(dp) :: tarr(1000), tcarr(1000)

open(newunit=u, file="data.txt", status="old", action="read", iostat=ios)
if (ios /= 0) stop "data.txt를 열 수 없습니다"
read(u, *)                      ! 첫 줄(제목) 건너뛰기
n = 0
do
  read(u, *, iostat=ios) t, T_c
  if (ios /= 0) exit            ! 파일 끝이면 음수, 읽기 오류면 양수
  n = n + 1
  tarr(n) = t;  tcarr(n) = T_c
end do
close(u)
print *, n, "줄을 읽었습니다"

처음 질문의 "파일 끝"은 iostat이 알려 준다. 읽기에 성공하면 0, 파일 끝이면 음수, 읽기 오류면 양수가 들어오므로, 조건 없는 do 안에서 0이 아니면 exit한다. 또 read(u, *)의 *는 목록 지향 입력이라, 공백이나 쉼표로 나뉜 수를 차례로 읽는다. 한편 status는 "old"(있어야 함), "new"(없어야 함), "replace"(있으면 덮어씀) 가운데 하나이다.

포트란에서는 변수 이름의 대소문자를 구별하지 않으므로 t와 T는 같은 변수이다. 그래서 위에서는 온도를 T_c로, 배열을 tarr, tcarr로 썼다. 가령 ts와 Ts를 함께 선언하면 같은 이름이라 컴파일 오류가 난다.

2.2.2형식을 정한 출력

처음 질문의 둘째 일, 곧 열을 맞춘 출력은 write에 형식을 주어 한다.

open(newunit=u, file="result.txt", status="replace", action="write")
write(u, '(A8, A10)') "t(s)", "T(K)"
do i = 1, n
  write(u, '(F8.1, F10.2)') tarr(i), tcarr(i) + 273.15_dp
end do
close(u)
형식뜻예 (값 → 출력)
I5정수, 5칸42 → 42
F8.3고정 소수점, 8칸, 소수 3자리3.14159 → 3.142
ES12.4과학적 표기, 소수 4자리0.000123 → 1.2300E-04
A, A8문자열
3F8.2, 2X같은 형식 3번, 빈칸 2개

그림 1에서 형식을 하나씩 골라 보면 각 형식이 몇 칸을 차지하는지 보인다. 가령 F8.3은 3.14159를 소수 셋째 자리로 반올림해 8칸에 오른쪽 맞춤으로 찍는다. 그런데 F4.1로 300.15를 찍으면 300.2에 5칸이 필요해 별표 ****가 찍힌다. 즉 출력에 별표가 보이면 값이 틀린 것이 아니라 칸이 모자란 것이다.

이렇게 열을 맞춘 파일은 파이썬이나 표 계산 프로그램에서 바로 읽을 수 있다. 그래서 계산은 포트란으로 하고 그래프는 파이썬(5.3절)으로 그리는 식으로 나누어 쓰기 좋다.

마무리

포트란은 open(newunit=u, file=..., status=..., iostat=...)으로 파일을 장치 번호에 잇고 read(u, *), write(u, 형식), close(u)로 다룬다. 처음 질문의 파일 끝은 do 안에서 iostat이 0이 아니면 exit하는 것으로 처리한다. 형식 I, F, ES, A, X로 열을 맞추며, 칸이 모자라면 별표가 찍힌다.
