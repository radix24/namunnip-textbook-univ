평균과 표준편차를 구하는 함수를 실험마다 새 파일에 다시 베껴 쓰고 있다면, 한 곳을 고칠 때 모든 파일을 고쳐야 한다. 함수를 한 곳에 모아 두고 불러 쓰려면 어떻게 할까? 또 용수철 진동자처럼 상태가 계속 바뀌는 시뮬레이션은 어떤 꼴로 정리하면 조건을 바꿔 비교하기 쉬울까?

먼저 알아야 할 것모듈과 클래스(전자계산(1) 3.3절), 포트란 모듈(2.1절), 함수로 나누기(4.1절)를 쓴다.

4.2.1내 모듈 만들기

처음 질문의 첫째 답은 모듈이다. 4.1절의 함수들을 labtools.py 한 파일에 모으면, 같은 폴더의 다른 프로그램에서 불러 쓸 수 있다. 포트란의 module과 use에 해당한다.

# labtools.py
"""실험 자료 처리용 함수 모음"""
R = 8.314

def mean(xs):
    return sum(xs) / len(xs)

def stdev(xs):
    m = mean(xs)
    return (sum((x - m) ** 2 for x in xs) / (len(xs) - 1)) ** 0.5

if __name__ == "__main__":       # 직접 실행할 때만: 간단한 시험
    assert abs(mean([1, 2, 3]) - 2) < 1e-12
    print("labtools 시험 통과")
# analyze.py
import labtools as lt
g = [9.71, 9.85, 9.78, 9.80, 9.83]
print(lt.mean(g), lt.stdev(g))

모듈 아래에 if __name__ == "__main__":으로 시험 코드를 넣어 두면, 함수를 고친 뒤 그 파일만 실행해서 바로 확인할 수 있다. 한편 파일이 많아지면 폴더(패키지)로 묶는다.

4.2.2클래스로 시뮬레이션 정리하기

처음 질문의 둘째 답은 클래스이다. 시뮬레이션의 상태(위치, 속도, 시간)와 동작(한 걸음 나아가기, 에너지 계산)을 클래스로 묶으면, 여러 개를 따로 돌리거나 조건을 바꿔 비교하기 쉽다.

class Oscillator:
    """용수철 진동자 x'' = -(k/m) x 를 오일러-크로머 방법으로 푼다"""
    def __init__(self, k=1.0, m=1.0, x=1.0, v=0.0):
        self.k, self.m, self.x, self.v, self.t = k, m, x, v, 0.0

    def step(self, dt):
        self.v += -(self.k / self.m) * self.x * dt   # 속도 먼저
        self.x += self.v * dt                         # 새 속도로 위치
        self.t += dt

    def energy(self):
        return 0.5 * self.m * self.v**2 + 0.5 * self.k * self.x**2

osc = Oscillator()
for _ in range(1000):
    osc.step(0.01)
print(osc.t, osc.x, osc.energy())    # t = 10에서 x ≈ cos(10), 에너지 ≈ 0.5

새 기능(감쇠, 바깥 힘)을 넣고 싶으면 이 클래스를 물려받아(상속) step만 고친 클래스를 만들 수 있다. 그런데 step의 두 줄 순서가 결과를 크게 바꾼다. 위치를 먼저 바꾸면 보통의 오일러 방법이 되어 에너지가 점점 늘어난다. 그림 1에서 방법을 "오일러"로 바꾸면 \(dt = 0.1\)에서 궤적이 바깥으로 풀려 나가고, \(t = 10\)에서 에너지가 처음 0.5의 약 2.7배가 된다. 하지만 오일러-크로머는 에너지가 0.5 둘레에서 조금씩 오르내릴 뿐이다. 이 차이는 5.2절에서 다시 다룬다.

마무리

처음 질문처럼 자주 쓰는 함수는 .py 파일 하나에 모아 import하고, 아래쪽에 if __name__ == "__main__":으로 시험 코드를 둔다. 상태가 바뀌는 시뮬레이션은 상태와 동작을 클래스로 묶으면 여러 조건을 나란히 돌리기 쉽다. 그림 1처럼 step 안의 순서 하나가 에너지 보존을 가르므로, 방법을 바꾼 결과는 늘 에너지 같은 양으로 확인한다.
