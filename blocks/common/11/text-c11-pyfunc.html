함수와 파일 처리로 프로그램 짜기

본문

  • 함수를 다른 함수의 인수로 넘긴다.

먼저 알아야 할 것
  • 파이썬 함수와 파일 (공통10 3.1절, 3.2절), 포트란 서브루틴 (2.1절).

4.1.1프로그램을 함수로 나누기

긴 프로그램은 "자료 읽기 → 계산 → 결과 쓰기"처럼 단계별 함수로 나누면 읽기 쉽고, 단계마다 따로 시험할 수 있습니다. 파이썬 함수는 인수를 객체로 넘기므로, 리스트를 넘기고 함수 안에서 append하면 바깥 리스트가 바뀝니다(포트란의 참조 전달과 비슷). 하지만 함수 안에서 이름에 새 값을 대입하면 바깥에는 영향이 없습니다. 결과는 되도록 return으로 돌려주는 것이 깔끔합니다.

import csv

def read_data(path):
    """첫 줄은 제목, 이후 t, T가 쉼표로 나뉜 CSV를 읽는다"""
    ts, Ts = [], []
    with open(path, encoding="utf-8", newline="") as f:
        reader = csv.reader(f)
        next(reader)                       # 제목 줄 건너뛰기
        for row in reader:
            ts.append(float(row[0]))
            Ts.append(float(row[1]))
    return ts, Ts

def rate(ts, Ts):
    return (Ts[-1] - Ts[0]) / (ts[-1] - ts[0])

def write_result(path, value):
    with open(path, "w", encoding="utf-8") as f:
        f.write(f"rate,{value:.5f}\n")

if __name__ == "__main__":
    ts, Ts = read_data("data.csv")
    write_result("result.csv", rate(ts, Ts))

마지막 if __name__ == "__main__": 아래는 이 파일을 직접 실행할 때만 돌아갑니다. 다른 파일에서 import하면 함수만 가져가고 이 부분은 실행되지 않습니다(4.2절).

4.1.2함수를 인수로 넘기기

파이썬에서는 함수도 값이라 다른 함수에 넘길 수 있습니다. 공통10 6.2절의 trapezoid(f, a, b, n)이 그 예입니다. 짧은 함수는 lambda로 그 자리에서 만듭니다.

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)     # 중앙 차분

import math
print(derivative(math.sin, 0.0))               # 약 1.0
print(derivative(lambda x: x**3, 2.0))         # 약 12.0

4.1.3NumPy로 한 번에 읽기

숫자만 있는 표 파일은 numpy.loadtxt로 한 줄에 읽을 수 있습니다.

import numpy as np
data = np.loadtxt("data.csv", delimiter=",", skiprows=1)
t, T = data[:, 0], data[:, 1]        # 첫째 열, 둘째 열
np.savetxt("kelvin.csv", np.column_stack([t, T + 273.15]),
           delimiter=",", header="t,T_K", fmt="%.2f", comments="")

포트란 프로그램이 형식을 맞춰 쓴 출력 파일(2.2절)도 같은 방법으로 읽어 그래프를 그립니다.

요약
  1. 읽기·계산·쓰기를 함수로 나누고, if __name__ == "__main__":에서 이어 붙인다.
  2. 함수는 값이므로 인수로 넘길 수 있다. lambda.
  3. csv.reader, np.loadtxt, np.savetxt.
