뉴턴 방법은 맞는 자릿수가 매번 두 배로 늘어나는지 보고, 멀리서 시작하면 이분법으로 먼저 좁힌다

요령 · 뉴턴 방법

언제 쓰는가

\(f(x) = 0\)의 근을 뉴턴 방법으로 구하고, 몇 번 반복해야 하는지, 수렴이 맞는지 판단할 때입니다.

요령

  1. 갱신식
    \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\).
  2. 자릿수를 센다
    근 근처에서는 오차가 \(e_{n+1} \approx Ce_n^2\)이라 맞는 자릿수가 2, 4, 8로 늘어납니다. 그렇지 않으면 도함수 식이나 코드를 의심합니다.
  3. 출발점이 멀면
    그래프가 크게 휘거나 \(f'\)이 0에 가까운 곳에서는 엉뚱한 곳으로 튑니다. 이분법으로 근이 있는 구간을 좁힌 뒤 뉴턴으로 마무리합니다.
  4. 멈춤 조건
    \(|x_{n+1} - x_n|\)과 \(|f(x_n)|\)이 모두 허용 오차보다 작으면 멈춥니다.

흔한 실수

  • 도함수를 틀리게 넣어 1차 수렴으로 느려졌는데 알아채지 못하는 것.
  • 반복 횟수 상한 없이 돌려 발산할 때 끝나지 않는 것.

바로 풀어보기

\(x^3 - 2x - 5 = 0\)을 \(x_0 = 2\)에서 뉴턴 방법으로 두 번 반복하세요. 근 2.0945515와 비교해 오차가 어떻게 줄어드는지 말하세요.

답과 풀이

답: \(x_1 = 2.1\), \(x_2 \approx 2.0945682\). 오차 0.095 → 0.0054 → 0.000017

\(f(2) = -1\), \(f'(2) = 10\)이므로 \(x_1 = 2.1\). \(f(2.1) = 0.061\), \(f'(2.1) = 11.23\)이므로 \(x_2 = 2.1 - 0.00543 = 2.0945682\)입니다.

오차는 0.095, 0.0054, 0.000017로, 맞는 자릿수가 1, 2, 4자리로 두 배씩 늘어납니다. 한 번 더 하면 약 \(10^{-10}\)입니다. 이분법은 같은 정확도에 30번 넘게 걸립니다.

이 요령으로 풀리는 문제

  • 과학 계산 프로그래밍 단원 연습 7번
영상 콘티 · 40초
  1. 0~5초\(y = x^3 - 2x - 5\) 곡선과 \(x_0 = 2\)의 점이 보입니다.근에 얼마나 빨리 다가갈까요?
  2. 5~13초점에서 접선이 그어져 \(x\)축과 만나는 곳 2.1로 점이 내려옵니다.접선이 \(x\)축과 만나는 곳으로.
  3. 13~22초한 번 더 접선을 긋자 점이 근에 거의 붙고, 화면이 확대됩니다.근 근처에서는 아주 빠릅니다.
  4. 22~31초오른쪽에 맞는 자릿수 막대가 1, 2, 4, 8칸으로 두 배씩 자랍니다.자릿수가 두 배씩 늘어납니다.
  5. 31~40초다른 출발점에서는 접선이 평평한 곳에서 멀리 튕겨 나가고, 이분법이 구간을 먼저 좁힌 뒤 뉴턴이 마무리하는 장면.멀면 이분법으로 먼저 좁힙니다.
