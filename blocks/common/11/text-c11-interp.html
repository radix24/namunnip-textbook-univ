보간: 측정점 사이의 값 어림하기

본문

물성표에는 20 °C와 40 °C의 값만 있는데 30 °C의 값이 필요하다. 사이 값을 어떻게 어림할까? 점을 많이 주면 그 점들을 모두 지나는 다항식 하나로 더 정확하게 어림할 수 있을 것 같은데, 정말 그럴까?

먼저 알아야 할 것직선의 방정식과 다항식(고교 수학), 반복문과 함수(4.1절), 자료 맞춤(5.3절)을 쓴다.

5.7.1보간과 맞춤

처음 질문처럼 물성표나 보정표는 몇 개의 점에서만 값을 아는데 그 사이 값이 필요할 때가 많다. 보간은 주어진 점을 정확히 지나는 함수로 사이 값을 어림한다. 반면 5.3절의 맞춤(최소제곱)은 점을 꼭 지나지 않고 잡음을 평균 내는 직선이나 곡선을 찾는다. 그러므로 표의 값이 정확하면 보간, 잡음이 섞인 측정값이면 맞춤을 쓴다.

5.7.2선형 보간

가장 간단한 보간은 이웃한 두 점 \((x_0, y_0)\), \((x_1, y_1)\) 사이를 직선으로 잇는 선형 보간이다.

\[y \approx y_0 + (y_1 - y_0)\,\frac{x - x_0}{x_1 - x_0}\]
예제 5.7.1

백금 저항 온도계(Pt100)의 저항이 20 °C에서 107.79 Ω, 40 °C에서 115.54 Ω일 때, 30 °C의 저항을 선형 보간으로 구하여라(표 값은 국제 규격 표에서 옮긴 것이다).

풀이. \(R(30) \approx 107.79 + (115.54 - 107.79)\times\frac{30 - 20}{40 - 20} = 107.79 + 7.75\times0.5 = 111.665\) Ω이다. 규격 표의 30 °C 값은 약 111.67 Ω으로, 차이가 0.01 Ω보다 작다. 이 온도계의 저항은 온도에 대해 거의 직선이라 선형 보간이 잘 맞는다. NumPy에서는 np.interp(30, [20, 40], [107.79, 115.54])가 같은 계산을 한다.

def lin_interp(xs, ys, x):
    for i in range(len(xs) - 1):          # x가 들어 있는 칸을 찾는다
        if xs[i] <= x <= xs[i + 1]:
            t = (x - xs[i]) / (xs[i + 1] - xs[i])
            return ys[i] + t * (ys[i + 1] - ys[i])
    raise ValueError("표의 범위 밖입니다")   # 범위 밖은 보간이 아니라 외삽

5.7.3다항식 보간과 룽게 현상

점 \(n\)개를 모두 지나는 \(n-1\)차 다항식은 하나뿐이다. 라그랑주 형태로 쓰면 다음과 같다.

\[P(x) = \sum_{i} y_i\,L_i(x),\qquad L_i(x) = \prod_{j \ne i}\frac{x - x_j}{x_i - x_j}\]

여기서 \(L_i\)는 \(x_i\)에서 1, 다른 점에서는 0이 되는 다항식이라 \(P(x_i) = y_i\)가 된다.

def lagrange(xs, ys, x):
    total = 0.0
    for i, xi in enumerate(xs):
        L = 1.0
        for j, xj in enumerate(xs):
            if j != i:
                L *= (x - xj) / (xi - xj)
        total += ys[i] * L
    return total
예제 5.7.2

함수 \(f(x) = \dfrac{1}{1 + 25x^2}\)를 \([-1, 1]\)에서 같은 간격의 점 5개와 11개로 다항식 보간하고, 구간 전체에서 가장 큰 오차를 선형 보간(같은 점들을 직선으로 이음)과 비교하여라.

점의 수다항식 보간 최대 오차선형 보간 최대 오차
5 (4차)0.440.18
11 (10차)1.920.067

풀이. 구간을 2000칸으로 나눠 오차를 재었다. 점을 늘리면 선형 보간은 좋아지지만, 다항식 보간은 오히려 나빠진다. 10차 다항식은 \(x = 0.95\)에서 1.92인데 참값은 0.042이다. 그림 1에서 점의 수를 11에서 15로 늘리면 양 끝의 출렁임이 더 커진다. 차수가 높은 다항식이 점 사이에서, 특히 양 끝 가까이에서 크게 출렁이는 것을 룽게 현상이라 한다.

그래서 처음 질문의 둘째 물음에 답하면, 점이 많다고 고차 다항식 하나로 보간하면 안 된다. 실제로는 칸마다 낮은 차수의 다항식을 이어 붙이는데, 선형 보간이나 3차 스플라인(scipy.interpolate.CubicSpline)이 그것이다. 점을 양 끝에 더 촘촘히 두는 방법(체비쇼프 점)도 있다.

마무리

보간은 점을 정확히 지나고, 맞춤은 잡음을 평균 낸다. 처음 질문의 30 °C 값은 선형 보간 \(y_0 + (y_1 - y_0)\frac{x - x_0}{x_1 - x_0}\)으로 구하며, 표의 범위 밖(외삽)은 믿기 어렵다. 같은 간격 점의 고차 다항식 보간은 양 끝에서 출렁이므로(룽게 현상), 낮은 차수를 칸마다 잇는다.

5.7.4연습문제

기본

  1. 세 점 \((0, 1)\), \((1, 3)\), \((2, 7)\)을 지나는 2차 다항식을 구하세요.
    답

    \(P(x) = ax^2 + bx + c\)에서 \(c = 1\), \(a + b + 1 = 3\), \(4a + 2b + 1 = 7\). 풀면 \(a = 1\), \(b = 1\), 곧 \(P(x) = x^2 + x + 1\).

  2. 예제 5.7.1의 표로 70 °C의 저항을 구하려면 어떤 문제가 있나요?
    답

    70 °C는 표의 범위(20~40 °C) 밖이라 보간이 아니라 외삽입니다. 이 온도계는 거의 직선이라 크게 틀리지 않겠지만, 일반적으로 범위 밖의 값은 근거가 약합니다. 범위를 넓힌 표를 찾는 것이 바른 방법입니다.
