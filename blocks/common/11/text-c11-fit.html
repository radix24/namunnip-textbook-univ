실험 자료 맞추기와 그래프

본문

1차 반응의 농도를 1분마다 재서 10.0, 6.1, 3.6, 2.3, 1.3을 얻었다. 이 점들에 직선을 맞추면 곧 음수 농도를 예측하게 된다. 점들이 따르는 모형을 어떻게 고르고, 그 모형의 상수(속도 상수, 반감기)를 자료에서 어떻게 뽑아낼까?

먼저 알아야 할 것회귀 직선(통계학입문 10.2절), NumPy 배열(3.2절), 파일 읽기(4.1절)를 쓴다.

5.3.1최소제곱 직선

자료 \((x_i, y_i)\)에 직선 \(y = a + bx\)를 맞출 때는 잔차의 제곱합 \(\sum(y_i - a - bx_i)^2\)이 가장 작은 \(a, b\)를 고른다. 이것이 최소제곱법이며, 답은 다음과 같다.

\[b = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}, \qquad a = \bar y - b\bar x.\] 
import numpy as np

def linfit(x, y):
    xm, ym = x.mean(), y.mean()
    b = np.sum((x - xm) * (y - ym)) / np.sum((x - xm) ** 2)
    a = ym - b * xm
    r2 = 1 - np.sum((y - a - b * x) ** 2) / np.sum((y - ym) ** 2)
    return a, b, r2

결정계수 \(R^2\)은 1에 가까울수록 직선이 자료를 잘 설명한다는 뜻이다. NumPy에는 np.polyfit(x, y, 1)이 있으며, 기울기와 절편 순서로 돌려준다.

5.3.2지수 함수 맞추기

방사성 붕괴, 1차 반응, RC 회로의 방전처럼 \(y = Ae^{-kt}\)인 자료는 로그를 취하면 \(\ln y = \ln A - kt\)로 직선이 된다. 그러므로 \(\ln y\)를 \(t\)에 직선으로 맞추면 \(A\)와 \(k\)를 얻는다.

예제 5.3.1

시간 \(t\) = 0, 1, 2, 3, 4 (분)에서 농도 \(y\) = 10.0, 6.1, 3.6, 2.3, 1.3을 얻었다. \(A\), \(k\), 반감기를 구하여라.

t = np.array([0, 1, 2, 3, 4], dtype=float)
y = np.array([10.0, 6.1, 3.6, 2.3, 1.3])
a, b, r2 = linfit(t, np.log(y))
A, k = np.exp(a), -b
print(A, k, np.log(2) / k, r2)     # 10.06  0.506  1.37  0.9990

풀이. 직선의 절편과 기울기에서 \(A \approx 10.1\), \(k \approx 0.506\) /분, 반감기 \(\frac{\ln 2}{k} \approx 1.37\)분, \(R^2 \approx 0.999\)를 얻는다. 처음 질문처럼 같은 자료에 그냥 직선을 맞추면 기울기 −2.12인 직선이 나오는데, \(t = 5\)에서 −1.7이라는 음수 농도를 예측해 모형이 맞지 않는다. 그림 1에서 세로축을 로그로 바꾸면 점들이 거의 한 직선에 놓이므로 지수 모형이 알맞다는 것을 눈으로 확인할 수 있다. 즉 자료를 그려 보고 알맞은 모형을 고르는 것이 먼저이다.

로그를 취해 맞추면 작은 \(y\)값의 오차가 크게 부풀려져 결과에 더 큰 영향을 준다. 정밀한 분석에서는 scipy.optimize.curve_fit으로 원래 식을 직접 맞추기도 한다.

5.3.3그래프 그리기

자료와 맞춘 곡선은 matplotlib으로 함께 그린다.

import matplotlib.pyplot as plt
tt = np.linspace(0, 5, 100)
plt.plot(t, y, "o", label="측정값")
plt.plot(tt, A * np.exp(-k * tt), "-", label=f"맞춤: {A:.2f} exp(-{k:.3f} t)")
plt.xlabel("t (min)"); plt.ylabel("y")
plt.legend(); plt.savefig("fit.png", dpi=150)

세로축을 로그 눈금(plt.yscale("log"))으로 바꾸면 그림 1의 둘째 그림처럼 지수 자료가 직선으로 보여 모형을 확인하기 좋다. 한편 한글 축 이름이 깨지면 글꼴 설정이 필요하다. 아래 실습 카드에서 잡음의 크기를 바꾸며 두 맞춤을 비교할 수 있다.

마무리

최소제곱 직선은 \(b = S_{xy}/S_{xx}\), \(a = \bar y - b\bar x\)이고, \(R^2\)으로 맞음의 정도를 본다. 처음 질문의 농도 자료처럼 지수적으로 줄어드는 자료는 \(\ln y\)를 \(t\)에 직선으로 맞춰 \(A\)와 \(k\)를 얻으며, 반감기는 \(\ln 2/k\)이다. 맞추기 전에 먼저 그려 보고, 로그 눈금으로 모형을 확인한다.

5.3.4연습문제

기본

  1. \(y = Ax^n\) 꼴(거듭제곱 법칙)의 자료는 무엇을 무엇에 대해 직선으로 맞추면 되는가?
    답

    \(\ln y = \ln A + n\ln x\)이므로 \(\ln y\)를 \(\ln x\)에 대해 맞춘다. 기울기가 \(n\).
