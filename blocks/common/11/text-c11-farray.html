포트란 배열

본문
이 절에서 배울 것
  • 1차원, 2차원 배열을 선언하고 원소와 구간을 다룬다.
  • 배열 전체 연산과 내장 배열 함수를 쓴다.
  • 열 우선 저장과 할당 배열을 안다.
먼저 알아야 할 것
  • DO 반복문 (1.2절), C 배열 (공통10 5.1절).

1.3.1선언과 인덱스

real(dp) :: T(5), A(3, 3)
integer :: i
T = [20.1_dp, 20.6_dp, 21.3_dp, 22.0_dp, 22.8_dp]
print *, T(1), T(5)       ! 첫째와 마지막: 인덱스는 1부터
print *, T(2:4)           ! 구간: 2, 3, 4번 (끝 포함)
print *, T(5:1:-1)        ! 거꾸로

포트란 배열은 괄호를 쓰고, 인덱스는 기본이 1부터입니다(C, 파이썬은 0부터). real(dp) :: B(0:10)처럼 시작 번호를 정할 수도 있습니다. 구간 T(2:4)는 끝을 포함합니다.

1.3.2배열 전체 연산

포트란의 큰 장점은 반복문 없이 배열 전체를 한꺼번에 계산할 수 있다는 것입니다.

real(dp) :: x(101), y(101)
x = [(0.01_dp * i, i = 0, 100)]   ! 0, 0.01, ..., 1 (암시적 do)
y = sin(x)**2 + x                  ! 원소마다 계산
print *, sum(y) / size(y)          ! 평균
print *, maxval(y), maxloc(y)      ! 최댓값과 그 위치
where (y > 1.0_dp) y = 1.0_dp       ! 조건에 맞는 원소만 바꾸기
  • sum, product, maxval, minval, size.
  • dot_product(u, v): 내적.
  • matmul(A, B): 행렬 곱. transpose(A): 전치.

1.3.3열 우선 저장과 할당 배열

2차원 배열 A(i, j)는 메모리에 열 우선으로, 곧 A(1,1), A(2,1), A(3,1), A(1,2), ... 순서로 놓입니다(C는 행 우선). 메모리를 차례로 읽을 때 빠르므로, 이중 반복문에서는 첫째 인덱스를 안쪽 반복에 둡니다.

do j = 1, n          ! 바깥: 열
  do i = 1, n        ! 안쪽: 행 (메모리 순서대로)
    A(i, j) = 1.0_dp / (i + j - 1)
  end do
end do

크기를 실행 중에 정하려면 할당 배열을 씁니다.

real(dp), allocatable :: data(:)
read *, n
allocate(data(n))
! ... 사용 ...
deallocate(data)

아래 실습 카드에서 행 우선과 열 우선의 메모리 순서를 비교해 볼 수 있습니다.

요약
  1. 인덱스는 1부터, 구간 a(i:j)는 끝 포함.
  2. 배열 전체 연산, sum, matmul, where.
  3. 열 우선 저장: 첫째 인덱스를 안쪽 반복에. 크기를 나중에 정하면 allocatable.
