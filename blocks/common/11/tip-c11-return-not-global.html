함수 안에서 바꾸는 값은 전역 변수로 두지 말고 인자로 받아 반환한다

요령 · 함수와 변수 범위

언제 쓰는가

함수 안에서 바깥 변수를 바꾸다 UnboundLocalError가 나거나, 어떤 함수는 바깥 리스트를 바꾸는데 어떤 함수는 못 바꾸는 이유가 궁금할 때이다.

요령

  1. 대입하면 지역 변수
    함수 안에서 x = …나 x += …처럼 대입하면 그 이름은 함수의 지역 변수가 된다. 대입 전에 읽으면 오류가 난다.
  2. 고치는 것은 대입이 아니다
    items.append(x)는 바깥 리스트 객체를 고칠 뿐 이름을 대입하지 않아서 동작한다.
  3. 인자로 받고 반환
    def add(total, x): return total + x처럼 값을 받아 새 값을 돌려주면 함수만 봐도 무엇이 바뀌는지 알 수 있다.
  4. global은 마지막 수단
    global로 고칠 수는 있지만, 어디서 값이 바뀌는지 찾기 어려워진다.

흔한 실수

  • UnboundLocalError를 보고 무작정 global을 붙이는 것.
  • 함수가 리스트를 바꾸지 않는다고 생각하고 원본을 그대로 넘기는 것.

바로 풀어보기

items = [], total = 0을 바깥에 두고 함수 안에서 items.append(x)와 total += x를 실행했다. 왜 첫째는 되고 둘째는 오류가 나나요? 둘째를 고쳐라.

답과 풀이

답: 첫째는 객체를 고치는 것이라 이름이 지역이 되지 않고, 둘째는 대입이라 total이 지역 변수가 된다. total = add(total, x)처럼 반환으로 고친다.

파이썬은 함수 안에 대입문이 있는 이름을 지역 변수로 정한다. total += x는 '지역 total을 읽고 더해 넣기'인데 지역 total은 아직 값이 없어 UnboundLocalError이다.

def add(total, x):
    return total + x

total = add(total, 5)

이 요령으로 풀리는 문제

  • 파이썬 함수와 모듈 단원 연습 1번, 3번, 6번
영상 콘티 · 40초
  1. 0~5초바깥에 상자 items와 total, 함수 상자 안에 두 줄의 코드가 있다.둘 중 하나만 오류가 난다.
  2. 5~14초items.append(x)가 바깥 리스트 상자에 손을 뻗어 원소를 넣는다. 이름표는 그대로이다.객체를 고치는 것은 된다.
  3. 14~23초total += x가 실행되자 함수 안에 빈 'total' 이름표가 새로 생기고, 비어 있는 것을 읽으려다 오류가 뜬다.대입하면 지역 변수가 생긴다.
  4. 23~33초함수 입구로 total 값이 들어가고, 출구로 새 값이 나와 바깥 상자에 담긴다.인자로 받고 반환한다.
  5. 33~40초global 표지판이 나오지만 여러 함수가 같은 상자를 마구 고치는 장면에 '추적 어려움' 경고가 붙는다.global은 마지막 수단.
