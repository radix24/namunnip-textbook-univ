지수 함수 \(y = Ae^{bx}\)를 맞출 때는 로그를 취해 직선으로 바꾼 뒤 최소제곱을 쓴다

요령 · 지수 함수 맞추기

언제 쓰는가

방사성 붕괴, 냉각, 성장처럼 지수적으로 변하는 측정값에 곡선을 맞추는 문제입니다.

요령

  1. 로그를 취한다
    \(\ln y = \ln A + bx\)이므로 \(Y = \ln y\)는 \(x\)에 대해 직선입니다. \(y\)가 모두 양수인지 확인합니다.
  2. 직선 맞추기
    \((x, \ln y)\)에 최소제곱 직선 \(Y = a + bx\)를 맞춥니다. np.polyfit(x, np.log(y), 1).
  3. 되돌린다
    \(A = e^a\), 기울기 \(b\)는 그대로입니다. 반감기는 \(\frac{\ln2}{|b|}\).
  4. 그래프로 확인
    반로그 그래프에서 점들이 직선 위에 놓이는지 보고, 원래 축에서 곡선과 점을 겹쳐 봅니다.

흔한 실수

  • 되돌릴 때 \(A = a\)로 써서 \(e^a\)를 빠뜨리는 것.
  • 로그 공간에서 맞추면 큰 값과 작은 값의 무게가 달라진다는 점을 모르고 오차를 비교하는 것.

바로 풀어보기

측정값 \((0, 5.0)\), \((1, 3.0)\), \((2, 1.8)\), \((3, 1.1)\)에 \(y = Ae^{bx}\)를 맞추고 반감기를 구하세요.

답과 풀이

답: \(y \approx 4.98e^{-0.505x}\), 반감기 약 1.37

\(\ln y = 1.609, 1.099, 0.588, 0.095\)입니다. \(\bar x = 1.5\), \(\bar Y = 0.848\), \(\sum(x - \bar x)(Y - \bar Y) = -2.527\), \(\sum(x - \bar x)^2 = 5\)이므로 \(b = -0.505\), \(a = 0.848 + 0.505\times1.5 = 1.606\)입니다.

\(A = e^{1.606} \approx 4.98\)이고 반감기는 \(\frac{0.693}{0.505} \approx 1.37\)입니다. 검산: \(x = 2\)에서 \(4.98e^{-1.01} \approx 1.81\).

영상 콘티 · 40초
  1. 0~5초점 네 개가 아래로 휘어지며 줄어듭니다.곡선을 어떻게 맞출까요?
  2. 5~14초세로축이 로그 눈금으로 바뀌자 휘었던 점들이 곧은 줄로 펴집니다.로그를 취하면 직선이 됩니다.
  3. 14~23초펴진 점들에 직선이 맞춰지고 기울기 \(-0.505\), 절편 1.606이 표시됩니다.직선은 최소제곱으로.
  4. 23~32초절편 1.606이 \(e^{\square}\) 상자를 지나 4.98로 바뀝니다.절편은 지수로 되돌립니다.
  5. 32~40초세로축이 원래대로 돌아오며 직선이 지수 곡선으로 휘어 점들을 지납니다.원래 축에서 확인합니다.
