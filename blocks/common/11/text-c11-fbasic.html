1.1.1포트란

포트란(FORTRAN, FORmula TRANslation)은 1950년대에 과학 계산을 위해 만든 가장 오래된 고급 언어 가운데 하나입니다. 지금도 기상 예측, 양자 화학, 유체 역학처럼 큰 수치 계산 프로그램에 많이 쓰이고, 배열 계산이 빠르고 편합니다. 여기서는 Fortran 90 이후의 자유 형식(줄 앞 칸 수 제한이 없음, 파일 이름 .f90)을 씁니다.

program hello
  implicit none
  print *, "Hello, Fortran!"
end program hello

C처럼 컴파일한 뒤 실행합니다(무료 컴파일러 gfortran: gfortran hello.f90 -o hello). 포트란은 대문자와 소문자를 구별하지 않고, 느낌표(!) 뒤는 주석입니다. 문장 끝에 세미콜론이 필요 없고, 한 줄이 길면 끝에 &를 붙여 다음 줄로 잇습니다.

1.1.2변수 선언

implicit none은 꼭 씁니다. 이것이 없으면 선언하지 않은 변수도 이름의 첫 글자가 I~N이면 정수, 나머지는 실수로 저절로 정해져서, 오타가 새 변수가 되어도 알아채지 못합니다.

program falling
  implicit none
  integer, parameter :: dp = kind(1.0d0)   ! 배정도의 종류 번호
  integer :: n
  real(dp) :: g, t, h
  g = 9.8_dp                ! _dp: 배정도 상수
  n = 3
  t = real(n, dp)
  h = 0.5_dp * g * t**2
  print *, "h =", h          ! 44.1 (배정도 자릿수로 출력)
end program falling
선언뜻
integer :: n정수 (보통 32비트)
real :: x기본 실수. 보통 단정도(유효숫자 약 7자리)
real(dp) :: x배정도 (약 16자리). 과학 계산은 이것을 쓴다
complex(dp) :: z복소수
logical :: ok.true., .false.
character(len=20) :: name문자열 (길이 20)
parameter바꿀 수 없는 상수

배정도를 real(8)로 쓰는 코드도 많지만, 종류 번호 8이 배정도라는 것은 컴파일러마다 다를 수 있어 위처럼 kind(1.0d0)이나 iso_fortran_env 모듈의 real64를 쓰는 것이 안전합니다. 상수도 0.1이라고만 쓰면 단정도이므로 0.1_dp나 0.1d0으로 씁니다.

1.1.3연산자와 내장 함수

  • + - * /, 거듭제곱 **.
  • 정수끼리 나누면 몫만 남는다(C와 같음): 7/2는 3, 7.0_dp/2는 3.5.
  • 형 변환: real(n, dp), int(x)(버림), nint(x)(반올림).
  • 내장 함수: sqrt, exp, log(자연로그), log10, sin, cos, atan2, abs, mod, max, min.

입력은 read *, x, 출력은 print *, ...입니다. *는 "형식을 알아서"라는 뜻이고, 자릿수를 정하려면 형식을 씁니다: print '(A, F8.3)', "h =", h(문자열, 전체 8칸에 소수 셋째 자리).

요약
  1. program ... end program, implicit none은 필수.
  2. 과학 계산은 배정도 real(dp)와 _dp 상수.
  3. 정수 나눗셈 주의, **는 거듭제곱, print *와 read *.
