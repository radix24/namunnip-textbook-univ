1.1.1포트란

포트란(FORTRAN, FORmula TRANslation)은 1950년대에 과학 계산을 위해 만든 가장 오래된 고급 언어 가운데 하나이다. 지금도 기상 예측, 양자 화학, 유체 역학처럼 큰 수치 계산 프로그램에 많이 쓰이고, 배열 계산이 빠르고 편하다. 여기서는 Fortran 90 이후의 자유 형식을 쓴다. 자유 형식은 줄 앞 칸 수에 제한이 없고, 파일 이름이 .f90으로 끝난다.

program hello
  implicit none
  print *, "Hello, Fortran!"
end program hello

C처럼 컴파일한 뒤 실행한다. 가령 무료 컴파일러 gfortran이면 gfortran hello.f90 -o hello로 실행 파일을 만든다. 포트란은 대문자와 소문자를 구별하지 않고, 느낌표(!) 뒤는 주석이다. 또 문장 끝에 세미콜론이 필요 없고, 한 줄이 길면 끝에 &를 붙여 다음 줄로 잇는다.

1.1.2변수 선언

처음 질문의 첫째 물음부터 답하자. 포트란 프로그램은 implicit none으로 시작하는 것이 원칙이다. 이것이 없으면 선언하지 않은 변수도 이름의 첫 글자가 I~N이면 정수, 나머지는 실수로 저절로 정해진다. 그래서 오타가 새 변수가 되어도 알아채지 못한다(1.4절).

program falling
  implicit none
  integer, parameter :: dp = kind(1.0d0)   ! 배정도의 종류 번호
  integer :: n
  real(dp) :: g, t, h
  g = 9.8_dp                ! _dp: 배정도 상수
  n = 3
  t = real(n, dp)
  h = 0.5_dp * g * t**2
  print *, "h =", h          ! 44.1 (배정도 자릿수로 출력)
end program falling
선언뜻
integer :: n정수 (보통 32비트)
real :: x기본 실수. 보통 단정도(유효숫자 약 7자리)
real(dp) :: x배정도 (약 16자리). 과학 계산은 이것을 쓴다
complex(dp) :: z복소수
logical :: ok.true., .false.
character(len=20) :: name문자열 (길이 20)
parameter바꿀 수 없는 상수

배정도를 real(8)로 쓰는 코드도 많다. 하지만 종류 번호 8이 배정도라는 것은 컴파일러마다 다를 수 있으므로, 위처럼 kind(1.0d0)이나 iso_fortran_env 모듈의 real64를 쓰는 것이 안전하다. 상수도 0.1이라고만 쓰면 단정도이므로 0.1_dp나 0.1d0으로 쓴다.

그렇다면 단정도와 배정도는 얼마나 다를까? 그림 1은 0.1을 거듭 더한 합의 상대 오차이다. \(N = 1000\)번 더하면 단정도 합은 99.99905로 이미 넷째 자리에서 틀리지만, 배정도 합은 열세 자리 넘게 맞는다. 즉 처음 질문의 둘째 물음에 답하면, 반복이 많은 과학 계산에서는 단정도의 오차가 결과의 유효숫자를 갉아먹으므로 배정도 real(dp)를 쓴다.

1.1.3연산자와 내장 함수

산술 연산자는 + - * /이고, 거듭제곱은 **이다. 그런데 C와 같이 정수끼리 나누면 몫만 남는다. 가령 7/2는 3이고 7.0_dp/2는 3.5이다. 그래서 형 변환 real(n, dp), int(x)(버림), nint(x)(반올림)를 함께 익혀 둔다. 또 sqrt, exp, log(자연로그), log10, sin, cos, atan2, abs, mod, max, min 같은 내장 함수를 선언 없이 쓴다.

입력은 read *, x, 출력은 print *, ...이다. 여기서 *는 "형식을 알아서"라는 뜻이다. 자릿수를 정하려면 형식을 쓰며, 가령 print '(A, F8.3)', "h =", h는 문자열 다음에 전체 8칸, 소수 셋째 자리로 찍는다(2.2절).

마무리

포트란 프로그램은 program … end program으로 감싸고 implicit none을 반드시 쓴다. 처음 질문처럼 \(\frac12 gt^2\)을 계산하려면 real(dp)로 배정도 변수를 선언하고 상수에 _dp를 붙이며, 그림 1에서 보듯 단정도는 반복 계산에서 오차가 빠르게 쌓인다. 정수 나눗셈은 몫이고 거듭제곱은 **, 입출력은 print *와 read *이다.
