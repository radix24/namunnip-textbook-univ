포트란 부프로그램과 파일 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 코드는 그 문제가 확인하는 성취기준이다.

  1. 실습반지름을 받아 원의 넓이를 돌려주는 포트란 함수 area를 쓰고 주 프로그램에서 불러라. [02-01]

    힌트 1

    contains 뒤에 내부 함수를 두면 인터페이스가 자동으로 맞춰진다.

    힌트 2

    real(dp) function area(r), 인자에 intent(in).

    풀이 
    program circle
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  print *, area(2.0_dp)          ! 12.566...
contains
  real(dp) function area(r)
    real(dp), intent(in) :: r
    real(dp), parameter :: pi = 3.141592653589793_dp
    area = pi * r**2
  end function area
end program circle

  2. 실습두 실수를 맞바꾸는 서브루틴 swap을 써라. C와 달리 포인터 없이 되는 이유는? [02-01]

    힌트 1

    서브루틴은 call로 부르고 값을 돌려주지 않는다. 인자를 바꿀 수 있다.

    힌트 2

    두 인자 모두 intent(inout).

    풀이 
    subroutine swap(a, b)
  real(dp), intent(inout) :: a, b
  real(dp) :: t
  t = a
  a = b
  b = t
end subroutine swap
! 쓰는 법: call swap(x, y)

    포트란은 인자를 참조로 넘기므로(변수의 주소가 넘어감) 서브루틴 안에서 바꾸면 부른 쪽 변수도 바뀐다. C는 값을 복사해 넘기므로 주소(포인터)를 넘겨야 합니다(공통10 5.2절).

  3. 개념intent(in), intent(out), intent(inout)의 뜻을 말하고, intent(in)인 인자에 값을 넣으면 어떻게 되는지 말하여라. [02-01]

    힌트 1

    intent는 인자를 읽기만 하는지, 결과를 담는지, 둘 다인지를 컴파일러에게 알린다.

    힌트 2

    컴파일러가 약속을 어긴 코드를 찾아 준다.

    풀이

    in: 읽기만 함. out: 서브루틴이 값을 채워 돌려줌(들어올 때 값은 쓰지 않음). inout: 읽고 바꿈. intent(in) 인자에 대입하면 컴파일 오류가 난다. 실수로 입력을 바꾸는 버그를 막고, 코드를 읽는 사람에게도 역할을 알려 준다.

  4. 실습1부터 10까지 \(i\)와 \(\sqrt i\)를 out.dat 파일에 (I3, F10.4) 형식으로 쓰는 프로그램을 써라. [02-02]

    힌트 1

    open(unit=10, file="out.dat", status="replace"), write(10, '(I3, F10.4)') ..., close(10).

    힌트 2

    I3은 정수 3칸, F10.4는 실수 10칸에 소수 넷째 자리까지.

    풀이 
    program table
  implicit none
  integer :: i
  open(unit=10, file="out.dat", status="replace", action="write")
  do i = 1, 10
    write(10, '(I3, F10.4)') i, sqrt(real(i))
  end do
  close(10)
end program table

    첫 줄은 1 1.0000, 마지막 줄은 10 3.1623이다.

  5. 실습앞 문제의 out.dat를 끝까지 읽어 둘째 열의 합을 구하여라. 줄 수를 미리 모를 때는 어떻게 하나요? [02-02]

    힌트 1

    read(10, *, iostat=ios) i, x에서 ios가 0이 아니면 파일 끝이나 오류이다.

    힌트 2

    do … if (ios /= 0) exit … end do.

    풀이 
    open(unit=10, file="out.dat", status="old", action="read")
s = 0.0
do
  read(10, *, iostat=ios) i, x
  if (ios /= 0) exit
  s = s + x
end do
close(10)
print *, s      ! 22.4683 (sqrt(1) + ... + sqrt(10))

    iostat 없이 읽으면 파일 끝에서 프로그램이 오류로 멈춘다.

  6. 판단앞의 swap(a, b)(intent(inout))를 call swap(1.0_dp, 2.0_dp)처럼 상수로 불렀다. 괜찮을까? [02-01]

    힌트 1

    inout 인자는 값이 바뀐다. 상수 1.0은 바뀔 수 있나요?

    힌트 2

    인터페이스가 있으면 컴파일러가 검사해 준다.

    풀이

    안 된다. 바꿀 수 없는 상수를 intent(inout)에 넘긴 것이라, 내부 서브루틴이나 모듈 서브루틴처럼 인터페이스가 알려진 경우 컴파일 오류가 난다. 옛날 방식(외부 서브루틴)에서는 오류 없이 상수 자리를 덮어써 이상한 결과가 나기도 했다. 바꿀 인자에는 변수를 넘겨야 한다.
