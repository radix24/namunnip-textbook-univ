수치 적분의 오차는 간격을 반으로 줄여 답이 얼마나 바뀌는지로 어림한다

요령 · 수치 미분방정식의 오차

언제 쓰는가

참값을 모르는 미분방정식을 오일러나 룽게-쿠타로 풀고, 결과를 얼마나 믿을 수 있는지 판단할 때입니다.

요령

  1. 두 번 푼다
    간격 \(h\)와 \(\frac h2\)로 같은 시각까지 풀어 두 값을 얻습니다.
  2. 차이가 오차의 크기
    \(p\)차 방법이면 \(\frac h2\) 결과의 오차는 대략 \(\frac{\text{두 값의 차}}{2^p - 1}\)입니다. 오일러(\(p = 1\))면 차이 정도가 오차입니다.
  3. 보정(리처드슨)
    \(y^* = y_{h/2} + \frac{y_{h/2} - y_h}{2^p - 1}\)로 더 정확한 값을 얻습니다.
  4. 차수 확인
    세 간격으로 풀어 차이의 비가 \(2^p\) 근처인지 보면 코드가 제대로 짜였는지도 확인됩니다.

흔한 실수

  • 한 간격으로만 풀고 결과를 그대로 믿는 것.
  • 간격을 줄였는데 결과가 그대로라서 맞다고 보는 것. 출력 자릿수가 모자랐을 수 있습니다.

바로 풀어보기

\(y' = y\), \(y(0) = 1\)을 오일러 방법으로 \(h = 0.1\)과 \(h = 0.05\)로 풀면 \(y(1)\)이 각각 2.5937, 2.6533입니다. 오차를 어림하고 리처드슨 보정값을 구하세요. (참값 \(e = 2.7183\))

답과 풀이

답: \(h = 0.05\)의 오차 약 0.06, 보정값 약 2.7129

두 값의 차는 0.0596이고 오일러는 1차이므로 \(h = 0.05\) 결과의 오차는 약 0.06입니다. 실제 오차 0.065와 맞습니다.

보정: \(2.6533 + 0.0596 = 2.7129\). 참값과의 차가 0.005로 열 배 넘게 줄었습니다.

이 요령으로 풀리는 문제

  • 과학 계산 프로그래밍 단원 연습 2번, 7번
영상 콘티 · 40초
  1. 0~5초오일러 방법의 계단 그래프가 참해 곡선 아래를 따라갑니다.참값을 모를 때 오차는?
  2. 5~13초간격을 반으로 줄인 계단이 겹쳐 그려지고, \(t = 1\)에서 두 끝점 2.5937과 2.6533이 표시됩니다.간격을 반으로 해서 한 번 더 풉니다.
  3. 13~22초두 끝점 사이 거리 0.0596이 자로 재어지고, 그 길이만큼의 막대가 참값까지의 거리와 거의 같다는 것이 보입니다.1차 방법이면 차이가 곧 오차 크기.
  4. 22~32초차이만큼 위로 화살표가 뻗어 2.7129에 닿고, 참값 2.7183 바로 아래에 멈춥니다.차이로 보정하면 훨씬 가까워집니다.
  5. 32~40초간격을 세 번 바꾼 결과의 차이 비가 2에 가깝게 찍힙니다.비로 방법의 차수도 확인합니다.
