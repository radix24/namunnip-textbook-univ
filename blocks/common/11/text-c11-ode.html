5.2.1오일러 방법

\(y' = f(t, y)\), \(y(t_0) = y_0\)에서 짧은 시간 \(h\) 동안 기울기가 일정하다고 보고 나아갑니다.

\[y_{n+1} = y_n + h\,f(t_n, y_n).\] 
def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y)
        t = t + h
    return y

5.2.24차 룽게-쿠타

한 걸음 안에서 기울기를 네 번 재서 가중 평균합니다.

\[\begin{aligned} k_1 &= f(t_n, y_n), & k_2 &= f\!\left(t_n + \tfrac h2, y_n + \tfrac h2 k_1\right),\\ k_3 &= f\!\left(t_n + \tfrac h2, y_n + \tfrac h2 k_2\right), & k_4 &= f(t_n + h, y_n + hk_3), \end{aligned}\] \[y_{n+1} = y_n + \frac h6(k_1 + 2k_2 + 2k_3 + k_4).\] 
function rk4_step(f, t, y, h) result(ynew)
  interface
    function f(t, y)
      import dp
      real(dp), intent(in) :: t, y
      real(dp) :: f
    end function f
  end interface
  real(dp), intent(in) :: t, y, h
  real(dp) :: ynew, k1, k2, k3, k4
  k1 = f(t, y)
  k2 = f(t + h/2, y + h/2*k1)
  k3 = f(t + h/2, y + h/2*k2)
  k4 = f(t + h, y + h*k3)
  ynew = y + h/6*(k1 + 2*k2 + 2*k3 + k4)
end function rk4_step

포트란에서 함수를 인수로 받으려면 interface로 그 함수의 모양을 알려 줍니다(dp를 정의한 모듈 안에 둔다고 가정).

5.2.3오차의 차수

\(y' = -y\), \(y(0) = 1\)을 \(t = 1\)까지 풀어 참값 \(e^{-1} = 0.3678794\)와 비교합니다.

\(h\)를 절반으로 줄이면 오일러 오차는 약 \(\frac12\)(1차 방법, 오차 \(\propto h\)), RK4 오차는 약 \(\frac1{16}\)(4차 방법, 오차 \(\propto h^4\))이 됩니다. RK4는 한 걸음에 \(f\)를 네 번 계산하지만, 같은 정확도라면 훨씬 큰 \(h\)를 쓸 수 있어 전체 계산이 적습니다.

5.2.4연립 방정식과 2계 방정식

2계 방정식 \(x'' = -\omega^2 x\)는 \(y = (x, v)\)로 두면 \(y' = (v, -\omega^2 x)\)라는 1계 연립 방정식이 됩니다. 위 코드에서 y를 배열(NumPy 배열, 포트란 배열)로 바꾸기만 하면 그대로 씁니다. 진동자에 오일러 방법을 쓰면 에너지가 매 걸음 \((1 + \omega^2h^2)\)배씩 늘어 진폭이 커지는데, 이것은 물리가 아니라 방법의 오차입니다. 아래 실습 카드에서 확인해 보세요.

요약
  1. 오일러: \(y + hf\), 1차. RK4: 기울기 네 번의 가중 평균, 4차.
  2. 2계 방정식은 \((x, v)\)의 1계 연립으로 바꿔 푼다.

5.2.5연습문제

기본

  1. RK4로 \(h = 0.1\)일 때 오차가 \(3.3\times10^{-7}\)이었다. \(h = 0.025\)이면 대략 얼마인가?
    답

    \(h\)가 1/4이므로 \(4^4 = 256\)분의 1, 약 \(1.3\times10^{-9}\).
