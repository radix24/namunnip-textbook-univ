오일러 방법과 룽게-쿠타 방법

본문

미분방정식 \(y' = -y\)는 손으로 풀어 \(y = e^{-t}\)를 얻지만, 행성 궤도나 화학 반응망처럼 손으로 풀 수 없는 방정식이 더 많다. 컴퓨터로 \(y\)를 조금씩 나아가며 구할 때, 한 걸음을 어떻게 내디뎌야 정확할까? 간격 \(h\)를 절반으로 줄이면 오차는 얼마나 줄까?

먼저 알아야 할 것1계 미분방정식과 수치해(고등미적분학(1) 1.1절, 7.1절)와 함수를 인수로 넘기기(4.1절)를 쓴다.

5.2.1오일러 방법

\(y' = f(t, y)\), \(y(t_0) = y_0\)에서 짧은 시간 \(h\) 동안 기울기가 일정하다고 보고 나아간다. 이것이 오일러 방법이다.

\[y_{n+1} = y_n + h\,f(t_n, y_n).\] 
def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y)
        t = t + h
    return y

그런데 \(y' = -y\)처럼 휘는 곡선에서는 한 걸음 동안 기울기가 실제로 바뀌므로, 처음 기울기만 쓰면 매 걸음 조금씩 빗나간다. 그림 1에서 오일러 점이 곡선 아래로 처지는 까닭이다.

5.2.24차 룽게-쿠타

처음 질문의 "더 정확한 한 걸음"은 한 걸음 안에서 기울기를 네 번 재서 가중 평균하는 것이다. 이것이 4차 룽게-쿠타 방법(RK4)이다.

\[\begin{aligned} k_1 &= f(t_n, y_n), & k_2 &= f\!\left(t_n + \tfrac h2, y_n + \tfrac h2 k_1\right),\\ k_3 &= f\!\left(t_n + \tfrac h2, y_n + \tfrac h2 k_2\right), & k_4 &= f(t_n + h, y_n + hk_3), \end{aligned}\] \[y_{n+1} = y_n + \frac h6(k_1 + 2k_2 + 2k_3 + k_4).\]

\(k_1\)은 출발점의 기울기, \(k_2\)와 \(k_3\)은 가운데 점의 기울기, \(k_4\)는 끝점의 기울기이다. 포트란으로 쓰면 다음과 같다.

function rk4_step(f, t, y, h) result(ynew)
  interface
    function f(t, y)
      import dp
      real(dp), intent(in) :: t, y
      real(dp) :: f
    end function f
  end interface
  real(dp), intent(in) :: t, y, h
  real(dp) :: ynew, k1, k2, k3, k4
  k1 = f(t, y)
  k2 = f(t + h/2, y + h/2*k1)
  k3 = f(t + h/2, y + h/2*k2)
  k4 = f(t + h, y + h*k3)
  ynew = y + h/6*(k1 + 2*k2 + 2*k3 + k4)
end function rk4_step

포트란에서 함수를 인수로 받으려면 interface로 그 함수의 모양을 알려 준다(dp를 정의한 모듈 안에 둔다고 가정한다).

5.2.3오차의 차수

처음 질문의 둘째 물음을 숫자로 확인하자. \(y' = -y\), \(y(0) = 1\)을 \(t = 1\)까지 풀어 참값 \(e^{-1} = 0.3678794\)와 비교한다.

\(h\)를 절반으로 줄이면 오일러 오차는 약 \(\frac12\)이 되고, RK4 오차는 약 \(\frac1{16}\)이 된다. 즉 오일러는 오차가 \(h\)에 비례하는 1차 방법이고, RK4는 \(h^4\)에 비례하는 4차 방법이다. 그림 1에서 \(h\)를 바꾸며 읽기 줄의 두 오차를 비교해 보면 같은 비율이 나온다. RK4는 한 걸음에 \(f\)를 네 번 계산하지만, 같은 정확도라면 훨씬 큰 \(h\)를 쓸 수 있어 전체 계산이 적다.

5.2.4연립 방정식과 2계 방정식

2계 방정식 \(x'' = -\omega^2 x\)는 \(y = (x, v)\)로 두면 \(y' = (v, -\omega^2 x)\)라는 1계 연립 방정식이 된다. 그러므로 위 코드에서 y를 배열(NumPy 배열, 포트란 배열)로 바꾸기만 하면 그대로 쓴다. 진동자에 오일러 방법을 쓰면 에너지가 매 걸음 \((1 + \omega^2h^2)\)배씩 늘어 진폭이 커지는데(4.2절 그림 1), 이것은 물리가 아니라 방법의 오차이다. 아래 실습 카드에서 확인해 볼 수 있다.

마무리

오일러 방법은 \(y_{n+1} = y_n + hf\)로 출발점의 기울기만 쓰는 1차 방법이고, RK4는 한 걸음 안의 기울기 네 개를 가중 평균하는 4차 방법이다. 처음 질문처럼 \(h\)를 절반으로 하면 오일러 오차는 절반, RK4 오차는 16분의 1이 된다. 2계 방정식은 \((x, v)\)의 1계 연립으로 바꿔 같은 코드로 푼다.
