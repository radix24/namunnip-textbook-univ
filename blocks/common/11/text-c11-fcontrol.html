포트란의 IF 문과 DO 반복문

본문
이 절에서 배울 것
  • 비교 연산자와 논리 연산자, if 구문을 쓴다.
  • do, do while, exit, cycle로 반복한다.
먼저 알아야 할 것
  • 포트란 변수 (1.1절), C의 제어문 (공통10 4.2절).

1.2.1IF 구문

if (pH < 7.0_dp) then
  print *, "산성"
else if (pH == 7.0_dp) then
  print *, "중성"
else
  print *, "염기성"
end if
뜻새 표기옛 표기
같다, 다르다==, /=.eq., .ne.
작다, 작거나 같다<, <=.lt., .le.
크다, 크거나 같다>, >=.gt., .ge.
그리고, 또는, 아님.and., .or., .not.

"다르다"가 /=인 점이 C, 파이썬(!=)과 다릅니다. 옛 프로그램에는 점으로 감싼 표기가 많이 남아 있어 둘 다 읽을 수 있어야 합니다. 한 줄짜리는 if (x < 0) x = -x처럼 then 없이 씁니다.

1.2.2DO 반복문

integer :: i
real(dp) :: s
s = 0.0_dp
do i = 1, 100          ! i = 1, 2, ..., 100 (끝을 포함한다)
  s = s + 1.0_dp / i**2
end do
print *, s             ! 1.6349839... (π²/6 = 1.6449...에 다가감)

do i = 10, 1, -2       ! 10, 8, 6, 4, 2
  print *, i
end do

파이썬 range와 달리 끝값을 포함합니다. 반복 변수 i는 정수로 선언하고, 몸체 안에서 바꾸면 안 됩니다.

  • do while (조건) ... end do: 조건이 참인 동안.
  • exit: 반복을 끝낸다(C의 break).
  • cycle: 다음 차례로 건너뛴다(C의 continue).
  • 조건 없이 do ... end do로 쓰고 안에서 exit으로 나오는 꼴도 흔하다.
예제 1.2.1

\(\cos x = x\)의 근을 고정점 반복 \(x_{k+1} = \cos x_k\)로 \(10^{-10}\)까지 구하여라.

real(dp) :: x, xnew
integer :: k
x = 1.0_dp
do k = 1, 1000
  xnew = cos(x)
  if (abs(xnew - x) < 1.0e-10_dp) exit
  x = xnew
end do
print *, k, xnew        ! 58번, 0.7390851332...

반복 횟수에 상한(1000)을 두면 수렴하지 않을 때 무한 반복을 막을 수 있습니다.

요약
  1. if (...) then / else if / else / end if. 다르다는 /=.
  2. do i = 시작, 끝, 간격은 끝을 포함. do while, exit, cycle.

1.2.3연습문제

기본

  1. 1부터 \(n\)까지의 곱(계승)을 do로 구하는 코드를 써라. \(n = 20\)이면 어떤 자료형이 필요한가?
    답

    f = 1; do i = 1, n; f = f * i; end do. 20!은 약 \(2.4\times10^{18}\)이라 64비트 정수 integer(kind=8)(또는 int64)가 필요하다.
