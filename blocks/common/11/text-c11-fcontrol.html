포트란의 IF 문과 DO 반복문

본문

\(\cos x = x\)는 손으로 풀 수 없는 방정식이다. 그런데 계산기에 아무 수나 넣고 cos 단추를 계속 누르면 값이 0.739…에 멈춘다. 이 "같은 일을 되풀이하다가 충분히 가까워지면 멈추기"를 포트란으로 쓰려면 조건과 반복을 어떻게 적어야 할까?

먼저 알아야 할 것포트란 변수(1.1절)와 C의 제어문(전자계산(1) 4.2절)을 쓴다.

1.2.1IF 구문

포트란의 조건문은 if (조건) then으로 시작해 end if로 끝난다. 갈래가 여럿이면 else if와 else를 끼워 넣는다.

if (pH < 7.0_dp) then
  print *, "산성"
else if (pH == 7.0_dp) then
  print *, "중성"
else
  print *, "염기성"
end if

비교와 논리 연산자는 새 표기와 옛 표기가 있다.

뜻새 표기옛 표기
같다, 다르다==, /=.eq., .ne.
작다, 작거나 같다<, <=.lt., .le.
크다, 크거나 같다>, >=.gt., .ge.
그리고, 또는, 아님.and., .or., .not.

"다르다"가 /=인 점이 C, 파이썬(!=)과 다르다. 옛 프로그램에는 점으로 감싼 표기가 많이 남아 있어 둘 다 읽을 수 있어야 한다. 한편 한 줄짜리는 if (x < 0) x = -x처럼 then 없이 쓴다.

1.2.2DO 반복문

정해진 횟수만큼 되풀이할 때는 do i = 시작, 끝, 간격을 쓴다.

integer :: i
real(dp) :: s
s = 0.0_dp
do i = 1, 100          ! i = 1, 2, ..., 100 (끝을 포함한다)
  s = s + 1.0_dp / i**2
end do
print *, s             ! 1.6349839... (π²/6 = 1.6449...에 다가감)

do i = 10, 1, -2       ! 10, 8, 6, 4, 2
  print *, i
end do

파이썬 range와 달리 끝값을 포함한다는 점에 주의한다. 반복 변수 i는 정수로 선언하고, 몸체 안에서 바꾸면 안 된다.

조건이 참인 동안 되풀이하려면 do while (조건) … end do를 쓴다. 또 exit은 반복을 끝내고(C의 break), cycle은 다음 차례로 건너뛴다(C의 continue). 그래서 조건 없이 do … end do로 쓰고 안에서 exit으로 나오는 꼴도 흔하다.

예제 1.2.1

\(\cos x = x\)의 근을 고정점 반복 \(x_{k+1} = \cos x_k\)로 \(10^{-10}\)까지 구하여라.

풀이. 처음 질문의 "cos 단추 되풀이"를 그대로 옮기면 된다. 고친 양 \(|x_{k+1} - x_k|\)이 \(10^{-10}\)보다 작아지면 exit으로 나온다.

real(dp) :: x, xnew
integer :: k
x = 1.0_dp
do k = 1, 1000
  xnew = cos(x)
  if (abs(xnew - x) < 1.0e-10_dp) exit
  x = xnew
end do
print *, k, xnew        ! 58번, 0.7390851332...

58번 반복해 0.7390851332…를 얻는다. 그림 1에서 \(k\)를 늘리면 거미줄이 교점 둘레를 돌며 좁혀지는데, 곡선의 기울기 \(-\sin x\)의 크기가 교점에서 약 0.67로 1보다 작아 한 번에 오차가 약 0.67배씩 줄기 때문이다. 이렇게 천천히 줄어드는 반복이라 58번이 필요하다. 또 반복 횟수에 상한(1000)을 두면 수렴하지 않을 때 무한 반복을 막을 수 있다.

마무리

포트란의 조건문은 if (...) then, else if, else, end if이고 "다르다"는 /=이다. 반복은 끝을 포함하는 do i = 시작, 끝, 간격과 do while을 쓰며, exit과 cycle로 흐름을 바꾼다. 처음 질문의 되풀이는 상한을 둔 do 안에서 고친 양이 충분히 작으면 exit하는 꼴로 쓴다.

1.2.3연습문제

기본

  1. 1부터 \(n\)까지의 곱(계승)을 do로 구하는 코드를 써라. \(n = 20\)이면 어떤 자료형이 필요한가?
    답

    f = 1; do i = 1, n; f = f * i; end do. 20!은 약 \(2.4\times10^{18}\)이라 64비트 정수 integer(kind=8)(또는 int64)가 필요하다.
