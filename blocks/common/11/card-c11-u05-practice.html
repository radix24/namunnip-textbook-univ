과학 계산 프로그래밍 단원 마무리 연습

문제 10 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 코드는 그 문제가 확인하는 성취기준이다.

  1. 계산가우스 소거로 연립방정식 \(2x + y - z = 8\), \(-3x - y + 2z = -11\), \(-2x + y + 2z = -3\)을 손으로 풀어라. [05-01]

    힌트 1

    첫 식으로 둘째, 셋째 식의 \(x\)를 없앱니다(둘째 + 1.5 × 첫째, 셋째 + 1 × 첫째).

    힌트 2

    그러면 \(0.5y + 0.5z = 1\), \(2y + z = 5\).

    풀이

    둘째 줄 ×4를 셋째에서 빼면 \(-z = 1\), \(z = -1\). 거꾸로 대입: \(0.5y - 0.5 = 1\), \(y = 3\). \(2x + 3 + 1 = 8\), \(x = 2\). 해 \((2, 3, -1)\). 프로그램은 이 과정을 그대로 반복문으로 씁니다(전진 소거 \(O(n^3)\), 후진 대입 \(O(n^2)\)).

  2. 계산\(y' = y\), \(y(0) = 1\)을 \(h = 0.1\)로 한 걸음 진행할 때 오일러 방법과 4차 룽게-쿠타 방법의 값을 구하고 참값 \(e^{0.1}\)과 비교하여라. [05-02]

    힌트 1

    오일러: \(y_1 = y_0 + hf(y_0)\). RK4: \(k_1 = f(y_0)\), \(k_2 = f(y_0 + \tfrac h2k_1)\), \(k_3 = f(y_0 + \tfrac h2k_2)\), \(k_4 = f(y_0 + hk_3)\).

    힌트 2

    \(k_1 = 1\), \(k_2 = 1.05\), \(k_3 = 1.0525\), \(k_4 = 1.10525\).

    풀이

    오일러: 1.1 (오차 \(5.2\times10^{-3}\)). RK4: \(1 + \tfrac{0.1}6(1 + 2.1 + 2.105 + 1.10525) = 1.10517083\). 참값 1.10517092와 \(8.5\times10^{-8}\) 차이. 한 걸음에 함수를 네 번 계산하는 대신 오차가 비교할 수 없이 작다.

  3. 계산측정값 (0, 1.0), (1, 3.0), (2, 5.2), (3, 6.8)에 최소제곱 직선 \(y = a + bx\)를 맞춰라. [05-03]

    힌트 1

    \(b = \dfrac{\sum(x - \bar x)(y - \bar y)}{\sum(x - \bar x)^2}\), \(a = \bar y - b\bar x\).

    힌트 2

    \(\bar x = 1.5\), \(\bar y = 4.0\), \(S_{xy} = 9.8\), \(S_{xx} = 5\).

    풀이

    \(b = 1.96\), \(a = 4.0 - 2.94 = 1.06\). 파이썬에서는 np.polyfit(x, y, 1)이 [1.96, 1.06]을 준다.

  4. 실습방사성 시료의 측정값 (0, 2.0), (1, 5.4), (2, 14.8), (3, 40.2)가 \(y = Ae^{bx}\)를 따른다고 본다. 로그를 취해 직선으로 바꾼 뒤 \(A\)와 \(b\)를 구하여라. [05-03]

    힌트 1

    \(\ln y = \ln A + bx\)이므로 \((x, \ln y)\)에 직선을 맞춘다.

    힌트 2

    \(\ln y = 0.693, 1.686, 2.695, 3.694\).

    풀이

    기울기 \(b = 1.001\), 절편 0.6905, \(A = e^{0.6905} = 1.995\). 곧 \(y \approx 2.0e^{1.0x}\). 이 방법은 작은 \(y\)의 오차를 크게 키우므로, 정밀하게 하려면 비선형 최소제곱(scipy.optimize.curve_fit)을 쓴다.

  5. 개념같은 이중 반복문(100만 번 곱셈과 덧셈)을 포트란, 파이썬 반복문, NumPy로 실행하면 대개 어떤 순서로 빠른가요? 이유는? [05-04]

    힌트 1

    포트란은 컴파일되어 기계어로, 파이썬은 한 줄씩 해석되며 실행된다.

    힌트 2

    NumPy는 배열 연산을 컴파일된 코드로 처리한다.

    풀이

    대체로 포트란 ≈ NumPy > 파이썬 반복문이고, 파이썬 반복문은 수십~수백 배 느리다. 파이썬은 원소마다 자료형 확인과 객체 생성을 하기 때문이다. 실제 배수는 컴퓨터와 코드에 따라 다르므로 직접 재 봐야 합니다(5.4절 본문의 시간 재기 코드).

  6. 판단\(0.0001x + y = 1\), \(x + y = 2\)를 유효숫자 3자리로만 계산하는 컴퓨터에서 첫 식을 기준으로(피벗 없이) 가우스 소거를 했더니 \(x = 0\)이 나왔다. 참값은 \(x \approx 1.0001\)이다. 무엇이 잘못되었고 어떻게 고치나요? [05-01]

    힌트 1

    첫 식에 10000을 곱해 둘째에서 빼면 \(y\)의 계수와 우변이 어떻게 되나요?

    힌트 2

    두 식의 순서를 바꾸고(부분 피벗팅) 다시 해 보아라.

    풀이

    피벗 0.0001이 너무 작아 곱하는 수가 10000이 되었다. \((1 - 10000)y = 2 - 10000\)이 3자리 계산에서 \(-10000y = -10000\), \(y = 1.00\)이 되고, \(0.0001x = 1 - 1.00 = 0\)에서 \(x = 0\)이 된다. 절댓값이 가장 큰 계수를 피벗으로 삼도록 줄을 바꾸면 \(y = 1.00\), \(x = 2 - 1.00 = 1.00\)으로 바른 답이 나온다. 그래서 실제 프로그램은 언제나 부분 피벗팅을 씁니다(공통9 7.1절).

  7. 계산\(\cos x = x\)를 뉴턴 방법으로 푼다. \(x_0 = 1\)에서 \(x_1\)을 구하고, 몇 번 만에 \(10^{-10}\)까지 맞는지 말하여라. [05-05]

    힌트 1

    \(f(x) = \cos x - x\), \(f'(x) = -\sin x - 1\).

    힌트 2

    \(x_1 = 1 - \frac{\cos 1 - 1}{-\sin 1 - 1}\).

    풀이

    \(x_1 \approx 0.750364\), \(x_2 \approx 0.739113\), \(x_3 \approx 0.7390851334\), \(x_4 = 0.7390851332\). 오차는 약 \(1.1\times10^{-2}, 2.8\times10^{-5}, 1.7\times10^{-10}\)으로 줄어, 4번이면 \(10^{-10}\)보다 작아진다.

  8. 계산사분원에 점을 던져 \(\pi\)를 어림하는 몬테카를로 실험을 \(N = 400\)번 했다. 표준오차는 대략 얼마인가요? 표준오차를 그 절반으로 줄이려면 \(N\)을 얼마로 해야 하나요? [05-06]

    힌트 1

    어림값의 표준오차는 \(4\sqrt{p(1-p)/N}\), \(p = \pi/4\).

    힌트 2

    \(4\sqrt{p(1-p)} \approx 1.64\).

    풀이

    \(1.64/\sqrt{400} = 0.082\). 절반으로 줄이려면 \(\sqrt N\)이 두 배, 곧 \(N = 1600\)이어야 한다.

  9. 계산표 \((1, 2)\), \((2, 3)\), \((4, 9)\)에서 \(x = 3\)의 값을 선형 보간으로 구하여라. 세 점을 모두 지나는 2차 다항식으로 구하면 얼마인가요? [05-07]

    힌트 1

    \(x = 3\)은 2와 4 사이에 있다.

    힌트 2

    2차 다항식은 \(ax^2 + bx + c\)에 세 점을 넣어 연립방정식을 푼다.

    풀이

    선형 보간: \(3 + (9 - 3)\times\frac{3 - 2}{4 - 2} = 6\). 2차 다항식: \(a + b + c = 2\), \(4a + 2b + c = 3\), \(16a + 4b + c = 9\)에서 \(a = \frac23\), \(b = -1\), \(c = \frac73\), \(P(3) = 6 - 3 + \frac73 = \frac{16}{3} \approx 5.33\). 두 방법의 답이 다르므로, 자료만으로는 사이 값을 확정할 수 없다는 것도 알 수 있다.

  10. 개념f2py로 만든 모듈에서 포트란 서브루틴 subroutine scale(a, n, c)(a는 intent(inout)인 배정도 배열, c는 intent(in))를 부를 때, 원래 NumPy 배열이 바뀌게 하려면 어떤 배열을 넘겨야 하나요? [05-08]

    힌트 1

    f2py는 자료형이나 메모리 순서가 맞지 않으면 복사본을 만들어 넘긴다.

    힌트 2

    포트란의 double precision에 맞는 NumPy 자료형은 float64이다.

    풀이

    float64(배정도 실수) 배열을 넘긴다. 예: a = np.array([1.0, 2.0, 3.0]). 정수 배열을 넘기면 f2py가 자료형을 맞춘 복사본을 만들어, 포트란이 바꾼 값이 원래 배열에 남지 않는다. 2차원이면 np.asfortranarray로 열 우선 배열을 만들어 넘긴다.
