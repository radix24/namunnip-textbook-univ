포트란과 파이썬의 속도 비교

본문

\(\sum_{i=1}^{N} \frac{1}{i^2}\)을 \(N = 10^7\)까지 더하는 같은 계산을 포트란과 파이썬으로 돌리면 걸리는 시간이 크게 다르다. 그런데 파이썬에서도 NumPy로 쓰면 포트란에 가까워진다. 같은 덧셈인데 무엇이 이런 차이를 만들까? 그리고 어떤 일에 어느 언어를 써야 할까?

먼저 알아야 할 것포트란 배열(1.3절)과 NumPy(3.2절)를 쓴다.

5.4.1시간 재기

처음 질문의 합을 \(N = 10^7\)까지 세 가지로 계산해 걸린 시간을 비교한다. 포트란은 cpu_time으로 잰다.

program timing
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  integer :: i, N
  real(dp) :: s, t0, t1
  N = 10000000
  call cpu_time(t0)
  s = 0.0_dp
  do i = 1, N
    s = s + 1.0_dp / real(i, dp)**2
  end do
  call cpu_time(t1)
  print '(A, F12.9, A, F8.4, A)', "s = ", s, ",  ", t1 - t0, " s"
end program timing

파이썬은 순수 반복문과 NumPy를 한 파일에서 잰다.

import time
import numpy as np
N = 10_000_000

t0 = time.perf_counter()
s = 0.0
for i in range(1, N + 1):
    s += 1.0 / i**2
t1 = time.perf_counter()
print("파이썬 반복문", s, t1 - t0)

t0 = time.perf_counter()
i = np.arange(1, N + 1, dtype=float)
s = np.sum(1.0 / i**2)
t1 = time.perf_counter()
print("NumPy", s, t1 - t0)

컴파일할 때 최적화 옵션(gfortran -O2 timing.f90)을 켜고, 같은 컴퓨터에서 여러 번 재서 비교한다. 결과는 컴퓨터, 컴파일러, 파이썬 판에 따라 다르므로 직접 재 보아야 한다. 일반적으로는 순수 파이썬 반복문이 가장 느리고(포트란보다 수십~수백 배), NumPy는 포트란에 가깝게 빨라지는 경우가 많다. 다만 실제 배수는 환경마다 다르다. 또 세 결과의 \(s\)가 마지막 몇 자리에서 조금 다를 수 있는데, 더하는 순서와 방식이 달라 반올림 오차가 다르게 쌓이기 때문이다.

5.4.2차이의 이유

처음 질문의 첫째 물음에 답하자. 포트란은 실행 전에 전체를 기계어로 번역하고, 자료형이 미리 정해져 있어 컴파일러가 반복문을 최적화한다. 그래서 반복 한 번이 기계어 몇 개뿐이다. 반면 순수 파이썬은 한 줄씩 해석하면서, 더하기 한 번마다 두 값의 자료형을 확인하고 새 객체를 만든다. 이 부담이 \(10^7\)번 되풀이된다.

그렇다면 NumPy는 왜 빠를까? 반복은 미리 컴파일된 C 코드 안에서 일어나고, 파이썬은 "배열 전체를 더하라"는 명령만 한 번 내리기 때문이다. 대신 \(10^7\)개짜리 배열을 메모리에 만든다. 그림 1에서 세 방식을 바꿔 보면, 되풀이되는 상자 안에 무엇이 들었는지가 속도를 가른다는 것이 보인다.

5.4.3언어 고르기

처음 질문의 둘째 물음은 기준별로 비교하면 정리된다.

기준포트란파이썬 (+NumPy)
실행 속도매우 빠름반복문은 느림, 배열 연산은 빠름
코드 쓰는 시간선언, 컴파일이 필요짧고 바로 실행
그래프, 자료 정리불편함라이브러리가 많음
오래된 과학 코드많이 남아 있음감싸서 부를 수 있음

그래서 실제 연구에서는 무거운 계산 부분은 포트란이나 C로 쓰고, 입력 준비와 결과 분석, 그래프는 파이썬으로 하는 경우가 많다. NumPy에 들어 있는 f2py로 포트란 서브루틴을 파이썬 함수처럼 불러 쓸 수도 있다(5.8절). 즉 "먼저 파이썬으로 맞게 짜고, 느린 곳을 재서 그 부분만 빠르게"가 기본 순서이다.

마무리

실행 시간은 cpu_time과 time.perf_counter로 같은 조건에서 여러 번 잰다. 처음 질문의 차이는 순수 파이썬이 덧셈마다 해석, 자료형 확인, 객체 만들기를 되풀이하기 때문이며, 포트란과 NumPy는 반복을 컴파일된 코드 안에서 돌려 빠르다. 무거운 계산은 포트란, 준비와 분석은 파이썬으로 나누고 f2py로 잇는다.
