포트란과 파이썬을 오갈 때는 첫 첨자와 끝 포함 여부를 표로 맞춘다

요령 · 배열 첨자

언제 쓰는가

같은 계산을 포트란과 파이썬으로 옮기거나, 배열 일부(슬라이스)를 다룰 때이다.

요령

  1. 첫 첨자
    포트란은 기본이 1부터, 파이썬(NumPy)은 0부터이다.
  2. 끝 포함 여부
    포트란 a(2:4)는 2, 3, 4번 세 개를 포함한다. 파이썬 a[2:4]는 2, 3번 두 개이고 끝은 빠진다.
  3. 옮기는 공식
    포트란 a(i:j) = 파이썬 a[i-1:j]. 반복 do k = 1, n = for k in range(n)(첨자만 하나씩 작게).
  4. 개수로 검산
    슬라이스의 원소 개수가 같은지(포트란 \(j - i + 1\), 파이썬 \(j - i\)) 확인한다.

흔한 실수

  • a(2:4)를 그대로 a[2:4]로 옮겨 원소 하나를 잃고 하나를 밀리게 하는 것.
  • 포트란 반복을 range(1, n)으로 옮겨 마지막 원소를 빠뜨리는 것.

바로 풀어보기

원소가 1, 2, 3, 4, 5인 배열에서 포트란 sum(x(2:4))와 파이썬 sum(x[2:4])의 값을 구하고, 포트란과 같은 결과를 내는 파이썬 슬라이스를 써라.

답과 풀이

답: 포트란 9, 파이썬 7. 같은 것은 x[1:4]

포트란 x(2:4)는 둘째부터 넷째까지 2, 3, 4로 합 9이다. 파이썬 x[2:4]는 0부터 세어 셋째, 넷째인 3, 4로 합 7이다.

포트란 \(i:j\)는 파이썬 \(i - 1:j\)이므로 x[1:4]가 2, 3, 4이다.

이 요령으로 풀리는 문제

  • 포트란 기초 단원 연습 5번
  • 파이썬 기초 단원 연습 6번
영상 콘티 · 40초
  1. 0~5초상자 다섯 개에 1~5가 들어 있고, 위에는 포트란 번호 1~5, 아래에는 파이썬 번호 0~4가 붙는다.같은 배열, 다른 번호.
  2. 5~14초포트란 (2:4) 집게가 위 번호 2부터 4까지 상자 세 개를 집는다.포트란은 끝을 포함한다.
  3. 14~23초파이썬 [2:4] 집게가 아래 번호 2, 3 상자 두 개만 집고 4번 칸 앞에서 멈춘다.파이썬은 0부터, 끝은 빠진다.
  4. 23~32초집게의 시작이 한 칸 왼쪽으로 옮겨져 [1:4]가 되자 포트란과 같은 세 상자를 집는다.시작은 하나 작게, 끝은 그대로.
  5. 32~40초두 집게 아래 원소 개수 3 = 3이 표시된다.개수로 검산한다.
