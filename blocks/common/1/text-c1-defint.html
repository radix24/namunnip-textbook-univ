정적분

본문
이 절에서 배울 것
  • 넓이를 직사각형의 합(리만 합)으로 어림하고, 그 극한으로 정적분을 정의한다.
  • 정적분을 부호 있는 넓이로 해석하고 성질을 쓴다.
먼저 알아야 할 것
  • 시그마 기호와 \(\sum k = \frac{n(n+1)}{2}\), \(\sum k^2 = \frac{n(n+1)(2n+1)}{6}\) (고교 수학I).
  • 다항함수의 정적분 계산 (고교 수학II). 이 절은 그 정적분이 무엇인지를 다시 정의합니다.

4.1.1넓이를 어떻게 정할까

직사각형이나 삼각형의 넓이는 공식이 있지만, \(y = x^2\) 아래, \(0 \le x \le 1\) 부분처럼 곡선으로 둘러싸인 넓이는 어떻게 정할까요? 고등학교에서는 "부정적분을 구해 위끝과 아래끝 값을 뺀다"고 배웠지만, 그것은 계산법이고 넓이가 무엇인지에 대한 설명은 아닙니다. 아르키메데스 때부터 쓴 생각은 영역을 얇은 직사각형으로 잘라 그 넓이를 더하는 것입니다.

\([0, 1]\)을 \(n\)등분하면 각 조각의 폭은 \(\frac1n\)입니다. \(k\)번째 조각의 오른쪽 끝 \(\frac kn\)에서 높이 \(\left(\frac kn\right)^2\)인 직사각형을 세우면 넓이의 합은

\[R_n = \sum_{k=1}^{n}\left(\frac kn\right)^2\cdot\frac1n = \frac{1}{n^3}\sum_{k=1}^{n}k^2 = \frac{(n+1)(2n+1)}{6n^2}\]

입니다. \(n = 10\)이면 0.385, \(n = 100\)이면 0.33835, \(n = 1000\)이면 0.3338335로, \(n\)을 키우면 \(\frac13\)에 다가갑니다. 실제로 \(R_n = \frac16\left(1 + \frac1n\right)\left(2 + \frac1n\right) \to \frac26 = \frac13\)입니다. 이 극한을 넓이로 정의합니다.

4.1.2정적분의 정의

정의 4.1.1 (정적분)

\(f\)가 \([a, b]\)에서 정의된 함수일 때, \([a, b]\)를 폭 \(\Delta x = \frac{b - a}{n}\)인 \(n\)개의 작은 구간으로 나누고 각 작은 구간에서 점 \(x_k^*\)를 고른다. 극한

\[\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{k=1}^{n}f(x_k^*)\,\Delta x\]

가 점을 고르는 방법에 상관없이 같은 값으로 존재하면, 이를 \(f\)의 \(a\)에서 \(b\)까지의 정적분이라 한다. 합 \(\sum f(x_k^*)\Delta x\)를 리만 합이라 한다.

기호 \(\int\)는 합(Sum)의 S를 길게 늘인 것이고, \(dx\)는 폭 \(\Delta x\)가 한없이 얇아진 것을 나타냅니다. 곧 \(\int_a^b f(x)\,dx\)는 "높이 \(f(x)\) × 아주 얇은 폭 \(dx\)를 \(a\)부터 \(b\)까지 모두 더한 것"이라고 읽으면 됩니다. 이 읽는 법은 6단원(부피, 길이)과 물리(일, 질량)에서 그대로 쓰입니다.

연속함수이면 이 극한이 항상 존재합니다(증명은 해석학 과목). 그래서 이 과목에서 다루는 함수는 모두 정적분을 가집니다.

4.1.3부호 있는 넓이와 성질

\(f(x) < 0\)인 곳에서는 \(f(x_k^*)\Delta x\)가 음수입니다. 그래서 정적분은 "\(x\)축 위의 넓이 − \(x\)축 아래의 넓이"인 부호 있는 넓이입니다. 예를 들어 \(\int_0^{2\pi}\sin x\,dx = 0\)인 것은 위아래 넓이가 같기 때문입니다.

리만 합의 성질에서 다음이 나옵니다.

  • \(\int_a^b [f(x) + g(x)]\,dx = \int_a^b f\,dx + \int_a^b g\,dx\), \(\int_a^b cf\,dx = c\int_a^b f\,dx\).
  • \(\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx\).
  • \(\int_b^a f\,dx = -\int_a^b f\,dx\), \(\int_a^a f\,dx = 0\).
  • \([a, b]\)에서 \(f(x) \le g(x)\)이면 \(\int_a^b f\,dx \le \int_a^b g\,dx\).
예제 4.1.2

넓이로 해석하여 \(\int_0^3\sqrt{9 - x^2}\,dx\)와 \(\int_0^5(x - 2)\,dx\)를 구하여라.

풀이. \(y = \sqrt{9 - x^2}\)은 반지름 3인 원의 위쪽 반이고, \(0 \le x \le 3\)은 그중 \(\frac14\)입니다. 넓이 \(\frac14\pi\cdot9 = \frac{9\pi}{4}\).

\(y = x - 2\)는 직선입니다. \(0 \le x \le 2\)에서는 \(x\)축 아래에 넓이 2인 삼각형, \(2 \le x \le 5\)에서는 위에 넓이 \(\frac92\)인 삼각형이 있으므로 정적분은 \(\frac92 - 2 = \frac52\).

주의정적분과 넓이는 같지 않습니다. 함수가 음수인 부분이 있으면 정적분은 넓이보다 작습니다. "넓이"를 물으면 \(\int_a^b|f(x)|\,dx\)를 구해야 합니다.
요약
  1. 정적분은 리만 합 \(\sum f(x_k^*)\Delta x\)의 극한이다. "높이 × 얇은 폭의 합"으로 읽는다.
  2. 정적분은 부호 있는 넓이: \(x\)축 위는 +, 아래는 −.
  3. 선형성, 구간 나누기, 위끝·아래끝 바꾸면 부호 바뀜, 크기 비교가 성립한다.

4.1.4연습문제

기본

  1. 리만 합의 극한으로 \(\int_0^2 x\,dx\)를 구하여라.
    답

    \(\Delta x = \frac2n\), \(x_k = \frac{2k}{n}\). 합 \(\frac{4}{n^2}\cdot\frac{n(n+1)}{2} \to 2\).

  2. 넓이로 해석하여 \(\int_{-1}^{1}|x|\,dx\)를 구하여라.
    답

    삼각형 두 개, 각 \(\frac12\). 합 1.

응용

  1. \(\int_0^1 f(x)\,dx = 2\), \(\int_0^3 f(x)\,dx = 5\)일 때 \(\int_1^3 f(x)\,dx\)와 \(\int_3^1 2f(x)\,dx\)는?
    답

    \(5 - 2 = 3\), \(-2\cdot3 = -6\).

  2. \(\int_0^1 e^{-x^2}dx\)가 \(e^{-1}\)과 1 사이에 있음을 보여라.
    답

    \(0 \le x \le 1\)에서 \(e^{-1} \le e^{-x^2} \le 1\). 크기 비교 성질로 적분하면 \(e^{-1} \le \int \le 1\).
