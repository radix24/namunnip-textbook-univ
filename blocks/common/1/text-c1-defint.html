정적분

본문

\(y = x^2\) 아래, \(0 \le x \le 1\) 부분의 넓이는 얼마일까? 고등학교에서는 \(\frac13\)이라고 계산했지만, 곡선으로 둘러싸인 모양의 "넓이"란 애초에 무엇을 뜻할까?

먼저 알아야 할 것고교 수학I의 시그마 기호와 \(\sum k = \frac{n(n+1)}{2}\), \(\sum k^2 = \frac{n(n+1)(2n+1)}{6}\), 그리고 고교 수학II의 다항함수의 정적분 계산을 쓴다. 이 절은 그 정적분이 무엇인지를 다시 정의한다.

4.1.1넓이를 어떻게 정할까

직사각형이나 삼각형의 넓이는 공식이 있지만, 곡선으로 둘러싸인 넓이는 어떻게 정할까? 고등학교에서는 "부정적분을 구해 위끝과 아래끝 값을 뺀다"고 배웠지만, 그것은 계산법이지 넓이가 무엇인지에 대한 설명은 아니다. 그래서 아르키메데스 때부터 쓴 생각으로 돌아간다. 영역을 얇은 직사각형으로 잘라 그 넓이를 더하는 것이다.

\([0, 1]\)을 \(n\)등분하면 각 조각의 폭은 \(\frac1n\)이다. \(k\)번째 조각의 오른쪽 끝 \(\frac kn\)에서 높이 \(\left(\frac kn\right)^2\)인 직사각형을 세우면 넓이의 합은 다음과 같다.

\[R_n = \sum_{k=1}^{n}\left(\frac kn\right)^2\cdot\frac1n = \frac{1}{n^3}\sum_{k=1}^{n}k^2 = \frac{(n+1)(2n+1)}{6n^2}\]

\(n = 10\)이면 0.385, \(n = 100\)이면 0.33835, \(n = 1000\)이면 0.3338335로, \(n\)을 키우면 \(\frac13\)에 다가간다. 실제로 \(R_n = \frac16\left(1 + \frac1n\right)\left(2 + \frac1n\right) \to \frac26 = \frac13\)이다. 그림 1에서 \(n = 10\)일 때 직사각형이 곡선 위로 조금씩 삐져나온 부분이 0.385와 \(\frac13\)의 차이이고, \(n\)을 60까지 올리면 그 삐져나온 부분이 눈에 띄지 않게 된다. 그러므로 이 극한을 넓이로 정의한다.

높이를 왼쪽 끝에서 재면 직사각형이 곡선 아래로 들어가서 합이 \(\frac13\)보다 작다. 가령 \(n = 10\)이면 0.285이다. 그런데 오른쪽 끝의 합과 왼쪽 끝의 합은 \(n\)을 키우면 같은 값 \(\frac13\)으로 모인다. 그림 1에서 높이를 재는 점을 바꾸어 이 사실을 확인할 수 있다.

4.1.2정적분의 정의

정의 4.1.1 (정적분)

\(f\)가 \([a, b]\)에서 정의된 함수일 때, \([a, b]\)를 폭 \(\Delta x = \frac{b - a}{n}\)인 \(n\)개의 작은 구간으로 나누고 각 작은 구간에서 점 \(x_k^*\)를 고른다. 극한

\[\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{k=1}^{n}f(x_k^*)\,\Delta x\]

가 점을 고르는 방법에 상관없이 같은 값으로 존재하면, 이를 \(f\)의 \(a\)에서 \(b\)까지의 정적분이라 한다. 합 \(\sum f(x_k^*)\Delta x\)를 리만 합이라 한다.

정의의 "점을 고르는 방법에 상관없이"가 바로 앞 문단에서 확인한 사실이다. 기호 \(\int\)는 합(Sum)의 S를 길게 늘인 것이고, \(dx\)는 폭 \(\Delta x\)가 한없이 얇아진 것을 나타낸다. 즉 \(\int_a^b f(x)\,dx\)는 "높이 \(f(x)\) × 아주 얇은 폭 \(dx\)를 \(a\)부터 \(b\)까지 모두 더한 것"으로 읽는다. 이 읽는 법은 6단원의 부피와 길이, 물리의 일과 질량에서 그대로 쓰인다.

연속함수이면 이 극한이 항상 존재한다. 그래서 이 과목에서 다루는 함수는 모두 정적분을 가진다.

증명은 3학년 해석학에서 한다. 연속이 아니어도 불연속점이 유한 개이고 함수가 유계이면 정적분이 존재한다.

4.1.3부호 있는 넓이와 성질

그런데 \(f(x) < 0\)인 곳에서는 \(f(x_k^*)\Delta x\)가 음수이다. 따라서 정적분은 "\(x\)축 위의 넓이 − \(x\)축 아래의 넓이"인 부호 있는 넓이이다. 가령 \(\int_0^{2\pi}\sin x\,dx = 0\)인 것은 위아래 넓이가 같기 때문이다.

리만 합의 성질에서 몇 가지 규칙이 바로 나온다. 합과 상수배는 적분 밖으로 나눠 쓸 수 있어서 \(\int_a^b [f + g]\,dx = \int_a^b f\,dx + \int_a^b g\,dx\), \(\int_a^b cf\,dx = c\int_a^b f\,dx\)이다. 구간을 이어 붙이면 \(\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx\)이고, 위끝과 아래끝을 바꾸면 부호가 바뀌어 \(\int_b^a f\,dx = -\int_a^b f\,dx\), \(\int_a^a f\,dx = 0\)이다. 마지막으로 \([a, b]\)에서 \(f(x) \le g(x)\)이면 \(\int_a^b f\,dx \le \int_a^b g\,dx\)이다. 네 규칙 모두 직사각형의 넓이를 더하는 그림에서 확인할 수 있다.

예제 4.1.2

넓이로 해석하여 \(\int_0^3\sqrt{9 - x^2}\,dx\)와 \(\int_0^5(x - 2)\,dx\)를 구하여라.

풀이. \(y = \sqrt{9 - x^2}\)은 반지름 3인 원의 위쪽 반이고, \(0 \le x \le 3\)은 그중 \(\frac14\)이다. 따라서 값은 \(\frac14\pi\cdot9 = \frac{9\pi}{4}\)이다.

\(y = x - 2\)는 직선이다. \(0 \le x \le 2\)에서는 \(x\)축 아래에 넓이 2인 삼각형이, \(2 \le x \le 5\)에서는 위에 넓이 \(\frac92\)인 삼각형이 있다. 그러므로 정적분은 \(\frac92 - 2 = \frac52\)이고, 두 삼각형의 넓이를 그냥 더한 \(\frac{13}{2}\)이 아니다.

주의정적분과 넓이는 같지 않다. 함수가 음수인 부분이 있으면 정적분은 넓이보다 작다. 넓이를 물으면 \(\int_a^b|f(x)|\,dx\)를 구해야 한다.
마무리

곡선 아래의 넓이는 영역을 얇은 직사각형으로 잘라 더한 리만 합의 극한으로 정의하고, 이것이 정적분이다. 그래서 처음 질문의 넓이 \(\frac13\)은 \(\frac{(n+1)(2n+1)}{6n^2}\)이 다가가는 값이며, 높이를 어디서 재든 같은 값으로 모인다. 함수가 음수인 곳은 음의 넓이로 세므로 정적분은 부호 있는 넓이이다.

4.1.4연습문제

기본

  1. 리만 합의 극한으로 \(\int_0^2 x\,dx\)를 구하여라.
    답

    \(\Delta x = \frac2n\), \(x_k = \frac{2k}{n}\). 합 \(\frac{4}{n^2}\cdot\frac{n(n+1)}{2} \to 2\).

  2. 넓이로 해석하여 \(\int_{-1}^{1}|x|\,dx\)를 구하여라.
    답

    삼각형 두 개, 각 \(\frac12\). 합 1.

응용

  1. \(\int_0^1 f(x)\,dx = 2\), \(\int_0^3 f(x)\,dx = 5\)일 때 \(\int_1^3 f(x)\,dx\)와 \(\int_3^1 2f(x)\,dx\)는?
    답

    \(5 - 2 = 3\), \(-2\cdot3 = -6\).

  2. \(\int_0^1 e^{-x^2}dx\)가 \(e^{-1}\)과 1 사이에 있음을 보여라.
    답

    \(0 \le x \le 1\)에서 \(e^{-1} \le e^{-x^2} \le 1\). 크기 비교 성질로 적분하면 \(e^{-1} \le \int \le 1\).
