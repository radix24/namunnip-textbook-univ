수렴 구간은 비 판정법으로 반지름을 구한 뒤 양 끝을 따로 넣어 본다

요령 · 거듭제곱급수의 수렴 구간

언제 쓰는가

\(\sum c_n(x - a)^n\)의 수렴 반지름과 수렴 구간을 묻는 문제입니다. 답에 괄호 \([\ \ )\)의 모양까지 정확히 써야 하는 문제가 대부분입니다.

요령

  1. \(x\)를 품은 채 비 판정
    \(\left|\frac{a_{n+1}}{a_n}\right|\)를 \(x\)까지 포함해 계산하면 \(L|x - a|\) 꼴의 극한이 나옵니다.
  2. 1보다 작게 두고 중심과 반지름
    \(L|x - a| < 1\)에서 중심 \(a\), 반지름 \(R = \frac1L\)입니다. \((2x + 1)^n\)처럼 \(x\)에 계수가 있으면 \(\left|x + \frac12\right|\) 꼴로 바꾼 뒤 읽습니다.
  3. 왼쪽 끝을 넣는다
    \(x = a - R\)을 원래 급수에 넣습니다. 보통 부호가 번갈아 바뀌는 급수가 되어 교대급수 판정법을 씁니다.
  4. 오른쪽 끝을 넣는다
    \(x = a + R\)을 넣으면 보통 양수항 급수가 되어 \(p\)급수와 비교합니다.
  5. 괄호 모양을 정한다
    수렴하는 끝은 대괄호, 발산하는 끝은 소괄호로 씁니다.

흔한 실수

  • 끝점에서 다시 비 판정법을 쓰는 것. 끝점에서는 비의 극한이 언제나 1이라 판정이 되지 않습니다.
  • \((2x + 1)^n\) 꼴에서 \(|2x + 1| < 1\)을 반지름 1로 읽는 것. \(\left|x + \frac12\right| < \frac12\)이므로 반지름은 \(\frac12\)입니다.

바로 풀어보기

\(\displaystyle\sum_{n=1}^\infty\frac{(x - 2)^n}{n\,3^n}\)의 수렴 반지름과 수렴 구간을 구하세요.

답과 풀이

답: \(R = 3\), 수렴 구간 \([-1, 5)\)

비: \(\left|\frac{(x - 2)^{n+1}}{(n + 1)3^{n+1}}\cdot\frac{n\,3^n}{(x - 2)^n}\right| = \frac{n}{n + 1}\cdot\frac{|x - 2|}{3} \to \frac{|x - 2|}{3}\). 이것이 1보다 작으면 \(|x - 2| < 3\)이므로 중심 2, 반지름 3, 열린 구간 \((-1, 5)\)입니다.

왼쪽 끝 \(x = -1\): \(\sum\frac{(-3)^n}{n\,3^n} = \sum\frac{(-1)^n}{n}\), 교대급수 판정법으로 수렴합니다. 오른쪽 끝 \(x = 5\): \(\sum\frac1n\), 조화급수라 발산합니다. 따라서 \([-1, 5)\)입니다.

이 요령으로 풀리는 문제

  • 무한수열과 급수 단원 연습 5번
영상 콘티 · 45초
  1. 0~5초\(\sum\frac{(x - 2)^n}{n\,3^n}\) 아래에 수직선이 깔립니다.이 급수는 어떤 \(x\)에서 수렴할까요?
  2. 5~14초\(a_{n+1}\)과 \(a_n\)이 나란히 놓이고 나눗셈 선이 그어진 뒤 공통 부분이 지워져 \(\frac{|x - 2|}{3}\)만 남습니다.\(x\)를 품은 채로 비를 구합니다.
  3. 14~22초수직선의 2에 중심 점이 찍히고, 양쪽으로 길이 3인 화살표가 뻗어 \(-1\)과 5에 닿습니다. 그 사이가 초록으로 칠해지고 양 끝에는 빈 동그라미가 놓입니다.중심 2, 반지름 3. 끝은 아직 비어 있습니다.
  4. 22~32초왼쪽 끝 \(-1\)에 확대경이 다가가 \(\sum\frac{(-1)^n}{n}\)이 나오고, 부분합이 위아래로 흔들리며 한 값에 모이는 그래프가 나옵니다. 빈 동그라미가 채워집니다.왼쪽 끝은 교대급수, 수렴.
  5. 32~40초오른쪽 끝 5에서 \(\sum\frac1n\)이 나오고 부분합이 천천히 끝없이 올라갑니다. 동그라미는 비어 있는 채로 남습니다.오른쪽 끝은 조화급수, 발산.
  6. 40~45초수직선 위의 칠한 구간이 \([-1, 5)\) 기호로 바뀝니다.끝점은 하나씩 따로 넣어 봅니다.
