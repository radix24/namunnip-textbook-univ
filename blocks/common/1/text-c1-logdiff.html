로그함수와 역삼각함수의 도함수

본문

\(y = \ln x\)의 그래프는 오른쪽으로 갈수록 점점 완만해진다. 그렇다면 \(x = 2\)에서의 접선 기울기는 정확히 얼마일까? 그리고 \(x^x\)처럼 밑과 지수에 모두 \(x\)가 있는 함수는 어떻게 미분할까?

먼저 알아야 할 것자연로그와 역삼각함수의 정의(1.2절), 연쇄법칙(2.2절), 음함수 미분법(2.3절)을 쓴다.

2.4.1자연로그의 도함수

\(y = \ln x\)는 \(e^y = x\)와 같은 뜻이다. 즉 \(\ln x\)는 식으로 바로 미분하기 어려워도, 관계식 \(e^y = x\)는 음함수 미분법으로 미분할 수 있다. 양변을 \(x\)로 미분하면 \(e^y\dfrac{dy}{dx} = 1\)이고, 따라서 \(\dfrac{dy}{dx} = \dfrac{1}{e^y} = \dfrac1x\)이다.

정리 2.4.1

\(\dfrac{d}{dx}\ln x = \dfrac1x\) (\(x > 0\)), \(\dfrac{d}{dx}\ln|x| = \dfrac1x\) (\(x \ne 0\)), \(\dfrac{d}{dx}\log_a x = \dfrac{1}{x\ln a}\).

처음 질문의 답은 \(\frac12\)이다. 그림 1에서 \(x\)를 1, 2, 4로 옮기면 접선의 기울기가 1, 0.5, 0.25로 절반씩 줄어든다. 이것은 지수함수 \(e^x\)의 기울기가 값과 같다는 성질을 \(y = x\)에 대해 뒤집어 본 것이다. \(e^x\)의 그래프에서 높이가 \(x\)인 점의 기울기가 \(x\)이므로, 뒤집은 \(\ln x\)의 그래프에서는 그 점의 기울기가 \(\frac1x\)이 된다.

두 번째 식은 \(x < 0\)일 때 \(\ln|x| = \ln(-x)\)를 연쇄법칙으로 미분해 \(\dfrac{1}{-x}\cdot(-1) = \dfrac1x\)을 얻는다. 세 번째 식은 \(\log_a x = \dfrac{\ln x}{\ln a}\)에서 나온다. 여기에 연쇄법칙을 합치면 \(\dfrac{d}{dx}\ln u = \dfrac{u'}{u}\)가 되는데, 이 꼴은 적분 \(\int\frac{u'}{u}dx = \ln|u|\)에서도 계속 나온다.

예제 2.4.2

(가) \(y = \ln(x^2 + 1)\) (나) \(y = \ln\sqrt{\dfrac{x + 1}{x - 1}}\)을 미분하여라.

풀이. (가) 속함수가 \(x^2 + 1\)이므로 \(y' = \dfrac{2x}{x^2 + 1}\)이다.

(나) 바로 미분하면 복잡하니 먼저 로그의 성질로 풀어 둔다. \(y = \frac12\ln(x + 1) - \frac12\ln(x - 1)\)이므로 \(y' = \dfrac{1}{2(x + 1)} - \dfrac{1}{2(x - 1)} = \dfrac{-1}{x^2 - 1}\)이다. 그러므로 로그를 미분하기 전에 곱·몫·거듭제곱을 합·차·상수배로 바꾸면 계산이 크게 줄어든다. 가령 \(x = 3\)에서 답은 \(-\frac18\)인데, 근호와 분수를 그대로 둔 채 몫의 미분법과 연쇄법칙을 겹쳐 쓰면 같은 값을 얻기까지 서너 줄이 더 든다.

2.4.2로그 미분법

그런데 \(y = x^x\)은 밑과 지수에 모두 \(x\)가 있어서 \((x^n)' = nx^{n-1}\)도 \((a^x)' = a^x\ln a\)도 쓸 수 없다. 앞의 공식은 지수가 상수일 때, 뒤의 공식은 밑이 상수일 때의 것이기 때문이다. 이럴 때 양변에 로그를 취하면 지수가 앞으로 내려와 곱이 된다.

예제 2.4.3

\(y = x^x\) (\(x > 0\))을 미분하여라.

풀이. 양변에 로그를 취하면 \(\ln y = x\ln x\)이다. 양변을 \(x\)로 미분하면, 왼쪽은 음함수 미분이므로 \(\dfrac{y'}{y} = \ln x + x\cdot\dfrac1x = \ln x + 1\)이다. 따라서 \(y' = x^x(\ln x + 1)\)이다.

결과를 읽어 보자. \(\ln x + 1 = 0\), 곧 \(x = \frac1e \approx 0.368\)에서 기울기가 0이므로 \(x^x\)은 여기서 가장 작은 값 \(e^{-1/e} \approx 0.692\)를 갖는다. 실제로 \(0.3^{0.3} \approx 0.697\), \(0.4^{0.4} \approx 0.693\)으로 둘 다 이 값보다 조금 크다.

로그 미분법은 여러 인수의 곱과 몫을 미분할 때도 편하다. 가령 \(y = \dfrac{x^{3/4}\sqrt{x^2 + 1}}{(3x + 2)^5}\)이면 \(\ln y = \frac34\ln x + \frac12\ln(x^2 + 1) - 5\ln(3x + 2)\)로 바꾸어 미분하고, 마지막에 \(y\)를 곱한다.

2.4.3역삼각함수의 도함수

역삼각함수도 같은 방법으로 미분한다. \(y = \arcsin x\)는 \(\sin y = x\), \(-\frac\pi2 \le y \le \frac\pi2\)와 같은 뜻이다. 음함수 미분하면 \(\cos y\,\dfrac{dy}{dx} = 1\), 곧 \(\dfrac{dy}{dx} = \dfrac{1}{\cos y}\)이다. 그런데 이 범위의 \(y\)에서는 \(\cos y \ge 0\)이므로 \(\cos y = \sqrt{1 - \sin^2 y} = \sqrt{1 - x^2}\)이다. 한편 \(y = \arctan x\)는 \(\tan y = x\)이므로 \(\sec^2 y\,\dfrac{dy}{dx} = 1\)이고, \(\sec^2 y = 1 + \tan^2 y = 1 + x^2\)이다.

정리 2.4.4 \[\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1 - x^2}}, \qquad \frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1 - x^2}}, \qquad \frac{d}{dx}\arctan x = \frac{1}{1 + x^2}.\]

\(\arccos\)는 \(\arcsin x + \arccos x = \frac\pi2\)(1.2절 연습문제)이므로 \(\arcsin\)의 도함수에 부호만 바꾼 것이다. 그림 2에서 보듯이 \(\arctan x\)의 기울기는 \(x = 0\)에서 1로 가장 크고, \(x\)가 커질수록 0으로 줄어든다. 그래프가 수평 점근선 \(y = \pm\frac\pi2\)에 붙어 가는 모습과 맞는다.

이 세 공식은 거꾸로 읽으면 적분 공식이 된다. 가령 \(\int\dfrac{dx}{1 + x^2} = \arctan x + C\)이고, 유리함수를 적분할 때(5.4절) 이 식이 꼭 필요하다.

예제 2.4.5

\(y = \arctan(\sqrt x)\)를 미분하여라.

풀이. 겉함수는 \(\arctan\), 속함수는 \(\sqrt x\)이므로 연쇄법칙으로 \(y' = \dfrac{1}{1 + (\sqrt x)^2}\cdot\dfrac{1}{2\sqrt x} = \dfrac{1}{2\sqrt x(1 + x)}\)이다. 가령 \(x = 1\)이면 \(\frac14\)이다.

주의\(\ln(x^2 + 1)\)의 도함수를 \(\dfrac{1}{x^2 + 1}\)이라고 쓰면 속함수의 도함수 \(2x\)를 빠뜨린 것이다. 또 \(x^x\)를 \(x\cdot x^{x-1}\)로 미분하면 틀린다. 지수에 \(x\)가 있으면 로그 미분법을 쓴다.
마무리

\(\ln x\)는 \(e^y = x\)를 음함수 미분해 \((\ln x)' = \frac1x\)을 얻고, 그래서 처음 질문의 \(x = 2\)에서 기울기는 \(\frac12\)이다. 밑과 지수에 모두 \(x\)가 있는 \(x^x\)은 양변에 로그를 취해 미분하며 \((x^x)' = x^x(\ln x + 1)\)이다. 역삼각함수도 같은 방법으로 \((\arcsin x)' = \frac{1}{\sqrt{1 - x^2}}\), \((\arctan x)' = \frac{1}{1 + x^2}\)를 얻는다.

2.4.4연습문제

기본

  1. 미분하여라. (가) \(\ln(3x)\) (나) \(\log_2(x^2)\) (다) \(\arcsin(2x)\)
    답

    (가) \(\frac1x\) (나) \(\frac{2}{x\ln2}\) (다) \(\frac{2}{\sqrt{1 - 4x^2}}\)

  2. \(y = x\ln x - x\)를 미분하여라.
    답

    \(\ln x + 1 - 1 = \ln x\).

응용

  1. 로그 미분법으로 \(y = x^{\sin x}\)을 미분하여라.
    답

    \(\ln y = \sin x\ln x\), \(\frac{y'}{y} = \cos x\ln x + \frac{\sin x}{x}\). \(y' = x^{\sin x}\left(\cos x\ln x + \frac{\sin x}{x}\right)\).

  2. \(y = \arctan\frac1x\)과 \(y = \arctan x\)의 도함수를 비교하고 그 이유를 설명하여라.
    답

    \(\left(\arctan\frac1x\right)' = \frac{1}{1 + 1/x^2}\cdot\left(-\frac{1}{x^2}\right) = -\frac{1}{1 + x^2}\). 부호만 다르다. \(x > 0\)이면 \(\arctan x + \arctan\frac1x = \frac\pi2\)로 합이 상수이기 때문이다.
