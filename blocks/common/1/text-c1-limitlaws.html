극한 법칙과 압축 정리 (보충)

보충 본문

\(x^2\sin\frac1x\)은 0 근처에서 끝없이 출렁여서 대입도 약분도 통하지 않는다. 그래도 \(x \to 0\)일 때 이 함수가 0으로 간다고 말할 수 있을까? 그리고 고등학교에서 "그냥 대입"하던 계산은 왜 맞았을까?

먼저 알아야 할 것ε-δ 정의와 "두 δ 가운데 작은 쪽을 잡는" 기법(1.3절), 고교 수학I의 호도법과 부채꼴의 넓이 \(\frac12r^2\theta\), 삼각함수의 정의를 쓴다. 고교 수학II에서 극한을 계산해 본 경험이 있으면 좋다. 이 절은 그 계산 규칙이 왜 맞는지 보인다.

2.2.1매번 ε-δ를 쓸 수는 없다

1.3절에서 \(\lim_{x\to3}x^2 = 9\) 하나를 증명하는 데도 한 문단이 들었다. 그렇다면 \(\lim_{x\to2}\frac{x^3 + 5x}{x^2 - 1}\) 같은 것을 매번 정의로 증명할 수는 없다. 그래서 간단한 극한 몇 개와 "극한끼리 더하고 곱해도 된다"는 규칙을 한 번 증명해 두고, 그다음부터는 규칙으로 계산한다. 고등학교에서 쓰던 규칙이 바로 이것이며, 이 절에서는 그 근거를 본다.

2.2.2극한 법칙

정리 2.2.1 (극한 법칙)

\(\lim_{x\to a}f(x) = L\), \(\lim_{x\to a}g(x) = M\)이고 \(c\)가 상수이면 (1) \(\lim_{x\to a}[f(x) + g(x)] = L + M\), (2) \(\lim_{x\to a}cf(x) = cL\), (3) \(\lim_{x\to a}f(x)g(x) = LM\), (4) \(M \ne 0\)이면 \(\lim_{x\to a}\frac{f(x)}{g(x)} = \frac LM\)이다.

모든 법칙에는 두 극한이 존재한다는 가정이 붙어 있다. 가령 \(\lim_{x\to0}\left[\frac1x + \left(-\frac1x\right)\right] = 0\)이지만, 각각의 극한은 존재하지 않으므로 "\(\lim\frac1x + \lim\left(-\frac1x\right)\)"로 나누어 쓸 수 없다.

여기서는 합의 법칙만 증명한다. 나머지도 같은 생각으로 증명할 수 있다(곱의 법칙은 연습문제 6). 증명의 생각은 허용 오차를 반씩 나누는 것이다. \(f\)와 \(g\)가 각각 \(\frac\varepsilon2\) 안에 들어오면, 둘을 더한 것은 \(\varepsilon\) 안에 들어온다.

증명 (1).\(\varepsilon > 0\)이 주어졌다고 하자. \(\lim f = L\)이므로 \(0 < |x - a| < \delta_1\)이면 \(|f(x) - L| < \frac\varepsilon2\)인 \(\delta_1\)이 있다(정의의 \(\varepsilon\) 자리에 \(\frac\varepsilon2\)을 넣었다). 마찬가지로 \(0 < |x - a| < \delta_2\)이면 \(|g(x) - M| < \frac\varepsilon2\)인 \(\delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 놓으면 \(0 < |x - a| < \delta\)일 때 두 부등식이 모두 성립하고, 삼각부등식(1.1절)에 의해

\[|(f + g)(x) - (L + M)| \le |f(x) - L| + |g(x) - M| < \tfrac\varepsilon2 + \tfrac\varepsilon2 = \varepsilon\]

이다. ∎

이 법칙들과 두 가지 기본 극한 \(\lim_{x\to a}c = c\), \(\lim_{x\to a}x = a\)를 합치면 다음을 얻는다.

따름정리 2.2.2 (대입 법칙)

\(p\)가 다항함수이면 \(\lim_{x\to a}p(x) = p(a)\)이다. \(r = \frac pq\)가 유리함수이고 \(q(a) \ne 0\)이면 \(\lim_{x\to a}r(x) = r(a)\)이다.

\(x^2 = x\cdot x\)이므로 곱의 법칙에서 \(\lim x^2 = a^2\)이고, 같은 방식으로 \(\lim x^n = a^n\)이다. 여기에 상수배와 합의 법칙을 쓰면 다항식 전체가 처리된다. 즉 처음 질문의 "그냥 대입"은 극한 법칙 네 개를 한꺼번에 쓴 것이다.

2.2.3\(\frac00\) 꼴 정리하기

대입했을 때 분모가 0이면 몫의 법칙을 쓸 수 없다. 분자도 0인 \(\frac00\) 꼴이면 극한이 있을 수도 없을 수도 있어서 식을 정리해야 한다. 그때 정리해도 되는 근거는 다음 사실이다.

정리 2.2.3

\(a\) 근처에서 \(x \ne a\)인 모든 \(x\)에 대해 \(f(x) = g(x)\)이고 \(\lim_{x\to a}g(x)\)가 존재하면, \(\lim_{x\to a}f(x) = \lim_{x\to a}g(x)\)이다.

정의 2.1.1이 \(x = a\)를 빼고 보기 때문에 이 정리는 정의에서 곧바로 나온다. 따라서 \(x \ne a\)일 때만 성립하는 약분을 해도 극한은 변하지 않는다.

예제 2.2.4

(가) \(\lim_{x\to2}\frac{x^3 - 8}{x^2 - 4}\) (나) \(\lim_{h\to0}\frac{\sqrt{9 + h} - 3}{h}\)을 구하여라.

풀이. (가) 분자와 분모에 공통인수 \(x - 2\)가 있다. \(x \ne 2\)이면

\[\frac{x^3 - 8}{x^2 - 4} = \frac{(x - 2)(x^2 + 2x + 4)}{(x - 2)(x + 2)} = \frac{x^2 + 2x + 4}{x + 2}\]

이고, 오른쪽은 \(x = 2\)에서 분모가 4이므로 대입할 수 있다. 따라서 극한은 \(\frac{12}{4} = 3\)이다.

(나) 근호가 있으면 분자를 유리화한다. \(h \ne 0\)이면

\[\frac{\sqrt{9 + h} - 3}{h} = \frac{(9 + h) - 9}{h(\sqrt{9 + h} + 3)} = \frac{1}{\sqrt{9 + h} + 3} \to \frac16\]

이다. 마지막 단계에서 \(\sqrt{9 + h} \to 3\)을 썼는데, 이는 \(\sqrt{\ }\)가 연속이라는 사실(1.4절)이다. 수치로 확인하면 \(h = 0.01\)일 때 \(\frac{\sqrt{9.01} - 3}{0.01} \approx 0.16662\)로 \(\frac16 \approx 0.16667\)에 가깝다.

2.2.4압축 정리

그런데 대입도 약분도 안 되는 극한이 있다. 처음 질문의 \(x^2\sin\frac1x\)은 \(x \to 0\)일 때 \(\sin\frac1x\)이 \(-1\)과 1 사이를 끝없이 오가므로, \(\lim\sin\frac1x\)이 없어 곱의 법칙을 쓸 수 없다. 하지만 \(-x^2 \le x^2\sin\frac1x \le x^2\)이고 양쪽 벽이 모두 0으로 간다. 그림 1에서 보는 폭 \(w\)를 1에서 0.02까지 줄여 보면 곡선은 계속 출렁이지만 두 벽 사이를 벗어나지 못하고, 벽과 함께 0으로 좁아진다. 이것을 정리로 만든 것이 압축 정리이다.

정리 2.2.5 (압축 정리)

\(a\) 근처에서 (\(a\) 제외) \(g(x) \le f(x) \le h(x)\)이고 \(\lim_{x\to a}g(x) = \lim_{x\to a}h(x) = L\)이면 \(\lim_{x\to a}f(x) = L\)이다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. 가정에 의해 \(0 < |x - a| < \delta_1\)이면 \(L - \varepsilon < g(x)\), \(0 < |x - a| < \delta_2\)이면 \(h(x) < L + \varepsilon\)인 \(\delta_1, \delta_2\)가 있다. 또 부등식 \(g \le f \le h\)가 성립하는 범위를 \(0 < |x - a| < \delta_3\)이라 하자. \(\delta = \min(\delta_1, \delta_2, \delta_3)\)이면 \(0 < |x - a| < \delta\)일 때 \(L - \varepsilon < g(x) \le f(x) \le h(x) < L + \varepsilon\)이므로 \(|f(x) - L| < \varepsilon\)이다. ∎

그러므로 압축 정리를 쓸 때 할 일은 같은 극한을 갖는 두 함수 사이에 원하는 함수를 끼워 넣는 부등식을 찾는 것이다. 진동하는 인수가 있으면 대개 \(|\sin(\cdots)| \le 1\), \(|\cos(\cdots)| \le 1\)이 그 부등식을 준다.

2.2.5\(\frac{\sin x}{x}\)의 극한

삼각함수의 미분은 모두 다음 극한 하나에 기댄다. 고교 미적분에서 이 극한을 배웠다면 증명을 여기서 다시 확인하고, 배우지 않았다면 처음부터 따라오면 된다.

정리 2.2.6 \[\lim_{x\to0}\frac{\sin x}{x} = 1 \qquad (x\text{는 라디안}).\]

먼저 수치로 확인해 보자. \(x = 0.1\)이면 \(\frac{\sin 0.1}{0.1} = 0.99833\)이고, \(x = 0.01\)이면 \(0.9999833\)이다. 분자와 분모가 모두 0으로 가는데 그 비는 1로 간다. 다시 말해 작은 \(x\)에서 \(\sin x \approx x\)이다. 증명은 그림 2의 세 도형의 넓이를 비교하는 데서 나온다.

증명.먼저 \(0 < x < \frac\pi2\)인 경우를 보자. 반지름 1인 원에서 중심 \(O\), 점 \(A = (1, 0)\), 각 \(x\)만큼 돌린 점 \(P = (\cos x, \sin x)\)를 잡고, 직선 \(OP\)가 \(A\)에서의 접선 \(x = 1\)과 만나는 점을 \(T = (1, \tan x)\)라 하자. 그림 2에서 삼각형 \(OAP\), 부채꼴 \(OAP\), 삼각형 \(OAT\)가 차례로 포함되므로 넓이를 비교하면

\[\frac12\sin x \;<\; \frac12x \;<\; \frac12\tan x\]

이다. 가운데는 부채꼴의 넓이 \(\frac12r^2\theta\)(\(r = 1\), \(\theta = x\))이고, 양쪽은 밑변 \(OA = 1\)과 높이 \(\sin x\), \(\tan x\)인 삼각형의 넓이이다. 각 변을 \(\frac12\sin x > 0\)으로 나누면 \(1 < \frac{x}{\sin x} < \frac{1}{\cos x}\)이고, 양수끼리 역수를 취하면 부등호가 뒤집혀

\[\cos x < \frac{\sin x}{x} < 1\]

이 된다. \(-\frac\pi2 < x < 0\)이면 \(x\)를 \(-x\)로 바꿔도 \(\frac{\sin x}{x}\)과 \(\cos x\)가 변하지 않으므로 같은 부등식이 성립한다. \(x \to 0\)일 때 \(\cos x \to 1\)이므로, 압축 정리에 의해 \(\frac{\sin x}{x} \to 1\)이다. ∎

증명에서 \(\cos x \to 1\)을 썼는데, 이것도 같은 그림에서 나온다. 호 \(AP\)의 길이는 \(|x|\)이고 현 \(AP\)는 그보다 짧으므로, \(P\)와 \(A\)의 가로 거리 \(1 - \cos x\)와 세로 거리 \(|\sin x|\)는 모두 \(|x|\) 이하이다. 따라서 압축 정리로 \(x \to 0\)일 때 \(\sin x \to 0\), \(\cos x \to 1\)이다.1

예제 2.2.7

(가) \(\lim_{x\to0}\frac{\sin 3x}{x}\) (나) \(\lim_{x\to0}\frac{1 - \cos x}{x^2}\)을 구하여라.

풀이. (가) \(u = 3x\)로 놓으면 \(x \to 0\)일 때 \(u \to 0\)이고 \(\frac{\sin 3x}{x} = 3\cdot\frac{\sin u}{u} \to 3\)이다.

(나) 분자와 분모에 \(1 + \cos x\)를 곱해 \(\sin^2x + \cos^2x = 1\)을 쓴다.

\[\frac{1 - \cos x}{x^2} = \frac{1 - \cos^2x}{x^2(1 + \cos x)} = \left(\frac{\sin x}{x}\right)^2\cdot\frac{1}{1 + \cos x} \to 1^2\cdot\frac12 = \frac12\]

마지막에 곱의 법칙을 썼는데, 각 인수의 극한이 존재하므로 쓸 수 있다. 이 결과는 작은 \(x\)에서 \(\cos x \approx 1 - \frac{x^2}{2}\)라는 뜻이고, 8.8절의 테일러 다항식에서 다시 나온다. 일반물리에서 진자의 주기를 구할 때 쓰는 작은 각 근사가 바로 \(\sin x \approx x\)와 이 식이다.

주의\(\lim_{x\to0}x\sin\frac1x\)을 "\(\lim x\cdot\lim\sin\frac1x = 0\cdot(\text{무엇})= 0\)"으로 계산하면 결과는 맞아도 논리는 틀린다. \(\lim\sin\frac1x\)이 존재하지 않으므로 곱의 법칙을 쓸 수 없다. 올바른 근거는 \(-|x| \le x\sin\frac1x \le |x|\)와 압축 정리이다.
  1. 라디안이라는 조건은 여기서 쓰였다. 각을 도(°)로 재면 부채꼴 넓이가 \(\frac{\pi}{360}r^2\theta\)가 되어 극한이 \(\frac{\pi}{180} \approx 0.01745\)로 바뀐다. 미적분에서 각을 늘 라디안으로 재는 것은 이 극한을 1로 만들기 위해서이다.
마무리

두 극한이 존재하면 그 합·곱·몫의 극한은 극한의 합·곱·몫이고, 그래서 다항함수와 분모가 0이 아닌 유리함수는 대입으로 극한을 구한다. \(\frac00\) 꼴은 \(x \ne a\)에서 약분하거나 유리화해 정리하며, 정리해도 극한이 변하지 않는 까닭은 정의가 \(x = a\)를 빼고 보기 때문이다. 처음의 \(x^2\sin\frac1x\)처럼 출렁이는 함수는 \(\pm x^2\) 사이에 끼워 압축 정리로 0임을 보이고, 같은 방법으로 \(\lim_{x\to0}\frac{\sin x}{x} = 1\)도 얻는다.

2.2.6연습문제

기본

  1. 극한을 구하여라. (가) \(\lim_{x\to-3}\frac{x^2 + x - 6}{x + 3}\) (나) \(\lim_{x\to1}\frac{\sqrt x - 1}{x - 1}\) (다) \(\lim_{x\to0}\frac{\tan x}{x}\)
    답

    (가) \(x - 2 \to -5\) (나) \(\frac{1}{\sqrt x + 1} \to \frac12\) (다) \(\frac{\sin x}{x}\cdot\frac{1}{\cos x} \to 1\)

  2. \(\lim_{x\to0}x^2\cos\frac{1}{x^2}\)을 압축 정리로 구하여라.
    답

    \(-x^2 \le x^2\cos\frac{1}{x^2} \le x^2\)이고 양쪽이 0으로 가므로 0.

  3. \(\lim_{x\to0}\frac{\sin 5x}{\sin 2x}\)을 구하여라.
    답

    \(\frac{\sin 5x}{5x}\cdot\frac{2x}{\sin 2x}\cdot\frac52 \to \frac52\).

응용

  1. \(\lim_{x\to2}f(x) = 3\)이고 \(\lim_{x\to2}\frac{g(x)}{x - 2} = 5\)일 때 \(\lim_{x\to2}g(x)\)와 \(\lim_{x\to2}\frac{f(x)g(x)}{x^2 - 4}\)를 구하여라.
    힌트

    \(g(x) = \frac{g(x)}{x - 2}\cdot(x - 2)\).

    답

    \(\lim g = 5\cdot0 = 0\). \(\frac{fg}{x^2 - 4} = f(x)\cdot\frac{g(x)}{x - 2}\cdot\frac{1}{x + 2} \to 3\cdot5\cdot\frac14 = \frac{15}{4}\).

  2. "\(\lim(f + g)\)가 존재하면 \(\lim f\)와 \(\lim g\)도 존재한다"가 거짓임을 반례로 보여라.
    답

    \(f = \frac1x\), \(g = -\frac1x\) (\(a = 0\)). 합은 0이라 극한이 있지만 각각은 없다.

심화

  1. 곱의 법칙을 증명하여라.
    힌트

    \(fg - LM = (f - L)g + L(g - M)\). \(g\)가 \(a\) 근처에서 유계(예: \(|g| < |M| + 1\))임을 먼저 보여라.

    답

    \(\varepsilon = 1\)에 대한 \(\delta_0\)에서 \(|g(x)| < |M| + 1 =: K\). \(|f - L| < \frac{\varepsilon}{2K}\)인 \(\delta_1\), \(|g - M| < \frac{\varepsilon}{2(|L| + 1)}\)인 \(\delta_2\)를 잡고 \(\delta = \min(\delta_0, \delta_1, \delta_2)\)이면 \(|fg - LM| \le |f - L||g| + |L||g - M| < \frac\varepsilon2 + \frac\varepsilon2\).
