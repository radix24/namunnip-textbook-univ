실수와 함수 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(A = \left\{ \dfrac{(-1)^n}{n} : n \in \mathbb{N} \right\}\)의 상한, 하한, 최댓값, 최솟값을 구하여라. [01-01]

    힌트 1

    원소를 몇 개 나열해 보아라: \(-1, \frac12, -\frac13, \frac14, \dots\)

    힌트 2

    양수 원소 중 가장 큰 것, 음수 원소 중 가장 작은 것은?

    풀이

    \(n\)이 짝수이면 원소는 \(\frac1n \le \frac12\), 홀수이면 \(-\frac1n \ge -1\). 따라서 모든 원소가 \([-1, \frac12]\) 안에 있고, \(\frac12\)(\(n=2\))과 \(-1\)(\(n=1\))은 원소다. 그러므로 최댓값 = 상한 = \(\frac12\), 최솟값 = 하한 = \(-1\).

  2. 증명\(B = \{x \in \mathbb{R} : x^2 < 3\}\)일 때 \(\sup B = \sqrt3\)임을 상한의 ε 판정법으로 보여라. [01-01]

    힌트 1

    먼저 \(\sqrt3\)이 상계임을 보이고, 다음으로 \(\sqrt3 - \varepsilon\)보다 큰 원소를 찾아라.

    힌트 2

    \(\sqrt3 - \frac{\varepsilon}{2}\)는 어떨까? (\(\varepsilon < 2\sqrt3\)인 경우만 보면 충분하다.)

    풀이

    상계: \(x \in B\)이면 \(x^2 < 3\)이므로 \(|x| < \sqrt3\), 특히 \(x < \sqrt3\).

    ε 조건: \(\varepsilon > 0\)이 주어졌다고 하자. \(\varepsilon \ge 2\sqrt3\)이면 \(0 \in B\)이고 \(0 > \sqrt3 - \varepsilon\)이다. \(\varepsilon < 2\sqrt3\)이면 \(a = \sqrt3 - \frac\varepsilon2\)로 두자. \(-\sqrt3 < a < \sqrt3\)이므로 \(a^2 < 3\), 곧 \(a \in B\)이고 \(a > \sqrt3 - \varepsilon\)이다. 판정법에 의해 \(\sup B = \sqrt3\). ∎

  3. 계산\(|3 - 2x| < 7\)과 \(|x + 1| \ge |x - 3|\)을 동시에 만족하는 \(x\)의 범위를 구간으로 써라. [01-01]

    힌트 1

    첫째 식은 거리 꼴로 바꾸고, 둘째 식은 "−1과 3 중 어디에 더 가까운가"로 읽어라.

    힌트 2

    첫째: \(|x - \frac32| < \frac72\). 둘째: 두 점의 가운데 1보다 오른쪽(또는 같음).

    풀이

    첫째 식: \(|3 - 2x| = 2|x - \frac32| < 7 \iff |x - \frac32| < \frac72 \iff -2 < x < 5\).

    둘째 식: −1까지의 거리가 3까지의 거리 이상이면 \(x\)는 3 쪽에 있거나 가운데에 있다. 양변 제곱(둘 다 0 이상이라 동치)으로 확인하면 \((x+1)^2 \ge (x-3)^2 \iff 8x \ge 8 \iff x \ge 1\).

    교집합: \([1, 5)\).

  4. 계산\(f(x) = x^2 - 4x + 1\)이 역함수를 갖도록 정의역을 \([a, \infty)\)로 제한할 때 가능한 가장 작은 \(a\)와, 그때의 \(f^{-1}\)을 구하여라. [01-02]

    힌트 1

    완전제곱식으로 바꾸면 꼭짓점이 보인다.

    힌트 2

    \(f(x) = (x-2)^2 - 3\). 꼭짓점 오른쪽에서 순증가한다. \(y = (x-2)^2 - 3\)을 \(x\)에 대해 풀 때 부호를 골라라.

    풀이

    \(f(x) = (x-2)^2 - 3\)은 \(x \ge 2\)에서 순증가, \(x \le 2\)에서 순감소한다. \([a, \infty)\)에서 일대일이려면 \(a \ge 2\)이어야 하므로 가장 작은 \(a = 2\). 이때 치역은 \([-3, \infty)\).

    \(y = (x-2)^2 - 3\), \(x \ge 2\)에서 \(x - 2 = \sqrt{y + 3}\) (\(x - 2 \ge 0\)이므로 양의 제곱근). 따라서 \(f^{-1}(y) = 2 + \sqrt{y+3}\), 정의역 \([-3, \infty)\).

  5. 계산\(\arctan(\tan 3)\)과 \(\sin(\arccos\frac{3}{5})\)를 구하여라. [01-02]

    힌트 1

    \(\tan\)은 주기 \(\pi\). 3과 같은 탄젠트값을 갖는 \(\left(-\frac\pi2, \frac\pi2\right)\)의 수는?

    힌트 2

    \(\theta = \arccos\frac35\)이면 \(\cos\theta = \frac35\), \(\theta \in [0, \pi]\). 이 구간에서 \(\sin\theta\)의 부호는?

    풀이

    \(\tan 3 = \tan(3 - \pi)\)이고 \(3 - \pi \approx -0.142 \in \left(-\frac\pi2, \frac\pi2\right)\)이므로 \(\arctan(\tan 3) = 3 - \pi\).

    \(\theta = \arccos\frac35 \in [0, \pi]\)에서 \(\sin\theta \ge 0\)이므로 \(\sin\theta = \sqrt{1 - \frac{9}{25}} = \frac45\).

  6. 증명\(\cosh 2x = \cosh^2 x + \sinh^2 x\)를 증명하고, 이를 써서 \(\cosh^2 x = \frac{1 + \cosh 2x}{2}\)를 유도하여라. [01-02]

    힌트 1

    오른쪽을 정의대로 전개하여라.

    힌트 2

    두 번째 식은 \(\sinh^2 x = \cosh^2 x - 1\)을 대입한다.

    풀이

    \(\cosh^2 x + \sinh^2 x = \frac{e^{2x} + 2 + e^{-2x}}{4} + \frac{e^{2x} - 2 + e^{-2x}}{4} = \frac{e^{2x} + e^{-2x}}{2} = \cosh 2x\).

    \(\cosh^2 x - \sinh^2 x = 1\)에서 \(\sinh^2 x = \cosh^2 x - 1\)을 대입하면 \(\cosh 2x = 2\cosh^2 x - 1\), 곧 \(\cosh^2 x = \frac{1 + \cosh 2x}{2}\). 삼각함수의 반각 공식과 모양이 같다.

  7. 개념유리수만 모은 집합 \(\{x \in \mathbb Q : x^2 < 2\}\)는 유리수 안에서 상한을 갖지 않는다. 이것이 실수에 완비성 공리가 필요한 이유와 어떻게 이어지는지 설명하여라. [01-01]

    힌트 1

    01-01 절: 상한의 정의를 다시 읽어라.

    힌트 2

    실수 안에서는 상한이 \(\sqrt2\)이다. 그런데 \(\sqrt2\)는 유리수가 아니다.

    풀이

    유리수 안에서 이 집합은 위로 유계(예: 2)이지만, 가장 작은 유리수 상계는 없다. 어떤 유리수 상계 \(q\)를 잡아도 \(q > \sqrt2\)이고, 그 사이에 더 작은 유리수 상계가 있기 때문이다. 유리수에는 \(\sqrt2\) 자리에 구멍이 있는 셈이다. 완비성 공리는 "위로 유계인 집합은 상한을 갖는다"고 약속해 이런 구멍이 없게 한다. 극한, 연속, 중간값 정리가 모두 이 공리에 기대고 있다.

  8. 판단한 학생이 \(\arcsin\left(\sin\frac{5\pi}{6}\right) = \frac{5\pi}{6}\)이라고 썼다. 맞나요? [01-02]

    힌트 1

    01-02 절: \(\arcsin\)의 치역은?

    힌트 2

    \(\sin\frac{5\pi}{6} = \frac12\).

    풀이

    틀렸다. \(\arcsin\)의 값은 \(\left[-\frac\pi2, \frac\pi2\right]\) 안에 있어야 하는데 \(\frac{5\pi}{6}\)은 그 밖이다. \(\sin\frac{5\pi}6 = \frac12\)이므로 답은 \(\arcsin\frac12 = \frac\pi6\)이다. \(\arcsin(\sin x) = x\)는 \(x\)가 치역 안에 있을 때만 성립한다.
