극좌표에서의 넓이와 길이

본문

심장형 \(r = 1 + \cos\theta\)로 둘러싸인 넓이는 얼마일까? 세로 띠로 자르면 위아래 경계가 복잡해지는데, 원점에서 뻗어 나가는 조각으로 자르면 더 간단해지지 않을까?

먼저 알아야 할 것극좌표와 극곡선(7.3절), 고교 수학I의 부채꼴의 넓이 \(\frac12r^2\theta\), 그리고 반각 공식(5.2절)을 쓴다.

7.4.1부채꼴로 나누기

직교좌표에서는 넓이를 세로 띠, 곧 직사각형으로 나누었다. 그런데 극좌표에서는 원점에서 뻗어 나가는 가는 부채꼴로 나누는 것이 자연스럽다. 극곡선은 각마다 원점에서의 거리를 알려 주므로, 부채꼴의 반지름을 바로 읽을 수 있기 때문이다. 중심각 \(d\theta\), 반지름 \(r = f(\theta)\)인 부채꼴의 넓이는 \(\frac12r^2d\theta\)이므로 다음을 얻는다.

정리 7.4.1

\(r = f(\theta)\), \(a \le \theta \le b\)로 둘러싸인 부채꼴 모양 영역의 넓이는 \(\displaystyle A = \int_a^b\frac12[f(\theta)]^2d\theta\)이다.

4.1절의 리만 합과 같은 생각이다. 직사각형 대신 부채꼴을, 폭 \(dx\) 대신 중심각 \(d\theta\)를 썼을 뿐이다. 그림 1에서 \(n = 12\)이면 부채꼴 사이로 곡선이 들쭉날쭉 삐져나오지만, \(n\)을 80까지 늘리면 부채꼴들이 곡선 안을 거의 빈틈없이 채운다.

예제 7.4.2

심장형 \(r = 1 + \cos\theta\)로 둘러싸인 넓이를 구하여라.

풀이. \(\theta\)가 0부터 \(2\pi\)까지 돌면 곡선을 한 바퀴 그린다. 따라서

\[A = \frac12\int_0^{2\pi}(1 + 2\cos\theta + \cos^2\theta)\,d\theta = \frac12\left(2\pi + 0 + \pi\right) = \frac{3\pi}{2}\]

이다. 여기서 \(\int_0^{2\pi}\cos^2\theta\,d\theta = \pi\)는 5.2절의 반각 공식으로 구했다. 처음 질문의 답은 약 4.712이고, 지름 2인 원의 넓이 \(\pi\)의 1.5배이다.

예제 7.4.3

장미 곡선 \(r = \cos2\theta\)의 잎 하나의 넓이를 구하여라.

풀이. 오른쪽 잎은 \(r \ge 0\)인 \(-\frac\pi4 \le \theta \le \frac\pi4\)에서 그려진다. 따라서 \(A = \frac12\int_{-\pi/4}^{\pi/4}\cos^22\theta\,d\theta = \frac12\cdot\frac\pi4 = \frac\pi8\)이다. 잎이 네 개이므로 전체 넓이는 \(\frac\pi2\)이고, 이는 장미 곡선을 품는 단위원 넓이의 절반이다.

두 곡선 사이의 넓이는 바깥 곡선의 넓이에서 안쪽 곡선의 넓이를 빼서 \(\frac12\int(r_{\text{바깥}}^2 - r_{\text{안}}^2)\,d\theta\)로 구한다. 그때 두 곡선이 만나는 각을 먼저 구해 적분 구간으로 쓴다.

7.4.2길이

길이는 \(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)에 7.2절의 길이 공식을 쓰면 된다. 곱의 미분법으로 \(x'\)과 \(y'\)을 구해 제곱해 더하면 교차항이 지워지고 \(x'^2 + y'^2 = r^2 + \left(\frac{dr}{d\theta}\right)^2\)만 남는다.

정리 7.4.4 \[L = \int_a^b\sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta.\]

식의 두 항은 각각 원을 따라 도는 움직임과 원점에서 멀어지는 움직임의 빠르기이다. \(r\)이 일정하면 둘째 항이 0이 되어 \(L = r(b - a)\), 곧 호의 길이가 된다.

예제 7.4.5

심장형 \(r = 1 + \cos\theta\)의 길이를 구하여라.

풀이. \(r^2 + r'^2 = (1 + \cos\theta)^2 + \sin^2\theta = 2 + 2\cos\theta = 4\cos^2\frac\theta2\)이다. 곡선이 \(x\)축에 대해 대칭이므로 위쪽 절반(\(0 \le \theta \le \pi\), \(\cos\frac\theta2 \ge 0\))의 두 배를 구하면 \(L = 2\int_0^\pi2\cos\frac\theta2\,d\theta = 2\left[4\sin\frac\theta2\right]_0^\pi = 8\)이다.

주의적분 구간을 정할 때 곡선이 겹쳐 그려지지 않는지 확인한다. \(r = \cos2\theta\)를 \(0\)부터 \(2\pi\)까지 적분하면 잎 네 개를 모두 센다. 또 \(r\)이 음수가 되는 구간에서는 점이 반대쪽에 찍힌다.
마무리

극곡선으로 둘러싸인 넓이는 원점에서 뻗는 가는 부채꼴의 넓이 \(\frac12r^2d\theta\)를 더한 \(\int\frac12r^2d\theta\)이고, 그래서 처음 질문의 심장형 넓이는 \(\frac{3\pi}{2}\)이다. 길이는 \(\int\sqrt{r^2 + r'^2}\,d\theta\)로 구하며 심장형의 길이는 8이다. 두 경우 모두 곡선을 한 번만 그리는 \(\theta\)의 범위로 적분한다.

7.4.3연습문제

기본

  1. 원 \(r = 2\sin\theta\)로 둘러싸인 넓이를 공식으로 구하여라.
    답

    \(0 \le \theta \le \pi\): \(\frac12\int_0^\pi4\sin^2\theta\,d\theta = \pi\). (반지름 1인 원)

응용

  1. \(r = 3\cos\theta\)의 안쪽, \(r = 1 + \cos\theta\)의 바깥쪽 영역의 넓이를 구하여라.
    답

    교점 \(3\cos\theta = 1 + \cos\theta\), \(\theta = \pm\frac\pi3\). \(A = 2\cdot\frac12\int_0^{\pi/3}(9\cos^2\theta - (1 + \cos\theta)^2)d\theta = \int_0^{\pi/3}(8\cos^2\theta - 2\cos\theta - 1)d\theta = \pi\).
