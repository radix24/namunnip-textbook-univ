유리함수는 부분분수로 쪼개서 적분한다

일차·반복·이차 인수

절차

  1. 진분수로: 분자의 차수 ≥ 분모의 차수이면 먼저 다항식 나눗셈을 한다.
  2. 분모 인수분해: 실수 범위에서 일차식과 (판별식 < 0인) 이차식의 곱으로. 이것은 대수학의 기본정리로 늘 가능하다.
  3. 꼴 정하기:
    • \((x - a)\) → \(\frac{A}{x - a}\)
    • \((x - a)^k\) → \(\frac{A_1}{x - a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_k}{(x-a)^k}\)
    • \((x^2 + bx + c)\) → \(\frac{Bx + C}{x^2 + bx + c}\)
  4. 계수 구하기: 양변에 분모를 곱한 항등식에 편한 \(x\)를 넣거나 계수를 비교한다.
  5. 항별 적분: \(\int\frac{dx}{x - a} = \ln|x - a|\), \(\int\frac{dx}{(x-a)^k} = \frac{(x-a)^{1-k}}{1-k}\), 이차는 완전제곱 후 \(\ln\)과 \(\arctan\).

\(\displaystyle\int\frac{2x^2 + 3}{x(x - 1)^2}\,dx\)와 \(\displaystyle\int\frac{x + 3}{x^2 + 2x + 5}\,dx\)를 구하여라.

풀이

  1. 첫째: 분자 차수 2 < 분모 차수 3이므로 진분수. \(\dfrac{2x^2 + 3}{x(x-1)^2} = \dfrac{A}{x} + \dfrac{B}{x - 1} + \dfrac{C}{(x-1)^2}\).
    반복 인수 \((x-1)^2\)에는 두 항이 필요하다.
  2. 양변에 \(x(x-1)^2\)을 곱하면 \(2x^2 + 3 = A(x-1)^2 + Bx(x-1) + Cx\).
    모든 \(x\)에서 성립하는 항등식(\(x = 0, 1\)에서도 연속성으로 성립).
  3. \(x = 0\): \(3 = A\). \(x = 1\): \(5 = C\). \(x^2\)의 계수: \(2 = A + B\), 곧 \(B = -1\).
    근을 넣으면 항이 사라진다. 남은 하나는 최고차 계수 비교.
  4. \(\int\left(\frac3x - \frac{1}{x-1} + \frac{5}{(x-1)^2}\right)dx = 3\ln|x| - \ln|x - 1| - \dfrac{5}{x - 1} + C\).
    항별 적분.
  5. 둘째: \(x^2 + 2x + 5\)는 판별식 \(4 - 20 < 0\)이라 인수분해되지 않는다. 분자를 "분모의 도함수 + 나머지"로 나눈다: \(x + 3 = \frac12(2x + 2) + 2\).
    \((x^2 + 2x + 5)' = 2x + 2\). 앞부분은 \(\ln\), 뒷부분은 \(\arctan\)이 된다.
  6. \(\frac12\int\frac{2x+2}{x^2+2x+5}dx + 2\int\frac{dx}{(x+1)^2 + 4} = \frac12\ln(x^2 + 2x + 5) + \arctan\dfrac{x + 1}{2} + C\).
    완전제곱 후 \(\int\frac{du}{u^2 + a^2} = \frac1a\arctan\frac ua\) (\(a = 2\)). 분모가 늘 양수라 절댓값 불필요.

의미

모든 유리함수는 부분분수로 쪼개면 다항식, \(\ln\), \(\arctan\)의 합으로 적분된다. 유리함수의 적분은 언제나 끝까지 계산할 수 있다는 뜻이다. 미분방정식과 회로 이론에서 라플라스 변환을 되돌릴 때 같은 분해를 쓴다.

검산

분해를 통분해 되돌려 본다. \(x = 2\)에서 왼쪽 \(\frac{11}{2}\), 오른쪽 \(\frac32 - 1 + 5 = \frac{11}{2}\). 3단계에서 쓰지 않은 점에서 맞으면 계수가 맞을 가능성이 크다.

흔한 오해

  • 반복 인수에서 낮은 차수 항 빠뜨리기: \(\frac{C}{(x-1)^2}\)만 쓰면 계수가 맞지 않다.
  • 이차 인수의 분자를 상수로: \(\frac{B}{x^2+1}\)이 아니라 \(\frac{Bx + C}{x^2+1}\).
  • 가분수인데 바로 분해: \(\frac{x^3}{x^2 - 1}\)은 먼저 \(x + \frac{x}{x^2 - 1}\)로 나눈다.
