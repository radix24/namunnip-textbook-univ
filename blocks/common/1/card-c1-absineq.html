절댓값 부등식은 '거리'로 읽는다

절댓값 · 구간 · 삼각부등식

먼저 읽는 법

\(|x - a|\)는 수직선에서 \(x\)와 \(a\) 사이의 거리입니다. 그래서

\[|x - a| < r \iff a - r < x < a + r, \qquad |x - a| > r \iff x < a - r \text{ 또는 } x > a + r.\]

앞의 것은 "\(a\)에서 \(r\)보다 가까운 점", 뒤의 것은 "\(r\)보다 먼 점"입니다. ε-δ 정의의 \(|x - a| < \delta\)가 바로 이 꼴입니다.

문제 1. \(|2x + 1| \ge 5\)를 풀어 구간으로 나타내세요.

풀이

  1. \(|2x+1| = 2\left|x + \frac12\right|\)이므로 부등식은 \(\left|x - \left(-\frac12\right)\right| \ge \frac52\)이다.
    \(|cu| = |c||u|\). 계수를 빼내야 '거리' 꼴이 된다.
  2. \(-\frac12\)에서 \(\frac52\) 이상 떨어진 점이므로 \(x \le -\frac12 - \frac52 = -3\) 또는 \(x \ge -\frac12 + \frac52 = 2\).
    \(|x-a| \ge r \iff x \le a - r\) 또는 \(x \ge a + r\).
  3. 답: \((-\infty, -3] \cup [2, \infty)\).
    등호가 있으므로 끝점 포함(닫힌 괄호).

문제 2. \(|x - 1| + |x + 2| < 5\)를 푸세요.

전략

절댓값이 두 개면 '거리의 합'으로 읽을 수도 있지만(1과 −2까지의 거리 합이 5보다 작은 점), 확실한 방법은 절댓값 안이 0이 되는 점에서 나누어 각 구간에서 절댓값을 벗기는 것입니다. 경계점은 \(x = -2\)와 \(x = 1\)입니다.

풀이

  1. \(x < -2\)이면 \(x - 1 < 0\), \(x + 2 < 0\)이므로 식은 \(-(x-1) - (x+2) = -2x - 1 < 5\), 곧 \(x > -3\). 이 구간과 겹치는 부분은 \(-3 < x < -2\).
    \(u < 0\)이면 \(|u| = -u\). 구한 해를 그 구간과 반드시 겹쳐 본다.
  2. \(-2 \le x < 1\)이면 \(-(x-1) + (x+2) = 3 < 5\)로 늘 참이다. 이 구간 전체가 해.
    \(x - 1 < 0\), \(x + 2 \ge 0\). 두 점 사이에서는 거리의 합이 두 점 사이 거리 3으로 일정하다.
  3. \(x \ge 1\)이면 \((x - 1) + (x + 2) = 2x + 1 < 5\), 곧 \(x < 2\). 겹치는 부분은 \(1 \le x < 2\).
    두 절댓값 안이 모두 0 이상.
  4. 세 경우를 합치면 \(-3 < x < 2\), 곧 \((-3, 2)\).
    경우 나누기의 해는 합집합.

검산

끝점 \(x = 2\): \(|1| + |4| = 5\), 부등식 \(< 5\)가 아니므로 제외. 맞습니다. 안쪽 점 \(x = 0\): \(1 + 2 = 3 < 5\). 바깥 점 \(x = 3\): \(2 + 5 = 7\). 해의 경계와 일치합니다.

삼각부등식

정리

모든 실수 \(u, v\)에 대해 \(|u + v| \le |u| + |v|\). 따라서 \(|u - w| \le |u - v| + |v - w|\).

  1. \(-|u| \le u \le |u|\), \(-|v| \le v \le |v|\).
    절댓값의 정의(경우 \(u \ge 0\), \(u < 0\)을 나눠 확인).
  2. 더하면 \(-(|u| + |v|) \le u + v \le |u| + |v|\).
    부등식끼리 더하기.
  3. \(|y| \le c \iff -c \le y \le c\)이므로 \(|u+v| \le |u| + |v|\). 두 번째 식은 \(u \to u - v\), \(v \to v - w\)로 바꿔 넣은 것.
    절댓값 부등식의 '거리' 읽기.

두 번째 식은 "\(u\)에서 \(w\)로 곧장 가는 거리는 \(v\)를 거쳐 가는 거리보다 길지 않다"입니다. 극한 증명에서 \(|f(x) - L|\)을 쪼갤 때 매번 씁니다.

바꿔 보기

  • 문제 2에서 5를 3으로 바꾸면? 2단계의 "3 < 3"이 거짓이 되고 다른 경우도 해가 없어 해가 없습니다. 두 점까지 거리의 합은 3보다 작을 수 없기 때문입니다.
  • \(|x - 1| < |x + 2|\)는? 1보다 −2에서 더 먼 점, 곧 두 점의 가운데 \(-\frac12\)보다 오른쪽: \(x > -\frac12\).
