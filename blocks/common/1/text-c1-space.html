3차원 좌표계

본문
이 절에서 배울 것
  • 공간의 점을 \((x, y, z)\)로 나타내고 두 점 사이의 거리를 구한다.
  • 구의 방정식과 간단한 평면의 방정식을 읽는다.
먼저 알아야 할 것
  • 좌표평면, 두 점 사이의 거리, 원의 방정식 (고교 수학). 고교 기하의 공간좌표를 듣지 않았어도 처음부터 읽을 수 있습니다.

9.1.1세 개의 축

방 한구석을 원점으로 잡으면 바닥의 두 모서리와 세로 모서리가 서로 수직인 세 직선이 됩니다. 이를 \(x\)축, \(y\)축, \(z\)축으로 삼으면 방 안의 모든 점을 세 수 \((x, y, z)\)로 나타낼 수 있습니다. 축의 방향은 오른손 법칙으로 정합니다. 오른손 손가락을 \(x\)축에서 \(y\)축 쪽으로 감아쥐면 엄지가 \(z\)축의 양의 방향입니다.

두 축이 만드는 평면을 좌표평면이라 합니다. \(xy\)평면은 \(z = 0\), \(yz\)평면은 \(x = 0\), \(xz\)평면은 \(y = 0\)인 점들입니다. 공간에서는 방정식 하나가 보통 곡면을 나타냅니다. 예를 들어 \(z = 3\)은 \(xy\)평면과 나란하고 높이가 3인 평면이고, 평면에서 직선을 나타내던 \(y = 5\)는 공간에서는 평면입니다.

9.1.2거리와 구

정리 9.1.1 (두 점 사이의 거리) \[|P_1P_2| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}.\]

피타고라스 정리를 두 번 쓴 것입니다. 바닥에서의 대각선 길이 \(\sqrt{\Delta x^2 + \Delta y^2}\)과 높이 차 \(\Delta z\)가 다시 직각삼각형을 이룹니다.

중심 \((h, k, l)\)에서 거리가 \(r\)인 점들의 모임이 구이므로, 구의 방정식은

\[(x - h)^2 + (y - k)^2 + (z - l)^2 = r^2.\]
예제 9.1.2

\(x^2 + y^2 + z^2 + 4x - 6y + 2z + 6 = 0\)이 구임을 보이고 중심과 반지름을 구하여라.

풀이. 완전제곱식을 만듭니다: \((x + 2)^2 + (y - 3)^2 + (z + 1)^2 = -6 + 4 + 9 + 1 = 8\). 중심 \((-2, 3, -1)\), 반지름 \(2\sqrt2\).

요약
  1. 공간의 점은 \((x, y, z)\). \(x = 0\) 같은 방정식 하나는 평면을 나타낸다.
  2. 거리 \(\sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}\), 구 \((x - h)^2 + (y - k)^2 + (z - l)^2 = r^2\).

9.1.3연습문제

기본

  1. 점 \((1, 2, 3)\)과 \((4, 6, 3)\) 사이의 거리는?
    답

    \(\sqrt{9 + 16 + 0} = 5\).

  2. \(x^2 + y^2 + z^2 = 2z\)는 어떤 도형인가?
    답

    \(x^2 + y^2 + (z - 1)^2 = 1\), 중심 \((0, 0, 1)\), 반지름 1인 구.
