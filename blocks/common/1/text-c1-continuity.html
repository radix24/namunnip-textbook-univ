연속

본문

택시 요금은 거리에 따라 계단처럼 뛰어오르고, 물의 온도는 가열 시간에 따라 매끄럽게 오른다. 두 그래프의 차이를 "끊어졌다"는 그림 말고 식으로 말하려면 무엇을 확인해야 할까?

먼저 알아야 할 것극한 법칙과 한쪽 극한(1.3절), 그리고 고교 수학II에서 배운 연속의 직관적 뜻 "그래프가 끊어지지 않는다"를 쓴다.

2.3.1끊어지지 않는다는 것

택시 요금은 어느 순간 값이 갑자기 바뀌고, 물의 온도는 입력을 조금 바꾸면 출력도 조금만 바뀐다. 수학에서 연속은 이 두 번째 성질, 곧 입력의 작은 변화가 출력의 작은 변화만 만든다는 것을 뜻한다. 고교에서 배운 "그래프가 끊어지지 않는다"는 이것을 그림으로 본 것이다. 그러면 이 성질을 1.3절의 극한으로 어떻게 적을 수 있을까?

2.3.2한 점에서의 연속

정의 2.3.1 (연속)

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있고

\[\lim_{x\to a}f(x) = f(a)\]

이면 \(f\)는 \(a\)에서 연속이라 한다. 연속이 아니면 \(a\)를 \(f\)의 불연속점이라 한다.

이 한 줄의 등식 안에는 세 가지 조건이 들어 있고, 하나라도 어기면 불연속이다. 먼저 \(f(a)\)가 정의되어 있어야 한다. 다음으로 \(\lim_{x\to a}f(x)\)가 존재해야 하는데, 이는 두 한쪽 극한이 존재하고 같다는 뜻이다. 마지막으로 둘이 같아야 한다. 그림 1의 다섯 보기는 이 세 조건이 하나씩 깨지는 모습을 보여 준다.

ε-δ로 쓰면 "임의의 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어서 \(|x - a| < \delta \Rightarrow |f(x) - f(a)| < \varepsilon\)"이다. 극한의 정의와 비교하면 \(L\) 자리에 \(f(a)\)가 들어가고, \(x = a\)를 뺄 필요가 없어졌다. \(x = a\)이면 차이가 0이기 때문이다. 다시 말해 이 식은 "입력을 \(\delta\) 이내로 바꾸면 출력이 \(\varepsilon\) 이내로만 바뀐다"를 그대로 옮긴 것이다.

구간의 끝점에서는 한쪽 극한을 쓴다. \(\lim_{x\to a^+}f(x) = f(a)\)이면 오른쪽 연속, \(\lim_{x\to a^-}f(x) = f(a)\)이면 왼쪽 연속이라 한다. 그래서 \(f\)가 열린구간 \((a, b)\)의 모든 점에서 연속이면 "\((a, b)\)에서 연속"이라 하고, 여기에 더해 \(a\)에서 오른쪽 연속이고 \(b\)에서 왼쪽 연속이면 "\([a, b]\)에서 연속"이라 한다.

2.3.3불연속의 종류

세 조건 가운데 어느 것이 어떻게 깨지는지에 따라 불연속점을 나눈다.

정의 2.3.2 (제거 가능 불연속)

\(\lim_{x\to a}f(x)\)가 존재하지만 \(f(a)\)와 다르거나 \(f(a)\)가 정의되지 않은 경우.

정의 2.3.3 (도약 불연속)

두 한쪽 극한이 모두 유한한 값으로 존재하지만 서로 다른 경우.

정의 2.3.4 (무한 불연속, 진동 불연속)

한쪽 극한 가운데 적어도 하나가 \(\pm\infty\)로 발산하면 무한 불연속, 진동하여 존재하지 않으면 진동 불연속이라 한다. 둘을 묶어 본질적 불연속이라고도 한다.

이름이 뜻을 말해 준다. 제거 가능 불연속은 한 점의 값만 고쳐, 곧 \(f(a)\)를 극한값으로 다시 정의해 연속으로 만들 수 있다. 그림 1의 제거 가능 보기에서 빈 동그라미 자리에 점을 옮겨 놓으면 그래프가 이어진다. 반면 도약 불연속은 어떻게 고쳐도 그래프가 이어지지 않고, 본질적 불연속은 그래프가 위아래로 달아나거나 끝없이 흔들린다.

예제 2.3.5

다음 함수의 불연속점을 찾고 종류를 말하여라. (가) \(f(x) = \frac{x^2 - 1}{x - 1}\) (나) \(g(x) = \frac{|x|}{x}\) (다) \(h(x) = \frac{1}{(x - 2)^2}\) (라) \(k(x) = \sin\frac1x\) (\(x \ne 0\)), \(k(0) = 0\)

풀이. (가) \(x = 1\)에서 정의되지 않는다. \(x \ne 1\)이면 \(f(x) = x + 1\)이므로 \(\lim_{x\to1}f(x) = 2\)가 존재한다. 따라서 제거 가능 불연속이고, \(f(1) = 2\)로 정의하면 연속인 함수 \(x + 1\)이 된다.

(나) \(x > 0\)이면 1, \(x < 0\)이면 \(-1\)이므로 \(x = 0\)에서 오른쪽 극한은 1, 왼쪽 극한은 \(-1\)이다. 즉 도약 불연속이고 도약의 크기는 2이다.

(다) \(x \to 2\)일 때 분모가 양수이면서 0으로 가므로 \(h(x) \to +\infty\)이다. 따라서 무한 불연속이며, 3.3절에서는 이런 직선 \(x = 2\)를 수직 점근선이라 부른다.

(라) \(x \to 0\)일 때 \(\frac1x\)이 한없이 커지면서 \(\sin\frac1x\)은 \(-1\)과 1 사이를 끝없이 오간다. 가령 \(x_n = \frac{1}{2n\pi}\)에서는 값이 0이고 \(x_n = \frac{1}{2n\pi + \pi/2}\)에서는 1인데, 두 수열 모두 0으로 간다. 0에 아무리 가까워도 값 0과 1을 모두 가지므로 극한이 없고, 진동 불연속이다.

2.3.4연속함수를 모으기

어떤 함수가 연속인지 매번 정의로 확인할 필요는 없다. 극한 법칙(1.3절)을 \(L = f(a)\), \(M = g(a)\)로 놓고 읽으면 바로 다음이 나온다.

정리 2.3.6

\(f, g\)가 \(a\)에서 연속이면 \(f + g\), \(cf\), \(fg\)도 \(a\)에서 연속이고, \(g(a) \ne 0\)이면 \(\frac fg\)도 \(a\)에서 연속이다.

정리 2.3.7 (합성함수의 연속)

\(g\)가 \(a\)에서 연속이고 \(f\)가 \(g(a)\)에서 연속이면 \(f \circ g\)는 \(a\)에서 연속이다. 곧 \(\lim_{x\to a}f(g(x)) = f\left(\lim_{x\to a}g(x)\right)\).

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(f\)가 \(b = g(a)\)에서 연속이므로 \(|y - b| < \eta\)이면 \(|f(y) - f(b)| < \varepsilon\)인 \(\eta > 0\)이 있다. 이 \(\eta\)를 허용 오차로 삼아 \(g\)의 연속을 쓰면 \(|x - a| < \delta\)이면 \(|g(x) - b| < \eta\)인 \(\delta > 0\)이 있다. 그러면 \(|x - a| < \delta\)일 때 \(y = g(x)\)가 \(|y - b| < \eta\)를 만족하므로 \(|f(g(x)) - f(g(a))| < \varepsilon\)이다. ∎

증명은 바깥 함수 \(f\)의 요구 \(\varepsilon\)을 먼저 처리해 \(\eta\)를 얻고, 그것을 안쪽 함수 \(g\)에 대한 요구로 넘긴다. 즉 바깥에서 안으로 거슬러 오는 순서이다. 이 정리들과 다음의 기본 함수들을 합치면, 식으로 쓴 함수 대부분이 정의된 곳에서 연속임을 알 수 있다.

정리 2.3.8 (기본 연속함수)

다항함수, 유리함수, \(\sqrt[n]{x}\), \(\sin x\), \(\cos x\), \(\tan x\), \(a^x\), \(\log_a x\), 역삼각함수, 쌍곡선 함수는 정의역의 모든 점에서 연속이다.

다항함수와 유리함수는 1.3절의 대입 법칙에서 이미 보았다. \(\sin\)과 \(\cos\)은 1.3절에서 0에서의 연속을 보였고, 덧셈정리 \(\sin(a + h) = \sin a\cos h + \cos a\sin h\)에서 \(h \to 0\)으로 보내면 모든 점에서 연속이다. 지수함수의 연속은 \(a^{x+h} = a^xa^h\)에서 \(\lim_{h\to0}a^h = 1\)로 귀결되는데, 이 사실은 받아들이고 8.8절에서 급수로 다시 확인한다. 역함수의 연속은 "연속인 일대일 함수의 역함수는 연속"이라는 정리에서 나온다.1

예제 2.3.9

\(F(x) = \frac{\ln(1 + x^2)}{\cos x - 2}\)가 실수 전체에서 연속임을 보이고 \(\lim_{x\to0}F(x)\)를 구하여라.

풀이. \(1 + x^2\)은 다항함수라 연속이고 늘 양수이므로 \(\ln\)의 정의역 안에 있다. 따라서 합성 \(\ln(1 + x^2)\)이 연속이다(정리 2.3.7). 분모 \(\cos x - 2\)도 연속이고, \(\cos x \le 1\)이므로 늘 \(-1\) 이하라서 0이 되지 않는다. 그러면 몫이므로 정리 2.3.6에 의해 \(F\)는 모든 점에서 연속이다. 연속이므로 극한은 대입으로 구하면 되고, \(F(0) = \frac{\ln 1}{1 - 2} = 0\)이다.

주의"정의역에서 연속"과 "실수 전체에서 연속"은 다르다. \(\frac1x\)은 정의역 \(x \ne 0\)의 모든 점에서 연속인 연속함수이지만, \(x = 0\)에서는 정의되지 않으므로 연속도 불연속도 논하지 않는 것이 엄밀한 표현이다. 다만 많은 교재가 이런 점도 불연속점이라 부르므로, 문제가 무엇을 묻는지 보고 판단한다.
  1. 이 정리의 증명은 3학년 해석학에서 다룬다. 증명에는 중간값 정리(1.4절 보충)가 쓰인다.
마무리

함수가 \(a\)에서 연속이라는 것은 \(\lim_{x\to a}f(x) = f(a)\), 곧 값이 정의되고, 극한이 존재하고, 둘이 같다는 세 조건을 모두 만족한다는 뜻이다. 처음 질문의 택시 요금은 둘째 조건이 깨진 도약 불연속이고, 물의 온도는 세 조건을 모두 만족한다. 연속함수의 합·곱·몫·합성은 다시 연속이므로, 식으로 쓴 함수 대부분은 정의된 곳에서 연속이고 극한을 대입으로 구할 수 있다.

2.3.5연습문제

기본

  1. 불연속점과 종류를 말하여라. (가) \(\frac{x^2 - 9}{x + 3}\) (나) \(\frac{x}{x^2 - 4}\) (다) \(\lfloor x\rfloor\) (\(x\)를 넘지 않는 최대 정수)
    답

    (가) \(x = -3\) 제거 가능(극한 \(-6\)) (나) \(x = \pm2\) 무한 불연속 (다) 모든 정수에서 도약 불연속(도약 크기 1)

  2. \(f(x) = x^2\) (\(x < 1\)), \(f(x) = ax + 3\) (\(x \ge 1\))이 연속이 되도록 \(a\)를 정하여라.
    답

    왼쪽 극한 1, \(f(1) = a + 3\). \(a = -2\).

  3. \(\lim_{x\to\pi}\sin(x + \sin x)\)를 구하여라.
    답

    합성함수가 연속이므로 대입: \(\sin(\pi + 0) = 0\).

응용

  1. \(f(x) = \frac{\sin x}{x}\) (\(x \ne 0\))을 실수 전체에서 연속인 함수로 만들려면 \(f(0)\)을 얼마로 정해야 하는가? 이유를 정리 번호와 함께 말하여라.
    답

    정리 2.2.6에서 극한이 1이므로 \(f(0) = 1\). 그러면 0에서 정의 2.3.1을 만족하고, \(x \ne 0\)에서는 연속함수의 몫(정리 2.3.6)이라 연속이다.

  2. \(f\)가 \(a\)에서 연속이고 \(f(a) > 0\)이면 \(a\)를 포함하는 어떤 구간에서 \(f(x) > 0\)임을 보여라.
    힌트

    정의에서 \(\varepsilon = \frac{f(a)}{2}\)로 잡으세요.

    답

    \(\varepsilon = \frac{f(a)}2\)에 대한 \(\delta\)를 잡으면 \(|x - a| < \delta\)에서 \(f(x) > f(a) - \frac{f(a)}{2} = \frac{f(a)}2 > 0\).

심화

  1. 유리수에서 1, 무리수에서 0인 함수(Dirichlet 함수)는 모든 점에서 불연속임을 보여라. 한편 \(x \cdot (\text{이 함수})\)는 0에서만 연속임을 보여라.
    힌트

    어떤 구간에도 유리수와 무리수가 모두 있다는 사실을 쓰세요. 둘째는 \(|x\cdot D(x)| \le |x|\).

    답

    \(\varepsilon = \frac12\)이면 어떤 \(\delta\)에도 \((a - \delta, a + \delta)\)에 값이 0인 점과 1인 점이 모두 있어 둘 중 하나는 \(f(a)\)와 \(\frac12\) 이상 차이 난다. 둘째 함수는 \(|xD(x)| \le |x| \to 0\)이라 0에서 연속. \(a \ne 0\)이면 근처에 값이 0인 점과 \(\approx a\)인 점이 모두 있어 불연속.
