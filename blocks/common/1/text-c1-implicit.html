음함수 미분법

본문
이 절에서 배울 것
  • \(y\)를 \(x\)에 대해 풀지 않고 \(\dfrac{dy}{dx}\)를 구한다.
  • 원, 타원 같은 곡선 위의 점에서 접선을 구한다.
먼저 알아야 할 것
  • 연쇄법칙 (2.2절).
  • 곱의 미분법 \((uv)' = u'v + uv'\) (2.1절, 고교 수학II).

2.3.1식을 풀 수 없는 곡선

지금까지 다룬 함수는 \(y = x^2 + 1\)처럼 \(y\)가 \(x\)의 식으로 바로 주어졌습니다. 그런데 원 \(x^2 + y^2 = 25\)은 \(y = \pm\sqrt{25 - x^2}\)로 풀면 위쪽 반원과 아래쪽 반원 두 함수로 나뉘고, \(x^3 + y^3 = 6xy\) 같은 곡선은 \(y\)에 대해 풀기조차 어렵습니다. 이렇게 \(x\)와 \(y\)의 관계식으로 정해지는 함수를 음함수라고 합니다.

음함수 미분법의 생각은 간단합니다. \(y\)를 "\(x\)의 함수인데 식을 모르는 것"으로 보고, 관계식의 양변을 \(x\)로 미분합니다. \(y\)가 들어간 항을 미분할 때는 \(y\)가 속함수이므로 연쇄법칙에 따라 \(\dfrac{dy}{dx}\)를 곱합니다. 예를 들어

\[\frac{d}{dx}(y^2) = 2y\frac{dy}{dx}, \qquad \frac{d}{dx}(\sin y) = \cos y\,\frac{dy}{dx}.\]

2.3.2방법

  1. 관계식의 양변을 \(x\)로 미분한다. \(y\)가 든 항에는 \(\dfrac{dy}{dx}\)를 곱한다.
  2. \(\dfrac{dy}{dx}\)가 든 항을 한쪽으로 모은다.
  3. \(\dfrac{dy}{dx}\)에 대해 푼다.
예제 2.3.1

원 \(x^2 + y^2 = 25\) 위의 점 \((3, 4)\)에서 접선의 방정식을 구하여라.

풀이. 양변을 \(x\)로 미분하면 \(2x + 2y\dfrac{dy}{dx} = 0\), 따라서 \(\dfrac{dy}{dx} = -\dfrac xy\)입니다. 점 \((3, 4)\)에서 기울기는 \(-\dfrac34\)이고, 접선은 \(y - 4 = -\dfrac34(x - 3)\), 곧 \(3x + 4y = 25\)입니다.

검산: 원의 접선은 반지름에 수직입니다. 반지름 방향 \((3, 4)\)의 기울기는 \(\dfrac43\)이고 \(\dfrac43\cdot\left(-\dfrac34\right) = -1\)이므로 수직이 맞습니다. 또 \(y = \sqrt{25 - x^2}\)을 직접 미분해도 \(\dfrac{-x}{\sqrt{25 - x^2}} = -\dfrac xy\)로 같은 답이 나옵니다.

결과 \(-\dfrac xy\)에 \(y\)가 들어 있다는 점이 음함수 미분법의 특징입니다. 같은 \(x = 3\)이라도 위쪽 점 \((3, 4)\)와 아래쪽 점 \((3, -4)\)에서 기울기가 다르기 때문에, 기울기를 \(x\)만으로 말할 수 없습니다.

예제 2.3.2 (데카르트의 엽선)

\(x^3 + y^3 = 6xy\) 위의 점 \((3, 3)\)에서 접선의 기울기를 구하여라.

풀이. 오른쪽 \(6xy\)는 곱이므로 곱의 미분법을 씁니다: \(\dfrac{d}{dx}(6xy) = 6y + 6x\dfrac{dy}{dx}\). 양변을 미분하면

\[3x^2 + 3y^2\frac{dy}{dx} = 6y + 6x\frac{dy}{dx}.\]

\(\dfrac{dy}{dx}\)가 든 항을 왼쪽으로 모으면 \((3y^2 - 6x)\dfrac{dy}{dx} = 6y - 3x^2\), 따라서

\[\frac{dy}{dx} = \frac{2y - x^2}{y^2 - 2x}.\]

\((3, 3)\)을 넣으면 \(\dfrac{6 - 9}{9 - 6} = -1\)입니다. (먼저 \(3^3 + 3^3 = 54 = 6\cdot3\cdot3\)이므로 점이 곡선 위에 있음을 확인하세요.)

2.3.3이계도함수

음함수의 이계도함수는 \(\dfrac{dy}{dx}\)의 식을 한 번 더 미분하고, 그 안에 나오는 \(\dfrac{dy}{dx}\)에 앞에서 구한 식을 넣어 구합니다.

예제 2.3.3

\(x^2 + y^2 = 25\)에서 \(\dfrac{d^2y}{dx^2}\)을 구하여라.

풀이. \(y' = -\dfrac xy\)를 몫의 미분법으로 미분하면

\[y'' = -\frac{1\cdot y - x\cdot y'}{y^2} = -\frac{y - x\left(-\frac xy\right)}{y^2} = -\frac{y^2 + x^2}{y^3} = -\frac{25}{y^3}.\]

마지막에 원래 식 \(x^2 + y^2 = 25\)를 썼습니다. 위쪽 반원(\(y > 0\))에서 \(y'' < 0\)이라 위로 볼록하고, 아래쪽 반원에서는 아래로 볼록합니다. 그림과 맞습니다.

주의\(y^2\)을 \(x\)로 미분해 \(2y\)라고만 쓰는 실수가 가장 흔합니다. \(y\)는 \(x\)의 함수이므로 \(2y\dfrac{dy}{dx}\)입니다. 또 \(xy\) 같은 곱은 반드시 곱의 미분법을 씁니다.
요약
  1. 관계식의 양변을 \(x\)로 미분하고, \(y\)가 든 항에는 \(\dfrac{dy}{dx}\)를 곱한다(연쇄법칙).
  2. \(\dfrac{dy}{dx}\)를 모아 풀면, 답에 \(x\)와 \(y\)가 함께 나올 수 있다.
  3. 접선은 그 점의 좌표를 넣어 기울기를 구한 뒤 \(y - y_0 = m(x - x_0)\).

2.3.4연습문제

기본

  1. \(x^2 - y^2 = 1\)에서 \(\dfrac{dy}{dx}\)를 구하여라.
    답

    \(2x - 2yy' = 0\), \(y' = \dfrac xy\).

  2. 타원 \(\dfrac{x^2}{4} + y^2 = 1\) 위의 점 \(\left(1, \dfrac{\sqrt3}{2}\right)\)에서 접선의 기울기를 구하여라.
    답

    \(\frac x2 + 2yy' = 0\), \(y' = -\frac{x}{4y} = -\frac{1}{2\sqrt3}\).

응용

  1. \(\sin(x + y) = y\)에서 \(\dfrac{dy}{dx}\)를 구하여라.
    답

    \(\cos(x + y)(1 + y') = y'\), \(y' = \dfrac{\cos(x + y)}{1 - \cos(x + y)}\).

  2. \(xy = 6\) 위의 점 \((2, 3)\)에서 접선의 방정식을 구하여라.
    답

    \(y + xy' = 0\), \(y' = -\frac yx = -\frac32\). 접선 \(y - 3 = -\frac32(x - 2)\), 곧 \(3x + 2y = 12\).

심화

  1. 예제 2.3.2의 곡선에서 접선이 수평인 점을 구하여라.
    힌트

    분자 \(2y - x^2 = 0\)과 곡선의 식을 연립하세요.

    답

    \(y = \frac{x^2}{2}\)를 대입하면 \(x^3 + \frac{x^6}{8} = 3x^3\), \(x^6 = 16x^3\), \(x = 0\) 또는 \(x^3 = 16\). 원점은 분모도 0이라 제외하면 \(x = 2^{4/3} \approx 2.52\), \(y = 2^{5/3} \approx 3.17\).
