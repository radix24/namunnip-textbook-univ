근사 적분: 사다리꼴 공식과 심프슨 공식

본문 · 5.6절
이 절에서 배울 것
  • 사다리꼴 공식과 심프슨 공식을 유도하고 계산한다.
  • 두 공식의 오차가 칸의 폭에 따라 어떻게 줄어드는지 비교한다.
  • 원하는 정확도를 얻으려면 몇 칸으로 나눠야 하는지 어림한다.
먼저 알아야 할 것
  • 리만 합과 정적분 (4.1절), 컴퓨터로 적분 어림하기 (4.4절).
  • 세 점을 지나는 이차함수(고교 수학의 이차함수). 아래에서 필요한 부분을 다시 설명합니다.

원시함수를 모를 때

\(\int_0^1e^{-x^2}dx\), \(\int_0^\pi\frac{\sin x}x\,dx\)처럼 원시함수를 기본 함수로 쓸 수 없는 적분이 많고, 실험에서 일정한 시간 간격으로 잰 속도에서 이동 거리를 구할 때는 함수의 식 자체가 없습니다. 이럴 때는 몇 개 점의 함숫값만으로 정적분을 어림합니다. 리만 합은 칸마다 직사각형을 썼습니다. 직사각형 대신 곡선에 더 잘 맞는 도형을 쓰면 같은 점의 수로 훨씬 정확해집니다.

5.6.1사다리꼴 공식

구간 \([a, b]\)를 \(n\)등분해 폭을 \(h = (b - a)/n\), 나눈 점을 \(x_i = a + ih\), \(y_i = f(x_i)\)라 합니다. 이웃한 두 점을 직선으로 이으면 칸마다 사다리꼴이 생기고, 넓이는 \(\tfrac h2(y_{i-1} + y_i)\)입니다. 모두 더하면 가운데 점들은 두 번씩 들어갑니다.

정리 5.6.1 (사다리꼴 공식)

\[T_n = \frac h2\left(y_0 + 2y_1 + 2y_2 + \cdots + 2y_{n-1} + y_n\right).\]

\(f''\)이 연속이고 \(|f''| \le K\)이면 오차는 \(|E_T| \le \dfrac{K(b - a)^3}{12n^2}\).

오차가 \(1/n^2\)에 비례하므로 \(n\)을 두 배로 하면 오차는 약 4분의 1이 됩니다. 오차에 \(f''\)이 들어 있는 것은, 직선으로 이었을 때 틀리는 정도가 곡선이 휜 정도에 달려 있기 때문입니다. 아래로 볼록(\(f'' > 0\))하면 사다리꼴이 곡선 위로 지나가 값이 크게 나옵니다.

5.6.2심프슨 공식

이번에는 두 칸씩 묶어 세 점 \((x_0, y_0)\), \((x_1, y_1)\), \((x_2, y_2)\)를 지나는 포물선으로 잇습니다. 세 점의 가로 간격이 \(h\)로 같으면 그 포물선 아래 넓이는 놀랍게도 간단합니다.

정리 5.6.2 (포물선 아래 넓이)

세 점 \((-h, y_0)\), \((0, y_1)\), \((h, y_2)\)를 지나는 포물선 \(y = Ax^2 + Bx + C\) 아래의 \([-h, h]\) 넓이는 \(\dfrac h3(y_0 + 4y_1 + y_2)\)이다.

넓이는 \(\int_{-h}^h(Ax^2 + Bx + C)\,dx = \tfrac23Ah^3 + 2Ch\)입니다(\(Bx\)는 기함수라 0). 한편 \(y_0 = Ah^2 - Bh + C\), \(y_1 = C\), \(y_2 = Ah^2 + Bh + C\)에서 \(y_0 + y_2 = 2Ah^2 + 2C\)이므로 \(y_0 + 4y_1 + y_2 = 2Ah^2 + 6C\). 따라서 \(\dfrac h3(y_0 + 4y_1 + y_2) = \dfrac23Ah^3 + 2Ch\)로 넓이와 같습니다. 가로로 옮겨도 넓이는 그대로이므로 어느 세 점에서나 성립합니다. ∎

\(n\)이 짝수일 때 두 칸씩 이 넓이를 더하면, 묶음의 가운데 점에는 4가, 묶음 사이의 점에는 2가 붙습니다.

정리 5.6.3 (심프슨 공식)

\[S_n = \frac h3\left(y_0 + 4y_1 + 2y_2 + 4y_3 + \cdots + 2y_{n-2} + 4y_{n-1} + y_n\right)\quad(n\text{은 짝수}).\]

\(f^{(4)}\)가 연속이고 \(|f^{(4)}| \le K\)이면 \(|E_S| \le \dfrac{K(b - a)^5}{180n^4}\).

오차가 \(1/n^4\)에 비례하므로 \(n\)을 두 배로 하면 오차는 약 16분의 1입니다. 또 오차에 \(f^{(4)}\)가 들어 있으므로 3차 이하의 다항식에서는 오차가 0입니다. 포물선으로 이었는데 3차까지 정확한 것은, 3차 항의 오차가 묶음 좌우에서 서로 지워지기 때문입니다.

예제 5.6.4

\(\int_1^2\dfrac{dx}x = \ln2\)를 \(n = 4\)인 사다리꼴 공식과 심프슨 공식으로 어림하고 오차를 비교하여라.

풀이. \(h = 0.25\), 점의 값은 \(y_0 = 1\), \(y_1 = 0.8\), \(y_2 = 0.6667\), \(y_3 = 0.5714\), \(y_4 = 0.5\)입니다.

\(T_4 = 0.125\left(1 + 1.6 + 1.3333 + 1.1429 + 0.5\right) = 0.69702\), 오차 \(+0.00388\).

\(S_4 = \dfrac{0.25}3\left(1 + 3.2 + 1.3333 + 2.2857 + 0.5\right) = 0.693254\), 오차 \(+0.000107\).

참값 \(\ln2 = 0.693147\)이므로 같은 다섯 점을 쓰고도 심프슨 공식이 36배 정확합니다. \(1/x\)은 아래로 볼록이라 사다리꼴이 크게 나왔습니다.

예제 5.6.5

\(\int_1^2\frac{dx}x\)를 사다리꼴 공식으로 오차 \(10^{-6}\) 이하로 구하려면 \(n\)이 얼마 이상이어야 하는가? 심프슨 공식이면?

풀이. \(f'' = 2/x^3 \le 2\), \(f^{(4)} = 24/x^5 \le 24\)(구간 \([1, 2]\)). 사다리꼴: \(\dfrac{2}{12n^2} \le 10^{-6}\)에서 \(n^2 \ge 1.67\times10^5\), \(n \ge 409\). 심프슨: \(\dfrac{24}{180n^4} \le 10^{-6}\)에서 \(n^4 \ge 1.33\times10^5\), \(n \ge 19.1\), 짝수이므로 \(n = 20\). 오차 공식은 최악의 경우를 잡은 것이라 실제 오차는 이보다 작습니다.

심프슨 공식은 \(n\)이 짝수일 때만 씁니다. 홀수 칸을 억지로 묶으면 마지막 칸이 남습니다. 또 \(\sqrt x\)처럼 끝점에서 도함수가 무한대인 함수는 오차 공식의 가정이 깨져 \(n\)을 늘려도 오차가 기대만큼 줄지 않습니다.

POSTECH 미적분학 I(Lax & Terrell 8장)과 Stewart 7.7절이 이 내용을 다룹니다. 연세대 미분적분학과벡터해석(1)의 2026 진도에는 없어 보충으로 넣었습니다. 더 정확한 방법(롬베르그, 가우스 구적)은 수치해석 과목에서 배웁니다.

요약
  1. 사다리꼴: \(T_n = \tfrac h2(y_0 + 2y_1 + \cdots + 2y_{n-1} + y_n)\), 오차 \(\propto h^2\).
  2. 심프슨(\(n\) 짝수): \(S_n = \tfrac h3(y_0 + 4y_1 + 2y_2 + \cdots + 4y_{n-1} + y_n)\), 오차 \(\propto h^4\), 3차 다항식까지 정확.
  3. 오차 상한으로 필요한 \(n\)을 미리 어림할 수 있다.
연습문제
  1. 기본 \(\int_0^2x^3\,dx\)를 \(n = 2\)인 심프슨 공식으로 계산하고 참값과 비교하여라.
    답\(\tfrac13(0 + 4 + 8) = 4\). 참값 4와 정확히 같다(3차 다항식).
  2. 기본 1초 간격으로 잰 자동차의 속력이 0, 4, 9, 13, 16 m/s였다. 4초 동안 간 거리를 사다리꼴 공식과 심프슨 공식으로 어림하여라.
    답\(T = \tfrac12(0 + 8 + 18 + 26 + 16) = 34\) m, \(S = \tfrac13(0 + 16 + 18 + 52 + 16) = 34\) m.
  3. 응용 \(S_{2n} = \dfrac{2M_n + T_n}{3}\)(\(M_n\)은 가운데 합)임을 보이고, 이것으로 심프슨 공식이 정확한 이유를 말하여라.
    답가운데 합의 오차는 사다리꼴 오차의 약 \(-\tfrac12\)배라, \(2M + T\)에서 \(h^2\) 오차가 지워진다.
  4. 심화 \(\int_0^1e^{-x^2}dx\)를 심프슨 공식으로 소수 넷째 자리까지 맞추려면 \(n\)이 얼마면 되는가? 계산기로 확인하여라.
    답\(n = 4\)이면 0.746855, 참값 0.746824와 \(3\times10^{-5}\) 차이로 충분하다.
