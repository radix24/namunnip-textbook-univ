삼각함수의 적분

본문

\(\sin^2 x\)를 한 주기 동안 적분하면 얼마일까? 거듭제곱 공식처럼 \(\frac{\sin^3x}{3}\)이라고 쓰고 싶지만 그것은 틀린 답이다. 그렇다면 사인과 코사인의 거듭제곱은 어떻게 적분해야 할까?

먼저 알아야 할 것치환적분(4.3절)과 \(\sin^2x + \cos^2x = 1\), 배각 공식 \(\cos2x = 1 - 2\sin^2x = 2\cos^2x - 1\)을 쓴다. 배각 공식은 고교 수학I과 미적분에서 배우지만, 이 절에서 쓰는 꼴을 다시 적는다.

5.2.1지수 하나가 홀수일 때

\(\int\sin^3x\,dx\)처럼 사인이나 코사인의 거듭제곱을 적분할 때는 지수가 홀수인지부터 본다. 지수가 홀수이면 하나를 떼어 \(du\)로 쓰고, 남은 짝수 개를 \(\sin^2x + \cos^2x = 1\)로 바꾼다. 그러면 4.3절의 치환적분이 그대로 통한다.

예제 5.2.1

(가) \(\int\sin^3x\,dx\) (나) \(\int\sin^2x\cos^5x\,dx\)

풀이. (가) \(\sin^3x = \sin^2x\cdot\sin x = (1 - \cos^2x)\sin x\)이다. \(u = \cos x\), \(du = -\sin x\,dx\)로 놓으면 \(\int(1 - u^2)(-du) = -u + \frac{u^3}{3} + C = -\cos x + \frac{\cos^3x}{3} + C\)이다.

(나) 코사인의 지수 5가 홀수이므로 코사인 하나를 뗀다. \(\cos^5x = (\cos^2x)^2\cos x = (1 - \sin^2x)^2\cos x\)이고, \(u = \sin x\)로 놓으면 \(\int u^2(1 - u^2)^2du = \int(u^2 - 2u^4 + u^6)du = \frac{\sin^3x}{3} - \frac{2\sin^5x}{5} + \frac{\sin^7x}{7} + C\)이다.

5.2.2두 지수가 모두 짝수일 때

그런데 둘 다 짝수이면 떼어 낼 하나가 없다. 이때는 배각 공식을 거꾸로 쓴 반각 공식으로 차수를 낮춘다.

\[\sin^2x = \frac{1 - \cos2x}{2}, \qquad \cos^2x = \frac{1 + \cos2x}{2}, \qquad \sin x\cos x = \frac{\sin2x}{2}\]

첫 식은 그림 1을 식으로 쓴 것이기도 하다. \(\sin^2x\)는 높이 \(\frac12\)에서 진폭 \(\frac12\), 주기 \(\pi\)로 출렁이는 코사인 곡선을 뒤집은 것이다.

예제 5.2.2

\(\int_0^\pi\sin^2x\,dx\)와 \(\int\sin^4x\,dx\)를 구하여라.

풀이. 반각 공식으로 \(\int_0^\pi\frac{1 - \cos2x}{2}dx = \left[\frac x2 - \frac{\sin2x}{4}\right]_0^\pi = \frac\pi2\)이다. 이것이 처음 질문의 답이다. 그림 1에서 보듯이 한 주기에서 \(\sin^2\)의 평균은 \(\frac12\)이고, 이 사실은 일반물리의 교류 전력 계산에 그대로 쓰인다.

\(\sin^4x\)는 반각 공식을 두 번 쓴다. \(\sin^4x = \left(\frac{1 - \cos2x}{2}\right)^2 = \frac14(1 - 2\cos2x + \cos^22x)\)이고, 여기서 \(\cos^22x = \frac{1 + \cos4x}{2}\)로 한 번 더 낮추면

\[\int\sin^4x\,dx = \frac{3x}{8} - \frac{\sin2x}{4} + \frac{\sin4x}{32} + C\]

이다. 결과의 첫 항 \(\frac{3x}{8}\)은 \(\sin^4x\)의 평균이 \(\frac38\)이라는 뜻이고, 나머지 두 항은 한 주기마다 0으로 돌아오는 출렁임이다.

5.2.3탄젠트와 시컨트

탄젠트와 시컨트의 적분에는 \((\tan x)' = \sec^2x\), \((\sec x)' = \sec x\tan x\), 그리고 \(\tan^2x = \sec^2x - 1\)을 쓴다. 가령 다음과 같다.

\[\int\tan^2x\,dx = \int(\sec^2x - 1)\,dx = \tan x - x + C\]

또 \(\int\sec x\,dx = \ln|\sec x + \tan x| + C\)는 외워 두면 편리하다. 이 식은 우변을 미분하면 \(\frac{\sec x\tan x + \sec^2x}{\sec x + \tan x} = \sec x\)가 되어 확인할 수 있다. 처음부터 이 답을 찾아내기는 어렵다. 분자와 분모에 \(\sec x + \tan x\)를 곱하면 분자가 분모의 도함수가 된다는 관찰이 필요한데, 그런 관찰은 대개 답을 알고 거꾸로 맞춘 결과이다. 그래서 이 적분은 유도 과정보다 결과를 기억해 두고, 쓸 때마다 미분으로 확인하는 편이 낫다.

주의\(\int\sin^2x\,dx\)를 \(\frac{\sin^3x}{3}\)로 계산하면 틀린다. \((\sin^3x)' = 3\sin^2x\cos x\)이므로, \(\cos x\)가 곱해져 있지 않은 식에는 거듭제곱 공식을 쓸 수 없다. 처음 질문의 \(\frac{\sin^3x}{3}\)은 \([0, \pi]\)에서 0을 주는데, 그림 1의 넓이가 분명히 양수이므로 틀렸음을 바로 알 수 있다.
마무리

사인과 코사인의 거듭제곱은 지수 중 홀수가 있으면 하나를 떼어 \(du\)로 쓰고 나머지를 \(\sin^2 + \cos^2 = 1\)로 바꾸며, 둘 다 짝수이면 반각 공식으로 차수를 낮춘다. 그래서 처음 질문의 \(\int_0^\pi\sin^2x\,dx\)는 \(\frac\pi2\)이고, 이는 \(\sin^2x\)의 평균이 \(\frac12\)이라는 뜻이다. 탄젠트와 시컨트는 \(\tan^2x = \sec^2x - 1\)로 바꾸어 적분한다.

5.2.4연습문제

기본

  1. (가) \(\int\cos^3x\,dx\) (나) \(\int_0^{\pi/2}\cos^2x\,dx\)
    답

    (가) \(\sin x - \frac{\sin^3x}{3} + C\) (나) \(\frac\pi4\)

응용

  1. \(\int\sin^2x\cos^2x\,dx\)를 구하여라.
    답

    \(\sin x\cos x = \frac{\sin2x}{2}\)이므로 \(\frac14\int\sin^22x\,dx = \frac14\int\frac{1 - \cos4x}{2}dx = \frac x8 - \frac{\sin4x}{32} + C\).

  2. \(\int\tan x\sec^2x\,dx\)를 구하여라.
    답

    \(u = \tan x\): \(\frac{\tan^2x}{2} + C\).
