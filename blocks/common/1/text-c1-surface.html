회전체의 겉넓이

본문
이 절에서 배울 것
  • 곡선을 돌려 생기는 곡면의 넓이를 \(S = \int2\pi y\,ds\)로 구한다.
먼저 알아야 할 것
  • 곡선의 길이와 \(ds\) (6.3절).

6.4.1띠를 둘러 더하기

곡선 \(y = f(x) \ge 0\)을 \(x\)축 둘레로 돌리면 꽃병 같은 곡면이 생깁니다. 곡선의 짧은 조각(길이 \(ds\))을 돌리면 반지름 \(y\)인 얇은 띠가 되고, 띠를 펼치면 가로 \(2\pi y\), 세로 \(ds\)인 직사각형에 가깝습니다. 그래서 띠의 넓이는 \(2\pi y\,ds\)입니다.

정의 6.4.1 (회전체의 겉넓이)

\(y = f(x) \ge 0\) (\(a \le x \le b\))를 \(x\)축 둘레로 돌린 곡면의 넓이는

\[S = \int_a^b 2\pi f(x)\sqrt{1 + [f'(x)]^2}\,dx.\]
예제 6.4.2

반지름 \(r\)인 구의 겉넓이를 구하여라.

풀이. \(y = \sqrt{r^2 - x^2}\), \(-r \le x \le r\)을 돌립니다. \(y' = \dfrac{-x}{\sqrt{r^2 - x^2}}\)이므로 \(\sqrt{1 + y'^2} = \dfrac{r}{\sqrt{r^2 - x^2}}\). 따라서 \(y\sqrt{1 + y'^2} = r\)이고

\[S = \int_{-r}^{r}2\pi r\,dx = 4\pi r^2.\]

구의 부피 \(\frac43\pi r^3\)을 \(r\)로 미분하면 겉넓이 \(4\pi r^2\)이 됩니다. 반지름을 \(dr\)만큼 늘리면 부피가 "겉넓이 × 두께 \(dr\)"만큼 늘어나기 때문입니다.

주의\(ds\) 대신 \(dx\)를 써서 \(\int2\pi y\,dx\)로 계산하면 틀립니다. 곡면은 기울어져 있어 그 넓이는 \(x\)축 방향 폭이 아니라 곡선을 따른 길이로 재야 합니다.
요약
  1. \(S = \int2\pi y\,ds = \int_a^b2\pi f(x)\sqrt{1 + f'(x)^2}\,dx\).
  2. \(y\)축 둘레로 돌리면 반지름이 \(x\)이므로 \(S = \int2\pi x\,ds\).

6.4.2연습문제

기본

  1. \(y = 2x\), \(0 \le x \le 1\)을 \(x\)축 둘레로 돌린 원뿔의 옆넓이를 구하여라.
    답

    \(\int_0^1 2\pi(2x)\sqrt5\,dx = 2\sqrt5\pi\). (공식 \(\pi r\ell = \pi\cdot2\cdot\sqrt5\)와 같다.)

응용

  1. \(y = \sqrt x\), \(1 \le x \le 4\)를 \(x\)축 둘레로 돌린 곡면의 넓이를 구하여라.
    답

    \(y\sqrt{1 + y'^2} = \sqrt{x + \frac14}\). \(\int_1^4 2\pi\sqrt{x + \frac14}\,dx = \frac{4\pi}{3}\left[(x + \tfrac14)^{3/2}\right]_1^4 = \frac\pi6(17\sqrt{17} - 5\sqrt5) \approx 30.85\).
