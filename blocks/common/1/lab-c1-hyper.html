늘어진 전깃줄은 포물선일까?

탐구 · 쌍곡선 함수와 현수선

질문

두 기둥 사이에 늘어뜨린 전깃줄이나 목걸이 줄은 포물선처럼 보입니다. 실제 모양은 \(e^x\)와 \(e^{-x}\)의 평균인 함수 \(\cosh x\)로 나타납니다. 쌍곡선 함수가 어떤 모양이고, 삼각함수와 어떻게 닮았는지 슬라이더로 확인합니다.

복원

  • \(\cosh x = \dfrac{e^x + e^{-x}}2\) (보라), \(\sinh x = \dfrac{e^x - e^{-x}}2\) (주황). 연한 점선은 \(e^x\)와 \(e^{-x}\)입니다. \(\cosh\)는 두 점선의 평균, \(\sinh\)는 차의 절반입니다.
  • 회색 점선은 현수선 \(y = a\cosh(x/a)\)입니다. \(a\)는 줄의 장력과 무게의 비로 정해지며, 클수록 팽팽합니다.

설명

\(x = 1\)이면 \(\cosh1 = 1.5431\), \(\sinh1 = 1.1752\)이고 \(\cosh^21 - \sinh^21 = 1.000000\)입니다. 어느 \(x\)에서나 \(\cosh^2x - \sinh^2x = 1\)이 성립합니다. 점 \((\cosh t, \sinh t)\)가 쌍곡선 \(x^2 - y^2 = 1\) 위에 있다는 뜻이고, \((\cos t, \sin t)\)가 원 \(x^2 + y^2 = 1\) 위에 있는 것과 짝을 이룹니다. 그래서 "쌍곡선" 함수라는 이름이 붙었습니다.

미분은 \((\cosh x)' = \sinh x\), \((\sinh x)' = \cosh x\)로, 삼각함수와 달리 부호가 바뀌지 않습니다. \(\cosh\)는 우함수라 \(x = 0\)에서 가장 작은 값 1을 갖고, \(\sinh\)는 기함수로 원점을 지납니다. 현수선은 \(x\)가 0 근처일 때 \(a + \dfrac{x^2}{2a}\)(포물선)와 거의 같지만, 멀리 가면 지수함수처럼 더 빨리 올라갑니다.

연결

쌍곡선 함수는 \(\int\dfrac{dx}{\sqrt{1 + x^2}}\) 같은 적분(5.3절)과 곡선의 길이(6.3절)에 나타나고, 고등미적분학에서는 복소수 \(\cosh x = \cos(ix)\)로 삼각함수와 하나로 이어집니다(공통9 3.5절).

적용

현수선 \(y = \cosh x\)의 \(-1 \le x \le 1\) 부분의 길이는 \(\int_{-1}^1\sqrt{1 + \sinh^2x}\,dx = 2\sinh1\)입니다. 위의 출력으로 값을 구해 보세요(답: 2.3504).

판단

“\(\cosh x\)는 \(x^2\)처럼 생겼으니 \(\cosh x = 1 + x^2\)이다.” \(x = 2\)에서 두 값을 비교해 판단해 보세요.
