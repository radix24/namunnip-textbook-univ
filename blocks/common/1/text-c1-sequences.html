본문

\(a_1 = \sqrt2\), \(a_2 = \sqrt{2 + \sqrt2}\), \(a_3 = \sqrt{2 + \sqrt{2 + \sqrt2}}\), …처럼 근호를 끝없이 겹쳐 가면 그 값은 어디로 갈까? 일반항을 식으로 쓸 수 없는 수열이 수렴한다는 것을 어떻게 보일 수 있을까?

먼저 알아야 할 것고교 수학I의 수열과 일반항, 함수의 극한과 로피탈 법칙(3.3절), 그리고 수학적 귀납법을 쓴다. 수열의 극한(고교 미적분)은 처음부터 설명한다.

8.1.1수열의 극한

수열 \(a_n = \frac{n}{n + 1}\)은 \(\frac12, \frac23, \frac34, \dots\)로 1에 다가간다. 반면 \(a_n = (-1)^n\)은 \(-1\)과 1을 오가며 어디에도 다가가지 않는다. 이렇게 \(n\)이 커질 때 \(a_n\)이 한 값 \(L\)에 한없이 가까워지면 \(\lim_{n\to\infty}a_n = L\)이라 쓰고 수열이 수렴한다고 한다. 그렇지 않으면 발산한다고 한다.

정확한 정의는 함수의 극한(3.3절 보충의 \(x \to \infty\))과 같은 방식이다. 즉 임의의 \(\varepsilon > 0\)에 대해, \(n > N\)이면 \(|a_n - L| < \varepsilon\)이 되는 \(N\)이 있다는 뜻이다. 그러면 수열은 정수에서만 정의된 함수이므로 다음이 성립한다.

정리 8.1.1

\(\lim_{x\to\infty}f(x) = L\)이고 \(a_n = f(n)\)이면 \(\lim_{n\to\infty}a_n = L\)이다.

그래서 수열의 극한을 함수의 극한으로 바꾸어 로피탈 법칙 같은 도구를 쓸 수 있다. 극한의 합·곱·몫 법칙과 압축 정리도 수열에서 그대로 성립한다.

예제 8.1.2

(가) \(\lim\dfrac{\ln n}{n}\) (나) \(\lim\dfrac{(-1)^n}{n}\) (다) \(\lim r^n\)

풀이. (가) \(f(x) = \frac{\ln x}{x}\)에 로피탈 법칙을 쓰면 \(\frac{1/x}{1} \to 0\)이므로 극한은 0이다. (나) \(-\frac1n \le \frac{(-1)^n}{n} \le \frac1n\)이고 양쪽이 0으로 가므로 압축 정리로 0이다. (다) \(|r| < 1\)이면 0, \(r = 1\)이면 1이고, \(r > 1\)이면 발산하며 \(r \le -1\)이면 진동하며 발산한다. 이 결과는 다음 절의 등비급수에서 핵심이다.

8.1.2단조이고 유계인 수열

그런데 처음 질문의 수열 \(a_1 = \sqrt2\), \(a_{n+1} = \sqrt{2 + a_n}\)처럼 일반항을 직접 계산할 수 없는 수열도 있다. 이런 수열의 수렴은 다음 정리로 보인다.

정리 8.1.3 (단조 수렴 정리)

증가하고(\(a_n \le a_{n+1}\)) 위로 유계인(모든 \(n\)에 대해 \(a_n \le M\)) 수열은 수렴한다. 감소하고 아래로 유계인 수열도 수렴한다.

계속 올라가지만 천장 \(M\)을 넘지 못하면 어떤 값에 다가갈 수밖에 없다는 뜻이다. 다가가는 값은 수열의 항들의 상한이다. 이 정리는 실수에 빈틈이 없다는 성질, 곧 완비성에 기대고 있으며 그 이야기는 1.1절의 보충 본문에 있다.

예제 8.1.4

\(a_1 = \sqrt2\), \(a_{n+1} = \sqrt{2 + a_n}\)이 수렴함을 보이고 극한을 구하여라.

풀이. 먼저 위로 유계, 곧 \(a_n < 2\)임을 귀납법으로 보인다. \(a_1 = \sqrt2 < 2\)이고, \(a_n < 2\)이면 \(a_{n+1} = \sqrt{2 + a_n} < \sqrt4 = 2\)이다.

다음으로 증가함을 보인다. \(0 < a_n < 2\)이면 \(a_{n+1}^2 - a_n^2 = 2 + a_n - a_n^2 = (2 - a_n)(1 + a_n) > 0\)이므로 \(a_{n+1} > a_n\)이다.

따라서 단조 수렴 정리로 수렴한다. 극한을 \(L\)이라 하면 점화식 양변의 극한에서 \(L = \sqrt{2 + L}\), 곧 \(L^2 - L - 2 = 0\)이고 \(L > 0\)이므로 \(L = 2\)이다. 실제로 수열은 \(\sqrt2 \approx 1.414\), \(1.848\), \(1.962\), \(1.990, \dots\)로 2에 다가간다. 그림 1의 거미줄 그림은 이 계산을 눈으로 보여 준다. 곡선 \(y = \sqrt{2 + x}\)가 \(x < 2\)에서 직선 \(y = x\)보다 위에 있으므로 한 단계마다 오른쪽으로 옮겨 가고, 두 그래프가 만나는 \(x = 2\)를 넘지는 못한다.

주의수렴한다는 것을 보이기 전에 "\(L = \sqrt{2 + L}\)"로 극한을 구하면 안 된다. 발산하는 수열에 같은 계산을 하면 엉뚱한 값이 나온다. 가령 \(a_{n+1} = 2a_n\), \(a_1 = 1\)이면 \(L = 2L\)에서 \(L = 0\)이지만, 실제로는 1, 2, 4, 8, …로 발산한다.
마무리

수열의 극한은 함수의 극한과 같은 방식으로 정의되므로, \(a_n = f(n)\)이면 \(\lim f(x)\)로 계산하고 극한 법칙과 압축 정리를 그대로 쓴다. 일반항을 쓸 수 없는 점화식 수열은 귀납법으로 유계이고 단조임을 보이면 단조 수렴 정리로 수렴하며, 그다음에 점화식에서 극한을 구한다. 그래서 처음 질문의 끝없이 겹친 근호는 2로 간다.

8.1.3연습문제

기본

  1. 극한을 구하여라. (가) \(\frac{3n^2 + 1}{n^2 - n}\) (나) \(\frac{n}{e^n}\) (다) \(\left(1 + \frac2n\right)^n\)
    답

    (가) 3 (나) 0 (다) \(e^2\) (3.3절)

응용

  1. \(a_1 = 1\), \(a_{n+1} = \frac{a_n + 6}{2}\)이 수렴함을 보이고 극한을 구하여라.
    답

    귀납법으로 \(a_n < 6\)이고 \(a_{n+1} - a_n = \frac{6 - a_n}{2} > 0\). 증가하고 유계이므로 수렴. \(L = \frac{L + 6}{2}\)에서 \(L = 6\).
