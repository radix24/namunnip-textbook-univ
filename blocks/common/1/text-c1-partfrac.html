부분분수를 이용한 유리함수의 적분

본문
이 절에서 배울 것
  • 유리함수를 간단한 분수의 합(부분분수)으로 나눈다.
  • 나눈 분수를 각각 적분한다.
먼저 알아야 할 것
  • 다항식의 나눗셈과 인수분해 (고교 수학).
  • \(\int\frac{dx}{x - a} = \ln|x - a|\), \(\int\frac{dx}{1 + x^2} = \arctan x\) (4.2절).

5.4.1통분을 거꾸로

\(\dfrac{2}{x - 1} - \dfrac{1}{x + 1}\)을 통분하면 \(\dfrac{x + 3}{x^2 - 1}\)입니다. 거꾸로 \(\int\dfrac{x + 3}{x^2 - 1}dx\)를 구하라는 문제를 받으면, 통분을 거꾸로 해서 두 분수로 나누면 각각은 로그로 바로 적분됩니다.

\[\int\frac{x + 3}{x^2 - 1}dx = 2\ln|x - 1| - \ln|x + 1| + C.\]

이렇게 분모를 인수분해해서 간단한 분수의 합으로 나누는 것을 부분분수 분해라고 합니다.

5.4.2나누는 방법

  1. 분자의 차수가 분모의 차수보다 크거나 같으면 먼저 나눗셈을 한다(몫 + 나머지/분모).
  2. 분모를 일차식과 (더 이상 인수분해되지 않는) 이차식의 곱으로 인수분해한다.
  3. 인수마다 아래 꼴의 항을 둔다.
    • 일차식 \((ax + b)\): \(\dfrac{A}{ax + b}\)
    • 거듭 나오는 일차식 \((ax + b)^2\): \(\dfrac{A}{ax + b} + \dfrac{B}{(ax + b)^2}\)
    • 이차식 \((x^2 + c)\): \(\dfrac{Ax + B}{x^2 + c}\)
  4. 양변에 분모를 곱하고, 편한 \(x\) 값을 넣거나 계수를 비교해 \(A, B, \dots\)를 구한다.
예제 5.4.1

\(\int\dfrac{5x - 4}{x^2 - x - 2}dx\)를 구하여라.

풀이. \(x^2 - x - 2 = (x - 2)(x + 1)\). \(\dfrac{5x - 4}{(x - 2)(x + 1)} = \dfrac{A}{x - 2} + \dfrac{B}{x + 1}\)로 놓고 분모를 곱하면 \(5x - 4 = A(x + 1) + B(x - 2)\). \(x = 2\)를 넣으면 \(6 = 3A\), \(A = 2\). \(x = -1\)을 넣으면 \(-9 = -3B\), \(B = 3\). 따라서

\[\int\left(\frac{2}{x - 2} + \frac{3}{x + 1}\right)dx = 2\ln|x - 2| + 3\ln|x + 1| + C.\]
예제 5.4.2

\(\int\dfrac{dx}{x(x^2 + 1)}\)을 구하여라.

풀이. \(\dfrac{1}{x(x^2 + 1)} = \dfrac Ax + \dfrac{Bx + C}{x^2 + 1}\). 분모를 곱하면 \(1 = A(x^2 + 1) + (Bx + C)x\). \(x = 0\)에서 \(A = 1\). \(x^2\)의 계수: \(0 = A + B\), \(B = -1\). \(x\)의 계수: \(0 = C\). 따라서

\[\int\left(\frac1x - \frac{x}{x^2 + 1}\right)dx = \ln|x| - \frac12\ln(x^2 + 1) + C.\]

부분분수 분해는 2학년 고등미적분학(1)의 라플라스 변환에서 역변환을 구할 때 다시 핵심 도구로 쓰입니다.

주의분자 차수가 분모 차수 이상인데 나눗셈 없이 분해하면 틀린 답이 나옵니다. 예를 들어 \(\dfrac{x^2}{x^2 - 1}\)은 먼저 \(1 + \dfrac{1}{x^2 - 1}\)로 바꿉니다.
요약
  1. 필요하면 나눗셈 → 분모 인수분해 → 인수마다 부분분수 항 → 계수 구하기.
  2. 일차식 항은 \(\ln\), 이차식 항은 \(\ln\)과 \(\arctan\)으로 적분된다.

5.4.3연습문제

기본

  1. \(\int\frac{dx}{x^2 - 4}\)을 구하여라.
    답

    \(\frac14\left(\frac{1}{x - 2} - \frac{1}{x + 2}\right)\). \(\frac14\ln\left|\frac{x - 2}{x + 2}\right| + C\).

응용

  1. \(\int\frac{x + 1}{(x - 1)^2}dx\)를 구하여라.
    답

    \(\frac{1}{x - 1} + \frac{2}{(x - 1)^2}\). \(\ln|x - 1| - \frac{2}{x - 1} + C\).

  2. \(\int\frac{x^3}{x^2 + 1}dx\)를 구하여라.
    답

    나눗셈: \(x - \frac{x}{x^2 + 1}\). \(\frac{x^2}{2} - \frac12\ln(x^2 + 1) + C\).
