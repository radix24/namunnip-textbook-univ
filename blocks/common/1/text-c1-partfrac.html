부분분수를 이용한 유리함수의 적분

본문

\(\frac{2}{x - 1} - \frac{1}{x + 1}\)을 통분하면 \(\frac{x + 3}{x^2 - 1}\)이 된다. 그렇다면 \(\int\frac{x + 3}{x^2 - 1}dx\)를 받았을 때 통분을 거꾸로 해서 다시 두 분수로 나눌 수 있을까? 나눌 수 있다면 어떻게 나누어야 할까?

먼저 알아야 할 것고교 수학의 다항식의 나눗셈과 인수분해, 그리고 \(\int\frac{dx}{x - a} = \ln|x - a|\), \(\int\frac{dx}{1 + x^2} = \arctan x\)(4.2절)를 쓴다.

5.4.1통분을 거꾸로

처음 질문의 적분은 통분을 거꾸로 해서 두 분수로 나누면 각각이 로그로 바로 적분된다.

\[\int\frac{x + 3}{x^2 - 1}dx = \int\left(\frac{2}{x - 1} - \frac{1}{x + 1}\right)dx = 2\ln|x - 1| - \ln|x + 1| + C\]

이렇게 분모를 인수분해해서 간단한 분수의 합으로 나누는 것을 부분분수 분해라고 한다. 그림 1에서 보듯이 나눈 분수 하나하나는 분모의 인수 하나에 대응하고, 그 인수가 0이 되는 곳에서만 무한대로 달아난다. 다시 말해 원래 함수의 복잡한 모양은 단순한 조각들의 합이다.

5.4.2나누는 방법

나누는 일은 네 단계로 한다. 먼저 분자의 차수가 분모의 차수보다 크거나 같으면 나눗셈을 해서 몫과 "나머지/분모"로 바꾼다. 다음으로 분모를 일차식과, 더 이상 인수분해되지 않는 이차식의 곱으로 인수분해한다. 그다음 인수마다 정해진 꼴의 항을 둔다. 일차식 \(ax + b\)에는 \(\frac{A}{ax + b}\)를, 거듭 나오는 일차식 \((ax + b)^2\)에는 \(\frac{A}{ax + b} + \frac{B}{(ax + b)^2}\)을, 이차식 \(x^2 + c\)에는 \(\frac{Ax + B}{x^2 + c}\)를 둔다. 마지막으로 양변에 분모를 곱하고, 편한 \(x\) 값을 넣거나 계수를 비교해 \(A, B, \dots\)를 구한다.

이차식에 \(Ax + B\)처럼 일차식 분자를 두는 까닭은 분자의 차수가 분모보다 하나 낮은 식까지 모두 나타내야 하기 때문이다. 일차식 분모 위에는 상수만 두면 충분하지만, 이차식 분모 위에는 일차식까지 와야 빠지는 경우가 없다.

예제 5.4.1

\(\int\dfrac{5x - 4}{x^2 - x - 2}dx\)를 구하여라.

풀이. 분모는 \(x^2 - x - 2 = (x - 2)(x + 1)\)이다. \(\dfrac{5x - 4}{(x - 2)(x + 1)} = \dfrac{A}{x - 2} + \dfrac{B}{x + 1}\)로 놓고 분모를 곱하면 \(5x - 4 = A(x + 1) + B(x - 2)\)이다. 여기서 \(x = 2\)를 넣으면 \(B\)가 붙은 항이 사라져 \(6 = 3A\), 곧 \(A = 2\)이다. 같은 방법으로 \(x = -1\)을 넣으면 \(-9 = -3B\), 곧 \(B = 3\)이다. 따라서

\[\int\left(\frac{2}{x - 2} + \frac{3}{x + 1}\right)dx = 2\ln|x - 2| + 3\ln|x + 1| + C\]

이다. 분해가 맞는지는 \(x = 0\)을 넣어 확인할 수 있다. 원래 식은 \(\frac{-4}{-2} = 2\)이고, 나눈 식은 \(\frac{2}{-2} + \frac{3}{1} = 2\)이다. 그림 1은 이 분해를 그래프로 그린 것이다.

예제 5.4.2

\(\int\dfrac{dx}{x(x^2 + 1)}\)을 구하여라.

풀이. \(x^2 + 1\)은 더 인수분해되지 않으므로 \(\dfrac{1}{x(x^2 + 1)} = \dfrac Ax + \dfrac{Bx + C}{x^2 + 1}\)로 놓는다. 분모를 곱하면 \(1 = A(x^2 + 1) + (Bx + C)x\)이다. \(x = 0\)을 넣으면 \(A = 1\)이다. 그런데 남은 두 계수는 0이 되는 \(x\)가 없으므로 계수를 비교한다. \(x^2\)의 계수에서 \(0 = A + B\), 곧 \(B = -1\)이고, \(x\)의 계수에서 \(0 = C\)이다. 따라서

\[\int\left(\frac1x - \frac{x}{x^2 + 1}\right)dx = \ln|x| - \frac12\ln(x^2 + 1) + C\]

이다. 둘째 항은 \(u = x^2 + 1\)로 치환해 적분했다. 분자가 \(Bx + C\)에서 \(C \ne 0\)이었다면 \(\arctan\) 항도 나왔을 것이다.

부분분수 분해는 2학년 고등미적분학의 라플라스 변환에서 역변환을 구할 때 다시 핵심 도구로 쓰인다.

주의분자 차수가 분모 차수 이상인데 나눗셈 없이 분해하면 틀린 답이 나온다. 가령 \(\dfrac{x^2}{x^2 - 1}\)은 먼저 \(1 + \dfrac{1}{x^2 - 1}\)로 바꾼다.
마무리

유리함수는 필요하면 먼저 나눗셈을 하고, 분모를 인수분해한 뒤 인수마다 부분분수 항을 두어 계수를 구하면 간단한 분수의 합으로 나뉜다. 처음 질문의 \(\frac{x + 3}{x^2 - 1}\)은 이렇게 \(\frac{2}{x - 1} - \frac{1}{x + 1}\)로 돌아가고, 적분하면 \(2\ln|x - 1| - \ln|x + 1| + C\)이다. 일차식 항은 \(\ln\)으로, 이차식 항은 \(\ln\)과 \(\arctan\)으로 적분된다.

5.4.3연습문제

기본

  1. \(\int\frac{dx}{x^2 - 4}\)을 구하여라.
    답

    \(\frac14\left(\frac{1}{x - 2} - \frac{1}{x + 2}\right)\). \(\frac14\ln\left|\frac{x - 2}{x + 2}\right| + C\).

응용

  1. \(\int\frac{x + 1}{(x - 1)^2}dx\)를 구하여라.
    답

    \(\frac{1}{x - 1} + \frac{2}{(x - 1)^2}\). \(\ln|x - 1| - \frac{2}{x - 1} + C\).

  2. \(\int\frac{x^3}{x^2 + 1}dx\)를 구하여라.
    답

    나눗셈: \(x - \frac{x}{x^2 + 1}\). \(\frac{x^2}{2} - \frac12\ln(x^2 + 1) + C\).
