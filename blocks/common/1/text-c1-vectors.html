9.2.1크기와 방향

질량이나 온도는 수 하나로 나타내지만, 속도나 힘은 "얼마나"와 함께 "어느 쪽으로"가 필요합니다. 북쪽으로 시속 60 km와 남쪽으로 시속 60 km는 다른 속도입니다. 이렇게 크기와 방향을 함께 가진 양을 벡터라 하고, 화살표로 그립니다. 화살표의 길이가 크기, 가리키는 쪽이 방향입니다. 수 하나로 나타내는 양은 스칼라라고 합니다.

화살표를 평행이동해도 크기와 방향이 같으면 같은 벡터로 봅니다. 그래서 벡터는 시작점을 원점에 두고 끝점의 좌표로 나타낼 수 있습니다: \(\mathbf a = \langle a_1, a_2, a_3\rangle\). 이 수들을 벡터의 성분이라 합니다. 점 \(A(x_1, y_1, z_1)\)에서 \(B(x_2, y_2, z_2)\)로 가는 벡터는 \(\overrightarrow{AB} = \langle x_2 - x_1, y_2 - y_1, z_2 - z_1\rangle\)입니다.

9.2.2연산

  • 덧셈: \(\mathbf a + \mathbf b = \langle a_1 + b_1, a_2 + b_2, a_3 + b_3\rangle\). 그림으로는 \(\mathbf a\)의 끝에 \(\mathbf b\)의 시작을 이어 붙인 화살표(삼각형 법칙)이다. 두 힘을 함께 가하면 합력이 이 벡터다.
  • 실수배: \(c\mathbf a = \langle ca_1, ca_2, ca_3\rangle\). 길이가 \(|c|\)배가 되고, \(c < 0\)이면 방향이 반대가 된다.
  • 크기: \(|\mathbf a| = \sqrt{a_1^2 + a_2^2 + a_3^2}\) (9.1절의 거리).
  • 단위벡터: 크기가 1인 벡터. \(\mathbf a \ne \mathbf 0\)과 같은 방향의 단위벡터는 \(\dfrac{\mathbf a}{|\mathbf a|}\).

축 방향의 단위벡터 \(\mathbf i = \langle1, 0, 0\rangle\), \(\mathbf j = \langle0, 1, 0\rangle\), \(\mathbf k = \langle0, 0, 1\rangle\)을 쓰면 \(\langle a_1, a_2, a_3\rangle = a_1\mathbf i + a_2\mathbf j + a_3\mathbf k\)로 쓸 수 있습니다. 물리 교재는 주로 이 표기를 씁니다.

예제 9.2.1

\(\mathbf a = \langle4, 0, 3\rangle\), \(\mathbf b = \langle-2, 1, 5\rangle\)일 때 \(2\mathbf a + 3\mathbf b\), \(|\mathbf a|\), \(\mathbf a\) 방향의 단위벡터를 구하여라.

풀이. \(2\mathbf a + 3\mathbf b = \langle8 - 6, 0 + 3, 6 + 15\rangle = \langle2, 3, 21\rangle\). \(|\mathbf a| = \sqrt{16 + 9} = 5\). 단위벡터 \(\left\langle\frac45, 0, \frac35\right\rangle\).

예제 9.2.2 (힘의 합)

무게 100 N인 물체를 두 줄이 각각 수직선에서 왼쪽으로 30°, 오른쪽으로 30° 기울어져 당겨 정지시키고 있다. 줄의 장력은?

풀이. 두 장력의 크기를 \(T\)라 하면 수평 성분은 \(\pm T\sin30^\circ\)로 지워지고, 수직 성분의 합 \(2T\cos30^\circ\)가 무게 100 N과 같아야 합니다. \(T = \dfrac{100}{2\cos30^\circ} = \dfrac{100}{\sqrt3} \approx 57.7\) N. 각 줄의 장력이 50 N이 아니라 그보다 큰 것은 줄이 기울어져 있기 때문입니다.

요약
  1. 벡터는 크기와 방향을 가진 양. 성분 \(\langle a_1, a_2, a_3\rangle\)으로 나타낸다.
  2. 덧셈과 실수배는 성분끼리. 크기 \(\sqrt{a_1^2 + a_2^2 + a_3^2}\), 단위벡터 \(\mathbf a/|\mathbf a|\).
  3. \(\mathbf i, \mathbf j, \mathbf k\) 표기: \(a_1\mathbf i + a_2\mathbf j + a_3\mathbf k\).

9.2.3연습문제

기본

  1. 점 \(A(1, 0, 2)\)에서 \(B(3, -1, 4)\)로 가는 벡터와 그 크기를 구하여라.
    답

    \(\langle2, -1, 2\rangle\), 크기 3.

  2. \(\mathbf a = \mathbf i + 2\mathbf j - 2\mathbf k\) 방향의 단위벡터는?
    답

    \(|\mathbf a| = 3\). \(\frac13\mathbf i + \frac23\mathbf j - \frac23\mathbf k\).
