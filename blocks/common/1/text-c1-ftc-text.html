미적분의 기본정리

본문
이 절에서 배울 것
  • 적분으로 정의된 함수 \(g(x) = \int_a^x f(t)\,dt\)를 미분한다(기본정리 1).
  • 부정적분으로 정적분을 계산한다(기본정리 2).
먼저 알아야 할 것
  • 정적분의 정의와 성질 (4.1절).
  • 연쇄법칙 (2.2절), 평균값 정리 (3.2절).

4.2.1미분과 적분을 잇는 다리

미분은 접선의 기울기 문제에서, 적분은 넓이 문제에서 따로 출발했습니다. 두 문제는 전혀 달라 보이지만, 뉴턴과 라이프니츠는 이 둘이 서로 거꾸로 된 계산이라는 것을 알아냈습니다. 이 사실이 미적분의 기본정리이고, 덕분에 리만 합의 극한을 직접 계산하지 않고 부정적분으로 정적분을 구할 수 있습니다.

4.2.2기본정리 1: 넓이 함수의 도함수

\(f\)가 연속일 때 \(g(x) = \int_a^x f(t)\,dt\)는 "\(a\)부터 \(x\)까지의 넓이"입니다. \(x\)를 조금(\(h\)만큼) 늘리면 넓이는 폭 \(h\), 높이 약 \(f(x)\)인 띠만큼 늘어납니다. 그래서 \(g(x + h) - g(x) \approx f(x)\,h\)이고, \(h\)로 나누어 극한을 취하면 \(g'(x) = f(x)\)입니다.

정리 4.2.1 (미적분의 기본정리 1)

\(f\)가 \([a, b]\)에서 연속이면 \(g(x) = \int_a^x f(t)\,dt\)는 미분 가능하고 \(g'(x) = f(x)\)이다.

예제 4.2.2

(가) \(\dfrac{d}{dx}\int_0^x\sqrt{1 + t^2}\,dt\) (나) \(\dfrac{d}{dx}\int_1^{x^2}\cos t\,dt\)

풀이. (가) 정리 그대로 \(\sqrt{1 + x^2}\). 적분을 계산할 필요가 없습니다.

(나) 위끝이 \(x^2\)이므로 연쇄법칙을 씁니다. \(u = x^2\), \(G(u) = \int_1^u\cos t\,dt\)로 놓으면 \(\dfrac{d}{dx}G(x^2) = \cos(u)\cdot\dfrac{du}{dx} = 2x\cos(x^2)\).

일반적으로 \(\dfrac{d}{dx}\int_a^{h(x)}f(t)\,dt = f(h(x))\,h'(x)\)입니다. 위끝을 넣고, 위끝의 도함수를 곱합니다.

4.2.3기본정리 2: 정적분의 계산

정리 4.2.3 (미적분의 기본정리 2)

\(f\)가 \([a, b]\)에서 연속이고 \(F' = f\)이면 \(\displaystyle\int_a^b f(x)\,dx = F(b) - F(a)\)이다.

이유는 짧습니다. 기본정리 1의 \(g\)도 \(g' = f\)이므로 \(F\)와 \(g\)는 도함수가 같고, 3.2절의 정리에 의해 \(F = g + C\)입니다. 따라서 \(F(b) - F(a) = g(b) - g(a) = \int_a^b f\,dx - 0\).

\(F' = f\)인 \(F\)를 \(f\)의 부정적분(역도함수)이라 하고 \(\int f(x)\,dx = F(x) + C\)로 씁니다. 지금까지 배운 미분 공식을 거꾸로 읽으면 부정적분 표가 됩니다.

\(f(x)\)\(\int f(x)\,dx\)\(f(x)\)\(\int f(x)\,dx\)
\(x^n\) (\(n \ne -1\))\(\frac{x^{n+1}}{n+1}\)\(\frac1x\)\(\ln|x|\)
\(e^x\)\(e^x\)\(a^x\)\(\frac{a^x}{\ln a}\)
\(\sin x\)\(-\cos x\)\(\cos x\)\(\sin x\)
\(\sec^2 x\)\(\tan x\)\(\frac{1}{1 + x^2}\)\(\arctan x\)
\(\frac{1}{\sqrt{1 - x^2}}\)\(\arcsin x\)\(\cosh x\)\(\sinh x\)

(모두 \(+C\)를 붙입니다.)

예제 4.2.4

(가) \(\int_0^1 x^2\,dx\) (나) \(\int_1^e\frac1x\,dx\) (다) \(\int_0^1\frac{dx}{1 + x^2}\)

풀이. (가) \(\left[\frac{x^3}{3}\right]_0^1 = \frac13\). 4.1절에서 리만 합의 극한으로 힘들게 구한 값과 같습니다. (나) \([\ln x]_1^e = 1\). (다) \([\arctan x]_0^1 = \frac\pi4\).

(다)의 결과를 거꾸로 쓰면 \(\pi = 4\int_0^1\frac{dx}{1 + x^2}\)입니다. 넓이를 수치로 어림하면 \(\pi\)를 계산할 수 있다는 뜻이고, 실제로 컴퓨터가 \(\pi\)를 구하는 방법 가운데 하나가 이것과 관련 있습니다(8.7절의 급수).

주의기본정리 2는 \(f\)가 구간에서 연속일 때만 씁니다. \(\int_{-1}^1\frac{1}{x^2}dx\)를 \(\left[-\frac1x\right]_{-1}^1 = -2\)로 계산하면 틀립니다. \(x = 0\)에서 불연속이라 이 적분은 5.5절의 이상적분이고, 실제로는 발산합니다. 양수 함수의 적분이 음수가 나온 것이 이상하다는 신호입니다.
요약
  1. 기본정리 1: \(\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\). 위끝이 \(h(x)\)이면 \(f(h(x))h'(x)\).
  2. 기본정리 2: \(\int_a^b f\,dx = F(b) - F(a)\) (\(F' = f\), \(f\)는 연속).
  3. 미분 공식을 거꾸로 읽으면 부정적분 공식이다.
