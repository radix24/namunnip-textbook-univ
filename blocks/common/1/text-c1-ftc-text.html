미적분의 기본정리

본문

넓이를 리만 합의 극한으로 구하는 일은 \(y = x^2\) 하나에도 한 문단이 들었다. 그런데 고등학교에서는 부정적분의 값을 빼기만 하면 넓이가 나왔다. 기울기를 구하는 미분과 넓이를 구하는 적분은 왜 이렇게 이어져 있을까?

먼저 알아야 할 것정적분의 정의와 성질(4.1절), 연쇄법칙(2.2절), 그리고 평균값 정리에서 나온 "도함수가 같으면 상수만큼 다르다"(3.2절)를 쓴다.

4.2.1미분과 적분을 잇는 다리

미분은 접선의 기울기 문제에서, 적분은 넓이 문제에서 따로 출발했다. 두 문제는 전혀 달라 보이지만, 뉴턴과 라이프니츠는 둘이 서로 거꾸로 된 계산이라는 것을 알아냈다. 이 사실이 미적분의 기본정리이고, 덕분에 리만 합의 극한을 직접 계산하지 않고 부정적분으로 정적분을 구할 수 있다.

4.2.2기본정리 1: 넓이 함수의 도함수

\(f\)가 연속일 때 \(g(x) = \int_a^x f(t)\,dt\)는 \(a\)부터 \(x\)까지의 넓이이고, \(x\)를 바꾸면 넓이도 바뀌므로 \(x\)의 함수이다. 그림 1에서 \(x\)를 \(h\)만큼 늘리면 넓이는 폭 \(h\), 높이 약 \(f(x)\)인 띠만큼 늘어난다. 그래서 \(g(x + h) - g(x) \approx f(x)\,h\)이고, \(h\)로 나누어 극한을 취하면 \(g'(x) = f(x)\)이다. 그림에서 \(h\)를 0.4에서 0.02로 줄여 보면 띠의 위쪽 가장자리가 점점 평평해져 직사각형에 가까워지고, 읽은 값 \(\frac{g(x+h) - g(x)}{h}\)가 \(f(x)\)에 다가간다.

정리 4.2.1 (미적분의 기본정리 1)

\(f\)가 \([a, b]\)에서 연속이면 \(g(x) = \int_a^x f(t)\,dt\)는 미분 가능하고 \(g'(x) = f(x)\)이다.

다시 말해 넓이 함수가 늘어나는 빠르기는 그 자리의 높이이다. 높이가 클수록 같은 폭을 더할 때 넓이가 많이 늘기 때문이다.1

예제 4.2.2

(가) \(\dfrac{d}{dx}\int_0^x\sqrt{1 + t^2}\,dt\) (나) \(\dfrac{d}{dx}\int_1^{x^2}\cos t\,dt\)

풀이. (가) 정리 그대로 \(\sqrt{1 + x^2}\)이다. 적분을 계산할 필요가 없다.

(나) 위끝이 \(x^2\)이므로 연쇄법칙을 쓴다. \(u = x^2\), \(G(u) = \int_1^u\cos t\,dt\)로 놓으면 \(\dfrac{d}{dx}G(x^2) = \cos(u)\cdot\dfrac{du}{dx} = 2x\cos(x^2)\)이다. 일반적으로 \(\dfrac{d}{dx}\int_a^{h(x)}f(t)\,dt = f(h(x))\,h'(x)\)이다. 즉 위끝을 넣고, 위끝의 도함수를 곱한다. 그림 1의 말로 하면 위끝이 \(x^2\)이면 \(x\)를 조금 늘릴 때 띠의 폭이 \(h\)가 아니라 약 \(2xh\)가 되므로, 넓이가 그만큼 더 빨리 늘어난다.

4.2.3기본정리 2: 정적분의 계산

정리 4.2.3 (미적분의 기본정리 2)

\(f\)가 \([a, b]\)에서 연속이고 \(F' = f\)이면 \(\displaystyle\int_a^b f(x)\,dx = F(b) - F(a)\)이다.

이유는 짧다. 기본정리 1의 \(g\)도 \(g' = f\)이므로 \(F\)와 \(g\)는 도함수가 같고, 3.2절의 정리에 의해 \(F = g + C\)이다. 따라서 \(F(b) - F(a) = g(b) - g(a) = \int_a^b f\,dx - 0\)이다.

이때 \(F' = f\)인 \(F\)를 \(f\)의 부정적분(역도함수)이라 하고 \(\int f(x)\,dx = F(x) + C\)로 쓴다. 그러면 지금까지 배운 미분 공식을 거꾸로 읽은 것이 곧 부정적분 표가 된다. 아래 표의 값에는 모두 \(+C\)를 붙인다.

\(f(x)\)\(\int f(x)\,dx\)\(f(x)\)\(\int f(x)\,dx\)
\(x^n\) (\(n \ne -1\))\(\frac{x^{n+1}}{n+1}\)\(\frac1x\)\(\ln|x|\)
\(e^x\)\(e^x\)\(a^x\)\(\frac{a^x}{\ln a}\)
\(\sin x\)\(-\cos x\)\(\cos x\)\(\sin x\)
\(\sec^2 x\)\(\tan x\)\(\frac{1}{1 + x^2}\)\(\arctan x\)
\(\frac{1}{\sqrt{1 - x^2}}\)\(\arcsin x\)\(\cosh x\)\(\sinh x\)
예제 4.2.4

(가) \(\int_0^1 x^2\,dx\) (나) \(\int_1^e\frac1x\,dx\) (다) \(\int_0^1\frac{dx}{1 + x^2}\)

풀이. (가) \(\left[\frac{x^3}{3}\right]_0^1 = \frac13\)이다. 4.1절에서 리만 합의 극한으로 힘들게 구한 값과 같다. (나) \([\ln x]_1^e = 1\)이다. (다) \([\arctan x]_0^1 = \frac\pi4\)이다.

(다)의 결과를 거꾸로 쓰면 \(\pi = 4\int_0^1\frac{dx}{1 + x^2}\)이다. 그러므로 넓이를 수치로 어림하면 \(\pi\)를 계산할 수 있고, 실제로 컴퓨터가 \(\pi\)를 구하는 방법 가운데 하나가 이것과 관련 있다(8.7절의 급수).

주의기본정리 2는 \(f\)가 구간에서 연속일 때만 쓴다. \(\int_{-1}^1\frac{1}{x^2}dx\)를 \(\left[-\frac1x\right]_{-1}^1 = -2\)로 계산하면 틀린다. \(x = 0\)에서 불연속이라 이 적분은 5.5절의 이상적분이고, 실제로는 발산한다. 양수 함수의 적분이 음수로 나왔다는 것이 이상하다는 신호이다.
  1. 엄밀하게는 띠의 넓이가 \(h\)에 띠 위의 최솟값과 최댓값을 곱한 값 사이에 있음을 쓰고, \(f\)의 연속성으로 두 값이 모두 \(f(x)\)로 간다는 것을 압축 정리로 보인다.
마무리

넓이 함수 \(g(x) = \int_a^x f(t)\,dt\)는 \(x\)를 조금 늘릴 때 높이 \(f(x)\)인 띠만큼 늘어나므로 \(g' = f\)이다. 그래서 \(F' = f\)인 부정적분을 하나 찾으면 \(\int_a^b f\,dx = F(b) - F(a)\)로 정적분이 계산되고, 처음 질문처럼 미분과 적분은 서로 거꾸로 된 계산으로 이어진다. 다만 구간에서 연속이라는 가정을 확인하고 쓴다.
