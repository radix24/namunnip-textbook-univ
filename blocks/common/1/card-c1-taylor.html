Taylor 다항식과 나머지 항으로 오차 보장하기

Taylor 정리 · 라그랑주 나머지

아이디어

선형 근사(4-05)는 \(a\)에서 값과 기울기를 맞춘 일차식입니다. 2계, 3계, … 도함수까지 맞추면 더 가까운 다항식을 얻습니다.

\[T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x - a)^k.\]

계수에 \(k!\)이 있는 이유: \((x - a)^k\)를 \(k\)번 미분하면 \(k!\)이 되므로, \(T_n^{(k)}(a) = f^{(k)}(a)\)가 되도록 나눠 둔 것입니다.

정리 · Taylor (라그랑주 나머지)

\(f\)가 \(a\)와 \(x\)를 포함하는 구간에서 \(n + 1\)번 미분 가능하면, \(a\)와 \(x\) 사이의 어떤 \(c\)가 있어

\[f(x) - T_n(x) = R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x - a)^{n+1}.\]

\(n = 0\)이면 평균값 정리 그 자체입니다. 증명은 평균값 정리(롤 정리)를 보조 함수에 \(n+1\)번 되풀이해 씁니다. \(R_n(x) \to 0\) (\(n \to \infty\))이면 \(f\)는 Taylor 급수와 같습니다.

기본 급수 (\(a = 0\), Maclaurin)

함수급수수렴
\(e^x\)\(\sum\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \cdots\)모든 \(x\)
\(\sin x\)\(x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots\)모든 \(x\)
\(\cos x\)\(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\)모든 \(x\)
\(\frac{1}{1-x}\)\(1 + x + x^2 + \cdots\)\(|x| < 1\)
\(\ln(1 + x)\)\(x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots\)\(-1 < x \le 1\)
\(\arctan x\)\(x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\)\(|x| \le 1\)

뒤의 셋은 등비급수를 항별 적분해 얻습니다: \(\frac{1}{1 + t} = \sum(-t)^n\)을 \(0\)부터 \(x\)까지 적분하면 \(\ln(1 + x)\), \(\frac{1}{1 + t^2}\)이면 \(\arctan x\). \(x = 1\)을 넣으면 \(\ln2 = 1 - \frac12 + \frac13 - \cdots\), \(\frac\pi4 = 1 - \frac13 + \frac15 - \cdots\).

문제. (가) \(e^x\)의 Maclaurin 급수가 모든 \(x\)에서 \(e^x\)와 같음을 보이세요. (나) \(e\)를 오차 \(10^{-5}\) 이하로 구하려면 몇 차까지 필요한가요? (다) \(\sin x \approx x - \frac{x^3}{6}\)의 오차를 \(|x| \le 0.5\)에서 추정하세요.

풀이

  1. (가) \(f^{(k)}(x) = e^x\)이므로 \(f^{(k)}(0) = 1\), \(T_n(x) = \sum_{k=0}^n\frac{x^k}{k!}\).
    모든 도함수가 자기 자신.
  2. \(|R_n(x)| = \frac{e^c}{(n+1)!}|x|^{n+1} \le \frac{e^{|x|}|x|^{n+1}}{(n+1)!}\).
    \(c\)는 0과 \(x\) 사이라 \(e^c \le e^{|x|}\). \(c\)를 몰라도 위에서 누른다.
  3. 고정된 \(x\)에 대해 \(\frac{|x|^{n+1}}{(n+1)!} \to 0\). 따라서 \(R_n(x) \to 0\), \(e^x = \sum\frac{x^n}{n!}\).
    \(\sum\frac{|x|^n}{n!}\)이 비 판정으로 수렴(\(\rho = 0\))하므로 일반항이 0으로 간다(발산 판정의 대우).
  4. (나) \(x = 1\): \(|R_n(1)| \le \frac{e}{(n+1)!} < \frac{3}{(n+1)!}\). \(n = 8\)이면 \(\frac{3}{9!} = \frac{3}{362880} \approx 8.3\times10^{-6} < 10^{-5}\). (\(n = 7\)이면 \(\frac{3}{8!} \approx 7.4\times10^{-5}\)로 부족.)
    \(e < 3\)을 써서 모르는 \(e\)를 없앴다. \(T_8(1) = 2.718278\ldots\), 참값 \(2.718281\ldots\)
  5. (다) \(x - \frac{x^3}{6}\)은 \(T_3\)이자 \(T_4\)이다(\(x^4\) 계수가 0). \(R_4\)를 쓰면 \(|R_4(x)| = \frac{|\cos c|}{5!}|x|^5 \le \frac{0.5^5}{120} \approx 2.6\times10^{-4}\).
    \(\sin\)의 5계 도함수는 \(\cos\), \(|\cos c| \le 1\). \(T_4\)로 보면 \(R_3\)보다 좋은 한계를 얻는다.

의미

나머지 항 덕분에 근삿값이 몇 자리까지 맞는지 보장할 수 있습니다. 계산기가 \(e^x\), \(\sin x\)를 계산하는 방법이 이것이고, 물리의 "작은 진동", "약한 장" 근사는 모두 Taylor 다항식의 첫 한두 항입니다.

검산

(다) \(x = 0.5\): \(\sin0.5 = 0.479426\), \(0.5 - \frac{0.125}{6} = 0.479167\), 실제 오차 \(0.000259\). 한계 \(0.00026\)과 거의 같습니다(교대급수 오차 \(\le\) 다음 항 \(\frac{x^5}{120}\)과도 일치).

흔한 오해

  • "Taylor 급수가 수렴하면 원래 함수와 같다." \(f(x) = e^{-1/x^2}\ (x \ne 0)\), \(f(0) = 0\)은 모든 도함수가 0에서 0이라 Maclaurin 급수가 0이지만, \(f\)는 0이 아닙니다. \(R_n \to 0\)을 확인해야 합니다.
  • 수렴 구간 밖에서 쓰기: \(\ln(1 + x)\)의 급수에 \(x = 2\)를 넣으면 발산합니다.
