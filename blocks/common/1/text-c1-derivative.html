미분계수와 도함수

본문 · 3.1절
이 절에서 배울 것
  • 평균변화율의 극한으로 순간변화율(미분계수)을 정의한다.
  • 정의를 써서 미분계수와 도함수를 직접 구한다.
  • 미분 가능하면 연속이지만, 연속이라고 미분 가능하지는 않음을 증명과 반례로 이해한다.
먼저 알아야 할 것
  • 함수의 극한과 극한 법칙 (2.2절), 특히 한쪽 극한.
  • 연속의 정의 (2.3절): \(\lim_{x\to a}f(x) = f(a)\).
  • 직선의 기울기: 두 점 \((x_1, y_1), (x_2, y_2)\)를 지나는 직선의 기울기는 \(\frac{y_2 - y_1}{x_2 - x_1}\).

3.1.1평균 속도에서 순간 속도로

공을 떨어뜨리면 \(t\)초 뒤 떨어진 거리가 대략 \(s(t) = 4.9t^2\) m입니다. 처음 2초 동안 공은 \(s(2) - s(0) = 19.6\) m를 갔으므로, 그동안의 평균 속도는 \(\frac{19.6}{2} = 9.8\) m/s입니다.

그런데 "정확히 \(t = 2\)인 순간의 속도"는 무엇일까요? 한 순간에는 움직인 거리도 걸린 시간도 0이라, 나눗셈 \(\frac00\)으로는 답할 수 없습니다. 대신 \(t = 2\)부터 아주 짧은 시간 \(h\) 동안의 평균 속도를 계산해 봅니다.

\[\frac{s(2 + h) - s(2)}{h} = \frac{4.9(4 + 4h + h^2) - 19.6}{h} = \frac{19.6h + 4.9h^2}{h} = 19.6 + 4.9h \qquad (h \ne 0).\]

\(h\)를 0.1, 0.01, 0.001로 줄이면 평균 속도는 20.09, 19.649, 19.6049 m/s로 19.6에 한없이 다가갑니다. \(h\)가 음수여도(2초 직전 구간) 마찬가지입니다. 이 극한값 19.6 m/s를 \(t = 2\)에서의 순간 속도라고 부르는 것이 자연스럽습니다. 핵심은 \(h \ne 0\)일 때 먼저 식을 정리해 \(h\)를 약분하고, 그다음 극한을 취했다는 것입니다.

이 생각은 속도에만 쓰이지 않습니다. 함수의 값이 입력에 따라 얼마나 빨리 변하는지 묻는 모든 곳(비용의 증가율, 반응 속도, 곡선의 기울기)에 같은 방법을 씁니다. 그래서 함수 일반에 대해 정의합니다.

3.1.2미분계수의 정의

정의 3.1.1 (미분계수)

함수 \(f\)가 점 \(a\)를 포함하는 열린구간에서 정의되어 있다고 하자. 극한

\[f'(a) = \lim_{h\to0}\frac{f(a + h) - f(a)}{h}\]

가 존재하면 \(f\)는 \(a\)에서 미분 가능하다고 하고, 이 값을 \(a\)에서의 미분계수라고 한다.

정의의 각 부분이 무엇을 뜻하는지 차례로 봅시다. 분수 \(\frac{f(a+h) - f(a)}{h}\)는 그래프 위의 두 점 \((a, f(a))\)와 \((a + h, f(a + h))\)를 잇는 직선(할선)의 기울기이고, 구간 \([a, a+h]\)에서의 평균변화율입니다. \(h \to 0\)은 두 번째 점을 첫 번째 점 쪽으로 끌어오는 것이고, 그때 할선이 다가가는 직선이 접선입니다. 그래서 미분계수는 \(x = a\)에서의 접선의 기울기이며, 접선의 방정식은 \(y = f(a) + f'(a)(x - a)\)입니다.

"열린구간에서 정의되어 있다"는 조건은 \(h\)가 양수와 음수 양쪽에서 0으로 갈 수 있게 하려는 것입니다. 극한은 양쪽 극한이 모두 존재하고 같을 때만 존재하므로(2.2절), 미분 가능하려면 오른쪽에서 잰 기울기와 왼쪽에서 잰 기울기가 같아야 합니다.

\(x = a + h\)로 바꾸어 쓰면 같은 정의를 \(f'(a) = \lim_{x\to a}\frac{f(x) - f(a)}{x - a}\)로 쓸 수도 있습니다. 문제에 따라 편한 쪽을 씁니다.

예제 3.1.2

\(f(x) = x^2 - 3x\)의 \(x = 1\)에서의 미분계수와 접선을 구하여라.

풀이. 정의에 넣고, 분자를 정리해 \(h\)를 약분한 뒤 극한을 취합니다.

\[\frac{f(1 + h) - f(1)}{h} = \frac{(1 + h)^2 - 3(1 + h) - (-2)}{h} = \frac{-h + h^2}{h} = -1 + h \;\to\; -1.\]

따라서 \(f'(1) = -1\)이고, \(f(1) = -2\)이므로 접선은 \(y = -2 - (x - 1)\), 곧 \(y = -x - 1\)입니다. 검산 삼아 접선과 곡선의 교점을 구하면 \(x^2 - 3x = -x - 1\), 곧 \((x - 1)^2 = 0\)이라 \(x = 1\)에서만 만나고(중근), 접선답게 곡선에 닿기만 합니다.

3.1.3도함수

예제 3.1.2의 계산을 점 \(1\) 대신 임의의 점 \(x\)에서 하면, 미분계수가 \(x\)에 따라 어떻게 변하는지 알려 주는 새로운 함수를 얻습니다.

정의 3.1.3 (도함수)

\(f\)가 미분 가능한 각 점 \(x\)에 미분계수 \(f'(x)\)를 대응시킨 함수 \(f'\)을 \(f\)의 도함수라 한다. 도함수를 구하는 일을 미분한다고 한다. \(f'(x)\)를 \(\frac{df}{dx}\), \(\frac{dy}{dx}\) (\(y = f(x)\)), \(Df(x)\)로도 쓴다.

표기 \(\frac{dy}{dx}\)는 라이프니츠의 것으로, "\(y\)의 아주 작은 변화 \(dy\)와 \(x\)의 아주 작은 변화 \(dx\)의 비"라는 직관을 담고 있습니다. 엄밀하게는 하나의 기호이지 분수가 아니지만, 연쇄 법칙(3.2절)과 치환적분(5.3절)에서 분수처럼 다뤄도 맞는 결과가 나오도록 잘 만들어진 기호입니다.

예제 3.1.4

\(f(x) = \sqrt x\)의 도함수를 구하고, \(x = 0\)에서 미분 가능한지 판정하여라.

풀이. \(x > 0\)일 때 분자에 근호가 있어 그대로는 \(h\)를 약분할 수 없으므로, 분자와 분모에 \(\sqrt{x + h} + \sqrt x\)를 곱해 분자를 유리화합니다.

\[\frac{\sqrt{x + h} - \sqrt x}{h} = \frac{(x + h) - x}{h\left(\sqrt{x + h} + \sqrt x\right)} = \frac{1}{\sqrt{x + h} + \sqrt x} \;\to\; \frac{1}{2\sqrt x}.\]

마지막 단계에서 \(\sqrt{\ }\)가 연속이라 \(\sqrt{x + h} \to \sqrt x\)임을 썼습니다. 따라서 \(x > 0\)에서 \(f'(x) = \frac{1}{2\sqrt x}\).

\(x = 0\)에서는 \(f\)가 \(x \ge 0\)에서만 정의되어 왼쪽 극한을 생각할 수 없고, 오른쪽에서도 \(\frac{\sqrt h - 0}{h} = \frac{1}{\sqrt h} \to \infty\)입니다. 극한이 유한하지 않으므로 미분 가능하지 않습니다. 그래프로는 원점에서 접선이 수직으로 서 있습니다.

3.1.4미분 가능성과 연속성

그래프가 "매끄럽다"는 것과 "끊어지지 않았다"는 것은 어떤 관계일까요? 다음 정리는 한쪽 방향이 늘 성립함을 말합니다.

정리 3.1.5

\(f\)가 \(a\)에서 미분 가능하면, \(f\)는 \(a\)에서 연속이다.

증명.연속임을 보이려면 \(\lim_{h\to0}f(a + h) = f(a)\), 곧 \(\lim_{h\to0}\left[f(a + h) - f(a)\right] = 0\)을 보이면 된다(\(x = a + h\)로 바꾼 연속의 정의). \(h \ne 0\)이면 \(h\)를 곱하고 나누어

\[f(a + h) - f(a) = \frac{f(a + h) - f(a)}{h}\cdot h\]

로 쓸 수 있다. 가정에 의해 \(h \to 0\)일 때 첫째 인수는 \(f'(a)\)로 수렴하고, 둘째 인수는 0으로 수렴한다. 두 극한이 모두 존재하므로 극한의 곱셈 법칙(2.2절)을 쓸 수 있고, 따라서 \(f(a + h) - f(a) \to f'(a)\cdot0 = 0\)이다. ∎

증명에서 미분 가능성 가정이 쓰인 곳은 단 한 곳, "첫째 인수의 극한이 존재한다"입니다. 이 가정이 없으면 곱셈 법칙을 쓸 수 없습니다. 실제로 거꾸로는 성립하지 않습니다.

예제 3.1.6 (연속이지만 미분 불가능)

\(f(x) = |x|\)는 \(x = 0\)에서 연속이지만 미분 가능하지 않음을 보여라.

풀이. \(\lim_{x\to0}|x| = 0 = f(0)\)이므로 연속입니다. 미분계수의 정의에서 \(\frac{|h| - 0}{h}\)는 \(h > 0\)이면 1, \(h < 0\)이면 −1입니다. 오른쪽 극한 1과 왼쪽 극한 −1이 달라 극한이 존재하지 않으므로 미분 불가능합니다. 그래프는 원점에서 꺾여 있어, 오른쪽에서 본 접선과 왼쪽에서 본 접선이 다릅니다.

정리 3.1.5의 대우 "불연속이면 미분 불가능"은 판정에 바로 쓸 수 있습니다. 그러나 "연속이니까 미분 가능"은 예제 3.1.6 때문에 쓸 수 없습니다. 19세기에 바이어슈트라스는 모든 점에서 연속이지만 어느 점에서도 미분 가능하지 않은 함수까지 만들어 보였습니다.

주의구간별로 정의된 함수의 경계점에서는 도함수 공식이 통하지 않습니다. \(f(x) = x^2\) (\(x \le 1\)), \(2x - 1\) (\(x > 1\))은 양쪽에서 공식으로 구한 기울기가 모두 2라서 미분 가능해 보이지만, 그것만으로는 부족하고 먼저 \(x = 1\)에서 연속인지(\(1 = 1\))를 확인한 뒤 정의의 양쪽 극한을 직접 계산해야 합니다. 연속이 아니면 기울기가 같아도 미분 불가능합니다.
요약
  1. 미분계수 \(f'(a) = \lim_{h\to0}\frac{f(a+h) - f(a)}{h}\)는 평균변화율의 극한, 곧 접선의 기울기이다.
  2. 계산할 때는 \(h \ne 0\)에서 식을 정리해 \(h\)를 약분한 뒤 극한을 취한다. 근호가 있으면 유리화한다.
  3. 미분 가능하면 연속이다. 거꾸로는 성립하지 않는다(\(|x|\)).
  4. 미분 불가능한 전형: 꺾인 점, 수직 접선, 불연속점.

3.1.5연습문제

기본

  1. 정의를 써서 \(f(x) = 3x^2 + 1\)의 도함수를 구하여라.
    힌트

    \(f(x + h) - f(x) = 6xh + 3h^2\).

    답

    \(f'(x) = \lim_{h\to0}(6x + 3h) = 6x\).

  2. \(f(x) = \frac1x\)의 \(x = 2\)에서의 접선의 방정식을 구하여라.
    힌트

    \(\frac{1}{2+h} - \frac12 = \frac{-h}{2(2+h)}\).

    답

    \(f'(2) = -\frac14\), 접선 \(y = \frac12 - \frac14(x - 2)\), 곧 \(y = -\frac x4 + 1\).

  3. 위치가 \(s(t) = t^3\) (m)인 물체의 \(t = 1\)에서 \(t = 1 + h\)까지의 평균 속도를 \(h\)의 식으로 쓰고, \(t = 1\)에서의 순간 속도를 구하여라.
    답

    평균 속도 \(3 + 3h + h^2\), 순간 속도 3 m/s.

응용

  1. \(f(x) = x|x|\)는 \(x = 0\)에서 미분 가능한가? 미분 가능하면 \(f'(0)\)을 구하여라.
    힌트

    \(\frac{f(h) - f(0)}{h} = |h|\).

    답

    미분 가능, \(f'(0) = 0\). \(|x|\)의 꺾인 점이 \(x\)를 곱해 펴진다.

  2. \(f(x) = ax + b\) (\(x < 1\)), \(x^2\) (\(x \ge 1\))이 \(x = 1\)에서 미분 가능하도록 \(a, b\)를 정하여라.
    힌트

    먼저 연속 조건, 다음으로 양쪽 기울기가 같다는 조건.

    답

    연속: \(a + b = 1\). 오른쪽 미분계수 2, 왼쪽 \(a\)이므로 \(a = 2\), \(b = -1\).

심화

  1. \(f(x) = x^2\sin\frac1x\) (\(x \ne 0\)), \(f(0) = 0\)이 \(x = 0\)에서 미분 가능함을 보이고, \(f'\)이 \(x = 0\)에서 연속이 아님을 보여라.
    힌트

    정의의 몫은 \(h\sin\frac1h\)이고 \(|h\sin\frac1h| \le |h|\) (압축 정리). \(x \ne 0\)에서는 곱의 법칙과 연쇄 법칙(3.2절)을 쓴다.

    답

    \(f'(0) = 0\). \(x \ne 0\)이면 \(f'(x) = 2x\sin\frac1x - \cos\frac1x\)인데 \(x \to 0\)일 때 \(\cos\frac1x\)가 진동해 극한이 없다. 도함수는 존재해도 연속이 아닐 수 있다.
