컴퓨터로 미분과 적분 확인하기

본문 · 4.4절

도함수의 정의에서 극한만 빼면 \(\frac{f(a + h) - f(a)}{h}\)라는 계산할 수 있는 식이 남는다. 그렇다면 컴퓨터로 \(h\)를 \(10^{-15}\)처럼 아주 작게 잡으면 도함수를 거의 정확히 얻을 수 있을까?

먼저 알아야 할 것도함수의 정의(2.1절), 리만 합과 정적분(4.1절), 미적분의 기본정리(4.2절)를 쓴다. 파이썬을 처음 쓴다면 전자계산(1) 1.1절의 설치와 첫 프로그램만 먼저 보면 충분하다.

왜 컴퓨터로 확인하는가

\(\int_0^2 e^{-x^2}dx\)는 원시함수를 기본 함수로 쓸 수 없고, 실험에서 얻은 자료는 식조차 없다. 그래도 값은 필요하다. 또 손으로 푼 답이 맞는지 확인하는 가장 빠른 방법은 컴퓨터로 같은 양을 근사해 보는 것이다. 다행히 미분과 적분의 정의 자체가 계산 방법을 알려 준다. 극한을 취하기 직전의 식을 작은 간격으로 계산하면 된다.

4.4.1차분으로 도함수 어림하기

도함수의 정의 \(f'(a) = \lim_{h\to0}\dfrac{f(a + h) - f(a)}h\)에서 극한을 빼면 계산할 수 있는 식이 남는다. 정의 그대로의 식 \(D_+(h) = \dfrac{f(a + h) - f(a)}h\)를 앞쪽 차분이라 한다. 한편 양쪽으로 같은 거리만큼 나간 할선의 기울기 \(D_0(h) = \dfrac{f(a + h) - f(a - h)}{2h}\)를 가운데 차분이라 한다.

두 식이 \(f'(a)\)와 얼마나 다른지는 테일러 전개(8.8절) \(f(a \pm h) = f(a) \pm hf'(a) + \tfrac{h^2}2f''(a) \pm \tfrac{h^3}6f'''(a) + \cdots\)로 알 수 있다.

정리 4.4.1 (차분의 절단 오차)

\(D_+(h) - f'(a) \approx \dfrac h2f''(a)\), \(D_0(h) - f'(a) \approx \dfrac{h^2}6f'''(a)\).

증명.\(f(a + h) - f(a) = hf'(a) + \tfrac{h^2}2f''(a) + \cdots\)를 \(h\)로 나누면 \(D_+ = f'(a) + \tfrac h2f''(a) + \cdots\)이다. 한편 \(f(a + h) - f(a - h)\)에서는 짝수 차 항(\(f(a)\), \(h^2\) 항)이 지워지고 \(2hf'(a) + \tfrac{h^3}3f'''(a) + \cdots\)가 남으므로, \(2h\)로 나누면 \(D_0 = f'(a) + \tfrac{h^2}6f'''(a) + \cdots\)이다. ∎

그래서 \(h\)를 10분의 1로 줄이면 앞쪽 차분의 오차는 10분의 1, 가운데 차분의 오차는 100분의 1이 된다. 즉 같은 계산량으로 가운데 차분이 훨씬 정확하다. 그림 1의 오른쪽 절반에서 두 선의 기울기가 1과 2로 다른 것이 이 차이이다. 로그 눈금에서는 오차가 \(h\)의 몇 제곱에 비례하는지가 선의 기울기로 바로 읽히므로, 수치 계산에서 새 방법을 시험할 때도 이런 그래프를 먼저 그려 본다. 기울기가 예상과 다르면 공식이나 코드 어딘가가 틀렸다는 신호이다.

예제 4.4.2

\(f(x) = \sin x\), \(a = 1\), \(h = 0.01\)일 때 두 차분의 값과 오차를 구하여라.

풀이. 참값은 \(\cos1 = 0.540302\ldots\)이다. \(D_+ = \dfrac{\sin1.01 - \sin1}{0.01} = 0.536086\)이므로 오차는 \(-4.22\times10^{-3}\)이고, 정리 4.4.1의 예측 \(\tfrac{0.01}2(-\sin1) = -4.21\times10^{-3}\)과 맞는다. \(D_0 = 0.540293\)이므로 오차는 \(-9.0\times10^{-6}\)이고, 예측 \(\tfrac{0.0001}6(-\cos1) = -9.0\times10^{-6}\)과 맞는다.

4.4.2간격을 너무 줄이면 생기는 일

그렇다면 처음 질문처럼 \(h = 10^{-15}\)으로 아주 작게 하면 될까? 컴퓨터의 실수(배정밀도)는 유효숫자가 약 16자리이다. \(\sin1.000000000000001\)과 \(\sin1\)은 앞의 15자리가 같아서, 빼면 믿을 수 있는 자리가 거의 남지 않는다. 이 반올림 오차는 대략 \(\dfrac{10^{-16}}h\)이라서 \(h\)가 작을수록 커진다. 따라서 절단 오차(\(h\)나 \(h^2\)에 비례)와 반올림 오차(\(\frac1h\)에 비례)의 합은 어느 \(h\)에서 가장 작아지고, 그림 1의 V자 바닥이 그곳이다. 앞쪽 차분은 \(h \approx 10^{-8}\), 가운데 차분은 \(h \approx 10^{-5}\) 근처가 바닥이다.

그러므로 수학의 극한 \(h \to 0\)과 컴퓨터의 "작은 \(h\)"는 다르다. 수치 계산에서는 언제나 알맞은 크기를 골라야 하고, 결과가 \(h\)를 조금 바꿔도 안정한지 확인해야 한다.

4.4.3리만 합으로 정적분 어림하기

정적분은 리만 합의 극한이다(4.1절). 구간을 \(n\)등분하고 각 칸의 가운데 점 높이를 쓰는 가운데 합 \(M_n = h\sum_{i=1}^nf\!\left(a + (i - \tfrac12)h\right)\), \(h = (b - a)/n\)이 간단하면서 정확하고, 오차는 \(h^2\)에 비례한다. 더 정확한 사다리꼴 공식과 심프슨 공식은 5.6절에서 다룬다.

예제 4.4.3

\(\int_0^2e^{-x^2}dx\)를 가운데 합으로 \(n = 10, 100\)일 때 계산하는 파이썬 코드를 쓰고, 결과를 해석하여라.

import math
def midpoint(f, a, b, n):
    h = (b - a) / n
    return h * sum(f(a + (i - 0.5) * h) for i in range(1, n + 1))
f = lambda x: math.exp(-x * x)
for n in (10, 100):
    print(n, midpoint(f, 0, 2, n))
# 10  0.882202...   100  0.882083...   (참값 0.882081...)

풀이. \(n = 10\)에서 0.882202, \(n = 100\)에서 0.882083이다. 즉 \(n\)을 10배 하면 오차가 \(1.2\times10^{-4}\)에서 \(1.2\times10^{-6}\)으로 약 100분의 1이 된다. 참값은 \(\tfrac{\sqrt\pi}2\operatorname{erf}(2) = 0.882081\)이고, 정규분포의 확률 계산(통계학 입문 5.2절)이 바로 이런 적분이다.

4.4.4검산 습관

손 계산과 컴퓨터 계산은 서로를 검산한다. 가령 손으로 \(\frac{d}{dx}\int_0^{x^2}\cos t\,dt = 2x\cos x^2\)을 얻었다면, \(F(x) = \int_0^{x^2}\cos t\,dt = \sin x^2\)을 \(x = 1\)에서 가운데 차분으로 미분해 \(2\cos1 = 1.0806\)과 같은지 확인할 수 있다. 그래프를 그려 보는 것도 좋은 검산이다. 극값의 위치, 부호, 대칭이 답과 맞는지 눈으로 본다. 반대로 컴퓨터가 낸 값이 이상해 보일 때는 손 계산이 원인을 짚어 준다. 앞에서 \(h\)를 지나치게 줄인 차분이 엉뚱한 값을 냈을 때, 테일러 전개로 오차의 크기를 미리 알고 있었기에 그것이 공식의 잘못이 아니라 반올림 때문임을 알아챌 수 있었다.

이 절은 미적분학 연습문제를 컴퓨터로 풀어 보는 보충 절이다. 이 절 뒤의 실습 카드에서 \(h\)를 직접 바꾸며 그림 1의 V자 그래프를 만들어 볼 수 있다.

마무리

도함수는 차분으로, 정적분은 리만 합으로 어림하며, 가운데 차분과 가운데 합은 간격을 10분의 1로 줄일 때 오차가 100분의 1로 준다. 그러나 컴퓨터 실수의 유효숫자는 약 16자리이므로, 처음 질문처럼 \(h\)를 \(10^{-15}\)까지 줄이면 반올림 오차가 커져 오히려 부정확해진다. 그래서 알맞은 \(h\)를 고르고, 손 계산의 답은 수치와 그래프로 검산한다.

연습문제
  1. 기본 \(f(x) = x^3\), \(a = 2\), \(h = 0.1\)에서 앞쪽 차분과 가운데 차분을 손으로 계산하고 참값 12와 비교하여라.
    답\(D_+ = (9.261 - 8)/0.1 = 12.61\), \(D_0 = (9.261 - 6.859)/0.2 = 12.01\). 가운데 차분의 오차 0.01은 \(h^2f'''/6 = 0.01\)과 같다.
  2. 응용 \(\int_0^1\sqrt x\,dx = 2/3\)을 가운데 합으로 계산하면 \(n\)을 10배 해도 오차가 100분의 1로 줄지 않는다. 이유는?
    답\(\sqrt x\)는 \(x = 0\)에서 도함수가 무한대라 오차 공식의 가정(이계도함수가 유계)이 깨진다. 오차는 대략 \(n^{-1.5}\)로 줄어 10배마다 약 30분의 1이다.
  3. 심화 앞쪽 차분의 전체 오차를 \(E(h) = \dfrac h2M + \dfrac{\varepsilon}h\)(\(M = |f''|\), \(\varepsilon \approx 10^{-16}\))로 보고, \(E\)를 최소로 하는 \(h\)를 구하여라.
    답\(E'(h) = M/2 - \varepsilon/h^2 = 0\)에서 \(h = \sqrt{2\varepsilon/M} \approx 1.4\times10^{-8}\) (\(M \approx 1\)).
