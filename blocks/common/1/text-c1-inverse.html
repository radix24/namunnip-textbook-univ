역함수와 역삼각함수

본문 · 1.3절
이 절에서 배울 것
  • 역함수가 존재할 조건(일대일 대응)을 판정한다.
  • 정의역을 제한해 일대일이 아닌 함수에서 역함수를 만든다.
  • \(\arcsin\), \(\arccos\), \(\arctan\)의 정의역과 치역을 정하고 값을 구한다.
먼저 알아야 할 것
  • 함수, 정의역, 치역, 합성함수 \(g \circ f\) (고교 수학).
  • 역함수의 뜻과 그래프가 직선 \(y = x\)에 대칭이라는 사실 (고교 수학).
  • 삼각함수 \(\sin, \cos, \tan\)의 정의, 그래프, 주기, 특수각의 값 (고교 수학I).

1.3.1되돌리는 함수

섭씨 온도 \(C\)를 화씨로 바꾸는 함수는 \(F = f(C) = \frac95 C + 32\)입니다. 거꾸로 화씨를 섭씨로 바꾸려면 식을 \(C\)에 대해 풀면 됩니다: \(C = \frac59(F - 32)\). 이렇게 "출력에서 입력을 되찾는" 함수가 역함수입니다.

그런데 모든 함수를 되돌릴 수 있지는 않습니다. \(f(x) = x^2\)에서 출력이 4라면 입력은 2였을까요, \(-2\)였을까요? 알 수 없습니다. 두 입력이 같은 출력을 내면 출력만 보고는 입력을 하나로 정할 수 없습니다. 이 관찰이 역함수의 존재 조건입니다.

1.3.2일대일 함수와 역함수

정의 1.3.1 (일대일 함수)

함수 \(f\)의 정의역의 서로 다른 두 원소 \(x_1 \ne x_2\)에 대해 언제나 \(f(x_1) \ne f(x_2)\)이면 \(f\)를 일대일이라 한다. 같은 말로, \(f(x_1) = f(x_2)\)이면 \(x_1 = x_2\)이다.

정의 1.3.2 (역함수)

정의역이 \(A\), 치역이 \(B\)인 일대일 함수 \(f\)에 대하여, 각 \(y \in B\)에 \(f(x) = y\)인 단 하나의 \(x \in A\)를 대응시키는 함수를 \(f\)의 역함수라 하고 \(f^{-1}\)로 쓴다. 곧

\[f^{-1}(y) = x \iff f(x) = y.\]

정의에서 \(f^{-1}\)의 정의역은 \(f\)의 치역 \(B\)이고, \(f^{-1}\)의 치역은 \(f\)의 정의역 \(A\)입니다. 입력과 출력의 역할이 통째로 바뀝니다. 그래서 다음이 성립합니다.

\[f^{-1}(f(x)) = x \quad (x \in A), \qquad f(f^{-1}(y)) = y \quad (y \in B).\]

기호 \(f^{-1}\)의 \(-1\)은 지수가 아닙니다. \(f^{-1}(x)\)와 \(\frac{1}{f(x)}\)는 전혀 다른 것입니다. 예를 들어 \(f(x) = 2x\)이면 \(f^{-1}(x) = \frac x2\)이지만 \(\frac{1}{f(x)} = \frac{1}{2x}\)입니다.

일대일인지 그래프로 판정하는 방법이 있습니다. 수평선 판정법: 모든 수평선이 그래프와 많아야 한 번 만나면 일대일입니다. 두 번 만나는 수평선 \(y = c\)가 있으면 서로 다른 두 입력이 같은 출력 \(c\)를 낸다는 뜻이기 때문입니다. 특히 정의역 전체에서 증가하거나(\(x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\)) 감소하는 함수는 일대일입니다.

예제 1.3.3

\(f(x) = \frac{2x + 1}{x - 3}\) (\(x \ne 3\))이 일대일임을 보이고 역함수를 구하여라.

풀이. \(f(x_1) = f(x_2)\)라 하고 \(x_1 = x_2\)를 이끌어 냅니다. 분모를 곱해 정리하면

\[(2x_1 + 1)(x_2 - 3) = (2x_2 + 1)(x_1 - 3)\] \[\Rightarrow\ -6x_1 + x_2 = -6x_2 + x_1 \ \Rightarrow\ 7x_2 = 7x_1.\]

따라서 \(x_1 = x_2\)이고 일대일입니다. 역함수는 \(y = \frac{2x + 1}{x - 3}\)을 \(x\)에 대해 풉니다: \(y(x - 3) = 2x + 1\), \(x(y - 2) = 3y + 1\), \(x = \frac{3y + 1}{y - 2}\). 변수 이름을 관습대로 \(x\)로 바꾸어 \(f^{-1}(x) = \frac{3x + 1}{x - 2}\) (\(x \ne 2\))입니다. 치역에 2가 없다는 것(\(y = 2\)이면 \(0 = 7\)이 되어 풀리지 않음)도 이 계산에서 함께 나옵니다.

1.3.3정의역을 잘라 역함수 만들기

\(f(x) = x^2\)은 실수 전체에서 일대일이 아니지만, 정의역을 \([0, \infty)\)로 제한하면 증가함수가 되어 일대일입니다. 그 역함수가 \(\sqrt x\)입니다. 정의역을 \((-\infty, 0]\)으로 제한하면 역함수는 \(-\sqrt x\)가 됩니다. 어느 쪽으로 자르느냐에 따라 역함수가 달라지므로, 어디로 잘랐는지가 역함수 정의의 일부입니다.

삼각함수는 주기함수라서 같은 값을 무한히 반복합니다. 그래서 역함수를 만들려면 반드시 정의역을 잘라야 하고, 수학자들이 관습으로 정한 구간이 있습니다. 고르는 기준은 세 가지입니다. (1) 그 구간에서 증가하거나 감소할 것, (2) 함수가 가질 수 있는 모든 값을 한 번씩 가질 것, (3) 0 근처의 익숙한 각을 포함할 것.

1.3.4역삼각함수

정의 1.3.4 (역사인, 역코사인, 역탄젠트)
  • \(\sin\)을 \(\left[-\frac\pi2, \frac\pi2\right]\)로 제한한 함수의 역함수를 \(\arcsin\)이라 한다. 정의역 \([-1, 1]\), 치역 \(\left[-\frac\pi2, \frac\pi2\right]\).
  • \(\cos\)을 \([0, \pi]\)로 제한한 함수의 역함수를 \(\arccos\)이라 한다. 정의역 \([-1, 1]\), 치역 \([0, \pi]\).
  • \(\tan\)을 \(\left(-\frac\pi2, \frac\pi2\right)\)로 제한한 함수의 역함수를 \(\arctan\)이라 한다. 정의역 \(\mathbb{R}\), 치역 \(\left(-\frac\pi2, \frac\pi2\right)\).

읽는 법: \(\arcsin x\)는 "사인 값이 \(x\)인 각, 단 \(-\frac\pi2\)와 \(\frac\pi2\) 사이에서 고른 것"입니다. 각은 라디안으로 잽니다. \(\sin^{-1}x\)라고도 쓰지만, 앞에서 말했듯 \(\frac{1}{\sin x}\)과 헷갈리기 쉬워 이 책에서는 \(\arcsin\)을 씁니다.

왜 이 구간들일까요? \(\sin\)은 \(\left[-\frac\pi2, \frac\pi2\right]\)에서 \(-1\)부터 1까지 증가하며 모든 값을 한 번씩 지납니다. \(\cos\)은 그 구간에서 증가하지 않으므로(0에서 최댓값) 대신 \([0, \pi]\)에서 1부터 \(-1\)까지 감소하는 부분을 씁니다. \(\tan\)은 \(\pm\frac\pi2\)에서 정의되지 않으므로 열린구간입니다.

예제 1.3.5

다음 값을 구하여라. (가) \(\arcsin\left(-\frac12\right)\) (나) \(\arccos\left(-\frac{\sqrt2}{2}\right)\) (다) \(\arctan\sqrt3\)

풀이. 각각 "값이 주어진 수인 각"을 정해진 치역 안에서 찾습니다.

(가) \(\sin\theta = -\frac12\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)인 \(\theta\)는 \(-\frac\pi6\)입니다. \(\frac{7\pi}{6}\)도 사인 값이 \(-\frac12\)이지만 치역 밖입니다.

(나) \(\cos\theta = -\frac{\sqrt2}{2}\)이고 \(0 \le \theta \le \pi\)인 \(\theta\)는 \(\frac{3\pi}{4}\)입니다. \(-\frac{3\pi}{4}\)는 치역 밖입니다.

(다) \(\tan\theta = \sqrt3\)이고 \(-\frac\pi2 < \theta < \frac\pi2\)인 \(\theta\)는 \(\frac\pi3\)입니다.

역함수의 두 등식 \(f^{-1}(f(x)) = x\), \(f(f^{-1}(y)) = y\)는 각각 정의된 범위에서만 성립합니다. 역삼각함수에서 이 점이 특히 중요합니다.

예제 1.3.6

\(\arcsin(\sin 2)\)를 구하여라. 왜 2가 아닌가?

풀이. \(\arcsin(\sin x) = x\)는 \(x\)가 \(\left[-\frac\pi2, \frac\pi2\right]\)에 있을 때만 성립합니다. \(\frac\pi2 \approx 1.571\)이므로 \(2\)는 그 범위 밖입니다. 그래서 \(\sin\theta = \sin 2\)이고 \(\theta \in \left[-\frac\pi2, \frac\pi2\right]\)인 다른 각을 찾아야 합니다. \(\sin(\pi - x) = \sin x\)이므로 \(\theta = \pi - 2 \approx 1.142\)가 조건을 만족합니다. 따라서 \(\arcsin(\sin 2) = \pi - 2\)입니다.

반대 방향 \(\sin(\arcsin y) = y\)는 \(\arcsin\)이 정의되는 모든 \(y \in [-1, 1]\)에서 성립합니다. 두 방향이 대칭이 아니라는 점을 기억하세요.

예제 1.3.7

\(\cos(\arcsin x)\)를 \(x\)의 식으로 나타내어라 (\(-1 \le x \le 1\)).

풀이. \(\theta = \arcsin x\)로 놓으면 \(\sin\theta = x\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)입니다. \(\sin^2\theta + \cos^2\theta = 1\)에서 \(\cos\theta = \pm\sqrt{1 - x^2}\)인데, 이 범위의 \(\theta\)에서는 \(\cos\theta \ge 0\)이므로 부호는 +입니다. 답: \(\cos(\arcsin x) = \sqrt{1 - x^2}\). 이 식은 3.4절에서 \(\arcsin\)을 미분할 때 다시 씁니다.

주의"\(\arcsin\)과 \(\sin\)은 서로 상쇄된다"고만 기억하면 예제 1.3.6 같은 문제에서 틀립니다. 역삼각함수의 값은 언제나 정해진 치역 안에 있어야 합니다. 답을 낸 뒤 치역 안에 있는지 확인하는 습관을 들이세요.
요약
  1. 역함수는 일대일 함수에만 있다. 수평선 판정법, 증가·감소로 확인한다.
  2. \(f^{-1}\)의 정의역은 \(f\)의 치역, 치역은 \(f\)의 정의역이다. \(f^{-1} \ne \frac1f\).
  3. 일대일이 아니면 정의역을 잘라 역함수를 만든다. 자른 구간이 역함수의 치역이 된다.
  4. \(\arcsin\): \([-1,1] \to [-\frac\pi2, \frac\pi2]\), \(\arccos\): \([-1,1] \to [0, \pi]\), \(\arctan\): \(\mathbb{R} \to (-\frac\pi2, \frac\pi2)\).

1.3.5연습문제

기본

  1. 다음 값을 구하여라. (가) \(\arccos\frac12\) (나) \(\arctan(-1)\) (다) \(\arcsin 1\)
    답

    (가) \(\frac\pi3\) (나) \(-\frac\pi4\) (다) \(\frac\pi2\)

  2. \(f(x) = x^3 + 1\)의 역함수를 구하여라.
    답

    \(y = x^3 + 1\)에서 \(x = \sqrt[3]{y - 1}\). \(f^{-1}(x) = \sqrt[3]{x - 1}\). \(x^3\)은 증가함수라 일대일이다.

  3. \(f(x) = x^2 - 4x\)가 일대일이 되도록 정의역을 \([a, \infty)\)로 제한할 때 가장 작은 \(a\)와 그때의 역함수를 구하여라.
    힌트

    완전제곱식 \((x - 2)^2 - 4\).

    답

    \(a = 2\). \(y = (x - 2)^2 - 4\), \(x \ge 2\)에서 \(x = 2 + \sqrt{y + 4}\). \(f^{-1}(x) = 2 + \sqrt{x + 4}\), 정의역 \([-4, \infty)\).

응용

  1. \(\arccos(\cos\frac{5\pi}{3})\)과 \(\arctan(\tan\frac{3\pi}{4})\)를 구하여라.
    답

    \(\cos\frac{5\pi}{3} = \frac12\)이므로 \(\frac\pi3\). \(\tan\frac{3\pi}{4} = -1\)이므로 \(-\frac\pi4\).

  2. \(\tan(\arcsin x)\)를 \(x\)의 식으로 나타내고 정의역을 말하여라.
    답

    예제 1.3.7에서 \(\cos(\arcsin x) = \sqrt{1 - x^2}\)이므로 \(\frac{x}{\sqrt{1 - x^2}}\). 분모가 0이 아니어야 하므로 \(-1 < x < 1\).

심화

  1. 모든 \(x \in [-1, 1]\)에 대해 \(\arcsin x + \arccos x = \frac\pi2\)임을 보여라.
    힌트

    \(\theta = \arcsin x\)이면 \(\cos(\frac\pi2 - \theta) = x\)이고 \(\frac\pi2 - \theta \in [0, \pi]\).

    답

    \(\theta = \arcsin x \in [-\frac\pi2, \frac\pi2]\)이면 \(\frac\pi2 - \theta \in [0, \pi]\)이고 \(\cos(\frac\pi2 - \theta) = \sin\theta = x\). \(\arccos x\)는 \([0, \pi]\)에서 코사인 값이 \(x\)인 유일한 각이므로 \(\arccos x = \frac\pi2 - \theta\).
