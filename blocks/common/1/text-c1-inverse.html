역함수와 로그함수

본문

사인 값이 \(\frac12\)인 각은 \(\frac\pi6\)도 있고 \(\frac{5\pi}6\)도 있고 그 밖에도 끝없이 많다. 그렇다면 "사인 값이 \(\frac12\)인 각"을 돌려주는 함수는 어떻게 만들 수 있을까?

먼저 알아야 할 것고교 수학의 함수, 정의역, 치역, 합성함수 \(g \circ f\)와 역함수의 그래프가 직선 \(y = x\)에 대칭이라는 사실, 그리고 고교 수학I의 삼각함수 \(\sin, \cos, \tan\)의 그래프와 특수각의 값을 쓴다.

1.3.1되돌리는 함수

섭씨 온도 \(C\)를 화씨로 바꾸는 함수는 \(F = f(C) = \frac95 C + 32\)이다. 거꾸로 화씨를 섭씨로 바꾸려면 이 식을 \(C\)에 대해 풀어 \(C = \frac59(F - 32)\)를 얻으면 된다. 이렇게 출력에서 입력을 되찾는 함수가 역함수이다.

그런데 모든 함수를 되돌릴 수 있지는 않다. \(f(x) = x^2\)에서 출력이 4라면 입력은 2였을까, \(-2\)였을까? 출력만 보고는 알 수 없다. 즉 두 입력이 같은 출력을 내면 출력에서 입력을 하나로 정할 수 없고, 이것이 역함수가 있을 조건을 알려 준다.

1.3.2일대일 함수와 역함수

정의 1.3.1 (일대일 함수)

함수 \(f\)의 정의역의 서로 다른 두 원소 \(x_1 \ne x_2\)에 대해 언제나 \(f(x_1) \ne f(x_2)\)이면 \(f\)를 일대일이라 한다. 같은 말로, \(f(x_1) = f(x_2)\)이면 \(x_1 = x_2\)이다.

정의 1.3.2 (역함수)

정의역이 \(A\), 치역이 \(B\)인 일대일 함수 \(f\)에 대하여, 각 \(y \in B\)에 \(f(x) = y\)인 단 하나의 \(x \in A\)를 대응시키는 함수를 \(f\)의 역함수라 하고 \(f^{-1}\)로 쓴다. 곧

\[f^{-1}(y) = x \iff f(x) = y.\]

정의에서 \(f^{-1}\)의 정의역은 \(f\)의 치역 \(B\)이고, \(f^{-1}\)의 치역은 \(f\)의 정의역 \(A\)이다. 다시 말해 입력과 출력의 역할이 통째로 바뀐다. 따라서 다음 두 등식이 성립한다.

\[f^{-1}(f(x)) = x \quad (x \in A), \qquad f(f^{-1}(y)) = y \quad (y \in B).\]

기호 \(f^{-1}\)의 \(-1\)은 지수가 아니다. \(f(x) = 2x\)이면 \(f^{-1}(x) = \frac x2\)이지만 \(\frac{1}{f(x)} = \frac{1}{2x}\)이므로 둘은 전혀 다른 함수이다.

일대일인지는 그래프로도 판정할 수 있다. 모든 수평선이 그래프와 많아야 한 번 만나면 일대일이고, 이것을 수평선 판정법이라 한다. 두 번 만나는 수평선 \(y = c\)가 있다면 서로 다른 두 입력이 같은 출력 \(c\)를 낸다는 뜻이기 때문이다. 특히 정의역 전체에서 증가하거나(\(x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\)) 감소하는 함수는 일대일이다.

예제 1.3.3

\(f(x) = \frac{2x + 1}{x - 3}\) (\(x \ne 3\))이 일대일임을 보이고 역함수를 구하여라.

풀이. \(f(x_1) = f(x_2)\)라 하고 \(x_1 = x_2\)를 이끌어 낸다. 분모를 곱해 정리하면

\[(2x_1 + 1)(x_2 - 3) = (2x_2 + 1)(x_1 - 3)\] \[\Rightarrow\ -6x_1 + x_2 = -6x_2 + x_1 \ \Rightarrow\ 7x_2 = 7x_1\]

이므로 \(x_1 = x_2\)이고, 따라서 \(f\)는 일대일이다. 이제 역함수를 구하려면 \(y = \frac{2x + 1}{x - 3}\)을 \(x\)에 대해 푼다. \(y(x - 3) = 2x + 1\)에서 \(x(y - 2) = 3y + 1\), 곧 \(x = \frac{3y + 1}{y - 2}\)이다. 변수 이름을 관습대로 \(x\)로 바꾸면 \(f^{-1}(x) = \frac{3x + 1}{x - 2}\) (\(x \ne 2\))이다. 이 계산에서 \(f\)의 치역에 2가 없다는 사실도 함께 나온다. \(y = 2\)를 넣으면 \(0 = 7\)이 되어 풀리지 않기 때문이다.

1.3.3정의역을 잘라 역함수 만들기

\(f(x) = x^2\)은 실수 전체에서 일대일이 아니지만, 정의역을 \([0, \infty)\)로 제한하면 증가함수가 되어 일대일이다. 그 역함수가 \(\sqrt x\)이다. 그림 2에서 보듯이 두 그래프는 직선 \(y = x\)에 대해 서로 대칭이다. 한편 정의역을 \((-\infty, 0]\)으로 제한하면 역함수는 \(-\sqrt x\)가 된다. 즉 어느 쪽으로 자르느냐에 따라 역함수가 달라지므로, 어디로 잘랐는지가 역함수 정의의 일부이다.

삼각함수는 주기함수라서 같은 값을 끝없이 되풀이한다. 그래서 역함수를 만들려면 반드시 정의역을 잘라야 하고, 수학자들이 관습으로 정해 둔 구간이 있다. 그 구간은 세 가지를 만족하도록 고른다. 함수가 그 구간에서 증가하거나 감소해야 하고, 함수가 가질 수 있는 모든 값을 한 번씩 가져야 하며, 0 근처의 익숙한 각을 포함해야 한다.

1.3.4역삼각함수

그림 1에서 \(c\)를 \(-1\)부터 1까지 움직여 보자. 수평선은 사인 그래프와 여러 번 만나지만 굵게 그린 구간 \(\left[-\frac\pi2, \frac\pi2\right]\)에서는 언제나 꼭 한 번 만난다. 그 교점의 \(x\)좌표를 \(c\)에 대응시키면 역함수가 생긴다.

정의 1.3.4 (역사인, 역코사인, 역탄젠트)

\(\sin\)을 \(\left[-\frac\pi2, \frac\pi2\right]\)로 제한한 함수의 역함수를 \(\arcsin\)이라 한다. 정의역은 \([-1, 1]\), 치역은 \(\left[-\frac\pi2, \frac\pi2\right]\)이다.

\(\cos\)을 \([0, \pi]\)로 제한한 함수의 역함수를 \(\arccos\)이라 한다. 정의역은 \([-1, 1]\), 치역은 \([0, \pi]\)이다.

\(\tan\)을 \(\left(-\frac\pi2, \frac\pi2\right)\)로 제한한 함수의 역함수를 \(\arctan\)이라 한다. 정의역은 \(\mathbb{R}\), 치역은 \(\left(-\frac\pi2, \frac\pi2\right)\)이다.

\(\arcsin x\)는 "사인 값이 \(x\)인 각 가운데 \(-\frac\pi2\)와 \(\frac\pi2\) 사이에서 고른 것"으로 읽는다. 각은 라디안으로 잰다. \(\sin^{-1}x\)라고도 쓰지만 \(\frac{1}{\sin x}\)과 헷갈리기 쉬워서 이 책에서는 \(\arcsin\)을 쓴다.

그러면 왜 하필 이 구간들일까? \(\sin\)은 \(\left[-\frac\pi2, \frac\pi2\right]\)에서 \(-1\)부터 1까지 증가하며 모든 값을 한 번씩 지난다. 하지만 \(\cos\)은 그 구간에서 0일 때 최댓값을 가지므로 증가하지 않는다. 그래서 대신 \([0, \pi]\)에서 1부터 \(-1\)까지 감소하는 부분을 쓴다. \(\tan\)은 \(\pm\frac\pi2\)에서 정의되지 않으므로 열린구간을 쓴다.

예제 1.3.5

다음 값을 구하여라. (가) \(\arcsin\left(-\frac12\right)\) (나) \(\arccos\left(-\frac{\sqrt2}{2}\right)\) (다) \(\arctan\sqrt3\)

풀이. 각각 값이 주어진 수인 각을 정해진 치역 안에서 찾는다. (가) \(\sin\theta = -\frac12\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)인 \(\theta\)는 \(-\frac\pi6\)이다. \(\frac{7\pi}{6}\)도 사인 값이 \(-\frac12\)이지만 치역 밖이다. 그림 1에서 \(c = -0.5\)로 두면 굵은 구간 안의 교점이 \(x \approx -0.52\)에 하나만 있다. (나) \(\cos\theta = -\frac{\sqrt2}{2}\)이고 \(0 \le \theta \le \pi\)인 \(\theta\)는 \(\frac{3\pi}{4}\)이며, \(-\frac{3\pi}{4}\)는 치역 밖이다. (다) \(\tan\theta = \sqrt3\)이고 \(-\frac\pi2 < \theta < \frac\pi2\)인 \(\theta\)는 \(\frac\pi3\)이다.

그런데 역함수의 두 등식 \(f^{-1}(f(x)) = x\), \(f(f^{-1}(y)) = y\)는 각각 정해진 범위에서만 성립한다. 역삼각함수에서는 이 범위를 놓치기 쉽다.

예제 1.3.6

\(\arcsin(\sin 2)\)를 구하여라. 왜 2가 아닌가?

풀이. \(\arcsin(\sin x) = x\)는 \(x\)가 \(\left[-\frac\pi2, \frac\pi2\right]\)에 있을 때만 성립한다. \(\frac\pi2 \approx 1.571\)이므로 \(2\)는 그 범위 밖이다. 그래서 \(\sin\theta = \sin 2\)이고 \(\theta \in \left[-\frac\pi2, \frac\pi2\right]\)인 다른 각을 찾아야 한다. \(\sin(\pi - x) = \sin x\)이므로 \(\theta = \pi - 2 \approx 1.142\)가 조건을 만족한다. 따라서 \(\arcsin(\sin 2) = \pi - 2\)이다. 그림 1로 확인하면, \(c = \sin 2 \approx 0.91\)인 수평선은 \(x = 2\)에서도 그래프와 만나지만 그 점은 굵은 구간 밖에 있고, 구간 안의 교점은 \(x \approx 1.14\)이다.

반대 방향 \(\sin(\arcsin y) = y\)는 \(\arcsin\)이 정의되는 모든 \(y \in [-1, 1]\)에서 성립한다. 즉 두 방향은 대칭이 아니다.

예제 1.3.7

\(\cos(\arcsin x)\)를 \(x\)의 식으로 나타내어라 (\(-1 \le x \le 1\)).

풀이. \(\theta = \arcsin x\)로 놓으면 \(\sin\theta = x\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)이다. \(\sin^2\theta + \cos^2\theta = 1\)에서 \(\cos\theta = \pm\sqrt{1 - x^2}\)인데, 이 범위의 \(\theta\)에서는 \(\cos\theta \ge 0\)이므로 부호는 +이다. 따라서 \(\cos(\arcsin x) = \sqrt{1 - x^2}\)이다. 이 식은 2.4절에서 \(\arcsin\)을 미분할 때 다시 쓴다.

주의"\(\arcsin\)과 \(\sin\)은 서로 상쇄된다"고만 기억하면 예제 1.3.6 같은 문제에서 틀린다. 역삼각함수의 값은 언제나 정해진 치역 안에 있어야 하므로, 답을 낸 뒤 치역 안에 있는지 확인한다.
마무리

역함수는 일대일 함수에만 있고, 일대일인지는 수평선 판정법이나 증가·감소로 확인한다. 사인처럼 같은 값을 되풀이하는 함수는 정의역을 잘라 일대일로 만든 다음 되돌리며, 자른 구간이 곧 역함수의 치역이 된다. 그래서 "사인 값이 \(\frac12\)인 각"을 돌려주는 함수 \(\arcsin\)은 \(\left[-\frac\pi2, \frac\pi2\right]\)에서 그 각을 고르고, \(\arcsin\frac12 = \frac\pi6\)이다.

1.3.5연습문제

기본

  1. 다음 값을 구하여라. (가) \(\arccos\frac12\) (나) \(\arctan(-1)\) (다) \(\arcsin 1\)
    답

    (가) \(\frac\pi3\) (나) \(-\frac\pi4\) (다) \(\frac\pi2\)

  2. \(f(x) = x^3 + 1\)의 역함수를 구하여라.
    답

    \(y = x^3 + 1\)에서 \(x = \sqrt[3]{y - 1}\). \(f^{-1}(x) = \sqrt[3]{x - 1}\). \(x^3\)은 증가함수라 일대일이다.

  3. \(f(x) = x^2 - 4x\)가 일대일이 되도록 정의역을 \([a, \infty)\)로 제한할 때 가장 작은 \(a\)와 그때의 역함수를 구하여라.
    힌트

    완전제곱식 \((x - 2)^2 - 4\).

    답

    \(a = 2\). \(y = (x - 2)^2 - 4\), \(x \ge 2\)에서 \(x = 2 + \sqrt{y + 4}\). \(f^{-1}(x) = 2 + \sqrt{x + 4}\), 정의역 \([-4, \infty)\).

응용

  1. \(\arccos(\cos\frac{5\pi}{3})\)과 \(\arctan(\tan\frac{3\pi}{4})\)를 구하여라.
    답

    \(\cos\frac{5\pi}{3} = \frac12\)이므로 \(\frac\pi3\). \(\tan\frac{3\pi}{4} = -1\)이므로 \(-\frac\pi4\).

  2. \(\tan(\arcsin x)\)를 \(x\)의 식으로 나타내고 정의역을 말하여라.
    답

    예제 1.3.7에서 \(\cos(\arcsin x) = \sqrt{1 - x^2}\)이므로 \(\frac{x}{\sqrt{1 - x^2}}\). 분모가 0이 아니어야 하므로 \(-1 < x < 1\).

심화

  1. 모든 \(x \in [-1, 1]\)에 대해 \(\arcsin x + \arccos x = \frac\pi2\)임을 보여라.
    힌트

    \(\theta = \arcsin x\)이면 \(\cos(\frac\pi2 - \theta) = x\)이고 \(\frac\pi2 - \theta \in [0, \pi]\).

    답

    \(\theta = \arcsin x \in [-\frac\pi2, \frac\pi2]\)이면 \(\frac\pi2 - \theta \in [0, \pi]\)이고 \(\cos(\frac\pi2 - \theta) = \sin\theta = x\). \(\arccos x\)는 \([0, \pi]\)에서 코사인 값이 \(x\)인 유일한 각이므로 \(\arccos x = \frac\pi2 - \theta\).
