무한대와 관련된 극한, 점근선 (보충)

보충 본문

\(f(x) = \frac{x^2 + 1}{x - 1}\)의 그래프를 멀리서 보면 어떤 모양일까? \(x = 1\) 근처에서는 어디로 달아나고, \(x\)가 아주 커지면 어떤 직선에 붙어 갈까?

먼저 알아야 할 것극한의 ε-δ 정의와 극한 법칙(1.3절), 고교 수학의 유리함수 \(y = \frac{k}{x - p} + q\)의 그래프와 점근선, 그리고 지수·로그함수의 그래프(1.2절)를 쓴다.

2.5.1무한대는 수가 아니다

\(\lim_{x\to0}\frac{1}{x^2} = \infty\)라고 쓰지만, \(\infty\)는 실수가 아니므로 이 식은 1.3절의 정의 그대로의 극한이 아니다. 그 정의는 \(|f(x) - L| < \varepsilon\)에서 \(L\)이 실수여야 하기 때문이다. 따라서 이 식은 "\(x\)가 0에 가까워지면 \(\frac{1}{x^2}\)이 어떤 수보다도 커진다"는 다른 종류의 진술이다. 같은 기호 \(\lim\)을 쓰지만 따로 정의해야 하고, 엄밀히 말하면 이때 극한은 존재하지 않으며 다만 특정한 방식으로 발산한다고 말한다.

2.5.2정의

정의 2.5.1 (무한대로 발산)

임의의 \(M > 0\)에 대하여 어떤 \(\delta > 0\)이 있어서 \(0 < |x - a| < \delta \Rightarrow f(x) > M\)이면 \(\lim_{x\to a}f(x) = \infty\)라 쓴다. \(f(x) < -M\)으로 바꾸면 \(\lim_{x\to a}f(x) = -\infty\)이다.

정의 2.5.2 (무한대에서의 극한)

임의의 \(\varepsilon > 0\)에 대하여 어떤 \(N\)이 있어서 \(x > N \Rightarrow |f(x) - L| < \varepsilon\)이면 \(\lim_{x\to\infty}f(x) = L\)이라 쓴다. \(x < N \Rightarrow \cdots\)로 바꾸면 \(\lim_{x\to-\infty}f(x) = L\)이다.

1.3절과 비교하면 바뀐 곳이 보인다. 정의 2.5.1에서는 "\(L\)에서 \(\varepsilon\) 이내" 대신 "\(M\)보다 크다"가 목표이고, 정의 2.5.2에서는 "\(a\)에서 \(\delta\) 이내" 대신 "\(N\)보다 크다"가 조건이다. 그래도 도전과 응답의 구조는 같다. 상대가 아무리 큰 \(M\)을 불러도, 아무리 작은 \(\varepsilon\)을 불러도 답할 수 있어야 한다.

예제 2.5.3

정의로 \(\lim_{x\to\infty}\frac1x = 0\)과 \(\lim_{x\to0}\frac{1}{x^2} = \infty\)를 보여라.

풀이. 첫째 식에서는 \(\varepsilon > 0\)에 대해 \(N = \frac1\varepsilon\)로 잡는다. 그러면 \(x > N\)일 때 \(0 < \frac1x < \frac1N = \varepsilon\)이다. 둘째 식에서는 \(M > 0\)에 대해 \(\delta = \frac{1}{\sqrt M}\)으로 잡는다. 그러면 \(0 < |x| < \delta\)일 때 \(x^2 < \frac1M\), 곧 \(\frac{1}{x^2} > M\)이다. 가령 \(M = 10^6\)이면 \(\delta = 0.001\)이다.

극한 법칙(1.3절 보충)은 \(x \to \pm\infty\)일 때도 그대로 성립한다. 증명도 같아서, \(\delta\) 대신 \(N\)을 쓰고 두 \(N\) 가운데 큰 쪽을 잡으면 된다. 그래서 \(\lim_{x\to\infty}\frac{1}{x^n} = 0\) (\(n > 0\))을 기본으로 삼아 복잡한 식을 계산한다.

2.5.3최고차항으로 나누기

\(x \to \pm\infty\)일 때 다항식은 최고차항이 지배한다. \(x = 1000\)이면 \(3x^2 - 5x + 7 = 2\,995\,007\)인데 \(3x^2 = 3\,000\,000\)이어서 거의 같다. 그래서 유리함수는 분모의 최고차 거듭제곱으로 분자와 분모를 나누어 계산한다.

예제 2.5.4

(가) \(\lim_{x\to\infty}\frac{3x^2 - 5x + 7}{2x^2 + 1}\) (나) \(\lim_{x\to\infty}\frac{x + 4}{x^2 - 3}\) (다) \(\lim_{x\to-\infty}\frac{x^3}{x^2 + 1}\)

풀이. (가) 분자와 분모를 \(x^2\)으로 나누면 다음과 같다.

\[\frac{3 - \frac5x + \frac7{x^2}}{2 + \frac1{x^2}} \to \frac{3 - 0 + 0}{2 + 0} = \frac32\]

(나) \(x^2\)으로 나누면 \(\frac{\frac1x + \frac4{x^2}}{1 - \frac3{x^2}} \to \frac01 = 0\)이다. (다) \(x^2\)으로 나누면 \(\frac{x}{1 + \frac1{x^2}}\)이고, 분모는 1로, 분자는 \(-\infty\)로 가므로 \(-\infty\)로 발산한다.

세 결과를 모으면 차수가 같으면 최고차항 계수의 비, 분자의 차수가 낮으면 0, 분자의 차수가 높으면 \(\pm\infty\)로 발산한다. 다만 공식처럼 외우기보다 최고차항끼리 비교한다고 기억하는 편이 낫다.

예제 2.5.5

(가) \(\lim_{x\to-\infty}\frac{\sqrt{4x^2 + 1}}{x - 3}\) (나) \(\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right)\)

풀이. (가) 근호 안에서 \(x^2\)을 꺼낼 때 \(\sqrt{x^2} = |x|\)이고, \(x < 0\)이면 \(|x| = -x\)이다(1.1절). 그러므로

\[\sqrt{4x^2 + 1} = |x|\sqrt{4 + \tfrac1{x^2}} = -x\sqrt{4 + \tfrac1{x^2}} \quad (x < 0)\]

이고, \(\frac{-x\sqrt{4 + 1/x^2}}{x - 3} = \frac{-\sqrt{4 + 1/x^2}}{1 - 3/x} \to -2\)이다. 부호를 놓쳐 2라고 답하기 쉬운데, 숫자 하나로 검산할 수 있다. \(x = -1000\)이면 분자는 약 2000으로 양수이고 분모는 약 \(-1003\)으로 음수이므로, 비는 음수여야 한다.

(나) \(\infty - \infty\) 꼴은 극한 법칙을 쓸 수 없으므로 유리화한다.

\[\sqrt{x^2 + 6x} - x = \frac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x} = \frac{6x}{\sqrt{x^2 + 6x} + x} = \frac{6}{\sqrt{1 + \frac6x} + 1} \to 3\]

두 항이 각각 한없이 커지지만 그 차는 3으로 다가간다. \(\sqrt{x^2 + 6x} = \sqrt{(x + 3)^2 - 9} \approx x + 3\)이라는 것을 생각하면 그럴듯하다.

2.5.4점근선

그래프가 멀리 가면서 어떤 직선에 한없이 다가가면 그 직선을 점근선이라 한다. 그림 1의 곡선에는 두 종류가 보이고, 그림 2에는 또 다른 종류가 보인다.

정의 2.5.6 (수직 점근선)

\(\lim_{x\to a^+}f(x)\) 또는 \(\lim_{x\to a^-}f(x)\)가 \(\pm\infty\)이면 직선 \(x = a\)를 수직 점근선이라 한다.

정의 2.5.7 (수평 점근선)

\(\lim_{x\to\infty}f(x) = L\) 또는 \(\lim_{x\to-\infty}f(x) = L\)이면 직선 \(y = L\)을 수평 점근선이라 한다.

정의 2.5.8 (비스듬한 점근선)

\(\lim_{x\to\pm\infty}[f(x) - (mx + b)] = 0\)이고 \(m \ne 0\)이면 직선 \(y = mx + b\)를 비스듬한 점근선이라 한다.

수직 점근선은 분모가 0이 되는 점 가운데 약분 뒤에도 남는 것, \(\ln\)의 정의역 끝, \(\tan\)의 \(\frac\pi2 + n\pi\) 같은 곳에서 찾는다. 수평 점근선은 \(x \to \infty\)와 \(x \to -\infty\)의 극한을 따로 구해 얻는다. 비스듬한 점근선은 \(m = \lim\frac{f(x)}{x}\), \(b = \lim[f(x) - mx]\)로 구하는데, 유리함수이면 나눗셈으로 바로 얻는다.

예제 2.5.9

\(f(x) = \frac{x^2 + 1}{x - 1}\)의 점근선을 모두 구하여라.

풀이. \(x = 1\)에서 분모가 0이고 분자는 2라서 약분되지 않는다. \(x \to 1^+\)이면 \(\frac{2}{0^+} \to \infty\), \(x \to 1^-\)이면 \(-\infty\)이므로 \(x = 1\)은 수직 점근선이다.

다음으로 다항식의 나눗셈을 하면 \(x^2 + 1 = (x - 1)(x + 1) + 2\)이므로 \(f(x) = x + 1 + \frac{2}{x - 1}\)이다. \(x \to \pm\infty\)일 때 \(\frac{2}{x - 1} \to 0\)이므로 \(f(x) - (x + 1) \to 0\), 곧 \(y = x + 1\)이 비스듬한 점근선이다. 분자의 차수가 분모보다 하나 높으므로 수평 점근선은 없다. 그림 1에서 보는 범위 \(R\)을 8에서 60까지 넓히면 \(x = R\)에서의 차이 \(\frac{2}{R - 1}\)이 0.29에서 0.034로 줄어, 곡선이 점선에 붙어 보인다.

예제 2.5.10

\(g(x) = \frac{2e^x}{e^x + 1}\)의 수평 점근선을 구하여라.

풀이. \(x \to \infty\)이면 분자와 분모를 \(e^x\)로 나누어 \(\frac{2}{1 + e^{-x}} \to 2\)이다. \(x \to -\infty\)이면 \(e^x \to 0\)이므로 \(\frac{0}{0 + 1} = 0\)이다. 따라서 수평 점근선은 \(y = 2\)와 \(y = 0\) 두 개이다. 그림 2처럼 유리함수와 달리 양쪽 극한이 다를 수 있으므로, 반드시 따로 구해야 한다. 이런 S자 곡선을 로지스틱 곡선이라 하며, 개체군 성장 모형과 통계의 분류 모형에 나온다.

주의\(\frac{\infty}{\infty} = 1\), \(\infty - \infty = 0\), \(0\cdot\infty = 0\)은 모두 틀린 계산이다. 이런 꼴은 부정형이라 하며, 식을 정리하거나 3.3절의 로피탈 법칙을 써야 값이 정해진다. 예제 2.5.5(나)는 \(\infty - \infty\)인데 답이 3이었다.
마무리

\(\lim f = \infty\)는 "어떤 \(M\)보다도 커진다", \(\lim_{x\to\infty}f = L\)은 "\(x > N\)이면 \(L\)에서 \(\varepsilon\) 이내"라는 뜻으로, 1.3절과 같은 도전과 응답의 구조를 갖는다. 유리함수의 무한대 극한은 최고차항끼리 비교하고, \(\infty - \infty\)는 유리화로 정리한다. 처음의 \(\frac{x^2 + 1}{x - 1}\)은 \(x = 1\)에서 위아래로 달아나는 수직 점근선과, 나눗셈으로 얻은 비스듬한 점근선 \(y = x + 1\)을 갖는다.

2.5.5연습문제

기본

  1. 극한을 구하여라. (가) \(\lim_{x\to\infty}\frac{5x^3 - x}{2 - x^3}\) (나) \(\lim_{x\to3^-}\frac{x}{x - 3}\) (다) \(\lim_{x\to\infty}\frac{\sin x}{x}\)
    답

    (가) \(-5\) (나) \(-\infty\) (분자 3, 분모 \(0^-\)) (다) \(|\frac{\sin x}{x}| \le \frac1x\)이므로 압축 정리로 0

  2. \(f(x) = \frac{3x - 1}{x + 2}\)의 점근선을 구하여라.
    답

    수직 \(x = -2\), 수평 \(y = 3\).

  3. \(\lim_{x\to\infty}\left(\sqrt{x^2 + x} - \sqrt{x^2 - x}\right)\)을 구하여라.
    답

    유리화: \(\frac{2x}{\sqrt{x^2 + x} + \sqrt{x^2 - x}} = \frac{2}{\sqrt{1 + 1/x} + \sqrt{1 - 1/x}} \to 1\).

응용

  1. \(f(x) = \frac{\sqrt{9x^2 + 4}}{x}\)의 수평 점근선을 \(x \to \infty\)와 \(x \to -\infty\)에서 각각 구하여라.
    답

    \(x \to \infty\): 3. \(x \to -\infty\): \(\sqrt{9x^2 + 4} = |x|\sqrt{9 + 4/x^2}\), \(|x| = -x\)이므로 \(-3\). 점근선 \(y = 3\), \(y = -3\).

  2. \(f(x) = \frac{2x^3 + x^2}{x^2 + 1}\)의 비스듬한 점근선을 구하여라.
    힌트

    나눗셈: \(2x^3 + x^2 = (x^2 + 1)(2x + 1) - 2x - 1\).

    답

    \(f(x) = 2x + 1 - \frac{2x + 1}{x^2 + 1}\)이고 마지막 항은 0으로 가므로 \(y = 2x + 1\).

심화

  1. 정의 2.5.2로 \(\lim_{x\to\infty}\frac{2x + 1}{x} = 2\)를 증명하고, \(\varepsilon = 0.01\)일 때의 \(N\)을 구하여라.
    답

    \(\left|\frac{2x + 1}{x} - 2\right| = \frac1x\) (\(x > 0\)). \(N = \frac1\varepsilon\)이면 \(x > N\)에서 \(\frac1x < \varepsilon\). \(\varepsilon = 0.01\)이면 \(N = 100\).
