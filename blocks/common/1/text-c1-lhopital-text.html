부정형과 로피탈 법칙

본문
이 절에서 배울 것
  • \(\frac00\), \(\frac\infty\infty\) 꼴의 극한을 로피탈 법칙으로 구한다.
  • \(0\cdot\infty\), \(\infty - \infty\), \(1^\infty\), \(0^0\), \(\infty^0\) 꼴을 앞의 두 꼴로 바꾼다.
먼저 알아야 할 것
  • 극한 계산과 무한대 극한 (고교 수학II, 1.3절).
  • 여러 함수의 도함수 (2단원).

3.3.1부정형

\(\lim_{x\to0}\dfrac{\sin x}{x}\)처럼 분자와 분모가 모두 0으로 가는 극한은 대입만으로는 값이 정해지지 않습니다. \(\dfrac{x^2}{x}\to0\), \(\dfrac{x}{x^2}\to\infty\), \(\dfrac{2x}{x}\to2\)처럼 경우마다 답이 다릅니다. 이런 꼴을 부정형이라 합니다. 고교에서는 인수분해나 유리화로 정리했지만, \(\dfrac{e^x - 1}{x}\)이나 \(\dfrac{\ln x}{x}\)처럼 정리할 방법이 없는 경우가 많습니다.

3.3.2로피탈 법칙

정리 3.3.1 (로피탈 법칙)

\(f, g\)가 \(a\) 근처에서 미분 가능하고 \(g'(x) \ne 0\)이며, \(\lim_{x\to a}f(x) = \lim_{x\to a}g(x) = 0\)이거나 둘 다 \(\pm\infty\)일 때, 오른쪽 극한이 존재하면(또는 \(\pm\infty\)이면)

\[\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}.\]

\(a\) 대신 \(a^\pm\), \(\pm\infty\)여도 성립한다.

왜 맞는지 직관적으로 보면, \(f(a) = g(a) = 0\)일 때 \(a\) 근처에서 선형근사(2.5절)로 \(f(x) \approx f'(a)(x - a)\), \(g(x) \approx g'(a)(x - a)\)이므로 그 비는 \(\dfrac{f'(a)}{g'(a)}\)에 가깝습니다. 분자와 분모가 0으로 가는 "빠르기"를 비교하는 셈입니다.

예제 3.3.2

(가) \(\lim_{x\to0}\dfrac{e^x - 1}{x}\) (나) \(\lim_{x\to\infty}\dfrac{\ln x}{x}\) (다) \(\lim_{x\to\infty}\dfrac{e^x}{x^2}\)

풀이. (가) \(\frac00\) 꼴. \(\lim\dfrac{e^x}{1} = 1\).

(나) \(\frac\infty\infty\) 꼴. \(\lim\dfrac{1/x}{1} = 0\). 로그는 \(x\)보다 훨씬 느리게 자랍니다.

(다) \(\frac\infty\infty\) 꼴. \(\lim\dfrac{e^x}{2x}\)도 여전히 \(\frac\infty\infty\)라서 한 번 더 쓰면 \(\lim\dfrac{e^x}{2} = \infty\). 지수함수는 어떤 다항식보다 빨리 자랍니다.

로피탈 법칙을 쓸 때마다 "아직 \(\frac00\)이나 \(\frac\infty\infty\)인가"를 먼저 확인해야 합니다. 부정형이 아닌데 쓰면 틀린 답이 나옵니다. 예를 들어 \(\lim_{x\to0}\dfrac{x + 1}{x + 2} = \dfrac12\)인데, 분자와 분모를 미분하면 \(\dfrac11 = 1\)이 됩니다.

3.3.3다른 부정형

나머지 부정형은 식을 고쳐 \(\frac00\)이나 \(\frac\infty\infty\)로 만든 뒤 로피탈 법칙을 씁니다.

  • \(0\cdot\infty\): \(fg = \dfrac{f}{1/g}\)로 고친다.
  • \(\infty - \infty\): 통분하거나 공통인수로 묶는다.
  • \(1^\infty\), \(0^0\), \(\infty^0\): \(y = f^g\)에 로그를 취해 \(\ln y = g\ln f\)(\(0\cdot\infty\) 꼴)의 극한을 구한 뒤 \(e\)의 거듭제곱으로 되돌린다.
예제 3.3.3

(가) \(\lim_{x\to0^+}x\ln x\) (나) \(\lim_{x\to0^+}x^x\) (다) \(\lim_{x\to\infty}\left(1 + \dfrac1x\right)^x\)

풀이. (가) \(0\cdot(-\infty)\) 꼴. \(x\ln x = \dfrac{\ln x}{1/x}\)는 \(\frac{-\infty}{\infty}\) 꼴이므로 \(\lim\dfrac{1/x}{-1/x^2} = \lim(-x) = 0\).

(나) \(0^0\) 꼴. \(\ln y = x\ln x \to 0\)이므로 (가)에서 \(y \to e^0 = 1\).

(다) \(1^\infty\) 꼴. \(\ln y = x\ln\left(1 + \frac1x\right) = \dfrac{\ln(1 + 1/x)}{1/x}\). \(t = \frac1x \to 0^+\)로 놓으면 \(\dfrac{\ln(1 + t)}{t} \to \dfrac{1/(1 + t)}{1} \to 1\). 따라서 극한은 \(e^1 = e\). 1.2절에서 복리 계산으로 본 \(\left(1 + \frac1n\right)^n \to e\)가 이렇게 확인됩니다.

주의로피탈 법칙은 \(\dfrac{f'}{g'}\)이지 \(\left(\dfrac fg\right)'\)(몫의 미분)이 아닙니다. 분자와 분모를 따로 미분합니다.
요약
  1. \(\frac00\), \(\frac\infty\infty\) 꼴이면 \(\lim\frac fg = \lim\frac{f'}{g'}\). 쓸 때마다 부정형인지 확인한다.
  2. \(0\cdot\infty\)는 분수로, \(\infty - \infty\)는 통분으로, 거듭제곱 꼴은 로그를 취해 바꾼다.
  3. 크게 갈 때 \(\ln x \ll x^p \ll e^x\).

3.3.4연습문제

기본

  1. (가) \(\lim_{x\to0}\dfrac{\tan x}{x}\) (나) \(\lim_{x\to1}\dfrac{\ln x}{x - 1}\) (다) \(\lim_{x\to0}\dfrac{1 - \cos x}{x^2}\)
    답

    (가) \(\frac{\sec^2 0}{1} = 1\) (나) \(\frac{1/1}{1} = 1\) (다) \(\frac{\sin x}{2x} \to \frac12\)

  2. \(\lim_{x\to\infty}\dfrac{x^3}{e^x}\)을 구하여라.
    답

    세 번 적용: \(\frac{6}{e^x} \to 0\).

응용

  1. \(\lim_{x\to0}\left(\dfrac1x - \dfrac{1}{\sin x}\right)\)을 구하여라.
    답

    통분: \(\frac{\sin x - x}{x\sin x}\) (\(\frac00\)). 미분: \(\frac{\cos x - 1}{\sin x + x\cos x}\) (\(\frac00\)). 한 번 더: \(\frac{-\sin x}{2\cos x - x\sin x} \to 0\).

  2. \(\lim_{x\to\infty}\left(1 + \dfrac3x\right)^x\)을 구하여라.
    답

    \(\ln y = \frac{\ln(1 + 3/x)}{1/x} \to 3\). 답 \(e^3\).
