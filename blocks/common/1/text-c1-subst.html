치환적분

본문

\(\int 2x\cos(x^2)\,dx\)를 보면 부정적분 표의 어느 칸에도 맞지 않는다. 그런데 \(\sin(x^2)\)을 미분하면 정확히 이 식이 나온다. 그렇다면 미분의 연쇄법칙을 거꾸로 읽어 적분하는 방법이 있지 않을까?

먼저 알아야 할 것연쇄법칙(2.2절)과 미적분의 기본정리, 부정적분 표(4.2절)를 쓴다. 고교 미적분에서 치환적분을 배웠다면 복습이고, 배우지 않았어도 처음부터 읽을 수 있다.

4.3.1연쇄법칙을 거꾸로

연쇄법칙에 따르면 \(\dfrac{d}{dx}\sin(x^2) = \cos(x^2)\cdot2x\)이다. 이것을 거꾸로 읽으면 \(\int2x\cos(x^2)\,dx = \sin(x^2) + C\)이다. 즉 적분할 식 안에 어떤 함수 \(u\)와 그 도함수 \(u'\)가 함께 들어 있으면, \(u\)를 한 글자로 바꿔 간단한 적분으로 만들 수 있다.

정리 4.3.1 (치환적분)

\(u = g(x)\)가 미분 가능하고 \(f\)가 연속이면 \(\displaystyle\int f(g(x))\,g'(x)\,dx = \int f(u)\,du\)이다.

실제 계산에서는 \(u = g(x)\)로 놓고 \(\dfrac{du}{dx} = g'(x)\)를 "\(du = g'(x)\,dx\)"로 바꾸어 식에 넣는다. 그러면 \(x\)가 모두 사라지고 \(u\)만 남아야 한다. 여기서 라이프니츠 기호 \(\frac{du}{dx}\)를 분수처럼 다룬 것이 맞는 결과를 주는데, 2.1절에서 말한 "잘 만들어진 기호"가 바로 이 뜻이다.

예제 4.3.2

(가) \(\int x^3\cos(x^4 + 2)\,dx\) (나) \(\int\sqrt{2x + 1}\,dx\) (다) \(\int\tan x\,dx\)

풀이. (가) \(u = x^4 + 2\)이면 \(du = 4x^3dx\), 곧 \(x^3dx = \frac14du\)이다. 따라서 \(\int\cos u\cdot\frac14du = \frac14\sin(x^4 + 2) + C\)이다.

(나) \(u = 2x + 1\)이면 \(du = 2dx\)이다. 그러면 \(\int\sqrt u\cdot\frac12du = \frac12\cdot\frac23u^{3/2} + C = \frac13(2x + 1)^{3/2} + C\)이다.

(다) \(\tan x = \dfrac{\sin x}{\cos x}\)이므로 \(u = \cos x\), \(du = -\sin x\,dx\)로 놓는다. 그러면 \(\int\dfrac{-du}{u} = -\ln|\cos x| + C = \ln|\sec x| + C\)이다.

무엇을 \(u\)로 놓을지는 괄호 안, 근호 안, 지수, 분모처럼 안쪽에 들어 있는 식을 먼저 후보로 삼고, 그 도함수가 상수배를 빼고 식에 남아 있는지 보아 정한다. 검산은 답을 미분해서 원래 식이 나오는지 보면 된다. 가령 (나)의 답을 미분하면 \(\frac13\cdot\frac32(2x + 1)^{1/2}\cdot2 = \sqrt{2x + 1}\)이다.

4.3.2정적분의 치환

정적분에서는 \(u\)로 바꿀 때 적분 구간도 \(u\)의 값으로 바꾼다. 그러면 마지막에 \(x\)로 되돌릴 필요가 없다.

예제 4.3.3

\(\int_0^2 xe^{-x^2}dx\)를 구하여라.

풀이. \(u = -x^2\)으로 놓으면 \(du = -2x\,dx\)이다. 구간은 \(x = 0\)이면 \(u = 0\), \(x = 2\)이면 \(u = -4\)로 바뀐다. 따라서

\[\int_0^2 xe^{-x^2}dx = \int_0^{-4}e^u\left(-\frac12\right)du = \frac12\int_{-4}^{0}e^u\,du = \frac12(1 - e^{-4}) \approx 0.491\]

이다. 그림 1은 이 계산을 넓이로 보여 준다. 왼쪽의 넓이와 오른쪽의 넓이는 모양이 전혀 다르지만, \(b = 2\)이면 둘 다 0.491이다. 다시 말해 치환은 가로축의 눈금을 \(u = -x^2\)에 맞게 늘이고 줄이면서, 높이도 그만큼 보정해 넓이를 지킨다.

4.3.3미분방정식 맛보기: \(y' = ky\)

늘어나는 빠르기가 지금의 양에 비례하는 현상은 아주 흔하다. 세균의 증식, 예금의 복리, 방사성 원소의 붕괴, 축전기의 방전이 모두 이런 꼴이고, 식으로는 \(\dfrac{dy}{dt} = ky\)이다. 이렇게 도함수가 들어 있는 식을 미분방정식이라 하며, 2학년 고등미적분학에서 본격적으로 배운다. 여기서는 치환적분만으로 풀어 본다.

\(y > 0\)이라 하고 양변을 \(y\)로 나누면 \(\dfrac{1}{y}\dfrac{dy}{dt} = k\)이다. 양변을 \(t\)로 적분하면 왼쪽은 치환적분으로 \(\int\dfrac{dy}{y} = \ln y\)가 되고, 오른쪽은 \(kt + C\)이다. 따라서 \(\ln y = kt + C\)이고, 곧 다음을 얻는다.

\[y = e^{kt + C} = y_0e^{kt} \qquad (y_0 = e^C = y(0))\]
예제 4.3.4

세균 수가 늘어나는 빠르기가 세균 수에 비례하고, 처음 1000마리가 3시간 뒤 8000마리가 되었다. 5시간 뒤의 수는?

풀이. \(y = 1000e^{kt}\)이다. \(8000 = 1000e^{3k}\)에서 \(e^{3k} = 8\), 곧 \(e^k = 2\)이다. 따라서 \(y = 1000\cdot2^t\)이고 5시간 뒤에는 \(32\,000\)마리이다. 한 시간마다 두 배가 되는 셈이며, 3시간에 8배라는 조건과도 맞는다.

반대로 \(k < 0\)이면 같은 식이 붕괴, 냉각, 방전 같은 지수적 감소를 나타낸다. 일반물리의 RC 회로와 일반화학의 1차 반응 속도식이 이 식을 그대로 쓴다.

주의치환한 뒤 \(x\)와 \(u\)가 섞여 남으면 잘못 고른 것이다. 또 정적분에서 구간을 바꾸지 않고 \(x\)의 구간을 그대로 쓰는 실수가 흔하다. 구간을 바꾸든지, \(x\)로 되돌린 뒤 원래 구간을 넣든지 둘 중 하나만 한다.
마무리

적분할 식에 안쪽 함수 \(u = g(x)\)와 그 도함수가 함께 있으면 \(du = g'(x)dx\)로 바꾸어 \(u\)만의 간단한 적분으로 만든다. 처음 질문의 \(\int 2x\cos(x^2)\,dx\)는 \(u = x^2\)으로 \(\sin(x^2) + C\)가 된다. 정적분에서는 구간도 \(u\)의 값으로 바꾸며, 같은 방법으로 미분방정식 \(y' = ky\)를 풀면 \(y = y_0e^{kt}\)를 얻는다.

4.3.4연습문제

기본

  1. (가) \(\int(3x - 1)^5dx\) (나) \(\int\frac{2x}{x^2 + 1}dx\) (다) \(\int e^{\sin x}\cos x\,dx\)
    답

    (가) \(\frac{(3x - 1)^6}{18} + C\) (나) \(\ln(x^2 + 1) + C\) (다) \(e^{\sin x} + C\)

  2. \(\int_0^{\pi/2}\sin^3x\cos x\,dx\)를 구하여라.
    답

    \(u = \sin x\): \(\int_0^1 u^3du = \frac14\).

응용

  1. \(\int\frac{\ln x}{x}dx\)를 구하여라.
    답

    \(u = \ln x\), \(du = \frac{dx}{x}\). \(\frac{(\ln x)^2}{2} + C\).

  2. 반감기가 10일인 물질 80 g이 있다. 25일 뒤 남은 양을 \(y' = ky\)로 구하여라.
    답

    \(e^{10k} = \frac12\), \(y = 80\left(\frac12\right)^{t/10}\). \(y(25) = 80\cdot2^{-2.5} \approx 14.1\) g.
