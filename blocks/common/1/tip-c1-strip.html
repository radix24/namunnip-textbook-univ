회전체의 부피는 얇은 띠 하나를 그려 놓고 방법을 고른다

요령 · 원판과 원통껍질

언제 쓰는가

평면 영역을 어떤 축으로 돌린 입체의 부피를 구할 때이다. 특히 \(y = f(x)\)로 주어진 영역을 \(y\)축이나 \(x = c\) 같은 세로축으로 돌려서, 원판과 원통껍질 가운데 무엇을 쓸지 고민될 때 쓴다.

요령

  1. 영역과 축을 그린다
    경계 곡선의 교점을 구해 영역을 칠하고, 회전축을 점선으로 그린다.
  2. 얇은 띠를 하나 긋는다
    세로 띠(두께 \(dx\))나 가로 띠(두께 \(dy\)) 가운데, 띠의 양 끝이 각각 한 곡선 위에 놓여 구간을 쪼갤 필요가 없는 쪽을 고른다.
  3. 띠와 축의 방향을 비교
    띠가 축에 수직이면 띠가 돌아 와셔(가운데 구멍 난 원판)가 된다: \(\pi(R^2 - r^2)\times\)두께. 띠가 축과 평행하면 원통껍질이 된다: \(2\pi\times\)반지름\(\times\)높이\(\times\)두께.
  4. 반지름은 축까지의 거리
    축이 \(y\)축이면 반지름은 \(x\)이지만, 축이 \(x = 3\)이면 \(3 - x\), \(y = -1\)이면 \(y + 1\)이다. 띠에서 축까지 선을 그어 확인한다.

흔한 실수

  • 와셔의 넓이를 \(\pi(R - r)^2\)로 쓰는 것. 큰 원에서 작은 원을 빼야 하므로 \(\pi(R^2 - r^2)\)이다.
  • 축을 옮긴 문제에서 반지름을 그대로 \(x\)나 \(y\)로 쓰는 것.

바로 풀어보기

\(y = x^2\)과 \(y = 2x\)로 둘러싸인 영역을 (가) \(y\)축, (나) 직선 \(x = 3\)으로 돌린 입체의 부피를 각각 구하여라.

답과 풀이

답: (가) \(\frac{8\pi}{3}\) (나) \(\frac{16\pi}{3}\)

교점은 \(x = 0, 2\)이고, 그 사이에서 \(2x \ge x^2\)이다. 세로 띠의 위끝은 \(y = 2x\), 아래끝은 \(y = x^2\)으로 하나씩이라 세로 띠가 편하다. 세로 띠는 두 축과 모두 평행하므로 원통껍질을 쓴다.

(가) 반지름 \(x\): \(2\pi\int_0^2 x(2x - x^2)\,dx = 2\pi\left(\frac{16}{3} - 4\right) = \frac{8\pi}{3}\).

(나) 반지름 \(3 - x\): \(2\pi\int_0^2(3 - x)(2x - x^2)\,dx = 2\pi\int_0^2(6x - 5x^2 + x^3)\,dx = 2\pi\left(12 - \frac{40}{3} + 4\right) = \frac{16\pi}{3}\).

검산: (가)를 가로 띠 와셔로 하면 \(\pi\int_0^4\left(y - \frac{y^2}{4}\right)dy = \pi\left(8 - \frac{16}{3}\right) = \frac{8\pi}{3}\)로 같다.

이 요령으로 풀리는 문제

  • 적분의 응용 단원 연습 2번, 5번
  • 매개변수방정식과 극좌표 단원 연습 1번, 7번, 8번
영상 콘티 · 55초
  1. 0~6초\(y = x^2\)과 \(y = 2x\) 사이 영역이 칠해지고, \(y\)축이 점선으로 강조된다.이 영역을 \(y\)축으로 돌리면 부피는?
  2. 6~14초영역 안에 세로로 얇은 띠 하나가 그려진다. 띠의 위끝이 직선에, 아래끝이 포물선에 닿아 반짝인다.먼저 띠 하나를 긋는다.
  3. 14~24초띠가 \(y\)축을 중심으로 돌아 얇은 원통 껍질이 되며 3차원으로 솟아오른다. 반지름 \(x\)와 높이 \(2x - x^2\)에 치수선이 붙는다.축과 평행한 띠는 돌면 원통껍질.
  4. 24~32초껍질이 세로로 잘려 펼쳐지며 얇은 직사각형 판이 된다. 가로 \(2\pi x\), 세로 \(2x - x^2\), 두께 \(dx\).펼치면 둘레 × 높이 × 두께.
  5. 32~42초같은 영역에 가로 띠가 그려지고 \(y\)축으로 돌아 가운데 구멍 난 와셔가 된다. 바깥 반지름 \(\sqrt y\), 안 반지름 \(\frac y2\).축에 수직인 띠는 돌면 와셔.
  6. 42~55초축이 \(x = 3\)으로 옮겨 가고, 띠에서 새 축까지 화살표가 그려져 길이 \(3 - x\)가 표시된다. 원래의 반지름 \(x\)에는 X가 뜬다.반지름은 언제나 축까지의 거리이다.
