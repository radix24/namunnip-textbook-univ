절대수렴과 조건수렴은 무엇이 다른가

재배열 · 리만 재배열 정리
정의

\(\sum|a_n|\)이 수렴하면 \(\sum a_n\)은 절대수렴한다. \(\sum a_n\)은 수렴하지만 \(\sum|a_n|\)은 발산하면 조건수렴한다.

절대수렴하면 수렴한다

  1. \(0 \le a_n + |a_n| \le 2|a_n|\).
    \(a_n \ge 0\)이면 \(2a_n\), \(a_n < 0\)이면 0.
  2. \(\sum 2|a_n|\)이 수렴하므로 비교 판정으로 \(\sum(a_n + |a_n|)\)이 수렴한다.
    양의 항 급수의 비교 판정.
  3. \(\sum a_n = \sum(a_n + |a_n|) - \sum|a_n|\)은 수렴하는 두 급수의 차이므로 수렴한다.
    수렴 급수의 선형성.

그래서 부호가 섞인 급수는 먼저 \(\sum|a_n|\)에 양의 항 판정법(비교, 비, 근, 적분)을 쓴다. 수렴하면 끝, 발산하면 교대급수 판정 등으로 조건수렴인지 본다.

차이가 드러나는 곳: 순서 바꾸기

유한 합은 순서를 바꿔도 같다. 무한 합은 그렇지 않을 수 있다.

교대 조화급수 \(1 - \frac12 + \frac13 - \frac14 + \cdots = \ln 2\) (8-05 카드에서 Taylor 급수로 확인)는 조건수렴한다. 항의 순서를 "양수 하나, 음수 둘"로 바꿔 본다.

\[\left(1 - \tfrac12\right) - \tfrac14 + \left(\tfrac13 - \tfrac16\right) - \tfrac18 + \left(\tfrac15 - \tfrac1{10}\right) - \tfrac1{12} + \cdots = \tfrac12 - \tfrac14 + \tfrac16 - \tfrac18 + \tfrac1{10} - \cdots\]

오른쪽은 \(\frac12\left(1 - \frac12 + \frac13 - \cdots\right) = \frac12\ln 2\)이다. 같은 항들을 같은 횟수로 썼는데 합이 절반이 되었다.

정리 (증명은 해석학)

절대수렴하는 급수는 어떻게 재배열해도 같은 합으로 수렴한다.

리만 재배열 정리: 조건수렴하는 급수는 재배열해서 임의의 실수로 수렴하게 하거나 발산하게 할 수 있다.

왜 그런가 (직관)

조건수렴하는 급수에서 양수 항만 모은 급수와 음수 항만 모은 급수는 둘 다 발산합니다(하나라도 수렴하면 절대수렴하거나 원래 급수가 발산). 무한히 큰 양의 "저수지"와 음의 "저수지"가 있으니, 목표값을 넘을 때까지 양수를 더하고, 넘으면 음수를 더하기를 되풀이하면 어떤 목표에도 다가갈 수 있다. 항이 0으로 가므로 흔들림도 점점 작아진다. 절대수렴하는 급수는 두 저수지가 모두 유한해서 이렇게 할 수 없다.

예

  • \(\sum\frac{(-1)^n}{n^2}\): \(\sum\frac1{n^2}\) 수렴 → 절대수렴.
  • \(\sum\frac{(-1)^n}{n}\): 교대급수로 수렴, \(\sum\frac1n\) 발산 → 조건수렴.
  • \(\sum\frac{\sin n}{n^2}\): 교대급수가 아니지만 \(\left|\frac{\sin n}{n^2}\right| \le \frac{1}{n^2}\) → 절대수렴, 따라서 수렴.
  • \(\sum(-1)^n\frac{n}{n+1}\): 항이 0으로 가지 않음 → 발산(절대도 조건도 아님).

흔한 오해

  • "수렴하는 급수는 괄호를 풀거나 순서를 바꿔도 된다." 괄호를 넣는 것은 괜찮지만, 순서 바꾸기는 절대수렴할 때만 안전하다. 또 괄호를 푸는 것은 안 될 수 있다: \((1 - 1) + (1 - 1) + \cdots = 0\)이지만 \(1 - 1 + 1 - \cdots\)은 발산한다.
