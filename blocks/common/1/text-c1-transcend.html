1.4.1지수함수 다시 보기

세균 한 마리가 한 시간마다 둘로 나뉘면 \(t\)시간 뒤에는 \(2^t\)마리가 됩니다. 빚에 매년 5%의 이자가 붙으면 \(t\)년 뒤의 원리금은 처음의 \(1.05^t\)배입니다. 이렇게 같은 시간 동안 같은 비율로 늘거나 주는 양은 지수함수로 나타냅니다.

정의 1.4.1 (지수함수)

\(a > 0\), \(a \ne 1\)인 상수 \(a\)에 대하여 \(f(x) = a^x\)를 밑이 \(a\)인 지수함수라 한다. 정의역은 실수 전체, 치역은 \((0, \infty)\)이다.

고교 수학I에서 배운 성질을 정리하면 다음과 같습니다. 모두 지수법칙 \(a^{x+y} = a^x a^y\), \((a^x)^y = a^{xy}\)에서 나옵니다.

  • \(a > 1\)이면 증가함수, \(0 < a < 1\)이면 감소함수이다. 따라서 일대일이고 역함수가 있다.
  • 그래프는 언제나 점 \((0, 1)\)을 지나고, \(x\)축 위에 있다(\(a^x > 0\)).
  • \(a > 1\)이면 \(x \to -\infty\)일 때 \(a^x \to 0\)이다. 곧 \(x\)축이 점근선이다.
  • \(\left(\frac1a\right)^x = a^{-x}\)이므로 밑이 \(\frac1a\)인 그래프는 밑이 \(a\)인 그래프를 \(y\)축에 대해 뒤집은 것이다.

\(a^x\)에서 \(x\)가 무리수일 때, 예를 들어 \(2^{\sqrt2}\)는 무엇일까요? 고등학교에서는 넘어갔지만, 1.1절의 상한으로 정의할 수 있습니다. \(\sqrt2\)보다 작은 유리수 \(r\)에 대해 \(2^r\)들을 모은 집합의 상한이 \(2^{\sqrt2}\)입니다. 이 집합은 위로 유계(\(2^2 = 4\)가 상계)이므로 완비성 공리가 상한의 존재를 보장합니다.

1.4.2특별한 밑 \(e\)

밑으로 2나 10을 써도 되는데, 미적분에서는 거의 언제나 \(e \approx 2.718\)이라는 이상한 수를 씁니다. 이유는 접선의 기울기에 있습니다.

지수함수 \(y = a^x\)의 그래프가 점 \((0, 1)\)에서 갖는 접선의 기울기를 생각합시다. 접선의 기울기는 두 점 \((0, 1)\), \((h, a^h)\)를 잇는 직선의 기울기 \(\frac{a^h - 1}{h}\)에서 \(h\)를 0에 가깝게 보낸 값입니다(고교 수학II의 미분계수, 2.1절에서 다시 정의합니다). 계산기로 \(h = 0.0001\)을 넣어 보면

\(a\)22.52.72.723
\(\frac{a^h - 1}{h}\) (\(h = 0.0001\))0.69320.91630.99331.00071.0987

입니다. 밑이 커질수록 기울기가 커지고, 2.7과 2.72 사이 어딘가에서 기울기가 정확히 1이 됩니다. 그 밑을 \(e\)라고 부릅니다.

정의 1.4.2 (자연상수 \(e\))

\(y = a^x\)의 그래프의 \((0, 1)\)에서의 접선의 기울기가 1이 되는 밑 \(a\)를 \(e\)라 한다. 곧

\[\lim_{h\to0}\frac{e^h - 1}{h} = 1.\]

\(e = 2.71828\ldots\)이고 무리수이다.

왜 기울기 1이 좋을까요? 2.2절에서 보겠지만, 이 성질 하나 때문에 \(e^x\)의 도함수가 자기 자신 \(e^x\)가 됩니다. 다른 밑이면 \((a^x)' = (\text{상수})\cdot a^x\) 꼴로 귀찮은 상수가 붙습니다. 그래서 미적분, 물리, 화학, 통계에서 지수함수는 거의 언제나 \(e^x\)로 씁니다. \(e^x\)를 \(\exp(x)\)로 쓰기도 합니다.

같은 수 \(e\)가 이자 계산에서도 나옵니다. 연이율 100%를 1년에 \(n\)번 나누어 복리로 붙이면 1년 뒤 원리금은 \(\left(1 + \frac1n\right)^n\)배입니다. \(n = 1, 12, 365, 10^6\)이면 각각 2, 2.613, 2.7146, 2.71828로, \(n\)을 키울수록 \(e\)에 다가갑니다. 두 정의가 같은 수를 준다는 것은 8.8절에서 확인합니다.

1.4.3로그함수와 자연로그

정의 1.4.3 (로그함수)

지수함수 \(y = a^x\)의 역함수를 밑이 \(a\)인 로그함수라 하고 \(y = \log_a x\)로 쓴다. 곧 \(\log_a x = y \iff a^y = x\). 정의역은 \((0, \infty)\), 치역은 실수 전체이다.

밑이 \(e\)인 로그를 자연로그라 하고 \(\ln x\)로 씁니다. \(\ln x = y \iff e^y = x\)입니다. 역함수 관계에서 바로

\[e^{\ln x} = x \quad (x > 0), \qquad \ln(e^x) = x \quad (x \in \mathbb{R})\]

입니다. 로그의 성질(고교 수학I)은 지수법칙을 뒤집은 것입니다.

  • \(\ln(xy) = \ln x + \ln y\), \(\ln\frac xy = \ln x - \ln y\), \(\ln(x^r) = r\ln x\) (\(x, y > 0\)).
  • \(\ln 1 = 0\), \(\ln e = 1\). \(0 < x < 1\)이면 \(\ln x < 0\).
  • 밑 바꾸기: \(\log_a x = \frac{\ln x}{\ln a}\). 그래서 어떤 로그든 자연로그로 바꿔 쓸 수 있다.
  • \(a^x = e^{x\ln a}\). 어떤 지수함수든 \(e\)의 거듭제곱으로 바꿔 쓸 수 있다.

마지막 두 성질 덕분에 앞으로는 \(e^x\)와 \(\ln x\)만 다루면 됩니다. 예를 들어 1.4.2의 표에서 밑이 \(a\)일 때의 기울기가 정확히 \(\ln a\)라는 것도 2.2절에서 보입니다(\(\ln 2 = 0.6931\ldots\), \(\ln 3 = 1.0986\ldots\)으로 표와 맞습니다).

예제 1.4.4

방사성 탄소 \({}^{14}\text{C}\)의 양은 5730년마다 절반이 된다. 처음 양을 \(N_0\)이라 할 때 \(t\)년 뒤의 양 \(N(t)\)를 \(e\)를 써서 나타내고, 양이 처음의 10%가 되는 데 걸리는 시간을 구하여라.

풀이. 5730년마다 절반이므로 \(N(t) = N_0\left(\frac12\right)^{t/5730}\)입니다. \(\frac12 = e^{-\ln 2}\)이므로

\[N(t) = N_0\, e^{-kt}, \qquad k = \frac{\ln 2}{5730} \approx 1.210\times10^{-4}\ \text{/년}.\]

\(N(t) = 0.1N_0\)이면 \(e^{-kt} = 0.1\), 양변에 자연로그를 취해 \(-kt = \ln 0.1 = -\ln 10\), 따라서 \(t = \frac{\ln 10}{k} = 5730\cdot\frac{\ln 10}{\ln 2} \approx 5730 \times 3.322 \approx 19\,000\)년입니다. 검산: 반감기를 세 번 지나면 \(\frac18 = 12.5\%\), 네 번이면 \(6.25\%\)이므로, 10%는 세 번(17 190년)과 네 번(22 920년) 사이여야 합니다. 답 19 000년은 그 사이에 있습니다.

이처럼 "\(N\)이 지수적으로 줄어든다"를 \(N_0 e^{-kt}\)로 쓰는 것이 표준입니다. 공통6-03(반응 속도), 공통4-03-03(축전기 방전)에서 같은 꼴이 다시 나옵니다.

1.4.4쌍곡선 함수

\(e^x\)와 \(e^{-x}\)를 더하고 빼서 만든 함수들이 공학과 물리에 자주 나옵니다. 양 끝을 잡은 쇠사슬이 처지는 모양, 상대성 이론의 속도 덧셈, 미분방정식 \(y'' = y\)의 해가 그 예입니다.

정의 1.4.5 (쌍곡선 함수) \[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x}.\]

각각 하이퍼볼릭 사인, 하이퍼볼릭 코사인, 하이퍼볼릭 탄젠트라 읽는다.

그래프의 모양을 정의에서 읽어 봅시다.

  • \(\cosh x\): \(e^x\)와 \(e^{-x}\)의 평균이다. \(x\)를 \(-x\)로 바꿔도 같으므로 우함수이고(\(y\)축 대칭), \(\cosh 0 = 1\)이 최솟값이다. \(x\)가 커지면 \(e^{-x}\)는 0으로 가므로 \(\cosh x \approx \frac{e^x}{2}\)이다. 그래프는 U자 모양으로, 늘어진 쇠사슬의 모양(현수선)이다.
  • \(\sinh x\): 기함수이고(원점 대칭) \(\sinh 0 = 0\)이며 증가함수이다. 큰 \(x\)에서 \(\sinh x \approx \frac{e^x}{2}\), 큰 음수 \(x\)에서 \(\approx -\frac{e^{-x}}{2}\)이다.
  • \(\tanh x\): 기함수이고 증가하며, 값이 \(-1\)과 1 사이에 있다. \(x \to \infty\)일 때 1, \(x \to -\infty\)일 때 \(-1\)로 다가간다.

이름에 "사인", "코사인"이 붙은 이유는 삼각함수와 아주 닮은 항등식을 만족하기 때문입니다.

정리 1.4.6

모든 실수 \(x\)에 대하여 \(\cosh^2 x - \sinh^2 x = 1\).

증명.정의를 넣고 전개한다. \(\cosh^2 x = \frac{e^{2x} + 2 + e^{-2x}}{4}\), \(\sinh^2 x = \frac{e^{2x} - 2 + e^{-2x}}{4}\)이다. 여기서 \(e^x e^{-x} = e^0 = 1\)을 썼다. 빼면 \(\frac{4}{4} = 1\)이다. ∎

삼각함수에서는 \(\cos^2 t + \sin^2 t = 1\)이라서 점 \((\cos t, \sin t)\)가 원 \(x^2 + y^2 = 1\) 위에 있습니다. 쌍곡선 함수에서는 부호가 하나 바뀌어 점 \((\cosh t, \sinh t)\)가 쌍곡선 \(x^2 - y^2 = 1\) 위에 있습니다. "쌍곡선 함수"라는 이름이 여기서 왔습니다.

덧셈 공식도 삼각함수와 닮았습니다: \(\sinh(x + y) = \sinh x\cosh y + \cosh x\sinh y\), \(\cosh(x + y) = \cosh x\cosh y + \sinh x\sinh y\). 둘째 식은 코사인과 부호가 다릅니다(연습문제 5).

예제 1.4.7 (역쌍곡선 사인)

\(\sinh\)는 증가함수이므로 역함수가 있다. \(\sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right)\)임을 보여라.

풀이. \(y = \sinh^{-1}x\)이면 \(x = \sinh y = \frac{e^y - e^{-y}}{2}\)입니다. \(u = e^y\)로 놓으면 \(2x = u - \frac1u\), 양변에 \(u\)를 곱하면 \(u^2 - 2xu - 1 = 0\)인 \(u\)에 대한 이차방정식입니다. 근의 공식으로 \(u = x \pm \sqrt{x^2 + 1}\). \(u = e^y > 0\)이어야 하는데 \(x - \sqrt{x^2 + 1} < 0\)이므로(\(\sqrt{x^2 + 1} > \sqrt{x^2} = |x| \ge x\)) 부호는 +입니다. 따라서 \(e^y = x + \sqrt{x^2 + 1}\), \(y = \ln(x + \sqrt{x^2 + 1})\).

쌍곡선 함수가 지수함수로 정의되므로 그 역함수는 로그로 나옵니다. 이 식은 5.3절에서 \(\int\frac{dx}{\sqrt{x^2 + 1}}\)을 계산할 때 다시 만납니다.

1.4.5세 함수의 크기 비교

\(x\)가 커질 때 \(\ln x\), \(x^n\), \(e^x\)는 모두 무한히 커지지만 빠르기가 크게 다릅니다. \(x = 100\)이면 \(\ln 100 \approx 4.6\), \(100^2 = 10^4\), \(e^{100} \approx 2.7\times10^{43}\)입니다. 일반적으로

\[\ln x \ll x^p \ll e^x \qquad (x \to \infty,\ p > 0)\]

입니다. 여기서 \(f \ll g\)는 \(\frac{f(x)}{g(x)} \to 0\)이라는 뜻입니다. 이 사실은 3.3절(로피탈 정리)에서 증명합니다. 알고리즘의 실행 시간을 비교할 때(전전2 데이터구조), 확률분포의 꼬리를 비교할 때 이 순서가 기준이 됩니다.

주의\(\ln(x + y) = \ln x + \ln y\)는 틀립니다. 로그는 곱을 합으로 바꾸지 합을 바꾸지 않습니다. 또 \((\ln x)^2\)과 \(\ln(x^2) = 2\ln x\)는 다릅니다. \(\ln^2 x\)라고 쓰면 \((\ln x)^2\)을 뜻합니다.
요약
  1. 지수함수 \(a^x\)는 같은 비율로 늘거나 주는 양을 나타낸다. 증가 또는 감소하므로 역함수 \(\log_a x\)가 있다.
  2. \(e\)는 \(y = a^x\)의 \((0,1)\)에서의 접선 기울기가 1이 되는 밑이다. \(e \approx 2.71828\).
  3. \(a^x = e^{x\ln a}\), \(\log_a x = \frac{\ln x}{\ln a}\)이므로 \(e^x\)와 \(\ln x\)만 알면 된다.
  4. \(\cosh x = \frac{e^x + e^{-x}}{2}\), \(\sinh x = \frac{e^x - e^{-x}}{2}\), \(\cosh^2 x - \sinh^2 x = 1\).
  5. 크게 갈 때 \(\ln x \ll x^p \ll e^x\).

1.4.6연습문제

기본

  1. 다음을 간단히 하여라. (가) \(e^{3\ln 2}\) (나) \(\ln\frac{1}{\sqrt e}\) (다) \(\log_2 5\)를 자연로그로
    답

    (가) \(e^{\ln 8} = 8\) (나) \(-\frac12\) (다) \(\frac{\ln 5}{\ln 2}\)

  2. 방정식 \(3e^{2x} = 7\)을 풀어라.
    답

    \(e^{2x} = \frac73\), \(x = \frac12\ln\frac73 \approx 0.424\).

  3. \(\cosh x\)가 우함수, \(\sinh x\)가 기함수임을 정의로 보여라.
    답

    \(\cosh(-x) = \frac{e^{-x} + e^{x}}{2} = \cosh x\). \(\sinh(-x) = \frac{e^{-x} - e^{x}}{2} = -\sinh x\).

응용

  1. 어떤 양이 매년 3%씩 늘어난다. 두 배가 되는 데 걸리는 시간을 구하고, "72를 이율(%)로 나누면 두 배 시간"이라는 경험 규칙과 비교하여라.
    힌트

    \(1.03^t = 2\)에서 \(t = \frac{\ln 2}{\ln 1.03}\).

    답

    \(t = \frac{0.6931}{0.02956} \approx 23.4\)년. 경험 규칙은 \(\frac{72}{3} = 24\)년으로 비슷하다. 정확한 식 \(\frac{\ln 2}{\ln(1 + r)}\)에서 \(\ln(1 + r) \approx r\)로 어림하면 \(\frac{69.3}{100r}\)인데, \(\ln(1 + r)\)이 \(r\)보다 조금 작은 것을 보정하고 암산하기 쉽게 분자를 72로 올린 것이 이 규칙이다.

  2. \(\cosh(x + y) = \cosh x\cosh y + \sinh x\sinh y\)임을 보여라.
    힌트

    오른쪽을 \(e^x, e^y\)로 전개하면 \(e^{x+y}\)와 \(e^{-x-y}\) 항만 남습니다.

    답

    오른쪽 \(= \frac{(e^x + e^{-x})(e^y + e^{-y}) + (e^x - e^{-x})(e^y - e^{-y})}{4} = \frac{2e^{x+y} + 2e^{-x-y}}{4} = \cosh(x+y)\). 교차항 \(e^{x-y}\), \(e^{-x+y}\)는 부호가 반대라 지워진다.

심화

  1. \(\tanh^{-1}x = \frac12\ln\frac{1 + x}{1 - x}\) (\(-1 < x < 1\))임을 보여라.
    힌트

    \(x = \tanh y = \frac{e^{2y} - 1}{e^{2y} + 1}\)을 \(e^{2y}\)에 대해 푸세요.

    답

    \(x(e^{2y} + 1) = e^{2y} - 1\)에서 \(e^{2y} = \frac{1 + x}{1 - x}\), \(y = \frac12\ln\frac{1+x}{1-x}\). \(|x| < 1\)이면 분수가 양수라 로그가 정의된다.
