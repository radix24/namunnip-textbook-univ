곡선의 길이

본문

곡선 \(y = x^{3/2}\)의 \(x = 0\)부터 1까지의 길이는 얼마일까? 실을 곡선에 대고 편 다음 자로 재는 일을 계산으로 하려면 어떻게 해야 할까?

먼저 알아야 할 것고교 수학의 두 점 사이의 거리 \(\sqrt{\Delta x^2 + \Delta y^2}\)와 정적분(4.1절), 치환적분(4.3절)을 쓴다.

6.3.1짧은 선분으로 어림하기

수학에서는 곡선 위에 점을 촘촘히 찍고 이웃한 점을 선분으로 이어 그 길이를 더한다. 선분은 길이를 재기 쉽기 때문이다. 이웃한 두 점 사이에서 \(x\)가 \(\Delta x\), \(y\)가 \(\Delta y\)만큼 변하면 선분의 길이는 피타고라스 정리로 다음과 같다.

\[\sqrt{\Delta x^2 + \Delta y^2} = \sqrt{1 + \left(\frac{\Delta y}{\Delta x}\right)^2}\,\Delta x\]

그림 1에서 선분 수를 1에서 30까지 늘려 보면 꺾은선의 길이는 1.414에서 1.440 가까이로 자란다. 그리고 점을 한없이 촘촘히 하면 \(\frac{\Delta y}{\Delta x}\)는 그 자리의 기울기 \(f'(x)\)가 되고, 합은 정적분이 된다.

정의 6.3.1 (곡선의 길이)

\(f'\)이 \([a, b]\)에서 연속이면 곡선 \(y = f(x)\) (\(a \le x \le b\))의 길이는

\[L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx.\]

\(ds = \sqrt{1 + (y')^2}\,dx\)를 아주 짧은 곡선 조각의 길이라고 읽으면 기억하기 쉽다. 즉 이 식은 피타고라스 정리 \(ds^2 = dx^2 + dy^2\)을 \(dx\)로 묶은 것이다. 곡선이 평평한 곳(\(f' \approx 0\))에서는 \(ds \approx dx\)이고, 가파른 곳에서는 같은 \(dx\)에 더 긴 \(ds\)가 대응한다.

예제 6.3.2

\(y = x^{3/2}\), \(0 \le x \le 1\)의 길이를 구하여라.

풀이. \(y' = \frac32x^{1/2}\)이므로 \(1 + (y')^2 = 1 + \frac94x\)이다. \(u = 1 + \frac94x\)로 치환하면 다음을 얻는다.

\[L = \int_0^1\sqrt{1 + \tfrac94x}\,dx = \frac49\cdot\frac23\left[u^{3/2}\right]_1^{13/4} = \frac{8}{27}\left(\frac{13\sqrt{13}}{8} - 1\right) = \frac{13\sqrt{13} - 8}{27} \approx 1.440\]

이 답을 처음 질문의 그림으로 되짚어 보자. 두 끝점 \((0, 0)\)과 \((1, 1)\)을 잇는 선분, 곧 \(n = 1\)인 꺾은선의 길이는 \(\sqrt2 \approx 1.414\)이다. 곡선은 그 선분보다 조금 길어야 하므로 1.440은 그럴듯하다. 실제로 \(n = 3\)이면 약 1.434이고, \(n\)을 늘릴수록 1.440에 아래쪽에서 다가간다. 꺾은선이 언제나 곡선보다 짧은 까닭은 두 점 사이의 가장 짧은 길이 선분이기 때문이다. 그래서 선분을 더 잘게 나누면 꺾은선이 곡선을 더 바짝 따라가며 길어질 뿐, 곡선보다 길어지지는 않는다.

그런데 근호 안이 완전제곱이 되지 않으면 이 적분은 대개 계산하기 어렵다. 그래서 교재의 예제와 연습문제에는 \(1 + (y')^2\)이 완전제곱이 되거나 치환 한 번으로 풀리도록 골라 놓은 함수가 많다. 실제 문제에서는 5.6절의 수치 적분으로 어림한다. 가령 포물선 \(y = x^2\)의 길이조차 \(\int\sqrt{1 + 4x^2}\,dx\)가 되어 삼각치환과 부분적분을 함께 써야 하고, 사인 곡선 한 마루의 길이는 기본 함수로 쓸 수 없다.

주의\(\sqrt{1 + (y')^2}\)을 \(1 + y'\)로 바꾸면 틀린다. 근호는 합에 나누어 쓸 수 없다.
마무리

곡선의 길이는 곡선을 짧은 선분으로 나누어 피타고라스 정리로 잰 길이의 합의 극한이고, \(L = \int_a^b\sqrt{1 + (y')^2}\,dx\)로 계산한다. 그래서 처음 질문의 길이는 \(\frac{13\sqrt{13} - 8}{27} \approx 1.440\)이다. 곡선의 길이는 끝점을 잇는 선분보다 길다는 사실이 좋은 검산이 된다.

6.3.2연습문제

기본

  1. 직선 \(y = 2x\), \(0 \le x \le 3\)의 길이를 공식으로 구하고 피타고라스 정리와 비교하여라.
    답

    \(\int_0^3\sqrt5\,dx = 3\sqrt5\). 끝점 \((0,0)\), \((3,6)\)의 거리 \(\sqrt{45} = 3\sqrt5\)와 같다.

응용

  1. \(y = \cosh x\), \(0 \le x \le 1\)의 길이를 구하여라.
    답

    \(1 + \sinh^2x = \cosh^2x\). \(\int_0^1\cosh x\,dx = \sinh1 \approx 1.175\).

  2. \(y = \frac{x^3}{6} + \frac{1}{2x}\), \(1 \le x \le 2\)의 길이를 구하여라.
    답

    \(y' = \frac{x^2}{2} - \frac{1}{2x^2}\), \(1 + y'^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2\). \(\int_1^2\left(\frac{x^2}{2} + \frac{1}{2x^2}\right)dx = \frac76 + \frac14 = \frac{17}{12}\).
