곡선의 길이

본문
이 절에서 배울 것
  • 곡선을 짧은 선분으로 나누어 길이 공식을 얻는다.
  • \(L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx\)로 곡선의 길이를 구한다.
먼저 알아야 할 것
  • 두 점 사이의 거리 \(\sqrt{\Delta x^2 + \Delta y^2}\) (고교 수학), 정적분 (4.1절).

6.3.1짧은 선분으로 어림하기

곡선의 길이를 재려면 실을 곡선에 대고 편 다음 자로 잽니다. 수학에서는 곡선 위에 점을 촘촘히 찍고 이웃한 점을 선분으로 이어 그 길이를 더합니다. 이웃한 두 점 사이에서 \(x\)가 \(\Delta x\), \(y\)가 \(\Delta y\)만큼 변하면 선분의 길이는 \(\sqrt{\Delta x^2 + \Delta y^2} = \sqrt{1 + \left(\frac{\Delta y}{\Delta x}\right)^2}\,\Delta x\)입니다. 점을 한없이 촘촘히 하면 \(\frac{\Delta y}{\Delta x}\)는 \(f'(x)\)가 됩니다.

정의 6.3.1 (곡선의 길이)

\(f'\)이 \([a, b]\)에서 연속이면 곡선 \(y = f(x)\) (\(a \le x \le b\))의 길이는

\[L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx.\]

\(ds = \sqrt{1 + (y')^2}\,dx\)를 "아주 짧은 곡선 조각의 길이"라고 읽으면 기억하기 쉽습니다. 피타고라스 정리 \(ds^2 = dx^2 + dy^2\)을 \(dx\)로 묶은 것입니다.

예제 6.3.2

\(y = x^{3/2}\), \(0 \le x \le 1\)의 길이를 구하여라.

풀이. \(y' = \frac32x^{1/2}\), \(1 + (y')^2 = 1 + \frac94x\). \(u = 1 + \frac94x\)로 치환하면

\[L = \int_0^1\sqrt{1 + \tfrac94x}\,dx = \frac49\cdot\frac23\left[u^{3/2}\right]_1^{13/4} = \frac{8}{27}\left(\frac{13\sqrt{13}}{8} - 1\right) = \frac{13\sqrt{13} - 8}{27} \approx 1.440.\]

검산: 두 끝점 \((0, 0)\)과 \((1, 1)\)을 잇는 선분의 길이는 \(\sqrt2 \approx 1.414\)입니다. 곡선은 선분보다 조금 길어야 하므로 1.440은 그럴듯합니다.

근호 안이 완전제곱이 되지 않으면 이 적분은 대개 계산하기 어렵습니다. 그래서 교재의 예제와 연습문제는 \(1 + (y')^2\)이 완전제곱이 되도록 골라 놓은 함수가 많습니다. 실제 문제에서는 수치 적분으로 어림합니다.

주의\(\sqrt{1 + (y')^2}\)을 \(1 + y'\)로 바꾸면 틀립니다. 근호는 합에 나누어 쓸 수 없습니다.
요약
  1. \(L = \int_a^b\sqrt{1 + (y')^2}\,dx\), \(ds^2 = dx^2 + dy^2\).
  2. 곡선의 길이는 끝점을 잇는 선분보다 길다(검산).

6.3.2연습문제

기본

  1. 직선 \(y = 2x\), \(0 \le x \le 3\)의 길이를 공식으로 구하고 피타고라스 정리와 비교하여라.
    답

    \(\int_0^3\sqrt5\,dx = 3\sqrt5\). 끝점 \((0,0)\), \((3,6)\)의 거리 \(\sqrt{45} = 3\sqrt5\)와 같다.

응용

  1. \(y = \cosh x\), \(0 \le x \le 1\)의 길이를 구하여라.
    답

    \(1 + \sinh^2x = \cosh^2x\). \(\int_0^1\cosh x\,dx = \sinh1 \approx 1.175\).

  2. \(y = \frac{x^3}{6} + \frac{1}{2x}\), \(1 \le x \le 2\)의 길이를 구하여라.
    답

    \(y' = \frac{x^2}{2} - \frac{1}{2x^2}\), \(1 + y'^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2\). \(\int_1^2\left(\frac{x^2}{2} + \frac{1}{2x^2}\right)dx = \frac76 + \frac14 = \frac{17}{12}\).
