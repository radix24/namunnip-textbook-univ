실수와 절댓값

본문
이 절에서 배울 것
  • 절댓값을 "수직선 위의 거리"로 읽는다.
  • \(|x - a| < r\), \(|x - a| > r\) 꼴의 부등식을 풀고 구간으로 쓴다.
  • 삼각부등식을 증명하고 극한 계산에서 쓰는 방식을 익힌다.
먼저 알아야 할 것
  • 절댓값의 뜻 \(|x| = x\) (\(x \ge 0\)), \(-x\) (\(x < 0\)) (고교 수학).
  • 일차·이차부등식의 풀이와 구간 기호 (고교 수학).
  • 상한과 하한 (1.1절)은 이 절의 예제 하나에서만 씁니다.

1.2.1절댓값은 거리이다

고등학교에서 절댓값은 "부호를 떼는 것"으로 배웠습니다. 계산에는 이것으로 충분하지만, 미적분에서는 다른 읽는 법이 훨씬 쓸모 있습니다. \(|x|\)는 수직선 위에서 점 \(x\)와 원점 사이의 거리이고, 일반적으로

\[|x - a| = \text{점 } x \text{와 점 } a \text{ 사이의 거리}\]

입니다. 예를 들어 \(|3 - 7| = 4\)이고 \(|-2 - 5| = 7\)입니다. 빼는 순서는 상관없습니다: \(|x - a| = |a - x|\).

이렇게 읽으면 2장의 극한 정의에 나오는 "\(x\)가 \(a\)에 가깝다"를 숫자로 쓸 수 있습니다. "\(x\)와 \(a\)의 거리가 0.01보다 작다"는 \(|x - a| < 0.01\)입니다. 이 절은 그런 식을 자유롭게 풀고 바꾸는 연습입니다.

계산에 쓰는 기본 성질은 다음과 같습니다. 모두 \(x, y\)의 부호를 나누어 확인할 수 있습니다.

  • \(|x| \ge 0\)이고, \(|x| = 0\)인 것은 \(x = 0\)일 때뿐이다.
  • \(|xy| = |x||y|\), \(\left|\frac xy\right| = \frac{|x|}{|y|}\) (\(y \ne 0\)).
  • \(\sqrt{x^2} = |x|\). 그래서 \(\sqrt{x^2} = x\)라고 쓰면 \(x < 0\)일 때 틀린다.
  • \(-|x| \le x \le |x|\).

1.2.2절댓값 부등식의 기본형

정리 1.2.1

\(r > 0\)일 때

  1. \(|x - a| < r \iff a - r < x < a + r\), 곧 \(x \in (a - r, a + r)\).
  2. \(|x - a| > r \iff x < a - r\) 또는 \(x > a + r\).

거리로 읽으면 바로 보입니다. "\(a\)에서 거리가 \(r\)보다 작은 점"은 \(a\)를 가운데 둔 폭 \(2r\)의 열린구간이고, "거리가 \(r\)보다 큰 점"은 그 바깥입니다. 계산으로 확인하려면 \(x - a \ge 0\)인 경우와 \(x - a < 0\)인 경우로 나누면 됩니다.

증명.(1) \(x - a \ge 0\)이면 \(|x - a| < r\)은 \(x - a < r\), 곧 \(a \le x < a + r\)이다. \(x - a < 0\)이면 \(|x - a| = -(x - a) < r\)은 \(x > a - r\), 곧 \(a - r < x < a\)이다. 두 경우를 합치면 \(a - r < x < a + r\). (2)는 (1)의 부정에서 등호인 경우 \(|x - a| = r\)을 뺀 것이다. ∎

부등호에 등호가 붙으면(\(\le\), \(\ge\)) 구간의 끝점도 포함되어 닫힌구간이 됩니다.

예제 1.2.2

\(|2x - 3| \le 5\)를 풀어 구간으로 나타내어라.

풀이. 정리 1.2.1을 \(2x - 3\)에 적용하면 \(-5 \le 2x - 3 \le 5\)입니다. 세 변에 3을 더하면 \(-2 \le 2x \le 8\), 2로 나누면 \(-1 \le x \le 4\). 답은 \([-1, 4]\)입니다.

거리로 읽어 검산할 수 있습니다. \(|2x - 3| = 2\left|x - \frac32\right|\)이므로 부등식은 \(\left|x - \frac32\right| \le \frac52\), 곧 "\(\frac32\)에서 거리 \(\frac52\) 이내"입니다. \(\frac32 - \frac52 = -1\), \(\frac32 + \frac52 = 4\)로 같은 답입니다.

예제 1.2.3

\(|x + 1| > 2|x - 2|\)를 풀어라.

풀이. 양쪽에 절댓값이 있을 때는 두 가지 방법이 있습니다.

방법 1 (제곱). 양변이 모두 0 이상이므로 제곱해도 부등호 방향이 유지됩니다(\(0 \le A < B \iff A^2 < B^2\)). \((x + 1)^2 > 4(x - 2)^2\)을 정리하면 \(x^2 + 2x + 1 > 4x^2 - 16x + 16\), 곧 \(3x^2 - 18x + 15 < 0\), \(x^2 - 6x + 5 < 0\), \((x - 1)(x - 5) < 0\). 답은 \(1 < x < 5\)입니다.

방법 2 (경우 나누기). 절댓값 안이 0이 되는 \(x = -1\), \(x = 2\)로 수직선을 세 구간으로 나눕니다. \(x < -1\)이면 \(-(x + 1) > -2(x - 2)\), 곧 \(x > 5\)라서 해가 없습니다. \(-1 \le x < 2\)이면 \(x + 1 > -2(x - 2)\), 곧 \(x > 1\)이므로 \(1 < x < 2\). \(x \ge 2\)이면 \(x + 1 > 2(x - 2)\), 곧 \(x < 5\)이므로 \(2 \le x < 5\). 합치면 \(1 < x < 5\).

제곱하는 방법은 빠르지만 양변이 모두 음이 아님을 확인해야 쓸 수 있고, 경우를 나누는 방법은 느리지만 언제나 통합니다.

1.2.3삼각부등식

정리 1.2.4 (삼각부등식)

모든 실수 \(x, y\)에 대하여 \(|x + y| \le |x| + |y|\).

이름은 평면에서 "삼각형의 한 변은 나머지 두 변의 합보다 짧다"는 사실에서 왔습니다. 수직선에서는 "\(0\)에서 \(x\)로 간 뒤 다시 \(y\)만큼 가면, 같은 방향일 때만 거리가 그대로 더해지고 반대 방향이면 일부가 상쇄된다"는 뜻입니다.

증명.1.2.1의 성질에서 \(-|x| \le x \le |x|\), \(-|y| \le y \le |y|\)이다. 두 부등식을 변끼리 더하면 \(-(|x| + |y|) \le x + y \le |x| + |y|\)이다. 정리 1.2.1(등호를 포함한 판)에서 \(r = |x| + |y|\), \(a = 0\)으로 놓으면 이것은 \(|x + y| \le |x| + |y|\)와 같다. ∎

등호는 \(x\)와 \(y\)의 부호가 같을 때(또는 하나가 0일 때) 성립합니다. 삼각부등식에서 자주 쓰는 변형이 둘 있습니다.

  • \(|x - y| \le |x - z| + |z - y|\): 두 점 사이의 거리는 중간에 들른 점을 거친 거리 이하이다. (\(x - y = (x - z) + (z - y)\)에 정리 1.2.4를 쓴다.)
  • \(\big||x| - |y|\big| \le |x - y|\): 역삼각부등식. (\(|x| = |(x - y) + y| \le |x - y| + |y|\)에서 \(|x| - |y| \le |x - y|\), \(x, y\)를 바꾸어 반대쪽도 얻는다.)
예제 1.2.5 (극한 증명에서 쓰는 방식)

\(|x - 2| < 1\)이면 \(|x^2 - 4| < 5|x - 2|\)임을 보여라.

풀이. \(x^2 - 4 = (x - 2)(x + 2)\)이므로 \(|x^2 - 4| = |x - 2||x + 2|\)입니다. 남은 일은 \(|x + 2|\)를 상수로 위에서 막는 것입니다. \(|x - 2| < 1\)이면 \(1 < x < 3\)이므로 \(3 < x + 2 < 5\), 곧 \(|x + 2| < 5\)입니다. 삼각부등식으로도 \(|x + 2| = |(x - 2) + 4| \le |x - 2| + 4 < 5\)를 얻습니다. 따라서 \(|x^2 - 4| < 5|x - 2|\).

이 계산은 1.3절에서 "\(x \to 2\)일 때 \(x^2 \to 4\)"를 증명할 때 그대로 쓰입니다. \(x\)를 2 근처로 제한해 곱해지는 인수를 상수로 막는 것이 요령입니다.

주의\(|x - a| < r\)을 "\(x - a < r\) 그리고 \(x - a < -r\)"처럼 풀면 틀립니다. 올바른 꼴은 \(-r < x - a < r\)입니다. 또 \(|x| < -1\)처럼 오른쪽이 음수이면 해가 없고, \(|x| > -1\)이면 모든 실수가 해입니다. 절댓값은 음수가 될 수 없기 때문입니다.
요약
  1. \(|x - a|\)는 수직선에서 \(x\)와 \(a\) 사이의 거리이다.
  2. \(|x - a| < r \iff x \in (a - r, a + r)\), \(|x - a| > r \iff x\)가 그 구간 밖.
  3. 양변에 절댓값이 있으면 제곱하거나(양변이 0 이상일 때) 경우를 나눈다.
  4. 삼각부등식 \(|x + y| \le |x| + |y|\)와 역삼각부등식 \(\big||x| - |y|\big| \le |x - y|\).

1.2.4연습문제

기본

  1. 다음 부등식을 풀어 구간으로 나타내어라. (가) \(|x - 4| < 0.1\) (나) \(|3x + 6| \ge 9\) (다) \(|1 - 2x| \le 0\)
    답

    (가) \((3.9, 4.1)\) (나) \(3|x + 2| \ge 9\), 곧 \(|x + 2| \ge 3\): \((-\infty, -5] \cup [1, \infty)\) (다) \(1 - 2x = 0\)일 때뿐이므로 \(\{\frac12\}\).

  2. 구간 \((-3, 7)\)을 \(|x - a| < r\) 꼴로 나타내어라.
    답

    중점 \(a = 2\), 반폭 \(r = 5\): \(|x - 2| < 5\).

  3. \(\sqrt{(x - 3)^2} = x - 3\)이 성립하는 \(x\)의 범위를 구하여라.
    답

    \(\sqrt{(x-3)^2} = |x - 3|\)이므로 \(x - 3 \ge 0\), 곧 \(x \ge 3\).

응용

  1. \(|x - 1| + |x + 2| < 5\)를 풀어라.
    힌트

    \(x = -2\), \(x = 1\)로 세 구간을 나누세요. 거리로 읽으면 "1과 \(-2\)까지의 거리의 합이 5보다 작은 점"입니다.

    답

    \(x < -2\): \(-2x - 1 < 5\), \(x > -3\). \(-2 \le x \le 1\): \(3 < 5\) 항상 성립. \(x > 1\): \(2x + 1 < 5\), \(x < 2\). 답 \((-3, 2)\).

  2. \(|x - 3| < 1\)이면 \(\left|\frac1x - \frac13\right| < \frac{|x - 3|}{6}\)임을 보여라.
    힌트

    \(\frac1x - \frac13 = \frac{3 - x}{3x}\). \(|x - 3| < 1\)에서 \(x > 2\).

    답

    \(\left|\frac1x - \frac13\right| = \frac{|x - 3|}{3|x|}\)이고 \(x > 2\)이므로 \(3|x| > 6\). 따라서 \(< \frac{|x-3|}{6}\).

심화

  1. 모든 실수 \(x_1, \dots, x_n\)에 대하여 \(|x_1 + \cdots + x_n| \le |x_1| + \cdots + |x_n|\)임을 수학적 귀납법으로 증명하여라.
    힌트

    \(x_1 + \cdots + x_{n+1} = (x_1 + \cdots + x_n) + x_{n+1}\)에 정리 1.2.4를 쓰세요.

    답

    \(n = 1\)은 등식. \(n\)에서 성립하면 \(|x_1 + \cdots + x_{n+1}| \le |x_1 + \cdots + x_n| + |x_{n+1}| \le |x_1| + \cdots + |x_n| + |x_{n+1}|\). 첫 부등호는 삼각부등식, 둘째는 귀납 가정.
