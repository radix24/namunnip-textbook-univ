부분적분

본문

\(\int xe^x\,dx\)나 \(\int\ln x\,dx\)는 치환으로 풀리지 않는다. 미분의 곱셈 규칙 \((uv)' = u'v + uv'\)을 거꾸로 읽으면 이런 적분을 다른 적분으로 바꿀 수 있지 않을까? 바꾼 적분이 더 쉬우려면 무엇을 골라야 할까?

먼저 알아야 할 것고교 수학II의 곱의 미분법과 치환적분(4.3절)을 쓴다.

5.1.1곱의 미분법을 거꾸로

\(\int xe^x\,dx\)는 안쪽 함수와 그 도함수가 함께 있는 꼴이 아니어서 치환으로 풀리지 않는다. 이런 곱의 적분에는 곱의 미분법 \((uv)' = u'v + uv'\)을 쓴다. 양변을 적분하면 \(uv = \int v\,du + \int u\,dv\)이고, 이것을 정리하면 다음을 얻는다.

정리 5.1.1 (부분적분) \[\int u\,dv = uv - \int v\,du, \qquad \int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du.\]

적분할 식을 \(u\)와 \(dv\) 두 부분으로 나누어, \(u\)는 미분하고 \(dv\)는 적분한다. 그러면 새로 생긴 \(\int v\,du\)가 처음 것보다 쉬워지도록 나누는 것이 요령이다.

그림 1은 정적분 꼴을 넓이로 보여 준다. 가로축을 \(v\), 세로축을 \(u\)로 잡고 \(u = \ln x\), \(v = x\)인 곡선을 그리면, \(v = 1\)부터 \(v = b\)까지 곡선 아래 넓이가 \(\int u\,dv\)이고 곡선 왼쪽의 넓이가 \(\int v\,du\)이다. 두 조각을 합치면 큰 직사각형에서 작은 직사각형을 뺀 \(\big[uv\big]\)가 된다. 즉 부분적분은 "한쪽 넓이를 모르면 다른 쪽 넓이로 구한다"는 말이다.

예제 5.1.2

(가) \(\int xe^x\,dx\) (나) \(\int\ln x\,dx\)

풀이. (가) \(u = x\), \(dv = e^xdx\)로 놓으면 \(du = dx\), \(v = e^x\)이다. 따라서 \(\int xe^xdx = xe^x - \int e^xdx = xe^x - e^x + C\)이다. 거꾸로 \(u = e^x\), \(dv = x\,dx\)로 놓으면 \(\int\frac{x^2}{2}e^xdx\)가 남아 더 어려워진다.

(나) 곱이 아닌 것 같지만 \(\ln x\cdot1\)로 본다. \(u = \ln x\), \(dv = dx\)로 놓으면 \(du = \frac{dx}{x}\), \(v = x\)이다. 따라서 \(\int\ln x\,dx = x\ln x - \int x\cdot\frac1x dx = x\ln x - x + C\)이다. 그림 1에서 \(b = 4\)로 두면 왼쪽 조각 \(\int v\,du = \int_0^{\ln 4}e^u\,du = 3\)이고, 바깥 직사각형은 \(4\ln 4 \approx 5.545\)이므로 아래 조각은 \(5.545 - 3 = 2.545\)이다. 공식으로 구한 \(\big[x\ln x - x\big]_1^4 = 4\ln4 - 3 \approx 2.545\)와 같다.

\(u\)로 고르기 좋은 함수는 흔히 로그, 역삼각, 다항, 삼각, 지수의 순서로 외운다. 앞쪽에 있을수록 \(u\)로 고르는데, 앞쪽 함수일수록 미분하면 간단해지기 때문이다. 로그와 역삼각함수는 미분하면 유리식이 되고, 다항식은 미분할 때마다 차수가 낮아진다.

5.1.2두 번 쓰기와 되돌아오는 적분

예제 5.1.3

(가) \(\int x^2\sin x\,dx\) (나) \(\int e^x\sin x\,dx\)

풀이. (가) \(u = x^2\), \(dv = \sin x\,dx\)로 놓으면 적분은 \(-x^2\cos x + \int2x\cos x\,dx\)가 된다. 남은 적분에 한 번 더, \(u = 2x\), \(dv = \cos x\,dx\)로 쓰면 \(\int2x\cos x\,dx = 2x\sin x - \int2\sin x\,dx = 2x\sin x + 2\cos x\)이다. 합치면 \(-x^2\cos x + 2x\sin x + 2\cos x + C\)이다. 다항식의 차수가 2이므로 두 번 만에 다항식이 사라졌다.

(나) \(I = \int e^x\sin x\,dx\)라 하고 \(u = \sin x\), \(dv = e^xdx\)로 놓으면 \(I = e^x\sin x - \int e^x\cos x\,dx\)이다. 다시 \(u = \cos x\), \(dv = e^xdx\)로 놓으면 \(\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I\)이다. 이것을 대입하면 \(I = e^x\sin x - e^x\cos x - I\)가 되어, 원래 적분 \(I\)가 오른쪽에 다시 나타난다. 그러면 이항해서 \(2I = e^x(\sin x - \cos x)\)이고, 따라서

\[\int e^x\sin x\,dx = \frac{e^x}{2}(\sin x - \cos x) + C\]

이다. 그러니 원래 적분이 되돌아오면 방정식처럼 풀면 된다. 다만 두 번 모두 같은 종류, 여기서는 삼각함수를 \(u\)로 골라야 한다. 둘째에 지수함수를 \(u\)로 고르면 첫째 단계를 되돌리는 셈이 되어 \(I = I\)라는 쓸모없는 식이 나온다.

주의\(\int u\,dv\)의 부호를 놓치기 쉽다. \(uv\)에서 \(\int v\,du\)를 빼는 것이다. 또 정적분에서는 \(uv\)에도 위끝과 아래끝 값을 넣어야 한다.
마무리

곱의 미분법을 적분하면 \(\int u\,dv = uv - \int v\,du\)를 얻고, 이것은 그림 1에서 직사각형을 두 조각으로 나누는 일과 같다. 그래서 처음 질문의 \(\int xe^x\,dx\)는 \(u = x\)를 골라 \(xe^x - e^x + C\)가 되고, \(\int\ln x\,dx\)는 \(\ln x\cdot1\)로 보아 \(x\ln x - x + C\)가 된다. \(u\)는 미분하면 간단해지는 함수로 고르며, 원래 적분이 되돌아오면 방정식으로 푼다.

5.1.3연습문제

기본

  1. (가) \(\int x\cos x\,dx\) (나) \(\int x\ln x\,dx\) (다) \(\int_0^1 xe^{2x}dx\)
    답

    (가) \(x\sin x + \cos x + C\) (나) \(\frac{x^2}{2}\ln x - \frac{x^2}{4} + C\) (다) \(\left[\frac{x}{2}e^{2x} - \frac14e^{2x}\right]_0^1 = \frac{e^2 + 1}{4}\)

응용

  1. \(\int\arctan x\,dx\)를 구하여라.
    답

    \(u = \arctan x\), \(dv = dx\): \(x\arctan x - \int\frac{x}{1 + x^2}dx = x\arctan x - \frac12\ln(1 + x^2) + C\).

  2. \(\int e^x\cos x\,dx\)를 구하여라.
    답

    \(\frac{e^x}{2}(\sin x + \cos x) + C\).
