삼각치환

본문

반지름 \(a\)인 원의 넓이가 \(\pi a^2\)이라는 사실을 적분으로 보이려면 \(\int_{-a}^a\sqrt{a^2 - x^2}\,dx\)를 계산해야 한다. 근호 안의 \(a^2 - x^2\)를 깔끔한 제곱으로 바꿀 방법이 있을까?

먼저 알아야 할 것치환적분(4.3절)과 삼각함수의 적분(5.2절), 그리고 항등식 \(1 - \sin^2\theta = \cos^2\theta\), \(1 + \tan^2\theta = \sec^2\theta\)를 쓴다.

5.3.1근호를 없애는 치환

원의 넓이 적분에서 근호 안 \(a^2 - x^2\)의 도함수 \(-2x\)는 바깥에 곱해져 있지 않으므로, 4.3절의 치환은 통하지 않는다. 그런데 \(x = a\sin\theta\)로 놓으면 \(a^2 - x^2 = a^2(1 - \sin^2\theta) = a^2\cos^2\theta\)가 되어 근호가 벗겨진다. 그림 1에서 \(\theta\)를 움직여 보면, 원 위의 점의 높이가 언제나 \(a\cos\theta\)이고 가로 위치가 \(a\sin\theta\)이다. 다시 말해 근호는 원의 높이를 뜻했고, 원을 각으로 재면 높이가 삼각함수 하나로 쓰인다. 이렇게 \(x\)를 삼각함수로 바꾸는 방법을 삼각치환이라 한다.

근호의 모양에 따라 쓰는 항등식이 다르다. 아래 표의 세 경우가 기본이다.

식에 있는 것치환쓰는 항등식
\(\sqrt{a^2 - x^2}\)\(x = a\sin\theta\), \(-\frac\pi2 \le \theta \le \frac\pi2\)\(1 - \sin^2\theta = \cos^2\theta\)
\(\sqrt{a^2 + x^2}\)\(x = a\tan\theta\), \(-\frac\pi2 < \theta < \frac\pi2\)\(1 + \tan^2\theta = \sec^2\theta\)
\(\sqrt{x^2 - a^2}\)\(x = a\sec\theta\)\(\sec^2\theta - 1 = \tan^2\theta\)

\(\theta\)의 범위를 정해 두는 까닭은 1.2절의 역삼각함수와 같다. 그 범위에서 \(\theta\)가 \(x\)마다 하나로 정해지고, \(\cos\theta \ge 0\)처럼 근호를 벗길 때의 부호가 정해진다.

예제 5.3.1

반지름 \(a\)인 원의 넓이가 \(\pi a^2\)임을 적분으로 보여라.

풀이. 대칭을 쓰면 넓이는 \(4\int_0^a\sqrt{a^2 - x^2}\,dx\)이다. \(x = a\sin\theta\)로 놓으면 \(dx = a\cos\theta\,d\theta\)이고, 구간은 \(x = 0\)이면 \(\theta = 0\), \(x = a\)이면 \(\theta = \frac\pi2\)로 바뀐다. 이 범위에서 \(\cos\theta \ge 0\)이므로 \(\sqrt{a^2 - x^2} = a\cos\theta\)이다. 따라서

\[4\int_0^{\pi/2}a\cos\theta\cdot a\cos\theta\,d\theta = 4a^2\int_0^{\pi/2}\cos^2\theta\,d\theta = 4a^2\cdot\frac\pi4 = \pi a^2\]

이다. 마지막 적분은 5.2절의 반각 공식으로 구했다. 결과를 처음 질문과 맞춰 보면, 적분이 원의 넓이를 정확히 돌려준다.

예제 5.3.2

\(\int\dfrac{dx}{x^2\sqrt{x^2 + 4}}\)를 구하여라.

풀이. 근호가 \(\sqrt{x^2 + 4}\) 꼴이므로 \(x = 2\tan\theta\)로 놓는다. 그러면 \(dx = 2\sec^2\theta\,d\theta\), \(\sqrt{x^2 + 4} = 2\sec\theta\)이고

\[\int\frac{2\sec^2\theta\,d\theta}{4\tan^2\theta\cdot2\sec\theta} = \frac14\int\frac{\sec\theta}{\tan^2\theta}d\theta = \frac14\int\frac{\cos\theta}{\sin^2\theta}d\theta = -\frac{1}{4\sin\theta} + C\]

이다. 마지막 단계에서는 \(u = \sin\theta\)로 치환했다. 이제 \(x\)로 되돌린다. \(\tan\theta = \frac x2\)이므로 밑변 2, 높이 \(x\), 빗변 \(\sqrt{x^2 + 4}\)인 직각삼각형을 그리면 \(\sin\theta = \frac{x}{\sqrt{x^2 + 4}}\)이다. 따라서 답은 \(-\dfrac{\sqrt{x^2 + 4}}{4x} + C\)이다.

그림 2처럼 되돌릴 때 직각삼각형을 그리는 것이 가장 실수가 적다. 치환식에서 두 변을 정하고, 피타고라스 정리로 나머지 한 변을 구한 뒤 필요한 삼각비를 읽는다. 답을 미분해 원래 식이 나오는지 보는 검산도 잊지 않는다.

주의근호가 있다고 늘 삼각치환을 쓰는 것은 아니다. \(\int x\sqrt{x^2 + 4}\,dx\)는 \(u = x^2 + 4\)로 치환하면 훨씬 간단하다. 바깥에 근호 안의 도함수(\(x\))가 있는지 먼저 본다.
마무리

\(\sqrt{a^2 - x^2}\)은 원의 높이이므로 \(x = a\sin\theta\)로 놓으면 \(a\cos\theta\)가 되어 근호가 사라지고, 같은 생각으로 \(\sqrt{a^2 + x^2}\)에는 \(x = a\tan\theta\), \(\sqrt{x^2 - a^2}\)에는 \(x = a\sec\theta\)를 쓴다. 그래서 처음 질문의 원의 넓이 적분은 \(4a^2\int_0^{\pi/2}\cos^2\theta\,d\theta = \pi a^2\)이 된다. 부정적분이면 직각삼각형을 그려 \(x\)로 되돌리고, 정적분이면 구간을 \(\theta\)로 바꾸어 되돌리지 않아도 된다.

5.3.2연습문제

기본

  1. \(\int_0^1\frac{dx}{\sqrt{4 - x^2}}\)를 구하여라.
    답

    \(x = 2\sin\theta\): \(\int_0^{\pi/6}d\theta = \frac\pi6\).

  2. \(\int\frac{dx}{1 + x^2}\)을 \(x = \tan\theta\)로 치환해 구하고 4.2절의 표와 비교하여라.
    답

    \(\int\frac{\sec^2\theta}{\sec^2\theta}d\theta = \theta = \arctan x + C\). 표와 같다.

응용

  1. \(\int\frac{x^2}{\sqrt{9 - x^2}}dx\)를 구하여라.
    답

    \(x = 3\sin\theta\): \(9\int\sin^2\theta\,d\theta = \frac92(\theta - \sin\theta\cos\theta) = \frac92\arcsin\frac x3 - \frac x2\sqrt{9 - x^2} + C\).
