항을 더 많이 더하면 어디서나 함수에 가까워질까?

탐구 · 거듭제곱급수와 수렴 반지름

질문

\(\dfrac{1}{1 - x} = 1 + x + x^2 + \cdots\)라는 식은 어떤 \(x\)에서 맞을까요? 항의 수 \(N\)을 늘려 가며 부분합(주황)이 함수(보라)에 붙는 구간과 멀어지는 구간을 찾아봅니다.

복원

  • 연한 띠는 \(-1 < x < 1\)입니다. 처음 세 급수의 수렴 반지름은 1입니다.
  • 등비급수 \(\sum x^n\)은 \(|x| < 1\)일 때만 수렴합니다. \(\ln(1 + x)\)와 \(\arctan x\)의 급수는 \(\dfrac{1}{1 + x}\), \(\dfrac{1}{1 + x^2}\)의 등비급수를 항별로 적분해 얻으므로 수렴 반지름이 같습니다. 항별로 미분하거나 적분해도 수렴 반지름은 바뀌지 않습니다.
  • \(e^x\)의 급수는 비 판정법에서 \(\left|\dfrac{x}{n + 1}\right| \to 0\)이므로 모든 \(x\)에서 수렴합니다.

설명

\(x = 0.5\), \(N = 10\)이면 \(1/(1 - x)\)의 부분합은 \(2(1 - 0.5^{10}) = 1.998046875\)로 함숫값 2와 0.002쯤 다릅니다. \(x = 1.2\)에서는 함숫값이 \(-5\)인데 부분합은 25.96이고 \(N\)을 늘릴수록 더 커집니다. 함수는 \(x = 1.2\)에서도 멀쩡히 정의되지만 급수는 쓸 수 없습니다. 끝점에서는 급수마다 다릅니다. \(\ln(1 + x)\)의 급수는 \(x = 1\)에서 교대급수로 \(\ln 2\)에 수렴하지만 매우 느려서, \(N = 10\)이면 0.6456(참값 0.6931)입니다.

연결

수렴 반지름은 비 판정법·근 판정법(8.5절)으로 구합니다. 복소수로 넓히면 \(\dfrac{1}{1 + x^2}\)의 반지름이 1인 이유가 보입니다. 실수에서는 멀쩡하지만 \(x = \pm i\)에서 분모가 0이 되기 때문입니다(공통9 5.1절).

적용

\(\arctan 1 = \pi/4\)를 이용해 급수로 \(\pi\)를 구하려 합니다. 부분합의 4배가 소수 둘째 자리까지 \(\pi\)와 맞으려면 항이 몇 개 필요한지 출력으로 찾아보세요.

판단

"\(e^x\)의 급수는 모든 \(x\)에서 수렴하므로 \(x = -1.9\)에서도 항 5개면 충분하다." 출력으로 확인하고 이 말의 어디가 틀렸는지 말해 보세요.
