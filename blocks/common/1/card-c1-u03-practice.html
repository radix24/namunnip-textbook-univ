미분 연습 문제

문제 7 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(f(x) = \dfrac{1}{x}\)의 도함수를 정의로 구하세요. [03-01]

    힌트 1

    \(\dfrac{1}{x+h} - \dfrac1x\)를 통분하세요.

    힌트 2

    통분하면 분자가 \(-h\)가 되어 \(h\)가 약분됩니다.

    풀이

    \(x \ne 0\)에서 \(\dfrac{f(x+h) - f(x)}{h} = \dfrac{1}{h}\cdot\dfrac{x - (x+h)}{x(x+h)} = \dfrac{-1}{x(x+h)}\). \(h \to 0\)이면 \(x + h \to x\)이므로 극한은 \(-\dfrac{1}{x^2}\).

  2. 개념\(f(x) = x|x|\)는 \(x = 0\)에서 미분 가능한가요? 미분 가능하면 \(f'(0)\)을 구하세요. [03-01]

    힌트 1

    공식이 통하지 않는 점이므로 정의로 확인합니다.

    힌트 2

    \(\dfrac{f(h) - f(0)}{h} = \dfrac{h|h|}{h} = |h|\).

    풀이

    \(\dfrac{f(h) - 0}{h} = |h| \to 0\) (\(h \to 0\), 양쪽 모두). 따라서 미분 가능하고 \(f'(0) = 0\). \(|x|\)는 0에서 꺾이지만 \(x\)를 곱하면 꺾임이 펴집니다. 참고로 \(f'(x) = 2|x|\)이고, 이것은 0에서 미분 불가능합니다.

  3. 계산\(y = \sin^3(\sqrt{x^2 + 1})\)을 미분하세요. [03-02]

    힌트 1

    바깥부터 껍질을 벗기세요: 세제곱 → sin → 제곱근 → \(x^2 + 1\).

    힌트 2

    껍질마다 도함수 하나씩, 모두 곱합니다(연쇄 법칙을 세 번).

    풀이

    \(u = \sqrt{x^2+1}\)로 두면 \(y = \sin^3 u\), \(y' = 3\sin^2 u\cdot\cos u\cdot u'\), \(u' = \dfrac{x}{\sqrt{x^2+1}}\). 따라서

    \[y' = \frac{3x\sin^2\!\left(\sqrt{x^2+1}\right)\cos\!\left(\sqrt{x^2+1}\right)}{\sqrt{x^2+1}}.\]

  4. 계산곡선 \(x^2 + xy + y^2 = 7\) 위의 점 \((1, 2)\)에서 접선과 법선의 방정식을 구하세요. [03-03]

    힌트 1

    \(xy\)는 곱의 법칙, \(y^2\)은 연쇄 법칙으로 미분합니다.

    힌트 2

    \(2x + y + xy' + 2yy' = 0\). 법선의 기울기는 접선 기울기의 음의 역수입니다.

    풀이

    점 확인: \(1 + 2 + 4 = 7\). 미분: \(2x + y + xy' + 2yy' = 0\)에서 \(y' = -\dfrac{2x + y}{x + 2y}\). \((1,2)\)에서 \(y' = -\dfrac45\).

    접선: \(y - 2 = -\frac45(x - 1)\), 곧 \(4x + 5y = 14\). 법선: 기울기 \(\frac54\), \(y - 2 = \frac54(x - 1)\), 곧 \(5x - 4y = -3\).

  5. 도전\(y = \arctan\!\left(\dfrac{1 + x}{1 - x}\right)\)를 미분하고, 결과가 왜 그렇게 단순한지 설명하세요. [03-04]

    힌트 1

    \((\arctan u)' = \dfrac{u'}{1 + u^2}\).

    힌트 2

    \(\tan\left(\frac\pi4 + \theta\right) = \dfrac{1 + \tan\theta}{1 - \tan\theta}\)를 떠올리세요.

    풀이

    \(u = \frac{1+x}{1-x}\), \(u' = \frac{(1-x) + (1+x)}{(1-x)^2} = \frac{2}{(1-x)^2}\). \(1 + u^2 = \frac{(1-x)^2 + (1+x)^2}{(1-x)^2} = \frac{2(1 + x^2)}{(1-x)^2}\). 따라서 \(y' = \dfrac{1}{1 + x^2}\) (\(x \ne 1\)).

    이유: \(x = \tan\theta\)로 두면 \(u = \tan\left(\frac\pi4 + \theta\right)\)이므로, \(x < 1\)에서 \(y = \frac\pi4 + \arctan x\)입니다. 상수만 다르니 도함수가 같습니다. (\(x > 1\)에서는 \(y = \arctan x - \frac{3\pi}{4}\)로 상수가 바뀝니다.)

  6. 계산구 모양 풍선에 공기를 매초 \(100\ \text{cm}^3\)씩 넣습니다. 지름이 50 cm일 때 반지름과 겉넓이가 늘어나는 속도를 구하세요. [03-05]

    힌트 1

    \(V = \frac43\pi r^3\), \(S = 4\pi r^2\). 반지름은 25 cm입니다.

    힌트 2

    \(\dot V = 4\pi r^2\dot r\)에서 \(\dot r\)을 구한 뒤 \(\dot S = 8\pi r\dot r\).

    풀이

    \(\dot V = 4\pi r^2\dot r\)에서 \(100 = 4\pi\cdot 625\cdot\dot r\), \(\dot r = \dfrac{1}{25\pi} \approx 0.0127\) cm/s.

    \(\dot S = 8\pi r\dot r = 8\pi\cdot 25\cdot\dfrac{1}{25\pi} = 8\ \text{cm}^2/\text{s}\). 검산: \(\dot S = \dfrac{2\dot V}{r}\)이라는 관계(\(S\dot r = \dot V\), \(\dot S = \frac{2S\dot r}{r}\))로도 \(\frac{200}{25} = 8\).

  7. 판단한 학생이 \(\dfrac{d}{dx}\ln(2x) = \dfrac{1}{2x}\)라고 썼습니다. 맞나요? 두 가지 방법으로 확인하세요. [03-02]

    힌트 1

    03-02 절: 연쇄 법칙의 안쪽 도함수.

    힌트 2

    \(\ln(2x) = \ln2 + \ln x\).

    풀이

    틀렸습니다. 연쇄 법칙으로 \(\frac{1}{2x}\cdot2 = \frac1x\). 로그의 성질로도 \(\ln2 + \ln x\)를 미분하면 \(\frac1x\)입니다. \(\ln(2x)\)와 \(\ln x\)는 상수 \(\ln2\)만큼 차이 나는 평행이동이라 기울기가 같아야 합니다.
