변수분리형 미분방정식과 성장 모형

본문 · 10.2절

세균은 처음에는 두 배, 네 배로 불어나지만 먹이와 공간이 모자라면 언젠가 멈춘다. 이 두 성장을 식으로 쓰면 어떻게 다르고, 그 식은 공식으로 풀 수 있을까?

먼저 알아야 할 것미분방정식과 방향장(10.1절), 치환적분(4.3절)과 부분분수(5.4절)를 쓴다.

방향장에서 공식으로

10.1절에서는 그림으로 해의 모양을 보았다. 이 절에서는 식을 직접 풀어 해를 공식으로 얻는다. 모든 미분방정식을 풀 수 있는 것은 아니지만, 오른쪽이 \(x\)만의 함수와 \(y\)만의 함수의 곱으로 나뉘는 식은 적분 두 번으로 풀 수 있다.

10.2.1변수분리형

정의 10.2.1

\(\dfrac{dy}{dx} = g(x)h(y)\) 꼴의 미분방정식을 변수분리형이라 한다.

푸는 순서는 이렇다. \(h(y) \ne 0\)인 곳에서 양변을 \(h(y)\)로 나누면 \(\dfrac{1}{h(y)}\dfrac{dy}{dx} = g(x)\)이다. 양변을 \(x\)로 적분하면 왼쪽은 4.3절의 치환적분(\(y\)를 새 변수로)에 의해 \(\int \dfrac{dy}{h(y)}\)가 되므로 다음을 얻는다.

\[\int \frac{dy}{h(y)} = \int g(x)\,dx + C\]

이 등식을 \(y\)에 대해 풀면 해이다. 흔히 "\(y\)는 왼쪽으로, \(x\)는 오른쪽으로 나눈 뒤 적분한다"고 기억한다. 그런데 \(h(y_0) = 0\)인 상수 \(y = y_0\)은 나눌 때 빠지지만 그 자체로 해이므로, 이런 평형해는 따로 확인해야 한다.

예제 10.2.2

\(y' = ry\), \(y(0) = P_0\)을 풀어라 (\(r > 0\)).

풀이. 변수를 나누어 적분하면 \(\int \dfrac{dy}{y} = \int r\,dx\)에서 \(\ln|y| = rx + C\), 곧 \(|y| = e^C e^{rx}\)이다. 부호까지 넣어 상수를 \(A\)로 쓰면 \(y = Ae^{rx}\)이고, 처음 값에서 \(A = P_0\)이므로 \(y = P_0e^{rx}\)이다. 이것이 지수 성장이다. 개체 수가 두 배가 되는 시간은 \(e^{rT} = 2\)에서 \(T = \frac{\ln 2}{r}\)로, 개체 수와 상관없이 일정하다. 가령 \(r = 0.6\)이면 약 1.16시간마다 두 배가 된다.

10.2.3로지스틱 성장

지수 성장은 시간이 지나면 한없이 커진다. 하지만 실제 생물은 먹이와 공간이 모자라 어느 수 \(K\) 근처에서 멈추고, 이 \(K\)를 환경 수용력이라 한다. 개체 수가 \(K\)에 가까워질수록 성장률이 0에 다가가게 하려면 \(r\) 대신 \(r(1 - P/K)\)를 쓰면 된다. 그러면 \(P\)가 작을 때는 성장률이 거의 \(r\)이고, \(P = K\)이면 0이다.

정리 10.2.4 (로지스틱 방정식의 해)

\(P' = rP\left(1 - \dfrac{P}{K}\right)\), \(P(0) = P_0 > 0\)의 해는 \(P(t) = \dfrac{K}{1 + Ae^{-rt}}\), \(A = \dfrac{K - P_0}{P_0}\)이다.

증명.변수를 나누면 \(\displaystyle\int \frac{K\,dP}{P(K - P)} = \int r\,dt\)이다. 부분분수(5.4절)로 \(\dfrac{K}{P(K - P)} = \dfrac1P + \dfrac{1}{K - P}\)이므로 왼쪽은 \(\ln|P| - \ln|K - P| = \ln\left|\dfrac{P}{K - P}\right|\)이다. 따라서 \(\ln\left|\dfrac{P}{K - P}\right| = rt + C\)이고, 양변의 지수를 취하면 \(\dfrac{K - P}{P} = Ae^{-rt}\)(\(A\)는 상수)이다. \(t = 0\)을 넣으면 \(A = \dfrac{K - P_0}{P_0}\)이다. 이 식을 \(P\)에 대해 풀면 \(\dfrac KP - 1 = Ae^{-rt}\), 곧 \(P = \dfrac{K}{1 + Ae^{-rt}}\)이다. 마지막으로 이 식을 미분해 원래 식에 넣으면 등식이 성립하므로 해이다. ∎

해를 읽어 보자. \(t \to \infty\)일 때 \(e^{-rt} \to 0\)이므로 \(P \to K\)이다. \(P_0 < K\)이면 \(A > 0\)이라 \(P\)는 \(K\) 아래에서 올라가고, \(P_0 > K\)이면 \(-1 < A < 0\)이라 위에서 내려온다. 처음 \(P\)가 \(K\)보다 아주 작을 때는 \(1 - P/K \approx 1\)이라 지수 성장과 거의 같다. 그림 1에서 처음 몇 시간 동안 두 곡선이 겹쳐 있다가 갈라지는 것이 이 때문이다.

예제 10.2.5

\(r = 0.6\), \(K = 120\), \(P_0 = 5\)일 때 \(P(5)\)를 구하고, 같은 \(r\), \(P_0\)의 지수 성장과 비교하여라. 증가 속도가 가장 큰 때는 언제인가?

풀이. \(A = 115/5 = 23\)이므로 \(P(5) = \dfrac{120}{1 + 23e^{-3}} \approx 55.9\)이다. 지수 성장이면 \(5e^{3} \approx 100.4\)이므로, 5시간 뒤에는 이미 두 모형이 두 배 가까이 차이 난다. 증가 속도 \(rP(1 - P/K)\)는 \(P\)의 이차함수이므로 \(P = K/2 = 60\)에서 가장 크고, 그 값은 \(rK/4 = 18\)이다. \(P = 60\)이 되는 때는 \(1 + 23e^{-0.6t} = 2\)에서 \(t = \ln 23 / 0.6 \approx 5.23\)이다. 그림 1의 처음 화면이 이 경우이고, 곡선이 가장 가파른 곳이 \(t \approx 5.2\)이다.

주의\(\int \dfrac{dy}{y} = \ln|y|\)에서 절댓값을 빠뜨리거나, 적분상수를 양쪽에 따로 붙여 두 번 쓰는 실수가 흔하다. 상수는 한쪽에 하나면 충분하다.
마무리

오른쪽이 \(x\)만의 함수와 \(y\)만의 함수의 곱인 미분방정식은 변수를 나누어 \(\int\frac{dy}{h(y)} = \int g(x)\,dx + C\)로 풀며, 나눌 때 빠지는 평형해를 따로 확인한다. 처음 질문의 두 성장은 지수 성장 \(P = P_0e^{rt}\)와 로지스틱 성장 \(P = \frac{K}{1 + Ae^{-rt}}\)으로 풀린다. 앞의 것은 일정한 시간마다 두 배가 되고, 뒤의 것은 처음에는 같다가 \(K\)로 다가가며 \(P = \frac K2\)에서 가장 빠르게 늘어난다.

연습문제
  1. 기본 \(y' = xy^2\), \(y(0) = 1\)을 풀어라.
    답\(-1/y = x^2/2 + C\), \(C = -1\). \(y = \dfrac{2}{2 - x^2}\) (\(|x| < \sqrt2\)).
  2. 기본 세균이 3시간마다 두 배가 된다. \(r\)을 구하여라.
    답\(r = \ln 2 / 3 \approx 0.231\) (1/시간).
  3. 응용 로지스틱 모형에서 \(P_0 = K/2\)이면 해는 어떻게 되는가? \(A\)의 값으로 설명하여라.
    답\(A = 1\)이므로 \(P(t) = K/(1 + e^{-rt})\). \(t = 0\)에서 증가 속도가 가장 크고 이후 느려지며 \(K\)로 간다.
