극한의 정확한 정의

본문

"\(x\)가 3에 한없이 가까워지면 \(x^2\)은 9에 한없이 가까워진다"는 말에서 "한없이 가깝다"는 얼마나 가까운 것일까? 0.001이면 충분할까, 아니면 다른 기준이 필요할까?

먼저 알아야 할 것고교 수학II의 함수의 극한(직관적 뜻과 계산), \(|x - a| < \delta\)를 구간으로 읽는 법과 삼각부등식(1.1절), 그리고 고교 수학의 "모든", "어떤 …가 있다"를 쓰는 명제와 그 부정을 쓴다.

2.1.1"한없이 가까워진다"는 무슨 뜻인가

고등학교에서는 "\(x\)가 \(a\)에 한없이 가까워질 때 \(f(x)\)가 \(L\)에 한없이 가까워지면 \(\lim_{x\to a}f(x) = L\)"이라고 배웠다. 계산에는 이것으로 충분했지만, 이 문장으로는 답할 수 없는 질문이 있다. 처음 질문처럼 0.001이면 충분히 가까운지 알 수 없고, \(f(x) = x\sin\frac1x\)처럼 0 근처에서 끝없이 출렁이는 함수가 0에 "가까워지는" 것인지도 판단하기 어렵다. 더구나 "극한의 합은 합의 극한" 같은 극한 법칙이 왜 성립하는지는 직관만으로 증명할 수 없다.

19세기 수학자 코시와 바이어슈트라스는 가까움을 오차의 크기로 바꾸어 이 문제를 풀었다. 그 생각은 도전과 응답으로 설명할 수 있다. 누군가 "\(f(x)\)와 \(L\)의 차이를 0.01보다 작게 해 봐"라고 요구하면, 우리는 "\(x\)를 \(a\)에서 0.003 이내로만 잡으면 된다"고 답할 수 있어야 한다. 요구가 0.0001로 더 까다로워져도 답할 수 있어야 하고, 어떤 양수를 요구해도 답할 수 있으면 그때 극한이 \(L\)이라고 말한다. 다시 말해 "한없이 가깝다"는 정해진 한 숫자가 아니라, 어떤 요구에도 응할 수 있다는 약속이다.

가령 \(f(x) = 2x + 1\)이 \(x \to 3\)일 때 7로 간다는 것을 이 방식으로 확인해 보자. \(|f(x) - 7| = |2x - 6| = 2|x - 3|\)이다. 차이를 0.01보다 작게 하라는 요구에는 \(|x - 3| < 0.005\)라고 답하면 된다. 그러면 \(2|x - 3| < 0.01\)이기 때문이다. 일반적으로 요구가 \(\varepsilon\)이면 답은 \(\frac\varepsilon2\)이다.

2.1.2ε-δ 정의

그림 1에서 이 도전과 응답을 직접 해 보자. 함수는 \(y = x^2\), 점은 \(a = 3\), 극한값은 \(L = 9\)이다. \(\varepsilon\)을 2로 두면 가로 띠는 높이 7부터 11까지이다. 이때 \(\delta\)를 1.5로 크게 잡으면 세로 띠 안의 그래프 일부가 가로 띠를 벗어나 빨갛게 보이지만, \(\delta\)를 0.25까지 좁히면 빨간 부분이 사라진다. \(\varepsilon\)을 더 줄이면 \(\delta\)도 더 줄여야 하지만, 줄일 수 있는 \(\delta\)가 언제나 있다.

정의 2.1.1 (함수의 극한)

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 (\(a\) 자신은 빼도 된다) 정의되어 있다고 하자. 임의의 \(\varepsilon > 0\)에 대하여 어떤 \(\delta > 0\)이 있어서

\[0 < |x - a| < \delta \ \Longrightarrow\ |f(x) - L| < \varepsilon\]

이 성립하면 \(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한이 \(L\)이라 하고 \(\lim_{x\to a}f(x) = L\)로 쓴다.

정의를 구절 단위로 끊어 그림 1과 맞춰 읽어 보자. "임의의 \(\varepsilon > 0\)에 대하여"는 상대가 허용 오차 \(\varepsilon\)을 마음대로, 얼마든지 작게 정한다는 뜻이다. \(\varepsilon\)은 \(f(x)\) 쪽, 곧 세로축의 오차이고 그림의 가로 띠이다.

"어떤 \(\delta > 0\)이 있어서"는 우리가 그 \(\varepsilon\)에 맞추어 \(x\)의 허용 범위 \(\delta\)를 고른다는 뜻이다. \(\delta\)는 \(x\) 쪽, 곧 가로축의 범위이고 그림의 세로 띠이다. 여기서 \(\delta\)는 \(\varepsilon\)에 따라 달라져도 되며, 보통 \(\varepsilon\)이 작아지면 \(\delta\)도 작아져야 한다.

"\(0 < |x - a|\)"는 \(x = a\)를 제외한다는 뜻이다. 즉 극한은 \(a\) 근처의 행동만 보고 \(a\)에서의 값 \(f(a)\)는 상관하지 않는다. 그래서 \(f(a)\)가 정의되지 않거나 엉뚱한 값이어도 극한은 있을 수 있다.

마지막으로 "\(|x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon\)"은 \(a\)에서 거리 \(\delta\) 이내의 모든 \(x\)(단 \(a\) 제외)에 대해 \(f(x)\)가 \(L\)에서 거리 \(\varepsilon\) 이내에 있어야 한다는 뜻이다. 몇몇 \(x\)만 들어오는 것으로는 부족하다. 그림 1에서 빨간 부분이 조금이라도 남아 있으면 그 \(\delta\)는 실패이다.1

2.1.3정의로 증명하기: 초안과 증명

정의로 극한을 증명하는 일은 언제나 두 단계를 거친다. 교과서에는 보통 둘째 단계만 실려 있어서, 처음 보면 "\(\delta = \frac\varepsilon5\)는 어디서 나왔나" 하고 당황하게 된다. 그래서 여기서는 첫 단계를 숨기지 않고 보인다. 첫 단계는 연습장에 쓰는 초안이다. 목표 \(|f(x) - L| < \varepsilon\)에서 출발해 식을 \(|x - a|\)의 식으로 바꾸고, 어떤 \(\delta\)를 잡으면 될지 거꾸로 찾는다. 둘째 단계는 답안에 쓰는 증명이다. 찾은 \(\delta\)를 먼저 제시하고, \(0 < |x - a| < \delta\)에서 출발해 \(|f(x) - L| < \varepsilon\)에 도착하는 순서로 쓴다.

예제 2.1.2

\(\lim_{x\to2}(5x - 3) = 7\)을 ε-δ 정의로 증명하여라.

초안. \(|f(x) - 7| = |5x - 10| = 5|x - 2|\)이다. 이것이 \(\varepsilon\)보다 작으려면 \(|x - 2| < \frac\varepsilon5\)이면 된다. 그러니 \(\delta = \frac\varepsilon5\)로 잡는다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \frac\varepsilon5\)로 놓는다. \(0 < |x - 2| < \delta\)이면 \(|(5x - 3) - 7| = 5|x - 2| < 5\delta = \varepsilon\)이다. 따라서 정의에 의해 \(\lim_{x\to2}(5x - 3) = 7\)이다. ∎

일차함수 \(mx + b\) (\(m \ne 0\))이면 언제나 \(\delta = \frac{\varepsilon}{|m|}\)이 통한다. 기울기가 가파를수록 \(x\)를 더 좁게 잡아야 한다는 뜻이다.

예제 2.1.3

\(\lim_{x\to3}x^2 = 9\)를 ε-δ 정의로 증명하여라.

초안. \(|x^2 - 9| = |x - 3|\cdot|x + 3|\)이다. 그런데 일차함수와 달리 \(|x - 3|\)에 곱해진 \(|x + 3|\)이 \(x\)에 따라 변해서 상수로 나눌 수 없다. 그래서 1.1절의 마지막 예제처럼 먼저 \(x\)를 3 근처로 제한해 \(|x + 3|\)을 상수로 막는다.

\(\delta \le 1\)로 정하기로 하면 \(|x - 3| < 1\), 곧 \(2 < x < 4\)이므로 \(5 < x + 3 < 7\), 즉 \(|x + 3| < 7\)이다. 그러면 \(|x^2 - 9| < 7|x - 3|\)이고, 이것이 \(\varepsilon\)보다 작으려면 \(|x - 3| < \frac\varepsilon7\)이면 된다. 따라서 두 조건 \(\delta \le 1\)과 \(\delta \le \frac\varepsilon7\)을 동시에 만족하도록 \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 잡는다. \(\min\)은 둘 중 작은 쪽이다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 놓는다. \(0 < |x - 3| < \delta\)라 하자. \(\delta \le 1\)이므로 \(2 < x < 4\)이고 \(|x + 3| < 7\)이다. 또 \(\delta \le \frac\varepsilon7\)이므로 \(|x^2 - 9| = |x - 3||x + 3| < \frac\varepsilon7\cdot7 = \varepsilon\)이다. ∎

이 결과를 그림 1로 되짚어 보자. \(\varepsilon = 2\)이면 \(\delta = \min(1, \frac27) \approx 0.29\)이고, 실제로 \(\delta\)를 0.25로 두면 빨간 부분이 없다. 그런데 \(\delta \le 1\)의 1은 아무 양수나 써도 된다. \(\delta \le \frac12\)로 정했다면 \(|x + 3| < 6.5\)가 되어 \(\delta = \min\left(\frac12, \frac{\varepsilon}{6.5}\right)\)을 잡으면 된다. 즉 먼저 \(x\)를 가둬 곱해지는 인수를 상수로 막는 것이 방법이고, 이 방법은 다항함수와 유리함수 모두에 통한다.

예제 2.1.4

\(\lim_{x\to2}\frac1x = \frac12\)을 증명하여라.

초안. \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2|x|}\)이다. 이번에는 \(\frac{1}{|x|}\)을 위에서 막아야 하고, 이는 \(|x|\)를 아래에서 막는 것과 같다. \(\delta \le 1\)이면 \(1 < x < 3\)이라 \(|x| > 1\)이고, 따라서 \(\frac{|x - 2|}{2|x|} < \frac{|x - 2|}{2}\)이다. 이것이 \(\varepsilon\) 미만이려면 \(|x - 2| < 2\varepsilon\)이면 되므로 \(\delta = \min(1, 2\varepsilon)\)으로 잡는다.

증명.\(\varepsilon > 0\)에 대해 \(\delta = \min(1, 2\varepsilon)\)으로 놓는다. \(0 < |x - 2| < \delta\)이면 \(x > 1\)이므로 \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2x} < \frac{|x - 2|}{2} < \frac{2\varepsilon}{2} = \varepsilon\)이다. ∎

여기서는 \(\delta \le 1\)이라는 제한이 더 큰 역할을 한다. 제한이 없으면 \(x\)가 0에 가까워질 수 있고, 그러면 \(\frac1x\)이 한없이 커져서 어떤 상수로도 막을 수 없다.

2.1.4극한이 존재하지 않음을 보이기

이번에는 정의의 부정을 정확히 써 보자. "모든 \(\varepsilon\)에 대해 어떤 \(\delta\)가 있어서 …"의 부정은 "어떤 \(\varepsilon\)에 대해서는 모든 \(\delta\)가 실패한다"이다. 곧 \(\lim_{x\to a}f(x) \ne L\)은 다음을 뜻한다.

어떤 \(\varepsilon > 0\)이 있어서, 모든 \(\delta > 0\)에 대해 \(0 < |x - a| < \delta\)이면서 \(|f(x) - L| \ge \varepsilon\)인 \(x\)가 있다

그림 1의 말로는 상대가 너무 얇은 가로 띠를 그려서, 우리가 세로 띠를 아무리 좁혀도 빨간 부분이 남는 상황이다.

예제 2.1.5

\(H(x) = 0\) (\(x < 0\)), \(H(x) = 1\) (\(x \ge 0\))일 때 \(\lim_{x\to0}H(x)\)가 존재하지 않음을 보여라.

풀이. 어떤 \(L\)이 극한이라고 가정하고 모순을 보인다. \(\varepsilon = \frac12\)을 잡자. 어떤 \(\delta > 0\)이든 구간 \((-\delta, \delta)\)에는 \(x_1 = -\frac\delta2\)(\(H = 0\))과 \(x_2 = \frac\delta2\)(\(H = 1\))이 모두 있다. 두 점에서 모두 \(|H(x) - L| < \frac12\)이려면 \(|0 - L| < \frac12\)이고 \(|1 - L| < \frac12\)이어야 한다. 그런데 삼각부등식으로 \(1 = |1 - 0| \le |1 - L| + |L - 0| < 1\)이 되어 모순이다. 따라서 어떤 \(L\)도 극한이 아니다.

이 함수는 오른쪽에서 1, 왼쪽에서 0으로 다가간다. 정의 2.1.1에서 \(x > a\)인 점만 보면 오른쪽 극한 \(\lim_{x\to a^+}\)이 되고, \(x < a\)인 점만 보면 왼쪽 극한 \(\lim_{x\to a^-}\)이 된다. 극한이 존재하는 것은 두 한쪽 극한이 모두 존재하고 같을 때뿐이다(연습문제 6).

2.1.5극한은 하나뿐이다

정의가 생겼으니 직관으로는 당연하던 것을 증명할 수 있다. 그 첫 번째가 극한값이 둘일 수 없다는 사실이다.

정리 2.1.6 (극한의 유일성)

\(\lim_{x\to a}f(x) = L\)이고 \(\lim_{x\to a}f(x) = M\)이면 \(L = M\)이다.

증명.\(L \ne M\)이라 가정하고 \(\varepsilon = \frac{|L - M|}{2} > 0\)을 잡는다. 극한이 \(L\)이므로 \(0 < |x - a| < \delta_1\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1\)이 있고, 극한이 \(M\)이므로 같은 방식의 \(\delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 잡고 \(0 < |x - a| < \delta\)인 \(x\)를 하나 고르면 두 부등식이 모두 성립하므로, 삼각부등식에서 \(|L - M| \le |L - f(x)| + |f(x) - M| < 2\varepsilon = |L - M|\)이 되어 모순이다. 따라서 \(L = M\)이다. ∎

"두 조건의 \(\delta\) 가운데 작은 쪽을 잡는다"는 기법은 극한 법칙의 증명에서도 그대로 쓰인다.

주의\(\delta\)를 \(x\)의 식으로 잡으면 안 된다. 가령 예제 2.1.3에서 "\(\delta = \frac{\varepsilon}{|x + 3|}\)"이라고 쓰면 \(\delta\)를 정하기 전에 \(x\)를 이미 안다는 뜻이 되어 순서가 뒤집힌다. \(\delta\)는 \(\varepsilon\)과 \(a\)만으로 정해야 하고, 그래서 \(x\)를 먼저 가두어 \(|x + 3|\)을 상수로 바꾸는 단계가 필요하다.
  1. \(\varepsilon\)과 \(\delta\)라는 그리스 문자는 관습이다. \(\varepsilon\)은 오차(error)의 e, \(\delta\)는 차이(difference)의 d에서 왔다고들 한다.
마무리

"한없이 가깝다"는 정해진 거리 하나가 아니라, 상대가 어떤 \(\varepsilon > 0\)을 요구해도 \(0 < |x - a| < \delta\)이면 \(|f(x) - L| < \varepsilon\)이 되는 \(\delta\)를 찾아 줄 수 있다는 약속이다. 이 \(\delta\)는 초안에서 \(|f(x) - L|\)을 \(|x - a|\)의 식으로 바꾸어 찾고, 곱해지는 인수가 있으면 먼저 \(\delta \le 1\)로 \(x\)를 가둔다. 그래서 처음 질문의 \(x^2 \to 9\)는 \(\delta = \min(1, \frac\varepsilon7)\)으로 증명되며, 같은 정의의 부정을 쓰면 극한이 없음도 보일 수 있다.

2.1.6연습문제

기본

  1. \(\lim_{x\to-1}(4 - 3x) = 7\)을 ε-δ 정의로 증명하여라.
    답

    \(|4 - 3x - 7| = 3|x + 1|\). \(\delta = \frac\varepsilon3\)이면 \(0 < |x + 1| < \delta\)에서 \(3|x + 1| < \varepsilon\).

  2. \(\lim_{x\to5}(2x + 1) = 11\)에서 \(\varepsilon = 0.01\)일 때 쓸 수 있는 \(\delta\)를 하나 구하여라. 그보다 큰 \(\delta\)도 되는가?
    답

    \(\delta = 0.005\). \(\delta = 0.006\)이면 \(x = 5.0055\)에서 차이가 0.011이 되어 실패한다. 0.005보다 작은 \(\delta\)는 모두 된다.

  3. 상수함수 \(f(x) = c\)에 대해 \(\lim_{x\to a}f(x) = c\)임을 보여라. \(\delta\)는 얼마로 잡는가?
    답

    \(|f(x) - c| = 0 < \varepsilon\)이 언제나 성립하므로 어떤 \(\delta\)를 잡아도 된다(예: \(\delta = 1\)).

응용

  1. \(\lim_{x\to1}(x^2 + x) = 2\)를 증명하여라.
    힌트

    \(x^2 + x - 2 = (x - 1)(x + 2)\). \(\delta \le 1\)이면 \(|x + 2| < 4\).

    답

    \(\delta = \min(1, \frac\varepsilon4)\). \(0 < |x - 1| < \delta\)이면 \(0 < x < 2\)라 \(|x + 2| < 4\), \(|x^2 + x - 2| < 4\cdot\frac\varepsilon4 = \varepsilon\).

  2. \(\lim_{x\to4}\sqrt x = 2\)를 증명하여라.
    힌트

    \(\sqrt x - 2 = \frac{x - 4}{\sqrt x + 2}\)이고 \(\sqrt x + 2 \ge 2\).

    답

    \(|\sqrt x - 2| = \frac{|x - 4|}{\sqrt x + 2} \le \frac{|x - 4|}{2}\). \(\delta = \min(4, 2\varepsilon)\)으로 잡는다(\(\delta \le 4\)는 \(x \ge 0\)이 되게, 곧 \(\sqrt x\)가 정의되게 하려는 것).

심화

  1. \(\lim_{x\to a}f(x) = L\)일 필요충분조건은 \(\lim_{x\to a^+}f(x) = L\)이고 \(\lim_{x\to a^-}f(x) = L\)인 것임을 증명하여라.
    힌트

    (⇐) 두 한쪽 극한에서 얻은 \(\delta_1, \delta_2\) 중 작은 쪽을 써라.

    답

    (⇒) 양쪽 조건을 만족하는 \(\delta\)는 한쪽만 보는 조건도 만족한다. (⇐) \(a < x < a + \delta_1\)이면, \(a - \delta_2 < x < a\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1, \delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)이면 \(0 < |x - a| < \delta\)인 \(x\)는 둘 중 한 경우에 속하므로 \(|f(x) - L| < \varepsilon\).
