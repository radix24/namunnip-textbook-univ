극한의 정확한 정의

본문
이 절에서 배울 것
  • "한없이 가까워진다"를 부등식으로 바꾼 ε-δ 정의를 읽는다.
  • 간단한 함수의 극한을 정의로 증명한다. 먼저 초안에서 δ를 찾고, 다음에 증명을 정리해 쓴다.
  • 극한이 존재하지 않음을 정의의 부정으로 보인다.
먼저 알아야 할 것
  • 함수의 극한의 직관적 뜻과 계산 (고교 수학II).
  • \(|x - a| < \delta\)를 구간으로 읽기, 삼각부등식 (1.1절).
  • "모든", "어떤 … 가 있다"를 쓰는 명제와 그 부정 (고교 수학 집합과 명제).

2.1.1"한없이 가까워진다"는 무슨 뜻인가

고등학교에서는 "\(x\)가 \(a\)에 한없이 가까워질 때 \(f(x)\)가 \(L\)에 한없이 가까워지면 \(\lim_{x\to a}f(x) = L\)"이라고 배웠습니다. 계산에는 이것으로 충분했지만, 이 문장은 몇 가지 질문에 답하지 못합니다.

  • "한없이 가깝다"는 얼마나 가까운 것인가? 0.001이면 충분한가?
  • \(f(x) = x\sin\frac1x\)처럼 0 근처에서 끝없이 출렁이는 함수는 0에 "가까워지는" 것인가?
  • 극한 법칙("극한의 합은 합의 극한")은 왜 성립하는가? 직관만으로는 증명할 수 없다.

19세기 수학자들(코시, 바이어슈트라스)은 "가까움"을 오차의 크기로 바꾸어 이 문제를 풀었습니다. 핵심 생각은 도전과 응답입니다. 누군가 "\(f(x)\)와 \(L\)의 차이를 0.01보다 작게 해 봐"라고 요구하면, 우리는 "\(x\)를 \(a\)에서 0.003 이내로만 잡으면 된다"고 답할 수 있어야 합니다. 요구가 0.0001로 더 까다로워져도 답할 수 있어야 하고, 어떤 양수를 요구해도 답할 수 있으면 그때 극한이 \(L\)이라고 말합니다.

예를 들어 \(f(x) = 2x + 1\)이 \(x \to 3\)일 때 7로 간다는 것을 이 방식으로 확인해 봅시다. \(|f(x) - 7| = |2x - 6| = 2|x - 3|\)입니다. 차이를 0.01보다 작게 하라는 요구에는 \(|x - 3| < 0.005\)라고 답하면 됩니다. 그러면 \(2|x - 3| < 0.01\)이니까요. 일반적으로 요구가 \(\varepsilon\)이면 답은 \(\frac\varepsilon2\)입니다.

2.1.2ε-δ 정의

정의 2.1.1 (함수의 극한)

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 (\(a\) 자신은 빼도 된다) 정의되어 있다고 하자. 임의의 \(\varepsilon > 0\)에 대하여 어떤 \(\delta > 0\)이 있어서

\[0 < |x - a| < \delta \ \Longrightarrow\ |f(x) - L| < \varepsilon\]

이 성립하면 \(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한이 \(L\)이라 하고 \(\lim_{x\to a}f(x) = L\)로 쓴다.

정의를 구절 단위로 끊어 읽습니다.

  • "임의의 \(\varepsilon > 0\)에 대하여": 상대가 허용 오차 \(\varepsilon\)을 마음대로 정합니다. 아주 작게 정할 수도 있습니다. \(\varepsilon\)은 \(f(x)\) 쪽, 곧 세로축의 오차입니다.
  • "어떤 \(\delta > 0\)이 있어서": 우리가 그 \(\varepsilon\)에 맞추어 \(x\)의 허용 범위 \(\delta\)를 고릅니다. \(\delta\)는 \(x\) 쪽, 곧 가로축의 범위입니다. \(\delta\)는 \(\varepsilon\)에 따라 달라져도 됩니다. 보통 \(\varepsilon\)이 작아지면 \(\delta\)도 작아져야 합니다.
  • "\(0 < |x - a|\)": \(x = a\)는 제외합니다. 극한은 \(a\) 근처의 행동만 보고, \(a\)에서의 값 \(f(a)\)는 상관하지 않습니다. \(f(a)\)가 정의되지 않아도, 엉뚱한 값이어도 극한은 있을 수 있습니다.
  • "\(|x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon\)": \(a\)에서 거리 \(\delta\) 이내의 모든 \(x\)(단 \(a\) 제외)에 대해 \(f(x)\)가 \(L\)에서 거리 \(\varepsilon\) 이내에 있어야 합니다. 몇몇 \(x\)만 들어오는 것으로는 부족합니다.

그림으로 보면, 높이가 \(L - \varepsilon\)부터 \(L + \varepsilon\)까지인 가로 띠를 상대가 그리면, 우리는 폭이 \(a - \delta\)부터 \(a + \delta\)까지인 세로 띠를 골라 그 안의 그래프가 (점 \(x = a\)를 빼고) 모두 가로 띠 안에 들어가게 해야 합니다. 이 절 뒤의 탐구 카드에서 직접 띠를 움직여 볼 수 있습니다.

\(\varepsilon\)과 \(\delta\)라는 그리스 문자는 관습입니다. \(\varepsilon\)은 "오차(error)"의 e, \(\delta\)는 "차이(difference)"의 d에서 왔다고들 합니다.

2.1.3정의로 증명하기: 초안과 증명

정의로 극한을 증명하는 일은 언제나 두 단계입니다. 교과서에는 보통 두 번째 단계만 실려 있어서, 처음 보면 "\(\delta = \frac\varepsilon5\)는 어디서 나왔나" 하고 당황하게 됩니다. 첫 단계를 숨기지 않고 보이겠습니다.

  1. 초안(연습장에 쓰는 것): 목표 \(|f(x) - L| < \varepsilon\)에서 출발해 식을 \(|x - a|\)의 식으로 바꾸고, 어떤 \(\delta\)를 잡으면 될지 거꾸로 찾는다.
  2. 증명(답안에 쓰는 것): 찾은 \(\delta\)를 먼저 제시하고, \(0 < |x - a| < \delta\)에서 출발해 \(|f(x) - L| < \varepsilon\)에 도착하는 순서로 쓴다.
예제 2.1.2

\(\lim_{x\to2}(5x - 3) = 7\)을 ε-δ 정의로 증명하여라.

초안. \(|f(x) - 7| = |5x - 10| = 5|x - 2|\)입니다. 이것이 \(\varepsilon\)보다 작으려면 \(|x - 2| < \frac\varepsilon5\)이면 됩니다. 그러니 \(\delta = \frac\varepsilon5\)로 잡습니다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \frac\varepsilon5\)로 놓는다. \(0 < |x - 2| < \delta\)이면 \(|(5x - 3) - 7| = 5|x - 2| < 5\delta = \varepsilon\)이다. 따라서 정의에 의해 \(\lim_{x\to2}(5x - 3) = 7\)이다. ∎

일차함수 \(mx + b\)이면 언제나 \(\delta = \frac{\varepsilon}{|m|}\)이 통합니다(\(m \ne 0\)). 기울기가 가파를수록 \(x\)를 더 좁게 잡아야 한다는 뜻입니다.

예제 2.1.3

\(\lim_{x\to3}x^2 = 9\)를 ε-δ 정의로 증명하여라.

초안. \(|x^2 - 9| = |x - 3|\cdot|x + 3|\)입니다. 일차함수와 달리 \(|x - 3|\)에 곱해진 \(|x + 3|\)이 \(x\)에 따라 변해서, 상수로 나눌 수 없습니다. 요령은 1.1절의 예제 1.2.5와 같습니다. 먼저 \(x\)를 3 근처로 제한해 \(|x + 3|\)을 상수로 막습니다.

\(\delta \le 1\)로 정하기로 하면 \(|x - 3| < 1\), 곧 \(2 < x < 4\)이므로 \(5 < x + 3 < 7\), \(|x + 3| < 7\)입니다. 그러면 \(|x^2 - 9| < 7|x - 3|\)이고, 이것이 \(\varepsilon\)보다 작으려면 \(|x - 3| < \frac\varepsilon7\)이면 됩니다. 두 조건(\(\delta \le 1\)과 \(\delta \le \frac\varepsilon7\))을 동시에 만족하도록 \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 잡습니다. \(\min\)은 둘 중 작은 쪽입니다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 놓는다. \(0 < |x - 3| < \delta\)라 하자. \(\delta \le 1\)이므로 \(2 < x < 4\)이고 \(|x + 3| < 7\)이다. 또 \(\delta \le \frac\varepsilon7\)이므로 \(|x^2 - 9| = |x - 3||x + 3| < \frac\varepsilon7\cdot7 = \varepsilon\)이다. ∎

왜 \(\delta \le 1\)이었을까요? 1은 아무 양수나 써도 됩니다. \(\delta \le \frac12\)로 정했다면 \(|x + 3| < 6.5\)가 되어 \(\delta = \min\left(\frac12, \frac{\varepsilon}{6.5}\right)\)을 잡으면 됩니다. 중요한 것은 "먼저 \(x\)를 가둬 곱해지는 인수를 상수로 막는다"는 방법입니다. 이 방법은 다항함수, 유리함수 모두에 통합니다.

예제 2.1.4

\(\lim_{x\to2}\frac1x = \frac12\)을 증명하여라.

초안. \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2|x|}\)입니다. 이번에는 \(\frac{1}{|x|}\)을 위에서 막아야 하는데, 이는 \(|x|\)를 아래에서 막는 것과 같습니다. \(\delta \le 1\)이면 \(1 < x < 3\)이라 \(|x| > 1\), 따라서 \(\frac{|x - 2|}{2|x|} < \frac{|x - 2|}{2}\)입니다. 이것이 \(\varepsilon\) 미만이려면 \(|x - 2| < 2\varepsilon\). 그래서 \(\delta = \min(1, 2\varepsilon)\).

증명.\(\varepsilon > 0\)에 대해 \(\delta = \min(1, 2\varepsilon)\)으로 놓는다. \(0 < |x - 2| < \delta\)이면 \(x > 1\)이므로 \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2x} < \frac{|x - 2|}{2} < \frac{2\varepsilon}{2} = \varepsilon\)이다. ∎

\(\delta \le 1\)이라는 제한이 여기서는 더 중요합니다. 제한이 없으면 \(x\)가 0에 가까워질 수 있고, 그러면 \(\frac1x\)이 폭발해서 어떤 상수로도 막을 수 없습니다.

2.1.4극한이 존재하지 않음을 보이기

정의의 부정을 정확히 써 봅시다. "모든 \(\varepsilon\)에 대해 어떤 \(\delta\)가 있어서 …"의 부정은 "어떤 \(\varepsilon\)에 대해서는 모든 \(\delta\)가 실패한다"입니다. 곧 \(\lim_{x\to a}f(x) \ne L\)은

어떤 \(\varepsilon > 0\)이 있어서, 모든 \(\delta > 0\)에 대해 \(0 < |x - a| < \delta\)이면서 \(|f(x) - L| \ge \varepsilon\)인 \(x\)가 있다

는 뜻입니다. 상대가 너무 작은 띠를 그려서, 우리가 세로 띠를 아무리 좁혀도 띠를 벗어나는 점이 남는 상황입니다.

예제 2.1.5

\(H(x) = 0\) (\(x < 0\)), \(H(x) = 1\) (\(x \ge 0\))일 때 \(\lim_{x\to0}H(x)\)가 존재하지 않음을 보여라.

풀이. 어떤 \(L\)이 극한이라고 가정하고 모순을 보입니다. \(\varepsilon = \frac12\)을 잡습니다. 어떤 \(\delta > 0\)이든, 구간 \((-\delta, \delta)\)에는 \(x_1 = -\frac\delta2\)(\(H = 0\))과 \(x_2 = \frac\delta2\)(\(H = 1\))이 모두 있습니다. 두 점에서 모두 \(|H(x) - L| < \frac12\)이려면 \(|0 - L| < \frac12\)이고 \(|1 - L| < \frac12\)이어야 하는데, 삼각부등식으로 \(1 = |1 - 0| \le |1 - L| + |L - 0| < 1\)이 되어 모순입니다. 따라서 어떤 \(L\)도 극한이 아닙니다.

이 함수는 오른쪽에서 1, 왼쪽에서 0으로 다가갑니다. 정의 2.1.1에서 \(x > a\)인 점만 보면 오른쪽 극한 \(\lim_{x\to a^+}\), \(x < a\)인 점만 보면 왼쪽 극한 \(\lim_{x\to a^-}\)이 됩니다. 극한이 존재하는 것은 두 한쪽 극한이 모두 존재하고 같을 때뿐입니다(연습문제 6).

2.1.5극한은 하나뿐이다

정의가 생겼으니 직관으로는 당연하던 것을 증명할 수 있습니다. 첫 번째로, 극한값이 둘일 수 없다는 것입니다.

정리 2.1.6 (극한의 유일성)

\(\lim_{x\to a}f(x) = L\)이고 \(\lim_{x\to a}f(x) = M\)이면 \(L = M\)이다.

증명.\(L \ne M\)이라 가정하고 \(\varepsilon = \frac{|L - M|}{2} > 0\)을 잡는다. 극한이 \(L\)이므로 \(0 < |x - a| < \delta_1\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1\)이 있고, 극한이 \(M\)이므로 같은 방식의 \(\delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 잡고 \(0 < |x - a| < \delta\)인 \(x\)를 하나 고르면, 두 부등식이 모두 성립하므로 삼각부등식에서 \(|L - M| \le |L - f(x)| + |f(x) - M| < 2\varepsilon = |L - M|\)이 되어 모순이다. 따라서 \(L = M\). ∎

"두 조건의 \(\delta\) 가운데 작은 쪽을 잡는다"는 기법은 극한 법칙의 증명(1.3절)에서도 그대로 쓰입니다.

주의\(\delta\)를 \(x\)의 식으로 잡으면 안 됩니다. 예를 들어 예제 2.1.3에서 "\(\delta = \frac{\varepsilon}{|x + 3|}\)"이라고 쓰면, \(\delta\)를 정하기 전에 \(x\)를 이미 안다는 뜻이 되어 순서가 뒤집힙니다. \(\delta\)는 \(\varepsilon\)(과 \(a\))만으로 정해야 합니다. 그래서 \(x\)를 먼저 가두어 \(|x + 3|\)을 상수로 바꾸는 단계가 필요한 것입니다.
요약
  1. \(\lim_{x\to a}f(x) = L\): 임의의 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어서 \(0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon\).
  2. 증명은 초안(\(\delta\) 찾기)과 증명(\(\delta\) 제시 후 확인) 두 단계로 한다.
  3. 곱해지는 인수가 \(x\)에 따라 변하면 \(\delta \le 1\) 같은 제한으로 먼저 가둔다. \(\delta = \min(1, \dots)\).
  4. 극한이 없음: 어떤 \(\varepsilon\)에 대해 모든 \(\delta\)가 실패함을 보인다.
  5. 극한은 하나뿐이다. 한쪽 극한이 다르면 극한은 없다.

2.1.6연습문제

기본

  1. \(\lim_{x\to-1}(4 - 3x) = 7\)을 ε-δ 정의로 증명하여라.
    답

    \(|4 - 3x - 7| = 3|x + 1|\). \(\delta = \frac\varepsilon3\)이면 \(0 < |x + 1| < \delta\)에서 \(3|x + 1| < \varepsilon\).

  2. \(\lim_{x\to5}(2x + 1) = 11\)에서 \(\varepsilon = 0.01\)일 때 쓸 수 있는 \(\delta\)를 하나 구하여라. 그보다 큰 \(\delta\)도 되는가?
    답

    \(\delta = 0.005\). \(\delta = 0.006\)이면 \(x = 5.0055\)에서 차이가 0.011이 되어 실패한다. 0.005보다 작은 \(\delta\)는 모두 된다.

  3. 상수함수 \(f(x) = c\)에 대해 \(\lim_{x\to a}f(x) = c\)임을 보여라. \(\delta\)는 얼마로 잡는가?
    답

    \(|f(x) - c| = 0 < \varepsilon\)이 언제나 성립하므로 어떤 \(\delta\)를 잡아도 된다(예: \(\delta = 1\)).

응용

  1. \(\lim_{x\to1}(x^2 + x) = 2\)를 증명하여라.
    힌트

    \(x^2 + x - 2 = (x - 1)(x + 2)\). \(\delta \le 1\)이면 \(|x + 2| < 4\).

    답

    \(\delta = \min(1, \frac\varepsilon4)\). \(0 < |x - 1| < \delta\)이면 \(0 < x < 2\)라 \(|x + 2| < 4\), \(|x^2 + x - 2| < 4\cdot\frac\varepsilon4 = \varepsilon\).

  2. \(\lim_{x\to4}\sqrt x = 2\)를 증명하여라.
    힌트

    \(\sqrt x - 2 = \frac{x - 4}{\sqrt x + 2}\)이고 \(\sqrt x + 2 \ge 2\).

    답

    \(|\sqrt x - 2| = \frac{|x - 4|}{\sqrt x + 2} \le \frac{|x - 4|}{2}\). \(\delta = \min(4, 2\varepsilon)\)으로 잡는다(\(\delta \le 4\)는 \(x \ge 0\)이 되게, 곧 \(\sqrt x\)가 정의되게 하려는 것).

심화

  1. \(\lim_{x\to a}f(x) = L\)일 필요충분조건은 \(\lim_{x\to a^+}f(x) = L\)이고 \(\lim_{x\to a^-}f(x) = L\)인 것임을 증명하여라.
    힌트

    (⇐) 두 한쪽 극한에서 얻은 \(\delta_1, \delta_2\) 중 작은 쪽을 쓰세요.

    답

    (⇒) 양쪽 조건을 만족하는 \(\delta\)는 한쪽만 보는 조건도 만족한다. (⇐) \(a < x < a + \delta_1\)이면, \(a - \delta_2 < x < a\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1, \delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)이면 \(0 < |x - a| < \delta\)인 \(x\)는 둘 중 한 경우에 속하므로 \(|f(x) - L| < \varepsilon\).
