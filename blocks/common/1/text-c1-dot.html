9.3.1정의와 사잇각

정의 9.3.1 (내적)

\(\mathbf a = \langle a_1, a_2, a_3\rangle\), \(\mathbf b = \langle b_1, b_2, b_3\rangle\)의 내적은 \(\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + a_3b_3\). 결과는 벡터가 아니라 수(스칼라)이다.

계산은 같은 자리 성분끼리 곱해 더하면 됩니다. 이 단순한 계산이 두 벡터 사이의 각을 알려 줍니다.

정리 9.3.2

\(\theta\)가 \(\mathbf a\)와 \(\mathbf b\)의 사잇각(\(0 \le \theta \le \pi\))이면 \(\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\theta\).

이유: 두 벡터와 \(\mathbf a - \mathbf b\)가 이루는 삼각형에 코사인 법칙을 쓰면 \(|\mathbf a - \mathbf b|^2 = |\mathbf a|^2 + |\mathbf b|^2 - 2|\mathbf a||\mathbf b|\cos\theta\)입니다. 왼쪽을 성분으로 전개하면 \(|\mathbf a|^2 + |\mathbf b|^2 - 2(a_1b_1 + a_2b_2 + a_3b_3)\)이므로 비교하면 됩니다.

따라서 두 벡터가 수직(\(\theta = \frac\pi2\))일 필요충분조건은 \(\mathbf a\cdot\mathbf b = 0\)입니다. 내적이 양수이면 사잇각이 예각, 음수이면 둔각입니다.

예제 9.3.3

\(\mathbf a = \langle2, 2, -1\rangle\), \(\mathbf b = \langle5, -3, 2\rangle\)의 사잇각을 구하여라. 또 \(\langle1, 2, 2\rangle\)과 \(\langle2, -1, 0\rangle\)이 수직임을 보여라.

풀이. \(\mathbf a\cdot\mathbf b = 10 - 6 - 2 = 2\), \(|\mathbf a| = 3\), \(|\mathbf b| = \sqrt{38}\). \(\cos\theta = \dfrac{2}{3\sqrt{38}} \approx 0.108\), \(\theta \approx 1.46\) rad \(\approx 84^\circ\). 둘째: \(2 - 2 + 0 = 0\)이므로 수직.

9.3.2정사영

\(\mathbf b\)에 \(\mathbf a\) 방향으로 수직으로 빛을 비추면 \(\mathbf a\) 위에 그림자가 생깁니다. 그림자의 부호 있는 길이를 스칼라 정사영, 그림자 벡터를 벡터 정사영이라 합니다.

\[\text{comp}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|}, \qquad \text{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|^2}\mathbf a.\]

물리에서 힘 \(\mathbf F\)가 물체를 변위 \(\mathbf D\)만큼 옮길 때 한 일은 "이동 방향의 힘 성분 × 거리"이므로 \(W = \mathbf F\cdot\mathbf D\)입니다. 일반물리학(1)의 일이 바로 내적입니다.

예제 9.3.4

수평에서 30° 위쪽으로 70 N의 힘으로 썰매를 끌어 수평으로 100 m 옮겼다. 한 일은?

풀이. \(W = |\mathbf F||\mathbf D|\cos30^\circ = 70\cdot100\cdot\frac{\sqrt3}{2} \approx 6062\) J.

주의내적의 결과는 수입니다. \(\mathbf a\cdot\mathbf b\)를 벡터처럼 \(\langle a_1b_1, a_2b_2, a_3b_3\rangle\)로 쓰면 틀립니다. 벡터를 결과로 주는 곱(외적)은 공통2 1단원에서 배웁니다.
요약
  1. \(\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + a_3b_3 = |\mathbf a||\mathbf b|\cos\theta\).
  2. \(\mathbf a\cdot\mathbf b = 0 \iff\) 수직.
  3. 정사영 \(\text{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|^2}\mathbf a\). 일 \(W = \mathbf F\cdot\mathbf D\).

9.3.3연습문제

기본

  1. \(\langle1, 1, 0\rangle\)과 \(\langle0, 1, 1\rangle\)의 사잇각은?
    답

    \(\cos\theta = \frac{1}{\sqrt2\sqrt2} = \frac12\), \(\theta = \frac\pi3\).

  2. \(\langle3, k, -2\rangle\)과 \(\langle1, 2, 4\rangle\)이 수직이 되는 \(k\)는?
    답

    \(3 + 2k - 8 = 0\), \(k = \frac52\).

응용

  1. \(\mathbf b = \langle1, 1, 2\rangle\)의 \(\mathbf a = \langle-2, 3, 1\rangle\) 위로의 벡터 정사영을 구하여라.
    답

    \(\mathbf a\cdot\mathbf b = 3\), \(|\mathbf a|^2 = 14\). \(\frac{3}{14}\langle-2, 3, 1\rangle\).
