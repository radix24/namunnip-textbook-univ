유리함수를 적분할 때는 분자와 분모의 차수부터 비교한다

요령 · 부분분수

언제 쓰는가

다항식 나누기 다항식, 곧 \(\frac{P(x)}{Q(x)}\) 꼴을 적분할 때입니다. 분모가 인수분해되고 치환이 바로 보이지 않으면 거의 언제나 이 순서로 풉니다.

요령

  1. 차수 비교
    분자의 차수가 분모의 차수와 같거나 크면 먼저 나눗셈을 해 '몫 + \(\frac{\text{나머지}}{Q}\)'로 바꿉니다. 부분분수는 진분수에만 씁니다.
  2. 분모를 끝까지 인수분해
    일차 인수 \((x - a)\), 거듭된 일차 인수 \((x - a)^2\), 더 쪼갤 수 없는 이차 인수 \((x^2 + bx + c)\)로 나눕니다.
  3. 인수마다 틀을 쓴다
    \(\frac{A}{x - a}\), 거듭되면 \(\frac{A}{x - a} + \frac{B}{(x - a)^2}\), 이차 인수 위에는 \(\frac{Cx + D}{x^2 + bx + c}\)처럼 일차식을 둡니다.
  4. 계수는 근을 넣어 먼저
    양변에 분모를 곱한 뒤 \(x = a\)를 넣으면 다른 항이 사라져 \(A\)가 바로 나옵니다. 남은 계수만 차수별 계수 비교로 구합니다.
  5. 항마다 적분
    \(\frac{A}{x - a} \to A\ln|x - a|\), \(\frac{B}{(x - a)^2} \to -\frac{B}{x - a}\), 이차 인수 항은 \(\ln\)과 \(\arctan\)으로 나눕니다.

흔한 실수

  • 가분수에 곧바로 부분분수 틀을 씌우는 것. 계수 방정식이 풀리지 않거나 틀린 답이 나옵니다.
  • 이차 인수 위에 상수 \(C\)만 두는 것. 분자는 분모보다 한 차수 낮은 일차식이어야 합니다.

바로 풀어보기

\(\displaystyle\int_2^3\frac{x^3}{x^2 - 1}\,dx\)를 구하세요.

답과 풀이

답: \(\frac52 + \frac12\ln\frac83 \approx 2.990\)

분자 3차, 분모 2차이므로 먼저 나눕니다. \(x^3 = x(x^2 - 1) + x\)이므로 \(\frac{x^3}{x^2 - 1} = x + \frac{x}{x^2 - 1}\)입니다. 둘째 항은 분자가 분모 도함수의 절반이라 부분분수 없이 \(\frac12\ln|x^2 - 1|\)로 적분됩니다.

\[\Big[\frac{x^2}{2} + \frac12\ln(x^2 - 1)\Big]_2^3 = \frac92 - 2 + \frac12(\ln 8 - \ln 3).\]

나눗셈을 하고 나니 부분분수조차 필요 없어졌습니다. 차수 비교를 먼저 하는 이유입니다.

이 요령으로 풀리는 문제

  • 적분법 단원 연습 3번, 7번 (다)
영상 콘티 · 45초
  1. 0~5초\(\int\frac{x^3}{x^2 - 1}dx\)가 나타나고, 분모 아래에서 부분분수 틀 \(\frac{A}{x - 1} + \frac{B}{x + 1}\)이 성급하게 튀어나옵니다.잠깐, 바로 쪼개면 안 됩니다.
  2. 5~12초틀이 사라지고, 분자 위에 '3차', 분모 아래에 '2차' 이름표가 저울 양쪽에 올라갑니다. 분자 쪽으로 저울이 기웁니다.먼저 차수를 비교합니다.
  3. 12~22초세로 나눗셈 칸이 펼쳐져 몫 \(x\)와 나머지 \(x\)가 내려옵니다. 식이 \(x + \frac{x}{x^2 - 1}\)로 바뀝니다.무거우면 먼저 나눕니다.
  4. 22~32초남은 분수의 분모 \(x^2 - 1\)에서 \(2x\)가 빠져나와 분자 \(x\)와 나란히 서고, '절반' 표시가 붙습니다.나누고 보니 치환으로 바로 풀립니다.
  5. 32~45초다른 예 \(\frac{5x + 1}{(x + 1)(x^2 + 1)}\)에서 저울이 분모 쪽으로 기울고, 틀 \(\frac{A}{x + 1} + \frac{Bx + C}{x^2 + 1}\)이 나타납니다. \(x = -1\)이 떨어져 들어가 \(A\)만 남기고 나머지 항이 사라집니다.가벼우면 쪼개고, 근을 넣어 계수를 구합니다.
