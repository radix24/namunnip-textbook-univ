비 판정법과 근 판정법

본문

\(\frac{1}{3} + \frac{8}{9} + \frac{27}{27} + \frac{64}{81} + \cdots = \sum\frac{n^3}{3^n}\)은 처음 몇 항이 오히려 커진다. 이 급수가 수렴하는지 어떻게 판단할까? 멀리 있는 항들끼리의 비를 보면 등비급수처럼 보이지 않을까?

먼저 알아야 할 것등비급수(8.2절), 절대수렴(8.4절), 고교 수학의 계승 \(n!\)을 쓴다.

8.5.1비 판정법

등비급수는 이웃한 항의 비가 일정한 \(r\)이고, \(|r| < 1\)이면 수렴했다. 그런데 항의 비가 일정하지는 않아도 \(n\)이 커질 때 어떤 값 \(L\)에 다가간다면, 먼 항들은 공비가 거의 \(L\)인 등비급수처럼 행동할 것이다. 처음 질문의 급수에서 비는 \(\frac13\left(1 + \frac1n\right)^3\)이라서, \(n = 1, 2\)에서는 1보다 크지만 \(n = 3\)부터 1보다 작아지고 결국 \(\frac13\)에 다가간다.

정리 8.5.1 (비 판정법)

\(\displaystyle L = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|\)이라 하자. \(L < 1\)이면 \(\sum a_n\)은 절대수렴하고, \(L > 1\)(또는 \(\infty\))이면 발산한다. \(L = 1\)이면 이 판정법으로는 알 수 없다.

\(L < 1\)이면 \(L\)과 1 사이의 수 \(r\)을 하나 골라, 어느 항부터는 비가 \(r\)보다 작다고 할 수 있다. 그러면 그 뒤의 항들은 공비 \(r\)인 등비급수의 항보다 작으므로 8.3절의 비교 판정법으로 수렴한다. 계승(\(n!\))이나 거듭제곱(\(2^n\), \(n^n\))이 들어 있으면 비 판정법이 잘 통한다. 비를 계산하면 대부분이 약분되기 때문이다.

예제 8.5.2

(가) \(\sum\frac{n^3}{3^n}\) (나) \(\sum\frac{n!}{2^n}\) (다) \(\sum\frac{1}{n^2}\)에 비 판정법을 써라.

풀이. (가) \(\dfrac{(n + 1)^3/3^{n+1}}{n^3/3^n} = \dfrac13\left(1 + \dfrac1n\right)^3 \to \dfrac13 < 1\)이므로 수렴한다.

(나) \(\dfrac{(n + 1)!/2^{n+1}}{n!/2^n} = \dfrac{n + 1}{2} \to \infty\)이므로 발산한다. 항 자체가 끝없이 커지니 당연한 결과이기도 하다.

(다) \(\dfrac{n^2}{(n + 1)^2} \to 1\)이므로 판정할 수 없다. 실제로 이 급수는 수렴하지만, 같은 \(L = 1\)인 \(\sum\frac1n\)은 발산한다. 즉 \(p\)-급수에는 비 판정법이 통하지 않는다. 그림 1에서 \(\frac{1}{n^2}\)의 비가 1 아래에서 1로 붙어 가는 것이 이 경우이다.

8.5.2근 판정법

비 대신 항의 \(n\)제곱근을 보아도 같은 생각이 통한다. 등비급수에서는 \(\sqrt[n]{|ar^{n-1}|}\)이 \(|r|\)로 가기 때문이다.

정리 8.5.3 (근 판정법)

\(L = \lim\sqrt[n]{|a_n|}\)이라 하자. \(L < 1\)이면 절대수렴, \(L > 1\)이면 발산, \(L = 1\)이면 알 수 없다.

근 판정법은 항 전체가 \(n\)제곱 꼴일 때 편리하다.

예제 8.5.4

\(\sum\left(\dfrac{2n + 3}{3n + 2}\right)^n\)의 수렴을 판정하여라.

풀이. \(\sqrt[n]{a_n} = \dfrac{2n + 3}{3n + 2} \to \dfrac23 < 1\)이므로 수렴한다. 같은 급수에 비 판정법을 쓰면 비를 정리하기가 훨씬 번거롭다.

8.5.3판정법 고르기

여러 판정법 가운데 하나를 고를 때는 대략 다음 순서로 본다. 먼저 항이 0으로 가지 않으면 발산이다(8.2절). 다음으로 \(\frac{1}{n^p}\)이나 \(ar^{n-1}\) 꼴이면 그대로 판정한다. 항이 다항식이나 근호로 된 분수식이면 \(p\)-급수와 비교하거나 극한 비교한다(8.3절). 부호가 번갈아 바뀌면 교대급수 판정법을 쓴다(8.4절). \(n!\)이나 \(r^n\)이 있으면 비 판정법을, 항 전체가 \((\cdots)^n\)이면 근 판정법을 쓴다. 마지막으로 \(f(n)\)을 쉽게 적분할 수 있으면 적분 판정법을 쓴다.

이 순서는 외울 규칙이라기보다 항의 모양에서 등비급수나 \(p\)-급수와 닮은 점을 찾는 습관이다. 닮은 급수를 찾으면 거기에 맞는 판정법이 정해진다.

마무리

이웃한 항의 비가 \(L\)로 가면 먼 항들은 공비 \(L\)인 등비급수처럼 행동하므로, \(L < 1\)이면 수렴하고 \(L > 1\)이면 발산한다. 그래서 처음 질문의 \(\sum\frac{n^3}{3^n}\)은 비가 \(\frac13\)으로 가서 수렴한다. 다만 \(L = 1\)이면 판정할 수 없고, 항 전체가 \(n\)제곱 꼴이면 같은 판정을 \(n\)제곱근으로 하는 근 판정법이 편하다.
