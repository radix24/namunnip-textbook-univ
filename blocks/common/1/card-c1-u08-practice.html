수열과 급수 연습 문제

문제 6 · 힌트 2단계 · 풀이

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. \(a_1 = 1\), \(a_{n+1} = \dfrac{a_n + 6}{2}\)이 수렴함을 보이고 극한을 구하세요. [08-01]

    힌트 1

    고정점 \(L = \frac{L + 6}{2}\)에서 \(L = 6\). 상계 후보는 6.

    힌트 2

    \(a_{n+1} - a_n = \frac{6 - a_n}{2}\).

    풀이

    유계: \(a_n < 6\) (귀납): \(a_1 = 1 < 6\), \(a_n < 6\)이면 \(a_{n+1} < \frac{12}{2} = 6\). 증가: \(a_{n+1} - a_n = \frac{6 - a_n}{2} > 0\). 단조 수렴 정리로 수렴하고, 극한 \(L = \frac{L + 6}{2}\)에서 \(L = 6\).

  2. \(\displaystyle\sum\frac{3^n}{n!}\), \(\displaystyle\sum\frac{1}{\sqrt{n^3 + 1}}\), \(\displaystyle\sum\frac{\ln n}{n}\)의 수렴, 발산을 판정하세요. [08-02]

    힌트 1

    계승 → 비. 근호식 → 극한 비교. 셋째는 \(\frac1n\)과 비교하거나 적분 판정.

    힌트 2

    \(n \ge 3\)이면 \(\ln n > 1\).

    풀이

    첫째: \(\frac{a_{n+1}}{a_n} = \frac{3}{n+1} \to 0 < 1\). 수렴.

    둘째: \(\frac{1}{\sqrt{n^3+1}}\big/\frac{1}{n^{3/2}} \to 1\), \(p = \frac32 > 1\). 수렴.

    셋째: \(n \ge 3\)에서 \(\frac{\ln n}{n} > \frac1n\), \(\sum\frac1n\) 발산. 발산.

  3. \(\displaystyle\sum_{n=1}^\infty\frac{(-1)^{n+1}}{n^3}\)의 합을 오차 \(0.001\) 이하로 구하려면 몇 항까지 더해야 하나요? [08-02]

    힌트 1

    교대급수 오차: \(|S - S_N| \le b_{N+1}\).

    힌트 2

    \(\frac{1}{(N+1)^3} \le 0.001 \iff N + 1 \ge 10\).

    풀이

    \(N = 9\)항이면 오차 \(\le \frac{1}{1000}\). \(S_9 \approx 0.90211\) (참값 \(\frac34\zeta(3) \approx 0.90154\)).

  4. \(\displaystyle\sum\frac{(-1)^n n}{n^2 + 1}\)과 \(\displaystyle\sum\frac{\cos(n\pi)}{n\sqrt n}\)이 절대수렴, 조건수렴, 발산 중 어느 것인지 판정하세요. [08-03]

    힌트 1

    첫째의 절댓값 \(\frac{n}{n^2 + 1}\)은 \(\frac1n\)과 닮았습니다.

    힌트 2

    \(\cos(n\pi) = (-1)^n\).

    풀이

    첫째: 극한 비교로 \(\sum\frac{n}{n^2+1}\) 발산. \(b_n = \frac{n}{n^2 + 1}\)은 \(n \ge 1\)에서 감소(\(\left(\frac{x}{x^2+1}\right)' = \frac{1 - x^2}{(x^2+1)^2} \le 0\))하며 \(\to 0\). 조건수렴.

    둘째: \(\left|\frac{(-1)^n}{n^{3/2}}\right| = \frac{1}{n^{3/2}}\), \(p = \frac32\). 절대수렴.

  5. \(\displaystyle\sum_{n=0}^\infty\frac{n\,(2x + 1)^n}{4^n}\)의 수렴 반지름과 수렴 구간을 구하세요. [08-04]

    힌트 1

    비 판정: \(\to\frac{|2x+1|}{4}\).

    힌트 2

    \(|2x + 1| < 4 \iff |x + \frac12| < 2\). 끝점에서 항이 0으로 가나요?

    풀이

    \(\left|\frac{a_{n+1}}{a_n}\right| = \frac{n+1}{n}\cdot\frac{|2x+1|}{4} \to \frac{|2x+1|}{4}\). \(|x + \frac12| < 2\)에서 수렴, 중심 \(-\frac12\), \(R = 2\).

    끝점 \(x = \frac32\): \(\sum n\), \(x = -\frac52\): \(\sum(-1)^nn\). 둘 다 항이 0으로 가지 않아 발산. 수렴 구간 \(\left(-\frac52, \frac32\right)\).

  6. \(\cos x\)의 Maclaurin 급수를 써서 \(\displaystyle\int_0^1\cos(x^2)\,dx\)를 오차 \(10^{-4}\) 이하로 구하세요. [08-05]

    힌트 1

    \(\cos(x^2) = 1 - \frac{x^4}{2!} + \frac{x^8}{4!} - \frac{x^{12}}{6!} + \cdots\). 항별 적분.

    힌트 2

    적분하면 \(1 - \frac{1}{10} + \frac{1}{216} - \frac{1}{9360} + \cdots\), 교대급수.

    풀이

    \(\int_0^1\cos(x^2)dx = \sum_{n\ge0}\frac{(-1)^n}{(2n)!(4n+1)} = 1 - 0.1 + 0.0046296 - 0.0001068 + 0.0000020 - \cdots\).

    교대급수이고 항이 감소하므로 넷째 항까지의 합 \(0.904523\)의 오차는 다섯째 항 \(\frac{1}{8!\cdot17} \approx 1.5\times10^{-6}\) 이하입니다. 답 \(\approx 0.9045\). (셋째 항까지만 더하면 오차가 \(1.07\times10^{-4}\)까지 될 수 있어 부족합니다.)
