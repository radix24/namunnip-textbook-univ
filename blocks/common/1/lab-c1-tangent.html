할선이 접선이 되는 순간

실습 · 도함수의 정의

목표

\(h\)를 0에 가깝게 줄이며 할선의 기울기 \(\frac{f(a + h) - f(a)}{h}\)가 접선의 기울기 \(f'(a)\)에 다가가는 것을 숫자와 그림으로 확인합니다. 미분할 수 없는 점에서는 왼쪽과 오른쪽 극한이 다르다는 것을 봅니다. 성취기준 [공통1-02-01].

준비

파란 곡선이 함수, 주황 직선이 할선, 회색 점선이 접선입니다. \(h\)는 로그 눈금으로 조절합니다(−3이면 \(h = 0.001\)). "왼쪽에서"를 켜면 \(h < 0\)입니다.

절차

  1. \(x^2\), \(a = 1\)에서 \(\log h\)를 0, −1, −2, −3으로 바꾸며 할선 기울기와 차이를 기록한다.
  2. "왼쪽에서"를 켜고 같은 일을 한다.
  3. \(|x|\)를 고르고 \(a = 0\)에서 왼쪽과 오른쪽의 할선 기울기를 비교한다.

기대 결과

  • \(x^2\)의 할선 기울기는 \(2 + h\)로, 차이가 \(h\)에 비례해 줄어든다(\(h\)를 10분의 1로 하면 차이도 10분의 1).
  • \(|x|\)의 \(a = 0\)에서 오른쪽은 늘 1, 왼쪽은 늘 −1. 극한이 없으므로 미분 불가능.

분석

  1. \(\sqrt x\)의 \(a = 0\)에서는 무슨 일이 생기나요? 접선이 어떻게 생겼을지 생각해 보세요.
  2. \(h\)를 \(10^{-4}\)보다 더 작게 하면 컴퓨터 계산에서는 오히려 오차가 커질 수 있습니다. 왜 그럴까요?

더 해 보기

할선 대신 \(\frac{f(a + h) - f(a - h)}{2h}\)(중앙 차분)를 계산해 보면 차이가 \(h^2\)에 비례해 훨씬 빨리 줄어듭니다. \(x^3 - 3x\)에서 손으로 확인해 보세요.
