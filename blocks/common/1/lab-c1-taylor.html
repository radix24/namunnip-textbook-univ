테일러 다항식으로 함수 흉내 내기

실습 · 차수, 중심, 수렴 반지름

목표

차수 \(n\)과 중심 \(a\)를 바꿔 테일러 다항식 \(P_n\)이 함수에 얼마나 가까워지는지 보고, 어떤 함수는 수렴 반지름 밖에서 차수를 아무리 높여도 맞지 않음을 확인한다. 성취기준 [공통1-08-08].

준비

파란 곡선이 함수, 주황 곡선이 \(P_n(x) = \sum_{k=0}^n\frac{f^{(k)}(a)}{k!}(x - a)^k\)이다. 보라색 띠는 수렴 구간이다. 아래 숫자 줄은 고른 \(x\)에서의 값과 오차이다.

절차

  1. \(e^x\), \(a = 0\), \(x = 1\)에서 \(n = 1, 2, 4, 8\)의 오차를 기록한다(공통1 8.8절 자기 점검: \(e\)를 소수 넷째 자리까지).
  2. \(\sin x\)에서 \(n\)을 늘리며 잘 맞는 구간이 넓어지는 모습을 본다.
  3. \(\ln(1 + x)\), \(a = 0\)에서 \(x = 0.5\)와 \(x = 1.5\)의 오차를 \(n\)을 늘리며 비교한다.
  4. \(1/(1 - x)\)에서 중심을 \(-2\)로 옮겨 수렴 구간이 어떻게 바뀌는지 본다.

기대 결과

  • \(e^1\): \(n = 8\)이면 오차 약 \(3\times10^{-6}\). \(n = 7\)에서 이미 소수 넷째 자리까지 맞는다.
  • \(\sin x\)는 모든 \(x\)에서 수렴하므로 \(n\)을 늘리면 맞는 구간이 계속 넓어진다.
  • \(\ln(1 + x)\)는 수렴 반지름 1: \(x = 0.5\)에서는 오차가 줄고, \(x = 1.5\)에서는 \(n\)을 늘릴수록 오히려 커진다.
  • \(1/(1 - x)\)의 중심을 \(-2\)로 옮기면 수렴 반지름이 3(특이점 1까지의 거리)이 된다.

분석

  1. \(e^x\), \(\sin x\)와 \(\ln(1 + x)\)의 차이는 무엇인가요? 그래프만 보아서는 \(\ln(1 + x)\)가 \(x = 1.5\)에서 특별해 보이지 않는데 왜 맞지 않을까? (공통9 5.1절에서 복소수로 답한다.)
  2. 계산기는 \(\sin x\)를 어떻게 계산할까? 큰 \(x\)를 작은 \(x\)로 바꾸는 방법을 생각해 보자.

더 해 보기

라그랑주 나머지 \(|R_n| \le \frac{M}{(n + 1)!}|x - a|^{n + 1}\)으로 \(e^1\)의 오차를 어림하고(\(M = e < 3\)), 출력의 실제 오차와 비교해 보자.
