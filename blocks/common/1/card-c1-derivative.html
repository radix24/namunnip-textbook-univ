도함수의 정의와, 미분 가능하면 연속인 이유

미분계수 · 미분가능성

왜 필요한가

고등학교에서는 \(x^n\)의 도함수가 \(nx^{n-1}\)이라는 공식부터 썼다. 대학에서는 공식이 통하지 않는 함수(\(|x|\), \(x^2\sin\frac1x\), 구간별로 정의된 함수)를 다루므로, 정의로 직접 미분계수를 구하고 "미분 가능한가"를 판정할 수 있어야 한다.

정의 · 미분계수와 도함수

\(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있을 때, 극한

\[f'(a) = \lim_{h\to 0}\frac{f(a+h) - f(a)}{h}\]

가 존재하면 \(f\)는 \(a\)에서 미분 가능하다고 하고 이 값을 미분계수라 한다. 각 점의 미분계수를 대응시킨 함수 \(f'\)을 도함수라 한다.

정의를 풀어 읽기

  1. \(\frac{f(a+h) - f(a)}{h}\)두 점 \((a, f(a))\), \((a+h, f(a+h))\)를 잇는 할선의 기울기, 곧 구간 \([a, a+h]\)의 평균변화율이다.
  2. \(h \to 0\)\(h\)는 양수와 음수 양쪽에서 0으로 간다. 오른쪽 극한과 왼쪽 극한이 모두 존재하고 같아야 미분 가능하다.
  3. 극한이 존재하지 않는 경우꺾인 점(양쪽 기울기가 다름), 수직 접선(기울기 → ∞), 진동(극한 없음)에서는 미분 불가능하다.
  4. 다른 표기\(x = a + h\)로 두면 \(f'(a) = \lim_{x\to a}\frac{f(x) - f(a)}{x - a}\). 라이프니츠 표기 \(\frac{dy}{dx}\)는 같은 것을 "아주 작은 변화의 비"로 읽게 해 준다.

예: 정의로 미분하기

예 1. \(f(x) = \sqrt{x}\), \(a > 0\):

\[\frac{\sqrt{a+h} - \sqrt{a}}{h} = \frac{(a+h) - a}{h(\sqrt{a+h} + \sqrt{a})} = \frac{1}{\sqrt{a+h} + \sqrt{a}} \to \frac{1}{2\sqrt a}.\]

분자를 유리화해 \(h\)를 약분한 뒤 극한을 취했다. \(a = 0\)에서는 오른쪽 몫이 \(\frac{1}{\sqrt h} \to \infty\)라 미분 불가능합니다(수직 접선).

예 2. \(f(x) = |x|\), \(a = 0\): \(\frac{|h|}{h}\)는 \(h > 0\)이면 1, \(h < 0\)이면 −1. 양쪽 극한이 달라 미분 불가능합니다(꺾인 점). 그런데 \(|x|\)는 0에서 연속이다.

예 3. \(f(x) = x^2\sin\frac1x\ (x\ne0)\), \(f(0) = 0\): \(\frac{f(h) - 0}{h} = h\sin\frac1h\)이고 \(|h\sin\frac1h| \le |h| \to 0\)이므로 압축 정리로 \(f'(0) = 0\). 그래프가 끝없이 출렁여도 미분 가능할 수 있다.

미분 가능하면 연속이다

정리

\(f\)가 \(a\)에서 미분 가능하면 \(a\)에서 연속이다.

  1. \(h \ne 0\)일 때 \(f(a+h) - f(a) = \dfrac{f(a+h) - f(a)}{h}\cdot h\).
    \(h\)를 곱하고 나눈 항등식. \(h \ne 0\)이라 나눌 수 있다.
  2. \(h \to 0\)일 때 앞의 인수 → \(f'(a)\), 뒤의 인수 → 0이므로 \(f(a+h) - f(a) \to f'(a)\cdot 0 = 0\).
    곱의 극한 법칙. 두 극한이 모두 존재하므로 쓸 수 있다(미분 가능성 가정을 여기서 씀).
  3. 따라서 \(\lim_{h\to0} f(a+h) = f(a)\), 곧 \(f\)는 \(a\)에서 연속이다.
    \(x = a + h\)로 바꾸면 연속의 정의 \(\lim_{x\to a} f(x) = f(a)\).

되짚기: 거꾸로는 성립하지 않는다. 예 2의 \(|x|\)가 반례이다. 그래서 "불연속이면 미분 불가능"(대우)은 판정에 쓸 수 있지만, "연속이니까 미분 가능"은 쓸 수 없다.

흔한 오해

  • "도함수의 공식을 대입해서 \(f'(a)\)를 구했으니 미분 가능하다." 구간별로 정의된 함수는 경계점에서 공식이 통하지 않는다. 경계점은 정의(양쪽 극한)로 확인해야 한다.
  • "\(f'(x)\)의 극한이 \(f'(a)\)다." 예 3에서 \(x \ne 0\)이면 \(f'(x) = 2x\sin\frac1x - \cos\frac1x\)인데, \(x \to 0\)일 때 극한이 없다. 그래도 \(f'(0) = 0\)은 존재한다. 도함수는 연속이 아닐 수 있다.

확인경계점에서

\(f(x) = x^2\ (x \le 1)\), \(f(x) = 2x - 1\ (x > 1)\)은 \(x = 1\)에서?
