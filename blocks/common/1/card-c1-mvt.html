평균값 정리: 진술, 증명, 부등식에 쓰기

롤 정리 · 평균값 정리

왜 중요한가

도함수는 한 점의 정보이고, 함수값의 차이는 구간의 정보입니다. 평균값 정리는 이 둘을 잇는 다리입니다. "도함수가 양수이면 증가한다", "도함수가 0이면 상수다" 같은 당연해 보이는 사실도 이 정리로 증명합니다.

정리 · 평균값 정리 (MVT)

\(f\)가 \([a, b]\)에서 연속이고 \((a, b)\)에서 미분 가능하면, 어떤 \(c \in (a, b)\)가 있어

\[f'(c) = \frac{f(b) - f(a)}{b - a}.\]

쓰는 것

  • 최대·최소 정리: 닫힌구간에서 연속인 함수는 최댓값과 최솟값을 갖는다(실수의 완비성에서 나옴, 해석학에서 증명).
  • 페르마 정리: \(f\)가 열린구간 안의 점 \(c\)에서 극값을 갖고 미분 가능하면 \(f'(c) = 0\).

1단계: 페르마 정리

  1. \(f(c)\)가 극대라고 하자. \(c\) 근처의 작은 \(h\)에 대해 \(f(c+h) - f(c) \le 0\).
    극대의 정의. 극소는 \(-f\)에 적용하면 된다.
  2. \(h > 0\)이면 \(\frac{f(c+h) - f(c)}{h} \le 0\), 그러므로 오른쪽 극한 \(f'(c) \le 0\).
    0 이하의 값들의 극한은 0 이하.
  3. \(h < 0\)이면 \(\frac{f(c+h) - f(c)}{h} \ge 0\) (음수 ÷ 음수), 그러므로 \(f'(c) \ge 0\).
    미분 가능하므로 양쪽 극한이 모두 \(f'(c)\)와 같다.
  4. 따라서 \(f'(c) = 0\).
    2, 3단계.

2단계: 롤 정리 (\(f(a) = f(b)\)인 경우)

  1. \(f\)가 \([a,b]\)에서 상수이면 모든 \(c\)에서 \(f'(c) = 0\). 끝.
    상수의 도함수는 0.
  2. 상수가 아니면 \(f\)는 \(f(a)\)보다 큰 값이나 작은 값을 갖는다. 큰 값을 갖는다고 하자.
    작은 값이면 아래 논의를 최솟값으로 바꾼다.
  3. 최대·최소 정리로 \(f\)는 \([a,b]\)의 어떤 \(c\)에서 최댓값을 갖는다. \(f(c) > f(a) = f(b)\)이므로 \(c\)는 끝점이 아니다.
    연속성 가정을 여기서 씀.
  4. \(c \in (a,b)\)에서 최대이므로 극대, 페르마 정리로 \(f'(c) = 0\).
    미분 가능성 가정을 여기서 씀.

3단계: 평균값 정리

아이디어: 그래프에서 할선을 빼면 양 끝 높이가 같아져 롤 정리를 쓸 수 있습니다.

  1. \(m = \frac{f(b) - f(a)}{b - a}\), \(g(x) = f(x) - f(a) - m(x - a)\)로 둔다.
    \(g\)는 그래프와 할선의 세로 차이.
  2. \(g(a) = 0\), \(g(b) = f(b) - f(a) - (f(b) - f(a)) = 0\).
    \(m\)의 정의를 대입.
  3. \(g\)는 \([a,b]\)에서 연속, \((a,b)\)에서 미분 가능하다.
    \(f\)와 일차식의 차.
  4. 롤 정리로 \(g'(c) = f'(c) - m = 0\)인 \(c \in (a,b)\)가 있다. 곧 \(f'(c) = m\).
    2단계를 \(g\)에 적용.

바로 나오는 결과

  • 구간에서 \(f' = 0\)이면 \(f\)는 상수: 임의의 \(x_1 < x_2\)에 MVT를 쓰면 \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1) = 0\).
  • 구간에서 \(f' > 0\)이면 순증가: 같은 식에서 \(f(x_2) - f(x_1) > 0\).
  • \(f' = g'\)이면 \(f - g\)는 상수. 부정적분이 "상수 차이"까지만 정해지는 이유입니다.

부등식 증명에 쓰기 (성취기준 [공통1-04-01])

모든 실수 \(a, b\)에 대해 \(|\sin b - \sin a| \le |b - a|\)임을 보이세요. 또 \(x > 0\)이면 \(\dfrac{x}{1+x} < \ln(1+x) < x\)임을 보이세요.

  1. \(a = b\)이면 자명하게 등호. \(a \ne b\)이면 MVT로 \(\sin b - \sin a = \cos c\,(b - a)\)인 \(c\)가 \(a, b\) 사이에 있다.
    \(\sin\)은 어디서나 미분 가능.
  2. \(|\cos c| \le 1\)이므로 \(|\sin b - \sin a| \le |b - a|\).
    양변에 절댓값.
  3. 둘째: \(f(t) = \ln(1+t)\)에 \([0, x]\)에서 MVT. \(\ln(1+x) - 0 = \frac{1}{1+c}\cdot x\), \(0 < c < x\).
    \(f'(t) = \frac{1}{1+t}\).
  4. \(0 < c < x\)이면 \(\frac{1}{1+x} < \frac{1}{1+c} < 1\). 양변에 \(x > 0\)을 곱하면 \(\frac{x}{1+x} < \ln(1+x) < x\).
    \(\frac{1}{1+t}\)는 감소함수. \(c\)의 값을 몰라도 범위만으로 부등식을 얻는다.

요령: "차이" \(f(b) - f(a)\)가 보이면 MVT를 떠올리고, \(c\)를 모른다는 약점을 "\(c\)가 어느 범위에 있는지는 안다"로 바꿔 씁니다.

흔한 오해

  • 가정 생략: \(f(x) = |x|\), \([-1, 1]\)에서 할선 기울기는 0이지만 \(f'(c) = 0\)인 \(c\)는 없습니다. 0에서 미분 불가능하기 때문입니다.
  • "\(c\)는 구간의 가운데다." \(c\)의 위치는 일반적으로 모릅니다. 존재만 보장됩니다.
