거듭제곱급수

본문

\(1 + x + x^2 + x^3 + \cdots\)처럼 끝없이 이어지는 다항식은 함수가 될 수 있을까? 된다면 어떤 \(x\)에서 값이 정해지고, 어떤 \(x\)에서는 정해지지 않을까?

먼저 알아야 할 것비 판정법(8.5절), 교대급수(8.4절)와 \(p\)-급수(8.3절)를 쓴다.

8.6.1무한 차수의 다항식

다항식 \(c_0 + c_1x + c_2x^2 + \cdots + c_nx^n\)을 끝없이 이어 쓴 식

\[\sum_{n=0}^\infty c_nx^n = c_0 + c_1x + c_2x^2 + \cdots\]

를 거듭제곱급수라 한다. \(x\)에 수를 넣을 때마다 하나의 급수가 되고, 그 급수가 수렴하는 \(x\)에서 함숫값이 정해진다. 가장 간단한 예는 처음 질문의 모든 계수가 1인 \(\sum x^n\)이다. 이것은 등비급수이므로 \(|x| < 1\)일 때만 수렴하고 합은 \(\frac{1}{1 - x}\)이다. 즉 이 급수는 구간 \((-1, 1)\)에서 함수 \(\frac{1}{1 - x}\)과 같다.

그림 1에서 \(N\)을 4에서 30으로 늘려 보면 이 사실이 보인다. \(x = 0.5\)에서는 부분합이 곧바로 2에 붙지만, \(x = 0.9\)에서는 30항을 더해도 10에 조금 못 미친다. \(x < -1\) 쪽에서는 부분합이 \(N\)마다 위아래로 크게 흔들리며 \(\frac{1}{1 - x}\)과 멀어진다. 중심 \(a\)를 둔 \(\sum c_n(x - a)^n\)도 같은 방식으로 다룬다.

8.6.2수렴 반지름

정리 8.6.1

거듭제곱급수 \(\sum c_n(x - a)^n\)이 수렴하는 \(x\)는 다음 세 경우 가운데 하나이다. \(x = a\)에서만 수렴하거나, 모든 \(x\)에서 수렴하거나, 어떤 \(R > 0\)이 있어 \(|x - a| < R\)이면 수렴하고 \(|x - a| > R\)이면 발산한다. 이 \(R\)을 수렴 반지름이라 한다(앞의 두 경우는 \(R = 0\), \(R = \infty\)).

즉 수렴하는 \(x\)는 중심 \(a\)에서 거리 \(R\) 안에 모여 있다. 다만 경계 \(x = a \pm R\)에서는 수렴할 수도 발산할 수도 있어서 따로 확인한다. 수렴하는 \(x\) 전체를 수렴 구간이라 한다.

\(R\)을 구할 때는 비 판정법을 \(x\)를 남겨 둔 채 쓰고, 그 극한이 1보다 작아지는 \(x\)의 범위를 구한다. 그다음 양 끝점을 따로 넣어 본다.

예제 8.6.2

\(\displaystyle\sum_{n=1}^\infty\frac{(x - 3)^n}{n}\)의 수렴 반지름과 수렴 구간을 구하여라.

풀이. \(\left|\dfrac{(x - 3)^{n+1}/(n + 1)}{(x - 3)^n/n}\right| = \dfrac{n}{n + 1}|x - 3| \to |x - 3|\)이다. 이것이 1보다 작으면 수렴하므로 \(R = 1\)이고, \(2 < x < 4\)에서 수렴한다.

끝점은 따로 본다. \(x = 4\)이면 \(\sum\frac1n\), 곧 조화급수라 발산한다. \(x = 2\)이면 \(\sum\frac{(-1)^n}{n}\)이라 교대급수로 수렴한다. 따라서 수렴 구간은 \([2, 4)\)이다. 같은 반지름 안에서도 양 끝의 운명이 다를 수 있다는 것을 이 예가 보여 준다.

예제 8.6.3

\(\sum\frac{x^n}{n!}\)과 \(\sum n!\,x^n\)의 수렴 반지름을 구하여라.

풀이. 앞의 것은 비가 \(\frac{|x|}{n + 1} \to 0 < 1\)이고 이것이 모든 \(x\)에서 성립하므로 \(R = \infty\)이다. 이 급수는 \(e^x\)이며 8.8절에서 확인한다. 뒤의 것은 비가 \((n + 1)|x| \to \infty\) (\(x \ne 0\))이므로 \(x = 0\)에서만 수렴하고 \(R = 0\)이다. 계수 \(n!\)이 분모에 있느냐 분자에 있느냐가 정반대의 결과를 낸다.

주의비 판정법은 경계(\(L = 1\))에서는 아무것도 알려 주지 않는다. 양 끝점을 넣어 \(p\)-급수, 교대급수 판정법 등으로 따로 판정해야 수렴 구간이 정해진다.
마무리

거듭제곱급수는 끝없이 이어진 다항식으로, 급수가 수렴하는 \(x\)에서 정의되는 함수이다. 처음 질문의 \(1 + x + x^2 + \cdots\)는 \(|x| < 1\)에서 \(\frac{1}{1 - x}\)과 같고 그 바깥에서는 값이 정해지지 않는다. 일반적으로 수렴하는 \(x\)는 중심에서 수렴 반지름 \(R\) 안에 모이며, \(R\)은 비 판정법으로 구하고 끝점은 따로 판정한다.

8.6.3연습문제

기본

  1. \(\sum\frac{x^n}{2^n}\)의 수렴 반지름과 수렴 구간은?
    답

    \(R = 2\). 끝점에서 항이 \(\pm1\)이라 발산. 구간 \((-2, 2)\).

응용

  1. \(\sum\frac{(-1)^nx^n}{n^2}\)의 수렴 구간을 구하여라.
    답

    \(R = 1\). \(x = \pm1\)에서 \(\sum\frac{1}{n^2}\)로 절대수렴. 구간 \([-1, 1]\).
