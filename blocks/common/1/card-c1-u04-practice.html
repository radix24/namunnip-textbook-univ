미분의 응용 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 증명\(0 < a < b\)일 때 \(\dfrac{b - a}{b} < \ln\dfrac{b}{a} < \dfrac{b - a}{a}\)임을 보이세요. [03-02]

    힌트 1

    \(\ln\frac ba = \ln b - \ln a\)는 "차이"입니다.

    힌트 2

    \([a, b]\)에서 \(\ln x\)에 평균값 정리를 쓰고 \(\frac1c\)의 범위를 보세요.

    풀이

    MVT로 \(\ln b - \ln a = \frac1c(b - a)\)인 \(c \in (a, b)\)가 있다. \(a < c < b\)이므로 \(\frac1b < \frac1c < \frac1a\). 양변에 \(b - a > 0\)을 곱하면 원하는 부등식.

  2. 증명방정식 \(x^5 + 3x - 1 = 0\)의 실근이 정확히 하나임을 보이세요. [03-02]

    힌트 1

    "적어도 하나"는 사잇값 정리, "많아야 하나"는 롤 정리입니다.

    힌트 2

    근이 둘이라면 그 사이에 \(f'(c) = 0\)인 \(c\)가 있어야 합니다. \(f'\)을 보세요.

    풀이

    존재: \(f(0) = -1 < 0\), \(f(1) = 3 > 0\), \(f\)는 연속이므로 사잇값 정리로 \((0,1)\)에 근이 있다.

    유일: 서로 다른 두 근 \(r_1 < r_2\)가 있다면 \(f(r_1) = f(r_2) = 0\)이므로 롤 정리로 \(f'(c) = 0\)인 \(c\)가 있다. 그런데 \(f'(x) = 5x^4 + 3 \ge 3 > 0\). 모순.

  3. 계산\(f(x) = xe^{-x}\)의 증감, 극값, 오목성, 변곡점, 점근선을 구하세요. [03-02]

    힌트 1

    \(f'(x) = (1 - x)e^{-x}\), \(f''(x) = (x - 2)e^{-x}\). \(e^{-x} > 0\)이므로 부호는 앞 인수가 정합니다.

    힌트 2

    \(x \to \infty\)일 때 \(\frac{x}{e^x}\)는 로피탈로 구합니다.

    풀이

    \(x < 1\)에서 증가, \(x > 1\)에서 감소, 극대 \(f(1) = \frac1e\). \(x < 2\)에서 위로 볼록, \(x > 2\)에서 아래로 볼록, 변곡점 \((2, \frac{2}{e^2})\).

    \(\lim_{x\to\infty}\frac{x}{e^x} = \lim\frac{1}{e^x} = 0\)이므로 수평점근선 \(y = 0\) (오른쪽). \(x \to -\infty\)이면 \(f \to -\infty\).

  4. 계산점 \((4, 0)\)에서 곡선 \(y = \sqrt{x}\) 위의 점까지의 거리가 최소인 점을 구하세요. [03-01]

    힌트 1

    거리 대신 거리의 제곱을 최소화해도 같습니다. 왜일까요?

    힌트 2

    \(D(x) = (x - 4)^2 + x\), 정의역 \(x \ge 0\).

    풀이

    거리 \(d \ge 0\)에서 \(d \mapsto d^2\)은 증가함수이므로 같은 점에서 최소가 된다. \(D(x) = (x-4)^2 + x = x^2 - 7x + 16\), \(D'(x) = 2x - 7 = 0 \iff x = \frac72\). \(D\)는 위로 열린 포물선이므로 \([0, \infty)\)에서 이 점이 최소(끝점 \(D(0) = 16 > D(\frac72) = \frac{15}{4}\)도 확인).

    답: \(\left(\frac72, \sqrt{\frac72}\right)\), 최소 거리 \(\frac{\sqrt{15}}{2}\).

  5. 계산\(\displaystyle\lim_{x\to0^+} x^{x}\)과 \(\displaystyle\lim_{x\to0}\left(\frac{1}{x} - \frac{1}{\sin x}\right)\)을 구하세요. [03-03]

    힌트 1

    첫째는 \(0^0\)꼴: 로그를 취하세요. 둘째는 \(\infty - \infty\)꼴: 통분하세요.

    힌트 2

    \(\ln x^x = x\ln x \to 0\) (카드의 (나)). 둘째는 통분 뒤 로피탈을 두 번.

    풀이

    \(\ln(x^x) = x\ln x \to 0\)이므로 \(x^x \to e^0 = 1\).

    \(\frac1x - \frac1{\sin x} = \frac{\sin x - x}{x\sin x}\) (\(\frac00\)). 로피탈: \(\frac{\cos x - 1}{\sin x + x\cos x}\) (\(\frac00\)). 다시: \(\frac{-\sin x}{2\cos x - x\sin x} \to \frac{0}{2} = 0\).

  6. 계산Newton 방법으로 \(\sqrt[3]{10}\)을 구하는 점화식을 쓰고, \(x_0 = 2\)에서 \(x_2\)까지 계산하세요. 선형 근사로 구한 값과 비교하세요. [02-05]

    힌트 1

    \(f(x) = x^3 - 10\)의 근입니다.

    힌트 2

    \(x_{n+1} = x_n - \frac{x_n^3 - 10}{3x_n^2} = \frac{2x_n}{3} + \frac{10}{3x_n^2}\).

    풀이

    \(x_1 = \frac43 + \frac{10}{12} = \frac{13}{6} \approx 2.16667\). \(x_2 = \frac{2}{3}\cdot\frac{13}{6} + \frac{10}{3}\cdot\frac{36}{169} = \frac{13}{9} + \frac{120}{169} \approx 1.44444 + 0.71006 = 2.15450\). 참값 \(2.15443\ldots\)

    선형 근사(\(g(x) = \sqrt[3]{x}\), \(a = 8\)): \(2 + \frac{1}{12}\cdot 2 = 2.1667\). 이것은 Newton의 \(x_1\)과 같습니다. Newton 1회 = 역함수 쪽에서의 선형 근사 1회이고, 되풀이할수록 정확해집니다.

  7. 개념(가) \(f'(c) = 0\)이지만 \(c\)에서 극값이 아닌 함수, (나) \(c\)에서 극값이지만 \(f'(c)\)가 존재하지 않는 함수를 하나씩 드세요. [03-02]

    힌트 1

    03-02 절: 임계점의 두 종류를 떠올리세요.

    힌트 2

    (가)는 삼차함수, (나)는 절댓값.

    풀이

    (가) \(f(x) = x^3\), \(c = 0\): \(f'(0) = 0\)이지만 계속 증가합니다. (나) \(f(x) = |x|\), \(c = 0\): 최솟값이지만 미분 불가능합니다. 그래서 극값 후보(임계점)는 \(f' = 0\)인 점과 \(f'\)이 없는 점 모두이고, 후보마다 부호 변화로 확인해야 합니다.

  8. 판단한 학생이 \(\displaystyle\lim_{x\to0}\frac{x^2\sin(1/x)}{\sin x}\)에 로피탈을 쓰니 분자의 도함수 \(2x\sin\frac1x - \cos\frac1x\)의 극한이 없어서 "극한이 존재하지 않는다"고 결론 내렸습니다. 맞나요? [03-03]

    힌트 1

    03-03 절: 로피탈 정리는 \(f'/g'\)의 극한이 있을 때만 결론을 줍니다.

    힌트 2

    \(\frac{x}{\sin x}\cdot x\sin\frac1x\)로 나눠 보세요.

    풀이

    틀렸습니다. \(f'/g'\)의 극한이 없으면 로피탈 정리는 아무것도 말하지 않습니다. 다른 방법으로: \(\frac{x^2\sin(1/x)}{\sin x} = \frac{x}{\sin x}\cdot x\sin\frac1x\). 앞 인수 → 1, 뒤 인수는 \(|x\sin\frac1x| \le |x| \to 0\) (압축 정리). 극한은 0입니다.
