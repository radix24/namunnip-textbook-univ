적분의 응용 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

식을 세우기 전에 그림을 그리고, 한 조각의 양을 먼저 적어라.

  1. 계산\(y = \sqrt x\), \(y = 0\), \(x = 4\)로 둘러싸인 영역을 직선 \(y = -1\) 둘레로 돌린 입체의 부피를 구하여라. [06-01]

    힌트 1

    축이 영역 아래 1만큼 떨어져 있으므로 가운데가 빈 와셔이다.

    힌트 2

    \(R = \sqrt x + 1\), \(r = 0 + 1 = 1\).

    풀이

    \(V = \pi\int_0^4\left[(\sqrt x + 1)^2 - 1\right]dx = \pi\int_0^4(x + 2\sqrt x)\,dx = \pi\left(8 + \frac43\cdot8\right) = \frac{56\pi}{3}\).

  2. 계산\(y = \cosh x\), \(0 \le x \le \ln 2\)의 길이를 구하여라. [06-03]

    힌트 1

    \(1 + \sinh^2x = \cosh^2x\).

    힌트 2

    \(\sinh(\ln 2) = \frac{2 - \frac12}{2}\).

    풀이

    \(L = \int_0^{\ln2}\sqrt{1 + \sinh^2x}\,dx = \int_0^{\ln 2}\cosh x\,dx = \sinh(\ln2) = \frac{2 - 1/2}{2} = \frac34\).

  3. 계산자연 길이에서 0.1 m 늘이는 데 5 N이 드는 용수철을 자연 길이에서 0.3 m까지 늘이는 일을 구하세요(훅의 법칙). [06-01]

    힌트 1

    \(F(x) = kx\)에서 \(k\)를 먼저 구한다.

    힌트 2

    \(W = \int_0^{0.3}kx\,dx\).

    풀이

    \(5 = k(0.1)\), \(k = 50\ \text{N/m}\). \(W = \int_0^{0.3}50x\,dx = 25(0.09) = 2.25\ \text{J}\). 힘이 늘이는 거리에 따라 커지므로 "힘 × 거리"를 한 번에 곱할 수 없다.

  4. 계산반원판 \(x^2 + y^2 \le r^2\), \(y \ge 0\)의 무게중심을 구하고, 파푸스 정리로 구의 부피를 다시 얻어라. [06-01]

    힌트 1

    대칭으로 \(\bar x = 0\). \(\bar y = \frac1A\int\frac{f^2}{2}dx\), \(f = \sqrt{r^2 - x^2}\).

    힌트 2

    \(\int_{-r}^r\frac{r^2 - x^2}{2}dx = \frac{2r^3}{3}\).

    풀이

    \(A = \frac{\pi r^2}{2}\), \(\bar y = \frac{2r^3/3}{\pi r^2/2} = \frac{4r}{3\pi}\).

    파푸스: 반원판을 \(x\)축 둘레로 돌리면 구. \(V = A\cdot2\pi\bar y = \frac{\pi r^2}{2}\cdot2\pi\cdot\frac{4r}{3\pi} = \frac43\pi r^3\).

  5. 계산\(x = t^2\), \(y = t^3 - 3t\)인 곡선이 자기 자신과 만나는 점과 그 점에서의 두 접선의 기울기를 구하여라. [07-01]

    힌트 1

    서로 다른 \(t_1 \ne t_2\)에서 같은 점이 되려면 \(t_1^2 = t_2^2\), 곧 \(t_2 = -t_1\).

    힌트 2

    그러면 \(y\)도 같아야 하므로 \(t^3 - 3t = -(t^3 - 3t)\).

    풀이

    \(t^3 - 3t = 0\), \(t \ne 0\)이므로 \(t = \pm\sqrt3\). 교차점 \((3, 0)\).

    \(\frac{dy}{dx} = \frac{3t^2 - 3}{2t}\). \(t = \sqrt3\): \(\frac{6}{2\sqrt3} = \sqrt3\). \(t = -\sqrt3\): \(-\sqrt3\). 두 접선 \(y = \pm\sqrt3(x - 3)\).

  6. 계산장미 곡선 \(r = \sin 2\theta\)의 잎 하나의 넓이와 전체 넓이를 구하여라. [07-04]

    힌트 1

    한 잎은 \(r\)이 0에서 0까지: \(0 \le \theta \le \frac\pi2\).

    힌트 2

    \(\sin^22\theta = \frac{1 - \cos4\theta}{2}\). 잎은 4개이다.

    풀이

    한 잎: \(\frac12\int_0^{\pi/2}\sin^22\theta\,d\theta = \frac12\cdot\frac12\cdot\frac\pi2 = \frac\pi8\). 전체: \(4\cdot\frac\pi8 = \frac\pi2\).

    참고: \(\frac12\int_0^{2\pi}\sin^22\theta\,d\theta = \frac\pi2\)로 같다. \(r = \sin2\theta\)는 \(r < 0\)인 구간에서도 서로 다른 잎을 그리기 때문입니다(\(\sin3\theta\)와 다른 점).

  7. 개념회전체의 부피를 구할 때 원판(와셔)법과 원통껍질법 중 무엇을 고를지 정하는 기준을 설명하여라. [06-01]

    힌트 1

    06-01 절: 자르는 방향과 회전축의 관계.

    힌트 2

    곡선을 \(x\)로 쓰기 쉬운지, \(y\)로 쓰기 쉬운지도 본다.

    풀이

    회전축에 수직으로 자르면 원판, 평행하게 자르면 원통껍질이다. 영역의 경계가 \(y = f(x)\)로 주어졌다면 세로 띠(폭 \(dx\))가 편하다. 그래서 \(x\)축 회전이면 원판법, \(y\)축 회전이면 껍질법이 보통 쉽다. 다른 쪽을 쓰려면 곡선을 \(x = g(y)\)로 풀어야 하고, 풀 수 없으면 그 방법은 쓰기 어렵다.

  8. 판단한 학생이 \(y = x^2\) (\(0 \le x \le 1\)) 아래 영역을 \(x\)축 둘레로 돌린 부피를 \(\pi\int_0^1x^2\,dx = \frac\pi3\)이라고 했다. 다른 입체와 비교해 이 답이 이상한 이유를 쓰고 바로잡아라. [06-01]

    힌트 1

    06-01 절: \(0 \le x \le 1\)에서 \(x^2\)과 \(x\)를 비교하여라.

    힌트 2

    \(y = x\)를 돌리면 반지름 1, 높이 1인 원뿔(부피 \(\frac\pi3\))이다.

    풀이

    \(x^2 \le x\)라 이 입체는 원뿔 안에 들어가므로 부피가 \(\frac\pi3\)보다 작아야 한다. 원판의 넓이는 \(\pi(\text{반지름})^2 = \pi(x^2)^2\)인데 반지름을 제곱하지 않았다. 바른 답: \(\pi\int_0^1x^4\,dx = \frac\pi5\).
