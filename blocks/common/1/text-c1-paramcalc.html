먼저 알아야 할 것
  • 매개변수 곡선 (7.1절), 곡선의 길이 (6.3절).

7.2.1넓이

곡선 아래의 넓이 \(\int y\,dx\)에서 \(x = f(t)\)로 치환하면 \(dx = f'(t)\,dt\)이므로 넓이는 \(\int g(t)f'(t)\,dt\)입니다. 적분 구간은 \(x\)의 양 끝에 해당하는 \(t\) 값입니다.

예제 7.2.1

사이클로이드 \(x = r(\theta - \sin\theta)\), \(y = r(1 - \cos\theta)\)의 아치 하나 아래의 넓이를 구하여라.

풀이. \(dx = r(1 - \cos\theta)\,d\theta\), \(0 \le \theta \le 2\pi\).

\[A = \int_0^{2\pi}r^2(1 - \cos\theta)^2d\theta = r^2\int_0^{2\pi}\left(1 - 2\cos\theta + \frac{1 + \cos2\theta}{2}\right)d\theta = r^2\cdot3\pi = 3\pi r^2.\]

바퀴 넓이의 정확히 세 배입니다(갈릴레이가 종이를 오려 무게를 재서 짐작한 결과라고 전해집니다).

7.2.2곡선의 길이

6.3절의 \(ds^2 = dx^2 + dy^2\)을 \(dt\)로 묶으면 됩니다.

정리 7.2.2

곡선 \(x = f(t)\), \(y = g(t)\) (\(\alpha \le t \le \beta\))가 한 번만 지나가면 길이는

\[L = \int_\alpha^\beta\sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt.\]

\(t\)를 시간으로 보면 근호 안은 속력의 제곱이고, 길이는 "속력을 시간으로 적분한 것", 곧 이동 거리입니다.

예제 7.2.3

사이클로이드(반지름 \(r\)) 아치 하나의 길이를 구하여라.

풀이. \(\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 = r^2(1 - \cos\theta)^2 + r^2\sin^2\theta = 2r^2(1 - \cos\theta) = 4r^2\sin^2\frac\theta2\) (반각 공식). \(0 \le \theta \le 2\pi\)에서 \(\sin\frac\theta2 \ge 0\)이므로

\[L = \int_0^{2\pi}2r\sin\frac\theta2\,d\theta = 2r\left[-2\cos\frac\theta2\right]_0^{2\pi} = 8r.\]
주의곡선이 같은 부분을 두 번 지나가면(예: \(x = \sin2t\), \(y = \cos2t\), \(0 \le t \le 2\pi\)) 공식은 두 번 센 길이를 줍니다. 곡선을 한 번만 지나는 \(t\)의 범위를 고르세요.
요약
  1. 넓이: \(\int y\,dx = \int g(t)f'(t)\,dt\).
  2. 길이: \(\int\sqrt{x'(t)^2 + y'(t)^2}\,dt\) (속력의 적분).

7.2.3연습문제

기본

  1. \(x = \cos t\), \(y = \sin t\), \(0 \le t \le 2\pi\)의 길이를 공식으로 구하여라.
    답

    \(\int_0^{2\pi}1\,dt = 2\pi\).

응용

  1. \(x = e^t\cos t\), \(y = e^t\sin t\), \(0 \le t \le 1\)의 길이를 구하여라.
    답

    \(x'^2 + y'^2 = 2e^{2t}\). \(\int_0^1\sqrt2e^tdt = \sqrt2(e - 1) \approx 2.430\).
