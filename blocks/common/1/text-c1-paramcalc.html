매개변수 곡선의 넓이와 길이

본문

굴러가는 바퀴의 한 점이 그리는 아치 하나는 바퀴 자체와 비교해 넓이가 얼마나 되고, 길이는 얼마나 될까? 곡선이 매개변수로만 주어져도 넓이와 길이를 적분으로 구할 수 있을까?

먼저 알아야 할 것매개변수 곡선과 사이클로이드(7.1절), 곡선의 길이(6.3절), 치환적분과 반각 공식(5.2절)을 쓴다.

7.2.1넓이

곡선 아래의 넓이는 \(\int y\,dx\)였다. 곡선이 \(x = f(t)\), \(y = g(t)\)로 주어지면 \(x = f(t)\)로 치환하면 된다. 그러면 \(dx = f'(t)\,dt\)이므로 넓이는 \(\int g(t)f'(t)\,dt\)이고, 적분 구간은 \(x\)의 양 끝에 해당하는 \(t\) 값이다. 다시 말해 높이 \(y\)에 가로 폭 \(dx\)를 곱해 더한다는 생각은 그대로이고, 폭을 \(t\)로 재었을 뿐이다.

예제 7.2.1

사이클로이드 \(x = r(\theta - \sin\theta)\), \(y = r(1 - \cos\theta)\)의 아치 하나 아래의 넓이를 구하여라.

풀이. \(dx = r(1 - \cos\theta)\,d\theta\)이고 아치 하나는 \(0 \le \theta \le 2\pi\)이다. 반각 공식 \(\cos^2\theta = \frac{1 + \cos2\theta}{2}\)를 쓰면

\[A = \int_0^{2\pi}r^2(1 - \cos\theta)^2d\theta = r^2\int_0^{2\pi}\left(1 - 2\cos\theta + \frac{1 + \cos2\theta}{2}\right)d\theta = r^2\cdot3\pi = 3\pi r^2\]

이다. 즉 아치 아래 넓이는 바퀴 넓이 \(\pi r^2\)의 정확히 세 배이다. 갈릴레이가 종이를 오려 무게를 재서 이 비를 짐작했다고 전해진다. 그림 1에서 아치 아래에 바퀴 세 개를 늘어놓은 것과 넓이가 같다. 적분 안의 세 항 가운데 \(\cos\theta\)와 \(\cos2\theta\)는 한 주기 동안 적분하면 0이 되므로, 남는 것은 상수 \(1 + \frac12\)이고 여기에 \(2\pi\)를 곱해 \(3\pi\)가 나온다.

7.2.2곡선의 길이

길이는 6.3절의 \(ds^2 = dx^2 + dy^2\)을 \(dt\)로 묶으면 된다.

정리 7.2.2

곡선 \(x = f(t)\), \(y = g(t)\) (\(\alpha \le t \le \beta\))가 한 번만 지나가면 길이는

\[L = \int_\alpha^\beta\sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt.\]

\(t\)를 시간으로 보면 근호 안은 속력의 제곱이다. 따라서 길이는 속력을 시간으로 적분한 것, 곧 이동 거리이다. 자동차의 주행 거리계가 하는 일이 바로 이것이다.

예제 7.2.3

사이클로이드(반지름 \(r\)) 아치 하나의 길이를 구하여라.

풀이. 속력의 제곱은 \(\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 = r^2(1 - \cos\theta)^2 + r^2\sin^2\theta = 2r^2(1 - \cos\theta)\)이고, 반각 공식으로 \(4r^2\sin^2\frac\theta2\)이다. \(0 \le \theta \le 2\pi\)에서 \(\sin\frac\theta2 \ge 0\)이므로

\[L = \int_0^{2\pi}2r\sin\frac\theta2\,d\theta = 2r\left[-2\cos\frac\theta2\right]_0^{2\pi} = 8r\]

이다. 바퀴가 한 바퀴 구르는 동안 중심은 둘레 \(2\pi r \approx 6.28r\)만큼 가지만, 테두리의 점은 위로 올라갔다 내려오느라 그보다 긴 \(8r\)을 움직인다. 또 속력 \(2r\sin\frac\theta2\)는 꼭대기(\(\theta = \pi\))에서 \(2r\)로 가장 빠르고 바닥에서 0이다. 굴러가는 바퀴의 맨 위는 중심보다 두 배 빠르게 움직이고, 땅에 닿은 점은 잠깐 멈춘다는 뜻이다.

주의곡선이 같은 부분을 두 번 지나가면, 가령 \(x = \sin2t\), \(y = \cos2t\), \(0 \le t \le 2\pi\)이면, 공식은 두 번 센 길이를 준다. 곡선을 한 번만 지나는 \(t\)의 범위를 고른다.
마무리

매개변수 곡선 아래의 넓이는 \(\int y\,dx = \int g(t)f'(t)\,dt\)로, 길이는 속력을 적분한 \(\int\sqrt{x'(t)^2 + y'(t)^2}\,dt\)로 구한다. 그래서 처음 질문의 사이클로이드 아치는 넓이가 바퀴의 세 배인 \(3\pi r^2\)이고, 길이는 지름의 네 배인 \(8r\)이다. 곡선을 두 번 지나는 범위로 적분하지 않도록 \(t\)의 범위를 확인한다.

7.2.3연습문제

기본

  1. \(x = \cos t\), \(y = \sin t\), \(0 \le t \le 2\pi\)의 길이를 공식으로 구하여라.
    답

    \(\int_0^{2\pi}1\,dt = 2\pi\).

응용

  1. \(x = e^t\cos t\), \(y = e^t\sin t\), \(0 \le t \le 1\)의 길이를 구하여라.
    답

    \(x'^2 + y'^2 = 2e^{2t}\). \(\int_0^1\sqrt2e^tdt = \sqrt2(e - 1) \approx 2.430\).
