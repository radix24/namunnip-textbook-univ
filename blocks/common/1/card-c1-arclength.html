곡선의 길이와 회전면의 넓이는 어디서 오는가

꺾은선 근사 · 원뿔대 근사

무엇을 유도하나

\(f\)가 \([a,b]\)에서 연속인 도함수를 가질 때(매끄러운 곡선)

\[L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx, \qquad S = \int_a^b 2\pi f(x)\sqrt{1 + [f'(x)]^2}\,dx\ (f \ge 0,\ x\text{축 회전}).\]

길이의 유도

  1. \([a,b]\)를 분할하고 점 \(P_i = (x_i, f(x_i))\)를 이은 꺾은선의 길이를 곡선 길이의 근사로 삼는다.
    곡선 길이의 정의: 분할을 가늘게 할 때 꺾은선 길이의 극한.
  2. \(|P_{i-1}P_i| = \sqrt{\Delta x_i^2 + \Delta y_i^2}\), \(\Delta y_i = f(x_i) - f(x_{i-1})\).
    피타고라스.
  3. 평균값 정리로 \(\Delta y_i = f'(x_i^*)\Delta x_i\)인 \(x_i^* \in (x_{i-1}, x_i)\)가 있다. 따라서 \(|P_{i-1}P_i| = \sqrt{1 + f'(x_i^*)^2}\,\Delta x_i\).
    \(\Delta x_i\)를 근호 밖으로 묶었다. 평균값 정리 덕에 "≈"가 아니라 "="이다.
  4. 꺾은선 길이 \(\sum\sqrt{1 + f'(x_i^*)^2}\,\Delta x_i\)는 \(\sqrt{1 + f'^2}\)의 리만 합이고, 이 함수가 연속이라 \(\|P\| \to 0\)일 때 \(\int_a^b\sqrt{1 + f'^2}\,dx\)로 간다.
    5단원의 정의와 "연속이면 적분 가능".

기억법: 아주 짧은 조각에서 \(ds^2 = dx^2 + dy^2\), 곧 \(ds = \sqrt{1 + (dy/dx)^2}\,dx\).

회전면 넓이의 유도

각 선분 \(P_{i-1}P_i\)를 \(x\)축 둘레로 돌리면 원뿔대의 옆면이 된다. 원뿔대 옆면의 넓이는 \(2\pi\bar r\ell\) (\(\bar r\): 두 반지름의 평균, \(\ell\): 모선의 길이)이다. \(\bar r = \frac{f(x_{i-1}) + f(x_i)}{2} \to f(x)\), \(\ell = \sqrt{1 + f'^2}\,\Delta x\)이므로 합의 극한이 \(\int 2\pi f\sqrt{1 + f'^2}\,dx\)이다.

원판처럼 \(2\pi f\,dx\)로 하면 틀린다. 경사진 띠의 폭은 \(dx\)가 아니라 \(ds\)이기 때문이다. (부피에서는 \(dx\)로 해도 극한이 같지만, 넓이에서는 다르다.)

예제

(가) \(y = \frac23x^{3/2}\), \(0 \le x \le 3\)의 길이. (나) 반지름 \(r\)인 구의 겉넓이를 \(y = \sqrt{r^2 - x^2}\)을 돌려서 유도.

  1. (가) \(y' = x^{1/2}\), \(1 + y'^2 = 1 + x\). \(L = \int_0^3\sqrt{1 + x}\,dx = \left[\frac23(1 + x)^{3/2}\right]_0^3 = \frac23(8 - 1) = \frac{14}{3}\).
    근호 안이 깔끔해지도록 고른 예. 대부분의 곡선 길이는 부정적분을 식으로 못 써서 수치 적분을 쓴다.
  2. (나) \(y' = \frac{-x}{\sqrt{r^2 - x^2}}\), \(1 + y'^2 = \frac{r^2}{r^2 - x^2}\), \(y\sqrt{1 + y'^2} = \sqrt{r^2 - x^2}\cdot\frac{r}{\sqrt{r^2 - x^2}} = r\).
    근호가 소거되어 피적분함수가 상수가 된다.
  3. \(S = \int_{-r}^{r}2\pi r\,dx = 4\pi r^2\).
    끝점 \(x = \pm r\)에서 \(y'\)이 발산하지만 피적분함수는 상수 \(2\pi r\)로 연속이라 문제없다.

검산

(가) 끝점 \((0,0)\), \((3, 2\sqrt3)\) 사이의 직선 거리는 \(\sqrt{9 + 12} = \sqrt{21} \approx 4.58\)이고, 곡선 길이 \(4.67\)은 그보다 조금 길다. 맞다.
