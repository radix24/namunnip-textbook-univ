오비탈의 모양과 마디

본문
이 절에서 배울 것
  • s, p, d 오비탈의 모양을 안다.
  • 방사 마디와 각 마디의 수를 센다.
먼저 알아야 할 것
  • 양자수 (6.2절).

6.3.1모양

  • s 오비탈: 공 모양. 방향이 없다. \(n\)이 클수록 크다.
  • p 오비탈: 원자핵을 사이에 둔 두 개의 엽(아령 모양). \(p_x, p_y, p_z\) 세 방향.
  • d 오비탈: 대부분 네 잎 클로버 모양 다섯 개(\(d_{z^2}\)는 아령과 고리).

그림의 모양은 전자를 찾을 확률이 높은 영역(보통 90%)의 경계입니다. 전자가 그 표면을 도는 것이 아닙니다.

6.3.2마디

전자를 발견할 확률이 0인 곳을 마디라 합니다(공통3 9.3절 정상파의 마디와 같은 개념).

  • 전체 마디 수 \(= n - 1\).
  • 각 마디(평면이나 원뿔) 수 \(= l\). p는 원자핵을 지나는 평면 하나, d는 둘.
  • 방사 마디(구면) 수 \(= n - l - 1\).
예제 6.3.1

2s, 3p, 3d 오비탈의 방사 마디와 각 마디 수는?

풀이. 2s: 방사 1, 각 0. 3p: 방사 1, 각 1. 3d: 방사 0, 각 2.

방사 마디가 있으면 바깥 오비탈의 전자도 일부는 원자핵 가까이까지 들어옵니다(침투). 같은 껍질에서 s가 p보다, p가 d보다 원자핵을 잘 느껴 에너지가 낮은 이유이며, 다음 절의 쌓음 순서를 정합니다.

요약
  1. s 공, p 아령(3), d 클로버(5).
  2. 마디: 전체 \(n - 1\), 각 \(l\), 방사 \(n - l - 1\).

6.3.3연습문제

기본

  1. 4f 오비탈의 방사 마디 수는?
    답

    \(4 - 3 - 1 = 0\).
