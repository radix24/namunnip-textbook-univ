연소 반응식은 탄소, 수소, 산소 순서로 맞추고 산소는 마지막에 맞춘다

요령 · 반응식 맞추기

언제 쓰는가

탄화수소나 알코올이 산소와 타는 반응식처럼, 원소가 여러 물질에 나뉘어 들어 있어 계수를 맞추다 꼬일 때이다.

요령

  1. 한 번만 나오는 원소부터
    반응물과 생성물에 각각 한 물질에만 들어 있는 원소(C, H)를 먼저 맞춘다.
  2. 탄소 → 이산화 탄소
    연료의 C 수만큼 \(\mathrm{CO_2}\)의 계수를 둔다.
  3. 수소 → 물
    연료의 H 수의 절반만큼 \(\mathrm{H_2O}\)의 계수를 둔다.
  4. 산소는 마지막에
    오른쪽 O 원자를 모두 세고, \(\mathrm{O_2}\) 계수를 그 절반으로 둔다. 분수가 나오면 전체에 2를 곱한다.
  5. 원자 수로 검산
    원소마다 양쪽 원자 수를 세어 같은지 확인한다.

흔한 실수

  • 아래 첨자를 바꿔서 맞추는 것. \(\mathrm{H_2O}\)를 \(\mathrm{H_2O_2}\)로 바꾸면 다른 물질이 된다.
  • 연료 안에 든 산소(알코올의 O)를 빠뜨리고 \(\mathrm{O_2}\) 계수를 정하는 것.

바로 풀어보기

뷰테인 \(\mathrm{C_4H_{10}}\)이 완전 연소하는 반응식을 맞춰라.

답과 풀이

답: \(\mathrm{2C_4H_{10} + 13O_2 \to 8CO_2 + 10H_2O}\)

C 4개 → \(\mathrm{4CO_2}\), H 10개 → \(\mathrm{5H_2O}\)이다. 오른쪽 O는 \(8 + 5 = 13\)개이므로 \(\mathrm{\tfrac{13}{2}O_2}\)이다.

분수를 없애려고 2를 곱하면 \(\mathrm{2C_4H_{10} + 13O_2 \to 8CO_2 + 10H_2O}\)이다. 검산: C 8 = 8, H 20 = 20, O 26 = 16 + 10.

이 요령으로 풀리는 문제

  • 화학량론 단원 연습 2번
영상 콘티 · 40초
  1. 0~5초\(\mathrm{C_4H_{10} + O_2 \to CO_2 + H_2O}\)가 나타나고 계수 자리가 빈칸이다.계수, 어디부터 맞출까?
  2. 5~12초뷰테인 분자 모형에서 탄소 공 4개가 떨어져 나와 오른쪽 \(\mathrm{CO_2}\) 쪽으로 날아가고 계수 4가 채워진다.탄소부터 맞춘다.
  3. 12~19초수소 공 10개가 둘씩 짝지어 \(\mathrm{H_2O}\) 다섯 개로 들어가고 계수 5가 채워진다.다음은 수소.
  4. 19~28초오른쪽의 산소 원자 13개가 반짝이며 세어지고, 왼쪽 \(\mathrm{O_2}\) 칸에 \(\frac{13}{2}\)이 들어간다.산소는 마지막에 센다.
  5. 28~35초분수 \(\frac{13}{2}\)이 흔들리다 모든 계수에 ×2가 곱해져 2, 13, 8, 10이 된다.분수가 나오면 전체에 2를 곱한다.
  6. 35~40초원소마다 양쪽 개수 표가 나타나 모두 체크 표시가 된다.원자 수로 검산한다.
