원소 분석 자료는 100 g으로 놓고, 몰수를 가장 작은 값으로 나눈 뒤 소수 부분을 본다

요령 · 실험식

언제 쓰는가

질량 백분율이나 연소 분석 결과로 실험식과 분자식을 구하는 문제입니다.

요령

  1. 100 g으로 놓는다
    백분율을 그대로 그램으로 읽습니다. C 81.8%면 C 81.8 g입니다.
  2. 몰수로 바꾼다
    원소마다 원자량으로 나눕니다.
  3. 가장 작은 값으로 나눈다
    모든 몰수를 가장 작은 몰수로 나누어 비를 만듭니다.
  4. 소수 부분을 본다
    1.5 근처면 ×2, 1.33이나 1.67 근처면 ×3, 1.25 근처면 ×4를 해서 정수로 만듭니다. 0.1 이상 벗어난 값을 함부로 반올림하지 않습니다.
  5. 분자식은 몰질량 비로
    분자식 = 실험식 \(\times\frac{\text{몰질량}}{\text{실험식량}}\)입니다.

흔한 실수

  • 2.67 같은 비를 3으로 반올림하는 것. 정수에 가깝지 않으면 정수배를 곱해야 합니다.
  • 백분율끼리 바로 비를 내는 것. 질량비는 원자 수의 비가 아닙니다.

바로 풀어보기

어떤 탄화수소는 질량으로 C 81.8%, H 18.2%이고 몰질량은 44 g/mol입니다. 실험식과 분자식을 구하세요.

답과 풀이

답: 실험식 \(\mathrm{C_3H_8}\), 분자식 \(\mathrm{C_3H_8}\)

C \(\frac{81.8}{12.01} = 6.81\) mol, H \(\frac{18.2}{1.008} = 18.06\) mol입니다. 작은 값으로 나누면 C : H = 1 : 2.65입니다.

2.65는 \(2\frac23\)에 가까우므로 3을 곱해 3 : 7.95, 곧 3 : 8입니다. 실험식량 44.1이 몰질량과 같으므로 분자식도 \(\mathrm{C_3H_8}\)(프로페인)입니다. 2.65를 3으로 반올림했다면 \(\mathrm{CH_3}\)라는 있을 수 없는 답이 나옵니다.

이 요령으로 풀리는 문제

  • 화학량론 단원 연습 5번
영상 콘티 · 45초
  1. 0~5초원그래프 C 81.8%, H 18.2%가 나타납니다.이 화합물의 화학식은?
  2. 5~12초원그래프가 저울 위 그램 추 81.8 g과 18.2 g으로 바뀝니다.100 g으로 놓고 그램으로 읽습니다.
  3. 12~20초각 추가 원자량 크기의 상자로 나뉘어 개수 6.81과 18.06이 표시됩니다.원자량으로 나눠 몰수로.
  4. 20~29초두 수를 6.81로 나누자 1과 2.65가 됩니다. 2.65 옆 눈금자에 2.67(\(2\frac23\)) 눈금이 빛납니다.가장 작은 값으로 나누고 소수 부분을 봅니다.
  5. 29~37초×3이 곱해져 3과 7.95, 곧 \(\mathrm{C_3H_8}\)이 만들어지고 프로페인 분자 모형이 조립됩니다.정수가 되도록 정수배를 곱합니다.
  6. 37~45초2.65를 3으로 반올림한 \(\mathrm{CH_3}\) 모형이 조립되다가 결합이 남아 무너집니다.함부로 반올림하면 틀립니다.
