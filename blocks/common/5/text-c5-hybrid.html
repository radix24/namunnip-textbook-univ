혼성 오비탈과 시그마·파이 결합

본문
이 절에서 배울 것
  • 전자 영역 수로 혼성(sp, sp², sp³)을 정한다.
  • 단일·이중·삼중 결합을 시그마 결합과 파이 결합으로 나눈다.
먼저 알아야 할 것
  • 오비탈 모양 (6.3절), VSEPR (9.1절).

9.3.1혼성 오비탈

탄소의 원자가 오비탈은 2s 하나와 2p 셋이지만, 메테인의 네 C–H 결합은 모두 같고 109.5°를 이룹니다. 원자가 결합 이론에서는 s와 p 오비탈이 섞여 같은 모양의 혼성 오비탈이 된다고 설명합니다. 혼성 오비탈의 수 = 섞인 오비탈의 수 = 전자 영역 수입니다.

전자 영역혼성배치예
2sp직선\(\text{C}_2\text{H}_2\), \(\text{CO}_2\)의 C
3sp²평면 삼각형\(\text{C}_2\text{H}_4\), \(\text{BF}_3\)
4sp³사면체\(\text{CH}_4\), \(\text{NH}_3\), \(\text{H}_2\text{O}\)

9.3.2시그마와 파이 결합

  • 시그마(σ) 결합: 두 원자핵을 잇는 축 위에서 오비탈이 정면으로 겹친다. 모든 단일 결합.
  • 파이(π) 결합: 혼성에 참여하지 않은 p 오비탈이 옆으로 나란히 겹친다. 축의 위아래에 전자 밀도.
  • 이중 결합 = σ 1 + π 1, 삼중 결합 = σ 1 + π 2.

π 결합은 옆으로 겹쳐 있어 결합 축을 중심으로 돌리면 끊어집니다. 그래서 C=C 결합은 자유롭게 회전하지 못하고, 시스와 트랜스 이성질체가 생깁니다.

예제 9.3.1

아크릴로나이트릴 \(\text{CH}_2\text{=CH–C≡N}\)의 σ 결합과 π 결합 수, 각 탄소의 혼성은?

풀이. C–H 3, C=C 1(σ)+1(π), C–C 1, C≡N 1(σ)+2(π). σ 6개, π 3개. 혼성은 차례로 sp², sp², sp.

요약
  1. 전자 영역 2, 3, 4 → sp, sp², sp³.
  2. 단일 = σ, 이중 = σ + π, 삼중 = σ + 2π. π 결합은 회전을 막는다.
