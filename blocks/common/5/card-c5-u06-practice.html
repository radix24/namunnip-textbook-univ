원자의 전자 구조 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산수소 원자의 전자가 \(n = 4\)에서 \(n = 2\)로 떨어질 때 내는 빛의 파장을 구하세요. (\(E_n = -2.18\times10^{-18}\ \text{J}/n^2\), \(h = 6.626\times10^{-34}\) J·s, \(c = 2.998\times10^8\) m/s) [06-01]

    힌트 1

    내놓는 빛의 에너지는 두 준위의 에너지 차입니다.

    힌트 2

    \(\Delta E = 2.18\times10^{-18}\left(\tfrac14 - \tfrac1{16}\right)\), \(\lambda = hc/\Delta E\).

    풀이

    \(\Delta E = 2.18\times10^{-18} \times 0.1875 = 4.09\times10^{-19}\) J. \(\lambda = \dfrac{6.626\times10^{-34}\times2.998\times10^8}{4.09\times10^{-19}} = 4.86\times10^{-7}\) m = 486 nm. 청록색 빛으로, 발머 계열의 둘째 선입니다(6.1절 실습 참고).

  2. 계산파장 500 nm인 빛의 광자 하나의 에너지와, 이 광자 1 mol의 에너지(kJ/mol)를 구하세요. [06-01]

    힌트 1

    \(E = hc/\lambda\). 1 mol은 아보가드로수만큼의 광자입니다.

    힌트 2

    \(\lambda = 5.00\times10^{-7}\) m.

    풀이

    \(E = \dfrac{6.626\times10^{-34}\times2.998\times10^8}{5.00\times10^{-7}} = 3.97\times10^{-19}\) J. 1 mol이면 \(3.97\times10^{-19}\times6.022\times10^{23} = 2.39\times10^5\) J = 239 kJ/mol입니다. 화학 결합 에너지(수백 kJ/mol)와 비슷한 크기라서, 가시광선과 자외선이 분자를 들뜨게 하거나 결합을 끊을 수 있습니다.

  3. 개념\(n = 3\)일 때 가능한 \(l\)과 \(m_l\)을 모두 쓰고, 오비탈 수와 전자 수를 구하세요. 또 \((n, l, m_l, m_s) = (2, 2, 0, +\tfrac12)\), \((3, 1, -1, -\tfrac12)\), \((4, 0, 1, +\tfrac12)\) 가운데 가능한 것을 고르세요. [06-02]

    힌트 1

    \(l = 0, 1, \ldots, n - 1\), \(m_l = -l, \ldots, +l\), \(m_s = \pm\tfrac12\).

    힌트 2

    \(n = 3\)이면 \(l = 0, 1, 2\)이고, 각각 오비탈이 1, 3, 5개입니다.

    풀이

    \(l = 0\)(\(m_l = 0\)), \(l = 1\)(\(m_l = -1, 0, 1\)), \(l = 2\)(\(m_l = -2, \ldots, 2\)). 오비탈은 \(1 + 3 + 5 = 9 = n^2\)개, 전자는 18개입니다.

    \((2, 2, 0, +\tfrac12)\)은 \(l < n\)을 어겨 불가능, \((3, 1, -1, -\tfrac12)\)은 3p 오비탈의 전자로 가능, \((4, 0, 1, +\tfrac12)\)은 \(l = 0\)인데 \(m_l = 1\)이라 불가능합니다.

  4. 계산길이 0.50 nm인 상자에 갇힌 전자의 가장 낮은 에너지를 eV로 구하세요. 상자 길이를 두 배로 하면 어떻게 되나요? (\(m_e = 9.109\times10^{-31}\) kg, 1 eV = \(1.602\times10^{-19}\) J) [06-05]

    힌트 1

    \(E_n = \dfrac{n^2h^2}{8mL^2}\)에 \(n = 1\)을 넣습니다.

    힌트 2

    \(L\)이 분모에 제곱으로 들어갑니다.

    풀이

    \(E_1 = \dfrac{(6.626\times10^{-34})^2}{8\times9.109\times10^{-31}\times(5.0\times10^{-10})^2} = 2.41\times10^{-19}\) J = 1.50 eV입니다. 상자를 두 배로 늘리면 \(E_1\)은 4분의 1인 0.376 eV가 됩니다. 갇힌 공간이 좁을수록 에너지가 커지고 준위 간격도 넓어집니다(6.5절).

  5. 계산Fe, \(\mathrm{Fe^{3+}}\), Cu, \(\mathrm{S^{2-}}\)의 바닥 상태 전자 배치를 쓰세요. [06-04]

    힌트 1

    쌓음 원리(1s, 2s, 2p, 3s, 3p, 4s, 3d …)로 채우고, 3d가 절반이나 꽉 찬 경우를 조심합니다.

    힌트 2

    전이 금속이 양이온이 될 때는 4s 전자가 먼저 빠집니다. 구리는 \(3d^{10}4s^1\)이 더 안정합니다.

    풀이

    Fe: \(\mathrm{[Ar]}3d^64s^2\). \(\mathrm{Fe^{3+}}\): \(\mathrm{[Ar]}3d^5\) (4s 2개와 3d 1개를 뺌). Cu: \(\mathrm{[Ar]}3d^{10}4s^1\) (예외). \(\mathrm{S^{2-}}\): \(\mathrm{[Ne]}3s^23p^6\) = \(\mathrm{[Ar]}\)과 같은 배치.

  6. 판단“4s가 3d보다 먼저 채워지므로, Fe가 \(\mathrm{Fe^{2+}}\)가 될 때는 나중에 들어간 3d에서 전자 2개를 뺀다.” 판단하세요. 2p 오비탈과 3s 오비탈의 마디 수도 함께 말하세요. [06-03]

    힌트 1

    이온의 실험 결과(자성, 분광)는 \(\mathrm{Fe^{2+}}\)를 \(3d^6\)으로 보여 줍니다.

    힌트 2

    마디의 총수는 \(n - 1\), 그 가운데 각 마디가 \(l\)개입니다.

    풀이

    틀렸습니다. 채우는 순서와 빼는 순서는 다릅니다. 3d가 채워지면 4s의 에너지가 3d보다 높아지므로 4s 전자가 먼저 빠져 \(\mathrm{Fe^{2+}}\)는 \(\mathrm{[Ar]}3d^6\)입니다.

    마디: 2p는 \(n - 1 = 1\)개(각 마디 1, 구형 마디 0), 3s는 2개(모두 구형 마디)입니다.
