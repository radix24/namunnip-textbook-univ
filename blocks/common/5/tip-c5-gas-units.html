이상 기체 계산은 \(R\)의 단위를 먼저 고르고, 모든 값을 그 단위로 바꾼 뒤 넣는다

요령 · 이상 기체 방정식

언제 쓰는가

\(PV = nRT\)로 압력, 부피, 몰수, 몰질량, 밀도를 구하는 문제이다. torr, mL, °C처럼 단위가 섞여 있을 때 쓴다.

요령

  1. \(R\)을 고른다
    \(0.08206\ \text{L·atm/(mol·K)}\)이면 L, atm, K로, \(8.314\ \text{J/(mol·K)}\)이면 m³, Pa, K로 맞춘다.
  2. 온도는 언제나 켈빈
    \(T(\text K) = t(^\circ\text C) + 273.15\).
  3. 압력·부피 환산
    \(760\ \text{torr} = 1\ \text{atm} = 101.3\ \text{kPa}\), \(1000\ \text{mL} = 1\ \text L\).
  4. 몰질량·밀도는 \(n = \frac mM\)
    \(PV = \frac mMRT\)에서 \(M = \frac{mRT}{PV}\), 밀도는 \(\frac{PM}{RT}\)이다.

흔한 실수

  • 섭씨온도를 그대로 넣는 것. 0 °C에서는 부피가 0이 되어 버린다.
  • \(R = 8.314\)를 쓰면서 L와 atm을 넣는 것.

바로 풀어보기

어떤 기체 1.42 g이 25 °C, 750 torr에서 0.800 L를 차지한다. 몰질량을 구하고 어떤 기체일지 짐작하여라.

답과 풀이

답: 약 44.0 g/mol (\(\mathrm{CO_2}\) 또는 \(\mathrm{N_2O}\), \(\mathrm{C_3H_8}\))

\(R = 0.08206\)을 고르면 \(P = \frac{750}{760} = 0.987\ \text{atm}\), \(T = 298.15\ \text K\), \(V = 0.800\ \text L\)이다. \(n = \frac{PV}{RT} = \frac{0.987\times0.800}{0.08206\times298.15} \approx 0.0323\ \text{mol}\)이다.

\(M = \frac{1.42}{0.0323} \approx 44.0\ \text{g/mol}\)이므로 \(\mathrm{CO_2}\) 같은 기체이다.

이 요령으로 풀리는 문제

  • 기체 단원 연습 1번, 2번, 3번
영상 콘티 · 40초
  1. 0~5초\(PV = nRT\) 옆에 750 torr, 0.800 L, 25 °C가 뒤섞여 떠 있다.단위가 뒤섞이면 어떻게 넣을까?
  2. 5~12초\(R\) 자리에 두 장의 카드 0.08206(L·atm)과 8.314(J)가 나타나고, 첫 카드가 선택되어 'L · atm · K' 문이 열린다.\(R\)부터 고른다.
  3. 12~22초750 torr가 문을 통과하며 0.987 atm으로, 25 °C가 298.15 K로 바뀐다. 0.800 L은 그대로 통과한다.모든 값을 \(R\)의 단위로 바꾼다.
  4. 22~31초바뀐 값들이 식에 들어가 \(n = 0.0323\) mol이 나오고, 1.42 g을 나누어 44.0 g/mol이 나온다.질량을 몰수로 나누면 몰질량.
  5. 31~40초25 °C를 그대로 넣은 계산이 엉뚱한 값을 내고, 0 °C를 넣자 부피가 0이 되는 그래프와 함께 X가 그어진다.온도는 언제나 켈빈이다.
