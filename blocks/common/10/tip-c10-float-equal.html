실수는 ==로 비교하지 않고 허용 오차 안에 있는지로 비교한다

요령 · 실수 비교

언제 쓰는가

계산한 실수가 어떤 값과 같은지 검사하는 if 문, 실수가 목표값이 될 때까지 도는 while 문을 쓸 때입니다.

요령

  1. 이진수로는 정확하지 않다
    0.1, 0.2 같은 값은 2진수로 정확히 나타낼 수 없어 아주 작은 오차가 들어 있습니다.
  2. 차이로 비교
    abs(a - b) < 1e-9 또는 math.isclose(a, b)를 씁니다. 값이 크면 상대 오차로 비교합니다.
  3. 반복은 정수로 센다
    x += 0.1을 x != 1.0까지 반복하지 말고, 정수 i로 반복 횟수를 세고 x = i * 0.1로 계산합니다.
  4. 출력은 자릿수를 정해서
    f"{x:.2f}"처럼 필요한 자릿수만 보여 주면 오차가 눈에 띄지 않습니다. 비교는 출력값이 아니라 위 방법으로 합니다.

흔한 실수

  • 0.1 + 0.2 == 0.3이 False라서 '파이썬이 고장 났다'고 보는 것.
  • while x != 1.0:이 영원히 끝나지 않는 것.

바로 풀어보기

x = 0.0에서 시작해 while x != 1.0: x += 0.1을 실행하면 어떻게 되나요? 0.0, 0.1, …, 1.0을 정확히 11개 출력하도록 고치세요.

답과 풀이

답: \(x\)가 1.0을 정확히 만나지 못해(0.9999999999999999 다음 1.0999…) 끝없이 돕니다. 정수로 셉니다.

0.1을 10번 더한 값은 0.9999999999999999라서 != 조건이 계속 참이고, 다음 값에서 1.0을 건너뜁니다.

for i in range(11):
    x = i * 0.1
    print(f"{x:.1f}")

정수 i가 반복 횟수를 정확히 세므로 반복은 11번에서 끝납니다.

이 요령으로 풀리는 문제

  • 파이썬 시작하기 단원 연습 6번
  • 컴퓨터의 자료 표현과 과학 계산 단원 연습 3번, 6번
영상 콘티 · 40초
  1. 0~5초0.1 + 0.2 == 0.3이 실행되고 False가 뜹니다.파이썬이 틀렸을까요?
  2. 5~13초0.1이 2진수로 펼쳐지며 0.000110011001100…이 끝없이 반복되다 잘립니다.0.1은 2진수로 정확히 쓸 수 없습니다.
  3. 13~21초수직선을 확대하자 0.30000000000000004와 0.3이 아주 가까이 있지만 다른 점으로 보입니다.아주 작은 차이가 남습니다.
  4. 21~30초두 점 사이에 폭 \(10^{-9}\)짜리 허용 범위 상자가 놓이고 두 점이 그 안에 들어가 체크가 뜹니다.차이가 충분히 작은지로 비교합니다.
  5. 30~40초while x != 1.0 루프의 점이 1.0을 훌쩍 건너뛰어 계속 달아나고, 정수 카운터 루프는 11번째에서 멈춥니다.반복은 정수로 셉니다.
