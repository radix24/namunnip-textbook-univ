파이썬으로 숫자와 문자열 다루기

본문

계산기로 \(\frac12gt^2\)을 구할 때는 숫자를 하나하나 다시 눌러야 한다. 그런데 시간 \(t\)만 바꿔 같은 계산을 백 번 해야 한다면? 컴퓨터에게 계산 순서를 글로 적어 맡기면 되는데, 그 글에서 \(g\)와 \(t\) 같은 이름은 어떻게 값을 기억하고, x = x + 1처럼 수학에서는 말이 안 되는 식은 무엇을 뜻할까?

먼저 알아야 할 것없다. 컴퓨터에 파이썬을 설치하거나 웹에서 실행할 수 있는 환경만 있으면 된다.

1.1.1프로그램과 파이썬

프로그램은 컴퓨터가 차례로 실행할 명령을 적은 글이다. 컴퓨터가 직접 이해하는 것은 0과 1로 된 기계어뿐이라, 사람이 읽기 쉬운 언어로 쓴 뒤 번역해서 실행한다. 파이썬은 한 줄씩 읽어 바로 실행하는 인터프리터 방식이고, 4단원의 C는 전체를 미리 기계어로 바꾸는 컴파일러 방식이다.

파이썬을 설치하면 함께 오는 IDLE이나 VS Code 같은 편집기에서 파일(.py)을 만들어 실행한다. 첫 프로그램은 화면에 글자를 내보내는 것이다.

print("Hello, world!")
print(3 + 4)          # 7
print("3" + "4")      # 34  (문자열은 이어 붙인다)

여기서 # 뒤는 주석이라 실행되지 않는다.

1.1.2자료형

값에는 종류, 곧 자료형이 있다. 7, -3 같은 정수는 int이며, 파이썬의 정수는 아무리 커도 정확하다. 3.14, 2e-3(= 0.002) 같은 실수는 float이며, 유효숫자가 약 16자리로 제한된다(6.1절). 따옴표로 감싼 글자들 "화학", 'H2O'는 문자열 str이다. 그리고 True와 False는 불 bool이다(1.2절). 값의 자료형은 type(값)으로 확인할 수 있다.

1.1.3연산자와 변수

연산자뜻예결과
+ - *더하기, 빼기, 곱하기2 * 36
/나누기 (결과는 늘 실수)7 / 23.5
//몫7 // 23
%나머지7 % 21
**거듭제곱2 ** 101024

변수는 값에 붙이는 이름이다. 처음 질문의 답이 여기 있다. =는 "같다"가 아니라 "오른쪽 값을 계산해 왼쪽 이름에 넣는다(대입)"는 뜻이다. 그래서 x = x + 1처럼 쓸 수 있으며, x += 1로 줄여 쓴다. 그림 1에서 넷째 줄 t = t + 1을 실행하면 상자 t의 3이 4로 바뀐다.

g = 9.8           # 중력 가속도 (m/s^2)
t = 3
h = 0.5 * g * t ** 2
print("떨어진 거리:", h, "m")      # 떨어진 거리: 44.1 m
print(f"떨어진 거리: {h:.1f} m")   # f-문자열로 소수 첫째 자리까지

거듭제곱은 곱하기보다 먼저 계산한다. 헷갈리면 괄호를 쓴다.

1.1.4문자열 다루기와 입력

문자열에는 쓸모 있는 도구가 많다. len(s)는 길이이다. s[0]은 첫 글자(번호는 0부터), s[-1]은 마지막 글자, s[1:3]은 1번부터 3번 앞까지이다(2.1절). 또 s.upper(), s.replace("a", "b"), s.split()은 각각 대문자로 바꾸기, 바꿔 넣기, 쪼개기이다.

한편 input()은 키보드로 입력한 내용을 언제나 문자열로 돌려준다. 그러므로 계산하려면 int()나 float()로 바꿔야 한다.

r = float(input("반지름(cm)? "))
area = 3.14159 * r ** 2
print(f"넓이 {area:.2f} cm^2")
흔한 오해input()으로 받은 값을 숫자로 여기고 그대로 더하기 쉽다. 하지만 "3" + "4"처럼 이어 붙어 "34"가 된다. 또 문자열과 숫자를 +로 더하면 TypeError가 난다.
마무리

파이썬의 기본 자료형은 int, float, str, bool이며, /는 실수 나누기, //는 몫, %는 나머지, **는 거듭제곱이다. 처음 질문의 =는 오른쪽을 계산해 이름에 넣는 대입이고, input()은 문자열을 돌려주므로 int()나 float()로 바꿔 쓴다.
