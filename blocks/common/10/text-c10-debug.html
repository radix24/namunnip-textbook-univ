오류 메시지 읽고 고치기

본문
이 절에서 배울 것
  • 문법 오류, 실행 오류, 논리 오류를 구별한다.
  • 오류 메시지(Traceback)에서 오류의 종류와 줄 번호를 찾는다.
  • 중간값을 출력해 논리 오류가 생긴 곳을 좁힌다.
먼저 알아야 할 것
  • 변수와 연산자, input (1.1절), if 문 (1.2절).

1.3.1오류의 세 종류

처음 쓴 프로그램이 한 번에 맞게 돌아가는 일은 드뭅니다. 프로그램의 잘못을 찾아 고치는 일을 디버깅이라 합니다. 오류는 언제 드러나느냐에 따라 세 가지로 나눕니다.

문법 오류: 파이썬 문법에 맞지 않아 프로그램이 아예 시작하지 못합니다. 괄호를 닫지 않거나, 들여쓰기가 어긋나거나, if 끝의 :을 빠뜨린 경우입니다. 메시지 이름은 SyntaxError, IndentationError입니다.

실행 오류: 문법은 맞지만 실행하는 도중에 할 수 없는 일을 만나 멈춥니다. 없는 변수 이름(NameError), 맞지 않는 자료형끼리의 계산(TypeError), 0으로 나누기(ZeroDivisionError), 숫자로 바꿀 수 없는 문자열(ValueError), 리스트 범위를 벗어난 번호(IndexError)가 대표적입니다.

논리 오류: 멈추지 않고 끝까지 돌지만 답이 틀립니다. 메시지가 없으므로 가장 찾기 어렵습니다.

1.3.2오류 메시지 읽기

실행 오류가 나면 파이썬은 Traceback을 출력합니다. 아래에서 위로 읽습니다.

  • 맨 아래 줄: 오류의 종류와 설명. 여기부터 봅니다.
  • 그 위: 오류가 난 파일과 줄 번호, 그 줄의 코드. 파이썬 3.11부터는 ^ 표시로 문제가 된 부분까지 가리킵니다.
  • 함수 안에서 오류가 나면 함수를 부른 줄들이 위로 쌓여 나옵니다. 내가 쓴 코드 중 가장 아래 줄이 먼저 볼 곳입니다.
예제 1.3.1

원의 넓이를 구하는 아래 프로그램에 반지름 2를 입력했더니 오류가 났습니다. 메시지를 읽고 고치세요.

r = input("반지름: ")
area = 3.14159 * r ** 2
print(area)
Traceback (most recent call last):
  File "circle.py", line 2, in <module>
    area = 3.14159 * r ** 2
                     ~~^^~~
TypeError: unsupported operand type(s) for ** or pow(): 'str' and 'int'

풀이. 맨 아래 줄은 "** 연산을 문자열(str)과 정수(int) 사이에 할 수 없다"는 뜻입니다. 줄 번호는 2이고, ^가 r ** 2를 가리킵니다. input은 입력을 언제나 문자열로 돌려주므로 r은 숫자 2가 아니라 글자 "2"입니다. 첫 줄을 r = float(input("반지름: "))으로 고치면 12.56636이 출력됩니다.

문법 오류는 Traceback 없이 위치만 알려 줍니다. print("합"처럼 괄호를 닫지 않으면 SyntaxError: '(' was never closed가 나옵니다. 문법 오류의 줄 번호는 파이썬이 "더 이상 읽을 수 없다"고 판단한 곳이라, 실제 실수는 그보다 한두 줄 위에 있는 경우가 많습니다.

1.3.3논리 오류 찾기

논리 오류에는 두 가지 방법을 함께 씁니다.

  • 손으로 답을 아는 작은 입력으로 돌려 본다. 1부터 10까지의 합은 55처럼, 답을 미리 아는 경우로 확인합니다.
  • 중간값을 출력한다. 의심 가는 곳에 print를 넣어 변수가 예상대로 변하는지 봅니다. 고친 뒤에는 지웁니다.
예제 1.3.2

1부터 n까지의 합을 구하려고 쓴 프로그램이 n = 10에서 55가 아니라 45를 출력합니다. 중간값을 출력해 원인을 찾으세요.

n = 10
s = 0
for i in range(1, n):
    s += i
print(s)   # 45

풀이. 반복 안에 print(i, s)를 넣으면 마지막 줄이 9 45입니다. i가 10까지 가지 않고 9에서 끝났습니다. range(1, n)은 끝값 n을 포함하지 않기 때문입니다(2.3절). range(1, n + 1)로 고치면 55가 나옵니다. 차이 45와 55는 마지막 항 하나(10)만큼이므로, "마지막 항이 빠졌다"는 짐작을 바로 할 수 있습니다. 답과 틀린 값의 차이를 보는 것도 좋은 단서입니다.

요약
  1. 문법 오류는 시작 전, 실행 오류는 실행 중 멈춤, 논리 오류는 멈추지 않고 틀린 답.
  2. Traceback은 맨 아래 줄(종류와 설명) → 줄 번호 순서로 읽는다.
  3. 논리 오류는 답을 아는 작은 입력과 중간값 출력으로 좁힌다.

1.3.4연습문제

기본

  1. int("3.5")를 실행하면 어떤 종류의 오류가 나나요? 3.5를 정수 3으로 바꾸려면 어떻게 쓰나요?
    답

    ValueError: invalid literal for int() with base 10: '3.5'. 소수점이 있는 문자열은 int가 바로 바꾸지 못합니다. int(float("3.5"))로 쓰면 3입니다(소수 부분은 버림).

  2. 다음 코드가 내는 오류의 종류를 말하세요. scores = [90, 85, 77] 다음 줄에 print(scores[3]).
    답

    IndexError: list index out of range. 원소가 3개이면 번호는 0, 1, 2뿐입니다.
