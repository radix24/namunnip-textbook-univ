반복문의 결과는 변수마다 한 열씩 만든 추적 표로 손으로 따라간다

요령 · 반복문 추적

언제 쓰는가

반복문이나 중첩 반복문의 출력을 실행하지 않고 예측하는 문제, 무한 반복이나 한 번 모자라는 반복의 원인을 찾을 때입니다.

요령

  1. 열을 만든다
    반복 조건에 쓰이는 변수와 바뀌는 변수마다 한 열을 둡니다.
  2. 조건부터 검사
    한 줄 내려갈 때마다 먼저 조건을 확인하고, 참이면 몸체를 순서대로 실행해 값을 갱신합니다.
  3. 순서가 중요
    s += i와 i *= 3의 순서가 바뀌면 결과가 달라집니다. 한 줄씩 그대로 따릅니다.
  4. 끝난 뒤의 값
    조건이 거짓이 되는 순간의 값까지 표에 적어, 반복이 끝난 뒤 변수의 값을 확인합니다.

흔한 실수

  • range(1, 4)에 4가 들어간다고 보는 것.
  • 조건을 마지막에 한 번 더 확인하지 않아 반복 횟수를 하나 틀리는 것.

바로 풀어보기

s = 0; i = 1에서 while i < 20: s += i; i *= 3을 실행한 뒤 s와 i의 값을 구하세요.

답과 풀이

답: s = 13, i = 27

표: (i, s) = (1, 0) → 조건 참, s = 1, i = 3 → 참, s = 4, i = 9 → 참, s = 13, i = 27 → 조건 거짓, 끝.

반복은 3번이고, 끝난 뒤 i는 조건을 처음 깨뜨린 27입니다.

이 요령으로 풀리는 문제

  • 파이썬 자료 구조와 반복 단원 연습 4번, 5번
  • 파이썬 함수, 파일, 모듈, 클래스 단원 연습 2번
영상 콘티 · 40초
  1. 0~5초코드 세 줄과 빈 표(열: 조건, i, s)가 나타납니다.실행하지 않고 결과를 맞혀 봅시다.
  2. 5~13초첫 줄에 i = 1, s = 0이 적히고, 조건 칸에 '1 < 20 참'이 체크됩니다.조건부터 확인합니다.
  3. 13~23초코드의 커서가 s += i, i *= 3을 차례로 지나며 표에 1, 3이 적히고, 같은 과정이 반복되어 4·9, 13·27이 쌓입니다.한 줄씩 순서대로 갱신합니다.
  4. 23~32초마지막 줄의 조건 칸에 '27 < 20 거짓'이 빨갛게 표시되고 반복이 멈춥니다.조건이 깨지는 순간까지 적습니다.
  5. 32~40초두 줄의 순서를 바꾼 코드로 표가 다시 채워져 다른 결과가 나옵니다.순서가 바뀌면 답도 바뀝니다.
