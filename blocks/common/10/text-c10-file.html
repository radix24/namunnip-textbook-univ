파일 읽고 쓰기

본문

실험 장비가 측정값을 수백 줄짜리 텍스트 파일로 내놓았다. 숫자를 손으로 옮겨 적을 수는 없다. 파일을 열어 한 줄씩 읽고, 주석이나 빈 줄은 건너뛰며, 숫자만 골라 계산하려면 어떻게 할까? 그리고 계산 결과는 어떻게 다시 파일로 남길까?

먼저 알아야 할 것문자열의 split(1.1절)과 반복문(2.3절)을 쓴다.

3.2.1파일 열기

파일은 open(파일이름, 모드)로 열고, 다 쓰면 닫아야 한다. 그런데 with를 쓰면 묶음이 끝날 때 자동으로 닫힌다. 모드는 셋이다. "r"은 읽기이며 기본값이다. "w"는 쓰기인데, 같은 이름 파일이 있으면 내용을 지우고 새로 쓴다. "a"는 끝에 덧붙이기이다. 그리고 한글이 들어 있으면 encoding="utf-8"을 함께 적어 두는 것이 안전하다.

3.2.2읽기

파일 data.txt에 시간(s)과 온도(°C)가 한 줄에 하나씩, 공백으로 나뉘어 있다고 하자.

# data.txt
# t  T
0   20.1
30  24.8
60  29.2
90  33.0

처음 질문의 방법은 이렇다. 줄마다 strip()으로 앞뒤 공백과 줄바꿈을 지우고, 빈 줄과 주석은 continue로 건너뛴다. 그다음 split()으로 나누고 float()로 바꿔 리스트에 넣는다.

ts, Ts = [], []
with open("data.txt", encoding="utf-8") as f:
    for line in f:                 # 한 줄씩 (끝에 줄바꿈 문자 포함)
        line = line.strip()        # 앞뒤 공백, 줄바꿈 지우기
        if not line or line.startswith("#"):
            continue               # 빈 줄과 주석 건너뛰기
        t, T = line.split()
        ts.append(float(t))
        Ts.append(float(T))
rate = (Ts[-1] - Ts[0]) / (ts[-1] - ts[0])
print(f"평균 가열 속도 {rate:.4f} °C/s")   # 0.1433

그림 1에서 줄을 하나씩 읽어 보면 두 리스트가 차례로 채워지고, 마지막에 가열 속도 0.1433 °C/s가 나온다. 한편 쉼표로 나뉜 CSV 파일이면 line.split(",")을 쓰거나 표준 모듈 csv를 쓴다(3.3절).

3.2.3쓰기와 오류 처리

결과를 파일로 남길 때는 쓰기 모드로 열고 write를 쓴다. 이때 write는 줄바꿈을 자동으로 넣지 않으므로 직접 넣어야 한다.

with open("result.txt", "w", encoding="utf-8") as f:
    for t, T in zip(ts, Ts):
        f.write(f"{t:6.1f} {T:6.2f}\n")   # write는 줄바꿈을 직접 넣어야 한다

그런데 파일이 없으면 FileNotFoundError가 나고, 숫자가 아닌 글자를 float()로 바꾸면 ValueError가 난다. 그러므로 프로그램이 멈추지 않게 하려면 다음처럼 감싼다(3.4절).

try:
    f = open("data.txt", encoding="utf-8")
except FileNotFoundError:
    print("파일이 없습니다")
마무리

파일은 with open(이름, 모드, encoding="utf-8") as f:로 열며, 모드는 r, w(덮어씀), a이다. 처음 질문처럼 줄마다 strip(), split(), float() 순서로 숫자를 꺼내고, 쓸 때는 \n을 직접 넣으며, 오류는 try / except로 받는다.
