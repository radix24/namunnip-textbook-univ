재귀 호출 나무와 호출 스택

실습 · 피보나치, 메모이제이션

목표

재귀 함수 fib(n)이 자기 자신을 부르는 순서와 호출 스택이 쌓였다 풀리는 모습을 본다. 같은 값을 다시 계산하는 낭비를 메모이제이션으로 없애면 호출 수가 얼마나 줄어드는지 비교한다. 성취기준 [공통10-03-01].

준비

def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

동그라미 하나가 호출 한 번이고 안의 숫자가 \(n\)이다. 빨간 테두리는 지금 실행 중인 호출(스택 맨 위), 칠한 동그라미는 값을 돌려준 호출이다. 메모이제이션을 켜면 한 번 구한 값을 저장해 두고, 다시 부르면 계산 없이 꺼냅니다(주황).

절차

  1. \(n = 5\)에서 재생하고, 호출 스택이 가장 깊어질 때 몇 층인지 본다.
  2. \(n\)을 1부터 8까지 바꾸며 전체 호출 수를 적는다.
  3. 메모이제이션을 켜고 같은 일을 한다.

기대 결과

  • \(n = 5\)에서 스택은 fib(5) → fib(4) → fib(3) → fib(2) → fib(1)까지 5층. 전체 호출 15번.
  • 호출 수는 1, 3, 5, 9, 15, 25, 41, 67로 피보나치 수처럼(약 1.6배씩) 는다.
  • 메모이제이션을 켜면 \(2n - 1\)번(1, 3, 5, 7, ..., 15)으로 줄어든다.

분석

  1. fib(3)이 \(n = 6\)일 때 몇 번 계산되는지 그림에서 세어 보자.
  2. \(n = 40\)이면 메모이제이션 없이 호출이 약 3억 번이다. 반복문으로 쓴 fib는 몇 번 더하면 되는지 비교해 보자.
