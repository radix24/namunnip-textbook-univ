C의 배열

본문

파이썬 리스트는 원하는 만큼 늘어나고, 범위를 벗어나면 친절하게 IndexError를 낸다. 그런데 C의 배열은 크기를 처음에 정해야 하고, 범위를 벗어나도 아무 말 없이 계산을 이어 간다. 배열은 메모리에 어떻게 놓이기에 이런 차이가 생길까?

먼저 알아야 할 것파이썬 리스트(2.1절)와 C 반복문과 함수(4.2절, 4.3절)를 쓴다.

5.1.1배열 선언

C의 배열은 같은 자료형의 값을 정해진 개수만큼 메모리에 이어서 놓은 것이다. 크기는 선언할 때 정하고 바꿀 수 없으며, 이것이 파이썬 리스트와 다른 점이다.

double T[5] = {20.1, 20.6, 21.3, 22.0, 22.8};
double sum = 0;
for (int i = 0; i < 5; i++) {
    sum += T[i];
}
printf("평균 %.2f\n", sum / 5);     /* 21.36 */

인덱스는 0부터 크기−1까지이다. 그런데 처음 질문처럼 C는 T[5]나 T[-1]처럼 범위를 벗어나도 오류를 내지 않고 그 자리의 메모리를 읽거나 써 버린다. 원소가 이어진 칸에 있으므로 T[i]의 주소는 "시작 주소 + \(i\) × 칸 크기"로 바로 계산되는데, 그 계산을 \(i\)가 범위 밖이어도 그대로 하기 때문이다. 그 결과 엉뚱한 값, 다른 변수가 망가짐, 프로그램 종료가 생길 수 있으므로 반복 범위를 늘 확인해야 한다. 그림 1에서 \(i\)를 −1이나 5로 옮기면 빨간 칸을 읽는다.

5.1.2함수에 배열 넘기기

배열을 함수에 넘기면 복사되지 않고 배열의 시작 주소가 넘어간다(5.2절). 그래서 함수 안에서 배열 원소를 바꾸면 원래 배열이 바뀌고, 크기는 따로 넘겨야 한다.

double mean(const double a[], int n) {
    double s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s / n;
}

여기서 const는 이 함수가 배열을 바꾸지 않겠다는 표시이다.

5.1.3문자열과 2차원 배열

C의 문자열은 char 배열이고, 끝에 널 문자 '\0'이 붙어 끝을 표시한다. 가령 char s[] = "H2O";는 'H' '2' 'O' '\0'의 4칸이다.

한편 2차원 배열 double A[3][4];는 3행 4열의 표이고 A[i][j]로 쓴다. 메모리에는 0행, 1행, 2행 순서로 이어져 놓이며, 이것을 행 우선이라 한다. 행렬 곱셈이나 격자 위의 계산(전자계산(2) 5단원)에 쓴다.

double A[2][2] = {{1, 2}, {3, 4}}, B[2][2] = {{0, 1}, {1, 0}}, C[2][2];
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 2; j++) {
        C[i][j] = 0;
        for (int k = 0; k < 2; k++) C[i][j] += A[i][k] * B[k][j];
    }
/* C = {{2, 1}, {4, 3}} */
마무리

C 배열은 자료형 이름[크기]로 선언하며 같은 자료형을 이어진 칸에 놓고, 인덱스는 0부터 크기−1까지이다. 처음 질문처럼 범위 검사가 없으므로 반복 범위를 직접 지켜야 하고, 함수에는 주소가 넘어가므로 크기도 함께 넘긴다. 문자열은 '\0'로 끝나는 char 배열이고 2차원 배열은 행 우선이다.
