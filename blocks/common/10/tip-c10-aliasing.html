리스트를 다른 이름에 넣으면 같은 상자를 가리키므로, 바꾸기 전에 복사부터 한다

요령 · 리스트 복사

언제 쓰는가

리스트를 다른 변수에 넣거나 함수에 넘긴 뒤 바꿨더니 원래 리스트도 바뀌었을 때, 2차원 리스트를 만들 때입니다.

요령

  1. 이름표와 상자
    b = a는 상자를 복사하지 않고 같은 상자에 이름표를 하나 더 붙입니다. a is b가 True입니다.
  2. 복사는 명시적으로
    한 층이면 b = a.copy() 또는 a[:], 안에 리스트가 들어 있으면 copy.deepcopy(a)입니다.
  3. 2차원은 축약으로
    [[0]*3]*3은 같은 행 상자를 세 번 가리킵니다. [[0]*3 for _ in range(3)]로 행마다 새 상자를 만듭니다.
  4. id로 확인
    헷갈리면 id(a), id(b)를 찍어 같은 상자인지 봅니다.

흔한 실수

  • b = a로 '백업'을 만들었다고 생각하는 것.
  • 함수 기본값으로 빈 리스트를 두어 호출마다 같은 상자가 쌓이는 것.

바로 풀어보기

grid = [[0] * 3] * 3을 만든 뒤 grid[0][0] = 1을 하면 grid는 어떻게 되나요? 의도대로 한 칸만 바뀌게 고치세요.

답과 풀이

답: [[1, 0, 0], [1, 0, 0], [1, 0, 0]]. grid = [[0] * 3 for _ in range(3)]로 고칩니다.

바깥 * 3은 같은 행 리스트를 세 번 가리키므로, 한 행을 바꾸면 세 행이 모두 바뀌어 보입니다.

리스트 축약은 반복마다 [0] * 3을 새로 만들므로 행마다 다른 상자가 됩니다. grid[0] is grid[1]이 False인지 확인합니다.

  3. 14~22초b = a 장면: 새 상자는 생기지 않고 이름표만 하나 늘어납니다.대입은 복사가 아닙니다.
