C의 계산은 식 위에 자료형을 적어 가며 한 단계씩 따라간다

요령 · C의 자료형

언제 쓰는가

C에서 정수와 실수가 섞인 계산의 결과를 예측하거나, 파이썬과 다른 결과가 나온 이유를 찾을 때이다.

요령

  1. 연산마다 자료형
    두 피연산자가 모두 int면 결과도 int이다. 나눗셈은 버림이 일어난다.
  2. 대입은 마지막
    double x = a / b;는 오른쪽을 정수로 먼저 계산한 뒤에 실수로 바꾼다. 이미 버려진 소수는 돌아오지 않는다.
  3. 형 변환 위치
    (double)a / b처럼 계산 전에 하나를 실수로 바꿔야 실수 나눗셈이 된다. (double)(a / b)는 늦다.
  4. 출력 형식
    printf의 %d는 정수, %f는 실수이다. 형식과 자료형이 다르면 엉뚱한 값이 나온다.

흔한 실수

  • double x = 5 / 2;가 2.5가 될 것이라고 보는 것.
  • int 값을 %f로 출력하는 것.

바로 풀어보기

int a = 5, b = 2; double x = a / b; double y = (double)a / b; double z = (double)(a / b); int c = 7.9; 뒤에 x, y, z, c의 값을 구하여라.

답과 풀이

답: x = 2.0, y = 2.5, z = 2.0, c = 7

a / b는 int끼리라 2이고, 그것을 double에 넣어 2.0이다. (double)a는 5.0이 되어 5.0 / 2 = 2.5이다. (double)(a / b)는 이미 2가 된 뒤에 바꿔 2.0이다. int c = 7.9는 소수를 버려 7입니다(반올림이 아님).

이 요령으로 풀리는 문제

  • C/C++ 기초 단원 연습 1번, 2번, 6번
영상 콘티 · 40초
  1. 0~5초double x = a / b; 한 줄이 크게 놓인다.\(x\)는 2.5일까?
  2. 5~13초a와 b 위에 'int' 꼬리표가 붙고, 나눗셈 결과 위에도 'int 2'가 붙는다.연산마다 자료형을 적는다.
  3. 13~21초2가 등호를 건너 x 상자로 들어가며 2.0으로 바뀐다. 소수점 아래 .5는 이미 바닥에 떨어져 있다.대입은 계산이 끝난 뒤이다.
  4. 21~31초(double)이 a 앞에 붙자 꼬리표가 'double 5.0'으로 바뀌고 나눗셈 결과가 2.5가 된다.계산 전에 바꿔야 한다.
  5. 31~40초(double)(a / b)는 괄호 안이 먼저 2가 된 뒤 바뀌어 2.0, 7.9는 칼날에 소수가 잘려 7이 된다.형 변환의 위치가 결과를 가른다.
