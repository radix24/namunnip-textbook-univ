본문

제곱근이나 삼각함수를 매번 직접 만들 필요는 없다. 남이 이미 만들어 둔 기능을 가져다 쓰면 된다. 또 입자 여러 개의 질량, 위치, 속도를 따로따로 리스트에 담으면 어느 값이 어느 입자의 것인지 헷갈린다. 남의 코드를 불러 쓰는 방법과, 한 입자의 자료와 동작을 한 덩어리로 묶는 방법은 무엇일까?

먼저 알아야 할 것함수(3.1절)를 쓴다.

3.3.1모듈

처음 질문의 첫째 방법이 모듈이다. 모듈은 함수와 변수를 모아 둔 파이썬 파일이며, 자주 쓰는 기능은 이미 만들어져 있어 불러 쓰기만 하면 된다.

import math
print(math.sqrt(2), math.pi, math.exp(1))
from math import sin, radians
print(sin(radians(30)))          # 0.49999999999999994

import random
print(random.randint(1, 6))      # 주사위

import numpy as np               # 외부 패키지 (pip install numpy)
x = np.linspace(0, 1, 5)         # [0, 0.25, 0.5, 0.75, 1]
print(np.mean(x ** 2))

모듈은 세 종류가 있다. 먼저 math, random, csv, time, os 같은 표준 모듈은 파이썬에 들어 있다. 다음으로 외부 패키지는 pip install 이름으로 설치하며, 과학 계산에는 numpy(배열 계산), matplotlib(그래프), scipy(수치 해석)를 많이 쓴다. 끝으로 내가 만든 mytools.py도 같은 폴더에 두면 import mytools로 쓸 수 있다.

3.3.2클래스

처음 질문의 둘째 방법이 클래스이다. 클래스는 관련된 자료(속성)와 그 자료를 다루는 함수(메서드)를 묶은 설계도이고, 클래스로 만든 하나하나를 객체(인스턴스)라 한다. 사실 문자열이나 리스트도 객체이며, s.upper(), a.append(x)가 메서드이다.

class Particle:
    def __init__(self, m, x, v):     # 객체를 만들 때 실행
        self.m, self.x, self.v = m, x, v

    def kinetic(self):
        return 0.5 * self.m * self.v ** 2

    def move(self, dt):
        self.x += self.v * dt

p = Particle(2.0, 0.0, 3.0)
p.move(0.5)
print(p.x, p.kinetic())     # 1.5 9.0

self는 메서드를 부른 그 객체 자신이다. 그러므로 p.move(0.5)는 Particle.move(p, 0.5)와 같은 뜻이다. 같은 클래스로 입자를 여러 개 만들면 각자 자기 x, v를 가진다. 그림 1에서 move를 여러 번 불러도 두 입자의 위치가 서로 섞이지 않는 것이 이 때문이다. C++의 클래스(5.3절)도 같은 생각이다.

마무리

남이 만든 기능은 import 모듈, from 모듈 import 이름, import 모듈 as 별명으로 불러 쓴다. 처음 질문처럼 한 대상의 자료와 동작은 클래스로 묶으며, 클래스는 속성과 메서드로 이루어지고 __init__에서 self.속성을 만든다.
