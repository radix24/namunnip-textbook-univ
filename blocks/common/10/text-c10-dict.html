튜플과 딕셔너리

본문

원소 기호를 넣으면 원자량을 알려 주는 표를 만들고 싶다. 리스트로 만들면 "O는 몇 번째였더라?"를 기억해야 한다. 번호 대신 "O"라는 이름으로 바로 찾을 수는 없을까? 그리고 좌표처럼 한 덩어리로만 다루고 함부로 바뀌면 안 되는 값은 어떻게 담을까?

먼저 알아야 할 것리스트(2.1절)를 쓴다.

2.2.1튜플

처음 질문의 둘째 물음에 맞는 것이 튜플이다. 튜플은 괄호로 만들며, 리스트처럼 인덱스와 슬라이스를 쓰지만 만든 뒤에는 바꿀 수 없다. 그래서 좌표처럼 한 덩어리로 다루는 값에 쓴다.

p = (3.0, 4.0)
x, y = p              # 풀어서 두 변수에 넣기
a, b = b, a           # 두 변수 값 바꾸기 (오른쪽이 튜플)
p[0] = 1.0            # TypeError: 튜플은 바꿀 수 없다

또 함수가 값을 여러 개 돌려줄 때도 튜플을 쓴다(3.1절).

2.2.2딕셔너리

처음 질문의 첫째 물음에 맞는 것은 딕셔너리이다. 딕셔너리는 키와 값의 쌍을 모은 것으로, 번호 대신 이름(키)으로 값을 찾는다.

M = {"H": 1.008, "C": 12.011, "O": 15.999}   # 원자량
print(M["O"])          # 15.999
M["N"] = 14.007        # 새 키 추가
M["H"] = 1.00794       # 값 바꾸기
print("Na" in M)       # False  (키가 있는지)
print(M.get("Na", 0))  # 0      (없으면 기본값)
for k, v in M.items():
    print(k, v)

없는 키를 M["Na"]로 읽으면 KeyError가 난다. 그림 1에서 "Na"를 고르면 이 경우를 볼 수 있다. 그리고 키는 문자열, 숫자, 튜플처럼 바꿀 수 없는 값이어야 한다.

예제 2.2.1

물({"H": 2, "O": 1})의 몰질량을 위의 원자량 사전으로 구하여라.

풀이. 물의 원소마다 원자량에 개수를 곱해 더한다.

water = {"H": 2, "O": 1}
molar = 0
for el, n in water.items():
    molar += M[el] * n
print(round(molar, 3))      # 18.015 (H = 1.008일 때)

2.2.3무엇을 고를까

세 자료 구조는 찾는 방법과 바꿀 수 있는지에 따라 쓰임이 갈린다.

자료 구조찾는 방법바꿀 수 있나알맞은 곳
리스트 [ ]번호예순서 있는 측정값 모음
튜플 ( )번호아니요좌표, 고정된 설정값, 여러 값 반환
딕셔너리 { : }키예이름으로 찾는 표 (원소 → 원자량)
마무리

튜플은 바꿀 수 없는 묶음으로, 풀어서 대입할 수 있고 좌표나 여러 반환값에 쓴다. 처음 질문처럼 이름으로 찾는 표는 딕셔너리로 만들며, d[키]로 찾고 in, get, items()로 다룬다.
