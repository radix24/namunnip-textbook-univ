사다리꼴 공식과 이분법

본문

\(\int_0^\pi\sin x\,dx = 2\)는 손으로 구할 수 있지만, \(\int e^{-x^2}dx\)처럼 부정적분을 식으로 쓸 수 없는 적분도 많다. 또 \(x^2 = 2\)의 근은 알지만, 일반적인 방정식의 근은 공식이 없는 경우가 대부분이다. 이런 값을 컴퓨터로 원하는 만큼 정확하게 구하려면 어떤 계산을 몇 번 되풀이해야 할까?

먼저 알아야 할 것정적분(미분적분학(1) 4.2절), 중간값 정리(미분적분학(1) 1.4절), 함수와 반복문(3.1절)을 쓴다.

6.2.1사다리꼴 공식

처음 질문의 적분은 구간 \([a, b]\)를 폭 \(h = \frac{b-a}{n}\)인 \(n\)개로 나누고, 각 조각의 넓이를 사다리꼴로 어림해 구한다. 이것이 사다리꼴 공식이다.

\[\int_a^b f(x)\,dx \approx h\left[\frac{f(x_0)}{2} + f(x_1) + \cdots + f(x_{n-1}) + \frac{f(x_n)}{2}\right], \quad x_i = a + ih\] 
import math

def trapezoid(f, a, b, n):
    h = (b - a) / n
    s = (f(a) + f(b)) / 2
    for i in range(1, n):
        s += f(a + i * h)
    return h * s

for n in [4, 8, 16, 32]:
    T = trapezoid(math.sin, 0, math.pi, n)
    print(n, T, 2 - T)

\(n\)을 두 배로 하면 오차가 약 \(\frac14\)이 된다. 즉 사다리꼴 공식의 오차는 \(h^2\)에 비례한다(\(f''\)이 연속일 때). 곡선을 직선으로 이었기 때문이며, 포물선으로 잇는 심프슨 공식은 \(h^4\)에 비례해 훨씬 빠르게 줄어든다. 그림 1에서 \(n\)을 4에서 8, 16으로 늘리면 사다리꼴이 곡선에 점점 붙는다.

6.2.2이분법

처음 질문의 방정식은 이분법으로 푼다. 연속 함수 \(f\)가 \(f(a)\)와 \(f(b)\)의 부호가 다르면 \([a, b]\) 안에 근이 있다(중간값 정리). 그러므로 가운데 \(m = \frac{a+b}{2}\)에서 부호를 보고 근이 있는 절반을 남기는 일을 되풀이한다.

def bisect(f, a, b, tol=1e-6):
    if f(a) * f(b) > 0:
        raise ValueError("양 끝의 부호가 같습니다")
    steps = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
        steps += 1
    return (a + b) / 2, steps

print(bisect(lambda x: x * x - 2, 1, 2))   # (1.41421..., 20)

한 번에 구간이 절반이 되므로, 길이 \(L\)인 구간을 허용 오차 \(\varepsilon\) 아래로 줄이는 데 \(\lceil\log_2(L/\varepsilon)\rceil\)번이면 된다. 가령 \(L = 1\), \(\varepsilon = 10^{-6}\)이면 20번이다. 그림 1에서 이분법을 고르고 \(n\)을 20까지 올리면 구간이 \(\sqrt2\) 둘레로 좁혀진다. 이분법은 느리지만 부호만 바뀌면 반드시 수렴하는 튼튼한 방법이라, 빠른 뉴턴 방법(미분적분학(1) 3단원)의 출발점을 잡는 데도 쓴다. 한편 lambda x: ...는 이름 없는 짧은 함수이다.

마무리

사다리꼴 공식은 \(h[\frac{f_0}{2} + f_1 + \cdots + \frac{f_n}{2}]\)으로 적분을 어림하며 오차가 \(h^2\)에 비례한다. 이분법은 부호가 바뀌는 절반을 남기며 \(\lceil\log_2(L/\varepsilon)\rceil\)번이면 끝난다. 처음 질문처럼 공식이 없는 값도 이렇게 되풀이 횟수를 미리 알고 계산할 수 있다.

6.2.3연습문제

기본

  1. 사다리꼴 공식으로 \(n = 4\)일 때 오차가 0.104였다. 오차를 \(10^{-4}\) 아래로 하려면 \(n\)이 대략 얼마여야 하는가?
    답

    오차가 \(1/n^2\)에 비례하므로 \(0.104 \times (4/n)^2 < 10^{-4}\), \(n > 4\sqrt{1040} \approx 129\). \(n = 130\) 정도.

  2. 구간 \([0, 4]\)에서 이분법으로 오차 \(10^{-3}\) 아래까지 몇 번 반복해야 하는가?
    답

    \(\log_2 4000 \approx 11.97\), 12번.
