재귀 함수는 멈추는 경우부터 쓰고, 한 단계 작은 문제의 답은 맞다고 믿고 쓴다

요령 · 재귀 함수

언제 쓰는가

재귀 함수를 직접 만들거나, 재귀 함수가 몇 번 호출되는지와 결과를 예측하는 문제이다.

요령

  1. 기저 사례
    더 쪼갤 수 없는 가장 작은 입력(n == 0 등)에서 바로 답을 돌려주는 줄을 맨 위에 쓴다.
  2. 한 단계만 믿는다
    f(n)을 쓸 때 f(n - 1)이나 f(n // 2)의 답이 이미 맞다고 보고, 그것으로 f(n)을 만드는 식만 쓴다.
  3. 입력이 줄어드는지
    재귀 호출의 인자가 반드시 기저 사례 쪽으로 줄어드는지 확인한다. 아니면 끝없이 호출한다.
  4. 호출 나무
    호출 횟수는 나무 그림으로 센다. 한 번에 둘씩 부르면(피보나치) 나무가 빠르게 불어난다.

흔한 실수

  • 기저 사례를 빠뜨려 RecursionError가 나는 것.
  • 같은 재귀 호출을 두 번 써서 계산량을 크게 늘리는 것(power(b, n//2) * power(b, n//2)).

바로 풀어보기

\(b^n\)을 계산하는 재귀 함수를 '절반으로 줄이기'로 쓰고, power(2, 10)을 부를 때 함수가 몇 번 호출되는지 세어라.

답과 풀이

답: 5번(\(n\) = 10, 5, 2, 1, 0), 결과 1024

def power(b, n):
    if n == 0:
        return 1
    h = power(b, n // 2)
    return h * h if n % 2 == 0 else h * h * b

\(n\)이 10, 5, 2, 1, 0으로 줄어들어 5번 호출된다. \(n\)을 1씩 줄였다면 11번이 필요하다. 반쪽 결과를 변수 h에 받아 두어 호출이 한 번씩만 일어난다.

이 요령으로 풀리는 문제

  • 파이썬 함수, 파일, 모듈, 클래스 단원 연습 2번
영상 콘티 · 45초
  1. 0~5초power(2, 10) 상자 하나가 화면에 놓인다.재귀는 어디서부터 쓸까?
  2. 5~13초맨 아래에 '\(n = 0\) → 1' 바닥판이 먼저 깔린다.멈추는 경우부터 쓴다.
  3. 13~22초상자가 아래로 power(2, 5), power(2, 2), power(2, 1), power(2, 0)을 차례로 내려보내며 계단이 생긴다.입력이 바닥 쪽으로 줄어드는지 본다.
  4. 22~33초바닥에서 1이 올라오며 계단마다 제곱되거나 \(b\)가 곱해져 2, 4, 32, 1024가 된다.한 단계 작은 답을 믿고 조립한다.
  5. 33~45초h 없이 두 번 부르는 버전의 호출 나무가 옆에 펼쳐지며 가지가 두 갈래씩 불어난다.같은 호출을 두 번 하지 않는다.
