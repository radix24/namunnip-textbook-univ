함수와 재귀

본문

이상 기체의 압력 \(P = \frac{nRT}{V}\)를 프로그램 여기저기서 계산한다면, 같은 식을 매번 다시 쓰다가 한 곳에서 오타가 날 수 있다. 계산을 한 번만 써 두고 이름으로 부를 수는 없을까? 그리고 \(5! = 5\times4!\)처럼 문제를 같은 모양의 더 작은 문제로 줄여 가는 계산은 프로그램으로 어떻게 쓸까?

먼저 알아야 할 것반복문(2.3절)을 쓴다.

3.1.1함수 정의

처음 질문의 첫째 물음에 대한 답이 함수이다. 같은 계산을 여러 번 쓰면 함수로 묶는다. 그러면 프로그램이 짧아지고, 이름이 있어 읽기 쉽고, 고칠 곳이 한 군데가 된다.

def ideal_P(n, T, V, R=0.08206):
    """이상 기체 압력 (atm). n mol, T K, V L"""
    return n * R * T / V

print(ideal_P(1, 273.15, 22.414))   # 약 1.0
print(ideal_P(2, 300, V=10))        # 키워드로 넘기기

함수가 받는 값의 이름(n, T, V)을 매개변수라 하며, R=0.08206처럼 기본값을 줄 수 있다. 호출할 때 실제로 넘기는 값은 인수라 한다. 그리고 return 뒤의 값을 반환값이라 하며, return이 없으면 None을 돌려준다. 여러 값은 return a, b로 돌려주면 튜플이 된다.

3.1.2지역 변수

함수 안에서 만든 변수는 함수가 끝나면 사라지고 바깥에서는 보이지 않는다. 이것을 지역 변수라 한다. 함수 밖의 같은 이름 변수와는 서로 다른 변수이다. 그러므로 함수가 바깥 값을 쓰려면 매개변수로 받고, 결과는 return으로 돌려주는 것이 깔끔하다.

3.1.3재귀

처음 질문의 둘째 물음, 곧 함수가 자기 자신을 부르는 것을 재귀라 한다. 문제를 같은 모양의 더 작은 문제로 줄이고, 더 줄일 수 없는 경우(기저 사례)는 바로 답한다.

def fact(n):
    if n <= 1:            # 기저 사례
        return 1
    return n * fact(n - 1)

print(fact(5))   # 120

fact(5)는 fact(4)를 부르고 기다리며, 이것이 fact(1)까지 이어진다. 호출될 때마다 컴퓨터는 그 호출의 n을 따로 기억해 두는데, 이것을 호출 스택이라 한다. 그리고 fact(1)이 1을 돌려주면 거꾸로 1·2·3·4·5를 곱하며 돌아온다. 그림 1에서 단계를 넘기면 스택이 다섯 칸까지 쌓였다가 하나씩 풀리는 것을 볼 수 있다.

재귀를 쓸 때는 두 가지를 조심한다. 기저 사례가 없거나 도달하지 못하면 끝없이 부르다 RecursionError가 난다(파이썬 기본 한도 약 1000단계). 또 피보나치 \(F(n) = F(n-1) + F(n-2)\)를 그대로 재귀로 쓰면 같은 값을 수없이 다시 계산해 호출 수가 지수적으로 는다. 그래서 반복문이나 이미 구한 값을 저장해 두는 방법(메모이제이션)으로 고친다. 아래 실습에서 호출 수를 세어 볼 수 있다.

마무리

함수는 def 이름(매개변수):로 정의하고 return 값으로 결과를 돌려주며, 함수 안의 변수는 지역 변수이다. 처음 질문의 작은 문제로 줄이는 계산은 재귀로 쓰며, 기저 사례와 더 작은 문제로의 자기 호출로 이루어지고 호출 스택에 쌓였다가 거꾸로 돌아온다.
