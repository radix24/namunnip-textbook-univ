포인터 문제는 변수를 상자로, 포인터를 화살표로 그려 한 줄씩 따라간다

요령 · 포인터

언제 쓰는가

포인터를 거쳐 값을 바꾸는 코드의 결과를 예측하거나, 함수가 인자를 바꾸지 못하는 이유를 찾을 때이다.

요령

  1. 상자와 화살표
    변수마다 상자를 그리고 값을 적는다. 포인터 변수는 다른 상자를 가리키는 화살표이다.
  2. &와 *
    &x는 '\(x\) 상자의 주소', 곧 화살표를 만들고, *p는 '화살표 끝의 상자'이다.
  3. p = q와 *p = *q를 구별
    p = q는 화살표의 방향을 바꾸고, *p = *q는 화살표 끝 상자의 값을 바꾼다.
  4. 함수 인자
    C 함수는 값을 복사해 받으므로, 원래 변수를 바꾸려면 주소(화살표)를 넘긴다. 함수 안의 지역 배열 주소를 돌려주면 함수가 끝난 뒤 사라진 상자를 가리킨다.

흔한 실수

  • p = q 뒤에도 *p가 원래 변수를 가리킨다고 보는 것.
  • swap(int a, int b)로 바꿔지길 기대하는 것.

바로 풀어보기

int a = 1, b = 2; int *p = &a, *q = &b; *p = *q + 3; p = q; *p = 10; 뒤에 a와 b의 값은?

답과 풀이

답: a = 5, b = 10

*p = *q + 3: p가 가리키는 a에 \(2 + 3 = 5\)가 들어간다. p = q: 이제 p도 b를 가리킨다. *p = 10: p가 가리키는 b가 10이 된다. a는 5 그대로이다.

이 요령으로 풀리는 문제

  • C/C++ 배열, 포인터, 구조체, 클래스 단원 연습 2번, 3번, 6번
영상 콘티 · 40초
  1. 0~5초상자 a(1), b(2)와 화살표 p → a, q → b가 그려진다.포인터는 그림으로 따라간다.
  2. 5~13초q 화살표 끝의 2가 복사되어 3이 더해지고, p 화살표를 타고 a 상자로 들어가 5가 된다.*p는 화살표 끝의 상자.
  3. 13~21초p 화살표가 a에서 떨어져 휙 돌아 b를 가리킨다. a의 값은 그대로이다.p = q는 화살표만 바꾼다.
  4. 21~30초10이 p 화살표를 타고 내려가 b 상자에 들어간다.이제 *p는 b이다.
  5. 30~40초swap(int a, int b) 장면: 함수 안에 복사된 상자 두 개만 바뀌고 바깥 상자는 그대로이다. 화살표를 넘기는 버전에서는 바깥 상자가 바뀐다.바꾸려면 주소를 넘긴다.
