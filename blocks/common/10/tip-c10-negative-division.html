정수 나눗셈과 나머지는 음수를 넣어 먼저 확인한다

요령 · 나눗셈과 나머지

언제 쓰는가

//, %, int(), round()의 결과를 예측하는 문제, 같은 계산을 파이썬과 C로 옮길 때이다.

요령

  1. 파이썬 //는 내림
    -7 // 2는 \(-3.5\)를 아래로 내려 \(-4\)이다.
  2. 나머지는 나누는 수의 부호
    파이썬은 a == (a // b) * b + a % b가 늘 성립하도록 -7 % 2를 1로 정한다.
  3. int()는 0 쪽으로
    int(-3.5)는 \(-3\)으로 버린다. C의 정수 나눗셈 -7 / 2도 0 쪽으로 버려 \(-3\), 나머지 -7 % 2는 \(-1\)이다.
  4. round는 짝수 쪽
    파이썬 round(2.5)는 2, round(3.5)는 4입니다(가운데 값은 짝수로).

흔한 실수

  • -7 // 2를 \(-3\)으로 예측하는 것.
  • 파이썬 코드를 C로 옮기며 음수 나머지가 달라지는 것을 놓치는 것.

바로 풀어보기

파이썬에서 -7 // 2, -7 % 2, int(-3.5), round(2.5)의 값을 예측하고, C에서 -7 / 2와 -7 % 2를 예측하여라.

답과 풀이

답: 파이썬 \(-4\), \(1\), \(-3\), \(2\). C \(-3\), \(-1\)

파이썬의 //는 내림이라 \(-4\), 그러면 \(-7 = (-4)(2) + 1\)이 되도록 나머지는 1이다. int는 0 쪽으로 버려 \(-3\), round(2.5)는 짝수 쪽 2이다.

C는 정수 나눗셈을 0 쪽으로 버리므로 \(-3\)이고, \(-7 = (-3)(2) + (-1)\)이 되도록 나머지는 \(-1\)이다.

이 요령으로 풀리는 문제

  • 파이썬 시작하기 단원 연습 1번
  • C/C++ 기초 단원 연습 1번
영상 콘티 · 40초
  1. 0~5초수직선 위 \(-3.5\)에 점이 찍힌다.\(-7 \div 2\)를 정수로 만들면?
  2. 5~13초파이썬 로고가 붙은 화살표가 점을 왼쪽으로 밀어 \(-4\)에 떨어뜨린다.파이썬 //는 아래로 내린다.
  3. 13~21초C 로고가 붙은 화살표는 점을 0 쪽으로 밀어 \(-3\)에 떨어뜨린다.C와 int()는 0 쪽으로 버린다.
  4. 21~31초두 결과 옆에 '몫 × 2 + 나머지 = −7' 저울이 각각 나타나 나머지 1과 −1이 채워진다.나머지는 몫에 맞춰 정해진다.
  5. 31~40초2.5와 3.5가 각각 가까운 짝수 2와 4로 굴러간다.round는 가운데면 짝수 쪽.
