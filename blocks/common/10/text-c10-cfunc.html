C의 함수

본문

변수를 두 배로 만드는 C 함수 twice(a)를 불렀는데, 부른 뒤에도 a는 그대로 5였다. 함수 안에서는 분명히 두 배를 했다. 함수에 넘긴 값은 어디로 가며, 왜 원래 변수가 바뀌지 않았을까?

먼저 알아야 할 것파이썬 함수(3.1절)와 C 제어문(4.2절)을 쓴다.

4.3.1함수 정의

C 함수는 돌려줄 값의 자료형(반환형), 이름, 매개변수의 자료형과 이름을 모두 적는다. 돌려줄 값이 없으면 반환형을 void로 쓴다.

#include <stdio.h>
#include <math.h>

double distance(double x1, double y1, double x2, double y2);   /* 원형 선언 */

int main(void) {
    printf("%.3f\n", distance(0, 0, 3, 4));     /* 5.000 */
    return 0;
}

double distance(double x1, double y1, double x2, double y2) {
    double dx = x2 - x1, dy = y2 - y1;
    return sqrt(dx * dx + dy * dy);
}

C 컴파일러는 위에서 아래로 읽기 때문에, 함수를 main보다 뒤에 정의하려면 앞에 원형(머리 부분과 세미콜론)을 먼저 적어 둔다. 또 수학 함수를 쓰는 프로그램은 컴파일할 때 -lm을 붙여야 하는 환경도 있다.

4.3.2값에 의한 전달

처음 질문의 답이 여기 있다. C는 함수를 부를 때 인수의 값을 복사해서 넘긴다. 그러므로 함수 안에서 매개변수를 바꿔도 부른 쪽의 변수는 그대로이다.

void twice(int x) { x = 2 * x; }

int a = 5;
twice(a);
printf("%d\n", a);     /* 5  (바뀌지 않음) */

그림 1에서 단계를 넘기면, a의 5가 x로 복사되고 x만 10이 된 뒤 사라진다. 부른 쪽의 변수를 함수가 바꾸게 하려면 변수의 주소를 넘긴다. scanf("%d", &a)에 &를 붙이는 까닭이 이것이며, 5.2절 포인터에서 다룬다.

4.3.3재귀

C 함수도 자기 자신을 부를 수 있다. 3.1절의 계승을 C로 쓰면 다음과 같다.

long long fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

그런데 int로 쓰면 fact(13)부터 범위(약 21억)를 넘어 틀린 값이 나온다. 반면 long long은 fact(20)까지 담는다.

마무리

C 함수는 반환형 이름(자료형 매개변수, ...) { ... return 값; }으로 쓰고, 돌려줄 값이 없으면 void, 뒤에 정의하면 앞에 원형을 선언한다. 처음 질문처럼 인수는 값이 복사되어 넘어가므로, 원래 변수를 바꾸게 하려면 주소를 넘긴다.
