실행 시간과 계산량

본문
이 절에서 배울 것
  • time.perf_counter로 실행 시간을 잰다.
  • 선형 탐색과 이진 탐색의 비교 횟수를 세어, 입력이 커질 때 늘어나는 빠르기를 비교한다.
  • 계산량을 \(O(n)\), \(O(\log n)\), \(O(n^2)\)으로 나타내는 뜻을 안다.
먼저 알아야 할 것
  • 리스트와 반복문 (2.1절, 2.3절), 함수 (3.1절), 로그 \(\log_2\) (고교 수학I).

6.3.1시간 재기

import time
t0 = time.perf_counter()
# 잴 코드
dt = time.perf_counter() - t0      # 초 단위

같은 코드라도 컴퓨터와 그때의 상황에 따라 시간이 달라지므로, 여러 번 재거나 입력 크기를 바꾸며 비율을 보는 것이 좋습니다. 그래서 시간 대신 "기본 연산(비교, 덧셈)을 몇 번 하는가"를 세는 방법을 함께 씁니다. 이 횟수를 계산량이라 합니다.

6.3.2선형 탐색과 이진 탐색

정렬된 리스트 a에서 값 x의 위치를 찾는 두 방법입니다.

선형 탐색: 앞에서부터 하나씩 비교합니다. 길이가 \(n\)이면 최악의 경우 \(n\)번 비교합니다.

이진 탐색: 가운데 원소와 비교해, x가 더 크면 오른쪽 절반, 작으면 왼쪽 절반만 남깁니다. 한 번 비교할 때마다 후보가 절반으로 줄어듭니다. 사전에서 단어를 찾는 방법과 같습니다.

def binary(a, x):
    lo, hi, steps = 0, len(a) - 1, 0
    while lo <= hi:
        steps += 1
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid, steps
        elif a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1, steps        # 없으면 -1
예제 6.3.1

짝수 \(0, 2, 4, \ldots\)를 \(n\)개 담은 리스트에서 마지막 원소를 찾을 때, 선형 탐색과 이진 탐색의 비교 횟수를 \(n = 1000\)과 \(n = 1\,000\,000\)에서 구하세요.

풀이. 선형 탐색은 마지막까지 가야 하므로 1000번, 1000000번입니다. 이진 탐색은 후보 수가 \(n \to n/2 \to n/4 \to \cdots\)로 줄어 1이 될 때까지이므로 약 \(\log_2 n\)번입니다. \(2^{10} = 1024\)이므로 \(n = 1000\)에서 10번, \(2^{20} \approx 10^6\)이므로 \(n = 10^6\)에서 20번입니다. 위 코드로 세어 보아도 10번, 20번이 나옵니다. 리스트에 없는 값(예: 1)을 찾을 때도 같은 10번, 20번 뒤에 -1을 돌려줍니다. 자료가 1000배 커질 때 선형 탐색은 1000배, 이진 탐색은 10번만 더 늘었습니다. 다만 이진 탐색은 자료가 정렬되어 있어야 쓸 수 있습니다.

6.3.3계산량의 표기

\(n\)이 클 때 계산량이 무엇에 비례하는지만 남겨 \(O(\cdot)\)로 씁니다(읽기: "빅 오"). 상수배와 작은 항은 버립니다.

  • \(O(\log n)\): 이진 탐색. \(n\)이 두 배가 되면 한 번 더.
  • \(O(n)\): 선형 탐색, 합 구하기. \(n\)이 두 배면 두 배.
  • \(O(n^2)\): 모든 쌍을 비교하는 이중 반복. \(n\)이 두 배면 네 배.
예제 6.3.2

측정값 \(n\)개에서 차이가 0.001보다 작은 쌍의 수를 세는 함수가 있습니다. 쌍 \((i, j)\), \(i < j\)를 모두 비교합니다. 비교 횟수를 \(n\)으로 나타내고, \(n\)을 1000 → 2000 → 4000으로 늘리면 실행 시간이 어떻게 변할지 예상하세요.

def pairs(xs):
    n, cnt = len(xs), 0
    for i in range(n):
        for j in range(i + 1, n):
            if abs(xs[i] - xs[j]) < 1e-3:
                cnt += 1
    return cnt

풀이. \(i = 0\)일 때 \(n - 1\)번, \(i = 1\)일 때 \(n - 2\)번, …이므로 모두 \(\frac{n(n-1)}{2}\)번, 곧 \(O(n^2)\)입니다. \(n\)이 두 배가 될 때마다 시간은 약 네 배가 될 것으로 예상합니다. 실제로 이 교재를 쓴 컴퓨터에서 난수 자료로 재 보니 대략 0.25초, 1.2초, 4.0초로, 한 단계마다 3~5배였습니다(컴퓨터마다 절대 시간은 다릅니다). 자료를 먼저 정렬하면 이웃한 값끼리만 비교해도 되므로 정렬 \(O(n\log n)\)에 훑기 \(O(n)\)으로 줄일 수 있습니다.

요약
  1. 시간은 time.perf_counter()의 차이로 재고, 입력 크기를 바꿔 비율을 본다.
  2. 선형 탐색 \(O(n)\), 이진 탐색 \(O(\log n)\)(정렬된 자료), 모든 쌍 비교 \(O(n^2)\).
  3. \(n\)이 두 배일 때 \(O(n^2)\)은 네 배, \(O(\log n)\)은 한 단계만 늘어난다.

6.3.4연습문제

기본

  1. 정렬된 자료 100만 개에서 이진 탐색은 최대 몇 번 비교하나요? 10억 개라면?
    답

    \(2^{20} = 1\,048\,576\)이므로 약 20번. \(2^{30} \approx 1.07\times10^9\)이므로 약 30번.

  2. \(O(n^2)\) 프로그램이 \(n = 1000\)에서 0.3초 걸렸습니다. \(n = 10000\)이면 대략 얼마나 걸릴까요?
    답

    \(n\)이 10배이므로 시간은 100배, 약 30초.
