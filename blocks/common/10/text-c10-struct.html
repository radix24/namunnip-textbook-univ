구조체와 C++ 클래스

본문

원소마다 기호(문자열), 원자 번호(정수), 원자량(실수)을 담으려면 배열 세 개를 따로 만들어야 할까? 배열은 같은 자료형만 담을 수 있다. 자료형이 다른 값들을 한 덩어리로 묶고, 3.3절의 파이썬 클래스처럼 자료와 함수를 함께 묶는 방법은 C와 C++에서 어떻게 쓸까?

먼저 알아야 할 것파이썬 클래스(3.3절)와 포인터(5.2절)를 쓴다.

5.3.1구조체

처음 질문처럼 원소 기호, 원자 번호, 원자량같이 자료형이 다른 값들을 하나로 묶을 때 구조체를 쓴다.

#include <stdio.h>
struct Element {
    char symbol[3];
    int Z;
    double mass;
};

int main(void) {
    struct Element e[3] = {{"H", 1, 1.008}, {"C", 6, 12.011}, {"O", 8, 15.999}};
    for (int i = 0; i < 3; i++)
        printf("%-2s Z=%d  %.3f\n", e[i].symbol, e[i].Z, e[i].mass);
    struct Element *p = &e[1];
    printf("%s\n", p->symbol);       /* C   (*p).symbol과 같음 */
    return 0;
}

구조체의 멤버는 점(.)으로 쓴다. 가령 e[i].Z이다. 반면 구조체 포인터는 화살표(->)로 쓰며, p->mass는 (*p).mass와 같다. 그림 1에서 p가 가리키는 원소를 바꾸면 p->symbol이 그 원소의 기호가 된다. 또 typedef struct { ... } Element;로 이름을 줄일 수 있다.

5.3.2C++ 클래스

C++는 C에 클래스를 더한 언어이며, C 코드 대부분이 그대로 컴파일된다. 구조체처럼 자료를 묶고, 그 자료를 다루는 함수(멤버 함수)도 함께 넣는다.

#include <iostream>
using namespace std;

class Particle {
private:                         // 바깥에서 직접 못 건드림
    double m, x, v;
public:                          // 바깥에서 쓸 수 있음
    Particle(double m_, double x_, double v_) : m(m_), x(x_), v(v_) {}   // 생성자
    void move(double dt) { x += v * dt; }
    double kinetic() const { return 0.5 * m * v * v; }
    double pos() const { return x; }
};

int main() {
    Particle p(2.0, 0.0, 3.0);
    p.move(0.5);
    cout << p.pos() << " " << p.kinetic() << endl;    // 1.5 9
    return 0;
}

이 코드는 3.3절의 파이썬 Particle과 같은 일을 한다. 차이는 넷이다. 먼저 C++는 멤버의 자료형을 선언한다. 다음으로 self 대신 멤버 이름을 바로 쓰며, 필요하면 this->x로 쓴다. 또 생성자는 클래스와 같은 이름의 함수로, 파이썬의 __init__에 해당한다. 끝으로 private로 감춘 자료는 멤버 함수를 통해서만 바꿀 수 있으며, 이것을 캡슐화라 한다. 그래서 잘못된 값이 들어가는 것을 막는다.

한편 입출력은 printf 대신 cout <<을 많이 쓴다.

마무리

처음 질문처럼 자료형이 다른 값들은 struct로 묶고, 멤버는 .으로, 구조체 포인터의 멤버는 ->로 꺼낸다. C++의 class는 자료와 멤버 함수를 함께 묶으며, 생성자와 public/private로 객체를 만들고 감춘다.
