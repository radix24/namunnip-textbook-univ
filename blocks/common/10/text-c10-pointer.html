포인터와 메모리 주소

본문

4.3절에서 함수는 값의 복사본만 받으므로 원래 변수를 바꿀 수 없었다. 그런데 scanf("%d", &n)은 분명히 n에 값을 써 넣는다. 변수의 "값"이 아니라 그 변수가 메모리 어디에 있는지를 알려 주면 될 것 같은데, 그 위치는 어떻게 얻고 어떻게 쓸까?

먼저 알아야 할 것값에 의한 전달(4.3절)과 배열(5.1절)을 쓴다.

5.2.1주소

메모리는 1바이트마다 번호가 붙은 긴 칸의 줄이라고 볼 수 있고, 그 번호가 주소이다. 처음 질문의 "위치"가 이것이다. 가령 int a = 5;를 선언하면 4바이트짜리 자리가 잡히고 그 안에 5가 들어간다. 주소는 실행할 때마다 달라질 수 있으며, 보통 16진수로 나타낸다.

주소를 다루는 기호는 셋이다. &a는 변수 a의 주소이다. int *p;는 int 값이 놓인 주소를 담는 변수, 곧 포인터 p의 선언이다. 그리고 *p는 p가 가리키는 자리의 값이며, 이것을 역참조라 한다.

int a = 5;
int *p = &a;          /* p는 a를 가리킨다 */
printf("%p\n", (void *)p);   /* 예: 0x7ffd5e8c (실행마다 다름) */
*p = 9;               /* p가 가리키는 자리에 9를 쓴다 */
printf("%d\n", a);    /* 9 */

같은 기호 *가 선언에서는 "포인터 자료형", 식에서는 "가리키는 값"이라는 뜻이라 처음에 헷갈린다.

5.2.2함수가 바깥 변수를 바꾸기

처음 질문의 답은 주소를 넘기는 것이다. 그러면 함수는 그 주소로 가서 원래 변수를 바꿀 수 있다.

void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}
int a = 1, b = 2;
swap(&a, &b);         /* a = 2, b = 1 */

scanf("%d", &n)도 같은 원리로, 읽은 값을 n의 자리에 써 넣으려고 주소를 받는다.

5.2.3배열과 포인터

배열 이름은 식 안에서 첫 원소의 주소로 바뀐다. 그리고 포인터에 정수를 더하면 자료형의 크기만큼 주소가 움직인다. 가령 int가 4바이트이면 p + 1은 4바이트 뒤이다. 그림 1에서 자료형을 double로 바꾸면 같은 p + k가 8바이트씩 움직인다.

int a[4] = {10, 20, 30, 40};
int *p = a;            /* &a[0]과 같음 */
printf("%d %d\n", *(p + 2), p[2]);   /* 30 30  a[i]는 *(a + i)와 같다 */

그래서 배열을 함수에 넘기면 주소만 넘어가 복사가 일어나지 않고(5.1절), 범위를 벗어난 p[10]도 컴파일러가 막지 않는다. 또 아무 곳도 가리키지 않는 포인터는 NULL로 두고, 쓰기 전에 확인한다. 아래 실습 카드에서 포인터를 움직이며 주소와 값을 볼 수 있다.

파이썬에는 포인터 문법이 없지만, 모든 변수가 객체를 가리키는 이름이므로 생각은 같다. 2.1절에서 b = a가 리스트를 복사하지 않던 까닭이다.
마무리

&변수는 주소, 자료형 *p는 포인터 선언, *p는 가리키는 값이다. 처음 질문처럼 주소를 넘기면 함수가 원래 변수를 바꿀 수 있으며(swap, scanf), 배열 이름은 첫 원소의 주소이고 a[i]는 *(a + i)와 같다. 포인터 더하기는 자료형 크기 단위로 움직인다.
