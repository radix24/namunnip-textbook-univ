  2. 계산재귀 함수 def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)로 fib(5)를 계산할 때 함수가 모두 몇 번 호출되나요? [03-01]

    힌트 1

    \(C(n)\)을 fib(n)의 호출 수라 하면 \(C(0) = C(1) = 1\)이고 \(C(n) = C(n-1) + C(n-2) + 1\).

    힌트 2

    \(C(2) = 3\), \(C(3) = 5\).

    풀이

    \(C(4) = 9\), \(C(5) = 15\)번. 값은 fib(5) = 5. 같은 값(fib(2)는 세 번)을 여러 번 다시 계산하기 때문에 \(n\)이 커지면 호출 수가 지수적으로 늘어납니다. 한 번 계산한 값을 저장해 두면(메모이제이션) \(n\)번 정도로 줄어듭니다.

  5. 실습2차원 벡터 클래스 Vector를 만들어 길이를 구하는 메서드 length와 두 벡터를 더하는 __add__를 넣으세요. Vector(3, 4).length()는 5.0이어야 합니다. [03-03]

    힌트 1

    __init__(self, x, y)에서 self.x = x처럼 속성을 저장합니다.

    힌트 2

    __add__(self, other)는 a + b를 쓸 때 불립니다. 새 Vector를 돌려줍니다.

    풀이 
    import math
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def length(self):
        return math.hypot(self.x, self.y)
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
v = Vector(3, 4) + Vector(1, -1)
print(Vector(3, 4).length(), v.x, v.y)   # 5.0 4 3

  6. 판단def add(item, box=[]): box.append(item); return box를 만들고 add(1), add(2)를 차례로 불렀더니 두 번째 결과가 [2]가 아니라 [1, 2]였습니다. 왜 그런지, 어떻게 고쳐야 하는지 말하세요. [03-01]

    힌트 1

    기본값 []는 언제 만들어지나요? 함수를 정의할 때 한 번인가요, 부를 때마다인가요?

    힌트 2

    기본값으로 None을 두고 함수 안에서 새 리스트를 만듭니다.

    풀이

    기본값은 함수를 정의할 때 한 번만 만들어져 모든 호출이 같은 리스트를 씁니다. 고친 코드: def add(item, box=None): 안에서 if box is None: box = []. 바뀔 수 있는 객체(리스트, 딕셔너리)를 기본값으로 쓰지 않는 것이 규칙입니다.

  7. 실습평균을 돌려주는 함수 mean(xs)를 쓰되, 빈 리스트가 들어오면 ValueError를 내게 하세요. 부르는 쪽에서는 그 예외를 받아 "자료가 없습니다"를 출력하세요. [03-04]

    힌트 1

    빈 리스트는 거짓으로 취급되므로 if not xs:로 확인합니다.

    힌트 2

    함수 안에서는 raise, 부르는 쪽에서는 try / except ValueError.

    풀이 
    def mean(xs):
    if not xs:
        raise ValueError("빈 리스트의 평균은 없습니다")
    return sum(xs) / len(xs)

print(mean([2, 4, 9]))   # 5.0
try:
    mean([])
except ValueError:
    print("자료가 없습니다")

    검사하지 않으면 ZeroDivisionError가 나는데, 이 메시지로는 "자료가 비었다"는 진짜 원인을 알기 어렵습니다. 원인을 말해 주는 예외를 직접 내는 편이 낫습니다.
