C의 자료형과 연산자

본문

파이썬으로 잘 돌던 계산을 C로 옮겼더니 \(\frac12 gt^2\)이 0으로 나왔다. 식은 똑같이 1 / 2 * 9.8인데 무엇이 달라졌을까? C는 파이썬보다 훨씬 빠르다는데, 그 대가로 프로그래머가 무엇을 더 챙겨야 할까?

먼저 알아야 할 것파이썬의 자료형과 연산자(1.1절)를 쓴다.

4.1.1C 프로그램의 구조

#include <stdio.h>           /* 입출력 함수를 쓰겠다는 선언 */

int main(void) {               /* 프로그램은 main에서 시작 */
    printf("Hello, C!\n");     /* 줄바꿈 \n을 직접 넣는다 */
    return 0;                  /* 0: 정상 종료 */
}

C는 문장 끝에 세미콜론(;)을 쓰고, 묶음을 중괄호로 나타낸다. 즉 들여쓰기는 읽기 위한 것일 뿐이다. 소스 파일 hello.c를 컴파일러(예: gcc hello.c -o hello)로 기계어 실행 파일로 바꾼 뒤 실행한다. 그래서 번역을 미리 해 두므로 같은 계산을 파이썬보다 대체로 훨씬 빠르게 한다(전자계산(2) 5.4절에서 비교).

4.1.2자료형과 변수 선언

처음 질문의 대가 가운데 하나가 이것이다. C에서는 변수를 쓰기 전에 자료형을 정해 선언해야 하고, 그 변수에는 그 자료형의 값만 넣을 수 있다.

자료형뜻크기 (흔한 환경)printf 형식
int정수4바이트, 약 ±21억%d
long long큰 정수8바이트%lld
float실수 (유효숫자 약 7자리)4바이트%f
double실수 (약 16자리)8바이트%f, 입력은 %lf
char문자 하나1바이트%c

크기는 컴파일러와 컴퓨터에 따라 다를 수 있으며, sizeof(int)로 확인한다. 또 파이썬 정수와 달리 C의 int는 범위를 넘으면 엉뚱한 값이 된다. 이것을 오버플로라 한다(6.1절).

#include <stdio.h>
int main(void) {
    double r, area;
    printf("반지름? ");
    scanf("%lf", &r);              /* &r: r의 주소 (5.2절) */
    area = 3.14159 * r * r;
    printf("넓이 %.2f\n", area);
    return 0;
}

4.1.3연산자와 형 변환

산술 연산자는 + - * / %이고, 거듭제곱 연산자는 없어 math.h의 pow를 쓴다. 그런데 가장 흔한 함정은 정수끼리 나누면 몫만 남는다는 것이다. 처음 질문의 0이 바로 이 때문이다.

int a = 7, b = 2;
printf("%d\n", a / b);             /* 3 */
printf("%f\n", a / 2.0);           /* 3.500000 */
printf("%f\n", (double)a / b);     /* 3.500000  형 변환 */
double h = 1 / 2 * 9.8;            /* 0.0 ! 1/2가 먼저 0이 된다 */

그림 1에서 1 / 2 * 9.8을 고르면 왼쪽부터 계산하므로 1 / 2가 먼저 0이 되고, 그 뒤에 9.8을 곱해도 0이다. 반면 1.0 / 2 * 9.8은 4.9가 된다. 그 밖에 ++i(1 증가), +=, 비교 == != < >, 논리 &&(그리고) ||(또는) !(아님)이 있다. 그리고 C에서는 0이 거짓, 0이 아닌 값이 참이다.

마무리

C 프로그램은 #include와 int main(void) { ... return 0; }으로 이루어지고, 세미콜론과 중괄호를 쓰며 컴파일한 뒤 실행한다. 변수는 int, double, char 같은 자료형과 함께 선언하고 형식 지정자 %d %f %lf %c로 입출력한다. 처음 질문처럼 정수 나눗셈은 몫이므로, 실수가 필요하면 2.0이나 (double)을 쓴다.
