4.1.1C 프로그램의 구조

#include <stdio.h>           /* 입출력 함수를 쓰겠다는 선언 */

int main(void) {               /* 프로그램은 main에서 시작 */
    printf("Hello, C!\n");     /* 줄바꿈 \n을 직접 넣는다 */
    return 0;                  /* 0: 정상 종료 */
}

C는 문장 끝에 세미콜론(;)을 쓰고, 묶음을 중괄호로 나타냅니다(들여쓰기는 읽기 위한 것일 뿐). 소스 파일 hello.c를 컴파일러(예: gcc hello.c -o hello)로 기계어 실행 파일로 바꾼 뒤 실행합니다. 번역을 미리 해 두므로 같은 계산을 파이썬보다 대체로 훨씬 빠르게 합니다(공통11 5.4절에서 비교).

4.1.2자료형과 변수 선언

C에서는 변수를 쓰기 전에 자료형을 정해 선언해야 하고, 그 변수에는 그 자료형의 값만 넣을 수 있습니다.

자료형뜻크기 (흔한 환경)printf 형식
int정수4바이트, 약 ±21억%d
long long큰 정수8바이트%lld
float실수 (유효숫자 약 7자리)4바이트%f
double실수 (약 16자리)8바이트%f, 입력은 %lf
char문자 하나1바이트%c

크기는 컴파일러와 컴퓨터에 따라 다를 수 있고, sizeof(int)로 확인합니다. 파이썬 정수와 달리 C의 int는 범위를 넘으면 엉뚱한 값이 됩니다(오버플로, 6.1절).

#include <stdio.h>
int main(void) {
    double r, area;
    printf("반지름? ");
    scanf("%lf", &r);              /* &r: r의 주소 (5.2절) */
    area = 3.14159 * r * r;
    printf("넓이 %.2f\n", area);
    return 0;
}

4.1.3연산자와 형 변환

산술 연산자는 + - * / %이고 거듭제곱 연산자는 없습니다(math.h의 pow). 가장 흔한 함정은 정수끼리 나누면 몫만 남는다는 것입니다.

int a = 7, b = 2;
printf("%d\n", a / b);             /* 3 */
printf("%f\n", a / 2.0);           /* 3.500000 */
printf("%f\n", (double)a / b);     /* 3.500000  형 변환 */
double h = 1 / 2 * 9.8;            /* 0.0 ! 1/2가 먼저 0이 된다 */

그 밖에 ++i(1 증가), +=, 비교 == != < >, 논리 &&(그리고) ||(또는) !(아님)이 있습니다. C에서는 0이 거짓, 0이 아닌 값이 참입니다.

요약
  1. #include, int main(void) { ... return 0; }, 세미콜론과 중괄호. 컴파일 후 실행.
  2. 변수는 자료형과 함께 선언. int, double, char. 형식 지정자 %d %f %lf %c.
  3. 정수 나눗셈은 몫. 실수가 필요하면 2.0이나 (double).
