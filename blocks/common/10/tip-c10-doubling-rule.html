계산량은 입력을 두 배로 했을 때 시간이 몇 배가 되는지로 읽는다

요령 · 계산량

언제 쓰는가

실행 시간을 재서 알고리즘의 계산량을 짐작하거나, 입력이 커질 때 걸릴 시간을 예측하는 문제이다.

요령

  1. 두 배 규칙
    입력이 2배일 때 시간이 2배면 \(O(n)\), 4배면 \(O(n^2)\), 8배면 \(O(n^3)\), 거의 그대로면 \(O(\log n)\)이다. \(O(n\log n)\)은 2배보다 조금 크다.
  2. 비례식으로 예측
    \(O(n^2)\)에서 입력이 \(k\)배면 시간은 \(k^2\)배이다.
  3. 로그는 반으로 접는 횟수
    이진 탐색처럼 매번 반으로 줄이면 \(\lceil\log_2(n + 1)\rceil\)번이면 끝난다.
  4. 작은 입력은 믿지 않는다
    입력이 작으면 고정 비용이 커서 비가 흐려진다. 충분히 큰 입력으로 잰다.

흔한 실수

  • 입력이 4배면 어느 알고리즘이든 시간이 4배라고 보는 것.
  • 정렬되지 않은 자료에 이진 탐색을 쓰는 것.

바로 풀어보기

(가) \(O(n^2)\) 알고리즘이 \(n = 1000\)에서 0.5초 걸린다. \(n = 4000\)이면? (나) 정렬된 자료 100만 개에서 이진 탐색은 최대 몇 번 비교하나요?

답과 풀이

답: (가) 약 8초 (나) 20번

(가) 입력이 4배이므로 시간은 \(4^2 = 16\)배, \(0.5\times16 = 8\)초이다. \(O(n\log n)\)이었다면 \(4\times\frac{\log4000}{\log1000} \approx 4.8\)배, 약 2.4초이다.

(나) \(2^{20} = 1{,}048{,}576 > 10^6\)이므로 20번이면 충분하다. 선형 탐색은 최대 100만 번이다.

이 요령으로 풀리는 문제

  • 컴퓨터의 자료 표현과 과학 계산 단원 연습 5번, 7번
영상 콘티 · 40초
  1. 0~5초입력 크기 \(n\)을 2배씩 늘리는 버튼과 스톱워치 네 개(선형, 제곱, 로그, \(n\log n\))가 보인다.입력이 두 배면 시간은?
  2. 5~14초버튼을 누를 때마다 선형 스톱워치는 2배, 제곱은 4배, 로그는 한 칸만 늘어난다.두 배 규칙으로 계산량을 읽는다.
  3. 14~23초\(n = 1000\)에서 0.5초인 제곱 알고리즘의 막대가 \(n = 4000\)에서 16배로 솟아 8초가 된다.\(k\)배면 \(k^2\)배.
  4. 23~33초100만 개의 칸이 반으로 접히기를 20번 반복하며 칸 하나만 남는다.이진 탐색은 반으로 접는 횟수.
  5. 33~40초작은 \(n\)에서 막대들이 거의 같은 높이로 섞여 있어 '?'가 뜬다.충분히 큰 입력으로 잰다.
