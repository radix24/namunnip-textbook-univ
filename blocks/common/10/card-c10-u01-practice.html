파이썬 시작하기 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산다음 식의 값을 실행하기 전에 예측하고, 파이썬으로 확인하세요. 7 // 2, 7 % 2, -7 // 2, 2 ** 10, "ab" * 3, int("42") + 1 [01-01]

    힌트 1

    //는 몫(아래로 내림), %는 나머지, **는 거듭제곱입니다.

    힌트 2

    -7 // 2는 −3.5를 아래로 내린 값입니다. 문자열에 정수를 곱하면 반복됩니다.

    풀이

    3, 1, -4, 1024, 'ababab', 43.

    -7 // 2가 −3이 아니라 −4인 것에 주의하세요. 파이썬의 //는 0 쪽이 아니라 작은 쪽(음의 무한대 쪽)으로 내립니다. C의 정수 나눗셈은 0 쪽으로 버려 -7 / 2가 −3입니다(4.1절).

  2. 실습섭씨 온도를 입력받아 화씨로 바꿔 소수 첫째 자리까지 출력하는 프로그램을 쓰세요. 입력 36.5에 대해 36.5 C = 97.7 F가 나와야 합니다. [01-01]

    힌트 1

    input()은 문자열을 돌려주므로 float()로 바꿔야 계산할 수 있습니다.

    힌트 2

    f-문자열 f"{x:.1f}"는 소수 첫째 자리까지 씁니다. 화씨 = 섭씨 × 9/5 + 32.

    풀이 
    c = float(input("섭씨 온도: "))
f = c * 9 / 5 + 32
print(f"{c:.1f} C = {f:.1f} F")

    float()를 빼먹으면 "36.5" * 9에서 오류가 나거나(문자열 × 정수는 반복) 엉뚱한 결과가 나옵니다.

  3. 계산s = "Python"일 때 s[0], s[-1], s[1:4], s[::-1], len(s)의 값을 쓰세요. [01-01]

    힌트 1

    인덱스는 0부터 시작하고, 음수 인덱스는 끝에서부터 셉니다.

    힌트 2

    슬라이스 s[a:b]는 a부터 b 바로 앞까지, [::-1]은 거꾸로입니다.

    풀이

    'P', 'n', 'yth', 'nohtyP', 6. 슬라이스의 끝 번호(4)는 포함되지 않습니다. 그래서 s[1:4]의 길이는 \(4 - 1 = 3\)입니다.

  4. 실습연도를 입력받아 윤년인지 출력하는 프로그램을 쓰세요. 4로 나누어떨어지면 윤년이지만, 100으로 나누어떨어지면 평년이고, 400으로 나누어떨어지면 다시 윤년입니다. 1900, 2000, 2023, 2024로 확인하세요. [01-02]

    힌트 1

    조건을 그대로 논리식으로 옮깁니다: 4의 배수 그리고 (100의 배수가 아님 또는 400의 배수).

    힌트 2

    y % 4 == 0 and (y % 100 != 0 or y % 400 == 0).

    풀이 
    y = int(input("연도: "))
if y % 4 == 0 and (y % 100 != 0 or y % 400 == 0):
    print(y, "윤년")
else:
    print(y, "평년")

    1900 평년, 2000 윤년, 2023 평년, 2024 윤년. 괄호를 빼면 and가 or보다 먼저 계산되어 1900이 윤년으로 나옵니다. 경계에 있는 값(1900, 2000)으로 시험해야 이런 잘못을 찾을 수 있습니다.

  5. 개념x = 3과 x == 3의 차이를 말하세요. 또 bool("0")과 bool("")의 값은 무엇인가요? [01-02]

    힌트 1

    하나는 값을 넣는 문장(대입), 하나는 참·거짓을 돌려주는 식(비교)입니다.

    힌트 2

    빈 문자열, 0, 빈 리스트는 거짓으로, 그 밖의 값은 참으로 봅니다.

    풀이

    x = 3은 x에 3을 넣고, x == 3은 x가 3인지 물어 True나 False를 돌려줍니다. 파이썬은 if x = 3:을 문법 오류로 막아 줍니다. bool("0")은 True(글자가 하나 있는 문자열), bool("")은 False입니다.

  6. 판단한 학생이 if 0.1 + 0.2 == 0.3:으로 검사했더니 False가 나와서 “파이썬의 덧셈이 고장 났다”고 합니다. 무엇이 문제이고 어떻게 고쳐야 하나요? [01-02]

    힌트 1

    print(0.1 + 0.2)를 실행해 보세요.

    힌트 2

    컴퓨터는 0.1을 이진수로 정확히 나타내지 못합니다(6.1절).

    풀이

    덧셈은 고장 나지 않았습니다. 0.1과 0.2가 이진수로 근삿값만 저장되어 합이 0.30000000000000004가 됩니다. 실수는 ==로 비교하지 말고 math.isclose(0.1 + 0.2, 0.3)이나 abs(a - b) < 1e-9처럼 오차를 허용해 비교합니다.
