for 문과 while 문

본문
이 절에서 배울 것
  • for와 range로 정해진 횟수만큼 되풀이한다.
  • while로 조건이 참인 동안 되풀이하고, break와 continue를 쓴다.
먼저 알아야 할 것
  • if 문 (1.2절), 리스트 (2.1절).

2.3.1for 문

for 변수 in 묶음:은 묶음(리스트, 문자열, range 등)의 값을 하나씩 변수에 넣으며 들여 쓴 부분을 되풀이합니다.

  • range(5): 0, 1, 2, 3, 4.
  • range(1, 6): 1~5 (끝은 포함하지 않음).
  • range(10, 0, -2): 10, 8, 6, 4, 2.
total = 0
for i in range(1, 101):
    total += i
print(total)       # 5050

for i, t in enumerate([20.1, 20.6, 21.3]):
    print(i, t)    # 번호와 값을 함께

반복문 안에 반복문을 넣으면(중첩) 표 같은 2차원 자료를 다룰 수 있습니다. 바깥이 \(m\)번, 안쪽이 \(n\)번이면 안쪽 몸체는 \(mn\)번 실행됩니다.

2.3.2while 문

몇 번 되풀이할지 미리 모를 때는 while 조건:을 씁니다. 몸체 안에서 조건이 언젠가 거짓이 되도록 값을 바꿔야 하며, 그렇지 않으면 끝나지 않습니다(무한 반복, Ctrl+C로 멈춤).

예제 2.3.1

예금 100만 원이 연 5% 복리로 200만 원 이상이 되는 데 몇 년 걸리는가?

money, year = 100, 0
while money < 200:
    money *= 1.05
    year += 1
print(year, round(money, 1))     # 15 207.9

2.3.3break와 continue

  • break: 반복을 곧바로 끝낸다.
  • continue: 이번 차례의 나머지를 건너뛰고 다음 차례로.
for n in range(2, 50):
    if n % 7 == 0 and n % 5 == 3:
        print("찾음:", n)       # 28
        break

반복이 어떻게 진행되는지 헷갈리면 변수 값을 줄마다 표로 적어 보는 것(추적)이 가장 좋은 방법입니다. 아래 실습 카드에서 한 줄씩 따라가 볼 수 있습니다.

요약
  1. for x in 묶음:, range(시작, 끝, 간격)은 끝을 포함하지 않는다.
  2. while 조건:은 조건이 거짓이 될 때까지. 무한 반복 주의.
  3. break는 끝내기, continue는 건너뛰기.
