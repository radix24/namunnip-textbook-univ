for 문과 while 문

본문

1부터 100까지 더하는 줄을 100번 쓸 수는 없다. 또 예금이 200만 원이 될 때까지 해마다 이자를 붙이려면, 몇 번 되풀이할지 미리 알 수도 없다. 정해진 횟수만큼, 또는 조건이 맞는 동안 같은 일을 되풀이하게 하려면 어떻게 쓸까?

먼저 알아야 할 것if 문(1.2절)과 리스트(2.1절)를 쓴다.

2.3.1for 문

정해진 횟수의 되풀이는 for 문으로 쓴다. for 변수 in 묶음:은 묶음(리스트, 문자열, range 등)의 값을 하나씩 변수에 넣으며 들여 쓴 부분을 되풀이한다. 수를 차례로 만드는 range는 세 꼴로 쓴다. range(5)는 0, 1, 2, 3, 4이고, range(1, 6)은 1부터 5까지로 끝은 포함하지 않는다. 또 range(10, 0, -2)는 10, 8, 6, 4, 2이다.

total = 0
for i in range(1, 101):
    total += i
print(total)       # 5050

for i, t in enumerate([20.1, 20.6, 21.3]):
    print(i, t)    # 번호와 값을 함께

반복문 안에 반복문을 넣으면(중첩) 표 같은 2차원 자료를 다룰 수 있다. 이때 바깥이 \(m\)번, 안쪽이 \(n\)번이면 안쪽 몸체는 \(mn\)번 실행된다.

2.3.2while 문

처음 질문의 둘째 경우처럼 몇 번 되풀이할지 미리 모를 때는 while 조건:을 쓴다. 그런데 몸체 안에서 조건이 언젠가 거짓이 되도록 값을 바꿔야 한다. 그렇지 않으면 끝나지 않으며, 이것을 무한 반복이라 한다(Ctrl+C로 멈춤).

예제 2.3.1

예금 100만 원이 연 5% 복리로 200만 원 이상이 되는 데 몇 년 걸리는가?

풀이. 200보다 작은 동안 1.05를 곱하고 해를 센다.

money, year = 100, 0
while money < 200:
    money *= 1.05
    year += 1
print(year, round(money, 1))     # 15 207.9

즉 15년이 걸린다. 그림 1에서 되풀이한 횟수를 15까지 올리면 마지막 막대가 처음으로 200을 넘는다.

2.3.3break와 continue

반복 도중에 흐름을 바꾸는 명령도 있다. break는 반복을 곧바로 끝내고, continue는 이번 차례의 나머지를 건너뛰고 다음 차례로 간다.

for n in range(2, 50):
    if n % 7 == 0 and n % 5 == 3:
        print("찾음:", n)       # 28
        break

반복이 어떻게 진행되는지 헷갈리면 변수 값을 줄마다 표로 적어 보는 것, 곧 추적이 가장 좋은 방법이다.

마무리

정해진 횟수의 되풀이는 for x in 묶음:으로 쓰며, range(시작, 끝, 간격)은 끝을 포함하지 않는다. 처음 질문처럼 횟수를 모르면 while 조건:을 쓰되 무한 반복에 주의하고, break로 끝내거나 continue로 건너뛴다.
