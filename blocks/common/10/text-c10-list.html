2.1.1리스트 만들기와 인덱스

실험값 여러 개를 변수 하나로 다루려면 리스트를 씁니다. 대괄호 안에 쉼표로 값을 늘어놓습니다.

T = [20.1, 20.5, 21.3, 22.0, 22.8]   # 온도 측정값
print(T[0])      # 20.1  첫째 (번호는 0부터)
print(T[-1])     # 22.8  마지막
print(len(T))    # 5
T[1] = 20.6      # 값 바꾸기

길이가 5이면 쓸 수 있는 인덱스는 0~4(또는 −5~−1)이고, T[5]는 IndexError입니다.

2.1.2슬라이스

a[시작:끝:간격]은 시작부터 끝 바로 앞까지 간격마다 골라 새 리스트를 만듭니다. 생략하면 처음, 마지막, 1로 봅니다.

a = [0, 10, 20, 30, 40, 50]
a[1:4]     # [10, 20, 30]
a[:3]      # [0, 10, 20]
a[::2]     # [0, 20, 40]
a[::-1]    # [50, 40, 30, 20, 10, 0]  거꾸로

끝을 빼는 규칙 덕분에 a[:k]와 a[k:]를 이으면 원래 리스트가 되고, a[i:j]의 길이는 j - i입니다.

2.1.3추가, 삭제, 함수

쓰는 법하는 일
a.append(x)끝에 하나 추가
a.insert(i, x)i번 자리에 끼워 넣기
a.pop(), a.pop(i)끝(또는 i번)을 꺼내며 삭제
a.remove(x)값 x를 처음 찾은 곳에서 삭제
x in a들어 있는지 (True/False)
sum(a), max(a), min(a)합, 최댓값, 최솟값
a.sort(), sorted(a)제자리 정렬 / 정렬된 새 리스트
 
T.append(23.5)
mean = sum(T) / len(T)
print(f"평균 {mean:.2f}")
같은 리스트를 가리키는 두 이름. b = a는 리스트를 복사하지 않고 같은 리스트에 이름을 하나 더 붙입니다. b[0] = 99를 하면 a[0]도 바뀝니다. 복사하려면 b = a[:]나 b = a.copy()를 씁니다. 이것은 5.2절의 포인터와 비슷한 생각입니다.
요약
  1. 인덱스는 0부터, 음수는 뒤에서부터.
  2. 슬라이스 a[시작:끝:간격]은 끝을 포함하지 않는다.
  3. append, insert, pop, remove, sum, sorted.
