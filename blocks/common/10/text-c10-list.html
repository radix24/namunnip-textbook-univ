2.1.1리스트 만들기와 인덱스

처음 질문의 묶음이 리스트이다. 대괄호 안에 쉼표로 값을 늘어놓으며, 몇 번째 값은 대괄호 안의 번호, 곧 인덱스로 꺼낸다.

T = [20.1, 20.5, 21.3, 22.0, 22.8]   # 온도 측정값
print(T[0])      # 20.1  첫째 (번호는 0부터)
print(T[-1])     # 22.8  마지막
print(len(T))    # 5
T[1] = 20.6      # 값 바꾸기

길이가 5이면 쓸 수 있는 인덱스는 0~4(또는 −5~−1)이고, T[5]는 IndexError이다.

2.1.2슬라이스

앞의 몇 개만 꺼내는 것은 슬라이스로 한다. a[시작:끝:간격]은 시작부터 끝 바로 앞까지 간격마다 골라 새 리스트를 만든다. 생략하면 시작은 처음, 끝은 마지막, 간격은 1로 본다.

a = [0, 10, 20, 30, 40, 50]
a[1:4]     # [10, 20, 30]
a[:3]      # [0, 10, 20]
a[::2]     # [0, 20, 40]
a[::-1]    # [50, 40, 30, 20, 10, 0]  거꾸로

끝을 빼는 규칙 덕분에 a[:k]와 a[k:]를 이으면 원래 리스트가 되고, a[i:j]의 길이는 j - i이다. 그림 1에서 시작과 끝을 바꿔 보면 빨간 막대 칸은 언제나 빠진다.

2.1.3추가, 삭제, 함수

리스트는 만든 뒤에도 늘리고 줄일 수 있으며, 자주 쓰는 도구는 아래 표와 같다.

쓰는 법하는 일
a.append(x)끝에 하나 추가
a.insert(i, x)i번 자리에 끼워 넣기
a.pop(), a.pop(i)끝(또는 i번)을 꺼내며 삭제
a.remove(x)값 x를 처음 찾은 곳에서 삭제
x in a들어 있는지 (True/False)
sum(a), max(a), min(a)합, 최댓값, 최솟값
a.sort(), sorted(a)제자리 정렬 / 정렬된 새 리스트
 
T.append(23.5)
mean = sum(T) / len(T)
print(f"평균 {mean:.2f}")
흔한 오해b = a가 리스트를 복사한다고 생각하기 쉽다. 하지만 이것은 같은 리스트에 이름을 하나 더 붙일 뿐이다. 그래서 b[0] = 99를 하면 a[0]도 바뀐다. 복사하려면 b = a[:]나 b = a.copy()를 쓴다. 이것은 5.2절의 포인터와 비슷한 생각이다.
마무리

리스트는 여러 값을 한 이름으로 묶으며, 인덱스는 0부터, 음수는 뒤에서부터 센다. 처음 질문처럼 일부만 꺼낼 때는 끝을 포함하지 않는 슬라이스 a[시작:끝:간격]을 쓰고, append, insert, pop, remove, sum, sorted로 늘리고 줄이고 계산한다.
