비교 연산자와 if 문

본문

pH를 입력하면 "산성", "중성", "염기성" 가운데 하나를 알려 주는 프로그램을 만들고 싶다. 지금까지의 프로그램은 위에서 아래로 모든 줄을 실행했다. 조건에 따라 어떤 줄은 실행하고 어떤 줄은 건너뛰게 하려면 어떻게 써야 할까? 그리고 조건이 여러 개면 어느 것이 먼저일까?

먼저 알아야 할 것변수와 자료형(1.1절)을 쓴다.

1.2.1참과 거짓

조건은 참(True)이나 거짓(False)이 되는 식이며, 비교 연산자로 만든다.

연산자뜻예결과
==같다3 == 3.0True
!=다르다"a" != "A"True
< > <= >=크기 비교2 <= 1False

대입 =와 비교 ==를 헷갈리지 않아야 한다. 또 여러 조건은 논리 연산자로 묶는다. and는 둘 다 참일 때 참이고, or는 하나라도 참이면 참이며, not은 참과 거짓을 뒤집는다. 파이썬은 0 < x < 10처럼 비교를 이어 쓸 수도 있으며, 이것은 0 < x and x < 10과 같다.

1.2.2if 문

처음 질문의 방법이 if 문이다. 조건 뒤에 콜론(:)을 쓰고, 조건이 참일 때 실행할 줄들은 같은 칸만큼 들여 쓴다(보통 공백 4칸). 파이썬은 중괄호 대신 들여쓰기로 묶음을 나타내므로, 들여쓰기가 틀리면 오류가 나거나 뜻이 달라진다.

pH = float(input("pH? "))
if pH < 7:
    print("산성")
elif pH == 7:
    print("중성")
else:
    print("염기성")
print("끝")        # 들여쓰지 않았으므로 늘 실행

이때 위에서부터 조건을 차례로 보고 처음 참이 되는 한 곳만 실행한다. 그러므로 범위를 나눌 때는 순서가 중요하다. 그림 1에서 pH를 바꿔 보면 빨간 화살표가 한 갈래로만 내려가고, 들여쓰지 않은 print("끝")은 늘 실행된다.

예제 1.2.1

연도 y가 윤년인지 판별하여라. 윤년은 4로 나누어떨어지되, 100으로 나누어떨어지면 아니고, 400으로 나누어떨어지면 다시 윤년이다.

풀이. 세 조건을 and와 or로 묶으면 다음과 같다.

if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
    print("윤년")
else:
    print("평년")

그러면 2024는 윤년, 1900은 평년, 2000은 윤년이다.

흔한 오해실수도 ==로 비교하면 된다고 생각하기 쉽다. 하지만 0.1 + 0.2 == 0.3은 False이다(6.1절). 그래서 실수는 abs(a - b) < 1e-9처럼 차이가 충분히 작은지로 비교한다.
마무리

조건은 비교 연산자 == != < > <= >=와 논리 연산자 and or not으로 만든다. 처음 질문처럼 조건에 따라 실행할 줄을 고르려면 if / elif / else를 콜론과 들여쓰기로 묶으며, 처음 참인 한 곳만 실행되므로 조건의 순서가 중요하다.
