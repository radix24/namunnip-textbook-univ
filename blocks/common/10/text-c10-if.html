비교 연산자와 if 문

본문
이 절에서 배울 것
  • 비교 연산자와 논리 연산자로 참·거짓을 만든다.
  • if, elif, else로 조건에 따라 다른 코드를 실행한다.
먼저 알아야 할 것
  • 변수와 자료형 (1.1절).

1.2.1참과 거짓

연산자뜻예결과
==같다3 == 3.0True
!=다르다"a" != "A"True
< > <= >=크기 비교2 <= 1False

대입 =와 비교 ==를 헷갈리지 않아야 합니다. 여러 조건은 논리 연산자로 묶습니다.

  • and: 둘 다 참일 때 참.
  • or: 하나라도 참이면 참.
  • not: 참과 거짓을 뒤집는다.

파이썬은 0 < x < 10처럼 비교를 이어 쓸 수 있습니다(0 < x and x < 10과 같음).

1.2.2if 문

조건 뒤에 콜론(:)을 쓰고, 조건이 참일 때 실행할 줄들은 같은 칸만큼 들여 씁니다(보통 공백 4칸). 파이썬은 중괄호 대신 들여쓰기로 묶음을 나타내므로 들여쓰기가 틀리면 오류가 나거나 뜻이 달라집니다.

pH = float(input("pH? "))
if pH < 7:
    print("산성")
elif pH == 7:
    print("중성")
else:
    print("염기성")
print("끝")        # 들여쓰지 않았으므로 늘 실행

위에서부터 조건을 차례로 보고 처음 참이 되는 한 곳만 실행합니다. 그래서 범위를 나눌 때는 순서가 중요합니다.

예제 1.2.1

연도 y가 윤년인지 판별하여라. 윤년은 4로 나누어떨어지되, 100으로 나누어떨어지면 아니고, 400으로 나누어떨어지면 다시 윤년이다.

if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
    print("윤년")
else:
    print("평년")

2024는 윤년, 1900은 평년, 2000은 윤년입니다.

실수 비교 주의. 0.1 + 0.2 == 0.3은 False입니다(6.1절). 실수는 abs(a - b) < 1e-9처럼 차이가 충분히 작은지로 비교합니다.
요약
  1. 비교 == != < > <= >=, 논리 and or not.
  2. if / elif / else, 콜론과 들여쓰기로 묶는다. 처음 참인 한 곳만 실행.
