\(e^{at}\)이 곱해지면 \(s\)를 옮기고, \(u(t - a)\)가 붙으면 \(e^{-as}\)를 곱한다

요령 · 이동 정리

언제 쓰는가

감쇠 진동 \(e^{at}\cos\omega t\)나 늦게 켜지는 입력 \(u(t - a)f(t - a)\)의 변환과 역변환을 구할 때입니다.

요령

  1. 어느 쪽이 옮겨졌나
    \(t\) 쪽에 \(e^{at}\)이 곱해졌으면 \(s\)축 이동(\(s \to s - a\)), \(t\) 쪽이 \(t - a\)로 늦춰졌으면 \(t\)축 이동입니다.
  2. \(s\)축 이동
    \(\mathcal L\{e^{at}f(t)\} = F(s - a)\). 역변환에서는 분모를 완전제곱 \((s - a)^2 + \omega^2\)으로 만들어 찾습니다.
  3. \(t\)축 이동
    \(\mathcal L\{u(t - a)f(t - a)\} = e^{-as}F(s)\). 역변환에서 \(e^{-as}\)를 보면 떼어 두고 나머지를 역변환한 뒤 \(t\)를 \(t - a\)로 바꾸고 \(u(t - a)\)를 붙입니다.
  4. 그래프로 검산
    \(t\)축 이동한 결과는 \(t < a\)에서 0이어야 합니다.

흔한 실수

  • \(e^{-2s}\frac{1}{s^2 + 4}\)의 역변환을 \(u(t - 2)\frac{\sin2t}{2}\)로 써서 \(t\)를 옮기지 않는 것.
  • \(e^{3t}\)이 곱해진 함수의 변환에 \(e^{-3s}\)를 곱하는 것.

바로 풀어보기

(가) \(\mathcal L\{t^2e^{3t}\}\) (나) \(\mathcal L^{-1}\left\{\frac{e^{-2s}}{s^2 + 4}\right\}\)를 구하세요.

답과 풀이

답: (가) \(\frac{2}{(s - 3)^3}\) (나) \(\frac12u(t - 2)\sin(2(t - 2))\)

(가) \(\mathcal L\{t^2\} = \frac{2}{s^3}\)에서 \(s\)를 \(s - 3\)으로 옮겨 \(\frac{2}{(s - 3)^3}\)입니다.

(나) \(e^{-2s}\)를 떼면 \(\mathcal L^{-1}\left\{\frac{1}{s^2 + 4}\right\} = \frac12\sin2t\)이고, \(t\)를 \(t - 2\)로 바꾸고 \(u(t - 2)\)를 붙입니다. \(t < 2\)에서 0입니다.

이 요령으로 풀리는 문제

  • 라플라스 변환 단원 연습 1번, 3번, 5번
영상 콘티 · 45초
  1. 0~5초\(t\)축 그래프와 \(s\)축 그래프 두 창이 위아래로 열립니다.두 가지 이동, 헷갈리지 않는 법.
  2. 5~14초\(t\) 창의 \(t^2\) 곡선에 \(e^{3t}\)가 곱해지자, \(s\) 창의 \(\frac{2}{s^3}\) 그래프가 오른쪽으로 3만큼 미끄러집니다.\(e^{at}\)이 곱해지면 \(s\)가 옮겨 갑니다.
  3. 14~24초\(t\) 창의 사인 곡선이 오른쪽으로 2만큼 밀리고 앞쪽은 0으로 눌립니다(\(u(t - 2)\)). \(s\) 창의 그래프에는 \(e^{-2s}\)가 곱해져 높이가 줄어듭니다.\(t\)가 늦춰지면 \(e^{-as}\)가 곱해집니다.
  4. 24~35초역변환: \(e^{-2s}\) 도장이 떨어져 옆에 놓이고, 나머지가 \(\frac12\sin2t\)로 바뀐 뒤 도장이 다시 찍히며 곡선이 2만큼 밀립니다.떼어 두었다가 마지막에 밀어 줍니다.
  5. 35~45초밀리지 않은 곡선 \(u(t - 2)\sin2t\)가 겹쳐 그려지며 위상이 어긋나 X가 뜹니다.\(t\)도 함께 \(t - a\)로 바꿉니다.
