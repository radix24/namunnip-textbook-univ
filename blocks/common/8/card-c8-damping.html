감쇠 진동: 과감쇠, 임계감쇠, 미감쇠

mx″ + cx′ + kx = 0 · 판별식 c² − 4mk · 자동차 충격흡수기

왜 필요한가

공통3의 용수철 진자는 영원히 진동했지만, 실제 진동은 마찰과 공기 저항으로 멈춘다. 저항이 얼마나 센지에 따라 "흔들리며 멈추는지", "흔들리지 않고 멈추는지"가 갈린다. 문이 쾅 닫히지 않게 하는 도어 클로저, 자동차가 과속방지턱을 넘은 뒤 출렁이지 않게 하는 충격흡수기의 설계가 이 구분에 달려 있다.

정의

속도에 비례하는 저항(\(-cx'\))이 있는 진동 \(mx'' + cx' + kx = 0\). 특성근 \(r = \frac{-c \pm\sqrt{c^2 - 4mk}}{2m}\).

과감쇠 \(c^2 > 4mk\), 임계감쇠 \(c^2 = 4mk\), 미감쇠 \(c^2 < 4mk\).

정의를 풀어 읽기

  1. 미감쇠복소근 \(-\frac{c}{2m} \pm i\omega_d\), \(\omega_d = \sqrt{\frac km - \frac{c^2}{4m^2}}\). 해 \(e^{-ct/2m}(A\cos\omega_dt + B\sin\omega_dt)\): 진폭이 지수적으로 줄며 진동. 진동수는 감쇠 없는 \(\omega_0 = \sqrt{k/m}\)보다 조금 작다.
  2. 임계감쇠중근 \(-\frac{c}{2m}\). 해 \((A + Bt)e^{-ct/2m}\): 진동 없이 가장 빨리 평형으로 돌아옴(평형을 많아야 한 번 지남).
  3. 과감쇠음의 실근 두 개. 해는 두 지수의 합으로 진동 없이 천천히 돌아옴. 저항이 너무 세서 오히려 느립니다(꿀 속의 용수철).
  4. 에너지\(\frac{d}{dt}\left(\frac12mx'^2 + \frac12kx^2\right) = -cx'^2 \le 0\). 저항이 에너지를 빼앗아 간다.

예와 반례

  • 예: \(m = 1\) kg, \(k = 100\) N/m이면 임계 감쇠 계수 \(c_c = 2\sqrt{mk} = 20\) N·s/m. \(c = 4\)이면 미감쇠, \(\omega_d = \sqrt{100 - 4} = 9.80\) rad/s (\(\omega_0 = 10\)), 진폭이 \(e^{-2t}\)로 줄어 약 0.35초마다 절반.
  • 예(설계): 자동차 충격흡수기는 임계보다 조금 약하게(감쇠비 약 0.2~0.4) 설계해 승차감과 빠른 안정을 맞춘다. 측정 기기의 바늘은 임계 근처로 맞춰 빨리, 흔들림 없이 값을 보여 준다.
  • 반례(감쇠가 0): \(c = 0\)이면 공통3 6-01의 단순 조화 운동. 실제로는 아무리 작아도 \(c > 0\)이라 언젠가 멈춘다.

다른 개념과의 관계

공통4 5-03의 LC 회로에 저항을 넣은 RLC 회로가 같은 방정식입니다(3-03 카드). 감쇠비 \(\zeta = \frac{c}{2\sqrt{mk}}\)로 쓰면 \(\zeta = 1\)이 임계이다. 5단원에서 이 방정식을 연립 일계로 바꾸면, 미감쇠는 위상 평면의 안정 나선점, 과감쇠는 안정 마디가 된다.
