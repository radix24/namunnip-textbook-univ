푸리에 계수는 함수가 짝함수인지 홀함수인지부터 보고 0이 되는 계수를 지운다

요령 · 푸리에 급수

언제 쓰는가

주기 함수의 푸리에 급수를 구하는 문제이다. 적분이 길어 보일 때 계산량을 반으로 줄이려고 쓴다.

요령

  1. 대칭을 본다
    \(f(-x) = f(x)\)면 짝함수, \(f(-x) = -f(x)\)면 홀함수이다. 상수를 빼면 홀함수가 되는 경우도 본다.
  2. 반을 지운다
    짝함수는 \(b_n = 0\)(코사인만), 홀함수는 \(a_n = 0\)(사인만)이다.
  3. 반 구간 적분
    남은 계수는 \(a_n = \frac2\pi\int_0^\pi f\cos nx\,dx\) 또는 \(b_n = \frac2\pi\int_0^\pi f\sin nx\,dx\)로 반 구간만 적분한다.
  4. 특정 점에 넣어 덤 얻기
    연속인 점에 \(x\)를 넣으면 수열의 합(\(\sum\frac1{n^2}\) 등)이 나온다. 불연속점에서는 양쪽 극한의 평균으로 수렴한다.

흔한 실수

  • 짝함수인데 \(b_n\)까지 적분해 시간을 쓰고 부호 실수를 하는 것.
  • \(a_0\)의 정의(\(\frac1{2\pi}\int\)인지 \(\frac1\pi\int\)인지)를 교재와 다르게 쓰는 것.

바로 풀어보기

\(f(x) = x^2\) (\(-\pi < x < \pi\), 주기 \(2\pi\))의 푸리에 급수를 구하고, \(x = \pi\)를 넣어 \(\sum\frac{1}{n^2}\)을 구하여라.

답과 풀이

답: \(x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n}{n^2}\cos nx\), \(\sum\frac1{n^2} = \frac{\pi^2}{6}\)

짝함수이므로 사인 항이 없다. 상수항(평균)은 \(\frac1\pi\int_0^\pi x^2dx = \frac{\pi^2}{3}\), \(a_n = \frac2\pi\int_0^\pi x^2\cos nx\,dx = \frac{4(-1)^n}{n^2}\)입니다(부분적분 두 번).

\(x = \pi\)에서 함수는 연속(\(\pi^2\))이고 \(\cos n\pi = (-1)^n\)이므로 \(\pi^2 = \frac{\pi^2}{3} + 4\sum\frac1{n^2}\), \(\sum\frac1{n^2} = \frac{\pi^2}{6}\)이다.

이 요령으로 풀리는 문제

  • 푸리에 급수 단원 연습 1번, 2번, 3번, 6번
영상 콘티 · 45초
  1. 0~5초주기적으로 이어진 포물선 \(x^2\) 그래프가 그려진다.푸리에 계수, 다 계산해야 할까?
  2. 5~13초그래프가 \(y\)축을 거울로 접히며 양쪽이 꼭 겹친다. '짝함수' 도장.먼저 대칭을 본다.
  3. 13~21초사인 곡선들이 그래프 위에 겹쳐지자 왼쪽과 오른쪽 넓이가 서로 지워져 0이 되고, \(b_n\) 칸이 모두 비워진다.짝함수는 사인 계수가 0.
  4. 21~31초남은 코사인 곡선들이 하나씩 더해지며 포물선을 점점 닮아 간다.코사인만으로 충분하다.
  5. 31~45초\(x = \pi\)에 세로선이 그어지고 급수에 \(\pi\)가 들어가 \(\sum\frac1{n^2} = \frac{\pi^2}{6}\)이 튀어나온다.점 하나를 넣으면 덤으로 수열의 합이 나온다.
