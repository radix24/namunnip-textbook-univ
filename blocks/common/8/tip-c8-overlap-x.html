미정계수법은 추측한 꼴이 동차해와 겹치는지 먼저 보고, 겹치면 \(x\)를 곱한다

요령 · 미정계수법

언제 쓰는가

우변이 \(e^{ax}\), 다항식, \(\sin\), \(\cos\)인 상수계수 비동차 방정식의 특수해를 구할 때이다. 대입했더니 '0 = 우변'이 되어 막힐 때 쓴다.

요령

  1. 동차해를 먼저
    특성방정식으로 동차해를 구해 둔다.
  2. 우변의 꼴로 추측
    \(e^{ax} \to Ae^{ax}\), \(x^2 \to Ax^2 + Bx + C\), \(\cos\beta x \to A\cos\beta x + B\sin\beta x\).
  3. 겹침 검사
    추측의 어느 항이 동차해와 같으면 \(x\)를 곱한다. 중근과 겹치면 \(x^2\)을 곱한다.
  4. 대입하고 초기 조건은 마지막
    계수를 비교해 특수해를 정한 뒤, 일반해 = 동차해 + 특수해에 초기 조건을 넣는다.

흔한 실수

  • 겹치는데 그대로 대입해 \(0 = e^x\) 같은 모순을 얻고 '특수해가 없다'고 하는 것.
  • 동차해에만 초기 조건을 넣고 특수해를 나중에 더하는 것.

바로 풀어보기

\(y'' - 3y' + 2y = e^x\)의 특수해를 구하여라.

답과 풀이

답: \(y_p = -xe^x\)

특성근은 1, 2이므로 동차해는 \(c_1e^x + c_2e^{2x}\)이다. 우변 \(e^x\)가 동차해와 겹치므로 \(y_p = Axe^x\)로 둔다.

\(y_p' = A(1 + x)e^x\), \(y_p'' = A(2 + x)e^x\)를 넣으면 \(A[(2 + x) - 3(1 + x) + 2x]e^x = -Ae^x = e^x\), \(A = -1\)이다.

이 요령으로 풀리는 문제

  • 2계 선형 상미분방정식 단원 연습 2번, 3번, 6번
영상 콘티 · 45초
  1. 0~5초\(y'' - 3y' + 2y = e^x\) 옆에 추측 \(Ae^x\)가 날아온다.\(Ae^x\)로 추측하면?
  2. 5~13초\(Ae^x\)를 넣자 식이 \(0 = e^x\)로 무너지며 빨간 경고가 뜬다.대입하니 모순이 나온다.
  3. 13~22초동차해 \(c_1e^x + c_2e^{2x}\)가 위에 나타나고, \(e^x\) 항과 추측의 \(e^x\)가 같은 색으로 겹쳐 빛난다.추측이 동차해와 겹쳤다.
  4. 22~31초추측 앞에 \(x\)가 날아와 붙어 \(Axe^x\)가 된다.겹치면 \(x\)를 곱한다.
  5. 31~40초대입하자 \(x\)가 든 항들이 지워지고 \(-Ae^x = e^x\)만 남아 \(A = -1\)이 나온다.이번에는 계수가 정해진다.
  6. 40~45초중근인 경우의 예에서 \(x^2\)이 붙는 모습이 짧게 나온다.중근과 겹치면 \(x^2\).
