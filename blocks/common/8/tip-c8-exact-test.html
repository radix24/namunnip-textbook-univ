완전형인지는 \(M_y = N_x\)로 보고, 아니면 \(\frac{M_y - N_x}{N}\)이 \(x\)만의 함수인지 본다

요령 · 완전 미분방정식

언제 쓰는가

\(M\,dx + N\,dy = 0\) 꼴의 1계 방정식이 변수분리도 선형도 아닐 때입니다.

요령

  1. 완전형 검사
    \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\)이면 완전형이라 퍼텐셜 \(F\)가 있습니다.
  2. 아니면 적분인자
    \(\frac{M_y - N_x}{N}\)이 \(x\)만의 함수면 \(\mu(x) = e^{\int\frac{M_y - N_x}{N}dx}\), \(\frac{N_x - M_y}{M}\)이 \(y\)만의 함수면 \(\mu(y)\)입니다.
  3. 퍼텐셜을 찾는다
    \(F = \int M\,dx + g(y)\)로 두고 \(F_y = N\)과 맞춰 \(g\)를 정합니다.
  4. 해는 \(F = C\)
    해는 음함수 \(F(x, y) = C\)입니다. \(y\)에 대해 풀리지 않아도 됩니다.

흔한 실수

  • 적분인자를 곱한 뒤 완전형인지 다시 확인하지 않는 것.
  • \(F\)를 구할 때 \(g(y)\)를 빠뜨려 \(F_y \ne N\)이 되는 것.

바로 풀어보기

\((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\)을 푸세요.

답과 풀이

답: \(x^3y + \frac12x^2y^2 = C\)

\(M_y = 3x + 2y\), \(N_x = 2x + y\)로 다르므로 완전형이 아닙니다. \(\frac{M_y - N_x}{N} = \frac{x + y}{x(x + y)} = \frac1x\)이 \(x\)만의 함수이므로 \(\mu = x\)입니다.

곱하면 \((3x^2y + xy^2)dx + (x^3 + x^2y)dy = 0\)이고 \(M_y = 3x^2 + 2xy = N_x\)로 완전형입니다. \(F = x^3y + \frac12x^2y^2 + g(y)\), \(F_y = x^3 + x^2y + g' = N\)에서 \(g' = 0\)입니다.

이 요령으로 풀리는 문제

  • 1계 상미분방정식 단원 연습 4번
영상 콘티 · 40초
  1. 0~5초\(M\,dx + N\,dy = 0\) 꼴의 식이 나타나고 \(M\), \(N\)에 각각 색이 칠해집니다.이 방정식은 완전형일까요?
  2. 5~13초\(M\)에서 \(\partial_y\) 화살표, \(N\)에서 \(\partial_x\) 화살표가 내려와 \(3x + 2y\)와 \(2x + y\)가 나란히 섭니다. ≠ 표시.\(M_y\)와 \(N_x\)를 비교합니다.
  3. 13~22초두 식의 차 \(x + y\)가 \(N = x(x + y)\)로 나뉘어 \(\frac1x\)만 남습니다. '\(x\)만의 함수' 도장.차를 \(N\)으로 나눠 봅니다.
  4. 22~31초\(\mu = x\)가 식 전체에 곱해지고, 다시 비교하니 = 표시가 뜹니다.적분인자를 곱하면 완전형.
  5. 31~40초등고선 지도 위에 \(F = x^3y + \frac12x^2y^2\)의 등고선들이 그려지고 '해 = 등고선' 이름표가 붙습니다.해는 퍼텐셜의 등고선입니다.
