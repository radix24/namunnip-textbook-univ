고계 선형 상미분방정식

본문

양 끝이 고정된 보의 처짐은 4계 방정식 \(EIy'''' = w\)를 따르고, 전기 회로를 여러 단 이으면 3계, 4계 방정식이 나온다. 2계에서 쓴 특성방정식, 기저, 미정계수법은 계가 더 높아져도 그대로 쓸 수 있을까?

먼저 알아야 할 것상수계수 동차 방정식(2.2절), 론스키안(2.5절), 미정계수법(2.6절)을 쓴다.

8.1.1일반해와 기저

\(n\)계 선형 방정식은 \(y^{(n)} + p_{n-1}(x)y^{(n-1)} + \cdots + p_1(x)y' + p_0(x)y = r(x)\)이다. 계수 \(p_k\)와 \(r\)가 구간에서 연속이면, 초기 조건 \(y(x_0)\), \(y'(x_0)\), …, \(y^{(n-1)}(x_0)\)를 \(n\)개 주었을 때 해가 하나뿐이다. 그러므로 동차 방정식(\(r = 0\))의 일반해는 일차독립인 해 \(n\)개, 곧 기저 \(y_1, \dots, y_n\)의 일차결합 \(c_1y_1 + \cdots + c_ny_n\)이다. 처음 질문의 첫째 답이 여기 있다. 2계에서 기저가 둘이었던 것이 \(n\)계에서는 \(n\)개로 늘어날 뿐이다.

이때 해들이 일차독립인지는 \(n \times n\) 론스키안 \(W = \det[y_j^{(i)}]\)로 판정한다. 해들의 론스키안은 한 점에서라도 0이 아니면 구간 전체에서 0이 아니고, 그때 해들이 기저이다. 또 비동차 방정식의 일반해는 2계와 같이 동차 일반해에 특수해 하나를 더한 \(y = y_h + y_p\)이다.

8.1.2상수계수 방정식

계수가 상수이면 \(y = e^{\lambda x}\)를 넣어 \(n\)차 특성방정식 \(\lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_0 = 0\)을 얻는다. 근이 서로 다른 실수이면 \(e^{\lambda_1x}, \dots, e^{\lambda_nx}\)가 기저이다. 그런데 근 \(\lambda\)가 \(m\)중근이면 \(e^{\lambda x}, xe^{\lambda x}, \dots, x^{m-1}e^{\lambda x}\)의 \(m\)개를 기저로 쓴다. 또 복소근 \(\alpha \pm i\omega\)는 2계와 같이 \(e^{\alpha x}\cos\omega x\), \(e^{\alpha x}\sin\omega x\)를 주며, 중복되면 여기에 \(x\)의 거듭제곱을 곱한다. 이렇게 하면 근의 중복도를 모두 더한 \(n\)개의 기저가 나온다.

그림 1에서 방정식을 바꿔 가며 보면 이 규칙이 한눈에 들어온다. 가령 \(y''' + y' = 0\)은 근 0과 \(\pm i\)에서 \(1\), \(\cos x\), \(\sin x\)를 얻는다. 그리고 처음 질문의 보 방정식 \(y'''' = 0\)은 4중근 0이라 \(1, x, x^2, x^3\)이 기저이므로, 동차해는 3차 다항식이다.

다만 3차 이상의 특성방정식은 근의 공식으로 풀기 어려우므로, 정수 근을 대입해 찾고 인수분해하거나 수치적으로 근을 구한다. 한편 비동차 방정식의 특수해는 미정계수법을 그대로 쓴다. 이때 \(r(x)\)의 지수가 \(m\)중근과 겹치면 시험 함수에 \(x^m\)을 곱한다. 그리고 미정계수법이 맞지 않는 \(r(x)\)에는 2계의 매개변수변환법을 \(n\)개 함수로 넓혀 크라메르 공식으로 푼다. 즉 처음 질문의 셋째 도구도 그대로 쓰인다.

예제 8.1.1

\(y''' - y'' - y' + y = 0\), \(y(0) = 2\), \(y'(0) = 1\), \(y''(0) = 0\)을 풀어라.

풀이. 특성방정식은 \(\lambda^3 - \lambda^2 - \lambda + 1 = \lambda^2(\lambda - 1) - (\lambda - 1) = (\lambda - 1)^2(\lambda + 1)\)이다. 따라서 일반해는 \(y = (c_1 + c_2x)e^x + c_3e^{-x}\)이다. 초기 조건을 넣으면 \(c_1 + c_3 = 2\), \(c_1 + c_2 - c_3 = 1\), \(c_1 + 2c_2 + c_3 = 0\)이다. 첫째와 셋째 식에서 \(c_2 = -1\)이고, 그러면 둘째 식에서 \(c_1 - c_3 = 2\)이므로 \(c_1 = 2\), \(c_3 = 0\)이다. 즉 \(y = (2 - x)e^x\)이다.

그림 1의 첫 방정식에서 굵은 검은 곡선이 이 해이다. 초기 조건이 \(e^{-x}\)의 몫을 0으로 만들어, 해는 중근이 준 두 기저 \(e^x\)와 \(xe^x\)만으로 이루어진다. 그래서 \(x = 2\)에서 0을 지난 뒤 음수로 커진다.

마무리

\(n\)계 선형 방정식의 동차 일반해는 기저 \(n\)개의 일차결합이고, 기저인지는 \(n \times n\) 론스키안으로 판정한다. 처음 질문처럼 상수계수이면 2계의 도구가 그대로 넓어져, \(n\)차 특성방정식의 근으로 기저를 만들고 \(m\)중근에는 \(x^ke^{\lambda x}\)(\(k < m\))를 쓴다. 비동차 방정식은 미정계수법이나 매개변수변환법으로 특수해를 구해 더한다.

8.1.3연습문제

기본

  1. \(y'''' - y = 0\)의 일반해를 구하여라.
    답

    \(\lambda^4 - 1 = (\lambda^2 - 1)(\lambda^2 + 1)\)이므로 \(y = c_1e^x + c_2e^{-x} + c_3\cos x + c_4\sin x\).

응용

  1. \(y''' - 3y'' + 3y' - y = e^x\)의 특수해 꼴을 정하고 구하여라.
    답

    특성근 1이 3중근이라 시험 함수는 \(Cx^3e^x\)이다. 대입하면 \(6C = 1\)이므로 \(y_p = \frac16x^3e^x\).
