Frobenius 방법: 정칙 특이점 근처의 해

y = x^r Σ aₙxⁿ · 지표방정식 · 정칙 특이점 판정

정칙 특이점과 방법

\(y'' + p(x)y' + q(x)y = 0\)에서 \(p\)나 \(q\)가 \(x = 0\)에서 터지지만 \(xp(x)\), \(x^2q(x)\)는 해석적이면 \(x = 0\)은 정칙 특이점입니다. Euler-Cauchy 방정식(02-04 카드)이 대표적인 예이고, 그 해 \(x^m\)처럼 거듭제곱이 정수가 아닐 수 있습니다. 그래서 \(y = x^r\sum_{n=0}^\infty a_nx^n\) (\(a_0 \ne 0\))로 추측합니다.

가장 낮은 거듭제곱의 계수에서 지표방정식 \(r(r - 1) + p_0r + q_0 = 0\) (\(p_0 = \lim xp\), \(q_0 = \lim x^2q\))이 나옵니다. 근 \(r_1 \ge r_2\)에 대해 \(r_1\)으로는 늘 해가 하나 있고, \(r_1 - r_2\)가 정수가 아니면 \(r_2\)로 둘째 해가 있습니다(정수이면 로그 항이 생길 수 있음).

\(2xy'' + y' + y = 0\)의 \(x = 0\) 근처 해를 Frobenius 방법으로 구하세요.

풀이

  1. 정규화: \(p = \frac{1}{2x}\), \(q = \frac{1}{2x}\). \(xp = \frac12\), \(x^2q = \frac x2\)는 해석적: 정칙 특이점. \(p_0 = \frac12\), \(q_0 = 0\).
    판정.
  2. 지표방정식 \(r(r - 1) + \frac12r = 0\), \(r\left(r - \frac12\right) = 0\). \(r = \frac12, 0\). 차가 정수가 아니라 두 해 모두 급수꼴.
    \(r^2 - \frac r2 = 0\).
  3. \(y = \sum a_nx^{n+r}\)을 넣으면 \(\sum2(n + r)(n + r - 1)a_nx^{n+r-1} + \sum(n + r)a_nx^{n+r-1} + \sum a_nx^{n+r} = 0\). 앞 두 합을 묶으면 \(\sum(n + r)(2n + 2r - 1)a_nx^{n+r-1}\).
    대입.
  4. \(x^{n+r}\)의 계수: \((n + 1 + r)(2n + 2r + 1)a_{n+1} + a_n = 0\), \(a_{n+1} = -\frac{a_n}{(n + 1 + r)(2n + 2r + 1)}\).
    지표 옮김.
  5. \(r = 0\): \(a_{n+1} = -\frac{a_n}{(n+1)(2n+1)}\), \(y_1 = 1 - x + \frac{x^2}{6} - \frac{x^3}{90} + \cdots\). \(r = \frac12\): \(a_{n+1} = -\frac{a_n}{(n + 1)(2n + 3)}\), \(y_2 = x^{1/2}\left(1 - \frac x3 + \frac{x^2}{30} - \cdots\right)\).
    \(a_0 = 1\)로 두고 계산.

의미

\(y_2\)의 \(x^{1/2}\) 같은 비정수 거듭제곱은 보통의 급수로는 나오지 않습니다. 특이점에서 해는 거듭제곱 하나만큼 "망가질" 수 있고, 지표방정식이 그 정도를 알려 줍니다. Bessel 방정식(다음 카드)이 정칙 특이점 \(x = 0\)을 가져 이 방법으로 풉니다. 사실 이 방정식의 해는 \(\cos\sqrt{2x}\), \(\sin\sqrt{2x}\)입니다.

검산

\(\cos\sqrt{2x} = 1 - \frac{2x}{2} + \frac{(2x)^2}{24} - \frac{(2x)^3}{720} + \cdots = 1 - x + \frac{x^2}{6} - \frac{x^3}{90}\). \(y_1\)과 일치합니다. \(\sin\sqrt{2x} = \sqrt2\,x^{1/2}\left(1 - \frac{2x}{6} + \frac{4x^2}{120} - \cdots\right) = \sqrt2\,x^{1/2}\left(1 - \frac x3 + \frac{x^2}{30}\right)\): \(y_2\)의 \(\sqrt2\)배.
