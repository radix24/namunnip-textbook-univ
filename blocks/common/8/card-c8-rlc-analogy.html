질량-용수철 계와 RLC 회로는 같은 방정식이다

대응표 · 감쇠 판정 · 같은 수학, 다른 물리 · 문제 해결 전략

두 방정식

질량-용수철-감쇠기: \(mx'' + cx' + kx = F(t)\) (뉴턴 제2법칙). 직렬 RLC 회로: \(Lq'' + Rq' + \frac1Cq = E(t)\) (Kirchhoff 고리 법칙, 공통4 3-02). 문자만 다른 같은 방정식이다.

역학전기
변위 \(x\)전하 \(q\)
질량 \(m\)인덕턴스 \(L\)
감쇠 계수 \(c\)저항 \(R\)
용수철 상수 \(k\)\(\frac1C\)
외력 \(F(t)\)기전력 \(E(t)\)
문제 해결 전략 · 진동 모형
  1. 계의 방정식을 표준형 \(ay'' + by' + cy = g(t)\)로 세운다(역학: 힘의 합, 전기: 고리 법칙).
  2. 판별식 \(b^2 - 4ac\)로 감쇠의 종류를 정한다.
  3. 과도 응답(동차해)과 정상 상태 응답(특수해)을 따로 구한다.
  4. 필요하면 대응표로 다른 계의 직관을 빌린다.

\(L = 0.5\) H, \(R = 10\ \Omega\), \(C = 0.01\) F인 직렬 RLC 회로의 축전기가 처음에 \(q(0) = 0.1\) C로 충전되어 있고 전류가 0입니다(전원 없음). \(q(t)\)를 구하고, 감쇠의 종류와 같은 행동을 하는 질량-용수철 계를 말하여라.

풀이

  1. \(0.5q'' + 10q' + 100q = 0\), 곧 \(q'' + 20q' + 200q = 0\).
    \(\frac1C = 100\). 2를 곱함.
  2. 판별식 \(400 - 800 < 0\): 미감쇠. \(r = -10 \pm 10i\).
    02-02 카드.
  3. \(q = e^{-10t}(A\cos10t + B\sin10t)\). \(q(0) = A = 0.1\).
    일반해에 초기조건.
  4. \(q'(0) = -10A + 10B = 0\), \(B = 0.1\). \(q(t) = 0.1e^{-10t}(\cos10t + \sin10t)\).
    전류 \(I = q'\)의 초기값 0.

대응하는 역학계: \(m = 0.5\) kg, \(c = 10\) N·s/m, \(k = 100\) N/m 용수철을 0.1 m 당겼다가 놓은 것.

의미

같은 방정식이면 같은 해를 가지므로, 큰 기계 구조물의 진동을 작은 전기 회로로 흉내 내 실험할 수 있었다. 디지털 컴퓨터 이전의 "아날로그 컴퓨터"가 이 원리였다. 하나를 이해하면 다른 하나도 이해한 것이 된다: 저항은 마찰처럼 에너지를 열로 바꾸고, 인덕터는 질량처럼 변화에 저항한다.

검산

감쇠비 \(\zeta = \frac{R}{2}\sqrt{\frac CL} = 5\sqrt{0.02} = 0.707 < 1\): 미감쇠. 진폭이 \(e^{-10t}\)로 줄어 약 0.5초 뒤 0.7% 미만. 차원: \(\frac RL\)은 1/s.
