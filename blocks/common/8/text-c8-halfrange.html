임의 주기, 우함수와 기함수, 반구간 전개

본문

양 끝을 고정한 줄의 처음 모양이나 막대의 처음 온도는 \([0, L]\)에서만 주어진다. 주기 함수도 아니고 \(-L\)부터의 값도 없는데, 푸리에 급수로 나타낼 수 있을까? 나타낸다면 어떤 급수를 골라야 할까?

먼저 알아야 할 것푸리에 급수(6.1절)와 우함수·기함수의 적분(미분적분학(1) 4단원 보충)을 쓴다.

6.2.1주기 \(2L\)

실제 신호의 주기는 \(2\pi\)가 아닌 경우가 대부분이다. 그러므로 \(x\)를 \(\frac{\pi x}{L}\)로 바꾸어 주기 \(2L\)인 함수를 다룬다.

\[f(x) = a_0 + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right),\] \[a_0 = \frac{1}{2L}\int_{-L}^Lf\,dx, \quad a_n = \frac1L\int_{-L}^Lf\cos\frac{n\pi x}{L}dx, \quad b_n = \frac1L\int_{-L}^Lf\sin\frac{n\pi x}{L}dx\]

6.2.2우함수와 기함수

\(f\)가 우함수이면 \(b_n = 0\)이고 푸리에 코사인 급수가 된다. 기함수이면 \(a_0 = a_n = 0\)이고 푸리에 사인 급수가 된다. 이때 적분은 \([0, L]\)에서 두 배로 계산하면 된다. 가령 기함수이면 \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\)이다.

6.2.3반구간 전개

처음 질문의 답은 함수를 \([-L, 0]\)으로 원하는 방식으로 넓혀서 푸리에 급수를 쓰는 것이다. 이 문제는 고등미적분학(2)의 편미분방정식에서 자주 나온다. \(y\)축 대칭으로, 곧 우함수로 넓히면 코사인 급수가 되며 \(a_0 = \frac1L\int_0^Lf\,dx\), \(a_n = \frac2L\int_0^Lf\cos\frac{n\pi x}{L}dx\)이다. 반면 원점 대칭으로, 곧 기함수로 넓히면 사인 급수가 되며 \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\)이다.

예제 6.2.1

\(f(x) = x\) (\(0 < x < L\))의 반구간 사인 급수를 구하여라.

풀이. \(b_n = \frac2L\int_0^Lx\sin\frac{n\pi x}{L}dx\)를 부분적분하면 \(b_n = \frac{2L}{n\pi}(-1)^{n+1}\)이다. 따라서 다음과 같다.

\[x = \frac{2L}{\pi}\left(\sin\frac{\pi x}{L} - \frac12\sin\frac{2\pi x}{L} + \frac13\sin\frac{3\pi x}{L} - \cdots\right) \quad (0 < x < L)\]

양 끝에서 0이 되는 사인 급수는 "양 끝이 고정된" 경계 조건에 잘 맞는다. 그래서 줄의 진동 문제에서는 사인 급수를 쓴다. 그림 1의 처음 상태가 \(L = 1\)인 이 급수이다. 한편 코사인 급수로 바꾸면, 넓힌 함수가 연속이 되어 같은 항 수에서 오차가 훨씬 작다.

마무리

주기 \(2L\)이면 \(nx\) 대신 \(\frac{n\pi x}{L}\)을, 계수 앞의 \(\frac1\pi\) 대신 \(\frac1L\)을 쓴다. 우함수는 코사인 급수, 기함수는 사인 급수가 되며, 처음 질문처럼 \([0, L]\)에서만 주어진 함수는 우함수나 기함수로 넓혀 전개한다(반구간 전개).

6.2.4연습문제

기본

  1. \(f(x) = 1\) (\(0 < x < L\))의 반구간 코사인 급수와 사인 급수를 구하여라.
    답

    코사인 급수는 \(1\)(상수 하나)이고, 사인 급수는 \(\frac4\pi\left(\sin\frac{\pi x}{L} + \frac13\sin\frac{3\pi x}{L} + \cdots\right)\).
