계단 함수와 델타 함수 입력의 응답 구하기

u(t − a) · t축 이동 · δ(t − a) · 충격 응답

도구

  • 계단 함수 \(u(t - a)\): \(t < a\)이면 0, \(t \ge a\)이면 1. 스위치를 켜는 순간. \(\mathcal L\{u(t - a)\} = \frac{e^{-as}}{s}\).
  • \(t\)축 이동: \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\). 시간 지연이 \(e^{-as}\) 곱하기.
  • 델타 함수 \(\delta(t - a)\): 폭 \(\varepsilon\), 높이 \(\frac1\varepsilon\)인 직사각형 펄스(넓이 1)의 \(\varepsilon \to 0\) 극한. 망치로 한 번 치는 순간적인 충격. \(\mathcal L\{\delta(t - a)\} = e^{-as}\).

델타 함수의 변환: 펄스 \(\frac1\varepsilon[u(t - a) - u(t - a - \varepsilon)]\)의 변환 \(e^{-as}\frac{1 - e^{-\varepsilon s}}{\varepsilon s} \to e^{-as}\) (로피탈).

먼저 예측

정지한 용수철 진자를 \(t = \pi\)에 망치로 한 번 톡 치면, 그 뒤의 운동은 어떤 모양일까?

예측 확인

\(t = \pi\)까지는 가만히 있다가, 그 순간 속도를 얻어 사인 모양으로 진동한다.

(가) \(y'' + y = \delta(t - \pi)\), \(y(0) = y'(0) = 0\) (나) \(y' + 2y = u(t - 1)\), \(y(0) = 0\) (\(t = 1\)에 일정한 입력이 켜짐)

풀이

  1. (가) \((s^2 + 1)Y = e^{-\pi s}\), \(Y = e^{-\pi s}\frac{1}{s^2 + 1}\).
    초기조건이 0이라 깔끔.
  2. \(\frac{1}{s^2 + 1} \leftrightarrow \sin t\)이고 \(e^{-\pi s}\)는 \(\pi\)만큼 지연: \(y = \sin(t - \pi)u(t - \pi) = -\sin t\cdot u(t - \pi)\).
    \(t\)축 이동 정리.
  3. (나) \((s + 2)Y = \frac{e^{-s}}{s}\), \(Y = e^{-s}\frac{1}{s(s + 2)} = e^{-s}\cdot\frac12\left(\frac1s - \frac{1}{s + 2}\right)\).
    부분분수.
  4. \(y = \frac12\left(1 - e^{-2(t - 1)}\right)u(t - 1)\).
    \(t = 1\) 전에는 0, 그 뒤 \(\frac12\)로 지수적으로 다가감.

의미

(가)에서 \(y'\)는 \(t = \pi\)에서 0에서 1로 뛴다. 델타 함수는 "순간적으로 운동량 1을 주는 충격"(공통3 4-01의 충격량)이고, 그 응답(충격 응답)은 \(\frac{1}{s^2 + 1}\), 곧 전달함수의 역변환이다. 계의 충격 응답을 알면 어떤 입력에 대한 응답도 다음 카드의 합성곱으로 구할 수 있다. 공학에서 구조물을 망치로 쳐서 고유 진동수를 재는 이유이다.

검산

(나) \(t > 1\)에서 \(y' + 2y = e^{-2(t-1)} + 1 - e^{-2(t-1)} = 1\). \(t = 1\)에서 \(y = 0\)으로 연속. 정상 상태 \(\frac12\)은 \(2y = 1\)에서 바로 보인다.
