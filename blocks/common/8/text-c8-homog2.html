2계 동차 선형 미분방정식

본문

뉴턴의 제2법칙 \(F = ma\)에서 가속도는 위치의 2계 도함수이다. 그래서 용수철, 진자, 전기 회로의 방정식은 대부분 2계 미분방정식이 된다. 1계 방정식은 초기값 하나로 해가 정해졌는데, 2계 방정식은 해를 몇 개 찾아야 모든 해를 안다고 말할 수 있을까?

먼저 알아야 할 것1계 선형 방정식(1.4절)을 쓴다.

2.1.12계 선형 방정식

2계 방정식 가운데 가장 중요하고 완전히 풀 수 있는 것이 선형 방정식이다.

정의 2.1.1 (2계 선형 미분방정식)

\(y'' + p(x)y' + q(x)y = r(x)\) 꼴의 식. \(r(x) = 0\)이면 동차, 아니면 비동차이다.

\(y\), \(y'\), \(y''\)이 모두 1차로만 들어 있어야 선형이다. 그러므로 \(y'' + y^2 = 0\)이나 진자의 정확한 식 \(y'' + \sin y = 0\)은 비선형이다.

2.1.2중첩 원리

정리 2.1.2 (중첩 원리)

\(y_1\), \(y_2\)가 동차 방정식 \(y'' + py' + qy = 0\)의 해이면, 임의의 상수 \(c_1, c_2\)에 대해 \(c_1y_1 + c_2y_2\)도 해이다.

식에 넣으면 \(c_1(y_1'' + py_1' + qy_1) + c_2(y_2'' + py_2' + qy_2) = 0 + 0\)이기 때문이다. 다만 이 원리는 동차이고 선형일 때만 성립한다. 비동차이거나 비선형이면 해를 더해도 해가 되지 않는다.

예제 2.1.3

\(y'' + y = 0\)의 해 \(\cos x\)와 \(\sin x\)로 \(y(0) = 3\), \(y'(0) = -0.5\)인 해를 구하여라.

풀이. \(y = c_1\cos x + c_2\sin x\)로 놓으면 \(y(0) = c_1 = 3\), \(y'(0) = c_2 = -0.5\)이다. 따라서 답은 \(y = 3\cos x - 0.5\sin x\)이며, 그림 1의 처음 상태가 이 해이다.

2.1.3일반해와 기저

처음 질문에 답하면, 2계 방정식의 초기값 문제에는 \(y(x_0)\)와 \(y'(x_0)\) 두 조건이 필요하다. 그래서 일반해에도 상수가 두 개 있어야 하며, 해 두 개가 필요하다. 그런데 \(y_1\)과 \(y_2\)가 서로 비례하면, 가령 \(y_2 = 3y_1\)이면 \(c_1y_1 + c_2y_2 = (c_1 + 3c_2)y_1\)이 되어 상수가 사실상 하나뿐이다.

정의 2.1.4 (기저와 일반해)

동차 방정식의 두 해 \(y_1, y_2\)가 서로 비례하지 않을 때(일차독립), 이 두 해를 기저라 하고 \(y = c_1y_1 + c_2y_2\)를 일반해라 한다.

예제 2.1.3의 \(\cos x\)와 \(\sin x\)는 비례하지 않으므로 기저이다. 따라서 모든 해가 \(c_1\cos x + c_2\sin x\) 꼴로 쓰이며, 이것은 2.5절에서 확인한다.

2.1.4계수 낮추기

해 하나 \(y_1\)을 알면 \(y_2 = u\,y_1\)로 놓아 \(u\)에 대한 1계 방정식으로 바꿀 수 있다. 표준형 \(y'' + py' + qy = 0\)이면 결과는 다음과 같다.

\[y_2 = y_1\int U\,dx, \qquad U = \frac{1}{y_1^2}e^{-\int p\,dx}\]
예제 2.1.5

\(x^2y'' - xy' + y = 0\) (\(x > 0\))의 한 해가 \(y_1 = x\)일 때 기저를 구하여라.

풀이. \(x^2\)으로 나누면 \(p = -\frac1x\)이므로 \(e^{-\int p\,dx} = e^{\ln x} = x\)이다. 그러면 \(U = \frac{x}{x^2} = \frac1x\), \(\int U\,dx = \ln x\)이므로 \(y_2 = x\ln x\)이다. 따라서 기저는 \(x\), \(x\ln x\)이다.

마무리

2계 선형 방정식 \(y'' + py' + qy = r\)은 \(r = 0\)일 때 동차이고, 동차이면 해의 일차결합도 해이다. 처음 질문의 답은 비례하지 않는 두 해, 곧 기저이며 일반해 \(c_1y_1 + c_2y_2\)의 상수는 조건 두 개로 정한다. 한 해를 알면 계수 낮추기로 다른 해를 구한다.

2.1.5연습문제

기본

  1. \(e^x\)와 \(e^{-x}\)가 \(y'' - y = 0\)의 해임을 확인하고 \(y(0) = 2\), \(y'(0) = 0\)인 해를 구하여라.
    답

    \(c_1 + c_2 = 2\), \(c_1 - c_2 = 0\). \(y = e^x + e^{-x} = 2\cosh x\).

응용

  1. \(y'' - 2y' + y = 0\)의 한 해 \(e^x\)로부터 다른 해를 구하여라.
    답

    \(p = -2\), \(e^{2x}/e^{2x} = 1\), \(\int1\,dx = x\). \(y_2 = xe^x\).
