합성곱 정리로 역변환 구하기

(f * g)(t) = ∫₀ᵗ f(τ)g(t − τ)dτ · L{f * g} = FG

정리와 뜻

합성곱 \((f * g)(t) = \int_0^tf(\tau)g(t - \tau)\,d\tau\)에 대해 \(\mathcal L\{f * g\} = F(s)G(s)\). 곱의 역변환은 합성곱입니다(곱의 역변환은 역변환의 곱이 아니다).

근거(개요): \(F(s)G(s) = \int_0^\infty\int_0^\infty e^{-s(\tau + \sigma)}f(\tau)g(\sigma)\,d\tau\,d\sigma\)에서 \(t = \tau + \sigma\)로 변수를 바꾸고 적분 순서를 바꾸면(공통2 6-01, 6-03) \(\int_0^\infty e^{-st}\left[\int_0^tf(\tau)g(t - \tau)d\tau\right]dt\).

뜻: 계의 충격 응답 \(h(t)\)를 알면 입력 \(g(t)\)에 대한 응답(초기조건 0)은 \(y = h * g\). 입력을 시각 \(\tau\)마다의 작은 충격 \(g(\tau)d\tau\)로 쪼개면, 각각이 \(t - \tau\)만큼 지난 뒤의 응답 \(h(t - \tau)\)을 남기고, 그것을 모두 더한 것이다.

(가) \(\mathcal L^{-1}\left\{\frac{1}{s^2(s^2 + 1)}\right\}\)을 합성곱으로 구하여라. (나) \(y'' + y = g(t)\), \(y(0) = y'(0) = 0\)의 해를 \(g\)에 대한 적분으로 써라.

풀이

  1. (가) \(\frac{1}{s^2} \leftrightarrow t\), \(\frac{1}{s^2 + 1} \leftrightarrow \sin t\). 따라서 역변환은 \(t * \sin t = \int_0^t\tau\sin(t - \tau)\,d\tau\).
    합성곱 정리.
  2. 부분적분 \(u = \tau\), \(dv = \sin(t - \tau)d\tau\) (\(v = \cos(t - \tau)\)): \(\left[\tau\cos(t - \tau)\right]_0^t - \int_0^t\cos(t - \tau)\,d\tau = t - \sin t\).
    \(\int_0^t\cos(t - \tau)d\tau = \sin t\).
  3. (나) 충격 응답 \(h = \mathcal L^{-1}\left\{\frac{1}{s^2 + 1}\right\} = \sin t\).
    05-03 카드 (가)에서 지연 없는 경우.
  4. \(y(t) = \int_0^t\sin(t - \tau)g(\tau)\,d\tau\).
    \(Y = \frac{G(s)}{s^2 + 1}\)의 역변환. 어떤 입력 \(g\)에도 쓸 수 있는 공식.

의미

(나)의 공식은 2단원의 매개변수 변환법(02-06 카드)과 같은 결과를 더 투명하게 준다. \(\sin(t - \tau)\)는 "\(\tau\)에 받은 충격이 \(t\)까지 남긴 흔적"이다. 신호 처리의 필터, 영상의 흐림 효과(블러), 확률에서 두 독립 확률변수의 합의 분포가 모두 합성곱이다.

검산

(가) 부분분수로도: \(\frac{1}{s^2(s^2+1)} = \frac{1}{s^2} - \frac{1}{s^2 + 1}\) → \(t - \sin t\). 일치한다.

흔한 오해

  • \(\mathcal L^{-1}\{FG\} = fg\): \(\frac{1}{s}\cdot\frac1s = \frac{1}{s^2}\)인데 \(1\cdot1 = 1 \ne t\). 곱의 역변환은 합성곱 \(1 * 1 = \int_0^t1\,d\tau = t\)이다.
