본문

\(2xy'' + y' + y = 0\)을 표준형으로 바꾸면 계수에 \(\frac1x\)이 생겨 \(x = 0\)에서 무한히 커진다. 그러면 4.1절의 거듭제곱급수가 통하지 않는다. 실제로 해는 \(\sqrt x\)처럼 원점에서 기울기가 무한한 모양으로 시작하는데, 그런 해는 어떤 꼴로 찾아야 할까?

먼저 알아야 할 것거듭제곱급수 방법(4.1절)과 오일러-코시 방정식(2.4절)을 쓴다.

4.3.1왜 \(x^r\)을 곱하는가

오일러-코시 방정식 \(x^2y'' + axy' + by = 0\)을 표준형으로 바꾸면 \(y'' + \frac axy' + \frac{b}{x^2}y = 0\)이 되어 계수가 \(x = 0\)에서 무한히 커진다. 그런데 그 해는 \(x^m\)처럼 \(m\)이 정수가 아닐 수도 있는 거듭제곱이었다. 그래서 처음 질문의 답으로, 이런 방정식에는 보통의 거듭제곱급수 대신 \(x^r\)을 곱한 급수를 넣는다.

정리 4.3.1 (프로베니우스 방법)

\(y'' + \frac{b(x)}{x}y' + \frac{c(x)}{x^2}y = 0\)에서 \(b, c\)가 \(x = 0\)에서 테일러 급수로 전개되면, 적어도 하나의 해가

\[y = x^r\sum_{m=0}^\infty a_mx^m = x^r(a_0 + a_1x + a_2x^2 + \cdots), \quad a_0 \ne 0\]

꼴로 있다. \(r\)은 정수가 아니어도 된다.

가장 낮은 거듭제곱 \(x^r\)의 계수를 0으로 놓으면 \(r\)에 대한 이차방정식이 나오며, 이것을 지표방정식이라 한다.

\[r(r - 1) + b_0r + c_0 = 0 \qquad (b_0 = b(0),\ c_0 = c(0))\]

오일러-코시 방정식의 보조방정식과 같은 모양이다. 그리고 두 근 \(r_1, r_2\)의 관계에 따라 두 번째 해의 꼴이 달라진다. 두 근의 차가 정수가 아니면 두 해 모두 \(x^{r}\sum a_mx^m\) 꼴이다. 반면 중근이면 두 번째 해에 \(\ln x\)가 들어가고, 차가 0이 아닌 정수이면 \(\ln x\)가 들어갈 수도, 아닐 수도 있다.

예제 4.3.2

\(2xy'' + y' + y = 0\)의 지표방정식과 첫 번째 해의 처음 몇 항을 구하여라.

풀이. 양변에 \(\frac x2\)를 곱해 \(x^2\) 꼴로 맞추면 \(x^2y'' + \frac12xy' + \frac x2y = 0\)이므로 \(b_0 = \frac12\), \(c_0 = 0\)이다. 지표방정식은 \(r(r - 1) + \frac12r = r\left(r - \frac12\right) = 0\)이므로 \(r = 0, \frac12\)이다. 차가 정수가 아니므로 두 해 모두 급수 꼴이다.

\(r = \frac12\)이면 \(y = \sum a_mx^{m + 1/2}\)을 넣어 점화식 \(a_m = -\dfrac{a_{m-1}}{(2m + 1)m}\)을 얻는다. 따라서 \(a_1 = -\frac{a_0}{3}\), \(a_2 = \frac{a_0}{30}\)이고 \(y_1 = \sqrt x\left(1 - \frac x3 + \frac{x^2}{30} - \cdots\right)\)이다. 그림 1의 처음 상태가 이 세 항이며, \(x\)가 커질수록 더 많은 항이 있어야 해와 겹친다.

마무리

계수가 \(\frac bx\), \(\frac{c}{x^2}\) 꼴로 무한히 커지면 처음 질문처럼 \(y = x^r\sum a_mx^m\)을 넣고, 지표방정식 \(r(r - 1) + b_0r + c_0 = 0\)으로 \(r\)을 구한다. 두 근이 같거나 정수만큼 차이 나면 두 번째 해에 \(\ln x\)가 생길 수 있다.
