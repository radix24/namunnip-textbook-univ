프로베니우스 방법

본문
이 절에서 배울 것
  • 계수가 \(x = 0\)에서 무한히 커지는 방정식에 \(y = x^r\sum a_mx^m\)을 넣어 푼다.
  • 지표방정식으로 \(r\)을 구한다.
먼저 알아야 할 것
  • 거듭제곱급수 방법 (4.1절), 오일러-코시 방정식 (2.4절).

4.3.1왜 \(x^r\)을 곱하는가

오일러-코시 방정식 \(x^2y'' + axy' + by = 0\)을 표준형으로 바꾸면 \(y'' + \frac axy' + \frac{b}{x^2}y = 0\)이 되어 계수가 \(x = 0\)에서 무한히 커집니다. 그 해는 \(x^m\)처럼 \(m\)이 정수가 아닐 수도 있는 거듭제곱이었습니다. 그래서 이런 방정식에는 보통의 거듭제곱급수 대신 \(x^r\)을 곱한 급수를 넣습니다.

정리 4.3.1 (프로베니우스 방법)

\(y'' + \frac{b(x)}{x}y' + \frac{c(x)}{x^2}y = 0\)에서 \(b, c\)가 \(x = 0\)에서 테일러 급수로 전개되면, 적어도 하나의 해가

\[y = x^r\sum_{m=0}^\infty a_mx^m = x^r(a_0 + a_1x + a_2x^2 + \cdots), \quad a_0 \ne 0\]

꼴로 있다. \(r\)은 정수가 아니어도 된다.

가장 낮은 거듭제곱 \(x^r\)의 계수를 0으로 놓으면 \(r\)에 대한 이차방정식이 나옵니다.

\[r(r - 1) + b_0r + c_0 = 0 \qquad (b_0 = b(0),\ c_0 = c(0)).\]

이것을 지표방정식이라 합니다. 오일러-코시 방정식의 보조방정식과 같은 모양입니다. 두 근 \(r_1, r_2\)의 관계에 따라 두 번째 해의 꼴이 달라집니다.

  • 두 근의 차가 정수가 아니면: 두 해 모두 \(x^{r}\sum a_mx^m\) 꼴.
  • 중근이면: 두 번째 해에 \(\ln x\)가 들어간다.
  • 차가 0이 아닌 정수이면: 두 번째 해에 \(\ln x\)가 들어갈 수도, 아닐 수도 있다.
예제 4.3.2

\(2xy'' + y' + y = 0\)의 지표방정식과 첫 번째 해의 처음 몇 항을 구하여라.

풀이. \(2x\)로 나누어 \(x^2\) 꼴로 맞추면 \(x^2y'' + \frac12xy' + \frac x2y = 0\)이므로 \(b_0 = \frac12\), \(c_0 = 0\). 지표방정식 \(r(r - 1) + \frac12r = r\left(r - \frac12\right) = 0\), \(r = 0, \frac12\). 차가 정수가 아니므로 두 해 모두 급수 꼴입니다.

\(r = \frac12\): \(y = \sum a_mx^{m + 1/2}\)을 넣으면 점화식 \(a_m = -\dfrac{a_{m-1}}{(2m + 1)m}\). \(a_1 = -\frac{a_0}{3}\), \(a_2 = \frac{a_0}{30}\). \(y_1 = \sqrt x\left(1 - \frac x3 + \frac{x^2}{30} - \cdots\right)\).

요약
  1. 계수가 \(\frac bx\), \(\frac{c}{x^2}\) 꼴로 무한히 커지면 \(y = x^r\sum a_mx^m\)을 넣는다.
  2. 지표방정식 \(r(r - 1) + b_0r + c_0 = 0\)으로 \(r\)을 구한다.
  3. 근이 같거나 정수만큼 차이 나면 두 번째 해에 \(\ln x\)가 생길 수 있다.

4.3.2연습문제

기본

  1. \(x^2y'' + xy' + (x^2 - \frac14)y = 0\)의 지표방정식과 그 근은?
    답

    \(b_0 = 1\), \(c_0 = -\frac14\). \(r^2 - \frac14 = 0\), \(r = \pm\frac12\). (\(\nu = \frac12\)인 베셀 방정식)
