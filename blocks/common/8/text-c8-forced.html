강제 진동과 공명

본문
이 절에서 배울 것
  • 주기적인 외력이 가해지는 용수철 계 \(my'' + cy' + ky = F_0\cos\omega t\)를 푼다.
  • 공명과 맥놀이를 설명하고, 감쇠가 있을 때 정상 상태의 진폭을 구한다.
먼저 알아야 할 것
  • 자유 진동 (2.3절), 미정계수법 (2.6절).

2.7.1외력이 있을 때

그네를 밀어 주거나 세탁기의 회전으로 바닥이 흔들리듯, 주기적인 힘 \(F_0\cos\omega t\)가 가해지면 운동 방정식은

\[my'' + cy' + ky = F_0\cos\omega t\]

입니다. 해는 \(y_h\)(자유 진동) + \(y_p\)(외력이 만든 진동)입니다. 감쇠가 있으면 \(y_h\)는 시간이 지나면 사라지므로(과도 해), 오래 지나면 \(y_p\)만 남습니다(정상 상태 해).

2.7.2감쇠가 없을 때: 공명과 맥놀이

\(c = 0\)이고 \(\omega \ne \omega_0 = \sqrt{k/m}\)이면 미정계수법으로

\[y_p = \frac{F_0}{m(\omega_0^2 - \omega^2)}\cos\omega t.\]

외력의 진동수 \(\omega\)가 고유 진동수 \(\omega_0\)에 가까워질수록 분모가 작아져 진폭이 커집니다. \(\omega = \omega_0\)이면 \(\cos\omega_0t\)가 동차 해이므로 수정 규칙으로 \(y_p = \dfrac{F_0}{2m\omega_0}t\sin\omega_0t\)가 되어, 진폭이 시간에 비례해 끝없이 커집니다. 이것이 공명입니다. 그네를 그네의 고유 주기에 맞춰 밀면 점점 높이 올라가는 것과 같습니다.

\(\omega\)가 \(\omega_0\)에 가깝지만 같지 않으면, 자유 진동과 강제 진동이 겹쳐 진폭이 커졌다 작아졌다를 천천히 반복합니다. 이것을 맥놀이라 하고, 소리가 "웅웅" 하고 커졌다 작아지는 현상(기타 줄 조율)으로 들을 수 있습니다.

2.7.3감쇠가 있을 때: 진폭 곡선

\(c > 0\)이면 정상 상태 해는 \(y_p = C^*\cos(\omega t - \eta)\)이고, 그 진폭은

\[C^*(\omega) = \frac{F_0}{\sqrt{m^2(\omega_0^2 - \omega^2)^2 + \omega^2c^2}}.\]

분모가 0이 되지 않으므로 진폭이 무한히 커지지는 않지만, \(\omega\)가 \(\omega_0\) 근처일 때 가장 큽니다. 감쇠가 작을수록 봉우리가 높고 뾰족합니다. 다리나 건물을 설계할 때 바람·지진·발걸음의 진동수가 구조물의 고유 진동수와 겹치지 않게 하고, 감쇠 장치를 다는 이유입니다.

예제 2.7.1

\(y'' + 0.2y' + 4y = \cos\omega t\)에서 \(\omega = 1\)과 \(\omega = 2\)일 때 정상 상태의 진폭을 비교하여라.

풀이. \(m = 1\), \(c = 0.2\), \(\omega_0 = 2\), \(F_0 = 1\). \(\omega = 1\): \(C^* = \frac{1}{\sqrt{9 + 0.04}} \approx 0.333\). \(\omega = 2\): \(C^* = \frac{1}{\sqrt{0 + 0.16}} = 2.5\). 고유 진동수에서 진폭이 7배 이상 큽니다.

RLC 회로의 방정식 \(LI'' + RI' + \frac1CI = E'(t)\)는 이 식과 모양이 똑같습니다(교재 2.9절). 라디오가 특정 방송국의 주파수만 골라 듣는 것이 회로의 공명입니다.

요약
  1. 강제 진동의 해 = 과도 해(사라짐) + 정상 상태 해(남음).
  2. 감쇠 없음, \(\omega = \omega_0\): 공명(진폭이 \(t\)에 비례해 커짐). \(\omega \approx \omega_0\): 맥놀이.
  3. 감쇠 있음: 진폭 \(C^*(\omega)\)는 \(\omega_0\) 근처에서 최대.

2.7.4연습문제

기본

  1. \(y'' + 9y = 5\cos2t\)의 특수해는?
    답

    \(\frac{5}{9 - 4}\cos2t = \cos2t\).

응용

  1. \(y'' + 9y = \cos3t\)의 특수해를 구하고, 시간이 지나면 어떻게 되는지 설명하여라.
    답

    공명: \(y_p = \frac{t}{6}\sin3t\). 진폭이 끝없이 커진다.
