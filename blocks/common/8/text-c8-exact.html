완전 미분방정식과 적분인자

본문

지도의 등고선을 따라 걸으면 높이가 변하지 않는다. 거꾸로, 어떤 미분방정식의 해 곡선들이 마침 한 함수의 등고선이라면, 그 함수만 찾으면 해가 저절로 나온다. \((2xy + 3)\,dx + (x^2 - 1)\,dy = 0\)처럼 변수분리가 안 되는 식이 그런 경우인지는 어떻게 알아보고, 그 함수는 어떻게 찾을까?

먼저 알아야 할 것편도함수 \(\frac{\partial u}{\partial x}\), \(\frac{\partial u}{\partial y}\)(미분적분학(2) 4.2절)와 변수분리법(1.2절)을 쓴다.

1.3.1등고선이 해가 되는 경우

함수 \(u(x, y) = c\)의 등고선 위에서는 \(u\)가 변하지 않으므로 전미분이 0이다. 즉 \(du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy = 0\)이다. 거꾸로, 미분방정식 \(M(x, y)\,dx + N(x, y)\,dy = 0\)이 마침 어떤 \(u\)에 대해 \(M = u_x\), \(N = u_y\)이면 해는 \(u(x, y) = c\)이다. 이런 식을 완전 미분방정식이라 한다.

처음 질문의 첫째 물음은 \(u\)를 찾기 전에 판정할 수 있다. 편미분의 순서는 바꿔도 같으므로(\(u_{xy} = u_{yx}\), 미분적분학(2) 4.2절) 다음 정리가 성립한다.

정리 1.3.1 (완전형 판정)

\(M\,dx + N\,dy = 0\)이 완전형일 필요충분조건은 \(\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}\)이다(\(M, N\)과 편도함수가 연속인 영역에서).

1.3.2푸는 방법

먼저 \(M_y = N_x\)인지 확인한다. 다음으로 \(u = \int M\,dx + k(y)\)로 놓는다. \(x\)로 적분할 때 \(y\)는 상수 취급이므로, 적분 상수가 \(y\)의 함수 \(k(y)\)가 되는 것이다. 이어서 \(u_y = N\)에서 \(k'(y)\)를 구하고 적분해 \(k(y)\)를 정한다. 그러면 해는 \(u(x, y) = c\)이다.

예제 1.3.2

\((2xy + 3)\,dx + (x^2 - 1)\,dy = 0\)을 풀어라.

풀이. \(M_y = 2x\), \(N_x = 2x\)이므로 완전형이다. \(u = \int(2xy + 3)\,dx = x^2y + 3x + k(y)\)로 놓으면, \(u_y = x^2 + k'(y) = x^2 - 1\)에서 \(k'(y) = -1\), 곧 \(k = -y\)이다. 따라서 해는 \(x^2y + 3x - y = c\)이다. 그림 1에서 \(c\)를 바꾸면 해 곡선 하나하나가 이 함수의 등고선으로 나타난다.

검산해 보면, 해를 음함수 미분해 \(2xy\,dx + x^2dy + 3dx - dy = 0\)으로 원래 식이 나온다.

1.3.3적분인자

완전형이 아닌 식도 알맞은 함수 \(F\)를 곱하면 완전형이 될 때가 있다. 이 \(F\)를 적분인자라 한다. 일반적으로 찾기는 어렵지만, \(F\)가 \(x\)만의 함수이거나 \(y\)만의 함수인 경우에는 공식이 있다.

정리 1.3.3

\(R = \dfrac{1}{N}\left(\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}\right)\)이 \(x\)만의 함수이면 \(F(x) = e^{\int R\,dx}\)가 적분인자이다. \(R^* = \dfrac{1}{M}\left(\dfrac{\partial N}{\partial x} - \dfrac{\partial M}{\partial y}\right)\)이 \(y\)만의 함수이면 \(F(y) = e^{\int R^*dy}\)가 적분인자이다.

예제 1.3.4

\((y + x^2)\,dx - x\,dy = 0\)을 풀어라.

풀이. \(M_y = 1\), \(N_x = -1\)이라 완전형이 아니다. 그런데 \(R = \frac{1}{-x}(1 - (-1)) = -\frac2x\)은 \(x\)만의 함수이므로 \(F = e^{\int(-2/x)dx} = x^{-2}\)이다. 곱하면 \(\left(\frac{y}{x^2} + 1\right)dx - \frac1x dy = 0\)이고, 이제 \(M_y = \frac{1}{x^2} = N_x\)이다. \(u = \int\left(-\frac1x\right)dy = -\frac yx + k(x)\)로 놓으면 \(u_x = \frac{y}{x^2} + k'(x) = \frac{y}{x^2} + 1\)에서 \(k = x\)이다. 따라서 해는 \(x - \frac yx = c\), 곧 \(y = x^2 - cx\)이다.

마무리

\(M_y = N_x\)이면 완전형이고, 해는 \(u_x = M\), \(u_y = N\)인 함수의 등고선 \(u = c\)이다. 처음 질문의 함수는 \(u = \int M\,dx + k(y)\)로 놓고 \(u_y = N\)으로 \(k\)를 정해 찾으며, 완전형이 아니면 \(x\)만 또는 \(y\)만의 적분인자를 곱한다.

1.3.4연습문제

기본

  1. \((3x^2 + y)\,dx + (x + 2y)\,dy = 0\)을 풀어라.
    답

    완전형. \(u = x^3 + xy + y^2\). 해 \(x^3 + xy + y^2 = c\).

응용

  1. \(y\,dx + 2x\,dy = 0\)은 완전형인가? 적분인자를 찾아 풀어라.
    답

    \(M_y = 1 \ne N_x = 2\). \(R^* = \frac1y(2 - 1) = \frac1y\), \(F = y\). \(y^2dx + 2xy\,dy = 0\)은 완전형, \(u = xy^2\). 해 \(xy^2 = c\). (변수분리로도 풀린다.)
