자유 진동 모델링

본문

자동차가 과속 방지턱을 넘으면 차체가 한 번 출렁이고 곧 멈춘다. 충격흡수기가 낡으면 여러 번 출렁이고, 너무 뻑뻑하면 천천히 내려앉는다. 같은 용수철이라도 감쇠의 세기에 따라 이렇게 움직임이 달라지는데, 그 경계는 어디이고 어떻게 설계해야 가장 빨리 멈출까?

먼저 알아야 할 것상수계수 방정식(2.2절), 훅의 법칙과 \(F = ma\)(일반물리학(1) 9.1절)를 쓴다.

2.3.1운동 방정식

질량 \(m\)인 물체를 용수철에 매달고 평형 위치에서 아래로 \(y\)만큼 끌어당기면 두 힘이 작용한다. 하나는 훅의 법칙에 따른 용수철의 복원력 \(-ky\)이며, \(k\)는 용수철 상수이다. 다른 하나는 공기나 기름의 저항이 속도에 비례하는 감쇠력 \(-cy'\)이며, \(c\)는 감쇠 상수이다. 중력은 평형 위치를 정할 때 이미 용수철 힘과 상쇄되었으므로 식에 남지 않는다.

그러면 \(my'' = -ky - cy'\)이므로 운동 방정식은 다음과 같다.

\[my'' + cy' + ky = 0\]

2.3.2감쇠가 없을 때

\(c = 0\)이면 \(y'' + \omega_0^2y = 0\)(\(\omega_0 = \sqrt{k/m}\))이고, 특성근이 \(\pm i\omega_0\)이므로 해는 다음과 같다.

\[y = A\cos\omega_0t + B\sin\omega_0t = C\cos(\omega_0t - \delta)\]

이것은 진폭 \(C = \sqrt{A^2 + B^2}\)로 영원히 진동하는 조화 진동이다. 고유 진동수는 \(\frac{\omega_0}{2\pi}\) Hz, 주기는 \(2\pi\sqrt{m/k}\)이다. 즉 무거울수록 느리게, 용수철이 셀수록 빠르게 진동한다. 다만 실제 용수철은 공기 저항 때문에 조금씩 멈추므로, 영원한 조화 진동은 감쇠를 무시한 이상적인 경우이다.

2.3.3감쇠가 있을 때의 세 경우

처음 질문의 경계는 특성방정식 \(m\lambda^2 + c\lambda + k = 0\)의 판별식 \(c^2 - 4mk\)이다. \(c^2 > 4mk\)이면 서로 다른 두 음의 실근을 가지며 \(y = c_1e^{\lambda_1t} + c_2e^{\lambda_2t}\)이다. 이것을 과감쇠라 하며, 꿀 속의 용수철처럼 진동하지 않고 천천히 평형으로 돌아온다.

\(c^2 = 4mk\)이면 중근이며 \(y = (c_1 + c_2t)e^{-ct/2m}\)이다. 이것을 임계감쇠라 하며, 진동하지 않으면서 가장 빨리 평형으로 돌아온다. 그래서 자동차 충격흡수기나 닫히는 문의 완충 장치가 이 상태를 목표로 설계된다. 끝으로 \(c^2 < 4mk\)이면 복소근이며 \(y = e^{-ct/2m}C\cos(\omega^*t - \delta)\), \(\omega^* = \sqrt{\frac km - \frac{c^2}{4m^2}}\)이다. 이것을 미감쇠라 하며, 진동하면서 진폭이 지수적으로 줄어든다.

예제 2.3.1

\(m = 10\) kg, \(k = 90\) N/m인 계에서 \(c = 100\), \(60\), \(10\) kg/s일 때 각각 어떤 운동인가?

풀이. \(4mk = 3600\)이다. \(c = 100\)이면 \(c^2 = 10000 > 3600\)이므로 과감쇠이다. \(c = 60\)이면 \(c^2 = 3600\)이므로 임계감쇠이다. \(c = 10\)이면 \(100 < 3600\)이므로 미감쇠이고, \(\omega^* = \sqrt{9 - 0.25} \approx 2.958\)로 감쇠가 없을 때의 \(\omega_0 = 3\)보다 조금 느리게 진동한다. 그림 1의 처음 상태가 \(c = 10\)이며, 60과 100으로 올려 세 경우를 비교할 수 있다.

마무리

용수철-질량 계는 \(my'' + cy' + ky = 0\)을 따르며, 감쇠가 없으면 \(\omega_0 = \sqrt{k/m}\)로 조화 진동한다. 처음 질문의 경계는 \(c^2 = 4mk\)이며, 이보다 크면 과감쇠, 같으면 임계감쇠, 작으면 줄어드는 진동(미감쇠)이고, 가장 빨리 멈추는 것은 임계감쇠이다.

2.3.4연습문제

기본

  1. 질량 2 kg, 용수철 상수 50 N/m인 계의 주기는?
    답

    \(\omega_0 = 5\), 주기 \(\frac{2\pi}{5} \approx 1.26\) s.

  2. \(m = 1\), \(k = 4\)인 계가 임계감쇠가 되는 \(c\)는?
    답

    \(c^2 = 16\), \(c = 4\).

응용

  1. \(y'' + 2y' + 5y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀고 어떤 운동인지 말하여라.
    답

    근 \(-1 \pm 2i\). \(y = e^{-t}(\cos2t + \frac12\sin2t)\). 미감쇠 진동.
