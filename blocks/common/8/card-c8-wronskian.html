Wronskian으로 기본해 집합 판정하기

중첩 원리 · 일차독립 · 해 공간의 차원 2

왜 필요한가

이계 선형 동차 방정식 \(y'' + p(x)y' + q(x)y = 0\)의 해는 무한히 많습니다. 그런데 해 두 개만 잘 고르면 나머지 모든 해를 그 둘의 일차결합으로 쓸 수 있습니다. "잘 고른" 두 해가 무엇인지 판정하는 도구가 Wronskian입니다. 공통2 2단원의 기저와 차원이 미분방정식에서 다시 나타납니다.

정의

두 함수의 Wronskian \(W(y_1, y_2) = \begin{vmatrix}y_1 & y_2\\ y_1' & y_2'\end{vmatrix} = y_1y_2' - y_2y_1'\). 동차 방정식의 두 해 \(y_1, y_2\)가 구간에서 \(W \ne 0\)이면 기본해 집합이라 하고, 일반해는 \(y = c_1y_1 + c_2y_2\).

정의를 풀어 읽기

  1. 중첩 원리\(y_1, y_2\)가 동차 방정식의 해이면 \(c_1y_1 + c_2y_2\)도 해(방정식이 선형이라). 해 전체는 벡터공간입니다.
  2. 왜 행렬식인가초기값 \(y(x_0) = a\), \(y'(x_0) = b\)를 맞추려면 \(c_1y_1 + c_2y_2 = a\), \(c_1y_1' + c_2y_2' = b\)를 풀어야 합니다. 계수 행렬의 행렬식이 \(W(x_0)\)이므로 \(W \ne 0\)이면 어떤 초기값도 맞출 수 있습니다. 존재·유일성(01-05 카드)과 합치면 모든 해가 이 꼴입니다.
  3. Abel 공식\(W(x) = Ce^{-\int p\,dx}\). 지수는 0이 되지 않으므로 \(W\)는 구간 전체에서 0이거나 한 번도 0이 아닙니다. 한 점에서만 확인하면 됩니다.
  4. 차원 2해 공간은 2차원입니다(초기값 두 개가 해를 정하므로). 그래서 기본해는 정확히 두 개.

예와 반례

  • 예: \(y'' + y = 0\)의 해 \(\cos x, \sin x\). \(W = \cos^2x + \sin^2x = 1 \ne 0\). 기본해 집합.
  • 예: \(y'' - y = 0\)의 해 \(e^x, e^{-x}\): \(W = e^x(-e^{-x}) - e^{-x}e^x = -2\). 기본해. \(\cosh x, \sinh x\)도 기본해(\(W = 1\)).
  • 반례: \(e^x\)와 \(3e^x\)는 둘 다 해지만 \(W = 0\). 한쪽이 다른 쪽의 상수배라 새로운 방향을 주지 않아 \(y(0) = 0\), \(y'(0) = 1\) 같은 초기값을 맞출 수 없습니다.

다른 개념과의 관계

비동차 방정식의 일반해 = 동차 방정식의 일반해 + 특수해 하나(02-06 카드). 연립방정식 \(A\mathbf x = \mathbf b\)의 해 구조(공통2, 4단원)와 같습니다. Wronskian은 매개변수 변환법 공식의 분모로 다시 나옵니다.

흔한 오해

  • "아무 두 함수든 \(W = 0\)이면 일차종속." 방정식의 해가 아닌 일반 함수에서는 틀릴 수 있습니다(예: \(x^3\)과 \(|x|^3\)은 \(W \equiv 0\)이지만 \([-1, 1]\)에서 일차독립). 같은 방정식의 해일 때만 동치입니다.
