연립 미분방정식을 대수 방정식으로 바꿀 수 있을까?

예제 · 라플라스 변환으로 연립방정식 풀기

\(y_1' = -2y_1 + y_2\), \(y_2' = y_1 - 2y_2\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 라플라스 변환으로 풀어라.

전략

두 식을 모두 변환하면 \(\mathcal L\{y'\} = sY - y(0)\) 덕분에 \(Y_1\), \(Y_2\)에 대한 연립 일차방정식이 된다. 이것을 풀고 부분분수로 나눠 역변환한다. 초기 조건이 처음부터 들어가 상수를 따로 정할 필요가 없다.

풀이

  1. \(sY_1 - 1 = -2Y_1 + Y_2\), \(sY_2 = Y_1 - 2Y_2\). 곧 \((s + 2)Y_1 - Y_2 = 1\), \(-Y_1 + (s + 2)Y_2 = 0\).
    변환의 미분 공식.
  2. 둘째 식에서 \(Y_2 = Y_1/(s + 2)\). 첫째에 넣으면 \(Y_1\dfrac{(s + 2)^2 - 1}{s + 2} = 1\), \(Y_1 = \dfrac{s + 2}{(s + 1)(s + 3)}\).
    대입법.
  3. \(Y_1 = \dfrac12\left(\dfrac1{s + 1} + \dfrac1{s + 3}\right)\), \(Y_2 = \dfrac1{(s + 1)(s + 3)} = \dfrac12\left(\dfrac1{s + 1} - \dfrac1{s + 3}\right)\).
    부분분수.
  4. \(y_1 = \tfrac12(e^{-t} + e^{-3t})\), \(y_2 = \tfrac12(e^{-t} - e^{-3t})\).
    \(\mathcal L^{-1}\{1/(s + a)\} = e^{-at}\).

의미

분모의 근 \(-1\), \(-3\)이 계수 행렬의 고유값과 같다. 고유값 방법(3.3절)과 같은 답을 행렬 없이 얻었다. 입력에 계단 함수나 델타 함수가 있으면 라플라스 변환 쪽이 훨씬 편하다.

검산

\(y_1(0) = 1\), \(y_2(0) = 0\). \(y_1' = \tfrac12(-e^{-t} - 3e^{-3t})\)이고 \(-2y_1 + y_2 = -(e^{-t} + e^{-3t}) + \tfrac12(e^{-t} - e^{-3t}) = \tfrac12(-e^{-t} - 3e^{-3t})\). 맞다.

바꿔 보기

\(y_1' = y_2\), \(y_2' = -y_1\), \(y_1(0) = 0\), \(y_2(0) = 1\)이면 \(Y_1 = \dfrac1{s^2 + 1}\), \(y_1 = \sin t\), \(y_2 = \cos t\)로 원 운동이 나온다.

이해 확인

\(y_1' = y_2\), \(y_2' = y_1\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 풀어라.

답

\(Y_1 = \dfrac{s}{s^2 - 1}\), \(y_1 = \cosh t\), \(y_2 = \sinh t\).
