오른쪽이 sec x이면 미정계수법이 왜 안 될까?

예제 · 매개변수변환법

\(y'' + y = \sec x\) (\(-\pi/2 < x < \pi/2\))의 일반해를 구하세요.

전략

미정계수법은 오른쪽이 다항식, 지수, 사인·코사인과 그 곱일 때만 짐작할 꼴이 있습니다. \(\sec x\)는 미분할수록 새로운 꼴이 계속 나와 짐작할 수 없습니다. 매개변수변환법은 동차 해 \(y_1\), \(y_2\)의 상수를 함수 \(u_1(x)\), \(u_2(x)\)로 바꾸어 어떤 \(r(x)\)에도 씁니다: \(u_1' = -\dfrac{y_2r}W\), \(u_2' = \dfrac{y_1r}W\).

풀이

  1. 동차 해 \(y_1 = \cos x\), \(y_2 = \sin x\), 론스키안 \(W = \cos^2x + \sin^2x = 1\).
    특성근 \(\pm i\).
  2. \(u_1' = -\sin x\sec x = -\tan x\), \(u_1 = \ln|\cos x|\).
    \(\int\tan x\,dx = -\ln|\cos x|\).
  3. \(u_2' = \cos x\sec x = 1\), \(u_2 = x\).
    적분상수는 일반해에 들어가므로 생략.
  4. \(y_p = \cos x\ln|\cos x| + x\sin x\), 일반해 \(y = c_1\cos x + c_2\sin x + \cos x\ln|\cos x| + x\sin x\).
    \(y_p = u_1y_1 + u_2y_2\).

의미

\(x\sin x\) 항은 진폭이 \(x\)에 비례해 커지는 진동입니다. \(\sec x\)가 \(x = 0\) 근처에서 고유 진동수와 같은 성분(\(\cos x\))을 많이 갖고 있어 공명처럼 진폭이 자랍니다.

검산

\(y_p' = -\sin x\ln|\cos x| + x\cos x\), \(y_p'' = -\cos x\ln|\cos x| + \dfrac{\sin^2x}{\cos x} + \cos x - x\sin x\). \(y_p'' + y_p = \dfrac{\sin^2x}{\cos x} + \cos x = \dfrac1{\cos x} = \sec x\). 맞습니다.

바꿔 보기

오른쪽이 \(\cos x\)였다면 미정계수법(공명이므로 \(x(A\cos x + B\sin x)\))이 더 빠릅니다. 매개변수변환법도 같은 답 \(\tfrac12x\sin x\)를 줍니다.

이해 확인

\(y'' + y = \tan x\)의 특수해를 같은 방법으로 구하세요.

답

\(u_1' = -\sin x\tan x\), \(u_2' = \sin x\). \(u_2 = -\cos x\), \(u_1 = \sin x - \ln|\sec x + \tan x|\). \(y_p = -\cos x\ln|\sec x + \tan x|\).
