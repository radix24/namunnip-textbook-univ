급수해와 특수함수 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

지표를 옮길 때 합의 시작 번호를 꼭 함께 바꿔라.

  1. 계산\(y' = 2xy\)를 급수 \(y = \sum a_nx^n\)으로 풀고 알려진 함수와 비교하여라. [04-01]

    힌트 1

    04-01 절: \(\sum(n+1)a_{n+1}x^n = \sum2a_{n-1}x^n\).

    힌트 2

    \(a_1 = 0\), \(a_{n+1} = \frac{2a_{n-1}}{n+1}\).

    풀이

    홀수 계수 0. \(a_2 = a_0\), \(a_4 = \frac{a_0}{2}\), \(a_6 = \frac{a_0}{6}\): \(y = a_0\left(1 + x^2 + \frac{x^4}{2!} + \frac{x^6}{3!} + \cdots\right) = a_0e^{x^2}\). 변수분리로 얻는 해와 같다.

  2. 개념\(x(x - 1)^2y'' + y' + y = 0\)의 특이점을 찾고, 각각이 정칙 특이점인지 판정하여라. [04-03]

    힌트 1

    정규화: \(p = \frac{1}{x(x-1)^2}\), \(q\)도 같음.

    힌트 2

    \(x = 1\)에서 \((x - 1)p\)가 해석적인가요?

    풀이

    특이점 \(x = 0, 1\). \(x = 0\): \(xp = \frac{1}{(x-1)^2}\), \(x^2q = \frac{x}{(x-1)^2}\) 해석적: 정칙 특이점. \(x = 1\): \((x - 1)p = \frac{1}{x(x - 1)}\)이 여전히 터짐: 비정칙 특이점(Frobenius 방법을 쓸 수 없음).

  3. 계산\(x^2y'' + xy' + \left(x^2 - \frac14\right)y = 0\) (\(\nu = \frac12\)인 Bessel)의 지표방정식과 그 근을 구하여라. [04-03, 04-04]

    힌트 1

    \(p_0 = 1\), \(q_0 = -\frac14\).

    힌트 2

    \(r^2 - \frac14 = 0\).

    풀이

    \(r(r - 1) + r - \frac14 = r^2 - \frac14 = 0\), \(r = \pm\frac12\). 실제 해는 \(J_{1/2} = \sqrt{\frac{2}{\pi x}}\sin x\), \(J_{-1/2} = \sqrt{\frac{2}{\pi x}}\cos x\)로, 반정수 차수의 Bessel 함수는 기본 함수이다.

  4. 계산\(f(x) = x^2\)을 Legendre 다항식으로 전개하여라: \(x^2 = c_0P_0 + c_2P_2\). [04-04]

    힌트 1

    \(P_2 = \frac12(3x^2 - 1)\).

    힌트 2

    \(x^2 = \frac{2P_2 + 1}{3}\).

    풀이

    \(x^2 = \frac13P_0 + \frac23P_2\). 직교성으로도: \(c_0 = \frac{\int x^2P_0}{\int P_0^2} = \frac{2/3}{2} = \frac13\).

  5. 판단한 학생이 \(x = 0\) 근처에서 \(x^2y'' + y = 0\)을 보통의 급수 \(y = \sum a_nx^n\)으로 풀다가 모든 계수가 0이 되어 "해가 없다"고 했다. 무엇이 문제인가요? [04-01, 04-03]

    힌트 1

    \(x = 0\)은 정칙점인가요?

    힌트 2

    Euler-Cauchy: \(y = x^m\).

    풀이

    \(x = 0\)은 특이점(정칙 특이점)이라 보통의 급수가 맞지 않다. \(y = x^m\)을 넣으면 \(m^2 - m + 1 = 0\), \(m = \frac12 \pm\frac{\sqrt3}{2}i\): 해 \(x^{1/2}\cos\left(\frac{\sqrt3}{2}\ln x\right)\) 등. 비정수 거듭제곱과 로그가 들어 있어 거듭제곱 급수로는 표현되지 않는다. 해가 없는 것이 아니라 방법이 맞지 않은 것이다.

  6. 판단"북의 첫 배음 진동수는 기본 진동수의 2배다." 맞나요? (\(J_0\)의 영점 2.405, 5.520; 두 번째 대칭 모드) [04-04]

    힌트 1

    04-04 절: 진동수는 영점에 비례.

    힌트 2

    \(\frac{5.520}{2.405}\).

    풀이

    틀렸다. 대칭 모드끼리 비는 \(2.295\)로 정수가 아니다. (비대칭 모드 \(J_1\)의 첫 영점 3.832에서 오는 1.593배 모드가 실제로는 먼저 나온다.) 현의 배음(정수배)과 달라 북은 음정이 덜 뚜렷하다.
