라플라스 변환으로 연립방정식 풀기

본문

3.3절에서는 연립 미분방정식을 풀려고 고유값과 고유벡터를 먼저 구했다. 고유값이 복소수이면 계산이 더 번거로워진다. 라플라스 변환으로 미분이 곱셈으로 바뀐다면, 연립 미분방정식도 연립일차방정식으로 바뀌어 고유벡터 없이 풀 수 있지 않을까?

먼저 알아야 할 것도함수의 변환(5.2절)과 연립 미분방정식(3.2절)을 쓴다.

5.7.1방법

처음 질문의 예상대로, 각 식을 변환하면 \(Y_1(s), Y_2(s)\)에 대한 연립일차방정식이 된다. 이를 소거법이나 크라메르 공식으로 풀고 각각 역변환하면 된다. 그러므로 고유값과 고유벡터를 따로 구하지 않아도 되고, 계단·델타 입력도 그대로 넣을 수 있다.

예제 5.7.1

\(y_1' = -y_1 + y_2\), \(y_2' = -y_1 - y_2\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 풀어라.

풀이. 변환하면 \(sY_1 - 1 = -Y_1 + Y_2\), \(sY_2 = -Y_1 - Y_2\)이다. 정리하면 \((s + 1)Y_1 - Y_2 = 1\), \(Y_1 + (s + 1)Y_2 = 0\)이다. 둘째 식에서 \(Y_1 = -(s + 1)Y_2\)를 첫째 식에 넣으면 \(-[(s + 1)^2 + 1]Y_2 = 1\)이므로 다음을 얻는다.

\[Y_2 = -\frac{1}{(s + 1)^2 + 1}, \qquad Y_1 = \frac{s + 1}{(s + 1)^2 + 1}\]

s-이동으로 역변환하면 \(y_1 = e^{-t}\cos t\), \(y_2 = -e^{-t}\sin t\)이다. 행렬의 고유값이 \(-1 \pm i\)인 나선점(3.4절)이므로, 궤적이 돌면서 원점으로 감겨 들어간다. 그림 1에서 \(t\)를 움직이면 왼쪽 점이 나선을 따라 들어가고, 오른쪽 두 그래프는 진동하며 줄어든다.

마무리

연립 미분방정식은 각 식을 변환해 \(Y_1, Y_2\)의 연립일차방정식으로 만들고, 그것을 풀어 역변환한다. 처음 질문처럼 고유벡터를 따로 구하지 않아도 되며, 고유값이 복소수이거나 입력이 계단·델타여도 같은 순서로 푼다.

5.7.2연습문제

응용

  1. \(y_1' = y_2\), \(y_2' = y_1\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 라플라스 변환으로 풀어라.
    답

    \(sY_1 - 1 = Y_2\), \(sY_2 = Y_1\). \(Y_1 = \frac{s}{s^2 - 1}\), \(Y_2 = \frac{1}{s^2 - 1}\). \(y_1 = \cosh t\), \(y_2 = \sinh t\).
