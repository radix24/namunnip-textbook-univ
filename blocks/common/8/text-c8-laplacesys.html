라플라스 변환으로 연립방정식 풀기

본문
이 절에서 배울 것
  • 연립 미분방정식을 변환해 \(Y_1, Y_2\)에 대한 연립일차방정식으로 푼다.
먼저 알아야 할 것
  • 도함수의 변환 (5.2절), 연립 미분방정식 (3.2절).

5.7.1방법

각 식을 변환하면 \(Y_1(s), Y_2(s)\)에 대한 연립일차방정식이 됩니다. 이를 소거법이나 크라메르 공식으로 풀고 각각 역변환합니다. 고유값과 고유벡터를 따로 구하지 않아도 되고, 계단·델타 입력도 그대로 넣을 수 있습니다.

예제 5.7.1

\(y_1' = -y_1 + y_2\), \(y_2' = -y_1 - y_2\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 풀어라.

풀이. 변환: \(sY_1 - 1 = -Y_1 + Y_2\), \(sY_2 = -Y_1 - Y_2\). 정리하면 \((s + 1)Y_1 - Y_2 = 1\), \(Y_1 + (s + 1)Y_2 = 0\). 둘째 식에서 \(Y_1 = -(s + 1)Y_2\)를 첫째 식에 넣으면 \(-[(s + 1)^2 + 1]Y_2 = 1\).

\[Y_2 = -\frac{1}{(s + 1)^2 + 1}, \qquad Y_1 = \frac{s + 1}{(s + 1)^2 + 1}.\]

역변환(s-이동): \(y_1 = e^{-t}\cos t\), \(y_2 = -e^{-t}\sin t\). 행렬의 고유값이 \(-1 \pm i\)인 나선점(3.4절)으로, 궤적이 돌면서 원점으로 감겨 들어갑니다.

요약
  1. 각 식을 변환 → \(Y_1, Y_2\)의 연립일차방정식 → 풀어서 역변환.

5.7.2연습문제

응용

  1. \(y_1' = y_2\), \(y_2' = y_1\), \(y_1(0) = 1\), \(y_2(0) = 0\)을 라플라스 변환으로 풀어라.
    답

    \(sY_1 - 1 = Y_2\), \(sY_2 = Y_1\). \(Y_1 = \frac{s}{s^2 - 1}\), \(Y_2 = \frac{1}{s^2 - 1}\). \(y_1 = \cosh t\), \(y_2 = \sinh t\).
