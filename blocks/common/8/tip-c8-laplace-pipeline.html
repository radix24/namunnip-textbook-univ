라플라스 변환 풀이는 변환, \(Y\)에 대해 풀기, 부분분수, 표로 역변환의 네 단계를 지킨다

요령 · 라플라스 변환으로 초기값 문제

언제 쓰는가

초기 조건이 주어진 상수계수 선형 방정식, 특히 우변이 지수함수나 불연속 함수일 때입니다.

요령

  1. 변환
    \(\mathcal L\{y'\} = sY - y(0)\), \(\mathcal L\{y''\} = s^2Y - sy(0) - y'(0)\). 초기 조건이 여기서 바로 들어갑니다.
  2. \(Y\)에 대해 푼다
    대수 방정식이므로 \(Y(s)\)를 분수식으로 정리합니다.
  3. 부분분수
    표에 있는 꼴 \(\frac{1}{s - a}\), \(\frac{s}{s^2 + \omega^2}\) 등으로 쪼갭니다. 이차식은 완전제곱으로 바꿉니다.
  4. 표로 되돌린다
    항마다 역변환합니다. 마지막에 \(y(0)\)과 \(y'(0)\)을 확인합니다.

흔한 실수

  • \(\mathcal L\{y'\}\)에서 \(-y(0)\)을 빠뜨리는 것.
  • 곱의 역변환을 역변환의 곱으로 쓰는 것. 곱은 합성곱이 됩니다.

바로 풀어보기

\(y' + 2y = e^{-t}\), \(y(0) = 3\)을 라플라스 변환으로 푸세요.

답과 풀이

답: \(y = 2e^{-2t} + e^{-t}\)

\(sY - 3 + 2Y = \frac{1}{s + 1}\)이므로 \(Y = \frac{3}{s + 2} + \frac{1}{(s + 1)(s + 2)}\)입니다.

\(\frac{1}{(s + 1)(s + 2)} = \frac{1}{s + 1} - \frac{1}{s + 2}\)이므로 \(Y = \frac{2}{s + 2} + \frac{1}{s + 1}\), \(y = 2e^{-2t} + e^{-t}\)입니다. 검산: \(y(0) = 3\).

이 요령으로 풀리는 문제

  • 라플라스 변환 단원 연습 1번, 2번, 3번, 4번
영상 콘티 · 45초
  1. 0~5초\(t\) 세계의 미분방정식이 왼쪽에, 빈 \(s\) 세계가 오른쪽에 있습니다.미분을 대수로 바꿔 봅시다.
  2. 5~13초식이 다리를 건너 \(s\) 세계로 가면서 \(y'\)이 \(sY - 3\)으로 바뀝니다. 초기값 3이 이때 함께 들어갑니다.변환하면 초기 조건이 따라 들어옵니다.
  3. 13~21초\(Y\)를 모으는 대수 계산이 진행되어 분수식이 됩니다.\(Y\)에 대해 풉니다.
  4. 21~31초분수 하나가 \(\frac{1}{s + 1}\), \(\frac{1}{s + 2}\) 조각으로 쪼개져 표의 칸에 하나씩 꽂힙니다.표에 있는 조각으로 쪼갭니다.
  5. 31~40초조각들이 다리를 거꾸로 건너 \(e^{-t}\), \(e^{-2t}\)로 바뀌어 합쳐집니다.표로 되돌아옵니다.
  6. 40~45초\(t = 0\)을 넣자 3이 나와 체크.초기값으로 검산합니다.
