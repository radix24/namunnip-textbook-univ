감쇠 진동은 \(c^2\)과 \(4mk\)를 비교해 과감쇠, 임계감쇠, 미감쇠를 가른다

요령 · 감쇠 진동

언제 쓰는가

\(mx'' + cx' + kx = 0\)의 운동이 진동하는지, 얼마나 빨리 멈추는지를 묻는 문제입니다. RLC 회로도 같은 꼴입니다.

요령

  1. 계수를 읽는다
    질량 \(m\), 감쇠 계수 \(c\), 용수철 상수 \(k\)(회로면 \(L\), \(R\), \(\frac1C\)).
  2. \(c^2\)과 \(4mk\)
    \(c^2 > 4mk\) 과감쇠(진동 없이 천천히), \(c^2 = 4mk\) 임계감쇠(가장 빨리 진동 없이), \(c^2 < 4mk\) 미감쇠(진동하며 줄어듦).
  3. 미감쇠의 진동수
    \(\omega_d = \sqrt{\frac km - \frac{c^2}{4m^2}}\)로 감쇠 없는 \(\omega_0 = \sqrt{k/m}\)보다 작습니다.
  4. 임계값
    임계 감쇠 계수는 \(c = 2\sqrt{mk}\)입니다.

흔한 실수

  • 과감쇠가 임계감쇠보다 빨리 멈춘다고 보는 것. 감쇠가 너무 크면 오히려 천천히 돌아옵니다.
  • 미감쇠 진동수를 \(\omega_0\)과 같다고 쓰는 것.

바로 풀어보기

\(x'' + cx' + 16x = 0\)에서 \(c = 2\), \(8\), \(10\)일 때 각각 어떤 운동인지 말하고, 진동하는 경우의 진동수와 과감쇠 경우의 특성근을 구하세요.

답과 풀이

답: \(c = 2\) 미감쇠(\(\omega_d = \sqrt{15} \approx 3.87\)), \(c = 8\) 임계감쇠, \(c = 10\) 과감쇠(근 \(-2\), \(-8\))

\(4mk = 64\)입니다. \(c = 2\): \(4 < 64\) 미감쇠, \(\omega_d = \sqrt{16 - 1} = \sqrt{15}\). \(c = 8\): \(64 = 64\) 임계감쇠, 근 \(-4\)(중근).

\(c = 10\): \(100 > 64\) 과감쇠, \(r^2 + 10r + 16 = 0\)에서 \(r = -2, -8\)입니다. 느린 근 \(-2\) 때문에 임계감쇠(\(e^{-4t}\))보다 늦게 멈춥니다.

이 요령으로 풀리는 문제

  • 2계 선형 상미분방정식(진동) 단원 연습 1번, 2번, 4번, 5번
영상 콘티 · 45초
  1. 0~5초용수철에 매단 추 세 개가 나란히 같은 높이에서 놓입니다. 각각 감쇠기 손잡이 2, 8, 10이 붙어 있습니다.어느 추가 가장 빨리 멈출까요?
  2. 5~13초\(c^2\)과 \(4mk = 64\)이 저울에 올라가 세 번 비교됩니다.\(c^2\)과 \(4mk\)를 비교합니다.
  3. 13~23초\(c = 2\) 추는 위아래로 출렁이며 점점 작아지고, 진동 주기 표시 \(\frac{2\pi}{\sqrt{15}}\)가 붙습니다.작으면 미감쇠, 진동합니다.
  4. 23~33초\(c = 8\) 추는 한 번에 미끄러지듯 제자리로 돌아와 가장 먼저 멈춥니다.같으면 임계감쇠, 가장 빠릅니다.
  5. 33~45초\(c = 10\) 추는 꿀 속처럼 천천히 기어 들어오고, 그래프에 \(e^{-2t}\) 꼬리가 길게 남습니다.크면 과감쇠, 오히려 늦습니다.
