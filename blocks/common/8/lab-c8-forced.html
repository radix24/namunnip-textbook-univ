강제 진동: 맥놀이와 공명

실습 · 과도 응답과 정상 상태

목표

주기적인 힘 \(\cos\omega t\)를 받는 용수철의 운동을 그리고, 구동 진동수가 고유 진동수에 가까울수록 진폭이 커지는 공명, 감쇠가 없을 때의 맥놀이와 진폭의 무한 증가를 확인합니다. 성취기준 [공통8-02-07].

준비

질량은 1, 힘의 크기도 1로 두었습니다. 위 그래프는 정지 상태에서 시작한 변위(주황 점선은 정상 상태 진폭), 아래 그래프는 구동 진동수에 따른 정상 진폭(공명 곡선)이고 파란 점이 지금 진동수입니다.

절차

  1. \(c = 0.1\)에서 \(\omega\)를 0.5, 0.9, 1.0, 1.1, 2.0으로 바꾸며 정상 진폭을 기록한다.
  2. 처음 부분의 불규칙한 움직임이 시간이 지나 사라지는지 본다.
  3. \(c = 0\), \(\omega = 0.9\)로 맥놀이를 보고, 맥놀이 주기를 출력과 비교한다.
  4. \(c = 0\), \(\omega = 1.00\)으로 진폭이 어떻게 커지는지 본다.

기대 결과

  • 정상 진폭은 \(\omega \approx \omega_0\) 근처에서 가장 크다(\(c = 0.1\)이면 약 10). 감쇠가 클수록 봉우리가 낮고 넓다.
  • 처음의 과도 응답은 \(e^{-ct/2}\)로 줄어 정상 상태만 남는다.
  • \(c = 0\), \(\omega \ne \omega_0\): 진폭이 커졌다 작아졌다 하는 맥놀이(주기 \(\frac{2\pi}{|\omega - \omega_0|}\)).
  • \(c = 0\), \(\omega = \omega_0\): 진폭이 시간에 비례해 끝없이 커진다(해가 \(\frac{t}{2}\sin t\)).

분석

  1. 맥놀이 주기가 길어질수록 진폭의 최댓값이 커지는 이유를 생각해 보세요. 진동수 차이가 0인 극한이 공명입니다.
  2. 다리나 건물을 설계할 때 바람이나 지진의 진동수와 고유 진동수를 왜 떨어뜨려야 할까요? 감쇠를 넣으면 무엇이 좋아지나요?

더 해 보기

미정계수법으로 \(x'' + 0.1x' + x = \cos\omega t\)의 특수해 진폭 \(\frac{1}{\sqrt{(1 - \omega^2)^2 + (0.1\omega)^2}}\)을 유도하고, \(\omega = 1\)에서 10이 되는지 확인해 보세요.
