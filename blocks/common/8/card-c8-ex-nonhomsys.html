외부 입력이 있는 연립방정식은 어디로 가라앉을까?

예제 · 비동차 연립 미분방정식

\(\mathbf y' = A\mathbf y + \mathbf g\), \(A = \begin{pmatrix}-3 & 1\\ 1 & -3\end{pmatrix}\), \(\mathbf g = \begin{pmatrix}2\\ 0\end{pmatrix}\)의 일반해를 구하고, \(t \to \infty\)에서의 모습을 말하세요.

전략

단일 방정식과 같이 \(\mathbf y = \mathbf y_h + \mathbf y_p\)로 씁니다. 동차 해는 고유값과 고유벡터로, 특수해는 \(\mathbf g\)가 상수이므로 상수 벡터 \(\mathbf y_p\)로 짐작합니다(미정계수법).

풀이

  1. \(\det(A - \lambda I) = (\lambda + 3)^2 - 1 = 0\)에서 \(\lambda = -2\) (고유벡터 \((1, 1)\)), \(\lambda = -4\) (\((1, -1)\)).
    3.1절.
  2. \(\mathbf y_h = c_1e^{-2t}\begin{pmatrix}1\\1\end{pmatrix} + c_2e^{-4t}\begin{pmatrix}1\\-1\end{pmatrix}\).
    3.3절.
  3. 상수 \(\mathbf y_p\)이면 \(\mathbf 0 = A\mathbf y_p + \mathbf g\), 곧 \(-3a + b = -2\), \(a - 3b = 0\). \(a = 3/4\), \(b = 1/4\).
    상수의 도함수는 0.
  4. \(\mathbf y = c_1e^{-2t}\begin{pmatrix}1\\1\end{pmatrix} + c_2e^{-4t}\begin{pmatrix}1\\-1\end{pmatrix} + \begin{pmatrix}3/4\\1/4\end{pmatrix}\).
    일반해 = 동차 해 + 특수해.

의미

두 고유값이 모두 음수라 동차 부분은 사라지고, 처음 값과 상관없이 모든 해가 \((3/4, 1/4)\)에 다가갑니다. 이 점이 외부 입력이 일정할 때의 정상 상태(평형점)입니다. 공학에서는 "과도 응답이 사라진 뒤의 정상 응답"이라 부릅니다.

검산

\(A\mathbf y_p = (-9/4 + 1/4,\ 3/4 - 3/4) = (-2, 0) = -\mathbf g\). 맞습니다.

바꿔 보기

\(\mathbf g\)가 \(e^{-2t}\begin{pmatrix}1\\1\end{pmatrix}\)처럼 고유값 \(-2\)의 모양과 겹치면 공명이 생겨 \(\mathbf y_p\)에 \(te^{-2t}\) 항이 필요합니다.

이해 확인

같은 \(A\)에서 \(\mathbf g = \begin{pmatrix}0\\4\end{pmatrix}\)이면 정상 상태는?

답

\(-3a + b = 0\), \(a - 3b = -4\): \(a = 1/2\), \(b = 3/2\).
