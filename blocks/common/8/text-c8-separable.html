변수분리형 미분방정식과 모델링

본문

90 °C 커피를 20 °C 방에 두었더니 10분 뒤 60 °C가 되었다. 마시기 좋은 온도를 지나 30 °C까지 식으려면 얼마나 걸릴까? 처음 10분 동안 30 °C가 내려갔으니 20분이면 될 것 같지만, 식는 빠르기는 점점 느려진다. 이런 식을 실제로 풀어 시간을 구하려면 어떻게 해야 할까?

먼저 알아야 할 것미분방정식의 기본 용어(1.1절)와 치환적분, \(\int\frac{dy}{y} = \ln|y|\)(미분적분학(1) 4.3절)를 쓴다.

1.2.1변수분리법

\(y' = g(x)h(y)\)처럼 오른쪽이 "\(x\)만의 식 × \(y\)만의 식"으로 나뉘면, \(y\)가 든 것은 왼쪽, \(x\)가 든 것은 오른쪽으로 모을 수 있다. 그러면 양변을 따로 적분할 수 있으며, 이것이 변수분리법이다.

\[\frac{dy}{h(y)} = g(x)\,dx \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(x)\,dx + c\]

왼쪽은 \(y\)로, 오른쪽은 \(x\)로 적분한다. 이때 \(dy\)와 \(dx\)를 분수처럼 나눠 쓰는 것은 실제로는 치환적분(미분적분학(1) 4.3절)을 줄여 쓴 것이다.

예제 1.2.1

\(y' = -2xy\), \(y(0) = 1\)을 풀어라.

풀이. \(\dfrac{dy}{y} = -2x\,dx\)이다. 적분하면 \(\ln|y| = -x^2 + c\), 곧 \(y = Ce^{-x^2}\)(\(C = \pm e^c\))이다. \(y(0) = 1\)에서 \(C = 1\)이므로 답은 \(y = e^{-x^2}\)이다.

그런데 양변을 \(y\)로 나눌 때 \(y = 0\)인 경우가 빠진다. \(y = 0\)도 해이며, 위 식에서 \(C = 0\)으로 놓으면 포함된다. 그러므로 나눗셈으로 잃어버린 해가 없는지 확인하는 것이 좋다.

1.2.2모델링

미분방정식을 세울 때는 "변화율 = (원인)"을 문장으로 먼저 쓰고 식으로 옮긴다.

예제 1.2.2 (뉴턴의 냉각 법칙)

90 °C 커피를 20 °C 방에 두었더니 10분 뒤 60 °C가 되었다. 언제 30 °C가 되는가?

풀이. 식는 빠르기는 방과의 온도 차에 비례하므로 \(\dfrac{dT}{dt} = -k(T - 20)\)이다. 변수분리하면 \(\dfrac{dT}{T - 20} = -k\,dt\), \(\ln|T - 20| = -kt + c\), 곧 \(T = 20 + Ce^{-kt}\)이다. \(T(0) = 90\)에서 \(C = 70\)이다. 또 \(T(10) = 60\)에서 \(70e^{-10k} = 40\)이므로 \(e^{-10k} = \frac47\)이다.

이제 \(T = 30\)이면 \(70e^{-kt} = 10\), \(e^{-kt} = \frac17\)이므로 \(t = 10\cdot\dfrac{\ln7}{\ln(7/4)} \approx 34.8\)분이다. 처음 질문의 어림 20분보다 훨씬 길다. 그림 1에서 시간을 35분 근처로 옮기면 점이 30 °C 표시에 닿는다.

예제 1.2.3 (혼합 문제)

물 1000 L에 소금 100 kg이 녹아 있는 탱크에 맑은 물이 분당 10 L 들어오고, 잘 섞인 물이 분당 10 L 나간다. \(t\)분 뒤 소금의 양 \(y(t)\)는?

풀이. 소금의 변화율은 (들어오는 양) − (나가는 양)이다. 들어오는 물에는 소금이 없고, 나가는 물의 농도는 \(\frac{y}{1000}\) kg/L이므로 나가는 양은 \(10\cdot\frac{y}{1000} = 0.01y\) kg/분이다. 따라서 \(y' = -0.01y\), \(y(0) = 100\)이므로 \(y = 100e^{-0.01t}\)이다. 소금이 절반이 되는 시간은 \(\frac{\ln2}{0.01} \approx 69\)분이다.

들어오는 물에도 소금이 있으면 식이 \(y' = a - by\) 꼴이 된다. 이것도 변수분리로 풀 수 있고, 1.4절의 선형 미분방정식 방법으로도 풀 수 있다.
흔한 오해적분 상수는 마지막에 한 번만 붙이면 된다. 양변에 각각 붙여도 하나로 합쳐진다. 그러나 \(\ln|y| = -x^2 + c\)를 \(y = e^{-x^2} + c\)로 바꾸면 틀린다. \(e^{-x^2 + c} = e^ce^{-x^2}\)이므로 상수는 더해지지 않고 곱해진다.
마무리

\(y' = g(x)h(y)\)이면 \(\int\frac{dy}{h(y)} = \int g(x)\,dx + c\)로 푼다. 모델링은 "변화율 = 원인"을 문장으로 쓰고 식으로 옮기는 일이며, 처음 질문의 냉각은 \(T = T_{\text{주변}} + Ce^{-kt}\), 혼합은 "변화율 = 들어옴 − 나감"으로 세운다.

1.2.3연습문제

기본

  1. \(y' = \frac{x}{y}\), \(y(0) = 2\)를 풀어라.
    답

    \(y\,dy = x\,dx\), \(\frac{y^2}{2} = \frac{x^2}{2} + c\). \(y^2 = x^2 + 4\), \(y = \sqrt{x^2 + 4}\).

  2. \(y' = y^2\), \(y(0) = 1\)을 풀고, 해가 정의되는 범위를 말하여라.
    답

    \(-\frac1y = x + c\), \(c = -1\). \(y = \frac{1}{1 - x}\). \(x < 1\)에서만 정의된다(\(x \to 1\)이면 무한대로 발산).

응용

  1. 방사성 탄소의 반감기가 5730년일 때, 원래 양의 30%가 남은 화석의 나이는?
    답

    \(y = y_0e^{-kt}\), \(k = \frac{\ln2}{5730}\). \(0.3 = e^{-kt}\), \(t = \frac{5730\ln(1/0.3)}{\ln2} \approx 9950\)년.
