이계 선형 미분방정식 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

동차해 → 특수해 → 초기조건 순서를 지키세요.

  1. 계산\(y'' + 6y' + 9y = 0\), \(y(0) = 2\), \(y'(0) = -1\)을 푸세요. [02-02]

    힌트 1

    02-02 절: 중근 \(-3\).

    힌트 2

    \(y = (c_1 + c_2x)e^{-3x}\).

    풀이

    \(c_1 = 2\). \(y' = (c_2 - 3c_1 - 3c_2x)e^{-3x}\), \(y'(0) = c_2 - 6 = -1\), \(c_2 = 5\). \(y = (2 + 5x)e^{-3x}\).

  2. 계산\(y'' + 4y = 8x^2\)의 일반해를 구하세요. [02-06]

    힌트 1

    동차해 \(\cos2x, \sin2x\). 추측 \(Ax^2 + Bx + C\).

    힌트 2

    \(2A + 4(Ax^2 + Bx + C) = 8x^2\).

    풀이

    \(4A = 8\), \(4B = 0\), \(2A + 4C = 0\) → \(A = 2\), \(B = 0\), \(C = -1\). \(y = c_1\cos2x + c_2\sin2x + 2x^2 - 1\).

  3. 판단한 학생이 \(y'' + y = \cos x\)의 특수해를 \(y_p = A\cos x + B\sin x\)로 추측했더니 대입 결과가 \(0 = \cos x\)가 되어 "특수해가 없다"고 결론 내렸습니다. 무엇이 틀렸고, 바른 특수해는? [02-06]

    힌트 1

    추측이 동차해와 겹치면?

    힌트 2

    \(y_p = x(A\cos x + B\sin x)\).

    풀이

    추측이 동차해와 같아 대입하면 0이 됩니다. \(x\)를 곱해야 합니다. \(y_p = x(A\cos x + B\sin x)\)를 넣으면 \(-2A\sin x + 2B\cos x = \cos x\), \(A = 0\), \(B = \frac12\). \(y_p = \frac x2\sin x\). 진폭이 \(x\)에 비례해 커지는 공명입니다(3-02 카드).

  4. 개념\(y_1 = x\)와 \(y_2 = x^2\)이 어떤 방정식 \(y'' + p(x)y' + q(x)y = 0\)의 해라면, \(x = 0\)을 포함하는 구간에서 \(p\)나 \(q\)가 연속일 수 있나요? [02-05]

    힌트 1

    \(W(x, x^2) = x^2\).

    힌트 2

    Abel 공식: \(p, q\)가 연속이면 \(W\)는 늘 0이거나 한 번도 0이 아님.

    풀이

    \(W = x^2\)은 \(x = 0\)에서만 0입니다. \(p\)와 \(q\)가 연속인 구간에서는 그럴 수 없으므로(Abel), 그 방정식은 \(x = 0\)에서 계수가 불연속이어야 합니다. 실제로 \(x^2y'' - 2xy' + 2y = 0\) (Euler-Cauchy)을 정규화하면 \(p = -\frac2x\), \(q = \frac{2}{x^2}\)로 \(x = 0\)에서 터집니다.

  5. 계산\(x^2y'' + 3xy' + y = 0\) (\(x > 0\))의 일반해를 구하세요. [02-04]

    힌트 1

    \(m(m - 1) + 3m + 1 = 0\).

    힌트 2

    \((m + 1)^2 = 0\).

    풀이

    중근 \(m = -1\). \(y = (c_1 + c_2\ln x)x^{-1}\).

  6. 판단한 학생이 \(y'' - y = e^x\), \(y(0) = 0\), \(y'(0) = 0\)을 풀면서 동차해에만 초기조건을 넣어 \(c_1 = c_2 = 0\)을 얻고 그다음 \(y_p\)를 더했습니다. 결과가 초기조건을 만족하나요? [02-06]

    힌트 1

    \(y_p = \frac12xe^x\).

    힌트 2

    \(y = \frac12xe^x\)의 \(y'(0)\)은?

    풀이

    \(y = \frac12xe^x\)이면 \(y(0) = 0\)이지만 \(y'(0) = \frac12 \ne 0\). 초기조건은 \(y_h + y_p\) 전체에 넣어야 합니다. 바르게: \(y = c_1e^x + c_2e^{-x} + \frac12xe^x\), \(c_1 + c_2 = 0\), \(c_1 - c_2 + \frac12 = 0\) → \(c_1 = -\frac14\), \(c_2 = \frac14\). \(y = -\frac14e^x + \frac14e^{-x} + \frac12xe^x\).
