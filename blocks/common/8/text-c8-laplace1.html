라플라스 변환과 역변환, s-이동

본문

로그를 쓰면 곱셈이 덧셈으로 바뀌어 계산이 쉬워진다. 미분방정식에도 그런 "다른 세계"가 있다면, 그곳에서 미분이 곱셈으로 바뀌어 대수 계산만으로 풀 수 있을 것이다. 특히 스위치를 켜고 끄는 입력이나 순간적인 충격처럼 2단원의 방법으로 다루기 어려운 입력도 다룰 수 있을까?

먼저 알아야 할 것이상적분(미분적분학(1) 5.5절)과 부분적분(5.1절)을 쓴다.

5.1.1미분방정식을 대수 문제로

처음 질문의 다른 세계로 옮기는 도구가 라플라스 변환이다. 변환한 세계에서 대수 계산으로 풀고, 다시 되돌리면 해가 나온다.

정의 5.1.1 (라플라스 변환)

\(t \ge 0\)에서 정의된 \(f(t)\)에 대하여

\[F(s) = \mathcal L\{f\} = \int_0^\infty e^{-st}f(t)\,dt.\]

\(F\)를 \(f\)로 되돌리는 것을 역변환 \(f = \mathcal L^{-1}\{F\}\)이라 한다.

\(t\)의 함수가 \(s\)의 함수로 바뀌며, 관습적으로 원래 함수는 소문자, 변환은 대문자로 쓴다. 그림 1에서 보듯 \(F(s)\)는 \(f\)에 감쇠하는 \(e^{-st}\)를 곱한 함수의 아래 넓이이다.

예제 5.1.2

\(\mathcal L\{1\}\)과 \(\mathcal L\{e^{at}\}\)을 구하여라.

풀이. \(\mathcal L\{1\} = \int_0^\infty e^{-st}dt = \lim_{T\to\infty}\left[-\frac1se^{-st}\right]_0^T = \frac1s\)(\(s > 0\))이다. 또 \(\mathcal L\{e^{at}\} = \int_0^\infty e^{-(s - a)t}dt = \frac{1}{s - a}\)(\(s > a\))이다. 그림 1에서 \(f = 1\), \(s = 1\)로 놓으면 넓이가 1, 곧 \(\frac11\)이다.

같은 방식으로 부분적분과 오일러 공식을 쓰면 다음 표를 얻는다. 이 표는 외워 두면 계산이 빨라진다.

\(f(t)\)\(F(s)\)\(f(t)\)\(F(s)\)
1\(\frac1s\)\(e^{at}\)\(\frac{1}{s - a}\)
\(t\)\(\frac{1}{s^2}\)\(t^n\)\(\frac{n!}{s^{n+1}}\)
\(\cos\omega t\)\(\frac{s}{s^2 + \omega^2}\)\(\sin\omega t\)\(\frac{\omega}{s^2 + \omega^2}\)
\(\cosh at\)\(\frac{s}{s^2 - a^2}\)\(\sinh at\)\(\frac{a}{s^2 - a^2}\)

5.1.2선형성과 s-이동

적분은 선형이므로 \(\mathcal L\{af + bg\} = aF + bG\)이고, 역변환도 선형이다.

정리 5.1.3 (s-이동)

\(\mathcal L\{f\} = F(s)\)이면 \(\mathcal L\{e^{at}f(t)\} = F(s - a)\)이다.

즉 \(t\)쪽에서 \(e^{at}\)를 곱하면 \(s\)쪽에서는 \(s\)를 \(s - a\)로 바꾼다. 가령 \(\mathcal L\{e^{-2t}\cos3t\} = \dfrac{s + 2}{(s + 2)^2 + 9}\)이며, 감쇠 진동의 변환에 바로 쓰인다.

예제 5.1.4

\(\mathcal L^{-1}\left\{\dfrac{3s - 137}{s^2 + 2s + 401}\right\}\)을 구하여라.

풀이. 분모를 완전제곱으로 고치면 \((s + 1)^2 + 400\)이다. 그러면 분자를 \(3(s + 1) - 140\)으로 고쳐 다음과 같이 나눈다.

\[\frac{3(s + 1)}{(s + 1)^2 + 20^2} - 7\cdot\frac{20}{(s + 1)^2 + 20^2} \;\to\; e^{-t}(3\cos20t - 7\sin20t)\]
마무리

라플라스 변환 \(\mathcal L\{f\} = \int_0^\infty e^{-st}f\,dt\)는 처음 질문의 다른 세계로 옮기는 도구이며, 변환표를 익혀 두면 계산이 빠르다. 변환은 선형이고 s-이동 \(\mathcal L\{e^{at}f\} = F(s - a)\)가 성립하며, 역변환은 분모를 완전제곱이나 인수분해로 표의 꼴에 맞춰 구한다.
