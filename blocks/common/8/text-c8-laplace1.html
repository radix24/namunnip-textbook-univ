5.1.1미분방정식을 대수 문제로

로그를 쓰면 곱셈이 덧셈으로 바뀌어 계산이 쉬워지듯, 라플라스 변환을 쓰면 미분방정식이 대수방정식으로 바뀝니다. 변환한 세계에서 대수 계산으로 풀고, 다시 되돌리면 해가 나옵니다. 특히 스위치를 켜고 끄는 입력, 순간적인 충격처럼 2단원의 방법으로 다루기 어려운 입력에 강합니다.

정의 5.1.1 (라플라스 변환)

\(t \ge 0\)에서 정의된 \(f(t)\)에 대하여

\[F(s) = \mathcal L\{f\} = \int_0^\infty e^{-st}f(t)\,dt.\]

\(f\)를 \(F\)로 되돌리는 것을 역변환 \(f = \mathcal L^{-1}\{F\}\)이라 한다.

\(t\)의 함수가 \(s\)의 함수로 바뀝니다. 관습적으로 원래 함수는 소문자, 변환은 대문자로 씁니다.

예제 5.1.2

\(\mathcal L\{1\}\)과 \(\mathcal L\{e^{at}\}\)을 구하여라.

풀이. \(\mathcal L\{1\} = \int_0^\infty e^{-st}dt = \lim_{T\to\infty}\left[-\frac1se^{-st}\right]_0^T = \frac1s\) (\(s > 0\)). \(\mathcal L\{e^{at}\} = \int_0^\infty e^{-(s - a)t}dt = \frac{1}{s - a}\) (\(s > a\)).

같은 방식(부분적분, 오일러 공식)으로 다음 표를 얻습니다. 이 표는 외워 두면 계산이 빨라집니다.

\(f(t)\)\(F(s)\)\(f(t)\)\(F(s)\)
1\(\frac1s\)\(e^{at}\)\(\frac{1}{s - a}\)
\(t\)\(\frac{1}{s^2}\)\(t^n\)\(\frac{n!}{s^{n+1}}\)
\(\cos\omega t\)\(\frac{s}{s^2 + \omega^2}\)\(\sin\omega t\)\(\frac{\omega}{s^2 + \omega^2}\)
\(\cosh at\)\(\frac{s}{s^2 - a^2}\)\(\sinh at\)\(\frac{a}{s^2 - a^2}\)

5.1.2선형성과 s-이동

적분은 선형이므로 \(\mathcal L\{af + bg\} = aF + bG\)입니다. 역변환도 선형입니다.

정리 5.1.3 (s-이동)

\(\mathcal L\{f\} = F(s)\)이면 \(\mathcal L\{e^{at}f(t)\} = F(s - a)\)이다.

\(t\)쪽에서 \(e^{at}\)를 곱하면 \(s\)쪽에서는 \(s\)를 \(s - a\)로 바꿉니다. 예: \(\mathcal L\{e^{-2t}\cos3t\} = \dfrac{s + 2}{(s + 2)^2 + 9}\). 감쇠 진동의 변환에 바로 쓰입니다.

예제 5.1.4

\(\mathcal L^{-1}\left\{\dfrac{3s - 137}{s^2 + 2s + 401}\right\}\)을 구하여라.

풀이. 분모를 완전제곱으로: \((s + 1)^2 + 400\). 분자를 \(3(s + 1) - 140\)으로 고치면

\[\frac{3(s + 1)}{(s + 1)^2 + 20^2} - 7\cdot\frac{20}{(s + 1)^2 + 20^2} \;\to\; e^{-t}(3\cos20t - 7\sin20t).\]
요약
  1. \(\mathcal L\{f\} = \int_0^\infty e^{-st}f\,dt\). 변환표를 익힌다.
  2. 선형성, s-이동 \(\mathcal L\{e^{at}f\} = F(s - a)\).
  3. 역변환: 분모를 완전제곱이나 인수분해로 표의 꼴에 맞춘다.
