상수계수 연립방정식의 풀이

본문
이 절에서 배울 것
  • \(\mathbf y' = A\mathbf y\)의 해가 \(\mathbf x e^{\lambda t}\) (고유벡터 × 지수함수) 꼴임을 안다.
  • 고유값·고유벡터로 일반해를 쓰고 초기 조건을 맞춘다.
먼저 알아야 할 것
  • 고유값과 고유벡터 (3.1절), 연립 모델 (3.2절).

3.3.1고유벡터 방향으로 움직이는 해

1계 방정식 \(y' = ay\)의 해가 \(ce^{at}\)였던 것처럼, \(\mathbf y' = A\mathbf y\)에도 \(\mathbf y = \mathbf xe^{\lambda t}\)를 넣어 봅니다. 왼쪽은 \(\lambda\mathbf xe^{\lambda t}\), 오른쪽은 \(A\mathbf xe^{\lambda t}\)이므로 \(A\mathbf x = \lambda\mathbf x\)이면 해입니다. 곧 고유값과 고유벡터가 해를 줍니다.

정리 3.3.1

2×2 행렬 \(A\)가 서로 다른 고유값 \(\lambda_1, \lambda_2\)와 고유벡터 \(\mathbf x^{(1)}, \mathbf x^{(2)}\)를 가지면 \(\mathbf y' = A\mathbf y\)의 일반해는

\[\mathbf y = c_1\mathbf x^{(1)}e^{\lambda_1t} + c_2\mathbf x^{(2)}e^{\lambda_2t}.\]
예제 3.3.2

3.2절의 두 탱크 문제 \(y_1' = -0.02y_1 + 0.02y_2\), \(y_2' = 0.02y_1 - 0.02y_2\), \(y_1(0) = 150\), \(y_2(0) = 0\)을 풀어라.

풀이. \(\det(A - \lambda I) = (-0.02 - \lambda)^2 - 0.0004 = \lambda(\lambda + 0.04) = 0\). 고유값 0, \(-0.04\). \(\lambda = 0\)의 고유벡터 \(\begin{bmatrix}1\\1\end{bmatrix}\), \(\lambda = -0.04\)의 고유벡터 \(\begin{bmatrix}1\\-1\end{bmatrix}\).

\[\mathbf y = c_1\begin{bmatrix}1\\1\end{bmatrix} + c_2\begin{bmatrix}1\\-1\end{bmatrix}e^{-0.04t}.\]

\(t = 0\): \(c_1 + c_2 = 150\), \(c_1 - c_2 = 0\)이므로 \(c_1 = c_2 = 75\). \(y_1 = 75 + 75e^{-0.04t}\), \(y_2 = 75 - 75e^{-0.04t}\).

시간이 지나면 두 탱크 모두 75 kg으로 같아집니다. 고유값 0의 고유벡터 \(\begin{bmatrix}1\\1\end{bmatrix}\)이 "최종 균형 상태", 고유값 \(-0.04\)가 "균형으로 다가가는 빠르기"를 나타냅니다. 처음 차이 150 kg이 \(e^{-0.04t}\)로 줄어듭니다.

고유값이 복소수이면 해에 \(e^{\alpha t}(\cos\omega t, \sin\omega t)\)가 나타나고(2.2절과 같은 원리), 고유값이 중근이고 고유벡터가 하나뿐이면 \(te^{\lambda t}\)가 포함된 해가 필요합니다. 계산 방법은 교재 4.3절을 보세요.

요약
  1. \(\mathbf y = \mathbf xe^{\lambda t}\)가 해 \(\iff\) \(A\mathbf x = \lambda\mathbf x\).
  2. 일반해 \(c_1\mathbf x^{(1)}e^{\lambda_1t} + c_2\mathbf x^{(2)}e^{\lambda_2t}\). 초기 조건으로 \(c_1, c_2\)를 정한다.
  3. 음의 고유값은 줄어드는 모드, 0은 변하지 않는 모드, 양수는 커지는 모드.

3.3.2연습문제

기본

  1. \(y_1' = y_2\), \(y_2' = y_1\)의 일반해는?
    답

    \(A = \begin{bmatrix}0 & 1\\1 & 0\end{bmatrix}\), \(\lambda = \pm1\). \(\mathbf y = c_1\begin{bmatrix}1\\1\end{bmatrix}e^t + c_2\begin{bmatrix}1\\-1\end{bmatrix}e^{-t}\).

응용

  1. \(\mathbf y' = \begin{bmatrix}-5 & 2\\ 2 & -2\end{bmatrix}\mathbf y\), \(\mathbf y(0) = \begin{bmatrix}5\\0\end{bmatrix}\)을 풀어라(3.1절 예제의 행렬).
    답

    \(\mathbf y = c_1\begin{bmatrix}1\\2\end{bmatrix}e^{-t} + c_2\begin{bmatrix}2\\-1\end{bmatrix}e^{-6t}\). \(c_1 + 2c_2 = 5\), \(2c_1 - c_2 = 0\)에서 \(c_1 = 1\), \(c_2 = 2\).
