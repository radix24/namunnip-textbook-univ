상수계수 연립방정식의 풀이

본문

두 탱크의 비료 양은 서로 얽혀 있어서 \(y_1\)만 따로 풀 수 없다. 그런데 3.1절에서 행렬을 곱해도 방향이 그대로인 고유벡터를 보았다. 해가 고유벡터 방향으로만 움직인다면, 얽힌 두 양을 따로따로 풀리는 두 문제로 나눌 수 있지 않을까?

먼저 알아야 할 것고유값과 고유벡터(3.1절)와 연립 모델(3.2절)을 쓴다.

3.3.1고유벡터 방향으로 움직이는 해

1계 방정식 \(y' = ay\)의 해가 \(ce^{at}\)였던 것처럼, \(\mathbf y' = A\mathbf y\)에도 \(\mathbf y = \mathbf xe^{\lambda t}\)를 넣어 본다. 왼쪽은 \(\lambda\mathbf xe^{\lambda t}\), 오른쪽은 \(A\mathbf xe^{\lambda t}\)이므로 \(A\mathbf x = \lambda\mathbf x\)이면 해이다. 즉 처음 질문의 예상대로 고유값과 고유벡터가 해를 준다.

정리 3.3.1

2×2 행렬 \(A\)가 서로 다른 고유값 \(\lambda_1, \lambda_2\)와 고유벡터 \(\mathbf x^{(1)}, \mathbf x^{(2)}\)를 가지면 \(\mathbf y' = A\mathbf y\)의 일반해는

\[\mathbf y = c_1\mathbf x^{(1)}e^{\lambda_1t} + c_2\mathbf x^{(2)}e^{\lambda_2t}.\]
예제 3.3.2

3.2절의 두 탱크 문제 \(y_1' = -0.02y_1 + 0.02y_2\), \(y_2' = 0.02y_1 - 0.02y_2\), \(y_1(0) = 150\), \(y_2(0) = 0\)을 풀어라.

풀이. \(\det(A - \lambda I) = (-0.02 - \lambda)^2 - 0.0004 = \lambda(\lambda + 0.04) = 0\)이므로 고유값은 0, \(-0.04\)이다. \(\lambda = 0\)의 고유벡터는 \(\begin{bmatrix}1\\1\end{bmatrix}\), \(\lambda = -0.04\)의 고유벡터는 \(\begin{bmatrix}1\\-1\end{bmatrix}\)이다. 따라서 일반해는 다음과 같다.

\[\mathbf y = c_1\begin{bmatrix}1\\1\end{bmatrix} + c_2\begin{bmatrix}1\\-1\end{bmatrix}e^{-0.04t}\]

\(t = 0\)에서 \(c_1 + c_2 = 150\), \(c_1 - c_2 = 0\)이므로 \(c_1 = c_2 = 75\)이다. 그러므로 \(y_1 = 75 + 75e^{-0.04t}\), \(y_2 = 75 - 75e^{-0.04t}\)이다.

시간이 지나면 두 탱크 모두 75 kg으로 같아진다. 여기서 고유값 0의 고유벡터 \(\begin{bmatrix}1\\1\end{bmatrix}\)이 "최종 균형 상태"를, 고유값 \(-0.04\)가 "균형으로 다가가는 빠르기"를 나타낸다. 즉 처음 차이 150 kg이 \(e^{-0.04t}\)로 줄어든다. 그림 1에서 시간을 움직이면 점이 주황 점선을 따라서만 미끄러진다.

고유값이 복소수이면 해에 \(e^{\alpha t}(\cos\omega t, \sin\omega t)\)가 나타난다(2.2절과 같은 원리). 또 고유값이 중근이고 고유벡터가 하나뿐이면 \(te^{\lambda t}\)가 포함된 해가 필요하다. 계산 방법은 교재 4.3절을 본다.
마무리

\(\mathbf y = \mathbf xe^{\lambda t}\)가 해일 필요충분조건은 \(A\mathbf x = \lambda\mathbf x\)이므로, 일반해는 \(c_1\mathbf x^{(1)}e^{\lambda_1t} + c_2\mathbf x^{(2)}e^{\lambda_2t}\)이고 초기 조건으로 \(c_1, c_2\)를 정한다. 처음 질문처럼 얽힌 양이 고유벡터 방향의 모드로 나뉘며, 음의 고유값은 줄어드는 모드, 0은 변하지 않는 모드, 양수는 커지는 모드이다.

3.3.2연습문제

기본

  1. \(y_1' = y_2\), \(y_2' = y_1\)의 일반해는?
    답

    \(A = \begin{bmatrix}0 & 1\\1 & 0\end{bmatrix}\), \(\lambda = \pm1\). \(\mathbf y = c_1\begin{bmatrix}1\\1\end{bmatrix}e^t + c_2\begin{bmatrix}1\\-1\end{bmatrix}e^{-t}\).

응용

  1. \(\mathbf y' = \begin{bmatrix}-5 & 2\\ 2 & -2\end{bmatrix}\mathbf y\), \(\mathbf y(0) = \begin{bmatrix}5\\0\end{bmatrix}\)을 풀어라(3.1절 예제의 행렬).
    답

    \(\mathbf y = c_1\begin{bmatrix}1\\2\end{bmatrix}e^{-t} + c_2\begin{bmatrix}2\\-1\end{bmatrix}e^{-6t}\). \(c_1 + 2c_2 = 5\), \(2c_1 - c_2 = 0\)에서 \(c_1 = 1\), \(c_2 = 2\).
