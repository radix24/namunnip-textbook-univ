5.3.1스위치를 켜는 함수

정의 5.3.1 (단위 계단 함수)

\(u(t - a) = 0\) (\(t < a\)), \(1\) (\(t > a\)). 헤비사이드 함수라고도 한다.

시각 \(a\)에 스위치를 켜는 함수입니다. 함수에 곱하면 그 시각 이전을 지워 줍니다. 구간마다 다른 입력은 계단 함수의 합으로 씁니다. 예를 들어 \(1 \le t < 3\)에서만 전압 5를 거는 입력은 \(5[u(t - 1) - u(t - 3)]\)입니다.

\(\mathcal L\{u(t - a)\} = \int_a^\infty e^{-st}dt = \dfrac{e^{-as}}{s}\)입니다.

5.3.2t-이동

정리 5.3.2 (t-이동)

\(\mathcal L\{f(t)\} = F(s)\)이면 \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\).

그래프를 오른쪽으로 \(a\)만큼 옮기고 그 앞을 0으로 만들면, 변환에는 \(e^{-as}\)가 곱해집니다. 역변환에서 \(e^{-as}\)가 보이면 "\(a\)만큼 늦게 시작하는 함수"라고 읽습니다.

예제 5.3.3

\(f(t) = t^2\) (\(0 < t < 2\)), \(0\) (\(t > 2\))의 변환을 구하여라.

풀이. \(f = t^2[1 - u(t - 2)] = t^2 - t^2u(t - 2)\). t-이동을 쓰려면 \(t^2\)을 \((t - 2)\)로 나타내야 합니다: \(t^2 = (t - 2)^2 + 4(t - 2) + 4\). 따라서

\[F = \frac{2}{s^3} - e^{-2s}\left(\frac{2}{s^3} + \frac{4}{s^2} + \frac4s\right).\]
예제 5.3.4 (RC 회로에 펄스)

\(y' + y = u(t - 1) - u(t - 3)\), \(y(0) = 0\)을 풀어라.

풀이. \((s + 1)Y = \frac{e^{-s} - e^{-3s}}{s}\). \(\frac{1}{s(s + 1)} = \frac1s - \frac{1}{s + 1}\)의 역변환은 \(1 - e^{-t}\)이므로 t-이동으로

\[y = [1 - e^{-(t - 1)}]u(t - 1) - [1 - e^{-(t - 3)}]u(t - 3).\]

\(1 < t < 3\)에서는 1을 향해 올라가고, \(t > 3\)에서는 다시 0으로 내려옵니다. 구간마다 따로 풀어 이어 붙이지 않아도 한 번에 답이 나옵니다.

요약
  1. \(u(t - a)\): \(a\)에서 켜지는 스위치. \(\mathcal L = \frac{e^{-as}}{s}\).
  2. t-이동: \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\). 함수를 \(t - a\)의 식으로 고친 뒤 쓴다.

5.3.3연습문제

기본

  1. \(\mathcal L^{-1}\left\{\frac{e^{-2s}}{s^2}\right\}\)은?
    답

    \((t - 2)u(t - 2)\).

  2. \(t > \pi\)에서만 \(\sin t\)인 함수의 변환은?
    답

    \(\sin t\,u(t - \pi) = -\sin(t - \pi)u(t - \pi)\). \(-\frac{e^{-\pi s}}{s^2 + 1}\).
