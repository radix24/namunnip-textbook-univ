1계 선형 미분방정식과 베르누이 방정식

본문

\(y' - y = e^{2x}\)은 변수분리도 안 되고 완전형도 아니다. 그런데 왼쪽의 \(y' - y\)에 무언가를 곱하면 어떤 곱의 도함수로 깔끔하게 묶일 것 같다. 그런 곱수가 늘 있을까? 그리고 그렇게 얻은 해들 사이에는 어떤 짜임이 있을까?

먼저 알아야 할 것곱의 미분법과 적분(미분적분학(1))과 변수분리법(1.2절)을 쓴다.

1.4.1선형 미분방정식

\(y\)와 \(y'\)이 곱하거나 제곱하지 않고 1차로만 들어 있는 식을 선형이라 한다. 1계 선형 방정식의 표준형은 다음과 같다.

\[y' + p(x)\,y = r(x)\]

\(r(x) = 0\)이면 동차, 아니면 비동차라 한다. 동차이면 변수분리로 \(y = ce^{-\int p\,dx}\)를 얻는다. 비동차일 때 처음 질문의 곱수는 \(F = e^{\int p\,dx}\)이다. 이것을 양변에 곱하면 \(F' = Fp\)이므로 왼쪽이 곱의 도함수로 묶인다.

\[Fy' + Fp\,y = (Fy)'\]
정리 1.4.1 (1계 선형 방정식의 해)

\(h = \int p(x)\,dx\)라 하면 \(y' + py = r\)의 일반해는

\[y = e^{-h}\left(\int e^{h}r\,dx + c\right).\]

공식을 외우기보다 "\(e^{\int p\,dx}\)를 곱하면 왼쪽이 \((e^{h}y)'\)이 된다"는 과정을 기억하는 편이 낫다.

예제 1.4.2

\(y' - y = e^{2x}\), \(y(0) = 3\)을 풀어라.

풀이. \(p = -1\), \(h = -x\)이므로 \(F = e^{-x}\)이다. 곱하면 \((e^{-x}y)' = e^{x}\)이고, 적분하면 \(e^{-x}y = e^x + c\), 곧 \(y = e^{2x} + ce^x\)이다. \(y(0) = 1 + c = 3\)에서 \(c = 2\)이므로 답은 \(y = e^{2x} + 2e^x\)이다. 그림 1의 처음 상태가 이 해이다.

처음 질문의 짜임이 여기서 보인다. 일반해가 "비동차의 특수해 \(e^{2x}\)"와 "동차의 일반해 \(ce^x\)"의 합으로 나뉜다. 그림 1에서 \(c\)를 바꾸면 해 곡선이 모두 같은 특수해를 바탕으로 \(ce^x\)만큼씩 달라진다. 이 구조는 2단원의 2계 선형 방정식에서도 똑같다.

예제 1.4.3 (RC 회로)

저항 \(R\), 축전기 \(C\), 전압 \(E\)인 직류 전원을 \(t = 0\)에 연결했다. 축전기의 전하 \(q(t)\)를 구하여라(\(q(0) = 0\)).

풀이. 키르히호프 법칙에서 \(Rq' + \frac qC = E\), 곧 \(q' + \frac{1}{RC}q = \frac ER\)이다. \(F = e^{t/RC}\)를 곱해 적분하면 \(q = CE + ce^{-t/RC}\)이고, \(q(0) = 0\)에서 \(q = CE(1 - e^{-t/RC})\)이다. 즉 시간 상수 \(RC\)마다 남은 차이가 \(e^{-1} \approx 37\%\)로 줄어든다(일반물리학(2) 5.3절).

1.4.2베르누이 방정식

\(y' + p(x)y = g(x)y^a\)(\(a \ne 0, 1\))은 \(y^a\) 때문에 선형이 아니다. 하지만 \(u = y^{1-a}\)로 치환하면 선형이 된다. \(u' = (1 - a)y^{-a}y'\)이므로, 원래 식에 \((1 - a)y^{-a}\)를 곱하면 다음을 얻는다.

\[u' + (1 - a)p\,u = (1 - a)g\]

1.4.3개체군 모델: 로지스틱 방정식

\(y' = ky\)는 개체 수가 끝없이 늘어난다고 예측한다. 그런데 실제로는 먹이와 공간이 한정되어 있어 어느 수준에서 멈춘다. 그래서 늘어나는 빠르기가 개체 수와 "남은 여유"에 함께 비례한다고 놓은 것이 로지스틱 방정식이다.

\[y' = Ay - By^2 = Ay\left(1 - \frac{y}{K}\right), \qquad K = \frac AB\]

이것은 \(a = 2\)인 베르누이 방정식이므로 \(u = \frac1y\)로 치환하면 \(u' + Au = B\), \(u = \frac BA + ce^{-At}\)이다. 따라서 해는 다음과 같다.

\[y = \frac{K}{1 + Ce^{-At}}\]

처음에는 지수적으로 늘다가 \(K\)(환경 수용력)에 가까워지면 느려지며 \(K\)에 다가간다. 1.1절의 방향장(\(y' = y(1 - y)\))에서 본 S자 곡선이 바로 이것이다.

흔한 오해적분인자는 식이 어떤 꼴이든 \(e^{\int(\text{y의 계수})dx}\)라고 생각하기 쉽다. 하지만 먼저 \(y'\)의 계수를 1로 만들어야 한다. 가령 \(xy' + 2y = x^2\)이면 먼저 \(x\)로 나누어 \(y' + \frac2xy = x\)로 쓴 뒤 \(p = \frac2x\)를 쓴다.
마무리

1계 선형 방정식 \(y' + py = r\)은 \(e^{\int p\,dx}\)를 곱하면 왼쪽이 \((e^{\int p}y)'\)로 묶여 적분으로 풀린다. 처음 질문의 짜임은 "일반해 = 비동차 특수해 + 동차 일반해"이며, 베르누이 방정식은 \(u = y^{1-a}\)로 선형화하고 로지스틱 해는 \(y = K/(1 + Ce^{-At})\)이다.

1.4.4연습문제

기본

  1. \(y' + 2y = 4\)를 풀어라.
    답

    \((e^{2x}y)' = 4e^{2x}\), \(y = 2 + ce^{-2x}\).

  2. \(xy' + 2y = x^2\) (\(x > 0\))을 풀어라.
    답

    \(y' + \frac2xy = x\), \(F = x^2\). \((x^2y)' = x^3\), \(y = \frac{x^2}{4} + \frac{c}{x^2}\).

응용

  1. \(y' = 0.5y(1 - y/1000)\), \(y(0) = 100\)일 때 \(y\)가 500이 되는 시간은?
    답

    \(y = \frac{1000}{1 + 9e^{-0.5t}}\). \(500\)이면 \(9e^{-0.5t} = 1\), \(t = 2\ln9 \approx 4.39\).
