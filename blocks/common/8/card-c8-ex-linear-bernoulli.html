1계 선형 방정식과 베르누이 방정식은 어떻게 풀까?

예제 · 적분인자와 치환

(가) \(y' + \dfrac yx = x^2\) (\(x > 0\))의 일반해를 구하세요. (나) \(y' - y = -y^2\), \(y(0) = \tfrac12\)을 푸세요.

전략

(가)는 \(y' + p(x)y = r(x)\) 꼴의 선형 방정식입니다. 양변에 적분인자 \(F = e^{\int p\,dx}\)를 곱하면 왼쪽이 \((Fy)'\) 하나로 묶입니다. (나)는 \(y^2\) 때문에 선형이 아니지만 \(y' + py = gy^a\) 꼴(베르누이 방정식)이라 \(u = y^{1-a}\)로 바꾸면 선형이 됩니다.

풀이

  1. (가) \(F = e^{\int dx/x} = x\). 양변에 곱하면 \(xy' + y = x^3\), 곧 \((xy)' = x^3\).
    곱의 미분을 거꾸로 읽음.
  2. \(xy = \dfrac{x^4}4 + C\), \(y = \dfrac{x^3}4 + \dfrac Cx\).
    양변 적분.
  3. (나) \(a = 2\)이므로 \(u = y^{-1}\). \(u' = -y'/y^2 = -(y - y^2)/y^2 = -u + 1\), 곧 \(u' + u = 1\).
    베르누이 치환으로 선형 방정식이 됨.
  4. \(u = 1 + Ce^{-x}\), \(y = \dfrac1{1 + Ce^{-x}}\). \(y(0) = \tfrac12\)에서 \(C = 1\): \(y = \dfrac1{1 + e^{-x}}\).
    선형 방정식의 해와 초기 조건.

의미

(나)는 \(K = 1\), \(r = 1\)인 로지스틱 방정식(공통1 10.2절)이고, 답은 S자 곡선입니다. 변수분리로도 풀 수 있지만 베르누이 치환은 \(y' + py = gy^a\) 꼴이면 \(p\)와 \(g\)가 \(x\)의 함수여도 쓸 수 있습니다.

검산

(가) \(y = x^3/4 + C/x\)이면 \(y' = 3x^2/4 - C/x^2\), \(y' + y/x = 3x^2/4 - C/x^2 + x^2/4 + C/x^2 = x^2\). (나) \(y = 1/(1 + e^{-x})\)에서 \(y' = e^{-x}/(1 + e^{-x})^2 = y(1 - y)\). 맞습니다.

바꿔 보기

\(y' + 2y = e^{-2x}\)처럼 오른쪽이 적분인자와 같은 모양이면 \((e^{2x}y)' = 1\)이 되어 \(y = (x + C)e^{-2x}\)로, 지수함수에 \(x\)가 곱해집니다(공명과 같은 현상).

이해 확인

\(y' - \dfrac{2y}x = x^2\) (\(x > 0\))의 일반해를 구하세요.

답

\(F = x^{-2}\), \((y/x^2)' = 1\), \(y = x^3 + Cx^2\).
