매개변수변환법

본문

\(y'' + y = \sec x\)의 오른쪽은 미분할 때마다 새로운 함수가 나와서, 2.6절처럼 "같은 꼴"로 짐작할 수가 없다. 미정계수법이 통하지 않는 오른쪽에서도 특수해를 구하는 일반적인 방법이 있을까?

먼저 알아야 할 것론스키안(2.5절)과 비동차 방정식의 구조(2.6절)를 쓴다.

2.8.1상수를 함수로 바꾸기

처음 질문의 방법은 동차 해 \(c_1y_1 + c_2y_2\)의 상수 \(c_1, c_2\)를 함수 \(u(x), v(x)\)로 바꾸어 \(y_p = uy_1 + vy_2\)로 놓는 것이다. 그러면 \(u\)와 \(v\)에 대한 조건을 정리해 다음 공식을 얻으며, 이것을 매개변수변환법이라 한다.

정리 2.8.1 (매개변수변환법)

\(y'' + p(x)y' + q(x)y = r(x)\)의 동차 기저가 \(y_1, y_2\)이고 \(W = y_1y_2' - y_2y_1'\)이면

\[y_p = -y_1\int\frac{y_2r}{W}dx + y_2\int\frac{y_1r}{W}dx.\]

이때 방정식을 반드시 \(y''\)의 계수가 1인 표준형으로 바꾼 뒤 \(r\)을 읽어야 한다.

예제 2.8.2

\(y'' + y = \sec x\)를 풀어라.

풀이. \(y_1 = \cos x\), \(y_2 = \sin x\)이고 \(W = 1\)이다(2.5절). 그러면 다음과 같다.

\[y_p = -\cos x\int\sin x\sec x\,dx + \sin x\int\cos x\sec x\,dx = \cos x\ln|\cos x| + x\sin x\]

여기서 \(\int\tan x\,dx = -\ln|\cos x|\)를 썼다. 따라서 일반해는 \(y = (c_1 + \ln|\cos x|)\cos x + (c_2 + x)\sin x\)이다. 그림 1에서 \(x\)를 움직이면, \(y_p\)를 두 번 미분해 더한 값이 언제나 \(\sec x\)와 일치한다.

한편 미정계수법이 쓰일 수 있는 문제에도 이 방법을 쓸 수 있다. 하지만 적분이 번거로워 보통은 미정계수법이 더 빠르다.

마무리

매개변수변환법은 표준형으로 바꾼 뒤 기저 \(y_1, y_2\)와 \(W\)를 구해 \(y_p = -y_1\int\frac{y_2r}{W} + y_2\int\frac{y_1r}{W}\)로 계산한다. 처음 질문처럼 어떤 \(r\)에도 쓸 수 있지만, 미정계수법이 통하는 경우에는 그쪽이 빠르다.

2.8.2연습문제

응용

  1. \(y'' - 2y' + y = \frac{e^x}{x}\) (\(x > 0\))의 특수해를 구하여라.
    답

    \(y_1 = e^x\), \(y_2 = xe^x\), \(W = e^{2x}\). \(y_p = -e^x\int1\,dx + xe^x\int\frac1x dx = -xe^x + xe^x\ln x\). (\(-xe^x\)는 동차 해이므로 \(y_p = xe^x\ln x\)로 써도 된다.)
