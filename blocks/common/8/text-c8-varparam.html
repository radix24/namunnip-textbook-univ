2.8.1상수를 함수로 바꾸기

미정계수법은 오른쪽이 지수·다항·사인·코사인일 때만 씁니다. \(y'' + y = \sec x\)처럼 오른쪽이 다른 함수이면, 동차 해 \(c_1y_1 + c_2y_2\)의 상수 \(c_1, c_2\)를 함수 \(u(x), v(x)\)로 바꾸어 \(y_p = uy_1 + vy_2\)로 놓습니다. 조건을 정리하면 다음 공식이 나옵니다.

정리 2.8.1 (매개변수변환법)

\(y'' + p(x)y' + q(x)y = r(x)\)의 동차 기저가 \(y_1, y_2\)이고 \(W = y_1y_2' - y_2y_1'\)이면

\[y_p = -y_1\int\frac{y_2r}{W}dx + y_2\int\frac{y_1r}{W}dx.\]

방정식을 반드시 \(y''\)의 계수가 1인 표준형으로 바꾼 뒤 \(r\)을 읽어야 합니다.

예제 2.8.2

\(y'' + y = \sec x\)를 풀어라.

풀이. \(y_1 = \cos x\), \(y_2 = \sin x\), \(W = 1\) (2.5절).

\[y_p = -\cos x\int\sin x\sec x\,dx + \sin x\int\cos x\sec x\,dx = \cos x\ln|\cos x| + x\sin x.\]

(\(\int\tan x\,dx = -\ln|\cos x|\)를 썼습니다.) 일반해 \(y = (c_1 + \ln|\cos x|)\cos x + (c_2 + x)\sin x\).

미정계수법이 쓰일 수 있는 문제에도 이 방법을 쓸 수 있지만, 적분이 번거로워 보통은 미정계수법이 더 빠릅니다.

요약
  1. 표준형으로 바꾸고 기저 \(y_1, y_2\)와 \(W\)를 구한다.
  2. \(y_p = -y_1\int\frac{y_2r}{W} + y_2\int\frac{y_1r}{W}\). 어떤 \(r\)에도 쓸 수 있다.

2.8.2연습문제

응용

  1. \(y'' - 2y' + y = \frac{e^x}{x}\) (\(x > 0\))의 특수해를 구하여라.
    답

    \(y_1 = e^x\), \(y_2 = xe^x\), \(W = e^{2x}\). \(y_p = -e^x\int1\,dx + xe^x\int\frac1x dx = -xe^x + xe^x\ln x\). (\(-xe^x\)는 동차 해이므로 \(y_p = xe^x\ln x\)로 써도 된다.)
