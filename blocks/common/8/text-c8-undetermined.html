비동차 방정식과 미정계수법

본문

용수철에 바깥 힘이 작용하면 방정식의 오른쪽이 0이 아니게 된다. 그러면 중첩 원리가 깨져서 해 두 개를 더해도 해가 아니다. 그렇다면 비동차 방정식의 해는 어떤 짜임을 가지며, 오른쪽이 \(x^2\)나 \(e^{-1.5x}\)처럼 간단한 함수일 때는 해를 어떻게 짐작할 수 있을까?

먼저 알아야 할 것상수계수 동차 방정식(2.2절)을 쓴다.

2.6.1일반해의 구조

\(y'' + py' + qy = r(x)\)의 해 두 개를 빼면 오른쪽이 \(r - r = 0\)이 되어 동차 방정식의 해가 된다. 따라서 비동차 방정식의 해를 하나만 찾으면, 모든 해는 거기에 동차 방정식의 해를 더한 것이다. 이 하나를 특수해 \(y_p\)라 한다.

정리 2.6.1

비동차 방정식의 일반해는 \(y = y_h + y_p\)이다. \(y_h = c_1y_1 + c_2y_2\)는 동차 방정식의 일반해, \(y_p\)는 비동차 방정식의 특수해 하나이다.

이것이 처음 질문의 짜임이다. 즉 비동차 방정식을 풀 때는 동차 방정식과 특수해 하나를 따로 구해 더하면 되며, 1.4절의 1계 선형 방정식에서도 같은 구조를 보았다. 이때 초기 조건은 \(y_h + y_p\)를 다 만든 뒤에 넣는다.

2.6.2미정계수법

오른쪽 \(r(x)\)가 지수함수, 다항식, 사인·코사인과 그 곱이면, 이 함수들은 미분해도 같은 종류로 돌아온다. 그러므로 \(y_p\)도 같은 꼴로 짐작할 수 있으며, 계수만 모르는 채로 놓고 식에 넣어 계수를 정한다. 이것이 미정계수법이다.

\(r(x)\)에 있는 항\(y_p\)로 놓을 꼴
\(ke^{\gamma x}\)\(Ce^{\gamma x}\)
\(kx^n\)\(K_nx^n + \cdots + K_1x + K_0\)
\(k\cos\omega x\) 또는 \(k\sin\omega x\)\(K\cos\omega x + M\sin\omega x\)
\(ke^{\alpha x}\cos\omega x\) 등\(e^{\alpha x}(K\cos\omega x + M\sin\omega x)\)

두 가지 규칙이 덧붙는다. \(r\)이 여러 항의 합이면 각 항에 맞는 꼴을 더한다(합 규칙). 또 놓은 꼴이 이미 동차 방정식의 해이면 \(x\)를 곱하고, 중근 쪽이면 \(x^2\)을 곱한다(수정 규칙). 동차 해를 넣으면 왼쪽이 0이 되어 계수를 정할 수 없기 때문이다.

예제 2.6.2

\(y'' + y = 0.001x^2\), \(y(0) = 0\), \(y'(0) = 1.5\)를 풀어라.

풀이. \(y_h = A\cos x + B\sin x\)이다. \(y_p = K_2x^2 + K_1x + K_0\)으로 놓고 넣으면 \(2K_2 + K_2x^2 + K_1x + K_0 = 0.001x^2\)이다. 계수를 비교하면 \(K_2 = 0.001\), \(K_1 = 0\), \(K_0 = -0.002\)이므로 일반해는 \(y = A\cos x + B\sin x + 0.001x^2 - 0.002\)이다. 이제 \(y(0) = A - 0.002 = 0\), \(y'(0) = B = 1.5\)이므로 답은 \(y = 0.002\cos x + 1.5\sin x + 0.001x^2 - 0.002\)이다.

그림 1에서 범위를 10으로 좁히면 해는 거의 \(1.5\sin x\)처럼 보인다. 그런데 100까지 넓히면 \(0.001x^2\)이 10까지 자라 해 전체를 끌어올린다. 계수가 아주 작은 특수해도 오래 지나면 무시할 수 없다.

예제 2.6.3 (수정 규칙)

\(y'' + 3y' + 2.25y = -10e^{-1.5x}\)의 특수해를 구하여라.

풀이. 특성방정식이 \((\lambda + 1.5)^2 = 0\)으로 중근 \(-1.5\)이므로, \(e^{-1.5x}\)와 \(xe^{-1.5x}\)가 모두 동차 해이다. 그러므로 수정 규칙으로 \(y_p = Cx^2e^{-1.5x}\)로 놓는다. 넣어 정리하면 \(2Ce^{-1.5x} = -10e^{-1.5x}\)이므로 \(C = -5\), 곧 \(y_p = -5x^2e^{-1.5x}\)이다.

마무리

비동차 방정식의 일반해는 동차 일반해와 특수해의 합이며, 초기 조건은 마지막에 넣는다. 처음 질문처럼 오른쪽이 지수·다항·사인·코사인이면 같은 종류의 함수로 \(y_p\)를 놓고 계수를 맞추며, 놓은 꼴이 동차 해와 겹치면 \(x\)나 \(x^2\)을 곱한다.

2.6.3연습문제

기본

  1. \(y'' - y = 3e^{2x}\)의 일반해는?
    답

    \(y_p = Ce^{2x}\), \(4C - C = 3\), \(C = 1\). \(y = c_1e^x + c_2e^{-x} + e^{2x}\).

  2. \(y'' + 4y = 8\cos x\)의 특수해는?
    답

    \(y_p = K\cos x + M\sin x\): \(3K = 8\), \(M = 0\). \(y_p = \frac83\cos x\).

응용

  1. \(y'' + 4y = \sin2x\)의 특수해는?
    답

    \(\sin2x\)가 동차 해이므로 \(y_p = x(K\cos2x + M\sin2x)\). 넣으면 \(-4K\sin2x + 4M\cos2x = \sin2x\), \(K = -\frac14\), \(M = 0\). \(y_p = -\frac x4\cos2x\).
