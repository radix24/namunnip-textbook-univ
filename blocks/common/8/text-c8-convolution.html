합성곱과 적분방정식

본문
이 절에서 배울 것
  • 합성곱 \(f * g\)를 정의하고 \(\mathcal L\{f * g\} = FG\)를 쓴다.
  • 곱의 꼴인 변환의 역변환과 적분방정식을 푼다.
먼저 알아야 할 것
  • 라플라스 변환과 역변환 (5.1절, 5.4절).

5.5.1곱의 역변환

\(\mathcal L^{-1}\{FG\}\)는 \(\mathcal L^{-1}\{F\}\cdot\mathcal L^{-1}\{G\}\)가 아닙니다. 변환의 곱에 해당하는 것은 함수의 보통 곱이 아니라 다음의 합성곱입니다.

정의 5.5.1 (합성곱) \[(f * g)(t) = \int_0^t f(\tau)\,g(t - \tau)\,d\tau.\]
정리 5.5.2 (합성곱 정리)

\(\mathcal L\{f * g\} = F(s)G(s)\).

예제 5.5.3

\(\mathcal L^{-1}\left\{\dfrac{1}{s(s - a)}\right\}\)을 합성곱으로 구하여라.

풀이. \(\frac1s \to 1\), \(\frac{1}{s - a} \to e^{at}\). \(1 * e^{at} = \int_0^te^{a\tau}d\tau = \frac1a(e^{at} - 1)\). (부분분수로 구한 결과와 같습니다.)

합성곱의 뜻: 계의 충격 응답이 \(g\)이면, 입력 \(f\)를 시각 \(\tau\)마다 크기 \(f(\tau)\)인 작은 충격들의 연속으로 보고, 각 충격이 시각 \(t\)까지 남긴 효과 \(f(\tau)g(t - \tau)\)를 모두 더한 것이 응답입니다. 그래서 응답 = 입력 * 충격 응답입니다.

5.5.2적분방정식

미지 함수가 적분 안에 들어 있는 식을 적분방정식이라 합니다. 그 적분이 합성곱 꼴이면 라플라스 변환으로 쉽게 풉니다.

예제 5.5.4

\(y(t) - \int_0^ty(\tau)\sin(t - \tau)\,d\tau = t\)를 풀어라.

풀이. 적분은 \(y * \sin t\)입니다. 변환하면 \(Y - Y\frac{1}{s^2 + 1} = \frac{1}{s^2}\), 곧 \(Y\frac{s^2}{s^2 + 1} = \frac{1}{s^2}\), \(Y = \frac{s^2 + 1}{s^4} = \frac{1}{s^2} + \frac{1}{s^4}\). 따라서 \(y = t + \frac{t^3}{6}\).

요약
  1. \(f * g = \int_0^tf(\tau)g(t - \tau)d\tau\), \(\mathcal L\{f * g\} = FG\).
  2. 변환이 곱이면 역변환은 합성곱. 적분방정식도 변환으로 푼다.

5.5.3연습문제

기본

  1. \(t * t\)를 계산하고 합성곱 정리로 확인하여라.
    답

    \(\int_0^t\tau(t - \tau)d\tau = \frac{t^3}{6}\). 변환 \(\frac{1}{s^2}\cdot\frac{1}{s^2} = \frac{1}{s^4} \to \frac{t^3}{6}\).

응용

  1. \(\mathcal L^{-1}\left\{\frac{1}{(s^2 + 1)^2}\right\}\)을 합성곱으로 구하여라.
    답

    \(\sin t * \sin t = \frac12(\sin t - t\cos t)\).
