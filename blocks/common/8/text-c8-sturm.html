6.3.1경계값 문제

지금까지는 한 점에서 값과 기울기를 주는 초기값 문제를 풀었습니다. 양 끝이 고정된 줄처럼, 두 점에서 조건을 주는 문제도 있습니다. 예를 들어

\[y'' + \lambda y = 0, \qquad y(0) = 0,\ y(\pi) = 0.\]

\(y = 0\)은 언제나 해입니다. 그런데 특별한 \(\lambda\)에서만 0이 아닌 해가 있습니다. \(\lambda = k^2 > 0\)이면 \(y = A\cos kx + B\sin kx\)이고, \(y(0) = 0\)에서 \(A = 0\), \(y(\pi) = B\sin k\pi = 0\)이 \(B \ne 0\)이려면 \(k\)가 정수여야 합니다. (\(\lambda \le 0\)이면 0인 해만 나옵니다.)

따라서 \(\lambda = 1, 4, 9, \dots\)일 때 해 \(\sin x, \sin2x, \sin3x, \dots\)가 있습니다. 행렬의 고유값처럼, 이런 \(\lambda\)를 고유값, 해를 고유함수라 부릅니다. 기타 줄이 특정 음높이(기본음과 배음)로만 울리는 이유가 이것입니다.

6.3.2스투름-리우빌 문제와 직교성

정의 6.3.1 (스투름-리우빌 문제)

\([p(x)y']' + [q(x) + \lambda r(x)]y = 0\)에 구간 \([a, b]\) 양 끝의 경계 조건을 붙인 문제. \(r(x)\)를 가중함수라 한다.

\(p = r = 1\), \(q = 0\)이면 위의 \(y'' + \lambda y = 0\)이고, 르장드르 방정식(4.2절)과 베셀 방정식(4.4절)도 이 꼴로 쓸 수 있습니다.

정리 6.3.2 (직교성)

서로 다른 고유값에 대한 고유함수 \(y_m, y_n\)은 가중함수 \(r\)에 대해 직교한다: \(\int_a^br(x)y_m(x)y_n(x)\,dx = 0\). 또 고유값은 모두 실수이다.

이 정리는 6.1절의 사인·코사인의 직교성, 4.2절의 르장드르 다항식의 직교성을 모두 한꺼번에 설명합니다. 직교성이 있으면 6.1절처럼 계수를 적분으로 쉽게 구할 수 있어 다음 절의 "일반화된 푸리에 급수"가 가능해집니다.

양자역학의 슈뢰딩거 방정식도 스투름-리우빌 꼴입니다. 고유값이 에너지 준위, 고유함수가 파동함수가 됩니다. 원자의 에너지가 띄엄띄엄한 값만 갖는 이유가 여기에 있습니다(현대물리학, 물리화학).

요약
  1. 경계값 문제는 특정 \(\lambda\)(고유값)에서만 0이 아닌 해(고유함수)를 갖는다.
  2. \(y'' + \lambda y = 0\), \(y(0) = y(\pi) = 0\): \(\lambda = n^2\), \(y = \sin nx\).
  3. 스투름-리우빌 문제의 고유함수는 \(\int ry_my_n = 0\)으로 직교한다.

6.3.3연습문제

기본

  1. \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(L) = 0\)의 고유값과 고유함수를 구하여라.
    답

    \(\lambda = \left(\frac{n\pi}{L}\right)^2\), \(y = \sin\frac{n\pi x}{L}\) (\(n = 1, 2, \dots\)).

응용

  1. \(y'' + \lambda y = 0\), \(y'(0) = 0\), \(y'(\pi) = 0\)의 고유값과 고유함수는?
    답

    \(\lambda = n^2\) (\(n = 0, 1, 2, \dots\)), \(y = \cos nx\). (\(\lambda = 0\)이면 상수함수)
