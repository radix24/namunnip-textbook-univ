푸리에 급수

본문

악기의 소리, 심장 박동, 교류 전압처럼 주기적으로 되풀이되는 신호는 모양이 제각각이다. 그런데 모서리가 각진 사각파조차 매끄러운 사인파를 여러 개 더해서 만들 수 있다면, 복잡한 신호를 단순한 파동들로 쪼개어 다룰 수 있을 것이다. 어떤 사인파를 얼마씩 더해야 할까?

먼저 알아야 할 것삼각함수의 적분(미분적분학(1) 5.2절)과 급수의 수렴(미분적분학(1) 8단원)을 쓴다.

6.1.1복잡한 주기 신호를 단순한 파동으로

주기적인 신호는 모양이 복잡해도 진동수가 기본 진동수의 정수배인 사인파와 코사인파의 합으로 나타낼 수 있다. 테일러 급수가 함수를 \(x^n\)의 합으로 나타냈다면, 푸리에 급수는 \(\cos nx\), \(\sin nx\)의 합으로 나타낸다.

정의 6.1.1 (푸리에 급수)

주기 \(2\pi\)인 함수 \(f\)의 푸리에 급수는

\[f(x) = a_0 + \sum_{n=1}^\infty(a_n\cos nx + b_n\sin nx),\] \[a_0 = \frac{1}{2\pi}\int_{-\pi}^\pi f\,dx, \qquad a_n = \frac1\pi\int_{-\pi}^\pi f\cos nx\,dx, \qquad b_n = \frac1\pi\int_{-\pi}^\pi f\sin nx\,dx.\]

6.1.2계수 공식은 어디서 오는가: 직교성

\(m \ne n\)이면 \(\int_{-\pi}^\pi\cos mx\cos nx\,dx = 0\), \(\int_{-\pi}^\pi\sin mx\sin nx\,dx = 0\)이고, 언제나 \(\int_{-\pi}^\pi\cos mx\sin nx\,dx = 0\)이다. 곱을 합으로 바꾸는 공식으로 확인할 수 있다. 서로 다른 삼각함수의 곱을 한 주기 동안 적분하면 0이 된다는 이 성질을 직교성이라 한다. 벡터의 내적이 0이면 수직인 것처럼, 적분을 "함수의 내적"으로 보면 이 함수들은 서로 수직이다.

그래서 급수 양변에 \(\cos mx\)를 곱해 적분하면 다른 항은 모두 0이 되고 \(a_m\)의 항만 남아 \(\int f\cos mx\,dx = a_m\pi\)가 된다. 이것이 처음 질문의 "얼마씩"을 정하는 계수 공식이다. 벡터의 성분을 내적으로 구하는 것(미분적분학(1) 9.3절의 정사영)과 같은 원리이다.

예제 6.1.2 (사각파)

\(f(x) = -1\) (\(-\pi < x < 0\)), \(1\) (\(0 < x < \pi\))이고 주기 \(2\pi\)인 함수의 푸리에 급수를 구하여라.

풀이. \(f\)는 기함수이므로 \(a_0 = a_n = 0\)이다. 기함수와 우함수의 곱을 대칭 구간에서 적분하면 0이기 때문이다. 또 \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2}{n\pi}(1 - \cos n\pi)\)는 \(n\)이 짝수이면 0, 홀수이면 \(\frac{4}{n\pi}\)이다. 따라서 다음과 같다.

\[f(x) = \frac4\pi\left(\sin x + \frac13\sin3x + \frac15\sin5x + \cdots\right)\]

여기에 \(x = \frac\pi2\)를 넣으면 \(1 = \frac4\pi\left(1 - \frac13 + \frac15 - \cdots\right)\), 곧 미분적분학(1) 8.7절의 라이프니츠 급수 \(\frac\pi4 = 1 - \frac13 + \frac15 - \cdots\)가 나온다. 그림 1의 처음 상태는 5차까지의 세 항이다.

6.1.3수렴

정리 6.1.3

\(f\)가 한 주기에서 구간별로 연속이고 구간별로 매끄러우면, 푸리에 급수는 \(f\)가 연속인 점에서 \(f(x)\)로 수렴하고, 뛰어오르는 점에서는 왼쪽 극한과 오른쪽 극한의 평균으로 수렴한다.

사각파의 \(x = 0\)에서 급수는 \(\frac{-1 + 1}{2} = 0\)이며, 실제로 모든 항이 0이다. 그런데 항을 많이 더해도 뛰어오르는 점 근처에서 약 9% 튀어나오는 봉우리가 남는데, 이것을 기브스 현상이라 한다. 그림 1에서 \(N\)을 61까지 올려도 봉우리가 좁아질 뿐 높이는 약 1.18에 머문다. 이 절의 탐구 카드에서도 직접 볼 수 있다.

마무리

푸리에 급수는 주기 함수를 \(a_0 + \sum(a_n\cos nx + b_n\sin nx)\)로 나타내며, 처음 질문의 계수는 삼각함수의 직교성에서 적분으로 나온다. 기함수는 사인항만, 우함수는 코사인항과 상수만 남고, 불연속점에서는 양쪽 극한의 평균으로 수렴한다.

6.1.4연습문제

기본

  1. \(f(x) = x\) (\(-\pi < x < \pi\)), 주기 \(2\pi\)의 푸리에 급수를 구하여라.
    답

    기함수. \(b_n = \frac{2(-1)^{n+1}}{n}\). \(f = 2\left(\sin x - \frac{\sin2x}{2} + \frac{\sin3x}{3} - \cdots\right)\).

응용

  1. \(f(x) = |x|\) (\(-\pi < x < \pi\))의 푸리에 급수를 구하여라.
    답

    우함수. \(a_0 = \frac\pi2\), \(a_n = \frac{2}{\pi n^2}((-1)^n - 1)\). \(f = \frac\pi2 - \frac4\pi\left(\cos x + \frac{\cos3x}{9} + \cdots\right)\).
