변환의 미분과 적분

본문
이 절에서 배울 것
  • \(\mathcal L\{tf(t)\} = -F'(s)\), \(\mathcal L\{f(t)/t\} = \int_s^\infty F\,d\sigma\)로 새 변환을 구한다.
먼저 알아야 할 것
  • 라플라스 변환표 (5.1절).

5.6.1두 공식

변환의 정의 \(F(s) = \int_0^\infty e^{-st}f(t)dt\)를 \(s\)로 미분하면 적분 안에서 \(e^{-st}\)가 \(-te^{-st}\)로 바뀌므로

정리 5.6.1 \[\mathcal L\{tf(t)\} = -F'(s), \qquad \mathcal L\left\{\frac{f(t)}{t}\right\} = \int_s^\infty F(\sigma)\,d\sigma.\]

(둘째 식은 \(f(t)/t\)가 \(t \to 0\)에서 유한할 때 성립합니다.) \(t\)를 곱하면 \(s\)쪽에서 미분하고, \(t\)로 나누면 \(s\)쪽에서 적분합니다.

예제 5.6.2

\(\mathcal L\{t\sin\omega t\}\)를 구하여라.

풀이. \(-\dfrac{d}{ds}\dfrac{\omega}{s^2 + \omega^2} = \dfrac{2\omega s}{(s^2 + \omega^2)^2}\). 이 변환은 공명(2.7절)의 해 \(t\sin\omega t\)를 라플라스 변환으로 풀 때 나타납니다.

예제 5.6.3

\(\mathcal L^{-1}\left\{\ln\left(1 + \dfrac{\omega^2}{s^2}\right)\right\}\)을 구하여라.

풀이. \(F = \ln(s^2 + \omega^2) - 2\ln s\)이므로 \(-F' = -\frac{2s}{s^2 + \omega^2} + \frac2s\)이고, 이것의 역변환은 \(2 - 2\cos\omega t\)입니다. \(-F' = \mathcal L\{tf\}\)이므로 \(f = \dfrac{2(1 - \cos\omega t)}{t}\).

이 공식들은 계수가 \(t\)를 포함한 미분방정식(예: \(ty'' + y' + ty = 0\), 베셀 방정식)을 변환으로 풀 때도 쓰입니다(교재 6.6절).

요약
  1. \(t\) 곱하기 ↔ \(-\frac{d}{ds}\), \(t\)로 나누기 ↔ \(\int_s^\infty\).
