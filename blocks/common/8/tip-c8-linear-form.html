1계 선형 방정식은 \(y' + P(x)y = Q(x)\) 꼴로 맞춘 뒤 적분인자 \(e^{\int P\,dx}\)를 곱한다

요령 · 1계 선형 미분방정식

언제 쓰는가

\(y\)와 \(y'\)이 1차로만 나오지만 변수분리가 되지 않는 1계 방정식이다. \(xy' + 2y = x^2\)처럼 \(y'\) 앞에 계수가 붙어 있을 때 특히 쓴다.

요령

  1. 표준형으로
    \(y'\)의 계수로 양변을 나눠 \(y' + P(x)y = Q(x)\)로 만든다. 이 단계를 건너뛰면 \(P\)를 틀린다.
  2. 적분인자
    \(\mu = e^{\int P\,dx}\)를 구한다. 적분 상수는 붙이지 않는다.
  3. 곱의 미분으로 접는다
    양변에 \(\mu\)를 곱하면 왼쪽이 \((\mu y)'\)로 접힌다. 이것이 맞는지 한 번 미분해 확인한다.
  4. 적분하고 나눈다
    \(\mu y = \int\mu Q\,dx + C\), 그다음 \(\mu\)로 나눈다. 상수 \(C\)는 나누기 전에 붙인다.

흔한 실수

  • 표준형으로 나누지 않고 \(P\)를 읽어 \(xy' + 2y\)에서 \(P = 2\)로 잡는 것.
  • 마지막에 \(C\)를 \(\mu\)로 나누지 않아 \(\frac{C}{x^2}\) 대신 \(C\)라고 쓰는 것.

바로 풀어보기

\(xy' + 2y = x^2\) (\(x > 0\)), \(y(1) = 0\)을 풀어라.

답과 풀이

답: \(y = \frac{x^2}{4} - \frac{1}{4x^2}\)

표준형 \(y' + \frac2xy = x\)이므로 \(\mu = e^{\int 2/x\,dx} = x^2\)이다. 곱하면 \((x^2y)' = x^3\)이다.

\(x^2y = \frac{x^4}{4} + C\), \(y = \frac{x^2}{4} + \frac{C}{x^2}\). \(y(1) = 0\)에서 \(C = -\frac14\)이다. 검산: \(xy' + 2y = x\left(\frac x2 + \frac{1}{2x^3}\right) + \frac{x^2}{2} - \frac{1}{2x^2} = x^2\).

이 요령으로 풀리는 문제

  • 1계 상미분방정식 단원 연습 3번, 6번
영상 콘티 · 45초
  1. 0~5초\(xy' + 2y = x^2\)가 나타난다.변수분리가 안 될 때는?
  2. 5~12초\(y'\) 앞의 \(x\)가 빛나며 식 전체가 \(x\)로 나뉘어 \(y' + \frac2xy = x\)가 된다.먼저 표준형으로 맞춘다.
  3. 12~20초\(\frac2x\)가 위로 떠올라 지수에 들어가 \(e^{2\ln x} = x^2\)이 된다.적분인자를 만든다.
  4. 20~30초\(x^2\)가 식 왼쪽에 곱해지자 두 항 \(x^2y' + 2xy\)가 하나로 접히며 \((x^2y)'\)가 된다.곱의 미분으로 접힌다.
  5. 30~38초양변이 적분되어 \(x^2y = \frac{x^4}{4} + C\), 그다음 \(x^2\)로 나뉘며 \(C\)도 함께 \(\frac{C}{x^2}\)로 내려간다.적분하고 \(C\)까지 함께 나눈다.
  6. 38~45초\(P = 2\)로 잘못 읽은 경로가 \(e^{2x}\)를 만들다 X로 지워진다.표준형을 건너뛰면 틀린다.
