상수계수 2계 방정식은 특성방정식의 판별식으로 해의 모양 세 가지 가운데 하나를 고른다

요령 · 상수계수 동차 방정식

언제 쓰는가

\(ay'' + by' + cy = 0\)의 일반해나 초기값 문제를 풀 때이다.

요령

  1. 특성방정식
    \(y = e^{rx}\)를 넣어 \(ar^2 + br + c = 0\)을 얻는다.
  2. 판별식으로 고른다
    서로 다른 실근 \(r_1, r_2\): \(c_1e^{r_1x} + c_2e^{r_2x}\). 중근 \(r\): \((c_1 + c_2x)e^{rx}\). 복소근 \(\alpha \pm i\beta\): \(e^{\alpha x}(c_1\cos\beta x + c_2\sin\beta x)\).
  3. 초기 조건 두 개
    \(y(0)\)으로 첫 상수, \(y'(0)\)으로 둘째 상수를 정한다. 복소근이면 \(y'(0) = \alpha c_1 + \beta c_2\)이다.
  4. 모양으로 검산
    \(\alpha < 0\)이면 줄어드는 진동, 실근이 모두 음수면 진동 없이 줄어든다.

흔한 실수

  • 중근일 때 \(c_1e^{rx} + c_2e^{rx}\)로 써서 해가 하나뿐이 되는 것.
  • 복소근에서 \(e^{\alpha x}\)를 빠뜨리는 것.

바로 풀어보기

\(y'' + 4y' + 13y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.

답과 풀이

답: \(y = e^{-2x}\left(\cos3x + \frac23\sin3x\right)\)

\(r^2 + 4r + 13 = 0\)에서 판별식 \(16 - 52 < 0\), \(r = -2 \pm 3i\)이므로 \(y = e^{-2x}(c_1\cos3x + c_2\sin3x)\)이다.

\(y(0) = c_1 = 1\), \(y'(0) = -2c_1 + 3c_2 = 0\)에서 \(c_2 = \frac23\)이다.

이 요령으로 풀리는 문제

  • 2계 선형 상미분방정식 단원 연습 1번, 5번
  • 2계 선형 상미분방정식(진동) 단원 연습 1번, 5번
영상 콘티 · 40초
  1. 0~5초\(y'' + 4y' + 13y = 0\)이 나타나고 \(r^2 + 4r + 13 = 0\)으로 바뀐다.특성방정식부터.
  2. 5~13초판별식 계기의 바늘이 음수 쪽으로 넘어가고, 복소평면 위에 \(-2 \pm 3i\) 두 점이 찍힌다.판별식이 해의 모양을 고른다.
  3. 13~22초세 갈래 길(서로 다른 실근 · 중근 · 복소근) 표지판 중 '복소근'에 불이 들어오고, 줄어드는 진동 그래프가 그려진다.복소근이면 진동한다.
  4. 22~31초실부 \(-2\)는 포락선 \(e^{-2x}\)로, 허부 3은 진동수로 그래프 위에 표시된다.실부는 줄어드는 속도, 허부는 진동수.
  5. 31~40초\(x = 0\)에서 높이 1, 기울기 0인 접선이 그려지고 \(c_1 = 1\), \(c_2 = \frac23\)이 맞춰진다.초기 조건 두 개로 상수 두 개.
