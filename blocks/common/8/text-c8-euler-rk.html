7.1.1오일러 방법

대부분의 미분방정식은 해를 식으로 구할 수 없습니다. 하지만 \(y' = f(x, y)\)는 지금 위치에서의 기울기를 알려 주므로, 그 기울기로 조금 걸어가고, 새 위치에서 다시 기울기를 보고 조금 걸어가는 식으로 해 곡선을 따라갈 수 있습니다. 한 걸음의 폭을 \(h\)라 하면

\[x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h\,f(x_n, y_n).\]

이것이 오일러 방법입니다. 한 걸음마다 선형근사를 쓰는 셈입니다.

예제 7.1.1

\(y' = x + y\), \(y(0) = 0\)을 \(h = 0.2\)로 \(x = 0.6\)까지 오일러 방법으로 풀고 정확한 해 \(y = e^x - x - 1\)과 비교하여라.

7.1.24차 룽게-쿠타 방법

한 걸음 안에서 기울기를 네 번 재고 가중 평균을 내면 훨씬 정확해집니다.

\[k_1 = hf(x_n, y_n), \quad k_2 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_1}{2}\right), \quad k_3 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_2}{2}\right), \quad k_4 = hf(x_n + h, y_n + k_3),\] \[y_{n+1} = y_n + \tfrac16(k_1 + 2k_2 + 2k_3 + k_4).\]

처음, 가운데(두 번), 끝의 기울기를 1:2:2:1로 평균합니다(심프슨 공식과 같은 비율). 같은 예제를 \(h = 0.2\)로 풀면 \(x = 0.6\)에서 약 0.22211로, 정확한 값 0.22212와 소수 넷째 자리까지 맞습니다. 컴퓨터가 미분방정식을 풀 때 가장 널리 쓰는 기본 방법입니다.

요약
  1. 오일러: \(y_{n+1} = y_n + hf(x_n, y_n)\). 간단하지만 오차가 크다.
  2. 4차 룽게-쿠타: 기울기 네 개를 1:2:2:1로 평균. 같은 \(h\)에서 훨씬 정확하다.
