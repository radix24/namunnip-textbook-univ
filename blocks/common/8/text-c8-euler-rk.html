오일러 방법과 룽게-쿠타 방법

본문

대부분의 미분방정식은 해를 식으로 구할 수 없다. 그래도 \(y' = f(x, y)\)는 지금 위치에서 해 곡선이 어느 쪽으로 가는지 알려 준다. 방향장의 선분을 따라 조금씩 걸어가면 해 곡선을 따라갈 수 있을 것이다. 한 걸음을 어떻게 내디뎌야 곡선에서 덜 벗어날까?

먼저 알아야 할 것방향장(1.1절)과 선형근사(미분적분학(1) 2.5절)를 쓴다. 이 단원은 요람 개요에는 있지만 2026 진도에는 없는 보충 단원이며, 전자계산과 수치해석 과목으로 이어진다.

7.1.1오일러 방법

그러면 가장 간단한 걸음은 지금 위치의 기울기로 조금 걸어가고, 새 위치에서 다시 기울기를 보고 조금 걸어가는 것이다. 한 걸음의 폭을 \(h\)라 하면 다음과 같다.

\[x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h\,f(x_n, y_n)\]

이것이 오일러 방법이다. 즉 한 걸음마다 선형근사를 쓰는 셈이다.

예제 7.1.1

\(y' = x + y\), \(y(0) = 0\)을 \(h = 0.2\)로 \(x = 0.6\)까지 오일러 방법으로 풀고 정확한 해 \(y = e^x - x - 1\)과 비교하여라.

7.1.24차 룽게-쿠타 방법

처음 질문의 답은 한 걸음 안에서 기울기를 여러 번 재고 평균하는 것이다. 기울기를 네 번 재고 가중 평균을 내면 훨씬 정확해진다.

\[k_1 = hf(x_n, y_n), \quad k_2 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_1}{2}\right), \quad k_3 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_2}{2}\right), \quad k_4 = hf(x_n + h, y_n + k_3),\] \[y_{n+1} = y_n + \tfrac16(k_1 + 2k_2 + 2k_3 + k_4)\]

즉 처음, 가운데(두 번), 끝의 기울기를 1:2:2:1로 평균하며, 이것은 심프슨 공식과 같은 비율이다. 한편 같은 예제를 \(h = 0.2\)로 풀면 \(x = 0.6\)에서 약 0.22211로, 정확한 값 0.22212와 소수 넷째 자리까지 맞는다. 그림 1에서 방법을 바꾸면 파란 걸음이 주황 곡선 위에 거의 겹친다. 컴퓨터가 미분방정식을 풀 때 가장 널리 쓰는 기본 방법이다.

마무리

오일러 방법 \(y_{n+1} = y_n + hf(x_n, y_n)\)은 간단하지만 오차가 크다. 처음 질문처럼 덜 벗어나려면 한 걸음 안의 기울기를 여러 번 재어 평균하며, 4차 룽게-쿠타는 기울기 네 개를 1:2:2:1로 평균해 같은 \(h\)에서 훨씬 정확하다.
