감쇠의 세 경우 비교하기

실습 · 특성방정식의 근과 진동

목표

질량, 감쇠 계수, 용수철 상수를 바꿔 \(mx'' + cx' + kx = 0\)의 해를 그리고, 특성방정식의 근이 서로 다른 두 실근, 중근, 복소근일 때 각각 과감쇠, 임계감쇠, 미급감쇠가 됨을 확인한다. 성취기준 [공통8-02-02], [공통8-02-03].

준비

위 그래프는 \(x(0) = 1\), \(x'(0) = 0\)에서 놓은 변위, 아래는 같은 운동을 \((x, x')\) 평면(상평면)에 그린 것이다. 회색 점선은 미급감쇠일 때 진폭의 덮개 \(e^{-ct/2m}\)이다. "임계감쇠로 맞추기" 단추는 \(c = 2\sqrt{mk}\)로 맞춘다.

절차

  1. \(c = 0\)에서 진동 주기를 \(2\pi\sqrt{m/k}\)와 비교하고, 상평면 궤적이 닫힌 곡선인지 본다.
  2. \(c\)를 조금씩 올리며 근의 종류가 바뀌는 순간을 찾고, "임계감쇠로 맞추기"로 확인한다.
  3. 임계감쇠와 그보다 큰 \(c\)(과감쇠)에서 0 근처로 돌아오는 시간을 비교한다.
  4. \(m\)이나 \(k\)를 바꾸면 임계 감쇠 값이 어떻게 바뀌는지 본다.

기대 결과

  • \(c = 0\): 진폭이 줄지 않는 단순 조화 진동, 상평면은 타원.
  • 미급감쇠: 진동하며 덮개를 따라 줄어든다. 상평면은 안으로 감기는 나선.
  • 임계감쇠(\(m = 1, k = 2\)이면 \(c \approx 2.83\))는 진동 없이 가장 빨리 돌아오고, 과감쇠는 더 느리다.

분석

  1. 자동차 충격 흡수기나 문 닫힘 장치는 어느 경우에 가깝게 설계할까? 그 이유는?
  2. 감쇠가 있으면 진동수가 \(\omega_0\)보다 작아진다. 출력의 두 값을 비교하고, 근의 허수부와 연결해 보자.
