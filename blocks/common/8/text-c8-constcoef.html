상수계수 동차 방정식

본문

계수가 상수인 \(y'' + ay' + by = 0\)은 \(a\)와 \(b\)를 조금만 바꿔도 해가 지수적으로 줄어들기도, 진동하기도 한다. 이렇게 다른 모양의 해를 하나의 방법으로 모두 구할 수 있을까? 그리고 해가 어떤 모양일지는 무엇이 정할까?

먼저 알아야 할 것기저와 일반해(2.1절), 이차방정식의 근의 공식(고교 수학), 오일러 공식 \(e^{i\theta} = \cos\theta + i\sin\theta\)(미분적분학(1) 8.8절)를 쓴다.

2.2.1지수함수를 넣어 보기

계수가 상수이면 \(y\), \(y'\), \(y''\)이 서로 상수배만큼 다른 함수가 해일 것 같다. 그런 함수는 지수함수이다. \(y = e^{\lambda x}\)를 넣으면 \(y' = \lambda e^{\lambda x}\), \(y'' = \lambda^2e^{\lambda x}\)이므로 다음을 얻는다.

\[(\lambda^2 + a\lambda + b)e^{\lambda x} = 0\]

\(e^{\lambda x} \ne 0\)이므로 \(\lambda\)가 이차방정식 \(\lambda^2 + a\lambda + b = 0\)의 근이면 \(e^{\lambda x}\)가 해이다. 이 이차방정식을 특성방정식이라 한다. 즉 처음 질문의 하나의 방법이 이것이며, 미분방정식 풀기가 이차방정식 풀기로 바뀌었다. 그리고 해의 모양은 판별식 \(a^2 - 4b\)의 부호가 정한다. 판별식이 양수이면 두 실근, 0이면 중근, 음수이면 켤레 복소근이 나오며, 아래 표처럼 세 경우마다 기저가 다르다. 근의 공식이 아는 계산이므로, 이 단계에서 막히는 일은 거의 없다. 어려운 부분은 오히려 근을 해로 옮기는 마지막 단계이며, 특히 중근과 복소근에서 기저를 정확히 쓰는 것이 중요하다. 아래에서 두 경우를 차례로 살핀다.

2.2.2세 가지 경우

특성근기저일반해
서로 다른 실근 \(\lambda_1, \lambda_2\)\(e^{\lambda_1x}, e^{\lambda_2x}\)\(c_1e^{\lambda_1x} + c_2e^{\lambda_2x}\)
중근 \(\lambda = -\frac a2\)\(e^{\lambda x}, xe^{\lambda x}\)\((c_1 + c_2x)e^{\lambda x}\)
복소근 \(-\frac a2 \pm i\omega\)\(e^{-ax/2}\cos\omega x, e^{-ax/2}\sin\omega x\)\(e^{-ax/2}(A\cos\omega x + B\sin\omega x)\)

중근일 때는 \(e^{\lambda x}\) 하나만 나오므로, 다른 해는 2.1절의 계수 낮추기로 구한다. 그러면 \(xe^{\lambda x}\)가 나온다(2.1절 연습문제 2).

한편 복소근 \(\lambda = \alpha \pm i\omega\)이면 오일러 공식으로 \(e^{(\alpha + i\omega)x} = e^{\alpha x}(\cos\omega x + i\sin\omega x)\)이다. 이 복소수 해와 켤레 해를 더하고 빼서 2와 \(2i\)로 나누면, 중첩 원리에 따라 실수 해 \(e^{\alpha x}\cos\omega x\)와 \(e^{\alpha x}\sin\omega x\)를 얻는다.

예제 2.2.1

일반해를 구하여라. (가) \(y'' + y' - 2y = 0\) (나) \(y'' + 6y' + 9y = 0\) (다) \(y'' + 0.4y' + 9.04y = 0\)

풀이. (가) \(\lambda^2 + \lambda - 2 = (\lambda + 2)(\lambda - 1) = 0\)이므로 \(y = c_1e^x + c_2e^{-2x}\)이다. (나) \((\lambda + 3)^2 = 0\)으로 중근 \(-3\)이므로 \(y = (c_1 + c_2x)e^{-3x}\)이다. (다) \(\lambda = \dfrac{-0.4 \pm\sqrt{0.16 - 36.16}}{2} = -0.2 \pm 3i\)이므로 \(y = e^{-0.2x}(A\cos3x + B\sin3x)\)이다. 즉 진동하면서 진폭이 \(e^{-0.2x}\)로 줄어드는 해이다.

그림 1의 처음 상태가 (다)이다. 또 \(a = 6\), \(b = 9\)로 놓으면 두 근이 \(-3\)에서 겹치는 (나)가 되고, 해가 진동 없이 줄어든다.

예제 2.2.2

\(y'' + y' - 2y = 0\), \(y(0) = 4\), \(y'(0) = -5\)를 풀어라.

풀이. \(y = c_1e^x + c_2e^{-2x}\), \(y' = c_1e^x - 2c_2e^{-2x}\)이다. 그러면 \(c_1 + c_2 = 4\), \(c_1 - 2c_2 = -5\)에서 \(c_2 = 3\), \(c_1 = 1\)이므로 \(y = e^x + 3e^{-2x}\)이다.

흔한 오해복소근 \(\alpha \pm i\omega\)에서 지수에 허수부를, 사인·코사인 안에 실수부를 넣는 실수가 흔하다. 사인·코사인 안에 들어가는 것은 허수부 \(\omega\)이고, 지수에 들어가는 것은 실수부 \(\alpha\)이다.
마무리

\(y = e^{\lambda x}\)를 넣으면 특성방정식 \(\lambda^2 + a\lambda + b = 0\)을 얻으며, 처음 질문의 해의 모양은 이 근이 정한다. 서로 다른 실근이면 \(c_1e^{\lambda_1x} + c_2e^{\lambda_2x}\), 중근이면 \((c_1 + c_2x)e^{\lambda x}\), 복소근 \(\alpha \pm i\omega\)이면 \(e^{\alpha x}(A\cos\omega x + B\sin\omega x)\)이다.

2.2.3연습문제

기본

  1. (가) \(y'' - 9y = 0\) (나) \(y'' + 4y' + 4y = 0\) (다) \(y'' + 2y' + 5y = 0\)
    답

    (가) \(c_1e^{3x} + c_2e^{-3x}\) (나) \((c_1 + c_2x)e^{-2x}\) (다) \(e^{-x}(A\cos2x + B\sin2x)\)

응용

  1. \(y'' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 6\)을 풀어라.
    답

    \(y = A\cos2x + B\sin2x\), \(A = 1\), \(2B = 6\). \(y = \cos2x + 3\sin2x\).

  2. 일반해가 \(c_1e^{2x} + c_2e^{-x}\)인 상수계수 방정식을 구하여라.
    답

    \((\lambda - 2)(\lambda + 1) = \lambda^2 - \lambda - 2\). \(y'' - y' - 2y = 0\).
