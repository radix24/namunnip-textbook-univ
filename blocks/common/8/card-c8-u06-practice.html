Laplace 변환 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

변환 → 대수 → 부분분수 → 역변환. 마지막에 초기조건을 확인하여라.

  1. 계산\(\mathcal L\{e^{2t}\cos3t\}\)와 \(\mathcal L^{-1}\left\{\frac{s + 1}{s^2 + 2s + 10}\right\}\)을 구하여라. [05-01]

    힌트 1

    05-02 절의 표: \(e^{at}f(t) \leftrightarrow F(s - a)\).

    힌트 2

    \(s^2 + 2s + 10 = (s + 1)^2 + 9\).

    풀이

    \(\frac{s - 2}{(s - 2)^2 + 9}\). 둘째: \(\frac{s + 1}{(s + 1)^2 + 9} \leftrightarrow e^{-t}\cos3t\).

  2. 계산\(y'' - y = 0\), \(y(0) = 2\), \(y'(0) = 0\)을 Laplace 변환으로 풀어라. [05-02]

    힌트 1

    \(s^2Y - 2s - Y = 0\).

    힌트 2

    \(Y = \frac{2s}{s^2 - 1}\).

    풀이

    \(Y = \frac{2s}{(s-1)(s+1)} = \frac{1}{s - 1} + \frac{1}{s + 1}\), \(y = e^t + e^{-t} = 2\cosh t\).

  3. 계산RC 회로 \(q' + q = E(t)\) (\(RC = 1\) s), \(q(0) = 0\)에서 \(E(t)\)가 \(0 \le t < 2\)에서 1 V, 그 뒤 0인 직사각형 펄스이다. \(q(t)\)를 구하여라. [05-03]

    힌트 1

    \(E(t) = u(t) - u(t - 2)\).

    힌트 2

    \(Q = (1 - e^{-2s})\frac{1}{s(s+1)}\).

    풀이

    \(\frac{1}{s(s+1)} \leftrightarrow 1 - e^{-t}\). \(q = (1 - e^{-t}) - (1 - e^{-(t - 2)})u(t - 2)\). \(t < 2\): 충전 \(1 - e^{-t}\). \(t \ge 2\): \(e^{-(t-2)} - e^{-t} = (e^2 - 1)e^{-t}\)로 방전.

  4. 판단한 학생이 \(\mathcal L^{-1}\left\{\frac{1}{s(s + 1)}\right\} = \mathcal L^{-1}\left\{\frac1s\right\}\cdot\mathcal L^{-1}\left\{\frac{1}{s + 1}\right\} = 1\cdot e^{-t} = e^{-t}\)이라고 했다. 어디가 틀렸나요? [05-05]

    힌트 1

    05-05 절: 곱의 역변환은?

    힌트 2

    \(1 * e^{-t} = \int_0^te^{-\tau}d\tau\).

    풀이

    곱의 역변환은 역변환의 곱이 아니라 합성곱이다. \(1 * e^{-t} = 1 - e^{-t}\). 학생의 답 \(e^{-t}\)는 \(t = 0\)에서 1인데, \(\frac{1}{s(s+1)}\)의 역변환은 \(t = 0\)에서 0이어야 합니다(초기값 정리 \(\lim_{s\to\infty}sF(s) = 0\)).

  5. 개념왜 Laplace 변환은 "불연속인 입력"이 있는 문제에 특히 편한가요? 2단원의 미정계수법과 비교하여라. [05-03]

    힌트 1

    미정계수법으로 계단 입력을 풀려면?

    힌트 2

    구간마다 풀고 경계에서 이어 붙여야 한다.

    풀이

    미정계수법은 입력이 바뀔 때마다 구간을 나눠 풀고, 경계에서 \(y\)와 \(y'\)이 이어지도록 상수를 다시 맞춰야 한다. Laplace 변환은 \(u(t - a)\)가 \(e^{-as}\)로 바뀌어 전체를 한 번에 풀고, 초기조건도 자동으로 들어간다.

  6. 판단"\(\mathcal L\{e^{t^2}\}\)를 정의로 구하면 된다." 가능한가요? [05-01]

    힌트 1

    \(e^{-st}e^{t^2} = e^{t^2 - st}\).

    힌트 2

    \(t \to \infty\)이면 \(t^2 - st\)는?

    풀이

    불가능하다. 어떤 \(s\)에 대해서도 \(t^2 - st \to \infty\)라 적분이 발산한다. Laplace 변환은 \(|f(t)| \le Me^{ct}\)처럼 지수보다 빨리 커지지 않는 함수에만 정의된다.
