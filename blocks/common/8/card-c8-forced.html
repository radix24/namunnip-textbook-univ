강제 진동의 정상 상태 진폭과 공명

mx″ + cx′ + kx = F₀cos ωt · 진폭 곡선 · 맥놀이
무엇을 유도하나

정상 상태 해 \(x_p = A\cos(\omega t - \delta)\)의 진폭

\[A(\omega) = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2}}.\]

감쇠가 작으면 \(\omega \approx \omega_0 = \sqrt{k/m}\)에서 진폭이 크게 솟는다(공명).

모형

주기적 외력 \(F_0\cos\omega t\). 일반해 = 동차해(감쇠 때문에 시간이 지나면 사라지는 과도 응답) + 특수해(남는 정상 상태 응답). 오래 지나면 외력의 진동수 \(\omega\)로 진동한다.

유도

  1. 미정계수법(02-06 카드): \(x_p = a\cos\omega t + b\sin\omega t\).
    외력이 코사인이라 사인·코사인 둘 다 추측.
  2. 대입해 \(\cos\), \(\sin\) 계수 비교: \((k - m\omega^2)a + c\omega b = F_0\), \(-c\omega a + (k - m\omega^2)b = 0\).
    \(x_p'' = -\omega^2x_p\), \(x_p' = -a\omega\sin + b\omega\cos\).
  3. 풀면 \(a = \frac{F_0(k - m\omega^2)}{D}\), \(b = \frac{F_0c\omega}{D}\), \(D = (k - m\omega^2)^2 + (c\omega)^2\).
    2×2 연립(크라메르 공식).
  4. 진폭 \(A = \sqrt{a^2 + b^2} = \frac{F_0}{\sqrt D}\). 위상 지연 \(\tan\delta = \frac{c\omega}{k - m\omega^2}\).
    \(a\cos + b\sin = A\cos(\omega t - \delta)\).

결과 확인

  • \(\omega \to 0\): \(A \to \frac{F_0}{k}\). 아주 천천히 밀면 용수철이 정적으로 늘어나는 양.
  • \(\omega \to \infty\): \(A \to 0\). 너무 빨리 흔들면 질량이 따라가지 못함.
  • \(\omega = \omega_0\): 첫 항이 0이라 \(A = \frac{F_0}{c\omega_0}\). 감쇠가 작을수록 커짐. \(c = 0\)이면 무한대: 진폭이 \(t\)에 비례해 끝없이 커지는 해 \(\frac{F_0}{2m\omega_0}t\sin\omega_0t\) (02-R 문제 3).
  • 수치: \(m = 1\), \(k = 100\), \(c = 2\), \(F_0 = 10\)이면 \(\omega = 10\)에서 \(A = \frac{10}{20} = 0.5\) m, 정적 변위 0.1 m의 5배. \(c = 0.2\)이면 50배.

맥놀이와 한계

감쇠가 없고 \(\omega\)가 \(\omega_0\)에 가까우면, 처음 정지 상태에서 시작한 해는 \(\frac{2F_0}{m(\omega_0^2 - \omega^2)}\sin\frac{(\omega_0 - \omega)t}{2}\sin\frac{(\omega_0 + \omega)t}{2}\)로 진폭이 느리게 커졌다 작아집니다(맥놀이). 두 소리굽쇠가 조금 다른 음을 낼 때 "웅웅" 하는 소리이다. 실제 공명에서는 진폭이 커지면 비선형 효과(재료의 한계)가 나타나 이 선형 모형이 깨진다. 1940년 타코마 다리 붕괴는 단순 공명이 아니라 바람과 다리의 상호작용(자려 진동)이 원인이라는 것이 현재의 설명이다.
