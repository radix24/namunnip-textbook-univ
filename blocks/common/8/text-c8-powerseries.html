거듭제곱급수 방법

본문

2단원의 방법은 계수가 상수이거나 오일러-코시 꼴일 때만 통한다. 그런데 \(y'' + xy = 0\)처럼 계수가 \(x\)에 따라 변하면 해가 우리가 아는 함수로 나오지 않는 경우가 많다. 아는 함수가 없다면 해를 어떤 모양으로 찾아야 할까?

먼저 알아야 할 것거듭제곱급수와 항별 미분(미분적분학(1) 8.7절)과 테일러 급수(8.8절)를 쓴다.

4.1.1계수가 변하는 방정식

처음 질문의 답은 해를 거듭제곱급수로 놓고 계수를 하나씩 정하는 것이다. 해가 "무한 차수의 다항식"으로 나오는 셈이며, 이것을 거듭제곱급수 방법이라 한다.

4.1.2방법

먼저 \(y = \sum_{m=0}^\infty a_mx^m\)으로 놓고 \(y' = \sum ma_mx^{m-1}\), \(y'' = \sum m(m - 1)a_mx^{m-2}\)를 쓴다. 다음으로 방정식에 넣고, 모든 합이 같은 거듭제곱 \(x^s\)로 시작하도록 첨자를 바꾼다. 이어서 \(x^s\)의 계수를 0으로 놓으면 \(a_{s+2}\)를 앞의 계수로 나타내는 점화식을 얻는다. 이때 \(a_0\), \(a_1\)은 자유롭게 남으며, 이것이 일반해의 두 상수이다. 나머지 계수는 점화식으로 구한다.

예제 4.1.1

\(y'' + y = 0\)을 거듭제곱급수로 풀고, 이미 아는 해와 비교하여라.

풀이. 넣으면 \(\sum m(m - 1)a_mx^{m-2} + \sum a_mx^m = 0\)이다. 첫째 합에서 \(m = s + 2\)로 바꾸면 \(\sum_{s\ge0}(s + 2)(s + 1)a_{s+2}x^s\)이고, 둘째 합은 \(\sum_{s\ge0}a_sx^s\)이다. 따라서 \(x^s\)의 계수를 0으로 놓으면 다음 점화식을 얻는다.

\[a_{s+2} = -\frac{a_s}{(s + 2)(s + 1)}\]

그러면 \(a_2 = -\frac{a_0}{2!}\), \(a_4 = \frac{a_0}{4!}\), …, \(a_3 = -\frac{a_1}{3!}\), \(a_5 = \frac{a_1}{5!}\), …이므로 다음과 같다.

\[y = a_0\left(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\right) + a_1\left(x - \frac{x^3}{3!} + \cdots\right) = a_0\cos x + a_1\sin x\]

2.2절의 결과와 같다. 즉 이 방법이 맞게 동작한다는 확인이자, 급수로 나온 해가 어떤 함수인지 알아보는 연습이다. 그림 1의 처음 상태는 \(x^4\)까지의 부분합으로, \(|x| < 1.5\) 정도에서만 \(\cos x\)와 겹친다.

예제 4.1.2 (에어리 방정식)

\(y'' = xy\)의 급수해의 처음 몇 항을 구하여라.

풀이. 넣으면 \(\sum(s + 2)(s + 1)a_{s+2}x^s = \sum a_{s-1}x^s\)이며, 오른쪽은 \(s \ge 1\)부터이다. 그러므로 \(s = 0\)에서 \(a_2 = 0\)이고, \(s \ge 1\)에서 \(a_{s+2} = \frac{a_{s-1}}{(s + 2)(s + 1)}\)이다. 따라서 \(a_3 = \frac{a_0}{6}\), \(a_4 = \frac{a_1}{12}\), \(a_5 = 0\), \(a_6 = \frac{a_0}{180}\), …이고 해는 다음과 같다.

\[y = a_0\left(1 + \frac{x^3}{6} + \frac{x^6}{180} + \cdots\right) + a_1\left(x + \frac{x^4}{12} + \cdots\right)\]

이 해는 기본 함수로 쓸 수 없는 새로운 함수로, 광학과 양자역학에서 쓰는 에어리 함수이다. 즉 급수해 방법은 이렇게 새로운 함수를 만들어 낸다. 그림 1에서 에어리를 고르면 \(x < 0\)에서는 진동하고 \(x > 0\)에서는 빠르게 커지는 모양이 보인다. 다음 절의 르장드르 다항식, 베셀 함수도 같은 방식으로 나온다.

이 방법은 계수 \(p(x)\), \(q(x)\)가 \(x = 0\)에서 테일러 급수로 전개되는(해석적인) 경우에 통하고, 급수해의 수렴 반지름은 적어도 계수들의 수렴 반지름만큼은 된다. 계수가 0에서 무한히 커지는 경우에는 4.3절의 프로베니우스 방법을 쓴다.
마무리

\(y = \sum a_mx^m\)을 넣고 같은 거듭제곱의 계수를 맞추면 점화식을 얻으며, \(a_0\)과 \(a_1\)이 두 상수로 남는다. 처음 질문처럼 아는 함수가 없을 때도 이 급수가 해이며, 급수해는 \(\cos x\) 같은 아는 함수가 되기도 하고 에어리 함수 같은 새로운 함수를 정의하기도 한다.

4.1.3연습문제

기본

  1. \(y' = 2xy\)를 거듭제곱급수로 풀고 어떤 함수인지 말하여라.
    답

    \((s + 1)a_{s+1} = 2a_{s-1}\), \(a_1 = 0\). \(a_2 = a_0\), \(a_4 = \frac{a_0}{2}\), …. \(y = a_0(1 + x^2 + \frac{x^4}{2!} + \cdots) = a_0e^{x^2}\).

응용

  1. \(y'' - y = 0\)의 급수해를 구하고 \(\cosh x\), \(\sinh x\)와 비교하여라.
    답

    \(a_{s+2} = \frac{a_s}{(s+2)(s+1)}\). \(y = a_0\cosh x + a_1\sinh x\).
