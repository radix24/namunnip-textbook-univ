직교 급수와 일반화된 푸리에 급수

본문
이 절에서 배울 것
  • 직교 함수 \(y_0, y_1, \dots\)로 함수를 \(\sum a_my_m\)으로 전개하고 계수를 구한다.
  • 르장드르 다항식으로 함수를 전개해 본다.
먼저 알아야 할 것
  • 스투름-리우빌 문제와 직교성 (6.3절), 르장드르 다항식 (4.2절).

6.4.1사인·코사인 대신 다른 직교 함수로

푸리에 급수의 계수를 구할 수 있었던 이유는 직교성 하나였습니다. 그러므로 직교하는 함수의 모임 \(\{y_m\}\)만 있으면 같은 방법이 통합니다.

정리 6.4.1 (일반화된 푸리에 급수)

\(\{y_m\}\)이 \([a, b]\)에서 가중함수 \(r\)에 대해 직교하면, \(f = \sum a_my_m\)의 계수는

\[a_m = \frac{\int_a^brfy_m\,dx}{\int_a^bry_m^2\,dx}.\]

양변에 \(ry_n\)을 곱해 적분하면 \(m \ne n\)인 항이 모두 0이 되기 때문입니다. 분모 \(\|y_m\|^2 = \int ry_m^2\)은 \(y_m\)의 "길이의 제곱"입니다. 사인·코사인이면 6.1절의 공식이 됩니다.

예제 6.4.2 (푸리에-르장드르 급수)

\(f(x) = x^2\)을 \([-1, 1]\)에서 르장드르 다항식으로 전개하여라.

풀이. 르장드르 다항식은 \(r = 1\)로 직교하고 \(\int_{-1}^1P_m^2dx = \frac{2}{2m + 1}\)입니다. \(x^2\)은 2차이므로 \(P_0, P_1, P_2\)까지만 필요합니다. \(a_0 = \frac12\int_{-1}^1x^2dx = \frac13\), \(a_1 = 0\) (기함수), \(a_2 = \frac52\int_{-1}^1x^2\cdot\frac12(3x^2 - 1)dx = \frac54\left(\frac65 - \frac23\right) = \frac23\). 따라서 \(x^2 = \frac13P_0 + \frac23P_2\). (확인: \(\frac13 + \frac23\cdot\frac12(3x^2 - 1) = x^2\).)

일반화된 푸리에 급수는 \(f\)를 가장 잘 근사합니다. 처음 \(N\)개 항만 쓴다면, 그 계수를 위 공식으로 고를 때 오차의 제곱 적분이 가장 작아집니다(최소제곱 근사). 무한히 더해 오차가 0으로 가는 함수 모임을 "완전하다"고 합니다.

요약
  1. 직교 함수로 \(f = \sum a_my_m\), \(a_m = \frac{\int rfy_m}{\int ry_m^2}\).
  2. 사인·코사인이면 푸리에 급수, 르장드르 다항식이면 푸리에-르장드르 급수.
