오일러-코시 방정식

본문

\(x^2y'' - 1.5xy' - 1.5y = 0\)은 계수가 상수가 아니라 2.2절의 특성방정식을 쓸 수 없다. 그런데 \(x^2y''\), \(xy'\), \(y\)를 나란히 놓고 보면 무언가 규칙이 보인다. 지수함수 대신 어떤 함수를 넣어야 이 식이 이차방정식으로 바뀔까?

먼저 알아야 할 것상수계수 방정식의 세 경우(2.2절)와 로그의 성질(미분적분학(1) 1.2절)을 쓴다.

2.4.1거듭제곱을 넣어 보기

처음 질문의 규칙은 이렇다. \(y = x^m\)이면 \(x^2y''\), \(xy'\), \(y\)가 모두 \(x^m\)의 상수배가 된다(\(x^2\cdot m(m - 1)x^{m-2} = m(m - 1)x^m\)). 그래서 이 꼴의 방정식에는 지수함수 대신 거듭제곱을 넣는다. 2.2절에서 지수함수를 넣은 것과 같은 생각이다.

\[x^2y'' + axy' + by = 0 \;\Longrightarrow\; [m(m - 1) + am + b]x^m = 0\]

그러면 보조방정식 \(m^2 + (a - 1)m + b = 0\)의 근에 따라 해가 정해진다.

근일반해 (\(x > 0\))
서로 다른 실근 \(m_1, m_2\)\(c_1x^{m_1} + c_2x^{m_2}\)
중근 \(m\)\((c_1 + c_2\ln x)x^m\)
복소근 \(\mu \pm i\nu\)\(x^\mu[A\cos(\nu\ln x) + B\sin(\nu\ln x)]\)

2.2절의 표에서 \(e^{\lambda x}\) 자리에 \(x^m\), \(x\) 자리에 \(\ln x\)가 들어간 모양이다. 실제로 \(x = e^t\)로 치환하면 오일러-코시 방정식은 상수계수 방정식이 된다. 그림 1의 오른쪽이 바로 이 치환을 한 그림이다.

예제 2.4.1

(가) \(x^2y'' - 1.5xy' - 1.5y = 0\) (나) \(x^2y'' - 3xy' + 4y = 0\)

풀이. (가) \(m^2 - 2.5m - 1.5 = 0\)에서 \(m = 3, -\frac12\)이므로 \(y = c_1x^3 + \dfrac{c_2}{\sqrt x}\)이다. (나) \(m^2 - 4m + 4 = (m - 2)^2\)으로 중근 2이므로 \(y = (c_1 + c_2\ln x)x^2\)이다. 그림 1에서 두 방정식을 바꿔 보면, \(t\)에 대해서는 각각 \(e^{3t}\)와 \(e^{-t/2}\)의 합, \((c_1 + c_2t)e^{2t}\)로 보인다.

오일러-코시 방정식은 원통이나 구 모양 물체의 퍼텐셜, 열 분포를 구할 때 변수분리 뒤에 나온다(고등미적분학(2), 전자기학).
마무리

오일러-코시 방정식 \(x^2y'' + axy' + by = 0\)에는 처음 질문처럼 \(y = x^m\)을 넣어 보조방정식 \(m^2 + (a - 1)m + b = 0\)을 얻으며, \(a\)가 아니라 \(a - 1\)이 들어간다. 중근이면 \(\ln x\)를 곱한 해, 복소근이면 \(\cos(\nu\ln x)\)와 \(\sin(\nu\ln x)\)가 나오고, \(x = e^t\)로 바꾸면 상수계수 방정식이 된다.

2.4.2연습문제

기본

  1. \(x^2y'' - 2y = 0\)의 일반해는?
    답

    \(m^2 - m - 2 = 0\), \(m = 2, -1\). \(c_1x^2 + \frac{c_2}{x}\).

응용

  1. \(x^2y'' + xy' + 4y = 0\)의 일반해는?
    답

    \(m^2 + 4 = 0\), \(m = \pm2i\). \(A\cos(2\ln x) + B\sin(2\ln x)\).
