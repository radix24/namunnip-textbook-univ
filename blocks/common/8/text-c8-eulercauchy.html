오일러-코시 방정식

본문
이 절에서 배울 것
  • \(x^2y'' + axy' + by = 0\)에 \(y = x^m\)을 넣어 보조방정식을 얻고 세 경우로 푼다.
먼저 알아야 할 것
  • 상수계수 방정식의 세 경우 (2.2절), 로그의 성질 (공통1 1.2절).

2.4.1거듭제곱을 넣어 보기

\(x^2y''\), \(xy'\), \(y\)는 \(y = x^m\)일 때 모두 \(x^m\)의 상수배가 됩니다(\(x^2\cdot m(m - 1)x^{m-2} = m(m - 1)x^m\)). 그래서 이 꼴의 방정식에는 지수함수 대신 거듭제곱을 넣습니다.

\[x^2y'' + axy' + by = 0 \;\Longrightarrow\; [m(m - 1) + am + b]x^m = 0.\]

보조방정식 \(m^2 + (a - 1)m + b = 0\)의 근에 따라:

근일반해 (\(x > 0\))
서로 다른 실근 \(m_1, m_2\)\(c_1x^{m_1} + c_2x^{m_2}\)
중근 \(m\)\((c_1 + c_2\ln x)x^m\)
복소근 \(\mu \pm i\nu\)\(x^\mu[A\cos(\nu\ln x) + B\sin(\nu\ln x)]\)

2.2절의 표에서 \(e^{\lambda x}\) 자리에 \(x^m\), \(x\) 자리에 \(\ln x\)가 들어간 모양입니다. 실제로 \(x = e^t\)로 치환하면 오일러-코시 방정식은 상수계수 방정식이 됩니다.

예제 2.4.1

(가) \(x^2y'' - 1.5xy' - 1.5y = 0\) (나) \(x^2y'' - 3xy' + 4y = 0\)

풀이. (가) \(m^2 - 2.5m - 1.5 = 0\), \(m = 3, -\frac12\). \(y = c_1x^3 + \dfrac{c_2}{\sqrt x}\).

(나) \(m^2 - 4m + 4 = (m - 2)^2\), 중근 2. \(y = (c_1 + c_2\ln x)x^2\).

오일러-코시 방정식은 원통이나 구 모양 물체의 퍼텐셜, 열 분포를 구할 때 변수분리 뒤에 나옵니다(고등미적분학(2), 전자기학).

요약
  1. \(y = x^m\) → 보조방정식 \(m^2 + (a - 1)m + b = 0\) (\(a\)가 아니라 \(a - 1\)에 주의).
  2. 중근이면 \(\ln x\)를 곱한 해, 복소근이면 \(\cos(\nu\ln x)\), \(\sin(\nu\ln x)\).

2.4.2연습문제

기본

  1. \(x^2y'' - 2y = 0\)의 일반해는?
    답

    \(m^2 - m - 2 = 0\), \(m = 2, -1\). \(c_1x^2 + \frac{c_2}{x}\).

응용

  1. \(x^2y'' + xy' + 4y = 0\)의 일반해는?
    답

    \(m^2 + 4 = 0\), \(m = \pm2i\). \(A\cos(2\ln x) + B\sin(2\ln x)\).
