변환을 미분하면 원래 함수에 무엇이 곱해질까?

예제 · 라플라스 변환의 미분과 적분

\(\mathcal L\{t\sin\omega t\}\)와 \(\mathcal L\left\{\dfrac{\sin t}{t}\right\}\)를 구하여라.

전략

\(F(s) = \int_0^\infty e^{-st}f(t)\,dt\)를 \(s\)로 미분하면 피적분함수에 \(-t\)가 곱해진다: \(\mathcal L\{tf\} = -F'(s)\). 반대로 \(F\)를 \(s\)부터 \(\infty\)까지 적분하면 \(f\)가 \(t\)로 나뉜다: \(\mathcal L\{f/t\} = \int_s^\infty F(\sigma)\,d\sigma\).

풀이

  1. \(\mathcal L\{\sin\omega t\} = \dfrac{\omega}{s^2 + \omega^2}\).
    기본 변환표.
  2. \(\mathcal L\{t\sin\omega t\} = -\dfrac{d}{ds}\dfrac{\omega}{s^2 + \omega^2} = \dfrac{2\omega s}{(s^2 + \omega^2)^2}\).
    변환의 미분.
  3. \(\mathcal L\left\{\dfrac{\sin t}t\right\} = \displaystyle\int_s^\infty\frac{d\sigma}{\sigma^2 + 1} = \frac\pi2 - \arctan s = \arctan\frac1s\).
    변환의 적분. \(\sin t/t\)는 \(t \to 0\)에서 1로 가므로 조건을 만족.

의미

\(t\sin\omega t\)는 공명할 때 진폭이 시간에 비례해 커지는 응답입니다(\(y'' + \omega^2y = \sin\omega t\)의 해에 나옴). 분모가 제곱으로 겹친 꼴 \((s^2 + \omega^2)^2\)를 역변환할 때 이 결과를 거꾸로 쓴다.

검산

\(s \to 0^+\)이면 \(\arctan(1/s) \to \pi/2\)이고, 이것은 \(\int_0^\infty\frac{\sin t}t\,dt = \frac\pi2\)(공통9 1.1절의 디리클레 적분)과 맞다.

바꿔 보기

\(\mathcal L\{t^2e^{at}\}\)는 \(\dfrac1{s - a}\)를 두 번 미분해 \(\dfrac{2}{(s - a)^3}\). \(\mathcal L\{te^{at}\} = \dfrac1{(s - a)^2}\)과 함께 중근 꼴의 역변환에 쓴다.

이해 확인

\(\mathcal L\{t\cos\omega t\}\)를 구하여라.

답

\(-\dfrac{d}{ds}\dfrac{s}{s^2 + \omega^2} = \dfrac{s^2 - \omega^2}{(s^2 + \omega^2)^2}\).
