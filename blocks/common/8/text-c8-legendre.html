르장드르 방정식과 르장드르 다항식

본문

구 모양 물체 둘레의 전위나 온도를 구하면 각도 부분에서 르장드르 방정식이 나온다. 4.1절처럼 급수로 풀면 보통은 끝없는 급수가 나온다. 그런데 어떤 경우에는 급수가 저절로 끊겨 다항식이 된다. 언제 그렇게 되며, 그 다항식들은 어떤 성질을 가질까?

먼저 알아야 할 것거듭제곱급수 방법(4.1절)을 쓴다.

4.2.1르장드르 방정식

구면좌표에서 변수분리를 하면 각도 부분이 다음 방정식을 만족하며, 이것을 르장드르 방정식이라 한다(\(x = \cos\theta\)).

\[(1 - x^2)y'' - 2xy' + n(n + 1)y = 0\]

4.1절처럼 급수를 넣으면 다음 점화식을 얻는다.

\[a_{s+2} = -\frac{(n - s)(n + s + 1)}{(s + 2)(s + 1)}a_s\]

4.2.2급수가 끊기는 경우

처음 질문의 답은 점화식의 분자에 있는 \((n - s)\)이다. \(n\)이 0 이상의 정수이면 \(s = n\)에서 \(a_{n+2} = 0\)이 되고, 그 뒤로 두 칸씩 떨어진 계수가 모두 0이다. 그래서 짝수 항 또는 홀수 항 가운데 한쪽이 \(x^n\)에서 끊겨 다항식이 된다. 이 다항식을 \(x = 1\)에서 값이 1이 되도록 상수를 맞춘 것이 르장드르 다항식 \(P_n(x)\)이다.

\[P_0 = 1, \quad P_1 = x, \quad P_2 = \tfrac12(3x^2 - 1), \quad P_3 = \tfrac12(5x^3 - 3x)\]
예제 4.2.1

\(n = 2\)일 때 점화식으로 \(P_2\)를 구하여라.

풀이. 짝수 쪽은 \(a_2 = -\frac{2\cdot3}{2\cdot1}a_0 = -3a_0\), \(a_4 = -\frac{0\cdot5}{4\cdot3}a_2 = 0\)이다. 따라서 \(a_0(1 - 3x^2)\)이며, \(x = 1\)에서 1이 되도록 \(a_0 = -\frac12\)로 놓으면 \(P_2 = \frac12(3x^2 - 1)\)이다.

처음 질문의 둘째 물음에 답하면, 르장드르 다항식은 \([-1, 1]\)에서 서로 직교한다. 즉 \(m \ne n\)이면 \(\int_{-1}^1P_mP_n\,dx = 0\)이다. 그림 1의 처음 상태(\(P_1\)과 \(P_2\))에서 곱의 넓이가 왼쪽과 오른쪽에서 부호만 반대로 같아 합이 0이 된다. 이 성질 덕분에 함수를 \(\sum c_nP_n\)으로 전개할 수 있으며(6.4절의 일반화된 푸리에 급수), 원자 오비탈의 각도 모양과 전기 다중극 전개에 쓰인다.

마무리

르장드르 방정식 \((1 - x^2)y'' - 2xy' + n(n + 1)y = 0\)은 구 대칭 문제에서 나온다. 처음 질문처럼 \(n\)이 정수이면 급수가 끊겨 다항식 \(P_n\)(\(P_n(1) = 1\))이 되며, 서로 다른 \(P_n\)들은 \([-1, 1]\)에서 직교한다.

4.2.3연습문제

기본

  1. \(P_2\)가 \(n = 2\)인 르장드르 방정식을 만족함을 확인하여라.
    답

    \(y = \frac12(3x^2 - 1)\), \(y' = 3x\), \(y'' = 3\). \((1 - x^2)3 - 6x^2 + 3(3x^2 - 1) = 0\).

  2. \(\int_{-1}^1P_1P_2\,dx = 0\)을 확인하여라.
    답

    \(\frac12\int_{-1}^1(3x^3 - x)dx = 0\) (기함수).
