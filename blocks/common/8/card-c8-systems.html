연립 선형 미분방정식을 고유값 방법으로 풀기

x′ = Ax · 해 = Σ c e^(λt) v · 두 탱크 문제 · 문제 해결 전략

방법과 근거

\(\mathbf x' = A\mathbf x\)에 \(\mathbf x = e^{\lambda t}\mathbf v\)를 넣으면 \(\lambda e^{\lambda t}\mathbf v = e^{\lambda t}A\mathbf v\), 곧 \(A\mathbf v = \lambda\mathbf v\). 2단원의 \(e^{rx}\) 추측을 벡터로 올린 것이다. \(A\)가 일차독립인 고유벡터 \(n\)개를 가지면 일반해는

\[\mathbf x(t) = c_1e^{\lambda_1t}\mathbf v_1 + \dots + c_ne^{\lambda_nt}\mathbf v_n.\]

고계 방정식도 연립으로 바꿀 수 있다: \(y'' + by' + cy = 0\)은 \(x_1 = y\), \(x_2 = y'\)로 두면 \(\mathbf x' = \begin{pmatrix}0&1\\-c&-b\end{pmatrix}\mathbf x\)이고, 이 행렬의 특성방정식이 2단원의 특성방정식과 같다.

문제 해결 전략 · 연립 미분방정식과 역학계
  1. 방정식을 \(\mathbf x' = A\mathbf x\) 꼴로 쓴다(고계면 변수를 늘린다).
  2. 고유값과 고유벡터를 구한다(03-01 카드).
  3. 일반해를 쓰고 초기조건으로 상수를 정한다. 복소 고유값이면 실수부와 허수부로 실수해 두 개를 만든다.
  4. 고유값의 부호(실수부)로 \(t \to \infty\)의 행동과 평형점의 종류를 판정한다(03-04 카드).

물 100 L씩 든 두 탱크 A, B 사이로 분당 20 L씩 서로 흘러 들어가고(잘 섞임), 처음 A에 소금 30 kg, B에 0 kg이 있다. 소금 양 \(x_1(t), x_2(t)\)를 구하여라.

풀이

  1. \(x_1' = -0.2x_1 + 0.2x_2\), \(x_2' = 0.2x_1 - 0.2x_2\). \(A = \begin{pmatrix}-0.2&0.2\\0.2&-0.2\end{pmatrix}\).
    나감: \(\frac{x_1}{100}\times20\), 들어옴: \(\frac{x_2}{100}\times20\) (01-02 카드의 원리).
  2. \(\det(A - \lambda I) = (\lambda + 0.2)^2 - 0.04 = \lambda(\lambda + 0.4)\). 고유값 0, \(-0.4\).
    특성방정식.
  3. \(\lambda = 0\): \(\mathbf v_1 = (1, 1)\). \(\lambda = -0.4\): \(\mathbf v_2 = (1, -1)\).
    고유벡터.
  4. \(\mathbf x = c_1(1, 1) + c_2e^{-0.4t}(1, -1)\). \(t = 0\): \(c_1 + c_2 = 30\), \(c_1 - c_2 = 0\) → \(c_1 = c_2 = 15\).
    초기조건.
  5. \(x_1 = 15 + 15e^{-0.4t}\), \(x_2 = 15 - 15e^{-0.4t}\).
    각 성분.

의미

두 고유벡터가 각각 뜻을 가진다. \((1, 1)\) (고유값 0)은 "총량 보존", 곧 오래 지나 고르게 나뉜 상태. \((1, -1)\) (고유값 \(-0.4\))은 "두 탱크의 차이"로, 시간 상수 2.5분으로 사라진다. 고유벡터로 좌표를 바꾸면 얽힌 방정식이 서로 독립인 두 개로 풀린다. 진동하는 분자, 건물의 진동 모드도 같은 생각이다.

검산

\(x_1 + x_2 = 30\)이 늘 성립(소금 총량 보존). \(x_1' = -6e^{-0.4t}\), \(-0.2x_1 + 0.2x_2 = -0.2(30e^{-0.4t}) = -6e^{-0.4t}\). 맞다.
