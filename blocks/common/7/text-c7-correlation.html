10.1.1상관계수

공부 시간과 점수처럼 두 변수를 한 사람씩 짝지어 점으로 찍은 것이 산점도이다. 처음 질문의 수는 점들이 직선 주위에 얼마나 모여 있는지를 나타낸 상관계수이다.

\[r = \frac{1}{n - 1}\sum\left(\frac{x_i - \bar x}{s_x}\right)\left(\frac{y_i - \bar y}{s_y}\right)\]

상관계수는 \(-1 \le r \le 1\)이며, 부호가 방향을, 크기가 직선에 가까운 정도를 나타낸다. 점들이 오른쪽 위로 올라가면 양수이다. 또 z점수의 곱의 평균이므로 단위와 무관하다. 그런데 직선 관계만 재므로, \(y = x^2\)처럼 분명한 곡선 관계도 \(r \approx 0\)일 수 있다. 그리고 이상값 하나에 크게 흔들리므로 반드시 산점도를 먼저 본다.

예제 10.1.1

공부 시간 \(x\) = 1, 2, 3, 4, 5, 6시간, 점수 \(y\) = 52, 55, 61, 64, 70, 72점의 상관계수는?

풀이. 계산하면 \(r \approx 0.993\)이며, 엑셀 CORREL이나 R cor(x, y)로도 얻는다. 매우 강한 양의 직선 관계이다.

10.1.2상관은 인과가 아니다

처음 질문의 둘째 물음에 대한 답은 "아니다"이다. 아이스크림 판매량과 물놀이 사고는 양의 상관이 있지만, 아이스크림이 사고를 일으키지는 않는다. 둘 다 기온이라는 제3의 변수 때문에 함께 늘어나며, 이런 변수를 교란 변수라 한다. 그러므로 관찰 자료에서 상관이 보여도 원인이라고 말하려면 다른 설명을 배제해야 하고, 가장 확실한 방법은 무작위 배정 실험이다.

10.1.3손으로 계산해 보기, 그리고 이상값

공식의 각 항 \(\frac{x_i - \bar x}{s_x}\cdot\frac{y_i - \bar y}{s_y}\)는 점이 평균점 \((\bar x, \bar y)\)의 오른쪽 위나 왼쪽 아래에 있으면 양수, 나머지 두 사분면에 있으면 음수이다. 그래서 \(r\)은 "평균점을 기준으로 같은 방향에 놓인 점이 얼마나 많고 멀리 있는가"를 잰다. 실제 계산은 다음 꼴이 편하다.

\[r = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i - \bar x)^2\,\sum(y_i - \bar y)^2}}\]
예제 10.1.2

\(x\) = 1, 2, 3, 4, 5, \(y\) = 2, 4, 5, 4, 5의 상관계수를 손으로 구하여라.

풀이. \(\bar x = 3\), \(\bar y = 4\)이다. 편차는 \(x\)가 −2, −1, 0, 1, 2이고 \(y\)가 −2, 0, 1, 0, 1이다. 곱의 합은 \(4 + 0 + 0 + 0 + 2 = 6\)이고, \(\sum(x - \bar x)^2 = 10\), \(\sum(y - \bar y)^2 = 6\)이다. 따라서 \(r = \frac{6}{\sqrt{60}} = 0.775\)이다. 그림 1의 처음 상태가 이 자료이다.

그런데 이 자료에 점 \((12, 1)\) 하나만 더하면 \(r = -0.510\)으로 부호까지 바뀐다. 다른 점들과 멀리 떨어진 점은 편차가 커서 곱의 합을 혼자 좌우하기 때문이다. 그림 1에서 점을 추가하고 그 점의 \(y\)를 올려 보면 \(r\)이 음수에서 양수로 넘어간다. 숫자만 보지 말고 산점도를 먼저 그려야 하는 이유이다.

흔한 오해"\(r = 0\)이면 두 변수는 관계가 없다"는 틀리다. \(x\) = −2, −1, 0, 1, 2와 \(y = x^2\)은 \(y\)가 \(x\)로 완전히 정해지는데도 \(r = 0\)이다. \(r\)은 직선 관계만 잰다. 또 "\(r = 0.8\)은 \(r = 0.4\)보다 두 배 강하다"도 틀리다. 설명하는 변동의 비율 \(r^2\)으로 보면 0.64와 0.16, 네 배 차이이다.
마무리

상관계수 \(r\)은 z점수 곱의 평균으로, \(-1\)부터 1까지 직선 관계의 방향과 강도를 재며 단위와 무관하다. 곡선 관계는 잡지 못하고 이상값 하나에 크게 흔들리므로 산점도를 먼저 보며, 처음 질문처럼 상관이 커도 교란 변수가 있을 수 있어 인과로 읽지 않는다.
