이항분포의 모양과 두 근사

실습 · 포아송 근사, 정규 근사

목표

\(n\)과 \(p\)를 바꿔 이항분포의 모양을 보고 누적확률을 구한다. \(n\)이 크고 \(p\)가 작을 때의 포아송 근사, \(np\)와 \(n(1 - p)\)가 클 때의 정규 근사가 얼마나 잘 맞는지 확인한다. 성취기준 [공통7-04-02], [공통7-04-03].

준비

막대가 \(P(X = k)\)이고, 진한 막대가 \(k \le a\)인 부분(누적확률)이다. 주황 점은 같은 평균의 포아송 분포, 빨간 곡선은 같은 평균과 분산의 정규분포이다.

절차

  1. 4.2절 예제(\(n = 10\), \(p = 0.3\), \(a = 2\))의 누적확률을 확인한다.
  2. \(p\)를 0.1, 0.5, 0.9로 바꿔 분포가 치우치는 방향을 본다.
  3. \(n = 100\), \(p = 0.02\)로 놓고 포아송 점을 켜 본다.
  4. \(n = 100\), \(p = 0.5\)로 놓고 정규 곡선을 켜서 누적확률과 정규 근사를 비교한다.

기대 결과

  • \(P(X \le 2) \approx 0.383\).
  • \(p < 0.5\)면 오른쪽 꼬리, \(p > 0.5\)면 왼쪽 꼬리, 0.5면 대칭.
  • \(n = 100\), \(p = 0.02\)에서는 포아송(\(\lambda = 2\)) 점이 막대와 거의 겹친다.
  • \(n = 100\), \(p = 0.5\)에서는 정규 곡선이 막대 끝을 잘 따라가고, 연속성 보정한 근사값이 정확한 값과 소수 셋째 자리 정도까지 맞는다.

분석

  1. 정규 근사에서 \(P(X \le a)\)를 \(a + 0.5\)까지의 넓이로 구하는(연속성 보정) 이유를 막대의 폭으로 설명해 보자.
  2. \(n = 10\), \(p = 0.05\)에서는 정규 근사가 잘 맞지 않다. \(np\)를 계산해 이유를 말해 보자.
