이항분포는 네 조건부터 확인하고, '몇 개 이상'은 여사건으로 계산한다

요령 · 이항분포

언제 쓰는가

성공·실패가 되풀이되는 상황에서 성공 횟수의 확률을 묻는 문제입니다. '적어도', '이상'이 들어가 항이 많아질 때 쓴다.

요령

  1. 네 조건
    시행 횟수 \(n\)이 정해졌는가, 결과가 둘뿐인가, 성공 확률 \(p\)가 매번 같은가, 시행이 서로 독립인가를 확인한다. 되돌려 놓지 않고 뽑으면 \(p\)가 바뀐다.
  2. 한 항의 식
    \(P(X = k) = \binom nk p^k(1 - p)^{n-k}\).
  3. 항이 적은 쪽을 계산
    '3개 이상'처럼 항이 많으면 '2개 이하'를 구해 1에서 뺀다.
  4. 평균으로 검산
    \(E[X] = np\)이다. 답의 확률이 평균 근처에서 크게 나오는지 본다.

흔한 실수

  • '3개 이상'을 \(P(X = 3)\)만 계산하는 것.
  • 되돌려 놓지 않는 추출에 이항분포를 그대로 쓰는 것(표본이 모집단에 비해 클 때).

바로 풀어보기

5지선다 10문항을 모두 찍었을 때 3문항 이상 맞힐 확률을 구하여라.

답과 풀이

답: 약 0.32

네 조건이 모두 맞으므로 \(X \sim B(10, 0.2)\)이다. \(P(X \le 2) = 0.8^{10} + 10(0.2)(0.8)^9 + 45(0.04)(0.8)^8 \approx 0.107 + 0.268 + 0.302 = 0.678\)이다.

\(P(X \ge 3) = 1 - 0.678 \approx 0.322\)이다. 평균은 \(np = 2\)문항이라, 3문항 이상은 평균보다 조금 운이 좋은 경우이다.

이 요령으로 풀리는 문제

  • 이산형 확률변수 단원 연습 2번, 3번
영상 콘티 · 40초
  1. 0~5초OMR 카드 10줄에 무작위로 표시가 찍힌다.찍어서 3개 이상 맞힐 확률은?
  2. 5~13초체크리스트 네 칸(횟수 · 둘 중 하나 · 같은 확률 · 독립)에 차례로 체크가 붙는다.먼저 이항분포인지 확인한다.
  3. 13~22초0부터 10까지 막대그래프가 그려지고, 3 이상 막대 8개가 칠해지려다 멈춘다.칠할 막대가 너무 많다.
  4. 22~32초0, 1, 2 막대 세 개만 다른 색으로 칠해져 합 0.678이 뜨고, 1에서 빼는 화살표가 0.322를 낸다.적은 쪽을 구해서 1에서 뺀다.
  5. 32~40초막대그래프 위에 평균 \(np = 2\) 깃발이 꽂혀 가장 높은 막대 근처를 가리킨다.평균으로 감을 확인한다.
