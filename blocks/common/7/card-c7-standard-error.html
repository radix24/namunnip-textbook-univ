표본평균의 기대값과 표준오차

E[X̄] = μ · SE = σ/√n · 표본을 4배로 하면 오차는 절반
무엇을 유도하나

평균 \(\mu\), 표준편차 \(\sigma\)인 모집단에서 독립으로 뽑은 크기 \(n\)의 표본평균 \(\bar X\)에 대해 \(E[\bar X] = \mu\), \(\text{SD}(\bar X) = \frac{\sigma}{\sqrt n}\) (표준오차).

모형과 가정

관측값 \(X_1, \dots, X_n\)이 서로 독립이고 같은 분포(무작위 표본, 또는 모집단이 표본의 10배 이상인 비복원 추출). \(\bar X\)는 표본마다 달라지는 확률변수입니다(01-01 카드).

유도

  1. \(E[\bar X] = \frac1n(E[X_1] + \dots + E[X_n]) = \frac1n\cdot n\mu = \mu\).
    기대값의 선형성(04-01 카드). 독립이 아니어도 성립.
  2. \(\text{Var}(X_1 + \dots + X_n) = n\sigma^2\).
    독립이면 분산이 더해진다.
  3. \(\text{Var}(\bar X) = \frac{1}{n^2}n\sigma^2 = \frac{\sigma^2}{n}\), \(\text{SD}(\bar X) = \frac{\sigma}{\sqrt n}\).
    \(\text{Var}(aY) = a^2\text{Var}(Y)\), \(a = \frac1n\).

결과 확인

  • 치우침 없음: 평균적으로 \(\bar X\)는 \(\mu\)를 정확히 겨냥합니다. 편향(01-03 카드)이 있으면 이 성질이 깨집니다.
  • \(\sqrt n\): 표준오차를 절반으로 줄이려면 표본을 4배로 늘려야 합니다. 정밀도를 한 자리(10배) 올리려면 100배. 여론조사가 1000명 근처에서 멈추는 경제적 이유입니다.
  • 모집단 크기와 무관: 모집단이 충분히 크면 표준오차는 모집단 크기와 상관없습니다. 5000만 명 조사도 1000명이면 서울 1000만 명 조사와 같은 정밀도.
  • 예: 키 \(\sigma = 6\) cm, \(n = 36\)이면 \(\text{SE} = 1\) cm. 표본평균은 대략 \(\mu \pm 2\) cm 안에 95% 들어갑니다(다음 카드의 중심극한정리).

한계

관측값이 서로 독립이 아니면(같은 가족, 같은 반, 시계열) 실제 표준오차가 \(\frac{\sigma}{\sqrt n}\)보다 커서 지나치게 자신 있는 결론을 내리게 됩니다. \(\sigma\)를 모르면 표본표준편차 \(s\)로 대신해 \(\frac{s}{\sqrt n}\)을 씁니다(6단원).
