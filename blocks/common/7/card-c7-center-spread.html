중심과 퍼짐의 측도: 이상값 하나가 바꾸는 것

평균 · 중앙값 · 표준편차 · IQR · 저항성

정의와 성질

  • 평균 \(\bar x = \frac1n\sum x_i\). 표준편차 \(s = \sqrt{\frac{1}{n-1}\sum(x_i - \bar x)^2}\).
  • 중앙값: 크기순으로 늘어놓은 가운데 값. 사분위수 \(Q_1, Q_3\), 사분위범위 IQR = \(Q_3 - Q_1\).
  • 저항성: 극단값 하나에 크게 흔들리지 않는 성질. 중앙값과 IQR은 저항적, 평균과 표준편차는 아닙니다.
  • \(n - 1\)로 나누는 이유: 편차의 합이 0이라 \(n\)개 중 \(n - 1\)개만 자유롭고, 이렇게 나누면 \(s^2\)이 모분산의 치우치지 않은 추정량이 됩니다(5단원).
먼저 예측

직원 9명의 월급이 300만 원 근처인 회사에 사장(월급 5000만 원)을 넣어 계산하면 평균과 중앙값 중 무엇이 크게 바뀔까요?

예측 확인

평균이 크게 바뀌고, 중앙값은 거의 그대로입니다.

월급(만 원) 자료 280, 290, 300, 300, 310, 320, 330, 340, 350에 대해 평균, 중앙값, 표준편차, IQR을 구하세요. 그다음 5000을 더한 10개 자료로 다시 구하고 비교하세요.

풀이

  1. 9개: 합 2820, \(\bar x = 313.3\). 중앙값(5번째) 310.
    \(n = 9\) 홀수.
  2. 편차 제곱합: \(33.3^2 + 23.3^2 + 13.3^2 + 13.3^2 + 3.3^2 + 6.7^2 + 16.7^2 + 26.7^2 + 36.7^2 = 4400\). \(s = \sqrt{4400/8} = 23.5\).
    \(n - 1 = 8\)로 나눔.
  3. \(Q_1\) = 아래 4개(280, 290, 300, 300)의 중앙값 295, \(Q_3\) = 위 4개(320, 330, 340, 350)의 중앙값 335. IQR = 40.
    중앙값을 뺀 양쪽 절반의 중앙값(교재마다 규칙이 조금 다름).
  4. 10개(5000 추가): \(\bar x = 7820/10 = 782\). 중앙값 = 5, 6번째의 평균 \(\frac{310 + 320}{2} = 315\).
    \(n = 10\) 짝수.
  5. \(s \approx 1482\). \(Q_1 = 300\), \(Q_3 = 340\), IQR = 40.
    편차 제곱합의 대부분이 \((5000 - 782)^2\) 하나에서 온다.

의미

평균은 313에서 782로 2.5배, 표준편차는 약 63배가 됐지만, 중앙값은 5, IQR은 0 바뀌었습니다. 평균 782만 원은 10명 중 누구의 월급과도 닮지 않았습니다. 치우친 분포나 이상값이 있으면 중앙값과 IQR로 요약하고, 대칭 분포면 평균과 표준편차가 계산과 이론(정규분포)에 편리합니다. "평균 소득"보다 "중위 소득"이 정책에 쓰이는 이유입니다.

검산

상자그림 기준으로 5000은 \(Q_3 + 1.5\times\text{IQR} = 340 + 60 = 400\)을 훨씬 넘으므로 이상값으로 표시됩니다. 평균이 중앙값보다 크다는 것은 오른쪽 꼬리와 일치합니다.
