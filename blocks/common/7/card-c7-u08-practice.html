상관과 회귀 입문 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

먼저 산점도를 떠올리거나 그리세요(=CORREL, =SLOPE, =INTERCEPT).

  1. 계산\(x\): 1, 2, 3, 4, 5, \(y\): 2, 4, 5, 4, 5의 상관계수와 회귀 직선을 구하여라. [10-01, 10-02]

    힌트 1

    \(\bar x = 3\), \(\bar y = 4\).

    힌트 2

    \(S_{xy} = 6\), \(S_{xx} = 10\), \(S_{yy} = 6\).

    풀이

    편차 \(x\): −2, −1, 0, 1, 2. \(y\): −2, 0, 1, 0, 1. \(S_{xy} = 4 + 0 + 0 + 0 + 2 = 6\), \(S_{yy} = 4 + 0 + 1 + 0 + 1 = 6\). \(r = \frac{6}{\sqrt{60}} = 0.775\). \(b = 0.6\), \(a = 4 - 1.8 = 2.2\). \(\hat y = 2.2 + 0.6x\).

  2. 개념\(x\)가 −3, −2, −1, 0, 1, 2, 3이고 \(y = x^2\)일 때 상관계수는? 이것이 "두 변수가 관계없다"는 뜻인가요? [10-01]

    힌트 1

    10-01 절: 상관계수는 직선 관계만 잰다.

    힌트 2

    \(S_{xy} = \sum x(x^2 - \bar y)\)는 대칭이라?

    풀이

    \(r = 0\)입니다(대칭이라 양과 음의 곱이 상쇄). 그러나 \(y\)는 \(x\)로 완전히 정해진다. 상관계수 0은 "직선 관계가 없다"는 뜻일 뿐이다.

  3. 판단"지역별 소방관 수와 화재 피해액의 상관계수가 0.85이므로 소방관이 피해를 키운다." 무엇이 틀렸나요? [10-01]

    힌트 1

    두 변수 모두에 영향을 주는 변수는?

    힌트 2

    큰 화재일수록?

    풀이

    화재의 규모가 교란 변수(또는 역방향 원인)이다. 큰 불일수록 소방관이 많이 출동하고 피해도 크다. 같은 규모의 화재끼리 비교해야 소방관의 효과를 볼 수 있다.

  4. 계산어떤 지역에서 기온 \(x\) (℃)와 아이스크림 판매량 \(y\) (개)의 회귀 직선이 \(\hat y = -120 + 18x\), \(r = 0.9\)이다. 25 ℃일 때 예측 판매량과, 기울기의 뜻, \(r^2\)의 뜻을 써라. [10-02]

    힌트 1

    대입.

    힌트 2

    \(r^2 = 0.81\).

    풀이

    \(\hat y = -120 + 450 = 330\)개. 기울기: 기온이 1 ℃ 높은 날 평균 18개 더 팔림. \(r^2 = 0.81\): 판매량 변동의 81%가 기온과의 직선 관계로 설명됨. 0 ℃에서 −120개라는 절편은 자료 범위 밖이라 해석하지 않는다.

  5. 판단한 회사가 지난 5년 매출이 매년 20억 원씩 늘었다며 회귀 직선으로 "30년 뒤 매출 600억 원 증가"를 계획에 넣었다. 문제점은? [10-02]

    힌트 1

    자료 범위는 5년이다.

    힌트 2

    시장 포화, 경쟁, 경기 변화.

    풀이

    5년 자료로 30년을 외삽했다. 직선 추세가 그렇게 오래 이어진다는 근거가 없고, 성장은 보통 포화하거나 변동한다. 또 시간 자료는 해마다 독립이 아니라 단순 회귀의 불확실성 계산도 맞지 않다.

  6. 개념야구에서 "신인왕은 2년 차에 부진하다(2년 차 징크스)"는 말이 있다. 평균으로의 회귀로 설명해 보아라. [10-02]

    힌트 1

    10-02 절의 \(\hat z_y = rz_x\).

    힌트 2

    신인왕의 성적에는 실력과 운이 모두 들어 있다.

    풀이

    신인왕은 실력이 좋고 그해 운도 좋았던 선수일 가능성이 크다. 다음 해에는 운이 평균으로 돌아가 성적이 평균 쪽으로 내려오는 경향이 있다. 두 해 성적의 상관이 1보다 작은 한(운이 섞이는 한) 생기는 통계적 현상이며, 정신적 부담 같은 특별한 원인이 없어도 나타난다.
