값 하나를 끌어당겨 보기

실습 · 이상값과 로버스트한 측도

목표

자료 7개 가운데 한 값(빨간 점)을 크게 바꾸며 평균, 표준편차, 중앙값, IQR이 각각 얼마나 흔들리는지 비교한다. 상자그림에서 이상값이 표시되는 기준을 확인한다. 성취기준 [공통7-02-01].

준비

위쪽 점들이 자료, 아래가 상자그림이다. 빨간 점선은 평균이다. 나머지 6개 값은 2, 4, 4, 5, 7, 8로 고정되어 있다.

절차

  1. 값을 9에서 40, 60으로 바꾸며 네 측도를 기록한다(2.1절 예제는 40).
  2. 이상값으로 표시되기 시작하는 값을 찾는다.
  3. 값을 0으로 내려 작은 쪽 이상값도 확인한다.

기대 결과

  • 값을 크게 할수록 평균과 표준편차는 계속 커지지만, 중앙값과 IQR은 거의 그대로다.
  • \(Q_3 + 1.5\,\text{IQR}\)을 넘으면 상자그림에 따로 점이 찍힌다.

분석

  1. 평균은 값 하나가 끝없이 끌고 갈 수 있지만, 중앙값을 끝없이 움직이려면 자료의 몇 %를 바꿔야 할까?
  2. 이상값을 발견하면 무조건 지워야 할까? 입력 실수와 실제로 드문 값을 어떻게 구별할 수 있을까?

더 해 보기

가장 큰 값과 가장 작은 값을 하나씩 빼고 평균을 내는 "절사 평균"을 손으로 계산해, 이상값에 얼마나 강한지 비교해 보자.
