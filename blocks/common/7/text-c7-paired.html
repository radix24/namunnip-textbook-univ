짝지은 자료의 평균 차이

본문
이 절에서 배울 것
  • 같은 대상을 두 번 잰 자료를 차이 하나의 자료로 바꿔 검정한다.
  • 짝지은 설계가 독립 표본보다 유리한 이유를 안다.
먼저 알아야 할 것
  • t 분포 (7.1절), 두 평균의 비교 (9.1절).

9.3.1차이를 하나의 자료로

다이어트 전후의 체중, 같은 사람의 왼손과 오른손처럼 짝이 있는 자료는 두 집단이 독립이 아닙니다. 짝마다 차이 \(d = x_{\text{전}} - x_{\text{후}}\)를 계산하면 일표본 문제가 됩니다.

\[t = \frac{\bar d - 0}{s_d/\sqrt n}, \qquad \text{자유도 } n - 1.\]
예제 9.3.1

8명이 프로그램 전후로 잰 체중의 감소량(kg)이 2, 3, 1, 4, 0, 2, 3, 1이다. 체중이 줄었는지 유의수준 5%로 검정하여라. (자유도 7의 \(t^*\): 양측 2.365)

풀이. \(\bar d = 2\), \(s_d = \sqrt{\frac{12}{7}} \approx 1.31\), \(\text{SE} = \frac{1.31}{\sqrt8} \approx 0.463\). \(t = \frac{2}{0.463} \approx 4.32 > 2.365\). 기각. p값은 약 0.003으로 체중이 줄었다는 강한 증거가 있습니다.

9.3.2짝지은 설계의 장점

사람마다 체중이 크게 다르지만, 같은 사람의 전후 차이에서는 이 개인차가 지워집니다. 같은 자료를 독립인 두 집단처럼 잘못 분석하면 개인차가 표준오차에 그대로 들어가 효과를 못 찾기 쉽습니다(검정력이 떨어짐, 8.2절). 실험을 설계할 때 같은 대상을 두 조건에서 재거나, 비슷한 대상끼리 짝을 지으면 적은 표본으로 차이를 찾을 수 있습니다.

R t.test(before, after, paired = TRUE), 엑셀 T.TEST(범위1, 범위2, 2, 1).

요약
  1. 짝지은 자료: 차이 \(d\)의 일표본 t 검정. \(t = \bar d/(s_d/\sqrt n)\).
  2. 개인차가 지워져 검정력이 크다. 독립 표본 방법으로 분석하면 안 된다.
