이산형 확률변수의 기댓값과 분산

본문

1000원짜리 복권에 50만 원과 1만 원짜리 당첨이 걸려 있다. 한 장을 사면 대개 꽝이지만 가끔 큰돈을 받는다. 결과가 매번 다른 이런 시행에서 "평균적으로 얼마를 얻는가"와 "결과가 얼마나 들쭉날쭉한가"는 어떻게 계산할까?

먼저 알아야 할 것확률의 법칙(3.1절)과 평균과 분산(2.1절)을 쓴다.

4.1.1확률변수

시행의 결과에 수를 대응시킨 것을 확률변수 \(X\)라 한다. 가령 동전을 세 번 던져 나온 앞면의 수가 그렇다. \(X\)가 셀 수 있는 값만 가지면 이산형이라 하며, 각 값의 확률 \(P(X = x)\)를 모은 것을 확률분포(확률질량함수)라 한다. 이때 확률의 합은 1이다.

4.1.2기댓값과 분산

처음 질문의 "평균적으로"는 기댓값이다. 같은 시행을 아주 많이 되풀이할 때 \(X\)의 평균을 기댓값이라 하며, 각 값에 확률을 곱해 더한다. 그리고 기댓값에서 떨어진 정도의 제곱을 같은 방식으로 평균한 것이 분산이며, 그 제곱근이 표준편차이다.

\[E(X) = \mu = \sum xP(X = x), \qquad \text{Var}(X) = \sigma^2 = \sum(x - \mu)^2P(X = x) = E(X^2) - \mu^2, \qquad \sigma = \sqrt{\text{Var}(X)}\]

이 값들은 다음 성질을 가진다. 먼저 \(E(aX + b) = aE(X) + b\)이고 \(\text{Var}(aX + b) = a^2\text{Var}(X)\)이다. 또 \(X\)와 \(Y\)가 독립이면 \(\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)\)이다. 그림 1에서 \(n\)을 늘리면 분산이 한 번에 0.25씩 늘어나는 것이 이 성질이다.

예제 4.1.1

동전을 세 번 던져 나온 앞면의 수 \(X\)의 분포, 기댓값, 분산을 구하여라.

풀이. 결과 8가지가 같은 확률이므로 \(P(X = 0, 1, 2, 3) = \frac18, \frac38, \frac38, \frac18\)이다. 따라서 \(E(X) = \frac{0 + 3 + 6 + 3}{8} = 1.5\)이다. 또 \(E(X^2) = \frac{0 + 3 + 12 + 9}{8} = 3\)이므로 \(\text{Var}(X) = 3 - 1.5^2 = 0.75\)이다. 그림 1의 처음 상태가 이 분포이며, 받침점이 1.5에 놓인다.

예제 4.1.2

1000원짜리 복권에 당첨 확률 0.001로 50만 원, 0.01로 1만 원이 걸려 있다. 순이익의 기댓값은?

풀이. 상금의 기댓값은 \(500000(0.001) + 10000(0.01) = 600\)원이다. 그러므로 순이익의 기댓값은 \(600 - 1000 = -400\)원이다. 즉 처음 질문의 복권은 한 장 살 때마다 평균 400원을 잃는다.

마무리

기댓값 \(E(X) = \sum xP(X = x)\)는 확률분포의 무게중심이고, 분산은 \(E(X^2) - \mu^2\)으로 계산한다. \(E(aX + b) = aE(X) + b\), \(\text{Var}(aX + b) = a^2\text{Var}(X)\)이며, 독립인 확률변수를 더하면 분산도 더해진다.
