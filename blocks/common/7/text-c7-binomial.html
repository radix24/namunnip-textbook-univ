이항분포

본문

불량률이 30%인 공정에서 제품 10개를 뽑으면 불량품은 몇 개쯤 나올까? 평균은 3개일 것 같지만, 정확히 3개가 나올 확률은 생각보다 낮다. 같은 시행을 여러 번 되풀이할 때 성공 횟수의 분포는 어떻게 구할까?

먼저 알아야 할 것독립과 곱셈 법칙(3.1절), 기댓값(4.1절)을 쓴다.

4.2.1조합

서로 다른 \(n\)개 가운데 순서를 생각하지 않고 \(k\)개를 고르는 방법의 수는 다음과 같다.

\[\binom nk = \frac{n!}{k!(n - k)!}, \qquad n! = n(n - 1)\cdots2\cdot1\]

가령 5명 가운데 2명을 뽑는 방법은 \(\frac{5\cdot4}{2\cdot1} = 10\)가지이다.

4.2.2이항분포

이제 결과가 성공과 실패 둘뿐이고, 매번 성공 확률이 \(p\)로 같으며, 시행들이 서로 독립이라고 하자. 이런 시행을 \(n\)번 할 때 성공 횟수 \(X\)는 이항분포 \(B(n, p)\)를 따르며, 확률은 다음과 같다.

\[P(X = k) = \binom nkp^k(1 - p)^{n - k}, \qquad k = 0, 1, \dots, n\]

왜냐하면 성공 \(k\)번, 실패 \(n - k\)번이 나오는 특정한 순서 하나의 확률은 독립이므로 \(p^k(1 - p)^{n - k}\)이기 때문이다. 그리고 성공이 몇 번째에 나오는지 고르는 방법이 \(\binom nk\)가지이므로 그만큼 곱한다.

정리 4.2.1

\(X \sim B(n, p)\)이면 \(E(X) = np\), \(\text{Var}(X) = np(1 - p)\).

즉 한 번의 시행은 평균 \(p\), 분산 \(p(1 - p)\)이고, 독립인 \(n\)번을 더했기 때문이다(4.1절의 분산의 덧셈).

예제 4.2.2

불량률이 30%인 공정에서 10개를 뽑는다. 불량품이 정확히 3개일 확률, 2개 이하일 확률, 평균과 표준편차는?

풀이. \(P(X = 3) = \binom{10}{3}(0.3)^3(0.7)^7 = 120\times0.027\times0.0824 \approx 0.267\)이다. 다음으로 \(P(X \le 2) = P(0) + P(1) + P(2) \approx 0.028 + 0.121 + 0.233 = 0.383\)이다. 평균은 \(np = 3\)이고, 표준편차는 \(\sqrt{2.1} \approx 1.45\)이다. 그림 1의 처음 상태에서 빨간 막대가 0.267이고, \(k\)를 2로 내리면 누적 확률 0.383이 나온다. 처음 질문의 답처럼 평균이 3이어도 정확히 3개일 확률은 27% 정도이다.

한편 프로그램으로는 엑셀 =BINOM.DIST(3, 10, 0.3, FALSE), R dbinom(3, 10, 0.3)으로 구하며, 누적은 pbinom(2, 10, 0.3)이다.

마무리

성공 확률이 \(p\)인 독립 시행을 \(n\)번 할 때 성공 횟수는 \(B(n, p)\)를 따르고, \(P(X = k) = \binom nkp^k(1 - p)^{n - k}\)이다. 평균은 \(np\), 분산은 \(np(1 - p)\)이며, 처음 질문 같은 "몇 개 이하" 확률은 막대를 누적해 구한다.
