이산확률변수의 기대값과 분산

E[X] = Σx p(x) · Var = E[X²] − (E[X])² · 복권 · 보험

정의와 뜻

  • 확률변수 \(X\): 우연한 결과에 수를 대응시킨 것. 확률분포 \(p(x) = P(X = x)\).
  • 기대값 \(\mu = E[X] = \sum xp(x)\): 아주 여러 번 되풀이할 때 평균(큰 수의 법칙). 확률을 무게로 둔 무게중심.
  • 분산 \(\sigma^2 = E[(X - \mu)^2] = E[X^2] - \mu^2\), 표준편차 \(\sigma\).
  • 성질: \(E[aX + b] = aE[X] + b\), \(\text{Var}(aX + b) = a^2\text{Var}(X)\). \(E[X + Y] = E[X] + E[Y]\) (늘), \(\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)\) (독립일 때).
먼저 예측

1000원짜리 복권의 기대 상금이 500원이라면, 이 복권을 사는 것은 평균적으로 이득일까, 손해일까?

예측 확인

한 장당 평균 500원 손해이다. 그래도 사람들이 사는 것은 큰 상금의 작은 확률에 다른 가치를 두기 때문이고, 기대값만으로는 그 선택을 설명하지 못한다.

1000원짜리 즉석 복권: 1등 100만 원(확률 \(\frac{1}{10000}\)), 2등 1만 원(\(\frac{1}{100}\)), 3등 1000원(\(\frac{1}{10}\)), 나머지 꽝. 순이익 \(X\)의 기대값과 표준편차를 구하여라.

풀이

  1. 상금 \(W\)의 기대값: \(10^6\times10^{-4} + 10^4\times10^{-2} + 10^3\times10^{-1} = 100 + 100 + 100 = 300\)원.
    \(\sum wp(w)\). 꽝은 0.
  2. 순이익 \(X = W - 1000\), \(E[X] = 300 - 1000 = -700\)원.
    \(E[W + b] = E[W] + b\).
  3. \(E[W^2] = 10^{12}\times10^{-4} + 10^8\times10^{-2} + 10^6\times10^{-1} = 10^8 + 10^6 + 10^5 = 1.011\times10^8\).
    분산 계산을 위해.
  4. \(\text{Var}(W) = 1.011\times10^8 - 300^2 = 1.0101\times10^8\), \(\sigma = 10050\)원. \(\text{Var}(X) = \text{Var}(W)\).
    상수를 빼도 분산은 그대로.

의미

평균 손실은 700원인데 표준편차는 1만 원이 넘는다. 한 장으로는 결과가 거의 예측되지 않지만, 100만 장을 사면 평균 순이익은 −700원 근처에 몰립니다(5단원: 평균의 표준오차는 \(\frac{\sigma}{\sqrt n}\)). 복권 회사와 보험 회사는 이 "많이 하면 평균이 된다"에 기대어 운영한다. 보험 가입자는 기대값으로는 손해지만 큰 손실의 분산을 줄이려고 가입한다.

검산

확률의 합: \(0.0001 + 0.01 + 0.1 + 0.8899 = 1\). 기대값이 가능한 값의 범위(−1000 ~ 999000) 안에 있다. 분산의 대부분이 1등 한 항에서 옵니다(드문 큰 값이 퍼짐을 지배).
