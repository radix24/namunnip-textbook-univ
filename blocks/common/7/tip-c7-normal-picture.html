정규분포 확률은 그림부터 그리고 \(z\)로 바꾼 뒤, 표가 주는 왼쪽 넓이로 읽는다

요령 · 정규분포

언제 쓰는가

키, 점수, 무게처럼 정규분포를 따르는 양의 확률이나 상위 몇 %의 기준값을 묻는 문제입니다.

요령

  1. 종을 그리고 칠한다
    평균을 가운데 두고, 묻는 구간을 칠합니다. 답이 0.5보다 큰지 작은지 미리 압니다.
  2. \(z\)로 바꾼다
    \(z = \frac{x - \mu}{\sigma}\).
  3. 왼쪽 넓이로 읽는다
    표준정규분포표는 보통 \(\Phi(z) = P(Z \le z)\)를 줍니다. 오른쪽은 \(1 - \Phi\), 사이는 두 \(\Phi\)의 차입니다.
  4. 거꾸로 묻는 문제
    '상위 5%의 기준'처럼 확률을 주고 값을 묻으면 표에서 \(z\)를 찾은 뒤 \(x = \mu + z\sigma\)로 되돌립니다.

흔한 실수

  • 오른쪽 넓이를 구할 때 표 값을 그대로 쓰는 것.
  • 상위 5% 기준에 \(z = -1.645\)를 쓰는 것. 상위는 오른쪽이므로 \(+1.645\)입니다.

바로 풀어보기

시험 점수가 \(N(70, 8^2)\)을 따릅니다. 80점 이상인 비율과, 상위 5%에 드는 기준 점수를 구하세요.

답과 풀이

답: 약 10.6%, 약 83.2점

\(z = \frac{80 - 70}{8} = 1.25\), \(\Phi(1.25) = 0.8944\)이므로 \(P(X \ge 80) = 1 - 0.8944 = 0.1056\)입니다. 그림에서 오른쪽 꼬리라 0.5보다 작아야 하는 것과 맞습니다.

상위 5%는 \(\Phi(z) = 0.95\)인 \(z = 1.645\)이므로 \(x = 70 + 1.645\times8 \approx 83.2\)점입니다.

이 요령으로 풀리는 문제

  • 연속형 확률변수 단원 연습 2번, 3번, 6번
  • 이산형 확률변수 단원 연습 4번, 5번
영상 콘티 · 40초
  1. 0~5초종 모양 곡선과 가로축 70이 나타나고, 80 오른쪽이 칠해집니다.80점 이상의 비율은?
  2. 5~12초칠한 넓이가 절반보다 훨씬 작다는 표시 '< 0.5'가 붙습니다.그림으로 답의 크기를 먼저 짐작합니다.
  3. 12~20초가로축이 미끄러지고 줄어 70이 0, 80이 1.25가 됩니다.\(z\)로 바꿉니다.
  4. 20~29초표에서 0.8944가 집혀 나오는데, 그것은 왼쪽 넓이를 칠합니다. 전체 1에서 빼는 애니메이션으로 오른쪽 0.1056이 남습니다.표는 왼쪽 넓이를 줍니다.
  5. 29~40초오른쪽 꼬리 5%가 먼저 칠해지고, 그 경계에서 \(z = 1.645\)가 읽힌 뒤 원래 축으로 되돌아가 83.2가 됩니다.거꾸로 묻으면 \(z\)를 찾아 되돌립니다.
