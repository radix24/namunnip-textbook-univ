양성 판정을 받았을 때 정말 병에 걸렸을 확률: Bayes 정리

조건부확률 · 민감도 · 특이도 · 기저율

도구

조건부확률 \(P(A\mid B) = \frac{P(A\cap B)}{P(B)}\). 곱셈 법칙을 두 방향으로 쓰면 \(P(A\cap B) = P(B\mid A)P(A)\)이므로 Bayes 정리:

\[P(A\mid B) = \frac{P(B\mid A)P(A)}{P(B\mid A)P(A) + P(B\mid A^c)P(A^c)}.\]

분모는 \(B\)가 일어나는 두 경로(\(A\)일 때, \(A\)가 아닐 때)의 합(전확률 공리)입니다. "원인 → 결과"의 확률을 "결과 → 원인"의 확률로 뒤집는 공식이다.

먼저 예측

유병률 1%인 병의 검사가 환자의 99%를 양성으로, 건강한 사람의 95%를 음성으로 판정한다. 양성이 나온 사람이 실제 환자일 확률은? 99%? 95%? 그보다 훨씬 낮을까?

예측 확인

약 17%로 훨씬 낮다. 건강한 사람이 워낙 많아 그중 5%의 거짓 양성이 진짜 양성보다 많기 때문이다.

위 검사(유병률 1%, 민감도 99%, 특이도 95%)에서 (가) 양성일 때 환자일 확률 (나) 음성일 때 환자가 아닐 확률 (다) 양성이 나와 재검사(독립, 같은 성능)에서 또 양성이면 환자일 확률

풀이 (10000명으로 세기)

양성음성합
환자991100
건강49594059900
합594940610000
  1. (가) \(P(\text{환자}\mid+) = \frac{99}{594} = 0.167\).
    양성 594명 중 진짜 환자 99명. Bayes 식에 넣어도 \(\frac{0.99\times0.01}{0.99\times0.01 + 0.05\times0.99}\)로 같다.
  2. (나) \(P(\text{건강}\mid-) = \frac{9405}{9406} = 0.9999\).
    음성 판정은 매우 믿을 만하다.
  3. (다) 첫 검사 뒤 사전확률을 0.167로 바꿔 다시: \(\frac{0.99\times0.167}{0.99\times0.167 + 0.05\times0.833} = \frac{0.165}{0.165 + 0.0417} = 0.80\).
    Bayes 정리를 되풀이: 어제의 사후확률이 오늘의 사전확률.

의미

검사 성능이 좋아도 드문 병에서는 양성의 대부분이 거짓 양성입니다(기저율 무시 오류). 그래서 선별 검사에서 양성이 나오면 확진 검사를 한다. 음성은 매우 믿을 만해 "배제"에 강하다. 스팸 필터, 법정의 증거 판단, 기계학습의 분류기 평가가 모두 같은 구조이다.

검산

유병률을 50%로 바꾸면 \(P(\text{환자}\mid+) = \frac{0.495}{0.495 + 0.025} = 0.95\). 흔한 병일수록 양성을 믿을 수 있다는 직관과 맞다. 극단: 유병률 0이면 양성이어도 0.

흔한 오해

  • \(P(+\mid\text{환자})\)와 \(P(\text{환자}\mid+)\)를 같게 보기: 99%와 17%. 조건과 결과를 바꾸면 전혀 다른 확률입니다(검사의 오류).
