표본평균의 분포와 표준오차

본문
이 절에서 배울 것
  • 통계량도 표본마다 달라지는 확률변수임을 안다(표본분포).
  • 표본평균과 표본비율의 기댓값과 표준오차를 구한다.
먼저 알아야 할 것
  • 기댓값과 분산의 성질 (4.1절), 정규분포 (5.2절).

6.1.1표본분포

같은 모집단에서 크기 \(n\)인 표본을 여러 번 뽑으면 표본평균 \(\bar X\)는 매번 다릅니다. \(\bar X\)를 확률변수로 보고 그 분포를 생각한 것이 표본분포입니다. 모평균 \(\mu\), 모표준편차 \(\sigma\)인 모집단에서 독립으로 뽑으면

정리 6.1.1 \[E(\bar X) = \mu, \qquad \text{SE}(\bar X) = \frac{\sigma}{\sqrt n}.\]

표본평균의 표준편차를 표준오차라 합니다. 이유: \(\bar X = \frac1n(X_1 + \cdots + X_n)\)이고 독립이므로 분산은 \(\frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}\)입니다.

  • \(\bar X\)는 평균적으로 \(\mu\)를 맞힌다(치우침이 없다).
  • 표본을 4배로 키우면 표준오차는 절반. 정밀도를 두 배로 하려면 비용이 네 배.
  • 모집단이 정규분포이면 \(\bar X\)도 정규분포. 아니어도 \(n\)이 크면 정규분포에 가깝다(6.2절).
예제 6.1.2

모평균 50, 모표준편차 10인 정규 모집단에서 25개를 뽑는다. 표본평균이 53보다 클 확률은?

풀이. \(\text{SE} = \frac{10}{5} = 2\). \(z = \frac{53 - 50}{2} = 1.5\), \(P(Z > 1.5) \approx 0.067\). 하나의 값이 53보다 클 확률(\(z = 0.3\), 약 0.38)보다 훨씬 작습니다. 평균은 개별 값보다 덜 흔들리기 때문입니다.

6.1.2표본비율

성공 비율이 \(p\)인 모집단에서 \(n\)개를 뽑은 표본비율 \(\hat p\)는 \(E(\hat p) = p\), \(\text{SE}(\hat p) = \sqrt{\frac{p(1 - p)}{n}}\)입니다(이항분포를 \(n\)으로 나눈 것). 여론조사 1000명이면 \(p = 0.5\)일 때 \(\text{SE} \approx 0.016\)입니다.

요약
  1. \(E(\bar X) = \mu\), \(\text{SE} = \sigma/\sqrt n\).
  2. \(E(\hat p) = p\), \(\text{SE} = \sqrt{p(1 - p)/n}\).
