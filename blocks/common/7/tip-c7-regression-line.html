회귀 직선은 기울기 \(b = r\frac{s_y}{s_x}\)와 '평균점을 지난다' 두 가지로 바로 만든다

요령 · 회귀 직선

언제 쓰는가

상관계수와 두 변수의 평균, 표준편차가 주어지고 회귀 직선이나 예측값을 묻는 문제입니다.

요령

  1. 기울기
    \(b = r\frac{s_y}{s_x}\). \(x\)가 표준편차 하나만큼 늘면 \(y\)는 표준편차의 \(r\)배만큼 늘어납니다.
  2. 평균점을 지난다
    회귀 직선은 언제나 \((\bar x, \bar y)\)를 지나므로 절편 \(a = \bar y - b\bar x\)입니다.
  3. 예측
    \(\hat y = a + bx\). 자료가 있는 \(x\) 범위 안에서만 씁니다.
  4. 평균으로의 회귀
    \(|r| < 1\)이면 예측값은 \(x\)보다 덜 극단적인 \(z\)점수를 갖습니다. 키가 아주 큰 사람의 몸무게 예측은 평균 쪽으로 당겨집니다.

흔한 실수

  • 기울기를 \(\frac{s_y}{s_x}\)로 쓰고 \(r\)을 빠뜨리는 것.
  • \(x\)로 \(y\)를 예측한 직선을 뒤집어 \(y\)로 \(x\)를 예측하는 것. 두 회귀 직선은 다릅니다.

바로 풀어보기

키 \(x\)(cm)는 평균 170, 표준편차 6이고, 몸무게 \(y\)(kg)는 평균 65, 표준편차 8이며, 상관계수는 0.6입니다. 회귀 직선과 키 176 cm인 사람의 예측 몸무게를 구하세요.

답과 풀이

답: \(\hat y = -71 + 0.8x\), 69.8 kg

\(b = 0.6\times\frac86 = 0.8\), \(a = 65 - 0.8\times170 = -71\)이므로 \(\hat y = -71 + 0.8x\)입니다.

176 cm는 평균보다 표준편차 1개 위이므로, 예측 몸무게는 평균보다 표준편차의 0.6배(4.8 kg) 위인 69.8 kg입니다.

이 요령으로 풀리는 문제

  • 상관과 회귀 입문 단원 연습 1번, 4번, 5번, 6번
영상 콘티 · 45초
  1. 0~5초키와 몸무게의 산점도가 비스듬한 타원 모양으로 퍼져 있습니다.회귀 직선을 빨리 그리는 법.
  2. 5~13초평균점 (170, 65)에 큰 점이 찍히고 핀이 꽂힙니다.직선은 반드시 평균점을 지납니다.
  3. 13~23초평균점에서 오른쪽으로 \(s_x = 6\) 화살표, 위로 \(s_y = 8\) 화살표가 그려지는데, 위 화살표가 0.6배로 줄어 4.8이 됩니다.\(x\)가 표준편차 하나 늘면 \(y\)는 \(r\)배만큼.
  4. 23~32초평균점과 화살표 끝을 잇는 직선이 그려지고 기울기 0.8이 표시됩니다.기울기는 \(r\frac{s_y}{s_x}\).
  5. 32~40초176 cm 세로선이 직선과 만나 69.8 kg이 읽힙니다.직선에서 예측값을 읽습니다.
  6. 40~45초\(x\)축 밖 250 cm까지 직선이 뻗어 가다 점선으로 바뀌며 '자료 밖' 경고가 뜹니다.자료 범위 밖에서는 쓰지 않습니다.
