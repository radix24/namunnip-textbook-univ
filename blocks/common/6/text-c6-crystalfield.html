결정장 이론: 고스핀과 저스핀

본문
이 절에서 배울 것
  • 팔면체 결정장에서 d 오비탈이 갈라지는 이유를 안다.
  • 분리 에너지와 짝짓기 에너지로 고스핀·저스핀 배치와 자성을 예측한다.
먼저 알아야 할 것
  • d 오비탈 모양 (공통5 6.3절), 훈트 규칙 (공통5 6.4절), 착화합물 (9.1절).

9.2.1d 오비탈의 분리

자유로운 금속 이온의 d 오비탈 다섯 개는 에너지가 같습니다. 팔면체 착물에서 리간드는 \(x, y, z\)축 위에서 다가옵니다. 축 방향을 향한 두 오비탈(\(d_{x^2-y^2}\), \(d_{z^2}\), \(e_g\))의 전자는 리간드 전자와 더 많이 반발해 에너지가 오르고, 축 사이를 향한 세 오비탈(\(d_{xy}, d_{yz}, d_{xz}\), \(t_{2g}\))은 낮아집니다. 두 무리의 에너지 차이를 결정장 분리 에너지 \(\Delta_o\)라 합니다.

9.2.2고스핀과 저스핀

\(d^4\)~\(d^7\) 이온에서는 전자를 넣는 방법이 두 가지입니다.

  • \(\Delta_o\)가 작으면(약한 장 리간드): 위의 \(e_g\)에도 하나씩 먼저 넣는다. 홀전자가 많은 고스핀.
  • \(\Delta_o\)가 짝짓기 에너지보다 크면(강한 장 리간드): 아래 \(t_{2g}\)를 먼저 짝지어 채운다. 저스핀.

리간드를 \(\Delta\)가 커지는 순으로 늘어놓은 것이 분광 화학 계열입니다: \(\text{I}^- < \text{Cl}^- < \text{F}^- < \text{H}_2\text{O} < \text{NH}_3 < \text{en} < \text{CN}^- < \text{CO}\).

예제 9.2.1

\([\text{Fe}(\text{H}_2\text{O})_6]^{2+}\)와 \([\text{Fe}(\text{CN})_6]^{4-}\)의 홀전자 수는?

풀이. 둘 다 \(\text{Fe}^{2+}\), \(d^6\). 물은 약한 장: \(t_{2g}^4e_g^2\), 홀전자 4(상자성). \(\text{CN}^-\)은 강한 장: \(t_{2g}^6\), 홀전자 0(반자성). 같은 금속 이온이라도 리간드에 따라 자성이 달라집니다.

요약
  1. 팔면체: \(t_{2g}\)(낮음 3개), \(e_g\)(높음 2개), 차이 \(\Delta_o\).
  2. 약한 장 → 고스핀(홀전자 많음), 강한 장 → 저스핀.
