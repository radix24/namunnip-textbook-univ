반응 지수와 반응 방향

본문

공장에서 수소와 아이오딘, 아이오딘화 수소를 섞어 용기에 넣었다. 이 혼합물은 HI를 더 만들까, 아니면 HI가 분해될까? 평형 상수 \(K\)는 평형에서의 농도 관계만 알려 준다. 지금 농도가 평형인지, 아니라면 어느 쪽으로 갈지는 어떻게 알까?

먼저 알아야 할 것평형 상수와 평형 상수식(3.1절), 몰농도(일반화학(1) 4.2절)를 쓴다.

3.2.1반응 지수의 정의

처음 질문에 답하려면 지금 농도를 평형 상수식에 그대로 넣어 본다. 그 값이 \(K\)보다 작은지 큰지가 방향을 알려 준다.

정의 3.2.1

반응 \(a\mathrm A + b\mathrm B \rightleftharpoons c\mathrm C + d\mathrm D\)에서 임의의 순간의 농도로 계산한 다음 값을 반응 지수라 한다.

\[Q_c = \frac{[\mathrm C]^c[\mathrm D]^d}{[\mathrm A]^a[\mathrm B]^b}\]

식의 모양은 평형 상수식과 똑같고, 다른 점은 넣는 농도뿐이다. \(K\)에는 평형 농도만 넣고, \(Q\)에는 지금 이 순간의 농도를 넣는다. 그래서 \(K\)는 온도가 정해지면 하나의 값이지만, \(Q\)는 반응이 진행하는 동안 계속 변하다가 평형에 이르면 \(K\)와 같아진다.

3.2.2\(Q\)와 \(K\)로 방향 정하기

\(Q\)의 분자는 생성물, 분모는 반응물이다. 따라서 \(Q < K\)이면 평형에 비해 생성물이 모자라므로, 반응은 정반응 쪽으로 진행해 생성물을 늘리고 \(Q\)가 커지다가 \(K\)에 이르면 멈춘다. \(Q = K\)이면 이미 평형이라 겉으로 보이는 변화가 없다. 반대로 \(Q > K\)이면 생성물이 너무 많으므로, 역반응 쪽으로 진행해 \(Q\)를 줄인다. 즉 "\(Q\)가 \(K\)를 향해 움직인다"고 기억하면 된다. 그림 1에서 농도를 바꾸며 화살표의 방향을 확인할 수 있다.

예제 3.2.2

448 °C에서 \(\mathrm{H_2 + I_2 \rightleftharpoons 2HI}\)의 \(K_c = 50.5\)이다. [H₂] = 0.50 M, [I₂] = 0.50 M, [HI] = 4.0 M인 혼합물은 어느 쪽으로 진행하는가?

풀이. \(Q = \dfrac{(4.0)^2}{(0.50)(0.50)} = 64\)이다. \(Q = 64 > K = 50.5\)이므로 생성물이 지나치게 많다. 따라서 HI가 분해되는 역반응 쪽으로 진행해, [HI]는 줄고 [H₂]와 [I₂]는 늘어난다. 그림 1의 처음 상태가 이 예제이다.

예제 3.2.3

같은 반응에서 [H₂] = [I₂] = 0.20 M, [HI] = 1.0 M로 시작했다. 진행 방향을 정하고, 평형 농도를 구하여라.

풀이. \(Q = \dfrac{1.0^2}{0.20 \times 0.20} = 25 < 50.5\)이므로 정반응 쪽이다. H₂가 \(x\)만큼 줄면 I₂도 \(x\)만큼 줄고 HI는 \(2x\) 늘어난다. 그러면 \(\dfrac{(1.0 + 2x)^2}{(0.20 - x)^2} = 50.5\)이고, 양변에 제곱근을 씌우면 \(\dfrac{1.0 + 2x}{0.20 - x} = 7.11\)이다. 즉 \(1.0 + 2x = 1.42 - 7.11x\)이므로 \(x = 0.046\)이다. 평형 농도는 [H₂] = [I₂] = 0.154 M, [HI] = 1.092 M이다. 검산하면 \(1.092^2/0.154^2 = 50.3 \approx 50.5\)이다.

3.2.3기체의 분압과 순수한 물질

기체 반응은 농도 대신 분압으로 \(Q_p\)를 쓸 수 있고, 이것은 \(K_p\)와 비교한다. \(Q_c\)는 \(K_c\)와 비교하며, 섞어서 비교하면 안 된다. 또 순수한 고체와 순수한 액체는 농도가 사실상 변하지 않으므로 \(Q\)와 \(K\) 모두에서 빼고 쓴다. 가령 \(\mathrm{CaCO_3(s) \rightleftharpoons CaO(s) + CO_2(g)}\)에서는 \(Q_p = P_{\mathrm{CO_2}}\)이다. 그러므로 석회석을 데운 용기의 \(\mathrm{CO_2}\) 압력이 \(K_p\)보다 낮으면 석회석이 더 분해된다.

흔한 실수\(Q > K\)일 때 "반응이 일어나지 않는다"고 생각하기 쉽지만, 역반응이 일어난다. 또 계수를 지수로 쓰는 것을 빠뜨리는 실수도 많다. 2HI이면 \([\mathrm{HI}]^2\)이다.

\(Q\)는 6단원의 \(\Delta G = \Delta G° + RT\ln Q\)에서 다시 나온다(6.3절). \(Q < K\)이면 \(\Delta G < 0\)이라 정반응이 자발적이고, \(Q = K\)이면 \(\Delta G = 0\)인 평형이다. 방향을 정하는 규칙의 열역학적 근거이다.

마무리

반응 지수 \(Q\)는 지금의 농도나 분압을 평형 상수식에 넣은 값이다. 처음 질문의 방향은 \(Q < K\)이면 정반응, \(Q > K\)이면 역반응이고, \(Q = K\)이면 평형이다. \(Q_c\)는 \(K_c\)와, \(Q_p\)는 \(K_p\)와 비교하며 순수한 고체와 액체는 식에서 뺀다.

연습문제
  1. 기본 생성물만 넣고 시작하면 \(Q\)는 얼마이고, 반응은 어느 쪽으로 진행하는가?
    답분모가 0이라 \(Q\)는 한없이 크다(\(Q > K\)). 역반응 쪽.
  2. 기본 \(\mathrm{N_2 + 3H_2 \rightleftharpoons 2NH_3}\), \(K_c = 0.105\)(472 °C). [N₂] = 2.0, [H₂] = 1.0, [NH₃] = 0.50 M이면 어느 쪽으로 진행하는가?
    답\(Q = 0.25/(2.0 \times 1.0) = 0.125 > 0.105\). 역반응 쪽(NH₃ 분해).
  3. 응용 \(\mathrm{CaCO_3(s) \rightleftharpoons CaO(s) + CO_2(g)}\)의 \(K_p = 1.16\)(1073 K)이다. 용기 속 \(\mathrm{CO_2}\) 압력이 0.50 atm이면 석회석은 더 분해되는가?
    답\(Q_p = 0.50 < 1.16\)이므로 정반응 쪽, 더 분해된다. \(P_{\mathrm{CO_2}}\)가 1.16 atm이 될 때까지.
  4. 심화 예제 3.2.3에서 처음에 HI 1.0 M만 넣었다면 평형 농도는?
    답HI가 \(2x\) 줄고 H₂, I₂가 \(x\)씩 생긴다. \(\dfrac{1.0 - 2x}{x} = 7.11\)에서 \(x = 0.110\). [H₂] = [I₂] = 0.110 M, [HI] = 0.780 M.
