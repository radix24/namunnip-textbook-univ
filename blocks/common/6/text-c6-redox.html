산화-환원 반응식 맞추기

본문
이 절에서 배울 것
  • 산화수로 산화제와 환원제를 찾는다.
  • 반쪽 반응법으로 산성 용액의 산화-환원 반응식을 맞춘다.
먼저 알아야 할 것
  • 산화수 (공통5 4.1절).

7.1.1산화제와 환원제

  • 산화: 전자를 잃음, 산화수 증가.
  • 환원: 전자를 얻음, 산화수 감소.
  • 산화제: 상대를 산화시키고 자신은 환원되는 물질.
  • 환원제: 상대를 환원시키고 자신은 산화되는 물질.

7.1.2반쪽 반응법 (산성 용액)

  1. 산화 반쪽과 환원 반쪽으로 나눈다.
  2. 각 반쪽에서 O와 H 이외의 원자를 맞춘다.
  3. O는 \(\text{H}_2\text{O}\)로, H는 \(\text{H}^+\)로 맞춘다.
  4. 전하를 전자로 맞춘다.
  5. 두 반쪽의 전자 수가 같도록 정수배하고 더한다.
예제 7.1.1

산성 용액에서 \(\text{MnO}_4^- + \text{Fe}^{2+} \to \text{Mn}^{2+} + \text{Fe}^{3+}\)를 맞춰라.

풀이.

  • 환원: \(\text{MnO}_4^- + 8\text{H}^+ + 5e^- \to \text{Mn}^{2+} + 4\text{H}_2\text{O}\) (Mn +7 → +2).
  • 산화: \(\text{Fe}^{2+} \to \text{Fe}^{3+} + e^-\), 5배.

더하면 \(\text{MnO}_4^- + 8\text{H}^+ + 5\text{Fe}^{2+} \to \text{Mn}^{2+} + 5\text{Fe}^{3+} + 4\text{H}_2\text{O}\). 양쪽 전하가 +17로 같습니다. 보라색 과망가니즈산 이온이 무색 \(\text{Mn}^{2+}\)가 되므로 지시약 없이 적정에 씁니다. 염기성 용액이면 마지막에 \(\text{H}^+\) 수만큼 양쪽에 \(\text{OH}^-\)를 더해 물로 바꿉니다.

요약
  1. 산화제는 환원되고 환원제는 산화된다.
  2. 반쪽 반응: 원자 → O(H₂O) → H(H⁺) → 전하(e⁻) → 전자 수 맞춰 더하기.
