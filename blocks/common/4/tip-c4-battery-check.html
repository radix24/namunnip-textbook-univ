축전기 문제는 전지가 연결되어 있는지부터 본다

요령 · 축전기

언제 쓰는가

축전기의 판 간격을 바꾸거나 유전체를 넣는 등 축전기를 바꿀 때, 전하·전압·에너지가 어떻게 변하는지 묻는 문제입니다.

요령

  1. 무엇이 고정인지 정한다
    전지에 연결된 채라면 전압 \(V\)가 고정입니다. 충전 뒤 떼어 냈다면 전하 \(Q\)가 고정입니다.
  2. 새 \(C\)를 구한다
    \(C = \frac{\kappa\varepsilon_0A}{d}\)로 간격, 넓이, 유전 상수의 변화를 반영합니다.
  3. 고정된 양으로 나머지를 구한다
    \(V\) 고정이면 \(Q = CV\), \(Q\) 고정이면 \(V = \frac QC\)입니다.
  4. 에너지는 고정량이 든 식으로
    \(V\) 고정이면 \(U = \frac12CV^2\), \(Q\) 고정이면 \(U = \frac{Q^2}{2C}\)를 씁니다. 그래야 변하는 양이 하나뿐입니다.

흔한 실수

  • 전지를 뗀 축전기에 \(U = \frac12CV^2\)를 쓰고 \(V\)를 그대로 두는 것. \(V\)도 함께 변합니다.
  • 에너지가 늘어난 이유를 설명하지 못하는 것. 전지를 뗀 판을 벌리면 판을 당기는 사람이 일을 해 준 만큼 늘어납니다.

바로 풀어보기

\(10\ \mu\text F\) 평행판 축전기를 12 V로 충전했습니다. 판 간격을 두 배로 벌렸을 때의 전하, 전압, 에너지를 (가) 전지를 떼어 낸 경우 (나) 전지에 연결한 채인 경우로 나눠 구하세요.

답과 풀이

답: (가) \(Q = 120\ \mu\text C\), \(V = 24\ \text V\), \(U = 1.44\ \text{mJ}\) (나) \(Q = 60\ \mu\text C\), \(V = 12\ \text V\), \(U = 0.36\ \text{mJ}\)

처음: \(Q = 120\ \mu\text C\), \(U = \frac12(10\times10^{-6})(12)^2 = 0.72\ \text{mJ}\). 간격이 두 배면 \(C = 5\ \mu\text F\)입니다.

(가) \(Q\) 고정: \(V = \frac{120}{5} = 24\ \text V\), \(U = \frac{Q^2}{2C} = 1.44\ \text{mJ}\)로 두 배가 됩니다. 판을 벌린 사람의 일이 들어온 것입니다. (나) \(V\) 고정: \(Q = 5\times12 = 60\ \mu\text C\), \(U = \frac12CV^2 = 0.36\ \text{mJ}\)로 절반이 됩니다.

이 요령으로 풀리는 문제

  • 전기용량과 유전체 단원 연습 1번, 3번, 6번
  • 전류와 직류 회로 단원 연습 1번, 2번
영상 콘티 · 45초
  1. 0~5초전지에 연결된 평행판 축전기가 있고, 판 사이에 전기력선이 고르게 그려져 있습니다.판을 벌리면 무엇이 변할까요?
  2. 5~12초전지와 축전기를 잇는 도선에 가위가 다가갑니다. 화면이 둘로 갈라져 왼쪽은 도선을 자르고, 오른쪽은 그대로 둡니다.먼저 전지가 연결되어 있는지 봅니다.
  3. 12~21초왼쪽: 판 위의 전하 점 개수가 그대로인 채 판이 벌어지고, 전압계 바늘이 12에서 24로 올라갑니다.떼어 냈으면 전하가 고정입니다.
  4. 21~30초오른쪽: 판이 벌어지자 전하 점의 절반이 도선을 타고 전지로 돌아가고, 전압계는 12에 머뭅니다.연결된 채면 전압이 고정입니다.
  5. 30~38초두 화면 아래 에너지 막대가 왼쪽은 두 배로, 오른쪽은 절반으로 변합니다. 왼쪽 판을 당기는 손에 '일'이라는 이름표가 붙습니다.에너지는 고정량이 든 식으로 계산합니다.
  6. 38~45초왼쪽 화면에 \(\frac12CV^2\)에서 \(V\)를 그대로 둔 계산이 나오다 X가 그어집니다.\(V\)도 함께 변한다는 것을 잊지 않습니다.
