축전기와 직류 회로 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

\(\varepsilon_0 = 8.85\times10^{-12}\ \text{F/m}\).

  1. 계산2.0 μF과 3.0 μF 축전기를 직렬로, 또 병렬로 연결했을 때 합성 전기용량을 구하고, 직렬일 때 12 V 전지에 연결하면 각 축전기의 전압은? [03-01]

    힌트 1

    직렬은 전하가 같고, 병렬은 전압이 같습니다.

    힌트 2

    직렬: \(\frac1C = \frac1{C_1} + \frac1{C_2}\).

    풀이

    직렬 1.2 μF, 병렬 5.0 μF. 직렬: \(Q = 1.2\times12 = 14.4\ \mu\text{C}\), \(V_1 = 7.2\) V, \(V_2 = 4.8\) V. 작은 축전기에 큰 전압이 걸립니다.

  2. 판단충전한 평행판 축전기를 전지에서 떼어 낸 뒤 판 간격을 2배로 벌렸습니다. 한 학생이 "\(U = \frac12CV^2\)에서 \(C\)가 절반이 되니 에너지도 절반"이라고 했습니다. 맞나요? [03-01]

    힌트 1

    떼어 낸 뒤에 일정한 양은 \(Q\)와 \(V\) 중 무엇인가요?

    힌트 2

    \(U = \frac{Q^2}{2C}\)를 쓰세요.

    풀이

    틀렸습니다. 고립된 축전기는 \(Q\)가 일정하고 \(V\)는 2배가 됩니다. \(U = \frac{Q^2}{2C}\)는 2배. 늘어난 에너지는 판을 벌리며 판 사이 인력에 맞서 한 일입니다. "\(V\) 일정"은 전지에 연결된 채일 때입니다.

  3. 계산기전력 9.0 V, 내부 저항 0.50 Ω인 전지에 4.0 Ω 저항을 연결했습니다. 전류, 단자 전압, 외부 저항의 소비 전력을 구하세요. 소비 전력이 최대가 되는 외부 저항은? [03-02]

    힌트 1

    \(I = \frac{\mathcal E}{R + r}\).

    힌트 2

    \(P(R) = \frac{\mathcal E^2R}{(R + r)^2}\)를 \(R\)로 미분.

    풀이

    \(I = 2.0\) A, 단자 전압 \(9.0 - 1.0 = 8.0\) V, \(P = 16\) W. \(P'(R) = 0\)에서 \(R = r = 0.50\ \Omega\) (임피던스 정합), 그때 \(P = \frac{\mathcal E^2}{4r} = 40.5\) W.

  4. 개념전구 두 개를 직렬로 연결한 것과 병렬로 연결한 것 중 어느 쪽이 밝은가요(같은 전지, 같은 전구)? 집 안의 전등은 어느 방식으로 연결되나요? [03-02]

    힌트 1

    전구 하나에 걸리는 전압을 비교하세요.

    힌트 2

    \(P = \frac{V^2}{R}\).

    풀이

    병렬이 밝습니다. 병렬은 전구마다 전지 전압 전체가 걸리고, 직렬은 절반씩 나눠 전력이 \(\frac14\)입니다. 집 전등은 병렬입니다. 하나를 꺼도 나머지가 켜져 있고, 모두 같은 220 V를 받습니다.

  5. 계산충전된 축전기(\(C = 10\ \mu\text{F}\))가 1.0 MΩ 저항으로 방전됩니다. 전압이 처음의 절반이 되는 시간과, 에너지가 절반이 되는 시간을 구하세요. [03-03]

    힌트 1

    \(V = V_0e^{-t/\tau}\), \(\tau = 10\) s.

    힌트 2

    에너지는 \(V^2\)에 비례: \(e^{-2t/\tau}\).

    풀이

    전압 절반: \(t = \tau\ln2 = 6.9\) s. 에너지 절반: \(t = \frac\tau2\ln2 = 3.5\) s. 에너지가 전압보다 2배 빨리 줄어듭니다.

  6. 판단한 학생이 RC 충전 실험에서 "\(t = 2\tau\)에서 축전기 전압이 최종값의 2 × 63% = 126%"라고 기록했습니다. 어디가 틀렸고 실제 값은? [03-03]

    힌트 1

    최종값을 넘을 수 있나요?

    힌트 2

    \(1 - e^{-2}\).

    풀이

    지수 함수는 비례로 늘지 않습니다. 실제 \(1 - e^{-2} = 86.5\%\). 매 \(\tau\)마다 남은 차이가 \(e^{-1} = 37\%\)로 줄어듭니다: 100 → 37 → 13.5 → … 최종값을 넘을 수 없습니다.
