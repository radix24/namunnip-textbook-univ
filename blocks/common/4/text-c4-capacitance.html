축전기와 전기용량

본문
이 절에서 배울 것
  • 전기용량을 정의하고 평행판 축전기의 전기용량을 구한다.
  • 직렬·병렬 연결과 저장 에너지를 계산한다.
먼저 알아야 할 것
  • 평행판 사이 전기장 (1.2절), 전위 (3.1절).

4.1.1전기용량

두 도체에 \(+Q\)와 \(-Q\)를 주면 그 사이에 전위차 \(V\)가 생기고, \(Q\)는 \(V\)에 비례합니다. 이런 장치를 축전기라 합니다.

정의 4.1.1 (전기용량)

\(C = \frac QV\). 단위 패럿 F = C/V.

평행판(넓이 \(A\), 간격 \(d\))이면 판 사이 \(E = \frac{\sigma}{\varepsilon_0} = \frac{Q}{\varepsilon_0A}\), \(V = Ed\)이므로

\[C = \frac{\varepsilon_0A}{d}.\]

판이 넓고 가까울수록 큽니다. 1 F는 아주 커서 보통 μF, pF를 씁니다.

예제 4.1.2

넓이 0.010 m², 간격 1.0 mm인 평행판 축전기에 12 V를 걸었다. \(C\), \(Q\), 저장 에너지는?

풀이. \(C = \frac{8.85\times10^{-12}\times0.010}{1.0\times10^{-3}} = 88.5\) pF. \(Q = CV = 1.06\times10^{-9}\) C. \(U = \frac12CV^2 = 6.4\times10^{-9}\) J.

4.1.2직렬과 병렬

  • 병렬: 전압이 같고 전하가 나뉜다. \(C = C_1 + C_2\).
  • 직렬: 전하가 같고 전압이 나뉜다. \(\frac1C = \frac{1}{C_1} + \frac{1}{C_2}\).

저항의 공식과 반대 꼴입니다(5.2절). 예: 2.0 μF와 4.0 μF를 병렬로 연결하면 6.0 μF, 직렬로 연결하면 \(\frac{2\times4}{2 + 4} = 1.33\) μF.

4.1.3저장 에너지

전하를 조금씩 옮겨 충전할 때 전위차 \(v = q/C\)를 거슬러 \(dq\)를 옮기는 일은 \(v\,dq\)입니다. 0에서 \(Q\)까지 적분하면

\[U = \frac{Q^2}{2C} = \frac12CV^2 = \frac12QV.\]

이 에너지는 판 사이의 전기장에 저장되어 있다고 볼 수 있습니다. 부피 \(Ad\)로 나누면 에너지 밀도는 \(u = \frac12\varepsilon_0E^2\)입니다. 카메라 플래시와 심장 제세동기는 축전기에 모은 에너지를 짧은 시간에 내보냅니다.

요약
  1. \(C = Q/V\), 평행판 \(C = \varepsilon_0A/d\).
  2. 병렬 \(C_1 + C_2\), 직렬 \(1/C = 1/C_1 + 1/C_2\).
  3. \(U = \frac12CV^2\), 에너지 밀도 \(\frac12\varepsilon_0E^2\).

4.1.4연습문제

기본

  1. 충전된 평행판 축전기를 전지에서 떼고 간격을 두 배로 하면 \(C\), \(V\), \(U\)는?
    답

    \(Q\) 일정. \(C\) 절반, \(V\) 두 배, \(U = Q^2/2C\) 두 배 (판을 벌리는 일이 저장됨).

  2. 3.0 μF 세 개를 직렬로 연결하면?
    답

    1.0 μF.
