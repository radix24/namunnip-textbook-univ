간섭 문제는 경로차가 파장의 몇 배인지부터 센다

요령 · 간섭

언제 쓰는가

두 슬릿, 두 스피커, 얇은 막처럼 같은 근원에서 나온 두 파동이 만나 밝아지는지 어두워지는지 묻는 문제입니다.

요령

  1. 두 경로를 긋는다
    두 근원에서 관찰점까지 각각 선을 긋고 길이 \(r_1\), \(r_2\)를 구합니다.
  2. 경로차를 파장으로 나눈다
    \(\frac{r_2 - r_1}{\lambda}\)가 정수면 보강, 정수 + \(\frac12\)이면 상쇄입니다.
  3. 반사의 반 파장을 더한다
    얇은 막처럼 굴절률이 큰 매질에서 반사되는 빛은 반 파장이 더해집니다. 두 빛 가운데 하나만 그렇다면 조건이 뒤바뀝니다.
  4. 먼 스크린이면 근사
    슬릿과 스크린이 멀면 경로차는 \(d\sin\theta \approx d\frac yL\)이고, 밝은 무늬 간격은 \(\frac{\lambda L}{d}\)입니다.

흔한 실수

  • 막 안의 파장을 공기 중 파장 그대로 쓰는 것. 막 안에서는 \(\frac{\lambda}{n}\)입니다.
  • 두 근원의 위상이 처음부터 다른지 확인하지 않는 것.

바로 풀어보기

같은 위상으로 680 Hz 소리를 내는 두 스피커가 있습니다(음속 340 m/s). 한 스피커에서 3.0 m, 다른 스피커에서 4.25 m 떨어진 곳에서 소리가 커지나요, 작아지나요? 진동수를 얼마로 바꾸면 가장 가까운 보강 조건이 되나요?

답과 풀이

답: 작아집니다(상쇄). 544 Hz 또는 816 Hz

파장은 \(\frac{340}{680} = 0.50\ \text m\), 경로차는 1.25 m이므로 \(\frac{1.25}{0.50} = 2.5\)배입니다. 정수 + \(\frac12\)이라 상쇄 간섭으로 소리가 작아집니다.

경로차가 파장의 2배 또는 3배가 되면 보강입니다. \(\lambda = 0.625\ \text m\)이면 \(f = 544\ \text{Hz}\), \(\lambda = 0.417\ \text m\)이면 \(f = 816\ \text{Hz}\)입니다.

이 요령으로 풀리는 문제

  • 간섭과 회절 단원 연습 5번, 6번
영상 콘티 · 45초
  1. 0~5초두 스피커에서 동심원 물결 모양의 음파가 퍼져 나가고, 관찰자 한 명이 서 있습니다.이 자리에서는 소리가 클까요, 작을까요?
  2. 5~13초두 스피커에서 관찰자까지 줄자가 뻗어 3.0 m와 4.25 m가 표시됩니다.두 경로의 길이를 잽니다.
  3. 13~22초긴 줄자에서 짧은 줄자만큼이 잘려 나가고 남은 1.25 m가 파장 0.50 m짜리 눈금으로 2.5칸에 걸칩니다.경로차를 파장으로 셉니다. 2.5칸입니다.
  4. 22~31초관찰자 위치에서 두 파동의 사인 곡선이 겹쳐지는데, 하나의 마루가 다른 하나의 골과 만나 납작한 선이 됩니다.반 칸이 남으면 상쇄입니다.
  5. 31~39초진동수 조절 막대를 내리자 파장 눈금이 늘어나 경로차가 정확히 2칸이 되는 순간 두 곡선이 겹쳐 두 배 높이가 됩니다.정수 칸이면 보강입니다.
  6. 39~45초얇은 막 그림이 잠깐 나타나 위쪽 반사에만 '\(+\frac\lambda2\)' 꼬리표가 붙습니다.반사의 반 파장도 셈에 넣습니다.
