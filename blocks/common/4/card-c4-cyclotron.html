자기장 속 전하의 원운동: 반지름과 주기

F = qv × B · r = mv/qB · 질량 분석기 · 문제 해결 전략

출발점

Lorentz 힘: \(\mathbf F = q\mathbf E + q\mathbf v\times\mathbf B\). 자기력은 늘 속도에 수직이라 일을 하지 않고(공통3 3-01) 속력은 그대로, 방향만 바꿉니다. 균일한 \(\mathbf B\)에 수직으로 들어온 전하는 등속 원운동을 합니다.

문제 해결 전략 · 자기장
  1. \(\mathbf v\)(또는 전류 방향)와 \(\mathbf B\)를 그린다. 지면에 들어가는 방향 ⊗, 나오는 방향 ⊙.
  2. 힘의 방향은 오른손 규칙(\(\mathbf v\times\mathbf B\))으로 정하고, 음전하면 뒤집는다.
  3. 크기는 \(qvB\sin\theta\) (전류는 \(ILB\sin\theta\)).
  4. 원운동이면 자기력 = 구심력 \(\frac{mv^2}{r}\)으로 반지름을, \(T = \frac{2\pi r}{v}\)로 주기를 구한다.
  5. 단위(T = N/(A·m))와 크기를 확인한다.

질량 분석기에서 1000 V로 가속된 \(^{12}\text{C}^+\) 이온(\(m = 1.99\times10^{-26}\) kg)이 0.20 T 자기장에 수직으로 들어갑니다. 궤도 반지름과 주기를 구하고, \(^{13}\text{C}^+\)와 착지점이 얼마나 떨어지는지 구하세요.

풀이

  1. 속력: \(qV = \frac12mv^2\), \(v = \sqrt{\frac{2(1.60\times10^{-19})(1000)}{1.99\times10^{-26}}} = 1.27\times10^5\) m/s.
    전위차로 얻은 운동에너지(02-03 카드).
  2. \(qvB = \frac{mv^2}{r}\), \(r = \frac{mv}{qB} = \frac{1.99\times10^{-26}\times1.27\times10^5}{1.60\times10^{-19}\times0.20} = 0.079\) m.
    전략 4.
  3. 주기 \(T = \frac{2\pi m}{qB} = 3.9\ \mu\text{s}\).
    \(r\)과 \(v\)가 모두 소거되어 속력과 상관없다.
  4. \(r = \frac1B\sqrt{\frac{2mV}{q}} \propto \sqrt m\). \(^{13}\text{C}\): \(r' = 0.0789\sqrt{13/12} = 0.0821\) m. 반원을 돌아 착지하므로 지름 차 \(2(0.0821 - 0.0789) \approx 6.4\) mm.
    질량에 따라 반지름이 다르다.

의미

주기가 속력과 상관없다(사이클로트론 진동수 \(f = \frac{qB}{2\pi m}\))는 사실 덕분에, 일정한 진동수의 교류 전압으로 입자를 반 바퀴마다 가속하는 사이클로트론이 가능합니다. 반지름이 \(\sqrt m\)에 비례한다는 사실은 동위원소를 분리하는 질량 분석기의 원리이고, 탄소 연대 측정에 씁니다.

검산

단위: \(\frac{\text{kg·m/s}}{\text{C·T}}\), T = kg/(C·s)이므로 m. 수치 감각: 수 cm 반지름이라 실험실 장치 크기에 맞습니다.

흔한 오해

  • "자기장이 전하를 빠르게 한다." 자기력은 일을 하지 않습니다. 사이클로트론에서 가속은 전기장이 하고 자기장은 방향만 돌립니다.
