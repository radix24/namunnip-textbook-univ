전지에서 가장 큰 전력을 뽑으려면 저항을 얼마로 해야 할까?

실습 · 기전력, 내부 저항, 전력

목표

실제 전지는 기전력 \(\varepsilon\)과 작은 내부 저항 \(r\)을 가집니다. 바깥에 연결한 부하 저항 \(R\)을 바꾸며 전류, 단자 전압, 부하가 받는 전력을 계산하고, 전력이 가장 큰 조건을 찾습니다. 성취기준 [공통4-05-01].

준비

  • 회로 전체 저항이 \(R + r\)이므로 \(I = \dfrac{\varepsilon}{R + r}\). 단자 전압 \(V = \varepsilon - Ir\).
  • 부하 전력 \(P = I^2R = \dfrac{\varepsilon^2R}{(R + r)^2}\). 보라 곡선이 \(R\)에 따른 \(P\), 주황 점이 지금의 \(R\), 세로 점선이 \(R = r\)입니다.

절차

  1. \(\varepsilon = 12\) V, \(r = 2\ \Omega\)에서 \(R = 2, 6, 0.5\ \Omega\)일 때 전류, 단자 전압, 부하 전력, 효율을 기록합니다.
  2. \(R\)을 움직여 전력이 가장 큰 곳을 찾고, \(r\)과 비교합니다.
  3. \(r\)을 0.5 Ω으로 줄이면 최대 전력이 어떻게 바뀌는지 봅니다.

기대 결과

  • \(R = 2\ \Omega\): \(I = 3\) A, \(V = 6\) V, \(P = 18\) W, 효율 50%. 이것이 최대 전력 \(\varepsilon^2/4r = 18\) W입니다.
  • \(R = 6\ \Omega\): \(I = 1.5\) A, \(V = 9\) V, \(P = 13.5\) W, 효율 75%. \(R = 0.5\ \Omega\): \(I = 4.8\) A, \(V = 2.4\) V, \(P = 11.52\) W, 효율 20%.
  • \(r = 0.5\ \Omega\)이면 최대 전력은 72 W로 4배가 됩니다. 내부 저항이 작은 전지일수록 큰 전력을 낼 수 있습니다.

분석

  1. \(P(R) = \dfrac{\varepsilon^2R}{(R + r)^2}\)을 \(R\)로 미분해 \(P'(R) = 0\)인 곳이 \(R = r\)임을 보이세요(공통1 3.1절).
  2. 최대 전력일 때 효율이 50%뿐인데, 발전소와 가정의 전기 설비는 왜 \(R = r\)로 맞추지 않을까요? 오디오 앰프와 스피커는 왜 맞출까요?

더 해 보기
