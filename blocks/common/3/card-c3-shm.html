용수철과 진자의 주기는 어디서 오는가

x″ = −ω²x · 작은 각 근사 · 문제 해결 전략
무엇을 유도하나

용수철 진자 \(T = 2\pi\sqrt{\dfrac mk}\), 단진자(작은 진폭) \(T = 2\pi\sqrt{\dfrac Lg}\).

문제 해결 전략 · 진동
  1. 평형 위치를 찾고, 평형에서 벗어난 양(\(x\) 또는 \(\theta\))을 변수로 잡는다.
  2. 제2법칙(또는 \(\tau = I\alpha\))으로 \(\ddot x = -(\text{양수})\,x\) 꼴을 만든다. 필요하면 작은 진폭 근사.
  3. 그 양수가 \(\omega^2\). \(T = \frac{2\pi}{\omega}\), \(f = \frac1T\).
  4. 진폭과 위상은 처음 조건(처음 위치, 처음 속도)으로 정한다.

모형과 가정

  • 용수철: 훅의 법칙 \(F = -kx\), 마찰 없음, 용수철 질량 무시.
  • 단진자: 질량 없는 줄, 크기 없는 추, 작은 각 \(\sin\theta \approx \theta\) (라디안). 10°에서 오차 약 0.5%.

유도

  1. 용수철: \(m\ddot x = -kx\), 곧 \(\ddot x = -\frac kmx\).
    제2법칙. 평형에서 잰 변위.
  2. \(x(t) = A\cos(\omega t + \phi)\)를 넣으면 \(\ddot x = -\omega^2x\)이므로 \(\omega^2 = \frac km\).
    두 번 미분하면 자기 자신의 \(-\omega^2\)배가 되는 함수는 사인·코사인(미분방정식 과목에서 해가 이것뿐임을 증명).
  3. 진자: 접선 방향 힘 \(-mg\sin\theta\), 호의 길이 \(s = L\theta\). \(mL\ddot\theta = -mg\sin\theta\).
    장력은 줄 방향이라 접선 성분이 없다.
  4. 작은 각: \(\ddot\theta \approx -\frac gL\theta\).
    공통1의 선형 근사 \(\sin\theta \approx \theta\).
  5. \(\omega = \sqrt{\frac gL}\), \(T = 2\pi\sqrt{\frac Lg}\). 용수철은 \(T = 2\pi\sqrt{\frac mk}\).
    전략 3.

결과 확인

  • 차원: \(\sqrt{\text{kg}/(\text{N/m})} = \text{s}\), \(\sqrt{\text{m}/(\text{m/s}^2)} = \text{s}\).
  • 진폭과 무관: 작은 진폭이면 주기가 진폭과 상관없습니다(등시성, 갈릴레이). 진자 시계의 원리.
  • 진자의 질량과 무관: 중력과 관성이 모두 \(m\)에 비례해 소거.
  • 수치: \(L = 1\) m이면 \(T = 2\pi\sqrt{1/9.8} = 2.01\) s. "초진자"(한쪽 흔들림 1초)의 길이가 약 1 m인 이유.

한계

진폭이 크면 주기가 길어진다: \(T \approx 2\pi\sqrt{\frac Lg}\left(1 + \frac{\theta_0^2}{16}\right)\). 30°에서 약 1.7% 길다. 공기 저항이 있으면 진폭이 지수적으로 줄고(감쇠), 주기도 조금 길어진다. 8-03 카드에서 실제로 측정해 비교한다.
