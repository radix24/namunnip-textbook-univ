10.2.1이상 기체 상태 방정식

\[pV = nRT, \qquad R = 8.314\ \text{J/(mol·K)}.\]

\(n\)은 몰수, \(T\)는 절대온도입니다. 밀도가 낮은 기체는 이 식을 잘 따릅니다. 0 °C, 1 atm에서 1몰의 부피는 \(\frac{8.314\times273.15}{1.013\times10^5} = 0.0224\) m³ = 22.4 L입니다. 분자 수 \(N\)으로 쓰면 \(pV = NkT\), \(k = \frac{R}{N_A} = 1.38\times10^{-23}\) J/K (볼츠만 상수)입니다.

10.2.2압력의 정체

기체 분자들이 벽에 부딪혀 튕겨 나올 때 벽에 충격량을 줍니다. 수많은 충돌의 평균 힘을 넓이로 나눈 것이 압력입니다. 한 변이 \(L\)인 상자에서 분자 하나가 \(x\) 방향 속도 \(v_x\)로 벽에 탄성 충돌하면 운동량 변화는 \(2mv_x\)이고, 같은 벽에 다시 오기까지 \(\frac{2L}{v_x}\)가 걸립니다. 평균 힘 \(\frac{mv_x^2}{L}\)을 모든 분자에 대해 더하고, 세 방향이 고르다는 사실(\(\overline{v_x^2} = \frac13\overline{v^2}\))을 쓰면

\[pV = \frac13Nm\overline{v^2} = \frac23N\left(\frac12m\overline{v^2}\right).\]

\(pV = NkT\)와 비교하면

정리 10.2.1 \[\frac12m\overline{v^2} = \frac32kT.\]

온도는 분자 하나의 평균 병진 운동 에너지에 비례합니다. "뜨겁다"는 것은 분자가 빠르게 움직인다는 뜻입니다.

예제 10.2.2

300 K에서 산소 분자(몰질량 0.032 kg/mol)의 제곱평균제곱근 속력 \(v_{\text{rms}} = \sqrt{\overline{v^2}}\)은?

풀이. \(v_{\text{rms}} = \sqrt{\frac{3RT}{M}} = \sqrt{\frac{3(8.314)(300)}{0.032}} \approx 484\) m/s. 질소(0.028)는 약 517 m/s. 소리의 속력과 비슷한 크기입니다. 가벼운 분자일수록 빠릅니다.

요약
  1. \(pV = nRT = NkT\).
  2. 압력 = 분자 충돌의 평균 힘. 평균 운동 에너지 \(\frac32kT\). \(v_{\text{rms}} = \sqrt{3RT/M}\).
