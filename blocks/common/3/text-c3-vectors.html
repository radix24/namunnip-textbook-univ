물리에서 쓰는 벡터

본문
이 절에서 배울 것
  • 크기와 각으로 주어진 벡터를 성분으로 바꾸어 더한다.
  • 스칼라곱(일 계산)과 벡터곱(돌림힘 계산)을 한다.
먼저 알아야 할 것
  • 삼각함수 (고교 수학I). 벡터의 기초는 공통1 9.2절, 내적은 9.3절에서 수학적으로 다룹니다.

1.2.1스칼라와 벡터

질량, 시간, 에너지처럼 수 하나로 나타내는 양을 스칼라, 변위, 속도, 힘처럼 크기와 방향이 함께 필요한 양을 벡터라 합니다. 벡터는 굵은 글씨 \(\vec A\) 또는 \(\mathbf A\)로 쓰고 크기는 \(A\) 또는 \(|\vec A|\)로 씁니다.

1.2.2성분

\(x\)축에서 시계 반대 방향으로 \(\theta\)만큼 기운 크기 \(A\)인 벡터의 성분은

\[A_x = A\cos\theta, \qquad A_y = A\sin\theta.\]

거꾸로 성분에서 크기와 방향을 구할 때는 \(A = \sqrt{A_x^2 + A_y^2}\), \(\tan\theta = \frac{A_y}{A_x}\)입니다(\(\theta\)가 어느 사분면인지 확인). 벡터의 덧셈은 성분끼리 더하면 됩니다. 단위벡터 \(\hat\imath, \hat\jmath, \hat k\)로 \(\vec A = A_x\hat\imath + A_y\hat\jmath + A_z\hat k\)처럼 씁니다.

예제 1.2.1

\(\vec A\)는 크기 10 m, 방향 30°, \(\vec B\)는 크기 6.0 m, 방향 120°이다. \(\vec A + \vec B\)의 크기와 방향을 구하여라.

풀이.

  • \(\vec A\): \((10\cos30^\circ, 10\sin30^\circ) = (8.66, 5.00)\).
  • \(\vec B\): \((6.0\cos120^\circ, 6.0\sin120^\circ) = (-3.00, 5.20)\).
  • 합: \((5.66, 10.20)\).

크기 \(\sqrt{5.66^2 + 10.20^2} \approx 11.7\) m, 방향 \(\tan^{-1}\frac{10.20}{5.66} \approx 61^\circ\).

1.2.3스칼라곱

\[\vec A\cdot\vec B = AB\cos\phi = A_xB_x + A_yB_y + A_zB_z.\]

결과는 스칼라입니다. \(\phi\)는 두 벡터의 사잇각입니다. 4단원의 일 \(W = \vec F\cdot\vec d\)가 대표적인 예로, 힘 가운데 이동 방향 성분만 일을 합니다.

1.2.4벡터곱

\[\vec A\times\vec B = (A_yB_z - A_zB_y)\hat\imath + (A_zB_x - A_xB_z)\hat\jmath + (A_xB_y - A_yB_x)\hat k.\]

결과는 벡터입니다.

  • 크기: \(AB\sin\phi\).
  • 방향: \(\vec A\)와 \(\vec B\)에 모두 수직. 오른손 네 손가락을 \(\vec A\)에서 \(\vec B\)로 감을 때 엄지 방향.
  • \(\vec B\times\vec A = -\vec A\times\vec B\).

6단원의 돌림힘 \(\vec\tau = \vec r\times\vec F\)와 각운동량, 공통4의 자기력에서 씁니다.

예제 1.2.2

\(\vec A = 2\hat\imath + 3\hat\jmath\), \(\vec B = -\hat\imath + 4\hat\jmath\)일 때 \(\vec A\cdot\vec B\)와 \(\vec A\times\vec B\)를 구하여라.

풀이. \(\vec A\cdot\vec B = -2 + 12 = 10\). \(\vec A\times\vec B = (2\cdot4 - 3\cdot(-1))\hat k = 11\hat k\). 두 벡터가 \(xy\)평면에 있으므로 벡터곱은 \(z\) 방향입니다.

요약
  1. 성분 \(A\cos\theta, A\sin\theta\). 덧셈은 성분끼리.
  2. 스칼라곱 \(AB\cos\phi\) (스칼라), 벡터곱 크기 \(AB\sin\phi\), 오른손 방향 (벡터).

1.2.5연습문제

기본

  1. 동쪽으로 3.0 km, 북쪽으로 4.0 km 걸었다. 변위의 크기와 방향은?
    답

    5.0 km, 동쪽에서 북쪽으로 53°.

  2. \(\hat\imath\times\hat\jmath\)는?
    답

    \(\hat k\).
