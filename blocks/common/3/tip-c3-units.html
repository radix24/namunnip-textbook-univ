답을 쓰기 전에는 단위부터 맞춰 본다

요령 · 단위와 차원 검산

언제 쓰는가

식을 외워서 썼는데 맞는지 자신이 없을 때, 보기 중에서 맞는 식을 골라야 할 때, 그리고 계산을 마친 모든 문제의 마지막 단계이다.

요령

  1. 기본 단위로 푼다
    N, J, Pa, W 같은 단위를 kg, m, s로 푼다. \(\text N = \text{kg·m/s}^2\), \(\text J = \text{kg·m}^2/\text s^2\), \(\text{Pa} = \text{kg/(m·s}^2)\).
  2. 양변을 비교한다
    등호 양쪽의 단위가 같아야 한다. 다르면 식이 틀린 것이고, 같아도 무차원 상수(\(2\pi\), \(\frac12\))는 확인되지 않는다.
  3. 더하는 항끼리 같은 단위
    \(v_0t + \frac12at^2\)처럼 더하거나 빼는 항은 모두 같은 단위여야 한다. 하나만 달라도 틀린 식이다.
  4. 함수 안은 단위가 없다
    \(\sin\), \(e^{\square}\), \(\ln\) 안에 들어가는 것은 단위가 없어야 한다. \(e^{-t}\)가 아니라 \(e^{-t/\tau}\)처럼 시간끼리 나눈 꼴이 된다.
  5. 극단을 넣어 본다
    질량을 크게, 마찰을 0으로 하는 식으로 극단의 값을 넣어 답이 상식대로 변하는지 본다.

흔한 실수

  • km/h를 m/s로 바꾸지 않고 다른 SI 단위와 섞어 쓰는 것.
  • 단위가 맞으니 식이 맞다고 결론 내리는 것. 단위 검산은 틀린 식을 걸러 줄 뿐, \(\frac12\) 같은 숫자는 확인하지 못한다.

바로 풀어보기

공기 저항력이 \(F = \frac12C\rho Av^2\)(\(\rho\): 공기 밀도, \(A\): 단면적)일 때 \(C\)에 단위가 없음을 보여라. 또 종단 속력의 식으로 \(v_t = \sqrt{\frac{2mg}{C\rho A}}\)와 \(v_t = \frac{2mg}{C\rho A}\) 가운데 맞는 것을 단위로 골라라.

답과 풀이

답: \(C\)는 무차원, \(v_t = \sqrt{\frac{2mg}{C\rho A}}\)

\(\rho Av^2\)의 단위는 \(\frac{\text{kg}}{\text m^3}\cdot\text m^2\cdot\frac{\text m^2}{\text s^2} = \text{kg·m/s}^2 = \text N\)이므로 이미 힘의 단위이다. 따라서 \(C\)에는 단위가 없다.

\(\frac{mg}{\rho A}\)의 단위는 \(\frac{\text{kg·m/s}^2}{\text{kg/m}} = \frac{\text m^2}{\text s^2}\)이므로, 제곱근을 씌워야 속력(m/s)이 된다. 극단 검사: 무거울수록 \(v_t\)가 커지고, 단면적이 클수록 작아져 상식과 맞다.

이 요령으로 풀리는 문제

  • 단위, 물리량, 벡터 단원 연습 1번, 3번
영상 콘티 · 45초
  1. 0~5초식 두 개 \(v_t = \sqrt{\frac{2mg}{C\rho A}}\)와 \(v_t = \frac{2mg}{C\rho A}\)가 저울 양쪽에 놓인다.외운 식이 맞는지, 단위로 가려 봅시다.
  2. 5~13초\(m\), \(g\), \(\rho\), \(A\)가 하나씩 kg, m/s², kg/m³, m² 단위 블록으로 바뀌어 분수 안에 쌓인다.모든 양을 기본 단위로 푼다.
  3. 13~22초분자와 분모에서 같은 블록(kg, m)이 짝지어 사라지고 m²/s²만 남는다.약분하면 속력의 제곱이 남는다.
  4. 22~30초근호가 덮이자 m/s가 되어 왼쪽 \(v_t\)의 단위와 같은 색으로 빛나고, 근호 없는 식은 m²/s²라 빨간 X가 뜬다.단위가 맞지 않는 식은 틀린 식이다.
  5. 30~38초\(m\)을 조절 막대로 키우자 \(v_t\) 숫자가 커지고, \(A\)를 키우자 작아진다.극단을 넣어 상식과 맞는지도 본다.
  6. 38~45초\(\frac12\)과 \(\frac13\)을 바꿔 넣은 두 식이 모두 단위 검사를 통과하는 모습에 '?' 표시가 붙는다.숫자 계수는 단위로 확인할 수 없다.
