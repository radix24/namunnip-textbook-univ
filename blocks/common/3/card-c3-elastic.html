탄성 충돌과 완전 비탄성 충돌: 에너지는 어디로 가나

1차원 탄성 충돌 공식 · 잃는 에너지의 비율
무엇을 유도하나

1차원에서 \(m_1\)이 \(v_1\)로 정지한 \(m_2\)에 부딪힐 때, 탄성이면 \(v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1\), \(v_2' = \frac{2m_1}{m_1 + m_2}v_1\). 완전 비탄성(붙음)이면 \(v' = \frac{m_1}{m_1 + m_2}v_1\)이고 운동에너지의 \(\frac{m_2}{m_1 + m_2}\)를 잃는다.

모형

  • 탄성: 운동량과 운동에너지가 모두 보존. 당구공, 원자의 충돌처럼 변형이 다시 완전히 돌아오는 경우의 이상화.
  • 완전 비탄성: 충돌 후 한 덩어리. 운동량만 보존. 에너지 손실이 가장 큰 경우.
  • 실제는 그 사이. 반발 계수 \(e = \frac{v_2' - v_1'}{v_1 - v_2}\) (1이면 탄성, 0이면 붙음).

탄성 충돌 유도

  1. 운동량: \(m_1(v_1 - v_1') = m_2v_2'\).
    \(m_1\) 쪽을 한 변으로 모음.
  2. 에너지: \(m_1(v_1^2 - v_1'^2) = m_2v_2'^2\), 곧 \(m_1(v_1 - v_1')(v_1 + v_1') = m_2v_2'^2\).
    \(\frac12\)을 지우고 합차 공식.
  3. 2단계 ÷ 1단계: \(v_1 + v_1' = v_2'\).
    \(v_1 \ne v_1'\) (충돌이 일어났으므로). 이차식이 일차식으로 바뀌는 요령.
  4. 1단계에 넣으면 \(m_1(v_1 - v_1') = m_2(v_1 + v_1')\), \(v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1\), \(v_2' = v_1 + v_1' = \frac{2m_1}{m_1 + m_2}v_1\).
    일차방정식.

3단계 \(v_2' - v_1' = v_1\)은 "탄성 충돌에서 상대 속도는 크기가 같고 방향이 바뀐다"(\(e = 1\))는 뜻입니다.

결과 확인 (특수한 경우)

  • \(m_1 = m_2\): \(v_1' = 0\), \(v_2' = v_1\). 속도가 서로 바뀝니다(당구의 정면 충돌).
  • \(m_2 \gg m_1\) (벽): \(v_1' \to -v_1\), 같은 속력으로 튕김.
  • \(m_1 \gg m_2\) (트럭이 탁구공을): \(v_2' \to 2v_1\). 탁구공은 트럭 속력의 2배로 날아갑니다.

완전 비탄성 충돌의 에너지 손실

  1. \(v' = \frac{m_1v_1}{m_1 + m_2}\).
    운동량 보존.
  2. \(\frac{K'}{K} = \frac{(m_1 + m_2)v'^2}{m_1v_1^2} = \frac{m_1}{m_1 + m_2}\), 잃는 비율 \(\frac{m_2}{m_1 + m_2}\).
    대입 후 약분.

같은 질량이면 절반을 잃습니다. 정지한 큰 물체에 작은 물체가 박히면 거의 다 잃습니다. 탄도 진자(총알이 나무토막에 박힘)에서 에너지 보존을 충돌 순간에 쓰면 틀리는 이유입니다. 충돌은 운동량, 그 뒤 흔들려 올라가는 것은 에너지로 나눠 풉니다.

흔한 오해

  • "비탄성이면 운동량도 보존되지 않는다." 외력이 없으면 운동량은 언제나 보존됩니다. 보존되지 않는 것은 운동에너지입니다.

확인잃은 에너지

같은 질량의 두 진흙 공이 같은 속력으로 정면으로 부딪혀 붙었습니다. 처음 운동에너지 중 남은 것은?
