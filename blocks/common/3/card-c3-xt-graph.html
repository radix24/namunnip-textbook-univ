위치-시간 그래프에서 속도와 가속도 읽기

기울기 · 볼록성 · 넓이

왜 필요한가

운동을 식으로 쓰기 전에 그래프로 읽을 수 있어야 합니다. 실험에서 얻는 것은 식이 아니라 측정점(그래프)이고, 식이 주어져도 그래프를 그려 보면 부호 실수를 잡을 수 있습니다. 고등학교에서 배운 "기울기 = 속도"를 미분의 언어로 정확히 다시 씁니다.

정의

위치 \(x(t)\)에 대해 평균 속도 \(\bar v = \frac{\Delta x}{\Delta t}\), (순간) 속도 \(v(t) = \frac{dx}{dt}\), 가속도 \(a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2}\). 속력은 \(|v|\).

그래프로 풀어 읽기

  1. \(x\)-\(t\) 그래프의 할선 기울기그 구간의 평균 속도.
  2. 접선 기울기그 순간의 속도. 기울기가 양수면 \(+x\) 방향으로, 0이면 그 순간 멈춤(방향이 바뀌는 점일 수 있음).
  3. 볼록성아래로 볼록(위로 열림)이면 기울기가 커지는 중 → \(a > 0\). 위로 볼록이면 \(a < 0\). 변곡점에서 가속도의 부호가 바뀝니다. 공통1의 \(f''\)과 같은 판정입니다.
  4. \(v\)-\(t\) 그래프의 넓이\(\int_{t_1}^{t_2}v\,dt = \Delta x\) (변위, 부호 있음). 이동 거리는 \(\int|v|\,dt\).

예와 반례

예. \(x(t) = t^3 - 6t^2 + 9t\) (m, s). \(v = 3t^2 - 12t + 9 = 3(t - 1)(t - 3)\), \(a = 6t - 12\).

  • \(t = 1, 3\)에서 \(v = 0\): 방향이 바뀝니다(\(v\)의 부호가 + → − → +).
  • \(t = 2\)에서 \(a = 0\): \(x\)-\(t\) 그래프의 변곡점. \(t < 2\)에서 감속하다 \(t > 2\)에서 가속 방향이 바뀝니다.
  • \(0 \le t \le 4\)에서 변위 \(x(4) - x(0) = 4\) m, 이동 거리는 \(|x(1) - x(0)| + |x(3) - x(1)| + |x(4) - x(3)| = 4 + 4 + 4 = 12\) m.

반례(속도와 가속도의 부호가 다른 경우). \(t = 1.5\)에서 \(v = -2.25\), \(a = -3\): 둘 다 음수라 빨라지는 중입니다. \(t = 2.5\)에서 \(v = -2.25\), \(a = 3\): 부호가 반대라 느려지는 중입니다. "가속도가 음수 = 감속"은 틀립니다.

다른 개념과의 관계

속력이 늘어나는지는 \(\frac{d}{dt}v^2 = 2va\)의 부호, 곧 \(v\)와 \(a\)의 부호가 같은지로 정해집니다. 이것은 3단원에서 일률 \(P = Fv\)로, 공통2의 접선 가속도 \(a_T\)로 이어집니다.

흔한 오해

  • "\(x\)-\(t\) 그래프는 물체가 지나간 길이다." 1차원 운동의 \(x\)-\(t\) 그래프는 길 모양이 아니라 시간에 따른 위치입니다.
  • "속도가 0이면 가속도도 0." 위로 던진 공의 꼭대기에서 \(v = 0\)이지만 \(a = -g\)입니다.
