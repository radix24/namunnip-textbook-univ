등가속도 문제는 묻지도 주지도 않은 양이 빠진 식을 고른다

요령 · 등가속도 운동

언제 쓰는가

가속도가 일정한 직선 운동에서 \(v_0\), \(v\), \(a\), \(x\), \(t\) 가운데 셋이 주어지고 하나를 묻는 문제입니다. 어느 식을 쓸지 몰라 연립하다 막힐 때 씁니다.

요령

  1. 다섯 양을 표로
    \(v_0\), \(v\), \(a\), \(x\), \(t\)를 한 줄에 쓰고 주어진 것, 묻는 것, 상관없는 것을 표시합니다. 방향(부호)을 먼저 정합니다.
  2. 빠진 양을 찾는다
    주지도 묻지도 않은 양이 하나 남습니다. 이것이 들어 있지 않은 식을 고르면 한 번에 풀립니다.
  3. 식 네 개의 빠진 양
    \(v = v_0 + at\)에는 \(x\)가, \(x = v_0t + \frac12at^2\)에는 \(v\)가, \(v^2 = v_0^2 + 2ax\)에는 \(t\)가, \(x = \frac{v_0 + v}{2}t\)에는 \(a\)가 없습니다.
  4. 부호로 검산
    감속이면 \(a\)와 \(v_0\)의 부호가 반대여야 합니다. 시간이 음수로 나오면 방향 설정을 다시 봅니다.

흔한 실수

  • 멈추는 순간을 '\(v = 0\)'으로 쓰지 않고 \(a = 0\)으로 착각하는 것. 최고점이나 정지 순간에도 가속도는 그대로입니다.
  • 위로 던진 물체에서 \(g\)의 부호를 위쪽 양으로 둔 채 \(+9.8\)로 쓰는 것.

바로 풀어보기

30 m/s로 달리던 자동차가 일정하게 감속해 45 m를 가서 멈추었습니다. 가속도와 멈출 때까지 걸린 시간을 구하세요.

답과 풀이

답: \(a = -10\ \text{m/s}^2\), \(t = 3.0\ \text s\)

주어진 것: \(v_0 = 30\), \(v = 0\), \(x = 45\). 가속도를 구할 때는 \(t\)가 빠진 식 \(v^2 = v_0^2 + 2ax\)를 씁니다: \(0 = 900 + 90a\), \(a = -10\ \text{m/s}^2\).

시간을 구할 때는 \(a\)가 빠진 식 \(x = \frac{v_0 + v}{2}t\)를 쓰면 앞의 답에 의존하지 않습니다: \(45 = 15t\), \(t = 3.0\ \text s\). 검산: \(v = v_0 + at = 30 - 30 = 0\).

이 요령으로 풀리는 문제

  • 직선 운동과 평면 운동 단원 연습 3번, 4번
영상 콘티 · 45초
  1. 0~5초달리던 자동차가 브레이크를 밟아 45 m 뒤에 멈추는 장면이 옆으로 흐릅니다.가속도는? 시간은?
  2. 5~12초화면 위에 다섯 칸 \(v_0, v, a, x, t\)가 놓이고 30, 0, 45가 칸에 채워집니다. \(a\)에는 '?', \(t\)는 흐리게 남습니다.다섯 양을 한 줄로 늘어놓습니다.
  3. 12~22초식 카드 네 장이 나타나고, 각 카드 귀퉁이에 빠진 양(\(x\), \(v\), \(t\), \(a\))이 도장처럼 찍혀 있습니다.식마다 빠진 양이 하나씩 있습니다.
  4. 22~30초흐린 칸 \(t\)와 같은 도장이 찍힌 카드 \(v^2 = v_0^2 + 2ax\)가 앞으로 나와 숫자를 받아 \(a = -10\)을 냅니다.쓸모없는 양이 빠진 식을 고릅니다.
  5. 30~38초이번에는 \(t\)를 묻고 \(a\)를 모른다고 치면 \(a\) 도장 카드가 나와 \(t = 3\)을 냅니다.묻는 것에 따라 카드를 바꿉니다.
  6. 38~45초자동차 그림 위에 속도 화살표(앞)와 가속도 화살표(뒤)가 반대로 그려집니다.감속이면 부호가 반대인지 확인합니다.
