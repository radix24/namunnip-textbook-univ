등속 원운동은 왜 가속 운동이고, 그 크기는 왜 v²/r인가

구심 가속도 유도 · 주기와 각속도
무엇을 유도하나

반지름 \(r\)인 원을 일정한 속력 \(v\)로 도는 물체의 가속도는 중심을 향하고 크기는 \(a_c = \dfrac{v^2}{r} = \omega^2r\)이다.

모형과 가정

  • 궤도는 정확한 원, 속력은 일정(접선 가속도 0).
  • 각속도 \(\omega = \frac{v}{r}\) (라디안의 정의: 호의 길이 = \(r\theta\)), 주기 \(T = \frac{2\pi r}{v} = \frac{2\pi}{\omega}\).

유도

  1. 위치 \(\mathbf r(t) = (r\cos\omega t, r\sin\omega t)\).
    원점을 중심으로 각 \(\omega t\)만큼 돈 점.
  2. \(\mathbf v = \mathbf r' = r\omega(-\sin\omega t, \cos\omega t)\). 크기 \(r\omega = v\), 방향은 \(\mathbf r\)에 수직(접선).
    성분별 미분. \(\mathbf r\cdot\mathbf v = 0\).
  3. \(\mathbf a = \mathbf v' = -r\omega^2(\cos\omega t, \sin\omega t) = -\omega^2\mathbf r\).
    다시 미분.
  4. 방향은 \(-\mathbf r\), 곧 중심 쪽. 크기 \(\omega^2r = \frac{v^2}{r}\).
    \(\omega = \frac vr\) 대입.

속력은 일정한데 가속도가 있는 이유: 가속도는 속도 벡터의 변화율이고, 방향이 계속 바뀌기 때문입니다. 공통2의 \(a_N = \kappa v^2\)에서 원의 곡률 \(\kappa = \frac1r\)을 넣은 것과 같습니다.

결과 확인

  • 차원: \(\frac{(\text{m/s})^2}{\text{m}} = \text{m/s}^2\).
  • 극한: \(r \to \infty\) (직선)이면 \(a_c \to 0\). 맞습니다.
  • 수치 감각: 지구 적도의 자전: \(r = 6.37\times10^6\) m, \(T = 86164\) s(항성일), \(a_c = \frac{4\pi^2r}{T^2} \approx 0.034\ \text{m/s}^2\), \(g\)의 약 0.3%.

예제

반지름 30 cm 원심분리기가 분당 6000회 돕니다. 가장자리의 구심 가속도는 \(g\)의 몇 배인가요?

  1. \(\omega = 6000\times\frac{2\pi}{60} = 200\pi \approx 628\ \text{rad/s}\).
    1회전 = \(2\pi\) rad, 1분 = 60 s.
  2. \(a_c = \omega^2r = (628)^2(0.30) \approx 1.18\times10^5\ \text{m/s}^2 \approx 12000g\).
    ÷ 9.8.

한계

속력이 바뀌면 접선 가속도 \(\frac{dv}{dt}\)가 더해져 전체 가속도는 중심을 향하지 않습니다(공통2 3-03). 이 카드의 식은 법선 성분에 대해서는 여전히 맞습니다.
