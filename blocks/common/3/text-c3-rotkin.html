회전 운동과 관성 모멘트

본문
이 절에서 배울 것
  • 회전을 각위치, 각속도, 각가속도로 나타낸다.
  • 관성 모멘트를 구하고 회전 운동 에너지를 계산한다.
먼저 알아야 할 것
  • 호도법 (고교 수학I), 원운동 (2.4절), 운동 에너지 (4.2절).

6.1.1각으로 나타내기

고정된 축 둘레로 도는 강체(모양이 변하지 않는 물체)는 모든 점이 같은 각만큼 돕니다. 그래서 직선 운동의 \(x, v, a\) 대신 각을 씁니다.

  • 각위치 \(\theta\) (rad), 각속도 \(\omega = \frac{d\theta}{dt}\) (rad/s), 각가속도 \(\alpha = \frac{d\omega}{dt}\) (rad/s²).
  • 각가속도가 일정하면 2.2절과 같은 꼴: \(\omega = \omega_0 + \alpha t\), \(\theta = \theta_0 + \omega_0t + \frac12\alpha t^2\).

축에서 거리 \(r\)인 점의 운동은 다음과 같습니다(각은 반드시 라디안).

  • 속력 \(v = r\omega\).
  • 접선 가속도 \(a_{\text{tan}} = r\alpha\), 구심 가속도 \(a_{\text{rad}} = \omega^2r\).
예제 6.1.1

3000 rpm(분당 회전수)으로 도는 반지름 0.10 m 원판 가장자리의 속력은?

풀이. \(\omega = 3000\times\frac{2\pi}{60} = 314\) rad/s. \(v = 0.10\times314 = 31.4\) m/s.

6.1.2관성 모멘트와 회전 운동 에너지

각 점의 운동 에너지를 더하면 \(\sum\frac12m_i(r_i\omega)^2 = \frac12\left(\sum m_ir_i^2\right)\omega^2\)입니다.

정의 6.1.2 (관성 모멘트) \[I = \sum m_ir_i^2, \qquad K_{\text{회전}} = \frac12I\omega^2.\]

\(I\)는 회전에서 질량의 역할(돌리기 어려운 정도)을 합니다. 같은 질량이라도 축에서 멀리 있을수록 \(I\)가 크고, 같은 물체라도 축을 어디에 두느냐에 따라 달라집니다. 연속 물체는 적분으로 구하며 결과는 다음과 같습니다.

물체 (질량 \(M\))축\(I\)
가는 막대 (길이 \(L\))중심\(\frac{1}{12}ML^2\)
가는 막대한쪽 끝\(\frac13ML^2\)
얇은 고리 (반지름 \(R\))중심축\(MR^2\)
꽉 찬 원판·원기둥중심축\(\frac12MR^2\)
꽉 찬 구지름\(\frac25MR^2\)

평행축 정리: 질량 중심을 지나는 축에 대한 관성 모멘트가 \(I_{\text{cm}}\)이면, 그와 평행하고 거리 \(d\)인 축에 대해 \(I = I_{\text{cm}} + Md^2\). 막대의 경우 \(\frac{1}{12}ML^2 + M\left(\frac L2\right)^2 = \frac13ML^2\)으로 확인됩니다.

예제 6.1.3

질량을 무시할 수 있는 1.0 m 막대 양 끝에 1.0 kg 공이 하나씩 있다. (가) 막대 중심 (나) 한쪽 끝을 축으로 할 때 \(I\)는?

풀이. (가) \(2\times1.0\times0.50^2 = 0.50\) kg·m². (나) 축 위의 공은 \(r = 0\)이므로 \(1.0\times1.0^2 = 1.0\) kg·m². 두 배입니다.

요약
  1. \(v = r\omega\), \(a_{\text{tan}} = r\alpha\), \(a_{\text{rad}} = \omega^2r\).
  2. \(I = \sum mr^2\), \(K = \frac12I\omega^2\). 질량이 축에서 멀수록 \(I\)가 크다.

6.1.3연습문제

기본

  1. 2.0 kg, 반지름 0.20 m 원판이 10 rad/s로 돈다. 회전 운동 에너지는?
    답

    \(I = 0.040\), \(K = \frac12(0.040)(100) = 2.0\) J.
