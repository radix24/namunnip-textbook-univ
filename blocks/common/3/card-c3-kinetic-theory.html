기체 분자 운동론: 압력은 분자 충돌, 온도는 평균 운동에너지

PV = ⅓Nm⟨v²⟩ · ⟨K⟩ = (3/2)k_BT · 제곱평균제곱근 속력
무엇을 유도하나

이상기체에서 \(PV = \frac13Nm\langle v^2\rangle\). 이것을 \(PV = Nk_BT\)와 비교하면 분자 하나의 평균 병진 운동에너지 \(\langle K\rangle = \frac12m\langle v^2\rangle = \frac32k_BT\).

모형과 가정

  • 분자는 크기가 없는 점, 벽과 탄성 충돌, 분자끼리의 힘은 충돌할 때만(평소에는 무시).
  • 분자 수가 아주 많고 방향이 고르게 퍼져 있다: \(\langle v_x^2\rangle = \langle v_y^2\rangle = \langle v_z^2\rangle = \frac13\langle v^2\rangle\).
  • 한 변이 \(\ell\)인 정육면체 상자(모양은 결과에 영향 없음).

유도

  1. 분자 하나가 \(x\)축에 수직인 벽에 부딪히면 운동량 변화 \(2mv_x\).
    탄성 충돌: \(v_x \to -v_x\) (05-03 카드, 벽 극한).
  2. 같은 벽에 다시 오기까지 \(\Delta t = \frac{2\ell}{v_x}\). 평균 힘 \(\frac{2mv_x}{2\ell/v_x} = \frac{mv_x^2}{\ell}\).
    충격량-운동량 정리, 시간 평균.
  3. \(N\)개를 더하면 \(F = \frac{Nm\langle v_x^2\rangle}{\ell}\), 압력 \(P = \frac{F}{\ell^2} = \frac{Nm\langle v_x^2\rangle}{V}\).
    \(V = \ell^3\).
  4. \(\langle v_x^2\rangle = \frac13\langle v^2\rangle\)이므로 \(PV = \frac13Nm\langle v^2\rangle = \frac23N\langle K\rangle\).
    방향의 고름.
  5. 실험 법칙 \(PV = Nk_BT\)와 비교: \(\langle K\rangle = \frac32k_BT\).
    \(k_B = 1.38\times10^{-23}\) J/K. 이 비교가 온도의 미시적 뜻을 준다.

결과 확인

  • rms 속력: \(v_{\text{rms}} = \sqrt{\frac{3k_BT}{m}} = \sqrt{\frac{3RT}{M}}\). 300 K 질소(\(M = 0.028\) kg/mol): \(\sqrt{\frac{3(8.31)(300)}{0.028}} \approx 517\) m/s. 음속(343 m/s)과 같은 크기인 것이 자연스럽습니다(소리는 분자 충돌로 전해지므로).
  • 질량 의존: 같은 온도에서 가벼운 분자가 빠르다. 수소는 질소보다 \(\sqrt{14} \approx 3.7\)배 빠르다.
  • 차원: \(k_BT\)는 에너지(J).

한계

고압·저온에서는 분자 크기와 분자 사이 인력이 중요해져 이상기체에서 벗어납니다(반데르발스 식). 이원자 분자는 회전 운동에너지도 가져서 내부 에너지가 \(\frac52Nk_BT\)가 됩니다(에너지 등분배). 상온에서 진동이 거의 기여하지 않는 것은 양자역학으로만 설명된다.
