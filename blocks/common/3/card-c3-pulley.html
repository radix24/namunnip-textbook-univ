도르래로 연결된 물체: 물체마다 식 하나, 줄로 묶기

애트우드 기계 · 구속 조건 · 장력

모형과 가정

  • 줄은 늘어나지 않는다 → 연결된 물체의 가속도 크기가 같다(구속 조건).
  • 줄의 질량은 없다, 도르래는 질량과 마찰이 없다 → 줄 전체의 장력이 같다. (도르래의 질량을 넣으면 5단원에서처럼 양쪽 장력이 달라진다.)
먼저 예측

무거운 쪽 추(\(m_2\))가 내려가는 동안 줄의 장력은 \(m_2g\)보다 클까요, 작을까요? \(m_1g\)와는?

예측 확인

\(m_1g < T < m_2g\)입니다. \(T = m_2g\)이면 \(m_2\)가 가속하지 않고, \(T = m_1g\)이면 \(m_1\)이 가속하지 않습니다.

마찰 없는 수평 책상 위 상자 \(m_1 = 3.0\) kg이 책상 끝 도르래를 지나는 줄로 매달린 추 \(m_2 = 2.0\) kg과 연결되어 있습니다. 가속도와 장력을 구하세요. 또 상자와 책상 사이 \(\mu_k = 0.20\)이면 어떻게 바뀌나요?

풀이

  1. 각 물체의 + 방향을 "움직일 방향"으로 따로 잡는다: 상자는 도르래 쪽, 추는 아래. 그러면 두 가속도가 같은 \(a\).
    구속 조건을 부호 걱정 없이 쓰는 요령.
  2. 상자(수평): \(T = m_1a\).
    수평으로 받는 힘은 장력뿐.
  3. 추(아래 +): \(m_2g - T = m_2a\).
    중력 아래, 장력 위.
  4. 더하면 \(m_2g = (m_1 + m_2)a\), \(a = \frac{2.0(9.8)}{5.0} = 3.92\ \text{m/s}^2\). \(T = 3.0(3.92) = 11.8\) N.
    두 식을 더하면 \(T\)가 소거된다. 내력은 계 전체에서는 상쇄.
  5. 마찰이 있으면 상자 식이 \(T - \mu_km_1g = m_1a\). 더하면 \(a = \frac{m_2g - \mu_km_1g}{m_1 + m_2} = \frac{19.6 - 5.88}{5.0} = 2.74\ \text{m/s}^2\), \(T = 3.0(2.74) + 5.88 = 14.1\) N.
    마찰은 운동 반대 방향.

의미

4단계의 식은 "계 전체를 한 물체로 보면 바깥 힘 \(m_2g\)가 전체 질량 \(m_1 + m_2\)를 끈다"는 뜻입니다. 장력은 내력이라 계 전체의 가속도에 들어가지 않습니다. 장력을 구하려면 다시 물체 하나를 떼어 봐야 합니다.

검산

\(m_1 \to 0\)이면 \(a \to g\) (추가 자유 낙하), \(T \to 0\). \(m_1 \to \infty\)이면 \(a \to 0\), \(T \to m_2g\). 장력 11.8 N은 \(m_2g = 19.6\) N보다 작습니다. 모두 맞습니다.

흔한 오해

  • "장력 = 매달린 추의 무게." 추가 정지하거나 등속일 때만 맞습니다.
