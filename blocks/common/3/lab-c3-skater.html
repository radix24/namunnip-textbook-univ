팔을 오므리면 왜 빨리 돌까?

실습 · 각운동량 보존

목표

회전 의자에 앉아 아령을 든 팔을 오므리면 회전이 빨라집니다. 관성 모멘트가 줄어도 각운동량 \(L = I\omega\)가 보존되기 때문입니다. 팔 길이를 바꾸며 각속도와 회전 운동 에너지를 계산합니다. 성취기준 [공통3-06-04].

준비

  • 모형: 몸과 의자의 관성 모멘트 \(I_0 = 1.2\) kg·m², 양손에 4 kg 아령을 점질량으로 봅니다. 팔 길이가 \(r\)이면 \(I = I_0 + 2mr^2\).
  • 처음에는 팔을 0.80 m로 벌리고 \(\omega_0\)로 돕니다. 회전축에 대한 외부 돌림힘이 없으므로 \(L = I\omega\)는 일정합니다.
  • 위에서 내려다본 그림입니다. 재생을 누르면 지금 \(\omega\)로 돕니다.

절차

  1. \(\omega_0 = 2\) rad/s로 두고 팔 길이를 0.80, 0.50, 0.20 m로 줄이며 \(I\), \(\omega\), 운동 에너지를 기록합니다.
  2. 각운동량이 정말 그대로인지 출력에서 확인합니다.
  3. 재생을 누르고 팔 길이를 움직여 회전 빠르기가 바뀌는 것을 봅니다.

기대 결과

  • 처음 \(I = 1.2 + 2\cdot4\cdot0.8^2 = 6.32\) kg·m², \(L = 12.64\) kg·m²/s.
  • \(r = 0.50\) m: \(I = 3.20\), \(\omega = 3.95\) rad/s. \(r = 0.20\) m: \(I = 1.52\), \(\omega = 8.316\) rad/s(1.323바퀴/s)로 처음의 4.158배입니다.
  • 회전 운동 에너지는 12.64 J에서 \(r = 0.20\) m일 때 52.56 J로 같은 4.158배 늘어납니다. 에너지는 보존되지 않습니다.

분석

  1. \(K = \dfrac{L^2}{2I}\)임을 보이고, \(L\)이 일정할 때 \(I\)가 줄면 \(K\)가 같은 비율로 커지는 이유를 설명해 보세요.
  2. 늘어난 운동 에너지는 어디서 왔나요? 아령을 안쪽으로 당길 때 팔이 한 일(원심 방향의 힘을 거슬러 당김)과 연결해 보세요.
