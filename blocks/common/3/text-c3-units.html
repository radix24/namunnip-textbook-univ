1.1.1물리량과 단위

물리학은 자연을 측정하고 수로 나타내는 학문입니다. 측정한 양(물리량)은 "수 + 단위"로 씁니다. 5라고만 하면 5 m인지 5 s인지 알 수 없습니다. 국제적으로 쓰는 단위 체계(SI)의 역학 기본 단위는 다음 셋입니다.

  • 길이: 미터 (m).
  • 질량: 킬로그램 (kg).
  • 시간: 초 (s).

다른 단위는 이것들을 조합해 만듭니다. 속력 m/s, 가속도 m/s², 힘의 단위 뉴턴 N = kg·m/s², 에너지의 단위 줄 J = N·m입니다. 아주 크거나 작은 양은 접두어를 붙입니다.

  • 킬로 k = \(10^3\), 메가 M = \(10^6\), 기가 G = \(10^9\).
  • 센티 c = \(10^{-2}\), 밀리 m = \(10^{-3}\), 마이크로 μ = \(10^{-6}\), 나노 n = \(10^{-9}\).

1.1.2단위 환산

단위를 바꿀 때는 값이 1인 분수(예: \(\frac{1000\ \text{m}}{1\ \text{km}}\))를 곱해, 필요 없는 단위를 약분합니다.

예제 1.1.1

시속 100 km를 m/s로 바꾸어라.

풀이.

\[100\ \frac{\text{km}}{\text{h}}\times\frac{1000\ \text{m}}{1\ \text{km}}\times\frac{1\ \text{h}}{3600\ \text{s}} = 27.8\ \text{m/s}.\]

요령: km/h를 m/s로 바꿀 때는 3.6으로 나눕니다.

1.1.3유효숫자

측정값은 정확하지 않습니다. 자로 잰 2.3 m는 "2.2와 2.4 사이"라는 뜻이고, 2.30 m는 더 정밀하게 쟀다는 뜻입니다. 믿을 수 있는 자릿수를 유효숫자라 합니다(앞의 0은 세지 않음). 계산 결과는 입력보다 정밀할 수 없으므로 다음 규칙을 씁니다.

  • 곱셈·나눗셈: 결과의 유효숫자 개수 = 입력 중 가장 적은 개수.
  • 덧셈·뺄셈: 결과의 소수 자릿수 = 입력 중 가장 적은 소수 자릿수.
예제 1.1.2

가로 2.3 m, 세로 4.12 m인 방의 넓이는?

풀이. 계산기는 9.476을 보여 주지만 2.3이 유효숫자 2개이므로 9.5 m²로 씁니다.

1.1.4차원 점검

식의 양변과 더하는 항들은 단위가 같아야 합니다. 예를 들어 \(x = v_0t + \frac12at^2\)에서 \(v_0t\)는 (m/s)(s) = m, \(at^2\)은 (m/s²)(s²) = m으로 모두 길이입니다. 공식을 잘못 기억했을 때 단위를 맞춰 보면 많은 실수를 잡을 수 있습니다.

요약
  1. SI 기본: m, kg, s. N = kg·m/s², J = N·m.
  2. 환산은 값이 1인 분수를 곱해 약분.
  3. 곱셈은 유효숫자 개수, 덧셈은 소수 자릿수를 맞춘다.

1.1.5연습문제

기본

  1. 1 g/cm³를 kg/m³로 바꾸어라.
    답

    \(\frac{10^{-3}\ \text{kg}}{10^{-6}\ \text{m}^3} = 1000\) kg/m³ (물의 밀도).

  2. 12.0 + 0.345의 결과를 유효숫자에 맞게 써라.
    답

    소수 첫째 자리까지: 12.3.

응용

  1. 진자의 주기 \(T\)가 길이 \(L\)과 \(g\)(m/s²)로만 정해진다면 \(T\)는 \(\sqrt{L/g}\)에 비례해야 함을 단위로 보여라.
    답

    \(\frac{\text{m}}{\text{m/s}^2} = \text{s}^2\)이므로 \(\sqrt{L/g}\)가 시간 단위이다.
