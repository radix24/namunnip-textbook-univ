힘과 퍼텐셜 에너지 그래프

본문
이 절에서 배울 것
  • \(F = -\frac{dU}{dx}\)로 퍼텐셜 에너지에서 힘을 구한다.
  • 퍼텐셜 에너지 그래프에서 평형점과 운동 범위를 읽는다.
먼저 알아야 할 것
  • 퍼텐셜 에너지 (4.3절), 도함수와 극값 (고교 수학II).

4.4.1힘은 퍼텐셜의 기울기

보존력이 \(dx\)만큼 움직이며 한 일 \(F\,dx\)는 퍼텐셜 에너지의 감소 \(-dU\)와 같으므로

\[F(x) = -\frac{dU}{dx}.\]

확인: 용수철 \(U = \frac12kx^2\)이면 \(F = -kx\) (늘이면 되돌리는 힘). 중력 \(U = mgy\)이면 \(F = -mg\) (아래 방향). 그래프로 보면 힘은 언제나 \(U\)가 낮아지는 쪽(내리막)을 향합니다. 공이 언덕을 굴러 내려가는 모습을 떠올리면 됩니다.

4.4.2평형점

  • \(\frac{dU}{dx} = 0\)인 점에서는 힘이 0이다: 평형점.
  • \(U\)가 극소인 점: 조금 벗어나면 되돌아오는 힘. 안정 평형 (골짜기 바닥).
  • \(U\)가 극대인 점: 조금 벗어나면 더 멀어지는 힘. 불안정 평형 (언덕 꼭대기).

4.4.3운동 범위

역학적 에너지 \(E = K + U\)가 일정하고 \(K \ge 0\)이므로 물체는 \(U(x) \le E\)인 곳에서만 움직일 수 있습니다. 그래프에 높이 \(E\)인 수평선을 그으면, \(U\)가 그 아래에 있는 구간이 운동 범위입니다. \(U = E\)인 점에서 \(K = 0\)이 되어 방향을 바꿉니다(반환점).

예제 4.4.1

\(U(x) = x^4 - 2x^2\) (J, \(x\)는 m)이다. 평형점과 그 안정성을 구하고, \(E = -0.50\) J일 때 운동 범위를 구하여라.

풀이. \(\frac{dU}{dx} = 4x^3 - 4x = 4x(x^2 - 1) = 0\)에서 \(x = 0, \pm1\).

  • \(x = 0\): \(U = 0\), 극대. 불안정.
  • \(x = \pm1\): \(U = -1\), 극소. 안정.

\(E = -0.50\)이면 \(x^4 - 2x^2 \le -0.5\), 곧 \(x^2\)이 \(1 - \frac{1}{\sqrt2}\)과 \(1 + \frac{1}{\sqrt2}\) 사이입니다. 오른쪽 골짜기에 있으면 \(0.54 \le x \le 1.31\) m에서 왕복합니다. 가운데 언덕(\(U = 0\))을 넘지 못하므로 왼쪽 골짜기로 갈 수 없습니다. \(E > 0\)이면 언덕을 넘어 양쪽을 오갑니다.

원자 사이의 힘, 분자의 진동, 화학 반응의 활성화 에너지도 같은 그림으로 이해합니다(공통5 화학).

요약
  1. \(F = -dU/dx\): 힘은 \(U\)의 내리막 방향.
  2. \(U\) 극소 = 안정 평형, 극대 = 불안정 평형.
  3. 운동 범위는 \(U(x) \le E\). \(U = E\)에서 방향을 바꾼다.

4.4.4연습문제

기본

  1. \(U = 3x^2 - 2x\) (J)일 때 \(x = 1\) m에서의 힘은?
    답

    \(F = -(6x - 2) = -4\) N.

  2. 예제 4.4.1에서 \(x = 1\)에 정지해 있던 물체가 왼쪽 골짜기로 가려면 최소 얼마의 에너지를 받아야 하는가?
    답

    언덕 높이까지 \(0 - (-1) = 1\) J.
