9.2.1파동

줄의 한 끝을 흔들면 흔들림이 줄을 따라 전달됩니다. 매질의 각 부분은 제자리에서 진동할 뿐이고, 앞으로 가는 것은 진동의 모양과 에너지입니다. 이것이 역학적 파동입니다.

  • 횡파: 진동 방향이 진행 방향에 수직 (줄의 파동).
  • 종파: 진동 방향이 진행 방향과 나란함 (소리).

9.2.2사인파의 식

\(+x\) 방향으로 가는 사인파는

\[y(x, t) = A\sin(kx - \omega t).\]
  • 파수 \(k = \frac{2\pi}{\lambda}\) (\(\lambda\)는 파장, 한 모양의 길이).
  • 각진동수 \(\omega = 2\pi f\) (\(f\)는 진동수, 1초당 진동 횟수, Hz). 주기 \(T = \frac1f\).
  • 파동의 속력 \(v = \lambda f = \frac\omega k\).

\(kx - \omega t\)가 일정한 점(예를 들어 마루)은 \(x = \frac\omega kt + \text{상수}\)로 움직이므로 속력이 \(\frac\omega k\)입니다. \(-x\) 방향으로 가는 파는 \(kx + \omega t\)입니다.

예제 9.2.1

\(y = 0.020\sin(2.0x - 50t)\) (m, s)의 진폭, 파장, 진동수, 속력은?

풀이. \(A = 0.020\) m. \(\lambda = \frac{2\pi}{2.0} = 3.14\) m. \(f = \frac{50}{2\pi} = 7.96\) Hz. \(v = \frac{50}{2.0} = 25\) m/s, \(+x\) 방향.

9.2.3줄의 파동 속력

파동의 속력은 진동수가 아니라 매질의 성질로 정해집니다. 장력 \(F\), 선밀도(단위 길이당 질량) \(\mu\)인 줄에서

\[v = \sqrt{\frac F\mu}.\]

팽팽할수록 빠르고, 무거울수록 느립니다. 같은 줄에서 진동수를 높이면 속력은 그대로이고 파장이 짧아집니다.

예제 9.2.2

장력 100 N, 선밀도 0.010 kg/m인 줄의 파동 속력과, 진동수 50 Hz일 때 파장은?

풀이. \(v = \sqrt{10^4} = 100\) m/s. \(\lambda = \frac{100}{50} = 2.0\) m.

요약
  1. \(y = A\sin(kx - \omega t)\), \(k = 2\pi/\lambda\), \(\omega = 2\pi f\), \(v = \lambda f = \omega/k\).
  2. 줄: \(v = \sqrt{F/\mu}\). 속력은 매질이 정한다.
