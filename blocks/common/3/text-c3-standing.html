9.3.1중첩과 정상파

두 파동이 같은 곳을 지나면 각 점의 변위는 두 파동의 변위의 합입니다(중첩 원리). 파동끼리 부딪혀 튕겨 나가지 않고 서로 통과합니다.

줄의 고정된 끝에서 반사된 파동이 들어오는 파동과 겹치면, 같은 진폭으로 반대 방향으로 가는 두 파동의 합이 됩니다.

\[A\sin(kx - \omega t) + A\sin(kx + \omega t) = 2A\sin kx\cos\omega t.\]

모양 \(\sin kx\)는 움직이지 않고 제자리에서 위아래로만 진동합니다. 이것이 정상파입니다.

  • 마디: \(\sin kx = 0\)인 점. 전혀 움직이지 않는다. 간격은 \(\frac\lambda2\).
  • 배: 진폭 \(2A\)로 가장 크게 움직이는 점.

9.3.2고정된 줄의 고유 진동수

길이 \(L\)인 줄의 양 끝은 고정되어 있으므로 마디여야 합니다. 그러려면 줄 길이가 반 파장의 정수배여야 합니다.

\[L = n\frac{\lambda_n}{2}, \qquad f_n = \frac{v}{\lambda_n} = n\frac{v}{2L}, \quad n = 1, 2, 3, \dots\]

\(f_1 = \frac{v}{2L}\)을 기본 진동수, \(f_n = nf_1\)을 \(n\)번째 배음(조화 진동수)이라 합니다. 기타나 바이올린의 음높이는 기본 진동수로 정해지고, 배음의 섞인 비율이 음색을 정합니다.

예제 9.3.1

길이 0.65 m인 기타 줄의 기본 진동수가 440 Hz이다. 줄의 파동 속력과 셋째 배음은?

풀이. \(v = 2Lf_1 = 2(0.65)(440) = 572\) m/s. \(f_3 = 1320\) Hz.

줄을 조이면(장력 증가) \(v = \sqrt{F/\mu}\)가 커져 음이 높아지고, 손가락으로 눌러 길이를 줄여도 높아집니다. 굵은 줄(\(\mu\) 큼)은 낮은 음을 냅니다.

이 결과는 공통9(고등미적분학(2))에서 파동방정식을 변수분리로 풀어 다시 얻습니다.

요약
  1. 중첩: 변위를 더한다. 반대 방향 두 파의 합 = 정상파 \(2A\sin kx\cos\omega t\).
  2. 양 끝 고정: \(L = n\lambda/2\), \(f_n = nv/(2L)\).
