원 모양 영역은 왜 극좌표로 자르면 쉬울까?

실습 · 극좌표 이중적분

목표

원판 위에서 \(\iint e^{-(x^2 + y^2)}\,dA\)를 두 가지로 어림한다. 정사각형 조각으로 자르면 원의 둘레에서 조각이 삐져나오거나 모자라고, 극좌표 조각(부채꼴 고리)으로 자르면 원에 꼭 맞다. 조각의 넓이가 \(r\,\Delta r\,\Delta\theta\)인 이유도 그림으로 확인한다. 성취기준 [공통2-06-03].

준비

  • 색이 진할수록 함숫값 \(e^{-(x^2+y^2)}\)이 크다. 주황 원이 적분 영역의 경계이다.
  • 극좌표 조각은 반지름 방향으로 \(n\)개, 각 방향으로 \(4n\)개이다. 바깥 조각일수록 넓은 것을 눈으로 확인하자. 조각 하나의 넓이는 약 \(r_i\,\Delta r\,\Delta\theta\)이다.
  • 정확한 값: \(\displaystyle\int_0^{2\pi}\!\!\int_0^R e^{-r^2}\,r\,dr\,d\theta = \pi(1 - e^{-R^2})\).

절차

  1. \(R = 2\)에서 극좌표 조각 \(n = 2, 4, 10\)의 합을 기록한다.
  2. 정사각형 조각으로 바꿔 \(n = 4, 10, 40\)의 합을 기록한다.
  3. \(R = 3\)으로 늘려 결과가 \(\pi\)에 얼마나 가까운지 본다.

기대 결과

  • \(R = 2\)의 정확한 값은 \(\pi(1 - e^{-4}) = 3.08405\)이다. 극좌표 조각은 \(n = 2, 4, 10\)에서 3.44004, 3.16061, 3.09593으로 한쪽에서 차근차근 다가간다.
  • 정사각형 조각은 \(n = 4, 10, 40\)에서 3.08280, 3.08907, 3.08541이다. 원 둘레에 걸친 조각을 넣었다 뺐다 하므로 오차가 들쭉날쭉하다.
  • \(R = 3\)이면 정확한 값은 3.14120으로 \(\pi\)와 0.0004밖에 다르지 않다. \(R \to \infty\)이면 \(\iint_{\mathbb R^2} e^{-(x^2+y^2)}dA = \pi\)이다.

분석

  1. 극좌표 조각의 넓이가 \(\Delta r\,\Delta\theta\)가 아니라 \(r\,\Delta r\,\Delta\theta\)인 이유를 그림의 바깥 조각과 안쪽 조각을 비교해 설명해 보자.
  2. \(\iint_{\mathbb R^2} e^{-(x^2+y^2)}dA = \left(\int_{-\infty}^\infty e^{-x^2}dx\right)^2\)임을 이용하면 \(\int_{-\infty}^\infty e^{-x^2}dx\)는 얼마인가요? 이 값이 정규분포(공통7 5.2절)의 \(\sqrt{2\pi}\)가 나오는 곳이다.

더 해 보기
