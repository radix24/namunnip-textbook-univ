임계점을 분류할 때는 \(D = f_{xx}f_{yy} - f_{xy}^2\)의 부호부터 본다

요령 · 극대·극소·안장점

언제 쓰는가

이변수 함수의 임계점을 모두 구해 극대, 극소, 안장점으로 나누라는 문제입니다.

요령

  1. 임계점을 모두 찾는다
    \(f_x = 0\), \(f_y = 0\)을 연립합니다. 인수분해가 되면 경우를 나눠 빠짐없이 풉니다.
  2. 점마다 \(D\)
    이계 편도함수로 \(D = f_{xx}f_{yy} - f_{xy}^2\)을 점마다 계산합니다.
  3. 부호로 분류
    \(D < 0\)이면 안장점입니다. \(D > 0\)이면 \(f_{xx} > 0\)일 때 극소, \(f_{xx} < 0\)일 때 극대입니다.
  4. \(D = 0\)이면 직접 본다
    판정법이 답하지 않으므로, 그 점을 지나는 직선이나 곡선 위에서 값의 변화를 직접 비교합니다.

흔한 실수

  • \(f_{xx} > 0\)만 보고 극소라고 하는 것. \(D\)부터 봐야 하며, \(D < 0\)이면 \(f_{xx}\)의 부호와 관계없이 안장점입니다.
  • 연립방정식의 해를 일부 빠뜨리는 것. \(x = x^4\)에서 \(x = 0\)을 놓치기 쉽습니다.

바로 풀어보기

\(f(x, y) = x^3 - 3xy + y^3\)의 임계점을 모두 구하고 분류하세요.

답과 풀이

답: \((0, 0)\)은 안장점, \((1, 1)\)은 극소(극솟값 \(-1\))

\(f_x = 3x^2 - 3y = 0\)에서 \(y = x^2\), \(f_y = -3x + 3y^2 = 0\)에서 \(x = y^2\)입니다. 대입하면 \(x = x^4\), 곧 \(x(x^3 - 1) = 0\)이므로 \(x = 0\) 또는 \(x = 1\)이고, 임계점은 \((0, 0)\), \((1, 1)\)입니다.

\(f_{xx} = 6x\), \(f_{yy} = 6y\), \(f_{xy} = -3\)입니다. \((0, 0)\): \(D = 0 - 9 < 0\)이므로 안장점. \((1, 1)\): \(D = 36 - 9 = 27 > 0\), \(f_{xx} = 6 > 0\)이므로 극소, \(f(1, 1) = -1\)입니다.

이 요령으로 풀리는 문제

  • 최댓값과 최솟값 단원 연습 1번, 2번, 8번
영상 콘티 · 45초
  1. 0~6초\(z = x^3 - 3xy + y^3\)의 곡면이 돌아가며, 원점 근처의 말안장 모양과 \((1, 1)\) 근처의 우묵한 곳이 보입니다.임계점, 어떻게 분류할까요?
  2. 6~14초\(xy\) 평면 위에 곡선 \(y = x^2\)과 \(x = y^2\)이 그려지고, 두 곡선이 만나는 두 점에 핀이 꽂힙니다.먼저 임계점을 빠짐없이 찾습니다.
  3. 14~22초화면 한쪽에 계기판이 나타나 \(D = f_{xx}f_{yy} - f_{xy}^2\)를 보여 줍니다. 바늘이 0을 기준으로 왼쪽(음수)과 오른쪽(양수)을 가리킬 수 있습니다.\(D\)의 부호를 먼저 봅니다.
  4. 22~30초원점 핀을 누르자 바늘이 음수 쪽으로 넘어가고, 곡면의 원점이 확대되어 한 방향은 오르막, 다른 방향은 내리막인 말안장이 보입니다.\(D\)가 음수면 안장점.
  5. 30~38초\((1, 1)\) 핀을 누르자 바늘이 양수 쪽으로 가고, \(f_{xx} = 6 > 0\) 표시와 함께 그릇 모양이 확대됩니다.\(D\)가 양수이고 \(f_{xx}\)가 양수면 극소.
  6. 38~45초원점에서 \(f_{xx} = 0\)이라 판정을 미뤘던 장면, 또는 \(x^2 - y^2\)에서 \(f_{xx} > 0\)만 보고 '극소'라고 쓴 답에 X가 그어집니다.\(f_{xx}\)만 보면 안 됩니다.
