면적분과 발산·Stokes 정리 연습 문제

문제 7 · 개념·계산·판단 · 힌트 2단계

직접 계산과 정리를 쓴 계산 중 어느 쪽이 쉬운지 먼저 판단하세요.

  1. 계산원뿔면 \(z = \sqrt{x^2 + y^2}\), \(0 \le z \le 2\)의 넓이를 구하세요. [08-01]

    힌트 1

    \(g_x^2 + g_y^2 = \frac{x^2 + y^2}{x^2 + y^2} = 1\).

    힌트 2

    \(dS = \sqrt2\,dA\), 그림자는 반지름 2인 원판.

    풀이

    \(\sqrt2\cdot4\pi = 4\sqrt2\,\pi\). 검산: 원뿔 옆넓이 \(\pi r\ell = \pi\cdot2\cdot2\sqrt2\).

  2. 계산\(\mathbf F = (y, -x, z)\)가 평면 \(z = 4 - x - y\)의 제1팔분공간 부분(\(x, y, z \ge 0\))을 위쪽으로 지나는 선속을 구하세요. [08-02]

    힌트 1

    위쪽 법선 \((1, 1, 1)\).

    힌트 2

    \(\mathbf F\cdot(1,1,1) = y - x + z = 4 - 2x\). 그림자는 삼각형 \(x + y \le 4\).

    풀이

    \(\int_0^4\int_0^{4-x}(4 - 2x)\,dy\,dx = \int_0^4(4 - 2x)(4 - x)\,dx = \int_0^4(16 - 12x + 2x^2)\,dx = 64 - 96 + \frac{128}{3} = \frac{32}{3}\).

  3. 계산\(\mathbf F = (xyz, x^2y, yz^2)\)의 발산과 회전을 구하고, \(\nabla\cdot(\nabla\times\mathbf F) = 0\)을 확인하세요. [07-05]

    힌트 1

    \(\nabla\cdot\mathbf F = yz + x^2 + 2yz\).

    힌트 2

    \(\nabla\times\mathbf F = (R_y - Q_z, P_z - R_x, Q_x - P_y)\).

    풀이

    \(\nabla\cdot\mathbf F = x^2 + 3yz\). \(\nabla\times\mathbf F = (z^2 - 0,\ xy - 0,\ 2xy - xz) = (z^2, xy, 2xy - xz)\).

    발산: \(0 + x + (-x) = 0\). 확인됨.

  4. 개념\(\mathbf F = (x, y, z)\)가 단위구면을 바깥으로 지나는 선속을 발산 정리로 구하세요. 또 \(\mathbf F = \frac{(x,y,z)}{(x^2+y^2+z^2)^{3/2}}\)이면 어떻게 되나요? [08-03]

    힌트 1

    첫째: \(\nabla\cdot\mathbf F = 3\).

    힌트 2

    둘째는 원점에서 정의되지 않으므로 발산 정리를 바로 쓸 수 없습니다. 구면 위에서 직접 계산.

    풀이

    첫째: \(3\cdot\frac43\pi = 4\pi\).

    둘째: 단위구면 위에서 \(\mathbf F = \mathbf n\)이므로 \(\mathbf F\cdot\mathbf n = 1\), 선속 \(= 4\pi\). 원점 밖에서 발산은 0인데 선속은 \(4\pi\): 원점의 특이점이 모든 "샘"을 가지고 있습니다(쿨롱 법칙에서 가우스 법칙으로 가는 핵심 계산).

  5. 계산Stokes 정리로 \(\iint_S(\nabla\times\mathbf F)\cdot d\mathbf S\)를 구하세요. \(\mathbf F = (z, x, y)\), \(S\): 위반구면 \(x^2 + y^2 + z^2 = 4\), \(z \ge 0\), 바깥(위쪽) 방향. [08-03]

    힌트 1

    경계는 원 \(x^2 + y^2 = 4\), \(z = 0\), 반시계.

    힌트 2

    또는 곡면을 원판으로 바꿔도 됩니다: \(\nabla\times\mathbf F = (1, 1, 1)\).

    풀이

    경계 \((2\cos t, 2\sin t, 0)\): \(\mathbf F = (0, 2\cos t, 2\sin t)\), \(\mathbf r' = (-2\sin t, 2\cos t, 0)\). \(\int_0^{2\pi}4\cos^2t\,dt = 4\pi\).

    곡면 바꾸기: 원판 \(z = 0\), \(\mathbf n = (0,0,1)\), \((1,1,1)\cdot\mathbf n = 1\), 넓이 \(4\pi\). 일치.

  6. 계산\(\mathbf F = (x^3, y^3, z^3)\)가 공 \(x^2 + y^2 + z^2 \le a^2\)의 겉면을 바깥으로 지나는 선속을 구하세요. [08-03]

    힌트 1

    \(\nabla\cdot\mathbf F = 3(x^2 + y^2 + z^2) = 3\rho^2\).

    힌트 2

    구면좌표 \(\int_0^{2\pi}\int_0^\pi\int_0^a3\rho^2\cdot\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\).

    풀이

    \(3\cdot\frac{a^5}{5}\cdot2\cdot2\pi = \frac{12\pi a^5}{5}\).

  7. 판단한 학생이 \(\mathbf F = (x, y, z + 1)\)이 위반구면 \(x^2 + y^2 + z^2 = a^2\), \(z \ge 0\)을 위쪽으로 지나는 선속을 발산 정리로 \(\iiint3\,dV = 2\pi a^3\)이라고 했습니다. 어디가 틀렸고, 바른 값은? [08-03]

    힌트 1

    08-03 절: 발산 정리는 어떤 곡면에서 성립하나요?

    힌트 2

    밑면 원판(아래 방향)의 선속을 구해 빼세요.

    풀이

    반구면은 닫힌 곡면이 아니라 발산 정리를 바로 쓸 수 없습니다. 밑면 원판을 덮으면 닫힌 곡면의 바깥 선속은 \(3\cdot\frac23\pi a^3 = 2\pi a^3\). 밑면(\(z = 0\), \(\mathbf n = -\mathbf k\))에서 \(\mathbf F\cdot\mathbf n = -(0 + 1) = -1\)이라 선속 \(-\pi a^2\). 반구면의 선속 \(= 2\pi a^3 - (-\pi a^2) = 2\pi a^3 + \pi a^2\).

    검산: \((x, y, z)\) 부분은 구면 위에서 \(\mathbf F\cdot\mathbf n = a\)라 \(a\cdot2\pi a^2\), \((0, 0, 1)\) 부분은 반구면의 그림자 넓이 \(\pi a^2\). 합이 같습니다.
