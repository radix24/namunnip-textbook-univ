직사각형 영역의 이중적분

본문
이 절에서 배울 것
  • 이중적분을 곡면 아래 부피로 이해한다.
  • 반복적분(한 변수씩 차례로 적분)으로 계산한다.
먼저 알아야 할 것
  • 리만 합과 정적분 (공통1 4.1절), 단면으로 구하는 부피 (6.1절).

6.1.1부피와 이중적분

일변수 정적분은 구간을 잘게 나누어 "높이 × 폭"을 더한 것의 극한이었습니다. 직사각형 \(R = [a, b]\times[c, d]\) 위의 곡면 \(z = f(x, y) \ge 0\) 아래 부피도 같은 방법으로 구합니다. \(R\)을 작은 직사각형으로 나누고, 각 조각 위에 높이 \(f(x_i, y_j)\)인 기둥을 세워 부피 \(f(x_i, y_j)\Delta A\)를 더합니다. 조각을 한없이 작게 한 극한을 이중적분이라 합니다.

\[\iint_Rf(x, y)\,dA = \lim\sum_{i,j}f(x_i, y_j)\,\Delta A.\]

\(f\)가 음수인 곳은 부피를 빼는 것으로 셉니다. 또 \(\frac{1}{\text{넓이}(R)}\iint_Rf\,dA\)는 \(R\)에서 \(f\)의 평균값입니다.

6.1.2반복적분

정의대로 계산하기는 어렵습니다. 대신 공통1 6.1절의 "단면의 넓이를 적분하면 부피"를 씁니다. \(x\)를 고정하고 자른 단면의 넓이는 \(A(x) = \int_c^df(x, y)\,dy\)이고, 이것을 \(x\)에 대해 적분하면 부피입니다.

정리 6.1.1 (푸비니 정리)

\(f\)가 \(R = [a, b]\times[c, d]\)에서 연속이면

\[\iint_Rf\,dA = \int_a^b\left(\int_c^df(x, y)\,dy\right)dx = \int_c^d\left(\int_a^bf(x, y)\,dx\right)dy.\]

안쪽 적분을 할 때는 바깥 변수를 상수로 봅니다(편미분의 반대). 어느 순서로 해도 같으므로 계산이 쉬운 쪽을 고릅니다.

예제 6.1.2

\(R = [0, 2]\times[1, 2]\)에서 \(\iint_R(x - 3y^2)\,dA\)를 구하여라.

풀이. 먼저 \(x\)로: \(\int_0^2(x - 3y^2)\,dx = 2 - 6y^2\). 다음 \(y\)로: \(\int_1^2(2 - 6y^2)\,dy = 2 - 2(8 - 1) = -12\). 순서를 바꿔 계산해도 \(-12\)입니다.

\(f(x, y) = g(x)h(y)\)처럼 나뉘면 \(\iint_Rf\,dA = \int_a^bg(x)\,dx\cdot\int_c^dh(y)\,dy\)로 따로 계산할 수 있습니다.

예제 6.1.3

\(R = [0, \frac\pi2]\times[0, \frac\pi2]\)에서 \(\iint_R\sin x\cos y\,dA\)는?

풀이. \(\int_0^{\pi/2}\sin x\,dx\cdot\int_0^{\pi/2}\cos y\,dy = 1\cdot1 = 1\).

요약
  1. 이중적분 = 곡면 아래 (부호 있는) 부피.
  2. 직사각형에서는 어느 순서의 반복적분으로든 계산한다.

6.1.3연습문제

기본

  1. \(\int_0^1\int_0^2(x + y)\,dy\,dx\)는?
    답

    안쪽 \(2x + 2\), 바깥 \(1 + 2 = 3\).

  2. \(R = [0, 1]\times[0, 1]\)에서 \(f = xy\)의 평균값은?
    답

    \(\frac12\cdot\frac12 = \frac14\).
