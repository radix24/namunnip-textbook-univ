벡터함수와 공간곡선

본문

원을 돌면서 동시에 위로 올라가는 점은 어떤 곡선을 그릴까? 평면의 매개변수 곡선을 공간으로 넓히면, 움직이는 점의 위치를 하나의 함수로 쓸 수 있을까?

먼저 알아야 할 것매개변수 곡선(미분적분학(1) 7.1절)과 공간의 직선(1.2절)을 쓴다.

3.1.1벡터함수

실수 \(t\)마다 벡터 하나를 대응시키는 함수 \(\mathbf r(t) = \langle f(t), g(t), h(t)\rangle\)를 벡터함수라 한다. \(t\)를 시간으로 보면, 끝점 \((f(t), g(t), h(t))\)가 움직이며 그리는 자취가 공간곡선이다. 즉 미분적분학(1) 7.1절의 매개변수 곡선에 성분 하나를 더해 3차원으로 넓힌 것이다. 1.2절의 직선 \(\mathbf r(t) = \mathbf r_0 + t\mathbf v\)도 가장 단순한 벡터함수이다.

예제 3.1.1

\(\mathbf r(t) = \langle\cos t, \sin t, t\rangle\)이 그리는 곡선을 설명하여라.

풀이. \(x^2 + y^2 = \cos^2t + \sin^2t = 1\)이므로 점은 원기둥 위에 있다. \(t\)가 늘면 \((x, y)\)는 원을 돌고, 높이 \(z = t\)는 계속 올라간다. 따라서 용수철 모양의 나선이며, 한 바퀴(\(t\)가 \(2\pi\) 증가)에 \(2\pi\)만큼 올라간다. 그림 1에서 \(t\)를 0부터 12.5까지 움직이면 두 바퀴를 돈다. DNA의 이중 나선이 이런 모양이다.

예제 3.1.2

원기둥 \(x^2 + y^2 = 1\)과 평면 \(y + z = 2\)가 만나는 곡선을 벡터함수로 나타내어라.

풀이. 교선 위의 점은 두 식을 모두 만족해야 한다. 원기둥 위에서는 \(x = \cos t\), \(y = \sin t\)로 놓을 수 있고, 평면의 식에서 \(z = 2 - y = 2 - \sin t\)이다. 따라서 \(\mathbf r(t) = \langle\cos t, \sin t, 2 - \sin t\rangle\), \(0 \le t \le 2\pi\)이다. 비스듬히 잘린 원기둥의 단면이므로 이 곡선은 타원이다. 일반적으로 두 곡면의 교선은 한 곡면을 매개변수로 나타내고 다른 식에 대입해 구한다. 어느 곡면을 매개화할지는 매개화가 쉬운 쪽을 고르면 되는데, 원기둥은 각 하나로, 평면은 두 변수로 쓸 수 있으므로 원기둥을 먼저 매개화하는 편이 간단하다. 평면을 먼저 매개화하면 원기둥의 식을 풀 때 근호가 나와 곡선을 둘로 나누어 써야 한다.

3.1.2극한과 연속

벡터함수의 극한은 성분마다 극한을 구한 것이다. 벡터의 거리가 성분의 차로 정해지므로, 성분이 모두 다가가면 벡터도 다가가고 그 역도 성립하기 때문이다.

\[\lim_{t\to a}\mathbf r(t) = \left\langle\lim_{t\to a}f(t), \lim_{t\to a}g(t), \lim_{t\to a}h(t)\right\rangle\]

또 \(\lim_{t\to a}\mathbf r(t) = \mathbf r(a)\)이면 \(\mathbf r\)은 \(a\)에서 연속이라 하며, 성분이 모두 연속이면 된다. 연속인 벡터함수가 그리는 곡선은 끊어지지 않는다. 반대로 성분 하나만 끊어져도 점이 순간이동하므로 곡선이 끊긴다.

예제 3.1.3

\(\displaystyle\lim_{t\to0}\left\langle1 + t^3, te^{-t}, \frac{\sin t}{t}\right\rangle\)을 구하여라.

풀이. 성분별로 구하면 \(1\), \(0\), \(1\)이다. 셋째 성분 \(\frac{\sin t}{t} \to 1\)은 미분적분학(1) 1단원의 극한이다. 따라서 답은 \(\langle1, 0, 1\rangle\)이다.

마무리

벡터함수 \(\mathbf r(t) = \langle f, g, h\rangle\)는 시간에 따라 움직이는 점의 위치이고, 그 자취가 공간곡선이다. 그래서 처음 질문처럼 원을 돌며 올라가는 점은 \(\langle\cos t, \sin t, t\rangle\)라는 나선을 그린다. 극한과 연속은 성분별로 따지며, 두 곡면의 교선은 한 곡면을 매개화하고 다른 식에 대입해 구한다.

3.1.3연습문제

기본

  1. \(\mathbf r(t) = \langle t, t^2, t^3\rangle\)은 \(t = 2\)에서 어느 점을 지나는가?
    답

    \((2, 4, 8)\).

  2. \(\mathbf r(t) = \langle1 + t, 2 - t, 3t\rangle\)은 어떤 곡선인가?
    답

    점 \((1, 2, 0)\)을 지나고 방향 \(\langle1, -1, 3\rangle\)인 직선.

응용

  1. 원뿔 \(z = \sqrt{x^2 + y^2}\)과 평면 \(z = 1 + y\)의 교선을 매개화하여라.
    답

    제곱하면 \(x^2 + y^2 = (1 + y)^2\), \(y = \frac{x^2 - 1}{2}\). \(x = t\), \(y = \frac{t^2 - 1}{2}\), \(z = \frac{t^2 + 1}{2}\).
