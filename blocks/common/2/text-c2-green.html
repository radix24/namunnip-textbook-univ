그린 정리

본문

닫힌 곡선을 따라 한 바퀴 도는 선적분은 경계를 따라가며 계산한다. 그런데 그 값을 경계 안쪽 영역의 정보만으로 구할 수 있다면 어떨까? 안쪽의 작은 소용돌이들을 모두 더하면 경계를 도는 양이 될까?

먼저 알아야 할 것선적분(7.2절)과 일반 영역의 이중적분(6.2절)을 쓴다.

7.4.1정리

닫힌 곡선 \(C\)의 양의 방향은 곡선을 따라 걸을 때 둘러싸인 영역이 왼쪽에 있는 방향, 곧 시계 반대 방향이다.

정리 7.4.1 (그린 정리)

\(C\)가 영역 \(D\)를 둘러싼 양의 방향 단순 닫힌 곡선이고 \(P, Q\)의 편도함수가 연속이면

\[\oint_CP\,dx + Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA.\]

오른쪽의 \(Q_x - P_y\)는 각 점에서 벡터장이 얼마나 소용돌이치는지를 나타낸다(7.5절의 회전). 아주 작은 정사각형 하나를 한 바퀴 돌면 선적분이 대략 \((Q_x - P_y)\times\)(넓이)이기 때문이다. 그림 1처럼 \(D\)를 작은 정사각형으로 나누어 모두 시계 반대 방향으로 돌면, 이웃한 두 정사각형이 함께 쓰는 변에서는 서로 반대 방향으로 지나가 선적분이 지워진다. 그러면 바깥 경계 \(C\)만 남는다. 처음 질문의 답이 이것이다. 안쪽 소용돌이를 모두 더하면 경계를 도는 양이 된다. 미적분의 기본정리처럼 "안쪽의 미분을 적분하면 경계의 값"이라는 구조이다.

예제 7.4.2

\(C\)가 \((0, 0)\), \((1, 0)\), \((0, 1)\)을 잇는 삼각형(양의 방향)일 때 \(\oint_Cx^4\,dx + xy\,dy\)를 구하여라.

풀이. \(P = x^4\), \(Q = xy\)이므로 \(Q_x - P_y = y - 0 = y\)이다. 따라서

\[\int_0^1\int_0^{1-x}y\,dy\,dx = \int_0^1\frac{(1 - x)^2}{2}dx = \frac16\]

이다. 세 변을 따로 매개화해 선적분 세 개를 더하는 것보다 훨씬 간단하다.

예제 7.4.3

원 \(x^2 + y^2 = 9\)에서 \(\oint_C(3y - e^{\sin x})\,dx + (7x + \sqrt{y^4 + 1})\,dy\)를 구하여라.

풀이. 이 선적분은 직접은 거의 계산할 수 없다. 그러나 \(Q_x - P_y = 7 - 3 = 4\)로 상수이므로, 이중적분은 4에 원의 넓이 \(9\pi\)를 곱한 \(36\pi\)이다. \(e^{\sin x}\)나 \(\sqrt{y^4 + 1}\)처럼 까다로운 부분은 편미분하면 사라진다는 것이 요점이다.

7.4.2넓이 공식

거꾸로 이중적분 쪽을 넓이로 만들 수도 있다. \(Q_x - P_y = 1\)이 되도록 \(P = -\frac y2\), \(Q = \frac x2\)를 고르면 다음을 얻는다.

\[\text{넓이}(D) = \frac12\oint_C(x\,dy - y\,dx)\]
예제 7.4.4

타원 \(x = a\cos t\), \(y = b\sin t\)의 넓이를 구하여라.

풀이. \(x\,dy - y\,dx = (ab\cos^2t + ab\sin^2t)\,dt = ab\,dt\)이므로 넓이는 \(\frac12\int_0^{2\pi}ab\,dt = \pi ab\)이다. 6.6절에서 야코비안으로 구한 값과 같다. 경계만 따라가며 넓이를 재는 기계인 구적기가 이 원리로 작동한다.

마무리

그린 정리 \(\oint_CP\,dx + Q\,dy = \iint_D(Q_x - P_y)\,dA\)는 경계를 시계 반대 방향으로 도는 선적분을 안쪽의 소용돌이 \(Q_x - P_y\)의 이중적분으로 바꾼다. 처음 질문처럼 영역을 잘게 나누어 각 조각을 돌면 안쪽 변은 지워지고 경계만 남기 때문이다. \(Q_x - P_y = 1\)이 되게 고르면 넓이 공식 \(\frac12\oint(x\,dy - y\,dx)\)를 얻는다.

7.4.3연습문제

기본

  1. 단위원에서 \(\oint(-y\,dx + x\,dy)\)를 그린 정리로 구하여라.
    답

    \(Q_x - P_y = 2\). \(2\pi\).

  2. 보존장의 닫힌 곡선 선적분이 0임을 그린 정리로 설명하여라.
    답

    \(P_y = Q_x\)이므로 피적분 함수가 0.
