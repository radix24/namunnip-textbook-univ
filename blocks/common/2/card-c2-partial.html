편도함수, 전미분, 접평면

한 변수만 움직이기 · 선형 근사 · 미분가능성

정의

편도함수: 다른 변수를 상수로 묶고 한 변수로만 미분합니다. \(f_x(a,b) = \lim_{h\to0}\frac{f(a+h, b) - f(a,b)}{h}\). 그래프를 평면 \(y = b\)로 자른 곡선의 기울기입니다.

미분가능: \(f(a+h, b+k) = f(a,b) + f_x h + f_y k + \varepsilon(h,k)\sqrt{h^2 + k^2}\), \(\varepsilon \to 0\). 곧 원점 근처에서 그래프가 한 평면(접평면)으로 잘 근사됩니다. 이 근사식의 일차 부분이 전미분 \(df = f_x\,dx + f_y\,dy\)입니다.

편도함수만 있으면 되나?

아닙니다. 4-01 카드의 \(f = \frac{xy}{x^2 + y^2}\) (\(f(0,0) = 0\))은 \(f(x, 0) = 0\), \(f(0, y) = 0\)이라 \(f_x(0,0) = f_y(0,0) = 0\)이지만 원점에서 연속도 아닙니다. 두 방향만 보는 편도함수로는 미분가능성을 알 수 없습니다.

충분조건 (증명은 해석학)

\(f_x, f_y\)가 \((a, b)\) 근처에서 존재하고 \((a,b)\)에서 연속이면 \(f\)는 \((a,b)\)에서 미분가능하다.

다항식, 지수, 삼각함수의 조합은 정의역 안에서 이 조건을 만족하므로 실제 계산에서는 대부분 미분가능합니다.

\(f(x,y) = \sqrt{20 - x^2 - 7y^2}\)에 대해 (가) 점 \((2, 1)\)에서의 접평면 (나) 이것으로 \(f(1.95, 1.08)\)을 근사하세요.

풀이

  1. \(f(2,1) = \sqrt{20 - 4 - 7} = 3\).
    접점의 높이.
  2. \(f_x = \dfrac{-x}{\sqrt{20 - x^2 - 7y^2}}\), \(f_y = \dfrac{-7y}{\sqrt{20 - x^2 - 7y^2}}\). \((2,1)\)에서 \(f_x = -\frac23\), \(f_y = -\frac73\).
    \(y\)를 상수로 보고 연쇄 법칙(\(x\)도 마찬가지).
  3. (가) 접평면 \(z = 3 - \frac23(x - 2) - \frac73(y - 1)\).
    \(z = f(a,b) + f_x(a,b)(x - a) + f_y(a,b)(y - b)\). 근방에서 편도함수가 연속이라 미분가능.
  4. (나) \(dx = -0.05\), \(dy = 0.08\): \(f \approx 3 - \frac23(-0.05) - \frac73(0.08) = 3 + 0.0333 - 0.1867 = 2.8467\).
    전미분 \(df = f_xdx + f_ydy\)로 변화량 근사.

검산

참값 \(\sqrt{20 - 3.8025 - 8.1648} = \sqrt{8.0327} \approx 2.8342\). 근삿값이 약 0.0125 큽니다. 그래프는 위로 볼록한 반타원체라 접평면이 그래프 위에 있고, 그래서 근삿값이 늘 큽니다. 오차는 변화량의 제곱에 비례하므로, \(dx, dy\)를 절반으로 줄이면 오차는 약 4분의 1이 됩니다. \(f_{yy}\)가 큰 방향(\(y\)의 계수 7)으로 움직인 탓에 오차가 눈에 띕니다.

오차 전파에 쓰기

원기둥 부피 \(V = \pi r^2h\)에서 \(r\), \(h\)를 각각 1%, 2% 오차로 재면 \(\frac{dV}{V} = 2\frac{dr}{r} + \frac{dh}{h}\)이므로 최대 약 4%. 전미분을 \(V\)로 나누면 상대오차의 식이 됩니다.
