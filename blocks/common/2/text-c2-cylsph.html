원기둥좌표와 구면좌표의 삼중적분

본문

구의 부피 \(\frac43\pi a^3\)을 직교좌표 삼중적분으로 구하려면 근호가 겹겹이 나온다. 지구 위의 위치를 위도와 경도로 말하듯이, 공간의 점을 거리와 두 각으로 나타내면 구에 관한 적분이 쉬워지지 않을까?

먼저 알아야 할 것극좌표 이중적분(6.3절)과 삼중적분(6.4절)을 쓴다.

6.5.1원기둥좌표

먼저 \(xy\)평면은 극좌표로 쓰고 높이는 그대로 \(z\)로 두는 방법이 있다. 즉 \(x = r\cos\theta\), \(y = r\sin\theta\), \(z = z\)이고, 이것을 원기둥좌표라 한다. 부피 요소는 극좌표의 넓이 요소에 높이 \(dz\)를 곱한 \(dV = r\,dz\,dr\,d\theta\)이다. 원기둥, 원뿔, 포물면처럼 \(z\)축을 둘러싼 대칭 입체에 쓴다.

예제 6.5.1

포물면 \(z = x^2 + y^2\)과 평면 \(z = 4\) 사이 입체의 부피를 구하여라.

풀이. 원기둥좌표에서 포물면은 \(z = r^2\)이므로 입체는 \(r^2 \le z \le 4\), \(0 \le r \le 2\)이다. 따라서

\[\int_0^{2\pi}\int_0^2\int_{r^2}^4r\,dz\,dr\,d\theta = 2\pi\int_0^2(4r - r^3)\,dr = 2\pi(8 - 4) = 8\pi\]

이다. 반지름 2, 높이 4인 원기둥의 부피 \(16\pi\)의 절반이다. 직교좌표로 같은 계산을 하면 바닥 원판의 범위에 근호가 들어가 적분이 훨씬 길어진다. 원기둥좌표에서는 입체의 옆면이 \(r = 2\), 바닥 곡면이 \(z = r^2\)처럼 한 변수의 식으로 쓰여서 범위를 바로 읽을 수 있다.

6.5.2구면좌표

이번에는 점 \(P\)를 세 수로 나타낸다. 원점에서의 거리 \(\rho \ge 0\), 원기둥좌표와 같은 수평 각 \(\theta\)(경도와 비슷), 양의 \(z\)축에서 내려온 각 \(\phi\) (\(0 \le \phi \le \pi\), 북극에서 잰 위도와 비슷)이다. 이것을 구면좌표라 한다. 그림 1에서 점을 \(z\)축에 \(\rho\cos\phi\)만큼 올리고, 수평으로는 반지름 \(\rho\sin\phi\)인 원 위에서 각 \(\theta\)만큼 돌리면 다음 식이 된다.

\[x = \rho\sin\phi\cos\theta, \quad y = \rho\sin\phi\sin\theta, \quad z = \rho\cos\phi\]

작은 조각은 거의 상자이고, 세 변은 \(d\rho\), \(\rho\,d\phi\), \(\rho\sin\phi\,d\theta\)이다. 마지막 변에 \(\sin\phi\)가 붙는 것은 수평 원의 반지름이 \(\rho\sin\phi\)이기 때문이다. 그림 1에서 \(\phi\)를 0이나 180°에 가깝게 하면 수평 원이 작아지는데, 극 근처에서는 같은 \(d\theta\)만큼 돌아도 움직이는 거리가 짧다는 뜻이다. 그러므로 부피 요소는 다음과 같다.

\[dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\]
예제 6.5.2

반지름 \(a\)인 구의 부피를 구하여라.

풀이. 구는 \(0 \le \rho \le a\), \(0 \le \phi \le \pi\), \(0 \le \theta \le 2\pi\)이므로 범위가 모두 상수이다. \(\int_0^{2\pi}\int_0^\pi\int_0^a\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = 2\pi\cdot2\cdot\frac{a^3}{3} = \frac43\pi a^3\)이다. 처음 질문의 근호 대신, 세 적분이 따로 떨어져 한 줄로 끝났다.

예제 6.5.3

원뿔 \(\phi = \frac\pi4\) 안쪽, 단위구 안쪽에 있는 입체(아이스크림 모양)의 부피를 구하여라.

풀이. 범위는 \(0 \le \rho \le 1\), \(0 \le \phi \le \frac\pi4\)이므로 다음과 같다.

\[2\pi\cdot\frac13\cdot\left[-\cos\phi\right]_0^{\pi/4} = \frac{2\pi}{3}\left(1 - \frac{\sqrt2}{2}\right) \approx 0.613\]

단위구 전체의 부피 약 4.19와 비교하면 약 15%이다. 구 위쪽 꼭대기에서 위로 45° 안쪽만 잘라 낸 모양이니 그럴듯하다.

마무리

\(z\)축을 둘러싼 대칭 입체는 원기둥좌표로, 부피 요소 \(dV = r\,dz\,dr\,d\theta\)를 써서 적분한다. 처음 질문처럼 구나 원뿔에 관한 적분은 거리와 두 각으로 점을 나타내는 구면좌표로 바꾸면 범위가 상수가 되고, 부피 요소는 \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)이다.

6.5.3연습문제

기본

  1. 점 \((0, 0, 2)\)의 구면좌표는?
    답

    \(\rho = 2\), \(\phi = 0\) (\(\theta\)는 아무 값).

  2. 반지름 1, 높이 2인 원기둥의 부피를 원기둥좌표로 구하여라.
    답

    \(\int_0^{2\pi}\int_0^1\int_0^2r\,dz\,dr\,d\theta = 2\pi\).

응용

  1. 단위구 안에서 \(\iiint(x^2 + y^2 + z^2)\,dV\)는?
    답

    \(\int\int\int\rho^4\sin\phi = 2\pi\cdot2\cdot\frac15 = \frac{4\pi}{5}\).
