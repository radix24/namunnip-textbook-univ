곡선의 길이와 곡률

본문
이 절에서 배울 것
  • 공간곡선의 길이를 적분으로 구한다.
  • 곡선이 얼마나 급히 휘는지를 곡률로 나타내고, 가속도를 접선·법선 성분으로 나눈다.
먼저 알아야 할 것
  • 평면곡선의 길이 (공통1 6.3절), 접선벡터와 속력 (3.2절), 외적 (1.1절).

3.3.1곡선의 길이

속력을 시간에 대해 적분하면 움직인 거리입니다.

\[L = \int_a^b|\mathbf r'(t)|\,dt = \int_a^b\sqrt{f'(t)^2 + g'(t)^2 + h'(t)^2}\,dt.\]
예제 3.3.1

나선 \(\langle\cos t, \sin t, t\rangle\)의 한 바퀴(\(0 \le t \le 2\pi\)) 길이는?

풀이. 속력이 \(\sqrt2\)로 일정하므로 \(L = 2\pi\sqrt2\). 원기둥을 펼치면 나선은 밑변 \(2\pi\), 높이 \(2\pi\)인 직각삼각형의 빗변이 되므로 같은 답입니다.

3.3.2곡률

곡선이 얼마나 급히 휘는지는 "단위 길이를 갈 때 진행 방향 \(\mathbf T\)가 얼마나 빨리 바뀌는가"로 잽니다. 직선은 방향이 안 바뀌므로 0, 작은 원은 크게 바뀝니다.

정의 3.3.2 (곡률) \[\kappa = \left|\frac{d\mathbf T}{ds}\right| = \frac{|\mathbf T'(t)|}{|\mathbf r'(t)|}\quad(s\text{는 곡선의 길이}).\]

계산에는 다음 공식이 편리합니다.

정리 3.3.3 \[\kappa = \frac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|^3}, \qquad \text{평면곡선}\ y = f(x)\text{이면}\ \kappa = \frac{|f''(x)|}{(1 + f'(x)^2)^{3/2}}.\]
예제 3.3.4

(가) 반지름 \(a\)인 원 (나) 나선 \(\langle\cos t, \sin t, t\rangle\) (다) \(y = x^2\)의 원점에서 곡률을 구하여라.

풀이. (가) \(\mathbf r = \langle a\cos t, a\sin t, 0\rangle\), \(|\mathbf r'| = a\), \(\mathbf T = \langle-\sin t, \cos t, 0\rangle\), \(|\mathbf T'| = 1\). \(\kappa = \frac1a\). 작은 원일수록 많이 휩니다.

(나) \(\mathbf r' = \langle-\sin t, \cos t, 1\rangle\), \(\mathbf r'' = \langle-\cos t, -\sin t, 0\rangle\), \(\mathbf r'\times\mathbf r'' = \langle\sin t, -\cos t, 1\rangle\), 크기 \(\sqrt2\). \(\kappa = \frac{\sqrt2}{(\sqrt2)^3} = \frac12\).

(다) \(f' = 0\), \(f'' = 2\)이므로 \(\kappa = 2\). 원점 근처에서 반지름 \(\frac12\)인 원처럼 휩니다.

3.3.3가속도의 두 성분

\(\mathbf T\)가 바뀌는 방향의 단위벡터 \(\mathbf N = \frac{\mathbf T'}{|\mathbf T'|}\)를 주법선벡터라 합니다. 속력을 \(v\)라 하면 가속도는 다음처럼 나뉩니다.

\[\mathbf a = v'\,\mathbf T + \kappa v^2\,\mathbf N.\]

앞 항은 속력의 변화(가속 페달), 뒤 항은 방향의 변화(핸들)입니다. 같은 커브를 두 배 빠르게 돌면 옆으로 받는 가속도가 네 배가 되는 이유가 \(v^2\)에 있습니다. 원운동에서는 \(\kappa = \frac1r\)이므로 \(\frac{v^2}{r}\), 물리의 구심가속도입니다.

요약
  1. \(L = \int|\mathbf r'|\,dt\).
  2. \(\kappa = |\mathbf r'\times\mathbf r''|/|\mathbf r'|^3\). 원은 \(1/a\).
  3. \(\mathbf a = v'\mathbf T + \kappa v^2\mathbf N\).

3.3.4연습문제

기본

  1. \(\mathbf r(t) = \langle2t, t^2, \frac13t^3\rangle\), \(0 \le t \le 1\)의 길이는? (힌트: \(|\mathbf r'| = 2 + t^2\))
    답

    \(\int_0^1(2 + t^2)dt = \frac73\).

  2. 직선의 곡률은?
    답

    \(\mathbf T\)가 일정하므로 0.

응용

  1. \(y = \sin x\)의 \(x = \frac\pi2\)에서 곡률은?
    답

    \(f' = 0\), \(f'' = -1\). \(\kappa = 1\).
