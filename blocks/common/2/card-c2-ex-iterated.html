직사각형 위의 이중적분은 순서를 바꿔도 같을까?

예제 · 반복적분과 푸비니 정리

\(R = [0, 2]\times[1, 3]\)에서 \(\displaystyle\iint_R(x + 2y)\,dA\)를 두 가지 순서로 계산하세요.

전략

직사각형 영역에서 연속인 함수는 \(y\)로 먼저 적분하든 \(x\)로 먼저 적분하든 결과가 같습니다(푸비니 정리). 안쪽 적분에서는 다른 변수를 상수로 봅니다.

풀이

  1. \(y\) 먼저: \(\displaystyle\int_1^3(x + 2y)\,dy = \left[xy + y^2\right]_{y=1}^{3} = (3x + 9) - (x + 1) = 2x + 8\).
    \(x\)는 상수로 봄.
  2. \(\displaystyle\int_0^2(2x + 8)\,dx = \left[x^2 + 8x\right]_0^2 = 20\).
    바깥 적분.
  3. \(x\) 먼저: \(\displaystyle\int_0^2(x + 2y)\,dx = 2 + 4y\), \(\displaystyle\int_1^3(2 + 4y)\,dy = 4 + 16 = 20\).
    순서를 바꿔도 같은 값(푸비니).

의미

이중적분은 밑면 \(R\) 위에서 높이 \(x + 2y\)인 입체의 부피입니다. 20을 넓이 4로 나눈 5가 함수의 평균값이고, 일차함수라서 중심 \((1, 2)\)에서의 값 \(1 + 4 = 5\)와 같습니다.

검산

두 순서의 결과가 같고, 평균값이 중심의 함숫값과 같으므로 맞습니다.

바꿔 보기

영역이 직사각형이 아니면 안쪽 적분의 끝이 바깥 변수의 함수가 됩니다(6.2절). 순서를 바꾸면 경계를 다시 써야 합니다.

이해 확인

\(\displaystyle\iint_{[0,1]\times[0,1]}xy\,dA\)와 \(\displaystyle\iint_{[0,\pi]\times[0,1]}y\sin x\,dA\)를 구하세요.

답

\(\tfrac12\cdot\tfrac12 = \tfrac14\). \(\int_0^\pi\sin x\,dx\cdot\int_0^1y\,dy = 2\cdot\tfrac12 = 1\). 곱으로 나뉘는 함수는 두 일변수 적분의 곱입니다.
