매개곡면의 넓이와 스칼라 면적분

r(u,v) · dS = |r_u × r_v| du dv

넓이 요소

곡면을 \(\mathbf r(u, v)\), \((u, v) \in D\)로 매개화합니다. \(uv\)평면의 작은 직사각형 \(\Delta u\times\Delta v\)는 곡면 위에서 거의 평행사변형이 되고, 두 변은 \(\mathbf r_u\Delta u\), \(\mathbf r_v\Delta v\)입니다(6-03 카드와 같은 선형 근사). 넓이는 외적의 크기(1-02 카드):

\[dS = |\mathbf r_u\times\mathbf r_v|\,du\,dv, \qquad \text{넓이} = \iint_D|\mathbf r_u\times\mathbf r_v|\,du\,dv, \qquad \iint_Sf\,dS = \iint_Df(\mathbf r(u,v))|\mathbf r_u\times\mathbf r_v|\,du\,dv.\]

그래프 \(z = g(x,y)\)이면 \(\mathbf r = (x, y, g)\), \(\mathbf r_x\times\mathbf r_y = (-g_x, -g_y, 1)\), \(dS = \sqrt{1 + g_x^2 + g_y^2}\,dA\). 공통1의 곡선 길이 \(\sqrt{1 + f'^2}\,dx\)의 2차원판입니다.

(가) 반지름 \(a\)인 구면의 넓이를 매개화로 구하세요. (나) 포물면 \(z = x^2 + y^2\)의 \(z \le 4\) 부분의 넓이 (다) 위반구면 \(x^2 + y^2 + z^2 = a^2\), \(z \ge 0\)에서 \(\iint z\,dS\).

풀이

  1. (가) \(\mathbf r(\varphi, \theta) = (a\sin\varphi\cos\theta, a\sin\varphi\sin\theta, a\cos\varphi)\), \(0 \le \varphi \le \pi\), \(0 \le \theta \le 2\pi\).
    구면좌표에서 \(\rho = a\)로 고정.
  2. \(\mathbf r_\varphi\times\mathbf r_\theta = a^2\sin\varphi\,(\sin\varphi\cos\theta, \sin\varphi\sin\theta, \cos\varphi)\), 크기 \(a^2\sin\varphi\).
    괄호 속은 단위벡터(바깥 법선 방향). \(0 \le \varphi \le \pi\)라 \(\sin\varphi \ge 0\).
  3. 넓이 \(\int_0^{2\pi}\int_0^\pi a^2\sin\varphi\,d\varphi\,d\theta = 4\pi a^2\).
    공통1 7-02에서 회전면으로 구한 값과 같다.
  4. (나) \(dS = \sqrt{1 + 4x^2 + 4y^2}\,dA = \sqrt{1 + 4r^2}\,r\,dr\,d\theta\), \(0 \le r \le 2\).
    그래프 공식 후 극좌표.
  5. \(2\pi\int_0^2\sqrt{1 + 4r^2}\,r\,dr = 2\pi\cdot\frac{1}{12}\left[(1 + 4r^2)^{3/2}\right]_0^2 = \frac{\pi}{6}(17\sqrt{17} - 1)\).
    \(u = 1 + 4r^2\), \(du = 8r\,dr\).
  6. (다) \(z = a\cos\varphi\), \(dS = a^2\sin\varphi\,d\varphi\,d\theta\), \(0 \le \varphi \le \frac\pi2\): \(\int_0^{2\pi}\int_0^{\pi/2}a^3\cos\varphi\sin\varphi\,d\varphi\,d\theta = 2\pi a^3\cdot\frac12 = \pi a^3\).
    반구 껍질의 무게중심 높이 = \(\frac{\pi a^3}{2\pi a^2} = \frac a2\).

의미

\(dS = |\mathbf r_u\times\mathbf r_v|\,du\,dv\)는 곡선 길이 \(ds = |\mathbf r'|\,dt\)를 한 차원 올린 것입니다. 구의 겉넓이 \(4\pi a^2\)이 대원 넓이의 정확히 4배라는 것은 아르키메데스가 처음 보였습니다.

검산

(나) \(\frac\pi6(17\sqrt{17} - 1) \approx 36.2\). 밑면 원판 넓이 \(4\pi \approx 12.6\)보다 크고, 경사가 가장 급한 가장자리(\(\sqrt{17} \approx 4.1\)배)를 원판 전체에 곱한 \(51.8\)보다 작습니다. (다) 반구 껍질의 무게중심이 높이의 절반이라는 것은 아르키메데스의 "구면 띠의 넓이는 높이에 비례" 정리와 같습니다.

흔한 오해

  • \(dS = du\,dv\): 외적의 크기를 꼭 곱합니다.
  • \(dS\)와 \(dV\) 혼동: 구면의 \(dS = a^2\sin\varphi\,d\varphi\,d\theta\)는 공의 \(dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\)에서 \(d\rho\)를 뗀 것입니다.
