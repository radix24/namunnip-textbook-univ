용수철 모양의 곡선은 식으로 어떻게 쓸까?

탐구 · 벡터함수와 공간곡선

질문

원을 그리며 위로 일정하게 올라가는 점의 자취가 나선(헬릭스)입니다. DNA, 용수철, 나사가 이 모양입니다. 시각 \(t\)마다 점의 위치를 벡터 \(\mathbf r(t)\)로 주면, 미분으로 속도를, 적분으로 길이를 구할 수 있습니다.

복원

  • \(\mathbf r(t) = \langle\cos t, \sin t, ct\rangle\). 앞의 두 성분은 반지름 1인 원을, 셋째 성분은 일정하게 올라가는 높이를 줍니다.
  • 그림은 비스듬히 본 것입니다. x축은 앞쪽(왼쪽 아래), y축은 오른쪽, z축은 위쪽 점선입니다. 진한 부분이 0부터 \(t\)까지 지나온 자취, 주황 화살표가 속도 \(\mathbf r'(t)\)입니다.

설명

성분마다 미분하면 \(\mathbf r'(t) = \langle-\sin t, \cos t, c\rangle\)이고 속력은 \(\sqrt{\sin^2t + \cos^2t + c^2} = \sqrt{1 + c^2}\)로 일정합니다. 그래서 길이는 \(L = \int_0^t\sqrt{1 + c^2}\,du = t\sqrt{1 + c^2}\)입니다. \(c = 0.5\)이면 한 바퀴(\(t = 2\pi\))의 길이는 \(2\pi\sqrt{1.25} = 7.0248\)로, 원 둘레 \(2\pi = 6.28\)보다 깁니다. 곡률 \(\kappa = \dfrac1{1 + c^2} = 0.8\)은 원(곡률 1)보다 작습니다. 위로 늘인 만큼 덜 휘어 있기 때문입니다.

연결

공통1의 매개변수 곡선(공통1 7.1절)에 성분 하나를 더한 것입니다. 자기장 속에서 속도가 자기장에 비스듬한 전하는 나선 운동을 합니다(공통4 6.1절).

적용

\(c = 0\)으로 놓으면 무엇이 되나요? 그때 속력, 길이, 곡률을 출력으로 확인해 보세요.
