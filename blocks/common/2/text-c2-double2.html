일반 영역의 이중적분과 적분 순서 바꾸기

본문
이 절에서 배울 것
  • 곡선으로 둘러싸인 영역에서 적분 범위를 정해 이중적분을 계산한다.
  • 적분 순서를 바꾸어 계산할 수 없던 적분을 계산한다.
먼저 알아야 할 것
  • 반복적분 (6.1절), 두 곡선 사이의 넓이 (고교 미적분).

6.2.1두 가지 영역

영역이 직사각형이 아니면 안쪽 적분의 범위가 바깥 변수에 따라 달라집니다.

  • 세로로 자르기: \(D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_a^b\int_{g_1(x)}^{g_2(x)}f\,dy\,dx\).
  • 가로로 자르기: \(D = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_c^d\int_{h_1(y)}^{h_2(y)}f\,dx\,dy\).

범위를 정하는 요령: 영역을 그리고, 바깥 변수를 하나 고정한 선(세로선 또는 가로선)이 영역에 들어가는 곳과 나오는 곳을 읽습니다. \(f = 1\)이면 \(\iint_D1\,dA\)는 \(D\)의 넓이로, 고교의 "두 곡선 사이의 넓이"와 같습니다.

예제 6.2.1

\(D\)가 포물선 \(y = 2x^2\)과 \(y = 1 + x^2\)으로 둘러싸인 영역일 때 \(\iint_D(x + 2y)\,dA\)를 구하여라.

풀이. 교점: \(2x^2 = 1 + x^2\), \(x = \pm1\). \(-1 \le x \le 1\)에서 아래가 \(2x^2\), 위가 \(1 + x^2\)입니다.

\[\int_{-1}^1\left[xy + y^2\right]_{y=2x^2}^{y=1+x^2}dx = \int_{-1}^1(-3x^4 - x^3 + 2x^2 + x + 1)\,dx.\]

홀수 차수 항은 대칭 구간에서 0이므로 \(-\frac65 + \frac43 + 2 = \frac{32}{15}\).

6.2.2적분 순서 바꾸기

예제 6.2.2

\(\displaystyle\int_0^1\int_x^1\sin(y^2)\,dy\,dx\)를 구하여라.

풀이. \(\sin(y^2)\)의 부정적분은 기본 함수로 쓸 수 없어서 이 순서로는 계산할 수 없습니다. 영역은 \(0 \le x \le 1\), \(x \le y \le 1\): 꼭짓점이 \((0, 0)\), \((0, 1)\), \((1, 1)\)인 삼각형입니다. 가로로 자르면 \(0 \le y \le 1\), \(0 \le x \le y\)입니다.

\[\int_0^1\int_0^y\sin(y^2)\,dx\,dy = \int_0^1y\sin(y^2)\,dy = \left[-\frac12\cos(y^2)\right]_0^1 = \frac{1 - \cos1}{2}.\]

같은 영역을 다르게 잘랐을 뿐인데 계산이 가능해졌습니다. 순서를 바꿀 때는 반드시 영역을 그려서 범위를 새로 읽어야 합니다.

요약
  1. 안쪽 범위는 바깥 변수의 함수. 영역을 그려 읽는다.
  2. 계산이 막히면 순서를 바꾼다.

6.2.3연습문제

기본

  1. \(y = x\)와 \(y = x^2\)으로 둘러싸인 영역의 넓이를 이중적분으로 구하여라.
    답

    \(\int_0^1\int_{x^2}^x1\,dy\,dx = \frac12 - \frac13 = \frac16\).

응용

  1. \(\displaystyle\int_0^1\int_{\sqrt y}^1e^{x^3}\,dx\,dy\)의 순서를 바꾸어 계산하여라.
    답

    영역 \(0 \le x \le 1\), \(0 \le y \le x^2\). \(\int_0^1x^2e^{x^3}dx = \frac{e - 1}{3}\).
