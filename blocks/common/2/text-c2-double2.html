일반 영역의 이중적분과 적분 순서 바꾸기

본문

\(\int_0^1\int_x^1\sin(y^2)\,dy\,dx\)는 안쪽 적분부터 막힌다. \(\sin(y^2)\)의 부정적분을 기본 함수로 쓸 수 없기 때문이다. 같은 영역을 다른 방향으로 잘라 적분하면 이 막힌 계산이 풀릴 수 있을까?

먼저 알아야 할 것반복적분(6.1절)과 고교 미적분의 두 곡선 사이의 넓이를 쓴다.

6.2.1두 가지 영역

영역이 직사각형이 아니면 안쪽 적분의 범위가 바깥 변수에 따라 달라진다. 세로로 자르는 경우 \(D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_a^b\int_{g_1(x)}^{g_2(x)}f\,dy\,dx\)이다. 가로로 자르는 경우 \(D = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_c^d\int_{h_1(y)}^{h_2(y)}f\,dx\,dy\)이다.

범위는 영역을 그려서 읽는다. 바깥 변수를 하나 고정한 선, 곧 세로선이나 가로선이 영역에 들어가는 곳과 나오는 곳이 안쪽 적분의 범위이다. 특히 \(f = 1\)이면 \(\iint_D1\,dA\)는 \(D\)의 넓이로, 고교의 "두 곡선 사이의 넓이"와 같다.

예제 6.2.1

\(D\)가 포물선 \(y = 2x^2\)과 \(y = 1 + x^2\)으로 둘러싸인 영역일 때 \(\iint_D(x + 2y)\,dA\)를 구하여라.

풀이. 교점은 \(2x^2 = 1 + x^2\)에서 \(x = \pm1\)이다. \(-1 \le x \le 1\)에서 세로선을 그으면 아래가 \(2x^2\), 위가 \(1 + x^2\)이므로 다음과 같다.

\[\int_{-1}^1\left[xy + y^2\right]_{y=2x^2}^{y=1+x^2}dx = \int_{-1}^1(-3x^4 - x^3 + 2x^2 + x + 1)\,dx\]

홀수 차수 항은 대칭 구간에서 0이므로 값은 \(-\frac65 + \frac43 + 2 = \frac{32}{15}\)이다.

6.2.2적분 순서 바꾸기

예제 6.2.2

\(\displaystyle\int_0^1\int_x^1\sin(y^2)\,dy\,dx\)를 구하여라.

풀이. 처음 질문처럼 이 순서로는 계산할 수 없다. 그래서 먼저 범위에서 영역을 읽는다. \(0 \le x \le 1\), \(x \le y \le 1\)이므로 꼭짓점이 \((0, 0)\), \((0, 1)\), \((1, 1)\)인 삼각형이다. 그림 1에서 자르는 방향을 가로로 바꾸면, \(y\)를 고정한 가로선은 \(x = 0\)에서 들어가 \(x = y\)에서 나온다. 따라서 \(0 \le y \le 1\), \(0 \le x \le y\)이고 다음과 같다.

\[\int_0^1\int_0^y\sin(y^2)\,dx\,dy = \int_0^1y\sin(y^2)\,dy = \left[-\frac12\cos(y^2)\right]_0^1 = \frac{1 - \cos1}{2}\]

값은 약 0.230이다. 같은 영역을 다르게 잘랐을 뿐인데, 안쪽 적분이 \(x\)에 대한 것이 되면서 \(\sin(y^2)\)이 상수로 취급되었고 그 결과 \(y\)가 하나 곱해졌다. 바로 그 \(y\) 덕분에 바깥 적분이 치환으로 풀렸다. 다만 순서를 바꿀 때는 반드시 영역을 그려서 범위를 새로 읽어야 한다. 범위의 문자만 맞바꾸면 틀린다.

마무리

직사각형이 아닌 영역에서는 바깥 변수를 고정한 선이 영역에 들어가고 나오는 곳이 안쪽 적분의 범위가 되므로, 영역을 그려서 범위를 읽는다. 같은 영역을 세로로 자를 수도 가로로 자를 수도 있으며, 처음 질문의 막힌 적분은 순서를 바꾸면 \(\frac{1 - \cos1}{2}\)로 풀린다.

6.2.3연습문제

기본

  1. \(y = x\)와 \(y = x^2\)으로 둘러싸인 영역의 넓이를 이중적분으로 구하여라.
    답

    \(\int_0^1\int_{x^2}^x1\,dy\,dx = \frac12 - \frac13 = \frac16\).

응용

  1. \(\displaystyle\int_0^1\int_{\sqrt y}^1e^{x^3}\,dx\,dy\)의 순서를 바꾸어 계산하여라.
    답

    영역 \(0 \le x \le 1\), \(0 \le y \le x^2\). \(\int_0^1x^2e^{x^3}dx = \frac{e - 1}{3}\).
