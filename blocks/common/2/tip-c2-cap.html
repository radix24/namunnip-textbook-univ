열린 곡면의 선속은 뚜껑을 덮어 발산 정리로 구한 뒤 뚜껑을 뺀다

요령 · 발산 정리

언제 쓰는가

반구면이나 포물면처럼 경계가 있는 곡면을 지나는 선속을 묻는데, 곡면의 매개화는 번거롭고 \(\nabla\cdot\mathbf F\)는 간단할 때입니다.

요령

  1. 닫히지 않았음을 확인
    발산 정리는 닫힌 곡면에만 씁니다. 곡면에 가장자리가 있으면 그대로는 쓸 수 없습니다.
  2. 평평한 뚜껑을 덮는다
    가장자리를 원판 같은 평면 조각으로 막아 닫힌 곡면을 만듭니다.
  3. 전체 선속은 발산의 적분
    닫힌 곡면 전체를 바깥으로 지나는 선속은 \(\iiint_E\nabla\cdot\mathbf F\,dV\)입니다.
  4. 뚜껑의 선속을 따로
    뚜껑에서 바깥쪽 법선(원판이 아래에 있으면 \(-\mathbf k\))을 써서 선속을 계산합니다.
  5. 빼기
    구하는 선속 = 전체 − 뚜껑입니다. 뚜껑의 선속이 음수면 빼면서 더해집니다.

흔한 실수

  • 열린 곡면에 발산 정리를 그대로 써서 뚜껑의 선속까지 포함된 값을 답하는 것.
  • 뚜껑의 법선을 위쪽으로 잡는 것. 닫힌 곡면의 바깥쪽이어야 하므로 아래 뚜껑은 아래쪽입니다.

바로 풀어보기

\(\mathbf F = (x, y, z + 1)\)이 포물면 \(z = 1 - x^2 - y^2\), \(z \ge 0\)을 위쪽으로 지나는 선속을 구하세요.

답과 풀이

답: \(\frac{5\pi}{2} \approx 7.85\)

\(\nabla\cdot\mathbf F = 3\)이고, 포물면 아래 입체의 부피는 \(\int_0^{2\pi}\int_0^1(1 - r^2)\,r\,dr\,d\theta = \frac{\pi}{2}\)이므로 닫힌 곡면 전체의 선속은 \(\frac{3\pi}{2}\)입니다.

뚜껑은 \(z = 0\)의 단위 원판, 바깥 법선 \(-\mathbf k\)입니다. 그 위에서 \(\mathbf F\cdot(-\mathbf k) = -(0 + 1) = -1\)이므로 뚜껑의 선속은 \(-\pi\)입니다.

포물면의 선속은 \(\frac{3\pi}{2} - (-\pi) = \frac{5\pi}{2}\)입니다. 검산: 직접 계산하면 위쪽 법선 \((2x, 2y, 1)\,dA\)로 \(\iint(r^2 + 2)\,dA = 2\pi\left(\frac14 + 1\right) = \frac{5\pi}{2}\)입니다.

이 요령으로 풀리는 문제

  • 면적분과 스토크스·발산 정리 단원 연습 4번, 6번, 7번
영상 콘티 · 50초
  1. 0~6초그릇을 엎어 놓은 모양의 포물면 위로 벡터장 화살표가 흘러 지나갑니다.이 곡면을 지나는 선속은?
  2. 6~14초곡면 가장자리의 원이 빨갛게 빛나고 '열린 곡면'이라는 이름표가 붙습니다. 발산 정리 아이콘에 금지 표시가 뜹니다.가장자리가 있으면 발산 정리를 바로 쓸 수 없습니다.
  3. 14~22초아래에서 원판 뚜껑이 미끄러져 들어와 가장자리를 막고, 입체 안이 반투명하게 채워집니다.평평한 뚜껑을 덮어 닫습니다.
  4. 22~32초입체 안의 작은 점마다 '+3' 숫자가 솟아나 모두 합쳐지며 \(\frac{3\pi}{2}\)가 됩니다.닫히면 발산을 부피에 대해 더합니다.
  5. 32~42초뚜껑에서 아래쪽 법선 화살표가 나오고, 벡터장은 위로 들어가고 있어 뚜껑 선속에 \(-\pi\)가 붙습니다.뚜껑의 선속은 바깥 방향 기준으로 따로 구합니다.
  6. 42~50초\(\frac{3\pi}{2} - (-\pi)\) 식에서 뚜껑이 떨어져 나가고 포물면만 남으며 \(\frac{5\pi}{2}\)가 뜹니다.전체에서 뚜껑을 빼면 끝입니다.
