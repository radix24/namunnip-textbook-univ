벡터장의 선적분은 먼저 보존장인지부터 본다

요령 · 보존 벡터장

언제 쓰는가

\(\int_C\mathbf F\cdot d\mathbf r\)을 구하라는 문제에서 곡선의 매개화가 번거롭거나, 같은 두 점을 잇는 여러 경로가 나올 때이다.

요령

  1. 판정한다
    평면이면 \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\), 공간이면 \(\nabla\times\mathbf F = \mathbf 0\)인지 본다. 영역에 구멍(정의되지 않는 점)이 없는지도 함께 확인한다.
  2. 퍼텐셜을 찾는다
    \(P\)를 \(x\)로 적분하고 \(+\,g(y, z)\)를 붙인 뒤, \(y\)와 \(z\)로 미분해 \(Q\), \(R\)과 맞춰 \(g\)를 정한다.
  3. 끝점만 넣는다
    \(\int_C\mathbf F\cdot d\mathbf r = f(\text{끝}) - f(\text{시작})\)이다. 경로 모양은 상관없고, 닫힌 곡선이면 0이다.
  4. 아니면 매개화나 그린 정리
    보존장이 아니면 곡선을 매개화해 계산한다. 평면의 닫힌 곡선이면 그린 정리로 이중적분으로 바꾼다.

흔한 실수

  • 원점에서 정의되지 않는 \(\left(\frac{-y}{x^2 + y^2}, \frac{x}{x^2 + y^2}\right)\)처럼 구멍이 있는 영역에서 \(P_y = Q_x\)만 보고 닫힌 곡선의 선적분을 0이라 하는 것.
  • 퍼텐셜을 구할 때 적분 상수 자리의 \(g(y, z)\)를 빠뜨려 \(Q\)나 \(R\)과 맞지 않는 것.

바로 풀어보기

\(\mathbf F = (2xy + z^2,\ x^2 + 2yz,\ y^2 + 2xz)\)를 곡선 \(\mathbf r(t) = (t, t^2, t^3)\), \(0 \le t \le 1\)을 따라 선적분하여라.

답과 풀이

답: 3

\(\nabla\times\mathbf F = (2y - 2y,\ 2z - 2z,\ 2x - 2x) = \mathbf 0\)이고 \(\mathbf F\)는 공간 전체에서 정의되므로 보존장이다.

\(f = \int(2xy + z^2)\,dx = x^2y + xz^2 + g(y, z)\). \(f_y = x^2 + g_y = x^2 + 2yz\)에서 \(g = y^2z + h(z)\), \(f_z = 2xz + y^2 + h' = y^2 + 2xz\)에서 \(h' = 0\)이다. 따라서 \(f = x^2y + y^2z + xz^2\)이다.

시작점 \((0, 0, 0)\), 끝점 \((1, 1, 1)\)이므로 \(f(1, 1, 1) - f(0, 0, 0) = 3\)이다. 곡선을 매개화했다면 6차 다항식 적분을 해야 했다.

이 요령으로 풀리는 문제

  • 벡터장과 선적분 단원 연습 2번, 3번, 4번, 7번
영상 콘티 · 50초
  1. 0~6초공간의 화살표 벡터장 속을 곡선 \((t, t^2, t^3)\)이 휘어 지나간다.이 선적분, 매개화부터 해야 할까?
  2. 6~14초벡터장 위에 작은 바람개비들이 떠 있고, 모두 전혀 돌지 않는다. 옆에 \(\nabla\times\mathbf F = \mathbf 0\)이 뜬다.먼저 회전이 0인지 본다.
  3. 14~24초벡터장이 등고선 지도로 바뀌어, 화살표들이 등고선에 수직인 오르막 방향이었음이 드러난다. 지도에 \(f = x^2y + y^2z + xz^2\) 이름표가 붙는다.보존장은 어떤 높이 함수의 기울기이다.
  4. 24~34초시작점과 끝점에 높이 0과 3이 적힌 깃발이 서고, 그 사이를 잇는 서로 다른 곡선 세 개가 차례로 그려지는데 모두 같은 값 3을 낸다.끝점의 높이 차만 보면 된다.
  5. 34~42초닫힌 곡선이 한 바퀴 돌아 제자리로 오며 값 0이 찍힌다.닫힌 곡선이면 0이다.
  6. 42~50초원점에 구멍이 뚫린 평면 벡터장이 나오고, 구멍을 감싸는 원을 돌자 값 \(2\pi\)가 뜹니다. '\(P_y = Q_x\)인데 0이 아님' 경고가 깜박인다.구멍이 있으면 판정을 다시 본다.
