다변수 극값 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(f(x,y) = x^4 + y^4 - 4xy + 1\)의 임계점을 분류하여라. [05-01]

    힌트 1

    \(x^3 = y\), \(y^3 = x\)에서 \(x^9 = x\).

    힌트 2

    임계점 \((0,0), (1,1), (-1,-1)\). \(D = 144x^2y^2 - 16\).

    풀이

    \(f_x = 4x^3 - 4y\), \(f_y = 4y^3 - 4x\). \(x^9 = x\)의 실근 \(x = 0, \pm1\). \(f_{xx} = 12x^2\), \(f_{yy} = 12y^2\), \(f_{xy} = -4\).

    \((0,0)\): \(D = -16\), 안장점. \((\pm1, \pm1)\): \(D = 128 > 0\), \(f_{xx} = 12 > 0\), 극소 \(f = -1\).

  2. 계산점 \((1, 0, -2)\)에서 평면 \(x + 2y + z = 4\)까지의 최단 거리를 극값 문제로 구하고 거리 공식으로 검산하여라. [05-01]

    힌트 1

    \(z = 4 - x - 2y\)를 넣고 거리의 제곱 \(d^2(x,y)\)를 최소화.

    힌트 2

    \(d^2 = (x-1)^2 + y^2 + (6 - x - 2y)^2\).

    풀이

    \(\partial_x: 2(x - 1) - 2(6 - x - 2y) = 0\) → \(2x + 2y = 7\). \(\partial_y: 2y - 4(6 - x - 2y) = 0\) → \(4x + 10y = 24\). 풀면 \(x = \frac{11}{6}\), \(y = \frac53\). 그때 \(6 - x - 2y = \frac56\), \(d^2 = \frac{25}{36} + \frac{100}{36} + \frac{25}{36} = \frac{150}{36}\), \(d = \frac{5}{\sqrt6}\).

    거리 공식: \(\frac{|1 + 0 - 2 - 4|}{\sqrt6} = \frac{5}{\sqrt6}\). 일치.

  3. 계산삼각형 영역 (꼭짓점 \((0,0), (2,0), (0,2)\))에서 \(f(x,y) = x^2 + y^2 - x - y\)의 최댓값과 최솟값을 구하여라. [05-02]

    힌트 1

    내부 임계점 \(\left(\frac12, \frac12\right)\).

    힌트 2

    빗변 \(y = 2 - x\)에서 \(f = 2x^2 - 4x + 2\).

    풀이

    내부 \(f\left(\frac12, \frac12\right) = -\frac12\). 변 \(y = 0\): \(x^2 - x\), 최소 \(-\frac14\) (\(x = \frac12\)), 최대 2 (\(x = 2\)). 변 \(x = 0\): 같음. 빗변: \(2(x - 1)^2\), 최소 0, 최대 2 (끝점).

    최댓값 2 (\((2,0)\), \((0,2)\)), 최솟값 \(-\frac12\) (\(\left(\frac12,\frac12\right)\)).

  4. 계산원 \(x^2 + y^2 = 1\) 위에서 \(f = x + 2y\)의 최댓값과 최솟값을 Lagrange 승수법으로 구하여라. [05-03]

    힌트 1

    \(1 = 2\lambda x\), \(2 = 2\lambda y\) → \(y = 2x\).

    힌트 2

    \(x^2 + 4x^2 = 1\).

    풀이

    \(x = \pm\frac{1}{\sqrt5}\), \(y = \pm\frac{2}{\sqrt5}\). 최댓값 \(\sqrt5\), 최솟값 \(-\sqrt5\).

    검산: 코시-슈바르츠로 \(|(1,2)\cdot(x,y)| \le \sqrt5\cdot1\). 등호는 \((x,y)\)가 \((1,2)\)에 평행할 때.

  5. 계산타원 \(x^2 + 4y^2 = 4\)에 내접하고 각 변이 축에 평행한 직사각형의 넓이의 최댓값을 구하여라. [05-03]

    힌트 1

    제1사분면 꼭짓점 \((x, y)\)이면 넓이 \(4xy\).

    힌트 2

    \(4y = \lambda\cdot2x\), \(4x = \lambda\cdot8y\) → \(x^2 = 4y^2\).

    풀이

    \(x^2 = 4y^2\)을 제약에 넣으면 \(2x^2 = 4\), \(x = \sqrt2\), \(y = \frac{1}{\sqrt2}\). 넓이 \(4\cdot\sqrt2\cdot\frac{1}{\sqrt2} = 4\).

    참고: 타원 넓이 \(\pi ab = 2\pi\)의 \(\frac{2}{\pi}\)배이다. 원에서 내접 정사각형이 원의 \(\frac2\pi\)인 것과 같습니다(타원은 원을 늘인 것).

  6. 계산예산 \(x + 2y = 100\)에서 생산량 \(P = x^{2/3}y^{1/3}\)을 최대로 하여라. [05-03]

    힌트 1

    \(\ln P = \frac23\ln x + \frac13\ln y\)를 최대화해도 같다.

    힌트 2

    \(\frac{2}{3x} = \lambda\), \(\frac{1}{3y} = 2\lambda\).

    풀이

    \(\frac{1}{3y} = \frac{4}{3x}\) → \(x = 4y\). \(4y + 2y = 100\), \(y = \frac{50}{3}\), \(x = \frac{200}{3}\). 예산의 \(\frac23\)을 \(x\)에, \(\frac13\)을 \(y\)에 씁니다(지수와 같은 비율, 콥-더글러스 함수의 성질).

  7. 개념Lagrange 승수법의 조건 \(\nabla f = \lambda\nabla g\)를, \(f\)의 등위선과 제약 곡선 \(g = c\)를 그린 그림으로 설명하여라. [05-03]

    힌트 1

    05-03 절: 두 기울기 벡터는 각각 무엇에 수직인가요?

    힌트 2

    극값에서는 등위선이 제약 곡선을 가로지르지 않는다.

    풀이

    제약 곡선을 따라 걸으면서 \(f\)의 등위선을 가로지르면 \(f\) 값이 계속 바뀝니다(올라가거나 내려감). 극값에서는 등위선이 제약 곡선에 맞닿아 더 이상 가로지르지 않는다. 맞닿은 두 곡선은 그 점에서 법선이 같은 방향이고, 법선이 각각 \(\nabla f\), \(\nabla g\)이므로 둘이 평행하다.

  8. 판단한 학생이 \(f(x, y) = x^2 - y^2\)의 원점에서 \(f_{xx} = 2 > 0\)이므로 극소라고 했다. 맞나요? [05-01]

    힌트 1

    05-01 절: \(D = f_{xx}f_{yy} - f_{xy}^2\)부터.

    힌트 2

    \(y\)축을 따라가 보아라.

    풀이

    틀렸다. \(D = 2(-2) - 0 = -4 < 0\)이므로 안장점이다. \(x\)축 위에서는 \(x^2\) (극소처럼), \(y\)축 위에서는 \(-y^2\) (극대처럼) 보인다. \(f_{xx}\)의 부호는 \(D > 0\)일 때만 판정에 쓴다.
