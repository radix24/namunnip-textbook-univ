매개곡면과 곡면의 넓이

본문
이 절에서 배울 것
  • 두 매개변수로 곡면을 나타낸다.
  • \(|\mathbf r_u\times\mathbf r_v|\)를 적분해 곡면의 넓이를 구한다.
먼저 알아야 할 것
  • 외적과 평행사변형의 넓이 (1.1절), 구면좌표 (6.5절), 극좌표 이중적분 (6.3절).

8.1.1매개곡면

곡선은 매개변수 하나 \(\mathbf r(t)\)로 나타냈습니다. 곡면은 두 개가 필요합니다: \(\mathbf r(u, v) = \langle x(u, v), y(u, v), z(u, v)\rangle\).

  • 반지름 \(a\)인 구면: \(\mathbf r(\phi, \theta) = \langle a\sin\phi\cos\theta, a\sin\phi\sin\theta, a\cos\phi\rangle\), \(0 \le \phi \le \pi\), \(0 \le \theta \le 2\pi\).
  • 원기둥 \(x^2 + y^2 = a^2\): \(\mathbf r(\theta, z) = \langle a\cos\theta, a\sin\theta, z\rangle\).
  • 그래프 \(z = f(x, y)\): \(\mathbf r(x, y) = \langle x, y, f(x, y)\rangle\).

8.1.2넓이

\(uv\)평면의 작은 직사각형 \(\Delta u\times\Delta v\)는 곡면 위의 작은 조각으로 옮겨지고, 그 조각은 두 벡터 \(\mathbf r_u\Delta u\)와 \(\mathbf r_v\Delta v\)가 만드는 평행사변형에 가깝습니다. 평행사변형의 넓이는 외적의 크기이므로(1.1절)

정리 8.1.1 \[\text{넓이}(S) = \iint_D|\mathbf r_u\times\mathbf r_v|\,du\,dv.\]

그래프 \(z = f(x, y)\)이면 \(\displaystyle\iint_D\sqrt{1 + f_x^2 + f_y^2}\,dA\).

\(\mathbf r_u\times\mathbf r_v\)는 곡면에 수직인 벡터(법선)이기도 하며, 8.2절의 선속에서 다시 씁니다.

예제 8.1.2

반지름 \(a\)인 구면의 넓이를 구하여라.

풀이. 계산하면 \(|\mathbf r_\phi\times\mathbf r_\theta| = a^2\sin\phi\)입니다(6.5절의 부피 요소에서 \(d\rho\)를 뺀 것과 같습니다). \(\int_0^{2\pi}\int_0^\pi a^2\sin\phi\,d\phi\,d\theta = 4\pi a^2\).

예제 8.1.3

포물면 \(z = x^2 + y^2\)의 \(z \le 9\)인 부분의 넓이를 구하여라.

풀이. \(\sqrt{1 + 4x^2 + 4y^2} = \sqrt{1 + 4r^2}\), 영역은 \(r \le 3\). 극좌표로

\[\int_0^{2\pi}\int_0^3\sqrt{1 + 4r^2}\,r\,dr\,d\theta = 2\pi\cdot\frac{1}{12}\left[(1 + 4r^2)^{3/2}\right]_0^3 = \frac\pi6\left(37\sqrt{37} - 1\right) \approx 117.3.\]
요약
  1. 곡면 = 매개변수 두 개 \(\mathbf r(u, v)\).
  2. 넓이 \(= \iint|\mathbf r_u\times\mathbf r_v|\,du\,dv\). 그래프는 \(\sqrt{1 + f_x^2 + f_y^2}\).

8.1.3연습문제

기본

  1. 평면 \(z = 2x + 2y\)의 \(0 \le x \le 1\), \(0 \le y \le 1\) 부분의 넓이는?
    답

    \(\sqrt{1 + 4 + 4} = 3\). 넓이 3.

  2. 반지름 1, 높이 2인 원기둥 옆면의 넓이를 매개곡면으로 구하여라.
    답

    \(|\mathbf r_\theta\times\mathbf r_z| = 1\). \(2\pi\cdot2 = 4\pi\).
