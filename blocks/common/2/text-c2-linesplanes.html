공간에서 직선과 평면의 방정식

본문

평면에서는 직선을 \(y = mx + b\)로 썼다. 그런데 공간에서는 기울기 하나로 방향을 나타낼 수 없다. 공간의 직선과 평면은 무엇으로 정해지고, 어떤 식으로 쓸까?

먼저 알아야 할 것내적과 정사영(미분적분학(1) 9.3절), 외적(1.1절)을 쓴다.

1.2.1직선

공간의 직선은 지나는 점 \(P_0(x_0, y_0, z_0)\)과 방향을 알려 주는 벡터 \(\mathbf v = \langle a, b, c\rangle\)로 정한다. 이 \(\mathbf v\)를 방향벡터라 한다. 그러면 직선 위의 점은 \(P_0\)에서 \(\mathbf v\) 방향으로 \(t\)배만큼 간 곳이므로 다음과 같이 쓸 수 있다.

\[x = x_0 + at, \quad y = y_0 + bt, \quad z = z_0 + ct \quad (t\text{는 실수})\]

이것을 직선의 매개변수방정식이라 한다. 미분적분학(1)의 매개변수 곡선과 같은 생각이고, \(t\)를 시간으로 보면 점이 \(\mathbf v\)의 속도로 곧게 움직이는 자취이다. \(t\)를 소거하면 대칭방정식 \(\frac{x - x_0}{a} = \frac{y - y_0}{b} = \frac{z - z_0}{c}\)를 얻는다(분모가 0이 아닐 때).

예제 1.2.1

두 점 \(A(2, 4, -3)\), \(B(3, -1, 1)\)을 지나는 직선의 방정식을 구하여라.

풀이. 방향벡터로 \(\overrightarrow{AB} = \langle1, -5, 4\rangle\)을 쓰면 \(x = 2 + t\), \(y = 4 - 5t\), \(z = -3 + 4t\)이다. \(t = 0\)이면 \(A\), \(t = 1\)이면 \(B\)이므로 두 점을 지나는 것이 맞다. 방향벡터를 \(\overrightarrow{BA}\)로 쓰거나 \(B\)에서 출발해도 같은 직선이며, 식의 모양만 달라진다.

1.2.2평면

평면은 지나는 점 \(P_0\)과 평면에 수직인 벡터 \(\mathbf n = \langle a, b, c\rangle\)로 정해진다. 이 \(\mathbf n\)을 법선벡터라 한다. 평면 위의 점 \(P\)에 대해 \(\overrightarrow{P_0P}\)는 평면 안에 놓이므로 \(\mathbf n\)과 수직이고, 곧 내적이 0이다. 이 조건을 성분으로 쓰면 다음 식이 된다.

\[a(x - x_0) + b(y - y_0) + c(z - z_0) = 0, \quad \text{정리하면}\ ax + by + cz = d\]

거꾸로 \(ax + by + cz = d\)를 보면 법선벡터가 \(\langle a, b, c\rangle\)임을 바로 읽을 수 있다. 다시 말해 일차식의 계수가 평면의 기울어진 방향을 알려 준다.

예제 1.2.2

세 점 \(P(1, 4, 6)\), \(Q(-2, 5, -1)\), \(R(1, -1, 1)\)을 지나는 평면의 방정식을 구하여라.

풀이. 1.1절 예제에서 \(\overrightarrow{PQ}\times\overrightarrow{PR} = \langle-40, -15, 15\rangle\)이었다. 이 벡터는 평면 안의 두 벡터에 모두 수직이므로 법선벡터로 쓸 수 있고, \(-5\)로 나누어 \(\mathbf n = \langle8, 3, -3\rangle\)을 쓴다. 그러면 \(8(x - 1) + 3(y - 4) - 3(z - 6) = 0\), 곧 \(8x + 3y - 3z = 2\)이다. \(Q\)와 \(R\)을 넣으면 \(-16 + 15 + 3 = 2\), \(8 - 3 - 3 = 2\)로 맞는다.

예제 1.2.3

직선 \(x = 2 + 3t\), \(y = -4t\), \(z = 5 + t\)와 평면 \(4x + 5y - 2z = 18\)의 교점을 구하여라.

풀이. 직선 위의 점을 평면의 식에 대입하면 \(4(2 + 3t) + 5(-4t) - 2(5 + t) = 18\), 곧 \(-2 - 10t = 18\)이므로 \(t = -2\)이다. 따라서 교점은 \((-4, 8, 3)\)이다.

1.2.3점과 평면 사이의 거리

정리 1.2.4

점 \((x_1, y_1, z_1)\)에서 평면 \(ax + by + cz = d\)까지의 거리는

\[D = \frac{|ax_1 + by_1 + cz_1 - d|}{\sqrt{a^2 + b^2 + c^2}}.\]

그림 1에서 보듯이 평면 위의 한 점에서 주어진 점으로 가는 벡터를 법선 방향으로 정사영한 길이가 거리이다. 미분적분학(1) 9.3절의 스칼라 정사영 \(\frac{\mathbf n\cdot\mathbf w}{|\mathbf n|}\)을 계산하면 분자에 \(ax_1 + by_1 + cz_1 - d\)가 나온다. 고교에서 배운 점과 직선 사이의 거리 공식과 모양이 같은 것도 이 때문이다.

예제 1.2.5

점 \((1, 2, 3)\)에서 평면 \(2x - y + 2z = 10\)까지의 거리는?

풀이. \(\frac{|2 - 2 + 6 - 10|}{\sqrt{4 + 1 + 4}} = \frac43\)이다. 분자의 값 \(-4\)가 음수라는 것은 점이 평면의 법선 반대쪽에 있다는 뜻이다.

마무리

공간에서는 기울기 대신 벡터로 방향을 나타낸다. 직선은 점 하나와 방향벡터로 \(\mathbf r = \mathbf r_0 + t\mathbf v\)라 쓰고, 평면은 점 하나와 법선벡터로 \(ax + by + cz = d\)라 쓰며 계수 \(\langle a, b, c\rangle\)가 곧 법선이다. 세 점이 주어지면 외적으로 법선을 구하고, 점과 평면 사이의 거리는 법선 방향의 정사영으로 구한다.

1.2.4연습문제

기본

  1. 점 \((1, 0, -1)\)을 지나고 법선이 \(\langle2, 1, 1\rangle\)인 평면은?
    답

    \(2x + y + z = 1\).

  2. 원점에서 평면 \(x + 2y + 2z = 6\)까지의 거리는?
    답

    \(\frac63 = 2\).

응용

  1. 두 평면 \(x + y + z = 1\), \(x - 2y + 3z = 1\)의 사잇각의 코사인은? (법선벡터의 사잇각)
    답

    \(\frac{1 - 2 + 3}{\sqrt3\sqrt{14}} = \frac{2}{\sqrt{42}}\).
