편도함수

본문

산비탈에서 동쪽으로 한 걸음 가면 높이가 얼마나 변하고, 북쪽으로 한 걸음 가면 얼마나 변할까? 두 변수의 함수에서 한 방향의 변화율만 따로 떼어 낼 수 있을까?

먼저 알아야 할 것미분적분학(1)의 미분법(2.1절)과 다변수함수(4.1절)를 쓴다.

4.2.1정의와 계산

기온 \(T(x, y)\)에서 동쪽으로만 움직일 때 기온이 변하는 비율은 \(y\)를 고정하고 \(x\)에 대해 미분한 것이다. 즉 두 변수 가운데 하나를 멈춰 두면 남는 것은 일변수 함수이고, 그 도함수를 구하면 된다.

정의 4.2.1 (편도함수) \[f_x(a, b) = \lim_{h\to0}\frac{f(a + h, b) - f(a, b)}{h}, \qquad f_y(a, b) = \lim_{h\to0}\frac{f(a, b + h) - f(a, b)}{h}.\]

이것을 편도함수라 하고, \(f_x = \frac{\partial f}{\partial x} = \frac{\partial z}{\partial x}\)처럼 쓴다. 계산은 간단하다. \(f_x\)를 구할 때는 \(y\)를 상수로 보고 미분적분학(1)의 미분법을 그대로 쓴다.

예제 4.2.2

\(f(x, y) = x^3 + x^2y^3 - 2y^2\)일 때 \(f_x(2, 1)\), \(f_y(2, 1)\)을 구하여라.

풀이. \(y\)를 상수로 보면 \(f_x = 3x^2 + 2xy^3\)이고, \(x\)를 상수로 보면 \(f_y = 3x^2y^2 - 4y\)이다. 따라서 \(f_x(2, 1) = 12 + 4 = 16\), \(f_y(2, 1) = 12 - 4 = 8\)이다. 처음 질문의 말로 하면, 이 지점에서 \(x\) 방향으로 한 걸음 가면 높이가 약 16만큼, \(y\) 방향으로 가면 약 8만큼 오른다.

그림으로는 곡면 \(z = f(x, y)\)를 평면 \(y = b\)로 자른 곡선의 기울기가 \(f_x(a, b)\)이고, 평면 \(x = a\)로 자른 곡선의 기울기가 \(f_y(a, b)\)이다. 그림 1에서 자르는 위치 \(b\)를 바꾸면 단면 곡선의 모양과 그 기울기가 함께 바뀐다. 다시 말해 \(f_x(a, b)\)는 \(a\)뿐 아니라 어디서 잘랐는지에도 달려 있으므로, 편도함수 역시 두 변수의 함수이다. 그림의 곡면에서는 \(f_x = -x + 0.3y\)이라서, 같은 \(x = 0.5\)에서도 \(b\)가 클수록 기울기가 덜 가파르다.

4.2.2이계 편도함수

편도함수를 다시 편미분하면 이계 편도함수가 네 개 나온다. 같은 변수로 두 번 미분한 \(f_{xx} = \frac{\partial^2f}{\partial x^2}\), \(f_{yy} = \frac{\partial^2f}{\partial y^2}\)가 있고, 섞어서 미분한 \(f_{xy} = (f_x)_y\)와 \(f_{yx} = (f_y)_x\)가 있다. \(f_{xy}\)는 \(x\)로 미분한 뒤 \(y\)로, \(f_{yx}\)는 \(y\)로 미분한 뒤 \(x\)로 미분한 것이다.

정리 4.2.3 (클레로 정리)

\(f_{xy}\)와 \(f_{yx}\)가 연속이면 \(f_{xy} = f_{yx}\)이다.

예제 4.2.2에서 \(f_{xy} = (3x^2 + 2xy^3)_y = 6xy^2\)이고 \(f_{yx} = (3x^2y^2 - 4y)_x = 6xy^2\)로 같다. 이 책에서 다루는 함수는 거의 모두 이 조건을 만족하므로, 미분 순서는 계산하기 편한 쪽을 고르면 된다. 가령 \(f = x\sin(y) + e^{y}\cos(y)\)의 \(f_{xy}\)를 구할 때 \(y\)로 먼저 미분하면 곱의 미분법을 써야 하지만, \(x\)로 먼저 미분하면 둘째 항이 바로 사라져 \(\sin y\)만 남고 그다음 \(y\)로 미분하면 \(\cos y\)를 얻는다.

예제 4.2.4 (편미분방정식 맛보기)

\(u(x, t) = e^{-t}\sin x\)가 \(u_t = u_{xx}\)를 만족함을 보여라.

풀이. \(u_t = -e^{-t}\sin x\)이고, \(u_x = e^{-t}\cos x\), \(u_{xx} = -e^{-t}\sin x\)이므로 두 값이 같다. 이 식은 막대의 온도 변화를 나타내는 열방정식이며, 고등미적분학(2)에서 본격적으로 푼다. 해를 읽으면 온도 분포 \(\sin x\)의 모양은 그대로 두고 높이만 \(e^{-t}\)로 줄어드는데, 열이 퍼지며 막대가 식는 모습이다.

마무리

편도함수 \(f_x\)는 \(y\)를 상수로 두고 \(x\)로 미분한 것으로, 곡면을 \(y\)가 일정한 평면으로 자른 곡선의 기울기이다. 그래서 처음 질문의 동쪽과 북쪽 변화율은 각각 \(f_x\)와 \(f_y\)이다. 이계 편도함수는 네 개이고, 연속이면 미분 순서를 바꾸어도 \(f_{xy} = f_{yx}\)이다.

4.2.3연습문제

기본

  1. \(f = x^2e^{3y}\)의 \(f_x\), \(f_y\)는?
    답

    \(2xe^{3y}\), \(3x^2e^{3y}\).

  2. \(f = \sin(xy)\)의 \(f_{xy}\)는?
    답

    \(f_x = y\cos(xy)\), \(f_{xy} = \cos(xy) - xy\sin(xy)\).

응용

  1. \(u = \ln(x^2 + y^2)\)이 \(u_{xx} + u_{yy} = 0\)을 만족함을 보여라.
    답

    \(u_{xx} = \frac{2(y^2 - x^2)}{(x^2 + y^2)^2}\), \(u_{yy} = \frac{2(x^2 - y^2)}{(x^2 + y^2)^2}\). 합 0.
