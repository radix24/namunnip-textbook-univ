편도함수

본문
이 절에서 배울 것
  • 한 변수만 움직이고 나머지는 고정해 미분하는 편도함수를 계산한다.
  • 이계 편도함수를 구하고, 미분 순서를 바꿔도 같다는 것을 안다.
먼저 알아야 할 것
  • 미분법 (공통1 2단원), 다변수함수 (4.1절).

4.2.1정의와 계산

기온 \(T(x, y)\)에서 동쪽으로만 움직일 때 기온이 변하는 비율은 \(y\)를 고정하고 \(x\)에 대해 미분한 것입니다.

정의 4.2.1 (편도함수) \[f_x(a, b) = \lim_{h\to0}\frac{f(a + h, b) - f(a, b)}{h}, \qquad f_y(a, b) = \lim_{h\to0}\frac{f(a, b + h) - f(a, b)}{h}.\]

표기는 \(f_x = \frac{\partial f}{\partial x} = \frac{\partial z}{\partial x}\) 등을 씁니다. 계산 방법은 간단합니다. \(f_x\)를 구할 때는 \(y\)를 상수로 보고 공통1의 미분법을 그대로 씁니다.

예제 4.2.2

\(f(x, y) = x^3 + x^2y^3 - 2y^2\)일 때 \(f_x(2, 1)\), \(f_y(2, 1)\)을 구하여라.

풀이. \(f_x = 3x^2 + 2xy^3\), \(f_y = 3x^2y^2 - 4y\). \(f_x(2, 1) = 12 + 4 = 16\), \(f_y(2, 1) = 12 - 4 = 8\).

그림으로는 곡면 \(z = f(x, y)\)를 평면 \(y = b\)로 자른 곡선의 기울기가 \(f_x(a, b)\), 평면 \(x = a\)로 자른 곡선의 기울기가 \(f_y(a, b)\)입니다.

4.2.2이계 편도함수

편도함수를 다시 편미분하면 이계 편도함수가 네 개 나옵니다.

  • \(f_{xx} = \frac{\partial^2f}{\partial x^2}\), \(f_{yy} = \frac{\partial^2f}{\partial y^2}\).
  • \(f_{xy} = (f_x)_y\): \(x\)로 미분한 뒤 \(y\)로.
  • \(f_{yx} = (f_y)_x\): \(y\)로 미분한 뒤 \(x\)로.
정리 4.2.3 (클레로 정리)

\(f_{xy}\)와 \(f_{yx}\)가 연속이면 \(f_{xy} = f_{yx}\)이다.

예제 4.2.2에서 \(f_{xy} = (3x^2 + 2xy^3)_y = 6xy^2\), \(f_{yx} = (3x^2y^2 - 4y)_x = 6xy^2\)로 같습니다. 이 책에서 다루는 함수는 거의 모두 이 조건을 만족합니다.

예제 4.2.4 (편미분방정식 맛보기)

\(u(x, t) = e^{-t}\sin x\)가 \(u_t = u_{xx}\)를 만족함을 보여라.

풀이. \(u_t = -e^{-t}\sin x\), \(u_x = e^{-t}\cos x\), \(u_{xx} = -e^{-t}\sin x\). 같습니다. 이 식은 막대의 온도 변화를 나타내는 열방정식이며, 공통9(고등미적분학(2))에서 본격적으로 풉니다.

요약
  1. \(f_x\): \(y\)를 상수로 보고 \(x\)로 미분. 단면 곡선의 기울기.
  2. 이계 편도함수 네 개. 연속이면 \(f_{xy} = f_{yx}\).

4.2.3연습문제

기본

  1. \(f = x^2e^{3y}\)의 \(f_x\), \(f_y\)는?
    답

    \(2xe^{3y}\), \(3x^2e^{3y}\).

  2. \(f = \sin(xy)\)의 \(f_{xy}\)는?
    답

    \(f_x = y\cos(xy)\), \(f_{xy} = \cos(xy) - xy\sin(xy)\).

응용

  1. \(u = \ln(x^2 + y^2)\)이 \(u_{xx} + u_{yy} = 0\)을 만족함을 보여라.
    답

    \(u_{xx} = \frac{2(y^2 - x^2)}{(x^2 + y^2)^2}\), \(u_{yy} = \frac{2(x^2 - y^2)}{(x^2 + y^2)^2}\). 합 0.
