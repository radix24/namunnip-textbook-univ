평면의 방정식은 법선 벡터 하나와 점 하나부터 찾는다

요령 · 직선과 평면의 방정식

언제 쓰는가

세 점, 점과 직선, 두 평면 같은 조건으로 공간의 평면이나 직선을 세우는 문제입니다. 조건이 여러 개라 무엇부터 구할지 헷갈릴 때 씁니다.

요령

  1. 평면 = 점 + 법선
    평면은 \(a(x - x_0) + b(y - y_0) + c(z - z_0) = 0\) 하나로 쓰입니다. 필요한 것은 법선 \((a, b, c)\)와 점 하나뿐입니다.
  2. 법선은 외적으로
    평면 안에 놓인 두 방향을 찾아 외적하면 법선입니다. 세 점 \(P, Q, R\)이면 \(\overrightarrow{PQ}\times\overrightarrow{PR}\)입니다.
  3. 직선 = 점 + 방향
    두 평면의 교선은 두 법선에 모두 수직이므로 방향이 \(\mathbf n_1\times\mathbf n_2\)입니다. 점은 \(z = 0\) 같은 값을 하나 넣어 찾습니다.
  4. 대입해서 검산
    주어진 점을 모두 넣어 식이 성립하는지, 법선과 평면 안 벡터의 내적이 0인지 확인합니다.

흔한 실수

  • 법선과 평면 안의 방향을 바꿔 쓰는 것. '평면에 수직인 직선'의 방향은 법선이고, '평면에 평행한 직선'의 방향은 법선과 수직입니다.
  • 점과 평면 사이 거리의 분모에 \(\sqrt{a^2 + b^2 + c^2}\) 대신 \(a + b + c\)를 쓰는 것.

바로 풀어보기

점 \(P(1, 0, 2)\)를 지나고 두 평면 \(x + y - z = 1\), \(2x - y + z = 4\)에 모두 수직인 평면의 방정식을 구하세요.

답과 풀이

답: \(y + z = 2\)

구하는 평면이 두 평면에 수직이면, 그 법선은 두 평면의 법선 \(\mathbf n_1 = (1, 1, -1)\), \(\mathbf n_2 = (2, -1, 1)\)에 모두 수직입니다. 따라서 법선은 \(\mathbf n_1\times\mathbf n_2 = (0, -3, -3)\), 간단히 \((0, 1, 1)\)입니다.

점 \(P\)를 넣으면 \(0\cdot(x - 1) + (y - 0) + (z - 2) = 0\), 곧 \(y + z = 2\)입니다. 검산: \(P\)에서 \(0 + 2 = 2\)이고, \((0, 1, 1)\cdot\mathbf n_1 = 0\), \((0, 1, 1)\cdot\mathbf n_2 = 0\)입니다. 이 평면은 두 평면의 교선에 수직인 평면이기도 합니다.

이 요령으로 풀리는 문제

  • 벡터와 공간기하 단원 연습 4번, 5번, 8번
영상 콘티 · 45초
  1. 0~5초공간 좌표축 위에 점 \(P\) 하나와 기울어진 두 평면이 떠 있습니다.평면의 방정식, 무엇부터 구할까요?
  2. 5~13초빈 평면 하나가 나타나고, 그 위에 '점 하나'와 '수직 화살표 하나' 자리가 점선으로 비어 있습니다.평면은 점 하나와 법선 하나면 됩니다.
  3. 13~22초두 평면에서 법선 화살표 \(\mathbf n_1\), \(\mathbf n_2\)가 솟아오르고, 두 화살표 끝이 만나 오른손 모양과 함께 수직 방향 \(\mathbf n_1\times\mathbf n_2\)가 자랍니다.두 방향에 모두 수직인 방향은 외적으로 얻습니다.
  4. 22~30초새 화살표가 점 \(P\)로 날아가 꽂히고, 그 화살표에 수직인 평면이 \(P\)를 중심으로 펼쳐집니다.법선과 점을 넣으면 평면이 정해집니다.
  5. 30~38초펼쳐진 평면이 원래 두 평면과 만나는 곳에 직각 표시가 깜박입니다.두 평면에 모두 수직인지 확인합니다.
  6. 38~45초식 \(y + z = 2\)에 \(P(1, 0, 2)\)가 대입되어 \(2 = 2\)에 체크 표시가 붙습니다.마지막은 대입 검산입니다.
