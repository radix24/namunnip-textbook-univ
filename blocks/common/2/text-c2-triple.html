삼중적분, 질량과 질량중심

본문

밀도가 자리마다 다른 쇳덩이의 질량은 어떻게 구할까? 한쪽이 더 무거운 물체를 손가락 하나로 받쳐 균형을 잡으려면 어디를 받쳐야 할까? 부피 위에서 적분하는 방법이 필요하지 않을까?

먼저 알아야 할 것이중적분과 적분 범위 읽기(6.2절)를 쓴다.

6.4.1삼중적분

입체 \(E\)를 작은 상자로 나누고 \(f\times\)(상자 부피)를 더한 극한이 삼중적분 \(\iiint_Ef\,dV\)이다. 이중적분은 곡면 아래 부피로 그릴 수 있었지만, 삼중적분은 4차원 그림이 필요해 그릴 수 없다. 그래서 \(f\)를 밀도로 생각하면 이해가 쉽다. 밀도를 부피에 대해 적분하면 질량이고, \(f = 1\)이면 \(E\)의 부피이다.

계산은 이중적분처럼 한 변수씩 차례로 한다. 상자 \([a, b]\times[c, d]\times[r, s]\)이면 범위가 모두 상수이고, 일반 입체는 6.2절처럼 바깥 변수에 따라 안쪽 범위를 정한다.

예제 6.4.1

상자 \(B = [0, 1]\times[-1, 2]\times[0, 3]\)에서 \(\iiint_Bxyz^2\,dV\)를 구하여라.

풀이. 변수가 곱으로 나뉘므로 세 적분을 따로 계산해 곱한다. \(\int_0^1x\,dx\cdot\int_{-1}^2y\,dy\cdot\int_0^3z^2\,dz = \frac12\cdot\frac32\cdot9 = \frac{27}{4}\)이다.

예제 6.4.2

좌표평면들과 평면 \(x + y + z = 1\)로 둘러싸인 사면체의 부피를 구하여라.

풀이. 바닥은 삼각형 \(x \ge 0\), \(y \ge 0\), \(x + y \le 1\)이고, 그 위에서 높이는 \(0 \le z \le 1 - x - y\)이다. 따라서

\[\int_0^1\int_0^{1-x}(1 - x - y)\,dy\,dx = \int_0^1\frac{(1 - x)^2}{2}dx = \frac16\]

이다. 가운데 식의 \(\frac{(1 - x)^2}{2}\)는 그림 1의 삼각형 단면의 넓이이다. \(x\)를 0에서 1로 옮기면 단면이 직각을 낀 두 변 \(1 - x\)인 삼각형으로 줄어든다. 결과는 밑넓이 \(\frac12\), 높이 1인 뿔의 부피 \(\frac13\cdot\frac12\cdot1\)과 같다.

6.4.2질량과 질량중심

밀도가 \(\rho(x, y, z)\)인 물체의 질량은 \(m = \iiint_E\rho\,dV\)이다. 질량중심은 \(\bar x = \frac1m\iiint_Ex\rho\,dV\)이고, \(\bar y\), \(\bar z\)도 같은 방법으로 구한다. 또 \(z\)축에 대한 관성 모멘트는 \(I_z = \iiint_E(x^2 + y^2)\rho\,dV\)이다.

질량중심은 위치를 질량으로 가중평균한 것이다. 처음 질문의 손가락은 이 점을 받쳐야 한다. 관성 모멘트는 회전시키기 어려운 정도로, 축에서 먼 곳의 질량일수록 거리의 제곱만큼 크게 센다. 일반물리의 강체 회전에서 쓴다.

예제 6.4.3

단위정육면체 \([0, 1]^3\)의 밀도가 \(\rho = x + y + z\)일 때 질량과 \(\bar x\)를 구하여라.

풀이. 질량은 \(m = \iiint(x + y + z)\,dV = \frac12 + \frac12 + \frac12 = \frac32\)이다. 다음으로 \(\iiint x(x + y + z)\,dV = \frac13 + \frac14 + \frac14 = \frac56\)이므로 \(\bar x = \frac{5/6}{3/2} = \frac59\)이다. 밀도가 고르면 중심이 \(\frac12\)이었을 텐데, 밀도가 큰 쪽, 곧 꼭짓점 \((1, 1, 1)\) 쪽으로 \(\frac{1}{18}\)만큼 옮겨졌다. 대칭이므로 \(\bar y = \bar z = \frac59\)이다.

마무리

삼중적분은 입체를 작은 상자로 나누어 \(f\times\)부피를 더한 극한이고, 한 변수씩 차례로 적분하며 범위는 입체를 그려 정한다. 처음 질문의 쇳덩이는 밀도를 적분해 질량 \(\iiint\rho\,dV\)를 얻고, 위치를 질량으로 가중평균한 질량중심 \(\frac1m\iiint x\rho\,dV\)를 받치면 균형이 잡힌다.

6.4.3연습문제

기본

  1. \(\int_0^1\int_0^1\int_0^1(x + y + z)\,dz\,dy\,dx\)는?
    답

    \(\frac32\).

응용

  1. 예제 6.4.2의 사면체(밀도 1)의 질량중심 \(\bar z\)는? (힌트: \(\iiint z\,dV = \frac{1}{24}\))
    답

    \(\frac{1/24}{1/6} = \frac14\). 대칭으로 \(\bar x = \bar y = \frac14\).
