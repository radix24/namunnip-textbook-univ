삼중적분, 질량과 질량중심

본문

먼저 알아야 할 것
  • 이중적분 (6.2절).

6.4.1삼중적분

입체 \(E\)를 작은 상자로 나누고 \(f\times\)(상자 부피)를 더한 극한이 삼중적분 \(\iiint_Ef\,dV\)입니다. 4차원 그림은 그릴 수 없으므로, \(f\)를 밀도로 생각하면 이해가 쉽습니다. 밀도를 부피에 대해 적분하면 질량입니다. \(f = 1\)이면 \(E\)의 부피입니다.

계산은 한 변수씩 차례로 합니다. 상자 \([a, b]\times[c, d]\times[r, s]\)이면 범위가 상수이고, 일반 입체는 6.2절처럼 바깥 변수에 따라 안쪽 범위를 정합니다.

예제 6.4.1

상자 \(B = [0, 1]\times[-1, 2]\times[0, 3]\)에서 \(\iiint_Bxyz^2\,dV\)를 구하여라.

풀이. 변수가 나뉘므로 \(\int_0^1x\,dx\cdot\int_{-1}^2y\,dy\cdot\int_0^3z^2\,dz = \frac12\cdot\frac32\cdot9 = \frac{27}{4}\).

예제 6.4.2

좌표평면들과 평면 \(x + y + z = 1\)로 둘러싸인 사면체의 부피를 구하여라.

풀이. 바닥은 삼각형 \(x \ge 0\), \(y \ge 0\), \(x + y \le 1\)이고 높이는 \(0 \le z \le 1 - x - y\).

\[\int_0^1\int_0^{1-x}(1 - x - y)\,dy\,dx = \int_0^1\frac{(1 - x)^2}{2}dx = \frac16.\]

밑넓이 \(\frac12\), 높이 1인 뿔의 부피 \(\frac13\cdot\frac12\cdot1\)과 같습니다.

6.4.2질량과 질량중심

밀도가 \(\rho(x, y, z)\)인 물체에서

  • 질량: \(m = \iiint_E\rho\,dV\).
  • 질량중심: \(\bar x = \frac1m\iiint_Ex\rho\,dV\), \(\bar y\), \(\bar z\)도 같은 방법.
  • \(z\)축에 대한 관성 모멘트: \(I_z = \iiint_E(x^2 + y^2)\rho\,dV\).

질량중심은 위치를 질량으로 가중평균한 것입니다. 관성 모멘트는 회전시키기 어려운 정도로, 물리(공통3)의 강체 회전에서 씁니다.

예제 6.4.3

단위정육면체 \([0, 1]^3\)의 밀도가 \(\rho = x + y + z\)일 때 질량과 \(\bar x\)를 구하여라.

풀이. \(m = \iiint(x + y + z)\,dV = \frac12 + \frac12 + \frac12 = \frac32\). \(\iiint x(x + y + z)\,dV = \frac13 + \frac14 + \frac14 = \frac56\). \(\bar x = \frac{5/6}{3/2} = \frac59\). 밀도가 큰 쪽(꼭짓점 \((1, 1, 1)\) 쪽)으로 중심 \(\frac12\)에서 조금 옮겨졌습니다.

요약
  1. 삼중적분은 한 변수씩 차례로. 범위는 입체를 그려 정한다.
  2. 질량 \(\iiint\rho\), 질량중심 \(\frac1m\iiint x\rho\), 관성 모멘트 \(\iiint(x^2 + y^2)\rho\).

6.4.3연습문제

기본

  1. \(\int_0^1\int_0^1\int_0^1(x + y + z)\,dz\,dy\,dx\)는?
    답

    \(\frac32\).

응용

  1. 예제 6.4.2의 사면체(밀도 1)의 질량중심 \(\bar z\)는? (힌트: \(\iiint z\,dV = \frac{1}{24}\))
    답

    \(\frac{1/24}{1/6} = \frac14\). 대칭으로 \(\bar x = \bar y = \frac14\).
