선적분: 곡선을 따라 더하기

스칼라 선적분 ds · 벡터 선적분 F·dr · 일

두 가지 선적분

  • 스칼라 선적분 \(\int_Cf\,ds\): 곡선을 길이 \(ds\)인 조각으로 나눠 \(f\times ds\)를 더함. 예: 밀도 \(f\)인 철사의 질량. 계산: \(\mathbf r(t)\), \(a \le t \le b\)로 매개화하면 \(ds = |\mathbf r'(t)|\,dt\), \(\int_Cf\,ds = \int_a^bf(\mathbf r(t))|\mathbf r'(t)|\,dt\). 방향과 상관없음.
  • 벡터 선적분 \(\int_C\mathbf F\cdot d\mathbf r\): 조각마다 힘의 진행 방향 성분 × 길이, 곧 일. \(d\mathbf r = \mathbf r'(t)\,dt\), \(\int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt\). 방향을 뒤집으면 부호가 바뀜.

두 식은 \(\int_C\mathbf F\cdot d\mathbf r = \int_C(\mathbf F\cdot\mathbf T)\,ds\)로 이어집니다(\(\mathbf r'\,dt = \mathbf T|\mathbf r'|\,dt = \mathbf T\,ds\)). 성분으로 쓰면 \(\int_C P\,dx + Q\,dy\).

매개화를 바꿔도 값이 같습니다(벡터 선적분은 방향이 같을 때). 치환적분으로 확인된다. 그래서 가장 편한 매개화를 고르면 된다.

먼저 예측

(가)와 (나)의 두 경로가 같은 값을 준다면, 같은 끝점을 잇는 모든 경로가 같은 값을 줄까?

예측 확인

아니다. (다)에서 세 번째 경로가 다른 값을 준다. 두 경로가 같은 것은 우연일 수 있다.

\(\mathbf F = (y, x^2)\)일 때 \(\int_C\mathbf F\cdot d\mathbf r\)를 (가) \((0,0)\)에서 \((1,1)\)까지의 선분 (나) 포물선 \(y = x^2\)을 따라 같은 두 점 사이에서 계산하여라. 또 (다) 단위원의 위쪽 반원에서 \(\int_C y\,ds\)를 구하여라.

풀이

  1. (가) \(\mathbf r(t) = (t, t)\), \(\mathbf r' = (1, 1)\), \(0 \le t \le 1\). \(\mathbf F(\mathbf r) = (t, t^2)\).
    선분의 매개화.
  2. \(\int_0^1(t + t^2)\,dt = \frac12 + \frac13 = \frac56\).
    \(\mathbf F\cdot\mathbf r'\).
  3. (나) \(\mathbf r(t) = (t, t^2)\), \(\mathbf r' = (1, 2t)\), \(\mathbf F = (t^2, t^2)\). \(\int_0^1(t^2 + 2t^3)\,dt = \frac13 + \frac12 = \frac56\).
    같은 끝점.
  4. 두 경로가 같은 값을 주었지만 이것만으로 경로 독립이라 할 수는 없다. 실제로 \((0,0) \to (1,0) \to (1,1)\)이면 \(\int_0^1 0\,dt + \int_0^1 1\,dt = 1 \ne \frac56\).
    첫 구간 \(y = 0\)이라 \(\mathbf F\cdot(1,0) = 0\), 둘째 구간 \(x = 1\)이라 \(\mathbf F\cdot(0,1) = 1\). 다음 카드에서 이유를 본다.
  5. (다) \(\mathbf r = (\cos t, \sin t)\), \(0 \le t \le \pi\), \(|\mathbf r'| = 1\). \(\int_0^\pi\sin t\,dt = 2\).
    스칼라 선적분. 밀도가 높이에 비례하는 반원 철사의 질량.

의미

벡터 선적분은 힘이 경로를 따라 한 일이다. 같은 끝점이라도 경로에 따라 일이 달랐는데, 어떤 장에서는 경로와 상관없게 되는지가 다음 절(보존장)의 질문이다.

검산

(다) 반원의 길이 \(\pi\), \(y\)의 평균값은 \(\frac2\pi \approx 0.64\)로 0과 1 사이. 반원 철사의 무게중심 높이 \(\frac{2}{\pi}\)와 같다.

흔한 오해

  • \(ds\)에서 \(|\mathbf r'|\) 빠뜨리기: 매개변수가 호의 길이일 때만 \(ds = dt\).
  • \(\int_C f\,ds\)에 방향 부호 붙이기: 스칼라 선적분은 방향과 상관없습니다(길이는 늘 양수).
