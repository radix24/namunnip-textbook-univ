벡터함수와 곡선 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산곡선 \(\mathbf r(t) = (e^t, e^{-t}, \sqrt2\,t)\)의 \(t = 0\)에서의 접선의 매개방정식을 구하세요. [03-02]

    힌트 1

    점 \(\mathbf r(0)\), 방향 \(\mathbf r'(0)\).

    힌트 2

    \(\mathbf r'(t) = (e^t, -e^{-t}, \sqrt2)\).

    풀이

    \(\mathbf r(0) = (1, 1, 0)\), \(\mathbf r'(0) = (1, -1, \sqrt2)\). 접선 \((1 + s, 1 - s, \sqrt2 s)\).

  2. 계산가속도 \(\mathbf a(t) = (6t, 2, e^t)\), \(\mathbf v(0) = (0, 0, 1)\), \(\mathbf r(0) = (1, 0, 0)\)일 때 \(\mathbf r(t)\)를 구하세요. [03-02]

    힌트 1

    두 번 적분, 각각 초기조건으로 상수 결정.

    힌트 2

    \(\mathbf v = (3t^2, 2t, e^t) + \mathbf C\), \(\mathbf v(0) = (0,0,1)\)이면 \(\mathbf C = \mathbf 0\).

    풀이

    \(\mathbf v = (3t^2, 2t, e^t)\). \(\mathbf r = (t^3, t^2, e^t) + \mathbf D\), \(\mathbf r(0) = (0, 0, 1) + \mathbf D = (1, 0, 0)\)에서 \(\mathbf D = (1, 0, -1)\). \(\mathbf r(t) = (t^3 + 1, t^2, e^t - 1)\).

  3. 계산\(\mathbf r(t) = (3\cos t, 3\sin t, 4t)\)의 \(t = 0\)부터 \(t = 2\pi\)까지의 길이와, \(t = 0\)에서 시작하는 호의 길이 매개화를 구하세요. [03-03]

    힌트 1

    \(|\mathbf r'| = \sqrt{9 + 16}\).

    힌트 2

    \(s = 5t\).

    풀이

    속력 5, 길이 \(10\pi\). \(t = \frac s5\): \(\mathbf r(s) = \left(3\cos\frac s5, 3\sin\frac s5, \frac{4s}{5}\right)\). 확인: \(|d\mathbf r/ds| = \frac15\sqrt{9 + 16} = 1\).

  4. 도전\(y = x^3\)의 곡률이 최대가 되는 점(\(x > 0\))을 구하세요. [03-03]

    힌트 1

    \(\kappa(x) = \frac{6x}{(1 + 9x^4)^{3/2}}\).

    힌트 2

    \(\ln\kappa\)를 미분하면 계산이 쉽습니다.

    풀이

    \(\ln\kappa = \ln6 + \ln x - \frac32\ln(1 + 9x^4)\). 미분: \(\frac1x - \frac{54x^3}{1 + 9x^4} = 0 \iff 1 + 9x^4 = 54x^4 \iff x^4 = \frac{1}{45}\). \(x = 45^{-1/4} \approx 0.386\). \(x \to 0^+\)이면 \(\kappa \to 0\), \(x \to \infty\)이면 \(\kappa \to 0\)이므로 이 점이 최대.

  5. 계산\(\mathbf r(t) = (t, \cos t, \sin t)\)의 \(\mathbf T\), \(\mathbf N\), \(\mathbf B\)를 \(t = 0\)에서 구하세요. [03-03]

    힌트 1

    \(|\mathbf r'| = \sqrt2\)로 일정합니다.

    힌트 2

    \(\mathbf T(t) = \frac{1}{\sqrt2}(1, -\sin t, \cos t)\), 이것을 미분해 정규화.

    풀이

    \(\mathbf T(0) = \frac{1}{\sqrt2}(1, 0, 1)\). \(\mathbf T'(t) = \frac{1}{\sqrt2}(0, -\cos t, -\sin t)\), \(\mathbf N(0) = (0, -1, 0)\). \(\mathbf B = \mathbf T\times\mathbf N = \frac{1}{\sqrt2}(0\cdot0 - 1\cdot(-1),\ 1\cdot0 - 1\cdot0,\ 1\cdot(-1) - 0) = \frac{1}{\sqrt2}(1, 0, -1)\).

    확인: 세 벡터는 서로 수직이고 길이 1입니다.

  6. 계산\(\mathbf r(t) = (t^2, t^3)\)을 따라 움직이는 점의 \(t = 1\)에서 \(a_T\)와 \(a_N\)을 구하세요. [03-03]

    힌트 1

    \(\mathbf r' = (2t, 3t^2)\), \(\mathbf r'' = (2, 6t)\).

    힌트 2

    2차원 외적의 크기: \(|x'y'' - y'x''|\).

    풀이

    \(t = 1\): \(\mathbf r' = (2, 3)\), \(\mathbf r'' = (2, 6)\), \(v = \sqrt{13}\). \(a_T = \frac{4 + 18}{\sqrt{13}} = \frac{22}{\sqrt{13}}\). \(a_N = \frac{|2\cdot6 - 3\cdot2|}{\sqrt{13}} = \frac{6}{\sqrt{13}}\).

    검산: \(a_T^2 + a_N^2 = \frac{484 + 36}{13} = 40 = |\mathbf r''|^2\).

  7. 개념속력이 일정한 운동에서는 가속도가 늘 속도에 수직임을 보이고, 등속 원운동으로 확인하세요. [03-02]

    힌트 1

    03-02 절: \(|\mathbf v|^2 = \mathbf v\cdot\mathbf v\)를 미분하세요.

    힌트 2

    \(\frac{d}{dt}(\mathbf v\cdot\mathbf v) = 2\mathbf v\cdot\mathbf a\).

    풀이

    \(\mathbf v\cdot\mathbf v\)가 상수이므로 미분하면 \(2\mathbf v\cdot\mathbf a = 0\). 등속 원운동 \((\cos t, \sin t)\): \(\mathbf v = (-\sin t, \cos t)\), \(\mathbf a = (-\cos t, -\sin t)\), 내적 0. 가속도가 속력을 바꾸지 않고 방향만 바꿉니다.

  8. 판단한 학생이 포물선 \(\mathbf r(t) = (t, t^2)\)의 곡률을 \(|\mathbf r''| = 2\)라고 했습니다. 이 답이 이상한 이유는? [03-03]

    힌트 1

    03-03 절: 곡률이 상수라면 곡선은 어떤 모양인가요?

    힌트 2

    \(\kappa = \frac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|^3}\).

    풀이

    곡률이 어디서나 2라면 곡선은 반지름 \(\frac12\)인 원이어야 하는데, 포물선은 멀리 갈수록 펴집니다. \(|\mathbf r''|\)은 속력이 1일 때만 곡률입니다. 바른 값 \(\kappa = \frac{2}{(1 + 4t^2)^{3/2}}\): 꼭짓점에서 2, \(t \to \infty\)이면 0.
