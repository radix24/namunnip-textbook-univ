접평면과 선형근사

본문
이 절에서 배울 것
  • 곡면 \(z = f(x, y)\)의 접평면 방정식을 구한다.
  • 접평면으로 함숫값을 어림하고(선형근사), 전미분으로 오차를 어림한다.
먼저 알아야 할 것
  • 편도함수 (4.2절), 평면의 방정식 (1.2절), 일변수 선형근사 (공통1 2단원).

4.3.1접평면

일변수에서 곡선을 확대하면 접선처럼 보였듯이, 매끄러운 곡면을 한 점 근처에서 크게 확대하면 평면처럼 보입니다. 그 평면이 접평면입니다. 접평면은 \(x\) 방향 기울기 \(f_x\)와 \(y\) 방향 기울기 \(f_y\)를 함께 가져야 하므로

정리 4.3.1

곡면 \(z = f(x, y)\)의 점 \((a, b, f(a, b))\)에서의 접평면은

\[z = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b).\]
예제 4.3.2

\(z = 2x^2 + y^2\)의 점 \((1, 1, 3)\)에서 접평면을 구하여라.

풀이. \(f_x = 4x = 4\), \(f_y = 2y = 2\). \(z = 3 + 4(x - 1) + 2(y - 1)\), 곧 \(z = 4x + 2y - 3\).

4.3.2선형근사

점 근처에서는 곡면 대신 접평면의 값을 써서 어림할 수 있습니다.

\[f(x, y) \approx f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b).\]

예제 4.3.2에서 \(f(1.1, 0.95) \approx 3 + 4(0.1) + 2(-0.05) = 3.3\). 실제 값은 \(2.42 + 0.9025 = 3.3225\)로 가깝습니다.

편도함수가 있다고 해서 접평면이 있는 것은 아닙니다. 접평면으로 잘 근사되는 함수를 "미분 가능"하다고 하며, 편도함수가 연속이면 미분 가능합니다. 4.1절의 \(\frac{xy}{x^2 + y^2}\)(원점에서 0으로 정의)은 원점에서 편도함수가 모두 0이지만 연속조차 아닙니다.

4.3.3전미분과 오차

\(x, y\)가 \(dx, dy\)만큼 변할 때 \(z\)의 변화를 어림한 \(dz = f_x\,dx + f_y\,dy\)를 전미분이라 합니다. 측정 오차가 결과에 얼마나 영향을 주는지 어림하는 데 씁니다.

예제 4.3.3

원기둥의 반지름을 10 cm, 높이를 25 cm로 쟀는데 각각 최대 0.1 cm의 오차가 있다. 부피 \(V = \pi r^2h\)의 최대 오차를 어림하여라.

풀이. \(dV = 2\pi rh\,dr + \pi r^2\,dh = 2\pi(250)(0.1) + \pi(100)(0.1) = 60\pi \approx 188\) cm³. 전체 부피 \(2500\pi\)의 약 2.4%입니다. 반지름의 오차가 높이의 오차보다 다섯 배 크게 작용합니다.

요약
  1. 접평면 \(z = f(a, b) + f_x(x - a) + f_y(y - b)\).
  2. 근처의 값은 접평면으로 어림한다. 전미분 \(dz = f_xdx + f_ydy\)로 오차를 어림한다.

4.3.4연습문제

기본

  1. \(z = xy\)의 점 \((2, 3, 6)\)에서 접평면은?
    답

    \(z = 6 + 3(x - 2) + 2(y - 3) = 3x + 2y - 6\).

  2. \(f = \sqrt{x^2 + y^2}\)으로 \(\sqrt{3.02^2 + 3.97^2}\)을 어림하여라. (점 \((3, 4)\))
    답

    \(f_x = \frac35\), \(f_y = \frac45\). \(5 + 0.6(0.02) + 0.8(-0.03) = 4.988\).
