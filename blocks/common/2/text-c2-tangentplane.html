접평면과 선형근사

본문

곡선을 한 점 근처에서 확대하면 접선처럼 보였다. 그렇다면 곡면을 한 점 근처에서 확대하면 평면처럼 보일까? 그 평면을 알면 \(f(1.1, 0.95)\) 같은 값을 계산기 없이 어림할 수 있을까?

먼저 알아야 할 것편도함수(4.2절), 평면의 방정식(1.2절), 일변수 선형근사(미분적분학(1) 2.5절)를 쓴다.

4.3.1접평면

일변수에서 곡선을 확대하면 접선처럼 보였듯이, 매끄러운 곡면을 한 점 근처에서 크게 확대하면 평면처럼 보인다. 그 평면이 접평면이다. 그런데 평면은 기울기 두 개로 정해진다. 접평면은 곡면과 같은 \(x\) 방향 기울기 \(f_x\)와 \(y\) 방향 기울기 \(f_y\)를 함께 가져야 하므로 다음과 같다.

정리 4.3.1

곡면 \(z = f(x, y)\)의 점 \((a, b, f(a, b))\)에서의 접평면은

\[z = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b).\]

식에서 \(y = b\)로 두면 \(z = f(a, b) + f_x(a, b)(x - a)\)가 남는데, 이것은 단면 곡선의 접선이다. \(x = a\)로 두어도 마찬가지이다. 즉 접평면은 두 단면의 접선을 모두 품는 평면이다.

예제 4.3.2

\(z = 2x^2 + y^2\)의 점 \((1, 1, 3)\)에서 접평면을 구하여라.

풀이. \(f_x = 4x = 4\), \(f_y = 2y = 2\)이므로 접평면은 \(z = 3 + 4(x - 1) + 2(y - 1)\), 곧 \(z = 4x + 2y - 3\)이다.

4.3.2선형근사

점 근처에서는 곡면 대신 접평면의 값을 써서 어림할 수 있다. 이것이 이변수의 선형근사이다.

\[f(x, y) \approx f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)\]

처음 질문의 값을 예제 4.3.2로 어림하면 \(f(1.1, 0.95) \approx 3 + 4(0.1) + 2(-0.05) = 3.3\)이다. 실제 값은 \(2.42 + 0.9025 = 3.3225\)로 가깝다. 그림 1에서 범위 \(w\)를 1.2에서 0.1로 줄이면, 처음에는 곡면이 접평면 위로 휘어 올라간 것이 보이다가 곧 두 그물을 구별하기 어려워진다. 곡면이 접평면보다 위에 있으므로 어림값 3.3이 실제보다 조금 작게 나온 것도 그림과 맞는다.

편도함수가 있다고 해서 접평면이 있는 것은 아니다. 접평면으로 잘 근사되는 함수를 미분 가능하다고 하며, 편도함수가 연속이면 미분 가능하다. 4.1절의 \(\frac{xy}{x^2 + y^2}\)(원점에서 0으로 정의)은 원점에서 편도함수가 모두 0이지만 연속조차 아니다.

4.3.3전미분과 오차

\(x, y\)가 \(dx, dy\)만큼 변할 때 \(z\)의 변화를 어림한 \(dz = f_x\,dx + f_y\,dy\)를 전미분이라 한다. 미분적분학(1)의 \(dy = f'(x)dx\)에 변수가 하나 더해진 것이고, 측정 오차가 결과에 얼마나 영향을 주는지 어림하는 데 쓴다.

예제 4.3.3

원기둥의 반지름을 10 cm, 높이를 25 cm로 쟀는데 각각 최대 0.1 cm의 오차가 있다. 부피 \(V = \pi r^2h\)의 최대 오차를 어림하여라.

풀이. \(dV = 2\pi rh\,dr + \pi r^2\,dh = 2\pi(250)(0.1) + \pi(100)(0.1) = 60\pi \approx 188\) cm³이고, 이는 전체 부피 \(2500\pi\)의 약 2.4%이다. 두 항을 비교하면 반지름의 오차가 높이의 오차보다 다섯 배 크게 작용한다. 부피가 반지름의 제곱에 비례하고, 이 원기둥은 반지름에 비해 높이도 크기 때문이다. 그러므로 부피를 정확히 구하려면 반지름을 더 정밀하게 재야 한다.

마무리

매끄러운 곡면은 한 점 근처에서 접평면 \(z = f(a, b) + f_x(x - a) + f_y(y - b)\)와 거의 같으므로, 처음 질문의 \(f(1.1, 0.95)\)는 접평면의 값 3.3으로 어림된다. 같은 생각을 변화량으로 쓴 전미분 \(dz = f_x\,dx + f_y\,dy\)는 여러 측정값의 오차가 결과에 미치는 영향을 어림하게 해 준다.

4.3.4연습문제

기본

  1. \(z = xy\)의 점 \((2, 3, 6)\)에서 접평면은?
    답

    \(z = 6 + 3(x - 2) + 2(y - 3) = 3x + 2y - 6\).

  2. \(f = \sqrt{x^2 + y^2}\)으로 \(\sqrt{3.02^2 + 3.97^2}\)을 어림하여라. (점 \((3, 4)\))
    답

    \(f_x = \frac35\), \(f_y = \frac45\). \(5 + 0.6(0.02) + 0.8(-0.03) = 4.988\).
