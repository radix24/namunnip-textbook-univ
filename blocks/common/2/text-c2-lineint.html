선적분

본문
이 절에서 배울 것
  • 곡선을 따라 함수를 적분한다(철사의 질량 등).
  • 곡선을 따라 벡터장을 적분해 힘이 한 일을 구한다.
먼저 알아야 할 것
  • 곡선의 길이 (3.3절), 벡터장 (7.1절), 일 = 힘 × 거리 (고교 통합과학).

7.2.1함수의 선적분

휘어진 철사의 밀도가 위치에 따라 \(f(x, y)\)이면, 철사를 잘게 나누어 (밀도) × (조각의 길이 \(\Delta s\))를 더한 것이 질량입니다. 그 극한을 \(\int_Cf\,ds\)라 씁니다. 곡선을 \(\mathbf r(t)\), \(a \le t \le b\)로 매개화하면 \(ds = |\mathbf r'(t)|\,dt\)이므로

\[\int_Cf\,ds = \int_a^bf(\mathbf r(t))\,|\mathbf r'(t)|\,dt.\]
예제 7.2.1

\(C\)가 단위원의 위쪽 반일 때 \(\int_C(2 + x^2y)\,ds\)를 구하여라.

풀이. \(\mathbf r = \langle\cos t, \sin t\rangle\), \(0 \le t \le \pi\), \(|\mathbf r'| = 1\).

\[\int_0^\pi(2 + \cos^2t\sin t)\,dt = 2\pi + \left[-\frac{\cos^3t}{3}\right]_0^\pi = 2\pi + \frac23.\]

7.2.2벡터장의 선적분과 일

힘 \(\mathbf F\)를 받으며 곡선을 따라 움직일 때, 작은 변위 \(d\mathbf r\) 동안 힘이 한 일은 진행 방향 성분만 셈하므로 \(\mathbf F\cdot d\mathbf r\)입니다. 이것을 모두 더한 것이 일입니다.

정의 7.2.2 (벡터장의 선적분) \[W = \int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt.\]

성분으로 쓰면 \(\int_CP\,dx + Q\,dy + R\,dz\)입니다. 힘이 진행 방향과 수직이면(원운동의 구심력) 일은 0이고, 반대 방향이면 음수입니다.

예제 7.2.3

힘 \(\mathbf F = \langle x^2, -xy\rangle\)이 단위원 위를 \((1, 0)\)에서 \((0, 1)\)까지 움직이는 입자에 한 일을 구하여라.

풀이. \(\mathbf r = \langle\cos t, \sin t\rangle\), \(0 \le t \le \frac\pi2\), \(\mathbf r' = \langle-\sin t, \cos t\rangle\).

\[\mathbf F\cdot\mathbf r' = -\cos^2t\sin t - \cos^2t\sin t = -2\cos^2t\sin t.\] \[W = \int_0^{\pi/2}-2\cos^2t\sin t\,dt = \left[\frac23\cos^3t\right]_0^{\pi/2} = -\frac23.\]

7.2.3방향

  • \(\int_Cf\,ds\)는 곡선의 방향과 무관하다 (길이는 음수가 아님).
  • \(\int_C\mathbf F\cdot d\mathbf r\)는 방향을 바꾸면 부호가 바뀐다. 거꾸로 가면 일의 부호가 반대.
  • 값은 매개화 방법(속력)과 무관하고 곡선과 방향에만 의존한다.
요약
  1. \(\int_Cf\,ds = \int f(\mathbf r(t))|\mathbf r'|\,dt\).
  2. \(\int_C\mathbf F\cdot d\mathbf r = \int\mathbf F(\mathbf r(t))\cdot\mathbf r'\,dt\) = 일. 방향을 바꾸면 부호가 바뀐다.

7.2.4연습문제

기본

  1. \(C\): \((0, 0)\)에서 \((1, 1)\)까지의 선분. \(\int_C(x + y)\,ds\)는?
    답

    \(\mathbf r = \langle t, t\rangle\), \(|\mathbf r'| = \sqrt2\). \(\int_0^12t\sqrt2\,dt = \sqrt2\).

  2. 같은 선분에서 \(\int_Cy\,dx + x\,dy\)는?
    답

    \(\int_0^1(t + t)\,dt = 1\).
