중적분의 좌표계는 경계의 모양으로 고르고, 부피 요소를 함께 바꾼다

요령 · 좌표계 고르기

언제 쓰는가

원, 원기둥, 구, 원뿔이 경계에 있는 영역의 넓이, 부피, 질량을 구할 때입니다. 직교좌표로 끝값을 쓰면 근호가 겹겹이 생기는 문제가 신호입니다.

요령

  1. 경계의 모양을 읽는다
    \(x^2 + y^2\)이 보이면 극좌표나 원기둥좌표, \(x^2 + y^2 + z^2\)과 원뿔이면 구면좌표, \(xy = c\), \(y = kx\) 같은 곡선 쌍이면 새 변수 \(u, v\)를 생각합니다.
  2. 요소를 함께 바꾼다
    \(dA = r\,dr\,d\theta\), \(dV = r\,dz\,dr\,d\theta\), \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\), 일반 변환은 \(|J|\,du\,dv\)입니다.
  3. 끝값이 상수가 되는지 본다
    새 좌표에서 영역이 '직사각형'(끝값이 상수이거나 단순한 식)이 되면 좌표를 잘 고른 것입니다.
  4. 단위로 검산
    넓이는 길이의 제곱, 부피는 세제곱이어야 합니다. \(r\)을 빠뜨리면 차원이 하나 모자랍니다.

흔한 실수

  • 극좌표로 바꾸면서 \(r\)을 빠뜨리는 것. 반지름 3인 원판의 넓이가 \(6\pi\)로 나오면 이 실수입니다.
  • 구면좌표에서 \(\phi\)의 범위를 \(0\)부터 \(2\pi\)까지로 잡는 것. \(\phi\)는 \(0\)부터 \(\pi\)까지입니다.

바로 풀어보기

구 \(x^2 + y^2 + z^2 \le 4\) 안쪽이면서 원기둥 \(x^2 + y^2 \le 1\) 바깥쪽인 입체의 부피를 구하세요.

답과 풀이

답: \(4\sqrt3\,\pi \approx 21.77\)

원기둥 경계가 있으므로 원기둥좌표를 씁니다. 영역은 \(1 \le r \le 2\), \(-\sqrt{4 - r^2} \le z \le \sqrt{4 - r^2}\), \(0 \le \theta \le 2\pi\)로 끝값이 단순합니다.

\[V = \int_0^{2\pi}\int_1^2 2\sqrt{4 - r^2}\,r\,dr\,d\theta = 2\pi\Big[-\tfrac23(4 - r^2)^{3/2}\Big]_1^2 = 2\pi\cdot\tfrac23\cdot3\sqrt3 = 4\sqrt3\,\pi.\]

검산: 구 전체 \(\frac{32\pi}{3} \approx 33.5\)에서 원기둥 안쪽 부분(약 11.7)을 뺀 값으로, 0보다 크고 구보다 작습니다.

이 요령으로 풀리는 문제

  • 중적분 단원 연습 2번, 3번, 5번, 8번
영상 콘티 · 55초
  1. 0~6초구 안에 원기둥 구멍이 뚫린 입체(구슬 모양)가 돌아갑니다.이 입체의 부피, 어떤 좌표로 구할까요?
  2. 6~15초\(x, y, z\) 직교좌표 끝값이 \(\sqrt{4 - x^2 - y^2}\), \(\sqrt{1 - x^2}\) 같은 근호로 겹겹이 쌓이다 무너집니다.직교좌표로는 끝값이 복잡합니다.
  3. 15~24초경계 식의 \(x^2 + y^2\)이 빛나며 \(r^2\)으로 바뀌고, 좌표축이 원기둥좌표 \((r, \theta, z)\)로 돌아섭니다.경계의 모양으로 좌표를 고릅니다.
  4. 24~34초작은 상자 하나가 확대되어 가로 \(dr\), 세로 \(r\,d\theta\), 높이 \(dz\)로 치수가 붙습니다. \(r\,d\theta\)의 \(r\)이 빨갛게 강조됩니다.부피 요소 \(r\,dz\,dr\,d\theta\), \(r\)을 잊지 않습니다.
  5. 34~44초입체가 \(r\)–\(z\) 평면의 단면으로 펼쳐져 \(1 \le r \le 2\) 사이의 반원 띠가 됩니다.끝값이 단순해지면 잘 고른 것입니다.
  6. 44~55초반지름 3인 원판 위에 \(6\pi\)와 \(9\pi\)가 나란히 뜨고, \(6\pi\) 옆에 '단위: 길이' 표시가, \(9\pi\) 옆에 '단위: 길이²' 표시가 붙습니다.\(r\)을 빠뜨리면 단위부터 틀립니다.
