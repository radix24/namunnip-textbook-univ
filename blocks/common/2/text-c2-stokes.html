스토크스 정리

본문

그린 정리는 평면 영역 안의 소용돌이를 모두 더하면 경계를 도는 양이 된다고 말했다. 그런데 경계는 그대로 두고 그 안의 막을 비눗방울처럼 부풀리면 어떻게 될까? 막 위의 소용돌이를 더한 값도 바뀔까?

먼저 알아야 할 것그린 정리(7.4절), 회전(7.5절), 선속(8.2절)을 쓴다.

8.3.1정리

그린 정리에서 영역을 작은 정사각형으로 나누었던 생각은 휘어진 곡면에서도 그대로 통한다. 곡면을 작은 조각으로 나누어 각 조각의 경계를 같은 방향으로 돌면, 이웃한 조각이 함께 쓰는 변은 지워지고 곡면 전체의 경계만 남는다. 또 작은 조각 하나를 도는 양은 회전의 법선 성분 \((\nabla\times\mathbf F)\cdot\mathbf n\)에 넓이를 곱한 것이다.

정리 8.3.1 (스토크스 정리)

방향이 정해진 곡면 \(S\)의 경계가 곡선 \(C\)이면

\[\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S.\]

여기서 두 방향은 오른손 법칙으로 맞춘다. 오른손 엄지를 법선 \(\mathbf n\) 방향으로 두면 나머지 손가락이 감기는 방향이 \(C\)의 방향이다. 곡면이 평면 영역이고 \(\mathbf n = \mathbf k\)이면 \((\nabla\times\mathbf F)\cdot\mathbf k = Q_x - P_y\)이므로 그린 정리가 된다. 즉 스토크스 정리는 그린 정리를 휘어진 곡면으로 넓힌 것이고, 곡면 위 소용돌이의 합이 경계를 도는 양(순환)과 같다는 뜻도 같다.

8.3.2예제

예제 8.3.2

\(\mathbf F = \langle-y^2, x, z^2\rangle\), \(C\)는 평면 \(y + z = 2\)와 원기둥 \(x^2 + y^2 = 1\)의 교선(위에서 볼 때 시계 반대 방향)이다. \(\oint_C\mathbf F\cdot d\mathbf r\)를 구하여라.

풀이. 먼저 \(\nabla\times\mathbf F = \langle0, 0, 1 + 2y\rangle\)이다. \(C\)를 경계로 하는 곡면으로 평면 \(z = 2 - y\)에서 원기둥 안쪽 부분(타원판)을 고르고 위쪽 법선을 쓴다. 그래프 \(z = g(x, y)\)에서 \(\mathbf r_x\times\mathbf r_y = \langle-g_x, -g_y, 1\rangle = \langle0, 1, 1\rangle\)이므로 다음을 얻는다.

\[\iint_D\langle0, 0, 1 + 2y\rangle\cdot\langle0, 1, 1\rangle\,dA = \iint_D(1 + 2y)\,dA = \pi + 0 = \pi\]

여기서 \(D\)는 단위원판이고, \(\iint_D2y\,dA = 0\)은 위아래 대칭에서 나온다. 교선을 직접 매개화해 적분하는 것보다 간단하다.

예제 8.3.3

\(\mathbf F = \langle-y, x, 0\rangle\)에 대해, 단위 반구면 \(z \ge 0\)(바깥쪽)을 지나는 \(\nabla\times\mathbf F\)의 선속을 구하여라.

풀이. 경계는 \(xy\)평면의 단위원이다. 스토크스 정리에 따라 구하는 선속은 선적분 \(\oint(-y\,dx + x\,dy)\)이고, 이것은 7.4절의 넓이 공식으로 원의 넓이의 두 배인 \(2\pi\)이다. 경계가 같은 평평한 원판에서 \(\nabla\times\mathbf F = \langle0, 0, 2\rangle\)를 적분해도 \(2 \times \pi = 2\pi\)이다. 그림 1에서 \(h\)를 바꾸며 확인하듯이, 경계가 같으면 곡면 모양은 상관없다. 처음 질문의 답이 이것이다. 따라서 계산할 때는 경계가 같은 곡면 가운데 가장 쉬운 것을 고르면 된다.

마무리

스토크스 정리 \(\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S\)는 곡면 위 회전의 선속을 경계를 도는 순환으로 바꾸며, 두 방향은 오른손 법칙으로 맞춘다. 곡면이 평면이면 그린 정리가 된다. 처음 질문처럼 막을 부풀려도 경계가 같으면 값이 같으므로, 계산하기 쉬운 곡면을 골라 쓴다.

8.3.3연습문제

기본

  1. 보존장 \(\mathbf F = \nabla f\)에 대해 \(\oint_C\mathbf F\cdot d\mathbf r = 0\)임을 스토크스 정리로 설명하여라.
    답

    \(\nabla\times\nabla f = \mathbf 0\)이므로 면적분이 0.

응용

  1. \(\mathbf F = \langle0, x, 0\rangle\), \(C\)는 \(xy\)평면의 반지름 2인 원(시계 반대 방향). 선적분은?
    답

    \(\nabla\times\mathbf F = \langle0, 0, 1\rangle\). 원판 넓이 \(4\pi\).
