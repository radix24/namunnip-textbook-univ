선속: 곡면을 뚫고 지나가는 양

F·n dS · 방향 정하기 · r_u × r_v

정의와 계산식

유체의 속도장 \(\mathbf F\)가 곡면 조각 \(dS\)를 매초 지나가는 부피는 \(\mathbf F\)의 법선 성분 × 넓이, 곧 \(\mathbf F\cdot\mathbf n\,dS\)입니다(접선 성분은 곡면을 따라 흐를 뿐 뚫지 않음). 이것을 더한 것이 선속이다.

\[\iint_S\mathbf F\cdot d\mathbf S = \iint_S\mathbf F\cdot\mathbf n\,dS = \iint_D\mathbf F(\mathbf r(u,v))\cdot(\mathbf r_u\times\mathbf r_v)\,du\,dv.\]

마지막 등호: \(\mathbf n = \frac{\mathbf r_u\times\mathbf r_v}{|\mathbf r_u\times\mathbf r_v|}\), \(dS = |\mathbf r_u\times\mathbf r_v|\,du\,dv\)라 크기가 소거된다. 계산할 때는 \(\mathbf r_u\times\mathbf r_v\)만 구하면 된다.

방향: 선속은 어느 쪽을 +로 셀지(\(\mathbf n\)의 방향) 먼저 정해야 한다. 닫힌 곡면은 관례상 바깥쪽. \(\mathbf r_u\times\mathbf r_v\)가 원하는 방향과 반대면 부호를 바꾼다. 그래프 \(z = g(x,y)\)의 위쪽 방향은 \((-g_x, -g_y, 1)\).

먼저 예측

\(\mathbf F = (x, y, z)\)가 구면을 지나는 선속은 구의 반지름을 2배로 하면 몇 배가 될까?

예측 확인

8배이다. 구면 위에서 \(\mathbf F\cdot\mathbf n = a\)이고 넓이가 \(4\pi a^2\)이라 선속이 \(4\pi a^3\), 반지름의 세제곱에 비례한다.

(가) \(\mathbf F = (x, y, z)\)가 반지름 \(a\)인 구면을 바깥쪽으로 지나는 선속 (나) \(\mathbf F = (0, 0, z)\)가 포물면 \(z = 1 - x^2 - y^2\), \(z \ge 0\)를 위쪽으로 지나는 선속

풀이

  1. (가) 구면 위에서 \(\mathbf n = \frac{(x,y,z)}{a}\)이므로 \(\mathbf F\cdot\mathbf n = \frac{x^2 + y^2 + z^2}{a} = a\).
    구면의 바깥 법선은 위치벡터 방향. 매개화가 필요 없다.
  2. 선속 \(= \iint_Sa\,dS = a\cdot4\pi a^2 = 4\pi a^3\).
    피적분함수가 상수.
  3. (나) \(\mathbf r = (x, y, 1 - x^2 - y^2)\), 위쪽 법선 \((-g_x, -g_y, 1) = (2x, 2y, 1)\).
    \(z\) 성분이 양수라 위쪽.
  4. \(\mathbf F\cdot(2x, 2y, 1) = z = 1 - x^2 - y^2\).
    \(\mathbf F\)의 \(x, y\) 성분이 0.
  5. \(\iint_{r\le1}(1 - r^2)\,r\,dr\,d\theta = 2\pi\left(\frac12 - \frac14\right) = \frac\pi2\).
    곡면의 그림자 \(D\)는 단위원판.

의미

선속은 곡면을 뚫고 나가는 알짜 흐름이다. 전자기학의 가우스 법칙은 "닫힌 곡면을 지나는 전기장의 선속 = 안의 전하 ÷ \(\varepsilon_0\)"로, 이 카드의 (가)와 같은 계산이 점전하의 전기장을 정한다.

검산

(가) 다음 카드의 발산 정리로: \(\nabla\cdot\mathbf F = 3\), 선속 \(= 3\cdot\frac43\pi a^3 = 4\pi a^3\). (나) 포물면과 밑면 원판이 둘러싼 입체에서 \(\nabla\cdot\mathbf F = 1\)이므로 전체 바깥 선속은 부피 \(\frac\pi2\). 밑면(\(z = 0\))에서는 \(\mathbf F = \mathbf 0\)이라 선속 0. 그러므로 포물면의 선속도 \(\frac\pi2\). 일치한다.

흔한 오해

  • 방향을 정하지 않음: 같은 곡면도 방향에 따라 부호가 바뀐다. 문제에서 방향을 먼저 확인한다.
  • 스칼라 면적분과 혼동: 선속은 \(|\mathbf r_u\times\mathbf r_v|\)가 아니라 \(\mathbf r_u\times\mathbf r_v\) 벡터와 내적한다.
