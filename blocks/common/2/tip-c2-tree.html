다변수 연쇄법칙은 나무 그림을 그리고 가지를 따라 곱해 더한다

요령 · 다변수 연쇄법칙

언제 쓰는가

\(z = f(x, y)\)이고 \(x, y\)가 다시 \(s, t\)의 함수인 것처럼 변수가 여러 층으로 얽혀 있을 때입니다. 항을 빠뜨리기 쉬운 문제에 씁니다.

요령

  1. 나무를 그린다
    맨 위에 구하려는 함수 \(z\), 가운데 줄에 중간 변수 \(x, y\), 맨 아래에 독립 변수 \(s, t\)를 놓고 의존 관계를 선으로 잇습니다.
  2. 가지에 이름표
    가지마다 위 변수를 아래 변수로 미분한 편도함수를 적습니다. \(z\)에서 \(x\)로 가는 가지는 \(\frac{\partial z}{\partial x}\)입니다.
  3. 길마다 곱한다
    \(z\)에서 목표 변수(예: \(s\))까지 가는 길을 모두 찾고, 길 위의 이름표를 곱합니다.
  4. 길들을 더한다
    \(\frac{\partial z}{\partial s} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial s} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial s}\)처럼, 길의 수만큼 항이 생깁니다.

흔한 실수

  • 한쪽 길만 따라가 항을 빠뜨리는 것. 목표 변수에 닿는 길이 몇 개인지 먼저 세어 둡니다.
  • 편도함수를 계산한 뒤 \(x, y\)에 해당 점의 값을 넣지 않고 \(s, t\)의 값을 그대로 넣는 것.

바로 풀어보기

\(z = x^2y + y^3\), \(x = st\), \(y = s + t\)일 때 \((s, t) = (1, 2)\)에서 \(\frac{\partial z}{\partial s}\)를 구하세요.

답과 풀이

답: 55

\((s, t) = (1, 2)\)에서 \(x = 2\), \(y = 3\)입니다. \(z_x = 2xy = 12\), \(z_y = x^2 + 3y^2 = 31\), \(x_s = t = 2\), \(y_s = 1\)입니다.

\(s\)로 가는 길은 \(z \to x \to s\)와 \(z \to y \to s\) 두 개이므로 \(\frac{\partial z}{\partial s} = 12\cdot2 + 31\cdot1 = 55\)입니다.

검산: \(z = s^2t^2(s + t) + (s + t)^3\)을 직접 미분하면 \(2st^2(s + t) + s^2t^2 + 3(s + t)^2 = 24 + 4 + 27 = 55\)입니다.

이 요령으로 풀리는 문제

  • 편도함수 단원 연습 4번, 5번
영상 콘티 · 45초
  1. 0~5초\(z = x^2y + y^3\), \(x = st\), \(y = s + t\) 세 식이 화면 위쪽에 놓입니다.\(\frac{\partial z}{\partial s}\), 항이 몇 개일까요?
  2. 5~13초맨 위 \(z\)에서 \(x\)와 \(y\)로 가지가 내려오고, 각각에서 다시 \(s\)와 \(t\)로 가지가 뻗어 나무가 자랍니다.먼저 나무를 그립니다.
  3. 13~21초가지마다 \(\frac{\partial z}{\partial x}\), \(\frac{\partial x}{\partial s}\) 같은 이름표가 매달립니다.가지에 편도함수 이름표를 답니다.
  4. 21~31초\(z\)에서 \(s\)까지 가는 두 길이 서로 다른 색으로 빛나고, 길 위의 이름표가 곱해져 아래로 떨어집니다.길마다 곱합니다.
  5. 31~38초두 곱이 덧셈 기호로 합쳐지고, 값 \(12\cdot2 + 31\cdot1 = 55\)가 채워집니다.길들을 더하면 끝입니다.
  6. 38~45초한 길만 빛나는 나무 옆에 '24'가 뜨고 빨간 X가 그어집니다.길을 하나 빠뜨리면 틀립니다.
