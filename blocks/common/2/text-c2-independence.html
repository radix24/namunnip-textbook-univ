일차결합과 일차독립

본문

공간의 세 벡터 \(\langle1, 2, 3\rangle\), \(\langle4, 5, 6\rangle\), \(\langle7, 8, 9\rangle\)은 서로 달라 보인다. 그런데 그중 하나가 나머지 둘로 만들어진다면, 세 벡터는 공간의 세 방향을 제대로 가리키지 못하는 것이 아닐까? 그것을 어떻게 알아낼까?

먼저 알아야 할 것벡터의 덧셈과 실수배(미분적분학(1) 9.2절), 행렬식과 부피(1.4절)를 쓴다.

이 단원은 대학 요람 개요의 "선형벡터 공간"에 해당하며 2026학년도 진도표에는 없다. 고등미적분학의 연립미분방정식과 2학년 전공의 선형대수를 읽기 위한 다리로 둔다.

2.1.1일차결합

벡터 \(\mathbf v_1, \dots, \mathbf v_k\)에 실수를 곱해 더한 \(c_1\mathbf v_1 + \cdots + c_k\mathbf v_k\)를 일차결합이라 한다. 가령 평면의 모든 벡터는 \(\langle a, b\rangle = a\mathbf i + b\mathbf j\)로 \(\mathbf i, \mathbf j\)의 일차결합이다. 일차결합으로 만들 수 있는 벡터의 범위가 넓을수록 처음 벡터들이 가리키는 방향이 다양하다는 뜻이다.

2.1.2일차독립

정의 2.1.1 (일차독립, 일차종속)

\(c_1\mathbf v_1 + \cdots + c_k\mathbf v_k = \mathbf 0\)이 되는 경우가 \(c_1 = \cdots = c_k = 0\)뿐이면 일차독립, 그렇지 않으면 일차종속이라 한다.

일차종속이면 0이 아닌 계수가 하나 있으므로, 그 벡터를 나머지의 일차결합으로 쓸 수 있다. 즉 쓸모없는 벡터가 끼어 있다는 뜻이다. 반대로 일차독립은 어느 벡터도 다른 벡터들로 만들어지지 않는다는 뜻이다.

그림으로 보면 판정이 쉬워진다. 두 벡터가 일차종속인 것은 평행할 때, 곧 한쪽이 다른 쪽의 실수배일 때이다. 공간의 세 벡터가 일차종속인 것은 한 평면 위에 있을 때이고, 1.4절에 따르면 이것은 세 벡터의 행렬식이 0일 때이다. 그림 1에서 \(h\)를 1에서 0으로 내리면 평행육면체의 부피가 줄어 0이 되는데, 그 순간 \(\mathbf w\)는 \(\mathbf u\)와 \(\mathbf v\)의 일차결합이 된다.

예제 2.1.2

다음 벡터들이 일차독립인지 판정하여라. (가) \(\langle1, 2\rangle, \langle2, 4\rangle\) (나) \(\langle1, 0, 1\rangle, \langle0, 1, 1\rangle, \langle1, 1, 0\rangle\) (다) \(\langle1, 2, 3\rangle, \langle4, 5, 6\rangle, \langle7, 8, 9\rangle\)

풀이. (가) 둘째가 첫째의 2배이므로 종속이다. (나) 행렬식이 \(1(0 - 1) - 0 + 1(0 - 1) = -2 \ne 0\)이므로 독립이다. (다) 행렬식이 0이므로 종속이고, 실제로 \(\mathbf v_1 - 2\mathbf v_2 + \mathbf v_3 = \mathbf 0\)이다. 처음 질문의 세 벡터가 바로 이것이다. 서로 달라 보여도 셋째가 \(2\mathbf v_2 - \mathbf v_1\)로 만들어지므로 세 벡터는 한 평면 위에 놓인다.

정의를 직접 쓰는 방법도 알아 두자. (나)에서 \(c_1\langle1, 0, 1\rangle + c_2\langle0, 1, 1\rangle + c_3\langle1, 1, 0\rangle = \mathbf 0\)이면 성분마다 \(c_1 + c_3 = 0\), \(c_2 + c_3 = 0\), \(c_1 + c_2 = 0\)이다. 셋을 더하면 \(c_1 + c_2 + c_3 = 0\)이고, 여기서 각 식을 빼면 \(c_1 = c_2 = c_3 = 0\)이다. 따라서 계수가 모두 0일 수밖에 없고, 행렬식으로 판정한 결과와 같다.

공간에서 네 개 이상의 벡터는 언제나 일차종속이다. 공간에는 서로 독립인 방향이 셋까지만 있기 때문이다(2.2절의 차원).

마무리

일차독립은 \(\sum c_j\mathbf v_j = \mathbf 0\)이 되는 경우가 모든 계수가 0일 때뿐이라는 뜻이고, 어느 벡터도 나머지로 만들어지지 않는다는 말과 같다. 벡터가 정사각 배열을 이루면 행렬식이 0이 아닌 것과 일차독립이 같으므로, 처음 질문의 세 벡터는 행렬식이 0이라 일차종속이고 한 평면 위에 납작하게 놓인다.

2.1.3연습문제

기본

  1. \(\langle1, 1\rangle, \langle1, -1\rangle\)은 일차독립인가?
    답

    행렬식 \(-1 - 1 = -2 \ne 0\). 독립.

  2. \(\langle1, 2, 3\rangle, \langle2, 4, 6\rangle\)은?
    답

    둘째가 첫째의 2배. 종속.

응용

  1. \(\langle1, 0, 0\rangle, \langle1, 1, 0\rangle, \langle1, 1, k\rangle\)이 일차종속이 되는 \(k\)는?
    답

    행렬식 \(= k = 0\). \(k = 0\).
