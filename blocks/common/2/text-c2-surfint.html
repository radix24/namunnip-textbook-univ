면적분과 선속

본문

강물 속에 그물을 펼쳐 두면 1초 동안 그물을 지나가는 물의 양은 그물을 어떻게 세우느냐에 따라 달라진다. 흐름을 정면으로 막으면 많이 지나가고, 흐름과 나란히 두면 하나도 지나가지 않는다. 휘어진 그물이라면 이 양을 어떻게 셀까?

먼저 알아야 할 것곡면의 넓이(8.1절)와 선적분(7.2절)을 쓴다.

8.2.1함수의 면적분

얇은 금속판의 밀도가 위치에 따라 \(f\)이면, 판을 잘게 나누어 (밀도) × (조각 넓이 \(\Delta S\))를 더한 것이 질량이다. 8.1절에서 \(dS = |\mathbf r_u\times\mathbf r_v|\,du\,dv\)였으므로 다음과 같이 계산한다.

\[\iint_Sf\,dS = \iint_Df(\mathbf r(u, v))\,|\mathbf r_u\times\mathbf r_v|\,du\,dv\]

7.2절의 선적분 \(\int_Cf\,ds\)를 곡면으로 옮긴 것이다.

예제 8.2.1

단위구면 \(S\)에서 \(\iint_Sx^2\,dS\)를 구하여라.

풀이. 구면은 세 축을 서로 바꾸어도 그대로이므로 \(\iint x^2\,dS = \iint y^2\,dS = \iint z^2\,dS\)이다. 그런데 구면 위에서 \(x^2 + y^2 + z^2 = 1\)이므로 셋의 합은 \(\iint1\,dS\), 곧 넓이 \(4\pi\)이다. 따라서 \(\iint_Sx^2\,dS = \frac{4\pi}{3}\)이다. 매개화하여 적분하지 않고 대칭만으로 구했다.

8.2.2벡터장의 선속

처음 질문의 그물을 생각하자. 1초 동안 그물을 지나는 물의 양은 흐름 가운데 그물에 수직인 성분만 센다. 그물과 나란한 성분은 그물을 스치고 지나갈 뿐이기 때문이다. 곡면의 단위법선벡터를 \(\mathbf n\)이라 하면, 작은 조각 \(\Delta S\)를 지나는 양은 \(\mathbf F\cdot\mathbf n\,\Delta S\)이다(그림 1). 이것을 모두 더한 것이 선속이다.

정의 8.2.2 (선속) \[\iint_S\mathbf F\cdot d\mathbf S = \iint_S\mathbf F\cdot\mathbf n\,dS = \iint_D\mathbf F(\mathbf r(u, v))\cdot(\mathbf r_u\times\mathbf r_v)\,du\,dv.\]

마지막 식은 \(\mathbf n\,dS = \frac{\mathbf r_u\times\mathbf r_v}{|\mathbf r_u\times\mathbf r_v|}|\mathbf r_u\times\mathbf r_v|\,du\,dv\)에서 크기가 지워진 결과이다. 그런데 \(\mathbf n\)의 방향은 앞과 뒤 두 가지가 있으므로 먼저 하나를 정해야 하고, 이것을 곡면의 방향이라 한다. 닫힌 곡면은 보통 바깥쪽을 양의 방향으로 한다. 방향을 반대로 하면 그림 1에서 \(\alpha\)가 \(180^\circ - \alpha\)로 바뀌는 것처럼 선속의 부호가 바뀐다. 전기장의 선속은 일반물리학(2)의 가우스 법칙에서 쓴다.

예제 8.2.3

\(\mathbf F = \langle z, y, x\rangle\)가 단위구면을 바깥쪽으로 지나는 선속을 구하여라.

풀이. 단위구면의 바깥쪽 단위법선은 위치벡터 자신 \(\mathbf n = \langle x, y, z\rangle\)이다. 따라서 \(\mathbf F\cdot\mathbf n = zx + y^2 + xz = 2xz + y^2\)이다. 이때 \(\iint2xz\,dS = 0\)이다. \(x\)를 \(-x\)로 바꾸면 구면은 그대로이고 \(2xz\)는 부호만 바뀌어 서로 지워지기 때문이다. 또 \(\iint y^2\,dS = \frac{4\pi}{3}\)은 예제 8.2.1과 같다. 그러므로 선속은 \(\frac{4\pi}{3}\)이다. 8.4절에서 발산 정리로 이 값을 한 줄에 다시 구한다.

마무리

함수의 면적분은 \(\iint_Sf\,dS = \iint f\,|\mathbf r_u\times\mathbf r_v|\,du\,dv\)로 계산한다. 처음 질문의 그물을 지나는 양은 흐름의 법선 성분만 세는 선속 \(\iint\mathbf F\cdot\mathbf n\,dS = \iint\mathbf F\cdot(\mathbf r_u\times\mathbf r_v)\,du\,dv\)이다. 법선의 방향을 먼저 정해야 하며, 방향을 뒤집으면 부호가 바뀐다.

8.2.3연습문제

기본

  1. \(\mathbf F = \langle0, 0, 3\rangle\)이 \(xy\)평면의 단위정사각형을 위쪽으로 지나는 선속은?
    답

    \(\mathbf n = \mathbf k\), \(\mathbf F\cdot\mathbf n = 3\). 선속 3.

  2. \(\mathbf F = \langle x, y, z\rangle\)이 반지름 \(a\)인 구면을 바깥쪽으로 지나는 선속은?
    답

    \(\mathbf F\cdot\mathbf n = a\). \(a\cdot4\pi a^2 = 4\pi a^3\).
