라그랑주 승수법은 두 식을 나눠서 \(\lambda\)부터 지운다

요령 · 라그랑주 승수법

언제 쓰는가

원, 타원, 평면 같은 조건 \(g(x, y) = c\) 위에서 \(f\)의 최댓값과 최솟값을 구하는 문제이다. 연립방정식이 풀리지 않아 막힐 때 쓴다.

요령

  1. 식을 세운다
    \(f_x = \lambda g_x\), \(f_y = \lambda g_y\), \(g = c\)의 세 식, 미지수 \(x, y, \lambda\) 셋이다.
  2. 나눠서 \(\lambda\)를 지운다
    앞의 두 식을 변끼리 나누거나 둘 다 \(\lambda\)로 풀어 같게 놓으면 \(x\)와 \(y\)만의 관계식이 나온다. 나누기 전에 분모가 0인 경우를 따로 확인한다.
  3. 조건에 넣는다
    관계식을 \(g = c\)에 넣어 후보 점을 모두 구한다.
  4. 값을 비교한다
    후보마다 \(f\)를 계산해 가장 큰 값과 작은 값을 고른다. 조건이 닫힌 곡선이면 둘 다 반드시 있다.

흔한 실수

  • 나눌 때 \(x = 0\)이나 \(y = 0\)인 경우를 빠뜨려 후보를 놓치는 것.
  • 구한 \(\lambda\) 값을 최댓값이라고 답하는 것. 답은 \(f\)의 값이다.

바로 풀어보기

타원 \(x^2 + 2y^2 = 6\) 위에서 \(f(x, y) = xy\)의 최댓값과 최솟값을 구하여라.

답과 풀이

답: 최댓값 \(\frac{3\sqrt2}{2}\), 최솟값 \(-\frac{3\sqrt2}{2}\)

\(y = 2\lambda x\), \(x = 4\lambda y\)이다. \(x = 0\)이면 \(y = 0\)이 되어 조건을 만족하지 않으므로 \(x, y \ne 0\)이고, 두 식을 변끼리 나누면 \(\frac yx = \frac{x}{2y}\), 곧 \(x^2 = 2y^2\)이다.

조건에 넣으면 \(4y^2 = 6\), \(y^2 = \frac32\), \(x^2 = 3\)이다. \(xy = \pm\sqrt3\sqrt{\tfrac32} = \pm\frac{3}{\sqrt2}\)이므로 최댓값 \(\frac{3\sqrt2}{2} \approx 2.12\), 최솟값은 그 음수이다.

이 요령으로 풀리는 문제

  • 최댓값과 최솟값 단원 연습 4번, 5번, 6번, 7번
영상 콘티 · 50초
  1. 0~6초타원 \(x^2 + 2y^2 = 6\)과 쌍곡선 모양의 등위선 \(xy = k\) 여러 개가 함께 그려진다.타원 위에서 \(xy\)가 가장 큰 곳은?
  2. 6~15초\(k\)가 커지며 등위선이 바깥으로 밀려 나가다가 타원에 딱 닿는 순간 멈춘다. 닿는 점에서 두 곡선의 기울기 화살표가 같은 방향으로 겹친다.등위선이 조건에 접하는 곳이 답이다.
  3. 15~23초겹친 화살표가 \(\nabla f = \lambda\nabla g\)로 바뀌고, 성분 식 두 줄 \(y = 2\lambda x\), \(x = 4\lambda y\)가 나타난다.이것이 라그랑주 식이다.
  4. 23~33초두 식이 위아래로 겹쳐져 변끼리 나뉘고, \(\lambda\)가 양쪽에서 지워지며 \(x^2 = 2y^2\)만 남는다.나눠서 \(\lambda\)를 지운다.
  5. 33~42초\(x^2 = 2y^2\)이 두 직선으로 그려져 타원과 네 점에서 만나고, 각 점에 \(xy\) 값이 붙는다.조건에 넣어 후보를 구한다.
  6. 42~50초나누기 전 장면으로 돌아가 '\(x = 0\)이면?' 물음표가 뜨고, \(x = 0\)이 조건을 만족하지 않아 사라지는 모습이 나온다.나누기 전에 0인 경우를 꼭 확인한다.
