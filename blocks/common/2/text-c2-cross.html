본문
이 절에서 배울 것
  • 두 벡터에 동시에 수직인 벡터를 외적으로 구한다.
  • 외적의 크기가 평행사변형의 넓이임을 알고, 넓이와 돌림힘 계산에 쓴다.
먼저 알아야 할 것
  • 벡터의 성분과 크기 (공통1 9.2절), 내적과 사잇각 (9.3절).

1.1.1정의

내적은 두 벡터에서 수 하나를 만들었습니다. 외적은 두 벡터에서 새 벡터를 만듭니다. 먼저 계산에 쓸 기호 하나를 정합니다. 네 수를 정사각형으로 배열한 것에 대해

\[\begin{vmatrix}a & b\\ c & d\end{vmatrix} = ad - bc\]

로 약속합니다(이것을 2차 행렬식이라 하며, 1.4절에서 자세히 다룹니다).

정의 1.1.1 (외적)

\(\mathbf a = \langle a_1, a_2, a_3\rangle\), \(\mathbf b = \langle b_1, b_2, b_3\rangle\)일 때

\[\mathbf a\times\mathbf b = \langle a_2b_3 - a_3b_2,\ a_3b_1 - a_1b_3,\ a_1b_2 - a_2b_1\rangle.\]

외우는 요령: 첫째 성분은 \(\mathbf a, \mathbf b\)에서 첫째 성분을 가리고 남은 \(\begin{vmatrix}a_2 & a_3\\ b_2 & b_3\end{vmatrix}\), 둘째 성분은 둘째를 가리고 남은 것에 부호를 바꾼 것, 셋째 성분은 셋째를 가리고 남은 것입니다.

예제 1.1.2

\(\mathbf a = \langle1, 3, 4\rangle\), \(\mathbf b = \langle2, 7, -5\rangle\)일 때 \(\mathbf a\times\mathbf b\)를 구하고, 이것이 \(\mathbf a\)에 수직임을 확인하여라.

풀이.

  • 첫째: \(3\cdot(-5) - 4\cdot7 = -43\).
  • 둘째: \(4\cdot2 - 1\cdot(-5) = 13\).
  • 셋째: \(1\cdot7 - 3\cdot2 = 1\).

\(\mathbf a\times\mathbf b = \langle-43, 13, 1\rangle\). 내적 \(\langle1, 3, 4\rangle\cdot\langle-43, 13, 1\rangle = -43 + 39 + 4 = 0\)이므로 수직입니다.

1.1.2기하학적 뜻

정리 1.1.3
  1. \(\mathbf a\times\mathbf b\)는 \(\mathbf a\)와 \(\mathbf b\)에 모두 수직이다.
  2. 방향은 오른손 법칙: 오른손 네 손가락을 \(\mathbf a\)에서 \(\mathbf b\) 쪽으로 감을 때 엄지가 가리키는 쪽.
  3. 크기는 \(|\mathbf a\times\mathbf b| = |\mathbf a||\mathbf b|\sin\theta\) (\(\theta\)는 사잇각). 곧 \(\mathbf a, \mathbf b\)가 만드는 평행사변형의 넓이.

여기서 바로 나오는 사실들이 있습니다.

  • 두 벡터가 평행하면(\(\theta = 0\) 또는 \(\pi\)) 외적은 \(\mathbf 0\).
  • 순서를 바꾸면 방향이 반대: \(\mathbf b\times\mathbf a = -\mathbf a\times\mathbf b\). 곱셈의 교환법칙이 성립하지 않는다.
  • \(\mathbf i\times\mathbf j = \mathbf k\), \(\mathbf j\times\mathbf k = \mathbf i\), \(\mathbf k\times\mathbf i = \mathbf j\).
예제 1.1.4

세 점 \(P(1, 4, 6)\), \(Q(-2, 5, -1)\), \(R(1, -1, 1)\)을 꼭짓점으로 하는 삼각형의 넓이를 구하여라.

풀이. \(\overrightarrow{PQ} = \langle-3, 1, -7\rangle\), \(\overrightarrow{PR} = \langle0, -5, -5\rangle\).

\[\overrightarrow{PQ}\times\overrightarrow{PR} = \langle-40, -15, 15\rangle.\]

크기는 \(\sqrt{1600 + 225 + 225} = \sqrt{2050} = 5\sqrt{82}\). 삼각형은 평행사변형의 절반이므로 넓이는 \(\frac{5\sqrt{82}}{2} \approx 22.6\).

예제 1.1.5 (돌림힘)

길이 0.25 m인 렌치 끝에 렌치와 75°를 이루는 방향으로 40 N의 힘을 준다. 돌림힘의 크기는?

풀이. 물리에서 돌림힘은 \(\boldsymbol\tau = \mathbf r\times\mathbf F\)입니다. 크기 \(0.25\cdot40\cdot\sin75^\circ \approx 9.66\) N·m. 힘이 렌치에 수직일 때(\(\sin90^\circ = 1\)) 가장 크고, 렌치 방향으로 밀면 0입니다.

요약
  1. \(\mathbf a\times\mathbf b\)는 \(\mathbf a, \mathbf b\) 모두에 수직, 오른손 법칙 방향.
  2. \(|\mathbf a\times\mathbf b| = |\mathbf a||\mathbf b|\sin\theta\) = 평행사변형 넓이.
  3. \(\mathbf b\times\mathbf a = -\mathbf a\times\mathbf b\). 평행이면 \(\mathbf 0\).

1.1.3연습문제

기본

  1. \(\langle1, 0, 0\rangle\times\langle1, 1, 0\rangle\)을 구하여라.
    답

    \(\langle0, 0, 1\rangle\).

  2. \(\langle1, 2, 0\rangle\)과 \(\langle0, 1, 2\rangle\)이 만드는 평행사변형의 넓이는?
    답

    외적 \(\langle4, -2, 1\rangle\), 넓이 \(\sqrt{21}\).

응용

  1. \(\mathbf a\times\mathbf a = \mathbf 0\)임을 정의와 기하학적 뜻 두 가지로 설명하여라.
    답

    정의: 각 성분이 \(a_2a_3 - a_3a_2 = 0\) 꼴. 기하: 사잇각 0이라 \(\sin0 = 0\).
