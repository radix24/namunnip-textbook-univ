라그랑주 승수법

본문

원 \(x^2 + y^2 = 1\) 위를 걸으면서 \(f = x^2 + 2y^2\)의 값을 잰다면, 어디서 가장 크고 어디서 가장 작을까? 조건이 붙은 최대·최소를 등위선 그림 하나로 풀 수 있을까?

먼저 알아야 할 것기울기 벡터와 등위선(4.5절), 닫힌 영역의 최대·최소(5.2절)를 쓴다.

5.3.1생각

"재료 12 m²로 뚜껑 없는 상자를 만들 때 부피를 최대로"처럼, 변수들이 어떤 조건 \(g(x, y) = k\)를 만족하며 움직일 때의 최대·최소를 구하는 문제가 많다.

조건 곡선 \(g = k\)를 따라 걸으며 \(f\)의 등위선을 지나간다고 생각해 보자. 등위선을 가로지르는 동안은 \(f\)가 계속 커지거나 작아진다. 그러므로 \(f\)가 최대나 최소가 되는 곳은 조건 곡선이 등위선을 가로지르지 않고 살짝 접하는 곳이다. 그림 1에서 \(c\)를 1.5에 두면 타원이 원을 네 점에서 가로지르는데, 이것은 원 위에 \(f = 1.5\)보다 큰 곳과 작은 곳이 모두 있다는 뜻이다. 그런데 두 곡선이 접하면 법선이 평행하고, 4.5절에 따르면 법선은 기울기 벡터이므로 다음 방법이 나온다.

정리 5.3.1 (라그랑주 승수법)

\(g(x, y) = k\) 위에서 \(f\)의 최댓값·최솟값은 다음을 만족하는 점에서 나타난다(\(\nabla g \ne \mathbf 0\)).

\[\nabla f = \lambda\nabla g, \qquad g(x, y) = k.\]

이때 \(\lambda\)를 라그랑주 승수라 한다. 미지수는 \(x, y, \lambda\) 세 개이고 식도 \(f_x = \lambda g_x\), \(f_y = \lambda g_y\), \(g = k\) 세 개이다. 풀어서 나온 점들의 \(f\)값을 비교하면 된다. 삼변수도 같은 방법으로 푼다.

5.3.2예제

예제 5.3.2

원 \(x^2 + y^2 = 1\) 위에서 \(f = x^2 + 2y^2\)의 최댓값과 최솟값을 구하여라.

풀이. 세 식은 \(2x = 2\lambda x\), \(4y = 2\lambda y\), \(x^2 + y^2 = 1\)이다. 첫 식에서 \(x = 0\)이거나 \(\lambda = 1\)이다. \(x = 0\)이면 조건에서 \(y = \pm1\)이고 \(f = 2\)이다. \(\lambda = 1\)이면 둘째 식이 \(4y = 2y\)가 되어 \(y = 0\)이고, \(x = \pm1\), \(f = 1\)이다. 따라서 최댓값은 2, 최솟값은 1이다.

처음 질문의 그림과 맞춰 보자. 등위선 \(x^2 + 2y^2 = c\)는 가로 반지름 \(\sqrt c\), 세로 반지름 \(\sqrt{c/2}\)인 타원이다. \(c = 1\)이면 가로 반지름이 1이라 원의 양옆 \((\pm1, 0)\)에서 접하고, \(c = 2\)이면 세로 반지름이 1이라 원의 위아래 \((0, \pm1)\)에서 접한다. 라그랑주 승수법이 찾은 네 점이 바로 이 접점이다.

예제 5.3.3

재료 12 m²로 뚜껑 없는 직육면체 상자를 만들 때 최대 부피를 구하여라.

풀이. 가로 \(x\), 세로 \(y\), 높이 \(z\)라 하면 \(V = xyz\)이고, 조건은 겉넓이 \(g = 2xz + 2yz + xy = 12\)이다. 세 식은 다음과 같다.

\[yz = \lambda(2z + y), \quad xz = \lambda(2z + x), \quad xy = \lambda(2x + 2y)\]

각각에 \(x, y, z\)를 곱하면 좌변이 모두 \(xyz\)이므로 \(\lambda(2xz + xy) = \lambda(2yz + xy) = \lambda(2xz + 2yz)\)이다. \(\lambda \ne 0\)이므로 첫 두 식에서 \(x = y\)이고, 뒤 두 식에서 \(xy = 2xz\), 곧 \(y = 2z\)이다. 따라서 \(x = y = 2z\)이고, 조건에 넣으면 \(12z^2 = 12\), \(z = 1\)이다. 최대 부피는 \(2\cdot2\cdot1 = 4\) m³이다. 뚜껑이 없으므로 바닥을 넓게, 높이를 그 절반으로 하는 것이 재료를 가장 잘 쓰는 모양이다.

경제학의 효용 최대화(예산 조건), 물리의 평형 상태, 통계의 최대가능도 추정 등에서 같은 방법을 쓴다. \(\lambda\)는 조건 \(k\)를 1만큼 늘릴 때 최댓값이 늘어나는 비율이라는 뜻도 있다.

마무리

조건 \(g = k\) 아래의 최대·최소는 조건 곡선이 \(f\)의 등위선에 접하는 점에서 생기고, 접하면 두 기울기 벡터가 평행하므로 \(\nabla f = \lambda\nabla g\)와 \(g = k\)를 풀어 후보를 찾는다. 그래서 처음 질문의 원 위에서 \(f = x^2 + 2y^2\)은 등위선 타원이 원에 접하는 \((\pm1, 0)\)에서 최솟값 1, \((0, \pm1)\)에서 최댓값 2를 갖는다.

5.3.3연습문제

기본

  1. \(x + y = 10\)일 때 \(xy\)의 최댓값은?
    답

    \(y = \lambda\), \(x = \lambda\)에서 \(x = y = 5\). 25.

응용

  1. 원 \(x^2 + y^2 = 1\) 위에서 \(f = x + y\)의 최댓값은?
    답

    \(1 = 2\lambda x\), \(1 = 2\lambda y\)에서 \(x = y = \pm\frac{1}{\sqrt2}\). 최댓값 \(\sqrt2\).
