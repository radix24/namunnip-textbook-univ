안쪽 적분이 막히면 영역을 그려 적분 순서를 바꾼다

요령 · 적분 순서 바꾸기

언제 쓰는가

반복적분의 안쪽 변수에 \(e^{x^2}\), \(\sin(y^2)\), \(\sqrt{x^3 + 1}\)처럼 원시함수를 쓸 수 없는 함수가 걸려 있을 때이다.

요령

  1. 막힘 신호를 본다
    안쪽 적분의 원시함수를 기본 함수로 쓸 수 없으면 계산을 멈추고 순서를 바꿀 준비를 한다.
  2. 끝값으로 영역을 그린다
    안쪽 끝값은 곡선, 바깥 끝값은 직선으로 그린다. \(\int_0^4\int_{\sqrt y}^2\)이면 \(x = \sqrt y\), \(x = 2\), \(y = 0\), \(y = 4\)로 둘러싸인 영역이다.
  3. 반대 방향 띠로 다시 읽는다
    이번에는 다른 방향의 띠를 긋는다. 바깥 변수의 범위는 영역 전체의 폭, 안쪽 변수의 범위는 띠의 양 끝 곡선이다.
  4. 새 안쪽 적분을 한다
    순서를 바꾸면 안쪽 적분에서 곁에 도함수가 생겨 치환으로 풀리는 경우가 많다.

흔한 실수

  • 그림 없이 끝값의 문자만 맞바꾸는 것. 영역이 달라져 틀린 값이 나온다.
  • 순서를 바꾼 뒤 바깥 적분의 끝값에 변수가 남는 것. 바깥 끝값은 언제나 상수여야 한다.

바로 풀어보기

\(\displaystyle\int_0^4\int_{\sqrt y}^{2}\frac{1}{1 + x^3}\,dx\,dy\)를 구하여라.

답과 풀이

답: \(\frac23\ln3 \approx 0.732\)

\(\frac{1}{1 + x^3}\)의 원시함수는 부분분수로 가능하지만 매우 길다. 영역은 \(0 \le y \le 4\), \(\sqrt y \le x \le 2\), 곧 \(0 \le x \le 2\), \(0 \le y \le x^2\)이다.

\[\int_0^2\int_0^{x^2}\frac{1}{1 + x^3}\,dy\,dx = \int_0^2\frac{x^2}{1 + x^3}\,dx = \Big[\tfrac13\ln(1 + x^3)\Big]_0^2 = \tfrac13\ln9.\]

순서를 바꾸자 \(x^2\)이 생겨 \(1 + x^3\)의 도함수가 곁에 붙었다.

이 요령으로 풀리는 문제

  • 중적분 단원 연습 1번
영상 콘티 · 45초
  1. 0~5초\(\int_0^4\int_{\sqrt y}^2\frac{dx}{1 + x^3}\,dy\)가 나타나고, 안쪽 적분에 '?' 표시가 깜박인다.안쪽 적분이 막혔다.
  2. 5~13초끝값 \(x = \sqrt y\), \(x = 2\), \(y = 0\), \(y = 4\)가 하나씩 선으로 그려지며 영역이 칠해진다.끝값으로 영역부터 그린다.
  3. 13~20초영역 안에 가로 띠가 놓이고 왼끝이 \(x = \sqrt y\), 오른끝이 \(x = 2\)에 닿는다.지금은 가로 띠로 읽은 적분이다.
  4. 20~30초가로 띠가 90도 돌아 세로 띠가 되고, 아래끝 \(y = 0\), 위끝 \(y = x^2\)에 닿는다. 띠가 \(x = 0\)부터 2까지 훑는다.세로 띠로 다시 읽는다.
  5. 30~38초새 적분 \(\int_0^2\int_0^{x^2}\)이 쓰이고, 안쪽을 적분하자 \(x^2\)이 나타나 분모 \(1 + x^3\)과 같은 색으로 빛난다.도함수가 곁에 생겼다.
  6. 38~45초\(\frac13\ln9\)가 나오고 처음의 '?'가 체크로 바뀐다.막히면 그려서 순서를 바꾼다.
