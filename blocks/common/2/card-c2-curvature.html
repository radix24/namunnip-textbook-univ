호의 길이 매개화와 곡률: 얼마나 빨리 방향을 바꾸는가

s로 다시 쓰기 · κ = |dT/ds| · 나선

왜 호의 길이로 다시 쓰나

같은 곡선도 매개변수에 따라 빨리 또는 천천히 지나갑니다. "곡선이 얼마나 휘었나"는 지나가는 속도와 상관없는 곡선 자체의 성질이어야 합니다. 그래서 매개변수를 이동한 거리 \(s\)로 바꿔 속력을 늘 1로 만든 뒤 휨을 잽니다.

\(s(t) = \int_{t_0}^{t}|\mathbf r'(u)|\,du\) (공통1의 곡선 길이). \(\frac{ds}{dt} = |\mathbf r'(t)|\) (기본정리).

정의 · 곡률

\(\kappa = \left|\dfrac{d\mathbf T}{ds}\right|\): 단위 길이를 갈 때 단위접선이 회전하는 빠르기.

계산 공식 유도

  1. 연쇄 법칙: \(\dfrac{d\mathbf T}{dt} = \dfrac{d\mathbf T}{ds}\dfrac{ds}{dt}\)이므로 \(\kappa = \dfrac{|\mathbf T'(t)|}{|\mathbf r'(t)|}\).
    \(\frac{ds}{dt} = |\mathbf r'| > 0\).
  2. \(\mathbf r' = |\mathbf r'|\mathbf T\)를 미분: \(\mathbf r'' = |\mathbf r'|'\,\mathbf T + |\mathbf r'|\,\mathbf T'\).
    곱의 법칙.
  3. \(\mathbf r'\times\mathbf r'' = |\mathbf r'|^2(\mathbf T\times\mathbf T')\).
    \(\mathbf T\times\mathbf T = \mathbf 0\)이라 첫 항이 사라진다.
  4. \(|\mathbf T| = 1\)이므로 \(\mathbf T\perp\mathbf T'\) (앞 카드), 따라서 \(|\mathbf T\times\mathbf T'| = |\mathbf T'|\).
    수직이면 \(\sin 90° = 1\).
  5. \(|\mathbf r'\times\mathbf r''| = |\mathbf r'|^2|\mathbf T'| = |\mathbf r'|^3\kappa\), 곧 \(\kappa = \dfrac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|^3}\).
    1단계와 합침. \(\mathbf T\)를 구하지 않고 바로 계산할 수 있다.

평면곡선 \(y = f(x)\)이면 \(\mathbf r = (x, f(x), 0)\)으로 보고 \(\kappa = \dfrac{|f''|}{(1 + f'^2)^{3/2}}\).

나선 \(\mathbf r(t) = (a\cos t, a\sin t, bt)\) \((a > 0)\)를 호의 길이로 매개화하고 곡률을 구하세요.

풀이

  1. \(\mathbf r' = (-a\sin t, a\cos t, b)\), \(|\mathbf r'| = \sqrt{a^2 + b^2} =: c\).
    속력이 상수.
  2. \(s = ct\), \(t = \frac sc\). \(\mathbf r(s) = \left(a\cos\frac sc, a\sin\frac sc, \frac{bs}{c}\right)\).
    \(s(t) = \int_0^tc\,du\)를 \(t\)에 대해 풀었다.
  3. \(\mathbf r'' = (-a\cos t, -a\sin t, 0)\), \(\mathbf r'\times\mathbf r'' = (ab\sin t, -ab\cos t, a^2)\), 길이 \(a\sqrt{a^2 + b^2} = ac\).
    외적 성분: \((a\cos t\cdot0 - b(-a\sin t),\ b(-a\cos t) - (-a\sin t)\cdot0,\ a^2\sin^2t + a^2\cos^2t)\).
  4. \(\kappa = \dfrac{ac}{c^3} = \dfrac{a}{a^2 + b^2}\). 상수.
    공식.

검산

\(b = 0\)이면 반지름 \(a\)인 원이고 \(\kappa = \frac1a\). 원의 곡률이 반지름의 역수라는 사실과 맞습니다(곡률 반지름 = \(\frac1\kappa\)). \(b\)가 커지면 나선이 펴져 \(\kappa \to 0\), 직선에 가까워집니다.

흔한 오해

  • \(\kappa = |\mathbf T'(t)|\): \(t\)가 호의 길이가 아니면 \(|\mathbf r'|\)로 나눠야 합니다.
  • \(\kappa = |\mathbf r''|\): 속력이 1일 때만 맞습니다.
