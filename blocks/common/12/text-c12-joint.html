  • 조건부확률 (1.2절), pmf와 pdf (2.1절, 2.2절), 이중적분 (공통2 6.1절).

5.1.1결합분포

한 부품의 길이와 무게, 한 날의 주문 수와 반품 수처럼 두 양을 함께 다룰 때 결합분포를 씁니다.

  • 이산: 결합 pmf \(p(x, y) = P(X = x, Y = y)\), \(\sum_x\sum_y p(x, y) = 1\).
  • 연속: 결합 pdf \(f(x, y) \ge 0\), \(P((X, Y) \in A) = \iint_A f(x, y)\,dx\,dy\), 전체 적분 1.

5.1.2주변분포

한 변수만의 분포는 다른 변수에 대해 모두 더하거나 적분해서 얻습니다.

\[p_X(x) = \sum_y p(x, y), \qquad f_X(x) = \int_{-\infty}^{\infty} f(x, y)\,dy.\]
예제 5.1.1

어떤 기계의 하루 정지 횟수 \(X\)(0 또는 1)와 불량 수 \(Y\)(0, 1, 2)의 결합 pmf가 아래와 같다. 주변분포와 \(X = 1\)일 때 \(Y\)의 조건부분포를 구하여라.

\(Y = 0\)\(Y = 1\)\(Y = 2\)\(p_X\)
\(X = 0\)0.100.200.100.40
\(X = 1\)0.150.250.200.60
\(p_Y\)0.250.450.301

주변분포는 표의 가장자리(행 합, 열 합)에 적힌다는 데서 이름이 왔습니다.

5.1.3조건부분포

\[p_{Y \mid X}(y \mid x) = \frac{p(x, y)}{p_X(x)}, \qquad f_{Y \mid X}(y \mid x) = \frac{f(x, y)}{f_X(x)}.\]

위 예에서 \(X = 1\)일 때 \(Y\)의 분포는 \(\frac{0.15}{0.6}, \frac{0.25}{0.6}, \frac{0.20}{0.6} = 0.25, 0.417, 0.333\)입니다. 정지가 있던 날의 조건부 평균 불량 수는 \(0.417 + 2(0.333) \approx 1.08\)로, 전체 평균 \(E[Y] = 0.45 + 0.6 = 1.05\)보다 조금 큽니다.

예제 5.1.2

\(f(x, y) = 2\) (\(0 \le y \le x \le 1\))일 때 \(f_X\), \(f_Y\), \(f_{Y \mid X}\)를 구하여라.

풀이. \(f_X(x) = \int_0^x 2\,dy = 2x\) (\(0 \le x \le 1\)). \(f_Y(y) = \int_y^1 2\,dx = 2(1 - y)\). \(f_{Y \mid X}(y \mid x) = \frac2{2x} = \frac1x\) (\(0 \le y \le x\)): \(X = x\)가 주어지면 \(Y\)는 \([0, x]\)에서 균일. 적분 범위를 그림(삼각형 영역)으로 확인하는 것이 핵심입니다.

요약
  1. 결합 pmf/pdf, 전체 합/적분 1.
  2. 주변: 다른 변수에 대해 합하거나 적분.
  3. 조건부: 결합 ÷ 주변.
