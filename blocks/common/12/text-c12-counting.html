경우의 수와 표본 검사

본문

부품 20개 가운데 3개가 불량인 로트에서 4개를 골라 검사했다. 불량을 하나도 못 찾고 통과시킬 확률은 얼마나 될까? 뽑은 부품을 되돌려 놓느냐 아니냐에 따라 답이 달라질까?

먼저 알아야 할 것확률의 공리와 여사건(1.1절)과 고교 확률과 통계의 순열과 조합(이 절에서 다시 정리한다)을 쓴다.

1.4.1순열과 조합

표본공간의 모든 결과가 같은 가능성으로 일어나면, 사건 \(A\)의 확률은 \(P(A) = \frac{A\text{의 경우의 수}}{\text{전체 경우의 수}}\)이다. 그래서 경우의 수를 바르게 세는 것이 중요하다.

서로 다른 \(n\)개에서 \(r\)개를 골라 순서 있게 늘어놓는 경우의 수를 순열이라 하며 \({}_nP_r = n(n-1)\cdots(n-r+1) = \frac{n!}{(n-r)!}\)이다. 반면 순서 없이 고르기만 하는 경우의 수는 조합이며 \({}_nC_r = \binom{n}{r} = \frac{n!}{r!\,(n-r)!}\)이다.

같은 \(r\)개를 고른 묶음 하나는 \(r!\)가지 순서로 늘어놓을 수 있으므로 \({}_nP_r = {}_nC_r \times r!\)이다. 예를 들어 부품 10종에서 3종을 골라 조립 순서까지 정하면 \({}_{10}P_3 = 720\)가지, 순서 없이 고르기만 하면 \(\binom{10}{3} = 120\)가지이다. 그러므로 문제를 읽을 때 "순서가 결과를 바꾸는가"를 먼저 정한다. 파이썬에서는 math.perm(10, 3), math.comb(10, 3)으로 계산한다.

1.4.2초기하분포, 되돌려 놓지 않는 표본 검사

부품 \(N\)개가 든 로트(한 묶음)에 불량품이 \(K\)개 있다. 여기서 \(n\)개를 되돌려 놓지 않고 무작위로 뽑을 때, 뽑은 것 가운데 불량품 수 \(X\)의 분포를 초기하분포라 한다. \(n\)개를 고르는 방법 \(\binom{N}{n}\)가지가 모두 같은 가능성이고, 그중 불량 \(k\)개와 양품 \(n - k\)개를 고르는 방법은 \(\binom{K}{k}\binom{N-K}{n-k}\)가지이다. 따라서 다음을 얻는다.

\[P(X = k) = \frac{\dbinom{K}{k}\dbinom{N-K}{n-k}}{\dbinom{N}{n}}\]

평균은 \(E[X] = n\frac{K}{N}\)으로, 한 번 뽑을 때 불량일 확률 \(K/N\)에 \(n\)을 곱한 것과 같다.

예제 1.4.1

부품 20개 가운데 불량품이 3개 있다. 4개를 무작위로 골라 검사할 때, (1) 불량품이 하나도 안 나올 확률, (2) 적어도 하나 나올 확률, (3) 정확히 1개 나올 확률을 구하여라.

풀이. \(N = 20\), \(K = 3\), \(n = 4\)이고 전체는 \(\binom{20}{4} = 4845\)가지이다. (1) 양품 17개에서만 4개를 고르면 \(\binom{17}{4} = 2380\)가지이므로 \(P(X = 0) = \frac{2380}{4845} \approx 0.491\)이다. (2) 여사건이므로 \(1 - 0.491 = 0.509\)이다. (3) \(\binom{3}{1}\binom{17}{3} = 3\times680 = 2040\)가지이므로 \(P(X = 1) = \frac{2040}{4845} \approx 0.421\)이다.

즉 처음 질문의 답은 약 0.49로, 4개를 검사해도 불량이 섞인 로트를 놓칠 확률이 절반 가까이 된다. 평균 불량 수는 \(4\times\frac{3}{20} = 0.6\)개이다. 그림 1에서 검사 개수를 늘리면 0의 막대가 낮아지지만, 로트의 절반인 10개를 검사해도 놓칠 확률은 약 0.11이다.

1.4.3이항분포와 비교

예제 1.4.2

예제 1.4.1의 검사를 "한 개 뽑아 검사하고 되돌려 놓기"를 4번 하는 것으로 바꾸면, 불량품이 하나도 안 나올 확률은 얼마인가? 두 결과가 다른 까닭과, 로트가 클 때 어떻게 되는지 설명하여라.

풀이. 되돌려 놓으면 매번 불량일 확률이 \(p = \frac{3}{20} = 0.15\)로 같고 시행이 독립이므로 이항분포이다. 그래서 \(P(X = 0) = 0.85^4 \approx 0.522\)이다. 처음 질문의 둘째 물음에 답하면, 되돌려 놓지 않을 때(0.491)보다 크다. 되돌려 놓지 않으면 양품을 하나 뽑을 때마다 남은 것 가운데 불량품 비율이 조금씩 올라가기 때문이다(\(\frac{3}{19}, \frac{3}{18}, \ldots\)).

그런데 로트가 아주 크면(예를 들어 \(N = 20\,000\), \(K = 3000\)) 몇 개를 뽑아도 남은 비율이 거의 변하지 않는다. 그러므로 초기하분포를 \(p = K/N\)인 이항분포로 어림해도 된다. 흔히 \(n\)이 \(N\)의 5~10% 이하이면 이항 어림을 쓴다.

마무리

순서가 있으면 순열 \({}_nP_r = \frac{n!}{(n-r)!}\), 없으면 조합 \(\binom{n}{r} = \frac{n!}{r!(n-r)!}\)으로 센다. 되돌려 놓지 않는 표본 검사의 불량 수는 초기하분포 \(\binom{K}{k}\binom{N-K}{n-k}/\binom{N}{n}\)을 따르며 평균은 \(nK/N\)이고, 처음 질문의 로트는 4개 검사로 약 49% 확률로 통과된다. 로트가 표본보다 훨씬 크면 \(p = K/N\)인 이항분포로 어림한다.

1.4.4연습문제

기본

  1. 예제 1.4.1에서 정확히 2개가 불량일 확률을 구하여라.
    답

    \(\binom{3}{2}\binom{17}{2}/\binom{20}{4} = 3\times136/4845 = 408/4845 \approx 0.084\).

  2. 트럼프 카드 52장에서 5장을 뽑아 같은 무늬 10, J, Q, K, A가 나올 확률을 구하여라.
    답

    무늬가 4가지이므로 원하는 경우는 4가지, 전체는 \(\binom{52}{5} = 2\,598\,960\)가지. 확률은 약 \(1.54\times10^{-6}\)이다.
