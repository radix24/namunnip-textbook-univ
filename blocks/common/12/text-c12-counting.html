경우의 수와 표본 검사

본문
이 절에서 배울 것
  • 순열과 조합으로 같은 가능성의 표본공간에서 확률을 센다.
  • 되돌려 놓지 않고 뽑는 표본 검사의 확률을 초기하분포로 계산한다.
  • 로트가 클 때 초기하분포를 이항분포로 어림할 수 있는 까닭을 안다.
먼저 알아야 할 것
  • 확률의 공리와 여사건 (1.1절), 고교 확률과 통계의 순열과 조합(이 절에서 다시 정리합니다).

1.4.1순열과 조합

표본공간의 모든 결과가 같은 가능성으로 일어나면, 사건 \(A\)의 확률은 \(P(A) = \frac{A\text{의 경우의 수}}{\text{전체 경우의 수}}\)입니다. 그래서 경우의 수를 바르게 세는 것이 중요합니다.

순열: 서로 다른 \(n\)개에서 \(r\)개를 골라 순서 있게 늘어놓는 경우의 수. \({}_nP_r = n(n-1)\cdots(n-r+1) = \frac{n!}{(n-r)!}\).

조합: 서로 다른 \(n\)개에서 \(r\)개를 순서 없이 고르는 경우의 수. \({}_nC_r = \binom{n}{r} = \frac{n!}{r!\,(n-r)!}\).

같은 \(r\)개를 고른 묶음 하나는 \(r!\)가지 순서로 늘어놓을 수 있으므로 \({}_nP_r = {}_nC_r \times r!\)입니다. 예를 들어 부품 10종에서 3종을 골라 조립 순서까지 정하면 \({}_{10}P_3 = 720\)가지, 순서 없이 고르기만 하면 \(\binom{10}{3} = 120\)가지입니다. 문제를 읽을 때 "순서가 결과를 바꾸는가"를 먼저 정합니다. 파이썬에서는 math.perm(10, 3), math.comb(10, 3)으로 계산합니다.

1.4.2초기하분포: 되돌려 놓지 않는 표본 검사

부품 \(N\)개가 든 로트(한 묶음)에 불량품이 \(K\)개 있습니다. 여기서 \(n\)개를 되돌려 놓지 않고 무작위로 뽑을 때, 뽑은 것 가운데 불량품 수 \(X\)의 분포를 초기하분포라 합니다. \(n\)개를 고르는 방법 \(\binom{N}{n}\)가지가 모두 같은 가능성이고, 그중 불량 \(k\)개와 양품 \(n - k\)개를 고르는 방법은 \(\binom{K}{k}\binom{N-K}{n-k}\)가지이므로

\[P(X = k) = \frac{\dbinom{K}{k}\dbinom{N-K}{n-k}}{\dbinom{N}{n}}\]

입니다. 평균은 \(E[X] = n\frac{K}{N}\)으로, 한 번 뽑을 때 불량일 확률 \(K/N\)에 \(n\)을 곱한 것과 같습니다.

예제 1.4.1

부품 20개 가운데 불량품이 3개 있습니다. 4개를 무작위로 골라 검사할 때, (1) 불량품이 하나도 안 나올 확률, (2) 적어도 하나 나올 확률, (3) 정확히 1개 나올 확률을 구하세요.

풀이. \(N = 20\), \(K = 3\), \(n = 4\). 전체 \(\binom{20}{4} = 4845\)가지입니다.

  1. 양품 17개에서만 4개: \(\binom{17}{4} = 2380\). \(P(X = 0) = \frac{2380}{4845} \approx 0.491\).
  2. 여사건: \(1 - 0.491 = 0.509\).
  3. \(\binom{3}{1}\binom{17}{3} = 3\times680 = 2040\). \(P(X = 1) = \frac{2040}{4845} \approx 0.421\).

4개를 검사해도 불량이 섞인 로트를 놓칠 확률이 절반 가까이 됩니다. 평균 불량 수는 \(4\times\frac{3}{20} = 0.6\)개입니다.

1.4.3이항분포와 비교

예제 1.4.2

예제 1.4.1의 검사를 "한 개 뽑아 검사하고 되돌려 놓기"를 4번 하는 것으로 바꾸면, 불량품이 하나도 안 나올 확률은 얼마인가요? 두 결과가 다른 까닭과, 로트가 클 때 어떻게 되는지 설명하세요.

풀이. 되돌려 놓으면 매번 불량일 확률이 \(p = \frac{3}{20} = 0.15\)로 같고 시행이 독립이므로 이항분포입니다. \(P(X = 0) = 0.85^4 \approx 0.522\)입니다. 되돌려 놓지 않을 때(0.491)보다 큰 까닭은, 되돌려 놓지 않으면 양품을 하나 뽑을 때마다 남은 것 가운데 불량품 비율이 조금씩 올라가기 때문입니다(\(\frac{3}{19}, \frac{3}{18}, \ldots\)). 로트가 아주 크면(예: \(N = 20\,000\), \(K = 3000\)) 몇 개를 뽑아도 남은 비율이 거의 변하지 않으므로, 초기하분포를 \(p = K/N\)인 이항분포로 어림해도 됩니다. 흔히 \(n\)이 \(N\)의 5~10% 이하이면 이항 어림을 씁니다.

요약
  1. 순서가 있으면 \({}_nP_r = \frac{n!}{(n-r)!}\), 없으면 \(\binom{n}{r} = \frac{n!}{r!(n-r)!}\).
  2. 되돌려 놓지 않는 표본 검사: \(P(X = k) = \binom{K}{k}\binom{N-K}{n-k}/\binom{N}{n}\), 평균 \(nK/N\).
  3. 로트가 표본보다 훨씬 크면 \(p = K/N\)인 이항분포로 어림한다.

1.4.4연습문제

기본

  1. 예제 1.4.1에서 정확히 2개가 불량일 확률을 구하세요.
    답

    \(\binom{3}{2}\binom{17}{2}/\binom{20}{4} = 3\times136/4845 = 408/4845 \approx 0.084\).

  2. 트럼프 카드 52장에서 5장을 뽑아 같은 무늬 10, J, Q, K, A가 나올 확률을 구하세요.
    답

    무늬가 4가지이므로 원하는 경우는 4가지, 전체는 \(\binom{52}{5} = 2\,598\,960\)가지. 확률은 약 \(1.54\times10^{-6}\)입니다.
