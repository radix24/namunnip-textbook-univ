연속 확률변수와 확률밀도함수

본문
이 절에서 배울 것
  • 확률밀도함수를 적분해 구간의 확률을 구한다.
  • 확률밀도함수와 누적분포함수를 미분과 적분으로 오간다.
  • 분위수(중앙값, 백분위수)를 구한다.
먼저 알아야 할 것
  • 정적분과 미적분학의 기본정리 (공통1 4.3절), 누적분포함수 (2.1절).

2.2.1확률밀도함수

부품의 수명, 축의 지름처럼 연속적인 양은 특정한 한 값을 가질 확률이 0입니다(지름이 정확히 25.000000...mm일 확률). 그래서 확률을 구간에 대해서만 말하고, 넓이로 나타냅니다.

정의 2.2.1

함수 \(f\)가 \(f(x) \ge 0\), \(\int_{-\infty}^{\infty} f(x)\,dx = 1\)이고 모든 \(a \le b\)에 대해

\[P(a \le X \le b) = \int_a^b f(x)\,dx\]

이면 \(f\)를 \(X\)의 확률밀도함수(pdf)라 한다.

  • \(P(X = a) = 0\)이므로 \(\le\)와 \(<\)를 구별할 필요가 없다.
  • \(f(x)\) 자체는 확률이 아니라 밀도(단위 길이당 확률)라서 1보다 클 수 있다.
  • 짧은 구간에서 \(P(x \le X \le x + \Delta x) \approx f(x)\Delta x\).

2.2.2누적분포함수와의 관계

\[F(x) = \int_{-\infty}^{x} f(t)\,dt, \qquad f(x) = F'(x) \quad (\text{미분 가능한 곳에서}).\]

연속 확률변수의 cdf는 연속 함수입니다. \(P(a < X \le b) = F(b) - F(a)\)는 이산일 때와 같습니다.

예제 2.2.2

\(f(x) = cx^2\) (\(0 \le x \le 2\)), 나머지는 0. \(c\), \(F(x)\), \(P(1 < X < 2)\), 중앙값을 구하여라.

풀이.

  • \(\int_0^2 cx^2\,dx = \frac{8c}{3} = 1\)에서 \(c = \frac38\).
  • \(0 \le x \le 2\)에서 \(F(x) = \frac{x^3}{8}\). \(x < 0\)이면 0, \(x > 2\)이면 1.
  • \(P(1 < X < 2) = F(2) - F(1) = 1 - \frac18 = \frac78\).
  • 중앙값 \(m\): \(F(m) = \frac12\)에서 \(m^3 = 4\), \(m = 4^{1/3} \approx 1.587\).

2.2.3분위수

\(F(x_p) = p\)인 \(x_p\)를 \(100p\) 백분위수라 합니다. 중앙값은 \(x_{0.5}\)입니다. 품질 관리에서 "부품의 10%가 고장 나는 시간"(\(B_{10}\) 수명)처럼 씁니다. 예를 들어 지수분포 \(F(t) = 1 - e^{-\lambda t}\)이면 \(t_p = -\frac{\ln(1-p)}{\lambda}\)입니다(4.2절).

요약
  1. \(P(a \le X \le b) = \int_a^b f\), \(f \ge 0\), 전체 넓이 1. 한 점의 확률은 0.
  2. \(F(x) = \int_{-\infty}^x f\), \(f = F'\).
  3. 분위수: \(F(x_p) = p\).

2.2.4연습문제

기본
