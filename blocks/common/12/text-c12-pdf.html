연속 확률변수와 확률밀도함수

본문

축의 지름이 정확히 25.000000… mm일 확률은 얼마일까? 지름은 연속적인 양이라 어떤 한 값을 정확히 가질 확률은 0이다. 그런데도 "지름이 24.97과 25.03 사이일 확률"은 분명히 있다. 한 점의 확률이 모두 0인데 구간의 확률은 어떻게 나타낼까?

먼저 알아야 할 것정적분과 미적분학의 기본정리(미분적분학(1) 4.3절)와 누적분포함수(2.1절)를 쓴다.

2.2.1확률밀도함수

처음 질문의 답은 확률을 구간에 대해서만 말하고, 넓이로 나타내는 것이다.

정의 2.2.1

함수 \(f\)가 \(f(x) \ge 0\), \(\int_{-\infty}^{\infty} f(x)\,dx = 1\)이고 모든 \(a \le b\)에 대해

\[P(a \le X \le b) = \int_a^b f(x)\,dx\]

이면 \(f\)를 \(X\)의 확률밀도함수(pdf)라 한다.

이 정의에서 몇 가지가 따라 나온다. 먼저 \(P(X = a) = \int_a^a f = 0\)이므로 \(\le\)와 \(<\)를 구별할 필요가 없다. 또 \(f(x)\) 자체는 확률이 아니라 밀도(단위 길이당 확률)라서 1보다 클 수 있다. 그리고 짧은 구간에서는 \(P(x \le X \le x + \Delta x) \approx f(x)\Delta x\)이다.

2.2.2누적분포함수와의 관계

누적분포함수는 밀도를 왼쪽 끝부터 쌓은 넓이이고, 거꾸로 밀도는 누적분포함수의 기울기이다.

\[F(x) = \int_{-\infty}^{x} f(t)\,dt, \qquad f(x) = F'(x) \quad (\text{미분 가능한 곳에서}).\]

그래서 연속 확률변수의 cdf는 연속 함수이다. \(P(a < X \le b) = F(b) - F(a)\)는 이산일 때와 같다.

예제 2.2.2

\(f(x) = cx^2\) (\(0 \le x \le 2\)), 나머지는 0이다. \(c\), \(F(x)\), \(P(1 < X < 2)\), 중앙값을 구하여라.

풀이. 전체 넓이가 1이어야 하므로 \(\int_0^2 cx^2\,dx = \frac{8c}{3} = 1\)에서 \(c = \frac38\)이다. 그러면 \(0 \le x \le 2\)에서 \(F(x) = \frac{x^3}{8}\)이고, \(x < 0\)이면 0, \(x > 2\)이면 1이다. 따라서 \(P(1 < X < 2) = F(2) - F(1) = 1 - \frac18 = \frac78\)이다. 끝으로 중앙값 \(m\)은 \(F(m) = \frac12\)에서 \(m^3 = 4\), 곧 \(m = 4^{1/3} \approx 1.587\)이다.

그림 1에서 \(a = 1\), \(b = 2\)로 두면 파란 넓이가 \(\frac78 = 0.875\)이다. 이때 밀도 \(f(2) = 1.5\)는 1보다 크지만 넓이는 1을 넘지 않는다. 또 중앙값 1.587이 2의 가운데인 1보다 오른쪽에 있는 것은 밀도가 오른쪽으로 몰려 있기 때문이다.

2.2.3분위수

\(F(x_p) = p\)인 \(x_p\)를 \(100p\) 백분위수라 하며, 중앙값은 \(x_{0.5}\)이다. 품질 관리에서는 "부품의 10%가 고장 나는 시간"(\(B_{10}\) 수명)처럼 쓴다. 예를 들어 지수분포 \(F(t) = 1 - e^{-\lambda t}\)이면 \(t_p = -\frac{\ln(1-p)}{\lambda}\)이다(4.2절).

마무리

연속 확률변수는 처음 질문처럼 한 점의 확률이 0이므로, 확률밀도함수 아래의 넓이 \(P(a \le X \le b) = \int_a^b f\)로 구간의 확률을 나타낸다. 밀도는 음이 아니고 전체 넓이가 1이며, \(F(x) = \int_{-\infty}^x f\), \(f = F'\)으로 누적분포함수와 오간다. 분위수는 \(F(x_p) = p\)인 값이다.
