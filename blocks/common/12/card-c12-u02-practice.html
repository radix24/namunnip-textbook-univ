확률변수 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 코드는 그 문제가 확인하는 성취기준이다.

  1. 계산동전을 세 번 던져 앞면의 수를 \(X\)라 한다. 확률질량함수와 \(F(1) = P(X \le 1)\)을 구하여라. [02-01]

    힌트 1

    경우는 \(2^3 = 8\)가지이고 모두 같은 확률이다.

    힌트 2

    앞면이 \(k\)번인 경우의 수는 \(\binom3k\).

    풀이

    \(p(0) = 1/8\), \(p(1) = 3/8\), \(p(2) = 3/8\), \(p(3) = 1/8\). \(F(1) = 1/8 + 3/8 = 1/2\).

  2. 계산\(p(x) = cx\) (\(x = 1, 2, 3, 4\))가 확률질량함수가 되도록 \(c\)를 정하고 \(P(X \ge 3)\)을 구하여라. [02-01]

    힌트 1

    확률의 합이 1이어야 한다.

    힌트 2

    \(c(1 + 2 + 3 + 4) = 1\).

    풀이

    \(c = 1/10\), \(P(X \ge 3) = (3 + 4)/10 = 0.7\).

  3. 계산\(f(x) = cx^2\) (\(0 \le x \le 2\), 밖에서는 0)가 확률밀도함수가 되도록 \(c\)를 정하고, 누적분포함수와 \(P(X \le 1)\)을 구하여라. [02-02]

    힌트 1

    \(\int_0^2 cx^2\,dx = 1\).

    힌트 2

    \(F(x) = \int_0^x f(t)\,dt\).

    풀이

    \(c \cdot 8/3 = 1\), \(c = 3/8\). \(0 \le x \le 2\)에서 \(F(x) = x^3/8\)(그 아래 0, 위 1). \(P(X \le 1) = F(1) = 1/8\).

  4. 계산부품의 수명 \(X\)(천 시간)의 밀도가 \(f(x) = 2e^{-2x}\) (\(x \ge 0\))이다. 누적분포함수와 중앙값을 구하여라. [02-02]

    힌트 1

    \(F(x) = \int_0^x 2e^{-2t}dt\).

    힌트 2

    중앙값 \(m\)은 \(F(m) = 0.5\).

    풀이

    \(F(x) = 1 - e^{-2x}\). \(e^{-2m} = 0.5\)에서 \(m = \ln2/2 = 0.347\), 약 347시간. 평균(500시간)보다 짧다. 오른쪽 꼬리가 긴 분포에서는 평균이 중앙값보다 크다.

  5. 개념연속 확률변수에서 \(P(X = a) = 0\)인 이유와, 밀도 \(f(x)\)가 1보다 클 수 있는 이유를 설명하여라. [02-02]

    힌트 1

    연속 확률변수의 확률은 밀도 아래의 넓이이다.

    힌트 2

    폭이 0인 구간의 넓이는? 폭이 좁으면 높이가 1을 넘어도 넓이는 1보다 작을 수 있다.

    풀이

    \(P(X = a) = \int_a^a f(x)\,dx = 0\)이다. 그래서 \(P(X \le a) = P(X < a)\)이다. 밀도는 확률 자체가 아니라 단위 길이당 확률이므로 1보다 클 수 있다. 예: \([0, 0.5]\)의 균일분포는 \(f = 2\).

  6. 판단앞의 \(f(x) = \tfrac38x^2\)에서 \(f(2) = 1.5\)이다. 한 학생이 “\(X = 2\)일 확률은 1.5다”라고 했다. 판단하여라. [02-02]

    힌트 1

    확률이 1보다 클 수 있나요?

    힌트 2

    \(f(2)\)는 2 근처의 짧은 구간 \(\Delta x\)에서의 확률 \(\approx f(2)\Delta x\)를 알려 준다.

    풀이

    틀렸다. \(P(X = 2) = 0\)이고, 1.5는 확률 밀도이다. 예를 들어 \(P(1.99 \le X \le 2) \approx 1.5 \times 0.01 = 0.015\)이다.
