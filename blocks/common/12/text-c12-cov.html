공분산과 상관계수

본문
이 절에서 배울 것
  • 공분산과 상관계수를 정의하고 계산한다.
  • 상관계수의 범위와 뜻, 합의 분산 공식을 쓴다.
먼저 알아야 할 것
  • 결합분포와 독립 (5.1절, 5.2절), 분산 (3.1절).

5.3.1공분산

\[\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - \mu_X\mu_Y.\]

\(X\)가 평균보다 클 때 \(Y\)도 평균보다 큰 경향이 있으면 양수, 반대 경향이면 음수입니다. 성질은 다음과 같습니다.

  • \(\mathrm{Cov}(X, X) = \mathrm{Var}(X)\).
  • \(\mathrm{Cov}(aX + b, cY + d) = ac\,\mathrm{Cov}(X, Y)\).
  • 독립이면 \(\mathrm{Cov}(X, Y) = 0\) (역은 성립하지 않음, 5.2절).
  • \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\,\mathrm{Cov}(X, Y)\).

5.3.2상관계수

공분산은 단위에 따라 크기가 달라지므로(mm로 재면 cm로 잰 것의 100배), 표준편차로 나눈 상관계수를 씁니다.

\[\rho = \frac{\mathrm{Cov}(X, Y)}{\sigma_X\sigma_Y}, \qquad -1 \le \rho \le 1.\]

\(|\rho| = 1\)이면 \(Y = aX + b\)(직선 관계)이고, \(\rho = 0\)이면 직선 관계가 없다는 뜻입니다(곡선 관계는 있을 수 있음). 범위는 \(\mathrm{Var}\left(\frac{X}{\sigma_X} \pm \frac{Y}{\sigma_Y}\right) = 2 \pm 2\rho \ge 0\)에서 나옵니다.

예제 5.3.1

5.1절 예제의 결합 pmf에서 \(\mathrm{Cov}(X, Y)\)와 \(\rho\)를 구하여라.

풀이.

  • \(E[X] = 0.6\), \(E[Y] = 1.05\).
  • \(E[XY] = 1\cdot1\cdot0.25 + 1\cdot2\cdot0.20 = 0.65\).
  • \(\mathrm{Cov} = 0.65 - 0.6 \times 1.05 = 0.02\).
  • \(\mathrm{Var}(X) = 0.6 - 0.36 = 0.24\), \(\mathrm{Var}(Y) = 0.45 + 4(0.30) - 1.05^2 = 0.5475\).
  • \(\rho = \frac{0.02}{\sqrt{0.24 \times 0.5475}} \approx 0.055\).

독립은 아니지만(5.2절) 직선 관계는 아주 약합니다.

자료에서 구한 표본 상관계수 \(r\)(공통7 10.1절)은 \(\rho\)를 추정한 값입니다. 상관이 있다고 원인과 결과 관계가 있는 것은 아닙니다.

아래 실습 카드에서 \(\rho\)를 바꾸며 산점도의 모양과 \(X + Y\)의 분산이 어떻게 달라지는지 볼 수 있습니다.

요약
  1. \(\mathrm{Cov} = E[XY] - \mu_X\mu_Y\), \(\mathrm{Var}(X + Y) = \mathrm{Var}X + \mathrm{Var}Y + 2\mathrm{Cov}\).
  2. \(\rho = \mathrm{Cov}/(\sigma_X\sigma_Y) \in [-1, 1]\), 직선 관계의 세기.

5.3.3연습문제

기본

  1. \(\mathrm{Var}(X) = 4\), \(\mathrm{Var}(Y) = 9\), \(\rho = -0.5\)일 때 \(\mathrm{Var}(X + Y)\)와 \(\mathrm{Var}(X - Y)\)는?
    답

    \(\mathrm{Cov} = -0.5 \times 2 \times 3 = -3\). \(\mathrm{Var}(X + Y) = 4 + 9 - 6 = 7\), \(\mathrm{Var}(X - Y) = 4 + 9 + 6 = 19\).
