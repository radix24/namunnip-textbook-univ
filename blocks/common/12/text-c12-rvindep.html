확률변수의 독립

본문

5.1절의 기계는 멈춘 날 불량이 조금 더 많았다. 그 차이가 아주 작다면 "정지와 불량은 서로 상관없다"고 말해도 될까? 두 확률변수가 독립인지 정확히 가리는 기준은 무엇이고, 독립이면 계산이 어떻게 쉬워질까?

먼저 알아야 할 것사건의 독립(1.3절)과 주변분포(5.1절)를 쓴다.

5.2.1정의와 판정

정의 5.2.1

모든 \(x, y\)에서 \(p(x, y) = p_X(x)\,p_Y(y)\) (연속이면 \(f(x, y) = f_X(x)\,f_Y(y)\))이면 \(X\)와 \(Y\)는 독립이다.

처음 질문의 기준이 이것이며, 한 칸이라도 곱과 다르면 독립이라 할 수 없다. 5.1절 예제에서 \(p(0, 0) = 0.10 = 0.40 \times 0.25\)이지만 \(p(0, 1) = 0.20 \ne 0.40 \times 0.45 = 0.18\)이므로 독립이 되지 못한다. 그림 1에서 여섯 칸 가운데 네 칸이 주황인 것을 볼 수 있다. 같은 뜻으로, 조건부분포가 조건에 따라 달라지면(\(X = 0\)일 때와 \(X = 1\)일 때 \(Y\)의 분포가 다르면) 두 변수는 서로 의존한다. 즉 차이가 작아도 독립이라 할 수 없다.

연속인 경우에는 두 조건으로 빠르게 판정한다. \(f(x, y)\)가 \(g(x)h(y)\) 꼴로 인수분해되고, \(f\)가 0이 아닌 영역이 직사각형 \(a \le x \le b\), \(c \le y \le d\)이면 독립이다. 가령 5.1절 예제 5.1.2의 \(f = 2\)는 상수라 인수분해되지만, 영역이 삼각형(\(y \le x\))이라 독립이 되지 못한다. \(X\)가 작으면 \(Y\)도 작아야 하기 때문이다.

5.2.2독립의 결과

처음 질문의 둘째 물음에 답하면, 독립이면 세 가지 계산이 쉬워진다. 먼저 \(E[XY] = E[X]\,E[Y]\)이고, 더 일반적으로 \(E[g(X)h(Y)] = E[g(X)]\,E[h(Y)]\)이다. 다음으로 \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)\)이다(5.3절). 또 mgf가 \(M_{X+Y} = M_XM_Y\)로 곱해진다(3.2절).

예제 5.2.2

독립인 두 부품의 수명이 각각 \(\text{Exp}(\lambda_1)\), \(\text{Exp}(\lambda_2)\)이다. 직렬로 연결한 시스템의 수명 \(T = \min(T_1, T_2)\)의 분포는?

풀이. 독립이므로 \(P(T > t) = P(T_1 > t)P(T_2 > t) = e^{-(\lambda_1 + \lambda_2)t}\)이다. 따라서 \(T \sim \text{Exp}(\lambda_1 + \lambda_2)\)이고 평균 수명은 \(\frac1{\lambda_1 + \lambda_2}\)로 짧아진다. 1.3절 직렬 신뢰도의 연속판이다.

흔한 오해공분산이 0이면 독립이라고 생각하기 쉽다. 하지만 독립이면 공분산이 0이어도(5.3절), 거꾸로는 성립하지 않는다. 가령 \(X\)가 \(\{-1, 0, 1\}\)에서 균일하고 \(Y = X^2\)이면 공분산은 0이지만 \(Y\)는 \(X\)로 완전히 정해진다.
마무리

두 확률변수는 모든 점에서 결합분포가 주변분포의 곱일 때만 독립이므로, 처음 질문처럼 차이가 작아도 한 칸이라도 다르면 독립이 아니다. 연속이면 인수분해와 직사각형 영역으로 빠르게 판정한다. 독립이면 \(E[XY] = E[X]E[Y]\)이고 분산이 더해지며 mgf가 곱해진다.

5.2.3연습문제

기본

  1. \(f(x, y) = 6e^{-2x - 3y}\) (\(x, y \ge 0\))에서 \(X\)와 \(Y\)는 독립인가? 주변분포는?
    답

    \(2e^{-2x}\cdot3e^{-3y}\)로 인수분해되고 영역이 사분면이라 독립. \(X \sim \text{Exp}(2)\), \(Y \sim \text{Exp}(3)\).
