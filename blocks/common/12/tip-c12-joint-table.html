결합 확률표에서 주변분포는 가장자리 합으로, 조건부분포는 한 줄을 그 줄의 합으로 나눠 구한다

요령 · 결합분포

언제 쓰는가

두 확률변수의 결합 확률표가 주어지고 주변분포, 조건부확률, 독립 여부, 공분산을 묻는 문제입니다.

요령

  1. 가장자리를 채운다
    행 합은 \(X\)의 주변분포, 열 합은 \(Y\)의 주변분포입니다. 전체 합이 1인지 확인합니다.
  2. 조건부는 한 줄만
    \(P(Y = y\mid X = x)\)는 \(X = x\)인 행의 각 칸을 그 행의 합으로 나눕니다.
  3. 독립은 모든 칸
    모든 칸에서 칸 = 행 합 × 열 합이어야 독립입니다. 한 칸이라도 다르면 종속입니다.
  4. 공분산
    \(\text{Cov} = E[XY] - E[X]E[Y]\). \(E[XY]\)는 칸마다 \(xy\times\)확률을 더합니다.

흔한 실수

  • 조건부확률을 표의 칸 값 그대로 쓰는 것.
  • 한 칸만 확인하고 독립이라고 하는 것.

바로 풀어보기

\(P(0, 0) = 0.3\), \(P(0, 1) = 0.2\), \(P(1, 0) = 0.1\), \(P(1, 1) = 0.4\)일 때(앞이 \(X\), 뒤가 \(Y\)) \(P(Y = 1\mid X = 1)\), 독립 여부, 공분산을 구하세요.

답과 풀이

답: 0.8, 종속, 공분산 0.1

행 합: \(P(X = 0) = 0.5\), \(P(X = 1) = 0.5\). 열 합: \(P(Y = 0) = 0.4\), \(P(Y = 1) = 0.6\). \(P(Y = 1\mid X = 1) = \frac{0.4}{0.5} = 0.8\)입니다.

\(0.4 \ne 0.5\times0.6 = 0.3\)이므로 종속입니다. \(E[XY] = 0.4\), \(E[X]E[Y] = 0.5\times0.6 = 0.3\)이므로 공분산은 0.1입니다.

이 요령으로 풀리는 문제

  • 여러 개의 확률변수 단원 연습 1번, 2번, 3번, 6번
영상 콘티 · 40초
  1. 0~5초2×2 표에 0.3, 0.2, 0.1, 0.4가 채워져 있습니다.이 표에서 무엇을 읽을까요?
  2. 5~13초각 행의 숫자가 오른쪽으로, 각 열의 숫자가 아래로 미끄러져 가장자리에 합 0.5, 0.5, 0.4, 0.6이 쌓입니다.가장자리 합이 주변분포.
  3. 13~22초\(X = 1\) 행만 남고 나머지가 흐려진 뒤, 그 행이 0.5로 나뉘어 0.2, 0.8이 됩니다.조건부는 한 줄을 그 합으로 나눕니다.
  4. 22~31초오른쪽 아래 칸 0.4 옆에 가장자리 곱 0.3이 놓이고 ≠ 표시가 뜹니다.한 칸이라도 다르면 종속.
  5. 31~40초\(E[XY] = 0.4\)와 \(E[X]E[Y] = 0.3\)의 차 0.1이 공분산으로 표시됩니다.공분산은 곱의 평균 빼기 평균의 곱.
