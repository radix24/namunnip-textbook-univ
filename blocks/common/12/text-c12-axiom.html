표본공간과 확률의 공리

본문
이 절에서 배울 것
  • 표본공간, 사건, 사건의 연산을 집합으로 나타낸다.
  • 확률의 세 공리에서 여사건, 공집합, 합사건의 확률 공식을 끌어낸다.

  • 집합의 연산(합집합, 교집합, 여집합). 확률의 직관적 뜻 (공통7 3.1절)이 있으면 도움이 됩니다.

1.1.1표본공간과 사건

  • 시행: 결과를 미리 알 수 없는 실험이나 관찰.
  • 표본공간 \(S\): 일어날 수 있는 모든 결과의 집합.
  • 사건: \(S\)의 부분집합.

예를 들어 부품 세 개를 검사해 양호(G)와 불량(D)을 기록하면 \(S = \{GGG, GGD, \dots, DDD\}\)로 8개 원소입니다. "불량이 정확히 하나"는 사건 \(A = \{GGD, GDG, DGG\}\)입니다. 부품의 수명처럼 결과가 실수이면 \(S = [0, \infty)\)처럼 무한 집합이 됩니다.

사건의 연산은 집합의 연산과 같습니다. \(A \cup B\)는 "\(A\) 또는 \(B\)", \(A \cap B\)는 "\(A\)이고 \(B\)", \(A^c\)는 "\(A\)가 아님"입니다. \(A \cap B = \varnothing\)이면 두 사건은 배반(동시에 일어날 수 없음)입니다.

1.1.2확률의 공리

정의 1.1.1 (콜모고로프의 공리)

사건 \(A\)에 실수 \(P(A)\)를 대응시키는 함수 \(P\)가 다음을 만족하면 확률이라 한다.

  1. \(P(A) \ge 0\).
  2. \(P(S) = 1\).
  3. 서로 배반인 사건 \(A_1, A_2, \dots\)에 대해 \(P\left(\bigcup_i A_i\right) = \sum_i P(A_i)\).

확률이 "무엇인지"(상대도수의 극한인지, 믿음의 정도인지)를 묻지 않고, 어떤 규칙을 따르는지만 정한 것입니다. 나머지 성질은 모두 이 세 줄에서 나옵니다.

1.1.3공리에서 끌어낸 성질

정리 1.1.2
  1. \(P(A^c) = 1 - P(A)\).
  2. \(P(\varnothing) = 0\).
  3. \(A \subset B\)이면 \(P(A) \le P(B)\). 특히 \(P(A) \le 1\).
  4. \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).

증명.

  • (1) \(A\)와 \(A^c\)는 배반이고 합이 \(S\)이므로 공리 3과 2에서 \(P(A) + P(A^c) = 1\).
  • (2) (1)에서 \(A = S\)로 두면 \(P(\varnothing) = 1 - 1 = 0\).
  • (3) \(B = A \cup (B \cap A^c)\)이고 두 부분이 배반이므로 \(P(B) = P(A) + P(B \cap A^c) \ge P(A)\)(공리 1).
  • (4) \(A \cup B = A \cup (B \cap A^c)\)(배반)이고 \(B = (A \cap B) \cup (B \cap A^c)\)(배반)이므로, 두 식에서 \(P(B \cap A^c)\)를 지우면 된다. ∎
예제 1.1.3

어떤 부품에 긁힘이 있을 확률 0.12, 치수 불량일 확률 0.08, 둘 다일 확률 0.03이다. 적어도 하나의 결함이 있을 확률과 결함이 없을 확률은?

풀이. \(0.12 + 0.08 - 0.03 = 0.17\). 결함 없음은 \(1 - 0.17 = 0.83\).

결과가 \(N\)가지이고 모두 똑같이 일어날 법하면 \(P(A) = \frac{|A|}{N}\)입니다(고전적 확률). 이때 경우의 수를 세는 데 순열 \({}_nP_r\)과 조합 \(\binom nr\)을 씁니다.

요약
  1. 표본공간 \(S\), 사건은 그 부분집합. 배반이면 \(A \cap B = \varnothing\).
  2. 공리: 음이 아님, \(P(S) = 1\), 배반 사건의 가산 합.
  3. \(P(A^c) = 1 - P(A)\), \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).

1.1.4연습문제

기본

  1. 세 사건에 대한 포함-배제 공식 \(P(A \cup B \cup C)\)를 정리 1.1.2 (4)를 두 번 써서 끌어내어라.
    답

    \(P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C)\).

  2. 부품 10개 가운데 불량 2개가 있다. 3개를 뽑을 때 불량이 하나도 없을 확률은?
    답

    \(\binom83/\binom{10}3 = 56/120 \approx 0.467\).
