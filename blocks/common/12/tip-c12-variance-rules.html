분산은 상수배를 제곱으로 끌어내고, 독립인 두 양은 더하든 빼든 분산을 더한다

요령 · 평균과 분산의 성질

언제 쓰는가

단위를 바꾸거나 여러 측정값을 더하고 빼서 만든 양의 평균과 표준편차를 구하는 문제이다.

요령

  1. 평균은 그대로 따라간다
    \(E[aX + b] = aE[X] + b\), \(E[X \pm Y] = E[X] \pm E[Y]\).
  2. 상수배는 제곱
    \(\text{Var}(aX + b) = a^2\text{Var}(X)\). 더한 상수 \(b\)는 퍼짐을 바꾸지 않는다. 표준편차는 \(|a|\)배이다.
  3. 독립이면 분산을 더한다
    \(\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y)\). 빼도 더한다.
  4. 표준편차는 마지막에
    분산끼리 더한 뒤 제곱근을 씌운다. 표준편차끼리 더하지 않는다.

흔한 실수

  • \(X - Y\)의 분산을 \(\text{Var}(X) - \text{Var}(Y)\)로 빼는 것.
  • 표준편차 2와 1.5를 더해 3.5로 쓰는 것.

바로 풀어보기

\(X\)는 평균 10, 표준편차 2이고 \(Y\)는 평균 4, 표준편차 1.5이며 서로 독립이다. \(X - Y\)와 \(3X + 1\)의 평균과 표준편차를 구하여라.

답과 풀이

답: \(X - Y\): 평균 6, 표준편차 2.5. \(3X + 1\): 평균 31, 표준편차 6

\(X - Y\): 평균 \(10 - 4 = 6\), 분산 \(4 + 2.25 = 6.25\), 표준편차 2.5이다.

\(3X + 1\): 평균 31, 분산 \(9\times4 = 36\), 표준편차 6이다. 더한 1은 퍼짐에 영향이 없다.

이 요령으로 풀리는 문제

  • 확률변수의 적률 단원 연습 3번, 6번
  • 확률변수의 함수 단원 연습 3번, 4번
영상 콘티 · 40초
  1. 0~5초두 분포 \(X\), \(Y\)의 종 모양이 나란히 놓인다.빼면 퍼짐은 줄어들까?
  2. 5~14초\(X - Y\) 분포를 만들자 오히려 더 넓은 종이 나타난다.빼도 퍼짐은 커진다.
  3. 14~23초직각삼각형의 두 변 2와 1.5에서 빗변 2.5가 그려집니다(분산이 더해지는 그림).분산을 더하고 제곱근을 씌운다.
  4. 23~32초\(X\) 분포가 가로로 3배 늘어나고 1만큼 오른쪽으로 밀린다. 폭은 3배, 위치만 1 이동.상수배는 퍼짐을 키우고 더한 상수는 옮기기만.
  5. 32~40초표준편차 2 + 1.5 = 3.5 계산이 나오다 X가 그어진다.표준편차끼리 더하지 않는다.
