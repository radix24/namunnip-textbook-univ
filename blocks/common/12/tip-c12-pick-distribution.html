이산 분포는 '무엇을 세는가'로 고른다

요령 · 이산 분포 고르기

언제 쓰는가

결함 수, 성공 횟수, 처음 성공까지의 횟수, 도착 수처럼 개수를 세는 문제에서 어떤 분포를 쓸지 정할 때이다.

요령

  1. 횟수가 정해진 시행 속 성공 수
    \(n\)번 시행, 매번 같은 확률 \(p\), 독립이면 이항분포 \(B(n, p)\).
  2. 처음 성공까지 시행 수
    기하분포, \(P(X = k) = (1 - p)^{k-1}p\), 평균 \(\frac1p\).
  3. 단위 시간·면적의 개수
    평균 \(\lambda\)로 드문드문 독립적으로 일어나면 포아송, \(P(X = k) = \frac{e^{-\lambda}\lambda^k}{k!}\).
  4. 작은 모집단에서 비복원
    정해진 상자에서 되돌려 놓지 않고 뽑으면 초기하분포.

흔한 실수

  • '하루 동안의 전화 수'처럼 시행 횟수가 정해지지 않은 개수에 이항분포를 쓰는 것.
  • 포아송의 \(\lambda\)를 구간 길이에 맞추지 않는 것(1시간 평균 3이면 20분은 1).

바로 풀어보기

각 상황에 알맞은 분포를 골라라. (가) 하루에 들어오는 고장 신고 수(평균 3건) (나) 불량률 5%인 공정에서 20개 중 불량 수 (다) 성공률 20%인 시도에서 처음 성공까지의 시도 수 (라) 50개 중 5개가 불량인 상자에서 3개를 꺼낼 때 불량 수. 또 (가)에서 신고가 하나도 없을 확률은?

답과 풀이

답: (가) 포아송 (나) 이항 (다) 기하 (라) 초기하. 신고가 없을 확률 \(e^{-3} \approx 0.050\)

(가)는 시행 횟수가 없는 '시간 안의 개수'라 포아송, (나)는 횟수 20이 정해진 성공 수라 이항, (다)는 처음 성공까지라 기하, (라)는 작은 상자에서 비복원이라 초기하이다.

포아송 \(\lambda = 3\)에서 \(P(X = 0) = e^{-3} \approx 0.0498\)이다.

이 요령으로 풀리는 문제

  • 특수한 확률분포 단원 연습 1번, 2번, 3번
영상 콘티 · 45초
  1. 0~5초네 장면(신고 전화, 생산 라인, 슛 연습, 부품 상자)이 카드로 펼쳐진다.각각 어떤 분포일까?
  2. 5~14초카드마다 '무엇을 세나?' 질문이 붙고, 답이 '시간 안의 개수', '정해진 횟수 속 성공', '처음 성공까지', '상자에서 뽑기'로 채워진다.무엇을 세는지부터 본다.
  3. 14~24초네 분포 상자(포아송, 이항, 기하, 초기하)가 아래에 놓이고 카드가 하나씩 제 상자로 날아 들어간다.세는 것이 분포를 정한다.
  4. 24~34초포아송 상자에서 0, 1, 2, … 막대그래프가 그려지고 0의 막대 0.050이 강조된다.포아송: 평균만 알면 된다.
  5. 34~45초1시간 평균 3인 시계가 20분으로 잘리며 \(\lambda\)가 1로 바뀐다.\(\lambda\)는 구간 길이에 맞춘다.
