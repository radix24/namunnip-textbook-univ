  • 조건부확률 (1.2절).

1.3.1독립의 정의

정의 1.3.1

\(P(A \cap B) = P(A)\,P(B)\)이면 \(A\)와 \(B\)는 독립이다. \(P(B) > 0\)이면 이는 \(P(A \mid B) = P(A)\)와 같다.

\(B\)가 일어났다는 정보가 \(A\)의 확률을 바꾸지 않는다는 뜻입니다. \(A\)와 \(B\)가 독립이면 \(A\)와 \(B^c\), \(A^c\)와 \(B^c\)도 독립입니다.

예제 1.3.2

주사위 두 개를 던진다. \(A\) = 첫째가 짝수, \(B\) = 합이 7, \(C\) = 합이 8. \(A\)와 \(B\), \(A\)와 \(C\)는 독립인가?

풀이. \(P(A) = \frac12\), \(P(B) = \frac6{36} = \frac16\), \(P(A \cap B) = \frac3{36} = \frac1{12} = P(A)P(B)\): 독립. \(P(C) = \frac5{36}\), \(P(A \cap C) = \frac3{36}\)((2,6), (4,4), (6,2))인데 \(P(A)P(C) = \frac5{72}\): 독립이 아님.

1.3.2독립과 배반

배반인 두 사건(\(A \cap B = \varnothing\))은 확률이 모두 양수이면 독립이 아닙니다. 한쪽이 일어나면 다른 쪽은 절대 일어나지 않으므로 강하게 의존합니다(\(P(A \cap B) = 0 \ne P(A)P(B)\)). 두 낱말을 헷갈리지 않아야 합니다.

1.3.3여러 사건의 독립과 신뢰도

\(A_1, \dots, A_n\)이 서로 독립이라는 것은 그 가운데 아무 몇 개를 골라도 곱셈 공식이 성립한다는 뜻입니다(두 개씩 독립인 것만으로는 부족함). 부품이 서로 독립으로 고장 난다고 가정하면 시스템의 신뢰도(작동할 확률)를 계산할 수 있습니다. 부품 \(i\)의 신뢰도를 \(r_i\)라 하면

  • 직렬(모두 작동해야 함): \(R = r_1 r_2 \cdots r_n\).
  • 병렬(하나만 작동하면 됨): \(R = 1 - (1 - r_1)(1 - r_2)\cdots(1 - r_n)\).
예제 1.3.3

신뢰도 0.9인 펌프 두 대를 병렬로 두고, 이것을 신뢰도 0.95인 밸브와 직렬로 연결했다. 시스템의 신뢰도는?

풀이. 병렬부 \(1 - 0.1^2 = 0.99\). 전체 \(0.99 \times 0.95 = 0.9405\). 펌프 한 대만 쓰면 \(0.9 \times 0.95 = 0.855\)이므로, 예비 부품(중복)이 신뢰도를 크게 높입니다. 다만 같은 원인(정전, 같은 제조 결함)으로 함께 고장 나면 독립 가정이 깨져 실제 신뢰도는 이보다 낮습니다.

요약
  1. 독립: \(P(A \cap B) = P(A)P(B)\), 곧 \(P(A \mid B) = P(A)\).
  2. 배반이면서 확률이 양수인 두 사건은 독립이 아니다.
  3. 직렬 \(\prod r_i\), 병렬 \(1 - \prod(1 - r_i)\).
