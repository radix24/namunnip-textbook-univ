적률과 적률생성함수

본문

평균은 \(E[X]\), 분산에는 \(E[X^2]\)이 필요하고, 분포의 치우침을 보려면 \(E[X^3]\)까지 구해야 한다. 이것들을 하나하나 적분하는 대신, 함수 하나에 모두 담아 두고 필요할 때 꺼내 쓸 수는 없을까? 그리고 독립인 두 확률변수를 더한 분포는 어떻게 알아낼까?

먼저 알아야 할 것기댓값과 분산(3.1절)과 테일러 급수(미분적분학(1) 8.4절)를 쓴다.

3.2.1적률

\(E[X^k]\)을 \(k\)차 적률이라 한다. 1차 적률은 평균이고, 2차 적률로 분산(\(E[X^2] - \mu^2\))을 얻는다. 또 3차, 4차 중심 적률은 분포의 비대칭(왜도)과 꼬리의 두께(첨도)를 나타낸다.

3.2.2적률생성함수

처음 질문의 "적률을 모두 담은 함수"가 다음이다.

정의 3.2.1

0 근처의 \(t\)에서 \(M_X(t) = E[e^{tX}]\)이 존재하면 이를 적률생성함수(mgf)라 한다.

왜 적률이 담겨 있을까? \(e^{tX} = 1 + tX + \frac{t^2X^2}{2!} + \cdots\)의 기댓값을 취하면 \(M_X(t) = 1 + tE[X] + \frac{t^2}{2!}E[X^2] + \cdots\)이다. 즉 테일러 계수에 적률이 들어 있으므로 다음을 얻는다.

\[M_X^{(k)}(0) = E[X^k].\]

그래서 적률을 하나하나 적분하는 대신, \(M\)을 한 번 구해 두고 미분만 하면 된다. 주요 분포의 mgf는 다음과 같다.

분포\(M_X(t)\)평균분산
이항 \((n, p)\)\((1 - p + pe^t)^n\)\(np\)\(np(1-p)\)
포아송 \((\lambda)\)\(e^{\lambda(e^t - 1)}\)\(\lambda\)\(\lambda\)
지수 \((\lambda)\)\(\frac{\lambda}{\lambda - t}\) (\(t < \lambda\))\(\frac1\lambda\)\(\frac1{\lambda^2}\)
정규 \((\mu, \sigma^2)\)\(e^{\mu t + \sigma^2t^2/2}\)\(\mu\)\(\sigma^2\)
예제 3.2.2

지수분포의 mgf \(M(t) = \frac{\lambda}{\lambda - t}\)에서 평균과 분산을 구하여라.

풀이. 미분하면 \(M'(t) = \frac{\lambda}{(\lambda - t)^2}\), \(M''(t) = \frac{2\lambda}{(\lambda - t)^3}\)이다. 따라서 \(E[X] = M'(0) = \frac1\lambda\), \(E[X^2] = M''(0) = \frac2{\lambda^2}\)이고, \(\mathrm{Var} = \frac2{\lambda^2} - \frac1{\lambda^2} = \frac1{\lambda^2}\)이다.

그림 1에서 \(\lambda\)를 키우면 0에서의 접선이 눕는다. 기울기 \(M'(0) = \frac1\lambda\)가 평균이므로, 고장률 \(\lambda\)가 클수록 평균 수명이 짧다는 뜻이다. 또 \(t\)가 \(\lambda\)에 다가가면 \(M(t)\)가 무한히 커지므로 mgf는 \(t < \lambda\)에서만 존재한다.

3.2.3두 가지 중요한 성질

첫째는 유일성으로, 두 확률변수의 mgf가 0 근처에서 같으면 분포가 같다. 둘째는 독립인 합으로, \(X\), \(Y\)가 독립이면 \(M_{X+Y}(t) = M_X(t)\,M_Y(t)\)이다.

처음 질문의 둘째 물음은 이 둘을 합쳐 답한다. 예를 들어 독립인 포아송 \(X \sim \text{Poi}(\lambda_1)\), \(Y \sim \text{Poi}(\lambda_2)\)이면 \(M_{X+Y} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}\)이다. 이것은 \(\text{Poi}(\lambda_1 + \lambda_2)\)의 mgf이므로, 유일성에서 \(X + Y \sim \text{Poi}(\lambda_1 + \lambda_2)\)이다. 가령 두 생산 라인의 시간당 불량 수를 합친 것도 포아송이다. 같은 방법으로 독립인 정규분포의 합도 정규분포임을 보일 수 있다(6.2절). 한편 \(aX + b\)의 mgf는 \(e^{bt}M_X(at)\)이다.

마무리

적률생성함수 \(M_X(t) = E[e^{tX}]\)는 처음 질문처럼 모든 적률을 테일러 계수에 담고 있어, \(M^{(k)}(0) = E[X^k]\)로 미분만 하면 평균과 분산을 얻는다. mgf는 분포를 하나로 정하고(유일성), 독립인 합의 mgf는 곱이므로 합의 분포를 알아내는 데 쓴다.
