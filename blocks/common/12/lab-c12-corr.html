상관계수와 합의 분산

실습 · 공분산

목표

상관계수 \(\rho\)를 바꾸며 산점도의 모양을 보고, \(\mathrm{Var}(X \pm Y) = \mathrm{Var}X + \mathrm{Var}Y \pm 2\mathrm{Cov}\)를 표본으로 확인한다. 성취기준 [공통12-05-03].

준비

\(X\)는 표준정규분포, \(Y\)는 표준편차 \(\sigma_Y\)이고 \(X\)와의 상관계수가 \(\rho\)인 정규분포에서 300쌍을 뽑았다. 빨간 점선은 \(Y = \rho\sigma_Y X\)이다. "새 표본"을 누르면 같은 조건에서 다시 뽑는다.

절차

  1. \(\rho\)를 −1에서 1까지 옮기며 산점도가 어떻게 바뀌는지 본다.
  2. \(\rho = 0\)에서 "새 표본"을 여러 번 눌러 표본 상관계수 \(r\)이 얼마나 흔들리는지 본다.
  3. \(\rho = 0.6\)과 \(-0.6\)에서 \(\mathrm{Var}(X + Y)\)와 \(\mathrm{Var}(X - Y)\)를 비교한다.
  4. \(\sigma_Y\)를 2로 바꿔도 \(r\)은 그대로인지 본다.

기대 결과

  • \(|\rho|\)가 1에 가까울수록 점이 직선 둘레에 모이고, \(\rho = \pm1\)이면 직선 위에 놓인다.
  • \(\rho = 0\)이어도 \(r\)은 대략 ±0.1 범위에서 흔들린다(300쌍일 때).
  • \(\sigma_Y = 1\), \(\rho = 0.6\)이면 \(\mathrm{Var}(X + Y) = 3.2\), \(\mathrm{Var}(X - Y) = 0.8\). \(\rho = -0.6\)이면 둘이 바뀐다.
  • \(\sigma_Y\)를 바꾸면 공분산은 바뀌지만 \(r\)은 거의 그대로다.

분석

  1. 두 측정기의 오차가 양의 상관을 가질 때, 두 측정값의 차이로 무엇을 구하면 오차가 줄어드는 이유를 \(\mathrm{Var}(X - Y)\)로 설명해 보자.
  2. \(\rho = 0\)인데 \(X\)와 \(Y\)가 독립이 아닌 예를 5.2절에서 찾아 설명해 보자.
