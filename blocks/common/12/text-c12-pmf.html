2.1.1확률변수

확률변수 \(X\)는 표본공간의 각 결과에 실수를 하나씩 대응시키는 함수입니다. 부품 세 개 검사에서 "불량의 개수"는 \(GGD \mapsto 1\), \(DDD \mapsto 3\)처럼 결과를 수로 바꿉니다. 값이 셀 수 있는(유한하거나 1, 2, 3, ...처럼 늘어놓을 수 있는) 확률변수를 이산, 구간의 모든 실수를 값으로 가질 수 있는 것을 연속(2.2절)이라 합니다. 대문자 \(X\)는 확률변수, 소문자 \(x\)는 그것이 가지는 구체적인 값입니다.

2.1.2확률질량함수

정의 2.1.1

이산 확률변수 \(X\)의 확률질량함수(pmf)는 \(p(x) = P(X = x)\)이다. \(p(x) \ge 0\)이고 \(\sum_x p(x) = 1\).

예제 2.1.2

불량률 0.1인 공정에서 부품 3개를 독립으로 뽑을 때 불량 수 \(X\)의 pmf를 구하여라.

풀이. 불량이 \(k\)개인 배열은 \(\binom3k\)가지이고 각각 확률 \(0.1^k0.9^{3-k}\)입니다.

\(x\)0123
\(p(x)\)0.7290.2430.0270.001
\(F(x)\)0.7290.9720.9991

합이 1인지 확인하는 습관을 들입니다. 이것은 4.1절의 이항분포입니다.

2.1.3누적분포함수

정의 2.1.3

확률변수 \(X\)의 누적분포함수(cdf)는 \(F(x) = P(X \le x)\)이며, 모든 실수 \(x\)에서 정의된다.

  • \(F\)는 감소하지 않는다. \(\lim_{x \to -\infty}F(x) = 0\), \(\lim_{x \to \infty}F(x) = 1\).
  • 오른쪽 연속이다.
  • 이산이면 \(F\)는 계단 함수이고, 각 값 \(x\)에서 \(p(x)\)만큼 뛴다. 그래서 \(p(x) = F(x) - F(x^-)\).
  • \(P(a < X \le b) = F(b) - F(a)\).

위 예에서 \(F(1.5) = P(X \le 1.5) = 0.972\)이고, \(P(X \ge 2) = 1 - F(1) = 0.028\)입니다. 이산 확률변수에서는 \(\le\)와 \(<\)가 다르다는 것(\(P(X < 2) = F(1)\))에 주의합니다.

요약
  1. 확률변수 = 결과를 수로 바꾸는 함수. 이산과 연속.
  2. pmf \(p(x) = P(X = x)\), 합 1.
  3. cdf \(F(x) = P(X \le x)\), 이산이면 계단, \(P(a < X \le b) = F(b) - F(a)\).

2.1.4연습문제

기본

  1. \(p(x) = c\,x\) (\(x = 1, 2, 3, 4\))가 pmf가 되도록 \(c\)를 정하고 \(P(X \ge 3)\)을 구하여라.
    답

    \(c(1 + 2 + 3 + 4) = 1\)에서 \(c = 0.1\). \(P(X \ge 3) = 0.3 + 0.4 = 0.7\).
