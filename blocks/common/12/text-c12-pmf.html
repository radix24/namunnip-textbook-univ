이산 확률변수: 확률질량함수와 누적분포함수

본문

부품 세 개를 검사한 결과는 GGD, DGD처럼 글자열이지만, 우리가 궁금한 것은 대개 "불량이 몇 개인가"라는 수이다. 결과를 수로 바꾼 뒤 그 수가 각 값을 가질 확률을 어떻게 나타낼까? 또 "불량이 1개 이하"처럼 누적된 확률은 어떻게 한눈에 읽을까?

먼저 알아야 할 것확률의 공리와 독립(1.1절, 1.3절)을 쓴다.

2.1.1확률변수

처음 질문처럼 결과를 수로 바꾸는 것이 확률변수이다. 확률변수 \(X\)는 표본공간의 각 결과에 실수를 하나씩 대응시키는 함수이다. 가령 부품 세 개 검사에서 "불량의 개수"는 \(GGD \mapsto 1\), \(DDD \mapsto 3\)처럼 결과를 수로 바꾼다.

값이 셀 수 있는(유한하거나 1, 2, 3, …처럼 늘어놓을 수 있는) 확률변수를 이산 확률변수라 하고, 구간의 모든 실수를 값으로 가질 수 있는 것을 연속 확률변수(2.2절)라 한다. 대문자 \(X\)는 확률변수, 소문자 \(x\)는 그것이 가지는 구체적인 값이다.

2.1.2확률질량함수

정의 2.1.1

이산 확률변수 \(X\)의 확률질량함수(pmf)는 \(p(x) = P(X = x)\)이다. \(p(x) \ge 0\)이고 \(\sum_x p(x) = 1\).

예제 2.1.2

불량률 0.1인 공정에서 부품 3개를 독립으로 뽑을 때 불량 수 \(X\)의 pmf를 구하여라.

풀이. 불량이 \(k\)개인 배열은 \(\binom3k\)가지이고, 독립이므로 각각 확률 \(0.1^k0.9^{3-k}\)이다. 따라서 다음 표를 얻는다.

\(x\)0123
\(p(x)\)0.7290.2430.0270.001
\(F(x)\)0.7290.9720.9991

합이 1인지 확인하는 습관을 들인다. 이것은 4.1절의 이항분포이다. 그림 1의 왼쪽 막대가 이 표의 둘째 줄이다.

2.1.3누적분포함수

정의 2.1.3

확률변수 \(X\)의 누적분포함수(cdf)는 \(F(x) = P(X \le x)\)이며, 모든 실수 \(x\)에서 정의된다.

처음 질문의 누적된 확률이 이것이다. \(F\)는 감소하지 않고, \(\lim_{x \to -\infty}F(x) = 0\), \(\lim_{x \to \infty}F(x) = 1\)이며, 오른쪽 연속이다. 그리고 이산이면 \(F\)는 계단 함수이고, 각 값 \(x\)에서 \(p(x)\)만큼 뛴다. 그래서 \(p(x) = F(x) - F(x^-)\)이다. 또 구간의 확률은 \(P(a < X \le b) = F(b) - F(a)\)로 구한다.

위 예에서 \(F(1.5) = P(X \le 1.5) = 0.972\)이고, \(P(X \ge 2) = 1 - F(1) = 0.028\)이다. 그림 1에서 \(x\)를 움직이면 계단이 정수에서만 뛰고 그 사이에서는 평평하다는 것이 보인다. 한편 이산 확률변수에서는 \(\le\)와 \(<\)가 다르다는 데 주의한다. 가령 \(P(X < 2) = F(1)\)이다.

마무리

확률변수는 결과를 수로 바꾸는 함수이며 이산과 연속이 있다. 처음 질문처럼 각 값의 확률은 확률질량함수 \(p(x) = P(X = x)\)로 나타내고 합은 1이며, 누적된 확률은 누적분포함수 \(F(x) = P(X \le x)\)로 읽는다. 이산이면 \(F\)는 계단이고 \(P(a < X \le b) = F(b) - F(a)\)이다.

2.1.4연습문제

기본

  1. \(p(x) = c\,x\) (\(x = 1, 2, 3, 4\))가 pmf가 되도록 \(c\)를 정하고 \(P(X \ge 3)\)을 구하여라.
    답

    \(c(1 + 2 + 3 + 4) = 1\)에서 \(c = 0.1\). \(P(X \ge 3) = 0.3 + 0.4 = 0.7\).
