새 확률변수의 밀도는 누적분포함수로 바꿔 구한 뒤 미분한다

요령 · 확률변수의 변환

언제 쓰는가

\(Y = g(X)\)의 분포를 구하는 문제입니다. 특히 \(Y = X^2\)처럼 일대일이 아닌 변환에서 실수하기 쉬울 때 씁니다.

요령

  1. \(F_Y(y) = P(Y \le y)\)
    \(Y\)의 누적분포함수를 '\(g(X) \le y\)'라는 \(X\)의 사건으로 바꿉니다.
  2. \(X\)의 범위로 푼다
    \(g(X) \le y\)를 \(X\)의 구간으로 풀어 \(X\)의 분포로 계산합니다. 일대일이 아니면 구간이 둘 이상일 수 있습니다.
  3. 미분한다
    \(f_Y(y) = F_Y'(y)\).
  4. 범위와 넓이 확인
    \(Y\)가 가질 수 있는 값의 범위를 적고, 밀도의 적분이 1인지 확인합니다.

흔한 실수

  • \(f_Y(y) = f_X(g^{-1}(y))\)로 써서 도함수 인자를 빠뜨리는 것.
  • \(Y = X^2\)에서 \(X\)가 음수인 경우를 빠뜨리는 것.

바로 풀어보기

\(X\)가 \((0, 1)\)의 균일분포를 따를 때 \(Y = X^2\)의 밀도함수를 구하고, \(P(Y \le 0.25)\)를 구하세요.

답과 풀이

답: \(f_Y(y) = \frac{1}{2\sqrt y}\) (\(0 < y < 1\)), \(P(Y \le 0.25) = 0.5\)

\(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \sqrt y\) (\(0 < y < 1\))입니다. 미분하면 \(f_Y(y) = \frac{1}{2\sqrt y}\)입니다.

\(P(Y \le 0.25) = F_Y(0.25) = 0.5\)입니다. \(X\)가 절반의 확률로 0.5 이하이기 때문입니다. 검산: \(\int_0^1\frac{dy}{2\sqrt y} = 1\).

이 요령으로 풀리는 문제

  • 확률변수의 함수 단원 연습 1번, 2번
영상 콘티 · 40초
  1. 0~5초\(X\)의 평평한 균일분포 막대와 함수 \(y = x^2\) 그래프가 나란히 있습니다.\(Y = X^2\)의 분포는?
  2. 5~13초\(y\) 높이에 수평선을 긋자 그 아래에 해당하는 \(x\)의 구간 \([0, \sqrt y]\)가 바닥에 칠해집니다.\(Y \le y\)를 \(X\)의 구간으로 바꿉니다.
  3. 13~22초칠한 구간의 길이 \(\sqrt y\)가 누적분포 곡선 \(F_Y\)로 그려집니다.먼저 누적분포함수.
  4. 22~32초\(F_Y\) 곡선의 기울기가 밀도 \(\frac{1}{2\sqrt y}\)로 바뀌며 0 근처에서 높이 솟습니다.미분하면 밀도입니다.
  5. 32~40초\(X\)의 점들이 제곱되어 \(Y\)축으로 옮겨지면서 0 근처에 촘촘히 몰립니다.작은 값으로 몰리는 이유가 보입니다.
