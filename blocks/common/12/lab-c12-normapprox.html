이항분포를 정규분포로 바꿀 때 왜 0.5를 더할까?

실습 · 정규 근사와 연속성 수정

목표

불량률 \(p\)인 부품 \(n\)개 가운데 불량이 \(k\)개 이하일 확률처럼, 이항분포의 누적 확률은 \(n\)이 크면 정규분포로 어림합니다. 막대(이항)와 곡선(정규)을 겹쳐 보고, 막대의 폭 때문에 생기는 "0.5 수정"이 왜 필요한지 확인합니다. 성취기준 [공통12-04-03].

준비

  • \(X \sim B(n, p)\)의 평균은 \(np\), 표준편차는 \(\sqrt{np(1 - p)}\)입니다. 같은 평균과 표준편차를 가진 정규분포 곡선(주황)을 겹쳐 그립니다.
  • 진한 막대가 \(P(X \le k)\)에 들어가는 부분입니다. 막대 \(k\)는 \(k - 0.5\)부터 \(k + 0.5\)까지 폭 1을 차지하므로, 곡선 아래 넓이로 어림할 때는 \(k + 0.5\)까지 재야 합니다(세로 점선). 이것이 연속성 수정입니다.
  • \(\Phi\)는 표준정규분포의 누적분포함수입니다.

절차

  1. \(n = 20\), \(p = 0.5\), \(k = 8\)에서 세 값(정확, 정규 근사, 연속성 수정)을 기록합니다.
  2. \(n = 30\), \(p = 0.3\), \(k = 6\)과 \(n = 100\), \(p = 0.1\), \(k = 7\)에서 같은 것을 기록합니다.
  3. \(n = 10\), \(p = 0.1\), \(k = 1\)로 놓고 막대 모양과 곡선을 비교합니다.

기대 결과

  • \(n = 20\), \(p = 0.5\), \(k = 8\): 정확한 값 0.2517, 수정 없는 근사 0.1855(오차 −0.066), 연속성 수정 0.2512(오차 −0.0006). 0.5를 더하는 것만으로 오차가 100분의 1 가까이 줍니다.
  • \(n = 30\), \(p = 0.3\), \(k = 6\): 정확 0.1595, 수정 없이 0.1160, 수정하면 0.1596.
  • \(n = 100\), \(p = 0.1\), \(k = 7\): 정확 0.2061, 수정하면 0.2023.
  • \(n = 10\), \(p = 0.1\): \(np = 1\)이라 막대가 한쪽으로 치우쳐 있고 곡선은 0보다 왼쪽까지 퍼집니다. 연속성 수정을 해도 0.7009로 정확한 값 0.7361과 0.035나 다릅니다. 흔히 \(np \ge 5\), \(n(1 - p) \ge 5\)일 때 정규 근사를 씁니다.

분석

  1. \(P(X \ge k)\)나 \(P(X = k)\)를 어림할 때는 각각 어디까지 재야 하나요? 그림의 막대 폭으로 설명해 보세요.
  2. \(p\)가 0.5에서 멀어질수록 같은 \(n\)에서 근사가 나빠지는 이유를 막대 모양의 치우침으로 설명해 보세요.

더 해 보기

정규 근사가 성립하는 이유는 중심극한정리(6.3절)입니다. 이항분포는 베르누이 확률변수 \(n\)개의 합이기 때문입니다. \(p\)가 아주 작고 \(n\)이 크면 정규분포 대신 포아송 분포(4.1절)로 어림하는 것이 더 정확합니다.
