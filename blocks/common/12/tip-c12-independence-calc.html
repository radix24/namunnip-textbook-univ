두 사건이 독립인지는 \(P(A\cap B) = P(A)P(B)\)를 직접 계산해서만 판정한다

요령 · 독립

언제 쓰는가

두 사건이 독립인지, 배반인지 묻는 문제, 독립을 가정해 확률을 곱해도 되는지 판단할 때입니다.

요령

  1. 세 확률을 구한다
    \(P(A)\), \(P(B)\), \(P(A\cap B)\)를 각각 셉니다.
  2. 곱과 비교
    \(P(A\cap B) = P(A)P(B)\)이면 독립, 아니면 종속입니다. '느낌'으로 정하지 않습니다.
  3. 배반은 다른 말
    배반은 \(P(A\cap B) = 0\)입니다. 두 확률이 모두 양수인 배반 사건은 오히려 강하게 종속(하나가 일어나면 다른 것은 못 일어남)입니다.
  4. 조건부로 읽기
    독립이면 \(P(B\mid A) = P(B)\), 곧 \(A\)를 알아도 \(B\)의 확률이 그대로입니다.

흔한 실수

  • '서로 영향을 주지 않을 것 같다'는 이유로 독립이라 하는 것.
  • 배반이면 독립이라고 하는 것.

바로 풀어보기

카드 52장에서 한 장을 뽑습니다. \(A\) = 하트, \(B\) = 킹, \(C\) = 빨간 카드일 때 \(A\)와 \(B\), \(A\)와 \(C\)는 각각 독립인가요?

답과 풀이

답: \(A\)와 \(B\)는 독립, \(A\)와 \(C\)는 종속

\(P(A\cap B) = \frac1{52}\), \(P(A)P(B) = \frac{13}{52}\cdot\frac4{52} = \frac1{52}\)이므로 독립입니다. 무늬와 숫자는 서로 정보를 주지 않습니다.

\(P(A\cap C) = P(A) = \frac14\), \(P(A)P(C) = \frac14\cdot\frac12 = \frac18\)로 달라 종속입니다. 하트면 반드시 빨간 카드이기 때문입니다.

이 요령으로 풀리는 문제

  • 확률의 기본 개념 단원 연습 4번, 5번, 6번
영상 콘티 · 40초
  1. 0~5초카드 52장이 4줄 13칸 격자로 펼쳐집니다.하트와 킹은 독립일까요?
  2. 5~13초하트 줄(13장)과 킹 열(4장)이 각각 칠해지고, 겹치는 칸 하나가 진하게 표시됩니다.세 확률을 셉니다.
  3. 13~22초\(\frac{13}{52}\times\frac4{52}\)과 \(\frac1{52}\)이 저울에 올라 수평이 됩니다.곱과 같으면 독립.
  4. 22~32초빨간 카드 두 줄이 칠해지고 하트 줄이 그 안에 완전히 들어갑니다. 저울이 \(\frac14\)과 \(\frac18\)로 기웁니다.같지 않으면 종속.
  5. 32~40초'배반 = 독립?' 문장에 X가 그어지고, 겹침이 0인 두 영역이 서로 밀어내는 그림이 나옵니다.배반은 독립이 아닙니다.
