RL 직렬 회로의 전류와 위상

복소 임피던스 · 페이저 · 문제 해결 전략

출발점

교류 회로에서 저항은 \(R\), 코일은 \(i\omega L\), 축전기는 \(1/i\omega C\)의 복소 임피던스로 쓰면 직류처럼 옴의 법칙과 직병렬 공식을 쓸 수 있다. 크기는 진폭 비, 각도는 위상차이다.

문제 해결 전략 · 페이저 계산
  1. 각 소자의 임피던스를 복소수로 쓴다.
  2. 직렬은 더하고 병렬은 역수를 더한다.
  3. \(I = V/Z\): 크기와 위상을 구한다.
  4. 각 소자 전압을 구해 페이저 그림으로 점검한다.

\(R = 100\ \Omega\), \(L = 0.2\) H 직렬에 실효값 10 V, 60 Hz를 걸었다. 전류의 실효값, 전원과의 위상차, 저항과 코일 양단 전압은?

풀이

  1. \(X_L = 2\pi\times60\times0.2 = 75.4\ \Omega\). \(Z = 100 + 75.4i\), \(|Z| = 125.2\ \Omega\).
    코일 임피던스.
  2. \(I = 10/125.2 = 79.9\) mA.
    크기.
  3. 위상 \(\arctan(75.4/100) = 37.0°\): 전류가 전압보다 늦다.
    \(Z\)의 각.
  4. \(V_R = 7.99\) V, \(V_L = 6.02\) V. 산술 합 14.0 V지만 페이저 합은 \(\sqrt{7.99^2 + 6.02^2} = 10.0\) V.
    90° 어긋난 두 전압.

의미

멀티미터로 \(V_R\)과 \(V_L\)을 재서 더하면 전원 전압보다 크다. 실험에서 자주 보는 "이상한" 결과인데, 두 전압의 위상이 달라서 생긴다.

검산

전력: 저항만 소비, \(I^2R = 0.0799^2\times100 = 0.638\) W \(= VI\cos37° = 10\times0.0799\times0.799\). 같다.
