트랜지스터가 포화되는지 판단하기

활성 영역 · 포화 · 전류 이득 · 문제 해결 전략

출발점

활성 영역의 NPN 트랜지스터는 \(I_C = \beta I_B\), \(V_{BE} \approx 0.7\) V이다. 그런데 \(I_C\)가 컬렉터 회로가 허락하는 최댓값보다 커지려 하면 포화되어 \(V_{CE} \approx 0.2\) V로 붙고 \(I_C < \beta I_B\)가 된다.

문제 해결 전략 · 동작 영역 판단
  1. 베이스 회로로 \(I_B\)를 구한다.
  2. 활성이라 가정하고 \(I_C = \beta I_B\), \(V_{CE} = V_{CC} - I_CR_C\).
  3. \(V_{CE} > 0.2\) V이면 활성, 아니면 포화.
  4. 포화이면 \(I_C = (V_{CC} - 0.2)/R_C\)로 다시 쓴다.

\(V_{CC} = 10\) V, \(R_C = 1\ \text{k}\Omega\), \(\beta = 100\). 베이스에 5 V를 \(R_B\)로 연결한다. \(R_B = 100\ \text{k}\Omega\)와 \(R_B = 20\ \text{k}\Omega\)일 때 각각의 영역과 \(I_C\)는?

풀이

  1. \(R_B = 100\) k: \(I_B = (5 - 0.7)/10^5 = 43\ \mu\)A, \(I_C = 4.3\) mA, \(V_{CE} = 10 - 4.3 = 5.7\) V.
    활성 영역.
  2. \(R_B = 20\) k: \(I_B = 215\ \mu\)A, 활성이면 \(I_C = 21.5\) mA, \(V_{CE} = 10 - 21.5 = -11.5\) V.
    불가능한 값.
  3. 따라서 포화: \(I_C = (10 - 0.2)/1000 = 9.8\) mA.
    컬렉터 회로가 정한 최댓값.
  4. 포화에서는 \(I_C/I_B = 46 < \beta\).
    스위치로 켜진 상태.

의미

증폭기로 쓰려면 활성 영역 가운데에 동작점을 두고, 스위치로 쓰려면 포화(켜짐)와 차단(꺼짐)을 오간다. 디지털 회로의 트랜지스터는 대부분 스위치이다.

검산

포화 경계: \(I_B = 9.8\text{ mA}/100 = 98\ \mu\)A, 곧 \(R_B = 4.3/98\ \mu \approx 44\) kΩ. 100 kΩ(활성)과 20 kΩ(포화) 사이라 맞다.
