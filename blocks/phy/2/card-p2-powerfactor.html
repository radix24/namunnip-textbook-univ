RL 부하의 평균 전력과 역률 개선

임피던스의 각 · 역률 · 문제 해결 전략

출발점

임피던스 \(Z = |Z|e^{i\phi}\)에 실효값 \(V_{\text{rms}}\)를 걸면 \(I_{\text{rms}} = V_{\text{rms}}/|Z|\)이고, 전류는 전압보다 \(\phi\)만큼 늦다. 평균 전력은 \(V_{\text{rms}}I_{\text{rms}}\cos\phi = I_{\text{rms}}^2R\)이다. 축전기를 병렬로 달면 전원에서 본 임피던스의 각이 줄어 역률이 좋아진다.

문제 해결 전략 · 교류 전력 계산
  1. 각 소자의 임피던스를 구해 전체 \(Z\)를 복소수로 쓴다.
  2. \(|Z|\)와 각 \(\phi\)를 구한다.
  3. \(I_{\text{rms}}\), \(P = V_{\text{rms}}I_{\text{rms}}\cos\phi\)를 구하고 \(I^2R\)로 확인한다.

\(R = 30\ \Omega\), \(L = 0.127\) H의 직렬 부하에 220 V(실효값), 60 Hz를 건다. (가) \(|Z|\), 위상차, 전류, 평균 전력, 역률은? (나) 같은 평균 전력을 역률 1로 공급한다면 전류는 얼마인가?

풀이

  1. \(X_L = 2\pi\times60\times0.127 \approx 47.9\ \Omega\). \(Z = 30 + 47.9i\), \(|Z| = 56.5\ \Omega\).
    \(Z_L = i\omega L\).
  2. \(\phi = \tan^{-1}(47.9/30) = 57.9°\), 역률 \(\cos\phi = 0.53\).
    임피던스의 각.
  3. \(I_{\text{rms}} = 220/56.5 = 3.89\) A, \(P = 220\times3.89\times0.53 \approx 454\) W.
    평균 전력.
  4. 확인: \(I^2R = 3.89^2\times30 \approx 454\) W.
    저항에서만 소비.
  5. (나) \(454/220 = 2.06\) A. 역률 0.53일 때보다 전류가 약 47% 적다.
    \(P = VI\cos\phi\)에서 \(\cos\phi = 1\).

의미

같은 일을 하는데 역률이 낮으면 거의 두 배의 전류가 전선을 흐르고, 전선의 저항 손실은 전류의 제곱에 비례하므로 손실은 약 3.6배가 된다. 이 부하에 알맞은 축전기를 병렬로 달면 인덕터의 위상 지연을 상쇄해 전원 쪽 전류를 2.06 A 가까이로 줄일 수 있다.

검산

\(|Z|^2 = 30^2 + 47.9^2 = 3194\), \(\sqrt{3194} = 56.5\). 두 방법(\(VI\cos\phi\), \(I^2R\))의 전력이 같다.
