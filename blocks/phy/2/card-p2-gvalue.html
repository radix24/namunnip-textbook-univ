진자로 잰 중력 가속도의 불확도

불확도 전파 · 반복 측정 · 문제 해결 전략

출발점

측정값 \(q = f(x, y)\)의 불확도는 독립인 측정에서 \(\delta q = \sqrt{(\partial_xf\,\delta x)^2 + (\partial_yf\,\delta y)^2}\)이다. 여기서 \(\partial_xf\)는 \(y\)를 상수로 두고 \(x\)로만 미분한 값(편미분, 물리2 1.3절)으로, \(x\)가 조금 바뀔 때 \(q\)가 바뀌는 비율이다. 거듭제곱 꼴이면 상대 불확도로 쓰면 편하다.

문제 해결 전략 · 불확도 전파
  1. 각 측정의 불확도를 정한다(눈금의 반, 반복 측정의 표준 오차).
  2. 식을 거듭제곱 꼴로 쓰고 상대 불확도에 지수를 곱한다.
  3. 제곱합의 제곱근으로 더한다.
  4. 가장 큰 기여를 찾아 개선 방법을 정한다.

진자 길이 \(L = 1.000 \pm 0.002\) m, 20번 진동 시간 \(40.2 \pm 0.2\) s를 쟀다. \(g = 4\pi^2L/T^2\)과 그 불확도를 구하여라.

풀이

  1. \(T = 2.010 \pm 0.010\) s(20으로 나눔). \(g = 4\pi^2\times1.000/2.010^2 = 9.772\) m/s².
    여러 번 재서 시간 불확도를 줄였다.
  2. 상대 불확도: \(\delta L/L = 0.2\%\), \(2\delta T/T = 2\times0.50\% = 1.0\%\).
    \(T^2\)이라 지수 2.
  3. \(\delta g/g = \sqrt{0.2^2 + 1.0^2}\% = 1.02\%\), \(\delta g = 0.10\) m/s².
    제곱합.
  4. 결과 \(g = 9.77 \pm 0.10\) m/s². 표준값 9.80과 불확도 안에서 맞다.
    유효 숫자는 불확도에 맞춘다.

의미

시간 측정이 불확도를 지배한다. 20번 대신 100번 진동을 재면 시간 불확도가 1/5로 줄어 \(g\)의 불확도도 거의 1/5가 된다. 길이를 더 정밀하게 재는 것은 별 도움이 안 된다.

검산

\(T\)를 0.010 s 늘려 다시 계산하면 \(g = 9.675\), 차이 0.097. 전파 공식(시간 기여 0.098)과 맞다.
