RLC 공진 회로의 공진 진동수와 대역폭

공명 · Q 값 · 문제 해결 전략

출발점

RLC 직렬 회로는 \(\omega_0 = 1/\sqrt{LC}\)에서 임피던스가 \(R\)로 가장 작아 전류가 최대이다. 대역폭(전력 반값 폭)은 \(\Delta\omega = R/L\), \(Q = \omega_0/\Delta\omega = \frac1R\sqrt{L/C}\)이다. 물리1 4.4절의 진동자와 같은 수학이다.

문제 해결 전략 · 공진 회로
  1. \(f_0 = \frac1{2\pi\sqrt{LC}}\).
  2. \(Q = \frac1R\sqrt{L/C}\), 대역폭 \(f_0/Q\).
  3. 공진에서 전류 \(V/R\), 축전기 전압은 \(Q\)배.
  4. 측정 곡선의 반값 폭과 비교한다.

\(L = 10\) mH, \(C = 100\) nF, \(R = 20\ \Omega\) 직렬 회로에 1 V(실효값)를 건다. 공진 진동수, \(Q\), 대역폭, 공진에서 축전기 양단 전압은?

풀이

  1. \(f_0 = \frac1{2\pi\sqrt{10^{-2}\times10^{-7}}} = \frac1{2\pi\times3.16\times10^{-5}} = 5.03\) kHz.
    \(LC = 10^{-9}\).
  2. \(Q = \frac1{20}\sqrt{10^{-2}/10^{-7}} = \frac{316}{20} = 15.8\).
    \(\sqrt{L/C} = 316\ \Omega\).
  3. 대역폭 \(5.03/15.8 = 0.318\) kHz.
    \(R/2\pi L\)와 같다.
  4. 공진 전류 \(1/20 = 50\) mA, \(V_C = I/\omega_0C = 15.8\) V.
    전원 1 V인데 축전기에 15.8 V.

의미

공진에서 축전기와 코일 전압은 서로 반대 위상으로 \(Q\)배까지 커진다. 라디오 동조 회로는 이 성질로 약한 신호를 키우고, 높은 \(Q\) 회로는 전압 정격을 넘지 않게 조심해야 한다.

검산

공진에서 \(X_L = \omega_0L = 2\pi\times5030\times0.01 = 316\ \Omega = X_C\). 리액턴스가 지워져 \(Z = R\)이다.
