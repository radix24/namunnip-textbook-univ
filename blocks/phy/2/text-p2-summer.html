가산기: 여러 신호를 더하기

본문
이 절에서 배울 것
  • 가상 접지로 반전 가산기의 출력을 유도한다.
  • 입력 저항의 비로 가중 합을 만든다.
  • 가산기로 직류 오프셋을 더하거나 D/A 변환을 하는 원리를 안다.
먼저 알아야 할 것
  • 이상적 연산증폭기와 반전 증폭기 (6.1절), 키르히호프 전류 법칙 (2.1절).

6.2.1유도

반전 증폭기의 (−) 입력에 저항 \(R_1, R_2, \dots\)를 거쳐 신호 \(V_1, V_2, \dots\)를 함께 넣고, 되먹임 저항을 \(R_f\)라 합니다. 이상적 연산증폭기에서 (+) 입력이 접지이면 (−) 입력도 0 V(가상 접지)이고, 연산증폭기 입력으로는 전류가 들어가지 않습니다. 그러므로 각 입력 저항의 전류는 \(V_i/R_i\)로 서로 영향을 주지 않고, 이 전류들의 합이 모두 \(R_f\)를 지나갑니다(키르히호프 전류 법칙).

\[\sum_i \frac{V_i}{R_i} = -\frac{V_{\text{out}}}{R_f} \quad\Longrightarrow\quad V_{\text{out}} = -R_f\left(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots\right).\]

가상 접지 덕분에 한 입력의 신호원이 다른 입력의 신호원에 영향을 주지 않는다는 점이 수동 저항만으로 더하는 회로와 다릅니다.

6.2.2쓰임

  • 단순 합: \(R_1 = R_2 = \cdots = R_f\)이면 \(V_{\text{out}} = -(V_1 + V_2 + \cdots)\). 부호를 되돌리려면 이득 −1 반전 증폭기를 하나 더 단다.
  • 가중 합(믹서): 저항 비로 입력마다 다른 가중치를 준다. 음향 믹서의 기본 원리다.
  • 직류 오프셋 더하기: 신호에 일정한 직류 전압을 더해, 양의 전압만 받는 A/D 변환기(물리6) 범위에 맞춘다.
  • D/A 변환기: 저항을 \(R, 2R, 4R, 8R\)처럼 2배씩 다르게 하고 각 입력을 0 V 또는 기준 전압으로 켜고 끄면, 출력이 2진수의 크기에 비례한다(물리6에서 다룸).

출력은 전원 전압을 넘을 수 없으므로, 합이 커질 때 출력이 포화되지 않는지 확인해야 합니다(6.1절의 실제 연산증폭기의 한계).

요약
  1. 가상 접지로 입력 전류가 독립적으로 더해진다: \(V_{\text{out}} = -R_f\sum V_i/R_i\).
  2. 단순 합, 가중 합, 오프셋, D/A 변환에 쓴다. 출력 포화에 주의.

6.2.3연습문제

기본

  1. \(R_1 = R_2 = 10\) kΩ, \(R_f = 20\) kΩ인 가산기에 \(V_1 = 0.3\) V, \(V_2 = -0.5\) V를 넣으면 출력은?
    답

    \(-2\times(0.3 - 0.5) = +0.4\) V.

  2. 입력이 셋인 가산기에서 \(V_3\)만 두 배의 가중치를 주려면 \(R_3\)를 어떻게 정하는가? (\(R_1 = R_2 = R_f = R\))
    답

    \(R_3 = R/2\).
