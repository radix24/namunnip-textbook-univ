가산기: 여러 신호를 더하기

본문

음향 믹서는 마이크, 기타, 키보드의 신호를 각자 원하는 크기로 섞어 하나의 출력으로 만든다. 그냥 세 도선을 한데 묶으면 신호들이 서로를 끌어당겨 크기가 엉망이 된다. 서로 간섭하지 않고 정해진 비율로 더하려면 어떻게 해야 할까?

먼저 알아야 할 것이상적 연산증폭기와 반전 증폭기(6.1절), 키르히호프 전류 법칙(2.1절)을 쓴다.

6.2.1유도

도선을 그냥 묶으면 왜 안 될까? 묶은 점의 전압은 세 신호원이 서로 밀고 당긴 결과로 정해지고, 신호원 하나의 출력 저항이나 크기가 바뀌면 다른 신호까지 함께 바뀐다. 해결책은 묶는 점의 전압을 0으로 붙잡아 두는 것이다. 6.1절의 가상 접지가 바로 그 일을 한다.

반전 증폭기의 (−) 입력에 저항 \(R_1, R_2, \dots\)를 거쳐 신호 \(V_1, V_2, \dots\)를 함께 넣고, 되먹임 저항을 \(R_f\)라 하자. (+) 입력이 접지이므로 (−) 입력도 0 V이고, 연산증폭기 입력으로는 전류가 들어가지 않는다. 따라서 각 입력 저항의 전류는 \(V_i/R_i\)로, 다른 입력이 무엇이든 상관없이 정해진다. 그리고 키르히호프 전류 법칙에 따라 이 전류들의 합이 모두 \(R_f\)를 지나간다.

\[\sum_i \frac{V_i}{R_i} = -\frac{V_{\text{out}}}{R_f} \quad\Longrightarrow\quad V_{\text{out}} = -R_f\left(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots\right)\]

처음 질문의 답이 이 식이다. 가상 접지 덕분에 한 입력의 신호원이 다른 입력의 신호원에 영향을 주지 않고, 각 입력의 비중은 \(R_f/R_i\)로 따로 정할 수 있다. 저항만으로 더하는 수동 회로와의 결정적인 차이가 이것이다.

예제 6.2.1

\(R_f = 10\) kΩ, \(R_1 = 10\) kΩ, \(R_2 = 20\) kΩ, \(R_3 = 5\) kΩ인 가산기에 \(V_1 = 0.5\) V, \(V_2 = 1.0\) V, \(V_3 = -0.2\) V를 넣으면 출력은?

풀이. 가중치는 \(R_f/R_i\)이므로 각각 1, 0.5, 2이다. \(V_{\text{out}} = -(1\times0.5 + 0.5\times1.0 + 2\times(-0.2)) = -(0.5 + 0.5 - 0.4) = -0.6\) V이다. \(V_2\)의 신호원을 다른 것으로 바꿔도 첫째와 셋째 항은 그대로이다.

6.2.2쓰임

모든 저항을 같게 하면 \(V_{\text{out}} = -(V_1 + V_2 + \cdots)\)인 단순 합이 되고, 부호를 되돌리려면 이득 −1인 반전 증폭기를 하나 더 단다. 저항 비를 다르게 하면 입력마다 다른 가중치를 주는 가중 합이 되며, 처음 질문의 음향 믹서가 이 원리이다.

입력 하나에 일정한 직류 전압을 넣으면 신호에 직류 오프셋을 더할 수 있다. 가령 −1 V에서 +1 V로 흔들리는 신호를 0 V에서 2 V 범위로 옮겨, 양의 전압만 받는 A/D 변환기(물리6)에 맞출 때 쓴다. 한편 입력 저항을 \(R, 2R, 4R, 8R\)처럼 두 배씩 다르게 하고 각 입력을 0 V나 기준 전압으로 켜고 끄면, 출력이 그 켜고 끈 패턴을 2진수로 읽은 크기에 비례한다. 이것이 가장 단순한 D/A 변환기이며 물리6에서 다룬다.

흔한 실수입력이 많아지면 합이 커져 출력이 전원 전압에 닿아 잘리기 쉽다. 설계할 때 모든 입력이 최대일 때의 합이 출력 범위 안에 드는지 확인한다(6.1절).
마무리

반전 가산기는 (−) 입력을 가상 접지로 붙잡아 두므로, 각 입력의 전류 \(V_i/R_i\)가 서로 영향 없이 정해지고 그 합이 \(R_f\)를 지나 \(V_{\text{out}} = -R_f\sum V_i/R_i\)가 된다. 처음 질문의 믹서처럼 신호들이 간섭하지 않고 저항 비로 정한 가중치로 섞이는 까닭이 이것이다. 같은 회로로 단순 합, 가중 합, 직류 오프셋, D/A 변환을 만들며, 합이 출력 범위를 넘지 않게 주의한다.

6.2.3연습문제

기본

  1. \(R_1 = R_2 = 10\) kΩ, \(R_f = 20\) kΩ인 가산기에 \(V_1 = 0.3\) V, \(V_2 = -0.5\) V를 넣으면 출력은?
    답

    \(-2\times(0.3 - 0.5) = +0.4\) V.

  2. 입력이 셋인 가산기에서 \(V_3\)만 두 배의 가중치를 주려면 \(R_3\)를 어떻게 정하는가? (\(R_1 = R_2 = R_f = R\))
    답

    \(R_3 = R/2\).
