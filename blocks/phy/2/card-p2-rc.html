RC 회로의 충전 시간과 시간 상수 재기

과도 응답 · 지수 · 반감 시간 · 문제 해결 전략

출발점

RC 회로를 충전하면 \(V_C = V_0(1 - e^{-t/\tau})\), 방전하면 \(V_0e^{-t/\tau}\)이고 \(\tau = RC\)입니다. 실험에서는 63%가 되는 시간이나 반이 되는 시간(\(\tau\ln2\))으로 \(\tau\)를 잽니다.

문제 해결 전략 · 과도 응답
  1. \(\tau = RC\)를 계산한다.
  2. 원하는 비율의 시간 \(t = -\tau\ln(1 - V/V_0)\)(충전).
  3. 측정값에서는 로그 그래프 기울기로 \(\tau\)를 구한다.
  4. 계측기 입력 저항이 \(R\)과 병렬로 들어가지 않는지 확인한다.

\(R = 47\ \text{k}\Omega\), \(C = 10\ \mu\text{F}\)를 5 V로 충전한다. 시간 상수, 4 V가 되는 시각, 99%가 되는 시각은? 방전할 때 반이 되는 시간은?

풀이

  1. \(\tau = 47\times10^3\times10\times10^{-6} = 0.47\) s.
    단위: Ω·F = s.
  2. 4 V: \(t = -0.47\ln(1 - 0.8) = 0.47\times1.609 = 0.756\) s.
    80%.
  3. 99%: \(t = 0.47\ln100 = 2.16\) s(약 \(4.6\tau\)).
    보통 \(5\tau\)면 다 찼다고 본다.
  4. 반감: \(\tau\ln2 = 0.326\) s.
    방전.

의미

시간 상수는 회로의 "반응 속도"입니다. 카메라 플래시의 충전, 키보드 버튼의 떨림 제거, 555 타이머(7단원) 모두 \(RC\)로 시간을 만듭니다.

검산

\(t = \tau\)이면 \(1 - e^{-1} = 0.632\), 3.16 V. 0.47 s와 0.756 s 사이의 값(3.16 V < 4 V)이라 맞습니다.
