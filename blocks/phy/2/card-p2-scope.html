오실로스코프 화면에서 진폭, 주기, 실효값 읽기

눈금 읽기 · 실효값 · 문제 해결 전략

출발점

오실로스코프는 세로 눈금(V/div)과 가로 눈금(s/div)으로 파형을 보여 줍니다. 멀티미터의 교류 전압은 보통 실효값(rms)이고, 사인파에서는 진폭의 \(1/\sqrt2\)입니다.

문제 해결 전략 · 파형 읽기
  1. 봉우리에서 골까지 칸 수 × V/div = 봉우리-봉우리 전압 \(V_{pp}\).
  2. 한 주기의 칸 수 × s/div = 주기 \(T\), \(f = 1/T\).
  3. 사인파면 \(V_{\text{rms}} = V_{pp}/(2\sqrt2)\).
  4. 멀티미터 값과 비교해 파형 모양을 점검한다.

오실로스코프가 2 V/div, 0.5 ms/div일 때 사인파의 봉우리-골이 5.6칸, 한 주기가 4칸이었다. 진폭, 진동수, 실효값을 구하여라. 멀티미터는 몇 V를 보일까?

풀이

  1. \(V_{pp} = 5.6\times2 = 11.2\) V, 진폭 5.6 V.
    봉우리-골은 진폭의 두 배.
  2. \(T = 4\times0.5 = 2.0\) ms, \(f = 500\) Hz.
    가로 눈금.
  3. \(V_{\text{rms}} = 5.6/\sqrt2 = 3.96\) V.
    사인파의 실효값.
  4. 멀티미터(실효값 측정, 500 Hz가 측정 범위 안이면) 약 3.96 V.
    싼 멀티미터는 높은 진동수에서 오차가 크다.

의미

실효값은 같은 저항에서 같은 열을 내는 직류 전압입니다. 가정용 220 V는 실효값이라 진폭은 약 311 V입니다.

검산

\(V_{\text{rms}}^2/R\)과 진폭으로 구한 평균 일률 \(\frac{V_0^2}{2R}\)이 같습니다: \(3.96^2 = 15.7 = 5.6^2/2\).
