적분기에 사각파를 넣으면 삼각파

적분기 · 되먹임 축전기 · 문제 해결 전략

출발점

반전 입력에 \(R\), 되먹임에 \(C\)를 두면 \(V_{out} = -\frac1{RC}\int V_{in}dt\)이다. 반전 입력이 가상 접지라 입력 전류 \(V_{in}/R\)가 모두 축전기를 충전하기 때문이다.

문제 해결 전략 · 적분기 해석
  1. 입력 전류 \(V_{in}/R\)를 쓴다.
  2. 그 전류가 축전기에 쌓여 \(\Delta V_{out} = -\frac{1}{C}\int I\,dt\).
  3. 구간마다 기울기 \(-V_{in}/RC\)로 직선을 그린다.
  4. 출력이 포화되지 않는지, 직류 성분이 쌓이지 않는지 확인한다.

\(R = 10\ \text{k}\Omega\), \(C = 0.1\ \mu\text{F}\)인 적분기에 ±1 V, 1 kHz 사각파를 넣는다. 출력 파형과 봉우리-봉우리 전압은?

풀이

  1. \(RC = 10^{-3}\) s. 기울기 \(\mp1/10^{-3} = \mp1000\) V/s.
    입력 +1 V 동안 출력은 내려간다.
  2. 반 주기 0.5 ms 동안 변화 \(1000\times0.5\times10^{-3} = 0.5\) V.
    직선.
  3. 출력은 봉우리-봉우리 0.5 V인 삼각파.
    사각파의 적분.
  4. 입력에 작은 직류 성분이 있으면 계속 쌓여 결국 포화한다. 실제 회로는 \(C\)에 큰 저항을 병렬로 단다.
    실용적 주의.

의미

적분기는 아날로그 계산기의 핵심이었고, 지금도 파형 발생기, 충전량 측정, PID 제어의 I 항에 쓰인다. 진동수를 10배 올리면 출력은 1/10이 되어 저역 통과 필터처럼 행동한다.

검산

Fourier로: 사각파 기본 성분 진폭 \(4/\pi\) V가 \(1/\omega RC = 0.159\)배되어 0.203 V. 삼각파 진폭 0.25 V의 기본 성분 \(8/\pi^2\times0.25 = 0.203\) V와 같다.
