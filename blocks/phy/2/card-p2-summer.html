센서 신호를 A/D 범위에 맞추는 가산기

가중 합 · 오프셋 · 문제 해결 전략

출발점

A/D 변환기는 보통 0 V에서 기준 전압(예: 5 V) 사이만 받습니다. 양과 음을 오가는 센서 신호를 넣으려면 크기를 줄이거나 키우고(가중치) 직류를 더해(오프셋) 가운데를 범위 중앙으로 옮겨야 합니다. 반전 가산기 하나와 반전기 하나로 할 수 있습니다.

문제 해결 전략 · 가산기 설계
  1. 원하는 출력 \(V_{\text{out}} = aV_s + b\)의 \(a\), \(b\)를 정한다.
  2. 반전 가산기는 부호가 바뀌므로 \(-aV_s - b\)를 만들고 반전기로 되돌린다.
  3. \(R_f/R_s = a\), \(R_f/R_{\text{ref}}\times V_{\text{ref}} = b\)로 저항을 정한다.
  4. 입력 범위의 양 끝에서 출력을 확인한다.

센서 신호 \(V_s\)가 −0.5 V에서 +0.5 V 사이에서 변한다. 이를 0~5 V로 옮기려 한다. (가) 필요한 \(a\)와 \(b\)는? (나) \(R_f = 50\) kΩ, 오프셋용 기준 전압 \(V_{\text{ref}} = +5\) V일 때 신호 입력 저항 \(R_s\)와 기준 입력 저항 \(R_{\text{ref}}\)는? (가산기 뒤에 이득 −1 반전기를 단다.)

풀이

  1. (가) 폭 1 V → 5 V이므로 \(a = 5\). 가운데 0 V → 2.5 V이므로 \(b = 2.5\) V.
    \(V_{\text{out}} = 5V_s + 2.5\).
  2. 가산기 출력은 \(-(5V_s + 2.5)\)이어야 한다: \(-R_f\left(\frac{V_s}{R_s} + \frac{V_{\text{ref}}}{R_{\text{ref}}}\right)\).
    반전기가 부호를 되돌린다.
  3. \(R_f/R_s = 5\) → \(R_s = 10\) kΩ.
    신호 가중치.
  4. 상수항: \(-R_fV_{\text{ref}}/R_{\text{ref}} = -2.5\) V → \(R_{\text{ref}} = 50\times5/2.5 = 100\) kΩ.
    기준 전압이 양이면 가산기 출력의 상수항은 음이 되어 맞는다.

의미

반전 가산기에서는 모든 입력의 부호가 뒤집히므로, 오프셋 기준 전압의 부호를 거꾸로 생각하기 쉽습니다. 설계 뒤에는 반드시 입력 범위의 양 끝을 넣어 확인합니다. 최종 회로는 \(R_s = 10\) kΩ, \(R_{\text{ref}} = 100\) kΩ, \(V_{\text{ref}} = +5\) V, \(R_f = 50\) kΩ이고 뒤에 반전기를 둡니다. 가산기 출력이 −5~0 V로 움직이므로 연산증폭기의 음전원이 −5 V보다 넉넉히 낮아야 합니다.

검산

\(V_s = -0.5\) V: 가산기 \(-50(-0.05 + 0.05) = 0\), 반전 뒤 0 V. \(V_s = +0.5\) V: 가산기 \(-50(0.05 + 0.05) = -5\) V, 반전 뒤 5 V. 범위 0~5 V가 맞습니다(전류 단위 mA, 저항 kΩ).
