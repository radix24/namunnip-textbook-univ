원형 코일 축 위의 자기장 측정값 비교

Biot-Savart 법칙 · 축 위 장 · 문제 해결 전략

출발점

반지름 \(a\), \(N\)번 감은 코일에 전류 \(I\)가 흐르면 축 위 거리 \(z\)의 자기장은 \(B = \frac{\mu_0NIa^2}{2(a^2 + z^2)^{3/2}}\)이다. 홀 센서로 잰 값과 비교한다.

문제 해결 전략 · 측정과 이론 비교
  1. 중심(\(z = 0\))의 이론값 \(\mu_0NI/2a\)를 구한다.
  2. 여러 \(z\)에서 이론 곡선을 계산한다.
  3. 측정값에서 지구 자기장(약 50 μT) 같은 배경을 뺀다.
  4. 차이를 코일 크기, 센서 위치 오차로 해석한다.

\(N = 200\), \(a = 5\) cm 코일에 0.5 A가 흐른다. 중심과 \(z = 5\) cm에서의 자기장은? 센서가 \(z\) 방향으로 2 mm 어긋나면 \(z = 5\) cm에서 얼마나 틀리나?

풀이

  1. 중심: \(B = \frac{4\pi\times10^{-7}\times200\times0.5}{2\times0.05} = 1.26\) mT.
    \(z = 0\).
  2. \(z = a\): \(B = B_0\frac{a^3}{(2a^2)^{3/2}} = \frac{B_0}{2\sqrt2} = 0.444\) mT.
    비 0.354.
  3. 기울기 \(\frac{dB}{dz} = -\frac{3z}{a^2 + z^2}B\), \(z = a\)에서 \(-\frac{3}{2a}B = -13.3\) mT/m.
    위치 민감도.
  4. 2 mm 어긋남: \(13.3\times0.002 = 0.027\) mT, 약 6% 오차.
    중심보다 경사가 큰 곳이 민감.

의미

측정값이 이론과 어긋날 때 센서 위치 오차가 큰 원인일 수 있다. 중심 근처는 기울기가 0이라 위치에 덜 민감하다. 균일한 장이 필요하면 두 코일을 반지름만큼 띄운 Helmholtz 배치를 씁니다(물리10).

검산

지구 자기장(약 0.05 mT)은 중심 장의 4%라, 정밀하게 비교하려면 반드시 빼야 한다.
