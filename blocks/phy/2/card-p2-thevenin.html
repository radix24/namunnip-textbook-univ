전압 분배기에 부하를 달면

Thevenin 등가 · 부하 효과 · 최대 전력 · 문제 해결 전략

출발점

어떤 선형 회로도 두 단자에서 보면 전압원 \(V_{th}\)와 직렬 저항 \(R_{th}\)로 바꿀 수 있다. \(V_{th}\)는 열린 회로 전압, \(R_{th}\)는 전원을 끄고(전압원은 단락) 본 저항이다.

문제 해결 전략 · Thevenin 등가 회로
  1. 부하를 떼고 단자 전압 \(V_{th}\)를 구한다.
  2. 전원을 끄고 단자에서 본 저항 \(R_{th}\)를 구한다.
  3. 부하를 달아 \(V_L = V_{th}\frac{R_L}{R_{th} + R_L}\).
  4. 부하 전력을 최대로 하는 \(R_L = R_{th}\)를 확인한다.

12 V 전원에 \(R_1 = 2\ \text{k}\Omega\), \(R_2 = 1\ \text{k}\Omega\)로 만든 전압 분배기(출력은 \(R_2\) 양단)에 \(R_L = 1\ \text{k}\Omega\) 부하를 달면 출력 전압은? 부하 전력이 최대인 \(R_L\)과 그 전력은?

풀이

  1. \(V_{th} = 12\times\frac1{3} = 4.0\) V.
    부하 없을 때 분배.
  2. \(R_{th} = R_1\parallel R_2 = \frac{2\times1}{3} = 0.667\ \text{k}\Omega\).
    전원 단락.
  3. \(V_L = 4.0\times\frac{1}{1.667} = 2.40\) V.
    부하가 출력을 끌어내린다.
  4. 최대 전력: \(R_L = 0.667\ \text{k}\Omega\), \(P = \frac{V_{th}^2}{4R_{th}} = \frac{16}{2667} = 6.0\) mW.
    정합 조건.

의미

전압 분배기는 부하 저항이 \(R_{th}\)보다 훨씬 클 때만 계산대로 동작한다. 센서 출력을 읽는 계측기의 입력 저항을 크게 만드는 까닭입니다(1.4절 부하 효과).

검산

Kirchhoff로 직접: \(R_2\parallel R_L = 0.5\ \text{k}\Omega\), \(V = 12\times\frac{0.5}{2.5} = 2.40\) V. 같다.
