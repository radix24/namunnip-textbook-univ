다전자 원자: 주기율표와 훈트 규칙

본문

주기율표에서 헬륨, 네온, 아르곤은 반응하지 않고, 바로 다음의 리튬, 소듐, 포타슘은 물에 넣으면 격렬하게 반응한다. 원자 번호가 하나 늘었을 뿐인데 왜 이렇게 성질이 뒤바뀔까? 그리고 같은 원자들이 모인 고체는 왜 어떤 것은 금속이고 어떤 것은 절연체일까?

먼저 알아야 할 것동일 입자(1.1절), 교환 힘(1.2절), 띠 이론(물리7 3.3절)을 쓴다.

1.4.1전자 배치

원자 번호가 커지면 전자들은 파울리 원리 때문에 낮은 준위부터 차례로 채워진다. 그런데 다전자 원자에서는 바깥 전자가 보는 핵전하가 안쪽 전자에 가려 줄어든다. 또 같은 n에서는 l이 작은 궤도가 핵 가까이 스며들어 덜 가려지므로 에너지가 낮다. 그래서 1s, 2s, 2p, 3s, 3p, 4s, 3d의 순서로 채워지며, 여기서 주기율표의 주기가 나온다.

처음 질문의 첫째 답이 이것이다. 껍질이 꽉 찬 원소(He, Ne, Ar)는 이온화 에너지가 크고 화학적으로 안정하다(그림 1). 반면 바로 다음 원소는 새 껍질에 전자가 하나 들어가는데, 이 전자는 핵에서 멀고 안쪽 전자에 거의 가려져 쉽게 떨어진다. 예를 들어 리튬의 셋째 전자는 1s에 들어갈 수 없어 2s로 가며, 이온화 에너지가 5.4 eV로 헬륨(24.6 eV)의 4분의 1도 안 된다.

1.4.2훈트 규칙

껍질이 덜 찬 원자의 바닥 상태는 훈트 규칙으로 정한다. 먼저 전체 스핀 S가 가장 큰 배치를 고른다. 교환 효과로 반발이 작기 때문이다(1.2절). 다음으로 그 가운데 전체 궤도 각운동량 L이 가장 큰 배치를 고르는데, 전자들이 같은 방향으로 돌아 서로 피하기 때문이다. 그리고 껍질이 절반 이하로 차면 J = |L − S|, 절반 넘게 차면 J = L + S를 고르며, 이것은 스핀-궤도 결합에서 온다.

바닥 상태는 \(^{2S+1}L_J\)로 쓰며, L = 0, 1, 2, …를 S, P, D, …로 나타낸다. 예를 들어 질소(2p³)는 세 전자의 스핀이 나란해 S = 3/2이고, \(m_l\)이 +1, 0, −1이라 L = 0이므로 \(^4S_{3/2}\)이다.

1.4.3고체의 띠

고체에서는 원자 N개의 준위가 섞여, 각 준위가 N개의 촘촘한 준위로 갈라진 띠가 된다. 전자는 파울리 원리에 따라 아래부터 채운다. 그래서 채워진 맨 위가 띠 중간이면 작은 에너지로도 들뜰 수 있어 금속이 된다. 반면 띠가 꽉 차고 위 띠까지 간격이 있으면 절연체나 반도체가 된다. 처음 질문의 둘째 답이 이것이다.

흔한 오해4s가 3d보다 먼저 채워지므로 4s가 언제나 에너지가 낮다고 생각하기 쉽지만, 전이 금속이 이온이 될 때는 4s 전자가 먼저 떨어진다. 채움 순서는 전체 에너지의 결과이지 궤도 에너지의 고정된 순서가 아니다. 또 훈트 규칙은 바닥 상태에만 적용되며, 들뜬 상태의 순서는 알려 주지 않는다.
마무리

파울리 원리와 가려막기 때문에 전자는 1s, 2s, 2p, 3s, 3p, 4s, 3d 순서로 채워지며, 처음 질문처럼 껍질이 꽉 찬 원소는 안정하고 새 껍질을 시작하는 원소는 전자를 쉽게 잃는다. 훈트 규칙은 S 최대, L 최대, 절반 이하 J = |L − S|, 초과 J = L + S의 순서로 바닥 상태를 정한다. 고체에서 띠를 중간까지 채우면 금속, 꽉 채우고 간격이 있으면 절연체나 반도체이다.

1.4.4연습문제

기본

  1. 리튬(전자 3개)의 바닥 상태 전자 배치와, 셋째 전자가 2s에 들어가는 까닭은?
    답

    1s² 2s¹. 1s에는 스핀이 반대인 두 전자만 들어갈 수 있습니다(파울리).

  2. 질소(2p³)의 바닥 상태 기호는?
    답

    세 전자의 스핀이 나란해 \(S = 3/2\), \(m_l\)이 +1, 0, −1이라 \(L = 0\). \(^4S_{3/2}\).
