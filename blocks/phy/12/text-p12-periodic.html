다전자 원자: 주기율표와 훈트 규칙

본문
이 절에서 배울 것
  • 파울리 원리와 가려막기로 원자의 전자 배치와 주기율표를 설명한다.
  • 훈트 규칙으로 원자의 바닥 상태 기호를 정하고, 고체의 띠 채움으로 금속과 절연체를 구별한다.
먼저 알아야 할 것
  • 동일 입자 (1.1절), 교환 힘 (1.2절), 띠 이론 (물리7 3.3절).

1.4.1전자 배치

원자 번호가 커지면 전자들은 파울리 원리 때문에 낮은 준위부터 차례로 채워집니다. 다전자 원자에서는 바깥 전자가 보는 핵 전하가 안쪽 전자에 가려 줄어들고, 같은 \(n\)에서 \(l\)이 작은 궤도가 핵 가까이 스며들어 에너지가 낮습니다. 그래서 1s, 2s, 2p, 3s, 3p, 4s, 3d, …의 순서로 채워지며 주기율표의 주기가 나옵니다. 껍질이 꽉 찬 원소(He, Ne, Ar)는 이온화 에너지가 크고 화학적으로 안정합니다.

1.4.2훈트 규칙

껍질이 덜 찬 원자의 바닥 상태는 다음 순서로 정합니다.

  1. 전체 스핀 \(S\)가 가장 큰 배치(교환 효과로 반발이 작음, 1.2절).
  2. 그 가운데 전체 궤도 각운동량 \(L\)이 가장 큰 배치(전자들이 같은 방향으로 돌아 서로 피함).
  3. 껍질이 절반 이하로 차면 \(J = |L - S|\), 절반 넘게 차면 \(J = L + S\)(스핀-궤도 결합).

상태는 \(^{2S+1}L_J\)로 씁니다(\(L = 0, 1, 2, \dots\)를 S, P, D, …로).

1.4.3고체의 띠

고체에서는 원자 \(N\)개의 준위가 섞여 각 준위가 \(N\)개의 촘촘한 준위로 갈라진 띠가 됩니다. 전자는 파울리 원리에 따라 아래부터 채우고, 채워진 맨 위가 띠 중간이면 금속(작은 에너지로 들뜰 수 있음), 띠가 꽉 차고 위 띠까지 간격이 있으면 절연체·반도체입니다.

요약
  1. 파울리 원리 + 가려막기 → 1s, 2s, 2p, 3s, 3p, 4s, 3d … 채움 순서와 주기율표.
  2. 훈트: \(S\) 최대 → \(L\) 최대 → 절반 이하 \(J = |L - S|\), 초과 \(J = L + S\).
  3. 띠 중간까지 채우면 금속, 꽉 차고 간격이 있으면 절연체·반도체.

1.4.4연습문제

기본

  1. 리튬(전자 3개)의 바닥 상태 전자 배치와, 셋째 전자가 2s에 들어가는 까닭은?
    답

    1s² 2s¹. 1s에는 스핀이 반대인 두 전자만 들어갈 수 있습니다(파울리).

  2. 질소(2p³)의 바닥 상태 기호는?
    답

    세 전자의 스핀이 나란해 \(S = 3/2\), \(m_l\)이 +1, 0, −1이라 \(L = 0\). \(^4S_{3/2}\).
