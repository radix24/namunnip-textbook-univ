수소 n = 3 준위의 미세 구조

미세 구조 공식 · j 의존성 · 크기 어림

출발점

미세 구조를 넣은 수소 준위는 \(E_{nj} = E_n\left[1 + \frac{\alpha^2}{n^2}\left(\frac{n}{j + \frac12} - \frac34\right)\right]\)이고 \(j\)에만 의존합니다(2.3절). \(E_3 = -1.511\) eV, \(\alpha^2 = 5.33\times10^{-5}\)입니다.

문제 해결 전략 · 가능한 j를 모두 나열하기
  1. \(n = 3\)에서 가능한 \(l\)과 \(j = l \pm \frac12\)를 나열한다.
  2. \(j\)마다 보정 크기를 구한다.
  3. 준위 개수와 가장 큰 간격을 구한다.

수소 \(n = 3\) 준위는 미세 구조로 몇 개로 갈라지는가? 가장 아래와 가장 위 준위의 간격은 몇 eV, 몇 GHz인가?

풀이

  1. \(l = 0\): \(j = \frac12\). \(l = 1\): \(j = \frac12, \frac32\). \(l = 2\): \(j = \frac32, \frac52\). 서로 다른 \(j\)는 \(\frac12, \frac32, \frac52\) 셋.
    \(E\)는 \(j\)에만 의존.
  2. 괄호 안: \(j = \frac12\): \(3 - 0.75 = 2.25\), \(\frac32\): 0.75, \(\frac52\): 0.25. 보정 \(= E_3\frac{\alpha^2}9\times\) 이 값 \(= -2.01, -0.67, -0.22\ (\times10^{-5}\ \text{eV})\).
    \(E_3\alpha^2/9 = -8.95\times10^{-6}\) eV.
  3. 세 준위, 간격 \(1.79\times10^{-5}\) eV, \(\Delta E/h = 4.3\) GHz.
    \(h = 4.14\times10^{-15}\) eV·s.

의미

미세 구조는 준위 자체(1.5 eV)의 \(10^{-5}\) 규모로 \(\alpha^2\) 차수의 작은 효과입니다. \(j\)가 같은 3S₁/₂와 3P₁/₂는 이 이론에서 겹치지만 실제로는 램 이동(QED)으로 조금 갈라집니다. 발머 \(H_\alpha\) 선을 아주 높은 분해능으로 보면 이 갈라짐 때문에 여러 성분으로 나뉩니다.

검산

\(j\)가 작을수록(궤도가 핵에 가까이 스며들수록) 더 아래로 내려가, 상대론 보정과 스핀-궤도 결합이 모두 핵 근처에서 큰 효과라는 것과 맞습니다.
