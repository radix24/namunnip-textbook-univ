비축퇴 섭동이론

본문

정확히 풀리는 양자역학 문제는 조화 진동자, 수소 원자 같은 몇 개뿐이다. 그런데 실제 분자의 진동은 조화 진동자에서 조금 벗어나 있고, 실제 원자는 바깥 전기장 속에 있다. 정확히 풀리는 문제에 작은 변화가 더해졌을 때, 에너지는 얼마나 바뀔까?

먼저 알아야 할 것디랙 표기법(물리8 3.4절), 사다리 연산자(물리8 2.6절)를 쓴다.

2.1.1전개

해밀토니언이 \(\hat H = \hat H^0 + \lambda\hat H'\)이고, \(\hat H^0|n^0\rangle = E_n^0|n^0\rangle\)을 안다고 하자. 에너지와 상태를 λ의 거듭제곱으로 전개해 넣고 차수별로 맞추면 보정을 차례로 얻는다. 이것을 섭동 이론이라 한다.

정리 2.1.1 \[E_n^{(1)} = \langle n^0|\hat H'|n^0\rangle, \qquad |n^{(1)}\rangle = \sum_{m\ne n}\frac{\langle m^0|\hat H'|n^0\rangle}{E_n^0 - E_m^0}|m^0\rangle, \qquad E_n^{(2)} = \sum_{m\ne n}\frac{|\langle m^0|\hat H'|n^0\rangle|^2}{E_n^0 - E_m^0}\]

처음 질문의 답이 이 공식이다. 1차 보정은 옛 상태로 계산한 섭동의 기대값이다. 또 바닥 상태의 2차 보정은 분모가 모두 음수이므로 언제나 음수, 곧 준위를 내린다. 그런데 분모에 \(E_n^0 - E_m^0\)이 있으므로, 같은 에너지에 상태가 여럿 겹친 축퇴 준위에는 쓸 수 없으며 이것은 2.2절에서 다룬다. 그리고 섭동의 행렬 요소가 준위 간격보다 작아야 잘 맞는다.

2.1.2비조화 진동자

조화 진동자에 \(\hat H' = \lambda\hat x^4\)를 더해 보자. \(\hat x = \sqrt{\hbar/2m\omega}(\hat a_+ + \hat a_-)\)를 네 번 곱해 \(|0\rangle\)에서 \(|0\rangle\)로 돌아오는 항만 세면 \(\langle0|(\hat a_+ + \hat a_-)^4|0\rangle = 3\)이다. 2차 항은 \(|2\rangle\)과 \(|4\rangle\)로 가는 행렬 요소에서 나온다.

결과 2.1.2 \[E_0 \approx \frac12\hbar\omega + 3\lambda\left(\frac\hbar{2m\omega}\right)^2 - \frac{21}8\frac{\lambda^2}{\hbar\omega}\left(\frac\hbar{m\omega}\right)^4 + \cdots\]

ħ = m = ω = 1 단위로는 \(E_0 \approx 0.5 + 0.75\lambda - 2.625\lambda^2\)이다. 예를 들어 λ = 0.1이면 0.549로, 정확한 값 0.559와 2% 차이이다(그림 1). 그런데 이 급수는 사실 수렴하지 않는 점근 급수여서, λ가 작을 때만 처음 몇 항이 좋은 근사이다. λ = 0.3에서 2차 결과는 0.489로 정확한 값 0.638과 크게 어긋난다. 이 장의 실습 카드에서 정확한 수치 결과와 비교할 수 있다.

예제 2.1.3

폭 \(L\)인 무한 우물 바닥에 높이 \(V_0\)인 계단 \(V = V_0\) (\(0 < x < L/2\))을 두었다. 1차 에너지 보정을 구하여라.

풀이. \(E_n^{(1)} = V_0\int_0^{L/2}\frac2L\sin^2\frac{n\pi x}L\,dx = \frac{V_0}2\)이다. 모든 준위가 \(V_0/2\)만큼 올라간다. 확률이 두 반쪽에 절반씩 있으므로 직관과도 맞는다.

흔한 오해섭동 급수는 항을 더할수록 정확해진다고 생각하기 쉽지만, x⁴ 섭동처럼 점근 급수인 경우가 많아 어느 차수 뒤로는 오히려 나빠진다. 또 1차 보정이 0이면 에너지가 변하지 않는다고 여기기 쉽지만, 균일한 힘 εx처럼 1차가 0이어도 2차 보정 \(-\epsilon^2/2m\omega^2\)이 남는다.
마무리

비축퇴 섭동 이론에서 1차 보정은 \(E^{(1)} = \langle n|H'|n\rangle\), 2차 보정은 \(E^{(2)} = \sum_{m\ne n}|H'_{mn}|^2/(E_n - E_m)\)이며, 바닥 상태의 2차 보정은 언제나 음수이다. 처음 질문처럼 작은 섭동의 효과를 이 공식으로 어림하며, x⁴ 섭동의 바닥 에너지는 \(0.5 + 0.75\lambda - 2.625\lambda^2\)(자연 단위)이다. 축퇴가 있으면 쓸 수 없고, 섭동이 크면 급수가 맞지 않는다.

2.1.3연습문제

기본

  1. 조화 진동자에 \(\hat H' = \epsilon\hat x\)(균일한 힘)를 더할 때 1차, 2차 보정을 구하고 정확한 답과 비교하여라.
    답

    1차 보정은 \(\langle n|x|n\rangle = 0\)이고, 2차 보정은 \(E^{(2)} = -\frac{\epsilon^2}{2m\omega^2}\). 완전제곱으로 정확히 풀면 같은 값이 나와 2차에서 끝난다.

  2. \(\lambda x^4\) 섭동에서 \(n\)번째 준위의 1차 보정은?
    답

    \(\langle n|(\hat a_+ + \hat a_-)^4|n\rangle = 6n^2 + 6n + 3\). \(E_n^{(1)} = \lambda\left(\frac\hbar{2m\omega}\right)^2(6n^2 + 6n + 3)\). 높은 준위일수록 보정이 빨리 커진다.
