비축퇴 섭동이론

본문
이 절에서 배울 것
  • 풀 수 있는 해밀토니언에 작은 섭동이 더해졌을 때 에너지와 상태의 보정을 전개한다.
  • 1차 에너지 보정 \(E^{(1)} = \langle n|H'|n\rangle\)과 2차 보정 공식을 유도한다.
  • 조화 진동자에 \(x^4\) 섭동이 있을 때 바닥 상태 보정을 구한다.
먼저 알아야 할 것
  • 디랙 표기법 (물리8 3.3절), 사다리 연산자 (물리8 2.4절).

2.1.1전개

\(\hat H = \hat H^0 + \lambda\hat H'\)에서 \(\hat H^0|n^0\rangle = E_n^0|n^0\rangle\)을 안다고 합니다. 에너지와 상태를 \(\lambda\)의 거듭제곱으로 전개해 넣고 차수별로 맞추면

정리 2.1.1 \[E_n^{(1)} = \langle n^0|\hat H'|n^0\rangle, \qquad |n^{(1)}\rangle = \sum_{m\ne n}\frac{\langle m^0|\hat H'|n^0\rangle}{E_n^0 - E_m^0}|m^0\rangle, \qquad E_n^{(2)} = \sum_{m\ne n}\frac{|\langle m^0|\hat H'|n^0\rangle|^2}{E_n^0 - E_m^0}.\]
  • 1차 보정은 섭동의 기대값(옛 상태로 계산)이다.
  • 바닥 상태의 2차 보정은 분모가 모두 음이라 늘 음이다(준위가 내려간다).
  • 분모에 \(E_n^0 - E_m^0\)이 있어 겹친(축퇴된) 준위가 있으면 쓸 수 없다(2.2절). 섭동 행렬 요소가 준위 간격보다 작아야 잘 맞는다.

2.1.2예: 비조화 진동자

\(\hat H' = \lambda\hat x^4\)를 조화 진동자에 더합니다. \(\hat x = \sqrt{\frac\hbar{2m\omega}}(\hat a_+ + \hat a_-)\)를 네 번 곱해 \(|0\rangle\)에서 \(|0\rangle\)로 돌아오는 항만 세면 \(\langle0|(\hat a_+ + \hat a_-)^4|0\rangle = 3\).

결과 2.1.2 \[E_0 \approx \frac12\hbar\omega + 3\lambda\left(\frac\hbar{2m\omega}\right)^2 - \frac{21}8\frac{\lambda^2}{\hbar\omega}\left(\frac\hbar{m\omega}\right)^4 + \cdots\]

\(\hbar = m = \omega = 1\) 단위로 \(E_0 \approx 0.5 + 0.75\lambda - 2.625\lambda^2\).

2차 항은 \(|2\rangle\)과 \(|4\rangle\)로 가는 행렬 요소에서 나옵니다. 이 급수는 사실 수렴하지 않는(점근) 급수라 \(\lambda\)가 작을 때만 첫 몇 항이 좋은 근사입니다. 아래 실습 카드에서 정확한 수치 결과와 비교할 수 있습니다(2장 자기 점검).

예제 2.1.3

폭 \(L\)인 무한 우물 바닥에 높이 \(V_0\)인 계단 \(V = V_0\) (\(0 < x < L/2\))을 두었습니다. 1차 에너지 보정은?

풀이. \(E_n^{(1)} = V_0\int_0^{L/2}\frac2L\sin^2\frac{n\pi x}L\,dx = \frac{V_0}2\). 모든 준위가 \(V_0/2\)만큼 올라갑니다. 확률이 반쪽에 절반씩 있으므로 직관과 맞습니다.

요약
  1. \(E^{(1)} = \langle n|H'|n\rangle\), \(E^{(2)} = \sum_{m\ne n}|H'_{mn}|^2/(E_n - E_m)\).
  2. 바닥 상태 2차 보정은 음. 축퇴가 있으면 쓸 수 없다.
  3. \(\lambda x^4\): \(E_0 \approx 0.5 + 0.75\lambda - 2.625\lambda^2\) (자연 단위).

2.1.3연습문제

기본

  1. 조화 진동자에 \(\hat H' = \epsilon\hat x\)(균일한 힘)를 더할 때 1차, 2차 보정을 구하고 정확한 답과 비교하세요.
    답

    1차: \(\langle n|x|n\rangle = 0\). 2차: \(E^{(2)} = -\frac{\epsilon^2}{2m\omega^2}\). 완전제곱으로 정확히 풀면 같은 값이 나와 2차에서 끝납니다.

  2. \(\lambda x^4\) 섭동에서 \(n\)번째 준위의 1차 보정은?
    답

    \(\langle n|(\hat a_+ + \hat a_-)^4|n\rangle = 6n^2 + 6n + 3\). \(E_n^{(1)} = \lambda\left(\frac\hbar{2m\omega}\right)^2(6n^2 + 6n + 3)\). 높은 준위일수록 보정이 빨리 커집니다.
