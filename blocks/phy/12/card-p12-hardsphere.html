단단한 공의 고전 산란 단면적

충돌 매개변수 · 미분 단면적 · 문제 해결 전략

출발점

미분 단면적 \(\frac{d\sigma}{d\Omega} = \frac{b}{\sin\theta}\left|\frac{db}{d\theta}\right|\)는 충돌 매개변수 \(b\)와 산란각 \(\theta\)의 관계에서 나온다. 전체 단면적은 그것을 모든 방향으로 적분한 넓이이다.

문제 해결 전략 · 단면적 계산
  1. 충돌 기하로 \(b(\theta)\)를 구한다.
  2. \(d\sigma/d\Omega\)를 계산한다.
  3. \(\int d\Omega\)로 전체 단면적을 구한다.
  4. 기하학적 넓이와 비교한다.

반지름 \(R\)인 단단한 공에 점 입자가 튕기는 고전 산란의 미분·전체 단면적을 구하여라.

풀이

  1. 표면에서 거울 반사: \(b = R\cos\frac\theta2\).
    입사각 = 반사각.
  2. \(\left|\frac{db}{d\theta}\right| = \frac R2\sin\frac\theta2\).
    미분.
  3. \(\frac{d\sigma}{d\Omega} = \frac{R\cos(\theta/2)}{\sin\theta}\cdot\frac R2\sin\frac\theta2 = \frac{R^2}4\).
    \(\sin\theta = 2\sin\frac\theta2\cos\frac\theta2\).
  4. 전체 \(\sigma = 4\pi\times\frac{R^2}4 = \pi R^2\).
    기하학적 단면.

의미

단단한 공은 모든 방향으로 고르게 튕깁니다(등방 산란). 양자역학에서 파장이 공보다 훨씬 길면 전체 단면적이 \(4\pi R^2\)(기하 단면의 4배)가 되는데, 파동이 공 둘레를 돌아 회절하기 때문입니다(부분파 분석).

검산

단위: \(R^2\)은 넓이, \(d\Omega\)는 무차원. 맞다.
