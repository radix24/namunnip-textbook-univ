약한 장에서 강한 장까지: 2p 준위의 제이만 효과

실습 · 미세 구조와 자기장의 경쟁

목표

수소 \(2p\) 준위의 여섯 상태에 스핀-궤도 결합과 자기장을 함께 넣고 정확히 대각화해, 자기장에 따른 에너지를 그립니다. 약한 장 공식 \(g_Jm_j\mu_BB\)와 강한 장(파셴-바크) 공식 \(\mu_B(m_l + 2m_s)B\)가 각각 어디서 맞고, 둘 사이에서 준위가 어떻게 이어지는지 확인합니다. 성취기준 [물리12-02-04].

준비

섭동 해밀토니안은 \(H' = a\,\mathbf L\cdot\mathbf S/\hbar^2 + \mu_BB(L_z + 2S_z)/\hbar\)입니다. \(a = \frac23\Delta\)로 두면 \(B = 0\)에서 \(2p_{3/2}\)가 \(\frac\Delta3\), \(2p_{1/2}\)가 \(-\frac{2\Delta}3\)에 놓여 간격이 \(\Delta\)가 됩니다(상대론 보정은 두 준위를 똑같이 옮기므로 뺐습니다). 두 항 모두 \(m_j = m_l + m_s\)를 바꾸지 않으므로 \(6\times6\) 행렬이 \(1\times1\) 둘과 \(2\times2\) 둘로 나뉘어, 손으로도 풀 수 있습니다.

파란 곡선은 \(B = 0\)에서 \(j = \frac32\), 빨간 곡선은 \(j = \frac12\)에서 출발하는 상태입니다. 회색 점선은 약한 장 직선, 주황 점선은 강한 장 직선입니다. 세로 점선은 지금 고른 \(B\)이고, 출력에 그 자리의 세 값을 적습니다.

절차

  1. \(\Delta = 45\) μeV(수소 \(n = 2\))로 두고 \(B = 0.05\) T, \(0.1\) T에서 여섯 준위의 정확한 값과 약한 장 값을 비교한다.
  2. \(B\)를 \(0.78\) T(\(\mu_BB \approx \Delta\)) 근처로 옮겨 두 근사가 모두 어긋나는 상태를 찾는다.
  3. 범위를 5 T로 넓히고 \(B = 3\) T에서 정확한 값과 강한 장 값을 비교한다.
  4. \(m_j = \pm\frac32\) 두 상태가 모든 \(B\)에서 직선인 까닭을 행렬의 모양으로 설명한다.

기대 결과

  • \(B = 0.1\) T: \(j = \frac32\) 네 상태는 26.6, 19.0, 11.3, 3.4 μeV, \(j = \frac12\) 두 상태는 −28.2, −32.1 μeV. 약한 장 값(26.6, 18.9, 11.1, 3.4, −28.1, −31.9)과 0.2 μeV 안쪽에서 맞는다. 간격이 \(g_J\)에 비례해 \(j = \frac32\)는 \(\frac43\mu_BB\), \(j = \frac12\)는 \(\frac23\mu_BB\)이다.
  • \(B = 0.78\) T: \((j, m_j) = (\frac32, +\frac12)\) 상태는 정확한 값 51.9 μeV인데 약한 장과 강한 장 공식이 모두 45.1 μeV를 준다. \((\frac32, -\frac12)\)는 −4.1 μeV인데 두 공식은 −15 μeV. 이 영역에서는 행렬을 정확히 풀어야 한다.
  • \(B = 3\) T: 정확한 값 362.3, 176.0, −12.2, −17.4, −176.4, −332.3 μeV가 강한 장 값 362.3, 173.6, −15.0, −15.0, −173.6, −332.3과 3 μeV 안쪽에서 맞는다. \(m_l + 2m_s = 0\)인 두 상태(\(m_l = \pm1\), \(m_s = \mp\frac12\))는 거의 겹친다.
  • \(m_j = \pm\frac32\)는 그 \(m_j\)를 갖는 상태가 하나뿐이라 섞일 상대가 없다. 그래서 정확한 답이 \(\frac a2 \pm 2\mu_BB\)인 직선이고, 두 근사도 이 상태에서는 똑같다.

분석

  1. 같은 \(m_j\)를 가진 두 곡선(예: \(m_j = +\frac12\)의 파랑과 빨강)은 서로 가까워지다가 비켜 갑니다. 교차하지 않는 까닭을 \(2\times2\) 행렬의 비대각 성분 \(a/\sqrt2\)로 설명해 보세요.
  2. \(\Delta\)를 줄이면 같은 \(B\)에서 어느 근사가 더 잘 맞게 되는지 예상하고 확인해 보세요. 미세 구조가 큰 무거운 원자에서는 실험실 자기장이 대부분 어느 쪽인가요?

더 해 보기

\(m_j = +\frac12\) 블록 \(\begin{pmatrix}-a/2 & a/\sqrt2\\ a/\sqrt2 & \mu_BB\end{pmatrix}\)의 고유값을 손으로 구해, \(B\)가 작을 때 \(\frac a2 + \frac23\mu_BB\)와 \(-a + \frac13\mu_BB\)로 전개되는지 확인해 보세요. 기울기가 \(g_Jm_j\)와 같아야 합니다.
