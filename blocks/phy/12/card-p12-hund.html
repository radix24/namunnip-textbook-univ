탄소와 산소의 바닥 상태 기호

훈트 규칙 · 전자 배치 · 항 기호

출발점

훈트 규칙: 먼저 전체 스핀 \(S\)를 최대로, 다음 \(L\)을 최대로, 껍질이 절반 이하면 \(J = |L - S|\), 넘으면 \(J = L + S\)입니다(1.4절). p 껍질의 \(m_l\)은 +1, 0, −1이고 한 \(m_l\)에 스핀 반대인 전자 둘까지 들어간다.

문제 해결 전략 · 칸 채우기
  1. p 껍질의 세 칸(\(m_l = +1, 0, -1\))에 스핀이 같은 방향이 되도록 먼저 하나씩 채운다.
  2. 남은 전자는 \(m_l\)이 큰 칸부터 반대 스핀으로 채운다.
  3. \(S = \sum m_s\), \(L = |\sum m_l|\)을 구하고 \(J\)를 정한다.

(가) 탄소(2p²)와 (나) 산소(2p⁴)의 바닥 상태 기호를 구하여라.

풀이

  1. (가) \(m_l = +1, 0\)에 같은 스핀: \(S = 1\), \(L = 1\). 절반(3) 이하라 \(J = 0\). \(^3P_0\).
    두 전자, 같은 스핀.
  2. (나) 셋은 같은 스핀으로 +1, 0, −1(\(L = 0\)), 넷째는 \(m_l = +1\)에 반대 스핀. \(S = \frac32 - \frac12 = 1\), \(L = 1\).
    절반 넘음.
  3. 절반 넘게 차서 \(J = L + S = 2\). \(^3P_2\).
    구멍 두 개로 볼 수도 있음.

의미

산소의 2p⁴는 꽉 찬 껍질(2p⁶)에서 전자 두 개가 빠진 '구멍 두 개'로 볼 수 있어 탄소와 같은 \(^3P\)가 되지만, 구멍은 스핀-궤도 결합의 부호가 반대라 \(J\)가 가장 큰 값이 바닥이 된다. 이런 바닥 상태 기호가 원자 스펙트럼과 자기적 성질(산소 분자의 상자성 등)을 정한다.

검산

두 결과 모두 \(S = 1\)이라 홀전자 둘의 스핀이 나란하다는 것과 맞고, 측정된 탄소(³P₀)와 산소(³P₂)의 바닥 상태와 같다.
