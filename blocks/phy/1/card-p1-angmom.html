외적으로 구하는 토크와 각운동량

외적 · 오른손 규칙 · 원점 선택 · 문제 해결 전략

출발점

토크 \(\boldsymbol\Gamma = \mathbf r\times\mathbf F\)와 각운동량 \(\boldsymbol\ell = \mathbf r\times\mathbf p\)는 원점을 어디에 두느냐에 따라 달라진다. 외적은 행렬식이나 \(\epsilon_{ijk}\)로 계산하고, 방향은 오른손 규칙으로 점검한다.

문제 해결 전략 · 외적 계산
  1. 원점을 정하고 위치 벡터를 그 원점에서 잰다.
  2. 행렬식 \(\begin{vmatrix}\hat{\mathbf x} & \hat{\mathbf y} & \hat{\mathbf z}\\ a_x & a_y & a_z\\ b_x & b_y & b_z\end{vmatrix}\)로 성분을 구한다.
  3. 크기를 \(ab\sin\theta\)로, 방향을 오른손으로 점검한다.
  4. 결과가 두 벡터 모두에 수직인지(내적 0) 확인한다.

질량 2 kg인 공이 위치 \((3, 4, 0)\) m에서 속도 \((0, 0, 5)\) m/s로 움직인다. (가) 원점에 대한 각운동량 (나) 점 \((3, 0, 0)\)에 대한 각운동량을 구하여라.

풀이

  1. 운동량 \(\mathbf p = (0, 0, 10)\) kg·m/s.
    \(\mathbf p = m\mathbf v\).
  2. (가) \(\boldsymbol\ell = (3, 4, 0)\times(0, 0, 10) = (4\cdot10 - 0,\ 0 - 3\cdot10,\ 0) = (40, -30, 0)\).
    행렬식 전개: \(x\) 성분은 \(r_yp_z - r_zp_y\).
  3. (나) 위치를 새 원점에서 재면 \((0, 4, 0)\). \(\boldsymbol\ell' = (0, 4, 0)\times(0, 0, 10) = (40, 0, 0)\).
    원점을 옮기면 위치 벡터가 바뀐다.
  4. 점검: \((40, -30, 0)\cdot(3, 4, 0) = 120 - 120 = 0\), \(\cdot(0, 0, 10) = 0\). 두 벡터에 모두 수직.
    외적은 늘 두 벡터에 수직.

의미

같은 운동인데 원점에 따라 각운동량이 다르다. 그래서 각운동량 보존을 말할 때는 반드시 "어느 점에 대해"를 밝혀야 한다. 중심력 문제에서는 힘의 중심을 원점으로 잡아야 토크가 0이 되어 보존된다.

검산

(가)의 크기 \(\sqrt{40^2 + 30^2} = 50 = rp\sin90° = 5\times10\). 위치와 속도가 수직이라 \(\sin\theta = 1\)이다.
