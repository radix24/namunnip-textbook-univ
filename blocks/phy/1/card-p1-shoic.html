초기 조건으로 진폭과 위상 정하기

단순 조화 진동 · 초기 조건 · 에너지 · 문제 해결 전략

출발점

단순 조화 진동의 해 \(x = A\cos(\omega_0t - \delta)\)에서 \(\omega_0\)는 계가 정하고, \(A\)와 \(\delta\)는 처음 위치와 속도가 정한다. 에너지 \(\frac12kA^2\)로도 진폭을 검산할 수 있다.

문제 해결 전략 · 진동 문제
  1. \(\omega_0 = \sqrt{k/m}\)을 구한다.
  2. \(x = B_1\cos\omega_0t + B_2\sin\omega_0t\)에 \(x_0\), \(v_0\)를 넣는다.
  3. \(A = \sqrt{B_1^2 + B_2^2}\), \(\tan\delta = B_2/B_1\)(사분면 주의).
  4. 에너지로 진폭을 확인한다.

\(m = 0.5\) kg, \(k = 50\) N/m인 용수철 진동자를 평형에서 \(x_0 = 0.03\) m 당긴 뒤 바깥쪽으로 \(v_0 = 0.4\) m/s로 밀었다. 진폭, 위상, 처음으로 최대 변위에 닿는 시각을 구하여라.

풀이

  1. \(\omega_0 = \sqrt{50/0.5} = 10\) rad/s.
    계의 성질.
  2. \(B_1 = x_0 = 0.03\) m, \(B_2 = v_0/\omega_0 = 0.04\) m.
    \(x(0) = B_1\), \(\dot x(0) = \omega_0B_2\).
  3. \(A = \sqrt{0.03^2 + 0.04^2} = 0.05\) m, \(\tan\delta = 4/3\), \(\delta = 0.927\) rad.
    \(B_1, B_2 > 0\)이라 제1사분면.
  4. 최대 변위는 \(\omega_0t - \delta = 0\), \(t = 0.0927\) s.
    \(\cos\)가 처음 1이 되는 때.

의미

바깥쪽으로 밀었으니 처음 위치(3 cm)보다 더 나가 5 cm에서 멈춘다. 위상 \(\delta\)는 "최대 변위에 언제 닿느냐"를 담고 있다.

검산

에너지: \(\frac12(0.5)(0.4)^2 + \frac12(50)(0.03)^2 = 0.04 + 0.0225 = 0.0625\) J \(= \frac12(50)A^2\), \(A = 0.05\) m. 같다.
