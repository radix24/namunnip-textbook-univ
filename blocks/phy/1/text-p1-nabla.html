벡터 미분 연산자의 좌표 표현

본문
이 절에서 배울 것
  • 기울기, 발산, 회전을 직교 좌표로 계산한다.
  • 극, 원통, 구면 좌표에서 기울기를 쓰고 그 유도 원리를 안다.
먼저 알아야 할 것
  • 기울기 벡터 (공통2 4.3절), 발산과 회전 (공통2 7.1절), 좌표계 (1.1절).

1.3.1직교 좌표

연산자 \(\nabla = \hat{\mathbf x}\partial_x + \hat{\mathbf y}\partial_y + \hat{\mathbf z}\partial_z\)를 써서

  • 기울기 \(\nabla f\): 스칼라 \(f\)가 가장 빨리 증가하는 방향과 그 비율. \(df = \nabla f\cdot d\mathbf r\).
  • 발산 \(\nabla\cdot\mathbf F = \partial_xF_x + \partial_yF_y + \partial_zF_z\): 한 점에서 퍼져 나가는 정도.
  • 회전 \(\nabla\times\mathbf F\): 한 점 둘레의 소용돌이 정도. 행렬식으로 계산.
  • 라플라시안 \(\nabla^2f = \nabla\cdot\nabla f = \partial_x^2f + \partial_y^2f + \partial_z^2f\).

항등식 \(\nabla\times(\nabla f) = 0\), \(\nabla\cdot(\nabla\times\mathbf F) = 0\)이 중요합니다. 첫째 식에서 "퍼텐셜의 기울기로 쓰이는 힘은 회전이 0"이 나오고, 이것이 3.2절 보존력 판정의 바탕입니다.

1.3.2곡선 좌표의 기울기

\(df = \nabla f\cdot d\mathbf r\)에서 출발합니다. 구면 좌표에서 \(d\mathbf r = dr\,\hat{\mathbf r} + r\,d\theta\,\hat{\boldsymbol\theta} + r\sin\theta\,d\phi\,\hat{\boldsymbol\phi}\)(1.1절)이고 \(df = \partial_rf\,dr + \partial_\theta f\,d\theta + \partial_\phi f\,d\phi\)이므로, 두 식을 맞추면

\[\nabla f = \frac{\partial f}{\partial r}\hat{\mathbf r} + \frac1r\frac{\partial f}{\partial\theta}\hat{\boldsymbol\theta} + \frac1{r\sin\theta}\frac{\partial f}{\partial\phi}\hat{\boldsymbol\phi}.\]

같은 방법으로 원통 좌표에서 \(\nabla f = \partial_\rho f\,\hat{\boldsymbol\rho} + \frac1\rho\partial_\phi f\,\hat{\boldsymbol\phi} + \partial_zf\,\hat{\mathbf z}\)입니다. 분모의 \(r\), \(r\sin\theta\)는 각도를 거리로 바꾸는 축척 인자입니다.

예제 1.3.1

중력 퍼텐셜 에너지 \(U = -\frac{GMm}{r}\)에서 힘 \(\mathbf F = -\nabla U\)를 구하여라.

풀이. \(U\)는 \(r\)에만 의존하므로 \(\nabla U = \frac{dU}{dr}\hat{\mathbf r} = \frac{GMm}{r^2}\hat{\mathbf r}\). \(\mathbf F = -\frac{GMm}{r^2}\hat{\mathbf r}\), 중심을 향하는 역제곱 힘입니다. 직교 좌표로 하면 \(r = \sqrt{x^2 + y^2 + z^2}\)를 세 번 편미분해야 해서 훨씬 깁니다.

1.3.3발산, 회전, 라플라시안

곡선 좌표의 발산과 회전은 단위벡터의 미분까지 생각해야 해서 더 복잡합니다. 구면 좌표의 라플라시안은

\[\nabla^2f = \frac1{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial f}{\partial r}\right) + \frac1{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial f}{\partial\theta}\right) + \frac1{r^2\sin^2\theta}\frac{\partial^2f}{\partial\phi^2}\]

이고, 전자기학(물리5)과 수소 원자(물리8)에서 다시 씁니다. 외우기보다 필요할 때 표에서 찾아 쓰고, 구대칭인 경우 첫 항만 남는다는 것을 기억하면 됩니다.

요약
  1. \(\nabla f\), \(\nabla\cdot\mathbf F\), \(\nabla\times\mathbf F\), \(\nabla^2 f\). \(\nabla\times\nabla f = 0\).
  2. 곡선 좌표의 기울기는 \(df = \nabla f\cdot d\mathbf r\)에서 축척 인자로 얻는다.

1.3.4연습문제

기본

    답
