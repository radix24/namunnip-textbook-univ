감쇠 진동: 미감쇠, 임계, 과감쇠

본문
이 절에서 배울 것

  • 감쇠 상수와 고유 진동수를 비교해 세 경우로 분류한다.
먼저 알아야 할 것
  • 단순 조화 진동자 (4.1절), 선형 저항 (2.2절), 상수 계수 선형 방정식 (공통8 2.2절).

4.2.1방정식과 특성근

저항 \(-b\dot x\)를 더하면 \(m\ddot x + b\dot x + kx = 0\). \(2\beta = b/m\)(감쇠 상수), \(\omega_0^2 = k/m\)로 두면

\[\ddot x + 2\beta\dot x + \omega_0^2x = 0.\]

\(x = e^{rt}\)를 넣으면 \(r^2 + 2\beta r + \omega_0^2 = 0\), \(r = -\beta \pm \sqrt{\beta^2 - \omega_0^2}\)입니다.

4.2.2세 경우

경우조건해모습
미감쇠\(\beta < \omega_0\)\(Ae^{-\beta t}\cos(\omega_1t - \delta)\), \(\omega_1 = \sqrt{\omega_0^2 - \beta^2}\)진폭이 지수적으로 주는 진동
임계 감쇠\(\beta = \omega_0\)\((C_1 + C_2t)e^{-\beta t}\)진동 없이 가장 빨리 평형으로
과감쇠\(\beta > \omega_0\)\(C_1e^{-(\beta - \sqrt{\beta^2 - \omega_0^2})t} + C_2e^{-(\beta + \sqrt{\beta^2 - \omega_0^2})t}\)진동 없이 천천히 평형으로
  • 미감쇠의 진동수 \(\omega_1\)은 \(\omega_0\)보다 조금 작다. 진폭이 \(1/e\)로 주는 시간은 \(1/\beta\).
  • 과감쇠에서는 느린 쪽 지수 \(\beta - \sqrt{\beta^2 - \omega_0^2}\)가 오래 남는다. 감쇠가 너무 크면 오히려 평형에 늦게 돌아온다.
  • 자동차 완충기, 저울 바늘, 문 닫힘 장치는 임계 감쇠 근처로 설계한다.
예제 4.2.1

\(m = 1\) kg, \(k = 100\) N/m인 진동자의 진폭이 10번 진동하는 동안 절반으로 줄었다. \(\beta\)와 \(b\)는?

풀이. \(\beta \ll \omega_0 = 10\) rad/s이면 주기 \(\approx 0.628\) s, 10주기 \(6.28\) s. \(e^{-6.28\beta} = 0.5\)에서 \(\beta \approx 0.110\) s⁻¹, \(b = 2m\beta \approx 0.22\) kg/s. \(\beta/\omega_0 \approx 0.011\)이라 미감쇠이고 \(\omega_1\)은 \(\omega_0\)와 거의 같습니다.

에너지는 \(e^{-2\beta t}\)로 줄어듭니다(진폭의 제곱). 공통8의 감쇠 진동 실습 카드(공통8 2.2절)에서 세 경우를 직접 비교할 수 있습니다.

요약
  1. \(\ddot x + 2\beta\dot x + \omega_0^2x = 0\), 특성근 \(-\beta \pm \sqrt{\beta^2 - \omega_0^2}\).
  2. \(\beta < \omega_0\) 미감쇠, \(= \omega_0\) 임계, \(> \omega_0\) 과감쇠.

4.2.3연습문제

기본

    \(C_1 = x_0\), \(\dot x(0) = C_2 - \beta C_1 = 0\)에서 \(C_2 = \beta x_0\). \(x = x_0(1 + \beta t)e^{-\beta t}\).
