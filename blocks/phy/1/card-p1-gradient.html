퍼텐셜의 기울기로 힘 구하기

기울기 · 등퍼텐셜면 · 곡선 좌표 · 문제 해결 전략

출발점

보존력은 \(\mathbf F = -\nabla U\)이다. 직교 좌표로 편미분해도 되지만, 대칭이 있으면 구면·원통 좌표의 기울기 공식(축척 인자 포함)이 훨씬 빠르다.

문제 해결 전략 · 퍼텐셜에서 힘 구하기
  1. 퍼텐셜이 어떤 좌표에 의존하는지 보고 좌표계를 고른다.
  2. 기울기 공식으로 성분을 구한다(각도 성분에는 \(1/r\) 등이 붙는다).
  3. 부호: 힘은 \(U\)가 줄어드는 쪽.
  4. 한 점에서 직교 좌표로 확인한다.

쌍극자의 퍼텐셜 에너지 \(U = \frac{k\cos\theta}{r^2}\)에서 시험 입자가 받는 힘의 \(r\), \(\theta\) 성분을 구하고, \(\theta = 0\)과 \(\theta = 90°\)에서 방향을 말하여라.

풀이

  1. \(F_r = -\partial_rU = \frac{2k\cos\theta}{r^3}\).
    구면 좌표 \(r\) 성분, 축척 인자 1.
  2. \(F_\theta = -\frac1r\partial_\theta U = -\frac1r\cdot\frac{-k\sin\theta}{r^2} = \frac{k\sin\theta}{r^3}\).
    각도 성분에는 \(1/r\)이 붙는다.
  3. \(\theta = 0\): \(F_r = 2k/r^3\), \(F_\theta = 0\). 축을 따라 바깥쪽(\(k > 0\)).
    축 위에서는 지름 방향만.
  4. \(\theta = 90°\): \(F_r = 0\), \(F_\theta = k/r^3\). \(\hat{\boldsymbol\theta}\) 방향(적도면에서 아래쪽, \(-z\) 방향).
    적도면에서는 축에 나란한 방향.

의미

축 위의 힘은 적도면의 두 배이고 방향이 다르다. 막대자석 둘레의 자기장 모양과 같은 구조이다. 각도 성분의 \(1/r\)을 빼먹으면 \(F_\theta\)의 단위부터 틀린다.

검산

\(\theta = 0\)인 \(z\)축 위에서 \(U = k/z^2\), \(F_z = -dU/dz = 2k/z^3\). \(F_r\)과 같다.
