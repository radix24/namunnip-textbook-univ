회전으로 판정하고 퍼텐셜 찾기

회전 · 성분별 적분 · 문제 해결 전략

출발점

구멍 없는 영역에서 \(\nabla\times\mathbf F = 0\)이면 보존력이고, 퍼텐셜을 성분별 적분으로 찾을 수 있습니다. 적분 상수가 다른 변수의 함수라는 점에 주의합니다.

문제 해결 전략 · 보존력 판정과 퍼텐셜
  1. 힘이 위치만의 함수인지 확인한다.
  2. 회전 세 성분을 계산한다.
  3. 0이면 \(-\partial_xU = F_x\)를 \(x\)로 적분하고, 상수 자리에 \(g(y, z)\)를 둔다.
  4. 나머지 성분으로 \(g\)를 차례로 정한다.

\(\mathbf F = (y^2z,\ 2xyz,\ xy^2 + 3z^2)\)가 보존력인지 판정하고 퍼텐셜 에너지를 구하여라.

풀이

  1. \((\nabla\times\mathbf F)_x = \partial_yF_z - \partial_zF_y = 2xy - 2xy = 0\). 나머지 두 성분도 \(y^2 - y^2 = 0\), \(2yz - 2yz = 0\).
    회전 0: 보존력.
  2. \(-\partial_xU = y^2z\) → \(U = -xy^2z + g(y, z)\).
    상수 자리에 \(y, z\)의 함수.
  3. \(-\partial_yU = 2xyz - \partial_yg = 2xyz\) → \(g = h(z)\).
    \(y\) 성분 비교.
  4. \(-\partial_zU = xy^2 - h'(z) = xy^2 + 3z^2\) → \(h = -z^3\). \(U = -xy^2z - z^3\) (+상수).
    \(z\) 성분 비교.

의미

퍼텐셜이 있으면 에너지 보존 \(\frac12mv^2 + U = \)일정을 바로 쓸 수 있습니다. 회전이 0이 아니면 이 성분별 적분은 어딘가에서 모순(\(g\)가 \(x\)에 의존하는 등)을 일으킵니다.

검산

\(-\nabla(-xy^2z - z^3) = (y^2z,\ 2xyz,\ xy^2 + 3z^2)\). 원래 힘과 같습니다.
