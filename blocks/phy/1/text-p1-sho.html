단순 조화 진동자

본문
이 절에서 배울 것
  • \(\ddot x = -\omega_0^2x\)의 해를 세 가지 꼴(사인·코사인, 진폭·위상, 복소수)로 쓴다.
  • 진동자의 에너지와 2차원 진동자의 궤적을 구한다.
먼저 알아야 할 것
  • 평형점 근처의 운동 (3.3절), 2계 선형 미분방정식 (공통8 2.1절), 오일러 공식.

용수철에 매단 물체, 작게 흔들리는 진자, 결정 속 원자의 떨림, 회로의 전류는 모두 같은 방정식을 따릅니다. 평형에서 벗어난 만큼 되돌리는 힘이 생기는 계는 평형 근처에서 늘 단순 조화 진동자가 되기 때문입니다(3.3절). 이 절에서 푸는 해와 에너지는 이후 감쇠, 강제 진동, 결합 진동, 양자역학까지 계속 쓰이는 기본 도구입니다.

4.1.1운동 방정식과 해

용수철 \(F = -kx\) 또는 안정 평형점 근처의 작은 진동은 \(m\ddot x = -kx\), 곧 \(\ddot x = -\omega_0^2x\) (\(\omega_0 = \sqrt{k/m}\))를 따릅니다. 2계 선형 방정식이라 독립인 두 해의 선형 결합이 일반해입니다.

\[x(t) = B_1\cos\omega_0t + B_2\sin\omega_0t = A\cos(\omega_0t - \delta) = \text{Re}\left[\mathcal Ce^{i\omega_0t}\right].\]
  • \(B_1 = x_0\), \(B_2 = v_0/\omega_0\) (초기 조건).
  • 진폭 \(A = \sqrt{B_1^2 + B_2^2}\), 위상 \(\tan\delta = B_2/B_1\).
  • 복소수 꼴: \(\mathcal C = Ae^{-i\delta}\). 감쇠·강제 진동에서 계산이 가장 편하다.

세 꼴은 같은 운동을 다르게 적은 것입니다. \(B_1\cos + B_2\sin\)은 초기 조건을 넣기 쉽고, \(A\cos(\omega_0t - \delta)\)는 진폭과 위상을 바로 읽기 쉽습니다. 복소수 꼴은 미분이 \(i\omega_0\)를 곱하는 것으로 바뀌어 계산이 쉽습니다. 원 위를 일정하게 도는 점 \(\mathcal Ce^{i\omega_0t}\)의 그림자(실수부)가 진동이라고 생각하면 됩니다.

처음 보는 수학 · 복소수 지수와 선형 결합 \(i^2 = -1\)인 복소수를 지수에 넣은 \(e^{i\theta}\)는 \(\cos\theta + i\sin\theta\)로 약속합니다(오일러 공식). 복소평면에서 원점으로부터 길이 1, 각도 \(\theta\)인 점이고, \(\theta = \omega t\)로 두면 원을 일정하게 도는 점이 됩니다. 그 실수부(\(\text{Re}\))가 \(\cos\omega t\)라서 진동을 나타냅니다. 좋은 점은 미분이 곱셈이 된다는 것입니다: \(\frac{d}{dt}e^{i\omega t} = i\omega e^{i\omega t}\). 이 교재에서는 계산할 때만 복소수를 쓰고 마지막에 실수부를 취합니다. 또 이 방정식은 해 두 개를 더해도 해가 되므로(선형), \(\cos\), \(\sin\) 두 해에 상수를 곱해 더한 것이 모든 해입니다. 두 상수는 처음 위치와 처음 속도로 정합니다.

주기 \(\tau = 2\pi/\omega_0 = 2\pi\sqrt{m/k}\)는 진폭과 무관합니다(등시성). 퍼텐셜이 정확히 포물선이 아니면 큰 진폭에서 이 성질이 깨집니다.

4.1.2에너지

\[E = \frac12m\dot x^2 + \frac12kx^2 = \frac12kA^2\sin^2(\cdot) + \frac12kA^2\cos^2(\cdot) = \frac12kA^2.\]

여기서 \((\cdot)\)은 \(\omega_0t - \delta\)이고, \(\dot x = -A\omega_0\sin(\cdot)\)와 \(m\omega_0^2 = k\)를 썼습니다. 운동 에너지와 퍼텐셜 에너지가 번갈아 바뀌며 합은 일정합니다. 평형점을 지날 때 속력이 가장 크고, 양 끝에서 멈춥니다. 한 주기 평균은 둘이 같아 각각 \(\frac12E\)입니다.

4.1.32차원 진동자

등방 진동자 \(\mathbf F = -k\mathbf r\)이면 \(x\), \(y\)가 같은 \(\omega_0\)로 따로 진동합니다: \(x = A_x\cos\omega_0t\), \(y = A_y\cos(\omega_0t - \delta)\). 위상차 \(\delta\)에 따라 궤적은

  • \(\delta = 0\): 직선.
  • \(\delta = \pm\pi/2\): 축에 나란한 타원(진폭이 같으면 원).
  • 그 밖: 기울어진 타원.

두 방향의 용수철 상수가 다르면(비등방) \(\omega_x \ne \omega_y\)이고, 비 \(\omega_x/\omega_y\)가 유리수이면 닫힌 리사주 곡선, 무리수이면 닫히지 않는 곡선이 됩니다.

예제 4.1.1

질량 0.2 kg이 \(k = 80\) N/m 용수철에 매달려 평형점에서 2 m/s로 출발한다. 진폭, 주기, 최대 가속도는?

풀이. \(\omega_0 = \sqrt{400} = 20\) rad/s, \(A = v_0/\omega_0 = 0.1\) m, \(\tau = 2\pi/20 \approx 0.314\) s, \(a_{\max} = \omega_0^2A = 40\) m/s².

요약
  1. \(x = A\cos(\omega_0t - \delta) = \text{Re}[\mathcal Ce^{i\omega_0t}]\), \(\omega_0 = \sqrt{k/m}\).
  2. \(E = \frac12kA^2\), 주기는 진폭과 무관.
  3. 2차원: 위상차에 따라 직선, 타원, 원. 비등방이면 리사주.
