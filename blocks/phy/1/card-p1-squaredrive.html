사각파로 미는 진동자의 응답

Fourier 급수 · 중첩 · 공명 성분 · 문제 해결 전략

출발점

힘을 Fourier 성분으로 나누면 각 성분에 4.3절의 진폭 공식을 쓰고 더하면 된다. \(Q\)가 크면 고유 진동수 근처 성분 하나가 응답을 지배한다.

문제 해결 전략 · 주기적인 힘의 응답
  1. 힘의 Fourier 계수를 구한다.
  2. 성분마다 응답 진폭 \(A_n = \frac{f_n}{\sqrt{(\omega_0^2 - n^2\omega^2)^2 + 4\beta^2n^2\omega^2}}\).
  3. 가장 큰 응답 성분을 찾는다.
  4. 비율로 해석한다.

진폭 \(f_0\)인 사각파 힘(\(\frac{4f_0}\pi(\sin\omega t + \frac13\sin3\omega t + \cdots)\))으로 \(\omega_0 = 3\omega\), \(\beta = 0.01\omega_0\)인 진동자를 민다. 첫째 성분과 셋째 성분의 응답 진폭 비는?

풀이

  1. 첫째(\(\omega\)): 힘 \(\frac{4f_0}\pi\), 분모 \(\sqrt{(9\omega^2 - \omega^2)^2 + \cdots} \approx 8\omega^2\).
    감쇠 항 \(4\beta^2\omega^2\)는 무시할 만큼 작다.
  2. 셋째(\(3\omega = \omega_0\)): 힘 \(\frac{4f_0}{3\pi}\), 분모 \(2\beta\cdot3\omega = 2(0.03\omega)(3\omega) = 0.18\omega^2\).
    공명이라 첫 항이 0.
  3. 비 \(\frac{A_3}{A_1} = \frac{1/(3\times0.18)}{1/8} = \frac{8}{0.54} \approx 14.8\).
    힘은 1/3이지만 응답은 15배 가까이.
  4. 진동자는 주로 \(3\omega = \omega_0\)로 진동한다.
    높은 \(Q\)가 공명 성분을 골라낸다.

의미

힘의 기본 박자와 다른 진동수로 계가 흔들릴 수 있다. 엔진의 진동이 차체의 특정 부분을 울리거나, 악기에서 특정 배음이 강하게 나오는 것이 이 현상이다.

검산

\(Q = \omega_0/2\beta = 50\). 공명 진폭은 정적 변위의 \(Q\)배라, 비공명 성분(약 정적 변위의 \(\frac98\)배)보다 수십 배 큰 것이 맞다.
