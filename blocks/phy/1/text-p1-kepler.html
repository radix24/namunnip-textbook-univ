궤도 방정식과 케플러 법칙

본문

케플러는 화성을 오랫동안 관측한 자료에서 행성이 타원을 그리고, 같은 시간에 같은 넓이를 쓸며, 주기의 제곱이 궤도 크기의 세제곱에 비례한다는 세 법칙을 찾아냈다. 하지만 왜 그런지는 몰랐다. 역제곱 중력 하나에서 이 세 법칙이 모두 나올까?

먼저 알아야 할 것유효 퍼텐셜(5.2절), 상수 계수 비동차 방정식(공통8 2.3절), 원뿔 곡선의 극방정식을 쓴다.

5.3.1궤도 방정식

5.2절에서는 궤도의 종류를 그래프로 읽었다. 이제 궤도의 모양 자체를 구해 보자. 궤도의 모양을 알고 싶으니 시간 \(t\)보다 각도 \(\phi\)의 함수 \(r(\phi)\)를 구하는 편이 낫다. 여기에 한 가지 요령을 더한다. \(r\) 대신 \(u = 1/r\)을 쓰는 것이다.

각운동량 보존에서 \(\dot\phi = \ell u^2/\mu\)이다. 연쇄 법칙으로 시간 미분을 각도 미분(\('\)로 표시)으로 바꾸면 \(\dot r = \frac{dr}{d\phi}\dot\phi = -\frac{1}{u^2}u'\cdot\frac{\ell u^2}{\mu} = -\frac\ell\mu u'\)이고, 한 번 더 같은 방법으로 \(\ddot r = -\frac\ell\mu u''\dot\phi = -\frac{\ell^2u^2}{\mu^2}u''\)이다. 이것과 \(r\dot\phi^2 = \frac{\ell^2u^3}{\mu^2}\)를 극좌표 반지름 방향 방정식 \(\mu(\ddot r - r\dot\phi^2) = F(r)\)에 넣고 \(-\frac{\ell^2u^2}{\mu}\)로 나누면

\[u''(\phi) = -u(\phi) - \frac{\mu}{\ell^2u(\phi)^2}F\]

이다. 이것이 중심력의 궤도 방정식이다.

5.3.2역제곱 힘

역제곱 힘 \(F = -\gamma/r^2 = -\gamma u^2\)을 넣으면 \(F/u^2\)이 상수가 되어 궤도 방정식이

\[u'' = -u + \frac{\gamma\mu}{\ell^2}\]

로 단순해진다. 우변의 상수를 빼면 4.1절의 단순 조화 방정식이다. 다만 변수가 시간이 아니라 각도이다.

처음 보는 수학 · \(u'' = -u + k\) 풀기\(w = u - k\)로 두면 \(w'' = -w\)로, 4.1절의 단순 조화 방정식과 같다(시간 대신 각도가 변수). 그래서 \(w = A\cos(\phi - \phi_0)\)이고, 각을 재는 기준을 \(\phi_0 = 0\)으로 잡으면 \(u = k + A\cos\phi\)이다. \(A/k\)를 \(\epsilon\)이라 쓴 것이 아래 해이다.

따라서 해는 "상수 + 코사인"이고,

\[u = \frac{\gamma\mu}{\ell^2}(1 + \epsilon\cos\phi), \qquad r(\phi) = \frac{c}{1 + \epsilon\cos\phi}, \quad c = \frac{\ell^2}{\gamma\mu}\]

이다. 이것은 초점이 원점인 원뿔 곡선의 극방정식이다. 이심률 \(\epsilon\)은 에너지와 \(E = \frac{\gamma^2\mu}{2\ell^2}(\epsilon^2 - 1)\)로 이어진다. 그래서 \(\epsilon = 0\)이면 원, \(0 < \epsilon < 1\)이면 \(E < 0\)인 타원, \(\epsilon = 1\)이면 포물선, \(\epsilon > 1\)이면 쌍곡선이며, 5.2절의 표와 정확히 맞는다.

풀이가 이렇게 쉬운 데에는 깊은 이유가 있다. 코사인의 주기가 정확히 \(2\pi\)이므로, 한 바퀴 돌면 \(r\)이 제자리로 돌아와 궤도가 닫힌다. 힘이 역제곱에서 조금만 벗어나도 궤도 방정식에 \(u\)에 비례하는 항이 섞여 진동의 주기가 \(2\pi\)와 달라지고, 궤도가 한 바퀴마다 조금씩 돌아간다. 수성의 근일점이 백 년에 약 43초씩 더 돌아가는 현상은 일반 상대성 이론이 주는 이런 작은 보정으로 설명된다.

5.3.3케플러 법칙

이제 처음 질문에 하나씩 답할 수 있다. 제1법칙은 위의 해 그대로이다. 묶인 궤도(\(E < 0\))는 태양을 한 초점으로 하는 타원이다.

제2법칙은 각운동량 보존에서 나온다. 시간 \(dt\) 동안 행성이 쓸고 지나가는 부채꼴의 넓이는 \(dA = \frac12r^2\,d\phi\)이므로, 면적 속도는 \(\frac{dA}{dt} = \frac12r^2\dot\phi = \frac{\ell}{2\mu}\)로 일정하다. 그림 1에서 보듯이 태양에 가까운 근일점에서는 반지름이 짧으므로 같은 넓이를 쓸려면 더 빨리 돌아야 한다. 이 법칙은 중심력이기만 하면 역제곱이 아니어도 성립한다.

제3법칙은 둘을 합쳐 얻는다. 한 바퀴 동안 쓰는 넓이는 타원의 넓이 \(\pi ab\)이므로, 이를 면적 속도로 나누면 주기 \(\tau = \frac{2\pi ab\mu}{\ell}\)이다. 타원에서 \(b^2 = ac\)이고 \(c = \ell^2/(\gamma\mu)\)이므로 \(\ell\)을 지우면

\[\tau^2 = \frac{4\pi^2\mu}{\gamma}a^3 = \frac{4\pi^2}{G(m_1 + m_2)}a^3\]

이다. 주기의 제곱이 긴반지름의 세제곱에 비례하고, 비례 상수에는 두 질량의 합이 들어간다. 태양 질량이 행성보다 훨씬 크므로 모든 행성에서 이 상수가 거의 같고, 그래서 케플러는 하나의 법칙으로 보았다. 거꾸로 쌍성의 주기와 궤도 크기를 재면 이 식으로 별의 질량을 구할 수 있다.

예제 5.3.1

지구 궤도(\(a = 1.496\times10^{11}\) m, \(\tau = 1\) 년 \(= 3.156\times10^7\) s)로 태양 질량을 구하여라.

풀이. 지구 질량은 태양의 30만분의 1 정도라 무시하면 \(M \approx \frac{4\pi^2a^3}{G\tau^2} = \frac{4\pi^2(1.496\times10^{11})^3}{6.674\times10^{-11}(3.156\times10^7)^2} \approx 1.99\times10^{30}\) kg이다. 1년과 1 AU라는 두 숫자만으로 태양의 질량을 잰 셈이다.

마무리

각도를 변수로, \(u = 1/r\)을 미지수로 쓰면 중심력의 궤도 방정식은 \(u'' = -u - \mu F/(\ell^2u^2)\)이 되고, 역제곱 힘에서는 단순 조화 방정식이 되어 해가 원뿔 곡선 \(r = c/(1 + \epsilon\cos\phi)\)이다. 처음 질문의 세 법칙은 모두 여기서 나온다. 묶인 궤도는 타원이고, 각운동량 보존으로 면적 속도가 일정하며, 넓이를 면적 속도로 나누면 \(\tau^2 = 4\pi^2a^3/(GM)\)이 된다.
