조화 진동자 고유함수와 고전 확률

실습 · 대응 원리

목표

양자수 \(n\)을 바꾸며 조화 진동자 고유함수 \(\psi_n\)과 확률 밀도 \(|\psi_n|^2\)을 그리고, 고전 진동자가 각 위치에 머무는 비율과 비교합니다. \(n\)이 커지면 양자 결과가 고전 결과에 다가가는 대응 원리를 확인합니다. 성취기준 [물리8-02-04].

준비

가로축은 \(\xi = x\sqrt{m\omega/\hbar}\)입니다. 파랑이 \(|\psi_n|^2\), 옅은 선이 \(\psi_n\), 주황 점선이 같은 에너지의 고전 확률 밀도, 세로 점선이 고전 되돌이점입니다. \(\psi_n\)은 사다리 연산자에서 나온 점화식으로 계산합니다.

절차

  1. n = 0, 1, 2에서 마디 수와 되돌이점 바깥에서 찾을 확률을 적는다.
  2. n = 10, 20으로 올려 파란 곡선의 평균적인 모양이 주황 점선과 비슷해지는지 본다.
  3. n이 커질 때 되돌이점 바깥 확률이 어떻게 바뀌는지 기록한다.

기대 결과

  • n = 0: 마디 0개, 되돌이점 ±1, 바깥 확률 15.7%. n = 1: 마디 1개, 11.1%. n = 2: 마디 2개, 9.5%.
  • n = 10, 20에서 파란 곡선이 빠르게 출렁이지만 평균적인 모양은 양 끝이 높은 주황 점선을 따른다.
  • 되돌이점 바깥 확률은 n = 10에서 6.0%, n = 20에서 4.8%로 n이 커질수록 줄어든다.

분석

  1. 고전 진동자는 왜 되돌이점 근처에서 가장 오래 머물고, 바닥 상태는 왜 반대로 가운데에서 확률이 가장 큰가요?
  2. 되돌이점 바깥에서 입자를 찾을 확률이 0이 아닌 것은 무엇과 같은 현상인가요(물리3 4.5절)?
