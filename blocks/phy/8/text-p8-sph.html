구면 좌표의 슈뢰딩거 방정식과 지름 방정식

본문

원자 속 전자는 3차원에서 움직이므로 슈뢰딩거 방정식이 세 변수의 편미분방정식이 된다. 그런데 핵이 만드는 퍼텐셜은 거리 \(r\)에만 의존한다. 이 대칭을 쓰면 3차원 문제를 1차원 문제로 줄일 수 있을까? 그리고 각운동량이 있는 전자가 핵 가까이에 잘 오지 못하는 까닭은 무엇일까?

먼저 알아야 할 것구면 좌표의 라플라시안과 변수분리(공통9 9.1절)를 쓴다.

4.1.1변수분리

3차원에서는 \(\hat{\mathbf p} = -i\hbar\nabla\)이므로 시간에 무관한 방정식은 \(-\frac{\hbar^2}{2m}\nabla^2\psi + V\psi = E\psi\)이다. 퍼텐셜이 \(r\)에만 의존하는 중심력 퍼텐셜이면 구면 좌표가 알맞으며, 라플라시안은 다음과 같다.

\[\nabla^2 = \frac1{r^2}\frac\partial{\partial r}\left(r^2\frac\partial{\partial r}\right) + \frac1{r^2}\left[\frac1{\sin\theta}\frac\partial{\partial\theta}\left(\sin\theta\frac\partial{\partial\theta}\right) + \frac1{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right]\]

\(\psi = R(r)Y(\theta, \phi)\)로 놓고 \(-\frac{2mr^2}{\hbar^2}\frac1{RY}\)를 곱하면 \(r\)만의 부분과 각도만의 부분으로 나뉜다. 그래서 둘 다 같은 상수여야 하며, 이 분리 상수를 \(l(l + 1)\)로 적는다.

정리 4.1.1 \[\frac1{\sin\theta}\frac\partial{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac1{\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2} = -l(l + 1)Y,\] \[\frac{d}{dr}\left(r^2\frac{dR}{dr}\right) - \frac{2mr^2}{\hbar^2}\left[V(r) - E\right]R = l(l + 1)R\]

각 방정식에는 \(V\)가 없다. 따라서 중심력이면 퍼텐셜이 무엇이든 각 부분의 해는 같고, 그 해가 구면 조화 함수 \(Y_l^m\)이다(4.2절). 여기서 \(l = 0, 1, 2, \dots\)이고 \(m = -l, \dots, l\)이다.

4.1.2지름 부분과 유효 퍼텐셜

지름 방정식은 \(u(r) = rR(r)\)로 바꾸면 1차원 슈뢰딩거 방정식 꼴이 된다. 처음 질문의 첫째 답이 이것이다.

정리 4.1.2 \[-\frac{\hbar^2}{2m}\frac{d^2u}{dr^2} + \left[V(r) + \frac{\hbar^2}{2m}\frac{l(l + 1)}{r^2}\right]u = Eu, \qquad \int_0^\infty|u|^2dr = 1, \quad u(0) = 0\]

괄호 안의 퍼텐셜을 유효 퍼텐셜이라 하고, 그 둘째 항을 원심력 장벽이라 한다. 고전역학에서 각운동량이 보존될 때 생기는 \(L^2/2mr^2\)(물리1 중심력)과 같은 꼴이다. 이 항은 \(l\)이 클수록 원점 근처에서 커져 입자를 밀어낸다(그림 1). 처음 질문의 둘째 답이 이것으로, 그래서 s 전자만 핵 위치에서 0이 아닌 확률을 가진다.

또 에너지는 \(m\)에 무관하다. 지름 방정식에 \(m\)이 나오지 않기 때문이다. 따라서 각 \(l\)마다 \(2l + 1\)개의 상태가 같은 에너지를 가진다. 공간에 특별한 방향이 없으니 각운동량이 어느 쪽을 향하든 에너지가 같은 것이다.

예제 4.1.3

반지름 \(a\)인 무한 구형 우물(\(r < a\)에서 \(V = 0\))의 \(l = 0\) 준위를 구하여라.

풀이. \(l = 0\)이면 \(u'' = -k^2u\)이고, \(u(0) = 0\)에서 \(u = A\sin kr\)이다. 또 \(u(a) = 0\)에서 \(ka = n\pi\)이므로 \(E_{n0} = \frac{n^2\pi^2\hbar^2}{2ma^2}\)으로, 폭 \(a\)인 1차원 무한 우물과 같다. 한편 \(l \ge 1\)이면 준위가 구면 베셀 함수의 영점으로 정해진다.

흔한 오해\(u = rR\)이니 지름 확률 밀도도 \(|R|^2\)이라고 생각하기 쉽지만, 반지름 \(r\)인 구껍질의 부피가 \(4\pi r^2dr\)이므로 \(r\)과 \(r + dr\) 사이에서 찾을 확률은 \(r^2|R|^2dr = |u|^2dr\)이다. 그래서 \(\psi\)가 원점에서 가장 커도 지름 확률은 원점에서 0이다.
마무리

중심력 퍼텐셜에서는 \(\psi = R(r)Y_l^m(\theta, \phi)\)로 분리되고, 각 부분은 퍼텐셜과 무관하게 구면 조화 함수가 된다. 지름 부분은 \(u = rR\)로 바꾸면 유효 퍼텐셜 \(V + \hbar^2l(l + 1)/2mr^2\) 속의 1차원 문제가 되어, 처음 질문처럼 3차원 문제가 1차원으로 줄어든다. 원심력 장벽 때문에 \(l\)이 큰 입자는 원점에서 밀려나고, 에너지는 \(m\)에 무관해 \(2l + 1\)겹으로 축퇴한다.

4.1.3연습문제

기본

  1. \(l = 2\)인 상태는 몇 개의 \(m\) 값을 가지나요?
    답

    \(2l + 1 = 5\)개 (\(m = -2, \dots, 2\)).

발전

  1. 원점 근처에서 \(V\)가 \(1/r^2\)보다 덜 발산하면 \(u \sim r^{l+1}\)임을 보이세요.
    답

    작은 \(r\)에서 원심력 항이 지배해 \(u'' \approx l(l + 1)u/r^2\). \(u = r^s\)를 넣으면 \(s(s - 1) = l(l + 1)\), \(s = l + 1\) 또는 \(-l\). \(u(0) = 0\)이려면 \(s = l + 1\). 그래서 \(l > 0\) 상태는 원점에서 0이고 s 상태만 핵 위치에 확률이 있습니다.
