수소 원자

본문

보어 모형은 각운동량이 \(\hbar\)의 정수배라는 가정을 두고 수소의 준위 \(-13.6\ \text{eV}/n^2\)을 얻었다. 슈뢰딩거 방정식은 그런 가정 없이 같은 준위를 줄 수 있을까? 그리고 바닥 상태의 전자는 핵에서 얼마나 떨어진 곳에서 가장 잘 발견될까?

먼저 알아야 할 것지름 방정식(4.1절), 보어 모형(물리3 5.1절), 급수해(공통8 4.1절)를 쓴다.

4.3.1지름 방정식 풀기

쿨롱 퍼텐셜 \(V = -\frac{e^2}{4\pi\epsilon_0r}\)에서 \(E < 0\)인 속박 상태를 찾자. \(\kappa = \sqrt{-2m_eE}/\hbar\), \(\rho = \kappa r\), \(\rho_0 = \frac{m_ee^2}{2\pi\epsilon_0\hbar^2\kappa}\)로 두면 4.1절의 지름 방정식은 다음과 같다.

\[\frac{d^2u}{d\rho^2} = \left[1 - \frac{\rho_0}\rho + \frac{l(l + 1)}{\rho^2}\right]u\]

큰 \(\rho\)에서는 \(u \sim e^{-\rho}\), 작은 \(\rho\)에서는 \(u \sim \rho^{l+1}\)이므로, 두 행동을 떼어 내고 \(u = \rho^{l+1}e^{-\rho}v(\rho)\), \(v = \sum c_j\rho^j\)로 놓는다. 넣어 정리하면 다음 점화식을 얻는다.

\[c_{j+1} = \frac{2(j + l + 1) - \rho_0}{(j + 1)(j + 2l + 2)}c_j\]

그런데 급수가 끝나지 않으면 큰 \(j\)에서 \(c_{j+1} \approx \frac2jc_j\), 곧 \(v \sim e^{2\rho}\)가 되어 \(u \sim e^\rho\)로 발산한다. 그러므로 어떤 \(j_{\max}\)에서 분자가 0이 되어 급수가 끊겨야 하고, \(\rho_0 = 2(j_{\max} + l + 1) \equiv 2n\)이다. 물리18 5.1절에서 본 르장드르 급수와 같은 논리이다.

정리 4.3.1 (수소 준위) \[E_n = -\frac{m_e}{2\hbar^2}\left(\frac{e^2}{4\pi\epsilon_0}\right)^2\frac1{n^2} = -\frac{13.6\ \text{eV}}{n^2}, \qquad a_0 = \frac{4\pi\epsilon_0\hbar^2}{m_ee^2} = 0.0529\ \text{nm}\]

\(n = 1, 2, \dots\), \(l = 0, 1, \dots, n - 1\), \(m = -l, \dots, l\)이다.

따라서 처음 질문의 첫째 답은 그렇다는 것이다. 보어 모형과 같은 준위가 이번에는 가정 없이, 파동함수가 무한대에서 0이 되어야 한다는 조건에서 나왔다. 또 에너지가 \(l\)에도 무관한데, 이것은 쿨롱 퍼텐셜에만 있는 특별한 대칭 때문이다. 그래서 준위 \(n\)의 축퇴는 \(\sum_{l=0}^{n-1}(2l + 1) = n^2\)이고, 스핀을 넣으면 \(2n^2\)이다. 여기서 \(n\)을 주양자수라 한다.

4.3.2파동함수

파동함수는 \(\psi_{nlm} = R_{nl}(r)Y_l^m(\theta, \phi)\)이고, \(v\)는 연관 라게르 다항식이다. 처음 몇 개는 다음과 같다.

\[R_{10} = \frac2{a_0^{3/2}}e^{-r/a_0}, \quad R_{20} = \frac1{\sqrt2a_0^{3/2}}\left(1 - \frac r{2a_0}\right)e^{-r/2a_0}, \quad R_{21} = \frac1{\sqrt{24}a_0^{3/2}}\frac r{a_0}e^{-r/2a_0}\]

지름 방향 마디는 \(n - l - 1\)개, 각 방향 마디는 \(l\)개로 합하면 \(n - 1\)개이다. 또 반지름 \(r\)인 구껍질에서 찾을 확률은 지름 확률 밀도 \(P(r) = r^2|R_{nl}|^2\)이다. 바닥 상태는 \(P = \frac4{a_0^3}r^2e^{-2r/a_0}\)을 미분해 0으로 두면 \(r = a_0\)에서 가장 크다(그림 1). 처음 질문의 둘째 답이 이것으로, 보어 반지름이 가장 그럴듯한 거리로 다시 나타난다. 평균 거리는 \(\langle r\rangle = \frac{a_0}2[3n^2 - l(l + 1)]\)이어서 원자의 크기는 대략 \(n^2a_0\)이다. 아래 실습 카드에서 \(n\), \(l\)에 따른 지름 확률 밀도와 마디를 볼 수 있다.

예제 4.3.2

바닥 상태에서 전자를 \(r > 2a_0\)에서 찾을 확률은?

풀이. \(P = \frac4{a_0^3}\int_{2a_0}^\infty r^2e^{-2r/a_0}dr\)이다. \(x = 2r/a_0\)로 바꾸면 \(\frac12\int_4^\infty x^2e^{-x}dx = \frac12e^{-4}(16 + 8 + 2) = 13e^{-4} \approx 0.238\)이다. 즉 바닥 상태의 전자도 네 번에 한 번쯤은 보어 반지름의 두 배보다 멀리서 발견된다.

흔한 오해바닥 상태의 전자가 반지름 \(a_0\)인 궤도를 돈다고 생각하기 쉽지만, \(a_0\)는 지름 확률이 가장 큰 거리일 뿐이다. 바닥 상태의 각운동량은 0이어서 전자는 아무 방향으로도 돌지 않으며, 확률 밀도 \(|\psi|^2\) 자체는 오히려 핵 위치에서 가장 크다.
마무리

쿨롱 퍼텐셜의 지름 방정식은 급수가 끊겨야 무한대에서 유한하므로, 처음 질문처럼 가정 없이 \(E_n = -13.6\ \text{eV}/n^2\)을 준다. 양자수는 \(l < n\), \(|m| \le l\)이고 축퇴는 \(n^2\)이다. 지름 마디는 \(n - l - 1\)개이고, 지름 확률 밀도 \(P(r) = r^2R^2\)으로 보면 바닥 상태의 전자는 \(a_0\)에서 가장 잘 발견된다.

4.3.3연습문제

기본

  1. 바닥 상태의 \(\langle r\rangle\)과 가장 그럴듯한 \(r\)을 구하여라.
    답

    \(\langle r\rangle = \frac32a_0\), 최빈값 \(a_0\). 분포가 오른쪽으로 꼬리를 끌어 평균이 더 크다.

  2. \(n = 3\) 준위에 속하는 \((l, m)\) 조합을 모두 세어라.
    답

    \(l = 0\) (1개), \(l = 1\) (3개), \(l = 2\) (5개), 모두 9개 = \(3^2\).

발전

  1. 전자 대신 뮤온(\(m_\mu \approx 207m_e\))이 양성자에 묶이면 \(E_1\)과 \(a_0\)는 어떻게 되나요? 환산 질량을 고려하여라.
    답

    환산 질량 \(\mu = \frac{207m_e\cdot1836m_e}{207m_e + 1836m_e} \approx 186m_e\). \(E_1 \approx -186\times13.6 \approx -2.53\) keV, 반지름 \(\approx a_0/186 \approx 2.8\times10^{-4}\) nm. 핵 크기 효과를 재는 데 쓰인다.
