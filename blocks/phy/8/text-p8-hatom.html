수소 원자

본문
이 절에서 배울 것
  • 쿨롱 퍼텐셜의 지름 방정식을 급수로 풀어 에너지 준위 \(E_n = -13.6\ \text{eV}/n^2\)을 얻는다.
  • 양자수 \(n, l, m\)의 범위와 축퇴 \(n^2\)을 안다.
  • 지름 파동함수와 지름 확률 밀도를 해석한다.
먼저 알아야 할 것
  • 지름 방정식 (4.1절), 보어 모형 (물리3 5.1절), 급수해 (공통8 4.1절).

4.3.1지름 방정식 풀기

\(V = -\frac{e^2}{4\pi\epsilon_0r}\), \(E < 0\)인 속박 상태를 찾습니다. \(\kappa = \sqrt{-2m_eE}/\hbar\), \(\rho = \kappa r\), \(\rho_0 = \frac{m_ee^2}{2\pi\epsilon_0\hbar^2\kappa}\)로 두면

\[\frac{d^2u}{d\rho^2} = \left[1 - \frac{\rho_0}\rho + \frac{l(l + 1)}{\rho^2}\right]u.\]

큰 \(\rho\)에서 \(u \sim e^{-\rho}\), 작은 \(\rho\)에서 \(u \sim \rho^{l+1}\)이므로 \(u = \rho^{l+1}e^{-\rho}v(\rho)\), \(v = \sum c_j\rho^j\)로 놓습니다. 넣어 정리하면 점화식

\[c_{j+1} = \frac{2(j + l + 1) - \rho_0}{(j + 1)(j + 2l + 2)}c_j.\]

급수가 끝나지 않으면 큰 \(j\)에서 \(c_{j+1} \approx \frac2jc_j\), 곧 \(v \sim e^{2\rho}\)가 되어 \(u \sim e^{\rho}\)로 발산합니다. 그러므로 어떤 \(j_{\max}\)에서 끊겨야 하고, \(\rho_0 = 2(j_{\max} + l + 1) \equiv 2n\)입니다.

정리 4.3.1 (수소 준위) \[E_n = -\frac{m_e}{2\hbar^2}\left(\frac{e^2}{4\pi\epsilon_0}\right)^2\frac1{n^2} = -\frac{13.6\ \text{eV}}{n^2}, \qquad a_0 = \frac{4\pi\epsilon_0\hbar^2}{m_ee^2} = 0.0529\ \text{nm}.\]

\(n = 1, 2, \dots\), \(l = 0, 1, \dots, n - 1\), \(m = -l, \dots, l\).

보어 모형과 같은 준위가 나오지만 이번에는 가정 없이 방정식에서 나왔습니다. 에너지가 \(l\)에도 무관해(쿨롱 퍼텐셜의 특별한 대칭) 준위 \(n\)의 축퇴는 \(\sum_{l=0}^{n-1}(2l + 1) = n^2\)입니다(스핀을 넣으면 \(2n^2\)).

4.3.2파동함수

\(\psi_{nlm} = R_{nl}(r)Y_l^m(\theta, \phi)\)이고, \(v\)는 연관 라게르 다항식입니다. 처음 몇 개:

\[R_{10} = \frac2{a_0^{3/2}}e^{-r/a_0}, \quad R_{20} = \frac1{\sqrt2a_0^{3/2}}\left(1 - \frac r{2a_0}\right)e^{-r/2a_0}, \quad R_{21} = \frac1{\sqrt{24}a_0^{3/2}}\frac r{a_0}e^{-r/2a_0}.\]
  • 지름 마디 수 \(n - l - 1\), 각 마디 수 \(l\), 합해 \(n - 1\).
  • 지름 확률 밀도 \(P(r) = r^2|R_{nl}|^2\). 바닥 상태는 \(r = a_0\)에서 가장 크다(보어 반지름).
  • \(\langle r\rangle = \frac{a_0}2\left[3n^2 - l(l + 1)\right]\). 크기는 대략 \(n^2a_0\).

아래 실습 카드에서 \(n, l\)에 따른 지름 확률 밀도와 마디를 볼 수 있습니다.

예제 4.3.2

바닥 상태에서 전자를 \(r > 2a_0\)에서 찾을 확률은?

풀이. \(P = \frac4{a_0^3}\int_{2a_0}^\infty r^2e^{-2r/a_0}dr\). \(x = 2r/a_0\)로 바꾸면 \(\frac12\int_4^\infty x^2e^{-x}dx = \frac12e^{-4}(16 + 8 + 2) = 13e^{-4} \approx 0.238\).

요약
  1. 급수가 끊겨야 하므로 \(E_n = -13.6\ \text{eV}/n^2\).
  2. \(l < n\), \(|m| \le l\), 축퇴 \(n^2\).
  3. 지름 마디 \(n - l - 1\), \(P(r) = r^2R^2\), 바닥 상태는 \(a_0\)에서 최대.

4.3.3연습문제

기본

  1. 바닥 상태의 \(\langle r\rangle\)과 가장 그럴듯한 \(r\)을 구하세요.
    답

    \(\langle r\rangle = \frac32a_0\), 최빈값 \(a_0\). 분포가 오른쪽으로 꼬리를 끌어 평균이 더 큽니다.

  2. \(n = 3\) 준위에 속하는 \((l, m)\) 조합을 모두 세세요.
    답

    \(l = 0\) (1개), \(l = 1\) (3개), \(l = 2\) (5개), 모두 9개 = \(3^2\).

발전

  1. 전자 대신 뮤온(\(m_\mu \approx 207m_e\))이 양성자에 묶이면 \(E_1\)과 \(a_0\)는 어떻게 되나요? 환산 질량을 고려하세요.
    답

    환산 질량 \(\mu = \frac{207m_e\cdot1836m_e}{207m_e + 1836m_e} \approx 186m_e\). \(E_1 \approx -186\times13.6 \approx -2.53\) keV, 반지름 \(\approx a_0/186 \approx 2.8\times10^{-4}\) nm. 핵 크기 효과를 재는 데 쓰입니다.
