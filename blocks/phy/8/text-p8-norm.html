파동함수의 규격화와 확률 흐름

본문

파동함수의 절댓값 제곱이 입자를 찾을 확률이라면, 전체 공간에서 더한 확률은 1이어야 한다. 그런데 시간이 지나면 파동함수가 슈뢰딩거 방정식을 따라 모양을 바꾼다. 처음에 1로 맞춰 둔 전체 확률이 나중에도 1로 남는다는 보장이 있을까? 그리고 확률이 한곳에서 다른 곳으로 옮겨 갈 때 그 흐름은 어떻게 쓸까?

먼저 알아야 할 것파동함수와 확률 밀도의 뜻(물리3 4.1절), 복소수와 부분적분을 쓴다.

1.2.1슈뢰딩거 방정식과 통계적 해석

질량 \(m\)인 입자가 퍼텐셜 \(V(x)\) 속을 1차원으로 움직일 때 파동함수 \(\Psi(x, t)\)는 슈뢰딩거 방정식을 따른다.

\[i\hbar\frac{\partial\Psi}{\partial t} = -\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2} + V\Psi\]

이 식은 다른 원리에서 유도되는 것이 아니라 실험과 맞기 때문에 받아들이는 기본 법칙이며, 고전역학의 \(F = ma\)와 같은 자리에 있다. 또 보른 해석에 따르면 \(|\Psi(x, t)|^2dx\)는 시각 \(t\)에 입자를 \(x\)와 \(x + dx\) 사이에서 찾을 확률이다.

1.2.2규격화

입자는 어딘가에는 있으므로 \(\int_{-\infty}^{\infty}|\Psi|^2dx = 1\)이어야 한다. 그런데 슈뢰딩거 방정식은 선형이어서 \(\Psi\)가 해이면 \(A\Psi\)도 해이다. 이 상수 \(A\)를 위 조건으로 정하는 일을 규격화라 한다. 반면 적분이 무한대인 함수, 가령 상수 함수는 규격화할 수 없어 물리적 상태를 나타내지 못한다.

정리 1.2.1 (규격화 유지)

\(\Psi\)가 슈뢰딩거 방정식을 따르고 \(x \to \pm\infty\)에서 0으로 가면 \(\frac{d}{dt}\int|\Psi|^2dx = 0\)이다.

증명. 방정식과 그 켤레식, 곧 모든 \(i\)를 \(-i\)로, \(\Psi\)를 \(\Psi^*\)로 바꾼 식에서 \(\partial_t\Psi = \frac{i\hbar}{2m}\Psi'' - \frac i\hbar V\Psi\), \(\partial_t\Psi^* = -\frac{i\hbar}{2m}\Psi^{*\prime\prime} + \frac i\hbar V\Psi^*\)이다(\(V\)는 실수). 곱의 미분으로 \(|\Psi|^2 = \Psi^*\Psi\)를 미분하고 두 식을 넣으면 \(V\)가 든 항이 지워진다.

\[\frac{\partial}{\partial t}|\Psi|^2 = \frac{i\hbar}{2m}\left(\Psi^*\Psi'' - \Psi\Psi^{*\prime\prime}\right) = \frac{\partial}{\partial x}\left[\frac{i\hbar}{2m}\left(\Psi^*\Psi' - \Psi\Psi^{*\prime}\right)\right]\]

마지막 등호는 대괄호를 \(x\)로 미분해 보면 \(\Psi^{*\prime}\Psi'\) 항끼리 지워져 확인된다. 그러면 전 구간 적분은 양 끝 값의 차이이고, 끝에서 \(\Psi \to 0\)이므로 0이다. \(\square\) 따라서 처음 질문의 첫째 답은 그렇다는 것이다. 한 번 규격화하면 언제나 규격화되어 있으므로 확률 해석이 모순 없이 유지된다.

예제 1.2.4

\(\Psi(x, 0) = Ae^{-a|x|}\)(\(a > 0\))를 규격화하여라.

풀이. \(\int|A|^2e^{-2a|x|}dx = |A|^2\cdot2\cdot\frac1{2a} = |A|^2/a = 1\)이므로 \(A = \sqrt a\)이다. 이 함수는 2.3절에서 다룰 델타 우물의 바닥 상태이다.

1.2.3확률 흐름과 연속 방정식

증명의 대괄호에 음의 부호를 붙인 것을 확률 흐름이라 한다.

정의 1.2.2 \[j(x, t) = \frac{i\hbar}{2m}\left(\Psi\frac{\partial\Psi^*}{\partial x} - \Psi^*\frac{\partial\Psi}{\partial x}\right) = \frac\hbar m\,\mathrm{Im}\left(\Psi^*\frac{\partial\Psi}{\partial x}\right), \qquad \frac{\partial|\Psi|^2}{\partial t} + \frac{\partial j}{\partial x} = 0\]

전하의 연속 방정식과 같은 꼴이다. 그래서 구간 \([a, b]\) 안의 확률은 \(j(a) - j(b)\)의 빠르기로 바뀐다(그림 1). 처음 질문의 둘째 답이 이것이다. 한편 실수 파동함수, 또는 실수 함수에 상수 위상을 곱한 것은 \(j = 0\)이다.

예제 1.2.3

평면파 \(\Psi = Ae^{i(kx - \omega t)}\)의 확률 흐름을 구하여라.

풀이. \(\Psi^*\Psi' = ik|A|^2\)이므로 \(j = \frac{\hbar k}m|A|^2 = v|A|^2\)이다. 즉 밀도 \(|A|^2\)에 속도 \(v = p/m\)를 곱한 것이다. 2.4절의 반사율과 투과율은 이 흐름의 비로 정의한다.

흔한 오해\(\Psi\) 자체가 확률이라고 생각하기 쉽지만, \(\Psi\)는 복소수이고 음수도 될 수 있는 진폭이다. 확률 밀도는 \(|\Psi|^2\)이며, 단위도 1차원에서 길이의 역수이다. 그래서 \(\Psi\)의 전체 위상을 바꿔도 확률은 그대로이다.
마무리

\(|\Psi|^2\)는 확률 밀도이고 전체 적분은 1로 규격화한다. 슈뢰딩거 방정식은 규격화를 시간이 지나도 유지하므로, 처음 질문의 전체 확률은 늘 1로 남는다. 확률이 옮겨 가는 흐름은 \(j = (\hbar/m)\,\mathrm{Im}(\Psi^*\Psi')\)이고 연속 방정식 \(\partial_t|\Psi|^2 + \partial_xj = 0\)을 따른다.

1.2.4연습문제

기본

  1. \(\Psi(x, 0) = A x(L - x)\) (\(0 \le x \le L\), 바깥 0)를 규격화하세요.
    답

    \(\int_0^Lx^2(L - x)^2dx = L^5/30\)이므로 \(A = \sqrt{30/L^5}\).

  2. \(\Psi = Ae^{ikx} + Be^{-ikx}\)의 확률 흐름은?
    답

    \(j = \frac{\hbar k}{m}(|A|^2 - |B|^2)\). 교차항은 상쇄됩니다. 오른쪽 흐름에서 왼쪽 흐름을 뺀 것입니다.

발전

  1. 퍼텐셜에 허수부 \(V = V_0 - i\Gamma\) (\(\Gamma > 0\) 상수)를 넣으면 전체 확률이 어떻게 변하는지 보이세요.
    답

    증명을 다시 하면 \(\frac{dP}{dt} = -\frac{2\Gamma}{\hbar}P\), \(P = e^{-2\Gamma t/\hbar}\). 붕괴하는 불안정 입자를 흉내 내는 방법이며, 수명은 \(\tau = \hbar/2\Gamma\)입니다.
