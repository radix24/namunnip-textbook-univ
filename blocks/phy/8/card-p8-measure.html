무한 우물에서 에너지를 재면

보른 규칙 · 기대값 · 붕괴

출발점

상태 \(\Psi = \sum c_n\psi_n\)에서 에너지를 재면 \(E_n\)이 확률 \(|c_n|^2\)로 나오고, 측정 직후 상태는 \(\psi_n\)이 된다. 기대값은 \(\langle E\rangle = \sum|c_n|^2E_n\)입니다(3.2절). 무한 우물의 준위는 \(E_n = n^2E_1\)이다.

문제 해결 전략 · 확률 → 기대값 → 표준편차 → 측정 뒤
  1. 계수의 절댓값 제곱으로 각 결과의 확률을 구한다.
  2. \(\langle E\rangle\)와 \(\langle E^2\rangle\)에서 표준편차를 구한다.
  3. 측정 결과에 따라 바뀐 상태와 다음 측정을 예측한다.

무한 우물의 입자가 \(\Psi = \frac1{\sqrt5}(\psi_1 + 2\psi_2)\) 상태에 있다. (가) 에너지를 재어 각 값이 나올 확률은? (나) \(\langle E\rangle\)와 \(\sigma_E\)는? (다) \(E_2\)가 나왔다면, 곧바로 다시 재면? 위치를 잰 뒤 에너지를 다시 재면?

풀이

  1. (가) \(E_1\): 1/5, \(E_2 = 4E_1\): 4/5.
    \(|c_n|^2\).
  2. (나) \(\langle E\rangle = \frac15E_1 + \frac45\cdot4E_1 = 3.4E_1\). \(\langle E^2\rangle = \frac15 + \frac45\cdot16 = 13E_1^2\), \(\sigma_E = \sqrt{13 - 11.56}\,E_1 = 1.2E_1\).
    분산 = 제곱 평균 − 평균 제곱.
  3. (다) 상태가 \(\psi_2\)로 붕괴해 곧바로 다시 재면 반드시 \(E_2\). 위치를 재면 좁은 봉우리(여러 \(\psi_n\)의 중첩)가 되어 다시 잰 에너지는 여러 값이 나올 수 있다.
    측정이 상태를 바꿈.

의미

기대값 \(3.4E_1\)은 한 번의 측정에서는 결코 나오지 않는 값이다. 기대값은 같은 상태를 많이 준비해 잰 결과의 평균이지, 한 번 잰 값의 예측이 아니다. 또 서로 교환하지 않는 양(위치와 에너지)을 차례로 재면 앞의 측정 정보가 지워집니다(3.3절).

검산

확률의 합 1/5 + 4/5 = 1이고, \(\langle E\rangle\)가 \(E_1\)과 \(4E_1\) 사이에서 확률이 큰 \(4E_1\) 쪽에 있다.
