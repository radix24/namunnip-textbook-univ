각운동량의 합성과 클렙시-고르단 계수

본문

수소 원자의 바닥 상태에는 전자 스핀과 양성자 스핀이 있다. 두 스핀이 같은 방향일 때와 반대 방향일 때 에너지가 아주 조금 다른데, 이 차이가 우주 곳곳의 수소 구름에서 오는 21 cm 전파이다. 두 스핀 1/2을 더하면 전체 스핀은 무엇이 될까? 그리고 원자의 궤도 각운동량과 스핀은 어떻게 더할까?

먼저 알아야 할 것사다리 연산자의 작용(5.1절), 스핀 1/2(5.2절)을 쓴다.

5.4.1두 스핀 1/2

두 입자의 상태 공간은 각 공간의 곱이어서 \(2\times2 = 4\)차원이고, 기저는 \(\uparrow\uparrow\), \(\uparrow\downarrow\), \(\downarrow\uparrow\), \(\downarrow\downarrow\)이다. 전체 스핀 \(\hat{\mathbf S} = \hat{\mathbf S}^{(1)} + \hat{\mathbf S}^{(2)}\)의 \(z\)성분은 더하기만 하면 되므로 \(m = 1, 0, 0, -1\)이다. 그런데 \(m = 0\)인 상태가 둘이어서, 전체 \(S^2\)의 고유 상태가 되려면 섞어야 한다.

맨 위 \(\uparrow\uparrow\)은 \(m = 1\)인 유일한 상태이므로 \(s = 1\)이다. 여기에 \(\hat S_- = \hat S_-^{(1)} + \hat S_-^{(2)}\)를 작용하면 \(s = 1\)의 나머지 상태가 나오고, \(m = 0\) 가운데 그것에 직교하는 남은 상태가 \(s = 0\)이다.

결과 5.4.1 \[\text{삼중항 }(s = 1):\ \uparrow\uparrow,\quad \tfrac1{\sqrt2}(\uparrow\downarrow + \downarrow\uparrow),\quad \downarrow\downarrow; \qquad \text{단일항 }(s = 0):\ \tfrac1{\sqrt2}(\uparrow\downarrow - \downarrow\uparrow)\]

\(S^2\)을 직접 작용해 보면 삼중항은 \(2\hbar^2\), 단일항은 0이 나온다. 또 삼중항은 두 입자를 맞바꾸어도 그대로인 대칭 상태이고, 단일항은 부호가 바뀌는 반대칭 상태이다(그림 1). 처음 질문의 첫째 답이 이것이다. 수소 바닥 상태에서 전자와 양성자 스핀의 삼중항과 단일항 사이 에너지 차이가 21 cm 선이다.

5.4.2일반 규칙

두 각운동량을 더하는 일반 규칙은 다음과 같다.

정리 5.4.2

\(j_1\)과 \(j_2\)를 더하면 \(j = j_1 + j_2,\ j_1 + j_2 - 1,\ \dots,\ |j_1 - j_2|\)가 각각 한 번씩 나오고, \(m = m_1 + m_2\)이다.

\[|j\,m\rangle = \sum_{m_1 + m_2 = m}C^{j_1j_2j}_{m_1m_2m}\,|j_1m_1\rangle|j_2m_2\rangle\]

상태 수를 검산하면 \(\sum_{j=|j_1-j_2|}^{j_1+j_2}(2j + 1) = (2j_1 + 1)(2j_2 + 1)\)로 맞는다. 계수 \(C\)를 클렙시-고르단 계수라 하며, 콘든-쇼틀리 관례에 따라 실수로 잡는다.

5.4.3계수 구하기

처음 질문의 둘째 경우, 곧 궤도 \(l = 1\)과 스핀 \(\frac12\)을 더해 보자. 규칙에 따라 \(j = \frac32, \frac12\)이며, 원자 분광의 \(p_{3/2}\), \(p_{1/2}\)이 이것이다. 먼저 맨 위 상태는 \(|\tfrac32\,\tfrac32\rangle = |1\,1\rangle|\!\uparrow\rangle\)이다. 여기에 \(\hat J_- = \hat L_- + \hat S_-\)를 작용하면 왼쪽은 \(\hbar\sqrt3|\tfrac32\,\tfrac12\rangle\), 오른쪽은 \(\hbar\sqrt2|1\,0\rangle|\!\uparrow\rangle + \hbar|1\,1\rangle|\!\downarrow\rangle\)이다. 따라서 다음을 얻는다.

\[|\tfrac32\,\tfrac12\rangle = \sqrt{\tfrac23}|1\,0\rangle|\!\uparrow\rangle + \sqrt{\tfrac13}|1\,1\rangle|\!\downarrow\rangle, \qquad |\tfrac12\,\tfrac12\rangle = -\sqrt{\tfrac13}|1\,0\rangle|\!\uparrow\rangle + \sqrt{\tfrac23}|1\,1\rangle|\!\downarrow\rangle\]

둘째 식은 첫째 식에 직교하는 상태로 정했으며, 전체 부호는 관례이다. 나머지는 \(\hat J_-\)를 계속 작용하거나 대칭으로 얻고, 계수 표는 참고서와 입자물리 자료집에 실려 있다.

예제 5.4.3

전자가 \(|j = \tfrac32, m_j = \tfrac12\rangle\) 상태(\(l = 1\))에 있다. \(S_z\)를 재면 \(+\hbar/2\)가 나올 확률은?

풀이. \(|\!\uparrow\rangle\)이 붙은 항의 계수 제곱이므로 \(2/3\)이고, 이때 \(L_z = 0\)이다. 나머지 확률 \(1/3\)로는 \(S_z = -\hbar/2\), \(L_z = \hbar\)가 나온다. 어느 경우든 \(L_z + S_z = \hbar/2\)이다.

흔한 오해\(\uparrow\downarrow\) 상태가 전체 스핀 0이라고 생각하기 쉽지만, \(\uparrow\downarrow\)은 \(m = 0\)일 뿐 \(S^2\)의 고유 상태가 아니다. 삼중항과 단일항을 반씩 섞은 상태이므로 \(S^2\)을 재면 \(2\hbar^2\)과 0이 반반 나온다.
마무리

두 스핀 1/2의 네 상태는 대칭인 삼중항(\(s = 1\)) 셋과 반대칭인 단일항(\(s = 0\)) 하나로 다시 묶이며, 처음 질문의 21 cm 선이 이 두 묶음의 에너지 차이이다. 일반적으로 \(j_1\)과 \(j_2\)를 더하면 \(|j_1 - j_2|\)부터 \(j_1 + j_2\)까지의 \(j\)가 한 번씩 나오고 \(m = m_1 + m_2\)이다. 클렙시-고르단 계수는 맨 위 상태에서 \(\hat J_-\)로 내려가고 직교 조건으로 다음 \(j\)를 만들어 구한다.

5.4.4연습문제

기본

  1. \(j_1 = 2\)와 \(j_2 = 1\)을 더하면 어떤 \(j\)가 나오고 상태 수는 맞나요?
    답

    \(j = 3, 2, 1\). \(7 + 5 + 3 = 15 = 5\times3\).

  2. 단일항에 \(\hat S_z = \hat S_z^{(1)} + \hat S_z^{(2)}\)를 작용하면?
    답

    각 항의 \(m_1 + m_2 = 0\)이므로 0. \(m = 0\)입니다.

발전

  1. \(\hat{\mathbf S}^{(1)}\cdot\hat{\mathbf S}^{(2)} = \frac12(\hat S^2 - \hat S^{(1)2} - \hat S^{(2)2})\)를 써서 삼중항과 단일항에서 이 값을 구하세요.
    답

    삼중항은 \(\frac12(2 - \frac34 - \frac34)\hbar^2 = \frac14\hbar^2\), 단일항은 \(\frac12(0 - \frac32)\hbar^2 = -\frac34\hbar^2\)이다. 초미세 상호작용 \(\propto\hat{\mathbf S}^{(1)}\cdot\hat{\mathbf S}^{(2)}\)가 두 준위를 \(\hbar^2\)에 비례하는 만큼 가릅니다.
