각운동량의 합성과 클렙시-고르단 계수

본문
이 절에서 배울 것
  • 두 스핀 1/2을 더해 삼중항과 단일항을 만든다.
  • 일반적인 합성 규칙 \(j = |j_1 - j_2|, \dots, j_1 + j_2\)를 안다.
  • 내림 연산자로 클렙시-고르단 계수를 구한다.
먼저 알아야 할 것
  • 사다리 연산자의 작용 (5.1절), 스핀 1/2 (5.2절).

5.3.1두 스핀 1/2

두 입자의 상태 공간은 각 공간의 곱으로 \(2\times2 = 4\)차원입니다. 기저 \(\uparrow\uparrow, \uparrow\downarrow, \downarrow\uparrow, \downarrow\downarrow\). 전체 스핀 \(\hat{\mathbf S} = \hat{\mathbf S}^{(1)} + \hat{\mathbf S}^{(2)}\)의 \(z\)성분은 더하기만 하면 되므로 \(m = 1, 0, 0, -1\). 맨 위 \(\uparrow\uparrow\)에 \(\hat S_- = \hat S_-^{(1)} + \hat S_-^{(2)}\)를 작용하면

결과 5.3.1 \[\text{삼중항 }(s = 1):\ \uparrow\uparrow,\quad \tfrac1{\sqrt2}(\uparrow\downarrow + \downarrow\uparrow),\quad \downarrow\downarrow; \qquad \text{단일항 }(s = 0):\ \tfrac1{\sqrt2}(\uparrow\downarrow - \downarrow\uparrow).\]

단일항은 \(m = 0\) 중 삼중항에 직교한 남은 상태입니다. \(S^2\)을 직접 작용해 \(2\hbar^2\)(삼중항), 0(단일항)을 확인할 수 있습니다. 삼중항은 입자 교환에 대칭, 단일항은 반대칭입니다. 수소 바닥 상태의 초미세 갈라짐(21 cm 선)이 전자와 양성자 스핀의 삼중항과 단일항 사이 에너지 차입니다.

5.3.2일반 규칙

정리 5.3.2

\(j_1\)과 \(j_2\)를 더하면 \(j = j_1 + j_2,\ j_1 + j_2 - 1,\ \dots,\ |j_1 - j_2|\)가 각각 한 번씩 나오고, \(m = m_1 + m_2\)입니다.

\[|j\,m\rangle = \sum_{m_1 + m_2 = m}C^{j_1j_2j}_{m_1m_2m}\,|j_1m_1\rangle|j_2m_2\rangle.\]

상태 수 검산: \(\sum_{j=|j_1-j_2|}^{j_1+j_2}(2j + 1) = (2j_1 + 1)(2j_2 + 1)\). 계수 \(C\)가 클렙시-고르단 계수이며, 관례(콘든-쇼틀리)로 실수로 잡습니다.

5.3.3계수 구하기: \(1\otimes\frac12\)

궤도 \(l = 1\)과 스핀 \(\frac12\)을 더하면 \(j = \frac32, \frac12\)입니다(원자의 \(p_{3/2}\), \(p_{1/2}\)).

  1. 맨 위: \(|\tfrac32\,\tfrac32\rangle = |1\,1\rangle|\!\uparrow\rangle\).
  2. \(\hat J_- = \hat L_- + \hat S_-\)를 작용: 왼쪽 \(\hbar\sqrt3|\tfrac32\,\tfrac12\rangle\), 오른쪽 \(\hbar\sqrt2|1\,0\rangle|\!\uparrow\rangle + \hbar|1\,1\rangle|\!\downarrow\rangle\).
  3. 따라서 \(|\tfrac32\,\tfrac12\rangle = \sqrt{\tfrac23}|1\,0\rangle|\!\uparrow\rangle + \sqrt{\tfrac13}|1\,1\rangle|\!\downarrow\rangle\).
  4. \(j = \frac12\), \(m = \frac12\)은 이것에 직교: \(|\tfrac12\,\tfrac12\rangle = -\sqrt{\tfrac13}|1\,0\rangle|\!\uparrow\rangle + \sqrt{\tfrac23}|1\,1\rangle|\!\downarrow\rangle\) (부호는 관례).

나머지는 계속 \(\hat J_-\)를 작용하거나 대칭으로 얻습니다. 계수 표는 참고서와 입자물리 자료집에 실려 있습니다.

예제 5.3.3

전자가 \(|j = \tfrac32, m_j = \tfrac12\rangle\) 상태(\(l = 1\))에 있습니다. \(S_z\)를 재면 \(+\hbar/2\)가 나올 확률은?

풀이. \(|\!\uparrow\rangle\)이 붙은 항의 계수 제곱: \(2/3\). 이때 \(L_z = 0\)이고, 확률 \(1/3\)로 \(S_z = -\hbar/2\), \(L_z = \hbar\)입니다.

요약
  1. 두 스핀 1/2 = 삼중항(\(s = 1\), 대칭) + 단일항(\(s = 0\), 반대칭).
  2. \(j_1 \otimes j_2 = |j_1 - j_2| \oplus \dots \oplus (j_1 + j_2)\), \(m = m_1 + m_2\).
  3. 맨 위 상태에서 \(\hat J_-\)로 내려가고 직교 조건으로 다음 \(j\)를 만든다.

5.3.4연습문제

기본

  1. \(j_1 = 2\)와 \(j_2 = 1\)을 더하면 어떤 \(j\)가 나오고 상태 수는 맞나요?
    답

    \(j = 3, 2, 1\). \(7 + 5 + 3 = 15 = 5\times3\).

  2. 단일항에 \(\hat S_z = \hat S_z^{(1)} + \hat S_z^{(2)}\)를 작용하면?
    답

    각 항의 \(m_1 + m_2 = 0\)이므로 0. \(m = 0\)입니다.

발전

  1. \(\hat{\mathbf S}^{(1)}\cdot\hat{\mathbf S}^{(2)} = \frac12(\hat S^2 - \hat S^{(1)2} - \hat S^{(2)2})\)를 써서 삼중항과 단일항에서 이 값을 구하세요.
    답

    삼중항: \(\frac12(2 - \frac34 - \frac34)\hbar^2 = \frac14\hbar^2\). 단일항: \(\frac12(0 - \frac32)\hbar^2 = -\frac34\hbar^2\). 초미세 상호작용 \(\propto\hat{\mathbf S}^{(1)}\cdot\hat{\mathbf S}^{(2)}\)가 두 준위를 \(\hbar^2\)에 비례하는 만큼 가릅니다.
