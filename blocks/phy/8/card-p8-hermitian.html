운동량 연산자가 에르미트인 조건

에르미트 연산자 · 경계 조건 · 문제 해결 전략

출발점

연산자 \(\hat Q\)가 에르미트이면 \(\langle f|\hat Qg\rangle = \langle\hat Qf|g\rangle\)이고 고유값이 실수입니다. 미분 연산자는 부분적분에서 나오는 경계 항이 사라져야 에르미트가 됩니다.

문제 해결 전략 · 에르미트성 확인
  1. \(\langle f|\hat Qg\rangle\)를 적분으로 쓴다.
  2. 부분적분으로 미분을 \(f\) 쪽으로 옮긴다.
  3. 경계 항이 0이 되는 조건을 찾는다.
  4. \(i\) 같은 계수의 켤레까지 확인한다.

\(\hat p = -i\hbar\frac d{dx}\)가 \([0, L]\)에서 에르미트인 조건을 구하여라. \(\frac d{dx}\) 자체는 왜 에르미트가 아닌가?

풀이

  1. \(\int_0^Lf^*(-i\hbar g')dx = -i\hbar[f^*g]_0^L + i\hbar\int_0^Lf'^*g\,dx\).
    부분적분.
  2. 둘째 항 \(= \int(-i\hbar f')^*g\,dx = \langle\hat pf|g\rangle\).
    \((-i)^* = i\).
  3. 경계 항 \([f^*g]_0^L = 0\)이어야 한다: 양 끝에서 0이거나 주기 조건.
    물리적 파동함수의 조건.
  4. \(\frac d{dx}\)만이면 둘째 항의 부호가 반대(\(-\langle f'|g\rangle\))라 반에르미트.
    \(i\)가 부호를 고친다.

의미

운동량 연산자에 \(i\)가 붙는 까닭이 바로 이것입니다. \(i\) 덕분에 고유값이 실수가 되어 측정값(실수)과 대응할 수 있습니다.

검산

고유함수 \(e^{ikx}\)(주기 조건)의 고유값 \(\hbar k\)는 실수입니다.
