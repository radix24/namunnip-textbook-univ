슈테른-게를라흐 실험과 연속 측정

본문
이 절에서 배울 것
  • 불균일 자기장에서 자기 모멘트가 받는 힘으로 슈테른-게를라흐 실험의 원리를 설명한다.
  • 연속 슈테른-게를라흐 실험의 결과를 스피너로 계산하고, 교환하지 않는 성분의 측정이 서로의 정보를 지우는 것을 해석한다.
먼저 알아야 할 것
  • 스피너와 파울리 행렬 (5.2절), 측정 가설 (3.2절).

5.3.1장치와 원리

자기 모멘트 \(\boldsymbol\mu = \gamma\mathbf S\)는 불균일 자기장에서 힘 \(F_z = \mu_z\,\partial B_z/\partial z\)를 받습니다(전자는 \(\mu_z = \mp\mu_B\), 보어 마그네톤 \(\mu_B = 9.27\times10^{-24}\) J/T). 고전적으로 모멘트 방향이 아무렇게나면 화면에 연속 띠가 생겨야 하지만, 1922년 은 원자 빔은 두 점으로 갈라졌습니다. \(S_z\)가 \(\pm\hbar/2\) 두 값만 갖는다는 증거입니다(은 원자의 각운동량은 바깥 전자 하나의 스핀).

5.3.2연속 실험

  • z → z: 위만 골라 다시 z로 재면 100% 위. 측정은 반복 가능하다.
  • z → x: 위만 골라 x로 재면 반반. \(\chi_+ = \frac1{\sqrt2}(\chi_+^{(x)} + \chi_-^{(x)})\).
  • z → x → z: x 위만 골라 다시 z로 재면 다시 반반. x 측정이 처음 z 정보를 지웠다.
  • z → n → z: 둘째 장치를 \(z\)축과 \(\Theta\)만큼 기울이면 통과 확률 \(\cos^2(\Theta/2)\)(5.2절).

아래 실습 카드에서 두 장치의 각도를 바꾸며 이 확률을 시뮬레이션할 수 있습니다.

5.3.3측정 이론에 주는 뜻

z → x → z 결과는 \(S_x\)와 \(S_z\)가 교환하지 않기 때문입니다(\([\hat S_x, \hat S_z] = -i\hbar\hat S_y\)). x를 재는 순간 상태가 \(\chi_+^{(x)}\)로 붕괴하고, 이 상태는 z의 두 고유 상태를 같은 크기로 담고 있습니다. 측정 전 입자가 이미 정해진 \(S_x\)와 \(S_z\) 값을 함께 가지고 있었다는 그림으로는 이 결과를 설명할 수 없습니다. 한편 갈라진 두 빔을 측정 없이 다시 합치면 처음 상태가 되살아나는데, 이는 측정(어느 빔인지 기록)이 일어나야 붕괴가 일어난다는 뜻입니다.

요약
  1. \(F_z = \mu_z\,\partial B_z/\partial z\), 두 점으로 갈라짐 → \(S_z = \pm\hbar/2\).
  2. z → x → z: 교환하지 않는 성분의 측정은 앞 정보를 지운다.
  3. 기울인 장치의 통과 확률 \(\cos^2(\Theta/2)\).

5.3.4연습문제

기본

  1. z 위 → x 위만 통과 → z를 잴 때 처음 빔 중 z 아래로 나오는 비율은?
    답

    \(\frac12\times\frac12 = \frac14\). x 필터를 빼면 0인데, 필터를 넣으면 오히려 아래가 생깁니다.

  2. z 위 → 60° 기울인 장치의 위만 통과 → z 위가 나오는 비율은?
    답

    \(\cos^230°\times\cos^230° = 0.75\times0.75 \approx 0.56\).
