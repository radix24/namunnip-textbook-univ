p 궤도 전자를 원뿔 안에서 찾을 확률

구면 조화 함수 · 입체각 적분 · 규격화

출발점

각 부분의 확률 밀도는 \(|Y_l^m|^2\)이고, 입체각 요소 \(d\Omega = \sin\theta\,d\theta\,d\phi\)로 적분한다. \(Y_1^0 = \sqrt{3/4\pi}\cos\theta\), \(Y_1^{\pm1} = \mp\sqrt{3/8\pi}\sin\theta\,e^{\pm i\phi}\)입니다(4.2절).

문제 해결 전략 · \(\phi\) 적분부터
  1. \(|Y|^2\)가 \(\phi\)에 무관하면 \(\phi\) 적분은 \(2\pi\)다.
  2. \(u = \cos\theta\)로 바꿔 \(\theta\) 적분을 한다.
  3. 전체 구면에서 1이 되는지로 검산한다.

(가) \(Y_1^0\)이 규격화되어 있음을 확인하여라. (나) \(Y_1^0\) 상태의 전자를 \(z\)축 둘레 반각 45°인 원뿔(위쪽) 안에서 찾을 확률은? (다) \(Y_1^1\) 상태라면?

풀이

  1. (가) \(\frac3{4\pi}\cdot2\pi\int_{-1}^1u^2du = \frac32\cdot\frac23 = 1\).
    \(u = \cos\theta\).
  2. (나) \(\frac32\int_{1/\sqrt2}^1u^2du = \frac12\left(1 - \frac1{2\sqrt2}\right) = 0.32\).
    \(\theta: 0 \to 45°\)는 \(u: 1 \to 0.707\).
  3. (다) \(\frac3{8\pi}\cdot2\pi\int_{1/\sqrt2}^1(1 - u^2)du = \frac34\left[(1 - 0.707) - \frac{1 - 0.354}{3}\right] = 0.058\).
    \(\sin^2\theta = 1 - u^2\).

의미

\(m = 0\)인 상태는 \(z\)축 쪽으로 몰려 있고(위 원뿔 하나에 32%, 위아래 합쳐 64%), \(m = \pm1\)인 상태는 적도 쪽으로 몰려 있어(위 원뿔에 6%) 같은 \(l\)이라도 \(m\)에 따라 모양이 다르다. 원뿔 넓이는 구면 전체의 15%뿐이라 \(Y_0^0\)이면 15%이다.

검산

\(Y_0^0\)의 경우 확률 \(\frac{1}{4\pi}\cdot2\pi(1 - 0.707) = 0.146\)으로 원뿔의 입체각 비와 같고, \(Y_1^0\)(0.32)은 그보다 크고 \(Y_1^1\)(0.058)은 작아 위 해석과 맞다.
