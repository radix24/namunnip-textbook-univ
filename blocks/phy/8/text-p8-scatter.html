산란 상태와 퍼텐셜 계단

본문

공을 언덕보다 높은 에너지로 굴리면 반드시 언덕을 넘어간다. 그런데 전자를 퍼텐셜 계단의 두 배 에너지로 보내면 일부가 튕겨 나온다. 넘을 수 있는 계단에서 왜 반사가 생길까? 그리고 반사되는 비율은 어떻게 정의하고 계산할까?

먼저 알아야 할 것확률 흐름(1.2절), 경계 조건(2.2절)을 쓴다.

2.4.1산란 상태

\(E\)가 양쪽 무한대의 퍼텐셜보다 크면 \(\psi\)는 규격화되지 않는 진동 함수이다. 이런 해를 산란 상태라 한다. 산란 상태는 그대로는 물리적 상태가 아니지만, 이들을 겹친 파동 묶음은 규격화된다. 그래서 계산은 단색 파동으로 하고, 결과를 묶음의 평균 행동으로 읽는다. 왼쪽에서 들어오는 경우 해는 다음 꼴이다.

\[\psi = \begin{cases}Ae^{ikx} + Be^{-ikx} & (\text{왼쪽})\\ Fe^{ik'x} & (\text{오른쪽})\end{cases}\]

입사, 반사, 투과의 비율은 확률 흐름 \(j = v|\cdot|^2\)의 비로 정한다. 즉 반사율은 \(R = |j_{\text{반사}}|/j_{\text{입사}} = |B|^2/|A|^2\)이고, 투과율은 \(T = j_{\text{투과}}/j_{\text{입사}} = k'|F|^2/(k|A|^2)\)이다. 오른쪽의 속도가 다르므로 \(k'/k\)가 붙으며, 확률 보존으로 \(R + T = 1\)이다.

2.4.2퍼텐셜 계단

\(x < 0\)에서 \(V = 0\), \(x > 0\)에서 \(V = V_0\)인 계단을 보자. \(E > V_0\)이면 \(k = \sqrt{2mE}/\hbar\), \(k' = \sqrt{2m(E - V_0)}/\hbar\)이고, \(x = 0\)에서 \(\psi\)와 \(\psi'\)가 연속이므로 \(A + B = F\), \(k(A - B) = k'F\)이다. 두 식을 풀면 다음 결과를 얻는다.

정리 2.4.1 (계단, \(E > V_0\)) \[R = \left(\frac{k - k'}{k + k'}\right)^2, \qquad T = \frac{4kk'}{(k + k')^2}\]

고전 입자라면 \(E > V_0\)에서 늘 넘어가지만, 파동은 파수가 갑자기 바뀌는 곳에서 일부 반사된다. 처음 질문의 답이 이것이다. 빛이 굴절률이 다른 유리에 들어갈 때 일부 반사되는 것과 같은 현상이다. 사실 공식이 \(k\)와 \(k'\)에 대칭이므로, 아래로 내려가는 계단(\(V_0 < 0\))에서도 반사가 생긴다.

한편 \(E < V_0\)이면 오른쪽 해는 \(Fe^{-\kappa x}\)로 흐름이 0이다. 그래서 \(|B| = |A|\)이고 \(R = 1\)이지만, 파동함수는 여전히 \(1/\kappa\) 깊이로 계단 안에 스며든다. 아래 실습 카드에서 계단의 파동함수와 \(R\), \(T\)를 볼 수 있으며, 폭이 있는 장벽은 2.5절에서 다룬다.

예제 2.4.2

전자가 \(E = 2V_0\)로 계단에 들어온다. 반사율은?

풀이. \(k'/k = \sqrt{(E - V_0)/E} = 1/\sqrt2\)이므로 \(R = \left(\frac{1 - 0.707}{1 + 0.707}\right)^2 \approx 0.0294\)이다. 약 3%가 반사된다(그림 1). 이 값은 전자의 질량이나 \(V_0\)의 크기와 상관없이 \(E/V_0\)로만 정해진다.

흔한 오해투과율을 \(|F|^2/|A|^2\)로 계산하기 쉽지만, 양쪽 속도가 다르면 진폭의 제곱만으로는 확률 흐름을 비교할 수 없다. 예제의 경우 \(|F|^2/|A|^2 = 1.37\)로 1보다 크다. 속도 비 \(k'/k\)를 곱해야 \(T = 0.97\)이 되어 \(R + T = 1\)을 만족한다.
마무리

산란 상태의 반사율과 투과율은 확률 흐름의 비로 정하며, 투과율에는 속도 비 \(k'/k\)가 붙고 \(R + T = 1\)이다. 퍼텐셜 계단에서 \(E > V_0\)이면 \(R = ((k - k')/(k + k'))^2\)으로, 처음 질문처럼 넘을 수 있는 계단에서도 파수가 바뀌는 곳에서 일부가 반사된다. \(E < V_0\)이면 \(R = 1\)이지만 파동함수는 계단 안으로 스며든다.

2.4.3연습문제

기본

  1. 계단에서 \(E = V_0\)에 가까워지면 \(R\)은 어떻게 되나요?
    답

    \(k' \to 0\)이라 \(R \to 1\). \(E < V_0\)인 경우와 이어집니다.

발전

  1. 계단에서 \(T = \frac{k'|F|^2}{k|A|^2}\) 대신 \(|F|^2/|A|^2\)를 쓰면 \(R + T \ne 1\)임을 \(E = 2V_0\)로 확인하세요.
    답

    \(F/A = 2k/(k + k') = 2/(1.707) \approx 1.172\), \(|F/A|^2 \approx 1.373\). \(R + |F/A|^2 \approx 1.40\). \(k'/k = 0.707\)을 곱하면 \(0.971\)로 \(R + T = 1\)입니다.
