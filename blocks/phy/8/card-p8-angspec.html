각운동량 고유값을 대수로 세기

올림·내림 연산자 · 다중도 · 문제 해결 전략

출발점

\([L_i, L_j] = i\hbar\epsilon_{ijk}L_k\)만으로 \(L^2\)의 고유값 \(\ell(\ell + 1)\hbar^2\)와 \(L_z\)의 고유값 \(m\hbar\)(\(m = -\ell, \dots, \ell\))를 얻는다. \(L_\pm = L_x \pm iL_y\)가 \(m\)을 하나씩 올리고 내린다.

문제 해결 전략 · 각운동량 상태 세기
  1. \(\ell\)에서 \(m\)의 범위와 개수 \(2\ell + 1\)을 쓴다.
  2. \(L_\pm|\ell m\rangle = \hbar\sqrt{\ell(\ell + 1) - m(m \pm 1)}|\ell, m \pm 1\rangle\).
  3. 끝(\(m = \pm\ell\))에서 0이 되는지 확인한다.
  4. 벡터 모형으로 각을 해석한다.

\(\ell = 2\) 상태의 \(m\) 값, \(|\mathbf L|\), \(L_z\)가 최대일 때 \(\mathbf L\)과 \(z\)축 사이 최소 각을 구하고, \(L_+|2, 1\rangle\)을 계산하여라.

풀이

  1. \(m = -2, -1, 0, 1, 2\)(5개).
    \(2\ell + 1\).
  2. \(|\mathbf L| = \sqrt6\hbar = 2.45\hbar\).
    \(\sqrt{\ell(\ell + 1)}\).
  3. \(\cos\theta = 2/\sqrt6 = 0.816\), \(\theta = 35.3°\).
    \(\mathbf L\)은 \(z\)축과 나란할 수 없다.
  4. \(L_+|2, 1\rangle = \hbar\sqrt{6 - 2}|2, 2\rangle = 2\hbar|2, 2\rangle\).
    \(m(m + 1) = 2\).

의미

\(L_z\)가 최대여도 \(|\mathbf L|\)보다 작아, 각운동량은 결코 한 축을 정확히 가리키지 못한다. \(L_x\), \(L_y\)가 불확정하기 때문입니다(앞 예제).

검산

\(L_+|2, 2\rangle = \hbar\sqrt{6 - 6} = 0\). 사다리 끝에서 멈춘다.
