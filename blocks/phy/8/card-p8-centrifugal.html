지름 방정식의 원심 장벽

변수 분리 · 유효 퍼텐셜 · 원점 근처 행동 · 문제 해결 전략

출발점

구대칭 퍼텐셜에서 \(\psi = R(r)Y_\ell^m\)이고 \(u = rR\)로 두면 \(-\frac{\hbar^2}{2m}u'' + \left[V + \frac{\hbar^2\ell(\ell + 1)}{2mr^2}\right]u = Eu\)입니다. 1차원 문제와 같고, 둘째 항이 원심 장벽입니다.

문제 해결 전략 · 지름 방정식 다루기
  1. \(u = rR\)로 바꿔 1차원 꼴로 쓴다.
  2. 유효 퍼텐셜을 그려 운동 범위를 본다.
  3. 원점 근처(\(r \to 0\))와 무한대 행동을 따로 구한다.
  4. 경계 조건 \(u(0) = 0\)을 확인한다.

원점 근처에서 \(u \sim r^s\)로 두고 \(s\)를 구하여라. \(\ell = 0\)과 \(\ell = 1\) 상태는 원점에서 찾을 확률이 어떻게 다른가?

풀이

  1. \(r \to 0\)에서 원심 항이 지배: \(u'' \approx \frac{\ell(\ell + 1)}{r^2}u\).
    \(V\)는 \(1/r^2\)보다 약하다고 가정.
  2. \(s(s - 1) = \ell(\ell + 1)\): \(s = \ell + 1\) 또는 \(-\ell\).
    2차 방정식.
  3. \(u(0) = 0\)이어야 하므로 \(s = \ell + 1\), \(R \sim r^\ell\).
    규격화와 \(\nabla^2\)의 조건.
  4. \(\ell = 0\): \(R(0) \ne 0\), 핵 위치에서 확률 밀도가 있다. \(\ell = 1\): \(R \sim r\), 원점에서 0.
    원심 장벽이 밀어낸다.

의미

\(s\) 전자만 핵 안까지 들어가므로, 핵과의 직접 상호작용(초미세 구조, 전자 포획)은 \(s\) 상태에서 크게 나타납니다. 주기율표에서 4s가 3d보다 먼저 차는 침투 효과도 같은 이유입니다(물리3 예제).

검산

수소 2p의 \(R_{21} \propto re^{-r/2a_0}\)는 \(r\)에 비례해 시작합니다. \(s = \ell + 1 = 2\)인 \(u = rR \propto r^2\)과 맞습니다.
