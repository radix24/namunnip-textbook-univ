디랙 표기법

본문
이 절에서 배울 것
  • 켓 \(|\alpha\rangle\), 브라 \(\langle\beta|\), 내적과 외적을 쓴다.
  • 완비 관계 \(\sum|e_n\rangle\langle e_n| = 1\)로 기저를 바꾸고 연산자를 행렬로 나타낸다.
  • 위치 표현과 운동량 표현의 관계를 안다.
먼저 알아야 할 것
  • 힐베르트 공간과 에르미트 연산자 (3.1절), 행렬 곱과 켤레 전치.

3.3.1켓과 브라

상태 벡터를 어떤 기저도 고르지 않고 \(|\mathcal S\rangle\)로 씁니다. 파동함수 \(\Psi(x)\)는 이 벡터의 위치 기저 성분, \(\Phi(p)\)는 운동량 기저 성분입니다.

\[\Psi(x) = \langle x|\mathcal S\rangle, \qquad \Phi(p) = \langle p|\mathcal S\rangle, \qquad c_n = \langle n|\mathcal S\rangle.\]

브라 \(\langle\beta|\)는 켓을 받아 수를 내는 선형 함수입니다. 유한 차원에서 켓이 열벡터이면 브라는 켤레 전치 행벡터입니다.

3.3.2외적과 완비 관계

\(|\alpha\rangle\langle\beta|\)는 켓을 켓으로 보내는 연산자입니다: \((|\alpha\rangle\langle\beta|)|\gamma\rangle = \langle\beta|\gamma\rangle|\alpha\rangle\). 규격화된 \(|e\rangle\)의 \(\hat P = |e\rangle\langle e|\)는 그 방향으로의 투영이고 \(\hat P^2 = \hat P\)입니다.

정리 3.3.1 (완비 관계) \[\sum_n|e_n\rangle\langle e_n| = \hat 1, \qquad \int|x\rangle\langle x|\,dx = \hat 1, \qquad \int|p\rangle\langle p|\,dp = \hat 1.\]

어디에든 1을 끼워 넣을 수 있어 계산이 기계적으로 됩니다. 예를 들어

\[\langle\alpha|\beta\rangle = \sum_n\langle\alpha|e_n\rangle\langle e_n|\beta\rangle = \sum_na_n^*b_n, \qquad \Phi(p) = \int\langle p|x\rangle\langle x|\mathcal S\rangle dx, \quad \langle p|x\rangle = \frac{e^{-ipx/\hbar}}{\sqrt{2\pi\hbar}}.\]

3.3.3연산자의 행렬

기저 \(\{|e_n\rangle\}\)에서 \(Q_{mn} = \langle e_m|\hat Q|e_n\rangle\)라 두면 \(\hat Q|\beta\rangle\)의 성분은 행렬 곱 \(\sum_nQ_{mn}b_n\)입니다. 에르미트 연산자는 에르미트 행렬(\(Q_{nm} = Q_{mn}^*\))이 되고, 고유값 문제는 행렬 대각화가 됩니다.

예제 3.3.2

두 상태계에서 \(\hat H = \begin{pmatrix}h & g\\ g & h\end{pmatrix}\) (\(g > 0\))입니다. \(t = 0\)에 \(|1\rangle = \binom10\)이면 \(t\)에서 \(|2\rangle\)에 있을 확률은?

풀이. 고유값 \(h \pm g\), 고유벡터 \(\frac1{\sqrt2}\binom1{\pm1}\). \(|1\rangle = \frac1{\sqrt2}(|+\rangle + |-\rangle)\)이므로

\[|\mathcal S(t)\rangle = \frac{e^{-iht/\hbar}}{\sqrt2}\left(e^{-igt/\hbar}|+\rangle + e^{igt/\hbar}|-\rangle\right), \qquad P_2(t) = |\langle2|\mathcal S(t)\rangle|^2 = \sin^2\frac{gt}\hbar.\]

계가 두 상태 사이를 오갑니다. 암모니아 분자의 반전, 중성 K 중간자 진동, 중성미자 진동이 같은 구조입니다.

3.3.4위치 표현의 연산자

\(\langle x|\hat x|\mathcal S\rangle = x\Psi(x)\), \(\langle x|\hat p|\mathcal S\rangle = -i\hbar\frac{d}{dx}\Psi(x)\)입니다. 운동량 표현에서는 반대로 \(\hat p \to p\), \(\hat x \to i\hbar\frac{d}{dp}\)입니다. 같은 벡터, 같은 연산자를 다른 기저에서 본 것뿐입니다.

요약
  1. 상태 \(|\mathcal S\rangle\), 파동함수는 성분 \(\langle x|\mathcal S\rangle\).
  2. 완비 관계 \(\sum|e_n\rangle\langle e_n| = 1\)을 끼워 기저를 바꾼다.
  3. 연산자는 행렬 \(\langle e_m|\hat Q|e_n\rangle\), 고유값 문제는 대각화.

3.3.5연습문제

기본

  1. 조화 진동자의 에너지 기저에서 \(\hat a_+\)의 행렬을 왼쪽 위 3×3까지 쓰세요.
    답

    \(\langle m|\hat a_+|n\rangle = \sqrt{n + 1}\,\delta_{m,n+1}\): \(\begin{pmatrix}0&0&0\\1&0&0\\0&\sqrt2&0\end{pmatrix}\). 대각선 바로 아래에만 성분이 있습니다.

  2. \(\hat P = |e\rangle\langle e|\)의 고유값을 구하세요.
    답

    \(\hat P^2 = \hat P\)이므로 \(\lambda^2 = \lambda\), 곧 0 또는 1. \(|e\rangle\)은 고유값 1, 그에 직교한 모든 벡터는 고유값 0.

발전

  1. 예제 3.3.2에서 \(\langle\hat H\rangle\)이 시간에 따라 변하지 않음을 확인하세요.
    답

    \(|c_\pm|^2 = 1/2\)이 일정하므로 \(\langle H\rangle = \frac12(h + g) + \frac12(h - g) = h\). 상태는 오가지만 에너지 분포는 보존됩니다.
