사다리 연산자로 위치 기대값 구하기

생성·소멸 연산자 · 영점 진동 · 문제 해결 전략

출발점

조화 진동자에서 \(\hat x = \sqrt{\frac\hbar{2m\omega}}(\hat a + \hat a^\dagger)\), \(\hat a|n\rangle = \sqrt n|n - 1\rangle\), \(\hat a^\dagger|n\rangle = \sqrt{n + 1}|n + 1\rangle\)이다. 적분 없이 기대값을 계산할 수 있다.

문제 해결 전략 · 사다리 연산자 계산
  1. 물리량을 \(\hat a\), \(\hat a^\dagger\)로 쓴다.
  2. 곱을 전개해 각 항이 \(|n\rangle\)을 어디로 옮기는지 본다.
  3. \(\langle n|m\rangle = \delta_{nm}\)으로 남는 항만 계산한다.
  4. 에너지나 고전 극한으로 점검한다.

\(|n\rangle\) 상태의 \(\langle x\rangle\)와 \(\langle x^2\rangle\)을 구하고, 바닥 상태의 퍼텐셜 에너지 기대값이 전체 에너지의 절반임을 보여라.

풀이

  1. \(\langle x\rangle \propto \langle n|(\hat a + \hat a^\dagger)|n\rangle = 0\).
    \(|n \pm 1\rangle\)은 \(|n\rangle\)과 직교.
  2. \(\hat x^2 \propto \hat a^2 + \hat a\hat a^\dagger + \hat a^\dagger\hat a + \hat a^{\dagger2}\). 대각 항만: \(\langle n|\hat a\hat a^\dagger + \hat a^\dagger\hat a|n\rangle = (n + 1) + n = 2n + 1\).
    \(\hat a^2\)은 두 칸 옮겨 0.
  3. \(\langle x^2\rangle = \frac\hbar{2m\omega}(2n + 1)\).
    결과.
  4. \(n = 0\): \(\langle V\rangle = \frac12m\omega^2\cdot\frac\hbar{2m\omega} = \frac14\hbar\omega = \frac12E_0\).
    비리얼 정리.

의미

바닥 상태에도 위치가 \(\sqrt{\hbar/2m\omega}\)만큼 퍼져 있습니다(영점 진동). 이 때문에 헬륨은 상압에서 절대 0도까지 고체가 되지 않는다.

검산

\(\langle T\rangle = \langle V\rangle = \frac12(n + \frac12)\hbar\omega\), 합은 \(E_n\). 맞다.
