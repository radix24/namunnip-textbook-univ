각 부분: 구면 조화 함수

본문
이 절에서 배울 것
  • 각 방정식을 다시 분리해 \(m\)이 정수이고 \(|m| \le l\)인 까닭을 안다.
  • 구면 조화 함수 \(Y_l^m\)의 정규 직교성, 반전성, 각운동량과의 관계를 쓴다.
먼저 알아야 할 것
  • 변수분리와 지름 방정식 (4.1절), 르장드르 함수 (공통8 4.2절).

4.2.1다시 분리하기

4.1절 정리 4.1.1의 각 방정식에 \(Y = \Theta(\theta)\Phi(\phi)\)를 넣고 \(\sin^2\theta/Y\)를 곱하면 \(\phi\)만의 부분이 갈라져 \(\Phi'' = -m^2\Phi\), 곧 \(\Phi = e^{im\phi}\)입니다. \(\phi\)와 \(\phi + 2\pi\)는 같은 점이므로 \(e^{2\pi im} = 1\), \(m\)은 정수여야 합니다.

\(\Theta\)는 \(x = \cos\theta\)로 쓰면 연관 르장드르 방정식을 따릅니다. 이 방정식의 해는 일반적으로 \(\theta = 0\) 또는 \(\pi\)에서 발산하는데, 양쪽 끝에서 모두 유한하려면 \(l = 0, 1, 2, \dots\)이고 \(|m| \le l\)이어야 합니다. 1차원 우물에서 경계 조건이 에너지를 양자화했듯, 여기서는 구면 위에서 유한하다는 조건이 \(l\)과 \(m\)을 양자화합니다.

4.2.2구면 조화 함수

결과 4.2.1 \[Y_l^m(\theta, \phi) \propto e^{im\phi}P_l^{|m|}(\cos\theta), \qquad \int Y_l^{m*}Y_{l'}^{m'}\,d\Omega = \delta_{ll'}\delta_{mm'}.\]

예: \(Y_0^0 = \frac1{\sqrt{4\pi}}\), \(Y_1^0 = \sqrt{\frac3{4\pi}}\cos\theta\), \(Y_1^{\pm1} = \mp\sqrt{\frac3{8\pi}}\sin\theta\,e^{\pm i\phi}\).

\(d\Omega = \sin\theta\,d\theta\,d\phi\)는 입체각 요소입니다. 서로 다른 \((l, m)\)은 직교하므로, 구면 위의 어떤 함수든 \(Y_l^m\)의 합으로 전개할 수 있습니다(푸리에 급수의 구면판). 원점에 대해 뒤집으면(\(\theta \to \pi - \theta\), \(\phi \to \phi + \pi\)) \(Y_l^m \to (-1)^lY_l^m\)이어서, \(l\)이 짝수인 상태는 짝, 홀수인 상태는 홀 반전성을 가집니다.

4.2.3각운동량과 궤도 모양

5장에서 보듯 \(l\)은 각운동량 크기 \(L^2 = l(l + 1)\hbar^2\), \(m\)은 \(z\)성분 \(L_z = m\hbar\)를 정합니다. 화학의 s, p, d, f 궤도가 \(l = 0, 1, 2, 3\)입니다. s는 공 모양이고, \(p_z \propto Y_1^0 \propto \cos\theta\)는 \(z\)축 방향 두 덩이입니다. 화학에서 쓰는 \(p_x\), \(p_y\)는 \(Y_1^{\pm1}\)을 실수가 되도록 섞은 것(\(\sin\theta\cos\phi\), \(\sin\theta\sin\phi\))입니다.

요약
  1. \(m\)은 정수(한 바퀴 돌아 같은 값), \(l = 0, 1, \dots\), \(|m| \le l\)(양 극에서 유한).
  2. \(Y_l^m\)은 정규 직교, 반전성 \((-1)^l\).
  3. \(L^2 = l(l + 1)\hbar^2\), \(L_z = m\hbar\). s, p, d, f.
