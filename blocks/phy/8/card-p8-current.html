평면파와 가우스 파동 묶음의 확률 흐름

규격화 · 확률 흐름 · 연속 방정식 · 문제 해결 전략

출발점

확률 흐름 \(j = \frac{\hbar}{m}\text{Im}(\psi^*\psi')\)은 확률이 얼마나 빠르게 흘러가는지를 나타내고, 연속 방정식 \(\partial_t|\psi|^2 + \partial_xj = 0\)을 만족합니다. 평면파는 규격화할 수 없지만 흐름은 정의됩니다.

문제 해결 전략 · 확률 흐름 계산
  1. \(\psi\)와 \(\psi'\)를 쓴다.
  2. \(\psi^*\psi'\)의 허수부를 구한다.
  3. \(\hbar/m\)을 곱한다.
  4. \(j = |\psi|^2v\) 꼴(밀도 × 속도)인지 해석한다.

(가) \(\psi = Ae^{ikx}\)의 확률 흐름은? (나) 실수 파동함수(예: 무한 우물 고유 상태)의 흐름은? (다) \(\psi = Ae^{ikx} + Be^{-ikx}\)이면?

풀이

  1. (가) \(\psi^*\psi' = |A|^2ik\), \(j = \frac{\hbar k}m|A|^2\).
    밀도 \(|A|^2\) × 속도 \(\hbar k/m\).
  2. (나) \(\psi\)가 실수면 \(\psi^*\psi'\)도 실수, \(j = 0\).
    정상파: 흐름 없음.
  3. (다) 교차항은 허수부가 지워져 \(j = \frac{\hbar k}m(|A|^2 - |B|^2)\).
    오른쪽 흐름 − 왼쪽 흐름.
  4. 반사율 \(R = |B|^2/|A|^2\)의 근거가 된다(2.3절).
    산란 문제에 쓰임.

의미

확률 흐름 덕분에 계단이나 장벽의 반사율과 투과율을 정의할 수 있습니다. 투과한 쪽은 속도가 달라 \(|C|^2\)만이 아니라 \(k\)까지 곱해 비교해야 합니다.

검산

(가)에서 전자(\(k = 10^{10}\) m⁻¹)의 속도 \(\hbar k/m = 1.16\times10^6\) m/s. de Broglie 관계 \(p = \hbar k\)와 맞습니다.
