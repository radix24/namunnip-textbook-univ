Dirac 표기로 기저 바꾸기: 스핀 측정 확률

브라-켓 · 사영 · 문제 해결 전략

출발점

상태 \(|\psi\rangle\)를 측정해 고유값 \(q_n\)이 나올 확률은 \(|\langle n|\psi\rangle|^2\)이다. 다른 기저로 바꾸는 것은 내적(사영)을 계산하는 일이다.

문제 해결 전략 · 측정 확률
  1. 측정할 물리량의 고유 상태를 같은 기저로 쓴다.
  2. 내적 \(\langle n|\psi\rangle\)을 계산한다(브라는 켤레 전치).
  3. 절댓값 제곱으로 확률, 합이 1인지 확인한다.
  4. 측정 뒤 상태는 그 고유 상태로 바뀐다.

\(|\psi\rangle = \frac1{\sqrt5}(|{\uparrow}\rangle + 2i|{\downarrow}\rangle)\)(\(z\) 기저). \(S_z\), \(S_x\)를 쟀을 때 각 결과의 확률은?

풀이

  1. \(S_z\): \(P_\uparrow = 1/5\), \(P_\downarrow = 4/5\).
    계수의 절댓값 제곱.
  2. \(S_x\) 고유 상태 \(|\pm\rangle = \frac1{\sqrt2}(|{\uparrow}\rangle \pm |{\downarrow}\rangle)\).
    \(z\) 기저로 씀.
  3. \(\langle +|\psi\rangle = \frac1{\sqrt{10}}(1 + 2i)\), \(P_+ = \frac{5}{10} = \frac12\).
    \(|1 + 2i|^2 = 5\).
  4. \(\langle -|\psi\rangle = \frac1{\sqrt{10}}(1 - 2i)\), \(P_- = \frac12\).
    합 1.

의미

같은 상태라도 무엇을 재느냐에 따라 확률이 다르다. 여기서는 위상 \(i\) 때문에 \(S_x\) 결과가 반반이 되는데, 이 상태는 \(S_y\) 쪽으로 기울어 있다. 위상은 직접 보이지 않지만 다른 측정의 확률을 바꾼다.

검산

\(\langle S_x\rangle = \frac\hbar2(P_+ - P_-) = 0\), \(\langle S_y\rangle = \hbar\,\text{Im}(\psi_\uparrow^*\psi_\downarrow) = \hbar\cdot\frac25 = 0.4\hbar\), \(\langle S_z\rangle = \frac\hbar2(\frac15 - \frac45) = -0.3\hbar\). \(0^2 + 0.4^2 + 0.3^2 = 0.25 = (1/2)^2\): 순수 상태의 스핀 벡터 길이와 맞다.
