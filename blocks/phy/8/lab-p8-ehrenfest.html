자유 파동 묶음의 이동과 퍼짐

실습 · Ehrenfest 정리

목표

처음 폭과 운동량을 바꾸며 자유 입자 파동 묶음이 시간에 따라 어떻게 움직이고 퍼지는지 봅니다. 기대값 \(\langle x\rangle\)이 고전 입자처럼 등속으로 움직인다는 Ehrenfest 정리와, 폭이 넓어지는 양자적 효과를 함께 확인합니다. 성취기준 [물리8-01-03].

준비

단위는 \(\hbar = m = 1\)입니다. 파랑이 지금의 \(|\Psi|^2\), 회색 점선이 처음(\(t = 0\))의 \(|\Psi|^2\), 옅은 선이 \(\text{Re}\,\Psi\)입니다. 빨간 점은 같은 운동량으로 출발한 고전 입자의 위치입니다.

절차

  1. 처음 설정(σ₀ = 1, k₀ = 2)에서 t를 0, 4, 8로 바꾸며 ⟨x⟩, Δx, Δx·Δp를 적는다.
  2. σ₀를 0.5와 3으로 바꿔 t = 4에서의 Δx를 비교한다.
  3. k₀ = 0으로 두고 t를 늘려, 묶음이 제자리에서 퍼지기만 하는지 본다.

기대 결과

  • t = 0: ⟨x⟩ = 0, Δx = 1.000, Δx·Δp = 0.500. t = 4: ⟨x⟩ = 8.000(고전 입자와 같음), Δx = 2.236, Δx·Δp = 1.118. t = 8: ⟨x⟩ = 16.000, Δx = 4.123.
  • t = 4에서 σ₀ = 0.5이면 Δx = 4.031(처음 폭의 8배), σ₀ = 3이면 Δx = 3.073(거의 그대로). 좁게 출발할수록 빨리 퍼진다.
  • k₀ = 0, t = 8: ⟨x⟩ = 0에 머물고 Δx = 4.123으로 제자리에서 퍼지기만 한다.

분석

  1. 폭이 좁게 출발한 묶음일수록 더 빨리 퍼지는 까닭을 불확정성 원리로 설명해 보세요.
  2. ⟨x⟩가 고전 궤도와 정확히 같은 것은 자유 입자라서입니다. 힘이 위치에 따라 바뀌면 Ehrenfest 정리 \(m\frac{d\langle x\rangle}{dt} = \langle p\rangle\), \(\frac{d\langle p\rangle}{dt} = \langle F\rangle\)에서 무엇이 달라질까요?

더 해 보기

전자(\(m = 9.1\times10^{-31}\) kg)의 처음 폭이 1 nm이면 폭이 두 배가 되는 데 얼마나 걸리는지 \(t = 2\sqrt3\,m\sigma_0^2/\hbar\)로 어림해 보세요. 먼지 알갱이(\(10^{-15}\) kg, 1 μm)와 비교해 보세요.
