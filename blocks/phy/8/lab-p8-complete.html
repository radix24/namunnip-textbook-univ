고유함수로 함수 전개하기

실습 · 완비성

목표

무한 우물의 고유함수 \(\psi_n = \sqrt2\sin(n\pi x)\)로 여러 모양의 함수를 전개하고, 항을 늘릴수록 부분합이 원래 함수에 다가가는 것을 봅니다. 계수 제곱의 합 \(\sum|c_n|^2\)이 1로 다가간다는 완비성과, 모서리가 있는 함수일수록 많은 항이 필요하다는 것을 확인합니다. 성취기준 [물리8-03-01].

준비

고른 함수는 \(\int_0^1|\psi|^2dx = 1\)로 규격화합니다. 계수는 \(c_n = \int_0^1\psi_n\psi\,dx\)를 수치로 계산합니다. 위 그림의 회색 점선이 원래 함수, 파랑이 \(N\)항까지의 부분합이고, 아래 막대가 \(|c_n|^2\)(더한 항은 파랑)입니다.

절차

  1. 포물선에서 N = 1, 3일 때 Σ|cₙ|²과 남은 오차를 적는다.
  2. 삼각형으로 바꿔 N = 1, 5의 값을 적고 짝수 n의 계수가 0인 까닭을 생각한다.
  3. 왼쪽 절반 상자에서 N = 5, 40의 Σ|cₙ|²을 적고 불연속점 근처의 출렁임을 본다.

기대 결과

  • 포물선: N = 1에서 c₁ = 0.9993, Σ|cₙ|² = 0.99856, 오차 1.44×10⁻³. N = 3에서 0.99992, 오차 7.52×10⁻⁵.
  • 삼각형: N = 1에서 0.98553, N = 5에서 0.99928. 함수가 가운데에 대해 대칭이라 c₂ = 0처럼 짝수 n의 계수가 모두 0이다.
  • 왼쪽 절반 상자: N = 5에서 0.87181, N = 40에서도 0.98482(오차 1.52×10⁻²). 불연속점 근처에 출렁임이 남는다.

분석

  1. 포물선은 한 항만으로도 거의 맞는데 상자 모양은 40항으로도 부족한 까닭을 함수의 매끄러움으로 설명해 보세요.
  2. \(|c_n|^2\)은 이 상태에서 에너지를 쟀을 때 \(E_n\)이 나올 확률입니다. 합이 1이어야 하는 까닭을 측정의 뜻으로 말해 보세요(3.2절).

더 해 보기

포물선 상태의 평균 에너지 \(\sum|c_n|^2n^2E_1\)을 출력 계수로 어림하고, \(\langle\hat H\rangle = -\frac{\hbar^2}{2m}\int\psi\psi''dx\)로 직접 계산한 값 \(\frac{10}{\pi^2}E_1 \approx 1.0132E_1\)과 비교해 보세요.
