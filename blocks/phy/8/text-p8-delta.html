먼저 알아야 할 것
  • 디랙 델타 함수 (공통8 5.4절), 유한 우물 (앞 카드).

2.2.4\(\psi'\)의 끊김

\(V(x) = -\alpha\delta(x)\) (\(\alpha > 0\))는 아주 좁고 깊은 우물의 극한입니다. 시간 무관 방정식을 \(-\epsilon\)부터 \(\epsilon\)까지 적분하면

\[-\frac{\hbar^2}{2m}\left[\psi'(\epsilon) - \psi'(-\epsilon)\right] - \alpha\psi(0) = E\int_{-\epsilon}^{\epsilon}\psi\,dx \to 0.\]
정리 2.2.3 \[\Delta\psi'\big|_{x=0} = -\frac{2m\alpha}{\hbar^2}\psi(0), \qquad \psi\text{는 연속.}\]

2.2.5속박 상태

\(x \ne 0\)에서는 자유 입자이므로 \(E < 0\)이면 \(\psi = Be^{-\kappa|x|}\) (\(\kappa = \sqrt{-2mE}/\hbar\)). 연속 조건은 저절로 맞고, 기울기는 왼쪽의 \(B\kappa\)에서 오른쪽의 \(-B\kappa\)로 \(-2B\kappa\)만큼 끊깁니다. 정리 2.2.3과 맞추면 \(\kappa = m\alpha/\hbar^2\).

결과 2.2.4 \[\psi(x) = \sqrt\kappa\,e^{-\kappa|x|}, \qquad \kappa = \frac{m\alpha}{\hbar^2}, \qquad E = -\frac{m\alpha^2}{2\hbar^2}.\]

속박 상태는 \(\alpha\)의 크기와 상관없이 정확히 하나입니다.

유한 우물에서 폭 \(2a \to 0\), 깊이 \(V_0 \to \infty\)이며 \(2aV_0 = \alpha\)로 유지하면 \(z_0^2 = 2ma^2V_0/\hbar^2 \to 0\)이라 짝 상태 하나만 남고, 그 에너지가 위 값으로 갑니다.

2.2.6산란 상태 미리 보기

\(E > 0\)이면 왼쪽에서 들어오는 파동 \(Ae^{ikx}\)이 일부 반사되고 일부 투과합니다. 같은 끊김 조건으로 풀면

\[T = \frac1{1 + \beta^2}, \qquad R = \frac{\beta^2}{1 + \beta^2}, \qquad \beta = \frac{m\alpha}{\hbar^2k}.\]

\(\alpha\)의 부호가 바뀌어도(델타 장벽) \(T\)는 같습니다. 에너지가 높을수록 \(\beta\)가 작아 잘 투과합니다. 반사율과 투과율의 정의는 다음 절에서 다룹니다.

예제 2.2.5

델타 우물의 바닥 상태에서 \(|x| > 1/\kappa\)에서 입자를 찾을 확률은?

풀이. \(2\kappa\int_{1/\kappa}^\infty e^{-2\kappa x}dx = e^{-2} \approx 0.135\).

요약
  1. 델타 퍼텐셜에서 \(\psi'\)는 \(-\frac{2m\alpha}{\hbar^2}\psi(0)\)만큼 끊긴다.
  2. 델타 우물의 속박 상태는 하나: \(E = -m\alpha^2/2\hbar^2\).
  3. 산란: \(T = 1/(1 + \beta^2)\), \(\beta = m\alpha/\hbar^2k\).

2.2.7연습문제

기본

  1. 델타 우물 바닥 상태의 \(\sigma_x\)를 구하세요(1.3절 예제 이용).
    답

    \(\langle x\rangle = 0\), \(\langle x^2\rangle = 1/(2\kappa^2)\)이므로 \(\sigma_x = 1/(\sqrt2\kappa) = \hbar^2/(\sqrt2m\alpha)\).

  2. 델타 산란에서 \(T = 1/2\)이 되는 에너지는?
    답

    \(\beta = 1\), \(k = m\alpha/\hbar^2\), \(E = \hbar^2k^2/2m = m\alpha^2/(2\hbar^2)\). 속박 에너지의 크기와 같습니다.

발전

  1. \(V = -\alpha[\delta(x + a) + \delta(x - a)]\)의 짝 속박 상태 조건을 구하세요.
    답

    \(|x| < a\)에서 \(\cosh\kappa x\), 밖에서 \(e^{-\kappa|x|}\). \(x = a\)의 끊김 조건에서 \(\kappa(1 + \tanh\kappa a) = 2m\alpha/\hbar^2\). 이원자 분자 모형의 결합 궤도에 해당합니다.
