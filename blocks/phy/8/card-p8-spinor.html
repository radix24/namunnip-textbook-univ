비스듬히 준비한 스핀의 측정 확률과 기대값

스피너 · 파울리 행렬 · 기대값

출발점

\(\hat n = (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta)\) 방향 위 상태는 \(\chi = (\cos\frac\theta2, e^{i\phi}\sin\frac\theta2)^{\mathsf T}\)이고, \(\hat{\mathbf S} = \frac\hbar2\boldsymbol\sigma\)입니다(5.2절).

문제 해결 전략 · 스피너를 쓰고 행렬로 계산
  1. 주어진 방향으로 스피너를 쓴다.
  2. 기저 성분의 절댓값 제곱으로 \(S_z\) 확률을 구한다.
  3. \(\chi^\dagger\sigma_i\chi\)로 각 성분의 기대값을 구한다.

스핀을 \(xz\)평면에서 \(z\)축과 60°를 이루는 방향 위로 준비했다. (가) 스피너는? (나) \(S_z\)를 재면 위가 나올 확률은? (다) \(\langle S_x\rangle\), \(\langle S_y\rangle\), \(\langle S_z\rangle\)는?

풀이

  1. (가) \(\theta = 60°\), \(\phi = 0\): \(\chi = (\cos30°, \sin30°)^{\mathsf T} = (0.866, 0.5)^{\mathsf T}\).
    반각.
  2. (나) \(\cos^230° = 0.75\).
    결과 5.2.2와 같음.
  3. (다) \(\langle\sigma_x\rangle = 2(0.866)(0.5) = 0.866\), \(\langle\sigma_y\rangle = 0\), \(\langle\sigma_z\rangle = 0.75 - 0.25 = 0.5\). 곧 \(\langle\mathbf S\rangle = \frac\hbar2(0.866, 0, 0.5)\).
    실수 성분이면 \(\langle\sigma_y\rangle = 0\).

의미

기대값 벡터는 준비한 방향 \(\hat n = (\sin60°, 0, \cos60°)\)을 가리키고 크기는 \(\hbar/2\)이다. 스핀 1/2의 순수 상태는 늘 어떤 방향 위 상태이고, 그 방향을 블로흐 구 위의 점으로 나타낸다. 하지만 한 번 재면 언제나 \(\pm\hbar/2\) 중 하나만 나온다.

검산

확률 0.75, 0.25에서 \(\langle S_z\rangle = \frac\hbar2(0.75 - 0.25) = 0.25\hbar\)로 (다)의 \(z\)성분과 같다.
