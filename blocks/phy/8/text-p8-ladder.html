사다리 연산자로 푸는 조화 진동자

본문

조화 진동자의 에너지가 \((n + \frac12)\hbar\omega\)라는 것은 미분방정식을 급수로 풀어 얻을 수 있다. 그런데 미분방정식을 전혀 풀지 않고, 연산자를 곱하고 빼는 대수만으로 이 준위를 모두 얻는 방법이 있다. 어떻게 가능할까? 그리고 가장 낮은 에너지가 0이 아니라 \(\frac12\hbar\omega\)인 까닭은 무엇일까?

먼저 알아야 할 것조화 진동자의 결과(물리3 4.4절), 기대값과 연산자(1.3절)를 쓴다.

2.6.1교환자

두 연산자의 교환자는 \([\hat A, \hat B] = \hat A\hat B - \hat B\hat A\)이다. 연산자는 곱하는 순서에 따라 결과가 다를 수 있으며, 교환자가 그 차이를 잰다. 임의의 함수 \(f\)에 작용시켜 보면 \([\hat x, \hat p]f = -i\hbar xf' + i\hbar(xf)' = i\hbar f\)이므로 다음을 얻는다.

\[[\hat x, \hat p] = i\hbar\]

이것이 양자역학의 가장 기본적인 관계이며, 불확정성 원리(3.3절)의 뿌리이다.

2.6.2올림과 내림 연산자

해밀토니언 \(\hat H = \frac1{2m}[\hat p^2 + (m\omega\hat x)^2]\)를 \(u^2 + v^2 = (u - iv)(u + iv)\)처럼 인수분해하려는 생각에서 다음 두 연산자를 정의한다.

\[\hat a_\pm = \frac1{\sqrt{2\hbar m\omega}}\left(\mp i\hat p + m\omega\hat x\right)\]

그런데 \(\hat x\)와 \(\hat p\)가 교환하지 않으므로, 곱을 계산하면 교환자에서 덤이 붙는다.

정리 2.6.1 \[[\hat a_-, \hat a_+] = 1, \qquad \hat H = \hbar\omega\left(\hat a_+\hat a_- + \tfrac12\right), \qquad [\hat H, \hat a_\pm] = \pm\hbar\omega\,\hat a_\pm\]

마지막 식에서 \(\hat H\psi = E\psi\)이면 \(\hat H(\hat a_\pm\psi) = (E \pm \hbar\omega)(\hat a_\pm\psi)\)이다. 즉 \(\hat a_+\)는 에너지를 \(\hbar\omega\) 올리고 \(\hat a_-\)는 내리므로, 각각 올림 연산자와 내림 연산자라 한다(그림 1).

2.6.3바닥 상태와 사다리

내림을 계속하면 언젠가 에너지가 음이 되는데, 조화 진동자에서는 \(\langle H\rangle \ge 0\)이므로 어딘가에서 멈춰야 한다. 맨 아래 상태 \(\psi_0\)는 \(\hat a_-\psi_0 = 0\)을 만족한다. 이것은 1계 미분방정식이어서 바로 풀린다.

\[\frac1{\sqrt{2\hbar m\omega}}\left(\hbar\frac{d}{dx} + m\omega x\right)\psi_0 = 0 \;\Rightarrow\; \psi_0(x) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4}e^{-m\omega x^2/2\hbar}\]

그러면 \(\hat H\psi_0 = \hbar\omega(0 + \frac12)\psi_0\)이므로 \(E_0 = \frac12\hbar\omega\)이다. 처음 질문의 둘째 답이 이것이다. 정리 2.6.1의 \(\frac12\)은 \(\hat x\)와 \(\hat p\)가 교환하지 않아 생긴 덤이며, 위치와 운동량을 동시에 0으로 만들 수 없다는 사실의 표현이다. 이제 위로 올리면 모든 준위를 얻는다.

정리 2.6.2 \[E_n = \left(n + \tfrac12\right)\hbar\omega, \qquad \psi_n = \frac1{\sqrt{n!}}(\hat a_+)^n\psi_0, \qquad \hat a_+\psi_n = \sqrt{n + 1}\,\psi_{n+1}, \quad \hat a_-\psi_n = \sqrt n\,\psi_{n-1}\]

\(\hat a_+\hat a_-\psi_n = n\psi_n\)이므로 \(\hat N = \hat a_+\hat a_-\)를 개수 연산자라 부른다. 이렇게 미분방정식을 풀지 않고 준위를 모두 얻었다. 처음 질문의 첫째 답이다. 같은 방법이 각운동량(5.1절)과 장의 양자화, 곧 광자와 포논에 그대로 쓰인다.

예제 2.6.3

\(\psi_n\)에서 \(\langle x^2\rangle\)과 \(\langle V\rangle\)을 구하여라.

풀이. \(\hat x = \sqrt{\frac\hbar{2m\omega}}(\hat a_+ + \hat a_-)\)이다. \(\hat x^2\)에서 \(\hat a_+^2\), \(\hat a_-^2\) 항은 직교성 때문에 기대값이 0이고, \(\hat a_+\hat a_- + \hat a_-\hat a_+ = 2\hat N + 1\)이 남는다. 따라서 \(\langle x^2\rangle = \frac\hbar{2m\omega}(2n + 1)\)이고 \(\langle V\rangle = \frac12m\omega^2\langle x^2\rangle = \frac12(n + \frac12)\hbar\omega = \frac12E_n\)이다. 운동 에너지와 퍼텐셜 에너지가 반씩이며, 이것을 비리얼 정리라 한다.

흔한 오해\(\hat a_+\)를 작용하면 규격화된 상태가 그대로 다음 상태가 된다고 생각하기 쉽지만, \(\hat a_+\psi_n = \sqrt{n + 1}\,\psi_{n+1}\)처럼 계수가 붙는다. 그래서 \(\psi_n\)을 만들 때 \(1/\sqrt{n!}\)로 나누어야 규격화가 유지된다. 또 \(\hat a_\pm\)는 에르미트가 아니어서 관측 가능량이 아니다.
마무리

위치와 운동량의 교환자는 \([\hat x, \hat p] = i\hbar\)이고, 이것에서 \([\hat a_-, \hat a_+] = 1\), \(\hat H = \hbar\omega(\hat N + \frac12)\)이 나온다. 처음 질문처럼 올림과 내림 연산자만으로 \(E_n = (n + \frac12)\hbar\omega\)를 모두 얻으며, 바닥 에너지 \(\frac12\hbar\omega\)는 \(\hat x\)와 \(\hat p\)가 교환하지 않아 생긴다. 바닥 상태는 \(\hat a_-\psi_0 = 0\)에서 가우스 함수로 나오고, 들뜬 상태는 \(\hat a_+\)를 거듭 작용해 만든다.

2.6.4연습문제

기본

  1. \(\psi_1 = \hat a_+\psi_0\)를 계산해 \(\psi_1 \propto x\,e^{-m\omega x^2/2\hbar}\)임을 보이세요.
    답

    \(\hat a_+ = \frac1{\sqrt{2\hbar m\omega}}\left(-\hbar\frac d{dx} + m\omega x\right)\). \(\psi_0' = -\frac{m\omega x}{\hbar}\psi_0\)이므로 \(\hat a_+\psi_0 = \frac{2m\omega x}{\sqrt{2\hbar m\omega}}\psi_0 = \sqrt{\frac{2m\omega}\hbar}\,x\psi_0\).

  2. 바닥 상태에서 \(\sigma_x\sigma_p\)를 구하세요.
    답

    \(\langle x^2\rangle = \hbar/2m\omega\), 같은 방법으로 \(\langle p^2\rangle = m\hbar\omega/2\). \(\sigma_x\sigma_p = \hbar/2\), 최솟값입니다.

발전

  1. \(\hat a_-\)의 고유상태 \(\hat a_-|\alpha\rangle = \alpha|\alpha\rangle\) (결맞음 상태)를 \(\psi_n\)으로 전개하세요.
    답

    \(c_n = e^{-|\alpha|^2/2}\alpha^n/\sqrt{n!}\). \(|c_n|^2\)은 평균 \(|\alpha|^2\)인 푸아송 분포이고, 이 상태의 \(\langle x\rangle\)은 고전 진동자처럼 진동하며 모양이 퍼지지 않습니다.
