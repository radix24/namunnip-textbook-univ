델타 우물에 붙잡힌 전자

델타 퍼텐셜 · 속박 에너지 · 산란 · 문제 해결 전략

출발점

\(V = -\alpha\delta(x)\)의 속박 상태는 하나뿐이고 \(\kappa = m\alpha/\hbar^2\), \(E = -m\alpha^2/2\hbar^2\)이다. 산란 투과율은 \(T = 1/(1 + \beta^2)\), \(\beta = m\alpha/\hbar^2k\)입니다(2.3절). 계산에는 \(mc^2 = 0.511\) MeV, \(\hbar c = 197.3\) eV·nm가 편하다.

문제 해결 전략 · 자연 단위로 바꿔 계산하기
  1. \(\hbar^2/m = (\hbar c)^2/mc^2\)로 바꾼다.
  2. \(\kappa\), \(E\), 크기 \(1/\kappa\)를 구한다.
  3. 산란 에너지에서 \(\beta\)와 \(T\)를 구한다.

세기 \(\alpha = 0.10\) eV·nm인 델타 우물에 전자가 있다. (가) 속박 에너지와 파동함수가 \(1/e\)로 줄어드는 거리는? (나) 에너지 \(+0.066\) eV로 들어오는 전자의 투과율은? (다) \(+1.0\) eV이면?

풀이

  1. (가) \(\kappa = \frac{mc^2\alpha}{(\hbar c)^2} = \frac{511\,000\times0.10}{38\,930} = 1.31\) nm⁻¹, \(1/\kappa = 0.76\) nm. \(E = -\frac{\hbar^2\kappa^2}{2m} = -\frac{38\,930\times1.72}{2\times511\,000} = -0.066\) eV.
    \((\hbar c)^2 = 38\,930\) eV²·nm².
  2. (나) 속박 에너지와 크기가 같으므로 \(k = \kappa\), \(\beta = 1\), \(T = 1/2\).
    2.3절 연습문제의 결과.
  3. (다) \(k = \sqrt{2mc^2E}/\hbar c = \sqrt{1.022\times10^6}/197.3 = 5.12\) nm⁻¹, \(\beta = 1.31/5.12 = 0.256\), \(T = 1/1.066 = 0.94\).
    에너지가 크면 잘 투과.

의미

델타 우물은 아무리 약해도 속박 상태를 하나 가지며(1차원의 특징), 그 크기 \(1/\kappa\)는 우물이 약할수록 커진다. 같은 세기가 산란에서는 \(E\)가 속박 에너지 크기와 비슷할 때 반사를 크게 만들어, 속박과 산란이 같은 매개변수 하나로 이어져 있음을 보여 준다.

검산

\(1/\kappa = 0.76\) nm는 원자 크기의 몇 배라 얕게 묶인 상태다운 크기이다. \(\alpha\)를 두 배로 하면 \(E\)는 네 배, 크기는 절반이 되어야 하는데, 식 \(E \propto \alpha^2\), \(1/\kappa \propto 1/\alpha\)가 그렇다.
