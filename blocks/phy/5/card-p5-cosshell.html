표면 전위가 \(V_0\cos\theta\)인 구

구면 변수분리 · 안팎 이어 붙이기 · 문제 해결 전략

출발점

반지름 \(R\)인 얇은 구 껍질의 전위가 \(V(R, \theta) = V_0\cos\theta\)로 정해져 있고, 안팎에 다른 전하는 없습니다. 안쪽은 \(r^\ell\) 항만, 바깥은 \(r^{-(\ell+1)}\) 항만 남습니다(4.4절).

문제 해결 전략 · 영역마다 일반해, 경계에서 계수 비교
  1. 안과 밖의 일반해에서 발산하는 항을 지운다.
  2. 경계 조건을 르장드르 다항식으로 쓰고 같은 \(\ell\)끼리 계수를 비교한다.
  3. 전위의 법선 미분 차이로 표면 전하 밀도를 구한다(2.5절).

구 안팎의 전위와 껍질의 표면 전하 밀도 \(\sigma(\theta)\)를 구하여라. 구 안의 전기장은 어떤 모양인가?

풀이

  1. \(V_0\cos\theta = V_0P_1\)이므로 \(\ell = 1\)만 남는다. 안: \(A_1R = V_0\), 밖: \(B_1/R^2 = V_0\).
    직교성으로 다른 \(\ell\)은 0.
  2. \(V_{\text{안}} = V_0\frac rR\cos\theta = \frac{V_0}{R}z\), \(V_{\text{밖}} = V_0\frac{R^2}{r^2}\cos\theta\).
    \(r\cos\theta = z\).
  3. \(\sigma = -\varepsilon_0\left(\frac{\partial V_{\text{밖}}}{\partial r} - \frac{\partial V_{\text{안}}}{\partial r}\right)_R = -\varepsilon_0\left(-\frac{2V_0}{R} - \frac{V_0}{R}\right)\cos\theta = \frac{3\varepsilon_0V_0}{R}\cos\theta\).
    경계 조건.
  4. 안: \(\mathbf E = -\nabla V = -\frac{V_0}{R}\hat{\mathbf z}\), 균일한 장.
    \(V\)가 \(z\)에 비례.

의미

표면 전하가 \(\cos\theta\)에 비례하면 안쪽 장은 균일하고 바깥 장은 순수한 쌍극자 장입니다. 균일하게 분극된 공(5.1절)의 속박 전하가 바로 이 꼴이어서 같은 결과가 나오고, 균일한 장 속 도체 구(예제 4.4.1)의 유도 전하도 이 꼴입니다.

검산

\(r = R\)에서 두 식이 모두 \(V_0\cos\theta\)로 연속입니다. 바깥 전위를 쌍극자 꼴 \(\frac{p\cos\theta}{4\pi\varepsilon_0r^2}\)과 비교하면 \(p = 4\pi\varepsilon_0R^2V_0\)이고, \(\sigma\)로 직접 \(p = \int z\sigma\,da = \frac{3\varepsilon_0V_0}{R}R^3\cdot2\pi\int_0^\pi\cos^2\theta\sin\theta\,d\theta = 4\pi\varepsilon_0R^2V_0\)으로 같습니다.
