4.3.1직교 좌표

홈통 문제: \(y = 0\), \(y = a\)인 두 접지 판 사이(\(x > 0\))에서, \(x = 0\) 면의 전위가 \(V_0(y)\)로 주어졌습니다. \(V = X(x)Y(y)\)로 두면 \(\frac{X''}{X} + \frac{Y''}{Y} = 0\)이고, 각 항이 상수여야 하므로 \(X'' = k^2X\), \(Y'' = -k^2Y\)입니다.

  • \(Y(0) = Y(a) = 0\)에서 \(Y = \sin(n\pi y/a)\), \(k = n\pi/a\).
  • \(x \to \infty\)에서 \(V \to 0\)이므로 \(X = e^{-kx}\).
\[V(x, y) = \sum_{n=1}^\infty C_ne^{-n\pi x/a}\sin\frac{n\pi y}{a}, \qquad C_n = \frac2a\int_0^aV_0(y)\sin\frac{n\pi y}{a}\,dy.\]

\(V_0\)가 상수이면 \(C_n = \frac{4V_0}{n\pi}\) (\(n\) 홀수), 짝수는 0입니다. 높은 \(n\) 항은 \(x\)가 커지면 빨리 사라지므로, 멀리서는 첫 항이 거의 전부입니다. 상자 안 문제(\(x\)도 유한)이면 \(e^{-kx}\) 대신 \(\sinh\)를 씁니다. 아래 실습 카드에서 이 급수해를 완화법 수치해와 비교할 수 있습니다.

4.3.2구면 좌표 (축대칭)

\(V\)가 \(\phi\)에 무관하면 \(V = R(r)\Theta(\theta)\)로 분리해

\[V(r, \theta) = \sum_{\ell=0}^\infty\left(A_\ell r^\ell + \frac{B_\ell}{r^{\ell+1}}\right)P_\ell(\cos\theta),\]

\(P_0 = 1\), \(P_1 = \cos\theta\), \(P_2 = \frac12(3\cos^2\theta - 1)\)은 르장드르 다항식입니다.

예제 4.3.1

균일한 전기장 \(E_0\hat{\mathbf z}\) 속에 놓인 전하 없는 도체 구(반지름 \(R\))의 바깥 전위는?

풀이. 멀리서 \(V \to -E_0r\cos\theta\)(구의 전위를 0으로). 이 조건으로 \(A_1 = -E_0\), 나머지 \(A_\ell = 0\). 구면에서 \(V = 0\)이 모든 \(\theta\)에 대해 성립하려면 \(B_1 = E_0R^3\), 나머지 0. 그러므로

\[V = -E_0\left(r - \frac{R^3}{r^2}\right)\cos\theta, \qquad \sigma = -\varepsilon_0\frac{\partial V}{\partial r}\Big|_R = 3\varepsilon_0E_0\cos\theta.\]

구에 유도된 전하가 쌍극자(\(B_1\) 항)를 만들어 바깥 장을 휘게 합니다.

요약
  1. 직교: \(e^{\pm kx}\sin ky\) 등, 계수는 푸리에 급수로.
  2. 구면 축대칭: \(\sum(A_\ell r^\ell + B_\ell r^{-\ell-1})P_\ell(\cos\theta)\), 경계에서 계수 비교.
