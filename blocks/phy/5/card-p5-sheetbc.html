면전하 양쪽의 장: 경계 조건 맞추기

수직 성분의 불연속 · 접선 성분의 연속 · 문제 해결 전략

출발점

면전하 \(\sigma\)를 지나면 장의 수직 성분이 \(\sigma/\varepsilon_0\)만큼 뛰고 접선 성분은 이어집니다: \(E^{\perp}_{\text{위}} - E^{\perp}_{\text{아래}} = \sigma/\varepsilon_0\), \(\mathbf E^{\parallel}\) 연속.

문제 해결 전략 · 경계 조건
  1. 면의 법선 방향(아래 → 위)을 정한다.
  2. 한쪽 장을 성분으로 나눈다.
  3. 수직 성분에 \(\sigma/\varepsilon_0\)를 더하고 접선 성분은 그대로 둔다.
  4. 장이 꺾이는 각을 해석한다.

\(xy\) 평면에 면전하 \(\sigma = 8.85\times10^{-9}\) C/m²가 있다. 평면 바로 아래의 장이 \(\mathbf E = (300, 0, 400)\) V/m일 때 바로 위의 장과, 장이 법선과 이루는 각의 변화를 구하여라.

풀이

  1. \(\sigma/\varepsilon_0 = 8.85\times10^{-9}/8.85\times10^{-12} = 1000\) V/m.
    뛰는 양.
  2. 수직(\(z\)): \(400 + 1000 = 1400\) V/m. 접선(\(x\)): 300 그대로.
    경계 조건.
  3. 위: \(\mathbf E = (300, 0, 1400)\) V/m.
    결과.
  4. 법선과의 각: 아래 \(\arctan(300/400) = 36.9°\), 위 \(\arctan(300/1400) = 12.1°\).
    장선이 꺾인다.

의미

면전하가 장선의 원천이라 그 자리에서 수직 성분이 갑자기 늘어납니다. 접선 성분이 이어지는 것은 \(\nabla\times\mathbf E = 0\)(작은 사각 고리의 순환 0) 때문입니다.

검산

무한 평면 혼자서는 양쪽에 \(\sigma/2\varepsilon_0 = 500\) V/m씩 바깥으로 장을 만듭니다. 바깥 장 \((300, 0, 900)\)에 더하면 위 \(900 + 500\), 아래 \(900 - 500\)으로 같은 결과입니다.
