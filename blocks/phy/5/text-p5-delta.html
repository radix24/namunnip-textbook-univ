디랙 델타 함수와 점전하

본문
이 절에서 배울 것
  • 디랙 델타 함수의 정의와 성질을 쓴다.
  • \(\nabla\cdot(\hat{\mathbf r}/r^2) = 4\pi\delta^3(\mathbf r)\)를 이해하고 점전하 밀도를 나타낸다.
먼저 알아야 할 것
  • 발산 정리 (1.1절).

1.3.1역설

점전하의 전기장 모양인 \(\mathbf v = \hat{\mathbf r}/r^2\)의 발산을 구면 좌표로 계산하면 \(\frac1{r^2}\partial_r(r^2\cdot r^{-2}) = 0\)입니다. 그런데 원점을 감싸는 구에서 표면 적분은 \(\oint\frac1{R^2}R^2\sin\theta\,d\theta\,d\phi = 4\pi\)로 0이 아닙니다. 발산 정리가 틀린 것이 아니라, 모든 "샘"이 원점 한 점에 몰려 있어 \(r \ne 0\)에서는 발산이 0이지만 원점에서 무한대인 것입니다.

1.3.2델타 함수

1차원 디랙 델타 \(\delta(x)\)는 \(x \ne 0\)에서 0이고 \(\int\delta(x)\,dx = 1\)인 "함수"입니다(엄밀히는 적분 안에서만 뜻이 있는 일반화 함수). 폭이 0으로 줄고 높이가 무한대로 커지는 사각형이나 가우스 함수의 극한으로 생각합니다.

  • 거르기 성질: \(\int f(x)\delta(x - a)\,dx = f(a)\).
  • \(\delta(kx) = \frac1{|k|}\delta(x)\).
  • 3차원: \(\delta^3(\mathbf r) = \delta(x)\delta(y)\delta(z)\), \(\int\delta^3(\mathbf r)\,d\tau = 1\).
정리 1.3.1 \[\nabla\cdot\left(\frac{\hat{\mathbf r}}{r^2}\right) = 4\pi\delta^3(\mathbf r), \qquad \nabla^2\frac1r = -4\pi\delta^3(\mathbf r).\]

이제 점전하 \(q\)(위치 \(\mathbf r'\))의 전하 밀도를 \(\rho(\mathbf r) = q\,\delta^3(\mathbf r - \mathbf r')\)로 쓸 수 있고, 점전하와 연속 분포를 같은 식 하나로 다룰 수 있습니다. 점전하의 전기장 \(\mathbf E = \frac{q}{4\pi\varepsilon_0}\frac{\hat{\mathbf r}}{r^2}\)에 정리를 쓰면 \(\nabla\cdot\mathbf E = q\delta^3/\varepsilon_0 = \rho/\varepsilon_0\)로 가우스 법칙과 맞습니다.

예제 1.3.2

\(\int_{-2}^{2}(x^3 + 3x + 1)\,\delta(2x - 2)\,dx\)를 구하여라.

풀이. \(\delta(2x - 2) = \frac12\delta(x - 1)\). 값은 \(\frac12(1 + 3 + 1) = 2.5\).

요약
  1. \(\int f\delta(x - a)dx = f(a)\), \(\delta(kx) = \delta(x)/|k|\).
  2. \(\nabla\cdot(\hat{\mathbf r}/r^2) = 4\pi\delta^3\), \(\nabla^2(1/r) = -4\pi\delta^3\). 점전하 \(\rho = q\delta^3(\mathbf r - \mathbf r')\).

1.3.3연습문제

기본

  1. 원점의 점전하 \(q\)와 \((0, 0, d)\)의 \(-q\)로 된 전하 분포를 델타 함수로 쓰고 전체 전하를 확인하여라.
    답

    \(\rho = q\delta^3(\mathbf r) - q\delta^3(\mathbf r - d\hat{\mathbf z})\). 적분하면 0.
