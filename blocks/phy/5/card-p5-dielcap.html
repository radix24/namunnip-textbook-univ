유전체를 반만 채운 축전기

전기 변위장 · 직렬·병렬 · 문제 해결 전략

출발점

유전체가 있으면 \(\oint\mathbf D\cdot d\mathbf A = Q_{\text{자유}}\)로 \(\mathbf D\)를 먼저 구하고 \(\mathbf E = \mathbf D/\varepsilon\)로 바꿉니다. 판에 나란하게 층을 채우면 직렬, 수직으로 나누면 병렬 축전기가 됩니다.

문제 해결 전략 · 유전체가 있는 축전기
  1. 유전체 배치가 \(\mathbf D\) 방향으로 층인지(직렬) 옆으로 나뉘는지(병렬) 본다.
  2. 직렬이면 \(\mathbf D\)가 같고, 병렬이면 \(\mathbf E\)가 같다.
  3. 각 부분의 용량을 구해 합친다.
  4. 유전체가 없을 때와 비교한다.

판 넓이 \(A\), 간격 \(d\)인 평행판 축전기에 유전율 \(\varepsilon_r = 4\)인 판을 (가) 두께 \(d/2\)로 한쪽 판에 붙여 넣은 경우 (나) 넓이 \(A/2\)만큼 판 사이를 꽉 채운 경우의 용량을 \(C_0 = \varepsilon_0A/d\)로 나타내라.

풀이

  1. (가) 두 층이 직렬: \(C_1 = \frac{4\varepsilon_0A}{d/2} = 8C_0\), \(C_2 = \frac{\varepsilon_0A}{d/2} = 2C_0\).
    \(\mathbf D\)가 두 층에서 같다.
  2. \(\frac1C = \frac1{8C_0} + \frac1{2C_0}\), \(C = 1.6C_0\).
    직렬 합성.
  3. (나) 나란히: \(C = \frac{4\varepsilon_0A/2}d + \frac{\varepsilon_0A/2}d = 2.5C_0\).
    \(\mathbf E\)가 두 부분에서 같다.
  4. 같은 양의 유전체라도 배치에 따라 \(1.6C_0\)와 \(2.5C_0\)로 다르다.
    병렬이 더 크다.

의미

(가)에서 유전체 속 장은 공기층의 1/4이라, 공기층에 큰 장이 걸려 먼저 절연이 깨질 수 있습니다. 고전압 장비는 이런 장의 몰림을 피하도록 설계합니다.

검산

\(\varepsilon_r = 1\)이면 (가) \(\frac1C = \frac1{2C_0} + \frac1{2C_0}\), \(C = C_0\). (나) \(0.5 + 0.5 = C_0\). 극한이 맞습니다.
