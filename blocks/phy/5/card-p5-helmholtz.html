발산과 회전으로 장 되살리기

Helmholtz 정리 · 퍼텐셜 · 문제 해결 전략

출발점

무한대에서 충분히 빨리 0이 되는 벡터장은 발산 \(D = \nabla\cdot\mathbf F\)와 회전 \(\mathbf C = \nabla\times\mathbf F\)만 알면 하나로 정해집니다: \(\mathbf F = -\nabla U + \nabla\times\mathbf W\).

문제 해결 전략 · 원천에서 장 구하기
  1. 발산이 원천이면 스칼라 퍼텐셜 \(U = \frac1{4\pi}\int\frac{D}{|\mathbf r - \mathbf r'|}dV'\).
  2. 회전이 원천이면 벡터 퍼텐셜 \(\mathbf W = \frac1{4\pi}\int\frac{\mathbf C}{|\mathbf r - \mathbf r'|}dV'\).
  3. 대칭이 있으면 Gauss·Ampère 꼴 적분으로 빨리 푼다.
  4. 발산과 회전을 다시 계산해 확인한다.

발산이 반지름 \(a\)인 공 안에서 \(D_0\)(상수), 밖에서 0이고 회전은 어디서나 0인 장을 구하여라.

풀이

  1. 회전 0 → \(\mathbf F = -\nabla U\), 구대칭 → \(\mathbf F = F(r)\hat{\mathbf r}\).
    Helmholtz 분해에서 스칼라 부분만.
  2. 반지름 \(r\)인 구에 발산 정리: \(4\pi r^2F = \int D\,dV\).
    Gauss 법칙과 같은 꼴.
  3. \(r < a\): \(F = \frac{D_0r}3\). \(r > a\): \(F = \frac{D_0a^3}{3r^2}\).
    안쪽은 비례, 바깥은 역제곱.
  4. 정전기에 맞추면 \(D_0 = \rho_0/\varepsilon_0\): 균일한 공 전하의 장.
    같은 수학.

의미

전자기학의 Maxwell 방정식은 바로 \(\mathbf E\)와 \(\mathbf B\)의 발산과 회전을 주는 식입니다. Helmholtz 정리가 "그것만으로 장이 정해진다"를 보장합니다.

검산

\(r < a\)에서 \(\nabla\cdot(\frac{D_0r}3\hat{\mathbf r}) = \frac1{r^2}\partial_r(\frac{D_0r^3}3) = D_0\), \(r > a\)에서 0. 원천과 맞습니다.
