델타 함수로 쓴 전하 밀도와 적분

Dirac 델타 · 차원 · 좌표 변환 · 문제 해결 전략

출발점

점전하 \(q\)가 \(\mathbf r_0\)에 있으면 \(\rho(\mathbf r) = q\,\delta^3(\mathbf r - \mathbf r_0)\)입니다. \(\delta^3\)의 단위는 \(1/\text{m}^3\)이고 적분하면 1입니다. 곡선 좌표에서는 축척 인자로 나눠 줘야 합니다.

문제 해결 전략 · 델타 함수 다루기
  1. 전체 전하가 맞는지(적분 = \(q\))로 정규화를 확인한다.
  2. \(\int f(x)\delta(x - a)dx = f(a)\)를 쓴다.
  3. \(\delta(g(x)) = \sum\frac{\delta(x - x_i)}{|g'(x_i)|}\)로 바꾼다.
  4. 차원을 확인한다.

(가) 반지름 \(R\)인 얇은 구껍질에 전하 \(Q\)가 고르게 있을 때 \(\rho\)를 델타 함수로 써라. (나) \(\int_{-\infty}^{\infty}x^2\delta(2x - 4)dx\)는?

풀이

  1. (가) \(\rho = \sigma\,\delta(r - R)\), \(\sigma = \frac Q{4\pi R^2}\).
    반지름 방향으로만 몰려 있다.
  2. 확인: \(\int\rho\,dV = \int\sigma\delta(r - R)4\pi r^2dr = \sigma4\pi R^2 = Q\).
    정규화가 맞다.
  3. (나) \(\delta(2x - 4) = \frac12\delta(x - 2)\).
    \(|g'| = 2\).
  4. \(\int x^2\cdot\frac12\delta(x - 2)dx = \frac12\cdot4 = 2\).
    골라내기 성질.

의미

델타 함수 덕분에 점전하, 선전하, 면전하를 연속 분포와 같은 식(\(\nabla\cdot\mathbf E = \rho/\varepsilon_0\))으로 다룹니다. \(\nabla^2(1/r) = -4\pi\delta^3(\mathbf r)\)이 점전하 퍼텐셜의 근거입니다.

검산

(나)에서 \(2x - 4 = u\)로 바꾸면 \(\int\frac{(u + 4)^2}4\delta(u)\frac{du}2 = \frac{16}8 = 2\). 같습니다.
