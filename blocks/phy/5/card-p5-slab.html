고르게 대전된 판의 전위를 푸아송 방정식으로

1차원 푸아송 · 경계 조건 · 문제 해결 전략

출발점

두께 \(2d\)인 무한히 넓은 판(\(-d < x < d\))에 전하가 밀도 \(\rho\)로 고르게 퍼져 있다. 대칭 때문에 \(V\)는 \(x\)만의 함수이고 \(V(-x) = V(x)\)이다. 판 안에서는 \(V'' = -\rho/\varepsilon_0\), 밖에서는 \(V'' = 0\)이다.

문제 해결 전략 · 영역별 적분과 이어 붙이기
  1. 영역마다 방정식을 두 번 적분해 상수가 있는 일반해를 쓴다.
  2. 대칭(\(E(0) = 0\))과 기준점(\(V(0) = 0\))으로 상수를 줄인다.
  3. 경계 \(x = \pm d\)에서 \(V\)와 \(E\)가 연속이 되도록 바깥 해를 이어 붙인다.

\(V(0) = 0\)으로 잡고 판 안팎의 \(V(x)\)와 \(E(x)\)를 구하여라. \(\rho = 1.0\times10^{-6}\) C/m³, \(d = 1.0\) cm일 때 판 표면의 전기장과 표면과 가운데의 전위차는?

풀이

  1. 안(\(|x| < d\)): \(V = -\frac{\rho}{2\varepsilon_0}x^2 + ax + b\). 대칭으로 \(a = 0\), \(V(0) = 0\)으로 \(b = 0\). \(E = -V' = \frac{\rho}{\varepsilon_0}x\).
    두 번 적분.
  2. 밖(\(x > d\)): \(V = cx + e\). \(E\) 연속: \(-c = \frac{\rho d}{\varepsilon_0}\). \(V\) 연속: \(cd + e = -\frac{\rho d^2}{2\varepsilon_0}\) → \(e = \frac{\rho d^2}{2\varepsilon_0}\). 그래서 \(V = -\frac{\rho d}{\varepsilon_0}x + \frac{\rho d^2}{2\varepsilon_0}\), \(E = \frac{\rho d}{\varepsilon_0}\).
    경계에서 이어 붙임.
  3. 표면 \(E = \frac{10^{-6}\times0.01}{8.85\times10^{-12}} \approx 1.1\times10^3\) V/m. 전위차 \(\frac{\rho d^2}{2\varepsilon_0} \approx 5.6\) V(가운데가 표면보다 높다).
    수치 대입.

의미

판 밖의 전기장 \(\rho d/\varepsilon_0\)은 단위 넓이당 전하 \(\sigma = 2\rho d\)인 무한 평면의 \(\sigma/2\varepsilon_0\)과 같다. 가우스 법칙으로도 같은 답을 얻지만, 푸아송 방정식은 전위까지 한 번에 주고 대칭이 덜한 문제(전하 밀도가 \(x\)에 따라 변하는 경우)에도 그대로 쓸 수 있다. 반도체 pn 접합의 공핍층 전위가 이 방법으로 계산된다.

검산

안쪽 해를 미분하면 \(V'' = -\rho/\varepsilon_0\), 바깥은 \(V'' = 0\)으로 방정식을 만족한다. \(x = d\)에서 안팎의 \(V\)가 모두 \(-\rho d^2/2\varepsilon_0\)로 같다.
