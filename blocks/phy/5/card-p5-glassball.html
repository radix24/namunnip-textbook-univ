전기장 속 유리구슬의 분극과 유도 쌍극자

유전체 구 · 속박 전하 · 문제 해결 전략

출발점

균일한 장 \(E_0\) 속 유전체 구 안의 장은 \(\frac{3}{\varepsilon_r + 2}E_0\), 분극은 \(\mathbf P = \varepsilon_0(\varepsilon_r - 1)\mathbf E_{\text{안}}\), 바깥에서는 쌍극자 \(p = \frac43\pi R^3P\)로 보입니다(5.4절).

문제 해결 전략 · 안의 장에서 출발
  1. 공식으로 구 안의 장을 구한다.
  2. 분극, 표면 속박 전하 밀도의 최댓값 \(P\), 유도 쌍극자 모멘트를 차례로 구한다.
  3. 쌍극자 장으로 바깥 장이 얼마나 바뀌는지 어림한다.

반지름 1.0 cm, 비유전율 4.0인 유리구슬을 세기 \(1.0\times10^5\) V/m인 균일한 장에 놓았다. (가) 구슬 안의 장은? (나) 분극과 유도 쌍극자 모멘트는? (다) 극 바로 바깥(\(r = R\), \(\theta = 0\))에서 유도 쌍극자가 더하는 장은? (\(\varepsilon_0 = 8.85\times10^{-12}\) F/m)

풀이

  1. (가) \(E_{\text{안}} = \frac{3}{6}\times10^5 = 5.0\times10^4\) V/m.
    \(\varepsilon_r + 2 = 6\).
  2. (나) \(P = 8.85\times10^{-12}\times3\times5.0\times10^4 = 1.3\times10^{-6}\) C/m². \(p = \frac43\pi(0.01)^3\times1.33\times10^{-6} = 5.6\times10^{-12}\) C·m.
    \(\frac43\pi R^3 = 4.19\times10^{-6}\) m³.
  3. (다) \(\frac{2p}{4\pi\varepsilon_0R^3} = \frac{2P}{3\varepsilon_0} = \frac{2\times1.33\times10^{-6}}{3\times8.85\times10^{-12}} = 1.0\times10^5\) V/m. 극 바로 바깥의 장은 \(E_0\)의 두 배인 \(2.0\times10^5\) V/m.
    축 위 쌍극자 장(4.6절).

의미

극에서 바깥 장이 커지고 안쪽 장이 작아지는 것은 \(D^\perp\) 연속 조건 그대로이다. 극에서는 장이 표면에 수직이므로 \(\varepsilon_0E_{\text{밖}} = \varepsilon_r\varepsilon_0E_{\text{안}}\), 곧 \(2.0\times10^5 = 4\times5.0\times10^4\)이다. 전기력선이 유전체 쪽으로 모여드는 모습이고, 이 때문에 고르지 않은 장에서 유전체 구슬은 장이 센 쪽으로 끌립니다(유전 영동).

검산

\(D^\perp\) 연속을 위처럼 확인했다. 또 \(\varepsilon_r \to 1\)이면 \(P \to 0\)이 되어 장이 바뀌지 않는다.
