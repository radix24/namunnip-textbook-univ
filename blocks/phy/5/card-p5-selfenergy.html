공 전하의 정전 에너지를 두 방법으로

장 에너지 밀도 · 전하로 쌓기 · 문제 해결 전략

출발점

정전 에너지는 전하를 하나씩 모으는 일 \(W = \frac12\int\rho V\,dV\)로도, 장에 저장된 에너지 \(W = \frac{\varepsilon_0}2\int E^2\,dV\)로도 구할 수 있습니다. 두 값은 같아야 합니다.

문제 해결 전략 · 정전 에너지
  1. 영역마다 \(E\)를 구한다.
  2. \(\frac{\varepsilon_0}2E^2\)를 껍질 부피 \(4\pi r^2dr\)로 적분한다.
  3. 또는 \(\frac12\int\rho V\)로 계산한다.
  4. 두 값을 비교한다.

반지름 \(R\)에 전하 \(Q\)가 고르게 퍼진 공의 정전 에너지를 구하여라. 전자의 정지 에너지가 모두 이 에너지라면 반지름은 얼마인가?

풀이

  1. 바깥: \(\frac{\varepsilon_0}2\int_R^\infty\left(\frac{kQ}{r^2}\right)^24\pi r^2dr = \frac{kQ^2}{2R}\).
    \(\varepsilon_0k^2\cdot2\pi = k/2\).
  2. 안: \(\frac{\varepsilon_0}2\int_0^R\left(\frac{kQr}{R^3}\right)^24\pi r^2dr = \frac{kQ^2}{10R}\).
    \(r^4\) 적분.
  3. 합 \(W = \frac35\frac{kQ^2}R\).
    안쪽이 1/6을 차지.
  4. \(m_ec^2 = \frac35\frac{ke^2}R\) → \(R = \frac35\frac{ke^2}{m_ec^2} = 0.6\times2.82\times10^{-15} \approx 1.7\times10^{-15}\) m.
    고전 전자 반지름 \(ke^2/m_ec^2\)의 0.6배.

의미

점전하(\(R \to 0\))는 에너지가 무한대가 됩니다. 고전 전자기학의 한계로, 실험에서 전자는 이 반지름보다 훨씬 작게(점처럼) 보입니다. 이 문제는 양자 전기역학에서 다른 방식으로 다룹니다.

검산

\(\frac12\int\rho V\,dV\)로: \(\rho = \frac{3Q}{4\pi R^3}\), \(V = \frac{kQ}{2R}(3 - r^2/R^2)\)을 적분하면 \(\frac12\cdot\frac{3Q}{4\pi R^3}\cdot\frac{kQ}{2R}\cdot4\pi(R^3 - \frac{R^3}5) = \frac35\frac{kQ^2}R\). 같습니다.
