유일성 정리로 답이 맞는지 판단하기

경계 조건 · 짐작한 해 · 문제 해결 전략

출발점

경계에서의 전위(또는 도체의 전하)가 정해지면 Laplace 방정식의 해는 하나뿐입니다. 그래서 어떤 방법으로 찾든, 방정식과 경계 조건을 모두 만족하면 그것이 답입니다.

문제 해결 전략 · 짐작하고 확인하기
  1. 대칭이나 비슷한 문제로 해를 짐작한다.
  2. 영역 안에서 Laplace(또는 Poisson) 방정식을 만족하는지 확인한다.
  3. 모든 경계 조건을 확인한다.
  4. 유일성 정리로 그것이 답이라고 결론짓는다.

속이 빈 도체 껍질(모양 자유) 안에 전하가 없을 때, 안쪽 공간의 전위와 장을 구하여라. 껍질에 전하를 더 주거나 바깥에 다른 전하를 가져오면 바뀌는가?

풀이

  1. 도체 껍질 전체가 같은 전위 \(V_0\).
    정전 평형의 도체.
  2. 짐작: 안쪽 어디서나 \(V = V_0\).
    가장 단순한 후보.
  3. \(\nabla^2V_0 = 0\)이고 경계에서 \(V_0\). 방정식과 경계 조건을 만족한다.
    확인.
  4. 유일성으로 답은 \(V = V_0\), \(\mathbf E = 0\). 바깥 전하나 껍질 전하가 바뀌어도 \(V_0\)만 바뀌고 안쪽 장은 0이다.
    경계 조건이 상수라는 사실만 썼다.

의미

Faraday 상자(전자기 차폐)의 원리입니다. 번개 칠 때 자동차 안이 안전하고, 전자레인지 문의 금속망이 마이크로파를 막는(원리상 비슷한) 까닭입니다.

검산

Gauss 법칙으로도: 안쪽에 아무 닫힌 면을 잡으면 안에 전하가 없어 선속 0, 그리고 순환 0이라 장이 0입니다.
