4.2.1도체 평면

접지된 무한 도체 평면(\(z = 0\), \(V = 0\)) 위 높이 \(d\)에 점전하 \(q\)가 있습니다. 평면에 유도되는 전하 분포를 모르므로 직접 계산은 어렵습니다. 대신 평면이 없다고 치고 \((0, 0, -d)\)에 \(-q\)를 놓으면

\[V(x, y, z) = \frac{q}{4\pi\varepsilon_0}\left[\frac1{\sqrt{x^2 + y^2 + (z - d)^2}} - \frac1{\sqrt{x^2 + y^2 + (z + d)^2}}\right]\]

은 \(z > 0\)에서 라플라스 방정식(\(q\)의 자리 빼고)을 만족하고, \(z = 0\)에서 0, 무한대에서 0입니다. 유일성 정리로 이것이 \(z > 0\)의 정답입니다. \(-q\)를 영상 전하라 합니다(\(z < 0\)에서는 도체 속이라 \(V = 0\)).

  • 유도 전하: \(\sigma = -\varepsilon_0\frac{\partial V}{\partial z}\Big|_{z=0} = \frac{-qd}{2\pi(x^2 + y^2 + d^2)^{3/2}}\). 적분하면 전체가 \(-q\).
  • 힘: 영상 전하가 주는 힘과 같다. \(\mathbf F = -\frac{q^2}{4\pi\varepsilon_0(2d)^2}\hat{\mathbf z}\), 평면 쪽으로 끌린다.
  • 에너지: \(q\)를 무한대에서 가져오는 일은 \(W = -\frac{q^2}{4\pi\varepsilon_0(4d)}\)로, 실제 두 전하 계의 에너지의 절반이다(장이 \(z > 0\)에만 있으므로).

4.2.2접지된 도체 구

반지름 \(R\)인 접지 구의 중심에서 \(a\) (\(> R\)) 떨어진 곳에 \(q\)가 있으면, 같은 방향으로 중심에서 \(b\)인 곳에 크기 \(q'\)인 영상 전하를 놓아 구면 위 전위를 모두 0으로 만들 수 있습니다. 구면 위 두 점(가장 가까운 점과 가장 먼 점)에서 전위가 0이라는 조건으로 두 값을 정하면

\[q' = -\frac{R}{a}q, \qquad b = \frac{R^2}{a}.\]

구가 받는 힘(곧 \(q\)가 끌리는 힘)은 \(F = \frac{1}{4\pi\varepsilon_0}\frac{qq'}{(a - b)^2} = -\frac{q^2Ra}{4\pi\varepsilon_0(a^2 - R^2)^2}\)입니다. 구가 접지되지 않고 전체 전하가 0이면, 중심에 \(-q'\)를 더해 구의 알짜 전하를 0으로 만듭니다. 아래 실습 카드에서 영상 전하와 등전위선을 볼 수 있습니다.

요약
  1. 도체 평면: 반대편 같은 거리에 \(-q\). 힘 \(q^2/(4\pi\varepsilon_0(2d)^2)\)로 끌림.
  2. 접지 구: \(q' = -(R/a)q\), \(b = R^2/a\).
  3. 유일성 정리가 이 방법을 정당화한다.
