오차가 다른 세 측정의 가중 평균

가중 최소제곱 · 상수 모형 · 카이제곱

출발점

오차 \(\sigma_i\)가 다른 측정값 \(y_i\)에 상수 모형 \(f = \mu\)를 맞추면, \(\chi^2 = \sum(y_i - \mu)^2/\sigma_i^2\)를 최소로 하는 \(\mu\)는 \(w_i = 1/\sigma_i^2\)인 가중 평균이고 그 불확도는 \(1/\sqrt{\sum w_i}\)입니다(2.1절).

문제 해결 전략 · 무게 → 평균 → 불확도 → 일관성
  1. 무게 \(w_i = 1/\sigma_i^2\)를 구한다.
  2. 가중 평균과 그 불확도를 구한다.
  3. \(\chi^2\)로 세 측정이 서로 맞는지 확인한다.

세 실험이 \(g\)를 \(9.81 \pm 0.02\), \(9.78 \pm 0.05\), \(9.85 \pm 0.10\) m/s²로 얻었다. 가중 평균과 불확도를 구하고, 세 값이 서로 맞는지 판단하여라.

풀이

  1. \(w = 2500,\ 400,\ 100\), \(\sum w = 3000\).
    \(1/\sigma^2\).
  2. \(\bar g = (9.81\times2500 + 9.78\times400 + 9.85\times100)/3000 = 9.807\), \(\sigma = 1/\sqrt{3000} = 0.018\).
    가중 평균.
  3. \(\chi^2 = (0.003/0.02)^2 + (0.027/0.05)^2 + (0.043/0.10)^2 = 0.02 + 0.29 + 0.18 = 0.50\), 자유도 2. 기대값 2보다 작아 서로 잘 맞는다.
    자유도 = 3 − 1.

의미

가장 정밀한 측정이 결과를 거의 정합니다(무게의 83%). 단순 평균 9.813은 덜 정밀한 측정에 같은 무게를 주어 불확도가 더 크다. 다만 \(\chi^2\)가 자유도보다 훨씬 크면 측정들이 서로 맞지 않는 것이므로, 가중 평균을 내기 전에 원인(빠진 계통 오차)을 찾아야 한다.

검산

가중 평균 9.807은 세 값 사이에 있고 가장 정밀한 9.81에 가깝다. 불확도 0.018은 가장 작은 개별 불확도 0.02보다 조금 작다.
