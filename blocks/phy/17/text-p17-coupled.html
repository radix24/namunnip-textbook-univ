연성 진동자 시뮬레이션과 정규 모드 검증

본문

같은 진자 두 개를 약한 용수철로 잇고 한쪽만 당겼다 놓으면, 처음에 흔들리던 진자는 점점 멈추고 가만있던 진자가 크게 흔들리다가 다시 처음 진자로 돌아온다. 에너지가 넘어가는 데 걸리는 시간을 미리 계산할 수 있을까? 그리고 수치 계산 코드가 이것을 제대로 재현하는지는 어떻게 확인할까?

먼저 알아야 할 것solve_ivp(3.1절), 연성 진동(물리4 4.1절)을 쓴다.

3.2.1운동 방정식과 코드

길이 \(L\)인 같은 진자 둘을 용수철 상수 \(k\)인 용수철로 이으면, 작은 각에서 수평 변위 \(x_1\), \(x_2\)는 다음 방정식을 따른다.

\[m\ddot x_1 = -\frac{mg}{L}x_1 - k(x_1 - x_2), \qquad m\ddot x_2 = -\frac{mg}{L}x_2 - k(x_2 - x_1)\]

\(\omega_0^2 = g/L\), \(\kappa = k/m\)으로 두고 상태 벡터 \((x_1, x_2, v_1, v_2)\)로 쓰면 3.1절과 같은 방식으로 푼다. 아래 코드는 첫째 진자만 0.05만큼 당긴 처음 조건에서 출발한다.

def f(t, s):
    x1, x2, v1, v2 = s
    a1 = -w0**2 * x1 - kappa * (x1 - x2)    # w0^2 = g/L, kappa = k/m
    a2 = -w0**2 * x2 - kappa * (x2 - x1)
    return [v1, v2, a1, a2]
sol = solve_ivp(f, (0, 400), [0.05, 0, 0, 0], rtol=1e-9, atol=1e-12, max_step=0.05)

여기서 max_step을 정한 까닭은 빠른 진동이 수백 번 되풀이되는 긴 시간 동안 걸음 크기가 지나치게 커지지 않게 하려는 것이다.

3.2.2정규 모드로 검증

물리4 4.1절에서 구한 정규 모드는 두 진자가 같은 방향으로 흔들리는 \(\omega_1 = \omega_0\)과 반대 방향으로 흔들리는 \(\omega_2 = \sqrt{\omega_0^2 + 2\kappa}\)이다. 한 진자만 당겼다 놓으면 두 모드가 같은 크기로 섞여 \(x_1 \propto \cos\omega_1t + \cos\omega_2t\)가 되고, 삼각함수의 합 공식에 따라 진폭이 \(\cos\frac{(\omega_2 - \omega_1)t}{2}\)로 천천히 오르내린다. 이것이 맥놀이이며, 에너지가 두 진자 사이를 오간다.

따라서 처음 질문의 답은 에너지가 완전히 넘어가는 시간이 \(\pi/(\omega_2 - \omega_1)\)이라는 것이다. 수치해에서 맥놀이 주기를 재거나, 수치해를 푸리에 변환해 봉우리가 \(\omega_1\)과 \(\omega_2\)에 있는지 보면 코드가 검증된다.

예제 3.2.1

\(\omega_0 = 1\) rad/s, \(\kappa = 0.05\) s⁻²일 때 에너지가 둘째 진자로 완전히 넘어가는 시각은? 그동안 첫째 진자는 몇 번쯤 진동하는가?

풀이. \(\omega_2 = \sqrt{1 + 0.1} = 1.0488\)이므로 \(\omega_2 - \omega_1 = 0.0488\)이고, 시각은 \(\pi/0.0488 \approx 64\) s이다. 진동 주기는 약 \(2\pi\) s이므로 그동안 약 10번 진동한다(그림 1). 용수철이 약할수록 \(\omega_2 - \omega_1 \approx \kappa/\omega_0\)이 작아져 에너지가 더 천천히 넘어간다.

3.2.3해석해가 없는 문제로

해석해와 맞는 것을 확인한 코드는 해석해가 없는 문제로 넓힐 수 있다. 이것이 수치 계산의 진짜 쓸모이다. 예를 들어 \(-\omega_0^2x\)를 \(-\omega_0^2\sin x\)로 바꾸면 큰 진폭의 진자가 되고, 감쇠와 구동을 넣을 수도 있다. 큰 진폭에서는 진동수가 진폭에 따라 달라지므로, 두 진자의 진동수가 어긋나 에너지가 완전히 넘어가지 못하는 새로운 현상이 나타난다.

흔한 오해새 문제를 바로 풀고 결과를 해석하고 싶어지지만, 해석해가 있는 경우로 먼저 검증하지 않은 코드의 결과는 물리인지 버그인지 가릴 수 없다. 작은 진폭, 감쇠 없음 같은 알려진 극한에서 정규 모드를 재현한 뒤에 조건을 하나씩 바꾼다.
마무리

연성 진자의 운동 방정식은 상태 벡터로 써서 solve_ivp로 풀고, 정규 모드 \(\omega_1 = \omega_0\), \(\omega_2 = \sqrt{\omega_0^2 + 2\kappa}\)와 비교해 검증한다. 한 진자만 당기면 맥놀이가 생겨, 처음 질문의 에너지는 \(\pi/(\omega_2 - \omega_1)\) 뒤에 완전히 넘어간다. 해석해로 검증한 코드를 비선형, 감쇠, 구동이 있는 문제로 넓힌다.

기본

  1. 수치해를 FFT했더니 봉우리가 0.4982 Hz와 0.5032 Hz에 나왔다. 맥놀이 주기는?
    답

    \(1/(0.5032 - 0.4982) = 200\) s.

  2. max_step을 정해 주는 까닭은?
    답
