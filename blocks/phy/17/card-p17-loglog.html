로그-로그 그래프로 거듭제곱 법칙 찾기

로그 눈금 · 기울기 · 문제 해결 전략

출발점

\(y = Ax^n\)이면 \(\log y = \log A + n\log x\)라 로그-로그 그래프에서 직선이 되고 기울기가 지수 \(n\)이다. 자료가 몇 배씩 넓게 퍼져 있을 때 특히 유용하다.

문제 해결 전략 · 거듭제곱 법칙 찾기
  1. 양축을 로그 눈금으로 그린다(ax.loglog).
  2. 직선이면 거듭제곱 법칙. 휘면 다른 꼴을 생각한다.
  3. 두 점이나 직선 맞춤으로 기울기 \(n\)을 구한다.
  4. 물리적으로 기대되는 지수와 비교한다.

행성의 궤도 긴반지름(AU)과 주기(년): 수성 0.387, 0.241 / 지구 1, 1 / 목성 5.20, 11.86 / 해왕성 30.1, 164.8. 로그-로그 기울기를 구하여라.

풀이

  1. 지구와 해왕성: \(n = \frac{\log164.8 - \log1}{\log30.1 - \log1} = \frac{2.217}{1.479} = 1.499\).
    상용로그.
  2. 수성과 목성: \(\frac{\log11.86 - \log0.241}{\log5.20 - \log0.387} = \frac{1.074 + 0.618}{0.716 + 0.412} = \frac{1.692}{1.128} = 1.500\).
    같은 기울기.
  3. \(n = 1.50\): \(T \propto a^{3/2}\).
    케플러 제3법칙.
  4. 절편 \(\log A = 0\)(지구에서 \(T = 1\), \(a = 1\)).
    단위를 AU, 년으로 잡은 덕분.

의미

보통 그래프에서는 수성과 지구가 원점 근처에 뭉쳐 보이지 않지만, 로그 그래프에서는 모든 행성이 고르게 퍼져 직선 위에 놓인다. 그래프 선택이 자료에서 법칙을 찾는 첫걸음이다.

검산

목성: \(5.20^{1.5} = 11.86\). 표의 값과 같다.
