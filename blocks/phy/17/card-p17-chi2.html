카이제곱으로 두 모형 비교하기

환산 카이제곱 · 자유도 · 문제 해결 전략

출발점

\(\chi^2 = \sum\frac{(y_i - f(x_i))^2}{\sigma_i^2}\)는 오차 막대에 비해 모형이 자료에서 얼마나 벗어나는지를 잰다. 자유도 \(\nu = N - p\)(자료 수 − 매개변수 수)로 나눈 환산 카이제곱이 1 근처이면 모형과 오차가 서로 맞다.

문제 해결 전략 · 적합의 좋음 평가
  1. 각 모형의 \(\chi^2\)을 구한다.
  2. 자유도로 나눠 \(\chi^2_\nu\)를 비교한다.
  3. \(\chi^2_\nu \gg 1\)이면 모형이 틀렸거나 오차를 작게 잡았고, \(\ll 1\)이면 오차를 크게 잡았다.
  4. 매개변수가 많은 모형은 자유도가 줄어든다는 것을 고려한다.

오차 \(\sigma = 0.1\)인 자료 10개에 직선(매개변수 2개)을 맞추니 \(\chi^2 = 24\), 2차식(3개)을 맞추니 \(\chi^2 = 7.5\)였다. 어느 모형이 나은가?

풀이

  1. 직선: \(\nu = 8\), \(\chi^2_\nu = 3.0\).
    오차보다 체계적으로 벗어남.
  2. 2차식: \(\nu = 7\), \(\chi^2_\nu = 1.07\).
    오차 크기와 맞음.
  3. \(\chi^2_\nu = 3\)(\(\nu = 8\))이 우연히 나올 확률은 약 0.2%로 아주 작다.
    카이제곱 분포의 꼬리(대략값).
  4. 2차식이 낫다. 매개변수 하나를 더 써서 \(\chi^2\)가 16.5나 줄었다.
    단순히 늘린 효과(약 1)보다 훨씬 크다.

의미

매개변수를 늘리면 \(\chi^2\)는 늘 줄어든다. 그래서 "줄어든 양이 매개변수를 하나 더 쓴 값어치가 있는가"를 자유도로 따져야 한다. 이 생각이 4단원의 과적합 문제로 이어진다.

검산

모형이 맞다면 \(\chi^2\)의 기댓값은 \(\nu\), 표준편차는 \(\sqrt{2\nu}\): 2차식 \(7 \pm 3.7\) 안에 7.5가 들고, 직선 \(8 \pm 4\)에서 24는 4표준편차 밖이다.
