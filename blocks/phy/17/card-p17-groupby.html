여러 번 잰 자료를 조건별로 묶어 평균 내기

pandas groupby · 표준 오차 · 문제 해결 전략

출발점

실험 자료는 보통 "조건(예: 길이), 반복 번호, 측정값"의 긴 표이다. pandas로 읽어 조건별로 묶고(groupby) 평균과 표준 오차를 구하면 그래프에 쓸 점과 오차 막대가 나온다.

문제 해결 전략 · 자료 정리
  1. pd.read_csv로 읽고 열 이름과 단위를 확인한다.
  2. df.groupby('조건')['값'].agg(['mean', 'std', 'count'])로 요약한다.
  3. 표준 오차 \(\sigma/\sqrt N\)을 새 열로 만든다.
  4. 이상한 값(입력 실수)을 먼저 걸러 낸다.

진자 길이 0.5 m에서 주기를 4번 재서 1.42, 1.41, 1.43, 1.42 s, 1.0 m에서 2.01, 2.00, 2.02, 2.01 s를 얻었다. 길이별 평균과 표준 오차를 구하고, 이 정리를 하는 코드를 써라.

풀이

  1. 0.5 m: 평균 1.420 s, 표준편차 0.0082 s, 표준 오차 \(0.0082/\sqrt4 = 0.0041\) s.
    표본 표준편차(\(N - 1\)).
  2. 1.0 m: 평균 2.010 s, 표준 오차 0.0041 s.
    같은 흩어짐.
  3. 코드: s = df.groupby('L')['T'].agg(['mean','std','count']); s['sem'] = s['std']/s['count']**0.5.
    pandas의 sem()도 같다.
  4. 점검: \(T^2/L\) = 4.03, 4.04 s²/m로 거의 같아 \(T \propto \sqrt L\)과 맞다.
    물리 관계로 확인.

의미

자료를 "긴 표" 하나로 두고 필요할 때 묶어 요약하면, 측정을 더해도 같은 코드로 다시 정리할 수 있다. 손으로 평균을 내는 것보다 실수가 적고 재현이 쉽다.

검산

\(4\pi^2/(T^2/L) = 39.48/4.03 = 9.80\) m/s². 표준값과 맞다.
