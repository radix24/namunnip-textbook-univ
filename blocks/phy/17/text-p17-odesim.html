3.1.1solve_ivp

운동 방정식을 1계 연립 방정식 \(\dot{\mathbf y} = \mathbf f(t, \mathbf y)\)로 쓰고 함수로 넘깁니다. 기본 방법(RK45)은 걸음마다 4차와 5차 결과를 비교해 오차를 어림하고, 허용 오차에 맞게 걸음 크기를 스스로 조절합니다.

from scipy.integrate import solve_ivp
GM = 4 * np.pi**2                      # AU, 년 단위 (태양)
def kepler(t, s):
    x, y, vx, vy = s
    r3 = (x*x + y*y)**1.5
    return [vx, vy, -GM*x/r3, -GM*y/r3]

s0 = [1.0, 0.0, 0.0, 2*np.pi*0.8]      # 원 궤도 속력의 0.8배로 출발 → 타원
sol = solve_ivp(kepler, (0, 10), s0, rtol=1e-9, atol=1e-12, dense_output=True)
x, y, vx, vy = sol.y
E = 0.5*(vx**2 + vy**2) - GM/np.hypot(x, y)
L = x*vy - y*vx
print(np.ptp(E)/abs(E[0]), np.ptp(L)/abs(L[0]))   # 보존량의 상대 변화
  • rtol, atol: 상대·절대 허용 오차. 기본값(1e-3, 1e-6)은 장시간 궤도 계산에 너무 느슨하다.
  • 보존량(에너지, 각운동량)의 변화가 수치 오차의 좋은 지표다. 일반적인 RK 방법은 장시간에 에너지가 조금씩 표류한다(물리1, 공통11의 오일러-크로머처럼 보존 성질을 지키는 심플렉틱 방법을 쓰기도 함).
  • 진동이 빠른 성분과 느린 성분이 섞인 강성(stiff) 방정식은 method="Radau"나 "LSODA"를 쓴다.

3.1.2연성 진동자

물리4 4.1절의 두 진동자를 같은 방법으로 풀고, 결과를 정규 모드 해와 비교해 검증합니다. 해석해가 있는 경우로 먼저 코드를 검증한 뒤, 비선형 항(큰 진폭의 진자)이나 감쇠를 넣어 해석해가 없는 문제로 넓히는 것이 좋은 순서입니다.

예제 3.1.1

위 궤도에서 처음 속력이 원 궤도의 0.8배일 때 궤도 긴반지름과 주기를 예측하고 수치해와 비교하는 방법을 말하여라.

풀이. 에너지 \(E = \frac12(0.8\cdot2\pi)^2 - 4\pi^2 = 4\pi^2(0.32 - 1) = -0.68\times4\pi^2\). \(a = -GM/2E = 1/1.36 \approx 0.735\) AU, 주기 \(a^{3/2} \approx 0.63\) 년. 수치해에서 \(x\)가 같은 방향으로 다시 지나는 시각 간격을 재어 비교합니다.

요약
  1. solve_ivp(f, t_span, y0, rtol, atol), 걸음 크기 자동 조절.
  2. 보존량과 해석해로 검증, 강성 문제는 다른 방법.

기본
