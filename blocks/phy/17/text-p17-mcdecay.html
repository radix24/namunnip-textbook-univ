  • 실행마다의 흔들림을 이항분포로 예측하고, 시뮬레이션 자료에 맞춘 매개변수의 불확도를 확인한다.

  • 몬테카를로 원리 (3.4절), 붕괴 법칙 (물리7 4.2절), 곡선 적합 (2.1절).

3.5.1시뮬레이션

핵 \(N_0\)개가 시간 간격 \(\Delta t\)마다 각각 확률 \(p = 1 - e^{-\lambda\Delta t}\)로 붕괴하게 합니다. 남은 핵 하나하나에 난수를 쓰는 대신, 이번 간격의 붕괴 수를 이항분포에서 한 번에 뽑으면 빠릅니다.

rng = np.random.default_rng(1)
lam, dt, N0 = 0.1, 0.1, 1000
alive = N0
counts = []
for step in range(500):
    decays = rng.binomial(alive, 1 - np.exp(-lam*dt))   # 이번 간격의 붕괴 수
    alive -= decays
    counts.append(alive)

\(p = \lambda\Delta t\)로 근사해도 되지만, \(\lambda\Delta t\)가 크면 오차가 생기므로 정확한 식을 씁니다.

3.5.2흔들림과 검증

평균은 \(N_0e^{-\lambda t}\)를 따르지만 실행마다 흔들립니다. 시각 \(t\)에 각 핵이 살아 있을 확률이 \(q = e^{-\lambda t}\)이므로 남은 수는 이항분포를 따라, 표준편차가 \(\sqrt{N_0q(1 - q)}\)입니다. 핵이 적을수록 상대 흔들림이 커집니다.

같은 시뮬레이션을 여러 번 돌려 평균과 표준편차를 이론과 비교하면 코드가 검증되고 통계적 흔들림도 실감할 수 있습니다. 또 한 번의 시뮬레이션 자료에 2.1절 방법으로 지수 함수를 맞춰 얻은 \(\lambda\)의 불확도가, 여러 실행 사이에서 맞춘 \(\lambda\)가 흔들리는 정도와 같은지 확인해 봅니다. 같다면 불확도 계산이 올바른 것입니다.

요약
  1. 간격마다 붕괴 수를 이항분포로: \(p = 1 - e^{-\lambda\Delta t}\).
  2. 남은 수의 표준편차 \(\sqrt{N_0q(1 - q)}\), \(q = e^{-\lambda t}\).
  3. 여러 실행으로 평균, 흔들림, 맞춘 매개변수의 불확도를 검증.

3.5.3연습문제

기본

  1. \(\lambda = 0.1\) s⁻¹, \(\Delta t = 0.1\) s일 때 한 간격의 붕괴 확률은?
    답

    \(1 - e^{-0.01} \approx 0.00995\).

  2. \(N_0 = 1000\)일 때 \(t = 10\) s(\(\lambda t = 1\))에 남은 수의 기대값과 표준편차는?
    답

    \(1000e^{-1} = 368\), \(\sqrt{1000\times0.368\times0.632} \approx 15\).
