역전파와 경사 하강

본문

매개변수가 수십만 개인 신경망에서 손실 함수의 기울기를 어떻게 구할까? 매개변수마다 조금씩 바꾸어 차분으로 구하면 순전파를 수십만 번 해야 한다. 연쇄 법칙을 출력에서 입력 쪽으로 거꾸로 적용하면, 순전파 한 번과 비슷한 비용으로 모든 기울기를 얻는다.

먼저 알아야 할 것신경망의 순전파(5.1절), 편미분의 연쇄 법칙(미적분학), 정칙화(4.4절)를 쓴다.

5.2.1연쇄 법칙의 정리

앞 절의 신경망에서 자료 하나에 대해 \(\mathbf z = W_1\mathbf x + \mathbf b_1\), \(\mathbf h = \sigma(\mathbf z)\), \(\hat y = W_2\mathbf h + b_2\), \(L = (\hat y - y)^2\)이다. 출력 쪽부터 미분하자. \(\delta_2 = \partial L/\partial\hat y = 2(\hat y - y)\)이고, \(\hat y\)는 \(W_2\)와 \(\mathbf h\)에 대해 선형이므로

\[\frac{\partial L}{\partial W_2} = \delta_2\,\mathbf h^{\mathsf T}, \qquad \frac{\partial L}{\partial b_2} = \delta_2, \qquad \frac{\partial L}{\partial\mathbf h} = W_2^{\mathsf T}\delta_2\]

이다. 이제 \(\mathbf h = \sigma(\mathbf z)\)는 성분마다 작용하므로 \(\boldsymbol\delta_1 = \partial L/\partial\mathbf z = (W_2^{\mathsf T}\delta_2)\odot\sigma'(\mathbf z)\)이고(\(\odot\)는 성분별 곱), 같은 꼴로 \(\partial L/\partial W_1 = \boldsymbol\delta_1\mathbf x^{\mathsf T}\), \(\partial L/\partial\mathbf b_1 = \boldsymbol\delta_1\)이다. 따라서 층마다 "받은 기울기에 전치 행렬을 곱하고, 활성화의 미분을 성분별로 곱한다"를 되풀이하면 된다. 순전파에서 계산한 \(\mathbf z\), \(\mathbf h\)를 저장해 두었다가 다시 쓰는 것이 비용을 줄이는 열쇠이다.

def backward(X, y, yhat, H):
    N = len(X)
    d2 = 2*(yhat - y)/N               # (N, 1)
    gW2 = d2.T @ H; gb2 = d2.sum()
    d1 = (d2 @ W2) * (1 - H**2)      # tanh' = 1 - tanh^2
    gW1 = d1.T @ X; gb1 = d1.sum(axis=0)
    return gW1, gb1, gW2, gb2

eta = 0.05
for step in range(5000):
    yhat, H = forward(X)
    gW1, gb1, gW2, gb2 = backward(X, y, yhat, H)
    W1 -= eta*gW1; b1 -= eta*gb1
    W2 -= eta*gW2; b2 -= eta*gb2

5.2.2검증과 학습률

역전파 코드는 틀리기 쉬우므로 수치 미분과 비교해 검증한다. 매개변수 하나를 \(\pm\epsilon\)만큼 바꾼 중심 차분 \((L(\theta + \epsilon) - L(\theta - \epsilon))/2\epsilon\)이 역전파 값과 상대 오차 \(10^{-6}\) 이하로 맞으면 된다. 그다음 학습률 \(\eta\)를 정한다. 너무 크면 손실이 진동하거나 발산하고, 너무 작으면 수렴이 느리다. 손실 곡선을 그려 보고 고르는 것이 실용적이다.

예제 5.2.1

\(L(w) = (wx - y)^2\), \(x = 2\), \(y = 1\)에서 \(w = 0\)부터 경사 하강을 할 때, 수렴하는 학습률의 범위를 구하여라.

풀이. \(L'(w) = 2x(wx - y) = 8w - 4\)이고 최솟점은 \(w^* = 0.5\)이다. 갱신 \(w \leftarrow w - \eta(8w - 4)\)을 \(w^*\)에서의 편차로 쓰면 \(e \leftarrow (1 - 8\eta)e\)이다. 그러면 \(|1 - 8\eta| < 1\), 곧 \(0 < \eta < 0.25\)에서 수렴한다. \(\eta = 0.125\)이면 한 번에 도달하고, \(0.125 < \eta < 0.25\)이면 진동하며 수렴한다. 일반적으로 학습률의 한계는 손실의 곡률(헤세 행렬의 가장 큰 고유값)이 정한다.

마무리

역전파는 연쇄 법칙을 출력에서 입력 쪽으로 적용해, 순전파 한 번과 비슷한 비용으로 모든 매개변수의 기울기를 구한다. 각 층은 받은 기울기에 가중치의 전치를 곱하고 활성화의 미분을 성분별로 곱해 넘긴다. 구현은 중심 차분으로 검증하고, 경사 하강의 학습률은 손실의 곡률보다 작게 잡아야 수렴한다.

5.2.3연습문제

기본

  1. \(\sigma(z) = \mathrm{ReLU}(z)\)일 때 \(\sigma'(z)\)를 쓰고, 역전파 코드에서 바뀌는 줄을 말하여라.
    답

    \(z > 0\)이면 1, 아니면 0. d1 = (d2 @ W2) * (Z > 0)으로 바꾸며, 순전파에서 Z를 저장해야 한다.

응용

  1. L2 정칙화 항 \(\frac\lambda2\|W\|^2\)을 손실에 더하면 갱신식이 어떻게 바뀌는가?
    답

    기울기에 \(\lambda W\)가 더해져 \(W \leftarrow (1 - \eta\lambda)W - \eta\,\partial L/\partial W\)가 된다(가중치 감쇠).
