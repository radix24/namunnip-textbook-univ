1.1.1NumPy

NumPy 배열은 같은 자료형의 값을 메모리에 이어 담고, 원소별 연산을 컴파일된 코드로 처리합니다. 핵심은 반복문 대신 배열 전체에 식을 쓰는 것(벡터화)입니다.

import numpy as np
t = np.linspace(0, 10, 1001)              # 0~10 s, 1001점
x = np.exp(-0.2 * t) * np.cos(2 * t)      # 감쇠 진동 전체를 한 줄로
v = np.gradient(x, t)                      # 수치 미분
mask = np.abs(x) > 0.5                     # 조건으로 거르기
print(t[mask].max())                       # 진폭이 0.5보다 큰 마지막 시각

# 브로드캐스팅: 모양이 다른 배열끼리 자동으로 맞춰 연산
r = np.array([1.0, 2.0, 3.0])[:, None]     # (3, 1)
theta = np.linspace(0, np.pi, 5)[None, :]  # (1, 5)
X = r * np.cos(theta)                      # (3, 5) 격자

원소별 연산, 축(axis)에 따른 합·평균(x.mean(axis=0)), 불리언 마스크, 브로드캐스팅을 익히면 대부분의 자료 처리를 짧고 빠르게 쓸 수 있습니다.

1.1.2pandas

열마다 이름과 자료형이 다른 표(측정 일지, 여러 조건의 결과)는 pandas의 데이터프레임이 편합니다.

import pandas as pd
df = pd.read_csv("pendulum.csv")       # 열: L_m, T_s, group
df.head()                              # 앞 다섯 줄
df.describe()                          # 요약 통계
df = df.dropna()                       # 빈 값이 있는 행 버리기
df["g"] = 4 * np.pi**2 * df["L_m"] / df["T_s"]**2   # 새 열
long = df[df["L_m"] > 0.5]             # 조건으로 거르기
summary = df.groupby("group")["g"].agg(["mean", "std", "count"])
summary["sem"] = summary["std"] / np.sqrt(summary["count"])
print(summary)
  • 열 하나는 NumPy 배열처럼 다룰 수 있다(df["T_s"].to_numpy()).
  • groupby로 조건별 평균과 표준오차를 한 번에 구한다.
  • 빈 값(NaN), 단위가 섞인 열, 중복 행을 먼저 확인하는 것이 자료 정리의 절반이다.
예제 1.1.1

위 코드에서 조마다 측정 횟수가 다르다. 전체 평균 \(g\)를 조 평균의 단순 평균으로 구하면 어떤 문제가 있는가?

풀이. 측정이 적은 조와 많은 조가 같은 무게를 받습니다. 개별 측정을 모두 평균하거나, 조 평균을 표준오차의 역제곱으로 가중 평균(\(w_i = 1/\sigma_i^2\))해야 합니다.

요약
  1. NumPy: 벡터화, 축 연산, 마스크, 브로드캐스팅.
  2. pandas: read_csv, 거르기, 새 열, groupby로 요약.
