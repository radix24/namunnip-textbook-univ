통계 그래프로 분포와 상관 보기

본문
이 절에서 배울 것
  • 히스토그램, 상자 그림, 산점도, 산점도 행렬로 자료를 빠르게 살핀다.
  • 요약 통계만으로는 보이지 않는 구조를 그래프로 찾는다.
먼저 알아야 할 것
  • 기술통계와 그래프 (공통7 1.2절), matplotlib (공통11 5.3절).

1.2.1먼저 그려 본다

평균, 분산, 상관계수가 똑같은데 산점도는 전혀 다른 자료들이 있습니다(앤스컴의 네 자료가 유명한 예). 숫자 요약은 자료를 압축하면서 정보를 버리므로, 분석 전에 반드시 그림을 봅니다.

import seaborn as sns
import matplotlib.pyplot as plt
sns.histplot(df["g"], bins=20)                    # 분포 모양, 이상값
sns.boxplot(data=df, x="group", y="g")            # 조별 비교
sns.scatterplot(data=df, x="L_m", y="T_s", hue="group")
sns.pairplot(df[["L_m", "T_s", "g"]])             # 모든 쌍의 산점도
plt.show()

1.2.2무엇을 보나

  • 분포 모양: 봉우리가 하나인지 둘인지(두 조건이 섞였을 수 있음), 치우쳤는지, 꼬리가 긴지.
  • 이상값: 측정 실수인지, 실제 현상인지 기록을 확인한다. 이유 없이 지우지 않는다.
  • 관계: 직선인지 곡선인지. 곡선이면 변수를 변환(로그, 제곱근)해 직선이 되는지 본다. 진자의 \(T\)와 \(L\)은 \(\log T\) 대 \(\log L\)에서 기울기 1/2인 직선이다.
  • 숨은 변수: 색(hue)으로 조나 날짜를 구분하면, 전체로는 없던 관계가 조마다 나타나거나 반대로 될 수 있다(심슨의 역설).
예제 1.2.1

진자 실험에서 \(g\)의 히스토그램이 9.6과 9.9 근처에 봉우리가 둘 있었다. 무엇을 의심해야 하는가?

풀이. 두 조건이 섞였을 가능성이 큽니다. 조별(측정자, 장비, 진폭) 상자 그림을 그려 봅니다. 예를 들어 한 조만 큰 진폭으로 재어 주기가 길게 나왔다면(물리1 3.3절의 진폭 의존성) \(g\)가 작게 계산됩니다.

그래프의 축 이름과 단위, 오차 막대(무엇의 오차인지: 표준편차인지 표준오차인지)를 밝히는 것도 결과를 정직하게 전달하는 일입니다.

요약
  1. 요약 통계 전에 히스토그램, 상자 그림, 산점도를 본다.
  2. 분포 모양, 이상값, 곡선 관계, 숨은 변수를 확인한다.
