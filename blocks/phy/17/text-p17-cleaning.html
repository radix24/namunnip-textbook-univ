자료 정리: 빈 값, 단위, 이상값

본문
이 절에서 배울 것
  • 빈 값, 단위가 섞인 열, 중복 행을 찾아 정리한다.
  • 이상값을 중앙값과 MAD 같은 튼튼한 통계로 찾고, 지우기 전에 기록으로 확인한다.
먼저 알아야 할 것
  • 데이터프레임 (1.2절), 기술통계 (공통7 1.2절).

1.3.1먼저 점검할 것

분석의 절반은 자료 정리입니다. 계산을 시작하기 전에 다음을 확인합니다.

df.info()                       # 열마다 자료형과 빈 값이 아닌 개수
df.isna().sum()                 # 열마다 빈 값(NaN) 개수
df.duplicated().sum()           # 똑같은 행의 개수
df["L_m"].describe()            # 최솟값·최댓값이 말이 되는지
  • 빈 값: 버릴지(dropna), 채울지 정한다. 측정 실패를 평균으로 채우면 분산이 작아 보이므로, 물리 자료에서는 보통 버리고 몇 개를 버렸는지 적는다.
  • 단위: cm와 m가 섞이거나, 숫자 열에 문자("1.2 s")가 섞이면 자료형이 문자열이 된다. 단위를 열 이름에 적고(L_m) 하나로 맞춘다.
  • 중복: 같은 측정이 두 번 들어가면 그 측정에 두 배 무게가 실린다.

1.3.2이상값

평균과 표준편차는 이상값 하나에도 크게 흔들립니다. 중앙값과 중앙 절대 편차(MAD, 중앙값에서 벗어난 크기의 중앙값)는 자료의 절반 가까이가 엉망이어도 크게 바뀌지 않는 튼튼한(robust) 통계입니다. 정규분포에서는 표준편차 \(\approx 1.4826\times\text{MAD}\)이므로, 중앙값에서 \(3\times1.4826\times\text{MAD}\) 이상 벗어난 값을 이상값 후보로 봅니다.

후보를 찾으면 바로 지우지 말고 실험 기록을 봅니다. 기록 실수(단위, 자릿점)라면 고치고, 원인을 모르면 남긴 채로 분석한 결과와 뺀 결과를 함께 보고합니다. 이상값이 새로운 현상의 신호인 경우도 있습니다.

요약
  1. info, isna, duplicated, describe로 먼저 점검.
  2. 빈 값은 보통 버리고 개수를 기록. 단위는 열 이름에 적고 통일.
  3. 이상값은 중앙값·MAD로 찾고, 기록을 확인한 뒤 처리.

1.3.3연습문제

기본

  1. 자료 1, 2, 3, 4, 100의 평균과 중앙값은?
    답

    평균 22, 중앙값 3.

  2. 자료 9.8, 9.9, 10.0, 10.1, 10.2의 MAD는?
    답

    중앙값 10.0, 편차 크기 0.2, 0.1, 0, 0.1, 0.2의 중앙값 0.1.
