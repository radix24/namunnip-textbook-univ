2.1.1가중 최소제곱

측정값 \(y_i \pm \sigma_i\)에 모형 \(f(x; \boldsymbol\theta)\)를 맞출 때, 오차가 작은 점에 더 큰 무게를 주어

\[\chi^2(\boldsymbol\theta) = \sum_i\left(\frac{y_i - f(x_i; \boldsymbol\theta)}{\sigma_i}\right)^2\]

을 최소로 하는 \(\boldsymbol\theta\)를 찾습니다. 오차가 정규분포이면 이것이 가능도 최대 추정과 같습니다. 모형이 매개변수에 비선형이면(\(Ae^{-t/\tau}\cos(\omega t + \phi)\) 같은) 반복 계산(레벤버그-마쿼트 방법)으로 최솟값을 찾고, 처음 추측값이 필요합니다.

from scipy.optimize import curve_fit
def model(t, A, tau, w, phi):
    return A * np.exp(-t / tau) * np.cos(w * t + phi)

p0 = [1.0, 5.0, 2.0, 0.0]                          # 처음 추측
popt, pcov = curve_fit(model, t, y, p0=p0, sigma=sig, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))                      # 각 매개변수의 표준 불확도
for name, v, e in zip(["A", "tau", "w", "phi"], popt, perr):
    print(f"{name} = {v:.4f} ± {e:.4f}")

absolute_sigma=True는 \(\sigma_i\)를 실제 측정 오차로 쓴다는 뜻입니다. False(기본값)이면 맞춤의 잔차 크기로 오차 규모를 다시 맞춥니다. 어느 쪽인지 밝혀야 합니다.

요약
  1. \(\chi^2 = \sum((y - f)/\sigma)^2\) 최소화, 비선형은 반복법과 처음 추측.
  2. absolute_sigma=True는 측정 오차를 그대로 쓴다. 공분산과 상관은 2.2절.
