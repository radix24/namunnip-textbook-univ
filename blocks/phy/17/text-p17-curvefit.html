비선형 곡선 적합과 매개변수 불확도

본문

  • 측정 오차를 가중치로 넣은 최소제곱으로 비선형 모형을 맞춘다.

먼저 알아야 할 것
  • 최소제곱 직선 (공통11 5.3절), 불확도 전파 (물리2 1.3절).

2.1.1가중 최소제곱

측정값 \(y_i \pm \sigma_i\)에 모형 \(f(x; \boldsymbol\theta)\)를 맞출 때, 오차가 작은 점에 더 큰 무게를 주어

\[\chi^2(\boldsymbol\theta) = \sum_i\left(\frac{y_i - f(x_i; \boldsymbol\theta)}{\sigma_i}\right)^2\]

을 최소로 하는 \(\boldsymbol\theta\)를 찾습니다. 오차가 정규분포이면 이것이 가능도 최대 추정과 같습니다. 모형이 매개변수에 비선형이면(\(Ae^{-t/\tau}\cos(\omega t + \phi)\) 같은) 반복 계산(레벤버그-마쿼트 방법)으로 최솟값을 찾고, 처음 추측값이 필요합니다.

from scipy.optimize import curve_fit
def model(t, A, tau, w, phi):
    return A * np.exp(-t / tau) * np.cos(w * t + phi)

p0 = [1.0, 5.0, 2.0, 0.0]                          # 처음 추측
popt, pcov = curve_fit(model, t, y, p0=p0, sigma=sig, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))                      # 각 매개변수의 표준 불확도
for name, v, e in zip(["A", "tau", "w", "phi"], popt, perr):
    print(f"{name} = {v:.4f} ± {e:.4f}")

absolute_sigma=True는 \(\sigma_i\)를 실제 측정 오차로 쓴다는 뜻입니다. False(기본값)이면 맞춤의 잔차 크기로 오차 규모를 다시 맞춥니다. 어느 쪽인지 밝혀야 합니다.

2.1.2공분산 행렬

최솟값 근처에서 \(\chi^2\)는 매개변수에 대해 2차식이고, 그 곡률 행렬(헤세 행렬의 절반)의 역행렬이 공분산 행렬 \(\mathsf V\)입니다.

  • 대각 성분의 제곱근 = 각 매개변수의 표준 불확도.
  • 상관계수 \(\rho_{ij} = V_{ij}/\sqrt{V_{ii}V_{jj}}\). \(|\rho|\)가 1에 가까우면 두 매개변수를 자료가 따로 정하지 못한다(예: 원점에서 먼 좁은 구간만 잰 직선의 절편과 기울기).
  • 매개변수의 함수 \(g(\boldsymbol\theta)\)의 불확도를 전파할 때 상관을 넣어야 한다: \(\sigma_g^2 = \nabla g^{\mathsf T}\mathsf V\nabla g\).
예제 2.1.1

지수 붕괴 \(N_0e^{-t/\tau}\)를 \(t = 0\sim0.3\tau\)에서만 재어 맞추면 \(N_0\)와 \(\tau\)의 상관이 어떻게 되는가?

풀이. 짧은 구간에서는 곡선이 거의 직선 \(N_0(1 - t/\tau)\)이라, \(N_0\)를 키우고 \(\tau\)를 줄이는 것과 그 반대가 비슷하게 맞아 음의 상관이 큽니다(점마다 상대 오차가 같으면 구간 길이와 상관없이 약 \(-0.87\)). 더 중요한 것은 \(\tau\)의 불확도가 구간 길이에 반비례해 커진다는 점입니다. \(\tau\)의 여러 배까지 재야 \(\tau\)가 잘 정해집니다. 아래 실습 카드에서 \(\chi^2\) 지형을 볼 수 있습니다.

요약
  1. \(\chi^2 = \sum((y - f)/\sigma)^2\) 최소화, 비선형은 반복법과 처음 추측.
  2. 공분산 행렬: 대각 → 불확도, 비대각 → 상관. 전파에 상관을 넣는다.

2.1.3연습문제

기본

  1. 맞춤 결과 \(a = 2.0 \pm 0.1\), \(b = 3.0 \pm 0.2\), \(\rho_{ab} = -0.9\)이다. \(a + b\)의 불확도는?
    답

    \(\sqrt{0.01 + 0.04 + 2(-0.9)(0.1)(0.2)} = \sqrt{0.014} \approx 0.12\). 상관을 무시하면 0.22로 크게 어림한다.
