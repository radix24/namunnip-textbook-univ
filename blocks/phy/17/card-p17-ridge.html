매개변수 하나로 보는 릿지 회귀의 줄어듦

릿지 회귀 · 정칙화 세기 · 편향과 분산

출발점

원점을 지나는 직선 \(y = \theta x\)를 오차가 같은 자료에 맞출 때, \(\sum(y_i - \theta x_i)^2 + \alpha\theta^2\)를 최소로 하는 값은 \(\hat\theta = \frac{\sum x_iy_i}{\sum x_i^2 + \alpha}\)입니다(4.4절).

문제 해결 전략 · 닫힌 식으로 줄어듦 보기
  1. \(\alpha = 0\)의 보통 최소제곱 값을 구한다.
  2. 여러 \(\alpha\)에서 \(\hat\theta\)를 구해 줄어듦을 본다.
  3. 줄어듦이 편향과 분산에 주는 영향을 해석한다.

\(\sum x_i^2 = 10\), \(\sum x_iy_i = 20\)인 자료에서 \(\alpha = 0, 1, 10\)일 때 \(\hat\theta\)를 구하여라. 잡음 때문에 \(\sum x_iy_i\)가 20에서 ±4만큼 흔들린다면 \(\hat\theta\)의 흔들림은 각각 얼마인가?

풀이

  1. \(\alpha = 0\): \(20/10 = 2.0\). \(\alpha = 1\): \(20/11 = 1.82\). \(\alpha = 10\): \(20/20 = 1.0\).
    분모가 커짐.
  2. 흔들림: \(\pm4/10 = \pm0.40\), \(\pm4/11 = \pm0.36\), \(\pm4/20 = \pm0.20\).
    분산이 줄어듦.
  3. \(\alpha\)가 커지면 흔들림(분산)은 줄지만 값이 참값에서 0 쪽으로 치우친다(편향).
    편향-분산 맞바꿈.

의미

정칙화는 약간의 편향을 받아들이는 대신 분산을 줄여 새 자료에 대한 예측 오차를 줄이는 방법이다. 매개변수가 많고 자료가 적을수록 분산이 크므로 정칙화가 더 도움이 된다. 알맞은 \(\alpha\)는 계산으로 정하지 않고 교차검증으로 고른다.

검산

\(\alpha \to 0\)이면 보통 최소제곱 값 2.0으로, \(\alpha \to \infty\)이면 0으로 가서 두 극한이 맞다.
