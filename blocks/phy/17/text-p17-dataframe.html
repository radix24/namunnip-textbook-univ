pandas 데이터프레임으로 표 자료 다루기

본문
이 절에서 배울 것
  • pandas 데이터프레임으로 표 자료를 읽고, 열을 만들고, 조건으로 거른다.
  • groupby로 조건별 평균과 표준오차를 구하고, 가중 평균이 필요한 경우를 안다.
먼저 알아야 할 것
  • NumPy 배열 (1.1절).

1.2.1데이터프레임

열마다 이름과 자료형이 다른 표(측정 일지, 여러 조건의 결과)는 pandas의 데이터프레임이 편합니다. 열 하나는 NumPy 배열처럼 계산할 수 있습니다(df["T_s"].to_numpy()).

import numpy as np
import pandas as pd
df = pd.read_csv("pendulum.csv")       # 열: L_m, T_s, group
df.head()                              # 앞 다섯 줄
df.describe()                          # 요약 통계
df["g"] = 4 * np.pi**2 * df["L_m"] / df["T_s"]**2   # 새 열
long = df[df["L_m"] > 0.5]             # 조건으로 거르기

1.2.2묶어서 요약하기

summary = df.groupby("group")["g"].agg(["mean", "std", "count"])
summary["sem"] = summary["std"] / np.sqrt(summary["count"])
print(summary)

groupby는 같은 값(조, 날짜, 장비)을 가진 행끼리 묶어 각 묶음에 같은 계산을 합니다. 표준편차를 측정 수의 제곱근으로 나누면 평균의 표준오차가 됩니다.

예제 1.2.1

위 코드에서 조마다 측정 횟수가 다르다. 전체 평균 \(g\)를 조 평균의 단순 평균으로 구하면 어떤 문제가 있는가?

풀이. 측정이 적은 조와 많은 조가 같은 무게를 받습니다. 개별 측정을 모두 평균하거나, 조 평균을 표준오차의 역제곱으로 가중 평균(\(w_i = 1/\sigma_i^2\), 2.1절)해야 합니다.

요약
  1. 데이터프레임: 이름 붙은 열, 열 단위 계산, 조건 거르기.
  2. groupby → 조건별 평균, 표준편차, 개수 → 표준오차.
  3. 조 평균을 합칠 때는 가중 평균.
