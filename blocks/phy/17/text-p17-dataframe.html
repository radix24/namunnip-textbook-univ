pandas 데이터프레임으로 표 자료 다루기

본문

세 조가 진자로 중력 가속도를 재어 길이, 주기, 조 이름을 한 파일에 모았다. 조마다 측정 횟수도 다르다. 조별 평균과 그 불확도를 구하고 셋을 합쳐 하나의 \(g\)를 내려면 어떻게 해야 할까? 조 평균 셋을 그냥 평균하면 될까?

먼저 알아야 할 것NumPy 배열(1.1절)을 쓴다.

1.2.1데이터프레임

측정 일지처럼 열마다 이름과 자료형이 다른 표는 pandas의 데이터프레임으로 다루면 편하다. 열 하나는 이름으로 꺼내 NumPy 배열처럼 계산할 수 있고, df["T_s"].to_numpy()로 배열 자체를 얻을 수도 있다. 아래 코드는 파일을 읽고, 내용을 훑어보고, 새 열을 만들고, 조건으로 행을 거른다.

import numpy as np
import pandas as pd
df = pd.read_csv("pendulum.csv")       # 열: L_m, T_s, group
df.head()                              # 앞 다섯 줄
df.describe()                          # 요약 통계
df["g"] = 4 * np.pi**2 * df["L_m"] / df["T_s"]**2   # 새 열
long = df[df["L_m"] > 0.5]             # 조건으로 거르기

여기서 describe()는 열마다 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값을 보여 주어 값의 범위가 말이 되는지 빨리 확인하게 해 준다. 또 새 열 g는 \(g = 4\pi^2L/T^2\)을 모든 행에 한 번에 계산한 것이다. 열 이름에 단위를 붙여 L_m, T_s처럼 쓰면 나중에 단위를 헷갈리지 않는다.

1.2.2묶어서 요약하기

같은 값을 가진 행끼리 묶어 각 묶음에 같은 계산을 하는 것이 groupby이다(그림 1). 조, 날짜, 장비처럼 조건이 여럿인 자료를 정리할 때 가장 많이 쓴다.

summary = df.groupby("group")["g"].agg(["mean", "std", "count"])
summary["sem"] = summary["std"] / np.sqrt(summary["count"])
print(summary)

표준편차를 측정 수의 제곱근으로 나누면 평균의 표준오차가 된다. 측정을 많이 한 조일수록 평균이 더 정확하다는 뜻이다. 그렇다면 처음 질문처럼 조 평균 셋을 합칠 때 측정 수가 다른 것을 어떻게 반영할까?

예제 1.2.1

위 코드에서 조마다 측정 횟수가 다르다. 전체 평균 \(g\)를 조 평균의 단순 평균으로 구하면 어떤 문제가 있는가?

풀이. 측정이 3번인 조와 30번인 조가 같은 무게를 받는다. 따라서 개별 측정을 모두 모아 평균하거나, 조 평균을 표준오차의 역제곱 \(w_i = 1/\sigma_i^2\)로 가중 평균해야 한다(2.1절). 가중 평균의 표준오차는 \(1/\sqrt{\sum w_i}\)이다. 가령 조 평균의 표준오차가 0.02, 0.02, 0.04이면 무게는 2500, 2500, 625이고 합친 평균의 표준오차는 \(1/\sqrt{5625} \approx 0.013\)이다.

흔한 오해std()가 돌려주는 값을 평균의 불확도로 쓰기 쉽지만, 그것은 측정 하나하나가 흩어진 정도이다. 평균의 불확도는 그것을 \(\sqrt n\)으로 나눈 표준오차이다. 또 pandas의 std()는 \(n - 1\)로 나누고 NumPy의 np.std()는 기본값이 \(n\)으로 나누므로, 측정 수가 적을 때 둘이 다르게 나온다.
마무리

데이터프레임은 이름 붙은 열로 표 자료를 담고, 열 단위 계산과 조건 거르기를 한 줄로 해 준다. groupby로 조건별 평균, 표준편차, 개수를 구하고 표준편차를 \(\sqrt n\)으로 나누어 표준오차를 얻는다. 처음 질문처럼 측정 수가 다른 조 평균을 합칠 때는 단순 평균 대신 표준오차의 역제곱으로 가중 평균한다.
