CO의 회전선으로 결합 길이 구하기

강체 회전자 · 선택 규칙 · 전파 천문

출발점

\(\ell = 0 \to 1\) 회전 흡수선의 에너지는 \(\Delta E = \hbar^2/I\)이고, \(I = \mu r_0^2\)입니다(1.3절). 일산화탄소(¹²C¹⁶O)의 이 선은 115.27 GHz에서 관측된다.

문제 해결 전략 · 진동수 → 관성 모멘트 → 결합 길이
  1. 진동수에서 광자 에너지 \(h u\)를 구한다.
  2. \(I = \hbar^2/h u\)로 관성 모멘트를 구한다.
  3. 환산 질량으로 나누어 결합 길이를 구한다.

(가) ¹²C¹⁶O의 결합 길이를 구하여라. (나) \(\ell = 3 \to 4\) 선의 진동수는? (\(1\ \text{u} = 1.661\times10^{-27}\) kg)

풀이

  1. (가) \(h\nu = 6.626\times10^{-34}\times1.1527\times10^{11} = 7.64\times10^{-23}\) J (0.477 meV).
    광자 에너지.
  2. \(I = \hbar^2/h\nu = (1.055\times10^{-34})^2/7.64\times10^{-23} = 1.46\times10^{-46}\) kg·m².
    \(\Delta E = \hbar^2/I\).
  3. \(\mu = \frac{12\times16}{28} = 6.86\) u \(= 1.14\times10^{-26}\) kg. \(r_0 = \sqrt{I/\mu} = 1.13\times10^{-10}\) m = 0.113 nm.
    환산 질량.
  4. (나) \(\Delta E \propto \ell + 1 = 4\)이므로 \(4\times115.27 = 461\) GHz.
    같은 간격.

의미

CO는 분자 구름에서 가장 흔한 극성 분자이고, 115 GHz 선은 지구 대기를 잘 통과해 전파 망원경으로 관측된다. 이 선의 세기와 도플러 이동으로 별이 태어나는 차가운 수소 분자 구름(수소 자체는 거의 빛을 내지 않음)의 분포와 운동을 지도로 그린다.

검산

얻은 0.113 nm는 탄소와 산소의 공유 결합(삼중 결합) 길이로 알맞다. 단위: \(\sqrt{\text{kg·m}^2/\text{kg}} = \text{m}\).
