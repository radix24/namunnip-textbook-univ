LS 결합과 항 기호

본문

탄소 원자의 바깥 전자 두 개는 2p 오비탈에 들어 있다. 두 전자가 놓일 수 있는 방법은 15가지인데, 실제 스펙트럼에서는 에너지가 다른 몇 개의 준위로 묶인다. 그 묶음을 어떻게 이름 붙이고, 어느 것이 가장 낮은가?

먼저 알아야 할 것스핀-궤도 결합(6.1절), Pauli 배타 원리와 주기율표(현대물리학(1)의 원자 구조 절)를 쓴다. Beiser 7장 5~8절을 따른다.

6.2.1LS 결합

전자가 여럿이면 각운동량을 더하는 순서가 문제이다. 가벼운 원자에서는 전자 사이의 정전기적 반발이 각 전자의 스핀-궤도 결합보다 훨씬 크다. 그러면 먼저 궤도 각운동량끼리 \(\mathbf L = \sum\mathbf l_i\), 스핀끼리 \(\mathbf S = \sum\mathbf s_i\)를 더하고, 마지막에 \(\mathbf J = \mathbf L + \mathbf S\)를 만든다. 이것이 LS 결합(Russell-Saunders 결합)이다. 각 준위는 항 기호 \(^{2S+1}L_J\)로 쓰고, \(L = 0, 1, 2, 3\)을 S, P, D, F로 적는다. \(2S + 1\)은 다중도이다.

6.2.2같은 오비탈의 전자: Pauli 원리가 고르는 항

두 2p 전자의 \(l_1 = l_2 = 1\)이면 \(L = 0, 1, 2\), \(S = 0, 1\)이 가능해 보인다. 하지만 같은 \(n, l\)의 전자는 Pauli 원리 때문에 모든 조합이 허락되지 않는다. 전체 파동함수가 반대칭이어야 하므로, 공간 부분이 대칭인 \(L = 0, 2\)는 스핀 단일항 \(S = 0\)과, 반대칭인 \(L = 1\)은 스핀 삼중항 \(S = 1\)과만 짝지어진다. 그러면 남는 항은 \(^1S\), \(^1D\), \(^3P\)이고, 상태 수 \(1 + 5 + 9 = 15\)가 처음 센 15가지와 맞는다.

규칙 6.2.1 (Hund 규칙)

같은 배치의 항 가운데 (가) \(S\)가 가장 큰 것이 가장 낮다. (나) 그중 \(L\)이 가장 큰 것이 가장 낮다. (다) 껍질이 절반 이하로 차 있으면 \(J\)가 가장 작은 것이, 절반보다 많이 차 있으면 \(J\)가 가장 큰 것이 가장 낮다.

첫 규칙의 이유는 앞의 대칭성에서 나온다. 스핀이 나란하면 공간 파동함수가 반대칭이라 두 전자가 서로 피하고, 반발 에너지가 줄어든다. 따라서 탄소의 바닥 항은 \(^3P\)이고, 2p 껍질(정원 6)이 절반 이하로 찼으므로 바닥 준위는 \(^3P_0\)이다.

예제 6.2.2

산소(2p⁴)의 바닥 준위를 Hund 규칙으로 구하여라.

풀이. 2p⁴는 2p 껍질에서 구멍 두 개와 같아 탄소와 같은 항 \(^1S\), \(^1D\), \(^3P\)를 가진다. 바닥 항은 \(^3P\)이다. 껍질이 절반보다 많이 찼으므로 \(J\)가 가장 큰 \(J = 2\)가 가장 낮고, 바닥 준위는 \(^3P_2\)이다. \(m_l\) 칸에 전자를 넣어 확인할 수도 있다. \(m_l = 1, 0, -1\)에 위 스핀을 먼저 하나씩 넣고 넷째를 \(m_l = 1\)에 아래 스핀으로 넣으면 \(M_L = 1\), \(M_S = 1\)이라 \(L = S = 1\)이다.

마무리

가벼운 원자에서는 궤도와 스핀을 따로 더한 뒤 \(\mathbf J\)를 만드는 LS 결합으로 준위를 \(^{2S+1}L_J\)로 분류한다. 같은 오비탈의 전자는 Pauli 원리 때문에 허락되는 항이 줄어든다. Hund 규칙은 스핀이 크고 각운동량이 큰 항이 가장 낮다고 말하며, 껍질이 절반보다 적게 찼는지 많이 찼는지가 \(J\)의 순서를 정한다.

기본

    답

    세 전자를 \(m_l = 1, 0, -1\)에 위 스핀으로 넣으면 \(S = 3/2\), \(L = 0\)이므로 \(^4S_{3/2}\).

응용

  1. \(^3P\) 항의 세 준위 사이 간격의 비가 \(1 : 2\)(Landé 간격 규칙)임을 \(\mathbf L\cdot\mathbf S\)로 보여라.
    답
