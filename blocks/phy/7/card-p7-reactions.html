보존 법칙과 수명으로 상호작용 가려내기

보존량 · 기묘도 · 수명 · 문제 해결 전략

출발점

모든 반응에서 에너지, 운동량, 전하, 바리온 수, 맛별 렙톤 수가 보존된다. 기묘도는 강한·전자기 상호작용에서 보존되고 약한 상호작용에서만 1만큼 바뀔 수 있다. 수명은 강한 상호작용 \(\sim10^{-23}\) s, 전자기 \(\sim10^{-20}\)~\(10^{-16}\) s, 약한 상호작용 \(10^{-13}\) s 이상입니다(5.3절).

문제 해결 전략 · 보존량 표 만들기
  1. 반응 전후의 전하, 바리온 수 \(B\), 렙톤 수 \(L_e\), \(L_\mu\), 기묘도 \(S\)를 표로 적는다.
  2. 절대 보존량이 깨지면 금지.
  3. \(S\)가 바뀌면 약한 상호작용, 광자나 렙톤이 관여하면 전자기·약한 상호작용으로 좁힌다.

다음 과정이 가능한지, 가능하면 어떤 상호작용인지 판정하여라. (가) \(\pi^+ \to \mu^+ + \nu_\mu\) (나) \(K^- + p \to \Omega^- + K^+ + K^0\) (다) \(n \to p + e^- + \nu_e\) (라) \(\Sigma^0 \to \Lambda^0 + \gamma\) (수명 \(7\times10^{-20}\) s)

풀이

  1. (가) 전하 +1 = +1, \(L_\mu\): 0 = −1 + 1. 가능. 렙톤이 나오고 중성미자가 있으므로 약한 상호작용(수명 \(2.6\times10^{-8}\) s).
    중성미자 = 약.
  2. (나) 전하 0 = −1 + 1 + 0, \(B\) 1 = 1, \(S\): −1 = −3 + 1 + 1. 모두 보존되어 강한 상호작용으로 가능. Ω⁻가 1964년 이 반응으로 발견되었다.
    K⁻ = s\(\bar{\text{u}}\), K⁺, K⁰는 \(S = +1\).
  3. (다) \(L_e\): 0 → +1 + 1 = 2. 금지(\(\bar\nu_e\)여야 함).
    렙톤 수.
  4. (라) \(S\), \(B\), 전하 보존, 광자가 나오고 수명이 \(10^{-20}\) s 규모라 전자기 상호작용.
    광자 = 전자기.

의미

보존 법칙은 무엇이 일어날 수 있는지를, 수명은 어떤 힘이 일으키는지를 알려 준다. 같은 기묘 입자라도 기묘도를 바꾸지 않는 붕괴(Σ⁰ → Λ⁰ + γ)는 빠르고, 바꾸는 붕괴(Λ⁰ → p + π⁻)는 \(10^{-10}\) s로 느린 것이 그 예이다.

검산

(나)에서 쿼크를 세면 왼쪽 s\(\bar{\text{u}}\) + uud에 s가 1개, 오른쪽 sss + u\(\bar{\text{s}}\) + d\(\bar{\text{s}}\)에 s 3개와 \(\bar{\text{s}}\) 2개로 알짜 s 1개라, 강한 상호작용이 s\(\bar{\text{s}}\) 쌍을 두 개 만든 것이다.
