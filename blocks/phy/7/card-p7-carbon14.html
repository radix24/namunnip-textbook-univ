방사성 탄소 연대 측정

반감기 · 붕괴 상수 · 문제 해결 전략

출발점

방사성 핵의 수는 \(N = N_0e^{-\lambda t}\), 반감기 \(t_{1/2} = \ln2/\lambda\)로 줄어듭니다. 살아 있는 생물은 대기와 같은 비율의 \(^{14}\text{C}\)를 가지고, 죽은 뒤부터 줄어듭니다.

문제 해결 전략 · 붕괴 연대 측정
  1. 지금 비율과 처음 비율의 비 \(N/N_0\)(또는 방사능 비)를 구한다.
  2. \(t = \frac{t_{1/2}}{\ln2}\ln\frac{N_0}N\).
  3. 반감기의 몇 배인지로 어림을 확인한다.
  4. 측정 가능한 범위(반감기의 약 10배까지)를 판단한다.

어떤 나무 조각의 \(^{14}\text{C}\) 방사능이 살아 있는 나무의 25%이다. 나무가 죽은 지 얼마나 되었나? (\(t_{1/2} = 5730\) 년) 방사능이 1%라면?

풀이

  1. 25% = \((1/2)^2\): 반감기 두 번, \(2\times5730 = 11460\) 년.
    바로 보이는 경우.
  2. 일반식: \(t = \frac{5730}{0.693}\ln4 = 8268\times1.386 = 11460\) 년.
    같은 값.
  3. 1%: \(t = 8268\times\ln100 = 8268\times4.605 \approx 38100\) 년.
    반감기 약 6.6번.
  4. 5만 년이 넘으면 남은 양이 너무 적어 측정이 어렵다.
    측정 한계.

의미

대기 중 \(^{14}\text{C}\) 비율이 시대마다 조금 달라 실제로는 나이테 등으로 보정합니다. 지질 연대처럼 더 긴 시간은 반감기가 긴 U-Pb, K-Ar 방법을 씁니다.

검산

\(e^{-\lambda t}\)에 \(t = 11460\): \(\lambda = 1.21\times10^{-4}\)/년, \(e^{-1.386} = 0.25\). 맞습니다.
