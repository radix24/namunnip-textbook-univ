4.2.1붕괴 법칙

각 핵이 단위 시간에 붕괴할 확률 \(\lambda\)가 일정하므로 \(\frac{dN}{dt} = -\lambda N\), \(N = N_0e^{-\lambda t}\)입니다.

  • 반감기 \(t_{1/2} = \frac{\ln2}{\lambda}\), 평균 수명 \(\tau = \frac1\lambda = 1.44t_{1/2}\).
  • 방사능 \(R = \lambda N\), 단위 베크렐(Bq, 초당 1붕괴).
예제 4.2.1

라듐-226(반감기 1600년) 1 g의 방사능은?

풀이. \(N = \frac{6.022\times10^{23}}{226} = 2.66\times10^{21}\). \(\lambda = \frac{0.693}{1600\times3.156\times10^7\ \text{s}} = 1.37\times10^{-11}\) s⁻¹. \(R \approx 3.7\times10^{10}\) Bq. 이것이 옛 단위 1 퀴리(Ci)의 기원입니다.

4.2.2붕괴 사슬

어미 핵(A, \(\lambda_A\))이 딸 핵(B, \(\lambda_B\))으로, B가 다시 붕괴하면

\[\frac{dN_B}{dt} = \lambda_AN_A - \lambda_BN_B.\]

어미의 반감기가 딸보다 훨씬 길면(\(\lambda_A \ll \lambda_B\)) 시간이 조금 지나 \(\lambda_BN_B = \lambda_AN_A\), 곧 두 방사능이 같아지는 영년 평형에 이릅니다. 우라늄-238에서 납-206까지 이어지는 자연 붕괴 계열의 중간 핵들이 이런 평형에 있습니다. 라돈 기체가 땅에서 끊임없이 나오는 까닭입니다.

요약
  1. \(N = N_0e^{-\lambda t}\), \(t_{1/2} = \ln2/\lambda\), \(\tau = 1/\lambda\), \(R = \lambda N\).
  2. 긴 어미-짧은 딸: 영년 평형 \(\lambda_BN_B = \lambda_AN_A\).

4.2.3연습문제

기본

    \(N_{\text{Rn}}/N_{\text{Ra}} = t_{1/2,\text{Rn}}/t_{1/2,\text{Ra}} = 3.82/(1600\times365.25) \approx 6.5\times10^{-6}\).
