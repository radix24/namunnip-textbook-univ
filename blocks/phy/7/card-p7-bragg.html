X선 회절로 결정 면 간격 구하기

Bragg 법칙 · 입방 결정 · 문제 해결 전략

출발점

결정 면에서 반사된 X선은 \(2d\sin\theta = n\lambda\)일 때 보강됩니다. 입방 결정에서 Miller 지수 \((hkl)\) 면 간격은 \(d = a/\sqrt{h^2 + k^2 + l^2}\)입니다.

문제 해결 전략 · Bragg 회절 해석
  1. 회절 각 \(\theta\)(입사빔과 면 사이 각, \(2\theta\)가 아님)를 확인한다.
  2. \(d = n\lambda/2\sin\theta\)로 면 간격을 구한다.
  3. \(d = a/\sqrt{h^2 + k^2 + l^2}\)로 격자 상수를 구한다.
  4. 밀도나 알려진 값과 비교한다.

Cu K\(_\alpha\) X선(0.154 nm)으로 NaCl 결정(면심 입방, \(a = 0.564\) nm)을 비출 때 (200) 면의 1차 회절 각은?

풀이

  1. \(d_{200} = 0.564/\sqrt4 = 0.282\) nm.
    \(h^2 + k^2 + l^2 = 4\).
  2. \(\sin\theta = \frac{0.154}{2\times0.282} = 0.273\).
    1차, \(n = 1\).
  3. \(\theta = 15.8°\), 검출기 각 \(2\theta = 31.7°\).
    회절계는 \(2\theta\)를 읽는다.
  4. (100) 면 반사는 면심 입방에서 지워져 나타나지 않는다.
    구조 인자(소멸 규칙).

의미

X선 파장이 원자 간격과 같은 크기라서 결정이 회절격자 역할을 합니다. 회절 봉우리의 위치는 격자 상수를, 어떤 봉우리가 빠지는지는 결정 구조(단순, 체심, 면심)를 알려 줍니다.

검산

NaCl 밀도: 단위 세포에 NaCl 4쌍, \(\frac{4\times58.4\times1.66\times10^{-27}}{(0.564\times10^{-9})^3} = 2.16\times10^3\) kg/m³. 실제 2.17 g/cm³와 맞습니다.
