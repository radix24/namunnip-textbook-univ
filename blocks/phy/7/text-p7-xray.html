  • 결정 구조 (3.1절), 특성 X선 (물리3 5.5절), 간섭 (공통4 11.1절).

3.2.1브래그 조건

파장이 원자 간격과 비슷한 X선(구리 \(K_\alpha\) 0.154 nm, 물리3 5.5절)을 결정에 쬐면, 간격 \(d\)인 평행한 원자면들에서 반사된 X선 사이에 경로차 \(2d\sin\theta\)가 생깁니다(\(\theta\)는 면과 X선이 이루는 각). 이것이 파장의 정수배일 때만 보강 간섭하므로

\[2d\sin\theta = n\lambda\quad(\text{브래그 조건}).\]

검출기는 들어온 방향에서 \(2\theta\)만큼 꺾인 곳에 봉우리를 봅니다. \(\sin\theta \le 1\)이므로 \(\lambda \le 2d\)여야 회절이 일어나고, 가시광선(수백 nm)으로는 원자 간격(0.1 nm 규모)을 볼 수 없습니다.

3.2.2밀러 지수와 면 간격

결정 속 원자면은 세 축을 자르는 점의 역수를 정수로 맞춘 밀러 지수 \((hkl)\)로 나타냅니다. 입방 격자에서 면 간격은

\[d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}.\]

\(n\)차 회절은 \((nh\,nk\,nl)\)면의 1차 회절로 볼 수 있어, 보통 \(n = 1\)로 두고 지수에 포함시킵니다.

예제 3.2.1

구리 \(K_\alpha\)(0.154 nm)로 NaCl(\(a = 0.564\) nm)의 (200)면 1차 회절각은?

풀이. \(d_{200} = 0.564/2 = 0.282\) nm. \(\sin\theta = 0.154/0.564 = 0.273\), \(\theta \approx 15.8°\) (검출기 각 \(2\theta \approx 31.7°\)).

3.2.3소멸 규칙과 구조 판별

단위 세포 안에 원자가 여럿 있으면, 어떤 \((hkl)\)에서는 세포 안 원자들의 반사가 서로 상쇄되어 봉우리가 사라집니다.

  • sc: 모든 \((hkl)\)이 나타난다.
  • bcc: \(h + k + l\)이 짝수인 것만 (110), (200), (211), ...
  • fcc: \(h, k, l\)이 모두 짝수이거나 모두 홀수인 것만 (111), (200), (220), (311), ...

여러 방향을 향한 작은 결정 가루에 X선을 쬐는 분말법에서는 여러 각에 봉우리가 한꺼번에 나타나고, 봉우리 각의 \(\sin^2\theta\) 비가 \(h^2 + k^2 + l^2\)의 비와 같아 구조와 격자 상수를 함께 알아냅니다(아래 예제).

요약
  1. 브래그 \(2d\sin\theta = n\lambda\), 검출기 각 \(2\theta\).
  2. 입방 \(d = a/\sqrt{h^2 + k^2 + l^2}\).
  3. 소멸 규칙: bcc는 \(h + k + l\) 짝수, fcc는 모두 짝수 또는 모두 홀수.

3.2.4연습문제

기본

  1. fcc 결정에서 처음 세 봉우리의 \(h^2 + k^2 + l^2\)은?
    답

    3, 4, 8 ((111), (200), (220)).

  2. bcc 결정에서 처음 세 봉우리의 \(h^2 + k^2 + l^2\)은?
    답

    2, 4, 6 ((110), (200), (211)).
