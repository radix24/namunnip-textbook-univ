슈뢰딩거 방정식과 정상 상태

본문
이 절에서 배울 것
  • 슈뢰딩거 방정식이 드브로이 관계와 에너지 보존에서 나오는 과정을 안다.
  • 변수 분리로 시간 무관 방정식을 얻고, 정상 상태의 뜻을 설명한다.
  • 파동함수가 만족해야 할 조건이 에너지 양자화로 이어지는 까닭을 안다.
먼저 알아야 할 것
  • 파동함수와 확률 해석 (4.1절), 드브로이 관계 (3.1절).

4.2.1슈뢰딩거 방정식

\[i\hbar\frac{\partial\Psi}{\partial t} = -\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2} + U(x)\Psi.\]

자유 입자의 평면파 \(e^{i(kx - \omega t)}\)가 \(E = \hbar\omega\), \(p = \hbar k\), \(E = p^2/2m\)을 만족하도록 만든 방정식입니다. 오른쪽 첫 항이 운동 에너지, 둘째 항이 퍼텐셜 에너지에 해당합니다. 뉴턴 방정식이 처음 위치와 속도로 미래를 정하듯, 슈뢰딩거 방정식은 처음 파동함수로 미래의 파동함수를 정합니다.

처음 보는 수학 · 편미분과 평면파로 확인하기 \(\frac{\partial\Psi}{\partial t}\)는 \(x\)를 고정하고 \(t\)로만, \(\frac{\partial^2\Psi}{\partial x^2}\)는 \(t\)를 고정하고 \(x\)로 두 번 미분한 것(편미분)입니다. 평면파 \(\Psi = e^{i(kx - \omega t)}\)를 넣어 보면 \(\frac{\partial\Psi}{\partial t} = -i\omega\Psi\), \(\frac{\partial^2\Psi}{\partial x^2} = -k^2\Psi\)이므로 (\(U = 0\)일 때) 왼쪽은 \(\hbar\omega\Psi\), 오른쪽은 \(\frac{\hbar^2k^2}{2m}\Psi\)입니다. \(E = \hbar\omega\), \(p = \hbar k\)로 읽으면 \(E = p^2/2m\)이 됩니다.

4.2.2정상 상태

\(U\)가 시간에 무관하면 \(\Psi = \psi(x)e^{-iEt/\hbar}\)로 분리됩니다. 넣으면 왼쪽이 \(E\Psi\)가 되고, 양변의 \(e^{-iEt/\hbar}\)를 지우면 시간 무관 방정식

\[-\frac{\hbar^2}{2m}\psi'' + U(x)\psi = E\psi\]

가 남습니다. 이 해를 정상 상태라 하며, \(|\Psi|^2 = |\psi|^2\)이 시간에 따라 변하지 않아 모든 기댓값이 일정합니다. 에너지가 정확히 \(E\)인 상태입니다. 에너지가 다른 두 정상 상태를 겹친 상태는 정상 상태가 아니며, 확률밀도가 두 에너지 차에 해당하는 진동수로 출렁입니다.

4.2.3좋은 파동함수의 조건과 양자화

받아들일 수 있는 \(\psi\)는

  • 연속이고, \(U\)가 유한한 곳에서 \(\psi'\)도 연속이다.
  • 규격화할 수 있다(멀리서 0으로 줄어든다).

입자가 퍼텐셜에 묶여 있으면 이 조건을 모두 만족하는 해가 특정한 \(E\)에서만 존재합니다. 그래서 묶인 상태의 에너지는 띄엄띄엄한 값만 가집니다. 줄의 양 끝을 고정하면 특정한 진동수의 정상파만 생기는 것(공통3 9.3절)과 같은 이유이며, 4.3절의 무한 우물에서 구체적으로 봅니다.

요약
  1. \(i\hbar\partial_t\Psi = -\frac{\hbar^2}{2m}\partial_x^2\Psi + U\Psi\).
  2. 정상 상태 \(\Psi = \psi e^{-iEt/\hbar}\): \(-\frac{\hbar^2}{2m}\psi'' + U\psi = E\psi\), \(|\Psi|^2\) 일정.
  3. 연속성과 규격화 조건 → 묶인 상태의 에너지 양자화.

4.2.4연습문제

기본

  1. \(\psi(x) = \cos kx\)가 \(U = 0\)인 시간 무관 방정식을 만족함을 보이고 \(E\)를 \(k\)로 나타내어라.
    답

    \(\psi'' = -k^2\cos kx\)이므로 \(-\frac{\hbar^2}{2m}(-k^2\psi) = E\psi\), \(E = \frac{\hbar^2k^2}{2m}\).

  2. 정상 상태에서 \(\langle x\rangle\)이 시간에 따라 변하지 않는 까닭은?
    답

    \(|\Psi|^2 = |\psi|^2\)이 시간에 무관해 \(\int x|\Psi|^2dx\)도 일정하기 때문이다.
