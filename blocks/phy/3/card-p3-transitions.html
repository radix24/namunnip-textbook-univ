n = 3에서 내려오는 수소의 선 고르기

선택 규칙 · 파장 계산 · 문제 해결 전략

출발점

수소의 에너지는 \(n\)에만 의존하므로(5.2절) 파장은 뤼드베리 식으로 정해지지만, 어떤 상태에서 어떤 상태로 내려갈 수 있는지는 선택 규칙 \(\Delta\ell = \pm1\)이 정한다. 처음 상태의 \(\ell\)에 따라 갈 수 있는 길이 달라진다.

문제 해결 전략 · 허용 전이 찾기
  1. 처음 상태와 아래쪽 상태를 \((n, \ell)\)로 모두 적는다.
  2. \(\Delta\ell = \pm1\)인 쌍만 남긴다.
  3. 남은 쌍의 파장을 \(\frac1\lambda = R_\infty\left(\frac1{n_f^2} - \frac1{n_i^2}\right)\)로 구한다.

수소의 \(n = 3\) 상태(3s, 3p, 3d)에서 바로 내려가는 허용 전이를 모두 찾고, 각각의 파장을 구하여라. 3s 상태의 원자는 바닥 상태까지 어떤 경로로 내려오는가? (\(R_\infty = 1.097\times10^7\) m⁻¹)

풀이

  1. 아래쪽 상태: 1s(\(\ell = 0\)), 2s(0), 2p(1).
    \(n = 1, 2\).
  2. 3s(\(\ell = 0\)) → 2p만 허용. 3p(1) → 1s, 2s 허용. 3d(2) → 2p만 허용.
    \(\Delta\ell = \pm1\).
  3. \(n = 3 \to 2\): \(\frac1\lambda = R_\infty(\frac14 - \frac19)\), \(\lambda = 656\) nm (3s→2p, 3p→2s, 3d→2p).
    발머 Hα.
  4. \(n = 3 \to 1\): \(\frac1\lambda = R_\infty(1 - \frac19)\), \(\lambda = 102.6\) nm (3p→1s).
    라이먼 β.
  5. 3s → 2p(656 nm) → 1s(121.6 nm). 바닥 상태로 바로 갈 수 없어 두 단계로 내려온다.
    2p → 1s는 \(\Delta\ell = -1\)로 허용.

의미

수소에서는 같은 \(n\)의 상태들이 같은 에너지를 가지므로 3s, 3p, 3d에서 나온 656 nm 선이 겹쳐 하나로 보인다. 전자가 여럿인 원자에서는 같은 \(n\)이라도 \(\ell\)에 따라 에너지가 달라 선이 여러 개로 나뉘고, 선택 규칙이 어느 선이 보일지를 정한다. 나트륨의 노란 D선(3p → 3s)이 그 예이다.

검산

\(1/(1.097\times10^7\times8/9) = 1.026\times10^{-7}\) m = 102.6 nm, \(1/(1.097\times10^7\times3/4) = 1.215\times10^{-7}\) m = 121.5 nm. 측정값(102.6 nm, 121.6 nm)과 맞다.
