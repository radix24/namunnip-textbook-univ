주어진 파동함수가 방정식을 만족하는지 확인하고 에너지 구하기

시간 무관 방정식 · 대입 · 문제 해결 전략

출발점

어떤 함수가 정상 상태인지 확인하려면 시간 무관 방정식에 넣어 \(\hat H\psi = E\psi\) 꼴, 곧 왼쪽이 "상수 × \(\psi\)"가 되는지 본다. 그 상수가 에너지이다. 모든 \(x\)에서 성립해야 하므로 \(x\)에 따라 달라지는 항은 서로 지워져야 한다.

문제 해결 전략 · 정상 상태 확인
  1. \(\psi'\), \(\psi''\)를 구한다.
  2. \(-\frac{\hbar^2}{2m}\psi'' + U\psi\)를 계산한다.
  3. \(x\)에 의존하는 항이 지워지도록 매개변수를 정하고, 남는 상수를 \(E\)로 읽는다.

조화 진동자 퍼텐셜 \(U(x) = \frac12m\omega^2x^2\)에서 \(\psi(x) = Ae^{-\alpha x^2}\)가 시간 무관 방정식의 해가 되려면 \(\alpha\)가 얼마여야 하는가? 그때의 에너지는?

풀이

  1. \(\psi' = -2\alpha x\psi\), \(\psi'' = (4\alpha^2x^2 - 2\alpha)\psi\).
    곱의 미분.
  2. \(-\frac{\hbar^2}{2m}\psi'' + U\psi = \left[-\frac{\hbar^2}{2m}(4\alpha^2x^2 - 2\alpha) + \frac12m\omega^2x^2\right]\psi\).
    방정식의 왼쪽.
  3. \(x^2\) 항이 지워지려면 \(\frac{2\hbar^2\alpha^2}{m} = \frac12m\omega^2\), 곧 \(\alpha = \frac{m\omega}{2\hbar}\).
    모든 \(x\)에서 성립.
  4. 남는 상수 \(E = \frac{\hbar^2\alpha}{m} = \frac12\hbar\omega\).
    \(\hat H\psi = E\psi\).

의미

조화 진동자의 바닥 상태는 가우스 함수이고, 에너지는 0이 아니라 \(\frac12\hbar\omega\)입니다(영점 에너지). 고전적으로는 가만히 멈춘 상태(에너지 0)가 가능하지만, 양자역학에서는 불확정성 원리 때문에 불가능합니다(3.3절). 4.4절에서 들뜬 상태까지 다룬다.

검산

단위: \(\alpha = m\omega/2\hbar\)는 kg·s⁻¹/(J·s) = m⁻²로 \(\alpha x^2\)이 단위가 없어야 한다는 것과 맞다. \(\hbar^2\alpha/m\)은 J²s²·m⁻²/kg = J. 맞다.
