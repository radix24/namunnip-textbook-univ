저지 전압 두 개로 일함수와 플랑크 상수 구하기

광전 효과 · 직선 맞춤 · 문제 해결 전략

출발점

\(eV_0 = hf - \phi\)는 \(V_0\)와 \(f\) 사이의 직선입니다. 기울기는 \(h/e\), 세로 절편은 \(-\phi/e\), 가로 절편은 문턱 진동수 \(f_0\)입니다. 두 점만 있어도 직선을 정할 수 있습니다.

문제 해결 전략 · 광전 효과 직선
  1. 파장을 진동수 \(f = c/\lambda\)로 바꾼다.
  2. 두 점의 기울기 \(\Delta V_0/\Delta f\)에 \(e\)를 곱해 \(h\)를 구한다.
  3. 한 점에 대입해 \(\phi\)를, \(f_0 = \phi/h\)로 문턱을 구한다.

어떤 금속에 파장 400 nm 빛을 비추면 저지 전압이 0.82 V, 300 nm 빛이면 1.86 V였다. (가) 플랑크 상수는? (나) 일함수(eV)와 문턱 파장은? (\(e = 1.602\times10^{-19}\) C)

풀이

  1. \(f_1 = 3.00\times10^8/400\times10^{-9} = 7.50\times10^{14}\) Hz, \(f_2 = 1.00\times10^{15}\) Hz.
    \(f = c/\lambda\).
  2. (가) 기울기 \(= (1.86 - 0.82)/(2.50\times10^{14}) = 4.16\times10^{-15}\) V·s. \(h = 1.602\times10^{-19}\times4.16\times10^{-15} = 6.66\times10^{-34}\) J·s.
    기울기 = \(h/e\).
  3. (나) \(\phi = hf_1 - eV_0 = 4.16\times10^{-15}\times7.50\times10^{14} - 0.82 = 3.12 - 0.82 = 2.30\) eV.
    eV 단위로 계산: \(hf/e\) [V].
  4. 문턱 파장 \(\lambda_0 = 1240/2.30 \approx 540\) nm(초록빛).
    \(hc = 1240\) eV·nm.

의미

일함수 2.3 eV는 나트륨(약 2.3 eV)에 가깝습니다. 540 nm보다 긴 빛(노랑, 빨강)은 아무리 세게 비춰도 전자가 나오지 않습니다. 실제 실험에서는 점을 여러 개 재고 최소제곱 직선을 맞추어 \(h\)의 불확도까지 구합니다(물리2 7.3절).

검산

300 nm 점으로 확인: \(hf_2/e = 4.16\times10^{-15}\times10^{15} = 4.16\) V, \(4.16 - 2.30 = 1.86\) V. 맞습니다. \(h\)도 정의값 \(6.626\times10^{-34}\)과 0.5% 안쪽입니다.
