한 사건을 다른 관성계로 옮기기

로런츠 변환 · 시공간 간격 · 문제 해결 전략

출발점

사건은 "언제, 어디서"의 네 숫자 \((t, x, y, z)\)이다. 로런츠 변환은 같은 사건을 다른 관성계에서 본 네 숫자를 준다. 계산 뒤에는 시공간 간격이 같은지로 검산한다.

문제 해결 전략 · 로런츠 변환 계산
  1. \(\beta\)와 \(\gamma\)를 구한다.
  2. \(ct\)를 길이 단위로 바꾸면 \(x' = \gamma(x - \beta\,ct)\), \(ct' = \gamma(ct - \beta x)\)로 대칭인 꼴이 된다.
  3. \((ct)^2 - x^2 = (ct')^2 - x'^2\)로 검산한다.

S'은 S에 대해 \(+x\) 방향으로 \(0.60c\)로 움직인다. S에서 \(t = 5.0\ \mu\)s, \(x = 1200\) m인 곳에서 전구가 켜졌다. S'에서 이 사건의 \(x'\)과 \(t'\)은? 갈릴레이 변환으로 구한 값과 비교하여라.

풀이

  1. \(\beta = 0.60\), \(\gamma = 1/\sqrt{1 - 0.36} = 1.25\). \(ct = 3.0\times10^8\times5.0\times10^{-6} = 1500\) m.
    시간을 길이로.
  2. \(x' = 1.25(1200 - 0.60\times1500) = 1.25\times300 = 375\) m.
    \(x' = \gamma(x - \beta ct)\).
  3. \(ct' = 1.25(1500 - 0.60\times1200) = 1.25\times780 = 975\) m, \(t' = 975/3.0\times10^8 = 3.25\ \mu\)s.
    \(ct' = \gamma(ct - \beta x)\).
  4. 갈릴레이: \(x' = 1200 - 900 = 300\) m, \(t' = 5.0\ \mu\)s. 위치는 25% 다르고 시간은 1.75 μs 다르다.
    \(\gamma = 1\), 시간 그대로.

의미

빛의 속력의 60%에서는 상대론 효과가 25% 수준으로 크다. 특히 S'의 시각에는 위치 \(x\)가 섞여 들어가(\(-\gamma\beta x/c\)), 같은 시각에 일어난 두 사건이라도 위치가 다르면 S'에서는 시각이 다르다. 이것이 1.3절의 동시성의 상대성이다.

검산

S: \(1500^2 - 1200^2 = 8.1\times10^5\) m². S': \(975^2 - 375^2 = 950\,625 - 140\,625 = 8.1\times10^5\) m². 시공간 간격이 같다.
