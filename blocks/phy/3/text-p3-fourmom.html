4-운동량과 불변 질량

본문
이 절에서 배울 것
  • 에너지와 운동량을 4-운동량으로 묶고 그 크기가 모든 관성계에서 같음을 안다.
  • 여러 입자 계의 불변 질량을 구하고 충돌·붕괴 문제에 쓴다.
  • 문턱 에너지와 붕괴 생성물의 불변 질량을 계산한다.
먼저 알아야 할 것
  • 상대론적 운동량과 에너지 (1.4절), 시공간 간격 (1.1절).

1.5.14-운동량

\((E/c, \mathbf p)\)는 \((ct, \mathbf r)\)처럼 로런츠 변환을 따르는 네 성분의 양(4-벡터)이고, 이를 4-운동량이라 합니다. 시공간 간격이 모든 관성계에서 같듯이

\[E^2 - (pc)^2 = (mc^2)^2\]

도 모든 관성계에서 같습니다. 1.4절의 에너지-운동량 관계가 바로 4-운동량의 "길이"가 정지 질량이라는 뜻입니다.

1.5.2불변 질량

여러 입자 계의 전체 에너지와 전체 운동량으로 만든

\[Mc^2 = \sqrt{\left(\sum E\right)^2 - \left|\sum\mathbf pc\right|^2}\]

를 계의 불변 질량이라 합니다. 에너지와 운동량이 각각 보존되므로 불변 질량은 충돌이나 붕괴 전후에 보존되고, 어느 관성계에서 계산해도 같습니다. 질량 중심계(전체 운동량 0)에서는 \(Mc^2\)이 곧 전체 에너지입니다. 계의 불변 질량은 구성 입자 질량의 합과 같지 않습니다. 예를 들어 반대 방향으로 날아가는 두 광자는 각각 질량이 0이지만, 계의 불변 질량은 0이 아닙니다.

예제 1.5.1

에너지가 각각 \(E_1\), \(E_2\)인 두 광자가 사이각 \(\theta\)로 날아간다. 두 광자 계의 불변 질량을 구하고, \(E_1 = E_2 = 62.6\) GeV, \(\theta = 180°\)일 때 값을 구하여라.

풀이. \(p_ic = E_i\)이므로 \((Mc^2)^2 = (E_1 + E_2)^2 - |\mathbf p_1c + \mathbf p_2c|^2 = (E_1 + E_2)^2 - (E_1^2 + E_2^2 + 2E_1E_2\cos\theta) = 2E_1E_2(1 - \cos\theta)\). \(\theta = 180°\)이면 \(Mc^2 = 2\sqrt{E_1E_2} = 125.2\) GeV. 힉스 보손이 두 광자로 붕괴한 사건이 이런 모양입니다.

1.5.3쓰임: 문턱과 봉우리

  • 문턱 에너지: 새 입자를 만들려면 처음 상태의 불변 질량이 생성물 질량의 합 이상이어야 한다. 정지한 표적에 빔을 쏘면 운동량 보존 때문에 생성물도 움직여야 하므로, 필요한 빔 에너지가 생성물 질량보다 훨씬 크다(아래 예제).
  • 불변 질량 봉우리: 가속기에서 새 입자를 찾을 때, 붕괴 생성물의 에너지와 운동량으로 불변 질량 분포를 그리면 원래 입자의 질량에서 봉우리가 나온다. 힉스 보손 발견(2012)이 이 방법이다.
요약
  1. 4-운동량 \((E/c, \mathbf p)\)의 크기 \(E^2 - (pc)^2 = (mc^2)^2\)은 모든 관성계에서 같다.
  2. 불변 질량 \(\sqrt{(\sum E)^2 - |\sum\mathbf pc|^2}\)은 보존되고 관성계와 무관하다.
  3. 두 광자: \((Mc^2)^2 = 2E_1E_2(1 - \cos\theta)\). 문턱 에너지와 질량 봉우리에 쓴다.

1.5.4연습문제

기본

  1. 정지한 전자와 양전자가 쌍소멸해 광자 두 개가 나온다. 광자 하나의 에너지와 두 광자의 사이각은?
    답

    불변 질량 \(2\times0.511\) MeV, 전체 운동량 0이므로 각 0.511 MeV, 서로 반대 방향(180°).

  2. 광자 하나는 아무리 에너지가 커도 불변 질량이 0이다. 광자 하나가 혼자 전자-양전자 쌍으로 바뀔 수 없는 까닭은?
    답

    처음 불변 질량 0이 생성물의 최소 불변 질량 \(2m_ec^2\)보다 작기 때문이다. 원자핵 근처처럼 운동량을 받아 줄 상대가 있어야 한다.
