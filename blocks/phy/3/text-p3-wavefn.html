4.1.1확률 해석

입자의 상태는 복소수 함수 \(\Psi(x, t)\)로 나타냅니다. 보른의 해석에 따르면

\[P(a \le x \le b) = \int_a^b|\Psi(x, t)|^2\,dx,\]

곧 \(|\Psi|^2\)은 입자를 찾을 확률밀도입니다. 입자는 어딘가에 있어야 하므로 \(\int_{-\infty}^{\infty}|\Psi|^2dx = 1\)(규격화). 파동함수 자체는 측정되지 않고, 전체에 \(e^{i\alpha}\)를 곱해도 물리적으로 같은 상태입니다.

처음 보는 수학 · 복소수의 크기 \(|\Psi|^2 = \Psi^*\Psi\)에서 \(\Psi^*\)는 켤레 복소수(\(a + bi\)이면 \(a - bi\))입니다. \((a + bi)(a - bi) = a^2 + b^2\)이라 늘 0 이상인 실수가 되어 확률로 쓸 수 있습니다. \(e^{i\alpha} = \cos\alpha + i\sin\alpha\)는 크기가 1인 복소수라, 곱해도 \(|\Psi|^2\)이 바뀌지 않습니다.

전자 이중 슬릿 실험에서 각 전자는 화면의 한 점에 찍히지만(입자성), 많이 모이면 \(|\Psi|^2\)의 간섭 무늬가 드러납니다(파동성). 어느 슬릿을 지났는지 알아내면 무늬가 사라집니다. 확률은 한 번의 결과가 아니라 많은 결과의 분포를 예측합니다.

4.1.2기댓값

같은 상태를 많이 준비해 위치를 재면 평균은 \(\langle x\rangle = \int x|\Psi|^2dx\)입니다. 확률 분포의 평균과 같은 식입니다. 운동량은 연산자 \(\hat p = -i\hbar\,\partial/\partial x\)를 써서 \(\langle p\rangle = \int\Psi^*\hat p\Psi\,dx\)로 구합니다(평면파 \(e^{ikx}\)에 \(\hat p\)를 하면 \(\hbar k\)가 나와 드브로이 관계와 맞습니다). 표준편차 \(\Delta x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}\)가 3.3절 불확정성 원리의 \(\Delta x\)입니다.

예제 4.1.1

\(\psi(x) = Ae^{-|x|/a}\)를 규격화하고, \(|x| < a\)에서 입자를 찾을 확률을 구하여라.

풀이. \(\int|\psi|^2dx = 2A^2\int_0^\infty e^{-2x/a}dx = A^2a = 1\)에서 \(A = 1/\sqrt a\). \(P = 2\cdot\frac1a\int_0^ae^{-2x/a}dx = 1 - e^{-2} \approx 0.865\).

파동함수가 시간에 따라 어떻게 바뀌는지는 다음 절(4.2절)의 슈뢰딩거 방정식이 정합니다.

요약
  1. \(|\Psi|^2\)은 확률밀도, \(\int|\Psi|^2 = 1\).
  2. \(\langle x\rangle = \int x|\Psi|^2\), \(\hat p = -i\hbar\partial_x\), \(\Delta x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}\).

4.1.3연습문제

기본

  1. 예제 4.1.1의 상태에서 \(\langle x\rangle\)과 \(\langle x^2\rangle\)은?
    답

    \(\langle x\rangle = 0\)(대칭). \(\langle x^2\rangle = \frac2a\int_0^\infty x^2e^{-2x/a}dx = \frac{a^2}2\).

  2. \(\psi\)와 \(-\psi\), \(i\psi\)는 서로 다른 상태인가?
    답

    같은 상태다. 크기 1인 상수 \(e^{i\alpha}\)(−1, \(i\) 포함)를 곱해도 \(|\psi|^2\)과 모든 기댓값이 같다.
