4.1.1확률 해석

입자의 상태는 복소수 함수 \(\Psi(x, t)\)로 나타냅니다. 보른의 해석에 따르면

\[P(a \le x \le b) = \int_a^b|\Psi(x, t)|^2\,dx,\]

곧 \(|\Psi|^2\)은 입자를 찾을 확률밀도입니다. 입자는 어딘가에 있어야 하므로 \(\int_{-\infty}^{\infty}|\Psi|^2dx = 1\)(규격화). 파동함수 자체는 측정되지 않고, 전체에 \(e^{i\alpha}\)를 곱해도 물리적으로 같은 상태입니다.

처음 보는 수학 · 복소수의 크기 \(|\Psi|^2 = \Psi^*\Psi\)에서 \(\Psi^*\)는 켤레 복소수(\(a + bi\)이면 \(a - bi\))입니다. \((a + bi)(a - bi) = a^2 + b^2\)이라 늘 0 이상인 실수가 되어 확률로 쓸 수 있습니다. \(e^{i\alpha} = \cos\alpha + i\sin\alpha\)는 크기가 1인 복소수라, 곱해도 \(|\Psi|^2\)이 바뀌지 않습니다.

전자 이중 슬릿 실험에서 각 전자는 화면의 한 점에 찍히지만(입자성), 많이 모이면 \(|\Psi|^2\)의 간섭 무늬가 드러납니다(파동성). 어느 슬릿을 지났는지 알아내면 무늬가 사라집니다.

4.1.2슈뢰딩거 방정식

\[i\hbar\frac{\partial\Psi}{\partial t} = -\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2} + U(x)\Psi.\]

자유 입자의 평면파 \(e^{i(kx - \omega t)}\)가 \(E = \hbar\omega\), \(p = \hbar k\), \(E = p^2/2m\)을 만족하도록 만든 방정식입니다. \(U\)가 시간에 무관하면 \(\Psi = \psi(x)e^{-iEt/\hbar}\)로 분리되어 시간 무관 방정식

\[-\frac{\hbar^2}{2m}\psi'' + U(x)\psi = E\psi\]

를 얻습니다. 이 해(정상 상태)는 \(|\Psi|^2 = |\psi|^2\)이 시간에 따라 변하지 않습니다. 받아들일 수 있는 \(\psi\)는 연속이고, \(U\)가 유한한 곳에서 \(\psi'\)도 연속이며, 규격화 가능해야 합니다. 이 조건 때문에 묶인 상태의 에너지가 띄엄띄엄한 값만 가지게 됩니다(4.2절).

처음 보는 수학 · 편미분과 평면파로 확인하기 \(\frac{\partial\Psi}{\partial t}\)는 \(x\)를 고정하고 \(t\)로만, \(\frac{\partial^2\Psi}{\partial x^2}\)는 \(t\)를 고정하고 \(x\)로 두 번 미분한 것(편미분)입니다. 평면파 \(\Psi = e^{i(kx - \omega t)}\)를 넣어 보면 \(\frac{\partial\Psi}{\partial t} = -i\omega\Psi\), \(\frac{\partial^2\Psi}{\partial x^2} = -k^2\Psi\)이므로 (\(U = 0\)일 때) 왼쪽은 \(\hbar\omega\Psi\), 오른쪽은 \(\frac{\hbar^2k^2}{2m}\Psi\)입니다. \(E = \hbar\omega\), \(p = \hbar k\)로 읽으면 \(E = p^2/2m\)이 됩니다. \(\Psi = \psi(x)e^{-iEt/\hbar}\)를 넣으면 왼쪽이 \(E\Psi\)가 되고, 양변의 \(e^{-iEt/\hbar}\)를 지우면 시간 무관 방정식이 남습니다. 아래 \(\hat p\) 같은 "연산자"는 함수에 하는 작업(여기서는 \(x\)로 미분하고 \(-i\hbar\)를 곱하기)을 뜻합니다.

4.1.3기댓값

같은 상태를 많이 준비해 위치를 재면 평균은 \(\langle x\rangle = \int x|\Psi|^2dx\)입니다. 운동량은 연산자 \(\hat p = -i\hbar\,\partial/\partial x\)를 써서 \(\langle p\rangle = \int\Psi^*\hat p\Psi\,dx\)로 구합니다. 표준편차 \(\Delta x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}\)가 3.2절 불확정성 원리의 \(\Delta x\)입니다.

예제 4.1.1

\(\psi(x) = Ae^{-|x|/a}\)를 규격화하고, \(|x| < a\)에서 입자를 찾을 확률을 구하여라.

풀이. \(\int|\psi|^2dx = 2A^2\int_0^\infty e^{-2x/a}dx = A^2a = 1\)에서 \(A = 1/\sqrt a\). \(P = 2\cdot\frac1a\int_0^ae^{-2x/a}dx = 1 - e^{-2} \approx 0.865\).

요약
  1. \(|\Psi|^2\)은 확률밀도, \(\int|\Psi|^2 = 1\).
  2. 시간 무관 슈뢰딩거 방정식 \(-\frac{\hbar^2}{2m}\psi'' + U\psi = E\psi\).
  3. \(\langle x\rangle = \int x|\Psi|^2\), \(\hat p = -i\hbar\partial_x\).
