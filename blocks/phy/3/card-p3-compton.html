Compton 산란에서 잃은 에너지

광자 운동량 · 보존 법칙 · 문제 해결 전략

출발점

광자는 \(E = hf\), \(p = h/\lambda\)인 입자처럼 전자와 충돌합니다. 에너지와 운동량 보존에서 \(\Delta\lambda = \frac h{m_ec}(1 - \cos\theta)\)를 얻습니다. \(h/m_ec = 2.43\) pm은 전자의 Compton 파장입니다.

문제 해결 전략 · 광자 충돌
  1. 파장 이동 \(\Delta\lambda\)를 산란각으로 구한다.
  2. 처음과 나중 광자 에너지를 \(hc/\lambda\)로 구한다(\(hc = 1240\) eV·nm).
  3. 차이가 전자의 운동 에너지.
  4. \(\Delta\lambda\)가 처음 파장에 비해 작은지 보고, 효과가 잘 보이는 영역을 판단한다.

파장 71.0 pm의 X선이 정지 전자에 맞아 90°로 산란되었다. 산란된 X선의 파장과, 튕겨 나간 전자의 운동 에너지는?

풀이

  1. \(\Delta\lambda = 2.43(1 - \cos90°) = 2.43\) pm. 산란 파장 73.4 pm.
    90°에서 \(\cos = 0\).
  2. \(E_1 = 1240/0.0710 = 17.47\) keV, \(E_2 = 1240/0.0734 = 16.89\) keV.
    nm로 바꿔 \(hc = 1240\) eV·nm.
  3. 전자 운동 에너지 \(17.47 - 16.89 \approx 0.58\) keV.
    에너지 보존.
  4. 가시광(500 nm)이면 \(\Delta\lambda/\lambda \approx 5\times10^{-6}\)로 거의 보이지 않는다.
    \(\Delta\lambda\)는 파장과 무관한 크기.

의미

산란된 빛의 파장이 길어진다는 것은 빛이 에너지와 운동량을 덩어리로 주고받는다는 증거입니다. 파장 이동이 처음 파장과 상관없이 pm 정도라서, X선이나 감마선에서만 뚜렷이 보입니다.

검산

\(\theta = 180°\)이면 최대 이동 4.86 pm. \(\theta = 0\)이면 이동 0(충돌하지 않음). 극한이 맞습니다.
