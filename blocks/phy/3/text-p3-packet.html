파동 묶음과 군속도

본문
이 절에서 배울 것
  • 여러 파장의 파동을 겹쳐 국소화된 파동 묶음을 만든다.
  • 묶음의 폭과 파수 퍼짐의 관계 \(\Delta x\Delta k \sim 1\)을 안다.
  • 위상 속도와 군속도를 구별하고, 자유 입자의 묶음이 퍼지는 까닭을 설명한다.
먼저 알아야 할 것
  • 드브로이 파장 (3.1절), 푸리에 변환 (공통9 1.2절).

3.2.1파동 묶음

파장이 하나뿐인 사인파는 공간 전체에 퍼져 있어 입자가 "어디 있는지" 말할 수 없습니다. 파수 \(k = 2\pi/\lambda\)가 조금씩 다른 파동을 많이 겹치면 한 곳에서만 보강되고 나머지에서 상쇄되어 묶음이 됩니다.

\[\psi(x) = \int A(k)e^{ikx}\,dk.\]
처음 보는 수학 · 파동을 적분으로 더하기 \(e^{ikx} = \cos kx + i\sin kx\)는 파수 \(k\)인 사인파입니다. 이 적분은 파수가 조금씩 다른 사인파를 세기 \(A(k)\)로 무수히 많이 더한 것입니다. 개수가 유한하면 \(\sum_nA_ne^{ik_nx}\)처럼 쓸 수 있고, 몇 개만 더해도 가운데는 보강되고 양옆은 상쇄되는 묶음이 생깁니다.

\(A(k)\)가 \(k_0\) 둘레에 폭 \(\Delta k\)로 퍼져 있으면 \(\psi(x)\)의 폭은 대략 \(\Delta x \sim 1/\Delta k\)입니다(푸리에 변환의 성질). 묶음을 좁게 만들려면 더 넓은 범위의 파수를 섞어야 합니다. 가우스 묶음에서 표준편차로 정의하면 \(\Delta x\Delta k = \frac12\)로 가장 작고, 다른 모양은 이보다 큽니다. 이 관계가 다음 절의 불확정성 원리의 바탕입니다.

3.2.2위상 속도와 군속도

각 성분 파동은 위상 속도 \(v_p = \omega/k\)로, 묶음 전체(봉우리)는 군속도 \(v_g = d\omega/dk\)로 움직입니다. 드브로이 관계 \(E = \hbar\omega\), \(p = \hbar k\)를 자유 입자 \(E = \frac{p^2}{2m}\)에 넣으면 \(\omega = \frac{\hbar k^2}{2m}\)이므로

\[v_g = \frac{d\omega}{dk} = \frac{\hbar k}{m} = \frac pm, \qquad v_p = \frac{\omega}{k} = \frac{v_g}{2}.\]

군속도가 곧 고전적인 입자 속력이므로, 입자의 위치는 파동 묶음의 봉우리가 따라갑니다. \(\omega\)가 \(k\)에 비례하지 않으므로(분산) 파수마다 속력이 달라 파동 묶음은 시간이 지나며 퍼집니다. 처음에 좁은 묶음일수록 \(\Delta k\)가 커서 빨리 퍼집니다. 아래 실습 카드에서 \(\Delta k\)를 바꾸며 묶음의 폭과 퍼짐을 볼 수 있습니다.

요약
  1. 파동 묶음: 여러 파수의 중첩, \(\Delta x\Delta k \ge \frac12\).
  2. 군속도 \(d\omega/dk = p/m\)이 입자 속력. 자유 입자 묶음은 분산으로 퍼진다.

3.2.3연습문제

기본

  1. 빛(진공에서 \(\omega = ck\))의 파동 묶음은 퍼지는가? 위상 속도와 군속도는?
    답

    \(v_p = v_g = c\)로 모든 파수의 속력이 같아 퍼지지 않는다(분산 없음).

  2. 파동 묶음의 폭을 절반으로 줄이려면 파수 퍼짐 \(\Delta k\)를 어떻게 해야 하는가?
    답

    약 두 배로 늘려야 한다(\(\Delta x \sim 1/\Delta k\)).
