원자의 선 스펙트럼과 선택 규칙

본문
이 절에서 배울 것
  • 원자의 방출선과 흡수선이 준위 사이의 전이에서 생기는 과정을 설명한다.
  • 전기 쌍극자 선택 규칙 \(\Delta\ell = \pm1\)을 적용해 허용 전이를 고른다.
  • 선 스펙트럼으로 원소를 알아내고, 자기장 속에서 선이 갈라지는 까닭을 안다.
먼저 알아야 할 것
  • 양자역학의 수소 원자 (5.2절), 양자수와 주기율표 (5.3절).

5.4.1방출선과 흡수선

원자가 높은 준위 \(E_i\)에서 낮은 준위 \(E_f\)로 내려가면 에너지 차 \(hf = E_i - E_f\)의 광자를 내고(방출선), 반대로 그 에너지의 광자를 흡수하면 올라갑니다(흡수선). 뜨거운 기체는 밝은 방출선을, 연속 스펙트럼 앞의 차가운 기체는 같은 파장에 어두운 흡수선을 만듭니다. 원자마다 준위가 다르므로 선 스펙트럼은 원소의 지문이 되고, 별빛의 흡수선으로 별의 성분과 온도를 압니다(천문우주학과의 천체분광학).

5.4.2선택 규칙

모든 준위 쌍 사이에 선이 생기는 것은 아닙니다. 원자가 빛을 내며 상태를 바꿀 때 광자는 각운동량 \(\hbar\)(스핀 1)를 가져가므로, 각운동량 보존 때문에 주로 다음 전이만 일어납니다(전기 쌍극자 선택 규칙).

\[\Delta\ell = \pm1, \qquad \Delta m_\ell = 0, \pm1.\]

\(n\)은 얼마든지 바뀔 수 있습니다. 예를 들어 2p → 1s(\(\Delta\ell = -1\))는 허용되어 라이먼 α선(121.6 nm)을 내지만, 2s → 1s(\(\Delta\ell = 0\))는 금지되어 2s 상태는 아주 오래 삽니다(두 광자를 내는 느린 과정으로 붕괴). 선택 규칙을 어기는 전이도 아주 약하게는 일어나며, 이런 "금지선"은 밀도가 아주 낮은 성운에서 관측됩니다.

5.4.3자기장 속의 선: 제이만 효과

자기장 속에서는 각운동량의 \(z\) 성분 \(m_\ell\)에 따라 에너지가 \(\Delta E = m_\ell\mu_BB\) (\(\mu_B = 5.79\times10^{-5}\) eV/T)만큼 갈립니다. 선택 규칙 \(\Delta m_\ell = 0, \pm1\) 때문에 한 선이 세 선으로 갈라지는 것이 가장 단순한 경우입니다(전자 스핀까지 넣으면 더 복잡해지며 물리12에서 다룸). 태양 흑점의 스펙트럼선 갈라짐으로 흑점의 자기장을 잽니다.

요약
  1. 방출선·흡수선: \(hf = E_i - E_f\). 원소의 지문.
  2. 선택 규칙 \(\Delta\ell = \pm1\), \(\Delta m_\ell = 0, \pm1\). 2s → 1s는 금지.
  3. 제이만 효과: 자기장 속에서 \(m_\ell\)에 따라 선이 갈라진다.

5.4.4연습문제

기본

  1. 수소의 3d 상태에서 바로 내려갈 수 있는 상태는 1s, 2s, 2p 가운데 어느 것인가?
    답

    \(\Delta\ell = \pm1\)이어야 하므로 \(\ell = 1\)인 2p만.

  2. 1 T 자기장에서 \(m_\ell\)이 1 다른 준위의 에너지 차는?
    답

    \(\mu_BB = 5.79\times10^{-5}\) eV.
