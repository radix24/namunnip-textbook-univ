시공간 도표에서 동시성 보기

실습 · 로런츠 변환

목표

움직이는 좌표계 S'의 축을 S의 시공간 도표에 그리고, S에서 동시인 두 사건이 S'에서는 동시가 아닌 것을 확인합니다. 성취기준 [물리3-01-03], [물리3-01-01].

준비

가로축은 \(x\), 세로축은 \(ct\)(같은 눈금)입니다. 주황 점선은 빛의 세계선, 파란 선은 S'의 \(ct'\)축과 \(x'\)축, 연한 선은 S'에서 \(ct' = 1, 2, 3\)인 동시선입니다. 빨간 점 A, B는 S에서 같은 시각 \(ct = 2\)에 일어난 두 사건입니다. β가 음수이면 S'이 왼쪽으로 움직입니다.

절차

  1. β = 0에서 두 좌표계의 축이 겹치는 것을 본다.
  2. β를 0.5, 0.9로 올리며 S'의 두 축이 빛의 세계선 쪽으로 좁혀지는 것을 본다.
  3. β = 0.5에서 출력의 \(c\Delta t'\)를 읽고 \(-\gamma\beta\Delta x\)와 비교한다.
  4. β를 음수로 바꿔 A, B의 순서가 뒤바뀌는지 본다.

기대 결과

  • β = 0.5, Δx = 2이면 \(\gamma = 1.155\), \(c\Delta t' = -1.155\): S'에서는 B가 먼저 일어난다.
  • β가 1에 가까울수록 두 축이 45° 선에 붙고, 동시선이 크게 기운다.
  • β의 부호를 바꾸면 순서가 바뀐다. A, B는 공간꼴로 떨어져 있어 서로 원인과 결과가 될 수 없으므로 모순이 아니다.

분석

  1. A와 B를 빛원뿔 안쪽에 오도록(시간꼴) 놓으면 어떤 β에서도 순서가 바뀌지 않음을 로런츠 변환으로 보여 보세요.
  2. S'의 동시선이 \(x'\)축에 나란한 까닭을 \(t' = \gamma(t - vx/c^2)\)로 설명해 보세요.
