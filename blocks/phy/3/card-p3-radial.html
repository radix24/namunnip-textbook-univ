바닥 상태 수소에서 전자는 어디에 있나

지름 확률 밀도 · 적분 · 문제 해결 전략

출발점

1s 상태의 지름 확률 밀도는 \(P(r) = \frac{4r^2}{a_0^3}e^{-2r/a_0}\)입니다(5.2.3). 가장 그럴듯한 반지름은 \(P(r)\)의 최댓값에서, 어떤 반지름 안에 있을 확률은 \(P(r)\)을 적분해서 구합니다.

문제 해결 전략 · 지름 확률 다루기
  1. \(x = r/a_0\)로 바꿔 상수를 정리한다: \(P\,dr = 4x^2e^{-2x}dx\).
  2. 최댓값은 \(dP/dx = 0\)에서 찾는다.
  3. 확률은 부분적분으로 \(\int4x^2e^{-2x}dx\)를 계산한다.

(가) 바닥 상태 수소에서 전자를 찾을 확률이 가장 큰 반지름은? (나) 전자가 \(r < a_0\) 안에 있을 확률은? (다) 평균 반지름 \(\langle r\rangle\)은? (\(\int_0^\infty x^ne^{-2x}dx = n!/2^{n+1}\))

풀이

  1. (가) \(\frac{d}{dx}(x^2e^{-2x}) = (2x - 2x^2)e^{-2x} = 0\) → \(x = 1\), 곧 \(r = a_0\).
    최댓값 조건.
  2. (나) \(\int_0^14x^2e^{-2x}dx = \left[-(2x^2 + 2x + 1)e^{-2x}\right]_0^1 = 1 - 5e^{-2} \approx 0.32\).
    부분적분 두 번.
  3. (다) \(\langle r\rangle = a_0\int_0^\infty4x^3e^{-2x}dx = a_0\cdot4\cdot\frac{3!}{2^4} = 1.5a_0\).
    \(\langle r\rangle = \int rP(r)\,dr\).

의미

가장 그럴듯한 반지름은 보어 반지름과 같지만, 전자가 그 안쪽에 있을 확률은 약 1/3에 불과하고 평균 반지름은 \(1.5a_0\)으로 더 큽니다. 확률 분포의 봉우리, 평균, 누적 확률이 서로 다른 값이라는 점이 "궤도 반지름"이라는 고전적 그림과 다릅니다. 전자가 원자핵 근처(\(r \to 0\))에 있을 확률도 0이 아닙니다.

검산

전체 확률 \(\int_0^\infty4x^2e^{-2x}dx = 4\cdot\frac{2!}{2^3} = 1\)로 규격화가 맞습니다. (나)의 원시함수를 미분하면 \(4x^2e^{-2x}\)가 됩니다.
