광전 효과와 광자

본문
이 절에서 배울 것
  • 광전 효과의 관측 사실 세 가지가 파동 이론과 맞지 않는 까닭을 안다.
  • 광자 모형 \(K_{\max} = hf - \phi\)으로 저지 전압과 문턱 진동수를 계산한다.
  • 광자의 에너지와 운동량을 eV·nm 단위로 다룬다.
먼저 알아야 할 것
  • 광전 효과 (공통4 12.3절), 플랑크의 양자 가설 (2.1절).

2.2.1파동 이론으로 설명할 수 없는 관측

금속 표면에 빛을 비추면 전자가 튀어나옵니다(광전 효과). 실험은 다음을 보였습니다.

  • 문턱 진동수: 진동수가 어떤 값보다 낮으면 빛을 아무리 세게 비춰도 전자가 나오지 않는다.
  • 최대 운동 에너지: 튀어나온 전자의 최대 운동 에너지는 빛의 세기와 무관하고 진동수에 따라 직선으로 늘어난다.
  • 즉시 방출: 아주 약한 빛에서도 전자가 곧바로(약 \(10^{-9}\) s 안에) 나온다.

빛을 연속적인 파동으로 보면 세기가 클수록 전자에 전달되는 에너지가 커야 하고, 약한 빛에서는 에너지가 쌓일 때까지 시간이 걸려야 합니다. 세 관측 모두 이 예상과 어긋납니다.

2.2.2광자 모형

아인슈타인(1905)은 플랑크의 양자 가설을 빛 자체로 넓혀, 빛이 에너지 \(E = hf\)인 알갱이(광자)로 이루어졌다고 보았습니다. 광자 하나가 전자 하나에 에너지를 모두 주고, 전자가 금속을 빠져나오는 데 최소 \(\phi\)(일함수)가 필요하므로

\[K_{\max} = hf - \phi = eV_0.\]

\(V_0\)는 전자를 멈추게 하는 저지 전압입니다. 빛이 세면 광자 수가 늘어 전자 수(광전류)가 늘 뿐, 전자 하나의 에너지는 그대로입니다. \(hf < \phi\)이면 전자가 나오지 않으므로 문턱 진동수는 \(f_0 = \phi/h\)입니다. 세 관측이 모두 설명되며, 이 업적으로 아인슈타인은 1921년 노벨 물리학상을 받았습니다. 여러 진동수에서 \(V_0\)를 재어 \(V_0\)-\(f\) 직선의 기울기 \(h/e\)로 플랑크 상수를 구하는 실험은 물리2 7.3절에 있습니다.

2.2.3광자의 에너지와 운동량

광자는 질량이 0이므로 1.4절의 \(E = pc\)에 따라 운동량 \(p = E/c = h/\lambda\)를 가집니다. 계산에 편한 값은 \(hc = 1240\) eV·nm입니다. 파장 400 nm 광자의 에너지는 3.10 eV이고, 0.1 nm X선 광자는 12.4 keV입니다. 광자가 운동량을 가진다는 것은 다음 절의 콤프턴 산란에서 직접 확인됩니다.

요약
  1. 문턱 진동수, 세기와 무관한 최대 운동 에너지, 즉시 방출: 파동 이론으로 설명 불가.
  2. \(K_{\max} = hf - \phi = eV_0\), 문턱 \(f_0 = \phi/h\).
  3. 광자 \(E = hf\), \(p = h/\lambda\), \(hc = 1240\) eV·nm.

2.2.4연습문제

기본

  1. 일함수 4.3 eV인 아연에 파장 250 nm 빛을 비추면 저지 전압은?
    답

    \(hf = 1240/250 = 4.96\) eV, \(V_0 = 4.96 - 4.3 \approx 0.66\) V.

  2. 빛의 세기를 두 배로 하면 광전류와 저지 전압은 각각 어떻게 되는가?
    답

    광전류는 약 두 배(광자 수 두 배), 저지 전압은 그대로(광자 하나의 에너지가 같음).
