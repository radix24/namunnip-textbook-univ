상자 속 입자를 한쪽 절반에서 찾을 확률

규격화 · 확률 밀도 · 고전 극한 · 문제 해결 전략

출발점

\(|\psi(x)|^2dx\)는 입자를 \(x\)와 \(x + dx\) 사이에서 찾을 확률이다. 전체 적분이 1이 되도록(규격화) 계수를 정하고, 구간 확률은 그 구간의 적분이다.

문제 해결 전략 · 파동함수의 확률
  1. \(\int|\psi|^2dx = 1\)로 규격화 상수를 정한다.
  2. 구하는 구간에서 \(|\psi|^2\)을 적분한다.
  3. 대칭으로 답을 짐작하고 계산과 맞춘다.
  4. 고전적 기대(고르게 분포)와 비교한다.

폭 \(L\)인 무한 우물의 바닥 상태 \(\psi_1 = \sqrt{2/L}\sin(\pi x/L)\)에서 입자를 \(0 < x < L/4\)에서 찾을 확률은? 들뜬 상태 \(n = 2\)이면?

풀이

  1. \(P = \frac2L\int_0^{L/4}\sin^2\frac{n\pi x}L dx = \frac2L\left[\frac x2 - \frac{L}{4n\pi}\sin\frac{2n\pi x}L\right]_0^{L/4}\).
    \(\sin^2 = \frac12(1 - \cos2u)\).
  2. \(n = 1\): \(P = \frac14 - \frac1{2\pi}\sin\frac\pi2 = 0.25 - 0.159 = 0.091\).
    벽 근처라 확률이 작다.
  3. \(n = 2\): \(P = \frac14 - \frac1{4\pi}\sin\pi = 0.25\).
    첫 사분 구간에 봉우리 하나가 통째로 들어간다.
  4. 고전 입자(고르게 오감)는 늘 0.25.
    양자 상태마다 다르다.

의미

바닥 상태는 가운데에 몰려 있어 벽 근처에서 찾기 어렵다. \(n\)이 커질수록 봉우리가 촘촘해져 구간 확률이 고전값 0.25에 가까워지는데, 이것이 대응 원리이다.

검산

\(n = 1\)에서 대칭으로 \(L/4\)~\(L/2\) 구간 확률은 \(0.5 - 0.091 = 0.409\). 가운데 쪽이 훨씬 크다.
