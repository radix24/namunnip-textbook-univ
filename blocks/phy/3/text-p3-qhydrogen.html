양자역학의 수소 원자

본문
이 절에서 배울 것
  • 수소 원자의 상태를 세 양자수 \(n, \ell, m_\ell\)로 나타낸다.
  • 같은 에너지를 가진 상태의 수(축퇴)를 센다.
  • 확률 구름과 지름 확률 밀도로 보어 모형과 비교한다.
먼저 알아야 할 것
  • 보어 모형 (5.1절), 슈뢰딩거 방정식 (4.2절), 오비탈 (공통5 6.3절).

5.2.1세 양자수

쿨롱 퍼텐셜 \(U = -\frac{e^2}{4\pi\varepsilon_0r}\)로 3차원 슈뢰딩거 방정식을 풀면(물리8 4단원) 묶인 상태가 세 정수로 정해집니다.

  • 주양자수 \(n = 1, 2, \dots\): 에너지 \(E_n = -13.6/n^2\) eV. 보어 모형과 같다.
  • 궤도 양자수 \(\ell = 0, \dots, n - 1\): 각운동량 크기 \(\sqrt{\ell(\ell + 1)}\hbar\). \(\ell = 0, 1, 2, 3\)을 s, p, d, f라 한다.
  • 자기 양자수 \(m_\ell = -\ell, \dots, \ell\): 각운동량의 \(z\) 성분 \(m_\ell\hbar\).

3차원 공간에서 파동함수가 지름 방향, 위아래 방향, 옆 방향으로 각각 정상파를 이루어야 하므로 정수가 셋 필요합니다. 1차원 무한 우물(4.3절)의 \(n\) 하나가 3차원으로 넓어진 것으로 볼 수 있습니다.

5.2.2축퇴

에너지가 \(n\)에만 의존하므로, 같은 \(n\)에서 \(\ell\)과 \(m_\ell\)이 다른 상태들이 같은 에너지를 가집니다. 그 수는

\[\sum_{\ell=0}^{n-1}(2\ell + 1) = n^2\]

이고, 전자 스핀의 두 상태(5.3절)를 넣으면 \(2n^2\)입니다. 바닥 상태 \(n = 1\)은 1s 하나(스핀 포함 2), \(n = 2\)는 2s 하나와 2p 셋(스핀 포함 8)입니다. 이 수가 주기율표의 주기 길이와 이어집니다. 에너지가 \(\ell\)에 의존하지 않는 것은 쿨롱 퍼텐셜의 특별한 성질이며, 전자가 여럿인 원자에서는 이 축퇴가 풀려 같은 \(n\)에서도 s가 p보다 낮아집니다.

5.2.3확률 구름

양자역학에서 전자는 궤도를 도는 점이 아니라 \(|\psi|^2\)의 확률 구름으로 퍼져 있습니다. 바닥 상태(1s)의 파동함수는 \(\psi_{100} = \frac{1}{\sqrt{\pi a_0^3}}e^{-r/a_0}\)로 공 모양이고, 반지름 \(r\)과 \(r + dr\) 사이에서 전자를 찾을 확률(지름 확률 밀도)은

\[P(r)\,dr = |\psi|^2\cdot4\pi r^2\,dr = \frac{4r^2}{a_0^3}e^{-2r/a_0}\,dr\]

입니다. \(P(r)\)이 가장 큰 반지름이 정확히 보어 반지름 \(a_0\)입니다(아래 예제). 보어 모형이 에너지와 크기를 맞힌 것은 쿨롱 퍼텐셜의 특별한 성질 덕분이지만, 바닥 상태의 각운동량은 보어(\(\hbar\))와 달리 0입니다(\(\ell = 0\)).

요약
  1. \(n, \ell, m_\ell\): 에너지는 \(n\), 각운동량 크기는 \(\ell\), \(z\) 성분은 \(m_\ell\).
  2. 같은 \(n\)의 상태 수 \(n^2\)(스핀 포함 \(2n^2\)).
  3. 1s의 지름 확률 밀도 \(P(r) = \frac{4r^2}{a_0^3}e^{-2r/a_0}\), 봉우리가 \(a_0\).

5.2.4연습문제

기본

  1. \(n = 3\)에서 가능한 \((\ell, m_\ell)\)의 조합을 모두 세어 \(n^2\)인지 확인하여라.
    답

    \(\ell = 0\): 1개, \(\ell = 1\): 3개, \(\ell = 2\): 5개, 합 9 = \(3^2\).

  2. 4f 상태의 \(n\), \(\ell\)과 각운동량 크기는?
    답

    \(n = 4\), \(\ell = 3\), \(\sqrt{12}\hbar \approx 3.46\hbar\).
