무한 퍼텐셜 우물

본문

같은 물질로 만든 양자점이라도 지름이 6 nm이면 빨갛게, 2 nm이면 파랗게 빛난다. 크기만 바꿨는데 색이 바뀌는 까닭은 무엇일까? 가장 간단한 모형으로 전자를 폭 \(L\)인 상자에 가두면 에너지는 어떻게 되는가?

먼저 알아야 할 것시간 무관 슈뢰딩거 방정식과 경계 조건(4.2절)을 쓴다.

4.3.1풀이

\(0 < x < L\)에서 \(U = 0\)이고 바깥은 \(U = \infty\)인 퍼텐셜을 생각하자. 입자는 바깥으로 나갈 수 없으므로 바깥에서 \(\psi = 0\)이다. 안에서는 \(\psi'' = -k^2\psi\)(\(k^2 = 2mE/\hbar^2\))이므로 \(\psi = A\sin kx + B\cos kx\)이다. 파동함수가 연속이어야 하므로 \(\psi(0) = 0\)에서 \(B = 0\)이고, \(\psi(L) = 0\)에서 \(\sin kL = 0\), 곧 \(kL = n\pi\)이다. 규격화로 \(A\)를 정하면 다음을 얻는다.

정리 4.3.1 (무한 우물)

\[\psi_n(x) = \sqrt{\frac2L}\sin\frac{n\pi x}{L}, \qquad E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2h^2}{8mL^2},\quad n = 1, 2, 3, \dots\]

\(n = 0\)이면 \(\psi = 0\)이라 입자가 없는 것이고, 음의 \(n\)은 부호만 바뀐 같은 상태이므로 \(n = 1, 2, \dots\)만 센다.

4.3.2결과 읽기

이 간단한 결과에 양자 역학의 특징이 여럿 담겨 있다. 우선 에너지가 \(n^2\)에 비례하는 띄엄띄엄한 값만 가지며, 양 끝이 고정된 줄의 정상파와 같은 이유이다. 또 가장 낮은 에너지 \(E_1\)이 0보다 크므로 갇힌 입자는 정지할 수 없는데, 이것이 3.3절 불확정성 원리의 영점 에너지와 일치한다. 그림 1처럼 \(\psi_n\)은 우물 안에 마디가 \(n - 1\)개이고, 서로 다른 \(n\)의 파동함수는 직교해 \(\int\psi_m\psi_n\,dx = 0\)이다.

한편 \(n\)이 크면 \(|\psi|^2\)이 빠르게 출렁여 평균이 고르게 되므로, 어디서나 같은 확률로 발견된다는 고전적 결과에 다가간다. 이것을 대응 원리라 한다. 마지막으로 \(E_n \propto 1/L^2\)이므로 좁게 가둘수록 준위가 크게 벌어진다. 처음 질문의 양자점이 바로 이 경우이다.

예제 4.3.1

폭 1.0 nm 우물에 갇힌 전자의 \(E_1\)과, \(n = 2 \to 1\) 전이에서 나오는 빛의 파장은?

풀이. \(E_1 = \frac{h^2}{8m_eL^2} = \frac{(hc)^2}{8m_ec^2L^2} = \frac{(1240\ \text{eV·nm})^2}{8(511\times10^3\ \text{eV})(1.0\ \text{nm})^2} \approx 0.376\) eV이다. 따라서 \(\Delta E = 3E_1 = 1.13\) eV이고 \(\lambda = 1240/1.13 \approx 1100\) nm이다. 폭을 줄이면 \(\Delta E\)가 \(1/L^2\)로 커져 파장이 짧아지므로, 양자점은 작을수록 파랗게 빛난다.

흔한 오해바닥 상태 \(n = 1\)에서 입자가 우물 한가운데에 가만히 있다고 생각하기 쉽다. 가운데에서 찾을 확률이 가장 클 뿐 입자는 우물 전체에 퍼져 있고, 운동 에너지 \(E_1\)을 가진다. 또 실제 양자점은 벽이 유한해 파동함수가 벽 너머로 조금 스며들므로 준위가 무한 우물보다 약간 낮다.
마무리

무한 우물에서는 양 벽에서 \(\psi = 0\)이라는 경계 조건 때문에 \(kL = n\pi\)만 허용되어 \(E_n = n^2h^2/(8mL^2)\), \(\psi_n = \sqrt{2/L}\sin(n\pi x/L)\)을 얻는다. 바닥 에너지 \(E_1\)은 0보다 크고, \(n\)번째 상태는 마디가 \(n - 1\)개이며, \(n\)이 크면 고전적 극한에 다가간다. 처음 질문의 양자점은 준위 간격이 \(1/L^2\)에 비례해, 작을수록 큰 에너지 간격으로 짧은 파장의 빛을 낸다.

4.3.3연습문제

기본

  1. 무한 우물의 바닥 상태에서 입자를 \(0 < x < L/4\)에서 찾을 확률은?
    답

    \(\frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac14 - \frac1{2\pi} \approx 0.091\).

  2. 우물 폭을 두 배로 하면 \(E_1\)은 몇 배가 되는가?
    답

    \(E \propto 1/L^2\)이므로 1/4배.
