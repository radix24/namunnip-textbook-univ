무한 퍼텐셜 우물

본문
이 절에서 배울 것
  • 경계 조건으로 무한 우물의 에너지 준위와 파동함수를 구한다.
  • 양자화, 영점 에너지, 마디 수, 대응 원리를 무한 우물에서 확인한다.
  • 우물 폭과 준위 간격의 관계로 양자점의 색을 설명한다.
먼저 알아야 할 것
  • 시간 무관 슈뢰딩거 방정식과 경계 조건 (4.2절).

4.3.1풀이

\(0 < x < L\)에서 \(U = 0\), 바깥은 \(U = \infty\)인 퍼텐셜을 생각합니다. 입자는 바깥으로 나갈 수 없으므로 바깥에서 \(\psi = 0\)입니다. 안에서는 \(\psi'' = -k^2\psi\) (\(k^2 = 2mE/\hbar^2\))이므로 \(\psi = A\sin kx + B\cos kx\). 파동함수가 연속이어야 하므로 \(\psi(0) = 0\)에서 \(B = 0\), \(\psi(L) = 0\)에서 \(\sin kL = 0\), 곧 \(kL = n\pi\)입니다. 규격화로 \(A\)를 정하면

정리 4.3.1 \[\psi_n(x) = \sqrt{\frac2L}\sin\frac{n\pi x}{L}, \qquad E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2h^2}{8mL^2},\quad n = 1, 2, 3, \dots\]

\(n = 0\)은 \(\psi = 0\)이라 입자가 없는 것이고, 음의 \(n\)은 부호만 바뀐 같은 상태이므로 \(n = 1, 2, \dots\)만 셉니다.

4.3.2결과 읽기

  • 양자화: 에너지가 \(n^2\)에 비례하는 띄엄띄엄한 값이다. 양 끝이 고정된 줄의 정상파와 같은 이유다.
  • 영점 에너지: 가장 낮은 에너지 \(E_1 > 0\). 갇힌 입자는 정지할 수 없다(불확정성 원리와 일치, 3.3절).
  • 마디: \(\psi_n\)은 우물 안에 마디가 \(n - 1\)개. 서로 다른 \(n\)의 파동함수는 직교한다(\(\int\psi_m\psi_n\,dx = 0\)).
  • 대응 원리: \(n\)이 크면 \(|\psi|^2\)이 빠르게 출렁여 평균이 고르게 되어, 고전적 결과(어디서나 같은 확률)에 다가간다.
  • 폭 의존성: \(E_n \propto 1/L^2\). 좁게 가둘수록 준위가 크게 벌어진다.
예제 4.3.1

폭 1.0 nm 우물에 갇힌 전자의 \(E_1\)과, \(n = 2 \to 1\) 전이에서 나오는 빛의 파장은?

풀이. \(E_1 = \frac{h^2}{8m_eL^2} = \frac{(1240\ \text{eV·nm})^2}{8(511\times10^3\ \text{eV})(1.0\ \text{nm})^2} \approx 0.376\) eV. \(\Delta E = 3E_1 = 1.13\) eV, \(\lambda = 1240/1.13 \approx 1100\) nm. 양자점의 크기를 바꾸면 색이 바뀌는 까닭입니다(작을수록 파랗게).

요약
  1. \(E_n = n^2h^2/(8mL^2)\), \(\psi_n = \sqrt{2/L}\sin(n\pi x/L)\), \(n = 1, 2, \dots\)
  2. 영점 에너지 \(E_1 > 0\), 마디 \(n - 1\)개, 큰 \(n\)에서 고전적 극한.

4.3.3연습문제

기본

  1. 무한 우물의 바닥 상태에서 입자를 \(0 < x < L/4\)에서 찾을 확률은?
    답

    \(\frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac14 - \frac1{2\pi} \approx 0.091\).

  2. 우물 폭을 두 배로 하면 \(E_1\)은 몇 배가 되는가?
    답

    \(E \propto 1/L^2\)이므로 1/4배.
