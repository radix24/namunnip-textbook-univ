멀어지는 은하와 상대론적 Doppler 효과

적색 이동 · 빠르기 구하기 · 문제 해결 전략

출발점

광원이 시선 방향으로 \(v\)로 멀어지면 \(\frac{\lambda_{\text{관측}}}{\lambda_{\text{방출}}} = \sqrt{\frac{1 + \beta}{1 - \beta}}\) (\(\beta = v/c\))입니다. 작은 \(\beta\)에서는 고전 공식 \(1 + \beta\)와 같아집니다.

문제 해결 전략 · Doppler 이동
  1. \(z = \Delta\lambda/\lambda\)로 적색 이동을 구한다.
  2. \(1 + z = \sqrt{(1 + \beta)/(1 - \beta)}\)를 \(\beta\)에 대해 푼다: \(\beta = \frac{(1 + z)^2 - 1}{(1 + z)^2 + 1}\).
  3. 작은 \(z\)이면 \(\beta \approx z\)로 확인한다.
  4. \(\beta < 1\)인지 확인한다.

어떤 퀘이사의 수소 \(\text{H}_\alpha\)선(656.3 nm)이 1312.6 nm에서 관측되었다. 특수 상대론 Doppler로 해석할 때 멀어지는 빠르기는? 고전 공식으로는?

풀이

  1. \(1 + z = 1312.6/656.3 = 2.000\), \(z = 1.000\).
    파장이 두 배.
  2. \(\beta = \frac{4 - 1}{4 + 1} = 0.6\).
    \((1 + z)^2 = 4\).
  3. 고전 공식 \(\beta = z = 1\)이면 광속으로 멀어진다는 엉뚱한 답.
    큰 \(z\)에서는 고전 공식이 틀린다.
  4. 상대론 답: \(v = 0.6c = 1.8\times10^8\) m/s.
    \(\beta < 1\).

의미

\(z\)가 1을 넘어도 \(\beta\)는 1을 넘지 않습니다. 다만 아주 먼 천체의 적색 이동은 사실 공간 팽창(우주론적 적색 이동)으로 해석해야 하며, 이 계산은 특수 상대론으로만 본 단순한 해석입니다(천우1 6단원 참고).

검산

\(\beta = 0.6\)을 넣으면 \(\sqrt{1.6/0.4} = 2\). 맞습니다.
