Moseley 법칙으로 원소 확인하기

특성 X선 · 가림 효과 · 문제 해결 전략

출발점

안쪽 전자가 빠진 자리를 L 껍질 전자가 채우면 K\(_\alpha\) X선이 나옵니다. 남은 1s 전자 하나가 핵 전하를 가려 유효 전하가 \(Z - 1\)이 되므로 \(E_{K\alpha} \approx 13.6\ \text{eV}\,(Z - 1)^2\left(1 - \frac14\right)\)입니다.

문제 해결 전략 · 특성 X선
  1. 수소형 원자의 에너지에 유효 전하 \(Z - 1\)을 넣는다.
  2. \(2 \to 1\) 전이 에너지를 구한다.
  3. 파장을 \(hc/E\)로 구한다.
  4. 측정값에서 거꾸로 \(Z\)를 구해 원소를 확인한다.

구리(Z = 29)의 K\(_\alpha\) X선 에너지와 파장을 어림하여라. 어떤 시료의 K\(_\alpha\)가 6.4 keV이면 무슨 원소인가?

풀이

  1. Cu: \(E = 13.6\times28^2\times0.75 = 7.997\) keV, \(\lambda = 1240/7997 = 0.155\) nm.
    \((Z - 1)^2 = 784\).
  2. 측정값 8.05 keV, 0.154 nm(대략값)와 1% 안에서 맞다.
    간단한 가림 모형의 정확도.
  3. 6.4 keV: \((Z - 1)^2 = 6400/(13.6\times0.75) = 627\), \(Z - 1 \approx 25.0\).
    거꾸로 풀기.
  4. \(Z = 26\), 철.
    주기율표에서 26번.

의미

Moseley는 1913년 이 관계로 원소의 순서가 원자량이 아니라 핵 전하(원자 번호)로 정해진다는 것을 보였고, 비어 있던 원소 자리를 예측했습니다. 지금도 X선 형광 분석으로 시료의 원소를 알아냅니다.

검산

\(\sqrt{E}\)가 \(Z - 1\)에 비례: \(\sqrt{8.0/6.4} = 1.118\), \(28/25 = 1.12\). 맞습니다.
