K⁺ → π⁺π⁰ 붕괴의 파이온 운동량

2체 붕괴 · 에너지 배분

출발점

정지한 입자의 2체 붕괴에서 산물의 운동량은 \(p^* = \frac{\sqrt{[M^2 - (m_1 + m_2)^2][M^2 - (m_1 - m_2)^2]}}{2M}\), 에너지는 \(E_1 = \frac{M^2 + m_1^2 - m_2^2}{2M}\)입니다(1.2절).

문제 해결 전략 · 질량을 넣고 계산 순서 지키기
  1. 질량 합과 차를 구한다.
  2. \(p^*\)를 구한다.
  3. 각 산물의 에너지를 구하고 합이 \(M\)인지 확인한다.

정지한 \(K^+\)(493.7 MeV)가 \(\pi^+\)(139.6 MeV)와 \(\pi^0\)(135.0 MeV)로 붕괴한다. 각 파이온의 운동량, 에너지, 운동 에너지는?

풀이

  1. \(M^2 - (m_1 + m_2)^2 = 243\,740 - 75\,405 = 168\,335\), \(M^2 - (m_1 - m_2)^2 = 243\,740 - 21 = 243\,719\) (MeV²).
    합 274.6, 차 4.6 MeV.
  2. \(p^* = \sqrt{168\,335\times243\,719}/987.4 = 202\,550/987.4 \approx 205\) MeV.
    같은 크기, 반대 방향.
  3. \(E_{\pi^+} = (243\,740 + 19\,488 - 18\,225)/987.4 = 248.1\) MeV, \(E_{\pi^0} = 493.7 - 248.1 = 245.6\) MeV. 운동 에너지 108.5, 110.6 MeV.
    에너지 합 = \(M\).

의미

두 파이온의 질량이 비슷해 에너지도 거의 반씩 나눠 갖는다. 실험에서 \(\pi^+\)의 운동량이 205 MeV 근처에 날카롭게 모여 있으면 이 2체 붕괴로 판정하고, 더 넓게 퍼져 있으면 \(K^+ \to \pi^+\pi^0\pi^0\) 같은 3체 붕괴를 의심한다.

검산

\(\sqrt{205^2 + 139.6^2} = 248\) MeV로 \(E_{\pi^+}\)와 맞고, \(\sqrt{205^2 + 135^2} = 245.5\) MeV로 \(E_{\pi^0}\)와 맞다.
