1.1.1자연 단위

입자물리에서는 \(c = 1\)로 두고 에너지, 운동량, 질량을 모두 eV 단위(MeV, GeV)로 씁니다. 양자 효과를 다룰 때는 \(\hbar = 1\)로도 두는데, 그러면 길이와 시간도 에너지의 역수로 나타납니다. 다시 SI로 돌아올 때는 다음 두 값이면 충분합니다.

\[\hbar c = 197.3\ \text{MeV·fm}, \qquad \hbar = 6.582\times10^{-22}\ \text{MeV·s}.\]

예를 들어 1 GeV의 역수는 길이로 \(0.197\) fm, 시간으로 \(6.6\times10^{-25}\) s입니다.

1.1.24-운동량과 불변 질량

4-운동량 \(p = (E, \mathbf p)\)의 "길이"는 좌표계와 상관없습니다.

불변량 \[p^2 = E^2 - |\mathbf p|^2 = m^2, \qquad s = \Big(\sum_iE_i\Big)^2 - \Big|\sum_i\mathbf p_i\Big|^2.\]

입자 여럿의 \(\sqrt s\)를 불변 질량이라 합니다. 질량 중심계에서 \(\sqrt s\)는 전체 에너지와 같습니다.

에너지와 운동량이 보존되므로 반응 전후의 \(s\)는 같습니다. 이것 하나로 대부분의 운동학 문제가 풀립니다(1.2~1.5절).

요약
  1. \(c = \hbar = 1\). \(\hbar c = 197.3\) MeV·fm로 길이와 에너지를 바꾼다.
  2. \(p^2 = m^2\), \(s\)는 불변이고 보존된다.

1.1.3연습문제

기본

  1. 질량 0.938 GeV인 양성자의 콤프턴 파장 \(\hbar/mc\)은 몇 fm인가?
    답

    \(197.3/938 \approx 0.21\) fm.

  2. 운동량 3 GeV인 전자의 에너지는?
    답

    \(\sqrt{9 + 0.511^2\times10^{-6}} \approx 3.000\) GeV. 질량을 무시할 수 있다.
