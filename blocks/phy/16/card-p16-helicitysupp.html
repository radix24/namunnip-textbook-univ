파이온이 전자보다 뮤온으로 붕괴하는 비율

나선도 억제 · 위상 공간 · 문제 해결 전략

출발점

약한 상호작용은 반렙톤을 오른손 나선도로 만들려 하지만, 스핀 0인 파이온의 붕괴에서는 각운동량 보존 때문에 왼손 나선도가 필요합니다. 질량이 있어야 둘이 섞이므로 붕괴율에 \(m_\ell^2\)이 곱해집니다. 여기에 위상 공간 인자가 더해져 \(\Gamma \propto m_\ell^2(m_\pi^2 - m_\ell^2)^2\)입니다.

문제 해결 전략 · 붕괴 비율 어림
  1. 붕괴율 식에서 렙톤에 따라 다른 부분만 남긴다.
  2. 나선도 억제 인자 \((m_e/m_\mu)^2\)를 구한다.
  3. 위상 공간 인자의 비를 구한다.
  4. 곱해서 측정값과 비교한다.

\(m_e = 0.511\), \(m_\mu = 105.66\), \(m_\pi = 139.57\) MeV로 \(\frac{\Gamma(\pi^+ \to e^+\nu)}{\Gamma(\pi^+ \to \mu^+\nu)}\)를 구하여라.

풀이

  1. 나선도 인자 \((0.511/105.66)^2 = 2.34\times10^{-5}\).
    전자가 크게 억눌린다.
  2. 위상 공간 \(\left(\frac{139.57^2 - 0.511^2}{139.57^2 - 105.66^2}\right)^2 = 2.34^2 = 5.49\).
    전자 쪽 에너지가 더 많이 남는다.
  3. 비 \(= 2.34\times10^{-5}\times5.49 = 1.28\times10^{-4}\).
    곱.
  4. 측정값 약 \(1.23\times10^{-4}\)(대략값)과 복사 보정 수준에서 맞는다.
    비교.

의미

위상 공간만 보면 전자 쪽이 5배 더 많아야 하지만, 실제로는 1만 배쯤 드뭅니다. 이 억제는 약한 상호작용이 한쪽 나선도만 다룬다는, 곧 패리티를 최대로 깬다는 직접 증거입니다.

검산

렙톤 질량이 0이면 붕괴율이 0입니다. 질량 없는 반렙톤은 오른손 나선도만 가져 스핀 보존을 만족할 수 없기 때문입니다.
