쿼크 구성으로 강입자의 전하와 기묘도 구하기

쿼크 모형 · 양자수 더하기 · 문제 해결 전략

출발점

강입자의 전하, 기묘도, 맵시(charm)는 구성 쿼크 값을 더해 얻습니다. 위형 쿼크(u, c, t) \(+\frac23\), 아래형(d, s, b) \(-\frac13\), 반쿼크는 부호가 반대입니다. s 쿼크는 기묘도 \(-1\), c 쿼크는 맵시 \(+1\)입니다.

문제 해결 전략 · 쿼크 양자수 더하기
  1. 쿼크 구성을 쓴다(바리온 셋, 메손 쿼크-반쿼크).
  2. 전하를 더한다.
  3. 기묘도와 맵시를 센다.
  4. 전하가 정수인지 확인한다.

\(\Sigma^+ = uus\), \(\Xi^- = dss\), \(K^- = s\bar u\), \(D^0 = c\bar u\)의 전하, 기묘도, 맵시를 구하여라.

풀이

  1. \(\Sigma^+\): \(\frac23 + \frac23 - \frac13 = +1\), 기묘도 \(-1\).
    s 하나.
  2. \(\Xi^-\): \(-\frac13\times3 = -1\), 기묘도 \(-2\).
    s 둘.
  3. \(K^-\): \(-\frac13 - \frac23 = -1\), 기묘도 \(-1\).
    반 u는 \(-\frac23\).
  4. \(D^0\): \(\frac23 - \frac23 = 0\), 맵시 \(+1\), 기묘도 0.
    c 하나.

의미

Gell-Mann은 이런 규칙으로 바리온을 표로 정리하고, 기묘도 \(-3\)인 \(\Omega^- = sss\)의 존재와 질량을 예측했습니다. 1964년 이 입자가 발견되어 쿼크 모형의 강력한 증거가 되었습니다.

검산

쿼크 셋이나 쿼크-반쿼크 조합은 언제나 정수 전하를 냅니다. 분수 전하 입자가 관측되지 않는 것(가둠)과 맞습니다.
