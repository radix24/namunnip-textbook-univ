비대칭 B 공장의 질량 중심 운동

질량 중심계 · 로런츠 인자 · 설계 이유

출발점

전체 4-운동량에서 \(\gamma_{\text{cm}} = E_{\text{tot}}/\sqrt s\), \(\beta_{\text{cm}}\gamma_{\text{cm}} = |\mathbf P_{\text{tot}}|/\sqrt s\)입니다(1.4절). 질량이 무시되는 두 빔이 정면 충돌하면 \(s = 4E_1E_2\)이다.

문제 해결 전략 · 두 빔 에너지 → √s와 βγ
  1. \(s = 4E_1E_2\)로 \(\sqrt s\)를 구한다.
  2. 전체 운동량 \(E_1 - E_2\)로 \(\beta\gamma\)를 구한다.
  3. 만들어진 입자가 실험실에서 움직이는 정도를 해석한다.

KEKB는 8.0 GeV 전자와 3.5 GeV 양전자를 정면 충돌시켰다. (가) \(\sqrt s\)는? \(\Upsilon(4S)\)(10.58 GeV)를 만들 수 있는가? (나) 질량 중심계의 \(\beta\gamma\)는? (다) 같은 \(\sqrt s\)를 대칭 빔으로 만들면 빔 에너지는?

풀이

  1. (가) \(\sqrt{4\times8.0\times3.5} = \sqrt{112} = 10.58\) GeV. 정확히 \(\Upsilon(4S)\) 질량.
    \(s = 4E_1E_2\).
  2. (나) \(\beta\gamma = (8.0 - 3.5)/10.58 = 0.425\).
    운동량 차 / √s.
  3. (다) 5.29 GeV씩.
    대칭이면 질량 중심이 정지.

의미

\(\Upsilon(4S)\)는 B 중간자 쌍으로 붕괴하는데, 대칭 충돌이면 B가 거의 정지해 두 붕괴 위치를 구별할 수 없다. 비대칭으로 만들어 \(\beta\gamma = 0.43\)으로 움직이게 하면, 두 B의 붕괴 위치가 빔 방향으로 평균 0.2 mm쯤 벌어져 시간 차를 잴 수 있고, 이것으로 B 중간자의 CP 깨짐(3.5절)을 측정했다.

검산

\(\gamma = \sqrt{1 + 0.425^2} = 1.087\), \(E_{\text{tot}} = \gamma\sqrt s = 11.5\) GeV = 8.0 + 3.5로 맞다.
