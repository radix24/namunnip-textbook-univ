비행 시간으로 파이온과 케이온 구별하기

비행 시간 · 속력과 질량 · 분해능

출발점

운동량 \(p\), 질량 \(m\)인 입자의 속력은 \(\beta = p/\sqrt{p^2 + m^2}\)이고, 거리 \(L\)을 나는 시간은 \(t = L/\beta c\)입니다(4.2절). \(m_\pi = 0.140\) GeV, \(m_K = 0.494\) GeV이다.

문제 해결 전략 · 같은 운동량, 다른 속력
  1. 두 입자의 \(\beta\)를 구한다.
  2. 비행 시간 차 \(\Delta t = (L/c)(1/\beta_K - 1/\beta_\pi)\)를 구한다.
  3. 시간 분해능과 비교해 구별 가능성을 판단한다.

운동량 1.0 GeV인 \(\pi\)와 \(K\)가 3.0 m를 난다. (가) 비행 시간 차는? (나) 시간 분해능 100 ps인 검출기로 구별할 수 있는가? (다) 운동량이 3.0 GeV이면?

풀이

  1. (가) \(\beta_\pi = 1/\sqrt{1 + 0.0196} = 0.990\), \(\beta_K = 1/\sqrt{1 + 0.244} = 0.897\). \(\Delta t = 10\ \text{ns}\times(1.115 - 1.010) = 1.05\) ns.
    \(L/c = 10\) ns.
  2. (나) 1.05 ns = 1050 ps로 분해능의 10배. 뚜렷이 구별된다.
    여유 있음.
  3. (다) \(1/\beta \approx 1 + m^2/2p^2\): \(\Delta t \approx 10\ \text{ns}\times\frac{0.244 - 0.0196}{2\times9} = 0.12\) ns = 120 ps. 겨우 구별.
    \(\Delta t \propto 1/p^2\).

의미

비행 시간 차는 운동량의 제곱에 반비례해 줄어들므로 몇 GeV 이상에서는 다른 방법(체렌코프 복사의 각, 에너지 손실률)을 쓴다. 케이온을 파이온과 구별하는 것은 기묘 입자와 B 중간자 붕괴 연구에서 필수이다.

검산

근사식으로 (가)를 다시 계산하면 \(10\times(0.244 - 0.0196)/2 = 1.12\) ns로 정확한 값 1.05 ns와 비슷합니다(\(p\)가 작아 근사가 덜 정확).
