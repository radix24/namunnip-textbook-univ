같은 도형으로 쿼크 쌍과 뮤온 쌍 생성 비율 비교하기

파인먼 도형 · 꼭짓점 인자 · 색 · 문제 해결 전략

출발점

\(e^+e^- \to \mu^+\mu^-\)와 \(e^+e^- \to q\bar q\)는 같은 모양의 도형(가상 광자 하나)입니다. 다른 점은 나가는 꼭짓점의 전하뿐이라 확률은 \(Q_q^2\)배이고, 쿼크는 색이 세 가지라 3배가 더 붙습니다.

문제 해결 전략 · 도형 비교
  1. 두 과정의 도형을 그려 같은 부분과 다른 부분을 찾는다.
  2. 꼭짓점마다 진폭에 전하가 곱해지므로 확률은 전하의 제곱에 비례한다.
  3. 구별되는 끝 상태(색)의 수를 곱한다.
  4. 만들 수 있는 쿼크(질량 문턱)를 모두 더한다.

\(R = \frac{\sigma(e^+e^- \to \text{강입자})}{\sigma(e^+e^- \to \mu^+\mu^-)}\)를 (가) u, d, s만 만들 수 있는 에너지 (나) c까지 (다) b까지에서 어림하여라.

풀이

  1. \(R = 3\sum_qQ_q^2\).
    색 3 × 전하 제곱.
  2. (가) \(3\left(\frac49 + \frac19 + \frac19\right) = 2\).
    u, d, s.
  3. (나) \(2 + 3\times\frac49 = \frac{10}3 \approx 3.3\).
    c 추가.
  4. (다) \(\frac{10}3 + 3\times\frac19 = \frac{11}3 \approx 3.7\).
    b 추가.

의미

충돌 에너지를 올리며 \(R\)을 재면 새 쿼크의 문턱마다 계단처럼 뛰어오릅니다. 측정값이 색 3을 넣은 값과 맞는 것(강한 상호작용 보정으로 몇 % 큼, 대략값)이 쿼크에 색이 셋 있다는 직접 증거입니다.

검산

색을 빼면 (가)는 2/3이 되어 측정과 3배 어긋납니다. 색의 수가 결과를 바로 바꿉니다.
