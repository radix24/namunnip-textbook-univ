오메가 발견 반응과 중성미자 반응 판정

보존 법칙 점검표 · 힘의 종류 · 문제 해결 전략

출발점

반응 가능성은 질량(에너지) → 전하 → 바리온 수 → 세대별 렙톤 수 → 기묘도 순서로 점검한다. 기묘도만 바뀌면 약한 상호작용으로 가능하고 느리다.

문제 해결 전략 · 보존 점검
  1. 각 입자의 \(Q\), \(B\), \(L_e\), \(L_\mu\), \(S\)를 표로 쓴다.
  2. 양쪽 합을 비교한다.
  3. 붕괴라면 질량이 줄어드는지 본다.
  4. 기묘도나 중성미자로 힘의 종류를 정한다.

(가) \(K^- + p \to \Omega^- + K^+ + K^0\) (나) \(\Sigma^+ \to n + \pi^+\) (다) \(\nu_\mu + n \to \mu^- + p\) (라) \(\nu_e + n \to \mu^- + p\)의 가능 여부와 힘을 판단하여라.

풀이

  1. (가) \(Q\): \(0 \to 0\), \(B\): \(1 \to 1\), \(S\): \(-1 \to -3 + 1 + 1 = -1\). 강한 상호작용으로 가능.
    1964년 \(\Omega^-\) 발견 반응.
  2. (나) \(Q\), \(B\) 보존, 질량 \(1189 > 940 + 140\) MeV. \(S\): \(-1 \to 0\)이라 약한 붕괴.
    수명 약 0.08 ns.
  3. (다) \(L_\mu\): \(1 \to 1\), \(Q\): \(0 \to 0\), \(B\) 보존. 약한 상호작용으로 가능.
    중성미자 반응.
  4. (라) \(L_e\): \(1 \to 0\), \(L_\mu\): \(0 \to 1\). 금지.
    세대별 렙톤 수.

의미

(다)와 (라)의 차이가 1962년 브룩헤이븐 실험의 핵심이었다. 파이온 붕괴에서 나온 중성미자가 뮤온만 만들고 전자는 만들지 않아, 전자 중성미자와 뮤온 중성미자가 다르다는 것이 밝혀졌다.

검산

(나)에서 남는 에너지 \(1189 - 940 - 140 = 109\) MeV가 양수라 붕괴가 가능하다.
