Lorentz 진동자의 굴절률과 흡수

실습 · 분산 곡선

목표

공명 진동수 \(\omega_0\) 근처에서 굴절률 \(n\)과 흡수 \(\kappa\)가 진동수에 따라 어떻게 바뀌는지 그린다. 정상 분산, 이상 분산, 흡수 봉우리를 확인한다. 성취기준 [물리19-05-01].

준비

\(\omega_0 = 1\)로 맞추고 \(\tilde n^2 = 1 + \frac{\omega_p^2}{1 - \omega^2 - i\gamma\omega}\)에서 \(n\)(파랑)과 \(\kappa\)(빨강)를 계산한다. 점은 지금 고른 진동수의 값, 점선은 \(n = 1\)이다.

절차

  1. 처음 설정(γ = 0.1, ω_p = 1)에서 ω = 0.5의 n, κ, dn/dω를 적는다.
  2. ω를 1과 1.1로 옮겨 흡수가 크고 n이 줄어드는 구간을 확인한다. ω = 2에서도 본다.
  3. γ를 0.02와 0.5로 바꿔 흡수 봉우리의 높이와 폭이 어떻게 바뀌는지 본다.

기대 결과

  • ω = 0.5: n = 1.526, κ = 0.029, dn/dω = 0.569(정상 분산). 유리가 가시광에서 보이는 모습과 같다.
  • ω = 1: n = 2.351, κ = 2.127로 흡수가 크고 dn/dω가 음수(이상 분산). ω = 1.1: n = 0.560, κ = 1.747. ω = 2: n = 0.818로 1보다 작고 κ = 0.014, 다시 정상 분산.
  • 감쇠가 작을수록 흡수 봉우리가 높고 좁다(물리1 4.4절의 공명 곡선과 같은 모양).

분석

  1. n < 1이 되는 구간에서 위상 속도는 광속보다 빠르다. 이것이 상대론과 모순되지 않는 까닭을 말해 보자.
  2. 흡수가 큰 진동수에서 이상 분산이 나타나는 까닭을 강제 진동의 위상 변화(0 → π)와 연결해 보자.
