해밀턴 정준 방정식

본문
이 절에서 배울 것
  • 해밀토니안의 전미분에서 정준 방정식을 유도한다.
  • 정준 방정식으로 운동을 1계 연립 방정식으로 풀고 보존량을 읽는다.
  • 해밀턴 역학이 쓰이는 곳을 안다.
먼저 알아야 할 것
  • 르장드르 변환과 해밀토니안 (3.1절).

3.2.1유도

\(H\)의 전미분과 라그랑주 방정식을 비교합니다. \(dH = \sum_i(\dot q_i\,dp_i + p_i\,d\dot q_i) - \sum_i\left(\frac{\partial L}{\partial q_i}dq_i + \frac{\partial L}{\partial\dot q_i}d\dot q_i\right) - \frac{\partial L}{\partial t}dt\)에서 \(p_i = \partial L/\partial\dot q_i\)라 \(d\dot q_i\) 항이 지워지고(르장드르 변환을 쓰는 이유), \(\partial L/\partial q_i = \dot p_i\)를 넣으면 \(dH = \sum_i(\dot q_i\,dp_i - \dot p_i\,dq_i) - \frac{\partial L}{\partial t}dt\)입니다. \(dp_i\), \(dq_i\)의 계수를 읽으면

정리 3.2.1 (해밀턴 방정식) \[\dot q_i = \frac{\partial H}{\partial p_i}, \qquad \dot p_i = -\frac{\partial H}{\partial q_i}, \qquad \frac{dH}{dt} = \frac{\partial H}{\partial t}.\]

2계 방정식 \(n\)개가 1계 방정식 \(2n\)개가 되었습니다. \(H\)가 시간을 직접 포함하지 않으면 \(H\)가 보존되고, \(H\)에 \(q_j\)가 없으면 \(p_j\)가 보존됩니다(순환 좌표). 첫 식은 운동량과 속도의 관계를 되돌려 주고, 둘째 식이 실제 운동 방정식(힘)입니다.

3.2.2예: 중심력

예제 3.2.1

중심력 문제의 해밀토니안과 정준 방정식을 극좌표로 쓰라.

풀이. \(L = \frac12m(\dot r^2 + r^2\dot\phi^2) - U(r)\)에서 \(p_r = m\dot r\), \(p_\phi = mr^2\dot\phi\). \(H = \frac{p_r^2}{2m} + \frac{p_\phi^2}{2mr^2} + U(r)\). 정준 방정식:

  • \(\dot r = p_r/m\), \(\dot\phi = p_\phi/(mr^2)\).
  • \(\dot p_r = \frac{p_\phi^2}{mr^3} - U'(r)\), \(\dot p_\phi = 0\).

\(p_\phi\)는 각운동량으로 보존되고, \(r\)의 운동은 물리1 5.2절의 유효 퍼텐셜 문제와 같습니다.

3.2.3왜 해밀턴 역학인가

  • 1계 방정식이라 수치 적분과 위상 공간 분석(3.3절)에 알맞다. 위상 공간의 한 점이 상태 전체를 정하고, 궤적은 서로 교차하지 않는다.
  • \(q\)와 \(p\)를 대등하게 다루어, 둘을 섞는 좌표 변환(정준 변환)으로 문제를 단순하게 만들 수 있다.
  • 통계역학(위상 공간의 부피, 물리13)과 양자역학(해밀토니안 연산자, 물리8)의 출발점이다.
요약
  1. \(\dot q = \partial H/\partial p\), \(\dot p = -\partial H/\partial q\), \(dH/dt = \partial H/\partial t\).
  2. \(H\)에 \(t\)가 없으면 \(H\) 보존, \(q_j\)가 없으면 \(p_j\) 보존.

3.2.4연습문제

기본

  1. 단진자의 해밀토니안과 정준 방정식을 쓰라.
    답

    \(p_\phi = ml^2\dot\phi\), \(H = \frac{p_\phi^2}{2ml^2} - mgl\cos\phi\). \(\dot\phi = p_\phi/(ml^2)\), \(\dot p_\phi = -mgl\sin\phi\).

  2. 중력장 속 자유 낙하 \(H = \frac{p^2}{2m} + mgz\)의 정준 방정식을 풀어라.
    답

    \(\dot z = p/m\), \(\dot p = -mg\). \(p = p_0 - mgt\), \(z = z_0 + p_0t/m - \frac12gt^2\).
