해밀턴 정준 방정식

본문

라그랑주 방정식은 좌표마다 2계 미분 방정식을 하나씩 준다. 해밀토니안 \(H(q, p)\)를 만들었다면, 이번에는 \(H\)에서 운동 방정식을 어떻게 얻을까? 그리고 2계 방정식 대신 1계 방정식을 두 배로 늘려 쓰는 것이 무슨 이득일까?

먼저 알아야 할 것르장드르 변환과 해밀토니안(3.1절)을 쓴다.

3.2.1유도

\(H\)의 전미분을 라그랑주 방정식과 비교한다. \(H = \sum p_i\dot q_i - L\)을 미분하면 \(dH = \sum_i(\dot q_i\,dp_i + p_i\,d\dot q_i) - \sum_i\left(\frac{\partial L}{\partial q_i}dq_i + \frac{\partial L}{\partial\dot q_i}d\dot q_i\right) - \frac{\partial L}{\partial t}dt\)이다. 그런데 \(p_i = \partial L/\partial\dot q_i\)라 \(d\dot q_i\) 항이 지워지며, 르장드르 변환을 쓰는 이유가 바로 이것이다. 이제 \(\partial L/\partial q_i = \dot p_i\)를 넣으면 \(dH = \sum_i(\dot q_i\,dp_i - \dot p_i\,dq_i) - \frac{\partial L}{\partial t}dt\)이고, \(dp_i\)와 \(dq_i\)의 계수를 읽으면 다음을 얻는다.

정리 3.2.1 (해밀턴 방정식)

\[\dot q_i = \frac{\partial H}{\partial p_i}, \qquad \dot p_i = -\frac{\partial H}{\partial q_i}, \qquad \frac{dH}{dt} = \frac{\partial H}{\partial t}\]

이렇게 2계 방정식 \(n\)개가 1계 방정식 \(2n\)개가 되었다. 처음 질문의 첫째 답이 이것이다. 첫 식은 운동량과 속도의 관계를 되돌려 주고, 둘째 식이 힘에 해당하는 실제 운동 방정식이다. 또 \(H\)가 시간을 직접 포함하지 않으면 \(H\)가 보존되고, \(H\)에 \(q_j\)가 없으면 \(p_j\)가 보존된다(순환 좌표).

3.2.2예, 중심력

예제 3.2.1

중심력 문제의 해밀토니안과 정준 방정식을 극좌표로 쓰라.

풀이. \(L = \frac12m(\dot r^2 + r^2\dot\phi^2) - U(r)\)에서 \(p_r = m\dot r\), \(p_\phi = mr^2\dot\phi\)이므로 \(H = \frac{p_r^2}{2m} + \frac{p_\phi^2}{2mr^2} + U(r)\)이다. 정준 방정식은 \(\dot r = p_r/m\), \(\dot\phi = p_\phi/(mr^2)\), \(\dot p_r = \frac{p_\phi^2}{mr^3} - U'(r)\), \(\dot p_\phi = 0\)이다. 따라서 \(p_\phi\)는 각운동량으로 보존되고, \(r\)의 운동은 물리1 5.2절의 유효 퍼텐셜 문제와 같다.

3.2.3왜 해밀턴 역학인가

처음 질문의 둘째 부분, 곧 이득은 세 가지이다. 먼저 1계 방정식이라 수치 적분과 위상 공간 분석(3.3절)에 알맞다. 그림 1처럼 위상 공간의 한 점이 상태 전체를 정하고, 궤적은 서로 교차하지 않는다. 다음으로 \(q\)와 \(p\)를 대등하게 다루므로, 둘을 섞는 좌표 변환인 정준 변환으로 문제를 단순하게 만들 수 있다. 마지막으로 위상 공간의 부피를 다루는 통계 역학(물리13)과 해밀토니안 연산자를 쓰는 양자 역학(물리8)의 출발점이다.

흔한 오해두 번째 해밀턴 방정식의 음의 부호를 빠뜨리기 쉽다. \(\dot p = -\partial H/\partial q\)이며, 퍼텐셜이 \(q\)와 함께 커지면 운동량이 줄어드는 것, 곧 힘이 \(-\partial U/\partial q\)라는 것과 같다. 또 \(H\)를 \(p\)로 미분할 때 \(q\)는 상수로, \(q\)로 미분할 때 \(p\)는 상수로 둔다.
마무리

해밀토니안의 전미분을 라그랑주 방정식과 비교하면 해밀턴 방정식 \(\dot q = \partial H/\partial p\), \(\dot p = -\partial H/\partial q\), \(dH/dt = \partial H/\partial t\)가 나온다. 처음 질문처럼 2계 방정식 \(n\)개가 1계 방정식 \(2n\)개로 바뀌며, \(H\)에 \(t\)가 없으면 \(H\)가, \(q_j\)가 없으면 \(p_j\)가 보존된다. 1계라 위상 공간에서 상태가 한 점으로 정해지고, 정준 변환, 통계 역학, 양자 역학으로 이어진다.

3.2.4연습문제

기본

  1. 단진자의 해밀토니안과 정준 방정식을 쓰라.
    답

    \(p_\phi = ml^2\dot\phi\), \(H = \frac{p_\phi^2}{2ml^2} - mgl\cos\phi\). \(\dot\phi = p_\phi/(ml^2)\), \(\dot p_\phi = -mgl\sin\phi\).

  2. 중력장 속 자유 낙하 \(H = \frac{p^2}{2m} + mgz\)의 정준 방정식을 풀어라.
    답

    \(\dot z = p/m\), \(\dot p = -mg\). \(p = p_0 - mgt\), \(z = z_0 + p_0t/m - \frac12gt^2\).
