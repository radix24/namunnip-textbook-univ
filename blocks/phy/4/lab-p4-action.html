경로를 바꾸며 작용 재기

실습 · 해밀턴 원리

목표

양 끝을 고정한 채 실제 경로를 \(\epsilon\sin(n\pi t/T)\)만큼 흔들고 작용 \(S = \int L\,dt\)를 계산한다. 실제 경로에서 \(S\)가 정상값(기울기 0)이고, 경우에 따라 최소가 아닐 수도 있음을 확인한다. 성취기준 [물리4-01-04].

준비

질량은 1, 시간 구간은 \(T = 1\) s이다. 위 그림의 회색 점선이 실제 경로, 파란 선이 바꾼 경로이다. 아래 그림은 \(\epsilon\)을 −1에서 1까지 바꿀 때 \(S(\epsilon) - S(0)\)이고, 파란 점이 지금 값이다. 작용은 심프슨 공식으로 수치 적분한다.

절차

  1. 자유 낙하에서 ε를 바꿔 가며 \(S(\epsilon) - S(0)\)이 어디서 가장 작은지 본다. n을 바꿔도 같은지 확인한다.
  2. 조화 진동자 ω = 1, 2로 바꿔 같은 일을 한다.
  3. ω = 4.5로 바꾸고 n = 1과 n = 2에서 아래 곡선의 모양을 비교한다.

기대 결과

  • 자유 낙하: 실제 경로의 작용 \(S(0) = -4.0017\). ε = 0.5, n = 1이면 차이가 0.6169(이론 \(\frac{\pi^2}4\epsilon^2\)). 어느 n에서나 ε = 0이 최소다.
  • ω = 1, n = 1: 차이가 \(2.217\epsilon^2\)로 여전히 최소.
  • ω = 4.5, n = 1: 계수가 −2.595로 음수라 이 방향으로는 ε = 0이 최대다. n = 2에서는 계수 4.807로 최소. 실제 경로는 안장점이지만 기울기는 늘 0이다.

분석

  1. \(L\)이 \(q\), \(\dot q\)의 2차식이면 \(S(\epsilon)\)이 정확히 \(\epsilon\)의 2차식이 되는 까닭을 말해 보자. 1차 항이 0인 것이 오일러-라그랑주 방정식과 어떻게 이어지나요?
  2. \(\omega T > \pi\)일 때 n = 1 방향으로 작용이 줄어드는 까닭을 \(\frac T4\left[(n\pi/T)^2 - \omega^2\right]\)로 설명해 보자.
