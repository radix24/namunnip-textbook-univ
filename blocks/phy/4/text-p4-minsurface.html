최소 넓이 회전면과 벨트라미 항등식

본문
이 절에서 배울 것
  • 피적분 함수에 독립 변수가 없을 때 쓰는 벨트라미 항등식을 유도한다.
  • 최소 넓이 회전면 문제를 풀어 현수선을 얻는다.
  • 경계 조건에 따라 해가 둘이거나 없을 수 있음을 비누막 실험으로 해석한다.

  • 오일러-라그랑주 방정식 (1.1절), 최단 시간 곡선 (1.2절), 쌍곡선 함수 (공통1 2.6절).

1.3.1벨트라미 항등식

범함수 \(J = \int f(y, y')\,dx\)의 피적분 함수가 독립 변수 \(x\)를 직접 포함하지 않으면, 오일러-라그랑주 방정식의 첫 적분

\[f - y'\frac{\partial f}{\partial y'} = \text{상수}\]

를 쓸 수 있습니다(벨트라미 항등식). 확인하려면 왼쪽을 \(x\)로 미분합니다: \(\frac{d}{dx}\left(f - y'f_{y'}\right) = f_yy' + f_{y'}y'' - y''f_{y'} - y'\frac{d}{dx}f_{y'} = y'\left(f_y - \frac{d}{dx}f_{y'}\right) = 0\). 마지막 괄호가 바로 오일러-라그랑주 방정식이므로 0입니다. 1.2절에서는 독립 변수를 바꿔 같은 효과를 얻었고, 여기서는 이 항등식을 직접 씁니다. 역학에서 라그랑지안이 시간을 포함하지 않을 때 에너지가 보존되는 것(2.4절)과 같은 구조입니다.

1.3.2최소 넓이 회전면

두 원형 고리를 같은 축에 놓고 비누막을 걸면, 표면 장력 때문에 막은 넓이가 가장 작은 모양을 찾습니다. 곡선 \(y(x)\)를 \(x\)축 둘레로 돌린 면의 넓이는

\[A = 2\pi\int y\sqrt{1 + y'^2}\,dx.\]

\(f = y\sqrt{1 + y'^2}\)은 \(x\)를 포함하지 않으므로 벨트라미 항등식으로

\[f - y'\frac{\partial f}{\partial y'} = \frac{y}{\sqrt{1 + y'^2}} = c.\]

\(y' = \sqrt{y^2/c^2 - 1}\)로 풀어 적분하면

정리 1.3.1 \[y = c\cosh\frac{x - x_0}{c}\quad(\text{현수선}).\]

회전면은 현수면(catenoid)입니다. \(c\)는 가장 가는 목의 반지름입니다. 같은 곡선이 양 끝을 매단 사슬의 모양(현수선)으로도 나오는데, 그때는 길이가 정해진 사슬의 퍼텐셜 에너지를 최소로 하는 구속 조건 문제(2.6절의 라그랑주 승수)입니다.

1.3.3해가 둘이거나 없을 때

반지름 \(R\)인 두 고리가 \(x = \pm d\)에 있으면 경계 조건 \(R = c\cosh(d/c)\)를 풀어 \(c\)를 정합니다. 이 방정식은 \(d/R\)이 작으면 해가 둘(목이 굵은 것과 가는 것), \(d/R \approx 0.663\)보다 크면 해가 없습니다. 목이 굵은 해가 실제로 안정한 막이고, 고리를 그보다 멀리 떨어뜨리면 현수면이 존재할 수 없어 막이 터지고 두 고리에 원판 모양 막이 하나씩 남습니다(아래 예제). 변분법의 해는 "넓이가 정상값"이라는 조건일 뿐, 늘 최소이거나 늘 존재하는 것은 아니라는 좋은 보기입니다.

요약
  1. \(f\)에 \(x\)가 없으면 \(f - y'f_{y'} = \)상수(벨트라미).
  2. 최소 넓이 회전면: 현수선 \(y = c\cosh((x - x_0)/c)\).
  3. 고리 간격이 크면(\(2d \gtrsim 1.33R\)) 해가 없어 막이 터진다.

1.3.4연습문제

기본

  1. 평면에서 두 점을 잇는 가장 짧은 곡선(\(f = \sqrt{1 + y'^2}\))을 벨트라미 항등식으로 구하여라.
    답

    \(f - y'f_{y'} = \frac{1}{\sqrt{1 + y'^2}} = c\)이므로 \(y'\)이 상수, 곧 직선.

  2. \(y = c\cosh(x/c)\)가 \(\frac{y}{\sqrt{1 + y'^2}} = c\)를 만족함을 확인하여라.
    답

    \(y' = \sinh(x/c)\), \(\sqrt{1 + \sinh^2} = \cosh(x/c)\)이므로 \(y/\cosh(x/c) = c\).
