정규 모드의 중첩과 맥놀이

본문
이 절에서 배울 것
  • 일반 운동을 정규 모드의 중첩으로 쓰고 초기 조건으로 계수를 정한다.
  • 약하게 이어진 진동자 사이에서 에너지가 오가는 맥놀이를 설명한다.
먼저 알아야 할 것
  • 정규 모드 (4.1절).

4.1절에서 찾은 정규 모드는 특별한 처음 조건에서만 그대로 나타납니다. 보통은 한 물체만 당겼다 놓는 식으로 시작하므로 여러 모드가 섞입니다. 이 절은 처음 조건을 모드로 나누는 방법과, 두 모드의 진동수가 가까울 때 생기는 맥놀이, 곧 에너지가 두 진동자 사이를 천천히 오가는 현상을 봅니다.

4.2.1중첩

운동 방정식이 선형이므로 일반해는 정규 모드의 선형 결합입니다.

\[\mathbf x(t) = \sum_kA_k\mathbf a_k\cos(\omega_kt - \delta_k).\]

계수 \(A_k\), \(\delta_k\)는 처음 위치와 속도로 정합니다. 모드 벡터의 직교성을 쓰면 처음 위치를 각 모드에 사영해 바로 구할 수 있습니다.

4.2.2맥놀이와 에너지 교환

4.1절의 두 진동자에서 1번만 \(x_1(0) = A\)로 당기고 놓으면(\(x_2(0) = 0\), 정지) 처음 상태는 두 모드를 같은 양으로 섞은 것입니다.

\[x_1 = \frac A2(\cos\omega_1t + \cos\omega_2t) = A\cos\frac{\omega_2 - \omega_1}2t\,\cos\frac{\omega_1 + \omega_2}2t,\] \[x_2 = \frac A2(\cos\omega_1t - \cos\omega_2t) = A\sin\frac{\omega_2 - \omega_1}2t\,\sin\frac{\omega_1 + \omega_2}2t.\]

두 식의 둘째 등호는 삼각함수 합차 공식 \(\cos a + \cos b = 2\cos\frac{a - b}2\cos\frac{a + b}2\), \(\cos a - \cos b = -2\sin\frac{a - b}2\sin\frac{a + b}2\)를 쓴 것입니다(\(a = \omega_1t\), \(b = \omega_2t\)).

처음 상태를 모드로 나누면 \((A, 0) = \frac A2(1, 1) + \frac A2(1, -1)\)입니다. 처음에는 두 모드가 같은 위상이라 2번에서 서로 지워집니다. 진동수가 조금 달라 시간이 지나면 위상이 어긋나고, 반 맥놀이 주기 뒤에는 위상이 정반대가 되어 이번에는 1번에서 지워집니다.

연결이 약하면(\(k' \ll k\)) \(\omega_2 - \omega_1\)이 작아, 평균 진동수 \(\frac{\omega_1 + \omega_2}2\)로 빨리 진동하면서 진폭이 느리게 바뀝니다. 1번의 진폭이 줄어드는 동안 2번이 커지고, 반 맥놀이 주기 \(\frac{\pi}{\omega_2 - \omega_1}\)마다 에너지가 완전히 넘어갔다 돌아옵니다. 아래 실습 카드에서 이 에너지 교환을 볼 수 있습니다.

예제 4.2.1

\(k/m = 100\) s⁻², \(k'/m = 2\) s⁻²이면 에너지가 1번에서 2번으로 완전히 넘어가는 데 걸리는 시간은?

풀이. \(\omega_1 = 10\), \(\omega_2 = \sqrt{104} \approx 10.198\) rad/s. \(\frac{\pi}{0.198} \approx 15.9\) s. 그동안 약 25번 진동합니다.

이런 에너지 교환은 결합된 진자, 분자 진동, 양자역학의 두 준위 계(진동 효과), 결합 회로에서 같은 수학으로 나타납니다. 진동자가 많이 이어지면 정규 모드가 파동이 되고, 이 극한이 줄의 파동 방정식입니다(공통9 2.1절).

요약
  1. 일반 운동 = 정규 모드의 중첩, 계수는 초기 조건으로.
  2. 약한 연결: 맥놀이로 에너지가 반 주기 \(\pi/(\omega_2 - \omega_1)\)마다 넘어간다.

4.2.3연습문제

기본

  1. 처음에 \(x_1(0) = x_2(0) = A\)로 같이 당겨 놓으면 운동은 어떻게 되는가?
    답

    모드 1만 들뜨므로 두 물체가 진동수 \(\omega_1\)로 같이 진동하고 에너지 교환이 없다.
