에너지 함수와 그 보존

본문
이 절에서 배울 것
  • 라그랑지안이 시간을 직접 포함하지 않으면 보존되는 에너지 함수 \(h\)를 정의하고 보존을 증명한다.
  • \(h\)가 역학적 에너지 \(T + U\)와 같아지는 조건을 안다.
  • 움직이는 구속에서 \(h\)는 보존되지만 \(E\)는 보존되지 않는 예를 해석한다.
먼저 알아야 할 것
  • 라그랑주 방정식 (2.1절), 순환 좌표 (2.3절).

2.4.1에너지 함수

\(L\)이 \(t\)를 직접 포함하지 않으면

\[h = \sum_i\dot q_i\frac{\partial L}{\partial\dot q_i} - L = \text{상수}.\]

보존됨을 확인하려면 \(h\)를 시간으로 미분해 라그랑주 방정식을 쓰면 됩니다. \(\frac{dh}{dt} = \sum_i(\ddot q_ip_i + \dot q_i\dot p_i) - \sum_i\left(\frac{\partial L}{\partial q_i}\dot q_i + p_i\ddot q_i\right) - \frac{\partial L}{\partial t}\)에서 \(\dot p_i = \partial L/\partial q_i\)이므로 앞의 두 합이 지워지고 \(\frac{dh}{dt} = -\frac{\partial L}{\partial t}\)만 남습니다. 순환 좌표에서 운동량이 보존되듯(2.3절), "시간이 순환"이면 \(h\)가 보존된다고 볼 수 있습니다. 이 \(h\)는 3단원의 해밀토니안이 됩니다.

2.4.2언제 \(h = E\)인가

좌표 변환(직교 좌표 ↔ 일반화 좌표)이 시간에 의존하지 않으면 \(T\)는 속도 \(\dot q_i\)의 2차식이고, 오일러의 동차 함수 정리로 \(\sum\dot q_i\,\partial T/\partial\dot q_i = 2T\)입니다. \(U\)가 속도에 무관하면 \(h = 2T - (T - U) = T + U = E\), 곧 에너지 보존입니다.

회전하는 철사 위의 구슬처럼 구속이 시간에 따라 움직이면 \(T\)에 속도의 1차 항이나 0차 항이 섞여 \(h \ne E\)가 됩니다. 이때 \(h\)는 보존되지만 \(E\)는 보존되지 않을 수 있습니다. 철사를 돌리는 바깥 장치가 일을 해 주기 때문입니다.

예제 2.4.1

수직축 둘레로 일정한 각속도 \(\omega\)로 도는 반지름 \(R\)의 원형 고리 위를 구슬이 미끄러진다. 고리 바닥에서 잰 각 \(\theta\)의 운동 방정식과 보존량은?

풀이. \(T = \frac12m(R^2\dot\theta^2 + R^2\omega^2\sin^2\theta)\), \(U = -mgR\cos\theta\). 운동 방정식 \(R\ddot\theta = (R\omega^2\cos\theta - g)\sin\theta\). \(L\)이 \(t\)를 포함하지 않으므로 \(h = \frac12mR^2\dot\theta^2 - \frac12mR^2\omega^2\sin^2\theta - mgR\cos\theta\)가 보존됩니다. \(T + U\)와는 둘째 항의 부호가 다릅니다. \(\omega^2 > g/R\)이면 바닥(\(\theta = 0\))이 불안정해지고 \(\cos\theta = g/(R\omega^2)\)인 새 평형점이 생깁니다.

요약
  1. \(L\)에 \(t\)가 없으면 \(h = \sum\dot q_ip_i - L\) 보존.
  2. 구속이 시간에 무관하고 \(U\)가 속도에 무관하면 \(h = T + U\).
  3. 움직이는 구속에서는 \(h\)는 보존, \(E\)는 바깥의 일만큼 바뀐다.

2.4.3연습문제

기본

  1. 예제 2.4.1에서 \(\theta = 0\) 근처 작은 진동의 각진동수를 구하여라(\(\omega^2 < g/R\)).
    답

    \(\ddot\theta \approx -(g/R - \omega^2)\theta\), \(\Omega = \sqrt{g/R - \omega^2}\).

  2. 감쇠 진동자의 라그랑지안으로 \(L = e^{\gamma t}\left(\frac12m\dot x^2 - \frac12kx^2\right)\)을 쓸 수 있다. 이때 \(h\)가 보존되지 않는 까닭은?
    답

    \(L\)이 시간을 직접 포함해 \(dh/dt = -\partial L/\partial t \ne 0\)이기 때문이다.
