구면 진자의 보존량과 유효 퍼텐셜

순환 좌표 · 에너지 함수 · 문제 해결 전략

출발점

라그랑지안에 어떤 좌표가 없으면 그 일반화 운동량이 보존되고, 시간이 없으면 에너지 함수가 보존됩니다. 두 보존량으로 좌표 하나만의 1차원 문제를 만들 수 있습니다.

문제 해결 전략 · 보존량으로 차원 줄이기
  1. 라그랑지안을 쓰고 순환 좌표를 찾는다.
  2. 그 운동량을 보존량으로 둔다.
  3. 에너지에 넣어 남은 좌표의 유효 퍼텐셜을 만든다.
  4. 유효 퍼텐셜의 최솟값으로 정상 운동을 찾는다.

길이 \(l\)인 구면 진자(추가 구면 위를 자유롭게 움직임)의 보존량을 쓰고, 일정한 각 \(\theta_0\)로 원을 그리는 원뿔 진자의 각속도를 구하여라. \(l = 1\) m, \(\theta_0 = 30°\)이면?

풀이

  1. \(L = \frac12ml^2(\dot\theta^2 + \sin^2\theta\,\dot\phi^2) + mgl\cos\theta\) (\(\theta\)는 아래 방향에서 잰 각).
    구면 좌표 속력.
  2. \(\phi\)가 순환: \(p_\phi = ml^2\sin^2\theta\,\dot\phi\) 보존(수직축 둘레 각운동량). \(t\)가 없어 에너지도 보존.
    두 보존량.
  3. \(E = \frac12ml^2\dot\theta^2 + U_{\text{eff}}\), \(U_{\text{eff}} = \frac{p_\phi^2}{2ml^2\sin^2\theta} - mgl\cos\theta\).
    \(\dot\phi\)를 \(p_\phi\)로 지웠다.
  4. \(\theta\) 방정식에서 \(\ddot\theta = 0\)이면 \(\dot\phi^2 = \frac g{l\cos\theta_0}\). 값: \(\dot\phi = \sqrt{9.8/0.866} = 3.36\) rad/s(주기 1.87 s).
    원뿔 진자.

의미

원뿔 진자의 주기 \(2\pi\sqrt{l\cos\theta_0/g}\)는 같은 길이 단진자의 작은 진동 주기(2.01 s)보다 짧습니다. 각이 커질수록 \(\cos\theta_0\)가 작아져 더 빨리 돕니다.

검산

뉴턴 법칙으로: 장력의 수평 성분이 구심력 \(T\sin\theta = m\dot\phi^2l\sin\theta\), 수직 성분이 중력 \(T\cos\theta = mg\). 나누면 \(\dot\phi^2 = g/(l\cos\theta)\). 같습니다.
