푸아송 괄호와 보존량

본문

어떤 양이 보존되는지 확인하려면 그 양을 시간으로 미분하고, 운동 방정식을 넣어 0이 되는지 봐야 한다. 이 계산을 매번 새로 하지 않고 한 번의 연산으로 묶을 수는 없을까? 또 각운동량의 \(x\), \(y\) 성분이 보존되면 \(z\) 성분도 저절로 보존될까?

먼저 알아야 할 것해밀턴 방정식(3.2절)을 쓴다.

3.4.1정의

위상 공간 위의 두 함수 \(f(q, p)\), \(g(q, p)\)의 푸아송 괄호는 다음과 같다.

\[\{f, g\} = \sum_i\left(\frac{\partial f}{\partial q_i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q_i}\right)\]

이 괄호는 몇 가지 성질을 가진다. 반대칭이어서 \(\{f, g\} = -\{g, f\}\)이고, 따라서 \(\{f, f\} = 0\)이다. 기본 괄호는 \(\{q_i, p_j\} = \delta_{ij}\), \(\{q_i, q_j\} = \{p_i, p_j\} = 0\)이다. 또 선형이고, 곱의 법칙 \(\{fg, h\} = f\{g, h\} + \{f, h\}g\)와 야코비 항등식을 만족한다.

3.4.2시간 변화와 보존량

물리량 \(f(q, p, t)\)의 시간 미분에 해밀턴 방정식을 넣으면 처음 질문의 한 번의 연산이 나온다.

정리 3.4.1 (시간 변화)

\[\frac{df}{dt} = \{f, H\} + \frac{\partial f}{\partial t}\]

유도는 연쇄 법칙 한 줄이다. \(\frac{df}{dt} = \sum_i\left(\frac{\partial f}{\partial q_i}\dot q_i + \frac{\partial f}{\partial p_i}\dot p_i\right) + \frac{\partial f}{\partial t}\)에 \(\dot q_i = \partial H/\partial p_i\), \(\dot p_i = -\partial H/\partial q_i\)를 넣으면 합이 정확히 \(\{f, H\}\)의 정의가 된다.

그러므로 시간을 직접 포함하지 않는 \(f\)가 보존되는 조건은 \(\{f, H\} = 0\)이다. 해밀턴 방정식 자체도 \(\dot q_i = \{q_i, H\}\), \(\dot p_i = \{p_i, H\}\)로 쓸 수 있다. 게다가 두 보존량의 괄호도 보존량이라는 푸아송 정리가 있어, 새 보존량을 찾는 데 쓰기도 한다.

예제 3.4.1

각운동량 성분 \(\ell_x = yp_z - zp_y\), \(\ell_y = zp_x - xp_z\)에 대해 \(\{\ell_x, \ell_y\}\)를 구하여라.

풀이. 곱의 법칙과 기본 괄호를 쓰면 0이 아닌 항은 \(z\)와 \(p_z\)가 짝을 이루는 것뿐이다. 따라서 \(\{yp_z - zp_y, zp_x - xp_z\} = \{yp_z, zp_x\} + \{zp_y, xp_z\} = yp_x\{p_z, z\} + xp_y\{z, p_z\} = -yp_x + xp_y = \ell_z\)이다. 중심력이면 \(\ell_x\), \(\ell_y\)가 보존되므로 푸아송 정리로 \(\ell_z\)도 보존된다. 처음 질문의 둘째 답이 이것이다.

한편 양자 역학에서는 푸아송 괄호 \(\{f, g\}\)가 교환자 \(\frac1{i\hbar}[\hat f, \hat g]\)로 바뀐다(디랙). \(\{x, p\} = 1\)이 \([\hat x, \hat p] = i\hbar\)가 되며, 이것이 불확정성 원리의 바탕이다(물리8). 그래서 푸아송 괄호는 고전 역학과 양자 역학을 잇는 다리이다.

흔한 오해푸아송 괄호의 두 항 순서를 바꾸어 부호를 틀리기 쉽다. 정의는 \(\partial_qf\,\partial_pg - \partial_pf\,\partial_qg\)이고, 이 순서여야 \(\{q, p\} = +1\)이 된다. 또 \(\{f, H\} = 0\)은 \(f\)가 시간을 직접 포함하지 않을 때만 보존의 조건이다.
마무리

푸아송 괄호 \(\{f, g\} = \sum(\partial_qf\,\partial_pg - \partial_pf\,\partial_qg)\)는 반대칭이고 기본 괄호 \(\{q, p\} = 1\)을 가진다. 처음 질문의 한 번의 연산이 \(df/dt = \{f, H\} + \partial f/\partial t\)이며, 시간을 직접 포함하지 않는 양은 \(\{f, H\} = 0\)일 때 보존된다. 두 보존량의 괄호도 보존량이므로 \(\ell_x\), \(\ell_y\)가 보존되면 \(\{\ell_x, \ell_y\} = \ell_z\)도 보존되며, 이 괄호는 양자 역학의 교환자로 이어진다.
