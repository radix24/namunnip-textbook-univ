푸아송 괄호와 보존량

본문
이 절에서 배울 것
  • 푸아송 괄호를 정의하고 계산한다.
  • 푸아송 괄호로 물리량의 시간 변화를 쓰고 보존량을 판정한다.
먼저 알아야 할 것
  • 해밀턴 방정식 (3.1절).

3.3.1정의

위상 공간 위의 두 함수 \(f(q, p)\), \(g(q, p)\)의 푸아송 괄호는

\[\{f, g\} = \sum_i\left(\frac{\partial f}{\partial q_i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q_i}\right).\]
  • 반대칭: \(\{f, g\} = -\{g, f\}\), 그래서 \(\{f, f\} = 0\).
  • 기본 괄호: \(\{q_i, p_j\} = \delta_{ij}\), \(\{q_i, q_j\} = \{p_i, p_j\} = 0\).
  • 선형성, 곱의 법칙 \(\{fg, h\} = f\{g, h\} + \{f, h\}g\), 야코비 항등식.

3.3.2시간 변화와 보존량

물리량 \(f(q, p, t)\)의 시간 미분에 해밀턴 방정식을 넣으면

정리 3.3.1 \[\frac{df}{dt} = \{f, H\} + \frac{\partial f}{\partial t}.\]

그러므로 시간을 직접 포함하지 않는 \(f\)가 보존되는 조건은 \(\{f, H\} = 0\)입니다. 해밀턴 방정식 자체도 \(\dot q_i = \{q_i, H\}\), \(\dot p_i = \{p_i, H\}\)로 쓸 수 있습니다. 두 보존량의 괄호도 보존량이라는 성질(푸아송 정리)이 있어, 새 보존량을 찾는 데 쓰기도 합니다.

예제 3.3.2

각운동량 성분 \(\ell_x = yp_z - zp_y\), \(\ell_y = zp_x - xp_z\)에 대해 \(\{\ell_x, \ell_y\}\)를 구하여라.

풀이. 곱의 법칙과 기본 괄호로 \(\{yp_z - zp_y, zp_x - xp_z\} = \{yp_z, zp_x\} + \{zp_y, xp_z\} = yp_x\{p_z, z\} + xp_y\{z, p_z\} = -yp_x + xp_y = \ell_z\). 중심력이면 \(\ell_x\), \(\ell_y\)가 보존되므로 푸아송 정리로 \(\ell_z\)도 보존됩니다.

양자역학에서는 푸아송 괄호 \(\{f, g\}\)가 교환자 \(\frac1{i\hbar}[\hat f, \hat g]\)로 바뀝니다(디랙). \(\{x, p\} = 1\)이 \([\hat x, \hat p] = i\hbar\)가 되며, 이것이 불확정성 원리의 바탕입니다(물리8).

요약
  1. \(\{f, g\} = \sum(\partial_qf\,\partial_pg - \partial_pf\,\partial_qg)\), \(\{q, p\} = 1\).
  2. \(df/dt = \{f, H\} + \partial f/\partial t\). 보존 ⟺ \(\{f, H\} = 0\).

3.3.3연습문제

기본

  1. 자유 입자 \(H = p^2/2m\)에서 \(f = x - pt/m\)이 보존됨을 정리 3.3.1로 보여라.
    답

    \(\{f, H\} = \{x, H\} = p/m\), \(\partial f/\partial t = -p/m\). 합이 0.
