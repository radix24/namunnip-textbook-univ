조화 진동자를 정준 방정식으로 풀고 위상 공간에 그리기

1계 연립 방정식 · 위상 궤적 · 문제 해결 전략

출발점

\(H = \frac{p^2}{2m} + \frac12kx^2\)에서 정준 방정식은 \(\dot x = p/m\), \(\dot p = -kx\)입니다. \(H\)가 시간을 포함하지 않으므로 \(H = E\)가 보존되고, 위상 공간 \((x, p)\)에서 궤적은 \(H = E\)인 곡선, 곧 타원입니다.

문제 해결 전략 · 정준 방정식 풀기
  1. 정준 방정식 두 개를 쓴다.
  2. 하나를 미분해 다른 하나에 넣어 2계 방정식으로 풀거나, 직접 해의 꼴을 넣는다.
  3. 보존되는 \(H = E\)로 위상 궤적의 모양을 그린다.

\(m = 0.20\) kg, \(k = 20\) N/m인 진동자를 \(x_0 = 0.050\) m에서 정지 상태로 놓았다. (가) \(x(t)\)와 \(p(t)\)는? (나) 위상 공간 궤적의 두 반축과 넓이는? (다) 넓이가 \(2\pi E/\omega\)임을 확인하여라.

풀이

  1. \(\dot x = p/m\)을 미분해 \(\ddot x = \dot p/m = -(k/m)x\). \(\omega = \sqrt{k/m} = 10\) rad/s.
    두 식을 합친다.
  2. (가) \(x = 0.050\cos10t\) m, \(p = m\dot x = -0.10\sin10t\) kg·m/s.
    처음 조건.
  3. (나) 반축 \(x_{\max} = 0.050\) m, \(p_{\max} = 0.10\) kg·m/s. 넓이 \(\pi\times0.050\times0.10 = 0.0157\) J·s.
    타원 넓이 \(\pi ab\).
  4. (다) \(E = \frac12kx_0^2 = 0.025\) J, \(2\pi E/\omega = 2\pi\times0.025/10 = 0.0157\) J·s. 같다.
    \(x_{\max} = \sqrt{2E/k}\), \(p_{\max} = \sqrt{2mE}\).

의미

위상 공간 궤적이 둘러싸는 넓이 \(\oint p\,dx\)(작용 변수)는 \(2\pi E/\omega\)입니다. 양자역학 초기(보어-조머펠트)에는 이 넓이가 \(h\)의 정수배라는 조건으로 진동자의 에너지 \(E = n\hbar\omega\)를 얻었습니다. 해밀턴 역학의 위상 공간이 양자역학으로 이어지는 한 예입니다(3.3절에서 위상 공간을 더 다룸).

검산

\(t\)에 상관없이 \(\frac{p^2}{2m} + \frac12kx^2 = \frac{0.01\sin^2}{0.4} + 10\times0.0025\cos^2 = 0.025\) J로 일정합니다. 단위: kg·m/s × m = J·s(작용의 단위).
