라그랑주 승수와 구속력

본문
이 절에서 배울 것
  • 구속 조건을 라그랑주 승수로 방정식에 넣는다.
  • 승수에서 구속력(장력, 수직 항력)을 구한다.
먼저 알아야 할 것
  • 라그랑주 방정식 (2.1절), 라그랑주 승수법 (공통2 5.2절).

라그랑주 방법은 구속력을 없애 주는 것이 장점이었지만, 때로는 그 구속력이 바로 알고 싶은 값입니다. 롤러코스터가 레일을 누르는 힘, 줄이 끊어지지 않을 장력 같은 것입니다. 라그랑주 승수는 구속을 줄이지 않고 남겨 둔 채 "구속을 지키게 하는 힘의 크기"를 미지수 \(\lambda\)로 두어 함께 구하는 방법입니다.

2.6.1방법

2.1절에서는 구속을 써서 좌표를 줄였기 때문에 구속력이 사라졌습니다. 구속력이 궁금하거나 좌표를 줄이기 어려울 때는, 구속을 줄이지 않은 좌표로 쓰고 구속 \(f(q_1, \dots, q_n) = 0\)마다 승수 \(\lambda\)를 하나씩 두어

\[\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} - \frac{\partial L}{\partial q_i} = \lambda\frac{\partial f}{\partial q_i}\]

와 \(f = 0\)을 함께 풉니다. 오른쪽 \(\lambda\,\partial f/\partial q_i\)가 바로 \(q_i\) 방향의 일반화 구속력입니다. 미적분학의 라그랑주 승수법과 같은 생각으로, 구속면에 수직인 방향(기울기 \(\nabla f\))으로 구속력이 작용합니다.

승수의 뜻을 그림으로 보면, 구속 \(f = 0\)은 입자가 머물러야 하는 면(또는 곡선)입니다. 이상적인 구속력은 그 면을 따라 미끄러지는 운동을 방해하지 않으므로 면에 수직, 곧 \(\nabla f\) 방향입니다. 크기만 모르니 \(\lambda\nabla f\)로 두고, \(\lambda\)는 입자가 면을 벗어나지 않는다는 조건으로 정해집니다.

2.6.2예

예제 2.6.1

단진자를 극좌표 \(r, \phi\)로 쓰고 구속 \(f = r - l = 0\)을 승수로 넣어 줄의 장력을 구하여라.

풀이. \(L = \frac12m(\dot r^2 + r^2\dot\phi^2) + mgr\cos\phi\). \(r\) 방정식: \(m\ddot r - mr\dot\phi^2 - mg\cos\phi = \lambda\). \(\phi\) 방정식: \(\frac{d}{dt}(mr^2\dot\phi) + mgr\sin\phi = 0\). 구속 \(r = l\)을 넣으면 \(\lambda = -ml\dot\phi^2 - mg\cos\phi\). 반지름 방향 구속력이 \(\lambda\)이므로 장력(중심 방향)은 \(T = -\lambda = ml\dot\phi^2 + mg\cos\phi\). 뉴턴 법칙으로 구한 결과와 같습니다.

예제 2.6.2

물리1 2.1절의 반원통 문제(꼭대기에서 미끄러지는 물체)를 승수로 풀면 물체가 면을 떠나는 각도는?

풀이. 같은 방법으로 수직 항력 \(N = \lambda = mg(3\cos\phi - 2)\)(에너지 보존 \(R\dot\phi^2 = 2g(1 - \cos\phi)\) 사용). \(N = 0\)에서 \(\cos\phi = 2/3\), 약 48.2°.

주의\(\lambda\)의 부호와 크기는 구속식을 어떻게 썼느냐에 달려 있습니다. \(f = r - l\) 대신 \(f = l - r\)로 쓰면 \(\lambda\)의 부호가 바뀌고, \(f = r^2 - l^2\)으로 쓰면 \(\partial f/\partial r = 2r\)이라 \(\lambda\)가 \(1/2l\)배가 됩니다. 물리적인 힘은 \(\lambda\,\partial f/\partial q_i\)로 계산해야 같은 값이 나옵니다.

구속 조건이 속도를 포함해 좌표 관계식으로 적분되지 않는 경우(굴러가는 원판 같은 비홀로노믹 구속)에도 승수 방법을 넓혀 쓸 수 있습니다.

요약
  1. 구속 \(f = 0\)마다 승수 \(\lambda\): \(\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} - \frac{\partial L}{\partial q_i} = \lambda\frac{\partial f}{\partial q_i}\).
  2. \(\lambda\,\partial f/\partial q_i\)가 일반화 구속력.

2.6.3연습문제

기본

  1. 예제 2.6.1에서 진자를 수평 위치(\(\phi = 90°\))에서 놓았을 때 바닥(\(\phi = 0\))에서의 장력은?
    답

    바닥에서 \(l\dot\phi^2 = 2g\)이므로 \(T = 2mg + mg = 3mg\).
