자기장 속 전하의 해밀토니안

Legendre 변환 · 정준 운동량 · 문제 해결 전략

출발점

전자기장 속 전하의 라그랑지안은 \(L = \frac12mv^2 - q\phi + q\mathbf v\cdot\mathbf A\)이다. 정준 운동량 \(\mathbf p = m\mathbf v + q\mathbf A\)는 보통의 운동량과 다르며, 해밀토니안은 \(\mathbf p\)로 써야 한다.

문제 해결 전략 · Legendre 변환
  1. \(p_i = \partial L/\partial\dot q_i\)를 구한다.
  2. 속도를 \(p\)로 풀어낸다.
  3. \(H = \sum p_i\dot q_i - L\)에 넣어 \(q, p\)만의 함수로 쓴다.
  4. 정준 방정식으로 알려진 운동이 나오는지 확인한다.

균일한 자기장 \(\mathbf B = B\hat{\mathbf z}\)(\(\mathbf A = (-By/2, Bx/2, 0)\), \(\phi = 0\)) 속 전하의 해밀토니안을 구하고, 정준 방정식에서 원운동 각속도를 얻어라.

풀이

  1. \(\mathbf p = m\mathbf v + q\mathbf A\), 곧 \(m\mathbf v = \mathbf p - q\mathbf A\).
    \(\mathbf v\cdot\mathbf A\) 항 때문에 \(q\mathbf A\)가 더해진다.
  2. \(H = \mathbf p\cdot\mathbf v - L = \frac{(\mathbf p - q\mathbf A)^2}{2m}\).
    \(\frac12mv^2\)를 \(\mathbf p\)로 쓴 것. 자기력은 일을 하지 않아 에너지는 운동 에너지뿐.
  3. \(\dot x = \partial H/\partial p_x = (p_x + qBy/2)/m = v_x\), \(\dot p_x = -\partial H/\partial x = \frac{qB}{2m}(p_y - qBx/2) = \frac{qB}2v_y\).
    정준 방정식.
  4. \(m\dot v_x = \dot p_x + \frac{qB}2\dot y = qBv_y\), 마찬가지로 \(m\dot v_y = -qBv_x\). 각속도 \(\omega_c = qB/m\)(사이클로트론 진동수).
    Lorentz 힘 \(q\mathbf v\times\mathbf B\)와 같다.

의미

양자역학에서 자기장 속 전자의 해밀토니안 \((\hat{\mathbf p} - q\mathbf A)^2/2m\)이 바로 이것이다. 정준 운동량은 게이지(\(\mathbf A\)의 선택)에 따라 바뀌지만, \(m\mathbf v\)와 운동은 바뀌지 않는다.

검산

전자(\(m = 9.11\times10^{-31}\), \(B = 1\) T): \(\omega_c = 1.76\times10^{11}\) rad/s, 진동수 28 GHz. 전자 사이클로트론 공명에서 쓰는 값과 맞다.
