반구 위의 구슬: 수직 항력과 떠나는 각

라그랑주 승수 · 구속력 · 문제 해결 전략

출발점

구속을 남겨 두고 승수 \(\lambda\)를 두면, 라그랑주 방정식의 오른쪽 \(\lambda\,\partial f/\partial q_i\)가 구속력입니다. 구속력이 0이 되는 순간 물체는 면을 떠납니다.

문제 해결 전략 · 라그랑주 승수
  1. 구속을 줄이지 않은 좌표(예: \(r\), \(\theta\))로 \(L\)을 쓴다.
  2. 구속식 \(f = 0\)을 쓴다.
  3. 승수가 붙은 라그랑주 방정식과 구속식을 함께 푼다.
  4. \(\lambda\)를 물리적 힘으로 읽고 부호를 해석한다.

반지름 \(R\)인 매끄러운 반구 꼭대기에서 질량 \(m\)인 구슬이 처음 속력 \(v_0\)로 미끄러지기 시작한다. 수직 항력을 각 \(\theta\)(꼭대기에서 잰)의 함수로 구하고, \(v_0 = 0.5\sqrt{gR}\)일 때 떠나는 각을 구하여라.

풀이

  1. \(L = \frac12m(\dot r^2 + r^2\dot\theta^2) - mgr\cos\theta\), 구속 \(f = r - R = 0\).
    극좌표, 높이 \(r\cos\theta\).
  2. \(r\) 방정식: \(m\ddot r - mr\dot\theta^2 + mg\cos\theta = \lambda\). 구속 대입: \(\lambda = mg\cos\theta - mR\dot\theta^2\).
    \(\lambda\)가 바깥 방향 수직 항력.
  3. 에너지: \(R\dot\theta^2 = \frac{v_0^2}R + 2g(1 - \cos\theta)\). 넣으면 \(N = mg(3\cos\theta - 2) - \frac{mv_0^2}R\).
    \(\theta\) 방정식 대신 에너지 보존.
  4. \(N = 0\): \(\cos\theta = \frac23 + \frac{v_0^2}{3gR} = 0.667 + 0.083 = 0.75\), \(\theta = 41.4°\).
    \(v_0 = 0\)이면 48.2°.

의미

처음에 밀어 주면 더 일찍(작은 각에서) 떨어집니다. \(v_0 \ge \sqrt{gR}\)이면 꼭대기에서 바로 떠납니다(\(N(0) = mg - mv_0^2/R \le 0\)).

검산

\(v_0 = 0\)이면 \(\cos\theta = 2/3\)로 물리1 예제 2.1.1과 같습니다.
