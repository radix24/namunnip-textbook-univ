일반화 좌표와 라그랑지안

본문
이 절에서 배울 것
  • 구속 조건이 있는 계의 자유도와 일반화 좌표를 고른다.
  • 일반화 좌표로 라그랑지안을 쓰고 라그랑주 방정식으로 운동 방정식을 얻는다.
먼저 알아야 할 것
  • 해밀턴 원리 (1.3절), 극좌표 속도 (물리1 1.1절).

2.1.1구속과 자유도

진자 추는 줄 길이 때문에 원 위에서만, 구슬은 철사 위에서만 움직입니다. 이런 조건을 구속이라 합니다. 좌표 사이의 관계식 \(f(\mathbf r_1, \dots, t) = 0\)으로 쓸 수 있는 구속(홀로노믹 구속)이 \(k\)개이면, \(N\)개 입자 계의 자유도는 \(3N - k\)이고, 그만큼의 독립 좌표 \(q_1, \dots, q_n\)(일반화 좌표)로 계의 배치를 나타낼 수 있습니다. 평면 진자는 각도 \(\phi\) 하나, 이중 진자는 두 각도면 됩니다.

2.1.2라그랑주 방정식

\(T\)와 \(U\)를 일반화 좌표와 그 시간 미분으로 쓰고 \(L = T - U\)로 두면, 구속력이 일을 하지 않는 한(이상적인 구속) 해밀턴 원리에서

정리 2.1.1 \[\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} = \frac{\partial L}{\partial q_i},\qquad i = 1, \dots, n.\]

\(p_i = \partial L/\partial\dot q_i\)를 일반화 운동량, \(F_i = \partial L/\partial q_i\)를 일반화 힘이라 하면 \(\dot p_i = F_i\)로 뉴턴 법칙과 같은 꼴입니다. 각도 좌표이면 \(p_i\)는 각운동량, \(F_i\)는 토크입니다.

  1. 일반화 좌표를 고른다.
  2. 각 입자의 직교 좌표를 일반화 좌표로 쓰고 미분해 \(T\)를 구한다.
  3. \(U\)를 쓴다. \(L = T - U\).
  4. 좌표마다 라그랑주 방정식을 쓴다.
예제 2.1.2

수직 원뿔 \(z = \rho\cot\alpha\)의 안쪽 면을 마찰 없이 움직이는 입자의 운동 방정식을 원통 좌표 \(\rho, \phi\)로 구하여라.

풀이. \(z = \rho\cot\alpha\)이므로 \(T = \frac12m(\dot\rho^2 + \rho^2\dot\phi^2 + \dot z^2) = \frac12m(\dot\rho^2\csc^2\alpha + \rho^2\dot\phi^2)\), \(U = mg\rho\cot\alpha\). \(\phi\) 방정식: \(\frac{d}{dt}(m\rho^2\dot\phi) = 0\)(각운동량 보존). \(\rho\) 방정식: \(m\csc^2\alpha\,\ddot\rho = m\rho\dot\phi^2 - mg\cot\alpha\). 수직 항력은 어디에도 나오지 않습니다.

2.1.3이중 진자

길이 \(l_1, l_2\), 질량 \(m_1, m_2\)인 이중 진자를 두 각 \(\phi_1, \phi_2\)로 나타내면

\[L = \frac12(m_1 + m_2)l_1^2\dot\phi_1^2 + \frac12m_2l_2^2\dot\phi_2^2 + m_2l_1l_2\dot\phi_1\dot\phi_2\cos(\phi_1 - \phi_2) + (m_1 + m_2)gl_1\cos\phi_1 + m_2gl_2\cos\phi_2.\]

라그랑주 방정식 둘은 서로 얽힌 비선형 방정식이고, 진폭이 크면 처음 조건의 아주 작은 차이가 시간이 지나며 크게 벌어지는 혼돈 운동을 합니다. 작은 진동에서는 4단원의 정규 모드가 됩니다. 아래 실습 카드에서 이중 진자를 돌려 볼 수 있습니다.

요약
  1. 자유도 = \(3N\) − 구속 수, 일반화 좌표 \(q_i\).
  2. \(\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} = \frac{\partial L}{\partial q_i}\). 구속력이 나오지 않는다.
