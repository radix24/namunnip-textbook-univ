케플러 문제의 숨은 보존량: Laplace-Runge-Lenz 벡터

Poisson 괄호 · 보존 판정 · 문제 해결 전략

출발점

물리량 \(f\)가 보존되는지 보려면 \(\{f, H\}\)를 계산합니다. 역제곱 힘에서는 에너지와 각운동량 말고도 근일점 방향을 가리키는 벡터 \(\mathbf A = \mathbf p\times\mathbf L - mk\hat{\mathbf r}\)가 보존됩니다.

문제 해결 전략 · Poisson 괄호로 보존 판정
  1. \(H\)를 쓴다.
  2. 기본 괄호와 곱의 법칙으로 \(\{f, H\}\)를 계산하거나, \(df/dt\)를 운동 방정식으로 직접 계산한다.
  3. 0이면 보존.
  4. 보존량의 물리적 뜻을 해석한다.

\(H = \frac{p^2}{2m} - \frac kr\)에서 \(\mathbf A = \mathbf p\times\mathbf L - mk\hat{\mathbf r}\)가 보존됨을 보여라(\(df/dt = \{f, H\}\)이므로 운동 방정식으로 시간 미분을 계산해도 된다).

풀이

  1. \(\mathbf L\)은 보존되므로 \(\frac{d}{dt}(\mathbf p\times\mathbf L) = \dot{\mathbf p}\times\mathbf L = -\frac k{r^2}\hat{\mathbf r}\times(m\mathbf r\times\dot{\mathbf r})\).
    \(\dot{\mathbf p} = -k\hat{\mathbf r}/r^2\), \(\mathbf L = m\mathbf r\times\dot{\mathbf r}\).
  2. 삼중곱: \(\hat{\mathbf r}\times(\mathbf r\times\dot{\mathbf r}) = \mathbf r(\hat{\mathbf r}\cdot\dot{\mathbf r}) - \dot{\mathbf r}(\hat{\mathbf r}\cdot\mathbf r) = \dot r\mathbf r - r\dot{\mathbf r}\).
    \(\hat{\mathbf r}\cdot\dot{\mathbf r} = \dot r\).
  3. 따라서 \(\frac{d}{dt}(\mathbf p\times\mathbf L) = mk\left(\frac{\dot{\mathbf r}}r - \frac{\dot r\mathbf r}{r^2}\right) = mk\frac{d\hat{\mathbf r}}{dt}\).
    \(\frac{d}{dt}\frac{\mathbf r}r\)를 알아본다.
  4. \(\frac{d\mathbf A}{dt} = mk\dot{\hat{\mathbf r}} - mk\dot{\hat{\mathbf r}} = 0\). 보존.
    \(\{\mathbf A, H\} = 0\).

의미

\(\mathbf A\)는 근일점을 가리키고 크기가 \(mk\epsilon\)입니다. 이것이 보존된다는 것은 타원 궤도가 돌지 않고 닫힌다는 뜻입니다. 힘이 역제곱에서 조금만 벗어나도(수성의 상대론 보정) \(\mathbf A\)가 천천히 돌아 근일점이 이동합니다.

검산

원 궤도(\(\epsilon = 0\))에서 \(\mathbf p\times\mathbf L\)은 바깥쪽 크기 \(pL = mk\)라 \(mk\hat{\mathbf r}\)과 정확히 지워져 \(\mathbf A = 0\)입니다.
