르장드르 변환과 해밀토니안

본문
이 절에서 배울 것
  • 르장드르 변환으로 라그랑지안에서 해밀토니안을 얻는다.
  • 해밀토니안을 반드시 좌표와 운동량의 함수로 쓰는 순서를 익힌다.
먼저 알아야 할 것
  • 라그랑주 방정식과 에너지 함수 (2.1절, 2.4절).

라그랑주 방법이 위치와 속도로 운동을 기술한다면, 해밀턴 방법은 위치와 운동량을 대등한 짝으로 놓고 기술합니다. 그러면 운동 방정식이 "위치의 변화율은 \(H\)를 운동량으로 미분한 것, 운동량의 변화율은 \(H\)를 위치로 미분한 것에 음의 부호"라는 대칭적인 1계 방정식이 됩니다. 이 대칭이 위상 공간, 통계역학, 양자역학으로 이어지는 길을 엽니다.

3.1.1해밀토니안

라그랑주 역학은 \((q, \dot q)\)를 변수로 쓰는 2계 방정식 \(n\)개입니다. 해밀턴 역학은 속도 대신 일반화 운동량 \(p_i = \partial L/\partial\dot q_i\)를 변수로 써서 1계 방정식 \(2n\)개로 바꿉니다. 변수를 바꾸는 방법이 르장드르 변환입니다.

\[H(q, p, t) = \sum_ip_i\dot q_i - L,\]

오른쪽의 \(\dot q_i\)는 모두 \(q, p\)로 바꿔 씁니다. 2.3절의 에너지 함수 \(h\)와 같은 식이며, 보통의 경우(좌표 변환이 시간에 무관) \(H = T + U\)입니다.

3.1.2해밀토니안 구하는 순서

  1. 일반화 좌표를 골라 \(L(q, \dot q, t)\)를 쓴다.
  2. \(p_i = \partial L/\partial\dot q_i\)를 구한다.
  3. 이 식을 \(\dot q_i\)에 대해 풀어 \(\dot q_i(q, p)\)로 만든다.
  4. \(H = \sum p_i\dot q_i - L\)에 넣어 \(q\)와 \(p\)만의 함수로 정리한다.

예를 들어 단진자는 \(L = \frac12ml^2\dot\phi^2 + mgl\cos\phi\)에서 \(p_\phi = ml^2\dot\phi\), \(\dot\phi = p_\phi/(ml^2)\)이므로 \(H = \frac{p_\phi^2}{2ml^2} - mgl\cos\phi\)로, 운동 에너지 + 퍼텐셜 에너지를 운동량으로 쓴 것입니다. 자기장 속 전하처럼 \(p\)가 \(m\dot q\)와 다른 경우는 아래 예제에서 봅니다. \(H\)로 운동 방정식을 얻는 방법(정준 방정식)은 다음 절(3.2절)에서 다룹니다.

주의\(H\)는 반드시 \(q\)와 \(p\)의 함수로 써야 합니다. \(H = \frac12m\dot r^2 + \dots\)처럼 속도가 남은 채로 \(p\)로 미분하면 틀린 답이 나옵니다. 먼저 \(p_i = \partial L/\partial\dot q_i\)를 \(\dot q_i\)에 대해 풀어 모두 바꿔 넣으세요.
요약
  1. \(H = \sum p\dot q - L\)을 \(q, p\)의 함수로 쓴다. 보통 \(T + U\).
  2. 순서: \(L\) → \(p\) → \(\dot q(q, p)\) → \(H(q, p)\).

3.1.3연습문제

기본

  1. 질량 \(m\)인 입자가 중력장 속에서 연직으로 움직일 때 \(L = \frac12m\dot z^2 - mgz\)이다. 해밀토니안은?
    답

    \(p = m\dot z\), \(H = \frac{p^2}{2m} + mgz\).

  2. 극좌표의 자유 입자 \(L = \frac12m(\dot r^2 + r^2\dot\phi^2)\)의 해밀토니안은?
    답

    \(p_r = m\dot r\), \(p_\phi = mr^2\dot\phi\), \(H = \frac{p_r^2}{2m} + \frac{p_\phi^2}{2mr^2}\).
