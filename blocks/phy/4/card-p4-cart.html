수레에 매단 진자의 작은 진동

두 자유도 · 보존량으로 좌표 줄이기 · 문제 해결 전략

출발점

2.2.3의 라그랑지안 \(L = \frac12(M + m)\dot x^2 + ml\dot x\dot\phi\cos\phi + \frac12ml^2\dot\phi^2 + mgl\cos\phi\)에서 출발합니다. 순환 좌표 \(x\)의 운동량 보존으로 \(\dot x\)를 \(\dot\phi\)로 나타내면, 남은 \(\phi\) 하나의 방정식이 됩니다.

문제 해결 전략 · 결합된 두 좌표
  1. 모든 좌표에 대해 라그랑주 방정식을 쓴다.
  2. 보존량(순환 좌표의 운동량)으로 한 좌표의 가속도를 다른 좌표로 바꾼다.
  3. 작은 진동에서는 \(\sin\phi \approx \phi\), \(\cos\phi \approx 1\)로 선형화하고 \(\omega^2\)을 읽는다.

\(M = 2.0\) kg인 수레에 \(l = 0.40\) m, \(m = 0.50\) kg인 진자를 매달았다. 처음에 수레는 정지해 있고 진자를 조금 당겼다 놓는다. (가) 작은 진동의 각진동수와 주기는? (나) 수레를 고정했을 때의 주기와 비교하여라. (\(g = 9.8\) m/s²)

풀이

  1. \(x\) 방정식: \(\frac{d}{dt}[(M + m)\dot x + ml\dot\phi\cos\phi] = 0\). 작은 진동에서 \((M + m)\ddot x + ml\ddot\phi \approx 0\).
    순환 좌표.
  2. \(\phi\) 방정식(선형화): \(ml\ddot x + ml^2\ddot\phi = -mgl\phi\).
    \(\cos\phi \approx 1\), 2차 항 버림.
  3. 첫 식에서 \(\ddot x = -\frac{ml}{M + m}\ddot\phi\)를 넣으면 \(l\ddot\phi\frac{M}{M + m} = -g\phi\), 곧 \(\omega^2 = \frac gl\cdot\frac{M + m}{M}\).
    좌표 하나로 줄이기.
  4. (가) \(\omega^2 = 24.5\times1.25 = 30.6\), \(\omega = 5.53\) rad/s, \(T = 1.14\) s.
    수치 대입.
  5. (나) 고정: \(T_0 = 2\pi\sqrt{l/g} = 1.27\) s. 움직이는 수레에서 약 10% 짧다.
    \(T/T_0 = \sqrt{M/(M + m)} = 0.894\).

의미

추가 한쪽으로 갈 때 수레가 반대로 밀려 나가므로, 추와 수레의 질량 중심은 움직이지 않고 추는 질량 중심 둘레로 더 짧은 "유효 길이" \(l\frac{M}{M + m}\)의 진자처럼 흔들립니다. 수레가 무거울수록(\(M \to \infty\)) 고정된 진자로 돌아갑니다.

검산

\(M \to \infty\)에서 \(\omega^2 \to g/l\)로 단진자와 같습니다. 수레가 가벼울수록 질량 중심 둘레의 유효 길이가 짧아져 진동이 빨라지는 방향도 맞습니다.
