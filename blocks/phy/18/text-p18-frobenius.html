급수해와 Frobenius 방법

본문
이 절에서 배울 것
  • 보통점과 정칙 특이점을 구별한다.
  • \(y = \sum a_nx^{n+s}\)를 넣어 결정 방정식과 점화식을 얻는다.
  • 급수가 끊기는 조건이 양자화(허용된 값)로 이어짐을 본다.
먼저 알아야 할 것
  • 거듭제곱급수 방법과 Frobenius 방법 (공통8 4.1절, 4.3절).

구, 원통, 원자 문제에서 변수를 분리하면 계수가 상수가 아닌 2계 미분방정식이 나옵니다. 이런 방정식은 보통 초등 함수로 풀리지 않으므로, 해를 거듭제곱급수로 놓고 계수를 하나씩 정합니다. 특이점(계수가 무한대가 되는 점) 근처에서는 \(x^s\)를 곱한 급수가 필요한데, 이것이 Frobenius 방법입니다. 물리에서는 급수가 무한히 이어지면 해가 발산하므로, 급수가 어디서 끊겨야 한다는 조건이 에너지 준위 같은 허용된 값을 줍니다.

5.1.1용어

  • 보통점: \(y'' + P(x)y' + Q(x)y = 0\)에서 \(P\), \(Q\)가 해석적인 점. 보통의 거듭제곱급수로 풀린다.
  • 정칙 특이점: \(P\)나 \(Q\)가 발산하지만 \(xP\), \(x^2Q\)는 해석적인 점(\(x = 0\)이라 할 때).
  • 결정 방정식(indicial equation): 가장 낮은 차수 항에서 나오는 \(s\)의 2차 방정식.
  • 점화식: \(a_{n+2}\)를 \(a_n\)으로 나타내는 식. 계수를 차례로 정한다.

5.1.2방법

  1. \(y = \sum_{n\ge0}a_nx^{n+s}\) (\(a_0 \ne 0\))를 방정식에 넣는다. 특이점 근처의 행동 \(x^s\)를 미리 허용하려는 것이다.
  2. 가장 낮은 차수 \(x^{s-2}\)(또는 \(x^{s-1}\))의 계수를 0으로 두면 결정 방정식이 나온다. \(a_0 \ne 0\)이므로 \(s\)에 대한 조건이 된다.
  3. 일반 차수의 계수를 0으로 두어 점화식을 얻는다. 차수를 맞추려면 합의 첨자를 옮겨야 한다.
  4. 두 근 \(s_1, s_2\)의 차가 정수가 아니면 두 독립해가 모두 이렇게 나온다. 정수이면 둘째 해에 \(\ln x\)가 섞일 수 있다.
예제 5.1.2

Legendre 방정식 \((1 - x^2)y'' - 2xy' + \ell(\ell + 1)y = 0\)의 \(x = 0\) 근처 급수해의 점화식을 구하고, \(\ell = 2\)이면 한 해가 다항식이 됨을 보여라.

풀이. \(x = 0\)은 보통점이라 \(s = 0\). \(y = \sum a_nx^n\)을 넣고 \(x^n\)의 계수를 모으면 \((n + 2)(n + 1)a_{n+2} - n(n - 1)a_n - 2na_n + \ell(\ell + 1)a_n = 0\), 곧

\[a_{n+2} = \frac{n(n + 1) - \ell(\ell + 1)}{(n + 2)(n + 1)}a_n.\]

\(\ell = 2\), \(a_0 = 1\), \(a_1 = 0\)이면 \(a_2 = \frac{0 - 6}{2} = -3\), \(a_4 = \frac{6 - 6}{12}a_2 = 0\)이고 그 뒤로 모두 0. 해는 \(1 - 3x^2\)이며, \(P_2(1) = 1\)로 맞추면 \(P_2 = \frac12(3x^2 - 1)\)입니다. 끊기지 않는 쪽 급수는 \(a_{n+2}/a_n \to 1\)이라 \(x = \pm1\)(구의 극)에서 발산합니다. 그래서 구 문제에서는 \(\ell\)이 정수여야 합니다.

주의점화식을 쓸 때 가장 흔한 실수는 합의 첨자를 옮기면서 시작 값을 잘못 두는 것입니다. \(\sum_{n\ge2}n(n - 1)a_nx^{n-2}\)를 \(x^n\)으로 맞추려면 \(n \to n + 2\)로 바꿔 \(\sum_{n\ge0}(n + 2)(n + 1)a_{n+2}x^n\)이 됩니다. 또 결정 방정식의 근이 정수만큼 차이 나면, 작은 근으로 만든 급수가 점화식 분모 0 때문에 막힐 수 있습니다.
요약
  1. 보통점은 거듭제곱급수, 정칙 특이점은 \(x^s\sum a_nx^n\).
  2. 최저 차수 → 결정 방정식, 일반 차수 → 점화식.
  3. 급수가 끊겨야 경계에서 유한 → 허용된 값(정수 \(\ell\) 등).

5.1.3연습문제

기본
