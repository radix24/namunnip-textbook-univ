변수 분리로 푸는 Laplace 방정식

본문

폭 \(a\)인 긴 금속 홈의 양 옆면은 접지하고 바닥에만 전압 \(V_0\)을 걸었다. 홈 가운데에서 바닥으로부터 \(a/2\) 높이의 퍼텐셜은 얼마일까? 편미분방정식 \(\nabla^2V = 0\)을 경계 조건과 함께 풀어야 하는데, 이것을 상미분방정식 몇 개로 쪼갤 수는 없을까?

먼저 알아야 할 것편미분방정식의 기본 개념(공통9 2.1절), 곡선 좌표의 라플라시안(1.2절), 르장드르와 베셀 함수(5.2절)를 쓴다.

6.1.1변수 분리

전하가 없는 곳의 전기 퍼텐셜, 정상 상태의 온도, 소용돌이 없는 흐름의 퍼텐셜은 모두 라플라스 방정식 \(\nabla^2V = 0\)을 따르고, 해는 경계에서 정한 조건에 따라 달라진다. 경계에서 \(V\) 값을 주는 조건을 디리클레 조건, 법선 도함수를 주는 조건을 노이만 조건이라 한다.

해를 \(V(x, y) = X(x)Y(y)\)처럼 좌표마다의 함수의 곱으로 놓으면 편미분방정식이 상미분방정식 여러 개로 갈라진다. 이 방법을 변수 분리라 한다. 갈라진 해 하나하나는 경계 조건을 다 맞추지 못하지만, 그것들을 더하면 맞출 수 있다. 그리고 경계 조건을 모두 만족하는 라플라스 방정식의 해는 하나뿐이라는 유일성 정리가 있다. 그래서 어떤 방법으로 찾든 경계를 다 맞추기만 하면 그것이 답이다.

6.1.2직교 좌표의 홈

처음 질문의 홈(\(0 < x < a\), \(y > 0\))을 풀어 보자. \(V = XY\)를 넣고 \(XY\)로 나누면 \(X''/X + Y''/Y = 0\)이다. 첫 항은 \(x\)만, 둘째 항은 \(y\)만의 함수인데 합이 늘 0이므로 각각 상수여야 한다. 그래서 \(X''/X = -k^2\), \(Y''/Y = k^2\)으로 두며, 이 \(k^2\)을 분리 상수라 한다.

옆면 조건 \(X(0) = X(a) = 0\)을 만족하려면 두 번 0이 되는 진동 해가 필요하므로 부호를 \(-k^2\)으로 골랐고, 해는 \(\sin(n\pi x/a)\), \(k = n\pi/a\)이다. 다음으로 \(Y\)는 \(e^{\pm ky}\) 가운데 멀리서 0이 되는 \(e^{-ky}\)만 남긴다. 이제 분리해를 더해 \(V = \sum c_n\sin(n\pi x/a)e^{-n\pi y/a}\)로 두고, 바닥 조건 \(V_0 = \sum c_n\sin(n\pi x/a)\)를 푸리에 사인 급수로 맞추면 \(c_n = \frac{4V_0}{n\pi}\)(\(n\) 홀수)이다.

높은 \(n\)은 \(e^{-n\pi y/a}\)로 빨리 사라진다. 가령 \(x = a/2\), \(y = a/2\)에서 첫 항은 \(\frac{4V_0}\pi e^{-\pi/2} \approx 0.265V_0\)이고 셋째 항은 \(-0.0038V_0\)이다. 그래서 처음 질문의 답은 약 \(0.26V_0\)이며, 급수 전체를 더하면 \(0.261V_0\)이다(그림 1).

6.1.3원통 좌표와 구면 좌표

원통 좌표에서 \(z\) 방향으로 균일한 문제의 일반해는 \(V = (A + B\ln\rho) + \sum(C_m\rho^m + D_m\rho^{-m})(E_m\cos m\phi + F_m\sin m\phi)\)이며, \(z\)에도 의존하면 베셀 함수가 나온다. 한편 구면 좌표에서 축대칭인 문제의 일반해는 \(V = \sum_\ell(A_\ell r^\ell + B_\ell r^{-\ell-1})P_\ell(\cos\theta)\)이다. 영역이 원점을 포함하면 원점에서 발산하는 \(B_\ell\) 항을 버리고, 무한대까지 가면 \(A_\ell\) 항을 버리거나 균일한 바깥 장만 남긴다.

예제 6.1.2

반지름 \(R\)인 접지된 도체 구를 균일한 전기장 \(E_0\hat{\mathbf z}\) 속에 놓았다. 바깥 퍼텐셜과 표면 전하 밀도의 최댓값을 구하여라.

풀이. 멀리서 \(V \to -E_0r\cos\theta\)이므로 \(\ell = 1\) 항만 필요하고, \(V = (-E_0r + B_1/r^2)\cos\theta\)로 둔다. \(r = R\)에서 0이려면 \(B_1 = E_0R^3\)이다. 표면 전하는 \(\sigma = -\varepsilon_0\partial_rV|_R = 3\varepsilon_0E_0\cos\theta\)이므로 극에서 최댓값 \(3\varepsilon_0E_0\)을 가진다. 즉 장이 극에서 바깥 장의 3배로 몰린다. 예를 들어 \(E_0 = 10^4\) V/m이면 \(\sigma_{\max} \approx 2.7\times10^{-7}\) C/m²이다.

흔한 오해분리 상수의 부호는 아무렇게나 골라도 된다고 생각하기 쉽지만, 경계 조건이 정한다. 양쪽이 0인 방향은 진동 해가 필요해 \(-k^2\)을, 한쪽으로 사라져야 하는 방향은 지수 해가 필요해 \(+k^2\)을 준다. 반대로 고르면 경계 조건을 만족하는 해가 0밖에 없다.
마무리

변수 분리는 해를 좌표마다의 함수의 곱으로 놓아 편미분방정식을 상미분방정식으로 가르고, 경계가 허용하는 분리 상수만 남긴다. 분리해를 더하고 푸리에나 르장드르 직교성으로 계수를 정하며, 유일성 정리에 따라 경계를 다 맞추면 그것이 답이다. 처음 질문의 홈 가운데 높이 \(a/2\)의 퍼텐셜은 약 \(0.26V_0\)이고, 첫 항만으로도 거의 정확하다.

6.1.4연습문제

기본

  1. 반지름 \(R\)인 구 표면 퍼텐셜이 \(V_0\cos\theta\)일 때 안쪽과 바깥 퍼텐셜을 구하여라.
    답

    안쪽은 \(V_0\frac rR\cos\theta\)로 균일한 장이고, 바깥은 \(V_0\frac{R^2}{r^2}\cos\theta\)로 쌍극자 장이다.
