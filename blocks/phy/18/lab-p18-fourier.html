Fourier 부분합과 Gibbs 현상

실습 · Parseval 정리

목표

사각파, 톱니파, 삼각파의 Fourier 부분합을 항의 수에 따라 그리고, 담긴 세기(Parseval)와 불연속점 근처의 넘침을 숫자로 봅니다. 성취기준 [물리18-03-01].

준비

회색 점선이 원래 함수, 파란 선이 \(n = 1\)부터 \(N\)까지의 부분합입니다. 담긴 세기는 \(\frac12\sum(a_n^2 + b_n^2)\)를 평균 세기 \(\langle f^2\rangle\)로 나눈 값입니다.

절차

  1. 사각파에서 N = 1, 5, 99일 때 담긴 세기와 넘침을 적는다.
  2. 톱니파와 삼각파에서 같은 N = 5의 담긴 세기를 비교한다.
  3. N을 늘리면 넘침의 높이와 폭이 각각 어떻게 되는지 그림으로 본다.

기대 결과

  • 사각파: N = 1이면 81.06%, N = 5이면 93.31%, N = 99이면 99.59%. 넘침은 N = 5에서 9.4%, N = 99에서 9.0%로 약 9%에 머물고 폭만 좁아진다.
  • N = 5에서 삼각파는 99.93%로 거의 다 담기고, 톱니파는 88.98%다. 계수가 \(1/n^2\)로 줄어드는 연속 함수가 \(1/n\)로 줄어드는 불연속 함수보다 훨씬 빨리 수렴한다.
  • 삼각파는 넘침이 없다.

분석

  1. 사각파의 담긴 세기가 \(\frac8{\pi^2}\sum_{\text{홀수 } n\le N}\frac1{n^2}\)임을 보이고 N = 1 값을 확인해 보세요.
  2. 함수에 꺾인 점이 있으면 \(1/n^2\), 끊긴 점이 있으면 \(1/n\)로 계수가 줄어드는 까닭을 부분적분으로 설명해 보세요.
