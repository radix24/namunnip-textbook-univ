복소 함수 연습 문제

문제 3 · 계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(f(z) = 1/z\)의 실수부와 허수부를 쓰고 Cauchy-Riemann 조건을 확인하여라. 어디서 해석적이 아닌가? [04-01]

    힌트 1

    \(\frac1z = \frac{\bar z}{|z|^2}\).

    힌트 2

    \(u = \frac x{x^2 + y^2}\), \(v = \frac{-y}{x^2 + y^2}\).

    풀이

    \(u_x = \frac{y^2 - x^2}{(x^2 + y^2)^2} = v_y\), \(u_y = \frac{-2xy}{(\cdot)^2} = -v_x\). \(z = 0\)을 빼고 해석적.

  2. 계산\(\int_{-\infty}^{\infty}\frac{dx}{(x^2 + 1)^2}\)을 구하여라. [04-02]

    힌트 1

    \(z = i\)는 2차 극점.

    힌트 2

    \(\text{Res} = \frac{d}{dz}\frac1{(z + i)^2}\Big|_{z=i}\).

    풀이

    \(\text{Res} = -\frac2{(2i)^3} = -\frac2{-8i} = \frac1{4i}\). \(2\pi i\cdot\frac1{4i} = \frac\pi2 \approx 1.571\).

  3. 판단\(\int_{-\infty}^{\infty}\frac{e^{-ix}}{x^2 + 1}dx\)를 위쪽 반원으로 닫아 계산하면 왜 안 되는가? [04-02]

    힌트 1

    \(z = iR\)에서 \(|e^{-iz}|\)는?

    힌트 2

    \(e^{-i(iR)} = e^{R}\).

    풀이

    위쪽 반원에서 \(e^{-iz}\)가 \(e^{R}\)처럼 커져 반원 기여가 0으로 가지 않는다. 아래로 닫아야 하고, 그러면 \(-2\pi i\)와 극점 \(-i\)를 써서 \(\pi/e\)를 얻는다.
