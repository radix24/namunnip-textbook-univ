Fourier 급수와 Parseval 정리

본문
이 절에서 배울 것
  • 주기 함수를 사인·코사인(또는 \(e^{inx}\))의 합으로 전개한다.
  • Parseval 정리로 신호의 에너지를 진동수 성분으로 나눈다.
  • 불연속점에서의 수렴과 Gibbs 현상을 안다.
먼저 알아야 할 것
  • Fourier 급수 계산 (공통8 6.1절, 6.2절), 강제 진동의 Fourier 분해 (물리1 4.5절).

소리, 진동, 교류, 결정 속 원자 배열처럼 반복되는 것은 Fourier 급수로 "어떤 진동수가 얼마나 섞였나"로 바꿔 볼 수 있습니다. 공통8에서 계수를 구하는 법을 배웠으니, 여기서는 물리에서 쓰는 두 가지를 더합니다. 복소 지수 꼴로 쓰는 법과, 에너지가 성분마다 따로 더해진다는 Parseval 정리입니다.

3.1.1용어

  • 기본 진동수: 주기 \(2L\)인 함수의 \(\omega_1 = \pi/L\). 나머지 성분은 그 정수배(배음).
  • 복소 Fourier 계수 \(c_n\): \(f(x) = \sum_{n=-\infty}^{\infty}c_ne^{in\pi x/L}\)의 계수.
  • 직교성: 서로 다른 \(n, m\)의 \(e^{in\pi x/L}\)과 \(e^{im\pi x/L}\)을 곱해 한 주기 적분하면 0.
  • Parseval 정리: 한 주기 평균 \(\overline{|f|^2} = \sum|c_n|^2\).
  • Gibbs 현상: 불연속점 근처에서 부분합이 약 9% 넘쳐 오르는 현상. 항을 늘려도 높이는 줄지 않고 폭만 좁아진다.

3.1.2복소 꼴과 계수

목적: 사인과 코사인을 따로 다루지 않고 한 식으로 계산하기. 직교성 덕분에 \(f\)에 \(e^{-im\pi x/L}\)을 곱해 적분하면 \(m\)번째 항만 남습니다.

\[c_n = \frac1{2L}\int_{-L}^{L}f(x)e^{-in\pi x/L}dx,\qquad c_{-n} = c_n^*\ (f\text{가 실수일 때}).\]

실수 꼴과는 \(a_n = 2\,\text{Re}\,c_n\), \(b_n = -2\,\text{Im}\,c_n\)로 이어집니다. 미분이 \(in\pi/L\)을 곱하는 것으로 바뀌어, 미분방정식에 넣기 편합니다.

3.1.3Parseval 정리

목적: "전체 세기 = 성분 세기의 합"을 확인하기. 피타고라스 정리의 무한 차원 판입니다.

  1. \(|f|^2 = ff^* = \sum_n\sum_mc_nc_m^*e^{i(n - m)\pi x/L}\). 두 급수를 곱한다.
  2. 한 주기 평균을 내면 직교성으로 \(n \ne m\)인 항이 모두 0이 된다. 서로 다른 진동수의 곱은 평균이 0이기 때문이다.
  3. 남는 것은 \(\sum_n|c_n|^2\).

소리라면 전체 음량이 배음마다의 음량의 합이고, 교류라면 실효값의 제곱이 각 고조파 실효값 제곱의 합입니다.

예제 3.1.2

진폭 1인 사각파(\(0 < x < \pi\)에서 1, \(-\pi < x < 0\)에서 −1)의 Fourier 급수를 쓰고, Parseval 정리로 \(\sum_{k\ \text{홀수}}1/k^2\)을 구하여라.

풀이. 기함수라 사인만 남고 \(b_n = \frac4{n\pi}\) (\(n\) 홀수), 짝수는 0. \(f = \frac4\pi\left(\sin x + \frac13\sin3x + \frac15\sin5x + \cdots\right)\). 평균 \(\overline{f^2} = 1\). 실수 꼴의 Parseval은 \(\overline{f^2} = \frac{a_0^2}4 + \frac12\sum(a_n^2 + b_n^2)\)이므로 \(1 = \frac12\sum_{\text{홀수}}\frac{16}{n^2\pi^2}\), 곧 \(\sum_{\text{홀수}}\frac1{n^2} = \frac{\pi^2}8 \approx 1.2337\). 첫 세 항만 더해도 \(1 + 0.111 + 0.04 = 1.151\)로 에너지의 93%입니다.

주의불연속점에서 급수는 \(f\)의 값이 아니라 좌우 극한의 평균으로 수렴합니다(사각파는 0). 또 항을 많이 넣어도 불연속점 바로 옆의 넘침(약 9%)은 사라지지 않습니다. "항을 늘리면 모든 점에서 고르게 가까워진다"는 생각은 불연속 함수에서는 틀립니다. 평균 제곱 오차는 0으로 갑니다.
요약
  1. \(c_n = \frac1{2L}\int fe^{-in\pi x/L}dx\), 실수 함수는 \(c_{-n} = c_n^*\).
  2. Parseval: 평균 세기 = \(\sum|c_n|^2\). 진동수 성분끼리는 섞이지 않는다.
  3. 불연속점: 평균값으로 수렴, Gibbs 넘침 약 9%.

3.1.4연습문제

기본

  1. \(f(x) = x\) (\(-\pi < x < \pi\), 주기 \(2\pi\))의 계수가 \(b_n = \frac{2(-1)^{n+1}}n\)임을 이용해 Parseval 정리로 \(\sum1/n^2\)을 구하여라.
    답

    \(\overline{x^2} = \pi^2/3 = \frac12\sum\frac4{n^2}\), \(\sum\frac1{n^2} = \frac{\pi^2}6\).
