급수가 끊겨야 하는 까닭: 양자 조화 진동자

급수해 · 점화식 · 양자화 · 문제 해결 전략

출발점

양자 조화 진동자의 Schrödinger 방정식을 무차원으로 쓰고 \(\psi = h(\xi)e^{-\xi^2/2}\)로 두면 Hermite 방정식 \(h'' - 2\xi h' + (\varepsilon - 1)h = 0\)이 나옵니다(\(\varepsilon = 2E/\hbar\omega\)).

문제 해결 전략 · 급수해와 끊김 조건
  1. \(h = \sum a_n\xi^n\)을 넣어 점화식을 얻는다.
  2. 끊기지 않을 때 큰 \(n\)에서의 비 \(a_{n+2}/a_n\)으로 행동을 판단한다.
  3. 물리 조건(경계에서 유한)에 맞게 끊김 조건을 고른다.
  4. 허용된 값(에너지)을 정리한다.

점화식을 구하고, \(\psi\)가 무한대에서 0이 되려면 \(E = (n + \frac12)\hbar\omega\)이어야 함을 보여라.

풀이

  1. \(\xi^n\)의 계수: \((n + 2)(n + 1)a_{n+2} - 2na_n + (\varepsilon - 1)a_n = 0\), \(a_{n+2} = \frac{2n + 1 - \varepsilon}{(n + 2)(n + 1)}a_n\).
    \(\xi h'\)는 차수를 바꾸지 않으므로 \(-2na_n\).
  2. 끊기지 않으면 큰 \(n\)에서 \(a_{n+2}/a_n \approx 2/n\). 이것은 \(e^{\xi^2} = \sum\frac{\xi^{2k}}{k!}\)의 계수 비와 같다.
    \(e^{\xi^2}\)은 \(a_{2k+2}/a_{2k} = \frac1{k+1} \approx \frac2n\).
  3. 그러면 \(\psi \sim e^{\xi^2}e^{-\xi^2/2} = e^{\xi^2/2} \to \infty\). 확률을 정규화할 수 없다.
    물리적으로 허용되지 않는 해.
  4. 따라서 어떤 \(n\)에서 \(2n + 1 - \varepsilon = 0\), 곧 \(\varepsilon = 2n + 1\), \(E = (n + \frac12)\hbar\omega\). 다른 쪽 급수는 \(a_0\) 또는 \(a_1\)을 0으로 둔다.
    급수가 다항식(Hermite 다항식)이 된다.

의미

에너지 양자화는 "급수가 끊겨야 한다"는 수학 조건에서 나옵니다. Legendre 방정식에서 \(\ell\)이 정수여야 했던 것(본문 예제 5.1.2), 수소 원자의 주양자수(물리8)도 같은 구조입니다.

검산

\(n = 1\): \(\varepsilon = 3\), \(a_1 = 1\), \(a_3 = \frac{3 - 3}{6} = 0\). \(h = \xi\), \(\psi = \xi e^{-\xi^2/2}\). 방정식에 넣으면 \(0 - 2\xi + 2\xi = 0\). 맞습니다.
