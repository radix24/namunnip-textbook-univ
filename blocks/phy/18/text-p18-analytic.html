해석 함수와 Cauchy-Riemann 조건

본문
이 절에서 배울 것
  • 복소 함수가 미분 가능하려면 Cauchy-Riemann 조건이 필요함을 유도한다.
  • 해석 함수의 실수부와 허수부가 라플라스 방정식을 만족함을 보이고 2차원 퍼텐셜 문제에 쓴다.
먼저 알아야 할 것
  • 복소수와 복소 함수 (공통9 3.1절, 3.3절), Cauchy-Riemann 방정식 (공통9 3.4절).

복소 함수를 미분할 수 있다는 조건은 실수 함수보다 훨씬 까다롭습니다. 그런데 그 까다로운 조건을 통과한 함수(해석 함수)는 놀라운 성질을 갖습니다. 실수부와 허수부가 저절로 라플라스 방정식을 풀고, 적분이 경로에 거의 무관해집니다. 그래서 2차원 정전기, 유체 흐름, 그리고 다음 절의 실수 적분 계산에 쓰입니다.

4.1.1용어

  • 복소 함수: \(f(z) = u(x, y) + iv(x, y)\), \(z = x + iy\).
  • 복소 미분: \(f'(z) = \lim_{\Delta z\to0}\frac{f(z + \Delta z) - f(z)}{\Delta z}\). \(\Delta z\)가 어느 방향에서 0으로 가든 같아야 한다.
  • 해석 함수: 어떤 영역의 모든 점에서 복소 미분 가능한 함수.
  • 조화 함수: 라플라스 방정식 \(\nabla^2u = 0\)을 만족하는 함수.
  • 켤레 조화 함수: 해석 함수 \(u + iv\)에서 \(u\)에 대한 \(v\).

4.1.2Cauchy-Riemann 조건 유도

목적: "어느 방향으로 다가가도 같은 도함수"를 식으로 쓰기. 두 방향만 비교해도 조건이 나옵니다.

  1. 실수축 방향(\(\Delta z = \Delta x\)): \(f' = u_x + iv_x\). \(y\)를 고정하고 \(x\)로 미분했다.
  2. 허수축 방향(\(\Delta z = i\Delta y\)): \(f' = \frac{u_y + iv_y}{i} = v_y - iu_y\). \(i\)로 나누면 실수부와 허수부가 바뀐다.
  3. 둘이 같아야 하므로 실수부끼리, 허수부끼리 맞춘다.
정리 4.1.1 \[u_x = v_y,\qquad u_y = -v_x.\]

편도함수가 연속이고 이 조건을 만족하면 \(f\)는 해석적이다.

첫 식을 \(x\)로, 둘째 식을 \(y\)로 미분해 더하면 \(u_{xx} + u_{yy} = v_{yx} - v_{xy} = 0\). 실수부가 조화 함수입니다. \(v\)도 마찬가지입니다. 또 \(\nabla u\cdot\nabla v = u_xv_x + u_yv_y = 0\)이라 \(u\) 등고선과 \(v\) 등고선은 직각으로 만납니다. 정전기에서 \(u\)를 퍼텐셜로 보면 \(v\) 등고선이 전기력선입니다.

예제 4.1.2

(가) \(f = z^2\) (나) \(f = \bar z = x - iy\)가 해석적인지 판정하여라. (가)를 2차원 흐름의 복소 퍼텐셜로 보면 무슨 흐름인가?

풀이. (가) \(u = x^2 - y^2\), \(v = 2xy\). \(u_x = 2x = v_y\), \(u_y = -2y = -v_x\). 해석적. (나) \(u = x\), \(v = -y\): \(u_x = 1 \ne v_y = -1\). 어디서도 해석적이 아닙니다. (가)의 \(v = 2xy\) 등고선(쌍곡선)은 직각 모서리 안쪽을 도는 흐름의 유선입니다.

주의\(u\)와 \(v\)가 각각 매끄러운 함수여도 \(f = u + iv\)가 해석적이라는 보장은 없습니다. 예제의 \(\bar z\)는 두 성분이 모두 1차 함수인데도 해석적이 아닙니다. 판정은 반드시 Cauchy-Riemann 조건으로 하세요. 간단한 요령: \(f\)를 \(z\)만으로 쓸 수 있고 \(\bar z\)가 섞이지 않으면 대개 해석적입니다.
요약
  1. 복소 미분은 방향에 무관해야 한다 → \(u_x = v_y\), \(u_y = -v_x\).
  2. 해석 함수의 \(u\), \(v\)는 조화 함수이고 등고선이 직교한다.
  3. 2차원 퍼텐셜과 흐름 문제를 복소 함수 하나로 푼다.

4.1.3연습문제

기본

  1. \(u = e^x\cos y\)가 조화 함수임을 보이고 켤레 \(v\)를 구하여라. \(f\)는 무엇인가?
    답

    \(u_{xx} + u_{yy} = e^x\cos y - e^x\cos y = 0\). \(v_y = u_x = e^x\cos y\)에서 \(v = e^x\sin y\) (+상수). \(f = e^z\).
