원판의 정상 온도와 평균값 성질

원통 좌표 변수 분리 · 경계 맞추기 · 문제 해결 전략

출발점

원판 안(\(\rho < R\))의 Laplace 방정식 해는 \(V = A_0 + \sum_m\rho^m(A_m\cos m\phi + B_m\sin m\phi)\)입니다. 원점에서 유한해야 하므로 \(\rho^{-m}\)과 \(\ln\rho\)는 뺍니다.

문제 해결 전략 · 경계값을 Fourier 성분으로 맞추기
  1. 경계 함수를 \(\cos m\phi\), \(\sin m\phi\)의 합으로 쓴다(삼각함수 공식).
  2. 같은 \(m\)끼리 계수를 맞춘다(직교성).
  3. 원점에서 유한한 해만 남긴다.
  4. 원의 중심 값이 경계 평균과 같은지 확인한다.

반지름 \(R\)인 얇은 원판의 테두리 온도가 \(T(R, \phi) = T_0\sin^2\phi\)이다. 원판 안의 정상 온도와 중심 온도를 구하여라.

풀이

  1. \(\sin^2\phi = \frac12 - \frac12\cos2\phi\).
    경계 함수를 Fourier 성분으로.
  2. \(m = 0\) 항: \(A_0 = \frac{T_0}2\). \(m = 2\) 항: \(A_2R^2 = -\frac{T_0}2\), \(A_2 = -\frac{T_0}{2R^2}\). 나머지는 0.
    같은 \(m\)끼리 맞춘다.
  3. \(T(\rho, \phi) = \frac{T_0}2\left[1 - \left(\frac\rho R\right)^2\cos2\phi\right]\).
    원점에서 유한한 \(\rho^m\)만 썼다.
  4. 중심: \(T(0) = \frac{T_0}2\). \(T_0 = 80\) °C이면 40 °C.
    \(\rho = 0\)에서 \(m \ge 1\) 항이 모두 사라진다.

의미

조화 함수의 중심 값은 둘레의 평균과 같습니다(평균값 성질). 그래서 정상 상태의 온도나 퍼텐셜은 안쪽에서 극대·극소를 가질 수 없고, 가장 뜨거운 곳과 차가운 곳은 늘 경계에 있습니다.

검산

\(\rho = R\)에서 \(\frac{T_0}2(1 - \cos2\phi) = T_0\sin^2\phi\). 경계 조건을 만족합니다. \(T = \frac{T_0}2 - \frac{T_0}{2R^2}(x^2 - y^2)\)라서 직교 좌표 라플라시안도 0입니다.
