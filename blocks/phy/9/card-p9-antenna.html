짧은 안테나의 복사 저항

진동 쌍극자 · 복사 일률 · 문제 해결 전략

출발점

진동 쌍극자(\(p_0\cos\omega t\))의 평균 복사 일률은 \(\langle P\rangle = \frac{\mu_0p_0^2\omega^4}{12\pi c}\)입니다. 길이 \(d\)의 짧은 안테나에 전류 \(I_0\)가 흐르면 \(p_0 = I_0d/\omega\)이고, \(\langle P\rangle = \frac12R_{\text{rad}}I_0^2\)으로 복사 저항을 정의합니다.

문제 해결 전략 · 복사 저항
  1. 전류에서 쌍극자 모멘트 진폭 \(p_0 = I_0d/\omega\)를 구한다.
  2. 복사 일률 식에 넣는다.
  3. \(R_{\text{rad}} = 2\langle P\rangle/I_0^2\).
  4. 파장에 대한 길이 비로 해석한다.

길이 \(d = \lambda/20\)인 짧은 안테나의 복사 저항을 구하여라. 회로 저항이 2 Ω이면 공급 전력의 몇 %가 복사되나?

풀이

  1. \(\langle P\rangle = \frac{\mu_0I_0^2d^2\omega^2}{12\pi c}\).
    \(p_0\omega = I_0d\).
  2. \(R_{\text{rad}} = \frac{\mu_0\omega^2d^2}{6\pi c} = 80\pi^2\left(\frac d\lambda\right)^2\ \Omega\).
    \(\omega/c = 2\pi/\lambda\), \(\mu_0c = 120\pi\).
  3. \(d/\lambda = 0.05\): \(R_{\text{rad}} = 789.6\times0.0025 = 1.97\ \Omega\).
    값.
  4. 복사 비율 \(\frac{1.97}{1.97 + 2} \approx 50\%\).
    나머지는 열.

의미

안테나가 파장보다 훨씬 짧으면 복사 저항이 \((d/\lambda)^2\)로 작아져 효율이 떨어집니다. 그래서 라디오 안테나는 파장의 반쯤(반파장 쌍극자, 약 73 Ω, 대략값) 길이로 만듭니다.

검산

\(\omega^4\) 의존: 진동수가 두 배면 같은 쌍극자 진폭에서 복사가 16배. 짧은 파장 빛이 더 많이 산란되는(하늘이 파란) 까닭과 같은 식입니다.
