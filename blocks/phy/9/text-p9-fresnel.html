경계면의 반사와 투과: 프레넬 식

본문
이 절에서 배울 것
  • 경계 조건에서 반사·굴절 법칙과 프레넬 식을 유도한다.
  • 수직 입사의 반사율 \(R = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2\)을 쓴다.
  • 브루스터 각과 전반사를 설명한다.
먼저 알아야 할 것
  • 물질 속 경계 조건 (4.1절), 평면파와 세기 (5.2절), 스넬 법칙 (공통4 10.1절).

5.3.1세 법칙

\(z = 0\)인 경계에 입사·반사·투과파가 있을 때, 경계 조건이 경계 위 모든 점, 모든 시각에 성립하려면 세 파동의 위상이 경계에서 같아야 합니다. 그래서 진동수가 같고 \(\mathbf k\)의 경계 성분이 같습니다.

  • 세 파동 벡터는 한 평면(입사면)에 있다.
  • 반사각 = 입사각.
  • \(n_1\sin\theta_I = n_2\sin\theta_T\) (스넬).

이 세 법칙은 파동이면 늘 성립하는 기하학적 결과입니다. 얼마나 반사되는지는 전자기 경계 조건이 정합니다.

5.3.2프레넬 식

전기장이 입사면에 수직인 경우(s 편광)와 나란한 경우(p 편광)로 나눕니다. \(\mu_1 = \mu_2 = \mu_0\)이면 \(E^\parallel\), \(H^\parallel\) 연속 조건에서

정리 5.3.1 (프레넬 식) \[r_s = \frac{n_1\cos\theta_I - n_2\cos\theta_T}{n_1\cos\theta_I + n_2\cos\theta_T}, \qquad r_p = \frac{n_2\cos\theta_I - n_1\cos\theta_T}{n_2\cos\theta_I + n_1\cos\theta_T},\] \[R = |r|^2, \qquad T = 1 - R.\]

\(r_p\)의 부호는 장의 방향을 어떻게 정의하느냐에 따라 책마다 다르지만 \(R\)은 같습니다. 투과율 \(T\)는 세기의 비에 \(\frac{n_2\cos\theta_T}{n_1\cos\theta_I}\)가 붙어(단면 넓이와 속도 차이) \(R + T = 1\)이 됩니다.

5.3.3세 가지 특별한 경우

  • 수직 입사: 두 편광이 같아 \(R = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2\). 공기-유리(1.5)에서 4%.
  • 브루스터 각 \(\tan\theta_B = n_2/n_1\): \(r_p = 0\). 반사광은 s 편광만 남는다. 반사파와 굴절파가 수직인 각이다. 편광 선글라스가 물 위 반사를 막는 원리.
  • 전반사 (\(n_1 > n_2\), \(\sin\theta_I > n_2/n_1\)): \(\cos\theta_T\)가 허수가 되어 \(|r| = 1\). 경계 너머에는 지수적으로 줄어드는 소멸파가 생긴다. 광섬유가 이것을 쓴다.

아래 실습 카드에서 입사각과 굴절률을 바꾸며 두 편광의 반사율을 볼 수 있습니다.

예제 5.3.2

공기에서 유리(\(n = 1.5\))로 입사할 때 브루스터 각과, 그 각에서 s 편광의 반사율은?

풀이. \(\theta_B = \arctan1.5 \approx 56.3°\). 굴절각 \(\theta_T = 90° - 56.3° = 33.7°\). \(r_s = \frac{\cos56.3° - 1.5\cos33.7°}{\cos56.3° + 1.5\cos33.7°} = \frac{0.555 - 1.248}{0.555 + 1.248} \approx -0.384\), \(R_s \approx 0.148\). 편광되지 않은 빛을 이 각으로 비추면 반사광은 약 7.4%이고 완전히 s 편광입니다.

요약
  1. 반사·굴절 법칙은 경계에서 위상이 맞아야 한다는 데서 나온다.
  2. 프레넬 식: s, p 편광의 \(r\). 수직 입사 \(R = ((n_1 - n_2)/(n_1 + n_2))^2\).
  3. 브루스터 각에서 \(R_p = 0\), 임계각 넘으면 전반사와 소멸파.

5.3.4연습문제

기본

  1. 유리(1.5)에서 공기로 나갈 때 임계각은?
    답

    \(\arcsin(1/1.5) \approx 41.8°\).

  2. 물(1.33)과 공기의 수직 입사 반사율은?
    답

    \((0.33/2.33)^2 \approx 0.020\), 2%.

발전

  1. 렌즈 표면에 굴절률 \(\sqrt{n}\), 두께 \(\lambda/(4\sqrt n)\)인 막을 입히면 수직 입사 반사가 사라지는 까닭을 설명하세요.
    답

    공기-막, 막-유리 두 면의 반사 진폭이 \(\frac{1 - \sqrt n}{1 + \sqrt n}\)으로 같고, 막을 왕복하는 경로차가 반파장이라 서로 상쇄됩니다. 무반사 코팅의 원리입니다.
