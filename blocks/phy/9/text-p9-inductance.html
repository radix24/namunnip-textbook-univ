인덕턴스와 자기 에너지

본문
이 절에서 배울 것
  • 상호 인덕턴스를 노이만 공식으로 쓰고 \(M_{12} = M_{21}\)임을 안다.
  • 솔레노이드, 토로이드, 동축 케이블의 자체 인덕턴스를 구한다.
  • 자기 에너지 \(W = \frac12LI^2 = \frac1{2\mu_0}\int B^2d\tau\)를 유도한다.
먼저 알아야 할 것
  • 패러데이 법칙 (3.1절), 벡터 퍼텐셜 (1.3절), 인덕터의 기초 (공통4 7.2절).

3.2.1상호 인덕턴스

고리 1의 전류 \(I_1\)이 만든 자기장이 고리 2를 지나는 자속 \(\Phi_2\)는 \(I_1\)에 비례합니다: \(\Phi_2 = M_{21}I_1\). \(\Phi_2 = \oint\mathbf A_1\cdot d\mathbf l_2\)에 \(\mathbf A_1 = \frac{\mu_0I_1}{4\pi}\oint\frac{d\mathbf l_1}{\mathcal R}\)를 넣으면

정리 3.2.1 (노이만 공식) \[M_{21} = \frac{\mu_0}{4\pi}\oint\oint\frac{d\mathbf l_1\cdot d\mathbf l_2}{\mathcal R} = M_{12}.\]

모양과 위치에만 의존하고 두 고리에 대칭입니다. 놀라운 결과: 작은 고리에 전류를 흘려 큰 고리를 지나는 자속은, 큰 고리에 같은 전류를 흘려 작은 고리를 지나는 자속과 같습니다. 계산하기 쉬운 쪽을 고르면 됩니다.

3.2.2자체 인덕턴스

자기 자신의 전류가 만드는 자속 \(\Phi = LI\)의 비례 상수 \(L\)이 자체 인덕턴스이고, 전류가 변하면 역기전력 \(\mathcal E = -L\,dI/dt\)가 생깁니다.

  • 솔레노이드(길이 \(l\), 단면 \(A\), \(N\)회): \(\Phi = N\cdot\mu_0\frac NlI\cdot A\), \(L = \mu_0N^2A/l\).
  • 사각 단면 토로이드(안·밖 반지름 \(a\), \(b\), 높이 \(h\), \(N\)회): \(L = \frac{\mu_0N^2h}{2\pi}\ln\frac ba\).
  • 동축 케이블(단위 길이): \(L/l = \frac{\mu_0}{2\pi}\ln\frac ba\) (전류가 표면에만 흐를 때).

3.2.3자기 에너지

전류를 0에서 \(I\)까지 올리는 동안 역기전력을 거슬러 하는 일은 \(\int LI\,dI = \frac12LI^2\)입니다. \(LI = \Phi = \oint\mathbf A\cdot d\mathbf l\)를 쓰고 부피 전류로 일반화한 뒤 \(\nabla\times\mathbf B = \mu_0\mathbf J\)와 부분적분을 쓰면(모든 공간을 적분하면 표면 항이 사라짐)

정리 3.2.2 \[W = \frac12LI^2 = \frac12\int\mathbf A\cdot\mathbf J\,d\tau = \frac1{2\mu_0}\int_{\text{모든 공간}}B^2d\tau.\]

에너지는 자기장 속에 밀도 \(u_B = B^2/2\mu_0\)로 저장되어 있다고 볼 수 있습니다. 정전에너지 \(\frac{\epsilon_0}2E^2\)(물리5 3.1절)의 짝입니다. 반대로 에너지를 먼저 계산해 \(L = 2W/I^2\)로 인덕턴스를 구할 수도 있습니다.

예제 3.2.3

동축 케이블(안 반지름 \(a\), 밖 반지름 \(b\))의 단위 길이당 인덕턴스를 에너지로 구하세요.

풀이. \(a < s < b\)에서 \(B = \mu_0I/2\pi s\). 길이 \(l\)의 에너지 \(W = \frac1{2\mu_0}\int_a^b\left(\frac{\mu_0I}{2\pi s}\right)^22\pi sl\,ds = \frac{\mu_0I^2l}{4\pi}\ln\frac ba\). \(L/l = 2W/(I^2l) = \frac{\mu_0}{2\pi}\ln\frac ba\). 자속으로 구한 값과 같습니다.

요약
  1. \(\Phi_2 = MI_1\), \(M = \frac{\mu_0}{4\pi}\oint\oint\frac{d\mathbf l_1\cdot d\mathbf l_2}{\mathcal R}\), \(M_{12} = M_{21}\).
  2. \(\Phi = LI\), 솔레노이드 \(L = \mu_0N^2A/l\).
  3. \(W = \frac12LI^2 = \frac1{2\mu_0}\int B^2d\tau\).

3.2.4연습문제

기본

  1. 길이 30 cm, 반지름 1 cm, 1000회 감은 솔레노이드의 \(L\)은?
    답

    \(L = 4\pi\times10^{-7}\times10^6\times\pi(10^{-4})/0.3 \approx 1.3\) mH.

  2. MRI 자석(3 T, 부피 약 1 m³ 정도)에 저장된 자기 에너지를 어림하세요.
    답

    \(u = 9/(2\times4\pi\times10^{-7}) \approx 3.6\times10^6\ \text{J/m}^3\), 약 4 MJ. 실제 값은 장치마다 다릅니다(확인 필요).

발전

  1. 긴 솔레노이드(\(n_1\)회/m, 반지름 \(R\)) 안에 작은 고리(반지름 \(r < R\), 축에 수직)를 넣었습니다. \(M\)을 두 가지 방법으로 구하고 같음을 보이세요.
    답

    솔레노이드에 \(I\): 고리를 지나는 자속 \(\mu_0n_1I\pi r^2\), \(M = \mu_0n_1\pi r^2\). 고리에 \(I\): 고리의 자기장이 솔레노이드 각 감김을 지나는 자속의 합을 계산해야 해 어렵지만, 노이만 공식의 대칭으로 같은 값이 보장됩니다.
