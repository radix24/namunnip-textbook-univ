H 장과 자성체 속의 앙페르 법칙

본문
이 절에서 배울 것
  • \(\mathbf H = \mathbf B/\mu_0 - \mathbf M\)을 정의하고 \(\nabla\times\mathbf H = \mathbf J_f\)를 유도한다.
  • 선형 자성체의 투자율과 경계 조건을 쓴다.
  • 철심이 있는 솔레노이드와 자기 회로를 계산한다.
먼저 알아야 할 것
  • 속박 전류 (2.1절), 전기 변위장 (물리5 5.2절).

2.3.1자유 전류와 H

전체 전류는 우리가 흘리는 자유 전류와 속박 전류의 합 \(\mathbf J = \mathbf J_f + \nabla\times\mathbf M\)입니다. 앙페르 법칙에 넣고 정리하면

정리 2.3.1 \[\mathbf H \equiv \frac1{\mu_0}\mathbf B - \mathbf M, \qquad \nabla\times\mathbf H = \mathbf J_f, \qquad \oint\mathbf H\cdot d\mathbf l = I_{f,\text{감김}}.\]

실험에서 조절하는 것은 자유 전류이므로 \(\mathbf H\)가 편리합니다. 전기의 \(\mathbf D\)와 같은 역할이지만, \(\nabla\cdot\mathbf H = -\nabla\cdot\mathbf M\)이 0이 아닐 수 있어 대칭만으로 \(\mathbf H\)가 정해지지 않는 경우가 있습니다(앙페르 법칙을 쓸 대칭이 있는지 먼저 확인).

2.3.2선형 자성체

\(\mathbf M = \chi_m\mathbf H\)이면

\[\mathbf B = \mu_0(1 + \chi_m)\mathbf H = \mu\mathbf H, \qquad \mu = \mu_0(1 + \chi_m) = \mu_0\mu_r.\]

균일한 선형 자성체 안에서는 \(\mathbf J_b = \chi_m\mathbf J_f\)라, 자유 전류가 없는 곳에는 속박 부피 전류도 없습니다.

경계 조건 2.3.2 \[B^\perp_1 = B^\perp_2, \qquad \mathbf H^\parallel_1 - \mathbf H^\parallel_2 = \mathbf K_f\times\hat{\mathbf n}.\]

자유 면전류가 없으면 \(H^\parallel\)이 연속입니다. 그래서 자기력선은 투자율이 큰 쪽으로 몰려 들어가고, 경계에서 \(\tan\theta_1/\tan\theta_2 = \mu_1/\mu_2\)로 꺾입니다.

2.3.3철심과 자기 회로

감은 수 \(n\)인 긴 솔레노이드를 투자율 \(\mu\)인 철심으로 채우면 앙페르 법칙으로 \(H = nI\)(철심과 무관), \(B = \mu nI\)입니다. \(\mu_r\)이 수천이면 같은 전류로 수천 배의 자기장을 얻습니다.

고리 모양 철심(평균 둘레 \(l\), 단면 \(A\))에 \(N\)번 감고 틈 \(g\)를 내면, 자기력선이 철심을 따라 돌아 \(\Phi = BA\)가 어디서나 같습니다. \(\oint\mathbf H\cdot d\mathbf l = NI\)에서

\[NI = \Phi\left(\frac{l}{\mu A} + \frac{g}{\mu_0A}\right).\]

전기 회로의 \(V = I(R_1 + R_2)\)와 같은 꼴로, 괄호 안을 자기 저항이라 합니다. \(\mu \gg \mu_0\)이면 작은 틈이 자기 저항 대부분을 차지합니다.

예제 2.3.3

\(l = 30\) cm, \(\mu_r = 2000\)인 철심에 \(N = 500\), \(I = 1\) A. 틈이 없을 때와 \(g = 1\) mm일 때 \(B\)는?

풀이. 틈 없음: \(B = \mu_0\mu_rNI/l = 4\pi\times10^{-7}\times2000\times500/0.3 \approx 4.2\) T. 실제 철은 약 2 T에서 포화하므로 이 값은 선형 모형의 한계를 넘습니다. 틈 1 mm: \(B = \mu_0NI/(l/\mu_r + g) = 4\pi\times10^{-7}\times500/(1.5\times10^{-4} + 10^{-3}) \approx 0.55\) T. 1 mm 틈이 자기장을 8분의 1 가까이로 줄입니다.

요약
  1. \(\mathbf H = \mathbf B/\mu_0 - \mathbf M\), \(\nabla\times\mathbf H = \mathbf J_f\).
  2. 선형: \(\mathbf B = \mu\mathbf H\), \(\mu = \mu_0(1 + \chi_m)\).
  3. 경계: \(B^\perp\) 연속, \(H^\parallel\)은 \(K_f\)만큼 뜀. 자기 회로 \(NI = \Phi\sum l_i/(\mu_iA)\).

2.3.4연습문제

기본

  1. 반지름 \(a\)인 구리 도선(\(\chi_m = -9.7\times10^{-6}\))에 균일 전류 \(I\)가 흐릅니다. 도선 안의 \(H\), \(B\), \(M\)은?
    답

    \(H = \frac{Is}{2\pi a^2}\), \(B = \mu_0(1 + \chi_m)H\), \(M = \chi_mH\) (방향 \(\hat\phi\), \(M\)은 반대). 차이는 \(10^{-5}\) 수준입니다.

  2. 공기에서 철(\(\mu_r = 1000\)) 표면으로 자기력선이 법선과 \(89°\)로 들어가면 철 안에서는?
    답

    공기 쪽 \(\tan\theta_1 = \tan89° \approx 57.3\). \(\tan\theta_2 = \tan\theta_1\cdot\mu_2/\mu_1 = 57300\)이라 \(\theta_2 \approx 89.999°\). 철 안의 자기력선은 면에 거의 나란하게 철을 따라 흐릅니다. 반대로 철에서 나올 때는 면에 거의 수직입니다.

발전

  1. 균일한 장 \(\mathbf B_0\) 속에 선형 자성체 공(\(\mu\))을 넣으면 안의 장은 \(\mathbf B = \frac{3\mu_r}{\mu_r + 2}\mathbf B_0\)입니다. \(\mu_r \to \infty\)와 \(\mu_r = 0\)일 때를 해석하세요.
    답

    \(\mu_r \to \infty\): 안의 \(B \to 3B_0\), 자기력선을 빨아들임. \(\mu_r = 0\)(완전 반자성, 초전도체): 안의 \(B = 0\), 자기장을 밀어냄(마이스너 효과).
