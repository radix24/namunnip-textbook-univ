긴 솔레노이드의 벡터 퍼텐셜

벡터 퍼텐셜 · Stokes 정리 · 문제 해결 전략

출발점

\(\mathbf B = \nabla\times\mathbf A\)이므로 Stokes 정리로 \(\oint\mathbf A\cdot d\mathbf l = \iint\mathbf B\cdot d\mathbf a = \Phi\)이다. 대칭이 있으면 Ampère 법칙처럼 \(\mathbf A\)를 바로 구할 수 있다.

문제 해결 전략 · 벡터 퍼텐셜 구하기
  1. 대칭으로 \(\mathbf A\)의 방향을 정한다(전류와 나란한 방향).
  2. \(\mathbf A\)가 일정한 고리를 골라 \(\oint\mathbf A\cdot d\mathbf l\)을 쓴다.
  3. 고리 안 자기 선속과 같게 놓는다.
  4. 회전을 계산해 \(\mathbf B\)가 나오는지 확인한다.

반지름 \(R\), 안쪽 자기장 \(B_0\hat{\mathbf z}\)인 긴 솔레노이드의 안팎 벡터 퍼텐셜을 구하여라. 바깥은 \(\mathbf B = 0\)인데 \(\mathbf A\)는 0인가?

풀이

  1. 대칭: \(\mathbf A = A(s)\hat{\boldsymbol\phi}\). 반지름 \(s\)인 원: \(2\pi sA = \Phi(s)\).
    전류가 \(\hat{\boldsymbol\phi}\) 방향.
  2. 안(\(s < R\)): \(\Phi = B_0\pi s^2\), \(A = \frac{B_0s}2\).
    선속이 \(s^2\)에 비례.
  3. 바깥(\(s > R\)): \(\Phi = B_0\pi R^2\), \(A = \frac{B_0R^2}{2s}\).
    선속 일정.
  4. 바깥에서 \(\mathbf B = 0\)이지만 \(\mathbf A \ne 0\).
    \(\nabla\times(\hat{\boldsymbol\phi}/s) = 0\).

의미

고전 전자기학에서는 \(\mathbf A\)가 계산 도구일 뿐이지만, 양자역학에서는 자기장이 0인 곳을 지나는 전자도 \(\mathbf A\)의 영향으로 간섭무늬가 이동합니다(Aharonov-Bohm 효과).

검산

안쪽: \(\frac1s\frac{d}{ds}(sA) = \frac1s\frac{d}{ds}\frac{B_0s^2}2 = B_0\). 맞다.
