비오-사바르 법칙

본문
이 절에서 배울 것
  • 비오-사바르 법칙으로 직선 도선 토막과 원형 고리의 자기장을 계산한다.
  • 자기장의 발산이 0임을 보인다.
먼저 알아야 할 것
  • 전류 밀도 (1.1절), 비오-사바르 법칙의 기초 (공통4 6.2절), 쿨롱 법칙과 연속 분포 (물리5 2.1절).

1.2.1법칙

법칙 1.2.1 (비오-사바르) \[\mathbf B(\mathbf r) = \frac{\mu_0}{4\pi}\int\frac{\mathbf I\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}dl' = \frac{\mu_0}{4\pi}\int\frac{\mathbf J(\mathbf r')\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}d\tau', \qquad \boldsymbol{\mathcal R} = \mathbf r - \mathbf r'.\]

\(\mu_0 = 4\pi\times10^{-7}\ \text{N/A}^2\) (2019년 SI 개정 뒤에는 측정값이며 이 값과 \(10^{-10}\) 수준으로 같음).

정전기의 쿨롱 법칙과 같은 \(1/\mathcal R^2\)이지만, 원천이 벡터이고 외적이 들어가 자기장은 전류에 수직으로 감깁니다. 정상 전류에서만 정확합니다.

1.2.2직선 도선 토막

도선에서 수직 거리 \(s\)인 점에서, 도선 양 끝을 보는 각을 \(\theta_1\), \(\theta_2\)(수직선에서 잼)라 하면 \(dl' \times \hat{\boldsymbol{\mathcal R}}\)의 크기는 \(dl'\cos\theta\), \(l' = s\tan\theta\), \(\mathcal R = s/\cos\theta\)이므로

\[B = \frac{\mu_0I}{4\pi}\int_{\theta_1}^{\theta_2}\frac{\cos\theta}{s}d\theta = \frac{\mu_0I}{4\pi s}(\sin\theta_2 - \sin\theta_1).\]

무한 도선(\(\theta_1 = -\pi/2\), \(\theta_2 = \pi/2\))이면 \(B = \mu_0I/(2\pi s)\)입니다.

1.2.3원형 고리의 축 위

반지름 \(R\)인 고리의 축 위 높이 \(z\)에서, 고리 각 조각의 \(d\mathbf B\)는 축에 수직인 성분이 대칭으로 상쇄되고 축 성분만 남습니다.

결과 1.2.2 \[B_z(z) = \frac{\mu_0I}{2}\frac{R^2}{(R^2 + z^2)^{3/2}}.\]

중심(\(z = 0\))에서 \(\mu_0I/2R\), 먼 곳(\(z \gg R\))에서 \(\frac{\mu_0}{2\pi}\frac{m}{z^3}\) (\(m = I\pi R^2\)). 전기 쌍극자와 같은 \(1/z^3\)입니다.

같은 고리 두 개를 반지름만큼 떨어뜨려 놓으면(헬름홀츠 코일) 가운데에서 \(B\)가 매우 고르게 됩니다. 아래 실습 카드에서 간격을 바꾸며 확인할 수 있습니다.

1.2.4자기장의 발산

비오-사바르 식에서 \(\nabla\cdot(\mathbf J\times\hat{\boldsymbol{\mathcal R}}/\mathcal R^2) = \frac{\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}\cdot(\nabla\times\mathbf J) - \mathbf J\cdot\left(\nabla\times\frac{\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}\right)\)이고, \(\mathbf J\)는 \(\mathbf r'\)의 함수라 첫 항이 0, \(\nabla\times(\hat{\boldsymbol{\mathcal R}}/\mathcal R^2) = 0\)이라 둘째 항도 0입니다. 따라서

\[\nabla\cdot\mathbf B = 0.\]

자기 홀극이 없다는 뜻이며, 자기력선은 시작도 끝도 없이 닫힙니다.

예제 1.2.3

한 변 \(a\)인 정사각형 고리에 전류 \(I\)가 흐릅니다. 중심의 자기장은?

풀이. 한 변은 중심에서 거리 \(s = a/2\), 양 끝 각 \(\pm45°\)이므로 \(B_1 = \frac{\mu_0I}{4\pi(a/2)}\cdot2\cdot\frac{\sqrt2}2 = \frac{\sqrt2\mu_0I}{2\pi a}\). 네 변이 같은 방향으로 더해져 \(B = \frac{2\sqrt2\mu_0I}{\pi a} \approx 0.90\frac{\mu_0I}{a}\). 같은 둘레의 원(\(R = 2a/\pi\))은 \(\frac{\pi\mu_0I}{4a} \approx 0.785\frac{\mu_0I}a\)입니다.

요약
  1. \(\mathbf B = \frac{\mu_0}{4\pi}\int\frac{\mathbf I\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}dl'\).
  2. 직선 토막 \(\frac{\mu_0I}{4\pi s}(\sin\theta_2 - \sin\theta_1)\), 고리 축 \(\frac{\mu_0IR^2}{2(R^2 + z^2)^{3/2}}\).
  3. \(\nabla\cdot\mathbf B = 0\): 자기 홀극이 없다.

1.2.5연습문제

기본

  1. 반지름 \(R\)인 반원과 두 직선으로 된 머리핀 모양 도선의 반원 중심의 자기장은?
    답

    반원 \(\frac{\mu_0I}{4R}\), 두 반무한 직선 각각 \(\frac{\mu_0I}{4\pi R}\). 합 \(\frac{\mu_0I}{4R}\left(1 + \frac2\pi\right)\).

  2. 감은 수 \(n\)/m인 무한 솔레노이드의 안쪽 자기장을 고리 결과를 적분해 구하세요.
    답

    \(B = \int\frac{\mu_0nI}{2}\frac{R^2\,dz}{(R^2 + z^2)^{3/2}} = \mu_0nI\).

발전

  1. 헬름홀츠 코일(반지름 \(R\), 간격 \(d\))에서 가운데 \(d^2B_z/dz^2 = 0\)이 되는 \(d\)를 구하세요.
    답

    한 고리의 \(B(z)\)를 \(z = d/2\)에서 두 번 미분해 0으로 두면 \(d = R\). 이때 홀수 차 미분은 대칭으로 0이라 4차까지 평평합니다.
