동축 케이블의 단위 길이당 인덕턴스

자기 에너지 · 인덕턴스 · 문제 해결 전략

출발점

인덕턴스는 선속으로 \(L = \Phi/I\), 또는 자기 에너지로 \(W = \frac12LI^2 = \frac1{2\mu_0}\int B^2dV\)에서 구한다. 두 방법이 같은 답을 줘야 한다.

문제 해결 전략 · 인덕턴스 계산
  1. Ampère 법칙으로 \(B\)를 구한다.
  2. 선속(또는 에너지)을 적분한다.
  3. \(L = \Phi/I\)(또는 \(2W/I^2\)).
  4. 두 방법으로 확인한다.

안쪽 반지름 \(a = 0.5\) mm, 바깥 \(b = 2\) mm인 동축 케이블(두 도체 사이 공기)의 단위 길이당 인덕턴스는? (전류는 표면으로만 흐른다고 본다)

풀이

  1. 사이 영역: \(B = \frac{\mu_0I}{2\pi s}\).
    Ampère 법칙.
  2. 길이 \(\ell\)당 선속 \(\Phi = \ell\int_a^b\frac{\mu_0I}{2\pi s}ds = \frac{\mu_0I\ell}{2\pi}\ln\frac ba\).
    직사각형 단면.
  3. \(L/\ell = \frac{\mu_0}{2\pi}\ln\frac ba = 2\times10^{-7}\ln4 = 0.277\ \mu\text{H/m}\).
    결과.
  4. 에너지로: \(\frac1{2\mu_0}\int B^2\cdot2\pi s\ell\,ds = \frac{\mu_0I^2\ell}{4\pi}\ln\frac ba\), \(L = 2W/I^2\)이 같다.
    두 방법 일치.

의미

단위 길이당 정전 용량 \(C/\ell = 2\pi\varepsilon_0/\ln(b/a)\)과 곱하면 \(LC/\ell^2 = \mu_0\varepsilon_0 = 1/c^2\). 신호가 케이블을 광속으로(유전체가 있으면 그만큼 느리게) 전달된다는 뜻이다.

검산

특성 임피던스 \(\sqrt{L/C} = \frac{\ln(b/a)}{2\pi}\sqrt{\mu_0/\varepsilon_0} = 0.221\times377 = 83\ \Omega\)(공기). 실제 케이블은 유전체 때문에 50~75 Ω이다.
