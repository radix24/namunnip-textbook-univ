벡터 퍼텐셜

본문

전기장은 스칼라 퍼텐셜의 기울기로 쓸 수 있어 계산이 쉬웠다. 자기장에도 비슷한 퍼텐셜이 있을까? 그런데 긴 솔레노이드 바깥은 자기장이 0인데, 그곳에서도 퍼텐셜은 0이 아니라고 한다. 자기장이 없는 곳의 퍼텐셜이 무슨 의미가 있을까?

먼저 알아야 할 것헬름홀츠 정리와 퍼텐셜(물리5 1.4절), 앙페르 법칙(1.2절), 다중극 전개(물리5 4.5절)를 쓴다.

1.3.1정의와 게이지

\(\nabla\cdot\mathbf B = 0\)이므로 \(\mathbf B = \nabla\times\mathbf A\)인 벡터장 \(\mathbf A\)가 있으며, 이것을 벡터 퍼텐셜이라 한다. 그런데 \(\mathbf A\)에 아무 기울기 \(\nabla\lambda\)를 더해도 회전은 그대로이므로 \(\mathbf B\)가 변하지 않는다. 그래서 편한 조건을 하나 더 걸 수 있으며, 정자기학에서는 \(\nabla\cdot\mathbf A = 0\)인 쿨롱 게이지를 고른다. 그러면 앙페르 법칙은 다음과 같이 된다.

\[\nabla\times(\nabla\times\mathbf A) = \nabla(\nabla\cdot\mathbf A) - \nabla^2\mathbf A = \mu_0\mathbf J \;\Rightarrow\; \nabla^2\mathbf A = -\mu_0\mathbf J\]

성분마다 푸아송 방정식이므로, 정전기의 해 \(V = \frac1{4\pi\epsilon_0}\int\frac\rho{\mathcal R}d\tau'\)를 그대로 옮겨 쓸 수 있다.

정리 1.3.1 \[\mathbf A(\mathbf r) = \frac{\mu_0}{4\pi}\int\frac{\mathbf J(\mathbf r')}{\mathcal R}d\tau' = \frac{\mu_0}{4\pi}\int\frac{\mathbf I}{\mathcal R}dl'\]

그래서 \(\mathbf A\)는 대개 전류와 같은 방향을 가리킨다. 또 적분에 외적이 없어 \(\mathbf B\)를 직접 구하는 것보다 쉬울 때가 많다.

1.3.2몇 가지 예

균일한 자기장은 \(\mathbf A = \frac12\mathbf B\times\mathbf r\)로 쓸 수 있으며, 회전을 계산하면 \(\mathbf B\)가 나온다. 또 스토크스 정리로 \(\oint\mathbf A\cdot d\mathbf l = \int\mathbf B\cdot d\mathbf a = \Phi\)이므로, \(\mathbf A\)의 고리 적분은 그 고리를 지나는 자기 선속이다. 이것을 무한 솔레노이드에 쓰면 안에서 \(A_\phi = \frac{\mu_0nI}2s\), 밖에서 \(A_\phi = \frac{\mu_0nIR^2}{2s}\)이다(그림 1). 즉 밖에서는 \(\mathbf B = 0\)인데 \(\mathbf A \ne 0\)이다. 한편 무한 도선은 적분이 발산하므로 기준점 \(s_0\)를 잡아 \(A_z = -\frac{\mu_0I}{2\pi}\ln\frac s{s_0}\)로 쓴다.

그렇다면 처음 질문처럼 자기장이 없는 곳의 \(\mathbf A\)는 의미가 있을까? 고전적으로는 아무 효과가 없다. 하지만 양자역학에서는 솔레노이드 바깥을 지나는 전자의 위상이 \(\mathbf A\)만큼 바뀌어 간섭 무늬가 움직인다. 이것을 아하로노프-봄 효과라 하며, 1959년 예측되어 실험으로 확인되었다. 퍼텐셜이 계산 도구 이상일 수 있다는 예이다.

1.3.3자기 쌍극자

작은 고리 전류의 \(\mathbf A\)를 먼 곳에서 다중극 전개하면, 홀극 항은 \(\oint d\mathbf l' = 0\)이어서 사라지고 쌍극자 항이 첫 항이 된다.

결과 1.3.2 \[\mathbf A_{\text{dip}} = \frac{\mu_0}{4\pi}\frac{\mathbf m\times\hat{\mathbf r}}{r^2}, \qquad \mathbf B_{\text{dip}} = \frac{\mu_0}{4\pi r^3}\left[3(\mathbf m\cdot\hat{\mathbf r})\hat{\mathbf r} - \mathbf m\right], \qquad \mathbf m = I\int d\mathbf a\]

먼 곳의 모양은 전기 쌍극자와 같지만 가까이에서는 다르다. 고리 안을 지나는 자기력선은 위로 이어져 닫히기 때문이다.

예제 1.3.3

반지름 \(R\)인 구 껍질에 전하 \(Q\)가 고르게 있고 각속도 \(\omega\)로 돈다. 자기 쌍극자 모멘트는?

풀이. 폭 \(R\,d\theta\)인 띠의 전류는 \(dI = \sigma(\omega R\sin\theta)R\,d\theta\)이고, 띠가 둘러싼 넓이는 \(\pi R^2\sin^2\theta\)이다. 따라서 \(m = \int\pi R^2\sin^2\theta\,dI = \pi\sigma\omega R^4\int_0^\pi\sin^3\theta\,d\theta = \frac43\pi\sigma\omega R^4 = \frac13QR^2\omega\)이다. 정확히 풀면 안쪽 자기장은 균일하게 \(\frac23\mu_0\sigma R\omega\)이다.

1.3.4경계 조건

면전류 \(\mathbf K\)가 흐르는 면을 지날 때, \(\hat{\mathbf n}\)을 아래에서 위로 잡으면 다음이 성립한다.

\[B^\perp_{\text{위}} = B^\perp_{\text{아래}}, \qquad \mathbf B_{\text{위}} - \mathbf B_{\text{아래}} = \mu_0\mathbf K\times\hat{\mathbf n}, \qquad \mathbf A\text{는 연속}\]

앞의 식은 \(\nabla\cdot\mathbf B = 0\)을 납작한 상자에 적용해, 뒤의 식은 앙페르 법칙을 면을 가로지르는 좁은 고리에 적용해 얻는다.

흔한 오해\(\mathbf A\)가 하나로 정해진다고 생각하기 쉽지만, 기울기를 더해도 같은 \(\mathbf B\)를 주므로 게이지를 골라야 정해진다. 또 \(\mathbf B = 0\)인 곳에서는 \(\mathbf A\)도 0이라는 생각은 솔레노이드 바깥에서 틀린다. 고리 적분이 안쪽 선속 \(\Phi\)와 같아야 하기 때문이다.
마무리

벡터 퍼텐셜은 \(\mathbf B = \nabla\times\mathbf A\)로 정의하고, 쿨롱 게이지에서 \(\nabla^2\mathbf A = -\mu_0\mathbf J\)이므로 \(\mathbf A = \frac{\mu_0}{4\pi}\int\frac{\mathbf J}{\mathcal R}d\tau'\)로 계산한다. \(\oint\mathbf A\cdot d\mathbf l = \Phi\)이므로 처음 질문의 솔레노이드 바깥에서도 \(\mathbf A\)는 0이 아니며, 이것이 아하로노프-봄 효과로 드러난다. 쌍극자의 퍼텐셜은 \(\frac{\mu_0}{4\pi}\frac{\mathbf m\times\hat{\mathbf r}}{r^2}\)이고, 경계에서 \(B^\perp\)는 연속, \(B^\parallel\)은 \(\mu_0K\)만큼 뛴다.

1.3.5연습문제

기본

  1. \(\mathbf A = \frac12\mathbf B\times\mathbf r\)의 발산과 회전을 확인하세요(\(\mathbf B = B\hat z\)).
    답

    \(\mathbf A = \frac B2(-y, x, 0)\). \(\nabla\cdot\mathbf A = 0\), \(\nabla\times\mathbf A = (0, 0, B)\).

  2. 반지름 2 cm 고리에 3 A가 흐를 때 자기 쌍극자 모멘트는?
    답

    \(m = 3\times\pi(0.02)^2 \approx 3.8\times10^{-3}\ \text{A·m}^2\).

발전

  1. \(\mathbf A' = \mathbf A + \nabla\lambda\)가 쿨롱 게이지가 되려면 \(\lambda\)가 어떤 방정식을 만족해야 하나요?
    답

    \(\nabla^2\lambda = -\nabla\cdot\mathbf A\). 푸아송 방정식이므로 늘 풀 수 있어, 쿨롱 게이지는 언제나 고를 수 있습니다.
