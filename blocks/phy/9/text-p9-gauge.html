퍼텐셜과 게이지 변환

본문
이 절에서 배울 것
  • 시간에 변하는 경우의 스칼라·벡터 퍼텐셜을 정의한다.
  • 게이지 변환이 장을 바꾸지 않음을 보인다.
  • 쿨롱 게이지와 로런츠 게이지의 특징을 비교한다.
먼저 알아야 할 것
  • 벡터 퍼텐셜 (1.3절), 맥스웰 방정식 (4.1절).

4.3.1퍼텐셜

\(\nabla\cdot\mathbf B = 0\)은 늘 성립하므로 여전히 \(\mathbf B = \nabla\times\mathbf A\). 패러데이 법칙에 넣으면 \(\nabla\times(\mathbf E + \partial_t\mathbf A) = 0\)이라 괄호 안을 기울기로 쓸 수 있습니다.

정의 4.3.1 \[\mathbf B = \nabla\times\mathbf A, \qquad \mathbf E = -\nabla V - \frac{\partial\mathbf A}{\partial t}.\]

동차 방정식 두 개(\(\nabla\cdot\mathbf B = 0\), 패러데이)는 저절로 맞고, 나머지 두 개는

\[\nabla^2V + \frac\partial{\partial t}(\nabla\cdot\mathbf A) = -\frac\rho{\epsilon_0}, \qquad \left(\nabla^2\mathbf A - \mu_0\epsilon_0\frac{\partial^2\mathbf A}{\partial t^2}\right) - \nabla\left(\nabla\cdot\mathbf A + \mu_0\epsilon_0\frac{\partial V}{\partial t}\right) = -\mu_0\mathbf J.\]

장 6성분 대신 퍼텐셜 4성분만 구하면 됩니다.

4.3.2게이지 변환

정리 4.3.2

임의의 스칼라 함수 \(\lambda(\mathbf r, t)\)에 대해

\[\mathbf A' = \mathbf A + \nabla\lambda, \qquad V' = V - \frac{\partial\lambda}{\partial t}\]

는 같은 \(\mathbf E\), \(\mathbf B\)를 줍니다.

\(\nabla\times\nabla\lambda = 0\)이라 \(\mathbf B\)는 그대로이고, \(\mathbf E\)에서 \(-\nabla(-\partial_t\lambda) - \partial_t\nabla\lambda = 0\)이라 그대로입니다. 측정되는 것은 장(과 힘)이므로, 이 자유를 써서 \(\nabla\cdot\mathbf A\)를 원하는 대로 정할 수 있습니다.

4.3.3두 가지 게이지

쿨롱 게이지로런츠 게이지
조건\(\nabla\cdot\mathbf A = 0\)\(\nabla\cdot\mathbf A = -\mu_0\epsilon_0\,\partial_tV\)
\(V\)의 방정식\(\nabla^2V = -\rho/\epsilon_0\) (푸아송)\(\Box^2V = -\rho/\epsilon_0\)
\(\mathbf A\)의 방정식복잡함(\(V\)가 섞임)\(\Box^2\mathbf A = -\mu_0\mathbf J\)
특징\(V\)가 순간적으로 변함(그래도 \(\mathbf E\)는 인과적)\(V\), \(\mathbf A\)가 같은 파동 방정식, 상대론과 잘 맞음

\(\Box^2 = \nabla^2 - \frac1{c^2}\frac{\partial^2}{\partial t^2}\)는 달랑베르 연산자입니다. 로런츠 게이지에서 네 퍼텐셜이 모두 빛의 속도로 퍼지는 파동 방정식을 따르므로, 6장의 지연 퍼텐셜이 바로 나옵니다.

쿨롱 게이지의 \(V\)가 멀리 떨어진 전하의 움직임을 즉시 반영해도 인과율을 어기지 않는 것은, \(\mathbf E\)에 들어가는 \(\partial_t\mathbf A\) 항이 그 순간적인 변화를 정확히 지우기 때문입니다.

예제 4.3.3

\(V = 0\), \(\mathbf A = -\frac{qt}{4\pi\epsilon_0r^2}\hat{\mathbf r}\)가 만드는 장은? 더 간단한 퍼텐셜로 바꾸는 게이지 함수는?

풀이. \(\mathbf E = -\partial_t\mathbf A = \frac{q}{4\pi\epsilon_0r^2}\hat{\mathbf r}\), \(\mathbf B = 0\) (지름 방향 함수의 회전은 0). 정지한 점전하입니다. \(\nabla(1/r) = -\hat{\mathbf r}/r^2\)이므로 \(\mathbf A = \nabla\left(\frac{qt}{4\pi\epsilon_0r}\right)\)입니다. \(\lambda = -\frac{qt}{4\pi\epsilon_0r}\)로 게이지 변환하면 \(\mathbf A' = \mathbf A + \nabla\lambda = 0\), \(V' = -\partial_t\lambda = \frac{q}{4\pi\epsilon_0r}\). 익숙한 쿨롱 퍼텐셜입니다.

요약
  1. \(\mathbf B = \nabla\times\mathbf A\), \(\mathbf E = -\nabla V - \partial_t\mathbf A\).
  2. 게이지 변환 \(\mathbf A + \nabla\lambda\), \(V - \partial_t\lambda\)는 장을 바꾸지 않는다.
  3. 쿨롱 게이지: \(V\)는 푸아송. 로런츠 게이지: \(\Box^2V = -\rho/\epsilon_0\), \(\Box^2\mathbf A = -\mu_0\mathbf J\).

4.3.4연습문제

기본

  1. 로런츠 게이지가 아닌 \((V, \mathbf A)\)가 있을 때, 로런츠 게이지로 바꾸려면 \(\lambda\)가 어떤 방정식을 만족해야 하나요?
    답

    \(\Box^2\lambda = -\left(\nabla\cdot\mathbf A + \mu_0\epsilon_0\partial_tV\right)\). 원천이 있는 파동 방정식이라 늘 풀 수 있습니다.

  2. 균일한 정전기장 \(E_0\hat x\)를 \(V = 0\)인 퍼텐셜로 나타내세요.
    답

    \(\mathbf A = -E_0t\,\hat x\). \(-\partial_t\mathbf A = E_0\hat x\), \(\nabla\times\mathbf A = 0\).

발전

  1. 로런츠 게이지 조건이 상대론적으로 불변인 까닭을 4원 퍼텐셜 \(A^\mu = (V/c, \mathbf A)\)로 설명하세요.
    답

    조건이 \(\partial_\mu A^\mu = 0\), 곧 4원 발산이 0이라는 스칼라 식이기 때문입니다. 쿨롱 게이지 \(\nabla\cdot\mathbf A = 0\)은 공간 성분만 쓰므로 좌표계마다 다릅니다.
