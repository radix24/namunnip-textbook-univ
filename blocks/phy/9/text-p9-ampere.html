앙페르 법칙

본문

긴 솔레노이드 안의 자기장은 도선 감은 수와 전류만으로 정해지고, 바깥은 거의 0이다. 비오-사바르 법칙으로 수천 바퀴를 하나하나 적분하지 않고 이것을 한 줄로 얻을 수 있을까? 가우스 법칙이 대칭 좋은 전하 분포의 전기장을 쉽게 구하듯, 자기장에도 그런 도구가 있을까?

먼저 알아야 할 것비오-사바르 법칙(앞 카드), 스토크스 정리(물리5 1.1절), 가우스 법칙의 활용(물리5 2.2절)을 쓴다.

1.2.5법칙

비오-사바르 식의 회전을 계산하면, 정상 전류 조건 \(\nabla'\cdot\mathbf J = 0\)과 \(\nabla^2(1/\mathcal R) = -4\pi\delta^3\)을 써서 다음을 얻는다.

정리 1.2.4 (앙페르 법칙) \[\nabla\times\mathbf B = \mu_0\mathbf J, \qquad \oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}\]

손가락이 고리 방향을 따라 감기면 엄지 방향으로 지나는 전류를 양으로 센다.

뒤의 적분형은 스토크스 정리로 앞의 미분형에서 나온다. 가우스 법칙처럼 늘 성립하지만, 계산에 쓸모 있는 것은 대칭이 커서 \(\mathbf B\)를 적분 밖으로 꺼낼 수 있을 때뿐이다. 그런 경우는 사실상 무한 직선, 무한 평면, 무한 솔레노이드, 토로이드의 넷이다. 처음 질문의 답이 이것이다.

1.2.6네 가지 대칭

먼저 반지름 \(a\)인 무한 도선에 전류가 고르게 흐르면, 도선을 둘러싼 원을 고리로 잡는다. 밖에서는 \(B\cdot2\pi s = \mu_0I\)이므로 \(B = \frac{\mu_0I}{2\pi s}\)이고, 안에서는 감긴 전류가 \(Is^2/a^2\)이므로 \(B = \frac{\mu_0Is}{2\pi a^2}\)이다. 한편 \(xy\)평면에 흐르는 무한 면전류 \(\mathbf K = K\hat x\)는 위아래로 \(B = \frac{\mu_0K}2\)를 반대 방향으로 만들며, 면을 지날 때 자기장이 \(\mu_0K\)만큼 뛴다.

또 단위 길이당 \(n\)번 감은 무한 솔레노이드는 안에서 \(B = \mu_0nI\), 밖에서 0이다(그림 1). 직사각형 고리의 한 변만 안에 넣으면 감긴 전류가 \(nIl\)이므로 \(Bl = \mu_0nIl\)이다. 밖이 0인 것은 대칭 논증에서 나온다. 먼 곳에서 0이고, 밖에서 두 거리를 지나는 직사각형 고리에는 전류가 감기지 않으므로 밖의 값이 어디서나 같아야 하기 때문이다. 마지막으로 \(N\)번 감은 토로이드는 안에서 \(B = \frac{\mu_0NI}{2\pi s}\), 밖에서 0이며, 단면 모양과 상관없다.

그러므로 정자기학과 정전기학은 발산과 회전으로 나란히 정리된다.

정전기정자기
발산\(\nabla\cdot\mathbf E = \rho/\epsilon_0\)\(\nabla\cdot\mathbf B = 0\)
회전\(\nabla\times\mathbf E = 0\)\(\nabla\times\mathbf B = \mu_0\mathbf J\)
힘\(q\mathbf E\)\(q\mathbf v\times\mathbf B\)
예제 1.2.5

동축 케이블(안 도선 반지름 \(a\), 바깥 얇은 원통 반지름 \(b\))에 같은 전류 \(I\)가 반대로 흐른다. 안 도선의 전류가 표면에만 흐를 때 모든 곳의 \(B\)를 구하여라.

풀이. 축을 중심으로 한 원을 고리로 잡는다. \(s < a\)에서는 감긴 전류가 0이므로 \(B = 0\)이다. \(a < s < b\)에서는 안 도선의 전류만 감기므로 \(B = \frac{\mu_0I}{2\pi s}\)이다. \(s > b\)에서는 알짜 전류가 0이므로 \(B = 0\)이다. 그래서 자기장이 케이블 안에 갇혀 바깥 회로와 간섭하지 않는다.

흔한 오해앙페르 법칙으로 아무 전류 분포의 자기장이나 구할 수 있다고 생각하기 쉽지만, 법칙은 고리 위 적분값만 알려 준다. 대칭이 없으면 \(\mathbf B\)를 적분 밖으로 꺼낼 수 없어, 유한한 도선 토막이나 원형 고리에는 비오-사바르 법칙을 써야 한다. 또 \(\oint\mathbf B\cdot d\mathbf l = 0\)이 고리 위에서 \(\mathbf B = 0\)이라는 뜻도 아니다.
마무리

앙페르 법칙은 \(\nabla\times\mathbf B = \mu_0\mathbf J\), 적분형으로 \(\oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}\)이다. 대칭 논증으로 \(\mathbf B\)의 방향과 크기가 일정한 고리를 고르면, 도선 \(\mu_0I/2\pi s\), 면전류 \(\mu_0K/2\), 솔레노이드 \(\mu_0nI\), 토로이드 \(\mu_0NI/2\pi s\)를 한 줄로 얻는다. 처음 질문의 솔레노이드도 고리 한 변만 안에 넣어 안의 자기장을 구하고, 밖이 0인 것은 대칭에서 나온다.

1.2.7연습문제

기본

  1. 길이 20 cm에 500회 감은 솔레노이드에 2 A가 흐릅니다. 안의 \(B\)는?
    답

    \(n = 2500\)/m, \(B = 4\pi\times10^{-7}\times2500\times2 \approx 6.3\) mT.

  2. \(J = ks\)인 무한 도선(반지름 \(a\)) 안팎의 \(B\)는?
    답

    안에서는 \(I_{\text{감김}} = 2\pi ks^3/3\)이므로 \(B = \mu_0ks^2/3\)이고, 밖에서는 \(B = \mu_0ka^3/(3s)\)이다.

발전

  1. 두께 \(2d\)인 무한 판(\(|z| < d\))에 균일한 \(\mathbf J = J\hat x\)가 흐릅니다. \(B(z)\)를 구하세요.
    답

    \(|z| < d\)에서는 \(\mathbf B = -\mu_0Jz\,\hat y\)이고, \(|z| > d\)에서는 \(\mathbf B = \mp\mu_0Jd\,\hat y\)이다(\(z > 0\)이면 \(-\)). \(d \to 0\), \(2Jd = K\)이면 면전류 결과가 됩니다.
