앙페르 법칙

본문
이 절에서 배울 것
  • 미분형 \(\nabla\times\mathbf B = \mu_0\mathbf J\)와 적분형 앙페르 법칙을 안다.
  • 대칭이 큰 전류 분포(도선, 솔레노이드, 토로이드, 면전류)의 자기장을 앙페르 고리로 구한다.
먼저 알아야 할 것
  • 비오-사바르 법칙 (앞 카드), 스토크스 정리 (물리5 1.1절), 가우스 법칙의 활용 (물리5 2.2절).

1.2.5법칙

비오-사바르 식의 회전을 계산하면(정상 전류 \(\nabla'\cdot\mathbf J = 0\)과 \(\nabla^2(1/\mathcal R) = -4\pi\delta^3\)을 씀)

정리 1.2.4 (앙페르 법칙) \[\nabla\times\mathbf B = \mu_0\mathbf J, \qquad \oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}.\]

오른손 법칙: 손가락이 고리 방향을 따라 감기면 엄지 방향으로 지나는 전류가 양.

가우스 법칙처럼 늘 성립하지만, 계산에 쓸모 있는 것은 대칭이 커서 \(\mathbf B\)를 적분 밖으로 꺼낼 수 있을 때뿐입니다. 쓸 수 있는 경우는 사실상 넷입니다: 무한 직선, 무한 평면, 무한 솔레노이드, 토로이드.

1.2.6네 가지 대칭

  1. 무한 도선 (반지름 \(a\), 균일 전류): 밖은 \(B = \frac{\mu_0I}{2\pi s}\), 안은 감긴 전류가 \(I s^2/a^2\)이라 \(B = \frac{\mu_0Is}{2\pi a^2}\).
  2. 무한 면전류 \(\mathbf K = K\hat x\) (\(xy\)평면): 위아래로 \(B = \frac{\mu_0K}2\), 방향은 반대(\(\mp\hat y\)). 면을 지날 때 \(\mu_0K\)만큼 뛴다.
  3. 무한 솔레노이드 (\(n\)회/m): 안 \(B = \mu_0nI\), 밖 0. 직사각형 고리의 한 변만 안에 넣어 얻는다.
  4. 토로이드 (감은 수 \(N\)): 안 \(B = \frac{\mu_0NI}{2\pi s}\), 밖 0. 단면 모양과 상관없다.

대칭 논증이 핵심입니다. 예를 들어 솔레노이드 밖의 자기장이 0인 것은 "먼 곳에서 0"과 "밖의 두 지름 거리에서 같은 값"(직사각형 고리에 전류가 감기지 않음)에서 나옵니다.

정전기정자기
발산\(\nabla\cdot\mathbf E = \rho/\epsilon_0\)\(\nabla\cdot\mathbf B = 0\)

예제 1.2.5

동축 케이블(안 도선 반지름 \(a\), 바깥 얇은 원통 반지름 \(b\))에 같은 전류 \(I\)가 반대로 흐릅니다. 모든 곳의 \(B\)를 구하세요(안 도선 전류는 표면에만).

풀이. \(s < a\): 감긴 전류 0, \(B = 0\). \(a < s < b\): \(B = \frac{\mu_0I}{2\pi s}\). \(s > b\): 알짜 전류 0이라 \(B = 0\). 자기장이 케이블 안에 갇혀 바깥 회로와 간섭하지 않습니다.

요약
  1. \(\nabla\times\mathbf B = \mu_0\mathbf J\), \(\oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}\).
  2. 도선 \(\mu_0I/2\pi s\), 면 \(\mu_0K/2\), 솔레노이드 \(\mu_0nI\), 토로이드 \(\mu_0NI/2\pi s\).
  3. 대칭 논증으로 \(\mathbf B\)의 방향과 크기가 일정한 고리를 고른다.

1.2.7연습문제

기본

  1. 길이 20 cm에 500회 감은 솔레노이드에 2 A가 흐릅니다. 안의 \(B\)는?
    답

    \(n = 2500\)/m, \(B = 4\pi\times10^{-7}\times2500\times2 \approx 6.3\) mT.

  2. \(J = ks\)인 무한 도선(반지름 \(a\)) 안팎의 \(B\)는?
    답

    안: \(I_{\text{감김}} = 2\pi ks^3/3\), \(B = \mu_0ks^2/3\). 밖: \(B = \mu_0ka^3/(3s)\).

발전

  1. 두께 \(2d\)인 무한 판(\(|z| < d\))에 균일한 \(\mathbf J = J\hat x\)가 흐릅니다. \(B(z)\)를 구하세요.
    답

    \(|z| < d\): \(\mathbf B = -\mu_0Jz\,\hat y\). \(|z| > d\): \(\mathbf B = \mp\mu_0Jd\,\hat y\) (\(z > 0\)이면 \(-\)). \(d \to 0\), \(2Jd = K\)이면 면전류 결과가 됩니다.
