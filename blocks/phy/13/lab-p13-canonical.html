온도에 따른 준위 점유와 비열

실습 · 정준 앙상블

목표

2준위계, 조화 진동자, 강체 회전자에서 온도를 바꾸며 준위별 점유 확률과 분배함수 \(Z\), 평균 에너지 \(U\), 비열 \(C\)를 봅니다. 비열이 낮은 온도에서 0으로 "얼고" 높은 온도에서 등분배 값에 다가가는 모습을 비교합니다. 성취기준 [물리13-02-02].

준비

에너지 단위는 \(\varepsilon\)입니다. 2준위계는 \(0, \varepsilon\), 조화 진동자는 \(n\varepsilon\), 강체 회전자는 \(\ell(\ell + 1)\varepsilon\)(겹침 \(2\ell + 1\))입니다. 위 막대가 낮은 8개 준위의 점유 확률, 아래 곡선이 온도에 따른 비열이고 노란 점이 지금 온도입니다. \(C = (\langle E^2\rangle - \langle E\rangle^2)/kT^2\)으로 계산합니다.

절차

  1. 2준위계에서 kT = 0.5ε, 2ε의 Z, U, C를 적는다. 비열 곡선의 봉우리(Schottky 봉우리) 위치를 찾는다.
  2. 조화 진동자로 바꿔 kT = 0.1ε, 1ε, 5ε의 C를 적는다.
  3. 강체 회전자에서 kT = 5ε의 점유 막대를 보고 가장 많이 점유된 준위가 바닥 상태가 아닌 까닭을 생각한다.

기대 결과

  • 2준위계: kT = 0.5ε에서 Z = 1.1353, U = 0.1192ε, C = 0.4200k. kT = 2ε에서 Z = 1.6065, U = 0.3775ε, C = 0.0588k. 비열 봉우리는 kT ≈ 0.42ε 근처(kT = 0.4ε에서 0.4381k).
  • 조화 진동자: kT = 0.1ε에서 C = 0.0045k(얼어붙음), 1ε에서 0.9207k, 5ε에서 0.9967k(등분배 값 k에 다가감).
  • 강체 회전자 kT = 5ε: 점유 확률이 ℓ = 0에서 0.187, ℓ = 1에서 0.376, ℓ = 2에서 0.282로 ℓ = 1이 가장 크다. 준위마다 겹침 2ℓ + 1이 있어 에너지가 조금 높아도 상태 수가 많기 때문이다. 이때 C = 1.0010k.

분석

  1. 2준위계의 비열은 높은 온도에서 왜 다시 0으로 줄어드나요? 조화 진동자와 다른 까닭은 준위 구조의 어떤 차이인가요?
  2. 조화 진동자의 고온 비열이 \(k\)인 것을 등분배 정리(운동 에너지와 퍼텐셜 에너지에 각각 \(\frac12kT\))로 설명해 보세요.
