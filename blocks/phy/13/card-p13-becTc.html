루비듐 원자 기체의 BEC 임계 온도

Bose-Einstein 응축 · 임계 온도 · 문제 해결 전략

출발점

보손 기체가 \(n\lambda_{th}^3 = 2.612\)에 이르면 바닥 상태에 거시적인 수의 입자가 모입니다. 임계 온도 \(T_c = \frac{2\pi\hbar^2}{mk}\left(\frac n{2.612}\right)^{2/3}\)입니다.

문제 해결 전략 · BEC 임계 온도
  1. 원자 질량과 수 밀도를 정한다.
  2. \(T_c\) 식에 넣는다.
  3. \(T < T_c\)에서 응축 비율 \(1 - (T/T_c)^{3/2}\).
  4. 실험값과 비교한다.

\(^{87}\text{Rb}\)(\(m = 1.44\times10^{-25}\) kg) 기체의 수 밀도가 \(10^{20}\) m⁻³일 때 임계 온도는? \(T = 0.5T_c\)에서 응축 비율은?

풀이

  1. \((n/2.612)^{2/3} = (3.83\times10^{19})^{2/3} = 1.14\times10^{13}\) m⁻².
    값.
  2. \(\frac{2\pi\hbar^2}{mk} = \frac{2\pi\times1.11\times10^{-68}}{1.44\times10^{-25}\times1.38\times10^{-23}} = 3.51\times10^{-20}\) m²K.
    상수.
  3. \(T_c = 3.51\times10^{-20}\times1.14\times10^{13} = 4.0\times10^{-7}\) K = 400 nK.
    수백 nK.
  4. \(0.5T_c\): \(1 - 0.5^{1.5} = 0.65\), 65%가 응축.
    응축 비율.

의미

1995년 첫 BEC 실험은 레이저 냉각과 증발 냉각으로 원자 기체를 수백 nK까지 식혀 이 조건을 만들었습니다. 수십만 개의 원자가 하나의 양자 상태에 들어간, 눈에 보이는 크기의 양자 현상입니다.

검산

\(T_c\)에서 \(n\lambda_{th}^3 = 2.612\): \(\lambda_{th} = h/\sqrt{2\pi mkT_c} = 0.30\ \mu\)m, \(10^{20}\times(2.97\times10^{-7})^3 = 2.6\). 맞습니다.
