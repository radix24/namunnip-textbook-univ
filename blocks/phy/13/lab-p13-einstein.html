맞닿은 두 Einstein 고체

실습 · 다중도와 열평형

목표

진동자 \(N_A\), \(N_B\)개로 된 두 Einstein 고체가 에너지 양자 \(q\)개를 나눠 가질 때, 각 나눔의 다중도 \(\Omega_A\Omega_B\)를 확률로 그립니다. 가장 가능성 큰 나눔에서 진동자당 에너지(온도)가 같아지고, 계가 클수록 분포가 날카로워져 열평형이 사실상 확실해지는 것을 확인합니다. 성취기준 [물리13-02-01].

준비

\(\Omega(N, q) = \binom{q + N - 1}{q}\)이고, 모든 미시 상태가 같은 확률이라는 기본 가정으로 \(q_A\)의 확률을 \(\Omega_A\Omega_B\)에 비례하게 그립니다. 큰 수는 로그 감마 함수로 계산합니다. 노란 점이 가장 가능성 큰 \(q_A\)입니다.

절차

  1. 처음 설정(100, 200, 150)에서 가장 가능성 큰 q_A, 두 고체의 진동자당 에너지, 상대 폭을 적는다.
  2. N_A = N_B = 30, q = 60으로 줄여 상대 폭을 비교한다.
  3. N_A = N_B = 300, q = 600으로 늘려 상대 폭과 미시 상태 수를 적는다.

기대 결과

  • 처음 설정(100, 200, 150): 가장 가능성 큰 q_A = 50, 두 고체 모두 진동자당 0.500, 상대 폭 14.1%, 미시 상태 수 약 10^122.8.
  • N_A = N_B = 30, q = 60: q_A = 30, 상대 폭 18.1%.
  • N_A = N_B = 300, q = 600: q_A = 300, 상대 폭 5.8%(진동자 수 10배에 약 1/3), 미시 상태 수 약 10^359.3.

분석

  1. 가장 가능성 큰 나눔에서 \(\frac{\partial\ln\Omega_A}{\partial q_A} = \frac{\partial\ln\Omega_B}{\partial q_B}\)가 성립하는 까닭과, 이것이 온도의 정의 \(1/T = \partial S/\partial U\)와 어떻게 이어지는지 말해 보세요.
  2. 상대 폭이 대략 \(1/\sqrt N\)로 줄어든다면, \(N \sim 10^{23}\)인 실제 물체에서는 얼마일까요?

더 해 보기
