음의 온도

본문

  • 2준위계의 엔트로피를 에너지의 함수로 구하고 \(1/T = \partial S/\partial U\)가 음수가 되는 영역을 찾는다.
  • 음의 온도가 무한대보다 뜨겁다는 뜻과 실현되는 계를 설명한다.
먼저 알아야 할 것
  • 2준위계와 상자성체 (3.2절), 미시정준 앙상블 (2.1절).

3.3.1엔트로피와 온도

간격 \(\epsilon\)인 2준위계 \(N\)개 가운데 \(n\)개가 위 준위에 있으면 \(U = n\epsilon\)이고 미시 상태 수는 \(\Omega = \binom Nn\)입니다. 스털링 근사로 \(S = k\ln\Omega\)를 \(U\)로 미분하면

\[\frac1T = \frac{\partial S}{\partial U} = \frac k\epsilon\ln\frac{N - n}n.\]

\(n < N/2\)이면 양수, \(n = N/2\)에서 \(1/T = 0\)(\(T = \pm\infty\)), \(n > N/2\)이면 음수입니다. 위 준위가 더 많은 밀도 반전 상태가 음의 온도입니다.

3.3.2무한대보다 뜨겁다

준위가 위로 막힌 계에서 위 준위 입자가 절반보다 많아지면, 에너지를 더 넣을수록 미시 상태 수가 줄어 \(\partial S/\partial U < 0\), 곧 \(T < 0\)입니다. 이런 계는 양의 온도인 어떤 계와 접촉해도 에너지를 내주므로 "무한대보다 뜨겁다"고 볼 수 있습니다. 온도의 순서는 \(+0 \to +\infty = -\infty \to -0\)이고, \(1/T\)로 보면 매끄럽게 이어집니다.

핵스핀 계(퍼셀과 파운드, 1951)와 레이저의 밀도 반전 상태에서 실현됩니다. 운동 에너지처럼 위로 막히지 않은 자유도가 있으면 음의 온도는 생기지 않으므로, 음의 온도인 스핀계도 결국 격자와 열을 주고받으며 양의 온도로 돌아갑니다.

요약
  1. \(1/T = (k/\epsilon)\ln[(N - n)/n]\): 밀도 반전(\(n > N/2\))이면 \(T < 0\).
  2. 음의 온도는 무한대보다 뜨겁다. 위로 막힌 자유도에서만 가능.

3.3.3연습문제

기본

  1. 2준위계의 엔트로피가 최대인 에너지는?
    답

    \(n = N/2\), \(U = N\epsilon/2\). 이때 \(1/T = 0\).

  2. 음의 온도인 계와 양의 온도인 계를 접촉시키면 열은 어느 쪽으로 흐르는가?
    답

    음의 온도인 계에서 양의 온도인 계로.
