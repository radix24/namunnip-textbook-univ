대정준 앙상블의 응용: 흡착과 입자 수 요동

본문

헤모글로빈은 폐에서 산소를 붙잡고 조직에서 내놓는다. 금속 표면은 기체 분자를 흡착한다. 붙을 자리에 분자가 붙어 있을 확률은 기체의 압력과 온도에 따라 어떻게 바뀔까? 입자 수가 바뀌는 계는 대정준 앙상블로 다룬다.

먼저 알아야 할 것대정준 앙상블과 화학 퍼텐셜(2.3절), 이상기체의 화학 퍼텐셜(3.1절)을 쓴다.

2.5.1자리 하나의 대분배함수

흡착 자리 하나를 계로 보자. 자리는 비어 있거나(에너지 0, 입자 0), 분자 하나가 붙어 있다(에너지 \(-\epsilon\), 입자 1). 기체는 온도 \(T\), 화학 퍼텐셜 \(\mu\)의 저장소이다. 대정준 확률은 \(e^{-(E - \mu N)/kT}\)에 비례하므로 대분배함수는 \(\mathcal Z = 1 + e^{(\epsilon + \mu)/kT}\)이고, 자리가 차 있을 확률(덮임률)은

\[\theta = \frac{e^{(\epsilon + \mu)/kT}}{1 + e^{(\epsilon + \mu)/kT}} = \frac{1}{e^{-(\epsilon + \mu)/kT} + 1}\]

이다. 이제 이상기체의 화학 퍼텐셜 \(\mu = kT\ln(P/P_Q)\)(\(P_Q = kT/v_Q\), \(v_Q\)는 양자 부피)를 넣으면 \(e^{\mu/kT} = P/P_Q\)이고, 정리하면 그림 1의 Langmuir 등온선 \(\theta = \frac{P}{P + P_0}\), \(P_0 = P_Qe^{-\epsilon/kT}\)를 얻는다. 낮은 압력에서는 덮임률이 압력에 비례하고, 높은 압력에서는 자리가 거의 다 차 포화한다.

2.5.2입자 수 요동

대정준 앙상블에서 입자 수는 고정되지 않고 요동한다. \(\langle N\rangle = kT\frac{\partial\ln\mathcal Z}{\partial\mu}\)를 한 번 더 미분하면 분산이 나온다.

\[\langle N^2\rangle - \langle N\rangle^2 = kT\frac{\partial\langle N\rangle}{\partial\mu}.\]

이상기체에서는 \(\langle N\rangle \propto e^{\mu/kT}\)이므로 분산이 \(\langle N\rangle\)이고, 상대 요동은 \(1/\sqrt{\langle N\rangle}\)이다. 거시적인 계에서 \(10^{-12}\) 정도라 대정준 앙상블과 정준 앙상블이 같은 열역학을 준다. 그런데 임계점 근처에서는 압축률이 발산해 \(\partial N/\partial\mu\)가 커지고, 밀도 요동이 빛을 강하게 산란하는 임계 단백광이 나타난다.

예제 2.5.1

\(P = P_0\)일 때 덮임률과 자리 하나의 점유 수 분산을 구하여라.

풀이. \(\theta = \frac12\)이다. 점유 수는 0 또는 1이므로 분산은 \(\theta(1 - \theta) = \frac14\)이다. 요동 공식으로 확인하면 \(kT\frac{\partial\theta}{\partial\mu} = \theta(1 - \theta)\)로 같다. 자리 하나에서는 상대 요동이 100%이지만, 자리가 \(10^{15}\)개인 표면 전체의 흡착량은 상대 요동이 \(10^{-7.5}\) 정도로 작다.

마무리

입자를 주고받는 흡착 자리는 대정준 앙상블로 다루며, 자리 하나의 대분배함수에 이상기체의 화학 퍼텐셜을 넣으면 Langmuir 등온선 \(\theta = P/(P + P_0)\)가 나온다. 대정준 앙상블의 입자 수 분산은 \(kT\,\partial\langle N\rangle/\partial\mu\)이고, 이상기체에서 상대 요동은 \(1/\sqrt N\)로 작아 정준 앙상블과 같은 결과를 준다.

2.5.3연습문제

기본

  1. \(P = 3P_0\)일 때 덮임률을 구하여라.
    답

    \(3/4\).

응용

  1. 흡착 에너지 \(\epsilon\)가 클수록 같은 압력에서 덮임률이 커지는 이유를 \(P_0(T)\)로 설명하여라.
    답

    \(P_0 = P_Qe^{-\epsilon/kT}\)가 작아져 \(\theta = P/(P + P_0)\)가 커진다. 강하게 붙는 자리는 낮은 압력에서도 찬다.
