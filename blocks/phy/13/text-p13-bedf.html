보스-아인슈타인 분포와 페르미-디랙 분포

본문
이 절에서 배울 것
  • 한 입자 상태(궤도) 하나를 계로 보고 대정준 앙상블로 점유수를 구한다.
  • 페르미-디랙, 보스-아인슈타인, 볼츠만 분포를 비교한다.
  • 입자 수 조건으로 화학 퍼텐셜을 정하는 방법을 안다.
먼저 알아야 할 것
  • 대정준 앙상블 (2.3절), 동일 입자 (물리12 1.1절).

4.1.1궤도 하나를 계로

상호작용 없는 동일 입자들을 다룰 때는 입자가 아니라 한 입자 상태(궤도)를 계로 봅니다. 에너지 \(\epsilon\)인 궤도에 입자가 \(n\)개 있으면 에너지는 \(n\epsilon\)이고, 나머지 궤도들이 입자 저장소 역할을 합니다. 깁스 인자로

  • 페르미온: \(n = 0, 1\)만 가능. \(\mathcal Z = 1 + e^{-(\epsilon - \mu)/kT}\).
  • 보손: \(n = 0, 1, 2, \dots\). \(\mathcal Z = \sum_n e^{-n(\epsilon - \mu)/kT} = \frac1{1 - e^{-(\epsilon - \mu)/kT}}\) (\(\mu < \epsilon\)이어야 수렴).
결과 4.1.1 \[\bar n_{FD} = \frac1{e^{(\epsilon - \mu)/kT} + 1}, \qquad \bar n_{BE} = \frac1{e^{(\epsilon - \mu)/kT} - 1}, \qquad \bar n_{B} = e^{-(\epsilon - \mu)/kT}.\]

4.1.2비교

  • \(\epsilon - \mu \gg kT\)이면 셋이 모두 볼츠만 분포와 같다(점유수가 작아 겹칠 일이 없음).
  • 페르미-디랙: 0과 1 사이. \(T = 0\)에서 \(\epsilon < \mu\)는 1, \(\epsilon > \mu\)는 0인 계단. \(\mu\) 근처 \(kT\) 폭에서만 부드럽다.
  • 보스-아인슈타인: \(\epsilon \to \mu\)에서 발산. 낮은 에너지 궤도에 입자가 몰린다(보스-아인슈타인 응축, 6.3절).

\(\mu\)는 전체 입자 수 \(N = \sum_{\text{궤도}}\bar n(\epsilon)\)이 맞도록 정합니다. 많은 경우 합을 상태 밀도 \(g(\epsilon)\)의 적분 \(N = \int g(\epsilon)\bar n(\epsilon)d\epsilon\)으로 바꿉니다. 광자처럼 입자 수가 보존되지 않으면 \(\mu = 0\)입니다(6.1절).

예제 4.1.2

\(\epsilon - \mu = kT\)인 궤도의 평균 점유수를 세 분포로 구하세요.

풀이. FD: \(1/(e + 1) \approx 0.269\). BE: \(1/(e - 1) \approx 0.582\). 볼츠만: \(1/e \approx 0.368\). 점유수가 1에 비해 작지 않으면 세 분포가 크게 다릅니다.

요약
  1. 궤도 하나를 대정준 계로: FD \(1/(e^x + 1)\), BE \(1/(e^x - 1)\), \(x = (\epsilon - \mu)/kT\).
  2. \(x \gg 1\)이면 볼츠만으로 수렴.
  3. \(\mu\)는 입자 수 조건으로 정한다. 입자 수가 보존되지 않으면 \(\mu = 0\).

기본

  1. FD 분포에서 \(\bar n(\mu + \delta) + \bar n(\mu - \delta) = 1\)임을 보이세요.
    답
