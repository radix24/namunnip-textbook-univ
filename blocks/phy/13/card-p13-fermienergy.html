구리의 Fermi 에너지와 축퇴압

Fermi 에너지 · 축퇴압 · 문제 해결 전략

출발점

절대 0도에서 전자가 아래 준위부터 채우면 가장 높은 준위가 Fermi 에너지 \(E_F = \frac{\hbar^2}{2m}(3\pi^2n)^{2/3}\)입니다. 평균 에너지 \(\frac35E_F\)이고, 이 운동이 축퇴압 \(P = \frac25nE_F\)을 만듭니다.

문제 해결 전략 · Fermi 기체
  1. 전자 수 밀도를 구한다.
  2. \(E_F\)와 Fermi 온도 \(T_F = E_F/k\)를 구한다.
  3. 축퇴압을 구한다.
  4. 실온과 비교해 축퇴 정도를 본다.

구리(\(n = 8.5\times10^{28}\) m⁻³)의 Fermi 에너지, Fermi 온도, Fermi 속력, 축퇴압은?

풀이

  1. \((3\pi^2n)^{2/3} = (2.52\times10^{30})^{2/3} = 1.85\times10^{20}\) m⁻².
    값.
  2. \(E_F = \frac{(1.055\times10^{-34})^2}{2\times9.11\times10^{-31}}\times1.85\times10^{20} = 1.13\times10^{-18}\) J = 7.0 eV.
    수 eV.
  3. \(T_F = 82000\) K, \(v_F = \sqrt{2E_F/m} = 1.57\times10^6\) m/s.
    실온의 270배.
  4. \(P = \frac25nE_F = 0.4\times8.5\times10^{28}\times1.13\times10^{-18} = 3.8\times10^{10}\) Pa.
    약 38만 기압.

의미

금속 전자는 실온에서도 사실상 절대 0도 상태입니다(\(T \ll T_F\)). 엄청난 축퇴압은 이온과 전자의 Coulomb 인력이 붙잡아 균형을 이룹니다. 이 압력이 금속을 압축하기 어렵게 만듭니다.

검산

구리의 실제 체적 탄성률(약 \(1.4\times10^{11}\) Pa, 대략값)과 같은 크기입니다. 단순 모형치고 잘 맞습니다.
