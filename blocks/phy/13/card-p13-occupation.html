같은 에너지에서 세 분포의 점유 수 비교

Fermi-Dirac · Bose-Einstein · Maxwell-Boltzmann · 문제 해결 전략

출발점

한 상태의 평균 점유 수는 \(\bar n = \frac1{e^{(E - \mu)/kT} \pm 1}\)(+ 페르미온, − 보손)이고, \(e^{(E - \mu)/kT} \gg 1\)이면 둘 다 Boltzmann \(e^{-(E - \mu)/kT}\)가 됩니다.

문제 해결 전략 · 점유 수 비교
  1. \(x = (E - \mu)/kT\)를 구한다.
  2. 세 분포에 넣는다.
  3. \(x\)가 클 때와 작을 때를 비교한다.
  4. 물리적 차이(배타, 뭉침)를 해석한다.

\(x = 0.1, 1, 5\)일 때 FD, BE, MB 점유 수를 구하여라.

풀이

  1. \(x = 0.1\): FD \(1/(1.105 + 1) = 0.475\), BE \(1/0.105 = 9.51\), MB \(0.905\).
    크게 다름.
  2. \(x = 1\): FD 0.269, BE 0.582, MB 0.368.
    MB가 가운데.
  3. \(x = 5\): FD 0.00669, BE 0.00678, MB 0.00674.
    1% 안으로 같다.
  4. 점유 수가 작으면(희박) 세 분포가 같다.
    고전 극한.

의미

페르미온은 한 상태에 하나 이하라 점유 수가 1을 넘지 않고, 보손은 \(\mu\) 근처에서 무한히 많이 모일 수 있습니다(Bose-Einstein 응축, 6.3절). 고전 통계는 둘 사이의 근사입니다.

검산

FD는 늘 0~1, BE는 \(x > 0\)이어야(\(\mu < E\)) 양수. 값들이 그 범위에 있습니다.
