밀도 행렬과 양자 앙상블

본문

스핀 1/2 입자 하나가 "위"와 "아래"의 중첩 상태에 있는 것과, 입자들의 절반은 위, 절반은 아래인 무리는 같은가? 둘 다 \(z\) 방향으로 재면 반반이다. 그런데 \(x\) 방향으로 재면 다르다. 이 차이를 담는 대상이 밀도 행렬이다.

먼저 알아야 할 것Dirac 표기와 기대값(양자역학(1)의 형식론 단원), 정준 앙상블(2.2절)을 쓴다.

4.3.1정의

계가 확률 \(p_i\)로 상태 \(|\psi_i\rangle\)에 있는 앙상블을 \(\hat\rho = \sum_ip_i|\psi_i\rangle\langle\psi_i|\)로 나타낸다. 그러면 관측량의 평균은 \(\langle A\rangle = \sum_ip_i\langle\psi_i|\hat A|\psi_i\rangle = \operatorname{tr}(\hat\rho\hat A)\)이다. \(\hat\rho\)는 에르미트이고 양이며 대각합이 1이다. 상태가 하나뿐이면(\(p_1 = 1\)) 순수 상태로 \(\hat\rho^2 = \hat\rho\), 아니면 섞인 상태로 \(\operatorname{tr}\hat\rho^2 < 1\)이다.

처음 질문의 두 경우를 써 보자. 중첩 \(|\psi\rangle = \frac{1}{\sqrt2}(|\uparrow\rangle + |\downarrow\rangle)\)이면 \(\hat\rho = \frac12\begin{pmatrix}1 & 1\\1 & 1\end{pmatrix}\)이고, 반반의 무리는 \(\hat\rho = \frac12\begin{pmatrix}1 & 0\\0 & 1\end{pmatrix}\)이다. 대각성분은 같아 \(z\) 측정 결과가 같지만, 비대각성분(결맞음)이 다르다. 그러면 \(\langle\sigma_x\rangle = \operatorname{tr}(\hat\rho\sigma_x)\)는 앞의 것에서 1, 뒤의 것에서 0이다.

4.3.2열평형 밀도 행렬

정준 앙상블에서 에너지 고유 상태 \(|n\rangle\)의 확률은 \(e^{-\beta E_n}/Z\)이다. 따라서

\[\hat\rho = \frac{e^{-\beta\hat H}}{Z}, \qquad Z = \operatorname{tr}e^{-\beta\hat H}\]

이다. 이 꼴은 기저에 무관하다. 에너지 고유 기저가 아닌 기저에서도 연산자의 지수로 계산할 수 있다는 것이 밀도 행렬의 쓸모이다. 엔트로피는 von Neumann 엔트로피 \(S = -k\operatorname{tr}(\hat\rho\ln\hat\rho)\)이고, 고유값으로 쓰면 Gibbs 엔트로피 \(-k\sum p\ln p\)와 같다.

예제 4.3.1

자기장 \(B\hat{\mathbf z}\) 속 스핀 1/2(\(\hat H = -\mu B\sigma_z\))의 열평형 밀도 행렬과 \(\langle\sigma_z\rangle\), \(\langle\sigma_x\rangle\)를 구하여라.

풀이. \(e^{-\beta\hat H} = \operatorname{diag}(e^{\beta\mu B}, e^{-\beta\mu B})\), \(Z = 2\cosh(\beta\mu B)\)이다. 그러면 \(\langle\sigma_z\rangle = \tanh(\beta\mu B)\)이고 \(\langle\sigma_x\rangle = 0\)이다. 열평형 상태에는 비대각성분이 없어 \(x\) 방향 자화가 없다. 고온에서는 \(\hat\rho \to I/2\)로 Bloch 구의 중심으로 가고, 저온에서는 위쪽 순수 상태로 간다.

마무리

밀도 행렬 \(\hat\rho = \sum p_i|\psi_i\rangle\langle\psi_i|\)는 양자 상태의 확률적 섞임을 나타내고, 평균은 \(\operatorname{tr}(\hat\rho\hat A)\)이다. 순수한 중첩과 고전적인 섞임은 대각성분이 같아도 비대각성분(결맞음)이 달라 다른 측정에서 구별된다. 열평형 밀도 행렬은 \(e^{-\beta\hat H}/Z\)이고, von Neumann 엔트로피가 열역학 엔트로피를 준다.

4.3.3연습문제

기본

  1. \(\hat\rho = \frac12I\)의 von Neumann 엔트로피를 구하여라.
    답

    \(-k(\frac12\ln\frac12\times2) = k\ln2\).

응용

  1. Bloch 벡터 \(\mathbf r\)로 \(\hat\rho = \frac12(I + \mathbf r\cdot\boldsymbol\sigma)\)를 쓰면 \(\operatorname{tr}\hat\rho^2 = \frac12(1 + r^2)\)임을 보이고, 순수 상태의 조건을 말하여라.
    답

    \(\sigma\)의 대각합 성질로 계산된다. 순수 상태는 \(r = 1\)(구의 표면)이다.
