양자 중력을 실험하기 어려운 까닭

플랑크 에너지 · 차원 분석 · 문제 해결 전략

출발점

양자역학(\(\hbar\)), 상대성(\(c\)), 중력(\(G\))이 모두 중요해지는 에너지는 이 세 상수만으로 만들 수 있는 에너지, 곧 플랑크 에너지 \(E_P = \sqrt{\hbar c^5/G}\)로 어림합니다.

문제 해결 전략 · 차원 분석으로 규모 어림
  1. 관련된 기본 상수를 고른다.
  2. 그 상수들을 곱하고 나누어 원하는 단위(여기서는 에너지)를 만든다.
  3. 값을 넣어 계산하고, 익숙한 단위(GeV)로 바꾼다.
  4. 실험으로 닿을 수 있는 값과 비교한다.

\(\hbar = 1.055\times10^{-34}\) J·s, \(c = 3.00\times10^8\) m/s, \(G = 6.67\times10^{-11}\) N·m²/kg²로 플랑크 에너지를 J와 GeV로 구하여라(1 GeV = \(1.602\times10^{-10}\) J). LHC의 충돌 에너지 13.6 TeV(= 13 600 GeV)의 몇 배인가?

풀이

  1. \(c^5 = (3.00\times10^8)^5 = 2.43\times10^{42}\).
    거듭제곱을 먼저.
  2. \(\hbar c^5/G = 1.055\times10^{-34}\times2.43\times10^{42}/6.67\times10^{-11} = 3.84\times10^{18}\) J².
    단위를 정리하면 J².
  3. \(E_P = \sqrt{3.84\times10^{18}} = 1.96\times10^9\) J.
    제곱근.
  4. \(E_P = 1.96\times10^9/1.602\times10^{-10} = 1.2\times10^{19}\) GeV.
    GeV로 바꾸기.
  5. \(1.2\times10^{19}/1.36\times10^4 \approx 10^{15}\)배.
    LHC와 비교.

의미

입자 하나가 가진 에너지로 보면 플랑크 에너지는 LHC보다 천조 배나 큽니다. 그래서 양자 중력은 가속기로 직접 시험하기 어렵고, 블랙홀이나 초기 우주처럼 극단적인 환경의 흔적을 관측해 간접적으로 단서를 찾습니다.

검산

단위: \(\text{J·s}\times\text{m}^5/\text{s}^5\div(\text{N·m}^2/\text{kg}^2) = \text{J}^2\)이 되는지 확인합니다. \(\text{N} = \text{kg·m/s}^2\)를 넣으면 \(\text{kg}^2\text{m}^4/\text{s}^4 = \text{J}^2\). 맞습니다.
