큐비트를 측정하면

실습 · 중첩과 측정 확률

목표

큐비트 상태 \(\cos\frac\theta2|0\rangle + e^{i\varphi}\sin\frac\theta2|1\rangle\)을 정하고 측정을 되풀이해, 한 번의 결과는 무작위이지만 여러 번의 비율이 이론 확률로 다가가는 것을 봅니다. 측정 방향(기저)을 바꾸면 확률이 달라지는 것도 확인합니다. 성취기준 [물리15-03-01].

준비

왼쪽 구(블로흐 구)의 빨간 화살표가 상태를 나타냅니다. 위쪽 끝이 \(|0\rangle\), 아래쪽 끝이 \(|1\rangle\)입니다. 오른쪽 막대는 측정 결과의 비율, 파란 가로선은 이론 확률입니다. Z 측정은 \(|0\rangle\)인지 \(|1\rangle\)인지, X 측정은 \(|\pm\rangle = \frac1{\sqrt2}(|0\rangle \pm |1\rangle)\) 가운데 어느 것인지를 묻습니다.

절차

  1. θ = 60°에서 "1번 측정"을 여러 번 눌러 결과가 무작위인지 본다.
  2. "100번 측정"을 몇 번 눌러 1의 비율이 이론 확률 \(\sin^2 30° = 0.25\)로 다가가는지 본다.
  3. θ = 0°, 90°, 180°에서 Z 측정을 해 본다.
  4. θ = 90°로 두고 X 측정으로 바꾼 뒤 φ를 0°, 90°, 180°로 바꾼다.

기대 결과

  • 한 번의 결과는 예측할 수 없지만, 측정 수가 늘면 비율이 0.25 근처로 모이고 흔들림은 \(1/\sqrt N\)처럼 준다.
  • θ = 0°이면 늘 0, 180°이면 늘 1, 90°이면 반반.
  • θ = 90°에서 Z 측정은 φ와 상관없이 반반이지만, X 측정은 φ = 0°이면 늘 +, 180°이면 늘 −, 90°이면 반반이다. 위상 φ는 Z 측정으로는 보이지 않는다.

분석

  1. Z 측정의 결과가 같은 두 상태(φ만 다른 상태)를 X 측정으로 구별할 수 있는 까닭을 말해 보세요.
  2. 양자 암호가 엿듣기를 알아챌 수 있는 까닭을, 엿듣는 사람이 측정 기저를 모른다는 것과 이어 설명해 보세요.

더 해 보기

공통7의 이항분포(공통7 4.2절)로, 100번 측정했을 때 1이 15번 이하로 나올 확률을 \(p = 0.25\)에서 구해 보세요.
