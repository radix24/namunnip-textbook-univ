PET 검사의 광자 에너지와 위치 측정

쌍소멸 · 운동량 보존 · 비행 시간 · 문제 해결 전략

출발점

PET(양전자 방출 단층 촬영)은 몸속 방사성 추적자가 낸 양전자가 전자와 만나 사라지며(쌍소멸) 반대 방향으로 내는 광자 두 개를 검출합니다. 두 검출기를 잇는 선 위 어딘가에서 소멸이 일어났다는 정보로 영상을 만듭니다.

문제 해결 전략 · 쌍소멸 분석
  1. 정지한 전자-양전자 쌍의 전체 에너지 \(2m_ec^2\).
  2. 운동량 0 → 같은 에너지의 광자 두 개가 반대 방향.
  3. 두 광자의 도착 시간 차로 선 위의 위치를 구한다.
  4. 시간 분해능을 거리 분해능으로 바꾼다.

각 광자의 에너지는? 두 검출기에 도착한 시간 차가 200 ps이면 소멸 위치는 가운데에서 얼마나 떨어져 있나?

풀이

  1. \(2\times0.511\) MeV를 둘이 나눠 각 0.511 MeV(511 keV).
    에너지·운동량 보존.
  2. 광자 운동량이 같고 반대: 정확히 180° 방향.
    처음 운동량 0.
  3. 시간 차 \(\Delta t\)면 위치 차 \(\Delta x = c\Delta t/2\).
    한쪽은 \(x\) 더 가고 다른 쪽은 \(x\) 덜 감.
  4. \(3\times10^8\times200\times10^{-12}/2 = 3\) cm.
    비행 시간(TOF) PET.

의미

물리3의 특수 상대성(\(E = mc^2\))과 운동량 보존이 병원 장비의 원리입니다. 시간 분해능이 좋아질수록 선 위의 위치를 더 정확히 알아 영상이 선명해집니다.

검산

511 keV 광자의 파장 \(1240/511000\) nm = 2.4 pm. 전자의 Compton 파장과 같습니다(정지 에너지와 같은 에너지라서).
