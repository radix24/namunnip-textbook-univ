자기 이력 곡선 측정

본문
이 절에서 배울 것
  • 고리 시료의 1차 코일 전류로 \(H\)를, 2차 코일 유도 전압의 적분으로 \(B\)를 구한다.
  • RC 적분기와 오실로스코프 XY 모드로 이력 곡선을 그린다.
먼저 알아야 할 것
  • H 장과 자기 회로 (물리9 2.3절), 강자성과 이력 (물리9 2.2절), 적분기 (물리2 6.2절).

2.1.1장치

평균 둘레 \(l\), 단면 \(A\)인 고리(토로이드) 시료에 1차 코일 \(N_1\)회, 2차 코일 \(N_2\)회를 감습니다.

  • H: 앙페르 법칙으로 \(H = N_1I_1/l\). 1차 회로에 작은 저항 \(R_1\)을 넣어 전압 \(V_X = I_1R_1\)으로 잰다.
  • B: 2차 코일 유도 전압 \(V_2 = -N_2A\frac{dB}{dt}\). 적분하면 \(B\). RC 적분기(\(RC \gg\) 주기)의 축전기 전압 \(V_Y \approx \frac1{RC}\int V_2dt = -\frac{N_2A}{RC}B\).
  • 오실로스코프를 XY 모드로 놓고 \(V_X\)(가로)와 \(V_Y\)(세로)를 넣으면 이력 곡선이 그려진다.
식 2.1.1 \[H = \frac{N_1}{lR_1}V_X, \qquad B = \frac{RC}{N_2A}|V_Y|.\]
예제 2.1.2

\(N_1 = 200\), \(l = 0.10\) m, \(R_1 = 1.0\ \Omega\), \(N_2 = 100\), \(A = 1.0\ \text{cm}^2\), \(RC = 0.10\) s입니다. \(V_X = 0.50\) V, \(V_Y = 0.12\) V일 때 \(H\)와 \(B\)는?

풀이. \(H = \frac{200}{0.10\times1.0}\times0.50 = 1000\) A/m. \(B = \frac{0.10}{100\times10^{-4}}\times0.12 = 1.2\) T. \(\mu_r = B/(\mu_0H) \approx 950\).

요약
  1. \(H = N_1I_1/l\), \(B = \frac{RC}{N_2A}V_Y\) (RC 적분기).
  2. XY 모드로 이력 곡선을 그린다. 곡선 읽기는 2.2절.
  3. \(RC \gg\) 주기. 손실의 분리는 2.3절.

2.1.2연습문제

기본

  1. \(RC = 0.10\) s인 적분기로 50 Hz 신호를 적분하면 \(RC\)는 주기의 몇 배인가? 충분한가?
    답

    주기 20 ms의 5배. 대략 충분하지만 10배 이상이면 위상 오차가 더 작다.
