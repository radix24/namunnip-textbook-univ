빈 브리지 발진기

본문
이 절에서 배울 것
  • 빈 회로망의 전달 함수와 바르크하우젠 조건으로 발진 진동수와 필요한 이득을 구한다.
  • 진폭 안정화의 원리와 발진 진동수를 측정하는 방법을 안다.
먼저 알아야 할 것
  • 능동 필터 (4.1절), 복소 임피던스 (물리9 3.3절).

4.2.1발진 조건

증폭기 출력을 RC 직렬-RC 병렬 회로(빈 회로망)를 거쳐 비반전 입력으로 되먹입니다. 빈 회로망의 전달 함수는 \(\omega = 1/RC\)에서 위상 0, 크기 \(\frac13\)입니다.

바르크하우젠 조건

한 바퀴 이득 \(A\beta = 1\)(크기 1, 위상 0)이면 정상 발진. 빈 브리지에서 \(f = \frac1{2\pi RC}\), 증폭기 이득 \(A = 3\).

예제 4.2.1

\(R = 10\) kΩ, \(C = 10\) nF로 살렌-키 버터워스 필터와 빈 브리지 발진기를 만들면 차단 진동수와 발진 진동수는?

풀이. 둘 다 \(\frac1{2\pi RC} = \frac1{2\pi\times10^{-4}} \approx 1.59\) kHz. 버터워스 필터의 이득은 1.586(\(R_f/R_g = 0.586\)), 발진기는 3(\(R_f/R_g = 2\))으로 맞춥니다.

4.2.2진폭 안정화와 측정

이득이 3보다 조금 크면 발진이 자라고, 작으면 꺼집니다. 진폭을 안정시키려면 이득이 진폭에 따라 줄어드는 소자(전구, 다이오드, JFET)를 되먹임에 넣습니다. 휼렛-팩커드의 첫 제품(1939)이 전구로 안정화한 빈 브리지 발진기였습니다. 발진 진동수는 오실로스코프로 주기를 재거나 주파수 계수기로 재고, 출력 파형의 일그러짐(사인파에서 벗어남)으로 이득이 너무 큰지 확인합니다.

요약
  1. 빈 회로망: \(\omega = 1/RC\)에서 위상 0, 크기 1/3 → 이득 3에서 발진.
  2. 진폭 안정화 소자로 이득을 정확히 3에 맞춘다.

4.2.3연습문제

기본

  1. \(C = 22\) nF로 1.0 kHz 발진기를 만들려면 \(R\)은?
    답

    \(1/(2\pi\times1000\times22\times10^{-9}) \approx 7.2\) kΩ.

  2. 이득을 3.5로 고정하면 출력은 어떻게 되는가?
    답

    진폭이 계속 자라 OP-amp가 포화되어 일그러진 파형이 된다.
