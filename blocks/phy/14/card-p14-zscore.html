두 조의 결과가 맞는지 묻는 질문에 수치로 답하기

z 값 · 가중 평균 · 문제 해결 전략

출발점

두 측정값의 차이가 의미 있는지는 \(z = \frac{|x_1 - x_2|}{\sqrt{u_1^2 + u_2^2}}\)로 판단합니다. \(|z| < 2\)이면 우연 오차로 설명되는 범위입니다. 서로 맞으면 가중치 \(1/u^2\)로 평균을 내어 더 정밀한 값을 얻습니다.

문제 해결 전략 · 질문에 수치로 답하기
  1. 두 값의 차이와 합성 불확도로 \(z\)를 구한다.
  2. \(|z| < 2\)이면 서로 맞는다고 말한다.
  3. 가중 평균과 그 불확도를 구한다.
  4. 기준값과 비교해 결론을 한 문장으로 말한다.

발표 중 "두 조의 값이 다른데 어느 쪽이 맞나요?"라는 질문을 받았다. A조 \(g = 9.74 \pm 0.05\), B조 \(9.85 \pm 0.04\) m/s²이다. 수치 근거를 갖춘 답을 준비하여라(기준값 9.80).

풀이

  1. \(z = \frac{0.11}{\sqrt{0.05^2 + 0.04^2}} = \frac{0.11}{0.064} = 1.7\).
    2보다 작다.
  2. 두 값은 불확도 안에서 서로 맞는다. 어느 한쪽이 틀렸다고 할 근거는 없다.
    판단.
  3. 가중치 400, 625. 평균 \(\frac{9.74\times400 + 9.85\times625}{1025} = 9.81\), 불확도 \(1/\sqrt{1025} = 0.031\).
    정밀도가 좋아진다.
  4. 기준값과 \(z = 0.01/0.031 = 0.3\). 합친 결과는 기준값과 잘 맞는다.
    결론.

의미

답은 "차이는 합성 불확도의 1.7배로 우연 오차 범위입니다. 두 값을 합치면 9.81 ± 0.03으로 기준값과 맞습니다"처럼 수치와 판단을 함께 말합니다. \(z\)가 3을 넘었다면 체계 오차를 찾겠다고 답해야 합니다.

검산

가중 평균 불확도 0.031은 두 불확도(0.05, 0.04)보다 작습니다. 독립인 두 측정을 합치면 늘 더 정밀해집니다.
