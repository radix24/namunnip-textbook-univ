광자 큐비트의 상태 단층 촬영

본문

광자 하나의 편광은 큐비트이다. 그런데 측정 한 번은 "통과" 또는 "차단" 하나만 알려 주고 상태를 무너뜨린다. 같은 방식으로 준비한 광자를 많이 재면 상태 전체를 알아낼 수 있을까? 어떤 측정을 몇 가지 해야 하는가?

먼저 알아야 할 것밀도 행렬과 Bloch 벡터(통계물리학의 밀도 행렬 절), 파장판과 편광(물리학실험(B-1)의 편광 실험)을 쓴다.

7.1.1세 기저 측정

큐비트의 밀도 행렬은 Bloch 벡터 \(\mathbf r = (r_x, r_y, r_z)\)로 \(\hat\rho = \frac12(I + r_x\sigma_x + r_y\sigma_y + r_z\sigma_z)\)이고, \(r_i = \langle\sigma_i\rangle\)이다. 편광에서는 수평·수직(H, V)이 \(\sigma_z\), 대각·반대각(D, A)이 \(\sigma_x\), 오른·왼 원편광(R, L)이 \(\sigma_y\)의 고유 상태이다. 따라서 각 기저에서 두 결과의 계수 \(N_+\), \(N_-\)를 재면

\[r_i = \frac{N_+ - N_-}{N_+ + N_-}\]

로 Bloch 벡터의 세 성분을 얻는다. 측정 기저는 파장판으로 바꾼다. 반파장판을 22.5° 돌리면 D/A 측정이 되고, 사분파장판을 45°에 두면 R/L 측정이 된다. 상태 하나를 알려면 이렇게 서로 다른 세 기저가 필요하다. 하나만 재면 Bloch 구에서 그 축 성분만 알 수 있기 때문이다.

7.1.2통계 오차와 물리적 조건

계수는 Poisson 요동을 가지므로 \(N\)개의 광자로 잰 \(r_i\)의 표준 오차는 \(\sqrt{(1 - r_i^2)/N}\) 정도이다. 그래서 단순 역산으로 얻은 \(\mathbf r\)가 \(|\mathbf r| > 1\)이 되어, 음의 고유값을 가진 비물리적 밀도 행렬이 나오기도 한다. 이때는 물리적 밀도 행렬 가운데 자료를 가장 잘 설명하는 것을 최대 가능도로 고른다. 재구성한 \(\hat\rho\)가 목표 상태 \(|\psi\rangle\)에 얼마나 가까운지는 충실도 \(F = \langle\psi|\hat\rho|\psi\rangle\)로 나타낸다.

예제 7.1.1

대각 편광 D를 만들려고 한 광자원을 재었더니 H/V에서 (510, 490), D/A에서 (960, 40), R/L에서 (505, 495)였다. Bloch 벡터와 목표 상태에 대한 충실도를 구하여라.

풀이. \(r_z = 0.02\), \(r_x = 0.92\), \(r_y = 0.01\)이다. D는 \(\mathbf r = (1, 0, 0)\)이므로 \(F = \frac12(1 + r_x) = 0.96\)이다. \(|\mathbf r| \approx 0.92\)라 순수 상태보다 조금 섞여 있다. 파장판 각도의 오차나 광원의 편광 불완전성이 원인일 수 있고, 각 성분의 통계 오차는 0.01~0.03 정도이다.

마무리

큐비트 상태는 Bloch 벡터의 세 성분으로 정해지므로, 같은 방식으로 준비한 광자를 서로 다른 세 기저(H/V, D/A, R/L)에서 재어 재구성한다. 기저는 파장판으로 바꾸고, 계수의 차를 합으로 나누면 각 성분이 나온다. 통계 오차 때문에 비물리적 결과가 나오면 최대 가능도로 보정하고, 결과는 충실도로 평가한다.

7.1.3연습문제

기본

  1. H 상태를 측정했더니 H/V에서 (980, 20)이었다. \(r_z\)와 H에 대한 충실도를 구하여라.
    답

    \(r_z = 0.96\), 다른 성분이 0이면 \(F = \frac12(1 + 0.96) = 0.98\).

응용

  1. 두 큐비트 상태의 단층 촬영에는 측정 설정이 몇 가지 필요한가?
    답

    각 큐비트에 세 기저를 짝지어 \(3^2 = 9\)가지. 밀도 행렬의 실수 매개변수는 15개이다.
