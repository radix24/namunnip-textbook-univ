네 번 재서 참 홀 전압 얻기

잡전압 분리 · 부호 조합 · 이동도

출발점

홀 전압은 \(I\)와 \(B\)의 부호에 모두 따라 바뀌고, 비정렬 전압은 \(I\)의 부호만, 열전 전압은 어느 부호에도 따르지 않습니다(1.2절).

문제 해결 전략 · 부호 표 만들기
  1. 네 측정에서 각 성분의 부호를 표로 적는다.
  2. 홀 전압만 남는 조합을 찾는다.
  3. 농도와 비저항으로 이동도를 구한다.

두께 1.0 mm인 시료에 10 mA, 0.30 T로 잰 전압이 \(V(+I,+B) = 5.8\), \(V(+I,-B) = -4.2\), \(V(-I,+B) = -5.4\), \(V(-I,-B) = 4.6\) mV였다. (가) 홀 전압, 비정렬 전압, 열전 전압은? (나) 비저항이 \(0.010\ \Omega\cdot\text{m}\)일 때 운반자 농도와 이동도는?

풀이

  1. (가) \(V_H = \frac14[V(+,+) - V(+,-) - V(-,+) + V(-,-)] = \frac14(5.8 + 4.2 + 5.4 + 4.6) = 5.0\) mV. 비정렬 \(V_0 = \frac14[V(+,+) + V(+,-) - V(-,+) - V(-,-)] = \frac14(5.8 - 4.2 + 5.4 - 4.6) = 0.6\) mV.
    \(I\) 부호만 따르는 성분.
  2. 열전 \(V_T = \frac14(5.8 - 4.2 - 5.4 + 4.6) = 0.2\) mV.
    모두 더한 평균.
  3. (나) \(n = \frac{IB}{qtV_H} = \frac{0.010\times0.30}{1.6\times10^{-19}\times10^{-3}\times0.0050} = 3.8\times10^{21}\ \text{m}^{-3}\). \(\mu = \frac1{nq\rho} = \frac1{3.8\times10^{21}\times1.6\times10^{-19}\times0.010} = 0.16\ \text{m}^2/(\text{V·s})\).
    \(\mu = |R_H|/\rho\).

의미

한 번만 재면 5.8 mV를 홀 전압으로 착각해 16% 큰 값을 얻는다. 네 번 재는 조합은 잡전압이 홀 전압과 다른 방식으로 부호를 바꾼다는 성질을 이용한 것으로, 대조 실험(5.2절)의 좋은 예이다.

검산

세 성분을 다시 합치면 \(V(+,+) = 5.0 + 0.6 + 0.2 = 5.8\), \(V(-,-) = 5.0 - 0.6 + 0.2 = 4.6\) mV로 측정값과 맞다.
