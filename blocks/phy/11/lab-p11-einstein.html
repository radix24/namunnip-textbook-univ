두 아인슈타인 고체의 에너지 나눔

실습 · 다중도

목표

맞닿은 두 아인슈타인 고체가 에너지 양자를 나눠 가질 때, 나눔 \(q_A\)의 확률 분포를 다중도로 계산하고, 진동자 수가 늘수록 분포가 좁아져 "가장 그럴듯한 나눔"이 압도적이 되는 모습을 확인한다. 성취기준 [물리11-03-02], [물리11-03-01].

준비

막대 높이는 \(\Omega_A(q_A)\,\Omega_B(q - q_A)/\Omega_{\text{전체}}\)이다. 빨간 막대가 가장 그럴듯한 나눔, 점선이 진동자당 같은 몫(\(q_A/N_A = q_B/N_B\))이다.

절차

  1. \(N_A = N_B = 3\), \(q = 6\)에서 3.2절 예제의 확률(0.216, 0.061)을 확인한다.
  2. \(N_A = N_B = 300\), \(q = 100\)으로 키워 상대 폭과 "모두 A에 있을 확률"을 본다.
  3. \(N_A = 100\), \(N_B = 300\), \(q = 400\)에서 가장 그럴듯한 \(q_A\)가 진동자 수 비율로 나뉘는지 본다.
  4. 같은 \(N\)에서 \(q\)를 키우거나 줄이며 상대 폭이 어떻게 변하는지 본다.

기대 결과

  • 작은 계: 분포가 넓고, 한쪽에 몰리는 경우도 흔하다.
  • \(N_A = N_B = 300\), \(q = 100\): 상대 폭이 10% 정도로 좁아지고, 모두 A에 있을 확률은 약 \(10^{-27}\)이다.
  • \(N_A : N_B = 1 : 3\)이면 \(q_A \approx q/4\). 진동자당 에너지가 같아지는 곳 = 온도가 같아지는 곳.
  • 계가 클수록 상대 폭은 대략 \(1/\sqrt N\)로 줄어든다.

분석

  1. 진동자가 \(10^{23}\)개라면 상대 폭이 얼마쯤일지 어림하고, 이것이 열역학의 "평형값"이 사실상 확정적인 까닭임을 설명해 보자.
  2. 처음에 모든 에너지가 A에 있었다면 시간이 지나며 어떻게 될지, 이 분포로 말해 보자.

더 해 보기

가장 그럴듯한 \(q_A\)에서 \(\partial\ln\Omega_A/\partial q_A = \partial\ln\Omega_B/\partial q_B\)를 수치로 확인하고, 이 값이 \(\hbar\omega/kT\)임을 보이자.
