열역학 항등식과 맥스웰 관계식

본문

엔트로피를 직접 재는 계기는 없다. 그런데 기체를 등온 압축할 때 엔트로피가 얼마나 줄어드는지는 알고 싶다. 잴 수 없는 양을 잴 수 있는 양으로 바꾸는 방법이 있을까? 열역학의 수많은 편미분 사이에는 어떤 관계가 숨어 있을까?

먼저 알아야 할 것자유 에너지(4.1절), 편미분과 전미분(공통2 4.1절)을 쓴다.

4.3.1열역학 항등식

S(U, V, N)의 전미분에서 \(\partial S/\partial U = 1/T\), \(\partial S/\partial V = P/T\), \(\partial S/\partial N = -\mu/T\)로 정의하면 다음을 얻는다.

항등식 4.3.1 \[dU = T\,dS - P\,dV + \mu\,dN,\] \[dH = T\,dS + V\,dP + \mu\,dN, \quad dF = -S\,dT - P\,dV + \mu\,dN, \quad dG = -S\,dT + V\,dP + \mu\,dN\]

이것은 상태 함수 사이의 관계이므로 가역이든 비가역이든 성립한다. 다만 가역 과정에서만 T dS를 열로, −P dV를 일로 읽을 수 있다. 각 퍼텐셜은 미분하는 변수가 서로 다르며, 이것을 자연 변수라 한다. 그리고 −TS나 +PV를 더하는 르장드르 변환으로 서로 바뀐다(그림 1).

4.3.2맥스웰 관계식

dF = −S dT − P dV에서 \(S = -\partial F/\partial T\), \(P = -\partial F/\partial V\)이다. 그런데 혼합 편미분은 순서와 상관없으므로 \(\partial^2F/\partial V\partial T = \partial^2F/\partial T\partial V\)이고, 여기서 관계식 하나가 나온다. 네 퍼텐셜에서 같은 일을 하면 네 개의 맥스웰 관계식을 얻는다.

맥스웰 관계식 \[\left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial P}{\partial S}\right)_V, \quad \left(\frac{\partial T}{\partial P}\right)_S = \left(\frac{\partial V}{\partial S}\right)_P,\] \[\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial P}{\partial T}\right)_V, \quad -\left(\frac{\partial S}{\partial P}\right)_T = \left(\frac{\partial V}{\partial T}\right)_P\]

처음 질문의 답이 이 관계식들이다. 엔트로피는 직접 잴 수 없지만, 오른쪽의 상태방정식 기울기는 잴 수 있다. 예를 들어 마지막 식에 따르면 등온 압축에서 엔트로피가 얼마나 줄어드는지는 열팽창 계수로 알 수 있다.

4.3.3C_P − C_V의 일반식

S를 T와 V의 함수로 보고 정압에서 T로 미분하면 \((\partial S/\partial T)_P = (\partial S/\partial T)_V + (\partial S/\partial V)_T(\partial V/\partial T)_P\)이다. 여기에 맥스웰 관계식과 C = T(∂S/∂T)를 쓰고 정리하면 다음을 얻는다.

결과 4.3.2 \[C_P - C_V = \frac{TV\beta^2}{\kappa_T}, \qquad \beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_P, \quad \kappa_T = -\frac1V\left(\frac{\partial V}{\partial P}\right)_T\]

β는 열팽창 계수, \(\kappa_T\)는 등온 압축률이다. 이상기체이면 β = 1/T, \(\kappa_T\) = 1/P이므로 \(C_P - C_V = PV/T = Nk\)로 2.3절과 같다. 고체는 β가 작아 그 차이가 몇 % 이하이다.

예제 4.3.3

이상기체에서 \((\partial U/\partial V)_T = 0\)임을 맥스웰 관계식으로 보여라.

풀이. dU = T dS − P dV에서 \((\partial U/\partial V)_T = T(\partial S/\partial V)_T - P = T(\partial P/\partial T)_V - P\)이다. 이상기체 P = NkT/V이면 T·Nk/V − P = 0이다. 그러므로 이상기체의 내부 에너지가 온도만의 함수라는 사실이 상태방정식에서 나온다.

흔한 오해맥스웰 관계식을 외워야 할 공식 넷으로 여기기 쉽지만, 퍼텐셜의 미분형 하나에서 혼합 편미분의 대칭으로 언제든 다시 유도할 수 있다. 또 편미분에서 고정하는 변수를 빠뜨리면 전혀 다른 양이 된다. (∂S/∂V)_T와 (∂S/∂V)_U는 다르다.
마무리

열역학 항등식 dU = T dS − P dV + μ dN과 H, F, G의 미분형은 상태 함수 사이의 관계로, 르장드르 변환으로 서로 바뀐다. 혼합 편미분의 대칭에서 나오는 맥스웰 관계식은, 처음 질문처럼 잴 수 없는 엔트로피의 미분을 상태방정식의 기울기로 바꾼다. 이것으로 \(C_P - C_V = TV\beta^2/\kappa_T\) 같은 일반식을 얻는다.

4.3.4연습문제

기본

  1. \(dG\)에서 맥스웰 관계식 하나를 유도하여라.
    답

    \(S = -\partial G/\partial T\), \(V = \partial G/\partial P\). 혼합 편미분: \(-(\partial S/\partial P)_T = (\partial V/\partial T)_P\).

발전

  1. 판데르발스 기체 \((P + aN^2/V^2)(V - Nb) = NkT\)에서 \((\partial U/\partial V)_T\)를 구하여라.
    답

    \(T(\partial P/\partial T)_V - P = \frac{NkT}{V - Nb} - P = \frac{aN^2}{V^2}\). 부피가 커지면 분자 사이 인력을 거슬러 내부 에너지가 늘어난다.
