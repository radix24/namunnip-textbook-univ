네 과정으로 된 순환의 일과 열

등압·등적 과정 · 순환 · 문제 해결 전략

출발점

순환 과정에서 기체가 한 알짜 일은 \(P\)-\(V\) 그래프에서 고리가 둘러싼 넓이이고, 내부 에너지 변화는 0이라 알짜 열 = 알짜 일이다. 각 과정에서 열이 들어오는지 나가는지를 따로 센다.

문제 해결 전략 · 순환 분석
  1. 각 꼭짓점의 \(P, V, T\)를 표로 만든다.
  2. 과정마다 \(W\), \(\Delta U = nC_V\Delta T\), \(Q = \Delta U + W\)를 구한다.
  3. 들어온 열(\(Q > 0\))만 더해 \(Q_{\text{in}}\).
  4. 효율 \(W_{\text{알짜}}/Q_{\text{in}}\).

단원자 이상기체 1 mol이 (1) 1 atm, 22.4 L → 등압으로 44.8 L → 등적으로 0.5 atm → 등압으로 22.4 L → 등적으로 처음으로 돌아온다. 알짜 일과 효율은?

풀이

  1. 알짜 일 = 넓이 \(0.5\ \text{atm}\times22.4\ \text{L} = 11.2\) L·atm = 1135 J.
    직사각형.
  2. 들어온 열: 등압 팽창(1→2) \(Q = nC_P\Delta T = \frac52P\Delta V = \frac52\times22.4 = 56\) L·atm.
    \(\Delta T > 0\).
  3. 마지막 등적(0.5 → 1 atm)도 온도가 올라 열이 들어옴: \(\frac32V\Delta P = \frac32\times22.4\times0.5 = 16.8\) L·atm.
    \(\Delta T > 0\).
  4. \(Q_{\text{in}} = 72.8\) L·atm, 효율 \(11.2/72.8 = 15.4\%\).
    나머지 두 과정은 열을 내놓는다.

의미

같은 최고·최저 온도(546 K, 136.5 K) 사이 Carnot 효율은 75%인데 이 순환은 15%이다. 온도 차가 큰 상태로 열을 주고받는 등적·등압 과정이 비가역성을 키우기 때문이다.

검산

내놓은 열: 2→3 등적 \(\frac32\times44.8\times0.5 = 33.6\), 3→4 등압 \(\frac52\times0.5\times22.4 = 28\). 합 61.6, \(72.8 - 61.6 = 11.2\) = 알짜 일. 맞다.
