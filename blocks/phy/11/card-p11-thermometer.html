두 온도계가 다르게 읽는 까닭

열평형 · 온도 눈금 · 기체 온도계 · 문제 해결 전략

출발점

제0법칙은 "A와 B가 각각 C와 열평형이면 A와 B도 열평형"이라 온도라는 공통 양을 정의하게 해 준다. 하지만 눈금은 온도계 물질의 성질(팽창, 저항)에 달려 있어, 두 기준점 사이에서는 온도계마다 다르게 읽을 수 있다.

문제 해결 전략 · 온도 눈금 비교
  1. 두 기준점(얼음점, 끓는점)에서 온도계 값을 정한다.
  2. 그 사이를 선형으로 나눈 눈금을 쓴다.
  3. 물질의 성질이 온도에 선형이 아니면 중간에서 차이가 난다.
  4. 물질에 무관한 기준(이상기체 온도계, 열역학 온도)과 비교한다.

저항 \(R(T) = R_0(1 + aT + bT^2)\)(\(a = 3.9\times10^{-3}\)/°C, \(b = -5.8\times10^{-7}\)/°C², 백금, 대략값)인 저항 온도계를 0 °C와 100 °C에서 맞춰 선형 눈금을 만들었다. 실제 50 °C에서 이 눈금은 몇 °C를 가리키나?

풀이

  1. 선형 눈금: \(T_R = 100\frac{R - R(0)}{R(100) - R(0)}\).
    두 기준점.
  2. \(R(100) - R_0 = R_0(0.39 - 0.0058) = 0.3842R_0\).
    100 °C.
  3. \(R(50) - R_0 = R_0(0.195 - 0.00145) = 0.19355R_0\).
    50 °C.
  4. \(T_R = 100\times0.19355/0.3842 = 50.38\) °C.
    0.38 °C 차이.

의미

온도계마다 눈금이 조금씩 다르므로 국제 온도 눈금은 물질에 무관한 열역학 온도(이상기체 극한, Carnot 효율로 정의)를 기준으로 하고, 실용 온도계를 그에 맞춰 보정한다.

검산

\(b = 0\)이면 정확히 50 °C가 나온다. 차이는 2차 항에서만 생긴다.
