CP와 CV의 차이와 엔탈피

열용량 · 엔탈피 · Mayer 관계 · 문제 해결 전략

출발점

등적에서 넣은 열은 모두 내부 에너지가 되지만, 등압에서는 일부가 팽창하는 일에 쓰입니다. 그래서 \(C_P > C_V\)이고 이상기체에서 \(C_P - C_V = nR\)입니다. 등압 과정의 열은 엔탈피 변화 \(\Delta H\)입니다.

문제 해결 전략 · 열용량 계산
  1. 자유도로 \(C_V = \frac f2nR\)을 구한다.
  2. \(C_P = C_V + nR\), \(\gamma = C_P/C_V\).
  3. 등압 가열 열 \(= \Delta H = C_P\Delta T\).
  4. 측정값과 비교해 자유도를 판단한다.

방 안 공기(50 m³, 1 atm, 이원자)를 10 °C에서 20 °C로 데운다. (가) 창문을 열어 둔 채(등압, 공기 일부가 빠져나감은 무시) 필요한 열 (나) 완전히 밀폐(등적)한 경우는?

풀이

  1. 몰수 \(n = PV/RT = \frac{101325\times50}{8.314\times283} = 2153\) mol.
    이상기체.
  2. (가) \(Q = nC_{P,m}\Delta T = 2153\times\frac72\times8.314\times10 = 627\) kJ.
    \(C_P = \frac72R\).
  3. (나) \(Q = nC_{V,m}\Delta T = 2153\times\frac52\times8.314\times10 = 448\) kJ.
    \(C_V = \frac52R\).
  4. 차이 179 kJ는 공기가 팽창하며 바깥 대기를 밀어낸 일.
    \(nR\Delta T\).

의미

실제 방은 공기가 틈으로 빠져나가 등압에 가깝습니다. 벽과 가구의 열용량이 공기보다 훨씬 커서, 실제 난방에 드는 열은 이 계산보다 훨씬 많습니다.

검산

\(\gamma = 627/448 = 1.40\). 이원자 기체의 7/5와 맞습니다.
