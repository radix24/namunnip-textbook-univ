아인슈타인 고체와 열 교환

본문
이 절에서 배울 것
  • 아인슈타인 고체의 다중도 \(\Omega(N, q) = \binom{q + N - 1}{q}\)를 유도한다.
  • 두 고체가 에너지를 나눌 때 가장 그럴듯한 나눔이 압도적임을 보인다.
  • 온도를 \(1/T = \partial S/\partial U\)로 정의한다.
먼저 알아야 할 것
  • 미시 상태와 엔트로피 (3.1절), 양자 조화 진동자 (물리3 4.2절).

3.2.1다중도

아인슈타인 고체는 진동수가 모두 같은 양자 진동자 \(N\)개입니다(원자 \(N/3\)개의 세 방향 진동). 진동자마다 에너지는 \(\hbar\omega\)의 정수배이므로, 전체 에너지 양자 \(q\)개를 \(N\)개 진동자에 나누는 방법의 수가 다중도입니다. 양자 \(q\)개를 점, 진동자 경계를 막대 \(N - 1\)개로 늘어놓는 방법의 수와 같습니다.

결과 3.2.1 \[\Omega(N, q) = \binom{q + N - 1}{q} = \frac{(q + N - 1)!}{q!\,(N - 1)!}.\]

예: \(N = 3\), \(q = 3\)이면 \(\binom53 = 10\).

3.2.2두 고체의 열 교환

고체 A(\(N_A\), \(q_A\))와 B(\(N_B\), \(q_B\))가 맞닿아 \(q = q_A + q_B\)를 나눠 가집니다. 전체 계의 미시 상태가 모두 같은 확률이면, 나눔 \(q_A\)의 확률은 \(\Omega_A(q_A)\Omega_B(q - q_A)\)에 비례합니다.

  • 진동자 수가 몇 개면 분포가 넓어 여러 나눔이 흔하다.
  • 진동자 수가 수백 개만 되어도 봉우리가 아주 좁아진다. 폭은 대략 \(1/\sqrt N\)의 비율로 줄어든다.
  • 봉우리는 단위 양자당 다중도 증가율이 두 고체에서 같아지는 곳, 곧 \(\frac{\partial\ln\Omega_A}{\partial q_A} = \frac{\partial\ln\Omega_B}{\partial q_B}\)에 있다.

처음에 에너지가 한쪽에 몰려 있어도 무작위 교환이 계속되면 봉우리 근처로 가서 머뭅니다. 되돌아갈 확률은 0은 아니지만 너무 작아 관측되지 않습니다. 이것이 "열은 뜨거운 데서 찬 데로 흐른다"의 통계적 설명입니다. 아래 실습 카드에서 \(N\)을 키우며 봉우리가 좁아지는 모습을 볼 수 있습니다.

3.2.3온도의 정의

평형에서 같아지는 양은 \(\partial S/\partial U\)이고, 에너지는 이 값이 작은 쪽에서 큰 쪽으로 흐릅니다(그래야 전체 엔트로피가 증가). 온도가 높은 쪽에서 에너지가 나오므로

정의 3.2.2 \[\frac1T = \left(\frac{\partial S}{\partial U}\right)_{N, V}.\]

큰 아인슈타인 고체(\(q \gg N\))에서 스털링 근사로 \(S \approx Nk[\ln(q/N) + 1]\), \(U = q\hbar\omega\)이므로 \(1/T = Nk/U\), 곧 \(U = NkT\)로 등분배와 같습니다. 낮은 온도에서는 이 근사가 깨져 열용량이 0으로 줄어듭니다(물리13).

예제 3.2.3

\(N_A = N_B = 3\), \(q = 6\)에서 \(q_A = 3\)과 \(q_A = 6\)의 확률은?

풀이. 전체 \(\Omega = \binom{6 + 6 - 1}{6} = 462\). \(q_A = 3\): \(\Omega_A\Omega_B = 10\times10 = 100\), 확률 0.216. \(q_A = 6\): \(\binom86\times1 = 28\), 확률 0.061. 진동자가 적으면 한쪽에 몰리는 경우도 흔합니다.

요약
  1. \(\Omega(N, q) = \binom{q + N - 1}{q}\).
  2. 두 고체의 나눔은 \(\Omega_A\Omega_B\)가 최대인 곳에 극도로 쏠린다.
  3. \(1/T = \partial S/\partial U\). 큰 고체에서 \(U = NkT\).

3.2.4연습문제

기본

  1. \(N = 4\), \(q = 2\)인 아인슈타인 고체의 미시 상태를 모두 나열하고 수를 확인하세요.
    답

    한 진동자에 2개: 4가지, 두 진동자에 1개씩: 6가지. 합 10 = \(\binom52\).

발전

  1. \(q \gg N\)에서 \(S \approx Nk[\ln(q/N) + 1]\)을 스털링 근사로 유도하세요.
    답

    \(\ln\Omega \approx (q + N)\ln(q + N) - q\ln q - N\ln N\). \(\ln(q + N) \approx \ln q + N/q\)를 쓰면 \(N\ln(q/N) + N\).
