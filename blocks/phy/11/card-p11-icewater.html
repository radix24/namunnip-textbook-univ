얼음을 넣은 음료의 끝 온도

잠열 · 열량 보존 · 문제 해결 전략

출발점

단열된 그릇에서 잃은 열 = 얻은 열입니다. 얼음은 녹는 데 333 J/g, 물은 1 K 데우는 데 4.18 J/g가 듭니다(2.4절).

문제 해결 전략 · 녹일 열이 충분한지부터
  1. 물이 0 °C까지 식으며 내놓을 수 있는 열을 구한다.
  2. 얼음을 모두 녹이는 데 드는 열과 비교한다.
  3. 충분하면 끝 온도를 미지수로 두고 열량 보존식을 푼다.

30 °C 물 200 g에 0 °C 얼음 50 g을 넣었다(그릇과 바깥으로의 열 출입은 무시). 끝 온도는?

풀이

  1. 물이 0 °C까지 내놓는 열: \(200\times4.18\times30 = 25.1\) kJ. 얼음을 모두 녹이는 열: \(50\times333 = 16.7\) kJ. 충분하므로 모두 녹는다.
    먼저 비교.
  2. 끝 온도 \(T\): \(200\times4.18(30 - T) = 16\,650 + 50\times4.18\,T\).
    녹은 물도 \(T\)까지 데워짐.
  3. \(25\,080 - 836T = 16\,650 + 209T\) → \(T = 8430/1045 \approx 8.1\) °C.
    일차식.

의미

얼음 50 g이 녹는 데 드는 열(16.7 kJ)은 같은 물 50 g을 40 K 데우는 열과 맞먹습니다. 그래서 같은 질량의 0 °C 찬물보다 얼음이 음료를 훨씬 많이 식힙니다. 끝 온도가 0 °C보다 낮게 나오면 가정(모두 녹음)이 틀린 것이므로 처음 비교가 중요합니다.

검산

잃은 열 \(200\times4.18\times21.9 = 18.3\) kJ, 얻은 열 \(16.65 + 50\times4.18\times8.1 = 18.3\) kJ로 같습니다.
