오차가 다른 점들의 가중 직선 맞춤

최소제곱 · 가중치 · 기울기 불확도 · 문제 해결 전략

출발점

점마다 불확도 \(\sigma_i\)가 다르면 가중치 \(w_i = 1/\sigma_i^2\)를 주어 \(\chi^2 = \sum w_i(y_i - a - bx_i)^2\)을 최소로 한다. 정확한 점일수록 직선을 더 세게 끌어당긴다.

문제 해결 전략 · 가중 최소제곱
  1. 가중치 \(w_i = 1/\sigma_i^2\)를 구한다.
  2. \(S = \sum w\), \(S_x = \sum wx\), \(S_y = \sum wy\), \(S_{xx} = \sum wx^2\), \(S_{xy} = \sum wxy\), \(\Delta = SS_{xx} - S_x^2\).
  3. \(b = (SS_{xy} - S_xS_y)/\Delta\), \(a = (S_{xx}S_y - S_xS_{xy})/\Delta\), \(\sigma_b = \sqrt{S/\Delta}\).
  4. 잔차와 \(\chi^2\)로 점검한다.

세 점 \((1, 2.1 \pm 0.1)\), \((2, 3.9 \pm 0.1)\), \((3, 6.3 \pm 0.3)\)에 직선을 가중 맞춤하여라.

풀이

  1. \(w = 100, 100, 11.1\). \(S = 211.1\), \(S_x = 333.3\), \(S_y = 670.0\), \(S_{xx} = 600.0\), \(S_{xy} = 1200.0\).
    셋째 점은 불확도가 3배라 가중치 1/9.
  2. \(\Delta = 211.1\times600 - 333.3^2 = 15556\).
    \(a\), \(b\)에 대한 연립일차방정식을 풀 때 분모에 나오는 값(행렬식)이다.
  3. \(b = (211.1\times1200.0 - 333.3\times670.0)/15556 = 1.93\), \(a = (600.0\times670.0 - 333.3\times1200.0)/15556 = 0.13\).
    기울기와 절편.
  4. \(\sigma_b = \sqrt{211.1/15556} = 0.12\). 결과 \(b = 1.93 \pm 0.12\).
    불확도.

의미

가중치 없이 맞추면 부정확한 셋째 점이 기울기를 2.10으로 끌어올린다. 가중 맞춤은 정확한 두 점을 주로 따릅니다(두 점만의 기울기는 1.8).

검산

\(x = 3\)에서 직선 값 \(0.13 + 5.79 = 5.92\), 셋째 점 6.3과의 차 0.38은 그 점 불확도(0.3)의 1.3배로 받아들일 만하다.
