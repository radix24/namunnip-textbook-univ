밀리컨 기름방울 실험

본문

전하가 연속적인 양이 아니라 어떤 기본 단위의 정수배라는 것을 어떻게 직접 보일 수 있을까? 밀리컨은 지름이 1 μm쯤인 기름방울 하나하나의 전하를 재었다. 너무 작아 무게도 잴 수 없는 방울의 전하를 어떻게 알아냈을까?

먼저 알아야 할 것공기 저항과 종단 속도(물리1 2.2절), 평행판 사이 전기장(공통4 4.1절)을 쓴다.

3.1.1떨어지는 방울

반지름 a, 밀도 ρ인 기름방울이 점성 계수 η인 공기 속에서 떨어지면, 금방 무게와 끌림힘이 같아져 일정한 종단 속도 \(v_f\)로 움직인다. 느리게 움직이는 작은 공이 받는 끌림힘은 스토크스 법칙 \(F = 6\pi\eta av\)이다. 부력은 공기 밀도 \(\rho_a\)를 빼서 넣으면 된다. 그러면 힘의 균형에서 방울의 반지름을 얻는다.

\[\frac43\pi a^3(\rho - \rho_a)g = 6\pi\eta av_f \quad\Rightarrow\quad a = \sqrt{\frac{9\eta v_f}{2(\rho - \rho_a)g}}\]

처음 질문의 첫 단계가 이것이다. 방울의 크기를 현미경으로 직접 재는 대신, 떨어지는 속력에서 반지름을 구한다.

3.1.2전기장 속에서

간격 d인 평행판에 전압 V를 걸어 위쪽으로 전기장 E = V/d를 만들면, 전하 q인 방울은 새 종단 속도 \(v_r\)로 올라간다. 여기서 \(v_r\)은 위쪽을 양으로 잡는다. 이때 전기력은 무게와, 아래로 향하는 끌림을 합한 것과 같다(그림 1).

\[qE = \frac43\pi a^3(\rho - \rho_a)g + 6\pi\eta av_r = 6\pi\eta a(v_f + v_r)\]
식 3.1.1 \[q = \frac{6\pi\eta ad}V(v_f + v_r), \qquad a = \sqrt{\frac{9\eta v_f}{2(\rho - \rho_a)g}}\]

그러므로 처음 질문의 답은 두 속력이다. 전기장을 끄고 떨어지는 속력과 켜고 올라가는 속력만 재면, 방울의 반지름과 전하가 모두 나온다. 또 같은 방울을 여러 번 오르내리게 하는 동안 방사선이나 공기의 이온화로 방울의 전하가 바뀌면, \(v_r\)이 띄엄띄엄 바뀐다. 이 변화량도 기본 전하의 정수배이므로, 한 방울만으로도 양자화를 볼 수 있다. 밀리컨이 1909~1913년에 쓴 방법이 이것이다.

다만 방울이 작으면 스토크스 법칙이 맞지 않아 보정이 필요하며, 이것은 3.2절에서 다룬다. 여러 방울의 전하에서 기본 전하를 찾는 방법은 3.3절에서 다룬다.

흔한 오해방울이 계속 가속하며 떨어진다고 생각하기 쉽지만, 아주 짧은 시간 안에 종단 속도에 이르므로 일정한 속력으로 보고 시간을 잰다. 또 올라가는 경우의 끌림은 아래쪽을 향하므로 전기력은 무게와 끌림의 합과 같다. 그리고 부력을 빼지 않으면 반지름과 전하가 함께 조금씩 틀린다.
마무리

기름방울이 떨어지는 종단 속도에서 스토크스 법칙으로 반지름 \(a = \sqrt{9\eta v_f/2\Delta\rho g}\)를 구한다. 전기장을 켜 올라가는 속도까지 재면 식 3.1.1의 \(q = 6\pi\eta ad(v_f + v_r)/V\)로 전하를 얻는다. 처음 질문처럼 두 속력만으로 보이지도 않는 방울의 전하를 알아내며, 작은 방울의 커닝엄 보정은 3.2절에서 다룬다.

3.1.3연습문제

기본

  1. 전압을 조절해 방울을 공중에 멈추게 했다면 전하를 구하는 식은?
    답

    정지하면 \(qV/d = \frac43\pi a^3\Delta\rho g\), \(q = \frac{4\pi a^3\Delta\rho gd}{3V}\). 반지름은 전기장을 끄고 \(v_f\)로 구합니다.

  2. \(q \propto v_f^{1/2}(v_f + v_r)\)에서 \(v_f\)의 상대 불확도가 3%, \(v_r\)이 3%일 때 \(q\)의 상대 불확도를 어림하세요(\(v_f \approx v_r\)).
    답

    \(\ln q = \frac12\ln v_f + \ln(v_f + v_r)\)이므로 \(\frac{\partial\ln q}{\partial\ln v_f} = \frac12 + \frac{v_f}{v_f + v_r} = 1\), \(\frac{\partial\ln q}{\partial\ln v_r} = \frac{v_r}{v_f + v_r} = \frac12\). \(\delta q/q = \sqrt{(1\times0.03)^2 + (0.5\times0.03)^2} \approx 3.4\%\).
