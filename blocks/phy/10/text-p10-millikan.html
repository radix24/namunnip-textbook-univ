밀리컨 기름방울 실험

본문
이 절에서 배울 것
  • 스토크스 법칙과 종단 속도로 기름방울의 반지름을 구한다.
  • 전기장을 켰을 때의 속도로 방울의 전하를 계산한다.
  • 작은 방울에서 필요한 커닝엄 보정을 안다.
먼저 알아야 할 것
  • 공기 저항과 종단 속도 (물리1 2.2절), 평행판 사이 전기장 (공통4 4.1절).

3.1.1떨어지는 방울

반지름 \(a\), 밀도 \(\rho\)인 기름방울이 점성 계수 \(\eta\)인 공기 속에서 떨어지면, 금방 무게와 끌림힘이 같아져 종단 속도 \(v_f\)로 움직입니다. 느린 작은 공의 끌림힘은 스토크스 법칙 \(F = 6\pi\eta av\)입니다(부력은 공기 밀도 \(\rho_a\)를 빼서 넣음).

\[\frac43\pi a^3(\rho - \rho_a)g = 6\pi\eta av_f \;\Rightarrow\; a = \sqrt{\frac{9\eta v_f}{2(\rho - \rho_a)g}}.\]

3.1.2전기장 속에서

간격 \(d\)인 평행판에 전압 \(V\)를 걸어 위로 \(E = V/d\)를 만들면, 전하 \(q\)인 방울은 새 종단 속도 \(v_r\)로 올라갑니다(\(v_r\)은 위로 양).

\[qE = \frac43\pi a^3(\rho - \rho_a)g + 6\pi\eta av_r = 6\pi\eta a(v_f + v_r).\]
식 3.1.1 \[q = \frac{6\pi\eta a d}{V}(v_f + v_r), \qquad a = \sqrt{\frac{9\eta v_f}{2(\rho - \rho_a)g}}.\]

같은 방울을 여러 번 오르내리게 하면, 방사선이나 이온화로 전하가 바뀔 때 \(v_r\)이 띄엄띄엄 바뀝니다. 이 변화량도 기본 전하의 정수배입니다. 밀리컨이 1909~1913년에 쓴 방법입니다.

3.1.3커닝엄 보정

방울 반지름이 공기 분자의 평균 자유 거리(상온 1기압에서 약 0.07 μm)에 가까우면 공기를 연속체로 볼 수 없어 끌림이 줄어듭니다. 점성 계수를 다음으로 바꿉니다.

\[\eta_{\text{eff}} = \frac{\eta}{1 + \frac{b}{pa}},\]

\(b\)는 실험으로 정한 상수(공기에서 약 \(8.2\times10^{-3}\) Pa·m, 확인 필요), \(p\)는 기압입니다. 반지름 1 μm에서 보정은 약 8%로, 무시하면 \(e\)가 크게 나옵니다.

예제 3.1.2

\(\rho - \rho_a = 875\ \text{kg/m}^3\), \(\eta = 1.83\times10^{-5}\) Pa·s, \(d = 6.0\) mm. 방울이 0.50 mm를 떨어지는 데 15.0 s, \(V = 500\) V에서 같은 거리를 올라가는 데 10.0 s 걸렸습니다. 반지름과 전하는(커닝엄 보정 없이)?

풀이. \(v_f = 3.33\times10^{-5}\) m/s, \(v_r = 5.00\times10^{-5}\) m/s. \(a = \sqrt{\frac{9(1.83\times10^{-5})(3.33\times10^{-5})}{2(875)(9.81)}} \approx 5.6\times10^{-7}\) m. \(q = \frac{6\pi(1.83\times10^{-5})(5.6\times10^{-7})(6.0\times10^{-3})}{500}(8.33\times10^{-5}) \approx 1.9\times10^{-19}\) C. 기본 전하 하나와 비슷하지만 20% 정도 큽니다. 이 크기(\(a \approx 0.56\) μm)에서는 커닝엄 보정이 15% 가까이 되어(\(b/pa \approx 0.14\)), 보정하면 \(e\)에 가까워집니다.

요약
  1. 떨어지는 종단 속도에서 반지름 \(a = \sqrt{9\eta v_f/2\Delta\rho g}\).
  2. \(q = \frac{6\pi\eta ad}{V}(v_f + v_r)\).
  3. 작은 방울은 커닝엄 보정으로 점성 계수를 줄인다.

3.1.4연습문제

기본

  1. 전압을 조절해 방울을 공중에 멈추게 했다면 전하를 구하는 식은?
    답

    정지하면 \(qV/d = \frac43\pi a^3\Delta\rho g\), \(q = \frac{4\pi a^3\Delta\rho gd}{3V}\). 반지름은 전기장을 끄고 \(v_f\)로 구합니다.

  2. \(q \propto v_f^{1/2}(v_f + v_r)\)에서 \(v_f\)의 상대 불확도가 3%, \(v_r\)이 3%일 때 \(q\)의 상대 불확도를 어림하세요(\(v_f \approx v_r\)).
    답

    \(\ln q = \frac12\ln v_f + \ln(v_f + v_r)\)이므로 \(\frac{\partial\ln q}{\partial\ln v_f} = \frac12 + \frac{v_f}{v_f + v_r} = 1\), \(\frac{\partial\ln q}{\partial\ln v_r} = \frac{v_r}{v_f + v_r} = \frac12\). \(\delta q/q = \sqrt{(1\times0.03)^2 + (0.5\times0.03)^2} \approx 3.4\%\).
