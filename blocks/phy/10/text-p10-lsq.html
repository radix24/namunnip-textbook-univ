가중 최소제곱 직선 맞춤

본문
이 절에서 배울 것
  • 측정점마다 불확도가 다를 때 가중 최소제곱으로 직선을 맞추고, 기울기와 절편의 불확도를 구한다.
  • \(\chi^2\)으로 맞춤의 질을 판단한다.
  • 비선형 관계를 직선으로 바꾸는 방법과 그때 불확도를 다루는 법을 안다.
먼저 알아야 할 것
  • 측정 불확도와 전파 (물리2 1.2절), 곡선 맞춤과 공분산 (물리17 2.1절).

1.1.1가중 최소제곱

측정점 \((x_i, y_i)\)에서 \(y_i\)의 불확도가 \(\sigma_i\)이고 \(x_i\)는 정확하다고 하면, \(y = a + bx\)의 최적 매개변수는 \(\chi^2 = \sum_i\left(\frac{y_i - a - bx_i}{\sigma_i}\right)^2\)을 최소로 합니다. 무게 \(w_i = 1/\sigma_i^2\)을 써서

정리 1.1.1 \[S = \sum w_i,\ S_x = \sum w_ix_i,\ S_y = \sum w_iy_i,\ S_{xx} = \sum w_ix_i^2,\ S_{xy} = \sum w_ix_iy_i,\ \Delta = SS_{xx} - S_x^2,\] \[b = \frac{SS_{xy} - S_xS_y}{\Delta}, \quad a = \frac{S_{xx}S_y - S_xS_{xy}}{\Delta}, \quad \sigma_b = \sqrt{\frac S\Delta}, \quad \sigma_a = \sqrt{\frac{S_{xx}}\Delta}, \quad \mathrm{cov}(a, b) = -\frac{S_x}\Delta.\]

모든 \(\sigma_i\)가 같으면 보통의 최소제곱과 같습니다. 불확도가 작은 점이 더 큰 목소리를 냅니다. 절편과 기울기는 대개 음의 상관이 있으므로, 둘을 함께 쓰는 계산(예: \(y = 0\)이 되는 \(x\))에서는 공분산을 넣어야 합니다.

1.1.2맞춤의 질

자유도 \(\nu = N - 2\)일 때 모형이 맞고 \(\sigma_i\)가 옳으면 \(\chi^2 \approx \nu\)입니다.

  • \(\chi^2/\nu \gg 1\): 모형이 틀렸거나 불확도를 작게 잡았다.
  • \(\chi^2/\nu \ll 1\): 불확도를 크게 잡았다.
  • 잔차 \(y_i - a - bx_i\)를 그려 보면 체계적인 굽음이나 튀는 점이 보인다. 숫자 하나보다 잔차 그림이 더 많은 것을 알려 준다.

\(\sigma_i\)를 모를 때는 모두 같다고 두고 잔차의 흩어짐으로 \(\sigma\)를 추정합니다: \(\hat\sigma^2 = \chi^2_{\sigma=1}/\nu\). 이때는 \(\chi^2\)으로 맞춤의 질을 판단할 수 없습니다.

1.1.3직선으로 바꾸기

많은 실험은 \(y = Ax^n\)이나 \(y = Ae^{-kx}\)처럼 직선이 아닌 관계를 확인합니다. 로그를 취하거나 변수를 바꿔 직선으로 만들면 기울기에서 바로 \(n\)이나 \(k\)를 얻습니다. 이때 새 변수의 불확도는 전파 공식으로 다시 구해야 합니다. 예를 들어 \(Y = \ln y\)이면 \(\sigma_Y = \sigma_y/y\)이므로, \(y\)가 작은 점일수록 불확도가 커집니다. 같은 무게로 맞추면 결과가 치우칩니다.

예제 1.1.2

e/m 실험(2장)에서 가속 전압 \(V\)와 원 반지름 \(r\)을 쟀습니다. \(e/m = 2V/(B^2r^2)\)를 직선 맞춤으로 구하려면 어떤 변수를 그리면 될까요?

풀이. 같은 \(B\)에서 \(r^2 = \frac{2}{B^2(e/m)}V\)이므로 \(x = V\), \(y = r^2\)을 그리면 원점을 지나는 직선이고 기울기 \(b = 2/(B^2\,e/m)\). \(e/m = 2/(B^2b)\). \(r\)의 불확도 \(\sigma_r\)이 같으면 \(\sigma_{r^2} = 2r\sigma_r\)라 반지름이 큰 점일수록 무게가 작아집니다. 절편이 0에서 벗어나면 접촉 전위 같은 체계 오차가 있다는 신호입니다.

요약
  1. 무게 \(1/\sigma_i^2\)의 최소제곱: \(b\), \(a\)와 \(\sigma_b = \sqrt{S/\Delta}\), \(\sigma_a = \sqrt{S_{xx}/\Delta}\).
  2. \(\chi^2/\nu \approx 1\)이면 모형과 불확도가 일관된다. 잔차 그림을 꼭 본다.
  3. 직선화할 때 새 변수의 불확도를 다시 전파한다.

1.1.4연습문제

기본

  1. \(\sigma\)가 모두 같은 세 점 \((0, 1.0)\), \((1, 2.9)\), \((2, 5.1)\)에 직선을 맞추세요.
    답

    \(\bar x = 1\), \(\bar y = 3\), \(b = \frac{\sum(x - \bar x)(y - \bar y)}{\sum(x - \bar x)^2} = \frac{(-1)(-2) + 0 + (1)(2.1)}{2} = 2.05\), \(a = 3 - 2.05 = 0.95\).

  2. 점 10개 맞춤에서 \(\chi^2 = 31\)이 나왔습니다. 무엇을 의심해야 하나요?
    답

    \(\nu = 8\), \(\chi^2/\nu \approx 3.9\). 불확도를 작게 잡았거나 직선 모형이 맞지 않습니다. 잔차 그림으로 어느 쪽인지 봅니다.

발전

  1. 원점을 지나는 직선 \(y = bx\)만 맞출 때의 \(b\)와 \(\sigma_b\)를 유도하세요.
    답

    \(\chi^2 = \sum w_i(y_i - bx_i)^2\)을 \(b\)로 미분해 0으로 두면 \(b = S_{xy}/S_{xx}\), \(\sigma_b = 1/\sqrt{S_{xx}}\).
