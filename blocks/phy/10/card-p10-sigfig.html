보고서에 결과 쓰기: 유효 숫자와 불확도

반올림 규칙 · 비교 · 문제 해결 전략

출발점

결과는 "값 ± 불확도 단위"로, 불확도는 보통 유효 숫자 1~2자리, 값은 불확도와 같은 자리까지 쓴다. 표준값과 비교할 때는 차이가 불확도의 몇 배인지 말한다.

문제 해결 전략 · 결과 보고
  1. 불확도를 유효 숫자 1자리(첫 숫자가 1이면 2자리)로 반올림한다.
  2. 값을 불확도의 마지막 자리에 맞춘다.
  3. 표준값과의 차를 불확도로 나눈다(몇 \(\sigma\)인지).
  4. 2\(\sigma\) 안이면 일치, 3\(\sigma\) 이상이면 체계적 오차를 의심한다.

계산기가 \(e/m = 1.762834\times10^{11}\) C/kg, 불확도 \(0.0438\times10^{11}\)을 보였다. 보고할 결과와 표준값 \(1.7588\times10^{11}\)과의 비교를 써라.

풀이

  1. 불확도 \(0.04\times10^{11}\)(1자리).
    0.0438 → 0.04.
  2. 값 \(1.76\times10^{11}\), 결과 \((1.76 \pm 0.04)\times10^{11}\) C/kg.
    같은 자리.
  3. 차 \(0.004\times10^{11}\), 불확도의 0.1배.
    \(|1.763 - 1.759|/0.044\).
  4. 표준값과 잘 일치한다.
    \(1\sigma\) 안.

의미

\(1.762834\)처럼 계산기 자릿수를 다 쓰면 실제보다 정밀하다는 잘못된 인상을 준다. 반대로 불확도를 쓰지 않으면 결과가 맞는지 판단할 수 없다.

검산

상대 불확도 2.5%와 맞게 세 자리 유효 숫자(1.76)이다.
