Helmholtz 코일 중심의 장과 균일도

Biot-Savart · 코일 간격 · 문제 해결 전략

출발점

반지름 \(R\)인 코일 두 개를 간격 \(R\)로 같은 축에 두면 중심 근처에서 장의 2차 도함수까지 0이 되어 아주 균일합니다. 중심 장은 \(B = \left(\frac45\right)^{3/2}\frac{\mu_0NI}R\)입니다.

문제 해결 전략 · Helmholtz 코일
  1. 코일 하나의 축 위 장 \(B_1(z) = \frac{\mu_0NIR^2}{2(R^2 + z^2)^{3/2}}\).
  2. 두 코일(\(z = \pm R/2\))의 장을 더한다.
  3. 중심과 어긋난 점에서 값을 비교해 균일도를 구한다.
  4. e/m 실험의 궤도 크기와 비교한다.

\(R = 0.15\) m, \(N = 130\), \(I = 1.5\) A인 Helmholtz 코일의 중심 장은? 중심에서 축 방향 3 cm 떨어진 곳의 장은 중심보다 몇 % 다른가?

풀이

  1. \(B_0 = 0.7155\times\frac{4\pi\times10^{-7}\times130\times1.5}{0.15} = 1.17\) mT.
    \((4/5)^{3/2} = 0.7155\).
  2. \(z = 3\) cm: 두 코일까지 거리 4.5 cm, 10.5 cm. \(B \propto (R^2 + 0.045^2)^{-3/2} + (R^2 + 0.105^2)^{-3/2}\).
    코일 위치 ±7.5 cm.
  3. \(R^2 = 0.0225\): \((0.024525)^{-1.5} + (0.033525)^{-1.5} = 260.4 + 162.9 = 423.3\). 중심 \(2\times(0.028125)^{-1.5} = 424.0\).
    비율.
  4. 차이 약 0.2%.
    \(z^4\) 항만 남아 아주 균일.

의미

e/m 실험의 전자 궤도(반지름 수 cm)가 지나는 영역에서 장이 0.2% 안으로 균일하므로, 장의 불균일은 결과에 작은 오차만 줍니다. 코일 간격이 \(R\)에서 벗어나면 균일도가 급히 나빠집니다.

검산

\(\mu_0NI/R = 1.634\) mT에 0.7155를 곱해 1.17 mT. 지구 자기장(0.05 mT)의 약 23배라 지구 장 보정이 필요합니다.
