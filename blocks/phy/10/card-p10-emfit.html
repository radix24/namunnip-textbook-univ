네 점의 r²-V 직선으로 e/m 구하기

직선 맞춤 · 원점 통과 · 기울기

출발점

같은 \(B\)에서 \(r^2 = \frac{2}{B^2(e/m)}V\)이므로 \(V\)-\(r^2\)가 원점을 지나는 직선이고, 기울기 \(b\)에서 \(e/m = 2/(B^2b)\)입니다(2.2절, 1.2절).

문제 해결 전략 · 원점을 지나는 직선의 기울기
  1. 각 점의 \(r^2\)를 구한다.
  2. 원점을 지나는 맞춤의 기울기 \(b = \sum Vr^2/\sum V^2\)를 구한다.
  3. \(e/m\)을 구하고 기준값과 비교한다.

\(B = 1.17\) mT에서 \(V\) = 150, 200, 250, 300 V일 때 반지름 \(r\) = 3.53, 4.08, 4.56, 4.99 cm를 얻었다. \(e/m\)은?

풀이

  1. \(r^2\)(\(10^{-3}\) m²) = 1.246, 1.665, 2.079, 2.490.
    단위를 m로.
  2. \(\sum Vr^2 = 0.1869 + 0.3329 + 0.5198 + 0.7470 = 1.7867\) V·m², \(\sum V^2 = 215\,000\) V². \(b = 1.7867/215\,000 = 8.31\times10^{-6}\) m²/V.
    \(b = \sum Vr^2/\sum V^2\).
  3. \(e/m = 2/(B^2b) = 2/(1.369\times10^{-6}\times8.31\times10^{-6}) = 1.76\times10^{11}\) C/kg.
    기준값과 비교.

의미

맞춤값이 기준값 \(1.759\times10^{11}\) C/kg와 잘 맞다. 한 점만 쓰면 반지름 읽기 오차가 그대로 들어가지만, 네 점을 맞추면 그 오차가 평균되어 줄어든다. 맞춤값이 기준값에서 벗어나면 절편을 자유롭게 둔 맞춤을 함께 해 보아 원점을 지나지 않는지(접촉 전위), 또는 지구 자기장이 코일 장을 바꾸고 있는지 확인한다.

검산

각 점에서 따로 계산한 \(2V/(B^2r^2)\)도 모두 \(1.75\)~\(1.76\times10^{11}\) C/kg로 맞춤값과 같다.
