비선형 관계를 직선으로 바꾸기

본문
이 절에서 배울 것
  • 거듭제곱·지수 관계를 변수 변환으로 직선으로 만들고 기울기에서 매개변수를 얻는다.
  • 변환한 변수의 불확도를 다시 전파하고, 그에 맞는 무게로 맞춘다.
먼저 알아야 할 것
  • 가중 최소제곱 (1.1절), 불확도 전파 (물리2 1.3절).

1.2.1변수 바꾸기

많은 실험은 \(y = Ax^n\)이나 \(y = Ae^{-kx}\)처럼 직선이 아닌 관계를 확인합니다. 로그를 취하거나 변수를 바꿔 직선으로 만들면 기울기에서 바로 \(n\)이나 \(k\)를 얻습니다.

  • \(y = Ax^n\): \(\ln y = \ln A + n\ln x\). \(\ln x\)-\(\ln y\)의 기울기가 \(n\).
  • \(y = Ae^{-kx}\): \(\ln y = \ln A - kx\). \(x\)-\(\ln y\)의 기울기가 \(-k\).
  • 이론 식이 알려져 있으면 그 꼴에 맞춰 \(x\), \(y\)를 고른다. 예: 진자 \(T^2 = (4\pi^2/g)L\)는 \(L\)-\(T^2\)가 원점을 지나는 직선.

1.2.2새 변수의 불확도

새 변수의 불확도는 전파 공식으로 다시 구해야 합니다. 예를 들어 \(Y = \ln y\)이면 \(\sigma_Y = \sigma_y/y\)이므로, \(y\)가 작은 점일수록 불확도가 커집니다. 같은 무게로 맞추면 결과가 치우치므로 무게 \(1/\sigma_Y^2\)으로 가중 맞춤(1.1절)을 합니다.

예제 1.2.1

e/m 실험(2장)에서 가속 전압 \(V\)와 원 반지름 \(r\)을 쟀습니다. \(e/m = 2V/(B^2r^2)\)를 직선 맞춤으로 구하려면 어떤 변수를 그리면 될까요?

풀이. 같은 \(B\)에서 \(r^2 = \frac{2}{B^2(e/m)}V\)이므로 \(x = V\), \(y = r^2\)을 그리면 원점을 지나는 직선이고 기울기 \(b = 2/(B^2\,e/m)\). \(e/m = 2/(B^2b)\). \(r\)의 불확도 \(\sigma_r\)이 같으면 \(\sigma_{r^2} = 2r\sigma_r\)라 반지름이 큰 점일수록 무게가 작아집니다. 절편이 0에서 벗어나면 접촉 전위 같은 체계 오차가 있다는 신호입니다.

요약
  1. 거듭제곱은 로그-로그, 지수는 반로그로 직선.
  2. 새 변수의 불확도를 다시 전파(\(\sigma_{\ln y} = \sigma_y/y\))하고 그 무게로 맞춘다.

1.2.3연습문제

기본

  1. \(y = Ax^{3/2}\)를 확인하려면 무엇을 그리고, 기울기는?
    답

    \(\ln x\)-\(\ln y\), 기울기 1.5. 또는 \(x^{3/2}\)-\(y\)가 원점을 지나는 직선.

  2. \(y = 2.00 \pm 0.05\)이면 \(\ln y\)의 불확도는?
    답

    \(0.05/2.00 = 0.025\).
