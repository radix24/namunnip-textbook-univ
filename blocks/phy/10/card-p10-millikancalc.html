기름방울 하나의 전하 구하기

종단 속도 · Stokes 법칙 · 문제 해결 전략

출발점

장이 없을 때 떨어지는 종단 속도 \(v_1\)에서 방울 반지름을 구하고(Stokes 저항 \(6\pi\eta rv\) = 무게), 장을 걸어 올라가는 속도 \(v_2\)에서 전하를 구합니다.

문제 해결 전략 · Millikan 계산
  1. 낙하: \(\frac43\pi r^3\rho g = 6\pi\eta rv_1\) → \(r = \sqrt{\frac{9\eta v_1}{2\rho g}}\).
  2. 상승: \(qE = mg + 6\pi\eta rv_2\) → \(q = \frac{6\pi\eta r(v_1 + v_2)}E\).
  3. \(e\)의 배수인지 확인한다.
  4. 작은 방울은 Cunningham 보정을 생각한다.

기름 밀도 886 kg/m³, 공기 점성 \(1.81\times10^{-5}\) Pa·s. 방울이 장 없이 0.10 mm/s로 떨어지고, 판 간격 5 mm에 500 V를 걸면 0.12 mm/s로 올라간다. 전하는?

풀이

  1. \(r = \sqrt{\frac{9\times1.81\times10^{-5}\times10^{-4}}{2\times886\times9.8}} = 0.97\ \mu\)m.
    Stokes 법칙.
  2. \(E = 500/0.005 = 10^5\) V/m.
    균일한 장.
  3. \(q = \frac{6\pi\times1.81\times10^{-5}\times0.97\times10^{-6}\times2.2\times10^{-4}}{10^5} = 7.3\times10^{-19}\) C.
    \(v_1 + v_2 = 0.22\) mm/s.
  4. \(q/e = 4.5\). 4나 5에 딱 맞지 않아 보정(공기 부력, Cunningham)과 측정 불확도를 따져야 한다.
    정직한 해석.

의미

한 방울만으로는 양자화를 판단하기 어렵습니다. 많은 방울의 전하를 모아 공통 약수를 찾아야 하고(3.3절), 이 예처럼 정수에서 벗어나면 보정과 오차를 검토합니다.

검산

무게 \(\frac43\pi r^3\rho g = 3.3\times10^{-14}\) N과 저항 \(6\pi\eta rv_1 = 3.3\times10^{-14}\) N이 같습니다.
