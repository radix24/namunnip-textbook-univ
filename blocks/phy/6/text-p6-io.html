저수준 코드로 입출력 제어하기

본문

마이크로컨트롤러 프로그램에서 LED를 켜는 한 줄은 칩의 핀 하나를 5 V로 올리는 일이다. 소프트웨어의 명령이 어떻게 하드웨어 핀의 전압이 될까? 그리고 같은 포트에 이어진 다른 핀들을 건드리지 않고 핀 하나만 바꾸려면 어떻게 해야 할까?

먼저 알아야 할 것마이크로프로세서 구조(5.1절)와 C 언어(공통10 4.1절)를 쓴다.

5.2.1포트 레지스터

마이크로컨트롤러의 핀은 특정 메모리 주소의 레지스터 비트와 이어져 있다. 그래서 그 주소에 값을 쓰면 핀의 전압이 바뀌며, 이것을 메모리 사상 입출력이라 한다. 처음 질문의 답이 이것이다. 예를 들어 AVR 계열에서는 방향 레지스터 DDRx의 비트를 1로 하면 그 핀이 출력이 되고, 출력 레지스터 PORTx의 비트로 High와 Low를 정하며, 입력은 PINx 레지스터에서 읽는다. 이름은 칩마다 다르므로 사양서로 확인한다.

/* C로 쓴 저수준 제어 (AVR 예시) */
DDRB  |=  (1 << 5);      /* B포트 5번 핀을 출력으로 */
PORTB |=  (1 << 5);      /* 5번 핀 High: LED 켜기 */
PORTB &= ~(1 << 5);      /* 5번 핀 Low: LED 끄기 */
if (PINB & (1 << 0)) {   /* 0번 핀 입력이 High이면 */
    /* ... */
}

여기서는 비트 연산이 중요하다. |=(OR)는 특정 비트만 1로, &= ~(AND NOT)는 특정 비트만 0으로, ^=(XOR)는 특정 비트만 뒤집으며, &는 특정 비트를 검사한다. 그림 1처럼 OR 상대가 0인 비트는 원래 값을 지키고, AND 상대가 1인 비트도 원래 값을 지킨다. 그러므로 이 연산들은 같은 포트의 다른 핀을 건드리지 않으며, 처음 질문의 둘째 물음에 대한 답이 된다.

예제 5.2.1

PORTB가 0b0100 1001일 때 PORTB &= ~(1 << 3);을 실행하면 결과는? PORTB = (1 << 3);과는 어떻게 다른가?

풀이. \(\sim(1 \ll 3)\)은 0b1111 0111이고, 0b0100 1001과 AND 하면 0b0100 0001이 된다. 3번 비트만 0이 되고 6번과 0번은 그대로이다. 반면 대입 =를 쓰면 PORTB가 통째로 0b0000 1000이 되어, 다른 핀에 이어진 LED가 모두 꺼지고 3번만 켜진다.

5.2.2기계어와 어셈블리

컴파일러는 위의 C 코드를 기계어로 바꾼다. 사람이 읽을 수 있게 기계어를 기호로 쓴 것이 어셈블리어이다. 예를 들어 비트 하나를 켜는 명령은 SBI PORTB, 5처럼 한 줄이고, 한 클록 정도에 끝난다. 이렇게 저수준으로 쓰면 실행 시간을 클록 단위로 정확히 알 수 있어, 정밀한 타이밍이 필요한 측정에서 쓴다.

흔한 오해입력으로 쓸 핀의 상태를 PORTx에서 읽으려 하기 쉽지만, PORTx는 내보내려는 값을 담은 레지스터이고 실제 핀의 전압은 PINx에서 읽는다. 또 출력 핀을 GND에 바로 이은 채 High로 두면 큰 전류가 흘러 핀이 망가질 수 있으므로, 버튼은 입력 핀에 저항과 함께 잇는다.
마무리

마이크로컨트롤러의 핀은 메모리 주소에 놓인 포트 레지스터의 비트와 이어져 있어, 처음 질문처럼 소프트웨어가 그 비트를 쓰면 핀의 전압이 바뀐다. 방향, 출력, 입력 레지스터를 |=, &= ~, ^=, &의 비트 연산으로 다루면 다른 핀을 건드리지 않는다. 저수준 코드는 실행 시간을 클록 단위로 알 수 있으며, 타이머와 인터럽트는 5.3절에서 다룬다.
