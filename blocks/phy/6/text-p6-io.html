5.2.1포트 레지스터

마이크로컨트롤러의 핀은 특정 메모리 주소의 레지스터 비트와 연결되어 있습니다(메모리 사상 입출력). 예를 들어 AVR 계열에서는 방향 레지스터(DDRx)의 비트를 1로 하면 그 핀이 출력이 되고, 출력 레지스터(PORTx)의 비트로 High/Low를 정하며, 입력은 PINx 레지스터에서 읽습니다(이름은 칩마다 다르므로 사양서 확인 필요).

/* C로 쓴 저수준 제어 (AVR 예시) */
DDRB  |=  (1 << 5);      /* B포트 5번 핀을 출력으로 */
PORTB |=  (1 << 5);      /* 5번 핀 High: LED 켜기 */
PORTB &= ~(1 << 5);      /* 5번 핀 Low: LED 끄기 */
if (PINB & (1 << 0)) {   /* 0번 핀 입력이 High이면 */
    /* ... */
}

비트 연산이 핵심입니다. |=(OR)로 특정 비트만 1, &= ~(AND NOT)로 특정 비트만 0, ^=(XOR)로 특정 비트만 뒤집고, &로 특정 비트를 검사합니다. 다른 비트를 건드리지 않는다는 점이 중요합니다.

5.2.2기계어와 어셈블리

컴파일러는 위 C 코드를 기계어로 바꿉니다. 사람이 읽을 수 있게 기계어를 기호로 쓴 것이 어셈블리어입니다. 예를 들어 비트 하나를 켜는 명령은 SBI PORTB, 5처럼 한 줄(한 클록 정도)입니다. 저수준으로 쓰면 실행 시간을 클록 단위로 정확히 알 수 있어, 정밀한 타이밍이 필요한 측정에서 씁니다.

5.2.3타이머와 인터럽트

  • 바쁜 대기: 반복문으로 시간을 끄는 방법. 간단하지만 그동안 다른 일을 못 하고 시간이 부정확하다.
  • 타이머: 클록을 세는 하드웨어 카운터(2.2절). 정해진 값에 이르면 표시를 세우거나 핀을 뒤집는다. PWM 출력도 타이머로 만든다.
  • 인터럽트: 타이머가 넘치거나 핀 입력이 바뀌는 사건이 생기면, 하던 일을 잠시 멈추고 정해진 함수(인터럽트 서비스 루틴)를 실행한 뒤 돌아온다. 정확한 간격의 표본화(5.3절)에 쓴다.
예제 5.2.1

16 MHz 클록을 64로 나눈 타이머가 0부터 셀 때, 1 ms마다 인터럽트를 받으려면 비교값을 얼마로 하는가?

풀이. 타이머는 \(16\ \text{MHz}/64 = 250\) kHz로 셉니다. 1 ms는 250번이므로 0~249를 세고 되돌리도록 비교값 249를 넣습니다.

요약
  1. 포트 레지스터의 비트로 핀 방향, 출력, 입력을 다룬다. |=, &= ~, &.
  2. 정확한 시간은 타이머와 인터럽트로.
