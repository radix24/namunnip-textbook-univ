명령 하나가 실행되는 시간

명령 주기 · 클록 · 문제 해결 전략

출발점

CPU는 명령을 가져오기(fetch), 해독하기(decode), 실행하기(execute)의 주기로 처리한다. 명령마다 필요한 클록 수가 다르므로, 프로그램 실행 시간은 (명령 수 × 평균 클록 수) / 클록 진동수이다.

문제 해결 전략 · 실행 시간 어림
  1. 명령 종류별 개수와 클록 수를 정리한다.
  2. 전체 클록 수를 더한다.
  3. 클록 진동수로 나눠 시간을 구한다.
  4. 반복문은 반복 횟수를 곱한다.

16 MHz 마이크로컨트롤러에서 한 번 돌 때 1클록 명령 5개와 2클록 명령 3개(분기 포함)를 쓰는 반복문을 1000번 돈다. 걸리는 시간은? 이 반복문으로 1 ms 지연을 만들려면 몇 번 돌아야 하나?

풀이

  1. 한 바퀴 클록 수 \(5\times1 + 3\times2 = 11\).
    명령별 합.
  2. 1000번: 11000클록.
    반복.
  3. 시간 \(11000/(16\times10^6) = 0.6875\) ms.
    한 클록 62.5 ns.
  4. 1 ms는 16000클록, \(16000/11 \approx 1455\)번.
    소프트웨어 지연.

의미

소프트웨어 지연은 클록과 명령에 따라 달라져 정확하지 않다. 정밀한 시간이 필요하면 하드웨어 타이머(카운터, 2.3절)를 쓴다.

검산

1455 × 11 = 16005클록 = 1.0003 ms. 맞다.
