부울 대수와 논리 회로 간소화

본문
이 절에서 배울 것
  • 기본 논리 게이트와 진리표, 부울 대수의 법칙을 쓴다.
  • 진리표에서 논리식을 만들고 카르노 맵으로 간단히 한다.
먼저 알아야 할 것
  • 2진수 (공통10 6.1절), 트랜지스터 스위치 (물리2 5.1절).

1.1.1논리 게이트

디지털 회로는 전압을 두 상태(High = 1, Low = 0)로만 다룹니다. 5 V TTL 논리에서는 대략 2 V 이상이 1, 0.8 V 이하가 0입니다(계열마다 다름). 잡음이 조금 섞여도 판정이 바뀌지 않는다는 것이 디지털의 장점입니다.

게이트식1이 되는 경우
NOT\(\bar A\)\(A = 0\)
AND\(AB\)둘 다 1
OR\(A + B\)하나라도 1
NAND\(\overline{AB}\)둘 다 1이 아닐 때
NOR\(\overline{A + B}\)둘 다 0
XOR\(A \oplus B\)서로 다를 때

NAND(또는 NOR) 하나만으로 모든 논리 함수를 만들 수 있어 만능 게이트라 부릅니다. 예를 들어 NOT은 NAND의 두 입력을 묶은 것입니다.

1.1.2부울 대수

  • \(A + 0 = A\), \(A\cdot1 = A\), \(A + 1 = 1\), \(A\cdot0 = 0\), \(A + A = A\), \(A + \bar A = 1\), \(A\bar A = 0\).
  • 분배: \(A(B + C) = AB + AC\), \(A + BC = (A + B)(A + C)\).
  • 흡수: \(A + AB = A\), \(A + \bar AB = A + B\).
  • 드모르간: \(\overline{AB} = \bar A + \bar B\), \(\overline{A + B} = \bar A\bar B\).

1.1.3진리표에서 식으로, 카르노 맵

출력이 1인 행마다 입력의 곱(최소항)을 만들어 더하면 곱의 합 꼴의 식이 됩니다. 이 식을 간단히 하는 그림 방법이 카르노 맵입니다. 이웃한 칸이 입력 하나만 다르도록(그레이 코드 순서) 진리표를 표로 배치하고, 1이 있는 이웃 칸을 2, 4, 8개씩 가장 크게 묶으면 묶음마다 변하는 변수가 지워집니다.

예제 1.1.1

세 입력 중 두 개 이상이 1이면 1을 내는 다수결 회로의 식을 구하여라.

풀이. 최소항: \(\bar ABC + A\bar BC + AB\bar C + ABC\). 카르노 맵에서 \(ABC\)를 세 번 겹쳐 묶으면 \(F = AB + BC + CA\). AND 게이트 셋과 OR 게이트 하나로 만듭니다. 아래 실습 카드에서 식을 넣어 진리표와 카르노 맵을 확인할 수 있습니다.

요약
  1. NOT, AND, OR, NAND, NOR, XOR. NAND만으로 모든 함수.
  2. 드모르간 \(\overline{AB} = \bar A + \bar B\).
  3. 진리표 → 최소항의 합 → 카르노 맵으로 간소화.

1.1.4연습문제

기본

    답
