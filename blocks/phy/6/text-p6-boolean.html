부울 대수와 논리 회로 간소화

본문

실험실 서랍에 NAND 게이트 IC만 잔뜩 있고 AND, OR, NOT은 하나도 없다. 그래도 원하는 논리 회로를 모두 만들 수 있을까? 그리고 복잡한 논리식을 게이트 수가 적은 식으로 줄이는 규칙은 무엇일까?

먼저 알아야 할 것2진수(공통10 6.1절)와 트랜지스터 스위치(물리2 5.1절)를 쓴다.

1.1.1논리 게이트

디지털 회로는 전압을 High(1)와 Low(0) 두 상태로만 다룬다. 5 V TTL 논리에서는 대략 2 V 이상이 1, 0.8 V 이하가 0이며, 정확한 값은 계열마다 다르다. 그래서 잡음이 조금 섞여도 판정이 바뀌지 않으며, 이것이 디지털의 장점이다. 이런 두 상태를 입력으로 받아 정해진 규칙으로 출력을 내는 회로를 논리 게이트라 한다.

게이트식1이 되는 경우
NOT\(\bar A\)\(A = 0\)
AND\(AB\)둘 다 1
OR\(A + B\)하나라도 1
NAND\(\overline{AB}\)둘 다 1이 아닐 때
NOR\(\overline{A + B}\)둘 다 0
XOR\(A \oplus B\)서로 다를 때

표의 게이트 가운데 NAND 하나만으로, 또는 NOR 하나만으로 모든 논리 함수를 만들 수 있어 이 둘을 만능 게이트라 부른다. 처음 질문의 답이 이것이다. 그림 1처럼 NOT은 NAND의 두 입력을 묶은 것이고, AND는 NAND 뒤에 NOT을 붙인 것이다. 또 OR는 두 입력에 각각 NOT을 붙이고 NAND에 넣은 것이며, 그 근거가 아래의 드모르간 법칙이다.

1.1.2부울 대수

논리식을 다루는 대수를 부울 대수라 한다. 먼저 0과 1에 대한 기본 법칙이 있다. \(A + 0 = A\), \(A\cdot1 = A\), \(A + 1 = 1\), \(A\cdot0 = 0\)이고, 같은 변수끼리는 \(A + A = A\), \(A + \bar A = 1\), \(A\bar A = 0\)이다. 다음으로 분배 법칙은 \(A(B + C) = AB + AC\)뿐 아니라 \(A + BC = (A + B)(A + C)\)도 성립해 보통의 대수와 다르다. 또 흡수 법칙 \(A + AB = A\), \(A + \bar AB = A + B\)는 식을 줄이는 데 자주 쓴다.

가장 중요한 것은 드모르간 법칙이다.

\[\overline{AB} = \bar A + \bar B, \qquad \overline{A + B} = \bar A\bar B\]

곧 곱의 부정은 부정의 합이고, 합의 부정은 부정의 곱이다. 그러므로 \(A + B = \overline{\bar A\bar B}\)이며, 이것이 그림 1의 OR 구성이다.

예제 1.1.1

\(F = AB + A\bar B + \bar AB\)를 간단히 하고, NAND 게이트만으로 만들어라.

풀이. 앞의 두 항을 묶으면 \(AB + A\bar B = A(B + \bar B) = A\)이다. 따라서 \(F = A + \bar AB\)이고, 흡수 법칙으로 \(F = A + B\)가 된다. 원래 식대로라면 AND 셋, OR 하나, NOT 둘이 필요했지만 이제 OR 하나이다. 이것을 NAND로 만들면 \(F = \overline{\bar A\bar B}\)이므로, 두 입력을 각각 NAND로 부정한 뒤 NAND 하나에 넣는다. NAND 세 개면 충분하며, 74HC00 IC 하나에 NAND가 넷 들어 있다.

흔한 오해\(\overline{AB}\)를 \(\bar A\bar B\)로 쓰기 쉽지만 둘은 다르다. \(A = 1\), \(B = 0\)이면 \(\overline{AB} = 1\)이지만 \(\bar A\bar B = 0\)이다. 부정 막대를 쪼갤 때는 곱과 합을 서로 바꿔야 한다. 또 부울 대수의 \(+\)는 산술 덧셈이 아니라서 \(1 + 1 = 1\)이다.
마무리

기본 게이트는 NOT, AND, OR, NAND, NOR, XOR이며, 처음 질문처럼 NAND 하나만으로도 모든 함수를 만들 수 있다. 드모르간 법칙 \(\overline{AB} = \bar A + \bar B\)와 \(\overline{A + B} = \bar A\bar B\)가 그 근거이다. 흡수 법칙 \(A + AB = A\)와 \(A + \bar AB = A + B\)로 식을 줄이면 게이트 수가 줄어든다.
