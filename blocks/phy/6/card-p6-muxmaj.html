4:1 멀티플렉서 하나로 다수결 회로 만들기

멀티플렉서 · 진리표 접기 · 문제 해결 전략

출발점

\(2^n\):1 멀티플렉서의 선택선에 변수를 넣고 데이터 입력에 0, 1, 또는 남은 변수를 묶으면 논리 함수를 만들 수 있습니다(1.4절). 다수결 함수는 \(F = AB + BC + CA\)입니다(1.2절).

문제 해결 전략 · 선택선으로 진리표 나누기
  1. 선택선에 넣을 변수 둘(\(A\), \(B\))을 정한다.
  2. \(A\), \(B\)의 네 조합마다 \(F\)를 남은 변수 \(C\)의 함수로 쓴다.
  3. 그 결과(0, 1, \(C\), \(\bar C\))를 해당 데이터 입력에 묶는다.

세 입력 \(A, B, C\) 가운데 두 개 이상이 1이면 1을 내는 다수결 회로를 4:1 멀티플렉서 하나로 만들어라.

풀이

  1. \(AB = 00\): \(F = 0\)(하나만 1이어도 부족) → \(D_0 = 0\).
    \(C\)와 무관.
  2. \(AB = 01\) 또는 \(10\): \(F = C\) → \(D_1 = D_2 = C\).
    \(C\)가 1이어야 둘.
  3. \(AB = 11\): \(F = 1\) → \(D_3 = 1\). 선택선 \(S_1 = A\), \(S_0 = B\).
    이미 둘.

의미

게이트 네 개(AND 셋, OR 하나)가 들던 회로를 칩 하나로, 배선만 바꿔 만들었습니다. FPGA 같은 프로그램 가능한 논리 소자는 작은 멀티플렉서(룩업 테이블)에 진리표를 저장하는 방식으로 아무 함수나 만듭니다.

검산

\(A = 1\), \(B = 0\), \(C = 1\)이면 \(S_1S_0 = 10\)이라 \(D_2 = C = 1\)이 출력되고, \(AB + BC + CA = 0 + 0 + 1 = 1\)과 같습니다.
