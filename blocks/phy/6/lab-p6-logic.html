진리표에서 간단한 식으로

실습 · 카르노 맵

목표

세 입력 논리 함수의 진리표를 정하고, 카르노 맵과 최소 곱의 합 식을 함께 보며 간소화가 어떻게 이루어지는지 확인합니다. 성취기준 [물리6-01-01], [물리6-01-03].

준비

m0~m7은 입력 \(ABC\)를 2진수로 읽은 행 번호입니다(m5는 A = 1, B = 0, C = 1). 체크한 행의 출력이 1입니다. 미리 정한 함수를 고르거나 직접 체크합니다. 간단한 식은 모든 주항(prime implicant) 조합을 찾아보아 가장 짧은 것을 고른 결과입니다.

절차

  1. 다수결 함수의 카르노 맵에서 1이 있는 칸을 묶어 \(AB + BC + CA\)를 직접 찾아본다.
  2. 3입력 XOR로 바꿔 카르노 맵이 체크무늬가 되고 간단해지지 않는 것을 본다.
  3. 예제 함수에서 맨 왼쪽과 오른쪽 칸이 이웃이라는 것을 이용한 묶음을 찾는다.
  4. 직접 m0, m2, m4, m6을 체크해 본다.

기대 결과

  • 다수결: \(F = AB + AC + BC\)(순서는 다를 수 있음).
  • XOR은 이웃한 1이 없어 최소항 네 개 그대로다. 그래서 XOR 게이트를 따로 쓴다.
  • m2, m3, m5, m6, m7은 \(B + AC\)로 줄어든다.
  • m0, m2, m4, m6은 \(C\)가 0인 칸 모두이므로 \(\bar C\) 하나다.

분석

  1. 칸 네 개를 묶으면 변수 두 개가, 두 개를 묶으면 하나가 지워지는 까닭을 말해 보세요.
  2. 간단한 식을 NAND 게이트만으로 바꾸는 방법을 드모르간 법칙으로 설명해 보세요.
