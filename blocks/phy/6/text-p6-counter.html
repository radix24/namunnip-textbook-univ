카운터와 시프트 레지스터

본문
이 절에서 배울 것
  • 비동기(리플) 카운터와 동기 카운터를 만들고 타이밍 도표로 동작을 확인한다.
  • 모듈로 N 카운터와 시프트 레지스터의 쓰임을 안다.
먼저 알아야 할 것
  • 플립플롭 (2.1절).

2.2.1리플 카운터

T 플립플롭(\(T = 1\))을 이어, 각 단의 출력을 다음 단의 클록으로 쓰면 출력 \(Q_0Q_1Q_2\dots\)이 2진수로 0, 1, 2, 3, ...을 셉니다(\(Q_0\)가 가장 낮은 자리). 각 단은 앞 단 진동수의 절반이므로, \(n\)단이면 \(2^n\)까지 세고 맨 끝 출력은 클록 진동수의 \(1/2^n\)입니다(분주기). 간단하지만 앞 단의 지연이 쌓여 각 비트가 조금씩 늦게 바뀌므로, 바뀌는 순간 잠깐 틀린 값(글리치)이 보일 수 있습니다.

2.2.2동기 카운터와 모듈로 N

모든 플립플롭에 같은 클록을 넣고, 각 단의 \(T\) 입력을 아래 자리가 모두 1일 때만 1로(\(T_k = Q_0Q_1\cdots Q_{k-1}\)) 하면 모든 비트가 동시에 바뀝니다(동기 카운터). 원하는 수 \(N\)에 이르면 모두 0으로 되돌리는 논리를 더하면 모듈로 N 카운터가 됩니다. 10진 카운터(0~9), 시계(60진)에 씁니다.

예제 2.2.1

10 MHz 수정 발진기로 1 Hz 신호를 만들려면 어떻게 하는가?

풀이. 10진 카운터(÷10) 7개를 이어 \(10^7\)로 나눕니다. 2진 카운터만 쓰면 \(2^{23} \approx 8.4\times10^6\), \(2^{24} \approx 1.68\times10^7\)이라 정확히 나눌 수 없어, 수정 시계는 흔히 32 768 Hz(\(2^{15}\)) 발진기를 씁니다.

2.2.3시프트 레지스터

D 플립플롭을 일렬로 이어 각 출력을 다음 입력에 넣으면, 클록마다 비트가 한 칸씩 옮겨 갑니다.

  • 직렬 → 병렬 변환: 한 줄로 들어오는 자료(직렬 통신)를 모아 여러 비트로 동시에 꺼낸다.
  • 병렬 → 직렬 변환: 반대로 여러 비트를 한 줄로 내보낸다. 74HC595로 적은 핀으로 LED 여러 개를 켜는 것이 예다.
  • 끝을 처음에 이으면 고리 카운터(한 비트가 돌아감)가 된다.

아래 실습 카드에서 카운터의 타이밍 도표를 볼 수 있습니다.

요약
  1. 리플 카운터: 단마다 ÷2, 지연이 쌓임. 동기 카운터: 같은 클록, 동시 변화.
  2. 모듈로 N: N에서 되돌림. 시프트 레지스터: 직렬↔병렬.
