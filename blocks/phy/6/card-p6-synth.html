Wi-Fi 채널을 고르는 PLL 합성기 설계

분주비 · 채널 간격 · 루프 대역폭 · 문제 해결 전략

출발점

분주기를 넣은 PLL의 출력은 \(f_{\text{out}} = \frac NRf_{\text{ref}}\)이고, 비교 진동수 \(f_{\text{ref}}/R\)가 만들 수 있는 진동수의 간격입니다. 루프 대역폭은 보통 비교 진동수의 1/10 이하로 잡습니다(3.4절).

문제 해결 전략 · 간격에서 R, 채널에서 N
  1. 필요한 채널 진동수들의 최대공약수(간격)를 비교 진동수로 정한다.
  2. \(R = f_{\text{ref}}/f_{\text{pd}}\)를 구한다.
  3. 채널마다 \(N = f_{\text{out}}/f_{\text{pd}}\)를 구하고 정수인지 확인한다.
  4. 비교 진동수로 루프 대역폭의 상한을 어림한다.

2.4 GHz 대역 Wi-Fi 채널 1(2412 MHz)과 채널 6(2437 MHz)을 10 MHz 수정 기준으로 만든다. (가) 비교 진동수를 5 MHz로 하면 두 채널을 만들 수 있는가? (나) 1 MHz로 하면 R과 각 채널의 N은? (다) 이때 루프 대역폭은 대략 얼마 이하로 잡는가?

풀이

  1. (가) \(2412/5 = 482.4\)로 정수가 아니어서 만들 수 없다.
    N은 정수여야 함.
  2. (나) \(R = 10\ \text{MHz}/1\ \text{MHz} = 10\). 채널 1: \(N = 2412\), 채널 6: \(N = 2437\).
    1 MHz는 두 진동수의 공약수.
  3. (다) \(1\ \text{MHz}/10 = 100\) kHz 이하.
    비교 진동수의 출렁임을 걸러야 함.

의미

채널 간격은 5 MHz지만 채널 진동수 자체가 5 MHz의 배수가 아니어서 더 작은 비교 진동수가 필요했습니다. 비교 진동수가 작아지면 대역폭이 좁아지고 채널을 바꾸는 시간이 길어지므로, 실제 칩은 분수 분주로 큰 비교 진동수를 유지합니다.

검산

\(N\)을 25만큼 바꾸면 출력이 25 MHz 바뀌어 채널 1과 6의 차이 \(2437 - 2412 = 25\) MHz와 맞습니다.
