위상 고정 루프(PLL)

본문
이 절에서 배울 것
  • PLL의 세 구성 요소(위상 검출기, 루프 필터, 전압 제어 발진기)의 역할을 안다.
  • 되먹임으로 출력 진동수가 입력에 고정되는 원리와 진동수 합성을 설명한다.
먼저 알아야 할 것
  • 저역 통과 필터 (물리2 3.3절), 카운터 분주기 (2.2절).

3.2.1구성

  • 전압 제어 발진기(VCO): 입력 전압에 따라 진동수가 바뀌는 발진기. \(f = f_0 + K_vV_c\).
  • 위상 검출기(PD): 입력 신호와 VCO 출력의 위상 차이에 비례하는 전압을 낸다. 간단히는 XOR 게이트로 만든다.
  • 루프 필터: 위상 검출기 출력의 빠른 출렁임을 걸러 VCO에 매끈한 제어 전압을 준다(저역 통과 필터).

3.2.2고정 원리

VCO가 입력보다 조금 빠르면 위상이 앞서 나가고, 위상 검출기가 그 차이에 해당하는 전압을 내어 VCO를 느리게 합니다. 반대도 마찬가지입니다. 이 음되먹임 때문에 결국 두 신호의 진동수가 같아지고 위상 차이가 일정한 값에 머뭅니다(고정 상태). 진동수가 같으려면 위상 차이가 일정해야 하므로, 위상을 맞추면 진동수는 저절로 맞습니다.

  • 고정 범위: 고정된 뒤 입력 진동수가 바뀌어도 따라갈 수 있는 범위.
  • 포착 범위: 처음에 고정이 안 된 상태에서 고정으로 끌어들일 수 있는 범위. 보통 고정 범위보다 좁다.
  • 루프 필터의 시간 상수가 크면 출력이 깨끗하지만 입력 변화를 늦게 따라간다.

3.2.3쓰임

VCO 출력과 위상 검출기 사이에 ÷N 카운터를 넣으면, 고정 상태에서 \(f_{\text{out}}/N = f_{\text{in}}\), 곧 \(f_{\text{out}} = Nf_{\text{in}}\)입니다. 정확한 수정 기준(예: 10 MHz)으로 N만 바꿔 여러 진동수를 만들 수 있어(진동수 합성기), 라디오 채널 선택, 컴퓨터 CPU 클록(기준 클록의 수십 배), 휴대전화에 씁니다. 또 FM 복조, 잡음 속 신호의 클록 복원에도 씁니다. 실험의 록인 증폭기도 기준 신호와의 위상 관계를 쓰는 같은 계열의 장치입니다. 아래 실습 카드에서 PLL이 고정되는 과정을 볼 수 있습니다.

예제 3.2.1

기준 1 MHz, 분주비 N = 433으로 고정된 PLL의 출력 진동수는?

풀이. 433 MHz. N을 하나씩 바꾸면 1 MHz 간격으로 채널을 고를 수 있습니다.

요약
  1. PLL = 위상 검출기 + 루프 필터 + VCO, 음되먹임으로 위상(따라서 진동수) 고정.
  2. 되먹임에 ÷N을 넣으면 \(f_{\text{out}} = Nf_{\text{in}}\) (진동수 합성).
