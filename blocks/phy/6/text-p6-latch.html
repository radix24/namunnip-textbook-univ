래치: 기억하는 회로

본문

계산기는 방금 누른 숫자를 기억하고, 컴퓨터는 수십억 개의 비트를 기억한다. 그런데 1.3절의 조합 회로는 입력이 사라지면 출력도 사라진다. 게이트만으로 1비트를 기억하는 회로를 만들 수 있을까? 그리고 스위치를 한 번 눌렀는데 카운터가 여러 번 세는 문제는 어떻게 막을까?

먼저 알아야 할 것논리 게이트(1.1절)와 조합 회로(1.3절)를 쓴다.

2.1.1SR 래치

조합 회로는 출력이 지금 입력만으로 정해지지만, 순차 회로는 과거의 상태도 기억한다. 가장 간단한 순차 회로는 그림 1처럼 NOR 게이트 두 개의 출력을 서로의 입력으로 되먹인 SR 래치이다.

\(S\)\(R\)\(Q\)뜻
00이전 값 유지기억
101설정(set)
010재설정(reset)
11\(Q = \bar Q = 0\)금지

처음 질문의 답은 되먹임에 있다. \(S = R = 0\)일 때 \(Q = 0\)이면 위 NOR의 두 입력이 0, 0이 되어 \(\bar Q = 1\)이 다시 \(Q = 0\)을 붙잡고, \(Q = 1\)이어도 마찬가지로 스스로 유지된다. 두 상태가 모두 안정하므로 마지막에 \(S\)나 \(R\)로 정한 값을 기억한다. 그런데 \(S = R = 1\)이면 \(Q = \bar Q = 0\)이 되고, 거기서 둘이 동시에 0으로 돌아가면 어느 상태로 갈지 정해지지 않는다. 그래서 이 입력은 쓰지 않는다. 한편 NAND 두 개로 만들면 입력이 액티브 로우(\(\bar S\), \(\bar R\))가 된다.

2.1.2D 래치

SR 래치 앞에 게이트를 달아 허용 입력 \(E\)가 1일 때만 \(S = D\), \(R = \bar D\)가 들어가게 하면 D 래치가 된다. \(E = 1\)인 동안 출력은 입력을 그대로 따라가며, 이것을 투명하다고 한다. 그리고 \(E = 0\)이 되는 순간의 값을 붙잡아 둔다. \(S\)와 \(R\)이 늘 반대라 금지 입력이 생기지 않는 것이 장점이다.

하지만 \(E = 1\)인 동안의 변화가 모두 출력에 나타나므로, 여러 회로를 같은 순간에 맞춰 움직이기에는 불편하다. 이 문제를 푸는 것이 클록 가장자리에서만 바뀌는 플립플롭(2.2절)이다.

2.1.3스위치 떨림 제거

기계식 스위치는 닫히는 순간 접점이 수 ms 동안 여러 번 튀어 붙었다 떨어지며, 이것을 채터링이라 한다. 이 신호를 카운터에 넣으면 한 번 누른 것이 여러 번으로 세어진다. 처음 질문의 둘째 문제가 이것이다.

해결책은 SR 래치이다. 두 접점을 가진 단극 쌍투 스위치의 두 접점을 NAND SR 래치의 \(\bar S\), \(\bar R\)에 잇는다. 그러면 첫 접촉에서 상태가 바뀐 뒤, 접점이 튀는 동안에는 두 입력이 모두 비활성이라 래치가 상태를 유지한다. 따라서 출력은 깨끗한 계단 하나가 된다.

예제 2.1.1

NAND SR 래치에서 \(\bar S = 0\), \(\bar R = 1\)을 넣었다가 둘 다 1로 돌려놓았다. 그다음 \(\bar R\)에 짧은 0 펄스가 세 번 연달아 들어왔다. 각 단계의 \(Q\)는?

풀이. \(\bar S = 0\)이 설정이므로 \(Q = 1\)이 되고, 둘 다 1로 돌려도 \(Q = 1\)을 유지한다. 다음으로 \(\bar R\)의 첫 0 펄스에서 \(Q = 0\)으로 재설정되고, 펄스 사이에는 두 입력이 1이라 \(Q = 0\)을 유지한다. 둘째와 셋째 펄스는 이미 0인 상태를 다시 0으로 만들 뿐이다. 그러므로 출력은 1에서 0으로 한 번만 바뀌며, 튀는 접점이 만든 여러 펄스가 하나의 변화로 정리된다.

흔한 오해래치와 플립플롭을 같은 말로 쓰기 쉽지만, 래치는 허용 입력의 레벨에 반응해 그동안 입력을 따라가고, 플립플롭은 클록의 가장자리 한 순간에만 입력을 받아들인다. 또 SR 래치의 \(S = R = 1\)은 회로가 고장 나는 입력은 아니지만, 그 뒤의 상태를 예측할 수 없으므로 피한다.
마무리

SR 래치는 두 게이트의 되먹임으로 두 안정 상태를 만들어, 처음 질문처럼 게이트만으로 1비트를 기억하며 \(S = R = 1\)은 쓰지 않는다. D 래치는 \(E = 1\)이면 입력을 그대로 따라가고 \(E = 0\)이면 그 값을 붙잡는다. 단극 쌍투 스위치를 SR 래치에 이으면 채터링이 하나의 깨끗한 변화로 정리된다.

기본

  1. NOR SR 래치가 \(Q = 1\)인 상태에서 \(S = 0\), \(R = 0\)을 넣으면?
    답

    \(Q = 1\) 유지.

  2. D 래치에서 \(E = 1\)인 동안 \(D\)가 0 → 1 → 0으로 바뀌고 \(E\)가 0이 되었다. 최종 \(Q\)는?
    답

    \(E\)가 0이 되는 순간의 \(D\) = 0.
