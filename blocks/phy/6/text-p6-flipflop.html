플립플롭과 타이밍 도표

본문
이 절에서 배울 것
  • D, JK, T 플립플롭이 클록 가장자리에서 바뀌는 규칙을 안다.
  • 클록 가장자리에서 상태가 바뀌는 것을 타이밍 도표로 그리고 셋업·홀드 시간을 안다.
먼저 알아야 할 것
  • 래치 (2.1절).

2.2.1클록 플립플롭

2.1절의 D 래치는 허용 입력이 1인 동안 입력을 그대로 따라갑니다. 여러 회로가 함께 동작하려면 상태가 정해진 순간(클록의 올라가는 가장자리)에만 바뀌어야 합니다. D 래치 두 개를 앞뒤로 잇고 허용 입력을 서로 반대로 주면(주종형), 클록이 Low에서 High로 바뀌는 순간의 입력만 출력으로 넘어가는 가장자리 동작 플립플롭이 됩니다.

종류클록 가장자리에서 다음 상태 \(Q^+\)쓰임
D\(Q^+ = D\)자료 저장, 레지스터
JK\(J = K = 0\): 유지, \(J = 1\), \(K = 0\): 1, \(J = 0\), \(K = 1\): 0, \(J = K = 1\): 뒤집기범용
T\(T = 1\)이면 뒤집기, 0이면 유지카운터, 분주기

T 플립플롭에 클록을 넣으면 출력은 클록 주기의 두 배 주기(진동수 절반)인 사각파가 됩니다. 이것이 2.3절 카운터의 기본 단위입니다.

2.2.2타이밍

타이밍 도표는 클록, 입력, 출력의 시간에 따른 High/Low를 나란히 그린 것입니다. D 플립플롭이 바르게 동작하려면 입력 \(D\)가 클록 가장자리보다 셋업 시간 \(t_{su}\) 전부터 홀드 시간 \(t_h\) 뒤까지 일정해야 하고, 출력은 전파 지연 \(t_{pd}\)(수 ns) 뒤에 바뀝니다. 이 조건이 깨지면 출력이 0도 1도 아닌 상태에 한동안 머무는 준안정 상태가 생길 수 있습니다. 클록이 빨라질수록 이 시간들이 회로의 최대 동작 진동수를 정합니다.

예제 2.2.1

D 플립플롭의 \(D\)가 클록 1주기 동안 0 → 1 → 0으로 짧게 펄스를 냈지만 클록의 올라가는 가장자리와 겹치지 않았다. 출력은?

풀이. 가장자리에서의 \(D\) 값만 보므로 출력은 바뀌지 않습니다. 반면 래치(레벨에 반응)는 클록이 High인 동안의 변화를 따라갑니다. 이 차이가 가장자리 동작 플립플롭을 쓰는 까닭입니다.

요약
  1. D: \(Q^+ = D\). JK: \(J = K = 1\)이면 뒤집기. T: 뒤집기.
  2. 클록 가장자리에서만 변화. 셋업·홀드·전파 지연이 동작 속도를 정한다.
