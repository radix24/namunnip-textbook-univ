SR 래치로 스위치 떨림 없애기

SR 래치 · 타이밍 · 문제 해결 전략

출발점

NAND로 만든 SR 래치는 \(\bar S = 0\)이면 \(Q = 1\), \(\bar R = 0\)이면 \(Q = 0\), 둘 다 1이면 유지합니다(2.1절). 단극 쌍투 스위치의 공통 단자를 접지에 잇고 두 접점을 풀업 저항으로 1에 두면, 스위치가 닿은 접점만 0이 된다.

문제 해결 전략 · 입력이 바뀌는 순서대로 상태 따라가기
  1. 시간 순서대로 두 입력 \(\bar S\), \(\bar R\)의 값을 표로 적는다.
  2. 각 구간에서 래치가 설정, 재설정, 유지 가운데 무엇인지 정한다.
  3. 출력 \(Q\)의 파형을 그려 튀는 횟수가 사라졌는지 본다.

스위치가 \(\bar R\) 접점에서 \(\bar S\) 접점으로 넘어간다. 접점이 이동하는 동안 1 ms 동안은 어느 쪽에도 닿지 않고, \(\bar S\) 접점에 닿은 뒤 3 ms 동안 세 번 튀었다(닿음–떨어짐 반복). 처음 \(Q = 0\)일 때 \(Q\)의 변화는? 스위치 신호를 바로 카운터에 넣었다면 몇 번 세어지는가?

풀이

  1. 이동 중: \(\bar S = \bar R = 1\) → 유지, \(Q = 0\).
    어느 접점에도 닿지 않음.
  2. \(\bar S\) 접점에 첫 접촉: \(\bar S = 0\) → \(Q = 1\).
    설정.
  3. 튀어 떨어지면 \(\bar S = \bar R = 1\) → 유지(\(Q = 1\)). 다시 닿으면 다시 설정(\(Q = 1\)). 출력은 첫 접촉 때 한 번만 바뀐다.
    튀는 동안 \(\bar R\)에는 닿지 않음.
  4. 바로 넣었다면 닿을 때마다 하강 가장자리가 생겨 첫 접촉과 세 번의 재접촉, 모두 4번 세어진다.
    채터링.

의미

래치가 떨림을 없애는 열쇠는 튀는 동안 반대쪽 접점에 닿지 않는다는 사실이다. 접점이 하나뿐인 스위치에서는 이 방법을 쓸 수 없어, RC 필터와 슈미트 트리거를 쓰거나 마이크로컨트롤러에서 수십 ms 동안 값이 같을 때만 받아들이는 소프트웨어 방법을 쓴다.

검산

\(\bar S = \bar R = 0\)이 되는 순간이 없으므로 금지 입력은 생기지 않는다. 스위치를 되돌리면 같은 논리로 \(Q\)가 한 번만 0으로 바뀐다.
