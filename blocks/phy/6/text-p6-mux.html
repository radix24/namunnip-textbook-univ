디코더와 멀티플렉서

본문
이 절에서 배울 것
  • 디코더와 멀티플렉서의 진리표와 논리식을 쓴다.
  • 멀티플렉서로 임의의 논리 함수를 만들고, 디코더로 주소를 선택하는 원리를 안다.
먼저 알아야 할 것
  • 부울 대수 (1.1절), 곱의 합 (1.2절).

1.4.1디코더

\(n\)비트 입력을 받아 \(2^n\)개 출력 가운데 입력 번호에 해당하는 하나만 활성화하는 회로입니다. 2-4 디코더의 출력은 \(Y_0 = \bar A_1\bar A_0\), \(Y_1 = \bar A_1A_0\), \(Y_2 = A_1\bar A_0\), \(Y_3 = A_1A_0\)으로, 각 출력이 최소항 하나입니다. 대부분의 디코더 IC(예: 74HC138, 3-8 디코더)는 출력이 활성일 때 Low이고(액티브 로우), 허용(enable) 입력이 있어 여러 개를 이어 더 큰 디코더를 만들 수 있습니다.

메모리에서 주소에 해당하는 칸 하나를 고르는 것(3.1절), 여러 장치 가운데 하나를 선택하는 칩 선택 신호, 7-세그먼트 표시가 디코더의 쓰임입니다.

1.4.2멀티플렉서

선택 입력에 따라 여러 데이터 입력 가운데 하나를 출력으로 보내는 회로(데이터 선택기)입니다. 4:1 멀티플렉서는 선택선 2개로

\[Y = \bar S_1\bar S_0D_0 + \bar S_1S_0D_1 + S_1\bar S_0D_2 + S_1S_0D_3.\]

반대로 한 입력을 선택한 출력으로 보내는 것은 디멀티플렉서이며, 디코더에 데이터 입력을 더한 것과 같습니다. 여러 센서 신호를 하나의 ADC로 번갈아 재는 아날로그 멀티플렉서가 실험에서 흔한 예입니다.

1.4.3멀티플렉서로 논리 함수 만들기

\(2^n\):1 멀티플렉서의 선택선에 \(n\)개의 입력 변수를 넣고, 각 데이터 입력에 진리표의 출력값(0 또는 1)을 묶으면 어떤 \(n\)변수 함수든 만들 수 있습니다. 더 나아가 변수 하나를 데이터 입력 쪽으로 돌려 \(0\), \(1\), \(C\), \(\bar C\) 가운데 하나를 넣으면, 4:1 멀티플렉서 하나로 3변수 함수를 만들 수 있습니다(아래 예제).

요약
  1. 디코더: \(n\)비트 → \(2^n\)개 중 하나 활성. 출력 하나가 최소항 하나.
  2. 멀티플렉서: 선택선으로 데이터 입력 하나를 고른다. 진리표를 데이터 입력에 묶으면 임의의 함수.
