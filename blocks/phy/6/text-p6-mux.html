디코더와 멀티플렉서

본문

온도 센서 여덟 개를 ADC 하나로 재고 싶다. 센서를 하나씩 번갈아 ADC에 이어 주는 장치가 필요하다. 거꾸로 메모리에서는 주소 몇 비트로 수많은 칸 가운데 하나를 골라야 한다. 이렇게 고르고 나눠 주는 회로는 어떻게 만들까?

먼저 알아야 할 것부울 대수(1.1절)와 곱의 합(1.2절)을 쓴다.

1.4.1디코더

\(n\)비트 입력을 받아 \(2^n\)개 출력 가운데 입력 번호에 해당하는 하나만 활성화하는 회로를 디코더라 한다. 2-4 디코더의 출력은 \(Y_0 = \bar A_1\bar A_0\), \(Y_1 = \bar A_1A_0\), \(Y_2 = A_1\bar A_0\), \(Y_3 = A_1A_0\)이어서, 출력 하나하나가 최소항 하나이다. 실제 디코더 IC는 대부분 출력이 활성일 때 Low인 액티브 로우이다. 또 74HC138(3-8 디코더)처럼 허용 입력이 있어 여러 개를 이어 더 큰 디코더를 만들 수 있다.

그러면 처음 질문의 메모리가 디코더의 쓰임이다. 주소에 해당하는 칸 하나를 고르는 일(3.1절), 여러 장치 가운데 하나를 선택하는 칩 선택 신호, 7-세그먼트 표시가 모두 디코더로 만든다.

1.4.2멀티플렉서

선택 입력에 따라 여러 데이터 입력 가운데 하나를 출력으로 보내는 회로를 멀티플렉서, 곧 데이터 선택기라 한다. 그림 1의 4:1 멀티플렉서는 선택선 2개로 다음과 같이 동작한다.

\[Y = \bar S_1\bar S_0D_0 + \bar S_1S_0D_1 + S_1\bar S_0D_2 + S_1S_0D_3\]

즉 각 항은 선택선의 최소항에 데이터 입력을 곱한 것이어서, 선택선이 가리키는 항 하나만 살아남는다. 반대로 한 입력을 선택한 출력으로 보내는 것은 디멀티플렉서이며, 디코더에 데이터 입력을 더한 것과 같다. 처음 질문의 센서 여덟 개를 ADC 하나로 번갈아 재는 아날로그 멀티플렉서가 실험에서 흔한 예이다.

1.4.3멀티플렉서로 논리 함수 만들기

한편 멀티플렉서는 그 자체로 범용 논리 소자이기도 하다. \(2^n\):1 멀티플렉서의 선택선에 \(n\)개의 입력 변수를 넣고 각 데이터 입력에 진리표의 출력값(0 또는 1)을 묶으면, 어떤 \(n\)변수 함수든 만들 수 있다. 더 나아가 변수 하나를 데이터 입력 쪽으로 돌려 \(0\), \(1\), \(C\), \(\bar C\) 가운데 하나를 넣으면, 4:1 멀티플렉서 하나로 3변수 함수를 만들 수 있다.

예제 1.4.1

다수결 함수 \(F = AB + BC + CA\)를 4:1 멀티플렉서 하나로 만들어라. 선택선에는 \(A\), \(B\)를 넣는다.

풀이. 먼저 \(AB\)의 값마다 \(F\)를 \(C\)의 함수로 쓴다. \(AB = 00\)이면 \(F = 0\)이고, \(01\)이면 \(F = C\)이며, \(10\)이면 \(F = C\)이고, \(11\)이면 \(F = 1\)이다. 따라서 \(D_0 = 0\), \(D_1 = C\), \(D_2 = C\), \(D_3 = 1\)로 묶으면 된다. 게이트 넷이 필요했던 1.2절의 회로가 IC 하나로 줄어든다.

흔한 오해디코더와 멀티플렉서를 같은 것으로 보기 쉽지만, 디코더는 출력을 여럿 가지고 그 가운데 하나를 활성화하며, 멀티플렉서는 입력을 여럿 가지고 그 가운데 하나를 내보낸다. 또 액티브 로우 IC에서는 고른 출력이 0이 되므로, LED를 켜려면 LED를 전원 쪽에 잇는다.
마무리

디코더는 \(n\)비트 입력으로 \(2^n\)개 출력 가운데 하나를 활성화하며 출력 하나가 최소항 하나이고, 처음 질문의 메모리 주소 선택에 쓴다. 멀티플렉서는 선택선으로 데이터 입력 하나를 골라 내보내며, 센서 여럿을 ADC 하나로 번갈아 잴 때 쓴다. 진리표를 멀티플렉서의 데이터 입력에 묶으면 어떤 논리 함수든 만들 수 있다.

1.4.4연습문제

    답
