모의실험 연구 설계와 요약

본문
이 절에서 배울 것
  • 모의실험 연구의 구성(목표, 자료 생성, 방법, 평가 지표, 반복 수)을 정한다.
  • 결과를 몬테카를로 표준오차와 함께 요약한다.
먼저 알아야 할 것
  • 몬테카를로 (4.3절), 응통14 1.2절.

새 방법이 정말 나은가

새 추정량을 제안했다면 이론만으로는 작은 표본에서의 성능을 알기 어렵습니다. 참값을 아는 가상 자료를 수천 번 만들어 기존 방법과 비교하는 모의실험 연구가 표준적인 근거입니다.

6.2.1설계 요소

  1. 목표: 무엇을 비교하나(치우침, MSE, 덮임률, 검정력, 제1종 오류율).
  2. 자료 생성: 분포, 표본 크기, 효과 크기 등 조건을 격자로(요인계획처럼).
  3. 방법: 비교할 추정량·검정. 같은 자료에 모든 방법을 적용(공통 난수로 비교의 분산을 줄임).
  4. 반복 수: 덮임률 95%를 ±1%p로 재려면 몬테카를로 표준오차 \(\sqrt{0.95\times0.05/R} \le 0.005\)에서 \(R \ge 1900\).
  5. 보고: 조건별 표나 그림, 몬테카를로 표준오차, 사용한 코드와 씨앗.
예제 6.2.1

지수분포 표본(\(n = 10, 30, 100\))에서 평균의 t 구간과 붓스트랩 백분위수 구간의 덮임률을 비교하는 연구를 설계하세요.

set.seed(2026); R <- 2000
cover <- function(n) { res <- replicate(R, {
    x <- rexp(n); ci_t <- t.test(x)$conf.int
    b <- replicate(500, mean(sample(x, replace = TRUE)))
    ci_b <- quantile(b, c(.025, .975))
    c(t = ci_t[1] <= 1 && 1 <= ci_t[2], boot = ci_b[1] <= 1 && 1 <= ci_b[2]) })
  rowMeans(res) }
sapply(c(10, 30, 100), cover)

실행 결과 덮임률은 t 구간이 90.8%, 93.4%, 94.8%, 붓스트랩 백분위수 구간이 87.1%, 92.1%, 94.0%였습니다(\(n\) = 10, 30, 100). 치우친 모집단의 작은 표본에서는 둘 다 95%에 못 미치고, 이 경우 단순한 붓스트랩이 t보다도 나쁩니다. 몬테카를로 표준오차는 약 0.5%p이므로 그보다 작은 차이는 해석하지 않습니다. 붓스트랩 안의 500번까지 곱해져 계산량이 크다는 점도 함께 적습니다.

요약
  1. 목표 지표, 자료 생성 조건, 방법, 반복 수를 미리 정함.
  2. 같은 자료에 모든 방법을 적용(공통 난수).
  3. 결과에 몬테카를로 표준오차와 코드를 함께.
