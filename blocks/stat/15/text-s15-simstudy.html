모의실험 연구 설계와 요약

본문

치우친 자료에서는 t 구간 대신 붓스트랩 구간을 쓰라는 조언을 흔히 듣는다. 정말 그럴까? 지수분포 표본 10개로 두 구간의 95% 덮임률을 비교해 보면 어느 쪽이 더 정직할까? 그리고 그 비교를 믿으려면 반복을 몇 번 해야 할까?

먼저 알아야 할 것몬테카를로(4.3절)와 붓스트랩(응통14 1.2절)을 쓴다.

처음 질문의 답은 꼭 그렇지는 않다는 것이다. 지수분포의 작은 표본에서는 단순한 붓스트랩 백분위수 구간이 t 구간보다도 덮임률이 낮다(그림 1). 일반적으로 이론만으로는 작은 표본의 성능을 알기 어려우므로, 참값을 아는 가상 자료를 수천 번 만들어 방법들을 비교한다. 이것이 모의실험 연구이며, 새 방법을 제안할 때의 표준적인 근거이다.

6.2.1설계 요소

먼저 목표 지표를 정한다. 치우침, 평균제곱오차, 덮임률, 검정력, 제1종 오류율 가운데 무엇을 비교할지 미리 밝힌다. 다음으로 자료 생성 조건, 곧 분포, 표본 크기, 효과 크기를 요인계획처럼 격자로 짠다. 그리고 비교할 추정량이나 검정을 같은 자료에 모두 적용한다. 같은 난수를 쓰면 방법 사이 차이의 분산이 줄어드는데, 이것을 공통 난수라 한다.

반복 수는 몬테카를로 표준오차로 정한다. 예를 들어 덮임률 95%를 ±1%p로 재려면 \(\sqrt{0.95 \times 0.05/R} \le 0.005\)에서 \(R \ge 1900\)이다. 마지막으로 결과는 조건별 표나 그림에 몬테카를로 표준오차를 붙여 보고하고, 사용한 코드와 씨앗도 함께 남긴다.

예제 6.2.1

지수분포 표본(\(n = 10, 30, 100\))에서 평균의 t 구간과 붓스트랩 백분위수 구간의 덮임률을 비교하는 연구를 설계하고 실행하라.

set.seed(2026); R <- 2000
cover <- function(n) { res <- replicate(R, {
    x <- rexp(n); ci_t <- t.test(x)$conf.int
    b <- replicate(500, mean(sample(x, replace = TRUE)))
    ci_b <- quantile(b, c(.025, .975))
    c(t = ci_t[1] <= 1 && 1 <= ci_t[2], boot = ci_b[1] <= 1 && 1 <= ci_b[2]) })
  rowMeans(res) }
sapply(c(10, 30, 100), cover)

풀이. 위 코드를 실행하면 덮임률은 t 구간이 90.8%, 93.4%, 94.8%, 붓스트랩 백분위수 구간이 87.1%, 92.1%, 94.0%였다(\(n\) = 10, 30, 100, 그림 1). 그러므로 치우친 모집단의 작은 표본에서는 둘 다 95%에 못 미치고, 이 경우 단순한 붓스트랩이 t보다도 나쁘다. 한편 몬테카를로 표준오차는 약 0.5%p이므로 그보다 작은 차이는 해석하지 않는다. 또 붓스트랩 안의 500번이 곱해져 계산량이 크다는 점도 함께 적는다.

흔한 실수

모의실험 결과를 표로 내면서 몬테카를로 표준오차를 빼먹으면, 0.3%p 같은 우연한 차이를 방법의 차이로 읽게 된다. 따라서 표준오차를 함께 적고, 그보다 작은 차이에는 의미를 두지 않는다.

마무리

모의실험 연구는 목표 지표, 자료 생성 조건, 비교할 방법, 반복 수를 미리 정하고, 같은 자료에 모든 방법을 적용해 공통 난수로 비교한다. 반복 수는 원하는 몬테카를로 표준오차에서 정하며, 결과에는 표준오차와 코드, 씨앗을 함께 남긴다. 지수분포의 작은 표본에서 단순 붓스트랩 구간은 t 구간보다도 덮임률이 낮았다.

6.2.2연습문제

기본

  1. 제1종 오류율 0.05를 ±0.002로 확인하려면 반복이 몇 번 필요한가?
    답

    \(\sqrt{0.0475/R} \le 0.002\)에서 \(R \ge 11875\)번이다.

응용

  1. 예제 6.2.1의 계산량은 평균 계산 몇 번인가? 붓스트랩 반복을 줄이지 않고 계산을 줄이는 방법은 무엇인가?
    답

    \(3 \times 2000 \times 501 \approx 300\)만 번이다. 반복을 병렬로 나누거나(6.3절), 붓스트랩 표본 평균을 행렬로 한꺼번에 계산하는 벡터화(6.1절)로 줄인다.

  2. \(n = 10\)에서 t 구간의 덮임률이 0.908이었다. 참값이 0.95일 때 이 차이는 몬테카를로 오차로 설명되는가?
    답

    표준오차가 \(\sqrt{0.95 \times 0.05/2000} = 0.0049\)이므로 차이 0.042는 약 8.6배이다. 우연이 아니라 실제로 덮임률이 낮은 것이다.
