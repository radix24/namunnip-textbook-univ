벡터화와 프로파일링

본문

\(E[\max(Z_1, Z_2)]\)를 난수 100만 쌍으로 추정하는 R 코드가 있다. for 문으로 짜면 16초가 걸리는데, 한 줄짜리 mean(pmax(rnorm(n), rnorm(n)))은 0.5초도 안 걸린다. 같은 계산인데 왜 30배 넘게 차이가 날까? 그리고 느린 코드를 고칠 때는 어디부터 손대야 할까?

먼저 알아야 할 것R의 벡터화(응통3 1단원)와 계산 복잡도(1.2절)를 쓴다.

처음 질문의 답은 해석 비용에 있다. R의 반복문은 매 단계 명령을 해석하고 함수를 부르는 비용이 들지만, 벡터 연산은 내부의 C 코드가 한꺼번에 처리한다(그림 1). 그런데 코드가 느릴 때 짐작으로 고치면 시간을 낭비하기 쉽다. 실행 시간의 대부분은 보통 코드의 작은 부분에서 쓰이므로, 그곳을 측정으로 찾고 그곳만 고친다.

6.1.1측정

따라서 고치기 전에 먼저 잰다. 전체 시간은 system.time으로, 여러 방법의 비교는 bench::mark로 잰다. 특히 bench::mark는 결과가 같은지도 함께 확인해 준다. 또 함수별 시간은 Rprof로, 줄별 시간은 profvis로 본다.

system.time(f(x))                      # 전체 시간
bench::mark(f1(x), f2(x))              # 여러 방법 비교 (결과가 같은지도 확인)
Rprof("prof.out"); f(x); Rprof(NULL); summaryRprof("prof.out")   # 함수별 시간
profvis::profvis(f(x))                 # 줄별 시각화

6.1.2벡터화

예제 6.1.1

몬테카를로로 \(E[\max(Z_1, Z_2)]\)를 추정하는 두 코드를 비교하라.

n <- 1e6
f_loop <- function() { s <- 0; for (i in 1:n) s <- s + max(rnorm(1), rnorm(1)); s / n }
f_vec  <- function() mean(pmax(rnorm(n), rnorm(n)))
system.time(f_loop()); system.time(f_vec())

풀이. 두 값 모두 \(1/\sqrt\pi \approx 0.564\) 근처이다. 그러나 이 교재를 쓰며 잰 시간은 반복문이 16.1초, 벡터화한 쪽이 0.47초로 약 34배 차이였다(그림 1). 정확한 배율은 컴퓨터에 따라 다르지만, 수십 배에서 수백 배가 흔하다.

그 밖의 요령도 있다. 먼저 결과를 담을 객체를 미리 만든다. 벡터에 원소를 하나씩 붙이면 매번 새 벡터를 만들어 복사하므로 전체가 \(O(n^2)\)이 되기 때문이다(1.2절). 그러므로 numeric(n)으로 길이를 정해 두고 채운다. 또한 crossprod나 rowSums 같은 행렬 함수를 쓰고, 반복마다 같은 값이 나오는 계산은 반복문 밖으로 뺀다. 그래도 느리면 Rcpp로 병목 부분만 C++로 쓴다.

흔한 오해

apply나 sapply로 바꾸면 벡터화된다고 생각하기 쉽다. 그러나 이 함수들도 안에서 R 함수를 원소마다 부르므로 속도는 for 문과 비슷하다(그림 1). 진짜 벡터화는 pmax처럼 벡터 전체를 한 번에 받는 함수를 쓰는 것이다. 물론 sapply가 for 문보다 읽기 쉽고 미리 할당을 알아서 해 주는 장점은 있으므로, 속도가 문제되지 않는 곳에서는 써도 좋다.

마무리

느린 코드는 먼저 측정해 병목을 찾고, 그곳만 고친다. 벡터 연산은 내부 C 코드가 한꺼번에 처리해 반복문보다 수십 배 빠르며, 미리 할당과 행렬 함수도 도움이 된다. 빠르게 고친 코드도 결과가 같은지 반드시 확인한다.

6.1.3연습문제

기본

  1. 행렬 X의 열 평균을 반복문 없이 구하는 방법 두 가지를 써라.
    답

    colMeans(X)와 crossprod(rep(1, nrow(X)), X) / nrow(X)이다.

응용

  1. 프로파일링 결과 전체 20초 가운데 한 함수가 18초를 썼다. 그 함수를 10배 빠르게 하면 전체 시간은 얼마인가?
    답

    \(2 + 18/10 = 3.8\)초이다. 나머지 2초를 아무리 줄여도 이만큼의 효과는 없다.

  2. for (i in 1:n) if (x[i] < 0) x[i] <- 0을 벡터화하라.
    답

    x[x < 0] <- 0 또는 x <- pmax(x, 0)이다.
