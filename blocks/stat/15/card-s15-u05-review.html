MCMC 단원 마무리 연습

문제 6 · 실습·계산·적용·개념·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 실습목표분포 \(\pi(x)\)를 위한 랜덤워크 메트로폴리스 알고리즘의 한 단계를 쓰고 R 코드로 나타내어라. [05-01]

    힌트 1

    제안 \(x' = x + \varepsilon\), \(\varepsilon \sim N(0, s^2)\)는 대칭이다.

    힌트 2

    채택 확률은 \(\min\{1, \pi(x')/\pi(x)\}\)이고, 계산은 로그로 한다.

    풀이 
    mh <- function(logpi, x0, n, s) {
  x <- numeric(n); x[1] <- x0
  for (t in 2:n) {
    xp <- x[t - 1] + rnorm(1, 0, s)
    if (log(runif(1)) < logpi(xp) - logpi(x[t - 1])) x[t] <- xp else x[t] <- x[t - 1]
  }
  x
}

    기각되면 현재 값을 한 번 더 기록합니다(빼면 틀린 분포가 된다). 목표분포의 정규화 상수를 몰라도 비만 쓰므로 계산할 수 있다.

  2. 계산목표분포가 표준정규이고 현재 값이 \(x = 1\), 대칭 제안으로 \(x' = 2\)가 나왔다. 채택 확률을 구하여라. \(x' = 0.5\)라면 어떤가요? [05-01]

    힌트 1

    \(\pi(x')/\pi(x) = \exp\{-(x'^2 - x^2)/2\}\)이다.

    힌트 2

    비가 1보다 크면 항상 채택한다.

    풀이

    \(x' = 2\): \(\exp\{-(4 - 1)/2\} = e^{-1.5} \approx 0.223\). \(x' = 0.5\): 비가 \(e^{0.375} > 1\)이므로 채택 확률 1이다. 밀도가 높은 쪽으로는 항상 가고, 낮은 쪽으로는 밀도 비만큼의 확률로 간다.

  3. 실습상관계수 \(\rho\)인 표준 이변량 정규분포에서 깁스 표집을 하는 단계를 써라. \(\rho\)가 0.99에 가까우면 어떤 문제가 생기나요? [05-02]

    힌트 1

    조건부분포는 \(X \mid Y = y \sim N(\rho y, 1 - \rho^2)\)이고 \(Y \mid X\)도 같은 꼴입니다(응통6-05-04).

    힌트 2

    조건부 표준편차 \(\sqrt{1 - \rho^2}\)가 매우 작아진다.

    풀이

    (1) \(x \leftarrow N(\rho y, 1 - \rho^2)\)에서 뽑기, (2) \(y \leftarrow N(\rho x, 1 - \rho^2)\)에서 뽑기를 번갈아 반복한다.

    \(\rho = 0.99\)이면 조건부 표준편차가 약 0.14로, 한 번에 좌표축 방향으로 조금씩만 움직여 긴 대각선 방향의 분포를 매우 느리게 탐색한다. 표본의 자기상관이 커서 유효 표본 크기가 작아진다. 변수를 재모수화하거나 함께 뽑는(블록 깁스) 방법으로 개선한다.

  4. 적용MCMC 표본의 수렴을 진단하는 방법 세 가지를 쓰고 각각 무엇을 확인하는지 써라. [05-03]

    힌트 1

    그림, 여러 사슬 비교, 자기상관을 생각하여라.

    힌트 2

    \(\hat R\)은 사슬 사이와 사슬 안 분산을 비교한다.

    풀이

    (1) 추적 그림: 사슬이 한곳에 머물거나 추세가 있는지, 여러 사슬이 같은 영역을 섞어 다니는지. (2) \(\hat R\) (겔만-루빈): 서로 다른 시작값의 사슬 사이 분산과 사슬 안 분산의 비로, 1.01 근처면 수렴했다고 본다. (3) 유효 표본 크기와 자기상관 그림: 표본이 실제로 독립 표본 몇 개만큼의 정보를 갖는지. 초기 구간(번인)은 버린다.

  5. 개념MCMC 표본 10000개의 자기상관이 1차 자기회귀 꼴로 \(\rho_k = 0.9^k\)이다. 유효 표본 크기 \(n_{\mathrm{eff}} = n/(1 + 2\sum_{k\ge1}\rho_k)\)를 구하여라. [05-03]

    힌트 1

    \(\sum_{k\ge1}0.9^k = 9\)이다.

    힌트 2

    정리하면 \(n(1 - \rho)/(1 + \rho)\)이다.

    풀이

    \(n_{\mathrm{eff}} = 10000/(1 + 18) \approx 526\)이다. 표본 1만 개가 독립 표본 약 530개만큼의 정보만 가지므로, 사후평균의 몬테카를로 표준오차는 \(\sigma/\sqrt{526}\)로 계산해야 한다. 자기상관을 무시하면 정밀도를 크게 과대평가한다.

  6. 판단랜덤워크 메트로폴리스에서 (가) 제안 표준편차가 매우 작아 채택률이 98%, (나) 매우 커서 채택률이 2%이다. 각각 무엇이 문제이고 어떻게 조정하나요? [05-01]

    힌트 1

    채택률이 높다고 좋은 것이 아니다.

    힌트 2

    1차원에서 권장 채택률은 대략 0.44, 고차원에서는 약 0.23이다.

    풀이

    (가) 거의 모든 제안이 채택되지만 한 걸음이 아주 작아 분포를 천천히 탐색하므로 자기상관이 크다. (나) 대부분 기각되어 같은 값에 오래 머무르므로 역시 자기상관이 크다. 두 경우 모두 유효 표본 크기가 작다. 제안 폭을 조정해 채택률을 대략 0.2~0.5(1차원 약 0.44, 고차원 약 0.23)로 맞춘다. 조정은 번인 기간에만 하고 이후에는 고정한다.
