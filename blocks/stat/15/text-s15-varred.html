분산 감소: 반대 변수와 제어 변수

본문
이 절에서 배울 것
  • 몬테카를로 오차가 \(1/\sqrt N\)으로만 줄어 분산 감소가 필요한 이유를 안다.
  • 반대 변수로 음의 상관을 만들어 분산을 줄인다.
  • 기대값을 아는 제어 변수로 회귀 보정한다.
먼저 알아야 할 것
  • 몬테카를로 적분과 중요도 표집 (4.3절), 회귀 계수 (응통10).

표본을 100배 늘리는 대신

몬테카를로 추정의 표준오차는 \(\sigma/\sqrt N\)이라 자릿수를 하나 더 얻으려면 계산이 100배 필요합니다. \(N\)을 늘리는 대신 같은 \(N\)에서 \(\sigma\)를 줄이는 기법이 분산 감소입니다. 4.3절의 중요도 표집도 그중 하나이고, 이 절은 구현이 더 간단한 두 가지를 다룹니다.

4.4.1반대 변수

\(\theta = E[h(U)]\), \(U \sim U(0,1)\)을 추정할 때 \(U\)와 함께 \(1 - U\)도 씁니다. 둘 다 같은 분포이므로 \(\frac12[h(U) + h(1 - U)]\)도 불편이고, 분산은

\[\mathrm{Var}\left(\frac{h(U) + h(1-U)}{2}\right) = \frac{\sigma^2}{2}(1 + \rho),\quad \rho = \mathrm{Corr}(h(U), h(1-U)).\]

\(h\)가 단조이면 \(\rho < 0\)이 되어, 같은 함수 계산 횟수 \(N\)(쌍 \(N/2\)개)에서 독립 표본보다 분산이 \((1 + \rho)\)배로 줄어듭니다. 정규 난수라면 \(Z\)와 \(-Z\)를 짝짓습니다. \(h\)가 단조가 아니면(예: 대칭인 \(h\)) 오히려 나빠질 수 있습니다.

4.4.2제어 변수

\(Y = h(U)\)와 상관이 크고 기대값 \(\mu_C\)를 정확히 아는 변수 \(C\)가 있으면

\[\hat\theta_c = \bar Y - b(\bar C - \mu_C)\]

도 불편입니다. 분산을 최소로 하는 \(b = \mathrm{Cov}(Y, C)/\mathrm{Var}(C)\)(회귀 기울기)에서 분산이 \((1 - \rho_{YC}^2)\)배가 됩니다. \(b\)는 같은 모의실험 자료로 추정해도 큰 \(N\)에서 문제가 없습니다. 예: 옵션 가격 모의실험에서 기초자산 가격(기대값을 앎)을 제어 변수로 씁니다.

예제 4.4.1

\(\theta = E(e^U) = e - 1 = 1.71828\)을 \(N = 1000\)번 함수 계산으로 추정합니다. 단순 몬테카를로, 반대 변수, \(C = U\)를 제어 변수로 쓴 경우의 표준오차를 비교하세요.

풀이. \(\mathrm{Var}(e^U) = (e^2 - 1)/2 - (e - 1)^2 = 0.2420\), 단순 표준오차 \(\sqrt{0.242/1000} = 0.0156\). 반대 변수: \(\mathrm{Cov}(e^U, e^{1-U}) = e - (e - 1)^2 = -0.2342\), 쌍의 분산 \((0.2420 - 0.2342)/2 = 0.0039\), 쌍 500개로 표준오차 0.0028. 제어 변수: \(\mathrm{Corr}(e^U, U) = 0.992\), 분산 \(0.242(1 - 0.984)/1000\), 표준오차 0.0020. 모의실험 2000번으로 확인한 표준편차도 0.016, 0.0028, 0.0020이었습니다. 같은 계산량으로 6~8배 정확해졌고, 이는 \(N\)을 36~64배 늘린 효과입니다.

요약
  1. 반대 변수: \(U\)와 \(1 - U\)를 짝지어 음의 상관, 단조 함수에서 효과적.
  2. 제어 변수: 기대값을 아는 \(C\)로 회귀 보정, 분산 \((1 - \rho^2)\)배.
  3. 같은 계산량에서 표준오차를 줄이는 것이 \(N\)을 늘리는 것보다 싸게 먹힙니다.

4.4.3연습문제

기본

  1. 제어 변수와의 상관이 0.9이면 분산은 몇 배가 되고, 같은 정확도를 단순 몬테카를로로 얻으려면 \(N\)이 몇 배 필요한가요?
    답

    \(1 - 0.81 = 0.19\)배. 단순 방법으로는 \(1/0.19 = 5.3\)배의 \(N\)이 필요합니다.

응용

  1. \(h(u) = (u - 0.5)^2\)에 반대 변수를 쓰면 어떻게 되나요?
    답

    \(h(1 - u) = h(u)\)라 상관이 1입니다. 쌍의 평균이 \(h(U)\) 하나와 같아 분산 감소가 전혀 없고, 계산을 두 번 했으므로 같은 계산량의 단순 방법보다 분산이 두 배입니다.
