메트로폴리스-헤이스팅스 알고리즘

본문

베이즈 사후분포 \(\pi(\theta) \propto L(\theta)p(\theta)\)는 비례 상수인 주변 가능도가 고차원 적분이라 대부분 계산할 수 없다. 밀도의 모양은 알지만 넓이를 1로 맞출 수 없는 분포에서, 어떻게 표본을 뽑을 수 있을까?

먼저 알아야 할 것마르코프 연쇄의 정상분포와 상세 균형(응통9 3.3절, 3.4절)과 기각법(4.2절)을 쓴다.

처음 질문의 답은 밀도의 비만 쓰는 마르코프 연쇄이다. 두 점의 밀도 비 \(\pi(y)/\pi(x)\)에서는 정규화 상수가 약분되므로 몰라도 된다. 메트로폴리스-헤이스팅스(MH) 알고리즘은 이 비로 움직일지 말지를 정해, 오래 돌리면 연쇄가 \(\pi\)를 따르게 만든다(그림 1).

5.1.1알고리즘

현재 상태 \(x\)에서 먼저 제안 \(y \sim q(\cdot \mid x)\)를 뽑는다. 그리고 다음 확률로 \(y\)로 옮기고, 아니면 \(x\)에 머문다. 머문 것도 표본으로 한 번 더 센다.

\[ \alpha(x, y) = \min\left\{1, \frac{\pi(y)q(x \mid y)}{\pi(x)q(y \mid x)}\right\} \]

제안이 \(y = x + \varepsilon\)처럼 대칭(\(q(y \mid x) = q(x \mid y)\))이면 \(\alpha = \min\{1, \pi(y)/\pi(x)\}\)가 되며, 이를 메트로폴리스 알고리즘이라 한다. 즉 확률이 높은 곳으로는 항상 가고, 낮은 곳으로는 그 비율만큼 가끔 간다.

5.1.2정상분포가 되는 까닭

정리 5.1.1 (상세 균형)

MH 연쇄의 전이 핵 \(P(x, y) = q(y \mid x)\alpha(x, y)\)(\(y \ne x\))는 상세 균형 \(\pi(x)P(x, y) = \pi(y)P(y, x)\)를 만족한다. 따라서 \(\pi\)는 정상분포이다.

증명. \(\pi(x)q(y \mid x)\alpha(x, y) = \min\{\pi(x)q(y \mid x), \pi(y)q(x \mid y)\}\)이다. 이 식은 \(x\)와 \(y\)에 대해 대칭이므로 \(\pi(y)q(x \mid y)\alpha(y, x)\)와 같다. ∎

또 연쇄가 기약이고 비주기이면 에르고딕 정리에 따라 \(\frac1n\sum h(X_t) \to E_\pi[h]\)이다(응통9 3.4절).

5.1.3조율

랜덤워크 제안의 폭이 너무 작으면 수용률은 높지만 거의 움직이지 않는다. 반대로 너무 크면 대부분 기각되어 제자리에 머문다(그림 1). 그래서 수용률을 보며 폭을 맞추는데, 1차원 정규 목표에서 최적 수용률은 약 0.44, 고차원에서는 약 0.23으로 알려져 있다. 이 절의 실습 카드에서 폭을 바꿔 확인할 수 있다.

예제 5.1.2

베르누이 자료 \(n = 20\)에서 성공이 14번이고 사전분포가 균일할 때, 사후분포 \(\pi(p) \propto p^{14}(1 - p)^6\)에서 MH로 표본을 뽑는 코드를 써라.

풀이. 아래 코드는 폭 0.1의 정규 랜덤워크를 쓴다. 넘침을 피하려고 로그 척도에서 비교했고, 출발점의 영향이 남은 처음 1000개는 번인으로 버렸다. 남은 표본의 평균은 참값 \(15/22 = 0.682\) 근처이다.

lp <- function(p) if (p <= 0 || p >= 1) -Inf else 14*log(p) + 6*log(1-p)
x <- numeric(10000); x[1] <- 0.5
for (t in 2:10000) { y <- x[t-1] + rnorm(1, 0, 0.1)
  x[t] <- if (log(runif(1)) < lp(y) - lp(x[t-1])) y else x[t-1] }
mean(x[-(1:1000)])    # 참값 15/22 = 0.682 근처
흔한 실수

기각되었을 때 그 단계를 건너뛰고 표본에 넣지 않으면 분포가 틀어진다. 기각된 단계에서는 현재 값을 한 번 더 기록해야 상세 균형이 성립한다.

마무리

MH는 제안 \(y\)를 \(\min\{1, \pi(y)q(x \mid y)/(\pi(x)q(y \mid x))\}\)의 확률로 받아들이고, 기각되면 현재 값을 다시 센다. 상세 균형으로 \(\pi\)가 정상분포가 되며 정규화 상수는 필요 없다. 랜덤워크 제안의 폭은 수용률을 보며 조율한다.

5.1.4연습문제

기본

  1. 독립 제안 \(q(y \mid x) = g(y)\)의 수용 확률을 쓰고, 기각법과 다른 점을 말하라.
    답

    \(\min\{1, \pi(y)g(x)/(\pi(x)g(y))\}\)이다. 기각되면 다시 뽑는 기각법과 달리 현재 값을 한 번 더 센다. 그래서 \(M\)을 몰라도 되지만 표본이 서로 상관된다.

응용

  1. 예제 5.1.2에서 현재 값이 0.7이고 제안이 0.5이면 수용 확률은 얼마인가?
    답

    \((0.5/0.7)^{14}(0.5/0.3)^6 = 0.0090 \times 21.4 = 0.19\)이다.

  2. 제안 폭 1에서 수용률이 0.14였다. 이것이 뜻하는 바는 무엇인가?
    답

    사후분포의 폭(표준편차 약 0.1)보다 제안이 너무 넓어 대부분 0과 1 밖이나 꼬리로 제안된다. 폭을 줄여야 한다.
