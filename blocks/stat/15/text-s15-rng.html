역변환법과 기각법으로 난수 만들기

본문

컴퓨터의 난수 생성기가 기본으로 만드는 것은 0과 1 사이의 균일 난수뿐이다. 그런데 R은 rnorm, rgamma, rbeta로 온갖 분포의 난수를 내놓는다. 균일 난수 하나로 어떻게 정규분포나 베타분포를 만들까?

먼저 알아야 할 것확률변수의 변환(응통6 2.2절)을 쓴다.

처음 질문의 답은 변환과 선별이다. 분포함수의 역함수에 균일 난수를 넣으면 원하는 분포가 나오고(역변환법), 역함수를 구하기 어려우면 뽑기 쉬운 분포에서 뽑아 일부만 남긴다(기각법, 그림 1). 컴퓨터의 균일 난수는 사실 결정적인 수열이라 의사 난수라 부르지만, 다른 분포의 난수는 모두 이것을 바꿔 만든다.

4.2.1역변환법

정리 4.2.1 (역변환)

\(U \sim U(0, 1)\)이고 \(F^{-1}(u) = \inf\{x : F(x) \ge u\}\)이면 \(X = F^{-1}(U)\)의 분포함수는 \(F\)이다.

증명. \(F^{-1}(u) \le x\)와 \(u \le F(x)\)는 동치이므로 \(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\)이다. ∎

예를 들어 지수분포는 \(-\log(1 - U)/\lambda\)이다. 이산분포는 누적 확률표에서 \(U\)가 들어가는 칸을 찾는다. 그런데 정규분포처럼 \(F^{-1}\)이 닫힌 꼴이 아니면 수치로 구하거나 다른 방법을 쓴다. 정규 난수는 박스-뮬러 변환 \(\sqrt{-2\log U_1}\cos(2\pi U_2)\)로도 만든다.

4.2.2기각법

목표 밀도 \(f\)는 직접 뽑기 어렵지만, 뽑기 쉬운 밀도 \(g\)와 상수 \(M\)이 있어 모든 \(x\)에서 \(f(x) \le Mg(x)\)라고 하자. 그러면 \(Y \sim g\)와 \(U \sim U(0, 1)\)을 뽑아 \(U \le f(Y)/\{Mg(Y)\}\)이면 \(Y\)를 받아들이고, 아니면 다시 뽑는다.

정리 4.2.2 (기각법)

받아들인 \(Y\)의 밀도는 \(f\)이고, 한 번 시도에서 받아들일 확률은 \(1/M\)이다.

그림으로 보면 \(Mg\) 아래 영역에 점을 고르게 뿌리고 \(f\) 아래에 떨어진 점의 \(x\) 좌표만 남기는 것이다(그림 1). 그래서 \(f\)의 정규화 상수를 몰라도 되고 비만 있으면 된다. 또 \(M\)이 1에 가까울수록, 곧 \(g\)가 \(f\)를 꼭 맞게 덮을수록 효율적이다.

예제 4.2.3

\(\mathrm{Beta}(2, 2)\), 곧 \(f(x) = 6x(1 - x)\)를 균일 제안분포로 기각법으로 뽑아라.

풀이. \(f\)의 최댓값은 \(x = 0.5\)에서 1.5이므로 \(M = 1.5\), \(g = 1\)이다. \(Y\)와 \(U\)를 뽑아 \(U \le 4Y(1 - Y)\)이면 받아들이며, 수용률은 \(1/1.5 = 2/3\)이다. 그림 1의 300번 시도에서는 201개, 곧 0.67을 받아들였다.

rbeta22 <- function(n) { out <- numeric(0)
  while (length(out) < n) { y <- runif(n); u <- runif(n)
    out <- c(out, y[u <= 4 * y * (1 - y)]) }
  out[1:n] }
mean(rbeta22(1e5))   # 0.5 근처
주의

\(f \le Mg\)가 어느 한 곳에서라도 깨지면 그곳의 확률이 모자라게 뽑혀 분포가 틀어진다. 특히 \(g\)의 꼬리가 \(f\)보다 얇으면 어떤 \(M\)으로도 덮을 수 없다.

마무리

역변환법은 \(X = F^{-1}(U)\)로 원하는 분포를 만들며, 역함수를 구할 수 있는 분포에 쓴다. 기각법은 \(f \le Mg\)인 쉬운 \(g\)에서 제안하고 확률 \(f/(Mg)\)로 받아들이며, 효율은 \(1/M\)이고 정규화 상수가 필요 없다.

4.2.3연습문제

기본

  1. 밀도 \(f(x) = 2x\)(\(0 < x < 1\))의 역변환 공식은 무엇인가?
    답

    \(F(x) = x^2\)이므로 \(X = \sqrt U\)이다.

응용

  1. \(\mathrm{Beta}(3, 3)\), 곧 \(f(x) = 30x^2(1 - x)^2\)을 균일 제안분포로 기각법으로 뽑으면 수용률은 얼마인가?
    답

    최댓값은 \(x = 0.5\)에서 \(30/16 = 1.875\)이므로 수용률은 \(1/1.875 = 0.53\)이다.

  2. 로지스틱 분포 \(F(x) = 1/(1 + e^{-x})\)의 역변환 공식은 무엇인가?
    답

    \(u = 1/(1 + e^{-x})\)를 풀면 \(X = \log\{U/(1 - U)\}\)이다.
