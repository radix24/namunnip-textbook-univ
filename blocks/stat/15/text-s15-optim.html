준뉴턴법과 범용 최적화 함수 쓰기

본문

정규분포의 \(\sigma\)를 optim으로 추정하는데, 반복 도중 \(\sigma\)에 음수가 들어가 NaN 경고가 쏟아진다. 경계를 막는 복잡한 장치를 달아야 할까? 아니면 더 간단한 방법이 있을까?

먼저 알아야 할 것뉴턴-랩슨(3.1절)과 경사하강법(3.2절)을 쓴다.

처음 질문의 답은 모수를 바꾸는 것이다. \(\sigma = e^\eta\)로 두고 제약 없는 \(\eta\)를 최적화하면 \(\sigma\)는 저절로 양수가 된다. 게다가 \(\eta\) 척도에서는 곡면이 더 둥글어 2차 근사가 잘 맞으므로 수렴도 빨라진다(그림 1). 그래서 실무에서는 대개 이렇게 목적함수만 짜서 범용 함수 optim에 넘기며, 그 안에서 주로 쓰이는 것이 준뉴턴법이다.

3.4.1준뉴턴법

뉴턴법은 빠르지만 모형마다 헤세 행렬을 구해야 하고, 경사하강법은 기울기 하나로 되지만 느리다. 준뉴턴법은 그 중간이다. 뉴턴 단계 \(\Delta = -H^{-1}\nabla f\)에서 \(H\) 대신 근사 \(B_k\)를 쓰고, 매 단계 기울기의 변화로 \(B_k\)를 고친다. 이동량 \(\mathbf s_k = \mathbf x_{k+1} - \mathbf x_k\)와 기울기 변화 \(\mathbf y_k = \nabla f_{k+1} - \nabla f_k\)에 대해 할선 조건 \(B_{k+1}\mathbf s_k = \mathbf y_k\)를 만족하게 고치는 것이 BFGS인데, 이것은 할선법(1.3절)을 여러 차원으로 넓힌 것이다.

따라서 BFGS는 기울기만 필요하고, 없으면 수치 미분으로 대신한다. 또 근 근처에서 초선형으로 수렴하며, \(B_k\)를 양의 정부호로 유지해 항상 내려가는 방향을 준다. 모수가 수천 개라면 최근 몇 단계만 기억하는 L-BFGS를 쓴다.

3.4.2모수 변환

제약이 있는 모수는 제약 없는 모수로 바꿔 최적화하고 결과를 되돌린다. 양수인 \(\sigma\)는 \(\sigma = e^\eta\), 0과 1 사이의 확률은 로지스틱 \(p = 1/(1 + e^{-\eta})\), 상관계수는 \(\rho = \tanh\eta\)로 바꾼다. 그런데 최대가능도 추정량은 변환에 대해 불변이므로 결과는 같다. 다만 표준오차는 변환된 모수에서 구한 뒤 델타 방법 \(\mathrm{se}(\hat\sigma) \approx \hat\sigma\,\mathrm{se}(\hat\eta)\)로 되돌린다.

3.4.3결과 점검

nll <- function(th) -sum(dnorm(y, th[1], exp(th[2]), log = TRUE))
fit <- optim(c(0, 0), nll, method = "BFGS", hessian = TRUE)
fit$convergence          # 0이면 정상 종료
se <- sqrt(diag(solve(fit$hessian)))

optim이 답을 냈다고 끝이 아니다. 먼저 convergence가 0인지 보고, 시작점을 바꿔도 같은 답인지 확인해 국소 최솟값이 아닌지 살핀다. 그리고 음의 로그가능도의 헤세 행렬의 역행렬이 관측 정보량의 역, 곧 표준오차 행렬이다(응통7 3단원). 또 모수의 크기가 크게 다르면 control = list(parscale = ...)로 맞춘다.

예제 3.4.1

\(\eta = \log\sigma\)로 최적화해 \(\hat\eta = 0.693\), \(\mathrm{se}(\hat\eta) = 0.071\)을 얻었다. \(\hat\sigma\)와 표준오차, 95% 신뢰구간을 구하라.

풀이. \(\hat\sigma = e^{0.693} = 2.00\)이고, 델타 방법으로 \(\mathrm{se} \approx 2.00 \times 0.071 = 0.142\)이다. 그런데 구간은 \(\eta\) 척도에서 만들어 되돌리는 편이 낫다. \(e^{0.693 \pm 1.96 \times 0.071} = [1.74, 2.30]\)으로, 양수이고 오른쪽이 조금 긴 비대칭 구간이다. 그림 1에서 \(\eta\) 척도의 곡면이 2차식에 더 가까우므로 이 구간이 더 정확하다.

흔한 실수

hessian = TRUE로 얻은 헤세 행렬은 optim이 최적화한 척도, 곧 \(\eta\)에 대한 것이다. 이것으로 구한 표준오차를 \(\sigma\)의 표준오차로 그대로 보고하면 틀린다.

마무리

BFGS는 기울기의 변화로 헤세 근사를 갱신하는 준뉴턴법으로, 헤세 행렬 없이 초선형으로 수렴한다. 제약은 \(e^\eta\), 로지스틱, \(\tanh\) 변환으로 없애며, 변환은 곡면을 둥글게 해 수렴과 구간을 함께 낫게 한다. 결과는 수렴 코드, 여러 시작점, 헤세 행렬로 점검하고 표준오차는 델타 방법으로 되돌린다.

3.4.4연습문제

기본

  1. 확률 \(p\)를 \(\eta = \log\{p/(1 - p)\}\)로 최적화해 \(\hat\eta = -1\)을 얻었다. \(\hat p\)는 얼마인가?
    답

    \(1/(1 + e) = 0.269\)이다.

응용

  1. 혼합분포의 로그가능도를 optim으로 최대화했는데 시작점에 따라 답이 다르다. 무엇을 해야 하는가?
    답

    국소 최댓값이 여럿이다. 여러 시작점이나 EM(3.3절)으로 돌려 로그가능도가 가장 큰 답을 고르고, 성분 하나의 분산이 0으로 가는 퇴화 해는 제외한다.

  2. 위 문제에서 \(\hat\eta = -1\), \(\mathrm{se}(\hat\eta) = 0.2\)이다. \(\hat p\)의 표준오차를 델타 방법으로 구하라.
    답

    \(dp/d\eta = p(1 - p) = 0.269 \times 0.731 = 0.197\)이므로 \(\mathrm{se}(\hat p) \approx 0.197 \times 0.2 = 0.039\)이다.
