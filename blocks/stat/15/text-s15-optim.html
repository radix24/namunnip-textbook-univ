준뉴턴법과 범용 최적화 함수 쓰기

본문
이 절에서 배울 것
  • BFGS 같은 준뉴턴법이 헤세 행렬 없이 뉴턴법을 흉내 내는 원리를 안다.
  • 모수 변환으로 제약(양수, 0~1)을 없앤다.
  • optim 결과에서 수렴과 표준오차를 점검한다.
먼저 알아야 할 것
  • 뉴턴-랩슨 (3.1절), 경사하강법 (3.2절).

모형마다 미분하지 않기

뉴턴법은 빠르지만 모형마다 2계 도함수(헤세 행렬)를 구해야 하고, 경사하강법은 도함수 하나로 되지만 느립니다. 실무에서는 대개 목적함수(음의 로그가능도)만 짜서 범용 함수 optim에 넘깁니다. 그 안에서 주로 쓰이는 방법이 준뉴턴법입니다.

3.4.1준뉴턴법

뉴턴 단계 \(\Delta = -H^{-1}\nabla f\)에서 \(H\) 대신 근사 \(B_k\)를 쓰고, 매 단계 기울기의 변화로 \(B_k\)를 갱신합니다. 이동량 \(\mathbf s_k = \mathbf x_{k+1} - \mathbf x_k\), 기울기 변화 \(\mathbf y_k = \nabla f_{k+1} - \nabla f_k\)에 대해 \(B_{k+1}\mathbf s_k = \mathbf y_k\)(할선 조건, 1.3절의 할선법을 여러 차원으로)를 만족하게 고치는 것이 BFGS입니다. 기울기만 필요하고(없으면 수치 미분), 근 근처에서 초선형으로 수렴하며, \(B_k\)를 양의 정부호로 유지해 항상 내려가는 방향을 줍니다. 모수가 수천 개면 최근 몇 단계만 기억하는 L-BFGS를 씁니다.

3.4.2모수 변환

표준편차 \(\sigma > 0\), 확률 \(0 < p < 1\) 같은 제약이 있으면 최적화가 경계 밖으로 나가 오류가 납니다. 제약 없는 모수로 바꿔 최적화하고 결과를 되돌립니다.

  • \(\sigma = e^\eta\), \(\eta \in \mathbb R\).
  • \(p = 1/(1 + e^{-\eta})\)(로지스틱).
  • 상관계수 \(\rho = \tanh\eta\).

변환은 곡면을 더 둥글게 만들어 수렴도 빠르게 합니다. 최대가능도추정량은 변환에 대해 불변이라 결과는 같습니다. 표준오차는 변환된 모수에서 구한 뒤 델타 방법으로 되돌립니다(\(\mathrm{se}(\hat\sigma) \approx \hat\sigma\,\mathrm{se}(\hat\eta)\)).

3.4.3결과 점검

nll <- function(th) -sum(dnorm(y, th[1], exp(th[2]), log = TRUE))
fit <- optim(c(0, 0), nll, method = "BFGS", hessian = TRUE)
fit$convergence          # 0이면 정상 종료
se <- sqrt(diag(solve(fit$hessian)))
  • convergence가 0인지, 시작점을 바꿔도 같은 답인지 확인합니다(국소 최솟값).
  • 음의 로그가능도의 헤세 행렬 역행렬이 관측 정보량의 역, 곧 표준오차 행렬입니다(응통7 3단원).
  • 모수의 크기가 크게 다르면 control = list(parscale = ...)로 맞춥니다.
예제 3.4.1

\(\eta = \log\sigma\)로 최적화해 \(\hat\eta = 0.693\), \(\mathrm{se}(\hat\eta) = 0.071\)을 얻었습니다. \(\hat\sigma\)와 표준오차, 95% 신뢰구간은?

풀이. \(\hat\sigma = e^{0.693} = 2.00\), 델타 방법 \(\mathrm{se} \approx 2.00 \times 0.071 = 0.142\). 구간은 \(\eta\) 척도에서 만들어 되돌리는 편이 낫습니다: \(e^{0.693 \pm 0.139} = [1.74, 2.30]\). 양수이고 오른쪽이 조금 긴 비대칭 구간입니다.

요약
  1. BFGS: 기울기 변화로 헤세 근사를 갱신하는 준뉴턴법.
  2. 제약은 \(e^\eta\), 로지스틱, \(\tanh\) 변환으로 없앱니다.
  3. 수렴 코드, 여러 시작점, 헤세 행렬로 표준오차를 점검합니다.

3.4.4연습문제

기본

  1. 확률 \(p\)를 \(\eta = \log(p/(1-p))\)로 최적화해 \(\hat\eta = -1\)을 얻었습니다. \(\hat p\)는?
    답

    \(1/(1 + e) = 0.269\).

응용

  1. 혼합분포의 로그가능도를 optim으로 최대화했는데 시작점에 따라 답이 다릅니다. 무엇을 해야 하나요?
    답

    국소 최댓값이 여럿입니다. 여러 시작점(또는 EM, 3.3절)으로 돌려 로그가능도가 가장 큰 답을 고르고, 성분이 하나로 몰리는 퇴화 해(분산이 0으로 감)를 제외합니다.
