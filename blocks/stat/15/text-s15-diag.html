연쇄가 충분히 돌았나

MCMC는 "충분히 오래 돌리면" 맞는 답을 줍니다. 그런데 얼마나 오래가 충분한지 알려 주는 정리는 없습니다. 증상을 여러 각도로 살펴 문제가 없어 보이는지 확인할 뿐입니다.

5.3.1진단 도구

  • 경로 그림: 반복에 따른 값. 잘 섞인 연쇄는 일정한 띠 안에서 털뭉치처럼 오르내립니다. 추세, 계단, 한쪽에 갇힘이 보이면 문제입니다.
  • 번인: 출발점의 영향이 남은 초기 부분을 버립니다.
  • 자기상관: 이웃한 표본의 상관. 천천히 줄어들면 정보가 적습니다.
  • 유효 표본 크기: \(\mathrm{ESS} = \dfrac{N}{1 + 2\sum_{k\ge1}\rho_k}\). 상관된 \(N\)개가 독립 표본 몇 개만큼의 정보를 주는지. 몬테카를로 표준오차는 \(\mathrm{sd}/\sqrt{\mathrm{ESS}}\).
  • \(\hat R\)(겔만-루빈): 서로 멀리 떨어진 출발점에서 연쇄 여러 개를 돌려, 연쇄 사이 분산과 연쇄 안 분산을 비교합니다. 모두 같은 분포로 수렴했으면 1에 가깝고, 1.01(또는 1.05)을 넘으면 더 돌립니다.
예제 5.3.1

\(N = 10000\)인 연쇄의 자기상관이 \(\rho_k = 0.9^k\)이면 ESS는?

풀이. \(\sum_{k\ge1}0.9^k = 9\). \(\mathrm{ESS} = 10000/19 \approx 526\). 만 개를 뽑았지만 독립 표본 약 530개의 정보입니다. AR(1) 과정과 같은 구조입니다(응통20).

주의 진단은 문제를 찾아낼 수는 있어도 수렴을 증명하지는 못합니다. 봉우리가 여러 개인 분포에서 모든 연쇄가 같은 봉우리에 갇히면 \(\hat R\)도 1에 가깝게 나옵니다. 출발점을 다양하게 하고, 가능하면 모의 자료로 참값을 아는 경우를 먼저 시험합니다. 
library(coda)
ch <- mcmc.list(mcmc(chain1), mcmc(chain2), mcmc(chain3))
traceplot(ch); autocorr.plot(ch); effectiveSize(ch); gelman.diag(ch)
요약
  1. 경로 그림, 번인, 자기상관, ESS, \(\hat R\).
  2. 몬테카를로 표준오차는 ESS로 계산.
  3. 진단은 필요조건일 뿐입니다.

5.3.3연습문제

기본

  1. 사후 평균을 표준오차 0.01로 추정하려 합니다. 사후 표준편차 0.5, ESS/N = 0.05이면 반복이 몇 번 필요한가요?
    답

    ESS \(= (0.5/0.01)^2 = 2500\) 필요, \(N = 2500/0.05 = 50000\).
