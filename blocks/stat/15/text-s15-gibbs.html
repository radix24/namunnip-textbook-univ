깁스 표집

본문

정규 자료의 평균 \(\mu\)와 정밀도 \(\tau\)를 함께 추정하는 베이즈 모형에서, 결합 사후분포 \(\pi(\mu, \tau \mid \mathbf x)\)는 이름 있는 분포가 아니다. 그런데 \(\tau\)를 고정하면 \(\mu\)는 정규분포이고, \(\mu\)를 고정하면 \(\tau\)는 감마분포이다. 이 두 조각만으로 결합 분포의 표본을 얻을 수 있을까?

먼저 알아야 할 것메트로폴리스-헤이스팅스(5.1절)와 다변량 정규의 조건부분포(응통6 5.4절)를 쓴다.

처음 질문의 답은 그렇다는 것이다. 나머지를 고정했을 때의 조건부분포를 번갈아 뽑으면, 그 연쇄의 정상분포가 결합 분포가 된다. 이것이 깁스 표집이며, 한 번에 한 변수씩 축 방향으로 움직인다(그림 1). 결합 분포에서 직접 뽑기는 어려워도 조건부분포는 알려진 분포인 경우가 많아 널리 쓰인다.

5.2.1알고리즘

목표가 \(\pi(\theta_1, \ldots, \theta_k)\)일 때, 한 바퀴에서 \(j = 1, \ldots, k\) 순서로 가장 최근 값들을 조건으로 다음을 뽑는다.

\[ \theta_j^{(t+1)} \sim \pi\left(\theta_j \mid \theta_1^{(t+1)}, \ldots, \theta_{j-1}^{(t+1)}, \theta_{j+1}^{(t)}, \ldots, \theta_k^{(t)}\right) \]

이 완전 조건부분포에서 뽑는 것은 제안분포를 조건부분포 자체로 둔 MH와 같다. 이때 수용 확률은 항상 1이므로 기각이 없다.

그러므로 한 변수를 갱신하는 단계마다 \(\pi\)가 보존되고, 그런 단계를 이어 붙인 한 바퀴도 \(\pi\)를 정상분포로 가진다. 또 갱신 순서를 매번 무작위로 정해도 되지만, 고정된 순서가 구현이 간단해 흔히 쓰인다. 다만 어떤 조건부분포에서 직접 뽑기 어렵다면 그 단계만 MH로 바꾸는데, 이를 깁스 안의 메트로폴리스라 한다.

5.2.2정규 모형

예제 5.2.1

\(x_1, \ldots, x_n \sim N(\mu, 1/\tau)\)이고 사전분포가 \(\mu \sim N(0, 100)\), \(\tau \sim \mathrm{Gamma}(a, b)\)(비율 \(b\))일 때 완전 조건부분포를 구하라.

풀이. \(\mu\)의 조건부분포에서는 사전 정밀도 0.01과 자료 정밀도 \(n\tau\)가 더해진다. 또 \(\tau\)의 조건부분포는 감마분포의 모수에 자료가 더해진 꼴이다.

\[ \mu \mid \tau, \mathbf x \sim N\left(\frac{\tau\sum x_i}{n\tau + 0.01}, \frac{1}{n\tau + 0.01}\right), \qquad \tau \mid \mu, \mathbf x \sim \mathrm{Gamma}\left(a + \frac n2,\ b + \frac12\sum(x_i - \mu)^2\right) \]

두 분포 모두 R 함수로 바로 뽑을 수 있으므로, 아래와 같이 번갈아 뽑으면 된다.

x <- c(4.9, 5.6, 5.1, 6.2, 5.8, 4.7); n <- length(x); a <- b <- 0.01
S <- 5000; mu <- tau <- numeric(S); mu[1] <- mean(x); tau[1] <- 1
for (t in 2:S) {
  prec <- n * tau[t-1] + 0.01
  mu[t] <- rnorm(1, tau[t-1] * sum(x) / prec, sqrt(1 / prec))
  tau[t] <- rgamma(1, a + n/2, b + sum((x - mu[t])^2) / 2) }
quantile(mu[-(1:500)], c(.025, .5, .975))
주의

두 변수의 상관이 매우 높으면 축 방향으로만 움직이는 깁스 표집은 대각선 모양 분포 위에서 아주 느리게 움직인다(그림 1). 이때는 모수를 다시 매개화하거나, 상관된 변수를 함께 묶어 뽑는 블록 깁스를 쓴다.

마무리

깁스 표집은 완전 조건부분포를 번갈아 뽑으며, 수용 확률이 1인 MH와 같다. 켤레 사전분포를 쓰면 조건부분포가 정규나 감마처럼 간단해진다. 다만 변수 사이 상관이 크면 느리므로 재매개화나 블록 깁스를 쓴다.

5.2.3연습문제

기본

  1. 깁스 표집에 기각 단계가 없는 까닭은 무엇인가?
    답

    제안분포가 완전 조건부분포 자체라서 MH의 수용 확률이 항상 1이기 때문이다.

응용

  1. 이변량 정규(평균 0, 분산 1, 상관 \(\rho\))의 깁스 표집 단계를 써라.
    답

    \(x \mid y \sim N(\rho y, 1 - \rho^2)\), \(y \mid x \sim N(\rho x, 1 - \rho^2)\)이다. \(\rho = 0.99\)이면 한 걸음의 표준편차가 0.14로 작아 느리게 섞인다.

  2. 위 연쇄에서 \(x\)만 보면 연속한 값의 자기상관은 \(\rho^2\)이다. \(\rho = 0.99\)이면 유효 표본 크기는 \(N\)의 몇 분의 1인가?
    답

    자기상관 \(r = 0.98\)인 AR(1)이므로 ESS \(= N(1 - r)/(1 + r) = N \times 0.02/1.98\), 곧 약 99분의 1이다.
