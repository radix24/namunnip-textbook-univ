깁스 표집

본문
이 절에서 배울 것
  • 완전 조건부분포를 번갈아 뽑는 깁스 표집을 구현한다.
  • 깁스 표집이 MH의 특수한 경우임을 안다.
먼저 알아야 할 것
  • 메트로폴리스-헤이스팅스 (5.1절), 다변량 정규의 조건부분포 (응통6 5.3절).

한 번에 한 변수씩

여러 모수의 결합 분포에서 직접 뽑기는 어렵지만, 나머지를 고정했을 때 한 모수의 조건부분포는 알려진 분포인 경우가 많습니다. 그 조건부분포들을 번갈아 뽑으면 결합 분포의 표본이 됩니다.

5.2.1알고리즘

목표 \(\pi(\theta_1, \ldots, \theta_k)\). 한 바퀴에서 \(j = 1, \ldots, k\) 순서로

\[\theta_j^{(t+1)} \sim \pi(\theta_j \mid \theta_1^{(t+1)}, \ldots, \theta_{j-1}^{(t+1)}, \theta_{j+1}^{(t)}, \ldots, \theta_k^{(t)}).\]

이 완전 조건부분포에서 뽑는 것은 제안분포를 조건부분포 자체로 둔 MH이고, 이때 수용 확률은 항상 1입니다. 그래서 기각이 없습니다.

예제 5.2.1 (정규 모형)

\(x_1, \ldots, x_n \sim N(\mu, 1/\tau)\), 사전분포 \(\mu \sim N(0, 100)\), \(\tau \sim \mathrm{Gamma}(a, b)\)(비율 \(b\)). 완전 조건부분포를 구하세요.

풀이. \(\mu\mid\tau, \mathbf x \sim N\left(\frac{\tau\sum x_i}{n\tau + 0.01}, \frac{1}{n\tau + 0.01}\right)\) (정밀도가 더해짐). \(\tau\mid\mu, \mathbf x \sim \mathrm{Gamma}\left(a + \frac n2, b + \frac12\sum(x_i - \mu)^2\right)\). 두 분포 모두 R 함수로 바로 뽑을 수 있습니다.

x <- c(4.9, 5.6, 5.1, 6.2, 5.8, 4.7); n <- length(x); a <- b <- 0.01
S <- 5000; mu <- tau <- numeric(S); mu[1] <- mean(x); tau[1] <- 1
for (t in 2:S) {
  prec <- n * tau[t-1] + 0.01
  mu[t] <- rnorm(1, tau[t-1] * sum(x) / prec, sqrt(1 / prec))
  tau[t] <- rgamma(1, a + n/2, b + sum((x - mu[t])^2) / 2) }
quantile(mu[-(1:500)], c(.025, .5, .975))
주의 두 변수의 상관이 매우 높으면 축 방향으로만 움직이는 깁스 표집은 대각선 모양 분포 위에서 아주 느리게 움직입니다. 모수를 다시 매개화하거나 함께 묶어 뽑습니다(블록 깁스).
요약
  1. 완전 조건부분포를 번갈아 뽑음, 수용률 1인 MH.
  2. 켤레 사전분포에서 조건부분포가 간단해집니다.
  3. 변수 사이 상관이 크면 느립니다.

5.2.3연습문제

응용

  1. 이변량 정규(평균 0, 분산 1, 상관 \(\rho\))의 깁스 표집 단계를 쓰세요.
    답

    \(x \mid y \sim N(\rho y, 1 - \rho^2)\), \(y \mid x \sim N(\rho x, 1 - \rho^2)\). \(\rho = 0.99\)이면 한 걸음 표준편차가 0.14로 작아 느리게 섞입니다.
