검정력 0.8이 되는 표본 크기를 근 찾기로

예제 · uniroot 응용

먼저 읽는 법

"검정력 = 0.8"인 \(n\)은 \(g(n) = \text{검정력}(n) - 0.8\)의 근이다. 검정력이 \(n\)에 대해 증가하므로 부호가 바뀌는 구간을 찾아 이분법 계열 방법으로 푼다.

문제. 두 집단 비교에서 효과 크기 \(\Delta/\sigma = 0.5\), 양측 5% 수준의 검정력을 정규근사 \(\Phi(0.5\sqrt{n/2} - 1.96)\)로 나타냅니다(그룹당 \(n\)). 검정력 0.8이 되는 \(n\)을 이분법으로 구하여라.

풀이

  1. \(g(n) = \Phi(0.5\sqrt{n/2} - 1.96) - 0.8\). \(g(10) = \Phi(-0.84) - 0.8 = -0.60\), \(g(100) = \Phi(1.58) - 0.8 = 0.14\). 근은 [10, 100] 안.
    부호가 바뀌는 구간.
  2. 가운데 55: \(\Phi(0.5\sqrt{27.5} - 1.96) = \Phi(0.66) = 0.746\), 음수 → [55, 100]. 77.5: \(\Phi(1.15) = 0.875\) → [55, 77.5]. 66.25: \(\Phi(0.92) = 0.821\) → [55, 66.25]. …
    이분법.
  3. 계속하면 \(n = 62.8\), 올림해 그룹당 63명. 닫힌 꼴 \(2(1.96 + 0.84)^2/0.25 = 62.8\)과 같다.
    응통13 1.3절 공식.

검산

\(n = 63\): \(0.5\sqrt{31.5} - 1.96 = 0.846\), \(\Phi(0.846) = 0.801\). \(n = 62\): \(0.5\sqrt{31} - 1.96 = 0.824\), \(\Phi = 0.795\). 63이 0.8을 처음 넘는다.

의미

닫힌 꼴이 있는 경우에는 근 찾기가 검산 도구이고, t 분포를 쓰는 정확한 검정력이나 복잡한 설계처럼 닫힌 꼴이 없는 경우에는 근 찾기가 유일한 방법이다. R의 power.t.test도 내부에서 uniroot로 \(n\)을 구합니다(정확한 t 기준 64명).
