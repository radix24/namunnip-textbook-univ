수치 적분과 난수 생성 단원 마무리 연습

문제 7 · 실습·개념 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습\(\int_0^1 e^{-x^2}dx\)를 간격 \(h = 0.5\)인 사다리꼴 공식과 심프슨 공식으로 근사하고, 참값 0.746824와 비교하세요. [04-01]

    힌트 1

    사다리꼴: \(h[\frac12f(0) + f(0.5) + \frac12f(1)]\).

    힌트 2

    심프슨: \(\frac{1}{6}[f(0) + 4f(0.5) + f(1)]\).

    풀이

    \(f(0) = 1\), \(f(0.5) = 0.7788\), \(f(1) = 0.3679\)이므로 사다리꼴 \(0.5(0.5 + 0.7788 + 0.1839) \approx 0.7314\), 심프슨 \((1 + 3.1152 + 0.3679)/6 \approx 0.7472\)입니다. 오차는 사다리꼴 0.015, 심프슨 0.0004로, 같은 세 점으로 심프슨이 훨씬 정확합니다(오차 차수 \(h^2\) 대 \(h^4\)).

  2. 실습균등 난수 \(U\)로 (1) 비율 \(\lambda\)인 지수분포, (2) 표준 코시 분포 난수를 만드는 역변환식을 유도하세요. [04-02]

    힌트 1

    \(X = F^{-1}(U)\)이면 \(X\)는 분포함수 \(F\)를 따릅니다.

    힌트 2

    코시 분포함수는 \(F(x) = \frac12 + \frac1\pi\arctan x\)입니다.

    풀이

    (1) \(F(x) = 1 - e^{-\lambda x}\)에서 \(x = -\ln(1 - u)/\lambda\)이고, \(1 - U\)도 균등분포이므로 \(X = -\ln U/\lambda\)를 써도 됩니다. (2) \(u = \frac12 + \frac1\pi\arctan x\)에서 \(X = \tan(\pi(U - \frac12))\)입니다. 분포함수의 역함수를 닫힌 꼴로 쓸 수 있을 때 가장 간단한 방법입니다.

  3. 실습\(\mathrm{Beta}(2, 2)\) (밀도 \(6x(1-x)\))를 \(U(0, 1)\) 제안분포로 기각법으로 생성하는 알고리즘을 쓰고, 채택률을 구하세요. [04-02]

    힌트 1

    밀도의 최댓값은 \(x = 1/2\)에서 1.5이므로 \(M = 1.5\)입니다.

    힌트 2

    채택률은 \(1/M\)입니다.

    풀이

    (1) \(Y \sim U(0, 1)\), \(V \sim U(0, 1)\)을 뽑는다. (2) \(V \le f(Y)/M = 4Y(1 - Y)\)이면 \(Y\)를 채택하고, 아니면 다시 뽑는다. 채택률은 \(1/1.5 = 2/3\)입니다. \(M\)이 작을수록(제안분포가 목표에 가까울수록) 효율적입니다.

  4. 실습몬테카를로 방법으로 \(\int_0^1 e^{-x^2}dx\)를 추정하는 R 코드를 쓰고, \(n = 10^5\)일 때 표준오차를 구하는 방법을 쓰세요. [04-03]

    힌트 1

    적분은 \(E[e^{-U^2}]\), \(U \sim U(0, 1)\)입니다.

    힌트 2

    표준오차는 표본표준편차 \(/\sqrt n\)입니다.

    풀이 
    set.seed(1)
g <- exp(-runif(1e5)^2)
c(mean(g), sd(g) / sqrt(1e5))   # 0.74688, 0.00064

    추정값 0.7469, 표준오차 약 0.0006으로 참값 0.7468과 잘 맞습니다. 심프슨 공식(세 점, 오차 0.0004)과 비교하면 1차원에서는 몬테카를로가 매우 비효율적입니다.

  5. 실습\(P(Z > 4) \approx 3.17\times10^{-5}\)을 단순 몬테카를로로 추정하면 왜 어려운지 설명하고, \(N(4, 1)\)을 제안분포로 쓰는 중요도 표집 추정량을 쓰세요. [04-03]

    힌트 1

    단순 방법에서 \(10^5\)개를 뽑으면 4를 넘는 값이 몇 개쯤 나오나요?

    힌트 2

    중요도 가중치는 \(w(x) = \phi(x)/\phi(x - 4)\)입니다.

    풀이

    \(10^5\)개 중 평균 3개 정도만 4를 넘으므로 추정값이 0, 1e−5, 3e−5 등으로 크게 흔들립니다(상대 표준오차 약 56%).

    중요도 표집: \(X_i \sim N(4, 1)\)로 뽑아 \(\hat p = \frac1n\sum I(X_i > 4)\,\phi(X_i)/\phi(X_i - 4)\). 관심 영역에서 표본을 많이 뽑고 가중치로 보정합니다. \(n = 10^5\)이면 \(3.168\times10^{-5}\), 표준오차 약 \(2\times10^{-7}\)(상대 0.7%)로 크게 정확해집니다.

  6. 개념10차원 적분을 격자 구적법(차원마다 10점)과 몬테카를로로 할 때의 계산량과 오차를 비교하세요. [04-01]

    힌트 1

    격자점 수는 \(10^{10}\)입니다.

    힌트 2

    몬테카를로 오차는 차원과 무관하게 \(n^{-1/2}\)입니다.

    풀이

    격자 구적법은 \(10^{10}\)번 함수를 계산해야 하고, 차원이 늘면 계산량이 지수적으로 늘어 정확도가 급격히 떨어집니다(차원의 저주). 몬테카를로는 오차가 차원과 무관하게 \(\sigma/\sqrt n\)이므로 \(10^6\)번이면 \(\sigma\)의 0.1% 정도 오차를 얻습니다. 그래서 고차원 적분(베이즈 사후 기댓값 등)은 몬테카를로나 MCMC로 계산합니다.

  7. 계산\(\theta = E(U^2) = 1/3\)을 추정할 때 \(C = U\)(기대값 1/2)를 제어 변수로 쓰면 분산이 몇 배가 되나요? (\(\mathrm{Var}(U^2) = 4/45\), \(\mathrm{Cov}(U^2, U) = 1/12\), \(\mathrm{Var}(U) = 1/12\)) [04-04]

    힌트 1

    최적 분산 배율은 \(1 - \rho^2\)입니다.

    힌트 2

    \(\rho^2 = \mathrm{Cov}^2/(\mathrm{Var}(U^2)\mathrm{Var}(U))\).

    풀이

    \(\rho^2 = (1/144)/((4/45)(1/12)) = (1/144)/(1/135) = 135/144 = 0.9375\). 분산 배율 0.0625, 곧 16분의 1입니다.

    최적 계수 \(b = \mathrm{Cov}/\mathrm{Var}(U) = 1\)이라 추정량은 \(\overline{U^2} - (\bar U - 1/2)\)입니다. 같은 정확도를 단순 방법으로 얻으려면 반복이 16배 필요합니다.
