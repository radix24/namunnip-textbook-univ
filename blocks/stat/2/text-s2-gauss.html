가우스 소거와 해의 개수

본문
이 절에서 배울 것
  • 가우스 소거로 연립방정식을 사다리꼴로 만들어 푼다.
  • 해가 없음, 하나, 무수히 많음을 판정한다.
먼저 알아야 할 것
  • 행렬 연산 (1.1절).

정규방정식을 푸는 방법

회귀계수는 연립방정식 \(X^\top X\mathbf b = X^\top\mathbf y\)의 해입니다. 해가 하나뿐인지, 아예 정해지지 않는지(설명변수가 중복될 때)를 판정하는 것이 이 절의 내용입니다.

1.2.1가우스 소거

첨가 행렬 \([A \mid \mathbf b]\)에 기본 행 연산(행 바꾸기, 상수배, 한 행의 배수를 다른 행에 더하기)을 하면 해가 바뀌지 않습니다. 각 행의 첫 0이 아닌 원소(피벗)가 아래로 갈수록 오른쪽에 오는 사다리꼴로 만든 뒤 뒤에서부터 대입합니다.

1.2.2해의 개수

정리 1.2.1

사다리꼴에서 (가) \([0 \cdots 0 \mid c]\) (\(c \ne 0\)) 행이 있으면 해가 없다. (나) 그렇지 않고 피벗 수 = 미지수 수이면 해가 하나. (다) 피벗 수 < 미지수 수이면 해가 무수히 많다(피벗이 없는 열의 변수가 자유변수).

피벗 수가 행렬의 계수(rank)입니다(3.1절).

예제 1.2.2

\(x + 2y + z = 4\), \(2x + 4y + 3z = 9\), \(x + 2y + 2z = 5\)를 푸세요.

풀이. 2행 − 2×1행: \(z = 1\). 3행 − 1행: \(z = 1\). 3행 − 2행: \(0 = 0\). 피벗 2개(\(x, z\)), 미지수 3개 → \(y = t\)가 자유. \(z = 1\), \(x = 3 - 2t\). 해가 무수히 많습니다. 회귀로 치면 두 설명변수의 열이 비례(2열 = 2×1열)해서 계수를 하나로 정할 수 없는 상황입니다.

요약
  1. 기본 행 연산으로 사다리꼴 → 뒤에서 대입.
  2. 모순 행 → 해 없음, 피벗 = 미지수 수 → 하나, 그보다 적으면 무수히.

1.2.3연습문제

기본

  1. \(x + y = 2\), \(2x + 2y = 5\)의 해는?
    답

    2행 − 2×1행: \(0 = 1\). 해가 없습니다.
