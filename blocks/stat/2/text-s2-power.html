본문

  • 전이행렬의 거듭제곱으로 마르코프 연쇄의 장기 분포를 구한다.
먼저 알아야 할 것
  • 고유값과 대각화 (4.1절).

같은 변환을 여러 번

인구 이동, 고객 이탈, 날씨처럼 매 시점 같은 규칙으로 상태가 바뀌는 과정은 같은 행렬을 거듭 곱하는 일입니다. 100번 곱하는 대신 고유값으로 바꾸면 지수 계산 하나로 끝나고, 장기적으로 어디로 가는지도 바로 보입니다.

4.4.1대각화로 거듭제곱

\(A = PDP^{-1}\)(\(D\)는 고유값 대각 행렬)이면 \(A^2 = PDP^{-1}PDP^{-1} = PD^2P^{-1}\), 일반적으로

\[A^n = PD^nP^{-1}, \qquad D^n = \mathrm{diag}(\lambda_1^n, \ldots, \lambda_k^n).\]

\(|\lambda| < 1\)인 성분은 \(n\)이 커지면 0으로 사라지고, \(|\lambda| = 1\)인 성분만 남습니다. 가장 큰 \(|\lambda|\)가 1보다 크면 \(A^n\)은 폭발합니다. 둘째로 큰 고유값의 크기가 극한에 다가가는 속도를 정합니다.

4.4.2마르코프 연쇄

전이행렬 \(P\)(행의 합 1, 응통9)는 고유값 1을 가지고, 나머지 고유값은 크기가 1 이하입니다. 정칙인 연쇄에서는 1 말고 크기 1인 고유값이 없어 \(P^n\)의 모든 행이 정상분포 \(\boldsymbol\pi\)(\(\boldsymbol\pi P = \boldsymbol\pi\), 고유값 1의 왼쪽 고유벡터)로 수렴합니다.

예제 4.4.1

날씨 연쇄 \(P = \begin{pmatrix}0.9 & 0.1\\ 0.2 & 0.8\end{pmatrix}\)(1 = 맑음, 2 = 비)의 고유값과 \(P^n\)의 (1,1) 원소, 극한을 구하세요.

풀이. 대각합 1.7, 행렬식 0.7이라 고유값은 1과 0.7. 정상분포 \(\boldsymbol\pi\): \(0.1\pi_1 = 0.2\pi_2\), \(\boldsymbol\pi = (2/3, 1/3)\). \(P^n\)의 (1,1) 원소 \(= \frac23 + \frac13(0.7)^n\): \(n = 1\)에서 0.9, \(n = 5\)에서 0.723, \(n = 20\)에서 0.667. 오늘 맑으면 20일 뒤 맑을 확률은 장기 비율 2/3에 거의 같아집니다. 오차가 매일 0.7배로 줄어듭니다.

요약
  1. \(A^n = PD^nP^{-1}\), 고유값의 \(n\)제곱.
  2. \(|\lambda| < 1\) 성분은 사라지고, 둘째 고유값이 수렴 속도를 정함.
  3. 전이행렬은 고유값 1의 고유벡터(정상분포)로 수렴.

4.4.3연습문제

기본

  1. \(A = \begin{pmatrix}2 & 0\\ 0 & 0.5\end{pmatrix}\)에서 \(A^{10}\)은?
    답

    \(\mathrm{diag}(1024, 0.00098)\). 첫 성분은 폭발하고 둘째는 사라집니다.

응용

  1. 예제 4.4.1에서 \(P^n\)의 (1,1) 원소가 장기 비율과 0.01 이내가 되려면 며칠이 필요한가요?
    답

    \(\frac13(0.7)^n < 0.01\), \(0.7^n < 0.03\), \(n > \ln 0.03/\ln 0.7 = 9.8\). 10일.
