그람-슈미트 과정과 QR 분해

본문

설명변수들이 서로 상관되어 있으면 계수의 해석도 계산도 어렵다. 같은 열공간을 서로 수직인 단위벡터로 다시 표현할 수 있다면 사영과 최소제곱이 아주 간단해질 것이다. 그런 벡터는 어떻게 만들까? 그리고 R의 lm은 왜 \(X^\top X\)의 역행렬 대신 그 방법을 쓸까?

먼저 알아야 할 것직교 사영(3.2절)과 LU 분해의 후진 대입(1.3절)을 쓴다.

3.3.1그람-슈미트 과정

처음 질문의 첫째 부분은 앞의 방향 성분을 차례로 빼는 것으로 답한다. 독립인 \(\mathbf a_1, \ldots, \mathbf a_n\)이 있을 때 먼저 \(\mathbf q_1 = \mathbf a_1/\|\mathbf a_1\|\)로 둔다. 그다음 \(k = 2, 3, \ldots\)에 대해 \(\mathbf a_k\)에서 앞서 만든 방향의 성분을 모두 빼고 길이를 1로 맞춘다.

\[\mathbf v_k = \mathbf a_k - \sum_{j<k}(\mathbf q_j^\top\mathbf a_k)\mathbf q_j, \qquad \mathbf q_k = \frac{\mathbf v_k}{\|\mathbf v_k\|}\]

이렇게 만든 \(\mathbf q\)들은 서로 수직이고 길이가 1인 정규직교 벡터이며, 처음 \(k\)개가 \(\mathbf a_1, \ldots, \mathbf a_k\)와 같은 공간을 만든다. 통계로 읽으면 \(\mathbf v_k\)는 \(\mathbf a_k\)를 앞의 변수들로 회귀하고 남은 잔차이다. 그림 1이 \(k = 2\)인 경우이다.

3.3.2QR 분해

그람-슈미트를 거꾸로 읽으면 각 \(\mathbf a_k\)는 \(\mathbf q_1, \ldots, \mathbf q_k\)의 일차결합이다. 이를 행렬로 모으면 다음 분해가 된다.

정리 3.3.1 (QR 분해)

열이 독립인 \(m\times n\) 행렬은 \(A = QR\)로 쓸 수 있다. \(Q\)는 정규직교 열을 가진 \(m\times n\) 행렬(\(Q^\top Q = I\))이고, \(R\)은 대각이 양수인 \(n\times n\) 상삼각행렬로 \(r_{jk} = \mathbf q_j^\top\mathbf a_k\)이다.

이제 처음 질문의 둘째 부분이다. 정규방정식 \(X^\top X\mathbf b = X^\top\mathbf y\)에 \(X = QR\)을 넣으면 \(R^\top R\mathbf b = R^\top Q^\top\mathbf y\)이고, \(R^\top\)이 가역이므로 \(R\mathbf b = Q^\top\mathbf y\)이다. 이것은 상삼각 연립방정식이라 1.3절처럼 뒤에서부터 대입해 풀린다. 사영 행렬도 \(P = QQ^\top\)로 간단해진다. 무엇보다 \(X^\top X\)를 만들지 않으므로, 열들이 거의 종속일 때 생기는 반올림 오차의 증폭을 피한다. 그래서 수치적으로 안정적이고, R의 lm이 이 방법을 쓴다(응통15 2.1절).

예제 3.3.2

\(\mathbf a_1 = (1, 1, 1)\), \(\mathbf a_2 = (2, 4, 6)\)에 그람-슈미트를 적용하고 \(R\)을 구하여라.

풀이. \(\mathbf q_1 = (1, 1, 1)/\sqrt3\)이다. \(\mathbf q_1^\top\mathbf a_2 = 12/\sqrt3\)이므로 \(\mathbf v_2 = \mathbf a_2 - 4(1, 1, 1) = (-2, 0, 2)\)이고 \(\mathbf q_2 = (-1, 0, 1)/\sqrt2\)이다. 여기서 \(\mathbf v_2\)는 \(x\)에서 평균을 뺀 편차이다. 절편 열에 대한 회귀의 잔차가 곧 편차이기 때문이다. 그리고 \(R = \begin{pmatrix}\sqrt3 & 4\sqrt3\\ 0 & 2\sqrt2\end{pmatrix}\)이다.

주의교과서식 그람-슈미트는 열이 거의 종속이면 반올림 오차로 \(\mathbf q\)들의 직교성이 깨진다. 실제 프로그램은 같은 분해를 하우스홀더 반사로 계산한다. 결과 \(Q\), \(R\)은 같고 계산 경로만 다르다.
마무리

그람-슈미트 과정은 각 벡터에서 앞서 만든 방향의 성분을 빼고 길이를 1로 맞춰, 같은 열공간을 정규직교 벡터로 다시 표현한다. 각 단계는 앞의 변수들에 대한 회귀 잔차이다. 이를 모으면 \(A = QR\)이고, 최소제곱은 \(R\mathbf b = Q^\top\mathbf y\)를 후진 대입으로 풀면 된다. \(X^\top X\)를 만들지 않아 수치적으로 안정적이므로 회귀 프로그램이 이 방법을 쓴다.

3.3.3연습문제

기본

  1. 예제 3.3.2에서 \(\mathbf y = (1, 2, 6)\)의 최소제곱 계수를 \(R\mathbf b = Q^\top\mathbf y\)로 구하여라.
    답

    \(Q^\top\mathbf y = (9/\sqrt3, 5/\sqrt2)\)이다. \(2\sqrt2b_2 = 5/\sqrt2\)에서 \(b_2 = 1.25\)이고, \(\sqrt3b_1 + 4\sqrt3\times1.25 = 9/\sqrt3\)에서 \(b_1 = -2\)이다. 따라서 \(\hat y = -2 + 1.25x\)이다.

응용

  1. \(A = QR\)일 때 \(A^\top A = R^\top R\)임을 보여라. 이것은 5.2절의 어떤 분해와 같은가?
    답

    \(A^\top A = R^\top Q^\top QR = R^\top R\)이다. 하삼각 \(R^\top\)과 그 전치의 곱이므로 \(A^\top A\)의 촐레스키 분해이다.
