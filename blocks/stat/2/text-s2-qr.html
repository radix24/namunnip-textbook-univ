서로 수직인 축으로 바꾸기

설명변수들이 서로 상관되어 있으면 계수 해석과 계산이 어렵습니다. 같은 열공간을 서로 수직인 단위벡터로 다시 표현하면 사영과 최소제곱이 아주 간단해집니다.

3.3.1그람-슈미트

독립인 \(\mathbf a_1, \ldots, \mathbf a_n\)에서

  1. \(\mathbf q_1 = \mathbf a_1/\|\mathbf a_1\|\).
  2. \(\mathbf v_k = \mathbf a_k - \sum_{j<k}(\mathbf q_j^\top\mathbf a_k)\mathbf q_j\) (앞의 방향 성분을 빼냄), \(\mathbf q_k = \mathbf v_k/\|\mathbf v_k\|\).

\(\mathbf q\)들은 정규직교(\(\mathbf q_i^\top\mathbf q_j = 0\), 길이 1)이고 처음 \(k\)개가 \(\mathbf a_1, \ldots, \mathbf a_k\)와 같은 공간을 만듭니다. 통계로 읽으면 \(\mathbf v_k\)는 "\(\mathbf a_k\)를 앞의 변수들로 회귀한 잔차"입니다.

3.3.2QR 분해

정리 3.3.1

열이 독립인 \(m\times n\) 행렬 \(A = QR\). \(Q\)는 정규직교 열(\(Q^\top Q = I\)), \(R\)은 대각이 양수인 \(n\times n\) 위삼각행렬(\(r_{jk} = \mathbf q_j^\top\mathbf a_k\)).

최소제곱: \(X^\top X\mathbf b = X^\top\mathbf y\)에 \(X = QR\)을 넣으면 \(R^\top R\mathbf b = R^\top Q^\top\mathbf y\), 곧 \(R\mathbf b = Q^\top\mathbf y\)를 뒤에서부터 대입해 풉니다. 사영 행렬은 \(P = QQ^\top\). 이 방법이 수치적으로 안정적이라 R의 lm이 씁니다(응통15 2.1절).

예제 3.3.2

\(\mathbf a_1 = (1, 1, 1)\), \(\mathbf a_2 = (2, 4, 6)\)에 그람-슈미트를 적용하세요.

풀이. \(\mathbf q_1 = (1,1,1)/\sqrt3\). \(\mathbf q_1^\top\mathbf a_2 = 12/\sqrt3\), \(\mathbf v_2 = \mathbf a_2 - 4(1,1,1) = (-2, 0, 2)\), \(\mathbf q_2 = (-1, 0, 1)/\sqrt2\). \(\mathbf v_2\)는 \(x\)의 편차(평균을 뺀 값)입니다. \(R = \begin{pmatrix}\sqrt3 & 4\sqrt3\\ 0 & 2\sqrt2\end{pmatrix}\).

요약
  1. 그람-슈미트: 앞 방향 성분을 빼고 정규화.
  2. \(A = QR\), 최소제곱은 \(R\mathbf b = Q^\top\mathbf y\).
  3. 각 단계는 앞 변수들에 대한 회귀 잔차.

3.3.3연습문제

기본

  1. 예제에서 \(\mathbf y = (1, 2, 6)\)의 최소제곱 계수를 \(R\mathbf b = Q^\top\mathbf y\)로 구하세요.
    답

    \(Q^\top\mathbf y = (9/\sqrt3, 5/\sqrt2)\). \(2\sqrt2 b_2 = 5/\sqrt2\) → \(b_2 = 1.25\). \(\sqrt3b_1 + 4\sqrt3(1.25) = 9/\sqrt3\) → \(b_1 = 3 - 5 = -2\). \(\hat y = -2 + 1.25x\).
