중요한 성분만 남기기

사진 한 장을 1000×1000 행렬로 보면 100만 개의 수입니다. 특이값이 빠르게 작아진다면 앞의 몇십 개 성분만으로 사진을 거의 그대로 되살릴 수 있습니다.

6.2.1에카르트-영 정리

정리 6.2.1

\(A_k = \sum_{i=1}^k\sigma_i\mathbf u_i\mathbf v_i^\top\)는 계수가 \(k\) 이하인 모든 행렬 \(B\) 가운데 \(\|A - B\|_F\)를 최소화하고, 최소 오차는 \(\|A - A_k\|_F^2 = \sum_{i>k}\sigma_i^2\)이다.

\(\|\cdot\|_F\)는 원소 제곱합의 제곱근(프로베니우스 노름)이고 \(\|A\|_F^2 = \sum\sigma_i^2\)입니다. 그래서 \(\sum_{i\le k}\sigma_i^2/\sum\sigma_i^2\)가 근사가 담는 "에너지" 비율로, 주성분의 설명 분산 비율과 같습니다.

저장할 수: \(m\times n\) 대신 \(k(m + n + 1)\). \(m = n = 1000\), \(k = 50\)이면 약 10만 개로 1/10입니다.

예제 6.2.2

R에서 내장 volcano(87×61 지형 높이 행렬)를 계수 5로 근사하고 오차를 보세요.

s <- svd(volcano); k <- 5
Ak <- s$u[, 1:k] %*% diag(s$d[1:k]) %*% t(s$v[, 1:k])
sum(s$d[1:k]^2) / sum(s$d^2)          # 담은 에너지 비율
par(mfrow = c(1, 2)); image(volcano); image(Ak)

첫 성분 하나가 에너지의 99.5%, 다섯 개가 99.99%를 담습니다(높이 전체의 평균 수준이 첫 성분에 크게 실리기 때문). 그림에서도 계수 5 근사가 산의 모양을 거의 그대로 보여 줍니다.

요약
  1. SVD를 \(k\)개에서 자르면 최적 저계수 근사.
  2. 오차² = 버린 특이값의 제곱합.
  3. 압축, 잡음 제거, 주성분분석.
