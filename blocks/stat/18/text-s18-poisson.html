포아송 회귀와 과대산포

본문
이 절에서 배울 것
  • 셈 자료에 포아송 회귀를 적합하고 노출(offset)을 넣는다.
  • 과대산포를 진단하고 준포아송·음이항 모형으로 대처한다.
먼저 알아야 할 것
  • GLM (5.1절), 응통6 4.1절 포아송·음이항 분포.

몇 번 일어났나

교차로별 사고 건수, 환자의 응급실 방문 횟수, 웹페이지 클릭 수처럼 0, 1, 2, …로 세는 자료는 평균이 작으면 정규분포와 전혀 다른 모양이고 분산이 평균과 함께 커집니다.

5.2.1모형과 노출

\(Y_i \sim\) 포아송\((\mu_i)\), \(\log\mu_i = \mathbf x_i^\top\boldsymbol\beta\). 계수 \(e^{\beta_j}\)는 사건 비율의 배수(율비)입니다. 관찰 기간이나 인구가 단위마다 다르면 \(\log\mu_i = \log t_i + \mathbf x_i^\top\boldsymbol\beta\)로 노출 \(t_i\)를 계수 1인 항(offset)으로 넣어 비율 \(\mu_i/t_i\)를 모형화합니다.

glm(claims ~ age + region, offset = log(exposure), family = poisson, data = d)

5.2.2과대산포

포아송은 분산 = 평균을 가정합니다. 실제 셈 자료는 개체 차이 때문에 분산이 평균보다 큰 경우가 많습니다(과대산포). 그러면 표준오차가 과소평가되어 효과가 지나치게 유의해 보입니다.

  • 진단: 피어슨 \(X^2\)/잔차 자유도가 1보다 훨씬 크면 의심.
  • 준포아송: 분산 \(= \phi\mu\)로 두고 표준오차에 \(\sqrt{\hat\phi}\)를 곱함(family = quasipoisson).
  • 음이항 회귀: 분산 \(= \mu + \mu^2/\theta\)(MASS::glm.nb). 개체마다 비율이 감마분포로 흔들린다는 모형에서 나옵니다.
  • 0이 지나치게 많으면 영과잉 모형(ZIP, 허들)을 고려합니다.
예제 5.2.1

R 내장 InsectSprays(살충제별 벌레 수)에 포아송 회귀를 적합하고 과대산포를 점검하세요.

fit <- glm(count ~ spray, family = poisson, data = InsectSprays)
sum(residuals(fit, "pearson")^2) / df.residual(fit)   # 약 1.5
summary(glm(count ~ spray, family = quasipoisson, data = InsectSprays))

비가 1.51로 약한 과대산포가 있어 준포아송으로 표준오차를 약 \(\sqrt{1.51} = 1.23\)배 키웁니다. 살충제 간 차이는 그래도 매우 뚜렷합니다.

요약
  1. 포아송 회귀: 로그 연결, \(e^\beta\) = 율비, 노출은 offset.
  2. \(X^2/df \gg 1\)이면 과대산포.
  3. 준포아송, 음이항, 영과잉 모형으로 대처.

5.2.3연습문제

기본

  1. 계수 0.18이면 율비와 해석은?
    답

    \(e^{0.18} = 1.20\). 그 변수가 1 커지면 사건 비율이 약 20% 높습니다.
