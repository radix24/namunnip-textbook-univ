순서형 반응의 누적 로짓 모형

본문

병원 만족도를 1~5점으로 물었다. 점수를 그대로 선형회귀하면 1점과 2점의 차이가 4점과 5점의 차이와 같다고 가정하게 된다. 그렇다고 범주마다 따로 로지스틱 회귀를 하면 5점이 4점보다 높다는 순서 정보를 버린다. 순서는 살리면서 간격은 가정하지 않는 모형은 없을까?

먼저 알아야 할 것로지스틱 회귀(3.1절)를 쓴다.

처음 질문의 답은 누적 로짓 모형이다. 몇 점 이하일 확률을 경계마다 로짓으로 모형화하되, 설명변수의 기울기는 모든 경계에서 같다고 둔다(그림 1). 그러면 순서는 살리면서 범주 사이의 간격은 가정하지 않고, 설명변수의 효과를 하나의 오즈비로 요약할 수 있다.

6.1.1모형

정의 6.1.1 (누적 로짓 모형)

범주 \(1 < 2 < \cdots < J\)에 대해 \(\mathrm{logit}\,P(Y \le j \mid \mathbf x) = \alpha_j - \boldsymbol\beta^\top\mathbf x\), \(j = 1, \ldots, J-1\)이며, \(\alpha_1 < \cdots < \alpha_{J-1}\)이다.

절편 \(\alpha_j\)는 범주 경계마다 다르지만, 기울기 \(\boldsymbol\beta\)는 모든 경계에서 같은데 이것을 비례 오즈 가정이라 한다. 그래서 \(e^{\beta}\)는 \(x\)가 1 커질 때 더 높은 범주에 있을 오즈의 비이며, 어느 경계에서 잘라도 같다. 또 이 모형은 잠재 연속 변수 \(Y^* = \boldsymbol\beta^\top\mathbf x + \varepsilon\)(로지스틱 오차)를 경계 \(\alpha_j\)로 자른 것으로 볼 수 있다. 다만 부호 규약은 소프트웨어마다 달라 확인이 필요하다.

6.1.2적합과 점검

library(MASS)
fit <- polr(satisfaction ~ wait_time + staff, data = d, Hess = TRUE)
summary(fit); exp(coef(fit))      # 오즈비

비례 오즈 가정은 경계마다 따로 이진 로지스틱 회귀를 해서 계수가 비슷한지 보거나, 가정을 푼 모형과 우도비로 비교해 점검한다. 그런데 가정이 깨지면 부분 비례 오즈 모형이나, 범주마다 다른 계수를 두는 기준범주 로짓(6.2절)을 쓴다.

예제 6.1.1

대기 시간(10분 단위)의 계수가 \(\beta = -0.4\)이다. 해석하라.

풀이. \(e^{-0.4} = 0.67\)이다. 즉 대기 시간이 10분 길어질 때마다 더 높은 만족도 범주에 있을 오즈가 0.67배, 곧 33% 줄어든다(그림 1). 이 값은 4점 이상 대 3점 이하로 자르든 2점 이상 대 1점으로 자르든 같다.

흔한 실수

R의 polr는 \(\mathrm{logit}\,P(Y \le j) = \zeta_j - \eta\) 꼴이라 양의 계수가 높은 범주 쪽을 뜻하지만, 다른 소프트웨어는 반대 부호를 쓰기도 한다. 그러므로 해석하기 전에 예측 확률로 방향을 확인한다.

마무리

누적 로짓 모형은 누적 확률의 로짓을 경계별 절편과 공통 기울기로 나타낸다. 비례 오즈 가정 아래 설명변수의 효과를 하나의 오즈비로 요약하며, 가정을 점검해 깨지면 더 유연한 모형을 쓴다.

6.1.3연습문제

기본

  1. 범주가 5개이고 설명변수가 2개이면 절편과 기울기 모수는 모두 몇 개인가?
    답

    절편 4개와 기울기 2개로 6개이다. 범주마다 따로 하는 기준범주 로짓이면 \(4 \times 3 = 12\)개이다.

응용

  1. \(\alpha = (-2, -0.5, 0.8, 2.2)\), \(\beta = -0.4\)일 때 대기 시간 0에서 1점의 확률과 5점의 확률을 구하라.
    답

    \(P(Y \le 1) = 1/(1 + e^{2}) = 0.12\)이고, \(P(Y = 5) = 1 - 1/(1 + e^{-2.2}) = 0.10\)이다.

  2. 경계별 이진 로지스틱 회귀의 대기 시간 계수가 −0.2, −0.4, −0.7, −1.1로 나왔다. 무엇을 뜻하는가?
    답

    높은 경계일수록 효과가 커져 비례 오즈 가정이 의심스럽다. 우도비로 확인하고, 깨졌다면 부분 비례 오즈 모형을 쓴다.
