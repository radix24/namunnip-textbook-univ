순서형 분할표의 추세 검정

본문

약의 용량을 네 단계로 나눠 각 50명에게 주었더니 부작용이 5, 8, 12, 17명으로 늘어났다. 카이제곱 독립성 검정의 p값은 0.02였다. 그런데 이 검정은 용량의 순서를 모르고, 단계를 뒤섞어도 같은 값을 준다. 용량이 늘수록 위험이 커지는지를 묻는다면 더 알맞은 검정은 없을까?

먼저 알아야 할 것독립성 검정(1.3절)과 상관계수(응통5)를 쓴다.

처음 질문의 답은 점수를 붙인 추세 검정이다. 카이제곱 독립성 검정은 행의 순서를 무시하므로 어떤 차이든 같은 무게로 다루고, 자유도를 여러 개 써서 추세에 대한 검정력이 떨어진다. 하지만 용량에 0, 1, 2, 3 같은 점수를 붙이고 비율이 점수에 따라 직선으로 변하는지만 검정하면, 자유도 1을 추세 하나에 몰아 쓴다(그림 1).

1.4.1코크란-아미티지 추세 검정

\(I\)개 순서 집단에 점수 \(x_i\), 집단 크기 \(n_i\), 사건 수 \(y_i\), 전체 비율 \(\hat p = \sum y_i/N\), \(\bar x = \sum n_ix_i/N\)이라 하자. 그러면 다음 통계량은 비율이 점수에 대해 직선으로 변하지 않는다는 귀무가설 아래 근사적으로 표준정규이다.

\[ z = \frac{\sum x_i(y_i - n_i\hat p)}{\sqrt{\hat p(1 - \hat p)\left[\sum n_ix_i^2 - N\bar x^2\right]}} \]

즉 비율을 점수로 회귀한 기울기의 검정이며, 로지스틱 회귀에서 점수를 연속 설명변수로 넣은 점수 검정과 같다. 그래서 추세가 있으면 일반 카이제곱보다 훨씬 강력하다.

예제 1.4.1

용량 0, 1, 2, 3(각 50명)에서 부작용이 5, 8, 12, 17명이다. 추세 검정과 일반 카이제곱 검정을 비교하라.

풀이. \(\hat p = 42/200 = 0.21\), \(\bar x = 1.5\)이다. 분자는 \(\sum x_i(y_i - 10.5) = 0 + (-2.5) + 2(1.5) + 3(6.5) = 20\)이고, 분모는 \(\sqrt{0.21 \times 0.79 \times (50 \times 14 - 200 \times 2.25)} = \sqrt{41.48} = 6.44\)이다. 따라서 \(z = 3.11\), p값은 약 0.002이다. 한편 일반 카이제곱은 9.76(자유도 3), p값은 약 0.02이다(그림 1). 같은 자료에서 추세에 집중한 검정이 증거를 열 배 강하게 보여 준다.

1.4.2두 변수 모두 순서가 있을 때

행과 열 모두에 점수를 붙이고 칸 도수를 가중치로 한 상관계수 \(r\)을 구하면, \(M^2 = (n - 1)r^2\)이 독립 아래 근사적으로 \(\chi^2_1\)이다. 이것을 선형 연관 검정이라 한다. 이때 점수는 자료를 보기 전에 정해야 하며, 같은 간격이 자연스럽지 않으면 중간 순위 점수를 쓰기도 한다. 그러므로 결과가 점수 선택에 크게 달라지지 않는지 확인한다.

주의

추세 검정은 단조 관계만 찾는다. 비율이 용량 0, 1, 2, 3에서 0.1, 0.3, 0.3, 0.1처럼 가운데가 높으면 직선 추세가 없어 \(z\)가 0에 가깝다. 이런 모양은 일반 카이제곱이나 이차 점수로 찾아야 한다.

마무리

순서가 있는 변수에는 점수를 붙여 자유도 1의 추세 검정을 한다. 코크란-아미티지 검정은 비율의 점수에 대한 기울기를 검정하며, 추세가 있으면 일반 카이제곱보다 강력하다. 두 변수 모두 순서형이면 \(M^2 = (n-1)r^2\)을 쓴다.

1.4.3연습문제

기본

  1. 순서형 3×3 표에서 점수로 계산한 상관이 0.15이고 \(n = 400\)이다. \(M^2\)과 결론은 무엇인가?
    답

    \(M^2 = 399 \times 0.0225 = 8.98\), 자유도 1, p값 약 0.003이므로 양의 선형 연관이 있다.

응용

  1. 예제 1.4.1에서 점수를 0, 1, 2, 3 대신 1, 2, 3, 4로 바꾸면 \(z\)는 어떻게 되는가?
    답

    점수를 일정하게 옮겨도 \(\sum(y_i - n_i\hat p) = 0\)이라 분자가 같고 분모도 같으므로 \(z\)는 그대로이다.

  2. 점수를 0, 1, 2, 6처럼 마지막 단계만 크게 벌리면 어떤 위험이 있는가?
    답

    검정 결과가 마지막 집단에 크게 좌우된다. 점수는 자료를 보기 전에 실제 용량처럼 근거 있게 정하고, 몇 가지 점수로 결과가 바뀌지 않는지 확인한다.
