순서형 분할표의 추세 검정

본문
이 절에서 배울 것
  • 행에 순서가 있을 때 카이제곱 독립성 검정이 정보를 버리는 이유를 안다.
  • 점수를 붙여 코크란-아미티지 추세 검정을 한다.
  • 일반적인 선형 연관 통계량 \(M^2 = (n-1)r^2\)을 안다.
먼저 알아야 할 것
  • 독립성 검정 (1.3절), 상관계수 (응통5).

용량이 늘수록 늘어나는가

흡연량(없음, 조금, 보통, 많음)에 따른 질병 여부처럼 한 변수에 순서가 있으면, 질문은 대개 "용량이 늘수록 위험이 커지는가"입니다. 카이제곱 독립성 검정(1.3절)은 행의 순서를 무시하므로 어떤 차이든 같은 무게로 다루고, 자유도를 여러 개 써서 추세에 대한 검정력이 떨어집니다.

1.4.1코크란-아미티지 추세 검정

\(I\)개 순서 집단에 점수 \(x_i\)(예: 0, 1, 2, 3), 집단 크기 \(n_i\), 사건 수 \(y_i\), 전체 비율 \(\hat p = \sum y_i/N\)이라 하면

\[z = \frac{\sum x_i(y_i - n_i\hat p)}{\sqrt{\hat p(1 - \hat p)\left[\sum n_ix_i^2 - N\bar x^2\right]}}\]

은 "비율이 점수에 대해 직선으로 변하지 않는다"는 귀무가설 아래 근사적으로 표준정규입니다(\(\bar x = \sum n_ix_i/N\)). 비율을 점수로 회귀한 기울기의 검정이며, 로지스틱 회귀에서 점수를 연속 설명변수로 넣은 점수 검정과 같습니다. 자유도 1을 추세 하나에 몰아 쓰므로 추세가 있으면 일반 카이제곱보다 훨씬 강력합니다.

1.4.2두 변수 모두 순서가 있을 때

행과 열 모두에 점수를 붙이고 칸 도수를 가중치로 한 상관계수 \(r\)을 구하면, \(M^2 = (n - 1)r^2\)이 독립 아래 근사적으로 \(\chi^2_1\)입니다(선형 연관 검정). 점수는 자료를 보기 전에 정해야 하며, 같은 간격이 자연스럽지 않으면 중간 순위 점수를 쓰기도 합니다. 결과가 점수 선택에 크게 달라지지 않는지 확인합니다.

예제 1.4.1

용량 0, 1, 2, 3(각 50명)에서 부작용이 5, 8, 12, 17명입니다. 추세 검정과 일반 카이제곱 검정을 비교하세요.

풀이. \(\hat p = 42/200 = 0.21\), \(\bar x = 1.5\). 분자 \(\sum x_i(y_i - 10.5) = 0 + (-2.5) + 2(1.5) + 3(6.5) = 20\). 분모 \(\sqrt{0.21 \times 0.79 \times (50 \times 14 - 200 \times 2.25)} = \sqrt{41.48} = 6.44\). \(z = 3.11\), p값 약 0.002. 일반 카이제곱은 9.76(자유도 3), p값 약 0.02. 같은 자료에서 추세에 집중한 검정이 증거를 열 배 강하게 보여 줍니다.

요약
  1. 순서가 있으면 점수를 붙여 자유도 1의 추세 검정을 합니다.
  2. 코크란-아미티지 = 비율의 점수에 대한 기울기 검정.
  3. 두 변수 모두 순서형이면 \(M^2 = (n-1)r^2\).

1.4.3연습문제

기본

  1. 순서형 3×3 표에서 점수로 계산한 상관이 0.15, \(n = 400\)입니다. \(M^2\)과 결론은?
    답

    \(M^2 = 399 \times 0.0225 = 8.98\), 자유도 1, p값 약 0.003. 양의 선형 연관이 있습니다.

응용

  1. 비율이 용량 0, 1, 2, 3에서 0.1, 0.3, 0.3, 0.1처럼 가운데가 높으면 추세 검정은 어떤 결과를 줄까요?
    답

    직선 추세가 없으므로 \(z\)가 0에 가까워 유의하지 않습니다. 추세 검정은 단조 관계만 찾으므로, 이런 모양은 일반 카이제곱이나 이차 점수로 찾아야 합니다.
