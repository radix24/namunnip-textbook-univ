2×2 표에서 독립 모형의 이탈도 직접 계산

예제 · G² 계산

먼저 읽는 법

가장 작은 경우인 2×2 표에서 독립 모형의 기대 도수를 구해 \(G^2\)를 손으로 계산하고, 카이제곱 통계량과 비교한다. 포화 모형의 이탈도가 0이라는 것도 확인한다.

문제. 처리 (호전 40, 무변화 10), 대조 (호전 30, 무변화 20)인 표에 독립 로그선형모형 (X, Y)를 맞춘다. 기대 도수, \(G^2\), 피어슨 \(\chi^2\)를 구하고 포화 모형과 비교하여라.

풀이

  1. 행 합 50, 50, 열 합 70, 30. 기대 도수 35, 15, 35, 15.
    \(R_iC_j/N\).
  2. \(G^2 = 2[40\log\frac{40}{35} + 10\log\frac{10}{15} + 30\log\frac{30}{35} + 20\log\frac{20}{15}] = 2[5.34 - 4.05 - 4.62 + 5.75] = 4.83\).
    자유도 1.
  3. \(\chi^2 = 2(25/35 + 25/15) = 4.76\). 둘 다 5% 임계값 3.84를 넘어 독립 모형을 기각하고, 남는 모형은 포화 모형(XY)입니다(이탈도 0).
    이탈도 차이 4.83 = XY 항의 검정.

검산

포화 모형의 XY 계수는 로그 오즈비 \(\log\frac{40 \times 20}{10 \times 30} = \log 2.67 = 0.98\)이고, 같은 자료를 로지스틱 회귀(호전 ~ 처리)로 맞춘 처리 계수와 같다. 두 방법의 이탈도 차이 검정도 같은 4.83이다.

의미

한 변수를 반응으로 볼 수 있으면 로지스틱 회귀가, 모든 변수를 대칭적으로 다루면 로그선형모형이 자연스럽지만, 두 모형은 같은 연관 구조를 다른 모습으로 쓴 것이다. \(G^2\)와 \(\chi^2\)가 비슷하면 근사가 잘 맞고, 기대 도수가 작아 둘이 크게 다르면 정확 검정을 고려한다.
