먼저 알아야 할 것
  • 로지스틱 모형 (3.1절), 응통15 3.2절 피셔 점수법.

최소제곱 대신 최대가능도

이진 자료의 가능도는 \(\prod\pi_i^{y_i}(1-\pi_i)^{1-y_i}\)입니다. 로그가능도를 \(\boldsymbol\beta\)에 대해 최대화하는 닫힌 꼴의 해가 없어 반복 계산(IRLS, 응통15 3.2절)으로 구합니다.

3.2.1적합

fit <- glm(am ~ wt + hp, family = binomial, data = mtcars)
summary(fit)          # Estimate, Std. Error, z value, Pr(>|z|)
exp(coef(fit))        # 오즈비
exp(confint(fit))     # 프로파일 가능도 구간(MASS)
predict(fit, newdata = data.frame(wt = 3, hp = 120), type = "response")

점수 방정식 \(X^\top(\mathbf y - \hat{\boldsymbol\pi}) = \mathbf 0\)은 "관측 성공 수와 예측 성공 수가 설명변수 방향마다 같다"는 뜻입니다. 계수의 공분산은 \((X^\top WX)^{-1}\), \(W = \mathrm{diag}(\hat\pi_i(1-\hat\pi_i))\)입니다.

3.2.2검정

  • 왈드: \(z = \hat\beta/\mathrm{se}\), 출력의 z value. 간단하지만 계수가 크거나 완전 분리(어떤 \(x\) 값 이상은 모두 1)에 가까우면 표준오차가 부풀어 믿기 어렵습니다.
  • 우도비: 두 겹친 모형의 이탈도 차 \(D_0 - D_1 \sim \chi^2_{df}\)(응통7 6.1절). R: anova(fit0, fit1, test = "Chisq"). 왈드보다 믿을 만합니다.
예제 3.2.1

위 모형의 결과를 해석하세요.

풀이. wt 계수 −8.08(오즈비 약 0.0003), hp 0.036(오즈비 약 1.04)입니다. 이 모형의 널 이탈도는 43.2, 모형 이탈도는 10.1입니다(3.3절 예제). 마력이 같다면 무거운 차일수록 수동 변속기일 오즈가 크게 줄고, 무게가 같다면 마력이 클수록 수동일 오즈가 조금씩 늘어납니다. 32대뿐이라 계수의 표준오차가 크다는 점도 함께 봅니다.

요약
  1. glm(family = binomial), IRLS로 최대가능도.
  2. 오즈비 \(e^{\hat\beta}\)와 구간.
  3. 왈드보다 우도비(이탈도 차) 검정.

3.2.3연습문제

기본

  1. 완전 분리가 일어나면 최대가능도 추정값은 어떻게 되나요?
    답

    계수를 키울수록 가능도가 계속 커져 추정값이 무한대로 발산하고, 소프트웨어는 매우 큰 계수와 표준오차를 냅니다. 벌점(피르스) 로지스틱 회귀 등으로 대처합니다.
