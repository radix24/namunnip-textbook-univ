이항·다항분포로 비율 추정하기

본문

신약 시험에서 20명 가운데 18명이 반응했다. 교과서의 공식 \(\hat\pi \pm 1.96\sqrt{\hat\pi(1 - \hat\pi)/n}\)으로 95% 신뢰구간을 구했더니 [0.769, 1.031]이 나왔다. 반응률이 103%일 수는 없다. 공식이 어디서 잘못된 것일까?

먼저 알아야 할 것근사 신뢰구간(응통7 4.2절)과 이산분포(응통6 4.1절)를 쓴다.

처음 질문의 답은 왈드 구간이 표준오차에 \(\pi\) 대신 \(\hat\pi\)를 넣고 정규 근사를 그대로 쓴다는 데 있다. 표본이 작고 \(\hat\pi\)가 1에 가까우면 이 근사가 무너져, 구간이 [0, 1] 밖으로 나가고 실제 덮임률도 95%에 크게 모자란다(그림 1). 찬성과 반대, 합격과 불합격, 혈액형처럼 결과가 범주인 자료에서는 각 범주의 비율이 모수이며, 범주가 둘이면 이항분포, 셋 이상이면 다항분포가 기본 모형이다.

1.1.1이항분포와 신뢰구간

\(n\)번의 독립 시행에서 성공 수가 \(Y \sim B(n, \pi)\)이면, 최대가능도 추정값은 \(\hat\pi = y/n\)이고 표준오차는 \(\sqrt{\pi(1 - \pi)/n}\)이다. 그런데 신뢰구간을 만드는 방법은 여럿이다(표 1).

표 1. 비율의 신뢰구간
구간식특징
왈드\(\hat\pi \pm z\sqrt{\hat\pi(1 - \hat\pi)/n}\)간단하지만 작은 \(n\)과 0, 1 근처에서 덮임률이 나쁨
윌슨(점수)\(|\hat\pi - \pi| \le z\sqrt{\pi(1 - \pi)/n}\)을 \(\pi\)에 대해 풂대부분 상황에서 덮임률이 좋음
클로퍼-피어슨(정확)이항 꼬리확률로 정의항상 신뢰수준 이상(보수적)

여기서 윌슨 구간은 표준오차에 미지의 \(\pi\)를 그대로 두고 부등식을 풀므로 [0, 1] 안에 머문다. 그 가운데는 \((y + z^2/2)/(n + z^2)\)으로, 95%이면 성공과 실패에 2씩 더한 비율에 가깝다. 이것이 아그레스티-쿨 구간의 생각이다.

예제 1.1.1

신약 시험 20명 가운데 18명이 반응했다. 왈드, 윌슨, 정확 95% 구간을 구하라.

풀이. \(\hat\pi = 0.9\)이다. 왈드 구간은 \(0.9 \pm 1.96\sqrt{0.09/20} = 0.9 \pm 0.131\), 곧 [0.769, 1.031]로 1을 넘는다. 하지만 윌슨 구간은 R의 prop.test(18, 20, correct = FALSE)$conf.int로 [0.699, 0.972]이며, [0, 1] 안이고 비대칭이다. 한편 정확 구간 binom.test(18, 20)은 [0.683, 0.988]로 조금 더 넓다.

1.1.2다항분포

범주 \(k\)개의 관측 수 \((n_1, \ldots, n_k)\)는 다항분포 \(P = \frac{n!}{\prod n_j!}\prod\pi_j^{n_j}\)를 따른다. 최대가능도 추정값은 라그랑주 승수법(응통1 5.3절)으로 구하며 \(\hat\pi_j = n_j/n\)이다. 따라서 각 \(\hat\pi_j\)는 주변적으로 이항이므로, 범주 하나의 비율에는 이항의 구간을 그대로 쓴다.

흔한 실수

20명 가운데 0명이 부작용을 보였다고 왈드 구간을 쓰면 [0, 0]이 되어 부작용이 전혀 없다고 결론 내리게 된다. 하지만 윌슨 구간은 [0, 0.16]이므로, 부작용률이 16%까지일 수 있다.

마무리

이항의 최대가능도 추정값은 \(\hat\pi = y/n\), 다항은 \(\hat\pi_j = n_j/n\)이다. 왈드 구간은 작은 표본과 0, 1 근처에서 덮임률이 크게 모자라므로 윌슨 구간을 기본으로 쓰고, 보수적인 보장이 필요하면 정확 구간을 쓴다.

1.1.3연습문제

기본

  1. 아그레스티-쿨 근사는 성공과 실패에 2씩 더한 \(\tilde\pi\)로 왈드 구간을 만든다. 예제 1.1.1에 적용하라.
    답

    \(\tilde\pi = 20/24 = 0.833\), \(\tilde n = 24\)이므로 \(0.833 \pm 1.96\sqrt{0.833 \times 0.167/24} = 0.833 \pm 0.149\), 곧 [0.684, 0.982]이다.

응용

  1. n = 20, π = 0.9일 때 왈드 구간과 윌슨 구간의 실제 덮임률은 그림 1에서 대략 얼마인가?
    답

    왈드는 약 0.88, 윌슨은 약 0.96이다. 명목 95%에 비해 왈드는 모자라고 윌슨은 조금 넘는다.

  2. 혈액형 A, B, O, AB가 각각 34, 27, 28, 11명인 자료에서 A형 비율의 추정값과 표준오차를 구하라.
    답

    \(n = 100\)이므로 \(\hat\pi_A = 0.34\)이고, 표준오차는 \(\sqrt{0.34 \times 0.66/100} = 0.047\)이다.
