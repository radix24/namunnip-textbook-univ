카파 통계량으로 일치도 재기

본문

의사 두 명이 엑스레이 100장을 정상과 비정상으로 판정해 90장에서 일치했다. 90%면 높아 보인다. 그런데 사진의 대부분이 정상이라면, 둘 다 아무렇게나 정상이라고만 해도 일치율이 높게 나온다. 우연히 맞은 몫을 빼고 나면 두 의사는 얼마나 일치하는 것일까?

먼저 알아야 할 것분할표(1.3절)를 쓴다.

처음 질문의 답은 코언의 카파이다. 두 사람이 서로 독립으로 판정했을 때의 우연 일치율을 계산해, 관측 일치율에서 그만큼을 뺀 몫으로 일치도를 잰다. 그래서 같은 일치율 90%라도 정상이 흔한 자료에서는 카파가 낮다(그림 1).

2.1.1코언의 카파

두 평가자의 판정을 \(k \times k\) 표로 정리한다. 관측 일치율은 \(p_o = \sum_i n_{ii}/n\)이고, 두 사람이 독립으로 판정했을 때의 우연 일치율은 \(p_e = \sum_i p_{i+}p_{+i}\)이다.

정의 2.1.1 (코언의 카파)

\(\kappa = \dfrac{p_o - p_e}{1 - p_e}\)이다.

즉 카파는 우연을 넘어설 수 있는 몫 \(1 - p_e\) 가운데 실제로 넘어선 몫의 비율이다. 그래서 1이면 완전 일치, 0이면 우연 수준, 음수면 우연보다 못하다. 관례적 해석(랜디스-코크)은 0.41~0.60 보통, 0.61~0.80 상당, 0.81 이상 거의 완전이다. 한편 경증, 중등, 중증처럼 순서가 있는 범주라면 멀리 어긋난 판정에 더 큰 벌점을 주는 가중 카파(2.3절)를 쓴다.

예제 2.1.2

두 의사의 판정이 (정, 정) 80, (정, 비) 5, (비, 정) 5, (비, 비) 10이다. 카파는 얼마인가?

풀이. \(p_o = 0.90\)이다. 주변 비율은 의사 A의 정상 0.85, B의 정상 0.85이므로 \(p_e = 0.85^2 + 0.15^2 = 0.745\)이다. 따라서 \(\kappa = (0.90 - 0.745)/0.255 = 0.61\)이다(그림 1). 즉 일치율은 90%이지만, 우연을 빼면 상당한 수준이다.

주의

카파는 범주의 유병률에 민감하다. 같은 판정 능력이라도 한 범주가 매우 흔하면 \(p_e\)가 커져 카파가 낮아지는데, 이것을 카파 역설이라 한다. 그러므로 일치율, 범주별 일치, 카파를 함께 보고한다.

마무리

코언의 카파 \(\kappa = (p_o - p_e)/(1 - p_e)\)는 우연 일치를 뺀 일치도이다. 1이면 완전, 0이면 우연 수준이며, 순서 범주에는 가중 카파를 쓴다. 유병률에 민감하므로 일치율과 함께 보고한다.

2.1.3연습문제

기본

  1. (정, 정) 45, (정, 비) 5, (비, 정) 5, (비, 비) 45이면 카파는 얼마인가?
    답

    \(p_o = 0.9\), \(p_e = 0.5\)이므로 \(\kappa = 0.8\)이다. 같은 일치율이라도 범주가 고르면 카파가 높다.

응용

  1. 두 평가자가 모두 동전을 던져 판정하고, 각자 정상 비율이 0.85이다. 기대되는 관측 일치율과 카파는 얼마인가?
    답

    독립이므로 \(p_o = p_e = 0.745\)이고 \(\kappa = 0\)이다. 일치율 74.5%도 우연만으로 나온다.

  2. (정, 정) 90, (정, 비) 5, (비, 정) 5, (비, 비) 0이면 카파는 얼마이고, 무엇을 뜻하는가?
    답

    \(p_o = 0.90\), \(p_e = 0.95^2 + 0.05^2 = 0.905\)이므로 \(\kappa = -0.05\)이다. 일치율 90%이지만 비정상을 한 번도 함께 찾지 못했으므로, 비정상 판정에서는 전혀 일치하지 않는다.
