카파 통계량으로 일치도 재기

본문
이 절에서 배울 것
  • 두 평가자의 일치도를 우연 일치를 뺀 코언 카파로 잰다.
  • 카파의 해석과 한계를 안다.
먼저 알아야 할 것
  • 분할표 (1.3절).

둘이 얼마나 같은 판정을 하나

의사 두 명이 엑스레이 100장을 정상/비정상으로 판정해 90장에서 일치했습니다. 90%는 높아 보이지만, 거의 모든 사진이 정상이라면 둘 다 아무렇게나 "정상"이라고만 해도 높은 일치율이 나옵니다.

2.1.1코언의 카파

두 평가자의 판정을 \(k\times k\) 표로 정리합니다. 관측 일치율 \(p_o = \sum_i n_{ii}/n\), 우연 일치율(두 사람이 독립으로 판정했을 때) \(p_e = \sum_i p_{i+}p_{+i}\).

정의 2.1.1

\(\kappa = \dfrac{p_o - p_e}{1 - p_e}\).

1이면 완전 일치, 0이면 우연 수준, 음수면 우연보다 못함. 관례적 해석(랜디스-코크): 0.41~0.60 보통, 0.61~0.80 상당, 0.81 이상 거의 완전. 순서 범주(경증·중등·중증)라면 멀리 어긋난 판정에 더 큰 벌점을 주는 가중 카파를 씁니다.

예제 2.1.2

두 의사의 판정(정상/비정상): (정,정) 80, (정,비) 5, (비,정) 5, (비,비) 10. 카파는?

풀이. \(p_o = 0.90\). 주변 비율: 의사 A 정상 0.85, B 정상 0.85. \(p_e = 0.85^2 + 0.15^2 = 0.745\). \(\kappa = (0.90 - 0.745)/(0.255) = 0.61\). 일치율 90%이지만 우연을 빼면 "상당한" 수준입니다.

주의 카파는 범주의 유병률에 민감합니다. 같은 판정 능력이라도 한 범주가 매우 흔하면 \(p_e\)가 커져 카파가 낮아집니다(카파 역설). 일치율, 범주별 일치, 카파를 함께 보고합니다.
요약
  1. \(\kappa = (p_o - p_e)/(1 - p_e)\), 우연 일치를 뺀 일치도.
  2. 순서 범주는 가중 카파.
  3. 유병률에 민감하므로 일치율과 함께 보고.

2.1.3연습문제

기본

  1. (정,정) 45, (정,비) 5, (비,정) 5, (비,비) 45이면 카파는?
    답

    \(p_o = 0.9\), \(p_e = 0.5\), \(\kappa = 0.8\). 같은 일치율이라도 범주가 고르면 카파가 높습니다.
