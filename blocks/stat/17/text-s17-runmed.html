이동 중위수로 계열 자료 평활하기

본문

매일의 측정값 3, 5, 4, 20, 6, 7, 6, 8에서 넷째 날 20은 기기 오류로 보인다. 흐름을 보려고 이웃 세 값의 평균으로 매끄럽게 했더니, 오류 하나가 사흘에 걸친 언덕이 되었다. 튀는 값을 퍼뜨리지 않고 흐름만 보는 방법은 없을까?

먼저 알아야 할 것저항성(1.2절)을 쓴다.

처음 질문의 답은 이웃 값의 평균 대신 중앙값을 쓰는 것이다. 평균은 값 하나에 끌려가지만 중앙값은 셋 가운데 가운데만 보므로, 홀로 튀는 값은 결과에 남지 않는다(그림 1). 매일의 확진자 수, 주가, 기온처럼 오르내림이 심한 계열은 이웃 값들로 매끄럽게 해야 흐름이 드러나는데, 그 방법을 고를 때 저항성이 중요하다.

5.1.1이동 평균과 이동 중위수

정의 5.1.1 (이동 중위수)

폭 3의 이동 중위수는 \(z_t = \mathrm{median}(y_{t-1}, y_t, y_{t+1})\)이다. 이동 평균은 중앙값 대신 평균을 쓴 것이다.

이동 평균은 튀는 값 하나를 이웃으로 번지게 한다. 한 값이 세 칸에 1/3씩 영향을 주기 때문이다. 하지만 이동 중위수는 튀는 값 하나를 완전히 지우고, 꺾임과 계단도 보존한다. 그런데 그 대가로 평평한 조각을 만든다.

예제 5.1.1

계열 3, 5, 4, 20, 6, 7, 6, 8에 폭 3 이동 중위수와 이동 평균을 적용하라. 끝값은 그대로 둔다.

풀이. 여기서 이동 중위수는 3, 4, 5, 6, 7, 6, 7, 8로, 튀는 값 20이 사라졌다. 하지만 이동 평균은 3, 4, 9.67, 10, 11, 6.33, 7, 8로, 20이 이웃 세 칸을 끌어올렸다(그림 1).

5.1.2반복 평활

터키는 간단한 평활을 조합했다. 먼저 3R은 폭 3 이동 중위수를 변화가 없을 때까지 반복한다. 다음으로 S는 두 점짜리 평평한 구간을 쪼갠다. 그리고 H, 곧 해닝은 가중치 1/4, 1/2, 1/4의 이동 평균으로 마무리해 계단을 부드럽게 한다. R에서는 smooth(x, kind = "3RS3R")과 runmed(x, k)를 쓴다. 한편 끝점은 이웃이 부족하므로 끝값을 그대로 두거나 외삽하는 규칙을 따로 쓴다.

주의

폭 3 이동 중위수는 홀로 튀는 값만 지운다. 그러므로 튀는 값이 두 개 이상 연속되면 그것이 중앙값이 되어 남으므로, 폭을 5로 늘려야 한다.

마무리

이동 평균은 매끄럽지만 튀는 값을 이웃으로 번지게 하고, 이동 중위수는 튀는 값을 지우고 계단을 보존한다. 터키의 반복 평활은 3R, S, 해닝을 조합해 두 방법의 장점을 취한다.

5.1.3연습문제

기본

  1. 폭 3 이동 중위수로 지울 수 없는 튀는 값의 패턴은 무엇인가?
    답

    연속된 두 개 이상의 튀는 값이다. 폭을 5로 늘려야 한다.

응용

  1. 예제의 이동 중위수 결과 3, 4, 5, 6, 7, 6, 7, 8에 해닝(1/4, 1/2, 1/4)을 적용하라. 끝값은 그대로 둔다.
    답

    3, 4, 5, 6, 6.5, 6.5, 7, 8이다.

  2. 계열 1, 1, 1, 9, 9, 9의 계단에 폭 3 이동 평균과 이동 중위수를 적용하면 어떻게 다른가?
    답

    이동 평균은 1, 1, 3.67, 6.33, 9, 9로 계단을 비스듬히 무너뜨리고, 이동 중위수는 1, 1, 1, 9, 9, 9로 계단을 그대로 보존한다.
