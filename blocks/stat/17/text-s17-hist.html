히스토그램의 구간 폭

본문
이 절에서 배울 것
  • 구간 폭과 시작점이 히스토그램의 모양을 바꾸는 방식을 안다.
  • 스터지스 규칙과 프리드먼-다이아코니스 규칙으로 구간을 정한다.
  • 여러 구간으로 그려 보며 모양의 특징을 확인하는 습관을 들인다.
먼저 알아야 할 것
  • 줄기-잎 그림 (2.1절), 다섯 숫자 요약과 IQR (2.2절).

같은 자료, 다른 그림

히스토그램은 가장 흔한 분포 그림이지만, 구간 폭을 바꾸면 봉우리가 생기거나 사라집니다. 폭이 너무 좁으면 우연한 들쭉날쭉이 구조처럼 보이고, 너무 넓으면 봉우리 두 개가 하나로 뭉개집니다. 응통12 6.3절의 커널 밀도추정에서 띠너비가 하는 역할과 같습니다.

2.4.1구간을 정하는 규칙

  • 스터지스: 구간 수 \(k = 1 + \log_2 n\). 정규분포를 기준으로 만든 규칙이라 표본이 크거나 치우친 자료에서는 구간이 너무 적습니다. R hist의 기본값입니다.
  • 프리드먼-다이아코니스: 구간 폭 \(h = 2\,\mathrm{IQR}\,n^{-1/3}\). IQR을 써서 이상값에 저항적이고, 표본이 커질수록 폭이 \(n^{-1/3}\)으로 좁아집니다. R: hist(x, breaks = "FD").
  • 스콧: \(h = 3.49\,s\,n^{-1/3}\). 표준편차를 써서 정규에 가까울 때 좋습니다.

\(n^{-1/3}\)은 구간 폭에 따른 치우침(폭이 넓으면 밀도의 굽은 부분을 평평하게 만듦)과 분산(폭이 좁으면 구간마다 관측이 적음)을 맞바꾼 최적의 속도입니다.

2.4.2시작점과 정수 자료

같은 폭이라도 구간의 시작점을 반 칸 옮기면 모양이 달라질 수 있습니다. 정수 자료(나이, 점수)는 구간 경계를 정수 사이(예: 9.5, 19.5)에 두어야 경계 위의 값이 어느 쪽에 들어가는지 헷갈리지 않습니다. 반올림된 자료에서 폭이 반올림 단위보다 좁으면 빈 구간과 꽉 찬 구간이 번갈아 나오는 빗살 모양이 생깁니다.

예제 2.4.1

IQR이 10인 자료에서 \(n = 50, 200, 1000\)일 때 스터지스 구간 수와 FD 구간 폭을 구하세요.

풀이. 스터지스: \(1 + \log_2 n\) = 6.6, 8.6, 11.0 → 7, 9, 11개. FD: \(20n^{-1/3}\) = 5.4, 3.4, 2.0. 범위가 60이라면 FD 구간 수는 약 11, 18, 30개로, 표본이 클 때 스터지스보다 훨씬 많은 구간을 씁니다.

요약
  1. 구간 폭과 시작점이 모양을 바꿉니다. 여러 폭으로 그려 확인합니다.
  2. 스터지스 \(1 + \log_2 n\)(구간 수), FD \(2\,\mathrm{IQR}\,n^{-1/3}\)(폭).
  3. 정수·반올림 자료는 경계를 단위 사이에 둡니다.

2.4.3연습문제

기본

  1. \(n = 8000\), IQR 4이면 FD 구간 폭은?
    답

    \(8000^{1/3} = 20\), \(h = 8/20 = 0.4\).

응용

  1. 소득 자료에서 상위 1%가 매우 커서 기본 히스토그램이 왼쪽 막대 하나로 보입니다. 어떻게 그리면 좋을까요?
    답

    로그 척도로 변환해 그리거나(3.1절), 상위 몇 %를 따로 표시하고 본체의 범위로 그립니다. 스터지스처럼 표준편차·범위에 기대는 규칙보다 IQR 기반 FD 폭이 본체를 더 잘 보여 줍니다.
