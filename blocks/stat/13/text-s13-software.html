설계부터 분석까지 코드로

실험의 랜덤화 순서를 손으로 정하면 실수하기 쉽고 기록이 남지 않습니다. 설계표를 코드로 만들고, 같은 표에 결과를 채워 분석하면 처음부터 끝까지 재현할 수 있습니다.

7.1.1설계표 만들기

# 2^3 요인계획, 반복 2, 실험 순서 랜덤화
d <- expand.grid(A = c(-1, 1), B = c(-1, 1), C = c(-1, 1), rep = 1:2)
set.seed(2026); d$run <- sample(nrow(d))
d <- d[order(d$run), ]
write.csv(d, "design.csv", row.names = FALSE)   # 현장에서 이 순서로 실험

랜덤화 블록이면 블록마다 따로 sample을 합니다. 일부실시법과 중심합성계획은 FrF2, rsm 패키지가 설계표를 만들어 줍니다.

7.1.2분석

d <- read.csv("design_with_y.csv")
fit <- lm(y ~ A * B * C, data = d)      # 모든 효과
anova(fit)
2 * coef(fit)[-1]                      # ±1 부호화이면 효과 = 2 × 계수
par(mfrow = c(2, 2)); plot(fit)        # 잔차 진단
with(d, interaction.plot(A, B, y))

±1 부호화에서 회귀계수는 효과의 절반입니다(5.1절의 효과는 −1에서 +1로 2단위 움직인 변화).

예제 7.1.1

랜덤화 블록 설계 자료(y, trt, block)를 분석하는 코드를 쓰세요.

fit <- aov(y ~ trt + block, data = d)   # 블록을 모형에 넣음
summary(fit)
TukeyHSD(fit, "trt")
요약
  1. 설계표와 랜덤화 순서를 코드로 만들고 저장.
  2. 설계 구조(블록, 요인, 교호작용)를 모형식에 그대로.
  3. ±1 부호화에서 효과 = 2 × 계수.
