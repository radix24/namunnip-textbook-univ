본문

실험 16번의 순서를 손으로 섞어 종이에 적었다가 잃어버렸다. 나중에 분석 결과가 이상할 때 실험 순서와 처리를 맞춰 볼 방법이 없다. 설계부터 분석까지 처음부터 끝까지 다시 할 수 있게 하려면 어떻게 해야 할까?

먼저 알아야 할 것이 과목 2~6단원의 설계와 분석을 쓴다.

실험의 랜덤화 순서를 손으로 정하면 실수하기 쉽고 기록이 남지 않는다. 처음 질문의 답은 설계표를 코드로 만들고, 같은 표에 결과를 채워 분석하는 것이다(그림 1). 그러면 난수 씨앗 하나로 배정과 순서를 언제든 다시 만들 수 있다.

7.1.1설계표 만들기

다음은 \(2^3\) 요인계획을 2번 반복하며 실험 순서를 랜덤화하는 R 코드이다.

# 2^3 요인계획, 반복 2, 실험 순서 랜덤화
d <- expand.grid(A = c(-1, 1), B = c(-1, 1), C = c(-1, 1), rep = 1:2)
set.seed(2026); d$run <- sample(nrow(d))
d <- d[order(d$run), ]
write.csv(d, "design.csv", row.names = FALSE)   # 현장에서 이 순서로 실험

랜덤화 블록이면 블록마다 따로 sample을 한다. 한편 일부실시법과 중심합성계획은 FrF2, rsm 패키지가 설계표를 만들어 준다.

7.1.2분석

결과를 채운 표를 읽어 모든 효과를 넣은 모형을 적합하고, 잔차와 교호작용을 그림으로 본다.

d <- read.csv("design_with_y.csv")
fit <- lm(y ~ A * B * C, data = d)      # 모든 효과
anova(fit)
2 * coef(fit)[-1]                      # ±1 부호화이면 효과 = 2 × 계수
par(mfrow = c(2, 2)); plot(fit)        # 잔차 진단
with(d, interaction.plot(A, B, y))

±1 부호화에서 회귀계수는 효과의 절반이다. 5.1절의 효과는 −1에서 +1로 2단위 움직일 때의 변화이기 때문이다. 그러므로 코드에서 계수에 2를 곱해 효과를 얻는다.

예제 7.1.1

랜덤화 블록 설계 자료(y, trt, block)를 분석하는 코드를 써라.

풀이. 설계 구조인 블록을 모형식에 그대로 넣고, 처리 쌍은 튜키 방법으로 비교한다.

fit <- aov(y ~ trt + block, data = d)   # 블록을 모형에 넣음
summary(fit)
TukeyHSD(fit, "trt")
마무리

설계표와 랜덤화 순서를 코드로 만들어 저장한다. 블록, 요인, 교호작용 같은 설계 구조는 모형식에 그대로 넣는다. ±1 부호화에서 효과는 계수의 두 배이다.

7.1.3연습문제

기본

  1. 블록을 빼고 aov(y ~ trt)로 분석하면 무엇이 달라지는가?
    답

    블록 변동이 오차에 섞여 MSE가 커지고 처리 F 값이 작아진다(3.1절 예제).

응용

  1. 7.1.1의 코드에서 set.seed(2026)을 빼면 어떤 문제가 생기는가?
    답

    코드를 다시 돌릴 때마다 실험 순서가 바뀌어, 저장한 design.csv와 코드가 만드는 설계표가 달라진다. 그러면 나중에 어느 순서로 실험했는지 코드로 재현할 수 없다.
