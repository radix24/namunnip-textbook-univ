  • 일원배치 모형 \(y_{ij} = \mu + \tau_i + \varepsilon_{ij}\)를 쓴다.
  • 분산분석표와 F 검정, 기대 평균제곱을 안다.
먼저 알아야 할 것
  • 응통5 5.1절의 일원 분산분석, F 분포 (응통6 6.1절).

완전 랜덤화 설계

처리 \(a\)개를 실험 단위에 완전히 무작위로 배정하는 가장 단순한 설계입니다. 응통5에서 계산법을 배웠고, 여기서는 모형과 그 근거를 정리합니다.

2.1.1모형

정의 2.1.1

\(y_{ij} = \mu + \tau_i + \varepsilon_{ij}\), \(i = 1, \ldots, a\), \(j = 1, \ldots, n\). \(\sum\tau_i = 0\), \(\varepsilon_{ij}\)는 독립 \(N(0, \sigma^2)\).

\(\tau_i\)는 처리 \(i\)의 효과(전체 평균에서 벗어난 정도)입니다. 추정량은 \(\hat\mu = \bar y_{\cdot\cdot}\), \(\hat\tau_i = \bar y_{i\cdot} - \bar y_{\cdot\cdot}\)입니다.

2.1.2기대 평균제곱

결과 2.1.2

\(E(\mathrm{MSE}) = \sigma^2\), \(E(\mathrm{MS}_{\text{처리}}) = \sigma^2 + \dfrac{n\sum\tau_i^2}{a-1}\).

\(H_0: \tau_1 = \cdots = \tau_a = 0\)이면 두 평균제곱이 같은 \(\sigma^2\)를 추정하므로 \(F = \mathrm{MS}_{\text{처리}}/\mathrm{MSE}\)가 1 근처이고, 효과가 있으면 분자만 커집니다. 처리 제곱합과 오차 제곱합이 독립인 카이제곱이라는 사실(코크란 정리)에서 \(F \sim F(a-1, a(n-1))\)이 나옵니다.

요인제곱합자유도평균제곱F
처리\(n\sum(\bar y_{i\cdot} - \bar y_{\cdot\cdot})^2\)\(a - 1\)\(\mathrm{SS}/(a-1)\)\(\mathrm{MS}_{\text{처리}}/\mathrm{MSE}\)
오차\(\sum\sum(y_{ij} - \bar y_{i\cdot})^2\)\(a(n-1)\)MSE
합계\(\sum\sum(y_{ij} - \bar y_{\cdot\cdot})^2\)\(an - 1\)
예제 2.1.3

R 내장 PlantGrowth(대조군과 처리 두 가지, 각 10개 식물의 무게)를 분석하세요.

풀이. summary(aov(weight ~ group, data = PlantGrowth)): 처리 제곱합 3.766(자유도 2), 오차 10.492(27), \(F = 4.85\), p값 0.016. 세 집단 평균(5.03, 4.66, 5.53)이 모두 같지는 않습니다. 어느 쌍이 다른지는 2.2절에서 봅니다.

요약
  1. \(y_{ij} = \mu + \tau_i + \varepsilon_{ij}\).
  2. \(E(\mathrm{MS}_{\text{처리}}) = \sigma^2 + n\sum\tau_i^2/(a-1)\), \(E(\mathrm{MSE}) = \sigma^2\).
  3. \(H_0\) 아래 \(F \sim F(a-1, a(n-1))\).
