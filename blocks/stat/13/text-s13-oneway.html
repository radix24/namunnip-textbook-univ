일원배치 분산분석

본문

식물 30그루를 무작위로 대조군과 두 처리에 10그루씩 나눠 키운 뒤 무게를 쟀다. 세 집단의 평균은 5.03, 4.66, 5.53으로 조금씩 다르다. 이 차이가 처리 때문일까, 아니면 식물마다 원래 다른 우연한 차이일까?

먼저 알아야 할 것일원 분산분석(응통5 5.1절)과 F 분포(응통6 6.2절)를 쓴다.

처음 질문의 답은 집단 평균 사이의 흩어짐을 집단 안의 흩어짐과 견주는 것이다(그림 1). 처리 \(a\)개를 실험 단위에 완전히 무작위로 배정하는 이 가장 단순한 설계를 완전 랜덤화 설계라 한다. 응통5에서 계산법을 배웠으므로, 여기서는 모형과 그 근거를 정리한다.

2.1.1모형

정의 2.1.1 (일원배치 모형)

\(y_{ij} = \mu + \tau_i + \varepsilon_{ij}\), \(i = 1, \ldots, a\), \(j = 1, \ldots, n\)이다. 여기서 \(\sum\tau_i = 0\)이고 \(\varepsilon_{ij}\)는 독립인 \(N(0, \sigma^2)\)이다.

\(\tau_i\)는 처리 \(i\)의 효과, 곧 전체 평균에서 벗어난 정도이다. 추정량은 \(\hat\mu = \bar y_{\cdot\cdot}\), \(\hat\tau_i = \bar y_{i\cdot} - \bar y_{\cdot\cdot}\)이다.

2.1.2기대 평균제곱

정리 2.1.1 (기대 평균제곱)

\(E(\mathrm{MSE}) = \sigma^2\)이고 \(E(\mathrm{MS}_{\text{처리}}) = \sigma^2 + n\sum\tau_i^2/(a-1)\)이다.

\(H_0: \tau_1 = \cdots = \tau_a = 0\)이면 두 평균제곱이 같은 \(\sigma^2\)를 추정하므로 \(F = \mathrm{MS}_{\text{처리}}/\mathrm{MSE}\)가 1 근처이다. 반면 효과가 있으면 분자만 커진다. 그리고 처리 제곱합과 오차 제곱합이 독립인 카이제곱이라는 코크란 정리에서 \(F \sim F(a-1,\, a(n-1))\)이 나온다. 계산은 표 1의 분산분석표로 정리한다.

표 1. 일원배치 분산분석표
요인제곱합자유도평균제곱F
처리\(n\sum(\bar y_{i\cdot} - \bar y_{\cdot\cdot})^2\)\(a - 1\)\(\mathrm{SS}/(a-1)\)\(\mathrm{MS}_{\text{처리}}/\mathrm{MSE}\)
오차\(\sum\sum(y_{ij} - \bar y_{i\cdot})^2\)\(a(n-1)\)MSE
합계\(\sum\sum(y_{ij} - \bar y_{\cdot\cdot})^2\)\(an - 1\)
예제 2.1.1

R 내장 자료 PlantGrowth(대조군과 처리 두 가지, 각 10그루의 무게)를 분석하라.

풀이. summary(aov(weight ~ group, data = PlantGrowth))로 계산하면 처리 제곱합은 3.766(자유도 2), 오차 제곱합은 10.492(자유도 27)이다. 그러므로 \(F = 4.85\), p값은 0.016이다(그림 1). 따라서 세 집단 평균 5.03, 4.66, 5.53이 모두 같지는 않다. 어느 쌍이 다른지는 2.3절에서 본다.

마무리

일원배치 모형은 \(y_{ij} = \mu + \tau_i + \varepsilon_{ij}\)이다. 기대 평균제곱은 \(E(\mathrm{MS}_{\text{처리}}) = \sigma^2 + n\sum\tau_i^2/(a-1)\), \(E(\mathrm{MSE}) = \sigma^2\)이므로 그 비가 F 검정이 된다. \(H_0\) 아래 \(F \sim F(a-1,\, a(n-1))\)이다.

2.1.3연습문제

기본

  1. 예제 2.1.1에서 MSE와 \(\sigma\)의 추정값은 얼마인가?
    답

    MSE는 \(10.492/27 = 0.389\)이고 \(\hat\sigma = 0.62\)이다.

응용

  1. 예제 2.1.1에서 \(\sum\hat\tau_i^2\)를 구하고, 기대 평균제곱으로 \(\mathrm{MS}_{\text{처리}}\)가 왜 MSE보다 큰지 설명하라.
    답

    \(\hat\tau = (-0.041, -0.412, 0.453)\)이라 \(\sum\hat\tau_i^2 = 0.377\)이고, \(n\sum\hat\tau_i^2 = 3.766\)이 처리 제곱합이다. \(\mathrm{MS}_{\text{처리}} = 1.883\)은 \(\sigma^2\)에 \(n\sum\tau_i^2/(a-1)\)이 더해진 양을 추정하므로, 효과가 있으면 MSE 0.389보다 커진다.
