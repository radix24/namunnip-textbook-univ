라틴방격 설계

본문

자동차 4대로 타이어 4종의 마모를 시험한다. 차마다 운전 습관이 다르고, 앞바퀴와 뒷바퀴, 왼쪽과 오른쪽의 마모도 다르다. 차와 바퀴 위치라는 두 방향의 차이를 모두 통제하면서도 타이어 16개만으로 실험할 수 있을까?

먼저 알아야 할 것랜덤화 블록 설계(3.1절)를 쓴다.

처음 질문의 답이 라틴방격이다. 각 타이어를 모든 차와 모든 위치에 정확히 한 번씩 놓으면, 차 차이와 위치 차이가 모든 타이어에 똑같이 퍼져 처리 비교에서 함께 빠진다(그림 1). 블록이 두 방향일 때 쓰는 설계이다.

3.2.1구조

정의 3.2.1 (라틴방격)

\(p\)개 처리를 \(p \times p\) 표에 배치해 각 처리가 모든 행과 모든 열에 정확히 한 번씩 나타나게 한 것을 \(p \times p\) 라틴방격이라 한다.

가장 간단한 표준형은 첫 행을 A B C D로 두고 다음 행마다 한 칸씩 밀어 B C D A, C D A B, D A B C로 만드는 것이다. 그러나 실제로는 표준형을 만든 뒤 행, 열, 처리 이름을 무작위로 섞어 쓴다. 이것이 라틴방격의 랜덤화이다.

3.2.2모형과 분석

모형은 \(y_{ijk} = \mu + \alpha_i + \beta_j + \tau_k + \varepsilon_{ijk}\)이고, \(i\)는 행, \(j\)는 열, \(k\)는 처리이다. 자유도는 행, 열, 처리가 각각 \(p - 1\), 오차가 \((p-1)(p-2)\)이다. 이때 세 요인 사이에 교호작용이 없다고 가정한다. 그런데 \(p\)가 작으면 오차 자유도가 너무 작아 오차 추정이 불안정하다. 예를 들어 3×3이면 오차 자유도가 2뿐이므로, 방격을 여러 개 반복한다.

예제 3.2.1

5×5 라틴방격의 오차 자유도는 얼마인가? 같은 실험을 차를 블록으로 한 랜덤화 블록 설계로 하면 어떻게 되는가?

풀이. 라틴방격의 오차 자유도는 \(4 \times 3 = 12\)이다. 반면 위치를 무시하고 차만 블록으로 쓰면 오차 자유도는 \((5-1)(5-1) = 16\)으로 크지만, 위치 차이가 오차에 섞여 MSE가 커진다. 그러므로 위치 효과가 크면 라틴방격이 유리하다.

마무리

라틴방격은 처리가 모든 행과 열에 한 번씩 나타나게 해 두 방향의 블록을 함께 통제한다. 오차 자유도는 \((p-1)(p-2)\)이고 교호작용이 없다고 가정한다. 작은 방격은 오차 추정이 불안정하므로 여러 개 반복한다.

3.2.3연습문제

기본

  1. 3×3 라틴방격을 하나 써라.
    답

    A B C / B C A / C A B가 한 예이다.

응용

  1. 3×3 라틴방격을 2개 반복하면 오차 자유도는 얼마인가? 두 방격의 행과 열이 서로 다르다고 하자.
    답

    관측은 18개, 전체 자유도는 17이다. 방격 1, 방격 안의 행 4(방격마다 2), 방격 안의 열 4, 처리 2를 빼면 오차 자유도는 \(17 - 1 - 4 - 4 - 2 = 6\)이다. 방격 하나일 때의 2보다 크게 늘어난다.
