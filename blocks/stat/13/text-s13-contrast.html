대비와 직교 대비

본문
이 절에서 배울 것
  • 대비를 정의하고 추정·검정한다.
  • 직교 대비로 처리 제곱합을 나눈다.
  • 양적 처리에서 다항 대비로 경향을 검정한다.
먼저 알아야 할 것
  • 일원배치 (2.1절), 다중 비교 (응통5 4.5절).

F 검정 다음에

F 검정이 기각되면 "어딘가 다르다"는 것만 압니다. 실험의 질문은 대개 더 구체적입니다. "두 처리의 평균이 대조군보다 높은가?", "비료량을 늘릴수록 수확이 직선으로 느는가?" 이런 질문은 실험 전에 세울 수 있고, 대비라는 하나의 도구로 답합니다.

2.2.1대비

정의 2.2.1

대비: \(\sum c_i = 0\)인 계수로 만든 \(L = \sum c_i\mu_i\). 추정량 \(\hat L = \sum c_i\bar y_{i\cdot}\), 분산 \(\sigma^2\sum c_i^2/n\)(처리마다 반복 \(n\)).

예: \(L = \mu_1 - \frac12(\mu_2 + \mu_3)\)은 "대조군과 두 처리 평균의 차". \(t = \hat L/\sqrt{\mathrm{MSE}\sum c_i^2/n}\)이 자유도 \(a(n-1)\)인 t를 따르고, 같은 검정을 대비 제곱합 \(\mathrm{SS}_L = \hat L^2/(\sum c_i^2/n)\)(자유도 1)의 F 검정으로도 할 수 있습니다(\(F = t^2\)). 계수 합이 0이라 전체 평균 \(\mu\)가 사라지므로, 대비는 처리 효과 \(\tau_i\)만의 함수입니다.

2.2.2직교 대비

두 대비의 계수 곱의 합이 0(\(\sum c_id_i = 0\))이면 직교라 합니다. 직교 대비의 추정량은 서로 무상관(정규면 독립)이고, 처리가 \(a\)개일 때 서로 직교하는 대비 \(a - 1\)개의 제곱합을 더하면 처리 제곱합이 정확히 나뉩니다. F 검정의 "어딘가 다르다"를 자유도 1짜리 질문 \(a - 1\)개로 쪼개는 셈입니다.

예제 2.2.2

PlantGrowth(대조군, 처리1, 처리2 각 10개)의 평균이 5.032, 4.661, 5.526, MSE 0.389입니다. 직교 대비 "대조군 대 두 처리"와 "처리1 대 처리2"로 처리 제곱합을 나누세요.

풀이. \(L_1 = (1, -\frac12, -\frac12)\): \(\hat L_1 = 5.032 - 5.094 = -0.062\), \(\mathrm{SS} = 0.0038/(1.5/10) = 0.026\). \(L_2 = (0, 1, -1)\): \(\hat L_2 = -0.865\), \(\mathrm{SS} = 0.748/(2/10) = 3.741\). 두 계수의 곱의 합 \(0 - \frac12 + \frac12 = 0\)으로 직교. 합 3.767이 처리 제곱합(3.766)과 같습니다. F 검정의 유의성(F = 4.85)은 거의 전부 두 처리 사이 차이(\(F = 3.741/0.389 = 9.6\))에서 왔고, 대조군과 처리 평균의 차이(\(F = 0.07\))는 없습니다.

2.2.3다항 대비

처리가 같은 간격의 양(비료 0, 10, 20 kg)이면 "직선 경향"과 "곡률"을 대비로 검정할 수 있습니다. 수준이 3개면 선형 \((-1, 0, 1)\), 이차 \((1, -2, 1)\), 4개면 선형 \((-3, -1, 1, 3)\), 이차 \((1, -1, -1, 1)\), 삼차 \((-1, 3, -3, 1)\)입니다. 서로 직교하며, 회귀(응통10 3.3절)로 다항식을 맞춘 것과 같은 정보를 줍니다. 선형 대비가 유의하고 이차가 유의하지 않으면 "용량에 비례해 늘어난다"고 말할 수 있습니다.

주의 대비는 자료를 보기 전에 정해야 개별 t 검정의 유의수준이 지켜집니다. 자료를 보고 가장 차이가 커 보이는 쌍을 골라 검정하면 오류율이 부풀므로, 그때는 2.3절의 다중 비교 방법(특히 셰페)을 씁니다.
요약
  1. 대비 \(\sum c_i\mu_i\) (\(\sum c_i = 0\)), 분산 \(\sigma^2\sum c_i^2/n\), 제곱합 \(\hat L^2/(\sum c_i^2/n)\).
  2. 직교 대비 \(a - 1\)개가 처리 제곱합을 정확히 나눕니다.
  3. 양적 처리는 다항 대비로 선형·곡률을 검정합니다.

2.2.4연습문제

기본

  1. 예제 2.2.2에서 \(L_1\)의 t 값은?
    답

    \(\sum c^2 = 1.5\), se \(= \sqrt{0.389 \times 1.5/10} = 0.242\), \(t = -0.062/0.242 = -0.26\). 대조군과 두 처리의 평균은 다르지 않습니다.

응용

  1. 비료 0, 10, 20 kg(각 \(n = 5\))의 평균 수확이 20, 26, 28, MSE 4입니다. 선형과 이차 대비를 검정하세요.
    답

    선형 \(\hat L = 28 - 20 = 8\), SS \(= 64/(2/5) = 160\), \(F = 40\). 이차 \(\hat L = 20 - 52 + 28 = -4\), SS \(= 16/(6/5) = 13.3\), \(F = 3.3\)(자유도 1, 12에서 5% 임계값 4.75). 직선 경향은 뚜렷하고, 증가가 둔해지는 곡률은 5% 수준에서 확인되지 않습니다.
