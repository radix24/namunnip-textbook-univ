대비와 직교 대비

본문

F 검정이 기각되면 세 처리 가운데 "어딘가 다르다"는 것만 안다. 그런데 실험의 질문은 대개 더 구체적이다. "두 처리의 평균이 대조군보다 높은가?", "비료를 늘릴수록 수확이 직선으로 느는가?" 이런 질문에는 어떻게 답할까?

먼저 알아야 할 것일원배치(2.1절)와 다중 비교(응통5 4.5절)를 쓴다.

처음 질문의 답은 대비이다. 이런 질문은 실험 전에 세울 수 있고, 평균들의 계수 합이 0인 선형결합 하나로 답한다. 또 서로 직교하는 대비들은 처리 제곱합을 정확히 나눠, F 검정의 "어딘가 다르다"를 구체적인 질문 몇 개로 쪼갠다(그림 1).

2.2.1대비

정의 2.2.1 (대비)

\(\sum c_i = 0\)인 계수로 만든 \(L = \sum c_i\mu_i\)를 대비라 한다. 처리마다 반복이 \(n\)이면 추정량은 \(\hat L = \sum c_i\bar y_{i\cdot}\), 분산은 \(\sigma^2\sum c_i^2/n\)이다.

예를 들어 \(L = \mu_1 - \tfrac12(\mu_2 + \mu_3)\)은 대조군과 두 처리 평균의 차이다. \(t = \hat L/\sqrt{\mathrm{MSE}\sum c_i^2/n}\)은 자유도 \(a(n-1)\)인 t 분포를 따른다. 같은 검정을 자유도 1인 대비 제곱합 \(\mathrm{SS}_L = \hat L^2/(\sum c_i^2/n)\)의 F 검정으로도 할 수 있고, 이때 \(F = t^2\)이다. 한편 계수 합이 0이라 전체 평균 \(\mu\)가 사라지므로, 대비는 처리 효과 \(\tau_i\)만의 함수이다.

2.2.2직교 대비

두 대비의 계수 곱의 합이 0, 곧 \(\sum c_i d_i = 0\)이면 직교라 한다. 직교 대비의 추정량은 서로 무상관이고, 정규분포라면 독립이다. 그리고 처리가 \(a\)개일 때 서로 직교하는 대비 \(a - 1\)개의 제곱합을 더하면 처리 제곱합이 정확히 나뉜다. 다시 말해 F 검정을 자유도 1짜리 질문 \(a - 1\)개로 쪼개는 셈이다.

예제 2.2.1

PlantGrowth(대조군, 처리1, 처리2 각 10개)의 평균이 5.032, 4.661, 5.526이고 MSE는 0.389이다. 직교 대비 "대조군 대 두 처리"와 "처리1 대 처리2"로 처리 제곱합을 나눠라.

풀이. \(L_1 = (1, -\tfrac12, -\tfrac12)\)이면 \(\hat L_1 = 5.032 - 5.094 = -0.062\)이고 \(\mathrm{SS} = 0.0038/(1.5/10) = 0.026\)이다. \(L_2 = (0, 1, -1)\)이면 \(\hat L_2 = -0.865\)이고 \(\mathrm{SS} = 0.748/(2/10) = 3.741\)이다. 계수 곱의 합이 \(0 - \tfrac12 + \tfrac12 = 0\)이므로 둘은 직교한다. 그러므로 합 3.767이 처리 제곱합 3.766과 같다(그림 1). 즉 F 검정의 유의성(F = 4.85)은 거의 전부 두 처리 사이 차이(\(F = 3.741/0.389 = 9.6\))에서 왔고, 대조군과 처리 평균의 차이(\(F = 0.07\))는 없다.

2.2.3다항 대비

처리가 비료 0, 10, 20 kg처럼 같은 간격의 양이면 직선 경향과 곡률을 대비로 검정할 수 있다. 수준이 3개면 선형 \((-1, 0, 1)\)과 이차 \((1, -2, 1)\)을 쓴다. 4개면 선형 \((-3, -1, 1, 3)\), 이차 \((1, -1, -1, 1)\), 삼차 \((-1, 3, -3, 1)\)이다. 이들은 서로 직교하며, 회귀(응통10 3.3절)로 다항식을 맞춘 것과 같은 정보를 준다. 따라서 선형 대비가 유의하고 이차가 유의하지 않으면 용량에 비례해 늘어난다고 말할 수 있다.

주의

대비는 자료를 보기 전에 정해야 개별 t 검정의 유의수준이 지켜진다. 자료를 보고 가장 차이가 커 보이는 쌍을 골라 검정하면 오류율이 부풀어 오르므로, 그때는 2.3절의 다중 비교 방법, 특히 셰페 방법을 쓴다.

마무리

대비는 \(\sum c_i = 0\)인 \(\sum c_i\mu_i\)이며, 분산은 \(\sigma^2\sum c_i^2/n\), 제곱합은 \(\hat L^2/(\sum c_i^2/n)\)이다. 직교 대비 \(a - 1\)개는 처리 제곱합을 정확히 나눈다. 양적 처리에서는 다항 대비로 직선 경향과 곡률을 검정한다.

2.2.4연습문제

기본

  1. 예제 2.2.1에서 \(L_1\)의 t 값은 얼마인가?
    답

    \(\sum c^2 = 1.5\)이므로 표준오차는 \(\sqrt{0.389 \times 1.5/10} = 0.242\)이고 \(t = -0.062/0.242 = -0.26\)이다. 대조군과 두 처리의 평균은 다르지 않다.

응용

  1. 비료 0, 10, 20 kg(각 \(n = 5\))의 평균 수확이 20, 26, 28이고 MSE는 4이다. 선형과 이차 대비를 검정하라.
    답

    선형은 \(\hat L = 28 - 20 = 8\), SS \(= 64/(2/5) = 160\), \(F = 40\)이다. 이차는 \(\hat L = 20 - 52 + 28 = -4\), SS \(= 16/(6/5) = 13.3\), \(F = 3.3\)이고, 자유도 1, 12에서 5% 임계값은 4.75이다. 그러므로 직선 경향은 뚜렷하지만, 증가가 둔해지는 곡률은 5% 수준에서 확인되지 않는다.
