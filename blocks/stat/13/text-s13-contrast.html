F 검정 다음에

F 검정이 기각되면 "어딘가 다르다"는 것만 압니다. 실험의 질문은 대개 더 구체적입니다. "두 처리의 평균이 대조군보다 높은가?", "어느 쌍이 다른가?"

2.2.1대비

정의 2.2.1

대비: \(\sum c_i = 0\)인 계수로 만든 \(L = \sum c_i\mu_i\). 추정량 \(\hat L = \sum c_i\bar y_{i\cdot}\), 분산 \(\sigma^2\sum c_i^2/n\).

예: \(L = \mu_1 - \frac12(\mu_2 + \mu_3)\)은 "대조군과 두 처리 평균의 차". \(t = \hat L/\sqrt{\mathrm{MSE}\sum c_i^2/n}\)이 자유도 \(a(n-1)\)인 t를 따릅니다. 두 대비의 계수 곱의 합이 0이면 직교 대비라 하고, 직교 대비 \(a - 1\)개의 제곱합을 더하면 처리 제곱합이 됩니다.

2.2.2다중 비교 방법

방법쓰는 경우임계값
본페로니미리 정한 비교 \(m\)개\(t_{\alpha/(2m)}\)
튜키(HSD)모든 쌍 비교스튜던트화 범위 분포 \(q_\alpha/\sqrt2\)
셰페자료를 본 뒤 고른 모든 대비\(\sqrt{(a-1)F_\alpha}\)
더닛각 처리를 대조군 하나와 비교전용 분포표

쌍 비교만 한다면 튜키가 셰페보다 좁은 구간을 줍니다. 셰페는 가장 보수적이지만 어떤 대비든 사후에 골라도 전체 오류율을 지킵니다.

예제 2.2.3

PlantGrowth에서 튜키 비교를 하세요.

풀이. TukeyHSD(aov(weight ~ group, data = PlantGrowth)): trt2 − trt1 = 0.865(조정 p값 0.012)만 유의하고, 처리와 대조군의 차이는 유의하지 않습니다(trt1 − ctrl = −0.37, 조정 p값 0.39; trt2 − ctrl = 0.49, 조정 p값 0.20). F 검정의 유의성은 두 처리 사이 차이에서 왔습니다.

요약
  1. 대비 \(\sum c_i\mu_i\) (\(\sum c_i = 0\)), 분산 \(\sigma^2\sum c_i^2/n\).
  2. 계획된 소수 비교: 본페로니. 모든 쌍: 튜키. 사후 임의 대비: 셰페.

2.2.3연습문제

기본

  1. 예제에서 대조군 대 두 처리 평균의 대비 추정값과 t 값은? (평균 5.032, 4.661, 5.526, MSE 0.389, \(n = 10\))
    답

    \(\hat L = 5.032 - 5.094 = -0.062\). \(\sum c^2 = 1.5\), se \(= \sqrt{0.389 \times 1.5/10} = 0.242\), \(t = -0.26\).
