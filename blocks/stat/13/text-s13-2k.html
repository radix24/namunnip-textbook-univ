많은 요인을 빠르게 걸러내기

공정에 영향을 줄 수 있는 요인이 다섯 개 있을 때, 각 요인을 낮음(−)과 높음(+) 두 수준으로만 두고 모든 조합을 실험하면 \(2^5 = 32\)번입니다. 어떤 요인이 중요한지 가려내는 초기 실험에 널리 씁니다.

5.1.1\(2^2\) 계획

요인 A, B. 처리는 \((1)\)(둘 다 낮음), \(a\), \(b\), \(ab\)로 적고, 각 처리 \(n\)회 반복의 합계도 같은 기호로 씁니다.

처리ABAB
(1)−−+
a+−−
b−+−
ab+++
정의 5.1.1

효과: 그 열의 + 처리 평균 − − 처리 평균. \(A = \frac{1}{2n}[a + ab - b - (1)]\), \(AB = \frac{1}{2n}[ab + (1) - a - b]\).

주효과 A는 "B를 평균했을 때 A를 낮음에서 높음으로 바꾸는 효과", 교호작용 AB는 "B가 높을 때의 A 효과 − B가 낮을 때의 A 효과"의 절반입니다. 열들은 서로 직교하므로 효과 추정값은 서로 독립이고, 각 제곱합은 \(\mathrm{SS} = n2^{k-2}\times\text{효과}^2\)입니다(\(k = 2\)이면 \(n \times \text{효과}^2\)).

5.1.2\(2^k\)로 일반화

부호표의 교호작용 열은 해당 주효과 열을 곱해 만듭니다(ABC = A × B × C). 효과 \(= \frac{1}{n2^{k-1}}\)(부호 × 합계의 합). 반복이 없으면 오차를 추정할 수 없어, 효과들의 정규 분위수 그림에서 직선에서 벗어난 큰 효과만 중요하다고 봅니다(5.2절).

예제 5.1.2

\(2^2\), \(n = 2\)에서 처리 합계 (1) = 40, a = 60, b = 48, ab = 84입니다. 효과를 구하세요.

풀이. \(A = (60 + 84 - 48 - 40)/4 = 14\). \(B = (48 + 84 - 60 - 40)/4 = 8\). \(AB = (84 + 40 - 60 - 48)/4 = 4\). B가 낮을 때 A 효과는 \((60 - 40)/2 = 10\), 높을 때 \((84 - 48)/2 = 18\), 차이의 절반이 4입니다.

요약
  1. 부호표: 교호작용 열 = 주효과 열의 곱.
  2. 효과 = (+ 평균) − (− 평균), 서로 직교.
  3. 반복이 없으면 정규 분위수 그림으로 중요한 효과를 고릅니다.
