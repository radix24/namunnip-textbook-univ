지수평활 예측

본문

상점의 재고 담당자가 수천 품목의 수요를 매주 예측해야 한다. 품목마다 ACF를 그려 ARIMA를 고를 시간은 없다. 최근 판매량에 무게를 더 두는 간단한 규칙 하나로 충분히 좋은 예측을 할 수는 없을까?

먼저 알아야 할 것ARIMA 예측(5.1절)과 확정적 추세와 확률적 추세(3.3절)를 쓴다.

처음 질문의 답은 지수평활이다. 새 관측이 들어올 때마다 지금까지의 수준을 새 관측 쪽으로 조금씩 옮기면, 최근 관측일수록 무게가 큰 가중 평균이 된다(그림 1). 이 방법은 간단하고 튼튼해서 품목이 많은 수요 예측에 널리 쓰인다.

5.2.1단순 지수평활

수준을 \(\ell_t = \alpha y_t + (1 - \alpha)\ell_{t-1}\)(\(0 < \alpha < 1\))로 갱신하고, 다음 예측을 \(\hat y_{t+1} = \ell_t\)로 둔다. 이 식을 풀어 쓰면 \(\ell_t = \alpha\sum_{j \ge 0}(1 - \alpha)^jy_{t-j}\)이므로, 과거 관측의 지수 가중 평균이다. 그래서 \(\alpha\)가 크면 최근 변화에 빨리 반응하고, 작으면 잡음을 더 많이 걸러 낸다. 이 방법은 추세나 계절이 없는 계열에 알맞으며, 먼 미래 예측도 모두 \(\ell_t\)로 같다.

5.2.2홀트와 홀트-윈터스

추세가 있으면 홀트 방법으로 수준과 기울기를 함께 갱신한다.

\[\ell_t = \alpha y_t + (1 - \alpha)(\ell_{t-1} + b_{t-1}), \qquad b_t = \beta(\ell_t - \ell_{t-1}) + (1 - \beta)b_{t-1}\]

이때 \(h\)기 앞 예측은 \(\ell_t + hb_t\)이다. 또 계절이 있으면 홀트-윈터스 방법으로 주기 \(m\)의 계절 성분 \(s_t\)를 더하거나(덧셈형) 곱해(곱셈형) 갱신하고, 예측에 같은 계절의 성분을 붙인다. 한편 추세가 영원히 이어지지 않도록 \(b\)를 \(\phi\)배씩 줄여 가는 감쇠 추세는 장기 예측이 과하게 치솟는 것을 막아 실무 성능이 좋은 편이다.

평활 모수는 한 걸음 앞 예측 오차의 제곱합을 최소로 하도록 추정한다. 가령 R의 forecast::ets(y)는 오차, 추세, 계절의 형태(ETS)를 정보기준으로 자동 선택한다.

5.2.3ARIMA와의 관계

단순 지수평활의 예측은 ARIMA(0,1,1) \(\nabla y_t = \varepsilon_t - (1 - \alpha)\varepsilon_{t-1}\)의 최적 예측과 같다. 마찬가지로 홀트 방법은 ARIMA(0,2,2)와 대응한다. 즉 지수평활은 확률적 추세를 가정한 모형이며, 상태공간 모형(7.1절)으로 쓸 수 있어 예측구간도 계산된다.

예제 5.2.1

판매량 100, 104, 99, 106, 110, 108에 \(\alpha = 0.3\), \(\ell_1 = 100\)으로 단순 지수평활을 하라.

풀이. \(\ell_2 = 0.3(104) + 0.7(100) = 101.2\), \(\ell_3 = 0.3(99) + 0.7(101.2) = 100.54\)이다. 같은 방식으로 \(\ell_4 = 102.18\), \(\ell_5 = 104.52\), \(\ell_6 = 0.3(108) + 0.7(104.52) = 105.57\)이므로 다음 기 예측은 105.6이다. 관측의 오르내림이 걸러져 수준이 완만하게 따라간다(그림 1).

마무리

단순 지수평활은 과거 관측의 지수 가중 평균이고, \(\alpha\)가 반응 속도를 정한다. 홀트는 추세를, 홀트-윈터스는 계절까지 갱신하며, 감쇠 추세가 장기 예측에 안전하다. 단순 지수평활은 ARIMA(0,1,1)의 예측과 같다.

5.2.4연습문제

기본

  1. \(\alpha = 0.3\)일 때 최근 관측, 1기 전, 2기 전 관측의 가중치는 얼마인가?
    답

    0.3, \(0.3 \times 0.7 = 0.21\), \(0.3 \times 0.49 = 0.147\)이다.

응용

  1. 추세가 있는 계열에 단순 지수평활을 쓰면 예측이 어떻게 되는가?
    답

    수준이 늘 실제보다 뒤처져, 증가 추세라면 예측이 체계적으로 낮게 나온다. 홀트 방법으로 추세를 함께 갱신한다.

  2. 홀트 방법에서 \(\ell_t = 120\), \(b_t = 3\)이면 4기 앞 예측은 얼마인가? 감쇠 계수 \(\phi = 0.8\)인 감쇠 추세라면?
    답

    홀트는 \(120 + 4 \times 3 = 132\)이다. 감쇠 추세는 \(120 + 3(0.8 + 0.64 + 0.512 + 0.4096) = 127.1\)이다.
