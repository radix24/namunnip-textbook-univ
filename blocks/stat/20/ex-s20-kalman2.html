정상 상태 이득과 지수평활 상수

예제 · 신호 대 잡음 비

먼저 읽는 법

칼만 필터를 오래 돌리면 \(P\)가 일정한 값에 수렴하고 이득도 일정해집니다. 그 고정점을 이차방정식으로 구해 지수평활 상수와 비교합니다.

문제. \(\sigma_\eta^2 = 1\), \(\sigma_\varepsilon^2 = 4\)(\(q = 0.25\))인 국소 수준 모형에서 정상 상태의 예측 분산 \(P^* = P_{t|t-1}\)과 이득 \(K^*\)를 구하세요. 예측 분산은 \(P^* = \frac{P^*\sigma_\varepsilon^2}{P^* + \sigma_\varepsilon^2} + \sigma_\eta^2\)을 만족합니다.

풀이

  1. \(P^* = \frac{4P^*}{P^* + 4} + 1\)을 정리하면 \(P^{*2} - P^* - 4 = 0\).
    양변에 \(P^* + 4\)를 곱함.
  2. \(P^* = (1 + \sqrt{17})/2 = 2.56\).
    양의 근.
  3. \(K^* = 2.56/(2.56 + 4) = 0.39\). 단순 지수평활 \(\alpha = 0.39\)와 같습니다.
    7.2.3절.

검산

예제 7.2.1에서 갱신 직후 \(P\)는 2.4, 2.10으로 줄었고, 예측 단계 \(P_{t|t-1}\)은 6에서 시작해 4.4로 \(P^* = 2.56\) 쪽으로 다가가고 있습니다. 결측이 없다면 몇 단계 안에 수렴합니다.

의미

지수평활의 평활 상수를 "감으로" 정하는 대신, 상태공간 모형에서 두 분산을 최대가능도로 추정하면 최적 \(\alpha\)가 자동으로 정해집니다. 측정이 부정확할수록(\(\sigma_\varepsilon^2\)가 클수록) 이득이 작아져 더 매끄럽게 평활합니다.
