ARIMA 적합과 차수 선택

본문

호르몬 측정값 48개의 ACF와 PACF를 보니 AR(1)도, AR(3)도, ARMA(1,1)도 그럴듯하다. 셋을 모두 적합하면 차수가 큰 모형일수록 자료에 더 잘 맞는다. 그렇다면 언제나 가장 큰 모형을 골라야 할까?

먼저 알아야 할 것식별(2.2절)과 정보기준(응통10 6.1절)을 쓴다.

처음 질문의 답은 아니다이다. 모수를 늘리면 가능도는 늘 커지지만, 늘어난 모수가 잡음까지 따라가 예측은 오히려 나빠질 수 있다. 그래서 가능도에 모수 개수의 벌점을 더한 정보기준으로 후보를 비교한다(그림 1). 박스-젠킨스 절차는 식별, 추정, 진단을 되풀이하며 모형을 다듬는다.

4.1.1추정

ARIMA는 정규 잡음을 가정한 최대가능도로 추정한다. 보통 조건부 제곱합으로 시작값을 구한 뒤 정확한 가능도로 마무리하며, R에서는 arima(x, order = c(p, d, q))를 쓴다. 출력에는 계수와 표준오차, \(\hat\sigma^2\), 로그가능도, AIC가 나온다. 이때 계수를 표준오차로 나눈 값이 2보다 작으면 그 항이 정말 필요한지 의심한다.

4.1.2차수 선택

후보마다 \(\mathrm{AIC} = -2\ell + 2k\)와 \(\mathrm{BIC} = -2\ell + k\log n\)을 구해 작은 것을 고른다. 여기서 \(k\)는 추정한 모수의 개수이다. 그런데 차분하면 자료 자체가 바뀌므로, 차분 횟수 \(d\)가 같은 모형끼리만 비교해야 한다. 한편 forecast::auto.arima는 단위근 검정으로 \(d\)를 먼저 정한 뒤 AIC로 \(p\)와 \(q\)를 단계적으로 찾는다. 정보기준의 차이가 작으면 더 간단한 모형을 고르는데, 이것을 절약의 원칙이라 한다.

예제 4.1.1

R의 lh(48개 호르몬 측정값)에 AR(1), AR(3), ARMA(1,1)을 적합해 비교하라.

sapply(list(c(1,0,0), c(3,0,0), c(1,0,1)), function(o) AIC(arima(lh, order = o)))
arima(lh, order = c(1, 0, 0))

풀이. AR(1)의 \(\hat\phi = 0.57\)(표준오차 0.12)이다. AIC는 AR(1) 64.8, AR(3) 64.2, ARMA(1,1) 65.5로 AR(3)이 조금 작다. 하지만 차이가 0.6뿐이고, \(n = 48\)에서 벌점이 더 큰 BIC는 AR(1)을 가장 작게 본다(그림 1). 따라서 더 간단한 AR(1)을 우선 후보로 두고, 잔차 진단(4.2절)으로 최종 결정한다.

흔한 오해

AIC가 가장 작은 모형이 참 모형이라고 믿기 쉽다. 그러나 AIC 차이가 2 안쪽이면 두 모형은 사실상 비슷하게 지지되므로, 해석과 예측이 쉬운 쪽을 고르고 진단으로 확인한다.

마무리

ARIMA는 최대가능도로 적합하고, 계수와 표준오차의 비로 항의 필요를 살핀다. 차분 횟수가 같은 후보끼리 AIC와 BIC로 비교하며, 차이가 작으면 단순한 모형을 고른다.

4.1.3연습문제

기본

  1. ARIMA(1,1,0)과 ARMA(2,0)의 AIC를 직접 비교해도 되는가?
    답

    안 된다. 차분 횟수가 달라, 가능도가 서로 다른 자료(차분 계열과 원계열)에서 계산되기 때문이다.

응용

  1. 로그가능도가 −29.4인 AR(1)(모수 3개, 절편과 \(\phi\)와 \(\sigma^2\))의 AIC를 구하라.
    답

    \(-2(-29.4) + 2 \times 3 = 64.8\)이다. 예제의 출력과 같다.

  2. \(n = 48\)에서 모수 하나를 더할 때 BIC의 벌점은 AIC의 벌점보다 얼마나 큰가?
    답

    BIC는 \(\log 48 = 3.87\), AIC는 2를 더하므로 약 1.9배이다. 그래서 BIC는 더 작은 모형을 고르는 경향이 있다.
