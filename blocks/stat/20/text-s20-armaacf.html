AR(1)과 MA(1)의 자기상관 유도

본문
이 절에서 배울 것
  • AR(p), MA(q), ARMA 모형을 정의한다.
  • AR(1)과 MA(1)의 ACF를 유도하고 정상·가역 조건을 안다.
먼저 알아야 할 것
  • 정상성과 ACF (1.2절).

과거로 현재를 설명하기

오늘 값이 어제 값에 비례해 정해지거나(자기회귀), 최근 며칠의 충격이 합쳐져 정해진다(이동평균)고 가정하면, 의존 구조를 모수 몇 개로 나타낼 수 있습니다.

2.1.1모형

AR(p): \(x_t = \phi_1x_{t-1} + \cdots + \phi_px_{t-p} + e_t\).

MA(q): \(x_t = e_t + \theta_1e_{t-1} + \cdots + \theta_qe_{t-q}\).

ARMA(p, q): 둘을 합친 것.

\(e_t\)는 백색잡음(분산 \(\sigma^2\)), 평균이 0이 아니면 \(x_t - \mu\)로 씁니다.

2.1.2AR(1)

정리 2.1.1

\(x_t = \phi x_{t-1} + e_t\)는 \(|\phi| < 1\)이면 정상이고 \(\gamma(0) = \dfrac{\sigma^2}{1-\phi^2}\), \(\rho(h) = \phi^{|h|}\).

정상이면 양변의 분산이 같아 \(\gamma(0) = \phi^2\gamma(0) + \sigma^2\)(\(e_t\)는 과거 \(x\)와 무상관), 곧 \(\gamma(0) = \sigma^2/(1-\phi^2)\)이고, 이것이 양수려면 \(|\phi| < 1\). 양변에 \(x_{t-h}\)를 곱해 기대값을 취하면(\(h \ge 1\)) \(\gamma(h) = \phi\gamma(h-1)\), 따라서 \(\rho(h) = \phi^h\). ∎

ACF가 기하급수적으로 줄어듭니다(\(\phi < 0\)이면 부호가 번갈아). 같은 절의 실습 카드에서 \(\phi\)를 바꿔 볼 수 있습니다.

2.1.3MA(1)

1.2절 예제처럼 \(\rho(1) = \dfrac{\theta}{1+\theta^2}\), \(\rho(h) = 0\)(\(h \ge 2\)). MA(1)은 언제나 정상이지만, \(\theta\)와 \(1/\theta\)가 같은 ACF를 주므로 \(|\theta| < 1\)(가역 조건)인 쪽을 택합니다. 가역이면 MA를 무한 AR로 쓸 수 있어 과거 관측으로 현재 충격을 되살릴 수 있습니다.

예제 2.1.2

\(\phi = 0.8\), \(\sigma^2 = 1\)인 AR(1)의 분산과 \(\rho(3)\)은?

풀이. \(\gamma(0) = 1/0.36 = 2.78\). \(\rho(3) = 0.512\). 잡음 분산이 1이어도 의존성 때문에 계열의 분산은 2.78로 커집니다.

요약
  1. AR(1): \(|\phi| < 1\)이면 정상, \(\rho(h) = \phi^h\).
  2. MA(1): \(\rho(1) = \theta/(1+\theta^2)\), 이후 0, 가역 \(|\theta| < 1\).
  3. 일반 AR(p) 정상 조건: 특성 다항식의 근이 단위원 밖.

2.1.4연습문제

기본

  1. MA(1)에서 \(\rho(1)\)의 최댓값은?
    답

    \(\theta/(1+\theta^2)\)은 \(\theta = 1\)에서 최대 0.5. MA(1)의 시차 1 상관은 ±0.5를 넘을 수 없습니다.
