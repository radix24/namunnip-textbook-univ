AR(1)과 MA(1)의 자기상관 유도

본문

오늘의 기온은 어제의 기온과 닮고, 그제와는 조금 덜 닮는다. 오늘 값이 어제 값에 비례해 정해진다고 가정하면, 사흘 전과의 상관은 얼마일까? 그리고 잡음의 분산이 1인데 계열 전체의 분산은 왜 그보다 커질까?

먼저 알아야 할 것정상성과 ACF(1.2절)를 쓴다.

처음 질문의 답은 \(\phi^3\)이다. 오늘 값이 어제 값의 \(\phi\)배에 새 충격을 더한 것이라면, 상관은 하루 멀어질 때마다 \(\phi\)배씩 줄어든다(그림 1). 또 과거의 충격이 계속 남아 쌓이므로 계열의 분산은 잡음의 분산보다 크다. 일반적으로 오늘 값이 어제 값에 비례하는 자기회귀(AR)나, 최근 며칠의 충격이 합쳐지는 이동평균(MA)을 가정하면 의존 구조를 모수 몇 개로 나타낼 수 있다.

2.1.1모형

AR(\(p\))는 \(x_t = \phi_1x_{t-1} + \cdots + \phi_px_{t-p} + e_t\)이고, MA(\(q\))는 \(x_t = e_t + \theta_1e_{t-1} + \cdots + \theta_qe_{t-q}\)이며, 둘을 합친 것이 ARMA(\(p, q\))이다. 여기서 \(e_t\)는 분산 \(\sigma^2\)인 백색잡음이고, 평균이 0이 아니면 \(x_t - \mu\)로 쓴다.

2.1.2AR(1)

정리 2.1.1 (AR(1)의 자기상관)

\(x_t = \phi x_{t-1} + e_t\)는 \(|\phi| < 1\)이면 정상이고, \(\gamma(0) = \dfrac{\sigma^2}{1 - \phi^2}\), \(\rho(h) = \phi^{|h|}\)이다.

증명. 정상이면 양변의 분산이 같고 \(e_t\)는 과거 \(x\)와 무상관이므로 \(\gamma(0) = \phi^2\gamma(0) + \sigma^2\), 곧 \(\gamma(0) = \sigma^2/(1 - \phi^2)\)이다. 이것이 양수려면 \(|\phi| < 1\)이어야 한다. 또 양변에 \(x_{t-h}\)를 곱해 기대값을 취하면(\(h \ge 1\)) \(\gamma(h) = \phi\gamma(h-1)\)이므로 \(\rho(h) = \phi^h\)이다. ∎

그래서 ACF가 기하급수적으로 줄어들고, \(\phi < 0\)이면 부호가 번갈아 나타난다(그림 1). 같은 절의 실습 카드에서 \(\phi\)를 바꿔 볼 수 있다.

2.1.3MA(1)

1.2절 예제와 같이 MA(1)은 \(\rho(1) = \dfrac{\theta}{1 + \theta^2}\)이고 \(h \ge 2\)이면 \(\rho(h) = 0\)이다. 즉 MA(1)은 언제나 정상이다. 그런데 \(\theta\)와 \(1/\theta\)가 같은 ACF를 주므로 \(|\theta| < 1\)인 쪽을 택하는데, 이것이 가역 조건이다. 가역이면 MA를 무한 AR로 쓸 수 있어, 과거 관측으로 현재의 충격을 되살릴 수 있다(2.3절).

예제 2.1.2

\(\phi = 0.8\), \(\sigma^2 = 1\)인 AR(1)의 분산과 \(\rho(3)\)을 구하라.

풀이. \(\gamma(0) = 1/0.36 = 2.78\)이고 \(\rho(3) = 0.8^3 = 0.512\)이다(그림 1). 즉 잡음의 분산이 1이어도 의존성 때문에 계열의 분산은 2.78로 커진다.

주의

\(\phi\)가 1에 가까울수록 \(\gamma(0) = \sigma^2/(1 - \phi^2)\)가 폭발하고 ACF가 아주 천천히 줄어, 랜덤워크(\(\phi = 1\))와 구별하기 어려워진다(3.2절).

마무리

AR(1)은 \(|\phi| < 1\)이면 정상이고 \(\rho(h) = \phi^h\), \(\gamma(0) = \sigma^2/(1 - \phi^2)\)이다. MA(1)은 \(\rho(1) = \theta/(1 + \theta^2)\)이고 그 뒤 0이며, 가역 조건은 \(|\theta| < 1\)이다. 일반 AR(\(p\))의 정상 조건은 특성 다항식의 근이 단위원 밖에 있는 것이다(2.3절).

2.1.4연습문제

기본

  1. MA(1)에서 \(\rho(1)\)의 최댓값은 얼마인가?
    답

    \(\theta/(1 + \theta^2)\)는 \(\theta = 1\)에서 최대 0.5이다. MA(1)의 시차 1 상관은 ±0.5를 넘을 수 없다.

응용

  1. AR(1)의 \(\rho(1) = 0.9\)이면 \(\rho(1)\)이 처음 0.5 아래로 떨어지는 시차는 얼마인가?
    답

    \(0.9^h < 0.5\)에서 \(h > \log 0.5/\log 0.9 = 6.6\)이므로 시차 7이다.

  2. \(\phi = -0.6\), \(\sigma^2 = 2\)인 AR(1)의 분산과 \(\rho(2)\)를 구하라.
    답

    \(\gamma(0) = 2/0.64 = 3.125\), \(\rho(2) = 0.36\)이다.
