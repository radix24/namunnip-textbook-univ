시간 순서가 있는 자료

지금까지는 관측들이 서로 독립이라고 가정했습니다. 월별 매출, 일별 기온, 분기 GDP는 어제가 오늘과 닮고, 매년 같은 달이 비슷합니다. 이 의존성이 분석의 장애물이자 예측의 재료입니다.

1.1.1네 가지 구성 요소

추세: 장기적으로 오르거나 내리는 흐름.

계절성: 정해진 주기(1년, 1주, 하루)로 되풀이되는 무늬.

순환: 주기가 일정하지 않은 장기 오르내림(경기 순환).

불규칙 변동: 나머지 우연한 변동.

1.1.2분해

가법 모형 \(y_t = T_t + S_t + E_t\)는 계절 진폭이 일정할 때, 승법 모형 \(y_t = T_t\times S_t\times E_t\)는 수준이 커질수록 계절 진폭도 커질 때 씁니다. 승법은 로그를 취하면 가법이 됩니다. 고전적 분해: (1) 주기 길이의 중심 이동평균으로 추세를 구하고, (2) 추세를 뺀(나눈) 값을 달마다 평균해 계절 성분을 구하고, (3) 나머지가 불규칙 성분입니다. 더 유연한 방법으로 STL(국소 회귀 기반)이 있습니다.

예제 1.1.1

R의 AirPassengers를 분해하세요.

plot(AirPassengers)
plot(decompose(AirPassengers, type = "multiplicative"))
plot(stl(log(AirPassengers), s.window = "periodic"))

뚜렷한 증가 추세, 여름(7~8월)에 높은 연간 계절성이 있고, 계절 진폭이 해마다 커지므로 승법(또는 로그 가법)이 알맞습니다. decompose의 7월 계절 지수는 1.227(평균보다 약 23% 많음), 11월은 0.801입니다.

요약
  1. 추세, 계절성, 순환, 불규칙.
  2. 진폭 일정 → 가법, 비례 → 승법(로그).
  3. 이동평균 분해, STL.
