계절형 ARIMA 모형

  • 계절형 ARIMA(p,d,q)(P,D,Q)s의 구조를 이해한다.
  • 항공 모형을 적합하고 예측한다.
먼저 알아야 할 것
  • 차분 (3.1절), ARIMA 적합 (4.1절).

해마다의 의존성도 모형에

월별 자료는 지난달뿐 아니라 작년 같은 달과도 닮습니다. 계절형 ARIMA는 짧은 시차의 ARMA 구조와 계절 시차(\(s, 2s, \ldots\))의 ARMA 구조를 곱해 둘 다 담습니다.

6.1.1구조

후진 연산자 \(Bx_t = x_{t-1}\)으로 쓰면 ARIMA(p,d,q)(P,D,Q)s는

\[\Phi_P(B^s)\phi_p(B)(1-B)^d(1-B^s)^Dx_t = \Theta_Q(B^s)\theta_q(B)e_t.\]

소문자는 짧은 시차, 대문자는 계절 시차 다항식입니다. 계절 차분 \(D\)는 보통 1 이하. 식별은 ACF·PACF의 계절 시차(12, 24, …)에서 같은 절단·감소 규칙을 적용합니다.

6.1.2항공 모형

ARIMA(0,1,1)(0,1,1)12: \((1-B)(1-B^{12})\log y_t = (1 + \theta B)(1 + \Theta B^{12})e_t\). 모수 두 개로 추세와 계절성이 함께 변하는 많은 월별 자료를 잘 설명해, 박스와 젠킨스의 항공 승객 분석 이후 기준 모형으로 쓰입니다.

예제 6.1.1

AirPassengers에 항공 모형을 적합하고 2년을 예측하세요.

fit <- arima(log(AirPassengers), order = c(0, 1, 1),
             seasonal = list(order = c(0, 1, 1), period = 12))
fit                                   # ma1 약 −0.40, sma1 약 −0.56
p <- predict(fit, n.ahead = 24)
ts.plot(AirPassengers, exp(p$pred), exp(p$pred + 1.96 * p$se), exp(p$pred - 1.96 * p$se), lty = c(1, 1, 2, 2))

로그 척도에서 예측하고 지수로 되돌렸으므로 점예측은 중앙값에 해당하고 구간은 비대칭입니다. 계수는 ma1 = −0.40, sma1 = −0.56입니다.

요약
  1. 짧은 시차 × 계절 시차 다항식의 곱.
  2. 계절 시차의 ACF·PACF로 P, Q 식별.
  3. 항공 모형은 월별 자료의 기준 모형.

6.1.2연습문제

기본

  1. 분기 자료의 계절 주기 \(s\)는? ARIMA(1,0,0)(1,0,0)4를 전개하면 어떤 시차가 나오나요?
    답

    \(s = 4\). \((1 - \phi B)(1 - \Phi B^4)x_t = e_t\)이라 시차 1, 4, 5가 나옵니다(5는 곱의 교차항).
