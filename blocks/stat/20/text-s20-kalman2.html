칼만 필터로 결측값 처리와 평활

본문
이 절에서 배울 것
  • 관측이 빠진 시점에 칼만 필터가 예측 단계만 하는 원리를 안다.
  • 필터(과거까지의 정보)와 평활(전체 정보)의 차이를 안다.
  • 신호 대 잡음 비가 칼만 이득을 정하는 방식을 이해한다.
먼저 알아야 할 것
  • 국소 수준 모형과 칼만 필터 (7.1절).

빠진 날의 수준은

센서가 고장 난 날, 휴일로 자료가 없는 날에도 숨은 수준은 계속 움직입니다. ARIMA는 결측이 있으면 다루기 번거롭지만, 상태공간 모형은 칼만 필터의 구조 덕분에 결측을 자연스럽게 처리합니다.

7.2.1결측 시점의 처리

국소 수준 모형 \(y_t = \mu_t + \varepsilon_t\)(분산 \(\sigma_\varepsilon^2\)), \(\mu_t = \mu_{t-1} + \eta_t\)(분산 \(\sigma_\eta^2\))에서 칼만 필터는 매 시점

  1. 예측: \(a_{t|t-1} = a_{t-1}\), \(P_{t|t-1} = P_{t-1} + \sigma_\eta^2\).
  2. 갱신: \(K_t = P_{t|t-1}/(P_{t|t-1} + \sigma_\varepsilon^2)\), \(a_t = a_{t|t-1} + K_t(y_t - a_{t|t-1})\), \(P_t = (1 - K_t)P_{t|t-1}\).

관측이 없으면 갱신 단계를 건너뜁니다. 수준 추정은 그대로 두고 불확실성 \(P\)만 \(\sigma_\eta^2\)만큼 커집니다. 연속으로 빠지면 \(P\)가 계속 커져, 다음 관측이 들어올 때 이득 \(K\)가 커서 그 관측을 크게 반영합니다. 결측 구간을 따로 메울 필요 없이 가능도도 그대로 계산되어 모수 추정에 쓸 수 있습니다.

7.2.2평활

필터 \(a_t\)는 시점 \(t\)까지의 자료만 쓴 추정입니다. 과거를 돌아보는 분석에서는 그 뒤의 자료도 쓸 수 있으므로, 마지막 시점에서 거꾸로 돌아오며 필터 추정을 고치는 칼만 평활을 씁니다. 평활 추정의 분산은 필터 분산보다 작거나 같고, 결측 시점의 평활값은 앞뒤 관측을 모두 써서 보간한 값이 됩니다. R: KFAS, StructTS 뒤 tsSmooth.

7.2.3신호 대 잡음 비

정상 상태의 이득은 \(q = \sigma_\eta^2/\sigma_\varepsilon^2\)로 정해집니다. \(q\)가 크면(수준이 많이 움직이고 측정이 정확) 새 관측을 크게 믿고, 작으면 과거 추정을 더 믿어 매끄럽게 따라갑니다. 국소 수준 모형의 정상 상태 칼만 필터는 단순 지수평활(5.2절)과 같고, 평활 상수 \(\alpha\)가 정상 상태 이득 \(K\)입니다.

예제 7.2.1

\(\sigma_\eta^2 = 1\), \(\sigma_\varepsilon^2 = 4\), 시작 \(a_0 = 10\), \(P_0 = 5\)입니다. 관측 12, (결측), 15에 칼만 필터를 적용하세요.

풀이. \(t = 1\): \(P = 6\), \(K = 0.6\), \(a = 10 + 0.6(2) = 11.2\), \(P = 2.4\). \(t = 2\)(결측): \(a = 11.2\) 그대로, \(P = 3.4\). \(t = 3\): \(P = 4.4\), \(K = 4.4/8.4 = 0.524\), \(a = 11.2 + 0.524(3.8) = 13.19\), \(P = 2.10\). 결측 뒤라 이득이 커져 새 관측 15를 더 크게 반영했습니다.

요약
  1. 결측 시점: 예측만 하고 갱신은 건너뜀, \(P\)가 커짐.
  2. 평활은 전체 자료로 거꾸로 고친 추정, 결측의 보간.
  3. 신호 대 잡음 비가 이득을 정하고, 국소 수준 모형은 지수평활과 같음.

7.2.4연습문제

기본

  1. 예제에서 \(t = 2, 3\)이 연속으로 결측이고 \(t = 4\)에 관측이 들어온다면, \(t = 4\)의 예측 분산 \(P_{4|3}\)은?
    답

    \(t = 1\) 갱신 뒤 2.4에서 시점마다 1씩 더해 3.4(\(t = 2\)), 4.4(\(t = 3\)), 5.4(\(t = 4\)의 예측). 이득은 \(5.4/9.4 = 0.57\)로 커집니다.

응용

  1. \(\sigma_\eta^2 = 0\)이면 칼만 필터는 무엇을 계산하나요?
    답

    수준이 변하지 않는 상수라 \(P\)가 계속 줄고 이득이 \(1/t\)처럼 작아져, 지금까지 관측의 표본평균(사전 정보와 결합한 값)을 계산합니다.
