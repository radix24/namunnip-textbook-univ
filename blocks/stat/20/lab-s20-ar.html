오늘이 내일을 얼마나 닮는가: AR(1)과 자기상관

실습 · 시계열

목표

계수 \(\varphi\)를 바꾸며 AR(1) 과정의 가상 시계열을 만들고, 표본 자기상관함수가 이론값 \(\varphi^k\)를 따르는지 확인합니다. \(\varphi = 1\)(랜덤워크)에서 무엇이 달라지는지도 봅니다. 성취기준 [응통20-02-02].

AR(1) 과정: \(x_t = \varphi x_{t-1} + e_t\). \(e_t\)는 서로 독립인 \(N(0, 1)\) 잡음(백색잡음)입니다. \(|\varphi| < 1\)이면 정상 과정입니다.

자기상관: 시차 \(k\)만큼 떨어진 두 값의 상관계수 \(\rho_k = \mathrm{Corr}(x_t, x_{t-k})\). AR(1)이면 \(\rho_k = \varphi^k\)입니다.

표본 자기상관: \(r_k = \dfrac{\sum_{t=k+1}^{n}(x_t - \bar x)(x_{t-k} - \bar x)}{\sum_{t=1}^{n}(x_t - \bar x)^2}\).

준비

위 그림은 시계열, 아래 그림은 시차 0~20의 표본 자기상관(파란 막대)과 이론값 \(\varphi^k\)(빨간 점선)입니다. 주황 점선 \(\pm 2/\sqrt n\)은 백색잡음일 때 \(r_k\)가 대부분 들어가는 범위입니다. "새 자료"는 같은 \(\varphi\)로 잡음을 새로 뽑습니다.

절차

  1. \(\varphi = 0\)에서 시계열과 자기상관 막대를 봅니다. 백색잡음입니다.
  2. \(\varphi = 0.7\), 0.95로 올리며 시계열이 어떻게 매끄러워지는지, 막대가 얼마나 천천히 줄어드는지 봅니다.
  3. \(\varphi = -0.7\)로 바꿔 막대의 부호가 어떻게 바뀌는지 봅니다.
  4. \(\varphi = 1\)로 두고 "새 자료"를 여러 번 누릅니다.

기대 결과

  • \(\varphi = 0\): 시계열이 0 둘레에서 마구 오르내리고, 시차 1 이상의 막대 대부분(20개 중 19개 정도)이 주황 점선 안에 듭니다.
  • \(\varphi = 0.7\): 막대가 이론값 \(0.7, 0.49, \ldots\)(\(k = 5\)이면 0.17)을 따라 기하급수적으로 줄어듭니다. 길이 200이면 \(r_1\)은 ±0.05 안팎으로 맞지만 시차가 클수록 더 흔들려 \(r_5\)는 0.15 가까이 벗어나기도 합니다. 0.95에서는 시계열이 긴 물결처럼 보이고 막대가 아주 천천히 줄어듭니다.
  • \(\varphi = -0.7\): 시계열이 매번 부호를 바꾸며 지그재그하고, 막대도 \(-0.7, 0.49, -0.34, \ldots\)처럼 부호가 번갈아 바뀝니다.
  • \(\varphi = 1\): 랜덤워크가 되어 평균으로 돌아오지 않고 멀리 떠돕니다. 새 자료마다 모양이 전혀 다르고, 표본 자기상관은 시차 20까지도 크게 남습니다. 정상 과정이 아니므로 차분 \(x_t - x_{t-1}\)을 해서 분석합니다(20-03단원).

분석

  1. \(\rho_1 = \varphi\)를 \(\mathrm{Cov}(x_t, x_{t-1}) = \mathrm{Cov}(\varphi x_{t-1} + e_t, x_{t-1})\)에서 유도해 보세요.
  2. MA(1) 과정 \(x_t = e_t + \theta e_{t-1}\)의 자기상관은 시차 2부터 0입니다. 자기상관 그림만 보고 AR(1)과 MA(1)을 어떻게 구별할지 적어 보세요.
