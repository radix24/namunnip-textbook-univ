본문

  • 차분과 계절 차분으로 추세와 계절성을 없앤다.
  • ARIMA(p, d, q)의 뜻을 안다.
먼저 알아야 할 것
  • 정상성 (1.2절).

변화량은 정상일 수 있다

주가 수준은 정상이 아니지만 하루 변화량(수익률)은 대개 정상에 가깝습니다. 비정상 계열을 다루는 가장 간단한 방법은 이웃한 값의 차이를 보는 것입니다.

3.1.1차분

정의 3.1.1

1차 차분: \(\nabla x_t = x_t - x_{t-1}\).

계절 차분(주기 \(s\)): \(\nabla_s x_t = x_t - x_{t-s}\).

선형 추세 \(a + bt\)는 1차 차분으로 상수 \(b\)가 되고, 이차 추세는 2차 차분으로 없앱니다. 월별 계절성은 \(\nabla_{12}\)로 없앱니다. 너무 많이 차분하면(과차분) 불필요한 음의 자기상관(MA 구조)이 생기고 분산이 커지므로, 보통 \(d \le 2\)입니다.

3.1.2ARIMA

정의 3.1.2

\(\nabla^dx_t\)가 ARMA(p, q)이면 \(x_t\)는 ARIMA(p, d, q). "I"는 적분(차분의 역)을 뜻한다.

로그를 취하고 차분한 \(\nabla\log x_t \approx\) 증가율은 경제 자료에서 자주 쓰는 변환입니다.

예제 3.1.1

AirPassengers를 정상으로 만드는 변환을 고르세요.

y <- log(AirPassengers)
plot(diff(y))             # 추세는 사라졌지만 계절 무늬가 남음
plot(diff(diff(y), 12))   # 계절 차분까지: 정상에 가까움
acf(diff(diff(y), 12))

로그 → 1차 차분 → 계절 차분으로 거의 정상이 됩니다. 이 계열에 맞춘 ARIMA(0,1,1)(0,1,1)12가 유명한 "항공 모형"입니다(6.1절).

요약
  1. 차분 \(\nabla\)로 추세, 계절 차분 \(\nabla_s\)로 계절성 제거.
  2. ARIMA(p, d, q) = \(d\)번 차분한 ARMA.
  3. 과차분을 피함.

3.1.2연습문제

기본

  1. 백색잡음 \(e_t\)를 차분하면 \(\nabla e_t\)의 \(\rho(1)\)은?
    답

    \(\nabla e_t = e_t - e_{t-1}\)은 \(\theta = -1\)인 MA(1), \(\rho(1) = -0.5\). 과차분의 지문입니다.
