상태공간 모형과 칼만 필터

본문

여론조사 지지율은 진짜 지지율에 표본 오차가 더해진 값이다. 게다가 진짜 지지율도 주마다 조금씩 움직인다. 지난주 추정이 40%였는데 이번 주 조사가 46%로 나왔다면, 진짜 지지율을 얼마로 보아야 할까?

먼저 알아야 할 것다변량 정규의 조건부분포(응통6 5.4절)를 쓴다. 베이즈 갱신(응통21)을 알면 도움이 된다.

처음 질문의 답은 40과 46 사이의 가중평균이다. 관측에는 잡음이 있고 참값은 숨어서 변하므로, 지난 추정과 새 관측을 각각의 불확실성에 따라 섞어야 한다. 관측이 올 때마다 이렇게 참값의 추정을 갱신하는 방법이 칼만 필터이다(그림 1).

7.1.1국소 수준 모형

관측식과 상태식 두 개로 이루어진 다음 모형을 생각하자.

\[y_t = \mu_t + \varepsilon_t, \quad \varepsilon_t \sim N(0, \sigma_\varepsilon^2), \qquad \mu_t = \mu_{t-1} + \eta_t, \quad \eta_t \sim N(0, \sigma_\eta^2)\]

여기서 숨은 수준 \(\mu_t\)는 랜덤워크로 움직이고, 우리는 잡음 섞인 \(y_t\)만 본다. 일반적인 상태공간 모형은 이것을 행렬로 넓혀 추세, 계절, 회귀 효과, ARIMA까지 모두 담는다.

7.1.2칼만 필터

시점 \(t-1\)까지의 관측으로 \(\mu_{t-1} \sim N(m_{t-1}, P_{t-1})\)이라 하자. 먼저 예측 단계에서 \(\mu_t\)의 예측 평균은 \(m_{t-1}\), 예측 분산은 \(P_{t-1} + \sigma_\eta^2\)이다. 상태가 움직이므로 불확실성이 커진다. 다음으로 갱신 단계에서 새 관측 \(y_t\)가 오면 다음과 같이 고친다.

\[K_t = \frac{P_{t-1} + \sigma_\eta^2}{P_{t-1} + \sigma_\eta^2 + \sigma_\varepsilon^2}, \qquad m_t = m_{t-1} + K_t(y_t - m_{t-1}), \qquad P_t = (1 - K_t)(P_{t-1} + \sigma_\eta^2)\]

즉 새 추정은 예측과 관측의 가중평균이고, 가중치인 칼만 이득 \(K_t\)는 상대적 불확실성으로 정해진다. 그래서 관측 잡음이 크면 관측을 덜 믿고(\(K\)가 작음), 상태 변화가 크면 관측을 더 믿는다. 정규 가정 아래 이것은 정확한 베이즈 갱신(응통6 5.4절의 조건부분포)이며, 시간이 지나면 \(K_t\)가 일정해져 지수평활(5.2절)과 같아진다.

예제 7.1.1

\(m_{t-1} = 40\), \(P_{t-1} = 3\), \(\sigma_\eta^2 = 1\), \(\sigma_\varepsilon^2 = 4\)이고 새 여론조사가 \(y_t = 46\)이면 갱신된 추정은 얼마인가?

풀이. 예측 분산이 4이므로 \(K = 4/8 = 0.5\)이다. 따라서 \(m_t = 40 + 0.5 \times 6 = 43\), \(P_t = 0.5 \times 4 = 2\)이다. 조사 결과 46을 그대로 믿지 않고 이전 추정과 반반 섞은 셈이며, 불확실성은 4에서 2로 줄었다.

fit <- StructTS(Nile, type = "level"); fit$coef   # 분산 추정
plot(Nile); lines(tsSmooth(fit), col = "red")       # 숨은 수준의 평활 추정
주의

칼만 필터의 결과는 두 분산 \(\sigma_\eta^2\)와 \(\sigma_\varepsilon^2\)에 달려 있다. 실제로는 이 값을 모르므로 가능도를 최대로 하여 추정하는데, 그림 1의 나일강 자료에서는 \(\hat\sigma_\eta^2 = 1469\), \(\hat\sigma_\varepsilon^2 = 15099\)로 관측 잡음이 훨씬 크다.

마무리

상태공간 모형은 관측식과 상태식으로 숨은 상태를 나타낸다. 칼만 필터는 예측 단계에서 불확실성을 키우고, 갱신 단계에서 예측과 관측을 가중평균한다. 칼만 이득은 상대적 불확실성이며, 정규 가정 아래 베이즈 갱신과 같다.

7.1.3연습문제

기본

  1. 예제에서 \(\sigma_\varepsilon^2 = 0\)(관측에 잡음 없음)이면 \(K\)와 \(m_t\)는 얼마인가?
    답

    \(K = 1\), \(m_t = 46\)이다. 잡음이 없으면 관측이 곧 참값이다.

응용

  1. 예제 다음 주 조사가 44였다. 같은 분산으로 한 번 더 갱신하라.
    답

    예측 분산 \(2 + 1 = 3\), \(K = 3/7 = 0.43\)이므로 \(m = 43 + 0.43 \times 1 = 43.4\), \(P = 0.57 \times 3 = 1.71\)이다.

  2. \(\sigma_\eta^2 = 1\), \(\sigma_\varepsilon^2 = 4\)일 때 정상 상태의 칼만 이득을 구하라.
    답

    정상 상태의 예측 분산 \(p\)는 \(p = 4p/(p + 4) + 1\), 곧 \(p^2 - p - 4 = 0\)을 풀어 \(p = 2.56\)이다. 따라서 \(K = 2.56/6.56 = 0.39\)이고, 이것이 대응하는 지수평활의 \(\alpha\)이다.
