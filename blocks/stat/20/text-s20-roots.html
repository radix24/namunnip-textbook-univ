ARMA의 정상 조건과 가역 조건

본문

AR(1)은 \(|\phi| < 1\)이면 정상이다. 그렇다면 계수가 1.2와 −0.2인 AR(2) \(X_t = 1.2X_{t-1} - 0.2X_{t-2} + \varepsilon_t\)는 어떨까? 계수 하나는 1을 넘지만 합은 1이다. 계수를 하나씩 보아서는 판단이 서지 않을 때, 무엇을 보면 될까?

먼저 알아야 할 것AR(1)과 MA(1)(2.1절)과 식별(2.2절)을 쓴다.

처음 질문의 답은 다항식의 근이다. 차수가 높아지면 계수를 하나씩 볼 것이 아니라, 모형을 후행 연산자의 다항식으로 쓰고 그 근이 단위원 밖에 있는지 본다. AR(2)라면 그 조건이 계수 평면의 삼각형이 되며, 위의 모형은 그 변 위에 있어 정상이 아니다(그림 1).

2.3.1후행 연산자와 다항식

\(BX_t = X_{t-1}\)로 쓰면 ARMA(\(p, q\))는 \(\phi(B)X_t = \theta(B)\varepsilon_t\)이고, \(\phi(z) = 1 - \phi_1z - \cdots - \phi_pz^p\), \(\theta(z) = 1 + \theta_1z + \cdots + \theta_qz^q\)이다.

정상 조건은 \(\phi(z) = 0\)의 모든 근이 단위원 밖(\(|z| > 1\))에 있는 것이다. 이때 \(X_t = \phi(B)^{-1}\theta(B)\varepsilon_t\)로, 과거 잡음의 수렴하는 합(MA(∞))으로 쓸 수 있다. 한편 가역 조건은 \(\theta(z) = 0\)의 모든 근이 단위원 밖에 있는 것이다. 이때 \(\varepsilon_t\)를 과거 \(X\)들의 수렴하는 합(AR(∞))으로 되돌릴 수 있으므로, 같은 ACF를 주는 MA 모형이 둘 있을 때 가역인 쪽을 골라 모형을 하나로 정한다. 그리고 근이 단위원 위(\(|z| = 1\))에 있으면 단위근이며 차분이 필요하다(3단원).

2.3.2ARMA(1, 1)

\(X_t = \phi X_{t-1} + \varepsilon_t + \theta\varepsilon_{t-1}\)의 자기상관은 시차 1에서 \(\rho_1 = \frac{(1 + \phi\theta)(\phi + \theta)}{1 + 2\phi\theta + \theta^2}\)이고, 그 뒤로 \(\rho_k = \phi\rho_{k-1}\)로 지수적으로 줄어든다. 그래서 ACF와 PACF가 모두 꼬리를 끌며 줄어드는 모양이 ARMA의 지문이다(2.2절). 즉 AR이나 MA만으로는 많은 차수가 필요한 구조를 적은 모수로 나타낸다.

예제 2.3.1

(가) \(X_t = 0.5X_{t-1} + 0.3X_{t-2} + \varepsilon_t\)와 (나) \(X_t = 1.2X_{t-1} - 0.2X_{t-2} + \varepsilon_t\)의 정상성을 판정하라.

풀이. (가)는 \(1 - 0.5z - 0.3z^2 = 0\)의 근이 1.17과 −2.84로 모두 \(|z| > 1\)이므로 정상이다. 반면 (나)는 \(1 - 1.2z + 0.2z^2 = (1 - z)(1 - 0.2z)\)라 근이 1과 5이다. 근 1이 단위원 위에 있어 비정상, 곧 단위근이다(그림 1). 따라서 차분 \(\nabla X_t\)는 AR(1) \(\nabla X_t = 0.2\nabla X_{t-1} + \varepsilon_t\)가 되어 ARIMA(1, 1, 0)이다.

주의

AR(2)의 정상 조건을 계수로 쓰면 \(\phi_1 + \phi_2 < 1\), \(\phi_2 - \phi_1 < 1\), \(|\phi_2| < 1\)이다. 계수 하나하나가 1보다 작아도 합이 1이면 단위근이 생기므로, 세 조건을 모두 확인한다.

마무리

ARMA는 \(\phi(B)X_t = \theta(B)\varepsilon_t\)로 쓴다. \(\phi(z)\)의 근이 모두 단위원 밖이면 정상, \(\theta(z)\)의 근이 밖이면 가역이다. 근 1은 단위근이라 차분이 필요하며, ARMA(1, 1)은 ACF와 PACF가 모두 꼬리를 끈다.

2.3.3연습문제

기본

  1. MA(1) \(X_t = \varepsilon_t + 2\varepsilon_{t-1}\)은 가역인가? 같은 ACF를 주는 가역 모형은 무엇인가?
    답

    \(1 + 2z = 0\)의 근 −0.5가 단위원 안이라 가역이 아니다. \(\rho_1 = \theta/(1 + \theta^2)\)는 \(\theta\)와 \(1/\theta\)에서 같으므로, \(X_t = \varepsilon_t + 0.5\varepsilon_{t-1}\)(잡음 분산 4배)이 같은 ACF의 가역 모형이다.

응용

  1. 예제 2.3.1 (나)는 AR(2) 정상 조건 가운데 어느 것을 어기는가?
    답

    \(\phi_1 + \phi_2 = 1.2 - 0.2 = 1\)로 첫 조건의 경계에 있다(근 1).

  2. AR(2) \(X_t = 0.6X_{t-1} - 0.5X_{t-2} + \varepsilon_t\)는 정상인가? ACF는 어떤 모양인가?
    답

    세 조건(\(0.1 < 1\), \(-1.1 < 1\), \(0.5 < 1\))을 모두 만족해 정상이다. 또 \(\phi_1^2 + 4\phi_2 = -1.64 < 0\)이라 근이 복소수이므로 ACF가 감쇠 진동한다.
