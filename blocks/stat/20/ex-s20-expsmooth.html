홀트 방법으로 증가하는 수요 예측

예제 · 수준과 추세 갱신

먼저 읽는 법

수준과 추세를 매 기 갱신하는 식을 차례로 적용하고, 마지막 수준과 추세로 1기, 2기 앞을 예측한다.

문제. 수요 10, 12, 15, 16, 19에 홀트 방법(\(\alpha = 0.5\), \(\beta = 0.3\))을 쓴다. 시작값 \(\ell_1 = 10\), \(b_1 = 2\)로 마지막 수준과 추세, 1기·2기 앞 예측을 구하여라.

풀이

  1. \(t = 2\): \(\ell = 0.5(12) + 0.5(12) = 12\), \(b = 0.3(2) + 0.7(2) = 2\).
    예측과 관측이 같아 그대로.
  2. \(t = 3\): \(\ell = 0.5(15) + 0.5(14) = 14.5\), \(b = 0.3(2.5) + 0.7(2) = 2.15\). \(t = 4\): \(\ell = 0.5(16) + 0.5(16.65) = 16.33\), \(b = 0.3(1.83) + 0.7(2.15) = 2.05\).
    갱신식.
  3. \(t = 5\): \(\ell = 0.5(19) + 0.5(18.38) = 18.69\), \(b = 0.3(2.36) + 0.7(2.05) = 2.15\). 예측 1기 앞 20.8, 2기 앞 23.0.
    \(\ell + hb\).

검산

자료의 평균 증가량은 \((19 - 10)/4 = 2.25\)로, 추정된 추세 2.15와 비슷하다. 단순 지수평활(\(\alpha = 0.5\))이었다면 다음 예측이 마지막 수준 근처(약 17~18)에 머물러 증가를 따라가지 못한다.

의미

홀트 방법은 추세를 직선으로 영원히 연장하므로 몇 기 앞까지는 좋지만 1년 뒤처럼 먼 예측에서는 과하게 커질 수 있다. 성장이 둔해질 가능성이 있으면 감쇠 추세를 쓰고, 예측구간이 멀수록 넓어지는지 함께 확인한다.
