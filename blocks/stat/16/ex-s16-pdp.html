PDP가 숨긴 상호작용

예제 · ICE 곡선

먼저 읽는 법

상호작용이 있는 모형에서 사례마다 ICE 곡선을 구하고, 그 평균인 PDP와 비교한다. 평균 하나로는 사례별 기울기 차이가 보이지 않는다.

문제. 모형 \(\hat f(x_1, x_2) = 2 x_1 + x_1 x_2\)이고 자료의 \(x_2\)는 0, 1, 2(세 사례)이다. \(x_1\)의 ICE 곡선과 PDP를 구하여라. \(x_2\)가 −1, 0, 4라면 어떻게 되나요?

풀이

  1. ICE: \(x_2 = 0, 1, 2\)일 때 \(2v, 3v, 4v\). 기울기 2, 3, 4.
    사례마다 다른 기울기.
  2. PDP: \((2v + 3v + 4v)/3 = 3v\). 기울기는 \(2 + \bar x_2 = 3\).
    평균.
  3. \(x_2 = -1, 0, 4\)이면 ICE 기울기 1, 2, 6이고 PDP 기울기는 \(2 + 1 = 3\)으로 같다.
    \(\bar x_2 = 1\).

검산

\(\hat f = x_1 (2 + x_2)\)이므로 \(x_1\)의 기울기는 \(2 + x_2\)이다. 두 경우 모두 \(\bar x_2 = 1\)이라 PDP는 같지만, 두 번째 경우 기울기의 범위(1~6)가 훨씬 넓다.

의미

PDP만 보면 두 자료에서 "\(x_1\)의 효과는 3"으로 같아 보이지만, 실제로는 \(x_2\)가 큰 고객에게 효과가 훨씬 크다. 마케팅 대상을 고를 때는 이 차이가 중요하므로, PDP와 함께 ICE 곡선을 그려 갈라지는지 확인하고, 갈라지면 \(x_2\)로 나눠 PDP를 따로 그린다.
