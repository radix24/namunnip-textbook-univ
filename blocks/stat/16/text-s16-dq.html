처음 질문의 답은 자동 품질 검사이다. 파이프라인이 자동으로 돈다는 것은 잘못된 자료도 자동으로 결과에 들어간다는 뜻이다. 그러므로 행 수, 결측률, 값의 범위, 분포 같은 기준을 미리 정해 두고, 기준을 벗어나면 파이프라인을 멈추거나 경고를 남긴다(그림 1).

2.2.2분포 변화 감시

모형 입력 변수의 분포가 학습 때와 달라지면 성능이 떨어진다. 그래서 변수마다 학습 기간을 구간으로 나누고, 학습 기간 비율 \(p_i\)와 최근 기간 비율 \(q_i\)를 비교하는 집단 안정성 지수(PSI)를 흔히 쓴다.

\[ \mathrm{PSI} = \sum_i (q_i - p_i)\log\frac{q_i}{p_i} \]

관례로 0.1 미만은 안정, 0.1~0.25는 주의, 0.25 이상은 큰 변화로 본다.

예제 2.2.1

학습 때 소득 5분위 구간의 비율이 모두 0.2였는데, 최근에는 (0.10, 0.15, 0.20, 0.25, 0.30)이다. PSI를 구하라.

풀이. 구간별 항은 \(-0.1\log 0.5 = 0.069\), \(-0.05\log 0.75 = 0.014\), 0, \(0.05\log 1.25 = 0.011\), \(0.1\log 1.5 = 0.041\)이다. 합은 0.135로 주의 구간이다(그림 1). 따라서 모형 성능을 따로 확인하고 원인을 찾는다.

주의

최근 구간에 표본이 하나도 없으면 \(\log(q_i/p_i)\)가 정의되지 않는다. 그러므로 실무에서는 비율에 아주 작은 값을 더하거나 이웃 구간과 합친다.

마무리

자료 품질은 완전성, 유효성, 유일성, 일관성, 적시성, 분포 안정성으로 나누어 점검한다. 자동 검사를 파이프라인에 넣어 심각하면 멈추고 경미하면 경고한다. 입력 분포 변화는 PSI로 감시하며, 0.1과 0.25가 관례적 기준이다.

2.2.3연습문제

기본

  1. 두 구간의 비율이 학습 때 (0.5, 0.5), 최근 (0.7, 0.3)이면 PSI는 얼마인가?
    답

    \(0.2\log 1.4 + (-0.2)\log 0.6 = 0.2(0.336) + 0.2(0.511) = 0.169\)로, 주의할 만한 변화이다.

응용

  1. 처음 질문의 상황, 곧 주문 자료가 절반만 들어온 주를 잡아낼 검사는 표 1의 어느 것인가?
    답

    완전성 검사인 행 수가 지난주의 ±20% 안인지 확인하는 검사이다. 절반이면 기준을 벗어나 파이프라인이 멈춘다.

  2. 추석 연휴가 있는 주마다 행 수 검사가 실패해 파이프라인이 멈춘다. 어떻게 고치는가?
    답

    지난주 대신 작년 같은 주나 요일별 기준과 비교하거나, 휴일 목록을 두어 그 주에는 기준을 넓힌다. 기준을 아예 없애면 진짜 문제도 놓친다.
