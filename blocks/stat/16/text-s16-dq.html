  • 자료 품질의 차원(완전성, 유효성, 일관성, 적시성)을 안다.
  • 파이프라인에 자동 품질 검사를 넣는다.
먼저 알아야 할 것
  • 파이프라인 (2.1절), 응통11 2.1절.

쓰레기가 들어가면 쓰레기가 나온다

파이프라인이 자동으로 돈다는 것은 잘못된 자료도 자동으로 결과에 들어간다는 뜻입니다. 사람이 매번 보지 않아도 문제를 잡아내는 검사가 필요합니다.

2.2.1품질 차원과 검사

차원검사 예
완전성행 수가 지난주의 ±20% 안, 필수 열의 결측률 < 1%
유효성금액 ≥ 0, 날짜가 미래가 아님, 범주가 허용 목록 안
유일성주문 ID 중복 없음
일관성주문 합계 = 품목 합, 다른 시스템 집계와 일치
적시성최신 자료 날짜가 어제
분포 안정성주요 변수의 평균·분위수가 기준 기간과 크게 다르지 않음

검사에 실패하면 파이프라인을 멈추고 담당자에게 알립니다. 경미한 것은 경고로 기록만 합니다.

stopifnot(nrow(d) > 0.8 * n_last_week, !anyDuplicated(d$order_id),

2.2.2분포 변화 감시

모형 입력 변수의 분포가 학습 때와 달라지면 성능이 떨어집니다. 변수마다 학습 기간과 최근 기간을 구간으로 나눠 비율을 비교하는 집단 안정성 지수(PSI) \(\sum(p_i - q_i)\log(p_i/q_i)\)를 흔히 씁니다. 관례로 0.1 미만은 안정, 0.25 이상은 큰 변화로 봅니다.

요약
  1. 완전성, 유효성, 유일성, 일관성, 적시성, 분포 안정성.
  2. 자동 검사로 멈추거나 경고.
  3. 입력 분포 변화를 감시(PSI).
