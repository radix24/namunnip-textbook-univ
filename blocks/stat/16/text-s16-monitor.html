모형 감시와 재학습

본문
이 절에서 배울 것
  • 입력 분포의 변화를 모집단 안정성 지수(PSI)로 잰다.
  • 정답이 늦게 오는 상황에서 성능을 감시한다.
  • 재학습 시점을 규칙으로 정한다.
먼저 알아야 할 것
  • 배포 방식 (4.3절), 자료 품질 기준 (2.2절).

모형은 배포한 날부터 낡는다

고객 구성, 상품, 경쟁 환경이 바뀌면 학습 때의 관계가 더는 맞지 않습니다. 입력 변수의 분포가 바뀌는 것을 자료 표류(data drift), 입력과 결과의 관계 자체가 바뀌는 것을 개념 표류(concept drift)라 합니다.

4.4.1입력 분포 감시: PSI

학습 때 변수를 구간으로 나눈 비율 \(e_b\)와 운영 중 같은 구간의 비율 \(a_b\)를 비교합니다.

\[\mathrm{PSI} = \sum_b (a_b - e_b) \ln \frac{a_b}{e_b}.\]

관행적으로 0.1 미만은 안정, 0.1~0.25는 주의, 0.25 이상은 큰 변화로 봅니다. 예측 점수 자체의 분포에도 PSI를 계산합니다. 비율이 0인 구간이 있으면 작은 값을 더해 로그가 발산하지 않게 합니다.

4.4.2성능 감시

정답이 바로 오면(클릭 여부) 성능을 매일 잽니다. 정답이 늦게 오면(한 달 뒤 해지 여부) 그동안은 입력과 점수 분포로 대신 감시하고, 정답이 도착하는 대로 성능을 계산합니다. 성능은 전체와 함께 주요 집단별로도 봅니다(1.5절).

4.4.3재학습 규칙

  • 정기 재학습: 매월 등 정해진 주기. 단순하지만 불필요한 재학습이 생길 수 있음.
  • 조건부 재학습: PSI가 0.25를 넘거나 성능이 기준 아래로 떨어지면.
  • 재학습한 모형도 바로 바꾸지 않고, 시험 자료와 4.5절의 온라인 실험으로 기존 모형보다 나은지 확인합니다.
예제 4.4.1

네 구간의 학습 비율이 모두 0.25이고 운영 비율이 0.22, 0.26, 0.27, 0.25입니다. PSI는?

풀이. \((-0.03)\ln 0.88 + 0.01 \ln 1.04 + 0.02 \ln 1.08 + 0 = 0.00384 + 0.00039 + 0.00154 = 0.0058\). 0.1보다 훨씬 작아 안정입니다.

요약
  1. PSI로 입력과 점수 분포의 변화를 잽니다(0.1, 0.25 기준).
  2. 정답이 늦으면 분포로 대신 감시, 도착하면 성능 계산.
  3. 재학습 모형도 비교 검증 뒤 교체.

4.4.4연습문제

기본

  1. 입력 분포는 그대로인데 성능이 떨어졌습니다. 어떤 표류인가요?
    답

    개념 표류. 같은 입력에 대한 결과의 관계가 바뀐 것입니다(예: 경쟁사 할인으로 같은 이용 패턴의 고객도 더 많이 해지).

응용

  1. PSI 경보가 거의 매일 울려 담당자가 무시하기 시작했습니다. 어떻게 고치나요?
    답

    변수가 많으면 우연한 경보도 많아집니다(다중 비교). 중요 변수와 점수 분포 위주로 감시 대상을 줄이고, 며칠 연속 넘을 때만 알리거나 기준을 업무 영향에 맞게 조정합니다.
