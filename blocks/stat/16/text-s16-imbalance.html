  • 업무 지표로 해석 (3.2절), 교차검증 (3.3절).

99% 정확한 쓸모없는 모형

사기 거래가 1%인 자료에서 "모두 정상"이라고 답하는 모형의 정확도는 99%입니다. 그러나 사기는 하나도 잡지 못합니다. 양성이 드문 자료에서는 양성을 얼마나 잡는지와, 잡았다고 한 것 중 얼마나 맞는지를 따로 봐야 합니다.

3.4.1평가 지표

  • 재현율(참양성률) = TP / (TP + FN): 실제 양성 중 잡은 비율.
  • 정밀도 = TP / (TP + FP): 양성이라 한 것 중 맞은 비율.
  • PR 곡선과 그 아래 넓이(평균 정밀도): 임계값을 바꿀 때의 정밀도-재현율 관계. ROC AUC는 음성이 많으면 거짓양성률이 작게 보여 낙관적일 수 있습니다. 무작위 모형의 평균 정밀도는 양성 비율(여기서는 0.01)입니다.

3.4.2학습 조정

소수 집단에 큰 가중치를 주거나(class_weight="balanced"), 다수 집단을 줄이거나 소수 집단을 늘려 학습합니다. 표본을 조정하면 예측 확률이 실제 비율과 달라지므로, 확률 자체가 필요하면 보정해야 합니다. 표본 조정은 학습 자료에만 하고 검증 자료는 원래 비율을 유지합니다.

3.4.3비용에 맞춘 임계값

양성을 놓치는 비용 \(C_{FN}\)과 잘못 경보하는 비용 \(C_{FP}\)가 다르면, 보정된 확률 \(p\)에 대해 \(p \cdot C_{FN} > (1 - p) C_{FP}\)일 때 양성으로 판정합니다. 곧 임계값은

\[p^* = \frac{C_{FP}}{C_{FP} + C_{FN}}.\]
예제 3.4.1

거래 10000건 중 사기 100건. 모형이 150건을 사기로 판정했고 그중 80건이 실제 사기입니다. 정확도, 정밀도, 재현율은?

풀이. TP 80, FP 70, FN 20, TN 9830. 정확도 \(9910/10000 = 99.1\%\), 정밀도 \(80/150 = 0.533\), 재현율 \(80/100 = 0.80\). 정확도는 "모두 정상" 모형(99.0%)과 거의 같아 차이를 보여 주지 못합니다.

요약
  1. 불균형 자료에서는 정밀도, 재현율, PR 곡선.
  2. 가중치나 표본 조정은 학습 자료에만, 확률은 보정.
  3. 임계값 \(p^* = C_{FP}/(C_{FP} + C_{FN})\).

3.4.4연습문제

기본

  1. 예제에서 F1 점수(정밀도와 재현율의 조화평균)는?
    답

    \(2 \times 0.533 \times 0.8/(0.533 + 0.8) = 0.64\).

응용

  1. 학습 자료에서 소수 집단을 복제해 늘린 뒤 교차검증을 했더니 성능이 매우 좋게 나왔습니다. 무엇이 문제인가요?
    답

    복제를 분할 전에 하면 같은 양성 사례가 학습 겹과 검증 겹에 동시에 들어가 누수가 생깁니다. 표본 조정을 파이프라인 안에 넣어 겹마다 학습 부분에만 적용해야 합니다.
