교차검증으로 하이퍼파라미터 조정하기

본문

릿지 회귀의 규제 강도 \(\lambda\)를 17개 후보 가운데 고르려 한다. 5겹 교차검증 오차가 가장 작은 후보는 \(\lambda = 17.8\)이었지만, 오차 막대가 서로 크게 겹친다. 오차가 가장 작은 것을 그대로 고르면 될까? 그리고 그 최소 오차를 이 모형의 성능이라고 보고해도 될까?

먼저 알아야 할 것검증 자료로 평가(3.1절)와 파이프라인 객체(2.4절)를 쓴다.

처음 질문의 답은 둘 다 조심해야 한다는 것이다. 겹 사이 변동이 크면 가장 작은 오차는 우연히 좋아 보인 것일 수 있으므로, 변동 안에서 구별되지 않는 후보 가운데 더 단순한 것을 고르는 편이 안전하다(그림 1). 또 여러 후보 가운데 가장 좋은 값은 낙관적이므로 최종 성능은 따로 잰다. 계수는 학습이 정하지만 규제 강도, 나무 깊이, 이웃 수 같은 하이퍼파라미터는 새 자료에 대한 오차로 골라야 하기 때문에 교차검증을 쓴다.

3.3.1탐색 방법

격자 탐색은 후보 조합을 모두 시도한다. 규제 강도처럼 범위가 넓은 값은 0.01, 0.1, 1, 10처럼 로그 간격으로 둔다. 그런데 하이퍼파라미터가 여럿이면 조합이 폭증하므로, 정해진 횟수만큼 무작위 조합을 시도하는 무작위 탐색이 같은 비용으로 더 넓게 살핀다.

from sklearn.model_selection import GridSearchCV
grid = GridSearchCV(model, {"clf__C": [0.01, 0.1, 1, 10]},
                    cv=5, scoring="roc_auc")
grid.fit(X_train, y_train)

이때 파이프라인 전체(2.4절)를 넣어야 겹마다 전처리도 다시 학습된다. 시간 자료라면 TimeSeriesSplit으로 2.3절의 확장 창을 쓴다.

3.3.21-표준오차 규칙

\(k\)겹 오차의 평균이 가장 작은 후보를 고르면, 겹 사이 변동 때문에 우연히 좋아 보인 복잡한 모형을 고르기 쉽다. 그래서 최소 오차에 그 표준오차(겹 오차의 표준편차 / \(\sqrt k\))를 더한 값 안에 드는 후보 가운데 가장 단순한 모형을 고르는데, 이것이 1-표준오차 규칙이다. 그림 1에서는 최소 + 표준오차가 5.35이므로, 그 안에 드는 가장 큰 \(\lambda = 100\)을 고른다.

예제 3.3.1

5겹 교차검증의 한 후보에서 겹 오차가 0.20, 0.22, 0.19, 0.21, 0.23이다. 평균과 표준오차를 구하라.

풀이. 평균은 \(1.05/5 = 0.210\)이다. 표준편차는 \(\sqrt{(0.0001 + 0.0001 + 0.0004 + 0 + 0.0004)/4} = \sqrt{0.00025} = 0.0158\)이므로, 표준오차는 \(0.0158/\sqrt 5 = 0.0071\)이다.

3.3.3중첩 교차검증

교차검증으로 고른 후보의 교차검증 오차는 여러 후보 가운데 가장 좋은 값이라 낙관적이다. 따라서 최종 성능은 조정에 쓰지 않은 시험 자료로 재거나, 바깥 교차검증 안에서 안쪽 교차검증으로 조정을 반복하는 중첩 교차검증으로 추정한다.

흔한 실수

가장 좋은 후보가 격자의 끝값, 예컨대 \(C = 10\)이면 최적값이 격자 밖에 있을 수 있다. 그러므로 범위를 \(C = 100, 1000\)까지 넓혀 다시 탐색한다.

마무리

하이퍼파라미터는 로그 간격 격자나 무작위 탐색으로 후보를 정하고, 파이프라인 전체를 교차검증해 고른다. 1-표준오차 규칙은 변동 안에서 구별되지 않는 더 단순한 모형을 고르게 한다. 고른 후보의 교차검증 오차는 낙관적이므로 최종 성능은 시험 자료나 중첩 교차검증으로 잰다.

3.3.4연습문제

기본

  1. 하이퍼파라미터 3개에 각각 후보 5개를 두고 5겹 교차검증 격자 탐색을 하면 모형을 몇 번 학습하는가?
    답

    최종 재학습 1번을 빼면 \(5^3 \times 5 = 625\)번이다.

응용

  1. 같은 비용(학습 625번)으로 무작위 탐색을 하면 조합을 몇 개 시도할 수 있는가? 격자 탐색보다 나은 점은 무엇인가?
    답

    5겹이므로 125개 조합이다. 격자는 각 하이퍼파라미터의 값을 5개씩만 보지만, 무작위 탐색은 각 축에서 125개의 서로 다른 값을 본다. 중요한 하이퍼파라미터가 하나뿐일 때 특히 유리하다.

  2. 예제 3.3.1의 후보가 최소 오차였고, 다른 단순한 후보의 평균 오차가 0.215였다. 1-표준오차 규칙으로는 무엇을 고르는가?
    답

    \(0.210 + 0.0071 = 0.217\) 안에 0.215가 들므로 더 단순한 후보를 고른다.
