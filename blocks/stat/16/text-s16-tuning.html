교차검증으로 하이퍼파라미터 조정하기

본문
이 절에서 배울 것
  • 격자 탐색과 무작위 탐색으로 후보를 정한다.
  • \(k\)겹 교차검증 오차와 그 표준오차로 후보를 비교한다.
  • 1-표준오차 규칙과 중첩 교차검증을 안다.
먼저 알아야 할 것
  • 검증 자료로 평가 (3.1절), 파이프라인 객체 (2.4절).

학습이 정하지 못하는 값

계수는 학습이 정하지만, 규제 강도 \(\lambda\), 나무 깊이, 이웃 수 \(k\) 같은 값은 사람이 정해야 합니다. 이런 하이퍼파라미터는 학습 자료에 대한 오차가 아니라 새 자료에 대한 오차로 골라야 하므로 교차검증을 씁니다.

3.3.1탐색 방법

격자 탐색은 후보 조합을 모두 시도합니다. 규제 강도처럼 범위가 넓은 값은 0.01, 0.1, 1, 10처럼 로그 간격으로 둡니다. 하이퍼파라미터가 여럿이면 조합이 폭증하므로 무작위 탐색(정해진 횟수만큼 무작위 조합)이 같은 비용으로 더 넓게 살핍니다.

from sklearn.model_selection import GridSearchCV
grid = GridSearchCV(model, {"clf__C": [0.01, 0.1, 1, 10]},
                    cv=5, scoring="roc_auc")
grid.fit(X_train, y_train)

파이프라인 전체(2.4절)를 넣어야 겹마다 전처리도 다시 학습됩니다. 시간 자료라면 TimeSeriesSplit으로 2.3절의 확장 창을 씁니다.

3.3.21-표준오차 규칙

\(k\)겹의 오차 평균이 가장 작은 후보를 고르면 겹 사이 변동 때문에 우연히 좋아 보인 복잡한 모형을 고르기 쉽습니다. 최소 오차 + 그 표준오차(겹 오차의 표준편차 / \(\sqrt{k}\)) 안에 드는 후보 가운데 가장 단순한 모형을 고르는 것이 1-표준오차 규칙입니다.

3.3.3중첩 교차검증

교차검증으로 고른 후보의 교차검증 오차는 "여러 후보 중 가장 좋은 값"이라 낙관적입니다. 최종 성능은 조정에 쓰지 않은 시험 자료로 재거나, 바깥 교차검증 안에서 안쪽 교차검증으로 조정을 반복하는 중첩 교차검증으로 추정합니다.

예제 3.3.1

5겹 교차검증의 한 후보에서 겹 오차가 0.20, 0.22, 0.19, 0.21, 0.23입니다. 평균과 표준오차는?

풀이. 평균 \(1.05/5 = 0.210\). 표준편차 \(\sqrt{(0.0001 + 0.0001 + 0.0004 + 0 + 0.0004)/4} = \sqrt{0.00025} = 0.0158\), 표준오차 \(0.0158/\sqrt 5 = 0.0071\).

요약
  1. 로그 간격 격자나 무작위 탐색, 파이프라인 전체를 교차검증.
  2. 1-표준오차 규칙으로 단순한 모형을 선호.
  3. 최종 성능은 시험 자료나 중첩 교차검증으로.

3.3.4연습문제

기본

  1. 하이퍼파라미터 3개에 각각 후보 5개를 두고 5겹 교차검증 격자 탐색을 하면 모형을 몇 번 학습하나요?
    답

    \(5^3 \times 5 = 625\)번(최종 재학습 1번 제외).

응용

  1. 가장 좋은 후보가 격자의 끝값(예: \(C = 10\))이었습니다. 어떻게 하나요?
    답

    최적값이 격자 밖에 있을 수 있으므로 범위를 넓혀(\(C = 100, 1000\)) 다시 탐색합니다.
