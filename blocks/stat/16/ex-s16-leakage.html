표준화에 섞인 미래 정보

예제 · 전처리 누수

먼저 읽는 법

전체 자료로 평균을 구해 표준화하면, 시험 자료의 값이 평균에 들어가 학습 자료의 변환에도 영향을 줍니다. 작은 숫자로 두 방식의 변환값을 비교합니다.

문제. 학습 자료의 값이 2, 4, 6이고 시험 자료의 값이 12입니다(시험 기간에 값이 크게 올랐음). (가) 학습 자료만으로 (나) 네 값 전체로 평균을 구해 중심화(값 − 평균)할 때 각 변환값을 구하세요.

풀이

  1. (가) 평균 4. 학습 \(-2, 0, 2\), 시험 \(8\).
    운영과 같은 방식.
  2. (나) 평균 6. 학습 \(-4, -2, 0\), 시험 \(6\).
    시험 값이 평균을 끌어올림.
  3. (나)에서는 시험 값이 "평균보다 6 높음"으로 덜 극단적으로 보입니다. 모형은 미래의 수준 변화를 미리 안 셈입니다.
    누수.

검산

(가) \((2 + 4 + 6)/3 = 4\), (나) \((2 + 4 + 6 + 12)/4 = 6\). 운영에서는 미래 값을 알 수 없으므로 (가)만 재현할 수 있습니다.

의미

이 예에서는 차이가 눈에 띄지만, 실제로는 수백 개 변수에서 조금씩 누수가 쌓여 검증 성능을 몇 %p씩 부풀립니다. 전처리를 학습 자료로 "적합"하고 검증 자료에는 "적용"만 하도록 2.4절의 파이프라인 객체로 묶으면 이런 실수를 구조적으로 막을 수 있습니다.
