모집단이 치우쳐 있어도 표본평균은 왜 종 모양이 되는가?

실습 · 중심극한정리

목표

모집단 분포를 고르고 표본 크기 \(n\)을 바꾸면서, 표본평균 \(\bar X\) 2000개의 히스토그램이 정규분포 \(N(\mu, \sigma^2/n)\)에 가까워지는 모습을 본다. 성취기준 [응통5-03-01].

먼저 말을 정리해 둔다.

표본평균: 모집단에서 \(n\)개를 뽑아 구한 평균 \(\bar X = (X_1 + \cdots + X_n)/n\). 뽑을 때마다 값이 달라지므로 그 자체가 확률변수이다.

표본분포: 같은 방법으로 표본을 여러 번 뽑을 때 \(\bar X\)가 이루는 분포.

중심극한정리: 모집단의 평균이 \(\mu\), 표준편차가 \(\sigma\)이면, \(n\)이 클 때 \(\bar X\)의 분포는 모집단 모양과 관계없이 \(N(\mu, \sigma^2/n)\)에 가깝다.

준비

위 그림은 모집단(세로 빨간 점선이 \(\mu\)), 아래 그림은 크기 \(n\)인 표본을 2000번 뽑아 구한 표본평균의 히스토그램과 이론 곡선 \(N(\mu, \sigma^2/n)\)(빨강)이다. 자료는 모두 컴퓨터 난수로 만든 가상 자료이다. "새 표본"을 누르면 같은 조건에서 2000번을 다시 뽑는다.

절차

  1. 지수분포에서 \(n = 1\)로 둔다. 히스토그램은 모집단 그 자체이고, 정규 곡선과 전혀 맞지 않다.
  2. \(n\)을 2, 5, 10, 30, 100으로 키우며 히스토그램 모양과 출력의 "치우침"을 적는다.
  3. 출력의 표본평균들의 표준편차를 이론값 \(\sigma/\sqrt n\)과 비교한다. \(n\)을 4배로 하면 몇 배가 되는지 본다.
  4. 모집단을 균일분포, 봉우리 두 개, 베르누이로 바꿔 같은 일을 한다.

기대 결과

  • 어느 모집단이든 표본평균들의 평균은 \(\mu\)에 매우 가깝습니다(\(E(\bar X) = \mu\)).
  • 표본평균들의 표준편차는 \(\sigma/\sqrt n\)과 거의 같고, \(n\)을 4배로 하면 절반이 된다.
  • 지수분포의 치우침은 \(n = 1\)에서 약 2이고, 이론상 \(2/\sqrt n\)으로 줄어 \(n = 30\)이면 약 0.37, \(n = 100\)이면 약 0.2이다. 2000개로 잰 값이라 ±0.1 정도 흔들린다.
  • 균일분포는 이미 대칭이라 \(n = 5\) 정도에서도 정규 곡선과 잘 맞다.
  • 봉우리 두 개인 모집단도 \(n = 2\)에서는 봉우리가 셋(두 값이 모두 낮음, 하나씩, 모두 높음)이지만 \(n = 10\)이면 하나가 된다.
  • 베르누이 \(p = 0.1\)은 가장 느리다. \(\bar X\)는 \(0, 1/n, 2/n, \ldots\)만 가지는 이산 값이고, \(n = 10\)에서는 0이 나올 확률이 \(0.9^{10} \approx 0.35\)나 되어 한쪽으로 쏠린다. \(np\)가 10쯤 되는 \(n = 100\)에서야 종 모양에 가까워진다.

분석

  1. "\(n \ge 30\)이면 정규 근사를 써도 된다"는 말은 언제나 맞나요? 베르누이 \(p = 0.1\)과 균일분포의 결과로 답해 보자.
  2. \(\bar X\)의 표준편차가 \(\sigma/\sqrt n\)인 이유를 \(\mathrm{Var}(X_1 + \cdots + X_n) = n\sigma^2\)(독립)에서 설명해 보자.
  3. 출력의 "μ ± 1.96σ/√n 안에 든 비율"이 95%에 가까워진다는 사실이 다음 실습(신뢰구간)과 어떻게 이어지는지 적어 보자.

더 해 보기

R에서 같은 실험을 하려면 means <- replicate(2000, mean(rexp(30))), hist(means, freq = FALSE), curve(dnorm(x, 1, 1/sqrt(30)), add = TRUE)를 실행한다. 응통6 07단원에서 이 정리를 적률생성함수로 증명한다.
