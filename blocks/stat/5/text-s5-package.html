본문
이 절에서 배울 것
  • R에서 자료를 읽고, 요약하고, 검정하는 기본 흐름을 익힌다.
  • 출력에서 필요한 값(추정값, 검정통계량, p값, 신뢰구간)을 찾아 읽는다.
먼저 알아야 할 것
  • 이 과목 2~6장의 방법들.

어떤 패키지든 흐름은 같다

요람은 SAS, SPSS, MINITAB, R을 들지만 분석의 흐름은 같습니다. 자료 읽기 → 확인과 정리 → 그림과 요약 → 모형과 검정 → 결과 해석. 여기서는 무료인 R로 보입니다.

7.1.1자료 읽기와 확인

d <- read.csv("survey.csv")      # 같은 폴더의 CSV 파일
str(d)          # 변수 이름, 형식, 앞부분 값
summary(d)      # 변수별 요약, 결측값(NA) 수
d$major <- factor(d$major)       # 범주형으로 지정

숫자여야 할 변수가 문자로 읽혔는지, 결측값이 몇 개인지, 범위를 벗어난 값(나이 250)이 있는지 먼저 봅니다.

7.1.2요약과 그림

mean(d$hours, na.rm = TRUE); sd(d$hours, na.rm = TRUE)
table(d$major)
boxplot(hours ~ major, data = d)

7.1.3검정과 출력 읽기

t.test(hours ~ sex, data = d)         # 웰치 이표본 t 검정
chisq.test(table(d$major, d$mode))    # 독립성 검정
summary(lm(score ~ hours, data = d))  # 단순회귀

t.test 출력의 t는 검정통계량, df는 자유도, p-value는 p값, 95 percent confidence interval은 두 평균 차이의 신뢰구간입니다. lm의 Coefficients 표에서 Estimate는 \(b_0, b_1\), Std. Error는 표준오차, Pr(>|t|)는 "계수가 0"을 검정한 p값입니다.

예제 7.1.1

R에 내장된 sleep 자료(10명에게 두 수면제를 준 추가 수면 시간)를 분석하세요.

풀이. 같은 10명이 두 약을 모두 먹었으므로 대응표본입니다.

with(sleep, t.test(extra[group == 2], extra[group == 1], paired = TRUE))

평균 차이 1.58시간, \(t = 4.06\), 자유도 9, p값 0.0028, 95% 신뢰구간 [0.70, 2.46]. 약 2가 약 1보다 수면을 더 늘린다고 봅니다.

요약
  1. 읽기 → 확인 → 요약·그림 → 검정 → 해석.
  2. 범주형 변수는 factor로 지정합니다.
  3. 출력에서 추정값, 표준오차, 검정통계량, 자유도, p값, 신뢰구간을 찾습니다.
