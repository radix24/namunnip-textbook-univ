통계패키지로 분석 절차 수행하기

본문

지금까지 평균, 신뢰구간, t 검정, 카이제곱 검정, 회귀를 손으로 계산했다. 실제 조사 자료는 수백 명, 수십 변수라 손으로는 할 수 없다. SAS, SPSS, MINITAB, R처럼 패키지마다 화면은 다른데, 무엇을 어떤 순서로 하고 쏟아지는 출력에서 무엇을 읽어야 할까?

먼저 알아야 할 것이 과목 2~6단원의 방법들을 쓴다.

7.1.1자료 읽기와 확인

처음 질문의 첫째 답은 그림 1의 흐름이다. 패키지마다 명령은 달라도 순서는 같으므로, 여기서는 무료인 R로 보인다. 먼저 자료를 읽고 확인한다.

d <- read.csv("survey.csv")      # 같은 폴더의 CSV 파일
str(d)          # 변수 이름, 형식, 앞부분 값
summary(d)      # 변수별 요약, 결측값(NA) 수
d$major <- factor(d$major)       # 범주형으로 지정

이때 숫자여야 할 변수가 문자로 읽혔는지, 결측값이 몇 개인지, 범위를 벗어난 값(나이 250)이 있는지를 먼저 본다. 또 학과 코드처럼 숫자로 적힌 범주형 변수는 factor로 바꾸어야 평균 같은 엉뚱한 계산을 막는다(1.4절).

7.1.2요약과 그림

mean(d$hours, na.rm = TRUE); sd(d$hours, na.rm = TRUE)
table(d$major)
boxplot(hours ~ major, data = d)

검정 전에 요약과 그림을 보는 까닭은, 이상값이나 치우침처럼 검정의 가정을 흔드는 문제를 먼저 찾기 위해서이다(2.4절).

7.1.3검정과 출력 읽기

t.test(hours ~ sex, data = d)         # 웰치 이표본 t 검정
chisq.test(table(d$major, d$mode))    # 독립성 검정
summary(lm(score ~ hours, data = d))  # 단순회귀

둘째 질문, 출력에서 읽을 것은 정해져 있다. t.test 출력의 t는 검정통계량, df는 자유도, p-value는 p값, 95 percent confidence interval은 두 평균 차이의 신뢰구간이다. 또 lm의 Coefficients 표에서 Estimate는 \(b_0\), \(b_1\), Std. Error는 표준오차, Pr(>|t|)는 "계수가 0"을 검정한 p값이다.

예제 7.1.1

R에 내장된 sleep 자료(10명에게 두 수면제를 준 추가 수면 시간)를 분석하여라.

with(sleep, t.test(extra[group == 2], extra[group == 1], paired = TRUE))

풀이. 같은 10명이 두 약을 모두 먹었으므로 대응표본이다(4.3절). 출력에서 평균 차이 1.58시간, \(t = 4.06\), 자유도 9, p값 0.0028, 95% 신뢰구간 [0.70, 2.46]을 읽는다. 따라서 약 2가 약 1보다 수면을 더 늘린다고 본다.

흔한 실수패키지는 자료 구조를 알지 못한다. sleep 자료를 짝을 무시하고 t.test(extra ~ group, data = sleep)로 분석해도 오류 없이 결과가 나오지만, p값이 약 0.079로 유의하지 않게 바뀐다. 어떤 검정이 맞는지는 자료가 어떻게 모였는지를 아는 사람이 정한다.
마무리

통계패키지로 하는 분석은 어떤 패키지든 읽기, 확인과 정리, 요약과 그림, 모형과 검정, 해석의 순서를 따른다. 읽은 뒤에는 형식, 결측, 범위를 확인하고 범주형 변수를 지정하며, 검정 전에 그림으로 가정을 점검한다. 출력에서는 추정값, 표준오차, 검정통계량, 자유도, p값, 신뢰구간을 찾아 읽되, 맞는 검정을 고르는 것은 패키지가 아니라 분석자의 몫이다.

7.1.4연습문제

기본

  1. summary(d)에서 나이 변수의 최댓값이 250으로 나왔다. 무엇을 해야 하는가?
    답

    입력 실수일 가능성이 크므로 원자료를 확인한다. 고칠 수 없으면 결측으로 처리하고, 처리한 사실과 개수를 보고서에 적는다.

응용

  1. sleep 자료를 짝을 무시하고 이표본 검정하면 p값이 0.079로 커지는 까닭을 설명하여라.
    답

    사람마다 기본 수면 반응이 크게 달라, 짝을 무시하면 그 개인차가 표준오차에 섞여 들어가 \(t\)가 작아지고 검정력이 떨어진다.
