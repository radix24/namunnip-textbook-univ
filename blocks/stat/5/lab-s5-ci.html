"95% 신뢰구간"의 95%는 무엇의 비율인가?

실습 · 신뢰구간

목표

평균을 아는 가상 모집단에서 표본을 100번 뽑아 신뢰구간 100개를 그린다. 그중 참 평균을 덮는 구간의 비율(덮임률)이 신뢰수준과 같아지는지, 언제 어긋나는지 확인한다. 성취기준 [응통5-03-02].

평균의 신뢰구간: \(\bar x \pm q \cdot s/\sqrt n\). \(s\)는 표본표준편차, \(q\)는 신뢰수준에 맞춘 곱하는 값이다.

t 분포를 쓰는 이유: 모집단 표준편차 \(\sigma\) 대신 표본에서 구한 \(s\)를 쓰면 \((\bar X - \mu)/(s/\sqrt n)\)은 정규분포보다 꼬리가 두꺼운 자유도 \(n-1\)인 t 분포를 따릅니다(모집단이 정규일 때). 그래서 \(q\)를 t 분포에서 찾는다. 95%이고 \(n = 10\)이면 \(q = 2.262\)로, 정규분포의 1.960보다 크다.

준비

모집단 평균은 \(\mu = 50\)(세로선), 표준편차는 10이다. 가로줄 하나가 표본 하나로 만든 구간이고, 파랑은 \(\mu\)를 덮은 구간, 빨강은 놓친 구간입니다. "100개 더"를 누르면 새 표본 100개로 다시 그리고 누적 덮임률을 갱신한다. 조절기를 바꾸면 누적은 처음부터 다시 센다.

절차

  1. 기본값(정규 모집단, \(n = 10\), 95%, t 분포)에서 "100개 더"를 10번 눌러 누적 덮임률을 본다.
  2. 신뢰수준을 80%, 99%로 바꿔 덮임률과 평균 너비가 어떻게 바뀌는지 적다.
  3. 신뢰수준 95%로 돌리고 곱하는 값을 "정규분포 z"로 바꾼다. \(n = 5\)와 \(n = 50\)에서 각각 10번 눌러 본다.
  4. 다시 t 분포로 두고 모집단을 "지수분포 모양"으로 바꿔 \(n = 5\), \(n = 50\)에서 비교한다.

기대 결과

  • 정규 모집단 + t 분포이면 누적 덮임률이 신뢰수준 근처(95%이면 대략 93~97%)에 머문다. 100개 한 묶음은 90~99개 사이에서 흔들린다.
  • 신뢰수준을 올리면 덮임률이 오르는 대신 구간이 넓어진다. \(n = 10\)에서 평균 너비는 80%일 때 약 8.5, 99%일 때 약 20입니다(평균 너비는 \(2q \cdot E(s)/\sqrt n\)이고 \(n = 10\)이면 \(E(s) \approx 9.7\)).
  • z를 잘못 쓰면 \(n = 5\)에서 덮임률이 약 88%로 떨어진다. 자유도 4인 t 분포에서 \(|T| > 1.96\)일 확률이 약 0.12이기 때문이다. \(n = 50\)이면 t와 z가 거의 같아 차이가 사라진다.
  • 치우친 모집단에서는 \(n = 5\)일 때 t 구간도 덮임률이 약 88%로 내려간다. \(n = 50\)이면 중심극한정리 덕분에 약 94%로 95%에 가까워지지만, 치우침의 흔적이 조금 남는다.

분석

  1. 구간 하나를 구한 뒤 "\(\mu\)가 이 구간에 있을 확률이 95%"라고 말하면 왜 틀린가요? 그림의 구간 하나는 \(\mu\)를 덮었거나 못 덮었거나 둘 중 하나이다. 95%는 무엇의 비율인지 적어 보자.
  2. 너비를 절반으로 줄이려면 \(n\)을 몇 배로 해야 하나요? 출력의 평균 너비로 확인해 보자.

더 해 보기

R: ci <- replicate(1000, { x <- rnorm(10, 50, 10); t.test(x)$conf.int }), mean(ci[1, ] <= 50 & 50 <= ci[2, ]). 비율의 신뢰구간(\(\hat p \pm 1.96\sqrt{\hat p(1-\hat p)/n}\))은 \(p\)가 0이나 1에 가까우면 덮임률이 크게 떨어진다. 같은 실험을 비율로 해 보자.
