일표본 t 검정과 대응표본 t 검정

본문
이 절에서 배울 것
  • 일표본 t 검정으로 한 평균을 기준값과 비교한다.
  • 짝지은 자료를 차이로 바꾸어 대응표본 t 검정을 한다.
  • t 검정의 가정과 그것이 깨질 때의 대처를 안다.
먼저 알아야 할 것
  • t 분포 (3.2절), p값 (4.1절).

같은 숫자, 다른 검정

학생 10명의 수학 점수를 특강 전과 후에 쟀습니다. 이 20개 숫자를 "두 집단"으로 보면 이표본 검정(4.4절), "10명 각각의 변화"로 보면 대응표본 검정이 됩니다. 어느 쪽이 맞는지는 자료가 어떻게 모였는지가 정합니다. 이 절은 평균 하나를 다루는 검정과, 짝지은 자료를 평균 하나의 문제로 바꾸는 방법을 다룹니다.

4.3.1일표본 t 검정

결과 4.3.1

\(H_0: \mu = \mu_0\)의 검정통계량 \(t = \dfrac{\bar x - \mu_0}{s/\sqrt n}\)은 \(H_0\)와 정규 모집단 가정 아래에서 자유도 \(n-1\)인 t 분포를 따릅니다. 양측 p값은 \(2P(T_{n-1} \ge |t|)\).

4.1절의 z 검정에서 \(\sigma\)를 \(s\)로 바꾸고 표준정규 대신 t 분포를 쓴 것뿐입니다. 손으로 할 때는 \(|t|\)를 임계값 \(t_{\alpha/2, n-1}\)과 비교합니다.

예제 4.3.2

과자 16봉지의 평균 중량이 98.5 g, 표준편차 2.4 g입니다. 표시 중량 100 g과 다른지 \(\alpha = 0.05\)에서 검정하세요(\(t_{0.025,15} = 2.131\)).

풀이. \(t = (98.5 - 100)/(2.4/4) = -2.5\), 자유도 15. \(|t| = 2.5 > 2.131\)이므로 기각합니다(p값 약 0.025). 평균 중량이 표시와 다르며, 구간 \(98.5 \pm 2.131 \times 0.6 = [97.2, 99.8]\)을 보면 1 g 안팎 적게 담기는 것으로 보입니다.

4.3.2대응표본 t 검정

같은 대상을 두 번 쟀거나 짝지은 자료(쌍둥이, 왼눈과 오른눈, 같은 날 두 가게의 가격)는 쌍마다 차이 \(d_i\)를 구해 일표본 t 검정을 합니다: \(t = \bar d/(s_d/\sqrt n)\), 자유도 \(n-1\)(\(n\)은 쌍의 수). 사람마다 다른 기본 실력이 차이를 구할 때 빠지므로, 같은 자료를 이표본으로 분석할 때보다 검정력이 훨씬 큽니다. 1.3절의 블록 설계에서 블록 크기가 2인 경우입니다.

예제 4.3.3

5명의 특강 전후 점수: (60, 66), (72, 75), (55, 62), (80, 81), (68, 74). 대응표본 t 검정으로 효과가 있는지 \(\alpha = 0.05\)에서 검정하세요.

풀이. 차이 6, 3, 7, 1, 6. \(\bar d = 4.6\), 편차 1.4, −1.6, 2.4, −3.6, 1.4의 제곱합 \(1.96 + 2.56 + 5.76 + 12.96 + 1.96 = 25.2\), \(s_d = \sqrt{25.2/4} \approx 2.51\). \(t = 4.6/(2.51/\sqrt5) \approx 4.10\), 자유도 4. 양측 임계값 \(t_{0.025,4} = 2.776\)보다 크므로 기각합니다(p값 약 0.015). 같은 자료를 이표본 웰치 검정으로 하면 두 평균 67.0과 71.6의 차이가 사람 사이 퍼짐(표준편차 약 9.8과 7.6)에 묻혀 \(t \approx 0.83\)으로 유의하지 않습니다.

before <- c(60, 72, 55, 80, 68); after <- c(66, 75, 62, 81, 74)
t.test(after, before, paired = TRUE)
t.test(after, before)   # 잘못된 분석: 짝을 무시함

4.3.3가정과 대처

  • 독립: 관측값(대응표본이면 쌍)끼리 독립이어야 합니다. 같은 사람을 여러 번 넣으면 안 됩니다.
  • 정규성: 모집단(대응표본이면 차이)이 정규분포에 가까워야 합니다. \(n\)이 작을수록 중요하고, \(n\)이 30 이상이면 심한 치우침이 아닌 한 중심극한정리로 괜찮습니다.
  • 작은 표본에서 이상값이 있거나 크게 치우쳤으면 부호순위 검정 같은 비모수 검정을 씁니다(응통12 04단원).
요약
  1. 일표본: \(t = (\bar x - \mu_0)/(s/\sqrt n)\), 자유도 \(n-1\).
  2. 대응표본: 짝의 차이 \(d_i\)로 일표본 검정. 짝을 무시하면 검정력을 잃습니다.
  3. 독립과 정규성을 점검하고, 작은 표본에서 깨지면 비모수 검정을 씁니다.

4.3.4연습문제

기본

  1. 다음에 알맞은 검정은? (가) 남녀 학생의 키 비교 (나) 같은 환자의 투약 전후 혈압 (다) 전구 수명이 1000시간인지
    답

    (가) 이표본(4.4절), (나) 대응표본, (다) 일표본.

응용

  1. 쌍둥이 8쌍 가운데 한 명씩만 새 학습법을 쓰게 해 점수 차이(새 학습법 − 기존)를 구했더니 평균 3.0, 표준편차 4.0이었습니다. \(\alpha = 0.05\)에서 양측 검정하세요(\(t_{0.025,7} = 2.365\)).
    답

    \(t = 3.0/(4.0/\sqrt8) \approx 2.12 < 2.365\)이므로 기각하지 않습니다. 효과가 있다는 증거가 부족합니다. 쌍이 8개뿐이라 검정력이 낮습니다.
