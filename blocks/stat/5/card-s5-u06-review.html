상관과 회귀 단원 마무리 연습

문제 6 · 계산·개념·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 계산자료 \((x, y)\) = (1, 2), (2, 4), (3, 5), (4, 4), (5, 5)의 표본상관계수를 구하여라. [06-01]

    힌트 1

    평균은 \(\bar x = 3\), \(\bar y = 4\)이다. \(S_{xy} = \sum(x-\bar x)(y-\bar y)\)를 계산하여라.

    힌트 2

    \(r = S_{xy}/\sqrt{S_{xx}S_{yy}}\)이다.

    풀이

    \(x\) 편차는 \(-2, -1, 0, 1, 2\), \(y\) 편차는 \(-2, 0, 1, 0, 1\)이다. \(S_{xy} = 4 + 0 + 0 + 0 + 2 = 6\), \(S_{xx} = 10\), \(S_{yy} = 4 + 0 + 1 + 0 + 1 = 6\)이다.

    \(r = 6/\sqrt{60} \approx 0.775\)이다. 양의 비교적 강한 선형 관계이다.

  2. 계산앞 문제 자료에 최소제곱 직선을 적합하고, \(x = 4\)에서 예측값과 잔차를 구하여라. 잔차의 합이 0인지도 확인하여라. [06-02]

    힌트 1

    기울기 \(b = S_{xy}/S_{xx}\), 절편 \(a = \bar y - b\bar x\)이다.

    힌트 2

    잔차는 관측값 − 예측값이다.

    풀이

    \(b = 6/10 = 0.6\), \(a = 4 - 0.6\times3 = 2.2\)이므로 \(\hat y = 2.2 + 0.6x\)이다. \(x = 4\)에서 예측값은 \(4.6\), 잔차는 \(4 - 4.6 = -0.6\)이다.

    예측값은 차례로 2.8, 3.4, 4.0, 4.6, 5.2이고 잔차는 \(-0.8, 0.6, 1.0, -0.6, -0.2\)이다. 합은 0이다. 절편이 있는 최소제곱 직선에서는 항상 그렇다.

  3. 개념\(x = -2, -1, 0, 1, 2\)이고 \(y = x^2\)인 자료의 상관계수를 구하고, "상관계수가 0이므로 두 변수는 관계가 없다"는 말이 왜 틀렸는지 써라. [06-01]

    힌트 1

    \(\bar x = 0\)이므로 \(S_{xy} = \sum x(y - \bar y) = \sum x^3 - \bar y\sum x\)이다.

    힌트 2

    상관계수는 어떤 종류의 관계를 재는 값인가요?

    풀이

    \(\sum x = 0\), \(\sum x^3 = 0\)이므로 \(S_{xy} = 0\), 곧 \(r = 0\)이다.

    그러나 \(y\)는 \(x\)로 완전히 정해진다. 상관계수는 직선 관계의 세기만 재므로, U자 같은 곡선 관계는 놓칠 수 있다. 그래서 상관계수를 보고하기 전에 반드시 산점도를 그려야 한다.

  4. 판단여름 동안 날마다 아이스크림 판매량과 물놀이 사고 건수의 상관계수가 0.8이었습니다. "아이스크림 판매를 줄이면 사고가 줄어든다"는 주장을 평가하여라. [06-01]

    힌트 1

    두 변수에 모두 영향을 주는 제3의 변수를 생각해 보아라.

    힌트 2

    상관은 인과의 방향도, 존재도 보장하지 않는다.

    풀이

    타당하지 않는다. 기온이 교란 변수일 가능성이 크다. 더운 날에는 아이스크림도 많이 팔리고 물놀이하는 사람도 많아 사고가 늘어난다. 아이스크림 판매를 줄여도 기온과 물놀이 인원이 그대로면 사고는 줄지 않을 것이다.

    관계를 확인하려면 기온을 고정한 상태(같은 기온대의 날끼리)에서 비교하거나, 기온을 회귀모형에 함께 넣어 보정해야 한다.

  5. 판단단순회귀의 잔차를 예측값에 대해 그렸더니 (가) U자 곡선 모양, (나) 예측값이 커질수록 잔차의 퍼짐이 커지는 깔때기 모양이 나타났다. 각각 무엇을 뜻하고 어떻게 대처할지 써라. [06-03]

    힌트 1

    잔차그림이 0 주위에 고르게 흩어져 있어야 모형이 맞는 것이다.

    힌트 2

    (가)는 평균 구조, (나)는 분산 구조의 문제이다.

    풀이

    (가) 직선 모형이 관계의 모양을 제대로 담지 못했다는 뜻입니다(비선형성). \(x^2\) 항을 넣거나 변수를 변환(로그 등)해 본다.

    (나) 오차의 분산이 일정하지 않다(이분산성)는 뜻이다. 기울기 추정 자체는 여전히 불편이지만 표준오차와 신뢰구간이 틀릴 수 있다. \(y\)에 로그나 제곱근 변환을 하거나, 가중 최소제곱이나 이분산에 강한 표준오차를 쓴다.

  6. 계산문제 2의 회귀에서 결정계수 \(R^2\)를 구해 해석하고, 이 직선으로 \(x = 20\)일 때의 \(y\)를 예측해도 되는지 판단하여라. [06-03]

    힌트 1

    단순회귀에서는 \(R^2 = r^2\)이다.

    힌트 2

    자료의 \(x\) 범위는 1부터 5까지이다.

    풀이

    \(R^2 = 0.775^2 = 0.6\)입니다(정확히는 \(S_{xy}^2/(S_{xx}S_{yy}) = 36/60\)). \(y\)의 변동 가운데 60%가 \(x\)와의 직선 관계로 설명된다는 뜻이다.

    \(x = 20\)을 넣으면 \(2.2 + 12 = 14.2\)가 나오지만, 자료가 1~5 범위에만 있으므로 이 예측은 외삽이다. 그 범위 밖에서도 직선 관계가 유지된다는 근거가 없어(실제로 이 자료는 4~5에서 이미 평평해 보인다) 믿기 어렵다.
