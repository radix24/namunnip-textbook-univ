결정계수와 잔차 그림

본문
이 절에서 배울 것
  • 변동을 설명된 부분과 남은 부분으로 나누고 결정계수를 구한다.
  • 잔차 그림의 무늬로 직선 모형의 문제를 찾는다.
  • \(R^2\)만으로 모형을 판단하면 안 되는 이유를 안다.
먼저 알아야 할 것
  • 최소제곱 직선과 잔차 (6.2절).

직선을 그렸다고 끝이 아니다

최소제곱 직선은 어떤 자료에도 그릴 수 있습니다. 점들이 곡선을 그리든, 이상점 하나가 직선을 끌고 가든 계산은 답을 내놓습니다. 그래서 적합한 뒤에는 두 가지를 묻습니다. "직선이 \(y\)의 차이를 얼마나 설명하는가?"(결정계수)와 "직선이 자료의 모양에 맞는가?"(잔차 그림)입니다.

6.3.1변동의 분해와 결정계수

각 \(y_i\)가 평균에서 떨어진 정도를 직선이 설명하는 부분과 남은 부분으로 나누면 \(y_i - \bar y = (\hat y_i - \bar y) + (y_i - \hat y_i)\)이고, 제곱해 더하면 교차항이 0이 되어

\[\underbrace{\sum(y_i - \bar y)^2}_{\text{SST}} = \underbrace{\sum(\hat y_i - \bar y)^2}_{\text{SSR}} + \underbrace{\sum(y_i - \hat y_i)^2}_{\text{SSE}}\]

입니다(5.1절 분산분석의 변동 분해와 같은 구조).

정의 6.3.1

결정계수: \(R^2 = \dfrac{\text{SSR}}{\text{SST}} = 1 - \dfrac{\text{SSE}}{\text{SST}}\). \(y\)의 변동 가운데 직선이 설명하는 비율. 단순회귀에서는 \(R^2 = r^2\).

\(R^2 = 0.6\)은 "\(y\)의 변동 60%가 \(x\)와의 직선 관계로 설명되고 40%는 남는다"는 뜻입니다. 남은 변동의 크기는 잔차 표준오차 \(s = \sqrt{\text{SSE}/(n-2)}\)로 \(y\)의 단위로 말할 수 있고, 예측이 대략 \(\pm 2s\) 안팎으로 빗나간다는 뜻입니다.

6.3.2잔차 그림

잔차를 \(x\)(또는 적합값 \(\hat y\))에 대해 그립니다. 직선 모형이 알맞으면 잔차가 0 둘레에 무늬 없이 고르게 흩어집니다. 흔한 무늬는 세 가지입니다.

  1. U자 또는 뒤집힌 U자: 관계가 곡선입니다. \(x^2\) 항을 넣거나 변수를 변환합니다(응통10 05단원).
  2. 나팔 모양: \(x\)가 커질수록 잔차가 넓게 퍼집니다. 분산이 일정하지 않아 예측 범위와 검정이 틀어집니다. 로그 변환이 흔한 해법입니다.
  3. 동떨어진 점: 잔차가 \(\pm 2s\)를 크게 넘는 이상점이나, \(x\)가 멀리 떨어져 직선을 끌어당기는 영향점. 응통10 04단원의 실습 카드에서 점 하나를 옮기며 확인할 수 있습니다.
예제 6.3.2

6.2절 예제 자료 (1, 2), (2, 4), (3, 5), (4, 4), (5, 5)와 직선 \(\hat y = 2.2 + 0.6x\)로 잔차, \(R^2\), 잔차 표준오차를 구하세요.

풀이. \(\hat y\) = 2.8, 3.4, 4.0, 4.6, 5.2. 잔차 −0.8, 0.6, 1.0, −0.6, −0.2(합 0). SSE \(= 0.64 + 0.36 + 1 + 0.36 + 0.04 = 2.4\), SST \(= 4 + 0 + 1 + 0 + 1 = 6\). \(R^2 = 1 - 2.4/6 = 0.6 = 0.775^2\). \(s = \sqrt{2.4/3} \approx 0.89\). 잔차가 음, 양, 양, 음, 음으로 가운데가 높은 뒤집힌 U자 기미가 있지만 점이 5개뿐이라 판단하기 어렵습니다.

fit <- lm(y ~ x); summary(fit)$r.squared; summary(fit)$sigma
plot(fitted(fit), resid(fit)); abline(h = 0)

6.3.3\(R^2\)가 말하지 않는 것

앤스컴의 네 자료는 평균, 표준편차, 상관계수, 회귀 직선, \(R^2\)(약 0.67)가 모두 같지만 산점도는 직선, 곡선, 이상점 하나, 영향점 하나로 전혀 다릅니다. \(R^2\)가 높아도 곡선 관계일 수 있고, 낮아도 직선 모형이 옳을 수 있습니다(잡음이 클 뿐). 또 \(R^2\)는 인과도, 예측의 정확도도 직접 말하지 않습니다. 언제나 산점도와 잔차 그림을 함께 봅니다.

요약
  1. SST = SSR + SSE, \(R^2 = 1 - \text{SSE}/\text{SST}\), 단순회귀에서는 \(r^2\).
  2. 잔차 표준오차 \(s = \sqrt{\text{SSE}/(n-2)}\)는 예측 오차의 전형적 크기입니다.
  3. 잔차 그림의 U자는 곡선, 나팔은 분산 변화, 동떨어진 점은 이상점·영향점을 뜻합니다.

6.3.4연습문제

기본

  1. \(r = -0.7\)이면 \(R^2\)는? 뜻은?
    답

    \(R^2 = 0.49\). \(y\)의 변동 49%가 \(x\)와의 직선 관계로 설명됩니다. 부호는 \(R^2\)에 나타나지 않습니다.

응용

  1. 나이(20~70세)로 연간 의료비를 예측한 회귀에서 잔차 그림이 나이가 많을수록 넓게 퍼지는 나팔 모양입니다. 어떤 문제가 생기고 어떻게 고칠 수 있나요?
    답

    분산이 일정하지 않아 젊은 층의 예측 범위는 지나치게 넓게, 고령층은 지나치게 좁게 잡힙니다. 의료비에 로그를 취하면 퍼짐이 고르게 되는 경우가 많고, 가중 최소제곱을 쓸 수도 있습니다(응통10 05단원).
