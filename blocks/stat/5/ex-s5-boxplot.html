손으로 상자그림 그리기

예제 · 다섯 숫자 요약과 울타리

먼저 읽는 법

상자그림은 순서대로 정렬 → 중앙값 → 사분위수 → IQR → 울타리 → 수염 끝 → 이상값 후보로 그린다. 수염 끝은 울타리 값이 아니라 울타리 안의 실제 자료라는 점만 조심하면 된다.

문제. 두 반의 과제 제출 지연 시간(시간)이다.
A반 (11명): 0, 1, 1, 2, 2, 3, 3, 4, 5, 6, 20
B반 (10명): 0, 2, 3, 4, 5, 5, 6, 7, 8, 9
각 반의 다섯 숫자 요약과 이상값 후보를 구하고, 두 상자그림을 비교하여라.

풀이

  1. A반: \(n = 11\)이므로 중앙값은 6번째 값 3. 아래 절반 0, 1, 1, 2, 2의 중앙값 \(Q_1 = 1\), 위 절반 3, 4, 5, 6, 20의 중앙값 \(Q_3 = 5\). IQR = 4.
    \(n\)이 홀수면 가운데 값(3)은 어느 절반에도 넣지 않는다.
  2. A반 울타리: \(1 - 6 = -5\), \(5 + 6 = 11\). 20은 11보다 커서 이상값 후보이다. 위쪽 수염은 11 안의 가장 큰 값 6까지, 아래쪽 수염은 0까지.
    \(1.5 \times 4 = 6\). 수염은 울타리 11이 아니라 실제 자료 6에서 끝난다.
  3. B반: \(n = 10\)이므로 중앙값은 5번째와 6번째 값 5, 5의 평균 5. 아래 절반 0, 2, 3, 4, 5의 중앙값 \(Q_1 = 3\), 위 절반 5, 6, 7, 8, 9의 중앙값 \(Q_3 = 7\). IQR = 4.
    짝수면 정확히 반씩 나눈다.
  4. B반 울타리: \(3 - 6 = -3\), \(7 + 6 = 13\). 모든 자료가 안에 있어 이상값 후보가 없고, 수염은 0과 9까지이다.
    울타리 밖 자료가 없으면 수염 끝이 최솟값, 최댓값과 같다.
  5. 비교: 두 반의 IQR은 4로 같지만 중앙값은 B반(5)이 A반(3)보다 높아, 보통 학생의 지연은 B반이 길다. A반은 대부분 짧지만 20시간 늦은 학생이 한 명 있다.
    상자그림은 "대부분의 학생"과 "예외적인 학생"을 따로 보여 준다.

검산

평균으로 비교하면 A반 \(47/11 \approx 4.3\), B반 \(49/10 = 4.9\)로 차이가 작아 보인다. 학생 한 명(20시간)이 A반 평균을 끌어올렸기 때문이다. 20을 빼면 A반 평균은 2.7로 중앙값 3과 비슷해진다. 상자그림의 결론과 맞다.

의미

"어느 반이 더 늦게 내는가"라는 질문에 평균은 거의 같다고, 중앙값은 B반이라고 답한다. 무엇을 보고할지는 질문이 정한다. 담당 교수가 "보통 학생"을 알고 싶다면 중앙값과 상자그림이, "늦게 낸 총시간"을 알고 싶다면 평균이 맞다.
