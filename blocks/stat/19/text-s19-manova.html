분산분석을 행렬로

세 가지 교수법이 국어·영어·수학 점수에 영향을 주는지 보려면 일원 분산분석을 세 번 하는 대신, 세 점수를 한 벡터로 보고 한 번에 검정합니다.

2.2.1제곱합 행렬

일원배치의 SSB, SSW를 행렬로 바꿉니다.

집단 간: \(B = \sum_k n_k(\bar{\mathbf x}_k - \bar{\mathbf x})(\bar{\mathbf x}_k - \bar{\mathbf x})^\top\).

집단 내: \(W = \sum_k\sum_i(\mathbf x_{ki} - \bar{\mathbf x}_k)(\mathbf x_{ki} - \bar{\mathbf x}_k)^\top\).

\(T = B + W\)(전체). 일변량에서는 \(F = \frac{SSB/(g-1)}{SSW/(N-g)}\)였지만 행렬은 나눌 수 없어, \(W^{-1}B\)의 고유값 \(\lambda_1, \lambda_2, \ldots\)로 요약합니다.

2.2.2검정통계량

이름식
윌크스 람다\(\Lambda = \dfrac{|W|}{|B + W|} = \prod\frac{1}{1 + \lambda_j}\) (작을수록 차이 큼)
필라이 대각합\(\sum\frac{\lambda_j}{1 + \lambda_j}\) (가정 위반에 가장 강건)
호텔링-롤리 대각합\(\sum\lambda_j\)
로이 최대근\(\lambda_1\)

각 통계량은 근사 F로 바꿔 p값을 얻습니다. 윌크스 람다는 우도비 검정에서 나오며, 일변량이면 \(SSW/SST = 1 - R^2\)입니다.

예제 2.2.1

iris 세 종의 측정값 4개를 MANOVA로 비교하세요.

fit <- manova(cbind(Sepal.Length, Sepal.Width, Petal.Length, Petal.Width) ~ Species, data = iris)
summary(fit, test = "Wilks"); summary(fit, test = "Pillai")
summary.aov(fit)       # 변수별 일원 분산분석

윌크스 람다가 0.023으로 0에 가까워 세 종의 평균벡터가 크게 다릅니다. 변수별 분산분석으로 어느 측정값이 차이를 만드는지 봅니다.

요약
  1. \(B\), \(W\) 제곱합 행렬, \(W^{-1}B\)의 고유값으로 요약.
  2. 윌크스, 필라이, 호텔링-롤리, 로이.
  3. 가정: 다변량 정규, 집단 공분산 동일.

2.2.3연습문제

기본

  1. \(W^{-1}B\)의 고유값이 4, 0.25이면 윌크스 람다는?
    답

    \(\frac{1}{5}\cdot\frac{1}{1.25} = 0.16\).
