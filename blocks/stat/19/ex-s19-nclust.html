잘못 나눈 군집의 실루엣

예제 · 군집 수 비교

먼저 읽는 법

같은 자료를 군집 2개와 3개로 나눠 평균 실루엣을 비교합니다. 자연스러운 덩어리를 쪼개면 실루엣이 떨어지는지 확인합니다.

문제. 1차원 자료 1, 2, 3, 8, 9, 10을 {1, 2, 3}, {8, 9}, {10}의 세 군집으로 나눴습니다(한 원소 군집의 실루엣은 0으로 둠). 점 8과 9의 실루엣과 평균 실루엣을 구하고, 두 군집 분할(평균 0.81)과 비교하세요.

풀이

  1. 점 8: \(a = 1\)(9까지), 다른 군집과의 평균 거리 {10}: 2, {1, 2, 3}: 6 → \(b = 2\). \(s = (2 - 1)/2 = 0.5\).
    가장 가까운 다른 군집은 {10}.
  2. 점 9: \(a = 1\), \(b = 1\)({10}까지). \(s = 0\).
    경계에 놓임.
  3. {1, 2, 3}의 실루엣은 이제 가장 가까운 군집 {8, 9}와의 거리로 계산: 점 1 \(b = 7.5\), \(s = 0.80\); 점 2 \(b = 6.5\), \(s = 0.85\); 점 3 \(b = 5.5\), \(s = 0.73\). 평균 \((0.80 + 0.85 + 0.73 + 0.5 + 0 + 0)/6 = 0.48\).
    두 군집 분할 0.81보다 크게 낮음.

검산

점 3: \(a = 1.5\), \(b = (5 + 6)/2 = 5.5\), \(s = 4/5.5 = 0.73\). 쪼갠 군집 {8, 9}, {10}의 점들이 실루엣을 끌어내립니다.

의미

자연스러운 덩어리를 억지로 쪼개면 쪼갠 조각의 관측들이 서로 가까워 실루엣이 0 근처로 떨어집니다. 그래서 평균 실루엣은 군집 수를 늘릴수록 좋아지는 \(W(k)\)와 달리 알맞은 \(k\)에서 최대가 됩니다. 다만 한 원소 군집의 실루엣을 어떻게 정하느냐 같은 약속에 따라 값이 달라지므로, 소프트웨어의 정의를 확인합니다.
