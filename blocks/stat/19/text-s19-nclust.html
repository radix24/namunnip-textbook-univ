군집 수 정하기: 팔꿈치와 실루엣

본문
이 절에서 배울 것
  • 군집 내 제곱합 그림의 팔꿈치로 군집 수를 어림한다.
  • 실루엣 계수를 계산하고 해석한다.
  • 군집 결과의 안정성을 점검하는 방법을 안다.
먼저 알아야 할 것
  • 계층적 군집과 k-평균 (6.1절).

정답이 없는 질문

k-평균은 군집 수 \(k\)를 미리 정해야 하고, 덴드로그램은 어디서 자를지 정해야 합니다. 이름표가 없으니 "맞는" \(k\)는 없지만, 자료가 뚜렷하게 나뉘는 수를 찾는 기준은 있습니다.

6.2.1팔꿈치 방법

\(k\)를 1부터 늘리며 군집 내 제곱합 \(W(k)\)를 그립니다. \(W(k)\)는 \(k\)가 늘면 항상 줄어드므로 가장 작은 값을 고를 수는 없고, 줄어드는 폭이 갑자기 작아지는 곳(팔꿈치)을 고릅니다. 팔꿈치가 뚜렷하지 않은 경우가 많아, 갭 통계량(무작위 자료의 \(W(k)\)와 비교)으로 보완하기도 합니다.

6.2.2실루엣 계수

정의 6.2.1

관측 \(i\)에 대해 \(a(i)\) = 같은 군집 다른 관측들과의 평균 거리, \(b(i)\) = 가장 가까운 다른 군집의 관측들과의 평균 거리. \(s(i) = \dfrac{b(i) - a(i)}{\max\{a(i), b(i)\}}\).

\(s(i)\)는 −1과 1 사이이고, 1에 가까우면 자기 군집에 잘 속하고, 0 근처면 경계에 있으며, 음수면 다른 군집에 더 가깝습니다. 모든 관측의 평균 실루엣이 가장 큰 \(k\)를 고릅니다. 관측별 실루엣 그림은 잘못 배정된 관측도 보여 줍니다. R: cluster::silhouette(km$cluster, dist(X)).

6.2.3안정성

붓스트랩 표본이나 자료 일부로 다시 군집했을 때 같은 관측들이 계속 함께 묶이는지 확인합니다. k-평균은 시작점에 따라 결과가 달라지므로 여러 번 시작(nstart = 25)합니다. 변수 척도에 따라 거리가 달라지므로 표준화 여부도 결과를 좌우합니다.

예제 6.2.2

1차원 자료 1, 2, 3, 8, 9, 10을 {1, 2, 3}, {8, 9, 10}으로 나눴습니다. 점 1과 점 3의 실루엣과 평균 실루엣을 구하세요.

풀이. 점 1: \(a = (1 + 2)/2 = 1.5\), \(b = (7 + 8 + 9)/3 = 8\), \(s = 6.5/8 = 0.81\). 점 3: \(a = (2 + 1)/2 = 1.5\), \(b = (5 + 6 + 7)/3 = 6\), \(s = 4.5/6 = 0.75\). 점 2는 \(a = 1\), \(b = 7\), \(s = 0.86\). 대칭이므로 평균 실루엣 0.81. 두 군집이 뚜렷이 나뉜 자료입니다.

요약
  1. 팔꿈치: \(W(k)\)의 감소가 갑자기 둔해지는 곳.
  2. 실루엣 \((b - a)/\max(a, b)\), 평균이 가장 큰 \(k\).
  3. 여러 시작점, 재표집으로 안정성을 확인하고 척도를 정합니다.

6.2.4연습문제

기본

  1. \(W(k)\)가 \(k = 1, \ldots, 5\)에서 1000, 420, 180, 160, 145이면 팔꿈치는?
    답

    감소 폭 580, 240, 20, 15. \(k = 3\) 뒤로 크게 둔해지므로 \(k = 3\).

응용

  1. 평균 실루엣이 0.25로 낮게 나왔습니다. 무엇을 뜻하고 어떻게 하나요?
    답

    군집 사이 구분이 약해 자료가 뚜렷한 덩어리로 나뉘지 않는다는 뜻입니다. 변수 선택이나 표준화를 다시 보거나, 연속적인 변화를 군집으로 억지로 나누고 있지 않은지(주성분 그림으로 확인) 따집니다.
