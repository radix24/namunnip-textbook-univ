인자 모형과 주성분분석의 차이

본문
이 절에서 배울 것
  • 인자 모형 \(\mathbf x = \boldsymbol\mu + L\mathbf f + \boldsymbol\varepsilon\)과 공통성을 안다.
  • 주성분분석과 목적·가정이 어떻게 다른지 설명한다.
먼저 알아야 할 것
  • 주성분 (3.1절).

보이지 않는 원인

국어, 영어, 수학, 과학 점수가 서로 상관되어 있는 것은 "언어 능력"과 "수리 능력" 같은 보이지 않는 요인이 점수를 만들기 때문이라고 생각할 수 있습니다. 인자분석은 관측 변수 뒤의 잠재 요인을 추정합니다.

4.1.1모형

정의 4.1.1

\(\mathbf x - \boldsymbol\mu = L\mathbf f + \boldsymbol\varepsilon\). \(\mathbf f\)(\(m\)개 공통 인자)는 평균 0, 분산 1, 서로 무상관. \(\boldsymbol\varepsilon\)(고유 인자)은 서로 무상관이고 분산 \(\psi_j\). \(L\)은 \(p\times m\) 적재 행렬.

그러면 \(\Sigma = LL^\top + \Psi\). 변수 \(j\)의 분산 = 공통성 \(h_j^2 = \sum_k l_{jk}^2\)(공통 인자가 설명) + 고유분산 \(\psi_j\). 변수 사이 공분산은 모두 공통 인자에서 나옵니다.

4.1.2주성분분석과 비교

주성분분석인자분석
목적변동 요약(차원 축소)공분산을 만드는 잠재 요인 설명
모형없음(변환)확률 모형, 오차 항 있음
설명 대상총분산공통분산(공분산 구조)
방향성분 = 변수의 결합변수 = 인자의 결합 + 오차
유일성유일(부호 제외)회전에 대해 불확정(4.2절)

추정은 최대가능도(다변량 정규 가정, R의 factanal)나 주축 인자법으로 합니다. 인자 수는 가능도비 검정, 스크리, 해석 가능성으로 정합니다.

예제 4.1.1

적재 \(l_1 = (0.9, 0.8, 0.7)\)(인자 하나)이면 각 변수의 공통성과 고유분산, 변수 1·2의 상관은?

풀이. 공통성 0.81, 0.64, 0.49, 고유분산 0.19, 0.36, 0.51(표준화 변수). 상관 \(r_{12} = 0.9\times0.8 = 0.72\).

요약
  1. \(\Sigma = LL^\top + \Psi\), 공통성 + 고유분산.
  2. 주성분은 요약, 인자분석은 잠재 요인 모형.
  3. factanal(x, factors = m).
