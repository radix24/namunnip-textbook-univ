인자 모형과 주성분분석의 차이

본문

국어, 영어, 수학, 과학 점수가 서로 상관되어 있는 것은 언어 능력과 수리 능력처럼 눈에 보이지 않는 요인이 점수를 만들기 때문일지도 모른다. 주성분분석으로 변수를 요약하는 것과, 점수 뒤에 숨은 원인을 찾는 것은 같은 일일까?

먼저 알아야 할 것주성분(3.1절)을 쓴다.

처음 질문의 답은 같지 않다는 것이다. 주성분분석은 변수의 결합으로 변동을 요약하는 변환일 뿐 모형이 없다. 반면 인자분석은 관측 변수가 소수의 잠재 인자와 고유한 오차의 합이라는 확률 모형을 세우고, 변수 사이의 공분산을 그 인자로 설명한다(그림 1). 즉 방향이 반대이다. 주성분은 변수의 결합이고, 인자분석에서는 변수가 인자의 결합이다.

4.1.1모형

정의 4.1.1 (인자 모형)

\(\mathbf x - \boldsymbol\mu = L\mathbf f + \boldsymbol\varepsilon\)이다. 공통 인자 \(\mathbf f\)(\(m\)개)는 평균 0, 분산 1이고 서로 무상관이다. 고유 인자 \(\boldsymbol\varepsilon\)은 서로 무상관이고 분산이 \(\psi_j\)이며, \(L\)은 \(p \times m\) 적재 행렬이다.

그러면 \(\Sigma = LL^\top + \Psi\)이다. 따라서 변수 \(j\)의 분산은 공통 인자가 설명하는 공통성 \(h_j^2 = \sum_k l_{jk}^2\)과 고유분산 \(\psi_j\)의 합이고, 변수 사이의 공분산은 모두 공통 인자에서 나온다.

4.1.2주성분분석과 비교

두 방법은 목적과 가정이 다르다(표 1).

표 1. 주성분분석과 인자분석
주성분분석인자분석
목적변동 요약(차원 축소)공분산을 만드는 잠재 요인 설명
모형없음(변환)확률 모형, 오차 항 있음
설명 대상총분산공통분산(공분산 구조)
방향성분 = 변수의 결합변수 = 인자의 결합 + 오차
유일성유일(부호 제외)회전에 대해 불확정(4.2절)

추정은 다변량 정규를 가정한 최대가능도(R의 factanal)나 주축 인자법으로 한다. 또 인자 수는 가능도비 검정, 스크리, 해석 가능성으로 정한다(4.3절).

예제 4.1.1

적재가 \(l_1 = (0.9, 0.8, 0.7)\)인 인자 하나의 모형에서 각 변수의 공통성과 고유분산, 변수 1과 2의 상관을 구하라.

풀이. 표준화 변수이므로 공통성은 0.81, 0.64, 0.49이고 고유분산은 0.19, 0.36, 0.51이다. 그리고 상관은 \(r_{12} = 0.9 \times 0.8 = 0.72\)이다(그림 1).

흔한 오해

주성분분석의 결과를 인자분석이라 부르며 잠재 요인으로 해석하는 일이 흔하다. 하지만 주성분은 고유분산까지 섞인 총분산을 요약하므로, 공통 인자의 구조와 다를 수 있다. 특히 변수가 적고 고유분산이 크면 차이가 커진다.

마무리

인자 모형은 \(\Sigma = LL^\top + \Psi\)로 각 변수의 분산을 공통성과 고유분산으로 나눈다. 주성분분석은 변동을 요약하는 변환이고, 인자분석은 공분산을 만드는 잠재 요인의 확률 모형이다. R에서는 factanal(x, factors = m)으로 적합한다.

4.1.3연습문제

기본

  1. 예제에서 변수 2와 3의 상관은 얼마인가?
    답

    \(0.8 \times 0.7 = 0.56\)이다.

응용

  1. 변수 3개의 상관이 \(r_{12} = 0.48\), \(r_{13} = 0.40\), \(r_{23} = 0.30\)이고 인자 하나의 모형이 맞는다. 적재 \(l_1\)을 구하라.
    답

    \(l_1^2 = r_{12}r_{13}/r_{23} = 0.48 \times 0.40/0.30 = 0.64\)이므로 \(l_1 = 0.8\)이다. 그러면 \(l_2 = 0.6\), \(l_3 = 0.5\)이다.

  2. 인자 모형의 모수(적재와 고유분산)의 수가 공분산 행렬의 서로 다른 원소 수보다 많으면 어떤 문제가 생기는가?
    답

    모형이 식별되지 않아 같은 공분산을 설명하는 해가 무수히 많다. 그래서 \(p\)개 변수에서 쓸 수 있는 인자 수 \(m\)에는 한계가 있다.
