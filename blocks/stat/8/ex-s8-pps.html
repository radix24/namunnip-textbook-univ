PPS와 같은 확률 추출의 정확도 비교

예제 · 핸슨-허위츠 추정량

먼저 읽는 법

모집단이 작으면 가능한 모든 추출 결과를 나열해 추정량의 분포를 직접 볼 수 있습니다. 한 번 뽑는 경우(\(n = 1\))만 비교해도 두 설계의 차이가 분명히 드러납니다.

문제. 마을 4곳의 가구 수 \(M_i\)와 총 쌀 소비량 \(t_i\)(가마)가 (10, 22), (20, 38), (30, 63), (40, 77)입니다(총계 \(Y = 200\)). 마을 하나를 (가) 같은 확률로 뽑아 \(\hat Y = 4t_i\), (나) PPS로 뽑아 \(\hat Y = t_i/p_i\)로 추정할 때 각 추정량의 분포와 분산을 구하세요.

풀이

  1. (가) 확률 1/4씩 \(\hat Y\) = 88, 152, 252, 308. 평균 200(불편), 분산 \(\frac14[(−112)^2 + (−48)^2 + 52^2 + 108^2] = \frac14(12544 + 2304 + 2704 + 11664) = 7304\), 표준편차 85.5.
    작은 마을이 뽑히면 총계를 크게 과소 추정합니다.
  2. (나) \(M_0 = 100\), \(p_i\) = 0.1, 0.2, 0.3, 0.4. \(t_i/p_i\) = 220, 190, 210, 192.5. 평균 \(0.1(220) + 0.2(190) + 0.3(210) + 0.4(192.5) = 22 + 38 + 63 + 77 = 200\)(불편).
    \(t_i/p_i = 100 \times\) 가구당 소비량이라 마을마다 비슷합니다.
  3. 분산 \(0.1(20)^2 + 0.2(−10)^2 + 0.3(10)^2 + 0.4(−7.5)^2 = 40 + 20 + 30 + 22.5 = 112.5\), 표준편차 10.6.
    같은 확률 추출의 분산 7304에 비해 65분의 1입니다.

검산

가구당 소비량 \(t_i/M_i\)는 2.2, 1.9, 2.1, 1.925로 거의 같습니다. PPS 추정량은 "뽑힌 마을의 가구당 소비량 × 전체 가구 수"이므로 이 작은 차이만 반영해 흔들림이 작습니다. 같은 확률 추출은 마을 크기 차이(10~40가구)를 그대로 떠안습니다.

의미

PPS의 이득은 "집락 총계가 크기에 거의 비례할 때" 큽니다. 반대로 관심 변수가 크기와 무관하면(예: 마을 이장의 나이) PPS는 오히려 분산을 키울 수 있습니다. 설계는 무엇을 추정하려는지에 맞춰 정합니다.
