모든 표본을 나열해 HT의 불편성 확인하기

예제 · 호르비츠-톰슨 추정량

먼저 읽는 법

불편성은 "가능한 모든 표본에 대해 추정값을 확률로 가중평균하면 참값"이라는 뜻이다. 모집단과 표본이 작으면 직접 나열해 확인할 수 있고, 이 과정이 정리 6.2.1의 증명을 구체적으로 보여 준다.

문제. 모집단 3개 단위 A, B, C의 값이 \(y\) = 2, 4, 9(총계 15)이다. 크기 2인 표본을 확률 \(P(\{A,B\}) = 0.5\), \(P(\{A,C\}) = 0.2\), \(P(\{B,C\}) = 0.3\)으로 뽑는다. (1) 각 단위의 포함 확률을 구하여라. (2) 세 표본의 HT 추정값과 그 기대값, 분산을 구하여라. (3) 같은 설계에서 \(N\bar y = 3\bar y\)는 불편인가요?

풀이

  1. (1) \(\pi_A = 0.5 + 0.2 = 0.7\), \(\pi_B = 0.5 + 0.3 = 0.8\), \(\pi_C = 0.2 + 0.3 = 0.5\). 합은 2(표본 크기).
    단위가 들어 있는 표본의 확률을 더한다.
  2. (2) \(y/\pi\) = 2.857, 5, 18. {A,B}: 7.857, {A,C}: 20.857, {B,C}: 23.
    표본 안 단위의 \(y/\pi\)를 더한다.
  3. 기대값 \(0.5(7.857) + 0.2(20.857) + 0.3(23) = 3.929 + 4.171 + 6.9 = 15.0\). 불편이다. 분산 \(0.5(7.143)^2 + 0.2(5.857)^2 + 0.3(8)^2 = 25.51 + 6.86 + 19.2 \approx 51.6\).
    정리 6.2.1이 이 설계에서도 성립한다.
  4. (3) \(3\bar y\): {A,B} 9, {A,C} 16.5, {B,C} 19.5. 기대값 \(4.5 + 3.3 + 5.85 = 13.65 \ne 15\). 치우쳐 있다.
    C(값이 큰 단위)가 덜 뽑히는 설계인데 이를 반영하지 않았기 때문이다.

검산

정리 6.2.2로 분산을 다시 구한다. \(\pi_{AB} = 0.5\), \(\pi_{AC} = 0.2\), \(\pi_{BC} = 0.3\). 대각 항 \(\sum \pi_i(1-\pi_i)(y_i/\pi_i)^2 = 0.21(8.163) + 0.16(25) + 0.25(324) = 1.714 + 4 + 81 = 86.71\). 비대각 항 \(2[(0.5 - 0.56)(14.29) + (0.2 - 0.35)(51.43) + (0.3 - 0.4)(90)] = 2[-0.857 - 7.714 - 9] = -35.14\). 합 51.57로 위와 같다.

의미

포함 확률이 다른 설계에서는 "표본평균 × N"이 치우치고, 확률의 역수로 가중해야 불편이 된다. 분산이 큰 까닭은 C의 \(y/\pi = 18\)이 다른 단위보다 훨씬 커서인데, 값이 큰 단위를 덜 뽑는 이 설계가 HT에 불리하기 때문입니다(6.2.2절). \(\pi\)를 \(y\)에 비례하게 바꾸면 분산이 줄어든다.
