2.1.1설계 기반 추론

모집단 값 \(y_1, \ldots, y_N\)은 고정된 수이고, 우연은 어떤 \(n\)개를 뽑느냐에서만 생깁니다. 이것을 설계 기반 추론이라 하며, 모집단이 어떤 분포를 따른다는 가정이 필요 없다는 것이 강점입니다. 모평균 \(\bar Y = \frac1N\sum y_i\), 모총계 \(Y = N\bar Y\), 모분산 \(S^2 = \frac{1}{N-1}\sum(y_i - \bar Y)^2\)은 모두 모르는 고정값입니다.

정의 2.1.1

단순임의추출(SRS): 크기 \(n\)인 \(\binom Nn\)개의 표본이 모두 같은 확률로 뽑히는 방법. 각 단위가 뽑힐 확률은 \(n/N\)이고, 이 비율 \(f = n/N\)을 추출률이라 합니다.

2.1.2추정량과 분산

정리 2.1.2

표본평균 \(\bar y\)는 \(\bar Y\)의 불편추정량이고 \(\mathrm{Var}(\bar y) = \left(1 - \dfrac nN\right)\dfrac{S^2}{n}\). 표본분산 \(s^2\)은 \(S^2\)의 불편추정량이다.

\(Z_i\) = \(i\)가 뽑히면 1인 지시변수. \(P(Z_i = 1) = n/N\), \(i \ne j\)이면 \(P(Z_iZ_j = 1) = \frac{n(n-1)}{N(N-1)}\). \(\bar y = \frac1n\sum Z_iy_i\)이므로 \(E(\bar y) = \frac1n\sum\frac nNy_i = \bar Y\). \(\mathrm{Var}(Z_i) = \frac nN(1 - \frac nN)\), \(\mathrm{Cov}(Z_i, Z_j) = \frac{n(n-1)}{N(N-1)} - \frac{n^2}{N^2} = -\frac{n(N-n)}{N^2(N-1)}\). 이를 \(\mathrm{Var}(\sum Z_iy_i) = \sum y_i^2\mathrm{Var}Z_i + \sum_{i\ne j}y_iy_j\mathrm{Cov}\)에 넣고 \(\sum_{i \ne j}y_iy_j = (\sum y_i)^2 - \sum y_i^2\)를 쓰면 정리됩니다. ∎

여기서 확률변수는 \(y_i\)가 아니라 포함 지시변수 \(Z_i\)입니다. 공분산이 음수인 까닭은 한 사람이 뽑히면 다른 사람이 뽑힐 자리가 줄기 때문입니다. 분산 추정은 \(S^2\) 자리에 \(s^2\)을 넣습니다. 총계 \(Y\)의 추정량 \(\hat Y = N\bar y\)는 불편이고 분산은 \(N^2\)배입니다.

모수추정량분산 추정
평균 \(\bar Y\)\(\bar y\)\((1 - n/N)s^2/n\)
총계 \(Y = N\bar Y\)\(N\bar y\)\(N^2(1-n/N)s^2/n\)

신뢰구간은 \(n\)이 너무 작지 않으면 정규 근사로 추정값 \(\pm 1.96\)×표준오차를 씁니다. 모집단이 유한해도 성립하는 중심극한정리(유한 모집단 중심극한정리)가 근거이며, \(n\)과 \(N - n\)이 모두 커야 합니다.

예제 2.1.3

학생 2000명 중 100명을 단순임의추출해 한 주 아르바이트 시간을 물었더니 \(\bar y = 9.2\), \(s = 6\)이었습니다. 평균과 총 아르바이트 시간의 95% 신뢰구간은?

풀이. \(\mathrm{se}(\bar y) = \sqrt{0.95 \times 36/100} = 0.585\). 평균 \(9.2 \pm 1.96 \times 0.585 = 9.2 \pm 1.15\), 곧 [8.05, 10.35]시간. 총계 \(2000 \times 9.2 = 18400\), 표준오차 \(2000 \times 0.585 = 1170\), 구간 \(18400 \pm 2290\)시간.

library(survey)
d <- data.frame(y = y, fpc = 2000)
des <- svydesign(ids = ~1, fpc = ~fpc, data = d)
svymean(~y, des); svytotal(~y, des)
요약
  1. 설계 기반: 모집단 값은 고정, 우연은 추출에서.
  2. \(\mathrm{Var}(\bar y) = (1 - n/N)S^2/n\), 총계는 \(N^2\)배.
  3. 증명은 포함 지시변수의 평균과 (음의) 공분산으로 합니다.

2.1.3연습문제

기본

  1. 가구 500개 중 50개를 뽑아 한 달 전기 요금 평균 6.2만 원, 표준편차 2.0만 원을 얻었습니다. 총 요금의 추정값과 표준오차는?
    답

    \(\hat Y = 3100\)만 원. \(\mathrm{se} = 500\sqrt{0.9 \times 4/50} = 500 \times 0.268 = 134\)만 원.

응용

  1. \(n = N\)이면 \(\mathrm{Var}(\bar y)\)는? 이것이 말이 되는 이유를 쓰세요.
    답

    \(1 - n/N = 0\)이라 0입니다. 전수조사이면 \(\bar y = \bar Y\)로 우연이 없습니다.
