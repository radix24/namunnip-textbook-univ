누적분포함수 방법과 역변환

본문

컴퓨터의 난수 생성기는 0과 1 사이의 균일한 수만 만든다. 그런데 시뮬레이션에는 지수분포, 정규분포, 파레토분포의 난수가 필요하다. 균일 난수 하나를 어떻게 바꾸면 원하는 분포의 난수가 될까? 더 넓게, \(X\)의 분포를 알 때 \(Y = g(X)\)의 분포는 어떻게 구할까?

먼저 알아야 할 것누적분포함수와 밀도(2.1절)를 쓴다.

2.2.1누적분포함수 방법

처음 질문의 둘째 부분부터 답하자. 어떤 변환에도 쓸 수 있는 가장 기본적인 방법은 분포함수를 거치는 것이다. \(F_Y(y) = P(g(X) \le y)\)에서 사건 \(\{g(X) \le y\}\)를 \(X\)가 놓일 집합 \(\{x : g(x) \le y\}\)로 바꾸고 \(X\)의 분포로 계산한다. 연속형이면 마지막에 미분해 밀도를 얻는다. 단계는 세 개이다. 먼저 \(Y\)가 가질 수 있는 값의 범위를 정하고, 다음으로 그 범위의 \(y\)마다 \(\{g(x) \le y\}\)를 \(x\)의 구간으로 푼 뒤, 끝으로 확률을 계산하고 미분한다. 단조 변환에서 이를 공식으로 줄이는 것은 2.3절에서 한다.

예제 2.2.1

\(X \sim N(0, 1)\)일 때 \(Y = X^2\)의 밀도함수를 구하여라.

풀이. \(Y \ge 0\)이고, \(y > 0\)에서 \(F_Y(y) = P(-\sqrt y \le X \le \sqrt y) = \Phi(\sqrt y) - \Phi(-\sqrt y)\)이다. 미분하면 \(f_Y(y) = \phi(\sqrt y)\frac{1}{2\sqrt y} + \phi(-\sqrt y)\frac1{2\sqrt y} = \frac{1}{\sqrt{2\pi y}}e^{-y/2}\)이다. 이것이 자유도 1인 카이제곱 분포이다(6.1절). \(X^2\)는 단조가 아니므로 양쪽 가지를 모두 더했다.

2.2.2여러 변수의 함수, 최댓값과 최솟값

같은 방법이 여러 변수의 함수에도 통한다. \(X_1, \ldots, X_n\)이 독립이고 분포함수가 \(F\)이면, 최댓값 \(M = \max X_i\)에 대해 \(\{M \le y\} = \{X_1 \le y, \ldots, X_n \le y\}\)이므로 \(F_M(y) = F(y)^n\)이다. 또 최솟값 \(m\)은 \(P(m > y) = [1 - F(y)]^n\)이다. 예를 들어 하나라도 고장 나면 멈추는 직렬 부품의 수명은 최솟값이고, 모두 고장 나야 멈추는 병렬 부품은 최댓값이다. 6.4절의 순서통계량이 이 계산을 일반화한다.

예제 2.2.2

수명이 독립인 \(\mathrm{Exp}(\lambda)\) 부품 3개를 직렬로 연결한 장치의 수명 분포는 무엇인가?

풀이. \(P(m > y) = (e^{-\lambda y})^3 = e^{-3\lambda y}\)이므로 장치 수명은 \(\mathrm{Exp}(3\lambda)\)이고, 평균은 부품 하나의 1/3이다.

2.2.3확률적분변환과 역변환법

이제 처음 질문의 첫째 부분이다.

정리 2.2.3 (확률적분변환과 역변환)

(가) \(X\)의 분포함수 \(F\)가 연속이면 \(F(X) \sim U(0, 1)\)이다. (나) \(U \sim U(0, 1)\)이고 \(F^{-1}(u) = \inf\{x : F(x) \ge u\}\)이면 \(F^{-1}(U)\)의 분포함수는 \(F\)이다.

증명. (나) \(F^{-1}(u) \le x \iff u \le F(x)\)이므로 \(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\)이다. (가)는 \(F\)가 순증가인 경우 \(P(F(X) \le u) = P(X \le F^{-1}(u)) = u\)에서 나오며, 일반적인 연속 \(F\)에서도 같은 결론이 성립한다. ∎

(나)가 역변환법이다. 균일 난수 하나를 \(F^{-1}\)에 넣으면 원하는 분포의 난수가 된다(그림 1). 지수분포는 \(F(x) = 1 - e^{-\lambda x}\)에서 \(F^{-1}(u) = -\ln(1-u)/\lambda\)이고, \(1 - U\)도 균일이므로 \(-\ln U/\lambda\)를 쓴다. 한편 (가)는 분포 적합 검정(응통12 5단원)과, p값이 귀무가설 아래에서 균일분포를 따르는 이유이다.

주의역변환법은 \(F^{-1}\)을 식으로 쓸 수 있을 때 편하다. 정규분포처럼 \(F^{-1}\)이 닫힌 꼴로 없으면 수치로 역함수를 구하거나, 박스-뮬러 방법(2.3절 연습문제) 같은 다른 변환을 쓴다.
마무리

\(Y = g(X)\)의 분포는 \(F_Y(y) = P(g(X) \le y)\)를 \(X\)에 대한 사건으로 바꿔 계산하고 미분해 구하며, 단조가 아니면 여러 가지를 모두 더한다. 독립인 \(n\)개의 최댓값의 분포함수는 \(F^n\), 최솟값은 \(1 - (1-F)^n\)이다. 연속 분포에서 \(F(X) \sim U(0,1)\)이고 \(F^{-1}(U) \sim F\)이므로, 균일 난수를 \(F^{-1}\)에 넣으면 원하는 분포의 난수가 된다.

2.2.4연습문제

기본

  1. \(X \sim U(-1, 1)\)일 때 \(Y = |X|\)의 분포는 무엇인가?
    답

    \(0 \le y \le 1\)에서 \(F_Y(y) = P(-y \le X \le y) = y\)이므로 \(Y \sim U(0, 1)\)이다.

응용

  1. 분포함수 \(F(x) = 1 - (1 + x)^{-3}\) (\(x > 0\), 파레토형)을 따르는 난수를 균일 난수로 만드는 식을 써라.
    답

    \(u = 1 - (1+x)^{-3}\)을 풀면 \(x = (1-u)^{-1/3} - 1\)이다. \(1 - U\)도 균일이므로 \(X = U^{-1/3} - 1\)로 써도 된다.
