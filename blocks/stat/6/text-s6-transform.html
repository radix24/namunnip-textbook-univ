누적분포함수 방법과 역변환

본문
이 절에서 배울 것
  • \(Y = g(X)\)의 분포함수를 \(X\)에 대한 사건으로 바꿔 구한다.
  • 최댓값, 최솟값처럼 여러 변수의 함수에도 같은 방법을 쓴다.
  • 확률적분변환과 역변환법의 원리를 안다.
먼저 알아야 할 것
  • 누적분포함수와 밀도 (2.1절).

섭씨에서 화씨로, 반지름에서 넓이로

\(X\)의 분포를 알 때 \(Y = 1.8X + 32\)나 \(Y = \pi X^2\)의 분포를 알고 싶은 일이 많습니다. 컴퓨터가 균일 난수로 다른 분포의 난수를 만드는 원리도 변환입니다. 이 절은 어떤 변환에도 쓸 수 있는 가장 기본적인 방법, 분포함수를 거치는 방법을 다룹니다. 단조 변환에서 이를 공식으로 줄이는 것은 다음 절에서 합니다.

2.2.1누적분포함수 방법

\(F_Y(y) = P(g(X) \le y)\)에서 사건 \(\{g(X) \le y\}\)를 \(X\)가 놓일 집합 \(\{x : g(x) \le y\}\)로 바꾸고 \(X\)의 분포로 계산합니다. 연속형이면 마지막에 미분해 밀도를 얻습니다. 단계는 세 개입니다. (1) \(Y\)가 가질 수 있는 값의 범위를 정한다. (2) 그 범위의 \(y\)마다 \(\{g(x) \le y\}\)를 \(x\)의 구간으로 푼다. (3) 확률을 계산하고 미분한다.

예제 2.2.1

\(X \sim N(0, 1)\)일 때 \(Y = X^2\)의 밀도함수를 구하세요.

풀이. \(Y \ge 0\). \(y > 0\)에서 \(F_Y(y) = P(-\sqrt y \le X \le \sqrt y) = \Phi(\sqrt y) - \Phi(-\sqrt y)\). 미분하면 \(f_Y(y) = \phi(\sqrt y)\frac{1}{2\sqrt y} + \phi(-\sqrt y)\frac1{2\sqrt y} = \frac{1}{\sqrt{2\pi y}}e^{-y/2}\). 이것이 자유도 1인 카이제곱 분포입니다(6.1절). \(X^2\)는 단조가 아니므로 양쪽 가지를 모두 더했습니다.

2.2.2여러 변수의 함수: 최댓값과 최솟값

같은 방법이 여러 변수의 함수에도 통합니다. \(X_1, \ldots, X_n\)이 독립이고 분포함수가 \(F\)이면 최댓값 \(M = \max X_i\)에 대해 \(\{M \le y\} = \{X_1 \le y, \ldots, X_n \le y\}\)이므로 \(F_M(y) = F(y)^n\)이고, 최솟값 \(m\)은 \(P(m > y) = [1 - F(y)]^n\)입니다. 직렬로 연결된 부품(하나라도 고장 나면 멈춤)의 수명은 최솟값, 병렬(모두 고장 나야 멈춤)은 최댓값입니다. 6.4절의 순서통계량이 이 계산을 일반화합니다.

예제 2.2.2

수명이 독립인 \(\mathrm{Exp}(\lambda)\) 부품 3개를 직렬로 연결한 장치의 수명 분포는?

풀이. \(P(m > y) = (e^{-\lambda y})^3 = e^{-3\lambda y}\). 장치 수명은 \(\mathrm{Exp}(3\lambda)\), 평균은 부품 하나의 1/3입니다.

2.2.3확률적분변환과 역변환법

정리 2.2.3

(가) \(X\)의 분포함수 \(F\)가 연속이면 \(F(X) \sim U(0, 1)\). (나) \(U \sim U(0, 1)\)이고 \(F^{-1}(u) = \inf\{x : F(x) \ge u\}\)이면 \(F^{-1}(U)\)의 분포함수는 \(F\)입니다.

(나) \(F^{-1}(u) \le x \iff u \le F(x)\)이므로 \(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\). (가)는 \(F\)가 순증가인 경우 \(P(F(X) \le u) = P(X \le F^{-1}(u)) = u\)에서 나오며, 일반적인 연속 \(F\)에서도 같은 결론이 성립합니다. ∎

(나)가 역변환법입니다. 균일 난수 하나를 \(F^{-1}\)에 넣으면 원하는 분포의 난수가 됩니다. 지수분포는 \(F(x) = 1 - e^{-\lambda x}\)에서 \(F^{-1}(u) = -\ln(1-u)/\lambda\)이고, \(1 - U\)도 균일이므로 \(-\ln U/\lambda\)를 씁니다. (가)는 분포 적합 검정(응통12 05단원)과 p값이 귀무가설 아래에서 균일분포를 따르는 이유입니다. 이 절의 실습 카드에서 여러 변환을 직접 해 볼 수 있습니다.

요약
  1. \(F_Y(y) = P(g(X) \le y)\)를 \(X\)의 사건으로 바꿔 계산하고 미분합니다.
  2. 독립인 \(n\)개의 최댓값은 \(F^n\), 최솟값은 \(1 - (1-F)^n\).
  3. \(F(X) \sim U(0,1)\), \(F^{-1}(U) \sim F\): 역변환법의 원리.

2.2.4연습문제

기본

  1. \(X \sim U(-1, 1)\)일 때 \(Y = |X|\)의 분포는?
    답

    \(0 \le y \le 1\)에서 \(F_Y(y) = P(-y \le X \le y) = y\). \(Y \sim U(0, 1)\).

응용

  1. 분포함수 \(F(x) = 1 - (1 + x)^{-3}\) (\(x > 0\), 파레토형)을 따르는 난수를 균일 난수로 만드는 식을 쓰세요.
    답

    \(u = 1 - (1+x)^{-3}\)을 풀면 \(x = (1-u)^{-1/3} - 1\). \(1 - U\)도 균일이므로 \(X = U^{-1/3} - 1\).
