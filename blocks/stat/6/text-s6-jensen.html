본문

  • 볼록함수의 받침선 성질로 젠센 부등식을 증명한다.

  • 기대값과 그 선형성 (3.1절).

평균 속력의 함정

가는 길은 시속 60 km, 오는 길은 시속 40 km로 달렸다면 평균 속력은 50 km가 아닙니다. 거리가 \(d\)라면 걸린 시간이 \(d/60 + d/40\)이므로 평균 속력은 \(2d/(d/60 + d/40) = 48\) km입니다. 속력의 평균을 낸 다음 시간을 구하는 것과 시간의 평균을 구하는 것이 다른 까닭은 \(t = d/v\)가 직선이 아니기 때문입니다. 일반적으로 \(E[g(X)] \ne g(E X)\)이며, \(g\)가 볼록이면 어느 쪽이 큰지는 정해져 있습니다.

3.4.1볼록함수와 받침선

정의 3.4.1

구간 \(I\)에서 \(g\)가 볼록이란, 모든 \(x, y \in I\)와 \(0 \le \lambda \le 1\)에 대해 \(g(\lambda x + (1-\lambda)y) \le \lambda g(x) + (1-\lambda)g(y)\)인 것. 곧 그래프 위 두 점을 잇는 현이 그래프보다 위에 있습니다. \(-g\)가 볼록이면 \(g\)는 오목입니다.

두 번 미분가능하면 \(g'' \ge 0\)과 볼록이 같습니다. \(x^2\), \(e^x\), \(1/x\) (\(x > 0\))은 볼록, \(\ln x\), \(\sqrt x\)는 오목입니다. 볼록함수의 핵심 성질은 모든 점 \(\mu\)에서 받침선, 곧 \(g(x) \ge g(\mu) + c(x - \mu)\)를 모든 \(x\)에서 만족하는 직선이 있다는 것입니다(미분가능하면 \(c = g'(\mu)\), 접선).

3.4.2젠센 부등식

정리 3.4.2 (젠센 부등식)

\(g\)가 볼록이고 \(E|X|\)와 \(E|g(X)|\)가 유한하면 \(g(E X) \le E[g(X)]\). 오목함수이면 부등호가 반대. \(g\)가 엄격히 볼록이면 등호는 \(X\)가 상수일 때만 성립합니다.

\(\mu = E(X)\)에서의 받침선을 \(\ell(x) = g(\mu) + c(x - \mu)\)라 하면 모든 \(x\)에서 \(g(x) \ge \ell(x)\)이고, 기대값의 단조성과 선형성으로 \(E[g(X)] \ge g(\mu) + c(E X - \mu) = g(\mu)\). ∎

그림으로 기억하면 쉽습니다. 볼록 곡선 위의 점들을 확률 무게로 평균하면 그 무게중심은 곡선 위쪽(현 쪽)에 놓이므로, 함숫값의 평균이 평균의 함숫값보다 큽니다.

3.4.3여러 가지 결과

  • \(g(x) = x^2\): \((E X)^2 \le E(X^2)\), 곧 \(\mathrm{Var}(X) \ge 0\).
  • \(g(x) = 1/x\) (\(X > 0\)): \(E(1/X) \ge 1/E(X)\). 도입의 평균 속력 문제와 같은 구조이며, 조화평균 ≤ 산술평균으로 이어집니다.
  • \(g = \ln\) (오목): \(E(\ln X) \le \ln E(X)\). \(X\)가 \(x_1, \ldots, x_n\) 각각을 확률 \(1/n\)로 가지면 \(\frac1n\sum \ln x_i \le \ln \bar x\), 곧 기하평균 \(\le\) 산술평균입니다.
  • 추정량의 편향: \(S^2\)은 \(\sigma^2\)의 불편추정량이지만 \(\sqrt{\,}\)가 오목이므로 \(E(S) \le \sqrt{E(S^2)} = \sigma\). 표본표준편차는 \(\sigma\)를 평균적으로 작게 추정합니다(응통7 01단원).
예제 3.4.3

지수분포 \(\mathrm{Exp}(\lambda)\)의 평균은 \(1/\lambda\)입니다. 표본평균 \(\bar X\)로 \(\lambda\)를 \(\hat\lambda = 1/\bar X\)로 추정하면 \(E(\hat\lambda)\)는 \(\lambda\)보다 큰가 작은가?

풀이. \(g(x) = 1/x\)는 \(x > 0\)에서 엄격히 볼록이고 \(\bar X\)는 상수가 아니므로 \(E(1/\bar X) > 1/E(\bar X) = \lambda\). 평균적으로 과대 추정합니다. 정확히는 \(E(\hat\lambda) = n\lambda/(n-1)\)이며(4.3절의 감마분포로 계산), 응통7 03단원의 실습 카드에서 \(n = 5\)일 때 25% 크게 나오는 것을 볼 수 있습니다.

요약
  1. 볼록 \(g\): \(g(E X) \le E[g(X)]\). 오목이면 반대.
  2. 증명은 평균에서의 받침선 하나로 끝납니다.
  3. 분산 ≥ 0, 산술-기하 평균, \(E(S) \le \sigma\), \(1/\bar X\)의 과대 추정이 모두 같은 부등식입니다.

3.4.4연습문제

기본

  1. \(X\)가 1과 9를 확률 1/2씩 가질 때 \(E(\sqrt X)\)와 \(\sqrt{E X}\)를 비교하세요.
    답

    \(E(\sqrt X) = (1 + 3)/2 = 2\), \(\sqrt{E X} = \sqrt5 \approx 2.24\). 오목함수라 \(E(\sqrt X) \le \sqrt{E X}\).

응용

  1. 연 수익률이 +50%와 −50%를 같은 확률로 내는 투자의 기대 수익률은 0%입니다. 이 투자를 오래 반복하면 재산이 어떻게 되는지 젠센 부등식으로 설명하세요.
    답

    재산은 매년 1.5배 또는 0.5배가 곱해집니다. 장기 성장률은 \(E(\ln R) = (\ln 1.5 + \ln 0.5)/2 = \frac12\ln 0.75 < 0\)이므로 재산은 0으로 줄어듭니다. \(\ln\)이 오목이라 \(E(\ln R) \le \ln E(R) = \ln 1 = 0\)이고, 변동이 클수록 그 차이가 커집니다.
