기대값과 적률생성함수 단원 마무리 연습

문제 6 · 계산·증명 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(X \sim U(0, 1)\)의 \(E(X)\), \(E(X^2)\), \(\mathrm{Var}(X)\)를 구하고, \(\mathrm{Var}(3X + 2)\)를 구하세요. [03-01]

    힌트 1

    \(E(X^k) = \int_0^1 x^k\,dx = 1/(k+1)\)입니다.

    힌트 2

    \(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\)입니다.

    풀이

    \(E(X) = 1/2\), \(E(X^2) = 1/3\), \(\mathrm{Var}(X) = 1/3 - 1/4 = 1/12\)입니다. \(\mathrm{Var}(3X + 2) = 9/12 = 3/4\)입니다. 더한 상수 2는 위치만 옮기므로 분산에 영향이 없습니다.

  2. 계산\(X \sim \mathrm{Exp}(\lambda)\)의 평균과 분산을 적분으로 구하세요. [03-01]

    힌트 1

    부분적분 또는 감마 함수 \(\int_0^\infty x^{k}e^{-\lambda x}dx = k!/\lambda^{k+1}\)을 씁니다.

    힌트 2

    \(E(X^2) = 2/\lambda^2\)입니다.

    풀이

    \(E(X) = \lambda\cdot1!/\lambda^2 = 1/\lambda\), \(E(X^2) = \lambda\cdot2!/\lambda^3 = 2/\lambda^2\)이므로 \(\mathrm{Var}(X) = 2/\lambda^2 - 1/\lambda^2 = 1/\lambda^2\)입니다. 평균과 표준편차가 모두 \(1/\lambda\)로 같습니다.

  3. 계산포아송 분포의 적률생성함수 \(M(t) = \exp\{\lambda(e^t - 1)\}\)에서 \(M'(0)\), \(M''(0)\)을 구해 평균과 분산을 구하세요. [03-02]

    힌트 1

    \(M'(t) = \lambda e^tM(t)\)입니다.

    힌트 2

    \(M''(t) = \lambda e^tM(t) + (\lambda e^t)^2M(t)\)입니다.

    풀이

    \(M'(0) = \lambda\), \(M''(0) = \lambda + \lambda^2\)이므로 \(E(X) = \lambda\), \(\mathrm{Var}(X) = \lambda + \lambda^2 - \lambda^2 = \lambda\)입니다. 응통1-04-02에서 급수로 구한 결과와 같습니다.

  4. 계산(1) 서로 독립인 \(X \sim \mathrm{Poisson}(2)\), \(Y \sim \mathrm{Poisson}(3)\)에 대해 \(X + Y\)의 분포를 적률생성함수로 구하세요. (2) 적률생성함수가 \(M(t) = (0.3 + 0.7e^t)^5\)인 분포는 무엇인가요? [03-02]

    힌트 1

    독립이면 \(M_{X+Y}(t) = M_X(t)M_Y(t)\)입니다.

    힌트 2

    이항분포 \(B(n, p)\)의 적률생성함수는 \((1 - p + pe^t)^n\)입니다.

    풀이

    (1) \(M_{X+Y}(t) = e^{2(e^t-1)}e^{3(e^t-1)} = e^{5(e^t-1)}\)이므로 적률생성함수의 유일성에 따라 \(X + Y \sim \mathrm{Poisson}(5)\)입니다.

    (2) \(B(5, 0.7)\)입니다. 적률생성함수가 (0 근방에서) 같으면 분포가 같으므로, 모양만 보고 분포를 식별할 수 있습니다.

  5. 증명체비쇼프 부등식 \(P(|X - \mu| \ge k\sigma) \le 1/k^2\)을 마르코프 부등식(\(Y \ge 0\)이면 \(P(Y \ge a) \le E(Y)/a\))에서 유도하세요. \(k = 2\)일 때의 상한을 정규분포의 실제 값과 비교하세요. [03-03]

    힌트 1

    \(Y = (X - \mu)^2\)에 마르코프 부등식을 쓰고, \(a = k^2\sigma^2\)으로 둡니다.

    힌트 2

    정규분포에서 \(P(|Z| \ge 2) \approx 0.0455\)입니다.

    풀이

    \(P(|X - \mu| \ge k\sigma) = P((X-\mu)^2 \ge k^2\sigma^2) \le \dfrac{E(X-\mu)^2}{k^2\sigma^2} = \dfrac{1}{k^2}\).

    \(k = 2\)이면 상한은 0.25이지만 정규분포의 실제 값은 약 0.046입니다. 체비쇼프 부등식은 분포를 전혀 가정하지 않으므로 느슨하지만, 어떤 분포에도 성립한다는 장점이 있어 대수의 법칙 증명(응통6-07-02)에 쓰입니다.

  6. 증명젠센 부등식(\(g\)가 볼록이면 \(E[g(X)] \ge g(E[X])\))으로 양의 확률변수 \(X\)에 대해 (1) \(E(1/X) \ge 1/E(X)\), (2) \(E(\ln X) \le \ln E(X)\)를 보이고, (2)를 산술평균과 기하평균의 관계로 해석하세요. [03-04]

    힌트 1

    \(1/x\)는 \(x > 0\)에서 볼록, \(\ln x\)는 오목입니다.

    힌트 2

    오목 함수에서는 부등호가 반대입니다. \(X\)가 \(n\)개 값을 같은 확률로 가지면 \(E(\ln X) = \frac1n\sum\ln x_i\)입니다.

    풀이

    (1) \(g(x) = 1/x\)는 \(g''(x) = 2/x^3 > 0\)이라 볼록이므로 \(E(1/X) \ge 1/E(X)\). (2) \(\ln x\)는 \(g'' = -1/x^2 < 0\)이라 오목이므로 \(E(\ln X) \le \ln E(X)\).

    (2)에서 \(X\)가 \(x_1, \ldots, x_n\)을 같은 확률로 가지면 \(\frac1n\sum\ln x_i \le \ln\bar x\), 양변에 지수를 취하면 \((x_1\cdots x_n)^{1/n} \le \bar x\), 곧 기하평균 ≤ 산술평균입니다. (1)은 \(\hat\theta\)가 불편이어도 \(1/\hat\theta\)는 일반적으로 불편이 아님을 보여 줍니다.
