균일 난수 하나로 어떤 분포든 만들 수 있을까?

실습 · 확률변수의 변환

목표

\(X \sim U(0, 1)\)에 함수 \(Y = g(X)\)를 적용해 만든 난수의 히스토그램을, 변환 공식으로 구한 밀도 \(f_Y(y) = f_X(g^{-1}(y))\,|dg^{-1}/dy|\)와 비교한다. 역변환법으로 지수분포와 코시 분포를 만들 수 있음을 확인한다. 성취기준 [응통6-02-02].

분포함수 방법: \(F_Y(y) = P(g(X) \le y)\)를 \(X\)의 확률로 바꾸어 계산한 뒤 미분한다.

역변환법: \(F\)가 연속이고 증가하면 \(F^{-1}(U)\)는 분포함수 \(F\)를 따른다.

준비

막대는 컴퓨터가 만든 균일 난수(가상 자료)를 변환한 값의 히스토그램, 빨간 곡선은 이론 밀도이다. 그림 범위 밖의 값은 막대에서 빠집니다. "새 난수"를 누르면 다른 난수로 다시 만든다.

절차

  1. \(Y = -\ln X\)에서 히스토그램과 지수분포 밀도 \(e^{-y}\)를 비교하고, 표본 평균을 이론 1과 비교한다.
  2. \(Y = X^2\)으로 바꾸어 \(y = 0\) 근처 막대가 왜 높은지 생각한다. 밀도 \(1/(2\sqrt y)\)를 분포함수 방법으로 유도해 본다.
  3. \(Y = \sqrt X\)에서 밀도가 \(2y\)인 까닭을 같은 방법으로 확인한다.
  4. 코시 변환에서 "새 난수"를 여러 번 눌러 표본 평균과 표본 중앙값이 각각 얼마나 흔들리는지 적다. 난수 개수를 20000으로 늘려도 평균이 안정되나요?

기대 결과

  • 세 변환(\(-\ln X\), \(X^2\), \(\sqrt X\))에서 히스토그램이 빨간 곡선을 잘 따르고, 표본 평균이 이론값 1, 1/3, 2/3에 가깝습니다(2000개면 대략 ±0.02~0.03 안).
  • \(X^2\)은 0 근처 값을 더 0 쪽으로 몰아서 \(y \to 0\)에서 밀도가 무한히 커지지만, 넓이는 1이다.
  • 코시 분포는 평균이 존재하지 않아, 표본 평균이 새 난수마다 크게 튀고(가끔 ±5 이상) 난수를 늘려도 안정되지 않는다. 반면 표본 중앙값은 0 근처에 머뭅니다(응통6 단원 연습의 대수의 법칙 문제).
  • 그림 범위(−8~8) 안의 코시 값은 약 92%로, 나머지 8%는 아주 멀리 떨어진 값이다. 이론값 \(P(|Y| < 8) = \frac2\pi\arctan 8 \approx 0.921\)이다.

분석

  1. \(Y = -\ln X\)가 지수분포가 되는 것을 \(P(Y > y) = P(X < e^{-y})\)로 보여 보자.
  2. 정규분포는 분포함수의 역함수를 닫힌 꼴로 쓸 수 없다. 그래도 정규 난수를 만드는 방법을 하나 들어 보세요(박스-뮬러, 응통15-04-02).
  3. 변환이 일대일이 아니면(예: \(Y = (X - 1/2)^2\)) 변환 공식을 어떻게 고쳐야 하나요?
