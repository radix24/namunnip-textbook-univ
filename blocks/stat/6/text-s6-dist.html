  • 확률변수를 함수로 이해한다.
  • 누적분포함수의 성질을 쓰고, 이산형의 확률질량함수와 연속형의 확률밀도함수를 다룬다.

  • 확률의 공리 (1.1절), 정적분(고교 수학II, 응통1 03단원).

결과에 수를 붙이기

동전 세 번의 결과는 HHT 같은 문자열이지만, 관심 있는 것은 대개 "앞면의 수"처럼 결과에서 계산한 수입니다. 결과마다 수를 붙이는 규칙이 확률변수입니다.

2.1.1확률변수와 누적분포함수

정의 2.1.1

확률변수 \(X\): 표본공간의 각 결과 \(\omega\)에 실수 \(X(\omega)\)를 대응시키는 함수. 누적분포함수: \(F(x) = P(X \le x)\).

정리 2.1.2

\(F\)는 (가) 감소하지 않고, (나) \(\lim_{x\to-\infty}F(x) = 0\), \(\lim_{x \to \infty}F(x) = 1\)이며, (다) 오른쪽 연속이다. 또 \(P(a < X \le b) = F(b) - F(a)\).

(가)는 \(x < y\)이면 \(\{X \le x\} \subset \{X \le y\}\)이므로 단조성에서, (나)와 (다)는 확률의 연속성(1.1절 심화 연습)에서 나옵니다. 거꾸로 이 세 성질을 가진 함수는 모두 어떤 확률변수의 누적분포함수입니다.

2.1.2이산형과 연속형

정의 2.1.3

이산형: \(X\)가 셀 수 있는 값 \(x_1, x_2, \ldots\)만 가짐. 확률질량함수 \(p(x) = P(X = x)\), \(\sum p(x_i) = 1\).

정의 2.1.4

연속형: 음이 아닌 함수 \(f\)가 있어 \(F(x) = \int_{-\infty}^x f(t)\,dt\). \(f\)를 확률밀도함수라 하고 \(\int_{-\infty}^\infty f = 1\).

연속형에서는 \(P(X = a) = 0\)이고, 확률은 넓이 \(P(a \le X \le b) = \int_a^b f\)입니다. \(f(x)\) 자체는 확률이 아니어서 1보다 클 수 있습니다. \(F\)가 미분가능한 곳에서 \(f = F'\)입니다.

예제 2.1.5

\(f(x) = cx^2\) (\(0 \le x \le 2\)), 그 밖에서 0. \(c\), \(F\), \(P(X > 1)\)을 구하세요.

풀이. \(\int_0^2 cx^2dx = 8c/3 = 1\)에서 \(c = 3/8\). \(0 \le x \le 2\)에서 \(F(x) = x^3/8\), \(x < 0\)이면 0, \(x > 2\)이면 1. \(P(X > 1) = 1 - 1/8 = 7/8\). 이 분포는 공통12 실습 카드에서 그림으로 볼 수 있습니다.

요약
  1. 확률변수는 결과에 수를 붙이는 함수입니다.
  2. 누적분포함수는 비감소, 0에서 1, 오른쪽 연속.
  3. 이산형은 질량함수의 합, 연속형은 밀도함수의 적분으로 확률을 구합니다.

2.1.3연습문제

기본

  1. 동전 세 번 중 앞면 수 \(X\)의 질량함수와 \(F(1.5)\)는?
    답

    \(p(0) = 1/8\), \(p(1) = 3/8\), \(p(2) = 3/8\), \(p(3) = 1/8\). \(F(1.5) = 1/2\).

응용

  1. \(F(x) = 1 - e^{-2x}\) (\(x \ge 0\))의 밀도함수와 중앙값은?
    답

    \(f(x) = 2e^{-2x}\). \(1 - e^{-2m} = 1/2\)에서 \(m = (\ln 2)/2 \approx 0.347\).
