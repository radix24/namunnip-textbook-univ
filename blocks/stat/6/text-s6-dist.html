확률변수, 분포함수, 밀도함수

본문

동전 세 번의 결과는 HHT 같은 문자열이지만, 관심 있는 것은 대개 "앞면의 수"처럼 결과에서 계산한 수이다. 또 기다리는 시간처럼 연속적인 값은 정확히 3초일 확률이 0인데도 "3초 이하일 확률"은 분명히 있다. 결과에 붙인 수의 확률을 이산적인 경우와 연속적인 경우 모두 한 틀로 다룰 수 있을까?

먼저 알아야 할 것확률의 공리(1.1절)와 정적분(고교 수학II, 응통1 3단원)을 쓴다.

2.1.1확률변수와 누적분포함수

정의 2.1.1 (확률변수와 누적분포함수)

표본공간의 각 결과 \(\omega\)에 실수 \(X(\omega)\)를 대응시키는 함수를 확률변수라 한다. 또 \(F(x) = P(X \le x)\)를 \(X\)의 누적분포함수라 한다.

처음 질문의 답은 누적분포함수이다. 이산이든 연속이든 "\(x\) 이하일 확률"은 늘 정의되므로 두 경우를 한 틀로 다룬다.

정리 2.1.2 (분포함수의 성질)

\(F\)는 (가) 감소하지 않고, (나) \(\lim_{x\to-\infty}F(x) = 0\), \(\lim_{x \to \infty}F(x) = 1\)이며, (다) 오른쪽 연속이다. 또 \(P(a < X \le b) = F(b) - F(a)\)이다.

(가)는 \(x < y\)이면 \(\{X \le x\} \subset \{X \le y\}\)이므로 단조성에서 나오고, (나)와 (다)는 확률의 연속성(1.1절 심화 연습)에서 나온다. 거꾸로 이 세 성질을 가진 함수는 모두 어떤 확률변수의 누적분포함수이다.

2.1.2이산형과 연속형

정의 2.1.3 (이산형과 연속형)

\(X\)가 셀 수 있는 값 \(x_1, x_2, \ldots\)만 가지면 이산형이라 하고, 확률질량함수 \(p(x) = P(X = x)\)는 \(\sum p(x_i) = 1\)이다. 음이 아닌 함수 \(f\)가 있어 \(F(x) = \int_{-\infty}^x f(t)\,dt\)이면 연속형이라 하고, \(f\)를 확률밀도함수라 하며 \(\int_{-\infty}^\infty f = 1\)이다.

연속형에서는 \(P(X = a) = 0\)이고, 확률은 넓이 \(P(a \le X \le b) = \int_a^b f\)이다. 이것이 처음 질문의 "정확히 3초일 확률은 0"에 대한 설명이다. 그래서 \(f(x)\) 자체는 확률이 아니어서 1보다 클 수 있다(그림 1). 또 \(F\)가 미분가능한 곳에서 \(f = F'\)이다.

예제 2.1.1

\(f(x) = cx^2\) (\(0 \le x \le 2\)), 그 밖에서 0일 때 \(c\), \(F\), \(P(X > 1)\)을 구하여라.

풀이. \(\int_0^2 cx^2dx = 8c/3 = 1\)에서 \(c = 3/8\)이다. 따라서 \(0 \le x \le 2\)에서 \(F(x) = x^3/8\)이고, \(x < 0\)이면 0, \(x > 2\)이면 1이다. 그러므로 \(P(X > 1) = 1 - 1/8 = 7/8\)이다(그림 1).

흔한 오해밀도 \(f(x)\)를 "\(X = x\)일 확률"로 읽기 쉽다. 연속형에서 한 점의 확률은 0이고, \(f(x)\)는 \(x\) 근처의 작은 구간 \(dx\)에 대해 \(f(x)\,dx\)가 확률이 된다는 뜻의 단위 길이당 확률이다.
마무리

확률변수는 결과에 수를 붙이는 함수이고, 누적분포함수 \(F(x) = P(X \le x)\)는 이산형과 연속형을 한 틀로 다루며 감소하지 않고 0에서 1로 오르는 오른쪽 연속 함수이다. 이산형은 질량함수의 합으로, 연속형은 밀도함수의 적분(넓이)으로 확률을 구하며, 밀도 자체는 확률이 아니라 1보다 클 수 있다.

2.1.3연습문제

기본

  1. 동전 세 번 가운데 앞면 수 \(X\)의 질량함수와 \(F(1.5)\)는 무엇인가?
    답

    \(p(0) = 1/8\), \(p(1) = 3/8\), \(p(2) = 3/8\), \(p(3) = 1/8\)이고 \(F(1.5) = 1/2\)이다.

응용

  1. \(F(x) = 1 - e^{-2x}\) (\(x \ge 0\))의 밀도함수와 중앙값은 무엇인가?
    답

    \(f(x) = 2e^{-2x}\)이다. \(1 - e^{-2m} = 1/2\)에서 중앙값은 \(m = (\ln 2)/2 \approx 0.347\)이다.
