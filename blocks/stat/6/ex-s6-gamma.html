예비 부품은 몇 개면 충분한가

예제 · 감마분포와 지수분포

먼저 읽는 법

"하나 고장 나면 바로 다음 것으로 바꾼다"는 상황의 총 사용 시간은 지수분포의 합, 곧 감마분포이다. 감마분포의 확률은 포아송 과정의 사건 수로 바꾸면 손으로 계산할 수 있다: \(n\)번째 고장이 \(t\) 이후에 일어남 ⇔ 시간 \(t\)까지 고장이 \(n - 1\)번 이하.

문제. 탐사 장비의 전구는 평균 수명 100시간인 지수분포를 따르고, 고장 나면 즉시 예비 전구로 바꾼다. 임무 시간은 300시간이다. 처음 끼운 것을 포함해 전구가 \(n\)개 있을 때 임무 중 불이 꺼지지 않을 확률을 \(n = 3, 4, 5, 6\)에 대해 구하고, 확률 0.95 이상이 되는 최소 \(n\)을 구하여라.

풀이

  1. 총 수명 \(T_n = X_1 + \cdots + X_n \sim \mathrm{Gamma}(n, 100)\). 구하는 것은 \(P(T_n > 300)\).
    독립인 지수분포의 합(4.3.3절).
  2. 고장을 비율 \(1/100\)인 포아송 과정의 사건으로 보면 300시간 동안 고장 수 \(N \sim \mathrm{Poisson}(3)\). \(T_n > 300\) ⇔ \(N \le n - 1\).
    감마 분포함수를 포아송 누적확률로 바꾼다.
  3. \(P(N = k) = e^{-3}3^k/k!\): \(k = 0, \ldots, 5\)에서 0.0498, 0.1494, 0.2240, 0.2240, 0.1680, 0.1008.
    \(e^{-3} \approx 0.0498\).
  4. 누적: \(n = 3\): \(P(N \le 2) = 0.423\). \(n = 4\): 0.647. \(n = 5\): 0.815. \(n = 6\): 0.916. \(n = 7\): \(0.916 + 0.0504 = 0.966\).
    \(P(N = 6) = 0.1008 \times 3/6 = 0.0504\).
  5. 0.95 이상이 되려면 전구가 7개(예비 6개) 필요하다.
    평균 수명의 합만 보면 3개(300시간)로 충분해 보이지만, 그때 성공 확률은 42%에 불과하다.

검산

R: pgamma(300, shape = 3:7, scale = 100, lower.tail = FALSE)는 0.423, 0.647, 0.815, 0.916, 0.966을 준다. ppois(2:6, 3)도 같은 값이다.

의미

"평균 수명 × 개수 = 임무 시간"으로 계획하면 실패 확률이 절반을 넘는다. 지수분포는 표준편차가 평균과 같을 만큼 흩어짐이 커서, 신뢰도를 보장하려면 평균보다 훨씬 많은 여분이 필요하다. 감마분포와 포아송분포가 같은 사건을 시간 쪽과 개수 쪽에서 본 것이라는 점도 기억해 둔다.
