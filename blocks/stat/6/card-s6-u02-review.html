확률변수와 분포 단원 마무리 연습

문제 6 · 계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산공정한 동전을 두 번 던져 나온 앞면의 수를 \(X\)라 합니다. 확률질량함수와 분포함수 \(F(x)\)를 쓰고, \(F(1)\), \(P(X < 1)\), \(F(1.5)\)를 구하세요. [02-01]

    힌트 1

    \(P(X = 0) = 1/4\), \(P(X = 1) = 1/2\), \(P(X = 2) = 1/4\)입니다.

    힌트 2

    분포함수는 \(F(x) = P(X \le x)\)이며 계단 모양입니다.

    풀이

    \(F(x) = 0\) (\(x < 0\)), \(1/4\) (\(0 \le x < 1\)), \(3/4\) (\(1 \le x < 2\)), \(1\) (\(x \ge 2\))입니다.

    \(F(1) = 3/4\), \(P(X < 1) = P(X = 0) = 1/4\), \(F(1.5) = 3/4\)입니다. 이산형에서는 \(P(X \le 1)\)과 \(P(X < 1)\)이 다르며, 그 차이 \(1/2\)가 \(x = 1\)에서의 계단 높이 \(P(X = 1)\)입니다.

  2. 계산\(f(x) = cx^2\) (\(0 \le x \le 2\))가 밀도함수가 되도록 \(c\)를 정하고, 분포함수와 중앙값을 구하세요. [02-01]

    힌트 1

    \(\int_0^2 cx^2dx = 8c/3 = 1\)입니다.

    힌트 2

    중앙값 \(m\)은 \(F(m) = 1/2\)인 값입니다.

    풀이

    \(c = 3/8\), \(F(x) = x^3/8\) (\(0 \le x \le 2\))입니다. \(m^3/8 = 1/2\)에서 \(m = 4^{1/3} \approx 1.587\)입니다. 밀도가 오른쪽으로 갈수록 커지므로 중앙값이 구간 가운데(1)보다 오른쪽에 있습니다.

  3. 계산\(X \sim U(0, 1)\)일 때 \(Y = X^2\)의 분포함수와 밀도함수를 분포함수 방법으로 구하세요. [02-02]

    힌트 1

    \(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y)\) (\(0 < y < 1\))입니다.

    힌트 2

    밀도함수는 분포함수를 미분해 얻습니다.

    풀이

    \(F_Y(y) = \sqrt y\) (\(0 < y < 1\))이고, \(f_Y(y) = \dfrac{1}{2\sqrt y}\) (\(0 < y < 1\))입니다. \(y \to 0\)에서 밀도가 무한히 커지지만 적분은 1로 유한합니다. \(X\)가 0 근처에 있으면 제곱이 더 0에 몰리기 때문입니다.

  4. 계산\(Z \sim N(0, 1)\)일 때 \(Y = Z^2\)의 밀도함수를 구하세요. 이 분포의 이름은 무엇인가요? [02-02]

    힌트 1

    \(F_Y(y) = P(-\sqrt y \le Z \le \sqrt y) = \Phi(\sqrt y) - \Phi(-\sqrt y)\)입니다. 변환이 일대일이 아니라 두 갈래를 모두 셉니다.

    힌트 2

    미분하면 \(\phi(\sqrt y)\frac{1}{2\sqrt y}\)가 두 번 나옵니다.

    풀이

    \(f_Y(y) = 2\phi(\sqrt y)\cdot\dfrac{1}{2\sqrt y} = \dfrac{1}{\sqrt{2\pi y}}e^{-y/2}\) (\(y > 0\))입니다. 이것은 자유도 1인 카이제곱 분포(감마 분포 \(\alpha = 1/2\), 비율 \(1/2\))입니다. 응통6-06-01의 카이제곱 분포 유도의 출발점입니다.

  5. 계산\(X \sim \mathrm{Exp}(\lambda)\) (밀도 \(\lambda e^{-\lambda x}\))일 때 \(Y = \lfloor X\rfloor\) (내림, 정수 부분)의 확률질량함수를 구하고, 어떤 분포인지 쓰세요. [02-02]

    힌트 1

    \(P(Y = k) = P(k \le X < k + 1)\)입니다.

    힌트 2

    \(P(X > x) = e^{-\lambda x}\)를 쓰세요.

    풀이

    \(P(Y = k) = e^{-\lambda k} - e^{-\lambda(k+1)} = (e^{-\lambda})^k(1 - e^{-\lambda})\), \(k = 0, 1, 2, \ldots\)입니다. 성공 확률 \(p = 1 - e^{-\lambda}\)인 기하분포(실패 횟수형)입니다. 연속 대기 시간을 정수 단위로 자르면 이산 대기 시간 분포가 됩니다.

  6. 판단"밀도함수 값은 확률이므로 1을 넘을 수 없다"는 주장을 평가하세요. 연속 확률변수에서 \(P(X = a)\)는 얼마인가요? [02-01]

    힌트 1

    \(U(0, 1/2)\)의 밀도는 얼마인가요?

    힌트 2

    확률은 밀도의 적분(넓이)입니다.

    풀이

    틀렸습니다. \(U(0, 1/2)\)의 밀도는 구간 위에서 2로, 1보다 큽니다. 밀도는 "단위 길이당 확률"이고 확률은 밀도를 적분한 넓이이므로, 구간이 좁으면 밀도가 1을 넘을 수 있습니다.

    연속 확률변수에서 \(P(X = a) = \int_a^a f = 0\)입니다. 그래서 \(f(a)\)는 한 점의 확률이 아니라, \(P(a \le X \le a + h) \approx f(a)h\)처럼 작은 구간의 확률을 근사하는 데 쓰입니다.
