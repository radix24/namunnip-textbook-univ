조건부 기대값과 분산 분해

본문
이 절에서 배울 것
  • 조건부 기대값 \(E(Y \mid X)\)를 확률변수로 이해하고 계산한다.
  • 반복 기대값 \(E[E(Y\mid X)] = E(Y)\)와 분산 분해 공식을 증명하고 쓴다.
  • 조건부 기대값이 가장 좋은 예측이라는 뜻을 안다.
먼저 알아야 할 것
  • 조건부 분포 (5.1절), 공분산 (5.2절).

둘로 나누어 계산하기

하루 손님 수도 무작위이고 손님 한 명이 쓰는 돈도 무작위일 때 하루 매출의 평균과 분산을 직접 계산하기는 어렵습니다. "손님 수를 안다고 치고" 먼저 계산한 뒤, 손님 수에 대해 평균을 내면 쉬워집니다. 이렇게 조건을 걸어 문제를 둘로 나누는 도구가 조건부 기대값이며, 회귀분석(응통10)의 회귀함수도 조건부 기대값입니다.

5.3.1조건부 기대값

정의 5.3.1

\(E(Y \mid X = x) = \int y f(y \mid x)\,dy\) (이산이면 합). 이것을 \(x\)의 함수 \(h(x)\)로 보아 \(x\) 자리에 \(X\)를 넣은 확률변수 \(h(X)\)를 \(E(Y \mid X)\)라 씁니다.

\(E(Y \mid X = x)\)는 숫자이지만 \(E(Y \mid X)\)는 \(X\)에 따라 값이 정해지는 확률변수입니다. 기대값의 선형성은 조건부에서도 그대로 성립하고, \(X\)의 함수는 조건 아래에서 상수처럼 밖으로 나옵니다: \(E[g(X)Y \mid X] = g(X)E(Y \mid X)\). \(X\)와 \(Y\)가 독립이면 \(E(Y \mid X) = E(Y)\)입니다.

5.3.2반복 기대값과 분산 분해

정리 5.3.2

(가) 반복 기대값: \(E[E(Y \mid X)] = E(Y)\). (나) 분산 분해: \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y \mid X)] + \mathrm{Var}[E(Y \mid X)]\).

(가) \(E[E(Y\mid X)] = \int\left(\int y f(y\mid x)dy\right)f_X(x)dx = \iint y f(x,y)\,dy\,dx = E(Y)\). (나) \(\mathrm{Var}(Y \mid X) = E(Y^2 \mid X) - [E(Y\mid X)]^2\)의 기대값에 (가)를 쓰면 \(E[\mathrm{Var}(Y\mid X)] = E(Y^2) - E\{[E(Y\mid X)]^2\}\). 한편 \(\mathrm{Var}[E(Y \mid X)] = E\{[E(Y\mid X)]^2\} - [E(Y)]^2\). 둘을 더하면 \(\mathrm{Var}(Y)\). ∎

(가)는 "전체 평균 = 집단별 평균의 가중평균"이고, (나)는 "전체 변동 = 집단 안 변동의 평균 + 집단 평균들의 변동"입니다. 분산분석(응통5 5.1절)의 SST = SSW + SSB와 같은 구조입니다.

예제 5.3.3

5.1절 예제(\(0 < x < y < 1\)에서 균일)의 \(E(Y \mid X)\), \(E(Y)\), \(\mathrm{Var}(Y)\)를 반복 기대값과 분산 분해로 구하세요.

풀이. \(Y \mid X = x\)는 \(U(x, 1)\)이므로 \(E(Y\mid X) = (1 + X)/2\), \(\mathrm{Var}(Y \mid X) = (1 - X)^2/12\). \(X\)의 주변 밀도는 \(2(1-x)\)이므로 \(E(X) = 1/3\), \(E(X^2) = 1/6\), \(\mathrm{Var}(X) = 1/18\). (가)에서 \(E(Y) = (1 + 1/3)/2 = 2/3\). (나)에서 \(E[(1-X)^2]/12 = (1 - 2/3 + 1/6)/12 = 1/24\)이고 \(\mathrm{Var}[(1+X)/2] = (1/18)/4 = 1/72\), 합은 \(1/24 + 1/72 = 1/18\). \(Y\)의 주변 밀도 \(2y\)로 직접 구한 \(E(Y^2) - E(Y)^2 = 1/2 - 4/9 = 1/18\)과 같습니다.

5.3.3가장 좋은 예측

정리 5.3.4

\(X\)의 함수 \(g(X)\) 가운데 평균제곱오차 \(E[(Y - g(X))^2]\)를 가장 작게 하는 것은 \(g(X) = E(Y \mid X)\)입니다.

\(m(X) = E(Y\mid X)\)라 하면 \(E[(Y - g)^2] = E[(Y - m)^2] + E[(m - g)^2] + 2E[(Y - m)(m - g)]\). 마지막 항은 \(X\)로 조건을 걸면 \((m - g)E(Y - m \mid X) = 0\)이므로 0입니다. 따라서 \(E[(m-g)^2] \ge 0\)을 0으로 만드는 \(g = m\)이 최소입니다. ∎

\(X\)를 보고 \(Y\)를 맞히는 최선의 규칙은 조건부 평균이고, 그때 남는 오차가 \(E[\mathrm{Var}(Y\mid X)]\)입니다. 선형회귀는 이 \(E(Y \mid X)\)를 직선으로 가정한 것이며, 이변량 정규분포에서는 실제로 직선입니다(5.4절).

요약
  1. \(E(Y\mid X)\)는 \(X\)의 함수인 확률변수입니다.
  2. \(E(Y) = E[E(Y\mid X)]\), \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)] + \mathrm{Var}[E(Y\mid X)]\).
  3. \(E(Y\mid X)\)는 평균제곱오차를 최소로 하는 예측입니다.

5.3.4연습문제

기본

  1. 동전을 던져 앞면이면 \(N(0, 1)\), 뒷면이면 \(N(4, 1)\)에서 \(Y\)를 뽑습니다. \(E(Y)\)와 \(\mathrm{Var}(Y)\)는?
    답

    \(X\) = 동전 결과. \(E(Y) = (0 + 4)/2 = 2\). \(E[\mathrm{Var}(Y\mid X)] = 1\), \(\mathrm{Var}[E(Y\mid X)]\) = 0과 4가 반반인 분산 = 4. \(\mathrm{Var}(Y) = 5\).

응용

  1. 하루 손님 수 \(N \sim\) 포아송(10), 손님마다 독립으로 평균 2만 원, 분산 1을 씁니다. 하루 매출 \(S\)의 평균과 분산은?
    답

    \(E(S\mid N) = 2N\), \(\mathrm{Var}(S\mid N) = N\). 평균 \(E(2N) = 20\). 분산 \(E(N) + \mathrm{Var}(2N) = 10 + 4 \times 10 = 50\).
