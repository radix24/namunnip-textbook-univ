조건부 기대값과 분산 분해

본문

가게의 하루 손님 수는 평균 10명인 포아송 분포를 따르고, 손님 한 명은 서로 독립으로 평균 2만 원(분산 1)을 쓴다. 손님 수도 무작위, 한 명이 쓰는 돈도 무작위이니 하루 매출의 분포를 직접 구하기는 어렵다. 그래도 평균과 분산은 쉽게 구할 수 있지 않을까? "손님 수를 안다고 치고" 먼저 계산하면 어떨까?

먼저 알아야 할 것조건부 분포(5.1절)와 공분산(5.2절)을 쓴다.

5.3.1조건부 기대값

처음 질문의 생각처럼 조건을 걸어 문제를 둘로 나누는 도구가 조건부 기대값이다. 회귀분석(응통10)의 회귀함수도 바로 조건부 기대값이다.

정의 5.3.1 (조건부 기대값)

\(E(Y \mid X = x) = \int y f(y \mid x)\,dy\)이다(이산이면 합). 이를 \(x\)의 함수 \(h(x)\)로 보고 \(x\) 자리에 \(X\)를 넣은 확률변수 \(h(X)\)를 \(E(Y \mid X)\)라 쓴다.

여기서 \(E(Y \mid X = x)\)는 숫자이지만 \(E(Y \mid X)\)는 \(X\)에 따라 값이 정해지는 확률변수라는 점을 구별해야 한다. 기대값의 선형성은 조건 아래에서도 그대로 성립하고, \(X\)의 함수는 조건 아래에서 상수처럼 밖으로 나온다. 즉 \(E[g(X)Y \mid X] = g(X)E(Y \mid X)\)이다. 또 \(X\)와 \(Y\)가 독립이면 \(E(Y \mid X) = E(Y)\)이다.

5.3.2반복 기대값과 분산 분해

정리 5.3.2 (반복 기대값과 분산 분해)

(가) \(E[E(Y \mid X)] = E(Y)\)이다. (나) \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y \mid X)] + \mathrm{Var}[E(Y \mid X)]\)이다.

증명. (가)는 \(E[E(Y\mid X)] = \int\big(\int y f(y\mid x)\,dy\big)f_X(x)\,dx = \iint y f(x,y)\,dy\,dx = E(Y)\)이다. (나)는 \(\mathrm{Var}(Y \mid X) = E(Y^2 \mid X) - [E(Y\mid X)]^2\)의 기대값에 (가)를 쓰면 \(E[\mathrm{Var}(Y\mid X)] = E(Y^2) - E\{[E(Y\mid X)]^2\}\)이다. 한편 \(\mathrm{Var}[E(Y \mid X)] = E\{[E(Y\mid X)]^2\} - [E(Y)]^2\)이므로 둘을 더하면 \(\mathrm{Var}(Y)\)이다. ∎

말로 하면 (가)는 전체 평균이 집단별 평균의 가중평균이라는 뜻이다. 또 (나)는 전체 변동이 집단 안 변동의 평균과 집단 평균들의 변동의 합이라는 뜻이며(그림 1), 분산분석(응통5)의 SST = SSW + SSB와 같은 구조이다.

예제 5.3.1

처음 질문의 하루 매출 \(S\)의 평균과 분산을 구하여라.

풀이. 손님 수 \(N\)을 알면 매출은 독립인 \(N\)개의 합이므로 \(E(S\mid N) = 2N\), \(\mathrm{Var}(S\mid N) = N\)이다. (가)에서 평균은 \(E(2N) = 20\)만 원이다. (나)에서 분산은 \(E(N) + \mathrm{Var}(2N) = 10 + 4 \times 10 = 50\)이다. 손님 한 명의 씀씀이가 흩어진 몫(10)보다 손님 수가 흩어진 몫(40)이 훨씬 크다.

예제 5.3.2

5.1절 예제(\(0 < x < y < 1\)에서 균일)의 \(E(Y \mid X)\), \(E(Y)\), \(\mathrm{Var}(Y)\)를 반복 기대값과 분산 분해로 구하여라.

풀이. \(Y \mid X = x\)는 \(U(x, 1)\)이므로 \(E(Y\mid X) = (1 + X)/2\), \(\mathrm{Var}(Y \mid X) = (1 - X)^2/12\)이다. \(X\)의 주변 밀도가 \(2(1-x)\)이므로 \(E(X) = 1/3\), \(E(X^2) = 1/6\), \(\mathrm{Var}(X) = 1/18\)이다. 따라서 (가)에서 \(E(Y) = (1 + 1/3)/2 = 2/3\)이다. (나)에서 \(E[(1-X)^2]/12 = (1 - 2/3 + 1/6)/12 = 1/24\)이고 \(\mathrm{Var}[(1+X)/2] = (1/18)/4 = 1/72\)이므로 합은 \(1/18\)이다. \(Y\)의 주변 밀도 \(2y\)로 직접 구한 \(1/2 - 4/9 = 1/18\)과 같다.

5.3.3가장 좋은 예측

정리 5.3.3 (조건부 기대값의 최적성)

\(X\)의 함수 \(g(X)\) 가운데 평균제곱오차 \(E[(Y - g(X))^2]\)를 가장 작게 하는 것은 \(g(X) = E(Y \mid X)\)이다.

증명. \(m(X) = E(Y\mid X)\)라 하면 \(E[(Y - g)^2] = E[(Y - m)^2] + E[(m - g)^2] + 2E[(Y - m)(m - g)]\)이다. 마지막 항은 \(X\)로 조건을 걸면 \((m - g)E(Y - m \mid X) = 0\)이므로 0이다. 따라서 음이 아닌 \(E[(m-g)^2]\)을 0으로 만드는 \(g = m\)이 최소이다. ∎

즉 \(X\)를 보고 \(Y\)를 맞히는 최선의 규칙은 조건부 평균이고, 그때 남는 오차가 \(E[\mathrm{Var}(Y\mid X)]\)이다. 선형회귀는 이 \(E(Y \mid X)\)를 직선으로 가정한 것이며, 이변량 정규분포에서는 실제로 직선이다(5.4절).

흔한 실수\(\mathrm{Var}(Y)\)를 \(E[\mathrm{Var}(Y \mid X)]\)만으로 계산하기 쉽다. 그러면 집단 평균이 서로 다른 데서 오는 퍼짐 \(\mathrm{Var}[E(Y \mid X)]\)를 빠뜨리게 되며, 그림 1에서는 5 대신 1이라는 엉뚱한 답이 나온다.
마무리

조건부 기대값 \(E(Y\mid X)\)는 \(X\)의 함수인 확률변수이며, 조건을 걸어 문제를 둘로 나누는 도구이다. 반복 기대값 \(E(Y) = E[E(Y\mid X)]\)로 평균을, 분산 분해 \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)] + \mathrm{Var}[E(Y\mid X)]\)로 분산을 구한다. 또 \(E(Y\mid X)\)는 \(X\)로 \(Y\)를 예측할 때 평균제곱오차를 가장 작게 하는 규칙이다.

5.3.4연습문제

기본

  1. 동전을 던져 앞면이면 \(N(0, 1)\), 뒷면이면 \(N(4, 1)\)에서 \(Y\)를 뽑는다. \(E(Y)\)와 \(\mathrm{Var}(Y)\)는 얼마인가?
    답

    동전 결과를 \(X\)라 하면 \(E(Y) = (0 + 4)/2 = 2\)이다. \(E[\mathrm{Var}(Y\mid X)] = 1\)이고, \(\mathrm{Var}[E(Y\mid X)]\)는 0과 4를 반씩 가지는 변수의 분산이라 4이다. 따라서 \(\mathrm{Var}(Y) = 5\)이다(그림 1).

응용

  1. 예제 5.3.1에서 손님 수가 포아송이 아니라 늘 정확히 10명이라면 매출의 분산은 얼마인가? 두 답을 비교하여라.
    답

    \(N = 10\)으로 고정되면 \(\mathrm{Var}[E(S\mid N)] = 0\)이므로 분산은 \(E(N) \times 1 = 10\)이다. 포아송일 때의 50과 비교하면, 분산의 대부분인 40이 손님 수의 변동에서 왔음을 알 수 있다.
