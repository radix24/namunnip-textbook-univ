공분산, 상관계수, 합의 분산

본문
이 절에서 배울 것
  • 공분산과 상관계수를 정의하고 계산한다.
  • 여러 확률변수의 합과 선형결합의 분산을 공분산으로 구한다.
  • \(|\rho| \le 1\)과 "상관 0이 독립이 아니다"를 증명하고 예를 든다.
먼저 알아야 할 것
  • 결합분포 (5.1절), 기대값과 분산 (3.1절).

함께 변하는 정도

포트폴리오 두 주식의 수익률이 함께 오르내리면 위험이 커지고, 반대로 움직이면 위험이 줄어듭니다. 합의 퍼짐은 각자의 퍼짐뿐 아니라 "함께 움직이는 정도"에 달려 있으며, 이것을 재는 양이 공분산입니다.

5.2.1공분산과 상관계수

정의 5.2.1

\(\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E(XY) - \mu_X\mu_Y\). 상관계수 \(\rho = \mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)\).

두 편차의 곱이 평균적으로 양수이면(함께 평균보다 크거나 함께 작음) 공분산이 양수입니다. 공분산은 단위에 따라 크기가 바뀌므로(cm를 mm로 바꾸면 10배), 표준편차로 나눈 상관계수로 강도를 비교합니다. 공분산은 쌍선형입니다: \(\mathrm{Cov}(aX + b, cY + d) = ac\,\mathrm{Cov}(X, Y)\), \(\mathrm{Cov}(X_1 + X_2, Y) = \mathrm{Cov}(X_1, Y) + \mathrm{Cov}(X_2, Y)\), \(\mathrm{Cov}(X, X) = \mathrm{Var}(X)\).

5.2.2합의 분산

정리 5.2.2

(가) \(\mathrm{Var}(aX + bY) = a^2\mathrm{Var}X + b^2\mathrm{Var}Y + 2ab\,\mathrm{Cov}(X,Y)\). (나) 일반적으로 \(\mathrm{Var}\left(\sum_i a_iX_i\right) = \sum_i a_i^2\mathrm{Var}X_i + 2\sum_{i<j}a_ia_j\mathrm{Cov}(X_i, X_j)\). (다) 독립이면 \(E(XY) = E(X)E(Y)\), 따라서 \(\mathrm{Cov} = 0\)이고 분산이 그대로 더해집니다.

(나) \(\mathrm{Var}(\sum a_iX_i) = \mathrm{Cov}(\sum_i a_iX_i, \sum_j a_jX_j) = \sum_i\sum_j a_ia_j\mathrm{Cov}(X_i, X_j)\)을 대각(\(i = j\))과 나머지로 나눕니다. (다) 연속형이면 \(E(XY) = \iint xy f_X(x)f_Y(y)\,dx\,dy = E(X)E(Y)\). ∎

(나)는 행렬로 \(\mathrm{Var}(\mathbf a^\top\mathbf X) = \mathbf a^\top\Sigma\mathbf a\)(\(\Sigma\)는 공분산 행렬)이고, 분산은 음이 될 수 없으므로 공분산 행렬은 양의 준정치입니다(응통2 05단원).

5.2.3상관계수의 범위와 한계

정리 5.2.3

\(|\rho| \le 1\)이고, \(|\rho| = 1\)일 필요충분조건은 \(Y = a + bX\) (\(b \ne 0\))가 확률 1로 성립하는 것입니다.

표준화 변수 \(U = (X - \mu_X)/\sigma_X\), \(V = (Y - \mu_Y)/\sigma_Y\)에 대해 \(0 \le \mathrm{Var}(U \pm V) = 2(1 \pm \rho)\)이므로 \(-1 \le \rho \le 1\). 등호면 \(U \mp V\)의 분산이 0, 곧 \(V = \pm U\)가 확률 1로 성립합니다. ∎

(다)의 역은 거짓입니다. \(X \sim N(0,1)\), \(Y = X^2\)이면 \(\mathrm{Cov} = E(X^3) = 0\)이지만 \(Y\)는 \(X\)로 완전히 정해집니다. 상관계수는 직선 관계의 강도만 재기 때문입니다. 예외로, 결합분포가 다변량 정규이면 상관 0과 독립이 같습니다(5.4절).

예제 5.2.4

두 주식 수익률의 표준편차가 20%, 30%이고 상관계수가 \(\rho\)입니다. 반씩 투자한 포트폴리오의 표준편차를 \(\rho = 1, 0, -0.5\)에서 구하세요.

풀이. \(\mathrm{Var} = 0.25(0.04) + 0.25(0.09) + 2(0.25)\rho(0.2)(0.3) = 0.0325 + 0.03\rho\). \(\rho = 1\): \(\sqrt{0.0625} = 25\%\)(두 표준편차의 평균). \(\rho = 0\): \(\sqrt{0.0325} \approx 18.0\%\). \(\rho = -0.5\): \(\sqrt{0.0175} \approx 13.2\%\). 상관이 낮을수록 분산 투자의 효과가 큽니다.

요약
  1. \(\mathrm{Cov}(X, Y) = E(XY) - \mu_X\mu_Y\), 쌍선형, \(\rho\)는 단위 없는 강도.
  2. \(\mathrm{Var}(\sum a_iX_i) = \sum a_i^2\sigma_i^2 + 2\sum_{i<j}a_ia_j\sigma_{ij}\).
  3. \(|\rho| \le 1\), 독립이면 \(\rho = 0\)이지만 역은 성립하지 않습니다.

5.2.4연습문제

기본

  1. \(\mathrm{Var}X = 4\), \(\mathrm{Var}Y = 9\), \(\rho = 0.5\)이면 \(\mathrm{Var}(X - Y)\)는?
    답

    \(\mathrm{Cov} = 0.5 \times 2 \times 3 = 3\). \(4 + 9 - 6 = 7\).

응용

  1. \(X_1, \ldots, X_n\)의 분산이 모두 \(\sigma^2\)이고 어떤 두 개의 상관계수도 \(\rho\)일 때 \(\mathrm{Var}(\bar X)\)는? \(n \to \infty\)이면?
    답

    \(\frac{1}{n^2}[n\sigma^2 + n(n-1)\rho\sigma^2] = \frac{\sigma^2}{n}[1 + (n-1)\rho]\). \(n \to \infty\)이면 \(\rho\sigma^2\)로 가며 0이 되지 않습니다. 같은 학교 학생처럼 서로 닮은 표본은 아무리 늘려도 정확도에 한계가 있습니다(응통8 05단원의 설계 효과).
