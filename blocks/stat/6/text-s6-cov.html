공분산, 상관계수, 합의 분산

본문

수익률의 표준편차가 20%인 주식과 30%인 주식에 반씩 투자한다. 포트폴리오의 표준편차는 두 값의 평균인 25%일까? 두 주식이 함께 오르내리면 그럴 것 같지만, 반대로 움직이면 위험이 서로 상쇄될 것이다. 합의 퍼짐은 각자의 퍼짐 말고 무엇에 달려 있을까?

먼저 알아야 할 것결합분포(5.1절)와 기대값, 분산(3.1절)을 쓴다.

5.2.1공분산과 상관계수

정의 5.2.1 (공분산과 상관계수)

\(\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E(XY) - \mu_X\mu_Y\)를 공분산이라 하고, \(\rho = \mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)\)를 상관계수라 한다.

두 편차의 곱이 평균적으로 양수이면, 곧 둘이 함께 평균보다 크거나 함께 작은 경우가 많으면 공분산이 양수이다. 그런데 공분산은 단위에 따라 크기가 바뀐다. cm를 mm로 바꾸면 10배가 되므로, 표준편차로 나눈 상관계수로 강도를 비교한다. 또 공분산은 두 자리 모두에서 선형이다. 즉 \(\mathrm{Cov}(aX + b, cY + d) = ac\,\mathrm{Cov}(X, Y)\)이고 \(\mathrm{Cov}(X_1 + X_2, Y) = \mathrm{Cov}(X_1, Y) + \mathrm{Cov}(X_2, Y)\)이며, \(\mathrm{Cov}(X, X) = \mathrm{Var}(X)\)이다.

5.2.2합의 분산

처음 질문의 답이 다음 정리이다.

정리 5.2.2 (선형결합의 분산)

(가) \(\mathrm{Var}(aX + bY) = a^2\mathrm{Var}(X) + b^2\mathrm{Var}(Y) + 2ab\,\mathrm{Cov}(X,Y)\)이다. (나) 일반적으로 \(\mathrm{Var}\big(\sum_i a_iX_i\big) = \sum_i a_i^2\mathrm{Var}(X_i) + 2\sum_{i<j}a_ia_j\mathrm{Cov}(X_i, X_j)\)이다. (다) \(X\)와 \(Y\)가 독립이면 \(E(XY) = E(X)E(Y)\)이므로 공분산이 0이고, 분산이 그대로 더해진다.

증명. (나)는 \(\mathrm{Var}(\sum a_iX_i) = \mathrm{Cov}(\sum_i a_iX_i, \sum_j a_jX_j) = \sum_i\sum_j a_ia_j\mathrm{Cov}(X_i, X_j)\)를 대각(\(i = j\))과 나머지로 나누면 된다. (다)는 연속형이면 \(E(XY) = \iint xy f_X(x)f_Y(y)\,dx\,dy = E(X)E(Y)\)이다. ∎

즉 합의 퍼짐은 각자의 분산에 "함께 움직이는 정도"인 공분산 항이 더해져 정해진다. 행렬로는 \(\mathrm{Var}(\mathbf a^\top\mathbf X) = \mathbf a^\top\Sigma\mathbf a\)(\(\Sigma\)는 공분산 행렬)이며, 분산은 음수가 될 수 없으므로 공분산 행렬은 양의 준정치이다(응통2 5단원).

예제 5.2.1

처음 질문에서 상관계수가 \(\rho = 1, 0, -0.5\)일 때 포트폴리오의 표준편차를 구하여라.

풀이. \(\mathrm{Var} = 0.25(0.04) + 0.25(0.09) + 2(0.25)\rho(0.2)(0.3) = 0.0325 + 0.03\rho\)이다. \(\rho = 1\)이면 \(\sqrt{0.0625} = 25\%\)로 두 표준편차의 평균이다. 그러나 \(\rho = 0\)이면 \(\sqrt{0.0325} \approx 18.0\%\), \(\rho = -0.5\)이면 \(\sqrt{0.0175} \approx 13.2\%\)이다. 그러므로 상관이 낮을수록 분산 투자의 효과가 크다(그림 1).

5.2.3상관계수의 범위와 한계

정리 5.2.3 (상관계수의 범위)

\(|\rho| \le 1\)이고, \(|\rho| = 1\)인 것은 어떤 \(a\)와 \(b \ne 0\)에 대해 \(Y = a + bX\)가 확률 1로 성립하는 것과 같다.

증명. 표준화 변수 \(U = (X - \mu_X)/\sigma_X\), \(V = (Y - \mu_Y)/\sigma_Y\)에 대해 \(0 \le \mathrm{Var}(U \pm V) = 2(1 \pm \rho)\)이므로 \(-1 \le \rho \le 1\)이다. 등호이면 \(U \mp V\)의 분산이 0이라 \(V = \pm U\)가 확률 1로 성립한다. ∎

한편 정리 5.2.2 (다)의 역은 거짓이다. \(X \sim N(0,1)\), \(Y = X^2\)이면 \(\mathrm{Cov}(X, Y) = E(X^3) = 0\)이지만 \(Y\)는 \(X\)로 완전히 정해진다. 상관계수는 직선 관계의 강도만 재기 때문이다. 다만 결합분포가 다변량 정규이면 상관 0과 독립이 같다(5.4절).

흔한 오해"상관이 0이면 관계가 없다"고 읽기 쉽다. 상관계수 0은 직선으로 나타낼 관계가 없다는 뜻일 뿐이며, 위의 \(Y = X^2\)처럼 완벽한 곡선 관계도 상관이 0일 수 있다. 자료를 다룰 때 산점도를 먼저 그려 보는 이유이다.
마무리

공분산 \(\mathrm{Cov}(X, Y) = E(XY) - \mu_X\mu_Y\)는 두 변수가 함께 움직이는 정도를 재며 두 자리 모두에서 선형이고, 상관계수 \(\rho\)는 이를 표준편차로 나눈 단위 없는 강도이다. 선형결합의 분산은 \(\sum a_i^2\sigma_i^2 + 2\sum_{i<j}a_ia_j\mathrm{Cov}(X_i, X_j)\)이므로 상관이 낮을수록 합의 퍼짐이 줄어든다. \(|\rho| \le 1\)이고 독립이면 \(\rho = 0\)이지만, 그 역은 성립하지 않는다.

5.2.4연습문제

기본

  1. \(\mathrm{Var}(X) = 4\), \(\mathrm{Var}(Y) = 9\), \(\rho = 0.5\)이면 \(\mathrm{Var}(X - Y)\)는 얼마인가?
    답

    \(\mathrm{Cov}(X, Y) = 0.5 \times 2 \times 3 = 3\)이므로 \(4 + 9 - 2 \times 3 = 7\)이다.

응용

  1. \(X_1, \ldots, X_n\)의 분산이 모두 \(\sigma^2\)이고 어느 두 개의 상관계수도 \(\rho\)일 때 \(\mathrm{Var}(\bar X)\)는 무엇인가? \(n \to \infty\)이면 어떻게 되는가?
    답

    \(\frac{1}{n^2}[n\sigma^2 + n(n-1)\rho\sigma^2] = \frac{\sigma^2}{n}[1 + (n-1)\rho]\)이다. \(n \to \infty\)이면 \(\rho\sigma^2\)으로 가며 0이 되지 않는다. 같은 학교 학생처럼 서로 닮은 표본은 아무리 늘려도 정확도에 한계가 있다(응통8 5단원의 설계 효과).
