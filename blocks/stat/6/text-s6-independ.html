사건의 독립과 조건부 독립

본문
이 절에서 배울 것
  • 두 사건과 여러 사건의 독립을 정의하고 판정한다.
  • 독립과 배반을 구별하고, 쌍별 독립과 상호 독립의 차이를 예로 보인다.
  • 조건부 독립이 무엇이며 독립과 어떻게 다른지 안다.
먼저 알아야 할 것
  • 조건부확률과 베이즈 정리 (1.3절).

안다고 달라지지 않는다

오늘 서울에 비가 왔다는 사실은 내일 부산의 주가 지수에 대해 아무것도 알려 주지 않을 것입니다. 반면 첫째 아이의 혈액형은 둘째 아이의 혈액형에 대해 많은 것을 알려 줍니다. "한 사건을 알아도 다른 사건의 확률이 바뀌지 않는다"는 생각을 수식으로 쓴 것이 독립이며, 확률 계산을 곱셈으로 단순하게 만드는 가장 강력한 가정입니다.

1.4.1두 사건의 독립

정의 1.4.1

\(P(A \cap B) = P(A)P(B)\)이면 \(A\)와 \(B\)는 독립입니다.

\(P(B) > 0\)이면 독립은 \(P(A \mid B) = P(A)\), 곧 \(B\)를 알아도 \(A\)의 확률이 바뀌지 않는다는 뜻입니다. 정의를 곱 꼴로 쓰는 까닭은 \(P(B) = 0\)인 경우까지 포함하고 \(A\), \(B\)에 대칭이기 때문입니다. \(A\)와 \(B\)가 독립이면 \(A\)와 \(B^c\), \(A^c\)와 \(B^c\)도 독립입니다: \(P(A \cap B^c) = P(A) - P(A)P(B) = P(A)P(B^c)\).

배반(\(A \cap B = \emptyset\))과 혼동하지 않습니다. 확률이 양수인 두 배반 사건은 하나가 일어나면 다른 하나는 절대 안 일어나므로(\(P(A \mid B) = 0 \ne P(A)\)) 오히려 강하게 종속입니다.

1.4.2여러 사건의 독립

정의 1.4.2

사건 \(A_1, \ldots, A_n\)이 상호 독립이란, 그중 어떤 부분 모임 \(A_{i_1}, \ldots, A_{i_k}\) (\(k \ge 2\))를 골라도 \(P(A_{i_1} \cap \cdots \cap A_{i_k}) = P(A_{i_1}) \cdots P(A_{i_k})\)인 것.

세 사건이면 둘씩의 곱 공식 세 개와 셋 전체의 곱 공식 하나, 모두 네 개를 확인해야 합니다. 둘씩만 성립하는 것을 쌍별 독립이라 하며, 이것은 상호 독립보다 약합니다.

예제 1.4.3

공정한 동전 두 개를 던집니다. \(A\) = 첫째가 앞, \(B\) = 둘째가 앞, \(C\) = 두 결과가 같음. 세 사건이 쌍별 독립이지만 상호 독립은 아님을 보이세요.

풀이. 네 결과 앞앞, 앞뒤, 뒤앞, 뒤뒤가 같은 가능성(1.2절). \(P(A) = P(B) = P(C) = 1/2\). \(A \cap B\) = {앞앞}, \(A \cap C\) = {앞앞}, \(B \cap C\) = {앞앞}이고 확률이 모두 \(1/4 = (1/2)^2\)이라 쌍별 독립입니다. 그런데 \(A \cap B \cap C\) = {앞앞}의 확률은 \(1/4 \ne 1/8\)입니다. \(A\)와 \(B\)를 알면 \(C\)는 완전히 정해지기 때문입니다.

1.4.3독립 시행과 곱셈

같은 실험을 서로 영향 없이 되풀이하면(독립 시행) 결과의 확률은 각 시행 확률의 곱입니다. 성공 확률 \(p\)인 시행을 \(n\)번 할 때 "적어도 한 번 성공"의 확률은 여사건으로 \(1 - (1-p)^n\)입니다. 부품 10개가 모두 작동해야 하는 직렬 시스템에서 부품마다 고장 확률이 1%이고 서로 독립이면 시스템이 작동할 확률은 \(0.99^{10} \approx 0.904\)입니다. 독립 가정이 깨지면(예: 같은 정전이 모든 부품에 영향) 이 계산은 크게 틀릴 수 있습니다.

1.4.4조건부 독립

정의 1.4.4

\(P(C) > 0\)일 때 \(P(A \cap B \mid C) = P(A \mid C)P(B \mid C)\)이면 \(A\)와 \(B\)는 \(C\)가 주어졌을 때 조건부 독립입니다.

조건부 독립과 독립은 서로를 함의하지 않습니다. 같은 병의 두 검사 결과는 환자인지 아닌지(\(C\))를 알면 서로 독립이라고 가정하는 경우가 많지만, \(C\)를 모르면 첫 검사가 양성일 때 환자일 가능성이 커지므로 둘째 검사도 양성일 가능성이 커져 종속입니다. 1.3절 연습문제의 "같은 검사를 한 번 더" 계산이 바로 조건부 독립 가정을 쓴 것입니다. 거꾸로 독립인 두 사건이 어떤 조건 아래에서는 종속이 될 수도 있습니다(독립인 두 동전에서 "적어도 하나가 앞"이 주어지면 두 결과는 종속).

요약
  1. 독립: \(P(A \cap B) = P(A)P(B)\). 배반과는 다르며, 양의 확률인 배반 사건은 종속입니다.
  2. 상호 독립은 모든 부분 모임의 곱 공식이 필요하고, 쌍별 독립보다 강합니다.
  3. 조건부 독립과 독립은 서로 다른 성질입니다.

1.4.5연습문제

기본

  1. 주사위 하나를 던질 때 \(A\) = 짝수, \(B\) = 4 이하. 독립인가요?
    답

    \(P(A) = 1/2\), \(P(B) = 2/3\), \(A \cap B = \{2, 4\}\)로 \(P = 1/3 = (1/2)(2/3)\). 독립입니다.

  2. 성공 확률 0.1인 독립 시행을 몇 번 해야 적어도 한 번 성공할 확률이 0.9 이상이 되나요?
    답

    \(1 - 0.9^n \ge 0.9\), \(0.9^n \le 0.1\), \(n \ge \ln 0.1/\ln 0.9 \approx 21.85\). 22번.

응용

  1. 독립인 두 사건 \(A\), \(B\)가 \(C = A \cup B\)가 주어졌을 때 종속일 수 있음을 공정한 동전 두 개(\(A\) = 첫째 앞, \(B\) = 둘째 앞)로 보이세요.
    답

    \(P(C) = 3/4\). \(P(A \mid C) = P(B \mid C) = (1/2)/(3/4) = 2/3\), \(P(A \cap B \mid C) = (1/4)/(3/4) = 1/3 \ne (2/3)^2 = 4/9\). 종속입니다. 하나가 뒷면이면 다른 하나는 반드시 앞면이어야 하기 때문입니다.
