다변량 분포 단원 마무리 연습

문제 6 · 계산·개념 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(X, Y\)의 결합 확률질량함수가 \(p(0,0) = 0.4\), \(p(0,1) = 0.1\), \(p(1,0) = 0.2\), \(p(1,1) = 0.3\)입니다. 주변분포, \(P(Y = 1 \mid X = 1)\)을 구하고 독립인지 판정하세요. [05-01]

    힌트 1

    주변분포는 행 합, 열 합입니다.

    힌트 2

    독립이면 모든 칸에서 \(p(x, y) = p_X(x)p_Y(y)\)입니다.

    풀이

    \(P(X = 0) = 0.5\), \(P(X = 1) = 0.5\), \(P(Y = 0) = 0.6\), \(P(Y = 1) = 0.4\)입니다. \(P(Y = 1 \mid X = 1) = 0.3/0.5 = 0.6\)입니다.

    \(p(1, 1) = 0.3 \ne 0.5\times0.4 = 0.2\)이므로 독립이 아닙니다. \(X = 1\)이면 \(Y = 1\)일 확률이 0.4에서 0.6으로 높아집니다.

  2. 계산앞 문제에서 \(\mathrm{Cov}(X, Y)\)와 상관계수를 구하세요. [05-02]

    힌트 1

    \(\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y)\)이고, \(E(XY) = P(X = 1, Y = 1)\)입니다.

    힌트 2

    베르누이 변수의 분산은 \(p(1-p)\)입니다.

    풀이

    \(E(XY) = 0.3\), \(E(X) = 0.5\), \(E(Y) = 0.4\)이므로 \(\mathrm{Cov} = 0.3 - 0.2 = 0.1\)입니다. \(\mathrm{Var}(X) = 0.25\), \(\mathrm{Var}(Y) = 0.24\)이므로 \(\rho = 0.1/\sqrt{0.06} \approx 0.408\)입니다.

  3. 계산결합 밀도 \(f(x, y) = x + y\) (\(0 \le x, y \le 1\))에서 주변 밀도 \(f_X(x)\)와 조건부 밀도 \(f(y \mid x)\)를 구하세요. [05-01]

    힌트 1

    \(f_X(x) = \int_0^1(x + y)\,dy\)입니다.

    힌트 2

    \(f(y \mid x) = f(x, y)/f_X(x)\)입니다.

    풀이

    \(f_X(x) = x + 1/2\) (\(0 \le x \le 1\)), \(f(y \mid x) = \dfrac{x + y}{x + 1/2}\) (\(0 \le y \le 1\))입니다. 조건부 밀도가 \(x\)에 따라 바뀌므로 \(X\)와 \(Y\)는 독립이 아닙니다. 각 \(x\)에서 \(\int_0^1 f(y \mid x)dy = 1\)인지 확인해 보세요.

  4. 계산앞 문제에서 \(E(Y \mid X = x)\)를 구하고, 반복 기대값의 법칙 \(E[E(Y \mid X)] = E(Y)\)가 성립함을 확인하세요. [05-03]

    힌트 1

    \(E(Y \mid X = x) = \int_0^1 y\frac{x+y}{x+1/2}dy\)입니다.

    힌트 2

    대칭성에서 \(E(Y) = E(X) = \int_0^1 x(x + 1/2)\,dx\)입니다.

    풀이

    \(E(Y \mid X = x) = \dfrac{x/2 + 1/3}{x + 1/2}\)입니다. \(E[E(Y \mid X)] = \int_0^1\frac{x/2 + 1/3}{x + 1/2}(x + 1/2)\,dx = \int_0^1(x/2 + 1/3)\,dx = 1/4 + 1/3 = 7/12\)입니다.

    직접 계산한 \(E(Y) = \int_0^1 y(y + 1/2)\,dy = 1/3 + 1/4 = 7/12\)과 같습니다.

  5. 개념\(X\)가 \(-1, 0, 1\)을 같은 확률로 가지고 \(Y = X^2\)일 때 \(\mathrm{Cov}(X, Y) = 0\)이지만 \(X, Y\)가 독립이 아님을 보이세요. [05-02]

    힌트 1

    \(E(XY) = E(X^3)\)입니다.

    힌트 2

    \(P(X = 0, Y = 1)\)과 \(P(X = 0)P(Y = 1)\)을 비교하세요.

    풀이

    \(E(X) = 0\), \(E(XY) = E(X^3) = 0\)이므로 \(\mathrm{Cov} = 0\)입니다. 그러나 \(P(X = 0, Y = 1) = 0\)인데 \(P(X = 0)P(Y = 1) = \frac13\cdot\frac23 \ne 0\)이므로 독립이 아닙니다.

    공분산은 선형 관계만 잽니다. 독립이면 공분산이 0이지만, 거꾸로는 성립하지 않습니다(다변량 정규분포는 예외).

  6. 계산\((X, Y)\)가 평균 0, 분산 1, 상관계수 0.6인 이변량 정규분포를 따릅니다. \(X = 1.5\)일 때 \(Y\)의 조건부 분포를 쓰고, \(P(Y > 0 \mid X = 1.5)\)를 구하세요. [05-04]

    힌트 1

    표준화된 이변량 정규에서 \(Y \mid X = x \sim N(\rho x, 1 - \rho^2)\)입니다.

    힌트 2

    조건부 표준편차는 \(\sqrt{1 - 0.36} = 0.8\)입니다.

    풀이

    \(Y \mid X = 1.5 \sim N(0.9, 0.8^2)\)입니다. \(P(Y > 0 \mid X = 1.5) = \Phi(0.9/0.8) = \Phi(1.125) \approx 0.870\)입니다.

    조건부 평균 \(0.9\)가 \(1.5\)보다 0 쪽에 가까운 것이 "평균으로의 회귀"이고, 조건부 분산이 \(x\)와 무관하게 \(1 - \rho^2\)으로 줄어든다는 점이 회귀분석의 등분산 가정과 이어집니다.
