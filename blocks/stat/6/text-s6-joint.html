결합, 주변, 조건부 분포

본문

0과 1 사이에서 두 점을 골라 작은 값을 \(X\), 큰 값을 \(Y\)라 하자. \((X, Y)\)는 \(0 < x < y < 1\)인 삼각형 위에 고르게 퍼져 있으므로 결합 밀도는 상수 2이다. 밀도가 상수이니 \(X\)와 \(Y\)는 서로 무관할 것 같다. 정말 그럴까? 두 변수를 함께 다룰 때 한 변수만의 분포, 한 변수를 알 때 다른 변수의 분포는 어떻게 구할까?

먼저 알아야 할 것이중적분(응통1 6단원)과 조건부확률(1.3절)을 쓴다.

5.1.1결합 분포와 주변 분포

키와 몸무게, 공부 시간과 점수처럼 두 양을 함께 다루려면 \(P(X \le x, Y \le y)\) 같은 결합 확률이 필요하다. 한 변수의 밀도가 구간 위의 넓이로 확률을 주었듯, 두 변수의 결합 밀도는 평면 영역 위의 부피로 확률을 준다.

정의 5.1.1 (결합 밀도와 주변 밀도)

평면의 모든 영역 \(A\)에 대해 \(P((X, Y) \in A) = \iint_A f(x,y)\,dx\,dy\)인 \(f(x, y) \ge 0\)을 결합 밀도라 한다. 또 \(f_X(x) = \int f(x, y)\,dy\)와 \(f_Y(y) = \int f(x,y)\,dx\)를 주변 밀도라 한다. 이산형은 적분 대신 합을 쓴다.

즉 주변 밀도는 다른 변수를 적분해 없앤 것이다. 분할표에서 행 합과 열 합을 구해 표 가장자리(주변)에 적는 것과 같아서 이런 이름이 붙었다.

5.1.2조건부 분포와 독립

정의 5.1.2 (조건부 밀도)

\(f_X(x) > 0\)일 때, \(X = x\)가 주어진 \(Y\)의 조건부 밀도는 \(f(y \mid x) = f(x, y)/f_X(x)\)이다.

그런데 연속형에서는 \(P(X = x) = 0\)이므로 1.3절의 정의를 그대로 쓸 수 없다. 그래도 이렇게 정의할 수 있는 것은, 조건을 \(x \le X \le x + h\)로 두고 계산한 조건부확률에서 \(h \to 0\)으로 보낸 극한이 이 식이기 때문이다. 그림으로는 결합 밀도를 \(X = x\)인 세로선으로 잘라 낸 단면을, 넓이가 1이 되도록 \(f_X(x)\)로 나눈 것이다.

정리 5.1.3 (독립의 판정)

\(X\)와 \(Y\)가 독립인 것은 모든 \(x, y\)에서 \(f(x, y) = f_X(x)f_Y(y)\)인 것과 같다. 또 이는 \(f(x,y) = g(x)h(y)\)로 인수분해되고 밀도가 양수인 영역이 직사각형인 것과 같다.

두 번째 판정법에서 영역 조건을 빠뜨리면 안 된다. 영역이 직사각형이 아니면 한 변수의 값이 다른 변수가 가질 수 있는 범위를 바꾸므로, 식이 아무리 깔끔하게 나뉘어도 독립이 아니다.

예제 5.1.1

처음 질문의 \(f(x, y) = 2\) (\(0 < x < y < 1\))에서 주변 밀도, \(f(y \mid x)\), 독립 여부를 구하여라.

풀이. \(f_X(x) = \int_x^1 2\,dy = 2(1 - x)\), \(f_Y(y) = \int_0^y 2\,dx = 2y\)이다. 작은 값은 0 쪽에, 큰 값은 1 쪽에 몰린다. 조건부 밀도는 \(f(y \mid x) = \frac{2}{2(1-x)} = \frac{1}{1-x}\) (\(x < y < 1\))이므로, \(X = x\)이면 \(Y\)는 \((x, 1)\)의 균일분포이다(그림 1). 그런데 \(f_Xf_Y = 4y(1-x) \ne 2\)이므로 독립이 아니다. 처음 질문의 직관과 달리, 밀도가 상수여도 영역이 삼각형이라 두 변수는 종속이다.

마무리

결합 밀도는 평면 영역 위의 부피로 확률을 주며, 주변 밀도는 다른 변수를 적분해 없애 얻는다. 조건부 밀도는 결합 밀도를 한 변수의 값으로 자른 단면을 주변 밀도로 나눈 것이다. 두 변수가 독립인 것은 결합 밀도가 주변 밀도의 곱인 것과 같고, 인수분해로 판정할 때는 값을 가지는 영역이 직사각형인지도 확인해야 한다.

5.1.3연습문제

기본

  1. 예제 5.1.1에서 \(P(Y > 2X)\)는 얼마인가?
    답

    \(\int_0^{1/2}\int_{2x}^1 2\,dy\,dx = \int_0^{1/2}2(1 - 2x)\,dx = 1/2\)이다.

응용

  1. \(f(x, y) = e^{-x-y}\) (\(x, y > 0\))이면 \(X\)와 \(Y\)는 독립인가? \(P(X < Y)\)는 얼마인가?
    답

    \(e^{-x}e^{-y}\)로 나뉘고 영역이 사분면(직사각형)이므로 독립이다. 두 변수의 분포가 같고 대칭이므로 \(P(X < Y) = 1/2\)이다.
