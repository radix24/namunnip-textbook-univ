두 균일분포의 합: 짝 변수를 붙여 적분하기

예제 · 야코비안

먼저 읽는 법

변수 하나의 분포만 필요할 때도 2변수 변환 공식을 쓰려면 짝 변수가 하나 더 있어야 합니다. 가장 간단한 짝(\(Y_2 = X_2\))을 붙이고, 마지막에 그 변수로 적분합니다. 어려운 부분은 계산보다 새 변수가 가질 수 있는 영역을 정확히 그리는 일입니다.

문제. \(X_1, X_2\)가 독립이고 둘 다 \(U(0, 1)\)일 때 \(S = X_1 + X_2\)의 밀도를 구하세요.

풀이

  1. 짝 변수 \(T = X_2\)를 붙입니다. 역변환 \(x_1 = s - t\), \(x_2 = t\). \(J = \det\begin{pmatrix}1 & -1\\ 0 & 1\end{pmatrix} = 1\).
    선형 변환이라 야코비안이 상수입니다.
  2. 결합 밀도 \(f_{S,T}(s, t) = 1 \cdot 1\), 단 \(0 < s - t < 1\)이고 \(0 < t < 1\).
    원래 밀도는 단위 정사각형에서 1입니다. 그 조건을 새 변수로 옮겨 씁니다.
  3. 영역: \(\max(0, s-1) < t < \min(1, s)\). \(0 < s \le 1\)이면 \(0 < t < s\), \(1 < s < 2\)이면 \(s - 1 < t < 1\).
    \(s\)를 고정하고 \(t\)의 범위를 구합니다. \(s\)가 1을 넘는지에 따라 경계가 바뀝니다.
  4. \(t\)로 적분: \(f_S(s) = s\) (\(0 < s \le 1\)), \(f_S(s) = 2 - s\) (\(1 < s < 2\)). 삼각형 모양의 분포입니다.
    적분 구간의 길이가 곧 밀도입니다.

검산

넓이: 밑변 2, 높이 1인 삼각형이라 \(\frac12 \times 2 \times 1 = 1\). 평균은 대칭에서 1로 \(E(X_1) + E(X_2) = 1/2 + 1/2\)과 맞습니다. R로 hist(runif(1e5) + runif(1e5), freq = FALSE)를 그리면 삼각형이 보입니다.

의미

균일분포 하나는 평평하지만 둘을 더하면 가운데가 솟은 삼각형이 되고, 12개를 더하면 거의 정규분포가 됩니다(7.3절의 중심극한정리). 더하는 것은 밀도의 합성곱 \(f_S(s) = \int f_{X_1}(s - t)f_{X_2}(t)\,dt\)이며, 위 계산은 그 적분을 변환 공식으로 얻은 것입니다.
