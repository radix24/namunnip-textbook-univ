같은 가능성 모형과 경우의 수

본문
이 절에서 배울 것
  • 결과가 유한하고 모두 같은 가능성일 때 확률을 경우의 수의 비로 계산한다.
  • 곱의 법칙, 순열, 조합, 같은 것이 있는 순열을 구별해 쓴다.
  • 초기하분포와 생일 문제를 경우의 수로 푼다.
먼저 알아야 할 것
  • 표본공간과 확률의 공리 (1.1절).

23명이면 생일이 같은 쌍이 있을 확률이 절반을 넘는다

한 반에 23명이 있으면 생일이 같은 두 사람이 있을 확률은 약 0.507입니다. 1년이 365일이니 23명은 적어 보이지만, 비교할 "쌍"은 \(\binom{23}{2} = 253\)개나 됩니다. 이런 계산은 모든 결과가 같은 가능성을 갖는 모형에서 경우의 수를 세는 일로 바뀝니다. 셀 때 "순서를 구별하는가", "같은 것을 다시 뽑을 수 있는가"를 정확히 정하지 않으면 쉽게 틀립니다.

1.2.1같은 가능성 모형

정의 1.2.1

표본공간 \(\Omega\)가 유한하고 모든 근원사건의 확률이 같으면, 사건 \(A\)의 확률은 \(P(A) = \dfrac{|A|}{|\Omega|}\)입니다.

공리(1.1절)에서 바로 나옵니다. 근원사건 \(N\)개의 확률이 같고 합이 1이므로 각각 \(1/N\)이고, \(A\)는 그중 \(|A|\)개의 배반 합집합입니다. 주의할 점은 "같은 가능성"이 모형의 가정이라는 것입니다. 동전 두 개를 던질 때 결과를 {앞앞, 앞뒤, 뒤뒤} 세 가지로 세면 같은 가능성이 아니고(앞뒤는 두 가지 방법으로 일어남), 순서를 구별한 네 가지 {앞앞, 앞뒤, 뒤앞, 뒤뒤}가 같은 가능성입니다.

1.2.2세는 규칙

정리 1.2.2

(가) 곱의 법칙: 단계 \(k\)개를 차례로 거치고 단계 \(i\)의 선택지가 앞 단계와 관계없이 \(n_i\)개이면 전체 경우는 \(n_1 n_2 \cdots n_k\).
(나) 순열: \(n\)개에서 \(r\)개를 순서 있게 뽑는 경우 \({}_nP_r = \dfrac{n!}{(n-r)!}\).
(다) 조합: 순서 없이 뽑는 경우 \(\dbinom nr = \dfrac{n!}{r!(n-r)!}\).
(라) 같은 것이 있는 순열: 종류별 개수가 \(n_1, \ldots, n_k\)인 \(n\)개를 일렬로 놓는 경우 \(\dfrac{n!}{n_1! \cdots n_k!}\).

(나)는 곱의 법칙에서 첫 자리 \(n\)가지, 둘째 자리 \(n-1\)가지, …를 곱한 것이고, (다)는 같은 \(r\)개를 순서만 바꾼 \(r!\)개의 순열을 하나로 센 것이라 \({}_nP_r/r!\)입니다. (라)도 같은 종류끼리 자리를 바꾼 \(n_1! \cdots n_k!\)개를 하나로 셉니다. 복원추출로 \(r\)번 뽑으면(같은 것을 다시 뽑을 수 있으면) 곱의 법칙으로 \(n^r\)입니다.

예제 1.2.3

불량품 4개가 섞인 20개의 부품에서 5개를 비복원으로 뽑을 때 불량품이 정확히 1개일 확률은?

풀이. 순서 없이 5개를 고르는 모든 경우 \(\binom{20}5 = 15504\)가 같은 가능성입니다. 불량 4개 중 1개, 양품 16개 중 4개를 고르는 경우는 곱의 법칙으로 \(\binom41\binom{16}4 = 4 \times 1820 = 7280\). 확률 \(7280/15504 \approx 0.470\). 일반적으로 \(\binom Kk\binom{N-K}{n-k}\big/\binom Nn\)을 초기하분포라 하며, 표본조사와 품질 검사의 기본 모형입니다(4.1절의 이항분포는 이것의 복원추출 판).

1.2.3여사건으로 세기: 생일 문제

"적어도 하나"를 직접 세면 경우가 겹쳐 복잡하므로 여사건 "하나도 없음"을 셉니다. \(n\)명의 생일이 모두 다른 경우는 \(365 \times 364 \times \cdots \times (365 - n + 1)\)이고 전체는 \(365^n\)이므로

\[P(\text{같은 생일이 있음}) = 1 - \frac{{}_{365}P_n}{365^n} = 1 - \prod_{i=0}^{n-1}\left(1 - \frac{i}{365}\right).\]

\(n = 23\)이면 약 0.507, \(n = 50\)이면 약 0.970입니다. \(1 - x \approx e^{-x}\)로 근사하면 곱은 \(\exp(-n(n-1)/730)\)이 되어, 확률이 절반이 되는 \(n\)은 \(\sqrt{730\ln 2} \approx 22.5\) 근처입니다. 같은 계산이 해시 충돌, 무작위 식별번호의 중복 확률을 추정하는 데 쓰입니다.

n <- 23; 1 - prod(1 - (0:(n-1))/365)   # 0.507
pbirthday(23)                           # 같은 값을 계산하는 내장 함수
요약
  1. 같은 가능성 모형에서 \(P(A) = |A|/|\Omega|\). 같은 가능성이 성립하도록 표본공간을 잡습니다.
  2. 순서를 구별하면 순열, 구별하지 않으면 조합. 복원이면 \(n^r\).
  3. "적어도 하나"는 여사건으로 셉니다.

1.2.4연습문제

기본

  1. STATISTICS의 글자를 일렬로 배열하는 방법의 수는?
    답

    10글자 중 S 3, T 3, I 2, A 1, C 1. \(10!/(3!\,3!\,2!) = 3628800/72 = 50400\).

  2. 52장 카드에서 5장을 뽑을 때 모두 하트일 확률은?
    답

    \(\binom{13}5/\binom{52}5 = 1287/2598960 \approx 0.000495\).

응용

  1. 편지 \(n\)통을 봉투 \(n\)개에 무작위로 넣을 때 모두 엉뚱한 봉투에 들어갈 확률은 \(n\)이 커지면 \(1/e\)에 가까워집니다. 포함-배제 원리 \(P(\bigcup A_i) = \sum P(A_i) - \sum_{i<j} P(A_i \cap A_j) + \cdots\)로 이를 보이세요.
    답

    \(A_i\) = \(i\)번째 편지가 제자리. \(P(A_{i_1} \cap \cdots \cap A_{i_k}) = (n-k)!/n!\)이므로 \(P(\bigcup A_i) = \sum_{k=1}^n (-1)^{k+1}\binom nk\frac{(n-k)!}{n!} = \sum_{k=1}^n \frac{(-1)^{k+1}}{k!}\). 여사건 확률은 \(\sum_{k=0}^n (-1)^k/k! \to e^{-1} \approx 0.368\).
