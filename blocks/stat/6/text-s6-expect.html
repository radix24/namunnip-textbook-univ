  • 질량함수와 밀도함수 (2.1절), 부분적분.

길게 보면 평균적으로 얼마인가

복권 한 장의 상금은 대부분 0이고 아주 드물게 큽니다. 한 장으로는 알 수 없지만 수없이 사면 한 장당 평균 얼마를 받는지는 정해져 있습니다. 이 값이 기대값입니다.

3.1.1정의

정의 3.1.1

기대값: 이산형 \(E(X) = \sum_x x\,p(x)\), 연속형 \(E(X) = \int x f(x)\,dx\). 단 \(\sum |x|p(x)\) 또는 \(\int |x|f(x)dx\)가 유한할 때만 정의합니다.

함수의 기대값은 \(Y = g(X)\)의 분포를 구하지 않고 \(E[g(X)] = \sum g(x)p(x)\) 또는 \(\int g(x)f(x)dx\)로 계산할 수 있습니다. 코시 분포 \(f(x) = \frac{1}{\pi(1+x^2)}\)는 \(\int |x|f\)가 발산해 기대값이 없습니다.

3.1.2선형성과 분산

정리 3.1.2

\(E(aX + b) = aE(X) + b\). 일반적으로 \(E(X + Y) = E(X) + E(Y)\)(독립이 아니어도).

정의 3.1.3

분산 \(\mathrm{Var}(X) = E[(X - \mu)^2]\), \(\mu = E(X)\). \(k\)차 적률 \(E(X^k)\).

전개하고 선형성을 쓰면 \(\mathrm{Var}(X) = E(X^2) - 2\mu E(X) + \mu^2 = E(X^2) - \mu^2\). 또 \(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\)입니다.

예제 3.1.4

지수분포 \(f(x) = \lambda e^{-\lambda x}\) (\(x > 0\))의 평균과 분산을 구하세요.

풀이. 부분적분: \(E(X) = \int_0^\infty x\lambda e^{-\lambda x}dx = [-xe^{-\lambda x}]_0^\infty + \int_0^\infty e^{-\lambda x}dx = 1/\lambda\). 같은 방법으로 \(E(X^2) = \frac2\lambda E(X) = 2/\lambda^2\). \(\mathrm{Var}(X) = 2/\lambda^2 - 1/\lambda^2 = 1/\lambda^2\).

예제 3.1.5 (지시변수)

편지 \(n\)통을 봉투에 무작위로 넣을 때 제 봉투에 들어간 편지 수의 기대값은?

풀이. \(I_i\) = \(i\)번째 편지가 맞으면 1, 아니면 0. \(E(I_i) = 1/n\). 개수 \(=\sum I_i\)이고 선형성에서 기대값은 \(n \times 1/n = 1\). \(I_i\)들은 독립이 아니지만 선형성에는 독립이 필요 없습니다.

요약
  1. \(E(X) = \sum xp(x)\) 또는 \(\int xf(x)dx\), 절대수렴할 때.
  2. 기대값은 선형, 독립 불필요.
  3. \(\mathrm{Var}(X) = E(X^2) - (EX)^2\), \(\mathrm{Var}(aX+b) = a^2\mathrm{Var}X\).

3.1.3연습문제

기본

  1. 주사위 눈 \(X\)의 평균과 분산은?
    답

    \(E(X) = 3.5\), \(E(X^2) = 91/6\), 분산 \(91/6 - 12.25 = 35/12 \approx 2.92\).

응용

  1. \(E[(X - c)^2]\)을 가장 작게 하는 \(c\)는?
    답

    \(E[(X-c)^2] = \mathrm{Var}(X) + (\mu - c)^2\)이므로 \(c = \mu\).
