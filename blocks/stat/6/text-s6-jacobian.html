단조 변환 공식과 야코비안

본문

로그 수익률이 정규분포를 따른다면 주가 자체는 어떤 분포일까? 2.2절의 누적분포함수 방법은 어떤 변환에도 쓸 수 있지만, 매번 확률을 \(X\)에 대한 사건으로 바꾸고 미분해야 한다. 변환이 한 방향으로만 움직인다면 이 과정을 한 줄 공식으로 줄일 수 있을까? 그리고 두 변수를 함께 바꾸면 어떻게 될까?

먼저 알아야 할 것누적분포함수 방법(2.2절)과 응통1의 야코비안(6단원)을 쓴다.

2.3.1단조 변환 공식

정리 2.3.1 (단조 변환)

\(X\)의 밀도가 \(f_X\)이고 \(g\)가 \(X\)가 가질 수 있는 값의 구간에서 미분가능하고 엄격히 단조이면, \(Y = g(X)\)의 밀도는 다음과 같다.

\[f_Y(y) = f_X\big(g^{-1}(y)\big)\left|\frac{d}{dy}g^{-1}(y)\right|\]

증명. \(g\)가 증가하면 \(F_Y(y) = P(X \le g^{-1}(y)) = F_X(g^{-1}(y))\)이고, 연쇄법칙으로 미분하면 \(f_X(g^{-1}(y))\frac{d}{dy}g^{-1}(y)\)이다. \(g\)가 감소하면 \(F_Y(y) = P(X \ge g^{-1}(y)) = 1 - F_X(g^{-1}(y))\)이고 미분하면 부호가 바뀌는데, 이때 \(\frac{d}{dy}g^{-1} < 0\)이라 절댓값으로 합쳐 쓸 수 있다. ∎

처음 질문의 첫째 답이 이 공식이다. 절댓값 인자는 변환이 구간을 늘이거나 줄이는 비율이다. \(x\) 근처의 짧은 구간 \(dx\)에 담긴 확률 \(f_X(x)\,dx\)는 변환 뒤 \(dy = |g'(x)|\,dx\) 길이의 구간에 그대로 옮겨지므로, 그림 1처럼 구간이 늘어난 만큼 밀도가 낮아진다.

예제 2.3.1

(가) \(X \sim N(\mu, \sigma^2)\)이면 \(Y = aX + b\) (\(a \ne 0\))의 분포는 무엇인가? (나) \(X \sim N(\mu, \sigma^2)\)이면 \(Y = e^X\)의 밀도는 무엇인가?

풀이. (가) \(g^{-1}(y) = (y - b)/a\)이고 \(|dg^{-1}/dy| = 1/|a|\)이므로 \(f_Y(y) = \frac{1}{|a|\sigma\sqrt{2\pi}}\exp\left(-\frac{(y - b - a\mu)^2}{2a^2\sigma^2}\right)\), 곧 \(N(a\mu + b, a^2\sigma^2)\)이다. (나) \(g^{-1}(y) = \ln y\)이고 \(|dg^{-1}/dy| = 1/y\)이므로 \(f_Y(y) = \frac{1}{y\sigma\sqrt{2\pi}}\exp\left(-\frac{(\ln y - \mu)^2}{2\sigma^2}\right)\) (\(y > 0\))이다. 이것이 로그정규분포로, 처음 질문의 주가처럼 소득과 주가같이 곱셈으로 쌓이는 양의 모형이다.

2.3.2단조가 아닌 변환

그런데 \(g\)가 단조가 아니면 정의역을 \(g\)가 단조인 조각 \(I_1, \ldots, I_m\)으로 나누고, 각 조각에서 공식을 쓴 뒤 더한다. 곧 \(f_Y(y) = \sum_j f_X(g_j^{-1}(y))\left|\frac{d}{dy}g_j^{-1}(y)\right|\)이다. 예를 들어 2.2절 예제의 \(Y = X^2\)는 \(x < 0\)과 \(x > 0\) 두 가지에서 \(\pm\sqrt y\)를 더한 것이다.

2.3.3두 변수의 변환과 야코비안

처음 질문의 둘째 부분은 같은 생각을 두 변수로 넓히면 된다.

정리 2.3.2 (두 변수의 변환)

\((X_1, X_2)\)의 결합 밀도가 \(f\)이고 \((Y_1, Y_2) = g(X_1, X_2)\)가 일대일이며, 역변환 \(x_1 = h_1(y_1, y_2)\), \(x_2 = h_2(y_1, y_2)\)가 미분가능하면 다음과 같다.

\[f_{Y}(y_1, y_2) = f\big(h_1(y), h_2(y)\big)\,|J|, \qquad J = \det\begin{pmatrix}\partial x_1/\partial y_1 & \partial x_1/\partial y_2\\ \partial x_2/\partial y_1 & \partial x_2/\partial y_2\end{pmatrix}\]

여기서 1변수의 \(|dx/dy|\)가 2변수에서는 작은 사각형의 넓이가 몇 배로 바뀌는지를 재는 \(|J|\)가 된다. 또 한 변수 \(Y_1 = X_1 + X_2\)의 분포만 원할 때도, 짝 변수 \(Y_2 = X_2\)를 붙여 결합 밀도를 구한 뒤 \(y_2\)로 적분해 없앤다.

예제 2.3.2

\(X_1, X_2\)가 독립이고 둘 다 \(\mathrm{Exp}(1)\)일 때 \(Y_1 = X_1 + X_2\), \(Y_2 = X_1/(X_1 + X_2)\)의 결합 밀도를 구하여라.

풀이. 먼저 역변환은 \(x_1 = y_1y_2\), \(x_2 = y_1(1 - y_2)\)이므로 \(J = \det\begin{pmatrix}y_2 & y_1\\ 1 - y_2 & -y_1\end{pmatrix} = -y_1\), \(|J| = y_1\)이다. 또 \(f(x_1, x_2) = e^{-(x_1+x_2)} = e^{-y_1}\)이므로 \(f_Y(y_1, y_2) = y_1e^{-y_1}\) (\(y_1 > 0\), \(0 < y_2 < 1\))이다. 그런데 이 밀도가 \(y_1\)만의 함수 \(y_1e^{-y_1}\)과 \(y_2\)만의 함수 1의 곱이므로, \(Y_1 \sim \mathrm{Gamma}(2, 1)\), \(Y_2 \sim U(0, 1)\)이고 서로 독립이다(4.3절).

흔한 실수절댓값을 빼먹거나, \(dy/dx\)와 \(dx/dy\)를 바꿔 쓰기 쉽다. 공식의 인자는 역변환의 미분 \(|dx/dy|\)이며, 넓은 구간으로 퍼지면 밀도가 낮아져야 한다는 그림 1의 직관으로 확인하자.
마무리

단조 변환에서는 \(f_Y(y) = f_X(g^{-1}(y))\,|dg^{-1}/dy|\)로 밀도를 바로 구하며, 절댓값 인자는 구간이 늘어나는 비율만큼 밀도를 낮춘다. 단조가 아니면 단조 조각마다 더한다. 두 변수의 변환은 결합 밀도에 역변환의 야코비안 \(|J|\)를 곱해 구하고, 필요 없는 짝 변수는 적분해 없앤다.

2.3.4연습문제

기본

  1. \(X \sim U(0, 1)\)일 때 \(Y = \sqrt X\)와 \(Y = X^2\)의 밀도는 무엇인가?
    답

    \(\sqrt X\)는 \(g^{-1}(y) = y^2\)이므로 \(f_Y(y) = 2y\) (\(0 < y < 1\))이다. \(X^2\)는 \(g^{-1}(y) = \sqrt y\)이므로 \(f_Y(y) = 1/(2\sqrt y)\) (\(0 < y < 1\))이다.

응용

  1. \(Z_1, Z_2\)가 독립인 표준정규일 때 극좌표 \(R = \sqrt{Z_1^2 + Z_2^2}\), \(\Theta\)로 변환하면 \(R\)과 \(\Theta\)가 독립이고 \(\Theta \sim U(0, 2\pi)\)임을 보여라(\(x_1 = r\cos\theta\), \(x_2 = r\sin\theta\), \(|J| = r\)).
    답

    \(f(r, \theta) = \frac{1}{2\pi}e^{-r^2/2} \cdot r\)이다. \(\theta\)만의 함수 \(1/(2\pi)\)와 \(r\)만의 함수 \(re^{-r^2/2}\)의 곱이므로 독립이고 \(\Theta \sim U(0, 2\pi)\)이다. 이를 거꾸로 쓴 것이 정규 난수를 만드는 박스-뮬러 방법이다.
