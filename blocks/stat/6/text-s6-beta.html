베타분포

본문

새 광고의 클릭률은 아직 정확히 모른다. 비슷한 광고들을 보면 2%에서 5% 사이일 것 같다는 정도만 안다. 이렇게 0과 1 사이의 값을 가지는 "확률 자체"의 불확실성은 어떤 분포로 나타낼까? 그 분포는 가운데에 몰리게도, 한쪽 끝에 몰리게도 자유롭게 조절할 수 있어야 한다.

먼저 알아야 할 것감마분포(4.3절)와 베타 함수(응통1 3단원)를 쓴다.

4.4.1정의와 적률

처음 질문처럼 치료 성공률, 클릭률, 타율 같은 비율을 정확히 모를 때가 많다. 값이 0과 1 사이에만 있고, 어디에 몰릴지를 두 모수로 정할 수 있는 분포가 베타분포이다. 베타 함수 \(B(a, b) = \int_0^1 x^{a-1}(1-x)^{b-1}dx\) (\(a, b > 0\))는 감마 함수로 \(B(a, b) = \Gamma(a)\Gamma(b)/\Gamma(a+b)\)이다.

정의 4.4.1 (베타분포)

밀도가 \(f(x) = \dfrac{1}{B(a, b)}x^{a-1}(1-x)^{b-1}\) (\(0 < x < 1\))인 분포를 베타분포 \(\mathrm{Beta}(a, b)\)라 한다.

정리 4.4.2 (베타분포의 적률)

\(X \sim \mathrm{Beta}(a, b)\)이면 \(E(X^k) = B(a+k, b)/B(a, b)\)이다. 특히 \(E(X) = \dfrac{a}{a+b}\), \(\mathrm{Var}(X) = \dfrac{ab}{(a+b)^2(a+b+1)}\)이다.

증명. \(E(X^k) = \frac{1}{B(a,b)}\int_0^1 x^{a+k-1}(1-x)^{b-1}dx = B(a+k, b)/B(a, b)\)이다. 감마 함수로 쓰면 \(\frac{\Gamma(a+k)\Gamma(a+b)}{\Gamma(a)\Gamma(a+b+k)}\)이고, \(\Gamma(\alpha + 1) = \alpha\Gamma(\alpha)\)를 쓰면 \(k = 1\)일 때 \(\frac{a}{a+b}\), \(k = 2\)일 때 \(\frac{a(a+1)}{(a+b)(a+b+1)}\)이다. 분산은 둘째에서 첫째의 제곱을 빼서 정리한다. ∎

베타분포의 적분은 대부분 베타 함수로 끝나므로, 적률생성함수를 거치기보다 이렇게 적률을 직접 구하는 편이 쉽다.

4.4.2모양 읽기

처음 질문이 요구한 자유로운 모양은 두 모수의 크기로 정해진다(그림 1). \(a = b = 1\)이면 균일분포 \(U(0, 1)\)이고, \(a = b > 1\)이면 0.5를 중심으로 대칭인 종 모양이며 \(a = b\)가 클수록 좁아진다. 반대로 \(a, b < 1\)이면 양 끝이 솟은 U자가 된다. 또 \(a > b\)이면 1 쪽으로, \(a < b\)이면 0 쪽으로 몰리며, \(a, b > 1\)일 때 최빈값은 \(\frac{a-1}{a+b-2}\)이다.

한편 \(a + b\)는 분포가 얼마나 좁은지를 정하는 "자료 수"처럼 움직인다. 평균이 0.3으로 같아도 \(\mathrm{Beta}(3, 7)\)의 표준편차는 약 0.14이고 \(\mathrm{Beta}(30, 70)\)은 약 0.046이다. 그래서 베이즈 분석에서는 \(\mathrm{Beta}(a, b)\) 사전분포를 "성공 \(a\)번, 실패 \(b\)번을 미리 본 것과 같은 믿음"으로 읽는다(응통21 1단원).

예제 4.4.1

\(\mathrm{Beta}(2, 2)\)와 \(\mathrm{Beta}(2, 5)\)의 평균, 분산, 최빈값을 구하고 모양을 비교하여라.

풀이. \(\mathrm{Beta}(2, 2)\)는 평균 \(1/2\), 분산 \(4/(16 \times 5) = 0.05\), 최빈값 \(1/2\)이다. 밀도가 \(6x(1-x)\)로 0.5를 중심으로 대칭인 둥근 봉우리이다. 반면 \(\mathrm{Beta}(2, 5)\)는 평균 \(2/7 \approx 0.286\), 분산 \(10/(49 \times 8) \approx 0.0255\), 최빈값 \(1/5 = 0.2\)이다. 0 쪽으로 몰리고 오른쪽 꼬리가 길어서 최빈값이 평균보다 작다.

curve(dbeta(x, 2, 2), 0, 1); curve(dbeta(x, 2, 5), add = TRUE, lty = 2)

4.4.3다른 분포와의 관계

베타분포는 여러 곳에서 저절로 나타난다. 먼저 \(X \sim \mathrm{Gamma}(a, \beta)\)와 \(Y \sim \mathrm{Gamma}(b, \beta)\)가 독립이면 비율 \(X/(X+Y)\)는 \(\mathrm{Beta}(a, b)\)를 따르고 \(X + Y\)와 독립이다. 이는 2.3절 예제에서 지수분포 둘로 본 결과를 일반화한 것이다. 또 \(U(0, 1)\) 표본 \(n\)개의 \(k\)번째로 작은 값은 \(\mathrm{Beta}(k, n-k+1)\)을 따른다(6.4절).

처음 질문에 직접 쓰이는 것은 이항분포와의 관계이다. 비율 \(p\)의 사전분포가 \(\mathrm{Beta}(a, b)\)이고 \(n\)번 가운데 \(x\)번 성공하면, 사후분포는 \(\mathrm{Beta}(a + x, b + n - x)\)로 다시 베타분포가 된다. 즉 자료를 볼 때마다 성공 수를 \(a\)에, 실패 수를 \(b\)에 더하기만 하면 믿음이 갱신된다.

흔한 실수모수 순서를 바꿔 \(\mathrm{Beta}(a, b)\)의 평균을 \(b/(a+b)\)로 쓰기 쉽다. \(x^{a-1}\)에 붙은 \(a\)가 1 쪽의 무게이고, 성공 수 쪽이라고 기억하면 평균이 \(a/(a+b)\)임을 헷갈리지 않는다.
마무리

베타분포 \(\mathrm{Beta}(a, b)\)는 0과 1 사이의 값을 가지며, 평균은 \(a/(a+b)\), 분산은 \(ab/[(a+b)^2(a+b+1)]\)이다. \(a = b = 1\)이면 균일분포이고, 두 모수의 크기에 따라 종, 치우친 봉우리, U자 모양이 되며 \(a + b\)가 클수록 좁아진다. 독립인 감마분포의 비, 균일분포의 순서통계량, 이항 비율의 사후분포가 모두 베타분포이다.

4.4.4연습문제

기본

  1. \(X \sim \mathrm{Beta}(3, 1)\)의 밀도와 \(P(X > 0.5)\)는 무엇인가?
    답

    \(B(3, 1) = \Gamma(3)\Gamma(1)/\Gamma(4) = 2/6 = 1/3\)이므로 \(f(x) = 3x^2\)이다. 따라서 \(P(X > 0.5) = 1 - 0.5^3 = 0.875\)이다.

응용

  1. 평균이 0.2이고 표준편차가 0.1인 베타분포의 모수를 구하여라.
    답

    평균 \(m = a/(a+b) = 0.2\)이고 분산은 \(m(1-m)/(a+b+1) = 0.01\)이다. 따라서 \(a + b + 1 = 0.16/0.01 = 16\), \(a + b = 15\)이므로 \(a = 3\), \(b = 12\)이다.
