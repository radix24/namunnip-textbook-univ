적률생성함수

본문

\(E(X)\), \(E(X^2)\), \(E(X^3)\)을 하나씩 적분하는 일은 번거롭다. 게다가 독립인 두 정규변수를 더한 값의 분포를 구하려면 2.3절처럼 야코비안을 쓰고 적분해야 한다. 모든 적률을 한 함수에 담고, 독립인 변수의 합도 쉽게 다루는 방법이 있을까?

먼저 알아야 할 것기대값(3.1절)과 지수함수의 테일러 전개(응통1 2단원)를 쓴다.

3.2.1정의와 적률

정의 3.2.1 (적률생성함수)

\(M_X(t) = E(e^{tX})\)가 0을 포함하는 어떤 열린 구간 \(|t| < h\)에서 유한하면, 이를 \(X\)의 적률생성함수라 한다.

\(e^{tX} = 1 + tX + \frac{t^2X^2}{2!} + \cdots\)의 기대값을 항별로 구하면 \(M(t) = \sum_k E(X^k)\frac{t^k}{k!}\)이다. 그러므로 \(t = 0\)에서 \(k\)번 미분하면 \(k\)차 적률이 나온다.

\[M^{(k)}(0) = E(X^k)\]

처음 질문의 첫째 부분에 대한 답이 이 식이다. 그림 1에서 보듯 \(M(0) = 1\)은 어느 분포에서나 같고, 0에서의 기울기와 휨이 평균과 이차 적률을 정한다. 적분은 \(M\)을 구할 때 한 번만 하면 되고, 나머지는 미분이다.

3.2.2유일성과 독립인 합

정리 3.2.2 (적률생성함수의 성질)

(가) 두 확률변수의 적률생성함수가 0 근처의 열린 구간에서 같으면 두 분포는 같다. (나) \(X\)와 \(Y\)가 독립이면 \(M_{X+Y}(t) = M_X(t)M_Y(t)\)이다.

(가)의 증명은 라플라스 변환의 유일성에 기대므로 이 과목의 범위를 넘는다. 한편 (나)는 \(E(e^{t(X+Y)}) = E(e^{tX}e^{tY}) = E(e^{tX})E(e^{tY})\)에서 나오는데, 독립이면 곱의 기대값이 기대값의 곱이기 때문이다(5.2절). 두 성질을 합치면 처음 질문의 둘째 부분이 풀린다. 합의 적률생성함수를 곱으로 구한 뒤, 그것이 이미 아는 분포의 것과 같으면 합이 그 분포를 따른다.

예제 3.2.1

\(X \sim N(\mu, \sigma^2)\)의 적률생성함수를 구하고, 독립인 \(X_1 \sim N(\mu_1, \sigma_1^2)\), \(X_2 \sim N(\mu_2, \sigma_2^2)\)의 합의 분포를 구하여라.

풀이. 먼저 표준정규 \(Z\)에서 \(E(e^{tZ}) = \int \frac1{\sqrt{2\pi}}e^{tz - z^2/2}dz\)이다. 지수를 완전제곱하면 \(tz - z^2/2 = -\frac12(z - t)^2 + \frac{t^2}2\)이고, 남은 적분은 \(N(t, 1)\) 밀도의 적분이라 1이므로 \(M_Z(t) = e^{t^2/2}\)이다. 따라서 \(X = \mu + \sigma Z\)이면 \(M_X(t) = e^{\mu t}M_Z(\sigma t) = e^{\mu t + \sigma^2t^2/2}\)이다.

합의 적률생성함수는 \(e^{\mu_1 t + \sigma_1^2t^2/2}e^{\mu_2 t + \sigma_2^2t^2/2} = e^{(\mu_1 + \mu_2)t + (\sigma_1^2 + \sigma_2^2)t^2/2}\)이고, 이는 \(N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)\)의 것과 같다. 그러므로 유일성에서 \(X_1 + X_2 \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)\)이다. 평균도 분산도 더해지며, 표준편차가 더해지는 것은 아니다.

예제 3.2.2

포아송 분포 \(p(x) = e^{-\lambda}\lambda^x/x!\)의 적률생성함수와 평균, 분산을 구하여라.

풀이. \(M(t) = \sum_x e^{-\lambda}\frac{(\lambda e^t)^x}{x!} = e^{\lambda(e^t - 1)}\)이다. 미분하면 \(M'(t) = \lambda e^tM(t)\)이라 \(M'(0) = \lambda\)이고, \(M''(t) = (\lambda e^t + \lambda^2e^{2t})M(t)\)이라 \(M''(0) = \lambda + \lambda^2\)이다. 그러므로 평균과 분산이 모두 \(\lambda\)이다.

주의모든 분포에 적률생성함수가 있는 것은 아니다. 로그정규분포는 모든 적률이 유한하지만 \(t > 0\)에서 \(E(e^{tX})\)가 발산하고, 코시 분포는 적률부터 없다. 이런 경우에는 늘 존재하는 특성함수 \(E(e^{itX})\)를 쓰며, 7단원의 중심극한정리를 일반적으로 증명할 때도 특성함수가 쓰인다.
마무리

적률생성함수 \(M(t) = E(e^{tX})\)는 0 근처의 모양에 모든 적률을 담으며, \(M^{(k)}(0) = E(X^k)\)로 적분 대신 미분해서 적률을 얻는다. 0 근처에서 적률생성함수가 같으면 분포가 같고, 독립인 변수의 합의 적률생성함수는 곱이다. 두 성질을 함께 써서 정규분포나 포아송 분포의 합이 다시 같은 꼴의 분포임을 보인다.

3.2.3연습문제

기본

  1. 모수가 \(\lambda_1\), \(\lambda_2\)인 독립인 포아송 변수의 합의 분포는 무엇인가?
    답

    적률생성함수가 \(e^{\lambda_1(e^t-1)}e^{\lambda_2(e^t-1)} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}\)이므로 모수 \(\lambda_1 + \lambda_2\)인 포아송 분포이다.

응용

  1. 지수분포 \(\mathrm{Exp}(\lambda)\)의 적률생성함수를 구하고, 정의되는 \(t\)의 범위를 써라.
    답

    \(\int_0^\infty \lambda e^{-(\lambda - t)x}dx = \frac{\lambda}{\lambda - t}\)이고, 적분이 수렴하는 범위는 \(t < \lambda\)이다.
