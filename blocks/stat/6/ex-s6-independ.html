병렬 시스템의 신뢰도와 독립 가정

예제 · 독립 시행

먼저 읽는 법

"모두 작동"은 교집합이라 독립이면 곱, "적어도 하나 작동"은 합집합이라 여사건의 곱으로 계산합니다. 계산이 끝나면 독립 가정이 현실에서 맞는지를 반드시 따집니다.

문제 1. 서버 한 대가 하루 동안 고장 없이 버틸 확률이 0.95입니다. 같은 서버 세 대를 병렬로 두어 하나라도 살아 있으면 서비스가 유지됩니다. 서버 고장이 서로 독립일 때 서비스가 유지될 확률은?

풀이

  1. \(A_i\) = 서버 \(i\)가 버팀. 서비스 유지 = \(A_1 \cup A_2 \cup A_3\).
    병렬 구조는 합집합입니다.
  2. 여사건 = 셋 다 고장 = \(A_1^c \cap A_2^c \cap A_3^c\). 독립이면 확률 \(0.05^3 = 0.000125\).
    독립인 사건의 여사건들도 독립입니다(1.4.1절).
  3. 유지 확률 \(1 - 0.000125 = 0.999875\).
    하루 중단 확률이 5%에서 0.0125%로 줄었습니다.

문제 2. 실제로는 서버 세 대가 같은 전원을 씁니다. 전원이 나갈 확률은 하루 0.01이고, 전원이 나가면 셋 다 멈춥니다. 전원이 정상일 때 각 서버는 확률 0.96으로 독립으로 버팁니다. 서비스 유지 확률을 다시 구하세요.

풀이

  1. \(E\) = 전원 정상, \(P(E) = 0.99\). 전확률 공식(1.3절)으로 나눕니다.
    서버들은 \(E\)가 주어졌을 때 조건부 독립입니다.
  2. \(P(\text{유지} \mid E) = 1 - 0.04^3 = 0.999936\), \(P(\text{유지} \mid E^c) = 0\).
    전원이 나가면 모든 서버가 멈춥니다.
  3. \(P(\text{유지}) = 0.99 \times 0.999936 \approx 0.98994\).
    중단 확률이 약 1%로, 문제 1의 0.0125%보다 80배 큽니다.

검산

문제 2에서 서버 하나가 버틸 확률은 \(0.99 \times 0.96 = 0.9504\)로 문제 1의 0.95와 거의 같습니다. 개별 신뢰도는 같은데 공통 원인(전원) 때문에 서버 고장이 종속이 되어 병렬의 이득이 대부분 사라졌습니다. 실제로 두 서버가 함께 고장 날 확률은 \(0.01 + 0.99 \times 0.04^2 \approx 0.0116\)으로, 독립일 때의 \(0.0496^2 \approx 0.0025\)의 약 4.7배입니다.

의미

여분을 두는 설계는 고장이 독립일 때만 효과가 큽니다. 같은 전원, 같은 소프트웨어 버그, 같은 건물처럼 공통 원인이 있으면 독립 가정의 계산은 위험을 크게 과소평가합니다. 2008년 금융 위기 때 주택담보 대출의 부도를 독립으로 본 모형이 크게 틀린 것도 같은 구조입니다.
