보고서의 숫자가 어디서 나왔는지 석 달 뒤 스스로도 찾지 못하는 일이 흔합니다. 같은 자료와 코드로 같은 결과가 다시 나오게 정리하는 것을 재현 가능성이라 합니다.

5.2.1점검 목록

  1. 원자료는 손대지 않고 보관하고, 정리는 코드로 합니다(엑셀에서 손으로 고치지 않기).
  2. 스크립트 하나(또는 순서가 정해진 몇 개)로 원자료에서 최종 표와 그림까지 갑니다.
  3. 난수를 쓰면 set.seed를 적습니다.
  4. 쓴 R 버전과 패키지 버전을 기록합니다(sessionInfo()).
  5. 보고서의 숫자를 손으로 옮기지 않고 코드가 직접 문서에 넣게 합니다(R Markdown, Quarto).
  6. 버전 관리(git)로 바뀐 내용을 기록합니다.

```{r}
library(MASS); m <- tapply(birthwt$bwt, birthwt$smoke, mean); m
```

문서를 다시 만들면(knit) 코드가 실행되어 숫자와 그림이 자동으로 갱신됩니다. 자료가 바뀌어도 보고서를 다시 만들기만 하면 됩니다.

요약
  1. 원자료 보존, 정리는 코드로, 난수 씨앗과 버전 기록.
  2. 코드와 글을 한 문서에 넣어 숫자를 자동으로.
  3. 버전 관리로 변경 이력을 남깁니다.
