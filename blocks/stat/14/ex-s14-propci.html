불량률 5%인 공정에서 Wald 구간이 실패하는 경로

예제 · 정확한 포함 확률

먼저 읽는 법

참 비율 \(p\)를 고정하고 나올 수 있는 모든 \(x\)를 하나씩 따라가 구간이 \(p\)를 포함하는지 본다. 포함하지 못하는 \(x\)들의 확률을 더하면 실패 확률이다.

문제. 참 불량률 \(p = 0.05\)인 공정에서 20개를 검사한다. Wald 95% 구간이 \(p\)를 놓치는 \(x\) 값을 찾고 포함 확률을 구하여라.

풀이

  1. \(x = 0\): 구간 [0, 0], 0.05를 놓침. \(P(X = 0) = 0.95^{20} = 0.358\).
    표준오차가 0.
  2. \(x = 1\): \(0.05 \pm 1.96\sqrt{0.0475/20} = 0.05 \pm 0.096\), 포함. \(x = 2, 3\)도 포함(예: \(x = 3\)은 [−0.006, 0.306]).
    \(x = 1\)~3의 확률 0.377 + 0.189 + 0.060.
  3. \(x \ge 4\)의 구간 하한은 0.05보다 큽니다(\(x = 4\): [0.025, 0.375]는 포함, \(x = 5\): [0.060, 0.440]은 놓침). 놓치는 경우는 \(x = 0\)과 \(x \ge 5\)로, 포함 확률 \(\approx 0.64\).
    2.3.2절 표와 같음.

검산

\(P(X = 0) + P(X \ge 5) = 0.358 + 0.003 = 0.361\), 포함 확률 \(1 - 0.361 = 0.639\). Wilson 구간은 \(x = 0\)일 때 [0, 0.161]로 0.05를 포함하므로 이 큰 실패가 사라진다.

의미

Wald 구간의 실패는 대부분 "불량이 하나도 없었다"는 흔한 결과에서 나온다. 품질 관리처럼 비율이 작은 문제에서 [0, 0]이라는 구간은 "불량률이 정확히 0"이라는 잘못된 확신을 준다. 작은 비율에는 Wilson이나 정확 구간을 기본으로 쓴다.
