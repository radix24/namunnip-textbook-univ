소득을 숨기는 응답자: 완전 사례 분석의 편향

예제 · 결측 유형과 민감도 분석

먼저 읽는 법

결측 여부가 소득 자체에 달린(MNAR) 상황을 단순한 표로 만들어, 완전 사례 평균이 얼마나 치우치는지 계산한다. 그다음 "무응답자가 응답자보다 얼마나 다른가"를 바꿔 가며 결론이 얼마나 흔들리는지 본다.

문제. 가구 절반은 월소득 300만 원, 절반은 700만 원이다. 300만 원 가구는 90%, 700만 원 가구는 50%가 소득을 응답한다. (1) 참 평균과 완전 사례 평균 (2) 응답한 1400가구(2000가구 중)를 기준으로, 무응답 가구 평균이 응답 가구 평균보다 0, 100, 200만 원 높다고 가정할 때의 전체 평균 추정을 구하여라.

풀이

  1. 참 평균 500. 응답 비율 300만: 0.45, 700만: 0.25. 완전 사례 평균 \((0.45 \times 300 + 0.25 \times 700)/0.70 = 443\).
    편향 −57만 원.
  2. 응답률 \(r = 0.7\). 무응답 평균 = 443 + \(\delta\)이면 전체 \(= 443 + 0.3\delta\).
    1.3절의 무응답 편향 식.
  3. \(\delta = 0, 100, 200\)에서 443, 473, 503만 원.
    민감도 분석.

검산

실제 무응답 가구: 300만 원 가구 0.05, 700만 원 가구 0.25(비율 합 0.30), 평균 \((0.05 \times 300 + 0.25 \times 700)/0.3 = 633\). \(\delta = 633 - 443 = 190\)일 때 전체 \(443 + 57 = 500\)으로 참값과 같다.

의미

MNAR에서는 자료만으로 \(\delta\)를 알 수 없으므로 하나의 답 대신 "무응답 가구가 응답 가구보다 0~200만 원 높다면 평균은 443~503만 원"처럼 범위로 보고한다. 행정 자료나 외부 통계로 \(\delta\)의 그럴듯한 범위를 좁히는 것이 실무적인 해결책이고, 다중 대치는 MAR 가정 아래에서만 이 편향을 없애 준다.
