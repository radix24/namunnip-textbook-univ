정규근사가 통하지 않을 때

본문
이 절에서 배울 것
  • 치우친 분포와 작은 표본에서 t 구간의 실제 포함 확률이 떨어짐을 확인한다.
  • 모의실험으로 근사가 쓸 만한지 점검하는 방법을 익힌다.
  • 근사가 나쁠 때의 대안을 고른다.
먼저 알아야 할 것
  • 모의실험의 기본 틀 (1.2절), 중심극한정리 (응통6 7.3절).

"30개면 충분하다"는 말

중심극한정리는 표본이 커질수록 표본평균이 정규분포에 가까워진다고 말할 뿐, 몇 개면 충분한지는 모집단 분포의 모양에 달려 있습니다. 대칭에 가까우면 10개로도 충분하지만, 소득·보험금·입원비처럼 오른쪽 꼬리가 긴 분포는 수백 개가 필요할 수 있습니다.

1.4.1포함 확률 모의실험

참 평균을 아는 분포에서 표본을 되풀이해 뽑고, 매번 95% t 구간이 참 평균을 포함하는지 셉니다. 포함 비율이 0.95에 가까우면 근사가 쓸 만합니다.

set.seed(1); B <- 10000; n <- 10; mu <- 1
cover <- replicate(B, {
  x <- rexp(n, 1); ci <- t.test(x)$conf.int
  ci[1] <= mu && mu <= ci[2] })
mean(cover)
모집단\(n\)95% t 구간의 실제 포함 확률(모의실험)
지수분포5, 10, 300.88, 0.90, 0.93
로그정규(\(\sigma = 1.5\))10, 30, 1000.72, 0.79, 0.85

지수분포는 30개에서도 2%p 모자라고, 꼬리가 훨씬 긴 로그정규분포는 100개에서도 85%에 그칩니다. 실패는 대부분 한쪽에서 일어납니다. 표본에 큰 값이 드물게 들어오므로 표본평균이 참 평균보다 작게 나오는 경우가 많고, 그때 표준편차도 작게 나와 구간이 짧아집니다.

1.4.2대처

  • 질문 바꾸기: 평균보다 중앙값이 관심이면 분포 무관 구간(응통12 2.2절)을 씁니다.
  • 로그 척도: 로그정규에 가까우면 로그 값의 t 구간을 되돌려 기하평균(중앙값)의 구간을 얻습니다. 평균이 꼭 필요하면 \(e^{\sigma^2/2}\) 보정을 함께 고려합니다(응통10 5.1절).
  • 붓스트랩: 백분위 구간이나 BCa 구간(4.3절)이 치우침을 일부 반영합니다. 다만 작은 표본에서는 붓스트랩도 꼬리를 보지 못합니다.
  • 점검을 습관으로: 표본 크기와 비슷한 분포(표본의 히스토그램을 닮은 분포)로 위 모의실험을 돌려 포함 확률을 확인합니다.
예제 1.4.1

지수분포 자료 \(n = 10\)으로 만든 95% t 구간을 "95% 구간"이라고 보고해도 되나요?

풀이. 모의실험의 실제 포함 확률이 약 0.90으로, 열에 한 번 꼴로 참 평균을 놓칩니다. "근사적 95% 구간이며 치우친 분포라 실제 신뢰수준은 이보다 낮을 수 있다"고 밝히거나, 지수분포라는 근거가 있으면 정확한 구간(\(2n\bar X/\mu \sim \chi^2_{2n}\))을 씁니다.

요약
  1. 정규근사에 필요한 표본 크기는 분포의 치우침과 꼬리에 달려 있습니다.
  2. 모의실험으로 포함 확률을 직접 확인합니다.
  3. 중앙값으로 질문을 바꾸거나, 로그 척도, 붓스트랩, 정확한 방법을 씁니다.

1.4.3연습문제

기본

  1. 포함 확률 모의실험을 \(B = 10000\)번 했을 때, 참 포함 확률이 0.95라면 결과의 표준오차는?
    답

    \(\sqrt{0.95 \times 0.05/10000} = 0.0022\). 0.93과 0.95의 차이는 모의실험 오차보다 훨씬 큽니다.

응용

  1. 정규분포에서 \(n = 5\)일 때 95% t 구간의 포함 확률은 얼마일까요? z 임계값 1.96을 쓰면?
    답

    t 구간은 정규 모집단에서 정확하므로 0.95. z 임계값을 쓰면 \(P(|t_4| \le 1.96) \approx 0.88\)로 모자랍니다. 작은 표본의 문제는 치우침뿐 아니라 \(\sigma\)를 추정하는 데서도 옵니다.
