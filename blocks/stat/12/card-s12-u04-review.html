순위에 기초한 검정 단원 마무리 연습

문제 7 · 계산·개념·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산짝지은 차이 2.1, −0.5, 1.4, 3.0, 0.9, −1.2, 2.6에 대해 윌콕슨 부호순위 통계량 \(W^+\)와 \(W^-\)를 구하세요. R의 정확 양측 p값은 0.109입니다. 해석하세요. [04-01]

    힌트 1

    절댓값 순위: 0.5(1), 0.9(2), 1.2(3), 1.4(4), 2.1(5), 2.6(6), 3.0(7).

    힌트 2

    \(W^+ + W^- = n(n+1)/2 = 28\)입니다.

    풀이

    양수 차이의 순위는 5, 4, 7, 2, 6이므로 \(W^+ = 24\), \(W^- = 1 + 3 = 4\)입니다. 귀무가설 아래 평균은 14인데 24로 크게 치우쳐 있지만, 표본이 7개뿐이라 양측 p값이 0.109로 5%에서 유의하지 않습니다. 같은 자료에서 부호검정은 양수 5개/7개로 p ≈ 0.45로, 크기 정보를 쓰는 부호순위 검정이 더 민감합니다.

  2. 계산A = (12, 15, 9, 20), B = (22, 18, 25, 30, 16)에서 맨-휘트니 \(U\)(A의 값이 B의 값보다 큰 쌍의 수)를 세고, 순위합 \(W_A\)와의 관계를 확인하세요. [04-02]

    힌트 1

    전체 쌍은 \(4\times5 = 20\)개입니다. A의 각 값이 B의 몇 개보다 큰지 세세요.

    힌트 2

    \(U_A = W_A - m(m+1)/2\)입니다.

    풀이

    A의 12, 15, 9는 B의 어느 값보다도 크지 않고, 20은 18, 16보다 커서 \(U_A = 2\)입니다. 합친 순위에서 A는 1, 2, 3, 6위이므로 \(W_A = 12\), \(12 - 4\times5/2 = 2\)로 같습니다.

    R의 wilcox.test는 W = 2, 정확 양측 p = 0.063을 줍니다. \(U/(mn) = 0.1\)은 "A에서 하나, B에서 하나를 뽑을 때 A가 더 클 확률"의 추정값으로, 효과 크기로 쓸 수 있습니다.

  3. 계산세 집단 A: 1, 3, 5 / B: 2, 6, 8 / C: 7, 9, 10의 크러스컬-월리스 통계량 \(H = \frac{12}{N(N+1)}\sum\frac{R_j^2}{n_j} - 3(N+1)\)을 구하세요. [04-04]

    힌트 1

    아홉 값을 합쳐 순위를 매기면 1, 2, 3, 5, 6, 7, 8, 9, 10이 차례로 1~9위입니다.

    힌트 2

    순위 합은 A 8, B 14, C 23입니다.

    풀이

    \(H = \frac{12}{90}\cdot\frac{64 + 196 + 529}{3} - 30 = \frac{12}{90}\times263 - 30 \approx 5.07\)입니다. 자유도 2인 카이제곱 근사로 p ≈ 0.079입니다(표본이 작아 정확 분포를 쓰는 것이 더 좋습니다). 일원 분산분석의 순위판입니다.

  4. 계산평가자 4명(블록)이 세 제품을 순위 매겼습니다. 순위가 (1, 2, 3), (1, 3, 2), (1, 2, 3), (2, 1, 3)일 때 프리드먼 통계량 \(Q = \frac{12}{bk(k+1)}\sum R_j^2 - 3b(k+1)\)을 구하세요. [04-05]

    힌트 1

    제품별 순위 합은 5, 8, 11입니다.

    힌트 2

    \(b = 4\), \(k = 3\)입니다.

    풀이

    \(Q = \frac{12}{48}(25 + 64 + 121) - 48 = 52.5 - 48 = 4.5\), 자유도 2, p ≈ 0.105입니다. 평가자마다 점수 기준이 달라도 각자 안에서의 순위만 쓰므로 평가자 차이가 제거됩니다(랜덤화 블록 설계의 순위판).

  5. 개념같은 학생 20명이 세 종류의 문제(A, B, C)를 풀어 각각 맞음/틀림으로 기록했습니다. 세 문제의 정답률이 같은지 검정하는 방법과 그 까닭을 쓰세요. [04-06]

    힌트 1

    반응이 이진이고 같은 학생이 세 조건을 모두 겪었습니다.

    힌트 2

    맥니마 검정을 세 조건 이상으로 넓힌 검정이 있습니다.

    풀이

    코크란 Q 검정을 씁니다. 반응이 이진(0/1)이고 같은 학생이 블록이 되는 반복 측정 자료이므로, 독립 표본을 가정하는 카이제곱 검정은 알맞지 않습니다. 코크란 Q는 학생마다 정답 수가 다른 것(실력 차이)을 조건으로 두고, 세 문제의 정답 수가 고르게 퍼져 있는지 봅니다. 조건이 둘이면 맥니마 검정과 같습니다.

  6. 판단두 집단의 분포가 모양이 다르면(한쪽은 퍼짐이 크고 대칭, 다른 쪽은 좁고 치우침), 맨-휘트니 검정이 유의할 때 "중앙값이 다르다"고 결론지을 수 있나요? [04-02]

    힌트 1

    맨-휘트니 검정의 귀무가설은 엄밀히 무엇에 관한 것인가요?

    힌트 2

    \(P(X > Y) = 1/2\)인지를 검정한다고 볼 수 있습니다.

    풀이

    그대로는 결론지을 수 없습니다. 맨-휘트니 검정은 \(P(X > Y) \ne 1/2\)(한 집단이 확률적으로 더 크게 나오는 경향)을 검출하며, 두 분포가 위치만 다르다는 가정이 있어야 중앙값(위치) 차이로 해석됩니다. 모양이 다르면 중앙값이 같아도 유의하게 나올 수 있고 그 반대도 가능합니다. 이런 경우 "\(P(X > Y)\)의 추정값"으로 결과를 보고하거나, 중앙값 차이에 대한 붓스트랩 구간을 따로 구합니다.

  7. 계산(1) 짝지은 차이 1, 3, 4의 왈시 평균을 모두 쓰고 호지스-레만 추정값을 구하세요. (2) \(X\): 2, 5와 \(Y\): 4, 8, 9에서 위치 이동 \(\Delta\)의 호지스-레만 추정값을 구하세요. [04-03]

    힌트 1

    왈시 평균은 \(i \le j\)인 모든 쌍의 \((d_i + d_j)/2\)로, 자기 자신도 포함합니다.

    힌트 2

    두 표본에서는 \(mn\)개의 쌍별 차이 \(Y_j - X_i\)의 중앙값입니다.

    풀이

    (1) 1, 2, 2.5, 3, 3.5, 4의 여섯 개, 중앙값 \((2.5 + 3)/2 = 2.75\). 평균 2.67, 중앙값 3과 비교됩니다.

    (2) 차이 2, 6, 7, −1, 3, 4 → 정렬 −1, 2, 3, 4, 6, 7, 중앙값 3.5. 평균 차이 \(7 - 3.5 = 3.5\)와 이 경우 같습니다.
