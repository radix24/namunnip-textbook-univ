코크란 Q 검정의 쓰임

본문

학생 20명이 문제 세 개를 풀어 각각 맞음과 틀림으로 기록했다. 세 문제의 난이도가 같은지 알고 싶은데, 같은 학생이 세 문제를 모두 풀었으므로 독립 비율 비교는 쓸 수 없다. 대응 이진 자료를 셋 이상 비교하려면 어떻게 해야 할까?

먼저 알아야 할 것맥니마 검정(2.3절)과 프리드먼 검정(4.5절)을 쓴다.

처음 질문의 답이 코크란 Q 검정이다. 같은 대상이 여러 조건에서 성공이나 실패로 기록되었을 때 쓰며, 이진 자료에 대한 프리드먼 검정이라고 볼 수 있다(그림 1). 또 조건이 둘이면 맥니마 검정과 같다.

4.6.1검정

\(b\)명의 대상(블록)이 \(k\)개 처리를 받아 이진 결과 \(x_{ij}\)를 얻었다고 하자. 처리별 성공 합을 \(C_j\), 대상별 성공 합을 \(R_i\), 전체 합을 \(T = \sum C_j\)라 한다.

정리 4.6.1 (코크란 Q 통계량)

처리 사이 성공 확률이 같다는 귀무가설 아래 다음 통계량은 근사적으로 \(\chi^2_{k-1}\)을 따른다.

\[ Q = \frac{(k-1)\left[k \sum_j C_j^2 - T^2\right]}{kT - \sum_i R_i^2} \]

모두 맞혔거나 모두 틀린 대상, 곧 \(R_i = 0\)이나 \(R_i = k\)인 대상은 처리 사이 차이에 정보를 주지 않는다. 실제로 그런 대상을 빼도 분모 \(kT - \sum R_i^2\)와 분자가 변하지 않는다. 맥니마 검정에서 일치 쌍을 버린 것과 같은 이치이다.

예제 4.6.1

\(k = 3\), 학생 20명에서 문제별 정답 수가 \(C = (15, 10, 5)\)이다. 학생 가운데 셋 다 맞힌 사람, 두 문제, 한 문제를 맞힌 사람, 모두 틀린 사람이 각각 5명이다. \(Q\)를 구하라.

풀이. \(T = 30\)이고 \(\sum R_i^2 = 5(9 + 4 + 1 + 0) = 70\)이다. 그러므로 \(Q = \tfrac{2[3(225 + 100 + 25) - 900]}{90 - 70} = \tfrac{2 \times 150}{20} = 15\)이다. 자유도 2에서 p값은 \(e^{-7.5} \approx 0.0006\)이므로 세 문제의 정답률이 다르다. 다만 그림 1처럼 실제로 정보를 준 학생은 10명뿐이다.

4.6.2사후 비교

그러면 어느 문제 쌍이 다른가? 기각되면 쌍마다 맥니마 검정을 하고, 비교 횟수만큼 본페로니나 홀 방법으로 유의수준을 보정한다. 한편 대상 수가 작거나 정보를 주는 대상이 적으면 카이제곱 근사가 나빠지므로, 순열 분포(6.1절)로 p값을 구한다.

마무리

같은 대상이 여러 조건에서 이진 결과를 낸 자료에는 코크란 Q 검정을 쓴다. 이진 자료의 프리드먼 검정이며, \(k = 2\)이면 맥니마 검정과 같다. 모두 같은 결과인 대상은 정보가 없고, 기각 뒤에는 보정한 쌍별 맥니마 검정으로 비교한다.

4.6.3연습문제

기본

  1. 세 광고 시안을 같은 50명에게 보여 주고 구매 의향이 있는지 물었다. 어떤 검정을 쓰는가?
    답

    코크란 Q 검정을 쓴다. 기각되면 쌍마다 맥니마 검정을 하고 본페로니로 보정해 비교한다.

응용

  1. \(k = 2\)일 때 코크란 Q가 맥니마 통계량 \((b - c)^2/(b + c)\)와 같음을 보여라. 여기서 \(b, c\)는 불일치 쌍의 수이다.
    답

    일치 쌍을 빼도 \(Q\)는 변하지 않으므로 불일치 쌍만 남기면 \(C_1 = b\), \(C_2 = c\), \(T = b + c\), 모든 \(R_i = 1\)이라 \(\sum R_i^2 = b + c\)이다. 그러므로 \(Q = \tfrac{2(b^2 + c^2) - (b + c)^2}{2(b + c) - (b + c)} = \tfrac{(b - c)^2}{b + c}\)이다.
