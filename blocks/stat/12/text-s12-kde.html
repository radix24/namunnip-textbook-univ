분포의 모양을 매끄럽게

지금까지의 비모수 방법은 검정과 위치 추정이었습니다. 분포의 모양 자체, 곧 밀도함수를 분포족을 가정하지 않고 추정할 수도 있습니다. 히스토그램이 가장 단순한 밀도추정이지만, 막대의 시작점과 폭에 따라 모양이 달라지고 계단 모양이라 매끄럽지 않습니다.

6.3.1커널 밀도추정량

정의 6.3.1

커널 \(K\)(합이 1인 대칭 밀도, 흔히 표준정규 밀도 \(\phi\))와 띠너비 \(h > 0\)에 대해 \(\hat f_h(x) = \dfrac1{nh}\sum_{i=1}^n K\left(\dfrac{x - x_i}{h}\right)\).

관측값마다 넓이 \(1/n\)인 작은 종 모양 언덕을 놓고 모두 더한 것입니다. 각 언덕의 넓이가 \(1/n\)이라 전체 넓이는 1이고, 커널이 매끄러우면 추정도 매끄럽습니다. 히스토그램과 달리 시작점에 의존하지 않습니다.

예제 6.3.2

자료 1, 2, 2.5, 4, 7에서 정규 커널, \(h = 1\)로 \(\hat f(2)\)와 \(\hat f(5.5)\)를 구하세요.

풀이. \(\hat f(2) = \frac15[\phi(1) + \phi(0) + \phi(-0.5) + \phi(-2) + \phi(-5)] = \frac15(0.242 + 0.399 + 0.352 + 0.054 + 0.000) = 0.209\). \(\hat f(5.5) = \frac15[\phi(4.5) + \phi(3.5) + \phi(3) + \phi(1.5) + \phi(-1.5)] = \frac15(0.000 + 0.001 + 0.004 + 0.130 + 0.130) = 0.053\). 관측이 몰린 2 근처가 4배 높습니다.

6.3.2띠너비의 선택

\(h\)가 작으면 관측 하나하나에 뾰족한 봉우리가 생겨 울퉁불퉁하고(분산 큼), 크면 모든 것이 하나의 넓은 언덕으로 뭉개져 실제 봉우리를 놓칩니다(치우침 큼). 점마다 치우침은 대략 \(\frac{h^2}{2}f''(x)\), 분산은 대략 \(\frac{f(x)}{nh}\int K^2\)이라, 둘의 합(평균제곱오차)을 최소로 하는 \(h\)는 \(n^{-1/5}\)에 비례합니다. 표본이 32배가 되어야 띠너비가 절반이 됩니다.

  • 실버먼 규칙: \(h = 0.9\min(s, \mathrm{IQR}/1.34)\,n^{-1/5}\). 참 분포가 정규에 가까울 때 좋고, 봉우리가 여럿이면 지나치게 매끄럽게 합니다. R density(x)의 기본값입니다.
  • 자료 기반 선택: 시더-존스 방법(density(x, bw = "SJ"))이나 교차검증으로 고르면 봉우리가 여럿인 분포에 더 잘 맞습니다.
  • 경계: 소득처럼 0 아래가 없는 자료는 커널이 0 아래로 넘쳐 경계 근처 밀도를 낮게 추정합니다. 로그 변환 뒤 추정하는 방법을 씁니다.
요약
  1. \(\hat f_h(x) = \frac1{nh}\sum K((x - x_i)/h)\): 관측마다 언덕을 놓아 더함.
  2. 작은 \(h\)는 울퉁불퉁(분산), 큰 \(h\)는 뭉개짐(치우침), 최적 \(h \propto n^{-1/5}\).
  3. 실버먼 규칙이 기본, 봉우리가 여럿이면 SJ나 교차검증.

6.3.3연습문제

기본

  1. \(\int\hat f_h(x)\,dx = 1\)임을 보이세요.
    답

    각 항에서 \(u = (x - x_i)/h\)로 치환하면 \(\frac1h\int K((x - x_i)/h)dx = \int K(u)du = 1\). \(n\)개를 더해 \(n\)으로 나누면 1.

응용

  1. 예제 6.3.2에서 \(h\)를 0.2로 줄이면 \(\hat f(5.5)\)와 \(\hat f(4)\)는 어떻게 되나요? 그림은 어떤 모양일까요?
    답

    5.5는 가장 가까운 관측(4, 7)에서 띠너비의 7.5배 떨어져 \(\hat f(5.5) \approx 0\). \(\hat f(4) = \frac1{5 \times 0.2}\phi(0) \approx 0.40\)(다른 관측의 기여는 거의 0). 관측마다 높이 0.4 정도의 뾰족한 봉우리 다섯 개가 따로 서 있는 모양으로, 과소평활입니다.
