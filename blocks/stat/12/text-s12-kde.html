커널 밀도추정

본문

자료의 분포 모양을 보려고 히스토그램을 그렸더니, 막대의 시작점을 조금 옮기기만 해도 봉우리가 생겼다 사라졌다 한다. 게다가 계단 모양이라 매끄럽지도 않다. 분포족을 가정하지 않고 매끄러운 밀도함수를 추정할 수는 없을까?

먼저 알아야 할 것경험적 분포함수(5.1절)와 정규분포의 밀도(응통6)를 쓴다.

지금까지의 비모수 방법은 검정과 위치 추정이었다. 처음 질문의 답은 관측값마다 작은 종 모양 언덕을 놓고 모두 더하는 것이다(그림 1). 이것이 커널 밀도추정이며, 히스토그램과 달리 시작점에 의존하지 않고 매끄럽다.

6.3.1커널 밀도추정량

정의 6.3.1 (커널 밀도추정량)

넓이가 1인 대칭 밀도 \(K\)(커널, 흔히 표준정규 밀도 \(\phi\))와 띠너비 \(h > 0\)에 대해 다음을 커널 밀도추정량이라 한다.

\[ \hat f_h(x) = \frac{1}{nh} \sum_{i=1}^{n} K\!\left(\frac{x - x_i}{h}\right) \]

각 항 \(K((x - x_i)/h)/(nh)\)는 \(x_i\)를 중심으로 하고 넓이가 \(1/n\)인 언덕이다. 그러므로 전체 넓이는 1이고, 커널이 매끄러우면 추정도 매끄럽다.

예제 6.3.1

자료 1, 2, 2.5, 4, 7에서 정규 커널과 \(h = 1\)로 \(\hat f(2)\)와 \(\hat f(5.5)\)를 구하라.

풀이. \(\hat f(2) = \tfrac15[\phi(1) + \phi(0) + \phi(-0.5) + \phi(-2) + \phi(-5)] = \tfrac15(0.242 + 0.399 + 0.352 + 0.054 + 0.000) = 0.209\)이다. 또 \(\hat f(5.5) = \tfrac15[\phi(4.5) + \phi(3.5) + \phi(3) + \phi(1.5) + \phi(-1.5)] = \tfrac15(0.000 + 0.001 + 0.004 + 0.130 + 0.130) = 0.053\)이다. 즉 관측이 몰린 2 근처가 4배 높다(그림 1).

6.3.2띠너비의 선택

\(h\)가 작으면 관측 하나하나에 뾰족한 봉우리가 생겨 울퉁불퉁해진다. 이것은 분산이 큰 상태이다. 반대로 \(h\)가 크면 모든 것이 하나의 넓은 언덕으로 뭉개져 실제 봉우리를 놓치는데, 이것은 치우침이 큰 상태이다. 점마다 치우침은 대략 \(\tfrac{h^2}{2} f''(x)\)이고 분산은 대략 \(\tfrac{f(x)}{nh}\int K^2\)이다. 그러므로 둘을 합한 평균제곱오차를 최소로 하는 \(h\)는 \(n^{-1/5}\)에 비례한다. 다시 말해 표본이 32배가 되어야 띠너비가 절반이 된다.

실무에서 가장 흔한 것은 실버먼 규칙 \(h = 0.9 \min(s, \mathrm{IQR}/1.34)\, n^{-1/5}\)이며, R의 density(x) 기본값이다. 참 분포가 정규에 가까울 때 좋지만, 봉우리가 여럿이면 지나치게 매끄럽게 만든다. 이때는 시더-존스 방법(density(x, bw = "SJ"))이나 교차검증으로 자료에 맞춰 고르는 편이 낫다.

주의

소득처럼 0 아래 값이 없는 자료에서는 커널이 0 아래로 넘쳐, 경계 근처 밀도를 낮게 추정한다. 이럴 때는 로그 변환한 뒤 추정하고 되돌린다.

마무리

커널 밀도추정량 \(\hat f_h(x) = \tfrac{1}{nh}\sum K((x - x_i)/h)\)는 관측마다 언덕을 놓아 더한 것이다. 작은 \(h\)는 울퉁불퉁하고(분산), 큰 \(h\)는 뭉개지며(치우침), 최적 \(h\)는 \(n^{-1/5}\)에 비례한다. 실버먼 규칙이 기본이고, 봉우리가 여럿이면 SJ나 교차검증을 쓴다.

6.3.3연습문제

기본

  1. \(\int \hat f_h(x)\,dx = 1\)임을 보여라.
    답

    각 항에서 \(u = (x - x_i)/h\)로 치환하면 \(\tfrac1h \int K((x - x_i)/h)\,dx = \int K(u)\,du = 1\)이다. \(n\)개를 더해 \(n\)으로 나누면 1이다.

응용

  1. 예제 6.3.1에서 \(h\)를 0.2로 줄이면 \(\hat f(5.5)\)와 \(\hat f(4)\)는 어떻게 되는가? 그림은 어떤 모양일까?
    답

    5.5는 가장 가까운 관측 4와 7에서 띠너비의 7.5배 떨어져 있어 \(\hat f(5.5) \approx 0\)이다. \(\hat f(4) = \phi(0)/(5 \times 0.2) \approx 0.40\)이고 다른 관측의 기여는 거의 0이다. 그러므로 관측마다 높이 0.4 정도의 뾰족한 봉우리가 따로 서 있는 모양, 곧 과소평활이 된다.
