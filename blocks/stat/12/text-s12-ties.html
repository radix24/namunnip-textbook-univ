분포를 몰라도 분포를 셀 수 있다

비모수 검정의 p값은 어디서 나올까요? 귀무가설 아래에서는 관측값이 어떤 분포에서 왔든 "어느 순위가 어느 집단(또는 어느 부호)에 붙는가"의 모든 배치가 같은 확률입니다. 그래서 배치를 모두 세면 정확한 분포가 나오고, 이 분포는 원래 분포와 무관합니다.

1.3.1정확 분포 세기

  • 부호순위 통계량 \(W^+\)(4.1절): 순위 \(1, \ldots, n\) 각각에 + 또는 −가 독립으로 반반. \(2^n\)가지 배치.
  • 순위합 통계량 \(W\)(4.2절): \(N = m + n\)개 순위 가운데 둘째 집단이 차지할 \(n\)개를 고르는 \(\binom Nn\)가지 배치.
예제 1.3.1

\(n = 4\)일 때 \(W^+\)의 정확 분포를 구하고 \(P(W^+ \ge 9)\)를 계산하세요.

풀이. 16가지 부호 배치에서 양수 순위의 합을 세면 \(W^+ = 0, 1, \ldots, 10\)의 경우의 수가 1, 1, 1, 2, 2, 2, 2, 2, 1, 1, 1입니다(합 16). 예를 들어 \(W^+ = 3\)은 {3}과 {1, 2}의 두 가지. \(P(W^+ \ge 9) = 2/16 = 0.125\). 분포는 평균 5를 중심으로 대칭입니다. \(n = 4\)에서는 가장 극단인 경우도 단측 p값이 \(1/16 = 0.0625\)라 5% 수준에서 기각할 수 없습니다.

1.3.2정규근사와 연속성 보정

\(n\)이 커지면 배치 수가 폭발하지만, 통계량이 독립 항(또는 비복원 추출)의 합이라 중심극한정리로 정규근사가 됩니다. 평균과 분산은 다음과 같습니다.

통계량평균분산
\(W^+\)\(n(n+1)/4\)\(n(n+1)(2n+1)/24\)
\(U\)(맨-휘트니)\(mn/2\)\(mn(N+1)/12\)

통계량이 정수(또는 0.5) 간격의 이산값이라, 정규근사에서 \(P(T \ge t)\)를 \(P(Z \ge (t - 0.5 - \mu)/\sigma)\)처럼 0.5만큼 보정하면(연속성 보정) 정확 값에 더 가깝습니다. 대략 집단마다 10개 이상이면 근사가 쓸 만하고, 그보다 작으면 정확 분포(R의 exact = TRUE)를 씁니다.

1.3.3동순위

같은 값에는 평균 순위를 줍니다(1.2절). 그러면 통계량의 평균은 그대로지만 분산은 줄어듭니다. 크기 \(t\)인 동순위 묶음마다 순위가 퍼질 여지가 사라지기 때문입니다. 보정한 분산은

\[\mathrm{Var}(U) = \frac{mn}{12}\left[(N+1) - \frac{\sum(t^3 - t)}{N(N-1)}\right], \qquad \mathrm{Var}(W^+) = \frac{n(n+1)(2n+1)}{24} - \frac{\sum(t^3 - t)}{48}\]

입니다. 동순위가 있으면 정확 분포표가 맞지 않으므로, 평균 순위를 그대로 둔 채 배치를 다시 세는 순열 분포(6.1절)를 쓰거나 보정한 정규근사를 씁니다. 부호순위 검정에서 차이가 정확히 0인 관측은 보통 빼고 \(n\)을 줄입니다.

요약
  1. \(H_0\) 아래 순위 배치가 모두 같은 확률이라 정확 분포를 셀 수 있습니다.
  2. 큰 표본은 평균·분산으로 정규근사, 연속성 보정 0.5.
  3. 동순위는 평균 순위, 분산을 \(\sum(t^3 - t)\)로 보정.

1.3.4연습문제

기본

  1. \(m = n = 2\)일 때 둘째 집단의 순위합 \(W\)의 정확 분포를 쓰세요.
    답

    \(\binom42 = 6\)가지: {1,2}=3, {1,3}=4, {1,4}=5, {2,3}=5, {2,4}=6, {3,4}=7. \(P(W = 3, 4, 5, 6, 7) = 1/6, 1/6, 2/6, 1/6, 1/6\).

응용

  1. \(n = 20\)인 부호순위 검정에서 \(W^+ = 150\)입니다. 연속성 보정을 한 단측 p값을 어림하세요(동순위 없음).
    답

    평균 105, 분산 \(20 \cdot 21 \cdot 41/24 = 717.5\), 표준편차 26.8. \(z = (150 - 0.5 - 105)/26.8 = 1.66\), p값 약 0.048.
