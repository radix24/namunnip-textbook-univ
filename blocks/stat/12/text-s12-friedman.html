프리드먼 검정

본문
이 절에서 배울 것
  • 블록(같은 대상의 반복 측정)이 있을 때 프리드먼 검정을 쓴다.
  • 블록 안에서 순위를 매기는 이유를 이해한다.
  • 켄들의 일치도 \(W\)로 효과의 크기를 나타낸다.
먼저 알아야 할 것
  • 부호검정 (2.1절), 크러스컬-월리스 (4.4절).

사람마다 기준이 다를 때

심사위원 네 명이 와인 세 종을 맛보고 점수를 매기면, 어떤 심사위원은 모두 후하게, 어떤 심사위원은 모두 박하게 줍니다. 이 사람 사이 차이를 그대로 두고 전체 순위를 매기면(크러스컬-월리스) 처리 차이가 묻힙니다. 사람마다(블록 안에서) 순위를 매기면 사람 사이 차이가 사라지고 처리 사이 비교만 남습니다.

4.5.1통계량

\(b\)개 블록이 \(k\)가지 처리를 모두 받았습니다. 블록마다 \(1, \ldots, k\) 순위를 매기고, 처리 \(j\)의 순위합을 \(R_j\)라 합니다. \(H_0\)(처리 효과 없음) 아래 각 블록의 순위는 \(k!\)가지 순열이 같은 확률이므로 \(E(R_j) = b(k+1)/2\)입니다.

결과 4.5.1 \[Q = \frac{12}{bk(k+1)}\sum_j\left(R_j - \frac{b(k+1)}{2}\right)^2 = \frac{12}{bk(k+1)}\sum_j R_j^2 - 3b(k+1) \approx \chi^2_{k-1}.\]

응통13의 랜덤화 블록 분산분석에 해당하는 순위 검정입니다. \(k = 2\)이면 부호검정과 같습니다(블록마다 어느 처리가 큰지만 남음). 블록 안 동순위는 평균 순위를 쓰고 보정합니다. 정보를 블록 안 순서로만 쓰므로 \(k\)가 작으면 효율이 낮고, 이때 블록 안 차이의 크기를 쓰는 정렬 순위 검정(aligned rank)이 대안입니다.

예제 4.5.2

심사위원 4명이 와인 3종(A, B, C)에 매긴 순위: (1, 2, 3), (1, 3, 2), (1, 2, 3), (2, 1, 3). 선호가 다른가요?

풀이. \(R_A = 5\), \(R_B = 8\), \(R_C = 11\). \(Q = \frac{12}{4 \cdot 3 \cdot 4}(25 + 64 + 121) - 3 \cdot 4 \cdot 4 = 52.5 - 48 = 4.5\), 자유도 2, p값 \(e^{-2.25} \approx 0.105\). 표본이 작아 유의하지 않습니다. R: friedman.test(m) (행 = 심사위원).

4.5.2켄들의 일치도

정의 4.5.3

\(W = \dfrac{Q}{b(k-1)}\). 0(블록들의 순위가 제각각)과 1(모든 블록이 같은 순위) 사이의 값이다.

p값은 블록 수 \(b\)가 커지면 작아지지만 \(W\)는 "심사위원들이 얼마나 같은 순서를 매겼는가"를 표본 크기와 무관하게 나타냅니다. 예제 4.5.2에서 \(W = 4.5/8 = 0.56\)입니다. 평가자 사이 일치도를 보고할 때 씁니다.

요약
  1. 프리드먼: 블록 안 순위, \(Q \approx \chi^2_{k-1}\).
  2. 블록 사이 차이를 순위로 없애 처리 비교만 남깁니다. \(k = 2\)이면 부호검정.
  3. 켄들의 \(W = Q/[b(k-1)]\)로 일치 정도를 나타냅니다.

4.5.3연습문제

기본

  1. 모든 블록이 같은 순위 (1, 2, 3)을 매기면 \(Q\)와 \(W\)는? (\(b\)개 블록)
    답

    \(R = (b, 2b, 3b)\), 평균 \(2b\). \(Q = \frac{12}{12b}(b^2 + 0 + b^2) = 2b\), \(W = 2b/(2b) = 1\).

응용

  1. 같은 자료를 블록을 무시하고 크러스컬-월리스로 분석하면 왜 검정력이 떨어지는지 설명하세요.
    답

    블록(사람) 사이 차이가 전체 순위의 변동에 섞여 오차처럼 작용하므로 처리 차이가 상대적으로 작아 보입니다. 또 같은 블록의 관측이 독립이 아니라 크러스컬-월리스의 가정도 어긋납니다.
