먼저 알아야 할 것
  • 랜덤 배정 (응통5 1.1절), 순위합 검정 (응통7 7.1절).

이름표가 의미 없다면

신약군과 위약군을 제비뽑기로 나눴다고 합시다. 약이 아무 효과가 없다면, 각 환자의 결과는 어느 집단에 배정되었든 똑같았을 것입니다. 그렇다면 이름표를 다시 섞어도 결과의 분포는 같아야 합니다. 이 생각이 순열 검정입니다.

6.1.1절차

  1. 검정통계량을 정합니다. 예: 두 집단 평균의 차 \(T = \bar y - \bar x\).
  2. 관측된 \(T_{obs}\)를 계산합니다.
  3. \(m + n\)개 값을 합쳐 크기 \(m\)과 \(n\)으로 다시 나누는 모든 방법(\(\binom{m+n}{m}\)가지)에 대해 \(T\)를 계산합니다. 너무 많으면 무작위로 수천 번 섞습니다.
  4. p값 = \(|T| \ge |T_{obs}|\)인 배치의 비율.

통계량으로 순위합을 쓰면 윌콕슨 검정이 되고, 평균 차를 쓰면 값의 크기를 모두 쓰는 분포 무관 검정이 됩니다. 정규성을 가정하지 않으면서 t 검정에 가까운 검정력을 가집니다. 근거는 귀무가설 아래 이름표의 교환 가능성이며, 랜덤 배정 실험에서 특히 자연스럽습니다.

예제 6.1.1

\(X\): 3, 5, 6. \(Y\): 8, 9. 평균 차 순열 검정의 정확한 단측 p값은?

풀이. \(T_{obs} = 8.5 - 4.667 = 3.833\). \(\binom52 = 10\)가지로 \(Y\) 자리 둘을 고르면, \(T \ge 3.833\)인 것은 (8, 9) 하나뿐입니다. p값 0.1.

x <- c(3, 5, 6); y <- c(8, 9); z <- c(x, y)
Tobs <- mean(y) - mean(x)
Tperm <- replicate(10000, { i <- sample(5, 2); mean(z[i]) - mean(z[-i]) })
mean(Tperm >= Tobs - 1e-9)
요약
  1. 귀무가설 아래 이름표는 교환 가능 → 섞어서 귀무분포를 만듦.
  2. 통계량은 자유롭게 고를 수 있습니다.
  3. 경우가 많으면 무작위 순열로 근사.
