그래프로 분포와 관계 나타내기

본문

보고서에 계산 금액의 분포와, 계산 금액과 팁의 관계를 나란히 넣으려 한다. 인터넷에서 찾은 파이썬 그래프 코드는 어떤 것은 plt.plot(...), 어떤 것은 ax.plot(...)으로 시작해 섞어 쓰면 엉뚱한 곳에 그려진다. 둘은 무엇이 다르고, 그래프 두 개를 한 그림에 원하는 대로 배치하려면 무엇을 알아야 할까?

먼저 알아야 할 것pandas(5.1절)와 그래프 읽기(응통5 2.3절)를 쓴다.

5.3.1matplotlib

matplotlib은 파이썬 그래프의 기반이다. 그림 1처럼 그림(Figure) 안에 축(Axes)을 하나 이상 만들고, 각 축에 그래프를 그린다. 처음 질문의 답이 여기 있다. ax.plot은 지정한 축에 그리고, plt.plot은 "지금 활성화된 축"에 그린다. 그래서 축이 여럿일 때 plt를 쓰면 마지막으로 만든 축에 그려지기 쉽다. 축 객체에 직접 그리는 습관을 들이자.

import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 2, figsize=(9, 3.5))
axes[0].hist(tips["total_bill"], bins=20, color="grey", edgecolor="white")
axes[0].set(xlabel="계산 금액 ($)", ylabel="빈도", title="분포")
axes[1].scatter(tips["total_bill"], tips["tip"], s=12, alpha=0.6)
axes[1].set(xlabel="계산 금액 ($)", ylabel="팁 ($)", title="관계")
fig.tight_layout(); fig.savefig("fig/tips.png", dpi=200)
# 한글 글꼴은 plt.rcParams["font.family"] = "Malgun Gothic"(윈도) 또는 "AppleGothic"(맥)
#       plt.rcParams["axes.unicode_minus"] = False

plt.subplots(1, 2)는 한 행 두 열의 축을 가진 그림을 만들어 그림과 축 배열을 돌려준다. 이어서 축마다 그리고 set으로 축 이름과 제목을 붙인 뒤, tight_layout으로 겹침을 정리하고 savefig로 저장한다. 한편 기본 글꼴은 한글을 그리지 못하므로 주석의 두 줄로 글꼴을 바꾸고, 음수 부호가 깨지지 않게 한다.

5.3.2seaborn

그런데 집단마다 색을 달리하거나 패널을 나누는 그래프를 matplotlib만으로 그리면 반복문이 필요하다. seaborn은 데이터프레임과 열 이름만 주면 이런 그래프를 바로 그린다.

import seaborn as sns
sns.boxplot(data=tips, x="day", y="tip")                       # 집단 비교
sns.histplot(data=tips, x="total_bill", hue="time", kde=True)  # 집단별 분포
sns.scatterplot(data=tips, x="total_bill", y="tip", hue="smoker")
sns.lmplot(data=tips, x="total_bill", y="tip", col="time")     # 회귀선 + 패널
sns.pairplot(tips, hue="sex")                                  # 산점도 행렬

변수를 색(hue), 패널(col, row)에 대응시키는 방식은 ggplot2(응통3 3.2절)와 비슷하다. 또 seaborn은 matplotlib 위에서 돌아가므로, sns.boxplot(..., ax=axes[0])처럼 그릴 축을 지정해 그림 1의 배치 안에 넣을 수 있다.

예제 5.3.1

팁 비율(tip / total_bill)의 분포를 흡연 여부별로 겹쳐 그리되, 두 집단의 크기가 달라도 모양을 비교할 수 있게 하여라.

sns.histplot(data=tips.assign(rate=tips.tip / tips.total_bill),
             x="rate", hue="smoker", stat="density", common_norm=False)

풀이. 빈도로 그리면 사람이 많은 집단의 막대가 높아 모양을 비교하기 어렵다. 따라서 stat="density"로 넓이를 1로 맞추고, common_norm=False로 집단마다 따로 정규화한다.

주의그래프에는 축 이름과 단위를 늘 붙인다. 화면에서는 열 이름 total_bill로 충분해 보여도, 보고서를 읽는 사람에게는 "계산 금액 ($)"처럼 뜻과 단위가 있어야 한다.
마무리

matplotlib은 그림(Figure) 안에 축(Axes)을 두고 축마다 그리는 구조이므로, fig, ax = plt.subplots()로 시작해 ax에 직접 그리고 ax.set으로 이름을 붙인 뒤 savefig로 저장한다. seaborn은 데이터프레임과 열 이름, hue, col로 집단별 그래프를 빠르게 그리고, ax=로 원하는 축에 넣을 수 있다. 축 이름과 단위, 한글 글꼴 설정을 잊지 말자.
