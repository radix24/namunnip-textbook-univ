배열 계산 단원 마무리 연습

문제 7 · 실습 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습다음 NumPy 코드의 출력을 예측하세요. 같은 연산을 리스트로 하면 어떻게 다른지도 쓰세요. [03-01]

    import numpy as np
x = np.array([1, 2, 3, 4])
print(x * 2, x[x > 2], x.mean())
    힌트 1

    배열의 산술 연산은 원소마다 적용됩니다.

    힌트 2

    불리언 배열로 첨자를 주면 True인 자리만 남습니다(R과 같음).

    풀이

    출력은 [2 4 6 8] [3 4] 2.5입니다. 리스트에서 [1, 2, 3, 4] * 2는 이어 붙이기, xs[xs > 2]는 오류입니다. 반복문 없이 배열 전체에 연산을 하는 것을 벡터화라 하며, C로 구현된 내부 반복을 써서 훨씬 빠릅니다.

  2. 실습np.std([2, 4, 4, 5, 7, 8])의 값이 R의 sd(c(2, 4, 4, 5, 7, 8))와 다른 까닭을 설명하고, 같은 값을 얻는 코드를 쓰세요. [03-01]

    힌트 1

    NumPy의 std는 기본으로 \(n\)으로 나눕니다. 그 설정 인수 이름은 ddof입니다.

    힌트 2

    편차 제곱합은 24입니다.

    풀이

    np.std는 기본값 ddof=0으로 \(\sqrt{24/6} = 2.0\)을 줍니다. R의 sd는 \(n - 1\)로 나누어 \(\sqrt{24/5} \approx 2.191\)입니다. np.std(x, ddof=1)로 쓰면 같은 값이 나옵니다. pandas의 Series.std()는 기본이 ddof=1이라 또 다르니, 라이브러리마다 기본값을 확인해야 합니다.

  3. 실습행이 관측, 열이 변수인 \(n\times p\) 배열 X의 각 열을 표준화(평균 0, 표준편차 1)하는 코드를 반복문 없이 쓰고, 어떤 규칙 덕분에 가능한지 설명하세요. [03-01]

    힌트 1

    X.mean(axis=0)은 열마다 평균을 구해 길이 \(p\)인 배열을 돌려줍니다.

    힌트 2

    \(n\times p\) 배열에서 길이 \(p\)인 배열을 빼면, 그 배열이 모든 행에 반복 적용됩니다(브로드캐스팅).

    풀이 
    Z = (X - X.mean(axis=0)) / X.std(axis=0, ddof=1)

    모양이 \((n, p)\)인 배열과 \((p,)\)인 배열의 연산에서 NumPy는 뒤쪽 축을 맞추어 작은 배열을 모든 행에 늘려 적용합니다. 이것을 브로드캐스팅이라 합니다. 행마다 표준화하려면 X.mean(axis=1, keepdims=True)로 모양을 \((n, 1)\)로 맞춰야 합니다.

  4. 실습A = np.array([[1, 2], [3, 4]]), B = np.array([[0, 1], [1, 0]])일 때 A @ B와 A * B의 결과를 쓰고 차이를 설명하세요. [03-02]

    힌트 1

    @는 행렬 곱, *는 원소별 곱입니다.

    힌트 2

    행렬 곱은 응통2-01-01에서 손으로 계산했습니다.

    풀이

    A @ B는 [[2, 1], [4, 3]](행렬 곱, 열 교환), A * B는 [[0, 2], [3, 0]](같은 자리끼리 곱)입니다. R에서는 행렬 곱이 %*%, 원소별 곱이 *로, 기호가 다르니 헷갈리지 않도록 주의하세요.

  5. 실습연립방정식 \(x + y + z = 6\), \(2x + y - z = 1\), \(x - y + 2z = 5\)를 NumPy로 푸는 코드를 쓰세요. np.linalg.inv(A) @ b 대신 np.linalg.solve(A, b)를 권하는 까닭도 쓰세요. [03-02]

    힌트 1

    계수행렬 A와 우변 b를 배열로 만듭니다.

    힌트 2

    역행렬을 구한 뒤 곱하는 것은 계산량도 많고 반올림 오차도 커집니다.

    풀이 
    A = np.array([[1, 1, 1], [2, 1, -1], [1, -1, 2]])
b = np.array([6, 1, 5])
print(np.linalg.solve(A, b))   # [1. 2. 3.]

    해는 \((1, 2, 3)\)으로 응통2-01-02에서 가우스 소거로 구한 것과 같습니다. solve는 LU 분해로 직접 풀어 역행렬 전체를 만들지 않으므로 더 빠르고 수치적으로 안정합니다.

  6. 실습NumPy의 새 난수 생성기로 표준정규 난수 100만 개를 만들어 \(P(Z > 1.96)\)을 추정하는 코드를 쓰세요. 이론값과 비교하고, 시드를 정하는 방법을 쓰세요. [03-02]

    힌트 1

    rng = np.random.default_rng(42)로 시드를 정한 생성기를 만듭니다.

    힌트 2

    불리언 배열의 평균은 True의 비율입니다.

    풀이 
    rng = np.random.default_rng(42)
z = rng.standard_normal(1_000_000)
print((z > 1.96).mean())

    이론값은 약 0.0250이고, 추정의 표준오차는 \(\sqrt{0.025\times0.975/10^6} \approx 0.00016\)이므로 결과는 0.0247~0.0253 근처에 나옵니다. 예전 방식 np.random.seed()보다 생성기 객체를 쓰는 방식이 권장됩니다.

  7. 실습x = np.array([4, 9, 2, 7, 5, 1])에서 (1) 5보다 큰 값 (2) 짝수 위치(0, 2, 4번째)의 값 (3) 가장 작은 세 값을 구하는 코드와 결과를 쓰세요. [03-03]

    힌트 1

    불리언 마스크, 슬라이싱, argsort.

    힌트 2

    x[::2]는 짝수 위치.

    풀이

    (1) x[x > 5] → [9, 7]. (2) x[::2] → [4, 2, 5]. (3) x[np.argsort(x)[:3]] → [1, 2, 4].
