정규분포 확률을 심프슨 공식으로

예제 · 사다리꼴과 심프슨 비교

먼저 읽는 법

같은 점 다섯 개를 쓰는 사다리꼴과 심프슨 공식으로 \(\int_0^1e^{-x^2}dx\)를 계산하고, 정확한 값과 오차를 비교합니다.

문제. \(h = 0.25\)(구간 4개)로 \(\int_0^1e^{-x^2}dx\)를 사다리꼴과 심프슨 공식으로 계산하세요. 정확한 값은 0.746824입니다.

풀이

  1. 함수값 \(f(0) = 1\), \(f(0.25) = 0.9394\), \(f(0.5) = 0.7788\), \(f(0.75) = 0.5698\), \(f(1) = 0.3679\).
    \(e^{-x^2}\).
  2. 사다리꼴: \(0.25(0.5 + 0.9394 + 0.7788 + 0.5698 + 0.1839) = 0.74298\), 오차 0.0038.
    양 끝은 절반 가중치.
  3. 심프슨: \(\frac{0.25}{3}(1 + 4(0.9394 + 0.5698) + 2(0.7788) + 0.3679) = 0.74686\), 오차 0.00003.
    가중치 1, 4, 2, 4, 1.

검산

같은 다섯 점으로 심프슨이 100배 이상 정확합니다. \(\int_0^1e^{-x^2}dx = \sqrt\pi(\Phi(\sqrt2) - 0.5)\)이고, \(\Phi(1.414) = 0.9214\)로 계산하면 \(1.7725 \times 0.4214 = 0.7469\)로 맞습니다.

의미

정규분포 함수 scipy.stats.norm.cdf는 이보다 정교한 방법으로 계산되지만 원리는 같습니다. 밀도가 매끄러울수록 고차 공식의 이득이 크고, 꼬리나 뾰족한 점이 있으면 적응 구적법(quad)이 구간을 잘게 나눠 대처합니다.
