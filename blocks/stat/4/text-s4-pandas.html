pandas로 자료 읽고 정리하기

본문

설문 자료를 엑셀에서 CSV로 저장해 읽었더니 소득 칸에 "1,200"처럼 쉼표가 들어가 문자열로 읽혔고, 무응답은 "-"나 999로 적혀 있으며, 성별은 "남", "남자", "M"이 섞여 있다. R에서는 데이터프레임과 dplyr로 정리했다. 파이썬에서는 이런 표를 무엇으로 읽고 어떻게 정리할까?

먼저 알아야 할 것NumPy(3.1절)와 불리언 마스크(3.3절)를 쓴다. R의 데이터프레임(응통3)을 알면 비교하며 익힐 수 있다.

5.1.1읽기와 둘러보기

파이썬에서 표 형태 자료를 다루는 표준 도구는 pandas이다. pandas의 데이터프레임은 그림 1처럼 행에 인덱스, 열에 이름이 붙은 표이고, 열 하나는 Series라는 이름 붙은 1차원 배열이다. R의 데이터프레임과 dplyr이 하는 일을 대부분 할 수 있다. 처음 질문의 자료는 결측 표시를 지정해 읽는다.

import pandas as pd
df = pd.read_csv("survey.csv", encoding="cp949", na_values=["", "-", "999"])
df.head(); df.info(); df.describe()
df.shape; df.columns; df.dtypes

한국어 윈도 엑셀이 저장한 CSV는 흔히 cp949 인코딩이다. 또 na_values에 적은 문자열은 결측(NaN)으로 읽힌다. 읽은 뒤에는 info로 열마다 자료형과 결측 아닌 개수를, describe로 요약 통계를 먼저 본다.

5.1.2고르기와 만들기

df["age"]                         # 열 하나 (Series)
df[["age", "income"]]             # 여러 열
df[df["age"] >= 30]               # 조건으로 행
df.loc[df["sex"] == "F", ["age", "income"]]   # 행 조건 + 열 이름
df.iloc[0:5, 0:2]                 # 위치로
df = df.assign(log_inc=np.log(df["income"]))  # 새 열
df["agegrp"] = pd.cut(df["age"], bins=[0, 29, 39, 49, 200],
                      labels=["20대 이하", "30대", "40대", "50대 이상"])

loc은 이름(열 이름, 행 인덱스)으로, iloc은 정수 위치로 고른다. 그래서 loc의 범위는 끝을 포함하고 iloc은 파이썬 규칙대로 끝을 뺀다. 행 조건은 NumPy의 불리언 마스크와 같은 원리이므로, 조건을 여러 개 묶을 때는 df[(df.age > 30) & (df.sex == "F")]처럼 &, |와 괄호를 쓴다.

5.1.3결측과 자료형

이제 처음 질문의 지저분한 칸들을 정리하자.

df.isna().sum()                   # 열별 결측 수
df = df.dropna(subset=["income"]) # 소득 결측 행 제거
df["income"] = pd.to_numeric(df["income"].str.replace(",", ""), errors="coerce")
df["date"] = pd.to_datetime(df["date"])
df["sex"] = df["sex"].replace({"남자": "M", "남": "M", "여자": "F", "여": "F"}).astype("category")

쉼표를 지운 뒤 to_numeric으로 숫자로 바꾸는데, errors="coerce"는 숫자로 바꿀 수 없는 값을 오류 대신 결측으로 만든다. 성별은 표기를 하나로 맞춘 뒤 범주형으로 바꾼다. 한편 이런 처리는 자료를 조용히 바꾸므로, 처리 전후의 행 수와 결측 수를 기록해 두어야 나중에 결과를 설명할 수 있다.

예제 5.1.1

R의 d[d$cyl == 4, c("mpg", "hp")]에 해당하는 pandas 코드를 쓰고, 행 이름표 대신 위치로 처음 세 행만 고르는 코드도 써라.

풀이. 행 조건과 열 이름을 함께 쓰므로 df.loc[df["cyl"] == 4, ["mpg", "hp"]]이다. 처음 세 행은 위치이므로 df.iloc[0:3]인데, R의 d[1:3, ]과 달리 0부터 세고 끝 3은 빠진다.

흔한 실수df[df.age > 30]["income"] = 0처럼 고른 결과에 다시 대입하면 복사본만 바뀌고 원본은 그대로일 수 있다(SettingWithCopyWarning). 원본을 바꿀 때는 df.loc[df.age > 30, "income"] = 0처럼 loc 하나로 쓴다.
마무리

pandas의 데이터프레임은 인덱스와 열 이름이 붙은 표이고 열 하나는 Series이다. read_csv에 인코딩과 결측 표시를 주어 읽고 info, describe로 둘러본다. 행과 열은 조건, loc(이름), iloc(위치)으로 고르고 assign, pd.cut으로 새 열을 만든다. 지저분한 칸은 to_numeric(errors="coerce"), to_datetime, replace로 정리하되 처리 전후의 행 수와 결측 수를 기록한다.

5.1.4연습문제

기본

  1. pd.to_numeric(pd.Series(["1,200", "없음", "350"]).str.replace(",", ""), errors="coerce")의 결과는 무엇인가?
    답

    [1200.0, NaN, 350.0]이다. 결측이 섞이면 정수 대신 실수형이 된다.

응용

  1. 인덱스가 [10, 20, 30, 40]인 데이터프레임에서 df.loc[10:30]과 df.iloc[1:3]은 각각 몇 행인가?
    답

    loc은 이름 10부터 30까지 끝을 포함해 3행, iloc은 위치 1, 2의 2행(인덱스 20, 30)이다.
