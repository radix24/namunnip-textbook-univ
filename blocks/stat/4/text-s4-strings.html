문자열 처리와 파일 입출력

본문

설문의 주소 칸에 " Seoul, Gangnam "처럼 앞뒤 공백이 붙은 응답이 들어오고, 서버 로그에는 날짜와 오류가 한 줄 문자열로 섞여 있다. 이런 자료는 표가 되기 전에 문자열 덩어리이다. 어떻게 잘라 내고 정리해야 분석할 수 있는 모양이 될까?

먼저 알아야 할 것자료형과 반복(1.1절), 리스트와 딕셔너리(1.2절)를 쓴다.

1.3.1문자열 메서드

처음 질문의 주소 응답부터 다듬어 보자. 그림 1의 위 갈래가 바로 아래 코드의 첫 두 줄이다.

s = "  Seoul, Gangnam  "
s.strip()                 # 'Seoul, Gangnam' (양끝 공백 제거)
s.strip().split(", ")     # ['Seoul', 'Gangnam']
"-".join(["2026", "03", "15"])   # '2026-03-15'
"abc".upper(), "A1B2".replace("1", "")   # 'ABC', 'AB2'
"report.csv".endswith(".csv")    # True
n, m = 7, 3.14159
f"표본 {n}개, 평균 {m:.2f}"      # '표본 7개, 평균 3.14'

여기서 주의할 점은 문자열이 바꿀 수 없는(불변) 자료형이라는 것이다. 그래서 메서드는 원래 문자열을 고치지 않고 새 문자열을 돌려주며, 결과를 변수에 다시 담아야 한다.

1.3.2파일 읽고 쓰기

이제 문자열을 파일에서 읽어 오자. 텍스트 파일은 with open으로 연다.

with open("data.txt", encoding="utf-8") as f:
    lines = [line.rstrip("\n") for line in f]   # 한 줄씩

with open("out.txt", "w", encoding="utf-8") as f:
    f.write("결과 42\n")

with 문은 블록이 끝나면 오류가 나도 파일을 자동으로 닫는다. 한편 한글이 있으면 encoding="utf-8"을 꼭 적는다. 윈도의 기본 인코딩은 다를 수 있기 때문이다. 표 형식 파일이라면 csv 모듈이나 pandas의 read_csv(5.1절)가 더 편하다.

1.3.3정규표현식

그런데 로그처럼 모양이 불규칙하면 split만으로는 원하는 조각을 꺼내기 어렵다. 이때는 글자의 패턴을 기술하는 정규표현식을 쓴다. 그림 1의 아래 갈래가 첫 줄이다.

import re
re.findall(r"\d+", "A12 B3 C456")             # ['12', '3', '456']
re.sub(r"\s+", " ", "too   many  spaces")     # 'too many spaces'
bool(re.match(r"^\d{3}-\d{4}$", "123-4567"))  # True

패턴에서 \d는 숫자, \s는 공백, +는 한 번 이상, {n}은 정확히 \(n\)번, ^와 $는 시작과 끝을 뜻한다. 또 문자열 앞의 r은 역슬래시를 그대로 두는 원시 문자열이므로, 패턴은 늘 r"..."로 쓰는 습관을 들이자.

예제 1.3.1

문장 "the cat and the hat and the bat"에서 가장 많이 나온 단어 두 개를 세어라.

from collections import Counter
Counter("the cat and the hat and the bat".split()).most_common(2)
# [('the', 3), ('and', 2)]

풀이. split()은 인자가 없으면 공백 덩어리마다 자른다. 그러면 단어 리스트가 되고, Counter(1.2절)가 빈도를 센다.

흔한 실수s.strip()만 쓰고 s를 다시 출력하면 공백이 그대로 남아 있다. 불변 자료형의 메서드는 새 값을 돌려줄 뿐이므로 s = s.strip()처럼 다시 담아야 한다.
마무리

표가 되기 전의 문자열은 strip, split, join, replace로 다듬고 f-문자열로 서식을 만든다. 문자열은 불변이므로 결과를 새 변수에 담는다. 파일은 with open(..., encoding="utf-8")으로 열어 자동으로 닫히게 하고, 모양이 불규칙한 텍스트는 re.findall, re.sub 같은 정규표현식으로 필요한 조각만 꺼낸다.

기본

    dates = [ln.split()[0] for ln in lines if " ERROR " in ln]이다. 정규표현식으로는 re.match(r"(\d{4}-\d{2}-\d{2}) \S+ ERROR", ln)의 그룹 1을 쓴다.
