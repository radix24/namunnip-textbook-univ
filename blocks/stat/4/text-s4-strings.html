표가 되기 전의 자료

로그 파일, 설문 자유 응답, 웹에서 받은 텍스트는 처음에 문자열 덩어리입니다. pandas(5.1절)로 넘기기 전에 문자열을 정리하는 일이 자주 필요합니다.

1.3.1문자열 메서드

s = "  Seoul, Gangnam  "
s.strip()                 # 'Seoul, Gangnam' (양끝 공백 제거)
s.strip().split(", ")     # ['Seoul', 'Gangnam']
"-".join(["2026", "03", "15"])   # '2026-03-15'
"abc".upper(), "A1B2".replace("1", "")   # 'ABC', 'AB2'
"report.csv".endswith(".csv")    # True
n, m = 7, 3.14159
f"표본 {n}개, 평균 {m:.2f}"      # '표본 7개, 평균 3.14'

문자열은 바꿀 수 없는(불변) 자료형이라 메서드는 새 문자열을 돌려줍니다. 결과를 변수에 다시 담아야 합니다.

1.3.2파일 읽고 쓰기

with open("data.txt", encoding="utf-8") as f:
    lines = [line.rstrip("\n") for line in f]   # 한 줄씩

with open("out.txt", "w", encoding="utf-8") as f:
    f.write("결과: 42\n")

with 문은 블록이 끝나면 오류가 나도 파일을 자동으로 닫습니다. 한글이 있으면 encoding="utf-8"을 명시합니다(윈도의 기본 인코딩은 다를 수 있음). 표 형식 파일은 csv 모듈이나 pandas의 read_csv가 편합니다.

1.3.3정규표현식

import re
re.findall(r"\d+", "A12 B3 C456")          # ['12', '3', '456']
re.sub(r"\s+", " ", "too   many  spaces")   # 'too many spaces'
bool(re.match(r"^\d{3}-\d{4}$", "123-4567"))  # True

\d(숫자), \s(공백), +(한 번 이상), {n}(정확히 \(n\)번), ^ $(시작과 끝). 문자열 앞의 r은 역슬래시를 그대로 두는 원시 문자열입니다.

예제 1.3.1

문장 "the cat and the hat and the bat"에서 가장 많이 나온 단어 두 개를 세세요.

from collections import Counter
Counter("the cat and the hat and the bat".split()).most_common(2)
# [('the', 3), ('and', 2)]
요약
  1. strip, split, join, replace, f-문자열.
  2. with open(..., encoding="utf-8")로 안전하게 읽고 쓰기.
  3. re.findall, re.sub로 패턴 처리.
