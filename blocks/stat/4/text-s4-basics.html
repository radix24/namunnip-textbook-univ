왜 파이썬인가

파이썬은 문법이 간결하고, 자료 분석(pandas), 수치 계산(NumPy, SciPy), 머신러닝(scikit-learn) 도구가 풍부해 통계와 데이터 과학에서 R과 함께 가장 많이 쓰입니다. R과 다른 점 하나는 들여쓰기가 문법이라는 것입니다.

1.1.1자료형

n = 10            # int (정수)
x = 3.14          # float (실수)
name = "통계"      # str (문자열)
ok = n > 5        # bool: True
print(type(x), 7 // 2, 7 % 2, 2 ** 10)   # <class 'float'> 3 1 1024
s = f"n = {n}, x = {x:.1f}"               # 형식 문자열: 'n = 10, x = 3.1'

인덱스는 0부터 시작합니다(R은 1부터). //는 몫, %는 나머지, **는 거듭제곱입니다.

1.1.2조건, 반복, 함수

def grade(score):
    """점수를 등급으로 바꾼다."""
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    else:
        return "C 이하"

total = 0
for i in range(1, 11):        # 1부터 10까지 (끝 미포함)
    total += i ** 2           # 385

k, s = 0, 0
while s < 100:
    k += 1
    s += k                    # k = 14에서 멈춤

print(grade(85), total, k)   # B 385 14

블록은 콜론(:)과 들여쓰기(보통 공백 4칸)로 만듭니다. 함수 첫 줄의 문자열(독스트링)은 설명입니다.

예제 1.1.1

숫자 리스트를 받아 평균과 표본표준편차를 돌려주는 함수를 표준 라이브러리 없이 작성하세요.

def mean_sd(xs):
    n = len(xs)
    m = sum(xs) / n
    var = sum((x - m) ** 2 for x in xs) / (n - 1)
    return m, var ** 0.5

print(mean_sd([1, 3, 5, 7, 9]))   # (5.0, 3.1622776601683795)

함수는 값을 여러 개 묶어(튜플) 돌려줄 수 있습니다. (x - m) ** 2 for x in xs는 생성식으로, 리스트를 만들지 않고 합을 구합니다.

요약
  1. int, float, str, bool. 인덱스는 0부터.
  2. 콜론 + 들여쓰기로 블록.
  3. def로 함수, 여러 값은 튜플로 반환.
