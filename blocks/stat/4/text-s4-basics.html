본문

R로 분석을 배운 사람이 파이썬 코드를 처음 보면 두 가지에 당황한다. 리스트의 첫 원소가 xs[1]이 아니라 xs[0]이고, 중괄호 대신 들여쓰기가 블록을 정한다. 통계와 데이터 과학에서 R과 함께 가장 많이 쓰이는 파이썬은 어떤 규칙으로 움직일까?

먼저 알아야 할 것파이썬(Anaconda 또는 python.org)과 편집기(VS Code, Jupyter)를 설치해 둔다. 프로그래밍 경험은 필요 없다.

1.1.1자료형

파이썬은 문법이 간결하고, 자료 분석(pandas), 수치 계산(NumPy, SciPy), 머신러닝(scikit-learn) 도구가 풍부하다. 처음 질문의 첫째 규칙부터 보자. 기본 자료형은 정수, 실수, 문자열, 참과 거짓의 네 가지이다.

n = 10            # int (정수)
x = 3.14          # float (실수)
name = "통계"      # str (문자열)
ok = n > 5        # bool, True
print(type(x), 7 // 2, 7 % 2, 2 ** 10)   # <class 'float'> 3 1 1024
s = f"n = {n}, x = {x:.1f}"               # 형식 문자열 'n = 10, x = 3.1'

//는 몫, %는 나머지, **는 거듭제곱이다. 그리고 그림 1처럼 인덱스는 0부터 시작하며, 음수 인덱스 -1은 마지막 원소이다.

1.1.2조건, 반복, 함수

둘째 규칙은 들여쓰기이다. 블록은 콜론(:)과 들여쓰기(보통 공백 4칸)로 만든다. 그래서 들여쓰기를 잘못하면 오류가 나거나 다른 뜻이 된다.

def grade(score):
    """점수를 등급으로 바꾼다."""
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    else:
        return "C 이하"

total = 0
for i in range(1, 11):        # 1부터 10까지 (끝 미포함)
    total += i ** 2           # 385

k, s = 0, 0
while s < 100:
    k += 1
    s += k                    # k = 14에서 멈춤

print(grade(85), total, k)   # B 385 14

함수 첫 줄의 문자열(독스트링)은 설명이다. 또 range(1, 11)은 끝 값 11을 넣지 않는다는 점에 주의하자. 시작은 포함하고 끝은 빼는 것이 파이썬의 일관된 규칙이다.

예제 1.1.1

숫자 리스트를 받아 평균과 표본표준편차를 돌려주는 함수를 표준 라이브러리 없이 작성하여라.

def mean_sd(xs):
    n = len(xs)
    m = sum(xs) / n
    var = sum((x - m) ** 2 for x in xs) / (n - 1)
    return m, var ** 0.5

print(mean_sd([1, 3, 5, 7, 9]))   # (5.0, 3.1622776601683795)

풀이. 함수는 값을 여러 개 튜플로 묶어 돌려줄 수 있다. 여기서 (x - m) ** 2 for x in xs는 생성식으로, 리스트를 만들지 않고 합을 구한다.

흔한 실수들여쓰기에 탭과 공백을 섞으면 눈에는 같아 보여도 오류가 난다. 편집기에서 탭을 공백 4칸으로 바꾸도록 설정해 두자.
마무리

파이썬의 기본 자료형은 int, float, str, bool이고, 인덱스는 0부터 세며 range처럼 끝 값은 빼는 것이 규칙이다. 블록은 중괄호 대신 콜론과 들여쓰기로 만들고, if/elif/else, for, while, def로 작은 프로그램을 짠다. 함수는 여러 값을 튜플로 돌려줄 수 있다.
