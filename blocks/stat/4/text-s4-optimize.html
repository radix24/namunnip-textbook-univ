최적화 라이브러리로 효용·가능도 최대화

본문

감마분포의 최대가능도 추정값은 닫힌 꼴이 없어 손으로 구할 수 없다. 예산 제약 아래 효용을 최대화하는 문제도 변수가 많아지면 라그랑주 승수법으로 풀기 버겁다. 그런데 파이썬의 최적화 함수는 이름부터 minimize, 곧 최소화만 한다. 최대화 문제를 이 도구로 어떻게 풀까?

먼저 알아야 할 것근 찾기(4.1절), 최대가능도와 라그랑주 승수법(응통1 2.2절, 5.3절), NumPy(3.1절)를 쓴다.

4.2.1사용법

처음 질문의 답은 간단하다. \(g\)를 최대화하는 점은 \(-g\)를 최소화하는 점과 같으므로, 부호를 바꾸어 최소화하면 된다. 먼저 scipy.optimize.minimize의 사용법을 최소점을 아는 함수로 익히자.

import numpy as np
from scipy.optimize import minimize
def f(v):
    x, y = v
    return (x - 1) ** 2 + 2 * (y + 2) ** 2      # 최소점 (1, -2)
res = minimize(f, x0=[0, 0], method="BFGS")
res.x, res.fun, res.success                     # [1, -2], 0, True

함수는 변수 묶음 하나(배열)를 받아 수 하나를 돌려주어야 한다. 방법(method)은 문제에 따라 고른다. BFGS는 기울기로 곡률을 어림하는 준뉴턴 방법이고, Nelder-Mead는 기울기 없이 함숫값만 쓰며, L-BFGS-B는 변수 범위 제약을 받는다. 또 제약이 있으면 bounds, constraints 인수를 준다. 그리고 결과의 success와 message는 꼭 확인한다. 반복이 한도에 걸려 멈추어도 res.x에는 값이 들어 있기 때문이다.

4.2.2최대가능도

이제 감마분포의 문제로 돌아가자. 가능도를 최대화하는 것은 음의 로그가능도를 최소화하는 것과 같다.

예제 4.2.1

감마분포 자료의 형상 \(\alpha\)와 척도 \(\beta\)를 최대가능도로 추정하여라.

from scipy import stats
rng = np.random.default_rng(3)
x = rng.gamma(shape=2.5, scale=1.5, size=500)
def nll(theta):
    a, b = np.exp(theta)                 # 로그 척도로 받아 양수 보장
    return -np.sum(stats.gamma.logpdf(x, a, scale=b))
res = minimize(nll, x0=[0, 0], method="BFGS")
np.exp(res.x)                            # 약 [2.5, 1.5]
stats.gamma.fit(x, floc=0)               # 내장 함수로 확인 (형상, 위치, 척도)

풀이. 형상과 척도는 양수여야 하는데, 최적화 함수는 음수 쪽도 거리낌 없이 시험한다. 그래서 \(\theta = (\log\alpha, \log\beta)\)를 변수로 삼아 제약 없는 문제로 바꾸었다. 또 로그가능도는 곱 대신 합으로 계산해 아주 작은 수의 곱이 0이 되는 문제를 피한다. 시작점이 결과에 영향을 줄 수 있으므로 적률추정값(응통7 1.1절)에서 시작하면 더 좋다.

예제 4.2.2 (효용 극대화)

예산 \(2x + y = 10\) 아래 효용 \(U = \sqrt x + \sqrt y\)를 최대화하여라.

cons = {"type": "eq", "fun": lambda v: 2 * v[0] + v[1] - 10}
res = minimize(lambda v: -(np.sqrt(v[0]) + np.sqrt(v[1])), x0=[1, 1],
               bounds=[(0, None), (0, None)], constraints=cons, method="SLSQP")
res.x                                    # 약 [1.667, 6.667]

풀이. 등식 제약은 "eq"로 주고, 부등식과 등식 제약을 함께 다루는 SLSQP 방법을 쓴다. 라그랑주 승수법으로 풀면 한계효용의 비 \(\sqrt{y/x} = 2\)에서 \(y = 4x\)이고, 예산에 넣어 \(x = 5/3\), \(y = 20/3\)을 얻어 같은 답이다(그림 1).

주의minimize는 지역 최소점을 찾는다. 가능도가 여러 봉우리를 가지면 시작점에 따라 다른 답이 나오므로, 여러 시작점에서 돌려 가장 작은 값을 고르는 것이 안전하다.
마무리

최적화 라이브러리는 최소화만 하므로, 효용이나 가능도를 최대화할 때는 부호를 바꾸어 minimize(f, x0, method)에 넘긴다. 최대가능도는 음의 로그가능도를 최소화해 구하고, 양수 모수는 로그 척도로 바꾸어 제약을 없앤다. 범위와 등식, 부등식 제약은 bounds와 constraints(SLSQP)로 주며, 결과의 success와 시작점의 영향을 늘 확인한다.

4.2.3연습문제

기본

  1. 포아송 자료 x의 \(\lambda\)를 minimize_scalar로 추정하고 표본평균과 비교하여라.
    답

    minimize_scalar(lambda l: -np.sum(stats.poisson.logpmf(x, l)), bounds=(1e-6, 100), method="bounded")의 결과가 x.mean()과 같다. 포아송의 최대가능도 추정값은 표본평균이기 때문이다.

응용

  1. 예제 4.2.2에서 예산이 10에서 12로 늘면 최적의 \(x\), \(y\)와 최대 효용은 어떻게 되는가?
    답

    여전히 \(y = 4x\)이므로 \(6x = 12\)에서 \(x = 2\), \(y = 8\)이고 효용은 \(\sqrt2 + \sqrt8 = 3\sqrt2 \approx 4.24\)이다.
