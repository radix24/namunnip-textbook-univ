최적화 라이브러리로 효용·가능도 최대화

본문
이 절에서 배울 것
  • scipy.optimize.minimize로 다변수 함수를 최소화한다.
  • 음의 로그가능도를 최소화해 최대가능도 추정값을 구한다.
먼저 알아야 할 것
  • 근 찾기 (4.1절), 최대가능도 (응통1 2.2절).

최대화는 최소화의 거울

최적화 라이브러리는 보통 최소화만 합니다. 가능도나 효용을 최대화하려면 부호를 바꿔 최소화합니다.

4.2.1사용법

import numpy as np
from scipy.optimize import minimize
def f(v):
    x, y = v
    return (x - 1) ** 2 + 2 * (y + 2) ** 2      # 최소점 (1, -2)
res = minimize(f, x0=[0, 0], method="BFGS")
res.x, res.fun, res.success                     # [1, -2], 0, True

주요 방법: BFGS(기울기 사용, 준뉴턴), Nelder-Mead(기울기 없이), L-BFGS-B(변수 범위 제약). 제약이 있으면 bounds, constraints 인수를 줍니다. 결과의 success와 message를 꼭 확인합니다.

4.2.2최대가능도

예제 4.2.1

감마분포 자료의 형상 \(\alpha\)와 척도 \(\beta\)를 최대가능도로 추정하세요.

from scipy import stats
rng = np.random.default_rng(3)
x = rng.gamma(shape=2.5, scale=1.5, size=500)
def nll(theta):
    a, b = np.exp(theta)                 # 로그 척도로 받아 양수 보장
    return -np.sum(stats.gamma.logpdf(x, a, scale=b))
res = minimize(nll, x0=[0, 0], method="BFGS")
np.exp(res.x)                            # 약 [2.5, 1.5]
stats.gamma.fit(x, floc=0)               # 내장 함수로 확인 (형상, 위치, 척도)

모수에 범위 제약(양수)이 있으면 로그를 취한 척도에서 최적화하면 편합니다. 시작점이 결과에 영향을 줄 수 있으므로 적률추정값(응통7 1.1절)에서 시작하는 것이 좋습니다.

예제 4.2.2 (효용 극대화)

예산 \(2x + y = 10\) 아래 효용 \(U = \sqrt x + \sqrt y\)를 최대화하세요.

cons = {"type": "eq", "fun": lambda v: 2 * v[0] + v[1] - 10}
res = minimize(lambda v: -(np.sqrt(v[0]) + np.sqrt(v[1])), x0=[1, 1],
               bounds=[(0, None), (0, None)], constraints=cons, method="SLSQP")
res.x                                    # 약 [1.667, 6.667]

라그랑주 승수법(응통1 5.3절)으로 풀면 \(y = 4x\), \(x = 5/3\), \(y = 20/3\)으로 같습니다.

요약
  1. minimize(f, x0, method), 최대화는 부호를 바꿈.
  2. 음의 로그가능도를 최소화해 MLE, 양수 모수는 로그 척도로.
  3. 제약: bounds, constraints(SLSQP).
