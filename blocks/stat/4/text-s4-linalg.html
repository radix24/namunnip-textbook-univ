행렬 연산과 난수 생성

본문

회귀계수는 정규방정식 \(X^{\mathsf T}X\beta = X^{\mathsf T}y\)의 해이다. 손으로는 2×2만 풀어도 번거롭지만, 변수가 열 개라면? 그리고 방법을 시험하려면 참값을 아는 가상 자료가 필요한데, 오늘 만든 난수를 내일 똑같이 다시 만들 수 있을까?

먼저 알아야 할 것NumPy 배열(3.1절)과 응통2의 행렬 곱, 역행렬, 고유값을 쓴다.

3.2.1행렬 연산

응통2에서 손으로 계산한 행렬 곱, 연립방정식, 고유값을 NumPy로 바로 확인할 수 있다.

import numpy as np
A = np.array([[2., 1.], [1., 2.]])
b = np.array([3., 3.])
A @ b                      # 행렬 곱 (* 는 원소별 곱)
np.linalg.solve(A, b)      # A x = b의 해 array([1., 1.])
np.linalg.det(A)           # 3.0
vals, vecs = np.linalg.eigh(A)   # 대칭 행렬 고유분해, vals = [1, 3]
U, s, Vt = np.linalg.svd(A)

@는 행렬 곱이고 *는 원소별 곱이다. 둘을 헷갈리면 오류 없이 엉뚱한 값이 나오므로 특히 조심하자. 또 \(A^{-1}b\)를 구할 때 역행렬을 만들어 곱하는 inv(A) @ b보다 solve가 빠르고 반올림 오차도 적다(응통15 2.1절). 한편 대칭 행렬에는 eig 대신 eigh를 쓰면 실수 고유값이 오름차순으로 나온다.

3.2.2난수

처음 질문의 둘째 부분은 씨앗(seed)으로 해결한다. 컴퓨터의 난수는 정해진 규칙으로 만드는 의사난수이므로, 같은 씨앗에서 시작하면 늘 같은 수열이 나온다.

rng = np.random.default_rng(seed=2026)    # 씨앗을 정하면 재현 가능
rng.normal(loc=10, scale=2, size=5)       # 정규 (scale = 표준편차)
rng.binomial(n=20, p=0.3, size=5)
rng.exponential(scale=1/0.5, size=5)      # 비율 0.5이면 scale 2
rng.choice([1, 2, 3], size=10, replace=True)
rng.permutation(10)

예전 방식인 np.random.seed()와 np.random.normal()보다 생성기 객체 default_rng를 쓰는 것이 권장된다. 생성기마다 상태를 따로 가지므로 여러 시뮬레이션이 서로 간섭하지 않기 때문이다. 그런데 분포마다 모수 이름이 달라, 정규분포의 scale은 표준편차이고 지수분포의 scale은 비율이 아니라 평균이다.

예제 3.2.1

가상 자료 \(y = 1 + 2x + \varepsilon\)(\(n = 100\))을 만들고 정규방정식으로 회귀계수를 구하여라.

rng = np.random.default_rng(1)
x = rng.uniform(0, 10, 100)
y = 1 + 2 * x + rng.normal(0, 1, 100)
X = np.column_stack([np.ones(100), x])
beta = np.linalg.solve(X.T @ X, X.T @ y)   # 약 [1, 2]
np.linalg.lstsq(X, y, rcond=None)[0]       # QR/SVD 기반, 같은 값

풀이. 절편을 위해 1로 된 열을 붙여 설계행렬 \(X\)를 만들고, 정규방정식을 solve로 푼다. 추정값은 참값 (1, 2) 가까이 나오며(그림 1), 씨앗이 같으면 몇 번을 돌려도 같은 값이다. 변수가 열 개여도 코드는 열을 더 붙이는 것 말고는 똑같다.

주의설명변수끼리 거의 비례하면 \(X^{\mathsf T}X\)가 특이 행렬에 가까워져 정규방정식의 해가 크게 흔들린다. 이런 경우에는 \(X^{\mathsf T}X\)를 만들지 않고 QR이나 SVD로 푸는 lstsq가 더 안정하다.
마무리

NumPy에서 행렬 곱은 @이고, 연립방정식은 역행렬 대신 solve로 풀며, 고유분해와 특잇값 분해는 eigh와 svd, 최소제곱은 lstsq로 구한다. 난수는 default_rng(seed) 생성기로 만들면 재현되고, 분포마다 scale 같은 모수 이름의 뜻을 확인해야 한다. 참값을 아는 가상 자료로 회귀를 시험하는 것이 두 도구를 함께 쓰는 대표적인 예이다.

3.2.3연습문제

기본

  1. A = np.array([[2., 1.], [1., 2.]])에서 A * A와 A @ A의 (1, 1) 원소는 각각 얼마인가?
    답

    원소별 곱은 \(2 \times 2 = 4\)이고, 행렬 곱은 \(2 \cdot 2 + 1 \cdot 1 = 5\)이다.

응용

  1. 상관 0.7인 이변량 표준정규 난수 1000쌍을 촐레스키 분해로 만드는 코드를 써라.
    답

    L = np.linalg.cholesky(np.array([[1, .7], [.7, 1]])), Z = rng.standard_normal((1000, 2)), XY = Z @ L.T이다. np.corrcoef(XY.T)로 0.7 가까이 나오는지 확인한다.
