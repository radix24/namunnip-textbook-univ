자료와 동작을 한 덩어리로

pandas의 데이터프레임은 df.mean(), df.plot()처럼 자기 자료를 다루는 함수를 함께 가지고 있습니다. 이런 덩어리를 객체라 하고, 객체의 설계도를 클래스라 합니다.

2.2.1클래스 만들기

class Sample:
    """숫자 표본과 그 요약을 담는 객체."""
    def __init__(self, data):          # 객체를 만들 때 실행
        self.data = list(data)

    def mean(self):
        return sum(self.data) / len(self.data)

    def var(self):
        m = self.mean()
        return sum((x - m) ** 2 for x in self.data) / (len(self.data) - 1)

    def add(self, x):                  # 자료를 바꾸는 메서드
        self.data.append(x)

    def __repr__(self):                # print 했을 때 보이는 모습
        return f"Sample(n={len(self.data)}, mean={self.mean():.2f})"

s = Sample([1, 3, 5, 7, 9]); print(s, s.var())    # Sample(n=5, mean=5.00) 10.0
s.add(11); print(s)                               # Sample(n=6, mean=6.00)

self는 그 객체 자신입니다. self.data처럼 객체에 붙은 변수를 속성, 객체에 붙은 함수를 메서드라 합니다.

2.2.2상속

기존 클래스를 넓혀 새 클래스를 만들 수 있습니다. class WeightedSample(Sample):로 정의하면 Sample의 메서드를 그대로 물려받고, 필요한 것(mean을 가중평균으로)만 다시 정의합니다.

요약
  1. 클래스 = 속성(자료) + 메서드(동작).
  2. __init__으로 초기화, self로 자신을 가리킴.
  3. 상속으로 기존 클래스를 넓힘.
