클래스와 객체

본문

pandas의 데이터프레임 df는 df.mean(), df.plot()처럼 자기 자료를 다루는 함수를 스스로 지니고 있다. 반면 1.1절의 mean_sd(xs)는 자료를 밖에서 넘겨받았다. 자료와 그것을 다루는 동작을 한 덩어리로 묶으면 무엇이 좋아질까? 그런 덩어리는 어떻게 만들까?

먼저 알아야 할 것함수와 모듈(2.1절)을 쓴다.

2.2.1클래스 만들기

자료와 그 자료를 다루는 함수를 묶은 덩어리를 객체라 하고, 객체의 설계도를 클래스라 한다. 객체에 붙은 변수를 속성, 객체에 붙은 함수를 메서드라 부른다. 그림 1의 Sample을 코드로 쓰면 다음과 같다.

class Sample:
    """숫자 표본과 그 요약을 담는 객체."""
    def __init__(self, data):          # 객체를 만들 때 실행
        self.data = list(data)
    def mean(self):
        return sum(self.data) / len(self.data)
    def var(self):
        m = self.mean()
        return sum((x - m) ** 2 for x in self.data) / (len(self.data) - 1)
    def add(self, x):                  # 자료를 바꾸는 메서드
        self.data.append(x)
    def __repr__(self):                # print 했을 때 보이는 모습
        return f"Sample(n={len(self.data)}, mean={self.mean():.2f})"

s = Sample([1, 3, 5, 7, 9]); print(s, s.var())    # Sample(n=5, mean=5.00) 10.0
s.add(11); print(s)                               # Sample(n=6, mean=6.00)

메서드의 첫 인자 self는 그 객체 자신이다. 그래서 s.mean()을 부르면 파이썬이 Sample.mean(s)로 바꾸어 실행하고, 메서드는 self.data로 자기 자료를 찾는다. 처음 질문의 답이 여기 있다. 자료를 일일이 넘기지 않아도 되고, add로 자료를 바꾸면 mean과 var가 늘 바뀐 자료로 계산하므로 자료와 요약이 어긋날 일이 없다.

2.2.2상속

한편 기존 클래스를 넓혀 새 클래스를 만들 수도 있다. class WeightedSample(Sample):로 정의하면 Sample의 메서드를 그대로 물려받고, 필요한 것만 다시 정의한다.

예제 2.2.1

가중치를 함께 받는 WeightedSample을 만들어 mean만 가중평균으로 바꾸어라.

class WeightedSample(Sample):
    def __init__(self, data, w):
        super().__init__(data)         # 부모의 초기화를 그대로 쓴다
        self.w = list(w)
    def mean(self):
        return sum(x * w for x, w in zip(self.data, self.w)) / sum(self.w)

ws = WeightedSample([1, 2, 3], [1, 1, 2]); print(ws)   # Sample(n=3, mean=2.25)

풀이. 가중평균은 \((1 + 2 + 6)/4 = 2.25\)이다. __repr__은 다시 쓰지 않았지만 물려받았고, 그 안의 self.mean()은 새 정의를 부른다. 그래서 출력에 가중평균이 나온다.

흔한 실수메서드를 정의할 때 self를 빠뜨리면 s.mean()을 부를 때 인자 개수가 맞지 않는다는 TypeError가 난다. 메서드의 첫 인자는 늘 self이다.
마무리

클래스는 속성(자료)과 메서드(동작)를 묶은 설계도이고, 그것으로 만든 하나하나가 객체이다. __init__이 객체를 만들 때 속성을 채우고, 메서드는 self로 자기 자료를 찾으므로 자료를 바꿔도 요약이 어긋나지 않는다. 상속으로 기존 클래스를 넓히면 필요한 메서드만 다시 정의하고 나머지는 물려받는다.
