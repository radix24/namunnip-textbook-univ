모듈과 패키지

본문

1.1절에서 평균과 표준편차를 구하는 함수를 직접 짰다. 그런데 분석 파일을 새로 만들 때마다 그 함수를 복사해 붙여야 할까? 그리고 난수, 날짜, 행렬 계산처럼 누군가 이미 잘 만들어 둔 도구는 어떻게 가져다 쓸까?

먼저 알아야 할 것함수(1.1절)를 쓴다.

2.1.1불러오기

파이썬의 힘은 언어 자체보다 그림 1의 왼쪽 출처들에서 나온다. 평균, 난수, 날짜 계산은 표준 라이브러리에 이미 있고, 수치 계산과 자료 분석 도구는 외부 패키지로 수십만 개가 공개되어 있다. 이것을 쓰려면 import로 불러온다.

import math
from statistics import mean, stdev
import random as rd
import numpy as np            # 외부 패키지, pip install numpy (Anaconda에는 포함)
math.sqrt(2); mean([1, 2, 3]); rd.seed(1); rd.random()

import math는 모듈 전체를 불러 math.sqrt처럼 이름을 붙여 쓰고, from ... import는 함수만 꺼내 오며, as는 짧은 별칭을 붙인다. 외부 패키지는 터미널에서 pip install 패키지명이나 conda install로 설치한다. 그런데 프로젝트마다 필요한 버전이 다를 수 있으므로, 프로젝트마다 가상 환경(python -m venv .venv)을 만들어 패키지를 따로 둔다.

2.1.2나만의 모듈

이제 처음 질문의 첫째 부분에 답하자. 함수를 .py 파일 하나에 모아 두면 그 파일이 곧 모듈이다. 같은 폴더에 mystats.py를 만들면 다른 파일에서 불러 쓸 수 있다.

# mystats.py
def mean_sd(xs):
    n = len(xs); m = sum(xs) / n
    return m, (sum((x - m) ** 2 for x in xs) / (n - 1)) ** 0.5

if __name__ == "__main__":          # 직접 실행할 때만 동작하는 시험 코드
    print(mean_sd([1, 3, 5, 7, 9]))

# analysis.py
from mystats import mean_sd
print(mean_sd([2, 4, 6]))           # (4.0, 2.0)

파일을 직접 실행하면 __name__이 "__main__"이 되고, 다른 파일이 불러오면 모듈 이름이 된다. 그래서 if __name__ == "__main__": 아래의 시험 코드는 모듈로 불러올 때는 실행되지 않으며, 함수 정의와 시험 코드를 한 파일에 둘 수 있다.

예제 2.1.1

표준 라이브러리 statistics로 [2, 4, 4, 4, 5, 5, 7, 9]의 중앙값과 모표준편차를 구하여라.

import statistics as st
xs = [2, 4, 4, 4, 5, 5, 7, 9]
st.median(xs), st.pstdev(xs)        # (4.5, 2.0)

풀이. 짝수 개이므로 중앙값은 가운데 두 값 4와 5의 평균 4.5이다. 또 평균 5에서의 제곱 편차 합이 32이고 \(n = 8\)로 나누면 4이므로 모표준편차는 2이다. 표본표준편차가 필요하면 \(n - 1\)로 나누는 st.stdev를 쓴다.

흔한 실수내 파일 이름을 random.py나 statistics.py처럼 표준 모듈과 같게 지으면, import random이 표준 모듈 대신 내 파일을 불러와 엉뚱한 오류가 난다. 모듈 이름은 겹치지 않게 짓자.
마무리

도구는 import, from ... import, as 별칭으로 불러온다. 표준 라이브러리는 설치 없이 쓰고, 외부 패키지는 pip이나 conda로 설치하되 프로젝트마다 가상 환경으로 나눈다. 자주 쓰는 함수는 .py 파일로 모아 모듈로 불러 쓰고, 시험 코드는 if __name__ == "__main__": 아래에 두면 불러올 때 실행되지 않는다.

2.1.3연습문제

기본

  1. from math import sqrt로 불러온 뒤 \(\sqrt{2}\)를 구하는 식과, import math로 불러온 뒤의 식을 각각 써라.
    답

    앞의 경우 sqrt(2), 뒤의 경우 math.sqrt(2)이다.

응용

  1. mystats.py에서 if __name__ == "__main__":을 빼고 시험 코드를 맨 아래에 그냥 두면 analysis.py를 실행할 때 무엇이 출력되는가?
    답

    불러오는 순간 시험 코드가 실행되어 (5.0, 3.1622776601683795)가 먼저 찍히고, 그다음 (4.0, 2.0)이 찍힌다.
