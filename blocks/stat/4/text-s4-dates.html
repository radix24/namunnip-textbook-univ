pandas로 날짜와 시계열 다루기

본문
이 절에서 배울 것
  • 문자열 열을 날짜형으로 바꾸고 연, 월, 요일을 뽑는다.
  • 날짜를 인덱스로 두고 일별 자료를 주·월 단위로 다시 묶는다.
  • 이동 평균과 증감률을 계산한다.
먼저 알아야 할 것
  • pandas 기초와 groupby (5.1절, 5.2절).

시간 순서가 있는 표

매출, 방문자, 센서 값은 거의 모두 시각과 함께 기록됩니다. 날짜를 날짜형으로 다루면 "월별 합계", "지난주 대비 증가율" 같은 계산이 한 줄로 끝납니다.

5.4.1날짜형으로 바꾸기

import pandas as pd
df = pd.DataFrame({"date": ["2026-03-01", "2026-03-02", "2026-03-08", "2026-03-09"],
                   "sales": [30, 20, 50, 10]})
df["date"] = pd.to_datetime(df["date"])
df["dow"] = df["date"].dt.dayofweek      # 월 = 0, …, 일 = 6
df["month"] = df["date"].dt.month
df.groupby("dow")["sales"].sum()         # 0: 30, 6: 80

형식이 다르면 pd.to_datetime(s, format="%d/%m/%Y")처럼 지정합니다. .dt 접근자로 year, day_name(), quarter 등을 뽑습니다. 날짜끼리 빼면 Timedelta가 되어 .dt.days로 일수를 얻습니다.

5.4.2다시 묶기와 이동 계산

ts = df.set_index("date")["sales"]
ts.resample("W").sum()          # 주 단위 합계(기본은 일요일에 끝나는 주)
ts.resample("MS").mean()        # 월초 기준 월평균
ts.rolling(7).mean()            # 7개 관측 이동 평균
ts.pct_change()                 # 직전 대비 증감률
ts.shift(1)                     # 한 칸 미루기(전날 값)

resample은 시간 단위의 groupby입니다. 빠진 날짜가 있으면 rolling(7)은 "관측 7개"라 7일과 다를 수 있으므로, rolling("7D")로 기간을 지정하거나 asfreq("D")로 빈 날을 먼저 채웁니다.

예제 5.4.1

위 자료에서 3월 1일과 8일이 같은 요일인지, 두 날의 매출 증가율은 얼마인지 구하세요.

풀이. 두 날 모두 dayofweek 6(일요일)입니다(7일 차이). 증가율 \((50 - 30)/30 = 66.7\%\). 같은 요일끼리 비교해야 요일 효과(응통17 5.4절의 계절)를 빼고 볼 수 있습니다: ts.pct_change(periods=2)는 이 자료에서 두 칸 전과 비교합니다.

요약
  1. pd.to_datetime과 .dt로 날짜 요소 추출.
  2. resample(시간 단위 묶기), rolling, pct_change, shift.
  3. 빠진 날짜를 확인하고 같은 요일·같은 달끼리 비교합니다.

5.4.3연습문제

기본

  1. 주문일 열 order와 배송일 열 ship(둘 다 날짜형)이 있을 때 배송 소요일 평균을 구하는 코드를 쓰세요.
    답

    (df["ship"] - df["order"]).dt.days.mean().

응용

  1. 일별 자료에 주말 매출이 없는 날(행 자체가 없음)이 있습니다. rolling(7).mean()이 왜 틀릴 수 있고 어떻게 고치나요?
    답

    관측 7개가 9~10일에 걸칠 수 있습니다. ts.asfreq("D", fill_value=0)으로 빈 날을 0(또는 결측)으로 채운 뒤 계산하거나 rolling("7D")를 씁니다.
