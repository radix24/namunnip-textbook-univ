붓스트랩과 순열 검정을 파이썬으로

본문
이 절에서 배울 것
  • np.random.default_rng로 재현 가능한 난수 생성기를 만든다.
  • 벡터화로 붓스트랩 표본을 한꺼번에 뽑아 신뢰구간을 구한다.
  • 순열 검정을 구현하고 scipy.stats.permutation_test와 비교한다.
먼저 알아야 할 것
  • 모의실험 (6.2절), 배열 인덱싱 (3.3절).

R에서 한 일을 파이썬으로

응통3 4.3절에서 R로 한 재표집을 파이썬으로 옮깁니다. NumPy에서는 반복문 대신 2차원 배열로 표본을 한꺼번에 뽑으면 훨씬 빠릅니다.

6.3.1난수 생성기

import numpy as np
rng = np.random.default_rng(2026)   # 시드가 있는 생성기
rng.integers(0, 10, size=5)          # 정수
rng.choice([1, 2, 3], size=5, replace=True)
rng.permutation(5)                   # 0~4를 섞기

예전 방식 np.random.seed보다 생성기 객체를 쓰는 것이 권장됩니다. 함수에 rng를 인자로 넘기면 어디서 난수를 썼는지 분명해집니다.

6.3.2붓스트랩

x = np.array([12, 15, 9, 20, 14, 11, 30, 13, 10, 16])
B = 5000
idx = rng.integers(0, len(x), size=(B, len(x)))   # B × n 복원 추출 번호
boot = np.median(x[idx], axis=1)                   # 행마다 중앙값
boot.std(ddof=1), np.percentile(boot, [2.5, 97.5])

6.3.3순열 검정

a = np.array([12, 15, 18]); b = np.array([20, 22, 25])
obs = b.mean() - a.mean()
allv = np.concatenate([a, b])
perm = np.array([ (p := rng.permutation(allv))[3:].mean() - p[:3].mean()
                  for _ in range(10000) ])
(perm >= obs).mean()                               # 약 0.05

from scipy.stats import permutation_test
permutation_test((b, a), lambda u, v: u.mean() - v.mean(),
                 alternative="greater").pvalue     # 작은 표본은 정확 계산: 0.05

permutation_test는 가능한 배치 수가 적으면 모두 세서 정확한 p값을 줍니다. 이 자료는 \(\binom63 = 20\)가지라 \(1/20 = 0.05\)입니다(응통3 4.3절과 같은 결과).

예제 6.3.1

idx = rng.integers(0, 10, size=(5000, 10))은 몇 개의 난수를 만들고, 반복문으로 5000번 뽑는 것과 무엇이 다른가요?

풀이. 50000개를 한 번에 만듭니다. 결과의 통계적 성질은 같지만 계산이 C 수준 반복으로 처리되어 수십 배 빠릅니다. 메모리가 \(B \times n\)만큼 필요하므로 \(n\)이 아주 크면 묶음으로 나눠 처리합니다.

요약
  1. rng = np.random.default_rng(시드)로 재현성.
  2. 번호 행렬 x[idx]와 axis=1로 붓스트랩을 벡터화.
  3. permutation_test는 작은 표본에서 정확 p값.

6.3.4연습문제

기본

  1. 평균의 붓스트랩 표준오차를 구하는 한 줄 코드를 쓰세요(x, rng, B가 있음).
    답

    x[rng.integers(0, len(x), (B, len(x)))].mean(axis=1).std(ddof=1).

응용

  1. 같은 시드로 두 번 실행했는데 붓스트랩 결과가 다릅니다. 가능한 원인은?
    답

    생성기를 만든 뒤 다른 곳에서 난수를 먼저 소비해 위치가 달라졌거나, 생성기를 함수마다 새로 만들지 않고 전역으로 공유했을 수 있습니다. 분석 단계마다 생성기를 명시적으로 넘기거나 같은 시드로 새로 만듭니다.
