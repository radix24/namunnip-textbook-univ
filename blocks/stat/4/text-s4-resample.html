붓스트랩과 순열 검정을 파이썬으로

본문

통근 시간 10개 [12, 15, 9, 20, 14, 11, 30, 13, 10, 16]의 중앙값은 13.5분이다. 30분짜리 값 하나가 끼어 있어 평균보다 중앙값이 대표값으로 낫지만, 중앙값의 표준오차에는 간단한 공식이 없다. 응통3에서 R로 했던 재표집을 파이썬으로 옮기면, 반복문 5000번 없이 한 번에 계산할 수 있을까?

먼저 알아야 할 것모의실험(6.2절), 팬시 인덱싱(3.3절), 응통3 4.3절의 붓스트랩과 순열 검정을 쓴다.

6.3.1난수 생성기

재표집은 난수를 많이 쓰므로 결과를 다시 만들 수 있게 생성기를 먼저 정한다(3.2절).

import numpy as np
rng = np.random.default_rng(2026)   # 시드가 있는 생성기
rng.integers(0, 10, size=5)          # 정수
rng.choice([1, 2, 3], size=5, replace=True)
rng.permutation(5)                   # 0~4를 섞기

분석 함수에 rng를 인자로 넘기면 어디서 난수를 썼는지 분명해지고, 같은 시드로 같은 결과를 다시 얻는다.

6.3.2붓스트랩

처음 질문의 핵심 기법은 복원 추출할 번호를 행렬 하나로 한꺼번에 뽑는 것이다. \(B \times n\) 번호 행렬 idx로 x[idx]를 만들면 행 하나가 붓스트랩 표본 하나가 되고, axis=1로 행마다 중앙값을 낸다.

x = np.array([12, 15, 9, 20, 14, 11, 30, 13, 10, 16])
B = 5000
idx = rng.integers(0, len(x), size=(B, len(x)))   # B × n 복원 추출 번호
boot = np.median(x[idx], axis=1)                   # 행마다 중앙값
boot.std(ddof=1), np.percentile(boot, [2.5, 97.5])

붓스트랩 중앙값들의 표준편차가 중앙값의 표준오차 추정값이고, 2.5%와 97.5% 백분위수가 백분위 신뢰구간이다. 그림 1을 그린 실행에서는 표준오차가 약 1.6분, 구간이 [11, 17.5]분이었다. 실행마다 값이 조금씩 다르므로, \(B\)를 늘려 소수 첫째 자리가 안정되는지 확인한다.

6.3.3순열 검정

이번에는 두 집단 비교이다. 귀무가설 아래에서는 집단 이름표가 아무 의미가 없으므로, 이름표를 뒤섞어 얻는 차이들과 관측한 차이를 비교한다.

a = np.array([12, 15, 18]); b = np.array([20, 22, 25])
obs = b.mean() - a.mean()
allv = np.concatenate([a, b])
perm = np.array([(p := rng.permutation(allv))[3:].mean() - p[:3].mean()
                 for _ in range(10000)])
(perm >= obs).mean()                               # 약 0.05
from scipy.stats import permutation_test
permutation_test((b, a), lambda u, v: u.mean() - v.mean(),
                 alternative="greater").pvalue     # 작은 표본은 정확 계산, 0.05

관측 차이는 \(22.33 - 15 = 7.33\)이다. 여섯 값을 세 개씩 나누는 방법은 \(\binom63 = 20\)가지이고, 그 가운데 차이가 7.33 이상인 것은 실제 배치 하나뿐이다. 그래서 정확한 p값은 \(1/20 = 0.05\)이다. permutation_test는 이렇게 배치 수가 적으면 모두 세어 정확한 값을 주고, 많으면 무작위로 뽑는다. 응통3 4.3절과 같은 결과이다.

예제 6.3.1

idx = rng.integers(0, 10, size=(5000, 10))은 난수를 몇 개 만들고, 반복문으로 5000번 뽑는 것과 무엇이 다른가?

풀이. 50000개를 한 번에 만든다. 결과의 통계적 성질은 같지만 계산이 C 수준의 반복으로 처리되어 수십 배 빠르다. 대신 메모리가 \(B \times n\)만큼 필요하므로 \(n\)이 아주 크면 묶음으로 나누어 처리한다.

주의자료가 작을 때 중앙값의 붓스트랩 분포는 그림 1처럼 몇 개의 값에만 몰려 매끄럽지 않다. 그러면 백분위 구간이 자료 값의 간격에 크게 좌우되므로, 표본이 아주 작을 때는 구간을 대략적인 어림으로 읽는다.
마무리

재표집은 default_rng(시드) 생성기로 재현성을 확보하고 시작한다. 붓스트랩은 \(B \times n\) 번호 행렬로 x[idx]를 만든 뒤 axis=1로 통계량을 계산해 반복문 없이 벡터화하며, 그 표준편차와 백분위수가 표준오차와 신뢰구간이다. 순열 검정은 이름표를 섞어 관측 차이와 비교하고, scipy.stats.permutation_test는 배치 수가 적으면 정확한 p값을 준다.

6.3.4연습문제

기본

  1. 평균의 붓스트랩 표준오차를 구하는 한 줄 코드를 써라(x, rng, B가 있다).
    답

    x[rng.integers(0, len(x), (B, len(x)))].mean(axis=1).std(ddof=1)이다.

응용

  1. 같은 시드로 두 번 실행했는데 붓스트랩 결과가 다르다. 가능한 원인은 무엇인가?
    답

    생성기를 만든 뒤 다른 곳에서 난수를 먼저 써 수열의 위치가 달라졌거나, 생성기를 전역으로 공유해 실행 순서에 따라 소비량이 달라졌을 수 있다. 분석 단계마다 생성기를 명시적으로 넘기거나 같은 시드로 새로 만든다.
