모의실험으로 확률 계산 검증하기

본문

한 반 23명 가운데 생일이 같은 사람이 있을 확률은 얼마일까? 많은 사람이 10% 안팎이라고 답하지만 실제로는 절반이 넘는다. 확률은 이렇게 직관이 자주 틀리는 분야이다. 내 계산이 맞는지 공식을 다시 보지 않고 확인할 방법은 없을까?

먼저 알아야 할 것NumPy 난수(3.2절)와 불리언 마스크(3.3절)를 쓴다.

6.2.1생일 문제

처음 질문의 답은 확률 실험을 컴퓨터로 수만 번 되풀이하는 것이다. 사건을 난수로 흉내 내고 그 사건이 일어난 비율을 세면, 큰 수의 법칙에 따라 비율이 확률로 다가간다. 이를 모의실험(몬테카를로 방법)이라 한다. 먼저 정확한 값을 구하자. 모두 생일이 다를 확률은 첫 사람부터 차례로 겹치지 않을 확률을 곱한 것이므로, 같은 사람이 있을 확률은 다음과 같다.

\[1 - \frac{365 \cdot 364 \cdots 343}{365^{23}} \approx 0.507\] 
import numpy as np
rng = np.random.default_rng(0)
B, n = 100_000, 23
days = rng.integers(0, 365, size=(B, n))
has_dup = np.array([len(set(r)) < n for r in days])
p = has_dup.mean(); se = np.sqrt(p * (1 - p) / B)
print(f"{p:.4f} ± {1.96 * se:.4f}")       # 약 0.507 ± 0.003
exact = 1 - np.prod((365 - np.arange(n)) / 365)
print(round(exact, 4))                    # 0.5073

한 행이 한 반이다. 집합으로 바꾸었을 때 원소가 23개보다 적으면 겹친 생일이 있다는 뜻이다. 여기서 중요한 것은 추정값만 보고하지 않는다는 점이다. 모의실험의 비율은 이항 비율이므로 표준오차가 \(\sqrt{p(1-p)/B}\)이고, \(B = 10^5\)이면 95% 오차 폭이 약 ±0.003이다. 그림 1처럼 정확도를 한 자리 늘리려면 \(B\)를 100배로 늘려야 한다.

6.2.2몬티 홀 문제

세 문 가운데 하나 뒤에 자동차가 있다. 참가자가 문 하나를 고르면, 답을 아는 사회자가 남은 두 문 가운데 염소가 있는 문을 열고 바꿀 기회를 준다. 바꾸는 것이 나을까?

B = 100_000
car = rng.integers(0, 3, B); pick = rng.integers(0, 3, B)
stay_win = (car == pick).mean()          # 약 1/3
switch_win = 1 - stay_win                # 바꾸면 약 2/3 (사회자가 늘 염소 문을 열므로)
print(stay_win, switch_win)

처음 고른 문이 맞을 확률은 1/3이다. 그런데 사회자는 늘 염소 문을 열므로, 처음 선택이 틀렸다면(확률 2/3) 남은 문이 반드시 자동차이다. 그래서 바꾸는 전략은 2/3의 확률로 이긴다. 많은 사람이 남은 두 문이라 1/2이라고 믿었던 문제이지만, 모의실험은 논쟁 없이 답을 보여 준다.

예제 6.2.1

주사위 두 개의 합이 7일 확률을 \(B = 10^5\)번의 모의실험으로 구하고 정답 1/6과 비교하여라.

s = rng.integers(1, 7, B) + rng.integers(1, 7, B)
p = (s == 7).mean()          # 약 0.167
1.96 * np.sqrt(p * (1 - p) / B)   # 약 0.0023

풀이. integers(1, 7)은 끝 7을 빼므로 1부터 6까지이다. 추정값이 \(1/6 \approx 0.1667\)에서 ±0.0023 안에 들면 계산과 실험이 서로 맞는다고 본다. 만약 벗어나면 계산과 코드 가운데 하나가 틀렸다는 신호이다.

주의모의실험은 확률 모형을 코드로 옮긴 것이므로, 모형을 잘못 옮기면 틀린 답을 정밀하게 얻는다. 몬티 홀 문제에서 사회자가 아무 문이나 열어 우연히 염소가 나온 경우라면 답은 1/2이 된다. 문제의 조건을 코드에 정확히 담아야 한다.
마무리

모의실험은 사건을 난수로 흉내 내고 일어난 비율을 세어 확률을 어림하는 방법이다. 추정값은 표준오차 \(\sqrt{p(1-p)/B}\)와 함께 보고하며, 오차는 \(1/\sqrt B\)로 줄어 한 자리를 더 얻으려면 반복을 100배로 늘려야 한다. 생일 문제와 몬티 홀 문제처럼 직관이 틀리기 쉬운 계산은 정확한 계산과 모의실험을 함께 해 서로 검증한다.

6.2.3연습문제

기본

  1. 모의실험으로 \(p \approx 0.5\)를 오차 폭(95%) ±0.001 안으로 추정하려면 \(B\)가 대략 얼마여야 하는가?
    답

    \(1.96\sqrt{0.25/B} \le 0.001\)에서 \(B \ge 960400\), 약 100만 번이다.

응용

  1. 생일이 같은 사람이 있을 확률이 처음으로 0.5를 넘는 반 인원 \(n\)을 정확한 공식으로 찾는 코드를 써라.
    답

    next(n for n in range(1, 366) if 1 - np.prod((365 - np.arange(n)) / 365) > 0.5)는 23이다. 22명이면 0.476이다.
