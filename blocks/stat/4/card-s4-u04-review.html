근 찾기와 최적화 단원 마무리 연습

문제 7 · 실습·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습\(f(x) = x^3 + x - 1\)의 근을 구간 \([0, 1]\)에서 이분법으로 찾는 함수를 쓰세요. 구간 길이가 \(10^{-6}\) 이하가 될 때까지 몇 번 반복해야 하는지 미리 계산하세요. [04-01]

    힌트 1

    한 번 반복할 때마다 구간 길이가 절반이 됩니다. \(2^{-k} \le 10^{-6}\)인 가장 작은 \(k\)를 찾으세요.

    힌트 2

    중점 \(m\)에서 \(f(a)f(m) \le 0\)이면 근은 \([a, m]\)에 있습니다.

    풀이 
    def bisect(f, a, b, tol=1e-6):
    if f(a) * f(b) > 0:
        raise ValueError("양 끝의 부호가 같습니다")
    n = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
        n += 1
    return (a + b) / 2, n

print(bisect(lambda x: x**3 + x - 1, 0, 1))   # (0.68232..., 20)

    \(2^{-20} \approx 9.5\times10^{-7} \le 10^{-6}\)이므로 20번입니다. 근은 약 0.682328이며 응통1-01-02에서 중간값 정리로 존재를 보인 그 근입니다.

  2. 실습뉴턴 방법으로 \(\sqrt2\)를 구하려 합니다. \(f(x) = x^2 - 2\)에 대한 반복식을 유도하고, \(x_0 = 1\)에서 네 번 반복한 값을 쓰세요. 맞는 자릿수가 어떻게 늘어나는지 관찰하세요. [04-01]

    힌트 1

    뉴턴 반복식은 \(x_{n+1} = x_n - f(x_n)/f'(x_n)\)입니다.

    힌트 2

    정리하면 \(x_{n+1} = (x_n + 2/x_n)/2\)입니다.

    풀이

    \(x_{n+1} = x_n - \dfrac{x_n^2 - 2}{2x_n} = \dfrac12\Big(x_n + \dfrac{2}{x_n}\Big)\)입니다. \(x_1 = 1.5\), \(x_2 = 1.4166667\), \(x_3 = 1.4142157\), \(x_4 = 1.4142136\)입니다(\(\sqrt2 = 1.41421356\cdots\)).

    맞는 자릿수가 대략 1, 3, 6, 12자리로 매번 두 배쯤 늘어납니다(이차 수렴). 이분법이 한 번에 1비트(약 0.3자리)씩 느는 것보다 훨씬 빠릅니다.

  3. 판단\(f(x) = x^3 - 2x + 2\)에 \(x_0 = 0\)에서 뉴턴 방법을 쓰면 어떻게 되는지 두 번 반복해 확인하고, 뉴턴 방법을 안전하게 쓰는 방법을 쓰세요. [04-01]

    힌트 1

    \(f'(x) = 3x^2 - 2\)이고 \(f(0) = 2\), \(f'(0) = -2\)입니다.

    힌트 2

    \(x_1\)에서 다시 반복식을 적용해 보세요.

    풀이

    \(x_1 = 0 - 2/(-2) = 1\), \(f(1) = 1\), \(f'(1) = 1\)이므로 \(x_2 = 1 - 1 = 0\)입니다. 0과 1 사이를 영원히 오가며 수렴하지 않습니다(실제 근은 약 \(-1.769\)).

    대처: 최대 반복 횟수를 두고, 미분계수가 0에 가까우면 멈추며, 근이 있는 구간을 알면 이분법으로 좁힌 뒤 뉴턴 방법을 쓰거나 두 방법을 섞은 브렌트 방법(scipy.optimize.brentq)을 씁니다.

  4. 실습포아송 자료 2, 0, 3, 1, 4에서 \(\lambda\)의 최대가능도 추정값을 scipy.optimize.minimize_scalar로 구하는 코드를 쓰세요. 결과를 해석적인 답과 비교하세요. [04-02]

    힌트 1

    최소화 함수를 쓰므로 음의 로그가능도를 넘깁니다. scipy.stats.poisson.logpmf를 쓸 수 있습니다.

    힌트 2

    \(\lambda > 0\)이어야 하므로 bounds=(1e-6, 20), method="bounded"를 씁니다.

    풀이 
    import numpy as np
from scipy import stats, optimize
x = np.array([2, 0, 3, 1, 4])
nll = lambda lam: -stats.poisson.logpmf(x, lam).sum()
res = optimize.minimize_scalar(nll, bounds=(1e-6, 20), method="bounded")
print(res.x)   # 약 2.0

    해석적인 답은 \(\hat\lambda = \bar x = 2\)입니다(응통1-02-02). 수치 최적화 결과는 허용 오차 안에서 2와 같습니다(R의 optimize로도 1.99999…). 해석해가 있는 문제로 먼저 코드를 확인한 뒤 해석해가 없는 모형에 쓰는 것이 좋은 습관입니다.

  5. 실습효용 \(U = \sqrt{xy}\)를 예산 \(2x + y = 100\) 아래 최대화하는 문제를 scipy.optimize.minimize로 푸는 코드를 쓰고, 라그랑주 승수법의 답과 비교하세요. [04-02]

    힌트 1

    최소화 함수이므로 \(-U\)를 넘기고, 제약은 {"type": "eq", "fun": lambda v: 2*v[0] + v[1] - 100}로 줍니다.

    힌트 2

    해석적으로는 \(y/x = 2\)(한계효용 비 = 가격 비)가 나옵니다.

    풀이 
    from scipy.optimize import minimize
negU = lambda v: -(v[0] * v[1]) ** 0.5
cons = {"type": "eq", "fun": lambda v: 2 * v[0] + v[1] - 100}
res = minimize(negU, x0=[10, 10], constraints=[cons],
               bounds=[(1e-6, None), (1e-6, None)], method="SLSQP")
print(res.x)   # 약 [25, 50]

    라그랑주 조건 \(\frac{y}{2\sqrt{xy}} = 2\lambda\), \(\frac{x}{2\sqrt{xy}} = \lambda\)에서 \(y = 2x\), 예산식에 넣으면 \(x = 25\), \(y = 50\)입니다. 예산의 절반씩을 두 재화에 쓰는 콥-더글러스 효용의 성질과 맞습니다.

  6. 판단\(f(x) = (x - 3)^2\)을 경사하강법 \(x_{k+1} = x_k - \eta f'(x_k)\)로 최소화합니다. \(x_0 = 0\)에서 (1) \(\eta = 0.1\)로 10번 반복한 값을 구하고, (2) \(\eta = 1.1\)이면 어떻게 되는지 쓰세요. [04-01]

    힌트 1

    \(f'(x) = 2(x - 3)\)이므로 \(x_{k+1} - 3 = (1 - 2\eta)(x_k - 3)\)입니다.

    힌트 2

    \(|1 - 2\eta| < 1\)이어야 3으로 수렴합니다.

    풀이

    (1) \(\eta = 0.1\)이면 \(x_k - 3 = 0.8^k(x_0 - 3)\), 곧 \(x_k = 3(1 - 0.8^k)\)이므로 \(x_{10} = 3(1 - 0.107) \approx 2.678\)입니다. 천천히 3에 다가갑니다.

    (2) \(\eta = 1.1\)이면 비가 \(1 - 2.2 = -1.2\)라 오차가 매번 1.2배로 커지며 부호가 바뀝니다. 3을 넘나들며 발산합니다. 학습률은 너무 작으면 느리고 너무 크면 발산하므로, 이 문제에서는 \(0 < \eta < 1\)이어야 합니다.

  7. 계산\(f(x) = x^3\)의 \(x = 1\) 도함수를 \(h = 0.1\)로 전진 차분과 중심 차분으로 어림하고 오차를 비교하세요. [04-03]

    힌트 1

    전진 \((1.1^3 - 1)/0.1\).

    힌트 2

    중심 \((1.1^3 - 0.9^3)/0.2\).

    풀이

    전진 \((1.331 - 1)/0.1 = 3.31\), 오차 0.31. 중심 \((1.331 - 0.729)/0.2 = 3.01\), 오차 0.01. 참값 3.

    중심 차분의 오차는 \(h^2f'''/6 = 0.01 \times 6/6 = 0.01\)로 정확히 맞습니다.
