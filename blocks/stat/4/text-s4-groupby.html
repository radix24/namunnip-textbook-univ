"지역별 평균 매출", "월별 제품별 판매량 표"처럼 집단으로 나누어 요약하는 일이 분석의 대부분입니다. pandas의 groupby는 자료를 집단으로 나누고(split), 함수를 적용하고(apply), 결과를 합칩니다(combine).

5.2.1groupby

df.groupby("region")["sales"].mean()
df.groupby(["region", "month"]).agg(total=("sales", "sum"),
                                    n=("sales", "size"),
                                    avg=("sales", "mean")).reset_index()
df["share"] = df["sales"] / df.groupby("region")["sales"].transform("sum")  # 집단 내 비율

agg는 집단마다 한 행으로 요약하고, transform은 원래 행 수를 유지하며 집단 값을 붙입니다.

5.2.2피벗과 형식 바꾸기

pd.pivot_table(df, index="region", columns="month", values="sales",
               aggfunc="sum", margins=True)          # 합계 행·열 포함
pd.crosstab(df["sex"], df["agegrp"], normalize="index")   # 행별 비율 분할표
long = df_wide.melt(id_vars="id", var_name="month", value_name="score")  # 넓은 → 긴
wide = long.pivot(index="id", columns="month", values="score")           # 긴 → 넓은

5.2.3결합

pd.merge(sales, info, on="store", how="inner")   # how: inner, left, right, outer
pd.concat([df_2025, df_2026], ignore_index=True)  # 위아래로 이어 붙이기

결합 뒤 len()으로 행 수를 확인하고, validate="many_to_one" 인수로 열쇠 중복을 검사할 수 있습니다.

예제 5.2.1

seaborn에 들어 있는 tips 자료(식당 팁)에서 요일·시간대별 평균 팁 비율 표를 만드세요.

import seaborn as sns
tips = sns.load_dataset("tips")
tips["rate"] = tips["tip"] / tips["total_bill"]
pd.pivot_table(tips, index="day", columns="time", values="rate", aggfunc="mean").round(3)
요약
  1. groupby().agg() 요약, transform은 행 유지.
  2. pivot_table, crosstab, melt/pivot.
  3. merge, concat 뒤 행 수 확인.
