그룹 요약, 피벗, 결합

본문

"지역별 평균 매출", "월별 제품별 판매량 표", "매장 정보와 매출 기록을 매장 번호로 합친 표"는 보고서에 가장 자주 들어가는 표이다. 반복문으로 지역마다 행을 골라 평균을 내면 지역이 열 개만 되어도 코드가 길어진다. 이런 집단별 요약을 한 줄로 쓰는 공통 원리가 있을까?

먼저 알아야 할 것pandas 기초(5.1절)를 쓴다.

5.2.1groupby

처음 질문의 공통 원리는 그림 1의 세 단계이다. 자료를 집단으로 나누고(split), 집단마다 함수를 적용하고(apply), 결과를 합친다(combine). pandas의 groupby가 이 일을 한다.

df.groupby("region")["sales"].mean()
df.groupby(["region", "month"]).agg(total=("sales", "sum"),
                                    n=("sales", "size"),
                                    avg=("sales", "mean")).reset_index()
df["share"] = df["sales"] / df.groupby("region")["sales"].transform("sum")  # 집단 내 비율

두 번째 줄의 agg는 결과 열 이름과 (열, 함수) 쌍을 짝지어 집단마다 한 행으로 요약하며, reset_index는 집단 이름을 인덱스에서 보통 열로 되돌린다. 반면 transform은 원래 행 수를 그대로 두고 각 행에 그 집단의 값을 붙인다. 그래서 셋째 줄처럼 행마다 집단 합계로 나누어 집단 안의 비율을 구할 때 쓴다.

5.2.2피벗과 형식 바꾸기

둘째 표, 곧 행은 지역이고 열은 월인 교차표는 피벗 표로 만든다.

pd.pivot_table(df, index="region", columns="month", values="sales",
               aggfunc="sum", margins=True)          # 합계 행과 열 포함
pd.crosstab(df["sex"], df["agegrp"], normalize="index")   # 행별 비율 분할표
long = df_wide.melt(id_vars="id", var_name="month", value_name="score")  # 넓은 → 긴
wide = long.pivot(index="id", columns="month", values="score")           # 긴 → 넓은

한편 같은 자료도 두 모양으로 담을 수 있다. 한 사람의 여러 달 점수를 한 행에 늘어놓은 넓은 형식은 사람이 읽기 좋고, (사람, 달, 점수)를 한 행씩 쌓은 긴 형식은 groupby와 그래프에 쓰기 좋다. melt와 pivot은 둘 사이를 오간다. R의 pivot_longer, pivot_wider(응통3)와 같은 일이다.

5.2.3결합

셋째 표는 두 표를 열쇠 열로 잇는 결합이다.

pd.merge(sales, info, on="store", how="inner")   # how는 inner, left, right, outer
pd.concat([df_2025, df_2026], ignore_index=True)  # 위아래로 이어 붙이기

inner는 양쪽에 다 있는 열쇠만, left는 왼쪽 표의 행을 모두 남긴다. 그런데 오른쪽 표에 같은 열쇠가 두 번 있으면 왼쪽 행이 두 배로 불어나 합계가 부풀려진다. 그러므로 결합 뒤에는 len()으로 행 수를 확인하고, validate="many_to_one" 인수로 열쇠 중복을 미리 검사한다.

예제 5.2.1

seaborn에 들어 있는 tips 자료(식당의 계산 금액과 팁)에서 요일과 시간대별 평균 팁 비율 표를 만들어라.

import seaborn as sns
tips = sns.load_dataset("tips")
tips["rate"] = tips["tip"] / tips["total_bill"]
pd.pivot_table(tips, index="day", columns="time", values="rate", aggfunc="mean").round(3)

풀이. 먼저 행마다 팁 비율 열을 만들고, 피벗 표로 요일을 행, 시간대를 열에 두어 칸마다 평균을 낸다. 관측이 없는 칸(예를 들어 주말 점심)은 NaN으로 나온다. 같은 결과는 tips.groupby(["day", "time"])["rate"].mean().unstack()으로도 얻는다.

흔한 실수집단별 평균 비율을 구하려다 groupby(...)["rate"].mean()과 tip 합 ÷ total_bill 합을 섞어 쓰면 값이 다르다. 앞의 것은 손님마다 비율의 평균이고, 뒤의 것은 금액으로 가중한 비율이다. 무엇을 보고할지 먼저 정하자.
마무리

집단별 요약은 나누고, 적용하고, 합치는 세 단계이며 pandas에서는 groupby가 맡는다. agg는 집단마다 한 행으로 요약하고 transform은 행 수를 그대로 둔 채 집단 값을 붙인다. 교차표는 pivot_table과 crosstab으로 만들고, melt와 pivot으로 긴 형식과 넓은 형식을 오간다. 두 표는 merge와 concat으로 잇되, 결합 뒤 행 수를 늘 확인한다.
