불리언 마스크와 팬시 인덱싱

본문
이 절에서 배울 것
  • 조건식으로 불리언 배열을 만들고 원소를 고른다.
  • 정수 배열로 원하는 위치를 한꺼번에 고른다(팬시 인덱싱).
  • 복사본과 뷰의 차이를 알고 값을 안전하게 바꾼다.
먼저 알아야 할 것
  • NumPy 배열 (3.1절).

반복문 없이 고르기

"점수가 60점 미만인 학생", "결측이 아닌 값", "상위 10%"처럼 조건에 맞는 원소를 고르는 일은 분석의 기본입니다. NumPy에서는 반복문 대신 조건식 하나로 합니다. pandas의 행 고르기(5.1절)도 같은 원리입니다.

3.3.1불리언 마스크

import numpy as np
x = np.array([3, 8, 1, 9, 4])
mask = x > 3            # array([False, True, False, True, True])
x[mask]                 # array([8, 9, 4])
x[(x > 2) & (x < 9)]    # array([3, 8, 4])  -- and는 &, or는 |, 괄호 필수
mask.sum(), mask.mean() # 3, 0.6  (조건을 만족하는 개수와 비율)
np.where(x > 3, x, 0)   # array([0, 8, 0, 9, 4])

파이썬의 and, or는 배열에 쓸 수 없고 &, |, ~(부정)를 씁니다. 연산자 우선순위 때문에 각 조건을 괄호로 감쌉니다. True가 1로 계산되어 sum은 개수, mean은 비율이 됩니다.

3.3.2팬시 인덱싱

x[[0, 2, 4]]            # array([3, 1, 4])
idx = np.argsort(x)     # array([2, 0, 4, 1, 3]) 작은 값의 위치 순서
x[idx]                  # array([1, 3, 4, 8, 9]) 정렬
x[idx[-2:]]             # array([8, 9]) 가장 큰 두 값
A = np.arange(12).reshape(3, 4)
A[A[:, 0] > 0]          # 첫 열이 양수인 행들

3.3.3복사본과 뷰

슬라이싱(x[1:3])은 원래 배열을 가리키는 뷰라 고치면 원본이 바뀌고, 마스크와 팬시 인덱싱의 결과는 복사본이라 고쳐도 원본이 그대로입니다. 원본의 조건부 원소를 바꾸려면 x[x < 0] = 0처럼 대입문 왼쪽에 마스크를 씁니다.

예제 3.3.1

점수 배열 s = np.array([55, 72, 90, 48, 66, 81])에서 60점 미만 학생 수, 60점 이상 학생의 평균, 60점 미만을 60점으로 올린 배열을 구하세요.

(s < 60).sum()            # 2
s[s >= 60].mean()         # (72 + 90 + 66 + 81)/4 = 77.25
t = s.copy(); t[t < 60] = 60
t                         # array([60, 72, 90, 60, 66, 81])
요약
  1. x[조건]으로 고르기, & | ~와 괄호.
  2. x[[위치들]], argsort로 순서대로 고르기.
  3. 슬라이스는 뷰, 마스크·팬시는 복사본. 원본을 바꿀 때는 왼쪽에 마스크.

3.3.4연습문제

기본

  1. x = np.array([2, -1, 5, -3, 0])에서 음수를 모두 0으로 바꾼 뒤의 합은?
    답

    x[x < 0] = 0 → [2, 0, 5, 0, 0], 합 7.

응용

  1. np.nan이 섞인 배열의 평균을 결측을 빼고 구하는 방법 두 가지를 쓰세요.
    답

    x[~np.isnan(x)].mean() 또는 np.nanmean(x). x[x != np.nan]은 nan != nan이 항상 참이라 걸러지지 않습니다.
