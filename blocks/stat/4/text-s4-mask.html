불리언 마스크와 팬시 인덱싱

본문

"60점 미만인 학생", "결측이 아닌 값", "가장 큰 두 값"처럼 조건에 맞는 원소를 고르는 일은 분석에서 끝없이 나온다. 반복문을 돌며 하나씩 검사하지 않고 조건식 한 줄로 고를 수 있을까? 그리고 고른 원소를 고치면 원래 배열도 바뀔까?

먼저 알아야 할 것NumPy 배열(3.1절)을 쓴다.

3.3.1불리언 마스크

배열에 비교 연산을 걸면 원소마다 참과 거짓이 매겨진 배열이 나온다. 이것을 불리언 마스크라 하며, 대괄호에 넣으면 참인 자리만 골라진다(그림 1).

import numpy as np
x = np.array([3, 8, 1, 9, 4])
mask = x > 3            # array([False, True, False, True, True])
x[mask]                 # array([8, 9, 4])
x[(x > 2) & (x < 9)]    # array([3, 8, 4])  and는 &, or는 |, 괄호 필수
mask.sum(), mask.mean() # 3, 0.6  (조건을 만족하는 개수와 비율)
np.where(x > 3, x, 0)   # array([0, 8, 0, 9, 4])

여기서 조건을 잇는 데 파이썬의 and, or는 쓸 수 없다. 이들은 값 하나의 참거짓만 묻기 때문이다. 대신 원소별로 계산하는 &, |, ~(부정)를 쓰고, 이 연산자들이 비교보다 먼저 계산되므로 조건마다 괄호로 감싼다. 또 참이 1로 계산되므로 sum은 개수, mean은 비율이다. pandas의 행 고르기(5.1절)도 같은 원리이다.

3.3.2팬시 인덱싱

조건 대신 위치를 정수 배열로 주어 한꺼번에 고를 수도 있다. 이를 팬시 인덱싱이라 한다. 처음 질문의 "가장 큰 두 값"은 정렬 순서를 돌려주는 argsort와 함께 쓴다.

x[[0, 2, 4]]            # array([3, 1, 4])
idx = np.argsort(x)     # array([2, 0, 4, 1, 3]) 작은 값의 위치 순서
x[idx]                  # array([1, 3, 4, 8, 9]) 정렬
x[idx[-2:]]             # array([8, 9]) 가장 큰 두 값
A = np.arange(12).reshape(3, 4)
A[A[:, 0] > 0]          # 첫 열이 양수인 행들

3.3.3복사본과 뷰

이제 둘째 질문이다. 답은 고르는 방법에 따라 다르다. 슬라이싱 x[1:3]은 원래 배열의 일부를 가리키는 뷰여서, 결과를 고치면 원본이 바뀐다. 반면 마스크와 팬시 인덱싱의 결과는 새로 만든 복사본이라 고쳐도 원본이 그대로이다. 그렇다면 원본의 조건부 원소를 바꾸려면 어떻게 할까? x[x < 0] = 0처럼 대입문 왼쪽에 마스크를 쓰면 된다.

예제 3.3.1

점수 배열 s = np.array([55, 72, 90, 48, 66, 81])에서 60점 미만 학생 수, 60점 이상 학생의 평균, 60점 미만을 60점으로 올린 배열을 구하여라.

(s < 60).sum()            # 2
s[s >= 60].mean()         # (72 + 90 + 66 + 81)/4 = 77.25
t = s.copy(); t[t < 60] = 60
t                         # array([60, 72, 90, 60, 66, 81])

풀이. 개수는 마스크의 합이고, 평균은 마스크로 고른 배열의 평균이다. 마지막은 원본 s를 지키려고 copy로 복사한 뒤 왼쪽에 마스크를 써서 바꾸었다.

흔한 실수결측을 빼려고 x[x != np.nan]을 쓰면 아무것도 걸러지지 않는다. nan은 자기 자신과도 같지 않아 nan != nan이 늘 참이기 때문이다. 결측은 np.isnan으로 찾는다.
마무리

비교 연산은 불리언 마스크를 만들고, x[조건]은 참인 자리의 원소만 고른다. 조건은 &, |, ~와 괄호로 잇고, 마스크의 합과 평균은 개수와 비율이다. 위치 배열로 고르는 팬시 인덱싱과 argsort를 함께 쓰면 정렬과 상위 값 고르기가 된다. 슬라이스는 원본을 가리키는 뷰이고 마스크와 팬시 인덱싱의 결과는 복사본이므로, 원본을 바꿀 때는 대입문 왼쪽에 마스크를 쓴다.

3.3.4연습문제

기본

  1. x = np.array([2, -1, 5, -3, 0])에서 음수를 모두 0으로 바꾼 뒤의 합은 얼마인가?
    답

    x[x < 0] = 0으로 [2, 0, 5, 0, 0]이 되어 합은 7이다.

응용

  1. np.nan이 섞인 배열의 평균을 결측을 빼고 구하는 방법 두 가지를 써라.
    답

    x[~np.isnan(x)].mean() 또는 np.nanmean(x)이다.

  2. y = x[1:3]와 z = x[[1, 2]]를 만든 뒤 y[0] = 100, z[1] = 200을 하면 x는 어떻게 되는가? (x = np.array([3, 8, 1, 9, 4]))
    답

    슬라이스 y는 뷰이므로 x[1]이 100으로 바뀌고, z는 복사본이므로 x에 영향이 없다. 결과는 [3, 100, 1, 9, 4]이다.
