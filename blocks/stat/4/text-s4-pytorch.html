PyTorch의 텐서와 자동 미분

본문

NumPy로 회귀 계수를 경사 하강으로 구하려면 손실 함수의 기울기를 손으로 미분해 코드로 써야 한다. 모형이 신경망처럼 복잡해지면 이 일은 감당하기 어렵다. 모형 식만 쓰면 기울기는 컴퓨터가 알아서 구해 줄 수 없을까?

먼저 알아야 할 것NumPy 배열 계산(3.1절), 최적화(4.2절), 통계 계산(6.1절)을 쓴다.

7.1.1텐서와 자동 미분

PyTorch의 텐서는 NumPy 배열과 비슷한 다차원 배열이다. 다른 점은 GPU에서 계산할 수 있고, requires_grad=True로 만든 텐서는 그것을 쓴 모든 연산이 기록된다는 것이다. 이제 손실 값에서 backward()를 부르면 연쇄 법칙으로 기울기가 거꾸로 전해져 각 텐서의 .grad에 쌓인다. 그러므로 처음 질문의 답처럼 모형 식만 쓰면 기울기는 자동으로 얻는다. 이것을 자동 미분이라 하며, 딥러닝 라이브러리의 핵심이다.

7.1.2선형회귀를 학습시키기

다음 코드는 \(y = 2x + 1 + \varepsilon\) 자료에 직선을 맞춘다. 매 반복에서 순방향으로 손실을 계산하고, 기울기를 구하고, 최적화 도구가 매개변수를 갱신한다. 그런데 기울기는 쌓이는 성질이 있어 매번 zero_grad()로 비워야 한다.

import torch
torch.manual_seed(0)
x = torch.linspace(0, 1, 100).unsqueeze(1)
y = 2*x + 1 + 0.1*torch.randn_like(x)

model = torch.nn.Linear(1, 1)
opt = torch.optim.SGD(model.parameters(), lr=0.5)
for step in range(500):
    opt.zero_grad()
    loss = torch.mean((model(x) - y)**2)
    loss.backward()
    opt.step()
print(model.weight.item(), model.bias.item())   # 약 2, 1

같은 틀에서 torch.nn.Linear를 여러 층의 신경망으로 바꾸고 손실 함수만 바꾸면 분류 모형도 학습시킬 수 있다. 다만 최소제곱 선형회귀는 닫힌 해가 있으므로, 실제로는 결과를 statsmodels나 \((X^{\mathsf T}X)^{-1}X^{\mathsf T}y\)와 비교해 확인한다.

예제 7.1.1

\(w\)가 스칼라 텐서이고 \(L = (3w - 6)^2\)일 때 \(w = 1\)에서 L.backward() 뒤 w.grad는 얼마인가?

풀이. \(dL/dw = 2(3w - 6)\times3 = 6(3w - 6)\)이므로 \(w = 1\)에서 \(-18\)이다. 따라서 w.grad는 \(-18\)이고, 학습률 0.01로 갱신하면 \(w \leftarrow 1 + 0.18 = 1.18\)이 되어 최솟점 2 쪽으로 움직인다.

마무리

PyTorch 텐서는 GPU 계산과 연산 기록이 되는 다차원 배열이고, backward()가 기록된 계산 그래프를 거꾸로 따라가 기울기를 자동으로 구한다. 학습은 손실 계산, 기울기 계산, 매개변수 갱신을 되풀이하며, 기울기는 쌓이므로 매번 비운다. 닫힌 해가 있는 모형은 결과를 통계 패키지와 비교해 확인한다.
