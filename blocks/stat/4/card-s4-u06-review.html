  2. 실습같은 자료로 대응표본 t 검정을 하는 scipy 코드를 쓰고 결과를 쓰세요. 인수의 순서를 바꾸면 무엇이 달라지나요? [06-01]

    힌트 2

  4. 실습"주사위를 4번 던져 6이 적어도 한 번 나올 확률"을 정확히 계산하고, NumPy 모의실험 10만 번으로 확인하는 코드를 쓰세요. [06-02]

    힌트 2

  5. 도전정규분포에서 크기 10인 표본을 뽑아 (가) \(\bar x \pm t_{0.025,9}\,s/\sqrt{10}\), (나) \(\bar x \pm 1.96\,s/\sqrt{10}\)으로 95% 신뢰구간을 만들 때, 각 구간이 참 평균을 포함하는 비율을 모의실험으로 추정하는 코드를 쓰고 이론값을 쓰세요. [06-02]

    힌트 1

    참 평균을 0으로 두고, 각 반복에서 구간이 0을 포함하는지 셉니다.

    힌트 2

    (나)의 이론 포함 확률은 \(P(|T_9| \le 1.96)\)입니다.

    풀이 
    import numpy as np
from scipy import stats
rng = np.random.default_rng(7)
x = rng.standard_normal((100_000, 10))
m, s = x.mean(axis=1), x.std(axis=1, ddof=1)
se = s / np.sqrt(10)
t = stats.t.ppf(0.975, df=9)
print((np.abs(m) <= t * se).mean(), (np.abs(m) <= 1.96 * se).mean())

    (가)는 0.95 근처, (나)는 이론값 \(P(|T_9| \le 1.96) \approx 0.918\) 근처가 나옵니다. 표본이 작을 때 \(s\)로 \(\sigma\)를 바꾸고도 \(z\) 값을 쓰면 구간이 너무 좁아 포함 확률이 명목값보다 낮아집니다(응통5-03-02).

  6. 판단모의실험으로 확률(0.5 근처)을 소수 셋째 자리까지 믿을 만하게(표준오차 0.001 이하) 추정하려면 반복을 몇 번 해야 하는지 계산하세요. 반복을 10배 늘리면 표준오차는 어떻게 되나요? [06-02]

    힌트 1

    비율 추정의 표준오차는 \(\sqrt{p(1-p)/n}\)입니다.

    힌트 2

    \(p = 0.5\)일 때 \(p(1-p) = 0.25\)로 가장 큽니다.

    풀이

    \(\sqrt{0.25/n} \le 0.001\)에서 \(n \ge 250000\)이므로 25만 번이 필요합니다. 반복을 10배 늘리면 표준오차는 \(1/\sqrt{10} \approx 0.32\)배로 줄어듭니다. 모의실험 결과를 보고할 때는 반복 횟수와 이 모의실험 오차를 함께 적는 것이 좋습니다.

  7. 실습두 집단 a, b의 중앙값 차이에 대한 95% 붓스트랩 구간을 구하는 코드를 rng = np.random.default_rng(1)로 쓰세요. [06-03]

    힌트 1

    풀이

  8. 계산로지스틱 회귀 계수가 절편 −2.0, 기울기 0.5입니다. \(x = 2\)와 \(x = 6\)의 예측 확률, 그리고 \(x\)가 4 늘 때의 오즈비를 구하세요. [06-04]

    힌트 1

    \(p = 1/(1 + e^{-\eta})\).

    힌트 2

    오즈비 \(e^{0.5 \times 4}\).

    풀이

    \(x = 2\): \(\eta = -1\), \(p = 0.269\). \(x = 6\): \(\eta = 1\), \(p = 0.731\). 오즈비 \(e^2 = 7.39\).

    오즈 \(0.731/0.269 = 2.72\)와 \(0.269/0.731 = 0.368\)의 비가 7.39로 맞습니다.
