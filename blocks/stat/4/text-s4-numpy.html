NumPy 배열과 벡터화 계산

본문

파이썬 리스트 [1, 2]에 2를 곱하면 [2, 4]가 아니라 [1, 2, 1, 2]가 된다. 리스트는 수를 담는 그릇일 뿐 계산 도구가 아니기 때문이다. 그렇다면 표준정규 난수 100만 개를 표준화하거나 각 열의 평균을 빼는 계산은 반복문 없이 어떻게 할까?

먼저 알아야 할 것리스트(1.2절)와 모듈(2.1절)을 쓴다.

3.1.1배열

수치 계산에는 NumPy의 배열을 쓴다. 배열은 같은 자료형의 원소를 메모리에 연속으로 놓아, 연산을 C로 짠 반복이 한꺼번에 처리한다. 그래서 연산이 원소별로 적용되고 빠르다. 이렇게 반복문 대신 배열 전체에 연산을 거는 방식을 벡터화라 한다.

import numpy as np
x = np.array([3, 1, 4, 1, 5])
x * 2                    # array([ 6,  2,  8,  2, 10])
x.mean(), x.std(ddof=1)  # (2.8, 1.7888...)  ddof=1이면 n-1로 나눔
x[x > 2]                 # 조건 인덱싱 array([3, 4, 5])
np.arange(0, 1, 0.25)    # array([0.  , 0.25, 0.5 , 0.75])
np.linspace(0, 1, 5)     # 끝 포함 5개
z = (x - x.mean()) / x.std(ddof=1)   # 표준화

표준화 줄을 보자. x - x.mean()은 배열에서 수 하나를 빼는데, 수가 배열 길이만큼 늘어나 원소마다 빠진다. 이것이 그림 1의 브로드캐스팅을 가장 단순한 경우에 쓴 것이다.

3.1.22차원 배열과 브로드캐스팅

이제 처음 질문의 둘째 계산, 각 열의 평균 빼기를 해 보자.

X = np.array([[1, 2], [3, 4], [5, 6]])     # 3×2
X.shape; X.mean(axis=0)                     # (3, 2), 열 평균 array([3., 4.])
Xc = X - X.mean(axis=0)                     # 3×2에서 길이 2를 빼면 행마다 적용

모양이 다른 배열끼리 연산하면 NumPy는 작은 쪽을 늘려 맞춘다. 이것을 브로드캐스팅이라 한다. 규칙은 뒤쪽 차원부터 맞추어 보아 길이가 같거나 한쪽이 1이면 늘린다는 것이다. 그래서 (3, 2)와 (2,)는 맞지만, 행 평균 (3,)을 빼려면 X.mean(axis=1, keepdims=True)로 (3, 1) 모양을 만들어야 한다. 또 axis=0은 행 방향으로 접어 열마다 계산하고, axis=1은 행마다 계산한다.

예제 3.1.1

표준정규 난수 100만 개 가운데 절댓값이 1.96을 넘는 비율을 반복문 없이 구하여라.

rng = np.random.default_rng(1)
z = rng.standard_normal(1_000_000)
np.mean(np.abs(z) > 1.96)          # 약 0.05

풀이. np.abs(z) > 1.96은 참과 거짓의 배열이고, 참은 1, 거짓은 0으로 계산되므로 그 평균이 곧 참의 비율이다. 이론값은 \(2(1 - \Phi(1.96)) = 0.05\)이다. 같은 계산을 파이썬 반복문으로 하면 수십 배 느리다.

주의np.std와 x.std()는 기본으로 \(n\)으로 나눈다(ddof=0). 표본표준편차는 ddof=1을 주어야 하며, R의 sd나 pandas의 std와 기본값이 다르다.
마무리

NumPy 배열은 같은 자료형을 연속으로 담아 연산을 원소별로, 빠르게 처리한다. 집계는 axis로 방향을 정하고, 표본표준편차는 ddof=1로 구한다. 모양이 다른 배열은 브로드캐스팅으로 작은 쪽이 늘어나 맞춰지며, 논리 배열의 평균이 비율이 되는 성질과 함께 쓰면 반복문 없이 대부분의 계산을 쓸 수 있다.

3.1.3연습문제

기본

  1. 3×2 배열 X의 각 열을 표준화하는 한 줄 코드를 써라.
    답

    (X - X.mean(axis=0)) / X.std(axis=0, ddof=1)이다.

응용

  1. 그림 1의 X에서 각 행의 평균을 빼려고 X - X.mean(axis=1)을 쓰면 어떻게 되는가? 고친 코드도 써라.
    답

    (3, 2)와 (3,)은 뒤쪽 차원 2와 3이 맞지 않아 오류가 난다. X - X.mean(axis=1, keepdims=True)로 (3, 1) 모양을 만들면 열 방향으로 늘어나 [[-0.5, 0.5], ...]가 된다.
