지저분한 설문 응답을 숫자로

예제 · 문자열 정리

먼저 읽는 법

자유 입력 칸에는 단위, 공백, 쉼표가 섞여 들어옵니다. 규칙을 정해 숫자만 뽑고, 바꿀 수 없는 값은 결측(None)으로 남겨 나중에 확인합니다.

문제. 월 소득 응답 ["350만원", " 1,200 ", "모름", "80만 원", "2000"]을 만 원 단위 정수로 바꾸는 함수를 쓰고 결과를 쓰세요.

풀이

  1. 공백·쉼표를 지우고 "만원", "만 원" 같은 단위를 지웁니다: re.sub(r"[\s,]|만\s*원", "", s).
    정리 규칙.
  2. 남은 문자열이 숫자로만 되어 있으면 int, 아니면 None: int(t) if t.isdigit() else None.
    바꿀 수 없는 값을 표시.
  3. 결과 [350, 1200, None, 80, 2000].
    "모름"은 결측.

검산

import re
def clean(s):
    t = re.sub(r"[\s,]|만\s*원", "", s)
    return int(t) if t.isdigit() else None
[clean(s) for s in ["350만원", " 1,200 ", "모름", "80만 원", "2000"]]

"80만 원"은 "만 원" 패턴(사이 공백 허용)이 지워져 "80"이 됩니다.

의미

"2000"과 "1,200"은 단위가 없어 만 원인지 원인지 알 수 없습니다. 정리 함수는 규칙을 코드로 남기지만, 애매한 값을 어떻게 판단했는지는 문서에 적어야 합니다. 바꾸지 못한 값을 None으로 남기면 결측 처리(응통14 5.3절)를 의식적으로 할 수 있습니다.
