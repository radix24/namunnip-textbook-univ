모듈과 객체 단원 마무리 연습

문제 6 · 실습·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 실습다음 세 가지 불러오기 방식의 차이를 쓰고, from numpy import *를 피하는 까닭을 써라. [02-01]

    import math
from math import sqrt
import numpy as np
    힌트 1

    이름을 쓸 때 앞에 무엇을 붙여야 하는지 비교해 보아라.

    힌트 2

    *로 불러오면 어떤 이름이 들어왔는지 코드만 보고 알 수 없다.

    풀이

    import math는 math.sqrt(2)처럼 모듈 이름을 붙여 쓴다. from math import sqrt는 sqrt(2)로 바로 쓴다. import numpy as np는 줄임 이름 np를 붙여 np.mean(x)로 쓴다.

    from numpy import *는 수백 개의 이름을 한꺼번에 들여와 파이썬 내장 함수(sum, max, round 등)를 덮어쓸 수 있고, 어떤 함수가 어디서 왔는지 알기 어렵게 만든다.

  2. 실습자주 쓰는 함수 mean_sd를 statutil.py 파일로 옮겨 다른 스크립트에서 불러 쓰려 한다. 파일 구조와 불러오는 코드를 쓰고, 파일 끝의 if __name__ == "__main__": 블록이 하는 일을 설명하여라. [02-01]

    힌트 1

    같은 폴더의 statutil.py는 import statutil로 불러온다.

    힌트 2

    파일을 직접 실행하면 __name__은 "__main__", 불러오면 모듈 이름이다.

    풀이 
    # statutil.py
def mean_sd(xs):
    ...

if __name__ == "__main__":
    print(mean_sd([2, 4, 4, 5, 7, 8]))   # 간단한 시험

# analysis.py
from statutil import mean_sd
print(mean_sd([1, 2, 3]))

    python statutil.py로 직접 실행하면 시험 코드가 돌고, analysis.py에서 불러올 때는 시험 코드가 실행되지 않는다. 모듈에 함수 정의와 간단한 확인 코드를 함께 두는 관례이다.

  3. 실습표본 자료를 담는 클래스 Sample을 만들어라. 생성할 때 숫자 리스트를 받고, mean() 메서드와 len()이 동작하도록 __len__을 정의하여라. s = Sample([1, 2, 3, 6])에서 s.mean(), len(s)의 값을 써라. [02-02]

    힌트 1

    생성자는 __init__(self, data)이고, 자료는 self.data에 저장한다.

    힌트 2

    메서드의 첫 인수는 항상 self이다.

    풀이 
    class Sample:
    def __init__(self, data):
        self.data = list(data)

    def mean(self):
        return sum(self.data) / len(self.data)

    def __len__(self):
        return len(self.data)

s = Sample([1, 2, 3, 6])
print(s.mean(), len(s))   # 3.0 4

    list(data)로 복사해 두면 바깥 리스트가 나중에 바뀌어도 객체 안의 자료가 바뀌지 않습니다(응통4-01-02의 별칭 문제).

  4. 판단클래스에 def mean(): return sum(self.data) / len(self.data)라고 쓰고 s.mean()을 호출했더니 TypeError: Sample.mean() takes 0 positional arguments but 1 was given이 났다. 원인과 해결책을 써라. [02-02]

    힌트 1

    s.mean()은 내부적으로 Sample.mean(s)로 바뀌어 호출된다.

    힌트 2

    정의에 인수가 몇 개 있나요?

    풀이

    s.mean()은 객체 자신 s를 첫 인수로 넘기는데, 정의에 받을 자리가 없어 "인수 0개를 받는데 1개가 주어졌다"는 오류가 난다. 또 정의 안의 self도 정의되지 않은 이름이다. def mean(self):로 고치면 된다.

  5. 실습문자열 리스트 ["10", "20", "삼십", "40"]을 실수로 바꾸되, 바꿀 수 없는 값은 None으로 두는 함수 safe_float를 try/except로 작성하여라. 결과 리스트를 써라. [02-03]

    힌트 1

    float("삼십")은 어떤 예외를 일으키나요?

    힌트 2

    특정 예외만 잡으려면 except ValueError:라고 쓴다.

    풀이 
    def safe_float(s):
    try:
        return float(s)
    except ValueError:
        return None

print([safe_float(v) for v in ["10", "20", "삼십", "40"]])
# [10.0, 20.0, None, 40.0]

    R의 as.numeric이 경고와 함께 NA를 만드는 것과 비슷하지만, 파이썬은 예외를 직접 처리해야 한다. 평균을 낼 때는 None을 걸러야 한다.

  6. 판단다음 코드처럼 모든 예외를 한꺼번에 잡는 것의 위험을 두 가지 쓰고 고쳐라. [02-03]

    try:
    value = float(rwo["score"])
except:
    value = 0
    힌트 1

    변수 이름의 오타(rwo)도 예외(NameError)를 일으킨다.

    힌트 2

    결측을 0으로 바꾸면 평균은 어떻게 되나요?

    풀이

    첫째, except:는 오타로 생긴 NameError나 키가 없는 KeyError, 심지어 사용자가 누른 중단(KeyboardInterrupt)까지 삼켜 버려 버그를 숨긴다. 이 코드는 오타 때문에 모든 행이 0이 되는데도 아무 오류가 나지 않는다. 둘째, 바꿀 수 없는 값을 0으로 채우면 평균이 아래로 치우친다.

    try:
    value = float(row["score"])
except ValueError:
    value = None   # 결측으로 표시하고 나중에 처리
