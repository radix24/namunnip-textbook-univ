이분법과 뉴턴 방법으로 근 찾기

본문

  • 이분법과 뉴턴 방법을 함수로 구현한다.
  • 두 방법의 수렴 속도와 안정성을 비교한다.
먼저 알아야 할 것
  • 중간값 정리와 테일러 근사 (응통1 1.2, 2.3절), 함수 (1.1절).

방정식을 컴퓨터로 풀기

내부수익률(IRR), 분위수, 최대가능도 방정식처럼 손으로 풀 수 없는 방정식 \(f(x) = 0\)이 많습니다. 반복해서 근에 다가가는 두 가지 기본 방법을 직접 만들어 봅니다.

4.1.1이분법

\(f(a)\)와 \(f(b)\)의 부호가 다르면 중간값 정리로 사이에 근이 있습니다. 가운데 점 \(m\)에서 부호를 보고 근이 있는 절반만 남깁니다.

def bisect(f, a, b, tol=1e-10, maxit=200):
    fa = f(a)
    if fa * f(b) > 0:
        raise ValueError("f(a)와 f(b)의 부호가 같습니다.")
    for _ in range(maxit):
        m = (a + b) / 2
        fm = f(m)
        if fm == 0 or (b - a) / 2 < tol:
            return m
        if fa * fm < 0:
            b = m
        else:
            a, fa = m, fm
    return (a + b) / 2

매 단계 구간이 절반이 되므로 오차가 \(2^{-k}\)로 줄어듭니다(선형 수렴, 약 3.3단계마다 한 자리). 느리지만 부호가 바뀌는 구간만 있으면 반드시 수렴합니다.

4.1.2뉴턴 방법

현재 점에서 접선을 그어 그 접선의 근으로 옮깁니다: \(x_{k+1} = x_k - f(x_k)/f'(x_k)\).

def newton(f, df, x0, tol=1e-12, maxit=50):
    x = x0
    for k in range(maxit):
        step = f(x) / df(x)
        x -= step
        if abs(step) < tol:
            return x, k + 1
    raise RuntimeError("수렴하지 않았습니다.")

근 근처에서는 2차 수렴(맞는 자릿수가 매번 약 두 배)이라 매우 빠르지만, 출발점이 멀거나 \(f'\)이 0에 가까우면 발산할 수 있습니다. 실무에서는 이분법으로 좁힌 뒤 뉴턴으로 마무리하는 혼합 방법(브렌트 방법, scipy.optimize.brentq)을 씁니다.

예제 4.1.1

\(\sqrt2\)를 \(f(x) = x^2 - 2\)의 근으로 두 방법으로 구하고 반복 횟수를 비교하세요.

f = lambda x: x * x - 2
print(bisect(f, 1, 2))                       # 1.41421356..., 34번 반복
print(newton(f, lambda x: 2 * x, 1.0))       # (1.4142135623730951, 6)

뉴턴 방법은 1 → 1.5 → 1.4167 → 1.41422 → …로 다섯 번째에 기계 정밀도에 닿습니다.

요약
  1. 이분법: 확실하지만 느림(선형 수렴).
  2. 뉴턴: 빠르지만(2차 수렴) 좋은 출발점 필요.
  3. 실무는 혼합 방법(brentq).

4.1.3연습문제

응용

  1. 3년 동안 매년 말 100만 원씩 받는 투자에 250만 원을 냈습니다. 내부수익률 \(r\)(\(\sum_{t=1}^3 100/(1+r)^t = 250\))을 이분법으로 구하세요.
    답

    bisect(lambda r: sum(100 / (1 + r) ** t for t in (1, 2, 3)) - 250, 0, 1) → 약 0.097(9.7%).
