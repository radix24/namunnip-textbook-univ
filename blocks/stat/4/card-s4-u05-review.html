혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 실습df = pd.read_csv("survey.csv")로 읽은 직후 확인할 내용을 pandas 메서드와 함께 세 가지 써라. [05-01]

    힌트 1

    행과 열의 수, 각 열의 자료형을 한 번에 보여 주는 메서드가 있다.

    힌트 2

    결측값 개수는 isna()와 sum()을 이어 쓴다.

    풀이

    (1) 구조: df.shape, df.head(), df.info()로 행·열 수와 자료형(int64, float64, object)을 본다. 숫자여야 할 열이 object면 글자가 섞인 것이다. (2) 요약: df.describe()로 범위와 이상한 값을 본다. (3) 결측: df.isna().sum()으로 열별 결측 개수를 센다. 범주형 열은 df["지역"].value_counts(dropna=False)로 오타 범주를 확인한다.

  2. 실습df에 열 name, score가 있다. (1) 점수 80 이상인 사람의 이름을 고르는 코드, (2) 첫 3행의 첫 2열을 위치로 고르는 코드를 쓰고, loc와 iloc의 차이를 써라. [05-01]

    힌트 1

    loc는 이름(레이블)과 조건으로, iloc는 정수 위치로 고른다.

    힌트 2

    iloc의 슬라이스는 끝을 포함하지 않는다.

    풀이 
    df.loc[df["score"] >= 80, "name"]
df.iloc[0:3, 0:2]

    loc는 행 이름과 열 이름(또는 불리언 조건)으로 고르고, 이름 슬라이스는 끝을 포함한다. iloc는 0부터 시작하는 위치로 고르고, 슬라이스는 끝을 포함하지 않습니다(파이썬 규칙). df[df.score >= 80]["name"] = ...처럼 연달아 대괄호로 값을 바꾸면 경고(SettingWithCopyWarning)가 나므로, 값을 바꿀 때는 loc 하나로 쓴다.

  3. 실습mtcars 자료를 df로 읽었다. 실린더 수별 차량 수와 평균 연비를 구하는 코드를 쓰고 결과를 써라. [05-02]

    힌트 1

    df.groupby("cyl")["mpg"] 다음에 집계 함수를 쓴다.

    힌트 2

    여러 통계량은 .agg(["count", "mean"])으로 한꺼번에 구한다.

    풀이 
    df.groupby("cyl")["mpg"].agg(["count", "mean"]).round(2)

    결과는 4기통 11대(26.66), 6기통 7대(19.74), 8기통 14대(15.10)로, 응통3-02-03의 R 결과와 같다. 이름 붙은 집계는 df.groupby("cyl").agg(n=("mpg", "size"), mpg=("mpg", "mean"))로 쓴다.

  4. 실습판매 자료 sales가 열 region, month, amount를 가진 긴 형식이다. 지역을 행, 월을 열로 하는 합계 표를 만들고, 다시 긴 형식으로 되돌리는 코드를 써라. [05-02]

    힌트 1

    피벗 표는 pd.pivot_table(data, index, columns, values, aggfunc)이다.

    힌트 2

    넓은 형식을 긴 형식으로 바꾸는 메서드는 melt이다.

    풀이 
    wide = pd.pivot_table(sales, index="region", columns="month",
                      values="amount", aggfunc="sum", fill_value=0)
long = wide.reset_index().melt(id_vars="region",
                               var_name="month", value_name="amount")

    같은 지역·월 조합이 여러 행이면 aggfunc로 합칩니다(pivot은 중복이 있으면 오류). fill_value=0은 판매가 없던 칸을 0으로 채우는데, "판매 0"과 "자료 없음"이 다르다면 NaN으로 두어야 한다.

  5. 실습학생 표 st(id 1, 2, 3)와 점수 표 sc(id 2, 3, 4)를 결합할 때 pd.merge의 how 값에 따른 행 수를 쓰고, 결합 후 검사하는 방법을 써라. [05-02]

    힌트 1

    how는 "inner"(기본), "left", "right", "outer"이다.

    힌트 2

    validate와 indicator 인수가 결합 검사에 쓰인다.

    풀이

    inner 2행(id 2, 3), left 3행(id 1~3, id 1의 점수는 NaN), right 3행(id 2~4), outer 4행이다.

    pd.merge(st, sc, on="id", how="left", validate="one_to_one", indicator=True)로 쓰면 키가 중복될 때 오류를 내고, _merge 열에 각 행이 어느 쪽에서 왔는지 표시해 준다.

  6. 실습matplotlib으로 한 그림에 두 패널(왼쪽: 연비 히스토그램, 오른쪽: 무게와 연비의 산점도)을 그리고 파일로 저장하는 코드를 써라. plt.subplots를 쓰는 객체 방식의 장점도 써라. [05-03]

    힌트 1

    fig, axes = plt.subplots(1, 2, figsize=(9, 4))로 두 축을 만든다.

    힌트 2

    각 축에 hist, scatter, set_xlabel을 쓴다.

    풀이 
    import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 2, figsize=(9, 4))
axes[0].hist(df["mpg"], bins=8)
axes[0].set_xlabel("연비"); axes[0].set_ylabel("대수")
axes[1].scatter(df["wt"], df["mpg"])
axes[1].set_xlabel("무게 (1000 lb)"); axes[1].set_ylabel("연비")
fig.tight_layout()
fig.savefig("mpg.png", dpi=150)

    객체 방식은 어느 패널에 무엇을 그리는지 명시하므로 여러 패널을 다루기 쉽고, 함수로 묶어 재사용하기 좋다. 한글 글꼴이 깨지면 plt.rcParams["font.family"]를 설치된 한글 글꼴로 지정한다.

    힌트 2
