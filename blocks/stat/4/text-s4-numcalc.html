수치 미분과 수치 적분

본문

도함수는 \(\lim_{h \to 0} (f(x+h) - f(x))/h\)이다. 그렇다면 컴퓨터에서 \(h\)를 \(10^{-15}\)처럼 아주 작게 잡으면 가장 정확한 도함수를 얻을까? 그리고 \(\int_0^1 e^{-t^2}\,dt\)처럼 닫힌 꼴이 없는 적분은 어떻게 값을 구할까?

먼저 알아야 할 것근 찾기와 최적화(4.1절, 4.2절), 테일러 전개(응통1 2.3절)를 쓴다.

4.3.1수치 미분

최적화(4.2절)에는 기울기가 필요하지만 복잡한 가능도는 손으로 미분하기 어렵다. 그래서 함숫값만으로 도함수를 어림한다. 테일러 전개 \(f(x \pm h) = f(x) \pm hf'(x) + \frac{h^2}{2}f''(x) \pm \frac{h^3}{6}f'''(x) + \cdots\)에서 두 공식의 오차를 읽을 수 있다.

결과 4.3.1 (차분 공식의 절단 오차) \[\frac{f(x+h) - f(x)}{h} = f'(x) + \frac h2 f''(x) + O(h^2), \qquad \frac{f(x+h) - f(x-h)}{2h} = f'(x) + \frac{h^2}{6}f'''(x) + O(h^4)\]

앞의 것을 전진 차분, 뒤의 것을 중심 차분이라 한다. 중심 차분은 두 전개를 빼면서 짝수 차 항이 상쇄되어 오차가 \(O(h^2)\)로 줄어든다. 그렇다면 처음 질문처럼 \(h\)를 한없이 줄이면 될까? 그렇지 않다. \(f(x+h)\)와 \(f(x)\)가 거의 같아지면 두 수의 차에서 유효숫자가 사라지는 상쇄 오차(응통15 1.1절)가 생기고, 그 크기는 기계 정밀도 \(\epsilon \approx 10^{-16}\)을 \(h\)로 나눈 정도이다. 그래서 그림 1처럼 오차는 \(h\)가 줄면 줄다가 다시 커지며, 전진 차분은 \(h \approx \sqrt\epsilon \approx 10^{-8}\), 중심 차분은 \(h \approx \epsilon^{1/3} \approx 10^{-5}\)이 알맞다.

import numpy as np
def dcentral(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)
dcentral(np.exp, 0.0)        # 1.0000000000 근처
예제 4.3.1

\(f(x) = e^x\)의 \(x = 0\) 도함수를 \(h = 0.1\)로 전진 차분과 중심 차분으로 어림하여라.

풀이. 전진 차분은 \((e^{0.1} - 1)/0.1 = 1.0517\)로 오차 0.052가 \(h/2 = 0.05\)와 맞는다. 중심 차분은 \((e^{0.1} - e^{-0.1})/0.2 = 1.00167\)로 오차 0.0017이 \(h^2/6\)과 맞는다. 따라서 같은 \(h\)에서 중심 차분이 30배 정확하다.

4.3.2수치 적분

이제 둘째 질문이다. 적분 구간을 \(n\)개로 나누어, 조각마다 함수를 직선으로 바꾸면 사다리꼴 공식, 두 조각씩 포물선으로 바꾸면 심프슨 공식이 된다.

def trapezoid(f, a, b, n):
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a) / n
    return h * (y[0] / 2 + y[1:-1].sum() + y[-1] / 2)

def simpson(f, a, b, n):            # n은 짝수
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a) / n
    return h / 3 * (y[0] + 4 * y[1:-1:2].sum() + 2 * y[2:-1:2].sum() + y[-1])

from scipy.integrate import quad
quad(lambda t: np.exp(-t**2), 0, 1)   # (0.746824..., 오차 추정)

사다리꼴의 오차는 \(O(h^2)\), 심프슨은 \(O(h^4)\)이다(응통15 4.1절). 즉 \(n\)을 두 배로 늘리면 사다리꼴은 오차가 4분의 1, 심프슨은 16분의 1로 준다. 한편 quad는 함수가 급하게 변하는 곳만 잘게 나누는 적응 구적법으로, 값과 함께 오차 추정값을 돌려준다.

흔한 실수심프슨 공식에 홀수 \(n\)을 넣으면 오류 없이 틀린 값이 나온다. 포물선은 두 조각씩 묶이므로 \(n\)은 짝수여야 하고, 함수 첫머리에서 확인해 ValueError를 일으키는 편이 낫다(2.3절).
마무리

도함수는 차분으로 어림하며, 테일러 전개에서 전진 차분의 오차는 \(O(h)\), 중심 차분은 \(O(h^2)\)이다. 하지만 \(h\)를 너무 작게 잡으면 상쇄 오차가 커지므로 전진 차분은 \(10^{-8}\), 중심 차분은 \(10^{-5}\) 안팎이 알맞다. 적분은 사다리꼴(\(O(h^2)\))과 심프슨(\(O(h^4)\)) 공식으로 어림하고, 실무에서는 오차 추정까지 주는 적응 구적법 quad를 쓴다.

4.3.3연습문제

기본

  1. 예제 4.3.1의 중심 차분에서 \(h\)를 0.01로 줄이면 오차는 대략 얼마가 되는가?
    답

    오차가 \(h^2\)에 비례하므로 100분의 1인 약 \(1.7 \times 10^{-5}\)이다.

응용

  1. 로그가능도 \(\ell(\theta)\)의 이계 도함수를 수치 미분으로 어림하는 공식을 쓰고, 그 값으로 무엇을 구할 수 있는지 써라.
    답

    \(\ell''(\theta) \approx \frac{\ell(\theta + h) - 2\ell(\theta) + \ell(\theta - h)}{h^2}\)이다. 최대가능도 추정값에서 \(-1/\ell''\)이 분산의 어림이므로 표준오차를 구할 수 있다. R의 optim(..., hessian = TRUE)가 하는 일이 이것이다.
