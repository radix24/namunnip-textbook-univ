통계 라이브러리로 기술통계, 검정, 회귀

본문

R에서는 qnorm(0.975), t.test(a, b), summary(lm(y ~ x)) 한 줄이면 분위수, 검정, 회귀표가 나왔다. 파이썬에서 같은 분석을 하려면 어디를 찾아야 할까? 그리고 결과표는 R과 같은 방식으로 읽으면 될까?

먼저 알아야 할 것pandas(5.1절)와 응통5의 검정과 회귀를 쓴다.

6.1.1scipy.stats

파이썬에서 고전 통계 분석은 주로 두 라이브러리로 한다. scipy.stats는 분포와 검정을, statsmodels는 R과 비슷한 공식 문법의 회귀모형과 요약표를 맡는다. 먼저 분포와 검정부터 보자.

from scipy import stats
stats.norm.cdf(1.96); stats.norm.ppf(0.975); stats.t.ppf(0.975, df=9)   # 0.975, 1.96, 2.262
a = tips.loc[tips.time == "Lunch", "tip"]; b = tips.loc[tips.time == "Dinner", "tip"]
stats.ttest_ind(a, b, equal_var=False)        # 웰치 t 검정
stats.mannwhitneyu(a, b)                      # 맨-휘트니
tab = pd.crosstab(tips.sex, tips.smoker)
stats.chi2_contingency(tab)                   # 카이제곱 통계량, p값, 자유도, 기대 도수

여기서 분포는 stats.norm, stats.t처럼 객체이고, 메서드 이름으로 할 일을 고른다. pdf(이산이면 pmf)는 밀도, cdf는 누적확률, ppf는 분위수, rvs는 난수로, R의 d, p, q, r 함수(응통3 4.1절)와 같다(그림 1). 주의할 점은 ttest_ind의 기본값이 등분산을 가정한다는 것이다. R의 t.test는 기본이 웰치 검정이므로, 같은 결과를 얻으려면 equal_var=False를 준다.

6.1.2statsmodels 회귀

이제 처음 질문의 회귀표이다. statsmodels의 공식 인터페이스는 R의 lm과 같은 공식 문법을 쓴다.

import statsmodels.formula.api as smf
fit = smf.ols("tip ~ total_bill + C(time) + size", data=tips).fit()
print(fit.summary())         # 계수, 표준오차, t, p, 신뢰구간, R²
fit.params; fit.conf_int(); fit.resid
smf.logit("I(smoker == 'Yes') ~ total_bill", data=tips).fit().summary()   # 로지스틱

이때 C()는 범주형 변수를 가변수로 바꾸고(응통10 3.1절), summary()의 계수표는 R과 같은 방식으로 읽는다. 그런데 파이썬에는 머신러닝 도구 scikit-learn도 있다. scikit-learn은 예측 성능에 맞추어져 있어 표준오차나 p값을 주지 않으므로, 계수를 해석하고 추론할 때는 statsmodels가 편하다.

예제 6.1.1

scipy로 자유도 3인 카이제곱 분포의 95% 분위수와, 검정통계량 9.0의 위꼬리 p값을 구하여라.

stats.chi2.ppf(0.95, 3)      # 7.815
stats.chi2.sf(9.0, 3)        # 0.029

풀이. 분위수는 ppf이다. 한편 위꼬리 확률은 1 - cdf로도 구하지만, 생존함수 sf를 쓰면 아주 작은 p값에서도 빼기의 반올림 오차가 생기지 않는다. 따라서 9.0이 7.815보다 크므로 p값은 0.05보다 작다.

흔한 실수statsmodels의 공식 없는 인터페이스 sm.OLS(y, X)는 절편을 자동으로 넣지 않는다. 그러므로 공식 인터페이스 smf.ols를 쓰거나 sm.add_constant(X)로 1의 열을 붙이자.
마무리

파이썬의 고전 통계는 scipy.stats와 statsmodels가 나누어 맡는다. scipy.stats의 분포 객체는 pdf, cdf, ppf, rvs, sf로 R의 d, p, q, r 함수를 대신하고, ttest_ind, chi2_contingency 같은 검정을 준다. statsmodels는 ols("y ~ x", data) 같은 R식 공식으로 회귀를 적합해 summary()로 표준오차와 p값을 보여 준다. 기본값이 R과 다른 곳(등분산 가정, 절편)을 확인하자.

응용

  1. 위 회귀에서 C(time)의 계수는 무엇과 무엇의 차이를 뜻하는가?
    답

    seaborn의 tips는 time을 Lunch, Dinner 순서의 범주형으로 두므로 첫 범주 Lunch가 기준이 되고, 요약표에는 C(time)[T.Dinner]로 나온다. 계산 금액과 인원이 같을 때 저녁 손님의 평균 팁이 점심 손님과 얼마나 다른지를 뜻한다. 문자열 열이라면 알파벳 순으로 앞인 범주가 기준이다.
