R의 t.test와 lm을 파이썬에서

파이썬에서 고전 통계 분석은 주로 두 라이브러리로 합니다. scipy.stats는 분포와 검정, statsmodels는 R과 비슷한 공식 문법의 회귀모형과 요약표를 제공합니다.

6.1.1scipy.stats

from scipy import stats
stats.norm.cdf(1.96); stats.norm.ppf(0.975); stats.t.ppf(0.975, df=9)   # 0.975, 1.96, 2.262
a = tips.loc[tips.time == "Lunch", "tip"]; b = tips.loc[tips.time == "Dinner", "tip"]
stats.ttest_ind(a, b, equal_var=False)        # 웰치 t 검정
stats.mannwhitneyu(a, b)                      # 맨-휘트니
tab = pd.crosstab(tips.sex, tips.smoker)
stats.chi2_contingency(tab)                   # 카이제곱 통계량, p값, 자유도, 기대 도수

분포 객체의 메서드 이름: pdf/pmf(밀도), cdf(누적), ppf(분위수), rvs(난수). R의 d, p, q, r과 같습니다(응통3 4.1절).

6.1.2statsmodels 회귀

import statsmodels.formula.api as smf
fit = smf.ols("tip ~ total_bill + C(time) + size", data=tips).fit()
print(fit.summary())         # 계수, 표준오차, t, p, 신뢰구간, R²
fit.params; fit.conf_int(); fit.resid
smf.logit("I(smoker == 'Yes') ~ total_bill", data=tips).fit().summary()   # 로지스틱

C()는 범주형 변수를 가변수로 바꿉니다(응통10 3.1절). 공식 문법은 R의 lm과 같습니다.

요약
  1. scipy.stats: cdf/ppf/pdf/rvs, ttest_ind, chi2_contingency.
  2. statsmodels: 공식 문법 ols("y ~ x", data), summary().
  3. 머신러닝 예측에는 scikit-learn이 있지만, 추론(표준오차, p값)은 statsmodels가 편합니다.
