statsmodels로 로지스틱 회귀

본문

쿠폰을 받은 고객 40명 가운데 20명이, 받지 않은 40명 가운데 10명이 물건을 샀다. 쿠폰의 효과를 나이와 지역을 고려해 추정하고 싶다. 반응이 산다, 안 산다의 0과 1이면 6.1절의 ols를 그대로 쓸 수 없는데, 파이썬에서는 어떤 모형으로 적합하고 계수를 어떻게 읽을까?

먼저 알아야 할 것통계 라이브러리(6.1절)와 로지스틱 회귀의 이론(응통18 3단원)을 쓴다.

6.4.1적합

0과 1의 반응에는 로지스틱 회귀를 쓴다. 확률 \(p\)를 직접 선형으로 두면 0과 1 밖으로 벗어나므로, 오즈 \(p/(1-p)\)의 로그를 선형으로 둔다. 그러면 그림 1처럼 확률은 S자 곡선이 된다. statsmodels는 R과 같은 공식 문법과 검정 결과표를 주므로 해석 중심 분석에 알맞다.

import numpy as np, pandas as pd
import statsmodels.formula.api as smf
fit = smf.logit("buy ~ age + C(region)", data=df).fit()
print(fit.summary())             # 계수, 표준오차, z, p, 로그가능도
np.exp(fit.params)               # 오즈비
np.exp(fit.conf_int())           # 오즈비의 95% 구간
fit.predict(pd.DataFrame({"age": [30], "region": ["서울"]}))   # 예측 확률

계수는 로그 오즈의 변화이므로 지수를 취해 오즈비로 읽는다. 예를 들어 나이 계수가 0.06이면 나이가 10세 많을 때 오즈가 \(e^{0.6} = 1.82\)배이다. 신뢰구간도 끝점마다 지수를 취하면 오즈비의 구간이 된다. 또 C()는 범주형 변수를 가변수로 바꾸고(R의 factor), 반응은 0과 1의 정수여야 한다.

그런데 어떤 변수가 결과를 완벽히 가르면, 곧 완전 분리가 있으면 계수가 한없이 커져 수렴하지 않고 경고가 난다. 그때는 벌점을 준 적합(fit_regularized)이나 베이즈 방법(응통21 6.3절)을 쓴다.

6.4.2statsmodels와 scikit-learn

파이썬에는 로지스틱 회귀가 하나 더 있다. scikit-learn의 LogisticRegression은 예측 성능 중심이라 기본으로 L2 벌점(능형, 응통10 6.4절)이 걸려 있다. 그래서 계수가 0 쪽으로 줄어 있고, 표준오차와 p값을 주지 않는다. 따라서 계수를 해석하고 검정하려면 statsmodels를, 예측 모형을 교차검증으로 고르려면 scikit-learn을 쓴다. scikit-learn에서 벌점을 빼려면 penalty=None을 지정한다.

예제 6.4.1

처음 질문의 자료로 smf.logit("buy ~ coupon", df)를 적합할 때 계수를 미리 계산하고 오즈비를 해석하여라.

풀이. 설명변수가 이진 하나이면 모형이 두 집단의 비율을 그대로 맞추는 포화 모형이라 계수가 표에서 바로 나온다. 절편은 쿠폰 없는 쪽의 로그 오즈 \(\log(10/30) = -1.099\)이고, 기울기는 로그 오즈비 \(\log\frac{20/20}{10/30} = \log 3 = 1.099\)이다. 즉 쿠폰을 받으면 구매 오즈가 3배이다. 예측 확률은 쿠폰 없음 0.25, 있음 0.5로 관측 비율과 같다.

흔한 오해오즈비 3을 "구매 확률이 3배"로 읽기 쉽다. 이 예에서 확률은 0.25에서 0.5로 2배일 뿐이다. 오즈비와 확률비는 사건이 드물 때만 비슷하다.
마무리

0과 1의 반응은 smf.logit("y ~ x + C(g)", df).fit()으로 로지스틱 회귀를 적합한다. 계수는 로그 오즈의 변화이므로 np.exp(params)와 np.exp(conf_int())로 오즈비와 그 구간을 읽고, 확률이 아니라 오즈가 곱으로 변한다는 점에 주의한다. 해석과 검정은 statsmodels, 예측 모형 선택은 scikit-learn에 맡기되 scikit-learn의 기본 벌점을 기억하자.

6.4.3연습문제

기본

  1. 나이 계수가 0.04이면 나이 10세 증가의 오즈비는 얼마인가?
    답

    \(e^{0.4} = 1.49\)이다. 오즈가 약 1.5배가 된다.

응용

  1. 같은 자료를 scikit-learn 기본값으로 적합했더니 계수가 statsmodels보다 작았다. 이유는 무엇인가?
    답

    scikit-learn의 기본 L2 벌점(C=1.0)이 계수를 0 쪽으로 줄였기 때문이다. 표본이 작을수록 차이가 크며, penalty=None으로 맞추면 같아진다.
