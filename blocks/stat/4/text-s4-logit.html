statsmodels로 로지스틱 회귀

본문
이 절에서 배울 것
  • 공식 문법(smf.logit)으로 로지스틱 회귀를 적합한다.
  • 계수와 신뢰구간을 지수로 바꿔 오즈비로 해석한다.
  • 예측 확률을 구하고 statsmodels와 scikit-learn의 차이를 안다.
먼저 알아야 할 것
  • 통계 라이브러리 (6.1절), 로지스틱 회귀의 이론 (응통18 03단원).

결과가 예/아니요일 때

6.1절의 ols는 연속 반응에 씁니다. 합격 여부, 구매 여부처럼 0/1 반응에는 로지스틱 회귀를 씁니다. statsmodels는 R과 비슷한 공식 문법과 통계 검정 결과표를 주어 해석 중심 분석에 알맞습니다.

6.4.1적합

import numpy as np, pandas as pd
import statsmodels.formula.api as smf
fit = smf.logit("buy ~ age + C(region)", data=df).fit()
print(fit.summary())             # 계수, 표준오차, z, p, 로그가능도
np.exp(fit.params)               # 오즈비
np.exp(fit.conf_int())           # 오즈비의 95% 구간
fit.predict(pd.DataFrame({"age": [30], "region": ["서울"]}))   # 예측 확률

C()는 범주형 변수를 가변수로 바꿉니다(R의 factor). 반응은 0/1 정수여야 합니다. 완전 분리(어떤 변수가 결과를 완벽히 가름)가 있으면 수렴하지 않고 경고가 나므로, 그때는 벌점을 준 적합(fit_regularized)이나 베이즈 방법(응통21 6.3절)을 씁니다.

6.4.2statsmodels와 scikit-learn

scikit-learn의 LogisticRegression은 예측 성능 중심이라 기본으로 L2 벌점(능형, 응통10 6.4절)이 걸려 있어 계수가 0 쪽으로 줄어 있고, 표준오차와 p값을 주지 않습니다. 계수를 해석하고 검정하려면 statsmodels를, 예측 모형을 교차검증으로 고르려면 scikit-learn을 씁니다. scikit-learn에서 벌점을 빼려면 penalty=None을 지정합니다.

예제 6.4.1

쿠폰을 받은 40명 중 20명, 받지 않은 40명 중 10명이 구매했습니다. smf.logit("buy ~ coupon", df)의 계수를 예상하고 오즈비를 해석하세요.

풀이. 설명변수가 이진이면 포화 모형이라 계수가 표에서 바로 나옵니다. 절편 = 쿠폰 없는 쪽 로그 오즈 \(\log(10/30) = -1.099\), 기울기 = 로그 오즈비 \(\log\frac{20/20}{10/30} = \log 3 = 1.099\). 쿠폰을 받으면 구매 오즈가 3배입니다. 예측 확률은 쿠폰 없음 0.25, 있음 0.5로 관측 비율과 같습니다.

요약
  1. smf.logit("y ~ x + C(g)", df).fit().
  2. np.exp(params), np.exp(conf_int())로 오즈비와 구간.
  3. 해석·검정은 statsmodels, 예측 모형 선택은 scikit-learn(기본 벌점 주의).

6.4.3연습문제

기본

  1. 나이 계수가 0.04이면 나이 10세 증가의 오즈비는?
    답

    \(e^{0.4} = 1.49\). 오즈가 약 1.5배.

응용

  1. 같은 자료를 scikit-learn 기본값으로 적합했더니 계수가 statsmodels보다 작았습니다. 이유는?
    답

    scikit-learn의 기본 L2 벌점(C=1.0)이 계수를 0 쪽으로 줄였기 때문입니다. 표본이 작을수록 차이가 큽니다. penalty=None으로 맞추면 같아집니다.
