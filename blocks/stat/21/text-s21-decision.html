틀렸을 때의 대가로 고르기

재고를 너무 많이 주문하면 남은 물건 비용이, 너무 적게 주문하면 놓친 판매 이익이 손실입니다. 두 손실이 다르면 "평균"이 최선의 추정이 아닙니다. 결정이론은 손실을 명시하고 기대 손실을 최소화하는 결정을 찾습니다.

5.1.1틀

손실함수 \(L(\theta, a)\): 참값이 \(\theta\)일 때 결정 \(a\)의 대가.

사후 기대 손실: \(\rho(a \mid \mathbf y) = E[L(\theta, a) \mid \mathbf y]\).

베이즈 규칙: 사후 기대 손실을 최소화하는 \(a\).

5.1.2대표 손실

정리 5.1.1

(가) 제곱 손실 \((\theta - a)^2\)의 베이즈 추정량은 사후 평균. (나) 절대 손실 \(|\theta - a|\)는 사후 중앙값. (다) 0-1 손실(정확히 맞히면 0)은 사후 최빈값.

(가) \(E[(\theta - a)^2 \mid \mathbf y] = \mathrm{Var}(\theta \mid \mathbf y) + (E[\theta \mid \mathbf y] - a)^2\)는 \(a = E[\theta \mid \mathbf y]\)에서 최소. (나) \(\frac{d}{da}E|\theta - a| = P(\theta < a \mid \mathbf y) - P(\theta > a \mid \mathbf y) = 0\)이면 \(a\)는 중앙값. ∎

비대칭 손실 \(L = c_1(\theta - a)\)(과소), \(c_2(a - \theta)\)(과대)이면 베이즈 추정량은 사후분포의 \(c_1/(c_1 + c_2)\) 분위수입니다(신문팔이 문제).

예제 5.1.2

내일 빵 수요의 사후분포가 \(N(200, 20^2)\)입니다. 남는 빵 하나의 손실이 500원, 모자란 빵 하나의 손실(놓친 이익)이 1500원이면 몇 개를 구워야 하나요?

풀이. \(c_1 = 1500\)(과소), \(c_2 = 500\)(과대), 분위수 \(1500/2000 = 0.75\). \(200 + 0.674\times20 \approx 213.5\), 약 214개. 모자라는 손실이 더 크므로 평균보다 많이 굽습니다.

요약
  1. 사후 기대 손실 최소화 = 베이즈 규칙.
  2. 제곱 → 평균, 절대 → 중앙값, 0-1 → 최빈값.
  3. 비대칭 선형 손실 → 분위수.
