베이즈 선형회귀

본문

회귀분석에서 능형 회귀는 계수가 너무 커지지 않도록 벌점을 준다. 이 벌점은 계산의 편의를 위한 장치처럼 보인다. 그런데 계수가 0 근처일 것이라는 믿음을 사전분포로 두고 베이즈 추론을 하면, 그 사후 평균이 능형 회귀와 같아진다. 벌점은 사실 무엇이었을까?

먼저 알아야 할 것깁스 표집(6.1절), 회귀분석과 능형 회귀(응통10 6.4절)를 쓴다.

처음 질문의 답은 사전분포이다. 능형 회귀의 벌점은 계수가 0 근처라는 사전 믿음으로 해석되며, 사후는 최소제곱 추정을 그 믿음 쪽으로 당긴 것이다(그림 1). 게다가 계수마다 사후분포를 얻으므로 가격 탄력성이 −1보다 작을 확률 같은 질문에 답하고, 예측에 모수의 불확실성까지 반영할 수 있다.

6.2.1사후분포

\(\mathbf y \mid \boldsymbol\beta, \sigma^2 \sim N(X\boldsymbol\beta, \sigma^2I)\)이고 사전이 \(\boldsymbol\beta \sim N(\mathbf 0, \sigma^2\lambda^{-1}I)\)라 하자. 여기서는 \(\sigma^2\)을 안다고 둔다.

정리 6.2.1 (회귀계수의 사후분포)

\(\boldsymbol\beta \mid \mathbf y \sim N\left((X^\top X + \lambda I)^{-1}X^\top\mathbf y,\ \sigma^2(X^\top X + \lambda I)^{-1}\right)\)이다.

따라서 사후 평균은 능형 회귀 추정량(응통10 6.4절)과 같다. 마찬가지로 라쏘는 라플라스(이중지수) 사전의 사후 최빈값이다. 반면 \(\lambda \to 0\)으로 사전을 평평하게 하면 최소제곱과 같아진다. 또 \(\sigma^2\)도 모르면 역감마 사전을 두고, 6.1절과 같은 구조의 깁스 표집으로 계산한다.

6.2.2사후 예측

새 \(\mathbf x_0\)에서의 예측분포 \(p(y_0 \mid \mathbf y) = \int p(y_0 \mid \boldsymbol\beta)p(\boldsymbol\beta \mid \mathbf y)\,d\boldsymbol\beta\)는 \(N(\mathbf x_0^\top\hat{\boldsymbol\beta}, \sigma^2[1 + \mathbf x_0^\top(X^\top X + \lambda I)^{-1}\mathbf x_0])\)이다. 이것은 응통10 1.5절 예측구간과 같은 구조이다. 한편 MCMC 표본이 있으면 표본마다 \(y_0\)를 뽑아 분포를 얻는다.

예제 6.2.1

설명변수 하나(표준화, \(\sum x_i^2 = n = 20\)), \(\sum x_iy_i = 30\), \(\sigma^2 = 4\), \(\lambda = 5\)일 때 기울기의 사후 평균과 표준편차를 구하라. 최소제곱과 비교하라(절편 없음).

풀이. 사후 평균은 \(30/(20 + 5) = 1.2\)이고 분산은 \(4/25 = 0.16\)이라 표준편차는 0.4이다. 반면 최소제곱은 \(30/20 = 1.5\), 표준오차 \(\sqrt{4/20} = 0.447\)이다. 즉 사전이 계수를 0 쪽으로 당기고 불확실성을 줄였다(그림 1). 또 \(P(\beta > 0 \mid \mathbf y) = \Phi(1.2/0.4) = 0.9987\)이다.

흔한 실수

설명변수의 척도가 다른데 같은 \(\lambda\)의 사전을 주면, 단위가 큰 변수의 계수만 지나치게 당겨진다. 그래서 정규 사전을 줄 때는 설명변수를 표준화하거나 변수마다 사전의 폭을 따로 정한다.

마무리

정규 사전에서 회귀계수의 사후는 정규이고, 사후 평균은 능형 추정량이다. 벌점 회귀는 사전분포의 사후 최빈값으로 읽을 수 있다. 사후 예측분포는 모수의 불확실성을 반영한 예측을 준다.

6.2.3연습문제

기본

  1. 예제에서 \(\lambda = 0\)이면 사후분포는 무엇인가?
    답

    \(N(1.5, 0.2)\)이다. 최소제곱 추정과 그 분산과 같다.

응용

  1. 예제의 사전 \(N(0, \sigma^2/\lambda)\)의 분산은 얼마이며, 가상 표본 크기로는 몇 개에 해당하는가?
    답

    분산은 \(4/5 = 0.8\)이다. \(\sum x_i^2 = n\)인 표준화 척도에서 \(\lambda = 5\)는 관측 5개만큼의 무게이다.

  2. 예제에서 \(x_0 = 1\)인 새 관측의 사후 예측분포를 구하라.
    답

    \(N(1.2, 4(1 + 1/25)) = N(1.2, 4.16)\)이다. 예측 분산의 대부분은 관측 잡음 4에서 온다.
