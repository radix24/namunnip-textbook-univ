베이즈 선형회귀

본문
이 절에서 배울 것
  • 계수에 정규 사전을 둔 베이즈 회귀의 사후분포를 안다.
  • 능형 회귀와의 관계와 사후 예측분포를 이해한다.
먼저 알아야 할 것
  • 깁스 표집 (6.1절), 응통10 회귀분석과 6.3절 능형 회귀.

회귀계수에 대한 믿음

회귀계수에도 사전분포를 줄 수 있습니다. 그러면 결과로 계수마다 사후분포를 얻어 "가격 탄력성이 −1보다 작을 확률" 같은 질문에 답하고, 예측에 모수의 불확실성까지 반영할 수 있습니다.

6.2.1사후분포

\(\mathbf y \mid \boldsymbol\beta, \sigma^2 \sim N(X\boldsymbol\beta, \sigma^2I)\), 사전 \(\boldsymbol\beta \sim N(\mathbf 0, \sigma^2\lambda^{-1}I)\)(\(\sigma^2\)을 안다고 두면).

결과 6.2.1

\(\boldsymbol\beta \mid \mathbf y \sim N\left((X^\top X + \lambda I)^{-1}X^\top\mathbf y,\ \sigma^2(X^\top X + \lambda I)^{-1}\right)\).

사후 평균은 능형 회귀 추정량(응통10 6.3절)과 같습니다. 능형 회귀의 벌점은 "계수가 0 근처라는 사전 믿음"으로 해석됩니다. 라쏘는 라플라스(이중지수) 사전의 사후 최빈값입니다. \(\lambda \to 0\)(평평한 사전)이면 최소제곱과 같아집니다. \(\sigma^2\)도 모르면 역감마 사전을 두고 깁스 표집(6.1절과 같은 구조)으로 계산합니다.

6.2.2사후 예측

새 \(\mathbf x_0\)에서의 예측분포 \(p(y_0 \mid \mathbf y) = \int p(y_0 \mid \boldsymbol\beta)p(\boldsymbol\beta \mid \mathbf y)\,d\boldsymbol\beta\)는 \(N(\mathbf x_0^\top\hat{\boldsymbol\beta}, \sigma^2[1 + \mathbf x_0^\top(X^\top X + \lambda I)^{-1}\mathbf x_0])\)로, 응통10 1.3절 예측구간과 같은 구조입니다. MCMC 표본이 있으면 표본마다 \(y_0\)를 뽑아 분포를 얻습니다.

예제 6.2.1

설명변수 하나(표준화, \(\sum x_i^2 = n = 20\)), \(\sum x_iy_i = 30\), \(\sigma^2 = 4\), \(\lambda = 5\)일 때 기울기의 사후 평균과 표준편차는? 최소제곱과 비교하세요(절편 없음).

풀이. 사후 평균 \(30/(20 + 5) = 1.2\), 분산 \(4/25 = 0.16\), 표준편차 0.4. 최소제곱 \(30/20 = 1.5\), 표준오차 \(\sqrt{4/20} = 0.447\). 사전이 계수를 0 쪽으로 당기고 불확실성을 줄였습니다. \(P(\beta > 0 \mid \mathbf y) = \Phi(1.2/0.4) = 0.9987\).

# rstanarm::stan_glm(y ~ x, data = d, prior = normal(0, 1)) 같은 패키지로 MCMC 적합
요약
  1. 정규 사전 → 정규 사후, 평균 = 능형 추정량.
  2. 벌점 회귀 = 사전분포의 사후 최빈값.
  3. 사후 예측분포로 불확실성을 반영한 예측.

6.2.3연습문제

기본

    답
