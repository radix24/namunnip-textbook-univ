사전분포 민감도 분석

본문
이 절에서 배울 것
  • 그럴듯한 사전분포 몇 개로 결론이 얼마나 달라지는지 점검한다.
  • 사후 평균을 사전 평균과 자료 평균의 가중 평균으로 읽는다.
  • 결론이 사전분포에 민감할 때 보고하는 방법을 안다.
먼저 알아야 할 것
  • 켤레 사전분포 (2.1절), 가상 표본 (2.2절).

"사전분포가 주관적이지 않나요?"

베이즈 분석에 가장 흔한 비판입니다. 가장 좋은 대답은 사전분포를 하나만 쓰지 않는 것입니다. 회의적인 사전, 낙관적인 사전, 약한 사전 등 여러 사전분포에서 결론이 같다면 사전분포는 문제가 아니고, 다르다면 자료만으로는 결론이 서지 않는다는 정직한 정보가 됩니다.

2.3.1가중 평균으로 읽기

베타-이항에서 사전 \(\mathrm{Beta}(a, b)\)(가상 표본 \(n_0 = a + b\), 사전 평균 \(m_0 = a/n_0\)), 자료 \(n\)번 중 \(y\)번 성공이면 사후 평균은

\[\frac{a + y}{n_0 + n} = \frac{n_0}{n_0 + n}m_0 + \frac{n}{n_0 + n}\cdot\frac yn.\]

자료의 무게는 \(n/(n_0 + n)\)입니다. 사전분포의 가상 표본이 실제 표본에 비해 작으면 어떤 사전을 써도 결론이 비슷합니다. 정규-정규 모형도 정밀도(분산의 역수)를 무게로 한 같은 꼴입니다.

2.3.2점검 절차

  1. 분석 목적에 맞는 사전분포 3~4개를 미리 정합니다(무정보, 회의적: 효과 없음 근처에 몰림, 낙관적: 기대 효과 근처, 과거 연구 기반).
  2. 각각의 사후 요약(사후 평균, 신용구간, 관심 사건의 사후 확률)을 표로 나란히 보여 줍니다.
  3. 결론이 바뀌는 경계(사전분포의 강도가 얼마일 때 결론이 뒤집히는가)를 찾습니다.
예제 2.3.1

신약 반응이 10명 중 7명입니다. 사전 \(\mathrm{Beta}(1, 1)\), \(\mathrm{Beta}(10, 10)\)(반응률 0.5 근처라는 회의적 사전), \(\mathrm{Beta}(2, 8)\)(기존 약 0.2 수준)에서 사후 평균은?

풀이. \((1 + 7)/12 = 0.67\), \((10 + 7)/30 = 0.57\), \((2 + 7)/20 = 0.45\). 사전에 따라 0.45~0.67로 크게 다릅니다. 10명의 자료가 가상 표본 10~20개짜리 사전과 비슷한 무게라 아직 사전을 이길 만큼 강하지 않습니다. "효과가 있어 보이지만, 회의적 사전에서는 결론이 약해진다"고 보고하고 표본을 늘립니다.

요약
  1. 사후 평균 = 사전 평균과 자료 평균의 가중 평균, 무게는 가상 표본 대 실제 표본.
  2. 여러 사전분포의 결과를 나란히 보고합니다.
  3. 결론이 사전에 민감하면 자료가 부족하다는 신호입니다.

2.3.3연습문제

기본

  1. 예제 2.3.1의 자료가 100명 중 70명이었다면 세 사전의 사후 평균은?
    답

    \(71/102 = 0.70\), \(80/120 = 0.67\), \(72/110 = 0.65\). 자료가 많아 차이가 크게 줄었습니다.

응용

  1. 사전 \(\mathrm{Beta}(a, a)\)(평균 0.5)에서 10명 중 7명일 때 사후 평균이 0.6 아래로 내려가는 \(a\)의 범위는?
    답

    \((a + 7)/(2a + 10) < 0.6\) ⇔ \(a + 7 < 1.2a + 6\) ⇔ \(a > 5\). 가상 표본 10개보다 강한 회의적 사전이면 0.6 아래입니다.
