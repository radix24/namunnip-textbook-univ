사전분포 민감도 분석

본문

베이즈 분석을 발표하면 거의 언제나 사전분포가 주관적이지 않느냐는 질문을 받는다. 사전 하나를 골라 결론을 내면 이 비판을 피하기 어렵다. 그렇다면 어떻게 답해야 정직하고 설득력이 있을까?

먼저 알아야 할 것켤레 사전분포(2.1절)와 가상 표본(2.2절)을 쓴다.

처음 질문의 답은 사전분포를 하나만 쓰지 않는 것이다. 회의적인 사전, 낙관적인 사전, 약한 사전처럼 여러 사전분포에서 결론이 같다면 사전분포는 문제가 되지 않는다. 반대로 결론이 다르다면, 자료만으로는 결론이 서지 않는다는 정직한 정보가 된다(그림 1).

2.3.1가중평균으로 읽기

베타-이항에서 사전이 \(\mathrm{Beta}(a, b)\)(가상 표본 \(n_0 = a + b\), 사전 평균 \(m_0 = a/n_0\))이고 자료가 \(n\)번 중 \(y\)번 성공이면 사후 평균은 다음과 같다.

\[\frac{a + y}{n_0 + n} = \frac{n_0}{n_0 + n}m_0 + \frac{n}{n_0 + n}\cdot\frac yn\]

여기서 자료의 무게는 \(n/(n_0 + n)\)이다. 따라서 사전의 가상 표본이 실제 표본에 비해 작으면 어떤 사전을 써도 결론이 비슷하다. 정규-정규 모형도 정밀도를 무게로 한 같은 꼴이다.

2.3.2점검 절차

먼저 분석 목적에 맞는 사전분포 3개에서 4개를 미리 정한다. 가령 무정보 사전, 효과 없음 근처에 몰린 회의적 사전, 기대 효과 근처의 낙관적 사전, 과거 연구에 기반한 사전이다. 다음으로 각 사전의 사후 요약(사후 평균, 신용구간, 관심 사건의 사후 확률)을 표로 나란히 보여 준다. 끝으로 사전의 강도가 얼마일 때 결론이 뒤집히는지, 그 경계를 찾는다.

예제 2.3.1

신약 반응이 10명 중 7명이다. 사전 \(\mathrm{Beta}(1, 1)\), \(\mathrm{Beta}(10, 10)\)(반응률 0.5 근처라는 회의적 사전), \(\mathrm{Beta}(2, 8)\)(기존 약 0.2 수준)에서 사후 평균을 구하라.

풀이. 사후 평균은 차례로 \((1 + 7)/12 = 0.67\), \((10 + 7)/30 = 0.57\), \((2 + 7)/20 = 0.45\)이다. 즉 사전에 따라 0.45에서 0.67까지 크게 다르다(그림 1). 10명의 자료가 가상 표본 10에서 20짜리 사전과 비슷한 무게라, 아직 사전을 이길 만큼 강하지 않기 때문이다. 그래서 효과가 있어 보이지만 회의적 사전에서는 결론이 약해진다고 보고하고, 표본을 늘린다.

주의

자료를 본 뒤 원하는 결론이 나오는 사전을 골라 보고하면 민감도 분석의 의미가 사라진다. 사전의 목록은 자료를 보기 전에 정하고, 모든 결과를 함께 보고한다.

마무리

사후 평균은 사전 평균과 자료 평균의 가중평균이며, 무게는 가상 표본과 실제 표본의 크기로 정해진다. 여러 사전분포의 결과를 나란히 보고하고, 결론이 사전에 민감하면 자료가 부족하다는 신호로 읽는다.

2.3.3연습문제

기본

  1. 예제 2.3.1의 자료가 100명 중 70명이었다면 세 사전의 사후 평균은 얼마인가?
    답

    \(71/102 = 0.70\), \(80/120 = 0.67\), \(72/110 = 0.65\)이다. 자료가 많아 차이가 크게 줄었다.

응용

  1. 사전 \(\mathrm{Beta}(a, a)\)(평균 0.5)에서 10명 중 7명일 때 사후 평균이 0.6 아래로 내려가는 \(a\)의 범위를 구하라.
    답

    \((a + 7)/(2a + 10) < 0.6\)은 \(a + 7 < 1.2a + 6\), 곧 \(a > 5\)와 같다. 가상 표본 10개보다 강한 회의적 사전이면 0.6 아래이다.

  2. 예제의 세 사전에서 자료의 무게 \(n/(n_0 + n)\)을 각각 구하라.
    답

    \(10/12 = 0.83\), \(10/30 = 0.33\), \(10/20 = 0.5\)이다. 회의적 사전에서는 자료의 무게가 3분의 1뿐이다.
