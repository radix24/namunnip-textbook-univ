제임스-스타인 축소 추정

본문

밀 가격, 야구 선수의 타율, 어느 도시의 강수량을 각각 측정값으로 추정한다. 셋은 서로 아무 관계가 없으니, 각자 자기 측정값을 쓰는 것이 최선일 것 같다. 그런데 셋을 함께 0 쪽으로 조금씩 당기면 전체 오차가 줄어든다고 한다. 어떻게 그럴 수 있을까?

먼저 알아야 할 것베이즈 추정량과 위험(5.1절), 정규-정규 켤레(2.1절)를 쓴다.

처음 질문의 답은 스타인의 역설이다. \(x_i \sim N(\theta_i, 1)\), \(i = 1, \ldots, p\)가 서로 독립일 때 각 \(\theta_i\)를 \(x_i\)로 추정하는 것은 하나씩 보면 최선이다. 그런데 스타인(1956)은 \(p \ge 3\)이면 전체 제곱 오차 \(\sum(\hat\theta_i - \theta_i)^2\)의 기대값을 모든 \(\boldsymbol\theta\)에서 더 작게 만드는 추정량이 있음을 보였다. 서로 무관한 양을 함께 추정해도 마찬가지라 역설처럼 들린다(그림 1).

5.3.1추정량

정의 5.3.1 (제임스-스타인 추정량)

\(\hat{\boldsymbol\theta}^{JS} = \left(1 - \dfrac{p - 2}{\|\mathbf x\|^2}\right)\mathbf x\)이다. 공통 값 쪽으로 줄이려면 \(\bar x + \left(1 - \dfrac{p - 3}{\sum(x_i - \bar x)^2}\right)(x_i - \bar x)\)를 쓴다.

이 추정량은 모든 좌표를 같은 비율로 0(또는 전체 평균) 쪽으로 당긴다. 이때 관측들이 0 근처에 모여 \(\|\mathbf x\|^2\)이 작으면 많이 당기고, 크면 조금 당긴다. 그리고 위험이 \(p - (p-2)^2E[1/\|\mathbf x\|^2]\)이라 표본평균의 위험 \(p\)보다 언제나 작다. 특히 참값들이 모두 0 근처에 있으면 \(\|\mathbf x\|^2\)이 \(p\) 정도라 위험이 약 2까지 줄어, \(p\)가 클수록 이득이 크다.

5.3.2경험적 베이즈 해석

\(\theta_i \sim N(0, \tau^2)\)라는 사전을 두면 베이즈 추정량은 \(\left(1 - \frac{1}{1 + \tau^2}\right)x_i\)이다. 그런데 \(\tau^2\)를 모르므로 자료로 추정한다. \(\|\mathbf x\|^2\)의 기대값이 \(p(1 + \tau^2)\)이고, \(1/(1 + \tau^2)\)의 불편추정량이 \((p - 2)/\|\mathbf x\|^2\)이므로 이것을 넣으면 제임스-스타인 추정량이 된다. 다시 말해 여러 평균이 서로 정보를 빌려 쓰는 것이며, 6.4절 계층 모형의 출발점이다.

예제 5.3.1

\(p = 5\), \(\mathbf x = (2, -1, 0.5, 1.5, -2)\)(각 분산 1)의 제임스-스타인 추정값을 구하라.

풀이. \(\|\mathbf x\|^2 = 4 + 1 + 0.25 + 2.25 + 4 = 11.5\)이므로 축소 계수는 \(1 - 3/11.5 = 0.739\)이다. 따라서 추정값은 (1.48, −0.74, 0.37, 1.11, −1.48)이며, 모든 값이 0 쪽으로 약 26% 당겨졌다(그림 1).

주의

이득은 전체 제곱 오차의 합에 대한 것이다. 그래서 특정 좌표 하나, 특히 극단적으로 큰 \(\theta_i\)는 오히려 나빠질 수 있으므로, 가장 높은 곳 하나를 고르는 것처럼 개별 값이 중요한 결정에서는 이 점을 고려한다.

마무리

\(p \ge 3\)이면 표본평균보다 전체 위험이 작은 축소 추정량 \(\hat{\boldsymbol\theta}^{JS} = (1 - (p-2)/\|\mathbf x\|^2)\mathbf x\)가 있다. 이것은 사전 분산을 자료로 추정한 경험적 베이즈 추정량이다.

5.3.3연습문제

기본

  1. \(p = 10\), \(\|\mathbf x\|^2 = 16\)이면 축소 계수는 얼마인가?
    답

    \(1 - 8/16 = 0.5\)로, 절반으로 줄인다.

응용

  1. \(\|\mathbf x\|^2 < p - 2\)이면 계수가 음수가 된다. 어떻게 고치는가?
    답

    음수면 부호가 뒤집혀 이상하므로 계수를 0으로 자른 양수부 제임스-스타인 \(\max(0, 1 - (p-2)/\|\mathbf x\|^2)\)을 쓴다. 이 추정량은 원래 제임스-스타인보다도 위험이 작다.

  2. 예제에서 추정한 \(1/(1 + \hat\tau^2)\)과 \(\hat\tau^2\)를 구하라.
    답

    \(1/(1 + \hat\tau^2) = 3/11.5 = 0.261\)이므로 \(\hat\tau^2 = 2.83\)이다. 참값들이 관측 잡음(분산 1)보다 넓게 퍼져 있다고 본 것이다.
