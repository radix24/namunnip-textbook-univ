제임스-스타인 축소 추정

본문
이 절에서 배울 것
  • 평균 여러 개를 함께 추정할 때 표본평균이 최선이 아닐 수 있음을 안다.
  • 제임스-스타인 추정량을 계산하고 경험적 베이즈로 해석한다.
  • 축소가 이득이 되는 조건과 한계를 안다.
먼저 알아야 할 것
  • 베이즈 추정량과 위험 (5.1절), 정규-정규 켤레 (2.1절).

스타인의 역설

\(x_i \sim N(\theta_i, 1)\), \(i = 1, \ldots, p\)가 서로 독립일 때, 각 \(\theta_i\)를 \(x_i\)로 추정하는 것은 하나씩 보면 최선입니다. 그런데 스타인(1956)은 \(p \ge 3\)이면 전체 제곱 오차 \(\sum(\hat\theta_i - \theta_i)^2\)의 기대값을 모든 \(\boldsymbol\theta\)에서 더 작게 만드는 추정량이 있음을 보였습니다. 서로 무관한 양(밀 가격, 야구 타율, 강수량)을 함께 추정해도 마찬가지라 역설처럼 들립니다.

5.3.1추정량

정의 5.3.1

\(\hat{\boldsymbol\theta}^{JS} = \left(1 - \dfrac{p - 2}{\|\mathbf x\|^2}\right)\mathbf x\). 공통 값 \(\mu\) 쪽으로 줄이려면 \(\bar x + \left(1 - \dfrac{p - 3}{\sum(x_i - \bar x)^2}\right)(x_i - \bar x)\).

모든 좌표를 같은 비율로 0(또는 전체 평균) 쪽으로 당깁니다. \(\|\mathbf x\|^2\)이 작으면(관측들이 0 근처에 모여 있으면) 많이 당기고, 크면 조금 당깁니다. 위험은 \(p - (p-2)^2E[1/\|\mathbf x\|^2] < p\)로 표본평균의 위험 \(p\)보다 항상 작습니다.

5.3.2경험적 베이즈 해석

\(\theta_i \sim N(0, \tau^2)\)라는 사전을 두면 베이즈 추정량은 \(\left(1 - \frac{1}{1 + \tau^2}\right)x_i\)입니다. \(\tau^2\)를 모르므로 자료로 추정하면(\(\|\mathbf x\|^2\)의 기대값이 \(p(1 + \tau^2)\)), \(1/(1 + \tau^2)\)의 불편추정량이 \((p - 2)/\|\mathbf x\|^2\)이고 이것이 제임스-스타인 추정량입니다. 여러 평균이 서로 정보를 빌려 쓰는 것으로, 6.4절 계층 모형의 출발점입니다.

주의 이득은 전체 제곱 오차의 합에 대한 것이고, 특정 좌표 하나(극단적으로 큰 \(\theta_i\))는 오히려 나빠질 수 있습니다. 개별 값이 중요한 결정(가장 높은 곳 하나를 고르기)에서는 이 점을 고려합니다.
예제 5.3.2

\(p = 5\), \(\mathbf x = (2, -1, 0.5, 1.5, -2)\)(각 분산 1)의 제임스-스타인 추정값은?

풀이. \(\|\mathbf x\|^2 = 4 + 1 + 0.25 + 2.25 + 4 = 11.5\), 축소 계수 \(1 - 3/11.5 = 0.739\). 추정값 (1.48, −0.74, 0.37, 1.11, −1.48). 모든 값이 0 쪽으로 약 26% 당겨졌습니다.

요약
  1. \(p \ge 3\)이면 표본평균보다 전체 위험이 작은 축소 추정량이 있습니다.
  2. \(\hat{\boldsymbol\theta}^{JS} = (1 - (p-2)/\|\mathbf x\|^2)\mathbf x\).
  3. 경험적 베이즈: 사전 분산을 자료로 추정한 베이즈 추정량.

5.3.3연습문제

기본

  1. \(p = 10\), \(\|\mathbf x\|^2 = 16\)이면 축소 계수는?
    답

    \(1 - 8/16 = 0.5\). 절반으로 줄입니다.

응용

  1. \(\|\mathbf x\|^2 < p - 2\)이면 계수가 음수가 됩니다. 어떻게 고치나요?
    답

    음수면 부호가 뒤집혀 이상하므로 계수를 0으로 자릅니다(양수부 제임스-스타인, \(\max(0, 1 - (p-2)/\|\mathbf x\|^2)\)). 이 추정량은 원래 제임스-스타인보다도 위험이 작습니다.
