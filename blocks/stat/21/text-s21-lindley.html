점 귀무가설과 린들리 역설

본문
이 절에서 배울 것
  • 점 귀무가설 \(\theta = \theta_0\)의 베이즈 검정을 사전 확률 질량으로 구성한다.
  • 정규 평균 검정의 베이즈 인자를 표본 크기와 함께 계산한다.
  • 같은 p값에서 표본이 클수록 베이즈 인자가 귀무가설을 지지하는 린들리 역설을 설명한다.
먼저 알아야 할 것
  • 베이즈 인자 (4.1절), p값의 해석 (응통14 3.3절).

정확히 0이라는 가설

연속 사전분포에서 \(\theta\)가 정확히 0일 사후 확률은 0입니다. "효과가 없다"를 검정하려면 \(\theta = 0\)에 사전 확률 덩어리(예: 0.5)를 주고, 나머지를 대립가설 아래의 연속 사전분포로 펼칩니다. 이 구성은 대립가설의 사전분포를 어떻게 펼치느냐에 결과가 크게 좌우된다는 특징이 있습니다.

4.3.1정규 평균의 베이즈 인자

\(\bar y \sim N(\theta, \sigma^2/n)\), \(H_0: \theta = 0\), \(H_1: \theta \sim N(0, \tau^2)\)이면 \(z = \sqrt n\bar y/\sigma\)에 대해

\[B_{01} = \sqrt{1 + \frac{n\tau^2}{\sigma^2}}\exp\left(-\frac{z^2}{2}\cdot\frac{n\tau^2/\sigma^2}{1 + n\tau^2/\sigma^2}\right).\]

\(B_{01} > 1\)이면 자료가 귀무가설을 더 지지합니다.

4.3.2린들리 역설

\(z = 1.96\)(양측 p값 0.05)으로 고정하고 \(n\)을 늘리면 지수 항은 \(e^{-1.92}\)로 수렴하지만 앞의 \(\sqrt{1 + n\tau^2/\sigma^2}\)는 계속 커져, \(B_{01} \to \infty\)입니다. 같은 p값 0.05가 표본이 크면 오히려 귀무가설의 강한 증거가 됩니다. 이유는 대립가설이 넓게 펼쳐 놓은 효과 크기에 비해, 큰 표본에서 \(z = 1.96\)에 해당하는 \(\bar y\)는 아주 작은 효과라 "효과 0"에 더 가깝기 때문입니다.

교훈은 두 가지입니다. p값을 표본 크기와 무관한 증거의 척도로 읽으면 안 되고(큰 표본의 p = 0.05는 약한 증거), 베이즈 인자는 대립가설의 사전분포(\(\tau\))에 민감하므로 \(\tau\)를 실질적으로 의미 있는 효과 크기로 정하고 민감도를 보고해야 합니다.

예제 4.3.1

\(\sigma = 1\), \(\tau = 1\), \(z = 1.96\)일 때 \(n = 100\)과 \(n = 10000\)의 \(B_{01}\)을 구하세요.

풀이. \(n = 100\): \(\sqrt{101}\,e^{-1.92 \times 100/101} = 10.05 \times 0.149 = 1.50\). \(n = 10000\): \(100 \times e^{-1.92} = 14.7\). p값은 둘 다 0.05이지만 베이즈 인자는 귀무가설을 1.5배, 14.7배 지지합니다. 사전 확률이 반반이면 \(P(H_0 \mid \mathbf y)\)는 0.60과 0.94입니다.

요약
  1. 점 귀무가설은 사전 확률 덩어리 + 대립가설의 연속 사전으로 구성.
  2. 같은 p값이라도 \(n\)이 크면 베이즈 인자는 귀무가설 쪽으로(린들리 역설).
  3. 베이즈 인자는 대립가설 사전의 폭에 민감, p값은 표본 크기와 함께 읽기.

4.3.3연습문제

기본

  1. \(B_{01} = 0.2\)이고 사전 확률이 반반이면 \(P(H_0 \mid \mathbf y)\)는?
    답

    사후 오즈 0.2, \(P = 0.2/1.2 = 0.17\).

응용

  1. 예제 4.3.1의 \(n = 100\)에서 \(\tau\)를 10으로 넓히면 \(B_{01}\)은 어떻게 되나요?
    답

    \(n\tau^2 = 10000\)이라 \(n = 10000\), \(\tau = 1\)과 같은 값 14.7. 대립가설을 터무니없이 넓게 잡으면 귀무가설이 유리해집니다. \(\tau\)는 그럴듯한 효과 크기로 정해야 합니다.
