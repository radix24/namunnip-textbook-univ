깁스 표집으로 정규 모형 사후 계산하기

본문

측정값 8개의 평균 \(\mu\)와 표준편차 \(\sigma\)를 모두 모른다. 이제 사후분포는 \(\mu\)와 \(\sigma\)의 이차원 분포이고, 켤레 사전을 써도 \(\mu\)만의 사후를 얻으려면 적분이 필요하다. 그런데 \(\sigma\)를 안다고 치면 \(\mu\)의 사후는 쉽고, \(\mu\)를 안다고 치면 \(\sigma\)의 사후도 쉽다. 이 두 가지 쉬운 계산만으로 어려운 결합 분포를 다룰 수 있을까?

먼저 알아야 할 것켤레 사전분포(2.1절)와 깁스 표집(응통15 5.2절)을 쓴다.

처음 질문의 답은 깁스 표집이다. 한 모수를 고정하고 다른 모수를 조건부분포에서 뽑는 일을 번갈아 되풀이하면, 그 표본이 결합 사후분포를 따르게 된다(그림 1). 그러면 \(\mu\)만의 사후는 표본에서 \(\mu\) 좌표만 모으면 된다.

6.1.1모형과 조건부분포

\(y_i \sim N(\mu, 1/\tau)\)이고 \(\tau\)는 정밀도이다. 사전은 \(\mu \sim N(\mu_0, 1/\kappa_0)\)와 \(\tau \sim \mathrm{Gamma}(a, b)\)를 서로 독립으로 둔다.

정리 6.1.1 (완전 조건부분포)

\(\mu \mid \tau, \mathbf y \sim N\left(\dfrac{\kappa_0\mu_0 + n\tau\bar y}{\kappa_0 + n\tau}, \dfrac{1}{\kappa_0 + n\tau}\right)\)이고, \(\tau \mid \mu, \mathbf y \sim \mathrm{Gamma}\left(a + \dfrac n2, b + \dfrac12\sum(y_i - \mu)^2\right)\)이다.

첫 식은 \(\tau\)를 안다고 둘 때의 정규-정규 켤레(2.1절)이고, 둘째 식은 \(\mu\)를 안다고 둘 때의 감마-정규 켤레이다. 즉 각각은 쉬운 분포라 번갈아 뽑을 수 있다. 이때 \(\mu\)의 조건부 평균은 사전 평균과 표본 평균을 정밀도 \(\kappa_0\)와 \(n\tau\)로 가중평균한 것이고, \(\tau\)의 조건부분포는 현재 \(\mu\) 둘레의 잔차 제곱합이 클수록 작은 정밀도, 곧 큰 \(\sigma\)를 준다.

6.1.2구현

y <- c(98, 105, 112, 101, 94, 108, 110, 99); n <- length(y)
mu0 <- 100; k0 <- 1 / 100; a <- 0.01; b <- 0.01
S <- 10000; mu <- tau <- numeric(S); mu[1] <- mean(y); tau[1] <- 1 / var(y)
set.seed(1)
for (s in 2:S) {
  prec <- k0 + n * tau[s - 1]
  mu[s] <- rnorm(1, (k0 * mu0 + n * tau[s - 1] * mean(y)) / prec, sqrt(1 / prec))
  tau[s] <- rgamma(1, a + n / 2, b + sum((y - mu[s])^2) / 2)
}
keep <- -(1:1000)
quantile(mu[keep], c(.025, .5, .975)); quantile(1 / sqrt(tau[keep]), c(.025, .5, .975))

번인 1000개를 버리고 \(\mu\)와 \(\sigma = 1/\sqrt\tau\)의 사후 분위수를 구한다. 약한 사전이므로 \(\mu\)의 95% 신용구간은 [98.1, 108.1](중앙값 103.2)이고, 이것은 t 신뢰구간 \(103.4 \pm 2.365 \times 6.37/\sqrt8\), 곧 [98.1, 108.7]과 비슷하다. 한편 \(\sigma\)의 사후는 중앙값 6.6, 95% 구간 [4.1, 12.5]로 오른쪽 꼬리가 길다(그림 1). 끝으로 경로 그림과 자기상관으로 수렴을 확인한다(응통15 5.3절).

주의

깁스 표집은 한 축씩만 움직이므로, 두 모수의 사후 상관이 강하면 좁은 대각선 골짜기를 계단으로 천천히 기어가게 되어 수렴이 느려진다. 이때는 모수를 다시 매개화하거나 두 모수를 한꺼번에 뽑는 블록 표집을 쓴다.

마무리

정규 모형에서 \(\mu \mid \tau\)는 정규, \(\tau \mid \mu\)는 감마를 따른다. 이 둘을 번갈아 뽑으면 결합 사후 표본을 얻는다. 표본의 분위수로 요약하고, 수렴을 진단한다.

6.1.3연습문제

기본

  1. 코드로 \(P(\mu > 105 \mid \mathbf y)\)를 어림하는 한 줄을 써라.
    답

    mean(mu[keep] > 105)이며, 결과는 약 0.21이다.

응용

  1. \(\tau = 1/36\)으로 고정했을 때 \(\mu\)의 조건부 사후 평균과 분산을 구하라(\(\mu_0 = 100\), \(\kappa_0 = 0.01\), \(n = 8\), \(\bar y = 103.375\)).
    답

    정밀도 \(0.01 + 8/36 = 0.232\)이므로 분산은 4.31이다. 평균은 \((0.01 \times 100 + 0.222 \times 103.375)/0.232 = 103.2\)이다.

  2. 코드에서 \(\sigma\)의 사후 표본을 얻는 한 줄을 쓰고, 왜 \(\tau\)의 표본을 변환하면 되는지 설명하라.
    답

    sig <- 1 / sqrt(tau[keep])이다. 모수의 함수의 사후 표본은 표본을 그대로 변환해 얻는다(3.3절).
