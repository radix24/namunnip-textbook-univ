  • 깔끔한 자료(tidy data)의 원칙을 안다.
  • 넓은 형식과 긴 형식 사이를 바꾼다.
먼저 알아야 할 것
  • 그룹 요약 (2.3절).

같은 자료, 두 모양

학생별 1~3월 점수를 한 행에 세 열로 적을 수도(넓은 형식), 학생-월 조합마다 한 행으로 적을 수도(긴 형식) 있습니다. 사람이 보기에는 넓은 쪽이, 그래프와 모형에는 긴 쪽이 편합니다.

2.4.1깔끔한 자료

정의 2.4.1

깔끔한 자료: (1) 변수마다 한 열, (2) 관측마다 한 행, (3) 값마다 한 칸.

"1월", "2월"이 열 이름이면 "월"이라는 변수가 열 이름에 숨어 있어 원칙 1을 어깁니다. 긴 형식으로 바꾸면 월과 점수가 각각 한 열이 됩니다.

2.4.2바꾸기

wide <- data.frame(id = 1:3, m1 = c(70, 80, 65), m2 = c(75, 82, 70), m3 = c(78, 85, 72))
# tidyr
long <- tidyr::pivot_longer(wide, cols = m1:m3, names_to = "month", values_to = "score")
back <- tidyr::pivot_wider(long, names_from = month, values_from = score)
# 기본 R
long2 <- reshape(wide, direction = "long", varying = c("m1", "m2", "m3"),
                 v.names = "score", timevar = "month", times = 1:3, idvar = "id")

긴 형식 9행(3명 × 3달). 이렇게 하면 tapply(long$score, long$month, mean)로 월별 평균을, ggplot(long, aes(month, score, group = id)) + geom_line()으로 학생별 추이를 바로 그릴 수 있습니다.

요약
  1. 깔끔한 자료: 변수 = 열, 관측 = 행.
  2. pivot_longer / pivot_wider (또는 reshape).
  3. 모형과 그래프는 긴 형식, 보고 표는 넓은 형식.
