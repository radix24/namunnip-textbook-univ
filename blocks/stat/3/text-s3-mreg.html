다중회귀를 R로: 적합, 진단, 예측

본문
이 절에서 배울 것
  • lm의 공식 문법으로 여러 설명변수, 범주형 변수, 상호작용을 넣는다.
  • summary, confint, plot으로 결과와 진단 그림을 읽는다.
  • predict로 신뢰구간과 예측구간을 구한다.
먼저 알아야 할 것
  • 단순 회귀 (5.2절), 다중회귀의 이론 (응통10 02단원).

한 줄의 공식

5.2절의 단순 회귀를 설명변수 여러 개로 넓힙니다. 이론은 응통10에서 자세히 다루고, 여기서는 R로 실제 분석을 끝까지 하는 순서를 익힙니다.

5.4.1공식 문법

공식뜻
y ~ x1 + x2두 설명변수
y ~ x1 + factor(g)범주형은 가변수로 자동 변환
y ~ x1 * x2주효과 + 상호작용 (x1 + x2 + x1:x2)
y ~ x + I(x^2)제곱항(I()로 감쌈)
log(y) ~ .반응 로그, 나머지 모든 변수

5.4.2적합에서 예측까지

fit <- lm(mpg ~ wt + hp, data = mtcars)
summary(fit)          # 계수, 표준오차, t, p, R^2
confint(fit)          # 계수의 95% 신뢰구간
par(mfrow = c(2, 2)); plot(fit)   # 진단 그림 네 장
new <- data.frame(wt = 3, hp = 150)
predict(fit, new, interval = "confidence")   # 평균 반응의 구간
predict(fit, new, interval = "prediction")   # 새 차 한 대의 구간

진단 그림 네 장은 (1) 잔차 대 적합값(곡선, 깔때기), (2) 정규 Q-Q, (3) 척도-위치(등분산), (4) 잔차 대 지렛값(쿡 거리)입니다(응통10 4단원). 두 구간 가운데 예측구간이 항상 더 넓습니다(응통10 1.5절).

예제 5.4.1

lm(mpg ~ wt + hp, data = mtcars)의 계수가 절편 37.227, wt −3.878, hp −0.0318입니다. 무게 3(천 lb), 마력 150인 차의 연비 예측값은?

풀이. \(37.227 - 3.878 \times 3 - 0.0318 \times 150 = 37.227 - 11.634 - 4.77 = 20.82\) mpg. predict의 fit 값과 같고, 구간은 interval 인자로 함께 얻습니다.

요약
  1. +, *, factor(), I()로 모형을 씁니다.
  2. summary, confint, plot(fit)으로 결과와 진단.
  3. predict(..., interval = )로 신뢰·예측구간.

5.4.3연습문제

기본

  1. lm(mpg ~ wt * am, data = mtcars)에 들어가는 항을 모두 쓰세요.
    답

    절편, wt, am, wt:am(상호작용).

응용

  1. cyl(4, 6, 8)을 lm(mpg ~ cyl)로 넣는 것과 lm(mpg ~ factor(cyl))로 넣는 것의 차이는?
    답

    앞은 실린더 수를 숫자로 보아 2개 늘 때마다 같은 양 변한다고 가정(기울기 1개), 뒤는 6기통·8기통을 4기통과 따로 비교(계수 2개)합니다. 효과가 직선이라는 근거가 없으면 factor가 안전합니다.
