다중회귀를 R로 적합하고 진단하고 예측하기

본문

연비를 무게 하나가 아니라 무게와 마력으로 함께 설명하고 싶다. 모형을 적합하고, 계수를 읽고, 모형이 자료에 맞는지 점검하고, 새 차의 연비를 구간과 함께 예측하는 데까지 R로는 몇 줄이 필요할까?

먼저 알아야 할 것단순 회귀(5.2절)와 다중회귀의 이론(응통10 02단원)을 쓴다.

5.4.1공식 문법

처음 질문의 첫 단계는 모형을 공식으로 쓰는 것이다. 이론은 응통10에서 자세히 다루고, 여기서는 R로 분석을 끝까지 하는 순서를 익힌다.

공식뜻
y ~ x1 + x2두 설명변수
y ~ x1 + factor(g)범주형은 가변수로 자동 변환
y ~ x1 * x2주효과와 상호작용(x1 + x2 + x1:x2)
y ~ x + I(x^2)제곱항(I()로 감쌈)
log(y) ~ .반응의 로그, 나머지 모든 변수

5.4.2적합에서 예측까지

fit <- lm(mpg ~ wt + hp, data = mtcars)
summary(fit)          # 계수, 표준오차, t, p, R^2
confint(fit)          # 계수의 95% 신뢰구간
par(mfrow = c(2, 2)); plot(fit)   # 진단 그림 네 장
new <- data.frame(wt = 3, hp = 150)
predict(fit, new, interval = "confidence")   # 평균 반응의 구간
predict(fit, new, interval = "prediction")   # 새 차 한 대의 구간

그러므로 답은 여섯 줄이다. summary로 계수를 읽고, confint로 계수의 신뢰구간을 얻는다. 진단 그림 네 장은 잔차 대 적합값(곡선이나 깔때기 모양), 정규 Q-Q, 척도-위치(등분산), 잔차 대 지렛값(쿡 거리)이다(응통10 04단원). 그림 1이 그 첫 장인데, U자 추세가 보이므로 무게의 제곱항이나 로그 변환을 고려할 만하다. 한편 두 구간 가운데 새 차 한 대의 예측구간은 개별 차의 흩어짐까지 담으므로 평균 반응의 신뢰구간보다 늘 넓다(응통10 1.5절).

예제 5.4.1

lm(mpg ~ wt + hp, data = mtcars)의 계수가 절편 37.227, wt −3.878, hp −0.0318이다. 무게 3(천 lb), 마력 150인 차의 연비 예측값을 구하여라.

풀이. \(37.227 - 3.878\times3 - 0.0318\times150 = 37.227 - 11.634 - 4.77 = 20.82\) mpg이다. predict의 fit 값과 같으며, 구간은 interval 인자로 함께 얻는다. 여기서 wt의 계수 −3.878은 마력을 고정했을 때 무게가 1천 lb 늘면 연비가 3.9 mpg 준다는 뜻이다.

흔한 실수계수를 읽을 때 다른 변수를 고정한다는 조건을 빠뜨리기 쉽다. 단순 회귀의 기울기 −5.34와 다중회귀의 −3.88이 다른 것은, 다중회귀에서는 마력이 같은 차끼리 비교하기 때문이다.
마무리

다중회귀는 +, *, factor(), I()로 공식을 쓰고 lm으로 적합한 뒤, summary와 confint로 다른 변수를 고정한 계수와 그 신뢰구간을 읽는다. plot(fit)의 진단 그림 네 장으로 모형이 자료에 맞는지 점검하는데, 잔차의 굽은 추세는 관계가 휘었다는 신호이다. 새 관측값은 predict(..., interval = )로 예측하며, 개별 예측구간은 평균의 신뢰구간보다 넓다.

5.4.3연습문제

기본

  1. lm(mpg ~ wt * am, data = mtcars)에 들어가는 항을 모두 써라.
    답

    절편, wt, am, 상호작용 wt:am이다.

응용

  1. cyl(4, 6, 8)을 lm(mpg ~ cyl)로 넣는 것과 lm(mpg ~ factor(cyl))로 넣는 것은 어떻게 다른가?
    답

    앞은 기통 수를 숫자로 보아 2개 늘 때마다 같은 양 변한다고 가정하고(기울기 1개), 뒤는 6기통과 8기통을 4기통과 따로 비교한다(계수 2개). 효과가 직선이라는 근거가 없으면 factor가 안전하다.
