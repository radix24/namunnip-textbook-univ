자료를 어디서 얻나

한국은행 경제통계시스템(ECOS), 통계청 국가통계포털(KOSIS), 미국 세인트루이스 연준(FRED)은 GDP, 물가, 고용, 금리 같은 경제 자료를 무료로 제공합니다. 대부분 CSV로 받거나 API로 직접 불러올 수 있습니다.

5.1.1시계열 정리

d <- read.csv("cpi.csv")                      # 열: date, cpi (월별 소비자물가지수)
d$date <- as.Date(d$date)
d <- d[order(d$date), ]
d$yoy <- 100 * (d$cpi / c(rep(NA, 12), head(d$cpi, -12)) - 1)   # 전년 동월 대비 %
summary(d$yoy)
plot(d$date, d$yoy, type = "l", xlab = "", ylab = "물가상승률 (%, 전년 동월 대비)")
abline(h = 2, lty = 2)                          # 물가 목표 2%

경제 시계열에서 자주 쓰는 변환: 전기 대비 증가율, 전년 동기 대비 증가율(계절성 제거 효과), 로그 차분(\(\Delta\log x \approx\) 증가율), 실질값(명목값 ÷ 물가지수 × 100).

예제 5.1.1

R 내장 AirPassengers(1949~1960 월별 항공 승객 수)로 연평균과 전년 대비 증가율을 구하세요.

yr <- tapply(AirPassengers, floor(time(AirPassengers)), mean)
round(yr); round(100 * diff(yr) / head(yr, -1), 1)
plot(log(AirPassengers))     # 로그 척도에서 추세와 계절 진폭이 일정해짐

연평균 승객이 1949년 약 127천 명에서 1960년 약 476천 명으로 늘었고, 해마다 3~22%(평균 약 13%) 증가했습니다. 원래 척도에서는 계절 진폭이 점점 커지지만 로그 척도에서는 일정해, 곱셈적 구조임을 보여 줍니다(응통17 3.1절).

요약
  1. ECOS, KOSIS, FRED에서 자료를 받음.
  2. 날짜 형 변환, 정렬, 증가율·로그 차분.
  3. 시계열은 선 그래프, 기준선과 단위를 표시.
