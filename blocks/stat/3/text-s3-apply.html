  • 반복문을 벡터 연산으로 바꾼다.

반복문 없이 쓰기

1.2절의 제곱합은 sum((1:10)^2) 한 줄이면 됩니다. R다운 코드는 짧고, 읽기 쉽고, 대개 더 빠릅니다(응통15 6.1절).

1.3.1벡터화

산술 연산, 비교, 수학 함수(log, exp, sqrt)는 원소마다 적용됩니다. 길이가 다르면 짧은 쪽을 되풀이합니다(재사용 규칙). (x - mean(x)) / sd(x)는 표준화, cumsum, diff, pmax도 벡터 함수입니다.

1.3.2apply 계열

함수하는 일예
apply(m, 1 또는 2, f)행렬의 행(1)·열(2)마다apply(m, 2, sd)
sapply(x, f)벡터·리스트 원소마다, 결과를 벡터로sapply(mtcars, mean)
tapply(x, g, f)집단마다tapply(mtcars$mpg, mtcars$cyl, mean)
replicate(B, expr)식을 B번 실행replicate(1000, mean(rnorm(100)))

열 합·평균은 전용 함수 colSums, colMeans, rowMeans가 더 빠릅니다.

예제 1.3.1

mtcars의 모든 변수의 변동계수를 구하고, 기통 수별 평균 무게를 구하세요.

sapply(mtcars, function(v) sd(v) / mean(v))
tapply(mtcars$wt, mtcars$cyl, mean)     # 4: 2.29, 6: 3.12, 8: 4.00
요약
  1. 산술·비교·수학 함수는 원소별로 적용.
  2. 행·열: apply, 원소: sapply, 집단: tapply, 반복 실험: replicate.
