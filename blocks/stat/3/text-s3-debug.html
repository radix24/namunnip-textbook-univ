오류 메시지 읽기와 디버깅

본문

잘 짠 코드도 처음에는 오류가 난다. 빨간 글씨가 뜨면 무작정 이것저것 고쳐 보게 되는데, 그러다 보면 한 시간이 금방 간다. 더 무서운 것은 오류 없이 틀린 답을 내는 코드이다. 오류를 빨리 찾고, 조용한 버그를 미리 막는 순서는 무엇일까?

먼저 알아야 할 것조건, 반복, 함수(1.2절)를 쓴다.

1.4.1오류, 경고, 메시지

처음 질문의 첫 단계는 메시지를 읽는 것이다. R이 내는 알림은 세 종류이다. 오류(Error)는 실행을 멈춘다. 예를 들어 object 'x' not found는 변수 이름에 오타가 있거나 아직 만들지 않았다는 뜻이고, non-numeric argument는 문자에 산술 연산을 했다는 뜻이다. 경고(Warning)는 실행은 되지만 결과가 의심스럽다는 알림이다. 예를 들어 NAs introduced by coercion은 as.numeric("1,234")처럼 숫자로 바꿀 수 없는 문자가 있다는 뜻이며, 무시하면 조용히 틀린 결과가 남는다. 메시지는 참고 정보이다.

오류 메시지의 앞부분 Error in f(x) :는 어느 함수에서 났는지, 뒷부분은 무엇이 문제인지 알려 준다. 검색할 때는 자기 변수 이름을 뺀 일반적인 부분을 쓴다.

1.4.2위치 찾기

다음은 어디서 났는지 찾는 단계이다. 오류 직후 traceback()을 실행하면 함수가 호출된 순서를 보여 주어 어느 단계에서 터졌는지 알 수 있다. 함수 안에 browser()를 넣으면 그 줄에서 멈춰 변수 값을 직접 볼 수 있으며, n은 다음 줄, c는 계속, Q는 멈춤이다. RStudio의 중단점도 같은 일을 한다. 그리고 문제를 작게 줄인다. 큰 자료 대신 값 3~5개로 같은 오류가 나는지 확인하면 원인이 잘 보인다.

1.4.3미리 막기

마지막으로 처음 질문의 둘째 부분, 곧 조용한 버그를 막는 방법이다. 함수 입력을 처음에 점검하면, 엉뚱한 곳에서 이상한 오류가 나는 대신 처음에 분명한 오류가 난다.

se <- function(x) {
  stopifnot(is.numeric(x), length(x) > 1)    # 조건이 거짓이면 즉시 오류
  x <- x[!is.na(x)]
  sd(x) / sqrt(length(x))
}

tryCatch로 오류를 잡아 대체 값을 돌려줄 수도 있지만, 오류를 숨기지 않도록 조심한다.

예제 1.4.1

se <- function(x) sd(x) / sqrt(length(x))에 c(2, 4, NA, 6)을 넣으면 결과가 NA이다. 원인을 찾고 고쳐라.

풀이. sd(c(2, 4, NA, 6))이 결측 때문에 NA이다. 그런데 sd(x, na.rm = TRUE)로만 고치면 표준편차는 2이지만 length(x)가 4라서 \(2/\sqrt4 = 1\)로 틀린다. 결측을 먼저 빼고(x <- x[!is.na(x)]) 계산해야 \(2/\sqrt3 = 1.155\)이다. 오류가 나지 않는 버그가 더 위험하다는 예이다.

흔한 실수경고를 끄려고 suppressWarnings()로 감싸기 쉽다. 경고의 원인을 고치지 않고 끄면, 숫자로 바뀌지 않은 값이 NA로 조용히 남아 결과를 바꾼다.
마무리

오류는 실행을 멈추고, 경고는 결과를 의심하라는 신호이며, 메시지는 참고 정보이다. 오류가 나면 메시지에서 함수와 문제를 읽고, traceback과 browser로 위치를 찾고, 값 몇 개로 줄여 원인을 확인한 뒤 고친다. 오류 없이 틀린 답을 내는 버그는 stopifnot으로 입력을 점검해 미리 막는다.

1.4.4연습문제

기본

  1. mean(df$Age)에서 argument is not numeric or logical: returning NA 경고가 났다. 가능한 원인과 확인 방법은 무엇인가?
    답

    열 이름에 오타가 있어 NULL이거나, 숫자가 문자로 읽혔다. names(df), str(df$Age)로 확인하고, 필요하면 as.numeric으로 바꾼 뒤 생긴 NA를 점검한다.

응용

  1. as.numeric(c("1,234", "567"))의 결과와 경고를 설명하고, 올바르게 바꾸는 코드를 써라.
    답

    결과는 NA 567이고 강제 변환 경고가 난다. 쉼표를 지운 뒤 바꾸면 된다. as.numeric(gsub(",", "", x))는 1234 567이다.
