분석 시간의 대부분은 정리

현업 분석가들은 시간의 절반 이상을 자료 정리에 쓴다고 말합니다. 결측, 잘못된 형, 제각각인 범주 이름("남", "남자", "M")을 정리해야 분석을 시작할 수 있습니다.

2.2.1결측값

colSums(is.na(d))            # 열별 결측 수
mean(is.na(d$income))        # 결측 비율
d_cc <- na.omit(d)           # 결측이 하나라도 있는 행 제거(완전 사례)
d$income[is.na(d$income)] <- median(d$income, na.rm = TRUE)   # 중앙값 대체(주의)

완전 사례 분석은 결측이 무작위일 때만 치우침이 없고 표본을 잃습니다. 평균·중앙값 대체는 분산을 줄여 표준오차를 과소평가합니다. 결측이 많거나 체계적이면 다중 대체(mice 패키지)를 고려하고, 어떤 처리를 했는지 반드시 기록합니다(응통8 6.2절).

2.2.2형 변환과 범주

d$age <- as.integer(d$age)
d$date <- as.Date(d$date, format = "%Y-%m-%d")
d$sex <- factor(d$sex)
levels(d$sex)                                    # "M" "남" "남자" "여" ...
d$sex <- ifelse(d$sex %in% c("M", "남", "남자"), "남", "여")   # 통일
d$grade <- factor(d$grade, levels = c("하", "중", "상"))       # 순서 지정
d$agegrp <- cut(d$age, breaks = c(0, 29, 39, 49, Inf), labels = c("20대 이하", "30대", "40대", "50대 이상"))

factor의 수준 순서는 그래프와 회귀의 기준 범주를 정합니다. 기본은 알파벳(가나다) 순입니다. relevel(f, ref = "남")으로 기준을 바꿉니다.

요약
  1. is.na로 결측을 세고, 처리 방법과 그 영향을 기록.
  2. as.*로 형 변환, 날짜는 as.Date.
  3. 범주 이름 통일, 수준 순서 지정, cut으로 구간화.
