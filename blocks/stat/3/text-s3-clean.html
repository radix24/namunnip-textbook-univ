결측값, 형 변환, 범주형 변수 처리

본문

현업 분석가들은 시간의 절반 이상을 자료 정리에 쓴다고 말한다. 설문의 성별 열에 "남", "남자", "M"이 섞여 있고, 소득 열의 4분의 1이 비어 있다. 빈칸은 지워야 할까, 채워야 할까? 그리고 그 선택은 결과를 어떻게 바꿀까?

먼저 알아야 할 것자료 읽기(2.1절)를 쓴다.

2.2.1결측값

처음 질문의 빈칸부터 보자. 먼저 결측이 어디에 얼마나 있는지 센다.

colSums(is.na(d))            # 열별 결측 수
mean(is.na(d$income))        # 결측 비율
d_cc <- na.omit(d)           # 결측이 하나라도 있는 행 제거(완전 사례)
d$income[is.na(d$income)] <- median(d$income, na.rm = TRUE)   # 중앙값 대체(주의)

처리 방법마다 대가가 있다. 결측이 있는 행을 지우는 완전 사례 분석은 결측이 무작위일 때만 치우침이 없고, 그림 1처럼 표본을 많이 잃는다. 평균이나 중앙값으로 채우면 모든 빈칸이 같은 값이 되어 분산을 줄이고, 그 결과 표준오차를 과소평가한다. 결측이 많거나 체계적이면 다중 대체(mice 패키지)를 고려한다(응통8 6.3절). 그러므로 처음 질문의 답은 어느 쪽이든 그 영향을 알고 고르며, 어떤 처리를 했는지 반드시 기록해야 한다는 것이다.

2.2.2형 변환과 범주

다음은 성별 열처럼 이름이 제각각인 범주이다.

d$age <- as.integer(d$age)
d$date <- as.Date(d$date, format = "%Y-%m-%d")
d$sex <- factor(d$sex)
levels(d$sex)                                    # "M" "남" "남자" "여" ...
d$sex <- ifelse(d$sex %in% c("M", "남", "남자"), "남", "여")   # 통일
d$grade <- factor(d$grade, levels = c("하", "중", "상"))       # 순서 지정
d$agegrp <- cut(d$age, breaks = c(0, 29, 39, 49, Inf),
                labels = c("20대 이하", "30대", "40대", "50대 이상"))

levels로 어떤 이름들이 섞였는지 먼저 보고 하나로 통일한다. 한편 factor의 수준 순서는 그래프의 막대 순서와 회귀의 기준 범주를 정하는데, 기본은 알파벳이나 가나다 순이다. 그래서 "하, 중, 상"처럼 뜻이 있는 순서는 levels로 지정하고, 기준 범주는 relevel(f, ref = "남")으로 바꾼다. 연속 변수를 구간으로 나눌 때는 cut을 쓴다.

예제 2.2.1

airquality의 열별 결측 수를 구하고, Ozone이 결측인 날과 아닌 날의 평균 기온을 비교하여라.

colSums(is.na(airquality))                              # Ozone 37, Solar.R 7
tapply(airquality$Temp, is.na(airquality$Ozone), mean)  # FALSE 77.9, TRUE 77.9 근처

풀이. Ozone은 153행 가운데 37행, Solar.R은 7행이 결측이다. 두 집단의 평균 기온 차이가 크다면 결측이 무작위가 아니라는 신호이므로, 완전 사례 분석을 할 때 주의해야 한다.

흔한 실수factor를 숫자로 바꾸려고 as.numeric(f)를 쓰면 원래 값이 아니라 수준의 번호(1, 2, 3)가 나온다. 숫자가 담긴 factor는 as.numeric(as.character(f))로 바꾼다.
마무리

결측은 is.na로 열마다 세고, 지울지 채울지는 대가를 알고 고른다. 완전 사례 분석은 표본을 잃고 결측이 무작위가 아니면 치우치며, 평균이나 중앙값 대체는 분산과 표준오차를 줄이므로 처리 방법을 꼭 기록한다. 제각각인 범주 이름은 levels로 확인해 하나로 통일하고, 뜻이 있는 수준 순서와 기준 범주를 지정하며, 형 변환은 as.*와 as.Date로 한다.

  1. 값 10개 가운데 3개가 결측인 변수를 나머지 7개의 평균으로 채우면, 표본분산은 결측을 뺀 7개의 표본분산보다 커지는가 작아지는가?

    작아진다. 채운 3개는 평균과의 차이가 0이라 제곱합은 그대로인데 나누는 수가 6에서 9로 커지기 때문이다.
