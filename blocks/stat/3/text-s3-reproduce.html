내 컴퓨터에서만 돌아가는 코드

"제 컴퓨터에서는 되는데요"는 흔한 문제입니다. 파일 경로가 다르거나, 패키지 버전이 다르거나, 실행 순서를 기억해야만 결과가 나오는 코드는 다른 사람(그리고 미래의 나)이 재현할 수 없습니다.

6.2.1점검 목록

  • 폴더 구조: data/raw(원자료, 수정 금지), data/clean, R/(스크립트), output/, report.qmd.
  • 상대 경로: RStudio 프로젝트(.Rproj) 기준. setwd("C:/...")를 코드에 넣지 않습니다.
  • 처음부터 실행: R을 새로 시작한 상태에서 스크립트가 처음부터 끝까지 돌아가는지 확인합니다. 작업 공간 저장(.RData)을 끕니다.
  • 난수: set.seed.
  • 환경: sessionInfo() 출력을 남기거나 renv로 패키지 버전을 고정합니다.
  • README: 무엇을, 어떤 순서로 실행하면 되는지.

6.2.2버전 관리

git init                          # 저장소 만들기
git add R/clean.R report.qmd      # 바뀐 파일 담기
git commit -m "결측 처리 방식 변경"  # 기록
git log --oneline                  # 이력 보기

원자료나 큰 결과 파일은 보통 .gitignore로 빼고 코드만 관리합니다. GitHub에 올리면 다른 사람과 공유하고 바뀐 내용을 비교할 수 있습니다.

요약
  1. 원자료 보존, 상대 경로, 처음부터 실행 가능.
  2. set.seed, sessionInfo/renv, README.
  3. git으로 변경 이력 관리.
