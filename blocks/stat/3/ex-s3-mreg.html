작은 자료로 lm 결과를 손으로 확인하기

예제 · 공식과 출력 대조

먼저 읽는 법

숫자가 깔끔하게 떨어지는 작은 자료를 만들어 lm의 출력과 손계산을 비교하면 공식 문법과 출력의 뜻을 확실히 익힐 수 있습니다.

문제. d <- data.frame(x1 = c(0, 1, 0, 1), x2 = c(0, 0, 1, 1), y = c(1, 3, 2, 6))에 lm(y ~ x1 + x2, d)와 lm(y ~ x1 * x2, d)를 맞추면 계수는? 상호작용 모형의 잔차는?

풀이

  1. 상호작용 모형은 칸 4개에 모수 4개라 완벽히 맞습니다: 절편 1(x1 = x2 = 0), x1 2(3 − 1), x2 1(2 − 1), x1:x2 \(6 - 3 - 2 + 1 = 2\). 잔차는 모두 0.
    포화 모형.
  2. 가법 모형: 균형 설계라 x1 계수 = x1 = 1 평균 − x1 = 0 평균 = \(4.5 - 1.5 = 3\), x2 계수 = \(4 - 2 = 2\).
    직교 설계에서는 주효과가 평균의 차.
  3. 절편 = 전체 평균 − 3 × 0.5 − 2 × 0.5 = \(3 - 2.5 = 0.5\). 적합값 0.5, 3.5, 2.5, 5.5, 잔차 0.5, −0.5, −0.5, 0.5.
    잔차의 합 0, 상호작용이 남긴 패턴.

검산

가법 모형의 잔차 패턴 (+, −, −, +)는 상호작용 항의 부호 패턴과 같고, 크기 0.5는 상호작용 계수 2의 1/4입니다. 상호작용을 빼면 그 몫이 잔차로 남는 것입니다.

의미

R 출력의 계수가 무엇과 무엇의 차이인지 작은 예로 확인해 두면, 큰 자료에서 x1:x2 같은 항을 잘못 해석하는 일을 막을 수 있습니다. 상호작용이 있으면 x1의 계수는 "x2 = 0일 때의 x1 효과"라는 점(응통10 3.2절)도 이 예에서 보입니다(x2 = 0일 때 2, x2 = 1일 때 4).
