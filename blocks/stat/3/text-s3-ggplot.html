문법 기반 그래픽(ggplot2)

본문
이 절에서 배울 것
  • 자료, 대응(aes), 기하 객체(geom)로 그래프를 쌓는다.
  • 색, 패널, 평활선으로 다변수 그래프를 그린다.
먼저 알아야 할 것
  • 기본 그래프 (3.1절), 긴 형식 (2.4절).

그래프를 문장처럼 조립하기

ggplot2는 "이 자료의 이 변수를 x에, 저 변수를 색에 대응시켜 점으로 그린다"처럼 그래프를 요소로 쌓아 만듭니다. 처음에는 길어 보이지만, 그래프를 바꾸고 확장하기가 훨씬 쉽습니다.

3.2.1구조

library(ggplot2)
ggplot(data = mtcars, aes(x = wt, y = mpg)) +   # 자료와 대응
  geom_point() +                                # 기하 객체: 점
  labs(x = "무게 (천 lb)", y = "연비 (mpg)")
요소예
aes(대응)x, y, colour, fill, size, shape, group
geomgeom_point, geom_line, geom_histogram, geom_boxplot, geom_smooth, geom_col
facetfacet_wrap(~ g), facet_grid(r ~ c)
scale, themescale_y_log10(), theme_minimal()

aes 안에 쓰면 변수에 대응하고(colour = factor(cyl)), 밖에 쓰면 고정값입니다(colour = "red").

예제 3.2.1

mtcars에서 무게-연비 산점도를 기통별 색으로, 변속기별 패널로, 직선 평활선과 함께 그리세요.

ggplot(mtcars, aes(wt, mpg, colour = factor(cyl))) +
  geom_point(size = 2) +
  geom_smooth(aes(group = 1), method = "lm", se = TRUE, colour = "black") +
  facet_wrap(~ am, labeller = label_both) +
  labs(x = "무게 (천 lb)", y = "연비 (mpg)", colour = "기통") +
  theme_minimal()
ggsave("fig/mpg_wt.png", width = 7, height = 4, dpi = 200)
요약
  1. ggplot(자료, aes(...)) + geom_*()로 쌓기.
  2. aes 안 = 변수 대응, 밖 = 고정값.
  3. facet으로 패널, geom_smooth로 추세, ggsave로 저장.
