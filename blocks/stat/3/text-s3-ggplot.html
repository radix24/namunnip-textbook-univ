문법 기반 그래픽 ggplot2

본문

3.1절의 산점도에 기통 수에 따라 색을 입히고, 변속기 종류마다 패널을 나누고, 추세선까지 더하려면 기본 그래픽으로는 코드가 금방 복잡해진다. 그래프를 문장처럼 조립할 수는 없을까?

먼저 알아야 할 것기본 그래프(3.1절)와 긴 형식(2.4절)을 쓴다.

3.2.1구조

처음 질문의 답이 ggplot2이다. ggplot2는 이 자료의 이 변수를 x에, 저 변수를 색에 대응시켜 점으로 그린다는 식으로 그래프를 요소로 쌓아 만든다.

library(ggplot2)
ggplot(data = mtcars, aes(x = wt, y = mpg)) +   # 자료와 대응
  geom_point() +                                # 기하 객체: 점
  labs(x = "무게 (천 lb)", y = "연비 (mpg)")
요소예
aes(대응)x, y, colour, fill, size, shape, group
geomgeom_point, geom_line, geom_histogram, geom_boxplot, geom_smooth, geom_col
facetfacet_wrap(~ g), facet_grid(r ~ c)
scale, themescale_y_log10(), theme_minimal()

처음에는 길어 보이지만, 그림 1처럼 요소 하나를 바꿔도 나머지는 그대로라 그래프를 바꾸고 넓히기가 훨씬 쉽다. 한 가지 규칙을 기억하자. aes 안에 쓰면 변수에 대응하고(colour = factor(cyl)), 밖에 쓰면 고정값이다(colour = "red").

예제 3.2.1

mtcars에서 무게-연비 산점도를 기통별 색으로, 변속기별 패널로, 직선 평활선과 함께 그려라.

ggplot(mtcars, aes(wt, mpg, colour = factor(cyl))) +
  geom_point(size = 2) +
  geom_smooth(aes(group = 1), method = "lm", se = TRUE, colour = "black") +
  facet_wrap(~ am, labeller = label_both) +
  labs(x = "무게 (천 lb)", y = "연비 (mpg)", colour = "기통") +
  theme_minimal()
ggsave("fig/mpg_wt.png", width = 7, height = 4, dpi = 200)

풀이. 색은 aes 안에서 기통에 대응시키고, 평활선은 group = 1로 기통과 상관없이 하나로 그리며, 선 색은 aes 밖에서 검정으로 고정했다. 패널은 facet_wrap이 나누고, ggsave는 마지막 그래프를 파일로 저장한다. 처음 질문의 세 요구가 각각 한 줄씩 더해진 것이다.

흔한 실수모든 점을 빨갛게 하려고 aes(colour = "red")라고 쓰면, "red"라는 이름의 범주 하나가 생겨 기본 색(분홍)으로 칠해지고 범례까지 나타난다. 고정 색은 aes 밖에 쓴다.
마무리

ggplot2는 ggplot(자료, aes(...))로 자료와 대응을 정하고, geom_*(), facet_*(), scale과 theme을 +로 더해 그래프를 쌓는다. aes 안은 변수 대응, 밖은 고정값이다. 그래서 색, 패널, 추세선 같은 요구가 각각 한 줄씩 더해지고, 하나를 바꿔도 나머지는 그대로이며, ggsave로 저장한다.
