한 줄로 그리는 그래프

R의 기본 그래픽 함수는 자료를 넣으면 바로 그림이 나옵니다. 탐색 단계에서는 빠르게 많이 그려 보는 것이 중요합니다.

3.1.1세 가지 그래프

hist(mtcars$mpg, breaks = 10, main = "연비 분포", xlab = "mpg", col = "grey")
boxplot(mpg ~ cyl, data = mtcars, xlab = "기통", ylab = "mpg")
plot(mpg ~ wt, data = mtcars, pch = 19, col = mtcars$cyl / 2,
     xlab = "무게 (천 lb)", ylab = "연비 (mpg)")
abline(lm(mpg ~ wt, data = mtcars), col = "red")      # 회귀선 추가
legend("topright", legend = c(4, 6, 8), col = c(2, 3, 4), pch = 19, title = "기통")

공통 인수: main(제목), xlab/ylab(축 이름), col(색), pch(점 모양), xlim/ylim(축 범위). par(mfrow = c(1, 2))로 여러 그림을 한 화면에 놓습니다.

3.1.2저장

png("fig/mpg.png", width = 1600, height = 1200, res = 200)
hist(mtcars$mpg)
dev.off()
# 한글 글꼴이 깨지면: par(family = "AppleGothic")(맥), windowsFonts() 확인(윈도우)
예제 3.1.1

airquality에서 월별 오존 상자그림과 기온-오존 산점도를 나란히 그리세요.

par(mfrow = c(1, 2))
boxplot(Ozone ~ Month, data = airquality, xlab = "월", ylab = "오존 (ppb)")
plot(Ozone ~ Temp, data = airquality, xlab = "기온 (°F)")

7~8월에 오존이 높고 퍼짐도 크며, 기온이 높을수록 오존이 휘어 오르는(지수적) 모양입니다. 결측 행은 자동으로 빠집니다.

요약
  1. hist, boxplot(y ~ g), plot(y ~ x).
  2. 제목, 축 이름, 단위를 항상 붙임.
  3. png() … dev.off()로 저장.

3.1.3연습문제

기본

  1. hist의 breaks를 5, 20으로 바꿔 그려 보고 차이를 설명하세요.
    답

    5는 너무 뭉뚱그려 모양이 안 보이고, 20은 막대가 들쭉날쭉해 잡음이 커 보입니다. 구간 수를 바꿔 보며 안정된 모양을 확인합니다.
