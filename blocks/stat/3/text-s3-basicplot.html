히스토그램, 상자그림, 산점도 그리기

본문

새 자료를 받았다. 평균과 표준편차부터 계산할까, 그림부터 그릴까? 숫자 요약은 같아도 모양이 전혀 다른 자료가 있으므로, 탐색 단계에서는 빠르게 많이 그려 보는 것이 중요하다. R에서는 몇 줄이면 될까?

먼저 알아야 할 것그래프 읽기(응통5 2.3절)와 데이터프레임(1.1절)을 쓴다.

3.1.1세 가지 그래프

처음 질문의 답은 그림부터이다. 왜냐하면 숫자 요약이 같아도 모양이 다를 수 있기 때문이다. 그리고 R의 기본 그래픽 함수는 자료를 넣으면 바로 그림이 나온다. 예를 들어 변수 하나의 분포는 히스토그램으로, 집단 사이의 비교는 상자그림으로, 두 변수의 관계는 산점도로 본다. 그림 1은 다음 코드로 그린 것이다.

hist(mtcars$mpg, breaks = 10, main = "연비 분포", xlab = "mpg", col = "grey")
boxplot(mpg ~ cyl, data = mtcars, xlab = "기통", ylab = "mpg")
plot(mpg ~ wt, data = mtcars, pch = 19, col = mtcars$cyl / 2,
     xlab = "무게 (천 lb)", ylab = "연비 (mpg)")
abline(lm(mpg ~ wt, data = mtcars), col = "red")      # 회귀선 추가
legend("topright", legend = c(4, 6, 8), col = c(2, 3, 4), pch = 19, title = "기통")

y ~ g, y ~ x처럼 공식으로 쓰면 세로축과 가로축이 분명해진다. 한편 공통 인수로 main은 제목, xlab과 ylab은 축 이름, col은 색, pch는 점 모양, xlim과 ylim은 축 범위이다. 여러 그림을 한 화면에 놓으려면 par(mfrow = c(1, 2))를 쓴다.

3.1.2저장

보고서에 넣을 그림은 파일로 저장한다.

png("fig/mpg.png", width = 1600, height = 1200, res = 200)
hist(mtcars$mpg)
dev.off()
# 한글 글꼴이 깨지면 par(family = "AppleGothic")(맥), windowsFonts() 확인(윈도우)

즉 png()로 파일을 열고, 그리고, dev.off()로 닫는다. 닫지 않으면 파일이 비어 있으므로 주의한다.

예제 3.1.1

airquality에서 월별 오존 상자그림과 기온-오존 산점도를 나란히 그려라.

par(mfrow = c(1, 2))
boxplot(Ozone ~ Month, data = airquality, xlab = "월", ylab = "오존 (ppb)")
plot(Ozone ~ Temp, data = airquality, xlab = "기온 (°F)")

풀이. 7~8월에 오존이 높고 퍼짐도 크다. 그리고 기온이 높을수록 오존이 휘어 오르는 지수적 모양이다. 물론 결측 행은 자동으로 빠진다.

흔한 실수축 이름과 단위를 빼먹기 쉽다. 그래프는 코드 없이 혼자 읽혀야 하므로, 제목과 축 이름에 변수 이름 대신 뜻과 단위를 적는다.
마무리

새 자료는 숫자 요약 전에 그림부터 그려 본다. 분포는 hist, 집단 비교는 boxplot(y ~ g), 두 변수의 관계는 plot(y ~ x)에 abline으로 추세선을 더하며, 제목과 축 이름, 단위를 늘 붙인다. 보고서용 그림은 png()로 열고 dev.off()로 닫아 저장한다.
