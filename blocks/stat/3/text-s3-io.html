외부 자료 읽고 저장하기

본문

공공데이터포털에서 받은 CSV 파일을 R로 읽었더니 한글이 깨지고, 소득 열의 평균이 계산되지 않는다. 자료를 읽는 첫 단계의 사소한 실수가 뒤의 모든 결과를 망칠 수 있다. 어떻게 읽고, 무엇을 확인해야 할까?

먼저 알아야 할 것데이터프레임(1.1절)을 쓴다.

2.1.1읽기

처음 질문의 두 문제는 읽기 인수로 해결한다. 예를 들어 CSV는 read.csv로 읽고, 인코딩과 결측 표시를 지정한다.

getwd()                                   # 현재 작업 폴더
d <- read.csv("data/survey.csv")          # 프로젝트 폴더 기준 상대 경로
d <- read.csv("survey.csv", fileEncoding = "CP949")   # 한글 윈도우 엑셀 CSV
d <- read.csv("survey.csv", na.strings = c("", "NA", "-", "999"))
# readr 패키지: readr::read_csv("survey.csv", locale = readr::locale(encoding = "EUC-KR"))
# 엑셀: readxl::read_excel("survey.xlsx", sheet = 1)

C:/Users/... 같은 절대 경로보다 프로젝트 폴더 기준 상대 경로를 쓰면 다른 컴퓨터에서도 코드가 돌아간다(RStudio 프로젝트). 그리고 읽은 뒤에는 반드시 str(d), head(d), summary(d)로 확인한다. 그림 1의 확인 단계가 이것이다.

2.1.2흔한 문제

확인 단계에서 자주 보이는 문제는 네 가지이다. 먼저 한글이 깨지면 파일 인코딩(UTF-8 또는 CP949, EUC-KR)을 맞춘다. 숫자가 문자로 읽히면 대개 천 단위 쉼표("1,234")나 "-" 같은 결측 표시 때문이므로, as.numeric(gsub(",", "", x))로 바꾼다. 또 결측이 999나 빈칸으로 적혀 있으면 na.strings로 지정한다. 첫 줄이 제목이 아니면 header와 skip 인수를 쓴다. 따라서 처음 질문의 깨진 한글은 인코딩 문제이고, 평균이 안 되는 소득 열은 문자로 읽힌 숫자 문제이다.

2.1.3저장

정리한 자료는 두 형식으로 저장해 두면 편하다.

write.csv(d, "out/clean.csv", row.names = FALSE, fileEncoding = "UTF-8")
saveRDS(d, "out/clean.rds"); d2 <- readRDS("out/clean.rds")   # R 객체 그대로(형식 보존)

여기서 CSV는 다른 프로그램과 주고받기 좋고, RDS는 factor 수준이나 날짜형 같은 R의 형식까지 그대로 보존한다.

예제 2.1.1

읽은 자료의 str(d)에서 소득 열이 chr로 나왔고, head(d$income)는 "3,200" "없음" "4,100"이었다. 숫자로 바르게 바꾸어라.

x <- d$income
x[x == "없음"] <- NA
d$income <- as.numeric(gsub(",", "", x))
summary(d$income)

풀이. 즉 결측 표시를 먼저 NA로 바꾸고 쉼표를 지운 뒤 숫자로 바꾼다. 이 순서를 지키면 강제 변환 경고 없이 바뀌며, 처음부터 na.strings = "없음"으로 읽어도 된다.

흔한 실수write.csv에서 row.names = FALSE를 빼면 행 번호가 이름 없는 첫 열로 저장된다. 다시 읽을 때마다 X라는 쓸모없는 열이 하나씩 늘어난다.
마무리

외부 자료는 read.csv로 읽되, 한글이 깨지면 인코딩을, 숫자가 문자로 읽히면 쉼표와 결측 표시를 맞춘다. 경로는 프로젝트 폴더 기준 상대 경로로 쓰고, 읽은 직후 str과 summary로 확인해 문제가 보이면 읽기 인수를 고쳐 다시 읽는다. 정리한 자료는 다른 프로그램용 CSV와 형식을 보존하는 RDS로 저장한다.

2.1.4연습문제

기본

  1. str(d)에서 소득 열이 chr로 나왔다. 원인 두 가지와 해결 방법은 무엇인가?
    답

    쉼표가 든 숫자와 "없음" 같은 문자 결측이다. gsub으로 쉼표를 지우고 결측 표시를 na.strings로 지정한 뒤 as.numeric으로 바꾼다.

응용

  1. factor로 정리한 자료를 CSV로 저장했다가 다시 읽으면 무엇이 달라지는가?
    답

    수준의 순서가 사라지고 문자로 읽힌다. 형식을 보존하려면 RDS로 저장하거나, 다시 읽은 뒤 factor(..., levels = ...)로 순서를 다시 정한다.
