외부 자료 읽고 저장하기

본문
이 절에서 배울 것
  • CSV, 엑셀 자료를 읽고 저장한다.
  • 작업 폴더, 인코딩, 결측 표시 문제를 해결한다.
먼저 알아야 할 것
  • 데이터프레임 (1.1절).

자료는 밖에서 온다

공공데이터포털, 통계청, 회사 데이터베이스에서 받은 자료를 R로 읽는 것이 분석의 첫 단계입니다. 이 단계의 사소한 실수(한글 깨짐, 숫자가 문자로 읽힘)가 뒤의 모든 결과를 망칠 수 있습니다.

2.1.1읽기

getwd()                                   # 현재 작업 폴더
d <- read.csv("data/survey.csv")          # 프로젝트 폴더 기준 상대 경로
d <- read.csv("survey.csv", fileEncoding = "CP949")   # 한글 윈도우 엑셀 CSV
d <- read.csv("survey.csv", na.strings = c("", "NA", "-", "999"))
# readr 패키지: readr::read_csv("survey.csv", locale = readr::locale(encoding = "EUC-KR"))
# 엑셀: readxl::read_excel("survey.xlsx", sheet = 1)

절대 경로(C:/Users/...)보다 프로젝트 폴더 기준 상대 경로를 쓰면 다른 컴퓨터에서도 코드가 돌아갑니다(RStudio 프로젝트). 읽은 뒤에는 반드시 str(d), head(d), summary(d)로 확인합니다.

2.1.2흔한 문제

  • 한글이 깨짐: 파일 인코딩(UTF-8 또는 CP949/EUC-KR)을 맞춥니다.
  • 숫자가 문자로 읽힘: 천 단위 쉼표("1,234"), "-" 같은 결측 표시. as.numeric(gsub(",", "", x)).
  • 결측이 999나 빈칸: na.strings로 지정.
  • 첫 줄이 제목이 아님: header, skip 인수.

2.1.3저장

write.csv(d, "out/clean.csv", row.names = FALSE, fileEncoding = "UTF-8")
saveRDS(d, "out/clean.rds"); d2 <- readRDS("out/clean.rds")   # R 객체 그대로(형식 보존)
요약
  1. read.csv(인코딩, 결측 표시), 상대 경로.
  2. 읽은 뒤 str, summary로 확인.
  3. 정리한 자료는 CSV와 RDS로 저장.
