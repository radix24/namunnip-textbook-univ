문자열과 날짜 다루기

본문

주문 자료에 "서울 강남구" 같은 주소와 "2026-03-15" 같은 주문일이 문자로 들어 있다. 시도별 주문 수나 요일별 매출을 내려면 문자에서 필요한 부분을 뽑고, 날짜끼리 빼고 더할 수 있어야 한다. 문자로 적힌 날짜를 어떻게 계산할 수 있게 만들까?

먼저 알아야 할 것결측과 형 변환(2.2절)을 쓴다.

2.5.1문자열

처음 질문의 주소부터 보자. 문자열을 합치고, 자르고, 찾고, 바꾸는 기본 함수는 다음과 같다.

paste("서울", "강남구", sep = " ")      # "서울 강남구"
nchar("통계학")                          # 3
substr("2026-03-15", 1, 4)               # "2026"
toupper("abc"); trimws("  공백  ")       # "ABC", "공백"
strsplit("a,b,c", ",")[[1]]              # "a" "b" "c"
grepl("구$", c("강남구", "수원시"))       # TRUE FALSE (구로 끝나는가)
gsub("[0-9]", "", "A12B3")               # "AB" (숫자 모두 지움)

grepl과 gsub에 쓴 "구$", "[0-9]"는 정규표현식이다. 기본 기호로 ^는 시작, $는 끝, .는 아무 한 글자, [0-9]는 숫자 하나, +는 한 번 이상, *는 0번 이상을 뜻한다. 한편 stringr 패키지의 str_detect, str_replace_all이 같은 일을 일관된 이름으로 한다.

예제 2.5.1

주소 벡터 c("서울 강남구", "경기 수원시", "서울 마포구")에서 시도만 뽑아 서울의 개수를 세어라.

addr <- c("서울 강남구", "경기 수원시", "서울 마포구")
sido <- sapply(strsplit(addr, " "), `[`, 1)   # "서울" "경기" "서울"
sum(sido == "서울")                             # 2
# 또는 sum(grepl("^서울", addr))

풀이. 빈칸으로 나눈 조각 가운데 첫째가 시도이다. 정규표현식 "^서울"로 서울로 시작하는 주소를 바로 세어도 같다.

2.5.2날짜

이제 처음 질문의 둘째 부분이다. 문자로 적힌 날짜는 as.Date로 날짜형으로 바꾼다.

d <- as.Date(c("2026-03-01", "2026-03-15"))
diff(d)                                  # Time difference of 14 days
weekdays(d[1])                           # "일요일" (로케일에 따라 Sunday)
format(d, "%Y-%m")                       # "2026-03" "2026-03"
d[1] + 100                               # "2026-06-09"
as.Date("15/03/2026", format = "%d/%m/%Y")

날짜형은 그림 1처럼 속으로는 1970-01-01부터 센 날 수이다. 그래서 더하고 빼기가 그대로 된다. 형식이 다른 문자열은 format 인자로 순서를 알려 주며, %d는 일, %m은 월, %Y는 네 자리 연도이다. 요일은 weekdays, 연월은 format(d, "%Y-%m")으로 뽑아 요일별, 월별로 묶는다. 시각까지 있으면 as.POSIXct를 쓰고, 편하게는 lubridate::ymd(), ymd_hms()를 쓴다.

흔한 실수날짜를 문자인 채로 정렬하면 "2026-10-01"이 "2026-9-30"보다 앞에 온다. 문자는 한 글자씩 비교하기 때문이다. 날짜형으로 바꾼 뒤 정렬하거나, 월과 일을 늘 두 자리로 적는다.
마무리

문자열은 paste로 합치고, substr과 strsplit으로 자르며, grepl과 gsub에 정규표현식 ^ $ . [0-9] + *를 써서 찾고 바꾼다. 문자로 적힌 날짜는 as.Date로 바꾸면 속값이 1970-01-01부터의 날 수가 되어 빼고 더하는 계산이 되고, weekdays와 format으로 요일과 연월을 뽑아 요일별, 월별로 묶을 수 있다.

2.5.3연습문제

기본

  1. 주문일 "2026-01-10"부터 배송일 "2026-01-17"까지 며칠인가? R 코드를 써라.
    답

    as.Date("2026-01-17") - as.Date("2026-01-10")은 7일이다.

응용

  1. 전화번호 "010-1234-5678"에서 가운데 네 자리를 ****로 가리는 코드를 써라.
    답

    sub("-[0-9]{4}-", "-****-", x)는 "010-****-5678"이다. {4}는 정확히 네 번을 뜻한다.
