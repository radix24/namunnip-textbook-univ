문자열과 날짜 다루기

본문
이 절에서 배울 것
  • 문자열을 합치고, 자르고, 찾고, 바꾼다.
  • 정규표현식의 기본 기호로 패턴을 찾는다.
  • 날짜를 날짜형으로 바꾸고 간격, 요일, 월을 계산한다.
먼저 알아야 할 것
  • 결측과 형 변환 (2.2절).

숫자가 아닌 자료

설문의 자유 응답, 주소, 상품명, 주문 일시처럼 실제 자료의 상당 부분은 문자열과 날짜입니다. 이것을 정리해야 "지역별", "요일별" 같은 분석이 가능합니다.

2.5.1문자열

paste("서울", "강남구", sep = " ")      # "서울 강남구"
nchar("통계학")                          # 3
substr("2026-03-15", 1, 4)               # "2026"
toupper("abc"); trimws("  공백  ")       # "ABC", "공백"
strsplit("a,b,c", ",")[[1]]              # "a" "b" "c"
grepl("구$", c("강남구", "수원시"))       # TRUE FALSE (구로 끝나는가)
gsub("[0-9]", "", "A12B3")               # "AB" (숫자 모두 지움)

정규표현식 기본 기호: ^(시작), $(끝), .(아무 한 글자), [0-9](숫자 하나), +(한 번 이상), *(0번 이상). stringr 패키지의 str_detect, str_replace_all이 같은 일을 일관된 이름으로 합니다.

2.5.2날짜

d <- as.Date(c("2026-03-01", "2026-03-15"))
diff(d)                                  # Time difference of 14 days
weekdays(d[1])                           # "일요일" (로케일에 따라 Sunday)
format(d, "%Y-%m")                       # "2026-03" "2026-03"
d[1] + 100                               # "2026-06-09"
as.Date("15/03/2026", format = "%d/%m/%Y")

날짜형은 내부적으로 1970-01-01부터의 일수라 더하고 빼기가 됩니다. 형식이 다른 문자열은 format 인자로 순서를 알려 줍니다(%d 일, %m 월, %Y 네 자리 연도). 시각까지 있으면 as.POSIXct, 편하게는 lubridate::ymd(), ymd_hms()를 씁니다.

예제 2.5.1

주소 벡터 c("서울 강남구", "경기 수원시", "서울 마포구")에서 시도만 뽑아 서울의 개수를 세세요.

addr <- c("서울 강남구", "경기 수원시", "서울 마포구")
sido <- sapply(strsplit(addr, " "), `[`, 1)   # "서울" "경기" "서울"
sum(sido == "서울")                             # 2
# 또는 sum(grepl("^서울", addr))
요약
  1. paste, substr, strsplit, grepl, gsub.
  2. 정규표현식 ^ $ . [0-9] + *.
  3. as.Date로 바꾸면 날짜 산술, format으로 월·연 추출.

2.5.3연습문제

기본

  1. 주문일 "2026-01-10"부터 배송일 "2026-01-17"까지 며칠인가요? R 코드는?
    답

    as.Date("2026-01-17") - as.Date("2026-01-10") → 7일.

응용

  1. 전화번호 "010-1234-5678"에서 가운데 네 자리를 ****로 가리는 코드를 쓰세요.
    답

    sub("-[0-9]{4}-", "-****-", x) → "010-****-5678". {4}는 정확히 네 번.
