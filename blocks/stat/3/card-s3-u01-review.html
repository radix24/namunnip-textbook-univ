R 기초 문법 단원 마무리 연습

문제 7 · 실습·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 실습다음 코드를 실행하기 전에 출력을 예측하고, R에서 실행해 확인하여라. [01-01]

    x <- c(3, 8, 1, 6)
x[x > 2]
x[-1]
c(1, "a", TRUE)
    힌트 1

    x > 2는 TRUE/FALSE로 된 벡터를 만들고, 대괄호에 넣으면 TRUE인 자리만 고른다.

    힌트 2

    음수 첨자는 "그 자리를 뺀다"는 뜻이다. 벡터에는 한 가지 형식만 들어갈 수 있다.

    풀이

    출력은 차례로 3 8 6, 8 1 6, "1" "a" "TRUE"이다.

    세 번째에서 숫자와 논리값이 모두 문자로 바뀐 까닭은 벡터(원자 벡터)가 한 가지 형식만 담을 수 있어서, 논리 → 숫자 → 문자 순서로 가장 일반적인 형식에 맞춰 강제 변환되기 때문이다. 여러 형식을 함께 담으려면 list(1, "a", TRUE)를 쓴다.

  2. 실습데이터프레임 d <- data.frame(name = c("A", "B", "C"), score = c(70, 85, 90))에서 (1) 점수가 80 이상인 사람의 이름, (2) 평균 점수, (3) 점수를 10% 올린 새 열 adj를 만드는 코드를 써라. [01-01]

    힌트 1

    행은 조건으로, 열은 이름으로 고른다: d[행 조건, "열 이름"].

    힌트 2

    새 열은 d$새이름 <- 계산식으로 만든다. 계산은 벡터 전체에 한꺼번에 적용된다.

    풀이 
    d[d$score >= 80, "name"]   # "B" "C"
mean(d$score)               # 81.66667
d$adj <- d$score * 1.1

    세 번째 줄은 반복문 없이 세 값에 한꺼번에 1.1을 곱합니다(벡터화 연산).

  3. 실습변동계수(표준편차/평균)를 구하는 함수 cv를 작성하여라. 결측값이 있으면 빼고 계산하고, 평균이 0이면 경고와 함께 NA를 돌려주게 하여라. cv(c(2, 4, 4, 5, 7, 8, NA))의 값도 구하여라. [01-02]

    힌트 1

    결측값을 빼려면 sd(x, na.rm = TRUE)처럼 na.rm 인수를 쓴다.

    힌트 2

    조건에 따라 일찍 끝내려면 if (...) { warning("..."); return(NA) }를 쓴다.

    풀이 
    cv <- function(x) {
  m <- mean(x, na.rm = TRUE)
  if (m == 0) {
    warning("평균이 0이라 변동계수를 정의할 수 없습니다")
    return(NA)
  }
  sd(x, na.rm = TRUE) / m
}
cv(c(2, 4, 4, 5, 7, 8, NA))   # 0.4381780

    표준편차 2.191을 평균 5로 나누어 약 0.438이다. 함수 안에서 결측과 예외 상황을 먼저 처리해 두면 나중에 엉뚱한 값이 조용히 나오는 일을 막을 수 있다.

  4. 실습1부터 100까지의 정수 가운데 3 또는 5의 배수의 개수를 (1) for와 if로, (2) 반복문 없이 한 줄로 구하여라. [01-02]

    힌트 1

    나머지 연산자는 %%입니다. "또는"은 |이다.

    힌트 2

    논리 벡터에 sum()을 쓰면 TRUE의 개수가 나온다.

    풀이 
    cnt <- 0
for (i in 1:100) {
  if (i %% 3 == 0 | i %% 5 == 0) cnt <- cnt + 1
}
cnt                                         # 47
sum((1:100) %% 3 == 0 | (1:100) %% 5 == 0)  # 47

    답은 47개입니다(3의 배수 33개 + 5의 배수 20개 − 15의 배수 6개). 두 번째 방법이 더 짧고 R에서는 보통 더 빠르다.

  5. 실습다음 코드의 출력을 예측하여라. [01-03]

    m <- matrix(1:6, nrow = 2)
apply(m, 1, sum)
apply(m, 2, sum)
sapply(list(a = 1:3, b = 4:6), mean)
    힌트 1

    matrix()는 기본적으로 값을 열 방향으로 채운다. 첫 열이 1, 2이다.

    힌트 2

    apply의 두 번째 인수 1은 행마다, 2는 열마다 함수를 적용한다.

    풀이

    m은 1행이 1 3 5, 2행이 2 4 6이다. 따라서 apply(m, 1, sum)은 9 12, apply(m, 2, sum)은 3 7 11이다. sapply는 리스트의 각 원소에 mean을 적용해 이름 붙은 벡터 a 2, b 5를 돌려준다.

    행·열 합계라면 rowSums(m), colSums(m)이 더 빠르다.

  6. 판단친구가 다음처럼 결과 벡터를 반복문 안에서 늘려 가는 코드를 썼다. 무엇이 비효율적인지 설명하고 두 가지 방법으로 고쳐라. [01-03]

    out <- c()
for (i in 1:100000) out <- c(out, i^2)
    힌트 1

    c(out, i^2)는 매번 새 벡터를 만들어 기존 값을 모두 복사한다.

    힌트 2

    크기를 미리 정해 두거나, 아예 벡터화하여라.

    풀이

    반복마다 길이가 하나 늘어난 벡터를 새로 만들고 앞의 값을 모두 복사하므로, 전체 작업량이 \(1 + 2 + \cdots + n \approx n^2/2\)에 비례해 매우 느리다.

    out <- numeric(100000)              # 미리 자리 만들기
for (i in 1:100000) out[i] <- i^2
out <- (1:100000)^2                 # 벡터화: 가장 간단하고 빠름

  7. 실습다음 함수는 cv(c("3", "4", "5"))에서 오류가 난다. 오류 메시지를 예상하고, 입력을 점검해 분명한 오류를 내도록 고쳐라.
    cv <- function(x) sd(x) / mean(x) [01-04]

    힌트 1

    문자 벡터에 mean을 쓰면 어떻게 되나요?

    힌트 2

    stopifnot(is.numeric(x)).

    풀이

    mean은 경고와 함께 NA를 주고 sd는 문자를 숫자로 바꾸려다 오류나 NA를 낸다. 원인이 입력의 형이라는 것이 메시지만으로는 분명하지 않다.

    cv <- function(x) {
  stopifnot(is.numeric(x))
  sd(x) / mean(x)
}

    이제 is.numeric(x) is not TRUE라는 분명한 오류가 난다. 호출하는 쪽에서 as.numeric으로 바꾼다.
