벡터, 행렬, 리스트, 데이터프레임

본문

설문 자료에는 나이(숫자), 성별(범주), 응답 여부(참과 거짓)가 한 표에 섞여 있다. R은 이런 표를 어떤 모양으로 담을까? 그리고 숫자 하나도 벡터라는 R의 규칙은 분석 코드를 어떻게 짧게 만들까?

먼저 알아야 할 것R과 RStudio(또는 Positron)를 설치해 둔다. 프로그래밍 경험은 필요 없다.

1.1.1벡터

처음 질문의 둘째 부분부터 보자. R에서는 숫자 하나도 길이 1인 벡터이다. 그리고 대부분의 계산이 벡터 전체에 한꺼번에 적용되므로, 자료 구조를 이해하면 반복문 없이 짧은 코드로 분석할 수 있다.

x <- c(3, 1, 4, 1, 5)        # 숫자 벡터
names <- c("가", "나", "다")   # 문자 벡터
ok <- x > 2                    # 논리 벡터 FALSE TRUE ...
x[2]; x[c(1, 3)]; x[-1]; x[x > 2]   # 위치, 여러 개, 제외, 조건
length(x); sum(x); mean(x)

여기서 벡터의 원소는 모두 같은 자료형이어야 한다. 그래서 섞으면 가장 일반적인 형으로 바뀌어, c(1, "a")는 문자 벡터가 된다. 한편 인덱스는 1부터 시작하며, x[x > 2]처럼 조건을 넣으면 조건에 맞는 원소만 꺼낸다.

1.1.2행렬, 리스트, 데이터프레임

이제 처음 질문의 표로 가자. 그림 1의 나머지 세 구조를 표로 정리하면 다음과 같다.

구조만들기특징
행렬matrix(1:6, nrow = 2)같은 자료형, 2차원. m[1, 2], m[, 2]
리스트list(a = 1, b = "x", c = 1:3)서로 다른 형과 길이. l$a, l[["c"]]
데이터프레임data.frame(id = 1:3, g = c("A","B","A"))열마다 다른 형, 같은 길이. 통계 자료의 기본
범주(factor)factor(c("저","고","중"), levels = c("저","중","고"))범주형 변수. 수준의 순서를 지정

그러므로 설문 표는 데이터프레임에 담는다. 데이터프레임은 같은 길이의 벡터들을 묶은 리스트이므로, 나이 열은 숫자 벡터, 응답 여부 열은 논리 벡터가 된다. 성별처럼 정해진 범주를 갖는 변수는 factor로 바꾸어 수준의 순서를 지정한다. 이제 열은 d$g로, 조건에 맞는 행은 d[d$g == "A", ]로 꺼낸다. str(d)는 구조를, summary(d)는 열별 요약을 보여 준다.

예제 1.1.1

내장 자료 mtcars에서 연비(mpg)가 25 이상인 차의 이름과 마력을 꺼내라.

mtcars[mtcars$mpg >= 25, "hp", drop = FALSE]
rownames(mtcars)[mtcars$mpg >= 25]

풀이. 먼저 논리 벡터 mtcars$mpg >= 25로 행을 고르고 열 이름으로 열을 고른다. Fiat 128, Honda Civic, Toyota Corolla, Fiat X1-9, Porsche 914-2, Lotus Europa의 6대가 나온다. 물론 drop = FALSE는 열이 하나일 때도 데이터프레임 모양을 유지하게 한다.

흔한 실수다른 언어에 익숙하면 첫 원소를 x[0]으로 꺼내려 하기 쉽다. R의 인덱스는 1부터이며, x[0]은 오류 없이 길이 0인 벡터를 돌려주므로 실수를 알아채기 어렵다.
마무리

R의 기본 자료 구조는 같은 형의 1차원 벡터, 같은 형의 2차원 행렬, 무엇이든 담는 리스트, 그리고 열마다 형이 다르지만 길이가 같은 데이터프레임이다. 숫자, 범주, 참과 거짓이 섞인 설문 표는 데이터프레임에 담고, 범주형 변수는 factor로 바꾼다. 숫자 하나도 벡터이고 계산이 벡터 전체에 적용되므로, 조건 인덱싱 x[x > 2]처럼 반복문 없이 짧게 자료를 고르고 요약할 수 있다.

1.1.3연습문제

기본

  1. x <- c(5, NA, 3)의 평균을 구하면 어떻게 되는가? 결측을 빼고 구하려면 어떻게 하는가?
    답

    mean(x)는 NA이다. mean(x, na.rm = TRUE)는 4이다.

응용

  1. c(1, TRUE, "2")는 어떤 형의 벡터가 되며, 원소는 무엇인가?
    답

    가장 일반적인 형인 문자 벡터가 되어 "1" "TRUE" "2"이다.
