모의실험으로 표본평균의 분포 확인하기

본문

"표본평균은 정규분포에 가깝고 표준오차는 \(\sigma/\sqrt n\)이다." 통계학 수업에서 늘 듣는 말이지만, 모집단이 한쪽으로 크게 치우친 지수분포여도 정말 그럴까? 증명을 따라가는 대신 컴퓨터로 직접 확인해 볼 수 있을까?

먼저 알아야 할 것분포 함수(4.1절)와 replicate(1.3절)를 쓴다.

4.2.1코드

처음 질문의 답은 표본을 수천 번 뽑아 평균을 모으는 모의실험이다. 응통5 3.1절의 실습 카드를 코드로 재현하면 다음과 같다.

set.seed(2026)
n <- 30; B <- 5000
m <- replicate(B, mean(rexp(n, rate = 1)))   # 지수분포(평균 1, 표준편차 1)
mean(m); sd(m); 1 / sqrt(n)                  # 약 1, 약 0.18, 0.1826
hist(m, breaks = 50, freq = FALSE, main = "표본평균의 분포 (n = 30)")
curve(dnorm(x, 1, 1 / sqrt(n)), add = TRUE, col = "red", lwd = 2)
qqnorm(m); qqline(m)                          # 정규성 확인

그림 1이 그 결과이다. 표본평균들의 표준편차가 이론값 \(1/\sqrt{30} = 0.183\)과 맞고, 모양도 정규 곡선에 가깝다. 여기서 freq = FALSE로 히스토그램을 밀도 척도로 그려야 정규 곡선과 겹쳐 비교할 수 있다. 또 Q-Q 그림에서 위쪽 끝이 직선 위로 조금 휘면 아직 오른쪽 꼬리가 남아 있다는 뜻이다. set.seed는 같은 난수를 다시 만들어 결과를 재현하게 한다.

예제 4.2.1

\(n\)을 5, 30, 100으로 바꾸며 표본평균들의 치우침(왜도)을 구하는 코드를 써라.

skew <- function(x) mean(((x - mean(x)) / sd(x))^3)
sapply(c(5, 30, 100), function(n) skew(replicate(5000, mean(rexp(n)))))
# 이론값 2/sqrt(n) 0.89, 0.37, 0.20 근처

풀이. 지수분포의 왜도는 2이고, 표본평균의 왜도는 \(2/\sqrt n\)으로 줄어든다. 그러므로 \(n\)이 커질수록 치우침이 사라져 정규분포에 다가가는 것을 숫자로 확인할 수 있다.

주의모의실험의 결과에도 오차가 있다. 반복 횟수 \(B = 5000\)이면 표준편차 추정의 상대 오차는 약 \(1/\sqrt{2B} \approx 1\%\)이므로, 이론값과 1~2% 차이는 우연으로 보아야 한다.
마무리

replicate(B, mean(r분포(n)))로 표본을 수천 번 뽑아 평균을 모으면 표본평균의 분포를 직접 볼 수 있다. 크게 치우친 지수분포에서도 크기 30인 표본의 평균은 정규분포에 가깝고 표준편차가 \(\sigma/\sqrt n\)과 맞으며, 치우침은 \(2/\sqrt n\)으로 줄어든다. 비교할 때는 히스토그램을 밀도 척도로 그려 이론 곡선과 겹치고 Q-Q 그림을 함께 보며, set.seed로 재현 가능하게 한다.

4.2.2연습문제

기본

  1. 위 코드에서 \(n = 100\)으로 바꾸면 표본평균의 표준편차는 대략 얼마가 되어야 하는가?
    답

    \(1/\sqrt{100} = 0.1\)이다.

응용

  1. 코시 분포(rcauchy)로 같은 실험을 하면 어떻게 되는가?
    답

    \(n\)을 키워도 표본평균의 퍼짐이 줄지 않는다. 코시 분포는 평균이 없어 중심극한정리가 성립하지 않기 때문이다(응통6 7.3절).
