모의실험으로 표본평균의 분포 확인하기

본문
이 절에서 배울 것
  • replicate로 표본평균의 분포를 만든다.
  • 중심극한정리와 표준오차 공식을 확인한다.
먼저 알아야 할 것
  • 분포 함수 (4.1절), apply 계열 (1.3절).

이론을 눈으로

"표본평균은 정규분포에 가깝고 표준오차는 \(\sigma/\sqrt n\)"이라는 말을 컴퓨터로 직접 확인해 봅니다. 응통5 3.1절의 실습 카드를 코드로 재현하는 것입니다.

4.2.1코드

set.seed(2026)
n <- 30; B <- 5000
m <- replicate(B, mean(rexp(n, rate = 1)))   # 지수분포(평균 1, 표준편차 1)
mean(m); sd(m); 1 / sqrt(n)                  # 약 1, 약 0.18, 0.1826
hist(m, breaks = 50, freq = FALSE, main = "표본평균의 분포 (n = 30)")
curve(dnorm(x, 1, 1 / sqrt(n)), add = TRUE, col = "red", lwd = 2)
qqnorm(m); qqline(m)                          # 정규성 확인

freq = FALSE로 히스토그램을 밀도 척도로 그려야 정규 곡선과 겹쳐 비교할 수 있습니다. Q-Q 그림의 위쪽 끝이 직선 위로 조금 휘면 아직 오른쪽 꼬리가 남아 있다는 뜻입니다.

예제 4.2.1

\(n\)을 5, 30, 100으로 바꾸며 표본평균들의 치우침(왜도)을 구하는 코드를 쓰세요.

skew <- function(x) mean(((x - mean(x)) / sd(x))^3)
sapply(c(5, 30, 100), function(n) skew(replicate(5000, mean(rexp(n)))))
# 이론값 2/sqrt(n): 0.89, 0.37, 0.20 근처
요약
  1. replicate(B, mean(r분포(n)))로 표본분포를 만듦.
  2. 히스토그램(밀도 척도) + 이론 곡선, Q-Q 그림으로 비교.
  3. set.seed로 재현 가능하게.

4.2.3연습문제

응용

  1. 코시 분포(rcauchy)로 같은 실험을 하면 어떻게 되나요?
    답

    \(n\)을 키워도 표본평균의 퍼짐이 줄지 않습니다. 코시 분포는 평균이 없어 중심극한정리가 성립하지 않기 때문입니다(응통6 7.3절).
