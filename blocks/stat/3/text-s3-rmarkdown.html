코드와 결과를 함께 담은 문서

본문

분석 결과를 워드 보고서에 손으로 옮겨 적었다. 그런데 자료에 오류가 있어 다시 분석하니 표 열 개와 그림 다섯 장, 본문의 숫자 스무 개를 모두 다시 옮겨야 한다. 하나라도 빠뜨리면 보고서와 분석이 어긋난다. 자료가 바뀌면 보고서가 저절로 바뀌게 할 수는 없을까?

먼저 알아야 할 것R 기초(1.1절)와 그래프(3.1절)를 쓴다.

6.1.1구조

처음 질문의 답은 글과 코드를 한 파일에 쓰고, 문서를 만들 때 코드가 실행되어 결과가 들어가게 하는 것이다. R Markdown이나 Quarto 문서가 그런 파일이다.

---
title: "연비 분석"
author: "홍길동"
format: html          # Quarto. R Markdown이면 output: html_document
---

## 자료
`mtcars`의 자동차 `r nrow(mtcars)`대를 분석했다.

```{r}
#| echo: true
fit <- lm(mpg ~ wt, data = mtcars)
summary(fit)$coefficients
```

무게가 1000 lb 늘면 연비가 평균 `r round(-coef(fit)[2], 1)` mpg 낮았다.

문서는 세 부분으로 되어 있다. 맨 위 --- 사이의 머리말(YAML)에는 제목과 출력 형식을 적는다. 그 아래 글은 마크다운으로 쓰며, ##는 제목, *기울임*은 기울임 글꼴이다. 그리고 ```{r}로 시작하는 코드 덩어리는 문서를 만들 때 실행되어 결과가 그 자리에 들어간다. 덩어리 옵션으로 echo는 코드를 보일지, eval은 실행할지, fig-cap은 그림 설명을 정한다.

특히 문장 속의 `r nrow(mtcars)`처럼 쓰는 인라인 코드가 처음 질문의 본문 숫자 스무 개를 해결한다. 숫자를 손으로 적지 않고 계산식으로 적으므로, 자료가 바뀌면 숫자도 저절로 바뀐다. 문서는 RStudio의 Render(Knit) 버튼이나 quarto render 파일.qmd로 만들며, 한 원본으로 HTML, PDF, Word를 모두 만들 수 있다. PDF에는 LaTeX(TinyTeX)가 필요하다.

예제 6.1.1

위 문서를 render하면 마지막 문장은 어떻게 나타나는가?

풀이. coef(fit)[2]는 무게의 기울기 −5.344이므로 인라인 코드가 5.3으로 바뀌어 "무게가 1000 lb 늘면 연비가 평균 5.3 mpg 낮았다."로 나타난다. 자료에서 차 한 대를 빼고 다시 render하면 32대라는 숫자와 5.3이 함께 새로 계산된다.

흔한 실수코드 덩어리는 문서를 만들 때 새 R 세션에서 처음부터 실행된다. 그래서 콘솔에서 만들어 둔 객체를 문서 안 코드가 쓰면 render할 때 object not found 오류가 난다. 필요한 자료는 문서 안에서 읽어야 한다.
마무리

R Markdown과 Quarto 문서는 머리말, 마크다운 글, 코드 덩어리를 한 원본에 담고, render할 때 코드를 실행해 결과와 그림을 문서에 넣는다. 본문의 숫자는 인라인 코드로 적어 계산 결과가 그대로 들어가게 한다. 그래서 자료가 바뀌어도 손으로 옮겨 적을 필요 없이 다시 render만 하면 보고서 전체가 새 결과로 바뀌고, 한 원본에서 HTML, PDF, Word를 모두 만든다.
