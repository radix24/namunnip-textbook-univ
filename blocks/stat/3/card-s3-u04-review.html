확률분포와 모의실험 단원 마무리 연습

문제 7 · 실습·판단·도전 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 실습R 함수로 다음을 구하여라. (1) \(Z \sim N(0, 1)\)에서 \(P(Z \le 1.96)\) (2) \(P(Z \le z) = 0.95\)인 \(z\) (3) \(X \sim B(10, 0.5)\)에서 \(P(X = 3)\) (4) \(P(X \le 3)\) [04-01]

    힌트 1

    접두어 d는 밀도(확률질량), p는 누적확률, q는 분위수, r은 난수이다.

    힌트 2

    이항분포는 dbinom(x, size, prob)이다.

    풀이

    (1) pnorm(1.96) = 0.975 (2) qnorm(0.95) = 1.645 (3) dbinom(3, 10, 0.5) = 0.1172 (4) pbinom(3, 10, 0.5) = 0.1719.

    (3)은 \(\binom{10}{3}/2^{10} = 120/1024\)과 같다. p와 q는 서로 역함수 관계라 pnorm(qnorm(0.95))는 0.95이다.

  2. 실습\(X \sim B(10, 0.5)\)에서 \(P(X \ge 3)\)을 구하려고 1 - pbinom(3, 10, 0.5)라고 썼다. 무엇이 틀렸는지 설명하고 바른 코드를 두 가지 써라. [04-01]

    힌트 1

    pbinom(3, ...)은 \(P(X \le 3)\)이다. \(1 -\) 이것은 무엇인가요?

    힌트 2

    이산분포에서는 \(\le\)와 \(<\)가 다르다.

    풀이

    1 - pbinom(3, 10, 0.5)은 \(P(X > 3) = P(X \ge 4)\)이다. \(P(X \ge 3) = 1 - P(X \le 2)\)이므로 1 - pbinom(2, 10, 0.5) 또는 pbinom(2, 10, 0.5, lower.tail = FALSE)가 바른 코드이고, 값은 0.9453이다. 연속분포에서는 이 차이가 없지만 이산분포에서는 경계값을 꼭 확인해야 한다.

  3. 판단runif(3)을 두 번 실행하면 값이 다르다. 보고서의 모의실험 결과를 매번 같게 하려면 어떻게 하는지 쓰고, 그 방법을 쓸 때 주의할 점을 써라. [04-01]

    힌트 1

    R의 난수는 정해진 규칙으로 만들어지는 의사 난수이다.

    힌트 2

    출발점(시드)을 정하면 같은 수열이 나온다.

    풀이

    모의실험 앞에 set.seed(2026)처럼 시드를 정하면 같은 코드에서 같은 난수열이 나온다.

    주의할 점: 시드는 분석 전에 한 번 정하고, 결과가 마음에 들 때까지 바꾸지 않는다. 또 R 버전에 따라 난수 생성 방식이 바뀐 적이 있으므로(R 3.6.0의 sample), 버전도 함께 기록한다. 시드에 따라 결과가 크게 달라진다면 반복 횟수가 부족하다는 신호이다.

  4. 실습평균이 1인 지수분포에서 크기 30인 표본의 평균을 10000번 모의실험하는 코드를 쓰고, 표본평균들의 평균과 표준편차가 이론적으로 얼마여야 하는지 써라. 히스토그램은 어떤 모양일까? [04-02]

    힌트 1

    replicate(10000, mean(rexp(30, rate = 1)))을 쓴다.

    힌트 2

    지수분포(비율 1)의 평균과 표준편차는 모두 1이다.

    풀이 
    set.seed(1)
m <- replicate(10000, mean(rexp(30, rate = 1)))
mean(m); sd(m); hist(m)

    이론값은 평균 1, 표준편차 \(1/\sqrt{30} \approx 0.183\)이다. 모의실험 값도 이와 가깝게 나온다. 지수분포는 오른쪽으로 많이 치우쳤지만, 표본평균의 히스토그램은 종 모양에 가깝고 오른쪽 꼬리가 약간 남아 있습니다(중심극한정리).

  5. 실습주사위 두 개를 던져 합이 7일 확률을 10000번 모의실험으로 추정하는 코드를 써라. 이론값과, 추정값의 표준오차(모의실험 오차의 크기)도 써라. [04-02]

    힌트 1

    sample(1:6, 10000, replace = TRUE)를 두 번 만들어 더한다.

    힌트 2

    비율 추정의 표준오차는 \(\sqrt{p(1-p)/n}\)이다.

    풀이 
    set.seed(1)
s <- sample(1:6, 10000, replace = TRUE) + sample(1:6, 10000, replace = TRUE)
mean(s == 7)

    이론값은 \(6/36 = 1/6 \approx 0.1667\)이고, 표준오차는 \(\sqrt{(1/6)(5/6)/10000} \approx 0.0037\)이다. 따라서 추정값은 대부분 0.159~0.174(±2 표준오차) 안에 들어온다. 오차를 반으로 줄이려면 반복을 4배로 늘려야 한다.

  6. 도전23명 가운데 생일이 같은 사람이 적어도 한 쌍 있을 확률을 모의실험으로 추정하고, 정확한 값 \(1 - \frac{365\cdot364\cdots343}{365^{23}}\)과 비교하세요(윤년은 무시). [04-02]

    힌트 1

    한 번의 실험은 b <- sample(1:365, 23, replace = TRUE)이고, 중복 여부는 any(duplicated(b))이다.

    힌트 2

    정확한 값은 1 - prod((365:343) / 365)이다.

    풀이 
    set.seed(1)
mean(replicate(10000, any(duplicated(sample(1:365, 23, replace = TRUE)))))
1 - prod((365:343) / 365)   # 0.5072972

    정확한 값은 약 0.507로, 23명만 모여도 절반 넘는 확률로 생일이 겹친다. 모의실험 값도 0.50 근처(표준오차 약 0.005)로 나온다. 직관보다 큰 까닭은 짝의 수가 \(\binom{23}{2} = 253\)개나 되기 때문이다.

  7. 실습자료 x의 평균에 대한 95% 붓스트랩 백분위 구간을 구하는 함수 boot_ci(x, B = 2000)를 작성하여라. [04-03]

    힌트 1

    replicate(B, mean(sample(x, replace = TRUE))).

    힌트 2

    quantile(..., c(0.025, 0.975)).

    풀이 
    boot_ci <- function(x, B = 2000) {
  m <- replicate(B, mean(sample(x, replace = TRUE)))
  quantile(m, c(0.025, 0.975))
}
set.seed(1); boot_ci(c(3, 7, 4, 9, 5, 6))

    표본 크기와 같은 크기로 복원 추출하는 것이 핵심이며, 시드를 고정해 재현한다.
