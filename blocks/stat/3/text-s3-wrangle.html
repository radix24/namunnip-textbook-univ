본문

매장별 매출 표와 매장별 지역 표가 따로 있다. 지역별 평균 매출을 내려면 두 표를 붙이고, 묶고, 요약해야 한다. 그런데 한 표에만 있는 매장은 어떻게 될까? 자료 정리의 수많은 작업은 몇 가지 동작으로 정리될까?

먼저 알아야 할 것자료 정리(2.2절)와 tapply(1.3절)를 쓴다.

2.3.1기본 R과 dplyr

처음 질문의 둘째 부분부터 답하자. 자료 정리의 대부분은 다섯 동작, 곧 행 고르기, 열 고르기, 정렬, 변수 만들기, 그룹 요약의 조합이다. dplyr 패키지는 이것을 동사 이름의 함수로 제공한다.

동작기본 Rdplyr
행 고르기d[d$cyl == 4, ]filter(d, cyl == 4)
열 고르기d[, c("mpg", "wt")]select(d, mpg, wt)
정렬d[order(-d$mpg), ]arrange(d, desc(mpg))
변수 만들기d$kpl <- d$mpg * 0.425mutate(d, kpl = mpg * 0.425)
그룹 요약aggregate(mpg ~ cyl, d, mean)d |> group_by(cyl) |> summarise(m = mean(mpg), n = n())

파이프 |>(R 4.1 이상)는 왼쪽 결과를 오른쪽 함수의 첫 인수로 넘긴다. 그래서 자료를 거르고, 묶고, 요약하는 순서대로 코드가 읽힌다.

예제 2.3.1

mtcars에서 기통 수별 대수, 평균 연비, 평균 마력을 연비가 높은 순으로 구하여라.

library(dplyr)
mtcars |> group_by(cyl) |>
  summarise(n = n(), mpg = mean(mpg), hp = mean(hp)) |>
  arrange(desc(mpg))
# 4기통 11대 26.7 82.6 / 6기통 7대 19.7 122 / 8기통 14대 15.1 209

풀이. 묶고, 요약하고, 정렬하는 세 단계가 파이프로 이어진다. 기통이 많을수록 마력은 크고 연비는 낮다.

2.3.2결합

이제 처음 질문의 두 표를 붙이자. 공통 열(열쇠)로 행을 맞추는 것이 결합이다.

sales <- data.frame(store = c(1, 2, 3, 4), amount = c(120, 80, 150, 60))
info  <- data.frame(store = c(1, 2, 3, 5), region = c("서울", "부산", "서울", "대구"))
merge(sales, info, by = "store")                 # 공통 열쇠만 1, 2, 3
merge(sales, info, by = "store", all.x = TRUE)   # sales 기준, 4번은 region NA
# dplyr: inner_join(sales, info, by = "store"), left_join(...)

그림 1처럼 기본은 두 표에 모두 있는 열쇠만 남긴다. 따라서 한 표에만 있는 매장은 빠지고, all.x = TRUE(dplyr의 left_join)를 쓰면 왼쪽 표의 행을 모두 남기되 짝이 없는 칸은 NA가 된다. 결합 뒤에는 행 수가 예상과 같은지 꼭 확인한다.

흔한 실수열쇠가 한쪽 표에서 중복되면 결합 뒤 행이 불어난다. 예를 들어 지역 표에 1번 매장이 두 번 적혀 있으면 1번 매장의 매출이 두 번 세어져 합계가 틀린다.
마무리

자료 정리는 행 고르기, 열 고르기, 정렬, 변수 만들기, 그룹 요약의 다섯 동작으로 대부분 해결되며, dplyr의 filter, select, arrange, mutate, group_by와 summarise를 파이프로 이으면 순서대로 읽힌다. 두 표는 열쇠로 결합하는데, 기본은 공통 열쇠만 남겨 한 표에만 있는 행이 빠지고, 왼쪽 기준 결합은 짝 없는 칸을 NA로 남긴다. 결합 뒤에는 행 수를 확인한다.
