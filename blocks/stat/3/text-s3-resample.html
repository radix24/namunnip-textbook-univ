붓스트랩과 순열 검정을 R로

본문

4.2절에서는 모집단을 알고 표본을 되풀이해 뽑았다. 그런데 실제 분석에서는 모집단을 모르고 표본 하나만 있다. 중앙값의 표준오차처럼 공식이 복잡한 양은 어떻게 구할까? 그리고 두 집단 평균 차이의 p값을 분포 가정 없이 구할 수 있을까?

먼저 알아야 할 것모의실험(4.2절), 함수와 반복(1.2절), replicate(1.3절)를 쓴다.

4.3.1sample

처음 질문의 답은 표본 자체를 재표집하는 것이다. 그러면 표준오차와 p값을 공식 없이 얻을 수 있고(이론은 응통12 06단원), 코드는 sample 하나로 거의 다 된다.

sample(1:5)                       # 순서를 섞기(비복원)
sample(1:5, replace = TRUE)       # 복원 추출(같은 값이 여러 번)
sample(c("H", "T"), 10, replace = TRUE, prob = c(0.3, 0.7))

4.3.2붓스트랩

먼저 첫째 질문이다. 표본과 같은 크기로 복원 추출하고, 통계량을 다시 계산하는 일을 수천 번 하는 것이 붓스트랩이다.

set.seed(2026)
x <- c(12, 15, 9, 20, 14, 11, 30, 13, 10, 16)
boot_med <- replicate(5000, median(sample(x, replace = TRUE)))
sd(boot_med)                          # 중앙값의 표준오차
quantile(boot_med, c(0.025, 0.975))   # 95% 백분위 구간

다시 뽑은 표본의 중앙값들이 흩어진 정도가 중앙값의 표준오차이고, 그 2.5%와 97.5% 분위수가 95% 백분위 구간이다. 두 집단이면 집단마다 따로 재표집한다(응통14 4.3절).

4.3.3순열 검정

이제 둘째 질문이다. 두 집단이 같다는 귀무가설 아래에서는 집단 이름표가 아무 의미가 없다. 그러므로 이름표를 섞어 차이의 분포를 만들고, 관측 차이 이상이 나온 비율을 p값으로 삼는다. 이것이 순열 검정이다.

a <- c(12, 15, 18); b <- c(20, 22, 25)
obs <- mean(b) - mean(a)                     # 7.33
all <- c(a, b)
perm <- replicate(10000, {
  idx <- sample(length(all), length(b))       # 무작위로 b 자리 고르기
  mean(all[idx]) - mean(all[-idx]) })
mean(perm >= obs)                            # 단측 p값
예제 4.3.1

위 자료에서 가능한 배치를 모두 세어 정확한 단측 p값을 구하고, 무작위 순열 10000번의 결과와 비교하여라.

풀이. 6개 가운데 b 자리 3개를 고르는 배치는 \(\binom63 = 20\)가지이다. 관측 배치, 곧 가장 큰 세 값이 b인 배치가 차이가 가장 크므로 7.33 이상은 그 하나뿐이고, 그림 1처럼 p값은 \(1/20 = 0.05\)이다. 무작위 순열 10000번이면 약 0.05 ± 0.002 근처가 나온다. 표본이 이렇게 작으면 combn(6, 3)으로 모든 배치를 세는 정확 검정이 낫다.

흔한 실수붓스트랩에서 replace = TRUE를 빼면 원래 표본을 순서만 바꿔 다시 뽑는 셈이라, 중앙값이 매번 같아 표준오차가 0으로 나온다. 붓스트랩은 복원 추출, 순열 검정은 비복원 추출이다.
마무리

모집단을 모를 때는 표본 자체를 재표집한다. 붓스트랩은 sample(x, replace = TRUE)로 복원 추출해 통계량을 수천 번 다시 계산하고, 그 표준편차와 분위수로 중앙값 같은 통계량의 표준오차와 신뢰구간을 얻는다. 순열 검정은 귀무가설 아래 의미 없는 집단 이름표를 sample로 섞어 차이의 분포를 만들고, 관측 이상인 비율로 p값을 얻으며, 표본이 작으면 combn으로 모든 배치를 센다.

4.3.4연습문제

기본

  1. set.seed를 쓰는 까닭은 무엇인가?
    답

    같은 난수를 다시 만들어 결과를 재현하기 위해서이다. 시드가 없으면 실행할 때마다 구간 끝이 조금씩 달라진다.

응용

  1. 대응 자료(같은 사람의 전후 차이 \(d\))의 순열 검정은 어떻게 하는가?
    답

    귀무가설 아래 차이의 부호가 무작위이므로 부호를 섞는다. replicate(10000, mean(d * sample(c(-1, 1), length(d), replace = TRUE)))에서 관측 평균 이상인 비율이 p값이다.
