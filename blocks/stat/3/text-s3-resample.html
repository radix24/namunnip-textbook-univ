붓스트랩과 순열 검정을 R로

본문
이 절에서 배울 것
  • sample로 복원·비복원 추출을 한다.
  • 붓스트랩으로 중앙값의 표준오차와 신뢰구간을 구하는 코드를 쓴다.
  • 순열 검정으로 두 집단 평균 차이의 p값을 구하는 코드를 쓴다.
먼저 알아야 할 것
  • 모의실험 (4.2절), 함수와 반복 (1.2절), replicate (1.3절).

공식 대신 컴퓨터로

4.2절에서는 모집단을 알고 표본을 되풀이해 뽑았습니다. 실제 분석에서는 모집단을 모르고 표본 하나만 있습니다. 그 표본 자체를 재표집하면 표준오차와 p값을 공식 없이 얻을 수 있습니다(이론은 응통12 06단원). 코드는 sample 하나로 거의 다 됩니다.

4.3.1sample

sample(1:5)                       # 순서를 섞기(비복원)
sample(1:5, replace = TRUE)       # 복원 추출(같은 값이 여러 번)
sample(c("H", "T"), 10, replace = TRUE, prob = c(0.3, 0.7))

4.3.2붓스트랩

set.seed(2026)
x <- c(12, 15, 9, 20, 14, 11, 30, 13, 10, 16)
boot_med <- replicate(5000, median(sample(x, replace = TRUE)))
sd(boot_med)                          # 중앙값의 표준오차
quantile(boot_med, c(0.025, 0.975))   # 95% 백분위 구간

표본과 같은 크기로 복원 추출하고, 통계량을 다시 계산하는 일을 수천 번 합니다. 두 집단이면 집단마다 따로 재표집합니다(응통14 4.3절).

4.3.3순열 검정

a <- c(12, 15, 18); b <- c(20, 22, 25)
obs <- mean(b) - mean(a)                     # 7.33
all <- c(a, b)
perm <- replicate(10000, {
  idx <- sample(length(all), length(b))       # 무작위로 b 자리 고르기
  mean(all[idx]) - mean(all[-idx]) })
mean(perm >= obs)                            # 단측 p값

귀무가설(두 집단이 같음) 아래 집단 이름표는 아무 의미가 없으므로 섞어서 차이의 분포를 만듭니다. 관측 차이 이상이 나온 비율이 p값입니다.

예제 4.3.1

4.3.3절의 자료에서 가능한 배치를 모두 세어 정확한 단측 p값을 구하고, 무작위 순열 10000번의 결과와 비교하세요.

풀이. 6개 가운데 b 자리 3개를 고르는 배치는 \(\binom63 = 20\)가지. 관측 배치(가장 큰 세 값이 b)가 차이가 가장 크므로 7.33 이상은 그 하나뿐, p값 \(1/20 = 0.05\). 무작위 순열 10000번이면 약 0.05 ± 0.002 근처가 나옵니다. 표본이 작으면 combn(6, 3)으로 모든 배치를 세는 정확 검정이 낫습니다.

요약
  1. sample(x, replace = TRUE) = 붓스트랩, sample(x) = 순열.
  2. replicate로 수천 번, sd와 quantile로 요약.
  3. 작은 표본은 combn으로 정확한 순열 분포.

4.3.4연습문제

기본

  1. set.seed를 쓰는 이유는?
    답

    같은 난수를 다시 만들어 결과를 재현하기 위해서입니다. 시드가 없으면 실행할 때마다 구간 끝이 조금씩 달라집니다.

응용

  1. 대응 자료(같은 사람의 전후 차이 \(d\))의 순열 검정은 어떻게 하나요?
    답

    귀무가설 아래 차이의 부호가 무작위이므로 부호를 섞습니다: replicate(10000, mean(d * sample(c(-1, 1), length(d), replace = TRUE))). 관측 평균 이상인 비율이 p값입니다.
