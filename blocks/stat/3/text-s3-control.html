조건문, 반복문, 함수

본문

변수 스무 개의 변동계수를 구해야 한다. 같은 계산 코드를 스무 번 복사해 변수 이름만 바꾸면 될까? 그러다 한 군데 이름을 잘못 바꾸면 틀린 결과가 조용히 섞인다. 되풀이되는 계산을 안전하게 묶는 방법은 무엇일까?

먼저 알아야 할 것자료 구조(1.1절)를 쓴다.

1.2.1조건과 반복

처음 질문의 답은 반복문과 함수로 묶는 것이다. 먼저 조건과 반복부터 보자.

score <- 78
if (score >= 90) { "A" } else if (score >= 80) { "B" } else { "C 이하" }
ifelse(c(95, 82, 60) >= 80, "합격", "불합격")    # 벡터에 한꺼번에

total <- 0
for (i in 1:10) total <- total + i^2              # 1~10 제곱합 385
n <- 0; s <- 0
while (s < 100) { n <- n + 1; s <- s + n }       # 합이 100을 넘는 첫 n = 14

여기서 if/else는 값 하나를 판단하고, ifelse는 벡터의 원소마다 한꺼번에 판단한다. for는 정해진 횟수만큼, while은 조건이 참인 동안 되풀이한다. 그림 1이 위 제곱합 코드의 흐름이다.

1.2.2함수

다음으로 되풀이되는 계산을 함수로 묶는다. 변동계수를 계산하는 함수는 다음과 같다.

cv <- function(x, na.rm = TRUE) {
  sd(x, na.rm = na.rm) / mean(x, na.rm = na.rm)   # 변동계수
}
cv(mtcars$mpg)          # 약 0.30
cv(c(1, NA, 3))         # 기본값 na.rm = TRUE

이때 함수는 마지막 식의 값을 돌려주며, return()은 중간에 끝낼 때 쓴다. 함수 안에서 만든 변수는 밖에 영향을 주지 않는 지역 변수이다. 그러므로 처음 질문의 스무 변수에는 같은 함수를 스무 번 부르면 되고, 계산식을 고칠 때도 한 곳만 고치면 된다. 좋은 함수는 한 가지 일만 하고, 이름이 그 일을 말해 준다.

예제 1.2.1

표본 크기 \(n\)을 받아 표준정규 난수 \(n\)개의 평균을 돌려주는 함수를 만들고, \(n = 100\)으로 1000번 실행해 평균들의 표준편차를 구하여라.

mean_norm <- function(n) mean(rnorm(n))
set.seed(1)
m <- numeric(1000)
for (b in 1:1000) m[b] <- mean_norm(100)
sd(m)      # 이론값 1/sqrt(100) = 0.1 근처

풀이. 결과를 담을 벡터 m을 미리 만들어 두고 채운다. 왜냐하면 반복할 때마다 벡터를 늘이면 느려지기 때문이다. 따라서 결과는 이론값 \(1/\sqrt{100} = 0.1\) 근처이다.

흔한 실수if (x > 0)에 길이가 2 이상인 벡터를 넣으면 R 4.2부터는 오류가 난다. 원소마다 판단하려면 ifelse를, 모두 또는 하나라도 만족하는지 보려면 all()이나 any()를 쓴다.
마무리

if/else는 값 하나를, ifelse는 벡터를 판단하며, for는 정해진 횟수만큼, while은 조건이 참인 동안 되풀이한다. 되풀이되는 계산은 인수와 기본값을 가진 함수로 묶어, 코드를 복사해 붙이며 생기는 실수를 막고 고칠 곳을 한 곳으로 줄인다. 반복 결과는 미리 만든 벡터에 채운다.
