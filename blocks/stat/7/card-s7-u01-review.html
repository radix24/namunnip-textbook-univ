점추정 단원 마무리 연습

문제 6 · 계산·개념·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 계산\(U(0, \theta)\)에서 표본 1.2, 3.5, 0.8, 2.9, 4.1을 얻었다. \(\theta\)의 적률추정량과 최대가능도추정량을 구하고 값을 계산하여라. [01-01]

    힌트 1

    적률법: \(E(X) = \theta/2\)를 \(\bar X\)와 같다고 놓는다.

    힌트 2

    가능도는 \(L(\theta) = \theta^{-n}\) (모든 \(x_i \le \theta\)일 때), 그 밖에서는 0이다. \(\theta\)가 작을수록 커지지만 \(\max x_i\)보다 작을 수는 없다.

    풀이

    적률추정량은 \(\tilde\theta = 2\bar X = 2\times2.5 = 5.0\)이다. 최대가능도추정량은 \(\hat\theta = X_{(n)} = 4.1\)이다.

    두 추정량이 꽤 다르다. 적률추정량은 관측된 최댓값보다 커서 말이 되지만, 경우에 따라 \(2\bar X < X_{(n)}\)이 되어 "관측된 값보다 작은 상한"이라는 모순이 생길 수 있다. 최대가능도추정량은 그런 일이 없지만 항상 참값보다 작게 나오는 경향(편향)이 있다.

  2. 계산\(N(\mu, \sigma^2)\)에서 \(\mu\)와 \(\sigma^2\)의 최대가능도추정량을 유도하고, 자료 2, 4, 4, 5, 7, 8로 값을 구하여라. 표본분산 \(S^2\)과 비교하여라. [01-02]

    힌트 1

    로그가능도는 \(-\frac n2\ln\sigma^2 - \frac{1}{2\sigma^2}\sum(x_i - \mu)^2 + \text{상수}\)이다.

    힌트 2

    \(\sigma^2\)을 하나의 변수로 보고 미분하여라.

    풀이

    \(\partial\ell/\partial\mu = \frac{1}{\sigma^2}\sum(x_i - \mu) = 0\)에서 \(\hat\mu = \bar x\). \(\partial\ell/\partial\sigma^2 = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum(x_i - \bar x)^2 = 0\)에서 \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\).

    자료에서 \(\hat\mu = 5\), \(\hat\sigma^2 = 24/6 = 4\), \(S^2 = 24/5 = 4.8\)이다. 최대가능도추정량은 \(n\)으로, 표본분산은 \(n - 1\)로 나눈다.

  3. 개념앞 문제의 \(\hat\sigma^2 = \frac1n\sum(X_i - \bar X)^2\)의 기댓값을 구해 편향을 밝히고, 그런데도 \(\hat\sigma^2\)을 나쁜 추정량이라 할 수 없는 까닭을 평균제곱오차와 일치성으로 설명하여라. [01-03]

    힌트 1

    \(E(S^2) = \sigma^2\)이고 \(\hat\sigma^2 = \frac{n-1}{n}S^2\)이다.

    힌트 2

    정규 표본에서 \(\mathrm{Var}(S^2) = 2\sigma^4/(n-1)\)이다.

    풀이

    \(E(\hat\sigma^2) = \frac{n-1}{n}\sigma^2\)이므로 편향은 \(-\sigma^2/n\)이다.

    그러나 평균제곱오차는 \(\mathrm{MSE}(\hat\sigma^2) = \frac{(2n-1)\sigma^4}{n^2}\), \(\mathrm{MSE}(S^2) = \frac{2\sigma^4}{n-1}\)이라 \(\hat\sigma^2\)이 언제나 더 작습니다(분산이 줄어든 효과가 편향보다 큼). 또 편향이 \(n\to\infty\)일 때 0으로 가고 분산도 0으로 가므로 일치추정량이다. 불편성은 추정량을 고르는 여러 기준 가운데 하나일 뿐이다.

  4. 계산\(U(0, \theta)\), \(n = 5\)에서 세 추정량 \(2\bar X\), \(X_{(n)}\), \(\frac{n+1}{n}X_{(n)}\)의 평균제곱오차를 \(\theta^2\)의 배수로 비교하여라. \(X_{(n)}\)의 평균은 \(\frac{n}{n+1}\theta\), 분산은 \(\frac{n\theta^2}{(n+1)^2(n+2)}\)이다. [01-03]

    힌트 1

    \(2\bar X\)는 불편이고 분산은 \(4\cdot\frac{\theta^2}{12n}\)이다.

    힌트 2

    \(\mathrm{MSE} = \mathrm{분산} + \mathrm{편향}^2\)이다.

    풀이

    \(2\bar X\): \(\theta^2/(3n) = \theta^2/15 \approx 0.067\theta^2\).

    \(X_{(n)}\): 편향 \(-\theta/6\), 분산 \(5\theta^2/252\)이므로 \(\mathrm{MSE} = \frac{2\theta^2}{(n+1)(n+2)} = \theta^2/21 \approx 0.048\theta^2\).

    \(\frac{n+1}{n}X_{(n)}\): 불편, 분산 \(\frac{\theta^2}{n(n+2)} = \theta^2/35 \approx 0.029\theta^2\).

    최댓값을 쓰는 추정량이 평균을 쓰는 추정량보다 훨씬 좋다. \(U(0, \theta)\)에서는 최댓값이 \(\theta\)에 대한 정보를 모두 담고 있기 때문입니다(응통7-02-01).

  5. 판단\(\mu\)를 추정할 때 첫 관측값 \(X_1\)만 쓰는 추정량은 불편이다. 이 추정량이 일치추정량인지 판단하고, 불편성과 일치성의 관계를 설명하여라. [01-04]

    힌트 1

    일치성은 \(n\to\infty\)일 때 추정량이 참값으로 확률수렴하는 성질이다.

    힌트 2

    \(X_1\)의 분포는 \(n\)이 커져도 바뀌지 않는다.

    풀이

    \(E(X_1) = \mu\)이므로 불편이지만, \(n\)이 아무리 커도 \(X_1\)의 분포는 그대로라 \(P(|X_1 - \mu| > \varepsilon)\)이 0으로 가지 않는다. 일치추정량이 아니다.

    불편이어도 일치가 아닐 수 있고(이 예), 편향이 있어도 일치일 수 있습니다(앞의 \(\hat\sigma^2\)). 충분조건으로는 "편향과 분산이 모두 0으로 가면 일치"가 자주 쓰인다.

  6. 계산기하분포 \(P(X = k) = (1-p)^{k-1}p\), \(k = 1, 2, \ldots\)에서 자료 3, 1, 4, 2를 얻었다. \(p\)의 최대가능도추정량을 구하여라. 적률추정량과 같나요? [01-02]

    힌트 1

    로그가능도는 \(\big(\sum x_i - n\big)\ln(1-p) + n\ln p\)이다.

    힌트 2

    \(E(X) = 1/p\)이다.

    풀이

    \(\ell'(p) = -\frac{\sum x_i - n}{1-p} + \frac np = 0\)에서 \(\hat p = n/\sum x_i = 1/\bar x = 1/2.5 = 0.4\)이다. 적률법도 \(1/p = \bar x\)에서 같은 값을 준다. 두 방법이 일치하는 경우가 많지만(지수족의 평균 모수), 앞의 균등분포처럼 다른 경우도 있다.
