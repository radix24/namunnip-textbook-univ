완비성과 레만-셰페 정리

본문
이 절에서 배울 것
  • 완비 통계량을 정의하고 간단한 경우에 완비성을 보인다.
  • 레만-셰페 정리로 최소분산불편추정량의 유일성을 증명한다.
  • 완비 충분통계량의 함수 가운데 불편인 것을 찾아 UMVUE를 구한다.
먼저 알아야 할 것
  • 라오-블랙웰 정리 (2.2절).

개선한 것이 최선인가

라오-블랙웰 정리는 어떤 불편추정량이든 충분통계량의 함수로 바꾸면 나아진다고 말합니다. 그런데 서로 다른 불편추정량에서 시작하면 서로 다른 \(T\)의 함수가 나오지 않을까요? 그렇다면 어느 것이 최선인지 또 비교해야 합니다. \(T\)의 함수인 불편추정량이 하나뿐이라면 고민이 사라지고, 그것이 곧 최선입니다. 이 "하나뿐"을 보장하는 성질이 완비성입니다.

2.3.1완비성

정의 2.3.1

통계량 \(T\)가 완비: 모든 \(\theta\)에서 \(E_\theta[g(T)] = 0\)이면 모든 \(\theta\)에서 \(P_\theta(g(T) = 0) = 1\)인 경우.

뜻: \(T\)의 함수로 0을 불편추정하는 방법은 0 자체뿐입니다. 그래서 \(T\)의 함수인 불편추정량이 두 개 \(g_1(T), g_2(T)\)라면 차 \(g_1 - g_2\)의 기대값이 항상 0이므로 둘이 같아야 합니다. 완비성은 "\(T\)에 쓸데없는 정보가 섞여 있지 않다"는 성질로 볼 수 있습니다.

예제 2.3.2

베르누이 표본의 \(T = \sum X_i \sim B(n, p)\)가 완비임을 보이세요.

풀이. \(E_p[g(T)] = \sum_{t=0}^n g(t)\binom nt p^t(1-p)^{n-t} = (1-p)^n\sum_t g(t)\binom nt r^t\) (\(r = p/(1-p)\))가 모든 \(p \in (0, 1)\), 곧 모든 \(r > 0\)에서 0이라 합시다. 그러면 \(r\)에 대한 다항식 \(\sum_t g(t)\binom nt r^t\)이 항등적으로 0이므로 모든 계수가 0, 곧 \(g(t) = 0\) (\(t = 0, \ldots, n\))입니다.

2.3.2레만-셰페 정리

정리 2.3.3 (레만-셰페)

\(T\)가 완비 충분통계량이고 \(\phi(T)\)가 \(\tau(\theta)\)의 불편추정량이면 \(\phi(T)\)는 \(\tau(\theta)\)의 유일한 UMVUE이다.

\(W\)를 \(\tau(\theta)\)의 임의의 불편추정량이라 합시다. 라오-블랙웰로 \(\psi(T) = E(W\mid T)\)는 불편이고 \(\mathrm{Var}(\psi(T)) \le \mathrm{Var}(W)\). \(\phi(T)\)와 \(\psi(T)\)가 모두 \(T\)의 함수인 불편추정량이므로 완비성으로 \(\phi(T) = \psi(T)\) (확률 1). 따라서 \(\mathrm{Var}(\phi(T)) \le \mathrm{Var}(W)\)가 모든 불편추정량 \(W\)와 모든 \(\theta\)에서 성립합니다. 유일성도 같은 논리입니다. ∎

2.3.3UMVUE를 찾는 두 길

  1. 맞추기: 완비 충분통계량 \(T\)의 분포로 \(E[g(T)]\)를 계산해, 그것이 \(\tau(\theta)\)가 되도록 \(g\)를 고칩니다. 예: \(E(X_{(n)}) = \frac{n}{n+1}\theta\)이면 \(g(T) = \frac{n+1}nT\).
  2. 조건부 기대값: 단순한 불편추정량 \(W\)를 잡아 \(E(W\mid T)\)를 계산합니다(2.2절의 예제). 맞추기가 어려운 \(e^{-\lambda}\) 같은 모수에 좋습니다.

완비 충분통계량은 지수족에서 쉽게 얻습니다(2.4절). 다만 UMVUE가 늘 좋은 것은 아닙니다. 불편성을 고집하면 연습문제처럼 터무니없는 값을 내는 경우도 있습니다.

예제 2.3.4

\(U(0,\theta)\)의 UMVUE를 구하세요.

풀이. \(T = X_{(n)}\)은 충분입니다(2.1절). 완비성: 밀도 \(nt^{n-1}/\theta^n\)에서 \(E[g(T)] = \frac{n}{\theta^n}\int_0^\theta g(t)t^{n-1}dt = 0\)이 모든 \(\theta\)에서 성립하면 적분이 0이고, \(\theta\)로 미분하면 \(g(\theta)\theta^{n-1} = 0\), 곧 \(g = 0\)입니다. \(E X_{(n)} = \frac{n}{n+1}\theta\)이므로 UMVUE는 \(\frac{n+1}{n}X_{(n)}\)이며, 분산 \(\theta^2/(n(n+2))\)는 \(2\bar X\)의 \(\theta^2/(3n)\)보다 훨씬 작습니다.

요약
  1. 완비: \(T\)의 함수로 0을 불편추정하는 것은 0뿐.
  2. 레만-셰페: 완비 충분통계량의 함수인 불편추정량은 유일한 UMVUE.
  3. 찾는 법은 기대값 맞추기와 조건부 기대값 두 가지입니다.

2.3.4연습문제

기본

  1. 베르누이 표본에서 \(p\)의 UMVUE는? (\(\sum X_i\)는 완비 충분)
    답

    \(\bar X\). \(T\)의 함수이고 불편입니다.

응용

  1. \(X \sim \mathrm{Poisson}(\lambda)\) 한 개에서 \(e^{-2\lambda}\)의 불편추정량은 \((-1)^X\)뿐임을 보이고, 왜 나쁜 추정량인지 쓰세요.
    답

    \(E[g(X)] = \sum g(x)e^{-\lambda}\lambda^x/x! = e^{-2\lambda}\)이면 \(\sum g(x)\lambda^x/x! = e^{-\lambda} = \sum(-1)^x\lambda^x/x!\)이므로 계수를 비교해 \(g(x) = (-1)^x\). 0과 1 사이의 확률을 1 또는 −1로 추정하므로, 불편이지만 언제나 참값에서 멀리 떨어진 값을 냅니다.
