자료를 줄여도 잃는 것이 없을 때

동전 100번의 결과를 HTTH…로 모두 적어 둘 필요가 있을까요? \(p\)를 추정하는 데는 앞면 수 하나면 충분해 보입니다. 이 직관을 정확히 한 것이 충분통계량입니다.

2.1.1정의

정의 2.1.1

통계량 \(T = T(X_1, \ldots, X_n)\)이 주어졌을 때 표본의 조건부분포가 \(\theta\)에 의존하지 않으면 \(T\)를 \(\theta\)의 충분통계량이라 한다.

\(T\)를 안 뒤에 남은 정보(자료의 순서나 세부 배치)는 \(\theta\)와 무관한 순수한 우연이라는 뜻입니다.

예제 2.1.2

베르누이 표본에서 \(T = \sum X_i\)가 충분함을 정의로 보이세요.

풀이. \(\sum x_i = t\)인 특정 결과의 확률은 \(p^t(1-p)^{n-t}\), \(P(T = t) = \binom nt p^t(1-p)^{n-t}\). 조건부확률은 \(1/\binom nt\)로 \(p\)가 없습니다. 앞면 수를 알면 앞면이 어느 자리에 나왔는지는 모든 배치가 똑같이 가능합니다.

2.1.2분해 정리

정리 2.1.3 (피셔-네이만 분해 정리)

\(T\)가 충분통계량 \(\iff\) 결합 밀도가 \(f(\mathbf x;\theta) = g(T(\mathbf x);\theta)\,h(\mathbf x)\)로 인수분해된다. 여기서 \(h\)는 \(\theta\)를 포함하지 않는다.

(이산형) (⇒) \(f(\mathbf x;\theta) = P(T = t;\theta)P(\mathbf X = \mathbf x \mid T = t)\)이고 둘째 인자가 \(\theta\)에 무관하므로 \(g = P(T = t;\theta)\), \(h\) = 둘째 인자. (⇐) \(P(T = t) = \sum_{\mathbf x: T(\mathbf x) = t}g(t;\theta)h(\mathbf x) = g(t;\theta)\sum h(\mathbf x)\). 조건부확률 \(f(\mathbf x;\theta)/P(T=t) = h(\mathbf x)/\sum h\)에서 \(\theta\)가 약분됩니다. ∎

예제 2.1.4

(가) 포아송 (나) \(N(\mu, \sigma^2)\) (다) \(U(0,\theta)\)의 충분통계량을 찾으세요.

풀이. (가) \(\prod e^{-\lambda}\lambda^{x_i}/x_i! = e^{-n\lambda}\lambda^{\sum x_i}\cdot\frac{1}{\prod x_i!}\), \(T = \sum X_i\). (나) \((2\pi\sigma^2)^{-n/2}\exp\{-\frac{1}{2\sigma^2}(\sum x_i^2 - 2\mu\sum x_i + n\mu^2)\}\), \(T = (\sum X_i, \sum X_i^2)\), 곧 \((\bar X, S^2)\)와 같은 정보. (다) \(\theta^{-n}1\{x_{(n)} \le \theta\}\cdot1\{x_{(1)} \ge 0\}\), \(T = X_{(n)}\).

주의 표본 전체 \((X_1, \ldots, X_n)\)도 항상 충분통계량입니다. 관심은 가장 많이 줄인 것(최소충분통계량)입니다. 또 충분통계량의 일대일 함수도 충분통계량입니다.
요약
  1. 충분 = \(T\)가 주어지면 자료의 조건부분포가 \(\theta\)와 무관.
  2. 분해 정리: 가능도가 \(g(T;\theta)h(\mathbf x)\).
  3. MLE와 좋은 추정량은 충분통계량의 함수로 쓸 수 있습니다(2.2절).

2.1.3연습문제

기본

  1. 지수분포 \(\lambda\)의 충분통계량은?
    답

    \(\lambda^ne^{-\lambda\sum x_i}\), \(T = \sum X_i\).

응용

  1. \(U(\theta, \theta+1)\)의 충분통계량은?
    답

    \(1\{\theta \le x_{(1)}\}1\{x_{(n)} \le \theta + 1\}\)이므로 \((X_{(1)}, X_{(n)})\). 모수는 하나지만 충분통계량은 두 개가 필요합니다.
