순위 통계량의 분포

본문

t 검정은 정규성을 가정한다. 자료가 몇 개 안 되고 이상값이 섞여 있으면 정규성을 확인할 길도 없다. 값 자체 대신 크기 순서, 곧 순위만 쓰면 어떨까? 귀무가설 아래에서 순위로 만든 통계량의 분포를 모집단이 정규인지 지수인지 모른 채로 정확히 계산할 수 있을까?

먼저 알아야 할 것같은 가능성 모형(응통6 1.2절)과 합의 분산(응통6 5.2절)을 쓴다.

처음 질문의 답은 "할 수 있다"이다. 순위만 쓰면 귀무가설 아래에서 통계량의 분포가 모집단 분포와 관계없이 정해지며, 이것이 비모수 검정의 출발점이다(응통12에서 자세히). 이 절은 그 바탕이 되는 순위의 분포를 구한다.

7.1.1순위 벡터의 분포

정리 7.1.1 (순위 벡터의 분포)

\(X_1, \ldots, X_N\)이 독립이고 같은 연속분포를 따르면, 순위 벡터 \((R_1, \ldots, R_N)\)은 \(\{1, \ldots, N\}\)의 \(N!\)가지 순열 위에서 균일분포이다.

증명. 먼저 연속분포라 같은 값이 나올 확률은 0이므로 순위가 잘 정의된다. 그런데 결합 밀도 \(\prod f(x_i)\)는 변수의 순서를 바꿔도 같으므로, \(P(X_{\pi(1)} < \cdots < X_{\pi(N)})\)이 모든 순열 \(\pi\)에서 같고, 합이 1이므로 각각 \(1/N!\)이다. ∎

따라서 모집단 분포 \(f\)가 증명 어디에도 남지 않았다는 점이 처음 질문에 대한 답의 근거이다. 순위의 분포는 \(N\)만으로 정해진다.

7.1.2적률

정리 7.1.2 (순위의 적률)

정리 7.1.1의 조건에서 각 \(R_i\)는 \(\{1, \ldots, N\}\)에서 균일하며, \(E(R_i) = \frac{N+1}2\), \(\mathrm{Var}(R_i) = \frac{N^2-1}{12}\)이고, \(i \ne j\)이면 \(\mathrm{Cov}(R_i, R_j) = -\frac{N+1}{12}\)이다.

증명. 균일분포의 평균과 분산은 \(\frac1N\sum k = \frac{N+1}2\), \(\frac1N\sum k^2 - \big(\frac{N+1}2\big)^2 = \frac{N^2 - 1}{12}\)이다. 한편 공분산은 \(\sum_i R_i= \frac{N(N+1)}2\)가 상수라 분산이 0이라는 데서 나온다. 즉 \(0 = N\mathrm{Var}(R_1) + N(N-1)\mathrm{Cov}(R_1, R_2)\)이다. ∎

순위끼리 음의 상관이 있는 것은 한 관측값이 높은 순위를 차지하면 다른 관측값이 그 순위를 가질 수 없기 때문이다. 이는 비복원추출과 같은 구조이며, 다음 절에서 순위합의 분산을 구할 때 이 공분산이 유한 모집단 수정의 꼴로 나타난다.

예제 7.1.1

\(N = 4\)개의 관측값 가운데 정해 둔 두 개(예를 들어 처리군)의 순위합 \(W\)의 분포를 모두 세어 구하고, 평균과 분산을 확인하여라.

풀이. 두 순위의 집합은 \(\binom42 = 6\)가지가 같은 확률이다. 그러므로 각 집합의 합은 {1,2}=3, {1,3}=4, {1,4}=5, {2,3}=5, {2,4}=6, {3,4}=7이므로, 분포는 3, 4, 6, 7이 각각 1/6, 5가 2/6이다. 평균은 \(30/6 = 5\)이고 \(E(W^2) = (9 + 16 + 50 + 36 + 49)/6 = 160/6\)이므로 분산은 \(160/6 - 25 = 5/3\)이다. 정리로 계산해도 평균 \(2 \times 2.5 = 5\), 분산 \(2 \times \frac{15}{12} + 2 \times\big(-\frac{5}{12}\big) = \frac53\)으로 일치한다.

주의정리 7.1.1은 연속분포를 가정한다. 자료에 같은 값(동점)이 있으면 순위를 하나로 정할 수 없어 순열이 같은 확률이 아니게 된다. 보통 동점에 평균 순위를 주고, 분산 공식을 동점 보정한 값으로 바꾸거나 순열 분포를 직접 계산한다(응통12 4단원).
마무리

같은 연속분포에서 뽑은 독립 표본의 순위 벡터는 \(N!\)가지 순열 위에서 균일하다. 각 순위의 평균은 \((N+1)/2\), 분산은 \((N^2-1)/12\)이고, 서로 다른 순위의 공분산은 \(-(N+1)/12\)이다. 그래서 순위로 만든 통계량의 분포는 \(N\)만으로 정해지고 모집단 분포와 무관하다.

7.1.3연습문제

기본

  1. \(N = 10\)이면 \(R_1\)의 평균과 분산은 얼마인가?
    답

    평균은 5.5, 분산은 \(99/12 = 8.25\)이다.

응용

  1. \(N = 10\)에서 정해 둔 5개의 순위합 \(W\)의 평균과 분산을 정리 7.1.2로 구하고, 그림 1과 비교하여라.
    답

    평균은 \(5 \times 5.5 = 27.5\)이다. 분산은 \(5 \times 8.25 + 20 \times(-11/12) = 41.25 - 18.33 = 22.9\)로 그림 1의 정규 근사와 같다.
