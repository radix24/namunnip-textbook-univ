지수분포 비율의 UMVUE: 맞추기로 찾기

예제 · 레만-셰페 정리

먼저 읽는 법

완비 충분통계량 \(T\)를 찾고, \(T\)의 분포로 후보 \(g(T)\)의 기대값을 계산해 원하는 모수가 나오도록 상수를 고칩니다. MLE가 \(T\)의 함수라면 MLE의 기대값을 구해 치우침을 없애는 것이 가장 빠른 길입니다.

문제. \(X_1, \ldots, X_n\) (\(n \ge 3\))이 \(\mathrm{Exp}(\lambda)\)(밀도 \(\lambda e^{-\lambda x}\))에서 뽑은 표본입니다. \(T = \sum X_i\)가 완비 충분통계량일 때 \(\lambda\)의 UMVUE와 그 분산을 구하고, MLE \(\hat\lambda = n/T\)와 MSE를 비교하세요.

풀이

  1. \(T \sim \mathrm{Gamma}(n, 1/\lambda)\)이므로 \(E(1/T) = \int_0^\infty \frac1t\cdot\frac{\lambda^n t^{n-1}e^{-\lambda t}}{\Gamma(n)}dt = \frac{\lambda\Gamma(n-1)}{\Gamma(n)} = \frac{\lambda}{n-1}\).
    감마 적분에서 지수를 하나 내리면 \(\Gamma(n-1)\lambda^{-(n-1)}\)이 나옵니다(응통6 4.3절).
  2. \(E(\hat\lambda) = \frac{n\lambda}{n-1}\)로 치우쳐 있습니다. \(\tilde\lambda = \frac{n-1}{T}\)이면 \(E(\tilde\lambda) = \lambda\).
    \(T\)의 함수이면서 불편이므로 레만-셰페로 UMVUE입니다.
  3. 같은 방법으로 \(E(1/T^2) = \frac{\lambda^2}{(n-1)(n-2)}\). \(\mathrm{Var}(\tilde\lambda) = (n-1)^2\frac{\lambda^2}{(n-1)(n-2)} - \lambda^2 = \frac{\lambda^2}{n-2}\).
    \(n \ge 3\)이어야 이 적률이 유한합니다.
  4. MLE: 분산 \(\frac{n^2}{(n-1)^2}\cdot\frac{\lambda^2}{n-2}\), 치우침 \(\frac{\lambda}{n-1}\). MSE \(= \frac{\lambda^2(n+2)}{(n-1)(n-2)}\)로 UMVUE의 MSE \(\frac{\lambda^2}{n-2}\)보다 \(\frac{n+2}{n-1}\)배 큽니다.
    \(\frac{n^2}{(n-1)^2(n-2)} + \frac{1}{(n-1)^2} = \frac{n^2 + n - 2}{(n-1)^2(n-2)} = \frac{n+2}{(n-1)(n-2)}\).

검산

\(n = 5\), \(\lambda = 0.4\)이면 MLE의 평균은 \(0.5\)로, 3.3절 실습 카드의 모의실험 값과 맞습니다. UMVUE \(4/T\)의 표준편차는 \(0.4/\sqrt3 \approx 0.231\), MLE의 MSE는 \(0.16 \times 7/12 \approx 0.093\)(제곱근 0.306)입니다.

의미

이 예에서는 UMVUE가 MLE보다 MSE까지 작습니다. 그러나 \(\frac{n-2}{T}\)처럼 조금 더 줄인 추정량은 치우쳤지만 MSE가 \(\frac{\lambda^2}{n-1}\)로 더 작습니다. 불편추정량 가운데 최선과 모든 추정량 가운데 MSE가 최선은 다를 수 있습니다(1.3절의 맞교환).
