점수함수와 피셔 정보량

본문
이 절에서 배울 것
  • 점수함수를 정의하고 그 평균이 0임을 보인다.
  • 피셔 정보량을 두 가지 식으로 계산한다.
  • 정보량을 로그가능도의 곡률로 해석하고, 모수 변환에 따라 어떻게 바뀌는지 안다.
먼저 알아야 할 것
  • 최대가능도추정량 (1.2절), 공분산 (응통6 5.2절).

자료에 정보가 얼마나 들어 있나

동전을 10번 던진 자료와 1000번 던진 자료는 \(p\)에 대해 담은 정보의 양이 다릅니다. 같은 10번이라도 \(p\)가 0.5 근처일 때와 0.01 근처일 때 추정의 어려움이 다릅니다. 이 "정보의 양"을 수로 나타낸 것이 피셔 정보량이며, 다음 절에서 어떤 불편추정량도 넘을 수 없는 분산의 하한을 정합니다.

3.1.1점수함수

정의 3.1.1

점수함수: \(U(\theta) = \dfrac{\partial}{\partial\theta}\log f(X;\theta)\). 표본 \(n\)개이면 \(U_n(\theta) = \sum_i \frac{\partial}{\partial\theta}\log f(X_i;\theta) = \ell'(\theta)\).

점수는 "모수를 조금 바꾸면 로그가능도가 얼마나 변하는가"입니다. MLE는 점수가 0이 되는 점입니다(가능도방정식). 미분과 적분의 순서를 바꿀 수 있는 정칙 조건(특히 \(X\)가 값을 가지는 영역이 \(\theta\)에 의존하지 않음) 아래에서

\[E[U(\theta)] = \int\frac{\partial f/\partial\theta}{f}f\,dx = \frac{\partial}{\partial\theta}\int f\,dx = \frac{\partial}{\partial\theta}1 = 0.\]

참값에서 점수의 평균이 0이라는 것은, 평균적으로 로그가능도가 참값에서 평평(최대)하다는 뜻입니다.

3.1.2피셔 정보량

정의 3.1.2

피셔 정보량: \(I(\theta) = E[U(\theta)^2] = \mathrm{Var}[U(\theta)]\). 정칙 조건 아래에서 \(I(\theta) = -E\left[\dfrac{\partial^2}{\partial\theta^2}\log f(X;\theta)\right]\).

\(\int \frac{\partial \log f}{\partial\theta}f\,dx = 0\)을 한 번 더 미분하면 \(\int\left[\frac{\partial^2\log f}{\partial\theta^2}f + \frac{\partial\log f}{\partial\theta}\frac{\partial f}{\partial\theta}\right]dx = 0\). 둘째 항은 \(\int\left(\frac{\partial\log f}{\partial\theta}\right)^2 f\,dx = E(U^2)\)이므로 \(E(U^2) = -E[\partial^2\log f/\partial\theta^2]\). ∎

둘째 식은 로그가능도의 곡률입니다. 로그가능도가 참값 근처에서 뾰족할수록 자료가 \(\theta\)를 정확히 가리키므로 정보가 많습니다. 독립 표본 \(n\)개의 정보량은 \(nI(\theta)\)로 더해집니다(독립인 점수의 분산이 더해짐). 실제 자료에서 계산한 곡률 \(-\ell''(\hat\theta)\)를 관측 정보량이라 부르며, 소프트웨어가 표준오차를 낼 때 흔히 이것을 씁니다.

예제 3.1.3

베르누이 \(p\)와 정규 \(N(\mu, \sigma^2)\)(\(\sigma\) 알려짐)의 정보량을 구하세요.

풀이. 베르누이: \(\log f = x\log p + (1-x)\log(1-p)\), \(\partial^2/\partial p^2 = -x/p^2 - (1-x)/(1-p)^2\). 기대값을 취하면 \(I(p) = \frac1p + \frac1{1-p} = \frac{1}{p(1-p)}\). \(p\)가 0이나 1에 가까울수록 정보량이 큽니다. 정규: \(\log f = -\frac{(x-\mu)^2}{2\sigma^2} + c\), \(\partial^2/\partial\mu^2 = -1/\sigma^2\), \(I(\mu) = 1/\sigma^2\). 잡음이 작을수록 정보가 많습니다.

3.1.3모수 변환과 정보량

모수를 \(\eta = g(\theta)\)로 바꾸면 연쇄법칙으로 점수가 \(\frac{\partial\log f}{\partial\eta} = \frac{\partial\log f}{\partial\theta}\cdot\frac{d\theta}{d\eta}\)이므로 \(I(\eta) = I(\theta)\left(\frac{d\theta}{d\eta}\right)^2\)입니다. 정보량은 모수의 "눈금"에 따라 달라집니다. 예를 들어 베르누이의 로짓 \(\eta = \log\frac{p}{1-p}\)에서는 \(d p/d\eta = p(1-p)\)이므로 \(I(\eta) = p(1-p)\)입니다. 로지스틱 회귀(응통18 03단원)의 표준오차 식이 이 형태입니다.

요약
  1. 점수 \(U = \partial\log f/\partial\theta\), 정칙 조건 아래 평균 0.
  2. \(I(\theta) = E[U^2] = -E[\partial^2\log f/\partial\theta^2]\), 표본은 \(nI\).
  3. 정보량은 로그가능도의 곡률이고, 모수 변환 시 \((d\theta/d\eta)^2\)배.

3.1.4연습문제

기본

  1. 포아송 \(\lambda\)의 정보량을 구하세요.
    답

    \(\log f = -\lambda + x\log\lambda - \log x!\), \(\partial^2/\partial\lambda^2 = -x/\lambda^2\), \(I = E(X)/\lambda^2 = 1/\lambda\).

응용

  1. 지수분포를 비율 \(\lambda\)로 쓸 때와 평균 \(\mu = 1/\lambda\)로 쓸 때의 정보량을 비교하세요.
    답

    \(\log f = \log\lambda - \lambda x\), \(I(\lambda) = 1/\lambda^2\). 변환 공식으로 \(I(\mu) = I(\lambda)(d\lambda/d\mu)^2 = \mu^2 \cdot \mu^{-4} = 1/\mu^2\). 직접 계산(\(\log f = -\log\mu - x/\mu\))해도 같습니다.
