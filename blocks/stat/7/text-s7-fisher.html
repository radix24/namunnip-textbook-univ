점수함수와 피셔 정보량

본문

동전을 10번 던진 자료와 100번 던진 자료는 앞면 확률 \(p\)에 대해 담은 정보의 양이 다르다. 같은 10번이라도 \(p\)가 0.5 근처일 때와 0.01 근처일 때 추정의 어려움이 다르다. 자료에 모수에 대한 정보가 얼마나 들어 있는지를 하나의 수로 잴 수 있을까?

먼저 알아야 할 것최대가능도추정량(1.2절)과 공분산(응통6 5.2절)을 쓴다.

처음 질문의 "정보의 양"을 수로 나타낸 것이 피셔 정보량이다. 다음 절에서 이 양이 어떤 불편추정량도 넘을 수 없는 분산의 하한을 정한다.

3.1.1점수함수

정의 3.1.1 (점수함수)

\(U(\theta) = \dfrac{\partial}{\partial\theta}\log f(X;\theta)\)를 점수함수라 한다. 표본이 \(n\)개이면 \(U_n(\theta) = \sum_i \frac{\partial}{\partial\theta}\log f(X_i;\theta) = \ell'(\theta)\)이다.

점수는 모수를 조금 바꾸면 로그가능도가 얼마나 변하는지를 잰다. MLE는 점수가 0이 되는 점이다(가능도방정식). 미분과 적분의 순서를 바꿀 수 있는 정칙 조건(특히 \(X\)가 값을 가지는 영역이 \(\theta\)에 의존하지 않음) 아래에서 다음이 성립한다.

\[E[U(\theta)] = \int\frac{\partial f/\partial\theta}{f}f\,dx = \frac{\partial}{\partial\theta}\int f\,dx = \frac{\partial}{\partial\theta}1 = 0\]

즉 참값에서 점수의 평균이 0이라는 것은, 평균적으로 로그가능도가 참값에서 평평하다(최대이다)는 뜻이다.

3.1.2피셔 정보량

정의 3.1.2 (피셔 정보량)

\(I(\theta) = E[U(\theta)^2] = \mathrm{Var}[U(\theta)]\)를 피셔 정보량이라 한다. 정칙 조건 아래에서 \(I(\theta) = -E\left[\dfrac{\partial^2}{\partial\theta^2}\log f(X;\theta)\right]\)이다.

증명. \(\int \frac{\partial \log f}{\partial\theta}f\,dx = 0\)을 한 번 더 미분하면 \(\int\big[\frac{\partial^2\log f}{\partial\theta^2}f + \frac{\partial\log f}{\partial\theta}\frac{\partial f}{\partial\theta}\big]dx = 0\)이다. 둘째 항은 \(\int\big(\frac{\partial\log f}{\partial\theta}\big)^2 f\,dx = E(U^2)\)이므로 \(E(U^2) = -E[\partial^2\log f/\partial\theta^2]\)이다. ∎

둘째 식이 처음 질문의 답을 그림으로 보여 준다. 그것은 로그가능도의 곡률이며, 로그가능도가 참값 근처에서 뾰족할수록 자료가 \(\theta\)를 정확히 가리키므로 정보가 많다(그림 1). 독립 표본 \(n\)개의 정보량은 독립인 점수의 분산이 더해지므로 \(nI(\theta)\)이다. 한편 실제 자료에서 계산한 곡률 \(-\ell''(\hat\theta)\)를 관측 정보량이라 부르며, 소프트웨어가 표준오차를 낼 때 흔히 이것을 쓴다.

예제 3.1.1

베르누이 \(p\)와 정규 \(N(\mu, \sigma^2)\)(\(\sigma\) 알려짐)의 정보량을 구하여라.

풀이. 베르누이에서 \(\log f = x\log p + (1-x)\log(1-p)\)이므로 \(\partial^2/\partial p^2 = -x/p^2 - (1-x)/(1-p)^2\)이다. 기대값을 취하면 \(I(p) = \frac1p + \frac1{1-p} = \frac{1}{p(1-p)}\)이므로, \(p\)가 0이나 1에 가까울수록 정보량이 크다. 정규에서는 \(\log f = -\frac{(x-\mu)^2}{2\sigma^2} + c\)이므로 \(\partial^2/\partial\mu^2 = -1/\sigma^2\), 곧 \(I(\mu) = 1/\sigma^2\)이다. 잡음이 작을수록 정보가 많다.

3.1.3모수 변환과 정보량

모수를 \(\eta = g(\theta)\)로 바꾸면 연쇄법칙으로 점수가 \(\frac{\partial\log f}{\partial\eta} = \frac{\partial\log f}{\partial\theta}\cdot\frac{d\theta}{d\eta}\)이므로 \(I(\eta) = I(\theta)\big(\frac{d\theta}{d\eta}\big)^2\)이다. 즉 정보량은 모수의 눈금에 따라 달라진다. 예를 들어 베르누이의 로짓 \(\eta = \log\frac{p}{1-p}\)에서는 \(dp/d\eta = p(1-p)\)이므로 \(I(\eta) = p(1-p)\)이며, 로지스틱 회귀(응통18 3단원)의 표준오차 식이 이 꼴이다.

주의정보량은 모수의 성질이 아니라 "어떤 눈금으로 잰 모수"의 성질이다. 그래서 \(p\)의 눈금에서는 \(p\)가 0 근처일 때 정보량이 크지만, 로짓의 눈금에서는 오히려 작다. 정보량을 비교할 때는 같은 모수화인지 먼저 확인하자.
마무리

점수 \(U = \partial\log f/\partial\theta\)는 정칙 조건 아래 평균이 0이다. 피셔 정보량 \(I(\theta) = E[U^2] = -E[\partial^2\log f/\partial\theta^2]\)는 로그가능도의 곡률이며, 표본 \(n\)개이면 \(nI\)로 더해진다. 모수를 \(\eta\)로 바꾸면 정보량은 \((d\theta/d\eta)^2\)배가 된다.

3.1.4연습문제

기본

  1. 포아송 \(\lambda\)의 정보량을 구하여라.
    답

    \(\log f = -\lambda + x\log\lambda - \log x!\)이므로 \(\partial^2/\partial\lambda^2 = -x/\lambda^2\)이고, \(I = E(X)/\lambda^2 = 1/\lambda\)이다.

응용

  1. 지수분포를 비율 \(\lambda\)로 쓸 때와 평균 \(\mu = 1/\lambda\)로 쓸 때의 정보량을 비교하여라.
    답

    \(\log f = \log\lambda - \lambda x\)이므로 \(I(\lambda) = 1/\lambda^2\)이다. 변환 공식으로 \(I(\mu) = I(\lambda)(d\lambda/d\mu)^2 = \mu^2 \cdot \mu^{-4} = 1/\mu^2\)이며, \(\log f = -\log\mu - x/\mu\)로 직접 계산해도 같다.
