가능도함수와 최대가능도추정량

본문

동전을 10번 던져 앞면이 7번 나왔다. 앞면이 나올 확률 \(p\)는 얼마로 보는 것이 자연스러울까? \(p = 0.5\)라면 이런 결과가 나올 확률은 \(\binom{10}7 0.5^{10} \approx 0.117\)이고, \(p = 0.7\)이라면 \(\binom{10}7 0.7^7 0.3^3 \approx 0.267\)이다. 관측된 자료를 가장 그럴듯하게 만드는 모수를 고르는 규칙을 일반적으로 세울 수 있을까?

먼저 알아야 할 것추정량(1.1절)과 편미분(응통1 5단원)을 쓴다.

처음 질문의 생각, 곧 관측된 자료를 가장 그럴듯하게 만드는 모수를 고르자는 것이 최대가능도법이며, 현대 통계학에서 가장 널리 쓰는 추정 방법이다.

1.2.1가능도함수

정의 1.2.1 (가능도함수와 최대가능도추정량)

독립 표본 \(x_1, \ldots, x_n\)에 대해 \(L(\theta) = \prod_{i=1}^n f(x_i; \theta)\)를 가능도함수라 한다. 자료를 고정하고 모수의 함수로 본 결합 밀도(또는 질량)이다. \(L(\theta)\)를 가장 크게 하는 \(\hat\theta\)를 최대가능도추정량(MLE)이라 한다.

가능도는 \(\theta\)에 대한 확률분포가 아니다. 예를 들어 그림 1의 곡선을 \(p\)로 적분해도 1이 되지 않는다. 또 곱보다 합이 미분하기 쉬우므로 보통 로그가능도 \(\ell(\theta) = \sum\log f(x_i;\theta)\)를 최대화하며, 로그는 증가함수라 최대점이 같다. 즉 가능도방정식 \(\ell'(\theta) = 0\)을 풀고 \(\ell''(\theta) < 0\)으로 최대임을 확인한다.

예제 1.2.1

(가) 지수분포 \(f(x;\lambda) = \lambda e^{-\lambda x}\)의 MLE를 구하여라. (나) \(N(\mu, \sigma^2)\)의 두 모수의 MLE를 구하여라.

풀이. (가) \(\ell(\lambda) = n\log\lambda - \lambda\sum x_i\)이므로 \(\ell'(\lambda) = n/\lambda - \sum x_i = 0\)에서 \(\hat\lambda = 1/\bar x\)이고, \(\ell''(\lambda) = -n/\lambda^2 < 0\)이므로 최대이다. (나) \(\ell = -\frac n2\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(x_i - \mu)^2\)이다. \(\partial\ell/\partial\mu = 0\)에서 \(\hat\mu = \bar x\)이고, \(\partial\ell/\partial\sigma^2 = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum(x_i - \mu)^2 = 0\)에서 \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\)이다. \(n-1\)이 아니라 \(n\)으로 나눈다는 점에 주의하자(1.3절).

1.2.2미분으로 풀 수 없을 때

가능도방정식이 늘 답을 주지는 않는다. 먼저 모수가 값의 범위를 정할 때가 있다. \(U(0, \theta)\)에서 \(L(\theta) = \theta^{-n}\)(모든 \(x_i \le \theta\)일 때)이고 그 밖에서는 0이다. 이 함수는 \(\theta \ge x_{(n)}\)에서 줄어들므로 \(\hat\theta = x_{(n)}\)(최댓값)이며, 미분이 0인 점은 없다. 다음으로 최대가 경계에 올 수 있다. 성공이 0번이면 베르누이의 MLE는 모수 공간의 경계인 \(\hat p = 0\)이다.

또 닫힌 식이 없을 때도 많다. 감마분포의 \(\alpha\)나 로지스틱 회귀 계수는 뉴턴 방법 같은 수치 최적화로 푼다(응통15 3단원). 어느 경우든 그림 1처럼 가능도의 그래프를 그려 보는 습관이 가장 안전하며, 극대가 여러 개이거나 곡선이 평평한 경우도 그림에서 드러난다.

1.2.3불변성

정리 1.2.2 (MLE의 불변성)

\(\hat\theta\)가 \(\theta\)의 MLE이면, 함수 \(g(\theta)\)의 MLE는 \(g(\hat\theta)\)이다.

증명. \(g\)가 일대일이면 \(\eta = g(\theta)\)로 다시 쓴 가능도 \(L^*(\eta) = L(g^{-1}(\eta))\)는 \(\eta = g(\hat\theta)\)에서 최대이다. 일대일이 아니면 \(L^*(\eta) = \sup_{\theta: g(\theta) = \eta}L(\theta)\)(유도 가능도)로 정의하면 같은 결론이 나온다. ∎

그래서 정규분포 표준편차의 MLE는 \(\sqrt{\hat\sigma^2}\), 지수분포 평균 \(1/\lambda\)의 MLE는 \(\bar x\), 포아송의 \(P(X = 0) = e^{-\lambda}\)의 MLE는 \(e^{-\bar x}\)이다. 적률법이나 불편추정량(1.3절)에는 이런 성질이 일반적으로 없다. 예를 들어 \(S^2\)은 불편이지만 \(S\)는 불편이 아니다.

마무리

가능도함수 \(L(\theta) = \prod f(x_i;\theta)\)는 자료를 고정하고 모수의 함수로 본 확률이며, 이를 가장 크게 하는 값이 최대가능도추정량이다. 보통 로그가능도를 미분해 0으로 놓고 풀지만, 범위가 모수에 달린 경우나 경계, 닫힌 식이 없는 경우는 그래프와 수치 방법으로 찾는다. MLE는 변환에 불변이어서 \(g(\theta)\)의 MLE는 \(g(\hat\theta)\)이다.

1.2.4연습문제

기본

  1. 베르누이 시행 \(n\)번 가운데 \(k\)번 성공일 때 \(p\)의 MLE는 무엇인가?
    답

    \(\ell = k\log p + (n-k)\log(1-p)\)이므로 \(\ell' = k/p - (n-k)/(1-p) = 0\)에서 \(\hat p = k/n\)이다.

  2. 포아송 \(\lambda\)의 MLE와 \(P(X = 0) = e^{-\lambda}\)의 MLE는 무엇인가?
    답

    \(\ell = -n\lambda + \sum x_i\log\lambda + c\)이므로 \(\hat\lambda = \bar x\)이고, 불변성으로 \(e^{-\bar x}\)이다.

응용

  1. \(U(\theta, \theta + 1)\)의 MLE를 구하여라. 유일한가?
    답

    \(\theta \le x_{(1)}\)이고 \(x_{(n)} \le \theta + 1\)일 때 \(L(\theta) = 1\)이다. 구간 \([x_{(n)} - 1, x_{(1)}]\)의 모든 값이 최대이므로 MLE가 유일하지 않다.
