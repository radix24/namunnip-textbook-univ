윌크스 정리와 우도비 구간

본문
이 절에서 배울 것
  • \(-2\log\Lambda\)가 근사적으로 카이제곱을 따르는 이유를 2차 전개로 설명한다.
  • 자유도를 "제약의 수"로 정하고 우도비 검정을 수행한다.
  • 우도비 검정을 뒤집어 우도비 신뢰구간을 만든다.
먼저 알아야 할 것
  • 우도비 통계량 (6.1절), MLE의 점근 정규성 (3.3절).

분포를 모를 때의 기각값

포아송 평균, 로지스틱 회귀의 계수, 분할표의 여러 확률처럼 우도비 통계량의 정확한 분포를 구할 수 없는 경우가 대부분입니다. 윌크스는 표본이 크면 \(-2\log\Lambda\)가 모형과 관계없이 카이제곱 분포에 가까워진다는 것을 보였습니다. 자유도만 세면 되므로 거의 모든 모형에서 같은 방식으로 검정할 수 있습니다.

6.2.1윌크스 정리

정리 6.2.1 (윌크스)

정칙 조건 아래, \(H_0\)가 참이면 \(-2\log\Lambda \xrightarrow D \chi^2_r\). \(r\)은 \(H_0\)가 고정하는 모수의 수(전체 모수 차원 − \(H_0\) 아래 모수 차원).

일모수에서 이유를 봅니다. \(\theta_0\)를 \(\hat\theta\) 둘레에서 2차 전개하면 \(\ell(\theta_0) \approx \ell(\hat\theta) + \ell'(\hat\theta)(\theta_0 - \hat\theta) + \frac12\ell''(\hat\theta)(\theta_0 - \hat\theta)^2\)이고, \(\ell'(\hat\theta) = 0\), \(-\ell''(\hat\theta) \approx nI(\theta_0)\)이므로

\[-2\log\Lambda = 2[\ell(\hat\theta) - \ell(\theta_0)] \approx nI(\theta_0)(\hat\theta - \theta_0)^2.\]

3.3절에서 \(\sqrt{nI}(\hat\theta - \theta_0) \approx N(0,1)\)이므로 그 제곱은 \(\chi^2_1\)입니다. 모수가 여럿이면 같은 2차 전개가 이차형식이 되고, \(H_0\)가 고정하는 방향의 수만큼 독립인 표준정규 제곱이 남아 \(\chi^2_r\)이 됩니다.

주의 \(H_0\)의 값이 모수 공간의 경계에 있으면(예: 분산 성분이 0, 혼합 비율이 0) 정칙 조건이 깨져 극한이 \(\chi^2\)가 아닙니다(예: \(\frac12\chi^2_0 + \frac12\chi^2_1\)). 이 경우 윌크스 근사를 그대로 쓰면 보수적인 검정이 됩니다.
예제 6.2.2

포아송 표본 \(n = 20\), \(\sum x_i = 52\)로 \(H_0: \lambda = 2\)를 우도비 검정하세요.

풀이. \(\hat\lambda = 2.6\). \(\ell(\lambda) = -n\lambda + \sum x_i\log\lambda + c\). \(-2\log\Lambda = 2[(-52 + 52\log 2.6) - (-40 + 52\log 2)] = 2[-12 + 52\log 1.3] = 2[-12 + 13.643] = 3.286\). \(\chi^2_1\)의 95%점 3.84보다 작으므로 \(\alpha = 0.05\)에서 기각하지 않습니다(p값 약 0.070).

6.2.2우도비 신뢰구간

5.4절의 쌍대성으로 우도비 검정을 뒤집으면 \(\{\theta_0 : 2[\ell(\hat\theta) - \ell(\theta_0)] \le \chi^2_{r,\alpha}\}\)가 근사 \(1 - \alpha\) 신뢰집합입니다. 일모수이면 로그가능도 곡선이 최댓값에서 \(\chi^2_{1, 0.05}/2 = 1.92\)만큼 내려간 곳까지가 95% 구간입니다. 이 구간은 모수의 눈금을 바꿔도 같은 구간으로 옮겨지고(불변), 비대칭인 가능도를 그대로 반영해 작은 표본에서 왈드 구간보다 정확합니다. 로지스틱 회귀에서 R의 confint(fit)가 주는 "프로파일 가능도 구간"이 이것입니다.

요약
  1. \(-2\log\Lambda \approx \chi^2_r\), \(r\) = 제약의 수.
  2. 근거는 로그가능도의 2차 전개와 MLE의 점근 정규성입니다.
  3. 로그가능도가 1.92 내려가는 범위가 95% 우도비 구간이며, 변환에 불변입니다.

6.2.3연습문제

기본

  1. 베르누이 \(n = 100\), 앞면 60에서 \(H_0: p = 0.5\)의 \(-2\log\Lambda\)는?
    답

    \(2[60\log1.2 + 40\log0.8] = 2[10.939 - 8.926] = 4.03\). 3.84보다 커서 기각.

  2. 세 집단의 포아송 평균이 같은지 검정할 때 윌크스 근사의 자유도는?
    답

    전체 모수 3개, \(H_0\) 아래 1개(공통 평균). 자유도 2.

응용

  1. 예제 6.2.2의 자료로 \(\lambda\)의 95% 우도비 구간 경계가 만족하는 방정식을 쓰고, 왈드 구간 \(2.6 \pm 1.96\sqrt{2.6/20}\)과 비교하세요.
    답

    \(2[(-52 + 52\log2.6) - (-20\lambda + 52\log\lambda)] = 3.84\). 수치로 풀면 약 [1.95, 3.37]. 왈드 구간 [1.89, 3.31]보다 오른쪽으로 치우쳐 있습니다(포아송 가능도가 오른쪽으로 긴 꼬리).
