  • 우도비 검정 (6.1절), 피셔 정보량 (3.1절).

로그가능도 곡선을 보는 세 가지 방법

\(H_0: \theta = \theta_0\)를 검정할 때 로그가능도 곡선 \(\ell(\theta)\) 위에서 세 가지를 잴 수 있습니다. 꼭짓점 \(\hat\theta\)과 \(\theta_0\)의 가로 거리(왈드), \(\theta_0\)에서의 기울기(점수), 두 점의 높이 차이(우도비)입니다.

6.2.1세 통계량

결과 6.2.1

\(H_0\) 아래에서 다음 셋은 모두 근사적으로 \(\chi^2_1\)을 따른다.

  • 왈드: \(W = (\hat\theta - \theta_0)^2\,nI(\hat\theta)\).
  • 점수(라오): \(S = \dfrac{[\ell'(\theta_0)]^2}{nI(\theta_0)}\).
  • 우도비: \(LR = 2[\ell(\hat\theta) - \ell(\theta_0)]\).

로그가능도가 정확히 이차식(정규 평균)이면 셋은 같습니다. 일반적으로는 큰 표본에서 서로 가까워지고, 작은 표본에서는 다를 수 있습니다.

6.2.2장단점

계산에 필요한 것특징
왈드\(\hat\theta\)만모수 변환에 따라 값이 바뀜. 소프트웨어 계수표의 z 값
점수\(\theta_0\)만제약 없는 MLE를 구하지 않아도 됨. 비율의 점수 검정이 윌슨 구간
우도비둘 다변환에 불변. 작은 표본에서 대체로 가장 정확
예제 6.2.2

6.1절 포아송 예(\(n = 20\), \(\bar x = 2.6\), \(\theta_0 = 2\))에서 세 통계량을 구하세요.

풀이. \(I(\lambda) = 1/\lambda\). 왈드 \(W = 0.6^2 \times 20/2.6 = 2.769\). 점수: \(\ell'(2) = -20 + 52/2 = 6\), \(S = 36/(20/2) = 3.6\). 우도비 \(LR = 3.286\). 셋 모두 3.84보다 작지만 값이 꽤 다릅니다(p값 0.096, 0.058, 0.070).

요약
  1. 왈드는 \(\hat\theta\)에서, 점수는 \(\theta_0\)에서, 우도비는 둘을 함께 씁니다.
  2. 모두 근사 \(\chi^2_r\), 큰 표본에서 같아집니다.
  3. 작은 표본이나 경계 근처에서는 우도비나 점수 검정을 권합니다.

6.2.3연습문제

기본

  1. 베르누이 \(n = 100\), 앞면 60, \(H_0: p = 0.5\)에서 왈드와 점수 통계량은?
    답

    \(W = 0.01 \times 100/(0.6 \times 0.4) = 4.17\). \(S = 0.01 \times 100/(0.25) = 4.0\). 우도비는 4.03(6.1절).
