충분통계량과 최적 추정 단원 마무리 연습

문제 6 · 증명·판단·계산 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 증명\(X_1, \ldots, X_n\)이 서로 독립인 \(\mathrm{Bernoulli}(p)\)일 때 \(T = \sum X_i\)가 \(p\)의 충분통계량임을 분해 정리로 보이세요. [02-01]

    힌트 1

    결합 확률질량함수 \(\prod p^{x_i}(1-p)^{1-x_i}\)를 정리해 보세요.

    힌트 2

    분해 정리: \(f(\mathbf x; p) = g(T(\mathbf x); p)\,h(\mathbf x)\) 꼴이면 \(T\)가 충분합니다.

    풀이

    \(f(\mathbf x; p) = p^{\sum x_i}(1-p)^{n - \sum x_i}\)이므로 \(g(t; p) = p^t(1-p)^{n-t}\), \(h(\mathbf x) = 1\)로 두면 분해됩니다. 따라서 \(T = \sum X_i\)는 충분통계량입니다.

    뜻: 성공 횟수만 알면, 어떤 순서로 성공했는지는 \(p\)에 대해 더 알려 주는 것이 없습니다. 실제로 \(T = t\)가 주어지면 각 순서의 조건부확률은 \(1/\binom nt\)로 \(p\)와 무관합니다.

  2. 증명\(U(0, \theta)\) 표본에서 \(X_{(n)} = \max X_i\)가 \(\theta\)의 충분통계량임을 보이세요. 지시함수를 써서 가능도를 정확히 쓰는 것이 핵심입니다. [02-01]

    힌트 1

    \(f(x; \theta) = \frac1\theta I(0 < x < \theta)\)입니다.

    힌트 2

    모든 \(x_i < \theta\)는 \(\max x_i < \theta\)와 같습니다.

    풀이

    \(f(\mathbf x; \theta) = \theta^{-n}\prod I(0 < x_i < \theta) = \theta^{-n}I(x_{(n)} < \theta)\cdot I(x_{(1)} > 0)\)입니다. \(g(t; \theta) = \theta^{-n}I(t < \theta)\), \(h(\mathbf x) = I(x_{(1)} > 0)\)으로 분해되므로 \(X_{(n)}\)은 충분통계량입니다.

    지지집합(값이 가능한 범위)이 \(\theta\)에 따라 바뀌는 분포에서는 지시함수를 빠뜨리면 틀린 결론에 이릅니다.

  3. 판단\(U(0, \theta)\)에서 표본평균 \(\bar X\)는 \(\theta\)의 충분통계량인가요? 두 표본 \((0.1, 0.1, 2.8)\)과 \((1.0, 1.0, 1.0)\)으로 생각해 보세요. [02-01]

    힌트 1

    두 표본의 평균은 같습니다. 그런데 \(\theta\)에 대해 같은 정보를 주나요?

    힌트 2

    첫 표본은 \(\theta \ge 2.8\)을 알려 줍니다.

    풀이

    충분하지 않습니다. 두 표본 모두 평균이 1이지만, 첫 표본은 \(\theta \ge 2.8\)임을, 둘째는 \(\theta \ge 1\)임을 알려 주어 가능도 함수가 다릅니다(\(\theta \in [1, 2.8)\)에서 첫 표본의 가능도는 0). 평균만으로는 이 정보를 잃습니다. 앞 단원에서 \(2\bar X\)가 최댓값 기반 추정량보다 나빴던 까닭입니다.

  4. 증명포아송 표본에서 \(P(X = 0) = e^{-\lambda}\)를 추정하려 합니다. \(W = I(X_1 = 0)\)은 불편입니다. 충분통계량 \(T = \sum X_i\)로 조건부 기댓값을 취해 라오-블랙웰 개선 추정량을 구하세요. [02-02]

    힌트 1

    \(T = t\)가 주어지면 \(X_1 \mid T = t \sim B(t, 1/n)\)입니다.

    힌트 2

    \(E(W \mid T = t) = P(X_1 = 0 \mid T = t)\)입니다.

    풀이

    \(X_1 \mid T = t \sim B(t, 1/n)\)이므로 \(E(W \mid T = t) = (1 - 1/n)^t\)입니다. 따라서 개선 추정량은 \(\big(\frac{n-1}{n}\big)^{T}\)입니다.

    라오-블랙웰 정리에 따라 이 추정량도 불편이고 분산은 \(W\) 이하입니다. 포아송에서 \(T\)는 완비 충분통계량이므로 레만-셰페 정리에 따라 이것이 최소분산불편추정량입니다. 단순한 \(e^{-\bar X}\)는 일치추정량이지만 불편은 아닙니다.

  5. 계산포아송 분포 \(f(x; \lambda) = e^{-\lambda}\lambda^x/x!\)를 지수족 꼴 \(h(x)c(\lambda)\exp\{w(\lambda)t(x)\}\)로 쓰고, 완비 충분통계량과 \(\lambda\)의 최소분산불편추정량을 구하세요. [02-03]

    힌트 1

    \(\lambda^x = \exp(x\ln\lambda)\)입니다.

    힌트 2

    모수 공간이 열린 구간을 포함하는 지수족이면 \(\sum t(X_i)\)가 완비 충분통계량입니다.

    풀이

    \(f(x; \lambda) = \frac{1}{x!}e^{-\lambda}\exp\{x\ln\lambda\}\)이므로 \(h(x) = 1/x!\), \(c(\lambda) = e^{-\lambda}\), \(w(\lambda) = \ln\lambda\), \(t(x) = x\)입니다. 따라서 \(T = \sum X_i\)가 완비 충분통계량입니다.

    \(\bar X = T/n\)은 \(T\)의 함수이면서 불편이므로 레만-셰페 정리에 따라 \(\lambda\)의 최소분산불편추정량입니다.

  6. 계산\(U(0, \theta)\)에서 \(X_{(n)}\)이 완비 충분통계량임이 알려져 있습니다. \(\theta\)의 최소분산불편추정량을 구하고, 응통7-01-01의 자료(\(n = 5\), 최댓값 4.1)로 값을 계산하세요. [02-02]

    힌트 1

    \(E(X_{(n)}) = \frac{n}{n+1}\theta\)입니다.

    힌트 2

    완비 충분통계량의 함수이면서 불편인 추정량을 찾으면 됩니다.

    풀이

    \(\frac{n+1}{n}X_{(n)}\)이 불편이고 완비 충분통계량의 함수이므로 최소분산불편추정량입니다. 값은 \(\frac65\times4.1 = 4.92\)입니다. 적률추정값 5.0, 최대가능도추정값 4.1 사이에 있습니다.
