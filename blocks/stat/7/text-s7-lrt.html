일반화 우도비 검정

본문
이 절에서 배울 것
  • 제약 있는 MLE와 제약 없는 MLE로 우도비 통계량을 만든다.
  • 정규 평균의 우도비 검정이 t 검정과 같음을 보인다.
  • 복합 가설에서 우도비 검정의 기각값을 정하는 방법을 안다.
먼저 알아야 할 것
  • 최대가능도추정량 (1.2절), 네이만-피어슨 보조정리 (5.2절).

모든 상황에 쓸 수 있는 검정 만들기

균일최강력 검정은 일모수의 단측 가설처럼 특별한 경우에만 있습니다. 모수가 여럿이고 일부만 검정하거나(\(\sigma\)를 모른 채 \(\mu\) 검정), 양측 가설인 경우가 훨씬 많습니다. 일반적인 처방은 네이만-피어슨의 "가능도의 비"를 넓혀, "\(H_0\) 안에서 가장 그럴듯한 설명"과 "전체에서 가장 그럴듯한 설명"을 비교하는 것입니다.

6.1.1정의

정의 6.1.1

우도비 통계량: \(\Lambda = \dfrac{\sup_{\theta\in\Theta_0}L(\theta)}{\sup_{\theta \in \Theta}L(\theta)} = \dfrac{L(\hat\theta_0)}{L(\hat\theta)}\). \(0 \le \Lambda \le 1\)이고, 작으면 \(H_0\)를 기각한다. 크기 \(\alpha\)가 되도록 \(c\)를 정해 \(\Lambda \le c\)이면 기각한다.

\(\hat\theta_0\)는 \(H_0\) 제약 아래 MLE, \(\hat\theta\)는 제약 없는 MLE입니다. 분모가 분자보다 작을 수 없으므로 \(\Lambda \le 1\)이고, \(H_0\)가 자료를 거의 전체만큼 잘 설명하면 1에 가깝습니다. 단순 가설 대 단순 가설이면 네이만-피어슨 검정과 같은 꼴입니다.

6.1.2정확한 분포로 바꾸기

\(\Lambda\)가 분포를 아는 통계량의 단조함수이면 그 분포로 정확한 기각값을 정합니다.

예제 6.1.2

정규 \(N(\mu, \sigma^2)\)에서 \(H_0: \mu = \mu_0\) (\(\sigma\) 모름)의 우도비 검정이 t 검정과 같음을 보이세요.

풀이. 제약 없는 MLE \(\hat\mu = \bar x\), \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\). 제약 아래 \(\hat\sigma_0^2 = \frac1n\sum(x_i - \mu_0)^2 = \hat\sigma^2 + (\bar x - \mu_0)^2\). 정규 가능도의 최댓값은 \((2\pi\hat\sigma^2)^{-n/2}e^{-n/2}\) 꼴이므로 \(\Lambda = (\hat\sigma^2/\hat\sigma_0^2)^{n/2}\). 따라서 \(\Lambda^{-2/n} = 1 + \frac{(\bar x - \mu_0)^2}{\hat\sigma^2} = 1 + \frac{t^2}{n-1}\)이고(\(t = \frac{\bar x - \mu_0}{s/\sqrt n}\)), \(\Lambda\)가 작음 ⟺ \(|t|\)가 큼. 기각값은 \(t_{n-1}\) 분포로 정합니다.

같은 방식으로 일원 분산분석의 F 검정(응통5 5.1절), 두 정규 분산의 F 검정, 분할표의 독립성 검정도 우도비 검정에서 나옵니다. 정확한 분포를 알 수 없을 때는 다음 절의 윌크스 정리로 근사합니다.

예제 6.1.3

지수분포 \(\mathrm{Exp}(\lambda)\)에서 \(H_0: \lambda = \lambda_0\)의 우도비 통계량을 \(\bar x\)로 쓰고, 기각역의 모양을 말하세요.

풀이. \(\ell(\lambda) = n\log\lambda - \lambda n\bar x\), \(\hat\lambda = 1/\bar x\). \(\log\Lambda = n\log(\lambda_0\bar x) - n\lambda_0\bar x + n\). \(u = \lambda_0\bar x\)로 두면 \(\log\Lambda = n(\log u - u + 1)\)이고, 이 함수는 \(u = 1\)에서 최대(0)이며 양쪽으로 감소합니다. 따라서 \(\Lambda \le c\) ⟺ \(u \le c_1\) 또는 \(u \ge c_2\): 양측 기각역입니다. \(2n\lambda_0\bar X \sim \chi^2_{2n}\)으로 \(c_1, c_2\)를 정할 수 있지만, 양쪽 꼬리 확률을 같게 잡는 관례적 구간과는 조금 다릅니다.

요약
  1. \(\Lambda = L(\hat\theta_0)/L(\hat\theta)\), 작으면 기각.
  2. \(\Lambda\)가 분포를 아는 통계량의 단조함수이면 정확한 검정이 됩니다(t, F 검정).
  3. 정확한 분포가 없으면 윌크스 근사(6.2절)를 씁니다.

6.1.4연습문제

기본

  1. 베르누이 \(n\)번 중 \(k\)번 성공일 때 \(H_0: p = p_0\)의 \(\Lambda\)를 쓰세요.
    답

    \(\Lambda = \dfrac{p_0^k(1-p_0)^{n-k}}{\hat p^k(1-\hat p)^{n-k}}\), \(\hat p = k/n\).

응용

  1. 두 독립 정규 표본(분산 같음)에서 \(H_0: \mu_1 = \mu_2\)의 우도비 검정이 합동분산 t 검정과 같음을 보이는 흐름을 쓰세요.
    답

    제약 없는 MLE의 분산은 집단 안 제곱합/\(N\), 제약 아래는 전체 제곱합/\(N\). \(\Lambda^{-2/N} = \frac{\text{전체 SS}}{\text{집단 안 SS}} = 1 + \frac{\text{집단 간 SS}}{\text{집단 안 SS}} = 1 + \frac{t^2}{N-2}\). 따라서 \(|t|\)가 클 때 기각.
