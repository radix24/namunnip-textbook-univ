연립방정식을 풀지 않고 정상분포 구하기

상태가 수십 개인 연쇄의 정상분포를 구하려면 \(\pi P = \pi\)라는 큰 연립방정식을 풀어야 합니다. 그런데 많은 연쇄에서는 "두 상태 사이를 오가는 흐름이 양방향으로 같다"는 훨씬 강한 조건이 성립해서, 이웃한 상태끼리의 비만으로 정상분포가 나옵니다. 이런 연쇄를 가역 연쇄라 하며, 응통15의 MCMC 알고리즘은 일부러 이 성질을 갖도록 설계됩니다.

3.5.1세부 균형

정리 3.5.1

확률분포 \(\pi\)가 모든 \(i, j\)에 대해 세부 균형 \(\pi_iP_{ij} = \pi_jP_{ji}\)을 만족하면 \(\pi\)는 정상분포이다.

\(\sum_i\pi_iP_{ij} = \sum_i\pi_jP_{ji} = \pi_j\sum_iP_{ji} = \pi_j\). ∎

정상분포의 조건 \(\pi P = \pi\)(전체 균형)는 "상태 \(j\)로 들어오는 흐름의 합 = 나가는 흐름의 합"인데, 세부 균형은 이것을 상태의 쌍마다 따로 요구합니다. 그래서 세부 균형은 충분조건일 뿐 필요조건은 아닙니다. 상태 1 → 2 → 3 → 1로만 도는 순환 연쇄는 균일분포가 정상분포이지만 세부 균형은 깨집니다(1에서 2로는 가지만 2에서 1로는 못 감).

세부 균형이 성립하면, 정상 상태에서 출발한 연쇄를 거꾸로 재생해도 같은 확률 법칙을 따릅니다(\(P(X_n = i, X_{n+1} = j) = P(X_n = j, X_{n+1} = i)\)). 그래서 가역이라 부릅니다.

3.5.2출생-사망 연쇄

상태 \(0, 1, \ldots, m\)에서 한 번에 한 칸씩만 오르내리는 연쇄(오를 확률 \(p_i\), 내릴 확률 \(q_i\))는 항상 가역입니다. 이웃한 두 상태 사이의 흐름만 있으므로 세부 균형 \(\pi_ip_i = \pi_{i+1}q_{i+1}\)을 차례로 쓰면

\[\pi_i = \pi_0\prod_{k=0}^{i-1}\frac{p_k}{q_{k+1}},\]

이고 합이 1이 되도록 \(\pi_0\)를 정합니다. 대기열(손님 수), 개체군 크기, 재고 수준 모형이 이 꼴입니다.

3.5.3그래프 위의 랜덤워크

연결된 그래프의 각 꼭짓점에서 이웃 가운데 하나로 같은 확률로 옮기면 \(P_{ij} = 1/d_i\)(\(d_i\)는 꼭짓점 \(i\)의 차수)입니다. \(\pi_i \propto d_i\)로 두면 \(\pi_iP_{ij} \propto 1 = \pi_jP_{ji}\)이므로 세부 균형이 성립하고, 정상분포는 \(\pi_i = d_i/\sum_k d_k\)입니다. 이웃이 많은 꼭짓점일수록 오래 머뭅니다. 웹 페이지의 링크를 따라 무작위로 걷는 모형(페이지랭크, 3.6절)의 출발점입니다(링크에 방향이 있으면 가역이 아니라 별도 계산이 필요).

예제 3.5.2

상태 0, 1, 2, 3인 출생-사망 연쇄에서 \(p_i = 0.6\) (\(i = 0, 1, 2\)), \(q_i = 0.4\) (\(i = 1, 2, 3\)), 나머지 확률은 제자리입니다. 정상분포는?

풀이. \(\pi_{i+1}/\pi_i = 0.6/0.4 = 1.5\). \(\pi \propto (1, 1.5, 2.25, 3.375)\), 합 8.125. \(\pi = (0.123, 0.185, 0.277, 0.415)\). 오르는 쪽이 유리하므로 높은 상태에 오래 머뭅니다.

요약
  1. 세부 균형 \(\pi_iP_{ij} = \pi_jP_{ji}\)이면 \(\pi\)는 정상분포(충분조건).
  2. 출생-사망 연쇄: \(\pi_{i+1}/\pi_i = p_i/q_{i+1}\).
  3. 그래프 랜덤워크: \(\pi_i \propto d_i\).

3.5.4연습문제

기본

  1. 꼭짓점 A, B, C, D가 A–B, B–C, C–D, D–A, A–C로 연결된 그래프의 랜덤워크 정상분포는?
    답

    차수 A 3, B 2, C 3, D 2, 합 10. \(\pi = (0.3, 0.2, 0.3, 0.2)\).

응용

  1. 상태 0~2의 연쇄 \(P = \begin{pmatrix}0 & 1 & 0\\ 0 & 0 & 1\\ 1 & 0 & 0\end{pmatrix}\)의 정상분포를 구하고, 세부 균형이 성립하지 않음을 보이세요.
    답

    정상분포는 \((1/3, 1/3, 1/3)\). \(\pi_0P_{01} = 1/3\)이지만 \(\pi_1P_{10} = 0\)이라 세부 균형이 깨집니다. 시간을 거꾸로 돌리면 0 → 2 → 1로 도는 다른 연쇄가 됩니다.
