가역 연쇄와 세부 균형

본문

상태가 수십 개인 연쇄의 정상분포를 구하려면 \(\boldsymbol\pi P = \boldsymbol\pi\)라는 큰 연립방정식을 풀어야 한다. 그런데 친구 관계망 위를 무작위로 옮겨 다니는 사람이 각 사람 곁에 머무는 비율은, 그 사람의 친구 수만 알면 바로 나온다고 한다. 어떻게 연립방정식 없이 정상분포를 알 수 있을까?

먼저 알아야 할 것정상분포(3.4절)를 쓴다.

처음 질문의 답은 세부 균형이다. 많은 연쇄에서는 두 상태 사이를 오가는 흐름이 양방향으로 같다는 훨씬 강한 조건이 성립해, 이웃한 상태끼리의 비만으로 정상분포가 나온다. 이런 연쇄를 가역 연쇄라 하며, 응통15의 MCMC 알고리즘은 일부러 이 성질을 갖도록 설계된다.

3.5.1세부 균형

정리 3.5.1

확률분포 \(\pi\)가 모든 \(i, j\)에 대해 세부 균형 \(\pi_iP_{ij} = \pi_jP_{ji}\)을 만족하면 \(\pi\)는 정상분포이다.

증명. \(\sum_i\pi_iP_{ij} = \sum_i\pi_jP_{ji} = \pi_j\sum_iP_{ji} = \pi_j\)이다. ∎

정상분포의 조건 \(\pi P = \pi\), 곧 전체 균형은 상태 \(j\)로 들어오는 흐름의 합이 나가는 흐름의 합과 같다는 것이다. 반면 세부 균형은 이것을 상태의 쌍마다 따로 요구한다. 그래서 세부 균형은 충분조건일 뿐 필요조건은 아니다. 예를 들어 1 → 2 → 3 → 1로만 도는 순환 연쇄는 균일분포가 정상분포이지만, 1에서 2로는 가고 2에서 1로는 못 가므로 세부 균형이 깨진다.

한편 세부 균형이 성립하면, 정상 상태에서 출발한 연쇄를 거꾸로 재생해도 \(P(X_n = i, X_{n+1} = j) = P(X_n = j, X_{n+1} = i)\)로 같은 확률 법칙을 따른다. 그래서 이런 연쇄를 가역이라 부른다.

3.5.2출생-사망 연쇄

상태 \(0, 1, \ldots, m\)에서 한 번에 한 칸씩만 오르내리는 연쇄(오를 확률 \(p_i\), 내릴 확률 \(q_i\))는 항상 가역이다. 이웃한 두 상태 사이의 흐름만 있으므로, 세부 균형 \(\pi_ip_i = \pi_{i+1}q_{i+1}\)을 차례로 쓰면 다음을 얻는다.

\[\pi_i = \pi_0\prod_{k=0}^{i-1}\frac{p_k}{q_{k+1}}\]

그리고 합이 1이 되도록 \(\pi_0\)를 정한다. 대기열의 손님 수, 개체군 크기, 재고 수준 모형이 이 꼴이다.

예제 3.5.1

상태 0, 1, 2, 3인 출생-사망 연쇄에서 \(p_i = 0.6\)(\(i = 0, 1, 2\)), \(q_i = 0.4\)(\(i = 1, 2, 3\))이고 나머지 확률은 제자리이다. 정상분포를 구하여라.

풀이. \(\pi_{i+1}/\pi_i = 0.6/0.4 = 1.5\)이므로 \(\pi \propto (1, 1.5, 2.25, 3.375)\)이고, 합 8.125로 나누면 \(\pi = (0.123, 0.185, 0.277, 0.415)\)이다. 오르는 쪽이 유리하므로 높은 상태에 오래 머문다.

3.5.3그래프 위의 랜덤워크

연결된 그래프의 각 꼭짓점에서 이웃 가운데 하나로 같은 확률로 옮기면, 꼭짓점 \(i\)의 차수를 \(d_i\)라 할 때 \(P_{ij} = 1/d_i\)이다. \(\pi_i \propto d_i\)로 두면 \(\pi_iP_{ij} \propto 1 = \pi_jP_{ji}\)이므로 세부 균형이 성립하고, 정상분포는 \(\pi_i = d_i/\sum_k d_k\)이다(그림 1). 처음 질문의 답이 이것이며, 웹 페이지의 링크를 따라 무작위로 걷는 페이지 순위 모형(3.6절)의 출발점이다. 다만 링크에 방향이 있으면 가역이 아니어서 따로 계산해야 한다.

마무리

세부 균형 \(\pi_iP_{ij} = \pi_jP_{ji}\)을 만족하는 \(\pi\)는 정상분포이며, 이는 충분조건일 뿐 필요조건은 아니다. 출생-사망 연쇄는 항상 가역이고 \(\pi_{i+1}/\pi_i = p_i/q_{i+1}\)이다. 무방향 그래프 위의 랜덤워크는 \(\pi_i \propto d_i\)로, 연립방정식 없이 정상분포를 얻는다.

3.5.4연습문제

기본

  1. 꼭짓점 A, B, C, D가 A–B, B–C, C–D, D–A, A–C로 연결된 그래프의 랜덤워크 정상분포는 무엇인가?
    답

    차수가 A 3, B 2, C 3, D 2이고 합은 10이므로 \(\pi = (0.3, 0.2, 0.3, 0.2)\)이다.

응용

  1. 상태 0~2의 연쇄 \(P = \begin{pmatrix}0 & 1 & 0\\ 0 & 0 & 1\\ 1 & 0 & 0\end{pmatrix}\)의 정상분포를 구하고, 세부 균형이 성립하지 않음을 보여라.
    답

    정상분포는 \((1/3, 1/3, 1/3)\)이다. 그러나 \(\pi_0P_{01} = 1/3\)인데 \(\pi_1P_{10} = 0\)이라 세부 균형이 깨진다. 시간을 거꾸로 돌리면 0 → 2 → 1로 도는 다른 연쇄가 된다.
