단순 랜덤워크와 파산 확률

본문

룰렛에서 빨강에 걸면 이길 확률이 18/38, 곧 47.4%이다. 반반에서 고작 2.6%p 모자란다. 50만 원을 들고 1만 원씩 걸어 100만 원이 되면 그만두려 한다. 성공 확률은 반쯤에서 조금 모자란 45% 정도일까?

먼저 알아야 할 것조건화(1.2절)와 등비수열의 합을 쓴다.

처음 질문의 답은 0.5%이다(그림 1). 한 판의 작은 불리함이 수백 판에 걸쳐 쌓이기 때문이다. 이 계산의 바탕이 단순 랜덤워크이며, 주가 모형, 확산, 대기열의 기초가 된다.

2.1.1정의

정의 2.1.1 (단순 랜덤워크)

\(X_i\)가 독립이고 \(P(X_i = 1) = p\), \(P(X_i = -1) = q = 1-p\)일 때 \(S_n = S_0 + X_1 + \cdots + X_n\)을 단순 랜덤워크라 한다. \(p = 1/2\)이면 대칭 랜덤워크라 한다.

\(E(S_n - S_0) = n(p - q)\)이고 \(\mathrm{Var}(S_n) = 4npq\)이다. 그래서 대칭이면 평균은 0이지만 표준편차는 \(\sqrt n\)으로 커져, 출발점에서 점점 멀리 퍼진다.

2.1.2도박꾼의 파산

\(k\)원에서 시작해 \(N\)원이 되거나 0원이 되면 멈춘다고 하자. \(N\)원에 먼저 도달할 확률 \(P_k\)는 첫 걸음으로 조건을 걸어 다음 점화식을 얻는다.

\[P_k = pP_{k+1} + qP_{k-1}, \qquad P_0 = 0,\ P_N = 1\]
정리 2.1.1

\(p \ne q\)이면 \(P_k = \dfrac{1 - (q/p)^k}{1 - (q/p)^N}\)이고, \(p = q\)이면 \(P_k = k/N\)이다.

증명. \(P_k = pP_k + qP_k\)를 점화식에서 빼면 \(P_{k+1} - P_k = \frac qp(P_k - P_{k-1})\)이다. 즉 차이가 등비수열이라 \(P_{k+1} - P_k = (q/p)^kP_1\)이다. 0부터 \(k-1\)까지 더하면 \(P_k = P_1\sum_{j=0}^{k-1}(q/p)^j\)이고, \(P_N = 1\)로 \(P_1\)을 정하면 결론이 나온다. ∎

예제 2.1.1

룰렛 빨강의 승률 \(p = 18/38\)에서 50만 원으로 시작해 1만 원씩 걸어 100만 원이 되면 멈추려 한다. 성공 확률은 얼마인가?

풀이. \(q/p = 20/18 = 1.111\)이므로 \(P_{50} = \frac{1 - 1.111^{50}}{1 - 1.111^{100}} = \frac{-193}{-37{,}640} = 0.0052\)이다. 한 판의 불리함은 작아 보여도 오래 하면 거의 확실히 잃는다. 공정한 게임이었다면 0.5이다.

마무리

단순 랜덤워크는 ±1인 독립 걸음의 합으로, 대칭이면 평균은 그대로이고 퍼짐은 \(\sqrt n\)으로 커진다. 파산 문제는 첫 걸음으로 조건을 걸어 점화식을 세우며, 해는 \(P_k = (1 - (q/p)^k)/(1 - (q/p)^N)\), 대칭이면 \(k/N\)이다. 조금만 불리한 게임도 오래 하면 성공 확률이 0 가까이로 떨어진다.

2.1.3연습문제

기본

  1. 이길 확률이 0.49인 게임에서 같은 조건(50만 원, 목표 100만 원, 1만 원씩)이면 성공 확률은 얼마인가?
    답

    \(q/p = 51/49\)를 넣으면 약 0.12이다.

응용

  1. 대칭 랜덤워크에서 게임이 끝날 때까지의 평균 판 수 \(D_k\)가 \(k(N-k)\)임을 점화식 \(D_k = 1 + \frac12(D_{k+1} + D_{k-1})\)로 확인하여라.
    답

    \(k(N-k)\)를 넣으면 \(1 + \frac12[(k+1)(N-k-1) + (k-1)(N-k+1)] = 1 + k(N-k) - 1\)이다. 경계 \(D_0 = D_N = 0\)도 만족한다.
