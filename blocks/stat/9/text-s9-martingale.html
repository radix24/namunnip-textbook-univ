마팅게일

본문
이 절에서 배울 것
  • 마팅게일, 우마팅게일, 열마팅게일을 정의한다.
  • 랜덤워크에서 마팅게일을 만드는 세 가지 방법을 익힌다.
  • 마팅게일의 기대값 보존과 거는 전략의 한계를 안다.
먼저 알아야 할 것
  • 조건부기대값 (1.1절), 정지시각 (4.1절).

공정한 게임

지금까지 가진 돈이 얼마든, 다음 판 뒤 가진 돈의 기대값이 지금과 같다면 그 게임은 공정합니다. 이런 과정을 마팅게일이라 합니다. 이름은 원래 "잃으면 두 배로 거는" 도박 전략에서 왔는데, 아이러니하게도 마팅게일 이론은 그런 전략이 통하지 않음을 증명합니다. 금융의 "공정한 가격", 순차 검정, 베이즈 갱신에서도 같은 구조가 나타납니다.

4.2.1정의

정의 4.2.1

\(E|M_n| < \infty\)이고 \(E(M_{n+1} \mid X_0, \ldots, X_n) = M_n\)이면 \((M_n)\)은 (\(X\)에 대한) 마팅게일. 등호 대신 \(\le\)이면 우마팅게일(불리한 게임), \(\ge\)이면 열마팅게일(유리한 게임).

조건에서 반복 기대값으로 \(E(M_n) = E(M_0)\)이 모든 \(n\)에서 성립합니다. 고정된 시각에는 기대값이 보존되는 것이고, "멈추는 시각을 자료를 보며 정해도 보존되는가"가 다음 절의 선택 정지 정리입니다.

4.2.2랜덤워크에서 만드는 마팅게일

\(S_n = X_1 + \cdots + X_n\)(\(X_i\)는 독립, \(P(X = 1) = p\), \(P(X = -1) = q\))에서 다음이 모두 마팅게일입니다.

  1. 평균을 빼기: \(S_n - n(p - q)\). 일반적으로 독립 합에서 \(S_n - n\mu\).
  2. 분산을 빼기(대칭일 때): \(S_n^2 - n\). 확인: \(E(S_{n+1}^2 \mid \cdot) = S_n^2 + 2S_nE(X) + 1 = S_n^2 + 1\)이므로 \(E(S_{n+1}^2 - (n+1)\mid\cdot) = S_n^2 - n\).
  3. 지수 꼴: \((q/p)^{S_n}\). 확인: \(E[(q/p)^{X}] = p\cdot\frac qp + q\cdot\frac pq = 1\)이므로 곱해도 기대값이 그대로입니다. 일반적으로 \(E(e^{\theta X}) = 1\)이 되는 \(\theta\)를 찾아 \(e^{\theta S_n}\)을 씁니다.

이 세 마팅게일이 다음 절에서 도달 확률과 기대 시간을 점화식 없이 구하는 열쇠가 됩니다.

예제 4.2.2

항아리에 빨강 1개, 파랑 1개가 있습니다. 매번 공 하나를 꺼내 색을 보고, 그 공과 같은 색 공을 하나 더해 두 개를 넣습니다(폴리아 항아리). \(n\)번 뒤 빨강의 비율 \(R_n\)이 마팅게일임을 보이세요.

풀이. \(n\)번 뒤 공은 \(n + 2\)개이고 빨강이 \(r\)개면 \(R_n = r/(n+2)\). 다음에 빨강을 꺼낼 확률은 \(R_n\)이고 그러면 \((r+1)/(n+3)\), 아니면 \(r/(n+3)\). \(E(R_{n+1}\mid\cdot) = R_n\frac{r+1}{n+3} + (1-R_n)\frac{r}{n+3} = \frac{r + R_n}{n+3} = \frac{R_n(n+2) + R_n}{n+3} = R_n\). 비율이 평균적으로 변하지 않지만, 실제로는 무작위한 값(균일분포)으로 수렴합니다. 초반의 우연이 영원히 남는 "부익부" 과정의 모형입니다.

4.2.3거는 전략으로 이길 수 있나

매 판 거는 금액 \(H_n\)을 그때까지의 결과를 보고 정해도(예견 가능), 마팅게일에 대한 누적 이익 \(\sum H_k(M_k - M_{k-1})\)은 다시 마팅게일입니다(이산 확률 적분). 고정된 판 수 안에서는 어떤 거는 전략도 기대 이익을 0에서 바꾸지 못하고, 불리한 게임(우마팅게일)에서는 0보다 크게 만들지 못합니다. 카지노가 손님의 전략을 걱정하지 않는 이유입니다.

요약
  1. 마팅게일: \(E(M_{n+1}\mid\text{과거}) = M_n\), 기대값이 시간에 따라 보존.
  2. 랜덤워크에서 \(S_n - n\mu\), \(S_n^2 - n\)(대칭), \((q/p)^{S_n}\)이 마팅게일.
  3. 거는 금액을 조절해도 공정한 게임은 공정하게 남습니다.

4.2.4연습문제

기본

  1. \(X_i\)가 독립이고 \(E(X_i) = 1\), \(X_i > 0\)이면 \(M_n = X_1X_2\cdots X_n\)이 마팅게일임을 보이세요.
    답

    \(E(M_{n+1}\mid\cdot) = M_nE(X_{n+1}) = M_n\).

응용

  1. \(p = 0.4\)인 랜덤워크에서 \(e^{\theta S_n}\)이 마팅게일이 되는 \(\theta \ne 0\)을 구하세요.
    답

    \(0.4e^\theta + 0.6e^{-\theta} = 1\). \(u = e^\theta\)로 두면 \(0.4u^2 - u + 0.6 = 0\), \(u = 1\) 또는 \(1.5\). \(\theta = \ln 1.5\), 곧 \((q/p)^{S_n} = 1.5^{S_n}\)과 같습니다.
