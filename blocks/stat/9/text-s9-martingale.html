마팅게일

본문

항아리에 빨간 공과 파란 공이 하나씩 있다. 공을 하나 꺼내 색을 보고, 같은 색 공을 하나 더해 두 개를 넣는다. 이를 천 번 되풀이하면 빨간 공의 비율은 어떻게 될까? 평균적으로는 늘 1/2일 것 같은데, 실제로 해 보면 어떤 때는 0.9, 어떤 때는 0.1에 자리 잡는다. 평균이 그대로인 과정이 왜 이렇게 다른 곳에 머물까?

먼저 알아야 할 것조건부기대값(1.1절)과 정지시각(4.1절)을 쓴다.

지금까지 가진 돈이 얼마든, 다음 판 뒤 가진 돈의 기댓값이 지금과 같다면 그 게임은 공정하다. 이런 과정을 마팅게일이라 한다. 처음 질문의 항아리 비율도 마팅게일이며, 평균이 보존된다는 것과 각 경로가 한곳에 머문다는 것은 서로 모순되지 않는다(그림 1). 마팅게일은 금융의 공정한 가격, 순차 검정, 베이즈 갱신에도 같은 구조로 나타난다.

4.2.1정의

정의 4.2.1 (마팅게일)

\(E|M_n| < \infty\)이고 \(E(M_{n+1} \mid X_0, \ldots, X_n) = M_n\)이면 \((M_n)\)을 \(X\)에 대한 마팅게일이라 한다. 등호 대신 \(\le\)이면 우마팅게일(불리한 게임), \(\ge\)이면 열마팅게일(유리한 게임)이라 한다.

조건에서 반복 기댓값으로 \(E(M_n) = E(M_0)\)이 모든 \(n\)에서 성립한다. 즉 고정된 시각에는 기댓값이 보존된다. 그런데 멈추는 시각을 자료를 보며 정해도 보존되는지는 따로 따져야 하며, 이것이 다음 절의 선택 정지 정리이다.

4.2.2랜덤워크에서 만드는 마팅게일

\(X_i\)가 독립이고 \(P(X = 1) = p\), \(P(X = -1) = q\)인 \(S_n = X_1 + \cdots + X_n\)에서 세 가지 마팅게일을 만들 수 있다. 첫째는 평균을 뺀 \(S_n - n(p - q)\)이며, 일반적으로 독립 합에서 \(S_n - n\mu\)이다. 둘째는 대칭일 때 분산을 뺀 \(S_n^2 - n\)이다. \(E(S_{n+1}^2 \mid \cdot) = S_n^2 + 2S_nE(X) + 1 = S_n^2 + 1\)이기 때문이다.

셋째는 지수 꼴 \((q/p)^{S_n}\)이다. \(E[(q/p)^{X}] = p\cdot\frac qp + q\cdot\frac pq = 1\)이므로 곱해도 기댓값이 그대로이다. 일반적으로는 \(E(e^{\theta X}) = 1\)이 되는 \(\theta\)를 찾아 \(e^{\theta S_n}\)을 쓴다. 이 세 마팅게일이 다음 절에서 도달 확률과 기대 시간을 점화식 없이 구하는 열쇠가 된다.

예제 4.2.1

처음 질문의 폴리아 항아리에서 \(n\)번 뒤 빨강의 비율 \(R_n\)이 마팅게일임을 보여라.

풀이. \(n\)번 뒤 공은 \(n + 2\)개이고, 빨강이 \(r\)개면 \(R_n = r/(n+2)\)이다. 다음에 빨강을 꺼낼 확률은 \(R_n\)이고 그러면 비율이 \((r+1)/(n+3)\), 아니면 \(r/(n+3)\)이 된다. 따라서 \(E(R_{n+1}\mid\cdot) = R_n\frac{r+1}{n+3} + (1-R_n)\frac{r}{n+3} = \frac{r + R_n}{n+3} = \frac{R_n(n+2) + R_n}{n+3} = R_n\)이다. 그러므로 비율은 평균적으로 변하지 않지만, 실제로는 균일분포를 따르는 무작위한 값으로 수렴한다. 초반의 우연이 영원히 남는 부익부 과정의 모형이다.

4.2.3거는 전략으로 이길 수 있는가

매 판 거는 금액 \(H_n\)을 그때까지의 결과를 보고 정해도, 마팅게일에 대한 누적 이익 \(\sum H_k(M_k - M_{k-1})\)은 다시 마팅게일이다. 이를 이산 확률 적분이라 한다. 그러므로 고정된 판 수 안에서는 어떤 거는 전략도 기대 이익을 0에서 바꾸지 못하고, 불리한 게임(우마팅게일)에서는 0보다 크게 만들지 못한다. 카지노가 손님의 전략을 걱정하지 않는 까닭이다.

마무리

마팅게일은 \(E(M_{n+1}\mid\text{과거}) = M_n\)인 과정으로, 기댓값이 시간에 따라 보존되지만 경로는 무작위한 값으로 수렴할 수 있다. 랜덤워크에서는 \(S_n - n\mu\), 대칭일 때 \(S_n^2 - n\), 그리고 \((q/p)^{S_n}\)이 마팅게일이다. 거는 금액을 어떻게 조절해도 공정한 게임은 공정하게 남는다.

4.2.4연습문제

기본

  1. \(X_i\)가 독립이고 \(E(X_i) = 1\), \(X_i > 0\)이면 \(M_n = X_1X_2\cdots X_n\)이 마팅게일임을 보여라.
    답

    \(E(M_{n+1}\mid\cdot) = M_nE(X_{n+1}) = M_n\)이다.

응용

  1. \(p = 0.4\)인 랜덤워크에서 \(e^{\theta S_n}\)이 마팅게일이 되는 \(\theta \ne 0\)을 구하여라.
    답

    \(0.4e^\theta + 0.6e^{-\theta} = 1\)이다. \(u = e^\theta\)로 두면 \(0.4u^2 - u + 0.6 = 0\)이므로 \(u = 1\) 또는 \(1.5\)이다. 따라서 \(\theta = \ln 1.5\)이며, \((q/p)^{S_n} = 1.5^{S_n}\)과 같다.
