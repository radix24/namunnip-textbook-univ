페이지 순위와 MCMC

본문

웹 페이지는 수십억 개이다. 검색어에 맞는 페이지 가운데 어느 것을 맨 위에 보여 줄까? 링크를 많이 받은 페이지가 중요하겠지만, 아무도 찾지 않는 페이지들이 서로 링크를 주고받으면 어떻게 될까? 중요한 페이지에서 받은 링크에 더 큰 무게를 주는 방법은 없을까?

먼저 알아야 할 것정상분포(3.4절)와 가역 연쇄(3.5절)를 쓴다.

지금까지는 연쇄가 주어지면 정상분포를 구했다. 응용에서는 방향을 바꿔 쓰기도 한다. 하나는 정상분포 자체가 답인 문제, 곧 웹 페이지의 중요도이고, 다른 하나는 원하는 분포를 정상분포로 갖는 연쇄를 일부러 만드는 문제, 곧 MCMC이다. 처음 질문의 답은 앞의 것이다.

3.6.1페이지 순위

웹 서퍼가 현재 페이지의 링크 가운데 하나를 무작위로 눌러 이동한다고 하자. 그러면 페이지가 상태, 링크가 전이인 마르코프 연쇄가 된다. 오래 돌아다닌 뒤 각 페이지에 머무는 시간의 비율, 곧 정상분포를 그 페이지의 중요도로 쓴다. 이렇게 하면 중요한 페이지에서 링크를 많이 받는 페이지가 저절로 중요해진다(그림 1).

그런데 링크가 없는 페이지나 빠져나올 수 없는 무리가 있으면 기약이 아니다. 그래서 확률 \(1 - d\)로 아무 페이지로나 순간 이동한다고 수정한다. 여기서 \(J\)는 모든 원소가 1인 행렬이고, 흔히 \(d \approx 0.85\)를 쓴다.

\[G = dP + (1-d)\frac1m J\]

\(G\)는 모든 원소가 양수이므로 기약이고 비주기이며, 유일한 정상분포를 갖는다. 실제로는 \(\boldsymbol\pi_{k+1} = \boldsymbol\pi_kG\)를 되풀이하는 거듭제곱법으로 계산한다.

예제 3.6.1

페이지 A, B, C에 A → B, A → C, B → C, C → A의 링크가 있다(\(d = 1\)로 단순화). 페이지 순위를 구하여라.

풀이. 전이행렬의 A 행은 (0, 1/2, 1/2), B 행은 (0, 0, 1), C 행은 (1, 0, 0)이다. 그러면 \(\pi_A = \pi_C\), \(\pi_B = \pi_A/2\), \(\pi_C = \pi_A/2 + \pi_B = \pi_A\)이고, 합이 1이므로 \((0.4, 0.2, 0.4)\)이다. 즉 링크를 두 개 받는 C와, 중요한 C에서 링크를 받는 A가 높다.

3.6.2MCMC의 아이디어

목표 분포 \(\pi\)에서 직접 표본을 뽑기 어렵다면, \(\pi\)를 정상분포로 갖는 연쇄를 만들어 오래 돌린 뒤 그 경로를 표본처럼 쓴다. 근거는 에르고딕 정리(3.4절)이다. 그리고 그런 연쇄를 만드는 쉬운 충분조건이 3.5절의 세부 균형 \(\pi_iP_{ij} = \pi_jP_{ji}\)이다.

예를 들어 메트로폴리스 알고리즘은 이웃 상태를 제안하고, 확률 \(\min(1, \pi_j/\pi_i)\)로 받아들인다. 제안이 대칭이면 이 규칙이 세부 균형을 만족하므로 \(\pi\)가 정상분포가 된다. 게다가 \(\pi\)의 비만 필요하므로, 정규화 상수를 몰라도 된다. 구현은 응통15 5단원과 그 실습 카드에서 다룬다.

마무리

페이지 순위는 순간 이동을 섞은 웹 연쇄 \(G = dP + (1-d)J/m\)의 정상분포로, 거듭제곱법으로 계산한다. MCMC는 원하는 분포를 정상분포로 갖는 연쇄를 만들어 그 경로를 표본으로 쓰며, 세부 균형이 그런 연쇄를 만드는 쉬운 충분조건이다. 메트로폴리스 알고리즘은 정규화 상수 없이 확률의 비만으로 이 조건을 맞춘다.

3.6.3연습문제

기본

  1. 순간 이동 확률 \(1-d\)를 1로 두면(\(d = 0\)) 페이지 순위는 어떻게 되는가?
    답

    링크와 상관없이 매번 무작위 페이지로 가므로 모든 페이지가 \(1/m\)으로 같아진다.

응용

  1. 예제 3.6.1에서 \(d = 0.85\)로 하면 페이지 순위는 어느 쪽으로 바뀌는가? R로 거듭제곱법을 써서 확인하여라.
    답

    순간 이동이 균일분포 쪽으로 당기므로 B가 조금 오르고(0.215) A와 C가 조금 내려간다(0.388, 0.397). 코드는 G <- 0.85*P + 0.15/3; p <- rep(1/3,3); for(k in 1:100) p <- p %*% G; p이다.
