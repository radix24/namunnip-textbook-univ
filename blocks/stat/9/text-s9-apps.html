정상분포를 일하게 만들기

지금까지는 연쇄가 주어지면 정상분포를 구했습니다. 응용에서는 방향을 바꿔 쓰기도 합니다. 정상분포 자체가 답인 문제(웹 페이지의 중요도)와, 원하는 분포를 정상분포로 가지는 연쇄를 일부러 만드는 문제(MCMC)입니다.

3.4.1페이지랭크

웹 서퍼가 현재 페이지의 링크 가운데 하나를 무작위로 눌러 이동한다고 합시다. 페이지가 상태, 링크가 전이입니다. 오래 돌아다닌 뒤 각 페이지에 머무는 시간의 비율, 곧 정상분포를 그 페이지의 중요도로 씁니다. 중요한 페이지에서 링크를 많이 받는 페이지가 중요해집니다.

링크가 없는 페이지나 빠져나올 수 없는 무리가 있으면 기약이 아니므로, 확률 \(1 - d\)로 아무 페이지로나 순간 이동한다고 수정합니다.

\[G = dP + (1-d)\frac1m J \quad (J\text{는 모든 원소가 1인 행렬, } d \approx 0.85).\]

\(G\)는 모든 원소가 양수라 기약·비주기이고 유일한 정상분포를 가집니다. \(\boldsymbol\pi_{k+1} = \boldsymbol\pi_kG\)를 되풀이하는 거듭제곱법으로 계산합니다.

3.4.2MCMC의 아이디어

목표 분포 \(\pi\)에서 직접 표본을 뽑기 어렵다면, \(\pi\)를 정상분포로 가지는 연쇄를 만들어 오래 돌린 뒤 그 경로를 표본처럼 씁니다(에르고딕 정리). 연쇄를 만드는 쉬운 충분조건은 상세 균형입니다.

정리 3.4.1

모든 \(i, j\)에서 \(\pi_iP_{ij} = \pi_jP_{ji}\)이면 \(\boldsymbol\pi\)는 정상분포이다.

\(\sum_i\pi_iP_{ij} = \sum_i\pi_jP_{ji} = \pi_j\sum_iP_{ji} = \pi_j\). ∎

메트로폴리스 알고리즘은 이 조건을 만족하도록 "제안하고 확률 \(\min(1, \pi_j/\pi_i)\)로 받아들이는" 규칙을 씁니다. 구현은 응통15 05단원과 그 실습 카드에서 다룹니다.

예제 3.4.2

페이지 A, B, C에서 A → B, A → C, B → C, C → A의 링크가 있습니다(\(d = 1\)로 단순화). 페이지랭크는?

풀이. \(P\): A 행 (0, 1/2, 1/2), B 행 (0, 0, 1), C 행 (1, 0, 0). \(\pi_A = \pi_C\), \(\pi_B = \pi_A/2\), \(\pi_C = \pi_A/2 + \pi_B = \pi_A\). 합 1에서 \((0.4, 0.2, 0.4)\). 링크를 두 개 받는 C와, 중요한 C에서 링크를 받는 A가 높습니다.

요약
  1. 페이지랭크 = 순간 이동을 섞은 웹 연쇄의 정상분포.
  2. MCMC: 원하는 분포를 정상분포로 가지는 연쇄를 만들어 경로를 표본으로.
  3. 상세 균형이면 정상분포.
