이산시간 Markov 연쇄 단원 마무리 연습

문제 7 · 계산·개념·적용 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 계산날씨 연쇄의 전이행렬이 \(P = \begin{pmatrix}0.7 & 0.3\\ 0.4 & 0.6\end{pmatrix}\) (상태 1 = 맑음, 2 = 비)이다. 오늘 맑을 때 이틀 뒤 비가 올 확률을 채프먼-콜모고로프 식으로 구하여라. [03-01]

    힌트 1

    \(P^{(2)} = P^2\)이다.

    힌트 2

    내일 맑음을 거치는 경로와 비를 거치는 경로를 더한다.

    풀이

    \(P^2 = \begin{pmatrix}0.61 & 0.39\\ 0.52 & 0.48\end{pmatrix}\)이므로 답은 \(P^2_{12} = 0.7\times0.3 + 0.3\times0.6 = 0.39\)이다. 중간 날의 상태로 나누어 더하는 것이 채프먼-콜모고로프 식 \(P^{(m+n)} = P^{(m)}P^{(n)}\)의 뜻이다.

  2. 계산앞 문제 연쇄의 정상분포를 구하고, 장기적으로 비 오는 날의 비율을 써라. [03-04]

    힌트 1

    \(\pi P = \pi\), \(\pi_1 + \pi_2 = 1\)을 푼다.

    힌트 2

    두 상태 연쇄에서는 \(\pi_1\times0.3 = \pi_2\times0.4\)(흐름 균형)이다.

    풀이

    \(0.3\pi_1 = 0.4\pi_2\)와 \(\pi_1 + \pi_2 = 1\)에서 \(\pi = (4/7, 3/7) \approx (0.571, 0.429)\)이다. 장기적으로 약 43%의 날에 비가 온다. \(P^n\)의 두 행이 모두 이 값으로 수렴하므로 오늘 날씨는 먼 미래에 영향을 주지 않는다.

  3. 개념상태 0, 1, 2의 전이행렬이 \(P = \begin{pmatrix}1 & 0 & 0\\ 0.5 & 0 & 0.5\\ 0 & 0 & 1\end{pmatrix}\)이다. 각 상태를 재귀와 일시로 분류하고, 상태 1에서 출발했을 때 장기적으로 어디에 있게 되는지 써라. [03-02]

    힌트 1

    상태 0과 2는 한 번 들어가면 나오지 않습니다(흡수 상태).

    힌트 2

    상태 1을 떠나면 다시 돌아올 수 있나요?

    풀이

    상태 0과 2는 흡수 상태라 재귀이다. 상태 1은 한 걸음 만에 0이나 2로 떠나 다시 돌아올 수 없으므로 일시이다.

    상태 1에서 출발하면 확률 1/2씩 0 또는 2에 흡수되어 그곳에 영원히 머문다. 이 연쇄는 정상분포가 하나가 아니며(0에 몰린 분포, 2에 몰린 분포와 그 섞임), 극한이 출발 상태에 따라 달라진다.

  4. 개념\(P = \begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}\)인 연쇄의 주기와 정상분포를 구하고, \(P^n\)이 수렴하지 않는 까닭을 설명하여라. [03-02]

    힌트 1

    상태 1에서 1로 돌아올 수 있는 걸음 수는 2, 4, 6, …이다.

    힌트 2

    \(P^n\)은 \(n\)이 짝수이면 단위행렬, 홀수이면 \(P\)이다.

    풀이

    두 상태 모두 주기 2이다. 정상분포는 \(\pi = (1/2, 1/2)\)로 존재한다.

    그러나 \(P^n\)은 \(I\)와 \(P\)를 번갈아 오가므로 수렴하지 않는다. 정상분포로 수렴하려면 기약성과 함께 비주기성이 필요하다. 그래도 장기 체류 비율(시간 평균)은 각 1/2로 정상분포와 같다.

  5. 계산상태 0, 1, 2, 3인 공정한 도박 연쇄(0과 3은 흡수, 1과 2에서는 확률 1/2씩 한 칸 이동)에서 상태 1에서 출발해 3에 흡수될 확률을 첫 단계 분석으로 구하여라. [03-03]

    힌트 1

    \(h_i\) = 상태 \(i\)에서 3에 흡수될 확률이라 하면 \(h_0 = 0\), \(h_3 = 1\)이다.

    힌트 2

    \(h_1 = \frac12h_0 + \frac12h_2\), \(h_2 = \frac12h_1 + \frac12h_3\)이다.

    풀이

    \(h_1 = h_2/2\), \(h_2 = h_1/2 + 1/2\)를 풀면 \(h_1 = 1/3\), \(h_2 = 2/3\)이다. 응통9-02-01의 공식 \(k/N = 1/3\)과 같다.

  6. 적용웹 페이지 세 개의 링크가 A→B, B→C, C→A, C→B이다. 각 페이지에서 나가는 링크를 같은 확률로 따라가는 마르코프 연쇄의 정상분포(페이지 순위)를 구하여라. 실제 페이지 순위 계산에서 "감쇠 계수"를 넣는 까닭도 써라. [03-06]

    힌트 1

    전이확률은 A→B 1, B→C 1, C→A 1/2, C→B 1/2이다.

    힌트 2

    \(\pi_A = \frac12\pi_C\), \(\pi_B = \pi_A + \frac12\pi_C\), \(\pi_C = \pi_B\)이다.

    풀이

    \(\pi_B = \pi_C\), \(\pi_A = \pi_C/2\)이고 합이 1이므로 \(\pi = (0.2, 0.4, 0.4)\)이다. B와 C가 같은 순위로 가장 높다.

    실제 웹에는 나가는 링크가 없는 페이지나 서로만 가리키는 페이지 묶음이 있어, 연쇄가 기약·비주기가 아닐 수 있다. 확률 \(1 - d\)(보통 \(d = 0.85\))로 아무 페이지로나 순간 이동하게 하면 연쇄가 기약·비주기가 되어 정상분포가 하나로 정해지고 반복 계산이 수렴한다. MCMC도 원하는 분포를 정상분포로 갖는 연쇄를 만들어 표본을 뽑는다는 같은 원리를 쓴다.

  7. 계산가운데 꼭짓점 하나에 잎 꼭짓점 4개가 붙은 별 모양 그래프에서 이웃 가운데 하나로 같은 확률로 옮기는 랜덤워크의 정상분포를 세부 균형으로 구하여라. 가운데에서 출발해 다시 가운데로 돌아오는 평균 시간은 얼마인가요? [03-05]

    힌트 1

    그래프 위의 랜덤워크에서는 \(\pi_i \propto d_i\)(차수)이다.

    힌트 2

    평균 복귀 시간은 \(1/\pi_i\)입니다(3.4절).

    풀이

    차수는 가운데 4, 잎 1씩, 합 8. \(\pi_{\text{가운데}} = 0.5\), 잎마다 0.125이다. 세부 균형 확인: \(0.5 \times \frac14 = 0.125 \times 1\).

    가운데로의 평균 복귀 시간은 \(1/0.5 = 2\)로, 잎으로 갔다가 반드시 바로 돌아오므로 정확히 2걸음인 것과 맞다. 이 연쇄는 주기 2라 \(P^n\)은 수렴하지 않지만 정상분포는 장기 체류 비율로 의미가 있다.
