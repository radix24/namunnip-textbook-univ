정지시각과 마팅게일 단원 마무리 연습

문제 6 · 개념·증명·계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 개념랜덤워크 \(S_n\)에 대해 다음이 정지시각인지 판정하세요. (가) \(S_n\)이 처음 5에 닿는 시각 (나) 100걸음 안에서 마지막으로 0에 있었던 시각 (다) 처음 10걸음 동안의 최댓값에 처음 도달한 시각 [04-01]

    힌트 1

    정지시각은 "지금까지의 정보만으로 지금 멈출지 결정할 수 있는" 시각입니다.

    힌트 2

    (나)와 (다)는 미래를 봐야 알 수 있나요?

    풀이

    (가) 정지시각입니다. \(n\)걸음째에 지금까지의 경로만 보고 처음 5에 닿았는지 알 수 있습니다.

    (나) 정지시각이 아닙니다. 지금 0에 있어도 100걸음까지 다시 0에 오는지는 미래를 봐야 압니다. (다) 정지시각이 아닙니다. 10걸음 전체의 최댓값은 10걸음이 끝나야 알 수 있습니다.

  2. 증명대칭 단순 랜덤워크 \(S_n\)에 대해 \(S_n\)과 \(S_n^2 - n\)이 마팅게일임을 보이세요. [04-02]

    힌트 1

    \(S_{n+1} = S_n + X_{n+1}\)이고 \(X_{n+1}\)은 과거와 독립이며 평균 0, 분산 1입니다.

    힌트 2

    \(E(S_{n+1}^2 \mid \mathcal F_n) = S_n^2 + 2S_nE(X_{n+1}) + E(X_{n+1}^2)\)입니다.

    풀이

    \(E(S_{n+1} \mid \mathcal F_n) = S_n + E(X_{n+1}) = S_n\)입니다. \(E(S_{n+1}^2 - (n+1) \mid \mathcal F_n) = S_n^2 + 0 + 1 - (n + 1) = S_n^2 - n\)입니다. 또 \(E|S_n| \le n\) 등 적분 가능성도 성립하므로 둘 다 마팅게일입니다.

  3. 계산앞 문제의 두 마팅게일에 선택 정지 정리를 써서, 공정한 도박에서 \(k\)에서 출발해 0 또는 \(N\)에 닿는 시각 \(T\)에 대해 \(P(S_T = N) = k/N\)과 \(E(T) = k(N-k)\)를 유도하세요. [04-02]

    힌트 1

    \(E(S_T) = S_0 = k\)이고 \(S_T\)는 0 또는 \(N\)입니다.

    힌트 2

    \(E(S_T^2 - T) = k^2\)입니다.

    풀이

    \(E(S_T) = N\cdot P(S_T = N) = k\)에서 \(P(S_T = N) = k/N\)입니다.

    \(E(S_T^2) - E(T) = k^2\)이고 \(E(S_T^2) = N^2\cdot k/N = kN\)이므로 \(E(T) = kN - k^2 = k(N-k)\)입니다. 응통9-02-01의 결과를 연립방정식 없이 얻었습니다(\(T\)가 유계에 가까운 조건을 만족하므로 정리를 쓸 수 있습니다).

  4. 판단"지면 판돈을 두 배로 올리고, 한 번이라도 이기면 멈춘다"는 전략을 쓰면 공정한 게임에서도 반드시 1만 원을 번다고 합니다. 선택 정지 정리와 어긋나 보이는 까닭을 설명하세요. [04-02]

    힌트 1

    이기는 순간 그때까지의 손실을 모두 되찾고 처음 판돈만큼 남습니다.

    힌트 2

    선택 정지 정리의 조건(정지시각이 유계이거나 증가분이 유계 등)을 확인하세요.

    풀이

    이기는 시각 \(T\)는 확률 1로 유한하지만 유계가 아니고, 그 직전까지의 손실 \(2^{T-1} - 1\)은 한없이 커질 수 있습니다. 선택 정지 정리의 조건(유계 정지시각, 또는 유계 증가분과 유한 기대 시간 등)이 성립하지 않아 \(E(S_T) = S_0\)이 깨지는 것입니다.

    현실에서는 자본과 판돈 한도가 유한하므로, 연속으로 지면 한도에 막혀 큰 손실을 봅니다. 그 손실 확률은 작지만 크기가 커서 기대 이익은 0입니다.

  5. 계산이길 확률 \(p \ne 1/2\)인 랜덤워크에서 \(Y_n = (q/p)^{S_n}\)이 마팅게일임을 보이고, 이를 써서 응통9-02-01의 불리한 도박 도달 확률 공식을 유도하세요. [04-02]

    힌트 1

    \(E[(q/p)^{X}] = p\cdot\frac qp + q\cdot\frac pq\)입니다.

    힌트 2

    \(E(Y_T) = (q/p)^k\)이고 \(Y_T\)는 \(1\) 또는 \((q/p)^N\)입니다.

    풀이

    \(E[(q/p)^X] = q + p = 1\)이므로 \(E(Y_{n+1} \mid \mathcal F_n) = Y_n\)입니다.

    \(r = q/p\)라 하고 \(N\)에 도달할 확률을 \(h\)라 하면 \(hr^N + (1 - h) = r^k\), 곧 \(h = \dfrac{1 - r^k}{1 - r^N}\)입니다.

  6. 계산주사위를 6이 나올 때까지 던질 때, 나온 눈의 합의 기댓값을 왈드 등식 \(E(S_T) = E(T)E(X)\)로 구하세요. \(T\)가 정지시각이라는 점이 왜 중요한가요? [04-01]

    힌트 1

    \(T\)는 기하분포로 \(E(T) = 6\)입니다.

    힌트 2

    눈의 평균은 3.5입니다.

    풀이

    \(E(S_T) = 6\times3.5 = 21\)입니다.

    왈드 등식은 \(T\)가 정지시각이고 \(E(T) < \infty\)일 때 성립합니다. 마지막 시행(6)이 멈춤을 결정하는데도 성립하는 까닭은, 각 시행 \(X_n\)을 할지 말지가 그 이전 결과로만 정해지기 때문입니다. 미래를 보고 멈추는 시각이면 성립하지 않습니다.
