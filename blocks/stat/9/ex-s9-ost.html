원숭이가 ABRACADABRA를 치기까지: 마팅게일 도박꾼 트릭

예제 · 선택 정지 정리

먼저 읽는 법

패턴이 처음 나올 때까지의 기대 시간은 흡수 연쇄(3.3절)로도 풀 수 있지만, "매 시점 새 도박꾼이 들어와 패턴에 공정하게 거는" 마팅게일을 만들면 한 줄로 끝납니다. 총 이익 = 지불한 돈 − 받은 돈이 마팅게일이고, 선택 정지 정리로 기대값이 0이 됩니다.

문제. 공정한 동전을 던질 때 패턴 HTH가 처음 나올 때까지의 기대 횟수를 구하세요. HHH는?

풀이

  1. 매 던지기 직전에 도박꾼이 한 명씩 들어와 1원을 "다음이 H"에 겁니다. 맞으면 2원을 받아 전부 "다음이 T"에 걸고, 맞으면 4원을 전부 "다음이 H"에 겁니다. 틀리면 빈손으로 떠납니다.
    공정한 배당(2배)이라 카지노의 순이익은 마팅게일입니다.
  2. 패턴이 처음 완성된 시각 \(T\)에 카지노가 받은 돈은 \(T\)원(도박꾼 \(T\)명이 1원씩). 그때 돈을 가진 도박꾼: HTH를 끝까지 맞힌 사람 8원, 마지막 H 하나를 맞힌 사람 2원(그 사람의 패턴 시작 H). 가운데 T에서 시작한 사람은 첫 걸음(H)부터 틀렸습니다.
    패턴의 끝부분이 패턴의 앞부분과 겹치는 만큼 돈이 남습니다.
  3. \(E(T) < \infty\)이고 증분이 유계이므로 선택 정지 정리로 카지노 순이익의 기대값은 0: \(E(T) - (8 + 2) = 0\), \(E(T) = 10\).
    정리 4.3.1 (나).
  4. HHH: 끝날 때 3명(8원, 4원, 2원)이 돈을 가지고 있어 \(E(T) = 8 + 4 + 2 = 14\).
    HHH는 자기 자신과 많이 겹쳐 "실패 후 처음부터"가 자주 일어납니다.

검산

HH는 같은 방법으로 \(4 + 2 = 6\)으로, 3.3절 연습문제에서 흡수 연쇄로 구한 값과 같습니다. HTT는 겹침이 없어 8입니다. 길이가 같은 패턴인데도 기대 시간이 8, 10, 14로 다른 까닭은 자기 겹침의 차이입니다.

의미

같은 원리로 원숭이가 26개 글자를 무작위로 칠 때 ABRACADABRA가 나올 기대 시간은 \(26^{11} + 26^4 + 26\)입니다(ABRA와 A가 겹침). 선택 정지 정리는 이런 조합론 문제를 "공정한 게임에서는 기대 이익이 0"이라는 한 문장으로 바꿉니다. 다만 \(E(T) < \infty\)를 먼저 확인해야 하며, 패턴 문제에서는 기하분포 꼬리로 쉽게 보일 수 있습니다.
