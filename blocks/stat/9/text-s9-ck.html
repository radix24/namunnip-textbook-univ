전이행렬과 채프먼-콜모고로프 식

본문
이 절에서 배울 것
  • 마르코프 성질과 전이행렬을 정의한다.
  • \(n\)단계 전이확률이 \(P^n\)임을 채프먼-콜모고로프 식으로 보인다.
먼저 알아야 할 것
  • 조건부확률 (응통6 1.2절), 행렬 곱 (응통2 01단원).

오늘만 알면 내일을 안다

내일 날씨가 오늘 날씨에만 달려 있고 어제 이전은 상관없다고 가정하면 계산이 크게 단순해집니다. 이 "기억 없음"을 가진 과정이 마르코프 연쇄입니다.

3.1.1정의

정의 3.1.1

상태 공간 \(\{1, \ldots, m\}\)의 확률변수열 \(X_0, X_1, \ldots\)가 \(P(X_{n+1} = j \mid X_n = i, X_{n-1}, \ldots, X_0) = P(X_{n+1} = j \mid X_n = i) = P_{ij}\)를 만족하면 (시간 동질) 마르코프 연쇄. \(P = (P_{ij})\)를 전이행렬이라 하고 각 행의 합은 1이다.

3.1.2채프먼-콜모고로프 식

정리 3.1.2

\(P^{(n)}_{ij} = P(X_{n} = j \mid X_0 = i)\)라 하면 \(P^{(m+n)}_{ij} = \sum_k P^{(m)}_{ik}P^{(n)}_{kj}\). 따라서 \(P^{(n)} = P^n\).

\(m\)단계 뒤의 상태 \(k\)로 조건화하면 \(P(X_{m+n} = j \mid X_0 = i) = \sum_k P(X_m = k \mid X_0 = i)P(X_{m+n} = j \mid X_m = k, X_0 = i)\). 마르코프 성질과 시간 동질성으로 둘째 인자는 \(P^{(n)}_{kj}\). 행렬로 쓰면 \(P^{(m+n)} = P^{(m)}P^{(n)}\)이고 귀납법으로 \(P^{(n)} = P^n\). ∎

처음 분포를 행벡터 \(\boldsymbol\pi_0\)로 쓰면 \(n\)단계 뒤 분포는 \(\boldsymbol\pi_0P^n\)입니다.

예제 3.1.3

맑음(1)과 비(2) 두 상태, \(P = \begin{pmatrix}0.8 & 0.2\\ 0.4 & 0.6\end{pmatrix}\). 오늘 맑으면 이틀 뒤 비가 올 확률은?

풀이. \(P^{(2)}_{12} = 0.8 \times 0.2 + 0.2 \times 0.6 = 0.28\).

요약
  1. 마르코프 성질: 다음 상태는 현재 상태에만 의존.
  2. \(n\)단계 전이확률 = \(P^n\).
  3. 분포는 \(\boldsymbol\pi_0P^n\)으로 갱신.

3.1.3연습문제

기본

  1. 예제에서 오늘 맑을 확률이 0.5이면 내일 비 올 확률은?
    답

    \(0.5 \times 0.2 + 0.5 \times 0.6 = 0.4\).
