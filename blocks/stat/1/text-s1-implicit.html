음함수 미분과 역함수 미분

본문
이 절에서 배울 것
  • 식을 \(y\)에 대해 풀지 않고 \(dy/dx\)를 구한다(음함수 미분).
  • 역함수의 도함수 \((f^{-1})'(y) = 1/f'(x)\)를 쓴다.
  • 분위수 함수의 도함수가 밀도의 역수임을 안다.
먼저 알아야 할 것
  • 연쇄법칙 (2.1절), 분위수의 존재 (1.2절).

풀 수 없는 식의 기울기

정규분포의 분위수 \(z_p\)는 \(\Phi(z) = p\)를 만족하는 값이지만 \(z\)를 \(p\)의 식으로 풀어 쓸 수 없습니다. 그래도 "\(p\)가 조금 변하면 \(z_p\)가 얼마나 변하는가"는 구할 수 있습니다. 식을 풀지 않고 양변을 미분하면 됩니다.

2.4.1음함수 미분

\(x\)와 \(y\)가 \(F(x, y) = 0\)으로 묶여 있으면, \(y\)를 \(x\)의 함수로 보고 양변을 \(x\)로 미분합니다. \(y\)가 들어간 항은 연쇄법칙으로 \(dy/dx\)가 곱해집니다.

예: 원 \(x^2 + y^2 = 1\)에서 \(2x + 2y\frac{dy}{dx} = 0\), 곧 \(\frac{dy}{dx} = -\frac xy\). 위쪽 반원 \(y = \sqrt{1 - x^2}\)을 직접 미분한 결과와 같습니다.

2.4.2역함수의 도함수

정리 2.4.1

\(f\)가 미분 가능하고 순증가(또는 순감소)이며 \(f'(x) \ne 0\)이면, 역함수 \(g = f^{-1}\)은 \(y = f(x)\)에서 미분 가능하고 \(g'(y) = \dfrac{1}{f'(x)} = \dfrac{1}{f'(g(y))}\).

\(f(g(y)) = y\)의 양변을 \(y\)로 미분하면 연쇄법칙으로 \(f'(g(y))\,g'(y) = 1\). ∎

예: \(y = e^x\)의 역함수 \(\ln y\)의 도함수는 \(1/e^x = 1/y\). 로그의 도함수를 지수의 도함수에서 얻는 방법입니다.

2.4.3분위수 함수의 도함수

연속 분포함수 \(F\)(밀도 \(f\))의 분위수 함수 \(Q(p) = F^{-1}(p)\)에 정리 2.4.1을 쓰면

\[Q'(p) = \frac{1}{f(Q(p))}.\]

밀도가 낮은 곳(꼬리)에서는 확률이 조금 변해도 분위수가 크게 움직입니다. 이 사실이 표본 분위수의 분산 공식 \(\frac{p(1-p)}{nf(\xi_p)^2}\)(응통7)의 핵심이고, 꼬리 분위수의 추정이 어려운 이유입니다(응통12 2.2절).

예제 2.4.2

표준정규분포에서 \(p = 0.5\)와 \(p = 0.975\)의 분위수 함수 기울기 \(Q'(p)\)를 구하세요.

풀이. \(Q(0.5) = 0\), \(\phi(0) = 0.399\), \(Q'(0.5) = 2.51\). \(Q(0.975) = 1.96\), \(\phi(1.96) = 0.0584\), \(Q'(0.975) = 17.1\). 꼬리에서는 확률 0.01의 변화가 분위수를 약 0.17 움직여, 가운데(약 0.025)보다 7배 민감합니다.

요약
  1. 음함수 미분: 양변을 미분하고 \(dy/dx\)에 대해 풉니다.
  2. 역함수의 도함수 \(g'(y) = 1/f'(g(y))\).
  3. 분위수 함수의 기울기 = 그 점 밀도의 역수.

2.4.4연습문제

기본

  1. \(xy + y^3 = 2\)에서 점 \((1, 1)\)의 \(dy/dx\)를 구하세요.
    답

    \(y + xy' + 3y^2y' = 0\), \(y' = -y/(x + 3y^2) = -1/4\).

응용

  1. 지수분포(비율 \(\lambda\))의 분위수 함수를 직접 구하고, 도함수가 \(1/f(Q(p))\)와 같음을 확인하세요.
    답

    \(F(x) = 1 - e^{-\lambda x} = p\)에서 \(Q(p) = -\ln(1 - p)/\lambda\), \(Q'(p) = \frac{1}{\lambda(1-p)}\). 한편 \(f(Q(p)) = \lambda e^{-\lambda Q(p)} = \lambda(1 - p)\)이라 역수가 같습니다.
