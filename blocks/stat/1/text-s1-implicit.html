음함수 미분과 역함수 미분

본문

표준정규분포의 97.5% 분위수는 1.96이다. 그런데 이 값은 \(\Phi(z) = 0.975\)를 만족하는 \(z\)일 뿐, \(z\)를 \(p\)의 식으로 풀어 쓸 수는 없다. 그래도 "\(p\)가 조금 변하면 분위수가 얼마나 변하는가"는 구할 수 있을까?

먼저 알아야 할 것연쇄법칙(2.1절)과 분위수의 존재(1.2절)를 쓴다.

2.4.1음함수 미분

처음 질문의 해법은 식을 풀지 않고 양변을 미분하는 것이다. 더 단순한 예부터 보자. 원 \(x^2 + y^2 = 1\)은 \(y\)를 \(x\)의 식 하나로 쓸 수 없지만, 위쪽 반원 근처에서 \(y\)를 \(x\)의 함수로 보고 양변을 \(x\)로 미분할 수 있다. \(y^2\)은 연쇄법칙으로 \(2y\frac{dy}{dx}\)가 되므로 \(2x + 2y\frac{dy}{dx} = 0\)이고, 따라서 \(\frac{dy}{dx} = -\frac xy\)이다. 위쪽 반원 \(y = \sqrt{1 - x^2}\)을 직접 미분한 결과와 같다.

일반적으로 \(x\)와 \(y\)가 \(F(x, y) = 0\)으로 묶여 있으면, \(y\)를 \(x\)의 함수로 보고 양변을 \(x\)로 미분한다. \(y\)가 들어간 항에는 연쇄법칙으로 \(dy/dx\)가 곱해지므로, 나온 식을 \(dy/dx\)에 대해 풀면 된다.

2.4.2역함수의 도함수

분위수 함수는 누적분포함수의 역함수이다. 그래서 역함수의 도함수를 알면 된다.

정리 2.4.1

\(f\)가 미분 가능하고 순증가(또는 순감소)이며 \(f'(x) \ne 0\)이면, 역함수 \(g = f^{-1}\)은 \(y = f(x)\)에서 미분 가능하고 \(g'(y) = \dfrac{1}{f'(x)} = \dfrac{1}{f'(g(y))}\)이다.

증명.\(f(g(y)) = y\)의 양변을 \(y\)로 미분하면 연쇄법칙으로 \(f'(g(y))\,g'(y) = 1\)이다. ∎

그래프로 보면 역함수는 \(y = x\)에 대해 뒤집은 것이므로 기울기도 뒤집혀 역수가 된다. 예를 들어 \(y = e^x\)의 역함수 \(\ln y\)의 도함수는 \(1/e^x = 1/y\)이다. 로그의 도함수를 지수의 도함수에서 얻는 방법이다.

2.4.3분위수 함수의 도함수

이제 처음 질문에 답할 수 있다. 연속 분포함수 \(F\)(밀도 \(f\))의 분위수 함수 \(Q(p) = F^{-1}(p)\)에 정리 2.4.1을 쓰면, \(F' = f\)이므로

\[Q'(p) = \frac{1}{f(Q(p))}\]

이다. 다시 말해 분위수 함수의 기울기는 그 점에서 밀도의 역수이다. 밀도가 낮은 꼬리에서는 확률이 조금 변해도 분위수가 크게 움직이는데, 그림 1의 양 끝이 가파른 까닭이다. 이 사실이 표본 분위수의 분산 공식 \(\frac{p(1-p)}{nf(\xi_p)^2}\)(응통7)의 핵심이고, 꼬리 분위수를 추정하기 어려운 이유이다(응통12 2.2절).

예제 2.4.2

표준정규분포에서 \(p = 0.5\)와 \(p = 0.975\)의 분위수 함수 기울기 \(Q'(p)\)를 구하여라.

풀이. \(Q(0.5) = 0\)이고 \(\phi(0) = 0.399\)이므로 \(Q'(0.5) = 2.51\)이다. 한편 \(Q(0.975) = 1.96\)이고 \(\phi(1.96) = 0.0584\)이므로 \(Q'(0.975) = 17.1\)이다. 따라서 꼬리에서는 확률 0.01의 변화가 분위수를 약 0.17 움직여, 가운데의 약 0.025보다 7배 민감하다.

마무리

식을 \(y\)에 대해 풀 수 없어도 양변을 미분하고 \(dy/dx\)에 대해 풀면 기울기를 얻는다. 역함수의 도함수는 원래 도함수의 역수 \(g'(y) = 1/f'(g(y))\)이고, 분위수 함수의 기울기는 그 점의 밀도의 역수이다. 그래서 정규분포의 1.96은 식으로 쓸 수 없어도 \(p\)에 대한 민감도 17.1은 바로 구할 수 있으며, 꼬리 분위수는 가운데보다 훨씬 민감하다.

2.4.4연습문제

기본

  1. \(xy + y^3 = 2\)에서 점 \((1, 1)\)의 \(dy/dx\)를 구하여라.
    답

    \(y + xy' + 3y^2y' = 0\)이므로 \(y' = -y/(x + 3y^2) = -1/4\)이다.

응용

  1. 지수분포(비율 \(\lambda\))의 분위수 함수를 직접 구하고, 도함수가 \(1/f(Q(p))\)와 같음을 확인하여라.
    답

    \(F(x) = 1 - e^{-\lambda x} = p\)에서 \(Q(p) = -\ln(1 - p)/\lambda\)이고 \(Q'(p) = \frac{1}{\lambda(1-p)}\)이다. 한편 \(f(Q(p)) = \lambda e^{-\lambda Q(p)} = \lambda(1 - p)\)이라 역수가 같다.
