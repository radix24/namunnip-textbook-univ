매개변수 곡선과 극좌표

본문

원 \(x^2 + y^2 = 1\)은 \(y = f(x)\) 꼴 함수 하나로 나타낼 수 없다. 하지만 시간 \(t\)에 따라 움직이는 점 \((\cos t, \sin t)\)로 쓰면 한 번에 그려진다. 또 원점 둘레를 도는 곡선은 거리와 각도 \((r, \theta)\)로 쓰는 편이 자연스럽다. 이런 곡선의 접선, 길이, 넓이는 어떻게 구할까?

먼저 알아야 할 것미분과 연쇄법칙(2.1절), 치환적분(3.1절)을 쓴다.

7.1.1매개변수 곡선

곡선을 \(x = f(t)\), \(y = g(t)\)로 쓰면 접선의 기울기는 연쇄법칙으로

\[\frac{dy}{dx} = \frac{dy/dt}{dx/dt}\]

이다(\(dx/dt \ne 0\)일 때). 곡선의 길이는 짧은 조각 \(ds = \sqrt{dx^2 + dy^2}\)를 더해 \(L = \int_a^b\sqrt{f'(t)^2 + g'(t)^2}\,dt\)이다. 예를 들어 반지름 \(R\)인 원 \((R\cos t, R\sin t)\)는 \(\sqrt{R^2\sin^2t + R^2\cos^2t} = R\)이므로, \(0 \le t \le 2\pi\)에서 길이가 \(2\pi R\)이다. 한편 같은 곡선도 매개변수를 여러 방식으로 잡을 수 있다. 예를 들어 \(t\) 대신 \(2t\)를 쓰면 점이 두 배 빠르게 돌지만, 곡선의 모양과 길이는 그대로이다. 그러므로 길이는 매개변수의 선택과 무관한 곡선 자체의 성질이다.

7.1.2극좌표

극좌표 \((r, \theta)\)와 직교좌표는 \(x = r\cos\theta\), \(y = r\sin\theta\)로 이어진다. 그러므로 극좌표 곡선 \(r = f(\theta)\)는 \(\theta\)를 매개변수로 한 곡선이다. 원점과 곡선이 둘러싼 넓이는 중심각 \(d\theta\)인 가는 부채꼴 넓이 \(\frac12r^2d\theta\)를 더해

\[A = \frac12\int_\alpha^\beta f(\theta)^2\,d\theta\]

로 구한다. 길이는 \(L = \int\sqrt{f(\theta)^2 + f'(\theta)^2}\,d\theta\)이다. 이 식은 매개변수 곡선의 길이 공식에 \(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)를 넣고 \(x'^2 + y'^2 = f^2 + f'^2\)으로 정리하면 나온다. 그런데 넓이를 구할 때는 곡선이 원점 둘레를 한 번만 도는 \(\theta\) 범위를 골라야 한다. 같은 영역을 두 번 지나면 넓이가 두 배로 계산되기 때문이다. 극좌표는 통계에서도 쓰인다. 정규분포의 규격화 상수를 구할 때 \(\int\!\!\int e^{-(x^2 + y^2)/2}dx\,dy\)를 극좌표로 바꾸어 \(2\pi\)를 얻는다.

예제 7.1.1

카디오이드 \(r = 1 + \cos\theta\)가 둘러싼 넓이를 구하여라.

풀이. \(A = \frac12\int_0^{2\pi}(1 + \cos\theta)^2d\theta = \frac12\int_0^{2\pi}(1 + 2\cos\theta + \cos^2\theta)\,d\theta\)이다. \(\int_0^{2\pi}\cos\theta\,d\theta = 0\), \(\int_0^{2\pi}\cos^2\theta\,d\theta = \pi\)이므로 \(A = \frac12(2\pi + \pi) = \frac{3\pi}2\)이다.

마무리

매개변수 곡선의 기울기는 \((dy/dt)/(dx/dt)\), 길이는 \(\int\sqrt{x'^2 + y'^2}\,dt\)이다. 극좌표 곡선 \(r = f(\theta)\)가 둘러싼 넓이는 가는 부채꼴을 더한 \(\frac12\int f^2d\theta\)이고, 길이는 \(\int\sqrt{f^2 + f'^2}\,d\theta\)이다.

7.1.3연습문제

기본

  1. 곡선 \(x = t^2\), \(y = t^3\)의 \(t = 1\)에서 접선의 기울기는?
    답

    \(3t^2/2t = 3/2\).

응용

  1. 장미 곡선 \(r = \cos2\theta\)의 꽃잎 하나의 넓이를 구하여라.
    답

    \(\frac12\int_{-\pi/4}^{\pi/4}\cos^22\theta\,d\theta = \pi/8\).
