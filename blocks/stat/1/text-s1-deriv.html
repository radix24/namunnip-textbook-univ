지수와 로그를 포함한 함수의 미분

본문
이 절에서 배울 것
  • 지수·로그 함수의 도함수와 연쇄법칙을 쓴다.
  • 로그 미분법과 로피탈 법칙을 쓴다.
먼저 알아야 할 것
  • 고교 수학II 다항함수의 미분, 1.1절의 기본 극한.

가능도 함수는 지수와 로그투성이

정규분포 밀도 \(e^{-(x-\mu)^2/2}\), 로그가능도 \(\sum\log f(x_i)\)처럼 통계의 식에는 지수와 로그가 계속 나옵니다. 이들을 자유롭게 미분할 수 있어야 최대가능도 추정(2.2절)을 할 수 있습니다.

2.1.1기본 도함수

함수도함수
\(e^x\)\(e^x\)
\(a^x\)\(a^x\log a\)
\(\log x\) (자연로그)\(1/x\)
\(x^r\)\(rx^{r-1}\)

\((e^x)' = e^x\)는 \(\lim_{h\to0}\frac{e^{x+h} - e^x}{h} = e^x\lim\frac{e^h - 1}{h} = e^x\)에서 나옵니다. 통계에서 \(\log\)는 자연로그입니다.

2.1.2연쇄법칙

정리 2.1.1 (연쇄법칙)

\(\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)\).

예: \(\frac{d}{dx}e^{-x^2/2} = -xe^{-x^2/2}\). 정규 밀도 \(\phi(x)\)에 대해 \(\phi'(x) = -x\phi(x)\)라는 유용한 식입니다.

로그 미분법: 곱과 거듭제곱이 많으면 로그를 취한 뒤 미분합니다. \(y = x^x\)이면 \(\log y = x\log x\), \(y'/y = \log x + 1\), \(y' = x^x(\log x + 1)\).

2.1.3로피탈 법칙

정리 2.1.2

\(\lim f = \lim g = 0\)(또는 둘 다 \(\pm\infty\))이고 \(\lim f'/g'\)이 있으면 \(\lim\frac fg = \lim\frac{f'}{g'}\).

예제 2.1.3

(가) \(\frac{d}{dp}[k\log p + (n-k)\log(1-p)]\) (나) \(\lim_{x\to\infty}\frac{x^2}{e^x}\)

풀이. (가) \(\frac kp - \frac{n-k}{1-p}\). 베르누이 로그가능도의 점수함수입니다(2.2절). (나) 로피탈을 두 번: \(\frac{2x}{e^x} \to \frac{2}{e^x} \to 0\).

요약
  1. \((e^x)' = e^x\), \((\log x)' = 1/x\).
  2. 연쇄법칙, 로그 미분법.
  3. \(0/0\), \(\infty/\infty\)는 로피탈 법칙.

2.1.4연습문제

기본

  1. \(\frac{d}{d\mu}\left[-\frac{(x - \mu)^2}{2\sigma^2}\right]\)은?
    답

    \(\frac{x - \mu}{\sigma^2}\).

  2. \(f(x) = \frac{1}{1 + e^{-x}}\)(로지스틱 함수)의 도함수가 \(f(1-f)\)임을 보이세요.
    답

    \(f' = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}}\cdot\frac{e^{-x}}{1 + e^{-x}} = f(1 - f)\).
