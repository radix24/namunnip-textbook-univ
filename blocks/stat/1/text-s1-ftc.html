미적분학의 기본정리와 라이프니츠 규칙

본문

\(X\)가 0과 1 사이에서 고르게 분포하면 \(Y = X^2\)은 어떤 분포를 따를까? 밀도를 바로 구하기는 어렵지만 "\(Y \le y\)일 확률"은 쉽게 구해진다. 그 확률에서 밀도로 건너가는 다리는 무엇일까?

먼저 알아야 할 것정적분(3.1절)과 연쇄법칙(2.1절)을 쓴다.

3.4.1분포함수와 밀도를 잇는 다리

확률변수 \(X\)의 분포함수 \(F(x) = P(X \le x) = \int_{-\infty}^xf(t)dt\)는 위끝이 변수인 적분이다. 처음 질문처럼 변수를 변환하거나 순서통계량의 분포를 구할 때는 먼저 분포함수를 구하고, 그것을 미분해 밀도를 얻는 경우가 많다. 그러므로 적분을 미분하는 규칙이 필요하다.

3.4.2기본정리

정리 3.4.1 (미적분학의 기본정리)

\(f\)가 연속이면 \(G(x) = \int_a^xf(t)\,dt\)는 미분 가능하고 \(G'(x) = f(x)\)이다.

그림 1로 보면 이유가 드러난다. \(G(x + h) - G(x)\)는 폭 \(h\), 높이 약 \(f(x)\)인 띠의 넓이이다. 따라서 \(\frac{G(x+h) - G(x)}{h} \approx f(x)\)이고, \(h \to 0\)이면 띠의 높이가 정확히 \(f(x)\)가 된다. 위끝이 \(x\)의 함수 \(u(x)\)이면 연쇄법칙을 더해 \(\frac{d}{dx}\int_a^{u(x)}f(t)dt = f(u(x))u'(x)\)이다.

분포함수에 적용하면 \(F'(x) = f(x)\), 곧 분포함수를 미분하면 밀도이다. 이것이 처음 질문의 다리이다.

예제 3.4.2

\(X \sim U(0, 1)\)이면 \(Y = X^2\)의 밀도는 무엇인가? 분포함수를 구한 뒤 미분하여라.

풀이. \(0 < y < 1\)에서 \(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \int_0^{\sqrt y}1\,dt = \sqrt y\)이다. 이것을 미분하면 \(f_Y(y) = \frac{1}{2\sqrt y}\)이다. 기본정리의 연쇄법칙판으로 계산해도 \(1 \cdot \frac{d}{dy}\sqrt y\)로 같다. 밀도가 0 근처에서 커지는 것은 \(X\)가 0 근처일 때 \(X^2\)이 0 쪽으로 몰리기 때문이다.

3.4.3라이프니츠 규칙

그런데 적분 끝뿐 아니라 피적분 함수에도 변수가 들어 있으면 어떻게 할까? 이때는 두 효과를 더한다.

정리 3.4.3 (라이프니츠 규칙)

\(g\)와 \(\partial g/\partial x\)가 연속이면 \(\dfrac{d}{dx}\int_{a(x)}^{b(x)}g(x, t)\,dt = g(x, b(x))b'(x) - g(x, a(x))a'(x) + \int_{a(x)}^{b(x)}\dfrac{\partial g}{\partial x}(x, t)\,dt\)이다.

앞의 두 항은 끝점이 움직이는 효과로, 그림 1의 띠를 위끝과 아래끝에서 각각 더하고 빼는 것이다. 마지막 항은 피적분 함수 자체가 변하는 효과이며, 적분 기호 안에서 미분한다. 이 마지막 항은 적률생성함수를 미분해 적률을 얻을 때(4.3절)와 가능도를 미분할 때 쓰인다.

마무리

위끝이 변수인 적분의 도함수는 피적분 함수의 값, 곧 \(\frac{d}{dx}\int_a^xf = f(x)\)이고, 위끝이 \(u(x)\)이면 \(f(u(x))u'(x)\)이다. 그래서 분포함수를 미분하면 밀도가 되며, \(X \sim U(0,1)\)일 때 \(Y = X^2\)의 분포함수 \(\sqrt y\)를 미분하면 밀도 \(1/(2\sqrt y)\)를 얻는다. 끝점과 피적분 함수가 모두 변하면 라이프니츠 규칙으로 끝점 효과와 적분 안의 편미분을 더한다.

3.4.4연습문제

기본

  1. \(\dfrac{d}{dx}\int_0^{x^2}e^{-t}dt\)를 구하여라.
    답

    \(e^{-x^2} \cdot 2x\)이다.

응용

  1. \(X_1, \ldots, X_n\)이 독립인 \(U(0, 1)\)일 때 최댓값 \(M\)의 밀도를 분포함수로 구하여라.
    답

    \(P(M \le m) = P(\text{모두} \le m) = m^n\)이고, 미분하면 \(nm^{n-1}\)(\(0 < m < 1\))이다. 응통6의 순서통계량 분포이다.
