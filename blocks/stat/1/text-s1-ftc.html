미적분학의 기본정리와 라이프니츠 규칙

본문
이 절에서 배울 것
  • 적분의 위끝이 변수인 함수를 미분한다(미적분학의 기본정리).
  • 분포함수를 미분해 밀도를 얻는다.
  • 적분 끝과 피적분 함수에 모두 변수가 있을 때 라이프니츠 규칙을 쓴다.
먼저 알아야 할 것
  • 정적분 (3.1절), 연쇄법칙 (2.1절).

분포함수와 밀도를 잇는 다리

확률변수 \(X\)의 분포함수 \(F(x) = P(X \le x) = \int_{-\infty}^xf(t)dt\)는 위끝이 변수인 적분입니다. 변수 변환이나 순서통계량의 분포를 구할 때는 먼저 분포함수를 구하고 그것을 미분해 밀도를 얻는 경우가 많습니다. 이때 "적분을 미분하는" 규칙이 필요합니다.

3.4.1기본정리

정리 3.4.1 (미적분학의 기본정리)

\(f\)가 연속이면 \(G(x) = \int_a^xf(t)\,dt\)는 미분 가능하고 \(G'(x) = f(x)\).

그림으로 보면 \(G(x + h) - G(x)\)는 폭 \(h\), 높이 약 \(f(x)\)인 띠의 넓이라 \(\frac{G(x+h) - G(x)}{h} \to f(x)\)입니다. 위끝이 \(x\)의 함수 \(u(x)\)이면 연쇄법칙으로 \(\frac{d}{dx}\int_a^{u(x)}f(t)dt = f(u(x))u'(x)\)입니다.

3.4.2라이프니츠 규칙

정리 3.4.2

\(\dfrac{d}{dx}\int_{a(x)}^{b(x)}g(x, t)\,dt = g(x, b(x))b'(x) - g(x, a(x))a'(x) + \int_{a(x)}^{b(x)}\dfrac{\partial g}{\partial x}(x, t)\,dt\) (\(g\)와 \(\partial g/\partial x\)가 연속일 때).

끝점이 움직이는 효과 두 가지와 피적분 함수 자체가 변하는 효과를 더한 것입니다. 적분 기호 안에서 미분하는 마지막 항은 적률생성함수를 미분해 적률을 얻을 때(4.3절)와 가능도를 미분할 때 쓰입니다.

예제 3.4.3

\(X \sim U(0, 1)\)이면 \(Y = X^2\)의 밀도는? 분포함수를 구한 뒤 미분하세요.

풀이. \(0 < y < 1\)에서 \(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \int_0^{\sqrt y}1\,dt = \sqrt y\). 미분하면 \(f_Y(y) = \frac{1}{2\sqrt y}\). 기본정리의 연쇄법칙판으로는 \(1 \cdot \frac{d}{dy}\sqrt y\)로 같은 결과입니다.

요약
  1. \(\frac{d}{dx}\int_a^xf = f(x)\), 위끝이 \(u(x)\)이면 \(f(u(x))u'(x)\).
  2. 분포함수를 미분해 밀도를 얻습니다.
  3. 라이프니츠: 끝점 효과 + 적분 안의 편미분.

3.4.4연습문제

기본

  1. \(\dfrac{d}{dx}\int_0^{x^2}e^{-t}dt\)를 구하세요.
    답

    \(e^{-x^2} \cdot 2x\).

응용

  1. \(X_1, \ldots, X_n\)이 독립인 \(U(0, 1)\)일 때 최댓값 \(M\)의 밀도를 분포함수로 구하세요.
    답

    \(P(M \le m) = P(\text{모두} \le m) = m^n\), 미분하면 \(nm^{n-1}\)(\(0 < m < 1\)). 응통6의 순서통계량 분포입니다.
