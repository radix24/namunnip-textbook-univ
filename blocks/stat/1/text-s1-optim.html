최적화와 최대가능도 추정

본문

동전을 10번 던져 앞면이 7번 나왔다. 이 동전의 앞면 확률 \(p\)를 얼마로 추정하는 것이 좋을까? 대부분 0.7이라고 답하겠지만, 그 답을 원리로 설명할 수 있을까?

먼저 알아야 할 것지수·로그 미분(2.1절), 고등학교 미적분의 함수의 극대·극소와 이계도함수, 확률과 통계의 독립 사건의 곱셈정리를 쓴다.

2.2.1자료를 가장 잘 설명하는 모수

한 가지 원리는 지금 본 결과가 나올 확률을 가장 크게 만드는 \(p\)를 고르자는 것이다. \(p = 0.5\)라면 10번 중 7번 앞면이 나올 확률은 약 0.117이다. 그런데 \(p = 0.7\)이면 약 0.267로 올라가고, \(p = 0.9\)이면 약 0.057로 다시 내려간다. 따라서 그림 1처럼 0.7일 때 관측 결과가 가장 그럴듯하다. 이렇게 고르는 방법이 최대가능도 추정이고, "가장 크게 만드는 값"을 찾는 계산은 미분을 이용한 최적화이다.

2.2.2극값 판정과 최댓값

정리 2.2.1

미분가능한 함수 \(f\)가 구간 안쪽의 점 \(c\)에서 극대 또는 극소이면 \(f'(c) = 0\)이다(일계 조건). 또 \(f'(c) = 0\)이고 \(f''(c) < 0\)이면 극대, \(f''(c) > 0\)이면 극소이다(이계 조건).

이계 조건은 고등학교에서 배운 그래프의 볼록성과 같다. \(f'' < 0\)이면 위로 볼록한 꼭대기 모양이고, \(f'' > 0\)이면 아래로 볼록한 골짜기 모양이다. 한편 구간 전체의 최댓값은 \(f' = 0\)인 점들과 구간 끝점에서의 값을 모두 비교해 찾는다. 특히 \(f''\)이 구간 전체에서 음수이면 그래프가 산 하나 모양이라 \(f' = 0\)인 점이 하나뿐이고, 그곳이 곧 최댓값이다. 통계에서 쓰는 로그가능도는 이런 모양인 경우가 많아 편리하다.

2.2.3가능도와 최대가능도

앞면 확률이 \(p\)인 동전을 \(n\)번 던지면 각 시행은 독립이다. 그러므로 특정한 순서로 앞면 \(k\)번, 뒷면 \(n - k\)번이 나올 확률은 곱셈정리에 따라 \(p^k(1-p)^{n-k}\)이다. 이 값을 자료는 고정하고 \(p\)의 함수로 본 것을 가능도 \(L(p)\)라 한다. 순서를 무시한 확률 \(\binom nk p^k(1-p)^{n-k}\)을 써도 \(\binom nk\)는 \(p\)와 무관한 상수라서 최댓값의 위치는 같다.

그런데 \(L(p)\)는 곱이라 미분이 번거롭다. 그래서 로그를 취한 로그가능도 \(\ell(p) = \ln L(p)\)를 쓴다. \(\ln\)은 증가함수이므로 \(L\)이 가장 큰 곳과 \(\ln L\)이 가장 큰 곳이 같고, 곱이 합으로 바뀌어 미분이 쉬워진다.

예제 2.2.2

\(\ell(p) = k\ln p + (n-k)\ln(1-p)\) (\(0 < p < 1\), \(0 < k < n\))를 최대로 하는 \(p\)를 구하여라.

풀이. 2.1절 예제에서 구한 대로 \(\ell'(p) = \frac kp - \frac{n-k}{1-p}\)이다. 이것을 0으로 두면 \(k(1-p) = (n-k)p\)이고, 정리하면 \(k = np\), 곧 \(\hat p = k/n\)이다. 이계도함수 \(\ell''(p) = -\frac{k}{p^2} - \frac{n-k}{(1-p)^2}\)는 모든 \(p\)에서 음수이므로 이 점이 최댓값이다. 처음 질문의 10번 중 7번이면 \(\hat p = 0.7\)로, 직관과 같은 답이 원리에서 나왔다. 모수 위의 모자 기호 \(\hat{\ }\)는 자료로 구한 추정값이라는 표시이다.

예제 2.2.3

대기 시간 \(x_1, \ldots, x_n\)이 서로 독립이고 밀도 \(f(x) = \lambda e^{-\lambda x}\) (\(x > 0\))를 따른다(지수분포). \(\lambda\)의 최대가능도 추정값을 구하여라.

풀이. 연속형 자료의 가능도는 확률 대신 밀도를 곱한다. 따라서 \(L(\lambda) = \prod_{i=1}^n\lambda e^{-\lambda x_i} = \lambda^ne^{-\lambda\sum x_i}\)이다. 로그를 취하면 \(\ell(\lambda) = n\ln\lambda - \lambda\sum x_i\)이고, \(\ell'(\lambda) = \frac n\lambda - \sum x_i = 0\)에서 \(\hat\lambda = \frac{n}{\sum x_i} = \frac{1}{\bar x}\)이다. \(\ell''(\lambda) = -n/\lambda^2 < 0\)이므로 최대이다. 가령 평균 대기 시간이 5분이면 \(\hat\lambda = 0.2\), 곧 분당 0.2명이 오는 속도이다.

흔한 실수가능도 \(L(p)\)는 "\(p\)가 참일 확률"이 아니다. \(L(0.7) = 0.267\)은 \(p = 0.7\)일 때 이 자료가 나올 확률이지, \(p\)가 0.7일 확률이 아니다. 그래서 여러 \(p\)의 가능도를 더해도 1이 되지 않는다. 모수에 확률을 주는 방법은 베이즈 통계(응통21)에서 다룬다.
마무리

극값의 후보는 \(f' = 0\)인 점이고, \(f''\)의 부호로 극대와 극소를 가르며, 최댓값은 끝점과 비교해 찾는다. 가능도는 자료를 고정하고 모수의 함수로 본 확률이나 밀도의 곱이며, 로그가능도를 최대로 하는 값이 최대가능도 추정값이다. 10번 중 7번 앞면이면 \(\hat p = k/n = 0.7\)이 원리에서 나오고, 지수분포 자료에서는 \(\hat\lambda = 1/\bar x\)이다.

2.2.4연습문제

기본

  1. 동전을 20번 던져 앞면이 5번 나왔을 때 \(p\)의 최대가능도 추정값과, 그 값에서 로그가능도의 이계도함수 부호를 구하여라.
    답

    \(\hat p = 0.25\)이다. \(\ell''(0.25) = -5/0.0625 - 15/0.5625 \approx -106.7 < 0\)이므로 최대이다.

응용

  1. 포아송 자료(\(f(x) = e^{-\lambda}\lambda^x/x!\), \(x = 0, 1, 2, \ldots\))의 \(\lambda\) 최대가능도 추정값을 구하여라.
    답

    \(\ell(\lambda) = -n\lambda + (\sum x_i)\ln\lambda - \sum\ln x_i!\)이고, \(\ell' = -n + \sum x_i/\lambda = 0\)에서 \(\hat\lambda = \bar x\)이다.
