적분과 확률 밀도 단원 마무리 연습

문제 7 · 계산·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. 문제 끝의 [번호]는 다시 볼 절이다.

  1. 계산\(\displaystyle\int_0^1 x e^{x^2}\,dx\)를 구하여라. [03-01]

    힌트 1

    \(u = x^2\)으로 치환하면 \(du = 2x\,dx\)이다.

    힌트 2

    적분 구간도 \(u\)에 맞게 \(0\)부터 \(1\)까지로 바뀐다.

    풀이

    \(u = x^2\)이면 \(x\,dx = du/2\)이고, \(x = 0 \to u = 0\), \(x = 1 \to u = 1\)이다. \(\displaystyle\int_0^1 x e^{x^2}dx = \frac12\int_0^1 e^u\,du = \frac{e-1}{2} \approx 0.859\)이다.

  2. 계산\(\displaystyle\int_0^1 x e^{x}\,dx\)를 부분적분으로 구하여라. [03-01]

    힌트 1

    \(\int u\,dv = uv - \int v\,du\)에서 미분하면 간단해지는 쪽을 \(u\)로 잡는다.

    힌트 2

    \(u = x\), \(dv = e^x dx\)로 놓아라.

    풀이

    \(u = x\), \(dv = e^x dx\)이면 \(du = dx\), \(v = e^x\)이다. \(\displaystyle\int_0^1 xe^x dx = \big[xe^x\big]_0^1 - \int_0^1 e^x dx = e - (e - 1) = 1\)이다.

  3. 계산\(f(x) = c\,e^{-2x}\) (\(x \ge 0\)), 그 밖에서 0인 함수가 확률밀도함수가 되도록 \(c\)를 정하고, \(P(X > 1)\)을 구하여라. [03-02]

    힌트 1

    밀도함수는 전체 적분이 1이어야 한다. \(\int_0^\infty e^{-2x}dx = \lim_{b\to\infty}\int_0^b e^{-2x}dx\)이다.

    힌트 2

    \(\int_0^b e^{-2x}dx = (1 - e^{-2b})/2\)이다.

    풀이

    \(\displaystyle\int_0^\infty e^{-2x}dx = \lim_{b\to\infty}\frac{1 - e^{-2b}}{2} = \frac12\)이므로 \(c = 2\)입니다(지수분포, 비율 2).

    \(P(X > 1) = \displaystyle\int_1^\infty 2e^{-2x}dx = e^{-2} \approx 0.135\)이다.

  4. 판단\(f(x) = 1/x^2\) (\(x \ge 1\))은 밀도함수인가요? 맞다면 이 분포의 기댓값 \(\int_1^\infty x f(x)\,dx\)가 있는지 판단하여라. [03-02]

    힌트 1

    \(\int_1^\infty x^{-p}dx\)는 \(p > 1\)일 때만 수렴한다.

    힌트 2

    기댓값의 적분은 \(\int_1^\infty \frac1x\,dx\)가 된다.

    풀이

    \(f \ge 0\)이고 \(\displaystyle\int_1^\infty x^{-2}dx = \lim_{b\to\infty}(1 - 1/b) = 1\)이므로 밀도함수이다.

    그러나 \(\displaystyle\int_1^\infty x\cdot x^{-2}dx = \lim_{b\to\infty}\ln b = \infty\)이므로 기댓값이 없습니다(무한대). 밀도함수라고 해서 평균이 항상 있는 것은 아니다. 이런 두꺼운 꼬리 분포에서는 표본평균이 안정되지 않으므로 중앙값 같은 다른 요약을 쓴다.

  5. 계산\(\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}dx\), \(\Gamma(\alpha+1) = \alpha\Gamma(\alpha)\), \(\Gamma(1/2) = \sqrt\pi\)를 써서 \(\Gamma(5)\), \(\Gamma(5/2)\), \(\displaystyle\int_0^\infty x^3e^{-2x}dx\)를 구하여라. [03-03]

    힌트 1

    자연수 \(n\)에서 \(\Gamma(n) = (n-1)!\)이다.

    힌트 2

    마지막 적분은 \(u = 2x\)로 치환하면 감마 함수가 된다.

    풀이

    \(\Gamma(5) = 4! = 24\). \(\Gamma(5/2) = \frac32\cdot\frac12\Gamma(\frac12) = \frac{3\sqrt\pi}{4} \approx 1.329\).

    \(u = 2x\)이면 \(\displaystyle\int_0^\infty x^3e^{-2x}dx = \int_0^\infty \frac{u^3}{8}e^{-u}\frac{du}{2} = \frac{\Gamma(4)}{16} = \frac{6}{16} = \frac38\)이다. 일반적으로 \(\int_0^\infty x^{\alpha-1}e^{-\beta x}dx = \Gamma(\alpha)/\beta^\alpha\)이다.

  6. 계산\(f(x) = c\,x^2(1-x)^3\) (\(0 < x < 1\))이 밀도함수가 되도록 \(c\)를 베타 함수로 구하여라. \(B(a, b) = \int_0^1 x^{a-1}(1-x)^{b-1}dx = \Gamma(a)\Gamma(b)/\Gamma(a+b)\)이다. [03-03]

    힌트 1

    \(x^2(1-x)^3\)은 \(a = 3\), \(b = 4\)인 경우이다.

    힌트 2

    \(\Gamma(3) = 2\), \(\Gamma(4) = 6\), \(\Gamma(7) = 720\)이다.

    풀이

    \(\displaystyle\int_0^1 x^2(1-x)^3dx = B(3, 4) = \frac{2\cdot6}{720} = \frac{1}{60}\)이므로 \(c = 60\)이다. 이 분포는 베타분포 \(\mathrm{Beta}(3, 4)\)이며, 전개해서 적분하는 것보다 베타 함수를 쓰는 편이 훨씬 빠르다.

  7. 계산\(X \sim\) 지수분포(비율 1)일 때 \(Y = \sqrt X\)의 밀도를 분포함수를 미분해 구하여라. [03-04]

    힌트 1

    \(P(Y \le y) = P(X \le y^2)\).

    힌트 2

    \(\frac{d}{dy}(1 - e^{-y^2})\).

    풀이

    \(F_Y(y) = 1 - e^{-y^2}\)(\(y > 0\)), \(f_Y(y) = 2ye^{-y^2}\).

    이것은 레일리 분포의 한 형태이다. 적분 위끝이 \(y^2\)이라 연쇄법칙으로 \(2y\)가 곱해졌다.
