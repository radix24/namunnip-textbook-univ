라그랑주 승수법

본문

조사원이 모두 \(n\)명을 조사할 수 있을 때 여러 지역에 몇 명씩 나누어야 추정이 가장 정밀할까? 범주별 확률의 합이 1이어야 할 때 가능도를 가장 크게 하는 확률은 무엇일까? 지켜야 할 조건이 붙은 최적화는 어떻게 풀까?

먼저 알아야 할 것편미분과 기울기 벡터(5.1절), 고등학교 미적분의 일변수 함수의 최대·최소를 쓴다.

5.3.1대입법으로 먼저 풀기

처음 질문들은 변수들 사이에 지켜야 할 등식이 있는 최적화이다. 가장 단순한 예부터 고등학교 방법으로 풀어 보자.

예제 5.3.1

\(x + y = 10\)일 때 \(xy\)의 최댓값을 구하여라.

풀이. 조건에서 \(y = 10 - x\)를 얻어 대입하면 \(xy = x(10 - x) = -x^2 + 10x\)라는 일변수 이차함수가 된다. 이것은 \(-(x - 5)^2 + 25\)이므로 \(x = 5\), 따라서 \(y = 5\)에서 최댓값 25이다.

다시 말해 조건식을 한 변수에 대해 풀 수 있으면 대입해 변수를 하나 줄이면 된다. 하지만 조건이 \(x^2 + xy + y^4 = 3\)처럼 복잡하거나 변수가 많으면 대입이 어렵다. 그럴 때 쓰는 일반적인 방법이 라그랑주 승수법이다.

5.3.2등고선과 조건 곡선이 접한다

예제 5.3.1을 그림 1로 생각해 보자. \(xy = k\)인 점들, 곧 등고선은 쌍곡선이고, \(k\)가 클수록 원점에서 멀어진다. 조건 \(x + y = 10\)은 직선이다. 직선 위를 따라 걸으면서 \(xy\)의 값을 보면, 직선이 등고선을 가로지르는 곳에서는 한쪽으로 더 가면 값이 커지므로 최대가 아니다. 따라서 최댓값은 직선이 어떤 등고선과 딱 접하는 곳, 여기서는 \(xy = 25\)와 만나는 \((5, 5)\)에서 생긴다.

두 곡선이 접한다는 것은 그 점에서 두 곡선의 수직 방향이 같다는 뜻이다. 5.1절에서 기울기 벡터는 등고선에 수직이었다. 그러므로 접점에서는 \(f\)의 기울기 벡터와 조건식 \(g\)의 기울기 벡터가 같은 직선 위에 있어, 한쪽이 다른 쪽의 몇 배이다. 그 배수를 \(\lambda\)로 쓴다.

정리 5.3.2 (라그랑주 승수법)

조건 \(g(x, y) = c\) 위에서 \(f(x, y)\)가 점 \((a, b)\)에서 최대 또는 최소이고 그 점에서 \(\nabla g \ne (0, 0)\)이면, 어떤 수 \(\lambda\)에 대해 \(f_x = \lambda g_x\), \(f_y = \lambda g_y\)가 성립한다. 이 두 식과 조건 \(g(a, b) = c\)를 연립해 \(a, b, \lambda\)를 구한다.

외우기 쉽게 \(L = f - \lambda(g - c)\)라는 함수를 만들어 \(x\), \(y\), \(\lambda\)로 각각 편미분해 0으로 두어도 같은 연립방정식이 나온다. \(\lambda\)로 미분하면 조건식이 되기 때문이다. 이 \(\lambda\)를 라그랑주 승수라 한다. 변수가 셋 이상이어도 편미분식이 늘어날 뿐 방법은 같다.

예제 5.3.1에 적용해 보자. \(f = xy\), \(g = x + y\)이므로 \(f_x = y\), \(f_y = x\), \(g_x = g_y = 1\)이다. \(y = \lambda\), \(x = \lambda\), \(x + y = 10\)을 연립하면 \(x = y = \lambda = 5\)이고, 대입법과 같은 답이다.

예제 5.3.3

범주가 \(k\)개인 자료에서 관측 수가 \(n_1, \ldots, n_k\) (합 \(n\))이다. 조건 \(p_1 + \cdots + p_k = 1\) 아래 로그가능도 \(\sum_j n_j\log p_j\)를 최대로 하는 \(p_j\)를 구하여라.

풀이. 변수가 \(k\)개라 대입법은 번거롭다. \(L = \sum n_j\log p_j - \lambda(\sum p_j - 1)\)을 각 \(p_j\)로 편미분하면 \(n_j/p_j - \lambda = 0\), 곧 \(p_j = n_j/\lambda\)이다. 이것을 조건에 넣으면 \(\sum n_j/\lambda = 1\)에서 \(\lambda = n\)이므로 \(\hat p_j = n_j/n\)이다. 다시 말해 각 범주의 관측 비율이 최대가능도 추정값이라는, 직관과 맞는 결과이다. 처음 질문의 지역별 배분도 같은 방법으로 풀리며, 연습문제 2가 그것이다.

흔한 실수라그랑주 조건을 만족하는 점은 최댓값이나 최솟값의 후보일 뿐이다. 후보가 여럿이면 각 점에서 \(f\)의 값을 비교하고, 조건 곡선에 끝이 있으면 끝점도 확인해야 한다. 예제 5.3.1에서 \(x, y\)에 제한이 없으면 \(xy\)는 최솟값이 없다. \(x\)가 아주 크면 \(y\)는 아주 작은 음수가 되기 때문이다.
마무리

조건식을 한 변수에 대해 풀 수 있으면 대입해 일변수 문제로 바꾼다. 일반적으로는 최적점에서 목적함수의 등고선과 조건 곡선이 접하므로 \(\nabla f = \lambda\nabla g\)와 조건식을 연립한다. 이 방법으로 확률의 합이 1이라는 조건 아래 다항분포의 최대가능도 추정값이 관측 비율임을 얻고, 조사원 \(n\)명을 지역에 나누는 네이만 배분도 같은 방법으로 얻는다.

5.3.4연습문제

기본

  1. \(2x + y = 8\)일 때 \(x^2 + y^2\)의 최솟값을 대입법과 라그랑주 승수법으로 각각 구하여라.
    답

    대입하면 \(x^2 + (8 - 2x)^2 = 5x^2 - 32x + 64\)는 \(x = 3.2\)에서 최소이고 \(y = 1.6\), 값은 12.8이다. 라그랑주 승수법으로는 \(2x = 2\lambda\), \(2y = \lambda\)에서 \(x = 2y\)이고, 조건에 넣어 \(y = 1.6\)으로 같다. 원점에서 직선까지 거리의 제곱이다.

응용

  1. \(n_1 + n_2 = n\) 아래 \(\frac{a^2}{n_1} + \frac{b^2}{n_2}\) (\(a, b > 0\))를 최소화하는 배분을 구하여라.
    답

    \(-a^2/n_1^2 = \lambda\), \(-b^2/n_2^2 = \lambda\)에서 \(n_1/n_2 = a/b\), 곧 \(n_1 = \frac{a}{a+b}n\)이다. 층의 표준편차에 비례해 배분하는 네이만 배분의 꼴이다.
