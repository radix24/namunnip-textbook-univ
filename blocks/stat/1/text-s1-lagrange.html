  • 기울기 벡터 (5.1절).

예산이 정해져 있을 때

조사 표본 \(n\)명을 층에 나누어 분산을 최소화하거나(응통8 3.2절), 확률의 합이 1이라는 조건 아래 가능도를 최대화하는 문제처럼 제약이 붙은 최적화가 많습니다.

5.3.1방법

정리 5.3.1

\(g(\mathbf x) = c\) 위에서 \(f\)의 극값이 \(\mathbf a\)에서 일어나고 \(\nabla g(\mathbf a) \ne \mathbf 0\)이면, \(\nabla f(\mathbf a) = \lambda\nabla g(\mathbf a)\)인 \(\lambda\)가 있다.

뜻: 최적점에서 \(f\)의 등고선과 제약 곡선이 접합니다. 접하지 않으면 제약을 따라 조금 움직여 \(f\)를 더 키울 수 있기 때문입니다. 실제로는 \(L = f - \lambda(g - c)\)를 모든 변수와 \(\lambda\)로 미분해 0으로 둡니다.

예제 5.3.2

다항분포에서 범주 \(k\)개의 관측 수가 \(n_1, \ldots, n_k\)일 때 \(\sum p_j = 1\) 아래 \(\sum n_j\log p_j\)를 최대화하세요.

풀이. \(L = \sum n_j\log p_j - \lambda(\sum p_j - 1)\). \(\partial L/\partial p_j = n_j/p_j - \lambda = 0\)에서 \(p_j = n_j/\lambda\). 합이 1이므로 \(\lambda = n\), \(\hat p_j = n_j/n\). 관측 비율이 최대가능도 추정값입니다.

예제 5.3.3

\(x + y = 10\) 위에서 \(xy\)의 최댓값은?

풀이. \(\nabla(xy) = (y, x) = \lambda(1, 1)\)에서 \(x = y = 5\), 최댓값 25.

요약
  1. \(\nabla f = \lambda\nabla g\): 등고선과 제약이 접함.
  2. \(L = f - \lambda(g - c)\)를 미분해 0으로.
  3. 네이만 배분, 다항분포 MLE가 대표 예.

5.3.3연습문제

응용

  1. \(n_1 + n_2 = n\) 아래 \(\frac{a^2}{n_1} + \frac{b^2}{n_2}\)를 최소화하는 배분은?
    답

    \(-a^2/n_1^2 = -b^2/n_2^2\)에서 \(n_1/n_2 = a/b\), \(n_1 = \frac{a}{a+b}n\). 네이만 배분의 꼴입니다.
