라그랑주 승수법

본문
이 절에서 배울 것
  • "\(x + y = 10\)" 같은 등식 조건이 붙은 최대·최소 문제를 대입법과 라그랑주 승수법으로 푼다.
  • 최적점에서 목적함수의 등고선과 조건 곡선이 접한다는 뜻을 이해한다.
  • 다항분포의 최대가능도 추정과 표본 배분 문제에 적용한다.
먼저 알아야 할 것
  • 편미분과 기울기 벡터 (5.1절), 일변수 함수의 최대·최소(고등학교 미적분).

예산이 정해져 있을 때

조사원이 모두 \(n\)명을 조사할 수 있을 때 여러 지역에 몇 명씩 나누어야 추정이 가장 정밀할까요(응통8 3.2절)? 범주별 확률의 합이 1이어야 할 때 가능도를 가장 크게 하는 확률은 무엇일까요? 이런 문제는 변수들 사이에 지켜야 할 등식(조건)이 있는 최적화입니다.

5.3.1대입법: 고등학교 방법으로 먼저 풀기

예제 5.3.1

\(x + y = 10\)일 때 \(xy\)의 최댓값을 구하세요.

풀이. 조건에서 \(y = 10 - x\)를 얻어 대입하면 \(xy = x(10 - x) = -x^2 + 10x\)라는 일변수 이차함수가 됩니다. \(-(x - 5)^2 + 25\)이므로 \(x = 5\)(따라서 \(y = 5\))에서 최댓값 25입니다.

조건식을 한 변수에 대해 풀 수 있으면 이렇게 대입해 변수를 하나 줄이면 됩니다. 그런데 조건이 복잡하거나(예: \(x^2 + xy + y^4 = 3\)) 변수가 많으면 대입이 어렵습니다. 그럴 때 쓰는 일반적인 방법이 라그랑주 승수법입니다.

5.3.2등고선과 조건 곡선이 접한다

예제 5.3.1을 그림으로 생각해 봅니다. \(xy = k\)인 점들(등고선)은 쌍곡선이고, \(k\)가 클수록 원점에서 멀어집니다. 조건 \(x + y = 10\)은 직선입니다. 직선 위를 따라 걸으면서 \(xy\)의 값을 보면, 직선이 등고선을 가로지르는 곳에서는 한쪽으로 더 가면 값이 커지므로 최대가 아닙니다. 최댓값은 직선이 어떤 등고선과 딱 접하는 곳, 여기서는 \(xy = 25\)와 만나는 \((5, 5)\)에서 생깁니다.

두 곡선이 접한다는 것은 그 점에서 두 곡선의 수직 방향이 같다는 뜻입니다. 5.1절에서 기울기 벡터는 등고선에 수직이었으므로, 접점에서는 \(f\)의 기울기 벡터와 조건식 \(g\)의 기울기 벡터가 같은 직선 위에 있습니다(한쪽이 다른 쪽의 몇 배). 그 배수를 \(\lambda\)("람다")로 씁니다.

정리 5.3.2

조건 \(g(x, y) = c\) 위에서 \(f(x, y)\)가 점 \((a, b)\)에서 최대 또는 최소이고 그 점에서 \(\nabla g \ne (0, 0)\)이면, 어떤 수 \(\lambda\)에 대해

\(f_x(a, b) = \lambda g_x(a, b)\), \(f_y(a, b) = \lambda g_y(a, b)\)

가 성립합니다. 이 두 식과 조건 \(g(a, b) = c\)를 연립해 \(a, b, \lambda\)를 구합니다.

외우기 쉽게 \(L = f - \lambda(g - c)\)라는 함수를 만들어 \(x\), \(y\), \(\lambda\)로 각각 편미분해 0으로 두어도 똑같은 연립방정식이 나옵니다(\(\lambda\)로 미분하면 조건식이 됩니다). \(\lambda\)를 라그랑주 승수라 합니다. 변수가 셋 이상이어도 편미분식이 늘어날 뿐 방법은 같습니다.

예제 5.3.3

예제 5.3.1을 라그랑주 승수법으로 다시 푸세요.

풀이. \(f = xy\), \(g = x + y\)이므로 \(f_x = y\), \(f_y = x\), \(g_x = g_y = 1\)입니다. \(y = \lambda\), \(x = \lambda\), \(x + y = 10\)을 연립하면 \(x = y = \lambda = 5\), 최댓값 25로 대입법과 같습니다.

예제 5.3.4

범주가 \(k\)개인 자료에서 관측 수가 \(n_1, \ldots, n_k\) (합 \(n\))입니다. 조건 \(p_1 + \cdots + p_k = 1\) 아래 로그가능도 \(\sum_j n_j\log p_j\)를 최대로 하는 \(p_j\)를 구하세요.

풀이. 변수가 \(k\)개라 대입법은 번거롭습니다. \(L = \sum n_j\log p_j - \lambda(\sum p_j - 1)\)을 각 \(p_j\)로 편미분하면 \(n_j/p_j - \lambda = 0\), 곧 \(p_j = n_j/\lambda\)입니다. 이것을 조건에 넣으면 \(\sum n_j/\lambda = 1\)에서 \(\lambda = n\)이므로 \(\hat p_j = n_j/n\)입니다. 곧 각 범주의 관측 비율이 최대가능도 추정값이라는, 직관과 맞는 결과입니다.

흔한 실수

라그랑주 조건을 만족하는 점은 최댓값·최솟값의 후보일 뿐입니다. 후보가 여럿이면 각 점에서 \(f\)의 값을 비교하고, 조건 곡선이 끝이 있으면 끝점도 확인해야 합니다. 예제 5.3.1에서 \(x, y\)에 제한이 없으면 \(xy\)는 최솟값이 없습니다(\(x\)가 아주 크면 \(y\)는 아주 작은 음수).

요약
  1. 조건식을 한 변수에 대해 풀 수 있으면 대입해 일변수 문제로 바꿉니다.
  2. 일반적으로는 최적점에서 \(\nabla f = \lambda\nabla g\)(등고선과 조건 곡선이 접함)와 조건식을 연립합니다.
  3. 다항분포의 최대가능도 추정값은 관측 비율이고, 네이만 배분(응통8)도 같은 방법으로 얻습니다.

5.3.3연습문제

기본

  1. \(2x + y = 8\)일 때 \(x^2 + y^2\)의 최솟값을 대입법과 라그랑주 승수법으로 각각 구하세요.
    답

    대입: \(x^2 + (8 - 2x)^2 = 5x^2 - 32x + 64\)는 \(x = 3.2\)에서 최소, \(y = 1.6\), 값 12.8. 라그랑주: \(2x = 2\lambda\), \(2y = \lambda\)에서 \(x = 2y\), 조건에 넣어 \(y = 1.6\), 같은 결과입니다(원점에서 직선까지 거리의 제곱).

응용

  1. \(n_1 + n_2 = n\) 아래 \(\frac{a^2}{n_1} + \frac{b^2}{n_2}\) (\(a, b > 0\))를 최소화하는 배분은?
    답

    \(-a^2/n_1^2 = \lambda\), \(-b^2/n_2^2 = \lambda\)에서 \(n_1/n_2 = a/b\), 곧 \(n_1 = \frac{a}{a+b}n\). 층의 표준편차에 비례해 배분하는 네이만 배분의 꼴입니다.
