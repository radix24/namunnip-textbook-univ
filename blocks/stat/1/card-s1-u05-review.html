다변수 미분 단원 마무리 연습

문제 6 · 계산·개념·적용 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(f(x, y) = x^2y + 3xy^2\)의 편도함수 \(f_x\), \(f_y\)와 점 \((1, 2)\)에서의 기울기 벡터를 구하세요. [05-01]

    힌트 1

    \(f_x\)를 구할 때는 \(y\)를 상수로 봅니다.

    힌트 2

    기울기 벡터는 \(\nabla f = (f_x, f_y)\)입니다.

    풀이

    \(f_x = 2xy + 3y^2\), \(f_y = x^2 + 6xy\)입니다. \((1, 2)\)에서 \(f_x = 4 + 12 = 16\), \(f_y = 1 + 12 = 13\)이므로 \(\nabla f(1, 2) = (16, 13)\)입니다.

  2. 개념\(f(x, y) = x^2 + y^2\)의 점 \((3, 4)\)에서 기울기 벡터를 구하고, 이 벡터의 방향과 크기가 각각 무엇을 뜻하는지 쓰세요. [05-01]

    힌트 1

    \(\nabla f = (2x, 2y)\)입니다.

    힌트 2

    기울기 벡터 방향은 \(f\)가 가장 빨리 커지는 방향이고, 등고선과 수직입니다.

    풀이

    \(\nabla f(3, 4) = (6, 8)\)이고 크기는 \(\sqrt{36+64} = 10\)입니다.

    방향 \((0.6, 0.8)\)은 \(f\)가 가장 빨리 증가하는 방향(여기서는 원점에서 멀어지는 방향)이고, 등고선(원 \(x^2+y^2 = 25\))에 수직입니다. 크기 10은 그 방향으로 단위 거리만큼 갈 때의 최대 증가율입니다. 경사하강법은 반대 방향 \(-\nabla f\)로 움직여 최솟값을 찾습니다.

  3. 계산\(f(x, y) = x^2 + xy + y^2 - 3x\)의 임계점을 구하고, 판정식 \(D = f_{xx}f_{yy} - f_{xy}^2\)으로 극값을 판정하세요. [05-02]

    힌트 1

    \(f_x = 2x + y - 3 = 0\), \(f_y = x + 2y = 0\)을 연립합니다.

    힌트 2

    \(D > 0\)이고 \(f_{xx} > 0\)이면 극소, \(D > 0\)이고 \(f_{xx} < 0\)이면 극대, \(D < 0\)이면 안장점입니다.

    풀이

    두 번째 식에서 \(x = -2y\), 첫 번째에 넣으면 \(-3y - 3 = 0\), 곧 \(y = -1\), \(x = 2\)입니다.

    \(f_{xx} = 2\), \(f_{yy} = 2\), \(f_{xy} = 1\)이므로 \(D = 4 - 1 = 3 > 0\)이고 \(f_{xx} > 0\)이라 극소입니다. 극솟값은 \(f(2, -1) = 4 - 2 + 1 - 6 = -3\)입니다. 이 함수는 이차식이라 완전제곱 \(\big(x + \frac y2 - \frac32\big)^2 + \frac34(y + 1)^2 - 3\)으로도 쓸 수 있어, 이 극소가 전체의 최솟값임을 바로 알 수 있습니다.

  4. 계산\(f(x, y) = x^3 - 3x + y^2\)의 임계점을 모두 구하고 각각 극대, 극소, 안장점 가운데 무엇인지 판정하세요. [05-02]

    힌트 1

    \(f_x = 3x^2 - 3\), \(f_y = 2y\)입니다.

    힌트 2

    \(f_{xx} = 6x\), \(f_{yy} = 2\), \(f_{xy} = 0\)입니다.

    풀이

    임계점은 \((1, 0)\), \((-1, 0)\)입니다.

    \((1, 0)\): \(D = 6\cdot2 - 0 = 12 > 0\), \(f_{xx} = 6 > 0\)이므로 극소(값 \(-2\)).

    \((-1, 0)\): \(D = -6\cdot2 - 0 = -12 < 0\)이므로 안장점입니다. \(x\) 방향으로는 극대, \(y\) 방향으로는 극소인 말안장 모양입니다.

  5. 계산\(x + y = 10\)이라는 제약 아래 \(xy\)의 최댓값을 라그랑주 승수법으로 구하세요. [05-03]

    힌트 1

    \(\mathcal L = xy - \lambda(x + y - 10)\)으로 놓고 \(x\), \(y\), \(\lambda\)로 편미분합니다.

    힌트 2

    \(y = \lambda\), \(x = \lambda\)가 나옵니다.

    풀이

    \(\mathcal L_x = y - \lambda = 0\), \(\mathcal L_y = x - \lambda = 0\), \(x + y = 10\)에서 \(x = y = 5\)입니다. 최댓값은 25입니다.

    기하적으로는 \(xy\)의 등고선과 제약 직선이 접하는 점, 곧 두 기울기 벡터 \((y, x)\)와 \((1, 1)\)이 평행한 점입니다.

  6. 적용세 범주의 관측 도수가 \(n_1 = 3\), \(n_2 = 5\), \(n_3 = 2\)입니다. 다항분포의 로그가능도 \(\sum n_i\ln p_i\)를 제약 \(p_1 + p_2 + p_3 = 1\) 아래 최대화해 \(\hat p_i\)를 구하세요. [05-03]

    힌트 1

    \(\mathcal L = \sum n_i\ln p_i - \lambda(\sum p_i - 1)\)을 \(p_i\)로 미분하면 \(n_i/p_i = \lambda\)입니다.

    힌트 2

    세 식을 더하면 \(\lambda\)가 나옵니다.

    풀이

    \(p_i = n_i/\lambda\)이고 \(\sum p_i = 1\)에서 \(\lambda = \sum n_i = 10\)입니다. 따라서 \(\hat p_i = n_i/10\), 곧 \(\hat p = (0.3, 0.5, 0.2)\)입니다. 범주별 표본 비율이 최대가능도 추정값입니다.
