스털링 근사는 얼마나 정확한가

예제 · 점근적으로 같음

먼저 읽는 법

\(a_n \sim b_n\)은 비가 1로 간다는 뜻이지 차이가 0으로 간다는 뜻이 아니다. 스털링 근사의 비와 차이를 몇 개의 \(n\)에서 계산해 이 구별을 확인한다.

문제. \(n! \sim \sqrt{2\pi n}(n/e)^n\)에서 \(n = 1, 5, 10\)일 때 근사값, 비(참값/근사), 차이를 구하여라.

풀이

  1. \(n = 1\): 근사 \(\sqrt{2\pi}/e = 0.922\), 참값 1, 비 1.084, 차이 0.08.
    작은 \(n\)에서도 8% 오차.
  2. \(n = 5\): 근사 118.02, 참값 120, 비 1.017, 차이 1.98.
    비는 1에 가까워짐.
  3. \(n = 10\): 근사 3598696, 참값 3628800, 비 1.0084, 차이 약 30104.
    차이는 오히려 커짐.

검산

더 정밀한 공식은 비가 \(1 + \frac{1}{12n} + O(n^{-2})\)이다. \(n = 10\)에서 \(1 + 1/120 = 1.0083\)으로 계산한 비 1.0084와 맞다.

의미

상대 오차는 \(O(1/n)\)으로 줄지만 절대 오차는 \(n!\) 자체가 커지므로 늘어난다. 확률 계산에서는 대개 비(상대 오차)가 중요하므로 스털링 근사는 매우 유용하다. "점근적으로 같다"를 "거의 같은 값"으로 오해하지 않도록 비와 차이를 구별해 읽는다.
