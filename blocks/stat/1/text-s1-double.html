이중적분과 반복적분

본문
이 절에서 배울 것
  • 곡면 아래 부피를 단면 넓이의 적분으로 구하는 이중적분(반복적분)을 계산한다.
  • 영역을 그림으로 읽어 적분 범위를 정하고, 필요하면 적분 순서를 바꾼다.
  • 두 확률변수의 결합 밀도에서 "\(X < Y\)일 확률" 같은 확률을 계산한다.
먼저 알아야 할 것
  • 정적분과 이상적분 (3.1, 3.2절), 고등학교 미적분의 "단면의 넓이를 적분해 입체의 부피 구하기", 편미분에서 다른 변수를 상수로 보는 생각 (5.1절).

두 변수의 확률은 부피

확률변수 하나의 확률은 밀도 곡선 아래 넓이였습니다. 키와 몸무게처럼 두 확률변수 \((X, Y)\)를 함께 다룰 때는 평면 위의 점 \((x, y)\)마다 "그 근처에 얼마나 몰려 있는지"를 나타내는 높이 \(f(x, y)\)를 생각합니다. 이것을 결합 밀도라 하며, \(f \ge 0\)이고 곡면 \(z = f(x, y)\) 아래 전체 부피가 1입니다. 어떤 영역 \(D\)에 \((X, Y)\)가 들어갈 확률은 \(D\) 위의 곡면 아래 부피입니다. 이 부피를 이중적분 \(\iint_D f(x, y)\,dA\)로 씁니다.

6.1.1단면 넓이에서 반복적분으로

고등학교 미적분에서 입체의 부피를 "\(x\)에서 자른 단면의 넓이 \(S(x)\)를 \(x\)로 적분"해서 구했습니다. 곡면 아래 부피도 똑같이 구합니다. 직사각형 \(a \le x \le b\), \(c \le y \le d\) 위의 부피를 구할 때, \(x\)를 하나 고정하고 자르면 단면은 곡선 \(z = f(x, y)\) (\(y\)의 함수) 아래 넓이이므로 \(S(x) = \int_c^d f(x, y)\,dy\)입니다(\(x\)는 상수 취급). 이 단면 넓이를 \(x\)로 적분하면 부피입니다.

정리 6.1.1 (반복적분, 푸비니 정리)

\(f\)가 연속이면 직사각형 \(R\) 위에서

\(\displaystyle\iint_R f\,dA = \int_a^b\left(\int_c^d f(x,y)\,dy\right)dx = \int_c^d\left(\int_a^b f(x,y)\,dx\right)dy\)

입니다. \(x\) 방향으로 자르든 \(y\) 방향으로 자르든 부피는 같습니다.

영역이 직사각형이 아니면 단면의 범위가 \(x\)에 따라 달라집니다. 예를 들어 영역이 "\(0 \le x \le 1\)이고 \(0 \le y \le x\)"(삼각형)이면 \(x\)에서 자른 단면은 \(y\)가 0부터 \(x\)까지이므로 \(\int_0^1\left(\int_0^x f\,dy\right)dx\)입니다. 순서를 바꾸어 \(y\)를 먼저 고정하면 같은 삼각형이 "\(0 \le y \le 1\)이고 \(y \le x \le 1\)"이 되어 \(\int_0^1\left(\int_y^1 f\,dx\right)dy\)입니다. 영역을 그림으로 그려 경계를 읽는 것이 가장 확실한 방법입니다.

예제 6.1.2

두 대기 시간 \(X, Y\)의 결합 밀도가 \(f(x, y) = e^{-x-y}\) (\(x, y > 0\))입니다. (가) 전체 부피가 1인지 확인하고 (나) \(P(X < Y)\) (다) \(P(X + Y < 1)\)을 구하세요.

풀이. (가) \(\int_0^\infty\left(\int_0^\infty e^{-x}e^{-y}dy\right)dx = \int_0^\infty e^{-x}\cdot1\,dx = 1\)입니다.

(나) 영역 \(x < y\)는 직선 \(y = x\) 위쪽입니다. \(x\)를 고정하면 \(y\)는 \(x\)부터 \(\infty\)까지이므로 \(\int_0^\infty\left(\int_x^\infty e^{-x-y}dy\right)dx = \int_0^\infty e^{-x}e^{-x}dx = \int_0^\infty e^{-2x}dx = \frac12\)입니다. 두 대기 시간이 같은 분포라 대칭적으로 생각해도 \(\frac12\)이어야 합니다.

(다) 영역 \(x + y < 1\) (\(x, y > 0\))은 삼각형이고, \(x\)를 고정하면 \(y\)는 0부터 \(1 - x\)까지입니다. \(\int_0^1 e^{-x}\big(1 - e^{-(1-x)}\big)dx = \int_0^1(e^{-x} - e^{-1})dx = (1 - e^{-1}) - e^{-1} = 1 - 2e^{-1} \approx 0.264\)입니다.

예제 6.1.3 (순서 바꾸기)

\(\displaystyle\int_0^1\left(\int_x^1 e^{y^2}dy\right)dx\)를 계산하세요.

풀이. \(e^{y^2}\)은 원시함수를 초등함수로 쓸 수 없어 안쪽 적분을 바로 할 수 없습니다. 영역은 \(0 \le x \le y \le 1\)(직선 \(y = x\) 위쪽 삼각형)이므로, \(y\)를 먼저 고정하면 \(x\)는 0부터 \(y\)까지입니다. 그러면 \(\int_0^1\left(\int_0^y e^{y^2}dx\right)dy = \int_0^1 ye^{y^2}dy\)이고, \(u = y^2\)으로 치환하면 \(\frac{e - 1}{2} \approx 0.859\)입니다. 순서만 바꾸었는데 풀 수 없던 적분이 풀렸습니다.

흔한 실수

안쪽 적분의 범위에 바깥 변수가 들어가는 것은 괜찮지만, 바깥 적분의 범위에 안쪽 변수가 들어가면 틀린 식입니다. \(\int_0^y\left(\int_0^1\cdots dy\right)dx\)처럼 쓰면 바깥 적분이 끝난 뒤에도 \(y\)가 남습니다. 바깥 적분의 범위는 언제나 숫자여야 합니다.

요약
  1. 이중적분은 곡면 아래 부피이고, 단면 넓이를 적분하는 반복적분으로 계산합니다.
  2. 영역을 그림으로 그려 범위를 정하고, 계산이 어려우면 적분 순서를 바꿉니다.
  3. 결합 밀도에서 확률은 해당 영역 위의 부피입니다.

6.1.2연습문제

기본

  1. \(\displaystyle\int_0^1\left(\int_0^2(x + y)\,dy\right)dx\)를 구하고, 순서를 바꾸어도 같은지 확인하세요.
    답

    안쪽 \(\int_0^2(x + y)dy = 2x + 2\), 바깥 \(\int_0^1(2x + 2)dx = 3\). 순서를 바꾸면 \(\int_0^2(\frac12 + y)dy = 1 + 2 = 3\).

  2. 결합 밀도 \(f(x, y) = 2\) (\(0 < x < y < 1\))에서 \(P(Y > 2X)\)를 구하세요.
    답

    영역은 \(0 < x < 1/2\), \(2x < y < 1\)이므로 \(\int_0^{1/2}2(1 - 2x)dx = 1/2\).
