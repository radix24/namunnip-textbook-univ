이중적분과 반복적분

본문
이 절에서 배울 것
  • 이중적분을 반복적분으로 계산하고 적분 순서를 바꾼다.
  • 결합 밀도에서 확률을 계산한다.
먼저 알아야 할 것
  • 정적분 (3.1절).

두 변수의 확률은 부피

한 변수의 확률이 밀도 곡선 아래 넓이였듯, 두 변수 \((X, Y)\)의 확률은 결합 밀도 곡면 아래 부피입니다. "\(X < Y\)일 확률"처럼 영역이 복잡하면 적분 범위를 잘 정해야 합니다.

6.1.1반복적분

정리 6.1.1 (푸비니)

\(f\)가 연속(또는 적분 가능)이면 \(\iint_R f\,dA = \int_a^b\left(\int_{c}^{d}f(x,y)\,dy\right)dx = \int_c^d\left(\int_a^bf\,dx\right)dy\) (직사각형 \(R\)).

영역이 \(\{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\)이면 안쪽 적분의 범위가 \(x\)에 따라 달라집니다. 순서를 바꾸면 영역을 \(y\) 기준으로 다시 써야 합니다. 그림을 그려 영역을 확인하는 것이 가장 확실합니다.

예제 6.1.2

\(f(x, y) = e^{-x-y}\) (\(x, y > 0\))에서 \(P(X < Y)\)와 \(P(X + Y < 1)\)을 구하세요.

풀이. \(P(X < Y) = \int_0^\infty\int_x^\infty e^{-x-y}dy\,dx = \int_0^\infty e^{-2x}dx = \frac12\). \(P(X + Y < 1) = \int_0^1\int_0^{1-x}e^{-x-y}dy\,dx = \int_0^1e^{-x}(1 - e^{-(1-x)})dx = \int_0^1(e^{-x} - e^{-1})dx = 1 - 2e^{-1} \approx 0.264\).

예제 6.1.3 (순서 바꾸기)

\(\int_0^1\int_x^1e^{y^2}dy\,dx\)를 계산하세요.

풀이. \(e^{y^2}\)는 \(y\)로 적분할 수 없지만, 영역 \(0 \le x \le y \le 1\)을 \(y\) 기준으로 쓰면 \(\int_0^1\int_0^ye^{y^2}dx\,dy = \int_0^1ye^{y^2}dy = \frac{e - 1}{2}\).

요약
  1. 이중적분 = 반복적분, 영역 그림으로 범위를 정함.
  2. 순서를 바꾸면 계산이 쉬워질 수 있음.
  3. 결합 밀도의 확률 = 영역 위 부피.
