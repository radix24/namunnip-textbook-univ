본문
이 절에서 배울 것
  • 극좌표 변환의 야코비안 \(r\)을 쓴다.
  • 가우스 적분 \(\int e^{-x^2/2}dx = \sqrt{2\pi}\)를 증명한다.
먼저 알아야 할 것
  • 변수 변환과 야코비안 (6.2절).

정규분포의 \(\sqrt{2\pi}\)는 어디서 왔나

표준정규 밀도 \(\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\)의 상수는 넓이를 1로 만들기 위한 것입니다. 그런데 \(e^{-x^2/2}\)는 초등함수로 적분할 수 없습니다. 이 적분을 제곱해 이중적분으로 만들고 극좌표로 바꾸면 놀랍게도 쉽게 풀립니다.

6.3.1극좌표

평면의 점은 \((x, y)\) 대신 "원점에서의 거리 \(r\)"과 "\(x\)축 양의 방향에서 잰 각 \(\theta\)"로도 나타낼 수 있습니다. 이것을 극좌표라 합니다. 삼각함수의 정의에 따라 \(x = r\cos\theta\), \(y = r\sin\theta\)이고, \(x^2 + y^2 = r^2\)입니다. 원 모양 영역은 극좌표로 쓰면 \(0 \le r \le r_0\), \(0 \le \theta \le 2\pi\)처럼 간단해집니다.

야코비안(6.2절의 \(J = x_ry_\theta - x_\theta y_r\))을 계산하면 \(x_r = \cos\theta\), \(x_\theta = -r\sin\theta\), \(y_r = \sin\theta\), \(y_\theta = r\cos\theta\)이므로 \(J = r\cos^2\theta + r\sin^2\theta = r\)입니다. 따라서 \(dx\,dy = r\,dr\,d\theta\)입니다.

그림으로도 이해할 수 있습니다. 반지름이 \(r\)에서 \(r + dr\)로, 각이 \(\theta\)에서 \(\theta + d\theta\)로 바뀌는 작은 조각은 폭이 \(dr\), 호의 길이가 \(r\,d\theta\)(반지름 × 각)인 거의 직사각형이므로 넓이가 \(r\,dr\,d\theta\)입니다. 원점에서 멀수록 같은 각이 더 긴 호를 덮기 때문에 \(r\)이 곱해집니다.

6.3.2가우스 적분

정리 6.3.1

\(\displaystyle I = \int_{-\infty}^\infty e^{-x^2/2}dx = \sqrt{2\pi}\).

\(I^2 = \int e^{-x^2/2}dx\int e^{-y^2/2}dy = \iint_{\mathbb R^2}e^{-(x^2+y^2)/2}dx\,dy\)(\(x\)만의 함수와 \(y\)만의 함수의 곱을 직사각형 영역에서 적분하면 두 적분의 곱이 되는 성질, 6.1절의 반복적분을 거꾸로 쓴 것). 극좌표로 바꾸면 \(x^2 + y^2 = r^2\)이므로 \(I^2 = \int_0^{2\pi}\int_0^\infty e^{-r^2/2}r\,dr\,d\theta\). 안쪽 적분은 \(u = r^2/2\)로 치환해 \(\int_0^\infty e^{-u}du = 1\). 따라서 \(I^2 = 2\pi\), \(I > 0\)이므로 \(I = \sqrt{2\pi}\). ∎

야코비안의 \(r\)이 치환에 꼭 필요한 \(r\,dr\)을 만들어 준 것이 핵심입니다. \(x = \mu + \sigma z\)로 치환하면 \(\int e^{-(x-\mu)^2/(2\sigma^2)}dx = \sigma\sqrt{2\pi}\)도 얻습니다.

예제 6.3.2

독립 표준정규 \(X, Y\)에 대해 \(P(X^2 + Y^2 \le r_0^2)\)는?

풀이. \(\frac{1}{2\pi}\int_0^{2\pi}\int_0^{r_0}e^{-r^2/2}r\,dr\,d\theta = 1 - e^{-r_0^2/2}\). 곧 \(X^2 + Y^2\)은 평균 2인 지수분포(자유도 2인 카이제곱)입니다. 박스-뮬러 난수 생성법(응통15 4.2절)이 이 사실을 거꾸로 씁니다.

요약
  1. 극좌표: \(dx\,dy = r\,dr\,d\theta\).
  2. \(\int e^{-x^2/2} = \sqrt{2\pi}\): 제곱 → 극좌표 → 치환.
  3. \(X^2 + Y^2\)은 지수분포(평균 2).

6.3.3연습문제

기본

  1. 가우스 적분으로 \(\int_{-\infty}^\infty x^2e^{-x^2/2}dx\)를 구하세요.
    답

    부분적분 \(u = x\), \(dv = xe^{-x^2/2}dx\): \([-xe^{-x^2/2}] + \int e^{-x^2/2} = \sqrt{2\pi}\). 표준정규의 분산이 1임을 뜻합니다.
