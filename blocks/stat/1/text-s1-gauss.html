극좌표로 정규분포의 규격화 상수 구하기

본문

표준정규 밀도 \(\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\)에는 원주율 \(\pi\)가 들어 있다. 원과 아무 상관없어 보이는 종 모양 곡선에 왜 \(\pi\)가 나올까? 그리고 \(e^{-x^2/2}\)는 원시함수를 쓸 수 없는데, 그 넓이는 어떻게 구했을까?

먼저 알아야 할 것변수 변환과 야코비안(6.2절)을 쓴다.

6.3.1극좌표

처음 질문의 \(\pi\)는 적분을 원 위에서 하면 나타난다. 그러려면 좌표를 바꿔야 한다. 평면의 점은 \((x, y)\) 대신 원점에서의 거리 \(r\)과 \(x\)축 양의 방향에서 잰 각 \(\theta\)로도 나타낼 수 있고, 이것을 극좌표라 한다. 삼각함수의 정의에 따라 \(x = r\cos\theta\), \(y = r\sin\theta\)이고 \(x^2 + y^2 = r^2\)이다. 따라서 원 모양 영역은 극좌표로 쓰면 \(0 \le r \le r_0\), \(0 \le \theta \le 2\pi\)처럼 간단해진다.

6.2절의 야코비안을 계산하면 \(x_r = \cos\theta\), \(x_\theta = -r\sin\theta\), \(y_r = \sin\theta\), \(y_\theta = r\cos\theta\)이므로 \(J = r\cos^2\theta + r\sin^2\theta = r\)이다. 따라서 \(dx\,dy = r\,dr\,d\theta\)이다. 그림 1이 이 식을 보여 준다. 작은 조각의 폭은 \(dr\)이고 호의 길이는 반지름 곱하기 각인 \(r\,d\theta\)이므로, 넓이가 \(r\,dr\,d\theta\)이다. 원점에서 멀수록 같은 각이 더 긴 호를 덮기 때문에 \(r\)이 곱해진다.

6.3.2가우스 적분

정리 6.3.1 (가우스 적분)

\(\displaystyle I = \int_{-\infty}^\infty e^{-x^2/2}dx = \sqrt{2\pi}\).

증명.적분 하나는 풀 수 없으므로 일부러 둘을 곱한다. \(x\)만의 함수와 \(y\)만의 함수의 곱을 평면 전체에서 적분하면 두 적분의 곱이 되므로(6.1절의 반복적분을 거꾸로 쓴 것) \(I^2 = \int e^{-x^2/2}dx\int e^{-y^2/2}dy = \iint e^{-(x^2+y^2)/2}dx\,dy\)이다. 이제 극좌표로 바꾸면 \(x^2 + y^2 = r^2\)이고 \(dx\,dy = r\,dr\,d\theta\)이므로 \(I^2 = \int_0^{2\pi}\int_0^\infty e^{-r^2/2}r\,dr\,d\theta\)이다. 안쪽 적분은 \(u = r^2/2\)로 치환하면 \(\int_0^\infty e^{-u}du = 1\)이고, 바깥 적분은 \(2\pi\)이다. 따라서 \(I^2 = 2\pi\)이고 \(I > 0\)이므로 \(I = \sqrt{2\pi}\)이다. ∎

증명의 열쇠는 두 가지이다. 첫째, 제곱하면 \(x^2 + y^2\)이 생겨 원 대칭이 되므로 각 \(\theta\)에 대한 적분이 그대로 \(2\pi\)를 준다. 처음 질문의 \(\pi\)는 여기서 온다. 둘째, 야코비안의 \(r\)이 치환에 꼭 필요한 \(r\,dr\)을 만들어 주어, 풀 수 없던 적분이 풀린다. 같은 결과에 \(x = \mu + \sigma z\)로 치환하면 \(\int e^{-(x-\mu)^2/(2\sigma^2)}dx = \sigma\sqrt{2\pi}\)도 얻는다.

예제 6.3.2

독립인 표준정규 확률변수 \(X, Y\)에 대해 \(P(X^2 + Y^2 \le r_0^2)\)를 구하여라.

풀이. 결합 밀도는 \(\frac{1}{2\pi}e^{-(x^2+y^2)/2}\)이고 영역은 원이므로 극좌표가 알맞다. \(\frac{1}{2\pi}\int_0^{2\pi}\int_0^{r_0}e^{-r^2/2}r\,dr\,d\theta = 1 - e^{-r_0^2/2}\)이다. 다시 말해 \(X^2 + Y^2\)은 평균 2인 지수분포, 곧 자유도 2인 카이제곱분포를 따른다. 박스-뮬러 난수 생성법(응통15 4.2절)이 이 사실을 거꾸로 써서 정규 난수를 만든다.

마무리

극좌표에서 작은 넓이는 \(dx\,dy = r\,dr\,d\theta\)이고, 이 \(r\)은 원점에서 멀수록 같은 각이 더 긴 호를 덮기 때문에 생긴다. 풀 수 없는 \(\int e^{-x^2/2}dx\)를 제곱해 평면 위의 적분으로 만들고 극좌표로 바꾸면, 각에 대한 적분이 \(2\pi\)를 주고 \(r\,dr\)이 치환을 가능하게 해 \(\sqrt{2\pi}\)가 나온다. 정규분포의 \(\pi\)는 이렇게 원 대칭에서 온다.

6.3.3연습문제

응용

  1. 가우스 적분으로 \(\int_{-\infty}^\infty x^2e^{-x^2/2}dx\)를 구하여라.
    답

    \(u = x\), \(dv = xe^{-x^2/2}dx\)로 부분적분하면 \([-xe^{-x^2/2}] + \int e^{-x^2/2}dx = \sqrt{2\pi}\)이다. 표준정규의 분산이 1임을 뜻한다.
