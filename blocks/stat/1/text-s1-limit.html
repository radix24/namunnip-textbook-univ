수열과 함수의 극한

본문

성공 확률이 1/1000인 복권을 1000번 사면 한 번도 당첨되지 않을 확률은 얼마일까? 식으로 쓰면 \((1 - 1/1000)^{1000}\)인데, 밑은 1에 가깝고 지수는 크다. 이런 값은 어디로 가까워질까?

먼저 알아야 할 것고등학교 수학II의 함수의 극한, 수학I의 수열, 미적분의 수열의 극한과 자연상수 \(e\)를 쓴다. 이 절은 그 내용을 통계에 쓰기 좋게 다시 정리한다.

1.1.1통계는 "\(n\)이 커지면"으로 가득하다

동전을 많이 던질수록 앞면 비율은 0.5에 가까워진다. 표본평균의 분포는 표본이 클수록 정규분포에 가까워진다. 시행 횟수가 많고 성공 확률이 작은 이항분포는 포아송분포에 가까워진다. 통계학의 이 세 결과, 곧 대수의 법칙, 중심극한정리, 포아송 근사는 모두 "\(n\)을 한없이 키우면 무엇에 가까워지는가"에 대한 답이다. 그래서 이 절에서는 그런 계산에 필요한 극한 기술을 고등학교 내용에서 출발해 정리한다.

1.1.2수열의 극한

정의 1.1.1

\(n\)이 한없이 커질 때 수열 \(a_n\)의 값이 어떤 수 \(L\)에 한없이 가까워지면 "\(a_n\)은 \(L\)에 수렴한다"고 하고 \(\lim_{n\to\infty}a_n = L\)로 쓴다. 어떤 수에도 가까워지지 않으면 발산한다고 한다.

고등학교에서 배운 대로, 두 수열이 각각 수렴하면 합, 차, 곱, 몫(분모의 극한이 0이 아닐 때)의 극한은 각 극한의 합, 차, 곱, 몫이다. 그런데 \(\frac{3n^2 + 5n}{2n^2 - 1}\)처럼 분자와 분모가 모두 한없이 커지면 이 성질을 바로 쓸 수 없다. 이때는 분자와 분모를 가장 빨리 커지는 항, 여기서는 \(n^2\)으로 나눈다. 그러면 \(\frac{3 + 5/n}{2 - 1/n^2}\)이 되고, \(5/n\)과 \(1/n^2\)이 0으로 가므로 극한은 \(3/2\)이다.

따라서 어느 항이 더 빨리 커지는지 알아 두면 편하다. \(n\)이 충분히 크면 \(\ln n \ll n^a \ll b^n \ll n!\)의 순서로 빨리 커진다(\(a > 0\), \(b > 1\)). 가령 \(n = 30\)이면 \(\ln 30 \approx 3.4\), \(30^3 = 27000\), \(2^{30} \approx 1.07\times10^9\), \(30! \approx 2.65\times10^{32}\)이다. 여기서 \(\ln\)은 밑이 \(e\)인 자연로그이다. 통계학 책에서는 자연로그를 \(\log\)로 쓰는 경우가 많으며, 이 교재에서도 따로 밝히지 않은 \(\log\)는 자연로그이다.

가운데 수열을 직접 계산하기 어려울 때는 위아래에서 끼워 넣는다.

정리 1.1.2 (조임 정리)

모든 \(n\)에서 \(a_n \le b_n \le c_n\)이고 \(\lim a_n = \lim c_n = L\)이면 \(\lim b_n = L\)이다.

예를 들어 \(-1 \le \sin n \le 1\)이므로 \(-\frac1n \le \frac{\sin n}{n} \le \frac1n\)이고, 양쪽이 0으로 가므로 \(\frac{\sin n}{n} \to 0\)이다.

1.1.3자연상수 \(e\)와 \((1 + x/n)^n\)

이제 처음 질문의 식으로 가자. 고등학교 미적분에서 \(e = \lim_{n\to\infty}(1 + 1/n)^n \approx 2.71828\)로 정의했다. 그림 1의 파란 점들이 이 수열이다. 통계에서는 이것을 조금 넓힌 다음 결과를 아주 자주 쓴다.

결과 1.1.3 \[\lim_{n\to\infty}\left(1 + \frac xn\right)^n = e^x\quad(x\text{는 어떤 실수든 된다})\]

이유.\(x > 0\)일 때 \(m = n/x\)로 놓으면 \(\left(1 + \frac xn\right)^n = \left[\left(1 + \frac1m\right)^m\right]^x\)이다. 여기서 \(n\to\infty\)이면 \(m\to\infty\)이므로 괄호 안이 \(e\)로 가고, 전체는 \(e^x\)로 간다. \(x < 0\)일 때도 같은 결론이 성립하며, 2.1절의 로그 극한으로 확인할 수 있다. ∎

처음 질문에 \(x = -1\)을 넣으면 \((1 - 1/1000)^{1000} \approx e^{-1} \approx 0.368\)이다. 다시 말해 1000분의 1 확률을 1000번 시도해도 36.8%의 확률로 한 번도 당첨되지 않는다. 일반적으로 성공 확률이 \(\lambda/n\)인 시행을 \(n\)번 할 때 한 번도 성공하지 않을 확률 \((1 - \lambda/n)^n\)은 \(e^{-\lambda}\)로 가고, 이것이 이항분포가 포아송분포로 가까워지는 출발점이다. 연이율 \(r\)을 1년에 \(n\)번 나누어 복리로 붙이면 \((1 + r/n)^n \to e^r\)배가 되는 연속 복리도 같은 식이다.

예제 1.1.4

(가) \(\displaystyle\lim_{n\to\infty}\frac{3n^2 + 5n}{2n^2 - 1}\) (나) \(\displaystyle\lim_{n\to\infty}\frac{n^3}{2^n}\) (다) \(\displaystyle\lim_{n\to\infty}\left(1 - \frac{2}{n}\right)^{3n}\)을 구하여라.

풀이. (가) 분자와 분모를 \(n^2\)으로 나누면 \(\frac{3 + 5/n}{2 - 1/n^2} \to \frac32\)이다. (나) 지수함수 \(2^n\)이 다항식 \(n^3\)보다 훨씬 빨리 커지므로 0이다. 실제로 \(n = 30\)에서 이미 \(27000/10^9 \approx 0.00003\)이다. (다) \(\left(1 - \frac2n\right)^{3n} = \left[\left(1 - \frac2n\right)^n\right]^3\)이고 괄호 안이 \(e^{-2}\)로 가므로 \(e^{-6} \approx 0.0025\)이다.

1.1.4함수의 극한

함수의 극한 \(\lim_{x\to a}f(x)\)도 수열과 같은 성질을 따른다. \(x = a\)를 넣으면 \(\frac00\)이 되는 꼴은 인수분해나 유리화로 약분한 뒤 넣는다. 통계에서 특히 자주 쓰는 기본 극한은 세 가지이다. 먼저 \(\lim_{h\to0}(e^h - 1)/h = 1\)과 \(\lim_{h\to0}\ln(1+h)/h = 1\)은 고등학교에서 \(e^x\)와 \(\ln x\)의 미분을 구할 때 배운 것이다. 그리고 어떤 양수 \(k\)에 대해서도 \(\lim_{x\to\infty}x^ke^{-x} = 0\)이다. 지수함수가 거듭제곱보다 빨리 커지기 때문이며, 확률밀도의 꼬리가 0으로 가는지 확인할 때 쓴다.

흔한 실수\((1 + 1/n)^n\)에서 "\(1/n \to 0\)이므로 \(1^n = 1\)"이라고 계산하면 틀린다. 밑은 1에 가까워지지만 지수 \(n\)은 한없이 커지므로 두 효과가 맞서고, 결과는 그림 1처럼 1이 아니라 \(e\)이다. 밑과 지수가 동시에 변하는 극한은 따로 계산해야 한다.
마무리

분수 꼴의 극한은 가장 빨리 커지는 항으로 나누고, 직접 계산이 어려우면 조임 정리로 끼워 넣는다. 커지는 속도는 \(\ln n \ll n^a \ll b^n \ll n!\) 순서이다. 밑이 1로 가고 지수가 커지는 \((1 + x/n)^n\)은 \(e^x\)로 가므로, 1/1000 확률의 복권을 1000번 사도 약 37%의 확률로 한 번도 당첨되지 않으며, 이 식이 포아송 근사의 바탕이다.

1.1.5연습문제

기본

  1. \(\displaystyle\lim_{n\to\infty}\sqrt{n}\left(\sqrt{n+1} - \sqrt n\right)\)을 구하여라.
    답

    유리화하면 \(\frac{\sqrt n}{\sqrt{n+1} + \sqrt n} = \frac{1}{\sqrt{1 + 1/n} + 1} \to \frac12\)이다.

  2. \(\displaystyle\lim_{n\to\infty}\frac{n!}{n^n} = 0\)임을 \(\frac{n!}{n^n} \le \frac1n\)으로 보여라.
    답

    \(\frac{n!}{n^n} = \frac1n\cdot\frac2n\cdots\frac nn\)에서 첫 인수 외에는 모두 1 이하이므로 \(0 < \frac{n!}{n^n} \le \frac1n\)이다. 조임 정리로 0이다.

응용

  1. 이항분포 \(B(n, \lambda/n)\)에서 \(P(X = 0) = (1 - \lambda/n)^n\)의 극한을 구하여라.
    답

    결과 1.1.3에 \(x = -\lambda\)를 넣으면 \(e^{-\lambda}\)이다. 포아송분포의 \(P(X = 0)\)과 같다.
