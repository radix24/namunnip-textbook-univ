수열과 함수의 극한

본문
이 절에서 배울 것
  • 수열과 함수의 극한을 계산하는 기본 방법(극한의 성질, 가장 빨리 커지는 항으로 나누기, 조임 정리)을 쓴다.
  • 통계에서 자주 나오는 극한 \((1 + x/n)^n \to e^x\)를 이해하고 쓴다.
먼저 알아야 할 것
  • 고등학교 수학II의 함수의 극한, 수학I의 수열, 미적분의 수열의 극한과 자연상수 \(e\). 이 절은 이 내용을 통계에 쓰기 좋게 다시 정리합니다.

통계는 "\(n\)이 커지면"으로 가득하다

통계학의 중요한 결과 가운데 많은 것이 "표본 크기 \(n\)을 한없이 키우면 무엇에 가까워지는가"라는 질문에 대한 답입니다. 예를 들어 동전을 많이 던질수록 앞면 비율이 0.5에 가까워진다는 대수의 법칙, 표본평균의 분포가 정규분포에 가까워진다는 중심극한정리, 시행 횟수가 많고 성공 확률이 작은 이항분포가 포아송분포에 가까워진다는 사실이 모두 극한입니다. 이 절에서는 그런 계산에 필요한 극한 기술을 고등학교 내용에서 출발해 정리합니다.

1.1.1수열의 극한

정의 1.1.1

\(n\)이 한없이 커질 때 수열 \(a_n\)의 값이 어떤 수 \(L\)에 한없이 가까워지면 "\(a_n\)은 \(L\)에 수렴한다"고 하고 \(\lim_{n\to\infty}a_n = L\)로 씁니다. 어떤 수에도 가까워지지 않으면 발산한다고 합니다.

고등학교에서 배운 대로, 두 수열이 각각 수렴하면 합, 차, 곱, 몫(분모의 극한이 0이 아닐 때)의 극한은 각 극한의 합, 차, 곱, 몫입니다. 이것을 극한의 성질이라 부릅니다.

분수 꼴은 가장 빨리 커지는 항으로 나눕니다. \(\frac{3n^2 + 5n}{2n^2 - 1}\)처럼 분자와 분모가 모두 커지면 극한의 성질을 바로 쓸 수 없습니다(\(\infty/\infty\) 꼴). 이때 분자와 분모를 가장 빨리 커지는 항(여기서는 \(n^2\))으로 나누면 \(\frac{3 + 5/n}{2 - 1/n^2}\)이 되고, \(5/n\)과 \(1/n^2\)은 0으로 가므로 극한은 \(3/2\)입니다.

어느 항이 더 빨리 커지는지 알아 두면 편리합니다. \(n\)이 충분히 크면 다음 순서로 커지는 속도가 빠릅니다(\(a > 0\), \(b > 1\)).

\(\ln n \;\ll\; n^a \;\ll\; b^n \;\ll\; n!\)

예를 들어 \(n = 30\)이면 \(\ln 30 \approx 3.4\), \(30^3 = 27000\), \(2^{30} \approx 1.07\times10^9\), \(30! \approx 2.65\times10^{32}\)입니다. 여기서 \(\ln\)은 밑이 \(e\)인 자연로그입니다. 통계학 책에서는 자연로그를 \(\log\)로 쓰는 경우가 많은데, 이 교재에서도 따로 밝히지 않은 \(\log\)는 자연로그입니다.

정리 1.1.2 (조임 정리)

모든 \(n\)에서 \(a_n \le b_n \le c_n\)이고 \(\lim a_n = \lim c_n = L\)이면 \(\lim b_n = L\)입니다.

가운데 수열을 직접 계산하기 어려울 때, 위아래에서 같은 값으로 가는 두 수열 사이에 끼워 넣는 방법입니다. 예를 들어 \(-1 \le \sin n \le 1\)이므로 \(-\frac1n \le \frac{\sin n}{n} \le \frac1n\)이고, 양쪽이 0으로 가므로 \(\frac{\sin n}{n} \to 0\)입니다.

1.1.2자연상수 \(e\)와 \((1 + x/n)^n\)

고등학교 미적분에서 \(e = \lim_{n\to\infty}(1 + 1/n)^n \approx 2.71828\)로 정의했습니다. 통계에서는 이것을 조금 넓힌 다음 결과를 아주 자주 씁니다.

결과 1.1.3 \[\lim_{n\to\infty}\left(1 + \frac xn\right)^n = e^x\quad(x\text{는 어떤 실수든 됨})\]

이유. \(x > 0\)일 때 \(m = n/x\)로 놓으면 \(\left(1 + \frac xn\right)^n = \left[\left(1 + \frac1m\right)^m\right]^x\)이고, \(n\to\infty\)이면 \(m\to\infty\)이므로 괄호 안이 \(e\)로 가서 전체는 \(e^x\)로 갑니다. \(x < 0\)일 때도 같은 결론이 성립합니다(연습 1.1.4의 응용 문제와 2.1절의 로그 극한으로 확인할 수 있습니다).

이 식은 여러 곳에 나옵니다. 성공 확률이 \(\lambda/n\)인 시행을 \(n\)번 할 때 한 번도 성공하지 않을 확률 \((1 - \lambda/n)^n\)은 \(e^{-\lambda}\)로 가고, 이것이 이항분포가 포아송분포로 가까워지는 출발점입니다. 연이율 \(r\)을 1년에 \(n\)번 나누어 복리로 붙이면 \((1 + r/n)^n \to e^r\)배가 되는 연속 복리도 같은 식입니다.

예제 1.1.4

(가) \(\displaystyle\lim_{n\to\infty}\frac{3n^2 + 5n}{2n^2 - 1}\) (나) \(\displaystyle\lim_{n\to\infty}\frac{n^3}{2^n}\) (다) \(\displaystyle\lim_{n\to\infty}\left(1 - \frac{2}{n}\right)^{3n}\)

풀이. (가) 분자·분모를 \(n^2\)으로 나누면 \(\frac{3 + 5/n}{2 - 1/n^2} \to \frac32\)입니다. (나) 지수함수 \(2^n\)이 다항식 \(n^3\)보다 훨씬 빨리 커지므로 0입니다(\(n = 30\)에서 이미 \(27000/10^9 \approx 0.00003\)). (다) \(\left(1 - \frac2n\right)^{3n} = \left[\left(1 - \frac2n\right)^n\right]^3\)이고 괄호 안이 \(e^{-2}\)로 가므로 \(e^{-6} \approx 0.0025\)입니다.

1.1.3함수의 극한

\(\lim_{x\to a}f(x)\)도 수열과 같은 성질을 따릅니다. \(x = a\)를 넣으면 \(\frac00\)이 되는 꼴은 인수분해나 유리화로 약분한 뒤 넣습니다. 통계에서 특히 자주 쓰는 기본 극한 세 가지는 다음과 같습니다(첫 두 개는 고등학교 미적분에서 \(e^x\)와 \(\ln x\)의 미분을 구할 때 배운 것입니다).

\(\displaystyle\lim_{h\to0}\frac{e^h - 1}{h} = 1\)

\(\displaystyle\lim_{h\to0}\frac{\ln(1+h)}{h} = 1\)

\(\displaystyle\lim_{x\to\infty}x^ke^{-x} = 0\) (\(k\)는 어떤 양수든): 지수함수가 거듭제곱보다 빨리 커지기 때문입니다. 확률밀도의 꼬리가 0으로 가는지 확인할 때 씁니다.

흔한 실수

\((1 + 1/n)^n\)에서 "\(1/n \to 0\)이므로 \(1^n = 1\)"이라고 계산하면 틀립니다. 밑은 1에 가까워지지만 지수 \(n\)은 한없이 커지므로 두 효과가 맞서고, 결과는 1이 아니라 \(e\)입니다. 밑과 지수가 동시에 변하는 극한은 따로 계산해야 합니다.

요약
  1. 분수 꼴은 가장 빨리 커지는 항으로 나누고, 직접 계산이 어려우면 조임 정리를 씁니다.
  2. 커지는 속도: \(\ln n \ll n^a \ll b^n \ll n!\).
  3. \((1 + x/n)^n \to e^x\)는 포아송 근사와 연속 복리의 바탕입니다.

1.1.4연습문제

기본

  1. \(\displaystyle\lim_{n\to\infty}\sqrt{n}\left(\sqrt{n+1} - \sqrt n\right)\)을 구하세요.
    답

    유리화하면 \(\frac{\sqrt n}{\sqrt{n+1} + \sqrt n} = \frac{1}{\sqrt{1 + 1/n} + 1} \to \frac12\).

  2. \(\displaystyle\lim_{n\to\infty}\frac{n!}{n^n}\)이 0임을 \(\frac{n!}{n^n} \le \frac1n\)으로 보이세요.
    답

    \(\frac{n!}{n^n} = \frac1n\cdot\frac2n\cdots\frac nn\)에서 첫 인수 외에는 모두 1 이하이므로 \(0 < \frac{n!}{n^n} \le \frac1n\). 조임 정리로 0입니다.

응용

  1. 이항분포 \(B(n, \lambda/n)\)에서 \(P(X = 0) = (1 - \lambda/n)^n\)의 극한을 구하세요.
    답

    결과 1.1.3에 \(x = -\lambda\)를 넣으면 \(e^{-\lambda}\)입니다. 포아송분포의 \(P(X = 0)\)과 같습니다.
