기하분포의 평균과 분산을 적률생성함수로

예제 · 4.2절과 비교

먼저 읽는 법

4.2절 예제 4.2.1에서는 \(\sum nq^{n-1}\)을 따로 계산해 기하분포의 평균과 분산을 구했다. 등비급수 하나로 적률생성함수를 만든 뒤 로그를 미분해 같은 결과를 얻는다.

문제. \(P(N = n) = q^{n-1}p\)(\(n = 1, 2, \ldots\), \(q = 1 - p\))의 적률생성함수를 구하고, 누율생성함수로 평균과 분산을 구하여라.

풀이

  1. \(M(t) = \sum_{n\ge1}e^{tn}q^{n-1}p = pe^t\sum_{n\ge1}(qe^t)^{n-1} = \dfrac{pe^t}{1 - qe^t}\)(\(qe^t < 1\)).
    등비급수.
  2. \(K(t) = \log p + t - \log(1 - qe^t)\). \(K'(t) = 1 + \dfrac{qe^t}{1 - qe^t}\), \(K'(0) = 1 + q/p = 1/p\).
    평균.
  3. \(K''(t) = \dfrac{qe^t}{(1 - qe^t)^2}\), \(K''(0) = q/p^2\).
    분산.

검산

예제 4.2.1의 결과 \(E(N) = 1/p\), \(V(N) = q/p^2\)와 같다. 주사위(\(p = 1/6\))면 평균 6, 분산 30이다.

의미

적률생성함수는 계산을 "합 여러 번"에서 "합 한 번 + 미분 몇 번"으로 바꾼다. 또 기하분포 \(r\)개의 합(처음 \(r\)번 성공까지의 시행 수, 음이항분포)의 적률생성함수는 \(M(t)^r\)이라, 평균 \(r/p\), 분산 \(rq/p^2\)가 곧바로 나온다.
