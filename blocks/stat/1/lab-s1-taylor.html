다항식 몇 개 항이면 함수를 충분히 흉내 낼까?

실습 · 테일러 근사

목표

\(e^x\), \(\ln(1+x)\), \(\sin x\)를 0 둘레의 테일러 다항식으로 근사하면서, 차수와 점 \(x\)에 따라 오차가 어떻게 달라지는지 봅니다. 라그랑주 나머지로 구한 오차 상한이 실제 오차보다 항상 크거나 같은지도 확인합니다. 성취기준 [응통1-02-03].

\(n\)차 테일러 다항식: \(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(0)}{k!}x^k\). 0에서의 값과 미분계수 \(n\)개를 원래 함수와 똑같이 맞춘 다항식입니다.

라그랑주 나머지: 0과 \(x\) 사이 어떤 \(c\)에 대해 \(f(x) - T_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}x^{n+1}\). \(|f^{(n+1)}|\)의 최댓값으로 오차 상한을 얻습니다.

준비

회색 실선이 원래 함수, 파란 점선이 테일러 다항식입니다. 검은 점은 \(f(x)\), 빨간 점은 \(T_n(x)\)입니다. 계산은 모두 정해진 식이라 같은 설정이면 언제나 같은 값이 나옵니다.

절차

  1. \(e^x\), \(x = 1\)에서 차수를 0부터 6까지 올리며 \(T_n(1)\)과 실제 오차를 적습니다.
  2. 각 차수에서 출력의 오차 상한과 실제 오차를 비교합니다.
  3. 차수를 4로 두고 \(x\)를 0.5, 1, 2, 3으로 바꿉니다. 0에서 멀어질수록 오차가 어떻게 되나요?
  4. \(\ln(1+x)\)로 바꾸어 \(x = 0.5\)와 \(x = 1.5\)에서 차수를 2, 4, 8, 12로 올려 봅니다.
  5. \(\sin x\)에서 \(x = 3\)을 두고, 그래프가 언제부터 원래 곡선과 겹치는지 봅니다.

기대 결과

  • \(e^1 = 2.718282\)에 대해 \(T_2(1) = 2.5\), \(T_4(1) = 2.708333\)(오차 약 0.00995), \(T_6(1) = 2.718056\)(오차 약 0.000226)으로, 차수를 2 올릴 때마다 오차가 수십 분의 1로 줄어듭니다.
  • 오차 상한(예: \(n = 4\)에서 \(e/5! \approx 0.0227\))은 언제나 실제 오차 이상입니다. 상한은 보장이지 정확한 값은 아닙니다.
  • 같은 차수에서 \(x\)가 0에서 멀어질수록 오차가 빠르게 커집니다(\(|x|^{n+1}\)에 비례). \(x = 3\), \(n = 4\)이면 \(T_4(3) = 16.375\)인데 \(e^3 \approx 20.09\)라 오차가 3.7이나 됩니다.
  • \(\ln(1+x)\)는 \(x = 0.5\)에서 차수를 올리면 오차가 줄지만(\(n = 4\)에서 약 0.0044), \(x = 1.5\)에서는 차수를 올릴수록 오히려 크게 빗나갑니다. 이 급수의 수렴 반지름이 1이기 때문입니다.
  • \(\sin x\)는 모든 \(x\)에서 수렴하지만, \(x = 3\)처럼 멀면 차수가 7~9쯤은 되어야 그림에서 거의 겹칩니다.

분석

  1. 통계에서 \(\ln(1+x) \approx x\)(1차 근사)를 쓰는 경우를 떠올리고, 어느 범위의 \(x\)에서 믿을 만한지 이 실습 결과로 정해 보세요.
  2. 델타 방법(응통6-07-04)은 1차 테일러 근사입니다. 근사가 나빠지는 상황은 무엇일까요?
  3. \(\ln(1+x)\)의 급수가 \(|x| > 1\)에서 발산하는 것을 \(k\)번째 항 \((-1)^{k+1}x^k/k\)의 크기로 설명해 보세요.
