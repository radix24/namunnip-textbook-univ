거듭제곱급수와 기하급수로 기대값 계산하기

본문
이 절에서 배울 것
  • 기하급수의 합과 그 도함수로 기하분포의 평균·분산을 구한다.
  • \(e^x\)의 거듭제곱급수로 포아송분포의 기대값을 구한다.
먼저 알아야 할 것
  • 급수 판정 (4.1절), 테일러 전개 (2.3절).

합을 닫힌 꼴로

판정법은 "수렴한다"까지만 알려 줍니다. 기대값의 실제 값을 얻으려면 합을 계산해야 하고, 그 열쇠는 기하급수와 지수함수의 급수입니다.

4.2.1기하급수와 미분

\(|x| < 1\)이면 \(\sum_{n=0}^\infty x^n = \frac{1}{1-x}\). 거듭제곱급수는 수렴 구간 안에서 항별로 미분할 수 있으므로

\[\sum_{n=1}^\infty nx^{n-1} = \frac{1}{(1-x)^2}, \qquad \sum_{n=2}^\infty n(n-1)x^{n-2} = \frac{2}{(1-x)^3}.\]
예제 4.2.1

기하분포 \(p(n) = (1-p)^{n-1}p\) (\(n = 1, 2, \ldots\))의 평균과 분산을 구하세요.

풀이. \(q = 1 - p\). \(E(N) = p\sum nq^{n-1} = \frac{p}{(1-q)^2} = \frac1p\). \(E[N(N-1)] = pq\sum n(n-1)q^{n-2} = \frac{2pq}{p^3} = \frac{2q}{p^2}\). \(\mathrm{Var} = E[N(N-1)] + E(N) - E(N)^2 = \frac{2q}{p^2} + \frac1p - \frac1{p^2} = \frac{q}{p^2}\).

4.2.2지수함수의 급수

\(e^x = \sum_{n=0}^\infty\frac{x^n}{n!}\)(모든 \(x\)에서 수렴).

예제 4.2.2

포아송분포의 평균을 구하세요.

풀이. \(\sum_{n=0}^\infty n\frac{e^{-\lambda}\lambda^n}{n!} = \lambda e^{-\lambda}\sum_{n=1}^\infty\frac{\lambda^{n-1}}{(n-1)!} = \lambda e^{-\lambda}e^\lambda = \lambda\). \(n = 0\) 항이 0이라 \(n = 1\)부터 시작하고, 지표를 하나 옮겨 \(e^\lambda\)의 급수를 만들었습니다.

요약
  1. \(\sum x^n = 1/(1-x)\), 미분해서 \(\sum nx^{n-1}\).
  2. \(e^x = \sum x^n/n!\), 지표 옮기기.
  3. 분산은 \(E[N(N-1)]\)을 먼저 구하면 편합니다.

4.2.3연습문제

기본

  1. 포아송분포의 분산을 \(E[N(N-1)]\)로 구하세요.
    답

    \(E[N(N-1)] = \lambda^2\), 분산 \(\lambda^2 + \lambda - \lambda^2 = \lambda\).
