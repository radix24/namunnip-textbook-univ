거듭제곱급수와 등비급수로 기댓값 계산하기

본문

주사위를 6이 나올 때까지 던지면 평균 몇 번 던지게 될까? 답은 6번인데, 이것을 구하려면 \(1\cdot p + 2\cdot qp + 3\cdot q^2p + \cdots\)라는 끝없는 합을 계산해야 한다. 이런 합은 어떻게 구할까?

먼저 알아야 할 것급수 판정(4.1절), 테일러 전개(2.3절), 고등학교 미적분의 등비급수, 확률과 통계의 평균과 분산 \(V(X) = E(X^2) - \{E(X)\}^2\)을 쓴다.

4.2.1합을 실제로 구하기

4.1절의 판정법은 급수가 수렴하는지까지만 알려 준다. 평균이 실제로 얼마인지 알려면 합을 계산해야 한다. 다행히 통계에서 만나는 무한급수 대부분은 두 가지, 곧 등비급수와 \(e^x\)의 급수로 바꾸어 계산할 수 있다.

4.2.2등비급수에서 \(\sum nx^{n-1}\)로

고등학교에서 배운 등비급수의 합은 \(|x| < 1\)일 때 \(\sum_{n=0}^\infty x^n = \dfrac{1}{1-x}\)이다. 그런데 평균을 구할 때는 각 항에 \(n\)이 곱해진 합 \(T = \sum_{n=1}^\infty nx^{n-1} = 1 + 2x + 3x^2 + \cdots\)이 필요하다. 이때 등비급수의 합을 구할 때 썼던 "\(S - xS\)" 방법을 그대로 쓰면 된다. \(T\)에서 \(xT\)를 빼면 계수가 한 칸씩 어긋나 지워지고

\[T - xT = 1 + x + x^2 + \cdots = \frac{1}{1-x}\]

가 남는다. 따라서 \((1 - x)T = \frac{1}{1-x}\)이고, 결국

\[\sum_{n=1}^\infty nx^{n-1} = \frac{1}{(1-x)^2}\quad(|x| < 1)\]

이다. 같은 결과를 \(\frac{1}{1-x} = \sum x^n\)의 양변을 \(x\)로 미분해서 얻을 수도 있다. 수렴 범위 안에서는 무한급수도 다항식처럼 항마다 미분해도 된다는 정리가 있기 때문이다. 한 번 더 미분하면 \(\sum_{n=2}^\infty n(n-1)x^{n-2} = \frac{2}{(1-x)^3}\)도 얻는다.

예제 4.2.1

성공 확률이 \(p\)인 시행을 처음 성공할 때까지 반복할 때 시행 횟수 \(N\)의 분포는 \(P(N = n) = (1-p)^{n-1}p\) (\(n = 1, 2, \ldots\))이다(기하분포). \(N\)의 평균과 분산을 구하여라.

풀이. \(q = 1 - p\)로 쓴다. 먼저 확률의 합은 \(p\sum_{n=1}^\infty q^{n-1} = \frac{p}{1-q} = 1\)이므로 제대로 된 분포이다. 평균은 위 결과에 \(x = q\)를 넣어 \(E(N) = p\sum_{n=1}^\infty n\,q^{n-1} = p\cdot\frac{1}{(1-q)^2} = \frac1p\)이다. 처음 질문의 주사위는 \(p = 1/6\)이므로 평균 6번 던진다.

분산은 \(E(N^2)\)를 바로 구하기보다 \(E[N(N-1)]\)을 먼저 구하는 것이 편하다. 둘째 미분 결과를 쓰면 \(E[N(N-1)] = pq\sum_{n=2}^\infty n(n-1)q^{n-2} = pq\cdot\frac{2}{p^3} = \frac{2q}{p^2}\)이다. 그런데 \(E(N^2) = E[N(N-1)] + E(N)\)이므로

\[V(N) = \frac{2q}{p^2} + \frac1p - \frac{1}{p^2} = \frac{2q + p - 1}{p^2} = \frac{q}{p^2}\]

이다. 주사위라면 \(V = (5/6)/(1/36) = 30\), 표준편차는 약 5.5이다. 평균 6번이지만 그림 1의 긴 꼬리 때문에 흩어짐이 크다.

4.2.3지수함수의 급수

둘째 도구는 2.3절의 테일러 전개 \(e^x = \sum_{n=0}^\infty\frac{x^n}{n!}\)이다. 이 급수는 4.1절 예제의 비 판정에 따라 모든 \(x\)에서 수렴한다.

예제 4.2.2

포아송분포 \(P(N = n) = e^{-\lambda}\dfrac{\lambda^n}{n!}\) (\(n = 0, 1, 2, \ldots\))의 확률을 모두 더하면 1임을 보이고, 평균을 구하여라.

풀이. 확률의 합은 \(e^{-\lambda}\sum\frac{\lambda^n}{n!} = e^{-\lambda}e^\lambda = 1\)이다. 평균은 \(\sum_{n=0}^\infty n\,e^{-\lambda}\frac{\lambda^n}{n!}\)인데, \(n = 0\)인 항은 0이므로 \(n = 1\)부터 더하고 \(\frac{n}{n!} = \frac{1}{(n-1)!}\)로 약분한다. 그러면 \(\lambda e^{-\lambda}\sum_{n=1}^\infty\frac{\lambda^{n-1}}{(n-1)!}\)이 된다. 여기서 \(m = n - 1\)로 바꾸면 남은 합이 \(\sum_{m=0}^\infty\frac{\lambda^m}{m!} = e^\lambda\)이므로 평균은 \(\lambda\)이다.

흔한 실수합의 시작값을 바꾸면서 식 안의 \(n\)을 바꾸지 않는 실수가 흔하다. "\(m = n - 1\)"처럼 새 문자를 도입해 시작값(\(n = 1\)이면 \(m = 0\))과 식 안의 \(n\)을 함께 바꾸면 틀리지 않는다.
마무리

등비급수 \(\sum x^n = \frac{1}{1-x}\)에 \(S - xS\) 방법이나 미분을 쓰면 \(\sum nx^{n-1} = \frac{1}{(1-x)^2}\)을 얻고, 이것으로 기하분포의 평균 \(1/p\)와 분산 \(q/p^2\)을 구한다. 그래서 주사위를 6이 나올 때까지 던지면 평균 6번이다. 포아송 계산은 \(e^x = \sum\frac{x^n}{n!}\)과 시작값 옮기기로 하며, 분산은 \(E[N(N-1)]\)을 먼저 구하면 편하다.

4.2.4연습문제

기본

  1. \(\displaystyle\sum_{n=1}^\infty\frac{n}{2^n}\)을 구하여라.
    답

    \(\frac12\sum n(\frac12)^{n-1} = \frac12\cdot\frac{1}{(1/2)^2} = 2\)이다.

응용

  1. 포아송분포의 분산을 \(E[N(N-1)]\)로 구하여라.
    답

    \(E[N(N-1)] = e^{-\lambda}\sum_{n=2}^\infty\frac{\lambda^n}{(n-2)!} = \lambda^2\)이므로 분산은 \(\lambda^2 + \lambda - \lambda^2 = \lambda\)이다. 평균과 분산이 같다.
