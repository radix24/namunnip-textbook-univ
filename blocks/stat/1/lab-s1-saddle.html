그릇, 산, 말안장: 판정식 D는 무엇을 보는가?

실습 · 이변수 극값 판정

목표

임계점 근처의 함수는 이차식 \(q(h, k) = Ah^2 + 2Bhk + Ck^2\)처럼 생겼습니다(5.2절). \(A, B, C\)를 바꾸며 이 이차식의 부호 지도를 보고, 판정식 \(D = AC - B^2\)의 부호가 그릇(극소), 산(극대), 말안장(안장점)을 정확히 가른다는 것을 확인합니다. 성취기준 [응통1-05-02].

\(A, B, C\): 임계점에서의 \(f_{xx}\), \(f_{xy}\), \(f_{yy}\). 각각 동서 방향으로 휘는 정도, 비틀린 정도, 남북 방향으로 휘는 정도입니다.

준비

그림은 원점(임계점) 둘레에서 \(q\)의 값을 색으로 칠한 것입니다. 빨강은 \(q > 0\)(임계점보다 높음), 파랑은 \(q < 0\)(낮음)이고 진할수록 크기가 큽니다. 검은 선은 높이가 같은 점을 이은 등고선입니다. 안장점이면 주황 화살표가 \(A\)와 반대 부호가 되는 방향 \((h, k) = (-B/A, 1)\)을 가리킵니다.

절차

  1. 처음 설정 \(A = C = 2\), \(B = 1\)(5.2절 예제와 같은 값)에서 색과 등고선 모양, \(D\)를 적습니다.
  2. \(A\)와 \(C\)는 2로 둔 채 \(B\)를 1에서 3까지 올립니다. \(D\)의 부호가 언제 바뀌고, 그림이 어떻게 변하나요?
  3. \(A = 1\), \(B = 1.5\), \(C = 1\)로 두고, \(A\)와 \(C\)가 모두 양수인데도 파란 영역이 생기는 것을 확인합니다. 주황 화살표 방향으로 가면 어떻게 되나요?
  4. \(A = -2\), \(B = 0\), \(C = -1\)과 \(A = 2\), \(B = 0\), \(C = -1\)을 비교합니다.
  5. \(D = 0\)이 되는 설정(예: \(A = 1\), \(B = 1\), \(C = 1\))을 찾아 그림이 어떻게 생겼는지 봅니다.

기대 결과

  • 처음 설정은 \(D = 3 > 0\), \(A > 0\)이라 사방이 빨강인 그릇(극소)이고, 등고선은 대각선 방향으로 비스듬한 타원입니다.
  • \(A = C = 2\)에서 \(B\)가 2를 넘으면 \(D = 4 - B^2 < 0\)이 되어 파란 띠가 나타나고(안장점), 등고선이 타원에서 쌍곡선 모양으로 바뀝니다. \(B = 2\)이면 \(D = 0\)입니다.
  • \(A = C = 1\), \(B = 1.5\)이면 \(D = 1 - 2.25 = -1.25 < 0\)입니다. \(x\)축·\(y\)축 방향은 빨강이지만 대각선 \((-1.5, 1)\) 방향은 파랑입니다. "\(f_{xx}\)와 \(f_{yy}\)가 모두 양수면 극소"는 틀린 판단입니다(5.2절의 흔한 실수).
  • \(A = -2\), \(C = -1\), \(B = 0\)은 사방이 파랑인 산(극대), \(A = 2\), \(C = -1\)은 \(x\) 방향으로는 오르고 \(y\) 방향으로는 내리는 말안장입니다.
  • \(D = 0\)이면 어떤 방향 하나에서 \(q\)가 0이 되어(그 방향으로 평평) 이차식만으로는 극값을 판정할 수 없습니다.

분석

  1. 완전제곱 \(A(h + \frac BAk)^2 + \frac DAk^2\)를 보고, \(D < 0\)일 때 주황 화살표 방향에서 \(q\)의 부호가 \(A\)와 반대가 되는 까닭을 설명해 보세요.
  2. 로그가능도의 꼭대기(최대가능도 추정값)에서 \(A, B, C\)는 어떤 부호 조건을 만족해야 하나요?
  3. 등고선이 가늘고 길게 늘어난 타원이면 어느 방향으로의 추정이 덜 정밀할지 생각해 보세요.

더 해 보기
