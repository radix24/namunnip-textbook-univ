치환적분과 부분적분

본문
이 절에서 배울 것
  • 치환적분과 부분적분으로 정적분을 계산한다.
  • 기대값 계산에 적용한다.
먼저 알아야 할 것
  • 고교 수학II 정적분, 미분 (2.1절).

기대값은 적분이다

연속형 확률변수의 평균은 \(E(X) = \int xf(x)\,dx\)입니다. 밀도가 \(\lambda e^{-\lambda x}\)이면 \(x\)와 지수함수의 곱을 적분해야 하므로 부분적분이 필요합니다.

3.1.1치환적분

정리 3.1.1

\(u = g(x)\)이면 \(\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)}f(u)\,du\).

연쇄법칙을 거꾸로 쓴 것입니다. 적분 구간도 함께 바꿉니다.

예제 3.1.2

\(\int_0^\infty xe^{-x^2/2}dx\)를 구하세요.

풀이. \(u = x^2/2\), \(du = x\,dx\). \(\int_0^\infty e^{-u}du = 1\).

3.1.2부분적분

정리 3.1.3

\(\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du\).

곱의 미분법을 거꾸로 쓴 것입니다. 미분하면 간단해지는 쪽(다항식, 로그)을 \(u\)로, 적분하기 쉬운 쪽(지수, 삼각)을 \(dv\)로 고릅니다.

예제 3.1.4

지수분포의 평균 \(\int_0^\infty x\lambda e^{-\lambda x}dx\)를 구하세요.

풀이. \(u = x\), \(dv = \lambda e^{-\lambda x}dx\), \(v = -e^{-\lambda x}\). \([-xe^{-\lambda x}]_0^\infty + \int_0^\infty e^{-\lambda x}dx = 0 + \frac1\lambda\). 첫 항이 0인 것은 \(xe^{-\lambda x} \to 0\)(1.1절)이기 때문입니다.

요약
  1. 치환: 연쇄법칙의 역, 구간도 바꿈.
  2. 부분적분: 곱의 미분의 역, \(u\)는 미분하면 간단해지는 것.
  3. 기대값, 분산 계산에 반복해서 씁니다.

3.1.3연습문제

기본

  1. \(\int_0^\infty x^2e^{-x}dx\)를 부분적분으로 구하세요.
    답

    두 번 부분적분하면 2. (3.3절의 \(\Gamma(3) = 2! = 2\).)

  2. \(\int_1^e\log x\,dx\)는?
    답

    \(u = \log x\), \(dv = dx\): \([x\log x]_1^e - \int_1^e 1\,dx = e - (e - 1) = 1\).
