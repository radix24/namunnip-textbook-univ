  • 고등학교 미적분의 정적분, 치환적분법, 부분적분법, 그리고 미분 (2.1절). 확률과 통계의 확률밀도함수.

확률과 기댓값은 적분이다

고등학교 확률과 통계에서 연속확률변수 \(X\)의 확률 \(P(a \le X \le b)\)는 확률밀도함수 \(f(x)\)의 그래프 아래 넓이, 곧 \(\int_a^bf(x)\,dx\)라고 배웠습니다. 평균(기댓값)도 같은 방식으로 정의합니다. 이산확률변수의 평균이 \(E(X) = \sum x_i\,P(X = x_i)\)였듯이, 연속확률변수는 합 대신 적분을 써서

\(E(X) = \displaystyle\int x\,f(x)\,dx\)

입니다(적분 구간은 \(X\)가 가질 수 있는 값 전체). 이런 적분에는 \(x\)와 지수함수의 곱처럼 바로 원시함수를 찾기 어려운 식이 자주 나오므로, 고등학교에서 배운 두 적분 기술을 다시 정리합니다.

3.1.1치환적분

정리 3.1.1

\(u = g(x)\)로 두면 \(\displaystyle\int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)}f(u)\,du\)입니다.

합성함수의 미분(연쇄법칙)을 거꾸로 쓴 것입니다. "\(du = g'(x)\,dx\)"로 기억하고, 적분 구간도 \(x\)의 범위에서 \(u\)의 범위로 함께 바꿉니다. 피적분함수 안에 "어떤 식"과 "그 식의 도함수"가 함께 보이면 치환을 떠올리면 됩니다.

예제 3.1.2

\(\displaystyle\int_0^2 xe^{-x^2/2}dx\)를 구하세요.

풀이. 지수 안의 \(-x^2/2\)를 미분하면 \(-x\)가 되고, 앞에 \(x\)가 곱해져 있으므로 \(u = x^2/2\)로 둡니다. \(du = x\,dx\)이고 \(x = 0 \to u = 0\), \(x = 2 \to u = 2\)이므로 \(\int_0^2 e^{-u}du = [-e^{-u}]_0^2 = 1 - e^{-2} \approx 0.865\)입니다.

3.1.2부분적분

정리 3.1.3

\(\displaystyle\int_a^b u(x)v'(x)\,dx = \big[u(x)v(x)\big]_a^b - \int_a^b u'(x)v(x)\,dx\). 줄여서 \(\int u\,dv = uv - \int v\,du\)로 씁니다.

곱의 미분 \((uv)' = u'v + uv'\)를 양변 적분하고 정리한 것입니다. 곱의 한쪽을 미분하고 다른 쪽을 적분하는 셈이므로, 미분하면 간단해지는 쪽(다항식, 로그)을 \(u\)로, 적분하기 쉬운 쪽(지수함수, 삼각함수)을 \(v'\)으로 고르는 것이 요령입니다.

예제 3.1.4

\(\displaystyle\int_0^1 xe^{x}\,dx\)를 구하세요.

풀이. \(u = x\)(미분하면 1), \(v' = e^x\)(적분하면 \(e^x\))로 고르면 \(\big[xe^x\big]_0^1 - \int_0^1 e^x dx = e - (e - 1) = 1\)입니다. 반대로 \(u = e^x\), \(v' = x\)로 고르면 \(\int\frac{x^2}{2}e^x dx\)가 나와 더 어려워집니다.

예제 3.1.5

확률밀도함수가 \(f(x) = 2x\) (\(0 \le x \le 1\))인 확률변수의 \(P(X \le 0.5)\)와 \(E(X)\)를 구하세요. 또 밀도가 \(f(x) = 3e^{-3x}\) (\(0 \le x \le 1\)에서만 생각)일 때 \(\int_0^1 x\cdot3e^{-3x}dx\)를 부분적분으로 계산하세요.

풀이. \(P(X \le 0.5) = \int_0^{0.5}2x\,dx = 0.25\), \(E(X) = \int_0^1 x\cdot2x\,dx = \frac23\)입니다.

둘째 적분은 \(u = x\), \(v' = 3e^{-3x}\), \(v = -e^{-3x}\)로 두면 \(\big[-xe^{-3x}\big]_0^1 + \int_0^1 e^{-3x}dx = -e^{-3} + \frac{1 - e^{-3}}{3} \approx 0.284\)입니다. 적분 구간을 \(0\)부터 끝없이 늘리면 첫 항이 0으로 가고 둘째 항이 \(\frac13\)으로 가서 지수분포의 평균 \(\frac13\)이 됩니다. 이렇게 끝이 무한대인 적분은 다음 절(이상적분)에서 다룹니다.

흔한 실수

치환한 뒤 적분 구간을 바꾸지 않고 원래 \(x\)의 구간을 그대로 쓰는 실수가 가장 흔합니다. 구간을 바꾸기 싫으면 원시함수를 \(x\)로 되돌린 뒤 원래 구간을 넣어도 됩니다. 둘 중 하나를 일관되게 하세요.

요약
  1. 치환적분: 연쇄법칙의 역. \(du = g'(x)dx\)로 바꾸고 구간도 바꿉니다.
  2. 부분적분: 곱의 미분의 역. 미분하면 간단해지는 쪽을 \(u\)로 고릅니다.
  3. 연속확률변수의 확률은 \(\int_a^bf\), 기댓값은 \(\int xf\)이며, 이 계산에 두 기술을 계속 씁니다.

3.1.3연습문제

기본

  1. \(\displaystyle\int_1^e\ln x\,dx\)를 구하세요.
    답

    \(u = \ln x\), \(v' = 1\)(\(v = x\)): \([x\ln x]_1^e - \int_1^e 1\,dx = e - (e - 1) = 1\).

  2. \(\displaystyle\int_0^1 x^2e^{x}dx\)를 부분적분을 두 번 써서 구하세요.
    답

    \([x^2e^x]_0^1 - 2\int_0^1 xe^xdx = e - 2\times1 = e - 2 \approx 0.718\) (예제 3.1.4 이용).

응용

  1. 밀도 \(f(x) = 2x\) (\(0 \le x \le 1\))인 확률변수의 분산 \(V(X) = E(X^2) - \{E(X)\}^2\)을 구하세요.
    답

    \(E(X^2) = \int_0^1 x^2\cdot2x\,dx = \frac12\), \(V(X) = \frac12 - \frac49 = \frac{1}{18}\).
