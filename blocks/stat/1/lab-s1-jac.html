좌표를 바꾸면 작은 칸의 넓이는 몇 배가 될까?

실습 · 야코비안

목표

\((u, v)\) 평면의 격자를 변환 \((x, y) = T(u, v)\)로 옮겨, 작은 정사각형 칸이 평행사변형(또는 부채꼴 조각)으로 바뀌는 모습을 봅니다. 바뀐 칸의 넓이를 원래 넓이로 나눈 배율이 야코비안의 절댓값 \(|J|\)와 같다는 것을 숫자로 확인합니다. 성취기준 [응통1-06-02], [응통1-06-03].

야코비안: \(J = x_uy_v - x_vy_u\). 작은 칸의 넓이 배율이며, \(dx\,dy = |J|\,du\,dv\)입니다(6.2절).

준비

왼쪽 그림은 \((u, v)\) 격자, 오른쪽은 변환한 \((x, y)\) 격자입니다. 주황 칸 하나가 어디로 가는지 따라가며, 출력에서 옮긴 칸의 실제 넓이(다각형 넓이로 계산)와 \(|J|\)를 비교합니다. "칸 위치"로 주황 칸을 옮길 수 있습니다.

절차

  1. 일차변환 처음 설정(\(a = 1\), \(b = 0.5\), \(c = 0\), \(d = 1\))에서 정사각형이 어떤 모양이 되는지, 넓이 배율과 \(|J|\)를 적습니다.
  2. \(a = 2\), \(d = 1\), \(b = c = 0\)과 \(a = 1\), \(b = 1\), \(c = 1\), \(d = 1\)을 해 봅니다. 두 번째에서는 무슨 일이 생기나요?
  3. 칸 위치를 바꾸어도 일차변환의 배율이 같은지 확인합니다.
  4. 극좌표로 바꾸고 칸 위치 \(u\)(= 반지름 \(r\))를 0 근처에서 1 가까이까지 옮기며 배율을 적습니다.

기대 결과

  • 처음 설정은 정사각형을 옆으로 미는 변환(층밀림)이라 칸이 평행사변형이 되지만 넓이는 그대로라 배율 1.000, \(J = 1\cdot1 - 0.5\cdot0 = 1\)입니다.
  • \(a = 2\), \(d = 1\)이면 가로로 두 배 늘어 배율 2입니다. \(a = b = c = d = 1\)이면 \(J = 1 - 1 = 0\)이라 모든 칸이 한 직선 위로 납작해져 넓이가 0입니다(일대일이 아닌 변환).
  • 일차변환에서는 칸이 어디에 있든 배율이 같습니다. \(J\)가 상수이기 때문입니다.
  • 극좌표에서는 반지름 \(r\)이 큰 칸일수록 넓어져, 배율이 칸 가운데의 \(r\)과 거의 같습니다(예: \(r \in [0.5, 0.75]\)인 칸은 배율 약 0.62, \(|J| = 0.625\)). 칸이 부채꼴 조각이라 다각형 근사와 \(|J|\)가 아주 조금 다를 수 있습니다. 이것이 \(dx\,dy = r\,dr\,d\theta\)의 뜻입니다.

분석

  1. \(J\)가 음수가 되는 설정(예: \(a = 0\), \(b = 1\), \(c = 1\), \(d = 0\))에서 격자는 어떻게 보이나요? 넓이 배율에 절댓값을 붙이는 까닭을 설명해 보세요.
  2. 정규분포의 \(\sqrt{2\pi}\)를 구할 때(6.3절) 극좌표의 배율 \(r\)이 왜 꼭 필요한지 설명해 보세요.
  3. 확률밀도를 변환할 때 \(f_{U,V} = f_{X,Y}\cdot|J|\)인 까닭을 "확률 = 밀도 × 넓이"로 설명해 보세요.
