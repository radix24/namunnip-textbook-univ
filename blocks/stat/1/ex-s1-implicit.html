역변환법 난수와 분위수 함수

예제 · 역함수의 응용

먼저 읽는 법

균등 난수 \(U\)를 분위수 함수에 넣으면 원하는 분포의 난수가 됩니다(응통15 4.2절). 분위수 함수의 기울기가 클수록 \(U\)의 작은 변화가 큰 값으로 번져, 그 구간의 밀도가 낮아진다.

문제. 밀도 \(f(x) = 2x\)(\(0 \le x \le 1\))인 분포의 분위수 함수를 구하고, 역함수 미분으로 \(Q'(p)\)를 검산하여라. \(U = 0.25\)이면 생성되는 값은?

풀이

  1. \(F(x) = x^2\), \(x^2 = p\)에서 \(Q(p) = \sqrt p\).
    분포함수의 역함수.
  2. 직접 미분 \(Q'(p) = \frac{1}{2\sqrt p}\). 역함수 공식 \(\frac{1}{f(Q(p))} = \frac{1}{2\sqrt p}\). 같다.
    정리 2.4.1.
  3. \(U = 0.25\) → \(\sqrt{0.25} = 0.5\).
    역변환법.

검산

\(P(X \le 0.5) = 0.25\)로 \(U\)와 같은 확률이다. \(p\)가 0 근처면 \(Q'\)가 무한히 커지는데, 0 근처의 밀도 \(2x\)가 0에 가까워 값이 드물게 나오기 때문이다.

의미

분위수 함수와 그 기울기를 알면 난수 생성, 분위수 추정의 정밀도, 신뢰구간의 폭을 한 번에 이해할 수 있다. 정규분포처럼 분위수 함수를 식으로 쓸 수 없을 때도 역함수 미분 공식은 기울기를 정확히 알려 준다.
