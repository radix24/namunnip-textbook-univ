감마 함수와 베타 함수

본문

\(3! = 6\)이고 \(4! = 24\)이다. 그렇다면 \(2.5!\)은 얼마일까? 계승을 정수가 아닌 수로 넓히는 것이 무슨 쓸모가 있기에 카이제곱분포와 t 분포의 식마다 그런 값이 나올까?

먼저 알아야 할 것부분적분과 이상적분(3.1절, 3.2절), 고등학교 확률과 통계의 계승 \(n!\)을 쓴다.

3.3.1계승을 실수로 넓히기

부분적분을 되풀이하면 \(\int_0^\infty x^2e^{-x}dx = 2\), \(\int_0^\infty x^3e^{-x}dx = 6\)처럼 \(\int_0^\infty x^ne^{-x}dx = n!\)이 나온다. 그런데 이 적분은 지수가 2.5처럼 정수가 아니어도 계산할 수 있다. 따라서 이 적분을 이용하면 계승을 정수가 아닌 수로 넓힐 수 있다. 이렇게 만든 함수가 감마 함수이고, 감마분포, 카이제곱분포, t 분포처럼 통계에서 중요한 분포의 밀도 상수에 모두 들어 있다. 이 분포들의 모수가 반정수일 때가 많아 정수가 아닌 곳의 값이 필요하다.

3.3.2감마 함수

정의 3.3.1 (감마 함수)

\(\alpha > 0\)에 대해 \(\Gamma(\alpha) = \displaystyle\int_0^\infty x^{\alpha-1}e^{-x}dx\)이다.

지수 \(\alpha - 1\)이 한 칸 밀려 있다는 점에 주의한다. 이 적분이 수렴하는 까닭은 두 끝에서 따로 확인된다. \(x\)가 클 때는 \(e^{-x}\)가 어떤 거듭제곱보다 빨리 줄고(1.1절), \(x\)가 0 근처일 때는 \(x^{\alpha-1}\)의 지수가 \(-1\)보다 커서 3.2절 결과 3.2.3의 조건을 만족하기 때문이다.

정리 3.3.2

(가) \(\Gamma(\alpha + 1) = \alpha\Gamma(\alpha)\). (나) 자연수 \(n\)에 대해 \(\Gamma(n) = (n-1)!\). (다) \(\Gamma(1/2) = \sqrt\pi\).

증명.(가) 부분적분에서 \(u = x^\alpha\), \(v' = e^{-x}\)(\(v = -e^{-x}\))로 두면 \(\Gamma(\alpha + 1) = \big[-x^\alpha e^{-x}\big]_0^\infty + \alpha\int_0^\infty x^{\alpha-1}e^{-x}dx\)이다. 첫 항은 \(x = 0\)에서도 \(x \to \infty\)에서도 0이므로 \(\alpha\Gamma(\alpha)\)만 남는다. (나) \(\Gamma(1) = \int_0^\infty e^{-x}dx = 1\)이고, (가)를 되풀이하면 \(\Gamma(2) = 1\), \(\Gamma(3) = 2\), \(\Gamma(4) = 6\), 곧 \(\Gamma(n) = (n-1)!\)이다. \(\Gamma(1) = 1\)은 \(0! = 1\)이라는 약속과도 맞는다. (다) \(x = z^2/2\)로 치환하면 \(dx = z\,dz\), \(x^{-1/2} = \sqrt2/z\)이므로 \(\Gamma(1/2) = \sqrt2\int_0^\infty e^{-z^2/2}dz\)이다. 6.3절에서 \(\int_{-\infty}^\infty e^{-z^2/2}dz = \sqrt{2\pi}\)를 보이며, 대칭이라 0부터의 적분은 그 절반이다. 따라서 \(\Gamma(1/2) = \sqrt2\cdot\frac{\sqrt{2\pi}}{2} = \sqrt\pi\)이다. ∎

(가)의 점화식이 그림 1의 곡선을 정수 사이에서 이어 주는 규칙이다. 처음 질문의 \(2.5!\)은 \(\Gamma(3.5) = \frac52\cdot\frac32\cdot\frac12\sqrt\pi \approx 3.32\)이다.

자주 쓰는 꼴이 하나 더 있다. \(x = \beta u\)로 치환하면 \(\int_0^\infty x^{\alpha-1}e^{-x/\beta}dx = \Gamma(\alpha)\beta^\alpha\)이다. 그러므로 이런 모양의 적분은 부분적분을 여러 번 하지 않고 감마 함수로 바로 계산할 수 있다. 가령 \(\int_0^\infty x^3e^{-2x}dx = \Gamma(4)(1/2)^4 = 6/16 = 3/8\)이다.

3.3.3베타 함수

정의 3.3.3 (베타 함수)

\(a, b > 0\)에 대해 \(B(a, b) = \displaystyle\int_0^1 x^{a-1}(1-x)^{b-1}dx\)이다.

정리 3.3.4

\(B(a, b) = \dfrac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}\).

증명에는 변수가 둘인 적분과 좌표 변환이 필요해 6.2절의 연습문제로 미룬다. 정수 \(a, b\)라면 \(B(a, b) = \frac{(a-1)!(b-1)!}{(a+b-1)!}\)이고, 작은 경우는 전개해서 직접 확인할 수 있다. 예를 들어 \(B(2, 2) = \int_0^1(x - x^2)dx = \frac16 = \frac{1!\,1!}{3!}\)이다. 0과 1 사이의 비율을 나타내는 베타분포의 밀도 상수가 \(1/B(a, b)\)이다.

예제 3.3.5

(가) \(\Gamma(5/2)\) (나) \(\displaystyle\int_0^1 x^3(1-x)^2dx\)를 구하여라.

풀이. (가) 정리 3.3.2 (가)를 두 번 쓰면 \(\Gamma(\frac52) = \frac32\Gamma(\frac32) = \frac32\cdot\frac12\Gamma(\frac12) = \frac34\sqrt\pi \approx 1.329\)이다. (나) 피적분함수가 \(x^{4-1}(1-x)^{3-1}\)이므로 \(B(4, 3) = \frac{3!\,2!}{6!} = \frac{12}{720} = \frac1{60}\)이다. 전개해서 적분한 \(\frac14 - \frac25 + \frac16\)도 같은 값이다.

흔한 실수\(\Gamma(n) = n!\)로 착각하기 쉽다. \(\Gamma(n) = (n-1)!\)이므로 \(\Gamma(5) = 24\)이다. 정의의 지수가 \(\alpha - 1\)이라는 것을 떠올리면 헷갈리지 않는다.
마무리

감마 함수 \(\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}dx\)는 \(\Gamma(\alpha+1) = \alpha\Gamma(\alpha)\)를 만족해 정수에서 \(\Gamma(n) = (n-1)!\)이 되고, 그 사이를 매끄럽게 이어 \(\Gamma(1/2) = \sqrt\pi\), \(2.5! = \Gamma(3.5) \approx 3.32\) 같은 값을 준다. \(\int_0^\infty x^{\alpha-1}e^{-x/\beta}dx = \Gamma(\alpha)\beta^\alpha\)로 지수 꼴 적분을 바로 계산하고, 0과 1 사이의 적분은 베타 함수 \(B(a,b) = \Gamma(a)\Gamma(b)/\Gamma(a+b)\)로 계산한다.

3.3.4연습문제

기본

  1. \(\Gamma(6)\)과 \(\Gamma(7/2)\)를 구하여라.
    답

    \(\Gamma(6) = 5! = 120\), \(\Gamma(7/2) = \frac52\cdot\frac32\cdot\frac12\sqrt\pi = \frac{15}{8}\sqrt\pi \approx 3.323\)이다.

응용

  1. 감마 밀도 \(\frac{1}{\Gamma(\alpha)\beta^\alpha}x^{\alpha-1}e^{-x/\beta}\) (\(x > 0\))의 평균을 감마 함수로 구하여라.
    답

    \(E(X) = \frac{1}{\Gamma(\alpha)\beta^\alpha}\int_0^\infty x^{\alpha}e^{-x/\beta}dx = \frac{\Gamma(\alpha+1)\beta^{\alpha+1}}{\Gamma(\alpha)\beta^\alpha} = \alpha\beta\)이다.
