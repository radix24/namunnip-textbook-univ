이상적분과 밀도함수의 규격화

본문
이 절에서 배울 것
  • 적분 구간이 무한하거나 함수가 한없이 커지는 적분(이상적분)을 정적분의 극한으로 계산한다.
  • 비교 판정으로 이상적분의 수렴을 판정한다.
  • 밀도함수의 상수를 넓이 1로 정하고, 평균이 존재하는지 판정한다.
먼저 알아야 할 것
  • 치환·부분적분 (3.1절), 극한 (1.1절), 고등학교 미적분의 삼각함수 미분(\((\tan x)' = \sec^2x\)).

넓이가 1이어야 밀도다

확률밀도함수는 음수가 아니고 그래프 아래 전체 넓이가 1이어야 합니다. 고등학교에서는 주로 유한한 구간 위의 밀도를 다루었지만, 대기 시간처럼 얼마든지 커질 수 있는 양이나 정규분포처럼 양쪽으로 끝없이 뻗은 분포는 넓이를 무한 구간에서 계산해야 합니다. 정적분은 유한 구간에서 정의되므로, 무한 구간의 넓이는 "구간을 점점 늘린 정적분의 극한"으로 정의합니다.

3.2.1이상적분의 정의

정의 3.2.1

무한 구간: \(\displaystyle\int_a^\infty f(x)\,dx = \lim_{b\to\infty}\int_a^b f(x)\,dx\). 이 극한이 유한하면 이상적분이 수렴한다고 하고, 그렇지 않으면 발산한다고 합니다. \(\int_{-\infty}^b\)도 같고, \(\int_{-\infty}^\infty\)는 중간의 한 점에서 둘로 나누어 각각 수렴해야 합니다.

함수가 한없이 커지는 경우: \(f\)가 \(x = a\) 근처에서 한없이 커지면 \(\displaystyle\int_a^b f(x)\,dx = \lim_{t\to a^+}\int_t^b f(x)\,dx\).

예제 3.2.2

\(f(x) = ce^{-2x}\) (\(x \ge 0\))이 밀도가 되도록 \(c\)를 정하세요.

풀이. \(\int_0^b e^{-2x}dx = \frac{1 - e^{-2b}}{2}\)이고 \(b\to\infty\)이면 \(e^{-2b}\to0\)이므로 \(\int_0^\infty e^{-2x}dx = \frac12\)입니다. 넓이가 1이 되려면 \(c = 2\)입니다.

결과 3.2.3

\(\displaystyle\int_1^\infty\frac{dx}{x^p}\)는 \(p > 1\)이면 수렴(값 \(\frac{1}{p-1}\))하고 \(p \le 1\)이면 발산합니다. \(\displaystyle\int_0^1\frac{dx}{x^p}\)는 \(p < 1\)이면 수렴하고 \(p \ge 1\)이면 발산합니다.

\(p \ne 1\)이면 \(\int_1^b x^{-p}dx = \frac{b^{1-p} - 1}{1 - p}\)입니다. \(p > 1\)이면 \(b^{1-p}\to0\)이라 \(\frac{1}{p-1}\)로 수렴하고, \(p < 1\)이면 \(b^{1-p}\to\infty\)라 발산합니다. \(p = 1\)이면 \(\int_1^b\frac1x dx = \ln b \to \infty\)라 발산합니다. 둘째 결과도 같은 계산입니다.

\(\frac1x\)과 \(\frac{1}{x^2}\)은 둘 다 0으로 가지만, \(\frac1x\)은 너무 천천히 줄어 넓이가 무한대이고 \(\frac{1}{x^2}\)은 넓이가 1입니다. "0으로 간다"와 "넓이가 유한하다"는 다른 이야기입니다.

정리 3.2.4 (비교 판정)

구간에서 \(0 \le f(x) \le g(x)\)일 때, \(\int g\)가 수렴하면 \(\int f\)도 수렴하고, \(\int f\)가 발산하면 \(\int g\)도 발산합니다.

넓이가 유한한 그래프 아래에 깔린 그래프의 넓이도 유한하다는 뜻입니다. 원시함수를 구하기 어려울 때 결과 3.2.3의 \(x^{-p}\)와 비교하면 수렴 여부를 알 수 있습니다. 예를 들어 \(x \ge 1\)에서 \(\frac{1}{x^2 + x} \le \frac{1}{x^2}\)이므로 \(\int_1^\infty\frac{dx}{x^2 + x}\)는 수렴합니다.

3.2.2규격화와 평균의 존재

예제 3.2.5

(가) \(f(x) = \dfrac{c}{1 + x^2}\) (모든 실수 \(x\))가 밀도가 되는 \(c\)를 구하세요. (나) 이 분포의 평균은 존재하나요?

풀이. (가) \(x = \tan\theta\)로 치환합니다(\(-\frac\pi2 < \theta < \frac\pi2\)). \(dx = \sec^2\theta\,d\theta\)이고 \(1 + \tan^2\theta = \sec^2\theta\)이므로 \(\frac{dx}{1 + x^2} = d\theta\)가 됩니다. \(x\)가 \(-\infty\)에서 \(\infty\)로 가면 \(\theta\)는 \(-\frac\pi2\)에서 \(\frac\pi2\)로 가므로 \(\int_{-\infty}^\infty\frac{dx}{1+x^2} = \int_{-\pi/2}^{\pi/2}d\theta = \pi\)입니다. 따라서 \(c = 1/\pi\)이고, 이 분포를 코시 분포라 합니다.

(나) 평균이 존재하려면 \(\int|x|f(x)\,dx\)가 수렴해야 합니다. \(\int_0^b\frac{x}{1+x^2}dx = \frac12\ln(1 + b^2) \to \infty\)이므로 발산합니다. \(x\)가 클 때 \(\frac{x}{1+x^2}\)은 \(\frac1x\)과 비슷하고(결과 3.2.3의 \(p = 1\)), 그래서 넓이가 무한대입니다. 코시 분포는 평균이 없는 분포이고, 이런 분포에서는 표본을 아무리 많이 모아도 표본평균이 한 값에 가까워지지 않습니다(응통6 07단원).

일반적으로 \(E(X^k)\)(이를 \(k\)차 적률이라 부릅니다)가 존재하려면 밀도의 꼬리가 \(x^{-(k+1)}\)보다 빨리 줄어야 합니다. 정규분포나 지수분포처럼 꼬리가 지수함수로 줄어드는 분포는 모든 적률이 존재합니다(1.1절에서 \(x^ke^{-x}\to0\)).

흔한 실수

\(\int_{-\infty}^\infty x\cdot\frac{1}{\pi(1+x^2)}dx\)를 "홀함수라 0"이라고 계산하면 틀립니다. 양쪽이 각각 무한대로 발산하므로 \(\infty - \infty\)는 정해지지 않습니다. 이상적분은 반드시 양쪽을 따로 계산해 각각 수렴하는지 확인해야 합니다.

요약
  1. 이상적분은 정적분의 극한으로 정의하고, 극한이 유한하면 수렴합니다.
  2. \(\int_1^\infty x^{-p}dx\)는 \(p > 1\)에서만 수렴하며, 비교 판정의 기준으로 씁니다.
  3. 밀도의 상수는 넓이 1로 정하고, 평균(적률)의 존재는 꼬리가 줄어드는 속도로 판정합니다.

3.2.3연습문제

기본

  1. \(f(x) = cx^{-3}\) (\(x \ge 1\))이 밀도가 되는 \(c\)와 평균을 구하세요. 분산은 존재하나요?
    답

    \(\int_1^\infty x^{-3}dx = \frac12\)이므로 \(c = 2\). 평균 \(\int_1^\infty x\cdot2x^{-3}dx = 2\int_1^\infty x^{-2}dx = 2\). \(E(X^2) = \int_1^\infty 2x^{-1}dx = \infty\)이므로 분산은 존재하지 않습니다.

  2. \(\int_0^1\frac{dx}{\sqrt x}\)를 구하세요.
    답

    \(\lim_{t\to0^+}[2\sqrt x]_t^1 = 2\). 함수는 0 근처에서 한없이 커지지만 넓이는 유한합니다(\(p = 1/2 < 1\)).
