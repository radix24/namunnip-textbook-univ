이계 편도함수로 극값 판정하기

본문
이 절에서 배울 것
  • 이계 편도함수 \(f_{xx}\), \(f_{yy}\), \(f_{xy}\)를 계산한다.
  • 판정식 \(D = f_{xx}f_{yy} - f_{xy}^2\)으로 임계점이 극대, 극소, 안장점 가운데 무엇인지 판정한다.
  • 판정식이 왜 성립하는지 이차식의 완전제곱으로 이해한다.
먼저 알아야 할 것
  • 편미분과 기울기 벡터 (5.1절), 이차함수의 완전제곱(고등학교 수학). 행렬은 몰라도 됩니다.

기울기가 0인 점은 꼭대기인가 골짜기인가

변수가 하나일 때는 \(f'(a) = 0\)인 점에서 \(f''(a) > 0\)이면 극소(아래로 볼록), \(f''(a) < 0\)이면 극대였습니다. 변수가 둘이면 사정이 조금 복잡합니다. 동서 방향으로는 오목한데 남북 방향으로는 볼록한, 말안장 같은 점이 있기 때문입니다. 이 점은 기울기 벡터가 \(\mathbf 0\)이지만 극대도 극소도 아니며 안장점이라고 부릅니다(예: \(f(x, y) = x^2 - y^2\)의 원점).

5.2.1이계 편도함수

정의 5.2.1

편도함수를 한 번 더 편미분한 것을 이계 편도함수라 합니다.

\(f_{xx}\): \(f_x\)를 다시 \(x\)로 미분. 동서 방향으로 휘는 정도.

\(f_{yy}\): \(f_y\)를 다시 \(y\)로 미분. 남북 방향으로 휘는 정도.

\(f_{xy}\): \(f_x\)를 \(y\)로 미분. 대각선 방향으로 비틀린 정도. 보통의 함수에서는 \(f_{xy} = f_{yx}\)이므로 순서를 신경 쓰지 않아도 됩니다.

이 네 값을 \(2\times2\)로 늘어놓은 표 \(\begin{pmatrix}f_{xx} & f_{xy}\\ f_{xy} & f_{yy}\end{pmatrix}\)를 헤세 행렬이라 부르기도 합니다. 여기서 "행렬"은 수를 가로세로로 늘어놓은 표라는 뜻일 뿐이며, 이 절에서는 표의 네 값만 쓰면 됩니다.

5.2.2판정식과 그 이유

정리 5.2.2

\(f_x = f_y = 0\)인 점에서 \(D = f_{xx}f_{yy} - f_{xy}^2\)이라 할 때

\(D > 0\)이고 \(f_{xx} > 0\)이면 극소, \(D > 0\)이고 \(f_{xx} < 0\)이면 극대, \(D < 0\)이면 안장점입니다. \(D = 0\)이면 이 방법으로는 판정할 수 없습니다.

왜 그런가. 임계점 근처를 아주 가까이서 보면 함수는 이차식처럼 생겼습니다. 일변수에서 \(f(a + h) \approx f(a) + \frac12 f''(a)h^2\)(\(f'(a) = 0\)일 때)였던 것처럼, 이변수에서는 \(x\)를 \(h\), \(y\)를 \(k\)만큼 옮길 때

\(f(a + h, b + k) - f(a, b) \approx \frac12\big(Ah^2 + 2Bhk + Ck^2\big)\), \(A = f_{xx}\), \(B = f_{xy}\), \(C = f_{yy}\)

입니다. 이제 괄호 안의 이차식이 모든 \((h, k)\)에서 양수인지(극소), 음수인지(극대), 둘 다 되는지(안장점)만 보면 됩니다. \(A \ne 0\)이면 완전제곱으로

\(Ah^2 + 2Bhk + Ck^2 = A\left(h + \dfrac{B}{A}k\right)^2 + \dfrac{AC - B^2}{A}k^2\)

로 바꿀 수 있습니다. \(AC - B^2 = D\)입니다.

  • \(D > 0\)이고 \(A > 0\)이면 두 항이 모두 0 이상이고 \((h, k) \ne (0, 0)\)이면 양수입니다. 어느 방향으로 움직여도 함수가 커지므로 극소입니다.
  • \(D > 0\)이고 \(A < 0\)이면 두 항이 모두 0 이하라 극대입니다.
  • \(D < 0\)이면 첫 항과 둘째 항의 부호가 반대라, \(k = 0\)인 방향에서는 \(A\)의 부호, \(h = -\frac BAk\)인 방향에서는 그 반대 부호가 됩니다. 방향에 따라 오르기도 내리기도 하므로 안장점입니다.

이 표의 \(D\)를 행렬식이라고도 부릅니다. 응통2(선형대수)에서 행렬식과 고유값을 배우면 같은 판정을 "헤세 행렬의 고유값이 모두 양수이면 극소"로 다시 쓸 수 있고, 변수가 셋 이상일 때도 쓸 수 있게 됩니다.

예제 5.2.3

\(f(x, y) = x^2 + xy + y^2 - 3x\)의 임계점과 그 종류를 구하세요.

풀이. 먼저 기울기 벡터가 0인 점을 찾습니다. \(f_x = 2x + y - 3 = 0\), \(f_y = x + 2y = 0\)을 연립하면 둘째 식에서 \(x = -2y\), 첫째 식에 넣어 \(-3y - 3 = 0\), 곧 \(y = -1\), \(x = 2\)입니다. 이계 편도함수는 \(f_{xx} = 2\), \(f_{yy} = 2\), \(f_{xy} = 1\)이므로 \(D = 2\times2 - 1^2 = 3 > 0\)이고 \(f_{xx} > 0\)입니다. 따라서 \((2, -1)\)은 극소점이고 극솟값은 \(f(2, -1) = 4 - 2 + 1 - 6 = -3\)입니다.

흔한 실수

\(f_{xx} > 0\)이고 \(f_{yy} > 0\)이면 극소라고 생각하기 쉽지만 틀릴 수 있습니다. \(f(x, y) = x^2 + 3xy + y^2\)은 \(f_{xx} = f_{yy} = 2 > 0\)인데 \(D = 4 - 9 = -5 < 0\)이라 원점이 안장점입니다(\(h = 1\), \(k = -1\) 방향으로 가면 \(1 - 3 + 1 = -1 < 0\)). 비틀림 \(f_{xy}\)가 크면 대각선 방향으로 내려갈 수 있습니다.

통계와의 연결

최대가능도 추정에서 로그가능도의 이계 도함수에 −를 붙인 값이 관측 정보량입니다. 이 값이 클수록 가능도 봉우리가 뾰족해 추정이 정밀합니다(응통7 3.2절).

요약
  1. 이계 편도함수 \(f_{xx}\), \(f_{yy}\), \(f_{xy}\)는 각 방향으로 휘는 정도와 비틀린 정도입니다.
  2. 임계점에서 \(D = f_{xx}f_{yy} - f_{xy}^2\): \(D > 0\)이면 \(f_{xx}\)의 부호로 극소·극대, \(D < 0\)이면 안장점, \(D = 0\)이면 판정 불가.
  3. 판정의 근거는 임계점 근처의 이차식을 완전제곱한 모양입니다.

5.2.3연습문제

기본

  1. \(f(x, y) = x^2 - y^2\)의 원점은 어떤 점인가요?
    답

    \(f_{xx} = 2\), \(f_{yy} = -2\), \(f_{xy} = 0\)이므로 \(D = -4 < 0\), 안장점입니다. \(x\) 방향으로는 오르고 \(y\) 방향으로는 내립니다.

  2. \(f(x, y) = -x^2 - 2y^2 + 4y\)의 임계점과 종류를 구하세요.
    답

    \(f_x = -2x = 0\), \(f_y = -4y + 4 = 0\)에서 \((0, 1)\). \(D = (-2)(-4) - 0 = 8 > 0\), \(f_{xx} < 0\)이므로 극대, 극댓값 2입니다.
