본문
이 절에서 배울 것
  • 선형 불편추정량의 뜻을 안다.
  • 최소제곱 추정량이 최량 선형 불편추정량(BLUE)임을 증명한다.
먼저 알아야 할 것
  • 행렬 표현 (2.1절), 양반정치 행렬 (응통2 05단원).

왜 최소제곱인가

잔차의 절댓값 합을 최소화할 수도 있고 다른 방법도 많습니다. 최소제곱을 쓰는 근거 하나는, 정규성 없이도 "선형이고 불편인 추정량 가운데 분산이 가장 작다"는 이 절의 정리입니다.

2.2.1정리

정리 2.2.1 (가우스-마르코프)

\(E(\boldsymbol\varepsilon) = \mathbf 0\), \(\mathrm{Var}(\boldsymbol\varepsilon) = \sigma^2I\)이면, 모든 상수 벡터 \(\mathbf c\)에 대해 \(\mathbf c^\top\hat{\boldsymbol\beta}\)는 \(\mathbf c^\top\boldsymbol\beta\)의 선형 불편추정량 가운데 분산이 가장 작다.

선형 불편추정량을 \(\mathbf a^\top\mathbf y\)라 합시다. 불편이려면 모든 \(\boldsymbol\beta\)에서 \(\mathbf a^\top X\boldsymbol\beta = \mathbf c^\top\boldsymbol\beta\), 곧 \(X^\top\mathbf a = \mathbf c\). 최소제곱 쪽은 \(\mathbf a_0 = X(X^\top X)^{-1}\mathbf c\)입니다. \(\mathbf d = \mathbf a - \mathbf a_0\)이라 하면 \(X^\top\mathbf d = \mathbf c - \mathbf c = \mathbf 0\)이고 \(\mathbf a_0^\top\mathbf d = \mathbf c^\top(X^\top X)^{-1}X^\top\mathbf d = 0\). 따라서 \(\mathrm{Var}(\mathbf a^\top\mathbf y) = \sigma^2\|\mathbf a_0 + \mathbf d\|^2 = \sigma^2(\|\mathbf a_0\|^2 + \|\mathbf d\|^2) \ge \sigma^2\|\mathbf a_0\|^2 = \mathrm{Var}(\mathbf c^\top\hat{\boldsymbol\beta})\). 등호는 \(\mathbf d = \mathbf 0\)일 때뿐. ∎

2.2.2가정이 하는 일

  • 등분산·무상관 (\(\sigma^2I\)): 증명의 \(\mathrm{Var}(\mathbf a^\top\mathbf y) = \sigma^2\|\mathbf a\|^2\)에 쓰입니다. 분산이 다르면 가중 최소제곱이 BLUE가 됩니다(05단원).
  • 정규성: 필요 없습니다. 정규성을 더하면 최소제곱은 비선형 추정량까지 포함한 모든 불편추정량 가운데 최선(UMVUE)이 됩니다.
  • 선형·불편이라는 제한: 치우친 추정량(능형 회귀, 06단원)은 MSE가 더 작을 수 있습니다.
예제 2.2.2

단순회귀에서 첫 점과 마지막 점을 잇는 기울기 \(\tilde\beta_1 = (Y_n - Y_1)/(x_n - x_1)\)는 선형 불편추정량임을 보이고, 최소제곱과 분산을 비교하세요.

풀이. \(E(\tilde\beta_1) = \beta_1(x_n - x_1)/(x_n - x_1) = \beta_1\). \(\mathrm{Var}(\tilde\beta_1) = 2\sigma^2/(x_n - x_1)^2\). \(x = 1, \ldots, 5\)이면 \(\sigma^2/8\), 최소제곱은 \(\sigma^2/S_{xx} = \sigma^2/10\)으로 더 작습니다.

요약
  1. 오차가 평균 0, 등분산, 무상관이면 최소제곱은 BLUE.
  2. 정규성은 필요 없지만, 등분산이 깨지면 BLUE가 아닙니다.
