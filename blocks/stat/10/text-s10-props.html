추정량의 평균과 분산, 오차분산의 추정

본문

같은 \(x\) 다섯 점에서 실험을 다시 하면 오차가 달라지므로 최소제곱 직선도 달라진다. 이렇게 다시 그은 직선들은 평균적으로 참 직선과 맞을까? 얼마나 흔들릴까? 그리고 흔들림을 줄이려면 \(x\)를 어디에 두어야 할까?

먼저 알아야 할 것최소제곱 추정량(1.1절)과 기댓값과 분산의 성질(응통6 3.1절, 5.3절)을 쓴다.

추정량의 평균은 평균적으로 참값을 맞히는지를, 분산은 얼마나 흔들리는지를 답한다. 처음 질문의 답부터 말하면, 다시 그은 직선은 평균적으로 참 직선과 맞고, 흔들림은 \(x\)가 넓게 퍼질수록 작다(그림 1). 이 두 가지가 1.3절의 t 검정과 1.5절의 예측구간을 만드는 재료이다.

1.2.1기울기와 절편의 평균과 분산

정리 1.2.1 (추정량의 평균과 분산)

\(E(\hat\beta_1) = \beta_1\), \(\mathrm{Var}(\hat\beta_1) = \dfrac{\sigma^2}{S_{xx}}\)이고, \(E(\hat\beta_0) = \beta_0\), \(\mathrm{Var}(\hat\beta_0) = \sigma^2\left(\dfrac1n + \dfrac{\bar x^2}{S_{xx}}\right)\), \(\mathrm{Cov}(\hat\beta_0, \hat\beta_1) = -\dfrac{\bar x\sigma^2}{S_{xx}}\)이다.

증명. \(\sum(x_i - \bar x) = 0\)이므로 \(S_{xy} = \sum(x_i - \bar x)Y_i\)이다. 그러므로 \(\hat\beta_1 = \sum c_iY_i\), \(c_i = (x_i - \bar x)/S_{xx}\)로 쓸 수 있다. 여기서 \(\sum c_i = 0\), \(\sum c_ix_i = 1\)이므로 \(E(\hat\beta_1) = \sum c_i(\beta_0 + \beta_1x_i) = \beta_1\)이다. 또 \(Y_i\)가 독립이므로 \(\mathrm{Var}(\hat\beta_1) = \sigma^2\sum c_i^2 = \sigma^2/S_{xx}\)이다. 한편 \(\mathrm{Cov}(\bar Y, \hat\beta_1) = \frac{\sigma^2}{n}\sum c_i = 0\)이므로, \(\hat\beta_0 = \bar Y - \hat\beta_1\bar x\)에서 \(\mathrm{Var}(\hat\beta_0) = \frac{\sigma^2}{n} + \bar x^2\frac{\sigma^2}{S_{xx}}\), \(\mathrm{Cov}(\hat\beta_0, \hat\beta_1) = -\bar x\,\mathrm{Var}(\hat\beta_1)\)이다. ∎

증명에서 정규성은 쓰지 않았다. 오차의 평균이 0이고, 분산이 같고, 서로 상관이 없다는 것만으로 충분하다. 여기에 정규성을 더하면 \(\hat\beta_1\)은 \(Y_i\)의 일차결합이므로 정확히 정규분포를 따른다.

1.2.2공식이 주는 교훈

\(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\)에서 보듯 \(S_{xx}\)가 클수록 기울기가 정확하다. 그래서 같은 비용이면 \(x\)를 넓은 범위에 퍼뜨려 실험한다. 또 \(x\)를 같은 방식으로 늘리면 \(S_{xx}\)가 \(n\)에 비례해 커지므로 표준오차는 \(1/\sqrt n\)로 줄어든다.

절편은 \(x = 0\)에서의 예측이므로, 0이 자료에서 멀면 분산이 커진다(그림 1). 그리고 \(\bar x > 0\)이면 기울기와 절편은 음의 상관을 갖는다. 직선이 \((\bar x, \bar y)\) 근처를 지나야 하므로 기울기가 올라가면 절편이 내려가기 때문이다. 그런데 \(x\) 대신 중심화한 \(x - \bar x\)를 쓰면 절편이 \(\bar y\)가 되고 공분산이 0이 되어, 계수 해석과 수치 계산이 모두 편해진다.

1.2.3오차분산의 추정

정리 1.2.2 (오차분산의 불편추정량)

\(\mathrm{SSE} = \sum e_i^2\)에 대해 \(E(\mathrm{SSE}) = (n-2)\sigma^2\)이다. 따라서 \(s^2 = \mathrm{MSE} = \mathrm{SSE}/(n-2)\)는 \(\sigma^2\)의 불편추정량이다.

왜 \(n - 2\)로 나눌까? 잔차는 오차와 달리 1.1절의 두 제약 \(\sum e_i = 0\), \(\sum x_ie_i = 0\)을 만족하므로 자유롭게 움직이는 방향이 \(n - 2\)개뿐이다. 따라서 \(n\)으로 나누면 \(\sigma^2\)을 체계적으로 작게 추정한다. 일반적인 증명은 2단원에서 모자 행렬의 대각합으로 한다(\(E(\mathrm{SSE}) = \sigma^2\,\mathrm{tr}(I - H) = (n-p)\sigma^2\)). 표준오차는 \(\sigma\)를 \(s\)로 바꾸어 \(\mathrm{se}(\hat\beta_1) = s/\sqrt{S_{xx}}\)로 쓴다.

예제 1.2.3

1.1절 연습문제의 자료(\(x\) = 1~5, \(S_{xx} = 10\), SSE = 3.6)에서 \(s^2\)과 두 계수의 표준오차, 두 추정량의 상관계수를 구하라.

풀이. \(s^2 = 3.6/3 = 1.2\)이다. 그러면 \(\mathrm{se}(\hat\beta_1) = \sqrt{1.2/10} = 0.346\), \(\mathrm{se}(\hat\beta_0) = \sqrt{1.2(0.2 + 9/10)} = \sqrt{1.32} = 1.149\)이다. 공분산은 \(-3 \times 1.2/10 = -0.36\)이므로 상관은 \(-0.36/(0.346 \times 1.149) = -0.905\)이다. 이 강한 음의 상관은 \(x\)를 중심화하면 사라진다. 그림 1의 모의실험에서도 기울기 40개의 표준편차는 0.27로, 직선이 40개뿐이라 흔들림이 있지만 이론값 0.346과 비슷하다.

마무리

\(\hat\beta_0, \hat\beta_1\)은 불편추정량이고 \(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\)이므로, \(x\)를 넓게 퍼뜨릴수록 기울기가 정확하다. 두 추정량의 공분산은 \(-\bar x\sigma^2/S_{xx}\)이며 \(x\)를 중심화하면 0이 된다. 오차분산은 \(s^2 = \mathrm{SSE}/(n-2)\)로 불편 추정하며, 자유도 2를 잃는 까닭은 잔차에 걸린 두 제약이다.

1.2.4연습문제

기본

  1. \(x\)를 [0, 10]에서 10개 고를 수 있다면 기울기를 가장 정확히 추정하는 배치는 무엇인가? 1, 2, …, 10에 하나씩 둘 때와 표준오차를 비교하라.
    답

    \(S_{xx}\)를 최대로 하는 배치, 곧 0에 5개, 10에 5개이며 \(S_{xx} = 250\)이다. 1~10 균등 배치는 \(S_{xx} = 82.5\)이므로 표준오차가 \(\sqrt{250/82.5} = 1.74\)배 차이 난다. 다만 양 끝에만 두면 직선성을 점검할 수 없으므로 실제로는 가운데에도 몇 개 둔다.

응용

  1. \(\hat\beta_1\)이 \(\beta_1\)의 선형 불편추정량 가운데 분산이 가장 작음을 보여라. \(\sum a_iY_i\)가 불편이려면 \(\sum a_i = 0\), \(\sum a_ix_i = 1\)이어야 한다.
    답

    \(a_i = c_i + d_i\)로 쓰면 조건에서 \(\sum d_i = 0\), \(\sum d_ix_i = 0\)이고, 따라서 \(\sum c_id_i = 0\)이다. 그러므로 \(\mathrm{Var} = \sigma^2(\sum c_i^2 + \sum d_i^2) \ge \sigma^2\sum c_i^2\)이다. 이것이 단순회귀의 가우스-마르코프 정리(2.3절)이다.
