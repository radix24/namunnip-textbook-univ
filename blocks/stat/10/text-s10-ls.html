자료를 만든 규칙을 모형으로

응통5에서는 자료에 직선을 맞추는 계산을 했습니다. 이제 그 직선이 무엇을 추정하는지 묻습니다. 자료가 "참 직선 + 우연한 오차"로 만들어졌다고 가정하면, 최소제곱 직선의 기울기는 참 기울기의 추정량이 되고 그 정확도를 계산할 수 있습니다.

1.1.1모형

정의 1.1.1

단순 선형회귀 모형: \(Y_i = \beta_0 + \beta_1x_i + \varepsilon_i\), \(i = 1, \ldots, n\). \(x_i\)는 주어진 상수, 오차 \(\varepsilon_i\)는 서로 독립이고 \(E(\varepsilon_i) = 0\), \(\mathrm{Var}(\varepsilon_i) = \sigma^2\). 추론을 할 때는 \(\varepsilon_i \sim N(0, \sigma^2)\)도 가정합니다.

가정은 네 가지입니다. 평균이 \(x\)의 일차식(선형성), 오차의 독립성, 분산 일정(등분산성), 정규성. 04단원에서 이 가정을 자료로 점검합니다.

1.1.2최소제곱 추정

\(Q(b_0, b_1) = \sum(y_i - b_0 - b_1x_i)^2\)을 최소화합니다. \(b_0\)과 \(b_1\) 각각에 대해 나머지를 상수로 보고 미분한 편미분(응통1-05-01)을 0으로 두면 정규방정식

\[\sum(y_i - b_0 - b_1x_i) = 0, \qquad \sum x_i(y_i - b_0 - b_1x_i) = 0\]

을 얻고, 풀면 \(S_{xx} = \sum(x_i - \bar x)^2\), \(S_{xy} = \sum(x_i - \bar x)(y_i - \bar y)\)에 대해

결과 1.1.2 \[\hat\beta_1 = \frac{S_{xy}}{S_{xx}}, \qquad \hat\beta_0 = \bar y - \hat\beta_1\bar x.\]

정규방정식은 "잔차의 합 = 0", "잔차와 \(x\)의 곱의 합 = 0"을 뜻합니다. 잔차가 \(x\)와 아무 직선 관계도 남기지 않게 직선을 고른 것입니다.

두 번째 편미분이 양수인 이차식이므로(\(Q\)는 \(b_0, b_1\)의 볼록한 이차함수) 이 점이 최소입니다. \(S_{xx} > 0\), 곧 \(x\)가 모두 같지 않아야 해가 하나로 정해집니다. \(x\)가 한 값뿐이면 그 점을 지나는 직선은 기울기가 무엇이든 같은 적합을 주어 기울기를 정할 수 없습니다.

1.1.3최소제곱 직선의 성질

정규방정식에서 바로 다음이 나옵니다. 잔차 \(e_i = y_i - \hat y_i\)라 할 때

  1. \(\sum e_i = 0\) (절편이 있는 모형에서만).
  2. 직선은 \((\bar x, \bar y)\)를 지난다: \(\hat\beta_0 + \hat\beta_1\bar x = \bar y\).
  3. \(\sum x_ie_i = 0\)이고, 따라서 \(\sum\hat y_ie_i = \hat\beta_0\sum e_i + \hat\beta_1\sum x_ie_i = 0\). 잔차는 \(x\)와도, 적합값과도 표본 상관이 0입니다.
  4. \(\sum\hat y_i = \sum y_i\): 적합값의 평균이 관측값의 평균과 같습니다.

성질 3은 02단원에서 "잔차 벡터는 설명변수가 펼치는 공간에 수직"이라는 기하적 사실로 일반화됩니다. 잔차를 적합값에 대해 그린 그림(04단원)에서 직선 경향이 보이지 않는 것은 당연하고, 곡선이나 깔때기 같은 다른 모양만 의미가 있습니다.

예제 1.1.3

R의 cars 자료(속도 speed, 제동 거리 dist, \(n = 50\))에 직선을 적합하세요.

풀이. fit <- lm(dist ~ speed, data = cars); summary(fit). \(\hat\beta_1 = 3.932\), \(\hat\beta_0 = -17.58\), \(s = 15.38\). 속도가 1 mph 오를 때 제동 거리가 평균 약 3.9 ft 늘어납니다. 절편 −17.6은 속도 0에서의 거리라 물리적 의미가 없습니다. 자료 범위(4~25 mph) 밖으로 해석하지 않습니다.

요약
  1. \(\hat\beta_1 = S_{xy}/S_{xx}\), \(\hat\beta_0 = \bar y - \hat\beta_1\bar x\).
  2. 정규방정식 = 잔차의 합 0, 잔차와 \(x\)의 곱의 합 0.
  3. 직선은 \((\bar x, \bar y)\)를 지나고 잔차는 \(x\), \(\hat y\)와 무상관입니다.

1.1.4연습문제

기본

  1. \(x\) = 1, 2, 3, 4, 5, \(y\) = 3, 5, 4, 7, 6일 때 \(\hat\beta_0, \hat\beta_1, s^2\)을 구하세요.
    답

    \(\bar x = 3\), \(\bar y = 5\), \(S_{xx} = 10\), \(S_{xy} = (-2)(-2) + (-1)(0) + 0 + (1)(2) + (2)(1) = 8\). \(\hat\beta_1 = 0.8\), \(\hat\beta_0 = 2.6\). 적합값 3.4, 4.2, 5.0, 5.8, 6.6, 잔차 −0.4, 0.8, −1.0, 1.2, −0.6, SSE = 3.6, \(s^2 = 1.2\)(1.2절).

응용

  1. 절편 없이 원점을 지나는 직선 \(y = bx\)를 최소제곱으로 맞추면 \(\hat b\)는? 이때 \(\sum e_i = 0\)이 성립하나요?
    답

    \(\frac{d}{db}\sum(y_i - bx_i)^2 = 0\)에서 \(\hat b = \sum x_iy_i/\sum x_i^2\). 정규방정식은 \(\sum x_ie_i = 0\) 하나뿐이라 \(\sum e_i\)는 일반적으로 0이 아닙니다. 그래서 원점 회귀에서는 \(R^2\)의 정의도 달라집니다.
