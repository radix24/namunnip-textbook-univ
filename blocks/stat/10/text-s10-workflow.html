회귀분석 전 과정 수행하기

본문

지금까지 최소제곱, 검정, 진단, 변환, 모형 선택을 단원마다 따로 배웠다. 그런데 실제 자료를 받아 들면 어디서부터 시작해야 할까? 도구들을 어떤 순서로 쓰고, 언제 앞 단계로 되돌아가야 할까?

먼저 알아야 할 것이 과목의 1~6단원을 쓴다.

실제 분석은 각 단원의 도구를 순서대로, 때로는 되돌아가며 쓴다(그림 1). 처음 질문에 답하려고, R에 들어 있는 mtcars로 무게가 연비에 주는 효과를 끝까지 분석해 본다.

7.1.1단계

먼저 질문을 정한다. 예측이 목적이면 변수 선택과 교차검증이 중심이 되고, 특정 변수의 효과를 아는 것이 목적이면 교란 변수 보정과 계수 해석이 중심이 된다. 여기서는 다른 특성을 보정한 무게의 효과를 추정한다.

다음은 탐색이다. pairs(mtcars[, c("mpg","wt","hp","disp","am")])로 산점도 행렬을 보며 곡선 관계, 이상값, 설명변수끼리의 상관을 확인한다. 그러면 mpg와 wt, hp 사이에 약한 곡선 관계가 보인다. 그다음 첫 모형 m <- lm(mpg ~ wt + hp + am, data = mtcars)을 적합하고 plot(m)으로 진단한다. 잔차 대 적합값 그림에 U자 무늬가 약하게 있고, 오른쪽 끝 몇 대(Toyota Corolla, Fiat 128)의 잔차가 크다. VIF는 5 미만이다.

진단에서 문제가 보였으므로 수정한다. 반응을 log(mpg)로 바꾸거나, 연비 대신 연료 소비율 \(1/\text{mpg}\)를 쓰면 무게와의 관계가 직선에 가까워진다. 물리적으로도 연료 소비는 무게에 비례하는 편이 자연스럽다. 이렇게 고친 모형으로 추론한다. 최종 모형의 무게 계수와 95% 신뢰구간을 confint(m2)로 구한다. 끝으로 민감도를 확인한다. 영향점을 뺀 결과나 다른 변수 조합의 결과가 결론을 바꾸는지 본다.

예제 7.1.1

위 흐름에서 쓰는 R 코드를 한곳에 모아라.

풀이. 100마일당 갤런(gpm)을 만들어 두 모형을 비교하고, 진단과 민감도 확인까지 한다.

d <- transform(mtcars, gpm = 100 / mpg)        # 100마일당 갤런
m1 <- lm(mpg ~ wt + hp + am, data = d)
m2 <- lm(gpm ~ wt + hp + am, data = d)
par(mfrow = c(2, 2)); plot(m1); plot(m2)
summary(m2); confint(m2)
car::vif(m2); which(cooks.distance(m2) > 4 / nrow(d))
summary(update(m2, subset = cooks.distance(m2) <= 4 / nrow(d)))

연료 소비 모형 m2에서 무게 계수는 1.18이고 95% 구간은 [0.69, 1.68]이다. 즉 마력과 변속기가 같을 때 무게가 1,000 lb 늘면 100마일당 약 1.2갤런을 더 쓴다.

주의1974년 자동차 32대의 자료는 관측 자료이고 표본도 작다. 그러므로 무게를 줄이면 연비가 이만큼 오른다는 인과 해석에는 조심해야 한다(응통5 1.1절).
마무리

회귀분석은 질문, 탐색, 적합, 진단, 수정, 추론, 민감도의 순서로 진행한다. 진단 결과에 따라 앞 단계로 되돌아가며, 문제가 정리된 뒤에야 추론한다. 변환은 잔차 그림 같은 통계적 근거와 해석 가능성을 함께 보고 고른다.

7.1.2연습문제

기본

  1. 예측이 목적인 분석과 한 변수의 효과를 아는 것이 목적인 분석에서 모형을 고르는 기준은 어떻게 다른가?
    답

    예측이 목적이면 교차검증 오차처럼 새 자료에서의 성능으로 고른다. 효과가 목적이면 교란 변수를 미리 정해 넣고, 계수의 해석과 진단을 중시하며 단계적 선택은 피한다.

응용

  1. R의 airquality 자료로 오존 Ozone을 태양 복사, 풍속, 기온으로 설명하는 분석을 위 단계대로 수행하라.
    답

    결측값을 먼저 처리하고(na.omit), 진단에서 나팔 모양과 오른쪽 꼬리가 보이면 log(Ozone)을 반응으로 쓴다. 그러면 가정이 크게 개선되고, 풍속과 기온의 계수가 뚜렷하게 유의하다.
