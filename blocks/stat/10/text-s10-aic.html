AIC, BIC, 수정 결정계수로 모형 비교

본문
이 절에서 배울 것
  • 변수를 늘리면 \(R^2\)가 반드시 커지는 문제를 안다.
  • 수정 결정계수, AIC, BIC를 계산하고 비교한다.
먼저 알아야 할 것
  • 결정계수 (1.4절), 최대가능도 (응통7 1.1절).

변수를 넣을수록 좋아 보이는 함정

아무 의미 없는 난수 변수를 넣어도 SSE는 줄어들고 \(R^2\)는 올라갑니다. 자료에 맞추는 정도만 보면 변수가 많은 모형이 늘 이깁니다. 하지만 새 자료에 대한 예측은 오히려 나빠질 수 있습니다(과적합). 그래서 적합도와 복잡도를 함께 보는 기준이 필요합니다.

6.1.1수정 결정계수

정의 6.1.1

\(R^2_{adj} = 1 - \dfrac{\mathrm{SSE}/(n-p)}{\mathrm{SST}/(n-1)}\).

제곱합 대신 자유도로 나눈 평균제곱을 씁니다. 변수를 하나 넣으면 SSE는 줄지만 \(n - p\)도 줄어, 기여가 작은 변수를 넣으면 \(R^2_{adj}\)가 내려갑니다.

6.1.2정보 기준

정의 6.1.2

\(\mathrm{AIC} = -2\ell(\hat\theta) + 2k\), \(\mathrm{BIC} = -2\ell(\hat\theta) + k\log n\). \(k\)는 추정한 모수의 수. 작을수록 좋다.

정규 회귀에서는 상수를 빼면 \(-2\ell = n\log(\mathrm{SSE}/n)\)입니다. AIC는 새 자료에 대한 예측 성능(쿨백-라이블러 거리)의 추정에서 나왔고, BIC는 베이즈 사후 확률의 근사에서 나왔습니다. \(n \ge 8\)이면 \(\log n > 2\)라 BIC가 복잡도를 더 무겁게 벌해 작은 모형을 고릅니다.

목표성질
AIC예측큰 모형 쪽으로 기울 수 있음
BIC참 모형 찾기\(n\)이 크면 참 모형을 고를 확률 → 1 (참 모형이 후보에 있을 때)
예제 6.1.3

mtcars에서 mpg ~ wt, mpg ~ wt + hp, mpg ~ wt + hp + qsec + drat의 AIC를 비교하세요.

풀이. AIC(m1, m2, m3)를 실행하면 AIC는 166.0, 156.7, 157.0입니다. 마력을 넣으면 약 9.4 작아지지만, qsec과 drat을 더 넣으면 오히려 0.4 커집니다. AIC 차이가 2 이내면 거의 비슷하다고 보고 간단한 모형을 고르는 것이 관례입니다.

요약
  1. \(R^2\)는 변수를 넣을수록 커지므로 모형 비교에 쓰지 않습니다.
  2. \(R^2_{adj}\), AIC(\(+2k\)), BIC(\(+k\log n\))는 복잡도를 벌합니다.
  3. 같은 자료, 같은 반응(변환 포함)으로 적합한 모형끼리만 비교합니다.

6.1.3연습문제

기본

  1. \(n = 100\)에서 변수 하나를 넣었더니 \(-2\ell\)이 3 줄었습니다. AIC와 BIC는 그 변수를 넣으라고 하나요?
    답

    AIC: \(-3 + 2 = -1\), 감소하므로 넣음. BIC: \(-3 + \log100 = -3 + 4.6 = 1.6\), 증가하므로 넣지 않음.
