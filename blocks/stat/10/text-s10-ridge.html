능형 회귀와 축소

본문
이 절에서 배울 것
  • 제곱 벌점을 더한 최소제곱으로 능형 회귀를 정의하고 닫힌 꼴 해를 구한다.
  • 능형 회귀가 어떤 방향을 얼마나 줄이는지 이해한다.
  • 치우침과 분산의 맞교환으로 능형 회귀가 최소제곱보다 나을 수 있는 이유를 안다.
먼저 알아야 할 것
  • MSE 분해 (응통7 1.3절), 다중공선성 (4.4절), 교차검증 (6.3절).

조금 치우치더라도 덜 흔들리게

다중공선성이 있거나 변수가 많으면 최소제곱 계수는 불편이지만 분산이 큽니다. MSE = 분산 + 치우침²이므로, 계수를 0 쪽으로 조금 당겨 치우침을 감수하고 분산을 크게 줄이면 전체 오차가 줄어들 수 있습니다. 가우스-마르코프 정리(2.3절)는 불편추정량 안에서만 최소제곱이 최선이라고 말할 뿐입니다.

6.4.1정의

정의 6.4.1

\(\hat{\boldsymbol\beta}_{\text{ridge}} = \arg\min_{\mathbf b}\left\{\|\mathbf y - X\mathbf b\|^2 + \lambda\sum_{j \ge 1}b_j^2\right\} = (X^\top X + \lambda I)^{-1}X^\top\mathbf y\) (설명변수는 표준화, 절편은 벌점에서 제외).

목적함수를 \(\mathbf b\)로 미분하면 \(-2X^\top\mathbf y + 2X^\top X\mathbf b + 2\lambda\mathbf b = \mathbf 0\)이라 닫힌 꼴 해가 나옵니다. \(\lambda I\)를 더하면 \(X^\top X\)가 거의 특이할 때도 역행렬이 안정됩니다. \(\lambda = 0\)이면 최소제곱, \(\lambda \to \infty\)이면 계수가 모두 0으로 갑니다. 계수는 작아지지만 정확히 0이 되지는 않습니다. 벌점이 계수의 크기에 걸리므로 단위가 다른 설명변수를 표준화하지 않으면 단위가 작은 변수만 부당하게 줄어듭니다.

6.4.2어느 방향을 줄이나

설명변수가 직교하고 표준화되어 \(X^\top X = I\)이면 \(\hat\beta_{j,\text{ridge}} = \hat\beta_{j,LS}/(1 + \lambda)\)로 모든 계수를 같은 비율로 줄입니다. 일반적으로 \(X\)의 특이값 분해 \(X = UDV^\top\)(응통2)를 쓰면 적합값은

\[X\hat{\boldsymbol\beta}_{\text{ridge}} = \sum_j \mathbf u_j\frac{d_j^2}{d_j^2 + \lambda}\mathbf u_j^\top\mathbf y\]

입니다. 특이값 \(d_j\)가 작은 방향, 곧 자료가 거의 퍼져 있지 않은 방향(다중공선성의 방향)을 크게 줄이고, 자료가 잘 퍼진 방향은 거의 그대로 둡니다. 정보가 적어 불안정한 방향만 골라 누르는 셈입니다. \(\sum d_j^2/(d_j^2 + \lambda)\)를 유효 자유도라 하며, \(\lambda\)가 커질수록 \(p\)에서 0으로 줄어듭니다.

6.4.3치우침과 분산

능형 추정량의 분산은 최소제곱보다 작고 치우침은 \(\lambda\)와 함께 커집니다. \(\lambda\)가 작을 때 MSE의 도함수를 보면, 분산이 줄어드는 속도(1차)가 치우침²이 커지는 속도(2차)보다 빠르므로, 항상 어떤 \(\lambda > 0\)에서 능형 회귀의 MSE가 최소제곱보다 작습니다(호얼-케너드, 1970). 다만 그 \(\lambda\)는 모르는 \(\boldsymbol\beta\)와 \(\sigma^2\)에 달려 있어 자료로 골라야 합니다.

예제 6.4.2

\(X^\top X = I\)이고 최소제곱 계수가 \((3, -1.2, 0.4)\)입니다. \(\lambda = 2\)인 능형 계수는? 각 계수의 MSE가 최소제곱보다 작아지려면 어떤 조건이 필요한가요(\(\sigma^2 = 1\))?

풀이. \(1/(1 + 2) = 1/3\)을 곱해 \((1, -0.4, 0.133)\). 한 계수에서 최소제곱의 MSE는 \(\sigma^2 = 1\), 능형은 분산 \(1/9\) + 치우침² \((\beta_j - \beta_j/3)^2 = \frac49\beta_j^2\)입니다. \(\frac19 + \frac49\beta_j^2 < 1\), 곧 \(|\beta_j| < \sqrt2\)이면 능형이 낫습니다. 참 계수가 작은 방향에서 이득이 큽니다.

6.4.4\(\lambda\) 고르기

\(\lambda\)를 여러 값으로 바꿔 교차검증 오차가 가장 작은 값을 고르거나, 1-SE 규칙(6.3절)으로 더 큰 \(\lambda\)(더 많이 줄인 모형)를 고릅니다. \(\lambda\)에 따라 계수가 줄어드는 모습을 그린 능형 자취로 어떤 계수가 불안정한지 봅니다.

library(glmnet)
X <- scale(as.matrix(mtcars[, -1])); y <- mtcars$mpg
cvfit <- cv.glmnet(X, y, alpha = 0)     # alpha = 0: 능형
plot(cvfit$glmnet.fit, xvar = "lambda") # 능형 자취
coef(cvfit, s = "lambda.1se")
요약
  1. 능형: \((X^\top X + \lambda I)^{-1}X^\top\mathbf y\), 설명변수는 표준화.
  2. 자료가 덜 퍼진(공선성) 방향을 더 많이 줄입니다: 비율 \(d_j^2/(d_j^2 + \lambda)\).
  3. 어떤 \(\lambda > 0\)은 항상 최소제곱보다 MSE가 작고, 그 값은 교차검증으로 고릅니다.

6.4.5연습문제

기본

  1. 설명변수가 하나이고 표준화되어 \(\sum x_i^2 = n\)일 때 능형 추정량을 최소제곱 추정량으로 나타내세요.
    답

    \(\hat\beta_{\text{ridge}} = \frac{\sum x_iy_i}{n + \lambda} = \frac{n}{n + \lambda}\hat\beta_{LS}\). 최소제곱을 일정 비율로 줄입니다.

응용

  1. 특이값이 \(d = (10, 1, 0.1)\)일 때 \(\lambda = 1\)이면 각 방향의 축소 비율과 유효 자유도는?
    답

    \(100/101 = 0.990\), \(1/2 = 0.5\), \(0.01/1.01 = 0.0099\). 유효 자유도 \(\approx 1.50\). 공선성 방향(0.1)은 거의 완전히 눌립니다.
