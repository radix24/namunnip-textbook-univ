능형 회귀와 축소

본문

mtcars의 변수 열 개를 모두 넣으면 배기량의 계수가 양수로 나온다. 배기량이 큰 차일수록 연비가 좋다는, 상식과 반대인 결과이다. 변수끼리 상관이 커서 계수가 크게 흔들리기 때문이다. 불편성을 조금 포기하고 계수를 0 쪽으로 당기면 오히려 더 나은 추정이 될 수 있을까?

먼저 알아야 할 것평균제곱오차의 분해(응통7 1.3절), 다중공선성(4.4절), 교차검증(6.3절)을 쓴다.

다중공선성이 있거나 변수가 많으면 최소제곱 계수는 불편이지만 분산이 크다. 평균제곱오차는 분산에 치우침의 제곱을 더한 것이므로, 계수를 0 쪽으로 조금 당겨 치우침을 감수하고 분산을 크게 줄이면 전체 오차가 줄어들 수 있다. 가우스-마르코프 정리(2.3절)는 불편추정량 안에서만 최소제곱이 최선이라고 말할 뿐이다. 그래서 처음 질문의 답은 그렇다는 것이다(그림 1).

6.4.1정의

정의 6.4.1 (능형 회귀)

설명변수를 표준화하고 절편은 벌점에서 뺀 채 \(\hat{\boldsymbol\beta}_{\text{ridge}} = \arg\min_{\mathbf b}\left\{\|\mathbf y - X\mathbf b\|^2 + \lambda\sum_{j \ge 1}b_j^2\right\} = (X^\top X + \lambda I)^{-1}X^\top\mathbf y\)를 능형 추정량이라 한다.

목적함수를 \(\mathbf b\)로 미분하면 \(-2X^\top\mathbf y + 2X^\top X\mathbf b + 2\lambda\mathbf b = \mathbf 0\)이라 닫힌 꼴 해가 나온다. \(\lambda I\)를 더하면 \(X^\top X\)가 거의 특이할 때도 역행렬이 안정된다. 또 \(\lambda = 0\)이면 최소제곱이고, \(\lambda \to \infty\)이면 계수가 모두 0으로 간다. 계수는 작아지지만 정확히 0이 되지는 않는다. 한편 벌점이 계수의 크기에 걸리므로, 단위가 다른 설명변수를 표준화하지 않으면 단위가 작은 변수만 부당하게 줄어든다.

6.4.2어느 방향을 줄이나

설명변수가 직교하고 표준화되어 \(X^\top X = I\)이면 \(\hat\beta_{j,\text{ridge}} = \hat\beta_{j,LS}/(1 + \lambda)\)로, 모든 계수를 같은 비율로 줄인다. 일반적으로는 \(X\)의 특이값 분해 \(X = UDV^\top\)(응통2)를 쓰면 적합값이 다음과 같다.

\[ X\hat{\boldsymbol\beta}_{\text{ridge}} = \sum_j \mathbf u_j\frac{d_j^2}{d_j^2 + \lambda}\mathbf u_j^\top\mathbf y \]

그러므로 특이값 \(d_j\)가 작은 방향, 곧 자료가 거의 퍼져 있지 않은 다중공선성의 방향을 크게 줄이고, 자료가 잘 퍼진 방향은 거의 그대로 둔다. 다시 말해 정보가 적어 불안정한 방향만 골라 누르는 셈이다. \(\sum d_j^2/(d_j^2 + \lambda)\)를 유효 자유도라 하며, \(\lambda\)가 커질수록 \(p\)에서 0으로 줄어든다.

6.4.3치우침과 분산

능형 추정량의 분산은 최소제곱보다 작고, 치우침은 \(\lambda\)와 함께 커진다. \(\lambda\)가 작을 때 평균제곱오차의 도함수를 보면, 분산이 줄어드는 속도는 1차이고 치우침의 제곱이 커지는 속도는 2차이다. 따라서 어떤 \(\lambda > 0\)에서는 늘 능형 회귀의 평균제곱오차가 최소제곱보다 작다(호얼과 케너드, 1970). 다만 그 \(\lambda\)는 모르는 \(\boldsymbol\beta\)와 \(\sigma^2\)에 달려 있어 자료로 골라야 한다.

예제 6.4.2

\(X^\top X = I\)이고 최소제곱 계수가 \((3, -1.2, 0.4)\)이다. \(\lambda = 2\)인 능형 계수는 무엇인가? \(\sigma^2 = 1\)일 때 각 계수의 평균제곱오차가 최소제곱보다 작아지려면 어떤 조건이 필요한가?

풀이. \(1/(1 + 2) = 1/3\)을 곱해 \((1, -0.4, 0.133)\)이다. 한 계수에서 최소제곱의 평균제곱오차는 \(\sigma^2 = 1\)이다. 반면 능형은 분산 \(1/9\)에 치우침의 제곱 \((\beta_j - \beta_j/3)^2 = \frac49\beta_j^2\)을 더한 값이다. 그러므로 \(\frac19 + \frac49\beta_j^2 < 1\), 곧 \(|\beta_j| < \sqrt2\)이면 능형이 낫다. 즉 참 계수가 작은 방향에서 이득이 크다.

6.4.4\(\lambda\) 고르기

\(\lambda\)를 여러 값으로 바꿔 교차검증 오차가 가장 작은 값을 고르거나, 1-SE 규칙(6.3절)으로 더 많이 줄인 큰 \(\lambda\)를 고른다. 또 \(\lambda\)에 따라 계수가 줄어드는 모습을 그린 능형 자취(그림 1)로 어떤 계수가 불안정한지 본다. R에서는 다음과 같이 한다.

library(glmnet)
X <- scale(as.matrix(mtcars[, -1])); y <- mtcars$mpg
cvfit <- cv.glmnet(X, y, alpha = 0)     # alpha = 0: 능형
plot(cvfit$glmnet.fit, xvar = "lambda") # 능형 자취
coef(cvfit, s = "lambda.1se")
마무리

능형 추정량은 \((X^\top X + \lambda I)^{-1}X^\top\mathbf y\)이며, 설명변수는 표준화해서 쓴다. 각 방향을 \(d_j^2/(d_j^2 + \lambda)\)의 비율로 줄이므로, 자료가 덜 퍼진 공선성 방향을 더 많이 줄인다. 어떤 \(\lambda > 0\)은 늘 최소제곱보다 평균제곱오차가 작으며, 그 값은 교차검증으로 고른다.

6.4.5연습문제

기본

  1. 설명변수가 하나이고 표준화되어 \(\sum x_i^2 = n\)일 때, 능형 추정량을 최소제곱 추정량으로 나타내라.
    답

    \(\hat\beta_{\text{ridge}} = \frac{\sum x_iy_i}{n + \lambda} = \frac{n}{n + \lambda}\hat\beta_{LS}\)이다. 최소제곱을 일정 비율로 줄인다.

응용

  1. 특이값이 \(d = (10, 1, 0.1)\)일 때 \(\lambda = 1\)이면 각 방향의 축소 비율과 유효 자유도는 얼마인가?
    답

    \(100/101 = 0.990\), \(1/2 = 0.5\), \(0.01/1.01 = 0.0099\)이고 유효 자유도는 약 1.50이다. 공선성 방향(0.1)은 거의 완전히 눌린다.
