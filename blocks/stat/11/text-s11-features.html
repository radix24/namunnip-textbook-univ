분석용 자료 정제와 변수 만들기

본문
이 절에서 배울 것
  • 거래 자료를 분석 단위(고객, 기간)로 집계해 변수를 만든다.
  • 미래 정보가 섞이는 누수를 막는다.
먼저 알아야 할 것
  • 자료 품질 (2.1절), 그룹 요약 (응통3 2.3절).

원자료에서 분석표로

예측 모형은 "고객 한 명 = 한 행"처럼 분석 단위로 정리된 표가 필요합니다. 수백만 건의 거래 기록을 고객별 최근 구매일, 구매 횟수, 총액 같은 변수로 바꾸는 작업이 변수 만들기(특성 공학)입니다.

2.2.1흔한 변수

  • RFM: 최근성(마지막 구매 후 일수), 빈도(기간 내 구매 횟수), 금액(총액).
  • 추세: 최근 1개월 / 이전 3개월 평균 사용량 비율.
  • 비율·다양성: 할인 구매 비율, 구매 품목 종류 수.
  • 범주 처리: 드문 범주를 "기타"로 묶기, 가변수.

2.2.2누수 막기

정의 2.2.1

누수: 예측 시점에는 알 수 없는 정보가 변수에 섞여 들어가는 것.

예: 3월 1일에 "3월 해지"를 예측하는데 3월 중 고객센터 해지 문의 횟수를 변수로 쓰면 성능은 매우 좋아 보이지만 실제로는 쓸 수 없습니다. 기준 시점(관측 마감일)을 정하고, 모든 변수는 그 이전 자료로만, 결과는 그 이후 기간에서만 만듭니다.

# 기준일 cutoff 이전 거래로 고객별 변수 만들기 (dplyr)
feat <- tx |> filter(date < cutoff) |> group_by(customer) |>
  summarise(recency = as.numeric(cutoff - max(date)),
            freq = n(), monetary = sum(amount))
label <- tx |> filter(date >= cutoff, date < cutoff + 30) |>
  distinct(customer) |> mutate(bought_next30 = 1)
요약
  1. 거래 → 분석 단위로 집계(RFM, 추세, 비율).
  2. 기준 시점 이전 자료로만 변수를 만듦.
  3. 성능이 지나치게 좋으면 누수를 의심.

2.2.3연습문제

기본

  1. 대출 연체 예측 모형에 "연체 독촉 문자 발송 횟수"를 넣었더니 정확도가 99%가 되었습니다. 문제는?
    답

    독촉 문자는 연체 뒤에 보내므로 결과를 담은 누수 변수입니다. 예측 시점에 알 수 없으니 빼야 합니다.
