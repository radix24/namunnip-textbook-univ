분석 결과를 실행 가능한 제안으로

본문
이 절에서 배울 것
  • 분석 결과를 "무엇을, 누가, 언제, 얼마나"의 제안으로 바꾼다.
  • 기대 효과와 위험, 확인 방법을 함께 제시한다.
먼저 알아야 할 것
  • 불확실성 평가 (3.2절).

그래서 무엇을 하라는 것인가

분석 보고를 들은 경영진의 첫 질문은 대개 이것입니다. 분석 결과는 행동으로 이어질 때 가치가 생깁니다.

4.1.1제안의 구조

  1. 결론 한 문장: "이탈 위험 상위 1만 명에게 유지 쿠폰을 보내기를 제안합니다."
  2. 근거: 모형 향상도 5배, 과거 쿠폰 실험의 이탈 감소 효과 2%p(구간 1~3%p).
  3. 기대 효과와 비용: 이탈 방지 약 200명(100~300명) × 고객 생애 가치, 쿠폰 비용과 비교.
  4. 위험과 가정: 효과가 과거 실험과 같다는 가정, 쿠폰에 길들여질 위험.
  5. 확인 방법: 대상의 10%는 무작위로 쿠폰을 보내지 않고 남겨 실제 효과를 측정.
  6. 다음 단계: 일정, 담당.

결론을 맨 앞에 둡니다(피라미드 구조). 읽는 사람은 바쁘고, 세부는 뒤나 부록에서 찾을 수 있으면 됩니다.

예제 4.1.1

3.2절 A/B 시험 결과(구매율 0.3%p 증가, 구간 0.05~0.55%p)로 제안 문장을 쓰세요. 방문자는 월 100만 명, 구매당 이익 2만 원입니다.

풀이. "새 결제 화면을 전체 적용하기를 제안합니다. 시험에서 구매율이 0.3%p(구간 0.05~0.55%p) 올랐고, 월 방문 100만 명 기준 추가 구매 약 3000건(500~5500건), 추가 이익 월 약 6000만 원(1000만~1억 1000만 원)이 예상됩니다. 효과 크기의 불확실성이 커서, 전체 적용 뒤에도 5%를 기존 화면에 남겨 두 달간 효과를 다시 측정하겠습니다."

요약
  1. 결론 → 근거 → 효과·비용 → 위험 → 확인 방법 → 다음 단계.
  2. 효과는 구간과 사업 단위(돈, 고객 수)로.
  3. 실행 뒤 효과를 측정할 장치를 함께 제안.

4.1.2연습문제

기본

  1. "분석 결과 20대 고객의 만족도가 낮았습니다"를 실행 가능한 제안으로 바꾸려면 무엇이 더 필요한가요?
    답

    무엇이 원인인지(어떤 항목의 불만인지), 어떤 조치를 할지, 기대 효과와 비용, 효과를 확인할 방법.
