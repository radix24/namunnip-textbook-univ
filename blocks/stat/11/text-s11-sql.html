SQL로 자료 추출하고 집계하기

본문
이 절에서 배울 것
  • SELECT, WHERE, GROUP BY, ORDER BY로 자료를 뽑고 요약한다.
  • JOIN으로 표를 결합한다.
  • 큰 자료는 데이터베이스에서 집계한 뒤 가져오는 이유를 안다.
먼저 알아야 할 것
  • 자료 품질 (2.1절), 그룹 요약 (응통3 2.3절, 응통4 5.2절).

자료는 데이터베이스에 있다

기업 자료는 대개 CSV 파일이 아니라 데이터베이스의 여러 표에 나뉘어 있습니다. 수억 행을 R이나 파이썬으로 다 가져올 수는 없으므로, SQL로 필요한 행과 열만 뽑고 집계한 결과를 가져옵니다. SQL의 문법은 dplyr과 pandas의 동사(응통3 2.3절)와 거의 일대일로 대응합니다.

2.3.1기본 문장

SELECT customer_id, SUM(amount) AS total, COUNT(*) AS n_orders
FROM orders
WHERE order_date >= '2026-01-01'
GROUP BY customer_id
HAVING COUNT(*) >= 2
ORDER BY total DESC
LIMIT 10;

실행 순서는 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT입니다. WHERE는 묶기 전 행을, HAVING은 묶은 뒤 그룹을 거릅니다. 집계 함수 COUNT, SUM, AVG, MIN, MAX는 NULL을 빼고 계산합니다(COUNT(*)만 행 수 전체).

2.3.2결합

SELECT c.region, AVG(o.amount) AS avg_amount
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
GROUP BY c.region;

JOIN(내부 결합)은 양쪽에 모두 있는 키만 남기고, LEFT JOIN은 왼쪽 표의 모든 행을 남겨 짝이 없으면 NULL을 채웁니다. 결합 전후의 행 수를 꼭 확인합니다(2.5절의 중복 결합 문제).

예제 2.3.1

orders 표가 (고객 1, 30), (고객 1, 20), (고객 2, 50), (고객 3, 10), (고객 3, NULL)일 때 SELECT customer_id, COUNT(*), COUNT(amount), AVG(amount) FROM orders GROUP BY customer_id의 결과는?

풀이. 고객 1: 2, 2, 25. 고객 2: 1, 1, 50. 고객 3: 2, 1, 10. 고객 3의 AVG는 NULL을 빼고 10이라, 금액 누락을 0으로 보는 \((10 + 0)/2 = 5\)와 다릅니다. COUNT(*)와 COUNT(amount)의 차이로 누락을 찾을 수 있습니다.

요약
  1. SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY.
  2. 집계 함수는 NULL을 뺍니다. COUNT(*)는 행 수.
  3. JOIN/LEFT JOIN 뒤에는 행 수를 확인합니다.

2.3.3연습문제

기본

  1. 2026년 3월 주문의 상품별 매출 합계 상위 5개를 뽑는 SQL을 쓰세요(orders(product_id, amount, order_date)).
    답

    SELECT product_id, SUM(amount) AS sales FROM orders WHERE order_date >= '2026-03-01' AND order_date < '2026-04-01' GROUP BY product_id ORDER BY sales DESC LIMIT 5;

응용

  1. 주문이 한 번도 없는 고객까지 포함해 고객별 주문 수를 세려면 어떻게 하나요?
    답

    customers를 왼쪽에 두고 LEFT JOIN orders 후 COUNT(o.order_id)로 셉니다. COUNT(*)를 쓰면 주문 없는 고객도 1로 세어집니다(결합된 행이 하나 있으므로).
