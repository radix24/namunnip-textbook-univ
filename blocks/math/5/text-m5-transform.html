확률변수의 변환

본문

\(X\)가 0과 1 사이에서 고르게 퍼진 난수일 때 \(Y = X^2\)은 어떻게 분포할까? 여전히 고르게 퍼져 있을까? 그리고 컴퓨터는 균등 난수만 만들 수 있는데, 지수분포나 정규분포를 따르는 난수는 어떻게 만들까?

먼저 알아야 할 것분포함수(2.1절), 기본 분포(2.2절), 치환적분과 역함수의 미분을 쓴다.

2.3.1분포함수 방법

\(X\)의 분포를 알 때 \(Y = g(X)\)의 분포를 구하는 가장 확실한 방법은 사건을 바꿔 쓰는 것이다. \(\{Y \le y\} = \{g(X) \le y\}\)를 \(X\)에 대한 조건으로 풀어 \(F_X\)로 계산하고, 필요하면 미분해 밀도를 얻는다.

예제 2.3.1

\(X \sim U(0, 1)\)일 때 \(Y = X^2\)의 분포함수와 밀도를 구하여라.

풀이. \(0 < y < 1\)에서 \(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \sqrt y\)이다. 미분하면 \(f_Y(y) = \frac1{2\sqrt y}\)이며, 예를 들어 \(P(Y \le 0.25) = 0.5\)이다. 그림 1처럼 0 근처에서 밀도가 무한히 커지는 것은, 제곱하면 작은 수가 더 작아져 0 근처로 몰리기 때문이다.

2.3.2단조 변환의 밀도 공식

정리 2.3.2

\(X\)가 밀도 \(f_X\)를 갖고 \(g\)가 \(X\)의 값의 범위에서 순증가 또는 순감소하며 \(g^{-1}\)이 미분가능하면, \(Y = g(X)\)의 밀도는 \(f_Y(y) = f_X(g^{-1}(y))\left|\dfrac{d}{dy}g^{-1}(y)\right|\)이다.

증명.증가하는 경우 \(F_Y(y) = P(X \le g^{-1}(y)) = F_X(g^{-1}(y))\)이고, 연쇄법칙으로 미분하면 \(f_X(g^{-1}(y))\,(g^{-1})'(y)\)이다. 감소하는 경우 \(F_Y(y) = P(X \ge g^{-1}(y)) = 1 - F_X(g^{-1}(y))\)이고 미분하면 \(-f_X(g^{-1}(y))(g^{-1})'(y)\)인데, \((g^{-1})' < 0\)이라 절댓값과 같다. ∎

절댓값이 붙은 인수는 \(X\)의 작은 구간이 \(Y\)에서 몇 배로 늘어나는가의 역수이다. 구간이 늘어나면 같은 확률이 넓게 퍼지므로 밀도가 낮아진다. 치환적분의 \(dx = |dx/dy|\,dy\)와 같은 이야기이다.

예제 2.3.3

\(X \sim N(0, 1)\)일 때 (1) \(Y = \sigma X + \mu\) (\(\sigma > 0\)), (2) \(Y = e^X\)의 밀도를 구하여라.

풀이. (1) \(g^{-1}(y) = (y - \mu)/\sigma\)이고 도함수는 \(1/\sigma\)이므로 \(f_Y(y) = \frac1\sigma\varphi\left(\frac{y-\mu}\sigma\right)\), 곧 \(N(\mu, \sigma^2)\)이다. 즉 정규분포는 표준정규분포를 늘리고 옮긴 것뿐이다. (2) \(g^{-1}(y) = \ln y\)이고 도함수는 \(1/y\)이므로 \(f_Y(y) = \frac{1}{y\sqrt{2\pi}}e^{-(\ln y)^2/2}\) (\(y > 0\))이며, 이것을 로그정규분포라 한다. 예를 들어 \(P(Y \le 2) = \Phi(\ln 2) \approx 0.7559\)이다.

2.3.3단조가 아닌 변환

\(g\)가 단조가 아니면 \(\{g(X) \le y\}\)가 여러 구간으로 나뉜다. 그래도 분포함수 방법은 그대로 쓸 수 있다.

예제 2.3.4

\(Z \sim N(0, 1)\)일 때 \(Y = Z^2\)의 밀도를 구하여라.

풀이. \(y > 0\)에서 \(F_Y(y) = P(-\sqrt y \le Z \le \sqrt y) = \Phi(\sqrt y) - \Phi(-\sqrt y)\)이다. 미분하면 \(f_Y(y) = \varphi(\sqrt y)\frac1{2\sqrt y}\cdot 2 = \frac1{\sqrt{2\pi y}}e^{-y/2}\)이다. 이것이 자유도 1인 카이제곱분포이며 \(\Gamma(1/2, 1/2)\)과 같다. 예를 들어 \(P(Y \le 1) = P(|Z| \le 1) \approx 0.6827\)이다.

2.3.4역변환 방법

정리 2.3.5

\(F\)가 연속이고 순증가인 분포함수이고 \(U \sim U(0, 1)\)이면 \(X = F^{-1}(U)\)의 분포함수는 \(F\)이다.

증명.\(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\)이다. ∎

컴퓨터는 균등 난수만 만들 수 있으므로, 모든 분포의 난수는 이렇게 만든다. 예를 들어 \(F(x) = 1 - e^{-\lambda x}\)의 역함수에서 \(X = -\ln(1 - U)/\lambda\)이고, \(1 - U\)도 균등분포이므로 \(X = -\ln U/\lambda \sim \mathrm{Exp}(\lambda)\)이다.

흔한 오해밀도를 그대로 대입해 \(f_Y(y) = f_X(g^{-1}(y))\)로 쓰기 쉽지만, 늘어난 비율의 인수를 빠뜨리면 넓이가 1이 되지 않는다. 또 단조가 아닌 \(g\)에 정리 2.3.2를 쓰는 실수가 있는데, \(Z^2\)에서는 \(\pm\sqrt y\) 두 갈래를 모두 더해야 한다. 값의 범위를 빠뜨리는 것도 흔하다. \(Y = X^2\)의 밀도는 \(0 < y < 1\)에서만 \(1/(2\sqrt y)\)이다.
마무리

처음 질문에 답하면, \(Y = X^2\)은 고르게 퍼져 있지 않고 밀도 \(\frac1{2\sqrt y}\)로 0 근처에 몰린다. 이런 분포는 \(\{g(X) \le y\}\)를 \(X\)에 대한 조건으로 풀어 계산한 뒤 미분하는 분포함수 방법으로 언제나 구할 수 있고, 단조 변환이면 \(f_Y = f_X(g^{-1})\cdot|(g^{-1})'|\)이다. 원하는 분포의 난수는 균등 난수 \(U\)를 \(F^{-1}(U)\)로 바꾸는 역변환 방법으로 만든다.

2.3.5연습문제

기본

  1. \(X \sim U(0, 1)\), \(Y = \sqrt X\)의 밀도는?
    답

    \(F_Y(y) = P(X \le y^2) = y^2\), \(f_Y(y) = 2y\) (\(0 < y < 1\)).

응용

  1. \(X \sim \mathrm{Exp}(1)\), \(Y = 2X + 3\)의 밀도와 \(P(Y > 5)\)를 구하여라.
    답

    \(f_Y(y) = \frac12e^{-(y-3)/2}\) (\(y > 3\)). \(P(Y > 5) = P(X > 1) = e^{-1} \approx 0.3679\).

심화

  1. \(U \sim U(0,1)\)일 때 \(Y = \tan(\pi(U - 1/2))\)의 밀도가 \(\frac1{\pi(1 + y^2)}\)(코시분포)임을 보여라.
    답

    \(g^{-1}(y) = \frac12 + \frac1\pi\arctan y\), 도함수 \(\frac1{\pi(1 + y^2)}\), \(f_U = 1\). 이 분포는 평균이 존재하지 않는다(3단원).
