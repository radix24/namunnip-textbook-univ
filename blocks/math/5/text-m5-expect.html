기대값과 지시변수 방법

본문
이 절에서 배울 것
  • 이산·연속 확률변수의 기대값, 분산, 공분산을 정의하고 기대값의 선형성을 쓴다.
  • 복잡한 개수를 지시변수의 합으로 쪼개 기대값을 계산한다.
  • 쿠폰 수집 문제처럼 대기 시간을 기하분포의 합으로 나누어 계산한다.
먼저 알아야 할 것
  • 대표 분포 (2.2절), 변환 (2.3절), 급수와 이상적분.

3.1.1기대값

기대값은 "실험을 많이 되풀이했을 때 값의 평균"을 미리 계산한 것입니다(그것이 정확히 맞다는 것이 6단원의 대수의 법칙). 값마다 그 값이 나올 확률을 가중치로 곱해 더합니다.

정의 3.1.1

기대값: 이산이면 \(E[X] = \sum_xx\,p(x)\), 연속이면 \(E[X] = \int xf(x)\,dx\). 단 \(\sum|x|p(x)\), \(\int|x|f(x)\,dx\)가 유한할 때만 정의한다.

분산: \(\mathrm{Var}(X) = E[(X - \mu)^2] = E[X^2] - \mu^2\) (\(\mu = E[X]\)).

공분산: \(\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - \mu_X\mu_Y\).

절대수렴 조건은 장식이 아닙니다. 코시분포(2.3절 연습문제 3)는 \(\int|x|/(\pi(1+x^2))\,dx = \infty\)라 기대값이 없고, 실제로 표본평균이 어디에도 수렴하지 않습니다. \(g(X)\)의 기대값은 \(Y = g(X)\)의 분포를 구하지 않고 \(E[g(X)] = \sum g(x)p(x)\) 또는 \(\int g(x)f(x)\,dx\)로 계산할 수 있습니다.

3.1.2선형성

정리 3.1.2

기대값이 있는 \(X, Y\)와 상수 \(a, b\)에 대해 \(E[aX + bY] = aE[X] + bE[Y]\). 독립일 필요가 없다. 또 \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\mathrm{Cov}(X, Y)\).

이산인 경우: 결합분포 \(p(x, y)\)로 \(E[aX + bY] = \sum_{x,y}(ax + by)p(x, y) = a\sum_xx\sum_yp(x, y) + b\sum_yy\sum_xp(x, y) = aE[X] + bE[Y]\). 합의 순서를 바꾼 것은 절대수렴 때문에 허용된다. 분산 공식은 \((X + Y - \mu_X - \mu_Y)^2\)을 전개하고 선형성을 쓴다. ∎

선형성의 힘은 "독립일 필요가 없다"에 있습니다. 서로 얽힌 사건들의 개수라도 사건 하나하나의 확률만 알면 기대값을 구할 수 있습니다.

3.1.3지시변수 방법

정의 3.1.3

지시변수: 사건 \(A\)가 일어나면 1, 아니면 0인 확률변수 \(1_A\). \(E[1_A] = P(A)\).

어떤 개수 \(N\)을 "일어난 사건의 수" \(N = \sum_i1_{A_i}\)로 쓰면 \(E[N] = \sum_iP(A_i)\)입니다. 분포를 몰라도 됩니다.

예제 3.1.4 (모자 문제, 단원 자기 점검)

\(n\)명이 모자를 무작위로 집을 때 자기 모자를 집는 사람 수 \(N\)의 기대값과 분산은?

풀이. \(A_i\) = "\(i\)번이 자기 모자", \(P(A_i) = 1/n\). \(E[N] = n\cdot\frac1n = 1\). 분산에는 둘씩의 확률이 필요합니다: \(P(A_i\cap A_j) = \frac{1}{n(n-1)}\). \(E[N^2] = \sum_iP(A_i) + \sum_{i\ne j}P(A_i\cap A_j) = 1 + n(n-1)\cdot\frac1{n(n-1)} = 2\)이므로 \(\mathrm{Var}(N) = 2 - 1 = 1\) (\(n \ge 2\)). 평균과 분산이 모두 1이라는 것은 \(N\)이 포아송(1)에 가깝다는 신호입니다(1.1절 탐구 카드).

예제 3.1.5

23명의 생일(365일 균등, 독립)에서 (a) 같은 생일인 쌍의 수의 기대값 (b) 서로 다른 생일의 수의 기대값.

풀이. (a) 쌍 \(\binom{23}2 = 253\)개 각각이 같은 생일일 확률 \(1/365\). 기대값 \(253/365 \approx 0.693\). (b) 날짜 \(d\)마다 "누군가의 생일"인 사건의 확률 \(1 - (364/365)^{23}\). 기대값 \(365(1 - (364/365)^{23}) \approx 22.32\).

예제 3.1.6 (쿠폰 수집)

종류 \(n\)개인 쿠폰이 상자마다 무작위로 하나씩 들어 있다. 모든 종류를 모으려면 평균 몇 상자가 필요한가?

풀이. 이번에는 지시변수 대신 대기 시간을 단계로 나눕니다. \(i - 1\)종류를 가진 뒤 새 종류를 얻을 때까지의 상자 수 \(T_i\)는 성공 확률 \(\frac{n - i + 1}n\)인 기하분포이고 \(E[T_i] = \frac n{n - i + 1}\)입니다. 선형성으로

\[E[T] = \sum_{i=1}^n\frac n{n - i + 1} = n\left(1 + \frac12 + \cdots + \frac1n\right) = nH_n \approx n\ln n.\]

\(n = 6\)(주사위 눈 모두 보기)이면 \(14.7\)번, \(n = 50\)이면 약 \(225\)번입니다. 마지막 몇 종류에 대부분의 시간이 듭니다: 마지막 한 종류만 평균 \(n\)번. 같은 절의 탐구 카드에서 시뮬레이션과 비교해 볼 수 있습니다.

흔한 실수(1) 선형성에 독립이 필요하다고 여긴다: 필요한 것은 분산의 합 공식(공분산 0)이다. (2) \(E[XY] = E[X]E[Y]\)를 독립이 아닐 때 쓴다. (3) \(E[1/X] = 1/E[X]\), \(E[X^2] = E[X]^2\)처럼 비선형 함수를 기대값 밖으로 뺀다. (4) 지시변수 방법에서 분산을 구할 때 \(P(A_i\cap A_j)\)를 \(P(A_i)P(A_j)\)로 쓴다.
요약
  1. \(E[X] = \sum xp(x)\) 또는 \(\int xf(x)\,dx\) (절대수렴할 때). 분산은 \(E[X^2] - \mu^2\).
  2. 선형성은 독립 없이 성립한다. 개수를 지시변수의 합으로 쓰면 \(E[N] = \sum P(A_i)\).
  3. 쿠폰 수집: 기하분포의 합, 평균 \(nH_n\).

3.1.4연습문제

기본

  1. \(B(n, p)\)의 평균과 분산을 지시변수로 구하여라.
    답

    \(X = \sum_{i=1}^n1_{A_i}\), \(A_i\)는 독립이고 확률 \(p\). \(E = np\), 독립이라 공분산 0이므로 \(\mathrm{Var} = n\,p(1-p)\).

응용

  1. 동전을 10번 던질 때 "앞앞"이 연속으로 나오는 위치(겹쳐도 셈)의 수의 기대값은?
    답

    위치 \(i = 1, \dots, 9\)마다 확률 \(1/4\). 기대값 \(9/4 = 2.25\).

심화

  1. 음이 아닌 정수 값 확률변수에 대해 \(E[X] = \sum_{k=1}^\infty P(X \ge k)\)임을 보이고 기하분포의 평균을 구하여라.
    답

    \(X = \sum_{k\ge1}1_{\{X\ge k\}}\)이므로 선형성(음이 아닌 항이라 무한합도 허용). 기하분포는 \(P(X \ge k) = (1-p)^{k-1}\), 합 \(1/p\).
