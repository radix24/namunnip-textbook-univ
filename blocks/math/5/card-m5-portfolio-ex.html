두 자산을 섞어 위험 줄이기

예제 · 음의 상관이 분산을 줄인다

먼저 예측

수익률의 표준편차가 0.2인 자산 X와 0.3인 자산 Y가 있습니다. 둘을 섞으면 표준편차가 0.2보다 작아질 수 있을까요?

예측 확인

상관계수가 음수이면 그렇습니다. \(\rho = -0.5\)이면 약 0.119까지 줄어듭니다.

\(\sigma_X = 0.2\), \(\sigma_Y = 0.3\), \(\rho = -0.5\)이다. 비율 \(w\)만큼 X, \(1 - w\)만큼 Y에 넣은 \(P = wX + (1 - w)Y\)의 분산을 최소로 하는 \(w\)와 그때의 표준편차를 구하여라.

전략

합의 분산 공식(3.3절)으로 \(\mathrm{Var}(P)\)를 \(w\)의 이차식으로 쓰고 꼭짓점을 찾습니다.

풀이

  1. \(\mathrm{Cov}(X, Y) = -0.5\times0.2\times0.3 = -0.03\).
    \(\mathrm{Cov} = \rho\sigma_X\sigma_Y\).
  2. \(\mathrm{Var}(P) = 0.04w^2 + 0.09(1 - w)^2 - 0.06w(1 - w)\).
    \(a = w\), \(b = 1 - w\).
  3. \(w\)로 미분해 0으로 두면 \(w^* = \dfrac{\sigma_Y^2 - \mathrm{Cov}}{\sigma_X^2 + \sigma_Y^2 - 2\mathrm{Cov}} = \dfrac{0.12}{0.19} \approx 0.632\).
    이차항 계수 \(0.19 > 0\)이라 최소.
  4. \(\mathrm{Var}(P) \approx 0.01421\), 표준편차 약 0.119.
    대입.

검산

반반(\(w = 0.5\))이면 \(0.01 + 0.0225 - 0.015 = 0.0175\), 표준편차 0.132로 최소보다 큽니다. 상관계수가 \(+0.5\)이면 최소 비율은 \(w = \frac{0.06}{0.07} \approx 0.857\)이고 표준편차 약 0.196으로 0.2보다 조금밖에 안 줄어듭니다.

의미

분산투자의 원리입니다. 한쪽이 떨어질 때 다른 쪽이 오르는 경향(음의 상관)이 있으면 섞을 때 위험이 크게 줄어듭니다. \(\rho = -1\)이면 분산을 0으로 만들 수도 있습니다(따름정리 3.3.3: 두 수익이 직선 관계).

이해 확인

\(\rho = -1\)일 때 분산이 0이 되는 \(w\)는?

답

\(\mathrm{Cov} = -0.06\), \(w^* = \frac{0.15}{0.25} = 0.6\). 표준편차 \(|0.6\times0.2 - 0.4\times0.3| = 0\).
