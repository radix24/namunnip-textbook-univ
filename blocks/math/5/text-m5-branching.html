분지 과정과 소멸 확률

본문

한 사람이 자녀를 0명, 1명, 2명 낳을 확률이 각각 정해져 있고 모든 사람이 독립적으로 같은 규칙을 따른다. 이 집안의 성(姓)이 언젠가 끊길 확률은 얼마인가? 평균 자녀 수가 1보다 크면 반드시 살아남을까?

먼저 알아야 할 것생성함수와 기대값(3.2절), 확률의 연속성(1.2절), 볼록함수의 성질을 쓴다. 이 예는 Williams 0장의 출발점이다.

8.4.1모형

\(Z_0 = 1\)에서 시작해, \(n\)세대의 각 사람이 독립적으로 같은 분포 \(p_k = P(\text{자녀 } k\text{명})\)를 따라 자녀를 낳는다고 하자. \(n + 1\)세대의 인원 \(Z_{n+1}\)은 \(Z_n\)명이 낳은 자녀 수의 합이다. 이것을 Galton-Watson 분지 과정이라 한다. 자녀 수의 생성함수를 \(f(s) = \sum_kp_ks^k\)라 하자.

생성함수를 쓰면 세대가 바뀔 때의 계산이 합성으로 바뀐다. \(Z_n = m\)일 때 \(Z_{n+1}\)은 독립인 \(m\)개의 합이라 생성함수가 \(f(s)^m\)이다. 따라서 \(E[s^{Z_{n+1}}] = E[f(s)^{Z_n}]\)이고, \(Z_n\)의 생성함수를 \(f_n\)이라 하면 \(f_{n+1} = f_n \circ f\), 곧 \(f_n = f \circ f \circ \dots \circ f\)(\(n\)번)이다.

8.4.2소멸 확률

\(\{Z_n = 0\}\)은 증가하는 사건열이다. 한 번 0이 되면 계속 0이기 때문이다. 그러면 연속성으로 소멸 확률은 \(q = \lim_nP(Z_n = 0) = \lim_nf_n(0)\)이다.

정리 8.4.1

\(p_1 < 1\)이라 하고 평균 자녀 수를 \(\mu = f'(1)\)이라 하자. 소멸 확률 \(q\)는 방정식 \(s = f(s)\)의 \([0, 1]\)에서 가장 작은 근이다. \(\mu \le 1\)이면 \(q = 1\)이고, \(\mu > 1\)이면 \(q < 1\)이다.

증명.\(x_n = f_n(0)\)은 \(x_{n+1} = f(x_n)\)을 만족하고, \(f\)가 증가함수라서 \(x_n\)은 증가한다. 극한 \(q\)는 \(f\)의 연속성으로 \(q = f(q)\)를 만족한다. \(s = f(s)\)의 다른 근 \(r \in [0, 1]\)이 있으면 \(x_0 = 0 \le r\)에서 출발해 \(x_n = f(x_{n-1}) \le f(r) = r\)이므로 \(q \le r\)이다. 따라서 \(q\)는 가장 작은 근이다. 이제 \(f\)는 볼록이고 \(f(1) = 1\)이다. \(\mu = f'(1) \le 1\)이면 그래프가 \([0, 1)\)에서 대각선보다 위에 있어 근이 1뿐이다. \(\mu > 1\)이면 1 바로 왼쪽에서 그래프가 대각선 아래로 내려가고, \(f(0) = p_0 \ge 0\)이므로 중간값 정리로 \([0, 1)\)에 근이 하나 더 있다. 이것이 그림 1의 \(q\)이다. ∎

예제 8.4.2

\(p_0 = \frac14\), \(p_1 = \frac14\), \(p_2 = \frac12\)일 때 소멸 확률을 구하여라.

풀이. \(\mu = \frac14 + 2\cdot\frac12 = \frac54 > 1\)이다. \(s = \frac14 + \frac14s + \frac12s^2\)을 정리하면 \(2s^2 - 3s + 1 = 0\), 곧 \((2s - 1)(s - 1) = 0\)이다. 가장 작은 근은 \(q = \frac12\)이다. 평균이 1보다 커도 첫 사람이 자녀 없이 끝날 확률 \(\frac14\)을 비롯해 일찍 끊기는 경로들이 있어, 절반의 확률로 결국 사라진다.

\(\mu > 1\)이고 살아남는 경우에는 \(Z_n\)이 대략 \(\mu^n\)으로 자란다. 정확히는 \(Z_n/\mu^n\)이 마팅게일이고 거의 확실히 수렴한다. Williams 책은 이 수렴을 증명하는 것을 목표로 측도론과 마팅게일 이론을 쌓아 간다.

마무리

분지 과정에서 \(n\)세대 인원의 생성함수는 자녀 수 생성함수 \(f\)를 \(n\)번 합성한 것이다. 소멸 확률은 \(f_n(0)\)의 극한이고, 이것은 \(s = f(s)\)의 가장 작은 근이다. 평균 자녀 수가 1 이하이면 반드시 소멸하고, 1보다 크면 소멸 확률이 1보다 작지만 0은 아닐 수 있다.

8.4.3연습문제

기본

  1. \(E[Z_n] = \mu^n\)임을 \(f_n'(1)\)로 보여라.
    답

    \(f_{n+1} = f_n \circ f\)를 미분하면 \(f_{n+1}'(1) = f_n'(f(1))f'(1) = f_n'(1)\mu\).

응용

  1. 자녀 수가 기하분포 \(p_k = (1 - a)a^k\)일 때 소멸 확률을 구하여라.
    답

    \(f(s) = \frac{1 - a}{1 - as}\). \(s = f(s)\)의 근은 \(1\)과 \(\frac{1 - a}{a}\)이므로 \(a > \frac12\)이면 \(q = \frac{1 - a}{a}\), 아니면 \(q = 1\).
