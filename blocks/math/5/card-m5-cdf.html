분포함수 하나로 모든 확률을 읽는다

탐구 · 구간 확률과 점프

질문

분포함수의 그래프에서 구간의 확률과 한 점의 확률은 어디에 보일까? 이산도 연속도 아닌 분포도 분포함수로 나타낼 수 있을까?

복원

\(P(a < X \le b) = F(b) - F(a)\), \(P(X = x) = F(x) - F(x^-)\) (2.1절 따름정리 2.1.3).

해 보기

  1. 혼합 분포에서 \(a = 1\), \(b = 2\)이면 \(P(1 < X \le 2) = 0.1628\)입니다(예제 2.1.5).
  2. \(b\)를 0으로 옮기자. \(P(X = 0) = 0.3\): 그래프가 0에서 0.3만큼 뛴다. \(a\)를 −0.5로 두면 \(P(-0.5 < X \le 0) = 0.3\)이다.
  3. 주사위로 바꾸고 \(a = 2\), \(b = 4\)로 두면 \(2/6 = 0.3333\)이다. \(a = 1.9\)로 바꾸면 \(3/6\)이 된다: 구간이 2를 포함하게 되었기 때문이다.
  4. 지수분포나 정규분포에서는 어느 점에서도 점프가 없어 \(P(X = b) = 0\)이다.

설명

  1. 채운 점이 위에 있다\(F(x) = P(X \le x)\)는 \(x\) 자신의 확률을 포함하므로 점프한 점에서 값은 위쪽이다. 이것이 오른쪽 연속이다.
  2. 세로 길이가 확률이다밀도에서는 넓이가 확률이지만, 분포함수에서는 세로 증가량이 확률이다. 그래서 이산, 연속, 혼합을 같은 그림으로 다룰 수 있다.

판단

"\(P(a \le X \le b) = F(b) - F(a)\)"는 연속 분포에서만 맞다. 점프가 있는 분포에서는 \(F(b) - F(a^-)\)여야 한다. 주사위에서 \(a = 2\), \(b = 4\)이면 \(1/2\)이지 \(1/3\)이 아니다.
