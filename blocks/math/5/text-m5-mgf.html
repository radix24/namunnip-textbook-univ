적률생성함수

본문

한 시간에 오는 전화 수가 \(\mathrm{Pois}(2)\)이고 이메일 수가 독립인 \(\mathrm{Pois}(3)\)이다. 둘을 합친 연락 수는 어떤 분포를 따를까? 합의 분포를 합성곱으로 직접 계산하지 않고 알아내는 방법이 있을까?

먼저 알아야 할 것기대값과 분산(3.1절), 기본 분포(2.2절), 지수함수의 테일러 급수를 쓴다.

3.2.1정의와 적률

\(E[X]\), \(E[X^2]\), \(E[X^3]\), …을 적률이라 한다. 적률을 하나씩 계산하는 대신 한 함수에 모아 두면 편리하다. \(e^{tX} = \sum_kt^kX^k/k!\)이므로 이 기대값을 취하면 계수에 적률이 나타난다.

정의 3.2.1

\(M_X(t) = E[e^{tX}]\)를 \(X\)의 적률생성함수라 하며, 0을 포함하는 어떤 열린 구간에서 유한할 때 쓴다.

정리 3.2.2

(1) \(M_X^{(k)}(0) = E[X^k]\)이다. (2) \(X, Y\)가 독립이면 \(M_{X+Y}(t) = M_X(t)M_Y(t)\)이다. (3) 0 근처 열린 구간에서 \(M_X = M_Y\)이면 \(X\)와 \(Y\)의 분포가 같다(유일성).

증명.(1) 0 근처에서 미분과 기대값의 순서를 바꿀 수 있음(우세수렴 정리, 여기서는 받아들인다)을 쓰면 \(M^{(k)}(t) = E[X^ke^{tX}]\)이고, \(t = 0\)을 넣는다. (2) 독립이면 \(e^{tX}\)와 \(e^{tY}\)도 독립이라 \(E[e^{tX}e^{tY}] = E[e^{tX}]E[e^{tY}]\)이다. (3)의 증명은 라플라스 변환의 역변환 이론이 필요해 생략한다. ∎

(2)와 (3)을 합치면 전략이 나온다. 합의 분포를 직접 구하는 대신 적률생성함수를 곱하고, 그 곱이 어떤 분포의 적률생성함수인지 알아보면 된다.

3.2.2대표 분포의 적률생성함수

예제 3.2.3

포아송, 지수, 정규분포의 적률생성함수를 구하여라.

풀이. 포아송분포는 \(\sum_ke^{tk}e^{-\lambda}\lambda^k/k! = e^{-\lambda}e^{\lambda e^t} = e^{\lambda(e^t - 1)}\)이다. 지수분포는 \(t < \lambda\)에서 \(\int_0^\infty e^{tx}\lambda e^{-\lambda x}dx = \frac\lambda{\lambda - t}\)이다. 표준정규분포는 지수를 완전제곱하면 \(tx - x^2/2 = t^2/2 - (x - t)^2/2\)이므로 \(e^{t^2/2}\)이다. 일반 \(N(\mu, \sigma^2)\)은 \(\sigma Z + \mu\)이므로 \(e^{\mu t}M_Z(\sigma t) = e^{\mu t + \sigma^2t^2/2}\)이다.

(1)로 확인해 보자. 지수분포에서 \(M' = \lambda/(\lambda - t)^2\), \(M'' = 2\lambda/(\lambda - t)^3\)이므로 \(E[X] = 1/\lambda\), \(E[X^2] = 2/\lambda^2\)이고 분산은 \(1/\lambda^2\)이다. 대표 분포를 모으면 다음 표와 같다.

분포\(M(t)\)평균분산
\(B(n, p)\)\((1 - p + pe^t)^n\)\(np\)\(np(1-p)\)
\(\mathrm{Pois}(\lambda)\)\(e^{\lambda(e^t-1)}\)\(\lambda\)\(\lambda\)
\(\mathrm{Exp}(\lambda)\)\(\lambda/(\lambda - t)\)\(1/\lambda\)\(1/\lambda^2\)
\(\Gamma(\alpha, \lambda)\)\((\lambda/(\lambda - t))^\alpha\)\(\alpha/\lambda\)\(\alpha/\lambda^2\)
\(N(\mu, \sigma^2)\)\(e^{\mu t + \sigma^2t^2/2}\)\(\mu\)\(\sigma^2\)

3.2.3독립 합의 분포

예제 3.2.4

독립인 \(X \sim \mathrm{Pois}(2)\), \(Y \sim \mathrm{Pois}(3)\)에 대해 \(X + Y\)의 분포와 \(P(X + Y = 2)\)를 구하여라.

풀이. \(M_{X+Y} = e^{2(e^t-1)}e^{3(e^t-1)} = e^{5(e^t-1)}\)이므로 유일성으로 \(X + Y \sim \mathrm{Pois}(5)\)이다. 따라서 \(P(X + Y = 2) = e^{-5}5^2/2 \approx 0.0842\)이다. 즉 처음 질문의 전화와 이메일 수를 합쳐도 포아송분포이다.

같은 방법으로 독립 정규의 합은 \(N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)\), 독립 \(\mathrm{Exp}(\lambda)\) \(k\)개의 합은 \(\Gamma(k, \lambda)\), 독립 베르누이 \(n\)개의 합은 \(B(n, p)\)이다. 6단원에서는 표준화한 합의 적률생성함수가 \(e^{t^2/2}\)로 수렴함을 보여 중심극한정리를 얻는다.

흔한 오해독립이 아닌데 적률생성함수를 곱하는 실수가 있다. 또 정규분포의 합에서 표준편차를 더하기 쉬운데, 더하는 것은 분산이다. 정의역을 잊는 것도 조심한다. 지수분포의 \(M(t)\)는 \(t < \lambda\)에서만 유한하고, 코시분포는 \(t \ne 0\)에서 모두 무한이라 적률생성함수가 없다.
마무리

처음 질문에 답하면, 연락 수는 \(\mathrm{Pois}(5)\)를 따른다. 독립이면 적률생성함수가 곱해지고(\(M_{X+Y} = M_XM_Y\)), 적률생성함수가 분포를 결정하므로 \(e^{5(e^t - 1)}\)에서 바로 알 수 있다. 적률생성함수 \(M_X(t) = E[e^{tX}]\)는 \(M^{(k)}(0) = E[X^k]\)로 적률을 모두 담고 있으며, 같은 방법으로 정규끼리의 합은 정규, 지수의 합은 감마임을 보인다.

3.2.4연습문제

기본

  1. \(M_X(t) = (0.3 + 0.7e^t)^{10}\)이면 \(X\)의 분포와 평균은?
    답

    \(B(10, 0.7)\), 평균 7.

응용

  1. 독립인 \(X \sim N(1, 4)\), \(Y \sim N(2, 9)\)에 대해 \(X + Y\)의 분포와 \(P(X + Y > 3)\)을 구하여라.
    답

    \(N(3, 13)\). 평균과 같으므로 \(P = 0.5\).

심화

  1. 포아송분포의 적률생성함수로 \(E[X(X-1)] = \lambda^2\)임을 보여라.
    답

    \(M'' (0) = E[X^2] = \lambda^2 + \lambda\) (\(M' = \lambda e^tM\), \(M'' = \lambda e^tM + \lambda^2e^{2t}M\)). \(E[X(X-1)] = E[X^2] - E[X] = \lambda^2\).
