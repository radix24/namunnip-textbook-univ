본문

  • 균등분포 표본에서 \(k\)번째로 작은 값의 밀도와 기대값을 구한다.

  • 분포함수와 밀도 (2.1절), 독립, 결합분포 (4.1절), 이항계수.

4.3.1최댓값과 최솟값

독립이고 분포함수가 \(F\)인 \(X_1, \dots, X_n\)을 작은 순서로 늘어놓은 것을 \(X_{(1)} \le X_{(2)} \le \dots \le X_{(n)}\)이라 쓰고 순서통계량이라 합니다. 최댓값은 "모두 \(x\) 이하"라는 사건으로, 최솟값은 "모두 \(x\)보다 큼"이라는 사건으로 바꾸면 독립을 쓸 수 있습니다.

정리 4.3.1

\(P(X_{(n)} \le x) = F(x)^n\), \(\quad P(X_{(1)} > x) = (1 - F(x))^n\).

\(X_{(n)} \le x \iff\) 모든 \(i\)에 대해 \(X_i \le x\). 독립이므로 확률은 \(F(x)^n\). 최솟값도 같은 방법. ∎

예제 4.3.2 (지수분포의 최솟값)

\(X_i \sim \mathrm{Exp}(\lambda_i)\)가 독립이면 \(P(X_{(1)} > x) = \prod e^{-\lambda_ix} = e^{-(\lambda_1 + \dots + \lambda_n)x}\). 따라서 \(X_{(1)} \sim \mathrm{Exp}(\lambda_1 + \dots + \lambda_n)\).

부품 \(n\)개가 직렬로 연결된 장치의 수명은 최솟값, 병렬(하나라도 살면 작동)이면 최댓값입니다.

4.3.2k번째 순서통계량

균등분포 \(U(0, 1)\) 표본에서 \(X_{(k)}\)가 \(x\) 근처 폭 \(dx\)에 있으려면, \(n\)개 중 하나가 그 구간에, \(k - 1\)개가 \(x\)보다 작고 \(n - k\)개가 크면 됩니다. 이렇게 나누는 방법의 수를 세면

정리 4.3.3

\(U(0, 1)\)의 독립 표본 \(n\)개에서 \(X_{(k)}\)의 밀도는 \(f_k(x) = \dfrac{n!}{(k - 1)!\,(n - k)!}x^{k - 1}(1 - x)^{n - k}\) (\(0 < x < 1\))이고 \(E[X_{(k)}] = \dfrac k{n + 1}\).

기대값은 베타 적분 \(\int_0^1x^a(1 - x)^bdx = \frac{a!\,b!}{(a + b + 1)!}\)로 계산합니다. \(n\)개의 점이 \([0, 1]\)을 평균적으로 \(n + 1\)등분한다는 뜻입니다. \(k = n\)이면 \(f_n(x) = nx^{n-1}\)로 정리 4.3.1을 미분한 것과 같습니다.

흔한 실수(1) \(P(X_{(1)} \le x) = F(x)^n\)이라 쓴다: 최솟값은 "모두 큼"의 여사건이라 \(1 - (1 - F(x))^n\)이다. (2) 순서통계량들이 독립이라 여긴다: \(X_{(1)} \le X_{(2)}\)이므로 독립이 아니다. (3) 밀도의 계수에서 가운데 하나를 고르는 \(n\)가지를 빠뜨린다.
요약
  1. 최댓값 \(F^n\), 최솟값 \(1 - (1 - F)^n\).
  2. 독립 지수분포의 최솟값은 비율을 더한 지수분포.
  3. 균등 표본의 \(k\)번째: 베타형 밀도, 기대값 \(\frac k{n + 1}\).

4.3.3연습문제

기본

  1. 주사위를 3번 던질 때 최댓값이 4 이하일 확률은?
    답

    \(\left(\frac46\right)^3 = \frac8{27} \approx 0.296\).

응용

  1. \(U(0, 1)\) 표본 5개의 중앙값 \(X_{(3)}\)의 밀도와 기대값을 구하여라.
    답

    \(f_3(x) = 30x^2(1 - x)^2\), \(E = \frac36 = \frac12\).

심화

  1. \(U(0, 1)\) 표본 \(n\)개의 범위 \(R = X_{(n)} - X_{(1)}\)의 기대값을 구하여라.
    답

    선형성으로 \(\frac n{n + 1} - \frac1{n + 1} = \frac{n - 1}{n + 1}\).
