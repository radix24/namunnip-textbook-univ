순서통계량

본문

부품 4개를 직렬로 연결한 장치는 하나만 고장 나도 멈추고, 병렬로 연결한 장치는 모두 고장 나야 멈춘다. 각 부품의 수명 분포를 알 때 두 장치의 수명은 어떻게 분포할까? 더 일반적으로, 표본을 크기순으로 늘어놓았을 때 \(k\)번째 값은 어디쯤 놓일까?

먼저 알아야 할 것분포함수(2.1절), 독립(4.1절), 지수분포(2.2절)를 쓴다.

4.3.1최댓값과 최솟값

독립이고 분포함수가 \(F\)인 \(X_1, \dots, X_n\)을 작은 순서로 늘어놓은 것을 \(X_{(1)} \le X_{(2)} \le \dots \le X_{(n)}\)이라 쓰고 순서통계량이라 한다. 여기서 최댓값은 "모두 \(x\) 이하"라는 사건으로, 최솟값은 "모두 \(x\)보다 큼"이라는 사건으로 바꾸면 독립을 쓸 수 있다.

정리 4.3.1

\(P(X_{(n)} \le x) = F(x)^n\)이고 \(P(X_{(1)} > x) = (1 - F(x))^n\)이다.

증명.\(X_{(n)} \le x\)인 것은 모든 \(i\)에 대해 \(X_i \le x\)인 것과 같다. 독립이므로 그 확률은 \(F(x)^n\)이다. 최솟값도 같은 방법으로 보인다. ∎

예제 4.3.2 (지수분포의 최솟값)

\(X_i \sim \mathrm{Exp}(\lambda_i)\)가 독립일 때 \(X_{(1)}\)의 분포를 구하여라.

풀이. \(P(X_{(1)} > x) = \prod e^{-\lambda_ix} = e^{-(\lambda_1 + \dots + \lambda_n)x}\)이므로 \(X_{(1)} \sim \mathrm{Exp}(\lambda_1 + \dots + \lambda_n)\)이다. 처음 질문의 직렬 장치의 수명은 최솟값이므로, 각 부품의 고장률을 더한 지수분포를 따른다. 반면 병렬 장치의 수명은 최댓값이라 분포함수가 \(F(x)^n\)이다.

4.3.2k번째 순서통계량

이제 균등분포 \(U(0, 1)\) 표본에서 \(X_{(k)}\)가 \(x\) 근처 폭 \(dx\)에 있으려면, \(n\)개 가운데 하나가 그 구간에 있고 \(k - 1\)개가 \(x\)보다 작고 \(n - k\)개가 크면 된다. 이렇게 나누는 방법의 수를 세면 다음 정리를 얻는다.

정리 4.3.3

\(U(0, 1)\)의 독립 표본 \(n\)개에서 \(X_{(k)}\)의 밀도는 \(0 < x < 1\)에서 \(f_k(x) = \dfrac{n!}{(k - 1)!\,(n - k)!}x^{k - 1}(1 - x)^{n - k}\)이고, \(E[X_{(k)}] = \dfrac k{n + 1}\)이다.

그러면 기대값은 베타 적분 \(\int_0^1x^a(1 - x)^bdx = \frac{a!\,b!}{(a + b + 1)!}\)으로 계산한다. 즉 \(n\)개의 점이 \([0, 1]\)을 평균적으로 \(n + 1\)등분한다는 뜻이며, 그림 1의 \(n = 4\)에서는 눈금 0.2, 0.4, 0.6, 0.8이다. 또 \(k = n\)이면 \(f_n(x) = nx^{n-1}\)로, 정리 4.3.1을 미분한 것과 같다.

이 결과는 통계에서 자주 쓰인다. 예를 들어 표본의 중앙값은 가운데 순서통계량이므로, 표본이 홀수 \(n = 2m + 1\)개이면 중앙값 \(X_{(m+1)}\)의 기대값은 \(\frac12\)이고 밀도는 가운데가 높고 양 끝이 낮은 종 모양이다. 그래서 표본이 많을수록 표본 중앙값은 참 중앙값 근처에 몰린다. 또 최댓값의 기대값 \(\frac n{n+1}\)에서, 균등분포의 끝점 1을 표본 최댓값으로 어림하면 평균적으로 \(\frac1{n+1}\)만큼 작게 나온다는 것도 알 수 있다.

흔한 오해\(P(X_{(1)} \le x) = F(x)^n\)이라 쓰기 쉽지만, 최솟값은 "모두 큼"의 여사건이라 \(1 - (1 - F(x))^n\)이다. 또 순서통계량들이 독립이라 여기는 실수가 있는데, \(X_{(1)} \le X_{(2)}\)이므로 독립이 아니다. 밀도의 계수에서 가운데 하나를 고르는 \(n\)가지를 빠뜨리는 것도 흔하다.
마무리

처음 질문에 답하면, 직렬 장치의 수명은 최솟값이라 \(P(X_{(1)} > x) = (1 - F(x))^n\)이고, 부품 수명이 지수분포이면 고장률을 더한 지수분포를 따른다. 병렬 장치의 수명은 최댓값이라 분포함수가 \(F(x)^n\)이다. 균등 표본을 크기순으로 늘어놓은 \(k\)번째 값은 베타형 밀도를 따르고 기대값이 \(\frac k{n + 1}\)이어서, 표본이 구간을 평균적으로 고르게 나눈다.

4.3.3연습문제

기본

  1. 주사위를 3번 던질 때 최댓값이 4 이하일 확률은?
    답

    \(\left(\frac46\right)^3 = \frac8{27} \approx 0.296\).

응용

  1. \(U(0, 1)\) 표본 5개의 중앙값 \(X_{(3)}\)의 밀도와 기대값을 구하여라.
    답

    \(f_3(x) = 30x^2(1 - x)^2\), \(E = \frac36 = \frac12\).

심화

  1. \(U(0, 1)\) 표본 \(n\)개의 범위 \(R = X_{(n)} - X_{(1)}\)의 기대값을 구하여라.
    답

    선형성으로 \(\frac n{n + 1} - \frac1{n + 1} = \frac{n - 1}{n + 1}\).
