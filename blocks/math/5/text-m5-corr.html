상관계수와 코시-슈바르츠 부등식

본문
이 절에서 배울 것

  • 코시-슈바르츠 부등식으로 \(-1 \le \rho \le 1\)을 증명하고 등호 조건을 구한다.

3.3.1합의 분산

선형성을 \((X + Y - \mu_X - \mu_Y)^2\)에 쓰면

\[\mathrm{Var}(aX + bY) = a^2\mathrm{Var}(X) + b^2\mathrm{Var}(Y) + 2ab\,\mathrm{Cov}(X, Y).\]

공분산은 단위에 따라 크기가 바뀌므로(키를 cm에서 m로 바꾸면 100분의 1), 단위와 무관한 지표로 표준화합니다.

정의 3.3.1

상관계수: \(\sigma_X, \sigma_Y > 0\)일 때 \(\rho(X, Y) = \dfrac{\mathrm{Cov}(X, Y)}{\sigma_X\sigma_Y}\).

3.3.2코시-슈바르츠 부등식

정리 3.3.2 (코시-슈바르츠)

\(E[X^2], E[Y^2] < \infty\)이면 \((E[XY])^2 \le E[X^2]\,E[Y^2]\). 등호는 어떤 상수 \(t\)에 대해 확률 1로 \(X = tY\)일 때(또는 \(Y = 0\)일 때) 성립한다.

증명 방향: 0 이상인 양 \(E[(X - tY)^2]\)를 \(t\)의 이차식으로 보고, 늘 0 이상이니 판별식이 0 이하임을 씁니다.

\(E[Y^2] = 0\)이면 확률 1로 \(Y = 0\)이라 양변이 0이다. 아니면 모든 실수 \(t\)에 대해 \(0 \le E[(X - tY)^2] = E[Y^2]t^2 - 2E[XY]t + E[X^2]\). 최고차 계수가 양수인 이차식이 늘 0 이상이므로 판별식 \(\frac D4 = (E[XY])^2 - E[X^2]E[Y^2] \le 0\). 등호이면 중근 \(t_0\)에서 \(E[(X - t_0Y)^2] = 0\)이라 확률 1로 \(X = t_0Y\). ∎

따름정리 3.3.3

\(-1 \le \rho(X, Y) \le 1\)이고, \(|\rho| = 1\)일 필요충분조건은 확률 1로 \(Y = aX + b\) (\(a \ne 0\))인 것이다. \(\rho = 1\)이면 \(a > 0\), \(\rho = -1\)이면 \(a < 0\).

정리 3.3.2를 \(X - \mu_X\), \(Y - \mu_Y\)에 쓰면 \(\mathrm{Cov}(X, Y)^2 \le \sigma_X^2\sigma_Y^2\)이 바로 나옵니다.

3.3.3상관 0과 독립

예제 3.3.4

\(X \sim U(-1, 1)\), \(Y = X^2\)이면 \(\mathrm{Cov}(X, Y) = E[X^3] - E[X]E[X^2] = 0 - 0 = 0\). 그러나 \(Y\)는 \(X\)로 완전히 정해지므로 독립이 아니다.

상관계수는 직선 관계의 강도만 잽니다. 독립이면 상관 0이지만 역은 성립하지 않습니다(정규분포 쌍은 예외, 4.1절).

흔한 실수(1) \(\rho = 0\)이면 관계가 없다고 여긴다: 예제 3.3.4처럼 곡선 관계는 잡지 못한다. (2) \(\rho\)가 클수록 기울기가 크다고 여긴다: \(\rho\)는 직선에 얼마나 몰려 있는지이고, 기울기는 \(\rho\sigma_Y/\sigma_X\)이다. (3) 음의 공분산이면 합의 분산이 커진다고 여긴다: 오히려 줄어든다(같은 절의 예제).
요약
  1. \(\mathrm{Var}(aX + bY) = a^2\sigma_X^2 + b^2\sigma_Y^2 + 2ab\,\mathrm{Cov}(X, Y)\).
  2. 코시-슈바르츠: \(E[(X - tY)^2] \ge 0\)의 판별식. \(|\rho| \le 1\).
  3. \(|\rho| = 1\) ⇔ 직선 관계. 상관 0은 독립을 뜻하지 않는다.

3.3.4연습문제

기본

  1. \(\sigma_X = 2\), \(\sigma_Y = 3\), \(\rho = 0.5\)일 때 \(\mathrm{Var}(X - Y)\)는?
    답

    \(\mathrm{Cov} = 3\). \(4 + 9 - 2\cdot3 = 7\).

응용

  1. \(\rho(aX + b, cY + d)\)를 \(\rho(X, Y)\)로 나타내어라 (\(a, c \ne 0\)).
    답

    공분산은 \(ac\)배, 표준편차의 곱은 \(|ac|\)배이므로 \(\mathrm{sign}(ac)\,\rho(X, Y)\). 단위 변환에 무관하다.

심화

  1. \(X_1, \dots, X_n\)의 분산이 모두 1이고 서로 상관계수가 모두 \(\rho\)이다. \(\mathrm{Var}(X_1 + \dots + X_n) \ge 0\)을 써서 \(\rho \ge -\frac1{n - 1}\)임을 보여라.
    답

    \(\mathrm{Var} = n + n(n - 1)\rho \ge 0\). 변수가 많으면 모두 서로 강하게 음의 상관일 수는 없다.
