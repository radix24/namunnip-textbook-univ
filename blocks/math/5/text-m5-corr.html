상관계수와 코시-슈바르츠 부등식

본문

키와 몸무게의 공분산은 키를 cm로 재느냐 m로 재느냐에 따라 100배나 달라진다. 두 양이 얼마나 함께 움직이는지 단위와 무관하게 재려면 어떻게 해야 할까? 그리고 그 값이 0이면 두 양은 아무 관계가 없는 것일까?

먼저 알아야 할 것기대값, 분산, 공분산(3.1절)과 이차식의 판별식을 쓴다.

3.3.1합의 분산

선형성을 \((aX + bY - a\mu_X - b\mu_Y)^2\)에 쓰면 다음을 얻는다.

\[\mathrm{Var}(aX + bY) = a^2\mathrm{Var}(X) + b^2\mathrm{Var}(Y) + 2ab\,\mathrm{Cov}(X, Y).\]

그런데 공분산은 처음 질문처럼 단위에 따라 크기가 바뀌므로, 단위와 무관한 지표로 표준화한다.

정의 3.3.1

\(\sigma_X, \sigma_Y > 0\)일 때 \(\rho(X, Y) = \dfrac{\mathrm{Cov}(X, Y)}{\sigma_X\sigma_Y}\)를 상관계수라 한다.

3.3.2코시-슈바르츠 부등식

정리 3.3.2 (코시-슈바르츠)

\(E[X^2], E[Y^2] < \infty\)이면 \((E[XY])^2 \le E[X^2]\,E[Y^2]\)이다. 등호는 어떤 상수 \(t\)에 대해 확률 1로 \(X = tY\)이거나 \(Y = 0\)일 때 성립한다.

여기서 증명의 방향은 0 이상인 양 \(E[(X - tY)^2]\)를 \(t\)의 이차식으로 보고, 늘 0 이상이니 판별식이 0 이하임을 쓰는 것이다.

증명.\(E[Y^2] = 0\)이면 확률 1로 \(Y = 0\)이라 양변이 0이다. 아니면 모든 실수 \(t\)에 대해 \(0 \le E[(X - tY)^2] = E[Y^2]t^2 - 2E[XY]t + E[X^2]\)이다. 최고차 계수가 양수인 이차식이 늘 0 이상이므로 판별식 \(\frac D4 = (E[XY])^2 - E[X^2]E[Y^2] \le 0\)이다. 등호이면 중근 \(t_0\)에서 \(E[(X - t_0Y)^2] = 0\)이라 확률 1로 \(X = t_0Y\)이다. ∎

따름정리 3.3.3

\(-1 \le \rho(X, Y) \le 1\)이고, \(|\rho| = 1\)일 필요충분조건은 확률 1로 \(Y = aX + b\) (\(a \ne 0\))인 것이다. \(\rho = 1\)이면 \(a > 0\), \(\rho = -1\)이면 \(a < 0\)이다.

그러면 정리 3.3.2를 \(X - \mu_X\)와 \(Y - \mu_Y\)에 쓰면 \(\mathrm{Cov}(X, Y)^2 \le \sigma_X^2\sigma_Y^2\)이 바로 나온다. 또 단위를 바꾸면 공분산과 표준편차의 곱이 같은 비율로 바뀌므로, \(\rho\)는 단위와 무관하다.

3.3.3상관 0과 독립

예제 3.3.4

\(X \sim U(-1, 1)\), \(Y = X^2\)이면 \(\mathrm{Cov}(X, Y) = 0\)이지만 \(X, Y\)가 독립이 아님을 보여라.

풀이. \(\mathrm{Cov}(X, Y) = E[X^3] - E[X]E[X^2] = 0 - 0 = 0\)이다. 하지만 \(Y\)는 \(X\)로 완전히 정해지므로 독립이 아니다. 그림 1의 세 번째 산점도가 이 상황이다.

즉 상관계수는 직선 관계의 강도만 잰다. 그래서 산점도를 함께 보는 것이 안전하다. 독립이면 상관이 0이지만 역은 성립하지 않으며, 결합 정규분포는 예외이다(4.1절).

흔한 오해\(\rho = 0\)이면 관계가 없다고 여기기 쉽지만, 예제 3.3.4처럼 곡선 관계는 잡지 못한다. 또 \(\rho\)가 클수록 기울기가 크다고 여기는 실수가 있는데, \(\rho\)는 점들이 직선에 얼마나 몰려 있는지이고 기울기는 \(\rho\sigma_Y/\sigma_X\)이다. 음의 공분산이면 합의 분산이 커진다고 여기는 것도 틀렸으며, 오히려 줄어든다.
마무리

처음 질문에 답하면, 공분산을 두 표준편차의 곱으로 나눈 상관계수 \(\rho\)가 단위와 무관하게 함께 움직이는 정도를 잰다. 코시-슈바르츠 부등식, 곧 \(E[(X - tY)^2] \ge 0\)의 판별식에서 \(|\rho| \le 1\)이고, \(|\rho| = 1\)은 정확히 직선 관계일 때이다. 그러나 상관계수가 0이어도 \(y = x^2\) 같은 곡선 관계가 있을 수 있으므로, 상관 0은 독립을 뜻하지 않는다. 합의 분산에는 \(2ab\,\mathrm{Cov}(X, Y)\)가 더해진다.

3.3.4연습문제

기본

  1. \(\sigma_X = 2\), \(\sigma_Y = 3\), \(\rho = 0.5\)일 때 \(\mathrm{Var}(X - Y)\)는?
    답

    \(\mathrm{Cov} = 3\). \(4 + 9 - 2\cdot3 = 7\).

응용

  1. \(\rho(aX + b, cY + d)\)를 \(\rho(X, Y)\)로 나타내어라 (\(a, c \ne 0\)).
    답

    공분산은 \(ac\)배, 표준편차의 곱은 \(|ac|\)배이므로 \(\mathrm{sign}(ac)\,\rho(X, Y)\). 단위 변환에 무관하다.

심화

  1. \(X_1, \dots, X_n\)의 분산이 모두 1이고 서로 상관계수가 모두 \(\rho\)이다. \(\mathrm{Var}(X_1 + \dots + X_n) \ge 0\)을 써서 \(\rho \ge -\frac1{n - 1}\)임을 보여라.
    답

    \(\mathrm{Var} = n + n(n - 1)\rho \ge 0\). 변수가 많으면 모두 서로 강하게 음의 상관일 수는 없다.
