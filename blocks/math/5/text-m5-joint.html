결합분포, 주변분포, 조건부분포

본문

아버지의 키가 평균보다 1.5 표준편차 크다면, 아들의 키는 평균보다 얼마나 클 것으로 기대할까? 두 양이 함께 움직이는 모습을 다루려면 각각의 분포만으로는 부족하다. 두 확률변수를 함께 묘사하고, 하나를 알 때 다른 하나의 분포를 구하려면 무엇이 필요할까?

먼저 알아야 할 것분포함수와 밀도(2.1절), 공분산(3.1절), 이중적분을 쓴다.

4.1.1결합분포

키와 몸무게, 두 주가의 수익률처럼 함께 움직이는 양을 다루려면 두 값이 함께 어떤 범위에 들어갈 확률이 필요하다.

정의 4.1.1

이산이면 \(p(x, y) = P(X = x, Y = y)\)를 결합질량함수라 한다. 평면의 적당한 영역 \(A\)에 대해 \(P((X, Y) \in A) = \iint_Af(x, y)\,dx\,dy\)인 \(f \ge 0\)을 결합밀도함수라 한다. \(f_X(x) = \int f(x, y)\,dy\)와 \(f_Y(y) = \int f(x, y)\,dx\)를 주변밀도라 한다.

주변밀도는 \(Y\)가 무엇이든 상관없이 본 \(X\)만의 분포이며, 결합밀도의 한 줄을 따라 \(y\)로 모두 더하면 된다. 결합분포는 주변분포를 정하지만, 주변분포는 결합분포를 정하지 못한다. 주변분포가 같은 표준정규라도 두 변수의 상관은 얼마든지 다를 수 있기 때문이다.

예제 4.1.2

\(f(x, y) = x + y\) (\(0 < x, y < 1\))에 대해 (1) 밀도임을 확인하고 \(f_X\)를 구하여라. (2) \(P(X + Y \le 1)\)을 구하여라. (3) \(\mathrm{Cov}(X, Y)\)를 구하여라.

풀이. (1) \(\int_0^1(x + y)\,dy = x + \frac12\)이고 \(\int_0^1(x + \frac12)dx = 1\)이므로 밀도이며 \(f_X(x) = x + \frac12\)이다. (2) 영역은 \(0 < y < 1 - x\)이므로 \(\int_0^1\int_0^{1-x}(x + y)\,dy\,dx = \int_0^1\left[x(1-x) + \frac{(1-x)^2}2\right]dx = \frac16 + \frac16 = \frac13\)이다. (3) \(E[X] = \int_0^1x(x + \frac12)dx = \frac7{12}\)이고 대칭으로 \(E[Y]\)도 같으며, \(E[XY] = \iint xy(x + y) = \frac13\)이다. 따라서 \(\mathrm{Cov} = \frac13 - \frac{49}{144} = -\frac1{144}\)로 약한 음의 상관이다.

4.1.2조건부분포

\(X = x\)를 알 때 \(Y\)의 분포는 그림 1처럼 결합밀도를 \(x\)에서 자른 단면을 넓이가 1이 되도록 나눈 것이다. 연속인 경우 \(P(X = x) = 0\)이라 1.3절의 정의를 그대로 쓸 수 없지만, 밀도의 비로 정의하면 같은 직관이 성립한다.

정의 4.1.3

\(f_X(x) > 0\)일 때 \(f_{Y\mid X}(y\mid x) = \dfrac{f(x, y)}{f_X(x)}\)를 조건부밀도라 한다. 모든 \(x, y\)에서 \(f(x, y) = f_X(x)f_Y(y)\)이면 (이산이면 \(p\)로) \(X, Y\)가 독립이라 하며, 같은 말로 \(f_{Y\mid X}(y\mid x) = f_Y(y)\)이다.

예제 4.1.4

\((X, Y)\)가 삼각형 \(0 < y < x < 1\)에서 균등하다(\(f = 2\)). 주변밀도와 \(X = x\)일 때 \(Y\)의 조건부분포를 구하고, 독립인지 판정하여라.

풀이. \(f_X(x) = \int_0^x2\,dy = 2x\)이고 \(f_Y(y) = \int_y^12\,dx = 2(1 - y)\)이다. 조건부밀도는 \(0 < y < x\)에서 \(f(y\mid x) = 2/(2x) = 1/x\), 곧 \(U(0, x)\)이고 \(E[Y\mid X = x] = x/2\)이다. 그리고 \(f_Xf_Y = 4x(1 - y) \ne 2\)이므로 독립이 아니다. 더 간단히 판정하는 방법도 있다. 결합밀도가 양수인 영역이 직사각형이 아니면 \(x\)를 알 때 \(y\)의 범위가 바뀌므로 독립일 수 없다.

4.1.3이변량 정규분포

정의 4.1.5

상관계수 \(\rho\) (\(|\rho| < 1\))인 표준 이변량 정규분포의 밀도는 \(f(x, y) = \dfrac1{2\pi\sqrt{1-\rho^2}}\exp\left(-\dfrac{x^2 - 2\rho xy + y^2}{2(1-\rho^2)}\right)\)이다.

지수의 \(y\)에 대한 부분을 완전제곱하면 \(x^2 - 2\rho xy + y^2 = (y - \rho x)^2 + (1 - \rho^2)x^2\)이다. 그래서 \(f(x, y) = \varphi(x)\cdot\frac1{\sqrt{1-\rho^2}}\varphi\left(\frac{y - \rho x}{\sqrt{1-\rho^2}}\right)\)로 갈라지고, 여기서 세 가지를 바로 읽을 수 있다. 첫째, 주변분포는 \(X \sim N(0, 1)\)이고 대칭으로 \(Y\)도 같다. 둘째, 조건부분포는 \(Y \mid X = x \sim N(\rho x, 1 - \rho^2)\)이다. 즉 조건부 평균은 \(x\)의 직선, 곧 회귀 직선이고, 조건부 분산은 \(x\)와 무관하게 \(1 - \rho^2\)로 줄어든다. 셋째, \(\rho = 0\)이면 \(f = \varphi(x)\varphi(y)\)라 독립이다. 그러므로 정규분포 쌍에서는 "상관 0이면 독립"이며, 일반적으로는 거짓이다(3.3절).

예를 들어 \(\rho = 0.6\), \(x = 1.5\)이면 \(Y\)의 조건부 평균은 0.9, 조건부 표준편차는 0.8이다. 처음 질문에 대입하면 키가 평균보다 1.5 표준편차 큰 아버지의 아들은 평균보다 0.9 표준편차만 크며, 이것이 골턴이 발견한 "평균으로의 회귀"이다.

흔한 오해주변밀도를 구할 때 적분 범위를 상수로 두기 쉽지만, 예제 4.1.4처럼 범위가 다른 변수에 따라 바뀐다. 또 조건부밀도에서 \(f_X(x)\)로 나누는 것을 잊으면 단면의 넓이가 1이 되지 않는다. 결합밀도가 \(g(x)h(y)\) 꼴이면 영역과 상관없이 독립이라 여기는 것도 틀렸으며, 영역도 직사각형이어야 한다.
마무리

처음 질문에 답하면, 상관계수가 0.6일 때 아들의 키는 평균보다 약 0.9 표준편차 클 것으로 기대한다. 이것은 이변량 정규분포의 조건부분포 \(Y\mid X = x \sim N(\rho x, 1 - \rho^2)\)에서 나온다. 두 확률변수를 함께 다루려면 결합밀도가 필요하며, 영역의 확률은 결합밀도의 적분, 주변밀도는 다른 변수로의 적분, 조건부밀도는 결합밀도를 주변밀도로 나눈 것이다. 독립은 결합밀도가 주변밀도의 곱인 것이다.

4.1.4연습문제

기본

  1. \(f(x, y) = 4xy\) (\(0 < x, y < 1\))에서 \(X\), \(Y\)는 독립인가?
    답

    \(f_X = 2x\), \(f_Y = 2y\), 곱이 \(4xy\)이고 영역이 정사각형이므로 독립.

응용

  1. 예제 4.1.2에서 \(E[Y\mid X = x]\)를 구하고 \(x = 0\), \(x = 1\)에서의 값을 비교하여라.
    답

    \(\int_0^1y\frac{x + y}{x + 1/2}dy = \frac{x/2 + 1/3}{x + 1/2}\). \(x = 0\)에서 \(2/3\), \(x = 1\)에서 \(5/9\). \(x\)가 커질수록 줄어드는 것이 음의 공분산과 맞다.

심화

  1. 표준 이변량 정규에서 \(\mathrm{Cov}(X, Y) = \rho\)임을 조건부분포로 보여라.
    답

    \(E[XY] = \int x\,E[Y\mid X = x]\varphi(x)\,dx = \int\rho x^2\varphi(x)\,dx = \rho\). 평균이 0이므로 공분산도 \(\rho\). (반복 기대값, 7.1절)
