중심극한정리와 그 증명

본문

대수의 법칙은 표본평균이 평균으로 다가간다고 말한다. 그러면 남은 차이 \(\bar X_n - \mu\)는 얼마나 빨리, 어떤 모양으로 작아질까? 원래 분포가 동전이든, 대기 시간이든, 주사위든 그 모양이 같다면 이상한 일이 아닐까?

먼저 알아야 할 것적률생성함수(3.2절), 대수의 법칙과 분포수렴(6.1절), 테일러 전개를 쓴다.

6.2.1정리의 내용

표본평균의 분산이 \(\sigma^2/n\)이므로 차이의 크기는 \(\sigma/\sqrt n\) 정도이다. 이 비율로 확대해 보면 모양이 늘 정규분포라는 것이 중심극한정리이다.

정리 6.2.1 (중심극한정리)

\(X_i\)가 독립이고 같은 분포이며 평균 \(\mu\), 분산 \(0 < \sigma^2 < \infty\)이면 다음이 성립한다. 곧 모든 \(z\)에서 \(P(Z_n \le z) \to \Phi(z)\)이다.

\[Z_n = \frac{X_1 + \cdots + X_n - n\mu}{\sigma\sqrt n} = \frac{\bar X_n - \mu}{\sigma/\sqrt n} \xrightarrow{d} N(0, 1)\]

놀라운 점은 처음 질문처럼 원래 분포가 균등이든, 지수든, 동전이든 극한이 똑같다는 것이다. 원래 분포의 정보 가운데 평균과 분산만 남고, 비대칭이나 꼬리 모양 같은 나머지는 \(n\)이 커지면 사라진다. 그림 1이 지수분포에서 이 과정을 보여 준다.

6.2.2적률생성함수를 이용한 증명

여기서는 \(X_i\)의 적률생성함수가 0 근처에서 존재한다고 가정한다. 일반적인 경우는 10단원의 특성함수 \(E[e^{itX}]\)로 같은 논법을 쓴다. 쓰는 도구는 다음 정리이다.

정리 6.2.2 (연속성 정리)

0 근처의 모든 \(t\)에서 \(M_{Z_n}(t) \to M_Z(t)\)이면 \(Z_n \xrightarrow{d} Z\)이다.

증명.먼저 표준화하여 \(Y_i = (X_i - \mu)/\sigma\)로 두면 \(E[Y_i] = 0\), \(E[Y_i^2] = 1\)이고 \(Z_n = \frac1{\sqrt n}\sum Y_i\)이다. 독립이고 같은 분포이므로 \(M_{Z_n}(t) = E\left[e^{(t/\sqrt n)\sum Y_i}\right] = \left[M_Y(t/\sqrt n)\right]^n\)이다. 다음으로 테일러 전개를 쓰면 \(s \to 0\)에서 \(M_Y(s) = 1 + E[Y]s + \frac{E[Y^2]}2s^2 + o(s^2) = 1 + \frac{s^2}2 + o(s^2)\)이고, \(s = t/\sqrt n\)을 넣으면 \(M_Y(t/\sqrt n) = 1 + \frac{t^2}{2n} + o(1/n)\)이다. 그러면 \(M_{Z_n}(t) = \left[1 + \frac{t^2/2 + n\cdot o(1/n)}{n}\right]^n\)이고 \(n\cdot o(1/n) \to 0\)이므로, \(a_n \to a\)일 때 \((1 + a_n/n)^n \to e^a\)인 사실에서 극한은 \(e^{t^2/2}\)이다. 이것은 \(N(0, 1)\)의 적률생성함수이므로 연속성 정리로 \(Z_n \xrightarrow{d} N(0,1)\)이다. ∎

가정이 쓰인 곳을 짚어 보자. 독립과 같은 분포는 \(n\)제곱에, 평균 0은 1차항을 없애는 데, 분산 1은 2차항의 계수 \(1/2\)를 정하는 데 쓰였다. 그리고 비대칭 같은 3차 이상의 항은 \(1/n\)보다 빨리 작아져 극한에 남지 않는다. 이것이 평균과 분산만 남는 이유이다.

예제 6.2.3

\(Y\)가 \(\pm1\)을 1/2씩 갖는 경우 \(\ln M_{Z_n}(1)\)이 \(1/2\)로 다가가는 모습을 계산하여라.

풀이. \(M_Y(s) = \cosh s\)이므로 \(\ln M_{Z_n}(1) = n\ln\cosh(1/\sqrt n)\)이다. \(n = 1, 4, 16, 100\)에서 0.4338, 0.4805, 0.4949, 0.4992로 \(1/2\)에 다가간다. 한편 평균 1인 지수분포에서 1을 뺀 \(Y\)는 \(n = 4, 16, 100\)에서 0.7726, 0.6029, 0.5361로 더 천천히 다가가며(\(n = 1\)이면 무한대), 비대칭을 나타내는 3차항이 더 크기 때문이다.

흔한 오해"\(X_i\)가 정규분포에 가까워진다"로 읽기 쉽지만, 정규에 가까워지는 것은 표준화한 합이나 평균이지 개별 값이 아니다. 또 분포수렴을 확률수렴으로 착각하는 실수가 있는데, \(Z_n\) 자체는 어떤 값으로도 수렴하지 않는다. 분산이 무한한 분포에 쓰는 것도 틀렸다. 코시분포 같은 경우 극한이 정규가 아니다.
마무리

처음 질문에 답하면, 차이 \(\bar X_n - \mu\)는 \(\sigma/\sqrt n\)의 빠르기로 작아지며, 그 비율로 확대한 \((\bar X_n - \mu)/(\sigma/\sqrt n)\)은 원래 분포와 상관없이 \(N(0,1)\)로 분포수렴한다. 이상하지 않은 이유는 증명에 있다. 표준화한 합의 적률생성함수 \([M_Y(t/\sqrt n)]^n\)을 2차까지 테일러 전개하면 평균과 분산만 남고, 3차 이상은 극한에서 사라져 \(e^{t^2/2}\)이 된다.

6.2.3연습문제

기본

  1. \(Z_n\)의 평균과 분산이 정확히 0과 1임을 보여라.
    답

    \(E[Z_n] = \frac{1}{\sqrt n}\sum E[Y_i] = 0\), \(\mathrm{Var}(Z_n) = \frac1n\sum\mathrm{Var}(Y_i) = 1\) (독립).

응용

  1. \(\mathrm{Pois}(n)\)을 표준화한 \((X - n)/\sqrt n\)이 \(N(0,1)\)로 분포수렴함을 적률생성함수로 직접 보여라.
    답

    \(\ln M(t) = -t\sqrt n + n(e^{t/\sqrt n} - 1) = -t\sqrt n + n\left(\frac t{\sqrt n} + \frac{t^2}{2n} + O(n^{-3/2})\right) \to t^2/2\).

심화

  1. 증명의 3단계에서 \(E[Y^3] = \gamma\)까지 쓰면 \(\ln M_{Z_n}(t) = \frac{t^2}2 + \frac{\gamma t^3}{6\sqrt n} + O(1/n)\)임을 보이고, 예제 6.2.3의 지수분포 수치(\(\gamma = 2\))와 비교하여라.
    답

    \(\ln M_Y(s) = \frac{s^2}2 + \frac{\gamma s^3}6 + O(s^4)\) (누적량 전개), \(n\)배 하고 \(s = t/\sqrt n\). \(t = 1\), \(n = 100\): \(0.5 + 2/60 \approx 0.533\), 실제 0.5361.
