확률변수와 분포함수

본문
이 절에서 배울 것
  • 확률변수와 분포함수 \(F(x) = P(X \le x)\)를 정의한다.
  • 분포함수의 세 성질(증가, 양 끝 극한, 오른쪽 연속)을 확률의 연속성으로 증명한다.
  • 분포함수에서 구간 확률과 한 점의 확률을 읽고, 이산·연속·혼합 분포를 구별한다.
먼저 알아야 할 것
  • 확률의 연속성 (1.2절), 함수의 극한과 연속 (수학7 3단원).

2.1.1확률변수

주사위 두 개를 던진 결과 \((3, 5)\)보다 "눈의 합 8"에 관심이 있는 경우가 많습니다. 결과마다 수를 하나 대응시키는 함수가 확률변수입니다. 이름과 달리 "변수"가 아니라 함수입니다.

정의 2.1.1

확률변수: 함수 \(X: \Omega \to \mathbb R\)로서 모든 실수 \(x\)에 대해 \(\{X \le x\} = \{\omega : X(\omega) \le x\}\)가 사건인 것.

분포함수(누적분포함수): \(F_X(x) = P(X \le x)\), \(x \in \mathbb R\).

"\(\{X \le x\}\)가 사건"이라는 조건은 이 집합에 확률을 매길 수 있게 하려는 것입니다. 이 조건만 있으면 구간, 한 점, 그 여집합과 가산 합집합 모두에 확률을 매길 수 있고, 그 값이 모두 \(F\)로 정해집니다. 곧 분포함수 하나가 확률변수의 분포 전체를 담고 있습니다.

2.1.2분포함수의 성질

정리 2.1.2

(a) \(x < y\)이면 \(F(x) \le F(y)\). (b) \(\lim_{x\to-\infty}F(x) = 0\), \(\lim_{x\to\infty}F(x) = 1\). (c) \(F\)는 오른쪽 연속: \(\lim_{h\to0^+}F(x + h) = F(x)\).

(a) \(\{X \le x\} \subseteq \{X \le y\}\)이므로 단조성. (b) \(F\)가 증가하므로 정수열 \(x = \pm n\)을 따라 극한을 보면 충분하다. \(\{X \le n\}\)은 증가하고 합집합이 \(\Omega\), \(\{X \le -n\}\)은 감소하고 교집합이 \(\varnothing\)이다. 연속성 정리로 극한은 각각 1, 0. (c) 마찬가지로 \(h = 1/n\)을 따라 보면 충분하다. \(\{X \le x + 1/n\}\)은 감소하고 교집합이 \(\{X \le x\}\)이므로 \(F(x + 1/n) \to F(x)\). ∎

(b)와 (c)에서 "수열을 따라 보면 충분하다"는 이유는 \(F\)가 증가함수이기 때문입니다. 증가함수의 한쪽 극한은 항상 존재하므로, 그 값을 특별한 수열 하나로 계산해도 됩니다. 역으로 (a)–(c)를 만족하는 함수는 모두 어떤 확률변수의 분포함수가 됩니다.

따름정리 2.1.3

\(P(a < X \le b) = F(b) - F(a)\), \(P(X < x) = F(x^-) = \lim_{h\to0^+}F(x - h)\), \(P(X = x) = F(x) - F(x^-)\).

첫째는 \(\{X \le b\} = \{X \le a\} \cup \{a < X \le b\}\)에서, 둘째는 증가하는 \(\{X \le x - 1/n\}\)의 합집합이 \(\{X < x\}\)인 데서 나옵니다(1.2절 예제 1.2.4). 곧 분포함수가 점프하는 곳에만 확률이 몰려 있고, 점프의 높이가 그 점의 확률입니다.

2.1.3이산, 연속, 혼합

정의 2.1.4

이산 확률변수: 값이 가산 집합 \(\{x_i\}\)에 있고 \(F\)는 계단 함수. 확률질량함수 \(p(x_i) = P(X = x_i)\).

연속 확률변수: \(F(x) = \int_{-\infty}^xf(t)\,dt\)인 \(f \ge 0\)(확률밀도함수)가 있는 것. \(F\)는 연속이고 모든 점의 확률이 0.

예제 2.1.5 (혼합 분포)

은행 창구 대기 시간 \(X\)(분)가 확률 0.3으로 0이고, 나머지 경우 평균 1분인 지수분포를 따른다. 곧 \(x \ge 0\)에서 \(F(x) = 0.3 + 0.7(1 - e^{-x})\), \(x < 0\)에서 \(F(x) = 0\). \(P(X = 0)\), \(P(X \le 1)\), \(P(1 < X \le 2)\)를 구하여라.

풀이. \(x = 0\)에서 \(F\)가 0에서 0.3으로 뛰므로 \(P(X = 0) = 0.3\). \(P(X \le 1) = F(1) = 0.3 + 0.7(1 - e^{-1}) \approx 0.7425\). \(P(1 < X \le 2) = F(2) - F(1) = 0.7(e^{-1} - e^{-2}) \approx 0.1628\). 이 \(X\)는 이산도 연속도 아닙니다. 확률밀도함수만으로는 0에 몰린 0.3을 나타낼 수 없지만 분포함수는 어떤 경우든 분포를 나타낸다는 것이 분포함수의 장점입니다. 같은 절의 탐구 카드에서 구간을 바꾸며 \(F(b) - F(a)\)를 읽어 볼 수 있습니다.

흔한 실수(1) 이산 분포에서 \(P(X < x)\)와 \(P(X \le x)\)를 같게 쓴다: 점프가 있는 점에서 다르다. (2) 확률밀도함수 값을 확률로 읽는다: \(f(x)\)는 1보다 클 수 있고 확률은 넓이이다. (3) 분포함수를 왼쪽 연속으로 그린다: \(F(x) = P(X \le x)\)이므로 점프한 점에서 값은 위쪽이다(채운 점이 위).
요약
  1. 확률변수는 \(\Omega\)에서 \(\mathbb R\)로 가는 함수, 분포함수 \(F(x) = P(X \le x)\)가 분포를 완전히 정한다.
  2. \(F\)는 증가, \(-\infty\)에서 0, \(\infty\)에서 1, 오른쪽 연속. 모두 확률의 연속성에서 나온다.
  3. 구간 확률은 \(F(b) - F(a)\), 한 점의 확률은 점프의 높이.

2.1.4연습문제

기본

  1. 공정한 주사위의 눈 \(X\)에 대해 \(F(3.5)\), \(F(3) - F(3^-)\)를 구하여라.
    답

    \(F(3.5) = 3/6 = 0.5\), 점프 높이 \(1/6\).

응용

  1. \(F(x) = 1 - e^{-2x}\) (\(x \ge 0\))일 때 \(P(X > 1)\)과 확률밀도함수를 구하여라.
    답

    \(P(X > 1) = e^{-2} \approx 0.1353\), \(f(x) = 2e^{-2x}\) (\(x > 0\)).

심화

  1. 분포함수의 불연속점은 많아야 가산 개임을 보여라.
    답

    점프 높이가 \(1/k\)보다 큰 점은 \(k\)개 미만이다(높이의 합이 1 이하). 불연속점 전체는 \(k = 1, 2, \dots\)에 대한 이 유한 집합들의 합집합이므로 가산.
