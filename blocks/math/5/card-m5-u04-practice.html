결합분포 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(f(x, y) = 6x\) (\(0 < x < y < 1\))의 주변밀도 \(f_X\), \(f_Y\)를 구하여라. [04-01]

    힌트 1

    \(x\)를 고정하면 \(y\)는 \(x\)부터 1까지(4.1절).

    힌트 2

    \(y\)를 고정하면 \(x\)는 0부터 \(y\)까지.

    풀이

    \(f_X(x) = \int_x^16x\,dy = 6x(1 - x)\), \(f_Y(y) = \int_0^y6x\,dx = 3y^2\). 둘 다 적분하면 1.

  2. 계산문제 1에서 \(Y = y\)일 때 \(X\)의 조건부밀도와 조건부 평균을 구하여라. [04-01]

    힌트 1

    \(f(x\mid y) = f(x, y)/f_Y(y)\).

    힌트 2

    \(6x/(3y^2) = 2x/y^2\).

    풀이

    \(f(x\mid y) = 2x/y^2\) (\(0 < x < y\)). \(E[X\mid Y = y] = \int_0^y x\cdot\frac{2x}{y^2}dx = \frac{2y}3\).

  3. 개념문제 1의 결합밀도는 \(6x = g(x)h(y)\) 꼴인데 \(X\), \(Y\)가 독립인가? [04-01]

    힌트 1

    밀도가 양수인 영역의 모양.

    힌트 2

    \(f_Xf_Y = 18x(1-x)y^2\).

    풀이

    독립이 아니다. 영역이 삼각형이라 \(X\)를 알면 \(Y\)의 범위가 바뀐다. 실제로 \(f_Xf_Y \ne 6x\).

  4. 계산독립인 \(X \sim U(0, 1)\), \(Y \sim \mathrm{Exp}(1)\)에 대해 \(S = X + Y\)의 밀도를 구하여라. [04-02]

    힌트 1

    \(f_S(s) = \int_0^1e^{-(s - x)}1_{\{s - x > 0\}}dx\)(4.2절).

    힌트 2

    \(s < 1\)과 \(s \ge 1\)로 나눠라.

    풀이

    \(0 < s < 1\): \(\int_0^se^{-(s-x)}dx = 1 - e^{-s}\). \(s \ge 1\): \(\int_0^1e^{-(s-x)}dx = e^{-s}(e - 1)\). 두 식은 \(s = 1\)에서 \(1 - e^{-1}\)로 이어진다.

  5. 증명독립인 \(X \sim N(0, 1)\), \(Y \sim N(0, 1)\)의 합의 밀도가 \(N(0, 2)\)임을 합성곱으로 보여라. [04-02]

    힌트 1

    지수 \(-\frac{x^2 + (s - x)^2}2\)를 \(x\)에 대해 완전제곱.

    힌트 2

    \(x^2 + (s - x)^2 = 2(x - s/2)^2 + s^2/2\).

    풀이

    \(f_S(s) = \frac1{2\pi}e^{-s^2/4}\int e^{-(x - s/2)^2}dx = \frac1{2\pi}e^{-s^2/4}\sqrt\pi = \frac1{\sqrt{4\pi}}e^{-s^2/4}\): \(N(0, 2)\)의 밀도. ∎

  6. 판단한 학생이 "\(X\)와 \(Y\)가 각각 정규분포를 따르면 \(X + Y\)도 정규분포다"라고 썼다. 맞는가? [04-02]

    힌트 1

    독립이나 결합 정규 조건이 있나요?

    힌트 2

    \(Y = -X\)이면?

    풀이

    일반적으로 틀렸다. \(Y = -X\)이면 \(X + Y = 0\)으로 정규가 아니다(분산 0인 퇴화 분포). 더 교묘한 예로, \(Z \sim N(0,1)\)과 독립인 부호 \(\varepsilon = \pm1\)로 \(Y = \varepsilon Z\)를 두면 \(Y\)도 표준정규지만 \(Z + Y\)는 확률 1/2로 0이다. 결합 정규(또는 독립)일 때만 합이 정규다.
