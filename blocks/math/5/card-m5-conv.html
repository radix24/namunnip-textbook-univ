더할수록 종 모양이 된다

탐구 · 합성곱과 정규 근사

질문

균등분포, 지수분포, 주사위처럼 모양이 전혀 다른 분포라도 독립으로 여러 개 더하면 비슷한 모양이 될까? 몇 개쯤 더해야 정규분포로 근사해도 될까?

복원

독립 합의 분포는 합성곱 \(f_S(s) = \int f_X(x)f_Y(s - x)dx\). \(n\)개의 합은 평균 \(n\mu\), 분산 \(n\sigma^2\) (4.2절).

해 보기

  1. 균등 2개: 삼각형 밀도이다. \(P(S \le 1.5) = 0.875\), 정규 근사는 0.8897로 아직 차이가 있다.
  2. \(n = 3\), \(s = 1\)로 두면 정확한 값 0.1667, 정규 근사 0.1587이다. \(n = 12\), \(s = 7\)이면 0.8393과 0.8413으로 거의 같다.
  3. 지수 2개, \(s = 1\): 0.2642와 약 0.240. 지수분포는 기울어져 있어 \(n\)을 12로 올려도 그림에서 꼭짓점이 정규보다 왼쪽에 있다.
  4. 주사위 2개, \(s = 7\): 정확한 값 \(21/36 = 0.5833\), 연속성 보정 정규 근사 0.5820.

설명

  1. 합성곱은 매끄럽게 만든다균등분포의 밀도는 계단, 둘을 합성곱하면 꺾인 선, 셋이면 이어진 2차식이다. 합성곱을 할 때마다 한 번 더 매끄러워진다.
  2. 비대칭은 천천히 사라진다표준화한 합의 왜도는 \(1/\sqrt n\)에 비례해 줄어든다. 지수분포(왜도 2)는 균등분포(왜도 0)보다 정규에 가까워지는 데 더 많은 개수가 필요하다.

판단

"\(n \ge 30\)이면 언제나 정규 근사가 좋다"는 규칙은 근거가 없다. 근사의 질은 원래 분포의 비대칭과 꼬리에 달려 있고, 꼬리 확률(아주 작은 확률)은 \(n\)이 커도 상대 오차가 클 수 있다. 분산이 없는 분포(코시)는 아무리 더해도 정규가 되지 않는다.
