전분산 공식

본문

한 학교 학생들의 키가 흩어진 정도에는 두 가지 원인이 섞여 있다. 같은 집단 안에서도 키가 다르고, 집단마다 평균 키도 다르다. 전체의 분산을 이 두 원인으로 정확히 나눌 수 있을까? 나눈다면 각 원인은 얼마씩 기여할까?

먼저 알아야 할 것조건부 기대값과 반복 기대값 법칙(7.1절), 분산(3.1절)을 쓴다.

7.2.1분산을 두 부분으로 나누기

처음 질문의 직관을 정확한 등식으로 만든 것이 전분산 공식이다. 먼저 조건부 분산을 정의하자.

정의 7.2.1

\(\mathrm{Var}(Y\mid X) = E\big[(Y - E[Y\mid X])^2\mid X\big] = E[Y^2\mid X] - (E[Y\mid X])^2\)을 조건부 분산이라 하며, \(X\)의 함수인 확률변수이다.

정리 7.2.2 (전분산 공식)

\(E[Y^2] < \infty\)이면 \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)] + \mathrm{Var}(E[Y\mid X])\)이다.

증명의 방향은 두 항을 각각 \(E[Y^2\mid X]\)와 \(E[Y\mid X]\)로 쓰고, 반복 기대값 법칙으로 바깥 기대값을 계산해 중간 항을 상쇄하는 것이다.

증명.\(m(X) = E[Y\mid X]\)라 두자. 첫째 항은 \(E[\mathrm{Var}(Y\mid X)] = E\big[E[Y^2\mid X]\big] - E[m(X)^2] = E[Y^2] - E[m(X)^2]\)이다. 둘째 항은 \(\mathrm{Var}(m(X)) = E[m(X)^2] - (E[m(X)])^2 = E[m(X)^2] - (E[Y])^2\)이다. 둘을 더하면 \(E[Y^2] - (E[Y])^2 = \mathrm{Var}(Y)\)이다. ∎

첫째 항은 \(X\)를 알아도 남는 불확실성의 평균, 곧 집단 안 분산이고, 둘째 항은 \(X\)에 따라 평균이 달라지는 정도, 곧 집단 사이 분산이다. 둘 다 0 이상이므로 \(\mathrm{Var}(E[Y\mid X]) \le \mathrm{Var}(Y)\)이며, 조건부 기대값으로 예측하면 퍼짐이 줄어든다는 결론도 나온다.

7.2.2적용

예제 7.2.3 (막대 쪼개기의 분산)

7.1절 예제 7.1.3에서 \(\mathrm{Var}(Y)\)를 구하여라.

풀이. \(Y\mid X \sim U(0, X)\)이므로 \(E[Y\mid X] = X/2\), \(\mathrm{Var}(Y\mid X) = X^2/12\)이다. \(E[X^2/12] = \frac1{36}\)이고 \(\mathrm{Var}(X/2) = \frac14\cdot\frac1{12} = \frac1{48}\)이므로, 합은 \(\frac1{36} + \frac1{48} = \frac7{144} \approx 0.0486\)이다. 직접 계산하면 \(E[Y^2] = E[X^2/3] = 1/9\)이므로 \(1/9 - 1/16\)으로 같다.

예제 7.2.4 (두 집단)

집단 A(비율 60%)의 키는 평균 160, 표준편차 6이고, 집단 B(40%)는 평균 175, 표준편차 6이다. 전체의 분산을 구하여라.

풀이. 집단을 \(X\)라 하면 집단 안 분산의 평균은 \(E[\mathrm{Var}(Y\mid X)] = 36\)이다. 집단 평균은 확률 0.6으로 160, 0.4로 175인 확률변수이므로 그 분산은 \(0.6\times0.4\times15^2 = 54\)이다. 따라서 전체 분산은 \(36 + 54 = 90\)이고 표준편차는 약 9.49이다. 그림 1처럼 전체 분산의 60%가 집단 차이로 설명되며, 이것이 통계학의 분산분석의 기본 생각이다.

예제 7.2.5 (무작위 합의 분산)

\(S = \sum_{i=1}^NX_i\)에서 \(X_i\)는 독립이고 \(N\)과도 독립이며, 평균 \(\mu\), 분산 \(\sigma^2\)이다. \(\mathrm{Var}(S)\)를 구하여라.

풀이. \(N\)으로 조건을 걸면 \(E[S\mid N] = N\mu\), \(\mathrm{Var}(S\mid N) = N\sigma^2\)이다. 전분산 공식으로 \(\mathrm{Var}(S) = E[N]\sigma^2 + \mu^2\mathrm{Var}(N)\)이다. 7.1절 예제 7.1.5에서 \(N \sim \mathrm{Pois}(50)\), \(\mu = 20\), \(\sigma = 10\)이면 \(50\cdot100 + 400\cdot50 = 25000\)이고 표준편차는 약 158이다. 즉 손님 수의 불확실성인 둘째 항이 금액의 불확실성인 첫째 항보다 4배 큰 기여를 한다.

흔한 오해\(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)]\)로 둘째 항을 빠뜨리기 쉬운데, 이것은 집단 평균의 차이를 무시한 것이다. 또 무작위 합의 분산을 \(E[N]\sigma^2\)로만 쓰는 실수가 있으며, 이것은 \(N\)이 고정일 때만 맞다. \(\mathrm{Var}(E[Y\mid X])\)를 \(E[\mathrm{Var}(Y)]\)와 혼동하지 않도록 한다.
마무리

처음 질문의 답은 "나눌 수 있다"이다. 전분산 공식 \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)] + \mathrm{Var}(E[Y\mid X])\)이 전체 분산을 집단 안 분산과 집단 사이 분산으로 나누며, 두 집단의 예에서는 36과 54씩 기여한다. 증명은 두 항을 \(E[Y^2\mid X]\)와 \(E[Y\mid X]\)로 펼쳐 반복 기대값 법칙을 쓰는 것이다. 무작위 합에서는 \(\mathrm{Var}(S) = E[N]\sigma^2 + \mu^2\mathrm{Var}(N)\)이다.

7.2.3연습문제

기본

  1. 예제 7.2.4에서 두 집단의 평균이 같다면 전체 분산은?
    답

    집단 사이 분산이 0이므로 36.

응용

  1. \(N \sim \mathrm{Pois}(\lambda)\)이고 각 손님이 독립으로 확률 \(p\)만큼 구매한다. 구매자 수 \(S\)의 평균과 분산을 전분산 공식으로 구하여라.
    답

    \(X_i\)(는 베르누이) \(\mu = p\), \(\sigma^2 = p(1-p)\). \(E[S] = \lambda p\), \(\mathrm{Var}(S) = \lambda p(1-p) + p^2\lambda = \lambda p\). 실제로 \(S \sim \mathrm{Pois}(\lambda p)\)(포아송 솎아내기).

심화

  1. \(\mathrm{Var}(E[Y\mid X]) = \mathrm{Var}(Y)\)인 것은 언제인가?
    답

    \(E[\mathrm{Var}(Y\mid X)] = 0\), 곧 확률 1로 \(\mathrm{Var}(Y\mid X) = 0\): \(Y\)가 \(X\)의 함수일 때(\(X\)를 알면 \(Y\)가 정해질 때).
