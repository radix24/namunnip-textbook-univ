확률의 공리와 포함배제 원리

본문
이 절에서 배울 것
  • 표본공간, 사건의 시그마 대수, 확률측도로 이루어진 확률공간을 정의한다.
  • 세 공리에서 여사건, 단조성, 합사건의 공식을 유도한다.
  • 포함배제 원리를 증명하고 "적어도 하나" 문제(모자 짝 맞추기)에 쓴다.
먼저 알아야 할 것
  • 고교 확률과 통계의 경우의 수와 확률, 집합의 연산 (수학2 2단원), 조합 (수학3 3.1절).

1.1.1왜 공리가 필요한가

고교에서는 "확률 = 해당 경우의 수 ÷ 전체 경우의 수"로 배웠습니다. 이 정의는 모든 결과가 똑같이 일어날 때만 쓸 수 있습니다. 찌그러진 동전, 내일 비가 올 확률, \([0, 1]\)에서 고른 실수가 \(1/3\)보다 작을 확률은 셀 수 있는 경우의 수로 설명되지 않습니다. 그래서 현대 확률론은 "확률이 무엇인가"를 묻지 않고, "확률이라면 반드시 만족해야 하는 규칙"만 정하고 나머지를 모두 그 규칙에서 증명합니다(콜모고로프, 1933).

1.1.2확률공간

정의 1.1.1 (확률공간)

표본공간 \(\Omega\): 실험의 가능한 결과 전체의 집합.

시그마 대수 \(\mathcal F\): 확률을 매길 부분집합(사건)들의 모임으로, \(\Omega \in \mathcal F\)이고 여집합과 가산 합집합에 대해 닫혀 있다.

확률측도 \(P: \mathcal F \to [0, 1]\): 다음 세 공리를 만족하는 함수.

(P1) 모든 사건 \(A\)에 대해 \(P(A) \ge 0\). (P2) \(P(\Omega) = 1\). (P3) 서로소인 사건 \(A_1, A_2, \dots\)에 대해 \(P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)\) (가산 가법성).

시그마 대수는 처음에는 낯설지만 역할은 단순합니다. "확률을 물어볼 수 있는 사건"이 여사건, 합사건을 취해도 여전히 확률을 물어볼 수 있게 해 둔 것입니다. 유한 표본공간에서는 모든 부분집합을 사건으로 삼으면 됩니다. \([0, 1]\) 같은 연속 공간에서 모든 부분집합에 길이를 매기는 것이 불가능하다는 사실이 시그마 대수가 필요한 이유이며, 자세한 내용은 측도론에서 다루며, 이 교재에서는 필요한 만큼만 씁니다.

1.1.3공리에서 나오는 성질

정리 1.1.2

(a) \(P(\varnothing) = 0\). (b) 유한 가법성: 서로소인 \(A_1, \dots, A_n\)에 대해 \(P(\bigcup A_i) = \sum P(A_i)\). (c) \(P(A^c) = 1 - P(A)\). (d) \(A \subseteq B\)이면 \(P(A) \le P(B)\). (e) \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).

(a) \(A_1 = \Omega\), \(A_i = \varnothing\) (\(i \ge 2\))에 (P3)을 쓰면 \(1 = 1 + \sum_{i \ge 2}P(\varnothing)\)이고, 각 항이 0 이상이므로 \(P(\varnothing) = 0\). (b) 나머지 \(A_i\)를 \(\varnothing\)으로 채워 (P3)을 쓴다. (c) \(A\)와 \(A^c\)는 서로소이고 합이 \(\Omega\)이므로 (b)와 (P2)에서. (d) \(B = A \cup (B \setminus A)\)는 서로소 합이므로 \(P(B) = P(A) + P(B \setminus A) \ge P(A)\). (e) \(A \cup B = A \cup (B \setminus A)\), \(B = (A \cap B) \cup (B \setminus A)\)를 각각 (b)로 쓰고 \(P(B \setminus A)\)를 소거한다. ∎

(e)에서 \(P(A \cap B)\)를 빼는 이유는 \(P(A) + P(B)\)가 겹친 부분을 두 번 셌기 때문입니다. 사건이 셋 이상이면 "두 번 센 것을 빼고, 너무 많이 뺀 것을 다시 더하는" 일을 반복해야 합니다.

1.1.4포함배제 원리

정리 1.1.3 (포함배제 원리)

\(P\left(\bigcup_{i=1}^n A_i\right) = \sum_i P(A_i) - \sum_{i<j}P(A_i \cap A_j) + \sum_{i<j<k}P(A_i\cap A_j\cap A_k) - \cdots + (-1)^{n+1}P(A_1 \cap \cdots \cap A_n)\).

\(n\)에 대한 귀납법. \(n = 2\)는 정리 1.1.2(e)이다. \(n\)에서 성립한다고 하고 \(B = \bigcup_{i=1}^nA_i\)라 두면 (e)에서 \(P(B \cup A_{n+1}) = P(B) + P(A_{n+1}) - P(B \cap A_{n+1})\)이다. \(B \cap A_{n+1} = \bigcup_{i=1}^n(A_i \cap A_{n+1})\)이므로 여기에도 귀납 가정을 쓸 수 있다. \(P(B)\)의 전개는 \(A_{n+1}\)을 포함하지 않는 교집합들을, \(-P(B\cap A_{n+1})\)의 전개는 \(A_{n+1}\)을 포함하는 교집합들을 부호를 하나 바꿔 내놓는다. 둘을 합치면 \(n+1\)개에 대한 공식이 된다. ∎

\(r\)개의 교집합 항이 붙는 부호는 \((-1)^{r+1}\)입니다. 원소 하나가 정확히 \(m\)개의 사건에 속한다면 이 원소는 우변에서 \(\binom m1 - \binom m2 + \cdots \pm \binom mm = 1 - (1-1)^m = 1\)번 세어집니다. 이것이 공식이 맞는 직관적인 이유입니다.

예제 1.1.4

1부터 100까지에서 하나를 고를 때 2, 3, 5 중 적어도 하나의 배수일 확률은?

풀이. \(A_2, A_3, A_5\)를 각 수의 배수인 사건이라 하면 \(P(A_2) = 0.50\), \(P(A_3) = 0.33\), \(P(A_5) = 0.20\). 교집합은 6, 10, 15의 배수: \(0.16, 0.10, 0.06\). 셋 모두는 30의 배수: \(0.03\). 따라서 \(0.50 + 0.33 + 0.20 - 0.16 - 0.10 - 0.06 + 0.03 = 0.74\).

예제 1.1.5 (모자 짝 맞추기)

\(n\)명이 모자를 무작위로 하나씩 집을 때 적어도 한 명이 자기 모자를 집을 확률 \(p_n\)을 구하여라.

풀이. 무엇을 구하나: \(A_i\) = "\(i\)번 사람이 자기 모자"일 때 \(P(\bigcup A_i)\). 지정된 \(r\)명이 모두 자기 모자를 집는 순열은 \((n-r)!\)개이므로 \(P(A_{i_1}\cap\cdots\cap A_{i_r}) = (n-r)!/n!\). 이런 항이 \(\binom nr\)개 있으므로 \(r\)번째 합은 \(\binom nr\frac{(n-r)!}{n!} = \frac1{r!}\)입니다. 따라서

\[p_n = 1 - \frac1{2!} + \frac1{3!} - \cdots + (-1)^{n+1}\frac1{n!}.\]

\(n = 4\)이면 \(1 - 0.5 + 0.1667 - 0.0417 = 0.625\)입니다. \(n \to \infty\)이면 \(e^{-1} = \sum(-1)^r/r!\)이므로 \(p_n \to 1 - 1/e \approx 0.6321\)이고, \(n = 7\)에서 이미 소수 넷째 자리까지 같습니다. 사람이 10명이든 100만 명이든 확률이 거의 같다는 것이 놀라운 점입니다. 같은 절의 탐구 카드에서 부분합이 어떻게 진동하며 수렴하는지 볼 수 있습니다.

흔한 실수(1) \(P(A\cup B\cup C) = P(A) + P(B) + P(C) - P(A\cap B\cap C)\)처럼 둘씩 교집합을 빠뜨린다. (2) "적어도 하나"를 \(1 - (1 - 1/n)^n\)으로 계산한다: 사건 \(A_i\)들은 독립이 아니므로 틀리다(다만 \(n\)이 크면 값은 비슷하다). (3) 가산 가법성을 "모든 합집합"에 쓴다: 셀 수 없는 합집합에는 쓸 수 없다(한 점의 확률이 0이어도 \([0,1]\)의 확률은 1).
요약
  1. 확률공간 \((\Omega, \mathcal F, P)\): 공리는 비음수, 전체 1, 가산 가법성 셋뿐.
  2. 여사건, 단조성, 두 사건의 합 공식이 모두 공리에서 나온다.
  3. 포함배제: 홀수 개 교집합은 더하고 짝수 개는 뺀다. 모자 문제의 답은 \(1 - 1/e\)로 수렴한다.

1.1.5연습문제

기본

  1. \(P(A) = 0.5\), \(P(B) = 0.4\), \(P(A\cap B) = 0.2\)일 때 \(A, B\) 어느 것도 일어나지 않을 확률은?
    답

    \(P(A\cup B) = 0.7\)이므로 \(0.3\).

응용

  1. 1부터 1000까지에서 하나를 고를 때 3, 5, 7 중 적어도 하나의 배수일 확률은?
    답

    \((333 + 200 + 142 - 66 - 47 - 28 + 9)/1000 = 0.543\).

심화

  1. (본페로니 부등식) \(P(A_1\cup\cdots\cup A_n) \ge \sum_iP(A_i) - \sum_{i<j}P(A_i\cap A_j)\)임을 보여라.
    답

    원소가 정확히 \(m \ge 1\)개의 사건에 속하면 좌변에서 1번, 우변에서 \(m - \binom m2 = m(3 - m)/2\)번 세어진다. \(m = 1, 2\)이면 1, \(m \ge 3\)이면 0 이하이므로 항상 \(1 \ge\) 우변 기여. 확률로 가중합하면 부등식. 부분합이 번갈아 위·아래 한계가 된다는 일반 결과의 첫 경우이다.
