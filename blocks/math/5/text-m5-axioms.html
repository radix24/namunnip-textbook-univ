확률의 공리와 포함배제 원리

본문

\(n\)명이 모자를 섞어 무작위로 하나씩 집을 때, 적어도 한 명이 자기 모자를 집을 확률은 얼마일까? 사람이 많아질수록 0에 가까워질까, 1에 가까워질까? 그리고 "같은 정도로 일어날 법한 경우의 수"로 셀 수 없는 확률까지 다루려면 확률을 무엇으로 정의해야 할까?

먼저 알아야 할 것고등학교 확률과 통계, 집합의 연산(집합론 2.1절), 가산집합(집합론 4.1절)을 쓴다.

1.1.1왜 공리가 필요한가

고등학교에서는 확률을 해당 경우의 수를 전체 경우의 수로 나눈 것으로 배웠다. 이 정의는 모든 결과가 똑같이 일어날 때만 쓸 수 있다. 그러나 찌그러진 동전, 내일 비가 올 확률, \([0, 1]\)에서 고른 실수가 \(1/3\)보다 작을 확률은 셀 수 있는 경우의 수로 설명되지 않는다. 그래서 현대 확률론은 확률이 무엇인지 묻지 않고, 확률이라면 반드시 만족해야 하는 규칙만 정한 뒤 나머지를 모두 그 규칙에서 증명한다(콜모고로프, 1933).

1.1.2확률공간

정의 1.1.1 (확률공간)

실험의 가능한 결과 전체의 집합 \(\Omega\)를 표본공간이라 한다. 확률을 매길 부분집합, 곧 사건들의 모임 \(\mathcal F\)가 \(\Omega \in \mathcal F\)이고 여집합과 가산 합집합에 대해 닫혀 있으면 시그마 대수라 한다. 함수 \(P: \mathcal F \to [0, 1]\)가 다음 세 공리를 만족하면 확률측도라 한다. (P1) 모든 사건 \(A\)에 대해 \(P(A) \ge 0\)이다. (P2) \(P(\Omega) = 1\)이다. (P3) 서로소인 사건 \(A_1, A_2, \dots\)에 대해 \(P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)\)이다(가산 가법성).

시그마 대수는 처음에는 낯설지만 역할은 단순하다. 확률을 물어볼 수 있는 사건에서 여사건이나 합사건을 취해도 여전히 확률을 물어볼 수 있게 해 둔 것이다. 유한 표본공간에서는 모든 부분집합을 사건으로 삼으면 된다. 그런데 \([0, 1]\) 같은 연속 공간에서는 모든 부분집합에 길이를 매기는 것이 불가능하며, 이것이 시그마 대수가 필요한 이유이다. 자세한 내용은 8단원과 측도론에서 다룬다.

1.1.3공리에서 나오는 성질

정리 1.1.2

(1) \(P(\varnothing) = 0\)이다. (2) 서로소인 \(A_1, \dots, A_n\)에 대해 \(P(\bigcup A_i) = \sum P(A_i)\)이다(유한 가법성). (3) \(P(A^c) = 1 - P(A)\)이다. (4) \(A \subseteq B\)이면 \(P(A) \le P(B)\)이다. (5) \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)이다.

증명.(1) \(A_1 = \Omega\), \(A_i = \varnothing\) (\(i \ge 2\))에 (P3)을 쓰면 \(1 = 1 + \sum_{i \ge 2}P(\varnothing)\)이고, 각 항이 0 이상이므로 \(P(\varnothing) = 0\)이다. (2) 나머지 \(A_i\)를 \(\varnothing\)으로 채워 (P3)을 쓴다. (3) \(A\)와 \(A^c\)는 서로소이고 합이 \(\Omega\)이므로 (2)와 (P2)에서 나온다. (4) \(B = A \cup (B \setminus A)\)는 서로소 합이므로 \(P(B) = P(A) + P(B \setminus A) \ge P(A)\)이다. (5) \(A \cup B = A \cup (B \setminus A)\)와 \(B = (A \cap B) \cup (B \setminus A)\)에 각각 (2)를 쓰고 \(P(B \setminus A)\)를 소거한다. ∎

(5)에서 \(P(A \cap B)\)를 빼는 이유는 \(P(A) + P(B)\)가 겹친 부분을 두 번 셌기 때문이다. 사건이 셋 이상이면 두 번 센 것을 빼고, 너무 많이 뺀 것을 다시 더하는 일을 되풀이해야 한다.

1.1.4포함배제 원리

정리 1.1.3 (포함배제 원리)

\(P\left(\bigcup_{i=1}^n A_i\right) = \sum_i P(A_i) - \sum_{i<j}P(A_i \cap A_j) + \sum_{i<j<k}P(A_i\cap A_j\cap A_k) - \cdots + (-1)^{n+1}P(A_1 \cap \cdots \cap A_n)\)이다.

증명.\(n\)에 대한 귀납법을 쓴다. \(n = 2\)는 정리 1.1.2 (5)이다. \(n\)에서 성립한다고 하고 \(B = \bigcup_{i=1}^nA_i\)라 두면 \(P(B \cup A_{n+1}) = P(B) + P(A_{n+1}) - P(B \cap A_{n+1})\)이다. 그런데 \(B \cap A_{n+1} = \bigcup_{i=1}^n(A_i \cap A_{n+1})\)이므로 여기에도 귀납 가정을 쓸 수 있다. \(P(B)\)의 전개는 \(A_{n+1}\)을 포함하지 않는 교집합들을 내놓고, \(-P(B\cap A_{n+1})\)의 전개는 \(A_{n+1}\)을 포함하는 교집합들을 부호를 하나 바꿔 내놓는다. 둘을 합치면 \(n+1\)개에 대한 공식이 된다. ∎

즉 \(r\)개의 교집합 항에는 부호 \((-1)^{r+1}\)이 붙는다. 원소 하나가 정확히 \(m\)개의 사건에 속한다면 우변에서 \(\binom m1 - \binom m2 + \cdots \pm \binom mm = 1 - (1-1)^m = 1\)번 세어지며, 이것이 공식이 맞는 직관적인 이유이다.

예제 1.1.4

1부터 100까지에서 하나를 고를 때 2, 3, 5 가운데 적어도 하나의 배수일 확률을 구하여라.

풀이. 각 수의 배수인 사건을 \(A_2, A_3, A_5\)라 하면 \(P(A_2) = 0.50\), \(P(A_3) = 0.33\), \(P(A_5) = 0.20\)이다. 둘씩의 교집합은 6, 10, 15의 배수라 \(0.16, 0.10, 0.06\)이고, 셋 모두는 30의 배수라 \(0.03\)이다. 따라서 \(0.50 + 0.33 + 0.20 - 0.16 - 0.10 - 0.06 + 0.03 = 0.74\)이다.

예제 1.1.5 (모자 짝 맞추기)

\(n\)명이 모자를 무작위로 하나씩 집을 때 적어도 한 명이 자기 모자를 집을 확률 \(p_n\)을 구하여라.

풀이. \(i\)번 사람이 자기 모자를 집는 사건을 \(A_i\)라 하면 구하는 것은 \(P(\bigcup A_i)\)이다. 지정된 \(r\)명이 모두 자기 모자를 집는 순열은 \((n-r)!\)개이므로 \(P(A_{i_1}\cap\cdots\cap A_{i_r}) = (n-r)!/n!\)이다. 이런 항이 \(\binom nr\)개 있으므로 \(r\)번째 합은 \(\binom nr\frac{(n-r)!}{n!} = \frac1{r!}\)이고, 다음을 얻는다.

\[p_n = 1 - \frac1{2!} + \frac1{3!} - \cdots + (-1)^{n+1}\frac1{n!}.\]

\(n = 4\)이면 \(1 - 0.5 + 0.1667 - 0.0417 = 0.625\)이다. \(e^{-1} = \sum(-1)^r/r!\)이므로 \(n \to \infty\)이면 \(p_n \to 1 - 1/e \approx 0.6321\)이고, 그림 1처럼 \(n = 7\)에서 이미 소수 넷째 자리까지 같다. 사람이 10명이든 100만 명이든 확률이 거의 같다는 것이 놀라운 점이다.

흔한 오해\(P(A\cup B\cup C) = P(A) + P(B) + P(C) - P(A\cap B\cap C)\)처럼 둘씩의 교집합을 빠뜨리기 쉽다. 또 "적어도 하나"를 \(1 - (1 - 1/n)^n\)으로 계산하는 실수가 있는데, 사건 \(A_i\)들이 독립이 아니므로 틀렸다(다만 \(n\)이 크면 값은 비슷하다). 가산 가법성을 셀 수 없는 합집합에 쓰는 것도 틀렸다. 한 점의 확률이 0이어도 \([0,1]\)의 확률은 1이다.
마무리

처음 질문에 답하면, 적어도 한 명이 자기 모자를 집을 확률은 사람 수가 늘수록 \(1 - 1/e \approx 0.632\)로 다가가며, 0이나 1로 가지 않는다. 이 계산은 홀수 개의 교집합은 더하고 짝수 개는 빼는 포함배제 원리로 한다. 경우의 수로 셀 수 없는 확률까지 다루기 위해, 확률은 비음수, 전체 1, 가산 가법성의 세 공리를 만족하는 확률공간 \((\Omega, \mathcal F, P)\)로 정의하며, 여사건·단조성·합 공식은 모두 이 공리에서 나온다.

1.1.5연습문제

기본

  1. \(P(A) = 0.5\), \(P(B) = 0.4\), \(P(A\cap B) = 0.2\)일 때 \(A, B\) 어느 것도 일어나지 않을 확률은?
    답

    \(P(A\cup B) = 0.7\)이므로 \(0.3\).

응용

  1. 1부터 1000까지에서 하나를 고를 때 3, 5, 7 중 적어도 하나의 배수일 확률은?
    답

    \((333 + 200 + 142 - 66 - 47 - 28 + 9)/1000 = 0.543\).

심화

  1. (본페로니 부등식) \(P(A_1\cup\cdots\cup A_n) \ge \sum_iP(A_i) - \sum_{i<j}P(A_i\cap A_j)\)임을 보여라.
    답

    원소가 정확히 \(m \ge 1\)개의 사건에 속하면 좌변에서 1번, 우변에서 \(m - \binom m2 = m(3 - m)/2\)번 세어진다. \(m = 1, 2\)이면 1, \(m \ge 3\)이면 0 이하이므로 항상 \(1 \ge\) 우변 기여. 확률로 가중합하면 부등식. 부분합이 번갈아 위·아래 한계가 된다는 일반 결과의 첫 경우이다.
