조건부 기대값 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(X \sim U(0, 1)\)이고 \(X = x\)일 때 \(Y \sim B(10, x)\)이다. \(E[Y]\)는? [07-01]

    힌트 1

    \(E[Y\mid X] = 10X\)(7.1절).

    힌트 2

    \(E[X] = 1/2\).

    풀이

    \(E[Y] = 10 \cdot \frac12 = 5\).

  2. 계산문제 1에서 \(\mathrm{Var}(Y)\)를 전분산 공식으로 구하여라. [07-02]

    힌트 1

    \(\mathrm{Var}(Y\mid X) = 10X(1 - X)\)(7.2절).

    힌트 2

    \(E[X(1-X)] = 1/2 - 1/3\), \(\mathrm{Var}(10X) = 100/12\).

    풀이

    \(10 \cdot \frac16 + \frac{100}{12} = \frac53 + \frac{25}3 = 10\). (실제로 \(Y\)는 0부터 10까지 균등이고 분산 \((11^2 - 1)/12 = 10\).)

  3. 계산주사위를 6이 나올 때까지 던진다. 던진 횟수의 기대값을 첫 단계 분석으로 구하여라. [07-01]

    힌트 1

    첫 던지기가 6인지로 조건.

    힌트 2

    \(m = 1 + \frac56m\).

    풀이

    \(m = \frac16\cdot1 + \frac56(1 + m)\)에서 \(m = 6\). 기하분포의 평균 \(1/p\)과 같다.

  4. 증명\(X\)와 \(Y\)가 독립이면 \(E[Y\mid X] = E[Y]\)이고 전분산 공식의 둘째 항이 0임을 보여라. [07-02]

    힌트 1

    독립이면 조건부분포 = 주변분포.

    힌트 2

    상수의 분산은 0.

    풀이

    \(f_{Y\mid X}(y\mid x) = f_Y(y)\)이므로 \(E[Y\mid X = x] = E[Y]\)로 \(x\)와 무관한 상수. \(\mathrm{Var}(E[Y\mid X]) = 0\)이고 \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y\mid X)]\). ∎

  5. 개념하루 보험 청구 건수가 \(\mathrm{Pois}(4)\), 건당 금액이 평균 100, 표준편차 50(만 원)이다. 하루 청구 총액의 평균과 표준편차는? [07-02]

    힌트 1

    \(\mathrm{Var}(S) = E[N]\sigma^2 + \mu^2\mathrm{Var}(N)\).

    힌트 2

    포아송이면 \(\mathrm{Var}(N) = E[N] = 4\).

    풀이

    평균 400. 분산 \(4\cdot2500 + 10000\cdot4 = 50000\), 표준편차 약 223.6.

  6. 판단한 학생이 "\(E[Y\mid X]\)는 기대값이므로 상수다"라고 썼다. 맞는가? [07-01]

    힌트 1

    막대 쪼개기 예제의 \(E[Y\mid X]\)는?

    힌트 2

    \(X\)를 아직 모르는 상태.

    풀이

    틀렸다. \(E[Y\mid X] = X/2\)처럼 \(X\)의 함수인 확률변수이다. 상수가 되는 것은 \(E[Y\mid X = x]\)(특정 \(x\)를 넣은 값)이나, \(X\)와 \(Y\)가 독립일 때뿐이다.
