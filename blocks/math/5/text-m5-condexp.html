조건부 기대값과 반복 기대값 법칙

본문

갱도에 갇힌 광부 앞에 문이 셋 있다. 1번 문은 3시간 뒤 밖으로 이어지고, 2번과 3번 문은 각각 5시간, 7시간 뒤 제자리로 돌아온다. 광부가 매번 문을 무작위로 고른다면, 밖으로 나가기까지 평균 몇 시간이 걸릴까? 경우가 끝없이 이어지는데 어떻게 계산할까?

먼저 알아야 할 것조건부분포(4.1절), 기대값(3.1절), 전확률 공식(1.3절)을 쓴다.

7.1.1두 가지 조건부 기대값

\(X = x\)를 알 때 \(Y\)의 평균은 조건부분포의 평균이다. 이것은 \(x\)마다 하나의 수이므로 \(x\)의 함수 \(h(x) = E[Y\mid X = x]\)이다. 그 함수에 확률변수 \(X\)를 넣은 \(h(X)\)를 \(E[Y\mid X]\)로 쓰며, 아직 \(X\)를 모를 때 \(X\)를 알게 되면 내놓을 예측이라는 확률변수이다.

정의 7.1.1

\(E[Y\mid X = x] = \sum_yy\,p_{Y\mid X}(y\mid x)\) 또는 \(\int yf_{Y\mid X}(y\mid x)\,dy\)를 \(X = x\)일 때 \(Y\)의 조건부 기대값이라 한다. \(h(x) = E[Y\mid X = x]\)일 때 확률변수 \(E[Y\mid X] = h(X)\)도 조건부 기대값이라 한다.

예를 들어 4.1절 예제 4.1.4에서 \(E[Y\mid X = x] = x/2\)이므로 \(E[Y\mid X] = X/2\)이다. 이변량 정규분포에서는 \(E[Y\mid X] = \rho X\)이다.

7.1.2반복 기대값 법칙

정리 7.1.2 (반복 기대값 법칙)

\(E[|Y|] < \infty\)이면 \(E\big[E[Y\mid X]\big] = E[Y]\)이다. 이산이면 \(E[Y] = \sum_xE[Y\mid X = x]P(X = x)\)이다.

증명.연속인 경우 \(E[h(X)] = \int h(x)f_X(x)\,dx = \int\left(\int y\frac{f(x, y)}{f_X(x)}dy\right)f_X(x)\,dx = \iint yf(x, y)\,dy\,dx = E[Y]\)이다. 적분 순서는 절대적분가능성 덕분에 바꿀 수 있다. 이산인 경우는 합으로 같다. ∎

이것은 전확률 공식의 기대값 판이다. 경우마다 평균을 구하고, 경우의 확률로 가중평균한다. 그래서 직접 구하기 어려운 \(E[Y]\)를, 무언가를 알고 나면 쉬워지는 조건부 평균으로 쪼개서 구한다.

예제 7.1.3 (막대 쪼개기)

길이 1인 막대에서 균등하게 한 점 \(X\)를 골라 왼쪽 조각 \([0, X]\)을 남기고, 다시 균등하게 한 점 \(Y\)를 골라 \([0, Y]\)를 남긴다. \(E[Y]\)를 구하여라.

풀이. \(Y\mid X = x \sim U(0, x)\)이므로 \(E[Y\mid X] = X/2\)이다. 반복 기대값으로 \(E[Y] = E[X/2] = 1/4\)이다. 즉 밀도 \(-\ln y\)라는 \(Y\)의 분포를 구하지 않고도 평균이 나온다.

7.1.3첫 단계 분석

예제 7.1.4 (갇힌 광부)

처음 질문에서 밖으로 나갈 때까지 걸리는 시간 \(T\)의 기대값을 구하여라.

풀이. 첫 선택 \(D\)로 조건을 건다. \(E[T\mid D = 1] = 3\)이고, 돌아온 뒤는 처음과 같은 상황이므로 \(E[T\mid D = 2] = 5 + E[T]\), \(E[T\mid D = 3] = 7 + E[T]\)이다. 반복 기대값으로 \(E[T] = \frac13(3 + 5 + E[T] + 7 + E[T])\), 곧 \(\frac13E[T] = 5\)이므로 \(E[T] = 15\)시간이다. 그림 1처럼 상황이 처음으로 돌아가는 구조를 이용해 무한한 경우를 방정식 하나로 처리했다. 확률과정론에서 마르코프 연쇄의 도달 시간을 계산하는 것도 같은 방법이다.

7.1.4무작위 개수의 합

예제 7.1.5

하루 손님 수 \(N \sim \mathrm{Pois}(50)\)이고, 손님마다 쓰는 금액 \(X_i\)는 평균 20(천 원)이며 \(N\)과 독립이다. 하루 매출 \(S = \sum_{i=1}^NX_i\)의 기대값을 구하여라.

풀이. \(E[S\mid N = n] = 20n\)이므로 \(E[S\mid N] = 20N\)이고 \(E[S] = 20E[N] = 1000\)이다. 일반적으로 \(E[S] = E[N]E[X]\)이며, 이것이 왈드 항등식의 간단한 형태이다. 분산은 다음 절의 전분산 공식이 필요하다.

흔한 오해\(E[Y\mid X]\)를 수로 여기기 쉽지만, \(X\)의 함수인 확률변수이다. 또 광부 문제에서 \(E[T\mid D = 2] = 5\)로 두는 실수가 있는데, 돌아온 뒤에 더 걸리는 시간을 빠뜨린 것이다. 지출이 많은 날 손님이 적은 경우처럼 \(N\)과 \(X_i\)가 독립이 아닌데 \(E[N]E[X]\)를 쓰는 것도 틀렸다.
마무리

처음 질문의 답은 15시간이다. 첫 선택으로 경우를 나누어 반복 기대값 법칙 \(E[E[T\mid D]] = E[T]\)를 쓰면, 제자리로 돌아오는 경우에 \(E[T]\)가 다시 나타나 방정식 하나로 풀린다. 조건부 기대값 \(E[Y\mid X = x]\)는 수이고 \(E[Y\mid X]\)는 \(X\)의 함수인 확률변수이며, 반복 기대값 법칙은 경우별 평균의 가중평균이다. 무작위 개수의 합에서는 \(E[S] = E[N]E[X]\)이다.

7.1.5연습문제

기본

  1. 주사위를 던져 나온 눈 \(K\)만큼 동전을 던진다. 앞면 수의 기대값은?
    답

    앞면 수를 \(H\)라 하면 \(E[H\mid K] = K/2\), 기대값 \(3.5/2 = 1.75\).

응용

  1. 동전을 앞면이 두 번 연속 나올 때까지 던진다. 던지는 횟수의 기대값을 첫 단계 분석으로 구하여라.
    답

    시작 상태의 기대값 \(a\), 직전이 앞면인 상태 \(b\). \(a = 1 + \frac12b + \frac12a\), \(b = 1 + \frac12\cdot0 + \frac12a\). 풀면 \(a = 6\).

심화

  1. \(E[g(X)Y\mid X] = g(X)E[Y\mid X]\)임을 이용해 \(E[(Y - E[Y\mid X])g(X)] = 0\)을 보여라. (예측 오차는 \(X\)의 어떤 함수와도 상관이 없다)
    답

    반복 기대값으로 \(E[g(X)Y] = E[g(X)E[Y\mid X]]\). 빼면 0. 이것이 \(E[Y\mid X]\)가 평균제곱오차를 최소화하는 예측이라는 사실의 핵심이다.
