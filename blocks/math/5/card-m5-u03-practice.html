기대값 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(n\)명이 모자를 무작위로 집을 때 자기 모자를 집는 사람 수의 기대값은? [03-01]

    힌트 1

    \(i\)번 사람마다 지시변수(3.1절).

    힌트 2

    각 지시변수의 기대값은 \(1/n\).

    풀이

    \(n \cdot \frac1n = 1\). \(n\)에 무관하다.

  2. 계산52장 카드를 섞을 때 이웃한 두 장이 모두 에이스인 자리(1–2, 2–3, …, 51–52)의 수의 기대값은? [03-01]

    힌트 1

    자리 51개 각각에 지시변수.

    힌트 2

    특정 두 자리가 모두 에이스일 확률 \(\frac{4}{52}\cdot\frac{3}{51}\).

    풀이

    \(51 \cdot \frac{4\cdot3}{52\cdot51} = \frac{12}{52} = \frac3{13} \approx 0.2308\).

  3. 증명\(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\)임을 정의로 보여라. [03-01]

    힌트 1

    \(E[aX + b] = a\mu + b\).

    힌트 2

    \((aX + b - a\mu - b)^2 = a^2(X - \mu)^2\).

    풀이

    \(\mathrm{Var}(aX + b) = E[(aX + b - (a\mu + b))^2] = E[a^2(X - \mu)^2] = a^2\mathrm{Var}(X)\). 이동 \(b\)는 퍼짐을 바꾸지 않는다. ∎

  4. 계산\(M_X(t) = e^{3(e^t - 1)}\)일 때 \(E[X]\), \(E[X^2]\)을 미분으로 구하여라. [03-02]

    힌트 1

    \(M' = 3e^tM\)(3.2절).

    힌트 2

    \(M'' = 3e^tM + 9e^{2t}M\).

    풀이

    \(E[X] = 3\), \(E[X^2] = 3 + 9 = 12\), 분산 3. \(\mathrm{Pois}(3)\)과 맞다.

  5. 계산독립인 \(X \sim B(5, 0.4)\), \(Y \sim B(7, 0.4)\)에 대해 \(X + Y\)의 분포는? \(X \sim B(5, 0.4)\), \(Y \sim B(7, 0.5)\)이면? [03-02]

    힌트 1

    \((0.6 + 0.4e^t)^5(0.6 + 0.4e^t)^7\).

    힌트 2

    두 번째 곱은 하나의 \((q + pe^t)^n\) 꼴이 되나요?

    풀이

    첫째는 \(B(12, 0.4)\). 둘째는 \((0.6 + 0.4e^t)^5(0.5 + 0.5e^t)^7\)이 한 이항분포의 적률생성함수 꼴이 아니므로 이항분포가 아니다(평균 5.5, 분산 2.95).

  6. 판단한 학생이 "\(X\)와 \(Y\)의 공분산이 0이므로 독립이다"라고 썼다. 맞는가? [03-01]

    힌트 1

    \(X\)가 \(\{-1, 0, 1\}\)에서 균등, \(Y = X^2\).

    힌트 2

    \(E[XY] = E[X^3]\).

    풀이

    틀렸다. 위의 예에서 \(\mathrm{Cov} = E[X^3] - E[X]E[X^2] = 0\)이지만 \(Y\)는 \(X\)로 완전히 정해진다. 공분산은 선형 관계만 잰다. 독립이면 공분산 0이지만 역은 거짓이다(정규분포 쌍은 예외, 4.2절).
