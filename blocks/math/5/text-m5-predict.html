조건부 기대값은 가장 좋은 예측

본문
이 절에서 배울 것
  • \(X\)를 보고 \(Y\)를 예측할 때 평균제곱오차를 가장 작게 하는 함수가 \(E[Y\mid X]\)임을 증명한다.
  • 직선만 쓸 때의 가장 좋은 예측(최량 선형 예측)과 그 오차 \(\sigma_Y^2(1 - \rho^2)\)를 구한다.
  • 두 예측이 같은 경우와 다른 경우를 비교한다.
먼저 알아야 할 것
  • 반복 기대값 법칙 (7.1절), 상관계수 (3.3절).

7.3.1평균제곱오차를 최소로

아버지의 키 \(X\)를 보고 아들의 키 \(Y\)를 맞히는 규칙 \(g\)를 정한다고 합시다. 오차를 \(E[(Y - g(X))^2]\)로 잴 때 가장 좋은 \(g\)는 무엇일까요? 상수 하나로 맞힐 때(\(X\)를 모를 때) 가장 좋은 값은 평균 \(E[Y]\)였습니다(\(E[(Y - c)^2] = \mathrm{Var}(Y) + (E[Y] - c)^2\)). \(X\)를 알면 그 정보 아래의 평균을 쓰면 됩니다.

정리 7.3.1

\(E[Y^2] < \infty\)이면 모든 함수 \(g\)(\(E[g(X)^2] < \infty\))에 대해 \(E[(Y - g(X))^2] \ge E[(Y - E[Y\mid X])^2]\)이다.

증명 방향: \(Y - g(X)\)를 \((Y - m(X)) + (m(X) - g(X))\)로 나누고, 두 부분의 곱의 기대값이 0임(7.1절 연습문제 3)을 씁니다.

\(m(X) = E[Y\mid X]\), \(h(X) = m(X) - g(X)\)라 두면 \(E[(Y - g(X))^2] = E[(Y - m(X))^2] + 2E[(Y - m(X))h(X)] + E[h(X)^2]\). 반복 기대값으로 \(E[(Y - m(X))h(X)] = E\big[h(X)\,E[Y - m(X)\mid X]\big] = 0\). 따라서 \(E[(Y - g(X))^2] = E[(Y - m(X))^2] + E[h(X)^2] \ge E[(Y - m(X))^2]\). ∎

이때 최소 오차는 \(E[\mathrm{Var}(Y\mid X)]\)로, 전분산 공식(7.2절)의 첫째 항입니다.

7.3.2최량 선형 예측

\(E[Y\mid X]\)를 구하려면 결합분포를 다 알아야 합니다. 평균, 분산, 공분산만 알 때는 직선 \(g(X) = a + bX\) 중에서 가장 좋은 것을 찾습니다.

정리 7.3.2

\(E[(Y - a - bX)^2]\)를 최소로 하는 직선은 \(b = \rho\dfrac{\sigma_Y}{\sigma_X}\), \(a = \mu_Y - b\mu_X\)이고, 최소 오차는 \(\sigma_Y^2(1 - \rho^2)\)이다.

\(a\)에 대해 최소화하면 \(a = \mu_Y - b\mu_X\)(상수 예측의 경우와 같음). 대입하면 \(E[((Y - \mu_Y) - b(X - \mu_X))^2] = \sigma_Y^2 - 2b\,\mathrm{Cov} + b^2\sigma_X^2\)이고, 이 이차식의 꼭짓점은 \(b = \mathrm{Cov}/\sigma_X^2 = \rho\sigma_Y/\sigma_X\), 값은 \(\sigma_Y^2 - \mathrm{Cov}^2/\sigma_X^2 = \sigma_Y^2(1 - \rho^2)\). ∎

\(\rho^2\)은 \(Y\)의 분산 중 직선으로 설명되는 비율입니다(수학9의 결정계수). 이변량 정규분포에서는 \(E[Y\mid X]\)가 원래 직선이라(4.1절) 두 예측이 같습니다. 일반적으로는 \(E[Y\mid X]\)가 더 좋거나 같습니다(같은 절의 예제).

흔한 실수(1) 최량 예측이 항상 직선이라 여긴다: 정규분포일 때의 성질이다. (2) 평균으로 돌아가는 회귀(\(|\rho| < 1\)이라 예측이 평균 쪽으로 당겨짐)를 인과 효과로 해석한다: 예측 공식의 산술적 결과다. (3) 평균절대오차를 최소로 하는 예측도 평균이라 여긴다: 그것은 중앙값이다.
요약
  1. \(E[Y\mid X]\)는 평균제곱오차를 최소로 하는 예측. 오차는 \(E[\mathrm{Var}(Y\mid X)]\).
  2. 최량 선형 예측: 기울기 \(\rho\sigma_Y/\sigma_X\), 오차 \(\sigma_Y^2(1 - \rho^2)\).
  3. 정규분포에서는 둘이 같고, 곡선 관계에서는 다르다.

7.3.3연습문제

기본

  1. \(\mu_X = \mu_Y = 170\), \(\sigma_X = \sigma_Y = 6\), \(\rho = 0.5\)일 때 \(X = 182\)인 아버지의 아들 키를 최량 선형 예측하여라.
    답

    \(170 + 0.5(182 - 170) = 176\). 평균 쪽으로 당겨진다.

응용

  1. 위에서 예측 오차의 표준편차는?
    답

    \(6\sqrt{1 - 0.25} \approx 5.20\). 아버지 키를 알아도 불확실성이 13%만 준다.

심화

  1. \(E[|Y - c|]\)를 최소로 하는 상수 \(c\)가 \(Y\)의 중앙값임을 연속분포에서 보여라.
    답

    \(\frac{d}{dc}E|Y - c| = P(Y < c) - P(Y > c)\). 0이 되는 곳은 \(P(Y < c) = \frac12\).
