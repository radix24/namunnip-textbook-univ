확률변수와 분포 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 증명\(G(x) = e^{-e^{-x}}\)가 분포함수임을 보이고 \(P(0 < X \le 1)\)을 구하여라. [02-01]

    힌트 1

    정리 2.1.2의 세 성질을 확인하세요(2.1절).

    힌트 2

    \(x\to-\infty\)이면 \(e^{-x} \to \infty\).

    풀이

    \(e^{-x}\)가 감소하므로 \(G\)는 증가, 연속(따라서 오른쪽 연속), \(-\infty\)에서 \(e^{-\infty} = 0\), \(\infty\)에서 \(e^0 = 1\). \(P(0 < X \le 1) = e^{-e^{-1}} - e^{-1} \approx 0.6922 - 0.3679 = 0.3243\). (굼벨 분포, 최댓값의 극한 분포)

  2. 계산한 시간에 평균 3통의 전화가 온다(포아송). 한 시간에 2통 이하일 확률은? [02-02]

    힌트 1

    \(k = 0, 1, 2\)의 확률을 더하세요(2.2절).

    힌트 2

    \(e^{-3}(1 + 3 + 9/2)\).

    풀이

    \(8.5e^{-3} \approx 0.4232\).

  3. 개념버스 도착 간격이 평균 10분인 지수분포를 따른다. 이미 5분 기다린 사람이 앞으로 10분 이상 더 기다릴 확률은? 이 결과가 일상 감각과 어긋나는 이유는? [02-02]

    힌트 1

    무기억성.

    힌트 2

    \(\lambda = 1/10\).

    풀이

    \(P(X > 15 \mid X > 5) = P(X > 10) = e^{-1} \approx 0.3679\). 실제 버스는 시간표가 있어 지수분포가 아니다. 지수 모형은 "언제 올지 아무 단서가 없는" 경우의 모형이다.

  4. 계산\(X \sim U(0, 1)\), \(Y = 1/X\)의 밀도를 구하고 \(P(Y > 4)\)를 구하여라. [02-03]

    힌트 1

    \(\{1/X \le y\} = \{X \ge 1/y\}\) (\(y > 1\))(2.3절).

    힌트 2

    \(F_Y(y) = 1 - 1/y\).

    풀이

    \(f_Y(y) = 1/y^2\) (\(y > 1\)). \(P(Y > 4) = 1/4\). 공식으로도 \(g^{-1}(y) = 1/y\), \(|(g^{-1})'| = 1/y^2\).

  5. 계산분포함수 \(F(x) = x^3\) (\(0 \le x \le 1\))을 따르는 난수를 균등 난수 \(U\)로 만드는 식을 쓰고, \(U = 0.125\)일 때의 값을 구하여라. [02-03]

    힌트 1

    역변환 방법: \(X = F^{-1}(U)\).

    힌트 2

    \(u = x^3\)을 \(x\)에 대해 푸세요.

    풀이

    \(X = U^{1/3}\). \(U = 0.125\)이면 \(X = 0.5\).

  6. 판단한 학생이 "확률밀도함수가 어떤 점에서 2이면 확률이 1을 넘으므로 잘못된 밀도다"라고 했다. 맞는가? [02-01]

    힌트 1

    밀도의 값은 확률이 아닙니다.

    힌트 2

    \(U(0, 0.5)\)를 생각하세요.

    풀이

    틀렸다. \(U(0, 0.5)\)의 밀도는 2이지만 넓이는 \(2 \times 0.5 = 1\)이다. 확률은 밀도의 적분이고, 밀도에 필요한 조건은 0 이상과 전체 적분 1뿐이다.
