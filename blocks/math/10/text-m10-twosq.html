두 제곱수의 합

본문
이 절에서 배울 것
  • \(4k + 3\) 꼴 소수는 두 제곱수의 합이 아님을 보인다.
  • \(4k + 1\) 꼴 소수가 두 제곱수의 합임을 투에 보조정리(비둘기집)로 설명한다.
  • 곱셈 공식으로 어떤 정수가 두 제곱수의 합인지 판정하는 기준을 안다.
먼저 알아야 할 것
  • \(-1\)이 이차 잉여일 조건 (5.1절), 비둘기집 원리 (수학3 3.2절), 가우스 정수 (수학12 7.2절).

6.3.1관찰

소수 중 5 = 1 + 4, 13 = 4 + 9, 17 = 1 + 16, 29 = 4 + 25는 두 제곱수의 합이고 3, 7, 11, 19, 23은 아닙니다. 앞의 것은 모두 \(4k + 1\) 꼴, 뒤의 것은 \(4k + 3\) 꼴입니다(2 = 1 + 1은 따로).

한 방향은 쉽습니다: 제곱수는 법 4로 0 또는 1이라 두 제곱수의 합은 0, 1, 2 (mod 4)이고 3이 될 수 없습니다.

6.3.2페르마의 두 제곱수 정리

정리 6.3.1 (페르마-오일러)

홀수 소수 \(p\)가 두 제곱수의 합일 필요충분조건은 \(p \equiv 1 \pmod 4\)이다.

증명 전략: \(p \equiv 1 \pmod 4\)이면 \(u^2 \equiv -1 \pmod p\)인 \(u\)가 있습니다(5.1절). 곧 \(x^2 + (ux)^2 \equiv 0 \pmod p\)이므로 \(y \equiv ux\)인 작은 \(x, y\)를 찾으면 \(x^2 + y^2\)이 \(p\)의 작은 배수, 결국 \(p\) 자신이 됩니다. 작은 \(x, y\)는 비둘기집 원리로 찾습니다.

투에 보조정리. \(s = \lfloor\sqrt p\rfloor\)라 하자. \(0 \le a, b \le s\)인 쌍 \((a, b)\)는 \((s+1)^2 > p\)개이므로, 비둘기집 원리로 \(a - ub\)의 나머지가 같은 서로 다른 두 쌍 \((a_1, b_1)\), \((a_2, b_2)\)가 있다. \(x = a_1 - a_2\), \(y = b_1 - b_2\)로 두면 \(x \equiv uy \pmod p\), \((x, y) \ne (0, 0)\), \(|x|, |y| \le s < \sqrt p\).

결론. \(x^2 + y^2 \equiv u^2y^2 + y^2 = (u^2 + 1)y^2 \equiv 0 \pmod p\)이고 \(0 < x^2 + y^2 < 2p\). 따라서 \(x^2 + y^2 = p\). ∎

예제 6.3.2

\(p = 13\)을 두 제곱수의 합으로 나타내는 과정을 따라가라.

풀이. \(5^2 = 25 \equiv -1 \pmod{13}\)이므로 \(u = 5\). \(s = 3\). \((a, b) \in \{0, \dots, 3\}^2\)의 16쌍 중 \(a - 5b \bmod 13\)이 같은 두 쌍을 찾으면, 예를 들어 \((2, 0)\)은 2, \((0, 1)\)은 \(-5 \equiv 8\), \((3, 1)\)은 \(-2 \equiv 11\), \((1, 2)\)는 \(-9 \equiv 4\), \((3, 2)\)는 \(-7 \equiv 6\), \((0, 3)\)은 \(-15 \equiv 11\)로 \((3, 1)\)과 겹칩니다. \(x = 3 - 0 = 3\), \(y = 1 - 3 = -2\): \(3^2 + 2^2 = 13\). 같은 절의 탐구 카드에서 다른 소수로 해 볼 수 있습니다.

6.3.3일반 정수

\((a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2\) (복소수 \(|z|^2|w|^2 = |zw|^2\))이므로 두 제곱수의 합끼리의 곱도 두 제곱수의 합입니다. 이로부터 양의 정수 \(n\)이 두 제곱수의 합일 필요충분조건은 \(n\)의 소인수분해에서 \(4k + 3\) 꼴 소수의 지수가 모두 짝수인 것입니다. 예: \(45 = 3^2\cdot5 = 36 + 9\)는 되고 \(21 = 3\cdot7\)은 안 됩니다. 표현의 개수(부호와 순서 포함)는 \(r_2(n) = 4(d_1(n) - d_3(n))\) (\(d_i\)는 \(\equiv i \pmod 4\)인 약수의 개수)로, \(65 = 5\cdot13\)은 16가지(\(1 + 64\), \(16 + 49\)의 부호·순서)입니다. 가우스 정수 \(\mathbb Z[i]\)에서 \(p = (a + bi)(a - bi)\)로 쪼개지는 것이 이 정리의 대수적 의미입니다.

흔한 실수(1) \(4k + 1\) 꼴 합성수는 모두 두 제곱수의 합이라 여긴다: \(21 = 3\cdot7 \equiv 1 \pmod 4\)이지만 아니다. (2) 투에 보조정리에서 \(|x|, |y| \le \sqrt p\)를 \(<\)로 확인하지 않아 \(x^2 + y^2 = 2p\)의 가능성을 빠뜨린다. (3) 0을 제곱수로 허용하는지 정하지 않는다(\(9 = 0 + 9\)).
요약
  1. 두 제곱수의 합은 \(\not\equiv 3 \pmod 4\). 홀수 소수는 \(p \equiv 1 \pmod 4\)일 때만 두 제곱수의 합.
  2. 증명: \(u^2 \equiv -1\)과 비둘기집으로 작은 \(x \equiv uy\) → \(x^2 + y^2 = p\).
  3. 일반 \(n\): \(4k + 3\) 소수의 지수가 모두 짝수일 때만. 곱셈 공식 \(|z|^2|w|^2 = |zw|^2\).

6.3.4연습문제

기본

  1. 41, 97을 두 제곱수의 합으로 나타내라.
    답

    \(41 = 16 + 25\), \(97 = 16 + 81\).

응용

  1. \(5 = 1^2 + 2^2\), \(13 = 2^2 + 3^2\)과 곱셈 공식으로 65를 두 가지 방법으로 나타내라.
    답

    \((1\cdot2 - 2\cdot3)^2 + (1\cdot3 + 2\cdot2)^2 = 16 + 49\), \((1\cdot2 + 2\cdot3)^2 + (1\cdot3 - 2\cdot2)^2 = 64 + 1\).

심화

  1. \(p \equiv 3 \pmod 4\)이고 \(p \mid x^2 + y^2\)이면 \(p \mid x\), \(p \mid y\)임을 보여라.
    답

    \(p \nmid y\)이면 \((xy^{-1})^2 \equiv -1\)이라 \(-1\)이 이차 잉여가 되어 \(p \equiv 1 \pmod 4\)와 모순. 따라서 \(p \mid y\), 그러면 \(p \mid x^2\), \(p \mid x\). (이것이 "지수가 짝수"라는 조건의 이유)
