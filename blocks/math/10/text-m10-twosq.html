두 제곱수의 합

본문

소수 \(5 = 1 + 4\), \(13 = 4 + 9\), \(17 = 1 + 16\), \(29 = 4 + 25\)는 두 제곱수의 합이다. 하지만 3, 7, 11, 19, 23은 그렇지 않다. 어떤 소수가 두 제곱수의 합이 될까? 소수가 아닌 정수는 어떨까?

먼저 알아야 할 것\(-1\)이 이차 잉여일 조건(5.1절), 비둘기집 원리(수학3 3.2절), 가우스 정수(수학12 7.2절)를 쓴다.

6.3.1관찰

처음 질문의 예에서 두 제곱수의 합인 소수는 모두 \(4k + 1\) 꼴이고, 아닌 것은 모두 \(4k + 3\) 꼴이다. 2 = 1 + 1은 따로 둔다. 한 방향은 쉽다. 제곱수는 법 4로 0 또는 1이므로 두 제곱수의 합은 법 4로 0, 1, 2이고 3이 될 수 없다.

6.3.2페르마의 두 제곱수 정리

정리 6.3.1 (페르마-오일러)

홀수 소수 \(p\)가 두 제곱수의 합일 필요충분조건은 \(p \equiv 1 \pmod 4\)이다.

증명의 방향은 이렇다. \(p \equiv 1 \pmod 4\)이면 5.1절로 \(u^2 \equiv -1 \pmod p\)인 \(u\)가 있다. 그러면 \(x^2 + (ux)^2 \equiv 0 \pmod p\)이므로, \(y \equiv ux\)인 작은 \(x, y\)를 찾으면 \(x^2 + y^2\)이 \(p\)의 작은 배수, 결국 \(p\) 자신이 된다. 작은 \(x, y\)는 비둘기집 원리로 찾는다.

증명.먼저 투에 보조정리를 보인다. \(s = \lfloor\sqrt p\rfloor\)라 하자. \(0 \le a, b \le s\)인 쌍 \((a, b)\)는 \((s+1)^2 > p\)개이므로, 비둘기집 원리로 \(a - ub\)의 나머지가 같은 서로 다른 두 쌍 \((a_1, b_1)\), \((a_2, b_2)\)가 있다. \(x = a_1 - a_2\), \(y = b_1 - b_2\)로 두면 \(x \equiv uy \pmod p\), \((x, y) \ne (0, 0)\)이고 \(|x|, |y| \le s < \sqrt p\)이다. 그러면 \(x^2 + y^2 \equiv u^2y^2 + y^2 = (u^2 + 1)y^2 \equiv 0 \pmod p\)이고 \(0 < x^2 + y^2 < 2p\)이다. 따라서 \(x^2 + y^2 = p\)이다. ∎

예제 6.3.2

\(p = 13\)을 두 제곱수의 합으로 나타내는 과정을 따라가라.

풀이. \(5^2 = 25 \equiv -1 \pmod{13}\)이므로 \(u = 5\)이고 \(s = 3\)이다. \((a, b) \in \{0, \dots, 3\}^2\)의 16쌍 가운데 \(a - 5b \bmod 13\)이 같은 두 쌍을 찾는다. 예를 들어 \((3, 1)\)은 \(-2 \equiv 11\)이고 \((0, 3)\)은 \(-15 \equiv 11\)이라 겹친다. 그러므로 \(x = 3 - 0 = 3\), \(y = 1 - 3 = -2\)이고 \(3^2 + 2^2 = 13\)이다. 같은 절의 탐구 카드에서 다른 소수로 해 볼 수 있다.

6.3.3일반 정수

\((a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2\)이다. 이것은 복소수에서 \(|z|^2|w|^2 = |zw|^2\)인 것과 같으므로, 두 제곱수의 합끼리의 곱도 두 제곱수의 합이다. 이로부터 양의 정수 \(n\)이 두 제곱수의 합일 필요충분조건은 소인수분해에서 \(4k + 3\) 꼴 소수의 지수가 모두 짝수인 것이다. 예를 들어 \(45 = 3^2\cdot5 = 36 + 9\)는 되고 \(21 = 3\cdot7\)은 안 된다.

또 부호와 순서까지 센 표현의 개수는 \(r_2(n) = 4(d_1(n) - d_3(n))\)이며, 여기서 \(d_i\)는 법 4로 \(i\)인 약수의 개수이다. 가령 \(65 = 5\cdot13\)은 \(1 + 64\)와 \(16 + 49\)의 부호와 순서를 바꾼 16가지이다. 한편 가우스 정수 \(\mathbb Z[i]\)에서 \(p = (a + bi)(a - bi)\)로 쪼개지는 것이 이 정리의 대수적 의미이다.

흔한 오해\(4k + 1\) 꼴 합성수는 모두 두 제곱수의 합이라고 여기기 쉽지만, \(21 = 3\cdot7 \equiv 1 \pmod 4\)는 아니다. 또 투에 보조정리에서 \(|x|, |y| < \sqrt p\)를 확인하지 않으면 \(x^2 + y^2 = 2p\)의 가능성을 빠뜨린다. 0을 제곱수로 허용하는지도 정해 두어야 하며, 가령 \(9 = 0 + 9\)이다.
마무리

처음 질문에 답하면, 홀수 소수 \(p\)가 두 제곱수의 합일 필요충분조건은 \(p \equiv 1 \pmod 4\)이다. \(4k + 3\) 꼴이 안 되는 것은 법 4로 바로 보이고, \(4k + 1\) 꼴이 되는 것은 \(u^2 \equiv -1\)인 \(u\)와 비둘기집 원리로 작은 해를 찾아 보인다. 일반 정수는 \(4k + 3\) 꼴 소수의 지수가 모두 짝수일 때만 두 제곱수의 합이며, 이것은 두 제곱수의 합끼리의 곱이 다시 두 제곱수의 합이라는 항등식에서 나온다.

6.3.4연습문제

기본

  1. 41, 97을 두 제곱수의 합으로 나타내라.
    답

    \(41 = 16 + 25\), \(97 = 16 + 81\).

응용

  1. \(5 = 1^2 + 2^2\), \(13 = 2^2 + 3^2\)과 곱셈 공식으로 65를 두 가지 방법으로 나타내라.
    답

    \((1\cdot2 - 2\cdot3)^2 + (1\cdot3 + 2\cdot2)^2 = 16 + 49\), \((1\cdot2 + 2\cdot3)^2 + (1\cdot3 - 2\cdot2)^2 = 64 + 1\).

심화

  1. \(p \equiv 3 \pmod 4\)이고 \(p \mid x^2 + y^2\)이면 \(p \mid x\), \(p \mid y\)임을 보여라.
    답

    \(p \nmid y\)이면 \((xy^{-1})^2 \equiv -1\)이라 \(-1\)이 이차 잉여가 되어 \(p \equiv 1 \pmod 4\)와 모순. 따라서 \(p \mid y\), 그러면 \(p \mid x^2\), \(p \mid x\). (이것이 "지수가 짝수"라는 조건의 이유)
