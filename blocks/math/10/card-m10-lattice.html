격자점을 세면 상호법칙이 나온다

탐구 · 아이젠슈타인의 증명

질문

직사각형 \(0 < x < p/2\), \(0 < y < q/2\) 안의 격자점을 대각선으로 둘로 나누어 세면 어떤 수가 나올까요? 그것이 \(\left(\frac qp\right)\), \(\left(\frac pq\right)\)와 어떻게 연결될까요?

복원

홀수 \(a\)에 대해 \(\left(\frac ap\right) = (-1)^{\sum_{k\le(p-1)/2}\lfloor ka/p\rfloor}\). 대각선 아래 격자점 수 = \(\sum\lfloor kq/p\rfloor\) (5.3절).

해 보기

  1. \(p = 7\), \(q = 11\): 아래 8개, 위 7개, 합 \(3\cdot5 = 15\). \(\left(\frac{11}7\right) = (-1)^8 = 1\), \(\left(\frac7{11}\right) = (-1)^7 = -1\) (5.3절 연습문제 2).
  2. 두 소수 중 하나를 \(4k + 1\) 꼴(5, 13, 17, …)로 바꾸면 \(\frac{p-1}2\cdot\frac{q-1}2\)가 짝수가 되어 두 기호가 같아집니다.
  3. 둘 다 \(4k + 3\) 꼴(3, 7, 11, 19, …)이면 곱이 항상 \(-1\)입니다.
  4. 큰 소수(41, 43)로 해도 대각선 위에 놓이는 격자점은 하나도 없습니다.

설명

  1. 세로줄로 세기, 가로줄로 세기\(x = k\)인 세로줄에서 대각선 아래 격자점은 \(\lfloor kq/p\rfloor\)개, \(y = j\)인 가로줄에서 대각선 위 격자점은 \(\lfloor jp/q\rfloor\)개입니다.
  2. 대각선 위에 점이 없다\((x, y)\)가 대각선 위에 있으면 \(py = qx\)인데 \(p, q\)가 서로소라 \(p \mid x\)이어야 하고, \(0 < x < p/2\)라 불가능합니다. 그래서 위·아래 합이 정확히 직사각형의 점 수입니다.

판단

"여러 소수 쌍에서 확인했으니 상호법칙이 증명되었다"는 근거가 될 수 없습니다. 이 카드의 계산은 증명의 각 단계(가우스 보조정리 → 바닥함수 합 → 격자점 세기)가 맞는지 보여 줄 뿐이고, 증명은 모든 \(p, q\)에 통하는 논리입니다.
