나눗셈 정리와 베주 항등식

본문

252와 198의 최대공약수는 18이다. 그런데 252와 198을 정수배해서 더하고 빼면 정확히 18을 만들 수 있을까? 만들 수 있다면 그 방법은 하나뿐일까? 그리고 이 사실이 정수론에서 왜 그렇게 중요할까?

먼저 알아야 할 것정렬 원리와 귀납법(수학2 1.3절), 호제법의 계산(수학3 4.1절)을 쓴다.

1.1.1나눗셈 정리

정수론의 거의 모든 증명은 나누어 나머지를 보는 데서 시작한다. 그래서 초등학교에서 쓰던 이 사실을 정확히 진술하고 증명해 둔다.

정리 1.1.1 (나눗셈 정리)

정수 \(a\)와 양의 정수 \(b\)에 대해 \(a = bq + r\), \(0 \le r < b\)인 정수 \(q, r\)이 유일하게 있다.

증명.먼저 존재를 보인다. \(S = \{a - bk : k \in \mathbb Z,\ a - bk \ge 0\}\)는 \(k = -|a|\)이면 \(a + b|a| \ge 0\)이므로 공집합이 아니다. 정렬 원리로 최솟값 \(r = a - bq\)가 있다. 만약 \(r \ge b\)라면 \(r - b = a - b(q+1) \in S\)가 \(r\)보다 작아 모순이므로 \(0 \le r < b\)이다. 다음으로 \(bq + r = bq' + r'\)이면 \(b(q - q') = r' - r\)이고 \(|r' - r| < b\)이므로 \(q = q'\), \(r = r'\)이다. ∎

1.1.2최대공약수와 베주 항등식

정의 1.1.2

\(b = ac\)인 정수 \(c\)가 있으면 \(a \mid b\)라 쓰고 \(a\)를 \(b\)의 약수라 한다. \(a, b\)가 모두 0은 아닐 때 공약수 가운데 가장 큰 것을 최대공약수 \(\gcd(a, b)\)라 하고, \(\gcd = 1\)이면 서로소라 한다.

정리 1.1.3 (베주 항등식)

\(a, b\)가 모두 0은 아니면 \(\gcd(a, b) = ax + by\)인 정수 \(x, y\)가 있다. 실제로 \(\gcd(a, b)\)는 \(ax + by\) 꼴의 수 가운데 가장 작은 양수이다.

증명의 방향은 이렇다. \(ax + by\) 꼴의 수 전체는 더하고 빼도 닫힌 집합이라 어떤 수 \(d\)의 배수 전체와 같다. 그 \(d\)가 가장 작은 양수이고, 그것이 최대공약수임을 나눗셈 정리로 보인다.

증명.\(a^2 + b^2 > 0\)이므로 \(S = \{ax + by > 0\}\)는 공집합이 아니고, 최솟값 \(d = ax_0 + by_0\)이 있다. \(a = dq + r\) (\(0 \le r < d\))로 나누면 \(r = a - dq = a(1 - qx_0) + b(-qy_0)\)도 \(ax + by\) 꼴이다. \(r > 0\)이면 \(d\)의 최소성에 모순이므로 \(r = 0\), 곧 \(d \mid a\)이다. 같은 방법으로 \(d \mid b\)이다. 또 \(c \mid a\), \(c \mid b\)이면 \(c \mid ax_0 + by_0 = d\)이므로 \(c \le d\)이다. 따라서 \(d = \gcd(a, b)\)이다. ∎

따름정리 1.1.4

(a) 모든 공약수는 \(\gcd(a, b)\)를 나눈다. (b) \(\gcd(a, b) = 1\)일 필요충분조건은 \(ax + by = 1\)인 \(x, y\)가 있는 것이다. (c) \(a \mid bc\)이고 \(\gcd(a, b) = 1\)이면 \(a \mid c\)이다.

(c)의 증명.\(ax + by = 1\)에 \(c\)를 곱하면 \(c = acx + bcy\)이고, 두 항이 모두 \(a\)의 배수이므로 \(a \mid c\)이다. ∎

이 사실이 다음 절의 유일 소인수분해를 떠받친다. 즉 베주 항등식이 중요한 이유는, 서로소라는 조건을 곱셈 관계 \(ax + by = 1\)로 바꿔 계산에 쓸 수 있게 해 주기 때문이다.

1.1.3계산, 호제법을 거꾸로

\(\gcd(a, b) = \gcd(b, a \bmod b)\)를 되풀이하는 유클리드 호제법으로 최대공약수를 구하고, 각 단계의 나머지를 앞의 두 수로 나타내며 거꾸로 올라가면 \(x, y\)를 얻는다.

예제 1.1.5

\(\gcd(252, 198)\)과 \(252x + 198y = \gcd\)인 \(x, y\)를 구하여라.

풀이. \(252 = 1\cdot198 + 54\), \(198 = 3\cdot54 + 36\), \(54 = 1\cdot36 + 18\), \(36 = 2\cdot18\)이므로 최대공약수는 18이다. 거꾸로 올라가면 \(18 = 54 - 36 = 54 - (198 - 3\cdot54) = 4\cdot54 - 198 = 4(252 - 198) - 198 = 4\cdot252 - 5\cdot198\)이다. 검산하면 \(1008 - 990 = 18\)이다. 그런데 해 \((x, y) = (4, -5)\)는 하나가 아니다. \(198/18 = 11\), \(252/18 = 14\)이므로 \((4 + 11t, -5 - 14t)\)가 모두 해이며, 그림 1이 이것이다. 같은 절의 탐구 카드에서 단계를 따라갈 수 있다.

흔한 오해나머지를 음수로 두기 쉽지만, 정리의 나머지는 \(0 \le r < b\)이므로 \(-7 = 3\cdot(-3) + 2\)이다. 또 베주의 \(x, y\)가 유일하다고 여기는 것도 틀렸다. \(a \mid bc\)에서 서로소인지 확인하지 않고 \(a \mid c\)라 결론내는 것도 오해이며, \(6 \mid 4\cdot3\)이지만 \(6 \nmid 4\)이다.
마무리

처음 질문의 답은 "만들 수 있다"이다. 베주 항등식에 따라 \(\gcd(a, b)\)는 \(ax + by\) 꼴의 수 가운데 가장 작은 양수이고, 252와 198에서는 \(18 = 4\cdot252 - 5\cdot198\)이다. 방법은 하나가 아니라 \((4 + 11t, -5 - 14t)\)처럼 무수히 많으며, 하나는 호제법을 거꾸로 올라가 구한다. 이 항등식은 서로소 조건을 계산에 쓸 수 있게 해 \(a \mid bc\)이면 \(a \mid c\)라는 사실을 주고, 그래서 유일 소인수분해의 바탕이 된다.

1.1.4연습문제

기본

  1. \(\gcd(105, 84)\)와 베주 계수를 구하여라.
    답

    \(105 = 84 + 21\), \(84 = 4\cdot21\). 21 \(= 105 - 84\), \((1, -1)\).

응용

  1. \(\gcd(n, n + 1) = 1\)과 \(\gcd(2n + 1, 3n + 1) = 1\)을 보여라.
    답

    \((n+1) - n = 1\). \(3(2n+1) - 2(3n+1) = 1\). 베주 꼴이 1이면 서로소.

심화

  1. 피보나치 수에서 \(\gcd(F_{n+1}, F_n) = 1\)이고, 호제법이 \(F_{n+1}, F_n\)에서 가장 많은 단계를 쓴다는 것(라메 정리)의 뜻을 설명하여라.
    답

    \(F_{n+1} = F_n + F_{n-1}\)이라 각 단계의 몫이 1이고 나머지가 피보나치 수를 하나씩 내려가 \(n - 1\)단계가 걸린다. 몫이 1이면 나머지가 가장 천천히 줄기 때문에 같은 크기의 수 중 최악이다. 단계 수는 작은 수의 자릿수의 약 5배를 넘지 않는다.
