나눗셈 정리와 베주 항등식

본문
이 절에서 배울 것
  • 정렬 원리로 나눗셈 정리(몫과 나머지의 존재와 유일성)를 증명한다.
  • 최대공약수를 정의하고 베주 항등식 \(\gcd(a, b) = ax + by\)를 증명한다.
  • 유클리드 호제법을 거꾸로 따라가 \(x, y\)를 구한다.
먼저 알아야 할 것
  • 정렬 원리와 귀납법 (수학2 1.3절), 호제법의 계산 (수학3 4.1절).

1.1.1나눗셈 정리

정수론의 거의 모든 증명은 "나누어 나머지를 본다"에서 시작합니다. 초등학교에서 쓰던 이 사실을 정확히 진술하고 증명해 둡니다.

정리 1.1.1 (나눗셈 정리)

정수 \(a\)와 양의 정수 \(b\)에 대해 \(a = bq + r\), \(0 \le r < b\)인 정수 \(q, r\)이 유일하게 있다.

존재. \(S = \{a - bk : k \in \mathbb Z,\ a - bk \ge 0\}\)는 공집합이 아니다(\(k = -|a|\)이면 \(a + b|a| \ge 0\)). 정렬 원리로 최솟값 \(r = a - bq\)가 있다. \(r \ge b\)라면 \(r - b = a - b(q+1) \in S\)가 \(r\)보다 작아 모순이므로 \(0 \le r < b\).

유일성. \(bq + r = bq' + r'\)이면 \(b(q - q') = r' - r\)이고 \(|r' - r| < b\)이므로 \(q = q'\), \(r = r'\). ∎

1.1.2최대공약수와 베주 항등식

정의 1.1.2

약수: \(b = ac\)인 정수 \(c\)가 있으면 \(a \mid b\).

최대공약수 \(\gcd(a, b)\): \(a, b\)가 모두 0은 아닐 때 공약수 중 가장 큰 것. \(\gcd = 1\)이면 서로소.

정리 1.1.3 (베주 항등식)

\(a, b\)가 모두 0은 아니면 \(\gcd(a, b) = ax + by\)인 정수 \(x, y\)가 있다. 실제로 \(\gcd(a, b)\)는 \(\{ax + by\}\) 중 가장 작은 양수이다.

증명 아이디어: \(ax + by\) 꼴의 수 전체는 "더하고 빼도 닫힌" 집합이라 어떤 수 \(d\)의 배수 전체와 같습니다. 그 \(d\)가 가장 작은 양수이고, 그것이 최대공약수임을 나눗셈 정리로 보입니다.

\(S = \{ax + by > 0\}\)는 공집합이 아니므로(\(a^2 + b^2 > 0\)) 최솟값 \(d = ax_0 + by_0\)이 있다. \(a = dq + r\) (\(0 \le r < d\))로 나누면 \(r = a - dq = a(1 - qx_0) + b(-qy_0)\)도 \(ax + by\) 꼴이다. \(r > 0\)이면 \(d\)의 최소성에 모순이므로 \(r = 0\), 곧 \(d \mid a\). 같은 방법으로 \(d \mid b\). 또 \(c \mid a\), \(c \mid b\)이면 \(c \mid ax_0 + by_0 = d\)이므로 \(c \le d\). 따라서 \(d = \gcd(a, b)\). ∎

따름정리 1.1.4

(a) 모든 공약수는 \(\gcd(a, b)\)를 나눈다. (b) \(\gcd(a, b) = 1\) ⇔ \(ax + by = 1\)인 \(x, y\)가 있다. (c) \(a \mid bc\)이고 \(\gcd(a, b) = 1\)이면 \(a \mid c\).

(c)의 증명: \(ax + by = 1\)에 \(c\)를 곱하면 \(c = acx + bcy\)이고 두 항이 모두 \(a\)의 배수입니다. 이 사실이 다음 절의 유일 소인수분해를 떠받칩니다.

1.1.3계산: 호제법을 거꾸로

\(\gcd(a, b) = \gcd(b, a \bmod b)\)를 되풀이하는 유클리드 호제법으로 최대공약수를 구하고, 각 단계의 나머지를 앞의 두 수로 나타내며 거꾸로 올라가면 \(x, y\)를 얻습니다.

예제 1.1.5

\(\gcd(252, 198)\)과 \(252x + 198y = \gcd\)인 \(x, y\)를 구하여라.

풀이. \(252 = 1\cdot198 + 54\), \(198 = 3\cdot54 + 36\), \(54 = 1\cdot36 + 18\), \(36 = 2\cdot18\). 최대공약수 18. 거꾸로: \(18 = 54 - 36 = 54 - (198 - 3\cdot54) = 4\cdot54 - 198 = 4(252 - 198) - 198 = 4\cdot252 - 5\cdot198\). 검산 \(1008 - 990 = 18\). 해 \((x, y) = (4, -5)\)은 하나가 아니라 \((4 + 11t, -5 - 14t)\)가 모두 해입니다(\(198/18 = 11\), \(252/18 = 14\)). 같은 절의 탐구 카드에서 단계를 따라갈 수 있습니다.

흔한 실수(1) 나머지를 음수로 둔다(\(-7 = 3\cdot(-2) - 1\)): 정리의 나머지는 \(0 \le r < b\)이므로 \(-7 = 3\cdot(-3) + 2\). (2) 베주의 \(x, y\)가 유일하다고 여긴다. (3) \(a \mid bc\)에서 서로소 확인 없이 \(a \mid c\)라 결론낸다(\(6 \mid 4\cdot3\)이지만 \(6 \nmid 4\)).
요약
  1. 나눗셈 정리: 정렬 원리로 존재, 크기 비교로 유일.
  2. \(\gcd(a, b)\) = \(\{ax + by\}\)의 최소 양수. 공약수는 모두 그것을 나눈다.
  3. 호제법을 거꾸로 올라가 베주 계수를 구한다. 해는 무수히 많다.

1.1.4연습문제

기본

  1. \(\gcd(105, 84)\)와 베주 계수를 구하여라.
    답

    \(105 = 84 + 21\), \(84 = 4\cdot21\). 21 \(= 105 - 84\), \((1, -1)\).

응용

  1. \(\gcd(n, n + 1) = 1\)과 \(\gcd(2n + 1, 3n + 1) = 1\)을 보여라.
    답

    \((n+1) - n = 1\). \(3(2n+1) - 2(3n+1) = 1\). 베주 꼴이 1이면 서로소.

심화

  1. 피보나치 수에서 \(\gcd(F_{n+1}, F_n) = 1\)이고, 호제법이 \(F_{n+1}, F_n\)에서 가장 많은 단계를 쓴다는 것(라메 정리)의 뜻을 설명하여라.
    답

    \(F_{n+1} = F_n + F_{n-1}\)이라 각 단계의 몫이 1이고 나머지가 피보나치 수를 하나씩 내려가 \(n - 1\)단계가 걸린다. 몫이 1이면 나머지가 가장 천천히 줄기 때문에 같은 크기의 수 중 최악이다. 단계 수는 작은 수의 자릿수의 약 5배를 넘지 않는다.
