피타고라스 세 수

본문

\(3^2 + 4^2 = 5^2\), \(5^2 + 12^2 = 13^2\), \(8^2 + 15^2 = 17^2\)이다. 이런 자연수 세 쌍은 모두 어떤 공식으로 만들 수 있을까? 그리고 제곱을 네제곱으로 바꾼 \(x^4 + y^4 = z^4\)에도 해가 있을까?

먼저 알아야 할 것산술의 기본정리(1.2절), 홀짝과 합동(2.1절)을 쓴다.

6.2.1원시 세 수

정의 6.2.1

\(x^2 + y^2 = z^2\)인 양의 정수 \((x, y, z)\)를 피타고라스 세 수라 하고, \(\gcd(x, y, z) = 1\)이면 원시라 한다.

모든 세 수는 원시 세 수의 배수이므로 원시인 것만 찾으면 된다. 원시이면 \(x, y\)는 서로소이고 정확히 하나가 짝수이다. 왜냐하면 둘 다 홀수이면 \(x^2 + y^2 \equiv 2 \pmod 4\)인데, 제곱수는 법 4로 0 또는 1이라 \(z^2\)이 될 수 없기 때문이다.

정리 6.2.2

\(y\)가 짝수인 원시 세 수는 정확히 \(x = m^2 - n^2\), \(y = 2mn\), \(z = m^2 + n^2\)이다. 여기서 \(m > n > 0\), \(\gcd(m, n) = 1\)이고 \(m - n\)은 홀수이다.

증명.\(y^2 = z^2 - x^2 = (z - x)(z + x)\)이다. \(x, z\)가 홀수라 \(z \pm x\)는 짝수이고 \(\left(\frac y2\right)^2 = \frac{z-x}2\cdot\frac{z+x}2\)이다. 두 인수의 공약수는 합 \(z\)와 차 \(x\)를 나누므로, 원시 조건에서 1이다. 그런데 서로소인 두 수의 곱이 제곱수이면 소인수분해의 지수가 모두 짝수여야 하므로 각각 제곱수이다. 따라서 \(\frac{z+x}2 = m^2\), \(\frac{z-x}2 = n^2\), 곧 \(z = m^2 + n^2\), \(x = m^2 - n^2\), \(y = 2mn\)이다. \(\gcd(m, n) = 1\)이고 \(x\)가 홀수이므로 \(m, n\)의 짝홀이 다르다. 역으로 이 꼴이 원시 세 수임은 계산으로 확인한다. ∎

예를 들어 \((m, n) = (2, 1), (3, 2), (4, 1), (4, 3), (5, 2)\)에서 \((3, 4, 5), (5, 12, 13), (15, 8, 17), (7, 24, 25), (21, 20, 29)\)를 얻는다. 빗변이 100보다 작은 원시 세 수는 16개이며, 그림 1의 점들이 이것이다.

6.2.2기하학, 단위원의 유리점

\(x^2 + y^2 = z^2\)을 \(z^2\)으로 나누면 단위원 \(X^2 + Y^2 = 1\) 위의 유리점이 된다. 이제 점 \((-1, 0)\)을 지나는 기울기 \(t\)의 직선 \(Y = t(X + 1)\)을 보자. 이 직선은 원과 한 점에서 더 만나고, 대입하면 \(X = \frac{1 - t^2}{1 + t^2}\), \(Y = \frac{2t}{1 + t^2}\)이다. 그러므로 \(t\)가 유리수일 필요충분조건은 그 점이 유리점인 것이다. \(t = n/m\)이면 점은 \(\left(\frac{m^2 - n^2}{m^2 + n^2}, \frac{2mn}{m^2 + n^2}\right)\)이고, 이것이 바로 위 정리의 공식이다. 같은 절의 탐구 카드에서 기울기를 움직여 볼 수 있다.

6.2.3무한강하법

정리 6.2.3 (페르마)

\(x^4 + y^4 = z^2\)은 양의 정수해가 없다. 따라서 \(x^4 + y^4 = z^4\)도 해가 없다.

증명의 흐름은 이렇다. 해가 있다면 \(z\)가 가장 작은 해를 잡는다. \((x^2)^2 + (y^2)^2 = z^2\)은 피타고라스 세 수이므로 정리 6.2.2의 매개화를 두 번 적용하면, \(z\)보다 작은 \(z'\)을 가진 새 해가 만들어진다. 이것은 최소성에 모순이다. 다시 말해 "해가 있으면 더 작은 해가 있다"는 것과 양의 정수는 끝없이 작아질 수 없다는 사실을 맞세우는 것이며, 페르마가 남긴 몇 안 되는 완전한 증명이다.

흔한 오해\(m, n\)이 모두 홀수인 경우를 넣기 쉽지만, \((3, 1)\)은 \((8, 6, 10)\)이라 원시가 아니다. 또 \(x\)와 \(y\) 가운데 어느 쪽이 짝수인지 정하지 않으면 같은 세 수를 두 번 센다. "서로소인 두 수의 곱이 제곱이면 각각 제곱"을 서로소가 아닐 때 쓰는 것도 틀렸으며, \(2\cdot8 = 16\)이 반례이다.
마무리

처음 질문에 답하면, 원시 피타고라스 세 수는 모두 \((m^2 - n^2, 2mn, m^2 + n^2)\)으로 만들 수 있고, \(m > n\)은 서로소이며 짝홀이 다르다. 증명은 \((y/2)^2\)을 서로소인 두 수의 곱으로 쓰고 각각이 제곱수임을 쓰는 것이다. 기하로 보면 \((-1, 0)\)을 지나는 유리 기울기의 직선이 단위원의 유리점을 모두 준다. 반면 \(x^4 + y^4 = z^4\)은 무한강하법으로 해가 없다.

6.2.4연습문제

기본

  1. \((m, n) = (6, 1), (7, 4)\)에서 세 수를 구하여라.
    답

    \((35, 12, 37)\), \((33, 56, 65)\).

응용

  1. 원시 세 수에서 \(xy\)는 12의 배수임을 보여라.
    답

    \(xy = 2mn(m^2 - n^2)\). \(m, n\) 중 하나는 짝수라 \(4 \mid 2mn\). 3으로 \(m, n\) 중 하나가 나누어지거나, 아니면 \(m^2 \equiv n^2 \equiv 1\)이라 \(3 \mid m^2 - n^2\).

심화

  1. \(z = 65\)인 원시 세 수를 모두 구하여라.
    답

    \(m^2 + n^2 = 65\): \((8, 1)\), \((7, 4)\). \((63, 16, 65)\), \((33, 56, 65)\). 65 = 5·13이 두 제곱수의 합으로 두 가지로 쓰이기 때문(6.3절).
