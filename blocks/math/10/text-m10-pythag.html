피타고라스 세 수

본문
이 절에서 배울 것
  • 원시 피타고라스 세 수의 매개화 \((m^2 - n^2, 2mn, m^2 + n^2)\)를 유도한다.
  • 같은 결과를 단위원 위의 유리점(직선 긋기)으로 이해한다.
  • 무한강하법으로 \(x^4 + y^4 = z^2\)에 자명하지 않은 해가 없음을 보인다.
먼저 알아야 할 것
  • 산술의 기본정리 (1.2절), 홀짝과 합동 (2.1절).

6.2.1원시 세 수

정의 6.2.1

피타고라스 세 수: \(x^2 + y^2 = z^2\)인 양의 정수 \((x, y, z)\). \(\gcd(x, y, z) = 1\)이면 원시.

모든 세 수는 원시 세 수의 배수이므로 원시인 것만 찾으면 됩니다. 원시이면 \(x, y\)는 서로소이고 정확히 하나가 짝수입니다: 둘 다 홀수이면 \(x^2 + y^2 \equiv 2 \pmod 4\)인데 제곱수는 0 또는 1 (mod 4)이라 불가능합니다.

정리 6.2.2

\(y\)가 짝수인 원시 세 수는 정확히 \(x = m^2 - n^2\), \(y = 2mn\), \(z = m^2 + n^2\)이다. 여기서 \(m > n > 0\), \(\gcd(m, n) = 1\), \(m - n\)은 홀수.

\(y^2 = z^2 - x^2 = (z - x)(z + x)\). \(x, z\)가 홀수라 \(z \pm x\)는 짝수이고 \(\left(\frac y2\right)^2 = \frac{z-x}2\cdot\frac{z+x}2\). 두 인수의 공약수는 합 \(z\)와 차 \(x\)를 나누므로 1이다(원시). 서로소인 두 수의 곱이 제곱수이면 각각 제곱수이다(소인수분해의 지수가 짝수). 따라서 \(\frac{z+x}2 = m^2\), \(\frac{z-x}2 = n^2\), 곧 \(z = m^2 + n^2\), \(x = m^2 - n^2\), \(y = 2mn\). \(\gcd(m, n) = 1\)이고 \(x\)가 홀수라 \(m, n\)의 짝홀이 다르다. 역으로 이 꼴은 계산으로 원시 세 수임을 확인한다. ∎

\((m, n) = (2, 1), (3, 2), (4, 1), (4, 3), (5, 2)\)에서 \((3, 4, 5), (5, 12, 13), (15, 8, 17), (7, 24, 25), (21, 20, 29)\). 빗변이 100보다 작은 원시 세 수는 16개입니다.

6.2.2기하학: 단위원의 유리점

\(x^2 + y^2 = z^2\)을 \(z^2\)으로 나누면 단위원 \(X^2 + Y^2 = 1\) 위의 유리점이 됩니다. 점 \((-1, 0)\)을 지나는 기울기 \(t\)의 직선 \(Y = t(X + 1)\)은 원과 한 점에서 더 만나고, 대입하면 \(X = \frac{1 - t^2}{1 + t^2}\), \(Y = \frac{2t}{1 + t^2}\)입니다. \(t\)가 유리수 ⇔ 그 점이 유리점이고, \(t = n/m\)이면 \(\left(\frac{m^2 - n^2}{m^2 + n^2}, \frac{2mn}{m^2 + n^2}\right)\): 위 정리의 공식입니다. 같은 절의 탐구 카드에서 기울기를 움직여 볼 수 있습니다.

6.2.3무한강하법

정리 6.2.3 (페르마)

\(x^4 + y^4 = z^2\)은 양의 정수해가 없다. 따라서 \(x^4 + y^4 = z^4\)도 해가 없다.

증명의 흐름: 해가 있다면 \(z\)가 가장 작은 해를 잡습니다. \((x^2)^2 + (y^2)^2 = z^2\)은 원시 세 수이므로 정리 6.2.2의 매개화를 두 번 적용하면 \(z\)보다 작은 \(z'\)을 가진 새 해가 만들어집니다. 최소성에 모순입니다. "해가 있으면 더 작은 해가 있다"는 무한히 내려갈 수 없는 양의 정수의 성질이 핵심이며, 페르마가 남긴 몇 안 되는 완전한 증명입니다.

흔한 실수(1) \(m, n\)이 모두 홀수인 경우를 넣는다: \((3, 1)\)은 \((8, 6, 10)\)으로 원시가 아니다. (2) \(x\)와 \(y\) 중 어느 쪽이 짝수인지 정하지 않아 같은 세 수를 두 번 센다. (3) "서로소인 두 수의 곱이 제곱이면 각각 제곱"을 서로소가 아닐 때 쓴다(\(2\cdot8 = 16\)).
요약
  1. 원시 세 수 = \((m^2 - n^2, 2mn, m^2 + n^2)\), \(m > n\), 서로소, 짝홀 다름.
  2. 증명: \((y/2)^2 = \frac{z-x}2\cdot\frac{z+x}2\), 서로소인 두 인수가 각각 제곱.
  3. 단위원 유리점 = 유리 기울기 직선. 무한강하로 \(x^4 + y^4 = z^2\)은 해가 없다.

6.2.4연습문제

기본

  1. \((m, n) = (6, 1), (7, 4)\)에서 세 수를 구하여라.
    답

    \((35, 12, 37)\), \((33, 56, 65)\).

응용

  1. 원시 세 수에서 \(xy\)는 12의 배수임을 보여라.
    답

    \(xy = 2mn(m^2 - n^2)\). \(m, n\) 중 하나는 짝수라 \(4 \mid 2mn\). 3으로 \(m, n\) 중 하나가 나누어지거나, 아니면 \(m^2 \equiv n^2 \equiv 1\)이라 \(3 \mid m^2 - n^2\).

심화

  1. \(z = 65\)인 원시 세 수를 모두 구하여라.
    답

    \(m^2 + n^2 = 65\): \((8, 1)\), \((7, 4)\). \((63, 16, 65)\), \((33, 56, 65)\). 65 = 5·13이 두 제곱수의 합으로 두 가지로 쓰이기 때문(6.3절).
