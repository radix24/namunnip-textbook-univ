약수는 격자를 이룬다

탐구 · 곱셈적 함수 τ, σ, φ

질문

\(n = 2^a3^b\)의 약수를 지수에 따라 늘어놓으면 어떤 모양일까? 그 모양에서 약수의 개수와 합의 공식이 곱으로 나오는 이유가 보일까?

복원

\(\tau(n) = \prod(e_i + 1)\), \(\sigma(n) = \prod\frac{p_i^{e_i+1} - 1}{p_i - 1}\), \(\varphi(n) = n\prod(1 - 1/p_i)\), \(\sum_{d\mid n}\varphi(d) = n\) (3.1절).

해 보기

  1. \(n = 360 = 2^3\cdot3^2\cdot5\): 가로 4칸 × 세로 3칸 판이 2장(5의 지수 0, 1)이라 \(\tau = 24\). \(\sigma = 1170\), \(\varphi = 96\).
  2. \(n = 496\)이나 \(n = 28\)로 바꾸면 \(\sigma(n) = 2n\)인 완전수이다.
  3. \(n\)을 소수로 바꾸면 격자가 두 점뿐이고 \(\varphi(p) = p - 1\)이다.
  4. 어떤 \(n\)이든 \(\sum\varphi(d) = n\)이 성립하는지 확인하자.

설명

  1. 격자 = 곱약수는 각 소수의 지수를 독립으로 고른 것이라, 약수 전체는 사슬들의 곱(직사각형 격자)이다. 칸의 수가 \(\prod(e_i + 1)\)이고, 칸의 합은 각 사슬의 합의 곱 \(\prod(1 + p + \cdots + p^e)\)으로 전개된다.
  2. 곱셈성의 그림서로소인 \(m, n\)의 격자는 서로 다른 방향의 사슬로 이루어져 \(mn\)의 격자는 두 격자의 곱이 된다. 그래서 \(\tau(mn) = \tau(m)\tau(n)\)이다.

판단

"\(\varphi(12) = \varphi(2)\varphi(6) = 1\cdot2 = 2\)"는 틀린다. 2와 6은 서로소가 아니라 곱셈성을 쓸 수 없다. 올바르게는 \(\varphi(4)\varphi(3) = 2\cdot2 = 4\).
