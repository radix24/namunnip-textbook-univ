곱셈적 함수: φ, τ, σ

본문
이 절에서 배울 것
  • 곱셈적 함수를 정의하고, 곱셈적 함수의 약수 합도 곱셈적임을 증명한다.
  • 약수의 개수 \(\tau\), 약수의 합 \(\sigma\), 오일러 함수 \(\varphi\)가 곱셈적임을 보이고 공식을 얻는다.
  • 완전수와 \(\sum_{d\mid n}\varphi(d) = n\)을 이해한다.
먼저 알아야 할 것
  • 산술의 기본정리 (1.2절), 중국인의 나머지 정리 (2.2절).

3.1.1수론함수와 곱셈성

정의 3.1.1

수론함수: 양의 정수에서 정의된 함수.

곱셈적: \(f(1) = 1\)이고 \(\gcd(m, n) = 1\)이면 \(f(mn) = f(m)f(n)\).

예: \(\tau(n)\) = 양의 약수의 개수, \(\sigma(n)\) = 양의 약수의 합, \(\varphi(n)\) = \(n\) 이하 \(n\)과 서로소인 수의 개수.

곱셈적 함수는 소수 거듭제곱에서의 값만 알면 모든 값을 압니다: \(n = p_1^{e_1}\cdots p_k^{e_k}\)이면 \(f(n) = f(p_1^{e_1})\cdots f(p_k^{e_k})\). 그래서 공식을 얻는 일은 두 단계입니다: 곱셈적임을 보이고, 소수 거듭제곱에서 계산합니다.

3.1.2약수 합의 곱셈성

정리 3.1.2

\(f\)가 곱셈적이면 \(F(n) = \sum_{d\mid n}f(d)\)도 곱셈적이다.

\(\gcd(m, n) = 1\)이면 \(mn\)의 약수 \(d\)는 \(d = d_1d_2\) (\(d_1 \mid m\), \(d_2 \mid n\))로 유일하게 쓰인다(소인수를 \(m\) 쪽과 \(n\) 쪽으로 나눔). 이때 \(\gcd(d_1, d_2) = 1\)이므로 \(F(mn) = \sum_{d_1\mid m}\sum_{d_2\mid n}f(d_1)f(d_2) = F(m)F(n)\). ∎

상수함수 1은 곱셈적이고 \(\tau = \sum_{d\mid n}1\), 항등함수 \(n\)도 곱셈적이고 \(\sigma = \sum_{d\mid n}d\)이므로 둘 다 곱셈적입니다. 소수 거듭제곱에서 \(\tau(p^e) = e + 1\), \(\sigma(p^e) = 1 + p + \cdots + p^e = \frac{p^{e+1} - 1}{p - 1}\).

예제 3.1.3

\(n = 360 = 2^3\cdot3^2\cdot5\)의 \(\tau\), \(\sigma\), \(\varphi\)를 구하여라.

풀이. \(\tau = 4\cdot3\cdot2 = 24\). \(\sigma = 15\cdot13\cdot6 = 1170\). \(\varphi\)는 다음 정리로 \(360\cdot\frac12\cdot\frac23\cdot\frac45 = 96\).

3.1.3오일러 함수

정리 3.1.4

\(\varphi\)는 곱셈적이고 \(\varphi(p^e) = p^e - p^{e-1}\). 따라서 \(\varphi(n) = n\prod_{p\mid n}\left(1 - \frac1p\right)\).

곱셈성: 중국인의 나머지 정리의 전단사 \(\mathbb Z_{mn} \to \mathbb Z_m\times\mathbb Z_n\), \(x \mapsto (x \bmod m, x \bmod n)\)에서 \(x\)가 \(mn\)과 서로소 ⇔ \(x \bmod m\)이 \(m\)과, \(x \bmod n\)이 \(n\)과 서로소. 따라서 기약 잉여끼리 일대일 대응이라 \(\varphi(mn) = \varphi(m)\varphi(n)\). 소수 거듭제곱: \(1, \dots, p^e\) 중 \(p\)의 배수 \(p^{e-1}\)개를 뺀다. ∎

정리 3.1.5 (가우스)

\(\sum_{d\mid n}\varphi(d) = n\).

증명: 분수 \(\frac1n, \frac2n, \dots, \frac nn\)을 기약분수로 고치면 분모는 \(n\)의 약수 \(d\)이고, 분모가 \(d\)인 것은 분자가 \(d\)와 서로소인 \(\varphi(d)\)개입니다. 예: \(n = 36\)이면 \(\varphi(1) + \varphi(2) + \varphi(3) + \varphi(4) + \varphi(6) + \varphi(9) + \varphi(12) + \varphi(18) + \varphi(36) = 1 + 1 + 2 + 2 + 2 + 6 + 4 + 6 + 12 = 36\).

3.1.4완전수

\(\sigma(n) = 2n\)인 수를 완전수라 합니다: 6, 28, 496, 8128. 유클리드는 \(2^p - 1\)이 소수이면 \(2^{p-1}(2^p - 1)\)이 완전수임을 보였고, 오일러는 짝수 완전수가 모두 이 꼴임을 증명했습니다. \(\sigma\)의 곱셈성으로 \(\sigma(2^{p-1}(2^p-1)) = (2^p - 1)\cdot2^p\)이 바로 확인됩니다. 홀수 완전수가 있는지는 아직 모릅니다. 같은 절의 탐구 카드에서 약수 구조를 볼 수 있습니다.

흔한 실수(1) 서로소가 아닐 때도 곱해 버린다: \(\varphi(4) = 2 \ne \varphi(2)^2 = 1\). (2) \(\sigma(p^e) = p^e + 1\)로 쓴다: 모든 거듭제곱의 합이다. (3) \(\varphi(n)\) 공식에서 지수를 곱한다: 곱하는 것은 서로 다른 소인수마다 \((1 - 1/p)\)이다.
요약
  1. 곱셈적 함수는 소수 거듭제곱 값으로 결정된다. 곱셈적 함수의 약수 합도 곱셈적.
  2. \(\tau(p^e) = e + 1\), \(\sigma(p^e) = \frac{p^{e+1}-1}{p-1}\), \(\varphi(p^e) = p^e - p^{e-1}\).
  3. \(\sum_{d\mid n}\varphi(d) = n\). 짝수 완전수 = \(2^{p-1}(2^p - 1)\), \(2^p - 1\) 소수.

3.1.5연습문제

기본

  1. \(\tau(100)\), \(\sigma(100)\), \(\varphi(100)\)은?
    답

    \(100 = 2^25^2\). \(\tau = 9\), \(\sigma = 7\cdot31 = 217\), \(\varphi = 40\).

응용

  1. \(\tau(n)\)이 홀수일 필요충분조건은 \(n\)이 완전제곱수임을 보여라.
    답

    \(\tau = \prod(e_i + 1)\)이 홀수 ⇔ 모든 \(e_i\)가 짝수 ⇔ 완전제곱. (약수를 \(d\), \(n/d\)로 짝지으면 \(d = \sqrt n\)일 때만 짝이 없다.)

심화

  1. \(\varphi(n) = 12\)인 \(n\)을 모두 구하여라.
    답

    13, 21, 26, 28, 36, 42. (소인수 \(p\)는 \(p - 1 \mid 12\)인 2, 3, 5, 7, 13 중에서 고르고 경우를 나눈다.)
