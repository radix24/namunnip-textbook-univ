곱셈적 함수: φ, τ, σ

본문

360의 약수는 몇 개이고, 그 합은 얼마일까? 360 이하에서 360과 서로소인 수는 몇 개일까? 약수를 하나하나 적지 않고 소인수분해 \(2^3\cdot3^2\cdot5\)만 보고 셀 수 있을까?

먼저 알아야 할 것산술의 기본정리(1.2절), 중국인의 나머지 정리(2.2절)를 쓴다.

3.1.1수론함수와 곱셈성

정의 3.1.1

양의 정수에서 정의된 함수를 수론함수라 한다. \(f(1) = 1\)이고 \(\gcd(m, n) = 1\)일 때마다 \(f(mn) = f(m)f(n)\)이면 \(f\)를 곱셈적이라 한다. 양의 약수의 개수를 \(\tau(n)\), 양의 약수의 합을 \(\sigma(n)\)이라 쓴다.

곱셈적 함수는 소수 거듭제곱에서의 값만 알면 모든 값을 안다. \(n = p_1^{e_1}\cdots p_k^{e_k}\)이면 \(f(n) = f(p_1^{e_1})\cdots f(p_k^{e_k})\)이기 때문이다. 그러므로 공식을 얻는 일은 두 단계이다. 먼저 곱셈적임을 보이고, 다음으로 소수 거듭제곱에서 계산한다.

3.1.2약수 합의 곱셈성

정리 3.1.2

\(f\)가 곱셈적이면 \(F(n) = \sum_{d\mid n}f(d)\)도 곱셈적이다.

증명.\(\gcd(m, n) = 1\)이면 \(mn\)의 약수 \(d\)는 소인수를 \(m\) 쪽과 \(n\) 쪽으로 나누어 \(d = d_1d_2\) (\(d_1 \mid m\), \(d_2 \mid n\))로 유일하게 쓰인다. 이때 \(\gcd(d_1, d_2) = 1\)이므로 \(F(mn) = \sum_{d_1\mid m}\sum_{d_2\mid n}f(d_1)f(d_2) = F(m)F(n)\)이다. ∎

상수함수 1과 항등함수 \(n\)은 곱셈적이고 \(\tau = \sum_{d\mid n}1\), \(\sigma = \sum_{d\mid n}d\)이다. 따라서 \(\tau\)와 \(\sigma\)도 곱셈적이며, 소수 거듭제곱에서는 \(\tau(p^e) = e + 1\), \(\sigma(p^e) = 1 + p + \cdots + p^e = \frac{p^{e+1} - 1}{p - 1}\)이다.

예제 3.1.3

\(n = 360 = 2^3\cdot3^2\cdot5\)의 \(\tau\), \(\sigma\), \(\varphi\)를 구하여라.

풀이. \(\tau = 4\cdot3\cdot2 = 24\)이고 \(\sigma = 15\cdot13\cdot6 = 1170\)이다. \(\varphi\)는 다음 정리로 \(360\cdot\frac12\cdot\frac23\cdot\frac45 = 96\)이다.

3.1.3오일러 함수

정리 3.1.4

\(\varphi\)는 곱셈적이고 \(\varphi(p^e) = p^e - p^{e-1}\)이다. 따라서 \(\varphi(n) = n\prod_{p\mid n}\left(1 - \frac1p\right)\)이다.

증명.중국인의 나머지 정리의 전단사 \(\mathbb Z_{mn} \to \mathbb Z_m\times\mathbb Z_n\), \(x \mapsto (x \bmod m, x \bmod n)\)을 보자. \(x\)가 \(mn\)과 서로소일 필요충분조건은 \(x \bmod m\)이 \(m\)과, \(x \bmod n\)이 \(n\)과 서로소인 것이다. 따라서 기약 잉여끼리 일대일로 대응해 \(\varphi(mn) = \varphi(m)\varphi(n)\)이다. 또 \(1, \dots, p^e\) 가운데 \(p\)의 배수 \(p^{e-1}\)개를 빼면 \(\varphi(p^e)\)이다. ∎

정리 3.1.5 (가우스)

\(\sum_{d\mid n}\varphi(d) = n\)이다.

증명.분수 \(\frac1n, \frac2n, \dots, \frac nn\)을 기약분수로 고치면 분모는 \(n\)의 약수 \(d\)이다. 분모가 \(d\)인 것은 분자가 \(d\) 이하이고 \(d\)와 서로소인 것이므로 \(\varphi(d)\)개이다. 이 개수를 모두 더하면 분수의 총 개수 \(n\)이다. ∎

예를 들어 \(n = 12\)이면 \(\varphi(1) + \varphi(2) + \varphi(3) + \varphi(4) + \varphi(6) + \varphi(12) = 1 + 1 + 2 + 2 + 2 + 4 = 12\)이다. 이 항등식은 4.2절에서 원시근의 개수를 셀 때 다시 쓴다.

3.1.4완전수

\(\sigma(n) = 2n\)인 수를 완전수라 하며, 6, 28, 496, 8128이 그 예이다. 유클리드는 \(2^p - 1\)이 소수이면 \(2^{p-1}(2^p - 1)\)이 완전수임을 보였는데, \(\sigma\)의 곱셈성으로 \(\sigma(2^{p-1}(2^p-1)) = (2^p - 1)\cdot2^p\)이 바로 확인된다. 자세한 것은 3.3절에서 다룬다. 같은 절의 탐구 카드에서 약수 구조를 볼 수 있다.

흔한 오해서로소가 아닐 때도 값을 곱해 버리는 실수가 많다. 가령 \(\varphi(4) = 2\)이지만 \(\varphi(2)^2 = 1\)이다. 또 \(\sigma(p^e) = p^e + 1\)로 쓰기 쉽지만 모든 거듭제곱의 합이다. \(\varphi(n)\) 공식에서 지수만큼 곱하는 것도 틀렸으며, 서로 다른 소인수마다 \((1 - 1/p)\)를 한 번씩 곱한다.
마무리

처음 질문의 답은 "셀 수 있다"이다. \(\tau\), \(\sigma\), \(\varphi\)가 모두 곱셈적이므로 소수 거듭제곱의 값만 곱하면 되고, 360에서는 약수 24개, 약수의 합 1170, 서로소인 수 96개이다. 곱셈성은 약수를 두 쪽으로 나누는 논증과 중국인의 나머지 정리에서 나온다. 공식은 \(\tau(p^e) = e + 1\), \(\sigma(p^e) = \frac{p^{e+1}-1}{p-1}\), \(\varphi(p^e) = p^e - p^{e-1}\)이며, 덧붙여 \(\sum_{d\mid n}\varphi(d) = n\)이다.

3.1.5연습문제

기본

  1. \(\tau(100)\), \(\sigma(100)\), \(\varphi(100)\)은?
    답

    \(100 = 2^25^2\). \(\tau = 9\), \(\sigma = 7\cdot31 = 217\), \(\varphi = 40\).

응용

  1. \(\tau(n)\)이 홀수일 필요충분조건은 \(n\)이 완전제곱수임을 보여라.
    답

    \(\tau = \prod(e_i + 1)\)이 홀수 ⇔ 모든 \(e_i\)가 짝수 ⇔ 완전제곱. (약수를 \(d\), \(n/d\)로 짝지으면 \(d = \sqrt n\)일 때만 짝이 없다.)

심화

  1. \(\varphi(n) = 12\)인 \(n\)을 모두 구하여라.
    답

    13, 21, 26, 28, 36, 42. (소인수 \(p\)는 \(p - 1 \mid 12\)인 2, 3, 5, 7, 13 중에서 고르고 경우를 나눈다.)
