√7의 연분수를 정수만으로 전개하기

예제 · 이차 무리수의 순환

먼저 예측

\(\sqrt7 \approx 2.6458\)의 연분수는 끝없이 이어진다. 언젠가 되풀이될까? 되풀이된다면 마지막 부분몫은 무엇일까?

예측 확인

되풀이된다. 주기 \(1, 1, 1, 4\)이고 마지막은 \(2a_0 = 4\)이다.

\((m, d, a)\) 점화식으로 \(\sqrt7\)을 전개하고, 순환함을 확인한 뒤 그 연분수로 정의되는 수가 \(\sqrt7\)임을 검산하여라.

전략

완전몫을 \(x_k = \frac{\sqrt7 + m_k}{d_k}\)로 유지하며 \(m_{k+1} = d_ka_k - m_k\), \(d_{k+1} = (7 - m_{k+1}^2)/d_k\), \(a_{k+1} = \lfloor(2 + m_{k+1})/d_{k+1}\rfloor\)을 되풀이합니다(7.2절). \((m, d)\)가 반복되면 그 뒤도 반복된다.

풀이

  1. \(a_0 = \lfloor\sqrt7\rfloor = 2\), \((m_0, d_0) = (0, 1)\).
    \(x_0 = \sqrt7\).
  2. \(m_1 = 1\cdot2 - 0 = 2\), \(d_1 = (7 - 4)/1 = 3\), \(a_1 = \lfloor4/3\rfloor = 1\).
    \(x_1 = \frac{\sqrt7 + 2}3 \approx 1.55\).
  3. \(m_2 = 3\cdot1 - 2 = 1\), \(d_2 = (7 - 1)/3 = 2\), \(a_2 = \lfloor3/2\rfloor = 1\).
    \(x_2 = \frac{\sqrt7 + 1}2 \approx 1.82\).
  4. \(m_3 = 2\cdot1 - 1 = 1\), \(d_3 = (7 - 1)/2 = 3\), \(a_3 = \lfloor3/3\rfloor = 1\).
    \(x_3 = \frac{\sqrt7 + 1}3 \approx 1.22\).
  5. \(m_4 = 3\cdot1 - 1 = 2\), \(d_4 = (7 - 4)/3 = 1\), \(a_4 = \lfloor4/1\rfloor = 4\). 다음은 \(m_5 = 1\cdot4 - 2 = 2\), \(d_5 = 3\)으로 \((m_1, d_1)\)과 같다. \(\sqrt7 = [2; \overline{1, 1, 1, 4}]\).
    \(x_4 = \sqrt7 + 2\), 그 소수 부분이 \(x_0\)의 소수 부분과 같아 순환이 시작된다.

검산

순환이 맞다면 \(\sqrt7 = [2; 1, 1, 1, \sqrt7 + 2]\)이어야 한다. 안쪽부터 계산하면 \(1 + \frac1{\sqrt7 + 2} = 1 + \frac{\sqrt7 - 2}3 = \frac{\sqrt7 + 1}3\), 그 역수 \(\frac3{\sqrt7 + 1} = \frac{\sqrt7 - 1}2\), \(1 + \frac{\sqrt7 - 1}2 = \frac{\sqrt7 + 1}2\), 역수 \(\frac{\sqrt7 - 1}3\), \(1 + \frac{\sqrt7 - 1}3 = \frac{\sqrt7 + 2}3\), 역수 \(\sqrt7 - 2\), 마지막으로 \(2 + (\sqrt7 - 2) = \sqrt7\). 맞다.

의미

\(d_k\)는 모두 \(7 - m^2\)의 약수라 유한한 값만 가질 수 있고, \((m_k, d_k)\)의 쌍도 유한 개라 반복이 불가피하다. 이것이 라그랑주 정리의 구체적인 모습이다. 또 \(d_k\) 값 \(1, 3, 2, 3, 1\)은 7.3절에서 수렴분수의 \(p^2 - 7q^2\)으로 다시 나타납니다(\(-3, 2, -3, 1\)).

이해 확인

같은 방법으로 \(\sqrt{11}\)을 전개하여라.

답

\(a_0 = 3\). \((m, d, a) = (3, 2, 3), (3, 1, 6)\). \(\sqrt{11} = [3; \overline{3, 6}]\).
