뫼비우스 함수와 반전 공식

본문
이 절에서 배울 것
  • 뫼비우스 함수를 정의하고 \(\sum_{d\mid n}\mu(d) = [n = 1]\)을 증명한다.
  • 뫼비우스 반전 공식을 증명한다.
  • 반전 공식으로 \(\varphi(n) = \sum_{d\mid n}\mu(d)\frac nd\)를 얻고 셈 문제에 적용한다.
먼저 알아야 할 것
  • 곱셈적 함수 (3.1절), 포함배제 원리 (수학5 1.1절).

3.2.1되돌리는 문제

\(F(n) = \sum_{d\mid n}f(d)\)처럼 약수들에 대해 더한 함수가 있을 때, \(F\)만 알면 \(f\)를 되살릴 수 있을까요? 예를 들어 3.1절의 \(\sum_{d\mid n}\varphi(d) = n\)에서 \(\varphi\)를 \(n\)으로 나타낼 수 있을까요? 이것은 수열의 부분합에서 원래 수열을 차분으로 되살리는 것의 "약수판"이며, 그 차분 역할을 하는 것이 뫼비우스 함수입니다.

정의 3.2.1

뫼비우스 함수: \(\mu(1) = 1\); \(n\)이 서로 다른 소수 \(k\)개의 곱이면 \(\mu(n) = (-1)^k\); \(n\)이 어떤 소수의 제곱으로 나누어지면 \(\mu(n) = 0\).

\(\mu(1), \dots, \mu(12) = 1, -1, -1, 0, -1, 1, -1, 0, 0, 1, -1, 0\). \(\mu\)는 곱셈적입니다(정의에서 바로).

정리 3.2.2

\(\sum_{d\mid n}\mu(d) = 1\) (\(n = 1\)), \(0\) (\(n > 1\)).

좌변은 곱셈적 함수의 약수 합이라 곱셈적이므로(정리 3.1.2) 소수 거듭제곱에서만 보면 된다. \(n = p^e\) (\(e \ge 1\))이면 \(\mu(1) + \mu(p) + 0 + \cdots = 1 - 1 = 0\). ∎

포함배제로 보면: \(n\)의 서로 다른 소인수가 \(k\)개이면 \(\sum\mu(d) = \sum_j\binom kj(-1)^j = (1 - 1)^k = 0\). \(\mu\)는 포함배제의 부호를 기록한 함수입니다.

3.2.2반전 공식

정리 3.2.3 (뫼비우스 반전)

\(F(n) = \sum_{d\mid n}f(d)\)이면 \(f(n) = \sum_{d\mid n}\mu(d)F\!\left(\frac nd\right)\). 역도 성립한다.

\(\sum_{d\mid n}\mu(d)F(n/d) = \sum_{d\mid n}\mu(d)\sum_{e\mid n/d}f(e)\). 쌍 \((d, e)\)는 \(de \mid n\)인 쌍 전체이므로 순서를 바꾸면 \(= \sum_{e\mid n}f(e)\sum_{d\mid n/e}\mu(d)\). 정리 3.2.2로 안쪽 합은 \(n/e = 1\), 곧 \(e = n\)일 때만 1이다. 따라서 \(f(n)\). ∎

예제 3.2.4

\(\sum_{d\mid n}\varphi(d) = n\)을 반전해 \(\varphi\)의 공식을 얻고 \(n = 36\)에서 확인하여라.

풀이. \(F(n) = n\)이므로 \(\varphi(n) = \sum_{d\mid n}\mu(d)\frac nd = n\sum_{d\mid n}\frac{\mu(d)}d = n\prod_{p\mid n}\left(1 - \frac1p\right)\) (\(\mu(d) \ne 0\)인 \(d\)는 서로 다른 소수의 곱). \(n = 36\): \(\mu(1)36 + \mu(2)18 + \mu(3)12 + \mu(6)6 = 36 - 18 - 12 + 6 = 12 = \varphi(36)\). 이것은 "2의 배수와 3의 배수를 빼고, 둘 다의 배수를 더한다"는 포함배제 그 자체입니다.

반전 공식은 "정확히 ~인 것의 개수"를 "~의 약수에 해당하는 것의 개수"에서 구할 때 쓰입니다. 예: 이진 체 위 \(n\)차 기약다항식의 개수 \(N_n\)은 \(\sum_{d\mid n}dN_d = 2^n\)을 만족하므로 \(N_n = \frac1n\sum_{d\mid n}\mu(d)2^{n/d}\)입니다(같은 절의 예제 카드).

흔한 실수(1) \(\mu(4) = 1\)로 쓴다: 제곱 인수가 있으면 0이다. (2) 반전 공식에서 \(\mu(d)F(d)\)로 쓴다: \(F(n/d)\)이다(대칭이라 \(\mu(n/d)F(d)\)로 써도 된다). (3) \(F\)가 곱셈적이 아닐 때도 반전을 못 쓴다고 여긴다: 반전 공식은 곱셈성과 상관없이 성립한다.
요약
  1. \(\mu\): 제곱 인수가 있으면 0, 아니면 \((-1)^k\) (\(k\)는 소인수 개수). \(\sum_{d\mid n}\mu(d) = [n = 1]\).
  2. \(F = \sum_{d\mid n}f(d)\) ⇔ \(f = \sum_{d\mid n}\mu(d)F(n/d)\). 증명은 합의 순서 바꾸기.
  3. \(\varphi(n) = \sum\mu(d)n/d\): 포함배제의 약수판.

3.2.3연습문제

기본

  1. \(\mu(30)\), \(\mu(50)\), \(\mu(77)\)은?
    답

    \(30 = 2\cdot3\cdot5\): −1. \(50 = 2\cdot5^2\): 0. \(77 = 7\cdot11\): 1.

응용

  1. \(\sum_{d\mid n}|\mu(d)| = 2^{\omega(n)}\)임을 보여라(\(\omega(n)\)은 서로 다른 소인수의 개수).
    답

    \(|\mu|\)는 곱셈적이고 \(p^e\)에서 약수 합이 \(1 + 1 = 2\). 곱하면 \(2^{\omega(n)}\).

심화

  1. \(n\)과 \(\sigma\)의 관계 \(\sigma(n) = \sum_{d\mid n}d\)를 반전하면 무엇을 얻는가? \(n = 12\)에서 확인하여라.
    답

    \(n = \sum_{d\mid n}\mu(d)\sigma(n/d)\). \(n = 12\): \(\sigma(12) - \sigma(6) - \sigma(4) + \sigma(2) = 28 - 12 - 7 + 3 = 12\).
