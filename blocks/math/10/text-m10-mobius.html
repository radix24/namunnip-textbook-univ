뫼비우스 함수와 반전 공식

본문

3.1절에서 \(\sum_{d\mid n}\varphi(d) = n\)을 보았다. 거꾸로 이 등식만 가지고 \(\varphi(n)\)을 \(n\)으로 나타낼 수 있을까? 일반적으로 약수들에 대해 더한 함수 \(F\)만 알 때 원래 함수 \(f\)를 되살릴 수 있을까?

먼저 알아야 할 것곱셈적 함수(3.1절), 포함배제 원리(수학5 1.1절)를 쓴다.

3.2.1되돌리는 문제

처음 질문은 수열의 부분합에서 원래 수열을 차분으로 되살리는 것의 "약수판"이다. 그리고 그 차분 역할을 하는 것이 뫼비우스 함수이다.

정의 3.2.1

뫼비우스 함수는 \(\mu(1) = 1\)이고, \(n\)이 서로 다른 소수 \(k\)개의 곱이면 \(\mu(n) = (-1)^k\), \(n\)이 어떤 소수의 제곱으로 나누어지면 \(\mu(n) = 0\)인 함수이다.

처음 몇 값은 \(\mu(1), \dots, \mu(12) = 1, -1, -1, 0, -1, 1, -1, 0, 0, 1, -1, 0\)이다. 정의에서 바로 \(\mu\)가 곱셈적임을 알 수 있다.

정리 3.2.2

\(\sum_{d\mid n}\mu(d)\)는 \(n = 1\)이면 1이고, \(n > 1\)이면 0이다.

증명.좌변은 곱셈적 함수의 약수 합이므로 정리 3.1.2로 곱셈적이다. 따라서 소수 거듭제곱에서만 보면 된다. \(n = p^e\) (\(e \ge 1\))이면 \(\mu(1) + \mu(p) + 0 + \cdots = 1 - 1 = 0\)이다. ∎

포함배제로 보아도 같다. \(n\)의 서로 다른 소인수가 \(k\)개이면 \(\sum\mu(d) = \sum_j\binom kj(-1)^j = (1 - 1)^k = 0\)이다. 즉 \(\mu\)는 포함배제의 부호를 기록한 함수이다.

3.2.2반전 공식

정리 3.2.3 (뫼비우스 반전)

\(F(n) = \sum_{d\mid n}f(d)\)이면 \(f(n) = \sum_{d\mid n}\mu(d)F\!\left(\frac nd\right)\)이다. 역도 성립한다.

증명.\(\sum_{d\mid n}\mu(d)F(n/d) = \sum_{d\mid n}\mu(d)\sum_{e\mid n/d}f(e)\)이다. 쌍 \((d, e)\)는 \(de \mid n\)인 쌍 전체이므로 합의 순서를 바꾸면 \(\sum_{e\mid n}f(e)\sum_{d\mid n/e}\mu(d)\)이다. 정리 3.2.2로 안쪽 합은 \(n/e = 1\), 곧 \(e = n\)일 때만 1이다. 따라서 전체는 \(f(n)\)이다. ∎

예제 3.2.4

\(\sum_{d\mid n}\varphi(d) = n\)을 반전해 \(\varphi\)의 공식을 얻고 \(n = 36\)에서 확인하여라.

풀이. \(F(n) = n\)이므로 \(\varphi(n) = \sum_{d\mid n}\mu(d)\frac nd = n\sum_{d\mid n}\frac{\mu(d)}d\)이다. 여기서 \(\mu(d) \ne 0\)인 \(d\)는 서로 다른 소수의 곱뿐이므로 이 합은 \(n\prod_{p\mid n}\left(1 - \frac1p\right)\)이다. \(n = 36\)이면 \(\mu(1)36 + \mu(2)18 + \mu(3)12 + \mu(6)6 = 36 - 18 - 12 + 6 = 12 = \varphi(36)\)이다. 다시 말해 "2의 배수와 3의 배수를 빼고, 둘 다의 배수를 다시 더한다"는 포함배제 그 자체이다.

반전 공식은 "정확히 무엇인 것의 개수"를 "약수에 해당하는 것의 개수"에서 구할 때 쓴다. 예를 들어 이진 체 위 \(n\)차 기약다항식의 개수 \(N_n\)은 \(\sum_{d\mid n}dN_d = 2^n\)을 만족하므로 \(N_n = \frac1n\sum_{d\mid n}\mu(d)2^{n/d}\)이다. 이 계산은 같은 절의 예제 카드에서 한다.

흔한 오해\(\mu(4) = 1\)로 쓰기 쉽지만 제곱 인수가 있으면 0이다. 또 반전 공식을 \(\mu(d)F(d)\)로 잘못 쓰는 경우가 있으며, 맞는 꼴은 \(F(n/d)\)이다. 물론 대칭이라 \(\mu(n/d)F(d)\)로 써도 된다. \(F\)가 곱셈적이 아니면 반전을 못 쓴다고 여기는 것도 틀렸으며, 반전 공식은 곱셈성과 상관없이 성립한다.
마무리

처음 질문의 답은 "되살릴 수 있다"이다. \(F = \sum_{d\mid n}f(d)\)이면 \(f = \sum_{d\mid n}\mu(d)F(n/d)\)이고, 증명은 합의 순서를 바꾼 뒤 \(\sum_{d\mid n}\mu(d)\)가 \(n = 1\)에서만 1이라는 사실을 쓰는 것이다. \(\mu\)는 제곱 인수가 있으면 0, 아니면 \((-1)^k\)이다. 이것을 \(\sum\varphi(d) = n\)에 쓰면 \(\varphi(n) = n\prod(1 - 1/p)\)가 포함배제의 약수판으로 나온다.

3.2.3연습문제

기본

  1. \(\mu(30)\), \(\mu(50)\), \(\mu(77)\)은?
    답

    \(30 = 2\cdot3\cdot5\): −1. \(50 = 2\cdot5^2\): 0. \(77 = 7\cdot11\): 1.

응용

  1. \(\sum_{d\mid n}|\mu(d)| = 2^{\omega(n)}\)임을 보여라(\(\omega(n)\)은 서로 다른 소인수의 개수).
    답

    \(|\mu|\)는 곱셈적이고 \(p^e\)에서 약수 합이 \(1 + 1 = 2\). 곱하면 \(2^{\omega(n)}\).

심화

  1. \(n\)과 \(\sigma\)의 관계 \(\sigma(n) = \sum_{d\mid n}d\)를 반전하면 무엇을 얻는가? \(n = 12\)에서 확인하여라.
    답

    \(n = \sum_{d\mid n}\mu(d)\sigma(n/d)\). \(n = 12\): \(\sigma(12) - \sigma(6) - \sigma(4) + \sigma(2) = 28 - 12 - 7 + 3 = 12\).
