수론함수 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(n = 2^4\cdot3^2\cdot7\)의 \(\tau\), \(\sigma\), \(\varphi\)를 구하여라. [03-01]

    힌트 1

    각 소수 거듭제곱에서 계산해 곱한다(3.1절).

    힌트 2

    \(\sigma(2^4) = 31\), \(\sigma(3^2) = 13\), \(\sigma(7) = 8\).

    풀이

    \(n = 1008\). \(\tau = 5\cdot3\cdot2 = 30\), \(\sigma = 31\cdot13\cdot8 = 3224\), \(\varphi = 8\cdot6\cdot6 = 288\).

  2. 증명\(2^p - 1\)이 소수이면 \(n = 2^{p-1}(2^p - 1)\)은 완전수임을 보여라. [03-01]

    힌트 1

    \(\sigma\)의 곱셈성.

    힌트 2

    \(\sigma(2^{p-1}) = 2^p - 1\), \(\sigma(q) = q + 1\).

    풀이

    \(q = 2^p - 1\)은 홀수 소수라 \(2^{p-1}\)과 서로소. \(\sigma(n) = (2^p - 1)(q + 1) = (2^p - 1)2^p = 2n\). ∎

  3. 계산1부터 1000까지 중 1000과 서로소인 수의 개수를 뫼비우스 함수로 구하여라. [03-02]

    힌트 1

    \(\varphi(1000) = \sum_{d\mid1000}\mu(d)\frac{1000}d\)(3.2절).

    힌트 2

    \(\mu \ne 0\)인 약수는 1, 2, 5, 10.

    풀이

    \(1000 - 500 - 200 + 100 = 400\).

  4. 증명\(n > 1\)이면 \(n\)과 서로소인 \(n\) 이하 수들의 합이 \(\frac12n\varphi(n)\)임을 보여라. [03-01]

    힌트 1

    \(k\)와 \(n - k\)를 짝짓기.

    힌트 2

    \(\gcd(k, n) = \gcd(n - k, n)\).

    풀이

    \(k\)가 \(n\)과 서로소이면 \(n - k\)도 서로소. 두 수의 합이 \(n\)인 짝이 \(\varphi(n)/2\)개(\(n > 2\)이면 \(k \ne n - k\); \(n = 2\)는 직접 확인). 합 \(n\varphi(n)/2\). ∎

  5. 개념\(f(n) = n^2\)과 \(g(n) = n + 1\) 중 곱셈적인 것은? [03-01]

    힌트 1

    \(f(1) = 1\)인가?

    힌트 2

    \(g(1) = 2\).

    풀이

    \(f\)는 완전 곱셈적(모든 \(m, n\)에서 \(f(mn) = f(m)f(n)\)). \(g(1) = 2 \ne 1\)이고 \(g(6) = 7 \ne g(2)g(3) = 12\)라 곱셈적이 아니다.

  6. 판단한 학생이 \(\mu(4) = \mu(12) = 1\)로 두고 \(\sum_{d\mid12}\mu(d) = 1 - 1 - 1 + 1 + 1 + 1 = 2\)를 얻어 "정리 3.2.2가 틀렸다"고 했다. 어디가 잘못인가? [03-02]

    힌트 1

    \(\mu(4)\), \(\mu(12)\)의 값.

    힌트 2

    제곱 인수.

    풀이

    \(4 = 2^2\), \(12 = 2^2\cdot3\)은 제곱 인수가 있어 \(\mu(4) = \mu(12) = 0\)이다. 올바른 합은 \(\mu(1) + \mu(2) + \mu(3) + \mu(6) = 1 - 1 - 1 + 1 = 0\)으로 정리와 맞다.
