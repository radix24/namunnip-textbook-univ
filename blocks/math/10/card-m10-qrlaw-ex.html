이차 합동식의 해가 있는지 판정하기

예제 · 상호법칙으로 르장드르 기호 계산

먼저 예측

\(x^2 \equiv 1234 \pmod{4567}\)은 해가 있을까? 4567은 소수이다. 제곱을 4000번 넘게 시도하지 않고 판정할 수 있을까?

예측 확인

상호법칙과 보충법칙을 몇 번 쓰면 판정됩니다. 답은 "해가 있다"입니다.

\(\left(\frac{1234}{4567}\right)\)을 구하여라.

전략

위를 소인수분해하고(\(1234 = 2\cdot617\), 617은 소수), 2는 보충법칙, 홀수 소수는 상호법칙으로 뒤집어 수를 줄여 갑니다(5.2절). 매 단계 부호의 근거(\(4k + 1\)인지, 법 8의 나머지)를 적어 둡니다.

풀이

  1. \(\left(\frac{1234}{4567}\right) = \left(\frac2{4567}\right)\left(\frac{617}{4567}\right)\).
    곱셈성.
  2. \(4567 \equiv 7 \pmod 8\)이므로 \(\left(\frac2{4567}\right) = 1\).
    \(4567 = 570\cdot8 + 7\). 보충법칙.
  3. \(617 \equiv 1 \pmod 4\)이므로 \(\left(\frac{617}{4567}\right) = \left(\frac{4567}{617}\right) = \left(\frac{248}{617}\right)\).
    \(4567 = 7\cdot617 + 248\). 한쪽이 \(4k + 1\)이라 부호 변화 없음.
  4. \(248 = 2^3\cdot31\)이고 \(617 \equiv 1 \pmod 8\)이라 \(\left(\frac2{617}\right) = 1\). 따라서 \(\left(\frac{248}{617}\right) = \left(\frac{31}{617}\right) = \left(\frac{617}{31}\right) = \left(\frac{28}{31}\right)\).
    \(617 = 19\cdot31 + 28\). 617이 \(4k + 1\)이라 뒤집어도 부호 그대로.
  5. \(\left(\frac{28}{31}\right) = \left(\frac4{31}\right)\left(\frac7{31}\right) = \left(\frac7{31}\right) = -\left(\frac{31}7\right) = -\left(\frac37\right) = -(-1) = 1\).
    7, 31 모두 \(4k + 3\)이라 뒤집으면 부호가 바뀐다. 법 7의 잉여는 1, 2, 4라 \(\left(\frac37\right) = -1\).

따라서 \(\left(\frac{1234}{4567}\right) = 1\): 1234는 법 4567의 이차 잉여이고 \(x^2 \equiv 1234\)는 해가 정확히 2개 있습니다.

검산

오일러 판정법으로 컴퓨터에서 \(1234^{2283} \bmod 4567\)을 계산하면 1입니다. 실제 해는 \(x \equiv 2148\)과 \(x \equiv 2419 = 4567 - 2148\)입니다(토넬리-섕크스 알고리즘으로 구함).

의미

상호법칙 계산은 유클리드 호제법처럼 수를 빠르게 줄이므로, 아주 큰 소수에서도 몇 단계면 끝납니다. 해가 있는지 판정하는 것과 해를 구하는 것은 다른 문제이고, 후자는 별도의 알고리즘이 필요합니다.

이해 확인

\(\left(\frac{-1234}{4567}\right)\)은?

답

\(\left(\frac{-1}{4567}\right) = -1\) (\(4567 \equiv 3 \pmod 4\))이므로 \(-1\cdot1 = -1\). \(x^2 \equiv -1234\)는 해가 없다.
