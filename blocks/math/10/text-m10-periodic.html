이차 무리수의 순환 연분수

본문

\(\sqrt2 = [1; 2, 2, 2, \dots]\), \(\sqrt7 = [2; 1, 1, 1, 4, 1, 1, 1, 4, \dots]\)처럼 제곱근의 연분수는 되풀이된다. 반면 \(\pi\)의 연분수에서는 아무 규칙도 보이지 않는다. 어떤 수의 연분수가 되풀이될까? 되풀이되는 마디에는 어떤 모양이 있을까?

먼저 알아야 할 것연분수와 수렴분수(7.1절), 이차방정식의 근을 쓴다.

7.2.1관찰

\(\sqrt3 = [1; \overline{1, 2}]\), \(\sqrt{13} = [3; \overline{1, 1, 1, 1, 6}]\)이고 황금비는 \([\overline1]\)이다. 하지만 \(\pi = [3; 7, 15, 1, 292, 1, 1, 1, 2, \dots]\)이나 \(\sqrt[3]2\)에서는 어떤 규칙도 보이지 않는다. 사실 순환하는 것은 정확히 이차 무리수, 곧 정수 계수 이차방정식의 무리수 근이다.

정리 7.2.1 (오일러-라그랑주)

실수 \(x\)의 연분수가 어느 지점부터 순환할 필요충분조건은 \(x\)가 이차 무리수인 것이다.

7.2.2순환이면 이차 무리수

증명.먼저 순수 순환 \(x = [\overline{a_0; \dots, a_{k-1}}]\)이면 \(x = [a_0; \dots, a_{k-1}, x]\)이다. 정리 7.1.2의 증명에서 쓴 식으로 \(x = \frac{xp_{k-1} + p_{k-2}}{xq_{k-1} + q_{k-2}}\)이고, 분모를 곱하면 \(q_{k-1}x^2 + (q_{k-2} - p_{k-1})x - p_{k-2} = 0\)이라는 정수 계수 이차방정식이 된다. 다음으로 앞부분이 순환하지 않으면 \(x = [b_0; \dots, b_j, y]\) (\(y\)는 순수 순환)이고, \(x\)는 \(y\)의 일차분수식이라 역시 이차 무리수이다. ∎

예를 들어 \(y = [\overline1]\)이면 \(y = 1 + 1/y\)에서 \(y^2 - y - 1 = 0\)이므로 \(y = \frac{1 + \sqrt5}2\)이다.

7.2.3이차 무리수이면 순환

이 방향은 흐름만 본다. \(x\)가 \(Ax^2 + Bx + C = 0\)의 근이면, \(x\)가 \(x_n\)의 일차분수식이므로 각 완전몫 \(x_n\)도 판별식이 같은 \(A_nx_n^2 + B_nx_n + C_n = 0\)의 근이 된다. 그런데 수렴분수가 \(x\)에 가까워지므로, \(n\)이 충분히 크면 \(|A_n|\), \(|B_n|\), \(|C_n|\)이 판별식으로 정해지는 한계 안에 갇힌다. 정수 계수의 조합은 유한 개뿐이므로 어떤 방정식이 다시 나타나고, 같은 방정식의 같은 근이 나오면 그 뒤로 전개가 반복된다. 즉 이것은 비둘기집 원리에 기댄 라그랑주의 증명이다.

7.2.4제곱근의 정확한 계산

부동소수점으로 전개하면 반올림 오차로 틀리므로, \(x_k = \frac{\sqrt n + m_k}{d_k}\) 꼴을 유지하며 정수만으로 계산한다. \(m_0 = 0\), \(d_0 = 1\), \(a_0 = \lfloor\sqrt n\rfloor\)에서 시작해 다음을 되풀이한다.

\[m_{k+1} = d_ka_k - m_k,\quad d_{k+1} = \frac{n - m_{k+1}^2}{d_k},\quad a_{k+1} = \left\lfloor\frac{a_0 + m_{k+1}}{d_{k+1}}\right\rfloor.\]

이때 \(d_{k+1}\)이 늘 정수가 된다는 것이 이 방법의 장점이다. 같은 절의 예제 카드에서 \(\sqrt7\)을 이 표로 전개한다. 결과를 보면 \(\sqrt n = [a_0; \overline{a_1, a_2, \dots, a_2, a_1, 2a_0}]\)처럼 마지막 항이 \(2a_0\)이고 그 앞부분이 좌우 대칭이다. 예를 들어 \(\sqrt{19} = [4; \overline{2, 1, 3, 1, 2, 8}]\)이고, \(\sqrt{61} = [7; \overline{1, 4, 3, 1, 2, 2, 1, 3, 4, 1, 14}]\)이다. 그림 1이 이 모양을 보여 준다.

흔한 오해\(\sqrt n\)의 순환 마디에 \(a_0\)을 넣는 실수가 많지만, 순환은 \(a_1\)부터 \(2a_0\)까지이다. 또 부동소수점 전개 결과를 그대로 믿기 쉬운데, \(\sqrt{61}\)처럼 마디가 길면 틀리기 쉽다. 3차 이상의 대수적 수도 순환한다고 여기는 것도 틀렸다. 그것은 이차 무리수만의 성질이다.
마무리

처음 질문에 답하면, 연분수가 되풀이되는 수는 정확히 이차 무리수이다(오일러-라그랑주). 순환하면 \(x = [a_0; \dots, x]\)에서 이차방정식이 바로 나오고, 거꾸로 이차 무리수의 완전몫들은 계수가 유계인 유한 개의 방정식만 만족하므로 되풀이된다. \(\sqrt n\)의 마디는 \(2a_0\)으로 끝나고 그 앞부분은 좌우 대칭이며, 정수만 쓰는 점화식으로 정확히 계산한다.

7.2.5연습문제

기본

  1. \([\overline{2}]\)과 \([1; \overline2]\)는 어떤 수인가?
    답

    \(y = 2 + 1/y\)에서 \(y = 1 + \sqrt2\). \([1; \overline2] = y - 1 = \sqrt2\).

응용

  1. \((m, d, a)\) 점화식으로 \(\sqrt{13}\)을 전개하여라.
    답

    \(a_0 = 3\). \((m, d, a) = (3, 4, 1), (1, 3, 1), (2, 3, 1), (1, 4, 1), (3, 1, 6)\). \([3; \overline{1, 1, 1, 1, 6}]\).

심화

  1. \([1; \overline{1, 2}]\)이 \(\sqrt3\)임을 보여라.
    답

    \(y = [\overline{1, 2}] = 1 + \frac1{2 + 1/y} = 1 + \frac y{2y + 1}\). \(y(2y + 1) = 2y + 1 + y\), \(2y^2 - 2y - 1 = 0\), \(y = \frac{1 + \sqrt3}2\). \([1; \overline{1,2}] = 1 + 1/y = 1 + \frac2{1 + \sqrt3} = 1 + (\sqrt3 - 1) = \sqrt3\).
