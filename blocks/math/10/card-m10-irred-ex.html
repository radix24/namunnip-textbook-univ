기약다항식은 몇 개인가

예제 · 뫼비우스 반전으로 세기

먼저 예측

계수가 0, 1뿐이고 1 + 1 = 0인 세계(\(\mathbb F_2\))에서 최고차 계수 1인 6차 다항식은 \(2^6 = 64\)개다. 그중 인수분해되지 않는 것은 대략 몇 개일까? 6, 9, 20 중에서.

예측 확인

9개이다. 대략 \(2^6/6 \approx 10.7\)개라는 어림과 비슷하다.

\(\mathbb F_2\) 위 \(n\)차 기약다항식의 개수 \(N_n\)이 \(\sum_{d\mid n}dN_d = 2^n\)을 만족한다는 사실(유한체 이론)을 받아들이고, 뫼비우스 반전으로 \(N_n\)의 공식을 얻어 \(N_6\)을 구하여라.

전략

\(f(d) = dN_d\), \(F(n) = 2^n\)으로 두면 \(F(n) = \sum_{d\mid n}f(d)\) 꼴이므로 반전할 수 있습니다(3.2절 정리 3.2.3). 관계식의 뜻은 "\(x^{2^n} - x\)는 차수가 \(n\)의 약수인 기약다항식을 모두 한 번씩 곱한 것"입니다(수학19).

풀이

  1. 반전: \(nN_n = \sum_{d\mid n}\mu(d)2^{n/d}\), 곧 \(N_n = \frac1n\sum_{d\mid n}\mu(d)2^{n/d}\).
    \(f(n) = \sum\mu(d)F(n/d)\).
  2. \(n = 6\)의 약수 1, 2, 3, 6에서 \(\mu = 1, -1, -1, 1\).
    \(6 = 2\cdot3\)이라 \(\mu(6) = 1\).
  3. \(6N_6 = 2^6 - 2^3 - 2^2 + 2^1 = 64 - 8 - 4 + 2 = 54\).
    \(2^{6/d}\)에 부호를 붙여 더함.
  4. \(N_6 = 9\).
    나누어떨어지는 것이 검산이 된다.

검산

작은 \(n\)에서 직접 셀 수 있다: \(N_1 = 2\) (\(x\), \(x + 1\)), \(N_2 = \frac12(4 - 2) = 1\) (\(x^2 + x + 1\)), \(N_3 = \frac13(8 - 2) = 2\) (\(x^3 + x + 1\), \(x^3 + x^2 + 1\)). 관계식도 \(n = 6\)에서 \(1\cdot2 + 2\cdot1 + 3\cdot2 + 6\cdot9 = 64\)로 맞다.

의미

\(N_n \approx 2^n/n\)은 소수 정리 \(\pi(x) \approx x/\ln x\)의 다항식판입니다(\(x = 2^n\)이면 \(\ln x\)가 \(n\)에 비례). 같은 공식은 길이 \(n\)인 "원형 목걸이 중 회전 대칭이 없는 것"의 수도 센다. 오류 정정 부호와 암호에서 기약다항식을 고를 때 "무작위로 고르면 약 \(1/n\)의 확률로 기약"이라는 감각을 준다.

이해 확인

\(N_4\)를 구하여라.

답

\(\frac14(2^4 - 2^2) = 3\) (\(\mu(4) = 0\)). \(x^4 + x + 1\), \(x^4 + x^3 + 1\), \(x^4 + x^3 + x^2 + x + 1\).
