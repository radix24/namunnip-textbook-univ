원 위의 격자점 세기

탐구 · 두 제곱수의 합

질문

원 \(x^2 + y^2 = n\) 위에 정수 좌표의 점이 몇 개 있을까? 소수 \(p\)에서는 언제 있고, 합성수에서는 개수가 어떻게 정해질까?

복원

홀수 소수는 \(p \equiv 1 \pmod 4\)일 때만 두 제곱수의 합. \(n\)은 \(4k + 3\) 꼴 소수의 지수가 모두 짝수일 때만. 격자점 수 \(r_2(n) = 4(d_1 - d_3)\) (6.3절).

해 보기

  1. \(n = 13\): 격자점 8개 (\(\pm2, \pm3\)과 순서 바꿈). \(13 = 2^2 + 3^2\).
  2. \(n = 7, 11, 19, 23\)은 격자점이 없다. 모두 \(4k + 3\) 꼴이다.
  3. \(n = 65 = 5\cdot13\): 16개, 두 가지 표현 \(1 + 64\), \(16 + 49\). \(n = 25\): 12개 (\(0 + 25\), \(9 + 16\)).
  4. \(n = 21 = 3\cdot7\)은 \(4k + 1\) 꼴인데 격자점이 없고, \(n = 45 = 3^2\cdot5\)는 8개(\(9 + 36\))이다. 3의 지수가 짝수인지가 갈림길이다.

설명

  1. 약수로 세기\(4k + 1\) 꼴 약수와 \(4k + 3\) 꼴 약수의 개수 차에 4를 곱한 것이 격자점 수이다. 이 공식은 가우스 정수에서의 소인수분해를 세는 것과 같다.
  2. 평균은 π\(n = 1\)부터 \(N\)까지 \(r_2(n)\)을 더하면 반지름 \(\sqrt N\)인 원판 안의 격자점 수라 약 \(\pi N\)이다. 들쭉날쭉한 \(r_2\)의 평균이 \(\pi\)이다.

판단

"\(n \equiv 1 \pmod 4\)이면 두 제곱수의 합이다"는 소수에서만 맞다. \(21 \equiv 1 \pmod 4\)는 \(3\cdot7\)이라 두 제곱수의 합이 아니다. 판정은 소인수분해로 해야 한다.
