5.3.1가우스 보조정리

정리 5.3.1 (가우스 보조정리)

홀수 소수 \(p\), \(p \nmid a\)에 대해 \(a, 2a, \dots, \frac{p-1}2a\)를 \(p\)로 나눈 나머지 중 \(p/2\)보다 큰 것의 개수를 \(n\)이라 하면 \(\left(\frac ap\right) = (-1)^n\).

아이디어: 오일러 정리의 증명(2.3절)처럼 \(ka\)들을 곱하는데, 반만 씁니다. \(p/2\)를 넘는 나머지 \(r\)을 \(p - r\)로 바꾸면(부호 \(-1\)이 하나씩 생김) 나머지들이 정확히 \(1, \dots, \frac{p-1}2\)의 재배열이 됩니다.

\(m = \frac{p-1}2\). \(ka \bmod p\) (\(k = 1, \dots, m\)) 중 \(p/2\)보다 작은 것을 \(r_i\), 큰 것을 \(s_j\) (\(n\)개)라 하자. \(r_i\)들과 \(p - s_j\)들은 모두 \(1, \dots, m\)에 있다. 이들이 서로 다름을 보이자: \(r_i\)끼리, \(s_j\)끼리는 \(ka\)가 서로 다르므로 다르다. \(r_i = p - s_j\)라면 \(ka + la \equiv 0\), 곧 \(k + l \equiv 0 \pmod p\)인데 \(2 \le k + l \le p - 1\)이라 불가능. 따라서 \(\{r_i\} \cup \{p - s_j\} = \{1, \dots, m\}\).

곱을 비교하면 \(m! \equiv \prod r_i\prod(p - s_j) \equiv (-1)^n\prod r_i\prod s_j \equiv (-1)^n\prod_{k=1}^m(ka) = (-1)^na^mm! \pmod p\). \(m!\)을 지우면 \(a^{(p-1)/2} \equiv (-1)^n\), 오일러 판정법으로 결론. ∎

예제 5.3.2

가우스 보조정리로 \(\left(\frac5{13}\right)\)을 구하여라.

풀이. \(5, 10, 15, 20, 25, 30 \equiv 5, 10, 2, 7, 12, 4\). 6.5보다 큰 것은 10, 7, 12의 3개이므로 \((-1)^3 = -1\). 실제로 법 13의 이차 잉여는 1, 3, 4, 9, 10, 12라 5는 비잉여입니다.

5.3.2\(\left(\frac2p\right)\)

\(a = 2\)이면 \(2, 4, \dots, p - 1\)이 모두 \(p\)보다 작아 나머지 그대로이고, \(p/2\)를 넘는 짝수의 개수 \(n = \frac{p-1}2 - \lfloor p/4\rfloor\)입니다. \(p = 8k + 1, 3, 5, 7\)이면 \(n = 2k, 2k + 1, 2k + 1, 2k + 2\)이므로 \(\left(\frac2p\right) = 1\) ⇔ \(p \equiv \pm1 \pmod 8\). 보충법칙(정리 5.2.2)입니다.

5.3.3상호법칙: 격자점 세기

아이젠슈타인은 가우스 보조정리를 다듬어, 홀수 \(a\)에 대해 \(n \equiv \sum_{k=1}^{m}\left\lfloor\frac{ka}p\right\rfloor \pmod 2\)임을 보였습니다(\(ka = p\lfloor ka/p\rfloor + r_k\), \(r_k\)는 나머지, 를 모두 더하고 짝홀만 비교). 이제 \(p, q\)가 서로 다른 홀수 소수이면

  • \(\sum_{k=1}^{(p-1)/2}\left\lfloor\frac{kq}p\right\rfloor\)는 직사각형 \(0 < x < p/2\), \(0 < y < q/2\) 안에서 대각선 \(y = \frac qpx\) 아래의 격자점 수,
  • \(\sum_{k=1}^{(q-1)/2}\left\lfloor\frac{kp}q\right\rfloor\)는 대각선 위의 격자점 수입니다.

대각선 위에는 격자점이 없으므로(\(p, q\) 서로소) 두 합의 합은 직사각형 안의 격자점 수 \(\frac{p-1}2\cdot\frac{q-1}2\)입니다. 따라서 \(\left(\frac qp\right)\left(\frac pq\right) = (-1)^{\frac{p-1}2\frac{q-1}2}\). 증명의 핵심은 "같은 격자점을 두 방향으로 센다"는 것뿐입니다. 같은 절의 탐구 카드에서 격자점을 직접 셀 수 있습니다.

흔한 실수(1) \(p/2\)를 넘는 것을 셀 때 \(k\)를 \(p - 1\)까지 돌린다: \(\frac{p-1}2\)까지만. (2) 나머지와 몫을 혼동한다: 가우스 보조정리는 나머지, 아이젠슈타인의 합은 몫(바닥)을 센다. (3) 아이젠슈타인 공식을 \(a\)가 짝수일 때 쓴다(\(a = 2\)는 따로).
요약
  1. 가우스 보조정리: \(ka \bmod p\) (\(k \le \frac{p-1}2\)) 중 \(p/2\) 초과의 개수 \(n\)으로 \(\left(\frac ap\right) = (-1)^n\).
  2. \(a = 2\)에서 보충법칙 \(p \equiv \pm1 \pmod 8\).
  3. 상호법칙 = 직사각형의 격자점을 대각선 위·아래로 나눠 센 것.

5.3.4연습문제

기본

  1. 가우스 보조정리로 \(\left(\frac3{7}\right)\)을 구하여라.
    답

    3, 6, 9 → 3, 6, 2. 3.5 초과는 6 하나. \((-1)^1 = -1\).

응용

  1. \(p = 7\), \(q = 11\)에서 두 바닥함수 합을 계산해 상호법칙을 확인하여라.
    답

    \(\sum_{k=1}^3\lfloor11k/7\rfloor = 1 + 3 + 4 = 8\), \(\sum_{k=1}^5\lfloor7k/11\rfloor = 0 + 1 + 1 + 2 + 3 = 7\). 합 15 = \(3\cdot5\). \((-1)^{15} = -1\)이고 실제로 \(\left(\frac7{11}\right) = -1\), \(\left(\frac{11}7\right) = 1\).

심화

  1. \(\left(\frac2p\right)\)의 공식 \(n = \frac{p-1}2 - \lfloor\frac p4\rfloor\)을 \(p = 17\)과 \(p = 19\)에서 확인하여라.
    답

    \(p = 17\): \(8 - 4 = 4\), 짝수라 1 (\(17 \equiv 1 \pmod 8\)). 실제로 \(6^2 = 36 \equiv 2\). \(p = 19\): \(9 - 4 = 5\), 홀수라 \(-1\) (\(19 \equiv 3 \pmod 8\)).
