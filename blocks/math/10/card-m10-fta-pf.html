베주 없이 유일 분해 증명하기

증명 · 최소 반례법
정리

1보다 큰 정수의 소인수분해는 순서를 빼면 유일하다.

쓰는 것

  • 정렬 원리: 양의 정수의 공집합 아닌 부분집합에는 최소 원소가 있다.
  • 나눗셈 정리와 소수의 정의만. 유클리드 보조정리와 베주 항등식은 쓰지 않는다.

아이디어

두 가지로 분해되는 수가 있다면 그중 가장 작은 수 \(n\)을 잡는다. \(n\)의 두 분해에서 가장 작은 소수끼리 빼서 더 작은 수를 만들면, 그 수도 두 가지로 분해된다는 것을 보여 모순을 냅니다(체르멜로의 증명).

증명

  1. 유일하지 않은 수가 있다고 하고, 그중 가장 작은 것을 \(n = p_1p_2\cdots p_r = q_1q_2\cdots q_s\)라 하자(\(p_1 \le \cdots\), \(q_1 \le \cdots\), 두 목록이 다름).
    정렬 원리.
  2. 어떤 \(p_i = q_j\)라면 양변에서 지운 수가 \(n\)보다 작으면서 두 분해를 가지므로 모순. 따라서 모든 \(p_i \ne q_j\), 특히 \(p_1 \ne q_1\). \(p_1 < q_1\)이라 하자.
    \(n\)의 최소성. \(r, s \ge 2\)이다(\(n\)이 소수면 분해가 하나뿐).
  3. \(p_1^2 \le n\), \(q_1^2 \le n\)이고 \(p_1 \ne q_1\)이므로 \(p_1q_1 < n\). \(m = n - p_1q_1 > 0\)을 생각한다.
    \(p_1\)은 \(n\)의 가장 작은 인수라 \(p_1^2 \le p_1p_2 \le n\). \(q_1\)도 같다. \(p_1q_1 < \max(p_1, q_1)^2 \le n\).
  4. \(p_1 \mid m\)이고 \(q_1 \mid m\). 그런데 \(m = q_1(q_2\cdots q_s - p_1)\)에서 \(m < n\)이므로 \(m\)의 분해는 유일하고, \(p_1\)은 \(q_1\) 또는 \(q_2\cdots q_s - p_1\)의 분해에 나타난다. \(p_1 \ne q_1\)이므로 \(p_1 \mid q_2\cdots q_s - p_1\), 곧 \(p_1 \mid q_2\cdots q_s\).
    \(m = p_1(p_2\cdots p_r - q_1)\)으로도 쓸 수 있다. \(m\)의 유일한 분해에 \(p_1\)과 \(q_1\)이 모두 있다.
  5. \(q_2\cdots q_s = n/q_1 < n\)이라 분해가 유일한데, \(p_1 \mid q_2\cdots q_s\)이므로 그 분해에 \(p_1\)이 나타나 어떤 \(q_j = p_1\). 2단계에 모순.
    \(q_2\cdots q_s = p_1k\)로 쓰고 \(k\)를 분해하면 \(p_1\)을 포함한 또 하나의 분해가 생긴다.

되짚기

  • 유클리드 보조정리를 대신한 것: "\(n\)보다 작은 수에서는 이미 유일 분해가 성립한다"는 최소 반례의 가정이 보조정리의 역할을 했다. 실제로 이 정리에서 거꾸로 유클리드 보조정리가 나온다.
  • 왜 \(2\mathbb Z\)에서는 안 되는가: 3단계의 \(m = n - p_1q_1\)이 그 세계 안에 있어도, 4단계에서 "\(p_1 \mid m\)이면 \(m\)의 분해에 \(p_1\)이 나타난다"가 깨진다. 정수의 나눗셈 구조가 핵심이다.

직접 써 보기

이 정리로부터 유클리드 보조정리(\(p \mid ab \Rightarrow p \mid a\) 또는 \(p \mid b\))를 유도하여라.

힌트

\(ab = pk\)의 양변을 소인수분해하여라.

답안

\(ab = pk\)에서 \(a, b, k\)를 각각 분해하면 좌변은 \(a\)와 \(b\)의 소인수를 모은 것, 우변은 \(p\)와 \(k\)의 소인수를 모은 것이다. 유일성으로 \(p\)는 \(a\)나 \(b\)의 분해에 나타나므로 \(p \mid a\) 또는 \(p \mid b\). ∎
