일차 부정방정식

본문
이 절에서 배울 것
  • \(ax + by = c\)가 정수해를 가질 조건과 일반해를 증명한다.
  • 양의 정수해(자연수해)만 고르는 범위를 구한다.
  • 여러 변수의 문제(백계 문제)와 동전 문제(프로베니우스 수)를 다룬다.
먼저 알아야 할 것
  • 베주 항등식과 호제법 (1.1절), 일차 합동식 (2.1절).

6.1.1해의 존재와 일반해

정수해만 찾는 방정식을 디오판토스 방정식이라 합니다. 가장 간단한 일차의 경우는 1단원의 도구로 완전히 풀립니다.

정리 6.1.1

\(d = \gcd(a, b)\)라 하자. \(ax + by = c\)는 \(d \mid c\)일 때만 정수해를 가지고, 한 해 \((x_0, y_0)\)이 있으면 모든 해는 \(x = x_0 + \frac bdt\), \(y = y_0 - \frac adt\) (\(t \in \mathbb Z\))이다.

존재: \(ax + by\)는 늘 \(d\)의 배수이고, \(d \mid c\)이면 베주 \(ax' + by' = d\)에 \(c/d\)를 곱한다. 일반해: \((x, y)\)가 해이면 \(a(x - x_0) = -b(y - y_0)\). \(d\)로 나누면 \(\frac ad(x - x_0) = -\frac bd(y - y_0)\)이고 \(\gcd(\frac ad, \frac bd) = 1\)이므로 \(\frac bd \mid x - x_0\) (따름정리 1.1.4(c)). \(x - x_0 = \frac bdt\)로 두면 \(y - y_0 = -\frac adt\). 역으로 이 꼴은 모두 해이다. ∎

예제 6.1.2

\(172x + 20y = 1000\)의 정수해와 양의 정수해를 구하여라.

풀이. 호제법: \(172 = 8\cdot20 + 12\), \(20 = 12 + 8\), \(12 = 8 + 4\), \(8 = 2\cdot4\). \(\gcd = 4 \mid 1000\). 거꾸로 \(4 = 12 - 8 = 2\cdot12 - 20 = 2\cdot172 - 17\cdot20\). 250을 곱하면 \((x_0, y_0) = (500, -4250)\). 일반해 \(x = 500 + 5t\), \(y = -4250 - 43t\). 양수 조건: \(t > -100\)이고 \(t < -98.8\)이므로 \(t = -99\), \((x, y) = (5, 7)\). 확인 \(860 + 140 = 1000\).

6.1.2세 변수: 백계 문제

『장구건산경』: 수탉 한 마리 5전, 암탉 3전, 병아리 3마리 1전. 100전으로 100마리를 사려면? \(x + y + z = 100\), \(5x + 3y + z/3 = 100\). \(z\)를 소거하면 \(7x + 4y = 100\). \(x = 4t\)로 두면 \(y = 25 - 7t\)이고 \(x, y \ge 0\)에서 \(t = 0, 1, 2, 3\): \((x, y, z) = (0, 25, 75), (4, 18, 78), (8, 11, 81), (12, 4, 84)\). 식 두 개, 미지수 세 개라 하나를 소거하면 일차 부정방정식이 됩니다.

6.1.3동전 문제

5원, 7원짜리 동전만으로 만들 수 없는 가장 큰 금액은? \(\gcd(a, b) = 1\)이면 \(ax + by = n\)의 음이 아닌 해가 없는 가장 큰 \(n\)은 \(ab - a - b\) (실베스터)입니다. 5, 7이면 23. 24부터는 모두 만들 수 있습니다. 또 \(n\)을 만드는 방법의 수는 \(n/(ab)\) 근처입니다: \(5x + 7y = 100\)은 \((6, 10), (13, 5), (20, 0)\)의 3가지. 같은 절의 탐구 카드에서 확인할 수 있습니다.

흔한 실수(1) 일반해의 간격을 \(b, a\)로 쓴다: \(b/d\), \(a/d\)이다. (2) \(x\)와 \(y\)의 간격의 부호를 같게 쓴다: 한쪽이 늘면 다른 쪽은 준다. (3) 양수 조건에서 부등식 방향을 틀린다: \(t\)의 범위를 두 부등식의 교집합으로 구한다.
요약
  1. \(ax + by = c\)는 \(\gcd(a, b) \mid c\)일 때만 해. 일반해 \((x_0 + \frac bdt, y_0 - \frac adt)\).
  2. 양의 해는 \(t\)에 대한 두 부등식의 교집합.
  3. \(\gcd(a, b) = 1\)이면 \(ab - a - b\)보다 큰 수는 모두 \(ax + by\) (\(x, y \ge 0\)).

6.1.4연습문제

기본

  1. \(7x + 11y = 1\)의 일반해를 구하여라.
    답

    \(7\cdot(-3) + 11\cdot2 = 1\). \(x = -3 + 11t\), \(y = 2 - 7t\).

응용

  1. 3원, 8원짜리 우표로 100원을 만드는 방법을 모두 구하여라.
    답

    \(3x + 8y = 100\): \(y\)는 \(100 - 8y \equiv 0 \pmod 3\), 곧 \(y \equiv 2 \pmod 3\). \(y = 2, 5, 8, 11\): \((28, 2), (20, 5), (12, 8), (4, 11)\).

심화

  1. \(\gcd(a, b) = 1\)이면 \(ab - a - b\)는 \(ax + by\) (\(x, y \ge 0\))로 나타낼 수 없음을 보여라.
    답

    \(ax + by = ab - a - b\)이면 \(a(x + 1) + b(y + 1) = ab\). 법 \(a\)로 \(b(y + 1) \equiv 0\), 서로소라 \(a \mid y + 1\), \(y + 1 \ge a\). 같은 방법으로 \(x + 1 \ge b\). 그러면 좌변 \(\ge 2ab > ab\). 모순.
