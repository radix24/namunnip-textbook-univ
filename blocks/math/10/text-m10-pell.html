펠 방정식

본문
이 절에서 배울 것
  • \(x^2 - dy^2 = 1\) (\(d\)는 제곱수가 아닌 양의 정수)의 해가 \(\sqrt d\)의 수렴분수에서 나옴을 안다.
  • 연분수의 주기로 기본해를 구한다.
  • 기본해의 거듭제곱 \((x_1 + y_1\sqrt d)^k\)로 모든 해를 만든다.
먼저 알아야 할 것
  • 수렴분수 (7.1절), \(\sqrt n\)의 순환 연분수 (7.2절).

7.3.1왜 연분수인가

\(x^2 - dy^2 = 1\)이면 \(\frac xy - \sqrt d = \frac1{y(x + y\sqrt d)}\)로 아주 작습니다: \(x/y\)는 \(\sqrt d\)의 매우 좋은 근사입니다. 그리고 매우 좋은 근사(\(|\sqrt d - x/y| < \frac1{2y^2}\))는 반드시 수렴분수라는 정리가 있으므로(르장드르), 해는 수렴분수 중에서 찾으면 됩니다. 실제로 수렴분수 \(p_n/q_n\)에서 \(p_n^2 - dq_n^2\)은 작은 값들을 오가며, 주기의 끝에서 \(\pm1\)이 됩니다.

정리 7.3.1

\(\sqrt d = [a_0; \overline{a_1, \dots, a_r}]\) (주기 \(r\))라 하자. \(r\)이 짝수이면 \((p_{r-1}, q_{r-1})\)가, \(r\)이 홀수이면 \((p_{2r-1}, q_{2r-1})\)가 \(x^2 - dy^2 = 1\)의 가장 작은 양의 해(기본해)이다. \(r\)이 홀수이면 \((p_{r-1}, q_{r-1})\)은 \(x^2 - dy^2 = -1\)의 해이다.

예제 7.3.2

(a) \(x^2 - 7y^2 = 1\) (b) \(x^2 - 13y^2 = 1\)의 기본해를 구하여라.

풀이. (a) \(\sqrt7 = [2; \overline{1, 1, 1, 4}]\), 주기 4(짝수). 수렴분수 \(2, 3, \frac52, \frac83\). \(p_3 = 8\), \(q_3 = 3\): \(64 - 63 = 1\). 기본해 \((8, 3)\).

(b) \(\sqrt{13} = [3; \overline{1, 1, 1, 1, 6}]\), 주기 5(홀수). 수렴분수 \(3, 4, \frac72, \frac{11}3, \frac{18}5\)에서 \(18^2 - 13\cdot5^2 = 324 - 325 = -1\). 한 주기 더 가면 \((649, 180)\): \(649^2 - 13\cdot180^2 = 421201 - 421200 = 1\). 또는 \((18 + 5\sqrt{13})^2 = 649 + 180\sqrt{13}\)으로도 얻습니다.

7.3.2모든 해

정리 7.3.3

기본해 \((x_1, y_1)\)에 대해 양의 해는 정확히 \(x_k + y_k\sqrt d = (x_1 + y_1\sqrt d)^k\) (\(k = 1, 2, \dots\))이다.

이 꼴이 해인 이유: \(N(a + b\sqrt d) = a^2 - db^2\)는 곱셈적이므로(\((a + b\sqrt d)(a - b\sqrt d)\)) 노름 1끼리의 곱도 노름 1입니다. 모든 해가 이 꼴인 이유: 다른 해 \(u\)가 있으면 \(\varepsilon = x_1 + y_1\sqrt d\)의 거듭제곱 사이 \(\varepsilon^k < u < \varepsilon^{k+1}\)에 놓이고, \(u\varepsilon^{-k}\)는 1과 \(\varepsilon\) 사이의 해가 되어 기본해의 최소성에 모순입니다. 점화식으로는 \(x_{k+1} = x_1x_k + dy_1y_k\), \(y_{k+1} = x_1y_k + y_1x_k\). \(d = 2\)이면 \((3, 2), (17, 12), (99, 70), \dots\).

기본해의 크기는 \(d\)에 따라 들쭉날쭉합니다. \(d = 60\)은 \((31, 4)\)인데 \(d = 61\)은 \((1766319049, 226153980)\)입니다. 1657년 페르마가 이 \(d = 61\)을 도전 문제로 냈고, 인도의 바스카라 2세는 이미 12세기에 차크라발라 방법으로 풀었습니다. 같은 절의 탐구 카드에서 여러 \(d\)를 볼 수 있습니다.

흔한 실수(1) 주기가 홀수일 때 첫 주기 끝의 해를 \(+1\) 해로 쓴다(\(\sqrt{13}\)의 \((18, 5)\)는 \(-1\)). (2) \(d\)가 완전제곱수인 경우에 적용한다: \((x - ky)(x + ky) = 1\)이라 자명한 해뿐. (3) 해 \((1, 0)\)을 기본해로 둔다: 기본해는 양의 정수 \(y\)를 갖는 가장 작은 해.
요약
  1. 펠 방정식의 해 \(x/y\)는 \(\sqrt d\)의 수렴분수.
  2. 주기 \(r\)이 짝수면 \((p_{r-1}, q_{r-1})\), 홀수면 \((p_{2r-1}, q_{2r-1})\)이 기본해.
  3. 모든 해: \((x_1 + y_1\sqrt d)^k\). 노름의 곱셈성.

7.3.3연습문제

기본

  1. \(x^2 - 2y^2 = 1\)의 해 세 개를 구하여라.
    답

    \((3, 2)\), \((17, 12)\), \((99, 70)\). (\(\sqrt2\)의 수렴분수 중 짝수 번째)

응용

  1. \(\sqrt{23} = [4; \overline{1, 3, 1, 8}]\)으로 \(x^2 - 23y^2 = 1\)의 기본해를 구하여라.
    답

    주기 4(짝수). 수렴분수 \(4, 5, \frac{19}4, \frac{24}5\). \(24^2 - 23\cdot25 = 576 - 575 = 1\). \((24, 5)\).

심화

  1. \((8, 3)\)에서 \(x^2 - 7y^2 = 1\)의 두 번째 해를 점화식으로 구하여라.
    답

    \(x_2 = 8\cdot8 + 7\cdot3\cdot3 = 127\), \(y_2 = 8\cdot3 + 3\cdot8 = 48\). 검산 \(16129 - 7\cdot2304 = 16129 - 16128 = 1\).
