펠 방정식

본문

\(x^2 - 2y^2 = 1\)은 \((3, 2)\), \((17, 12)\), \((99, 70)\)처럼 정수해가 끝없이 있다. 그런데 \(x^2 - 61y^2 = 1\)의 가장 작은 양의 해는 \(x\)가 10자리 수이다. 이런 방정식의 해는 어떻게 찾을까? 그리고 해는 모두 어떤 모양일까?

먼저 알아야 할 것수렴분수(7.1절), \(\sqrt n\)의 순환 연분수(7.2절)를 쓴다.

7.3.1왜 연분수인가

\(x^2 - dy^2 = 1\)이면 \(\frac xy - \sqrt d = \frac1{y(x + y\sqrt d)}\)로 아주 작다. 즉 \(x/y\)는 \(\sqrt d\)의 매우 좋은 근사이다. 그런데 \(|\sqrt d - x/y| < \frac1{2y^2}\)인 근사는 반드시 수렴분수라는 르장드르의 정리가 있으므로, 해는 수렴분수 가운데서 찾으면 된다. 실제로 수렴분수 \(p_n/q_n\)에서 \(p_n^2 - dq_n^2\)은 작은 값들을 오가다가 주기의 끝에서 \(\pm1\)이 된다.

정리 7.3.1

\(\sqrt d = [a_0; \overline{a_1, \dots, a_r}]\)의 주기를 \(r\)이라 하자. \(r\)이 짝수이면 \((p_{r-1}, q_{r-1})\)이, \(r\)이 홀수이면 \((p_{2r-1}, q_{2r-1})\)이 \(x^2 - dy^2 = 1\)의 가장 작은 양의 해(기본해)이다. \(r\)이 홀수이면 \((p_{r-1}, q_{r-1})\)은 \(x^2 - dy^2 = -1\)의 해이다.

예제 7.3.2

(a) \(x^2 - 7y^2 = 1\) (b) \(x^2 - 13y^2 = 1\)의 기본해를 구하여라.

풀이. (a) \(\sqrt7 = [2; \overline{1, 1, 1, 4}]\)이라 주기가 4로 짝수이다. 수렴분수는 \(2, 3, \frac52, \frac83\)이고 \(p_3 = 8\), \(q_3 = 3\)에서 \(64 - 63 = 1\)이므로 기본해는 \((8, 3)\)이다. (b) \(\sqrt{13} = [3; \overline{1, 1, 1, 1, 6}]\)이라 주기가 5로 홀수이다. 수렴분수 \(3, 4, \frac72, \frac{11}3, \frac{18}5\)에서 \(18^2 - 13\cdot5^2 = 324 - 325 = -1\)이다. 그러므로 한 주기를 더 가야 하며, 그러면 \((649, 180)\)이고 \(649^2 - 13\cdot180^2 = 421201 - 421200 = 1\)이다. 물론 \((18 + 5\sqrt{13})^2 = 649 + 180\sqrt{13}\)으로도 얻는다.

7.3.2모든 해

정리 7.3.3

기본해 \((x_1, y_1)\)에 대해 양의 해는 정확히 \(x_k + y_k\sqrt d = (x_1 + y_1\sqrt d)^k\) (\(k = 1, 2, \dots\))이다.

증명.노름 \(N(a + b\sqrt d) = (a + b\sqrt d)(a - b\sqrt d) = a^2 - db^2\)은 곱셈적이므로, 노름 1끼리의 곱도 노름 1이다. 따라서 이 꼴은 모두 해이다. 거꾸로 다른 양의 해 \(u = x + y\sqrt d\)가 있다고 하자. \(\varepsilon = x_1 + y_1\sqrt d\)라 하면 \(\varepsilon^k \le u < \varepsilon^{k+1}\)인 \(k\)가 있다. \(u \ne \varepsilon^k\)이면 \(u\varepsilon^{-k}\)는 노름 1이고 1과 \(\varepsilon\) 사이에 놓이는 해가 되어, 기본해의 최소성에 모순이다. ∎

점화식으로 쓰면 \(x_{k+1} = x_1x_k + dy_1y_k\), \(y_{k+1} = x_1y_k + y_1x_k\)이다. 가령 \(d = 2\)이면 \((3, 2), (17, 12), (99, 70), \dots\)이며, 그림 1이 처음 몇 해이다.

하지만 기본해의 크기는 \(d\)에 따라 들쭉날쭉하다. \(d = 60\)은 \((31, 4)\)인데 \(d = 61\)은 \((1766319049, 226153980)\)이다. 1657년 페르마가 이 \(d = 61\)을 도전 문제로 냈는데, 인도의 바스카라 2세는 이미 12세기에 차크라발라 방법으로 풀었다. 같은 절의 탐구 카드에서 여러 \(d\)를 볼 수 있다.

흔한 오해주기가 홀수일 때 첫 주기 끝의 해를 \(+1\)의 해로 쓰기 쉽지만, \(\sqrt{13}\)의 \((18, 5)\)는 \(-1\)의 해이다. 또 \(d\)가 완전제곱수일 때 적용하는 것도 틀렸다. 그때는 \((x - ky)(x + ky) = 1\)이라 자명한 해뿐이다. 해 \((1, 0)\)을 기본해로 두는 것도 주의하며, 기본해는 \(y\)가 양의 정수인 가장 작은 해이다.
마무리

처음 질문에 답하면, \(x^2 - dy^2 = 1\)의 해는 \(\sqrt d\)의 아주 좋은 근사이므로 연분수의 수렴분수 가운데 있다. 주기 \(r\)이 짝수이면 첫 주기 끝 \((p_{r-1}, q_{r-1})\)이, 홀수이면 두 번째 주기 끝이 기본해이다. 모든 양의 해는 기본해의 거듭제곱 \((x_1 + y_1\sqrt d)^k\)이며, 이것은 노름의 곱셈성과 기본해의 최소성에서 나온다. \(d = 61\)처럼 주기가 길면 기본해가 매우 커진다.

7.3.3연습문제

기본

  1. \(x^2 - 2y^2 = 1\)의 해 세 개를 구하여라.
    답

    \((3, 2)\), \((17, 12)\), \((99, 70)\). (\(\sqrt2\)의 수렴분수 중 짝수 번째)

응용

  1. \(\sqrt{23} = [4; \overline{1, 3, 1, 8}]\)으로 \(x^2 - 23y^2 = 1\)의 기본해를 구하여라.
    답

    주기 4(짝수). 수렴분수 \(4, 5, \frac{19}4, \frac{24}5\). \(24^2 - 23\cdot25 = 576 - 575 = 1\). \((24, 5)\).

심화

  1. \((8, 3)\)에서 \(x^2 - 7y^2 = 1\)의 두 번째 해를 점화식으로 구하여라.
    답

    \(x_2 = 8\cdot8 + 7\cdot3\cdot3 = 127\), \(y_2 = 8\cdot3 + 3\cdot8 = 48\). 검산 \(16129 - 7\cdot2304 = 16129 - 16128 = 1\).
