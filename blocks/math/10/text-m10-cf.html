연분수와 수렴분수

본문

원주율을 \(22/7\)로 어림하면 오차가 약 0.001이고, \(355/113\)으로 어림하면 오차가 약 0.0000003이다. 분모가 겨우 113인데 왜 이렇게 정확할까? 분모가 정해져 있을 때 무리수에 가장 가까운 분수는 어떻게 찾을까?

먼저 알아야 할 것유클리드 호제법(1.1절), 바닥함수와 귀납법을 쓴다.

7.1.1정의

정의 7.1.1

정수 \(a_0\)과 양의 정수 \(a_1, a_2, \dots\)로 만든 \([a_0; a_1, a_2, \dots] = a_0 + \cfrac1{a_1 + \cfrac1{a_2 + \cdots}}\)를 단순 연분수라 한다. 실수 \(x\)의 전개는 \(x_0 = x\), \(a_n = \lfloor x_n\rfloor\), \(x_{n+1} = 1/(x_n - a_n)\)으로 하고 \(x_n\)이 정수가 되면 멈춘다. 앞부분까지 자른 \(\frac{p_n}{q_n} = [a_0; a_1, \dots, a_n]\)을 수렴분수라 한다.

유리수에서는 이 과정이 정확히 유클리드 호제법이다. 예를 들어 \(67 = 2\cdot29 + 9\), \(29 = 3\cdot9 + 2\), \(9 = 4\cdot2 + 1\), \(2 = 2\cdot1\)이므로 몫을 늘어놓아 \(\frac{67}{29} = [2; 3, 4, 2]\)이다. 그러므로 유한 번에 끝나는 것은 유리수뿐이고, 무리수의 전개는 끝이 없다.

7.1.2수렴분수의 점화식

정리 7.1.2

\(p_{-2} = 0\), \(p_{-1} = 1\), \(q_{-2} = 1\), \(q_{-1} = 0\)으로 두고 \(p_n = a_np_{n-1} + p_{n-2}\), \(q_n = a_nq_{n-1} + q_{n-2}\)이라 하면 \([a_0; \dots, a_n] = p_n/q_n\)이다. 또 \(p_nq_{n-1} - p_{n-1}q_n = (-1)^{n-1}\)이다.

증명.첫째 주장은 더 강한 사실, 곧 모든 양의 실수 \(t\)에 대해 \([a_0; \dots, a_{n-1}, t] = \frac{tp_{n-1} + p_{n-2}}{tq_{n-1} + q_{n-2}}\)임을 \(n\)에 대한 귀납법으로 보이면 \(t = a_n\)을 넣어 얻는다. \(n\)에서 \(n + 1\)로 갈 때 \([a_0; \dots, a_n, t] = [a_0; \dots, a_{n-1}, a_n + 1/t]\)이므로, 귀납 가정에 \(a_n + 1/t\)를 넣고 분자와 분모에 \(t\)를 곱하면 \(\frac{t(a_np_{n-1} + p_{n-2}) + p_{n-1}}{t(a_nq_{n-1} + q_{n-2}) + q_{n-1}} = \frac{tp_n + p_{n-1}}{tq_n + q_{n-1}}\)이다. 둘째 주장은 \(p_nq_{n-1} - p_{n-1}q_n = (a_np_{n-1} + p_{n-2})q_{n-1} - p_{n-1}(a_nq_{n-1} + q_{n-2}) = -(p_{n-1}q_{n-2} - p_{n-2}q_{n-1})\)에서 부호가 매번 바뀌고, \(n = -1\)에서 값이 1이므로 나온다. ∎

둘째 주장에서 \(\gcd(p_n, q_n) = 1\), 곧 수렴분수는 기약분수이다. 또 양변을 \(q_nq_{n-1}\)로 나누면 연속한 수렴분수의 차가 \(\frac{(-1)^{n-1}}{q_nq_{n-1}}\)이다. 그래서 수렴분수는 \(x\)의 양쪽을 번갈아 오가며 다가가고 \(\left|x - \frac{p_n}{q_n}\right| < \frac1{q_nq_{n+1}} < \frac1{q_n^2}\)이다. 한편 \(67/29\)에서 \(p_2q_3 - p_3q_2 = 30\cdot29 - 67\cdot13 = -1\)이므로 \(67\cdot13 - 29\cdot30 = 1\)이다. 즉 베주 계수가 수렴분수에서 나온다.

7.1.3최선의 근사

예제 7.1.3

\(\pi = [3; 7, 15, 1, 292, \dots]\)의 수렴분수와 오차를 구하여라.

풀이. 점화식으로 수렴분수는 \(3\), \(\frac{22}7\), \(\frac{333}{106}\), \(\frac{355}{113}\), \(\frac{103993}{33102}\)이다. 오차는 \(|\pi - 22/7| \approx 1.26\times10^{-3}\)이고 \(|\pi - 355/113| \approx 2.67\times10^{-7}\)이다. 다음 부분몫 292가 아주 커서 오차가 대략 \(1/(292\cdot113^2)\)이므로 \(355/113\)이 유난히 좋은 근사이다. 실제로 분모가 113 이하인 어떤 분수도 \(355/113\)보다 \(\pi\)에 가깝지 않으며, 이것이 수렴분수의 최선 근사 성질이다. 같은 절의 탐구 카드에서 여러 수의 수렴분수를 볼 수 있다.

반대로 황금비 \(\varphi = [1; 1, 1, \dots]\)는 부분몫이 모두 1이라 수렴분수, 곧 피보나치 수의 비가 가장 느리게 다가간다. 다시 말해 황금비는 분수로 근사하기 가장 어려운 무리수이다.

흔한 오해음수를 전개할 때 \(a_0\)을 0 쪽으로 버리는 실수가 많다. \(a_0 = \lfloor x\rfloor\)이므로 \(-1.5\)이면 \(-2\)이다. 또 수렴분수를 매번 연분수를 풀어 계산하기 쉬운데, 점화식을 쓰면 간단하다. 부동소수점으로 오래 전개하는 것도 주의해야 하며, 반올림 오차가 쌓여 뒤쪽 부분몫이 틀린다.
마무리

처음 질문에 답하면, \(355/113\)은 \(\pi\)의 연분수 \([3; 7, 15, 1, 292, \dots]\)을 292 앞에서 자른 수렴분수이다. 수렴분수는 늘 \(|x - p_n/q_n| < 1/(q_nq_{n+1})\)을 만족하는데, 다음 부분몫 292가 커서 \(q_{n+1}\)이 크므로 오차가 유난히 작다. 수렴분수는 점화식 \(p_n = a_np_{n-1} + p_{n-2}\)로 구하며, 분모가 그 이하인 분수 가운데 가장 가까운 근사이다.

7.1.4연습문제

기본

  1. \(\frac{43}{19}\)을 연분수로 전개하고 수렴분수를 구하여라.
    답

    \(43 = 2\cdot19 + 5\), \(19 = 3\cdot5 + 4\), \(5 = 1\cdot4 + 1\), \(4 = 4\cdot1\). \([2; 3, 1, 4]\). 수렴분수 \(2, \frac73, \frac94, \frac{43}{19}\).

응용

  1. \(\sqrt2 = [1; 2, 2, 2, \dots]\)의 수렴분수 다섯 개를 구하고 \(p^2 - 2q^2\)을 계산하여라.
    답

    \(1, \frac32, \frac75, \frac{17}{12}, \frac{41}{29}\). \(p^2 - 2q^2 = -1, 1, -1, 1, -1\).

심화

  1. \(e = [2; 1, 2, 1, 1, 4, 1, 1, 6, \dots]\)의 수렴분수 \(\frac{193}{71}\)의 오차를 \(1/q^2\)과 비교하여라.
    답

    \(|e - 193/71| \approx 2.80\times10^{-5}\), \(1/71^2 \approx 1.98\times10^{-4}\). 정리대로 더 작다.
