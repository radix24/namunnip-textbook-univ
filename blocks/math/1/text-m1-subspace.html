부분공간과 생성

본문
이 절에서 배울 것
  • 부분공간 판정법(영벡터, 덧셈, 실수배 세 가지만 확인)을 증명하고 쓴다.
  • 벡터들의 일차결합과 생성 \(\operatorname{span}\)을 정의하고, 생성이 늘 부분공간임을 보인다.
먼저 알아야 할 것
  • 벡터공간의 공리 (2.1절).

2.2.1여덟 공리를 다시 확인하지 않아도 된다

\(\mathbb R^3\) 안의 평면 \(x + y + z = 0\)이나, \(P_3\) 안에서 \(p(1) = 0\)인 다항식들처럼, 이미 아는 벡터공간 \(V\)의 일부분 \(W\)가 그 자체로 벡터공간인지 묻는 일이 많습니다. 공리 여덟 개를 모두 다시 확인할 수도 있지만, 교환법칙이나 분배법칙 같은 등식은 \(V\)에서 이미 성립하므로 \(W\)에서도 저절로 성립합니다. 확인해야 할 것은 "연산 결과가 \(W\) 밖으로 나가지 않는가"뿐입니다.

정의 2.2.1 (부분공간)

벡터공간 \(V\)의 부분집합 \(W\)가 \(V\)의 연산으로 벡터공간이 되면 \(W\)를 \(V\)의 부분공간이라 한다.

정리 2.2.2 (부분공간 판정법)

\(V\)의 부분집합 \(W\)가 부분공간일 필요충분조건은 다음 세 가지이다.

  1. \(\mathbf 0 \in W\).
  2. \(\mathbf u, \mathbf v \in W\)이면 \(\mathbf u + \mathbf v \in W\).
  3. \(\mathbf u \in W\), \(c \in \mathbb R\)이면 \(c\mathbf u \in W\).

증명.부분공간이면 \(W\)의 영벡터 \(\mathbf 0_W\)가 있고, \(\mathbf 0_W + \mathbf 0_W = \mathbf 0_W\)의 양변에 \(V\)에서의 역원 \(-\mathbf 0_W\)를 더하면 \(\mathbf 0_W = \mathbf 0\)이므로 1이 성립하고, 2, 3은 벡터공간의 정의에 든 닫힘이다. 거꾸로 1~3이 성립한다고 하자. 2, 3으로 연산이 \(W\) 안에서 정의된다. 공리 1, 2, 5~8은 등식이고 \(V\)의 모든 벡터에 대해 성립하므로 \(W\)의 벡터에 대해서도 성립한다. 공리 3은 1에서 나온다. 공리 4: \(\mathbf u \in W\)이면 3에서 \((-1)\mathbf u \in W\)이고, 정리 2.1.4에서 이것이 \(-\mathbf u\)이다. ∎

실제로는 1을 가장 먼저 확인하는 것이 요령입니다. 영벡터가 없으면 바로 끝나고, 있으면 2, 3을 일반적인 원소로 확인합니다.

예제 2.2.3

(a) \(W_1 = \{p \in P_3 : p(1) = 0\}\)은 \(P_3\)의 부분공간인가? (b) \(W_2 = \{(x, y) : xy \ge 0\}\)은 \(\mathbb R^2\)의 부분공간인가?

풀이. (a) 0 다항식은 \(0(1) = 0\)이므로 \(W_1\)에 속합니다. \(p, q \in W_1\)이면 \((p + q)(1) = p(1) + q(1) = 0\), \((cp)(1) = c\cdot 0 = 0\). 따라서 부분공간입니다. (b) 영벡터는 들어 있고 실수배에도 닫혀 있지만(\(c^2xy \ge 0\)), \((1, 0) + (0, -1) = (1, -1)\)은 \(xy = -1 < 0\)이라 덧셈에 닫혀 있지 않습니다. 부분공간이 아닙니다. 1사분면과 3사분면을 합친 모양이라, 두 사분면에서 하나씩 골라 더하면 밖으로 나갑니다.

2.2.2일차결합과 생성

부분공간을 만드는 가장 기본적인 방법은 벡터 몇 개를 골라 그것들로 만들 수 있는 것을 모두 모으는 것입니다.

일차결합: 벡터 \(\mathbf v_1, \dots, \mathbf v_k\)와 실수 \(c_1, \dots, c_k\)로 만든 \(c_1\mathbf v_1 + \dots + c_k\mathbf v_k\).

생성 \(\operatorname{span}\{\mathbf v_1, \dots, \mathbf v_k\}\): 이 벡터들의 일차결합 전체의 집합. 공집합의 생성은 \(\{\mathbf 0\}\)으로 정한다.

정리 2.2.4

\(\operatorname{span} S\)는 \(S\)를 포함하는 \(V\)의 부분공간이고, \(S\)를 포함하는 모든 부분공간에 포함된다. 곧 \(S\)를 포함하는 가장 작은 부분공간이다.

증명.계수를 모두 0으로 하면 \(\mathbf 0 \in \operatorname{span}S\). 일차결합 둘의 합은 계수끼리 더한 일차결합이고, 일차결합의 \(c\)배는 계수에 \(c\)를 곱한 일차결합이므로 판정법의 2, 3이 성립한다. 또 \(W\)가 \(S\)를 포함하는 부분공간이면 \(W\)는 덧셈과 실수배에 닫혀 있으므로 \(S\)의 원소들의 일차결합을 모두 포함한다. ∎

\(\mathbb R^3\)에서 영이 아닌 벡터 하나의 생성은 원점을 지나는 직선, 같은 직선 위에 있지 않은 두 벡터의 생성은 원점을 지나는 평면입니다. "\(\mathbf b \in \operatorname{span}\{\mathbf a_1, \dots, \mathbf a_n\}\)인가?"는 "\(A\mathbf x = \mathbf b\)가 해를 갖는가?"와 같은 질문입니다(1.2절의 열 읽기). 그래서 소거법으로 판정합니다.

예제 2.2.5

\((1, 4, 7)\)이 \(\operatorname{span}\{(1, 2, 3), (0, 1, 2)\}\)에 속하는가?

풀이. \(c_1(1, 2, 3) + c_2(0, 1, 2) = (1, 4, 7)\)을 풀면 첫 성분에서 \(c_1 = 1\), 둘째에서 \(c_2 = 2\), 셋째에서 \(3 + 4 = 7\)로 맞습니다. 속하며, \((1, 4, 7) = (1, 2, 3) + 2(0, 1, 2)\)입니다.

주의부분공간 두 개의 합집합은 일반적으로 부분공간이 아닙니다. \(x\)축과 \(y\)축의 합집합에서 \((1, 0) + (0, 1) = (1, 1)\)은 어느 축에도 없습니다. 두 부분공간을 포함하는 가장 작은 부분공간은 합집합이 아니라 합공간 \(W_1 + W_2\)이며, 2.5절에서 다룹니다.
요약
  1. 부분공간 판정: 영벡터 포함, 덧셈에 닫힘, 실수배에 닫힘. 나머지 공리는 큰 공간에서 물려받는다.
  2. 영벡터를 먼저 확인하면 빨리 걸러진다.
  3. \(\operatorname{span} S\)는 \(S\)를 포함하는 가장 작은 부분공간이다.
  4. "\(\mathbf b\)가 생성에 속하는가"는 연립방정식의 해의 존재 문제다.

2.2.3연습문제

기본

  1. \(\{(x, y, z) : x - 2y + 3z = 0\}\)이 \(\mathbb R^3\)의 부분공간임을 판정법으로 보여라.
    답

    영벡터 포함. 두 벡터가 식을 만족하면 합도 만족(좌변이 선형), \(c\)배도 만족.

  2. 대칭행렬(\(A^{\mathsf T} = A\)) 전체는 \(M_{2\times2}\)의 부분공간인가? 가역 행렬 전체는?
    답

    대칭행렬: 예. 가역 행렬: 아니다(영행렬이 가역이 아님).

응용

  1. \(\operatorname{span}\{1 + x,\ x + x^2\}\)에 \(1 - x^2\)이 속하는가? \(1 + x^2\)은?
    답

    \(1 - x^2 = (1 + x) - (x + x^2)\)이므로 속한다. \(1 + x^2 = a(1 + x) + b(x + x^2)\)이면 \(a = 1, b = 1, a + b = 0\)이 동시에 성립해야 해서 불가능. 속하지 않는다.

심화

  1. \(W_1, W_2\)가 부분공간일 때, \(W_1 \cup W_2\)가 부분공간이면 한쪽이 다른 쪽에 포함됨을 보여라.
    힌트

    귀류법: \(\mathbf u \in W_1 \setminus W_2\), \(\mathbf v \in W_2 \setminus W_1\)이 있다고 하고 \(\mathbf u + \mathbf v\)가 어디 있는지 보세요.

    답

    \(\mathbf u + \mathbf v \in W_1\)이면 \(\mathbf v = (\mathbf u + \mathbf v) - \mathbf u \in W_1\)이라 모순, \(W_2\)에 있으면 \(\mathbf u \in W_2\)라 모순. 따라서 그런 \(\mathbf u, \mathbf v\)가 동시에 있을 수 없다.
