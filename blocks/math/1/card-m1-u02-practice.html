벡터공간 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념연속함수 전체 \(C(\mathbb R)\)에서 다음은 부분공간인가? (a) \(f(0) = 1\)인 함수 (b) \(f(0) = 2f(1)\)인 함수 (c) 늘 \(f \ge 0\)인 함수 [02-02]

    힌트 1

    먼저 영함수(늘 0)가 들어 있는지 보세요(2.2절).

    힌트 2

    (c)는 실수배 \(c = -1\)을 해 보세요.

    풀이

    (a) 영함수는 \(0(0) = 0 \ne 1\)이라 아니다. (b) 영함수 포함. \(f(0) = 2f(1)\), \(g(0) = 2g(1)\)이면 \((f + g)(0) = 2(f + g)(1)\), \((cf)(0) = 2(cf)(1)\). 부분공간이다. (c) \(f(x) = 1\)이면 \((-1)f\)는 음수라 실수배에 닫혀 있지 않다. 아니다.

  2. 계산\((1, 1, 0, 2), (2, 1, 1, 3), (0, 1, -1, 1), (1, 0, 1, 1)\)의 생성의 기저와 차원을 구하고, 버린 벡터를 기저로 나타내어라. [02-03, 02-04]

    힌트 1

    열로 세워 기약 행사다리꼴을 구하고 피벗 열을 고릅니다.

    힌트 2

    셋째 벡터는 \(2\mathbf v_1 - \mathbf v_2\), 넷째는 \(\mathbf v_2 - \mathbf v_1\)인지 확인해 보세요.

    풀이

    \(2\mathbf v_1 - \mathbf v_2 = (0, 1, -1, 1) = \mathbf v_3\), \(\mathbf v_2 - \mathbf v_1 = (1, 0, 1, 1) = \mathbf v_4\). \(\mathbf v_1, \mathbf v_2\)는 평행하지 않으므로 일차독립. 기저 \(\{\mathbf v_1, \mathbf v_2\}\), 차원 2. (열로 세운 행렬의 기약 행사다리꼴에서 피벗 열이 1, 2열이고 3, 4열이 \((2, -1)\), \((-1, 1)\)로 같은 계수를 보여 준다.)

  3. 증명\(\{\mathbf u, \mathbf v, \mathbf w\}\)가 일차독립이면 \(\{\mathbf u + \mathbf v,\ \mathbf v + \mathbf w,\ \mathbf w + \mathbf u\}\)도 일차독립임을 보여라. [02-03]

    힌트 1

    \(a(\mathbf u + \mathbf v) + b(\mathbf v + \mathbf w) + c(\mathbf w + \mathbf u) = \mathbf 0\)을 \(\mathbf u, \mathbf v, \mathbf w\)로 정리하세요.

    힌트 2

    \(a + c = 0,\ a + b = 0,\ b + c = 0\)을 풀면 됩니다.

    풀이

    정리하면 \((a + c)\mathbf u + (a + b)\mathbf v + (b + c)\mathbf w = \mathbf 0\). 원래 집합이 일차독립이므로 세 계수가 모두 0. 세 식을 더하면 \(2(a + b + c) = 0\)이고, 여기서 각 식을 빼면 \(b = 0, c = 0, a = 0\). 따라서 일차독립. ∎ (실수 대신 계수가 0과 1뿐인 세계(\(1 + 1 = 0\))에서는 \(2\)로 나눌 수 없어 결론이 깨진다.)

  4. 계산\(W = \{p \in P_3 : p(0) = 0,\ p'(0) = 0\}\)의 차원을 구하고, \(W\)의 기저를 \(P_3\)의 기저로 확장하여라. [02-03, 02-04]

    힌트 1

    \(p(x) = a + bx + cx^2 + dx^3\)에서 조건이 \(a, b\)에 무엇을 요구하나요?

    힌트 2

    \(W = \operatorname{span}\{x^2, x^3\}\). 생성 밖의 \(1, x\)를 보탭니다.

    풀이

    \(p(0) = a = 0\), \(p'(0) = b = 0\)이므로 \(W = \{cx^2 + dx^3\}\), 기저 \(\{x^2, x^3\}\), 차원 2. 표준기저에서 \(1 \notin W\)라 보태고, \(x \notin \operatorname{span}\{x^2, x^3, 1\}\)이라 보탠다. \(\{x^2, x^3, 1, x\}\)는 4개이고 \(\dim P_3 = 4\)이므로 기저(따름정리 2.4.4).

  5. 판단한 학생이 "\(\mathbb R^4\)의 두 2차원 부분공간의 합은 늘 4차원이다"라고 썼다. 맞는가? 합의 차원이 될 수 있는 값을 모두 들어라. [02-05]

    힌트 1

    차원 공식에서 \(\dim(W_1 \cap W_2)\)는 0, 1, 2 가운데 무엇이든 될 수 있습니다.

    힌트 2

    두 부분공간이 같으면 합은 무엇일까요?

    풀이

    틀렸다. \(\dim(W_1 + W_2) = 4 - \dim(W_1\cap W_2)\)이고 교집합의 차원은 0, 1, 2가 모두 가능하다. 예: \(W_1 = W_2\)이면 합은 2차원, \(W_1 = \operatorname{span}\{\mathbf e_1, \mathbf e_2\}, W_2 = \operatorname{span}\{\mathbf e_2, \mathbf e_3\}\)이면 3차원, \(W_2 = \operatorname{span}\{\mathbf e_3, \mathbf e_4\}\)이면 4차원.

  6. 도전\(V\)가 \(n\)차원이고 \(W\)가 부분공간이면 \(V = W \oplus U\)인 부분공간 \(U\)(보공간)가 있음을 보여라. [02-03, 02-05]

    힌트 1

    \(W\)의 기저를 \(V\)의 기저로 확장하세요(정리 2.3.5).

    힌트 2

    보탠 벡터들의 생성을 \(U\)로 잡고, 정리 2.5.5의 (b)나 (c)를 확인합니다.

    풀이

    \(W\)의 기저 \(\{\mathbf w_1, \dots, \mathbf w_k\}\)를 \(V\)의 기저 \(\{\mathbf w_1, \dots, \mathbf w_k, \mathbf u_1, \dots, \mathbf u_{n-k}\}\)로 확장하고 \(U = \operatorname{span}\{\mathbf u_j\}\)로 둔다. 확장한 기저가 \(V\)를 생성하므로 \(V = W + U\). \(\dim W + \dim U = k + (n - k) = n = \dim V\)이므로 정리 2.5.5 (c)에 따라 직합이다. ∎
