행렬식의 곱셈성과 가역성

본문
이 절에서 배울 것
  • \(A\)가 가역 ⇔ \(\det A \ne 0\)을 증명한다.
  • \(\det(AB) = \det A\det B\)를 기본 행렬로 증명하고, \(\det A^{-1} = 1/\det A\)를 얻는다.
  • 행렬식을 "넓이의 배율"로 해석한다.
먼저 알아야 할 것
  • 기본 행렬과 가역 행렬 정리 (1.3절), 행 연산과 행렬식 (5.1절).

5.3.1기본 행렬의 행렬식

5.1절의 정리 5.1.2를 단위행렬에 적용하면 기본 행렬의 행렬식이 바로 나옵니다. 교환 행렬은 \(-1\), \(c\)배 행렬은 \(c\), 배수 더하기 행렬은 1입니다. 그리고 \(EA\)는 \(A\)에 그 행 연산을 한 것이므로(정리 1.3.2)

\[\det(EA) = \det E\cdot\det A \qquad (E\text{는 기본 행렬})\]

입니다. 예를 들어 \(E\)가 교환이면 왼쪽은 \(-\det A\), 오른쪽도 \((-1)\det A\)입니다. 곱셈성의 증명은 이 특수한 경우에서 출발합니다.

5.3.2가역성의 판정

정리 5.3.1

\(n\times n\) 행렬 \(A\)가 가역 ⇔ \(\det A \ne 0\).

증명.\(A\)를 기약 행사다리꼴 \(R\)로 소거하면 \(R = E_k\cdots E_1A\)이고, 위의 식을 \(k\)번 쓰면 \(\det R = \det E_k\cdots\det E_1\det A\)이다. 기본 행렬의 행렬식은 0이 아니므로 \(\det A \ne 0\) ⇔ \(\det R \ne 0\)이다. \(A\)가 가역이면 \(R = I\)라 \(\det R = 1\). 가역이 아니면 \(R\)에 영인 행이 있어(정리 1.3.5) \(\det R = 0\). ∎

이제 1.3절의 가역 행렬 정리 목록에 "\(\det A \ne 0\)"이 붙습니다. 수 하나만 계산하면 가역성을 알 수 있다는 것이 행렬식의 가장 큰 쓸모입니다.

5.3.3곱셈성

정리 5.3.2

\(n\times n\) 행렬 \(A, B\)에 대해 \(\det(AB) = \det A\det B\).

아이디어는 경우를 나누는 것입니다. \(A\)가 가역이면 기본 행렬의 곱이므로 기본 행렬에 대한 식을 여러 번 쓰면 되고, 가역이 아니면 양변이 모두 0임을 보입니다.

증명.\(A\)가 가역이면 \(A = E_1\cdots E_k\)(정리 1.3.5)이다. 그러면 \(\det(AB) = \det(E_1\cdots E_kB) = \det E_1\det(E_2\cdots E_kB) = \cdots = \det E_1\cdots\det E_k\det B\)이고, 같은 계산을 \(B = I\)로 하면 \(\det A = \det E_1\cdots\det E_k\)이므로 \(\det(AB) = \det A\det B\). \(A\)가 가역이 아니면 \(\det A = 0\)이다. 이때 \(AB\)도 가역이 아니다(가역이라면 \(A(BC) = I\)인 \(C\)가 있어 \(A\)가 가역이 됨, 1.3절 연습 5 참고). 따라서 \(\det(AB) = 0 = \det A\det B\). ∎

곧바로 따라 나오는 것들:

  • \(\det A^{-1} = \dfrac{1}{\det A}\) (\(AA^{-1} = I\)의 양변에 \(\det\)).
  • \(\det(Q^{-1}AQ) = \det A\): 닮은 행렬은 행렬식이 같다(3.3절에서 미뤄 둔 것).
  • \(\det(AB) = \det(BA)\): \(AB \ne BA\)여도 행렬식은 같다.

5.3.4넓이의 배율로 읽기

\(\mathbb R^2\)에서 \(A\)는 단위정사각형을 넓이 \(|\det A|\)인 평행사변형으로 보냅니다. 어떤 도형이든 작은 정사각형들로 채워 생각하면, \(A\)는 모든 도형의 넓이를 \(|\det A|\)배 합니다. 그러면 곱셈성은 "\(B\)로 \(|\det B|\)배, 다시 \(A\)로 \(|\det A|\)배 하면 모두 \(|\det A||\det B|\)배"라는 당연한 말이 됩니다. 부호는 방향(앞면·뒷면)이 뒤집히는지를 나타냅니다. 해석학(2)의 다중적분 변수변환에서 야코비 행렬식 \(|\det J|\)가 넓이 요소의 배율로 나오는 것이 이 사실입니다.

예제 5.3.3

\(A = \begin{pmatrix} 2 & 1 \\ 1 & 3\end{pmatrix}\)이 단위원(넓이 \(\pi\))을 보내는 타원의 넓이를 구하여라.

풀이. \(\det A = 6 - 1 = 5\)이므로 넓이는 \(5\pi\)입니다. 타원의 반지름을 구하지 않아도 됩니다(선형대수(2)의 특이값 분해 탐구 카드에서 \(\sigma_1\sigma_2 = |\det A|\)로 확인할 수 있습니다).

주의"\(\det A = \det B\)이면 \(A = B\)"나 "\(\det A = 1\)이면 \(A = I\)"는 틀립니다. 층밀림 \(\begin{pmatrix} 1 & 5 \\ 0 & 1\end{pmatrix}\)은 행렬식이 1이지만 단위행렬이 아닙니다. 행렬식은 넓이의 배율 하나만 알려 줄 뿐, 모양이 어떻게 바뀌는지는 알려 주지 않습니다.
요약
  1. 기본 행렬 \(E\)에 대해 \(\det(EA) = \det E\det A\).
  2. 가역 ⇔ \(\det A \ne 0\).
  3. \(\det(AB) = \det A\det B\), \(\det A^{-1} = 1/\det A\), 닮은 행렬은 행렬식이 같다.
  4. \(|\det A|\)는 넓이(부피)의 배율, 부호는 방향의 보존 여부이다.

5.3.5연습문제

기본

  1. \(\det A = 2\), \(\det B = -3\)인 \(3\times3\) 행렬에 대해 \(\det(A^2B^{-1})\), \(\det(A^{\mathsf T}B)\)는?
    답

    \(4\cdot(-\frac13) = -\frac43\), \(2\cdot(-3) = -6\).

응용

  1. \(A^2 = A\)인 정사각행렬의 행렬식은 0이나 1뿐임을 보여라.
    답

    \((\det A)^2 = \det A\)이므로 \(\det A \in \{0, 1\}\).

  2. \(n\)이 홀수이고 \(A^{\mathsf T} = -A\)이면 \(\det A = 0\)임을 보여라.
    답

    \(\det A = \det A^{\mathsf T} = \det(-A) = (-1)^n\det A = -\det A\).

심화

  1. \(A\)의 모든 성분이 정수이고 \(A^{-1}\)의 모든 성분도 정수이면 \(\det A = \pm1\)임을 보여라. 거꾸로 \(\det A = \pm 1\)이고 성분이 정수이면 \(A^{-1}\)의 성분도 정수임을 다음 절의 공식으로 보여라.
    답

    정수 성분 행렬의 행렬식은 정수(라이프니츠 공식). \(\det A\det A^{-1} = 1\)인 두 정수이므로 \(\pm1\). 거꾸로 \(A^{-1} = \frac{1}{\det A}\operatorname{adj}A\)이고 수반행렬의 성분은 정수 소행렬식이다.
