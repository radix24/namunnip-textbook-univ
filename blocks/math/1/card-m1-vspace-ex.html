미분방정식의 해 전체는 벡터공간인가

예제 · 공리 확인과 반례

먼저 예측

\(y'' + y = 0\)의 해 전체와 \(y'' + y = 1\)의 해 전체 가운데 어느 쪽이 벡터공간일까요?

예측 확인

앞의 것(동차)만 벡터공간입니다. 1.2절의 동차 연립방정식과 같은 이유입니다.

두 번 미분 가능한 함수 전체의 공간에서 (a) \(S_0 = \{y : y'' + y = 0\}\)이 함수의 덧셈과 실수배로 벡터공간임을 보이고, (b) \(S_1 = \{y : y'' + y = 1\}\)은 벡터공간이 아님을 보여라.

전략

함수 공간 전체는 이미 벡터공간이므로(예제 2.1.2), 여덟 공리의 등식은 물려받습니다. 남는 것은 닫힘과 영벡터입니다. 2.2절의 부분공간 판정법을 미리 쓰는 셈입니다. (b)는 깨지는 조건 하나를 구체적으로 보입니다.

풀이

  1. 영함수 \(y = 0\)은 \(0'' + 0 = 0\)이므로 \(S_0\)에 속한다.
    공리 3(영벡터)은 함수 공간의 영벡터가 \(S_0\) 안에 있어야 성립한다.
  2. \(y_1, y_2 \in S_0\)이면 \((y_1 + y_2)'' + (y_1 + y_2) = (y_1'' + y_1) + (y_2'' + y_2) = 0\).
    미분은 합을 합으로 보낸다(미분의 선형성). 덧셈에 닫혀 있다.
  3. \(c\)가 실수이면 \((cy_1)'' + cy_1 = c(y_1'' + y_1) = 0\).
    상수배의 미분. 실수배에 닫혀 있다.
  4. 나머지 공리(교환·결합·분배 법칙 등)는 함수 공간 전체에서 성립하는 등식이므로 \(S_0\)에서도 성립한다. 역원 \(-y_1 = (-1)y_1\)도 3단계로 \(S_0\)에 있다. 따라서 \(S_0\)은 벡터공간이다.
    큰 공간에서 등식이 성립하면 그 부분집합의 원소에 대해서도 성립한다.
  5. \(S_1\): 영함수는 \(0'' + 0 = 0 \ne 1\)이라 \(S_1\)에 없다. 또 \(y = 1\)은 \(S_1\)의 원소인데 \(1 + 1 = 2\)는 \(2'' + 2 = 2 \ne 1\)이라 \(S_1\)에 없다. 벡터공간이 아니다.
    영벡터 공리와 덧셈의 닫힘이 모두 깨진다. 반례 하나면 충분하다.

검산

\(\sin x, \cos x \in S_0\)이므로 \(3\sin x - 2\cos x\)도 \(S_0\)에 있어야 합니다: 두 번 미분하면 \(-3\sin x + 2\cos x\)이고, 원래 함수를 더하면 0. 맞습니다.

의미

\(S_0\)이 벡터공간이므로 2~3단원의 도구(기저, 차원)를 쓸 수 있습니다. \(S_0\)은 \(\{\sin x, \cos x\}\)를 기저로 하는 2차원 공간이고(상미분방정식, 수학6 2단원), \(S_1\)은 \(S_0\)을 특수해 \(y = 1\)만큼 옮긴 \(1 + S_0\)입니다. 연립방정식의 "특수해 + 동차 해"와 똑같은 구조입니다.

이해 확인

\(y' = y^2\)의 해 전체는 벡터공간인가요?

답

아닙니다. \(y = \frac{1}{1 - x}\)(\(x < 1\))이 해인데 \(2y\)는 \((2y)' = 2y^2 \ne 4y^2 = (2y)^2\)이라 해가 아닙니다. 비선형 방정식이라 실수배에 닫혀 있지 않습니다.
