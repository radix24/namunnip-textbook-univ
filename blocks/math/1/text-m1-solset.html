동차와 비동차 방정식의 해집합

본문
이 절에서 배울 것
  • 행렬과 벡터의 곱 \(A\mathbf x\)로 연립방정식을 한 줄로 쓴다.
  • 동차 방정식 \(A\mathbf x = \mathbf 0\)의 해집합이 덧셈과 실수배에 대해 닫혀 있음을 보인다.
  • 비동차 방정식의 해집합이 "특수해 하나 + 동차 해 전체"임을 증명하고 그림으로 이해한다.
먼저 알아야 할 것
  • 기약 행사다리꼴과 자유변수 (1.1절).

1.2.1행렬과 벡터의 곱

지금까지는 방정식을 하나씩 썼습니다. 방정식이 많아지면 이것을 한 식으로 묶어 쓰는 편이 생각하기 쉽습니다. 그래서 \(m\times n\) 행렬 \(A\)와 성분이 \(n\)개인 열벡터 \(\mathbf x\)의 곱을 다음처럼 정합니다.

정의 1.2.1 (행렬과 벡터의 곱)

\(A\mathbf x\)는 성분이 \(m\)개인 열벡터이고, 그 \(i\)째 성분은 \(A\)의 \(i\)째 행과 \(\mathbf x\)의 성분을 차례로 곱해 더한 \(a_{i1}x_1 + a_{i2}x_2 + \dots + a_{in}x_n\)이다.

이렇게 정하면 연립방정식 전체가 \(A\mathbf x = \mathbf b\) 한 줄이 됩니다. 같은 곱을 열 쪽에서 보면 \(A\mathbf x = x_1\mathbf a_1 + x_2\mathbf a_2 + \dots + x_n\mathbf a_n\)입니다(\(\mathbf a_j\)는 \(A\)의 \(j\)째 열). 곧 "\(A\mathbf x = \mathbf b\)를 푼다"는 것은 "\(\mathbf b\)를 \(A\)의 열들의 일차결합으로 쓰는 계수를 찾는다"와 같습니다. 이 두 번째 읽기가 2단원 벡터공간의 출발점입니다.

정의에서 곧바로 다음 두 성질이 나옵니다. 각 성분이 곱의 합이므로, 분배법칙을 성분마다 쓰면 됩니다.

\[A(\mathbf x + \mathbf y) = A\mathbf x + A\mathbf y,\qquad A(c\mathbf x) = c(A\mathbf x).\]

1.2.2동차 방정식

우변이 \(\mathbf 0\)인 \(A\mathbf x = \mathbf 0\)을 동차 방정식이라고 합니다. \(\mathbf x = \mathbf 0\)은 늘 해이므로(자명한 해) 동차 방정식은 해가 없을 수 없습니다. 관심은 0이 아닌 해가 있는가, 있다면 해들이 어떤 모양인가입니다.

정리 1.2.2

\(\mathbf u, \mathbf v\)가 \(A\mathbf x = \mathbf 0\)의 해이고 \(c\)가 실수이면, \(\mathbf u + \mathbf v\)와 \(c\mathbf u\)도 해이다.

증명.1.2.1의 두 성질로 \(A(\mathbf u + \mathbf v) = A\mathbf u + A\mathbf v = \mathbf 0 + \mathbf 0 = \mathbf 0\)이고, \(A(c\mathbf u) = c(A\mathbf u) = c\mathbf 0 = \mathbf 0\)이다. ∎

그래서 동차 해집합은 원점을 지나는 직선, 평면, 또는 그보다 높은 차원의 "평평한" 집합입니다. 해 둘을 더하거나 늘여도 밖으로 나가지 않기 때문입니다. 이런 집합을 2단원에서 부분공간이라고 부르고, \(A\mathbf x = \mathbf 0\)의 해집합을 \(A\)의 영공간 \(N(A)\)라고 합니다.

기약 행사다리꼴에서 자유변수 하나마다 방향 벡터가 하나씩 생깁니다. 자유변수 \(t_1, \dots, t_k\)가 있으면 동차 해는 \(t_1\mathbf v_1 + \dots + t_k\mathbf v_k\) 꼴이고, 여기서 \(\mathbf v_i\)는 \(i\)째 자유변수만 1, 나머지 자유변수는 0으로 두고 구한 해입니다.

1.2.3비동차 방정식: 특수해 + 동차 해

우변이 \(\mathbf 0\)이 아니면 해 둘의 합은 해가 아닙니다(\(A(\mathbf u + \mathbf v) = 2\mathbf b\)). 대신 해 둘의 차가 동차 해가 됩니다. 이것이 해집합 전체의 모양을 정합니다.

정리 1.2.3 (해집합의 구조)

\(\mathbf p\)가 \(A\mathbf x = \mathbf b\)의 해 하나(특수해)라고 하자. 그러면 \(A\mathbf x = \mathbf b\)의 해집합은 \(\{\mathbf p + \mathbf h : A\mathbf h = \mathbf 0\}\)이다.

증명.두 집합이 서로 포함됨을 보인다. 먼저 \(A\mathbf h = \mathbf 0\)이면 \(A(\mathbf p + \mathbf h) = A\mathbf p + A\mathbf h = \mathbf b + \mathbf 0 = \mathbf b\)이므로 \(\mathbf p + \mathbf h\)는 해다. 거꾸로 \(\mathbf x\)가 해이면 \(\mathbf h = \mathbf x - \mathbf p\)로 두자. \(A\mathbf h = A\mathbf x - A\mathbf p = \mathbf b - \mathbf b = \mathbf 0\)이므로 \(\mathbf h\)는 동차 해이고 \(\mathbf x = \mathbf p + \mathbf h\)이다. ∎

그림으로는 비동차 해집합이 동차 해집합(원점을 지나는 평평한 집합)을 \(\mathbf p\)만큼 평행이동한 것입니다. 원점을 지나지 않는 직선이나 평면이 되는 것이지요. 특수해는 그 직선 위 아무 점이나 골라도 됩니다. 다른 특수해를 고르면 같은 집합을 다른 점에서 출발해 쓴 것일 뿐입니다.

예제 1.2.4

\(x + y - z = 1,\ 2x + y + z = 4\)의 해집합을 "특수해 + 동차 해"로 쓰고 기하적 모양을 말하여라.

풀이. \(R_2 \to R_2 - 2R_1\): \((0, -1, 3 \mid 2)\). \(R_2 \to -R_2\): \((0, 1, -3 \mid -2)\). \(R_1 \to R_1 - R_2\): \((1, 0, 2 \mid 3)\). 자유변수 \(z = t\)로 두면 \(x = 3 - 2t,\ y = -2 + 3t\), 곧

\[\begin{pmatrix} x\\y\\z\end{pmatrix} = \begin{pmatrix} 3\\-2\\0\end{pmatrix} + t\begin{pmatrix} -2\\3\\1\end{pmatrix}.\]

첫째 벡터가 특수해(\(t = 0\)), 둘째 항이 동차 해 전체입니다. 두 평면의 교선으로, 점 \((3, -2, 0)\)을 지나고 방향이 \((-2, 3, 1)\)인 직선입니다. 검산: 방향 벡터를 두 식의 좌변에 넣으면 \(-2 + 3 - 1 = 0\), \(-4 + 3 + 1 = 0\)으로 동차 해가 맞습니다.

1.2.4해의 개수와 동차 해

정리 1.2.3에서 바로 나오는 결론이 있습니다. 해가 하나라도 있으면, 해의 개수는 동차 해의 개수와 같습니다(\(\mathbf h \mapsto \mathbf p + \mathbf h\)가 일대일대응이므로). 그러므로

  • \(A\mathbf x = \mathbf 0\)의 해가 \(\mathbf 0\)뿐이면, 모든 \(\mathbf b\)에 대해 \(A\mathbf x = \mathbf b\)의 해는 많아야 하나입니다.
  • \(A\mathbf x = \mathbf 0\)에 0이 아닌 해가 있으면, \(A\mathbf x = \mathbf b\)는 해가 없거나 무수히 많습니다.

"해가 있는가"는 \(\mathbf b\)에 달렸고(상수 열에 피벗이 서는가), "있다면 몇 개인가"는 \(A\)만으로 정해집니다. 이 둘을 나누어 생각하는 것이 선형대수의 기본 습관입니다.

주의"비동차 방정식의 해집합도 부분공간이다"는 틀립니다. \(\mathbf b \ne \mathbf 0\)이면 \(\mathbf 0\)이 해가 아니므로 원점을 지나지 않고, 해 둘의 합도 해가 아닙니다. 평행이동한 집합(아핀 부분공간)일 뿐입니다.
요약
  1. 연립방정식은 \(A\mathbf x = \mathbf b\)로 쓰고, \(A\mathbf x\)는 \(A\)의 열들의 일차결합이다.
  2. 동차 해집합은 덧셈과 실수배에 닫혀 있다(영공간).
  3. 비동차 해집합 = 특수해 + 동차 해 전체. 동차 해집합을 평행이동한 것이다.
  4. 해가 있을 때 해의 개수는 동차 해가 정한다.

1.2.5연습문제

기본

  1. \(x - 2y + z = 0\)의 해집합을 두 방향 벡터의 일차결합으로 써라.
    답

    \(y = s,\ z = t\)로 두면 \((x, y, z) = s(2, 1, 0) + t(-1, 0, 1)\). 원점을 지나는 평면.

  2. \(\mathbf p = (1, 1, 1)\)이 \(x + y + z = 3\)의 해임을 확인하고, 해집합을 "특수해 + 동차 해"로 써라.
    답

    \((1, 1, 1) + s(-1, 1, 0) + t(-1, 0, 1)\).

응용

  1. \(\mathbf u, \mathbf v\)가 \(A\mathbf x = \mathbf b\)의 해이면 \(\frac12(\mathbf u + \mathbf v)\)도 해임을 보여라. \(\mathbf u + \mathbf v\)는 왜 일반적으로 해가 아닌가?
    답

    \(A(\frac12(\mathbf u + \mathbf v)) = \frac12(\mathbf b + \mathbf b) = \mathbf b\). 합은 \(2\mathbf b\)가 되어 \(\mathbf b \ne \mathbf 0\)이면 해가 아니다. 더 일반적으로 계수의 합이 1인 일차결합은 해이다.

심화

  1. \(3\times 3\) 행렬 \(A\)에 대해 \(A\mathbf x = \mathbf b_1\)은 해가 하나뿐이다. 그러면 \(A\mathbf x = \mathbf b_2\)는 어떤 \(\mathbf b_2\)에 대해서도 해가 하나뿐임을 보여라.
    힌트

    해가 하나뿐이면 동차 해는 \(\mathbf 0\)뿐이고, 기약 행사다리꼴에 피벗이 세 개입니다.

    답

    정리 1.2.3으로 동차 해가 \(\mathbf 0\)뿐이므로 \(A\)의 기약 행사다리꼴에 자유변수가 없다. 열이 셋이므로 피벗이 셋이고 행도 셋이라 모든 행에 피벗이 있다. 그러면 첨가행렬의 상수 열에는 피벗이 설 수 없으므로 어떤 \(\mathbf b_2\)에도 해가 있고, 동차 해가 \(\mathbf 0\)뿐이라 하나뿐이다.
