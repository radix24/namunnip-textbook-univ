쌍대공간과 전치사상

본문
이 절에서 배울 것
  • 일차범함수와 쌍대공간 \(V^*\)를 정의한다.
  • 기저 \(\beta\)의 쌍대기저 \(\beta^*\)를 구하고, 쌍대기저가 "좌표를 읽는 함수"임을 안다.
  • 전치사상 \(T^{\mathsf t}\)의 행렬이 \(T\)의 행렬의 전치행렬임을 증명한다.
먼저 알아야 할 것
  • 좌표와 행렬표현 (3.2절), 동형 (3.4절).

4.2.1벡터에서 수를 꺼내는 일차변환

지금까지 쓴 연산 가운데 벡터를 받아 수 하나를 내놓는 것이 많았습니다. 좌표의 \(i\)째 성분 읽기, 다항식의 \(x = 2\)에서의 값 \(p \mapsto p(2)\), 적분 \(f \mapsto \int_0^1 f\), 행렬의 대각합. 모두 일차변환이고, 값이 실수입니다. 이런 것들을 모아 하나의 공간으로 보면, 방정식이나 측정을 "벡터"처럼 다룰 수 있습니다.

정의 4.2.1 (쌍대공간)

일차변환 \(f: V \to \mathbb R\)를 \(V\) 위의 일차범함수라 한다. 일차범함수 전체에 함수의 덧셈과 실수배를 준 벡터공간을 \(V\)의 쌍대공간 \(V^*\)라 한다.

\(\mathbb R^n\) 위의 일차범함수는 표준기저에 대한 \(1\times n\) 행렬, 곧 행벡터 \((a_1, \dots, a_n)\)로 나타나고 \(f(\mathbf x) = a_1x_1 + \dots + a_nx_n\)입니다. 방정식 하나 \(a_1x_1 + \dots + a_nx_n = b\)의 좌변이 일차범함수인 셈입니다. 1단원에서 행 연산이 "방정식끼리 더하기"였던 것도, 쌍대공간의 원소끼리 더한 것입니다.

4.2.2쌍대기저

정리 4.2.2 (쌍대기저)

\(\beta = (\mathbf v_1, \dots, \mathbf v_n)\)이 \(V\)의 순서기저일 때, \(f_i(\mathbf v_j) = 1\) (\(i = j\)), \(0\) (\(i \ne j\))로 정한 일차범함수 \(f_1, \dots, f_n\)은 \(V^*\)의 기저이다. 이것을 \(\beta\)의 쌍대기저 \(\beta^*\)라 한다. 특히 \(\dim V^* = \dim V\).

일차변환은 기저의 값으로 정해지므로(3.1절) \(f_i\)는 하나씩 잘 정의됩니다. \(f_i\)는 무엇을 할까요? \(\mathbf v = \sum a_j\mathbf v_j\)이면 \(f_i(\mathbf v) = \sum a_jf_i(\mathbf v_j) = a_i\)입니다. 곧 \(f_i\)는 \(\beta\)-좌표의 \(i\)째 성분을 읽는 함수입니다.

증명.일차독립: \(\sum c_if_i = 0\)(영함수)이면 \(\mathbf v_j\)에 넣어 \(c_j = 0\). 생성: \(f \in V^*\)이면 \(g = \sum f(\mathbf v_i)f_i\)는 각 \(\mathbf v_j\)에서 \(f(\mathbf v_j)\)로 \(f\)와 같은 값을 가지므로, 기저에서 값이 같은 두 일차변환은 같아 \(f = g\). ∎

마지막 식 \(f = \sum f(\mathbf v_i)f_i\)는 \(V^*\)에서의 좌표가 "\(f\)를 기저 벡터에 넣은 값"이라는 뜻입니다.

예제 4.2.3

\(\mathbb R^2\)의 기저 \(\beta = ((2, 1), (3, 1))\)의 쌍대기저를 구하여라.

풀이. \(f_1(x, y) = ax + by\)라 하면 \(f_1(2, 1) = 2a + b = 1\), \(f_1(3, 1) = 3a + b = 0\)에서 \(a = -1, b = 3\). 같은 방법으로 \(f_2\): \(2a + b = 0,\ 3a + b = 1\)에서 \(a = 1, b = -2\). 따라서 \(f_1(x, y) = -x + 3y\), \(f_2(x, y) = x - 2y\).

계산을 정리하면 쌍대기저의 행벡터들은 \(Q = \begin{pmatrix} 2 & 3 \\ 1 & 1\end{pmatrix}\)(\(\beta\)를 열로 세운 행렬)의 역행렬의 행입니다: \(Q^{-1} = \begin{pmatrix} -1 & 3 \\ 1 & -2\end{pmatrix}\). \(Q^{-1}Q = I\)의 \((i, j)\) 성분이 \(f_i(\mathbf v_j)\)이기 때문입니다. 3.3절에서 새 좌표를 \(Q^{-1}\)로 구했던 것과 같은 이야기입니다.

4.2.3전치사상

\(T: V \to W\)가 있으면 \(W\) 위의 범함수 \(g\)를 \(V\) 위의 범함수로 "끌어올" 수 있습니다. 먼저 \(T\)로 보내고 \(g\)로 재면 됩니다.

정의 4.2.4 (전치사상)

\(T: V \to W\)의 전치사상 \(T^{\mathsf t}: W^* \to V^*\)는 \(T^{\mathsf t}(g) = g\circ T\)로 정의한다.

방향이 거꾸로(\(W^* \to V^*\))인 것에 주의하세요. \(g\circ T\)는 \(V\)의 벡터를 받아 수를 내므로 \(V^*\)의 원소입니다. \(T^{\mathsf t}\)가 일차변환인 것은 \((g_1 + g_2)\circ T = g_1\circ T + g_2\circ T\)에서 나옵니다.

정리 4.2.5

\(\beta, \gamma\)가 \(V, W\)의 순서기저이면 \([T^{\mathsf t}]_{\gamma^*}^{\beta^*} = \left([T]_\beta^\gamma\right)^{\mathsf T}\).

증명.\(A = [T]_\beta^\gamma\)이고 \(\beta = (\mathbf v_j)\), \(\gamma = (\mathbf w_i)\), 쌍대기저를 \((f_j)\), \((g_i)\)라 하자. \(A\)의 \((i, j)\) 성분은 \(T\mathbf v_j\)의 \(\gamma\)-좌표의 \(i\)째 성분이므로 \(a_{ij} = g_i(T\mathbf v_j)\)이다(쌍대기저는 좌표를 읽는 함수). 한편 \([T^{\mathsf t}]\)의 \(i\)째 열은 \(T^{\mathsf t}(g_i) = g_i\circ T\)의 \(\beta^*\)-좌표이고, 4.2.2의 끝 식에 따라 그 \(j\)째 성분은 \((g_i\circ T)(\mathbf v_j) = a_{ij}\)이다. 곧 \([T^{\mathsf t}]\)의 \((j, i)\) 성분이 \(a_{ij}\)이므로 전치행렬이다. ∎

그래서 행렬의 전치는 단순한 "성분 뒤집기"가 아니라, 범함수를 거꾸로 끌어오는 연산의 행렬입니다. \((AB)^{\mathsf T} = B^{\mathsf T}A^{\mathsf T}\)도 \((UT)^{\mathsf t}(h) = h\circ U\circ T = T^{\mathsf t}(U^{\mathsf t}(h))\)로 이해할 수 있습니다.

주의쌍대기저의 \(f_i\)는 \(\mathbf v_i\) 하나만 보고 정해지지 않고 기저 전체에 달려 있습니다. 예제 4.2.3에서 \(\mathbf v_1 = (2, 1)\)은 그대로 두고 \(\mathbf v_2\)만 \((0, 1)\)로 바꾸면 \(f_1\)이 \(\frac12x\)로 바뀝니다. "\(\mathbf v_1\) 방향의 좌표"는 다른 기저 벡터들이 무엇인지 알아야 정해집니다.
요약
  1. 일차범함수는 벡터를 수로 보내는 일차변환이고, 그 전체가 쌍대공간 \(V^*\)이다.
  2. 쌍대기저 \(f_i\)는 \(f_i(\mathbf v_j) = \delta_{ij}\)로 정해지며 \(i\)째 좌표를 읽는다. \(\dim V^* = \dim V\).
  3. \(\mathbb R^n\)에서 쌍대기저의 행벡터는 기저를 열로 세운 행렬의 역행렬의 행이다.
  4. \(T^{\mathsf t}(g) = g\circ T\)의 행렬은 \(T\)의 행렬의 전치이다.

4.2.4연습문제

기본

  1. \(\mathbb R^2\)의 기저 \(((1, 1), (1, -1))\)의 쌍대기저를 구하여라.
    답

    \(f_1 = \frac12(x + y)\), \(f_2 = \frac12(x - y)\).

  2. \(V = P_1\)에서 \(f(p) = \int_0^1 p(x)\,dx\)를 쌍대기저 \(\{p \mapsto p(0),\ p \mapsto p'(0)\}\)으로 나타내어라. (먼저 이것이 어느 기저의 쌍대기저인지 확인하라.)
    답

    기저 \((1, x)\)의 쌍대기저이다. \(f(1) = 1\), \(f(x) = \frac12\)이므로 \(f = 1\cdot(p\mapsto p(0)) + \frac12(p \mapsto p'(0))\).

응용

  1. \(T: \mathbb R^2 \to \mathbb R^3\), \(T(x, y) = (x, x + y, 2y)\)에 대해 \(T^{\mathsf t}(g)\)를 구하여라. 단 \(g(a, b, c) = a - b + c\).
    답

    \(g(T(x,y)) = x - (x + y) + 2y = y\). 표준 행렬로: \(A^{\mathsf T}(1, -1, 1)^{\mathsf T} = (0, 1)\).

심화

  1. 세 점 \(x_0, x_1, x_2\)(서로 다름)에서의 값 읽기 \(L_i(p) = p(x_i)\)는 \(P_2^*\)의 기저임을 보이고, 이것을 쌍대기저로 갖는 \(P_2\)의 기저를 구하여라.
    힌트

    \(\ell_j(x_i) = \delta_{ij}\)인 다항식 \(\ell_j\)를 찾으면 됩니다.

    답

    라그랑주 기저 \(\ell_0(x) = \frac{(x - x_1)(x - x_2)}{(x_0 - x_1)(x_0 - x_2)}\) 등. \(L_i(\ell_j) = \delta_{ij}\)이므로 \(\{L_i\}\)는 \(\{\ell_j\}\)의 쌍대기저(그래서 기저). 보간 다항식은 \(p = \sum p(x_j)\ell_j\).
