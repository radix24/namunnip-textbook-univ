해 하나를 알면 나머지는 동차 해로 찾는다

예제 · 특수해와 영공간

먼저 예측

미지수가 4개, 방정식이 2개이고 두 방정식이 서로 배수가 아니라면, 해집합은 몇 차원의 모양(점, 직선, 평면, …)일까?

예측 확인

피벗이 2개, 자유변수가 2개이므로 해가 있다면 매개변수 두 개로 쓰는 "평면"(4차원 공간 속의 2차원 집합)이다.

\(A = \begin{pmatrix} 1 & 1 & 2 & 0 \\ 0 & 1 & 1 & -1\end{pmatrix}\), \(\mathbf b = \begin{pmatrix} 4 \\ 1\end{pmatrix}\)일 때, \(\mathbf p = (3, 1, 0, 0)\)이 \(A\mathbf x = \mathbf b\)의 해임을 확인하고, 해집합 전체를 구하여라.

전략

정리 1.2.3에 따라 해집합은 "\(\mathbf p\) + 동차 해 전체"이다. 그러니 \(\mathbf b\)는 잊고 \(A\mathbf x = \mathbf 0\)만 풀면 된다. 이미 행사다리꼴에 가까우므로 소거가 짧다.

풀이

  1. \(A\mathbf p = (3 + 1 + 0 + 0,\ 1 + 0 - 0) = (4, 1) = \mathbf b\). \(\mathbf p\)는 특수해다.
    행렬과 벡터의 곱의 정의(정의 1.2.1)로 직접 계산.
  2. \(R_1 \to R_1 - R_2\)로 \(A\)를 기약 행사다리꼴 \(\begin{pmatrix} 1 & 0 & 1 & 1 \\ 0 & 1 & 1 & -1\end{pmatrix}\)로 만든다.
    둘째 열의 피벗 위를 0으로(기약 조건 4).
  3. 자유변수 \(x_3 = s,\ x_4 = t\). 동차 방정식은 \(x_1 = -s - t,\ x_2 = -s + t\).
    피벗 열은 1, 2열이므로 3, 4열의 변수가 자유변수.
  4. \(\mathbf x = (3, 1, 0, 0) + s(-1, -1, 1, 0) + t(-1, 1, 0, 1)\), \(s, t \in \mathbb R\).
    정리 1.2.3: 특수해에 동차 해 전체를 더한다.

의미

해집합은 4차원 공간에서 점 \(\mathbf p\)를 지나는 평면이다. 같은 \(A\)에 우변만 다른 \(\mathbf b\)가 오면 특수해만 바꾸면 되고, 방향 벡터 두 개는 그대로이다. 공학에서 같은 회로에 입력만 바꿔 여러 번 푸는 상황이 이렇다.

검산

방향 벡터 \((-1, -1, 1, 0)\)을 \(A\)에 넣으면 \((-1 - 1 + 2,\ -1 + 1) = (0, 0)\), \((-1, 1, 0, 1)\)은 \((-1 + 1 + 0,\ 1 + 0 - 1) = (0, 0)\). 둘 다 동차 해이다.

바꿔 보기

특수해로 \(\mathbf p' = (2, 0, 1, 0)\)을 써도 됩니다(\(A\mathbf p' = (4, 1)\)). 그러면 식이 \((2, 0, 1, 0) + s(\dots) + t(\dots)\)로 달라 보이지만, \(\mathbf p' - \mathbf p = (-1, -1, 1, 0)\)이 동차 해이므로 같은 집합이다.

이해 확인

같은 \(A\)에서 \(\mathbf b = (0, 0)\)이면 해집합은 무엇인가요? 원점을 지나나요?

답

\(s(-1, -1, 1, 0) + t(-1, 1, 0, 1)\). 특수해로 \(\mathbf 0\)을 쓸 수 있으니 원점을 지나는 평면이다.
