두 평면의 교선을 차원 공식으로 찾기

예제 · 합공간과 교집합의 기저

먼저 예측

\(\mathbb R^3\)에서 원점을 지나는 서로 다른 두 평면의 교집합은 몇 차원일까?

예측 확인

1차원(직선)이다. 합은 \(\mathbb R^3\)(3차원)이므로 \(2 + 2 - 3 = 1\).

\(W_1 = \operatorname{span}\{(1, 0, 1), (0, 1, 1)\}\), \(W_2 = \operatorname{span}\{(1, 1, 0), (1, 2, 3)\}\)일 때 \(W_1 + W_2\)와 \(W_1 \cap W_2\)의 기저와 차원을 구하여라.

전략

합공간은 네 벡터의 생성이므로 2.3절의 방법(열로 세워 피벗 열 고르기)으로 기저를 얻는다. 교집합은 "양쪽 생성으로 동시에 쓸 수 있는 벡터"이므로 \(a\mathbf v_1 + b\mathbf v_2 = c\mathbf w_1 + d\mathbf w_2\)를 푼다. 차원 공식으로 답을 검산한다.

풀이

  1. \(\begin{pmatrix} 1 & 0 & 1 & 1 \\ 0 & 1 & 1 & 2 \\ 1 & 1 & 0 & 3\end{pmatrix}\)을 소거하면 \(R_3 - R_1 - R_2\)로 셋째 행이 \((0, 0, -2, 0)\)이 되어 피벗 열은 1, 2, 3열이다.
    피벗이 3개이므로 \(\dim(W_1 + W_2) = 3\), 곧 \(W_1 + W_2 = \mathbb R^3\).
  2. 차원 공식으로 \(\dim(W_1\cap W_2) = 2 + 2 - 3 = 1\).
    \(W_1, W_2\) 각각의 두 벡터는 평행하지 않으므로 둘 다 2차원.
  3. \(a(1,0,1) + b(0,1,1) = c(1,1,0) + d(1,2,3)\): 성분별로 \(a = c + d,\ b = c + 2d,\ a + b = 3d\).
    교집합의 원소는 양쪽의 일차결합으로 쓰인다.
  4. 앞의 두 식을 셋째에 넣으면 \(2c + 3d = 3d\), 곧 \(c = 0\). 그러면 교집합의 원소는 \(d(1, 2, 3)\).
    \(d\)는 자유롭게 정할 수 있다(1차원과 일치).
  5. \(W_1\cap W_2 = \operatorname{span}\{(1, 2, 3)\}\), \(W_1 + W_2 = \mathbb R^3\) (기저 \((1,0,1), (0,1,1), (1,1,0)\)).
    4단계의 결과와 1단계의 피벗 열.

검산

\((1, 2, 3) = 1\cdot(1, 0, 1) + 2\cdot(0, 1, 1)\)이므로 \(W_1\)에 속하고, \(W_2\)의 생성 벡터이므로 \(W_2\)에도 속한다. 1단계에서 넷째 열 \((1, 2, 3)\)에 피벗이 없었던 것도 이 때문이다.

의미

두 평면의 방정식을 구해 연립하는 방법(교선의 방향은 두 법선의 외적)과 같은 답이 나온다. 그러나 이 방법은 4차원 이상에서도, 다항식 공간에서도 그대로 쓸 수 있다.

이해 확인

\(W_1 + W_2\)는 직합인가요?

답

아니다. 교집합이 1차원이라 \(\{\mathbf 0\}\)이 아니다. \(\dim W_1 + \dim W_2 = 4 \ne 3\)으로도 알 수 있다.
