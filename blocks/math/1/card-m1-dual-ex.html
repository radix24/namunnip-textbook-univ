심프슨 공식을 쌍대기저로 만들기

예제 · 범함수를 쌍대기저로 전개

먼저 예측

\(\int_{-1}^{1}p(x)\,dx\)는 \(P_2\) 위의 일차범함수이다. \(\dim P_2^* = 3\)이니, 세 점의 값 \(p(-1), p(0), p(1)\)의 일차결합으로 이 적분을 정확히 쓸 수 있을까?

예측 확인

쓸 수 있다. 세 값 읽기가 \(P_2^*\)의 기저이므로, 모든 범함수가 그 일차결합이다.

\(I(p) = \int_{-1}^1 p(x)\,dx\)를 \(L_{-1}(p) = p(-1)\), \(L_0(p) = p(0)\), \(L_1(p) = p(1)\)의 일차결합으로 나타내어라.

전략

\(\{L_{-1}, L_0, L_1\}\)은 라그랑주 기저 \(\{\ell_{-1}, \ell_0, \ell_1\}\)의 쌍대기저입니다(4.2절 연습 4). 정리 4.2.2의 증명에서 \(f = \sum f(\mathbf v_i)f_i\)였으므로, 계수는 \(I(\ell_j)\)이다.

풀이

  1. \(\ell_{-1}(x) = \frac{x(x - 1)}{2}\), \(\ell_0(x) = 1 - x^2\), \(\ell_1(x) = \frac{x(x + 1)}{2}\).
    각각 자기 점에서 1, 나머지 두 점에서 0인 2차 다항식(라그랑주 기저).
  2. \(I(\ell_{-1}) = \frac12\int_{-1}^1(x^2 - x)\,dx = \frac12\cdot\frac23 = \frac13\).
    기함수 \(x\)의 적분은 0, \(\int_{-1}^1x^2dx = \frac23\).
  3. \(I(\ell_0) = \int_{-1}^1(1 - x^2)\,dx = 2 - \frac23 = \frac43\). 대칭에서 \(I(\ell_1) = \frac13\).
    같은 계산.
  4. \(I = \frac13L_{-1} + \frac43L_0 + \frac13L_1\), 곧 \(\displaystyle\int_{-1}^1 p = \frac13\left[p(-1) + 4p(0) + p(1)\right]\).
    \(f = \sum f(\mathbf v_i)f_i\)에서 \(f = I\), \(\mathbf v_i = \ell_i\), \(f_i = L_i\).

검산

\(p = x^2\): 왼쪽 \(\frac23\), 오른쪽 \(\frac13(1 + 0 + 1) = \frac23\). \(p = 1\): 왼쪽 2, 오른쪽 \(\frac13\cdot 6 = 2\). 기저 셋에 대해 맞으면 \(P_2\) 전체에서 맞다.

의미

이것이 심프슨 공식이다. 2차 이하 다항식에 대해서는 정확하고, 실제로는 3차 다항식에도 정확합니다(\(x^3\)은 기함수라 양쪽이 0). 일반 함수에는 근사로 쓰며, 구간을 잘게 나누어 여러 번 쓰는 것이 수치적분(수학24 6단원)이다.

바꿔 보기

점을 \(-1, 1\) 두 개만 쓰면 \(P_1\)에서 \(I = L_{-1} + L_1\)(사다리꼴 공식)이다. 점의 개수 = 정확히 맞출 수 있는 다항식 공간의 차원이라는 원리가 같다.

이해 확인

\(p = x^4\)에서 심프슨 공식의 값과 참값을 비교해 보아라.

답

공식 \(\frac13(1 + 0 + 1) = \frac23\), 참값 \(\frac25\). \(x^4 \notin P_3\)이라 정확하지 않다.
