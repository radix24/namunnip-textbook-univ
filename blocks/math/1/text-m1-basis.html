2.3.1군더더기가 있는 생성 집합

\(\operatorname{span}\{(1, 0), (0, 1), (1, 1)\}\)은 평면 전체입니다. 그런데 \((1, 1) = (1, 0) + (0, 1)\)이라 셋째 벡터는 빼도 생성은 그대로입니다. 셋째 벡터는 군더더기입니다. 반대로 \(\{(1, 0), (0, 1)\}\)에서는 어느 것을 빼도 생성이 줄어듭니다. 이 차이를 식으로 나타낸 것이 일차독립입니다.

정의 2.3.1 (일차독립)

벡터 \(\mathbf v_1, \dots, \mathbf v_k\)에 대해 \(c_1\mathbf v_1 + \dots + c_k\mathbf v_k = \mathbf 0\)이면 반드시 \(c_1 = \dots = c_k = 0\)일 때, 이 벡터들을 일차독립이라 한다. 그렇지 않으면, 곧 모두 0은 아닌 계수로 \(\mathbf 0\)을 만들 수 있으면 일차종속이라 한다.

왜 이 식이 "군더더기 없음"인지 봅시다. 일차종속이면 0이 아닌 계수가 있는 식 \(c_1\mathbf v_1 + \dots + c_k\mathbf v_k = \mathbf 0\)이 있고, 예를 들어 \(c_k \ne 0\)이면 \(\mathbf v_k = -\frac{1}{c_k}(c_1\mathbf v_1 + \dots + c_{k-1}\mathbf v_{k-1})\)로 다른 벡터들의 일차결합이 됩니다. 곧 일차종속 ⇔ 어떤 벡터가 나머지의 일차결합 ⇔ 그 벡터를 빼도 생성이 그대로입니다.

또 일차독립이면 일차결합의 표현이 하나뿐입니다. \(\sum a_i\mathbf v_i = \sum b_i\mathbf v_i\)이면 \(\sum(a_i - b_i)\mathbf v_i = \mathbf 0\)이라 \(a_i = b_i\)이기 때문입니다.

\(\mathbb R^n\)에서 판정은 1단원 그대로입니다. 벡터들을 열로 세운 행렬 \(A\)에 대해 \(A\mathbf c = \mathbf 0\)의 해가 \(\mathbf 0\)뿐인지, 곧 모든 열에 피벗이 있는지 보면 됩니다.

예제 2.3.2

\((1, 2, 1), (2, 1, 0), (1, -4, -3)\)은 일차독립인가?

풀이. 열로 세워 소거합니다. \(R_2 - 2R_1\), \(R_3 - R_1\) 뒤 \(\begin{pmatrix} 1 & 2 & 1 \\ 0 & -3 & -6 \\ 0 & -2 & -4\end{pmatrix}\), 셋째 행에서 둘째 행의 \(\frac23\)배를 빼면 0인 행이 생겨 셋째 열에 피벗이 없습니다. 일차종속입니다. 실제로 \(c_3 = 1\)로 두고 풀면 \(c_2 = -2, c_1 = 3\)이고, \(3(1,2,1) - 2(2,1,0) + (1,-4,-3) = (0, 0, 0)\)입니다.

2.3.2기저

정의 2.3.3 (기저)

\(V\)의 부분집합 \(\beta\)가 일차독립이고 \(\operatorname{span}\beta = V\)이면 \(\beta\)를 \(V\)의 기저라 한다.

두 조건이 맡는 역할이 다릅니다. "생성"은 모든 벡터를 \(\beta\)로 쓸 수 있다(존재), "일차독립"은 그 표현이 하나뿐이다(유일성)를 보장합니다. 그래서 기저를 정하면 각 벡터에 계수의 목록, 곧 좌표가 하나씩 붙습니다. 3단원에서 이 좌표로 모든 유한차원 공간을 \(\mathbb R^n\)처럼 다룹니다.

\(\mathbb R^n\)의 표준기저: \(\mathbf e_1 = (1, 0, \dots, 0), \dots, \mathbf e_n = (0, \dots, 0, 1)\).

\(P_n\)의 표준기저: \(1, x, x^2, \dots, x^n\). 다항식의 계수가 곧 좌표입니다.

\(M_{2\times2}\)의 표준기저: 한 성분만 1이고 나머지가 0인 행렬 4개.

2.3.3기저로 확장하기

일차독립인 벡터 몇 개를 이미 가지고 있을 때, 거기에 벡터를 더 보태서 기저를 만들 수 있을까요? 생성하지 못하는 방향의 벡터를 하나씩 보태면 됩니다. 핵심은 "생성 밖의 벡터를 보태도 일차독립이 깨지지 않는다"는 것입니다.

보조정리 2.3.4

\(S\)가 일차독립이고 \(\mathbf v \notin \operatorname{span}S\)이면 \(S \cup \{\mathbf v\}\)도 일차독립이다.

증명.\(c\mathbf v + \sum c_i\mathbf s_i = \mathbf 0\)이라 하자. \(c \ne 0\)이면 \(\mathbf v = -\frac1c\sum c_i\mathbf s_i \in \operatorname{span}S\)가 되어 가정에 어긋나므로 \(c = 0\)이다. 그러면 \(\sum c_i\mathbf s_i = \mathbf 0\)이고 \(S\)가 일차독립이라 모든 \(c_i = 0\)이다. ∎

정리 2.3.5 (기저로의 확장)

\(V\)가 유한 집합 \(G\)로 생성된다고 하자. 그러면 \(V\)의 일차독립 집합 \(S\)는 \(G\)의 원소를 보태서 \(V\)의 기저로 확장할 수 있다.

증명.\(G = \{\mathbf g_1, \dots, \mathbf g_m\}\)의 원소를 차례로 본다. \(S_0 = S\)로 두고, \(\mathbf g_j \notin \operatorname{span}S_{j-1}\)이면 \(S_j = S_{j-1} \cup \{\mathbf g_j\}\), 아니면 \(S_j = S_{j-1}\)로 둔다. 보조정리 2.3.4에 따라 모든 \(S_j\)는 일차독립이다. 또 각 \(\mathbf g_j\)는 \(S_j\)의 원소이거나 \(\operatorname{span}S_{j-1} \subseteq \operatorname{span}S_j\)에 속하므로 \(\mathbf g_j \in \operatorname{span}S_m\)이다. 따라서 \(V = \operatorname{span}G \subseteq \operatorname{span}S_m\)이고(\(\operatorname{span}S_m\)은 \(G\)를 포함하는 부분공간, 정리 2.2.4), \(S_m\)은 \(V\)의 기저이다. ∎

\(S = \varnothing\)로 두면 "유한 집합으로 생성되는 공간은 기저가 있다"가 나옵니다. 또 같은 생각을 거꾸로 하면, 생성 집합에서 군더더기를 하나씩 빼서 기저를 얻을 수도 있습니다.

예제 2.3.6

\(\{(1, 1, 0)\}\)을 \(\mathbb R^3\)의 기저로 확장하여라.

풀이. 표준기저 \(G = \{\mathbf e_1, \mathbf e_2, \mathbf e_3\}\)을 차례로 봅니다. \(\mathbf e_1 \notin \operatorname{span}\{(1,1,0)\}\)이라 보탭니다. \(\mathbf e_2 = (1,1,0) - \mathbf e_1\)은 이미 생성에 있어 건너뜁니다. \(\mathbf e_3\)은 셋째 성분이 0이 아니라 생성 밖이므로 보탭니다. 기저 \(\{(1,1,0), \mathbf e_1, \mathbf e_3\}\).

주의"벡터들이 쌍마다 서로 평행하지 않으면 일차독립이다"는 틀립니다. 예제 2.3.2의 세 벡터는 어느 둘도 평행하지 않지만 일차종속입니다(셋이 한 평면에 있음). 일차독립은 벡터 전체를 한꺼번에 보는 조건입니다.
요약
  1. 일차독립 ⇔ \(\mathbf 0\)을 만드는 일차결합은 모든 계수가 0인 것뿐 ⇔ 어떤 벡터도 나머지의 일차결합이 아님.
  2. \(\mathbb R^n\)에서는 벡터를 열로 세운 행렬의 모든 열에 피벗이 있는지로 판정한다.
  3. 기저 = 일차독립 + 생성. 기저가 있으면 각 벡터의 좌표가 하나로 정해진다.
  4. 생성 밖의 벡터를 하나씩 보태면 일차독립 집합을 기저로 확장할 수 있다.

2.3.4연습문제

기본

  1. \(1 + x,\ 1 - x,\ x^2\)이 \(P_2\)의 기저임을 보여라.
    답

    \(a(1+x) + b(1-x) + cx^2 = 0\)이면 \(a + b = 0, a - b = 0, c = 0\)이라 일차독립. 표준기저를 생성한다(\(1 = \frac12[(1+x) + (1-x)]\) 등)이므로 \(P_2\)를 생성.

  2. \((1, 2), (3, 6)\)은 일차독립인가?
    답

    아니다. \(3(1,2) - (3,6) = \mathbf 0\).

응용

  1. \(\{(1, 0, 1, 0), (0, 1, 0, 1)\}\)을 \(\mathbb R^4\)의 기저로 확장하여라.
    답

    예: \(\mathbf e_1, \mathbf e_2\)를 보탠다. \(\{(1,0,1,0), (0,1,0,1), \mathbf e_1, \mathbf e_2\}\). (\(\mathbf e_3 = (1,0,1,0) - \mathbf e_1\), \(\mathbf e_4\)도 생성에 있음.)

심화

  1. \(\sin x, \cos x, \sin(x + 1)\)은 함수공간에서 일차종속임을 보여라. \(e^x, e^{2x}\)는 일차독립임을 보여라.
    답

    \(\sin(x+1) = \cos1\sin x + \sin1\cos x\). \(ae^x + be^{2x} = 0\)이 모든 \(x\)에서 성립하면 \(x = 0\)에서 \(a + b = 0\), 미분해서 \(x = 0\)을 넣으면 \(a + 2b = 0\)이라 \(a = b = 0\).
