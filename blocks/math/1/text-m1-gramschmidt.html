정규직교기저와 그람-슈미트 과정

본문
이 절에서 배울 것
  • 정규직교기저에서는 좌표를 내적 한 번으로 구함을 안다.
  • 그람-슈미트(Gram-Schmidt) 과정으로 일차독립 집합을 직교 집합으로 바꾼다.
  • 다항식 공간에서 직교 다항식(르장드르 다항식)을 만든다.
먼저 알아야 할 것
  • 내적, 직교, 정사영 공식 (7.1절과 그 탐구 카드).

7.2.1직교하는 기저가 좋은 이유

일반 기저에서 벡터의 좌표를 구하려면 연립방정식을 풀어야 했습니다(3.2절). 기저 벡터들이 서로 직교하면 사정이 달라집니다. \(\mathbf v = c_1\mathbf u_1 + \dots + c_n\mathbf u_n\)의 양변을 \(\mathbf u_j\)와 내적하면, 직교성 때문에 \(j\)째 항만 남아 \(\langle\mathbf v, \mathbf u_j\rangle = c_j\|\mathbf u_j\|^2\)입니다.

직교 집합: 서로 다른 두 벡터의 내적이 모두 0인 집합(영벡터 제외). 직교 집합은 일차독립입니다(위 계산에서 \(\mathbf v = \mathbf 0\)이면 모든 \(c_j = 0\)).

정규직교 집합: 직교 집합이면서 모든 벡터의 길이가 1인 것. 이때 \(c_j = \langle\mathbf v, \mathbf u_j\rangle\)입니다.

정리 7.2.1

\(\{\mathbf u_1, \dots, \mathbf u_n\}\)이 정규직교기저이면 모든 \(\mathbf v\)에 대해 \(\mathbf v = \sum_j\langle\mathbf v, \mathbf u_j\rangle\mathbf u_j\)이고 \(\|\mathbf v\|^2 = \sum_j\langle\mathbf v, \mathbf u_j\rangle^2\)이다.

둘째 식은 \(n\)차원 피타고라스 정리이고, 무한차원으로 넓힌 것이 푸리에 급수의 파스발 정리(수학15 2단원)입니다.

7.2.2그람-슈미트 과정

주어진 기저는 대개 직교하지 않습니다. 각 벡터에서 앞서 만든 직교 벡터 방향의 성분(정사영)을 빼면 나머지는 그것들과 직교합니다. 이 일을 차례로 합니다.

정리 7.2.2 (그람-슈미트 과정)

\(\{\mathbf w_1, \dots, \mathbf w_n\}\)이 일차독립이면 다음으로 정한 \(\mathbf v_1, \dots, \mathbf v_n\)은 직교 집합이고, 각 \(k\)에 대해 \(\operatorname{span}\{\mathbf v_1, \dots, \mathbf v_k\} = \operatorname{span}\{\mathbf w_1, \dots, \mathbf w_k\}\)이다.

\[\mathbf v_1 = \mathbf w_1,\qquad \mathbf v_k = \mathbf w_k - \sum_{j=1}^{k-1}\frac{\langle\mathbf w_k, \mathbf v_j\rangle}{\|\mathbf v_j\|^2}\mathbf v_j.\]

증명.\(k\)에 대한 귀납법. \(\mathbf v_1, \dots, \mathbf v_{k-1}\)이 직교하고 생성이 같다고 하자. \(i < k\)이면 \(\langle\mathbf v_k, \mathbf v_i\rangle = \langle\mathbf w_k, \mathbf v_i\rangle - \frac{\langle\mathbf w_k, \mathbf v_i\rangle}{\|\mathbf v_i\|^2}\|\mathbf v_i\|^2 = 0\)이다(합에서 \(j = i\)인 항만 남음, 직교성). \(\mathbf v_k \ne \mathbf 0\)인 이유: \(\mathbf v_k = \mathbf 0\)이면 \(\mathbf w_k\)가 \(\mathbf v_1, \dots, \mathbf v_{k-1}\), 곧 \(\mathbf w_1, \dots, \mathbf w_{k-1}\)의 일차결합이 되어 일차독립에 어긋난다. 정의식에서 \(\mathbf v_k \in \operatorname{span}\{\mathbf w_1, \dots, \mathbf w_k\}\)이고 \(\mathbf w_k \in \operatorname{span}\{\mathbf v_1, \dots, \mathbf v_k\}\)이므로 생성이 같다. ∎

마지막에 각 \(\mathbf v_k\)를 길이로 나누면 정규직교기저가 됩니다. 따라서 모든 유한차원 내적공간에는 정규직교기저가 있습니다.

예제 7.2.3

\(\mathbf w_1 = (1, 1, 0)\), \(\mathbf w_2 = (1, 0, 1)\), \(\mathbf w_3 = (0, 1, 1)\)에 그람-슈미트 과정을 적용하여라.

풀이. \(\mathbf v_1 = (1, 1, 0)\), \(\|\mathbf v_1\|^2 = 2\). \(\langle\mathbf w_2, \mathbf v_1\rangle = 1\)이므로 \(\mathbf v_2 = (1, 0, 1) - \frac12(1, 1, 0) = (\frac12, -\frac12, 1)\), \(\|\mathbf v_2\|^2 = \frac32\). \(\langle\mathbf w_3, \mathbf v_1\rangle = 1\), \(\langle\mathbf w_3, \mathbf v_2\rangle = \frac12\)이므로

\[\mathbf v_3 = (0, 1, 1) - \frac12(1, 1, 0) - \frac{1/2}{3/2}\left(\tfrac12, -\tfrac12, 1\right) = \left(-\tfrac23, \tfrac23, \tfrac23\right).\]

검산: \(\mathbf v_1\cdot\mathbf v_3 = -\frac23 + \frac23 = 0\), \(\mathbf v_2\cdot\mathbf v_3 = -\frac13 - \frac13 + \frac23 = 0\). 길이로 나누면 \(\frac1{\sqrt2}(1,1,0)\), \(\frac1{\sqrt6}(1,-1,2)\), \(\frac1{\sqrt3}(-1,1,1)\).

7.2.3함수에도: 르장드르 다항식

예제 7.2.4

\(P_2\)에 \(\langle f, g\rangle = \int_{-1}^1 fg\,dx\)를 주고 \(1, x, x^2\)에 그람-슈미트 과정을 적용하여라.

풀이. \(\mathbf v_1 = 1\). \(\langle x, 1\rangle = 0\)이므로 \(\mathbf v_2 = x\). \(\langle x^2, 1\rangle = \frac23\), \(\|1\|^2 = 2\), \(\langle x^2, x\rangle = 0\)이므로 \(\mathbf v_3 = x^2 - \frac{2/3}{2}\cdot1 = x^2 - \frac13\). 이것들의 상수배가 르장드르 다항식 \(P_0 = 1\), \(P_1 = x\), \(P_2 = \frac12(3x^2 - 1)\)입니다. 물리학의 전기 다중극 전개, 수치적분의 가우스 구적법에 쓰이고, 상미분방정식(수학6 4단원)의 르장드르 방정식의 해이기도 합니다.

주의그람-슈미트 과정은 순서에 따라 결과가 다릅니다. \(\mathbf w_1, \mathbf w_2\)의 순서를 바꾸면 첫 벡터가 \(\mathbf w_2\)가 되어 다른 직교기저가 나옵니다. 또 컴퓨터로 계산하면 반올림 오차 때문에 뒤쪽 벡터들의 직교성이 깨지기 쉬워, 실제로는 한 번에 한 방향씩 빼는 수정된 그람-슈미트나 하우스홀더 변환(수학16)을 씁니다.
요약
  1. 정규직교기저에서 좌표는 내적 \(\langle\mathbf v, \mathbf u_j\rangle\)이고, 길이의 제곱은 좌표의 제곱합이다.
  2. 그람-슈미트: 각 벡터에서 앞선 직교 벡터들로의 정사영을 빼서 직교화하고, 끝에 길이로 나눈다.
  3. 생성은 단계마다 보존되고, 일차독립이면 영벡터가 나오지 않는다.
  4. 적분 내적에서 \(1, x, x^2, \dots\)를 직교화하면 르장드르 다항식이 나온다.

7.2.4연습문제

기본

  1. \((3, 4)\), \((1, 0)\)에 그람-슈미트 과정을 적용해 정규직교기저를 구하여라.
    답

    \(\mathbf v_1 = (3, 4)\), \(\mathbf v_2 = (1, 0) - \frac{3}{25}(3, 4) = (\frac{16}{25}, -\frac{12}{25})\). 정규화: \(\frac15(3, 4)\), \(\frac15(4, -3)\).

  2. 정규직교기저 \(\frac1{\sqrt2}(1, 1), \frac1{\sqrt2}(1, -1)\)에 대한 \((5, 1)\)의 좌표를 내적으로 구하여라.
    답

    \(\frac{6}{\sqrt2} = 3\sqrt2\), \(\frac4{\sqrt2} = 2\sqrt2\).

응용

  1. \(\mathbb R^4\)의 \(\operatorname{span}\{(1, 1, 1, 1), (1, 1, 0, 0), (1, 0, 0, 0)\}\)의 정규직교기저를 구하여라.
    답

    \(\frac12(1,1,1,1)\), \(\frac12(1,1,-1,-1)\), \(\frac1{\sqrt2}(1,-1,0,0)\).

심화

  1. 예제 7.2.4를 이어 \(x^3\)을 직교화해 \(\mathbf v_4\)를 구하여라.
    답

    \(\langle x^3, 1\rangle = 0\), \(\langle x^3, x\rangle = \frac25\), \(\|x\|^2 = \frac23\), \(\langle x^3, x^2 - \frac13\rangle = 0\). \(\mathbf v_4 = x^3 - \frac35x\) (\(P_3 = \frac12(5x^3 - 3x)\)의 상수배).
