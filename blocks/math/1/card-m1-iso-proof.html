세 점을 지나는 포물선은 하나뿐이다: 동형으로 증명하기

증명 · 일대일이면 전사
정리

서로 다른 실수 \(x_0, x_1, x_2\)와 임의의 실수 \(y_0, y_1, y_2\)에 대해 \(p(x_i) = y_i\) (\(i = 0, 1, 2\))인 \(p \in P_2\)가 정확히 하나 있다.

쓰는 것

  • 일대일 ⇔ 핵이 \(\{\mathbf 0\}\) (정리 3.1.3).
  • 차원 정리 (정리 3.1.4), \(\dim P_2 = 3\).
  • 근의 개수: 0이 아닌 \(n\)차 이하 다항식의 실근은 많아야 \(n\)개 (고교 인수정리).

아이디어

"하나뿐"과 "있다"를 따로 증명하지 않는다. 값을 읽는 사상 \(T: P_2 \to \mathbb R^3\)을 만들면 "있다"는 전사, "하나뿐"은 일대일이다. 두 공간의 차원이 같으므로 일대일만 보이면 전사는 저절로 따라온다. 일대일은 근의 개수로 쉽게 보인다.

증명

  1. \(T: P_2 \to \mathbb R^3\), \(Tp = (p(x_0), p(x_1), p(x_2))\)로 정의한다. \(T\)는 일차변환이다.
    \((p + q)(x_i) = p(x_i) + q(x_i)\), \((cp)(x_i) = cp(x_i)\)이므로 성분마다 선형.
  2. \(Tp = \mathbf 0\)이라 하자. 그러면 \(p\)는 서로 다른 세 근 \(x_0, x_1, x_2\)를 갖는다.
    핵의 원소가 무엇인지 정의대로 쓴 것.
  3. \(p\)의 차수는 2 이하인데 근이 3개이므로 \(p = 0\)이다. 따라서 \(N(T) = \{0\}\)이고 \(T\)는 일대일이다.
    0이 아닌 2차 이하 다항식은 근이 많아야 2개. 정리 3.1.3. 여기서 "\(x_i\)가 서로 다르다"를 쓴다.
  4. 차원 정리로 \(\operatorname{rank}T = \dim P_2 - \operatorname{nullity}T = 3 - 0 = 3\)이다.
    \(\dim P_2 = 3\) (기저 \(1, x, x^2\)).
  5. \(R(T)\)는 \(\mathbb R^3\)의 3차원 부분공간이므로 \(R(T) = \mathbb R^3\), 곧 \(T\)는 전사이다.
    따름정리 2.4.6: 차원이 같은 부분공간은 전체.
  6. 전사이므로 \(Tp = (y_0, y_1, y_2)\)인 \(p\)가 있고, 일대일이므로 그런 \(p\)는 하나뿐이다.
    존재 = 전사(5단계), 유일성 = 일대일(3단계).

되짚기

  • "서로 다르다"는 3단계에서 썼다. \(x_0 = x_1\)이면 \(Tp = \mathbf 0\)이라도 근이 두 개뿐이라 \(p = (x - x_0)(x - x_2)\) 같은 0 아닌 해가 생긴다. 그러면 일대일도 전사도 깨집니다(같은 점에서 두 값을 요구할 수 없음).
  • 차원이 같다는 것은 4~5단계에서 썼다. \(P_3 \to \mathbb R^3\)으로 바꾸면 전사지만 일대일이 아니어서(nullity 1) 세 점을 지나는 3차 이하 다항식은 무수히 많다.

더 나아가기

같은 증명으로 "서로 다른 \(n+1\)개 점에 값을 주면 그것을 지나는 \(n\)차 이하 다항식이 하나뿐"(라그랑주 보간)이다. 그 다항식을 실제로 구하는 방법과 그 오차는 과학계산(수학24)과 수치해석(수학16)에서 다룬다. 점이 많아지면 생기는 문제는 룽게 현상 탐구 카드에 있다.

직접 써 보기

\(T: P_2 \to \mathbb R^3\), \(Tp = (p(0), p'(0), p''(0))\)이 동형사상임을 같은 방법으로 보여라.

힌트

\(p = a + bx + cx^2\)이면 \(Tp = (a, b, 2c)\)이다.

답안

\(T\)는 미분과 값 읽기가 선형이라 일차변환이다. \(Tp = \mathbf 0\)이면 \(a = b = 2c = 0\)이라 \(p = 0\), 일대일. \(\dim P_2 = \dim\mathbb R^3 = 3\)이므로 차원 정리로 전사. 따라서 동형사상이다(테일러 계수가 2차 이하 다항식을 정확히 하나 정한다). ∎
