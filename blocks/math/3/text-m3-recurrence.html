선형 점화식

본문

계단 \(n\)개를 한 번에 1칸이나 2칸씩 오르는 방법은 \(n = 1, 2, 3, 4, 5\)일 때 1, 2, 3, 5, 8가지이다. 앞의 두 수를 더하면 다음 수가 되는 것 같은데, \(n = 50\)일 때의 값을 앞의 것을 모두 계산하지 않고 바로 쓸 수 있을까?

먼저 알아야 할 것수학적 귀납법(1.3절), 이차방정식의 근, 일차독립(선형대수(1) 2.3절)을 쓴다.

3.3.1점화식 세우기

예제 3.3.1

계단 \(n\)개를 한 번에 1칸 또는 2칸씩 오르는 방법의 수 \(a_n\)의 점화식을 세워라.

풀이. 마지막 걸음이 1칸이면 그 전까지 \(n - 1\)칸을 오른 방법이 \(a_{n-1}\)가지이고, 2칸이면 \(a_{n-2}\)가지이다. 따라서 \(a_n = a_{n-1} + a_{n-2}\), \(a_1 = 1\), \(a_2 = 2\)이며, 이것은 피보나치 수열 \(a_n = F_{n+1}\)이다. 이렇게 마지막 단계로 경우를 나누는 것이 점화식을 세우는 기본 요령이다.

3.3.2특성방정식

\(a_n = c_1a_{n-1} + c_2a_{n-2}\)에 \(a_n = r^n\)을 넣으면 \(r^2 = c_1r + c_2\), 곧 특성방정식 \(r^2 - c_1r - c_2 = 0\)을 얻는다.

정리 3.3.2

(1) 특성방정식의 근이 \(r_1 \ne r_2\)이면 일반해는 \(a_n = \alpha r_1^n + \beta r_2^n\)이다. (2) 중근 \(r\)이면 일반해는 \(a_n = (\alpha + \beta n)r^n\)이다. 상수 \(\alpha, \beta\)는 초기값 두 개로 정한다.

증명의 뼈대.초기값 \(a_0, a_1\)이 해를 하나로 정하므로 해 전체는 2차원 벡터공간이다. (1)에서 \(r_1^n\)과 \(r_2^n\)은 해이고 일차독립이라 기저가 된다. (2)에서 \(nr^n\)이 해라는 것은 \(r^2 = c_1r + c_2\)와 중근 조건 \(2r = c_1\)을 써서 대입하면 확인된다. ∎

예제 3.3.3

피보나치 수열 \(F_n = F_{n-1} + F_{n-2}\), \(F_0 = 0\), \(F_1 = 1\)의 일반항을 구하여라.

풀이. 특성방정식 \(r^2 = r + 1\)의 근은 \(\phi = \frac{1 + \sqrt5}2\)와 \(\psi = \frac{1 - \sqrt5}2\)이다. \(F_0 = \alpha + \beta = 0\), \(F_1 = \alpha\phi + \beta\psi = 1\)에서 \(\alpha = \frac1{\sqrt5}\), \(\beta = -\frac1{\sqrt5}\)이므로 다음 비네 공식을 얻는다.

\[F_n = \frac{\phi^n - \psi^n}{\sqrt5}.\]

\(|\psi| < 1\)이므로 \(F_n\)은 \(\frac{\phi^n}{\sqrt5}\)에 가장 가까운 정수이고, 그림 1처럼 \(\frac{F_{n+1}}{F_n} \to \phi \approx 1.618\)이다. 예를 들어 \(F_{10} = 55\)이고 \(\frac{\phi^{10}}{\sqrt5} \approx 55.004\)이다.

3.3.3비동차 점화식

\(a_n = c_1a_{n-1} + c_2a_{n-2} + f(n)\)의 일반해는 동차 일반해에 특수해 하나를 더한 것이다. 이것은 상미분방정식의 비동차 선형 방정식과 같은 구조이며, \(f(n)\)이 다항식이나 지수이면 같은 꼴로 특수해를 추측한다.

예제 3.3.4 (하노이의 탑)

원판 \(n\)개를 옮기는 최소 횟수 \(h_n = 2h_{n-1} + 1\), \(h_1 = 1\)을 풀어라.

풀이. 동차해는 \(\alpha2^n\)이고, 특수해를 상수 \(c\)로 추측하면 \(c = 2c + 1\)에서 \(c = -1\)이다. 그러면 \(h_n = \alpha2^n - 1\)이고, \(h_1 = 1\)에서 \(\alpha = 1\)이므로 \(h_n = 2^n - 1\)이다. 원판이 64개면 약 \(1.8\times10^{19}\)번이다.

흔한 오해중근에서 일반해를 \(\alpha r^n + \beta r^n\)으로 쓰기 쉽지만, 이것은 사실상 한 항이라 \(nr^n\)이 필요하다. 또 특수해 추측이 동차해와 겹칠 때 \(n\)을 곱하지 않는 실수가 있다. \(a_n = 2a_{n-1} + 2^n\)이면 \(c\cdot2^n\)이 아니라 \(cn2^n\)으로 추측해야 한다. 초기값의 첨자가 0부터인지 1부터인지 섞지 않도록 주의한다.
마무리

처음 질문에 답하면, 계단 오르기 수는 \(a_n = F_{n+1}\)이고 비네 공식 \(F_n = \frac{\phi^n - \psi^n}{\sqrt5}\)으로 바로 쓸 수 있다. 점화식은 마지막 단계로 경우를 나누어 세우고, 특성방정식 \(r^2 = c_1r + c_2\)의 근으로 푼다. 서로 다른 근이면 \(\alpha r_1^n + \beta r_2^n\), 중근이면 \((\alpha + \beta n)r^n\)이 일반해이고, 비동차 점화식은 동차해에 특수해를 더한다.

3.3.4연습문제

기본

  1. \(a_n = 5a_{n-1} - 6a_{n-2}\), \(a_0 = 1\), \(a_1 = 0\)을 풀어라.
    답

    근 2, 3. \(\alpha + \beta = 1\), \(2\alpha + 3\beta = 0\). \(a_n = 3\cdot2^n - 2\cdot3^n\).

응용

  1. 길이 \(n\)인 비트열 중 1이 연속하지 않는 것의 수 \(b_n\)의 점화식과 \(b_5\)를 구하여라.
    답

    끝이 0이면 \(b_{n-1}\), 끝이 01이면 \(b_{n-2}\). \(b_1 = 2\), \(b_2 = 3\), \(b_5 = 13\).

심화

  1. \(a_n = 4a_{n-1} - 4a_{n-2}\), \(a_0 = 1\), \(a_1 = 4\)를 풀어라.
    답

    중근 2. \(a_n = (1 + n)2^n\).
