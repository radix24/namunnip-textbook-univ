탐색과 정렬의 복잡도

본문
이 절에서 배울 것
  • 선형 탐색과 이진 탐색의 최악 비교 횟수를 구한다.
  • 삽입 정렬(\(\Theta(n^2)\))과 병합 정렬(\(\Theta(n\log n))\)의 비교 횟수를 분석한다.
  • 비교 정렬은 최악의 경우 \(\Omega(n\log n)\)번 비교가 필요함을 결정 트리로 보인다.
먼저 알아야 할 것
  • 점근 표기 (2.1절), 등차수열의 합, \(\log(n!) = \Theta(n\log n)\) (2.1절 연습 1).

2.2.1탐색

선형 탐색은 앞에서부터 하나씩 비교해 최악 \(n\)번, \(\Theta(n)\)입니다. 정렬된 배열이면 이진 탐색을 씁니다: 가운데와 비교해 찾는 값이 작으면 왼쪽 절반, 크면 오른쪽 절반으로 범위를 줄입니다. 한 번 비교할 때마다 범위가 절반이 되므로 최악 \(\lfloor\log_2n\rfloor + 1\)번, \(\Theta(\log n)\)입니다. \(n = 10^6\)이면 선형 탐색 100만 번, 이진 탐색 20번입니다.

2.2.2삽입 정렬

카드를 손에 하나씩 끼우듯, 앞부분이 정렬된 상태에서 다음 원소를 왼쪽으로 옮기며 제자리를 찾습니다. \(k\)번째 원소는 최악 \(k - 1\)번 비교하므로 최악 비교 횟수는

\[1 + 2 + \dots + (n - 1) = \frac{n(n - 1)}{2} = \Theta(n^2).\]

최악은 거꾸로 정렬된 입력, 최선은 이미 정렬된 입력(\(n - 1\)번)입니다. 무작위 입력의 평균은 약 \(\frac{n^2}{4}\)번입니다.

2.2.3병합 정렬

배열을 반으로 나눠 각각 정렬하고(재귀), 정렬된 두 반을 앞에서부터 비교하며 합칩니다. 합치는 데 최대 \(n - 1\)번 비교하므로 비교 횟수 \(T(n)\)은

\[T(n) = 2T\!\left(\frac n2\right) + (n - 1), \qquad T(1) = 0.\]

\(n = 2^m\)이면 재귀 나무의 각 층에서 합 \(\approx n\)번, 층이 \(m = \log_2n\)개라 \(T(n) \approx n\log_2n\), 정확히는 \(n\log_2n - n + 1\)입니다(3.4절의 마스터 정리). \(n = 1024\)이면 삽입 정렬 최악 523,776번, 병합 정렬 최악 9,217번입니다.

2.2.4비교 정렬의 하한

정리 2.2.1

원소끼리의 비교만 쓰는 정렬 알고리즘은 최악의 경우 적어도 \(\lceil\log_2(n!)\rceil = \Omega(n\log n)\)번 비교한다.

증명.알고리즘의 비교 과정을 나무로 그린다(각 마디에서 비교 결과에 따라 두 갈래). 입력의 순서 \(n!\)가지는 서로 다른 잎에 도달해야 한다(아니면 두 입력을 같은 방식으로 재배열해 하나는 틀림). 높이 \(h\)인 이진 나무의 잎은 \(2^h\)개 이하라 \(2^h \ge n!\), \(h \ge \log_2n!\). ∎

그래서 병합 정렬은 (상수배를 빼면) 최선입니다. \(n = 1024\)이면 하한이 약 8,770번이라 병합 정렬의 9,217번과 가깝습니다. 같은 절의 탐구 카드에서 두 정렬의 비교 횟수를 무작위 입력으로 세어 볼 수 있습니다.

흔한 실수(1) 이진 탐색을 정렬되지 않은 배열에 쓴다. (2) 최악과 평균을 혼동한다: 퀵 정렬은 평균 \(\Theta(n\log n)\)이지만 최악 \(\Theta(n^2)\)이다. (3) 하한 정리를 모든 정렬에 적용한다: 계수 정렬처럼 비교하지 않고 값의 범위를 쓰는 방법은 \(\Theta(n)\)도 가능하다.
요약
  1. 선형 탐색 \(\Theta(n)\), 이진 탐색 \(\Theta(\log n)\) (정렬된 배열).
  2. 삽입 정렬 최악 \(\frac{n(n-1)}2 = \Theta(n^2)\), 병합 정렬 \(T(n) = 2T(n/2) + n - 1 = \Theta(n\log n)\).
  3. 비교 정렬의 최악은 \(\log_2n! = \Omega(n\log n)\) 이상(결정 트리).

2.2.5연습문제

기본

  1. 원소 1000개의 정렬된 배열에서 이진 탐색의 최악 비교 횟수는?
    답

    \(\lfloor\log_21000\rfloor + 1 = 10\).

응용

  1. \(n = 8\)일 때 병합 정렬의 최악 비교 횟수를 점화식으로 구하여라.
    답

    \(T(2) = 1\), \(T(4) = 2\cdot1 + 3 = 5\), \(T(8) = 2\cdot5 + 7 = 17 = 8\cdot3 - 8 + 1\).

심화

  1. 원소 3개를 정렬하는 데 최악 3번 비교가 필요하고 충분함을 보여라.
    답

    \(\lceil\log_26\rceil = 3\)이 하한. 삽입 정렬이 최악 3번이라 충분.
