열 개의 수에서 길이 넷인 단조 부분수열

예제 · 에르되시-세케레시를 직접 따라가기

먼저 예측

서로 다른 수 10개를 아무렇게나 늘어놓아도 길이 4인 증가 부분수열이나 감소 부분수열이 반드시 있을까요?

예측 확인

있습니다. \(10 = 3^2 + 1\)이라 정리 3.2.3(\(n = 3\))이 길이 \(n + 1 = 4\)를 보장합니다.

수열 \(5, 9, 2, 7, 1, 8, 3, 10, 4, 6\)에서 각 항의 \(L_i\) (그 항에서 시작하는 가장 긴 증가 부분수열의 길이)를 구하고, 정리의 증명대로 길이 4인 단조 부분수열을 찾아라.

전략

\(L_i\)는 뒤에서부터 구합니다: \(L_i = 1 + \max\{L_j : j > i,\ a_j > a_i\}\) (없으면 1). \(L_i \ge 4\)인 항이 있으면 증가 부분수열, 없으면 같은 \(L\) 값을 가진 항이 4개 이상이고 그것들이 감소 부분수열입니다(3.2절).

풀이

  1. 뒤에서부터: \(6\): 1, \(4\): 2 (4→6), \(10\): 1, \(3\): 3 (3→4→6), \(8\): 2 (8→10), \(1\): 4 (1→3→4→6).
    각 항 뒤의 더 큰 항 중 \(L\)이 가장 큰 것에 1을 더한다.
  2. 계속: \(7\): 3 (7→8→10), \(2\): 4 (2→3→4→6), \(9\): 2 (9→10), \(5\): 4 (5→7→8→10).
    \(5\)의 뒤 더 큰 항 9, 7, 8, 10, 6 중 \(L\) 최대는 \(7\)의 3.
  3. \(L = (4, 2, 4, 3, 4, 2, 3, 1, 2, 1)\). \(L_1 = 4\)라 길이 4인 증가 부분수열 \(5, 7, 8, 10\)이 있다.
    \(L_i \ge n + 1 = 4\)인 경우.
  4. 증명의 다른 갈래도 확인: 같은 \(L\) 값을 가진 항, 예를 들어 \(L = 4\)인 \(5, 2, 1\)은 감소한다.
    같은 \(L\)이면 앞 항이 뒤 항보다 커야 한다(작으면 \(L\)이 커짐).
  5. \(L = 2\)인 \(9, 8, 4\)도 감소, \(L = 1\)인 \(10, 6\)도 감소. 여기서는 증가 쪽에서 답을 얻었다.
    \(L\) 값이 4가지 이상이면 증가, 3가지 이하면 한 값에 4개 이상 몰려 감소.

검산

\(5 < 7 < 8 < 10\)이고 위치가 1, 4, 6, 8번째로 순서가 맞습니다. \(2, 3, 4, 6\)이나 \(1, 3, 4, 6\)도 길이 4인 증가 부분수열입니다.

의미

\(L_i\)를 뒤에서부터 채우는 계산은 "가장 긴 증가 부분수열" 문제의 동적 계획법 풀이 그 자체입니다. 존재 증명의 도구가 그대로 알고리즘이 됩니다.

이해 확인

길이 4인 단조 부분수열이 없는 수 9개의 수열을 하나 만들어라.

답

\(7, 8, 9, 4, 5, 6, 1, 2, 3\): 증가는 블록 안에서 최대 3, 감소는 블록마다 하나씩 최대 3.
