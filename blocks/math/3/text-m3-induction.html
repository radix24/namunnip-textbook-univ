1.3.1수학적 귀납법

명제 \(P(n)\)이 모든 자연수 \(n \ge n_0\)에서 참임을 보이려면 두 가지를 보이면 됩니다.

  1. 기초 단계: \(P(n_0)\)이 참이다.
  2. 귀납 단계: 모든 \(k \ge n_0\)에 대해 \(P(k)\)이면 \(P(k + 1)\)이다.
예 1.3.1 \(1 + 3 + \cdots + (2n - 1) = n^2\). 기초: \(n = 1\)이면 \(1 = 1^2\). 귀납: \(1 + \cdots + (2k - 1) = k^2\)이면 양변에 \(2k + 1\)을 더해 \(k^2 + 2k + 1 = (k + 1)^2\). 따라서 모든 \(n \ge 1\)에서 성립합니다.

도미노에 비유하면, 첫 도미노가 넘어지고(기초) 각 도미노가 다음 것을 넘어뜨리면(귀납) 모두 넘어집니다. 알고리즘의 정확성(반복문이 끝나면 원하는 값)이나 점화식의 닫힌 꼴(3.3절)을 증명할 때 기본 도구입니다.

1.3.2강한 귀납법

\(P(k + 1)\)을 보이는 데 바로 앞의 \(P(k)\)만이 아니라 더 앞의 경우들이 필요할 때가 있습니다. 강한 귀납법은 귀납 단계에서 "\(P(n_0), \dots, P(k)\)가 모두 참이면 \(P(k + 1)\)이 참"을 보입니다.

예 1.3.2 2 이상의 모든 정수는 소수의 곱이다. \(k + 1\)이 소수면 끝. 아니면 \(k + 1 = ab\) (\(2 \le a, b \le k\))이고, \(a\)와 \(b\)는 가정에 의해 각각 소수의 곱이므로 \(k + 1\)도 소수의 곱이다. 여기서 \(a, b\)는 \(k\)가 아니라 그보다 작은 수라 보통의 귀납법으로는 부족합니다.

1.3.3정렬 원리

"반례가 있다면 가장 작은 반례가 있다"는 정렬 원리로도 같은 증명을 할 수 있습니다. 가장 작은 반례 \(m\)을 잡아 그보다 작은 경우는 모두 참이라는 사실로 모순을 끌어냅니다. 강한 귀납법, 보통의 귀납법, 정렬 원리는 서로 동치입니다.

흔한 오해(1) 기초 단계를 빼먹는다. "\(n\)이 참이면 \(n + 1\)도 참"만으로는 \(n = n + 1\) 같은 거짓 명제도 "증명"된다. (2) 귀납 단계에서 증명하려는 \(P(k + 1)\)을 이미 쓴다. \(P(k)\)(또는 그 앞)만 써야 한다.
요약
  1. 기초 단계 + 귀납 단계 \(P(k) \Rightarrow P(k + 1)\).
  2. 강한 귀납법: \(P(n_0), \dots, P(k) \Rightarrow P(k + 1)\).
  3. 정렬 원리(가장 작은 반례)와 동치.

1.3.4연습문제

기본

  1. \(1 + 2 + \cdots + n = \frac{n(n + 1)}2\)를 귀납법으로 증명하여라.
    답

    기초 \(n = 1\). 귀납: \(\frac{k(k + 1)}2 + (k + 1) = \frac{(k + 1)(k + 2)}2\).

응용

  1. 모든 \(n \ge 4\)에서 \(2^n \ge n^2\)임을 증명하여라.
    답

    기초 \(16 \ge 16\). 귀납: \(2^{k+1} = 2\cdot2^k \ge 2k^2 \ge (k + 1)^2\) (\(k \ge 3\)이면 \(k^2 \ge 2k + 1\)).

심화

  1. 피보나치 수 \(F_1 = F_2 = 1\), \(F_{n+1} = F_n + F_{n-1}\)에 대해 \(F_n < 2^n\)을 강한 귀납법으로 증명하여라.
    답

    기초 \(F_1 = 1 < 2\), \(F_2 = 1 < 4\). 귀납: \(F_{k+1} = F_k + F_{k-1} < 2^k + 2^{k-1} < 2^{k+1}\). 두 앞 항을 쓰므로 기초 단계도 둘 필요.
