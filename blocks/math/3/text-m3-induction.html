수학적 귀납법과 강한 귀납법

본문

\(1 = 1\), \(1 + 3 = 4\), \(1 + 3 + 5 = 9\), \(1 + 3 + 5 + 7 = 16\)이다. 홀수를 차례로 더하면 늘 제곱수가 나오는 것 같다. 몇 개를 더 확인해도 "모든 \(n\)"에 대한 증명은 되지 않는데, 끝없이 많은 경우를 한 번에 증명하려면 어떻게 해야 할까?

먼저 알아야 할 것고등학교 수학Ⅰ의 수학적 귀납법과 명제와 논리(1.1절)를 쓴다.

1.3.1수학적 귀납법

명제 \(P(n)\)이 모든 자연수 \(n \ge n_0\)에서 참임을 보이려면 두 가지를 보이면 된다. 먼저 기초 단계로 \(P(n_0)\)이 참임을 보이고, 다음으로 귀납 단계로 모든 \(k \ge n_0\)에 대해 \(P(k)\)이면 \(P(k + 1)\)임을 보인다.

예제 1.3.1

\(1 + 3 + \cdots + (2n - 1) = n^2\)임을 보여라.

풀이. \(n = 1\)이면 \(1 = 1^2\)이므로 기초 단계가 성립한다. 귀납 단계로 \(1 + \cdots + (2k - 1) = k^2\)이라 하고 양변에 \(2k + 1\)을 더하면 \(k^2 + 2k + 1 = (k + 1)^2\)이다. 따라서 모든 \(n \ge 1\)에서 성립한다. 그림 1의 ㄱ자 띠가 바로 더한 \(2k + 1\)이다.

도미노에 비유하면, 첫 도미노가 넘어지고(기초) 각 도미노가 다음 것을 넘어뜨리면(귀납) 모두 넘어진다. 귀납법은 반복문이 끝나면 원하는 값이 나온다는 알고리즘의 정확성이나, 점화식의 닫힌 꼴(3.3절)을 증명할 때 기본 도구이다.

1.3.2강한 귀납법

그런데 \(P(k + 1)\)을 보이는 데 바로 앞의 \(P(k)\)만이 아니라 더 앞의 경우들이 필요할 때가 있다. 이때 쓰는 강한 귀납법은 귀납 단계에서 "\(P(n_0), \dots, P(k)\)가 모두 참이면 \(P(k + 1)\)이 참"을 보인다.

예제 1.3.2

2 이상의 모든 정수는 소수의 곱임을 보여라.

풀이. \(k + 1\)이 소수이면 끝난다. 아니면 \(k + 1 = ab\) (\(2 \le a, b \le k\))이고, 가정에 의해 \(a\)와 \(b\)가 각각 소수의 곱이므로 \(k + 1\)도 소수의 곱이다. 여기서 \(a, b\)는 \(k\)가 아니라 그보다 작은 수이므로 보통의 귀납법으로는 부족하다.

1.3.3정렬 원리

"반례가 있다면 가장 작은 반례가 있다"는 정렬 원리로도 같은 증명을 할 수 있다. 가장 작은 반례 \(m\)을 잡고, 그보다 작은 경우는 모두 참이라는 사실로 모순을 끌어낸다. 실제로 강한 귀납법, 보통의 귀납법, 정렬 원리는 서로 동치이며, 증명은 집합론 1.3절에 있다.

흔한 오해기초 단계를 빼먹기 쉽다. "\(n\)이 참이면 \(n + 1\)도 참"만으로는 \(n = n + 1\) 같은 거짓 명제도 "증명"되어 버린다. 또 귀납 단계에서 증명하려는 \(P(k + 1)\)을 이미 쓰는 실수가 있는데, 쓸 수 있는 것은 \(P(k)\)와 그 앞의 경우뿐이다.
마무리

처음 질문의 답은 수학적 귀납법이다. 첫 경우를 보이는 기초 단계와, 모든 \(k\)에서 \(P(k) \Rightarrow P(k + 1)\)을 보이는 귀납 단계 두 가지로 끝없이 많은 경우를 한 번에 증명한다. 홀수의 합이 \(n^2\)인 것은 정사각형에 ㄱ자 띠를 붙이는 한 걸음이 늘 통하기 때문이다. 더 앞의 경우가 필요하면 강한 귀납법을 쓰며, 이것은 가장 작은 반례를 잡는 정렬 원리와 동치이다.

1.3.4연습문제

기본

  1. \(1 + 2 + \cdots + n = \frac{n(n + 1)}2\)를 귀납법으로 증명하여라.
    답

    기초 \(n = 1\). (귀납) \(\frac{k(k + 1)}2 + (k + 1) = \frac{(k + 1)(k + 2)}2\).

응용

  1. 모든 \(n \ge 4\)에서 \(2^n \ge n^2\)임을 증명하여라.
    답

    기초 \(16 \ge 16\). (귀납) \(2^{k+1} = 2\cdot2^k \ge 2k^2 \ge (k + 1)^2\) (\(k \ge 3\)이면 \(k^2 \ge 2k + 1\)).

심화

  1. 피보나치 수 \(F_1 = F_2 = 1\), \(F_{n+1} = F_n + F_{n-1}\)에 대해 \(F_n < 2^n\)을 강한 귀납법으로 증명하여라.
    답

    기초 \(F_1 = 1 < 2\), \(F_2 = 1 < 4\). (귀납) \(F_{k+1} = F_k + F_{k-1} < 2^k + 2^{k-1} < 2^{k+1}\). 두 앞 항을 쓰므로 기초 단계도 둘 필요.
