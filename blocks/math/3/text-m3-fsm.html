유한상태 기계

본문
이 절에서 배울 것
  • 알파벳, 문자열, 언어를 정의한다.
  • 결정적 유한 오토마타(DFA)를 상태 전이도로 그리고 문자열을 받아들이는지 판정한다.
  • "상태는 무엇을 기억하는가"로 주어진 언어의 DFA를 설계한다.
먼저 알아야 할 것
  • 함수와 집합 (수학2 3단원), 합동 (4.1절), 방향 그래프 (5.1절).

7.1.1언어

정의 7.1.1

알파벳 \(\Sigma\): 유한한 기호 집합. 예: \(\{0, 1\}\).

문자열: 기호의 유한 열. 빈 문자열은 \(\varepsilon\). \(\Sigma^*\)는 모든 문자열의 집합.

언어: \(\Sigma^*\)의 부분집합. 예: "1이 짝수 개인 이진 문자열 전체".

7.1.2결정적 유한 오토마타

자판기, 엘리베이터, 신호등, 정규 표현식 검색은 "지금 상태"와 "들어온 입력"으로 다음 상태가 정해지는 기계입니다. 기억 장치가 상태 몇 개뿐이라는 것이 핵심입니다.

정의 7.1.2 (DFA)

\(M = (Q, \Sigma, \delta, q_0, F)\): 유한한 상태 집합 \(Q\), 알파벳 \(\Sigma\), 전이 함수 \(\delta: Q\times\Sigma \to Q\), 시작 상태 \(q_0\), 받아들이는 상태 집합 \(F \subseteq Q\). 문자열을 왼쪽부터 한 기호씩 읽으며 \(\delta\)로 상태를 옮기고, 다 읽었을 때 \(F\)에 있으면 받아들인다. \(M\)이 받아들이는 문자열 전체가 \(L(M)\).

예제 7.1.3

(a) 1이 짝수 개인 이진 문자열을 받아들이는 DFA. (b) 이진수로 읽은 값이 3의 배수인 문자열을 받아들이는 DFA.

풀이. (a) 기억할 것은 "지금까지 1의 개수의 짝홀"뿐입니다. 상태 \(E\)(짝, 시작·받아들임), \(O\)(홀). 1을 읽으면 바뀌고 0을 읽으면 그대로. "1011"은 \(E \to O \to O \to E \to O\)로 거부.

(b) 기억할 것은 "지금까지 읽은 수 \(\bmod 3\)"입니다. 수 \(x\) 뒤에 비트 \(b\)를 붙이면 \(2x + b\)가 되므로 \(\delta(r, b) = (2r + b) \bmod 3\). 상태 0(시작·받아들임), 1, 2.

  • 0에서: 0 → 0, 1 → 1.
  • 1에서: 0 → 2, 1 → 0.
  • 2에서: 0 → 1, 1 → 2.

"110"(=6): \(0 \to 1 \to 0 \to 0\) 받아들임. "111"(=7): \(0 \to 1 \to 0 \to 1\) 거부. 수가 아무리 길어도 상태 세 개로 충분합니다. 같은 절의 탐구 카드에서 문자열을 넣어 상태 이동을 볼 수 있습니다.

7.1.3설계 요령

"끝까지 읽었을 때 답을 정하려면 지금까지 읽은 것에서 무엇만 알면 되는가"를 묻고, 그 정보의 가능한 값마다 상태를 하나씩 둡니다. 정보가 유한 가지면 DFA로 됩니다. 반대로 "0이 \(n\)개 나온 뒤 1이 같은 \(n\)개"(\(\{0^n1^n\}\))는 \(n\)을 끝없이 세어야 해 유한 상태로는 불가능합니다(7.2절).

흔한 실수(1) 어떤 상태에서 어떤 기호의 전이를 빠뜨린다: DFA는 모든 (상태, 기호)에 전이가 정확히 하나 있어야 한다. 갈 곳이 없으면 "함정" 상태를 둔다. (2) 빈 문자열을 잊는다: 시작 상태가 받아들임이면 \(\varepsilon\)도 받아들인다.
요약
  1. 언어 = 문자열의 집합. DFA는 유한 상태, 전이 함수, 받아들이는 상태로 언어를 인식한다.
  2. 설계: 끝에서 판단하는 데 필요한 정보를 상태로(짝홀, 나머지, 최근 기호 등).
  3. 무한한 정보가 필요한 언어(\(0^n1^n\))는 DFA로 인식할 수 없다.

7.1.4연습문제

기본

  1. "01"로 끝나는 이진 문자열을 받아들이는 DFA를 설계하여라.
    답

    상태: A(마지막이 0도 01도 아님), B(마지막이 0), C(마지막 두 개가 01, 받아들임). A: 0→B, 1→A. B: 0→B, 1→C. C: 0→B, 1→A.

응용

  1. 예제 (b)의 DFA로 "10010"(=18)을 읽는 상태 순서를 쓰라.
    답

    \(0 \to 1 \to 2 \to 1 \to 0 \to 0\). 받아들임(18은 3의 배수).

심화

  1. "1이 짝수 개이고 0이 3의 배수 개"인 문자열의 DFA는 상태가 몇 개 필요한가?
    답

    (1의 짝홀) × (0의 개수 mod 3) = 6개(곱 오토마타).
