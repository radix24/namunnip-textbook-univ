상태 세 개로 3의 배수를 가려낸다

탐구 · 유한상태 기계 실행

질문

아무리 긴 이진수라도 3의 배수인지 판정하는 데 기억할 것이 몇 가지면 충분할까? 기계가 문자열을 읽는 동안 상태는 어떻게 움직일까?

복원

DFA는 상태와 전이 함수로 문자열을 한 기호씩 읽고, 끝난 상태가 받아들이는 상태이면 받아들인다. 3의 배수 판정은 \(\delta(r, b) = (2r + b) \bmod 3\) (7.1절).

해 보기

  1. 처음 입력 "110"(=6)을 한 글자씩 읽자. 상태가 0 → 1 → 0 → 0으로 움직여 받아들이다.
  2. 입력을 "111"(=7)로 바꾸면 0 → 1 → 0 → 1로 거부한다.
  3. "10010"(=18)이나 아주 긴 수를 넣어도 상태는 0, 1, 2 세 개 안에서만 움직인다. 상태가 "지금까지 읽은 수를 3으로 나눈 나머지"이기 때문이다.
  4. "1이 짝수 개" 기계와 "01로 끝남" 기계로 바꿔 같은 입력이 어떻게 판정되는지 비교해 보자.

설명

  1. 왜 \(2r + b\)인가이진수 \(x\) 뒤에 비트 \(b\)를 붙이면 값이 \(2x + b\)가 된다. 나머지만 보면 \((2r + b) \bmod 3\)이라 전체 값을 기억할 필요가 없다. 같은 원리로 아무 \(n\)의 배수도 상태 \(n\)개로 판정한다.
  2. 상태 = 기억DFA의 상태 수는 기계가 가진 기억의 전부이다. 판정에 필요한 정보가 유한 가지이면 DFA로 만들 수 있다.

판단

"긴 수를 판정하려면 수 전체를 저장해야 한다"는 틀린다. 3의 배수 판정은 상태 세 개면 충분하다. 무엇을 기억해야 하는지 정확히 아는 것이 기계 설계의 핵심이다.
