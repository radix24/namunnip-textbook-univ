별과 막대로 나누기를 세기

탐구 · 중복조합

질문

똑같은 사탕 \(k\)개를 아이 \(n\)명에게 나눠 주는 방법은 몇 가지일까? 나누는 방법 하나하나를 어떻게 빠짐없이 늘어놓을 수 있을까?

복원

\(x_1 + \dots + x_n = k\)의 음이 아닌 정수해는 별 \(k\)개와 막대 \(n - 1\)개의 나열과 일대일 대응이라 \(\binom{n+k-1}{k}\)개다 (3.1절).

해 보기

  1. \(n = 3\), \(k = 5\)이면 모두 \(\binom 75 = 21\)가지이다. 번호를 1부터 21까지 움직이며 막대 두 개가 7칸 중 어디에 있는지 보자.
  2. 막대가 맨 앞에 있으면 \(x_1 = 0\), 막대 두 개가 붙어 있으면 가운데 상자가 0이다. 빈 상자도 허용된다.
  3. \(n = 6\), \(k = 8\)이면 \(\binom{13}{8} = 1287\)가지로 늘어난다.

설명

  1. 세는 대상을 바꾸기나누는 방법을 직접 세는 대신, 같은 개수의 "별·막대 나열"을 센다. 나열은 막대(또는 별)의 자리만 고르면 되므로 조합이 된다. 전단사로 세는 대상을 바꾸는 것이 조합론의 기본 기술이다.

판단

"사탕 5개를 3명에게 나누는 방법은 \(3^5 = 243\)가지"는 사탕을 서로 구별할 때의 답이다. 사탕이 똑같으면 누가 몇 개 받는지만 중요해 21가지이다.
