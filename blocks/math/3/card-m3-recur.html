큰 근이 수열을 지배한다

탐구 · 선형 점화식과 특성근

질문

\(a_n = c_1a_{n-1} + c_2a_{n-2}\)의 수열은 길게 보면 어떻게 자랄까요? 연속한 두 항의 비 \(\frac{a_{n+1}}{a_n}\)은 어디로 갈까요?

복원

특성근 \(r_1, r_2\)로 \(a_n = \alpha r_1^n + \beta r_2^n\)이고, 중근이면 \((\alpha + \beta n)r^n\) (3.3절).

해 보기

  1. 처음 화면은 피보나치(\(c_1 = c_2 = 1\))입니다. 비가 1, 2, 1.5, 1.67, …으로 흔들리다 \(\phi \approx 1.618\)에 붙습니다.
  2. \(c_1 = 5\)는 범위 밖이니 \(c_1 = 1\), \(c_2 = 2\)로 해 보세요. 근 2와 \(-1\)이라 \(a_n\)은 \(2^n\) 꼴로 자라고 비는 2로 갑니다.
  3. \(c_1 = 2\), \(c_2 = -1\)이면 중근 1이라 \(a_n = \alpha + \beta n\), 직선처럼 자랍니다(비는 1로 아주 천천히).
  4. \(c_1 = 1\), \(c_2 = -1\)이면 근이 복소수(절댓값 1)라 수열이 0, 1, 1, 0, −1, −1, 0, …으로 주기 6을 돕니다. 비는 수렴하지 않습니다.

설명

  1. 지배적인 근\(|r_1| > |r_2|\)이고 \(\alpha \ne 0\)이면 \(a_n = r_1^n\left(\alpha + \beta(r_2/r_1)^n\right)\)에서 괄호 안이 \(\alpha\)로 가므로 \(\frac{a_{n+1}}{a_n} \to r_1\)입니다.
  2. 초기값이 특별하면초기값을 \(\alpha = 0\)이 되게 고르면(예: \(c_1 = 1\), \(c_2 = 2\), \(a_0 = 1\), \(a_1 = -1\)) 작은 근의 성분만 남아 \(a_n = (-1)^n\)입니다.

판단

"계수가 양수인 점화식의 비는 늘 수렴한다"는 이 카드의 범위에서는 맞지만(\(c_1, c_2 > 0\)이면 양의 지배근이 있음), "계수가 실수이면 늘 수렴한다"는 틀립니다. 복소근이나 크기가 같은 두 실근(\(\pm r\))이면 비가 진동합니다.
