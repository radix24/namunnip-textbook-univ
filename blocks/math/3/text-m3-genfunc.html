생성함수와 Catalan 수

본문

괄호 \(n\)쌍을 올바르게 늘어놓는 방법의 수는 \(1, 1, 2, 5, 14, \dots\)이다. 이 수열의 점화식은 앞의 항들을 곱해 더하는 꼴이라 특성방정식으로는 풀 수 없다. 수열 전체를 함수 하나로 묶으면 이 점화식이 이차방정식이 된다.

먼저 알아야 할 것선형 점화식(3.3절), 이항계수, 멱급수의 곱(미적분)을 쓴다.

8.2.1생성함수

수열 \((a_n)\)의 생성함수는 형식적 멱급수 \(A(x) = \sum_{n \ge 0}a_nx^n\)이다. 수렴 여부는 따지지 않고 계수를 담는 그릇으로 쓴다. 두 생성함수의 곱의 계수는 \(\sum_{k}a_kb_{n-k}\)이므로, 곱이 "둘로 나누어 세기"에 해당한다는 것이 생성함수의 쓸모이다.

먼저 익숙한 점화식을 풀어 보자. \(a_n = 2a_{n-1} + 1\), \(a_0 = 0\)(하노이 탑)에서 양변에 \(x^n\)을 곱해 \(n \ge 1\)에 대해 더하면 \(A(x) = 2xA(x) + \frac{x}{1 - x}\)이다. 그러면 \(A(x) = \frac{x}{(1 - x)(1 - 2x)} = \frac{1}{1 - 2x} - \frac{1}{1 - x}\)이고, 계수를 읽으면 \(a_n = 2^n - 1\)이다.

8.2.2Catalan 수

올바른 괄호열 \(n\)쌍의 개수를 \(C_n\)이라 하자. 그림 1처럼 경로가 처음 바닥으로 돌아오는 곳을 \(2(k+1)\)번째 걸음이라 하면, 맨 앞의 "("와 그 짝 ")" 사이에 \(k\)쌍짜리 올바른 열이 있고 뒤에 \(n - 1 - k\)쌍짜리 열이 있다. 따라서

\[C_n = \sum_{k=0}^{n-1}C_kC_{n-1-k}, \qquad C_0 = 1\]

이다. 오른쪽은 곱의 계수 꼴이므로 생성함수 \(C(x) = \sum C_nx^n\)에서 \(C(x) = 1 + xC(x)^2\)이 된다. 이차방정식을 풀면 \(C(x) = \frac{1 - \sqrt{1 - 4x}}{2x}\)이다. 다른 부호는 \(x \to 0\)에서 발산하므로 버린다.

정리 8.2.1

\(C_n = \frac{1}{n + 1}\binom{2n}{n}\).

일반화 이항정리로 \(\sqrt{1 - 4x} = \sum_m\binom{1/2}{m}(-4x)^m\)을 전개하면 된다. \(\binom{1/2}{m}(-4)^m = -\frac{2}{m}\binom{2m - 2}{m - 1}\)(\(m \ge 1\))이므로 \(1 - \sqrt{1 - 4x} = \sum_{m\ge1}\frac2m\binom{2m-2}{m-1}x^m\)이고, \(2x\)로 나누어 \(m = n + 1\)로 두면 \(C_n = \frac{1}{n+1}\binom{2n}{n}\)이다.

예제 8.2.2

볼록 \((n + 2)\)각형을 대각선으로 삼각형들로 나누는 방법의 수가 \(C_n\)임을 보이고 육각형의 경우를 구하여라.

풀이. 꼭짓점 \(0, 1, \dots, n + 1\)에서 변 \(0\)–\((n + 1)\)을 품는 삼각형의 셋째 꼭짓점을 \(k + 1\)이라 하면, 그 왼쪽에 \((k + 2)\)각형, 오른쪽에 \((n - k + 1)\)각형이 남는다. 두 쪽을 따로 나누므로 Catalan 점화식과 같고, 삼각형(\(n = 1\))은 1가지라 초깃값도 맞는다. 육각형은 \(n = 4\)이므로 \(C_4 = \frac15\binom84 = 14\)가지이다.

마무리

생성함수는 수열을 멱급수 하나에 담아, 둘로 나누어 세는 점화식을 곱셈으로 바꾼다. 괄호열을 처음 닫히는 곳에서 자르면 Catalan 점화식이 나오고, 그 생성함수는 이차방정식 \(C = 1 + xC^2\)을 만족한다. 이것을 풀어 전개하면 \(C_n = \frac{1}{n+1}\binom{2n}{n}\)이다.

8.2.3연습문제

기본

  1. \(a_n = a_{n-1} + a_{n-2}\), \(a_0 = 0\), \(a_1 = 1\)의 생성함수를 구하여라.
    답

    \(\frac{x}{1 - x - x^2}\).

응용

  1. 꼭짓점이 \(n + 1\)개인 뿌리 있는 평면 나무의 개수가 \(C_n\)임을 설명하여라.
    답

    나무를 깊이 우선으로 돌며 내려갈 때 "(", 올라올 때 ")"를 쓰면 \(n\)개의 변이 올바른 괄호열 \(n\)쌍과 일대일로 대응한다.
