분할 정복 점화식과 마스터 정리

본문

\(n\)자리 수 두 개를 곱할 때, 각 수를 반으로 쪼개 작은 곱셈 4번으로 나누면 전혀 빨라지지 않는다. 그런데 작은 곱셈을 3번으로 줄이면 갑자기 빨라진다. 곱셈 하나를 줄였을 뿐인데 왜 이렇게 큰 차이가 날까?

먼저 알아야 할 것점근 표기(2.1절), 병합 정렬(2.2절), 등비수열의 합을 쓴다.

3.4.1재귀 나무

크기 \(n\)인 문제를 크기 \(\frac nb\)인 문제 \(a\)개로 나누고, 나누고 합치는 데 \(f(n)\)이 들면 \(T(n) = aT(n/b) + f(n)\)이다. 이것을 나무로 그리면 깊이 \(j\)에 크기 \(\frac{n}{b^j}\)인 문제가 \(a^j\)개 있고, 층 \(j\)의 비용은 \(a^jf(n/b^j)\)이며, 깊이는 \(\log_bn\)이다.

특히 \(f(n) = n^d\)이면 층 \(j\)의 비용은 \(n^d\left(\frac{a}{b^d}\right)^j\), 곧 공비 \(q = \frac{a}{b^d}\)인 등비수열이다. 전체 비용은 이 등비수열의 합이므로, 공비에 따라 세 경우가 갈린다.

정리 3.4.1 (마스터 정리, 다항식 꼴)

\(T(n) = aT(n/b) + \Theta(n^d)\) (\(a \ge 1\), \(b > 1\), \(d \ge 0\))일 때 다음이 성립한다. (1) \(a < b^d\)이면 \(T(n) = \Theta(n^d)\)이고, 맨 위층의 합치기가 지배한다. (2) \(a = b^d\)이면 \(T(n) = \Theta(n^d\log n)\)이고, 모든 층이 같아 층 수만큼 곱해진다. (3) \(a > b^d\)이면 \(T(n) = \Theta(n^{\log_ba})\)이고, 맨 아래층의 잎이 지배한다.

증명의 뼈대.\(T(n) = \sum_{j=0}^{\log_bn}n^dq^j\)이다. \(q < 1\)이면 등비합이 첫 항의 상수배라 \(\Theta(n^d)\)이다. \(q = 1\)이면 합이 \((\log_bn + 1)n^d\)이다. \(q > 1\)이면 마지막 항 \(n^dq^{\log_bn} = n^d\frac{a^{\log_bn}}{n^d} = n^{\log_ba}\)가 상수배로 지배한다. ∎

3.4.2적용

이진 탐색 \(T(n) = T(n/2) + 1\)은 \(a = 1\), \(b = 2\), \(d = 0\)이라 \(a = b^d\)이고 \(\Theta(\log n)\)이다. 병합 정렬 \(T(n) = 2T(n/2) + n\)도 \(a = 2 = b^d\)라 \(\Theta(n\log n)\)이다. 반면 보통의 곱셈을 반으로 나눈 \(T(n) = 4T(n/2) + n\)은 \(4 > 2\)라 \(\Theta(n^2)\)이며, 나눠도 빨라지지 않는다.

그런데 카라추바 곱셈은 작은 곱셈 4번을 3번으로 줄여 \(T(n) = 3T(n/2) + n\)이 되고, \(3 > 2\)라 \(\Theta(n^{\log_23}) \approx \Theta(n^{1.585})\)이다. 곱셈 하나를 줄인 것이 상수가 아니라 지수를 바꾼 것이다. 실제로 \(n = 1024\)자리라면 \(n^2\)은 약 100만이고 \(n^{1.585}\)는 약 6만이라, 자릿수가 클수록 차이가 커진다. 같은 생각으로 스트라센 행렬 곱셈은 \(T(n) = 7T(n/2) + n^2\)이고 \(7 > 4\)라 \(\Theta(n^{\log_27}) \approx \Theta(n^{2.807})\)이다.

흔한 오해\(a\)와 \(b\)를 바꿔 읽기 쉽다. \(a\)는 하위 문제의 개수이고 \(b\)는 크기를 나누는 비율이다. 또 \(f(n)\)이 \(n^d\) 꼴이 아닌데 표를 그대로 쓰는 실수가 있다. \(T(n) = 2T(n/2) + n\log n\)은 이 정리에 맞지 않으며, 재귀 나무로 직접 계산하면 \(\Theta(n\log^2n)\)이다.
마무리

처음 질문에 답하면, 작은 곱셈의 개수 \(a\)가 잎의 수 \(a^{\log_2n} = n^{\log_2a}\)를 정하기 때문이다. \(a = 4\)이면 잎이 \(n^2\)개라 나눠도 \(\Theta(n^2)\)이지만, \(a = 3\)이면 \(n^{1.585}\)개로 줄어 지수가 바뀐다. 일반적으로 재귀 나무 층 \(j\)의 비용은 공비 \(a/b^d\)인 등비수열이고, \(a < b^d\)이면 \(\Theta(n^d)\), \(a = b^d\)이면 \(\Theta(n^d\log n)\), \(a > b^d\)이면 \(\Theta(n^{\log_ba})\)이다.

3.4.3연습문제

기본

  1. \(T(n) = 9T(n/3) + n\)과 \(T(n) = 2T(n/4) + n\)을 풀어라.
    답

    \(9 > 3\): \(\Theta(n^2)\). \(2 < 4\): \(\Theta(n)\).

응용

  1. \(T(n) = 2T(n/4) + \sqrt n\)을 풀어라.
    답

    \(d = \frac12\), \(b^d = 2 = a\): \(\Theta(\sqrt n\log n)\).

심화

  1. \(T(n) = 2T(n/2) + n\log n\)을 재귀 나무로 풀어라.
    답

    층 \(j\)의 비용 \(n\log(n/2^j) = n(\log n - j)\). 합 \(\approx n\frac{\log^2n}2 = \Theta(n\log^2n)\).
