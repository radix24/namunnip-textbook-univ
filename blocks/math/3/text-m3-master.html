분할 정복 점화식과 마스터 정리

본문
이 절에서 배울 것
  • 분할 정복 알고리즘의 실행 시간을 \(T(n) = aT(n/b) + f(n)\)으로 세운다.
  • 재귀 나무로 각 층의 비용을 더해 \(T(n)\)을 어림한다.
  • 마스터 정리의 세 경우를 \(f(n) = n^d\)에서 쓰고, 이진 탐색·병합 정렬·카라추바 곱셈에 적용한다.
먼저 알아야 할 것
  • 점근 표기와 병합 정렬 (2.1절, 2.2절), 등비급수, 로그의 성질 \(a^{\log_bn} = n^{\log_ba}\).

3.4.1재귀 나무

크기 \(n\)인 문제를 크기 \(\frac nb\)인 문제 \(a\)개로 나누고, 나누고 합치는 데 \(f(n)\)이 들면 \(T(n) = aT(n/b) + f(n)\)입니다. 나무로 그리면 깊이 \(j\)에 문제가 \(a^j\)개, 크기가 \(\frac{n}{b^j}\)이고, 층 \(j\)의 비용은 \(a^jf(n/b^j)\), 깊이는 \(\log_bn\)입니다.

\(f(n) = n^d\)이면 층 \(j\)의 비용은 \(n^d\left(\frac{a}{b^d}\right)^j\), 곧 공비 \(q = \frac{a}{b^d}\)인 등비수열입니다. 전체는 이 등비수열의 합이고, 공비에 따라 세 경우가 갈립니다.

정리 3.4.1 (마스터 정리, 다항식 꼴)

\(T(n) = aT(n/b) + \Theta(n^d)\) (\(a \ge 1\), \(b > 1\), \(d \ge 0\))이면

(1) \(a < b^d\) (\(q < 1\)): \(T(n) = \Theta(n^d)\) — 맨 위층(합치기)이 지배.

(2) \(a = b^d\) (\(q = 1\)): \(T(n) = \Theta(n^d\log n)\) — 모든 층이 같아 층 수만큼.

(3) \(a > b^d\) (\(q > 1\)): \(T(n) = \Theta(n^{\log_ba})\) — 맨 아래층(잎)이 지배.

증명의 뼈대.\(T(n) = \sum_{j=0}^{\log_bn}n^dq^j\). \(q < 1\)이면 등비합이 상수배라 \(\Theta(n^d)\). \(q = 1\)이면 \((\log_bn + 1)n^d\). \(q > 1\)이면 마지막 항 \(n^dq^{\log_bn} = n^d\frac{a^{\log_bn}}{n^d} = n^{\log_ba}\)이 상수배로 지배. ∎

3.4.2적용

  • 이진 탐색 \(T(n) = T(n/2) + 1\): \(a = 1\), \(b = 2\), \(d = 0\), \(a = b^d\) → \(\Theta(\log n)\).
  • 병합 정렬 \(T(n) = 2T(n/2) + n\): \(a = 2 = b^d\) → \(\Theta(n\log n)\).
  • 보통 곱셈을 나눠서 \(T(n) = 4T(n/2) + n\): \(4 > 2\) → \(\Theta(n^2)\). 나눠도 빨라지지 않습니다.
  • 카라추바 곱셈 \(T(n) = 3T(n/2) + n\): \(3 > 2\) → \(\Theta(n^{\log_23}) \approx \Theta(n^{1.585})\). 곱셈 4번을 3번으로 줄인 것이 지수를 바꿉니다.
  • 스트라센 행렬 곱셈 \(T(n) = 7T(n/2) + n^2\): \(7 > 4\) → \(\Theta(n^{\log_27}) \approx \Theta(n^{2.807})\).

같은 절의 탐구 카드에서 \(a, b, d\)를 바꿔 층별 비용을 막대로 볼 수 있습니다.

흔한 실수(1) \(a\)와 \(b\)를 바꿔 읽는다: \(a\)는 하위 문제 개수, \(b\)는 크기를 나누는 비율. (2) \(f(n)\)이 \(n^d\) 꼴이 아니면 그대로 쓴다: \(T(n) = 2T(n/2) + n\log n\)은 이 표에 맞지 않고 \(\Theta(n\log^2n)\)이다(재귀 나무로 직접).
요약
  1. 재귀 나무 층 \(j\)의 비용 \(n^d(a/b^d)^j\): 등비수열.
  2. \(a < b^d\): \(\Theta(n^d)\), \(a = b^d\): \(\Theta(n^d\log n)\), \(a > b^d\): \(\Theta(n^{\log_ba})\).
  3. 카라추바(3개로) \(n^{1.585}\), 스트라센(7개로) \(n^{2.807}\).

3.4.3연습문제

기본

  1. \(T(n) = 9T(n/3) + n\)과 \(T(n) = 2T(n/4) + n\)을 풀어라.
    답

    \(9 > 3\): \(\Theta(n^2)\). \(2 < 4\): \(\Theta(n)\).

응용

  1. \(T(n) = 2T(n/4) + \sqrt n\)을 풀어라.
    답

    \(d = \frac12\), \(b^d = 2 = a\): \(\Theta(\sqrt n\log n)\).

심화

  1. \(T(n) = 2T(n/2) + n\log n\)을 재귀 나무로 풀어라.
    답

    층 \(j\)의 비용 \(n\log(n/2^j) = n(\log n - j)\). 합 \(\approx n\frac{\log^2n}2 = \Theta(n\log^2n)\).
