재귀 나무의 어느 층이 비싼가

탐구 · 마스터 정리

질문

분할 정복 알고리즘의 시간은 "나누고 합치는 일"과 "가장 작은 문제를 푸는 일" 중 어느 쪽이 정할까요? \(a, b, d\)가 바뀌면 그 균형은 어떻게 변할까요?

복원

층 \(j\)의 비용은 \(n^d(a/b^d)^j\). 공비 \(< 1\)이면 \(\Theta(n^d)\), \(= 1\)이면 \(\Theta(n^d\log n)\), \(> 1\)이면 \(\Theta(n^{\log_ba})\) (3.4절).

해 보기

  1. 처음 화면(병합 정렬 \(a = 2\), \(b = 2\), \(d = 1\))은 모든 층의 막대 높이가 같습니다. 층이 \(\log_2n\)개라 \(\Theta(n\log n)\)입니다.
  2. \(a = 3\)(카라추바)으로 바꾸면 막대가 아래로 갈수록 1.5배씩 커져 잎이 지배합니다: \(\Theta(n^{1.585})\).
  3. \(a = 4\)이면 공비 2로 \(\Theta(n^2)\), 나눠 푸는 이득이 사라집니다.
  4. \(a = 2\), \(d = 2\)이면 공비 \(\frac12\)라 맨 위층(합치기)이 대부분이고 \(\Theta(n^2)\)입니다.
  5. \(a = 1\), \(d = 0\)(이진 탐색)이면 층마다 1이라 \(\Theta(\log n)\)입니다.

설명

  1. 두 힘의 줄다리기층이 내려갈 때 문제 수는 \(a\)배로 늘고, 문제 하나의 비용은 \(b^d\)분의 1로 줄어듭니다. 둘 중 어느 쪽이 큰지가 공비 \(\frac{a}{b^d}\)이고, 그것이 결과를 정합니다.
  2. 알고리즘 설계에의 교훈잎이 지배하는 경우(\(a > b^d\))에는 합치는 비용을 줄여도 소용이 없고, 하위 문제 수 \(a\)를 줄여야 합니다. 카라추바와 스트라센이 바로 그렇게 했습니다.

판단

"문제를 반으로 나누면 늘 빨라진다"는 틀립니다. \(T(n) = 4T(n/2) + n\)(곱셈을 4번 하는 분할)은 그냥 곱하는 \(\Theta(n^2)\)과 같습니다. 나눈 뒤 하위 문제 수가 너무 많으면 이득이 없습니다.
