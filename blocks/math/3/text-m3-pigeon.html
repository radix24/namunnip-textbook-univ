비둘기집 원리

본문
이 절에서 배울 것
  • 비둘기집 원리와 일반화된 꼴(\(\lceil n/k\rceil\))을 진술하고 증명한다.
  • "무엇을 비둘기로, 무엇을 집으로 볼지" 정해 존재성을 증명한다.
  • 에르되시-세케레시 정리(길이 \(n^2 + 1\) 수열의 단조 부분수열)를 증명한다.
먼저 알아야 할 것
  • 귀류법 (수학2 1.2절), 나머지(합동).

3.2.1원리

정리 3.2.1 (비둘기집 원리)

(a) 물건 \(n + 1\)개를 상자 \(n\)개에 넣으면 물건이 2개 이상 든 상자가 있다. (b) 물건 \(N\)개를 상자 \(k\)개에 넣으면 물건이 \(\lceil N/k\rceil\)개 이상 든 상자가 있다.

증명.(b) 모든 상자에 \(\lceil N/k\rceil - 1\)개 이하라면 합이 \(k(\lceil N/k\rceil - 1) < k\cdot\frac Nk = N\)이 되어 모순. (a)는 \(N = n + 1\), \(k = n\). ∎

원리는 당연하지만, 존재만 알려 주고 어느 상자인지는 알려 주지 않습니다. 실력은 "비둘기"와 "집"을 고르는 데서 나옵니다.

3.2.2예

예제 3.2.2

(a) 정수 \(n\)개 \(a_1, \dots, a_n\) 중 연속한 몇 개의 합이 \(n\)의 배수인 것이 있음을 보여라. (b) 1부터 200까지 중 101개를 고르면 하나가 다른 하나를 나누는 쌍이 있음을 보여라.

풀이. (a) 부분합 \(S_0 = 0, S_1 = a_1, \dots, S_n = a_1 + \dots + a_n\)은 \(n + 1\)개이고, \(n\)으로 나눈 나머지는 \(n\)가지입니다. 비둘기집 원리로 \(S_i \equiv S_j\) (\(i < j\))인 쌍이 있고, \(S_j - S_i = a_{i+1} + \dots + a_j\)가 \(n\)의 배수입니다. (b) 각 수를 \(2^e\cdot m\) (\(m\) 홀수)로 쓰면 \(m\)은 1, 3, …, 199의 100가지입니다. 101개 중 두 수가 같은 \(m\)을 가지며, 그 둘은 \(2^e m\)과 \(2^{e'}m\)이라 작은 것이 큰 것을 나눕니다. 100개로는 부족하다는 것도 101–200을 고르면 확인됩니다.

3.2.3에르되시-세케레시

정리 3.2.3

서로 다른 실수 \(n^2 + 1\)개의 수열에는 길이 \(n + 1\)인 증가 부분수열이나 감소 부분수열이 있다.

증명.각 항 \(a_i\)에 "\(a_i\)에서 시작하는 가장 긴 증가 부분수열의 길이" \(L_i\)를 붙인다. 모든 \(L_i \le n\)이라 하자(아니면 끝). 그러면 \(L_i\)의 값은 \(1, \dots, n\)의 \(n\)가지이고 항은 \(n^2 + 1\)개라, 일반화된 비둘기집 원리로 같은 \(L\) 값을 갖는 항이 \(\lceil\frac{n^2+1}{n}\rceil = n + 1\)개 있다. 그 항들 \(a_{i_1}, \dots, a_{i_{n+1}}\) (\(i_1 < \dots\))에서 \(a_{i_s} < a_{i_{s+1}}\)이면 \(a_{i_s}\) 앞에 붙여 \(L_{i_s} > L_{i_{s+1}}\)이 되어 모순이므로 \(a_{i_s} > a_{i_{s+1}}\). 곧 길이 \(n + 1\)인 감소 부분수열이다. ∎

예: \(n = 2\)이면 아무 수 5개(서로 다름)에서 길이 3인 단조 부분수열이 있습니다. 4개로는 부족합니다(2, 1, 4, 3). 같은 절의 예제 카드에서 더 연습합니다.

흔한 실수(1) 비둘기와 집의 수를 비교하지 않고 원리를 쓴다: 비둘기가 집보다 많아야 한다. (2) 원리로 "모든 상자에 2개 이상"을 결론짓는다: 적어도 한 상자만 보장된다.
요약
  1. \(N\)개를 \(k\)상자에 넣으면 어떤 상자에 \(\lceil N/k\rceil\)개 이상.
  2. 비둘기·집 선택이 핵심: 나머지, 홀수 부분, 부분수열 길이 등.
  3. 에르되시-세케레시: \(n^2 + 1\)개의 수열에 길이 \(n + 1\)인 단조 부분수열.

3.2.4연습문제

기본

  1. 367명 중 생일이 같은 두 사람이 있음을 보여라. 1000명이면 생일이 같은 사람이 적어도 몇 명?
    답

    날짜 366가지. \(\lceil 1000/366\rceil = 3\).

응용

  1. 한 변이 2인 정삼각형 안에 점 5개를 찍으면 거리가 1 이하인 두 점이 있음을 보여라.
    답

    변의 중점을 이어 한 변 1인 정삼각형 4개로 나누면 한 조각에 두 점, 거리 ≤ 1.

심화

  1. 파티에 \(n\)명(\(n \ge 2\))이 있으면 아는 사람 수가 같은 두 사람이 있음을 보여라.
    답

    가능한 수 \(0, \dots, n - 1\)이지만 0과 \(n - 1\)이 동시에 나올 수 없어 \(n - 1\)가지. 사람 \(n\)명이라 같은 값이 있다.
