세 팀 모두 일을 맡게 나누는 방법

예제 · 전사함수를 포함배제로 세기

먼저 예측

서로 다른 일 5개를 세 팀에 나눌 때(한 팀이 여러 개 가능), 일을 하나도 못 맡는 팀이 없는 방법은 전체 243가지 중 몇 가지일까요?

예측 확인

150가지입니다.

서로 다른 일 5개를 팀 A, B, C에 배정하되 모든 팀이 적어도 하나를 맡는 방법의 수를 구하여라.

전략

"팀 X가 하나도 못 맡음"인 사건 \(N_A, N_B, N_C\)의 합집합을 포함배제로 세어 전체에서 뺍니다(3.5절).

풀이

  1. 전체 \(3^5 = 243\).
    일마다 세 팀 중 하나.
  2. \(|N_A| = 2^5 = 32\) (나머지 두 팀에만), 셋 합 96. \(|N_A\cap N_B| = 1^5 = 1\), 셋 합 3. \(|N_A\cap N_B\cap N_C| = 0\).
    빠진 팀을 뺀 배정.
  3. \(|N_A\cup N_B\cup N_C| = 96 - 3 + 0 = 93\). 답 \(243 - 93 = 150\).
    여사건.

검산

팀별 일의 개수가 \((3, 1, 1)\) 꼴: 어느 팀이 3개인지 3가지 × \(\frac{5!}{3!1!1!} = 20\) → 60. \((2, 2, 1)\) 꼴: 1개 팀 3가지 × \(\frac{5!}{2!2!1!} = 30\) → 90. 합 150으로 같습니다.

의미

직접 세면 경우를 나누어야 하지만 포함배제는 기계적으로 끝납니다. 이 수를 \(3!\)로 나누면 일 5개를 이름 없는 세 묶음으로 나누는 방법(제2종 스털링 수 \(S(5, 3) = 25\))입니다.

이해 확인

일 4개를 두 팀에 빈 팀 없이 나누는 방법은?

답

\(2^4 - 2 = 14\).
