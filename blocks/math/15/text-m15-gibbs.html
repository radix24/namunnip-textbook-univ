깁스 현상

본문

사각파의 푸리에 부분합을 그리면 점프 바로 옆에 1보다 높은 봉우리가 솟는다. 항을 더 많이 넣으면 이 봉우리가 사라질까? 사라지지 않는다면, 각 점에서 부분합이 1로 수렴한다는 사실과는 어떻게 함께 성립할까?

먼저 알아야 할 것점별수렴 정리(2.2절), 페예르 핵(1.3절), 정적분과 리만 합을 쓴다.

2.3.1사각파의 부분합

\(0 < \theta < \pi\)에서 1이고 \(-\pi < \theta < 0\)에서 \(-1\)인 홀함수 \(f\)의 푸리에 급수는 다음과 같다.

\[f(\theta) \sim \frac4\pi\left(\sin\theta + \frac{\sin3\theta}3 + \frac{\sin5\theta}5 + \cdots\right)\]

\(N\)이 홀수일 때 마지막 항이 \(\frac{\sin N\theta}N\)인 부분합을 \(S_N\)이라 하자. 2.2절에 따라 \(0 < \theta < \pi\)의 각 점에서 \(S_N(\theta) \to 1\)이다. 그런데 그림 1처럼 0 바로 오른쪽에 1보다 높은 봉우리가 있고, \(N\)을 키우면 봉우리가 0 쪽으로 좁아질 뿐 높이는 거의 그대로이다.

2.3.2봉우리의 높이

미분하면 \(S_N'(\theta) = \frac4\pi\sum_{k = 1, 3, \dots, N}\cos k\theta = \frac{2}{\pi}\cdot\frac{\sin(N + 1)\theta}{\sin\theta}\)이므로, 0 오른쪽의 첫 극대점은 \(\theta_N = \frac\pi{N + 1}\)이다.

정리 2.3.1 (깁스 현상)

\(\displaystyle\lim_{N\to\infty}S_N\!\left(\frac\pi{N + 1}\right) = \frac2\pi\int_0^\pi\frac{\sin t}t\,dt \approx 1.17898\)이다.

증명.\(M = N + 1\), \(t_k = \frac{k\pi}M\)이라 하면 \(k = 1, 3, \dots, N\)에 대해 \(S_N(\theta_N) = \frac4\pi\sum_k\frac{\sin t_k}{k} = \frac2\pi\sum_k\frac{\sin t_k}{t_k}\cdot\frac{2\pi}M\)이다. 이 \(t_k\)들은 \([0, \pi]\)를 폭 \(\frac{2\pi}M\)으로 나눈 칸의 가운데 점이다. 그러므로 이 합은 \(\frac{\sin t}t\)의 리만 합이고, \(\frac2\pi\int_0^\pi\frac{\sin t}tdt\)로 수렴한다. ∎

점프의 크기가 2이므로 넘치는 양 0.179는 점프의 약 9%이다. 일반적으로 크기 \(d\)인 점프가 있는 구간별 매끄러운 함수에서는 부분합이 점프 근처에서 약 \(0.0895d\)만큼 넘친다.

2.3.3모순이 아닌 이유

고정된 점 \(\theta > 0\)에서는 \(N\)이 충분히 크면 봉우리의 위치 \(\frac\pi{N + 1}\)이 \(\theta\)보다 왼쪽으로 지나가므로 \(S_N(\theta) \to 1\)이다. 봉우리는 줄지 않고 움직일 뿐이며, 이것은 수렴이 균등하지 않다는 뜻이다. 연속함수의 균등극한은 연속이므로, 연속인 \(S_N\)이 불연속인 \(f\)로 균등수렴할 수 없다는 것과 같은 이야기이다.

한편 체사로 평균 \(\sigma_Nf = f * F_N\)은 페예르 핵이 \(F_N \ge 0\)이고 \(\frac1{2\pi}\int F_N = 1\)이라 \(f\)의 가중평균이다. 따라서 늘 \(-1 \le \sigma_Nf \le 1\)이고 넘치지 않는다. 디리클레 핵은 음수 값을 가지므로 이런 평균의 성질이 깨진다.

흔한 오해항을 많이 넣으면 넘침이 사라진다고 여기기 쉽지만, 봉우리의 폭만 줄고 높이는 1.179로 간다. 또 깁스 현상이 점별수렴의 반례라고 생각하는 것도 틀렸다. 각 점에서는 수렴하며 실패하는 것은 균등수렴이다. 수치 오차 때문에 생긴다고 여기는 경우도 있으나, 정확한 계산에서도 똑같이 나타난다.
마무리

처음 질문에 답하면, 항을 더 넣어도 봉우리는 사라지지 않는다. 첫 극대점 \(\frac\pi{N + 1}\)에서의 높이는 \(\frac2\pi\int_0^\pi\frac{\sin t}t\,dt \approx 1.179\)로 수렴하여 점프의 약 9%만큼 넘친다. 그래도 봉우리가 점프 쪽으로 움직이므로 각 점에서는 1로 수렴하며, 실패하는 것은 균등수렴뿐이다. 음이 아닌 페예르 핵을 쓰는 체사로 평균에는 넘침이 없다.

2.3.4연습문제

기본

  1. 0에서 값이 0에서 3으로 뛰는 구간별 매끄러운 함수의 부분합은 점프 근처에서 대략 얼마까지 올라가는가?
    답

    \(3 + 0.0895\times3 \approx 3.27\).

응용

  1. \(\sum_{k = 1, 3, \dots, N}\cos k\theta =\frac{\sin(N + 1)\theta}{2\sin\theta}\)을 보여라.
    답

    양변에 \(2\sin\theta\)를 곱하면 \(2\sin\theta\cos k\theta = \sin(k + 1)\theta - \sin(k - 1)\theta\)가 \(k = 1, 3, \dots, N\)에서 망원급수로 \(\sin(N + 1)\theta - \sin0\theta\)이 된다.

심화

  1. 톱니파 \(\theta\) (\(-\pi < \theta < \pi\))의 부분합이 \(\pi\) 근처에서 넘치는 높이의 극한을 구하여라.
    답

    점프가 \(2\pi\)이므로 같은 비율로 \(\pi\)를 약 \(0.0895\times2\pi \approx 0.562\) 넘는다. 극한값은 \(2\int_0^\pi\frac{\sin t}tdt \approx 3.704\).
