깁스 현상

본문
이 절에서 배울 것
  • 사각파의 푸리에 부분합이 점프 옆에서 약 9% 넘쳐 오르고, 항을 늘려도 그 높이가 줄지 않음을 계산한다.
  • 넘침의 극한값 \(\frac2\pi\int_0^\pi\frac{\sin t}t\,dt \approx 1.179\)를 리만 합으로 유도한다.
  • 이것이 점별수렴과 모순되지 않는 이유, 체사로 평균이 넘침을 없애는 이유를 설명한다.
먼저 알아야 할 것
  • 점별수렴 정리 (2.2절), 페예르 핵 (1.3절), 정적분과 리만 합(고등학교 수학).

2.3.1사각파의 부분합

\(f(\theta) = 1\) (\(0 < \theta < \pi\)), \(f(\theta) = -1\) (\(-\pi < \theta < 0\))인 홀함수의 푸리에 급수는

\[f(\theta) \sim \frac4\pi\left(\sin\theta + \frac{\sin3\theta}3 + \frac{\sin5\theta}5 + \cdots\right)\]

입니다. 마지막 항이 \(\frac{\sin N\theta}N\) (\(N\) 홀수)인 부분합을 \(S_N\)이라 합시다. 2.2절에 의해 \(0 < \theta < \pi\)의 각 점에서 \(S_N(\theta) \to 1\)입니다. 그런데 그래프를 그려 보면 0 바로 오른쪽에 1보다 높은 봉우리가 있고, \(N\)을 키우면 봉우리가 0 쪽으로 좁아질 뿐 높이는 거의 그대로입니다.

2.3.2봉우리의 높이

미분하면 \(S_N'(\theta) = \frac4\pi\sum_{k = 1, 3, \dots, N}\cos k\theta = \frac{2}{\pi}\cdot\frac{\sin(N + 1)\theta}{\sin\theta}\)이므로, 0 오른쪽의 첫 극대점은 \(\theta_N = \frac\pi{N + 1}\)입니다.

정리 2.3.1 (깁스 현상)

\(\displaystyle\lim_{N\to\infty}S_N\!\left(\frac\pi{N + 1}\right) = \frac2\pi\int_0^\pi\frac{\sin t}t\,dt \approx 1.17898\).

증명.\(M = N + 1\), \(t_k = \frac{k\pi}M\)이라 하면 \(k = 1, 3, \dots, N\)에 대해 \(S_N(\theta_N) = \frac4\pi\sum_k\frac{\sin t_k}{k} = \frac2\pi\sum_k\frac{\sin t_k}{t_k}\cdot\frac{2\pi}M\). 이 \(k\)들에 대한 \(t_k\)는 \([0, \pi]\)를 폭 \(\frac{2\pi}M\)으로 나눈 칸의 가운데 점이므로, 이것은 \(\frac{\sin t}t\)의 리만 합이고 \(\frac2\pi\int_0^\pi\frac{\sin t}tdt\)로 수렴한다. ∎

점프의 크기가 2이므로 넘치는 양 0.179는 점프의 약 9%입니다. 일반적으로 점프 \(d\)가 있는 구간별 매끄러운 함수에서는 부분합이 점프 근처에서 약 \(0.0895d\)만큼 넘칩니다.

2.3.3모순이 아닌 이유

각 고정된 점 \(\theta > 0\)에서는 \(N\)이 충분히 크면 봉우리 \(\frac\pi{N + 1}\)가 \(\theta\)보다 왼쪽으로 지나가므로 \(S_N(\theta) \to 1\)입니다. 봉우리는 줄지 않고 움직일 뿐이라, 수렴이 균등하지 않은 것입니다. 연속함수의 균등극한은 연속이므로, 불연속인 \(f\)로 연속인 \(S_N\)이 균등수렴할 수 없는 것과 같은 이야기입니다.

체사로 평균 \(\sigma_N f = f * F_N\)은 페예르 핵 \(F_N \ge 0\)과 \(\frac1{2\pi}\int F_N = 1\) 덕분에 늘 \(-1 \le \sigma_Nf \le 1\)이라 넘치지 않습니다. 디리클레 핵은 음수 값을 가져서 이 평균 성질이 깨집니다.

흔한 오해(1) 항을 많이 넣으면 넘침이 사라진다고 여긴다: 폭만 줄고 높이는 1.179로 간다. (2) 깁스 현상이 점별수렴에 반례라고 여긴다: 각 점에서는 수렴한다. 실패하는 것은 균등수렴이다. (3) 수치 오차 때문이라 여긴다: 정확한 계산에서도 나타난다.
요약
  1. 사각파 부분합의 첫 극대점 \(\frac\pi{N + 1}\), 높이는 \(\frac2\pi\int_0^\pi\frac{\sin t}t\,dt \approx 1.179\)로 수렴.
  2. 넘침은 점프의 약 9%, 점별수렴은 하지만 균등수렴은 아니다.
  3. 음이 아닌 페예르 핵을 쓰는 체사로 평균에는 넘침이 없다.

2.3.4연습문제

기본

  1. 0에서 값이 0에서 3으로 뛰는 구간별 매끄러운 함수의 부분합은 점프 근처에서 대략 얼마까지 올라가는가?
    답

    \(3 + 0.0895\times3 \approx 3.27\).

응용

  1. \(\sum_{k = 1, 3, \dots, N}\cos k\theta =\frac{\sin(N + 1)\theta}{2\sin\theta}\)을 보여라.
    답

    양변에 \(2\sin\theta\)를 곱하면 \(2\sin\theta\cos k\theta = \sin(k + 1)\theta - \sin(k - 1)\theta\)가 \(k = 1, 3, \dots, N\)에서 망원급수로 \(\sin(N + 1)\theta - \sin0\theta\)이 된다.

심화

  1. 톱니파 \(\theta\) (\(-\pi < \theta < \pi\))의 부분합이 \(\pi\) 근처에서 넘치는 높이의 극한을 구하여라.
    답

    점프가 \(2\pi\)이므로 같은 비율로 \(\pi\)를 약 \(0.0895\times2\pi \approx 0.562\) 넘는다. 극한값은 \(2\int_0^\pi\frac{\sin t}tdt \approx 3.704\).
