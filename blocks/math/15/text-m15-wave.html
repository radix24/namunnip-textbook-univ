파동방정식과 달랑베르 공식

본문

끝없이 긴 줄의 가운데를 망치로 치면 줄은 어떻게 움직일까? 열방정식처럼 변환으로 풀 수 있을까? 그리고 열은 곧바로 모든 곳에 닿았는데, 줄의 흔들림도 그럴까?

먼저 알아야 할 것실수선 위의 열방정식(5.1절), 역변환 공식(4.2절)을 쓰고, \(y'' = -\omega^2y\)의 해가 \(A\cos\omega t + B\sin\omega t\)라는 것을 쓴다.

5.2.1문제

팽팽한 줄의 변위 \(u(x, t)\)는 단위를 맞추어 파동의 속력을 1로 하면 다음 파동방정식을 따른다.

\[u_{tt} = u_{xx}, \qquad u(x, 0) = f(x), \quad u_t(x, 0) = g(x).\]

가속도 \(u_{tt}\)에 관한 방정식이므로 처음 모양 \(f\)와 처음 속도 \(g\)를 모두 주어야 한다.

5.2.2변환으로 풀기

\(x\)에 대해 변환하면 진동수 \(\xi\)마다 \(\hat u_{tt}(\xi, t) = -4\pi^2\xi^2\hat u(\xi, t)\)이고, 이것은 각진동수 \(2\pi|\xi|\)의 단진동이다. 초기 조건 \(\hat u(\xi, 0) = \hat f(\xi)\), \(\hat u_t(\xi, 0) = \hat g(\xi)\)를 넣으면 다음을 얻는다.

\[\hat u(\xi, t) = \hat f(\xi)\cos(2\pi\xi t) + \hat g(\xi)\frac{\sin(2\pi\xi t)}{2\pi\xi}.\]

열방정식에서는 모든 진동수 성분이 줄어들기만 했지만, 여기서는 각 성분이 크기를 유지한 채 진동한다.

5.2.3달랑베르 공식

역변환하려면 두 항을 지수함수로 고친다. 먼저 \(\cos(2\pi\xi t) = \frac12\left(e^{2\pi i\xi t} + e^{-2\pi i\xi t}\right)\)이고 \(e^{2\pi i\xi t}\hat f(\xi)\)는 \(f(x + t)\)의 변환이므로, 첫 항은 \(\frac12(f(x + t) + f(x - t))\)로 돌아간다. 다음으로 \(\frac{\sin(2\pi\xi t)}{2\pi\xi} = \frac12\int_{-t}^te^{2\pi i\xi s}\,ds\)이므로, 둘째 항은 \(\frac12\int_{-t}^tg(x + s)\,ds = \frac12\int_{x-t}^{x+t}g(y)\,dy\)로 돌아간다.

정리 5.2.1 (달랑베르)

\(f, g \in \mathcal S\)이면 파동방정식의 해는 \(\displaystyle u(x, t) = \frac{f(x + t) + f(x - t)}2 + \frac12\int_{x-t}^{x+t}g(y)\,dy\)이다.

직접 미분해서 확인할 수도 있다. \(f(x - t)\)는 모양 \(f\)가 오른쪽으로 속력 1로 움직이는 것이고, \(f(x + t)\)는 왼쪽으로 움직이는 것이다. 그러므로 처음 모양은 높이가 반인 두 사본으로 나뉘어 양쪽으로 떠나간다.

5.2.4유한한 전파 속도

공식에서 \(u(x, t)\)는 \(f\)와 \(g\)의 \([x - t, x + t]\) 안의 값에만 의존하며, 이 구간을 의존 영역이라 한다. 따라서 \(f, g\)가 \([-1, 1]\) 밖에서 0이면 시각 \(t\)에서 \(u\)는 \([-1 - t, 1 + t]\) 밖에서 0이다. 멀리 있는 사람에게 소리가 늦게 도착하는 것과 같으며, 5.1절의 열이 \(t > 0\)이면 곧바로 모든 곳에 닿은 것과 대조된다.

예제 5.2.2

\(f = 0\)이고 \(g\)가 \([-1, 1]\)에서 1, 밖에서 0일 때 \(x = 0\)과 \(x = 3\)에서의 변위를 구하여라.

풀이. 망치로 가운데를 친 줄이다. \(g\)는 슈바르츠 함수가 아니지만 공식을 그대로 쓸 수 있다. \(x = 0\)에서는 \(u(0, t) = \frac12\int_{-t}^tg = \min(t, 1)\)이므로, 줄은 \(t = 1\)까지 오른 뒤 높이 1에 머문다. \(x = 3\)에서는 \(t < 2\)이면 \(u = 0\)이고, \(t\)가 2에서 4로 가는 동안 0에서 1로 오른다. 그림 1이 이 상황이다.

같은 절의 탐구 카드에서 파동과 열이 퍼지는 모습을 나란히 비교한다.

흔한 오해처음 모양만 주면 해가 정해진다고 여기기 쉽지만, 2계 방정식이므로 처음 속도 \(g\)도 필요하다. 또 처음 모양이 그대로 한 방향으로 움직인다고 생각하는 것도 틀렸다. 처음 속도가 0이면 처음 모양은 높이가 반인 두 사본으로 갈라져 반대 방향으로 나아간다.
마무리

처음 질문에 답하면, 파동방정식도 변환으로 풀 수 있으며 진동수마다 단진동이 되어 달랑베르 공식 \(u = \frac{f(x + t) + f(x - t)}2 + \frac12\int_{x-t}^{x+t}g\)를 얻는다. 망치로 친 줄은 가운데가 솟은 뒤 평평한 부분이 속력 1로 양쪽으로 넓어진다. 해가 \([x - t, x + t]\) 안의 처음 값에만 의존하므로, 열과 달리 줄의 흔들림은 유한한 속력으로 퍼진다.

5.2.5연습문제

기본

  1. \(f(x) = e^{-x^2}\), \(g = 0\)일 때 \(u(0, t)\)를 구하여라.
    답

    \(u(0, t) = \frac{e^{-t^2} + e^{-t^2}}2 = e^{-t^2}\).

응용

  1. \(u(x, t) = F(x + t) + G(x - t)\)가 \(F, G\)가 두 번 미분 가능하면 언제나 파동방정식을 만족함을 보여라.
    답

    연쇄법칙으로 \(u_{tt} = F'' + G''\), \(u_{xx} = F'' + G''\).

심화

  1. 에너지 \(E(t) = \int(u_t^2 + u_x^2)\,dx\)가 보존됨을 플랑셰렐 정리와 변환된 해로 보여라.
    답

    \(\int u_t^2 + u_x^2 = \int\left(|\hat u_t|^2 + 4\pi^2\xi^2|\hat u|^2\right)d\xi\)이고, 각 \(\xi\)에서 단진동의 에너지 \(|\hat u_t|^2 + \omega^2|\hat u|^2\) (\(\omega = 2\pi\xi\))는 \(t\)에 관계없이 \(|\hat g|^2 + \omega^2|\hat f|^2\)이다.
