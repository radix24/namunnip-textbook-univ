파동방정식과 달랑베르 공식

본문
이 절에서 배울 것
  • 무한히 긴 줄의 파동방정식 \(u_{tt} = u_{xx}\)를 푸리에 변환으로 푼다.
  • 해를 다시 써서 달랑베르 공식 \(u = \frac{f(x + t) + f(x - t)}2 + \frac12\int_{x-t}^{x+t}g\)를 얻는다.
  • 파동은 유한한 속도로 퍼진다는 점을 열방정식과 비교한다.
먼저 알아야 할 것
  • 실수선 위의 열방정식 (5.1절), 역변환 공식 (4.2절), \(y'' = -\omega^2y\)의 해가 \(A\cos\omega t + B\sin\omega t\)임.

5.2.1문제

팽팽한 줄의 변위 \(u(x, t)\)는 (단위를 맞추면 파동의 속력이 1인) 파동방정식을 따릅니다.

\[u_{tt} = u_{xx}, \qquad u(x, 0) = f(x), \quad u_t(x, 0) = g(x).\]

처음 모양 \(f\)와 처음 속도 \(g\)를 둘 다 주어야 하는 것은 가속도(\(u_{tt}\))에 관한 방정식이기 때문입니다.

5.2.2변환으로 풀기

\(x\)에 대해 변환하면 \(\xi\)마다

\[\hat u_{tt}(\xi, t) = -4\pi^2\xi^2\hat u(\xi, t)\]

이고, 이는 각진동수 \(2\pi|\xi|\)의 단진동입니다. 초기 조건 \(\hat u(\xi, 0) = \hat f(\xi)\), \(\hat u_t(\xi, 0) = \hat g(\xi)\)를 넣으면

\[\hat u(\xi, t) = \hat f(\xi)\cos(2\pi\xi t) + \hat g(\xi)\frac{\sin(2\pi\xi t)}{2\pi\xi}.\]

열방정식에서는 모든 진동수가 줄어들기만 했지만, 여기서는 진동수마다 크기를 유지한 채 진동합니다.

5.2.3달랑베르 공식

역변환하려면 두 항을 지수함수로 고칩니다.

  • \(\cos(2\pi\xi t) = \frac12\left(e^{2\pi i\xi t} + e^{-2\pi i\xi t}\right)\)이고 \(e^{2\pi i\xi t}\hat f(\xi)\)는 \(f(x + t)\)의 변환이므로, 첫 항은 \(\frac12(f(x + t) + f(x - t))\)로 돌아갑니다.
  • \(\frac{\sin(2\pi\xi t)}{2\pi\xi} = \frac12\int_{-t}^te^{2\pi i\xi s}\,ds\)이므로 둘째 항은 \(\frac12\int_{-t}^tg(x + s)\,ds = \frac12\int_{x-t}^{x+t}g(y)\,dy\)로 돌아갑니다.
정리 5.2.1 (달랑베르) \(f, g \in \mathcal S\)이면 파동방정식의 해는 \[u(x, t) = \frac{f(x + t) + f(x - t)}2 + \frac12\int_{x-t}^{x+t}g(y)\,dy\] 이다.

직접 미분해서 확인할 수도 있습니다. \(f(x - t)\)는 모양 \(f\)가 오른쪽으로 속력 1로 움직이는 것이고, \(f(x + t)\)는 왼쪽으로 움직이는 것입니다. 처음 모양은 반씩 나뉘어 양쪽으로 떠나갑니다.

5.2.4유한 전파 속도

공식에서 \(u(x, t)\)는 \(f, g\)의 \([x - t, x + t]\) 안의 값에만 의존합니다(의존 영역). 따라서 \(f, g\)가 \([-1, 1]\) 밖에서 0이면, 시각 \(t\)에서 \(u\)는 \([-1 - t, 1 + t]\) 밖에서 0입니다. 소리가 늦게 도착하는 것과 같습니다. 5.1절의 열이 \(t > 0\)이면 즉시 모든 곳에 닿은 것과 대조됩니다.

예 5.2.2 \(f = 0\), \(g\)가 \([-1, 1]\)에서 1이고 밖에서 0인 경우(망치로 가운데를 친 줄, 슈바르츠 함수는 아니지만 공식은 그대로 씀). \(x = 0\)에서 \(u(0, t) = \frac12\int_{-t}^tg = \min(t, 1)\)이고, 줄은 \(t = 1\) 이후 높이 1로 머뭅니다. \(x = 3\)에서는 \(t < 2\)이면 \(u = 0\)이고 \(t\)가 2에서 4로 가는 동안 0에서 1로 오릅니다.

같은 절의 탐구 카드에서 파동과 열의 퍼짐을 나란히 봅니다.

흔한 오해(1) 처음 모양만 주면 된다고 여긴다. 처음 속도 \(g\)도 필요하다. (2) 처음 모양이 그대로 한 방향으로 간다고 여긴다. 처음 속도가 0이면 높이가 반인 두 사본으로 갈라져 반대 방향으로 간다.
요약
  1. 변환하면 진동수마다 단진동: \(\hat u = \hat f\cos2\pi\xi t + \hat g\frac{\sin2\pi\xi t}{2\pi\xi}\).
  2. 역변환이 달랑베르 공식: 왼쪽·오른쪽으로 가는 두 파동 + 처음 속도의 적분.
  3. 의존 영역 \([x - t, x + t]\): 유한 전파 속도.

5.2.5연습문제

기본

  1. \(f(x) = e^{-x^2}\), \(g = 0\)일 때 \(u(0, t)\)를 구하여라.
    답

    \(u(0, t) = \frac{e^{-t^2} + e^{-t^2}}2 = e^{-t^2}\).

응용

  1. \(u(x, t) = F(x + t) + G(x - t)\)가 \(F, G\)가 두 번 미분 가능하면 언제나 파동방정식을 만족함을 보여라.
    답

    연쇄법칙으로 \(u_{tt} = F'' + G''\), \(u_{xx} = F'' + G''\).

심화

  1. 에너지 \(E(t) = \int(u_t^2 + u_x^2)\,dx\)가 보존됨을 플랑셰렐 정리와 변환된 해로 보여라.
    답

    \(\int u_t^2 + u_x^2 = \int\left(|\hat u_t|^2 + 4\pi^2\xi^2|\hat u|^2\right)d\xi\)이고, 각 \(\xi\)에서 단진동의 에너지 \(|\hat u_t|^2 + \omega^2|\hat u|^2\) (\(\omega = 2\pi\xi\))는 \(t\)에 관계없이 \(|\hat g|^2 + \omega^2|\hat f|^2\)이다.
