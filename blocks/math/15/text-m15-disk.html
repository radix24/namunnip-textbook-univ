원판 위의 디리클레 문제

본문
이 절에서 배울 것
  • 원판 위의 라플라스 방정식에서 경계값이 주어질 때 해를 푸리에 급수로 구한다.
  • 해가 경계값과 푸아송 핵의 합성곱 \(u = f * P_r\)임을 보인다.
  • 원의 중심에서의 값이 경계값의 평균임(평균값 성질)을 확인한다.
먼저 알아야 할 것
  • 좋은 핵과 합성곱 (1.3절), 원 위의 열방정식 (3.3절), 극좌표.

3.4.1문제

얇은 원판의 테두리 온도를 \(f(\theta)\)로 유지하면 오랜 시간 뒤 원판 안의 온도 \(u\)는 더 이상 변하지 않습니다. 열방정식에서 \(u_t = 0\)이 된 상태이므로

\[u_{xx} + u_{yy} = 0\quad(x^2 + y^2 < 1),\qquad u(\cos\theta, \sin\theta) = f(\theta)\]

를 풉니다(둘째 식이 경계 조건). 이를 디리클레 문제라 하고, 라플라스 방정식의 해를 조화함수라 합니다. 극좌표로는 \(u_{rr} + \frac1ru_r + \frac1{r^2}u_{\theta\theta} = 0\)입니다.

3.4.2푸리에 급수로 풀기

각 \(r\)에서 \(u(r, \theta) = \sum_na_n(r)e^{in\theta}\)로 쓰고 방정식에 넣으면 \(a_n'' + \frac1ra_n' - \frac{n^2}{r^2}a_n = 0\)입니다. \(a_n = r^k\)를 넣으면 \(k = \pm n\)이고, 원점에서 유계인 해는 \(r^{|n|}\)뿐입니다. 경계 \(r = 1\)에서 \(a_n(1) = \hat f(n)\)이어야 하므로

\[u(r, \theta) = \sum_{n=-\infty}^\infty\hat f(n)\,r^{|n|}e^{in\theta}.\]

\(r < 1\)이면 \(r^{|n|}\)이 기하급수적으로 줄어서 이 급수는 아무리 거친 \(f\)에서도 잘 수렴하고 얼마든지 미분할 수 있습니다.

정리 3.4.1

\(f\)가 원 위에서 적분 가능하면 \(u(r, \theta) = (f * P_r)(\theta)\), 여기서 푸아송 핵은 \(P_r(\theta) = \sum_nr^{|n|}e^{in\theta} = \dfrac{1 - r^2}{1 - 2r\cos\theta + r^2}\). \(u\)는 원판 안에서 조화함수이고, \(f\)가 연속이면 \(r \to 1^-\)일 때 \(u(r, \theta) \to f(\theta)\)이다(균등하게).

증명.\(\hat f(n)\)의 정의를 넣고 합과 적분을 바꾸면(\(r < 1\)이라 균등수렴) \(u = f * P_r\). 닫힌 꼴은 두 기하급수 \(\sum_{n\ge0}(re^{i\theta})^n + \sum_{n\ge1}(re^{-i\theta})^n\)을 더해 얻는다. \(P_r \ge 0\), \(\frac1{2\pi}\int P_r = 1\), \(\delta \le |\theta| \le \pi\)에서 \(P_r \le \frac{1 - r^2}{1 - 2r\cos\delta + r^2} \to 0\)이므로 \(r \to 1^-\)에서 좋은 핵이고, 1.3절의 정리로 경계값에 수렴한다. ∎

3.4.3평균값 성질

\(r = 0\)을 넣으면 \(u(0) = \hat f(0) = \frac1{2\pi}\int_{-\pi}^\pi f(\theta)\,d\theta\): 원 중심의 온도는 테두리 온도의 평균입니다. 그 결과 조화함수는 원판 안에서 최댓값을 가질 수 없고 경계에서만 최대가 됩니다(최대 원리).

흔한 오해(1) \(r^{-|n|}\) 해를 함께 넣는다: 원점에서 발산하므로 원판 문제에서는 버린다(고리 모양 영역이면 필요하다). (2) 경계값이 불연속이면 해가 없다고 여긴다: 안쪽에서는 매끄러운 해가 있고 연속점에서만 경계값에 수렴한다. (3) 열방정식과 같은 해라 여긴다: 열방정식의 \(e^{-n^2t}\) 대신 \(r^{|n|}\)이 붙는다.
요약
  1. \(u(r, \theta) = \sum\hat f(n)r^{|n|}e^{in\theta} = f * P_r\).
  2. 푸아송 핵 \(\frac{1 - r^2}{1 - 2r\cos\theta + r^2}\)는 \(r \to 1^-\)에서 좋은 핵.
  3. 중심값 = 경계 평균, 최대는 경계에서.

3.4.4연습문제

기본

  1. 경계값이 \(f(\theta) = \cos2\theta\)일 때 원판 안의 해를 \(x, y\)로 써라.
    답

    \(u = r^2\cos2\theta = x^2 - y^2\).

응용

  1. 경계값이 \(f(\theta) = \cos^2\theta\)일 때 해와 원 중심의 값을 구하여라.
    답

    \(\cos^2\theta = \frac12 + \frac12\cos2\theta\)이므로 \(u = \frac12 + \frac12(x^2 - y^2)\). 중심값 \(\frac12\)은 \(\cos^2\)의 평균과 같다.

심화

  1. \(\frac1{2\pi}\int_{-\pi}^\pi P_r(\theta)\,d\theta = 1\)을 급수 표현으로 보여라.
    답

    \(n \ne 0\)인 항 \(e^{in\theta}\)의 적분은 0이고 \(n = 0\) 항만 남아 1. 급수는 \(r < 1\)에서 균등수렴하므로 항별 적분이 된다.
