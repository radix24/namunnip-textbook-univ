푸리에 급수로 증명하는 등주 부등식

본문

길이가 정해진 끈으로 땅을 둘러쌀 때, 원 모양으로 두르면 가장 넓은 땅을 얻는다는 것은 오래전부터 알려져 왔다. 이 사실을 어떻게 증명할까? 곡선을 진동수 성분으로 나누면, 원이 아닌 곡선이 손해를 보는 이유가 보일까?

먼저 알아야 할 것파서벌 등식(2.1절)을 쓰고, 그린 정리로 넓이 구하기(수학11 5.2절)를 함께 보면 좋다.

3.1.1진술

정리 3.1.1 (등주 부등식)

길이가 \(L\)인 매끄러운 단순 닫힌 곡선이 둘러싼 영역의 넓이를 \(A\)라 하면 \(4\pi A \le L^2\)이고, 등호는 곡선이 원일 때만 성립한다.

예를 들어 둘레 4, 넓이 1인 정사각형에서는 \(4\pi A = 12.57 < 16 = L^2\)이다. 반면 둘레 4인 원은 반지름이 \(\frac2\pi\)라 넓이가 \(\frac4\pi \approx 1.273\)이고, 이때 등호가 성립한다.

3.1.2계수로 쓴 길이와 넓이

곡선을 호의 길이에 비례하는 매개변수로 잡고 \(L = 2\pi\)로 맞춘다. 크기를 바꾸면 \(A\)와 \(L^2\)이 같은 비율로 변하므로 일반성을 잃지 않는다. 곡선을 복소수 \(z(s) = x(s) + iy(s)\) (\(s \in [0, 2\pi]\))로 쓰면 \(|z'(s)| = 1\)이고, \(z(s) = \sum c_ne^{ins}\)라 하자.

먼저 길이는 \(\widehat{z'}(n) = inc_n\)과 파서벌 등식에서 \(1 = \frac1{2\pi}\int|z'|^2 = \sum n^2|c_n|^2\)으로 바뀐다. 다음으로 넓이는 그린 정리에 의해 \(A = \frac12\int(x\,dy - y\,dx) = \frac12\operatorname{Im}\int\bar zz'\,ds\)이고, 내적판 파서벌 등식으로 계산하면 \(A = \pi\sum n|c_n|^2\)이다.

3.1.3증명

증명 (후르비츠, 1901).\(L = 2\pi\)일 때 \(A \le \pi\)를 보이면 된다. 위의 두 식에서 \(\pi - A = \pi\sum_n(n^2 - n)|c_n|^2\)이다. 모든 정수 \(n\)에 대해 \(n^2 - n = n(n - 1) \ge 0\)이므로 이 값은 0 이상이다. 등호는 \(n \ne 0, 1\)인 모든 \(n\)에서 \(c_n = 0\)일 때, 곧 \(z(s) = c_0 + c_1e^{is}\)이 중심 \(c_0\), 반지름 \(|c_1|\)인 원일 때만 성립한다. ∎

증명이 짧은 까닭은 길이와 넓이가 모두 계수의 제곱합으로 바뀌고, 그 차이가 진동수마다 따로 0 이상이기 때문이다. 원은 진동수 1 하나로만 이루어진 곡선이다. 다른 진동수의 성분은 그림 1의 출렁임처럼 넓이에 비해 길이를 더 많이 늘린다.

3.1.4확인 예

타원 \(z(t) = a\cos t + ib\sin t\)는 넓이가 \(\pi ab\)이므로, 정리에 따르면 둘레가 \(L \ge 2\pi\sqrt{ab}\)여야 한다. \(a = 2\), \(b = 1\)이면 넓이는 \(2\pi \approx 6.283\), 둘레는 약 9.688이다. 그러면 \(L^2 \approx 93.86\)이고 \(4\pi A \approx 78.96\)이라 부등식이 성립한다.

흔한 오해넓이 식 \(A = \pi\sum n|c_n|^2\)에서 \(n\)이 음수인 항은 넓이를 줄인다는 점을 놓치기 쉽다. 이 항들은 시계 방향으로 도는 성분이다. 또 매개변수를 호의 길이로 잡지 않은 채 \(|z'| = 1\)을 쓰는 실수가 있는데, 이 조건은 호의 길이 매개변수에서만 성립한다.
마무리

처음 질문에 답하면, 곡선을 호의 길이로 매개화하고 푸리에 급수로 쓰면 길이는 \(\sum n^2|c_n|^2 = 1\), 넓이는 \(A = \pi\sum n|c_n|^2\)이 된다. 그 차이 \(\pi - A = \pi\sum n(n - 1)|c_n|^2\)이 진동수마다 0 이상이라 \(4\pi A \le L^2\)이 나온다. 등호는 진동수 1만 남는 원에서만 성립하며, 다른 진동수의 성분은 넓이보다 둘레를 더 늘려 손해를 본다.

3.1.5연습문제

기본

  1. 둘레가 1인 정사각형과 정삼각형의 넓이를 원의 \(\frac1{4\pi}\)과 비교하여라.
    답

    정사각형 \(\frac1{16} = 0.0625\), 정삼각형 \(\frac{\sqrt3}{36} \approx 0.0481\), 원 \(\frac1{4\pi} \approx 0.0796\). 원이 가장 넓다.

응용

  1. \(z(s) = e^{is} + \varepsilon e^{2is}\)에서 \(\sum n^2|c_n|^2\)과 \(\sum n|c_n|^2\)을 구하고, 길이를 고정했을 때 \(\varepsilon\)이 넓이를 줄임을 확인하여라.
    답

    \(\sum n^2|c_n|^2 = 1 + 4\varepsilon^2\), \(\sum n|c_n|^2 = 1 + 2\varepsilon^2\). 길이 제곱 대비 넓이의 비 \(\frac{4\pi A}{L^2} = \frac{1 + 2\varepsilon^2}{1 + 4\varepsilon^2} < 1\) (\(\varepsilon \ne 0\)).

심화

  1. 비르팅거 부등식: \(f\)가 \(2\pi\)-주기 \(C^1\)이고 \(\int_0^{2\pi}f = 0\)이면 \(\int f^2 \le \int f'^2\)임을 보이고 등호 조건을 구하여라.
    답

    \(\hat f(0) = 0\)이라 파서벌로 \(\int f^2 = 2\pi\sum_{n\ne0}|\hat f(n)|^2 \le 2\pi\sum n^2|\hat f(n)|^2 = \int f'^2\). 등호는 \(|n| = 1\) 성분만 있을 때, 곧 \(f = a\cos\theta + b\sin\theta\).
