푸리에 급수로 증명하는 등주 부등식

본문
이 절에서 배울 것
  • 둘레가 \(L\)인 닫힌 곡선이 둘러싼 넓이 \(A\)는 \(A \le \frac{L^2}{4\pi}\)이고, 등호는 원뿐임을 진술한다.
  • 곡선을 복소 푸리에 급수로 쓰고 파서벌 등식으로 길이와 넓이를 계수로 나타낸다.
  • 후르비츠의 증명을 따라가고 등호 조건을 읽는다.
먼저 알아야 할 것
  • 파서벌 등식 (2.1절), 그린 정리로 넓이 구하기 (수학11 5.2절, 함께 보면 좋음).

3.1.1진술

정리 3.1.1 (등주 부등식)

길이가 \(L\)인 매끄러운 단순 닫힌 곡선이 둘러싼 영역의 넓이를 \(A\)라 하면 \(4\pi A \le L^2\)이고, 등호는 곡선이 원일 때만 성립한다.

둘레가 같으면 원이 가장 넓은 땅을 둘러싼다는, 고대부터 알려진 사실입니다. 정사각형(둘레 4, 넓이 1)은 \(4\pi = 12.57 < 16\), 원(둘레 4, 반지름 \(\frac2\pi\))은 넓이 \(\frac4\pi \approx 1.273\)으로 등호입니다.

3.1.2계수로 쓴 길이와 넓이

곡선을 호의 길이에 비례하는 매개변수로 잡아 \(L = 2\pi\)로 정규화합니다(크기를 바꾸면 \(A\)는 제곱, \(L\)도 제곱으로 변하므로 일반성을 잃지 않음). 곡선을 복소수 \(z(s) = x(s) + iy(s)\), \(s \in [0, 2\pi]\), \(|z'(s)| = 1\)로 쓰고 \(z(s) = \sum c_ne^{ins}\)라 하면

  • 길이: \(1 = \frac1{2\pi}\int|z'|^2 = \sum n^2|c_n|^2\) (파서벌, \(\widehat{z'}(n) = inc_n\)).
  • 넓이: 그린 정리로 \(A = \frac12\int(x\,dy - y\,dx) = \frac12\operatorname{Im}\int\bar zz'\,ds = \pi\sum n|c_n|^2\) (분극 등식).

3.1.3증명

증명 (후르비츠, 1901).\(L = 2\pi\)이면 보일 것은 \(A \le \pi\)이다. 위 두 식으로

\[\pi - A = \pi\sum_n(n^2 - n)|c_n|^2 \ge 0,\]

왜냐하면 모든 정수 \(n\)에 대해 \(n^2 - n = n(n - 1) \ge 0\)이기 때문이다. 등호는 \(n(n - 1) \ne 0\)인 모든 \(n\), 곧 \(n \ne 0, 1\)에서 \(c_n = 0\)일 때, 즉 \(z(s) = c_0 + c_1e^{is}\) (중심 \(c_0\), 반지름 \(|c_1|\)인 원)일 때만 성립한다. ∎

증명의 핵심은 길이와 넓이가 모두 계수의 제곱합으로 바뀌고, 그 차이가 각 진동수 \(n\)마다 따로 음이 아니라는 것입니다. 원은 진동수 1 하나로만 이루어진 곡선이고, 다른 진동수의 성분(울퉁불퉁함)은 넓이에 비해 길이를 더 많이 늘립니다.

3.1.4확인 예

타원 \(z(t) = a\cos t + ib\sin t\)는 넓이 \(\pi ab\)이고 둘레가 \(L \ge 2\pi\sqrt{ab}\)여야 합니다. \(a = 2\), \(b = 1\)이면 넓이 \(2\pi \approx 6.283\), 둘레 약 9.688이고 \(L^2 = 93.86 \ge 4\pi A = 78.96\)으로 성립합니다.

흔한 오해(1) 넓이 식에서 \(n\)이 음수인 항이 넓이를 줄인다는 점을 놓친다(시계 방향 성분). (2) 매개변수를 호의 길이로 잡지 않고 \(|z'| = 1\)을 쓴다.
요약
  1. \(4\pi A \le L^2\), 등호는 원.
  2. 호의 길이 매개변수(\(L = 2\pi\))에서 \(\sum n^2|c_n|^2 = 1\), \(A = \pi\sum n|c_n|^2\).
  3. \(\pi - A = \pi\sum n(n - 1)|c_n|^2 \ge 0\). 진동수 1만 남으면 원.

3.1.5연습문제

기본

  1. 둘레가 1인 정사각형과 정삼각형의 넓이를 원의 \(\frac1{4\pi}\)과 비교하여라.
    답

    정사각형 \(\frac1{16} = 0.0625\), 정삼각형 \(\frac{\sqrt3}{36} \approx 0.0481\), 원 \(\frac1{4\pi} \approx 0.0796\). 원이 가장 넓다.

응용

  1. \(z(s) = e^{is} + \varepsilon e^{2is}\)에서 \(\sum n^2|c_n|^2\)과 \(\sum n|c_n|^2\)을 구하고, 길이를 고정했을 때 \(\varepsilon\)이 넓이를 줄임을 확인하여라.
    답

    \(\sum n^2|c_n|^2 = 1 + 4\varepsilon^2\), \(\sum n|c_n|^2 = 1 + 2\varepsilon^2\). 길이 제곱 대비 넓이의 비 \(\frac{4\pi A}{L^2} = \frac{1 + 2\varepsilon^2}{1 + 4\varepsilon^2} < 1\) (\(\varepsilon \ne 0\)).

심화

  1. 비르팅거 부등식: \(f\)가 \(2\pi\)-주기 \(C^1\)이고 \(\int_0^{2\pi}f = 0\)이면 \(\int f^2 \le \int f'^2\)임을 보이고 등호 조건을 구하여라.
    답

    \(\hat f(0) = 0\)이라 파서벌로 \(\int f^2 = 2\pi\sum_{n\ne0}|\hat f(n)|^2 \le 2\pi\sum n^2|\hat f(n)|^2 = \int f'^2\). 등호는 \(|n| = 1\) 성분만 있을 때, 곧 \(f = a\cos\theta + b\sin\theta\).
