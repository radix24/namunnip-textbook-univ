상반평면의 라플라스 방정식

본문

원판에서는 테두리 온도로부터 안쪽의 평형 온도를 푸아송 핵으로 구했다. 경계가 끝없는 직선이고 영역이 그 위쪽 반평면 전체라면 어떻게 될까? 이때 나오는 핵은 열핵과 무엇이 다를까?

먼저 알아야 할 것실수선의 열방정식 풀이(5.1절)와 원판의 디리클레 문제(3.4절)를 쓴다.

5.3.1변환으로 풀기

\(y > 0\)에서 \(u_{xx} + u_{yy} = 0\)이고 \(u(x, 0) = f(x)\)이며, \(y \to \infty\)에서 \(u\)가 유계라 하자. 각 \(y\)에서 \(x\)로 변환한 \(\hat u(\xi, y)\)를 생각하면, 5.1절처럼 \(u_{xx}\)는 \(-4\pi^2\xi^2\hat u\)로 바뀐다. 따라서 다음과 같다.

\[\frac{\partial^2\hat u}{\partial y^2} = 4\pi^2\xi^2\,\hat u,\qquad \hat u(\xi, 0) = \hat f(\xi).\]

이것은 \(y\)에 대한 2계 상미분방정식이고, 해는 \(e^{2\pi|\xi|y}\)와 \(e^{-2\pi|\xi|y}\)의 결합이다. 유계 조건으로 커지는 쪽을 버리면 \(\hat u(\xi, y) = \hat f(\xi)e^{-2\pi|\xi|y}\)이다.

5.3.2푸아송 핵

정리 5.3.1

\(\mathcal P_y(x) = \dfrac1\pi\dfrac y{x^2 + y^2}\)이면 \(\widehat{\mathcal P_y}(\xi) = e^{-2\pi|\xi|y}\)이다. 따라서 해는 \(u(x, y) = (f * \mathcal P_y)(x) = \dfrac1\pi\displaystyle\int_{-\infty}^\infty f(t)\frac{y}{(x - t)^2 + y^2}\,dt\)이다.

증명.거꾸로 \(e^{-2\pi|\xi|y}\)를 역변환한다. \(\int_{-\infty}^\infty e^{-2\pi|\xi|y}e^{2\pi ix\xi}d\xi = 2\,\mathrm{Re}\int_0^\infty e^{-2\pi\xi(y - ix)}d\xi = 2\,\mathrm{Re}\frac1{2\pi(y - ix)} = \frac1\pi\frac y{x^2 + y^2}\)이다. 4.2절에 의해 곱은 합성곱으로 바뀌므로 \(u = f * \mathcal P_y\)이다. ∎

\(\mathcal P_y \ge 0\)이고, \(\arctan\)의 양 끝값의 차가 \(\pi\)이므로 \(\int\mathcal P_y = 1\)이다. 또 \(y \to 0^+\)일 때 \(|x| \ge \delta\) 바깥의 적분이 0으로 가므로 \(\mathcal P_y\)는 좋은 핵이다. 그래서 연속이고 유계인 \(f\)에 대해 \(u(x, y) \to f(x)\)가 되어 경계 조건이 성립한다.

간단한 예로 \(f(x) = \frac1{1 + x^2}\)을 보자. 이 함수는 \(\pi\mathcal P_1\)이므로 변환이 \(\pi e^{-2\pi|\xi|}\)이고, 해의 변환은 \(\pi e^{-2\pi|\xi|(1 + y)}\)이다. 따라서 \(u(x, y) = \pi\mathcal P_{1+y}(x) = \frac{1 + y}{x^2 + (1 + y)^2}\)이다. 직접 미분하면 이것이 조화함수이고 \(y = 0\)에서 \(f\)와 같음을 확인할 수 있다. 곧 푸아송 핵끼리의 합성곱은 다시 푸아송 핵이며, \(\mathcal P_a * \mathcal P_b = \mathcal P_{a+b}\)이다.

5.3.3세 핵의 비교

열핵 \(\mathcal H_t\)는 변환이 \(e^{-4\pi^2\xi^2t}\)이고, 꼬리가 \(e^{-x^2}\)처럼 매우 빨리 준다. 반면 상반평면의 푸아송 핵 \(\mathcal P_y\)는 변환이 \(e^{-2\pi|\xi|y}\)이고, 그림 1처럼 꼬리가 \(\frac1{x^2}\)로 천천히 줄어 분산이 무한하다. 확률론에서는 이것을 코시 분포라 부른다. 한편 원판의 푸아송 핵 \(P_r\)은 계수가 \(r^{|n|}\)이었는데, \(r = e^{-2\pi y}\)로 놓으면 \(e^{-2\pi|n|y}\)가 되어 상반평면의 것과 같은 꼴이다.

흔한 오해\(e^{2\pi|\xi|y}\) 해를 함께 남기기 쉽지만, 유계 조건을 쓰지 않으면 해가 하나로 정해지지 않는다. 예를 들어 \(u = y\)도 경계값이 0인 조화함수이다. 또 \(\mathcal P_y\)의 분산을 계산하려 하는 것도 틀렸으며, \(\int x^2\mathcal P_y = \infty\)라서 정의되지 않는다. \(y\)를 열방정식의 시간처럼 여기는 실수도 있는데, \(y\)는 공간 변수이고 해는 평형 상태이다.
마무리

처음 질문에 답하면, 상반평면에서도 \(x\)로 변환하면 진동수마다 \(e^{-2\pi|\xi|y}\)가 곱해지고, 해는 푸아송 핵 \(\mathcal P_y(x) = \frac1\pi\frac y{x^2 + y^2}\)과의 합성곱이다. 이 핵은 좋은 핵이라 경계값이 맞춰진다. 열핵의 꼬리는 \(e^{-x^2}\)처럼 빨리 주는 반면 푸아송 핵의 꼬리는 \(\frac1{x^2}\)로 천천히 줄어 분산이 무한하며, 원판의 푸아송 핵과는 \(r = e^{-2\pi y}\)로 이어진다.

5.3.4연습문제

기본

  1. \(\int_{-\infty}^\infty\mathcal P_y(x)\,dx = 1\)을 보여라.
    답

    \(\frac1\pi\left[\arctan\frac xy\right]_{-\infty}^\infty = \frac1\pi\left(\frac\pi2 + \frac\pi2\right) = 1\).

응용

  1. \(\mathcal P_{y_1} * \mathcal P_{y_2} = \mathcal P_{y_1 + y_2}\)을 보여라.
    답

    변환하면 \(e^{-2\pi|\xi|y_1}e^{-2\pi|\xi|y_2} = e^{-2\pi|\xi|(y_1 + y_2)}\). 높이 \(y_1\)의 해를 경계로 다시 \(y_2\)만큼 올라가면 높이 \(y_1 + y_2\)의 해가 된다.

심화

  1. 경계값 \(f(x) = \cos x\)에 대한 유계 해를 구하여라.
    답

    \(u = e^{-y}\cos x\). \(u_{xx} + u_{yy} = -e^{-y}\cos x + e^{-y}\cos x = 0\)이고 \(y = 0\)에서 \(\cos x\).
