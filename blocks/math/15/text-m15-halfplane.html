상반평면의 라플라스 방정식

본문
이 절에서 배울 것
  • 상반평면 \(y > 0\)에서 경계값 \(u(x, 0) = f(x)\)를 갖는 라플라스 방정식을 \(x\)에 대한 푸리에 변환으로 푼다.
  • 해가 \(u = f * \mathcal P_y\), \(\mathcal P_y(x) = \frac1\pi\frac y{x^2 + y^2}\)임을 보인다.
  • 열핵, 원판의 푸아송 핵과 비교한다.
먼저 알아야 할 것
  • 실수선의 열방정식 풀이 (5.1절), 원판의 디리클레 문제 (3.4절).

5.3.1변환으로 풀기

\(u_{xx} + u_{yy} = 0\) (\(y > 0\)), \(u(x, 0) = f(x)\)이고 \(y \to \infty\)에서 \(u\)가 유계라 합시다. 각 \(y\)에서 \(x\)로 변환한 \(\hat u(\xi, y)\)는 5.1절처럼 \(u_{xx} \to -4\pi^2\xi^2\hat u\)이므로

\[\frac{\partial^2\hat u}{\partial y^2} = 4\pi^2\xi^2\,\hat u,\qquad \hat u(\xi, 0) = \hat f(\xi).\]

\(y\)에 대한 2계 상미분방정식이고 해는 \(e^{\pm2\pi|\xi|y}\)의 결합입니다. 유계 조건으로 커지는 쪽을 버리면 \(\hat u(\xi, y) = \hat f(\xi)e^{-2\pi|\xi|y}\).

5.3.2푸아송 핵

정리 5.3.1

\(\mathcal P_y(x) = \dfrac1\pi\dfrac y{x^2 + y^2}\)이면 \(\widehat{\mathcal P_y}(\xi) = e^{-2\pi|\xi|y}\)이다. 따라서 해는 \(u(x, y) = (f * \mathcal P_y)(x) = \dfrac1\pi\displaystyle\int_{-\infty}^\infty f(t)\frac{y}{(x - t)^2 + y^2}\,dt\).

증명.역방향으로 \(e^{-2\pi|\xi|y}\)를 역변환한다. \(\int_{-\infty}^\infty e^{-2\pi|\xi|y}e^{2\pi ix\xi}d\xi = 2\,\mathrm{Re}\int_0^\infty e^{-2\pi\xi(y - ix)}d\xi = 2\,\mathrm{Re}\frac1{2\pi(y - ix)} = \frac1\pi\frac y{x^2 + y^2}\). 곱이 합성곱으로 바뀌므로(4.2절) \(u = f * \mathcal P_y\). ∎

\(\mathcal P_y \ge 0\), \(\int\mathcal P_y = 1\)(\(\arctan\)의 차가 \(\pi\)), 그리고 \(y \to 0^+\)에서 \(|x| \ge \delta\) 바깥의 질량이 0으로 가므로 \(\mathcal P_y\)는 좋은 핵입니다. 그래서 연속 유계인 \(f\)에 대해 \(u(x, y) \to f(x)\)입니다.

5.3.3세 핵의 비교

  • 열핵 \(\mathcal H_t\): 변환이 \(e^{-4\pi^2\xi^2t}\). 꼬리가 \(e^{-x^2}\)처럼 매우 빨리 준다.
  • 상반평면 푸아송 핵 \(\mathcal P_y\): 변환이 \(e^{-2\pi|\xi|y}\). 꼬리가 \(\frac1{x^2}\)로 천천히 줄어 분산이 무한하다(코시 분포).
  • 원판 푸아송 핵 \(P_r\): 계수가 \(r^{|n|}\). \(r = e^{-2\pi y}\)로 놓으면 \(e^{-2\pi|n|y}\)로 같은 꼴이다.
흔한 오해(1) \(e^{+2\pi|\xi|y}\) 해를 함께 남긴다: 유계 조건을 쓰지 않으면 해가 하나로 정해지지 않는다(\(u = y\)도 경계값 0인 해). (2) \(\mathcal P_y\)의 분산을 계산하려 한다: \(\int x^2\mathcal P_y = \infty\)라 정의되지 않는다. (3) 열방정식처럼 시간 변수라고 여긴다: \(y\)는 공간 변수이고 해는 시간에 따라 변하지 않는 평형 상태다.
요약
  1. \(\hat u(\xi, y) = \hat f(\xi)e^{-2\pi|\xi|y}\).
  2. \(u = f * \mathcal P_y\), \(\mathcal P_y = \frac1\pi\frac y{x^2 + y^2}\), 좋은 핵.
  3. 원판의 푸아송 핵과 같은 구조, 열핵보다 꼬리가 두껍다.

5.3.4연습문제

기본

  1. \(\int_{-\infty}^\infty\mathcal P_y(x)\,dx = 1\)을 보여라.
    답

    \(\frac1\pi\left[\arctan\frac xy\right]_{-\infty}^\infty = \frac1\pi\left(\frac\pi2 + \frac\pi2\right) = 1\).

응용

  1. \(\mathcal P_{y_1} * \mathcal P_{y_2} = \mathcal P_{y_1 + y_2}\)을 보여라.
    답

    변환하면 \(e^{-2\pi|\xi|y_1}e^{-2\pi|\xi|y_2} = e^{-2\pi|\xi|(y_1 + y_2)}\). 높이 \(y_1\)의 해를 경계로 다시 \(y_2\)만큼 올라가면 높이 \(y_1 + y_2\)의 해가 된다.

심화

  1. 경계값 \(f(x) = \cos x\)에 대한 유계 해를 구하여라.
    답

    \(u = e^{-y}\cos x\). \(u_{xx} + u_{yy} = -e^{-y}\cos x + e^{-y}\cos x = 0\)이고 \(y = 0\)에서 \(\cos x\).
