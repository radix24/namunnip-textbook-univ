좋은 핵과 나쁜 핵의 모양

탐구 · 디리클레, 페예르, 푸아송 핵

질문

세 핵은 모두 적분이 1이고 0 근처에서 높이 솟습니다. 그런데 왜 페예르 핵과 푸아송 핵만 "좋은 핵"이고 디리클레 핵은 아닐까요? 모양과 절대적분을 비교해 봅시다.

복원

좋은 핵: 적분 1, \(\frac1{2\pi}\int|K_n|\)이 유계, 0에서 떨어진 곳의 \(\int|K_n| \to 0\) (1.3절).

해 보기

  1. 페예르 핵은 어디서나 0 이상이라 절대적분이 정확히 1입니다. \(N\)을 5, 20, 80으로 키우면 \(|x| \ge 0.3\) 바깥의 무게가 약 0.55, 0.096, 0.025로 줄어듭니다.
  2. 디리클레 핵은 음수 부분이 크고, 절대적분이 \(N = 5, 20, 80\)에서 약 1.96, 2.49, 3.05로 \(\ln N\)처럼 계속 커집니다. 바깥 무게도 약 1.04에서 줄지 않습니다.
  3. 푸아송 핵도 양수이고 \(r \to 1\)일 때 0 근처로 몰립니다.

설명

  1. 진동하는 꼬리\(D_N(x) = \frac{\sin(N + \frac12)x}{\sin(x/2)}\)의 꼬리는 진폭 \(\frac1{|\sin(x/2)|}\)로 줄지 않은 채 점점 빨리 진동합니다. 부호를 고려한 적분(=1)은 상쇄로 맞지만, 절댓값의 적분은 진동 횟수만큼 쌓여 커집니다.
  2. 평균의 힘\(F_N\)은 \(D_0, \dots, D_{N-1}\)의 평균이라 진동이 서로 상쇄되어 \(\frac1N\frac{\sin^2(Nx/2)}{\sin^2(x/2)} \ge 0\)이 됩니다. 이 양수성 덕분에 연속함수의 체사로 평균이 항상 균등수렴합니다.

판단

"디리클레 핵은 0에서 높이 \(2N + 1\)로 솟고 적분이 1이니 부분합도 항상 수렴한다"는 틀립니다. 좋은 핵에는 절대적분의 유계성이 필요하고, 디리클레 핵은 이를 어깁니다. 실제로 연속인데 푸리에 급수가 한 점에서 발산하는 함수가 있습니다.
