유한 푸리에 해석과 디리클레 정리 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자. \(\zeta = e^{2\pi i/N}\), \(\hat f(k) = \frac1N\sum f(n)\zeta^{-kn}\)이다.

  1. 계산\(N = 4\)에서 \(f = (1, -1, 1, -1)\)의 DFT를 구하여라. [06-01]

    힌트 1

    \(f(n) = (-1)^n = \zeta^{2n}\) (\(\zeta = i\)).

    힌트 2

    기저 벡터 하나.

    풀이

    \(f = e_2\)이므로 \(\hat f = (0, 0, 1, 0)\) (6.1절).

  2. 증명\(\mathbb Z_N\) 위의 평행이동 \(g(n) = f(n - m)\)에 대해 \(\hat g(k) = \zeta^{-km}\hat f(k)\)임을 보이고, 따라서 \(|\hat g| = |\hat f|\)임을 설명하여라. [06-01]

    힌트 1

    합에서 \(n - m\)을 새 변수로.

    힌트 2

    \(\mathbb Z_N\)에서는 순환하므로 합의 범위가 그대로이다.

    풀이

    \(\hat g(k) = \frac1N\sum_nf(n - m)\zeta^{-k(n-m)}\zeta^{-km} = \zeta^{-km}\hat f(k)\). \(|\zeta^{-km}| = 1\)이므로 크기는 같다. 신호를 늦게 시작해도 진동수 성분의 크기는 변하지 않는다. ∎

  3. 계산\(N = 8\)인 FFT의 나비 연산 곱셈 수를 점화식 \(T(N) = 2T(\frac N2) + \frac N2\)로 구하고 \(N^2\)과 비교하여라. [06-02]

    힌트 1

    \(T(1) = 0\), \(T(2) = 1\).

    힌트 2

    \(T(4) = 2 + 2\).

    풀이

    \(T(2) = 1\), \(T(4) = 4\), \(T(8) = 8 + 4 = 12 = \frac82\log_28\). 정의대로는 64번 (6.2절).

  4. 판단"FFT는 계산을 줄이기 위해 작은 항을 버리므로 결과가 근삿값이다"는 옳은가? [06-02]

    힌트 1

    짝·홀 분해식은 등식인가 근사식인가?

    힌트 2

    같은 합을 다른 순서로 묶은 것뿐이다.

    풀이

    틀리다. 분해식 \(\hat f(k) = \frac12(\hat f_0(k) + \zeta_N^{-k}\hat f_1(k))\)은 정확한 등식이다. 컴퓨터의 반올림 오차를 빼면 결과는 정의대로 계산한 것과 같고, 오히려 연산이 적어 반올림 오차도 보통 더 작다.

  5. 계산\(q = 5\)의 지표 네 개를 모두 구하고, \(n \equiv 2 \pmod 5\)를 골라내는 식 \(\frac14\sum_\chi\overline{\chi(2)}\chi(n)\)이 \(n = 2\)에서 1, \(n = 3\)에서 0임을 확인하여라. [06-03]

    힌트 1

    2가 생성원이라 \(\chi(2) \in \{1, i, -1, -i\}\)로 \(\chi\)가 정해진다.

    힌트 2

    \(\chi(3) = \chi(2)^3\).

    풀이

    \(\chi_j(2) = i^j\) (\(j = 0, 1, 2, 3\)), \(\chi_j(2^m) = i^{jm}\). \(n = 2\): \(\frac14\sum_j|i^j|^2 = 1\). \(n = 3 = 2^3\): \(\frac14\sum_j\overline{i^j}i^{3j} = \frac14\sum_ji^{2j} = \frac14(1 - 1 + 1 - 1) = 0\) (6.3절).

  6. 판단"\(q = 4\)에서 \(L(1, \chi) = \frac\pi4\)가 0이 아니므로 \(4k + 1\) 꼴 소수와 \(4k + 3\) 꼴 소수가 정확히 같은 개수만큼 있다"는 옳은가? [06-03]

    힌트 1

    디리클레 정리가 말하는 것은 \(\sum\frac1p\)의 발산이다.

    힌트 2

    \(10^6\) 이하에서 39175개와 39322개.

    풀이

    틀리다. \(L(1, \chi) \ne 0\)에서 나오는 것은 두 종류 모두 무한히 많다(역수의 합이 발산)는 것이다. 개수가 정확히 같지는 않고, 실제로 작은 범위에서는 \(4k + 3\) 꼴이 약간 많은 경향이 있다(체비쇼프의 편향). 비율이 \(\frac12\)로 간다는 더 강한 결과는 별도의 정리(등차수열의 소수 정리)이다.
