유한군 위의 푸리에 해석

본문

컴퓨터는 연속 함수 전체를 다룰 수 없고 유한 개의 표본만 다룬다. 그렇다면 \(N\)개의 값으로 이루어진 신호도 진동수 성분으로 분해할 수 있을까? 분해한다면 무엇이 원 위의 \(e^{ik\theta}\) 노릇을 하고, 표본으로 바꾸면서 어떤 일이 생길까?

먼저 알아야 할 것복소수의 곱과 등비수열의 합, 푸리에 계수(1.1절), 군과 준동형사상(수학12)을 쓴다.

6.1.11의 거듭제곱근

\(\zeta = e^{2\pi i/N}\)으로 두면 \(\zeta^N = 1\)이고, \(1, \zeta, \dots, \zeta^{N-1}\)은 단위원을 \(N\)등분하는 점들이다. 함수 \(e_k(n) = \zeta^{kn}\) (\(k = 0, \dots, N - 1\))은 \(\mathbb Z_N\) 위에서 진동수가 \(k\)인 파동이며, 원 위의 \(e^{ik\theta}\)에 해당한다.

보조정리 6.1.1 (직교 관계)

\(k \equiv \ell \pmod N\)이면 \(\frac1N\sum_{n=0}^{N-1}\zeta^{(k-\ell)n} = 1\)이고, 그렇지 않으면 이 값은 0이다.

증명.\(k \equiv \ell\)이면 모든 항이 1이다. 그렇지 않으면 \(w = \zeta^{k-\ell} \ne 1\)이고 \(w^N = 1\)이므로 등비수열의 합 \(\sum_{n=0}^{N-1}w^n = \frac{w^N - 1}{w - 1}\)이 0이다. ∎

내적 \((f, g) = \frac1N\sum_nf(n)\overline{g(n)}\)으로 보면, \(e_0, \dots, e_{N-1}\)은 \(N\)차원 공간 \(\{f : \mathbb Z_N \to \mathbb C\}\)의 정규직교기저이다.

6.1.2이산 푸리에 변환

\(f : \mathbb Z_N \to \mathbb C\)의 \(k\)번째 계수를 \(\hat f(k) = (f, e_k) = \frac1N\sum_{n=0}^{N-1}f(n)\zeta^{-kn}\)이라 하고, 이 대응을 이산 푸리에 변환이라 한다.

정리 6.1.2

(1) \(f(n) = \sum_{k=0}^{N-1}\hat f(k)\zeta^{kn}\)이다. (2) \(\frac1N\sum_n|f(n)|^2 = \sum_k|\hat f(k)|^2\)이다.

증명.(1) \(\sum_k\hat f(k)\zeta^{kn} = \sum_mf(m)\cdot\frac1N\sum_k\zeta^{k(n-m)}\)이고, 직교 관계에 의해 안쪽 합은 \(m = n\)에서만 1이다. (2) 정규직교기저에 대한 피타고라스 정리이다. ∎

(1)이 역변환 공식이고 (2)가 파서벌 등식이다. 원 위의 급수에서는 수렴을 걱정해야 했지만, 여기서는 모든 것이 유한합이라 곧바로 성립한다.

예제 6.1.3

\(N = 4\)이고 \(f = (1, 2, 0, 0)\)일 때 \(\hat f\)를 구하고 파서벌 등식을 확인하여라.

풀이. \(\zeta = i\)이므로 \(\hat f(k) = \frac14(1 + 2(-i)^k)\)이고 \(\hat f = \left(\frac34, \frac{1 - 2i}4, -\frac14, \frac{1 + 2i}4\right)\)이다. 파서벌 등식의 왼쪽은 \(\frac14(1 + 4) = \frac54\)이고, 오른쪽은 \(\frac9{16} + \frac5{16} + \frac1{16} + \frac5{16} = \frac54\)이다.

6.1.3표본과 겹침

연속 신호를 \(N\)개 표본으로 얻어 \(f(n) = \cos\frac{2\pi an}N\)이라 하자. \(a\)가 정수이면 \(\hat f\)는 \(k = a\)와 \(k = N - a\)에서만 \(\frac12\)이다. 그런데 \(\zeta^{(N-a)n} = \zeta^{-an}\)이므로, 진동수 \(a\)와 \(N - a\)는 표본에서 구별되지 않는다. 이것을 겹침 또는 앨리어싱이라 한다. 한편 \(a\)가 정수가 아니면 그림 1의 주황 막대처럼 한 진동수의 에너지가 여러 \(k\)로 새어 나가며, 이것을 누출이라 한다. 같은 절의 탐구 카드에서 두 현상을 확인한다.

6.1.4유한 아벨 군

\(\mathbb Z_N\)에서 \(e_k\)는 \(e_k(m + n) = e_k(m)e_k(n)\)이고 \(|e_k| = 1\)이다. 일반적으로 유한 아벨 군 \(G\)에서 \(\chi(ab) = \chi(a)\chi(b)\)를 만족하는 \(\chi : G \to \{|z| = 1\}\)을 지표라 한다. 지표는 정확히 \(|G|\)개이고 서로 직교하므로, \(G\) 위의 모든 함수가 지표들로 분해된다. 6.3절에서 \(G = (\mathbb Z/q\mathbb Z)^\times\)의 지표를 쓴다.

흔한 오해\(\hat f(k)\)와 \(\hat f(N - k)\)를 서로 다른 진동수로 해석하기 쉽지만, 실수 신호에서는 \(\hat f(N - k) = \overline{\hat f(k)}\)라 같은 정보이다. 또 \(\frac1N\)을 두는 자리가 어디서나 같다고 여기는 것도 틀렸다. 계산 프로그램은 보통 변환에 \(\frac1N\)을 두지 않고 역변환에 둔다.
마무리

처음 질문에 답하면, \(N\)개의 값으로 이루어진 신호도 \(e_k(n) = \zeta^{kn}\)들로 분해되며, 이것이 원 위의 \(e^{ik\theta}\) 노릇을 한다. 1의 거듭제곱근의 직교 관계 덕분에 역변환 공식과 파서벌 등식이 유한합으로 곧바로 성립한다. 다만 표본으로 바꾸면 진동수 \(a\)와 \(N - a\)가 구별되지 않는 겹침과, 정수가 아닌 진동수가 여러 \(k\)로 퍼지는 누출이 생긴다.

6.1.5연습문제

기본

  1. \(N = 3\)에서 \(f = (1, 1, 1)\)과 \(f = (1, 0, 0)\)의 DFT를 구하여라.
    답

    \((1, 0, 0)\)과 \((\frac13, \frac13, \frac13)\). 상수는 진동수 0 하나, 한 점의 충격은 모든 진동수에 고르게 퍼진다.

응용

  1. \(\mathbb Z_N\) 위의 합성곱 \((f * g)(n) = \frac1N\sum_mf(n - m)g(m)\)에 대해 \(\widehat{f * g} = \hat f\hat g\)임을 보여라.
    답

    \(\frac1N\sum_n\frac1N\sum_mf(n - m)g(m)\zeta^{-kn}\)에서 \(\zeta^{-kn} = \zeta^{-k(n-m)}\zeta^{-km}\)로 나누고 \(n - m\)을 새 변수로 두면 \(\hat f(k)\hat g(k)\).

심화

  1. \(f\)가 실수값이면 \(\hat f(N - k) = \overline{\hat f(k)}\)임을 보여라.
    답

    \(\zeta^{-(N-k)n} = \zeta^{kn} = \overline{\zeta^{-kn}}\)이고 \(f(n)\)이 실수이므로.
