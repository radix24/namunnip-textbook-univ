위쪽 테두리만 데운 원판

예제 · 불연속 경계값의 디리클레 문제

먼저 예측

원판 테두리의 위쪽 반원은 온도 1, 아래쪽 반원은 0으로 유지합니다. 중심과 위쪽 반지름의 가운데 점 \((0, \frac12)\)의 온도는 얼마일까요?

예측 확인

중심은 0.5, \((0, \frac12)\)은 약 0.795입니다.

\(f(\theta) = 1\) (\(0 < \theta < \pi\)), \(f(\theta) = 0\) (\(-\pi < \theta < 0\))일 때 원판 위의 디리클레 문제의 해 \(u(r, \theta)\)를 구하고 \(u(0)\), \(u(\frac12, \frac\pi2)\), \(u(0.9, \frac\pi2)\)를 계산하여라.

전략

\(f = \frac12 + \frac12g\) (\(g\)는 2.3절의 사각파)로 쓰면 계수를 이미 압니다. 해는 \(\sum\hat f(n)r^{|n|}e^{in\theta}\)(3.4절)이고, 생기는 급수를 \(\arctan\)으로 닫힌 꼴로 만듭니다.

풀이

  1. \(f(\theta) \sim \frac12 + \frac2\pi\sum_{k = 1, 3, 5, \dots}\frac{\sin k\theta}k\).
    사각파 계수 \(\frac4\pi\cdot\frac1k\)의 절반.
  2. \(u(r, \theta) = \frac12 + \frac2\pi\sum_{k = 1, 3, \dots}\frac{r^k\sin k\theta}k\).
    각 항에 \(r^{|n|}\)을 곱함.
  3. \(\sum_{k\,\mathrm{odd}}\frac{z^k}k = \frac12\log\frac{1 + z}{1 - z}\)에 \(z = re^{i\theta}\)를 넣고 허수부를 잡으면 \(u = \frac12 + \frac1\pi\arctan\dfrac{2r\sin\theta}{1 - r^2}\).
    \(\frac{1 + z}{1 - z}\)의 편각이 \(\arctan\frac{2r\sin\theta}{1 - r^2}\).
  4. \(u(0) = \frac12\), \(u(\frac12, \frac\pi2) = \frac12 + \frac1\pi\arctan\frac43 \approx 0.7952\), \(u(0.9, \frac\pi2) = \frac12 + \frac1\pi\arctan\frac{1.8}{0.19} \approx 0.9665\).
    대입.

검산

급수를 \(k = 199\)까지 더해도 \(u(\frac12, \frac\pi2) = 0.795167\)로 닫힌 꼴과 일치합니다. 중심값 \(\frac12\)은 경계 평균과 같고(평균값 성질), 위쪽 테두리에 가까울수록 1에 다가갑니다.

의미

\(\theta = 0, \pi\)인 두 점에서 경계값이 뛰지만 안쪽의 해는 매끄럽습니다. 등온선 \(u = c\)는 두 점프 지점 \((\pm1, 0)\)을 지나는 원호이고, \(u\)의 값은 그 원호가 경계와 이루는 각도로 정해집니다. 라플라스 방정식이 경계의 거친 부분을 안쪽에서 즉시 매끄럽게 만든다는 점은 열방정식(3.3절)과 같습니다.

이해 확인

\(u(\frac12, -\frac\pi2)\)는?

답

\(\sin\theta = -1\)이라 \(\frac12 - \frac1\pi\arctan\frac43 \approx 0.2048\). 대칭으로 \(1 - 0.7952\).
