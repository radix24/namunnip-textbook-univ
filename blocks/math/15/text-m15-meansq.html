평균제곱 수렴과 파서벌 정리

본문
이 절에서 배울 것
  • 복소 내적 \((f, g) = \frac1{2\pi}\int f\bar g\)와 노름 \(\|f\|\)로 푸리에 급수를 직교 전개로 본다.
  • 최적 근사 보조정리와 페예르 정리를 결합해 \(\|f - S_Nf\| \to 0\)을 증명한다.
  • 파서벌 등식 \(\sum|\hat f(n)|^2 = \|f\|^2\)을 얻고 내적판(분극)도 쓴다.
먼저 알아야 할 것
  • 좋은 핵과 페예르 정리 (1.3절), 실수 꼴의 베셀·파서벌 (수학11 6.2절).

2.1.1복소 내적 공간

적분 가능한 \(2\pi\)-주기 복소함수에 \((f, g) = \frac1{2\pi}\int_{-\pi}^\pi f(\theta)\overline{g(\theta)}d\theta\), \(\|f\| = (f, f)^{1/2}\)을 주면 \(e_n(\theta) = e^{in\theta}\)들이 정규직교이고 \(\hat f(n) = (f, e_n)\)입니다. 부분합 \(S_Nf = \sum_{|n|\le N}(f, e_n)e_n\)은 \(f\)를 \(e_{-N}, \dots, e_N\)이 생성하는 공간에 직교 사영한 것입니다.

보조정리 2.1.1 (최적 근사)

차수 \(N\) 이하의 모든 삼각다항식 \(P = \sum_{|n|\le N}c_ne_n\)에 대해 \(\|f - S_Nf\| \le \|f - P\|\).

증명.\(f - S_Nf\)는 모든 \(e_n\) (\(|n| \le N\))과 직교하므로 \(S_Nf - P\)와 직교한다. 피타고라스로 \(\|f - P\|^2 = \|f - S_Nf\|^2 + \|S_Nf - P\|^2\). ∎

2.1.2평균제곱 수렴

정리 2.1.2

\(f\)가 적분 가능하면 \(\|f - S_Nf\| \to 0\)이고 \(\sum_{n\in\mathbb Z}|\hat f(n)|^2 = \|f\|^2\) (파서벌).

증명.먼저 \(f\)가 연속이라 하자. 페예르 정리(1.3절)로 \(\sigma_Mf \to f\) 균등이므로 \(\|f - \sigma_Mf\| \le \sup|f - \sigma_Mf| < \varepsilon\)인 \(M\)이 있다. \(\sigma_Mf\)는 차수 \(M\) 이하 삼각다항식이므로 \(N \ge M\)이면 최적 근사로 \(\|f - S_Nf\| \le \|f - \sigma_Mf\| < \varepsilon\). 일반적인 적분 가능 \(f\)는 \(\|f - g\| < \varepsilon\)인 연속 주기함수 \(g\)로 근사하고(수학11 6.2절), \(\|f - S_Nf\| \le \|f - S_Ng\| \le \|f - g\| + \|g - S_Ng\|\)로 마친다. 파서벌은 \(\|f\|^2 = \|S_Nf\|^2 + \|f - S_Nf\|^2 = \sum_{|n|\le N}|\hat f(n)|^2 + \|f - S_Nf\|^2\)에서 \(N \to \infty\). ∎

두 함수에 대해서는 \((f, g) = \sum_n\hat f(n)\overline{\hat g(n)}\)이 성립합니다(분극 항등식). 함수의 내적을 계수의 내적으로 바꿔 계산할 수 있다는 뜻입니다.

2.1.3응용 예

  • \(f = \theta\): \(|\hat f(n)|^2 = \frac1{n^2}\) (\(n \ne 0\)), \(\|f\|^2 = \frac{\pi^2}3\)이므로 \(2\sum_{n\ge1}\frac1{n^2} = \frac{\pi^2}3\), 곧 \(\sum\frac1{n^2} = \frac{\pi^2}6\).
  • 등주 부등식(3.1절)과 하이젠베르크 불확정성(4.4절)도 파서벌 등식에서 나옵니다.
흔한 오해(1) 평균제곱 수렴을 점별수렴으로 읽는다(2.2절). (2) 복소 내적에서 켤레를 빠뜨려 \(\|f\|^2\)이 복소수가 되게 한다.
요약
  1. \(S_Nf\)는 \(\operatorname{span}\{e_n\}_{|n|\le N}\)로의 직교 사영(최적 근사).
  2. 페예르의 균등수렴 + 최적 근사 ⇒ \(\|f - S_Nf\| \to 0\).
  3. 파서벌 \(\sum|\hat f(n)|^2 = \|f\|^2\), 내적판 \((f, g) = \sum\hat f(n)\overline{\hat g(n)}\).

2.1.4연습문제

기본

  1. \(f = e^{i\theta} + 2e^{-3i\theta}\)에 대해 \(\|f\|^2\)을 파서벌로 구하여라.
    답

    \(|1|^2 + |2|^2 = 5\).

응용

  1. 사각파 \(\operatorname{sgn}\theta\)의 파서벌 등식으로 양의 홀수 \(n\)에 대한 \(\sum\frac1{n^2}\)을 구하여라.
    답

    홀수 \(n\)(양수와 음수 모두)에서 \(|\hat f(n)|^2 = \frac4{\pi^2n^2}\), \(\|f\|^2 = 1\). 양수와 음수가 같은 값을 주므로 \(2\cdot\frac4{\pi^2}S = 1\) (\(S\)는 양의 홀수 \(n\)에 대한 합), 곧 \(S = \frac{\pi^2}8\).

심화

  1. 계수의 제곱합이 유한한 수열 \((c_n)\)이 주어지면 리만 적분 가능한 함수로 항상 실현되는가?
    답

    아니다. 부분합은 평균제곱으로 코시이지만 그 극한이 리만 적분 가능하지 않을 수 있다. 극한이 항상 존재하려면 르베그 적분의 \(L^2\) 공간이 필요하다(리스-피셔 정리).
