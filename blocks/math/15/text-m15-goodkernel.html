좋은 핵과 체사로 합

본문
이 절에서 배울 것
  • 합성곱 \(f * K\)를 정의하고, 부분합이 디리클레 핵과의 합성곱임을 안다.
  • 좋은 핵의 세 조건을 정하고, 좋은 핵이면 \(f * K_n \to f\)임을 증명한다.
  • 페예르 핵이 좋은 핵이라 체사로 평균이 연속함수로 균등수렴함을 보이고, 디리클레 핵은 좋은 핵이 아님을 안다.
먼저 알아야 할 것
  • 푸리에 계수 (1.1절), 균등연속 (수학7 3.3절).

1.3.1합성곱

합성곱: \(2\pi\)-주기 함수 \(f, g\)에 대해 \((f * g)(x) = \frac1{2\pi}\int_{-\pi}^\pi f(y)g(x - y)\,dy\).

\(\widehat{f * g}(n) = \hat f(n)\hat g(n)\)이고(적분 순서를 바꿔 계산), 부분합 \(S_Nf(x) = \sum_{|n|\le N}\hat f(n)e^{inx}\)은

\[S_Nf = f * D_N, \qquad D_N(x) = \sum_{|n|\le N}e^{inx} = \frac{\sin\left(N + \frac12\right)x}{\sin\frac x2}\]

입니다(디리클레 핵). 합성곱은 "\(g\)를 무게로 한 \(f\)의 이동평균"이라, \(g\)가 0 근처에 몰려 있으면 \(f * g \approx f\)일 것으로 기대됩니다.

1.3.2좋은 핵

정의 1.3.1 (좋은 핵)

함수열 \(K_n\)이 (a) \(\frac1{2\pi}\int_{-\pi}^\pi K_n = 1\), (b) \(\frac1{2\pi}\int|K_n| \le M\) (모든 \(n\)), (c) 모든 \(\delta > 0\)에 대해 \(\int_{\delta\le|x|\le\pi}|K_n| \to 0\)을 만족하면 좋은 핵이라 한다.

정리 1.3.2

\(K_n\)이 좋은 핵이고 \(f\)가 적분 가능하면, \(f\)가 연속인 모든 점 \(x\)에서 \((f * K_n)(x) \to f(x)\). \(f\)가 모든 곳에서 연속이면 수렴은 균등하다.

증명.(a)로 \((f * K_n)(x) - f(x) = \frac1{2\pi}\int K_n(y)[f(x - y) - f(x)]\,dy\). \(\varepsilon > 0\)에 대해 연속성으로 \(|y| < \delta\)이면 \(|f(x - y) - f(x)| < \varepsilon\)인 \(\delta\)를 잡는다. \(|y| < \delta\) 부분은 (b)로 \(M\varepsilon\) 이하이고, 나머지 부분은 \(2\sup|f|\cdot\frac1{2\pi}\int_{\delta\le|y|}|K_n| \to 0\) (c). 따라서 극한 상한이 \(M\varepsilon\) 이하이다. 연속이면 균등연속이라 \(\delta\)를 \(x\)와 무관하게 잡을 수 있어 균등수렴한다. ∎

1.3.3페예르 핵

체사로 평균: \(\sigma_Nf = \frac1N(S_0f + \cdots + S_{N-1}f) = f * F_N\), 페예르 핵 \(F_N = \frac1N\sum_{k=0}^{N-1}D_k = \frac1N\frac{\sin^2(Nx/2)}{\sin^2(x/2)}\).

\(F_N \ge 0\)이고 적분이 1이므로 (a), (b)가 성립하고(\(M = 1\)), \(\delta \le |x| \le \pi\)에서 \(F_N \le \frac1{N\sin^2(\delta/2)} \to 0\)이므로 (c)도 성립합니다. 따라서 다음을 얻습니다.

정리 1.3.3 (페예르)

연속인 \(2\pi\)-주기 함수의 체사로 평균 \(\sigma_Nf\)는 \(f\)로 균등수렴한다. 따라서 삼각다항식은 연속 주기함수 공간에서 조밀하다.

반면 디리클레 핵은 (a)와 (c)의 일부는 만족하지만 (b)가 깨집니다. \(\frac1{2\pi}\int|D_N| \approx \frac4{\pi^2}\log N \to \infty\)이고(르베그 상수), 이것이 연속함수의 푸리에 급수가 발산할 수 있는 원인입니다. 같은 절의 탐구 카드에서 두 핵의 모양을 비교합니다.

흔한 오해(1) "\(D_N\)도 0 근처에서 높이 솟으니 좋은 핵": 음수 부분이 커서 \(\int|D_N|\)이 발산한다. (2) 체사로 평균이 수렴하면 원래 급수도 수렴한다고 여긴다. 체사로 합은 더 많은 급수에 값을 준다(\(1 - 1 + 1 - \cdots\)의 체사로 합은 \(\frac12\)).
요약
  1. \(S_Nf = f * D_N\), \(\sigma_Nf = f * F_N\). \(\widehat{f * g} = \hat f\hat g\).
  2. 좋은 핵(적분 1, 절대적분 유계, 바깥에서 소멸) ⇒ 연속점에서 \(f * K_n \to f\).
  3. 페예르 핵은 좋은 핵(\(F_N \ge 0\)) → 페예르 정리. 디리클레 핵은 \(\int|D_N| \sim \log N\)이라 좋은 핵이 아니다.

1.3.4연습문제

기본

  1. \(D_N(0)\)과 \(F_N(0)\)을 구하여라.
    답

    \(D_N(0) = 2N + 1\) (항이 \(2N + 1\)개). \(F_N(0) = \frac1N\sum_{k=0}^{N-1}(2k + 1) = N\).

응용

  1. 푸아송 핵 \(P_r(x) = \sum r^{|n|}e^{inx} = \frac{1 - r^2}{1 - 2r\cos x + r^2}\) (\(0 < r < 1\))이 \(r \to 1^-\)일 때 좋은 핵임을 설명하여라.
    답

    \(P_r > 0\), 적분은 \(n = 0\) 항의 1, \(\delta \le |x|\)에서 분모 \(\ge (1 - r)^2 + 2r(1 - \cos\delta) \ge c > 0\)이라 \(P_r \le \frac{1 - r^2}c \to 0\).

심화

  1. \(F_N = \frac1N\frac{\sin^2(Nx/2)}{\sin^2(x/2)}\)을 \(\sum_{k=0}^{N-1}\sin(k + \frac12)x = \frac{\sin^2(Nx/2)}{\sin(x/2)}\)을 써서 보여라.
    답

    \(\sum_kD_k = \frac{\sum_k\sin(k + \frac12)x}{\sin(x/2)}\). \(2\sin\frac x2\sin(k + \frac12)x = \cos kx - \cos(k + 1)x\)를 더하면 \(1 - \cos Nx = 2\sin^2\frac{Nx}2\)이므로 \(\sum\sin(k + \frac12)x = \frac{\sin^2(Nx/2)}{\sin(x/2)}\). 나누면 된다.
