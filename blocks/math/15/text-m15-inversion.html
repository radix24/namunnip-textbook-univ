역변환 공식과 플랑셰렐 정리

본문

4.2.1곱셈 공식

보조정리 4.2.1 \(f, g \in \mathcal S\)이면 \(\int f(x)\hat g(x)\,dx = \int\hat f(y)g(y)\,dy\).
증명

두 변 모두 \(\iint f(x)g(y)e^{-2\pi ixy}\,dx\,dy\)와 같다. 피적분함수의 절댓값 \(|f(x)||g(y)|\)의 이중적분이 유한하므로 적분 순서를 바꿀 수 있다. ∎

4.2.2역변환 공식

정리 4.2.2 \(f \in \mathcal S\)이면 모든 \(x\)에서 \(f(x) = \int_{-\infty}^\infty\hat f(\xi)e^{2\pi ix\xi}\,d\xi\).
증명

\(x = 0\)인 경우. \(G_\delta(\xi) = e^{-\pi\delta\xi^2}\)의 변환은 \(K_\delta(x) = \frac1{\sqrt\delta}e^{-\pi x^2/\delta}\)이다(4.1절). \(K_\delta\)는 양수, 적분 1, \(\delta \to 0\)이면 0 근처로 몰리는 좋은 핵이므로 \(\int f(x)K_\delta(x)\,dx \to f(0)\). 곱셈 공식으로 왼쪽은 \(\int\hat f(\xi)G_\delta(\xi)\,d\xi\)이고, \(G_\delta \to 1\)이며 \(\hat f\)가 빨리 줄어 \(\int\hat f(\xi)\,d\xi\)로 간다. 따라서 \(f(0) = \int\hat f\).

일반의 \(x\). \(F(y) = f(y + x)\)에 적용하면 \(\hat F(\xi) = \hat f(\xi)e^{2\pi ix\xi}\)이므로 \(f(x) = F(0) = \int\hat f(\xi)e^{2\pi ix\xi}\,d\xi\). ∎

그래서 \(\mathcal S\)에서 \(f \mapsto \hat f\)는 일대일 대응이고, 거꾸로 가는 변환은 지수의 부호만 바꾼 것입니다. 급수(1.3절)에서는 \(S_Nf\)가 수렴하지 않을 수 있어 페예르 평균이 필요했지만, 슈바르츠 함수는 충분히 좋아서 바로 성립합니다.

4.2.3합성곱과 플랑셰렐 정리

합성곱 \((f * g)(x) = \int f(x - y)g(y)\,dy\)에 대해 \(\widehat{f * g} = \hat f\,\hat g\)입니다(적분 순서를 바꾸고 \(x - y\)를 치환). 급수의 \(\widehat{f * g}(n) = \hat f(n)\hat g(n)\)과 같은 모양입니다.

정리 4.2.3 (플랑셰렐) \(f \in \mathcal S\)이면 \(\int|\hat f(\xi)|^2\,d\xi = \int|f(x)|^2\,dx\).
증명

\(f^\flat(x) = \overline{f(-x)}\)로 두면 \(\widehat{f^\flat} = \overline{\hat f}\)이다. \(h = f * f^\flat\)이면 \(\hat h = \hat f\,\overline{\hat f} = |\hat f|^2\)이고

\[h(0) = \int f(-y)\overline{f(-y)}\,dy = \int|f|^2.\]

역변환 공식을 \(x = 0\)에서 \(h\)에 쓰면 \(h(0) = \int\hat h = \int|\hat f|^2\). ∎

푸리에 급수의 파서벌 등식(2.1절)이 \(\frac1{2\pi}\int|f|^2 = \sum|\hat f(n)|^2\)이었던 것과 짝을 이룹니다. 이를 이용해 변환을 \(\mathcal S\)보다 넓은 제곱적분 가능 함수 전체로 넓힐 수 있습니다.

예 4.2.4 \(f(x) = e^{-\pi x^2}\)이면 \(\int|f|^2 = \int e^{-2\pi x^2}\,dx = \frac1{\sqrt2}\)이고 \(\hat f = f\)이므로 등식이 당연히 맞습니다. \(f(x) = e^{-\pi\delta x^2}\)이면 \(\int|f|^2 = \frac1{\sqrt{2\delta}}\), \(\int|\hat f|^2 = \frac1\delta\int e^{-2\pi\xi^2/\delta}\,d\xi = \frac1\delta\sqrt{\frac\delta2} = \frac1{\sqrt{2\delta}}\)로 일치합니다.
흔한 오해(1) 역변환이 늘 \(f\)를 되돌려 준다고 여긴다. \(\hat f\)가 적분 가능하지 않으면(예: 특성함수의 \(\frac{\sin\pi\xi}{\pi\xi}\)) 역변환 적분 자체가 보통의 의미로 수렴하지 않는다. (2) 플랑셰렐에서 상수 \(2\pi\)를 붙인다. \(e^{-2\pi ix\xi}\) 관례에서는 상수가 없다.
요약
  1. 곱셈 공식 \(\int f\hat g = \int\hat fg\)는 적분 순서 바꾸기.
  2. 가우스 좋은 핵 + 곱셈 공식 ⇒ 역변환 공식 \(f(x) = \int\hat f(\xi)e^{2\pi ix\xi}\,d\xi\).
  3. \(\widehat{f * g} = \hat f\hat g\), 플랑셰렐 \(\|\hat f\| = \|f\|\).

4.2.4연습문제

기본

  1. \(\hat{\hat f}(x) = f(-x)\)임을 보여라.
    답

    \(\hat{\hat f}(x) = \int\hat f(\xi)e^{-2\pi ix\xi}\,d\xi = \int\hat f(\xi)e^{2\pi i(-x)\xi}\,d\xi = f(-x)\) (역변환 공식).

응용

  1. \(e^{-\pi x^2} * e^{-\pi x^2}\)을 변환으로 계산하여라.
    답

    변환은 \(e^{-2\pi\xi^2}\)이고 이는 \(\delta = 2\)의 \(G_\delta\)이므로 원래 함수는 \(\frac1{\sqrt2}e^{-\pi x^2/2}\).

심화

  1. \(\widehat{f^\flat} = \overline{\hat f}\)를 증명하여라.
    답

    \(\int\overline{f(-x)}e^{-2\pi ix\xi}\,dx\)에서 \(x \to -x\)로 치환하면 \(\int\overline{f(x)}e^{2\pi ix\xi}\,dx = \overline{\int f(x)e^{-2\pi ix\xi}\,dx}\).
