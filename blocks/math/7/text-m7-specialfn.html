멱급수로 정의하는 지수함수와 삼각함수

본문

고등학교에서 \(\sin x\)는 직각삼각형의 변의 비로, \(e^x\)는 \(e\)의 거듭제곱으로 배웠다. 그런데 무리수 지수 \(e^{\sqrt2}\)는 무엇이고, 각도라는 기하적 양을 해석학에서 어떻게 정의하는가? 멱급수 하나로 이 함수들을 처음부터 다시 세울 수 있다.

먼저 알아야 할 것균등수렴과 함수급수(6.2절, 6.3절), 평균값 정리(4.1절), 비 판정법(2.4절), 절대수렴 급수의 곱을 쓴다. Rudin 8장을 따른다.

6.5.1지수함수

복소수 \(z\)에 대해 \(E(z) = \sum_{n\ge0}\frac{z^n}{n!}\)로 정한다. 비 판정법으로 모든 \(z\)에서 절대수렴하고, 유계 원판에서 균등수렴한다. 두 절대수렴 급수의 Cauchy 곱을 계산하면 이항정리로

\[E(z)E(w) = \sum_n\frac{1}{n!}\sum_{k}\binom nkz^kw^{n-k} = E(z + w)\]

이다. 이 덧셈 정리 하나에서 거의 모든 성질이 나온다. \(E(z)E(-z) = E(0) = 1\)이므로 \(E\)는 0이 아니다. 실수에서 \(E(x) > 0\)이고 항별 미분으로 \(E' = E\)이므로 \(E\)는 실수에서 증가한다. 또 \(e = E(1)\)로 두면 자연수 \(n\)에서 \(E(n) = e^n\), 유리수 \(p/q\)에서 \(E(p/q)^q = E(p) = e^p\)이므로 \(E(p/q) = e^{p/q}\)이다. 그러면 무리수 \(x\)에서 \(e^x\)를 \(E(x)\)로 정의하는 것이 연속성에 맞는 유일한 선택이다.

6.5.2로그와 거듭제곱

\(E\)는 \(\mathbb R\)에서 \((0, \infty)\)로 가는 증가 전단사이다. 증가와 연속은 위에서 보았고, \(E(x) \ge 1 + x\)라서 위로 유계가 아니며, \(E(-x) = 1/E(x)\)라서 0에 얼마든지 가까워진다. 그러면 역함수 \(L = \log\)가 있고 \(L(xy) = L(x) + L(y)\), \(L'(y) = 1/y\)이다. 양수 \(x\)와 실수 \(\alpha\)에서 \(x^\alpha = E(\alpha L(x))\)로 정하면 지수 법칙이 덧셈 정리에서 따라온다.

6.5.3삼각함수와 π

이제 \(C(t) = \operatorname{Re}E(it)\), \(S(t) = \operatorname{Im}E(it)\)로 정의하자. 급수를 실수부와 허수부로 나누면 \(C(t) = 1 - \frac{t^2}{2!} + \cdots\), \(S(t) = t - \frac{t^3}{3!} + \cdots\)로 익숙한 Taylor 급수가 된다. 또 \(\overline{E(it)} = E(-it)\)이므로 \(|E(it)|^2 = E(it)E(-it) = 1\), 곧 \(C^2 + S^2 = 1\)이다. 미분하면 \(C' = -S\), \(S' = C\)이다.

정리 6.5.1

\(C(x) = 0\)인 양수 \(x\)가 있다. 그 가운데 가장 작은 것을 \(x_0\)이라 하고 \(\pi = 2x_0\)으로 정하면 \(E(i\pi/2) = i\), \(E(2\pi i) = 1\)이고, \(E(it)\)는 주기 \(2\pi\)인 함수이다.

증명.\(C\)가 \((0, \infty)\)에서 양수라고 가정하자. 그러면 \(S' = C > 0\)이라 \(S\)가 증가하고, \(0 < x < y\)에서 \(S(x)(y - x) < \int_x^yS = C(x) - C(y) \le 2\)이다. \(S(x) > 0\)이므로 \(y\)를 크게 하면 모순이다. 따라서 \(C\)의 양의 영점이 있고, 영점 집합이 닫혀 있으므로 가장 작은 것 \(x_0\)이 있다. 그 점에서 \(C = 0\)이고 \(S\)는 \((0, x_0)\)에서 증가했으므로 \(S(x_0) = 1\), 곧 \(E(ix_0) = i\)이다. 덧셈 정리로 \(E(4ix_0) = i^4 = 1\)이다. ∎

이 정의의 \(\pi\)가 원주율과 같은 이유도 그림 1에 있다. 곡선 \(t \mapsto E(it)\)의 속력은 \(|E'(it)\cdot i| = |E(it)| = 1\)이므로, \(0\)에서 \(2\pi\)까지 돈 길이가 \(2\pi\)이고 그 사이 곡선은 단위원을 정확히 한 바퀴 돈다. 따라서 \(\pi\)는 단위원 둘레의 절반이다.

예제 6.5.2

정의만으로 \(t \ge 0\)에서 \(S(t) \le t\)이고 \(\pi < 4\)임을 보여라.

풀이. \(C \le 1\)이므로 \(S(t) = \int_0^tC \le t\)이다. 다음으로 \(C(2) = 1 - 2 + \frac{16}{24} - \frac{64}{720} + \cdots\)인데 \(n \ge 2\)에서 항의 절댓값이 줄어드는 교대급수이므로 \(C(2) < 1 - 2 + \frac23 = -\frac13 < 0\)이다. \(C(0) = 1 > 0\)이므로 중간값 정리로 \((0, 2)\)에 영점이 있고, \(x_0 < 2\), 곧 \(\pi < 4\)이다.

마무리

멱급수 \(E(z) = \sum z^n/n!\)의 덧셈 정리에서 실지수함수, 로그, 실수 거듭제곱이 차례로 정의된다. \(E(it)\)의 실수부와 허수부가 코사인과 사인이고, 코사인의 첫 양의 영점의 두 배로 \(\pi\)를 정의하면 \(E(it)\)가 주기 \(2\pi\)로 단위원을 한 바퀴 도는 곡선이 된다. 기하에서 빌려 온 정의 없이 해석학만으로 이 함수들이 선다.

6.5.4연습문제

기본

  1. \(\lim_{x\to\infty}x^nE(-x) = 0\)을 보여라.
    답

    \(E(x) > \frac{x^{n+1}}{(n+1)!}\)이므로 \(x^nE(-x) < \frac{(n+1)!}{x}\).

응용

  1. \(\pi > 2\)를 보여라.
    답

    \(S(t) \le t\)이므로 \(C(t) = 1 - \int_0^tS \ge 1 - \frac{t^2}{2}\)이고, \([0, 1]\)에서 \(C \ge \frac12 > 0\)이다. 따라서 첫 영점 \(x_0\)은 1보다 크고 \(\pi = 2x_0 > 2\).
