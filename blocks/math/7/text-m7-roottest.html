급수의 수렴과 근·비 판정법

본문

급수 \(\frac13 + \frac14 + \frac1{27} + \frac1{16} + \frac1{243} + \cdots\)는 짝수 번째 항이 \(2^{-n}\), 홀수 번째 항이 \(3^{-n}\)이다. 이웃한 항의 비를 보는 비 판정법은 이 급수에 답을 내지 못한다. 그런데 항이 등비수열처럼 줄어드니 수렴할 것 같다. 급수를 등비급수와 자동으로 비교하는 더 강한 판정법은 없을까?

먼저 알아야 할 것코시 수열(2.2절), 상극한(2.3절), 등비급수를 쓴다.

2.4.1급수는 부분합의 수열

\(\sum_{n=1}^\infty a_n\)이 수렴한다는 것은 부분합 \(s_n = a_1 + \dots + a_n\)이 수렴한다는 뜻이다. 그래서 수열의 도구가 그대로 쓰인다. 먼저 코시 조건을 부분합에 쓰면, \(\sum a_n\)이 수렴할 필요충분조건은 모든 \(\varepsilon\)에 대해 \(N\)이 있어 \(m \ge n \ge N\)이면 \(|a_n + \dots + a_m| < \varepsilon\)인 것이다. 이것을 코시 판정이라 한다. 특히 \(m = n\)으로 두면 수렴하는 급수는 \(a_n \to 0\)이지만, 거꾸로는 \(\sum\frac1n\)이 반례이다. 또 \(|a_n| \le c_n\)이고 \(\sum c_n\)이 수렴하면 \(\sum a_n\)도 절대수렴한다. 코시 판정에서 \(|a_n + \dots + a_m| \le c_n + \dots + c_m\)이기 때문이며, 이것을 비교 판정이라 한다.

비교의 기준으로 가장 많이 쓰는 것은 등비급수 \(\sum x^n\)이다. \(|x| < 1\)이면 \(\frac{1}{1-x}\)로 수렴하고, \(|x| \ge 1\)이면 발산한다. 근 판정법과 비 판정법은 주어진 급수를 등비급수와 비교하는 자동 장치이다.

2.4.2근 판정법

정리 2.4.1 (근 판정법)

\(\alpha = \limsup\sqrt[n]{|a_n|}\)라 하자. \(\alpha < 1\)이면 \(\sum a_n\)은 절대수렴하고, \(\alpha > 1\)이면 발산한다. \(\alpha = 1\)이면 판정할 수 없다.

증명의 방향은 \(\sqrt[n]{|a_n|} \le \beta\)이면 \(|a_n| \le \beta^n\)이라 등비급수와 비교된다는 것이다. 상극한이 1보다 작으면 결국 이 부등식이 1보다 작은 \(\beta\)로 성립한다(2.3절).

증명.\(\alpha < 1\)이면 \(\alpha < \beta < 1\)인 \(\beta\)를 잡는다. 상극한의 성질에 따라 \(n \ge N\)이면 \(\sqrt[n]{|a_n|} < \beta\), 곧 \(|a_n| < \beta^n\)이다. \(\sum\beta^n\)이 수렴하므로 비교 판정으로 \(\sum|a_n|\)이 수렴하며, 앞의 유한 개는 수렴에 영향이 없다. \(\alpha > 1\)이면 무한히 많은 \(n\)에서 \(\sqrt[n]{|a_n|} > 1\), 곧 \(|a_n| > 1\)이므로 \(a_n \not\to 0\)이고 발산한다. ∎

\(\alpha = 1\)에서 판정할 수 없는 예를 보자. \(\sum\frac1n\)은 발산하고 \(\sum\frac1{n^2}\)은 수렴하지만, 둘 다 \(\sqrt[n]{n^p} \to 1\)이라 \(\alpha = 1\)이다.

2.4.3비 판정법

정리 2.4.2 (비 판정법)

\(\limsup\left|\frac{a_{n+1}}{a_n}\right| < 1\)이면 \(\sum a_n\)은 절대수렴한다. \(n \ge N\)인 모든 \(n\)에서 \(\left|\frac{a_{n+1}}{a_n}\right| \ge 1\)이면 발산한다.

증명.상극한이 \(\beta < 1\)보다 작으면 \(n \ge N\)에서 \(|a_{n+1}| < \beta|a_n|\)이고, 되풀이하면 \(|a_{N+k}| < \beta^k|a_N|\)이다. 그러므로 등비급수와 비교한다. 둘째 진술은 \(|a_n|\)이 \(N\) 이후 감소하지 않아 0으로 가지 않기 때문이다. ∎

발산 쪽의 조건이 근 판정법과 다른 것에 주의한다. \(\limsup > 1\)로는 부족하고 결국 늘 1 이상이어야 한다. 비가 1보다 큰 항과 작은 항이 섞일 수 있기 때문이다.

2.4.4근 판정법이 더 강하다

일반적으로 다음 부등식이 성립한다. 그래서 비 판정법이 수렴을 말해 주면 근 판정법도 말해 주지만, 거꾸로는 아니다.

\[\liminf\left|\frac{a_{n+1}}{a_n}\right| \le \liminf\sqrt[n]{|a_n|} \le \limsup\sqrt[n]{|a_n|} \le \limsup\left|\frac{a_{n+1}}{a_n}\right|\]
예제 2.4.3

짝수 \(n\)에서 \(a_n = 2^{-n}\), 홀수 \(n\)에서 \(a_n = 3^{-n}\)인 급수 \(\frac13 + \frac14 + \frac1{27} + \frac1{16} + \cdots\)에 두 판정법을 적용하여라.

풀이. 근 판정법에서 \(\sqrt[n]{a_n}\)은 짝수에서 \(\frac12\), 홀수에서 \(\frac13\)이므로 상극한은 \(\frac12 < 1\)이고 수렴한다. 비 판정법에서는 \(n\)이 짝수이면 \(\frac{a_{n+1}}{a_n} = \frac{3^{-n-1}}{2^{-n}} = \frac13(\frac23)^n \to 0\)이고, 홀수이면 \(\frac{2^{-n-1}}{3^{-n}} = \frac12(\frac32)^n \to \infty\)이다. 상극한이 \(\infty\)라 수렴을 말해 주지 못하고, 결국 늘 1 이상도 아니라 발산도 말해 주지 못한다. 즉 비 판정법은 이웃한 두 항만 보기 때문에 들쭉날쭉한 수열에 약하다.

그래도 \(n!\)이나 \(a^n\)이 든 급수, 예를 들어 지수함수의 테일러 급수에서는 비가 깔끔하게 정리되어 비 판정법이 계산하기 쉽다. 한편 거듭제곱급수의 수렴반경 공식 \(\frac1R = \limsup\sqrt[n]{|c_n|}\), 곧 코시-아다마르 공식은 근 판정법에서 바로 나온다.

흔한 오해"\(\left|\frac{a_{n+1}}{a_n}\right| < 1\)이 모든 \(n\)에서 성립하면 수렴한다"고 여기기 쉽지만 틀렸다. \(\sum\frac1n\)은 \(\frac{n}{n+1} < 1\)이지만 발산한다. 비가 1보다 작은 고정된 수 \(\beta\)로 눌려야 하며, 비가 1로 다가가면 판정이 안 된다.
마무리

처음 질문의 답은 근 판정법이다. \(\limsup\sqrt[n]{|a_n|} < 1\)이면 결국 \(|a_n| < \beta^n\)이라 등비급수와 비교되어 수렴하고, \(1\)보다 크면 발산한다. 처음 급수는 \(\sqrt[n]{a_n}\)의 상극한이 \(\frac12\)이므로 수렴하지만, 비가 0과 무한대를 오가 비 판정법은 답을 못 낸다. 일반적으로 근 판정이 더 강하며, 상극한을 쓰면 들쭉날쭉한 수열에도 쓸 수 있다. 값이 1이면 두 판정법 모두 판정할 수 없다.

2.4.5연습문제

기본

  1. \(\sum\frac{n^2}{2^n}\)의 수렴을 비 판정법으로 판정하여라.
    답

    비 \(\frac{(n+1)^2}{2n^2} \to \frac12 < 1\). 수렴.

  2. \(\sum\frac{n!}{n^n}\)의 수렴을 판정하여라.
    답

    비 \(\left(\frac{n}{n+1}\right)^n \to \frac1e < 1\). 수렴.

응용

  1. \(\sum\left(\frac{n}{2n+1}\right)^n\)을 근 판정법으로 판정하여라.
    답

    \(\sqrt[n]{a_n} = \frac{n}{2n+1} \to \frac12\). 수렴.

심화

  1. \(\limsup\sqrt[n]{a_n} \le \limsup\frac{a_{n+1}}{a_n}\) (\(a_n > 0\))을 증명하여라.
    힌트

    오른쪽이 \(\beta\)보다 작으면 \(a_{N+k} \le \beta^ka_N\). 양변에 \(\frac1{N+k}\)제곱근.

    답

    오른쪽 < \(\beta\)이면 \(n \ge N\)에서 \(a_n \le \beta^{n-N}a_N = \beta^n(a_N\beta^{-N})\). \(\sqrt[n]{a_n} \le \beta\sqrt[n]{C} \to \beta\). 따라서 왼쪽 \(\le \beta\), \(\beta\)는 오른쪽보다 큰 임의의 수.
