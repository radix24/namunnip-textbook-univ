도함수는 값을 건너뛰지 않는다

증명 · 다르부 정리를 한 단계씩
정리

\(f\)가 \([a, b]\)에서 미분 가능하고 \(f'(a) < 0 < f'(b)\)이면 \(f'(x) = 0\)인 \(x \in (a, b)\)가 있다.

쓰는 것

  • 미분 가능 ⇒ 연속 (공통1 정리 3.1.5).
  • 최대·최소 정리 (3.2절).
  • 페르마 정리: 내부 극값에서 도함수는 0 (4.1절).

아이디어

\(f'(a) < 0\)은 "출발할 때 내려간다", \(f'(b) > 0\)은 "도착할 때 올라간다"는 뜻입니다. 그러면 가장 낮은 곳은 출발점도 도착점도 아닌 안쪽입니다. 안쪽 최저점에서 접선은 수평입니다. 일반 \(\lambda\)는 \(f(t) - \lambda t\)로 바꾸면 이 경우가 됩니다.

증명

  1. \(f\)는 \([a, b]\)에서 연속이므로 최솟값을 갖는 점 \(x \in [a, b]\)가 있다.
    미분 가능하면 연속, 그리고 최대·최소 정리.
  2. \(f'(a) = \lim_{t\to a^+}\frac{f(t) - f(a)}{t - a} < 0\)이므로, \(a\)에 충분히 가까운 \(t > a\)에서 \(\frac{f(t) - f(a)}{t - a} < 0\), 곧 \(f(t) < f(a)\).
    극한이 음수이면 극한에 가까운 값들도 음수(ε = \(|f'(a)|/2\)로 극한의 정의). \(t - a > 0\)을 곱해도 부등호 방향 유지.
  3. 따라서 \(f(a)\)는 최솟값이 아니고 \(x \ne a\).
    더 작은 값 \(f(t)\)가 있다.
  4. 같은 방법으로 \(f'(b) > 0\)에서 \(b\)에 가까운 \(t < b\)는 \(f(t) < f(b)\)이므로 \(x \ne b\).
    \(t - b < 0\)이라 차분몫이 양수이려면 \(f(t) - f(b) < 0\).
  5. \(x \in (a, b)\)는 내부 최소점이므로 페르마 정리로 \(f'(x) = 0\).
    내부 극값 + 미분 가능.

되짚기

  • \(f'\)의 연속성은 어디에도 쓰지 않았습니다. 그래서 결론이 도함수가 불연속이어도 성립합니다. 만약 \(f'\)이 연속이라면 중간값 정리 한 줄이면 끝났을 것입니다.
  • \([a, b]\) 전체에서의 미분 가능성이 필요합니다. 한 점에서라도 미분 가능하지 않으면 깨집니다: \(f(x) = |x|\)는 \([-1, 1]\)에서 \(f'(-1) = -1 < 0 < 1 = f'(1)\)이지만 \(f' = 0\)인 점이 없습니다(최소점 0에서 미분 불가능이라 5단계 실패).

직접 써 보기

위 정리를 써서 일반적인 다르부 정리(\(f'(a) < \lambda < f'(b)\)이면 \(f'(x) = \lambda\)인 \(x\)가 있다)를 증명하여라. \(f'(a) > \lambda > f'(b)\)인 경우도 다뤄라.

답안

\(g(t) = f(t) - \lambda t\)는 \([a, b]\)에서 미분 가능하고 \(g'(a) = f'(a) - \lambda < 0 < g'(b)\). 위 정리로 \(g'(x) = 0\), 곧 \(f'(x) = \lambda\). 반대 경우는 \(-f\)에 같은 논증을 쓰거나 최댓값을 쓴다. ∎
