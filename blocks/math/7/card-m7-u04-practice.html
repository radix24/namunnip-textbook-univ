미분 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 증명\(f\)가 \(\mathbb R\)에서 미분 가능하고 모든 \(x\)에서 \(|f'(x)| \le 1\)이면 \(|f(x) - f(y)| \le |x - y|\)임을 보여라. [04-01]

    힌트 1

    평균값 정리(4.1절).

    힌트 2

    \(f(x) - f(y) = f'(c)(x - y)\).

    풀이

    \(x \ne y\)이면 평균값 정리로 그 사이의 \(c\)에서 \(f(x) - f(y) = f'(c)(x - y)\)이고 \(|f'(c)| \le 1\). ∎ (도함수가 유계이면 립시츠, 따라서 균등연속.)

  2. 계산\(\sqrt{1 + x}\)의 2차 테일러 다항식으로 \(\sqrt{1.1}\)을 근사하고 오차를 어림하여라. [04-01]

    힌트 1

    \(1 + \frac x2 - \frac{x^2}8\), 나머지는 \(\frac{f'''(c)}{6}x^3\).

    힌트 2

    \(f'''(t) = \frac38(1 + t)^{-5/2} \le \frac38\) (\(t \ge 0\)).

    풀이

    근사값 \(1 + 0.05 - 0.00125 = 1.04875\). 오차 \(\le \frac{3/8}{6}(0.1)^3 = 6.25\times10^{-5}\). 실제 \(\sqrt{1.1} = 1.048809\ldots\), 차 \(5.9\times10^{-5}\).

  3. 증명\(f\)가 \([0, 1]\)에서 두 번 미분 가능하고 \(f(0) = f(\frac12) = f(1) = 0\)이면 \(f''(c) = 0\)인 \(c \in (0, 1)\)이 있음을 보여라. [04-01]

    힌트 1

    롤 정리를 \([0, \frac12]\)과 \([\frac12, 1]\)에 각각.

    힌트 2

    그러면 \(f'\)이 0인 점이 둘 생긴다. 다시 롤.

    풀이

    롤로 \(f'(c_1) = 0\) (\(0 < c_1 < \frac12\)), \(f'(c_2) = 0\) (\(\frac12 < c_2 < 1\)). \(f'\)에 롤을 \([c_1, c_2]\)에서 쓰면 \(f''(c) = 0\). ∎

  4. 개념\(f\)가 \((a, b)\)에서 미분 가능하고 \(f'\)이 \(\mathbb Q\)의 값만 가진다. \(f\)에 대해 무엇을 말할 수 있는가? [04-02]

    힌트 1

    다르부 정리: \(f'\)의 값의 집합은 구간입니다(4.2절).

    힌트 2

    유리수만으로 된 구간은 한 점뿐이다.

    풀이

    \(f'\)의 값 집합은 중간값 성질 때문에 구간이고, 유리수만 포함하므로 한 점 \(\{r\}\). 따라서 \(f(x) = rx + C\)인 일차함수.

  5. 계산\(\displaystyle\lim_{x\to0}\frac{x - \sin x}{x^3}\)을 테일러 정리로 구하여라. [04-01]

    힌트 1

    \(\sin x = x - \frac{x^3}{6} + \frac{\cos c}{120}x^5\)(5차 나머지).

    힌트 2

    분자는 \(\frac{x^3}6 - \frac{\cos c}{120}x^5\).

    풀이

    \(\frac{x - \sin x}{x^3} = \frac16 - \frac{\cos c}{120}x^2 \to \frac16\) (\(|\cos c| \le 1\)).

  6. 판단한 학생이 "\(f(x) = x + 2x^2\sin\frac1x\) (\(f(0) = 0\))은 \(f'(0) = 1 > 0\)이므로 0 근처에서 증가한다"고 썼다. 맞는가? [04-01, 04-02]

    힌트 1

    \(x \ne 0\)에서 \(f'(x) = 1 + 4x\sin\frac1x - 2\cos\frac1x\)를 보아라.

    힌트 2

    \(\cos\frac1x = 1\)인 점에서 \(f'\)은 음수이다.

    풀이

    틀렸다. \(x = \frac1{2k\pi}\)에서 \(f'(x) = 1 + 0 - 2 = -1 < 0\)이고 이런 점이 0 근처에 무한히 많아, 0을 포함하는 어떤 구간에서도 증가하지 않는다. "한 점에서 \(f' > 0\) ⇒ 근처에서 증가"는 \(f'\)이 연속일 때만 맞다(\(f'(0) = \lim\frac{h + 2h^2\sin(1/h)}{h} = 1\)이지만 \(f'\)은 0에서 불연속).
