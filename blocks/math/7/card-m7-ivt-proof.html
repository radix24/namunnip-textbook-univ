중간값 정리를 상한으로 직접 증명하기

증명 · 완비성이 쓰이는 자리
정리

\(f\)가 \([a, b]\)에서 연속이고 \(f(a) < 0 < f(b)\)이면 \(f(c) = 0\)인 \(c \in (a, b)\)가 있다.

쓰는 것

  • 완비성 공리와 상한의 성질 (1.1절).
  • 연속의 부호 보존: \(f\)가 \(c\)에서 연속이고 \(f(c) > 0\)이면 \(c\) 근처의 어떤 구간에서 \(f > 0\)이다(ε = \(f(c)\)로 연속의 정의를 쓴다). 음수도 같다.

아이디어

"\(f\)가 아직 음수인 곳"의 오른쪽 끝을 상한으로 잡는다. 그 점에서 \(f\)가 양수면 조금 왼쪽부터 양수라 상한이 더 작아야 하고, 음수면 조금 오른쪽까지 음수라 상한이 더 커야 한다. 둘 다 모순이므로 0이다. 본문의 연결성 증명을 이 경우에 맞춰 풀어 쓴 것이다.

증명

  1. \(S = \{x \in [a, b] : f(x) < 0\}\)로 두자. \(a \in S\)이고 \(S\)는 \(b\)로 위로 유계이므로 \(c = \sup S\)가 있고 \(a \le c \le b\)이다.
    완비성 공리. \(\mathbb Q\)였다면 여기서 막힌다.
  2. \(f(c) > 0\)이라 하자. 부호 보존으로 \((c - r, c]\)에서 \(f > 0\)인 \(r > 0\)이 있다. 그러면 \((c - r, c]\)에 \(S\)의 원소가 없으므로 \(c - r\)도 \(S\)의 상계이다. \(c\)가 가장 작은 상계라는 데 모순.
    상한의 정의 (ii): \(c\)보다 작은 수는 상계가 아니다.
  3. \(f(c) < 0\)이라 하자. 그러면 \(c \ne b\)(\(f(b) > 0\))이므로 \(c < b\)이고, 부호 보존으로 \([c, c + r)\)에서 \(f < 0\)인 \(r > 0\)이 있다(\(c + r \le b\)로 잡는다). 그러면 \(c + \frac r2 \in S\)이고 \(c\)보다 크다. \(c\)가 상계라는 데 모순.
    상한의 정의 (i): \(c\)는 상계이다.
  4. 따라서 \(f(c) = 0\)이다. \(f(a) < 0\), \(f(b) > 0\)이므로 \(c \ne a, b\), 곧 \(c \in (a, b)\).
    실수의 삼분성: 양수, 음수, 0 가운데 하나.

되짚기

  • 완비성(1단계)을 빼면 깨진다. \(\mathbb Q\)에서 \(f(x) = x^2 - 2\)는 \([0, 2]\)에서 연속이고 \(f(0) < 0 < f(2)\)인데 유리수 근이 없다. \(S\)의 "상한"이 \(\sqrt2\)라 \(\mathbb Q\)에 없다.
  • 연속성(2, 3단계)을 빼면 깨진다. \(f(x) = -1\) (\(x < 1\)), \(1\) (\(x \ge 1\))은 \([0, 2]\)에서 0을 지나지 않는다. \(c = 1\)에서 2단계의 부호 보존이 실패한다.

더 나아가기

같은 상한 논법을 "구간을 반씩 나누며 부호가 바뀌는 쪽을 고르기"로 바꾸면 이분법이 되고, 근을 실제로 찾는 알고리즘이 됩니다(과학계산 수학24 5단원). 증명이 곧 계산법인 예이다.

직접 써 보기

홀수 차 다항식은 실근을 가짐을 위 정리로 보여라.

힌트

\(p(x) = x^n + \cdots\) (\(n\) 홀수)는 \(x \to \infty\)에서 양수, \(x \to -\infty\)에서 음수이다. 충분히 큰 \(M\)을 정확히 골라라.

답안

최고차 계수를 1로 두고 \(p(x) = x^n(1 + \frac{a_{n-1}}{x} + \dots + \frac{a_0}{x^n})\). \(|x| \ge M = 1 + 2n\max|a_i|\)이면 \(|x| \ge 1\)이라 \(\left|\frac{a_{n-k}}{x^k}\right| \le \frac{\max|a_i|}{M} < \frac1{2n}\)이고, 이런 항 \(n\)개의 합의 절댓값은 \(\frac12\)보다 작아 괄호가 양수. 그러면 \(p(M) > 0\), \(p(-M) < 0\)(\(n\) 홀수)이고, 다항식은 연속이므로 \((-M, M)\)에 근이 있다. ∎
