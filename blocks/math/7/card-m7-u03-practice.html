연속함수 연습 문제

문제 6 · 개념·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 증명\(f(x) = x^3\)이 \(x = 2\)에서 연속임을 ε-δ로 증명하여라. [03-01]

    힌트 1

    \(x^3 - 8 = (x - 2)(x^2 + 2x + 4)\). 둘째 인수를 상수로 누른다.

    힌트 2

    \(|x - 2| < 1\)이면 \(1 < x < 3\)이라 \(x^2 + 2x + 4 < 19\).

    풀이

    \(\delta = \min(1, \frac\varepsilon{19})\). \(|x - 2| < \delta\)이면 \(|x^2 + 2x + 4| < 19\)이고 \(|x^3 - 8| < 19\cdot\frac{\varepsilon}{19} = \varepsilon\). ∎

  2. 개념\(f: \mathbb R \to \mathbb R\)이 연속일 때 다음은 반드시 참인가? (a) \(f^{-1}([0, 1])\)은 닫혀 있다. (b) \(f((0, 1))\)은 열려 있다. (c) \(f([0, 1])\)은 닫힌 유계구간이다. [03-01, 03-02]

    힌트 1

    역상과 상의 차이(3.1절 주의).

    힌트 2

    (c)는 컴팩트와 연결을 함께 써라.

    풀이

    (a) 참(닫힌집합의 역상). (b) 거짓(\(f = 0\)이면 \(\{0\}\)). (c) 참: 상은 컴팩트(정리 3.2.1)이면서 연결(1.4절)이라 닫힌 유계구간(한 점일 수도 있음).

  3. 증명\(f: [0, 1] \to \mathbb R\)이 연속이고 모든 유리수 \(r\)에서 \(f(r) = 0\)이면 \(f = 0\)임을 보여라. [03-01]

    힌트 1

    수열로 본 연속을 써라.

    힌트 2

    임의의 \(x\)로 가는 유리수열이 있다.

    풀이

    \(x \in [0, 1]\)이면 조밀성으로 \(r_n \to x\)인 유리수열이 있고, 연속성으로 \(f(x) = \lim f(r_n) = 0\). ∎ (연속함수는 조밀한 집합 위의 값으로 정해진다.)

  4. 개념최대·최소 정리가 다음 각각에서 깨지는 예를 하나씩 들어라. (a) 정의역이 유계가 아닐 때 (b) 닫혀 있지 않을 때 (c) 함수가 불연속일 때 [03-02]

    힌트 1

    3.2절의 목록을 보지 말고 먼저 직접 만들어 보아라.

    힌트 2

    최댓값에 "다가가지만 닿지 않는" 함수를 만들면 된다.

    풀이

    예: (a) \([0, \infty)\)에서 \(\frac{x}{1+x}\)(상한 1, 최댓값 없음) (b) \((0, 1)\)에서 \(x\) (c) \([0, 1]\)에서 \(x\) (\(x < 1\)), \(0\) (\(x = 1\)).

  5. 증명\(f(x) = \frac{1}{1 + x^2}\)이 \(\mathbb R\)에서 균등연속임을 보여라. [03-03]

    힌트 1

    립시츠 조건을 찾아보세요(평균값 정리 또는 직접 계산).

    힌트 2

    \(|f(x) - f(y)| = \frac{|x + y||x - y|}{(1 + x^2)(1 + y^2)}\), \(\frac{|x|}{1 + x^2} \le \frac12\).

    풀이

    \(\frac{|x + y|}{(1+x^2)(1+y^2)} \le \frac{|x|}{1+x^2} + \frac{|y|}{1+y^2} \le 1\)이므로 \(|f(x) - f(y)| \le |x - y|\). \(\delta = \varepsilon\). ∎ (컴팩트가 아닌 정의역에서도 균등연속일 수 있다.)

  6. 판단한 학생이 "\(\sin(x^2)\)은 \(\mathbb R\)에서 유계이고 연속이며 각 점에서 미분 가능하므로 균등연속이다"라고 썼다. 맞는가? [03-03]

    힌트 1

    유계·연속·미분가능은 균등연속을 보장하지 않습니다(3.3절 주의).

    힌트 2

    \(x_n = \sqrt{n\pi}\), \(y_n = \sqrt{n\pi + \pi/2}\)를 보아라.

    풀이

    틀렸다. \(y_n - x_n = \frac{\pi/2}{\sqrt{n\pi + \pi/2} + \sqrt{n\pi}} \to 0\)인데 \(|\sin y_n^2 - \sin x_n^2| = |\pm1 - 0| = 1\). 진동이 점점 빨라져 균등연속이 아니다. 도함수 \(2x\cos x^2\)이 유계가 아닌 것이 단서다.
