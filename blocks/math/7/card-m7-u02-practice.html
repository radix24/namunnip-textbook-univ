수열과 급수 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 증명 문제는 답을 보기 전에 완성된 글로 써 보세요.

  1. 증명\(\displaystyle\lim_{n\to\infty}\frac{n^2 - 1}{2n^2 + n} = \frac12\)을 ε-N으로 증명하여라. [02-01]

    힌트 1

    차를 통분해 정리하세요(2.1절의 초안 → 증명 순서).

    힌트 2

    \(\left|\frac{n^2-1}{2n^2+n} - \frac12\right| = \frac{n + 2}{2(2n^2 + n)} \le \frac{3n}{4n^2} < \frac1n\) (\(n \ge 2\)).

    풀이

    \(\varepsilon > 0\)이 주어지면 \(N > \max(2, \frac1\varepsilon)\)인 자연수를 고른다. \(n \ge N\)이면 \(n + 2 \le 2n\)이라 차는 \(\frac{n+2}{2n(2n+1)} \le \frac{2n}{4n^2} = \frac1{2n} < \frac1N < \varepsilon\). ∎

  2. 개념다음 중 코시 수열인 것은? (a) \(\ln n\) (b) \(\sum_{k=1}^n\frac{(-1)^k}{k}\) (c) \(\sum_{k=1}^n\frac{1}{k\,2^k}\) (d) \(\cos n\) [02-02]

    힌트 1

    \(\mathbb R\)에서는 코시 ⇔ 수렴(2.2절).

    힌트 2

    (a) \(\ln(2n) - \ln n = \ln 2\). (d)는 \([-1, 1]\)에서 계속 흔들립니다.

    풀이

    (b) 교대급수 판정으로 수렴, (c) \(\frac1{k2^k} \le \frac1{2^k}\) 비교로 수렴 → 코시. (a)는 \(\ln(2n) - \ln n = \ln2\)가 줄지 않아 아님, (d)는 상극한 1, 하극한 \(-1\)이라 수렴하지 않으므로 아님.

  3. 계산\(a_n = \left(1 + \frac{(-1)^n}{n}\right)^n\)의 상극한과 하극한을 구하여라. [02-03]

    힌트 1

    짝수와 홀수 부분수열로 나누세요(2.3절).

    힌트 2

    \((1 + \frac1n)^n \to e\), \((1 - \frac1n)^n \to e^{-1}\).

    풀이

    짝수 번째 \(\to e\), 홀수 번째 \(\to \frac1e\). 부분수열 극한은 이 둘뿐이므로 상극한 \(e\), 하극한 \(\frac1e\). 수렴하지 않는다.

  4. 계산\(\sum_{n=1}^\infty\frac{3^n n!}{n^n}\)의 수렴을 판정하여라. [02-04]

    힌트 1

    \(n!\)이 있으면 비 판정법이 편합니다(2.4절).

    힌트 2

    비는 \(3\left(\frac{n}{n+1}\right)^n \to \frac3e\).

    풀이

    \(\frac{a_{n+1}}{a_n} = \frac{3^{n+1}(n+1)!}{(n+1)^{n+1}}\cdot\frac{n^n}{3^nn!} = 3\left(\frac{n}{n+1}\right)^n \to \frac3e \approx 1.10 > 1\). 비가 결국 늘 1보다 크므로 항이 0으로 가지 않아 발산한다. (같은 급수에서 3을 2로 바꾸면 \(\frac2e < 1\)이라 수렴.)

  5. 증명\(a_n \ge 0\)이고 \(\sum a_n\)이 수렴하면 \(\sum\sqrt{a_na_{n+1}}\)도 수렴함을 보여라. [02-04]

    힌트 1

    산술-기하 평균 부등식 \(\sqrt{xy} \le \frac{x + y}2\).

    힌트 2

    비교 판정을 쓰세요.

    풀이

    \(0 \le \sqrt{a_na_{n+1}} \le \frac{a_n + a_{n+1}}2\)이고 \(\sum\frac{a_n + a_{n+1}}{2} = \frac12\sum a_n + \frac12\sum a_{n+1}\)이 수렴하므로 비교 판정으로 수렴한다. ∎

  6. 판단한 학생이 "\(S = 1 - \frac12 + \frac13 - \frac14 + \cdots\)이면 \(2S = 2 - 1 + \frac23 - \frac12 + \frac25 - \cdots\)이고, 분모가 같은 항끼리 모으면 \((2 - 1) - \frac12 + (\frac23 - \frac13) - \frac14 + \cdots = S\), 따라서 \(2S = S\), \(S = 0\)"이라고 썼다. 어디가 틀렸는가? [02-05]

    힌트 1

    \(S = \ln 2 \ne 0\)이므로 어딘가에서 허용되지 않는 일을 했습니다.

    힌트 2

    "분모가 같은 항끼리 모으기"는 항의 순서를 바꾸는 일입니다(2.5절).

    풀이

    교대 조화급수는 조건수렴이라 항의 순서를 바꾸면 합이 달라질 수 있다(리만 재배열 정리). "분모가 같은 항끼리 모으기"는 \(2S\)의 항을 재배열한 것이라 그 합이 \(2S\)라는 보장이 없다. 실제로 재배열한 급수는 \(S\)로 수렴하지만 \(2S\)의 원래 순서 합과는 다르다.
