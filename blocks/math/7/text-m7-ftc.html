미적분학의 기본정리

본문
이 절에서 배울 것
  • 적분 함수 \(F(x) = \int_a^xf\)가 연속이고, \(f\)가 연속인 점에서 \(F' = f\)임을 증명한다(기본정리 1).
  • \(F' = f\)이고 \(f\)가 적분 가능하면 \(\int_a^bf = F(b) - F(a)\)임을 증명한다(기본정리 2).
  • 부분적분을 기본정리로 증명한다.
먼저 알아야 할 것
  • 적분의 성질 (5.2절), 평균값 정리 (4.1절).

5.3.1넓이를 미분하면

적분은 넓이(합의 극한), 미분은 기울기(차의 극한)로 서로 무관하게 정의되었습니다. 둘이 서로 역연산이라는 놀라운 사실이 기본정리입니다. 고교에서는 그림으로 받아들였지만, 이제 상합·하합의 정의와 평균값 정리로 증명합니다.

정리 5.3.1 (기본정리 1)

\(f \in \mathcal R\)이 \([a, b]\)에서 적분 가능하고 \(F(x) = \int_a^xf(t)\,dt\)라 하자. 그러면 \(F\)는 \([a, b]\)에서 (립시츠) 연속이고, \(f\)가 \(x_0\)에서 연속이면 \(F'(x_0) = f(x_0)\)이다.

증명.\(|f| \le M\)이라 하면 \(x < y\)일 때 \(|F(y) - F(x)| = \left|\int_x^yf\right| \le M(y - x)\)이므로 연속이다. 다음으로 \(f\)가 \(x_0\)에서 연속이면 \(\varepsilon\)에 대해 \(|t - x_0| < \delta\)에서 \(|f(t) - f(x_0)| < \varepsilon\)인 \(\delta\)가 있다. \(0 < |h| < \delta\)이면

\[\left|\frac{F(x_0 + h) - F(x_0)}{h} - f(x_0)\right| = \left|\frac1h\int_{x_0}^{x_0+h}[f(t) - f(x_0)]\,dt\right| \le \varepsilon.\]

(구간 가법성으로 차분몫을 적분 하나로 쓰고, \(f(x_0) = \frac1h\int_{x_0}^{x_0+h}f(x_0)\,dt\)를 빼서 단조성으로 어림했다.) 곧 차분몫이 \(f(x_0)\)로 수렴한다. ∎

"넓이 함수의 기울기는 높이"라는 그림 그대로입니다. 폭 \(h\)의 띠의 넓이는 높이 \(f(x_0)\) 곱하기 \(h\)와 거의 같고, \(f\)가 연속이라 그 오차가 \(\varepsilon h\) 이하입니다.

5.3.2도함수를 알면 적분이 나온다

정리 5.3.2 (기본정리 2)

\(f \in \mathcal R\)이 \([a, b]\)에서 적분 가능하고, 미분 가능한 \(F\)가 \(F' = f\)를 만족하면 \(\int_a^bf = F(b) - F(a)\).

증명.임의의 분할 \(P\)에서 각 조각에 평균값 정리를 쓰면 \(F(x_i) - F(x_{i-1}) = f(t_i)\Delta x_i\)인 \(t_i\)가 있다. 더하면 망원급수로 \(F(b) - F(a) = \sum f(t_i)\Delta x_i\)이고, 이 값은 \(L(P) \le \cdot \le U(P)\) 사이에 있다. 적분도 그 사이에 있으므로 \(\left|F(b) - F(a) - \int f\right| \le U(P) - L(P)\). 적분 가능이라 오른쪽을 \(\varepsilon\)보다 작게 만들 수 있다. ∎

이 증명은 \(f\)의 연속성을 쓰지 않습니다. 대신 "\(f\)가 적분 가능"이라는 가정이 필요합니다. 도함수가 존재해도 적분 가능하지 않은 예가 있기 때문입니다(볼테라의 함수).

예제 5.3.3

\(G(x) = \displaystyle\int_0^{x^2}\sqrt{1 + t^3}\,dt\)의 도함수를 구하여라.

풀이. \(F(u) = \int_0^u\sqrt{1 + t^3}\,dt\)로 두면 피적분함수가 연속이라 \(F'(u) = \sqrt{1 + u^3}\)(기본정리 1). \(G(x) = F(x^2)\)이므로 연쇄 법칙으로 \(G'(x) = \sqrt{1 + x^6}\cdot2x\). 적분을 계산하지 않고(사실 초등함수로 쓸 수 없음) 도함수를 얻었습니다.

5.3.3부분적분

\(F, G\)가 미분 가능하고 \(F' = f\), \(G' = g\)가 적분 가능하면 \((FG)' = fG + Fg\)에 기본정리 2를 써서

\[\int_a^bF(x)g(x)\,dx = F(b)G(b) - F(a)G(a) - \int_a^bf(x)G(x)\,dx.\]

(\(fG\), \(Fg\)는 적분 가능한 함수와 연속함수의 곱이라 적분 가능합니다.) 치환적분도 같은 방식으로 연쇄 법칙과 기본정리에서 나옵니다.

주의기본정리 1에서 "\(f\)가 \(x_0\)에서 연속"이라는 조건을 빼면 \(F'(x_0) = f(x_0)\)이 깨집니다. \(f\)가 0에서 0, 그 밖에서 1인 함수면 \(F(x) = x\)라 \(F'(0) = 1 \ne 0 = f(0)\)입니다. 적분은 한 점의 값을 보지 못합니다.
요약
  1. 기본정리 1: \(F(x) = \int_a^xf\)는 연속이고, \(f\)가 연속인 점에서 \(F' = f\).
  2. 기본정리 2: \(F' = f\)이고 \(f\)가 적분 가능하면 \(\int_a^bf = F(b) - F(a)\). 평균값 정리 + 망원급수.
  3. 부분적분과 치환적분은 곱·연쇄 법칙과 기본정리 2에서 나온다.

5.3.4연습문제

기본

  1. \(\frac{d}{dx}\int_x^{2x}\frac{\sin t}{t}\,dt\)를 구하여라 (\(x > 0\)).
    답

    \(\frac{\sin2x}{2x}\cdot2 - \frac{\sin x}{x} = \frac{\sin2x - \sin x}{x}\).

응용

  1. \(f\)가 연속이고 모든 \(x\)에서 \(\int_0^xf = \int_x^1f\)이면 \(f = 0\)임을 보여라.
    답

    양변을 미분하면 \(f(x) = -f(x)\).

  2. 부분적분으로 \(\int_0^1xe^x\,dx\)를 구하여라.
    답

    \([xe^x]_0^1 - \int_0^1e^x = e - (e - 1) = 1\).

심화

  1. \(f\)가 \([a, b]\)에서 연속이면 \(\int_a^bf = f(c)(b - a)\)인 \(c\)가 있음(적분의 평균값 정리)을 보여라.
    답

    \(F(x) = \int_a^xf\)에 평균값 정리: \(F(b) - F(a) = F'(c)(b - a) = f(c)(b - a)\).
