적분 가능한 함수들

본문

연속함수는 적분 가능할까? 그림으로는 당연해 보이지만, 리만 조건으로 증명하려면 조각마다의 진동을 한꺼번에 눌러야 한다. 또 불연속점이 무한히 많은 함수는 어떨까? 증가하기만 하는 계단 함수가 무한히 많이 뛰어도 넓이를 가질까?

먼저 알아야 할 것리만 조건(5.1절), 균등연속(3.3절)을 쓴다.

5.2.1연속이면 적분 가능

리만 조건은 진동과 폭을 곱해 더한 것을 작게 만드는 분할을 요구한다. 연속함수라면 조각을 잘게 만들수록 각 조각의 진동 \(M_i - m_i\)가 작아질 것 같다. 그런데 모든 조각에서 동시에 작아지려면, 조각의 위치와 상관없이 같은 폭으로 진동을 누를 수 있어야 한다. 바로 균등연속이다.

정리 5.2.1

\(f\)가 \([a, b]\)에서 연속이면 모든 증가함수 \(\alpha\)에 대해 \(f \in \mathcal R(\alpha)\)이다.

증명.\(\varepsilon > 0\)이 주어지면 \(\eta[\alpha(b) - \alpha(a)] < \varepsilon\)인 \(\eta > 0\)을 고른다. \([a, b]\)는 컴팩트이므로 정리 3.3.3에 따라 \(f\)는 균등연속이고, \(|x - t| < \delta\)이면 \(|f(x) - f(t)| < \eta\)인 \(\delta\)가 있다. 모든 조각의 폭이 \(\delta\)보다 작은 분할 \(P\)를 잡으면, 최대·최소 정리로 각 조각에서 최댓값과 최솟값이 있고 그 두 점의 거리가 \(\delta\)보다 작으므로 \(M_i - m_i < \eta\)이다. 따라서 \(U - L = \sum(M_i - m_i)\Delta\alpha_i < \eta\sum\Delta\alpha_i = \eta[\alpha(b) - \alpha(a)] < \varepsilon\)이고, 리만 조건으로 적분 가능하다. ∎

균등연속 대신 그냥 연속만 쓰면 \(\delta\)가 점마다 달라 모든 조각의 폭이 \(\delta\)보다 작은 분할을 정할 수 없다. 그러므로 3.3절의 정리가 여기서 결정적으로 쓰였다.

5.2.2단조이면 적분 가능

정리 5.2.2

\(f\)가 \([a, b]\)에서 단조함수이면 \(f \in \mathcal R\) (\(\alpha(x) = x\))이다.

증명.\(f\)가 증가한다고 하자. \(n\)등분 분할에서 각 조각의 최댓값은 오른쪽 끝, 최솟값은 왼쪽 끝의 값이므로 \(U - L = \sum_{i=1}^n[f(x_i) - f(x_{i-1})]\frac{b - a}{n} = \frac{b - a}{n}[f(b) - f(a)]\)이다. 합이 앞뒤로 지워지는 망원급수이기 때문이며, 이것은 \(n\)을 키우면 \(\varepsilon\)보다 작아진다. ∎

단조함수는 불연속점이 가산 무한 개일 수 있다. 예를 들어 \(\frac1{n+1} < x \le \frac1n\)에서 \(f(x) = \frac1n\)인 계단 함수가 그렇다. 그래도 적분 가능하며, 증명의 요점은 그림 1처럼 진동의 합이 전체 높이 \(f(b) - f(a)\)로 묶인다는 것이다.

5.2.3적분의 성질

다음 성질들은 모두 상합과 하합의 부등식에서 나온다(Rudin 6.12). 먼저 선형성으로, \(f, g \in \mathcal R(\alpha)\)이면 \(\int(cf + g)\,d\alpha = c\int f\,d\alpha + \int g\,d\alpha\)이다. 다음으로 단조성으로, \(f \le g\)이면 \(\int f\,d\alpha \le \int g\,d\alpha\)이고, 특히 \(|f| \le M\)이면 \(\left|\int f\,d\alpha\right| \le M[\alpha(b) - \alpha(a)]\)이다. 또 구간 가법성으로, \(a < c < b\)이면 \(\int_a^b = \int_a^c + \int_c^b\)이다. 끝으로 \(f, g \in \mathcal R\)이면 \(fg\)와 \(|f|\)도 적분 가능하고 \(\left|\int f\right| \le \int|f|\)이다.

예제 5.2.3

\(\displaystyle\left|\int_0^1\frac{\sin(100x)}{1 + x^2}\,dx\right| \le \frac\pi4\)임을 보여라.

풀이. 피적분함수는 연속이므로 적분 가능하고, \(|\sin(100x)| \le 1\)이므로 \(\left|\frac{\sin100x}{1+x^2}\right| \le \frac{1}{1+x^2}\)이다. 단조성과 \(\left|\int f\right| \le \int|f|\)로 \(\left|\int\right| \le \int_0^1\frac{dx}{1+x^2} = \arctan1 = \frac\pi4\)이다. 사실 실제 값은 약 0.006으로 훨씬 작은데, 빠른 진동이 서로 지우기 때문이다(6단원의 리만-르베그 정리와 수학15).

흔한 오해적분 가능한 함수의 합성은 적분 가능하다고 여기기 쉽지만 일반적으로 틀렸다. 연속함수 \(\varphi\)와 적분 가능한 \(f\)의 합성 \(\varphi\circ f\)는 적분 가능하지만(Rudin 6.11), 적분 가능한 함수끼리의 합성은 아닐 수 있다. 가령 적분 가능한 토매 함수에, 0에서 0이고 그 밖에서 1인 적분 가능한 함수를 합성하면 디리클레 함수가 된다.
마무리

처음 질문의 답은 둘 다 "그렇다"이다. 연속함수는 \([a, b]\)에서 균등연속이므로 모든 조각의 진동을 한꺼번에 누를 수 있어 적분 가능하다. 단조함수는 불연속점이 무한히 많아도, 진동의 합이 전체 높이 \(f(b) - f(a)\)로 묶여 \(U - L = \frac{b - a}{n}[f(b) - f(a)]\)이 되므로 적분 가능하다. 적분은 선형이고 단조이며 구간 가법적이고, \(\left|\int f\right| \le \int|f|\)이다.

5.2.4연습문제

기본

  1. \(f(x) = \lfloor 3x\rfloor\)는 \([0, 1]\)에서 적분 가능한가? 값은?
    답

    증가함수라 적분 가능. 값 \(0\cdot\frac13 + 1\cdot\frac13 + 2\cdot\frac13 + 3\cdot0 = 1\).

응용

  1. \(f\)가 \([a, b]\)에서 연속이고 \(f \ge 0\), \(\int_a^bf = 0\)이면 \(f = 0\)임을 보여라.
    답

    \(f(c) > 0\)이면 연속성으로 \(c\) 근처의 길이 \(\ell > 0\)인 구간에서 \(f > \frac{f(c)}2\)라 \(\int f \ge \frac{f(c)}2\ell > 0\). 모순.

심화

  1. 적분 가능한 \(f, g\)에 대해 \(\left(\int fg\right)^2 \le \int f^2\int g^2\)(코시-슈바르츠)를 증명하여라.
    답

    모든 \(t\)에서 \(\int(f - tg)^2 \ge 0\)을 전개해 판별식(선형대수(1) 7.1절과 같은 논법).
