절대수렴과 조건수렴, 리만 재배열 정리

본문

유한 개의 수를 더할 때는 순서를 바꿔도 합이 같다. 무한히 많은 수를 더하는 급수에서도 그럴까? \(1 - \frac12 + \frac13 - \frac14 + \cdots = \ln 2\)인데, 같은 항들을 "양수 둘, 음수 하나" 순서로 더하면 다른 값이 나온다. 언제 순서가 중요하고 언제 그렇지 않을까?

먼저 알아야 할 것급수의 수렴과 비교 판정(2.4절), 단조수렴 정리(2.1절)를 쓴다.

2.5.1교대급수

정리 2.5.1 (교대급수 판정법)

\(b_n\)이 감소하며 0으로 가면 \(\sum(-1)^{n+1}b_n\)은 수렴하고, 합 \(s\)와 부분합의 차는 \(|s - s_n| \le b_{n+1}\)이다.

증명.부분합을 짝수 번째와 홀수 번째로 나눈다. 짝수 번째 부분합 \(s_{2n} = (b_1 - b_2) + (b_3 - b_4) + \cdots\)는 괄호가 모두 0 이상이므로 증가하고, 같은 이유로 홀수 번째는 감소한다. 또 \(s_{2n} \le s_{2n+1} \le s_1\)이므로 둘 다 유계이고, 단조수렴 정리로 각각 수렴한다. 둘 사이의 차 \(b_{2n+1}\)이 0으로 가므로 같은 값 \(s\)로 모이며, \(s\)는 이웃한 두 부분합 사이에 있으므로 \(|s - s_n| \le b_{n+1}\)이다. ∎

\(\sum|a_n|\)이 수렴하면 절대수렴한다고 하며, 그러면 비교 판정으로 \(\sum a_n\)도 수렴한다. \(\sum a_n\)은 수렴하지만 \(\sum|a_n|\)은 발산하면 조건수렴한다고 하며, 교대 조화급수가 대표 예이다.

2.5.2절대수렴이면 순서가 상관없다

정리 2.5.2

\(\sum a_n\)이 절대수렴하면, 항의 순서를 어떻게 바꾼 급수(재배열)도 수렴하고 합이 같다.

증명.\(\varepsilon > 0\)이 주어지면 \(\sum|a_n|\)이 수렴하므로 \(\sum_{n > N}|a_n| < \varepsilon\)인 \(N\)이 있다. 재배열한 급수도 충분히 많은 \(M\)개 항을 더하면 \(a_1, \dots, a_N\)을 모두 포함한다. 그러면 재배열한 부분합과 원래 부분합 \(s_m\) (\(m \ge N\))의 차에는 번호가 \(N\)보다 큰 항들만 남고, 그 절댓값 합은 \(\varepsilon\)보다 작다. 따라서 두 급수는 같은 값으로 수렴한다. ∎

2.5.3조건수렴이면 무엇이든 된다

정리 2.5.3 (리만 재배열 정리)

\(\sum a_n\)이 조건수렴하면, 임의의 실수 \(T\)에 대해 합이 \(T\)가 되도록 항을 재배열할 수 있다. \(\pm\infty\)로 발산하게도 할 수 있다.

증명의 처방은 단순하다. 양수 항들을 \(p_1, p_2, \dots\), 음수 항들의 절댓값을 \(q_1, q_2, \dots\)라 하자. 조건수렴이므로 두 가지가 성립한다. 첫째, \(\sum p_k = \infty\)이고 \(\sum q_k = \infty\)이다. 둘 다 수렴하면 절대수렴이고, 하나만 발산하면 원래 급수가 발산하기 때문이다. 둘째, 원래 급수가 수렴하므로 \(a_n \to 0\)이고, 따라서 \(p_k \to 0\), \(q_k \to 0\)이다.

이제 부분합이 \(T\)를 넘을 때까지 양수 항을 차례로 더하고, 다시 \(T\) 아래로 내려갈 때까지 음수 항을 더하는 것을 되풀이한다. 첫째 성질 덕분에 양쪽 다 무한히 공급되므로 매번 넘거나 내려갈 수 있다. 또 둘째 성질 덕분에 넘친 양이 마지막에 더한 항보다 작아 0으로 줄어든다. 그래서 부분합이 \(T\)로 수렴한다. 같은 절의 탐구 카드에서 \(T\)를 정하고 이 과정을 직접 볼 수 있다.

예제 2.5.4

\(1 - \frac12 + \frac13 - \cdots = \ln 2\)를 써서, 양수 둘, 음수 하나 순서인 \(1 + \frac13 - \frac12 + \frac15 + \frac17 - \frac14 + \cdots\)의 합을 구하여라.

풀이. \(L = \ln2\)이라 하자. 원래 급수의 절반 \(\frac12 - \frac14 + \frac16 - \frac18 + \cdots = \frac L2\)를 0을 끼워 \(0 + \frac12 + 0 - \frac14 + 0 + \frac16 + \cdots\)로 쓰고 원래 급수와 항별로 더한다. 수렴하는 두 급수는 항별로 더할 수 있으므로 \(1 + 0 + \frac13 - \frac12 + \frac15 + 0 + \frac17 - \frac14 + \cdots = \frac32L\)이다. 0을 지우면 바로 문제의 급수이므로 합은 \(\frac32\ln2 \approx 1.0397\)이다. 즉 같은 항을 다른 순서로 더해 다른 합이 나왔으며, 그림 1이 이것을 보여 준다.

흔한 오해계산 중 무한급수의 항을 마음대로 묶거나 순서를 바꿔도 된다고 여기기 쉽다. 가령 \(1 - 1 + 1 - 1 + \cdots\)를 \((1 - 1) + (1 - 1) + \cdots = 0\)으로도, \(1 + (-1 + 1) + \cdots = 1\)로도 계산할 수 있지만, 이 급수는 수렴하지 않는다. 순서를 바꾸기 전에 절대수렴을 확인해야 한다.
마무리

처음 질문에 답하면, 절대수렴하는 급수는 재배열해도 합이 같지만 조건수렴하는 급수는 순서가 중요하다. 교대 조화급수는 조건수렴하므로, 양수 둘, 음수 하나 순서로 더하면 \(\ln2\) 대신 \(\frac32\ln2\)가 된다. 리만 재배열 정리에 따르면 양수 부분과 음수 부분이 각각 발산하고 항이 0으로 가므로, 재배열로 어떤 합이든 만들 수 있다. 교대급수 판정법은 감소하며 0으로 가는 \(b_n\)의 교대합이 수렴하고 오차가 다음 항 이하임을 말해 준다.

2.5.4연습문제

기본

  1. \(\sum\frac{(-1)^n}{\sqrt n}\)은 절대수렴, 조건수렴, 발산 가운데 무엇인가?
    답

    조건수렴(교대급수 판정으로 수렴, \(\sum\frac1{\sqrt n}\)은 발산).

  2. \(1 - \frac12 + \frac13 - \cdots\)의 합을 오차 0.01 이내로 구하려면 몇 항이 필요한가?
    답

    \(b_{n+1} = \frac1{n+1} \le 0.01\), 곧 99항.

응용

  1. \(\sum\frac{(-1)^n}{n^2}\)을 재배열하면 합이 바뀔 수 있는가?
    답

    아니다. 절대수렴(\(\sum\frac1{n^2}\) 수렴)이므로 어떤 재배열도 같은 합.

심화

  1. 교대 조화급수를 "양수 하나, 음수 둘"의 순서로 재배열하면 합이 \(\frac12\ln2\)임을 보여라.
    힌트

    \((1 - \frac12) - \frac14 + (\frac13 - \frac16) - \frac18 + \cdots\)로 묶어 보아라.

    답

    세 항씩 묶으면 \(\frac1{2k-1} - \frac1{4k-2} - \frac1{4k} = \frac1{4k-2} - \frac1{4k} = \frac12\left(\frac1{2k-1} - \frac1{2k}\right)\). 합은 원래 급수의 절반, \(\frac12\ln2\). (세 항씩 묶은 부분합이 수렴하고 항이 0으로 가므로 묶지 않은 급수도 같은 합.)
