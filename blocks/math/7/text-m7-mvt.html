4.1.1극값과 도함수

미분 가능성의 정의는 공통1과 같습니다: \(f'(x) = \lim_{t\to x}\frac{f(t) - f(x)}{t - x}\). 이 단원의 목표는 도함수의 정보(국소적인 기울기)에서 함수의 전체 모양(증가, 감소, 근사 오차)을 끌어내는 정리들을 증명하는 것입니다. 그 출발점이 다음 관찰입니다.

정리 4.1.1 (페르마)

\(f\)가 열린구간 안의 점 \(x\)에서 극댓값(또는 극솟값)을 갖고 \(x\)에서 미분 가능하면 \(f'(x) = 0\).

증명.극댓값이면 \(x\) 근처에서 \(f(t) \le f(x)\)이다. \(t > x\)이면 \(\frac{f(t) - f(x)}{t - x} \le 0\)이라 오른쪽 극한은 \(\le 0\), \(t < x\)이면 \(\ge 0\)이라 왼쪽 극한은 \(\ge 0\). 두 극한이 모두 \(f'(x)\)이므로 \(f'(x) = 0\). ∎

4.1.2평균값 정리

정리 4.1.2 (코시의 평균값 정리)

\(f, g\)가 \([a, b]\)에서 연속이고 \((a, b)\)에서 미분 가능하면 \([f(b) - f(a)]g'(x) = [g(b) - g(a)]f'(x)\)인 \(x \in (a, b)\)가 있다. 특히 \(g(t) = t\)이면 \(f(b) - f(a) = (b - a)f'(x)\) (평균값 정리).

아이디어: 끝점에서 값이 같아지도록 만든 보조함수 \(h\)에 최대·최소 정리와 페르마 정리를 씁니다(롤 정리의 방법).

증명.\(h(t) = [f(b) - f(a)]g(t) - [g(b) - g(a)]f(t)\)로 두면 \(h\)는 \([a, b]\)에서 연속, \((a, b)\)에서 미분 가능하고, 계산하면 \(h(a) = f(b)g(a) - f(a)g(b) = h(b)\)이다. \(h\)가 상수이면 모든 \(x\)에서 \(h'(x) = 0\). 아니면 \(h(a)\)와 다른 값이 있고, 최대·최소 정리로 \(h\)의 최댓값이나 최솟값 가운데 하나는 \(h(a) = h(b)\)와 다르므로 내부의 점 \(x\)에서 생긴다. 페르마 정리로 \(h'(x) = 0\)이고, 이것이 결론의 식이다. ∎

평균값 정리의 뜻은 "평균 변화율과 같은 순간 변화율이 어딘가에 있다"입니다. 같은 절의 탐구 카드에서 할선과 평행한 접선을 찾아볼 수 있습니다. 바로 나오는 결과: \((a, b)\)에서 \(f' \ge 0\)이면 \(f\)는 증가, \(f' = 0\)이면 상수입니다(\(f(y) - f(x) = (y - x)f'(c)\)). 이 사실은 고교에서 당연시했지만 완비성(최대·최소 정리)에 기대고 있습니다.

4.1.3테일러 정리

평균값 정리는 "\(f(b) = f(a) + (\text{오차})\)이고 오차는 \(f'(x)(b - a)\)"라는 0차 근사의 오차 공식입니다. 이것을 \(n - 1\)차 다항식 근사로 넓힌 것이 테일러 정리입니다.

정리 4.1.3 (테일러, 라그랑주 나머지)

\(f^{(n-1)}\)이 \([\alpha, \beta]\)에서 연속이고 \(f^{(n)}\)이 \((\alpha, \beta)\)에서 존재하면, \(P(t) = \sum_{k=0}^{n-1}\frac{f^{(k)}(\alpha)}{k!}(t - \alpha)^k\)에 대해

\[f(\beta) = P(\beta) + \frac{f^{(n)}(x)}{n!}(\beta - \alpha)^n\]

인 \(x\)가 \(\alpha\)와 \(\beta\) 사이에 있다.

증명.\(M\)을 \(f(\beta) = P(\beta) + M(\beta - \alpha)^n\)이 되게 정의하고 \(g(t) = f(t) - P(t) - M(t - \alpha)^n\)으로 두자. 목표는 \(n!M = f^{(n)}(x)\)인 \(x\)를 찾는 것이다. \(P\)의 \(k\)계 도함수가 \(\alpha\)에서 \(f\)의 것과 같으므로(\(k \le n - 1\)) \(g(\alpha) = g'(\alpha) = \dots = g^{(n-1)}(\alpha) = 0\)이고, \(M\)의 정의로 \(g(\beta) = 0\)이다. 평균값 정리(롤)를 \(g\)에 쓰면 \(g'(x_1) = 0\)인 \(x_1\)이 \(\alpha, \beta\) 사이에 있다. \(g'(\alpha) = g'(x_1) = 0\)이므로 다시 롤을 쓰면 \(g''(x_2) = 0\)인 \(x_2\)가 \(\alpha, x_1\) 사이에 있다. \(n\)번 되풀이하면 \(g^{(n)}(x_n) = 0\)인 \(x_n\)이 있고, \(g^{(n)}(t) = f^{(n)}(t) - n!M\)(\(P\)는 \(n - 1\)차라 \(n\)번 미분하면 0)이므로 \(f^{(n)}(x_n) = n!M\). ∎

예제 4.1.4

\(e\)를 \(1 + 1 + \frac1{2!} + \dots + \frac1{9!}\)로 근사할 때 오차를 어림하고, \(e\)가 무리수임을 보여라.

풀이. \(f = e^t\), \(\alpha = 0\), \(\beta = 1\), \(n = 10\)으로 쓰면 오차는 \(\frac{e^x}{10!}\) (\(0 < x < 1\))이라 \(\frac{3}{10!} \approx 8.3\times10^{-7}\) 이하입니다. 무리수: \(e = \frac pq\)라 하고 \(n > q\)로 테일러 정리를 쓰면 \(n!e = n!\sum_{k<n}\frac1{k!} + \frac{e^x}{n}\)에서 왼쪽과 첫째 항은 정수인데 \(0 < \frac{e^x}{n} < \frac3n < 1\)은 정수가 아니므로 모순입니다.

주의평균값 정리의 \(x\)는 존재할 뿐 위치를 알려 주지 않으며, 하나라는 보장도 없습니다. 또 미분 가능성이 깨지면 정리도 깨집니다: \(|t|\)는 \([-1, 1]\)에서 끝값이 같지만 도함수가 0인 점이 없습니다(0에서 미분 불가능).
요약
  1. 내부 극값에서 미분 가능하면 도함수가 0(페르마).
  2. 보조함수 + 최대·최소 정리 + 페르마 = 롤 → 평균값 정리, 코시 평균값 정리.
  3. 테일러 정리: 오차 = \(\frac{f^{(n)}(x)}{n!}(\beta - \alpha)^n\). 롤을 \(n\)번 쓴다.

4.1.4연습문제

기본

  1. \(|\sin a - \sin b| \le |a - b|\)를 평균값 정리로 보여라.
    답

    \(\sin a - \sin b = \cos x\,(a - b)\), \(|\cos x| \le 1\).

  2. \(\cos 0.1\)을 \(1 - \frac{0.1^2}2\)로 근사할 때 오차를 어림하여라.
    답

    \(n = 4\)로 쓰면(3차 항이 0) \(\frac{|\cos x|}{24}0.1^4 \le 4.2\times10^{-6}\).

응용

  1. \(x > 0\)이면 \(\frac{x}{1 + x} < \ln(1 + x) < x\)임을 보여라.
    답

    \(\ln(1 + x) - \ln 1 = \frac{x}{1 + c}\), \(0 < c < x\).

심화

  1. 코시의 평균값 정리로 로피탈 법칙(\(\frac00\) 꼴, \(x \to a^+\))을 증명하여라.
    답

    \(f(a) = g(a) = 0\)으로 두고 \(\frac{f(x)}{g(x)} = \frac{f(x) - f(a)}{g(x) - g(a)} = \frac{f'(c)}{g'(c)}\) (\(a < c < x\)). \(x \to a^+\)이면 \(c \to a^+\)이므로 \(\frac{f'}{g'}\)의 극한과 같다.
