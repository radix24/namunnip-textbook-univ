수열의 수렴

본문
이 절에서 배울 것
  • 거리공간에서 수열의 수렴을 ε-N으로 정의하고 극한의 유일성을 증명한다.
  • 초안(N 찾기) → 정리된 증명의 순서로 수렴을 증명한다.
  • 극한 법칙과 단조수렴 정리를 쓴다.
먼저 알아야 할 것
  • 아르키메데스 성질 (1.1절), 거리공간 (1.2절), 공통1의 ε-δ 카드.

2.1.1정의

고교에서는 "\(n\)이 한없이 커질 때 \(a_n\)이 \(L\)에 한없이 가까워진다"를 수렴이라 불렀습니다. "한없이"는 직관적이지만 증명에 쓸 수 없습니다. 이것을 "얼마나 가까워야 하는지(\(\varepsilon\))를 상대가 정하면, 그 다음부터는 늘 그만큼 가까운 번호(\(N\))를 우리가 내놓을 수 있다"로 바꿉니다.

정의 2.1.1 (수렴)

거리공간 \((X, d)\)의 수열 \((p_n)\)이 \(p \in X\)로 수렴한다는 것은, 모든 \(\varepsilon > 0\)에 대해 자연수 \(N\)이 있어 \(n \ge N\)이면 \(d(p_n, p) < \varepsilon\)인 것이다. 이때 \(p_n \to p\) 또는 \(\lim p_n = p\)로 쓴다.

문장을 구절별로 읽어 봅시다. "모든 \(\varepsilon\)"이 먼저 오고 "\(N\)이 있다"가 뒤에 오므로 \(N\)은 \(\varepsilon\)에 따라 달라도 됩니다. "\(n \ge N\)이면"은 앞쪽 유한 개의 항은 무시해도 된다는 뜻입니다. 같은 절의 탐구 카드(ε-N 게임)에서 이 구조를 그림으로 볼 수 있습니다.

정리 2.1.2 (극한의 유일성)

\(p_n \to p\)이고 \(p_n \to q\)이면 \(p = q\).

증명.\(\varepsilon > 0\)을 잡자. \(n \ge N_1\)이면 \(d(p_n, p) < \varepsilon/2\), \(n \ge N_2\)이면 \(d(p_n, q) < \varepsilon/2\)인 \(N_1, N_2\)가 있다. \(n = \max(N_1, N_2)\)에서 삼각부등식으로 \(d(p, q) \le d(p, p_n) + d(p_n, q) < \varepsilon\). 모든 \(\varepsilon > 0\)에 대해 \(d(p, q) < \varepsilon\)이므로 \(d(p, q) = 0\), 곧 \(p = q\). ∎

"모든 \(\varepsilon > 0\)에 대해 \(0 \le x < \varepsilon\)이면 \(x = 0\)"은 해석학에서 계속 쓰는 논법입니다(\(x > 0\)이라면 \(\varepsilon = x\)로 모순).

2.1.2초안에서 증명으로

예제 2.1.3

\(\displaystyle\lim_{n\to\infty}\frac{3n + 1}{n + 2} = 3\)을 증명하여라.

초안. 목표 \(\left|\frac{3n+1}{n+2} - 3\right| < \varepsilon\)을 정리하면 \(\left|\frac{3n + 1 - 3n - 6}{n + 2}\right| = \frac{5}{n + 2}\)입니다. \(\frac5{n+2} < \frac5n\)이므로 \(\frac5n < \varepsilon\), 곧 \(n > \frac5\varepsilon\)이면 충분합니다. \(N\)은 \(\frac5\varepsilon\)보다 큰 자연수로 고르면 됩니다.

정리된 증명.\(\varepsilon > 0\)이 주어졌다고 하자. 아르키메데스 성질로 \(N > \frac5\varepsilon\)인 자연수 \(N\)을 고른다. \(n \ge N\)이면 \(\left|\frac{3n+1}{n+2} - 3\right| = \frac5{n+2} < \frac5n \le \frac5N < \varepsilon\). ∎

초안은 결론에서 거꾸로 가며 \(N\)을 찾고, 정리된 증명은 찾은 \(N\)을 먼저 내놓고 앞으로 갑니다. 초안에서 \(\frac5{n+2}\)를 \(\frac5n\)으로 키운 것처럼, 정확한 \(N\)이 아니라 "통하는" \(N\)이면 됩니다.

2.1.3극한 법칙과 유계성

정리 2.1.4

(a) 수렴하는 수열은 유계이다. (b) 실수열 \(a_n \to a\), \(b_n \to b\)이면 \(a_n + b_n \to a + b\), \(a_nb_n \to ab\), \(b \ne 0\)이면 \(\frac{a_n}{b_n} \to \frac ab\).

(a)는 \(\varepsilon = 1\)로 정의를 쓰면 \(n \ge N\)인 항은 모두 \(a\)에서 1 이내이고, 그 앞의 항은 유한 개라 최댓값이 있기 때문입니다. (b)의 곱은 \(|a_nb_n - ab| \le |a_n||b_n - b| + |b||a_n - a|\)로 나누고, (a)로 \(|a_n|\)을 상수로 누릅니다. 공통1의 함수의 극한 법칙과 같은 논법입니다.

정리 2.1.5 (단조수렴 정리)

증가하고 위로 유계인 실수열은 상한으로 수렴한다.

증명.\(s = \sup\{a_n\}\)(완비성). \(\varepsilon > 0\)이면 \(a_N > s - \varepsilon\)인 \(N\)이 있고(상한의 성질), 증가하므로 \(n \ge N\)에서 \(s - \varepsilon < a_N \le a_n \le s\). ∎

이 정리는 극한값을 미리 몰라도 수렴을 보장합니다. 예를 들어 \(a_n = (1 + \frac1n)^n\)이 증가하고 3보다 작음을 보이면(이항정리) 수렴하고, 그 극한을 \(e\)로 정의합니다.

주의"\(a_{n+1} - a_n \to 0\)이면 수렴한다"는 틀립니다. \(a_n = \sqrt n\)이나 \(a_n = 1 + \frac12 + \dots + \frac1n\)은 이웃한 항의 차가 0으로 가지만 발산합니다. 이웃한 항이 아니라 모든 먼 항끼리 가까워야 한다는 것이 다음 절의 코시 수열입니다.
요약
  1. \(p_n \to p\): 모든 \(\varepsilon\)에 대해 \(N\)이 있어 \(n \ge N\)이면 \(d(p_n, p) < \varepsilon\). \(N\)은 \(\varepsilon\)에 따라 다르다.
  2. 극한은 하나뿐이다(삼각부등식과 ε/2).
  3. 증명은 초안으로 \(N\)을 찾은 뒤 정리된 증명으로 쓴다.
  4. 수렴하면 유계. 단조이고 유계이면 수렴(완비성).

2.1.4연습문제

기본

  1. \(\lim\frac{2n^2}{n^2 + 1} = 2\)를 ε-N으로 증명하여라.
    답

    차 \(\frac2{n^2+1} < \frac2n\). \(N > \frac2\varepsilon\).

  2. \(a_n = (-1)^n\)이 수렴하지 않음을 정의로 보여라.
    답

    극한 \(L\)이 있다면 \(\varepsilon = 1\)에 대해 큰 \(n\)에서 \(|1 - L| < 1\), \(|-1 - L| < 1\)이라 \(2 \le |1 - L| + |L + 1| < 2\). 모순.

응용

  1. \(a_1 = 1\), \(a_{n+1} = \sqrt{2 + a_n}\)이 수렴함을 보이고 극한을 구하여라.
    답

    귀납법으로 \(a_n < 2\)이고 증가. 단조수렴 정리로 수렴, 극한 \(L = \sqrt{2 + L}\)에서 \(L = 2\).

심화

  1. \(a_n \to a\)이면 산술평균 \(\frac{a_1 + \dots + a_n}{n} \to a\)임을 보여라. 거꾸로는?
    힌트

    앞쪽 \(N\)개와 뒤쪽을 나누고, 앞쪽의 합은 고정된 수라 \(n\)으로 나누면 0으로 갑니다.

    답

    \(|a_k - a| < \varepsilon/2\) (\(k > N\))로 잡으면 평균과 \(a\)의 차는 \(\frac{1}{n}\sum_{k\le N}|a_k - a| + \frac\varepsilon2\)보다 작고, 첫 항은 \(n\)이 크면 \(\varepsilon/2\)보다 작다. 거꾸로는 틀림: \((-1)^n\)의 평균은 0으로 수렴(체사로 합, 수학15의 페예르 평균).
