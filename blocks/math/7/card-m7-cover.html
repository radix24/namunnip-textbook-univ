유한 개로 덮을 수 있는가

탐구 · 열린 덮개와 컴팩트

질문

\([0, 1]\)과 \((0, 1]\)은 점 하나 차이이다. 그런데 열린구간 여러 개로 덮을 때, 한쪽은 늘 유한 개로 충분하고 다른 쪽은 그렇지 않은 덮개가 있다. 0 하나가 왜 그런 차이를 만들까?

복원

컴팩트: 모든 열린 덮개가 유한 부분덮개를 가진다. 하이네-보렐: \(\mathbb R^n\)에서 컴팩트 ⇔ 닫혀 있고 유계 (1.3절).

해 보기

  1. \([0, 1]\)에서 N을 늘리면 9개에서 빨강이 사라진다. 점마다 구간의 크기가 달라도 유한 개로 끝난다.
  2. \((0, 1]\)에 \((\frac1n, 2)\)를 주면 N을 40까지 올려도 \((0, \frac1N]\)이 남는다. 0에 가까운 점일수록 큰 \(n\)이 필요하고, 유한 개로는 최댓값 \(n\)이 있기 때문이다.
  3. \((0, 1]\)에 \((\frac x2, 2x)\)를 주면 고를 때마다 덮인 부분이 왼쪽으로 반씩만 늘어 0까지 닿지 못한다.
  4. 둘째 덮개에 0을 덮는 구간 하나 \((-0.01, 0.01)\)만 보태면 어떻게 될지 생각해 보자. 그러면 유한 개로 끝난다. 컴팩트한 \([0, 1]\)에서는 0을 덮는 구간이 덮개에 반드시 있어야 하기 때문이다.

설명

  1. 극한점을 빠뜨린 대가\((0, 1]\)은 극한점 0을 빠뜨려 닫혀 있지 않는다. 덮개의 구간들이 0 쪽으로 한없이 작아질 수 있어, 유한 개로는 0 바로 옆을 다 덮지 못한다.
  2. 닫힌구간에서는0도 집합의 점이라 0을 덮는 열린구간 \((-r, r)\) 하나가 0 근처를 한꺼번에 덮는다. 1.3절의 증명은 "유한 개로 덮이는 \([0, x]\)"의 상한을 끝까지 밀어 붙이는 방식으로 이를 보인다.

판단

"\((0, 1]\)도 덮개 \(\{(-1, 2)\}\) 하나로 덮이니 컴팩트다"는 틀린다. 컴팩트는 모든 덮개에 대해 유한 부분덮개가 있어야 한다. 이 카드의 둘째·셋째 덮개 같은 반례가 하나라도 있으면 컴팩트가 아니다.
