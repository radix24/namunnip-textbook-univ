기호 계산 연습 문제

문제 6 · 실습·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 실습\(\int x^2\sin x\,dx\)을 SymPy로 구하는 명령과 결과를 쓰고, 미분해 확인하는 명령도 써라. [02-01]

    힌트 1

    integrate(x**2*sin(x), x).

    힌트 2

    simplify(diff(F, x) - f)가 0인지.

    풀이

    결과 \(-x^2\cos x + 2x\sin x + 2\cos x\) (출력 -x**2*cos(x) + 2*x*sin(x) + 2*cos(x)). simplify(diff(F, x) - x**2*sin(x)) → 0 (2.1절).

  2. 실습\(\lim_{x\to0}\frac{\sin x - x}{x^3}\)과 \(\tan x\)의 5차 테일러 다항식을 구하는 명령과 결과를 써라. [02-01]

    힌트 1

    limit, series.

    힌트 2

    \(\tan x = x + \frac{x^3}3 + \frac{2x^5}{15} + \cdots\).

    풀이

    limit((sin(x) - x)/x**3, x, 0) → -1/6. series(tan(x), x, 0, 6) → x + x**3/3 + 2*x**5/15 + O(x**6).

  3. 실습\(A = \begin{pmatrix}1 & a\\ a & 1\end{pmatrix}\)이 역행렬을 가지지 않는 \(a\)를 SymPy로 구하는 명령과 결과를 써라. [02-02]

    힌트 1

    \(\det A = 0\).

    힌트 2

    solve(A.det(), a).

    풀이

    a = symbols('a'), solve(Matrix([[1, a], [a, 1]]).det(), a) → [-1, 1] (2.2절).

  4. 판단integrate(exp(-x**2), x)의 결과에 erf가 나왔다. "기호 계산이 실패했다"는 해석은 옳은가? [02-03]

    힌트 1

    erf의 정의.

    힌트 2

    실패이면 Integral이 그대로 나온다.

    풀이

    틀리다. 결과 sqrt(pi)*erf(x)/2는 정확한 원시함수이다. 초등함수가 아닐 뿐이며 erf는 이 적분으로 정의된 특수함수이다 (2.3절).

  5. 실습\(e^x = 3x\)의 두 실근을 nsolve로 구할 때 쓸 시작값과 결과를 써라. [02-03]

    힌트 1

    \(g(x) = e^x - 3x\)의 부호를 \(x = 0, 1, 2\)에서 본다.

    힌트 2

    \(g(0) = 1 > 0\), \(g(1) = e - 3 < 0\), \(g(2) = e^2 - 6 \approx 1.39 > 0\).

    풀이

    근은 \((0, 1)\)과 \((1, 2)\)에 하나씩. nsolve(exp(x) - 3*x, x, 0.5) → 약 0.6191, nsolve(exp(x) - 3*x, x, 1.5) → 약 1.5121.

  6. 판단x = 1/3을 넣고 3*x == 1을 기호 계산이라 믿고 쓰는 것의 문제는? [02-01]

    힌트 1

    1/3은 Python 실수.

    힌트 2

    Rational(1, 3).

    풀이

    1/3은 부동소수점 근삿값이라 기호 계산이 아니다(이 경우는 우연히 True지만 0.1*3 == 0.3은 False). 정확히 하려면 Rational(1, 3) 또는 S(1)/3.
