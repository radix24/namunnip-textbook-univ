그래프 그리기

본문

계산 결과를 수의 목록으로만 보면 패턴이 잘 보이지 않는다. 함수와 근삿값을 한 그림에 겹쳐 그리거나, \(10^{-2}\)에서 \(10^{-12}\)까지 변하는 오차를 한눈에 보려면 어떻게 그려야 할까? 수렴 차수는 그래프에서 어떻게 읽을까?

먼저 알아야 할 것배열 만들기(3.1절)와 로그함수를 쓴다.

3.3.1기본 그래프

import numpy as np
import matplotlib.pyplot as plt
x = np.linspace(0, 2*np.pi, 200)
plt.plot(x, np.sin(x), label='sin x')
plt.plot(x, x - x**3/6, '--', label='x - x^3/6')
plt.xlabel('x'); plt.ylabel('y')
plt.ylim(-1.5, 1.5); plt.legend(); plt.grid(True)
plt.savefig('taylor.png', dpi=150)

이 코드는 점 200개를 선으로 이어 곡선처럼 보이게 한다. 점이 너무 적으면 꺾인 선이 된다. 그림 1처럼 테일러 다항식이 0 근처에서만 \(\sin x\)를 잘 따라가고 \(x \approx 2\)부터 벌어지는 것이 한눈에 보인다. 보고서에 넣을 그림에는 축 이름과 범례를 꼭 붙이고 savefig로 저장한다.

3.3.2로그 축

오차가 \(10^{-2}\)에서 \(10^{-12}\)까지 변하면 보통 축에서는 작은 값이 모두 0에 붙어 보인다. 반면 로그-로그 축에서는 \(E = Ch^p\)가 \(\log E = \log C + p\log h\)로 직선이 되고, 그 기울기가 수렴 차수 \(p\)이다.

h = 10.0**-np.arange(1, 13)
err = abs((np.sin(1 + h) - np.sin(1)) / h - np.cos(1))
plt.loglog(h, err, 'o-')
plt.xlabel('h'); plt.ylabel('error')

이 그래프는 6.2절에서 자세히 본다. \(h\)가 \(10^{-8}\)까지는 기울기 1로 내려가다가, 그보다 작아지면 반올림 오차 때문에 다시 올라가 V자 모양이 된다.

3.3.3gnuplot

자료 파일을 빠르게 그릴 때는 gnuplot도 편하다. 예를 들어 plot 'data.csv' using 1:2 with linespoints는 쉼표나 빈칸으로 나뉜 첫째 칸을 \(x\), 둘째 칸을 \(y\)로 그리며, 쉼표로 나뉜 파일이면 set datafile separator ','를 먼저 쓴다. 또 set logscale xy는 로그 축을, set terminal png; set output 'a.png'는 파일 저장을 뜻한다. 이를 1.2절의 셸 스크립트와 엮으면 실험마다 그림을 자동으로 만들 수 있다.

한편 그래프는 계산이 맞는지 확인하는 도구이기도 하다. 예를 들어 6장의 수치 방법을 구현한 뒤 \(h\)에 따른 오차를 로그-로그로 그려 기울기가 이론 차수와 같은지 보면, 코드의 실수를 대부분 잡아낼 수 있다. 따라서 결과 수치만 보기 전에 먼저 그림을 그려 보는 습관이 좋다.

흔한 오해0이나 음수가 든 자료를 로그 축에 그려도 된다고 여기기 쉽지만, 오차가 정확히 0인 점처럼 그런 점은 그려지지 않는다. 또 축 범위를 늘 자동에 맡겨도 된다고 생각하는 것도 틀렸다. 이상값 하나가 축을 늘려 중요한 부분이 납작해질 수 있으므로 범위를 직접 정한다.
마무리

처음 질문에 답하면, matplotlib의 plot으로 함수와 근삿값을 한 그림에 겹쳐 그리고, 축 이름과 범례를 붙여 savefig로 저장한다. 크기가 여러 자릿수에 걸친 오차는 loglog로 그리며, 이때 \(E = Ch^p\)는 직선이 되어 그 기울기에서 수렴 차수 \(p\)를 읽는다. 자료 파일은 gnuplot으로도 빠르게 그릴 수 있다.

3.3.4연습문제

기본

  1. 로그-로그 그래프에서 점 \((10^{-2}, 10^{-4})\)과 \((10^{-3}, 10^{-6})\)을 잇는 직선의 기울기는?
    답

    \(\frac{-6 - (-4)}{-3 - (-2)} = 2\). 2차 수렴.

응용

  1. \(y = e^{-x}\cos(10x)\)를 \(0 \le x \le 3\)에서 그릴 때 점이 50개면 어떤 문제가 생기는가?
    답

    주기가 \(\frac{2\pi}{10} \approx 0.63\)인데 점 간격이 0.06이라 한 주기에 10점뿐, 봉우리가 깎이고 꺾여 보인다. 수백 점이 필요하다.

심화

  1. \(y = Cx^p\) 꼴의 자료에서 \(p\)를 추정하려면 어떤 그래프를 그리고 무엇을 계산하는가? \(y = Ce^{ax}\)이면?
    답

    \(\log y\) 대 \(\log x\)의 직선 기울기(로그-로그). 지수함수는 \(\log y\) 대 \(x\)의 기울기 \(a\) (세로만 로그, semilogy).
