실험 파일마다 평균을 구하는 스크립트

예제 · 반복문, awk, 명령 치환

먼저 예측

머리줄이 있는 csv 파일 세 개의 둘째 열 평균을 구할 때, 머리줄을 빼지 않으면 무슨 일이 생길까요?

예측 확인

awk는 글자 y를 0으로 보아 평균이 작아지고 개수도 하나 늘어 틀린 값이 나옵니다.

data/run1.csv ~ run3.csv는 머리줄 x,y 다음에 \((0, 1), (1, 1)\), \((0, 2), (1, 4)\), \((0, 3), (1, 9)\)를 담고 있다. 파일마다 \(y\)의 평균을 "파일이름 평균" 꼴로 출력하는 셸 스크립트를 써라.

전략

for로 파일을 돌고(1.2절), 평균은 awk의 NR>1(둘째 줄부터) 조건으로 구합니다. 이름은 basename으로 경로와 확장자를 뗍니다.

풀이

  1. #!/bin/bash
for f in data/run*.csv; do
    m=$(awk -F, 'NR>1 {s+=$2; n++} END {print s/n}' "$f")
    echo "$(basename "$f" .csv) $m"
done
    -F,: 쉼표로 칸 나누기, $2: 둘째 칸.
  2. $ bash avg.sh
run1 1
run2 3
run3 6
    \(\frac{1 + 1}2\), \(\frac{2 + 4}2\), \(\frac{3 + 9}2\).

검산

손으로 계산한 평균 1, 3, 6과 같습니다. NR>1을 빼면 run2는 \(\frac{0 + 2 + 4}3 = 2\)가 나와 틀립니다(머리줄의 y가 0으로 계산됨).

의미

파일이 300개여도 스크립트는 그대로입니다. 결과를 bash avg.sh > summary.txt로 저장하면 gnuplot이나 Python으로 바로 그릴 수 있어, 실험 → 요약 → 그림 과정을 한 번에 다시 돌릴 수 있습니다.

이해 확인

평균 대신 최댓값을 출력하려면 awk 부분을 어떻게 바꾸는가?

답

awk -F, 'NR>1 && (n==0 || $2>m) {m=$2; n=1} END {print m}'. 결과 1, 4, 9.
