파이프와 셸 스크립트

본문
이 절에서 배울 것
  • 표준 입출력, 리다이렉션 > >>, 파이프 |로 명령을 잇는다.
  • sort, cut, uniq로 자료를 가공한다.
  • 변수, for 반복문, 인수를 쓰는 셸 스크립트로 반복 실험을 자동화한다.
먼저 알아야 할 것
  • Unix 기본 명령 (1.1절).

1.2.1입출력과 파이프

명령은 표준 입력에서 읽고 표준 출력에 씁니다. 명령 > 파일은 출력을 파일에 쓰고(덮어씀), >>는 뒤에 덧붙이며, 명령1 | 명령2는 앞 명령의 출력을 뒤 명령의 입력으로 넘깁니다. 작은 도구를 이어 붙여 큰 일을 하는 것이 Unix의 방식입니다.

$ cat data/*.csv | grep -v x | sort -t, -k2 -n | tail -1
1,9

세 파일을 합치고(cat), 머리줄을 빼고(grep -v: 패턴이 없는 줄), 쉼표로 나눈 둘째 칸을 숫자로 정렬해(sort -t, -k2 -n) 마지막 줄을 취했습니다. 즉 모든 실험에서 \(y\)가 가장 큰 줄입니다.

1.2.2셸 스크립트

명령을 파일에 적어 두면 같은 작업을 몇 번이든 똑같이 되풀이할 수 있습니다.

#!/bin/bash
# last.sh: 각 실험 파일의 마지막 y값을 출력
for f in data/run*.csv; do
    y=$(tail -1 "$f" | cut -d, -f2)
    echo "$f $y"
done
$ bash last.sh
data/run1.csv 1
data/run2.csv 4
data/run3.csv 9

$( )는 명령의 출력을 값으로 받고, cut -d, -f2는 쉼표로 나눈 둘째 칸입니다. 변수는 "$f"처럼 따옴표로 감싸야 파일 이름에 빈칸이 있어도 안전합니다. chmod +x last.sh를 하면 ./last.sh로 바로 실행됩니다.

예 1.2.1 (매개변수 훑기) 프로그램 sim을 격자 크기 \(n = 16, 32, 64, 128\)로 돌리고 결과를 따로 저장하려면 
for n in 16 32 64 128; do
    ./sim $n > out_$n.txt
done
손으로 네 번 치는 것보다 실수가 적고, 같은 실험을 나중에 정확히 재현할 수 있습니다.
흔한 오해(1) >가 덧붙인다고 여긴다. 기존 내용을 지우고 쓴다. 덧붙이기는 >>. (2) 변수를 따옴표 없이 써도 된다고 여긴다. 빈칸이 든 값이 여러 인수로 쪼개진다.
요약
  1. > 덮어쓰기, >> 덧붙이기, | 이어 붙이기.
  2. sort cut uniq grep로 자료 가공.
  3. 스크립트: for, $( ), "$변수"로 반복 실험 자동화.

1.2.3연습문제

기본

  1. ls의 출력을 list.txt에 저장하고, 그 줄 수를 세는 명령을 한 줄로 써라.
    답

    ls > list.txt; wc -l list.txt (또는 ls | tee list.txt | wc -l).

응용

  1. 로그 파일 log.txt에서 ERROR가 든 줄을 종류별로 몇 번씩 나왔는지 세려면?
    답

    grep ERROR log.txt | sort | uniq -c | sort -n. uniq -c는 이웃한 같은 줄을 세므로 먼저 정렬한다.

심화

  1. 스크립트가 첫 인수로 받은 디렉터리의 csv 파일 수를 출력하도록 써라(인수가 없으면 사용법을 출력하고 끝).
    답

    [ -z "$1" ] && { echo "usage: $0 dir"; exit 1; } 다음 줄에 ls "$1"/*.csv | wc -l.
