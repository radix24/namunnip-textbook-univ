기호 미분, 적분, 급수 전개

본문

손으로 구한 적분이나 도함수가 맞는지 컴퓨터로 확인하고 싶다. 그런데 \(1.41421356\)처럼 근삿값을 내는 계산으로는 \(\sqrt2\)나 \(e - 2\) 같은 정확한 답과 비교하기 어렵다. 식을 식 그대로 다루는 계산은 어떻게 하며, 어떤 도구들이 있을까?

먼저 알아야 할 것미적분학의 미분과 적분, 테일러 급수(수학1)와 Python 기초를 쓴다.

2.1.1기호 계산이란

수치 계산은 \(\sqrt2 \approx 1.41421356\)처럼 근삿값을 다룬다. 반면 기호 계산은 \(\sqrt2\) 자체나 \(\frac{d}{dx}\sin x = \cos x\) 같은 식을 정확히 다룬다. 그래서 공식을 유도하거나 손계산을 검산할 때, 그리고 정확한 값이 필요할 때 쓴다. 다음은 Python의 SymPy로 한 예이다.

>>> from sympy import *
>>> x = symbols('x')
>>> diff(sin(x)*exp(x), x)
exp(x)*sin(x) + exp(x)*cos(x)
>>> integrate(1/(1 + x**2), x)
atan(x)
>>> integrate(x*exp(-x), (x, 0, oo))
1
>>> limit(sin(x)/x, x, 0)
1
>>> series(cos(x), x, 0, 6)
1 - x**2/2 + x**4/24 + O(x**6)

symbols로 기호를 만들고, oo는 무한대이다. 정적분에는 (변수, 아래끝, 위끝)을 준다. 출력에서 항의 순서는 버전에 따라 조금 다를 수 있다.

2.1.2다른 도구와의 대응

Mathematica와 Maple도 같은 일을 하며, 함수 이름만 조금씩 다르다.

작업SymPyMathematicaMaple
미분diff(f, x)D[f, x]diff(f, x)
적분integrate(f, (x, a, b))Integrate[f, {x, a, b}]int(f, x = a..b)
급수series(f, x, 0, n)Series[f, {x, 0, n}]series(f, x = 0, n)
수치값N(e, 20)N[e, 20]evalf(e, 20)
예제 2.1.1

손으로 구한 \(\int_0^1x^2e^xdx = e - 2\)를 기호 계산으로 검산하여라.

풀이. integrate(x**2*exp(x), (x, 0, 1))의 출력은 -2 + E이며, 여기서 E는 자연상수이다. 이어서 N(_, 10)을 하면 \(0.7182818285\)를 얻는다. 즉 그림 1의 넓이가 손계산과 일치한다.

기호 계산의 결과는 그대로 수치 계산에 넘길 수도 있다. 예를 들어 손으로 구하기 번거로운 도함수를 diff로 정확히 구한 뒤, 2.3절의 lambdify로 빠른 함수로 바꿔 뉴턴 방법에 쓰면 손계산의 실수를 막을 수 있다. 즉 기호 계산은 정확한 식을 만드는 일에, 수치 계산은 그 식으로 많은 값을 빠르게 구하는 일에 맡기는 것이 좋다.

흔한 오해x를 기호로 선언하지 않고 바로 써도 된다고 여기기 쉽지만, Python 변수 x가 없으면 오류가 나고 숫자가 들어 있으면 숫자 계산이 된다. 또 1/3이 정확한 분수라고 생각하는 것도 틀렸다. Python에서 1/3은 실수 0.333…이고, 정확한 분수는 Rational(1, 3)이다.
마무리

처음 질문에 답하면, 기호 계산은 근삿값 대신 식과 정확한 값을 그대로 다루므로 손으로 구한 미분, 적분, 극한, 급수를 검산할 수 있다. SymPy에서는 symbols로 기호를 만들고 diff, integrate, limit, series를 쓰며, Mathematica와 Maple에도 같은 함수가 있다. 정확한 답은 N으로 언제든 근삿값으로 바꿀 수 있다.

2.1.3연습문제

기본

  1. \(\frac{d}{dx}\ln(x^2 + 1)\)을 구하는 SymPy 명령과 결과를 써라.
    답

    diff(log(x**2 + 1), x) → 2*x/(x**2 + 1). (SymPy의 log는 자연로그.)

응용

  1. \(e^x\)의 6차까지의 테일러 다항식으로 \(e\)를 근사하면 오차는 얼마인가? 명령으로 계산하는 방법을 써라.
    답

    p = series(exp(x), x, 0, 7).removeO(), N(E - p.subs(x, 1)) → 약 \(2.26\times10^{-4}\).

심화

  1. integrate(1/x, (x, -1, 1))의 결과는 무엇이어야 하는가? 기호 계산 결과를 그대로 믿으면 안 되는 이유를 말하여라.
    답

    \(x = 0\)에서 발산하는 이상적분이라 값이 없다(코시 주값은 0). 버전에 따라 nan이나 zoo를 주거나 경고 없이 주값을 줄 수 있어, 특이점을 직접 확인해야 한다.
