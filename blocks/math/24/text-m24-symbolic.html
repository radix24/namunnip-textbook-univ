2.1.1기호 계산이란

수치 계산은 \(\sqrt2 \approx 1.41421356\)처럼 근삿값을 다룹니다. 기호 계산은 \(\sqrt2\) 자체, \(\frac{d}{dx}\sin x = \cos x\) 같은 식을 정확히 다룹니다. 공식을 유도하거나 손계산을 검산할 때, 그리고 정확한 값이 필요할 때 씁니다.

>>> from sympy import *
>>> x = symbols('x')
>>> diff(sin(x)*exp(x), x)
exp(x)*sin(x) + exp(x)*cos(x)
>>> integrate(1/(1 + x**2), x)
atan(x)
>>> integrate(x*exp(-x), (x, 0, oo))
1
>>> limit(sin(x)/x, x, 0)
1
>>> series(cos(x), x, 0, 6)
1 - x**2/2 + x**4/24 + O(x**6)

symbols로 기호를 만들고, oo는 무한대입니다. 정적분은 (변수, 아래끝, 위끝)을 줍니다. 출력은 버전에 따라 항의 순서가 조금 다를 수 있습니다.

2.1.2다른 도구와의 대응

작업SymPyMathematicaMaple
미분diff(f, x)D[f, x]diff(f, x)
적분integrate(f, (x, a, b))Integrate[f, {x, a, b}]int(f, x = a..b)
급수series(f, x, 0, n)Series[f, {x, 0, n}]series(f, x = 0, n)
수치값N(e, 20)N[e, 20]evalf(e, 20)
예 2.1.1 손으로 구한 \(\int_0^1x^2e^xdx = e - 2\)를 검산합니다. integrate(x**2*exp(x), (x, 0, 1))의 출력은 -2 + E입니다(E는 자연상수). N(_, 10)으로 \(0.7182818285\)를 얻습니다.
흔한 오해(1) x를 기호로 선언하지 않고 쓴다. Python 변수 x가 없으면 오류, 숫자가 들어 있으면 숫자 계산이 된다. (2) 1/3이 정확한 분수라 여긴다. Python에서는 0.333… 실수이다. 정확한 분수는 Rational(1, 3).
요약
  1. 기호 계산: 식을 정확히 다룸, 유도와 검산에.
  2. diff integrate limit series, oo, N.
  3. Mathematica, Maple도 같은 구조.

2.1.3연습문제

기본

  1. \(\frac{d}{dx}\ln(x^2 + 1)\)을 구하는 SymPy 명령과 결과를 써라.
    답

    diff(log(x**2 + 1), x) → 2*x/(x**2 + 1). (SymPy의 log는 자연로그.)

응용

  1. \(e^x\)의 6차까지의 테일러 다항식으로 \(e\)를 근사하면 오차는 얼마인가? 명령으로 계산하는 방법을 써라.
    답

    p = series(exp(x), x, 0, 7).removeO(), N(E - p.subs(x, 1)) → 약 \(2.26\times10^{-4}\).

심화

  1. integrate(1/x, (x, -1, 1))의 결과는 무엇이어야 하는가? 기호 계산 결과를 그대로 믿으면 안 되는 이유를 말하여라.
    답

    \(x = 0\)에서 발산하는 이상적분이라 값이 없다(코시 주값은 0). 버전에 따라 nan이나 zoo를 주거나 경고 없이 주값을 줄 수 있어, 특이점을 직접 확인해야 한다.
