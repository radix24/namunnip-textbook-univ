2점 경계치 문제: 사격법

본문

초기값 문제 풀이는 이미 할 줄 안다. 그런데 \(y(0) = 0\), \(y(1) = 1\)처럼 조건이 양 끝에 하나씩 주어지면 어디서 출발해야 할까? 대포를 쏠 때처럼 처음 기울기를 정해 쏘고, 빗나간 만큼 각도를 고쳐 다시 쏘면 된다.

먼저 알아야 할 것Runge-Kutta 방법(6.5절), 할선법(5.3절), 유한차분법(수치해석의 경계치 문제)을 쓴다. Heath 10장을 따른다.

6.6.1경계치 문제를 근 찾기로 바꾸기

\(y'' = f(x, y, y')\), \(y(a) = \alpha\), \(y(b) = \beta\)를 풀려고 한다. 둘째 조건을 잠시 잊고, 처음 기울기 \(y'(a) = s\)를 정하면 초기값 문제가 되어 Runge-Kutta 방법으로 풀린다. 그 해의 끝점 값을 \(y(b; s)\)라 하자. 그러면 할 일은 \(F(s) = y(b; s) - \beta = 0\)의 근 찾기이다. 함수 \(F\)를 한 번 계산하는 데 초기값 문제 하나를 풀어야 하므로, 도함수가 필요 없는 할선법이 잘 맞는다.

import numpy as np
from scipy.integrate import solve_ivp

def F(s):                        # y'' = -y + x, y(0) = 0, y(1) = 1
    sol = solve_ivp(lambda x, u: [u[1], -u[0] + x], [0, 1], [0, s], rtol=1e-10)
    return sol.y[0, -1] - 1

s0, s1 = 0.0, 1.0
for _ in range(8):
    s0, s1 = s1, s1 - F(s1) * (s1 - s0) / (F(s1) - F(s0))
print(s1)                          # 처음 기울기

이 문제는 선형이라 \(F\)가 \(s\)의 일차함수이고, 할선법이 한 번에 정확한 근을 준다. 실제로 해는 \(y = x\)이므로 \(s = 1\)이 나와야 한다. 비선형 문제에서는 할선법을 몇 번 되풀이한다.

6.6.2유한차분법과 비교

같은 문제를 유한차분법으로 풀면 \(y_i \approx y(x_i)\)를 미지수로 두고 \(\frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} = f(x_i, y_i, \cdot)\)을 연립해 푼다. 선형이면 삼중대각 연립방정식 하나이다. 두 방법은 장단점이 뚜렷하다.

사격법은 초기값 문제 풀이기의 높은 정확도를 그대로 쓰고 구현이 짧다. 하지만 해가 처음 기울기에 민감하면 실패한다. 가령 \(y'' = 100y\)에서는 \(s\)의 작은 오차가 \(e^{10}\)배로 커져 \(F\)가 사실상 계산되지 않는다. 그러면 구간을 여러 개로 나누어 각 구간에서 쏘고 이음 조건을 맞추는 다중 사격법을 쓴다. 유한차분법은 연립방정식 하나로 전체를 함께 풀므로 이런 불안정에 강하지만, 정확도를 높이려면 격자를 촘촘히 해야 한다.

예제 6.6.1

\(y'' = -y\), \(y(0) = 0\), \(y(\pi/2) = 1\)을 사격법으로 풀 때 \(F(s)\)를 정확히 쓰고 근을 구하여라. 또 \(y(\pi) = 1\)이면 무엇이 달라지는가?

풀이. 초기값 \(y(0) = 0\), \(y'(0) = s\)의 해는 \(y = s\sin x\)이므로 \(F(s) = s\sin\frac\pi2 - 1 = s - 1\)이고 근은 \(s = 1\), 해는 \(y = \sin x\)이다. 끝점이 \(\pi\)이면 \(F(s) = s\sin\pi - 1 = -1\)로 어떤 \(s\)에서도 0이 아니다. 경계치 문제에 해가 없는 경우이고, 사격법은 \(F\)가 상수로 나와 이 사실을 바로 드러낸다. \(y(\pi) = 0\)이었다면 모든 \(s\)가 근이라 해가 무한히 많다. 경계치 문제는 초기값 문제와 달리 해의 존재와 유일성이 보장되지 않는다.

마무리

사격법은 처음 기울기 \(s\)를 미지수로 삼아 초기값 문제를 풀고, 끝점 조건의 어긋남 \(F(s) = y(b; s) - \beta\)의 근을 할선법으로 찾는다. 구현이 짧고 정확하지만 처음 조건에 민감한 문제에서는 불안정하며, 그때는 다중 사격법이나 유한차분법을 쓴다. 경계치 문제는 해가 없거나 여럿일 수 있다.

6.6.3연습문제

기본

  1. 선형 경계치 문제에서 \(F(s)\)가 \(s\)의 일차함수인 이유를 설명하여라.
    답

    해가 \(y = y_0 + s\,y_1\)(\(y_0\)은 \(y'(a) = 0\)인 해, \(y_1\)은 동차 방정식의 \(y_1(a) = 0\), \(y_1'(a) = 1\)인 해)로 \(s\)에 대해 일차이다.

응용

  1. \(y'' = 100y\), \(y(0) = 1\), \(y(1) = 0\)을 사격법으로 풀 때 필요한 \(s\)의 값을 구하고 그 민감도를 설명하여라.
    답

    해는 \(y = \cosh10x - \coth10\sinh10x\)이므로 \(s = -10\coth10 \approx -10.0000000412\). \(s\)가 \(10^{-8}\)만 틀려도 \(y(1)\)이 \(10^{-9}\sinh10 \approx 10^{-5}\)만큼 어긋난다.
