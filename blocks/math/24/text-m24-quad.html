구적법 구현과 정확도 비교

본문

정적분을 수치로 구할 때, 구간마다 직선으로 근사하는 것과 포물선으로 근사하는 것은 얼마나 차이가 날까? 같은 함수 계산 횟수로 몇 자리를 얻을 수 있을까? 그리고 함수가 매끄럽지 않으면 고차 공식의 이점은 여전히 남을까?

먼저 알아야 할 것정적분과 리만 합, 벡터화(3.2절)를 쓴다. 이론은 수학16 4장에서 다룬다.

6.3.1구현

import numpy as np
def trap(f, a, b, n):
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a)/n
    return h*(y.sum() - (y[0] + y[-1])/2)
def simpson(f, a, b, n):        # n은 짝수
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a)/n
    return h/3*(y[0] + y[-1] + 4*y[1:-1:2].sum() + 2*y[2:-1:2].sum())

사다리꼴 공식은 구간마다 직선으로, 심프슨 공식은 두 구간마다 포물선으로 근사한다. 심프슨 공식에서는 홀수 번째 점(y[1:-1:2])에 4, 짝수 번째 내부 점(y[2:-1:2])에 2의 가중치를 준다.

\(\int_0^1e^xdx = e - 1 \approx 1.7182818285\)를 두 공식으로 구하면 다음과 같다.

\(n\)을 두 배로 하면 사다리꼴 오차는 약 4배 줄어 \(O(h^2)\)이고, 심프슨 오차는 약 16배 줄어 \(O(h^4)\)이다. 그래서 함수 계산 17번으로 심프슨 공식은 7자리, 사다리꼴 공식은 3자리를 얻는다.

6.3.3매끄럽지 않을 때

그런데 오차 공식은 \(f''\), \(f^{(4)}\)가 유계라는 가정에서 나온다. \(\int_0^1\sqrt x\,dx = \frac23\)처럼 끝점에서 도함수가 발산하면, 그림 1의 점선처럼 두 방법 모두 오차가 \(n^{-1.5}\) 정도로만 줄어 심프슨의 이점이 사라진다. 이럴 때는 \(x = t^2\) 같은 변수 치환으로 특이성을 없애거나, 특이점 근처를 촘촘히 나누는 SciPy quad 같은 적응 구적법을 쓴다. 반대로 주기함수를 한 주기 전체에서 적분하면 사다리꼴 공식이 지수적으로 빠르게 수렴하며, 수학15의 푸리에 계수 계산이 그 예이다.

흔한 오해심프슨 공식에 홀수 \(n\)을 넣어도 된다고 여기기 쉽지만, 구간을 두 개씩 묶으므로 \(n\)은 짝수여야 한다. 또 고차 공식이 늘 낫다고 생각하는 것도 틀렸다. 함수가 매끄럽지 않으면 차수의 이점이 사라진다.
마무리

처음 질문에 답하면, 매끄러운 함수에서 직선 근사인 사다리꼴 공식의 오차는 \(O(h^2)\), 포물선 근사인 심프슨 공식의 오차는 \(O(h^4)\)이라, 함수 계산 17번으로 각각 3자리와 7자리를 얻는다. 하지만 \(\sqrt x\)처럼 끝점에서 도함수가 발산하면 둘 다 \(n^{-1.5}\) 정도로만 줄어 고차 공식의 이점이 사라지므로, 치환이나 적응 구적법을 쓴다.

6.3.4연습문제

기본

  1. 표에서 심프슨 오차의 비 \(\frac{3.70\times10^{-5}}{2.33\times10^{-6}}\)를 구하고 차수를 확인하여라.
    답

    약 15.9 ≈ \(2^4\). 4차.

응용

  1. 사다리꼴로 오차 \(10^{-6}\)을 얻으려면 \(n\)이 대략 얼마여야 하는가? (\(n = 16\)에서 \(5.6\times10^{-4}\))
    답

    오차 \(\propto n^{-2}\): \(\frac{5.6\times10^{-4}}{10^{-6}} = 560\), \(\sqrt{560} \approx 24\)배, \(n \approx 380\).

심화

  1. \(\int_0^1\sqrt x\,dx\)를 \(x = t^2\)로 치환하면 어떤 적분이 되며 왜 정확해지는가?
    답

    \(\int_0^12t^2dt\). 매끄러운 다항식이라 심프슨이 정확(3차 이하는 오차 0).
