구적법 구현과 정확도 비교

본문
이 절에서 배울 것
  • 합성 사다리꼴 공식과 심프슨 공식을 벡터화해 구현한다.
  • 구간 수를 두 배로 할 때 오차가 \(\frac14\) (사다리꼴), \(\frac1{16}\) (심프슨)로 줆을 확인한다.
  • 매끄럽지 않은 함수에서 차수가 떨어지는 것을 안다.
먼저 알아야 할 것
  • 정적분과 리만 합, 벡터화 (3.2절). 이론은 수학16 4장.

6.3.1구현

import numpy as np
def trap(f, a, b, n):
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a)/n
    return h*(y.sum() - (y[0] + y[-1])/2)

def simpson(f, a, b, n):        # n은 짝수
    x = np.linspace(a, b, n + 1); y = f(x); h = (b - a)/n
    return h/3*(y[0] + y[-1] + 4*y[1:-1:2].sum() + 2*y[2:-1:2].sum())

사다리꼴은 구간마다 직선, 심프슨은 두 구간마다 포물선으로 근사합니다. 홀수 번째 점(y[1:-1:2])에 4, 짝수 번째 내부 점(y[2:-1:2])에 2의 가중치를 줍니다.

6.3.3매끄럽지 않을 때

오차 공식은 \(f''\), \(f^{(4)}\)가 유계라는 가정에서 나옵니다. \(\int_0^1\sqrt x\,dx = \frac23\)처럼 끝점에서 도함수가 발산하면 두 방법 모두 오차가 \(n^{-1.5}\) 정도로만 줄어 심프슨의 이점이 사라집니다. 이럴 때는 변수 치환(\(x = t^2\))으로 특이성을 없애거나, 특이점 근처를 촘촘히 나누는 적응 구적법(SciPy quad)을 씁니다. 반대로 주기함수를 한 주기 전체에서 적분하면 사다리꼴이 지수적으로 빠르게 수렴합니다(수학15의 푸리에 계수).

흔한 오해(1) 심프슨 공식에 홀수 \(n\)을 넣는다. 구간을 두 개씩 묶으므로 짝수여야 한다. (2) 고차 공식이 늘 낫다고 여긴다. 함수가 매끄럽지 않으면 차수의 이점이 없다.
요약
  1. 사다리꼴 \(O(h^2)\), 심프슨 \(O(h^4)\): \(n\) 두 배에 오차 \(\frac14\), \(\frac1{16}\).
  2. 벡터화한 한 줄 구현.
  3. 특이성이 있으면 차수 저하 → 치환·적응 구적.

6.3.4연습문제

기본

  1. 표에서 심프슨 오차의 비 \(\frac{3.70\times10^{-5}}{2.33\times10^{-6}}\)를 구하고 차수를 확인하여라.
    답

    약 15.9 ≈ \(2^4\). 4차.

응용

  1. 사다리꼴로 오차 \(10^{-6}\)을 얻으려면 \(n\)이 대략 얼마여야 하는가? (\(n = 16\)에서 \(5.6\times10^{-4}\))
    답

    오차 \(\propto n^{-2}\): \(\frac{5.6\times10^{-4}}{10^{-6}} = 560\), \(\sqrt{560} \approx 24\)배, \(n \approx 380\).

심화

  1. \(\int_0^1\sqrt x\,dx\)를 \(x = t^2\)로 치환하면 어떤 적분이 되며 왜 정확해지는가?
    답

    \(\int_0^12t^2dt\). 매끄러운 다항식이라 심프슨이 정확(3차 이하는 오차 0).
