오일러 방법과 룽게-쿠타 방법

본문

미분방정식 \(y' = f(t, y)\)의 해를 손으로 구할 수 없을 때, 기울기를 따라 한 걸음씩 나아가면 해를 근사할 수 있다. 가장 단순한 방법은 얼마나 정확할까? 한 걸음 안에서 기울기를 여러 번 재면 얼마나 나아지며, 진동하는 계에서는 어떤 차이가 드러날까?

먼저 알아야 할 것상미분방정식의 초기값 문제(수학6)와 테일러 전개를 쓴다.

6.5.1오일러 방법

오일러 방법은 \(y(t + h) \approx y(t) + hy'(t) = y + hf(t, y)\)를 되풀이한다. 즉 접선을 따라 한 걸음씩 가는 셈이다. 반면 RK4는 한 걸음 안에서 기울기를 네 번 재어 가중 평균한다.

def euler(f, t, y, h, n):
    for _ in range(n):
        y = y + h*f(t, y); t = t + h
    return y
def rk4(f, t, y, h, n):
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2)
        k4 = f(t + h, y + h*k3)
        y = y + h/6*(k1 + 2*k2 + 2*k3 + k4); t = t + h
    return y

6.5.2비교

\(y' = y\), \(y(0) = 1\)을 \(t = 1\)까지 풀면 참값은 \(e = 2.718281828\cdots\)이다.

오일러 방법은 \(h\)를 반으로 하면 오차도 반이 되는 1차이고, RK4는 \(\frac1{16}\)로 줄어드는 4차이다. 실제로 오일러 방법의 결과 \((1 + h)^{1/h}\)는 \(e\)의 정의 그 자체로, 느리게 다가간다. RK4는 한 걸음에 \(f\)를 4번 계산하지만, 같은 정확도에 필요한 걸음 수가 훨씬 적어 대부분의 문제에서 유리하다.

6.5.3연립방정식

진동자 \(x'' = -x\)는 \(y = (x, v)\)로 두면 \(y' = (v, -x)\)인 연립방정식이다. 그러므로 NumPy 배열을 그대로 넣으면 같은 코드가 동작하며, f = lambda t, y: np.array([y[1], -y[0]])로 쓰면 된다. 에너지 \(\frac12(x^2 + v^2)\)은 보존되어야 하는데, 오일러 방법은 매 걸음 이를 \((1 + h^2)\)배씩 키워 그림 1처럼 궤도가 바깥으로 나선을 그린다. 반면 RK4는 에너지를 아주 천천히 줄인다. 그래서 오래 적분할 때는 에너지를 보존하는 수학16의 심플렉틱 방법을 쓰기도 한다.

흔한 오해오일러 방법도 \(h\)만 작게 하면 충분하다고 여기기 쉽지만, 1차라서 6자리를 얻으려면 걸음이 수백만 번 필요하고 반올림 오차도 쌓인다. 또 계산량을 걸음 수로만 세는 것도 틀렸다. RK4는 걸음마다 \(f\)를 4번 부르므로, 같은 함수 계산 횟수로 비교해야 공정하다.
마무리

처음 질문에 답하면, 접선을 따라 가는 오일러 방법은 1차라서 \(h = 0.1\)로 \(e\)를 구해도 오차가 0.1이 넘는다. 한 걸음 안에서 기울기를 네 번 재는 RK4는 4차라서 같은 \(h\)로 오차가 \(10^{-6}\) 정도이다. 진동자에서는 오일러 방법이 에너지를 키워 궤도가 나선으로 퍼지지만, RK4는 원을 거의 그대로 따라간다.

6.5.4연습문제

기본

  1. \(y' = -2y\), \(y(0) = 1\)에 \(h = 0.1\)로 오일러 방법을 두 걸음 적용한 값을 구하여라.
    답

    \(1 \to 0.8 \to 0.64\). 참값 \(e^{-0.4} \approx 0.670\).

응용

  1. 표에서 RK4 오차 \(2.08\times10^{-6} \to 1.36\times10^{-7}\)의 비를 구하고 차수를 확인하여라.
    답

    약 15.3 ≈ \(2^4\). 4차.

심화

  1. \(y' = -50y\)에 오일러 방법을 \(h = 0.05\)로 쓰면 어떻게 되는가? 안정하려면 \(h\)가 얼마보다 작아야 하는가?
    답

    \(y_{k+1} = (1 - 2.5)y_k = -1.5y_k\)라 부호가 바뀌며 발산. \(|1 - 50h| < 1\)이려면 \(h < 0.04\) (경직 문제, 수학16).
