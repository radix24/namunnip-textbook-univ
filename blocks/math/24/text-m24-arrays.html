배열 만들기, 인덱싱, 행렬 연산

본문

수치 계산의 자료는 대부분 수를 격자로 늘어놓은 배열이다. 배열을 만들고, 원하는 원소나 행, 열, 조건에 맞는 원소를 반복문 없이 골라내려면 어떻게 할까? 그리고 원소끼리의 곱과 행렬의 곱은 어떻게 구별하며, 연립방정식은 어떻게 풀어야 할까?

먼저 알아야 할 것행렬의 곱과 역행렬(수학2)과 Python 기초를 쓴다.

3.1.1배열 만들기

>>> import numpy as np
>>> np.linspace(0, 1, 5)          # 0~1을 5점으로 고르게
array([0.  , 0.25, 0.5 , 0.75, 1.  ])
>>> x = np.arange(6).reshape(2, 3)  # 0..5를 2x3으로
>>> x
array([[0, 1, 2],
       [3, 4, 5]])
>>> np.zeros((2, 2)), np.eye(3)    # 영행렬, 단위행렬

Octave나 Matlab에서는 linspace(0, 1, 5), reshape(0:5, 3, 2)', zeros(2), eye(3)로 거의 같다. 다만 NumPy는 0번부터, Matlab은 1번부터 센다는 차이가 있다.

3.1.2인덱싱

>>> x[1, 2]        # 2행 3열 (0부터)
5
>>> x[:, 1]        # 둘째 열 전체
array([1, 4])
>>> x[x > 2]       # 조건을 만족하는 원소
array([3, 4, 5])
>>> x.sum(axis=0)  # 열마다 합
array([3, 5, 7])

:은 그 축의 전부이고, a:b는 a부터 b 직전까지이다. 또 x > 2는 참과 거짓으로 된 배열이며, 이를 인덱스로 쓰면 그림 1의 오른쪽처럼 참인 자리만 뽑힌다. 이것을 논리 인덱싱이라 하며, 자료에서 이상값을 고르거나 조건별 평균을 낼 때 반복문 없이 쓴다.

3.1.3원소별 연산과 행렬 연산

>>> A = np.array([[1, 2], [3, 4]])
>>> A * A          # 원소별 곱
array([[ 1,  4],
       [ 9, 16]])
>>> A @ A          # 행렬 곱
array([[ 7, 10],
       [15, 22]])
>>> np.linalg.solve(A, [1, 1])   # Ax = (1, 1) 풀기
array([-1.,  1.])

NumPy의 *는 원소별 곱이고 @는 행렬 곱이다. Matlab은 반대로 *가 행렬 곱이고 원소별 곱은 .*이다. 연립방정식은 역행렬을 구해 곱하지 말고 solve, 곧 Matlab의 A\b를 쓴다. 왜냐하면 solve는 수학16의 LU 분해, 즉 가우스 소거를 쓰므로 더 빠르고 정확하기 때문이다.

그런데 배열을 다룰 때는 복사와 참조를 구별해야 한다. 예를 들어 y = x[:, 1]은 새 배열이 아니라 x의 일부를 가리키는 뷰이므로, y를 바꾸면 x도 바뀐다. 따로 다루려면 x[:, 1].copy()로 복사한다. 반면 논리 인덱싱 x[x > 2]는 늘 새 배열을 만든다. 이 차이를 모르면 원래 자료가 몰래 바뀌는 버그가 생긴다.

또 배열에는 자료형이 있다. np.arange(6)은 정수 배열이라 x / 2는 실수 배열을 새로 만들지만, x[0] = 2.7처럼 실수를 넣으면 2로 잘려 저장된다. 그러므로 실수 계산에 쓸 배열은 처음부터 np.zeros(n)이나 np.arange(6, dtype=float)처럼 실수형으로 만든다. 배열의 자료형은 x.dtype으로 확인할 수 있으며, 큰 계산을 시작하기 전에 한 번 확인해 두면 이런 잘림을 미리 막을 수 있다.

흔한 오해NumPy에서 A * B가 행렬 곱이라고 여기기 쉽지만, 원소별 곱이며 행렬 곱은 A @ B이다. 또 inv(A) @ b로 연립방정식을 풀어도 된다고 생각하는 것도 틀렸다. 이 방법은 느리고 오차가 크므로 solve(A, b)를 쓴다.
마무리

처음 질문에 답하면, NumPy에서는 linspace, arange, reshape로 배열을 만들고, x[i, j], x[:, j], x[조건]으로 원소, 열, 조건에 맞는 원소를 반복문 없이 고른다. *는 원소별 곱, @는 행렬 곱이며, 연립방정식은 역행렬 대신 np.linalg.solve로 푼다.

3.1.4연습문제

기본

  1. np.arange(10)[2:7:2]의 결과는?
    답

    array([2, 4, 6]) (2부터 7 직전까지 2칸씩).

응용

  1. \(3\times3\) 행렬 M의 대각합을 반복문 없이 구하는 방법 두 가지를 써라.
    답

    np.trace(M), M.diagonal().sum() (또는 (M * np.eye(3)).sum()).

심화

  1. y = x[0]로 꺼낸 행을 바꾸면 x도 바뀌는 이유와, 바뀌지 않게 하는 방법을 말하여라.
    답

    NumPy의 조각은 원래 메모리를 공유하는 뷰(view)이다. y = x[0].copy()로 복사한다.
