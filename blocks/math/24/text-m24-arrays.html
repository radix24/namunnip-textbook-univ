3.1.1배열 만들기

>>> import numpy as np
>>> np.linspace(0, 1, 5)          # 0~1을 5점으로 고르게
array([0.  , 0.25, 0.5 , 0.75, 1.  ])
>>> x = np.arange(6).reshape(2, 3)  # 0..5를 2x3으로
>>> x
array([[0, 1, 2],
       [3, 4, 5]])
>>> np.zeros((2, 2)), np.eye(3)    # 영행렬, 단위행렬

Octave(Matlab)에서는 linspace(0, 1, 5), reshape(0:5, 3, 2)', zeros(2), eye(3)로 거의 같습니다. 차이 하나: NumPy는 0번부터, Matlab은 1번부터 셉니다.

3.1.2인덱싱

>>> x[1, 2]        # 2행 3열 (0부터)
5
>>> x[:, 1]        # 둘째 열 전체
array([1, 4])
>>> x[x > 2]       # 조건을 만족하는 원소
array([3, 4, 5])
>>> x.sum(axis=0)  # 열마다 합
array([3, 5, 7])

:은 그 축의 전부, a:b는 a부터 b 직전까지입니다. x > 2는 참/거짓 배열이고, 이를 인덱스로 쓰면 참인 자리만 뽑힙니다(논리 인덱싱). 자료에서 이상값을 고르거나 조건별 평균을 낼 때 반복문 없이 씁니다.

3.1.3원소별 연산과 행렬 연산

>>> A = np.array([[1, 2], [3, 4]])
>>> A * A          # 원소별 곱
array([[ 1,  4],
       [ 9, 16]])
>>> A @ A          # 행렬 곱
array([[ 7, 10],
       [15, 22]])
>>> np.linalg.solve(A, [1, 1])   # Ax = (1, 1) 풀기
array([-1.,  1.])

NumPy의 *는 원소별, @는 행렬 곱입니다. Matlab은 반대로 *가 행렬 곱이고 원소별은 .*입니다. 연립방정식은 역행렬을 구해 곱하지 말고 solve(Matlab의 A\b)를 씁니다. 가우스 소거(수학16의 LU 분해)라 더 빠르고 정확합니다.

흔한 오해(1) NumPy에서 A * B가 행렬 곱이라 여긴다. 원소별 곱이다. (2) inv(A) @ b로 연립방정식을 푼다. 느리고 오차가 크다. solve(A, b)를 쓴다.
요약
  1. linspace arange reshape zeros eye로 배열 만들기.
  2. x[i, j], x[:, j], 논리 인덱싱 x[x > 2].
  3. * 원소별, @ 행렬 곱, solve로 \(Ax = b\).

3.1.4연습문제

기본

  1. np.arange(10)[2:7:2]의 결과는?
    답

    array([2, 4, 6]) (2부터 7 직전까지 2칸씩).

응용

  1. \(3\times3\) 행렬 M의 대각합을 반복문 없이 구하는 방법 두 가지를 써라.
    답

    np.trace(M), M.diagonal().sum() (또는 (M * np.eye(3)).sum()).

심화

  1. y = x[0]로 꺼낸 행을 바꾸면 x도 바뀌는 이유와, 바뀌지 않게 하는 방법을 말하여라.
    답

    NumPy의 조각은 원래 메모리를 공유하는 뷰(view)이다. y = x[0].copy()로 복사한다.
