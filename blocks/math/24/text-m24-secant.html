할선법과 종료 조건

본문
이 절에서 배울 것
  • 도함수 대신 두 점의 기울기를 쓰는 할선법을 구현한다.
  • 수렴 차수 \(\frac{1 + \sqrt5}2 \approx 1.618\)을 출력으로 관찰한다.
  • 절대 오차, 상대 오차, 잔차, 반복 상한을 섞은 종료 조건을 설계한다.
먼저 알아야 할 것
  • 뉴턴 방법 (5.2절), 기계 엡실론 (4.2절).

5.3.1할선법

뉴턴 방법의 \(f'(x_k)\)를 최근 두 점의 기울기 \(\frac{f(x_k) - f(x_{k-1})}{x_k - x_{k-1}}\)로 바꿉니다.

def secant(f, x0, x1, tol=1e-12, maxit=50):
    for k in range(1, maxit + 1):
        x2 = x1 - f(x1)*(x1 - x0)/(f(x1) - f(x0))
        print(k, repr(x2))
        x0, x1 = x1, x2
        if abs(x1 - x0) < tol:
            return x1
    raise RuntimeError('수렴하지 않음')

5.3.2종료 조건

어느 하나만으로는 위험합니다.

  • \(|x_{k+1} - x_k| < \text{tol}\): 근이 매우 크면(\(10^{10}\)) 간격이 \(10^{-6}\)보다 작아질 수 없어 끝나지 않는다. → 상대 조건 \(|x_{k+1} - x_k| < \text{rtol}\cdot|x_{k+1}|\)을 함께.
  • \(|f(x_k)| < \text{tol}\): \(f\)의 크기 단위에 좌우된다. \(10^6f\)는 같은 근인데 조건이 다르다.
  • 반복 상한: 수렴하지 않는 경우를 위해 늘 둔다.

실전 라이브러리는 abs(dx) < atol + rtol*abs(x) 꼴(예: atol = 1e-12, rtol = 4*eps)과 반복 상한을 함께 씁니다.

흔한 오해(1) 할선법이 이분법처럼 늘 수렴한다고 여긴다. 두 점이 근을 끼고 있지 않아도 되는 대신 발산할 수 있다(근을 끼도록 유지하는 변형이 가위치법). (2) \(f(x_1) = f(x_0)\)인 경우를 생각하지 않는다. 0으로 나누므로 검사가 필요하다.
요약
  1. 할선법: 기울기를 두 점으로, 수렴 차수 약 1.618.
  2. 도함수 불필요, 반복당 \(f\) 한 번.
  3. 종료: 절대 + 상대 변화량, 잔차, 반복 상한.

5.3.3연습문제

기본

  1. \(f(x) = x^2 - 2\), \(x_0 = 1\), \(x_1 = 2\)에서 할선법의 첫 단계 \(x_2\)를 구하여라.
    답

    \(x_2 = 2 - 2\cdot\frac{1}{2 - (-1)} = 2 - \frac23 = \frac43\).

응용

  1. 오차가 \(10^{-3}\), \(10^{-5}\)이면 할선법의 다음 오차는 대략? (\(e_{k+1} \approx Ce_ke_{k-1}\), \(C \approx 1\))
    답

    \(10^{-8}\), 그다음 \(10^{-13}\). 지수가 피보나치처럼 더해진다.

심화

  1. 근이 \(x^* = 10^{12}\) 근처일 때 abs(dx) < 1e-12만 쓰면 왜 끝나지 않는가?
    답

    \(10^{12}\) 근처의 부동소수점 간격은 \(10^{12}\cdot2.2\times10^{-16} \approx 2\times10^{-4}\)이라 \(|dx|\)가 0이 아닌 한 그보다 작아질 수 없다(0이 되면 끝나지만 진동할 수 있다). 상대 조건을 써야 한다.
