사인 적분의 롬베르크 표

예제 · 엉망인 첫 근사에서 출발해도

먼저 예측

\(\int_0^\pi\sin x\,dx = 2\)를 구간 하나짜리 사다리꼴로 계산하면 0입니다(양 끝값이 0). 이런 첫 근사에서 출발해도 롬베르크 외삽이 2에 다가갈까?

예측 확인

다가간다. 함숫값 9개로 오차 \(6\times10^{-6}\)이다.

\(\int_0^\pi\sin x\,dx\)의 롬베르크 표를 \(m = 3\) (사다리꼴 1, 2, 4, 8구간)까지 만들어라.

전략

\(R_{i,0} = T_{2^i}\), \(R_{i,j} = R_{i,j-1} + \frac{R_{i,j-1} - R_{i-1,j-1}}{4^j - 1}\) (6.4절).

풀이

  1. \(T_1 = 0\), \(T_2 = \frac\pi2\cdot1 = 1.5707963268\), \(T_4 = 1.8961188979\), \(T_8 = 1.9742316019\).
    사다리꼴, 양 끝 \(\sin = 0\).
  2. 0.0000000000
1.5707963268 2.0943951024
1.8961188979 2.0045597550 1.9985707318
1.9742316019 2.0002691699 1.9999831309 2.0000055500
    대각선이 2로.

검산

둘째 열은 심프슨 공식이다: \(S_2 = \frac\pi6(0 + 4 + 0) = \frac{2\pi}3 = 2.0943951024\). 마지막 대각 원소의 오차 \(5.6\times10^{-6}\)은 사다리꼴 \(T_8\)의 오차 \(0.026\)보다 4600배쯤 작다.

의미

외삽은 처음 근사가 아무리 나빠도 오차의 구조(\(h^2, h^4, \dots\)의 급수)만 맞으면 작동한다. 함숫값 9개로 5~6자리를 얻었다.

이해 확인

\(R_{2,1} = 2.0045597550\)을 \(T_2\), \(T_4\)로 직접 계산하여라.

답

\(T_4 + \frac{T_4 - T_2}3 = 1.8961188979 + 0.1084408570 = 2.0045597549\) (반올림 차).
