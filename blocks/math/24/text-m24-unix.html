Unix 명령으로 파일 다루기

본문
이 절에서 배울 것
  • 디렉터리 구조와 절대 경로, 상대 경로를 이해한다.
  • pwd, ls, cd, mkdir, cp, mv, rm으로 파일을 다룬다.
  • cat, head, tail, wc, grep으로 자료 파일의 내용을 살펴본다.
먼저 알아야 할 것
  • 컴퓨터의 파일과 폴더 개념. 실습 환경: Linux, macOS의 터미널 또는 Windows의 Git Bash, WSL.

1.1.1파일 시스템

Unix의 파일은 뿌리 /에서 갈라지는 나무 모양으로 놓입니다. /home/kim/proj/data.csv처럼 뿌리부터 쓴 것이 절대 경로, 지금 있는 곳(작업 디렉터리)에서부터 쓴 proj/data.csv가 상대 경로입니다. .은 현재 디렉터리, ..은 한 단계 위, ~은 홈 디렉터리입니다.

pwd                 # 지금 위치 출력
mkdir -p proj/data  # 디렉터리 만들기 (-p: 중간 것도)
cd proj             # 이동
ls -l               # 자세히 나열 (권한, 크기, 날짜)
cd ..               # 위로

1.1.2복사, 이동, 삭제

cp data/run1.csv backup.csv   # 복사
mv backup.csv old.csv         # 이름 바꾸기(이동)
rm old.csv                    # 삭제 (휴지통 없음!)
cp -r data data_copy          # 디렉터리 통째로 복사

rm은 되돌릴 수 없습니다. 특히 rm -r은 디렉터리 전체를 지우므로 경로를 두 번 확인하는 습관이 필요합니다. *는 아무 글자열에 맞는 와일드카드라 ls data/*.csv는 data 안의 csv 파일 전부입니다.

1.1.3내용 살펴보기

data에 실험 결과 run1.csv, run2.csv, run3.csv가 있고 각각 머리줄 x,y와 두 줄의 자료가 있다고 합시다.

$ cat data/run2.csv
x,y
0,2
1,4
$ wc -l data/*.csv
 3 data/run1.csv
 3 data/run2.csv
 3 data/run3.csv
 9 total
$ grep -c ',' data/run3.csv
3

cat은 내용 전체, head -n 5와 tail -n 5는 처음과 끝 5줄, wc -l은 줄 수, grep 패턴 파일은 패턴이 든 줄을 찾습니다(-c는 개수만). 큰 자료 파일을 편집기로 열기 전에 이 명령들로 모양을 먼저 확인합니다.

예 1.1.1 계산 결과 파일이 수백 개일 때 ls results/ | wc -l로 개수를, grep -l NaN results/*.txt로 계산이 깨진 파일 목록을 바로 얻습니다.
흔한 오해(1) rm으로 지운 파일이 휴지통에 간다고 여긴다. 바로 사라진다. (2) 상대 경로가 스크립트 파일의 위치 기준이라 여긴다. 명령을 실행한 작업 디렉터리 기준이다.
요약
  1. 절대 경로(/부터), 상대 경로(현재 위치부터), . .. ~.
  2. ls cd mkdir cp mv rm: 이동·만들기·복사·이름 바꾸기·삭제.
  3. cat head tail wc grep: 내용 확인.

1.1.4연습문제

기본

  1. /home/kim/proj에 있을 때 ../data/a.txt의 절대 경로는?
    답

    /home/kim/data/a.txt.

응용

  1. data의 모든 csv 파일을 backup 디렉터리로 복사하는 명령을 써라(디렉터리가 없을 수도 있다).
    답

    mkdir -p backup && cp data/*.csv backup/.

심화

  1. rm -r $DIR/*을 스크립트에 쓸 때 변수 DIR이 비어 있으면 무슨 일이 생기는가? 어떻게 막는가?
    답

    rm -r /*가 되어 시스템 전체를 지우려 한다. rm -r "${DIR:?}"/*처럼 비어 있으면 멈추게 하거나, 지우기 전에 경로를 검사한다.
