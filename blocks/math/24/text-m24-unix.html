Unix 명령으로 파일 다루기

본문

계산 결과 파일이 수백 개 쌓이면, 마우스로 하나씩 열어 보는 방법으로는 감당할 수 없다. 글자로 명령을 내려 파일을 찾고 옮기고 살펴보는 방법은 무엇일까? 파일의 위치는 어떻게 가리키며, 어떤 명령은 왜 특히 조심해야 할까?

먼저 알아야 할 것컴퓨터의 파일과 폴더 개념을 쓴다. 실습 환경은 Linux, macOS의 터미널이나 Windows의 Git Bash, WSL이다.

1.1.1파일 시스템

Unix의 파일은 그림 1처럼 뿌리 /에서 갈라지는 나무 모양으로 놓인다. /home/kim/proj/data.csv처럼 뿌리부터 쓴 것이 절대 경로이고, 지금 있는 곳, 곧 작업 디렉터리에서부터 쓴 proj/data.csv가 상대 경로이다. 또 .은 현재 디렉터리, ..은 한 단계 위, ~은 홈 디렉터리를 뜻한다.

pwd                 # 지금 위치 출력
mkdir -p proj/data  # 디렉터리 만들기 (-p 는 중간 것도)
cd proj             # 이동
ls -l               # 자세히 나열 (권한, 크기, 날짜)
cd ..               # 위로

1.1.2복사, 이동, 삭제

cp data/run1.csv backup.csv   # 복사
mv backup.csv old.csv         # 이름 바꾸기(이동)
rm old.csv                    # 삭제 (휴지통 없음!)
cp -r data data_copy          # 디렉터리 통째로 복사

rm은 되돌릴 수 없다. 특히 rm -r은 디렉터리 전체를 지우므로 경로를 두 번 확인하는 습관이 필요하다. 한편 *는 아무 글자열에 맞는 와일드카드이므로, ls data/*.csv는 data 안의 csv 파일 전부를 나열한다.

1.1.3내용 살펴보기

data에 실험 결과 run1.csv, run2.csv, run3.csv가 있고, 각각 머리줄 x,y와 두 줄의 자료가 있다고 하자.

$ cat data/run2.csv
x,y
0,2
1,4
$ wc -l data/*.csv
 3 data/run1.csv
 3 data/run2.csv
 3 data/run3.csv
 9 total
$ grep -c ',' data/run3.csv
3

cat은 내용 전체를, head -n 5와 tail -n 5는 처음과 끝 5줄을 보여 준다. 또 wc -l은 줄 수를 세고, grep 패턴 파일은 패턴이 든 줄을 찾으며 -c를 붙이면 개수만 센다. 그러므로 큰 자료 파일을 편집기로 열기 전에 이 명령들로 모양을 먼저 확인한다.

예제 1.1.1

계산 결과 파일이 results/에 수백 개 있을 때, 파일의 개수와 계산이 깨져 NaN이 든 파일의 목록을 얻어라.

풀이. ls results/ | wc -l로 개수를 세고, grep -l NaN results/*.txt로 NaN이 든 파일의 이름만 나열하면 된다. 여기서 -l은 줄 대신 파일 이름을 출력하라는 뜻이다.

흔한 오해rm으로 지운 파일이 휴지통에 간다고 여기기 쉽지만, 바로 사라져 되살릴 수 없다. 또 상대 경로가 스크립트 파일이 있는 위치를 기준으로 한다고 생각하는 것도 틀렸다. 상대 경로는 명령을 실행한 작업 디렉터리를 기준으로 한다.
마무리

처음 질문에 답하면, Unix에서는 cd, ls, cp, mv, rm 같은 명령으로 파일을 다루고, cat, head, wc, grep으로 내용을 살펴본다. 파일의 위치는 뿌리부터 쓴 절대 경로나 작업 디렉터리부터 쓴 상대 경로로 가리킨다. rm은 휴지통 없이 바로 지우므로 특히 조심해야 한다.

1.1.4연습문제

기본

  1. /home/kim/proj에 있을 때 ../data/a.txt의 절대 경로는?
    답

    /home/kim/data/a.txt.

응용

  1. data의 모든 csv 파일을 backup 디렉터리로 복사하는 명령을 써라(디렉터리가 없을 수도 있다).
    답

    mkdir -p backup && cp data/*.csv backup/.

심화

  1. rm -r $DIR/*을 스크립트에 쓸 때 변수 DIR이 비어 있으면 무슨 일이 생기는가? 어떻게 막는가?
    답

    rm -r /*가 되어 시스템 전체를 지우려 한다. rm -r "${DIR:?}"/*처럼 비어 있으면 멈추게 하거나, 지우기 전에 경로를 검사한다.
