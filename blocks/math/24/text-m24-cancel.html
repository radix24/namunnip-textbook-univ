상쇄 오차와 식 바꾸기

본문

연산 하나의 상대 오차가 \(10^{-16}\)이라면 계산 결과도 그만큼 정확할 것 같다. 그런데 \(1 - \cos(10^{-8})\)을 계산하면 답이 0으로 나온다. 거의 같은 두 수를 빼면 무슨 일이 생기는 것일까? 같은 값을 뺄셈 없이 계산하도록 식을 바꿀 수 있을까?

먼저 알아야 할 것기계 엡실론(4.2절), 삼각함수의 반각 공식, 유리화를 쓴다.

4.3.1상쇄

\(a\)와 \(b\)가 각각 상대 오차 \(10^{-16}\)으로 저장되어 있어도, \(a - b\)가 \(a\)보다 \(10^{-8}\)배 작으면 뺀 결과의 상대 오차는 \(10^{-16}\div10^{-8} = 10^{-8}\)으로 불어난다. 앞자리가 지워지면서 뒤쪽의 반올림 잡음만 남기 때문이며, 이를 상쇄라 한다.

>>> x = 1e-8
>>> 1 - math.cos(x)
0.0
>>> 2*math.sin(x/2)**2
5.0000000000000005e-17

참값은 \(\frac{x^2}2 = 5\times10^{-17}\)이다. 그런데 \(\cos(10^{-8}) = 1 - 5\times10^{-17}\)은 1과의 차가 \(\frac\varepsilon2\)보다 작아 1로 반올림되었으므로, 빼면 0이 된다. 반면 반각 공식 \(1 - \cos x = 2\sin^2\frac x2\)는 뺄셈이 없어 정확하다.

4.3.2유리화

>>> x = 1e5
>>> math.sqrt(x + 1) - math.sqrt(x)
0.001581134877255863
>>> 1/(math.sqrt(x + 1) + math.sqrt(x))
0.0015811348772568783

\(\sqrt{x + 1} - \sqrt x = \frac1{\sqrt{x + 1} + \sqrt x}\)로 바꾸면 덧셈만 남는다. 그러므로 앞의 결과는 유효숫자 11자리쯤만 맞고 뒤쪽 55863이 틀리지만, 뒤의 결과는 16자리가 맞는다.

4.3.3이차방정식

\(b = 10^8\)일 때 \(x^2 - bx + 1 = 0\)의 작은 근 \(\approx 10^{-8}\)을 근의 공식 \(\frac{b - \sqrt{b^2 - 4}}2\)로 구하면, 거의 같은 두 수의 차라서 상쇄가 생긴다.

>>> b = 1e8
>>> (b - math.sqrt(b*b - 4))/2
7.450580596923828e-09
>>> 2/(b + math.sqrt(b*b - 4))
1e-08

첫 결과는 25%나 틀렸다. 대신 근과 계수의 관계 \(x_1x_2 = 1\)을 써서 정확한 큰 근으로 작은 근을 구하면 정확하다. 일반적으로 \(ax^2 + bx + c = 0\)에서는 \(q = -\frac12\left(b + \operatorname{sign}(b)\sqrt{b^2 - 4ac}\right)\)로 두고 \(x_1 = \frac qa\), \(x_2 = \frac cq\)를 쓴다.

상쇄는 큰 계산 속에서 눈에 띄지 않게 일어나기도 한다. 예를 들어 표본분산을 \(\frac1n\sum x_i^2 - \bar x^2\)으로 계산하면, 자료의 평균이 표준편차보다 훨씬 클 때 거의 같은 두 수를 빼게 되어 정확도가 크게 떨어진다. 그래서 통계 라이브러리는 평균을 먼저 빼고 제곱하는 \(\frac1n\sum(x_i - \bar x)^2\)이나, 자료를 한 번 훑으며 갱신하는 웰퍼드 방법을 쓴다.

흔한 오해상쇄가 빼기 연산 자체의 오차라고 여기기 쉽지만, 빼기는 정확에 가깝고 입력에 이미 있던 작은 오차가 상대적으로 커지는 것이다. 또 4배정밀도처럼 정밀도를 올리면 해결된다고 생각하는 것도 틀렸다. 그것은 문제를 미룰 뿐이고, 식을 바꾸는 것이 근본적인 해결이다.
마무리

처음 질문에 답하면, 거의 같은 두 수를 빼면 앞자리가 지워지고 입력의 반올림 잡음만 남아 상대 오차가 크게 불어나며, 이를 상쇄라 한다. \(1 - \cos(10^{-8})\)이 0이 되는 것이 그 예이다. 반각 공식 \(2\sin^2\frac x2\), 유리화, 근과 계수의 관계처럼 뺄셈을 없애도록 식을 바꾸면 거의 \(10^{-16}\)의 정확도를 되찾는다.

4.3.4연습문제

기본

  1. \(x\)가 작을 때 \(e^x - 1\)을 정확히 계산하는 함수 이름(Python, C 공통)을 말하여라.
    답

    expm1(x). 마찬가지로 \(\ln(1 + x)\)는 log1p(x).

응용

  1. \(x\)가 클 때 \(\frac1x - \frac1{x + 1}\)을 안정하게 바꿔라.
    답

    \(\frac1{x(x + 1)}\).

심화

  1. \(\frac{1 - \cos x}{x^2}\)을 \(x = 10^{-4}\)에서 그대로 계산하면 유효숫자가 몇 자리쯤 맞겠는가?
    답

    \(1 - \cos x \approx 5\times10^{-9}\)으로 1보다 \(5\times10^{-9}\)배 작아 상대 오차가 \(10^{-16}\div(5\times10^{-9}) \approx 2\times10^{-8}\), 약 7~8자리. 반각 공식이면 16자리.
