기호 계산의 한계와 수치 계산

본문
이 절에서 배울 것
  • 닫힌 꼴의 원시함수가 없는 적분과, 특수함수로 답하는 경우를 알아본다.
  • N, nsolve, lambdify로 기호 결과를 수치 계산에 넘긴다.
  • 식 단순화가 늘 원하는 꼴을 주지는 않음을 안다.
먼저 알아야 할 것
  • 기호 적분과 방정식 (2.1절, 2.2절).

2.3.1닫힌 꼴이 없는 적분

\(e^{-x^2}\), \(\frac{\sin x}x\), \(x^x\)의 원시함수는 초등함수로 쓸 수 없습니다(리우빌의 정리). 기호 계산은 특수함수로 답하거나 계산하지 못한 채 돌려줍니다.

>>> integrate(exp(-x**2), (x, 0, 1))
sqrt(pi)*erf(1)/2
>>> N(_)
0.746824132812427
>>> integrate(sin(x)/x, x)
Si(x)
>>> integrate(x**x, (x, 0, 1))
Integral(x**x, (x, 0, 1))

erf(오차함수), Si(사인 적분)는 정의 자체가 이 적분인 특수함수입니다. 마지막처럼 Integral(…)이 그대로 나오면 계산에 실패한 것이고, N(…)으로 수치적분을 시킵니다(\(\int_0^1x^xdx \approx 0.7834\)).

2.3.2수치로 넘기기

>>> nsolve(cos(x) - x, x, 1)
0.739085133215161
>>> f = lambdify(x, diff(x**3*exp(-x), x), 'math')
>>> f(3.0)
0.0

nsolve(식, 변수, 시작값)은 뉴턴 방법으로 수치해를 찾습니다(5장). lambdify는 기호식을 빠른 Python 함수로 바꿉니다. 도함수를 기호로 정확히 구한 뒤 수치 계산에 쓰는 흔한 방식으로, 위에서 \((x^3e^{-x})' = x^2e^{-x}(3 - x)\)이 \(x = 3\)에서 0임을 확인합니다.

2.3.3단순화

simplify(sin(x)**2 + cos(x)**2)는 1이지만, "가장 간단한 꼴"은 정의가 모호해 원하는 꼴이 안 나올 때가 많습니다. expand(전개), factor(인수분해), trigsimp, cancel처럼 목적이 분명한 함수를 쓰는 편이 예측 가능합니다. 또 \(\sqrt{x^2} = |x|\)처럼 변수의 범위를 알려 줘야(symbols('x', positive=True)) 단순화되는 경우가 있습니다.

흔한 오해(1) 기호 계산이 답을 못 주면 적분값이 없다고 여긴다. 원시함수가 초등함수가 아닐 뿐 값은 있다. (2) simplify가 늘 같은 결과를 준다고 여긴다. 버전과 식에 따라 다르다.
요약
  1. 초등 원시함수가 없으면 특수함수(erf, Si)나 미계산 Integral.
  2. N, nsolve, lambdify로 수치 계산과 결합.
  3. 목적이 분명한 단순화 함수와 변수 가정.

2.3.4연습문제

기본

  1. \(\int_0^\infty e^{-x^2}dx\)를 SymPy로 구하면 무엇이 나오는가?
    답

    sqrt(pi)/2. 정적분은 원시함수 없이도 정확히 나올 수 있다.

응용

  1. sqrt(x**2)가 x로 단순화되지 않는 이유와 해결법을 말하여라.
    답

    \(x\)가 음수일 수 있어 \(|x|\)이다. x = symbols('x', positive=True)로 선언하면 x가 된다.

심화

  1. \(\tan x = x\)의 양수 해 중 가장 작은 것을 nsolve로 구할 때 시작값을 1로 하면 어떤 문제가 생길 수 있는가? 어떤 시작값이 좋은가?
    답

    \(x = 0\)이 자명한 해라 1에서 출발하면 0으로 갈 수 있고, \(\frac\pi2\) 근처의 점근선도 방해한다. 해 \(4.4934\)는 \(\left(\pi, \frac{3\pi}2\right)\)에 있으므로 시작값 4.5 정도가 좋다.
