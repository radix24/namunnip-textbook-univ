다항식 보간과 룽게 현상

본문
이 절에서 배울 것
  • \(n + 1\)개 점을 지나는 \(n\)차 다항식을 라그랑주 꼴로 구현한다.
  • 등간격 점에서 차수를 올리면 양 끝에서 진동이 커지는 룽게 현상을 관찰한다.
  • 체비쇼프 점 \(x_j = \cos\frac{(2j + 1)\pi}{2(n + 1)}\)로 바꾸어 개선한다.
먼저 알아야 할 것
  • 배열과 그래프 (3.1절, 3.3절). 이론은 수학16 3장.

6.1.1구현

점 \((x_j, y_j)\)를 지나는 다항식은 \(p(x) = \sum_jy_jL_j(x)\), \(L_j(x) = \prod_{i\ne j}\frac{x - x_i}{x_j - x_i}\)입니다.

def lagrange(xs, ys, x):
    p = 0.0
    for j in range(len(xs)):
        L = 1.0
        for i in range(len(xs)):
            if i != j:
                L *= (x - xs[i])/(xs[j] - xs[i])
        p += ys[j]*L
    return p

점이 많으면 무게중심 꼴(barycentric)이 더 빠르고 안정적이며, NumPy의 np.polyfit(xs, ys, n)은 계수를 구합니다(차수가 높으면 계수 계산이 불안정해집니다).

6.1.2룽게 현상

\(f(x) = \frac1{1 + 25x^2}\)을 \([-1, 1]\)의 등간격 \(n + 1\)점에서 보간하면, \(n\)이 커질수록 가운데는 좋아지지만 양 끝에서 진동이 폭발합니다. 최대 오차는 \(n = 10\)에서 약 1.9, \(n = 20\)에서 약 60입니다. 보간 오차 공식

\[f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n + 1)!}\prod_{j=0}^n(x - x_j)\]

에서 등간격 점의 곱 \(\prod(x - x_j)\)가 끝 근처에서 가운데보다 지수적으로 크고, 이 함수의 고계 도함수도 빠르게 자라기 때문입니다.

6.1.3체비쇼프 점

점을 끝 쪽에 촘촘히 두면 \(\max|\prod(x - x_j)|\)가 최소(\(2^{-n}\))가 됩니다. 그 점이 체비쇼프 점(체비쇼프 다항식의 근)입니다. 같은 함수에서 체비쇼프 점을 쓰면 \(n\)을 올릴수록 오차가 지수적으로 줄어듭니다(\(n = 20\)에서 약 \(0.015\)). 이 절의 탐구 카드에서 직접 확인할 수 있습니다.

흔한 오해(1) 점을 늘리면 보간이 늘 좋아진다고 여긴다. 등간격이면 나빠질 수 있다. (2) 자료가 많으면 높은 차수의 다항식 하나로 맞추는 것이 좋다고 여긴다. 구간별 낮은 차수(스플라인)나 최소제곱 맞춤이 대개 낫다.
요약
  1. 라그랑주 꼴 구현, 높은 차수는 무게중심 꼴.
  2. 등간격 고차 보간: 양 끝 진동(룽게).
  3. 체비쇼프 점으로 오차가 지수적으로 감소.

6.1.4연습문제

기본

  1. 세 점 \((0, 1), (1, 3), (2, 7)\)을 지나는 이차식을 구하여라.
    답

    \(p(x) = x^2 + x + 1\).

응용

  1. \(n = 4\)인 체비쇼프 점 5개를 구하여라.
    답

    \(\cos\frac{\pi}{10}, \cos\frac{3\pi}{10}, 0, -\cos\frac{3\pi}{10}, -\cos\frac{\pi}{10}\) ≈ \(\pm0.951, \pm0.588, 0\).

심화

  1. np.polyfit으로 20차 다항식 계수를 구하면 경고가 나오는 이유를 말하여라.
    답

    계수를 푸는 방데르몽드 행렬의 조건수가 매우 커서(\(10^{10}\) 이상) 계수에 큰 오차가 생긴다. 보간값 자체는 무게중심 꼴로 안정적으로 계산할 수 있다.
