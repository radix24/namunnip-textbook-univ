단체 호몰로지 계산

본문
이 절에서 배울 것
  • 경계 연산자를 행렬로 쓰고 핵과 상을 구해 \(H_k = Z_k/B_k\)를 계산한다.
  • \(H_0\)이 연결 성분, \(H_1\)이 1차원 구멍을 셈을 확인한다.
  • 오일러 지표가 베티 수의 교대합 \(\chi = \sum(-1)^k\operatorname{rank}H_k\)임을 보인다.
먼저 알아야 할 것
  • 사슬과 경계 (6.1절), 행렬의 계수와 차원 정리 (수학2).

6.2.1원

예 6.2.1 속이 빈 삼각형 \(K\) (꼭짓점 \(a, b, c\), 변 \(e_1 = [a, b]\), \(e_2 = [b, c]\), \(e_3 = [c, a]\)). \[\partial_1 = \begin{pmatrix}-1 & 0 & 1\\ 1 & -1 & 0\\ 0 & 1 & -1\end{pmatrix}\] (열은 \(e_1, e_2, e_3\), 행은 \(a, b, c\)). 계수 2이라 \(Z_1 = \ker\partial_1\)은 계수 1, \((1, 1, 1)\)로 생성. \(B_1 = 0\) (2-단체 없음). \(H_1 = \mathbb Z\). \(H_0 = \mathbb Z^3/\operatorname{im}\partial_1 \cong \mathbb Z\) (\(\operatorname{im}\partial_1\)은 성분 합이 0인 벡터들).

연결 성분이 \(c\)개이면 \(H_0 \cong \mathbb Z^c\)라는 것은 일반적으로 성립합니다. 같은 성분의 두 꼭짓점은 변 경로로 이어져 차가 경계이기 때문입니다.

6.2.2구면

예 6.2.2 사면체의 겉면 \(\partial\Delta^3\) (꼭짓점 4, 변 6, 면 4)은 \(S^2\)입니다. 네 면의 합(방향을 맞춰) \(\partial[v_0, v_1, v_2, v_3]\)은 \(\partial_2\)의 핵에 있고 3-단체가 없어 경계가 아니므로 \(H_2 = \mathbb Z\). 계수로 세면 \(\operatorname{rank}\partial_1 = 3\), \(\operatorname{rank}\partial_2 = 3\)이라 \(\operatorname{rank}Z_1 = 6 - 3 = 3 = \operatorname{rank}B_1\), \(H_1 = 0\). 따라서 \(H_0 = \mathbb Z\), \(H_1 = 0\), \(H_2 = \mathbb Z\).

\(S^2\)는 단순연결이라 \(H_1 = 0\)이지만 \(H_2 \ne 0\)이라 수축 가능하지 않습니다. 기본군이 못 본 2차원 구멍을 호몰로지가 봅니다.

6.2.3오일러 지표

\(\beta_k = \operatorname{rank}H_k\)를 \(k\)번째 베티 수라 합니다.

정리 6.2.3 (오일러-푸앵카레) \(c_k\)를 \(k\)-단체의 수라 하면 \(\sum_k(-1)^kc_k = \sum_k(-1)^k\beta_k\).
증명

차원 정리로 \(c_k = \operatorname{rank}Z_k + \operatorname{rank}B_{k-1}\), \(\beta_k = \operatorname{rank}Z_k - \operatorname{rank}B_k\). 교대합을 취하면 \(B\) 항이 소거된다. ∎

우변은 위상 불변량(6.3절)이므로 좌변의 오일러 지표도 분할과 무관합니다. 5장에서 확인만 했던 사실의 증명입니다. 원환면은 \(\beta = (1, 2, 1)\)로 \(\chi = 0\), \(S^2\)는 \((1, 0, 1)\)로 2입니다.

흔한 오해(1) \(H_1\)의 계수가 고리의 수라 여긴다. 서로 독립인(경계로 이어지지 않는) 고리의 수다. (2) 호몰로지가 늘 자유 아벨군이라 여긴다. \(\mathbb RP^2\)는 \(H_1 = \mathbb Z_2\)로 꼬임이 있다(연습문제 3).
요약
  1. \(\partial\)를 행렬로: \(H_k = \ker\partial_k/\operatorname{im}\partial_{k+1}\).
  2. 원 \((\mathbb Z, \mathbb Z)\), 구면 \((\mathbb Z, 0, \mathbb Z)\). \(H_0\)은 연결 성분.
  3. \(\chi = \sum(-1)^kc_k = \sum(-1)^k\beta_k\).

6.2.4연습문제

기본

  1. 속이 찬 삼각형(면 하나 포함)의 호몰로지를 구하여라.
    답

    \(z = \partial[a, b, c]\)라 \(H_1 = 0\), \(\partial_2\)가 단사라 \(H_2 = 0\), \(H_0 = \mathbb Z\). 점과 같다.

응용

  1. 8자 모양 그래프(꼭짓점 1개에 고리 2개, 단체로 나누면 꼭짓점 5개 변 6개)의 \(H_1\)을 구하여라.
    답

    연결이라 \(\operatorname{rank}Z_1 = E - V + 1 = 2\), \(B_1 = 0\). \(H_1 = \mathbb Z^2\).

심화

  1. \(\mathbb RP^2\)의 CW 구조(셀 하나씩, 2-셀의 경계가 \(a\)를 두 번 감음)로 셀 호몰로지 \(\partial_2(D) = 2a\), \(\partial_1(a) = 0\)을 써서 \(H_*\)를 구하여라.
    답

    \(H_0 = \mathbb Z\), \(H_1 = \mathbb Z/2\mathbb Z\), \(H_2 = \ker\partial_2 = 0\). \(\chi = 1 - 0 + 0 = 1\) (꼬임은 계수에 들어가지 않음).
