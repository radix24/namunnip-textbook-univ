응용과 쌍대성 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 증명\(S^{n-1}\)이 \(D^n\)의 수축이 아님을 \(\tilde H_{n-1}\)로 보여라(\(n \ge 2\)). [07-01]

    힌트 1

    \(r\circ i = \mathrm{id}\).

    힌트 2

    \(\tilde H_{n-1}(D^n) = 0\).

    풀이

    \(\mathbb Z \xrightarrow{i_*} 0 \xrightarrow{r_*} \mathbb Z\)의 합성이 항등일 수 없다. ∎ (7.1절)

  2. 계산\(S^3\)의 대척사상의 차수와, \(S^3\) 위의 영점 없는 접벡터장 하나를 써라. [07-01]

    힌트 1

    \((-1)^{n+1}\).

    힌트 2

    \((x_1, x_2, x_3, x_4) \mapsto (-x_2, x_1, -x_4, x_3)\).

    풀이

    차수 \(+1\). 벡터장 \(v(x) = (-x_2, x_1, -x_4, x_3)\)은 \(v\cdot x = 0\), \(|v| = 1\).

  3. 계산\(S^2\)에서 차수 \(-1\)인 사상의 레프셰츠 수를 구하고, 부동점이 없을 수 있는지 말하여라. [07-02]

    힌트 1

    \(L = 1 + \deg f\).

    힌트 2

    대척사상.

    풀이

    \(L = 0\). 대척사상(차수 \(-1\))은 부동점이 없다 (7.2절).

  4. 계산원환면에서 \(A = \begin{pmatrix}1 & 1\\ 0 & 1\end{pmatrix}\)이 유도하는 사상의 레프셰츠 수를 구하여라. [07-02]

    힌트 1

    \(L = \det(I - A)\).

    힌트 2

    \(I - A = \begin{pmatrix}0 & -1\\ 0 & 0\end{pmatrix}\).

    풀이

    \(L = 0\). 실제로 부동점은 \(y \equiv 0\)인 원 전체(\((x + y, y) = (x, y)\))로 고립되지 않는다.

  5. 계산닫힌 가향 4차원 다양체에서 \(\beta_0 = 1\), \(\beta_1 = 0\), \(\beta_2 = 2\)이면 \(\chi\)는? [07-03]

    힌트 1

    \(\beta_3 = \beta_1\), \(\beta_4 = \beta_0\).

    힌트 2

    교대합.

    풀이

    \(1 - 0 + 2 - 0 + 1 = 4\). (예: \(S^2\times S^2\)) (7.3절)

  6. 판단"닫힌 5차원 다양체의 오일러 지표는 0이다." 참인지 판단하여라. [07-03]

    힌트 1

    가향이면 \(\beta_k = \beta_{5-k}\).

    힌트 2

    비가향이면 \(\mathbb Z_2\) 계수로 같은 논법.

    풀이

    참. 쌍대성으로 \(k\)와 \(5 - k\)의 항이 반대 부호로 짝지어 상쇄된다. 비가향이어도 \(\mathbb Z_2\) 계수 베티 수로 계산한 \(\chi\)가 같은 값이라 0이다.
