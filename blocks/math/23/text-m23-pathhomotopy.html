경로 호모토피와 경로의 곱

본문
이 절에서 배울 것
  • 끝점을 고정한 경로 호모토피 \(\simeq_p\)를 정의한다.
  • 경로의 곱 \(\alpha * \beta\)와 역경로 \(\bar\alpha\)를 정의한다.
  • 곱이 호모토피 류 수준에서 결합적이고 항등원과 역원을 가짐을 재매개화로 증명한다.
먼저 알아야 할 것
  • 호모토피 (1.1절), 경로연결 (수학14).

1.2.1경로 호모토피

경로는 연속사상 \(\alpha : I \to X\)입니다. 같은 시작점 \(x_0\)과 끝점 \(x_1\)을 가진 두 경로 \(\alpha, \beta\) 사이의 호모토피 \(H\)가 모든 \(t\)에서 \(H(0, t) = x_0\), \(H(1, t) = x_1\)이면 경로 호모토피라 하고 \(\alpha \simeq_p \beta\)라 씁니다. 끝점을 고정하지 않으면 모든 경로가 상수 경로로 줄어들어(\(H(s, t) = \alpha((1 - t)s)\)) 아무 정보도 남지 않기 때문입니다. 경로 호모토피 류를 \([\alpha]\)라 씁니다.

1.2.2곱과 역

\(\alpha\)의 끝점이 \(\beta\)의 시작점이면

\[(\alpha * \beta)(s) = \begin{cases}\alpha(2s) & 0 \le s \le \frac12\\ \beta(2s - 1) & \frac12 \le s \le 1\end{cases}, \qquad \bar\alpha(s) = \alpha(1 - s).\]

두 배 빠르게 \(\alpha\)를 지나고 이어서 \(\beta\)를 지나는 경로입니다. 경로 자체로는 결합법칙이 성립하지 않습니다. \((\alpha * \beta) * \gamma\)는 \(\alpha\)를 시간 \(\frac14\) 동안, \(\alpha * (\beta * \gamma)\)는 \(\frac12\) 동안 지나 다른 함수입니다. 하지만 호모토피 류에서는 성립합니다.

정리 1.2.1 경로 호모토피 류에서 \([\alpha] * [\beta] := [\alpha * \beta]\)는 잘 정의되고
  1. \(([\alpha] * [\beta]) * [\gamma] = [\alpha] * ([\beta] * [\gamma])\)
  2. \([e_{x_0}] * [\alpha] = [\alpha] = [\alpha] * [e_{x_1}]\) (\(e_x\)는 상수 경로)
  3. \([\alpha] * [\bar\alpha] = [e_{x_0}]\)
증명의 핵심

재매개화 보조정리: \(\varphi : I \to I\)가 연속이고 \(\varphi(0) = 0\), \(\varphi(1) = 1\)이면 \(\alpha\circ\varphi \simeq_p \alpha\). 호모토피 \(H(s, t) = \alpha((1 - t)\varphi(s) + ts)\)가 끝점을 고정한다. (1)은 \((\alpha * \beta) * \gamma = (\alpha * (\beta * \gamma))\circ\varphi\)인 조각마다 일차인 \(\varphi\)가 있어서, (2)도 같은 방식이다. (3)은 \(H(s, t) = \alpha(2s(1 - t))\) (\(s \le \frac12\)), \(\alpha((2 - 2s)(1 - t))\) (\(s \ge \frac12\)): 시각 \(t\)에는 \(\alpha\)를 \(1 - t\)까지만 갔다가 되돌아온다. ∎

1.2.3군의 준비

시작점과 끝점이 모두 \(x_0\)인 경로(고리)만 모으면 곱이 늘 정의되고, 위 정리가 군의 공리 그대로입니다. 이것이 2.1절의 기본군입니다. 시작점과 끝점이 다른 경로까지 모으면 "군의 모임이 서로 이어진" 구조(기본 군도)가 됩니다.

흔한 오해(1) 경로 호모토피에서 끝점이 움직여도 된다고 여긴다. 그러면 모든 경로가 상수로 줄어든다. (2) \(\alpha * \beta = \beta * \alpha\)라 여긴다. 끝점이 맞아도 일반적으로 다르다(8자 공간, 4.2절).
요약
  1. 경로 호모토피: 끝점 고정 \(\simeq_p\).
  2. 곱 \(\alpha * \beta\)는 두 배 속도로 이어 붙이기, 역은 거꾸로.
  3. 호모토피 류에서 결합·항등·역: 재매개화 보조정리.

1.2.4연습문제

기본

  1. \(\mathbb R^2\)에서 같은 끝점을 가진 두 경로는 늘 경로 호모토픽임을 보여라.
    답

    직선 호모토피 \(H(s, t) = (1 - t)\alpha(s) + t\beta(s)\)는 \(s = 0, 1\)에서 공통 끝점에 고정.

응용

  1. \((\alpha * \beta) * \gamma = (\alpha * (\beta * \gamma))\circ\varphi\)가 되는 \(\varphi\)를 써라.
    답

    \(\varphi(s) = \frac s2\) (\(0 \le s \le \frac12\)), \(s - \frac14\) (\(\frac12 \le s \le \frac34\)), \(2s - 1\) (\(\frac34 \le s \le 1\)).

심화

  1. \(\alpha \simeq_p \alpha'\), \(\beta \simeq_p \beta'\)이면 \(\alpha * \beta \simeq_p \alpha' * \beta'\)임을 보여 곱이 잘 정의됨을 확인하여라.
    답

    두 호모토피 \(F\), \(G\)를 \(s\)에 대해 이어 붙인 \(H(s, t) = F(2s, t)\) (\(s \le \frac12\)), \(G(2s - 1, t)\) (\(s \ge \frac12\)). \(s = \frac12\)에서 둘 다 공통 중간점이라 연속.
