경로 호모토피와 경로의 곱

본문

경로를 이어 붙이는 일은 수의 곱셈처럼 보이지만, 경로 자체로는 결합법칙조차 성립하지 않는다. 경로를 어떤 기준으로 같다고 보면 이어 붙이기가 군의 연산처럼 될까? 갔다가 그대로 되돌아오는 경로는 그 기준에서 아무것도 하지 않은 경로와 같을까?

먼저 알아야 할 것호모토피(1.1절), 경로연결(수학14)을 쓴다.

1.2.1경로 호모토피

경로는 연속사상 \(\alpha : I \to X\)이다. 같은 시작점 \(x_0\)과 끝점 \(x_1\)을 가진 두 경로 \(\alpha, \beta\) 사이의 호모토피 \(H\)가 모든 \(t\)에서 \(H(0, t) = x_0\), \(H(1, t) = x_1\)을 만족하면 경로 호모토피라 하고 \(\alpha \simeq_p \beta\)라 쓴다. 끝점을 고정하는 까닭은, 그러지 않으면 \(H(s, t) = \alpha((1 - t)s)\)로 모든 경로가 상수 경로로 줄어들어 아무 정보도 남지 않기 때문이다. 경로 호모토피 류를 \([\alpha]\)라 쓴다.

1.2.2곱과 역

\(\alpha\)의 끝점이 \(\beta\)의 시작점이면 곱과 역을 다음과 같이 정의한다.

\[(\alpha * \beta)(s) = \begin{cases}\alpha(2s) & 0 \le s \le \frac12\\ \beta(2s - 1) & \frac12 \le s \le 1\end{cases}, \qquad \bar\alpha(s) = \alpha(1 - s)\]

곱은 두 배 빠르게 \(\alpha\)를 지나고 이어서 \(\beta\)를 지나는 경로이다. 그런데 경로 자체로는 결합법칙이 성립하지 않는다. \((\alpha * \beta) * \gamma\)는 \(\alpha\)를 시간 \(\frac14\) 동안 지나고, \(\alpha * (\beta * \gamma)\)는 \(\frac12\) 동안 지나므로 서로 다른 함수이다. 하지만 호모토피 류에서는 성립한다.

정리 1.2.1

경로 호모토피 류에서 \([\alpha] * [\beta] := [\alpha * \beta]\)는 잘 정의되고 다음이 성립한다. (1) 결합법칙 \(([\alpha] * [\beta]) * [\gamma] = [\alpha] * ([\beta] * [\gamma])\). (2) 상수 경로 \(e_x\)에 대해 \([e_{x_0}] * [\alpha] = [\alpha] = [\alpha] * [e_{x_1}]\). (3) \([\alpha] * [\bar\alpha] = [e_{x_0}]\).

증명의 요점.재매개화 보조정리가 열쇠이다. 즉 \(\varphi : I \to I\)가 연속이고 \(\varphi(0) = 0\), \(\varphi(1) = 1\)이면, 끝점을 고정하는 호모토피 \(H(s, t) = \alpha((1 - t)\varphi(s) + ts)\)에 의해 \(\alpha\circ\varphi \simeq_p \alpha\)이다. (1)은 \((\alpha * \beta) * \gamma = (\alpha * (\beta * \gamma))\circ\varphi\)인 조각마다 일차인 \(\varphi\)가 있어서 성립하고, (2)도 같은 방식이다. (3)은 \(s \le \frac12\)이면 \(H(s, t) = \alpha(2s(1 - t))\), \(s \ge \frac12\)이면 \(H(s, t) = \alpha((2 - 2s)(1 - t))\)로 두면 된다. 즉 그림 1처럼 시각 \(t\)에는 \(\alpha\)를 \(1 - t\)까지만 갔다가 되돌아온다. ∎

1.2.3군의 준비

시작점과 끝점이 모두 \(x_0\)인 경로, 곧 고리만 모으면 곱이 늘 정의되고, 위 정리가 군의 공리 그대로이다. 이것이 2.1절의 기본군이다. 한편 시작점과 끝점이 다른 경로까지 모으면 군들이 서로 이어진 구조가 되며, 이를 기본 군도라 한다.

흔한 오해경로 호모토피에서 끝점이 움직여도 된다고 여기기 쉽지만, 그러면 모든 경로가 상수 경로로 줄어든다. 또 끝점이 맞으면 \(\alpha * \beta = \beta * \alpha\)라고 생각하는 것도 틀렸다. 일반적으로 두 곱은 호모토피 류로도 다르며, 4.2절의 8자 공간이 그 예이다.
마무리

처음 질문에 답하면, 끝점을 고정한 경로 호모토피로 같은 것을 묶으면 이어 붙이기가 결합법칙을 만족하고, 상수 경로가 항등원 노릇을 하며, 되돌아가는 경로 \(\bar\alpha\)가 역원이 된다. 갔다가 그대로 되돌아오는 경로는 \(1 - t\)까지만 갔다 오는 호모토피로 상수 경로와 같다. 고리만 모으면 이것이 곧 군이 된다.

1.2.4연습문제

기본

  1. \(\mathbb R^2\)에서 같은 끝점을 가진 두 경로는 늘 경로 호모토픽임을 보여라.
    답

    직선 호모토피 \(H(s, t) = (1 - t)\alpha(s) + t\beta(s)\)는 \(s = 0, 1\)에서 공통 끝점에 고정.

응용

  1. \((\alpha * \beta) * \gamma = (\alpha * (\beta * \gamma))\circ\varphi\)가 되는 \(\varphi\)를 써라.
    답

    \(\varphi(s) = \frac s2\) (\(0 \le s \le \frac12\)), \(s - \frac14\) (\(\frac12 \le s \le \frac34\)), \(2s - 1\) (\(\frac34 \le s \le 1\)).

심화

  1. \(\alpha \simeq_p \alpha'\), \(\beta \simeq_p \beta'\)이면 \(\alpha * \beta \simeq_p \alpha' * \beta'\)임을 보여 곱이 잘 정의됨을 확인하여라.
    답

    두 호모토피 \(F\), \(G\)를 \(s\)에 대해 이어 붙인 \(H(s, t) = F(2s, t)\) (\(s \le \frac12\)), \(G(2s - 1, t)\) (\(s \ge \frac12\)). \(s = \frac12\)에서 둘 다 공통 중간점이라 연속.
