푸앵카레 쌍대성

본문
이 절에서 배울 것
  • 닫힌 가향 \(n\)차원 다양체에서 \(H^k(M) \cong H_{n-k}(M)\)이라는 푸앵카레 쌍대성을 진술한다.
  • 베티 수의 대칭 \(\beta_k = \beta_{n-k}\)와 홀수 차원 다양체의 \(\chi = 0\)을 결론짓는다.
  • 쌍대 셀 분할과 교차수로 쌍대성의 기하학적 뜻을 이해한다.
먼저 알아야 할 것
  • 호몰로지 (6.2절), 곡면의 분류 (5.2절), 쌍대공간 (수학2).

7.3.1코호몰로지

사슬군의 쌍대 \(C^k = \operatorname{Hom}(C_k, \mathbb Z)\)에 \(\delta = \partial^*\)를 주고 그 호몰로지를 코호몰로지 \(H^k(X)\)라 합니다. 사슬이 "공간 안의 도형"이라면 코사슬은 "도형에 값을 매기는 함수"입니다(미분형식과 적분의 관계, 수학17의 드람 정리). 체 계수에서는 \(H^k \cong (H_k)^*\)라 차원이 같습니다.

7.3.2정리

정리 7.3.1 (푸앵카레 쌍대성) \(M\)이 닫힌(컴팩트, 경계 없음) 가향 \(n\)차원 다양체이면 기본류 \([M] \in H_n(M) \cong \mathbb Z\)와의 캡곱이 동형 \(H^k(M) \cong H_{n-k}(M)\)을 준다. 비가향이면 \(\mathbb Z_2\) 계수로 성립한다.

기하학적 그림은 쌍대 셀 분할입니다. 삼각분할의 각 \(k\)-단체에 그 단체를 수직으로 가로지르는 \((n - k)\)-셀을 대응시킵니다(2차원에서 꼭짓점 ↔ 면, 변 ↔ 변, 면 ↔ 꼭짓점). 원래 분할의 \(k\)-사슬과 쌍대 분할의 \((n - k)\)-사슬이 교차수로 짝지어집니다.

7.3.3결과

  • 체 계수에서 \(\beta_k = \beta_{n-k}\). 곡면은 \(\beta_0 = \beta_2 = 1\), 원환면 \((1, 2, 1)\), \(\Sigma_g\)는 \((1, 2g, 1)\).
  • \(n\)이 홀수이면 \(\chi = \sum(-1)^k\beta_k\)에서 \(k\)와 \(n - k\)의 항이 반대 부호로 상쇄되어 \(\chi(M) = 0\).
  • \(n = 2m\)이면 \(H_m\) 위의 교차형식(대칭 또는 반대칭 쌍선형형식)이 비퇴화이다. 곡면에서 \(H_1\)의 교차형식은 반대칭이라 \(\beta_1\)이 짝수이다.
예 7.3.2 원환면에서 \(H_1 = \mathbb Z^2\)의 생성원 \(a\) (가로 원)와 \(b\) (세로 원)는 한 점에서 만나 교차수 \(a\cdot b = 1\), \(b\cdot a = -1\), \(a\cdot a = 0\)입니다. 교차형식 \(\begin{pmatrix}0 & 1\\ -1 & 0\end{pmatrix}\)은 비퇴화입니다.
흔한 오해(1) 경계가 있는 다양체에도 그대로 쓴다. 원판 \(D^2\)는 \(\beta = (1, 0, 0)\)로 대칭이 아니다(르프셰츠 쌍대성은 상대 호몰로지를 쓴다). (2) 비가향 다양체에서 정수 계수로 쓴다. \(\mathbb RP^2\)는 정수 계수 \(H_2 = 0\), \(H_0 = \mathbb Z\)라 맞지 않는다. \(\mathbb Z_2\) 계수에서는 \((1, 1, 1)\)로 대칭이다.
요약
  1. 닫힌 가향 \(n\)-다양체: \(H^k \cong H_{n-k}\) (캡곱 \([M]\)).
  2. \(\beta_k = \beta_{n-k}\), 홀수 차원 \(\chi = 0\).
  3. 중간 차원의 교차형식은 비퇴화: 곡면의 \(\beta_1\)은 짝수.

7.3.4연습문제

기본

  1. 닫힌 가향 3차원 다양체에서 \(\beta_0 = 1\), \(\beta_1 = 3\)이면 \(\beta_2\), \(\beta_3\), \(\chi\)는?
    답

    \(\beta_2 = 3\), \(\beta_3 = 1\), \(\chi = 1 - 3 + 3 - 1 = 0\). (예: 3차원 원환면 \(T^3\))

응용

  1. \(\beta_1\)이 홀수인 닫힌 가향 곡면이 없음을 설명하여라.
    답

    \(H_1\) 위의 교차형식은 반대칭이고 비퇴화. 반대칭 비퇴화 형식은 짝수 차원에만 있다(\(\det A = \det(-A^T) = (-1)^n\det A\)).

심화

  1. \(\mathbb RP^3\)의 정수 계수 호몰로지는 \((\mathbb Z, \mathbb Z_2, 0, \mathbb Z)\)이다. 가향인지, 유리수 계수 베티 수가 쌍대성과 맞는지 확인하여라.
    답

    \(H_3 = \mathbb Z\)라 가향. 유리수 계수 베티 수 \((1, 0, 0, 1)\)은 \(\beta_k = \beta_{3-k}\)를 만족하고 \(\chi = 0\).
