구면 위의 제곱 사상의 부동점 세기

예제 · 레프셰츠 수와 실제 부동점

먼저 예측

리만 구 \(\hat{\mathbb C} = S^2\)에서 \(f(z) = z^2\)의 부동점은 몇 개일까요?

예측 확인

3개(\(0\), \(1\), \(\infty\))입니다. 레프셰츠 수도 3입니다.

\(f : S^2 \to S^2\), \(f(z) = z^2\) (\(f(\infty) = \infty\))의 레프셰츠 수를 구하고 실제 부동점과 비교하여라.

전략

\(S^2\)에서 \(L(f) = 1 + \deg f\) (7.2절). 차수는 일반적인 값의 역상 개수(방향 부호 포함)로 셉니다(7.1절).

풀이

  1. 일반적인 \(w \ne 0, \infty\)의 역상은 \(\pm\sqrt w\) 두 점이고 정칙함수라 방향을 보존한다. \(\deg f = 2\).
    정칙사상은 국소적으로 방향 보존.
  2. \(L(f) = 1 + 2 = 3 \ne 0\). 부동점이 존재한다.
    \(H_0\)에서 대각합 1, \(H_2\)에서 2.
  3. 실제로 \(z^2 = z\)에서 \(z = 0, 1\), 그리고 \(\infty\). 3개.
    \(z(z - 1) = 0\)과 무한원점.

검산

일반적으로 \(z \mapsto z^n\)은 \(\deg = n\), \(L = n + 1\)이고, 부동점은 \(z^{n-1} = 1\)의 \(n - 1\)개와 \(0\), \(\infty\)를 합쳐 \(n + 1\)개입니다. 각 부동점이 "횡단적"이면 지표가 \(+1\)씩이라 개수가 \(L\)과 같습니다.

의미

레프셰츠 수는 부동점을 지표(국소 차수)를 붙여 센 값입니다. 항등사상에서는 모든 점이 부동점이지만 살짝 흔들어 고립시키면 지표의 합이 \(\chi\)가 되고, 이것이 푸앵카레-호프 정리(수학22)와 같은 이야기입니다.

이해 확인

\(f(z) = \bar z\) (복소켤레)의 \(L\)과 부동점은?

답

반사라 \(\deg = -1\), \(L = 0\). 부동점은 실수축 전체와 \(\infty\) (원). \(L = 0\)이어도 부동점이 있을 수 있다.
