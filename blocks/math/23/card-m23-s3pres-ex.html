세 관계식이 만드는 여섯 원소의 군

예제 · 군의 표시 읽기

먼저 예측

\(\langle a, b \mid a^2, b^2, (ab)^3\rangle\)에는 원소가 몇 개 있을까요?

예측 확인

6개입니다. 정삼각형의 대칭군 \(S_3\)과 같습니다.

\(G = \langle a, b \mid a^2, b^2, (ab)^3\rangle\)의 원소를 모두 나열하고 \(G \cong S_3\)임을 보여라.

전략

(1) 관계식으로 모든 단어를 짧게 줄여 원소가 많아야 몇 개인지 본다. (2) 보편 성질(4.1절)로 \(S_3\)으로 가는 전사 준동형을 만들어 적어도 그만큼임을 본다.

풀이

  1. \(a^{-1} = a\), \(b^{-1} = b\)라 단어는 \(a\)와 \(b\)가 번갈아 나오는 꼴 \(abab\cdots\) 또는 \(baba\cdots\).
    같은 문자 둘은 지워진다.
  2. \((ab)^3 = 1\)에서 \(aba = b^{-1}a^{-1}b^{-1} = bab\). 길이 4 이상의 번갈이 단어는 \(aba\)를 \(bab\)로 바꿔 짧아진다.
    \(abab = bab\cdot b = ba\) 등.
  3. 따라서 \(G = \{1, a, b, ab, ba, aba\}\), 많아야 6개.
    길이 3 이하만 남음.
  4. \(a \mapsto (12)\), \(b \mapsto (23)\)은 \((12)^2 = (23)^2 = 1\), \((12)(23) = (123)\)이라 \(((12)(23))^3 = 1\)을 만족해 준동형이 있고, \(S_3\)을 생성하므로 전사. \(|G| \ge 6\)이라 \(G \cong S_3\).
    관계식을 만족하면 몫으로 내려온다.

검산

\(ab \mapsto (12)(23)\)은 위수 3인 회전이고 \(ba\)는 그 역입니다. \(aba \mapsto (12)(23)(12) = (13)\)으로 세 번째 반사입니다. 6개가 모두 다릅니다.

의미

표시만 보고 군을 알아내려면 위에서 "많아야 몇 개"(단어 줄이기)와 아래에서 "적어도 몇 개"(구체적인 군으로의 준동형)를 함께 봐야 합니다. \((ab)^3\)을 \((ab)^n\)으로 바꾸면 \(2n\)개 원소의 이면체군이 되고, \(n = \infty\) (관계식 없음)이면 무한 이면체군 \(\mathbb Z_2 * \mathbb Z_2\)입니다.

이해 확인

\(\langle a, b \mid a^2, b^2, (ab)^2\rangle\)은 어떤 군인가?

답

\(abab = 1\)에서 \(ab = b^{-1}a^{-1} = ba\), 가환. \(\{1, a, b, ab\} \cong \mathbb Z_2\times\mathbb Z_2\).
