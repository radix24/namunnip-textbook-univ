뫼비우스 띠를 가운데 원으로 줄이기

예제 · 상공간에서 변형 수축이 잘 정의되는지

먼저 예측

뫼비우스 띠의 폭을 점점 줄이면 무엇이 남을까? 줄이는 과정이 꼬인 이음매에서도 문제없이 정의될까?

예측 확인

가운데 원이 남고, 이음매에서도 잘 정의된다. 폭을 줄이는 것이 위아래 뒤집기와 교환되기 때문이다.

뫼비우스 띠 \(M = [0, 1]\times[-1, 1]/{\sim}\), \((0, y) \sim (1, -y)\)에서 \(H([s, y], u) = [s, (1 - u)y]\)가 가운데 원 \(C = \{[s, 0]\}\)로의 변형 수축임을 보이고, \(M \simeq S^1\)을 결론지어라.

전략

상공간 위의 사상은 동치인 점을 같은 점으로 보내야 잘 정의된다. 그다음 변형 수축의 세 조건(1.3절)을 확인한다.

풀이

  1. 잘 정의: \((0, y)\)는 \((0, (1 - u)y)\)로, \((1, -y)\)는 \((1, -(1 - u)y)\)로 가고 이 둘은 다시 동치이다.
    곱셈 \(y \mapsto (1 - u)y\)가 부호 바꾸기와 교환.
  2. 연속: \([0, 1]\times[-1, 1]\times I\)에서 연속이고 몫사상과 호환되므로 \(M\times I\)에서 연속(\(I\)가 컴팩트라 곱과 몫이 교환).
    상위상의 보편 성질.
  3. \(H_0 = \mathrm{id}\), \(H_1(M) = C\), \(C\)의 점 \([s, 0]\)은 모든 \(u\)에서 고정.
    변형 수축의 조건.
  4. \(C\)는 \([0, 1]\)의 양 끝 \((0, 0) \sim (1, 0)\)을 붙인 원이라 \(M \simeq C \cong S^1\).
    변형 수축은 호모토피 동치.

검산

원기둥 \([0, 1]\times[-1, 1]/(0, y) \sim (1, y)\)에도 같은 식이 통해 원기둥도 \(\simeq S^1\)이다. 그래서 뫼비우스 띠와 원기둥은 호모토피 동치이고 기본군 \(\mathbb Z\)도 같다. 그러나 경계는 뫼비우스 띠가 원 하나, 원기둥이 원 둘이라 위상동형은 아니다.

의미

호모토피 동치는 꼬임이나 경계의 개수처럼 "두께"에 담긴 정보를 잊는다. 뫼비우스 띠의 경계 원은 가운데 원을 두 번 감으므로, 포함사상이 기본군에서 \(\mathbb Z \xrightarrow{\times2} \mathbb Z\)를 준다. 이런 세밀한 정보는 쌍 \((M, \partial M)\)을 보면 남는다.

이해 확인

\(H([s, y], u) = [s, (1 - u)y + u]\)는 왜 \(M\)에서 잘 정의되지 않는가?

답

\((0, y) \mapsto (0, (1 - u)y + u)\), \((1, -y) \mapsto (1, -(1 - u)y + u)\)인데 동치이려면 \(-(1 - u)y + u = -((1 - u)y + u)\), 즉 \(u = 0\)이어야 한다.
