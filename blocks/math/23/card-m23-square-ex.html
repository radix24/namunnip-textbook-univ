두 삼각형의 경계에서 대각선이 사라진다

예제 · 경계 연산자 계산

먼저 예측

정사각형을 대각선으로 나눈 두 삼각형의 경계를 더하면 대각선은 어떻게 될까요?

예측 확인

방향이 맞으면 반대 부호로 두 번 나와 지워지고, 정사각형의 둘레만 남습니다.

꼭짓점 \(v_0, v_1, v_2, v_3\)인 정사각형을 \(\sigma = [v_0, v_1, v_2]\), \(\tau = [v_0, v_2, v_3]\)으로 나눈다. \(\partial(\sigma + \tau)\)를 구하고 \(\partial\partial(\sigma + \tau) = 0\)을 확인하여라.

전략

\(\partial[a, b, c] = [b, c] - [a, c] + [a, b]\) (6.1절)를 각각 쓰고 더합니다.

풀이

  1. \(\partial\sigma = [v_1, v_2] - [v_0, v_2] + [v_0, v_1]\).
    정의.
  2. \(\partial\tau = [v_2, v_3] - [v_0, v_3] + [v_0, v_2]\).
    정의.
  3. 합: \([v_0, v_1] + [v_1, v_2] + [v_2, v_3] + [v_3, v_0]\). 대각선 \([v_0, v_2]\)이 \(-1 + 1 = 0\).
    \(-[v_0, v_3] = [v_3, v_0]\).
  4. \(\partial\)을 다시: \((v_1 - v_0) + (v_2 - v_1) + (v_3 - v_2) + (v_0 - v_3) = 0\).
    닫힌 둘레는 끝점이 없다.

검산

\(\tau\)의 방향을 반대로(\([v_0, v_3, v_2]\)) 잡으면 \(\partial(\sigma + \tau)\)에서 대각선이 \(-2[v_0, v_2]\)로 남습니다. 두 삼각형의 방향을 "같은 회전 방향"으로 맞춰야 내부 변이 지워지며, 이것이 곡면의 방향성의 대수적 표현입니다.

의미

방향을 맞춘 모든 삼각형의 합은 내부 변이 모두 지워져 바깥 경계만 남습니다. 닫힌 가향 곡면이면 바깥 경계도 없어 그 합이 2-순환, 즉 \(H_2\)의 기본류가 됩니다. 비가향 곡면에서는 방향을 끝까지 맞출 수 없어 정수 계수 \(H_2 = 0\)입니다.

이해 확인

\(\partial[v_0, v_1, v_2, v_3]\)에 \(\partial\)을 한 번 더 쓴 결과에서 \([v_0, v_1]\)의 계수는?

답

\(+[v_0, v_1, v_3]\)에서 \(+1\), \(-[v_0, v_1, v_2]\)에서 \(-1\)이라 0.
