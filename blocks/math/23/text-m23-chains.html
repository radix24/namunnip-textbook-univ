사슬 복합체와 경계 연산자

본문
이 절에서 배울 것
  • 방향을 준 단체의 정수 결합으로 사슬군 \(C_k(K)\)를 정의한다.
  • 경계 연산자 \(\partial[v_0, \dots, v_k] = \sum_i(-1)^i[v_0, \dots, \hat v_i, \dots, v_k]\)를 계산한다.
  • \(\partial\circ\partial = 0\)을 증명하고, 순환(cycle)과 경계(boundary)를 정의한다.
먼저 알아야 할 것
  • 단체 복합체 (5.1절), 자유 아벨군과 몫군 (수학12).

6.1.1사슬

단체 \([v_0, \dots, v_k]\)에 꼭짓점 순서로 방향을 주고, 짝순열로 바꾼 것은 같은 단체, 홀순열은 부호를 바꾼 것으로 봅니다(\([v_1, v_0] = -[v_0, v_1]\)). \(k\)-단체들을 기저로 하는 자유 아벨군 \(C_k(K)\)의 원소를 \(k\)-사슬이라 합니다. 1-사슬 \(2[a, b] - [b, c]\)는 변 \(ab\)를 두 번, 변 \(cb\)를 한 번 지나는 "경로의 형식적 합"입니다.

6.1.2경계

\[\partial_k[v_0, \dots, v_k] = \sum_{i=0}^k(-1)^i[v_0, \dots, \hat v_i, \dots, v_k]\]

(\(\hat v_i\)는 빼는 꼭짓점). 선분은 \(\partial[a, b] = b - a\) (끝점 − 시작점), 삼각형은 \(\partial[a, b, c] = [b, c] - [a, c] + [a, b] = [a, b] + [b, c] + [c, a]\)로 둘레를 한 바퀴 도는 1-사슬입니다.

정리 6.1.1 \(\partial_{k-1}\circ\partial_k = 0\).
증명

\(\partial\partial[v_0, \dots, v_k]\)에서 두 꼭짓점 \(v_i, v_j\) (\(i < j\))를 뺀 항은 두 번 나온다. \(v_j\)를 먼저 빼고 \(v_i\)를 빼면 부호 \((-1)^j(-1)^i\), \(v_i\)를 먼저 빼면 \(v_j\)의 자리가 하나 당겨져 \((-1)^i(-1)^{j-1}\). 둘이 상쇄된다. ∎

"경계에는 경계가 없다"는 기하학적 사실의 대수판입니다. 삼각형의 둘레는 닫힌 곡선이라 끝점이 없습니다: \(\partial([a, b] + [b, c] + [c, a]) = (b - a) + (c - b) + (a - c) = 0\).

6.1.3순환과 경계

\(Z_k = \ker\partial_k\)의 원소를 순환(닫힌 사슬), \(B_k = \operatorname{im}\partial_{k+1}\)의 원소를 경계라 합니다. \(\partial\partial = 0\)이라 \(B_k \subset Z_k\)이고, 그 몫

\[H_k(K) = Z_k/B_k\]

가 \(k\)차 호몰로지입니다(6.2절). "닫혀 있지만 무언가의 둘레가 아닌" 사슬, 즉 구멍을 둘러싸는 사슬을 셉니다.

예 6.1.2 속이 빈 삼각형(꼭짓점 \(a, b, c\), 변 3개, 면 없음)에서 \(z = [a, b] + [b, c] + [c, a]\)는 순환이지만 2-단체가 없어 경계가 아닙니다. 그래서 \(H_1 \ne 0\)이고, 구멍 하나를 감지합니다. 면 \([a, b, c]\)를 채우면 \(z = \partial[a, b, c]\)가 되어 구멍이 사라집니다.
흔한 오해(1) 사슬이 실제 경로라 여긴다. 순서와 연결성은 잊은 형식적 합이다. (2) \(\partial\)의 부호를 무시한다. 부호가 없으면 \(\partial\partial = 0\)이 깨진다(계수 \(\mathbb Z_2\)에서는 부호가 필요 없다).
요약
  1. \(C_k\): 방향 단체의 정수 결합.
  2. \(\partial = \sum(-1)^i(\text{face}_i)\), \(\partial\partial = 0\).
  3. \(Z_k = \ker\partial\), \(B_k = \operatorname{im}\partial\), \(H_k = Z_k/B_k\).

6.1.4연습문제

기본

  1. \(\partial[v_0, v_1, v_2, v_3]\)을 쓰라.
    답

    \([v_1, v_2, v_3] - [v_0, v_2, v_3] + [v_0, v_1, v_3] - [v_0, v_1, v_2]\).

응용

  1. 1번 사슬에 \(\partial\)을 한 번 더 써서 0이 됨을 확인하여라.
    답

    각 변 \([v_i, v_j]\)가 정확히 두 번, 반대 부호로 나온다. 예: \([v_2, v_3]\)은 첫째 항에서 \(+\), 둘째 항에서 \(-\).

심화

  1. 그래프(1차원 복합체)에서 1-순환은 무엇인가? 꼭짓점 \(V\)개, 변 \(E\)개인 연결 그래프에서 \(Z_1\)의 계수를 구하여라.
    답

    각 꼭짓점에서 들어오는 수와 나가는 수가 같은 사슬(고리들의 합). \(\partial_1 : \mathbb Z^E \to \mathbb Z^V\)의 상은 계수 \(V - 1\)(연결)이라 \(\operatorname{rank}Z_1 = E - V + 1\), 독립 고리의 수.
