생일 문제를 시뮬레이션으로 확인하기

예제 · 시뮬레이션과 정확한 계산 비교

먼저 예측

23명이 모였을 때 생일이 같은 두 사람이 있을 확률은 10%쯤일까요, 50%쯤일까요?

예측 확인

약 50.7%입니다. 짝이 될 수 있는 쌍이 \(\binom{23}2 = 253\)개나 되기 때문입니다.

윤년을 무시하고 생일이 365일에 고르게 퍼져 있다고 할 때, 23명 가운데 생일이 같은 사람이 있을 확률을 (1) 시뮬레이션 10000번으로, (2) 정확한 계산으로 구해 비교하여라.

전략

한 번의 실험: 1~365의 난수 23개를 뽑아 집합으로 만들었을 때 크기가 23보다 작으면 겹친 것(1.3절의 집합). 정확한 값은 여사건 "모두 다름"의 확률 \(\frac{365}{365}\cdot\frac{364}{365}\cdots\frac{343}{365}\)을 1에서 뺍니다.

풀이

  1. import random, math
random.seed(2)
T, hit = 10000, 0
for _ in range(T):
    b = [random.randint(1, 365) for _ in range(23)]
    if len(set(b)) < 23:
        hit += 1
print(hit / T)                                      # 0.505
print(1 - math.prod((365 - i)/365 for i in range(23)))   # 0.5072972343239857
    시뮬레이션과 여사건 공식.
  2. 시뮬레이션 0.505, 정확한 값 0.5073. 차이 0.002.
    표준편차 \(\sqrt{0.25/10000} = 0.005\) 안.

검산

차이 0.002는 시뮬레이션의 예상 흩어짐 0.005보다 작아 자연스럽습니다. 차이가 0.05처럼 크게 났다면 코드(예: randint(1, 364) 같은 범위 실수)를 의심해야 합니다.

의미

정확한 계산이 있는 문제로 시뮬레이션을 검증해 두면, 정확한 계산이 어려운 변형(생일이 고르지 않을 때, 세 사람이 같을 확률)도 같은 코드로 믿고 추정할 수 있습니다.

이해 확인

확률이 처음으로 0.5를 넘는 인원을 정확한 공식으로 찾는 코드를 써라.

답

n = 1부터 늘리며 1 - math.prod((365 - i)/365 for i in range(n)) > 0.5가 되는 첫 \(n\): 23.
