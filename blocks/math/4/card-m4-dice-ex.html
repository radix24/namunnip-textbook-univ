두 주사위 눈의 합 분포표 만들기

예제 · 딕셔너리로 경우의 수 세기

먼저 예측

두 주사위의 눈의 합 가운데 가장 자주 나오는 값은 무엇이고, 몇 가지 경우가 있을까요?

예측 확인

7이고 6가지입니다.

두 주사위를 던질 때 눈의 합마다 경우의 수를 세는 딕셔너리를 만들고, 합이 7일 확률을 구하여라.

전략

36가지 경우를 이중 반복문으로 모두 돌며 빈도표를 채웁니다(1.3절).

풀이

  1. d = {}
for a in range(1, 7):
    for b in range(1, 7):
        d[a + b] = d.get(a + b, 0) + 1
print(d)
    모든 순서쌍 \((a, b)\).
  2. {2: 1, 3: 2, 4: 3, 5: 4, 6: 5, 7: 6, 8: 5, 9: 4, 10: 3, 11: 2, 12: 1}
    7을 꼭대기로 대칭.
  3. 합이 7일 확률 \(\frac6{36} = \frac16\).
    수학적 확률.

검산

값을 모두 더하면 sum(d.values()) = 36으로 전체 경우의 수와 같습니다. 합이 \(s\)인 경우의 수가 \(6 - |s - 7|\)이라는 공식과도 맞습니다.

의미

손으로 표를 그리던 계산을 컴퓨터가 빠짐없이 합니다. 주사위가 세 개, 네 개로 늘어도 반복문만 늘리면 되고, 손으로는 힘든 분포도 정확히 얻습니다.

이해 확인

주사위 세 개의 눈의 합이 10인 경우의 수를 구하는 코드를 써라.

답

len([1 for a in range(1, 7) for b in range(1, 7) for c in range(1, 7) if a + b + c == 10]) → 27.
