파이썬 기초 실습 문제

문제 6 · 실습·개념·판단 · 힌트 2단계

파이썬을 열어 직접 실행해 보아라. 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 실습루카스 수 \(L_0 = 2\), \(L_1 = 1\), \(L_{n+1} = L_n + L_{n-1}\)의 \(L_{20}\)을 반복문으로 구하여라. [01-01]

    힌트 1

    a, b = 2, 1에서 시작(1.1절).

    힌트 2

    20번 갱신한 뒤 a.

    풀이

    a, b = 2, 1; for _ in range(20): a, b = b, a + b → 15127.

  2. 실습자연수 \(n\)의 자릿수 합을 재귀 함수로 구현하고 digit_sum(2**100)을 구하여라. [01-01]

    힌트 1

    \(n\)의 자릿수 합 = 마지막 자리 + 나머지의 자릿수 합.

    힌트 2

    n % 10 + digit_sum(n // 10), 기저 n == 0.

    풀이

    def digit_sum(n): return 0 if n == 0 else n % 10 + digit_sum(n // 10) → 115.

  3. 실습리스트 내포로 100 이하의 완전제곱수 리스트를 만들어라. [01-01]

    힌트 1

    [k*k for k in range(…)].

    힌트 2

    \(10^2 = 100\).

    풀이

    [k*k for k in range(1, 11)] → [1, 4, 9, 16, 25, 36, 49, 64, 81, 100].

  4. 실습체를 이용해 1000 이하에서 \(p\)와 \(2p + 1\)이 모두 소수인 \(p\)(소피 제르맹 소수)의 개수를 구하여라. [01-02]

    힌트 1

    체는 \(2\cdot1000 + 1\)까지 돌린다(1.2절).

    힌트 2

    is_p[p] and is_p[2*p+1].

    풀이

    37개 (2, 3, 5, 11, 23, 29, 41, 53, …).

  5. 개념나누어 보기에서 조건을 d <= int(n**0.5)로 쓰는 것과 d * d <= n으로 쓰는 것의 차이는? [01-02]

    힌트 1

    부동소수점 제곱근.

    힌트 2

    아주 큰 완전제곱수.

    풀이

    수학적으로 같지만 n**0.5는 실수 계산이라 아주 큰 \(n\)에서 반올림 오차로 정수 제곱근보다 1 작게 나올 수 있다. 정수 연산 d * d <= n(또는 math.isqrt)은 정확하다.

  6. 판단한 학생이 "fib_rec(40)이 오래 걸리니 더 빠른 컴퓨터를 쓰면 된다"고 했다. 맞는가? [01-01]

    힌트 1

    호출 수 \(2F_{41} - 1\).

    힌트 2

    \(n = 60\)이면?

    풀이

    근본 해결이 아니다. 호출 수가 \(n = 40\)에서 약 3.3억, \(n = 60\)에서 약 5조로 1.6배씩 늘어 컴퓨터가 10배 빨라져도 \(n\)을 5 정도밖에 못 늘린다. 메모이제이션이나 반복문으로 바꾸면 \(n\)에 비례하는 시간에 끝난다.
