학습률을 키우면 더 빨리 내려갈까

탐구 · 경사하강법의 경로

질문

길쭉한 골짜기 \(f(x, y) = \frac12(x^2 + \kappa y^2)\)에서 \((-4, 1.5)\)부터 경사하강법을 돌립니다. 학습률 \(\eta\)를 키우면 언제까지 빨라지고, 언제부터 망가질까요?

복원

갱신 \(x \leftarrow (1 - \eta)x\), \(y \leftarrow (1 - \kappa\eta)y\). 수렴 조건 \(\eta < 2/\kappa\), 가장 빠른 \(\eta = 2/(1 + \kappa)\) (5.1절).

해 보기

  1. \(\kappa = 10\), 반복 200에서 \(\eta\)를 0.01, 0.05, 0.1로 키우면 \(f < 10^{-6}\)에 도달하는 횟수가 791, 155, 76으로 줄어듭니다(0.01은 200번 안에 도달하지 못함).
  2. \(\eta = 0.18\) 근처(가장 빠른 \(2/11\))에서는 42번 안팎이지만, 경로가 골짜기를 가로질러 지그재그로 움직입니다.
  3. \(\eta = 0.2\)이면 \(y\)가 \(\pm1.5\)를 영원히 오갑니다. 0.21이면 발산합니다.
  4. \(\kappa = 1\)(둥근 그릇)로 바꾸면 경로가 원점으로 곧게 가고, 슬라이더 범위 안에서는 \(\eta\)가 클수록 빠릅니다(수렴 조건은 \(\eta < 2\)). 다음에 \(\kappa = 20\)으로 바꾸면 허용되는 \(\eta\)의 상한이 0.1로 줄어듭니다.

설명

  1. 가장 가파른 방향의 제약보폭은 곡률이 가장 큰 방향(\(y\))이 정합니다. 그 방향에서 넘치지 않으려면 \(\eta < 2/\kappa\)여야 하고, 그러면 곡률이 작은 방향(\(x\))은 \(1 - \eta\)배씩 느리게 줄어듭니다.
  2. 조건수최적 학습률에서 수축률은 \(\frac{\kappa - 1}{\kappa + 1}\)이므로, \(\kappa\)가 클수록 1에 가까워 느려집니다. 변수의 단위를 맞추는 정규화(표준화)가 머신러닝에서 중요한 이유입니다(6.1절).

판단

"학습률이 클수록 빨리 수렴한다"는 일정 범위에서만 맞습니다. 가장 빠른 값을 넘으면 진동이 커져 느려지고, \(2/\kappa\)를 넘으면 발산합니다. 반대로 너무 작으면 수백 번을 돌아도 도착하지 못합니다.
