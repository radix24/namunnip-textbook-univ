SciPy로 적분, 최적화, 미분방정식 풀기

본문

\(\int_0^\infty e^{-x^2}dx\), \(x^4 - 3x + 1\)의 최솟값, 진자의 운동 방정식. 손으로 풀거나 직접 수치해석 코드를 짤 수도 있지만, 검증된 라이브러리로 풀고 그 답을 믿을 만한지 확인하는 것도 중요한 능력이다. 어떻게 하는가?

먼저 알아야 할 것NumPy 배열(3.1절), 함수 그래프 그리기(2.2절), 2계 미분방정식을 1계 연립으로 바꾸는 법을 쓴다.

7.1.1정적분

scipy.integrate.quad는 적응형 구적법으로 정적분 값과 오차 어림을 함께 돌려준다. 오차 어림을 버리지 말고 함께 보아야 한다. 그러면 그 숫자를 얼마나 믿어도 되는지 알 수 있다.

import numpy as np
from scipy import integrate, optimize

val, err = integrate.quad(lambda x: np.exp(-x**2), 0, np.inf)
print(val, err, np.sqrt(np.pi) / 2)   # 0.886226925452758  1.4e-08  0.886226925452758

무한 구간도 받는다. 결과를 정확한 값 \(\frac{\sqrt\pi}{2}\)와 비교해 보면 15자리까지 맞는다. 이렇게 답을 아는 문제로 먼저 도구를 확인하고 나서 답을 모르는 문제에 쓰는 것이 좋은 습관이다.

7.1.2최적화와 근 찾기

optimize.minimize_scalar는 한 변수 함수의 최솟값을, optimize.brentq는 부호가 바뀌는 구간에서 근을 찾는다. 여러 변수 함수는 optimize.minimize로 한다.

f = lambda x: x**4 - 3*x + 1
res = optimize.minimize_scalar(f)
print(res.x, res.fun)                  # 0.9085602964  -1.044...
print(optimize.brentq(lambda x: 4*x**3 - 3, 0, 2))   # 같은 x

둘째 줄은 검증이다. 최솟값에서는 도함수 \(4x^3 - 3\)이 0이어야 하므로, 그 근을 따로 구해 같은 값이 나오는지 본다. 실제로 \(x = (3/4)^{1/3} \approx 0.9086\)이다. 다만 minimize_scalar는 국소 최솟값 하나를 찾을 뿐이므로, 그래프를 먼저 그려 최솟값이 하나인지 확인해야 한다.

7.1.3미분방정식

integrate.solve_ivp는 \(\mathbf y' = F(t, \mathbf y)\) 꼴의 1계 연립방정식을 푼다. 진자 방정식 \(\theta'' + 0.3\theta' + \sin\theta = 0\)은 \(\mathbf y = (\theta, \theta')\)로 두어 1계로 바꾼다.

def F(t, y):
    th, om = y
    return [om, -0.3*om - np.sin(th)]

sol = integrate.solve_ivp(F, [0, 30], [1.5, 0], rtol=1e-8, dense_output=True)
t = np.linspace(0, 30, 600)
theta = sol.sol(t)[0]
예제 7.1.1

감쇠가 없을 때(\(0.3\)을 \(0\)으로) 에너지 \(E = \frac12\theta'^2 - \cos\theta\)가 보존되는지 수치해로 확인하여라.

풀이. 해를 구한 뒤 E = 0.5*om**2 - np.cos(th)를 계산하면 처음 값 \(-\cos1.5 \approx -0.0707\)에서 rtol=1e-8일 때 \(10^{-7}\) 정도만 변한다. 허용 오차를 1e-3으로 느슨하게 하면 에너지가 눈에 띄게 줄어든다. 따라서 수치해의 정확도는 보존량으로 점검할 수 있고, 이 점검이 그림 1 같은 그래프를 믿는 근거가 된다.

마무리

SciPy의 quad, minimize_scalar, brentq, solve_ivp로 적분, 최적화, 근 찾기, 미분방정식을 짧게 풀 수 있다. 결과는 오차 어림, 정확한 답이 있는 문제, 도함수의 근, 보존량 같은 독립된 방법으로 반드시 검증한다.

7.1.4연습문제

기본

  1. quad로 \(\int_0^1\frac{4}{1 + x^2}dx\)를 계산하고 \(\pi\)와 비교하여라.
    답

    3.141592653589793. 정확한 값이 \(4\arctan1 = \pi\)이다.

응용

  1. solve_ivp로 \(y' = y\), \(y(0) = 1\)을 \([0, 1]\)에서 풀고 rtol을 바꿔 가며 \(y(1)\)과 \(e\)의 차이를 비교하여라.
    답

    차이는 대략 rtol에 비례해 줄어든다. 기본값 \(10^{-3}\)에서는 \(10^{-4}\)쯤 차이가 난다.
