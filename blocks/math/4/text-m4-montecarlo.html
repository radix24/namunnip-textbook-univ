몬테카를로 시뮬레이션

본문

정사각형 과녁에 다트를 아무렇게나 던진다. 사분원 안에 꽂힌 다트의 비율로 원주율을 구할 수 있을까? 다트를 많이 던질수록 정확해질 텐데, 한 자리 더 정확하게 하려면 다트가 몇 배나 더 필요할까?

먼저 알아야 할 것반복문(1.1절), 이항분포의 평균과 표준편차를 쓴다.

2.3.1점을 뿌려 원주율 구하기

한 변이 1인 정사각형에 점을 무작위로 뿌리면, 사분원 \(x^2 + y^2 < 1\) 안에 떨어질 확률은 넓이의 비 \(\frac\pi4\)이다. 그러니 안에 떨어진 비율에 4를 곱하면 \(\pi\)의 추정값이 된다.

import random, math
def estimate_pi(N):
    c = 0
    for _ in range(N):
        x, y = random.random(), random.random()
        if x*x + y*y < 1:
            c += 1
    return 4 * c / N

random.seed(1)
for N in [100, 10000, 1000000]:
    p = estimate_pi(N)
    print(N, p, abs(p - math.pi))
100 3.2 0.05840734641020706
10000 3.1396 0.0019926535897929476
1000000 3.141176 0.00041665358979292577

여기서 random.seed(1)은 난수의 출발점을 고정해 누가 돌려도 같은 결과가 나오게 한다. 시드를 바꾸면 값이 조금씩 달라지며, 그림 1의 점 300개로는 3.133이 나왔다.

2.3.2오차는 \(\frac1{\sqrt N}\)로 준다

점 하나가 안에 떨어지는 것을 확률 \(p = \frac\pi4\)의 시행으로 보면, 이항분포에 따라 안에 떨어진 비율의 표준편차는 \(\sqrt{\frac{p(1 - p)}N}\)이다. 4를 곱하면 추정값의 흩어짐은 약 \(\frac{1.64}{\sqrt N}\)이다. 예를 들어 \(N = 100\)이면 약 0.16, \(N = 10^4\)이면 약 0.016, \(N = 10^6\)이면 약 0.0016이며, 위 실험의 오차도 이 크기 안에 있다.

즉 \(N\)을 100배 늘려야 오차가 10배 줄고, 한 자리 더 정확하게 하려면 계산이 100배 든다. 그래서 몬테카를로 방법은 몇 자리의 정확도에는 적합하지만 매우 정밀한 값에는 비효율적이다. 대신 차원이 높아도 오차가 \(\frac1{\sqrt N}\)로 같아서, 고차원 적분처럼 다른 방법이 어려운 곳에서 강력하다.

2.3.3확률 추정

계산이 어려운 확률도 실험을 되풀이해 셀 수 있다. 예를 들어 "23명 가운데 생일이 같은 두 사람이 있을 확률"은 23명의 생일을 무작위로 뽑는 실험을 만 번 하고 같은 생일이 나온 비율로 추정한다. 이 확률은 약 0.507로 정확히 계산할 수도 있으므로, 두 값을 비교하면 시뮬레이션 코드를 검증할 수 있다.

흔한 오해표본을 두 배로 하면 오차가 반이 된다고 여기기 쉽지만, 실제로는 \(\frac1{\sqrt2}\)배일 뿐이다. 또 시드를 고정하지 않은 결과를 그대로 보고하는 실수가 있는데, 그러면 재현할 수 없어 다른 사람이 확인할 수 없다.
마무리

처음 질문의 답은 "구할 수 있다"이다. 사분원 안에 든 비율이 넓이의 비 \(\frac\pi4\)에 가까우므로 4를 곱하면 원주율이 된다. 다만 오차가 \(\frac1{\sqrt N}\)에 비례해 줄기 때문에, 한 자리 더 정확하게 하려면 다트가 100배 필요하다. 실험은 random.seed로 재현할 수 있게 하고, 정확한 값을 아는 경우와 비교해 코드를 검증한다.

2.3.4연습문제

기본

  1. \(N = 10^4\)에서 오차가 약 0.016이면, 0.001 정도로 줄이려면 \(N\)이 대략 얼마여야 하는가?
    답

    16배 줄여야 하므로 \(16^2 = 256\)배, 약 \(2.6\times10^6\).

응용

  1. \(\int_0^1x^2dx\)를 몬테카를로로 추정하는 방법 두 가지를 말하여라.
    답

    (1) 정사각형에 점을 뿌려 \(y < x^2\)인 비율. (2) 균등난수 \(x_i\)에 대한 \(x_i^2\)의 평균. 둘 다 \(\frac13\)에 다가간다.

심화

  1. 주사위 두 개의 합이 7 이상일 확률을 시뮬레이션하는 코드를 쓰고 정확한 값과 비교하여라.
    답

    sum(random.randint(1, 6) + random.randint(1, 6) >= 7 for _ in range(N)) / N. 정확한 값 \(\frac{21}{36} = 0.5833\).
