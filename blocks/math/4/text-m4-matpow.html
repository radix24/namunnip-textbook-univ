행렬 거듭제곱으로 점화식과 마르코프 연쇄 계산하기

본문

피보나치 수 \(F_{10^{18}}\)을 어떤 수로 나눈 나머지를 구하라는 문제가 있다. 앞에서부터 \(10^{18}\)번 더하는 것은 불가능하다. 점화식을 행렬로 바꾸면 이 계산을 백 번 남짓으로 끝낼 수 있다는데, 어떻게 그럴 수 있을까?

먼저 알아야 할 것점화식(1.1절), 행렬의 곱, NumPy(3.1절)를 쓴다.

3.3.1점화식을 행렬로

피보나치 수열 \(F_{n+1} = F_n + F_{n-1}\)은 두 항을 묶으면 다음과 같이 행렬 곱이 된다.

\[\begin{pmatrix}F_{n+1}\\ F_n\end{pmatrix} = \begin{pmatrix}1 & 1\\ 1 & 0\end{pmatrix}\begin{pmatrix}F_n\\ F_{n-1}\end{pmatrix}, \qquad A^n = \begin{pmatrix}F_{n+1} & F_n\\ F_n & F_{n-1}\end{pmatrix}.\]

그래서 \(F_n\)을 구하는 일이 \(A^n\)을 구하는 일이 된다. 오른쪽 식은 귀납법으로 확인한다. \(n = 1\)이면 \(A\) 자신이고, \(A^n\)이 그 꼴이면 \(A^{n+1} = A^nA\)의 첫 열이 \((F_{n+1} + F_n, F_n + F_{n-1}) = (F_{n+2}, F_{n+1})\)이 되기 때문이다. 즉 선형 점화식이면 무엇이든 이렇게 행렬 곱으로 옮길 수 있다.

3.3.2빠른 거듭제곱

\(A^{50}\)을 \(A\)를 49번 곱해 구할 수도 있다. 하지만 그림 1처럼 \(A^{50} = A^{32}A^{16}A^2\)으로 지수를 이진법으로 나누면, \(A, A^2, A^4, \dots\)를 제곱으로 만들고 필요한 것만 곱하면 된다.

def matmul(A, B):
    return [[sum(A[i][k]*B[k][j] for k in range(len(B)))
             for j in range(len(B[0]))] for i in range(len(A))]

def matpow(A, n):
    R = [[1, 0], [0, 1]]
    while n > 0:
        if n % 2 == 1:
            R = matmul(R, A)
        A = matmul(A, A)
        n //= 2
    return R

print(matpow([[1, 1], [1, 0]], 10))        # [[89, 55], [55, 34]]
print(matpow([[1, 1], [1, 0]], 50)[0][1])  # 12586269025 = F_50

따라서 곱셈이 약 \(2\log_2n\)번이라 \(n = 10^{18}\)도 120번쯤이면 된다. 처음 질문처럼 나머지만 필요하면 매번 나머지를 취해 수가 커지지 않게 한다. NumPy에서는 np.linalg.matrix_power(A, n)이 같은 일을 한다.

3.3.3마르코프 연쇄

오늘 맑으면 내일 맑을 확률이 0.9, 오늘 흐리면 내일 맑을 확률이 0.5라 하자. 전이행렬 \(P = \begin{pmatrix}0.9 & 0.1\\ 0.5 & 0.5\end{pmatrix}\)의 \((i, j)\) 성분은 오늘 \(i\)이면 내일 \(j\)일 확률이고, \(P^n\)의 성분은 \(n\)일 뒤의 확률이다.

P = [[0.9, 0.1], [0.5, 0.5]]
Q = P
for _ in range(19):
    Q = matmul(Q, P)
print(Q)    # 약 [[0.833333, 0.166667], [0.833333, 0.166667]]

그런데 결과를 보면 20일 뒤에는 오늘 날씨와 무관하게 맑을 확률이 \(\frac56\)으로 같아진다. 두 행이 같아진 이 값이 장기 확률, 곧 정상분포이며, \(\pi P = \pi\)를 풀어도 \(\pi = \left(\frac56, \frac16\right)\)이다.

두 행이 얼마나 빨리 같아지는지도 고유값으로 알 수 있다. \(P\)의 고유값은 1과 0.4이며, 1은 정상분포에, 0.4는 오늘 날씨의 영향에 해당한다. 그래서 오늘 날씨의 영향은 하루마다 0.4배로 줄어, 20일 뒤에는 \(0.4^{20} \approx 10^{-8}\)만큼만 남는다. 이렇게 거듭제곱을 직접 계산하는 방법과 고유값으로 보는 방법은 같은 현상을 두 쪽에서 설명한다.

흔한 오해NumPy에서 A**n을 행렬 거듭제곱으로 여기기 쉽지만, 그것은 성분별 거듭제곱이다. 또 확률 행렬을 오래 곱하면 0으로 사라진다고 여기는 경우가 있는데, 각 행의 합이 1로 유지되어 일정한 분포로 다가간다.
마무리

처음 질문에 답하면, 피보나치 점화식을 행렬 \(A = \begin{pmatrix}1 & 1\\ 1 & 0\end{pmatrix}\)의 거듭제곱으로 바꾸고 지수를 이진법으로 나누어 제곱을 되풀이하면 곱셈 약 \(2\log_2n\)번, 곧 \(n = 10^{18}\)에서도 120번쯤으로 끝난다. 나머지가 필요하면 매번 나머지를 취한다. 같은 방법으로 전이행렬의 거듭제곱을 구하면 마르코프 연쇄의 장기 확률, 곧 정상분포를 얻는다.

3.3.4연습문제

기본

  1. \(A^{13}\)을 빠른 거듭제곱으로 구할 때 \(R\)에 곱해지는 거듭제곱들은?
    답

    \(13 = 1101_2\): \(A^1, A^4, A^8\).

응용

  1. 점화식 \(a_{n+1} = 2a_n + 3a_{n-1}\)을 행렬로 쓰라.
    답

    \(\begin{pmatrix}a_{n+1}\\ a_n\end{pmatrix} = \begin{pmatrix}2 & 3\\ 1 & 0\end{pmatrix}\begin{pmatrix}a_n\\ a_{n-1}\end{pmatrix}\).

심화

  1. 본문의 날씨 연쇄에서 장기 확률 \(\pi = (\pi_1, \pi_2)\)를 \(\pi P = \pi\), \(\pi_1 + \pi_2 = 1\)로 손으로 구하여라.
    답

    \(\pi_1 = 0.9\pi_1 + 0.5\pi_2\)에서 \(0.1\pi_1 = 0.5\pi_2\), \(\pi_1 = 5\pi_2\). \(\pi = \left(\frac56, \frac16\right)\).
