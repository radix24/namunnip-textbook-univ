행렬 거듭제곱으로 점화식과 마르코프 연쇄 계산하기

본문
이 절에서 배울 것
  • 선형 점화식(피보나치 수열)을 행렬 곱 \(\begin{pmatrix}F_{n+1}\\ F_n\end{pmatrix} = A\begin{pmatrix}F_n\\ F_{n-1}\end{pmatrix}\)으로 쓴다.
  • 제곱을 거듭하는 빠른 거듭제곱으로 \(A^n\)을 \(\log_2n\)번 정도의 곱셈으로 구한다.
  • 전이행렬의 거듭제곱으로 마르코프 연쇄의 장기 확률을 계산한다.
먼저 알아야 할 것
  • 행렬의 곱 (3.1절), 재귀와 점화식 (1.1절).

3.3.1점화식을 행렬로

피보나치 수열 \(F_{n+1} = F_n + F_{n-1}\)은 두 항을 묶으면

\[\begin{pmatrix}F_{n+1}\\ F_n\end{pmatrix} = \begin{pmatrix}1 & 1\\ 1 & 0\end{pmatrix}\begin{pmatrix}F_n\\ F_{n-1}\end{pmatrix}, \qquad A^n = \begin{pmatrix}F_{n+1} & F_n\\ F_n & F_{n-1}\end{pmatrix}.\]

그래서 \(F_n\)을 구하는 일이 \(A^n\)을 구하는 일이 됩니다.

3.3.2빠른 거듭제곱

\(A^{50}\)을 \(A\)를 49번 곱해 구할 수도 있지만, \(A^{50} = A^{32}A^{16}A^2\)처럼 지수를 이진법으로 나누면 \(A, A^2, A^4, \dots\)를 제곱으로 만들고 필요한 것만 곱하면 됩니다.

def matmul(A, B):
    return [[sum(A[i][k]*B[k][j] for k in range(len(B)))
             for j in range(len(B[0]))] for i in range(len(A))]

def matpow(A, n):
    R = [[1, 0], [0, 1]]
    while n > 0:
        if n % 2 == 1:
            R = matmul(R, A)
        A = matmul(A, A)
        n //= 2
    return R

print(matpow([[1, 1], [1, 0]], 10))        # [[89, 55], [55, 34]]
print(matpow([[1, 1], [1, 0]], 50)[0][1])  # 12586269025 = F_50

곱셈이 약 \(2\log_2n\)번이라 \(n = 10^{18}\)도 120번쯤이면 됩니다(나머지만 필요하면 매번 나머지를 취해 수가 커지지 않게 합니다). NumPy에서는 np.linalg.matrix_power(A, n)이 같은 일을 합니다.

3.3.3마르코프 연쇄

오늘 맑으면 내일 맑을 확률 0.9, 오늘 흐리면 내일 맑을 확률 0.5라 합시다. 전이행렬 \(P = \begin{pmatrix}0.9 & 0.1\\ 0.5 & 0.5\end{pmatrix}\)의 \((i, j)\) 성분은 "오늘 \(i\)이면 내일 \(j\)"인 확률이고, \(P^n\)의 성분은 \(n\)일 뒤의 확률입니다.

P = [[0.9, 0.1], [0.5, 0.5]]
Q = P
for _ in range(19):
    Q = matmul(Q, P)
print(Q)    # 약 [[0.833333, 0.166667], [0.833333, 0.166667]]

20일 뒤에는 오늘 날씨와 무관하게 맑을 확률이 \(\frac56\)으로 같아집니다. 두 행이 같아진 이 값이 장기 확률(정상분포)이고, \(\pi P = \pi\)를 풀어도 \(\pi = \left(\frac56, \frac16\right)\)입니다.

흔한 오해(1) 행렬 거듭제곱을 성분마다 거듭제곱한다(A**n in NumPy). 그것은 성분별 거듭제곱이다. (2) 확률 행렬을 오래 곱하면 0으로 사라진다고 여긴다. 각 행의 합이 1로 유지되어 일정한 분포로 다가간다.
요약
  1. 선형 점화식 → 행렬 곱, \(F_n\)은 \(A^n\)의 성분.
  2. 빠른 거듭제곱: 지수의 이진 전개, 곱셈 약 \(2\log_2n\)번.
  3. 전이행렬의 거듭제곱 → 장기 확률(정상분포).

3.3.4연습문제

기본

  1. \(A^{13}\)을 빠른 거듭제곱으로 구할 때 \(R\)에 곱해지는 거듭제곱들은?
    답

    \(13 = 1101_2\): \(A^1, A^4, A^8\).

응용

  1. 점화식 \(a_{n+1} = 2a_n + 3a_{n-1}\)을 행렬로 쓰라.
    답

    \(\begin{pmatrix}a_{n+1}\\ a_n\end{pmatrix} = \begin{pmatrix}2 & 3\\ 1 & 0\end{pmatrix}\begin{pmatrix}a_n\\ a_{n-1}\end{pmatrix}\).

심화

  1. 본문의 날씨 연쇄에서 장기 확률 \(\pi = (\pi_1, \pi_2)\)를 \(\pi P = \pi\), \(\pi_1 + \pi_2 = 1\)로 손으로 구하여라.
    답

    \(\pi_1 = 0.9\pi_1 + 0.5\pi_2\)에서 \(0.1\pi_1 = 0.5\pi_2\), \(\pi_1 = 5\pi_2\). \(\pi = \left(\frac56, \frac16\right)\).
