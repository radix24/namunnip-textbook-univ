k-겹 교차검증으로 모형 고르기

본문
이 절에서 배울 것
  • 자료를 \(k\)개 묶음으로 나눠 돌아가며 한 묶음을 검증용으로 쓰는 \(k\)-겹 교차검증을 구현한다.
  • 훈련 오차는 복잡한 모형일수록 늘 줄지만 교차검증 오차는 어느 복잡도에서 최소가 됨을 확인한다.
  • 교차검증 오차가 가장 작은 모형을 고른다.
먼저 알아야 할 것
  • 다항식 최소제곱 (3.2절), 과적합과 검증 오차 (6.3절).

6.4.1왜 나누어 검증하나

6.3절에서 자료를 훈련용과 검증용으로 한 번 나누었습니다. 자료가 적으면 어떻게 나누느냐에 따라 결과가 크게 흔들리고, 검증용으로 뺀 자료가 아깝습니다. \(k\)-겹 교차검증은 자료를 \(k\)개 묶음으로 나눠, 묶음마다 "그 묶음을 빼고 학습 → 그 묶음으로 오차 측정"을 하고 \(k\)번의 오차를 평균합니다. 모든 자료가 한 번씩 검증에 쓰입니다.

6.4.2구현

\(x_i = \frac i{19}\) (\(i = 0, \dots, 19\))에서 \(y_i = \sin2\pi x_i +\) 잡음(표준편차 0.2, random.seed(3))인 자료 20개에 \(d\)차 다항식을 맞춥니다. 묶음은 번호를 5로 나눈 나머지로 정합니다.

def cv_error(d, k=5):
    err = 0
    for f in range(k):
        Xt = [x for i, x in enumerate(xs) if i % k != f]
        Yt = [y for i, y in enumerate(ys) if i % k != f]
        w = fit(Xt, Yt, d)                  # d차 최소제곱 (3.2절)
        err += sum((ev(w, xs[i]) - ys[i])**2 for i in range(len(xs)) if i % k == f)
    return err / len(xs)

훈련 오차는 차수를 올릴수록 계속 줄어듭니다. 교차검증 오차는 3~5차에서 가장 작고(최소 4차, 0.031) 그 뒤로 다시 커집니다. 높은 차수는 잡음까지 따라가 처음 보는 자료를 잘 맞히지 못하기 때문입니다. 잡음의 분산이 \(0.2^2 = 0.04\)이므로 0.03~0.04가 사실상 가장 좋은 값입니다.

6.4.3고르는 규칙

교차검증 오차가 가장 작은 복잡도를 고르고, 그 복잡도로 자료 전체에 다시 학습합니다. 오차가 비슷하면 더 간단한 모형을 고르는 것이 보통입니다(위에서 3차와 4차는 거의 같으므로 3차도 좋은 선택). \(k\)는 5나 10을 흔히 쓰고, \(k\)가 자료 수와 같으면 하나씩 빼는 LOO(leave-one-out) 교차검증입니다.

흔한 오해(1) 훈련 오차가 가장 작은 모형을 고른다. 늘 가장 복잡한 모형이 되어 과적합한다. (2) 교차검증으로 고른 모형의 검증 오차를 최종 성능으로 보고한다. 고르는 데 썼으므로 약간 낙관적이다. 처음부터 떼어 둔 시험 자료로 따로 잰다.
요약
  1. \(k\)-겹: 묶음마다 빼고 학습, 그 묶음으로 검증, 평균.
  2. 훈련 오차는 단조 감소, 교차검증 오차는 U자.
  3. 최소(또는 비슷하면 더 간단한) 복잡도를 고른다.

6.4.4연습문제

기본

  1. 자료 20개에 5-겹 교차검증을 하면 모형을 몇 번 학습하며, 각 학습에 자료 몇 개를 쓰는가?
    답

    5번, 각 16개.

응용

  1. 표에서 1차의 교차검증 오차(0.30)가 잡음 분산(0.04)보다 훨씬 큰 이유는?
    답

    직선은 사인 곡선의 모양을 따라가지 못해(과소적합) 편향이 크다.

심화

  1. 묶음을 번호 순서대로 연속 4개씩(0~3, 4~7, …) 나누면 어떤 문제가 생기는가?
    답

    검증 묶음이 \(x\)의 한쪽 구간에 몰려 학습 자료에 없는 구간을 외삽하게 되어, 특히 높은 차수에서 오차가 과장된다. 섞거나 번갈아 나눈다.
