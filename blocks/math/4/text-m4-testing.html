함수로 나누고 테스트로 확인하기

본문

1000 이하의 쌍둥이 소수 쌍을 세는 프로그램을 짰더니 35라는 답이 나왔다. 이 답을 믿어도 될까? 큰 입력의 답은 손으로 확인할 수 없는데, 프로그램이 옳은지 어떻게 확신할 수 있을까?

먼저 알아야 할 것반복문과 함수(1.1절), 소수 판정(1.2절)을 쓴다.

1.4.1함수로 나누기

처음 질문처럼 "1000 이하의 쌍둥이 소수 쌍의 개수"를 구한다고 하자. 한 덩어리로 쓰면 어디가 틀렸는지 찾기 어렵다. 그래서 소수 판정, 쌍 찾기, 세기를 따로 나눈다.

def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

def twin_pairs(N):
    return [(p, p + 2) for p in range(2, N - 1) if is_prime(p) and is_prime(p + 2)]

print(len(twin_pairs(1000)))   # 35

1.4.2assert로 테스트하기

assert 조건은 조건이 거짓이면 프로그램을 멈추고 알려 준다. 이것으로 답을 아는 작은 경우에 함수를 검사한다.

assert is_prime(2) and is_prime(97)
assert not is_prime(1) and not is_prime(0) and not is_prime(91)   # 91 = 7*13
assert twin_pairs(20) == [(3, 5), (5, 7), (11, 13), (17, 19)]
print("모든 테스트 통과")

특히 경계값을 넣어야 한다. is_prime에서 n < 2 처리를 빼먹으면 1이 소수로 나오고, while d * d <= n을 <로 쓰면 25 같은 제곱수가 소수로 나온다. 위 테스트는 둘 다 잡아낸다. 즉 테스트는 아무 값이나가 아니라 틀리기 쉬운 곳을 겨냥해 고른다.

1.4.3왜 테스트를 먼저 쓰나

수학에서 정리를 증명하기 전에 작은 예로 확인하듯, 코드도 작은 예로 먼저 확인한다. 함수를 고칠 때마다 테스트를 다시 돌리면 고친 곳이 다른 곳을 망가뜨리지 않았는지 바로 알 수 있다. 실제 개발에서는 테스트를 한 파일에 모아 두고 pytest 같은 도구로 한꺼번에 돌린다. 또 특정 값 대신 성질을 검사하는 방법도 있다. 예를 들어 \(\gcd(a, b)\)가 \(a\)와 \(b\)를 모두 나누는지를 무작위 \(a, b\) 여러 쌍에 대해 확인하면, 답을 미리 몰라도 함수를 검사할 수 있다.

흔한 오해큰 입력에서 결과가 그럴듯하면 맞다고 여기기 쉽지만, 작은 경우를 손으로 확인해야 한다. 또 테스트가 통과하면 코드가 옳다고 여기는 것도 틀렸다. 테스트한 경우에만 맞다는 뜻이므로, 경계값과 특이한 경우를 골고루 넣어야 한다.
마무리

처음 질문에 답하면, 35라는 답을 믿으려면 프로그램을 한 가지 일만 하는 함수로 나누고 각 함수를 검사해야 한다. assert로 답을 아는 작은 경우, 특히 0, 1, 제곱수, 빈 입력 같은 경계값을 검사하면 흔한 실수를 잡아낼 수 있다. 테스트는 옳음의 증명은 아니지만, 고칠 때마다 다시 돌려 망가진 곳을 바로 찾게 해 준다.

1.4.4연습문제

기본

  1. 자연수의 자릿수 합을 구하는 함수 digit_sum(n)을 쓰고 테스트 두 개를 붙여라.
    답

    def digit_sum(n): return sum(int(c) for c in str(n)), assert digit_sum(0) == 0, assert digit_sum(1234) == 10.

응용

  1. is_prime의 while d * d <= n을 while d * d < n으로 바꾸면 어떤 테스트가 실패하는가?
    답

    4, 9, 25 같은 소수의 제곱이 소수로 판정된다. assert not is_prime(25)가 실패한다.

심화

  1. 최대공약수 함수 gcd(a, b)의 성질을 이용한 테스트를 두 가지 생각하여라(특정 값이 아닌 성질).
    답

    (1) gcd(a, b)는 a와 b를 모두 나눈다. (2) gcd(a, b) * lcm(a, b) == a * b. 여러 무작위 a, b에 대해 반복해 검사한다.
