NumPy로 연립방정식과 고유값 풀기

본문

선형대수 시간에 손으로 풀던 연립방정식과 고유값 문제를 컴퓨터에 맡기고 싶다. 파이썬 리스트로 행렬을 다루면 반복문을 직접 써야 하고 느리다. 행렬 계산을 빠르고 안전하게 하려면 무엇을 써야 하고, 무엇을 조심해야 할까?

먼저 알아야 할 것가우스 소거와 고유값(선형대수(1) 1.1절), 리스트(1.3절)를 쓴다.

3.1.1배열과 행렬 연산

NumPy 배열은 같은 자료형의 수를 연속된 메모리에 담고, 벡터·행렬 연산을 C로 구현된 함수가 한 번에 처리한다. 그래서 리스트와 반복문으로 계산하는 것보다 훨씬 빠르다.

import numpy as np
A = np.array([[2, 1, -1],
              [-3, -1, 2],
              [-2, 1, 2]], dtype=float)
b = np.array([8, -11, -3], dtype=float)
print(A.shape)        # (3, 3)
print(A @ A)          # 행렬 곱
print(A * A)          # 성분별 곱 (행렬 곱이 아님!)
print(A.T)            # 전치

여기서 *는 성분별 곱이고 행렬 곱은 @이다. 그림 1처럼 이 차이를 놓치는 것이 가장 흔한 버그이다.

3.1.2연립방정식

x = np.linalg.solve(A, b)
print(x)                    # 약 [ 2.  3. -1.]
print(np.allclose(A @ x, b))   # True

해는 \((x, y, z) = (2, 3, -1)\)이며, 가우스 소거로 검산할 수 있다. 출력이 2.이 아니라 1.9999999999999998처럼 나올 수도 있는데, 부동소수점 반올림 때문이다. 그래서 결과 비교는 == 대신 np.allclose로 한다.

한편 np.linalg.inv(A) @ b도 같은 답을 주지만 권하지 않는다. 역행렬을 만드는 데 연산이 더 들고 오차도 더 커지기 때문이다. solve는 부분 피벗팅 LU 분해(선형대수(2) 7.1절)로 직접 푼다. 또 행렬이 특이하면 LinAlgError를 내지만, 거의 특이하면 경고 없이 부정확한 답을 낼 수 있으므로 np.linalg.cond(A)로 조건수를 확인한다.

3.1.3고유값

S = np.array([[2., 1.], [1., 3.]])
w, V = np.linalg.eigh(S)    # 대칭행렬용: 고유값 오름차순
print(w)                     # 약 [1.381966 3.618034]
print(V)                     # 열이 정규직교 고유벡터
print(np.allclose(S @ V, V * w))   # True: S v_i = w_i v_i

결과는 고유값 \(\frac{5 \pm \sqrt5}2\)와 일치한다. 대칭행렬에는 eigh를 쓰면 실수 고유값과 직교 고유벡터를 안정적으로 준다. 일반 행렬에는 eig를 쓰며, 회전 행렬처럼 고유값이 복소수일 수 있다. 고유벡터는 길이 1로 정규화되지만 부호는 정해져 있지 않다. 그리고 V * w는 브로드캐스팅으로 각 열에 해당 고유값을 곱한 것이다.

예를 들어 마르코프 연쇄의 정상분포는 전이행렬 \(P\)에 대해 \(\pi P = \pi\)인 \(\pi\), 곧 \(P^T\)의 고유값 1에 대한 고유벡터이며, 3.3절에서 다른 방법으로도 구한다.

흔한 오해A * B를 행렬 곱으로 쓰는 실수가 가장 흔하다. 또 정수 배열(dtype=int)로 만들면 나눗셈 결과가 잘리거나 형이 바뀌므로 dtype=float로 만든다. 고유벡터의 부호가 손으로 구한 것과 반대라 틀렸다고 여기기도 하는데, 부호만 다르면 같은 고유벡터이다.
마무리

처음 질문에 답하면, 행렬 계산에는 NumPy 배열과 np.linalg를 쓴다. 행렬 곱은 @, 성분별 곱은 *, 전치는 .T이며, 연립방정식은 역행렬 대신 np.linalg.solve로 풀고 결과는 allclose로 비교한다. 고유값은 대칭이면 eigh, 일반 행렬이면 eig로 구하고, 고유벡터는 열로 나오며 부호는 임의이다. 거의 특이한 행렬에서는 조건수를 함께 확인해야 한다.

3.1.4연습문제

기본

  1. \(x + 2y = 5\), \(3x + 4y = 6\)을 solve로 풀 코드를 쓰고 답을 손으로 확인하여라.
    답

    np.linalg.solve([[1, 2], [3, 4]], [5, 6]) → \((-4, 4.5)\).

응용

  1. np.linalg.eig로 \(\begin{pmatrix}0 & -1\\1 & 0\end{pmatrix}\)의 고유값을 구하면 무엇이 나오는가?
    답

    복소수 [0.+1.j, 0.-1.j] (\(\pm i\)). 회전 행렬은 실고유값이 없다.

심화

  1. \(\begin{pmatrix}1 & 1\\1 & 1 + 10^{-12}\end{pmatrix}\mathbf x = (2, 2)\)를 solve로 풀고 조건수를 보아라. 결과를 얼마나 믿을 수 있는가?
    답

    정확한 해는 \((2, 0)\), 조건수는 약 \(4\times10^{12}\). 배정밀도에서 약 12자리를 잃어 해의 유효숫자는 3~4자리 정도뿐이다(수학8 7.2절).
