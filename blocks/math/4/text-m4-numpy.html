NumPy로 연립방정식과 고유값 풀기

본문
이 절에서 배울 것
  • NumPy 배열을 만들고 행렬 곱(@), 전치, 성분별 연산을 구별한다.
  • np.linalg.solve로 연립방정식을, np.linalg.eig/eigh로 고유값 문제를 푼다.
  • 역행렬을 직접 구하는 대신 solve를 쓰는 이유와 부동소수점 결과를 해석하는 법을 안다.
먼저 알아야 할 것
  • 파이썬 리스트와 반복문 (1.1절), 행렬과 고유값 (수학1 6.1절).

3.1.1배열과 행렬 연산

파이썬 리스트로 행렬을 다루면 반복문을 직접 써야 하고 느립니다. NumPy 배열은 같은 자료형의 수를 연속된 메모리에 담아, 벡터·행렬 연산을 C로 구현된 함수가 한 번에 처리합니다.

import numpy as np
A = np.array([[2, 1, -1],
              [-3, -1, 2],
              [-2, 1, 2]], dtype=float)
b = np.array([8, -11, -3], dtype=float)
print(A.shape)        # (3, 3)
print(A @ A)          # 행렬 곱
print(A * A)          # 성분별 곱 (행렬 곱이 아님!)
print(A.T)            # 전치

*는 성분별 곱이고 행렬 곱은 @입니다. 이 차이를 놓치는 것이 가장 흔한 버그입니다.

3.1.2연립방정식

x = np.linalg.solve(A, b)
print(x)                    # 약 [ 2.  3. -1.]
print(np.allclose(A @ x, b))   # True

해는 \((x, y, z) = (2, 3, -1)\)입니다(가우스 소거로 검산할 수 있습니다, 수학1 1.1절). 출력이 2.이 아니라 1.9999999999999998처럼 나올 수도 있는데, 부동소수점 반올림 때문입니다. 그래서 결과 비교는 == 대신 np.allclose로 합니다.

np.linalg.inv(A) @ b도 같은 답을 주지만 권하지 않습니다. 역행렬을 만드는 데 연산이 더 들고, 오차도 더 커집니다. solve는 부분 피벗팅 LU 분해(수학8 7.1절)를 써서 직접 풉니다. 행렬이 특이하면 LinAlgError를 내고, 거의 특이하면 경고 없이 부정확한 답을 낼 수 있으므로 np.linalg.cond(A)로 조건수를 확인합니다.

3.1.3고유값

S = np.array([[2., 1.], [1., 3.]])
w, V = np.linalg.eigh(S)    # 대칭행렬용: 고유값 오름차순
print(w)                     # 약 [1.381966 3.618034]
print(V)                     # 열이 정규직교 고유벡터
print(np.allclose(S @ V, V * w))   # True: S v_i = w_i v_i

고유값 \(\frac{5 \pm \sqrt5}2\)와 일치합니다. 대칭행렬에는 eigh를 쓰면 실수 고유값과 직교 고유벡터를 안정적으로 줍니다. 일반 행렬에는 eig를 쓰고, 고유값이 복소수일 수 있습니다(회전 행렬). 고유벡터는 길이 1로 정규화되지만 부호(\(\pm\))는 정해져 있지 않습니다. V * w는 브로드캐스팅으로 각 열에 해당 고유값을 곱한 것입니다.

응용: 마르코프 연쇄의 정상분포는 전이행렬 \(P\)의 \(\pi P = \pi\), 곧 \(P^T\)의 고유값 1의 고유벡터입니다. 같은 절의 예제 카드에서 계산합니다.

흔한 실수(1) A * B를 행렬 곱으로 쓴다. (2) 정수 배열(dtype=int)로 만들어 나눗셈 결과가 잘리거나 형이 바뀐다: dtype=float로 만든다. (3) 고유벡터의 부호가 손으로 구한 것과 반대라 틀렸다고 여긴다.
요약
  1. np.array, @(행렬 곱), *(성분별), .T.
  2. 연립방정식은 np.linalg.solve(역행렬 대신). 결과 비교는 allclose.
  3. 고유값: 대칭이면 eigh, 일반은 eig. 고유벡터는 열, 부호는 임의.

3.1.4연습문제

기본

  1. \(x + 2y = 5\), \(3x + 4y = 6\)을 solve로 풀 코드를 쓰고 답을 손으로 확인하여라.
    답

    np.linalg.solve([[1, 2], [3, 4]], [5, 6]) → \((-4, 4.5)\).

응용

  1. np.linalg.eig로 \(\begin{pmatrix}0 & -1\\1 & 0\end{pmatrix}\)의 고유값을 구하면 무엇이 나오는가?
    답

    복소수 [0.+1.j, 0.-1.j] (\(\pm i\)). 회전 행렬은 실고유값이 없다.

심화

  1. \(\begin{pmatrix}1 & 1\\1 & 1 + 10^{-12}\end{pmatrix}\mathbf x = (2, 2)\)를 solve로 풀고 조건수를 보아라. 결과를 얼마나 믿을 수 있는가?
    답

    정확한 해는 \((2, 0)\), 조건수는 약 \(4\times10^{12}\). 배정밀도에서 약 12자리를 잃어 해의 유효숫자는 3~4자리 정도뿐이다(수학8 7.2절).
