리스트, 딕셔너리, 리스트 내포

본문

어떤 정수를 제곱해서 7로 나누면 나머지가 3이 될 수 있을까? 제곱수의 일의 자리에 7이 나올 수 있을까? 몇 줄의 코드로 표를 만들어 보면 이런 질문에 금방 답할 수 있는데, 그 표를 어떻게 만들까?

먼저 알아야 할 것반복문과 함수(1.1절), 고등학교의 수열과 나머지를 쓴다.

1.3.1리스트 내포

1부터 10까지의 제곱처럼 규칙으로 만드는 목록은 반복문 대신 한 줄로 쓴다.

sq = [n*n for n in range(1, 11)]
print(sq)          # [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
even = [n for n in range(1, 21) if n % 2 == 0]
print(sum(even))   # 110

이 모양은 수학의 집합 기호 \(\{n^2 \mid 1 \le n \le 10\}\)과 같다. if 뒤의 조건으로 원소를 거른다. 예를 들어 [n for n in range(1, 101) if n % 7 == 3]은 7로 나누어 3이 남는 100 이하의 수 14개를 모은다. 반복문으로 쓰면 빈 리스트를 만들고, 조건을 검사하고, 원소를 덧붙이는 세 줄이 필요한 일을 한 줄로 쓰는 셈이며, 읽는 사람도 무엇을 모으는지 바로 알 수 있다.

1.3.2딕셔너리로 세기

딕셔너리는 열쇠와 값을 짝지은 표이다. 제곱수의 일의 자리가 각각 몇 번 나오는지 세어 보자.

freq = {}
for s in sq:
    d = s % 10
    freq[d] = freq.get(d, 0) + 1
print(freq)        # {1: 2, 4: 2, 9: 2, 6: 2, 5: 1, 0: 1}

여기서 freq.get(d, 0)은 열쇠가 없으면 0을 돌려준다. 표를 보면 제곱수의 일의 자리에는 2, 3, 7, 8이 절대 나오지 않는다. 제곱의 일의 자리는 일의 자리끼리의 곱으로 정해지고, 0부터 9까지를 제곱한 일의 자리가 0, 1, 4, 5, 6, 9뿐이기 때문이다.

같은 일을 표준 라이브러리의 collections.Counter로 하면 Counter(s % 10 for s in sq) 한 줄로 끝난다. 그래도 딕셔너리로 직접 세어 보는 것은 의미가 있다. 빈도표는 확률과 통계에서 도수분포표로, 정수론에서 나머지의 분포를 살피는 실험으로 거듭 나오며, 그때마다 열쇠가 무엇이고 값이 무엇인지 정하는 것이 문제를 정리하는 첫걸음이기 때문이다.

1.3.3집합

r = {n*n % 7 for n in range(7)}
print(r)           # {0, 1, 2, 4}

중괄호 내포는 집합을 만들고 중복을 자동으로 없앤다. 결과를 보면 7로 나눈 나머지 가운데 제곱수의 나머지는 0, 1, 2, 4뿐이며, 그림 1이 이 대응이다. 그래서 어떤 정수의 제곱도 7로 나누어 3이 남지 않는다. 이런 나머지를 이차잉여라 하며 정수론에서 자세히 다룬다. 0부터 6까지만 확인하면 충분한 이유는 \(n \equiv m \pmod 7\)이면 \(n^2 \equiv m^2 \pmod 7\)이기 때문이다.

흔한 오해range(1, 10)이 10을 포함한다고 여기기 쉽지만, 끝은 포함하지 않는다. 또 딕셔너리에 없는 열쇠를 freq[d] += 1로 바로 올리는 실수가 있다. 처음에는 열쇠가 없어 오류가 나므로 get을 쓴다.
마무리

처음 질문의 답은 둘 다 "없다"이다. 집합 내포로 제곱을 7로 나눈 나머지를 모으면 0, 1, 2, 4뿐이고, 딕셔너리로 일의 자리 빈도를 세면 7은 한 번도 나오지 않는다. 이런 표는 리스트 내포 [식 for … if …]로 수열을 만들고, 딕셔너리의 get(열쇠, 0) + 1로 빈도를 세고, 집합 내포로 중복 없는 결과를 모아 만든다.

1.3.4연습문제

기본

  1. 1부터 100까지 3의 배수이면서 5의 배수가 아닌 수의 개수를 리스트 내포로 구하여라.
    답

    len([n for n in range(1, 101) if n % 3 == 0 and n % 5 != 0]) → 27 (3의 배수 33개 − 15의 배수 6개).

응용

  1. 세제곱수 \(n^3\) (\(0 \le n \le 8\))을 9로 나눈 나머지의 집합을 구하여라.
    답

    {n**3 % 9 for n in range(9)} → {0, 1, 8}.

심화

  1. 문장의 글자마다 나온 횟수를 세고 가장 많이 나온 글자를 찾는 코드를 써라.
    답

    빈도표 freq를 만든 뒤 max(freq, key=freq.get). (빈칸은 미리 빼려면 if ch != ' '.)
