머신러닝 입문 연습 문제

문제 6 · 계산·실습·개념·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산점 \((0, 1), (1, 3), (2, 4)\)에 직선 \(\hat y = wx + b\)를 최소제곱으로 맞추어라. [06-01]

    힌트 1

    \(w = S_{xy}/S_{xx}\), \(b = \bar y - w\bar x\) (6.1절).

    힌트 2

    \(\bar x = 1\), \(\bar y = \frac83\).

    풀이

    \(S_{xx} = 1 + 0 + 1 = 2\), \(S_{xy} = (-1)(1 - \frac83) + 0 + (1)(4 - \frac83) = \frac53 + \frac43 = 3\). \(w = \frac32\), \(b = \frac83 - \frac32 = \frac76 \approx 1.1667\).

  2. 실습문제 1의 자료로 경사하강법(\(\eta = 0.1\), 시작 \(w = b = 0\))을 한 번 하여 \((w, b)\)를 구하여라. [06-01]

    힌트 1

    \(e_i = 0 - y_i\)이므로 \(e = (-1, -3, -4)\).

    힌트 2

    \(\partial_w = \frac23\sum e_ix_i\), \(\partial_b = \frac23\sum e_i\).

    풀이

    \(\sum e_ix_i = 0 - 3 - 8 = -11\), \(\sum e_i = -8\). 기울기 \((-\frac{22}3, -\frac{16}3)\). \(w = 0.1\cdot\frac{22}3 \approx 0.7333\), \(b = 0.1\cdot\frac{16}3 \approx 0.5333\). 정답 \((1.5, 1.1667)\) 쪽으로 움직였다.

  3. 계산로지스틱 회귀에서 한 점 \((x, y) = (2, 1)\)의 손실과 \(w\)에 대한 기울기를 \(w = 0.5\), \(b = -1\)에서 구하여라. [06-02]

    힌트 1

    \(t = wx + b = 0\)이므로 \(p = \sigma(0)\).

    힌트 2

    기울기는 \((p - y)x\) (6.2절).

    풀이

    \(p = \frac12\). 손실 \(-\ln\frac12 = \ln 2 \approx 0.693\). 기울기 \((\frac12 - 1)\cdot2 = -1\)이므로 경사하강법은 \(w\)를 키운다(이 점의 확률을 1 쪽으로 올리는 방향).

  4. 개념로지스틱 회귀의 손실로 MSE \(\frac1n\sum(p_i - y_i)^2\) 대신 교차 엔트로피를 쓰는 이유 두 가지를 들어라. [06-02]

    힌트 1

    최대가능도.

    힌트 2

    볼록성과, 크게 틀렸을 때의 기울기 크기.

    풀이

    (1) 교차 엔트로피는 베르누이 모형의 최대가능도에서 나온다. (2) 교차 엔트로피는 \((\mathbf w, b)\)에 대해 볼록이지만 시그모이드에 MSE를 붙이면 볼록이 아니다. 또 MSE의 기울기는 \((p - y)p(1 - p)\mathbf x\)라 \(p\)가 0이나 1 근처에서 크게 틀려도 기울기가 거의 0이 되어 학습이 멈춘다. 교차 엔트로피의 기울기 \((p - y)\mathbf x\)는 그렇지 않다.

  5. 개념자료 60개로 10-겹 교차검증을 할 때 각 점은 검증에 몇 번, 훈련에 몇 번 쓰이는가? [06-03]

    힌트 1

    묶음 하나는 6개.

    힌트 2

    자기 묶음이 검증용일 때만 검증에 쓰인다.

    풀이

    검증 1번, 훈련 9번. 맞춤은 모두 10번이며 각각 54개로 훈련한다(6.3절).

  6. 판단어떤 팀이 시험 자료의 정확도를 보며 모형 구조를 20번 바꾼 끝에 시험 정확도 95%를 얻고 "새 자료에서도 95%일 것"이라고 보고했다. 옳은가? [06-03]

    힌트 1

    시험 자료는 무엇에 쓰라고 떼어 둔 것인가?

    힌트 2

    20번의 선택이 시험 자료에 맞춰졌다.

    풀이

    옳지 않다. 시험 자료를 보고 구조를 골랐으므로 시험 자료가 사실상 검증 자료가 되었고, 95%는 낙관적인 추정이다. 선택은 검증 자료나 교차검증으로 하고, 한 번도 보지 않은 새 시험 자료로 다시 재야 한다.
