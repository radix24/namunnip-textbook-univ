선형회귀: 정규방정식과 경사하강법

본문

학생 10명의 공부 시간과 시험 점수를 모았더니, 오래 공부할수록 점수가 대체로 높았다. 12시간 공부한 학생의 점수를 예측하려면 어떤 직선을 그어야 할까? "가장 잘 맞는 직선"을 정확히 무엇으로 정하고, 어떻게 계산할까?

먼저 알아야 할 것다항식 맞춤과 계획행렬(3.2절), 경사하강법(5.1절)을 쓴다.

6.1.1모형과 손실

머신러닝의 지도학습은 입력 \(\mathbf x\)와 정답 \(y\)의 쌍 \(n\)개로 규칙을 배우는 일이며, 선형회귀는 그 가운데 가장 단순한 모형을 쓴다. 모형에 넣는 입력 변수를 특성이라 하며 여기서는 공부 시간 \(x\)이다. 매개변수를 가진 함수를 모형이라 하며, 선형회귀의 모형은 \(\hat y = wx + b\)이고 특성이 여럿이면 \(\hat y = \mathbf w\cdot\mathbf x + b\)이다. 예측이 정답과 얼마나 다른지 재는 함수를 손실함수라 하며, 선형회귀에서는 평균제곱오차 \(\mathrm{MSE}(w, b) = \frac1n\sum_{i=1}^n(wx_i + b - y_i)^2\)을 쓴다.

그러므로 학습은 손실을 최소로 하는 \((w, b)\)를 찾는 최적화 문제이다. 처음 질문의 자료로 해 보자.

\(x\) (시간)12345678910
\(y\) (점수)52556160687175748286

6.1.2정규방정식으로 풀기

계획행렬 \(A\)의 \(i\)행을 \((1, x_i)\)로 두면 손실은 \(\frac1n\|A\boldsymbol\beta - \mathbf y\|^2\) (\(\boldsymbol\beta = (b, w)\))이고, 기울기를 0으로 놓으면 정규방정식 \(A^TA\boldsymbol\beta = A^T\mathbf y\)를 얻는다(선형대수(2) 1.1절). 직선 하나라면 풀이가 간단하다. \(\bar x = 5.5\), \(\bar y = 68.4\), \(S_{xx} = \sum(x_i - \bar x)^2 = 82.5\), \(S_{xy} = \sum(x_i - \bar x)(y_i - \bar y) = 304\)이므로 다음을 얻는다.

\[w = \frac{S_{xy}}{S_{xx}} = \frac{304}{82.5} \approx 3.6848,\qquad b = \bar y - w\bar x \approx 48.1333.\] 
import numpy as np
x = np.arange(1, 11, dtype=float)
y = np.array([52, 55, 61, 60, 68, 71, 75, 74, 82, 86], dtype=float)
A = np.column_stack([np.ones_like(x), x])      # 열: 1, x
beta = np.linalg.solve(A.T @ A, A.T @ y)        # 또는 np.linalg.lstsq(A, y, rcond=None)[0]
print(beta)                                     # 약 [48.1333  3.6848]
print(np.mean((A @ beta - y)**2))               # MSE 약 3.0206
print(beta[0] + beta[1] * 12)                   # 12시간 공부하면 약 92.35점

즉 한 시간 더 공부할 때마다 점수가 약 3.68점 오른다는 뜻이며, 그림 1의 직선이다. 정규방정식은 한 번의 선형 연립방정식으로 끝나지만, 특성이 \(d\)개이면 \(d\times d\) 행렬을 풀어야 한다. 그래서 \(d\)가 수만 개 이상이거나 자료가 메모리에 다 들어가지 않으면 부담이 된다.

6.1.3경사하강법으로 풀기

\(e_i = wx_i + b - y_i\)로 두고 MSE를 편미분하면 다음과 같다.

\[\frac{\partial\,\mathrm{MSE}}{\partial w} = \frac2n\sum e_ix_i,\qquad \frac{\partial\,\mathrm{MSE}}{\partial b} = \frac2n\sum e_i.\] 
def fit_gd(x, y, eta, steps):
    w, b = 0.0, 0.0
    for _ in range(steps):
        e = w * x + b - y
        w -= eta * 2 * np.mean(e * x)
        b -= eta * 2 * np.mean(e)
    return w, b

print(fit_gd(x, y, 0.01, 3000))     # 약 (3.6849, 48.1332): 정규방정식과 같다

MSE는 \((w, b)\)의 볼록 이차함수이므로 경사하강법은 학습률만 알맞으면 유일한 최솟점에 간다(5.2절). 그러나 속도는 실망스럽다. \(\eta = 0.01\)이면 MSE가 최솟값과 \(10^{-6}\) 이내가 되기까지 2372번이 걸리고, 0.0255를 넘는 학습률에서는 발산한다. 원인은 5.1절의 길쭉한 골짜기이다. \(w\), \(b\) 순서로 쓴 MSE의 헤세 행렬 \(\begin{pmatrix}77 & 11\\11 & 2\end{pmatrix}\)의 고유값이 약 78.6과 0.42로, 비가 187이나 된다.

6.1.4표준화

특성을 \(x' = (x - \bar x)/s\) (\(s\)는 표준편차)로 바꾸어 평균 0, 분산 1로 만드는 것을 표준화라 한다. 표준화하면 헤세 행렬이 \(2I\)가 되어 골짜기가 둥글어지고, \(\eta = 0.5\)이면 한 번에 최솟점에 도착한다. 표준화한 기울기 \(w' \approx 10.58\)은 \(w = w'/s\) (\(s = \sqrt{8.25} \approx 2.872\))로 원래 단위의 3.6848로 돌아가며, 모형 자체는 같다. 특성이 여럿이고 키는 cm, 몸무게는 kg처럼 단위가 다르면 표준화의 효과가 더 크다.

한편 실제 머신러닝에서는 자료가 매우 많아 매 단계 전체 자료의 기울기를 계산하지 않고, 무작위로 뽑은 일부, 곧 미니배치로 기울기를 어림한다. 이것이 5.3절의 확률적 경사하강법이며, 신경망 학습의 기본 도구이다.

흔한 오해기울기에서 2나 \(1/n\)을 빼먹으면 학습률의 의미가 달라진다. 또 표준화의 평균과 표준편차를 검증·시험 자료로 다시 계산하는 실수가 있는데, 훈련 자료에서 구한 값을 그대로 써야 한다. 정규방정식을 inv(A.T @ A)로 푸는 것도 피하고, solve나 lstsq를 쓴다(3.1절).
마무리

처음 질문에 답하면, 가장 잘 맞는 직선은 평균제곱오차가 가장 작은 직선이고, 이 자료에서는 \(\hat y \approx 3.68x + 48.13\)이라 12시간이면 약 92.4점으로 예측된다. 계산은 정규방정식 \(A^TA\boldsymbol\beta = A^T\mathbf y\)로 한 번에 하거나, 기울기 \(\frac2n\sum e_i(x_i, 1)\)을 쓰는 경사하강법으로 한다. 경사하강법은 같은 해에 가지만 조건수가 크면 느리므로, 특성을 표준화해 헤세 행렬을 둥글게 만들면 빨라진다.

6.1.5연습문제

기본

  1. 위 모형으로 0시간 공부한 학생의 점수를 예측하고, 그 예측을 믿을 수 있는지 말하여라.
    답

    약 48.1점(절편). 자료의 범위(1~10시간) 밖이라 외삽이므로 조심해야 한다.

응용

  1. 특성이 \(d\)개인 선형회귀의 MSE 기울기를 행렬로 쓰면 \(\frac2nA^T(A\boldsymbol\beta - \mathbf y)\)임을 보이고, 이를 NumPy 한 줄로 써라.
    답

    \(\mathrm{MSE} = \frac1n(A\boldsymbol\beta - \mathbf y)^T(A\boldsymbol\beta - \mathbf y)\)을 미분하면 \(\frac2nA^T(A\boldsymbol\beta - \mathbf y)\). g = 2 / n * A.T @ (A @ beta - y).

심화

  1. 표준화한 특성(평균 0, 분산 1)에서 MSE의 헤세 행렬이 \(2I\)임을 보여라.
    답

    헤세 행렬은 \(\frac2nA^TA = 2\begin{pmatrix}\overline{x^2} & \bar x\\\bar x & 1\end{pmatrix}\)이고, \(\bar x = 0\), \(\overline{x^2} = 1\)이면 \(2I\)이다.
