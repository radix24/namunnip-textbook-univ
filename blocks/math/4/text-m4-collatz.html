수학 실험: 콜라츠 수열

본문

양의 정수에서 시작해 짝수면 2로 나누고 홀수면 3을 곱해 1을 더하기를 되풀이한다. 27에서 시작하면 몇 단계 만에 1에 닿을까? 어떤 수에서 시작해도 언젠가 1에 닿을까? 증명이 없는 문제를 컴퓨터로 어떻게 탐구할 수 있을까?

먼저 알아야 할 것반복문, 리스트 내포(1.3절), 테스트(1.4절)를 쓴다.

2.1.1문제

처음 질문의 규칙에 대해 "어떤 \(n\)에서 시작해도 언젠가 1에 도달한다"는 것이 콜라츠 추측이다. 규칙은 초등학생도 이해하지만 1937년 이래 아무도 증명하지 못했고, 컴퓨터로는 \(2^{68}\) 근처까지 확인되었다. 이 절의 목적은 증명이 아니라 실험하는 방법을 익히는 것이다.

def collatz(n):
    seq = [n]
    while n != 1:
        n = n // 2 if n % 2 == 0 else 3 * n + 1
        seq.append(n)
    return seq

print(collatz(6))            # [6, 3, 10, 5, 16, 8, 4, 2, 1]
print(len(collatz(6)) - 1)   # 8 (1에 닿기까지의 단계 수)

여기서 //는 정수 나눗셈이다. /를 쓰면 실수가 되어 큰 수에서 정확도를 잃는다. 또 추측이 틀려 1에 닿지 않는 수가 있다면 이 함수는 끝나지 않으므로, 실험 코드에는 단계 수의 상한을 두는 것이 안전하다.

2.1.2자료 모으기

print(len(collatz(27)) - 1, max(collatz(27)))   # 111 9232

steps = [len(collatz(n)) - 1 for n in range(1, 10001)]
best = max(range(1, 10001), key=lambda n: steps[n - 1])
print(best, steps[best - 1])                     # 6171 261
print(sum(steps) / len(steps))                   # 84.9666

결과에서 세 가지를 관찰할 수 있다. 첫째, 27은 작은 수인데 111단계를 거치고 9232까지 올라간다. 그림 1처럼 단계 수는 \(n\)의 크기와 거의 관계없이 들쭉날쭉하다. 둘째, 1만 이하에서 가장 오래 걸리는 수는 6171로 261단계이다. 셋째, 1만 이하의 평균 단계 수는 약 85이다.

2.1.3추측과 검증

관찰에서 추측을 세우고 더 많은 자료로 시험한다. 예를 들어 "단계 수는 \(\log n\)에 비례해 늘어난다"는 추측을 세울 수 있다. 홀수 단계 \(n \to 3n + 1\) 뒤에는 반드시 짝수가 와서 2로 나뉘므로, 한 쌍의 단계에서 대략 \(\frac32\)배가 되고 짝수 단계에서는 \(\frac12\)배가 된다. 평균적으로 이런 곱이 1보다 작아 로그적으로 줄어든다고 예측할 수 있으며, 범위를 10배씩 넓혀 평균 단계 수가 대략 일정량씩 늘어나는지 확인하면 된다.

반면 "\(2^k\)에서 시작하면 정확히 \(k\)단계"라는 추측은 실험할 필요도 없이 증명된다. 계속 2로 나뉘기 때문이다. 또 "단계 수는 \(n\)이 커지면 늘어난다"는 추측은 그림 1의 \(n = 27\)(111단계)과 \(n = 28\)(18단계)이 바로 반박한다. 그러므로 실험은 추측을 만들고 반례를 찾는 데 강력하지만, 유한한 확인은 "모든 \(n\)"에 대한 증명이 될 수 없다.

흔한 오해n / 2를 써서 실수로 바뀌는 실수가 흔하다. 또 끝나지 않을 가능성을 고려하지 않고 무한 반복을 만들기 쉽다. "1억까지 확인했으니 참이다"라고 결론내는 것도 틀렸다. 수학에는 첫 반례가 아주 큰 추측들이 있으며, 폴리아 추측은 첫 반례가 약 9억이다.
마무리

처음 질문에 답하면, 27에서 시작하면 111단계 만에 1에 닿지만 어떤 수에서 시작해도 그런지는 아직 아무도 모른다. 이런 문제는 규칙을 함수로, 시작값 범위를 리스트 내포로 써서 자료를 체계적으로 모으고, 관찰에서 추측을 세워 더 큰 자료로 시험하며 탐구한다. 다만 실험은 반례를 찾을 수는 있어도 증명은 아니며, 콜라츠 추측은 미해결로 남아 있다.

2.1.4연습문제

기본

  1. 100 이하에서 단계 수가 가장 많은 수와 그 단계 수는?
    답

    97, 118단계.

응용

  1. 규칙을 \(3n - 1\)로 바꾸면 1에 닿지 않는 시작값이 있음을 실험으로 보여라.
    답

    5 → 14 → 7 → 20 → 10 → 5로 순환한다. 이미 나온 값을 집합에 저장해 순환을 감지하면 된다.

심화

  1. \(n = 4k + 1\) (\(k \ge 1\))이면 \(n\)의 세 단계 뒤가 \(3k + 1\)임을 보이고 그 의미를 말하여라.
    답

    \(4k + 1 \to 12k + 4 \to 6k + 2 \to 3k + 1\). 세 단계 만에 처음보다 작아지므로, \(4k + 1\) 꼴은 "더 작은 수로 내려온다"는 것이 증명된다. 이런 경우를 늘려 가는 것이 실제 연구에서 확인 범위를 넓히는 방법이다.
