클래스로 수학 대상 만들기

본문

파이썬에서 \(\frac13 + \frac16\)을 계산하면 0.5에 가까운 소수가 나온다. 분수를 분수 그대로, 다항식을 다항식 그대로 더하고 곱하게 하려면 무엇이 필요할까?

먼저 알아야 할 것함수 정의와 리스트(1.3절, 1.4절), 최대공약수(정수론)를 쓴다.

1.5.1클래스와 객체

지금까지는 정수, 실수, 리스트처럼 파이썬에 이미 있는 자료형만 썼다. 분수를 나타내려면 분자와 분모 두 값을 한 묶음으로 다뤄야 한다. 그러면 새 자료형을 정의하는 것이 자연스럽다. 클래스는 "이 자료형의 값은 어떤 정보를 갖고, 어떤 연산을 할 수 있는가"를 적은 설계도이다.

from math import gcd

class Frac:
    def __init__(self, p, q=1):
        if q == 0:
            raise ZeroDivisionError("분모가 0")
        g = gcd(p, q) * (1 if q > 0 else -1)
        self.p, self.q = p // g, q // g

    def __add__(self, other):
        return Frac(self.p * other.q + other.p * self.q, self.q * other.q)

    def __mul__(self, other):
        return Frac(self.p * other.p, self.q * other.q)

    def __repr__(self):
        return f"{self.p}/{self.q}"

print(Frac(1, 3) + Frac(1, 6))   # 1/2

__init__은 객체를 만들 때 불리는 메서드이다. 여기서 분자와 분모를 최대공약수로 나누고 분모가 양수가 되게 정리해 두므로, 같은 수는 언제나 같은 모양으로 저장된다. 따라서 두 분수가 같은지 비교할 때 분자와 분모만 보면 된다. self는 지금 다루는 객체 자신을 가리킨다.

1.5.2연산자 겹쳐 쓰기

그림 1처럼 a + b를 쓰면 파이썬은 a.__add__(b)를 부른다. 그래서 __add__와 __mul__만 정의하면 분수끼리 +, *를 수식처럼 쓸 수 있다. __repr__은 출력할 때의 모양을 정한다. 이렇게 하면 다음 계산이 소수 오차 없이 정확하게 나온다.

예제 1.5.1

\(\sum_{k=1}^{n}\frac{1}{k(k+1)}\)을 Frac으로 \(n = 10\)까지 계산하고, 결과가 \(\frac{n}{n+1}\)인지 확인하여라.

s = Frac(0)
for k in range(1, 11):
    s = s + Frac(1, k * (k + 1))
print(s)                          # 10/11

풀이. 출력은 10/11이다. 부분분수 \(\frac{1}{k(k+1)} = \frac1k - \frac1{k+1}\)로 망원급수를 만들면 \(1 - \frac{1}{11}\)이 되므로 맞는다. 실수로 계산했다면 0.9090909090909091처럼 근삿값이 나와 \(\frac{10}{11}\)인지 바로 알기 어렵다.

1.5.3다항식 클래스로 넓히기

같은 생각으로 다항식도 만들 수 있다. 계수 리스트 [a0, a1, a2]를 저장하고 __add__는 계수끼리 더하기, __mul__은 합성곱 \(c_n = \sum_ka_kb_{n-k}\)로 정하면 된다. 여기에 __call__을 정의하면 p(2)처럼 값을 넣어 계산할 수도 있다. 계수로 Frac을 넣으면 유리계수 다항식이 되어 나눗셈까지 정확하게 할 수 있다.

마무리

클래스는 값이 가진 정보와 할 수 있는 연산을 함께 적은 설계도이고, 객체는 그것으로 만든 값이다. __init__에서 값을 표준 모양으로 정리하고 __add__, __mul__을 정의하면 분수와 다항식을 수식 그대로 정확하게 계산할 수 있다.

1.5.4연습문제

기본

  1. Frac에 뺄셈 __sub__와 같음 비교 __eq__를 더하여라.
    답

    __sub__은 Frac(self.p*other.q - other.p*self.q, self.q*other.q). 표준 모양으로 저장하므로 __eq__는 분자와 분모가 각각 같은지 비교한다.

응용

  1. 계수 리스트를 저장하는 Poly 클래스에 곱셈을 구현하고 \((1 + x)^5\)의 계수를 구하여라.
    답

    합성곱으로 곱하면 [1, 5, 10, 10, 5, 1]로 이항계수가 나온다.
