경사하강법의 O(1/k) 수렴 증명

증명 · 하강 보조정리와 망원급수
정리

\(f:\mathbb R^n \to \mathbb R\)가 볼록이고 \(L\)-매끄러우며 최솟점 \(\mathbf x^*\)를 가질 때, \(\mathbf x_{k+1} = \mathbf x_k - \frac1L\nabla f(\mathbf x_k)\)이면 \(f(\mathbf x_k) - f(\mathbf x^*) \le \frac{L\|\mathbf x_0 - \mathbf x^*\|^2}{2k}\).

쓰는 것

  • 하강 보조정리: \(L\)-매끄러우면 \(f(\mathbf y) \le f(\mathbf x) + \nabla f(\mathbf x)\cdot(\mathbf y - \mathbf x) + \frac L2\|\mathbf y - \mathbf x\|^2\). (\(g(t) = f(\mathbf x + t(\mathbf y - \mathbf x))\)에 미적분의 기본정리와 코시-슈바르츠를 쓰면 나온다.)
  • 볼록성의 1차 조건: \(f(\mathbf y) \ge f(\mathbf x) + \nabla f(\mathbf x)\cdot(\mathbf y - \mathbf x)\) (5.2절).
  • 항등식 \(2\mathbf a\cdot\mathbf b - \|\mathbf b\|^2 = \|\mathbf a\|^2 - \|\mathbf a - \mathbf b\|^2\).

아이디어

한 걸음의 진전을 "최솟점까지 거리의 제곱이 얼마나 줄었나"로 나타내면, 그 합이 망원급수가 되어 \(\|\mathbf x_0 - \mathbf x^*\|^2\)로 묶인다. 함수값이 매 단계 줄어든다는 사실로 합을 마지막 항으로 바꾼다.

증명

  1. \(\mathbf g = \nabla f(\mathbf x_k)\)라 하자. 하강 보조정리에 \(\mathbf y = \mathbf x_{k+1} = \mathbf x_k - \mathbf g/L\)을 넣으면 \(f(\mathbf x_{k+1}) \le f(\mathbf x_k) - \frac1L\|\mathbf g\|^2 + \frac1{2L}\|\mathbf g\|^2 = f(\mathbf x_k) - \frac1{2L}\|\mathbf g\|^2\).
    특히 \(f(\mathbf x_k)\)는 감소수열이다.
  2. 1차 조건에서 \(\mathbf x = \mathbf x_k\), \(\mathbf y = \mathbf x^*\)로 두면 \(f(\mathbf x_k) \le f(\mathbf x^*) + \mathbf g\cdot(\mathbf x_k - \mathbf x^*)\).
    볼록성이 쓰이는 유일한 곳.
  3. 두 식을 합치면 \(f(\mathbf x_{k+1}) - f(\mathbf x^*) \le \mathbf g\cdot(\mathbf x_k - \mathbf x^*) - \frac1{2L}\|\mathbf g\|^2 = \frac L2\left(2\,\tfrac{\mathbf g}L\cdot(\mathbf x_k - \mathbf x^*) - \|\tfrac{\mathbf g}L\|^2\right)\).
    \(\frac L2\)을 묶어 낸다.
  4. 항등식에 \(\mathbf a = \mathbf x_k - \mathbf x^*\), \(\mathbf b = \mathbf g/L\)을 넣으면 \(\mathbf a - \mathbf b = \mathbf x_{k+1} - \mathbf x^*\)이므로 \(f(\mathbf x_{k+1}) - f(\mathbf x^*) \le \frac L2\left(\|\mathbf x_k - \mathbf x^*\|^2 - \|\mathbf x_{k+1} - \mathbf x^*\|^2\right)\).
    한 걸음의 진전 = 거리 제곱의 감소.
  5. \(i = 0, \dots, k - 1\)에 대해 더하면 우변이 망원급수가 되어 \(\sum_{i=1}^{k}(f(\mathbf x_i) - f(\mathbf x^*)) \le \frac L2(\|\mathbf x_0 - \mathbf x^*\|^2 - \|\mathbf x_k - \mathbf x^*\|^2) \le \frac L2\|\mathbf x_0 - \mathbf x^*\|^2\).
    가운데 항이 모두 상쇄된다.
  6. 1단계에서 \(f(\mathbf x_i)\)가 감소하므로 좌변 \(\ge k(f(\mathbf x_k) - f(\mathbf x^*))\). 따라서 \(f(\mathbf x_k) - f(\mathbf x^*) \le \frac{L\|\mathbf x_0 - \mathbf x^*\|^2}{2k}\).
    합의 각 항은 마지막 항 이상이다.

되짚기

  • 4단계의 부산물: 좌변이 0 이상이므로 \(\|\mathbf x_{k+1} - \mathbf x^*\| \le \|\mathbf x_k - \mathbf x^*\|\). 볼록 함수에서는 최솟점과의 거리가 늘지 않는다.
  • 학습률이 \(1/L\)보다 크면: 1단계에서 \(f\)가 준다는 보장이 깨진다. \(\eta \le 1/L\)이면 같은 논리로 \(\frac{\|\mathbf x_0 - \mathbf x^*\|^2}{2\eta k}\)가 상한이다.
  • 볼록이 아니면: 2단계를 쓸 수 없어 함수값 대신 기울기 크기만 0으로 감을 보일 수 있습니다(1단계를 더하면 \(\sum\|\nabla f(\mathbf x_i)\|^2 \le 2L(f(\mathbf x_0) - f_{\inf})\)).

직접 써 보기

\(f(x) = \frac12x^2\) (\(L = 1\)), \(\eta = 1\)이면 정리의 상한은 무엇이고 실제 오차는 얼마인가? 상한이 느슨한 이유는?

힌트

\(x_1 = x_0 - x_0\).

답안

상한은 \(\frac{x_0^2}{2k}\)이지만 \(x_1 = 0\)이라 실제 오차는 \(k \ge 1\)에서 0이다. 정리는 모든 볼록·\(L\)-매끄러운 함수에 통하는 최악의 경우 상한이라, 곡률이 고른(강볼록) 함수에서는 훨씬 빠를 수 있다. ∎
