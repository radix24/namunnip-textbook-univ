SymPy로 미적분 결과 검증하기

본문

\(\int x^2e^x\,dx\)를 손으로 계산해 답을 얻었다. 컴퓨터로 이 답이 맞는지 확인하려면 어떻게 해야 할까? 부동소수점 대신 \(\frac13\)이나 \(\sqrt2\)를 정확히 다루는 계산이 있다면, 그것만 믿으면 될까?

먼저 알아야 할 것미분과 적분, 테일러 다항식, 파이썬 함수(1.1절)를 쓴다.

4.1.1기호와 식

수 대신 문자와 식을 그대로 다루어 분수, \(\sqrt2\), \(\pi\) 같은 정확한 결과를 내는 계산을 기호 계산이라 한다. 반면 부동소수점 수로 근사값을 내는 계산을 수치 계산이라 하며, 빠르지만 반올림 오차가 따른다. SymPy는 파이썬으로 쓴 기호 계산 라이브러리이며(pip install sympy), 먼저 문자를 기호로 선언해야 한다.

import sympy as sp
x = sp.symbols('x')
expr = (x + 1)**3
print(sp.expand(expr))          # x**3 + 3*x**2 + 3*x + 1
print(sp.factor(x**2 - 5*x + 6))  # (x - 3)*(x - 2)
print(sp.simplify(sp.sin(x)**2 + sp.cos(x)**2))   # 1
print(sp.Rational(1, 3) + sp.Rational(1, 6))      # 1/2
print(1/3 + 1/6)                 # 0.5 (부동소수점)

파이썬의 1/3은 이미 부동소수점 수 0.333…이므로, 정확한 분수가 필요하면 sp.Rational(1, 3)을 쓴다. sp.pi, sp.E, sp.oo(무한대)는 정확한 상수이며, .evalf()나 sp.N(expr, 30)으로 원하는 자릿수의 근사값을 얻는다.

4.1.2미분과 적분

print(sp.diff(x**2 * sp.sin(x), x))     # x**2*cos(x) + 2*x*sin(x)
print(sp.diff(sp.exp(x**2), x, 2))      # 2차 도함수
print(sp.integrate(x * sp.exp(x), x))   # (x - 1)*exp(x)
print(sp.integrate(sp.exp(-x**2), (x, 0, sp.oo)))   # sqrt(pi)/2

부정적분에는 적분상수 \(C\)가 붙지 않고, 정적분은 (x, a, b) 꼴로 구간을 준다. 마지막 결과 \(\frac{\sqrt\pi}2 \approx 0.886227\)은 가우스 적분으로, 손으로는 극좌표 변환이 필요한 결과를 한 줄로 확인할 수 있다.

그러나 모든 적분이 닫힌 꼴로 나오지는 않는다. \(\int e^{-x^2}\,dx\)는 오차함수 erf로, \(\int \frac{\sin x}x\,dx\)는 Si로 답한다. 기본 함수로 표현할 수 없으면 계산하지 못한 적분 Integral(...)을 그대로 돌려주며, 이때는 수치 적분으로 넘어간다.

4.1.3극한, 방정식, 급수

n = sp.symbols('n', positive=True)
print(sp.limit(sp.sin(x)/x, x, 0))            # 1
print(sp.limit((1 + 1/n)**n, n, sp.oo))       # E
print(sp.solve(x**3 - 6*x**2 + 11*x - 6, x))  # [1, 2, 3]
print(sp.series(sp.exp(x), x, 0, 5))          # 1 + x + x**2/2 + x**3/6 + x**4/24 + O(x**5)
f = sp.Function('f')
print(sp.dsolve(f(x).diff(x, 2) + f(x), f(x)))   # Eq(f(x), C1*sin(x) + C2*cos(x))

2.2절에서 \((1 + 1/n)^n\)의 값을 표로 만들어 \(e\)에 다가가는 것을 관찰했는데, limit은 그 극한을 정확히 \(e\)(E)로 돌려준다. 또 테일러 전개 series의 O(x**5)는 버린 고차항을 나타낸다.

4.1.4두 방향으로 검증하기

처음 질문처럼 손으로 \(\int x^2e^x\,dx = (x^2 - 2x + 2)e^x + C\)를 얻었다고 하자. 검증 방법은 두 가지이다. 기호적으로는 답을 미분해서 피적분함수와의 차를 simplify하면 0이 나와야 한다. 곧 sp.simplify(sp.diff(F, x) - x**2*sp.exp(x))가 0이다. 수치적으로는 sp.lambdify(x, F)로 파이썬 함수를 만들어 여러 점에서 값을 비교하거나, 정적분 \(F(1) - F(0) = e - 2 \approx 0.718282\)를 심프슨 공식 같은 수치 적분과 비교한다.

기호적 검증은 정확하지만 simplify가 0을 알아보지 못하는 경우가 있으며, 결과가 0으로 나오지 않았다고 답이 틀린 것은 아니다. 수치적 검증은 언제나 할 수 있지만 몇 점에서의 확인일 뿐이고 반올림 오차의 영향을 받는다. 예를 들어 도함수를 차분으로 확인할 때 \(h\)를 너무 작게 잡으면 그림 1처럼 오차가 오히려 커진다. 그래서 두 방향을 함께 쓴다.

한편 기호에는 가정이 중요하다. sp.sqrt(x**2)는 x로 줄어들지 않는데, \(x\)가 음수이면 \(\sqrt{x^2} = -x\)이기 때문이다. x = sp.symbols('x', positive=True)처럼 가정을 주면 x로 줄어든다. 마찬가지로 \(\int_0^\infty e^{-ax}\,dx\)는 \(a\)의 부호를 모르면 조건부 결과(Piecewise)를 돌려준다.

흔한 오해기호를 선언하지 않고 x를 써서 NameError가 나거나, 전에 수로 쓰던 x가 남아 있는 실수가 흔하다. 또 1/2*x를 정확한 분수로 여기기 쉽지만 실제로는 0.5이다. sp.sin 대신 math.sin을 기호에 적용하면 TypeError가 난다. 끝으로 simplify가 0을 내지 못했다고 답이 틀렸다고 단정해서는 안 된다.
마무리

처음 질문에 답하면, 손으로 구한 적분은 기호적 검증(미분해서 차가 0인지)과 수치적 검증(lambdify와 수치 적분) 두 방향으로 확인한다. 기호 계산은 정확하지만 simplify가 놓치는 경우가 있고, 수치 계산은 늘 가능하지만 반올림 오차가 있어 어느 하나만 믿을 수는 없다. SymPy에서는 sp.symbols로 기호를 선언하고 diff, integrate, limit, solve, series, dsolve를 쓰며, positive=True 같은 가정이 결과를 바꾼다.

4.1.5연습문제

기본

  1. \(\int_0^\pi x\sin x\,dx\)를 SymPy로 구하고 손 계산(부분적분)과 비교하여라.
    답

    sp.integrate(x*sp.sin(x), (x, 0, sp.pi)) → pi. (손으로) \([-x\cos x + \sin x]_0^\pi = \pi\).

응용

  1. \(\lim_{x\to0}\frac{\sin x - x}{x^3}\)을 limit과 series로 각각 구하여라.
    답

    \(-\frac16\). series(sin(x), x, 0, 5) = \(x - \frac{x^3}6 + O(x^5)\)이므로 \(\frac{\sin x - x}{x^3} = -\frac16 + O(x^2)\).

심화

  1. sp.solve(x**5 - x - 1, x)는 무엇을 돌려주는가? 실근의 근사값은 어떻게 구하는가?
    답

    5차 방정식은 일반적으로 근호로 풀 수 없으므로(갈루아 이론) CRootOf 객체를 돌려준다. sp.nsolve(x**5 - x - 1, x, 1)이나 .evalf()로 실근 약 1.1673을 얻는다.
