최소제곱으로 다항식 맞추기

본문

측정값 6개를 그래프에 찍었더니 대략 직선을 이룬다. 직선, 이차곡선, 삼차곡선을 맞춰 볼 수 있는데, 5차 다항식을 쓰면 모든 점을 정확히 지나게 할 수도 있다. 그렇다면 차수가 높을수록 좋은 모형일까?

먼저 알아야 할 것NumPy 배열과 연립방정식(3.1절), 최소제곱(선형대수(1) 7단원)을 쓴다.

3.2.1계획행렬

점 \((x_i, y_i)\)에 \(p(x) = c_0 + c_1x + \cdots + c_dx^d\)를 맞추는 것은 \(\|A\mathbf c - \mathbf y\|\)를 최소로 하는 문제이다. 여기서 \(A\)의 \(i\)행은 \((1, x_i, x_i^2, \dots, x_i^d)\)이고, 이 행렬을 계획행렬이라 한다. 문제가 계수에 대해 일차이므로 다항식이 \(x\)에 대해 비선형이어도 선형 최소제곱이다.

import numpy as np
x = np.array([0, 1, 2, 3, 4, 5], dtype=float)
y = np.array([1.0, 1.8, 3.3, 4.5, 6.3, 7.4])

c1 = np.polyfit(x, y, 1)      # 높은 차수부터: [기울기, 절편]
print(c1)                      # 약 [1.3343 0.7143]
c2 = np.polyfit(x, y, 2)
print(c2)                      # 약 [0.0482 1.0932 0.875 ]

A = np.vander(x, 3, increasing=True)          # 열: 1, x, x^2
c, res, rank, sv = np.linalg.lstsq(A, y, rcond=None)
print(c)                       # 약 [0.875  1.0932 0.0482] (낮은 차수부터)
print(res)                     # 잔차 제곱합 약 [0.1726]

polyfit은 계수를 높은 차수부터 돌려주고, lstsq는 계획행렬의 열 순서대로 돌려준다. 직선의 잔차 제곱합은 약 0.2594이고 2차는 0.1726이다. 다항식의 값은 np.polyval(c2, 6)처럼 계산한다. 또 lstsq는 내부적으로 특이값 분해(선형대수(2) 4.3절)를 써서 수치적으로 안정하다.

3.2.2차수를 올리면

점이 6개이면 5차 다항식은 모든 점을 정확히 지나 잔차가 0이다. 그러나 그림 1처럼 점 사이에서 출렁이고, 자료 범위 밖에서는 터무니없는 값을 낸다. 실제로 이 5차 다항식은 \(x = 5.5\)에서 5.7로, 마지막 점 7.4보다 오히려 작아진다. 즉 잔차가 작다고 좋은 모형이 아니다. 자료의 잡음까지 외워 버린 이런 상태를 과적합이라 하며, 6.3절에서 검증 오차로 진단한다.

또 차수가 높으면 계획행렬의 열 \(1, x, x^2, \dots\)이 거의 평행해져 조건수가 커진다(선형대수(2) 7.2절). 그래서 고차 다항식은 통계적으로도, 수치적으로도 조심해서 써야 한다.

흔한 오해polyfit의 계수 순서가 높은 차수부터라는 것을 잊기 쉽다. 또 정규방정식 \(A^TA\mathbf c = A^T\mathbf y\)를 inv로 풀면 고차에서 정확도를 잃는다. 잔차 0을 "완벽한 모형"으로 여기는 것도 흔한 오해이다.
마무리

처음 질문의 답은 "아니다"이다. 차수를 올리면 잔차는 줄지만, 5차 다항식처럼 자료의 잡음까지 따라가 범위 밖에서 엉뚱한 값을 내는 과적합이 생기고 계획행렬의 조건수도 나빠진다. 다항식 맞춤은 계획행렬 \((x_i^k)\)에 대한 선형 최소제곱이며, np.polyfit(높은 차수부터)이나 특이값 분해를 쓰는 np.linalg.lstsq로 푼다.

3.2.3연습문제

기본

  1. 위 자료에서 직선 모형으로 \(x = 6\)일 때의 예측값은?
    답

    \(0.7143 + 1.3343\cdot6 \approx 8.72\).

응용

  1. \(y = ae^{bx}\) 꼴을 맞추려면 어떻게 선형 최소제곱으로 바꾸는가?
    답

    로그를 취하면 \(\ln y = \ln a + bx\)이므로 np.polyfit(x, np.log(y), 1)로 \(b\)와 \(\ln a\)를 구한다(다만 원래 척도에서의 오차 최소화와는 조금 다르다).

심화

  1. 점이 \(n\)개이고 서로 다른 \(x\)에서 \(n - 1\)차 다항식을 맞추면 잔차가 0인 이유를 선형대수로 설명하여라.
    답

    계획행렬이 \(n\times n\) 방데르몽드 행렬이고 \(x_i\)가 서로 다르면 가역(행렬식 \(\prod_{i<j}(x_j - x_i) \ne 0\))이라 \(A\mathbf c = \mathbf y\)가 정확한 해를 가진다(수학1 4.2절의 라그랑주 보간).
