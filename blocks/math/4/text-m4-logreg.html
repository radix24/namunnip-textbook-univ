로지스틱 회귀로 이진 분류하기

본문

공부 시간으로 시험 합격 여부를 예측하고 싶다. 정답이 0(불합격)이나 1(합격)뿐이라 직선을 그대로 쓰면 예측값이 1보다 크거나 0보다 작아진다. 예측을 "합격할 확률"로 내놓는 모형은 어떻게 만들고, 그 모형을 무엇으로 학습할까?

먼저 알아야 할 것선형회귀와 경사하강법(6.1절), 볼록 함수(5.2절), 지수함수와 로그를 쓴다.

6.2.1점수를 확률로

정답이 0 또는 1이면 직선 \(wx + b\)의 값을 그대로 쓸 수 없다. 값이 0과 1 사이에 있지 않기 때문이다. 그래서 실수 전체를 \((0, 1)\)로 보내는 증가함수 \(\sigma(t) = \frac1{1 + e^{-t}}\)를 쓰며, 이것을 시그모이드 함수라 한다. 이 함수는 \(\sigma(0) = \frac12\), \(\sigma(-t) = 1 - \sigma(t)\), \(\sigma'(t) = \sigma(t)(1 - \sigma(t))\)를 만족한다.

\(P(y = 1\mid\mathbf x) = \sigma(\mathbf w\cdot\mathbf x + b)\)로 두는 분류 모형을 로지스틱 회귀라 한다. 예측 확률이 \(\frac12\)인 점들, 곧 \(\mathbf w\cdot\mathbf x + b = 0\)인 초평면을 결정 경계라 하며, 그 한쪽을 1, 다른 쪽을 0으로 분류한다. 또 \(\mathbf w\cdot\mathbf x + b = \ln\frac{p}{1 - p}\)이므로 선형 점수는 확률의 로그 오즈이고, \(w\)가 1 늘면 오즈가 \(e^w\)배가 된다.

6.2.2교차 엔트로피 손실

\(p_i = \sigma(\mathbf w\cdot\mathbf x_i + b)\)이면 관측 \(y_i\)의 확률은 \(p_i^{y_i}(1 - p_i)^{1 - y_i}\)이다. 자료 전체의 가능도를 최대로 하는 것은 그 로그에 음수를 붙인 평균, 곧 교차 엔트로피 손실 \(J(\mathbf w, b) = -\frac1n\sum_{i=1}^n\left[y_i\ln p_i + (1 - y_i)\ln(1 - p_i)\right]\)을 최소로 하는 것과 같다.

정리 6.2.1 (로지스틱 손실의 기울기)

\(\nabla_{\mathbf w}J = \frac1n\sum(p_i - y_i)\mathbf x_i\), \(\frac{\partial J}{\partial b} = \frac1n\sum(p_i - y_i)\)이다. 또 \(J\)는 \((\mathbf w, b)\)의 볼록 함수이다.

증명.\(t = \mathbf w\cdot\mathbf x + b\)일 때 한 점의 손실 \(\ell = -y\ln\sigma(t) - (1 - y)\ln(1 - \sigma(t))\)를 \(t\)로 미분하면, \(\sigma' = \sigma(1 - \sigma)\)에서 \(\frac{d\ell}{dt} = -y(1 - \sigma) + (1 - y)\sigma = \sigma - y\)이다. 연쇄법칙으로 \(\nabla_{\mathbf w}\ell = (\sigma - y)\mathbf x\), \(\partial\ell/\partial b = \sigma - y\)이다. 다시 미분하면 \(\frac{d^2\ell}{dt^2} = \sigma(1 - \sigma) \ge 0\)이므로 헤세 행렬 \(\sigma(1 - \sigma)(\mathbf x, 1)(\mathbf x, 1)^T\)는 양의 준정치이고, 그 평균도 마찬가지이다. ∎

기울기의 꼴 "(예측 − 정답) × 입력"은 선형회귀의 \(\frac2n\sum e_i\mathbf x_i\)와 같은 모양이다. 그러나 \(p_i\)가 매개변수에 대해 비선형이라 정규방정식 같은 닫힌 해는 없고, 반복법으로 풀어야 한다. 다행히 볼록이므로 국소 최솟점에 빠질 걱정은 없다.

6.2.3공부 시간과 합격의 예

8명의 공부 시간 \(x = 1, \dots, 8\)과 합격 여부 \(y = 0, 0, 0, 1, 0, 1, 1, 1\)에 모형을 맞춘다.

import numpy as np
x = np.arange(1, 9, dtype=float)
y = np.array([0, 0, 0, 1, 0, 1, 1, 1], dtype=float)
sig = lambda t: 1 / (1 + np.exp(-t))

w, b, eta = 0.0, 0.0, 0.1
for k in range(20000):
    p = sig(w * x + b)
    w -= eta * np.mean((p - y) * x)
    b -= eta * np.mean(p - y)
print(w, b)          # 약 1.2823, -5.7703
print(-b / w)        # 결정 경계 x = 4.5
print(sig(w * 6 + b))   # 6시간이면 합격 확률 약 0.873

첫 걸음에서는 \(p_i = \frac12\)이므로 기울기가 \(w\)에 대해 \(\frac18\sum(\frac12 - y_i)x_i = -0.875\), \(b\)에 대해 \(\frac18\sum(\frac12 - y_i) = 0\)이고, \(w\)가 0.0875로 커진다. 최종 모형의 결정 경계는 \(x = 4.5\)이다. 이 자료가 합격·불합격을 바꾸고 \(x \to 9 - x\)로 보내는 대칭을 가지므로 정확히 그 값이 나온다. 손실은 약 0.3129이고, 0.5를 기준으로 분류하면 그림 1처럼 \(x = 4\)(합격인데 불합격 예측)와 \(x = 5\)(그 반대)를 틀려 정확도는 6/8이다.

이 경사하강법은 \(10^4\)번쯤 돌아야 소수 넷째 자리까지 맞으며, 1000번 뒤에는 \(w \approx 0.997\)이다. 6.1절처럼 \(x\)를 표준화하면 훨씬 빨라지고, 실무 라이브러리는 헤세 행렬을 쓰는 뉴턴 방법 계열로 수십 번 안에 푼다.

6.2.4결과 해석

정확도는 맞게 분류한 비율이다. 그러나 환자가 1%뿐인 경우처럼 부류의 크기가 매우 다르면 모두 정상이라 해도 정확도가 99%이므로, 부류별로 맞힌 비율인 재현율 등을 함께 본다. 또 문턱값 0.5는 바꿀 수 있다. 질병 진단처럼 놓치면 위험한 경우에는 문턱을 낮춰 양성을 더 많이 잡는다. 끝으로 두 부류를 완벽히 가르는 경계가 있는 완전 분리의 경우에는 손실의 최솟점이 없어 \(\|\mathbf w\|\)가 끝없이 커진다. 이때는 정칙화 항 \(\lambda\|\mathbf w\|^2\)을 더하면 해결된다.

흔한 오해MSE를 손실로 쓰면 볼록성을 잃는다. 또 \(\ln 0\)이 나와 nan이 되기 쉬운데, \(p\)를 \([10^{-15}, 1 - 10^{-15}]\)로 자르거나 \(\ln\sigma(t) = -\ln(1 + e^{-t})\)로 안정적으로 계산한다. 예측 확률 0.99를 "99% 확실"로 읽는 것도 조심해야 한다. 그것은 모형이 맞다는 가정 아래의 값이다.

처음 질문에 답하면, 선형 점수를 시그모이드에 넣어 \(P(y = 1\mid\mathbf x) = \sigma(\mathbf w\cdot\mathbf x + b)\)로 확률을 내놓는 로지스틱 회귀를 쓰고, 최대가능도에서 나온 교차 엔트로피 손실로 학습한다. 기울기는 \(\frac1n\sum(p_i - y_i)(\mathbf x_i, 1)\)이고 손실이 볼록이지만 닫힌 해가 없으므로 경사하강법이나 뉴턴 방법으로 푼다. 결정 경계는 \(\mathbf w\cdot\mathbf x + b = 0\)이며, 결과는 정확도만이 아니라 부류별 성능, 문턱값, 분리 가능성과 함께 해석한다.

6.2.5연습문제

기본

  1. 위 모형에서 3시간 공부한 학생의 합격 확률을 구하여라.
    답

    \(\sigma(1.2823\cdot3 - 5.7703) = \sigma(-1.9234) \approx 0.127\).

응용

  1. \(\sigma'(t) = \sigma(t)(1 - \sigma(t))\)를 증명하여라.
    답

    \(\sigma = (1 + e^{-t})^{-1}\)에서 \(\sigma' = \frac{e^{-t}}{(1 + e^{-t})^2} = \frac1{1 + e^{-t}}\cdot\frac{e^{-t}}{1 + e^{-t}} = \sigma(1 - \sigma)\).

심화

  1. 자료가 완전히 분리될 때(모든 \(y_i = 1\)인 점에서 \(\mathbf w_0\cdot\mathbf x_i + b_0 > 0\), \(y_i = 0\)인 점에서 \(< 0\)) 손실의 하한이 0이지만 도달되지 않음을 보여라.
    답

    \((c\mathbf w_0, cb_0)\)에서 \(c \to \infty\)이면 모든 \(p_i\)가 정답(1 또는 0)으로 가서 손실 \(\to 0\). 그러나 유한한 \((\mathbf w, b)\)에서는 \(0 < p_i < 1\)이라 손실 \(> 0\)이다. 따라서 하한 0에 도달하는 최솟점이 없다.
