날씨 모형의 장기 분포를 NumPy로

예제 · 고유벡터와 연립방정식으로 정상분포

먼저 예측

맑음→맑음 0.9, 흐림→흐림 0.8, 비→비 0.5인 날씨 모형에서 아주 오랜 뒤 맑은 날의 비율은 50%, 60%, 80% 중 어디에 가까울까?

예측 확인

약 62.5%입니다. 맑음이 잘 지속되고 다른 상태에서도 맑음으로 잘 넘어오기 때문입니다.

전이행렬 \(P = \begin{pmatrix}0.9 & 0.075 & 0.025\\0.15 & 0.8 & 0.05\\0.25 & 0.25 & 0.5\end{pmatrix}\) (행: 오늘 맑음/흐림/비, 열: 내일)의 정상분포 \(\pi\) (\(\pi P = \pi\), 합 1)를 NumPy로 두 가지 방법으로 구하여라.

전략

\(\pi P = \pi\)를 전치하면 \(P^T\pi^T = \pi^T\): \(P^T\)의 고유값 1의 고유벡터입니다. 또는 \((P^T - I)\pi^T = 0\)의 한 줄을 "합 = 1"로 바꿔 solve로 풉니다(3.1절).

풀이

  1. P = np.array([[.9, .075, .025], [.15, .8, .05], [.25, .25, .5]])
    각 행의 합이 1인지 P.sum(axis=1)로 확인.
  2. 방법 1: w, V = np.linalg.eig(P.T), i = np.argmin(abs(w - 1)), pi = V[:, i] / V[:, i].sum() → 약 [0.625 0.3125 0.0625].
    고유벡터는 크기와 부호가 임의라 합이 1이 되게 나눈다. eig는 복소 배열을 줄 수 있어 .real을 취한다.
  3. 방법 2: A = P.T - np.eye(3); A[2] = 1; pi = np.linalg.solve(A, [0, 0, 1]) → 같은 값.
    \((P^T - I)\)는 특이(계수 2)라 한 줄을 정규화 조건으로 바꿔 가역으로 만든다.
  4. \(\pi = (0.625, 0.3125, 0.0625) = (\frac58, \frac5{16}, \frac1{16})\).
    분수로 검산하면 \(\pi P = \pi\)가 정확히 성립한다.

검산

np.allclose(pi @ P, pi)가 True. 또 아무 분포에서 시작해 x = x @ P를 50번 반복해도 같은 값에 다가갑니다(거듭제곱법, 수학8 7.3절). 첫째 성분 검산: \(0.625\cdot0.9 + 0.3125\cdot0.15 + 0.0625\cdot0.25 = 0.5625 + 0.046875 + 0.015625 = 0.625\).

의미

장기적으로 맑은 날 62.5%, 흐린 날 31.25%, 비 6.25%입니다. 같은 계산이 웹 페이지 순위(페이지랭크), 유전자 빈도의 평형 등에 쓰입니다. 큰 희소 행렬에서는 eig 대신 반복 곱(거듭제곱법)을 씁니다.

이해 확인

답

\(P^2\)의 (3, 1) 성분: \(0.25\cdot0.9 + 0.25\cdot0.15 + 0.5\cdot0.25 = 0.225 + 0.0375 + 0.125 = 0.3875\).
