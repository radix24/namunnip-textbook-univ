기호 계산 실습 문제

문제 6 · 실습·개념·판단 · 힌트 2단계

SymPy를 설치한 파이썬(pip install sympy)에서 import sympy as sp, x = sp.symbols('x')로 시작하세요. 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 실습\(\tan x\)의 도함수를 SymPy로 구하고, 교과서의 \(\sec^2 x\)와 같음을 확인하여라. [04-01]

    힌트 1

    sp.diff(sp.tan(x), x)(4.1절).

    힌트 2

    두 식의 차를 simplify한다.

    풀이

    출력은 tan(x)**2 + 1. sp.simplify(sp.tan(x)**2 + 1 - sp.sec(x)**2) → 0이므로 같다(\(1 + \tan^2x = \sec^2x\)). 겉모양이 다른 같은 식을 낼 수 있다.

  2. 실습\(\int_0^1 x\ln x\,dx\)를 구하여라. 피적분함수가 \(x = 0\)에서 정의되지 않는데 문제가 없는가? [04-01]

    힌트 1

    sp.integrate(x*sp.log(x), (x, 0, 1)).

    힌트 2

    \(\lim_{x\to0^+}x\ln x\)를 limit으로.

    풀이

    \(-\frac14\). 원시함수 \(\frac{x^2}2\ln x - \frac{x^2}4\)에서 \(x\to0^+\)일 때 \(x^2\ln x \to 0\)이므로 이상적분이 수렴한다. 중점 공식으로도 \(-0.25\)에 가깝다.

  3. 실습\(x^2 - 2x - 1 = 0\)을 solve로 풀고, 결과를 소수로 바꾸어라. [04-01]

    힌트 1

    근의 공식으로 미리 예상.

    힌트 2

    [r.evalf() for r in sols].

    풀이

    [1 - sqrt(2), 1 + sqrt(2)], 소수로 약 \(-0.414214\), \(2.414214\). SymPy는 정확한 근호 꼴로 준다.

  4. 개념sp.simplify(sp.sqrt(x**2))가 x가 아니라 sqrt(x**2)를 내는 이유와 해결법은? [04-01]

    힌트 1

    \(x = -3\)을 넣어 보라.

    힌트 2

    기호를 선언할 때의 가정.

    풀이

    \(\sqrt{(-3)^2} = 3 \ne -3\)이므로 일반적으로 \(\sqrt{x^2} = |x|\)이지 \(x\)가 아니다. x = sp.symbols('x', positive=True)로 선언하면 x로 줄어든다(실수 가정 real=True만 주면 Abs(x)).

  5. 실습\(\frac1{1 - x}\)의 \(x = 0\)에서의 테일러 전개를 4차까지 구하고, \(x = 0.1\)에서 전개(4차까지)의 값과 참값의 차를 구하여라. [04-01]

    힌트 1

    sp.series(1/(1 - x), x, 0, 5).

    힌트 2

    .removeO()로 \(O\) 항을 떼고 .subs(x, 0.1).

    풀이

    \(1 + x + x^2 + x^3 + x^4 + O(x^5)\). \(x = 0.1\)에서 1.1111, 참값 \(\frac1{0.9} = 1.1111\ldots\)과의 차는 \(\frac{0.1^5}{0.9} \approx 1.11\times10^{-5}\)(버린 등비급수의 합).

  6. 판단한 학생이 \(\frac{\sin t - t}{t^3}\)을 \(t = 10^{-8}\)에서 계산해 0을 얻고 "극한은 \(-\frac16\)이 아니라 0"이라고 했다. 옳은가? [04-01]

    힌트 1

    \(t = 10^{-2}, 10^{-4}, 10^{-6}, 10^{-7}\)에서도 계산해 보라.

    힌트 2

    \(\sin t\)와 \(t\)의 차는 \(t^3/6\) 정도인데, \(t\)에 비해 얼마나 작은가?

    풀이

    틀렸다. \(t = 10^{-2}, 10^{-4}\)에서는 \(-0.1666658\), \(-0.16666666\)으로 \(-\frac16\)에 다가가지만, \(10^{-6}\)에서 \(-0.166654\), \(10^{-7}\)에서 \(-0.172\)로 흔들리고 \(10^{-8}\)에서는 \(\sin t\)와 \(t\)가 부동소수점으로 같은 수가 되어 0이 된다. 자릿수 상쇄 때문이며, sp.limit은 정확히 -1/6을 준다.
