2점 경계치 문제의 유한차분법

본문

막대의 양 끝 온도를 정해 두면 그 사이의 정상 상태 온도는 어떻게 될까? 초깃값 문제처럼 한쪽 끝에서 출발해 차례로 나아가면 될까? 양 끝의 값이 주어진 미분방정식을 컴퓨터로 풀려면 무엇으로 바꿔야 하고, 그 계산은 얼마나 빠를까?

먼저 알아야 할 것2계 중심 차분(2.4절)과 가우스 소거(3.1절)를 쓴다.

7.1.1문제와 이산화

6장의 초깃값 문제와 달리, 양 끝의 값이 주어진 문제를 생각하자. 열원이 \(f\)인 막대의 정상 상태 온도나, 하중이 \(f\)인 줄의 처짐이 \(-u'' = f\), \(u(0) = \alpha\), \(u(1) = \beta\) 꼴이다. \([0, 1]\)을 \(n\)등분해 \(h = \frac1n\), \(x_i = ih\)로 두고 \(u_i \approx u(x_i)\)라 하자. \(u''(x_i) \approx \frac{u_{i-1} - 2u_i + u_{i+1}}{h^2}\)이므로 다음 연립방정식을 얻는다.

\[-u_{i-1} + 2u_i - u_{i+1} = h^2f(x_i), \qquad i = 1, \dots, n - 1\]

여기서 \(u_0 = \alpha\), \(u_n = \beta\)이다. 따라서 미지수가 \(n - 1\)개이고 행렬은 \(\operatorname{tridiag}(-1, 2, -1)\)이다. 사실 이 행렬은 대칭 양정치라 해가 하나뿐이다.

예제 7.1.1

\(f(x) = \pi^2\sin\pi x\), \(u(0) = u(1) = 0\)을 \(n = 4\)로 풀어 참값 \(u = \sin\pi x\)와 비교하여라.

풀이. \(h = 0.25\)이고 오른쪽 변은 0.4362, 0.6169, 0.4362이다. 대칭이라 \(u_1 = u_3\)이므로 두 식 \(2u_1 - u_2 = 0.4362\), \(-2u_1 + 2u_2 = 0.6169\)에서 \(u_1 = 0.7446\), \(u_2 = 1.0530\)이다. 참값 0.7071, 1과의 오차는 각각 0.038, 0.053이다.

7.1.2오차

2계 중심 차분의 절단 오차는 \(\frac{h^2}{12}u^{(4)}\)이다. 또 이 이산화는 행렬의 역의 노름이 \(h\)에 관계없이 유계라는 뜻에서 안정적이므로, 해의 오차도 \(O(h^2)\)이다. 예제 7.1.1에서 \(n = 4, 8, 16, 32\)이면 최대 오차가 0.053, 0.013, 0.0032, 0.0008로 매번 \(\frac14\)이 된다.

7.1.3토머스 알고리즘

삼중대각 행렬의 가우스 소거에서는 각 행에서 바로 아래 한 성분만 지우면 되므로 계산량이 \(O(n)\)이다. 이것을 토머스 알고리즘이라 한다.

def thomas(a, d, c, b):   # a: 아래, d: 대각, c: 위, b: 오른쪽
    n = len(d); cp = [0.0]*n; dp = [0.0]*n
    cp[0] = c[0]/d[0]; dp[0] = b[0]/d[0]
    for i in range(1, n):
        m = d[i] - a[i]*cp[i-1]
        cp[i] = c[i]/m; dp[i] = (b[i] - a[i]*dp[i-1])/m
    x = [0.0]*n; x[-1] = dp[-1]
    for i in range(n-2, -1, -1):
        x[i] = dp[i] - cp[i]*x[i+1]
    return x

한편 이 행렬은 대각 우세라서 피벗팅 없이도 안정적이다. 그래서 \(n = 10^6\)이어도 순식간에 풀린다.

흔한 오해경계치 문제를 초깃값 문제처럼 한쪽 끝에서 차례로 풀 수 있다고 여기기 쉽다. 그러나 한쪽 끝의 기울기를 모르므로 모든 점을 동시에 푸는 연립방정식이 되며, 기울기를 맞춰 가는 사격법은 또 다른 방법이다. 또 미지수가 \(n + 1\)개라고 생각하는 것도 틀렸다. 경계값은 알려져 있어 오른쪽 변으로 옮겨지므로 미지수는 \(n - 1\)개이다.
마무리

처음 질문에 답하면, 양 끝의 값이 주어진 문제는 한쪽 끝에서 차례로 풀 수 없고, 2계 도함수를 중심 차분으로 바꿔 모든 격자점을 동시에 푸는 연립방정식으로 바꿔야 한다. 그 행렬은 대칭 양정치인 삼중대각 행렬 \(\operatorname{tridiag}(-1, 2, -1)\)이고, 해의 오차는 \(O(h^2)\)이다. 토머스 알고리즘을 쓰면 \(O(n)\)의 계산으로 풀려, 백만 개의 격자점도 순식간에 계산된다.

7.1.4연습문제

기본

  1. \(-u'' = 2\), \(u(0) = u(1) = 0\)을 \(n = 2\)로 풀어 참값 \(u = x(1 - x)\)와 비교하여라.
    답

    \(2u_1 = \frac14\cdot2\), \(u_1 = 0.25 = u(0.5)\). 해가 2차식이라 \(u^{(4)} = 0\)으로 정확하다.

응용

  1. 경계값 \(u(0) = 1\), \(u(1) = 3\)이 주어지면 첫 식과 마지막 식의 오른쪽 변은 어떻게 바뀌는가?
    답

    \(i = 1\): \(2u_1 - u_2 = h^2f_1 + u_0 = h^2f_1 + 1\). \(i = n - 1\): \(-u_{n-2} + 2u_{n-1} = h^2f_{n-1} + 3\).

심화

  1. \(n = 4\)에서 \(u\)의 오차가 \(0.053\)이었다. \(10^{-6}\) 이하로 만들려면 \(n\)을 대략 얼마로 해야 하는가?
    답

    \(0.053\left(\frac4n\right)^2 \le 10^{-6}\)에서 \(n \ge 4\sqrt{5.3\times10^4} \approx 921\).
