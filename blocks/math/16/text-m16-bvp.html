2점 경계치 문제의 유한차분법

본문
이 절에서 배울 것
  • \(-u'' = f\), \(u(0) = \alpha\), \(u(1) = \beta\)를 격자점에서 2계 중심 차분으로 바꿔 삼중대각 연립방정식을 세운다.
  • 격자 간격 \(h\)에 대해 오차가 \(O(h^2)\)임을 실험으로 확인한다.
  • 토머스 알고리즘(삼중대각 소거)으로 \(O(n)\)에 풀고 구현한다.
먼저 알아야 할 것
  • 2계 중심 차분 (2.4절 연습 2), 가우스 소거 (3.1절).

7.1.1문제와 이산화

초깃값 문제(6장)와 달리 양 끝의 값이 주어진 문제입니다. 막대의 정상 상태 온도(열원 \(f\)), 줄의 처짐(하중 \(f\)) 등이 이 꼴입니다. \([0, 1]\)을 \(n\)등분해 \(x_i = ih\) (\(h = \frac1n\))로 두고 \(u_i \approx u(x_i)\)라 하면, \(u''(x_i) \approx \frac{u_{i-1} - 2u_i + u_{i+1}}{h^2}\)이므로

\[-u_{i-1} + 2u_i - u_{i+1} = h^2f(x_i), \qquad i = 1, \dots, n - 1,\]

\(u_0 = \alpha\), \(u_n = \beta\)입니다. 미지수 \(n - 1\)개의 연립방정식이고 행렬은 \(\operatorname{tridiag}(-1, 2, -1)\)입니다. 이 행렬은 대칭 양정치라 해가 하나뿐입니다.

예 7.1.1 \(f(x) = \pi^2\sin\pi x\), \(u(0) = u(1) = 0\)의 해는 \(u = \sin\pi x\)입니다. \(n = 4\) (\(h = 0.25\))이면 오른쪽 변은 \(0.4362, 0.6169, 0.4362\)이고, 대칭으로 \(u_1 = u_3\)이라 두 식 \(2u_1 - u_2 = 0.4362\), \(-2u_1 + 2u_2 = 0.6169\)에서 \(u_1 = 0.7446\), \(u_2 = 1.0530\)입니다. 참값 \(0.7071\), \(1\)과의 오차는 0.038, 0.053입니다.

7.1.2오차

2계 중심 차분의 절단 오차는 \(\frac{h^2}{12}u^{(4)}\)이고, 이 이산화는 안정적이라(행렬의 역의 노름이 \(h\)에 관계없이 유계) 해의 오차도 \(O(h^2)\)입니다. 예 7.1.1에서 \(n = 4, 8, 16, 32\)이면 최대 오차가 \(0.053, 0.013, 0.0032, 0.0008\)로 매번 \(\frac14\)이 됩니다.

7.1.3토머스 알고리즘

삼중대각 행렬의 가우스 소거는 각 행에서 바로 아래 한 성분만 지우면 되어 \(O(n)\)입니다.

def thomas(a, d, c, b):   # a: 아래, d: 대각, c: 위, b: 오른쪽
    n = len(d); cp = [0.0]*n; dp = [0.0]*n
    cp[0] = c[0]/d[0]; dp[0] = b[0]/d[0]
    for i in range(1, n):
        m = d[i] - a[i]*cp[i-1]
        cp[i] = c[i]/m; dp[i] = (b[i] - a[i]*dp[i-1])/m
    x = [0.0]*n; x[-1] = dp[-1]
    for i in range(n-2, -1, -1):
        x[i] = dp[i] - cp[i]*x[i+1]
    return x

대각 우세라 피벗팅 없이 안정적입니다. \(n = 10^6\)이어도 순식간에 풀립니다.

흔한 오해(1) 경계치 문제를 초깃값 문제처럼 한쪽 끝에서 차례로 풀 수 있다고 여긴다. 한쪽 끝의 기울기를 모르므로 모든 점을 동시에 푸는 연립방정식이 된다(사격법은 기울기를 맞춰 가는 다른 방법이다). (2) 미지수가 \(n + 1\)개라고 여긴다. 경계값은 알려져 있어 \(n - 1\)개이고, 경계값은 오른쪽 변으로 옮겨진다.
요약
  1. \(-u'' = f\)를 \(-u_{i-1} + 2u_i - u_{i+1} = h^2f_i\)로: 삼중대각 연립방정식.
  2. 오차 \(O(h^2)\): \(h\)를 절반으로 하면 \(\frac14\).
  3. 토머스 알고리즘으로 \(O(n)\).

7.1.4연습문제

기본

  1. \(-u'' = 2\), \(u(0) = u(1) = 0\)을 \(n = 2\)로 풀어 참값 \(u = x(1 - x)\)와 비교하여라.
    답

    \(2u_1 = \frac14\cdot2\), \(u_1 = 0.25 = u(0.5)\). 해가 2차식이라 \(u^{(4)} = 0\)으로 정확하다.

응용

  1. 경계값 \(u(0) = 1\), \(u(1) = 3\)이 주어지면 첫 식과 마지막 식의 오른쪽 변은 어떻게 바뀌는가?
    답

    \(i = 1\): \(2u_1 - u_2 = h^2f_1 + u_0 = h^2f_1 + 1\). \(i = n - 1\): \(-u_{n-2} + 2u_{n-1} = h^2f_{n-1} + 3\).

심화

  1. \(n = 4\)에서 \(u\)의 오차가 \(0.053\)이었다. \(10^{-6}\) 이하로 만들려면 \(n\)을 대략 얼마로 해야 하는가?
    답

    \(0.053\left(\frac4n\right)^2 \le 10^{-6}\)에서 \(n \ge 4\sqrt{5.3\times10^4} \approx 921\).
