오일러 방법과 룽게-쿠타 방법

본문

미분방정식 \(y' = f(t, y)\)는 대부분 공식으로 풀리지 않는다. 지금 위치의 기울기만 보고 한 걸음씩 나아가면 해를 따라갈 수 있을까? 오차를 줄이려면 걸음을 줄이는 수밖에 없을까, 아니면 한 걸음 안에서 기울기를 더 영리하게 쓸 수 있을까?

먼저 알아야 할 것미분방정식과 초깃값 문제(수학6), 테일러 정리(1.4절), 수치 적분(2.5절)을 쓴다.

6.1.1오일러 방법

간격 \(h\)로 \(t_n = t_0 + nh\)를 잡고, 현재 점의 기울기로 한 걸음 간다. 이것을 오일러 방법이라 한다.

\[y_{n+1} = y_n + hf(t_n, y_n)\]

테일러 정리에서 \(y(t_{n+1}) = y(t_n) + hy'(t_n) + \frac{h^2}2y''(\xi)\)이므로, 한 걸음에서 생기는 국소 절단 오차는 \(O(h^2)\)이다. 그런데 구간 \([t_0, T]\)를 가려면 \(\frac{T - t_0}h\)걸음이 필요하므로, 오차가 쌓인 전역 오차는 \(O(h)\)이다. 그래서 오일러 방법을 1차 방법이라 한다.

예제 6.1.1

\(y' = y\), \(y(0) = 1\)에서 오일러 방법으로 \(y(1) = e\)를 근사할 때 \(h\)에 따른 오차를 보아라.

풀이. \(h = 0.1, 0.05, 0.025\)에서 오차는 0.125, 0.065, 0.033으로 \(h\)에 비례해 절반씩 준다.

6.1.2룽게-쿠타 방법

한 걸음 안에서 기울기를 몇 번 더 재어 평균을 내면, 고차 도함수를 직접 계산하지 않고도 테일러 전개의 높은 차수까지 맞출 수 있다. 먼저 2차 방법인 개선된 오일러 방법, 곧 호인 방법은 \(k_1 = f(t_n, y_n)\), \(k_2 = f(t_n + h, y_n + hk_1)\)로 \(y_{n+1} = y_n + \frac h2(k_1 + k_2)\)이며, 사다리꼴 공식에 해당한다. 다음으로 고전적 4차 룽게-쿠타 방법은 다음과 같다.

\[k_1 = f(t_n, y_n),\quad k_2 = f\!\left(t_n + \tfrac h2, y_n + \tfrac h2k_1\right),\quad k_3 = f\!\left(t_n + \tfrac h2, y_n + \tfrac h2k_2\right),\quad k_4 = f(t_n + h, y_n + hk_3),\] \[y_{n+1} = y_n + \frac h6(k_1 + 2k_2 + 2k_3 + k_4)\]

\(f\)가 \(t\)에만 의존하면 이것은 심프슨 공식이 된다. 일반적으로 \(p\)차 방법은 전역 오차가 \(O(h^p)\)이고, \(h\)를 절반으로 하면 오차가 \(2^{-p}\)배가 된다.

예제 6.1.2

예제 6.1.1의 문제를 2차와 4차 방법으로 풀어 오차를 비교하여라.

풀이. \(h = 0.1, 0.05, 0.025\)일 때 2차 방법의 오차는 \(4.2\times10^{-3}\), \(1.09\times10^{-3}\), \(2.8\times10^{-4}\)으로 약 \(\frac14\)씩 준다. 4차 방법의 오차는 \(2.08\times10^{-6}\), \(1.36\times10^{-7}\), \(8.7\times10^{-9}\)으로 약 \(\frac1{16}\)씩 준다. 한 걸음의 함숫값 계산이 4배라도 4차 방법이 훨씬 효율적이다.

6.1.3구현과 차수 확인

def rk4(f, t, y, h, n):
    for _ in range(n):
        k1 = f(t, y); k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2); k4 = f(t + h, y + h*k3)
        y += h/6*(k1 + 2*k2 + 2*k3 + k4); t += h
    return y

두 간격의 오차 \(E(h)\), \(E(h/2)\)로 \(p \approx \log_2\frac{E(h)}{E(h/2)}\)를 계산하면 차수를 확인할 수 있다. 참값을 모르면 \(h, \frac h2, \frac h4\)로 얻은 세 결과의 차로 같은 비를 얻는다. 또 \(y\)를 벡터로 바꾸면 고차 방정식을 포함한 연립 미분방정식에도 그대로 쓸 수 있다.

흔한 오해국소 오차의 차수가 곧 방법의 차수라고 여기기 쉽지만, 국소 오차가 \(O(h^{p+1})\)이면 전역 오차가 \(O(h^p)\)이고 방법의 차수는 \(p\)이다. 또 \(h\)를 아주 작게 하면 늘 좋아진다고 생각하는 것도 틀렸다. 걸음 수가 늘면 반올림 오차가 쌓이고 계산량도 커진다.
마무리

처음 질문에 답하면, 지금 위치의 기울기로 한 걸음씩 나아가는 오일러 방법으로 해를 따라갈 수 있지만 전역 오차가 \(O(h)\)라 느리다. 걸음을 줄이는 대신 한 걸음 안에서 기울기를 여러 번 재어 가중평균하면, 고전적 4차 룽게-쿠타 방법처럼 전역 오차가 \(O(h^4)\)인 방법을 얻는다. 그래서 간격을 절반으로 하면 오차가 16분의 1이 되어, 같은 계산량으로 훨씬 정확하다.

6.1.4연습문제

기본

  1. \(y' = -2y\), \(y(0) = 1\)에서 \(h = 0.1\)로 오일러 방법 두 걸음을 계산하여라.
    답

    \(y_1 = 1 - 0.2 = 0.8\), \(y_2 = 0.64\). 참값 \(e^{-0.4} \approx 0.670\).

응용

  1. \(y' = y\)에 호인 방법을 한 걸음 쓰면 \(y_1 = 1 + h + \frac{h^2}2\)임을 보이고, 국소 오차의 차수를 구하여라.
    답

    \(k_1 = 1\), \(k_2 = 1 + h\), \(y_1 = 1 + \frac h2(2 + h)\). \(e^h\)와의 차는 \(\frac{h^3}6 + \cdots\)이라 국소 오차 \(O(h^3)\), 방법은 2차.

심화

  1. RK4를 \(y' = y\)에 한 걸음 쓰면 \(y_1 = 1 + h + \frac{h^2}2 + \frac{h^3}6 + \frac{h^4}{24}\)임을 확인하여라.
    답

    \(k_1 = 1\), \(k_2 = 1 + \frac h2\), \(k_3 = 1 + \frac h2 + \frac{h^2}4\), \(k_4 = 1 + h + \frac{h^2}2 + \frac{h^3}4\). \(\frac h6(k_1 + 2k_2 + 2k_3 + k_4) = h + \frac{h^2}2 + \frac{h^3}6 + \frac{h^4}{24}\).
