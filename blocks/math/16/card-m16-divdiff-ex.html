분할차분표로 보간 다항식 만들기

예제 · 뉴턴 꼴

먼저 예측

점 \((0, 1), (1, 3), (2, 2)\)를 지나는 2차 보간 다항식은 이미 구했습니다(2.1절 예). 여기에 점 \((4, 5)\)를 더하면, 처음부터 다시 계산해야 할까?

예측 확인

뉴턴 꼴이면 아니다. 분할차분표에 대각선 한 줄만 더 계산하고 항 하나를 붙이면 된다.

점 \((0, 1), (1, 3), (2, 2), (4, 5)\)를 지나는 3차 보간 다항식을 뉴턴 꼴로 구하고, \(x = 3\)에서의 값을 구하여라.

전략

분할차분표의 각 열은 바로 왼쪽 열의 이웃한 두 값의 차를 양 끝 \(x\)의 차로 나눈 것이다. 표의 맨 윗줄(대각선)이 뉴턴 꼴의 계수이다.

풀이

  1. 1차: \(f[0, 1] = \frac{3 - 1}{1} = 2\), \(f[1, 2] = \frac{2 - 3}1 = -1\), \(f[2, 4] = \frac{5 - 2}2 = 1.5\).
    이웃한 두 점의 평균변화율.
  2. 2차: \(f[0, 1, 2] = \frac{-1 - 2}{2 - 0} = -1.5\), \(f[1, 2, 4] = \frac{1.5 - (-1)}{4 - 1} = \frac56\).
    분모는 양 끝 \(x\)의 차(2 − 0, 4 − 1).
  3. 3차: \(f[0, 1, 2, 4] = \frac{5/6 - (-1.5)}{4 - 0} = \frac7{12}\).
    새 점 때문에 추가된 대각선은 \(1.5, \frac56, \frac7{12}\)뿐이다.
  4. \(p(x) = 1 + 2x - 1.5x(x - 1) + \frac7{12}x(x - 1)(x - 2)\).
    앞의 세 항은 2.1절 예의 2차 다항식 그대로이다.
  5. \(p(3) = 1 + 6 - 1.5\cdot6 + \frac7{12}\cdot6 = 1 + 6 - 9 + 3.5 = 1.5\).
    \(x(x - 1) = 6\), \(x(x - 1)(x - 2) = 6\).

검산

\(p(4) = 1 + 8 - 1.5\cdot12 + \frac7{12}\cdot24 = 1 + 8 - 18 + 14 = 5\). 마지막 점을 지난다. \(p(0), p(1), p(2)\)는 새 항이 0이 되어 그대로 1, 3, 2이다.

의미

새 항 \(\frac7{12}x(x - 1)(x - 2)\)는 기존 세 점에서 0이므로 기존 보간 조건을 깨뜨리지 않는다. 2차 보간과 3차 보간의 차이(여기서는 \(x = 3\)에서 \(3.5\))는 다음 절에서 보간 오차를 추정하는 데 쓰인다.

이해 확인

점의 순서를 \((4, 5), (2, 2), (1, 3), (0, 1)\)로 바꾸어 표를 만들면 최고차 계수 \(f[x_0, \dots, x_3]\)은 바뀌나요?

답

바뀌지 않는다. 최고차 계수는 보간 다항식(유일)의 \(x^3\) 계수이므로 점의 순서와 무관하게 \(\frac7{12}\)이다.
