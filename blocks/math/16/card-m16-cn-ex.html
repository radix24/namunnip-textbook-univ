크랭크-니콜슨 한 걸음을 손으로

예제 · 음적 차분법

먼저 예측

\(h = 0.25\), \(k = 0.0625\)이면 \(r = 1\)이다. 양적 방법이라면 이 간격으로 안정할까?

예측 확인

아니다. \(r = 1 > \frac12\)이라 불안정하다. 크랭크-니콜슨은 안정하다.

\(u_t = u_{xx}\), \(u(0, t) = u(1, t) = 0\), \(u(x, 0) = \sin\pi x\)를 \(h = 0.25\), \(k = 0.0625\)로 크랭크-니콜슨 한 걸음 계산하고, 참값 \(e^{-\pi^2k}\sin\pi x\) 및 음적 방법과 비교하여라.

전략

\(r = 1\)이면 식은 \(2u_i^{1} - \frac12(u_{i-1}^1 + u_{i+1}^1) = u_i^0 + \frac12(u_{i-1}^0 - 2u_i^0 + u_{i+1}^0)\)이다. 처음 값이 \(x = 0.5\)에 대해 대칭이라 \(u_1 = u_3\)으로 미지수가 둘로 줄어듭니다(7.3절).

풀이

  1. 처음 값 \(u^0 = (0, 0.7071, 1, 0.7071, 0)\). 오른쪽 변: \(i = 1\)은 \(0.7071 + \frac12(0 - 1.4142 + 1) = 0.5\), \(i = 2\)는 \(1 + \frac12(0.7071 - 2 + 0.7071) = 0.7071\).
    \(\frac r2 = \frac12\).
  2. 식: \(2x_1 - \frac12x_2 = 0.5\), \(-\frac12x_1 + 2x_2 - \frac12x_3 = 0.7071\)이고 \(x_3 = x_1\)이므로 \(-x_1 + 2x_2 = 0.7071\).
    경계값은 0.
  3. 첫 식에서 \(x_1 = 0.25 + 0.25x_2\), 둘째에 넣으면 \(1.75x_2 = 0.9571\), \(x_2 = 0.5469\), \(x_1 = 0.3867\).
    \(u^1 = (0, 0.3867, 0.5469, 0.3867, 0)\).

검산

참값 \(e^{-\pi^2\cdot0.0625} = 0.5396\)이라 \(u(0.5) = 0.5396\), \(u(0.25) = 0.3816\). 크랭크-니콜슨의 오차는 0.007과 0.005이다. 같은 걸음을 음적 방법으로 하면 \(3x_1 - x_2 = 0.7071\), \(-2x_1 + 3x_2 = 1\)에서 \(x_2 = 0.6306\)으로 오차가 0.091이다. 실제로 \(x_2\)는 증폭률 \(g(\frac\pi4) = \frac{1 - 2\sin^2(\pi/8)}{1 + 2\sin^2(\pi/8)} = 0.5469\)와 같다.

의미

처음 값 \(\sin\pi x\)는 격자에서 \(\theta = \pi h = \frac\pi4\)인 푸리에 모드 하나이므로, 한 걸음 뒤의 값은 정확히 그 모드의 증폭률배이다. 폰 노이만 분석의 \(g\)가 실제 계산 결과 그 자체라는 것을 보여 준다.

이해 확인

같은 문제를 양적 방법(\(r = 1\))으로 한 걸음 계산하면 \(u_2^1\)은?

답

\(1 + 1\cdot(0.7071 - 2 + 0.7071) = 0.4142\). 증폭률 \(1 - 4\sin^2\frac\pi8 = 0.414\)이고, 이 모드에서는 아직 안정하지만 \(\theta = \pi\)에 가까운 모드는 \(|1 - 4| = 3\)배씩 커진다.
