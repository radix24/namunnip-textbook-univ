SOR 한 단계를 손으로

예제 · 완화 인자

먼저 예측

해가 \((1, 1, 1)\)인 연립방정식을 0에서 출발해 가우스-자이델(\(\omega = 1\))과 SOR(\(\omega = 1.2\))로 풉니다. 첫 단계 뒤 \(x_1\)은 어느 쪽이 더 클까요?

예측 확인

SOR입니다. 같은 방향으로 1.2배 더 가므로 \(0.5\) 대신 \(0.6\)이 됩니다.

\(2x_1 - x_2 = 1\), \(-x_1 + 2x_2 - x_3 = 0\), \(-x_2 + 2x_3 = 1\)을 \(\mathbf x^{(0)} = 0\)에서 \(\omega = 1.2\)의 SOR로 한 단계 계산하고, 네 단계 뒤의 오차를 가우스-자이델과 비교하여라.

전략

각 성분마다 먼저 가우스-자이델 값 \(x_i^{GS}\)를 (새로 구한 값을 바로 써서) 계산하고, \(x_i \leftarrow (1 - \omega)x_i + \omega x_i^{GS}\)로 바꿉니다(4.2절).

풀이

  1. \(x_1^{GS} = \frac{1 + 0}2 = 0.5\), \(x_1 = -0.2\cdot0 + 1.2\cdot0.5 = 0.6\).
    \(1 - \omega = -0.2\).
  2. \(x_2^{GS} = \frac{0 + 0.6 + 0}2 = 0.3\), \(x_2 = 1.2\cdot0.3 = 0.36\).
    방금 구한 \(x_1 = 0.6\)을 쓴다.
  3. \(x_3^{GS} = \frac{1 + 0.36}2 = 0.68\), \(x_3 = 1.2\cdot0.68 = 0.816\).
    첫 단계 \(\mathbf x^{(1)} = (0.6, 0.36, 0.816)\).
  4. 계속하면 \(\infty\)-노름 오차가 \(\omega = 1\)에서 0.75, 0.375, 0.188, 0.094(매번 절반), \(\omega = 1.2\)에서 0.64, 0.30, 0.038, 0.0087로 줄어든다.
    \(\rho(T_{GS}) = \mu^2 = 0.5\), \(\omega = 1.2\)는 최적값 \(1.172\)에 가까워 \(\rho \approx 0.2\).

검산

\(\mu = \rho(T_J) = \cos\frac\pi4 \approx 0.707\)이므로 영의 공식 \(\omega_{\mathrm{opt}} = \frac2{1 + \sqrt{1 - 0.5}} \approx 1.172\), \(\rho(T_{\omega_{\mathrm{opt}}}) \approx 0.172\)입니다. 네 단계 오차 비 \(\frac{0.0087}{0.038} \approx 0.23\)과 비슷한 크기입니다.

의미

처음 두 단계에서는 두 방법의 차이가 크지 않지만(0.64 대 0.75, 0.30 대 0.375), 그 뒤로 SOR의 오차가 훨씬 빠르게 줄어듭니다. 반복법의 속도는 처음 몇 번이 아니라 \(\rho(T)\)가 정하는 장기적인 비율로 판단합니다.

이해 확인

\(\omega = 0.8\)(저완화)로 첫 단계를 계산하면 \(x_1\)은?

답

\(0.2\cdot0 + 0.8\cdot0.5 = 0.4\). 가우스-자이델보다 덜 가므로 이 문제에서는 더 느립니다.
