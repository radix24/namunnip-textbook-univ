뉴턴 방법과 이차 수렴

본문
이 절에서 배울 것
  • 접선과 \(x\)축의 교점으로 근을 갱신하는 뉴턴 방법 \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\)을 유도한다.
  • 단순근 근처에서 오차가 \(e_{n+1} \approx \frac{f''(r)}{2f'(r)}e_n^2\)로 줄어드는 이차 수렴을 증명한다.
  • 시작값이 멀거나 중근일 때 뉴턴 방법이 실패하거나 느려지는 경우를 안다.
먼저 알아야 할 것
  • 접선의 방정식, 평균값 정리(고등학교 수학), 고정점 반복 (1.3절).

1.4.1접선으로 근 찾기

점 \((x_n, f(x_n))\)에서 \(y = f(x)\)의 접선 \(y = f(x_n) + f'(x_n)(x - x_n)\)이 \(x\)축과 만나는 점을 다음 근삿값으로 삼습니다.

\[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}.\]
예 1.4.1 \(f(x) = x^2 - 2\)이면 \(x_{n+1} = x_n - \frac{x_n^2 - 2}{2x_n} = \frac12\left(x_n + \frac2{x_n}\right)\)입니다(바빌로니아의 제곱근 계산법). \(x_0 = 1\)에서 1.5, 1.41667, 1.4142157, 1.4142135623747이고 오차는 \(8.6\times10^{-2}\), \(2.5\times10^{-3}\), \(2.1\times10^{-6}\), \(1.6\times10^{-12}\)입니다. 맞는 자릿수가 매번 약 두 배가 됩니다.

1.4.2이차 수렴

증명에는 평균값 정리를 한 단계 더 쓴 다음 사실이 필요합니다.

2차 테일러 정리 \(f\)가 두 번 미분 가능하면 \(x\)와 \(r\) 사이의 어떤 \(\xi\)에 대해 \(f(r) = f(x) + f'(x)(r - x) + \frac12f''(\xi)(r - x)^2\)이다. 접선 근사 \(f(x) + f'(x)(r - x)\)의 오차가 \((r - x)^2\)에 비례한다는 뜻이다. (평균값 정리는 이 식의 1차 버전 \(f(r) = f(x) + f'(\xi)(r - x)\)이다. 증명은 수학7.)
정리 1.4.2 \(f\)가 두 번 연속 미분 가능하고 \(f(r) = 0\), \(f'(r) \ne 0\)이면, \(r\)에 충분히 가까운 \(x_0\)에서 시작한 뉴턴 방법은 \(r\)로 수렴하고 오차 \(e_n = x_n - r\)는 \[\lim_{n\to\infty}\frac{e_{n+1}}{e_n^2} = \frac{f''(r)}{2f'(r)}\] 를 만족한다.
증명

테일러 정리를 \(x = x_n\)에서 쓰면 \(0 = f(r) = f(x_n) + f'(x_n)(r - x_n) + \frac12f''(\xi_n)(r - x_n)^2\). 양변을 \(f'(x_n)\)으로 나누고 정리하면

\[x_n - \frac{f(x_n)}{f'(x_n)} - r = \frac{f''(\xi_n)}{2f'(x_n)}(x_n - r)^2.\]

즉 \(e_{n+1} = \frac{f''(\xi_n)}{2f'(x_n)}e_n^2\)이다.

\(r\) 근처의 구간에서 \(\left|\frac{f''}{2f'}\right| \le M\)이라 하고 \(M|e_0| < 1\)이 되도록 \(x_0\)을 고르면 \(|e_{n+1}| \le (M|e_n|)|e_n|\)이라 오차가 줄고 \(x_n \to r\). 그러면 \(\xi_n, x_n \to r\)이므로 비의 극한은 \(\frac{f''(r)}{2f'(r)}\)이다. ∎

예 1.4.1에서 \(\frac{f''}{2f'} = \frac1{2\sqrt2} \approx 0.354\)이고, 실제로 \(\frac{2.1\times10^{-6}}{(2.5\times10^{-3})^2} \approx 0.35\)입니다. 고정점 반복의 관점에서 보면 뉴턴 방법은 \(g(x) = x - \frac{f}{f'}\)이고 \(g'(r) = \frac{f(r)f''(r)}{f'(r)^2} = 0\)이라 일차보다 빠릅니다.

1.4.3실패하는 경우

  • 시작값이 멀 때: \(f(x) = \arctan x\) (근 0)에서 \(x_0 = 1.3\)이면 수렴하지만 \(x_0 = 1.5\)이면 \(-1.69, 2.32, -5.11, 32.3, \dots\)로 발산합니다. 경계는 약 \(1.39\)입니다.
  • 중근: \(f(r) = f'(r) = 0\)이면 이차 수렴이 깨집니다. \(f(x) = (x - 1)^2(x + 2)\)에서 \(x_0 = 2\)이면 오차가 0.56, 0.30, 0.16, 0.080, 0.040, …으로 매번 약 절반이 될 뿐입니다(일차 수렴).
  • \(f'(x_n) = 0\): 접선이 수평이라 다음 점이 없습니다.

실제로는 이분법으로 근을 좁힌 뒤 뉴턴 방법으로 마무리하는 혼합 방법을 많이 씁니다. 같은 절의 탐구 카드에서 여러 방법의 수렴을 비교합니다.

흔한 오해(1) 뉴턴 방법이 언제나 이차로 수렴한다고 여긴다. 단순근 근처에서만 그렇다. (2) 이차 수렴이면 처음부터 빠르다고 여긴다. 오차가 \(\frac1M\)보다 작아진 뒤에야 자릿수가 두 배씩 는다.
요약
  1. \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\): 접선의 \(x\)절편.
  2. 단순근 근처에서 \(e_{n+1} \approx \frac{f''(r)}{2f'(r)}e_n^2\): 맞는 자릿수가 두 배씩.
  3. 시작값이 멀면 발산할 수 있고, 중근에서는 일차 수렴으로 떨어진다.

1.4.4연습문제

기본

  1. \(\sqrt[3]{5}\)를 구하는 뉴턴 반복식을 쓰고 \(x_0 = 2\)에서 두 번 계산하여라.
    답

    \(x_{n+1} = x_n - \frac{x_n^3 - 5}{3x_n^2} = \frac{2x_n^3 + 5}{3x_n^2}\). \(x_1 = \frac{21}{12} = 1.75\), \(x_2 = \frac{15.71875}{9.1875} \approx 1.7109\) (참값 1.70998).

응용

  1. \(\frac1a\)을 나눗셈 없이 구하려고 \(f(x) = \frac1x - a\)에 뉴턴 방법을 쓰면 반복식이 \(x_{n+1} = x_n(2 - ax_n)\)임을 보여라.
    답

    \(f' = -\frac1{x^2}\)이므로 \(x - \frac{1/x - a}{-1/x^2} = x + x - ax^2 = x(2 - ax)\). 곱셈과 뺄셈만 쓴다.

심화

  1. \(r\)이 \(m\)중근이면 \(x_{n+1} = x_n - m\frac{f(x_n)}{f'(x_n)}\)이 다시 이차 수렴함을 \(f(x) = (x - r)^m\)에서 확인하여라.
    답

    \(\frac f{f'} = \frac{x - r}m\)이므로 \(x_{n+1} = x_n - (x_n - r) = r\)로 한 번에 도달한다. 일반의 \(m\)중근에서는 \(g'(r) = 0\)이 되어 이차 수렴한다.
