길쭉한 골짜기의 지그재그

탐구 · 경사하강법과 뉴턴 방법

질문

\(f = \frac12(x^2 + \kappa y^2)\)의 최솟점 \((0, 0)\)을 \((1.6, 0.9)\)에서 경사하강법으로 찾습니다. 간격 \(\alpha\)와 그릇의 길쭉한 정도 \(\kappa\)에 따라 경로와 반복 횟수는 어떻게 달라질까요?

복원

고유 방향마다 \(1 - \alpha\lambda\)배, 수렴 ⟺ \(\alpha < \frac2L\), 최적 \(\alpha = \frac2{m + L}\)에서 비 \(\frac{\kappa - 1}{\kappa + 1}\) (8.1절). 여기서 \(m = 1\), \(L = \kappa\)이고 슬라이더는 \(\alpha L\)입니다.

해 보기

  1. \(\kappa = 10\), \(\alpha L = 1\)이면 \(y\) 방향은 한 번에 0이 되고 \(x\) 방향은 매번 0.9배라 136번입니다. 경로가 \(x\)축을 따라 천천히 기어갑니다.
  2. \(\alpha L\)을 1.8 근처(최적 \(\frac{2\kappa}{1 + \kappa} = 1.82\))로 올리면 \(\alpha L = 1.8\)에서 73번으로 줄고, 경로는 골짜기를 가로지르며 지그재그합니다. 1.9이면 \(y\) 방향의 비가 \(0.9\)로 커져 다시 131번입니다.
  3. \(\alpha L = 2\)이면 \(y\) 방향이 \(-1\)배라 끝없이 튕기고, 2.05이면 발산합니다.
  4. \(\kappa = 100\)이면 최적 간격에서도 700번 넘게 걸립니다. \(\kappa = 2\)이면 \(\alpha L = 1.35\) 근처에서 14번 정도입니다. 뉴턴 방법(파랑 점선)은 어느 경우든 한 번입니다.

설명

  1. 두 방향의 줄다리기평평한 방향(\(\lambda = 1\))을 빨리 가려면 \(\alpha\)가 커야 하고, 가파른 방향(\(\lambda = \kappa\))이 튕기지 않으려면 \(\alpha < \frac2\kappa\)여야 합니다. 둘을 맞춘 최선의 비가 \(\frac{\kappa - 1}{\kappa + 1}\)이라 \(\kappa\)가 크면 1에 가깝습니다.
  2. 뉴턴 방법은 그릇을 둥글게 본다\(H^{-1}\)을 곱하면 방향마다 곡률로 나누어 모든 방향을 같은 비율로 줄이므로, 이차함수에서는 \(\kappa\)와 관계없이 한 번에 최솟점으로 갑니다.

판단

"경사하강법이 느리면 간격을 키우면 된다"는 늘 맞지는 않습니다. 출력에서 \(\kappa = 10\)일 때 \(\alpha L\)을 1.8에서 1.9로 키우면 73번에서 131번으로 오히려 느려지고, 2를 넘으면 발산합니다. 근본 원인은 조건수이며, 변수의 크기를 맞추는 전처리나 뉴턴형 방법으로 해결합니다.
