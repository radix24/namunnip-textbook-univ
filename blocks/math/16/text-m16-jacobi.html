야코비 방법과 가우스-자이델 방법

본문
이 절에서 배울 것
  • \(A = D - L - U\)로 나눠 야코비 방법과 가우스-자이델 방법을 반복식 \(\mathbf x^{(k+1)} = T\mathbf x^{(k)} + \mathbf c\)로 쓴다.
  • 반복이 모든 시작값에서 수렴할 필요충분조건이 스펙트럼 반지름 \(\rho(T) < 1\)임을 이해한다.
  • 대각 우세 행렬에서 야코비 방법이 수렴함을 증명한다.
먼저 알아야 할 것
  • 고윳값과 고유벡터 (수학1), 고정점 반복 (1.3절), 행렬 노름 (3.3절).

4.1.1왜 반복법인가

편미분방정식을 격자로 풀면 \(n = 10^6\)개 이상의 미지수가 생기는데, 행렬의 성분 대부분이 0(희소 행렬)입니다. 가우스 소거는 \(\frac23n^3\)번이 들고 소거 도중 0이 채워져 메모리도 부족합니다. 반복법은 행렬과 벡터의 곱만 쓰므로 0이 아닌 성분 수에 비례하는 계산으로 한 단계를 끝냅니다.

4.1.2두 방법

\(A\)의 대각 부분을 \(D\), 대각 아래를 \(-L\), 위를 \(-U\)라 하면 \(A = D - L - U\)입니다.

  • 야코비: \(i\)번째 식을 \(x_i\)에 대해 풀고 오른쪽에는 이전 값을 모두 넣는다. \[x_i^{(k+1)} = \frac1{a_{ii}}\left(b_i - \sum_{j\ne i}a_{ij}x_j^{(k)}\right), \qquad T_J = D^{-1}(L + U).\]
  • 가우스-자이델: 이미 새로 구한 \(x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}\)을 바로 쓴다. \[T_{GS} = (D - L)^{-1}U.\]
예 4.1.1 \(4x - y = 3\), \(-x + 4y = 3\) (해 \(x = y = 1\))을 \(\mathbf x^{(0)} = 0\)에서 야코비로 풀면 \((0.75, 0.75)\), \((0.9375, 0.9375)\), \((0.984, 0.984)\)로 오차가 매번 \(\frac14\)배이고, 가우스-자이델은 \((0.75, 0.9375)\), \((0.984, 0.996)\)으로 매번 \(\frac1{16}\)배입니다.

4.1.3수렴 조건

정확한 해 \(\mathbf x\)는 \(\mathbf x = T\mathbf x + \mathbf c\)를 만족하므로 오차 \(\mathbf e^{(k)} = \mathbf x^{(k)} - \mathbf x\)는 \(\mathbf e^{(k+1)} = T\mathbf e^{(k)}\), 즉 \(\mathbf e^{(k)} = T^k\mathbf e^{(0)}\)입니다.

정리 4.1.2 \(\mathbf x^{(k+1)} = T\mathbf x^{(k)} + \mathbf c\)가 모든 시작값에서 수렴할 필요충분조건은 \(\rho(T) = \max|\lambda_i(T)| < 1\)이다. 이때 오차는 대략 매 단계 \(\rho(T)\)배씩 줄어든다.
증명의 흐름

\(T\)가 고유벡터 \(\mathbf v_1, \dots, \mathbf v_n\)으로 대각화되는 경우, \(\mathbf e^{(0)} = \sum c_i\mathbf v_i\)이면 \(\mathbf e^{(k)} = \sum c_i\lambda_i^k\mathbf v_i\)이다. 모든 \(|\lambda_i| < 1\)이면 0으로 가고, 어떤 \(|\lambda_i| \ge 1\)이면 \(\mathbf e^{(0)} = \mathbf v_i\)에서 줄지 않는다. 대각화되지 않는 경우는 조르당 꼴로 같은 결론을 얻는다. ∎

고윳값을 구하기 어려울 때는 어떤 노름에서 \(\|T\| < 1\)임을 보이면 충분합니다(\(\rho(T) \le \|T\|\)).

정리 4.1.3 \(A\)가 엄격한 대각 우세(\(|a_{ii}| > \sum_{j\ne i}|a_{ij}|\), 모든 \(i\))이면 야코비 방법은 수렴한다.
증명

\(T_J\)의 \(i\)행 절댓값 합은 \(\sum_{j\ne i}\frac{|a_{ij}|}{|a_{ii}|} < 1\)이므로 \(\|T_J\|_\infty < 1\)이고, \(\rho(T_J) \le \|T_J\|_\infty < 1\). ∎

가우스-자이델도 같은 조건에서 수렴하며, 대칭 양정치 행렬이면 늘 수렴합니다. 예 4.1.1에서 \(\rho(T_J) = \frac14\), \(\rho(T_{GS}) = \frac1{16} = \rho(T_J)^2\)입니다. 2.3절의 스플라인이나 7.1절의 경계치 문제에서 나오는 삼중대각 행렬처럼 특정한 구조에서는 \(\rho(T_{GS}) = \rho(T_J)^2\)이 늘 성립해, 가우스-자이델이 반복 횟수를 절반으로 줄입니다.

흔한 오해(1) 가우스-자이델이 늘 야코비보다 빠르다고 여긴다. 둘 중 하나만 수렴하는 행렬도 있다. (2) \(\rho(T) < 1\)이면 빨리 수렴한다고 여긴다. \(\rho = 0.999\)이면 오차를 \(10^{-6}\)배 하는 데 약 14000번이 걸린다.
요약
  1. 야코비 \(T_J = D^{-1}(L + U)\), 가우스-자이델 \(T_{GS} = (D - L)^{-1}U\).
  2. 수렴 ⟺ \(\rho(T) < 1\), 오차는 단계마다 약 \(\rho\)배.
  3. 엄격한 대각 우세이면 야코비 수렴. 많은 경우 \(\rho(T_{GS}) = \rho(T_J)^2\).

4.1.4연습문제

기본

  1. \(\rho(T) = 0.9\)일 때 오차를 \(10^{-6}\)배로 줄이는 데 몇 번 반복이 필요한가?
    답

    \(0.9^k \le 10^{-6}\)에서 \(k \ge \frac{6}{-\log_{10}0.9} \approx 131\).

응용

  1. \(\begin{pmatrix}1 & 2\\ 2 & 1\end{pmatrix}\)에 대해 야코비 방법이 발산함을 \(\rho(T_J)\)로 보여라.
    답

    \(T_J = \begin{pmatrix}0 & -2\\ -2 & 0\end{pmatrix}\), 고윳값 \(\pm2\), \(\rho = 2 > 1\).

심화

  1. 예 4.1.1에서 \(T_{GS}\)를 직접 구하고 고윳값이 \(0, \frac1{16}\)임을 확인하여라.
    답

    \(D - L = \begin{pmatrix}4 & 0\\ -1 & 4\end{pmatrix}\), \(U = \begin{pmatrix}0 & 1\\ 0 & 0\end{pmatrix}\). \((D - L)^{-1}U = \begin{pmatrix}0 & \frac14\\ 0 & \frac1{16}\end{pmatrix}\)이라 고윳값은 \(0, \frac1{16}\).
