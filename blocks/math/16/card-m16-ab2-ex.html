애덤스-배시퍼스 2단계를 직접 돌리기

예제 · 다단계법

먼저 예측

\(y' = y\)에서 \(y_0 = 1\)만 알 때 AB2로 바로 \(y_1\)을 구할 수 있을까?

예측 확인

없다. AB2는 \(f_n\)과 \(f_{n-1}\)이 모두 필요하므로 \(y_1\)은 다른 방법(예: RK4)으로 구하고 \(y_2\)부터 AB2를 쓴다.

\(y' = -2y + t\), \(y(0) = 1\)을 \(h = 0.1\)로 푼다. \(y_1\)을 RK4로 구한 뒤 AB2로 \(y_2\)를 구하고, 참값 \(y(t) = \frac54e^{-2t} + \frac t2 - \frac14\)와 비교하여라.

전략

시작값 \(y_1\)의 오차가 \(O(h^5)\)로 충분히 작도록 RK4를 쓰고, 그다음부터 \(y_{n+1} = y_n + \frac h2(3f_n - f_{n-1})\)을 씁니다(6.2절).

풀이

  1. RK4: \(k_1 = -2\), \(k_2 = f(0.05, 0.9) = -1.75\), \(k_3 = f(0.05, 0.9125) = -1.775\), \(k_4 = f(0.1, 0.8225) = -1.545\). \(y_1 = 1 + \frac{0.1}6(-2 - 3.5 - 3.55 - 1.545) = 0.823417\).
    \(f(t, y) = -2y + t\).
  2. \(f_0 = -2\), \(f_1 = -2(0.823417) + 0.1 = -1.546833\).
    함숫값 계산은 새 점마다 한 번.
  3. \(y_2 = 0.823417 + 0.05(3(-1.546833) - (-2)) = 0.823417 + 0.05(-2.640500) = 0.691392\).
    AB2 공식.

검산

참값 \(y(0.1) = \frac54e^{-0.2} - 0.2 = 0.823413\), \(y(0.2) = \frac54e^{-0.4} - 0.15 = 0.687900\). \(y_1\)의 오차는 \(3.2\times10^{-6}\), \(y_2\)의 오차는 \(3.5\times10^{-3}\)으로, 2차 방법인 AB2의 한 걸음 오차가 RK4보다 훨씬 크다.

의미

시작값을 높은 차수로 구한 덕분에 오차는 대부분 AB2 자신에서 생긴다. 반대로 시작값을 오일러로 구하면 그 오차(\(O(h^2)\))가 이후 전체에 남아 방법의 차수를 떨어뜨릴 수 있다. 시작값은 다단계법과 같거나 높은 차수로 구한다.

이해 확인

\(y_3\)을 AB2로 구할 때 새로 계산해야 하는 함숫값은 무엇인가요?

답

\(f_2 = f(0.2, y_2)\) 하나뿐이다. \(f_1\)은 이미 있다.
