이미 사라진 성분이 걸음을 막는다

탐구 · 강성 문제

질문

\(y' = -\lambda(y - \cos t) - \sin t\), \(y(0) = 2\)의 해 \(\cos t + e^{-\lambda t}\)를 양적 오일러, RK4, 음적 오일러로 같은 간격 \(h\)로 푼다. \(h\)를 키우면 어느 방법이 먼저 무너질까?

복원

양적 오일러는 \(h\lambda \le 2\), RK4는 \(h\lambda \le 2.79\)일 때만 안정. 음적 오일러는 모든 \(h > 0\)에서 안정 (6.3절).

해 보기

  1. \(\lambda = 50\), \(h = 0.02\) (\(h\lambda = 1\))이면 세 방법 모두 참 해를 따라간다. \(t \ge 0.5\)의 오차는 양적·음적 오일러가 \(1.8\times10^{-4}\), RK4가 \(5.9\times10^{-6}\)이다.
  2. \(h = 0.04\) (\(h\lambda = 2\))이면 양적 오일러가 \(\pm1\) 크기로 계속 진동하며 줄지 않습니다(\(|1 + h\lambda| = 1\)). \(h = 0.05\)이면 발산하고, RK4는 아직 버팁니다(오차 \(7.5\times10^{-3}\)).
  3. \(h = 0.1\) (\(h\lambda = 5\))이면 RK4도 발산하지만 음적 오일러는 오차 \(8\times10^{-4}\)로 멀쩡하다.
  4. \(\lambda = 200\)으로 바꾸면 양적 방법은 \(h = 0.01\)에서 이미 한계이다. \(\lambda = 10\)이면 \(h = 0.1\)까지 모두 안정하다.

설명

  1. 한 걸음의 증폭률오차 속의 빠른 성분은 양적 오일러에서 매 걸음 \(1 - h\lambda\)배가 된다. \(h\lambda > 2\)이면 절댓값이 1보다 커서, 처음엔 아주 작아도 걸음마다 커져 결국 폭발한다. 음적 오일러의 배율 \(\frac1{1 + h\lambda}\)은 늘 1보다 작다.
  2. 정확도와 안정성은 다르다\(t \ge 0.5\)에서 참 해는 \(\cos t\)뿐이라 \(h = 0.1\)로도 정확도는 충분하다. 양적 방법의 간격을 제한하는 것은 이미 \(e^{-25}\)으로 사라진 성분이다.

판단

"양적 오일러가 발산했으니 RK4로 바꾸면 된다"는 강성 문제에서는 해결책이 아니다. 출력에서 \(\lambda = 200\)이면 RK4도 \(h = 0.02\)에서 발산한다. 안정 한계가 \(\frac2\lambda\)에서 \(\frac{2.79}\lambda\)로 늘 뿐이라 음적 방법이 필요하다.
