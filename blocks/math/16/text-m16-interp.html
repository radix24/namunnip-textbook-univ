보간 다항식: 라그랑주 꼴과 뉴턴 꼴

본문
이 절에서 배울 것
  • 서로 다른 \(n + 1\)개의 점을 지나는 \(n\)차 이하 다항식이 꼭 하나 있음을 보인다.
  • 라그랑주 기저 다항식으로 보간 다항식을 바로 쓴다.
  • 분할차분으로 뉴턴 꼴을 계산하고, 점을 하나 더할 때 항 하나만 추가하면 되는 장점을 안다.
먼저 알아야 할 것
  • 다항식의 나눗셈과 인수정리(고등학교 수학).

2.1.1존재와 유일성

측정값이나 표의 값처럼 점 \((x_0, y_0), \dots, (x_n, y_n)\) (\(x_i\)는 서로 다름)만 알 때, 그 사이의 값을 다항식으로 추정하는 것을 보간이라 합니다.

정리 2.1.1 \(x_0, \dots, x_n\)이 서로 다르면 \(p(x_i) = y_i\) (\(i = 0, \dots, n\))인 \(n\)차 이하 다항식 \(p\)가 꼭 하나 있다.
증명

유일성: 두 개 \(p, q\)가 있으면 \(p - q\)는 \(n\)차 이하인데 근이 \(x_0, \dots, x_n\)으로 \(n + 1\)개이므로 인수정리에 의해 영다항식이다. 존재: 아래 라그랑주 꼴이 실제로 조건을 만족한다. ∎

2.1.2라그랑주 꼴

\(x_i\)에서 1, 다른 모든 \(x_j\)에서 0인 다항식

\[L_i(x) = \prod_{j\ne i}\frac{x - x_j}{x_i - x_j}\]

을 만들면 \(p(x) = \sum_{i=0}^ny_iL_i(x)\)가 보간 다항식입니다. 식이 바로 써진다는 장점이 있지만, 점을 하나 더하면 모든 \(L_i\)를 다시 계산해야 합니다.

예 2.1.2 점 \((0, 1), (1, 3), (2, 2)\)이면 \(L_0 = \frac{(x - 1)(x - 2)}2\), \(L_1 = -x(x - 2)\), \(L_2 = \frac{x(x - 1)}2\)이고 \(p(x) = L_0 + 3L_1 + 2L_2 = -\frac32x^2 + \frac72x + 1\)입니다. \(p(1.5) = 2.875\).

2.1.3뉴턴 꼴과 분할차분

보간 다항식을

\[p(x) = c_0 + c_1(x - x_0) + c_2(x - x_0)(x - x_1) + \cdots + c_n(x - x_0)\cdots(x - x_{n-1})\]

꼴로 쓰면, \(x = x_0, x_1, \dots\)을 차례로 넣어 \(c_0, c_1, \dots\)을 하나씩 정할 수 있습니다. 계수는 분할차분

\[f[x_i] = y_i, \qquad f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}\]

으로 \(c_k = f[x_0, \dots, x_k]\)입니다. 1차 분할차분은 두 점 사이의 평균변화율이고, 고차 분할차분은 "평균변화율의 평균변화율"입니다.

점 \((x_{n+1}, y_{n+1})\)을 더하면 기존 항은 그대로 두고 \(c_{n+1}(x - x_0)\cdots(x - x_n)\) 한 항만 더하면 됩니다. 계산할 때는 호너 방법처럼 안쪽부터 묶어 곱셈 \(n\)번으로 값을 구합니다. 같은 절의 예제 카드에서 분할차분표를 직접 만듭니다.

흔한 오해(1) 라그랑주 꼴과 뉴턴 꼴이 다른 다항식이라고 여긴다. 유일성 때문에 같은 다항식을 다르게 쓴 것이다. (2) 점이 많을수록 보간이 원래 함수에 더 가까워진다고 여긴다. 등간격 점에서는 오히려 크게 어긋날 수 있다(다음 절의 룽게 현상).
요약
  1. \(n + 1\)개의 서로 다른 점을 지나는 \(n\)차 이하 다항식은 하나뿐이다.
  2. 라그랑주 꼴 \(\sum y_iL_i\): 바로 쓰지만 점 추가에 불리하다.
  3. 뉴턴 꼴: 계수는 분할차분, 점 추가는 항 하나.

2.1.4연습문제

기본

  1. 점 \((1, 2), (3, 6)\)을 지나는 1차 보간 다항식을 라그랑주 꼴로 쓰고 정리하여라.
    답

    \(2\cdot\frac{x - 3}{-2} + 6\cdot\frac{x - 1}2 = 2x\).

응용

  1. \(\sum_iL_i(x) = 1\)임을 보여라.
    답

    모든 \(y_i = 1\)일 때의 보간 다항식은 상수 1이고, 유일성으로 \(\sum L_i\)와 같다.

심화

  1. \(f(x) = x^2\)의 분할차분 \(f[a, b]\), \(f[a, b, c]\)를 구하여라.
    답

    \(f[a, b] = \frac{b^2 - a^2}{b - a} = a + b\), \(f[a, b, c] = \frac{(b + c) - (a + b)}{c - a} = 1\). 2차 다항식의 2차 분할차분은 최고차 계수와 같다.
