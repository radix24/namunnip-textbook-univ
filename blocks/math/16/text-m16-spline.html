3차 스플라인

본문

점이 많을 때 하나의 고차 다항식으로 보간하면 양 끝에서 크게 출렁일 수 있었다. 그렇다면 구간마다 낮은 차수의 다항식을 쓰고 이음매를 매끄럽게 이으면 어떨까? 몇 차 다항식을 쓰고 이음매에서 무엇을 맞추어야 하며, 그 계산은 얼마나 쉬울까?

먼저 알아야 할 것다항함수의 미분, 연립일차방정식, 보간 오차(2.2절)를 쓴다.

2.3.1조건 세기

점 \(x_0 < x_1 < \cdots < x_n\)과 값 \(y_i\)가 주어졌다고 하자. 각 구간 \([x_i, x_{i+1}]\)에서 3차 다항식 \(S_i\)를 정하되, 먼저 구간마다 양 끝에서 \(S_i(x_i) = y_i\), \(S_i(x_{i+1}) = y_{i+1}\)이라는 보간 조건을 요구한다. 이것이 모두 \(2n\)개이다. 다음으로 안쪽 이음점 \(x_1, \dots, x_{n-1}\)에서 \(S'\)과 \(S''\)이 이어지기를 요구하며, 이것이 \(2(n - 1)\)개이다.

미지수는 구간마다 계수 4개라 \(4n\)개인데 조건은 \(4n - 2\)개이므로 두 개가 남는다. 양 끝에서 \(S''(x_0) = S''(x_n) = 0\)으로 두는 것을 자연 스플라인이라 한다. 휘는 자를 점마다 핀으로 꽂았을 때의 모양이 이것이다.

2.3.22계 도함수로 풀기

\(M_i = S''(x_i)\)로 두자. 각 구간에서 \(S''\)은 1차식이므로 \(M_i\)와 \(M_{i+1}\)을 잇는 직선이고, 이것을 두 번 적분해 보간 조건을 넣으면 \(h_i = x_{i+1} - x_i\)에 대해 다음을 얻는다.

\[S_i(x) = M_i\frac{(x_{i+1} - x)^3}{6h_i} + M_{i+1}\frac{(x - x_i)^3}{6h_i} + \left(\frac{y_i}{h_i} - \frac{M_ih_i}6\right)(x_{i+1} - x) + \left(\frac{y_{i+1}}{h_i} - \frac{M_{i+1}h_i}6\right)(x - x_i)\]

이제 이음점에서 \(S'\)이 이어지는 조건만 남는데, 정리하면 \(i = 1, \dots, n - 1\)에 대해 다음과 같다.

\[h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_iM_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right)\]

각 식에 미지수가 세 개씩만 있는 삼중대각 연립방정식이라 \(n\)에 비례하는 계산으로 풀 수 있다. 또 대각 성분 \(2(h_{i-1} + h_i)\)이 양옆 성분의 합보다 커서 해가 하나뿐이고, 소거도 안정적이다.

예제 2.3.1

점 \((0, 0), (1, 1), (2, 0)\)을 지나는 자연 스플라인을 구하고 \(S(0.5)\)를 계산하여라.

풀이. \(M_0 = M_2 = 0\)이고, 식은 \(4M_1 = 6(-1 - 1) = -12\)이므로 \(M_1 = -3\)이다. 따라서 \([0, 1]\)에서 \(S(x) = -\frac12x^3 + \frac32x\)이고 \(S(0.5) = 0.6875\)이며, 오른쪽 구간은 대칭이다. 같은 세 점의 2차 보간 \(x(2 - x)\)은 \(0.75\)를 준다.

2.3.3왜 출렁이지 않는가

자연 스플라인은 주어진 점들을 지나는 \(C^2\) 함수 가운데 휨 에너지 \(\int(S'')^2\,dx\)가 가장 작은 함수이다. 또 \(f\)가 매끄러우면 간격 \(h\)에 대해 오차가 \(Ch^4\) 정도라서, 점을 늘려 \(h \to 0\)으로 보내면 오차가 확실히 준다. 차수를 높이지 않고 구간을 잘게 나누므로 그림 1처럼 룽게 현상이 생기지 않는다. 같은 절의 예제 카드에서 점 네 개의 경우를 푼다.

흔한 오해스플라인이 하나의 다항식이라고 여기기 쉽지만, 구간마다 다른 다항식을 이어 붙인 것이다. 또 끝 조건이 결과에 영향을 주지 않는다고 생각하는 것도 틀렸다. 자연 조건과 양 끝 기울기를 주는 조건은 끝 근처에서 서로 다른 곡선을 준다.
마무리

처음 질문에 답하면, 구간마다 3차 다항식을 쓰고 이음점에서 값과 1계, 2계 도함수를 맞추면 된다. 조건이 두 개 모자라므로 양 끝의 2계 도함수를 0으로 두는 자연 스플라인을 쓰고, \(M_i = S''(x_i)\)를 미지수로 하면 삼중대각 연립방정식이 되어 \(n\)에 비례하는 계산으로 풀린다. 스플라인은 차수를 높이지 않으므로 출렁이지 않고, 간격이 줄면 오차가 \(h^4\)처럼 준다.

2.3.4연습문제

기본

  1. 점이 \(n + 1\)개일 때 자연 스플라인의 미지수 \(M_i\) 가운데 실제로 풀어야 하는 것은 몇 개인가?
    답

    \(M_0 = M_n = 0\)이므로 \(M_1, \dots, M_{n-1}\)의 \(n - 1\)개.

응용

  1. 예 2.3.1의 \(S\)가 \(x = 1\)에서 \(S'\)이 연속임을 확인하여라.
    답

    왼쪽 \(S'(x) = -\frac32x^2 + \frac32\)이라 \(S'(1) = 0\). 대칭이므로 오른쪽도 0이다.

심화

  1. 모든 \(y_i\)가 한 직선 위에 있으면 자연 스플라인이 그 직선 자체임을 보여라.
    답

    오른쪽 변이 모두 0이라 \(M_i = 0\)이 해이고(해는 하나뿐), 그러면 각 \(S_i\)는 두 점을 잇는 1차식이다.
