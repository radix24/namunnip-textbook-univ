3차 스플라인

본문
이 절에서 배울 것
  • 구간마다 3차 다항식을 쓰되 이음점에서 값, 기울기, 휜 정도(2계 도함수)가 이어지도록 하는 3차 스플라인을 정의한다.
  • 이음점의 2계 도함수 \(M_i\)를 미지수로 하는 연립방정식을 세우고 푼다.
  • 스플라인이 고차 보간의 출렁임 없이 매끄러운 곡선을 주는 이유를 안다.
먼저 알아야 할 것
  • 다항함수의 미분, 연립일차방정식(고등학교 수학), 보간 오차 (2.2절).

2.3.1조건 세기

점 \(x_0 < x_1 < \cdots < x_n\)과 값 \(y_i\)가 주어졌을 때, 각 구간 \([x_i, x_{i+1}]\)에서 3차 다항식 \(S_i\)를 정하고 다음을 요구합니다.

  • 보간: \(S_i(x_i) = y_i\), \(S_i(x_{i+1}) = y_{i+1}\) (구간마다 2개, 모두 \(2n\)개).
  • 안쪽 이음점 \(x_1, \dots, x_{n-1}\)에서 \(S'\)과 \(S''\)이 이어짐(\(2(n - 1)\)개).

미지수는 구간마다 계수 4개로 \(4n\)개인데 조건은 \(4n - 2\)개라 두 개가 남습니다. 양 끝에서 \(S''(x_0) = S''(x_n) = 0\)으로 두는 것을 자연 스플라인이라 합니다(휘는 자를 점에 핀으로 꽂은 모양).

2.3.22계 도함수로 풀기

\(M_i = S''(x_i)\)로 두면 각 구간에서 \(S''\)은 1차식이라 \(M_i\)와 \(M_{i+1}\)을 잇는 직선이고, 두 번 적분해 보간 조건을 넣으면 (\(h_i = x_{i+1} - x_i\))

\[S_i(x) = M_i\frac{(x_{i+1} - x)^3}{6h_i} + M_{i+1}\frac{(x - x_i)^3}{6h_i} + \left(\frac{y_i}{h_i} - \frac{M_ih_i}6\right)(x_{i+1} - x) + \left(\frac{y_{i+1}}{h_i} - \frac{M_{i+1}h_i}6\right)(x - x_i)\]

입니다. 이제 이음점에서 \(S'\)이 이어지는 조건만 남는데, 정리하면 \(i = 1, \dots, n - 1\)에 대해

\[h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_iM_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right)\]

입니다. 각 식에 미지수가 세 개씩만 있어(삼중대각) \(n\)에 비례하는 계산으로 풀 수 있습니다. 대각 성분 \(2(h_{i-1} + h_i)\)이 양옆의 합보다 커서 해가 하나뿐이고 소거도 안정적입니다.

예 2.3.1 점 \((0, 0), (1, 1), (2, 0)\)의 자연 스플라인. \(M_0 = M_2 = 0\)이고 식은 \(4M_1 = 6(-1 - 1) = -12\)라 \(M_1 = -3\)입니다. \([0, 1]\)에서 \(S(x) = -\frac12x^3 + \frac32x\), \(S(0.5) = 0.6875\). 오른쪽도 대칭입니다. 같은 세 점의 2차 보간 \(x(2 - x)\)은 \(0.75\)를 줍니다.

2.3.3왜 출렁이지 않는가

자연 스플라인은 점들을 지나는 \(C^2\) 함수 가운데 휨 에너지 \(\int(S'')^2\,dx\)가 가장 작은 함수입니다. 또 \(f\)가 매끄러우면 간격 \(h\)에 대해 오차가 \(Ch^4\) 정도로, 점을 늘릴수록(\(h \to 0\)) 확실히 줄어듭니다. 차수를 높이지 않고 구간을 잘게 나누므로 룽게 현상이 생기지 않습니다. 같은 절의 예제 카드에서 점 네 개의 경우를 풉니다.

흔한 오해(1) 스플라인이 하나의 다항식이라고 여긴다. 구간마다 다른 다항식이다. (2) 끝 조건이 결과에 영향이 없다고 여긴다. 자연 조건과 양 끝 기울기를 주는 조건은 끝 근처에서 다른 곡선을 준다.
요약
  1. 3차 스플라인: 구간마다 3차, 이음점에서 값·1계·2계 도함수 연속, 자유도 2는 끝 조건으로.
  2. \(M_i = S''(x_i)\)에 대한 삼중대각 연립방정식.
  3. 휨 에너지 최소, 오차 \(O(h^4)\), 룽게 현상 없음.

2.3.4연습문제

기본

  1. 점이 \(n + 1\)개일 때 자연 스플라인의 미지수 \(M_i\) 가운데 실제로 풀어야 하는 것은 몇 개인가?
    답

    \(M_0 = M_n = 0\)이므로 \(M_1, \dots, M_{n-1}\)의 \(n - 1\)개.

응용

  1. 예 2.3.1의 \(S\)가 \(x = 1\)에서 \(S'\)이 연속임을 확인하여라.
    답

    왼쪽 \(S'(x) = -\frac32x^2 + \frac32\)이라 \(S'(1) = 0\). 대칭이므로 오른쪽도 0이다.

심화

  1. 모든 \(y_i\)가 한 직선 위에 있으면 자연 스플라인이 그 직선 자체임을 보여라.
    답

    오른쪽 변이 모두 0이라 \(M_i = 0\)이 해이고(해는 하나뿐), 그러면 각 \(S_i\)는 두 점을 잇는 1차식이다.
