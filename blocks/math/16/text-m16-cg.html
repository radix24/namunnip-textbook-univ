켤레기울기법

본문

대칭 양정치 행렬의 연립방정식은 어떤 그릇 모양 함수의 가장 낮은 점을 찾는 문제로 바꿀 수 있다. 그렇다면 가장 가파른 내리막을 따라가면 되지 않을까? 그 방법이 왜 느리고, 방향을 어떻게 고르면 \(n\)단계 만에 바닥에 닿을 수 있을까?

먼저 알아야 할 것내적과 양정치 행렬(수학8), 반복법(4.1절), 숄레스키 분해(3.2절)를 쓴다.

4.3.1최소화 문제로 보기

\(A\)가 대칭 양정치이면 \(\phi(\mathbf x) = \frac12\mathbf x^TA\mathbf x - \mathbf b^T\mathbf x\)의 기울기는 \(\nabla\phi = A\mathbf x - \mathbf b = -\mathbf r\)로, 잔차의 반대이다. \(\phi\)는 아래로 볼록한 그릇 모양이라 기울기가 0인 점, 곧 \(A\mathbf x = \mathbf b\)의 해에서 최소가 된다.

가장 단순한 방법은 내리막 방향 \(\mathbf r\)로 가장 낮은 곳까지 가는 것이며, 이것을 가장 가파른 하강법이라 한다. 그러나 조건수가 커서 그릇이 길쭉하면, 그림 1처럼 방향이 매번 직각으로 꺾이며 지그재그로 움직여 느리다. 예를 들어 \(n = 20\)인 \(\operatorname{tridiag}(-1, 2, -1)\)에서 잔차를 \(10^{-8}\)배로 줄이는 데 1624번이 걸린다.

4.3.2켤레 방향

두 벡터가 \(\mathbf p_i^TA\mathbf p_j = 0\)이면 \(A\)-켤레라 한다. \(A\)로 정한 내적에서 직교한다는 뜻이다. 서로 \(A\)-켤레인 방향 \(\mathbf p_0, \dots, \mathbf p_{n-1}\)을 따라 한 번씩 최소화하면, 앞에서 한 최소화가 뒤의 단계에 의해 망가지지 않으므로 \(n\)단계 뒤에 정확한 최솟값에 닿는다. 켤레기울기법은 이런 방향을 잔차로부터 하나씩 싸게 만든다.

알고리즘 4.3.1 (켤레기울기법)

\(\mathbf x_0\)을 고르고 \(\mathbf r_0 = \mathbf b - A\mathbf x_0\), \(\mathbf p_0 = \mathbf r_0\)으로 둔다. \(k = 0, 1, \dots\)에 대해 다음을 되풀이한다. \[\alpha_k = \frac{\mathbf r_k^T\mathbf r_k}{\mathbf p_k^TA\mathbf p_k}, \quad \mathbf x_{k+1} = \mathbf x_k + \alpha_k\mathbf p_k, \quad \mathbf r_{k+1} = \mathbf r_k - \alpha_kA\mathbf p_k,\] \[\beta_k = \frac{\mathbf r_{k+1}^T\mathbf r_{k+1}}{\mathbf r_k^T\mathbf r_k}, \quad \mathbf p_{k+1} = \mathbf r_{k+1} + \beta_k\mathbf p_k.\]

한 단계에 행렬과 벡터의 곱은 \(A\mathbf p_k\) 한 번뿐이고, 저장할 벡터도 몇 개뿐이다.

예제 4.3.2

\(A = \begin{pmatrix}4 & 1\\ 1 & 3\end{pmatrix}\), \(\mathbf b = (1, 2)^T\), \(\mathbf x_0 = 0\)에서 켤레기울기법을 두 단계 실행하여라.

풀이. \(\mathbf r_0 = \mathbf p_0 = (1, 2)\)이고 \(A\mathbf p_0 = (6, 7)\)이므로 \(\alpha_0 = \frac5{20} = \frac14\), \(\mathbf x_1 = (\frac14, \frac12)\), \(\mathbf r_1 = (-\frac12, \frac14)\)이다. 다음으로 \(\beta_0 = \frac{5/16}{5} = \frac1{16}\)이라 \(\mathbf p_1 = (-\frac7{16}, \frac38)\)이고, \(\alpha_1 = \frac4{11}\)이라 \(\mathbf x_2 = (\frac1{11}, \frac7{11})\), \(\mathbf r_2 = 0\)이다. 곧 \(n = 2\)단계에 정확한 해를 얻는다. \(\mathbf p_0^TA\mathbf p_1 = 6(-\frac7{16}) + 7\cdot\frac38 = 0\)이므로 두 방향이 켤레임도 확인된다.

4.3.3실제 수렴

반올림 오차 때문에 큰 \(n\)에서는 정확히 \(n\)단계에 끝나지 않는다. 그래도 조건수 \(\kappa\)에 대해 오차가 대략 \(\left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^k\)로 줄어, 가장 가파른 하강법의 \(\frac{\kappa - 1}{\kappa + 1}\)보다 훨씬 빠르다. 필요한 반복 횟수가 \(\kappa\)가 아니라 \(\sqrt\kappa\)에 비례하는 것이다. 예를 들어 \(\operatorname{tridiag}(-1, 2, -1)\), \(\mathbf b = \mathbf 1\)이면 \(n = 20, 50, 100\)에서 각각 10, 25, 50번에 잔차가 \(10^{-8}\)배가 된다. \(\mathbf b\)가 좌우 대칭이라 고유벡터의 절반만 쓰여서 \(\frac n2\)번이면 되는 것이다.

흔한 오해켤레기울기법을 아무 행렬에나 쓰기 쉽지만, 대칭 양정치가 아니면 \(\phi\)가 그릇 모양이 아니라 수렴이 보장되지 않는다. 비대칭 행렬에는 GMRES 같은 다른 방법을 쓴다. 또 켤레기울기법이 직접법이라 \(n\)번을 다 돌려야 한다고 생각하는 것도 틀렸다. 실제로는 \(n\)보다 훨씬 적은 반복에서 멈추는 반복법으로 쓴다.
마무리

처음 질문에 답하면, 대칭 양정치인 \(A\mathbf x = \mathbf b\)는 \(\phi(\mathbf x) = \frac12\mathbf x^TA\mathbf x - \mathbf b^T\mathbf x\)의 최소점을 찾는 문제이다. 가장 가파른 내리막을 따라가면 길쭉한 그릇에서 지그재그로 움직여 느리지만, 서로 \(A\)-켤레인 방향으로 차례로 최소화하면 앞의 결과가 망가지지 않아 \(n\)단계 만에 바닥에 닿는다. 켤레기울기법은 그 방향을 잔차로 싸게 만들고, 실제로는 \(\sqrt\kappa\)에 비례하는 반복만으로 충분히 정확한 해를 준다.

4.3.4연습문제

기본

  1. 예 4.3.2의 해 \((\frac1{11}, \frac7{11})\)이 \(A\mathbf x = \mathbf b\)를 만족함을 확인하여라.
    답

    \(4\cdot\frac1{11} + \frac7{11} = 1\), \(\frac1{11} + 3\cdot\frac7{11} = 2\).

응용

  1. 예 4.3.2에서 \(\mathbf r_0^T\mathbf r_1 = 0\)임을 확인하여라(잔차들은 서로 직교한다).
    답

    \((1, 2)\cdot(-\frac12, \frac14) = -\frac12 + \frac12 = 0\).

심화

  1. \(\kappa = 10^4\)일 때 \(\frac{\kappa - 1}{\kappa + 1}\)과 \(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\)로 오차를 \(10^{-6}\)배 하는 반복 횟수를 어림하여라.
    답

    \(\ln\frac{\kappa - 1}{\kappa + 1} \approx -\frac2\kappa\)이므로 \(\frac{6\ln10}{2\times10^{-4}} \approx 6.9\times10^4\)번. 켤레기울기법은 \(\frac{6\ln10}{2\times10^{-2}} \approx 690\)번.
