QR 분해로 푸는 최소제곱 문제

본문
이 절에서 배울 것
  • 식이 미지수보다 많은 \(A\mathbf x \approx \mathbf b\)에서 \(\|A\mathbf x - \mathbf b\|_2\)를 최소로 하는 최소제곱해가 정규방정식 \(A^TA\mathbf x = A^T\mathbf b\)를 만족함을 안다.
  • 정규방정식은 조건수를 제곱으로 키워 위험할 수 있음을 이해한다.
  • \(A = QR\)로 분해해 \(R\mathbf x = Q^T\mathbf b\)를 푸는 안정적인 방법을 쓴다.
먼저 알아야 할 것
  • 정사영과 그람-슈미트 과정 (수학1), 조건수 (3.3절).

5.1.1최소제곱해

데이터 \((t_i, y_i)\) (\(i = 1, \dots, m\))에 직선 \(y = x_1 + x_2t\)를 맞추면, 식은 \(m\)개, 미지수는 2개라 보통 정확한 해가 없습니다. 대신 \(A\mathbf x\)와 \(\mathbf b\)의 거리 \(\|A\mathbf x - \mathbf b\|_2\)를 최소로 합니다(\(A\)의 \(i\)행은 \((1, t_i)\)).

정리 5.1.1 \(A\) (\(m\times n\), \(m \ge n\))의 열이 일차독립이면 최소제곱해는 하나뿐이고 정규방정식 \(A^TA\mathbf x = A^T\mathbf b\)의 해이다.
증명

\(A\mathbf x\)가 \(\mathbf b\)에 가장 가까우려면 \(A\mathbf x\)가 \(\mathbf b\)의 \(A\)의 열공간 위로의 정사영이어야 하고, 이는 잔차 \(\mathbf b - A\mathbf x\)가 모든 열과 직교한다는 뜻, 즉 \(A^T(\mathbf b - A\mathbf x) = 0\)이다. 열이 일차독립이면 \(A^TA\)가 가역이다. ∎

예 5.1.2 점 \((0, 1), (1, 2), (2, 2), (3, 4)\)에 직선을 맞추면 정규방정식은 \(\begin{pmatrix}4 & 6\\ 6 & 14\end{pmatrix}\mathbf x = \begin{pmatrix}9\\ 18\end{pmatrix}\)이고 해는 \(x_1 = 0.9\), \(x_2 = 0.9\), 즉 \(y = 0.9 + 0.9t\)입니다.

5.1.2정규방정식의 위험

2-노름 조건수는 \(\kappa(A^TA) = \kappa(A)^2\)입니다. \(\kappa(A) = 10^6\)이면 \(A^TA\)는 \(10^{12}\)이라, 배정밀도에서 해의 자릿수가 16자리 가운데 4자리 정도만 남을 수 있습니다. 다항식 맞추기에서 \(A^TA\)는 힐베르트 행렬과 비슷해지는데, 힐베르트 행렬의 \(\infty\)-노름 조건수는 크기 4, 6, 8에서 약 \(2.8\times10^4\), \(2.9\times10^7\), \(3.4\times10^{10}\)으로 급격히 커집니다.

5.1.3QR 분해

\(A\)의 열에 그람-슈미트 과정을 적용하면 \(A = QR\) (\(Q\)는 \(m\times n\)이고 열이 정규직교, \(R\)은 \(n\times n\) 상삼각)을 얻습니다. \(Q^TQ = I\)이므로 정규방정식은

\[R^TQ^TQR\mathbf x = R^TQ^T\mathbf b \quad\Longrightarrow\quad R\mathbf x = Q^T\mathbf b\]

가 되고, 이는 뒤로 대입으로 풀립니다. \(\kappa(R) = \kappa(A)\)라 조건수가 제곱되지 않습니다. 실제 계산에서는 고전적 그람-슈미트 대신 직교성이 잘 유지되는 하우스홀더 반사(또는 수정된 그람-슈미트)로 \(Q\)를 만듭니다.

예 5.1.3 예 5.1.2의 \(A\)에서 첫 열 \((1, 1, 1, 1)\)을 정규화하면 \(\mathbf q_1 = \frac12(1, 1, 1, 1)\), \(r_{11} = 2\). 둘째 열 \((0, 1, 2, 3)\)에서 \(r_{12} = \mathbf q_1\cdot\mathbf a_2 = 3\)을 빼면 \((-1.5, -0.5, 0.5, 1.5)\), 길이 \(r_{22} = \sqrt5\). \(Q^T\mathbf b = (4.5, \frac{4.5}{\sqrt5})\)이라 \(x_2 = \frac{4.5}{5} = 0.9\), \(x_1 = \frac{4.5 - 3\cdot0.9}2 = 0.9\). 정규방정식과 같은 답입니다.
흔한 오해(1) 최소제곱해가 모든 식을 만족한다고 여긴다. 잔차가 열공간에 직교할 뿐이다. (2) 정규방정식이 늘 안전하다고 여긴다. 열이 거의 종속이면 \(A^TA\)의 조건수가 제곱으로 커진다.
요약
  1. 최소제곱해: 잔차가 열공간에 직교, \(A^TA\mathbf x = A^T\mathbf b\).
  2. \(\kappa(A^TA) = \kappa(A)^2\): 정규방정식은 자릿수를 두 배로 잃을 수 있다.
  3. \(A = QR\)이면 \(R\mathbf x = Q^T\mathbf b\)를 뒤로 대입, 조건수 그대로.

5.1.4연습문제

기본

  1. 예 5.1.2의 잔차 \(\mathbf b - A\mathbf x\)를 구하고 \(A\)의 두 열과 직교함을 확인하여라.
    답

    예측값 \(0.9, 1.8, 2.7, 3.6\), 잔차 \((0.1, 0.2, -0.7, 0.4)\). 합 0, \(t\)와의 내적 \(0.2 - 1.4 + 1.2 = 0\).

응용

  1. 상수 하나 \(y = c\)를 데이터에 맞추는 최소제곱해가 평균임을 정규방정식으로 보여라.
    답

    \(A = (1, \dots, 1)^T\), \(A^TA = m\), \(A^T\mathbf b = \sum y_i\)이므로 \(c = \frac1m\sum y_i\).

심화

  1. \(Q\)의 열이 정규직교이면 \(\|Q\mathbf y\|_2 = \|\mathbf y\|_2\)임을 보이고, 이것이 QR 방법이 안정적인 이유와 어떻게 관련되는지 설명하여라.
    답

    \(\|Q\mathbf y\|^2 = \mathbf y^TQ^TQ\mathbf y = \|\mathbf y\|^2\). 직교 변환은 길이와 오차를 키우지 않으므로 \(Q^T\)를 곱해도 반올림 오차가 증폭되지 않는다.
