보간 오차와 룽게 현상

본문
이 절에서 배울 것
  • 보간 오차 공식 \(f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n + 1)!}\prod(x - x_i)\)을 롤의 정리로 증명한다.
  • 등간격 점에서 차수를 높이면 오히려 오차가 커지는 룽게 현상을 관찰하고 이유를 공식으로 설명한다.
  • 체비쇼프 점처럼 양 끝에 몰린 점을 쓰면 오차가 줄어듦을 안다.
먼저 알아야 할 것
  • 롤의 정리(고등학교 수학), 보간 다항식 (2.1절).

2.2.1오차 공식

정리 2.2.1 \(f\)가 \([a, b]\)에서 \(n + 1\)번 미분 가능하고 \(p\)가 서로 다른 점 \(x_0, \dots, x_n \in [a, b]\)에서의 보간 다항식이면, 각 \(x \in [a, b]\)에 대해 어떤 \(\xi \in (a, b)\)가 있어 \[f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n + 1)!}\,\omega(x), \qquad \omega(x) = (x - x_0)(x - x_1)\cdots(x - x_n).\]
증명

\(x\)가 어떤 \(x_i\)와 같으면 양변이 0이다. 아니면 상수 \(K = \frac{f(x) - p(x)}{\omega(x)}\)로 두고 \(\phi(t) = f(t) - p(t) - K\omega(t)\)를 생각한다. \(\phi\)는 \(t = x_0, \dots, x_n\)과 \(t = x\)에서 0이므로 근이 \(n + 2\)개이다. 롤의 정리를 이웃한 근 사이에 쓰면 \(\phi'\)는 근이 \(n + 1\)개, 반복하면 \(\phi^{(n+1)}\)은 근 \(\xi\)를 하나 가진다. \(p^{(n+1)} = 0\)이고 \(\omega^{(n+1)} = (n + 1)!\)이므로 \(0 = f^{(n+1)}(\xi) - K(n + 1)!\). ∎

예 2.2.2 \(\sin x\)를 \([0, \frac\pi2]\)의 등간격 3점(\(n = 2\))으로 보간하면 \(|f'''| \le 1\)이고 \(|\omega(x)|\)의 최댓값은 \(\frac{2\sqrt3}{9}h^3\) (\(h = \frac\pi4\))이므로 오차는 \(\frac16\cdot\frac{2\sqrt3}9\left(\frac\pi4\right)^3 \approx 0.031\) 이하입니다. 실제 최대 오차는 약 0.024입니다.

2.2.2룽게 현상

오차 공식은 세 요소의 곱입니다. \(\frac1{(n + 1)!}\)은 빨리 줄지만, \(f^{(n+1)}\)이 \(n\)과 함께 빨리 커지거나 \(\omega(x)\)가 구간 끝에서 크면 오차가 커질 수 있습니다.

예 2.2.3 (룽게) \(f(x) = \frac1{1 + 25x^2}\)을 \([-1, 1]\)의 등간격 \(n + 1\)점으로 보간하면 최대 오차가 \(n = 5, 10, 20\)에서 약 0.43, 1.92, 59.8로 커집니다. 가운데에서는 잘 맞지만 양 끝 근처에서 다항식이 크게 출렁입니다.

등간격 점에서는 \(|\omega(x)|\)가 구간 끝 근처에서 가운데보다 훨씬 큽니다. 그리고 이 \(f\)는 복소수 \(x = \pm\frac i5\)에서 분모가 0이 되어, 도함수가 \(n!\cdot5^n\) 정도로 자랍니다.

2.2.3체비쇼프 점

\(x_i = \cos\frac{(2i + 1)\pi}{2(n + 1)}\) (\(i = 0, \dots, n\))로 양 끝에 몰리게 고르면 \(\max|\omega(x)|\)가 가능한 가장 작은 값 \(2^{-n}\)이 됩니다. 같은 룽게 함수의 최대 오차가 \(n = 10\)에서 0.109, \(n = 20\)에서 0.015로 줄어듭니다. 같은 절의 탐구 카드에서 두 점 배치를 비교합니다.

흔한 오해(1) 점을 늘리면 보간이 반드시 좋아진다고 여긴다. 등간격이면 발산할 수 있다. (2) 문제가 고차 다항식 자체에 있다고 여긴다. 점 배치를 바꾸거나(체비쇼프), 낮은 차수를 이어 붙이면(다음 절의 스플라인) 해결된다.
요약
  1. \(f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n + 1)!}\prod(x - x_i)\): 롤의 정리를 \(n + 1\)번.
  2. 등간격 고차 보간은 양 끝에서 출렁인다(룽게 현상).
  3. 체비쇼프 점은 \(\max|\prod(x - x_i)|\)을 최소화해 오차를 줄인다.

2.2.4연습문제

기본

  1. 1차 보간(두 점 \(a, b\))의 오차가 \(\frac{(b - a)^2}8\max|f''|\) 이하임을 보여라.
    답

    \(|(x - a)(x - b)|\)의 최댓값은 가운데에서 \(\frac{(b - a)^2}4\)이고 \(\frac12\)을 곱한다.

응용

  1. \(e^x\)를 \([0, 1]\)에서 간격 \(h\)의 1차 보간 표로 만들 때 오차를 \(10^{-6}\) 이하로 하려면 \(h\)를 얼마로 해야 하는가?
    답

    \(\frac{h^2}8e \le 10^{-6}\)에서 \(h \le \sqrt{8\times10^{-6}/e} \approx 1.7\times10^{-3}\).

심화

  1. \(n = 1\)일 때 체비쇼프 점 \(\pm\frac1{\sqrt2}\)에서 \(\max_{[-1,1]}|\omega|\)가 \(\frac12\)이고, 등간격(양 끝) 점 \(\pm1\)에서는 1임을 확인하여라.
    답

    \(\omega = x^2 - \frac12\)의 최댓값은 \(x = 0, \pm1\)에서 \(\frac12\). \(\omega = x^2 - 1\)은 \(x = 0\)에서 절댓값 1.
