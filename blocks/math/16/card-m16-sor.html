완화 인자 하나로 열 배 빠르게

탐구 · SOR 방법

질문

\(n\)개의 미지수를 가진 \(\operatorname{tridiag}(-1, 2, -1)\mathbf x = \mathbf 1\)을 SOR로 풀어 상대 오차 \(10^{-8}\)에 이르는 반복 횟수를 셉니다. 완화 인자 \(\omega\)를 0.5부터 2 가까이까지 바꾸면 반복 횟수는 어떻게 변할까요?

복원

\(x_i \leftarrow (1 - \omega)x_i + \omega x_i^{GS}\). 이 행렬에서 \(\rho(T_J) = \cos\frac\pi{n + 1}\), 최적값 \(\omega_{\mathrm{opt}} = \frac2{1 + \sqrt{1 - \rho(T_J)^2}}\) (4.2절).

해 보기

  1. \(n = 20\), \(\omega = 1\)(가우스-자이델)이면 822번입니다. \(\omega\)를 1.5로 올리면 263번, 1.74(최적값 근처)이면 70여 번입니다.
  2. \(\omega\)를 최적값보다 더 키우면 1.8에서 87번, 1.9에서 175번, 1.98에서 887번으로 다시 늘어납니다. 그래프가 최적값 왼쪽은 가파르고 오른쪽은 완만한 비대칭 V자입니다.
  3. \(\omega < 1\)이면 가우스-자이델보다 느립니다(\(\omega = 0.5\)에서 2477번).
  4. \(n\)을 10, 40으로 바꾸면 최적 \(\omega\)가 1.56, 1.86으로 2에 다가가고, 가우스-자이델의 반복 횟수는 224번에서 3141번으로 급격히 늘지만 최적 SOR은 39번에서 144번으로만 늡니다.

설명

  1. 격자가 촘촘할수록 느려지는 이유\(\rho(T_J) = \cos\frac\pi{n + 1} \approx 1 - \frac{\pi^2}{2(n + 1)^2}\)이라 가우스-자이델은 \(n^2\)에 비례하는 횟수가 필요합니다. 최적 SOR의 \(\rho = \omega_{\mathrm{opt}} - 1 \approx 1 - \frac{2\pi}{n + 1}\)이라 \(n\)에 비례하는 횟수로 줄어듭니다.
  2. 비대칭 V자최적값 오른쪽에서는 \(\rho(T_\omega) = \omega - 1\)로 직선적으로 커지고, 왼쪽에서는 제곱근 꼴로 급하게 커집니다. 그래서 최적값을 모를 때는 조금 크게 잡는 편이 안전합니다.

판단

"\(\omega\)가 클수록 한 번에 더 멀리 가므로 \(\omega = 1.98\)이 가장 빠르다"는 틀립니다. 출력에서 \(n = 20\)이면 1.98은 887번으로 가우스-자이델과 비슷합니다. 너무 멀리 가면 해를 넘어서 진동합니다.
