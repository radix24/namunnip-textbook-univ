네 점을 지나는 자연 스플라인

예제 · 삼중대각 방정식

먼저 예측

점 \((0, 0), (1, 1), (2, 0), (3, 1)\)은 지그재그이다. 자연 스플라인의 \(x = 1\)과 \(x = 2\)에서 2계 도함수의 부호는 각각 어떨까?

예측 확인

\(x = 1\)은 봉우리라 위로 볼록(\(M_1 < 0\)), \(x = 2\)는 골짜기라 아래로 볼록(\(M_2 > 0\))이다.

점 \((0, 0), (1, 1), (2, 0), (3, 1)\)의 자연 스플라인에서 \(M_1, M_2\)를 구하고, \(S(0.5)\)와 \(S(1.5)\)를 계산하여라.

전략

간격이 모두 \(h = 1\)이므로 방정식은 \(M_{i-1} + 4M_i + M_{i+1} = 6(y_{i+1} - 2y_i + y_{i-1})\)이다. \(M_0 = M_3 = 0\)을 넣고 두 식을 풉니다(2.3절).

풀이

  1. \(i = 1\): \(4M_1 + M_2 = 6(0 - 2 + 0) = -12\). \(i = 2\): \(M_1 + 4M_2 = 6(1 - 0 + 1) = 12\).
    \(y_{i+1} - 2y_i + y_{i-1}\)은 각각 \(0 - 2 + 0\), \(1 - 0 + 1\).
  2. 두 식을 더하면 \(5(M_1 + M_2) = 0\), 빼면 \(3(M_1 - M_2) = -24\). 따라서 \(M_1 = -4\), \(M_2 = 4\).
    예측대로 부호가 반대이다.
  3. \([0, 1]\): \(S(x) = M_1\frac{x^3}6 + \left(1 - \frac{M_1}6\right)x = -\frac23x^3 + \frac53x\). \(S(0.5) = -\frac1{12} + \frac56 = 0.75\).
    \(M_0 = 0\), \(y_0 = 0\)이라 공식의 두 항이 사라진다.
  4. \([1, 2]\): \(S(1.5) = -4\cdot\frac{0.125}6 + 4\cdot\frac{0.125}6 + \left(1 + \frac46\right)(0.5) + \left(0 - \frac46\right)(0.5) = 0.5\).
    \(x_{i+1} - x = x - x_i = 0.5\).

검산

\([0, 1]\)의 식에서 \(S'(1) = -2 + \frac53 = -\frac13\). \([1, 2]\)의 식을 미분해 \(x = 1\)을 넣으면 \(-\frac{M_1}2 - \left(1 - \frac{M_1}6\right) + \left(0 - \frac{M_2}6\right) = 2 - \frac53 - \frac23 = -\frac13\). 기울기가 이어진다.

의미

\(S(1.5) = 0.5\)는 1과 0의 평균으로, 점들이 \(x = 1.5\)를 중심으로 점대칭이기 때문이다. 같은 네 점의 3차 보간 다항식은 \(x = 1.5\)에서도 0.5이지만 \(x = 0.5\)에서 \(1\)을 주어 스플라인(0.75)보다 더 크게 솟는다.

이해 확인

점이 \((0, 0), (1, 1), (2, 2), (3, 3)\)이면 \(M_1, M_2\)는?

답

오른쪽 변이 모두 0이라 \(M_1 = M_2 = 0\)이고 스플라인은 직선 \(y = x\)이다.
