미분방정식의 수치해법 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(y' = t + y\), \(y(0) = 0\)을 \(h = 0.2\)로 호인 방법 한 걸음 계산하고 참값 \(y = e^t - t - 1\)과 비교하여라. [06-01]

    힌트 1

    \(k_1 = f(0, 0) = 0\).

    힌트 2

    \(k_2 = f(0.2, 0) = 0.2\).

    풀이

    \(y_1 = 0 + 0.1(0 + 0.2) = 0.02\). 참값 \(e^{0.2} - 1.2 \approx 0.02140\), 오차 \(1.4\times10^{-3}\) (6.1절).

  2. 계산어떤 방법으로 \(h = 0.1, 0.05\)에서 오차가 \(3.2\times10^{-5}\), \(4.0\times10^{-6}\)이었다. 차수를 추정하여라. [06-01]

    힌트 1

    \(p \approx \log_2\frac{E(h)}{E(h/2)}\).

    힌트 2

    비는 8.

    풀이

    \(\log_28 = 3\)이므로 3차 방법이다.

  3. 증명AB2가 \(y' = \lambda y\)에서 만족하는 점화식 \(y_{n+1} = (1 + \frac32z)y_n - \frac z2y_{n-1}\) (\(z = h\lambda\))를 유도하고, \(z = -1\)일 때 해가 줄어드는지 특성방정식으로 판정하여라. [06-02]

    힌트 1

    \(f_n = \lambda y_n\).

    힌트 2

    \(r^2 - (1 + \frac32z)r + \frac z2 = 0\).

    풀이

    공식에 \(f = \lambda y\)를 넣으면 점화식이 나온다. \(z = -1\)이면 \(r^2 + \frac12r - \frac12 = 0\), \(r = \frac12, -1\). \(|r| = 1\)인 근이 있어 줄지 않는다. AB2의 실수축 안정 구간은 \(-1 < z \le 0\)이다 (6.2절).

  4. 계산\(y' = -100y\), \(y(0) = 1\)을 \(h = 0.05\)로 양적 오일러와 음적 오일러로 두 걸음씩 계산하여라. [06-03]

    힌트 1

    양적: 배율 \(1 - 5 = -4\).

    힌트 2

    음적: 배율 \(\frac16\).

    풀이

    양적: \(-4, 16\)으로 폭발. 음적: \(\frac16 \approx 0.167\), \(\frac1{36} \approx 0.028\)로 줄어든다(참값 \(e^{-5} \approx 0.0067\), \(e^{-10}\)) (6.3절).

  5. 계산연립 방정식 \(y_1' = -y_1\), \(y_2' = -1000y_2\)에 양적 오일러를 쓸 때 최대 간격은? 이 연립계가 강성인 이유를 설명하여라. [06-03]

    힌트 1

    두 고윳값 \(-1, -1000\) 모두 안정 영역에 들어가야 한다.

    힌트 2

    \(h \le \frac2{1000}\).

    풀이

    \(h \le 0.002\). \(y_2\)는 \(t = 0.01\)이면 사라지지만, \(y_1\)을 \(t = 5\)까지 따라가려면 2500걸음이 필요하다. 시간 척도의 비 1000이 강성의 정도이다.

  6. 판단"음적 방법은 무조건 안정하므로 간격을 크게 잡을수록 좋다"는 옳은가? [06-03]

    힌트 1

    음적 오일러의 전역 오차는 \(O(h)\).

    힌트 2

    안정 ≠ 정확.

    풀이

    틀리다. 안정성은 발산하지 않는다는 보장일 뿐, 정확도는 차수와 \(h\)가 정한다. 천천히 변하는 성분을 원하는 정확도로 따라갈 만큼의 \(h\)는 여전히 필요하다.
