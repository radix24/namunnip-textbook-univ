선탐색을 포함한 최적화 알고리즘

본문
이 절에서 배울 것
  • 내리막 방향 \(\mathbf p\)가 정해졌을 때 간격 \(t\)를 정하는 선탐색, 특히 아르미호 조건의 백트래킹을 쓴다.
  • 선탐색을 붙인 경사하강법과 뉴턴 방법을 구현하고, 뉴턴 방향이 내리막이 아닐 때의 처리를 안다.
  • 멈춤 조건과 함수 호출 횟수를 고려해 알고리즘을 설계한다.
먼저 알아야 할 것
  • 경사하강법과 뉴턴 방법 (8.1절), 방향도함수 (수학11).

8.2.1왜 선탐색인가

8.1절에서 고정 간격은 \(\frac2L\)보다 작아야 했는데, 일반 함수에서는 \(L\)(곡률의 최댓값)을 모르고 위치마다 다릅니다. 또 뉴턴 방법은 최솟점에서 멀면 한 걸음이 너무 커서 오히려 함숫값이 커질 수 있습니다. 그래서 매 단계 방향 \(\mathbf p_k\)를 정한 뒤 "충분히 줄어드는" 간격 \(t_k\)를 찾습니다.

8.2.2아르미호 조건과 백트래킹

\(\mathbf p\)가 내리막 방향(\(\nabla f^T\mathbf p < 0\))이면 작은 \(t\)에서 \(f(\mathbf x + t\mathbf p) \approx f(\mathbf x) + t\nabla f^T\mathbf p\)이므로, 그 기울기의 일부(\(c\)배, 보통 \(c = 10^{-4}\))라도 줄면 받아들입니다.

\[f(\mathbf x + t\mathbf p) \le f(\mathbf x) + c\,t\,\nabla f(\mathbf x)^T\mathbf p.\]

백트래킹: \(t = 1\)에서 시작해 조건을 만족할 때까지 \(t \leftarrow \frac t2\). 내리막 방향이면 유한 번 안에 끝나고, 너무 작은 간격을 고르지도 않습니다(조건을 처음 만족하는 \(t\)이므로).

예 8.2.1 \(f = x^2 + 10y^2\), \(\mathbf x = (1, 1)\), \(\mathbf p = -\nabla f = (-2, -20)\)이면 \(f = 11\), \(\nabla f^T\mathbf p = -404\). \(t = 1, 0.5, 0.25, 0.125\)에서 \(f\)는 3611, 810, 160.25, 23.06으로 모두 늘고, \(t = 0.0625\)에서 \(1.39 \le 11 - 10^{-4}\cdot0.0625\cdot404\)로 받아들여집니다.

8.2.3알고리즘

def minimize(f, grad, hess, x, newton=True, tol=1e-6, maxit=10000):
    for k in range(maxit):
        g = grad(x)
        if norm(g) < tol: return x, k
        p = -g
        if newton:
            q = solve(hess(x), -g)          # H p = -g
            if dot(q, g) < 0: p = q         # 내리막일 때만 뉴턴 방향
        t, fx, slope = 1.0, f(x), dot(g, p)
        while f(x + t*p) > fx + 1e-4*t*slope:
            t /= 2
        x = x + t*p
    return x, maxit

뉴턴 방향은 \(H\)가 양정치일 때만 내리막이므로, 그렇지 않으면 기울기 방향으로 바꿉니다(실제로는 \(H + \mu I\)로 양정치가 되게 보정하기도 합니다). 최솟점 근처에서는 \(t = 1\)이 바로 받아들여져 뉴턴 방법의 이차 수렴이 그대로 나타납니다.

예 8.2.2 로젠브록 함수를 \((-1.2, 1)\)에서 기울기 크기 \(10^{-6}\)까지 풀면 백트래킹 경사하강법은 약 13756번, 백트래킹 뉴턴 방법은 21번입니다. 뉴턴 방법은 처음 몇 단계에서 \(t < 1\)로 줄여 휘어진 골짜기를 따라가고, 마지막 대여섯 번은 \(t = 1\)로 이차 수렴합니다.

8.2.4설계 시 고려할 점

  • 멈춤 조건: \(\|\nabla f\| < \)허용 오차, 또는 \(\mathbf x\)와 \(f\)의 변화가 충분히 작을 때. 상대적 기준이 크기에 덜 민감하다.
  • 비용: 백트래킹의 함수 호출 횟수도 센다. 뉴턴 방법은 헤세 행렬 비용이 크면 준뉴턴법(BFGS)으로 \(H\)를 기울기 변화로부터 추정한다.
  • 울프 조건: 아르미호 조건에 "기울기가 충분히 줄었다"는 조건을 더하면 너무 짧은 걸음을 막아 준뉴턴법의 수렴이 보장된다.
흔한 오해(1) 선탐색이 정확한 최솟점 \(\min_tf(\mathbf x + t\mathbf p)\)을 찾아야 한다고 여긴다. 충분한 감소면 되고, 정확한 탐색은 비용만 늘린다. (2) 뉴턴 방향은 늘 내리막이라고 여긴다. \(H\)가 양정치가 아니면 오르막이거나 안장점으로 갈 수 있다.
요약
  1. 아르미호 조건 \(f(\mathbf x + t\mathbf p) \le f(\mathbf x) + ct\nabla f^T\mathbf p\), 백트래킹으로 \(t = 1, \frac12, \frac14, \dots\).
  2. 뉴턴 방향은 내리막일 때만, 아니면 기울기 방향(또는 \(H\) 보정).
  3. 최솟점 근처에서 \(t = 1\)이 받아들여져 뉴턴의 이차 수렴이 살아난다.

8.2.5연습문제

기본

  1. \(f(x) = x^2\), \(x = 1\), \(p = -f'(1) = -2\)에서 백트래킹(\(c = 10^{-4}\))이 받아들이는 첫 \(t\)는?
    답

    \(t = 1\): \(f(-1) = 1 > 1 - 4\times10^{-4}\)라 거절. \(t = \frac12\): \(f(0) = 0\)으로 받아들임.

응용

  1. \(f(x, y) = x^2 - y^2\)의 \((1, 1)\)에서 뉴턴 방향을 구하고 내리막인지 판정하여라.
    답

    \(\nabla f = (2, -2)\), \(H = \operatorname{diag}(2, -2)\), \(\mathbf p = -H^{-1}\nabla f = (-1, -1)\). \(\nabla f^T\mathbf p = -2 + 2 = 0\)이라 내리막이 아니다(안장점 \((0, 0)\)으로 향함).

심화

  1. \(\nabla f\)가 립시츠 상수 \(L\)을 가지면, 경사하강 방향에서 \(t \le \frac{2(1 - c)}L\)인 모든 \(t\)가 아르미호 조건을 만족함을 보여라(따라서 백트래킹은 \(\frac{1 - c}L\) 이상의 간격을 고른다).
    답

    \(f(\mathbf x - t\mathbf g) \le f(\mathbf x) - t\|\mathbf g\|^2 + \frac L2t^2\|\mathbf g\|^2\)이고, 이것이 \(f(\mathbf x) - ct\|\mathbf g\|^2\) 이하일 조건은 \(\frac L2t \le 1 - c\)이다.
