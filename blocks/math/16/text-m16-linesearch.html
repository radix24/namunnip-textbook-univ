선탐색을 포함한 최적화 알고리즘

본문

경사하강법의 고정 간격은 곡률의 최댓값을 알아야 정할 수 있고, 뉴턴 방법은 최솟점에서 멀면 한 걸음이 너무 커서 함숫값이 오히려 커질 수 있다. 방향을 정한 뒤 얼마나 갈지를 그때그때 정하면 어떨까? 얼마만큼 줄어야 충분하다고 볼까?

먼저 알아야 할 것경사하강법과 뉴턴 방법(8.1절), 방향도함수(수학11)를 쓴다.

8.2.1왜 선탐색인가

8.1절에서 고정 간격은 \(\frac2L\)보다 작아야 했는데, 일반적인 함수에서는 곡률의 최댓값 \(L\)을 모르고 그 값도 위치마다 다르다. 또 뉴턴 방법은 최솟점에서 멀면 한 걸음이 너무 커서 오히려 함숫값이 커질 수 있다. 그래서 매 단계 방향 \(\mathbf p_k\)를 정한 뒤, 함숫값이 충분히 줄어드는 간격 \(t_k\)를 찾는다. 이것을 선탐색이라 한다.

8.2.2아르미호 조건과 백트래킹

\(\nabla f^T\mathbf p < 0\)인 내리막 방향 \(\mathbf p\)에서는 작은 \(t\)에 대해 \(f(\mathbf x + t\mathbf p) \approx f(\mathbf x) + t\nabla f^T\mathbf p\)이다. 그러므로 이 기울기의 일부, 보통 \(c = 10^{-4}\)배만큼이라도 줄면 받아들인다. 이것을 아르미호 조건이라 한다.

\[f(\mathbf x + t\mathbf p) \le f(\mathbf x) + c\,t\,\nabla f(\mathbf x)^T\mathbf p\]

백트래킹은 \(t = 1\)에서 시작해 이 조건을 만족할 때까지 \(t\)를 절반으로 줄인다. 내리막 방향이면 유한 번 안에 끝나고, 조건을 처음 만족하는 \(t\)를 고르므로 너무 작은 간격을 고르지도 않는다.

예제 8.2.1

\(f = x^2 + 10y^2\), \(\mathbf x = (1, 1)\), \(\mathbf p = -\nabla f\)일 때 백트래킹으로 받아들여지는 간격을 구하여라.

풀이. \(\mathbf p = (-2, -20)\)이고 \(f = 11\), \(\nabla f^T\mathbf p = -404\)이다. \(t = 1, 0.5, 0.25, 0.125\)에서 \(f\)는 3611, 810, 160.25, 23.06으로 모두 늘어난다. \(t = 0.0625\)에서 비로소 \(1.39 \le 11 - 10^{-4}\cdot0.0625\cdot404\)가 되어 받아들여진다.

8.2.3알고리즘

def minimize(f, grad, hess, x, newton=True, tol=1e-6, maxit=10000):
    for k in range(maxit):
        g = grad(x)
        if norm(g) < tol: return x, k
        p = -g
        if newton:
            q = solve(hess(x), -g)          # H p = -g
            if dot(q, g) < 0: p = q         # 내리막일 때만 뉴턴 방향
        t, fx, slope = 1.0, f(x), dot(g, p)
        while f(x + t*p) > fx + 1e-4*t*slope:
            t /= 2
        x = x + t*p
    return x, maxit

뉴턴 방향은 \(H\)가 양정치일 때만 내리막이므로, 그렇지 않으면 기울기 방향으로 바꾼다. 실제로는 \(H + \mu I\)가 양정치가 되도록 보정하기도 한다. 최솟점 근처에서는 \(t = 1\)이 바로 받아들여지므로, 뉴턴 방법의 이차 수렴이 그대로 나타난다.

예제 8.2.2

로젠브록 함수를 \((-1.2, 1)\)에서 기울기 크기 \(10^{-6}\)까지 백트래킹 경사하강법과 백트래킹 뉴턴 방법으로 풀어 비교하여라.

풀이. 백트래킹 경사하강법은 약 13756번, 백트래킹 뉴턴 방법은 21번이 걸린다. 뉴턴 방법은 처음 몇 단계에서 \(t < 1\)로 줄여 휘어진 골짜기를 따라가고, 마지막 대여섯 번은 \(t = 1\)로 이차 수렴한다. 그림 1이 그 경로이다.

8.2.4설계할 때 고려할 점

먼저 멈춤 조건으로는 \(\|\nabla f\|\)가 허용 오차보다 작거나, \(\mathbf x\)와 \(f\)의 변화가 충분히 작을 때를 쓴다. 상대적인 기준이 크기에 덜 민감하다. 다음으로 비용을 셀 때는 백트래킹의 함수 호출 횟수도 함께 센다. 헤세 행렬의 비용이 크면 준뉴턴법(BFGS)으로 \(H\)를 기울기의 변화로부터 추정한다. 또 아르미호 조건에 기울기가 충분히 줄었다는 조건을 더한 울프 조건을 쓰면, 너무 짧은 걸음을 막아 준뉴턴법의 수렴이 보장된다.

흔한 오해선탐색이 정확한 최솟점 \(\min_tf(\mathbf x + t\mathbf p)\)을 찾아야 한다고 여기기 쉽지만, 충분히 줄기만 하면 되고 정확한 탐색은 비용만 늘린다. 또 뉴턴 방향은 늘 내리막이라고 생각하는 것도 틀렸다. \(H\)가 양정치가 아니면 오르막이거나 안장점으로 갈 수 있다.
마무리

처음 질문에 답하면, 방향을 정한 뒤 간격을 그때그때 정하는 선탐색을 쓰면 곡률을 몰라도 안전하게 내려갈 수 있다. 충분한 감소의 기준은 아르미호 조건 \(f(\mathbf x + t\mathbf p) \le f(\mathbf x) + ct\nabla f^T\mathbf p\)이고, 백트래킹은 \(t = 1\)부터 절반씩 줄여 이 조건을 처음 만족하는 간격을 고른다. 뉴턴 방향과 합치면 멀리서는 간격을 줄여 안정하게, 가까이서는 간격 1로 이차 수렴한다.

8.2.5연습문제

기본

  1. \(f(x) = x^2\), \(x = 1\), \(p = -f'(1) = -2\)에서 백트래킹(\(c = 10^{-4}\))이 받아들이는 첫 \(t\)는?
    답

    \(t = 1\): \(f(-1) = 1 > 1 - 4\times10^{-4}\)라 거절. \(t = \frac12\): \(f(0) = 0\)으로 받아들임.

응용

  1. \(f(x, y) = x^2 - y^2\)의 \((1, 1)\)에서 뉴턴 방향을 구하고 내리막인지 판정하여라.
    답

    \(\nabla f = (2, -2)\), \(H = \operatorname{diag}(2, -2)\), \(\mathbf p = -H^{-1}\nabla f = (-1, -1)\). \(\nabla f^T\mathbf p = -2 + 2 = 0\)이라 내리막이 아니다(안장점 \((0, 0)\)으로 향함).

심화

  1. \(\nabla f\)가 립시츠 상수 \(L\)을 가지면, 경사하강 방향에서 \(t \le \frac{2(1 - c)}L\)인 모든 \(t\)가 아르미호 조건을 만족함을 보여라(따라서 백트래킹은 \(\frac{1 - c}L\) 이상의 간격을 고른다).
    답

    \(f(\mathbf x - t\mathbf g) \le f(\mathbf x) - t\|\mathbf g\|^2 + \frac L2t^2\|\mathbf g\|^2\)이고, 이것이 \(f(\mathbf x) - ct\|\mathbf g\|^2\) 이하일 조건은 \(\frac L2t \le 1 - c\)이다.
