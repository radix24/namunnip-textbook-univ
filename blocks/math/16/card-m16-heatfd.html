r = 1/2의 벽

탐구 · 열방정식의 차분법

질문

삼각형 모양의 처음 온도(가운데 1, 양 끝 0)를 \(h = \frac1{20}\)인 격자로 \(t = 0.1\)까지 푼다. 시간 간격을 \(r = \frac k{h^2}\)로 정할 때, \(r\)을 0.5보다 조금만 크게 하면 무슨 일이 생길까? 음적 방법은 어떨까?

복원

양적 방법의 증폭률 \(g = 1 - 4r\sin^2\frac\theta2\), 안정 ⟺ \(r \le \frac12\) (7.2절). 음적 방법과 크랭크-니콜슨은 모든 \(r\)에서 안정 (7.3절).

해 보기

  1. 양적 방법, \(r = 0.45\)이면 89걸음에 최대 오차 \(4.3\times10^{-4}\)로 참 해와 겹친다. \(r = 0.5\)이면 80걸음, 오차 \(2.5\times10^{-3}\)이다.
  2. \(r = 0.52\)로 아주 조금 올리면 77걸음 만에 오차가 0.65로 커지고, 수치해가 톱니 모양으로 흔들린다. \(r = 0.55\)이면 800, \(r = 0.6\)이면 폭발한다.
  3. 음적 방법으로 바꾸면 \(r = 1, 2, 5\)에서 오차가 \(4.9\times10^{-3}\), \(8.5\times10^{-3}\), \(1.9\times10^{-2}\)로 안정적입니다(걸음 수 40, 20, 8).
  4. 크랭크-니콜슨은 같은 \(r\)에서 \(1.2\times10^{-3}\) 정도로 음적 방법보다 정확하다. \(r = 5\)에서는 \(5.3\times10^{-3}\)이다.

설명

  1. 톱니가 먼저 자란다가장 빠르게 진동하는 성분(\(\theta = \pi\), 이웃 점마다 부호가 바뀜)의 증폭률이 \(1 - 4r\)이라, \(r > \frac12\)이면 \(|g| > 1\)이 되어 부호를 바꾸며 커진다. 삼각형의 꼭짓점이 이 성분을 처음부터 담고 있어 빨리 드러난다.
  2. 음적 방법의 증폭률후진 오일러는 \(g = \frac1{1 + 4r\sin^2(\theta/2)}\)으로 늘 0과 1 사이라 안정하다. 크랭크-니콜슨은 \(g = \frac{1 - 2r\sin^2(\theta/2)}{1 + 2r\sin^2(\theta/2)}\)으로 절댓값이 1 이하이고, 시간에 대해서도 2차 정확도라 더 정확하다.

판단

"\(r = 0.52\)는 0.5와 거의 같으니 결과도 거의 같을 것이다"는 틀린다. 출력에서 오차가 \(2.5\times10^{-3}\)에서 0.65로 260배가 된다. 안정 조건은 경계를 넘으면 결과가 급격히 달라지는 문턱이다.
