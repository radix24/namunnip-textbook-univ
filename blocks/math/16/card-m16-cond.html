거의 평행한 두 직선

탐구 · 조건수

질문

연립방정식 \(x + y = 2\), \(x + (1 + t)y = 2 + t + \delta\)의 해는 \(\delta = 0\)일 때 \((1, 1)\)입니다. 오른쪽 변을 아주 조금(\(\delta\)) 바꾸면 해는 얼마나 움직일까요? \(t\)가 작으면 어떻게 될까요?

복원

\(\frac{\|\delta\mathbf x\|}{\|\mathbf x\|} \le \kappa(A)\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}\), \(\kappa(A) = \|A\|\|A^{-1}\|\) (3.3절).

해 보기

  1. \(t = 1\) (\(\log t = 0\))이면 두 직선이 뚜렷하게 만나고 \(\kappa_\infty = 9\)입니다. \(\delta = 0.001\)이면 해가 \((0.999, 1.001)\)로 거의 그대로입니다.
  2. \(t = 10^{-2}\)이면 두 직선이 거의 평행하고 \(\kappa_\infty \approx 404\)입니다. 같은 \(\delta = 0.001\)에 해가 \((0.9, 1.1)\)로 움직여, 상대 변화가 입력의 201배입니다.
  3. \(t = 10^{-4}\)이면 \(\kappa_\infty \approx 4\times10^4\)이고, \(\delta = 0.0001\)만으로 해가 \((0, 2)\)가 됩니다(3.3절 예 3.3.2). \(\delta = 0.001\)이면 \((-9, 11)\)로 화면 밖입니다.
  4. \(\delta\)의 부호를 바꾸면 교점이 반대쪽으로 같은 만큼 미끄러집니다.

설명

  1. 그림으로 본 조건수두 직선이 이루는 각이 작을수록 한 직선을 평행이동했을 때 교점이 직선을 따라 멀리 미끄러집니다. 각이 작다는 것은 두 행이 거의 일차종속이라는 뜻이고, 그때 \(A^{-1}\)의 성분이 커져 \(\kappa\)가 커집니다.
  2. 상한과 실제출력의 증폭 배수(201, 20001)는 상한 \(\kappa\)(404, 40004)의 약 절반입니다. 조건수는 가장 나쁜 방향의 변화에 대한 상한입니다.

판단

"\(t = 10^{-4}\)인 방정식을 더 좋은 알고리즘으로 풀면 측정 오차 \(10^{-4}\)인 데이터로도 해를 정확히 얻는다"는 틀립니다. 출력에서 \(\delta = 10^{-4}\)이면 해가 \((1, 1)\)에서 \((0, 2)\)로 바뀝니다. 어떤 방법으로 풀어도 데이터가 허용하는 해의 범위 자체가 넓습니다.
