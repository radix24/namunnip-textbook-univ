보간과 수치 미적분 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산점 \((-1, 2), (0, 1), (1, 2), (2, 7)\)의 분할차분표를 만들고 보간 다항식을 구하여라. [02-01]

    힌트 1

    1차 분할차분은 \(-1, 1, 5\).

    힌트 2

    2차는 \(1, 2\), 3차는 \(\frac13\).

    풀이

    \(p(x) = 2 - (x + 1) + (x + 1)x + \frac13(x + 1)x(x - 1) = \frac13x^3 + x^2 - \frac13x + 1\). 검산: \(p(2) = \frac83 + 4 - \frac23 + 1 = 7\) (2.1절).

  2. 계산\(\ln x\)를 \(x = 1, 2, 3\)의 2차 보간으로 근사할 때 \(x = 1.5\)에서 오차 상한을 오차 공식으로 구하여라. [02-02]

    힌트 1

    \(f''' = \frac2{x^3}\)은 \([1, 3]\)에서 2 이하.

    힌트 2

    \(|\omega(1.5)| = 0.5\cdot0.5\cdot1.5\).

    풀이

    \(\frac{2}{3!}\cdot0.375 = 0.125\). 실제 보간값은 \(0.3825\)이고 \(\ln1.5 = 0.4055\)라 오차는 0.023으로 상한 안에 있다 (2.2절).

  3. 계산간격이 1인 점 \((0, 1), (1, 0), (2, 1)\)의 자연 스플라인에서 \(M_1\)과 \(S(0.5)\)를 구하여라. [02-03]

    힌트 1

    \(4M_1 = 6(1 - 2\cdot0 + 1)\).

    힌트 2

    \([0, 1]\)에서 \(S = M_1\frac{x^3}6 + (1 - x) + \left(0 - \frac{M_1}6\right)x\).

    풀이

    \(M_1 = 3\). \(S(0.5) = \frac{3}{6}\cdot0.125 + 0.5 - 0.5\cdot0.5 = 0.0625 + 0.5 - 0.25 = 0.3125\). 예 2.3.1을 뒤집은 것이라 \(1 - 0.6875\)와 같다 (2.3절).

  4. 판단"단정밀도(\(\varepsilon \approx 1.2\times10^{-7}\))에서 전진 차분으로 미분하면 \(h = 10^{-8}\)이 좋은 선택이다"는 옳은가? [02-04]

    힌트 1

    최적 \(h\)는 \(\sqrt\varepsilon\) 정도.

    힌트 2

    \(1 + 10^{-8}\)은 단정밀도로 얼마인가?

    풀이

    틀리다. 단정밀도에서 \(x + 10^{-8}\)은 \(x \approx 1\)이면 \(x\)와 같아져 분자가 0이 된다. 최적 \(h\)는 \(\sqrt{1.2\times10^{-7}} \approx 3\times10^{-4}\) 정도이고 오차도 \(10^{-4}\) 정도이다 (2.4절).

  5. 계산\(\int_0^1\frac{dx}{1 + x^2} = \frac\pi4\)를 심프슨(\(n = 2\))과 2점 가우스로 계산하여 오차를 비교하여라. [02-05]

    힌트 1

    심프슨: \(\frac16(1 + 4\cdot0.8 + 0.5)\).

    힌트 2

    가우스 점: \(x = \frac12 \pm \frac1{2\sqrt3}\), 가중치 \(\frac12\).

    풀이

    심프슨 \(\frac{4.7}6 = 0.78333\), 오차 \(2.1\times10^{-3}\). 가우스: \(x = 0.21132, 0.78868\)에서 \(f = 0.95725, 0.61652\), \(\frac12(1.57377) = 0.78689\), 오차 \(1.5\times10^{-3}\). 함숫값 2번의 가우스가 3번의 심프슨보다 정확하다 (2.5절).

  6. 증명\(n\)점 구적법 \(\sum w_if(t_i)\)는 \(2n\)차 다항식 전부에 대해 정확할 수 없음을 보여라. [02-05]

    힌트 1

    \(q(t) = \prod(t - t_i)^2\)을 생각하라.

    힌트 2

    공식은 0, 적분은 양수.

    풀이

    \(q(t) = \prod_{i=1}^n(t - t_i)^2\)은 \(2n\)차이고 모든 \(t_i\)에서 0이라 공식의 값은 0이다. 그러나 \(q \ge 0\)이고 항등적으로 0이 아니므로 \(\int_{-1}^1q > 0\). 따라서 \(2n - 1\)차가 가우스 구적법이 이룰 수 있는 최선이다. ∎
