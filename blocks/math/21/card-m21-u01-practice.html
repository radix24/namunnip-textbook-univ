조건부 확률과 기대값 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\((X, Y)\)가 네 점 \((0, 0), (1, 0), (1, 1), (2, 1)\) 위의 균등분포를 따른다. \(E[X \mid Y]\)를 구하고 반복 기대값 법칙을 확인하여라. [01-01]

    힌트 1

    \(Y = 0\)이면 \(X \in \{0, 1\}\)이 반반.

    힌트 2

    \(E[X \mid Y]\)는 \(Y\)의 함수.

    풀이

    \(E[X \mid Y = 0] = 0.5\), \(E[X \mid Y = 1] = 1.5\), 즉 \(E[X \mid Y] = 0.5 + Y\). \(E[0.5 + Y] = 0.5 + 0.5 = 1 = E[X] = \frac{0 + 1 + 1 + 2}4\) (1.1절).

  2. 계산주사위를 6이 두 번 연속 나올 때까지 던질 때 던지는 횟수의 평균을 구하여라. [01-02]

    힌트 1

    상태: 처음(\(a\)), 직전이 6(\(b\)).

    힌트 2

    \(a = 1 + \frac56a + \frac16b\), \(b = 1 + \frac56a\).

    풀이

    둘째 식을 첫째에 넣으면 \(a = \frac76 + \frac{35}{36}a\), \(\frac a{36} = \frac76\), \(a = 42\) (1.2절).

  3. 계산\(0, 1, \dots, 5\) 위의 랜덤워크가 확률 0.6으로 오른쪽, 0.4로 왼쪽으로 간다. 2에서 출발해 0보다 5에 먼저 닿을 확률을 구하여라. [01-02]

    힌트 1

    \(r = \frac qp\).

    힌트 2

    \(h_i = \frac{1 - r^i}{1 - r^N}\).

    풀이

    \(r = \frac23\). \(h_2 = \frac{1 - 4/9}{1 - 32/243} = \frac{5/9}{211/243} = \frac{135}{211} \approx 0.640\).

  4. 계산성공 확률 \(\frac14\)인 시행을 첫 성공까지 반복하고(횟수 \(N\)), 시행마다 평균 2인 지수분포 시간 \(X_i\)가 걸린다(모두 독립). 총시간 \(S\)의 평균과 분산을 구하여라. [01-03]

    힌트 1

    \(E[N] = 4\), \(\operatorname{Var}N = \frac{1 - p}{p^2} = 12\).

    힌트 2

    \(\operatorname{Var}X = 4\).

    풀이

    \(E[S] = 4\cdot2 = 8\). \(\operatorname{Var}S = 4\cdot4 + 12\cdot4 = 64\). (실제로 \(S\)는 평균 8인 지수분포이고 분산 \(8^2 = 64\)와 맞습니다.) (1.3절)

  5. 증명모든 함수 \(h\)에 대해 \(E\big[(X - E[X \mid Y])h(Y)\big] = 0\)임을 보여라. [01-01]

    힌트 1

    \(Y\)로 먼저 조건화한다.

    힌트 2

    \(Y\)의 함수는 조건부 기대값 밖으로 나온다.

    풀이

    \(E\big[(X - E[X \mid Y])h(Y) \mid Y\big] = h(Y)\big(E[X \mid Y] - E[X \mid Y]\big) = 0\). 반복 기대값으로 전체 평균도 0. ∎ 예측 오차가 \(Y\)의 어떤 함수와도 상관이 없다는 뜻이다.

  6. 판단"\(E[X \mid Y] = E[X]\)이면 \(X\)와 \(Y\)는 독립이다." 참인지 판단하여라. [01-01]

    힌트 1

    부호만 무작위인 경우를 생각한다.

    힌트 2

    \(Y \in \{1, 2\}\), \(Z = \pm1\) 독립, \(X = YZ\).

    풀이

    거짓. \(X = YZ\)이면 \(E[X \mid Y] = Y\cdot E[Z] = 0 = E[X]\)이지만 \(|X| = Y\)라 \(X\)를 알면 \(Y\)가 정해진다. 평균만 같고 분포는 \(Y\)에 의존한다.
