전이행렬과 여러 단계 전이확률

본문
이 절에서 배울 것
  • 마르코프 성질과 전이행렬 \(P = (p_{ij})\)을 정의한다.
  • 채프만-콜모고로프 방정식 \(P^{(m+n)} = P^{(m)}P^{(n)}\)으로 \(n\)단계 전이확률이 \(P^n\)의 성분임을 보인다.
  • 분포의 변화 \(\pi_n = \pi_0P^n\)을 계산하고 두 상태 연쇄의 \(P^n\)을 식으로 구한다.
먼저 알아야 할 것
  • 행렬의 곱(고등학교 또는 수학2), 조건부 확률 (1.1절).

2.1.1마르코프 연쇄

상태 집합 \(S\) 위의 확률변수열 \(X_0, X_1, \dots\)이

\[P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \dots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i) = p_{ij}\]

를 만족하면 (시간 동질) 마르코프 연쇄라 합니다. 미래는 현재에만 의존하고 과거가 어떻게 지나왔는지는 상관없다는 뜻입니다. \(P = (p_{ij})\)를 전이행렬이라 하며 각 행의 합은 1입니다.

예 2.1.1 오늘 맑으면(상태 1) 내일 맑을 확률 0.7, 오늘 비가 오면(상태 2) 내일 맑을 확률 0.4라 하면 \[P = \begin{pmatrix}0.7 & 0.3\\ 0.4 & 0.6\end{pmatrix}.\]

2.1.2채프만-콜모고로프 방정식

\(p_{ij}^{(n)} = P(X_n = j \mid X_0 = i)\)라 합니다.

정리 2.1.2 \(p_{ij}^{(m+n)} = \sum_kp_{ik}^{(m)}p_{kj}^{(n)}\). 따라서 \(P^{(n)} = P^n\).
증명

시각 \(m\)의 상태 \(k\)로 나누고 마르코프 성질을 쓰면 \(P(X_{m+n} = j \mid X_0 = i) = \sum_kP(X_m = k \mid X_0 = i)P(X_{m+n} = j \mid X_m = k)\). 이것이 행렬 곱의 성분이고, \(P^{(1)} = P\)에서 귀납법으로 \(P^{(n)} = P^n\). ∎

처음 분포를 행벡터 \(\pi_0\)으로 쓰면 \(n\)일 뒤의 분포는 \(\pi_n = \pi_0P^n\)입니다. 예 2.1.1에서 \(P^2\)의 첫 행은 \((0.7^2 + 0.3\cdot0.4,\ 0.7\cdot0.3 + 0.3\cdot0.6) = (0.61, 0.39)\)이라 오늘 맑으면 모레 맑을 확률은 0.61입니다.

2.1.3두 상태 연쇄의 \(P^n\)

\(P = \begin{pmatrix}1 - a & a\\ b & 1 - b\end{pmatrix}\) (\(0 < a + b < 2\))의 고윳값은 1과 \(\lambda = 1 - a - b\)이고

\[P^n = \frac1{a + b}\begin{pmatrix}b & a\\ b & a\end{pmatrix} + \frac{\lambda^n}{a + b}\begin{pmatrix}a & -a\\ -b & b\end{pmatrix}.\]

\(n = 0, 1\)을 넣어 확인할 수 있고, 두 행렬이 각각 고윳값 1과 \(\lambda\)의 사영이라 거듭제곱이 이렇게 갈라집니다. \(|\lambda| < 1\)이므로 \(n \to \infty\)이면 둘째 항이 사라지고 모든 행이 \(\left(\frac b{a + b}, \frac a{a + b}\right)\)로 갑니다. 예 2.1.1(\(a = 0.3\), \(b = 0.4\))에서는 \(\left(\frac47, \frac37\right)\), 수렴 속도는 \(0.3^n\)입니다.

흔한 오해(1) 마르코프 성질을 "과거와 미래가 독립"으로 여긴다. 현재를 알 때 과거와 미래가 조건부 독립이라는 뜻이다. (2) \(\pi_n = P^n\pi_0\)으로 열벡터에 곱한다. 행의 합이 1인 관례에서는 분포를 행벡터로 두고 오른쪽에 \(P\)를 곱한다.
요약
  1. 마르코프: 다음 상태의 분포가 현재 상태로만 정해짐, 전이행렬의 행 합은 1.
  2. 채프만-콜모고로프: \(n\)단계 전이확률은 \(P^n\)의 성분, \(\pi_n = \pi_0P^n\).
  3. 두 상태 연쇄: \(P^n\)은 극한 \(\left(\frac b{a + b}, \frac a{a + b}\right)\)에 \((1 - a - b)^n\) 속도로 다가간다.

2.1.4연습문제

기본

  1. 예 2.1.1에서 오늘 비가 오면 모레 비가 올 확률을 구하여라.
    답

    \(0.4\cdot0.3 + 0.6\cdot0.6 = 0.48\).

응용

  1. 예 2.1.1에서 오늘 맑을 때 \(n\)일 뒤 맑을 확률을 식으로 쓰고 \(n = 2\)로 확인하여라.
    답

    \(\frac47 + \frac37(0.3)^n\). \(n = 2\): \(\frac47 + \frac{0.27}7 = \frac{4.27}7 = 0.61\).

심화

  1. \(X_n\)이 마르코프 연쇄일 때 \(Y_n = (X_n, X_{n+1})\)도 마르코프 연쇄임을 보이고 전이확률을 써라.
    답

    \((i, j) \to (j, k)\)의 확률이 \(p_{jk}\)이고 나머지는 0. 다음 쌍은 \(X_{n+2}\)만 새로 정하면 되고 그 분포는 \(X_{n+1}\)에만 의존한다.
