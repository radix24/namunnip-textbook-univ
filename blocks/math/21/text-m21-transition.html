전이행렬과 여러 단계 전이확률

본문

오늘 날씨만 알면 내일 날씨의 확률이 정해지는 모형이 있다고 하자. 그러면 모레나 열흘 뒤의 날씨 확률은 어떻게 구할까? 그리고 아주 먼 뒤에는 오늘 날씨가 아직도 영향을 줄까?

먼저 알아야 할 것행렬의 곱(고등학교 또는 수학2)과 조건부 확률(1.1절)을 쓴다.

2.1.1마르코프 연쇄

상태 집합 \(S\) 위의 확률변수열 \(X_0, X_1, \dots\)이 다음을 만족하면 시간 동질 마르코프 연쇄라 한다.

\[P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \dots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i) = p_{ij}\]

미래는 현재에만 의존하고, 과거가 어떻게 지나왔는지는 상관없다는 뜻이다. \(P = (p_{ij})\)를 전이행렬이라 하며 각 행의 합은 1이다.

예제 2.1.1

오늘 맑으면(상태 1) 내일 맑을 확률이 0.7이고, 오늘 비가 오면(상태 2) 내일 맑을 확률이 0.4이다. 전이행렬을 써라.

풀이. 각 행이 오늘의 상태, 각 열이 내일의 상태이므로 다음과 같다.

\[P = \begin{pmatrix}0.7 & 0.3\\ 0.4 & 0.6\end{pmatrix}\]

2.1.2채프만-콜모고로프 방정식

\(n\)걸음 전이확률을 \(p_{ij}^{(n)} = P(X_n = j \mid X_0 = i)\)라 하자.

정리 2.1.2

\(p_{ij}^{(m+n)} = \sum_kp_{ik}^{(m)}p_{kj}^{(n)}\)이다. 따라서 \(P^{(n)} = P^n\)이다.

증명.시각 \(m\)의 상태 \(k\)로 나누고 마르코프 성질을 쓰면 \(P(X_{m+n} = j \mid X_0 = i) = \sum_kP(X_m = k \mid X_0 = i)P(X_{m+n} = j \mid X_m = k)\)이다. 이것이 행렬 곱의 성분이고, \(P^{(1)} = P\)에서 귀납법으로 \(P^{(n)} = P^n\)이다. ∎

처음 분포를 행벡터 \(\pi_0\)으로 쓰면 \(n\)일 뒤의 분포는 \(\pi_n = \pi_0P^n\)이다. 예를 들어 예제 2.1.1에서 \(P^2\)의 첫 행은 \((0.7^2 + 0.3\cdot0.4,\ 0.7\cdot0.3 + 0.3\cdot0.6) = (0.61, 0.39)\)이므로, 오늘 맑으면 모레 맑을 확률은 0.61이다.

2.1.3두 상태 연쇄의 \(P^n\)

\(P = \begin{pmatrix}1 - a & a\\ b & 1 - b\end{pmatrix}\) (\(0 < a + b < 2\))의 고윳값은 1과 \(\lambda = 1 - a - b\)이고, 거듭제곱은 다음과 같다.

\[P^n = \frac1{a + b}\begin{pmatrix}b & a\\ b & a\end{pmatrix} + \frac{\lambda^n}{a + b}\begin{pmatrix}a & -a\\ -b & b\end{pmatrix}\]

\(n = 0, 1\)을 넣어 확인할 수 있다. 두 행렬이 각각 고윳값 1과 \(\lambda\)의 사영이므로 거듭제곱이 이렇게 갈라진다. \(|\lambda| < 1\)이므로 \(n \to \infty\)이면 둘째 항이 사라지고, 모든 행이 \(\left(\frac b{a + b}, \frac a{a + b}\right)\)로 간다. 예제 2.1.1에서는 \(a = 0.3\), \(b = 0.4\)이므로 극한이 \(\left(\frac47, \frac37\right)\)이고, 그림 1처럼 두 출발점의 차이가 \(0.3^n\)으로 줄어든다.

흔한 오해마르코프 성질을 과거와 미래가 독립이라는 뜻으로 여기기 쉽지만, 현재를 알 때 과거와 미래가 조건부 독립이라는 뜻이다. 또 \(\pi_n = P^n\pi_0\)처럼 열벡터에 곱한다고 생각하는 것도 틀렸다. 행의 합이 1인 관례에서는 분포를 행벡터로 두고 오른쪽에 \(P\)를 곱한다.
마무리

처음 질문에 답하면, \(n\)일 뒤의 날씨 확률은 전이행렬의 거듭제곱 \(P^n\)의 성분이며, 이는 채프만-콜모고로프 방정식에서 나온다. 두 상태 연쇄에서는 \(P^n\)이 고윳값 1의 부분과 \(\lambda^n\)의 부분으로 갈라지고, \(|\lambda| < 1\)이라 뒤의 부분이 사라진다. 그래서 먼 뒤에는 오늘 날씨와 상관없이 맑을 확률이 \(\frac47\)에 가까워진다.

2.1.4연습문제

기본

  1. 예 2.1.1에서 오늘 비가 오면 모레 비가 올 확률을 구하여라.
    답

    \(0.4\cdot0.3 + 0.6\cdot0.6 = 0.48\).

응용

  1. 예 2.1.1에서 오늘 맑을 때 \(n\)일 뒤 맑을 확률을 식으로 쓰고 \(n = 2\)로 확인하여라.
    답

    \(\frac47 + \frac37(0.3)^n\). \(n = 2\): \(\frac47 + \frac{0.27}7 = \frac{4.27}7 = 0.61\).

심화

  1. \(X_n\)이 마르코프 연쇄일 때 \(Y_n = (X_n, X_{n+1})\)도 마르코프 연쇄임을 보이고 전이확률을 써라.
    답

    \((i, j) \to (j, k)\)의 확률이 \(p_{jk}\)이고 나머지는 0. 다음 쌍은 \(X_{n+2}\)만 새로 정하면 되고 그 분포는 \(X_{n+1}\)에만 의존한다.
