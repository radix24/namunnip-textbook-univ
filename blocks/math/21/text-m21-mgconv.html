마팅게일 수렴 정리와 폴리아 항아리

본문

항아리에서 공을 하나 꺼내 그 색의 공을 하나 더 넣는 일을 되풀이하면, 빨간 공의 비율은 결국 어떤 값에 자리 잡을까? 그 값은 처음 비율로 정해질까, 아니면 시행할 때마다 다를까? 그리고 공정한 게임의 재산은 언제 한 값으로 수렴할까?

먼저 알아야 할 것마팅게일과 베팅 전략(6.1절), 선택 정지 정리(6.2절)를 쓴다.

6.3.1수렴 정리

정리 6.3.1 (마팅게일 수렴 정리)

마팅게일 또는 우마팅게일 \(M_n\)이 \(\sup_nE|M_n| < \infty\)를 만족하면, 확률 1로 유한한 극한 \(M_\infty = \lim M_n\)이 있다. 특히 음이 아닌 우마팅게일은 늘 수렴한다.

증명의 아이디어.수렴하지 않으면 어떤 두 유리수 \(a < b\) 사이를 무한히 오르내린다. 그런데 \(a\) 아래로 내려가면 사고 \(b\) 위로 오르면 파는 전략은 한 번 오를 때마다 \(b - a\) 이상을 벌지만, 정리 6.1.2에 의해 평균 이득이 0 이하이다. \(n\)까지 \([a, b]\)를 오른 횟수를 \(U_n\)이라 하면 이로부터 \((b - a)E[U_n] \le E|M_n| + |a|\)이고, \(\sup E|M_n| < \infty\)이므로 오르는 횟수가 유한하다. ∎

바꿔 말하면, 공정한 게임에서 재산이 음이 될 수 없으면 결국 어딘가에 멈춘다. 공정한 랜덤워크는 유계가 아니라서 수렴하지 않는다. 반면 0에서 흡수되는 랜덤워크, 곧 파산하면 끝나는 게임은 결국 0에 멈춘다.

6.3.2폴리아 항아리

항아리에 빨간 공 \(a\)개, 파란 공 \(b\)개가 있다. 공을 하나 꺼내 색을 보고, 그 공과 같은 색 공 하나를 더해 넣는다. \(n\)번 뒤에는 공이 \(a + b + n\)개이고, 그 가운데 빨간 공의 수를 \(R_n\)이라 하자.

정리 6.3.2

비율 \(M_n = \frac{R_n}{a + b + n}\)은 마팅게일이고 확률 1로 수렴한다. 극한은 베타분포 \(\text{Beta}(a, b)\)를 따르며, 특히 \(a = b = 1\)이면 \(U(0, 1)\)이다.

증명.\(T = a + b + n\), \(R = R_n\)이라 하면 \(E[R_{n+1} \mid \mathcal F_n] = R + \frac RT\)이므로 \(E[M_{n+1} \mid \mathcal F_n] = \frac{R(T + 1)/T}{T + 1} = \frac RT\)이다. 또 \(0 \le M_n \le 1\)이므로 수렴 정리에 의해 수렴한다. \(a = b = 1\)이면 \(k = 1, \dots, n + 1\)에 대해 \(P(R_n = k) = \frac1{n + 1}\)임을 귀납법으로 보일 수 있으므로(연습문제 3), 극한은 균등분포이다. ∎

여기서 눈여겨볼 것은 극한이 상수가 아니라는 점이다. 처음 몇 번 우연히 빨강이 많이 나오면 그 뒤로도 빨강이 유리해져 부익부가 굳어진다. 그래서 그림 1처럼 시행할 때마다 다른 비율로 수렴하며, 그 비율의 분포가 균등분포이다.

6.3.3수렴과 평균

예제 6.3.3

개체마다 독립적으로 평균 \(m\)마리의 자손을 남기고 죽는 분기 과정에서 \(n\)세대 개체 수를 \(Z_n\)이라 하자(\(Z_0 = 1\)). \(\frac{Z_n}{m^n}\)의 수렴과 그 평균을 조사하여라.

풀이. \(E[Z_{n+1} \mid \mathcal F_n] = mZ_n\)이므로 \(\frac{Z_n}{m^n}\)은 음이 아닌 마팅게일이고, 따라서 수렴한다. 이제 \(m = 1\)인 임계 경우에 자손 수가 상수가 아니면 \(Z_n\)은 결국 0이 된다. 이때 모든 \(n\)에서 \(E[Z_n] = 1\)이지만 극한은 0이다. 즉 수렴하는 마팅게일이어도 \(E[M_\infty] = E[M_0]\)이 깨질 수 있다. 평균이 보존되려면 균등적분가능성이 더 필요하며, 유계인 폴리아 항아리는 이 조건을 만족해 평균이 보존된다.

흔한 오해폴리아 항아리의 비율이 처음 비율 \(\frac a{a + b}\)로 수렴한다고 여기기 쉽지만, 극한은 무작위이고 그 평균만 \(\frac a{a + b}\)이다. 또 수렴하는 마팅게일이면 극한의 평균이 처음과 같다고 생각하는 것도 틀렸다. 임계 분기 과정에서는 평균이 늘 1인데 극한은 0이다.
마무리

처음 질문에 답하면, 빨간 공 비율은 유계인 마팅게일이므로 마팅게일 수렴 정리에 의해 확률 1로 어떤 값에 자리 잡는다. 하지만 그 값은 처음 비율로 정해지지 않고 시행마다 다르며, 빨강과 파랑을 하나씩 넣고 시작하면 극한이 \(U(0, 1)\)을 따른다. 일반적으로 공정한 게임의 재산은 \(\sup E|M_n| < \infty\)이면, 특히 음이 될 수 없으면 수렴한다.

6.3.4연습문제

기본

  1. 빨강 1, 파랑 1로 시작한 폴리아 항아리에서 처음 두 번 모두 빨강이 나올 확률을 구하여라.
    답

    \(\frac12\cdot\frac23 = \frac13\).

응용

  1. 1번 항아리에서 비율의 극한 \(M_\infty\)가 0.9 이상일 확률을 구하여라.
    답

    \(U(0, 1)\)이라 0.1.

심화

  1. 빨강 1, 파랑 1로 시작하면 \(P(R_n = k) = \frac1{n + 1}\) (\(k = 1, \dots, n + 1\))임을 귀납법으로 보여라.
    답

    \(P(R_{n+1} = k) = \frac1{n + 1}\left(\frac{k - 1}{n + 2} + \frac{n + 2 - k}{n + 2}\right) = \frac1{n + 1}\cdot\frac{n + 1}{n + 2} = \frac1{n + 2}\). (빨강 \(k - 1\)개에서 빨강을 뽑거나, 빨강 \(k\)개에서 파랑을 뽑는 경우.)
