마팅게일 수렴 정리와 폴리아 항아리

본문
이 절에서 배울 것
  • 음이 아닌(또는 \(L^1\) 유계인) 마팅게일이 확률 1로 수렴한다는 정리와 그 아이디어(상향 횡단)를 안다.
  • 폴리아 항아리에서 빨간 공의 비율이 수렴하고, 그 극한이 무작위(균등분포)임을 계산한다.
  • 수렴해도 평균이 보존되지 않을 수 있음을 분기 과정으로 본다.
먼저 알아야 할 것
  • 마팅게일 (6.1절), 선택 정지 정리 (6.2절).

6.3.1수렴 정리

정리 6.3.1 (마팅게일 수렴 정리) 마팅게일(또는 우마팅게일) \(M_n\)이 \(\sup_nE|M_n| < \infty\)이면 확률 1로 유한한 극한 \(M_\infty = \lim M_n\)이 있다. 특히 음이 아닌 우마팅게일은 늘 수렴한다.
증명의 아이디어

수렴하지 않으면 어떤 두 유리수 \(a < b\) 사이를 무한히 오르내린다. "\(a\) 아래로 내려가면 사고 \(b\) 위로 오르면 파는" 전략은 한 번 오를 때마다 \(b - a\) 이상 벌지만, 정리 6.1.2로 평균 이득이 0 이하이다. 이로부터 \((b - a)E[U_n] \le E|M_n| + |a|\) (\(U_n\)은 \(n\)까지 \([a, b]\)를 오른 횟수)이고 \(\sup E|M_n| < \infty\)라 오르는 횟수가 유한하다. ∎

"공정한 게임에서 재산이 음이 될 수 없으면 결국 어딘가에 멈춘다"는 뜻입니다. 공정한 랜덤워크는 유계가 아니라서 수렴하지 않고, 0에서 흡수되는 랜덤워크(파산하면 끝)는 결국 0에 멈춥니다.

6.3.2폴리아 항아리

항아리에 빨간 공 \(a\)개, 파란 공 \(b\)개가 있습니다. 공을 하나 꺼내 색을 보고, 그 공과 같은 색 공 하나를 더해 넣습니다. \(n\)번 뒤 공은 \(a + b + n\)개이고 빨간 공 수를 \(R_n\)이라 합니다.

정리 6.3.2 비율 \(M_n = \frac{R_n}{a + b + n}\)은 마팅게일이고 확률 1로 수렴한다. 극한은 베타분포 \(\text{Beta}(a, b)\)를 따르며, 특히 \(a = b = 1\)이면 \(U(0, 1)\)이다.
증명

\(T = a + b + n\), \(R = R_n\)이라 하면 \(E[R_{n+1} \mid \mathcal F_n] = R + \frac RT\)이라 \(E[M_{n+1} \mid \mathcal F_n] = \frac{R(T + 1)/T}{T + 1} = \frac RT\). \(0 \le M_n \le 1\)이라 수렴 정리로 수렴한다. \(a = b = 1\)이면 \(P(R_n = k) = \frac1{n + 1}\) (\(k = 1, \dots, n + 1\))임을 귀납법으로 보일 수 있고(연습문제 3), 균등분포가 극한이다. ∎

놀라운 점은 극한이 상수가 아니라는 것입니다. 처음 몇 번 우연히 빨강이 많이 나오면 그 뒤로도 빨강이 유리해져 "부익부"가 굳어집니다. 시행할 때마다 다른 비율로 수렴하며, 그 비율의 분포가 균등분포입니다.

6.3.3수렴과 평균

예 6.3.3 (분기 과정) 개체마다 독립적으로 평균 \(m\)마리의 자손을 남기고 죽습니다. \(n\)세대 개체 수 \(Z_n\)에 대해 \(\frac{Z_n}{m^n}\)은 음이 아닌 마팅게일이라 수렴합니다. \(m = 1\)(임계)이고 자손 수가 상수가 아니면 \(Z_n\)은 결국 0이 됩니다. 이때 \(E[Z_n] = 1\)인데 극한은 0이라, 수렴하는 마팅게일이어도 \(E[M_\infty] = E[M_0]\)이 깨질 수 있습니다. 평균이 보존되려면 균등적분가능성이 더 필요합니다(폴리아 항아리는 유계라 보존됩니다).
흔한 오해(1) 폴리아 항아리의 비율이 처음 비율 \(\frac a{a + b}\)로 수렴한다고 여긴다. 극한은 무작위이고 그 평균만 \(\frac a{a + b}\)이다. (2) 수렴하는 마팅게일이면 극한의 평균이 처음과 같다고 여긴다. 임계 분기 과정에서 깨진다.
요약
  1. \(L^1\) 유계 마팅게일은 확률 1로 수렴(상향 횡단 논법).
  2. 폴리아 항아리: 비율이 \(\text{Beta}(a, b)\)를 따르는 무작위 극한으로.
  3. 극한에서 평균 보존은 균등적분가능성이 있어야.

6.3.4연습문제

기본

  1. 빨강 1, 파랑 1로 시작한 폴리아 항아리에서 처음 두 번 모두 빨강이 나올 확률을 구하여라.
    답

    \(\frac12\cdot\frac23 = \frac13\).

응용

  1. 1번 항아리에서 비율의 극한 \(M_\infty\)가 0.9 이상일 확률을 구하여라.
    답

    \(U(0, 1)\)이라 0.1.

심화

  1. 빨강 1, 파랑 1로 시작하면 \(P(R_n = k) = \frac1{n + 1}\) (\(k = 1, \dots, n + 1\))임을 귀납법으로 보여라.
    답

    \(P(R_{n+1} = k) = \frac1{n + 1}\left(\frac{k - 1}{n + 2} + \frac{n + 2 - k}{n + 2}\right) = \frac1{n + 1}\cdot\frac{n + 1}{n + 2} = \frac1{n + 2}\). (빨강 \(k - 1\)개에서 빨강을 뽑거나, 빨강 \(k\)개에서 파랑을 뽑는 경우.)
