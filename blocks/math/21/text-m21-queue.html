M/M/1 대기행렬과 리틀 공식

본문

창구가 시간당 10명을 처리할 수 있는데 손님은 시간당 8명만 온다. 처리 능력이 남으니 줄이 거의 생기지 않을까? 평균 몇 명이 기다리고 한 사람이 얼마나 머무는지, 그리고 손님이 조금 더 늘면 무슨 일이 생길까?

먼저 알아야 할 것M/M/1의 정상분포(4.2절)와 기하급수의 합을 쓴다.

4.3.1평균 인원

도착은 포아송, 서비스는 지수분포, 창구는 1개인 M/M/1에서 \(\rho = \frac\lambda\mu < 1\)이면 정상 상태의 인원 \(N\)은 \(P(N = n) = (1 - \rho)\rho^n\)을 따른다. 그러므로 평균 인원과 평균 줄 길이는 다음과 같다.

\[L = E[N] = \sum_nn(1 - \rho)\rho^n = \frac\rho{1 - \rho}, \qquad L_q = E[\max(N - 1, 0)] = \frac{\rho^2}{1 - \rho}\]

여기서 \(L_q\)는 서비스 중인 사람을 뺀 줄의 길이이고, \(L - L_q = \rho\)는 창구가 바쁠 확률이다.

4.3.2리틀 공식

정리 4.3.1 (리틀)

장기적으로 안정된 대기 시스템에서 평균 인원은 도착 비율과 평균 체류 시간의 곱이다. 즉 \(L = \lambda W\)이다.

증명의 흐름.시간 \([0, T]\) 동안 각 손님이 머문 시간을 모두 더한 양을 두 가지로 센다. 시각마다 인원을 적분하면 약 \(LT\)이고, 손님마다 체류 시간을 더하면 약 \((\lambda T)W\)이다. \(T \to \infty\)이면 둘이 같아진다. ∎

리틀 공식은 도착과 서비스의 분포와 상관없이 성립하므로 매우 넓게 쓰인다. M/M/1에서는 다음을 얻는다.

\[W = \frac L\lambda = \frac1{\mu - \lambda}, \qquad W_q = \frac{L_q}\lambda = \frac\rho{\mu - \lambda} = W - \frac1\mu\]
예제 4.3.2

손님이 시간당 8명 오고 창구가 시간당 10명을 처리한다. 평균 인원, 평균 체류 시간, 평균 대기 시간을 구하여라.

풀이. \(\rho = 0.8\)이므로 \(L = \frac{0.8}{0.2} = 4\)명이고, \(W = \frac1{10 - 8} = \frac12\)시간, 곧 30분이다. 서비스 시간의 평균이 6분이므로 \(W_q = 24\)분이다. 서비스 자체보다 기다리는 시간이 4배나 길다.

4.3.3\(\rho \to 1\)의 폭발

\(W = \frac1\mu\cdot\frac1{1 - \rho}\)이므로, 그림 1처럼 이용률이 0.8에서 0.9로 오르면 \(W\)가 2배가 되고 0.99이면 0.8일 때의 20배가 된다. 평균적으로 처리 능력이 남아도 도착과 서비스가 무작위로 흔들리기 때문이다. 창구가 노는 시간은 되돌릴 수 없는 손실이고, 그사이에 쌓인 줄은 천천히만 줄어든다. 그래서 실제 서비스 설계에서는 \(\rho\)를 0.7에서 0.85 정도로 둔다.

창구를 \(c\)개로 늘린 M/M/c는 4.2절에서 \(\mu_n = \min(n, c)\mu\)로 두면 같은 방식으로 풀린다. 이때 한 줄로 서서 빈 창구로 가는 것이 창구마다 따로 줄을 서는 것보다 대기 시간이 짧으며, 이는 연습문제 3에서 확인한다.

흔한 오해처리 능력이 도착보다 크면 줄이 생기지 않는다고 여기기 쉽지만, 무작위성 때문에 평균 \(\frac{\rho^2}{1 - \rho}\)명이 기다린다. 또 대기 시간이 이용률에 비례해 는다고 생각하는 것도 틀렸다. 대기 시간은 \(\frac1{1 - \rho}\)로 늘어나므로 \(\rho\)가 1 근처에서 폭발한다.
마무리

처음 질문에 답하면, 처리 능력이 남아도 줄은 생긴다. 시간당 8명이 오고 10명을 처리하면 평균 4명이 시스템에 있고, 리틀 공식 \(L = \lambda W\)로 한 사람이 평균 30분 머물며 그중 24분을 기다린다. 손님이 조금 더 늘어 이용률이 1에 다가가면 체류 시간이 \(\frac1{1 - \rho}\)로 폭발한다.

4.3.4연습문제

기본

  1. 시간당 5명이 오고 평균 서비스 시간이 10분이다. \(L\), \(W\), \(W_q\)를 구하여라.
    답

    \(\mu = 6\), \(\rho = \frac56\). \(L = 5\), \(W = 1\)시간, \(W_q = \frac56\)시간 = 50분.

응용

  1. 1번에서 평균 대기 시간 \(W_q\)를 10분 이하로 줄이려면 서비스 비율 \(\mu\)가 최소 얼마여야 하는가?
    답

    \(\frac{5/\mu}{\mu - 5} \le \frac16\): \(30 \le \mu^2 - 5\mu\), \(\mu \ge \frac{5 + \sqrt{145}}2 \approx 8.52\) (시간당).

심화

  1. \(\lambda = 1.6\), \(\mu = 1\)일 때 (가) 두 창구가 따로 줄을 받아 손님이 반반 나뉘는 경우(각각 M/M/1, \(\lambda = 0.8\))와 (나) 한 줄 두 창구(M/M/2)의 평균 체류 시간 \(W\)를 비교하여라.
    답

    (가) \(W = \frac1{1 - 0.8} = 5\). (나) \(\theta_n = 1.6\cdot0.8^{n-1}\) (\(n \ge 1\)), \(\sum\theta = 1 + 8 = 9\), \(L = \frac19\sum n\theta_n = \frac{1.6}9\sum_{n\ge1}n0.8^{n-1} = \frac{1.6}9\cdot25 \approx 4.44\), \(W = \frac L{1.6} \approx 2.78\). 한 줄이 훨씬 빠르다.
