M/M/1 대기행렬과 리틀 공식

본문
이 절에서 배울 것
  • M/M/1의 평균 인원 \(L = \frac\rho{1 - \rho}\)을 정상분포에서 구한다.
  • 리틀 공식 \(L = \lambda W\)로 평균 체류 시간 \(W = \frac1{\mu - \lambda}\)과 평균 대기 시간 \(W_q\)를 얻는다.
  • 이용률 \(\rho\)가 1에 가까워질 때 대기 시간이 폭발하는 이유를 설명한다.
먼저 알아야 할 것
  • M/M/1의 정상분포 \((1 - \rho)\rho^n\) (4.2절), 기하분포의 평균.

4.3.1평균 인원

M/M/1(도착은 포아송, 서비스는 지수분포, 창구 1개)에서 \(\rho = \frac\lambda\mu < 1\)이면 정상 상태의 인원 \(N\)은 \(P(N = n) = (1 - \rho)\rho^n\)입니다.

\[L = E[N] = \sum_nn(1 - \rho)\rho^n = \frac\rho{1 - \rho}, \qquad L_q = E[\max(N - 1, 0)] = \frac{\rho^2}{1 - \rho}.\]

\(L_q\)는 서비스 중인 사람을 뺀 줄의 길이이고, \(L - L_q = \rho\)는 창구가 바쁜 확률입니다.

4.3.2리틀 공식

정리 4.3.1 (리틀) 장기적으로 안정된 대기 시스템에서 (평균 인원) = (도착 비율) × (평균 체류 시간), 즉 \(L = \lambda W\).
증명의 흐름

시간 \([0, T]\) 동안 각 손님이 머문 시간을 모두 더한 양을 두 가지로 센다. 시각마다 인원을 적분하면 약 \(LT\), 손님마다 체류 시간을 더하면 약 \((\lambda T)W\). \(T \to \infty\)이면 둘이 같다. ∎

리틀 공식은 도착과 서비스의 분포와 무관하게 성립해 매우 넓게 쓰입니다. M/M/1에서는

\[W = \frac L\lambda = \frac1{\mu - \lambda}, \qquad W_q = \frac{L_q}\lambda = \frac\rho{\mu - \lambda} = W - \frac1\mu.\]
예 4.3.2 시간당 8명이 오고 창구가 시간당 10명을 처리합니다. \(\rho = 0.8\), \(L = 4\)명, \(W = \frac12\)시간 = 30분, \(W_q = 24\)분입니다. 서비스 자체는 평균 6분인데 기다리는 시간이 그 4배입니다.

4.3.3\(\rho \to 1\)의 폭발

\(W = \frac1\mu\cdot\frac1{1 - \rho}\)이라 이용률이 0.8에서 0.9로 오르면 \(W\)가 2배, 0.99이면 20배가 됩니다. 평균적으로 처리 능력이 남아도(\(\lambda < \mu\)) 도착과 서비스가 무작위로 흔들리면 창구가 노는 시간은 되돌릴 수 없는 손실이고, 그사이 쌓인 줄은 천천히만 줄어듭니다. 그래서 실제 서비스 설계는 \(\rho\)를 0.7~0.85 정도로 둡니다.

창구를 \(c\)개로 늘린 M/M/c는 4.2절의 \(\mu_n = \min(n, c)\mu\)로 같은 방식으로 풀립니다. 한 줄에서 여러 창구로 나눠 가는 것이 창구마다 따로 줄을 서는 것보다 대기 시간이 짧습니다(연습문제 3).

흔한 오해(1) 처리 능력이 도착보다 크면 줄이 생기지 않는다고 여긴다. 무작위성 때문에 평균 \(\frac{\rho^2}{1 - \rho}\)명이 기다린다. (2) 대기 시간이 이용률에 비례해 는다고 여긴다. \(\frac1{1 - \rho}\)로 늘어 1 근처에서 폭발한다.
요약
  1. \(L = \frac\rho{1 - \rho}\), \(L_q = \frac{\rho^2}{1 - \rho}\).
  2. 리틀 공식 \(L = \lambda W\): \(W = \frac1{\mu - \lambda}\), \(W_q = \frac\rho{\mu - \lambda}\).
  3. \(\rho \to 1\)이면 대기 시간이 \(\frac1{1 - \rho}\)로 폭발.

4.3.4연습문제

기본

  1. 시간당 5명이 오고 평균 서비스 시간이 10분이다. \(L\), \(W\), \(W_q\)를 구하여라.
    답

    \(\mu = 6\), \(\rho = \frac56\). \(L = 5\), \(W = 1\)시간, \(W_q = \frac56\)시간 = 50분.

응용

  1. 1번에서 평균 대기 시간 \(W_q\)를 10분 이하로 줄이려면 서비스 비율 \(\mu\)가 최소 얼마여야 하는가?
    답

    \(\frac{5/\mu}{\mu - 5} \le \frac16\): \(30 \le \mu^2 - 5\mu\), \(\mu \ge \frac{5 + \sqrt{145}}2 \approx 8.52\) (시간당).

심화

  1. \(\lambda = 1.6\), \(\mu = 1\)일 때 (가) 두 창구가 따로 줄을 받아 손님이 반반 나뉘는 경우(각각 M/M/1, \(\lambda = 0.8\))와 (나) 한 줄 두 창구(M/M/2)의 평균 체류 시간 \(W\)를 비교하여라.
    답

    (가) \(W = \frac1{1 - 0.8} = 5\). (나) \(\theta_n = 1.6\cdot0.8^{n-1}\) (\(n \ge 1\)), \(\sum\theta = 1 + 8 = 9\), \(L = \frac19\sum n\theta_n = \frac{1.6}9\sum_{n\ge1}n0.8^{n-1} = \frac{1.6}9\cdot25 \approx 4.44\), \(W = \frac L{1.6} \approx 2.78\). 한 줄이 훨씬 빠르다.
