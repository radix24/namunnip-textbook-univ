여과와 마팅게일

본문

공정한 게임이란 무엇일까? 지금까지의 결과를 다 보고 나서도 다음 판의 재산을 예측하면 지금 재산 그대로인 게임이라고 할 수 있을까? 그렇다면 판돈을 영리하게 바꾸는 전략으로 이런 게임에서 평균적으로 이길 수 있을까?

먼저 알아야 할 것조건부 기대값과 반복 기대값 법칙(1.1절)을 쓴다.

6.1.1여과

\(\mathcal F_n\)을 시각 \(n\)까지 관찰한 정보라 하자. 구체적으로는 \(X_1, \dots, X_n\)을 보았을 때 일어났는지 알 수 있는 사건들의 모임이다. 시간이 지나면 정보가 늘어나므로 \(\mathcal F_0 \subset \mathcal F_1 \subset \cdots\)이며, 이를 여과라 한다. \(E[Y \mid \mathcal F_n]\)은 \(E[Y \mid X_1, \dots, X_n]\)과 같은 뜻이고, 1.1절에서처럼 지금까지 본 것으로 내린 \(Y\)의 가장 좋은 예측이다.

6.1.2마팅게일

각 \(M_n\)이 \(\mathcal F_n\)의 정보로 정해지고 \(E|M_n| < \infty\)이며 다음을 만족하면 \(M_n\)을 마팅게일이라 한다.

\[E[M_{n+1} \mid \mathcal F_n] = M_n\]

지금까지의 모든 것을 알아도 다음 값의 예측은 지금 값 그대로라는 뜻이다. 공정한 게임에서의 재산이 전형적인 예이다. 등호 대신 \(\le\)이면 불리한 게임에 해당하는 우마팅게일, \(\ge\)이면 열마팅게일이라 한다. 반복 기대값 법칙에 의해 마팅게일은 모든 \(n\)에서 \(E[M_n] = E[M_0]\)이다.

예제 6.1.1

\(X_i\)가 독립이고 \(P(X_i = 1) = p\), \(P(X_i = -1) = q = 1 - p\)이며 \(S_n = X_1 + \cdots + X_n\)이다. \(S_n\)으로 만든 마팅게일을 찾아라.

풀이. \(p = \frac12\)이면 \(E[S_{n+1} \mid \mathcal F_n] = S_n + E[X_{n+1}] = S_n\)이므로 \(S_n\)은 마팅게일이다. 이때 \(E[(S_n + X)^2 \mid \mathcal F_n] = S_n^2 + 2S_nE[X] + 1 = S_n^2 + 1\)이므로 \(S_n^2 - n\)도 마팅게일이다. 일반적인 \(p\)에서는 \(S_n - n(p - q)\)가 마팅게일이다. 또 \(E\left[\left(\frac qp\right)^X\right] = p\cdot\frac qp + q\cdot\frac pq = 1\)이므로 \(\left(\frac qp\right)^{S_n}\)도 마팅게일이다.

그 밖에 \(Y\)를 하나 정하고 \(M_n = E[Y \mid \mathcal F_n]\)으로 두면 늘 마팅게일이다. 이것을 두브 마팅게일이라 하며, 정보가 쌓이면서 다듬어지는 예측이다. 또 평균이 1인 독립 확률변수들의 곱 \(\prod_{i\le n}Z_i\)도 마팅게일이다.

6.1.3베팅 전략

\(n\)번째 판의 판돈 \(H_n\)을 그 직전까지의 정보로, 곧 미래를 보지 않고 정한다고 하자. 그러면 재산은 \(W_n = W_0 + \sum_{k\le n}H_k(M_k - M_{k-1})\)이다.

정리 6.1.2

\(M\)이 마팅게일이고 \(H_k\)가 \(\mathcal F_{k-1}\)로 정해지며 유계이면 \(W_n\)도 마팅게일이다. 특히 \(E[W_n] = W_0\)이다.

증명.\(H_{n+1}\)은 \(\mathcal F_n\)으로 정해지므로 조건부 기대값에서 상수처럼 밖으로 나온다. 따라서 \(E[H_{n+1}(M_{n+1} - M_n) \mid \mathcal F_n] = H_{n+1}E[M_{n+1} - M_n \mid \mathcal F_n] = 0\)이다. ∎

그러므로 잃으면 판돈을 두 배로 올리는 전략도 유한한 시간 안에서는 평균 이득이 0이다. 결국 한 번은 이기니 반드시 번다는 주장은 무한한 자금과 시간을 가정한 것이며, 6.2절에서 선택 정지 정리의 조건이 깨지는 예로 다시 본다.

흔한 오해마팅게일이면 증분이 서로 독립이라고 여기기 쉽지만, 증분의 조건부 평균만 0이면 되고 그 크기는 과거에 의존해도 된다. 또 \(E[M_n] = E[M_0]\)이기만 하면 마팅게일이라고 생각하는 것도 틀렸다. 평균이 일정한 것은 필요조건일 뿐이고, 조건부 기대값에 대한 조건이 정의이다.
마무리

처음 질문에 답하면, 공정한 게임의 재산은 \(E[M_{n+1} \mid \mathcal F_n] = M_n\)을 만족하는 마팅게일로 정확히 표현된다. 판돈을 직전까지의 정보로만 정하는 한, 어떤 베팅 전략을 써도 재산은 다시 마팅게일이다. 따라서 유한한 시간 안에서는 평균 이득이 0이고, 영리한 전략으로도 평균적으로 이길 수 없다.

6.1.4연습문제

기본

  1. \(p = 0.6\)인 랜덤워크에서 \(S_n\)은 마팅게일, 우마팅게일, 열마팅게일 중 무엇인가?
    답

    \(E[X] = 0.2 > 0\)이라 열마팅게일.

응용

  1. \(X_i\)가 독립이고 \(E[X_i] = 0\), \(\operatorname{Var}X_i = \sigma^2\)이면 \(S_n^2 - n\sigma^2\)이 마팅게일임을 보여라.
    답

    \(E[(S_n + X_{n+1})^2 \mid \mathcal F_n] = S_n^2 + 2S_n\cdot0 + \sigma^2\). \(-(n + 1)\sigma^2\)를 빼면 \(S_n^2 - n\sigma^2\).

심화

  1. 공정한 랜덤워크에서 \(e^{\theta S_n}(\cosh\theta)^{-n}\)이 마팅게일임을 보여라.
    답

    \(E[e^{\theta X}] = \frac{e^\theta + e^{-\theta}}2 = \cosh\theta\)라 \(E[e^{\theta S_{n+1}} \mid \mathcal F_n] = e^{\theta S_n}\cosh\theta\). \((\cosh\theta)^{-(n+1)}\)을 곱하면 된다.
