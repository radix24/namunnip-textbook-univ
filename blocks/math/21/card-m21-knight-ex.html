체스판 구석으로 돌아오는 나이트

예제 · 차수로 정상분포 읽기

먼저 예측

나이트가 64칸 위를 무작위로 뛰어다닌다. 구석에서 출발해 다시 구석으로 돌아오는 평균 수는 64보다 클까, 작을까?

예측 확인

훨씬 큽니다(168). 구석은 갈 수 있는 칸이 2개뿐이라 잘 들르지 않는 칸이다.

8×8 체스판의 나이트가 매번 갈 수 있는 칸 가운데 하나를 같은 확률로 골라 움직인다. 구석 칸에서 출발해 다시 그 칸으로 돌아오기까지 평균 몇 수가 걸리는가?

전략

칸을 꼭짓점, 나이트로 한 번에 갈 수 있는 두 칸을 변으로 하는 그래프 위의 랜덤워크이다. 정상분포 \(\pi_v = \frac{\deg v}{2|E|}\) (2.5절)와 평균 재귀 시간 \(\frac1{\pi_v}\) (2.3절)을 쓴다.

풀이

  1. 칸별 차수(갈 수 있는 칸 수): 구석 2(4칸), 구석 옆 변 3(8칸), 나머지 변 4(16칸), 둘째 줄 구석 4(4칸), 둘째 줄 나머지 6(16칸), 가운데 4×4 8(16칸).
    칸 수의 합 \(4 + 8 + 16 + 4 + 16 + 16 = 64\).
  2. \(2|E| = 4\cdot2 + 8\cdot3 + 16\cdot4 + 4\cdot4 + 16\cdot6 + 16\cdot8 = 8 + 24 + 64 + 16 + 96 + 128 = 336\).
    차수의 합은 변 수의 두 배.
  3. 그래프는 연결되어 있어 연쇄가 기약이고, 정상분포는 \(\pi_{\text{corner}} = \frac2{336} = \frac1{168}\).
    정리 2.5.2.
  4. 평균 재귀 시간 \(\frac1{\pi} = 168\)수.
    \(\pi_j = \frac1{m_j}\).

검산

모든 칸의 \(\pi\)를 더하면 \(\frac{336}{336} = 1\)이다. 가운데 칸(차수 8)의 재귀 시간은 \(\frac{336}8 = 42\)로 구석의 \(\frac14\)이고, 차수 비 \(\frac28\)과 맞다. 나이트 그래프는 이분 그래프(칸 색이 매번 바뀜)라 주기 2지만, 평균 재귀 시간 공식은 주기와 무관하게 성립한다.

의미

64개 미지수의 연립방정식 \(\pi P = \pi\)를 풀지 않고 차수만 세서 답을 얻었다. 상세균형이 성립하는 가역 연쇄에서만 가능한 지름길이다. 웹 페이지 순위(PageRank)도 링크 그래프 위 랜덤워크의 정상분포라는 같은 생각에서 나왔다.

이해 확인
