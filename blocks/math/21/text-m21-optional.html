정지 시각과 선택 정지 정리

본문
이 절에서 배울 것
  • 미래를 보지 않고 정하는 정지 시각을 정의한다.
  • 선택 정지 정리 \(E[M_T] = E[M_0]\)의 조건을 알고, 조건이 깨지는 예를 본다.
  • 도박꾼 파산 문제의 확률과 기대 시간을 마팅게일로 구한다.
먼저 알아야 할 것
  • 마팅게일과 랜덤워크의 예 (6.1절), 도달 확률 (1.2절).

6.2.1정지 시각

음이 아닌 정수값 확률변수 \(T\)가, 각 \(n\)에서 "\(T = n\)인가"를 시각 \(n\)까지의 정보 \(\mathcal F_n\)만으로 판단할 수 있으면 정지 시각입니다. "처음으로 \(a\)에 닿는 시각"은 정지 시각이지만, "마지막으로 \(a\)에 있는 시각"은 미래를 봐야 알 수 있으므로 아닙니다.

6.2.2선택 정지 정리

정리 6.2.1 \(M\)이 마팅게일, \(T\)가 정지 시각이고 다음 가운데 하나가 성립하면 \(E[M_T] = E[M_0]\)이다.
  1. \(T \le K\)인 상수 \(K\)가 있다.
  2. \(T < \infty\)이고 \(|M_{n\wedge T}| \le C\)인 상수 \(C\)가 있다(멈추기 전까지 유계).
  3. \(E[T] < \infty\)이고 \(|M_{n+1} - M_n| \le C\)이다.
증명의 흐름

멈춘 과정 \(M_{n\wedge T}\)는 "\(T\) 전까지 판돈 1, 이후 0"인 베팅 전략이라 정리 6.1.2로 마팅게일이고 \(E[M_{n\wedge T}] = E[M_0]\). (1)은 \(n = K\)로 끝. (2), (3)은 \(n \to \infty\)의 극한을 기대값 안으로 넣는 근거(유계 수렴 정리, 지배 수렴 정리)이다. ∎

예 6.2.2 (조건이 깨지는 예) 공정한 랜덤워크가 처음 1에 닿는 시각 \(T\)는 확률 1로 유한하지만(2.2절의 재귀성) \(S_T = 1\)이라 \(E[S_T] = 1 \ne 0\)입니다. \(S_{n\wedge T}\)는 아래로 유계가 아니고 \(E[T] = \infty\)라 세 조건 모두 깨집니다. 판돈을 두 배씩 올리는 전략도 같은 이유로 실제로는 통하지 않습니다.

6.2.3도박꾼 파산

\(0 < i < N\)에서 출발해 0 또는 \(N\)에 닿으면 멈추는 시각 \(T\)를 봅니다. 멈추기 전까지 \(S\)는 \([0, N]\) 안에 있어 조건 (2)가 성립합니다.

정리 6.2.3 \(p = \frac12\)이면 \(P(S_T = N) = \frac iN\), \(E[T] = i(N - i)\). \(p \ne \frac12\), \(r = \frac qp\)이면 \(P(S_T = N) = \frac{1 - r^i}{1 - r^N}\), \(E[T] = \frac{P(S_T = N)N - i}{p - q}\).
증명

\(p = \frac12\): \(E[S_T] = i\)이고 \(S_T \in \{0, N\}\)이라 \(N\cdot P(S_T = N) = i\). \(S_n^2 - n\)에 정리를 쓰면(\(E[T] < \infty\)는 따로 보일 수 있다) \(E[S_T^2] - E[T] = i^2\), \(E[S_T^2] = N^2\cdot\frac iN = Ni\)이라 \(E[T] = Ni - i^2\). \(p \ne \frac12\): \(r^{S_n}\)에서 \(r^N P + (1 - P) = r^i\), \(S_n - n(p - q)\)에서 \(E[S_T] - (p - q)E[T] = i\). ∎

1.2절에서 점화식으로 구한 결과를 연립방정식 없이 한 줄로 얻습니다. 마팅게일을 잘 고르는 것이 기술입니다.

흔한 오해(1) \(T\)가 유한하기만 하면 \(E[M_T] = E[M_0]\)이라 여긴다. 예 6.2.2처럼 깨진다. (2) 유리한 게임(\(p > \frac12\))이면 파산하지 않는다고 여긴다. 자금 \(i\)가 작으면 \(r^i\)만큼의 파산 확률이 남는다(\(N \to \infty\)).
요약
  1. 정지 시각: 지금까지의 정보로 멈출지 판단.
  2. 선택 정지 정리: 유계 시간, 유계 과정, 또는 \(E[T] < \infty\)와 유계 증분이면 \(E[M_T] = E[M_0]\).
  3. 도박꾼 파산: \(\frac iN\), \(i(N - i)\) (공정), \(\frac{1 - r^i}{1 - r^N}\) (불공정).

6.2.4연습문제

기본

  1. 공정한 게임에서 3만 원으로 시작해 10만 원이 되거나 다 잃으면 멈춘다(한 판 1만 원). 10만 원에 닿을 확률과 평균 판 수를 구하여라.
    답

    \(\frac3{10}\), \(3\cdot7 = 21\)판.

응용

  1. 1번에서 이길 확률이 0.45이면 10만 원에 닿을 확률은?
    답

    \(r = \frac{0.55}{0.45} = \frac{11}9\). \(\frac{r^3 - 1}{r^{10} - 1} = \frac{0.8258}{6.4388} \approx 0.128\).

심화

  1. \(X_i \ge 0\), \(E[X_i] = \mu\)인 독립 확률변수와 정지 시각 \(T\) (\(E[T] < \infty\))에 대해 왈드 등식 \(E\left[\sum_{i\le T}X_i\right] = \mu E[T]\)를 마팅게일로 설명하여라.
    답

    \(M_n = \sum_{i\le n}X_i - n\mu\)는 마팅게일. \(E[M_{n\wedge T}] = 0\)에서 \(n \to \infty\)이면 단조 수렴으로 \(E\left[\sum_{i\le T}X_i\right] = \mu E[T]\).
