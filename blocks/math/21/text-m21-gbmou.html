기하 브라운 운동과 Ornstein-Uhlenbeck 과정

본문

주가는 음수가 되지 않고 대략 비율로 변한다. 반면 마찰을 받는 입자의 속도는 0 근처로 끌려가며 흔들린다. 두 현상을 나타내는 가장 간단한 확률미분방정식은 무엇이고, 그 해를 정확히 적을 수 있을까?

먼저 알아야 할 것Itô 공식(9.2절), 해의 존재와 유일성(10.1절), 일계 선형 상미분방정식의 적분인자를 쓴다. Evans 5장 1~2절을 따른다.

10.2.1기하 브라운 운동

\(dS = \mu S\,dt + \sigma S\,dW\)는 수익률 \(dS/S\)이 평균 \(\mu\,dt\)에 잡음 \(\sigma\,dW\)를 더한 것이라는 모형이다. 보통의 미적분이라면 \(\log S\)를 미분해 \(d\log S = dS/S\)로 풀었을 것이다. 그런데 Itô 공식에서는 \(f(x) = \log x\)의 2차 항이 남는다.

\[d\log S = \frac{dS}{S} - \frac{1}{2}\frac{(dS)^2}{S^2} = \left(\mu - \tfrac12\sigma^2\right)dt + \sigma\,dW.\]

오른쪽은 계수가 상수라 바로 적분된다. 따라서 \(S(t) = S_0\exp\left((\mu - \frac12\sigma^2)t + \sigma W(t)\right)\)이다. 이 해는 언제나 양수이고, \(\log S(t)\)는 정규분포를 따른다. 그런데 평균은 \(E[S(t)] = S_0e^{\mu t}\)인 반면, 전형적인 경로는 \(e^{(\mu - \sigma^2/2)t}\)로 자란다. \(\mu < \frac12\sigma^2\)이면 평균은 늘어나는데 거의 모든 경로는 0으로 간다.

10.2.2Ornstein-Uhlenbeck 과정

\(dY = -bY\,dt + \sigma\,dW\)(\(b > 0\))는 마찰 \(-bY\)와 일정한 잡음을 받는 속도의 Langevin 방정식이다. 상미분방정식의 적분인자 \(e^{bt}\)를 그대로 쓰자. Itô 공식에서 \(e^{bt}Y\)는 \(x\)에 대해 일차라 2차 항이 없으므로 \(d(e^{bt}Y) = e^{bt}(dY + bY\,dt) = \sigma e^{bt}dW\)이다. 적분하면

\[Y(t) = e^{-bt}Y_0 + \sigma\int_0^te^{-b(t - s)}dW(s)\]

이다. 둘째 항은 결정론적 함수의 Itô 적분이라 평균 0인 정규분포이고, 등거리로 분산이 \(\sigma^2\int_0^te^{-2b(t-s)}ds = \frac{\sigma^2}{2b}(1 - e^{-2bt})\)이다. 그러면 \(t \to \infty\)에서 \(Y(t)\)는 \(N(0, \frac{\sigma^2}{2b})\)로 수렴하고, 이것이 정상분포이다.

예제 10.2.1

주가가 \(\mu = 0.05\), \(\sigma = 0.4\)(연 단위)인 기하 브라운 운동일 때, 10년 뒤 주가의 평균과 중앙값을 처음 값과 비교하여라.

풀이. 평균은 \(e^{0.05\times10} = e^{0.5} \approx 1.65\)배이다. 중앙값은 \(\log S\)의 중앙값 \((\mu - \frac12\sigma^2)t = (0.05 - 0.08)\times10 = -0.3\)에서 \(e^{-0.3} \approx 0.74\)배이다. 그러면 평균은 65% 오르는데, 절반 이상의 경로에서는 26% 넘게 떨어진다. 변동성이 크면 소수의 큰 상승이 평균을 끌어올린다는 것이 \(-\frac12\sigma^2\) 보정의 뜻이다.

마무리

기하 브라운 운동 \(dS = \mu S\,dt + \sigma S\,dW\)는 \(\log S\)를 Itô 공식으로 미분해 \(S = S_0e^{(\mu - \sigma^2/2)t + \sigma W}\)로 풀리고, \(-\frac12\sigma^2\) 보정 때문에 평균과 전형적인 경로가 다르게 자란다. Ornstein-Uhlenbeck 과정은 적분인자로 풀리는 가우스 과정이며, 정상분포 \(N(0, \sigma^2/2b)\)로 수렴한다.

10.2.3연습문제

기본

  1. 기하 브라운 운동에서 \(E[S(t)] = S_0e^{\mu t}\)임을 해의 식과 정규분포의 적률생성함수로 보여라.
    답

    \(E[e^{\sigma W_t}] = e^{\sigma^2t/2}\)이 \(e^{-\sigma^2t/2}\)를 상쇄한다.

응용

  1. OU 과정에서 \(s < t\)일 때 \(\operatorname{Cov}(Y_s, Y_t)\)를 정상 상태에서 구하여라.
    답

    \(\frac{\sigma^2}{2b}e^{-b(t - s)}\). 시간 차가 커질수록 지수적으로 상관이 사라진다.
