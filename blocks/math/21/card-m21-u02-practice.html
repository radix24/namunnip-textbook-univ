이산시간 마르코프 연쇄 연습 문제

문제 6 · 계산·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(P = \begin{pmatrix}0.5 & 0.5\\ 0.2 & 0.8\end{pmatrix}\)에서 \(p_{11}^{(2)}\)와 정상분포를 구하여라. [02-01 02-03]

    힌트 1

    \(P^2\)의 (1, 1) 성분.

    힌트 2

    두 상태 연쇄: \(\pi = \left(\frac b{a + b}, \frac a{a + b}\right)\).

    풀이

    \(p_{11}^{(2)} = 0.25 + 0.1 = 0.35\). \(a = 0.5\), \(b = 0.2\)이라 \(\pi = \left(\frac27, \frac57\right)\) (2.1절).

  2. 판단상태 1~4에서 \(p_{12} = 1\), \(p_{21} = p_{23} = \frac12\), \(p_{34} = 1\), \(p_{43} = 1\)이다. 류, 재귀·일시, 주기를 판정하여라. [02-02]

    힌트 1

    \(\{3, 4\}\)에서 나갈 수 있는가?

    힌트 2

    \(\{1, 2\}\)에서는 3으로 새어 나간다.

    풀이

    \(\{1, 2\}\): 일시(언젠가 3으로 가서 돌아오지 않음). \(\{3, 4\}\): 닫힌 류라 재귀, 3 → 4 → 3만 가능해 주기 2 (2.2절).

  3. 판단\(P = \begin{pmatrix}0 & 1 & 0\\ \frac12 & 0 & \frac12\\ 0 & 1 & 0\end{pmatrix}\)의 정상분포를 구하고, \(p_{11}^{(n)}\)이 수렴하는지 판단하여라. 상태 1의 평균 재귀 시간은? [02-03]

    힌트 1

    꼭짓점 3개인 경로 그래프 위 랜덤워크.

    힌트 2

    홀수 걸음에는 1로 돌아올 수 없다.

    풀이

    \(\pi = \left(\frac14, \frac12, \frac14\right)\). 주기 2라 \(p_{11}^{(n)}\)은 \(0, \frac12, 0, \frac12, \dots\)로 진동해 수렴하지 않는다. 그래도 \(m_1 = \frac1{\pi_1} = 4\) (2.3절).

  4. 계산\(0, \dots, 4\) 위의 공정한 랜덤워크(0, 4 흡수)에서 1에서 출발할 때 파산(0에 흡수) 확률과, 2에서 출발할 때 기대 흡수 시간을 구하여라. [02-04]

    힌트 1

    \(N\)을 직접 구해도 되지만 공식이 빠르다.

    힌트 2

    \(N\)에 닿을 확률 \(\frac iN\), \(E[T] = i(N - i)\).

    풀이

    파산 \(1 - \frac14 = \frac34\). \(E[T] = 2\cdot2 = 4\). 기본 행렬 \(N = (I - Q)^{-1}\)의 둘째 행의 합도 4다 (2.4절).

  5. 계산상태 \(\{0, 1, 2\}\)에서 \(p_{00} = \frac12\), \(p_{01} = \frac12\), \(p_{10} = \frac14\), \(p_{11} = \frac14\), \(p_{12} = \frac12\), \(p_{21} = \frac14\), \(p_{22} = \frac34\)이다. 상세균형으로 정상분포를 구하여라. [02-05]

    힌트 1

    이웃으로만 움직이므로 가역이다.

    힌트 2

    \(\frac{\pi_1}{\pi_0} = \frac{p_{01}}{p_{10}}\).

    풀이

    \(\pi_1 = 2\pi_0\), \(\pi_2 = \pi_1\cdot\frac{1/2}{1/4} = 4\pi_0\). \(\pi = \left(\frac17, \frac27, \frac47\right)\) (2.5절).

  6. 판단"상태가 유한하고 기약인 마르코프 연쇄는 \(P^n\)이 늘 수렴한다." 참인지 판단하여라. [02-02 02-03]

    힌트 1

    3번 문제를 다시 본다.

    힌트 2

    극한 정리에는 비주기 조건이 있다.

    풀이

    거짓. 주기가 있으면 진동한다(3번). 유한 기약이면 정상분포가 유일하게 있고 시간 평균은 수렴하지만, \(P^n\) 자체의 수렴에는 비주기가 필요하다.
