생성 행렬과 콜모고로프 방정식

본문
이 절에서 배울 것
  • 연속시간 마르코프 연쇄를 "지수분포 시간만큼 머문 뒤 뛰는" 과정으로 이해한다.
  • 전이 비율 \(q_{ij}\)로 생성 행렬 \(Q\)를 만들고 \(P'(t) = QP(t) = P(t)Q\)를 유도한다.
  • 두 상태 연쇄의 \(P(t)\)를 풀고, 정상분포 조건 \(\pi Q = 0\)을 안다.
먼저 알아야 할 것
  • 이산시간 연쇄 (2.1절), 지수분포의 최솟값 (3.1절), 일계 선형 미분방정식.

4.1.1머무르고 뛰기

시간이 연속인 과정 \(X(t)\)가 시각 \(s\)까지의 과거가 어떻든 \(P(X(t + s) = j \mid X(s) = i) = P_{ij}(t)\)가 성립하면 연속시간 마르코프 연쇄입니다. 상태 \(i\)에 머무는 시간은 무기억성 때문에 지수분포 \(\text{Exp}(q_i)\)여야 합니다. 머문 뒤에는 확률 \(r_{ij}\)로 \(j\)로 뜁니다. 그래서

\[q_{ij} = q_ir_{ij} \quad (j \ne i)\]

를 \(i\)에서 \(j\)로 가는 전이 비율이라 합니다. 같은 말로, \(i\)에서 각 \(j\)로 가는 "알람"이 비율 \(q_{ij}\)인 지수분포로 따로 울리고 가장 먼저 울리는 곳으로 간다고 보아도 됩니다(3.1절의 경쟁).

4.1.2생성 행렬

\(Q_{ij} = q_{ij}\) (\(j \ne i\)), \(Q_{ii} = -q_i = -\sum_{j\ne i}q_{ij}\)로 놓은 행렬 \(Q\)를 생성 행렬이라 합니다. 각 행의 합은 0입니다. 짧은 시간 \(h\)에 대해 \(P_{ij}(h) = q_{ij}h + o(h)\), \(P_{ii}(h) = 1 - q_ih + o(h)\), 즉 \(P(h) = I + hQ + o(h)\)입니다.

정리 4.1.1 (콜모고로프 방정식) \(P(t + h) = P(t)P(h) = P(h)P(t)\) (채프만-콜모고로프)에서 \[P'(t) = QP(t) \ (\text{backward}), \qquad P'(t) = P(t)Q \ (\text{forward}), \qquad P(0) = I.\] 상태가 유한하면 해는 \(P(t) = e^{tQ} = \sum_n\frac{t^nQ^n}{n!}\)이다.

\(\frac{P(t + h) - P(t)}h = P(t)\frac{P(h) - I}h \to P(t)Q\)가 앞 방정식, 곱하는 순서를 바꾸면 뒤 방정식입니다.

4.1.3두 상태 연쇄

예 4.1.2 기계가 작동(0)하다가 비율 \(\alpha\)로 고장(1) 나고, 비율 \(\beta\)로 수리됩니다. \(Q = \begin{pmatrix}-\alpha & \alpha\\ \beta & -\beta\end{pmatrix}\). 앞 방정식의 (0, 0) 성분은 \(P_{00}' = -\alpha P_{00} + \beta P_{01} = -\alpha P_{00} + \beta(1 - P_{00})\)이라 \[P_{00}(t) = \frac\beta{\alpha + \beta} + \frac\alpha{\alpha + \beta}e^{-(\alpha + \beta)t}.\] 장기적으로 작동하는 비율은 \(\frac\beta{\alpha + \beta}\)입니다. 고장 비율이 하루 0.1, 수리 비율이 하루 0.9이면 90%입니다.

4.1.4정상분포

\(\pi P(t) = \pi\)가 모든 \(t\)에서 성립하는 것은 \(\pi Q = 0\)과 동치입니다. 성분으로 쓰면 \(\pi_jq_j = \sum_{i\ne j}\pi_iq_{ij}\), "\(j\)에서 나가는 비율 = \(j\)로 들어오는 비율"입니다. 기약이고 정상분포가 있으면 \(P_{ij}(t) \to \pi_j\)입니다. 연속시간에는 주기 문제가 없습니다.

주의: \(\pi\)는 뛰는 순서만 본 이산 연쇄 \((r_{ij})\)의 정상분포 \(\nu\)와 다릅니다. 머무는 시간까지 반영하면 \(\pi_j \propto \frac{\nu_j}{q_j}\)입니다.

흔한 오해(1) \(Q\)의 대각 성분도 확률이라 여긴다. 비율이고 대각은 음수, 행 합은 0이다. (2) \(e^{tQ}\)를 성분마다 \(e^{tq_{ij}}\)로 계산한다. 행렬 지수함수는 성분별 지수가 아니다.
요약
  1. 상태 \(i\)에 \(\text{Exp}(q_i)\)만큼 머물고, \(j\)로 가는 비율은 \(q_{ij}\).
  2. \(P' = QP = PQ\), \(P(t) = e^{tQ}\).
  3. 정상분포: \(\pi Q = 0\), 나가는 비율 = 들어오는 비율.

4.1.5연습문제

기본

  1. 예 4.1.2에서 \(\alpha = 1\), \(\beta = 3\)일 때 작동 중이던 기계가 시간 1 뒤에도 작동 중일 확률을 구하여라.
    답

    \(\frac34 + \frac14e^{-4} \approx 0.7546\).

응용

  1. 상태 \(\{1, 2, 3\}\)에서 \(q_{12} = 2\), \(q_{23} = 1\), \(q_{31} = 3\)이고 나머지 비율이 0이다. \(Q\)를 쓰고 정상분포를 구하여라.
    답

    \(Q = \begin{pmatrix}-2 & 2 & 0\\ 0 & -1 & 1\\ 3 & 0 & -3\end{pmatrix}\). \(2\pi_1 = 3\pi_3\), \(\pi_2 = 2\pi_1\): \(\pi \propto (3, 6, 2)\), \(\pi = \left(\frac3{11}, \frac6{11}, \frac2{11}\right)\).

심화

  1. 2번에서 뛰는 순서만 본 이산 연쇄의 정상분포 \(\nu\)를 구하고 \(\pi_j \propto \frac{\nu_j}{q_j}\)를 확인하여라.
    답

    뛰는 순서는 1→2→3→1로 고정이라 \(\nu = \left(\frac13, \frac13, \frac13\right)\). \(\frac{\nu_j}{q_j} \propto \left(\frac12, 1, \frac13\right) \propto (3, 6, 2)\).
