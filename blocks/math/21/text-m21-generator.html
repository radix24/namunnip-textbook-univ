생성 행렬과 콜모고로프 방정식

본문

기계는 아무 때나 고장 나고 아무 때나 수리된다. 시간이 연속으로 흐를 때는 한 걸음의 전이행렬 대신 무엇으로 연쇄를 나타낼까? 그것에서 시각 \(t\)의 전이확률과 장기적으로 작동하는 비율은 어떻게 얻을까?

먼저 알아야 할 것지수분포의 무기억성과 경쟁(3.1절), 정상분포(2.3절)를 쓴다.

4.1.1머무르고 뛰기

시간이 연속인 과정 \(X(t)\)에서 시각 \(s\)까지의 과거가 어떻든 \(P(X(t + s) = j \mid X(s) = i) = P_{ij}(t)\)가 성립하면, 이것을 연속시간 마르코프 연쇄라 한다. 그러면 상태 \(i\)에 머무는 시간은 무기억성 때문에 지수분포 \(\text{Exp}(q_i)\)여야 한다. 머문 뒤에는 확률 \(r_{ij}\)로 \(j\)로 뛴다. 그래서 다음 값을 \(i\)에서 \(j\)로 가는 전이 비율이라 한다.

\[q_{ij} = q_ir_{ij} \quad (j \ne i)\]

같은 말로, \(i\)에서 각 \(j\)로 가는 알람이 비율 \(q_{ij}\)인 지수분포로 따로 울리고, 가장 먼저 울리는 곳으로 간다고 보아도 된다. 이것은 3.1절의 경쟁이다.

4.1.2생성 행렬

\(Q_{ij} = q_{ij}\) (\(j \ne i\)), \(Q_{ii} = -q_i = -\sum_{j\ne i}q_{ij}\)로 놓은 행렬 \(Q\)를 생성 행렬이라 하며, 각 행의 합은 0이다. 짧은 시간 \(h\)에 대해 \(P_{ij}(h) = q_{ij}h + o(h)\), \(P_{ii}(h) = 1 - q_ih + o(h)\)이다. 즉 \(P(h) = I + hQ + o(h)\)이다.

정리 4.1.1 (콜모고로프 방정식)

채프만-콜모고로프 방정식 \(P(t + h) = P(t)P(h) = P(h)P(t)\)에서 뒤 방정식 \(P'(t) = QP(t)\)와 앞 방정식 \(P'(t) = P(t)Q\)가 나오며, \(P(0) = I\)이다. 상태가 유한하면 해는 \(P(t) = e^{tQ} = \sum_n\frac{t^nQ^n}{n!}\)이다.

\(\frac{P(t + h) - P(t)}h = P(t)\frac{P(h) - I}h \to P(t)Q\)가 앞 방정식이고, 곱하는 순서를 바꾸면 뒤 방정식이다.

4.1.3두 상태 연쇄

예제 4.1.2

기계가 작동(상태 0)하다가 비율 \(\alpha\)로 고장(상태 1) 나고, 비율 \(\beta\)로 수리된다. \(P_{00}(t)\)와 장기적으로 작동하는 비율을 구하여라.

풀이. 생성 행렬은 \(Q = \begin{pmatrix}-\alpha & \alpha\\ \beta & -\beta\end{pmatrix}\)이다. 앞 방정식의 (0, 0) 성분은 \(P_{00}' = -\alpha P_{00} + \beta P_{01} = -\alpha P_{00} + \beta(1 - P_{00})\)이므로, 이 일차 미분방정식을 풀면 다음과 같다.

\[P_{00}(t) = \frac\beta{\alpha + \beta} + \frac\alpha{\alpha + \beta}e^{-(\alpha + \beta)t}\]

따라서 장기적으로 작동하는 비율은 \(\frac\beta{\alpha + \beta}\)이다. 예를 들어 고장 비율이 하루 0.1, 수리 비율이 하루 0.9이면 90%이며, 그림 1이 이 경우이다.

4.1.4정상분포

\(\pi P(t) = \pi\)가 모든 \(t\)에서 성립하는 것은 \(\pi Q = 0\)과 동치이다. 성분으로 쓰면 \(\pi_jq_j = \sum_{i\ne j}\pi_iq_{ij}\)이고, 이는 \(j\)에서 나가는 비율과 \(j\)로 들어오는 비율이 같다는 뜻이다. 기약이고 정상분포가 있으면 \(P_{ij}(t) \to \pi_j\)이며, 연속시간에는 주기 문제가 없다.

한편 \(\pi\)는 뛰는 순서만 본 이산 연쇄 \((r_{ij})\)의 정상분포 \(\nu\)와 다르다. 머무는 시간까지 반영하면 \(\pi_j \propto \frac{\nu_j}{q_j}\)이므로, 오래 머무는 상태일수록 비중이 커진다.

흔한 오해\(Q\)의 성분도 확률이라고 여기기 쉽지만, 단위 시간당 비율이며 대각 성분은 음수이고 행의 합은 0이다. 또 \(e^{tQ}\)를 성분마다 \(e^{tq_{ij}}\)로 계산할 수 있다고 생각하는 것도 틀렸다. 행렬 지수함수는 거듭제곱의 급수이므로 성분별 지수와 다르다.
마무리

처음 질문에 답하면, 연속시간 연쇄는 전이 비율을 모은 생성 행렬 \(Q\)로 나타내며, 이는 \(P(h) = I + hQ + o(h)\)를 뜻한다. 시각 \(t\)의 전이확률은 콜모고로프 방정식 \(P' = PQ\)의 해 \(P(t) = e^{tQ}\)이다. 장기 비율은 \(\pi Q = 0\)을 풀어 얻으며, 고장과 수리의 예에서는 작동 비율이 \(\frac\beta{\alpha + \beta}\)이다.

4.1.5연습문제

기본

  1. 예 4.1.2에서 \(\alpha = 1\), \(\beta = 3\)일 때 작동 중이던 기계가 시간 1 뒤에도 작동 중일 확률을 구하여라.
    답

    \(\frac34 + \frac14e^{-4} \approx 0.7546\).

응용

  1. 상태 \(\{1, 2, 3\}\)에서 \(q_{12} = 2\), \(q_{23} = 1\), \(q_{31} = 3\)이고 나머지 비율이 0이다. \(Q\)를 쓰고 정상분포를 구하여라.
    답

    \(Q = \begin{pmatrix}-2 & 2 & 0\\ 0 & -1 & 1\\ 3 & 0 & -3\end{pmatrix}\). \(2\pi_1 = 3\pi_3\), \(\pi_2 = 2\pi_1\): \(\pi \propto (3, 6, 2)\), \(\pi = \left(\frac3{11}, \frac6{11}, \frac2{11}\right)\).

심화

  1. 2번에서 뛰는 순서만 본 이산 연쇄의 정상분포 \(\nu\)를 구하고 \(\pi_j \propto \frac{\nu_j}{q_j}\)를 확인하여라.
    답

    뛰는 순서는 1→2→3→1로 고정이라 \(\nu = \left(\frac13, \frac13, \frac13\right)\). \(\frac{\nu_j}{q_j} \propto \left(\frac12, 1, \frac13\right) \propto (3, 6, 2)\).
