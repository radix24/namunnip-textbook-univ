출생-사망 과정과 정상분포

본문

개체 수나 대기열 길그러므로 한 번에 하나씩만 늘거나 주는 양이 있다. 이런 과정의 정상분포는 생성 행렬의 연립방정식을 풀지 않고도 구할 수 있을까? 그리고 그 분포가 존재하지 않는 것은 언제일까?

먼저 알아야 할 것생성 행렬과 정상분포(4.1절), 상세균형(2.5절)을 쓴다.

4.2.1정의

상태가 \(0, 1, 2, \dots\)이고, \(n\)에서 \(n + 1\)로 비율 \(\lambda_n\)(출생), \(n - 1\)로 비율 \(\mu_n\)(사망)으로만 움직이는 연속시간 연쇄를 출생-사망 과정이라 하며, \(\mu_0 = 0\)이다. 상태는 개체 수나 대기열의 길이 같은 것이다. 그러면 상태 \(n\)에 머무는 시간은 \(\text{Exp}(\lambda_n + \mu_n)\)이고, 위로 갈 확률은 \(\frac{\lambda_n}{\lambda_n + \mu_n}\)이다.

4.2.2정상분포

\(\{0, \dots, n\}\)과 \(\{n + 1, \dots\}\) 사이의 경계를 넘는 길은 \(n \to n + 1\)과 \(n + 1 \to n\) 하나씩뿐이다. 따라서 장기적으로 경계를 오르는 횟수와 내리는 횟수가 같아야 하므로 다음이 성립한다.

\[\lambda_n\pi_n = \mu_{n+1}\pi_{n+1}\]
정리 4.2.1

\(\theta_0 = 1\), \(\theta_n = \frac{\lambda_0\lambda_1\cdots\lambda_{n-1}}{\mu_1\mu_2\cdots\mu_n}\)이라 하자. \(\sum_n\theta_n < \infty\)이면 정상분포는 \(\pi_n = \frac{\theta_n}{\sum_k\theta_k}\)이고, \(\sum\theta_n = \infty\)이면 정상분포가 없다.

증명.균형식을 되풀이하면 \(\pi_n = \theta_n\pi_0\)이고, 합이 1이 되려면 \(\pi_0 = \frac1{\sum\theta_k}\)이어야 한다. 이 \(\pi\)는 이웃한 쌍마다 상세균형을 만족하므로, 정리 2.5.1의 연속시간 판에 의해 \(\pi Q = 0\)이다. \(\sum\theta_k = \infty\)이면 \(\pi_0 = 0\)이 되어 모든 \(\pi_n\)이 0이므로 정상분포가 없다. ∎

4.2.3대기열의 예

예제 4.2.2

손님이 비율 \(\lambda\)로 오고 창구 하나가 비율 \(\mu\)로 처리하는 M/M/1 대기열의 정상분포를 구하여라.

풀이. \(\lambda_n = \lambda\), \(\mu_n = \mu\)이므로 \(\rho = \frac\lambda\mu\)라 하면 \(\theta_n = \rho^n\)이다. \(\rho < 1\)이면 \(\pi_n = (1 - \rho)\rho^n\)인 기하분포이고, 창구가 놀 확률은 \(1 - \rho\)이다. 한편 \(\rho \ge 1\)이면 대기열이 끝없이 늘어나 정상분포가 없다.

예제 4.2.3

창구가 무한히 많아 손님이 각자 바로 서비스를 받는 M/M/∞의 정상분포를 구하여라.

풀이. \(n\)명이 동시에 서비스를 받으므로 \(\mu_n = n\mu\)이다. 그러면 \(\theta_n = \frac{\rho^n}{n!}\)이므로 \(\pi_n = e^{-\rho}\frac{\rho^n}{n!}\), 즉 \(\text{Poisson}(\rho)\)이다. 주차장의 차 수나 동시 접속자 수가 이 모형을 따르며, 그림 1의 빨간 막대가 그 예이다.

예제 4.2.4

M/M/1에서 대기실이 \(K\)명까지만 받는다면(\(n \ge K\)이면 \(\lambda_n = 0\)) 정상분포는 어떻게 되는가?

풀이. 이때 상태가 \(0, \dots, K\)로 유한하므로 \(\pi_n = \frac{(1 - \rho)\rho^n}{1 - \rho^{K+1}}\) (\(n \le K\))이며, \(\rho \ge 1\)이어도 정상분포가 있다. 손님이 자리가 없어 돌아갈 확률은 \(\pi_K\)이다.

흔한 오해\(\rho = 1\)이면 도착과 처리가 딱 맞으니 안정하다고 여기기 쉽지만, \(\sum\theta_n = \infty\)라서 대기열이 안정되지 않는다. 또 균형식을 \(\lambda_n\pi_n = \mu_n\pi_n\)처럼 같은 상태끼리 쓰는 것도 틀렸다. 경계를 사이에 둔 두 상태 \(n\)과 \(n + 1\)의 흐름을 맞춰야 한다.
마무리

처음 질문에 답하면, 출생-사망 과정은 이웃한 두 상태 사이의 경계에서 흐름을 맞추는 \(\lambda_n\pi_n = \mu_{n+1}\pi_{n+1}\)만 풀면 되므로, 정상분포가 \(\pi_n \propto \theta_n\)으로 바로 나온다. 이것이 존재하지 않는 것은 \(\sum\theta_n = \infty\)일 때이며, M/M/1에서는 \(\rho \ge 1\)인 경우이다.

4.2.4연습문제

기본

  1. M/M/1에서 \(\lambda = 3\), \(\mu = 4\)일 때 대기열(서비스 중 포함)에 2명 이상 있을 확률을 구하여라.
    답

    \(\rho^2 = \frac9{16} \approx 0.5625\).

응용

  1. 창구가 2개인 M/M/2 (\(\mu_1 = \mu\), \(\mu_n = 2\mu\) (\(n \ge 2\)))에서 \(\lambda = \mu\)일 때 \(\pi_0\)을 구하여라.
    답

    \(\theta_0 = 1\), \(\theta_n = 2\left(\frac12\right)^n\) (\(n \ge 1\)). 합 \(1 + 2 = 3\)이라 \(\pi_0 = \frac13\).

심화

  1. 개체마다 비율 \(\lambda\)로 번식하고 비율 \(\mu\)로 죽으며 외부에서 비율 \(a\)로 이주해 온다(\(\lambda_n = n\lambda + a\), \(\mu_n = n\mu\)). \(\lambda < \mu\)이면 정상분포가 있음을 보여라.
    답

    \(\frac{\theta_{n+1}}{\theta_n} = \frac{n\lambda + a}{(n + 1)\mu} \to \frac\lambda\mu < 1\)이라 비 판정법으로 \(\sum\theta_n < \infty\).
