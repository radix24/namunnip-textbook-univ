출생-사망 과정과 정상분포

본문
이 절에서 배울 것
  • 한 칸씩만 오르내리는 출생-사망 과정을 비율 \(\lambda_n\), \(\mu_n\)으로 정의한다.
  • 이웃한 두 상태의 흐름 균형 \(\lambda_n\pi_n = \mu_{n+1}\pi_{n+1}\)으로 정상분포를 구한다.
  • 정상분포가 있을 조건과 대표적인 예(M/M/1, M/M/∞)를 안다.
먼저 알아야 할 것
  • 생성 행렬과 \(\pi Q = 0\) (4.1절), 상세균형 (2.5절), 등비급수.

4.2.1정의

상태가 \(0, 1, 2, \dots\)(개체 수, 대기열 길이)이고 \(n\)에서 \(n + 1\)로 비율 \(\lambda_n\)(출생), \(n - 1\)로 비율 \(\mu_n\)(사망)으로만 움직이는 연속시간 연쇄를 출생-사망 과정이라 합니다(\(\mu_0 = 0\)). 상태 \(n\)에 머무는 시간은 \(\text{Exp}(\lambda_n + \mu_n)\)이고, 위로 갈 확률은 \(\frac{\lambda_n}{\lambda_n + \mu_n}\)입니다.

4.2.2정상분포

\(\{0, \dots, n\}\)과 \(\{n + 1, \dots\}\) 사이의 경계를 넘는 길은 \(n \to n + 1\)과 \(n + 1 \to n\) 하나씩뿐입니다. 장기적으로 경계를 오르는 횟수와 내리는 횟수가 같아야 하므로

\[\lambda_n\pi_n = \mu_{n+1}\pi_{n+1}.\]
정리 4.2.1 \(\theta_0 = 1\), \(\theta_n = \frac{\lambda_0\lambda_1\cdots\lambda_{n-1}}{\mu_1\mu_2\cdots\mu_n}\)이라 하자. \(\sum_n\theta_n < \infty\)이면 정상분포는 \(\pi_n = \frac{\theta_n}{\sum_k\theta_k}\)이고, \(\sum\theta_n = \infty\)이면 정상분포가 없다.
증명

균형식을 반복하면 \(\pi_n = \theta_n\pi_0\)이고 합이 1이 되려면 \(\pi_0 = \frac1{\sum\theta_k}\). 이 \(\pi\)는 이웃 쌍마다 상세균형을 만족하므로 \(\pi Q = 0\)이다(정리 2.5.1의 연속시간 판). ∎

4.2.3예

예 4.2.2 (M/M/1) 손님이 비율 \(\lambda\)로 오고 창구 하나가 비율 \(\mu\)로 처리합니다. \(\lambda_n = \lambda\), \(\mu_n = \mu\)이라 \(\theta_n = \rho^n\) (\(\rho = \frac\lambda\mu\)). \(\rho < 1\)이면 \(\pi_n = (1 - \rho)\rho^n\) (기하분포)이고, 창구가 놀 확률은 \(1 - \rho\)입니다. \(\rho \ge 1\)이면 대기열이 끝없이 늘어 정상분포가 없습니다.
예 4.2.3 (M/M/∞) 창구가 무한히 많아 각자 바로 서비스를 받으면 \(\mu_n = n\mu\)입니다. \(\theta_n = \frac{\rho^n}{n!}\)이라 \(\pi_n = e^{-\rho}\frac{\rho^n}{n!}\), 즉 \(\text{Poisson}(\rho)\)입니다. 주차장의 차, 동시 접속자 수의 모형입니다.
예 4.2.4 (유한 용량) M/M/1에서 대기실이 \(K\)명까지만이면(\(\lambda_n = 0\), \(n \ge K\)) \(\pi_n = \frac{(1 - \rho)\rho^n}{1 - \rho^{K+1}}\) (\(n \le K\))로, \(\rho \ge 1\)이어도 정상분포가 있습니다. 손님이 돌아갈 확률은 \(\pi_K\)입니다.
흔한 오해(1) \(\rho = 1\)이면 "딱 맞으니" 안정이라 여긴다. \(\sum\theta_n = \infty\)라 대기열이 안정되지 않는다. (2) 균형식 \(\lambda_n\pi_n = \mu_{n+1}\pi_{n+1}\)을 \(\lambda_n\pi_n = \mu_n\pi_n\)처럼 같은 상태끼리 쓴다. 경계를 사이에 둔 두 상태의 흐름을 맞춘다.
요약
  1. 출생 비율 \(\lambda_n\), 사망 비율 \(\mu_n\), 이웃으로만 이동.
  2. \(\pi_n \propto \theta_n = \prod\frac{\lambda_{k-1}}{\mu_k}\), \(\sum\theta_n < \infty\)일 때만.
  3. M/M/1: 기하분포 \((1 - \rho)\rho^n\). M/M/∞: \(\text{Poisson}(\rho)\).

4.2.4연습문제

기본

  1. M/M/1에서 \(\lambda = 3\), \(\mu = 4\)일 때 대기열(서비스 중 포함)에 2명 이상 있을 확률을 구하여라.
    답

    \(\rho^2 = \frac9{16} \approx 0.5625\).

응용

  1. 창구가 2개인 M/M/2 (\(\mu_1 = \mu\), \(\mu_n = 2\mu\) (\(n \ge 2\)))에서 \(\lambda = \mu\)일 때 \(\pi_0\)을 구하여라.
    답

    \(\theta_0 = 1\), \(\theta_n = 2\left(\frac12\right)^n\) (\(n \ge 1\)). 합 \(1 + 2 = 3\)이라 \(\pi_0 = \frac13\).

심화

  1. 개체마다 비율 \(\lambda\)로 번식하고 비율 \(\mu\)로 죽으며 외부에서 비율 \(a\)로 이주해 온다(\(\lambda_n = n\lambda + a\), \(\mu_n = n\mu\)). \(\lambda < \mu\)이면 정상분포가 있음을 보여라.
    답

    \(\frac{\theta_{n+1}}{\theta_n} = \frac{n\lambda + a}{(n + 1)\mu} \to \frac\lambda\mu < 1\)이라 비 판정법으로 \(\sum\theta_n < \infty\).
