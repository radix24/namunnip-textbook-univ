하루 매출의 평균과 흩어짐

예제 · 손님 수도 흔들리는 합

먼저 예측

손님 수가 평균 50명으로 고정된 날과, 평균은 50명이지만 포아송 분포로 흔들리는 날. 매출의 표준편차는 어느 쪽이 클까요?

예측 확인

흔들리는 쪽입니다. 손님 수의 불확실성이 매출의 불확실성에 더해집니다.

하루 손님 수 \(N \sim \text{Poisson}(50)\)이고, 손님 한 명의 구매액 \(Y\)(만 원)는 0, 2, 5를 확률 0.6, 0.3, 0.1로 가지며 서로, 그리고 \(N\)과 독립이다. 하루 매출 \(S\)의 평균과 표준편차를 구하고, 손님 수가 정확히 50명일 때와 비교하여라.

전략

1.3절의 공식 \(E[S] = E[N]E[Y]\), \(\operatorname{Var}S = E[N]\operatorname{Var}Y + \operatorname{Var}N(E[Y])^2\)을 씁니다. 포아송이면 \(\operatorname{Var}S = \lambda E[Y^2]\)입니다.

풀이

  1. \(E[Y] = 0.3\cdot2 + 0.1\cdot5 = 1.1\), \(E[Y^2] = 0.3\cdot4 + 0.1\cdot25 = 3.7\), \(\operatorname{Var}Y = 3.7 - 1.21 = 2.49\).
    분포표에서 바로 계산.
  2. \(E[S] = 50\cdot1.1 = 55\)만 원.
    \(E[S \mid N] = 1.1N\)의 평균.
  3. \(\operatorname{Var}S = 50\cdot2.49 + 50\cdot1.1^2 = 124.5 + 60.5 = 185 = 50\cdot3.7\), 표준편차 \(\sqrt{185} \approx 13.6\)만 원.
    조건부 분산 공식, \(\operatorname{Var}N = 50\).
  4. 손님이 정확히 50명이면 \(\operatorname{Var}S = 124.5\), 표준편차 약 11.2만 원.
    \(\operatorname{Var}N = 0\)이라 둘째 항이 없다.

검산

두 분산의 차 \(185 - 124.5 = 60.5\)은 \(\operatorname{Var}N\cdot(E[Y])^2 = 50\cdot1.21\)과 같습니다. 손님 수가 \(\sqrt{50} \approx 7\)명쯤 흔들리고 한 명당 평균 1.1만 원이라 약 7.8만 원의 흔들림이 더해지는 셈입니다(\(\sqrt{60.5} \approx 7.8\)).

의미

재고나 현금 준비량을 정할 때 평균만으로는 부족하고 흩어짐을 알아야 합니다. 개수의 불확실성을 무시하면 위험을 과소평가합니다. 같은 구조가 보험 청구, 하루 강수량(비 오는 횟수 × 한 번의 양) 등에 나타납니다.

이해 확인

구매액이 늘 1.1만 원으로 고정이고 \(N \sim \text{Poisson}(50)\)이면 매출의 표준편차는?

답

\(\operatorname{Var}S = 50\cdot1.21 = 60.5\), 표준편차 약 7.8만 원.
