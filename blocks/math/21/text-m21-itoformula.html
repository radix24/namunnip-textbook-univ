Itô 공식

본문

보통의 연쇄법칙은 \(df(x(t)) = f'(x)\,dx\)이다. 브라운 운동에 이 규칙을 쓰면 \(d(W^2) = 2W\,dW\)가 되어야 하는데, 앞 절에서 \(\int W\,dW = \frac12W^2 - \frac12t\)였다. 사라진 \(\frac12t\)는 어디에서 오고, 일반적인 연쇄법칙은 어떤 모양인가?

먼저 알아야 할 것Itô 적분(9.1절), 이차변분(8.2절), Taylor 정리를 쓴다. Evans 4장 4절을 따른다.

9.2.1Taylor 전개에서 남는 항

\(f\)가 두 번 연속 미분 가능하다고 하자. 칸마다 Taylor 전개하면 \(f(W_{k+1}) - f(W_k) = f'(W_k)\Delta_k + \frac12f''(W_k)\Delta_k^2 + (\text{나머지})\)이다. 보통의 함수라면 \(\Delta_k^2\)이 칸 길이의 제곱 정도라 합이 0으로 갔다. 그런데 브라운 운동에서는 \(\Delta_k^2 \approx \delta_k\)이고, 이차변분 정리처럼 \(\sum f''(W_k)\Delta_k^2\)은 \(\int f''(W)\,dt\)로 수렴한다. 나머지 항은 \(|\Delta_k|^3\) 정도라 합이 0으로 간다. 그러면 다음을 얻는다.

정리 9.2.1 (Itô 공식)

\(f \in C^2\)이면 \(f(W(t)) = f(0) + \int_0^tf'(W)\,dW + \frac12\int_0^tf''(W)\,ds\)이다. 미분 꼴로 \(df(W) = f'(W)\,dW + \frac12f''(W)\,dt\)이다.

더 일반적으로 \(dX = F\,dt + G\,dW\)인 Itô 과정과 \(u(x, t) \in C^{2,1}\)에서

\[du(X, t) = \left(u_t + Fu_x + \tfrac12G^2u_{xx}\right)dt + Gu_x\,dW\]

이다. 기억하는 방법은 두 번째 차수까지 Taylor 전개한 뒤 곱셈표 \(dW\cdot dW = dt\), \(dW\cdot dt = dt\cdot dt = 0\)을 쓰는 것이다. 이 표가 이차변분 \((\Delta W)^2 \approx \Delta t\)를 미분 기호로 적은 것이다.

9.2.2계산

\(f(x) = x^2\)이면 \(d(W^2) = 2W\,dW + dt\)이고, 적분하면 \(\int_0^tW\,dW = \frac12W_t^2 - \frac12t\)가 다시 나온다. 따라서 처음 질문의 \(\frac12t\)는 \(\frac12f''\,dt\) 항이다. 그림 1처럼 \(x^2\)이 볼록이라 흔들림이 평균을 위로 밀어 올리는 몫이다.

예제 9.2.2

\(Y(t) = e^{\lambda W(t) - \frac12\lambda^2t}\)가 \(dY = \lambda Y\,dW\)를 만족함을 보이고 \(E[e^{\lambda W(t)}]\)를 구하여라.

풀이. \(u(x, t) = e^{\lambda x - \frac12\lambda^2t}\)이면 \(u_t = -\frac12\lambda^2u\), \(u_x = \lambda u\), \(u_{xx} = \lambda^2u\)이다. Itô 공식(\(F = 0\), \(G = 1\))으로 \(dY = \left(-\frac12\lambda^2 + \frac12\lambda^2\right)Y\,dt + \lambda Y\,dW = \lambda Y\,dW\)이다. 그러면 \(Y\)는 \(dt\) 항이 없는 Itô 적분이라 평균이 \(Y(0) = 1\)로 유지된다. 따라서 \(E[e^{\lambda W(t)}] = e^{\frac12\lambda^2t}\)이고, 이것은 \(N(0, t)\)의 적률생성함수와 같다. 보통의 미적분이었다면 \(e^{\lambda W}\)가 \(dY = \lambda Y\,dW\)를 만족했을 텐데, 확률미적분에서는 \(-\frac12\lambda^2t\)라는 보정이 필요하다.

흔한 오해Itô 공식의 \(\frac12f''\,dt\) 항을 작은 오차라서 버려도 된다고 여기기 쉽지만, \((dW)^2 = dt\)라서 \(dt\)와 같은 크기이며 버리면 \(\int W\,dW\) 같은 값이 틀린다. 또 \(dt\,dW\)나 \((dt)^2\)도 남는다고 생각하는 것도 틀렸다. 곱셈표에서 남는 것은 \((dW)^2 = dt\)뿐이다.
마무리

브라운 운동은 \((\Delta W)^2 \approx \Delta t\)라서 Taylor 전개의 2차 항이 사라지지 않는다. 그래서 확률미적분의 연쇄법칙은 \(df(W) = f'(W)\,dW + \frac12f''(W)\,dt\)이고, 일반 Itô 과정에서는 \(\frac12G^2u_{xx}\,dt\) 항이 붙는다. 곱셈표 \(dW^2 = dt\)로 계산하면 \(\int W\,dW\)와 지수 마팅게일 \(e^{\lambda W - \lambda^2t/2}\)이 바로 나온다.

9.2.3연습문제

기본

  1. \(d(W^3)\)을 구하고 \(E[W_t^3] = 0\)을 확인하여라.
    답

    \(d(W^3) = 3W^2dW + 3W\,dt\). 기대값을 취하면 \(\frac{d}{dt}E[W^3] = 3E[W] = 0\).

응용

  1. Itô 공식으로 \(E[W_t^4] = 3t^2\)을 보여라.
    답

    \(d(W^4) = 4W^3dW + 6W^2dt\)이므로 \(E[W_t^4] = 6\int_0^ts\,ds = 3t^2\).
