조건부 기대값과 반복 기대값 법칙

본문
이 절에서 배울 것
  • \(Y = y\)라는 정보가 있을 때의 기대값 \(E[X \mid Y = y]\)를 계산한다.
  • \(E[X \mid Y]\)를 \(Y\)의 함수인 확률변수로 보고 반복 기대값 법칙 \(E\big[E[X \mid Y]\big] = E[X]\)를 쓴다.
  • 조건부 분산 공식 \(\operatorname{Var}X = E[\operatorname{Var}(X \mid Y)] + \operatorname{Var}(E[X \mid Y])\)를 안다.
먼저 알아야 할 것
  • 조건부 확률, 기대값과 분산, 이항분포 (수학5).

1.1.1조건부 기대값

사건 \(Y = y\)가 일어났다는 것을 알면 \(X\)의 분포는 조건부 분포 \(P(X = x \mid Y = y) = \frac{P(X = x, Y = y)}{P(Y = y)}\)로 바뀝니다. 그 평균이 조건부 기대값입니다.

\[E[X \mid Y = y] = \sum_x x\,P(X = x \mid Y = y).\]

연속형이면 조건부 밀도 \(f_{X\mid Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}\)로 적분합니다. 이 값은 \(y\)마다 정해지는 수이므로 함수 \(g(y) = E[X \mid Y = y]\)가 됩니다. \(y\) 자리에 확률변수 \(Y\)를 넣은 \(g(Y)\)를 \(E[X \mid Y]\)라 씁니다. 즉 \(E[X \mid Y]\)는 "\(Y\)를 본 뒤 내리는 \(X\)의 최선의 예측"이고, 그 자체가 확률변수입니다.

1.1.2반복 기대값 법칙

정리 1.1.1 \(E[X]\)가 존재하면 \(E\big[E[X \mid Y]\big] = E[X]\). 즉 \(E[X] = \sum_y E[X \mid Y = y]P(Y = y)\).
증명

이산형에서 \(\sum_y\sum_x x\frac{P(X = x, Y = y)}{P(Y = y)}P(Y = y) = \sum_x x\sum_y P(X = x, Y = y) = \sum_x xP(X = x)\). ∎

전확률 공식의 기대값 판입니다. 복잡한 \(X\)의 평균을, 먼저 \(Y\)를 고정해 계산하고 나중에 \(Y\)에 대해 평균하는 두 단계로 나눌 수 있습니다.

예 1.1.2 주사위를 던져 나온 눈 \(N\)만큼 동전을 던지고 앞면 수를 \(X\)라 합니다. \(N = n\)이면 \(X \sim B(n, \frac12)\)이라 \(E[X \mid N] = \frac N2\). 따라서 \(E[X] = E\left[\frac N2\right] = \frac{3.5}2 = 1.75\)입니다. \(X\)의 분포를 직접 구하지 않아도 됩니다.

1.1.3조건부 분산 공식

\(\operatorname{Var}(X \mid Y) = E[X^2 \mid Y] - (E[X \mid Y])^2\)라 하면

정리 1.1.3 \(\operatorname{Var}X = E[\operatorname{Var}(X \mid Y)] + \operatorname{Var}(E[X \mid Y])\).
증명

\(E[\operatorname{Var}(X \mid Y)] = E[X^2] - E\big[(E[X \mid Y])^2\big]\), \(\operatorname{Var}(E[X \mid Y]) = E\big[(E[X \mid Y])^2\big] - (E[X])^2\). 더하면 \(E[X^2] - (E[X])^2\). ∎

흩어짐은 "그룹 안의 흩어짐의 평균"과 "그룹 평균들의 흩어짐"의 합입니다. 예 1.1.2에서 \(\operatorname{Var}(X \mid N) = \frac N4\), \(\operatorname{Var}N = \frac{35}{12}\)이라 \(\operatorname{Var}X = \frac{3.5}4 + \frac14\cdot\frac{35}{12} = 0.875 + 0.729 = 1.604\)입니다.

흔한 오해(1) \(E[X \mid Y]\)를 하나의 수로 여긴다. \(Y\)의 값에 따라 달라지는 확률변수다. (2) \(\operatorname{Var}X = E[\operatorname{Var}(X \mid Y)]\)라고 여긴다. 그룹 평균 자체가 흩어지는 부분 \(\operatorname{Var}(E[X \mid Y])\)가 빠졌다.
요약
  1. \(E[X \mid Y = y]\)는 조건부 분포의 평균, \(E[X \mid Y]\)는 \(Y\)의 함수인 확률변수.
  2. 반복 기대값: \(E[X] = E\big[E[X \mid Y]\big]\).
  3. \(\operatorname{Var}X = E[\operatorname{Var}(X \mid Y)] + \operatorname{Var}(E[X \mid Y])\).

1.1.4연습문제

기본

  1. 주머니 A에는 빨간 공 3개와 흰 공 1개, B에는 빨간 공 1개와 흰 공 1개가 있습니다. 동전으로 주머니를 고르고 공을 2개 꺼낼 때 빨간 공 개수의 기대값을 구하여라.
    답

    A이면 \(2\cdot\frac34 = 1.5\), B이면 \(2\cdot\frac12 = 1\). 평균 \(\frac{1.5 + 1}2 = 1.25\).

응용

  1. \(Y \sim U(0, 1)\)이고 \(Y = y\)일 때 \(X \sim U(0, y)\)이다. \(E[X]\)와 \(\operatorname{Var}X\)를 구하여라.
    답

    \(E[X \mid Y] = \frac Y2\), \(\operatorname{Var}(X \mid Y) = \frac{Y^2}{12}\). \(E[X] = \frac14\). \(\operatorname{Var}X = \frac1{12}\cdot\frac13 + \frac14\cdot\frac1{12} = \frac1{36} + \frac1{48} = \frac7{144}\).

심화

  1. \(Y\)의 함수 \(h(Y)\) 가운데 \(E[(X - h(Y))^2]\)을 최소로 하는 것이 \(E[X \mid Y]\)임을 보여라.
    답

    \(Y = y\)를 고정하면 \(E[(X - c)^2 \mid Y = y]\)는 \(c = E[X \mid Y = y]\)에서 최소(이차함수). 이것을 \(Y\)에 대해 평균해도 각 \(y\)에서 최소이므로 전체도 최소.
