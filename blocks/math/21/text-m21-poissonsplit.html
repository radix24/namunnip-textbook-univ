합병, 분해, 도착 시각의 순서통계량

본문
이 절에서 배울 것
  • 독립인 포아송 과정의 합이 포아송 과정임(합병)을 보인다.
  • 각 도착을 확률 \(p\)로 골라내면 서로 독립인 두 포아송 과정이 됨(분해)을 안다.
  • \(N(t) = n\)일 때 도착 시각들이 균등분포 \(n\)개의 순서통계량과 같음을 쓰고 대기 시간 합을 계산한다.
먼저 알아야 할 것
  • 포아송 과정의 정의 (3.2절), 무작위 합 (1.3절).

3.3.1합병

정리 3.3.1 비율 \(\lambda_1\), \(\lambda_2\)인 독립 포아송 과정의 합은 비율 \(\lambda_1 + \lambda_2\)인 포아송 과정이다. 각 도착이 첫째 과정에서 왔을 확률은 \(\frac{\lambda_1}{\lambda_1 + \lambda_2}\)이고 도착마다 독립이다.

정의 (나)로 보면 짧은 시간에 하나 올 확률이 \(\lambda_1h + \lambda_2h\)이고, 둘 이상은 \(o(h)\)입니다. 출처의 확률은 3.1절의 "지수분포의 경쟁"입니다.

3.3.2분해

정리 3.3.2 비율 \(\lambda\)인 포아송 과정의 각 도착을 독립적으로 확률 \(p\)로 유형 1, \(1 - p\)로 유형 2로 나누면 \(N_1\), \(N_2\)는 비율 \(\lambda p\), \(\lambda(1 - p)\)인 포아송 과정이고 서로 독립이다.
증명

\(P(N_1(t) = j, N_2(t) = k) = e^{-\lambda t}\frac{(\lambda t)^{j+k}}{(j + k)!}\binom{j + k}jp^j(1 - p)^k = e^{-\lambda pt}\frac{(\lambda pt)^j}{j!}\cdot e^{-\lambda(1-p)t}\frac{(\lambda(1 - p)t)^k}{k!}\). 결합분포가 두 포아송의 곱으로 갈라진다. ∎

독립이라는 결론은 놀랍습니다. 남자 손님이 많이 온 날이라고 여자 손님 수에 대한 정보가 생기지 않습니다. 총 인원이 고정된 이항분포에서는 둘이 음의 상관을 가지는데, 총 인원 자체가 포아송으로 흔들리면 그 상관이 정확히 지워집니다.

3.3.3순서통계량 성질

정리 3.3.3 \(N(t) = n\)이라는 조건 아래 도착 시각 \((S_1, \dots, S_n)\)은 \([0, t]\)의 균등분포에서 독립으로 뽑은 \(n\)개의 값을 크기순으로 늘어놓은 것과 같은 분포를 가진다.
증명의 흐름

도착 간격의 결합밀도 \(\lambda^ne^{-\lambda s_n}\) (\(0 < s_1 < \cdots < s_n\))에 \([s_n, t]\)에 도착이 없을 확률 \(e^{-\lambda(t - s_n)}\)을 곱하면 \(\lambda^ne^{-\lambda t}\)로 \(s\)에 무관하다. \(P(N(t) = n)\)으로 나누면 \(\frac{n!}{t^n}\), 즉 균등분포 \(n\)개의 순서통계량의 밀도이다. ∎

합처럼 순서와 무관한 양을 계산할 때 특히 편합니다. 정렬을 잊고 독립인 균등분포 \(n\)개로 바꿔 계산하면 됩니다.

예 3.3.4 승객이 비율 \(\lambda\)로 정류장에 오고 버스가 시각 \(t\)에 떠납니다. 승객들의 대기 시간 합 \(W = \sum_{i=1}^{N(t)}(t - S_i)\)의 평균은? \(N(t) = n\)이면 \(W\)는 \(\sum(t - U_i)\) (\(U_i \sim U(0, t)\))와 같은 분포라 \(E[W \mid N(t) = n] = \frac{nt}2\). 따라서 \(E[W] = \frac{\lambda t\cdot t}2 = \frac{\lambda t^2}2\)입니다.
흔한 오해(1) 분해된 두 과정이 총합을 나누니 음의 상관이 있다고 여긴다. 포아송 분해에서는 독립이다. (2) 순서통계량 성질을 \(N(t)\) 조건 없이 쓴다. \(N(t) = n\)으로 조건화해야 하고, 마지막에 \(n\)에 대해 평균한다.
요약
  1. 합병: 비율이 더해지고, 출처는 비율에 비례해 독립으로 정해진다.
  2. 분해: \(\lambda p\)와 \(\lambda(1 - p)\)의 독립 포아송 과정.
  3. \(N(t) = n\)이면 도착 시각은 \(U(0, t)\) \(n\)개의 순서통계량.

3.3.4연습문제

기본

  1. 시간당 10통의 전화 가운데 30%가 국제전화이다. 1시간 동안 국제전화가 하나도 없을 확률을 구하여라.
    답

    국제전화는 비율 3의 포아송: \(e^{-3} \approx 0.0498\).

응용

  1. \(N(1) = 1\)일 때 그 도착 시각 \(S_1\)의 분포를 구하여라.
    답

    \(U(0, 1)\). 정리 3.3.3에서 \(n = 1\).

심화

  1. 비율 \(\lambda\)로 오는 손님 가운데 시각 \(s\)에 온 손님은 확률 \(p(s)\)로 등록한다. \([0, t]\)에 등록한 손님 수의 분포를 구하여라.
    답

    \(N(t) = n\)이면 각 손님의 도착 시각은 \(U(0, t)\)라 등록 확률 \(\bar p = \frac1t\int_0^tp(s)ds\). 분해와 같은 계산으로 \(\text{Poisson}\left(\lambda\int_0^tp(s)ds\right)\).
