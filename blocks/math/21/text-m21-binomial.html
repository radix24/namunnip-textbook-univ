이항 모형과 무차익 가격

본문
이 절에서 배울 것
  • 한 기간 이항 모형에서 주식과 채권으로 옵션을 복제해 가격을 정한다.
  • 복제 가격이 위험중립 확률 \(q = \frac{1 + r - d}{u - d}\)의 기대값으로 쓰임을 보인다.
  • 여러 기간 모형에서 뒤로 거슬러 계산하는 방법과 할인된 가격이 마팅게일이라는 의미를 안다.
먼저 알아야 할 것
  • 연립일차방정식, 이항분포, 마팅게일 (6.1절).

7.1.1한 기간 모형

주식 가격이 지금 \(S_0\)이고 한 기간 뒤 \(uS_0\)(오름) 또는 \(dS_0\)(내림)이 됩니다. 안전한 채권은 한 기간에 이자율 \(r\)을 줍니다. 옵션은 기간 끝에 \(V_u\) 또는 \(V_d\)를 줍니다. 예를 들어 행사가 \(K\)인 콜옵션이면 \(V = \max(S_1 - K, 0)\)입니다.

차익거래란 돈을 들이지 않고 손해 볼 가능성 없이 이익을 볼 가능성이 있는 거래입니다. 시장에 차익거래가 없으려면 \(d < 1 + r < u\)여야 합니다(그렇지 않으면 주식이나 채권 한쪽이 늘 낫습니다).

7.1.2복제와 위험중립 확률

주식 \(\Delta\)주와 채권 \(B\)원을 사서 두 경우 모두 옵션과 같은 돈을 만들면

\[\Delta uS_0 + (1 + r)B = V_u, \qquad \Delta dS_0 + (1 + r)B = V_d, \qquad \Delta = \frac{V_u - V_d}{(u - d)S_0}.\]

옵션의 지금 가격은 이 묶음의 가격 \(V_0 = \Delta S_0 + B\)여야 합니다. 다르면 싼 쪽을 사고 비싼 쪽을 팔아 차익을 얻기 때문입니다.

정리 7.1.1 \(q = \frac{1 + r - d}{u - d}\)라 하면 \(0 < q < 1\)이고 \(V_0 = \frac{qV_u + (1 - q)V_d}{1 + r}\).

계산으로 확인할 수 있습니다. 놀라운 점은 실제로 오를 확률 \(p\)가 공식에 없다는 것입니다. 복제가 두 경우를 모두 맞추므로 확률은 상관없습니다. \(q\)는 \(E_q[S_1] = (1 + r)S_0\), 즉 주식의 평균 수익이 채권과 같아지게 하는 가상의 확률로, 위험중립 확률이라 합니다.

예 7.1.2 \(S_0 = 100\), \(u = 1.2\), \(d = 0.8\), \(r = 0.05\), \(K = 100\)인 콜옵션. \(V_u = 20\), \(V_d = 0\), \(q = \frac{1.05 - 0.8}{0.4} = 0.625\), \(V_0 = \frac{0.625\cdot20}{1.05} \approx 11.90\). 복제는 \(\Delta = \frac{20}{40} = 0.5\)주를 사고 \(\frac{0.5\cdot80}{1.05} \approx 38.10\)을 빌리는 것입니다: \(50 - 38.10 = 11.90\).

7.1.3여러 기간

\(n\)기간이면 끝에서부터 한 기간씩 같은 공식을 적용합니다(뒤로 거슬러 계산). 결과는

\[V_0 = \frac1{(1 + r)^n}E_q[V_n] = \frac1{(1 + r)^n}\sum_{k=0}^n\binom nkq^k(1 - q)^{n-k}V(u^kd^{n-k}S_0).\]

위험중립 확률 아래에서 할인된 주식 가격 \(\frac{S_k}{(1 + r)^k}\)과 할인된 옵션 가격은 마팅게일입니다. "공정한 게임"이라는 마팅게일의 뜻이 "차익거래가 없다"는 금융의 뜻과 정확히 맞물립니다(자산 가격 결정의 기본 정리).

흔한 오해(1) 오를 확률이 크면 콜옵션이 비싸야 한다고 여긴다. 가격은 \(p\)가 아니라 \(q\)로 정해진다(\(p\)는 이미 \(S_0\)에 반영). (2) \(q\)를 실제 확률로 여긴다. 가격 계산용 가상의 확률이다.
요약
  1. 무차익 조건 \(d < 1 + r < u\).
  2. 복제: \(\Delta = \frac{V_u - V_d}{(u - d)S_0}\), 가격은 \(q = \frac{1 + r - d}{u - d}\)의 할인 기대값.
  3. 여러 기간: 뒤로 거슬러 계산, 할인 가격은 \(q\) 아래 마팅게일.

7.1.4연습문제

기본

  1. 예 7.1.2의 조건에서 행사가 100인 풋옵션(\(\max(K - S_1, 0)\))의 가격을 구하여라.
    답

    \(V_u = 0\), \(V_d = 20\). \(\frac{0.375\cdot20}{1.05} \approx 7.14\).

응용

  1. 1번과 예 7.1.2로 풋-콜 패리티 \(C - P = S_0 - \frac K{1 + r}\)을 확인하여라.
    답

    \(11.90 - 7.14 = 4.76\), \(100 - \frac{100}{1.05} = 4.76\).

심화

  1. 예 7.1.2의 모형을 두 기간으로 늘려 콜옵션(\(K = 100\))의 가격을 구하여라.
    답

    끝 가격 144, 96, 64: 지급 44, 0, 0. \(V_0 = \frac{0.625^2\cdot44}{1.05^2} = \frac{17.1875}{1.1025} \approx 15.59\).
