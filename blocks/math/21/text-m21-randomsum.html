무작위 개수의 합

본문
이 절에서 배울 것
  • 개수 \(N\)도 확률변수인 합 \(S = X_1 + \cdots + X_N\)의 평균 \(E[S] = E[N]E[X]\)를 유도한다.
  • 분산 공식 \(\operatorname{Var}S = E[N]\operatorname{Var}X + \operatorname{Var}N(E[X])^2\)을 조건부 분산 공식으로 얻는다.
  • 보험 청구 총액 같은 문제에 적용한다.
먼저 알아야 할 것
  • 조건부 분산 공식 (1.1절), 포아송 분포 (수학5).

1.3.1평균

\(X_1, X_2, \dots\)가 같은 분포를 따르고 서로 독립이며, 개수 \(N\)(0 이상의 정수)이 이들과 독립이라 합니다. \(S = \sum_{i=1}^NX_i\)는 \(N = n\)이면 \(n\)개의 합이므로

\[E[S \mid N = n] = nE[X], \qquad \operatorname{Var}(S \mid N = n) = n\operatorname{Var}X.\]
정리 1.3.1 \(E[S] = E[N]E[X]\), \(\operatorname{Var}S = E[N]\operatorname{Var}X + \operatorname{Var}N\,(E[X])^2\).
증명

\(E[S \mid N] = NE[X]\)이므로 반복 기대값으로 \(E[S] = E[N]E[X]\). 조건부 분산 공식으로 \(\operatorname{Var}S = E[N\operatorname{Var}X] + \operatorname{Var}(NE[X]) = E[N]\operatorname{Var}X + (E[X])^2\operatorname{Var}N\). ∎

두 번째 항이 핵심입니다. 개수 자체가 흔들리면 그만큼 합도 더 흔들립니다. \(N\)이 상수 \(n\)이면 \(\operatorname{Var}N = 0\)이라 익숙한 \(n\operatorname{Var}X\)로 돌아갑니다.

1.3.2포아송 개수

\(N \sim \text{Poisson}(\lambda)\)이면 \(E[N] = \operatorname{Var}N = \lambda\)이므로

\[E[S] = \lambda E[X], \qquad \operatorname{Var}S = \lambda\left(\operatorname{Var}X + (E[X])^2\right) = \lambda E[X^2].\]

이런 \(S\)를 복합 포아송 분포라 하며 3.4절에서 시간에 따라 쌓이는 과정으로 다시 봅니다.

예 1.3.2 한 달에 들어오는 보험 청구 건수가 \(\text{Poisson}(20)\), 한 건의 금액이 평균 50만 원, 표준편차 30만 원이고 서로 독립입니다. 총액의 평균은 \(20\cdot50 = 1000\)만 원, 분산은 \(20(30^2 + 50^2) = 68000\), 표준편차는 약 261만 원입니다. 건수를 20으로 고정했다면 표준편차는 \(\sqrt{20}\cdot30 \approx 134\)만 원으로, 개수의 불확실성이 흩어짐을 거의 두 배로 키웁니다.

1.3.3독립 조건의 역할

\(N\)이 \(X_i\)들과 독립이 아니면 공식이 깨질 수 있습니다. 예를 들어 처음으로 \(X_i = 1\)이 나올 때 멈춘다면 \(N\)이 \(X\)값에 따라 정해집니다. 이런 "멈추는 시각"에서도 평균 공식 \(E[S] = E[N]E[X]\)는 \(E[N] < \infty\)이면 여전히 성립하는데(왈드 등식), 이는 6.2절의 선택 정지 정리로 증명합니다. 분산 공식은 일반적으로 성립하지 않습니다.

흔한 오해(1) \(\operatorname{Var}S = E[N]\operatorname{Var}X\)로 끝난다고 여긴다. 개수의 분산 항이 빠졌다. (2) \(E[S] = E[N]E[X]\)가 \(N\)과 \(X\)의 독립에서만 나온다고 여긴다. 정지 시각이면 왈드 등식으로 성립한다.
요약
  1. \(E[S] = E[N]E[X]\).
  2. \(\operatorname{Var}S = E[N]\operatorname{Var}X + \operatorname{Var}N(E[X])^2\).
  3. 포아송 개수이면 \(\operatorname{Var}S = \lambda E[X^2]\).

1.3.4연습문제

기본

  1. 하루 손님 수의 평균이 40, 한 사람의 구매액 평균이 1.5만 원일 때 하루 매출의 평균을 구하여라.
    답

    60만 원.

응용

  1. 주사위를 던져 나온 눈 \(N\)만큼 다시 주사위를 던져 눈의 합 \(S\)를 구한다. \(E[S]\)와 \(\operatorname{Var}S\)를 구하여라.
    답

    \(E[S] = 3.5^2 = 12.25\). \(\operatorname{Var}S = 3.5\cdot\frac{35}{12} + \frac{35}{12}\cdot3.5^2 = \frac{35}{12}(3.5 + 12.25) \approx 45.94\).

심화

  1. \(N \sim \text{Poisson}(\lambda)\), \(X_i \in \{0, 1\}\), \(P(X_i = 1) = p\)일 때 \(S\)의 분포를 구하여라.
    답

    \(P(S = k) = \sum_{n\ge k}e^{-\lambda}\frac{\lambda^n}{n!}\binom nkp^k(1 - p)^{n-k} = e^{-\lambda p}\frac{(\lambda p)^k}{k!}\). 즉 \(\text{Poisson}(\lambda p)\)(포아송 분해, 3.3절).
