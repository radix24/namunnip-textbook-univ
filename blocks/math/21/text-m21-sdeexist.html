확률미분방정식 해의 존재와 유일성

본문

상미분방정식 \(\dot x = b(x)\)에 잡음을 더한 \(dX = b(X)\,dt + \sigma(X)\,dW\)는 무엇을 뜻하고, 해가 언제 하나 있을까? 상미분방정식의 Picard 반복이 여기서도 통할까?

먼저 알아야 할 것Itô 적분과 등거리(9.1절), Itô 공식(9.2절), 상미분방정식의 Picard 반복(해석학)을 쓴다. Evans 5장을 따른다.

10.1.1뜻

\(dX = b(X, t)\,dt + \sigma(X, t)\,dW\), \(X(0) = X_0\)는 적분방정식

\[X(t) = X_0 + \int_0^tb(X(s), s)\,ds + \int_0^t\sigma(X(s), s)\,dW(s)\]

의 줄임말이다. 여기서 앞의 적분은 경로마다의 보통 적분이고 뒤의 것은 Itô 적분이다. 그러면 해는 이 등식을 만족하는 적합 과정이다. \(\sigma = 0\)이면 상미분방정식이 되고, \(b = 0\), \(\sigma = 1\)이면 해가 브라운 운동 자체이다.

10.1.2정리

정리 10.1.1

\(b\)와 \(\sigma\)가 \(x\)에 대해 Lipschitz이고(\(|b(x, t) - b(y, t)| + |\sigma(x, t) - \sigma(y, t)| \le L|x - y|\)) 선형 증가 조건 \(|b| + |\sigma| \le L(1 + |x|)\)을 만족하며 \(E|X_0|^2 < \infty\)이고 \(X_0\)이 브라운 운동과 독립이면, 해가 존재하고 거의 확실히 하나뿐이다.

증명의 흐름.Picard 반복 \(X^{n+1}(t) = X_0 + \int_0^tb(X^n)\,ds + \int_0^t\sigma(X^n)\,dW\)를 쓴다. 두 단계의 차 \(D_n(t) = E|X^{n+1}(t) - X^n(t)|^2\)을 재면, \(ds\) 적분은 Cauchy-Schwarz 부등식으로, \(dW\) 적분은 Itô 등거리로 다루어 \(D_n(t) \le C\int_0^tD_{n-1}(s)\,ds\)를 얻는다. 되풀이하면 \(D_n(t) \le \frac{(Ct)^n}{n!}D_0\)이고, 이 합이 수렴하므로 \(X^n\)은 수렴한다. 마팅게일 부등식으로 경로의 균등수렴까지 얻고, 극한이 해이다. 유일성은 두 해의 차에 같은 부등식을 쓰고 Gronwall 부등식을 쓰면 나온다. ∎

즉 증명의 뼈대는 상미분방정식과 같고, 바뀐 것은 확률적분을 등거리로 제곱 평균에서 다룬다는 점 하나이다. 하지만 Lipschitz 조건이 깨지면 상미분방정식처럼 해가 여러 개이거나 유한 시간에 폭발할 수 있다.

예제 10.1.2

\(dX = X\,dW\), \(X(0) = 1\)의 해를 구하여라. 또 \(dX = 3X^{1/3}dt + 3X^{2/3}dW\), \(X(0) = 0\)에 해가 여럿 있음을 보여라.

풀이. 앞의 것은 앞 절의 예제에서 \(\lambda = 1\)로 둔 것으로 \(X = e^{W_t - t/2}\)이다. 계수가 Lipschitz이므로 이것이 유일한 해이다. 뒤의 것은 \(X \equiv 0\)이 해이다. 그런데 \(X = W^3\)도 Itô 공식으로 \(d(W^3) = 3W^2dW + 3W\,dt = 3X^{2/3}dW + 3X^{1/3}dt\)라 해이다. 두 계수가 0에서 Lipschitz가 아니라서 유일성이 깨진 것이다.

마무리

확률미분방정식은 \(dt\) 적분과 Itô 적분을 함께 담은 적분방정식이다. 계수가 Lipschitz이고 선형 증가 조건을 만족하면, 상미분방정식과 같은 Picard 반복을 Itô 등거리로 제곱 평균에서 다루어 해의 존재와 유일성을 얻는다. Lipschitz가 깨지면 \(dX = 3X^{1/3}dt + 3X^{2/3}dW\)처럼 해가 여러 개일 수 있다.

10.1.3연습문제

기본

  1. \(dX = 2\,dt + 3\,dW\), \(X(0) = 1\)의 해와 \(X(t)\)의 분포를 구하여라.
    답

    \(X = 1 + 2t + 3W_t \sim N(1 + 2t, 9t)\).

응용

  1. 정리 10.1.1의 조건에서 \(E|X(t)|^2 \le Ce^{Ct}(1 + E|X_0|^2)\)임을 등거리와 Gronwall 부등식으로 보이는 흐름을 써라.
    답

    \(E|X_t|^2 \le 3E|X_0|^2 + 3tE\int|b|^2 + 3E\int|\sigma|^2\)이고 선형 증가로 \(\le C(1 + E|X_0|^2) + C\int_0^tE|X_s|^2ds\). Gronwall을 쓴다.
