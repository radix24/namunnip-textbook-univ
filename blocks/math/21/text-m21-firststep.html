첫걸음 분석

본문
이 절에서 배울 것
  • 첫 시행의 결과로 조건화해 도달 확률과 기대 시간에 대한 연립방정식을 세운다.
  • 동전에서 특정 무늬가 나올 때까지의 기대 횟수를 구한다.
  • 랜덤워크가 한쪽 끝에 먼저 닿을 확률을 점화식으로 구한다.
먼저 알아야 할 것
  • 반복 기대값 법칙 (1.1절), 수열의 점화식(고등학교 수학 I).

1.2.1아이디어

"지금 상태에서 앞으로 걸리는 시간"을 상태마다 미지수로 둡니다. 한 걸음을 가면 시간이 1 늘고 새 상태로 옮겨 가는데, 거기서부터 앞으로 걸리는 시간은 다시 같은 미지수입니다. 반복 기대값 법칙을 첫 걸음에 대해 쓰면 미지수들 사이의 일차 연립방정식이 나옵니다.

\[m_i = 1 + \sum_j p_{ij}m_j \quad (i \notin A), \qquad m_i = 0 \quad (i \in A).\]

여기서 \(A\)는 목표 상태들의 집합입니다. 도달 확률 \(h_i\) (목표 A에 B보다 먼저 닿을 확률)도 같은 방식으로 \(h_i = \sum_j p_{ij}h_j\), \(h_A = 1\), \(h_B = 0\)입니다. 이번에는 시간이 늘지 않으므로 "\(1 +\)"가 없습니다.

1.2.2동전 무늬 기다리기

예 1.2.1 공정한 동전을 앞면이 두 번 연속(HH) 나올 때까지 던집니다. 처음 상태의 기대 횟수를 \(a\), 직전이 H인 상태의 기대 횟수를 \(b\)라 하면 \[a = 1 + \tfrac12b + \tfrac12a, \qquad b = 1 + \tfrac12\cdot0 + \tfrac12a.\] 둘째 식을 첫째에 넣으면 \(a = 1.5 + 0.75a\), 따라서 \(a = 6\)입니다. 같은 방법으로 HT를 기다리면 \(a = 1 + \frac12b + \frac12a\), \(b = 1 + \frac12b\)라 \(b = 2\), \(a = 4\)입니다.

HH가 HT보다 오래 걸리는 이유는 H 다음에 실패하면(T) HH는 처음으로 돌아가지만, HT는 H 다음에 실패해도(H) 여전히 "직전이 H"이기 때문입니다.

1.2.3도박꾼의 도달 확률

정수 \(0, 1, \dots, N\) 위에서 확률 \(p\)로 오른쪽, \(q = 1 - p\)로 왼쪽으로 한 칸씩 움직입니다. \(i\)에서 출발해 \(N\)에 먼저 닿을 확률 \(h_i\)는

\[h_i = ph_{i+1} + qh_{i-1}, \qquad h_0 = 0,\ h_N = 1.\]
정리 1.2.2 \(p = \frac12\)이면 \(h_i = \frac iN\). \(p \ne \frac12\)이고 \(r = \frac qp\)이면 \(h_i = \frac{1 - r^i}{1 - r^N}\).
증명

\(h_i = ph_i + qh_i\)로 쓰면 \(p(h_{i+1} - h_i) = q(h_i - h_{i-1})\), 즉 차 \(d_i = h_{i+1} - h_i\)가 공비 \(r\)인 등비수열이다. \(h_i = d_0(1 + r + \cdots + r^{i-1})\)이고 \(h_N = 1\)로 \(d_0\)을 정하면 된다(\(r = 1\)이면 등차). ∎

기대 시간 \(m_i = 1 + pm_{i+1} + qm_{i-1}\), \(m_0 = m_N = 0\)도 같은 방식으로 풀립니다. \(p = \frac12\)이면 \(m_i = i(N - i)\)입니다(대입으로 확인).

흔한 오해(1) 무늬마다 확률이 \(\frac14\)로 같으니 기다리는 시간도 같다고 여긴다. 겹침 구조 때문에 HH는 6, HT는 4이다. (2) 도달 확률 방정식에도 "\(1 +\)"를 붙인다. 시간을 셀 때만 붙인다.
요약
  1. 첫 걸음으로 조건화: \(m_i = 1 + \sum p_{ij}m_j\), \(h_i = \sum p_{ij}h_j\).
  2. HH까지 6번, HT까지 4번.
  3. 도박꾼: \(h_i = \frac iN\) (공정), \(\frac{1 - r^i}{1 - r^N}\) (\(r = \frac qp\)).

1.2.4연습문제

기본

  1. 주사위를 6이 나올 때까지 던지는 기대 횟수를 첫걸음 분석으로 구하여라.
    답

    \(m = 1 + \frac56m\), \(m = 6\).

응용

  1. \(p = \frac12\), \(N = 4\)일 때 \(m_i = 1 + \frac12m_{i+1} + \frac12m_{i-1}\)을 직접 풀어 \(m_2\)를 구하여라.
    답

    대칭으로 \(m_1 = m_3\). \(m_2 = 1 + m_1\), \(m_1 = 1 + \frac12m_2\). 풀면 \(m_2 = 4 = 2\cdot2\).

심화

  1. 공정한 동전에서 HHH가 나올 때까지의 기대 횟수를 구하여라.
    답

    상태 0, H, HH의 기대값 \(a, b, c\): \(a = 1 + \frac12(a + b)\), \(b = 1 + \frac12(a + c)\), \(c = 1 + \frac12a\). 풀면 \(a = 14\).
