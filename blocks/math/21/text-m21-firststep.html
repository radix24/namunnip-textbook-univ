첫걸음 분석

본문

공정한 동전을 던질 때 HH와 HT는 연속한 두 번에서 나올 확률이 모두 \(\frac14\)이다. 그렇다면 처음 나올 때까지 기다리는 횟수도 같을까? 같지 않다면, 그 기대 횟수를 무엇으로 계산할 수 있을까?

먼저 알아야 할 것반복 기대값 법칙(1.1절)과 수열의 점화식(고등학교 수학 I)을 쓴다.

1.2.1아이디어

지금 상태에서 앞으로 걸리는 시간을 상태마다 미지수로 둔다. 한 걸음을 가면 시간이 1 늘고 새 상태로 옮겨 가는데, 거기서부터 앞으로 걸리는 시간은 다시 같은 미지수이다. 그러므로 반복 기대값 법칙을 첫 걸음에 대해 쓰면 미지수들 사이의 일차 연립방정식이 나온다. 목표 상태들의 집합을 \(A\)라 하면 다음과 같다.

\[m_i = 1 + \sum_j p_{ij}m_j \quad (i \notin A), \qquad m_i = 0 \quad (i \in A)\]

목표 \(A\)에 \(B\)보다 먼저 닿을 확률 \(h_i\)도 같은 방식으로 \(h_i = \sum_j p_{ij}h_j\), \(h_A = 1\), \(h_B = 0\)을 만족한다. 이때는 시간을 세지 않으므로 앞의 \(1 +\)가 없다.

1.2.2동전 무늬 기다리기

예제 1.2.1

공정한 동전을 HH가 나올 때까지 던질 때와 HT가 나올 때까지 던질 때, 기대 횟수를 각각 구하여라.

풀이. 그림 1의 위 그림에서 시작 상태의 기대 횟수를 \(a\), 직전이 H인 상태의 기대 횟수를 \(b\)라 하면 \(a = 1 + \frac12b + \frac12a\)이고 \(b = 1 + \frac12\cdot0 + \frac12a\)이다. 둘째 식을 첫째 식에 넣으면 \(a = 1.5 + 0.75a\)이므로 \(a = 6\)이다. 아래 그림에서는 \(a = 1 + \frac12b + \frac12a\)이고 \(b = 1 + \frac12b\)이므로 \(b = 2\), \(a = 4\)이다.

HH가 HT보다 오래 걸리는 까닭은 그림 1에서 바로 보인다. 직전이 H일 때 T가 나오면 HH는 처음으로 돌아가야 한다. 하지만 HT는 직전이 H일 때 H가 나와도 여전히 직전이 H이므로 잃는 것이 없다.

1.2.3도박꾼의 도달 확률

정수 \(0, 1, \dots, N\) 위에서 확률 \(p\)로 오른쪽, \(q = 1 - p\)로 왼쪽으로 한 칸씩 움직이는 걸음을 생각하자. \(i\)에서 출발해 0보다 \(N\)에 먼저 닿을 확률 \(h_i\)는 다음을 만족한다.

\[h_i = ph_{i+1} + qh_{i-1}, \qquad h_0 = 0,\quad h_N = 1\]
정리 1.2.2

\(p = \frac12\)이면 \(h_i = \frac iN\)이다. \(p \ne \frac12\)이고 \(r = \frac qp\)이면 \(h_i = \frac{1 - r^i}{1 - r^N}\)이다.

증명.\(h_i = ph_i + qh_i\)로 쓰면 \(p(h_{i+1} - h_i) = q(h_i - h_{i-1})\)이므로, 차 \(d_i = h_{i+1} - h_i\)는 공비가 \(r\)인 등비수열이다. 그러면 \(h_i = d_0(1 + r + \cdots + r^{i-1})\)이고, \(h_N = 1\)에서 \(d_0\)을 정하면 된다. \(r = 1\)이면 차가 일정하므로 \(h_i = \frac iN\)이다. ∎

기대 시간 \(m_i = 1 + pm_{i+1} + qm_{i-1}\), \(m_0 = m_N = 0\)도 같은 방식으로 풀린다. 예를 들어 \(p = \frac12\)이면 \(m_i = i(N - i)\)이고, 이것은 대입해서 확인할 수 있다. 가진 돈이 \(N\)의 절반일 때 게임이 가장 오래 가며, 그 기대 시간은 \(\frac{N^2}4\)이다.

흔한 오해무늬마다 나올 확률이 \(\frac14\)로 같으니 기다리는 시간도 같다고 여기기 쉽지만, 실패했을 때 남는 부분이 다르기 때문에 HH는 6번, HT는 4번이다. 또 도달 확률의 방정식에도 \(1 +\)를 붙여야 한다고 생각하는 것도 틀렸다. 이 항은 한 걸음마다 시간이 1 늘어나는 것을 센 것이므로 시간을 구할 때만 붙인다.
마무리

처음 질문에 답하면, 나올 확률은 같아도 기다리는 횟수는 다르다. 상태마다 앞으로 걸릴 기대 횟수를 미지수로 두고 첫 걸음에 대해 반복 기대값 법칙을 쓰면 연립방정식이 나오고, 이를 풀면 HH는 6번, HT는 4번이다. 같은 첫걸음 분석으로 도박꾼이 목표에 먼저 닿을 확률 \(\frac{1 - r^i}{1 - r^N}\)도 얻는다.

1.2.4연습문제

기본

  1. 주사위를 6이 나올 때까지 던지는 기대 횟수를 첫걸음 분석으로 구하여라.
    답

    \(m = 1 + \frac56m\), \(m = 6\).

응용

  1. \(p = \frac12\), \(N = 4\)일 때 \(m_i = 1 + \frac12m_{i+1} + \frac12m_{i-1}\)을 직접 풀어 \(m_2\)를 구하여라.
    답

    대칭으로 \(m_1 = m_3\). \(m_2 = 1 + m_1\), \(m_1 = 1 + \frac12m_2\). 풀면 \(m_2 = 4 = 2\cdot2\).

심화

  1. 공정한 동전에서 HHH가 나올 때까지의 기대 횟수를 구하여라.
    답

    상태 0, H, HH의 기대값 \(a, b, c\): \(a = 1 + \frac12(a + b)\), \(b = 1 + \frac12(a + c)\), \(c = 1 + \frac12a\). 풀면 \(a = 14\).
