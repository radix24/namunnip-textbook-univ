벡터장의 공변미분

본문
이 절에서 배울 것
  • 접벡터 \(\mathbf v\) 방향으로 벡터장 \(W\)가 변하는 비율 \(\nabla_{\mathbf v}W\)를 정의하고 성분으로 계산한다.
  • 공변미분의 선형성과 라이프니츠 규칙을 확인한다.
  • 곡선의 가속도, 곡면의 휘어짐(4.4절)을 공변미분으로 표현하는 준비를 한다.
먼저 알아야 할 것
  • 접벡터, 벡터장, 방향도함수 (1.1절).

1.4.1정의

1.1절에서 함수 \(f\)를 접벡터 \(\mathbf v_{\mathbf p}\) 방향으로 미분했습니다. 벡터장 \(W\)도 같은 방법으로 미분합니다. 점 \(\mathbf p\)에서 \(\mathbf v\) 방향으로 움직이며 \(W\)의 값을 지켜보면 됩니다.

공변미분: \(\nabla_{\mathbf v}W = \dfrac{d}{dt}W(\mathbf p + t\mathbf v)\Big|_{t=0}\), 점 \(\mathbf p\)에서의 접벡터.

\(\mathbb R^3\)에서는 모든 접공간을 자연틀 \(U_1, U_2, U_3\)으로 같은 것으로 볼 수 있으므로 성분별로 미분하면 됩니다.

정리 1.4.1

\(W = \sum_iw_iU_i\)이면 \(\nabla_{\mathbf v}W = \sum_i\mathbf v[w_i]\,U_i(\mathbf p)\). 여기서 \(\mathbf v[w_i] = \nabla w_i(\mathbf p)\cdot\mathbf v\)는 방향도함수이다.

증명.\(W(\mathbf p + t\mathbf v) = \sum_iw_i(\mathbf p + t\mathbf v)\mathbf e_i\)를 \(t = 0\)에서 미분하면 각 성분이 연쇄 법칙으로 \(\nabla w_i(\mathbf p)\cdot\mathbf v\)이다. ∎

예 1.4.2

\(W = x^2U_1 + yzU_3\), \(\mathbf p = (1, 2, 0)\), \(\mathbf v = (1, -1, 2)\). \(\mathbf v[x^2] = 2x\cdot1 = 2\), \(\mathbf v[yz] = z\cdot(-1) + y\cdot2 = 4\). 따라서 \(\nabla_{\mathbf v}W = 2U_1 + 4U_3\). 정의대로 \(W(\mathbf p + t\mathbf v) = ((1 + t)^2, 0, (2 - t)2t)\)를 미분해도 \((2, 0, 4)\).

1.4.2성질

벡터장 \(V\)에 대해 점마다 \(\nabla_{V(\mathbf p)}W\)를 모은 벡터장을 \(\nabla_VW\)라 씁니다. 다음이 성립합니다(\(f, g\)는 함수, \(a, b\)는 실수).

  • \(\nabla_{fV + gV'}W = f\nabla_VW + g\nabla_{V'}W\): \(V\)에 대해서는 함수 계수까지 선형.
  • \(\nabla_V(aW + bW') = a\nabla_VW + b\nabla_VW'\).
  • \(\nabla_V(fW) = V[f]\,W + f\nabla_VW\): 라이프니츠 규칙.
  • \(V[W\cdot W'] = \nabla_VW\cdot W' + W\cdot\nabla_VW'\): 내적의 미분.

마지막 성질에서 \(W\)가 단위벡터장이면 \(0 = V[W\cdot W] = 2\nabla_VW\cdot W\)이므로 \(\nabla_VW \perp W\)입니다. 곡면의 단위법벡터장을 미분하면 접평면 안의 벡터가 나온다는 사실(4.4절)이 여기서 나옵니다.

1.4.3곡선을 따라

곡선 \(\alpha\) 위의 벡터장 \(Y(t)\)는 그냥 \(t\)로 미분해 \(Y'(t)\)라 씁니다. \(Y = W\circ\alpha\)이면 연쇄 법칙으로 \(Y'(t) = \nabla_{\alpha'(t)}W\)입니다. 특히 속도장 \(\alpha'\)의 미분이 가속도 \(\alpha''\)이고, 프레네 공식(2.2절)은 틀 \(T, N, B\)를 이렇게 미분한 결과입니다.

흔한 오해(1) \(\nabla_{\mathbf v}W\)가 \(\mathbf v\)의 길이에 무관하다고 여긴다: \(\mathbf v\)를 두 배로 하면 두 배가 된다. (2) \(\nabla_VW = \nabla_WV\)라 여긴다: 일반적으로 다르다(차이가 리 괄호). (3) 곡면 위에서도 성분별로 미분하면 된다고 여긴다: 그 결과는 접평면을 벗어날 수 있다. 접평면 성분만 남긴 내재적 공변미분은 미분기하의 다음 주제다.
요약
  1. \(\nabla_{\mathbf v}W = \frac{d}{dt}W(\mathbf p + t\mathbf v)|_{t=0} = \sum\mathbf v[w_i]U_i\).
  2. \(V\)에 대해 함수 선형, \(W\)에 대해 라이프니츠 규칙.
  3. 단위벡터장의 공변미분은 자기 자신에 수직.

1.4.4연습문제

기본

  1. \(W = xyU_1 + zU_2\), \(\mathbf p = (1, 1, 1)\), \(\mathbf v = (0, 2, 1)\)일 때 \(\nabla_{\mathbf v}W\)는?
    답

    \(\mathbf v[xy] = y\cdot0 + x\cdot2 = 2\), \(\mathbf v[z] = 1\). \(2U_1 + U_2\).

응용

  1. \(W = xU_1 + yU_2 + zU_3\)이면 모든 \(\mathbf v\)에 대해 \(\nabla_{\mathbf v}W = \mathbf v\)임을 보여라.
    답

    \(\mathbf v[x] = v_1\) 등이므로 \((v_1, v_2, v_3)\).

심화

  1. \(V = U_1\), \(W = xU_2\)일 때 \(\nabla_VW - \nabla_WV\)를 구하여라.
    답

    \(\nabla_VW = U_1[x]U_2 = U_2\), \(\nabla_WV = 0\)(\(U_1\)은 상수장). 차이 \(U_2 \ne 0\).
