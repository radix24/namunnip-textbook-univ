타원의 곡률과 전체 곡률

예제 · 일반 매개화의 부호 곡률 공식

먼저 예측

타원 \(\frac{x^2}4 + y^2 = 1\)에서 가장 많이 휜 곳은 긴 축의 끝일까요, 짧은 축의 끝일까요? 두 곳의 곡률 비는 얼마쯤일까요?

예측 확인

긴 축의 끝 \((\pm2, 0)\)입니다. 곡률은 2와 0.25로 8배 차이입니다.

\(\alpha(t) = (2\cos t, \sin t)\)의 부호 있는 곡률을 구하고, \(t = 0\)과 \(t = \frac\pi2\)에서의 값, 그리고 전체 곡률 \(\int\kappa\,ds\)를 구하여라.

전략

공식 \(\kappa = \frac{x'y'' - y'x''}{(x'^2 + y'^2)^{3/2}}\)(2.4절)에 넣습니다. 전체 곡률은 \(ds = |\alpha'|dt\)를 쓰면 적분이 간단해집니다.

풀이

  1. \(x' = -2\sin t\), \(y' = \cos t\), \(x'' = -2\cos t\), \(y'' = -\sin t\).
    미분.
  2. \(x'y'' - y'x'' = 2\sin^2t + 2\cos^2t = 2\), \(\kappa(t) = \dfrac2{(4\sin^2t + \cos^2t)^{3/2}}\).
    분자는 상수.
  3. \(\kappa(0) = \frac2{1} = 2\), \(\kappa(\frac\pi2) = \frac2{8} = 0.25\).
    \(4^{3/2} = 8\).
  4. \(\int\kappa\,ds = \int_0^{2\pi}\kappa|\alpha'|\,dt = \int_0^{2\pi}\frac{2}{4\sin^2t + \cos^2t}\,dt = 2\pi\). 회전수 1.
    \(\int_0^{2\pi}\frac{dt}{a^2\sin^2t + b^2\cos^2t} = \frac{2\pi}{ab}\) (\(a = 2\), \(b = 1\)).

검산

곡률원의 반지름은 \((2, 0)\)에서 \(\frac12\), \((0, 1)\)에서 4입니다. 일반 타원 \((a\cos t, b\sin t)\)에서는 \(\frac a{b^2}\)과 \(\frac b{a^2}\)이고, \(a = b = r\)이면 둘 다 \(\frac1r\)로 원과 맞습니다.

의미

곡률이 어디서 크든 작든 한 바퀴의 합은 언제나 \(2\pi\)입니다. 곡률은 국소적 양이지만 그 적분은 전체적(위상적) 양이 됩니다. 곡면에서 같은 일을 하는 것이 가우스-보네 정리(6.4절)입니다.

이해 확인

\(\alpha(t) = (2\cos t, -\sin t)\)로 거꾸로 돌면 전체 곡률은?

답

분자가 \(-2\)가 되어 \(-2\pi\), 회전수 \(-1\).
