가우스-보네 정리

본문
이 절에서 배울 것
  • 컴팩트 방향 가능 곡면에서 \(\iint_MK\,dA = 2\pi\chi(M)\)이라는 가우스-보네 정리를 진술한다.
  • 구면과 원환면에서 직접 확인한다.
  • 측지 삼각형의 내각의 합 공식을 통해 국소판의 뜻을 이해한다.
먼저 알아야 할 것
  • 가우스 곡률 (4.5절), 오일러 지표 (6.2절), 평면곡선의 회전수 (2.4절).

6.4.1진술

정리 6.4.1 (가우스-보네)

\(M\)이 컴팩트 방향 가능 곡면이면 \(\displaystyle\iint_MK\,dA = 2\pi\chi(M)\).

좌변은 길이와 각을 재야 알 수 있는 기하적인 양이고, 우변은 꼭짓점·모서리·면의 수로 정해지는 위상적인 양입니다. 곡면을 아무리 찌그러뜨려도(구멍을 내거나 붙이지 않는 한) 곡률의 총합은 변하지 않습니다. 평면곡선의 \(\oint\kappa\,ds = 2\pi\times\)회전수(2.4절)의 곡면판입니다.

  • 반지름 \(r\)인 구면: \(\frac1{r^2}\cdot4\pi r^2 = 4\pi = 2\pi\cdot2\). \(\chi = 2\).
  • 원환면: 바깥쪽의 양의 곡률과 안쪽의 음의 곡률이 정확히 상쇄되어 0 \(= 2\pi\cdot0\)(같은 절의 예제).
  • 손잡이가 \(g\)개인 곡면: \(\iint K\,dA = 2\pi(2 - 2g)\). \(g \ge 2\)이면 음수라, 그런 곡면은 어딘가에 \(K < 0\)인 점이 있어야 합니다.

6.4.2측지 삼각형

곡면 위에서 가장 곧은 곡선(가속도가 곡면에 수직인 곡선)을 측지선이라 합니다. 구면에서는 대원입니다. 세 측지선으로 둘러싸인 삼각형 \(T\)의 내각을 \(\alpha, \beta, \gamma\)라 하면

\[\alpha + \beta + \gamma = \pi + \iint_TK\,dA.\]

평면(\(K = 0\))에서는 내각의 합이 \(\pi\)이고, 구면에서는 넓이에 비례해 \(\pi\)보다 크며, 안장 모양 곡면(\(K < 0\))에서는 \(\pi\)보다 작습니다. 곡면을 측지 삼각형들로 분할해 이 식을 모두 더하면, 각의 합과 \(\pi\)들이 꼭짓점·모서리·면의 수로 정리되어 정리 6.4.1이 나옵니다(증명의 흐름).

단위구면에서 북극과 적도 위의 경도 \(0^\circ\), \(90^\circ\)인 두 점을 꼭짓점으로 하는 삼각형은 세 각이 모두 직각이고 넓이는 구면의 \(\frac18\)인 \(\frac\pi2\)입니다. \(\frac{3\pi}2 = \pi + \frac\pi2\)로 맞습니다.

흔한 오해(1) 둥근 곡면만 전체 곡률이 양수라 여긴다: 구면과 위상이 같으면 어떤 모양이든 \(4\pi\)이다. (2) 원환면은 곡률이 0이라 여긴다: 점마다 \(K\)는 0이 아니고 적분만 0이다. (3) 경계가 있는 곡면에도 그대로 쓴다: 경계의 측지 곡률 항이 추가된다.
요약
  1. \(\iint_MK\,dA = 2\pi\chi(M)\): 기하 = 위상.
  2. 구면 \(4\pi\), 원환면 0, 손잡이 \(g\)개 \(2\pi(2 - 2g)\).
  3. 측지 삼각형: 내각의 합 \(= \pi + \iint K\,dA\).

6.4.3연습문제

기본

  1. 럭비공 모양(구면과 위상이 같은) 곡면의 전체 가우스 곡률은?
    답

    \(\chi = 2\)이라 \(4\pi\).

응용

  1. 반지름 1인 구면 위의 측지 삼각형의 내각이 \(90^\circ, 60^\circ, 60^\circ\)이면 넓이는?
    답

    \(\frac\pi2 + \frac\pi3 + \frac\pi3 - \pi = \frac\pi6\).

심화

  1. 원환면과 위상이 같은 곡면 위에 \(K > 0\)인 점과 \(K < 0\)인 점이 모두 있어야 함을 보여라. (컴팩트 곡면에는 \(K > 0\)인 점이 있다는 사실은 인정)
    답

    \(K > 0\)인 점이 있고 적분이 0이므로 \(K < 0\)인 점도 있어야 한다.
