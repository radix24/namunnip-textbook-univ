3차원 공간의 등장사상

본문
이 절에서 배울 것
  • 등장사상(거리를 보존하는 사상)을 정의하고, 평행이동과 직교변환이 그 예임을 확인한다.
  • 모든 등장사상이 평행이동과 직교변환의 합성으로 유일하게 쓰임을 증명한다.
  • 등장사상의 접사상이 내적을 보존하고, 곡률은 보존하며 열률은 방향에 따라 부호가 바뀜을 안다.
먼저 알아야 할 것
  • 정규직교기저와 직교행렬 (수학1 7.2절), 곡률과 열률 (2.1절).

3.1.1정의와 예

등장사상(isometry): 모든 \(\mathbf p, \mathbf q\)에 대해 \(d(F(\mathbf p), F(\mathbf q)) = d(\mathbf p, \mathbf q)\)인 사상 \(F: \mathbb R^3 \to \mathbb R^3\). 여기서 \(d(\mathbf p, \mathbf q) = |\mathbf p - \mathbf q|\).

  • 평행이동 \(T_{\mathbf a}(\mathbf p) = \mathbf p + \mathbf a\).
  • 직교변환 \(C(\mathbf p) = A\mathbf p\) (\(A^TA = I\)). \(|A\mathbf p - A\mathbf q|^2 = (\mathbf p - \mathbf q)^TA^TA(\mathbf p - \mathbf q) = |\mathbf p - \mathbf q|^2\). 회전(\(\det A = 1\))과 반사가 포함된다(\(\det A = -1\)).

등장사상의 합성과 역도 등장사상이므로, 등장사상 전체는 군을 이룹니다(유클리드 군).

3.1.2분해 정리

정리 3.1.1

모든 등장사상 \(F\)는 평행이동 \(T\)와 직교변환 \(C\)의 합성 \(F = T\circ C\)로 유일하게 쓰인다.

생각. \(F(\mathbf 0)\)만큼 되돌리는 평행이동을 먼저 하면 원점을 고정하는 등장사상이 남습니다. 원점을 고정하면 거리뿐 아니라 길이와 내적도 보존되고, 내적을 보존하는 사상은 자동으로 선형임을 보입니다.

증명.1단계. \(C = T_{-F(\mathbf 0)}\circ F\)로 두면 \(C\)는 등장사상이고 \(C(\mathbf 0) = \mathbf 0\)이다. 따라서 \(|C(\mathbf p)| = |\mathbf p|\).

2단계: 내적 보존. \(|C(\mathbf p) - C(\mathbf q)|^2 = |\mathbf p - \mathbf q|^2\)을 전개하면 \(|C\mathbf p|^2 - 2C\mathbf p\cdot C\mathbf q + |C\mathbf q|^2 = |\mathbf p|^2 - 2\mathbf p\cdot\mathbf q + |\mathbf q|^2\)이고, 1단계로 \(C\mathbf p\cdot C\mathbf q = \mathbf p\cdot\mathbf q\).

3단계: 선형성. \(\mathbf e_1, \mathbf e_2, \mathbf e_3\)의 상 \(\mathbf u_i = C(\mathbf e_i)\)은 2단계로 정규직교이다. 임의의 \(\mathbf p\)에 대해 \(C(\mathbf p) = \sum_i(C\mathbf p\cdot\mathbf u_i)\mathbf u_i = \sum_i(\mathbf p\cdot\mathbf e_i)\mathbf u_i = \sum_ip_i\mathbf u_i\). 따라서 \(C\)는 열이 \(\mathbf u_i\)인 행렬 \(A\)의 곱이고, 열이 정규직교이므로 \(A\)는 직교행렬이다.

유일성. \(T_{\mathbf a}\circ C = T_{\mathbf b}\circ C'\)이면 원점에 대입해 \(\mathbf a = \mathbf b\)이고, 그러면 \(C = C'\). ∎

3단계에서 연속성이나 미분가능성을 가정하지 않았다는 점이 놀랍습니다. 거리 보존만으로 선형(따라서 매끄러움)이 따라 나옵니다.

3.1.3접사상과 곡선의 불변량

\(F = T_{\mathbf a}\circ C\)의 접사상은 \(F_*(\mathbf v_{\mathbf p}) = (A\mathbf v)_{F(\mathbf p)}\)이므로 접벡터의 내적을 보존합니다. 곡선 \(\beta\)를 옮긴 \(\bar\beta = F\circ\beta\)는 속력이 같고(\(|\bar\beta'| = |A\beta'| = |\beta'|\)), 단위속력 곡선의 프레네 틀은 \(\bar T = AT\), \(\bar N = AN\)이며 \(\bar\kappa = \kappa\)입니다. 그런데 종법선은 외적이라

\[\bar B = \bar T\times\bar N = AT\times AN = (\det A)\,A(T\times N) = (\det A)\,AB,\]

따라서 \(\bar\tau = (\det A)\,\tau\)입니다. 회전(\(\det A = 1\))은 열률을 보존하고, 반사(\(\det A = -1\))는 열률의 부호를 바꿉니다. 오른나사 나선을 거울에 비추면 왼나사 나선이 되는 것입니다. 같은 절의 탐구 카드에서 확인합니다.

흔한 오해(1) "거리를 보존하는 사상은 회전과 평행이동뿐"이라 하고 반사를 빠뜨린다. (2) 등장사상이 외적을 보존한다고 여긴다. \(A\mathbf v\times A\mathbf w = (\det A)A(\mathbf v\times\mathbf w)\)이다.
요약
  1. 등장사상 = 평행이동 ∘ 직교변환 (유일). 원점을 고정하면 내적 보존 ⇒ 선형.
  2. 접사상은 내적을 보존한다. 곡률은 불변, 열률은 \(\det A\)배.
  3. \(\det A = 1\): 방향 보존(강체운동), \(\det A = -1\): 방향 반전.

3.1.4연습문제

기본

  1. \(F(x, y, z) = (y + 1, -x, z - 2)\)가 등장사상임을 보이고 \(F = T\circ C\)로 분해하여라. 방향을 보존하는가?
    답

    \(C(x, y, z) = (y, -x, z)\), 행렬 \(\begin{pmatrix}0 & 1 & 0\\-1 & 0 & 0\\0 & 0 & 1\end{pmatrix}\)은 직교이고 \(\det = 1\). \(T = T_{(1, 0, -2)}\). 방향 보존(\(z\)축 둘레 \(-90°\) 회전 후 평행이동).

응용

  1. \(A\mathbf v\times A\mathbf w = (\det A)A(\mathbf v\times\mathbf w)\) (\(A\) 직교)를 보여라.
    답

    임의의 \(\mathbf u\)에 대해 \(A\mathbf u\cdot(A\mathbf v\times A\mathbf w) = \det(A\mathbf u, A\mathbf v, A\mathbf w) = \det A\det(\mathbf u, \mathbf v, \mathbf w) = \det A\,(\mathbf u\cdot(\mathbf v\times\mathbf w)) = A\mathbf u\cdot(\det A)A(\mathbf v\times\mathbf w)\). \(A\mathbf u\)가 모든 벡터를 지나므로 같다.

심화

  1. 등장사상 \(F\)가 서로 다른 세 점(한 직선 위에 있지 않은)을 고정하고 방향을 보존하면 항등사상임을 보여라.
    답

    한 고정점을 원점으로 옮기면 \(F = C\) (선형, 직교). 나머지 두 고정점 \(\mathbf p, \mathbf q\)는 일차독립이라 \(C\)가 평면 \(\operatorname{span}\{\mathbf p, \mathbf q\}\)를 고정하고, 직교성으로 법선 \(\mathbf n\)은 \(\pm\mathbf n\)으로 간다. \(\det C = 1\)이므로 \(+\mathbf n\), 따라서 \(C = I\).
