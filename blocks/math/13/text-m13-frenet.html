프레네 공식

본문

곡선을 따라 움직이는 작은 비행기를 생각하자. 진행 방향 \(T\), 휘는 쪽 \(N\), 그 둘에 수직인 \(B\)가 비행기에 붙은 축이다. 곡선을 따라가면 이 세 축은 어떻게 돌까? 그 회전을 곡률과 열률만으로 완전히 쓸 수 있을까?

먼저 알아야 할 것곡률, 주법선, 종법선의 정의(2.1절)와 정규직교 기저의 전개 \(\mathbf u = \sum(\mathbf u\cdot\mathbf e_i)\mathbf e_i\)를 쓴다.

2.2.1정규직교틀을 미분하면

\(E_1(s), E_2(s), E_3(s)\)가 각 \(s\)에서 정규직교라 하고 \(E_i' = \sum_j\omega_{ij}E_j\) (\(\omega_{ij} = E_i'\cdot E_j\))로 쓴다. \(E_i\cdot E_j = \delta_{ij}\)를 미분하면 \(E_i'\cdot E_j + E_i\cdot E_j' = 0\), 곧 \(\omega_{ij} = -\omega_{ji}\)이다. 따라서 계수 행렬이 반대칭이라 대각 성분은 0이고, 독립인 성분은 \(\omega_{12}, \omega_{13}, \omega_{23}\) 셋뿐이다. 프레네 공식은 이 원리를 프레네 틀에 적용한 것이다.

2.2.2유도

정리 2.2.1 (프레네 공식)

\(\kappa > 0\)인 단위속력 곡선 \(\beta\)의 프레네 틀은 다음을 만족한다.

\[\begin{pmatrix}T\\N\\B\end{pmatrix}' = \begin{pmatrix}0 & \kappa & 0\\-\kappa & 0 & \tau\\0 & -\tau & 0\end{pmatrix}\begin{pmatrix}T\\N\\B\end{pmatrix}.\]

증명.첫째 줄은 \(N\)의 정의 \(T' = \kappa N\)이다. 다음으로 \(B'\cdot T = -B\cdot T' = -B\cdot\kappa N = 0\)이고 \(B\)가 단위벡터라 \(B'\cdot B = 0\)이므로, \(B'\)은 \(N\)의 배수이다. 이 배수를 \(-\tau\)라 부른 것이 열률의 정의이다. 끝으로 반대칭성에서 \(\omega_{21} = -\kappa\), \(\omega_{23} = \tau\), \(\omega_{22} = 0\)이므로 \(N' = -\kappa T + \tau B\)이다. ∎

임의 속력 \(v = |\alpha'|\)인 곡선에서는 \(\frac{d}{dt} = v\frac{d}{ds}\)이므로 오른쪽 행렬에 \(v\)를 곱하면 된다. 예를 들어 \(T' = v\kappa N\)이다.

2.2.3다르부 벡터, 틀의 회전

\(\mathbf D = \tau T + \kappa B\)로 두면 프레네 공식은 \(T' = \mathbf D\times T\), \(N' = \mathbf D\times N\), \(B' = \mathbf D\times B\)로 쓰인다. 가령 \(\mathbf D\times T = \kappa B\times T = \kappa N\)이다. 곧 곡선을 따라 움직일 때 프레네 틀은 순간마다 축 \(\mathbf D\) 둘레로 각속도 \(|\mathbf D| = \sqrt{\kappa^2 + \tau^2}\)로 회전하는 강체처럼 움직인다. 다시 말해 \(\kappa\)는 \(B\)축 둘레의 회전, 곧 접촉평면 안에서 휘기이고, \(\tau\)는 \(T\)축 둘레의 회전, 곧 비틀기이다. 나선에서는 \(\kappa, \tau\)가 상수라 틀이 일정한 축 둘레로 고르게 돈다. 같은 절의 탐구 카드에서 틀이 움직이는 모습을 본다.

2.2.4프레네 공식의 쓰임

먼저 국소 표준형을 얻는다. 테일러 전개에 프레네 공식을 쓰면 \(\beta(s) = \beta(0) + sT_0 + \frac{s^2}2\kappa_0N_0 + \frac{s^3}6(-\kappa_0^2T_0 + \kappa_0'N_0 + \kappa_0\tau_0B_0) + O(s^4)\)이다. \(B\) 방향의 첫 항이 \(\frac{\kappa\tau}6s^3\)이므로, 곡선은 접촉평면에서 3차로 벗어나고 그 정도가 \(\tau\)이다. 다음으로 2.3절에서 곡선을 분류한다. \(\kappa = 0\)이면 직선, \(\tau = 0\)이면 평면곡선, \(\kappa, \tau\)가 상수면 나선이다. 또 3단원에서는 \(\kappa, \tau\)가 같으면 같은 미분방정식을 풀므로 곡선이 강체운동을 빼고 같다는 것을 보인다.

흔한 오해\(N' = \tau B\)로 쓰고 \(-\kappa T\)를 빠뜨리기 쉬운데, 반대칭성을 떠올리면 막을 수 있다. 또 임의 속력 곡선에 단위속력 공식을 그대로 쓰는 실수가 있다. \(\tau\)의 부호 약속 \(B' = -\tau N\)이 모든 교재에서 같다고 여기는 것도 주의한다. 오닐과 두카르모는 이 약속을 쓰지만 일부 문헌은 반대이다.
마무리

처음 질문의 답은 "쓸 수 있다"이다. 정규직교틀의 미분 계수는 반대칭이므로 독립 성분이 셋뿐이고, 프레네 틀에서는 그것이 \(\kappa\), 0, \(\tau\)이다. 그래서 \(T' = \kappa N\), \(N' = -\kappa T + \tau B\), \(B' = -\tau N\)이 되며, 틀은 다르부 벡터 \(\tau T + \kappa B\) 둘레로 각속도 \(\sqrt{\kappa^2 + \tau^2}\)로 회전한다. \(\kappa\)는 휘기, \(\tau\)는 비틀기이고, 이 공식이 곡선의 분류와 합동 판정의 바탕이 된다.

2.2.5연습문제

기본

  1. \(\mathbf D = \tau T + \kappa B\)에 대해 \(\mathbf D\times N = N'\)과 \(\mathbf D\times B = B'\)을 확인하여라.
    답

    \(T\times N = B\), \(B\times N = -T\)이므로 \(\mathbf D\times N = \tau B - \kappa T = N'\). \(T\times B = -N\), \(B\times B = 0\)이므로 \(\mathbf D\times B = -\tau N = B'\).

응용

  1. 단위속력 곡선에서 \(\beta''' = -\kappa^2T + \kappa'N + \kappa\tau B\)임을 보여라.
    답

    \(\beta'' = \kappa N\)을 미분하면 \(\kappa'N + \kappa N' = \kappa'N + \kappa(-\kappa T + \tau B)\).

심화

  1. 단위속력 곡선이 원점을 중심으로 한 구면 \(|\beta| = r\) 위에 있으면 \(\kappa \ge \frac1r\)임을 보여라.
    답

    \(\beta\cdot\beta = r^2\)을 두 번 미분하면 \(\beta\cdot T = 0\), \(T\cdot T + \beta\cdot\kappa N = 0\), 곧 \(\kappa(\beta\cdot N) = -1\). 코시-슈바르츠로 \(1 = \kappa|\beta\cdot N| \le \kappa r\).
