당김과 외미분이 교환함을 계산으로 확인하기

예제 · 외곱, 외미분, 당김

먼저 예측

1-형식 \(\phi = -y\,dx + x\,dy\)를 극좌표 사상으로 당기면 \(dr\) 항과 \(d\theta\) 항 중 무엇이 남을까?

예측 확인

\(d\theta\) 항만 남습니다(\(r^2\,d\theta\)). \(\phi\)는 원점 둘레를 도는 방향의 성분을 재기 때문입니다.

\(F(r, \theta) = (r\cos\theta, r\sin\theta)\)이고 \(\phi = -y\,dx + x\,dy\)일 때 (1) \(F^*\phi\), (2) \(d\phi\)와 \(F^*(d\phi)\), (3) \(d(F^*\phi)\)를 구하고 (2)와 (3)이 같음을 확인하여라.

전략

당김은 \(x, y\)에 \(r\cos\theta\), \(r\sin\theta\)를, \(dx, dy\)에 그 미분을 대입하는 것이다. 외곱의 규칙 \(d\theta\wedge dr = -dr\wedge d\theta\)에 주의한다 (1.2절).

풀이

  1. \(dx = \cos\theta\,dr - r\sin\theta\,d\theta\), \(dy = \sin\theta\,dr + r\cos\theta\,d\theta\).
    \(d(r\cos\theta)\), \(d(r\sin\theta)\).
  2. \(F^*\phi = -r\sin\theta(\cos\theta\,dr - r\sin\theta\,d\theta) + r\cos\theta(\sin\theta\,dr + r\cos\theta\,d\theta) = r^2\,d\theta\).
    \(dr\) 항이 상쇄된다.
  3. \(d\phi = -dy\wedge dx + dx\wedge dy = 2\,dx\wedge dy\), \(F^*(dx\wedge dy) = dF_1\wedge dF_2 = r\,dr\wedge d\theta\)이므로 \(F^*(d\phi) = 2r\,dr\wedge d\theta\).
    \(dx\wedge dy\)의 당김은 야코비 행렬식 \(r\)배.
  4. \(d(F^*\phi) = d(r^2)\wedge d\theta = 2r\,dr\wedge d\theta\). (2)와 같다.
    \(F^*d = dF^*\).

검산

단위원 \(r = 1\), \(\theta: 0 \to 2\pi\)에서 \(\int F^*\phi = \int_0^{2\pi}1\,d\theta = 2\pi\)이고, 단위원판에서 \(\iint d\phi = 2\cdot\pi = 2\pi\)입니다. 스토크스 정리(5단원)와 맞습니다.

의미

"당긴 뒤 미분 = 미분한 뒤 당김"이라서, 형식의 계산을 편한 좌표에서 해도 됩니다. 이 성질 덕분에 곡면 위의 형식과 적분이 좌표조각의 선택에 무관하게 정의됩니다.

이해 확인

같은 \(F\)로 \(\psi = x\,dx + y\,dy\)를 당기면?

답

\(r\cos\theta(\cos\theta\,dr - r\sin\theta\,d\theta) + r\sin\theta(\sin\theta\,dr + r\cos\theta\,d\theta) = r\,dr\). \(\psi = d\left(\frac{x^2 + y^2}2\right)\)이고 \(F^*\psi = d\left(\frac{r^2}2\right)\)로 맞다.
