좌표조각, 정칙 곡면, 접평면

본문
이 절에서 배울 것
  • 매개곡면(좌표조각) \(\mathbf x(u, v)\)와 편미분 \(\mathbf x_u\), \(\mathbf x_v\)의 뜻을 안다.
  • \(\mathbf x_u\times\mathbf x_v \ne \mathbf 0\)으로 정칙성을 판정하고, 특이점이 생기는 원인(매개화의 문제인지 곡면의 문제인지)을 구별한다.
  • 접평면과 단위법벡터를 구한다.
먼저 알아야 할 것
  • 계수정리와 몰입 (수학11 2.3절), 외적, 곡선의 속도 (1.1절).

4.1.1좌표조각

좌표조각(coordinate patch): 평면의 열린집합 \(D\)에서 \(\mathbb R^3\)으로 가는 매끄러운 사상 \(\mathbf x(u, v) = (x_1(u, v), x_2(u, v), x_3(u, v))\)로, 일대일이고 \(\mathbf x_u\times\mathbf x_v \ne \mathbf 0\)인 것(정칙). 역사상이 연속이라는 조건(적합한 조각)도 덧붙인다.

곡면(surface): 각 점이 어떤 좌표조각의 상에 들어 있고, 그 조각들이 곡면의 근방을 덮는 \(\mathbb R^3\)의 부분집합.

\(\mathbf x_u = \frac{\partial\mathbf x}{\partial u}\)는 \(v\)를 고정한 곡선(\(u\)-매개변수 곡선)의 속도, \(\mathbf x_v\)는 \(v\)-매개변수 곡선의 속도입니다. 두 벡터가 일차독립(외적이 0이 아님)이라는 것은 야코비 행렬 \((\mathbf x_u\ \mathbf x_v)\)의 계수가 2, 곧 \(\mathbf x\)가 몰입이라는 뜻입니다. 이때 계수정리로 상이 국소적으로 매끄러운 2차원 조각입니다.

4.1.2예와 특이점

  • 그래프 \(\mathbf x(u, v) = (u, v, f(u, v))\): \(\mathbf x_u = (1, 0, f_u)\), \(\mathbf x_v = (0, 1, f_v)\), \(\mathbf x_u\times\mathbf x_v = (-f_u, -f_v, 1) \ne \mathbf 0\). 언제나 정칙입니다.
  • 구면의 지리 좌표 \(\mathbf x(u, v) = (\cos u\cos v, \cos u\sin v, \sin u)\) (\(u\)는 위도): \(|\mathbf x_u\times\mathbf x_v| = |\cos u|\)이라 극(\(u = \pm\frac\pi2\))에서 0입니다. 구면 자체는 극에서도 매끄럽지만 이 매개화가 극에서 퇴화한 것입니다(경선이 모두 한 점에 모임). 다른 조각(예: 극을 적도로 옮긴 회전)으로 극을 덮으면 됩니다.
  • 원뿔 \(\mathbf x(u, v) = (u\cos v, u\sin v, u)\): \(|\mathbf x_u\times\mathbf x_v| = \sqrt2|u|\)이라 꼭짓점(\(u = 0\))에서 0입니다. 이 경우는 매개화를 바꿔도 해결되지 않습니다. 원뿔은 꼭짓점에서 곡면이 아닙니다(근방이 두 원판이 한 점에서 붙은 모양).
  • 원환면 \(\mathbf x(u, v) = ((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\) (\(R > r > 0\)): \(|\mathbf x_u\times\mathbf x_v| = r(R + r\cos u) > 0\). 어디서나 정칙입니다.

같은 절의 탐구 카드에서 이 조각들의 \(\mathbf x_u\), \(\mathbf x_v\), 법벡터를 점마다 그려 봅니다.

4.1.3접평면과 법벡터

접평면 \(T_{\mathbf p}M\): \(\mathbf p\)를 지나는 곡면 위 곡선들의 속도 전체. 좌표조각 \(\mathbf x\)로 \(\mathbf p = \mathbf x(u_0, v_0)\)이면 \(\operatorname{span}\{\mathbf x_u, \mathbf x_v\}\) (\(\mathbf p\)에 붙은 접벡터).

단위법벡터 \(U = \frac{\mathbf x_u\times\mathbf x_v}{|\mathbf x_u\times\mathbf x_v|}\). 접평면의 방정식은 \((\mathbf q - \mathbf p)\cdot U = 0\).

곡면 위의 곡선 \(\alpha(t) = \mathbf x(u(t), v(t))\)의 속도는 연쇄 법칙으로 \(\alpha' = u'\mathbf x_u + v'\mathbf x_v\)이므로 접평면 안에 있습니다. 거꾸로 접평면의 모든 벡터가 이렇게 얻어집니다.

예제 4.1.1

나선면 \(\mathbf x(u, v) = (u\cos v, u\sin v, v)\)의 \((u, v) = (1, \frac\pi2)\)에서 접평면을 구하여라.

풀이. \(\mathbf p = (0, 1, \frac\pi2)\). \(\mathbf x_u = (\cos v, \sin v, 0) = (0, 1, 0)\), \(\mathbf x_v = (-u\sin v, u\cos v, 1) = (-1, 0, 1)\). \(\mathbf x_u\times\mathbf x_v = (1\cdot1 - 0, 0 - 0, 0 + 1) = (1, 0, 1)\). 접평면은 \(x + (z - \frac\pi2) = 0\), 곧 \(x + z = \frac\pi2\). 일반적으로 \(|\mathbf x_u\times\mathbf x_v| = \sqrt{1 + u^2} > 0\)이라 나선면은 어디서나 정칙입니다.

흔한 오해(1) 매개화의 특이점과 곡면의 특이점을 혼동한다(구면의 극과 원뿔의 꼭짓점). (2) 일대일 조건을 잊는다. \((\cos u, \sin u, v)\)를 \(u \in \mathbb R\)에서 쓰면 원기둥을 무한히 덮어 좌표조각이 아니다. (3) 법벡터의 방향(\(\mathbf x_u\times\mathbf x_v\)냐 그 반대냐)은 \(u\), \(v\)의 순서로 정해진다.
요약
  1. 좌표조각: 일대일, 정칙(\(\mathbf x_u\times\mathbf x_v \ne \mathbf 0\)), 역이 연속. 곡면은 그런 조각들로 덮인 집합.
  2. 매개화의 특이점(구면의 극)은 다른 조각으로 해결되지만, 곡면의 특이점(원뿔의 꼭짓점)은 그렇지 않다.
  3. 접평면 \(= \operatorname{span}\{\mathbf x_u, \mathbf x_v\}\), 법벡터 \(U = \frac{\mathbf x_u\times\mathbf x_v}{|\mathbf x_u\times\mathbf x_v|}\).

4.1.4연습문제

기본

  1. \(z = x^2 - y^2\) 위의 점 \((1, 1, 0)\)에서 접평면을 구하여라.
    답

    법벡터 \((-f_u, -f_v, 1) = (-2, 2, 1)\). \(-2(x - 1) + 2(y - 1) + z = 0\), 곧 \(z = 2x - 2y\).

응용

  1. 원환면 매개화에서 \(|\mathbf x_u\times\mathbf x_v| = r(R + r\cos u)\)임을 보여라.
    답

    \(\mathbf x_u = (-r\sin u\cos v, -r\sin u\sin v, r\cos u)\), \(\mathbf x_v = (-(R + r\cos u)\sin v, (R + r\cos u)\cos v, 0)\). 두 벡터는 수직이고 길이가 \(r\)과 \(R + r\cos u\)이므로 외적의 크기는 곱이다.

심화

  1. 회전면 \(\mathbf x(u, v) = (g(u)\cos v, g(u)\sin v, h(u))\)가 정칙일 조건을 구하여라(\(g > 0\)).
    답

    \(\mathbf x_u = (g'\cos v, g'\sin v, h')\), \(\mathbf x_v = (-g\sin v, g\cos v, 0)\)은 수직이고 \(|\mathbf x_u\times\mathbf x_v| = g\sqrt{g'^2 + h'^2}\). 따라서 단면 곡선 \((g(u), h(u))\)가 정칙(\((g', h') \ne \mathbf 0\))이면 회전면도 정칙이다.
