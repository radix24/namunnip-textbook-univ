곡률과 열률의 계산

본문

공간의 곡선이 얼마나 휘는지, 그리고 한 평면에서 얼마나 벗어나며 비틀리는지를 수 하나씩으로 잴 수 있을까? 나선 계단의 난간처럼 일정하게 휘고 비틀리는 곡선에서는 그 수가 얼마일까? 곡선을 어떤 빠르기로 따라가든 같은 값이 나오게 하려면 어떻게 할까?

먼저 알아야 할 것곡선의 속도(1.1절), 외적과 내적, 역함수의 미분을 쓴다.

2.1.1정칙 곡선과 호의 길이

정의

모든 \(t\)에서 \(\alpha'(t) \ne \mathbf 0\)인 매끄러운 곡선을 정칙 곡선이라 한다. \(s(t) = \int_{t_0}^t|\alpha'(u)|\,du\)를 호의 길이 함수라 하며, 정칙이면 \(s'(t) = |\alpha'(t)| > 0\)이라 역함수 \(t(s)\)가 있다. 그때 \(\beta(s) = \alpha(t(s))\)는 \(|\beta'(s)| = 1\)인 단위속력 곡선이다.

예를 들어 나선 \(\alpha(t) = (a\cos t, a\sin t, bt)\)는 \(|\alpha'| = \sqrt{a^2 + b^2} = c\)로 일정하므로 \(s = ct\)이고 \(\beta(s) = (a\cos\frac sc, a\sin\frac sc, \frac{bs}c)\)이다. 하지만 대부분의 곡선은 \(s(t)\)를 닫힌 꼴로 적분하거나 뒤집을 수 없으므로, 아래에서 임의의 매개변수로 계산하는 공식을 만든다.

2.1.2단위속력 곡선의 틀

\(\beta\)가 단위속력이면 \(T = \beta'\)는 단위 접벡터이다. \(|T| = 1\)을 미분하면 \(T\cdot T' = 0\)이므로 \(T'\)은 \(T\)에 수직이다.

정의

\(\kappa(s) = |T'(s)|\)를 곡률이라 하며, 방향이 얼마나 빨리 바뀌는지 잰다. \(\kappa > 0\)일 때 \(N = T'/\kappa\)를 주법선, \(B = T\times N\)을 종법선이라 하고, \((T, N, B)\)를 프레네 틀이라 한다. \(B' = -\tau N\)으로 정해지는 수 \(\tau\)를 열률이라 하며, 곡선이 \(T\)와 \(N\)이 생성하는 접촉평면에서 벗어나는 빠르기이다.

\(B'\)이 \(N\)의 배수라는 것은 2.2절에서 증명한다. 반지름 \(r\)인 원은 \(\kappa = \frac1r\), \(\tau = 0\)이다. 또 곡률은 일변수 미적분에서 배운 접촉원 반지름의 역수와 같으며, 같은 절의 탐구 카드에서 확인한다.

2.1.3임의의 속력 곡선의 공식

정리 2.1.1

정칙 곡선 \(\alpha\)에서 \(\alpha' \times \alpha'' \ne \mathbf 0\)이고 \(v = |\alpha'|\)이면 다음이 성립한다.

\[T = \frac{\alpha'}{v}, \quad B = \frac{\alpha'\times\alpha''}{|\alpha'\times\alpha''|}, \quad N = B\times T, \quad \kappa = \frac{|\alpha'\times\alpha''|}{v^3}, \quad \tau = \frac{(\alpha'\times\alpha'')\cdot\alpha'''}{|\alpha'\times\alpha''|^2}.\]

증명.\(\alpha'(t) = vT\)를 미분하면, 연쇄 법칙 \(\frac{dT}{dt} = v\frac{dT}{ds} = v\kappa N\)으로 \(\alpha'' = v'T + \kappa v^2N\)이다. 외적하면 \(\alpha'\times\alpha'' = \kappa v^3\,T\times N = \kappa v^3B\)이므로 \(B\)와 \(\kappa\)의 식이 나온다. 다시 미분하면 \(N\)의 미분에서 \(\tau B\)가 나오므로 \(\alpha''' = (\ldots)T + (\ldots)N + \kappa v^3\tau\,B\)이다. 이것을 \(B\)와 내적하면 \((\alpha'\times\alpha'')\cdot\alpha''' = \kappa v^3\cdot\kappa v^3\tau = |\alpha'\times\alpha''|^2\tau\)이다. ∎

2.1.4예

예제 2.1.2 (나선)

\(\alpha(t) = (a\cos t, a\sin t, bt)\) (\(a > 0\))의 곡률과 열률을 구하여라.

풀이. \(\alpha' = (-a\sin t, a\cos t, b)\), \(\alpha'' = (-a\cos t, -a\sin t, 0)\), \(\alpha''' = (a\sin t, -a\cos t, 0)\)이다. 그러면 \(\alpha'\times\alpha'' = (ab\sin t, -ab\cos t, a^2)\)이고 \(|\alpha'\times\alpha''| = a\sqrt{a^2 + b^2}\), \((\alpha'\times\alpha'')\cdot\alpha''' = a^2b\)이다. 따라서 \(\kappa = \frac a{a^2 + b^2}\)이고 \(\tau = \frac b{a^2 + b^2}\)이다. 예를 들어 \(a = 2\), \(b = 1\)이면 \(\kappa = 0.4\), \(\tau = 0.2\)이다. \(b = 0\)이면 원이고, \(b < 0\)이면 왼나사라 \(\tau < 0\)이다.

예제 2.1.3 (꼬인 삼차곡선)

\(\alpha(t) = (t, t^2, t^3)\)의 \(t = 0\)과 \(t = 1\)에서 곡률과 열률을 구하여라.

풀이. \(t = 0\)에서 \(\alpha' = (1, 0, 0)\), \(\alpha'' = (0, 2, 0)\), \(\alpha''' = (0, 0, 6)\)이므로 \(\alpha'\times\alpha'' = (0, 0, 2)\)이고 \(\kappa = 2\), \(\tau = \frac{12}4 = 3\)이다. 일반적으로 \(\tau = \frac3{9t^4 + 9t^2 + 1}\)이고, \(t = 1\)이면 \(\tau = \frac3{19} \approx 0.158\), \(\kappa = \frac{\sqrt{76}}{14^{3/2}} \approx 0.166\)이다. 그림 1이 이 두 함수이다.

흔한 오해단위속력이 아닌 곡선에 \(\kappa = |\alpha''|\)을 쓰는 실수가 많다. 속력이 변하면 가속도에 접선 성분이 생기기 때문이다. 또 곡률은 늘 0 이상이지만 열률은 부호가 있다는 점을 놓치기 쉽다. \(\kappa = 0\)인 점에서는 \(N\)과 \(\tau\)가 정의되지 않는다는 것도 주의한다.
마무리

처음 질문의 답은 "잴 수 있다"이다. 곡률 \(\kappa = |T'|\)은 휘는 빠르기를, 열률 \(\tau\)는 접촉평면에서 벗어나 비틀리는 빠르기를 재며, 단위속력 매개화로 정의하므로 따라가는 빠르기와 무관하다. 임의의 매개변수에서는 \(\kappa = |\alpha'\times\alpha''|/v^3\), \(\tau = (\alpha'\times\alpha'')\cdot\alpha'''/|\alpha'\times\alpha''|^2\)으로 계산한다. 나선은 \(\kappa = \frac a{a^2 + b^2}\), \(\tau = \frac b{a^2 + b^2}\)로 둘 다 상수이다.

2.1.5연습문제

기본

  1. 평면곡선 \(y = f(x)\)의 곡률이 \(\frac{|f''|}{(1 + f'^2)^{3/2}}\)임을 정리 2.1.1로 보여라.
    답

    \(\alpha = (x, f(x), 0)\), \(\alpha' = (1, f', 0)\), \(\alpha'' = (0, f'', 0)\), \(\alpha'\times\alpha'' = (0, 0, f'')\). \(\kappa = \frac{|f''|}{(1 + f'^2)^{3/2}}\).

응용

  1. \(\alpha(t) = (e^t\cos t, e^t\sin t, e^t)\)의 곡률을 \(t = 0\)에서 구하여라.
    답

    \(\alpha'(0) = (1, 1, 1)\), \(\alpha''(0) = (0, 2, 1)\). 외적 \((1\cdot1 - 1\cdot2, 1\cdot0 - 1\cdot1, 1\cdot2 - 1\cdot0) = (-1, -1, 2)\), 크기 \(\sqrt6\). \(\kappa = \frac{\sqrt6}{3^{3/2}} = \frac{\sqrt2}3 \approx 0.4714\).

심화

  1. 단위속력 곡선에서 \(\kappa\)와 \(\tau\)는 매개변수의 방향을 바꾸면(\(\beta(-s)\)) 어떻게 되는가?
    답

    \(T\)는 부호가 바뀌고 \(T' = \frac{d}{ds}(-\beta'(-s)) = \beta''(-s)\)라 \(\kappa\)와 \(N\)은 그대로, \(B = T\times N\)은 부호가 바뀐다. \(B' = -\tau N\)에서 \(B\)와 미분 방향이 모두 바뀌어 \(\tau\)는 그대로이다. 곡률과 열률은 방향에 무관한 곡선의 성질이다.
