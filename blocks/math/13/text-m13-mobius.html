방향 가능성과 뫼비우스 띠

본문
이 절에서 배울 것
  • 곡면의 연결성, 컴팩트성, 방향 가능성의 뜻을 정리한다.
  • 뫼비우스 띠의 중심선을 따라 법벡터를 연속으로 옮기면 한 바퀴 뒤 반대 방향이 됨을 계산으로 보이고, 방향 불가능함을 증명한다.
  • 방향 가능성을 좌표조각의 전이(야코비 행렬식의 부호)로 판정하는 방법을 안다.
먼저 알아야 할 것
  • 곡면의 방향 (5.1절), 좌표조각 (4.1절), 연결집합 (수학7 1.4절).

6.1.1곡면의 전체적 성질

  • 연결: 곡면 위의 두 점을 곡면 안의 곡선으로 이을 수 있다(곡면에서는 경로연결과 같다).
  • 컴팩트: \(\mathbb R^3\)에서 유계이고 닫힌 집합. 구면, 원환면은 컴팩트이고 평면, 원기둥은 아니다.
  • 방향 가능: 곡면 전체에서 연속인 단위법벡터장 \(U\)가 있다(5.1절).

음함수 꼴 곡면 \(g = c\)는 \(U = \nabla g/|\nabla g|\)라 늘 방향 가능합니다. 그래서 \(\mathbb R^3\)의 컴팩트 곡면은 모두 방향 가능하다는 정리가 있습니다(조르당-브라우어 분리 정리: 안과 밖이 있다). 방향 불가능한 곡면은 경계가 있거나 컴팩트하지 않아야 \(\mathbb R^3\)에 들어갑니다.

6.1.2뫼비우스 띠

긴 종이띠를 반 바퀴 비틀어 양 끝을 붙인 것을 매개화하면

\[\mathbf x(u, v) = \left(\left(1 + v\cos\tfrac u2\right)\cos u,\ \left(1 + v\cos\tfrac u2\right)\sin u,\ v\sin\tfrac u2\right), \quad 0 \le u \le 2\pi,\ -\tfrac12 < v < \tfrac12\]

입니다. 중심선(\(v = 0\))은 단위원이고, 그 위에서 띠의 가로 방향 \(\mathbf x_v = (\cos\frac u2\cos u, \cos\frac u2\sin u, \sin\frac u2)\)가 \(u\)가 \(2\pi\) 도는 동안 반 바퀴(\(\pi\)) 돕니다. 그리고 \(\mathbf x(u + 2\pi, -v) = \mathbf x(u, v)\)이므로 \(u = 2\pi\)에서의 가로 선분은 \(u = 0\)의 가로 선분을 뒤집어 붙인 것입니다.

정리 6.1.1

뫼비우스 띠는 방향 가능하지 않다.

증명.중심선 위에서 \(\mathbf x_u\times\mathbf x_v\)를 계산하면 \(N(u) = \left(\cos u\sin\frac u2, \sin u\sin\frac u2, -\cos\frac u2\right)\) (단위벡터)이다. \(N\)은 \(u\)에 대해 연속이고 \(N(0) = (0, 0, -1)\), \(N(2\pi) = (0, 0, 1)\)이며, 이 두 값은 같은 점 \((1, 0, 0)\)에서의 법벡터이다. 연속인 단위법벡터장 \(U\)가 있다고 하자. 각 \(u\)에서 \(U(\mathbf x(u, 0)) = \varepsilon(u)N(u)\), \(\varepsilon(u) = \pm1\)이고 \(\varepsilon = U\cdot N\)은 연속이므로 상수이다(\([0, 2\pi]\)가 연결). 그런데 \(u = 0\)과 \(u = 2\pi\)는 같은 점이라 \(U\)의 값이 같아야 하므로 \(\varepsilon N(0) = \varepsilon N(2\pi)\), 곧 \(N(0) = N(2\pi)\)인데 이는 거짓이다. ∎

같은 절의 탐구 카드에서 중심선을 따라 법벡터를 옮겨 보면 한 바퀴 뒤 정확히 반대 방향이 됩니다. 두 바퀴를 돌아야 원래로 돌아옵니다.

6.1.3좌표조각으로 판정하기

곡면을 덮는 좌표조각들 \(\mathbf x_\alpha\)이 있을 때, 두 조각이 겹치는 곳에서 좌표 변환 \(\mathbf x_\beta^{-1}\circ\mathbf x_\alpha\)의 야코비 행렬식이 항상 양수가 되게 조각들을 고를 수 있으면 방향 가능합니다(\(\mathbf x_u\times\mathbf x_v\)의 방향이 일치). 뫼비우스 띠를 두 조각(\(0 < u < \frac{3\pi}2\)과 \(\pi < u < \frac{5\pi}2\))으로 덮으면 겹치는 두 부분 중 하나에서는 행렬식이 양수, 다른 하나에서는 음수(\(v \mapsto -v\))이고, 어느 조각의 방향을 뒤집어도 이 불일치가 사라지지 않습니다. 이 판정법은 6.3절의 추상 다양체에서 방향의 정의가 됩니다.

흔한 오해(1) "뫼비우스 띠는 면이 하나라서 방향 불가능하다"는 직관으로는 맞지만, 증명은 법벡터장의 연속성으로 해야 한다. (2) "띠를 한 바퀴(2π) 비틀면 방향 불가능": 한 바퀴 비틀면 방향 가능하다. 반 바퀴의 홀수 배여야 방향 불가능하다.
요약
  1. 방향 가능 ⟺ 연속인 단위법벡터장이 있다 ⟺ 전이의 야코비 행렬식을 모두 양수로 맞출 수 있다.
  2. 뫼비우스 띠: 중심선을 한 바퀴 돌면 법벡터가 \(N(0) = -N(2\pi)\)로 뒤집혀 방향 불가능.
  3. \(\mathbb R^3\)의 컴팩트(경계 없는) 곡면과 음함수 꼴 곡면은 방향 가능.

6.1.4연습문제

기본

  1. 원기둥 \(x^2 + y^2 = 1\)이 방향 가능함을 보여라.
    답

    \(U = (x, y, 0)\)이 연속인 단위법벡터장이다(음함수 꼴).

응용

  1. 뫼비우스 띠를 중심선을 따라 자르면 무엇이 되는가? 그것은 방향 가능한가?
    답

    한 개의 긴 띠가 되며, 두 바퀴(\(4\pi\)) 비틀어져 있어 방향 가능하다(반 바퀴의 짝수 배). 중심선은 원래 띠의 경계가 아니었으므로 자른 뒤 길이가 두 배인 하나의 띠가 된다.

심화

  1. 정리 6.1.1의 증명에서 \(N(u)\)를 직접 계산하여라.
    답

    \(v = 0\)에서 \(\mathbf x_u = (-\sin u, \cos u, 0)\), \(\mathbf x_v = (\cos\frac u2\cos u, \cos\frac u2\sin u, \sin\frac u2)\). 외적 \(= (\cos u\sin\frac u2, \sin u\sin\frac u2, -\cos\frac u2)\)이고 길이 1이다. \(u = 0\)에서 \((0, 0, -1)\), \(u = 2\pi\)에서 \((0, 0, 1)\).
