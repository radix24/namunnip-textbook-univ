회전하는 흐름의 가속도

예제 · 공변미분으로 구심 가속도 구하기

먼저 예측

벡터장 \(W = -yU_1 + xU_2\)는 \(z\)축 둘레로 도는 흐름이다. \(\nabla_WW\)(흐름을 따라 움직이는 입자의 가속도)는 어느 쪽을 향할까?

예측 확인

\(z\)축 쪽, 곧 회전 중심을 향한다. 크기는 축까지의 거리와 같다.

\(W = -yU_1 + xU_2\)에 대해 (1) \(\nabla_WW\)를 구하고, (2) 점 \((3, 4, 0)\)에서 그 크기를 구하고, (3) 흐름선 \(\alpha(t) = (3\cos t - 4\sin t, 3\sin t + 4\cos t, 0)\)의 가속도와 비교하여라.

전략

정리 1.4.1로 성분 \(-y\), \(x\)를 \(W\) 방향으로 미분합니다(1.4절). 흐름선을 따른 \(W\)의 변화가 곧 가속도입니다(1.4.3).

풀이

  1. \(W[-y] = \nabla(-y)\cdot(-y, x, 0) = -x\), \(W[x] = \nabla x\cdot(-y, x, 0) = -y\).
    방향도함수.
  2. \(\nabla_WW = -xU_1 - yU_2\).
    정리 1.4.1.
  3. \((3, 4, 0)\)에서 \((-3, -4, 0)\), 크기 5. 축까지의 거리 \(r = 5\)와 같다.
    속력 \(|W| = r\)이라 구심 가속도 \(\frac{|W|^2}r = r\).
  4. \(\alpha''(t) = -\alpha(t)\)이고 \(t = 0\)에서 \(\alpha(0) = (3, 4, 0)\), \(\alpha''(0) = (-3, -4, 0)\)으로 같다.
    \(\alpha' = W\circ\alpha\)이므로 \(\alpha'' = \nabla_{\alpha'}W\).

검산

\(W\cdot\nabla_WW = (-y)(-x) + x(-y) = 0\)이라 가속도가 속도에 수직이다. 속력이 일정한 운동이라는 뜻이고, 실제로 \(|W|^2 = x^2 + y^2\)은 흐름선 위에서 상수이다.

의미

\(\nabla_WW\)는 유체역학에서 "흐름을 따라가며 본 속도 변화"(대류 가속도)이다. 각 점의 속도는 시간에 따라 변하지 않는데도, 입자는 방향이 바뀌므로 가속한다.

이해 확인

\(W' = xU_1 + yU_2\)(바깥으로 퍼지는 흐름)에서 \(\nabla_{W'}W'\)은?

답

\(W'[x] = x\), \(W'[y] = y\)라 \(xU_1 + yU_2 = W'\). 바깥으로 가속한다.
