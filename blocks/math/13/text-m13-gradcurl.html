외미분과 기울기, 회전, 발산

본문
이 절에서 배울 것
  • \(\mathbb R^3\)의 1-형식, 2-형식을 벡터장과 대응시키는 사전을 만든다.
  • 이 사전 아래에서 \(d\)가 기울기, 회전, 발산이 되고, 외곱이 외적과 내적이 됨을 확인한다.
  • \(d^2 = 0\)과 푸앵카레 보조정리를 벡터해석의 항등식과 퍼텐셜 존재 정리로 읽는다.
먼저 알아야 할 것
  • 외곱과 외미분 (1.2절).

1.3.1사전

벡터장 \(V = \sum f_iU_i\)에 다음 두 형식을 대응시킵니다.

\[V \;\leftrightarrow\; \phi_V = f_1\,dx + f_2\,dy + f_3\,dz, \qquad V \;\leftrightarrow\; \eta_V = f_1\,dy\wedge dz + f_2\,dz\wedge dx + f_3\,dx\wedge dy,\]

그리고 함수 \(g\)에는 0-형식 \(g\)와 3-형식 \(g\,dx\wedge dy\wedge dz\)를 대응시킵니다. 2-형식의 기저를 \(dy\wedge dz\), \(dz\wedge dx\), \(dx\wedge dy\)의 "순환 순서"로 잡은 것이 요점입니다(\(dz\wedge dx\)이지 \(dx\wedge dz\)가 아님).

1.3.2\(d\)의 정체

정리 1.3.1

(a) \(dg = \phi_{\nabla g}\). (b) \(d\phi_V = \eta_{\nabla\times V}\). (c) \(d\eta_V = (\nabla\cdot V)\,dx\wedge dy\wedge dz\).

증명.(a)는 \(dg = g_xdx + g_ydy + g_zdz\)이다. (b) \(d(f_1dx) = f_{1,y}\,dy\wedge dx + f_{1,z}\,dz\wedge dx = -f_{1,y}\,dx\wedge dy + f_{1,z}\,dz\wedge dx\)이고, \(f_2dy\), \(f_3dz\)도 같이 계산해 모으면 \(dy\wedge dz\)의 계수 \(f_{3,y} - f_{2,z}\), \(dz\wedge dx\)의 계수 \(f_{1,z} - f_{3,x}\), \(dx\wedge dy\)의 계수 \(f_{2,x} - f_{1,y}\)로, 회전의 세 성분이다. (c) \(d(f_1dy\wedge dz) = f_{1,x}\,dx\wedge dy\wedge dz\) 등을 더한다. ∎

마찬가지로 외곱은 \(\phi_V\wedge\phi_W = \eta_{V\times W}\), \(\phi_V\wedge\eta_W = (V\cdot W)\,dx\wedge dy\wedge dz\)입니다. 외적이라는 "3차원에서만 있는 곱"이 외곱과 사전의 조합으로 설명되는 것입니다.

1.3.3\(d^2 = 0\)과 푸앵카레 보조정리

\(d(dg) = 0\)은 \(\nabla\times\nabla g = \mathbf 0\), \(d(d\phi_V) = 0\)은 \(\nabla\cdot(\nabla\times V) = 0\)입니다. 거꾸로, 별 모양 영역(예: \(\mathbb R^3\) 전체)에서는 닫힌 형식이 완전 형식이라는 푸앵카레 보조정리가 다음을 줍니다.

  • \(\nabla\times V = \mathbf 0\)이면 \(V = \nabla g\)인 퍼텐셜 \(g\)가 있다(보존장).
  • \(\nabla\cdot V = 0\)이면 \(V = \nabla\times W\)인 벡터 퍼텐셜 \(W\)가 있다.
예제 1.3.2

\(V = yzU_1 + xzU_2 + xyU_3\)이 보존장임을 보이고 퍼텐셜을 구하여라. \(W = -yU_1 + xU_2\)의 회전과 발산은?

풀이. \(\nabla\times V = (x - x, y - y, z - z) = \mathbf 0\)이고 \(g = xyz\)이면 \(\nabla g = V\). \(W\)에 대해 \(\nabla\times W = (0, 0, 1 - (-1)) = (0, 0, 2)\), \(\nabla\cdot W = 0\). \(W\)는 \(z\)축 둘레의 강체 회전으로, 회전의 크기 2는 각속도 1의 두 배입니다. 그리고 \(W = \nabla\times\left(-\frac12(x^2 + y^2)U_3\right)\)처럼 벡터 퍼텐셜을 가집니다.

1.3.4물리적 의미

  • 기울기: 가장 가파른 증가 방향이고 등위면에 수직.
  • 회전: 축 방향 \(\mathbf n\)의 작은 원판 둘레를 도는 선적분을 넓이로 나눈 극한이 \((\nabla\times V)\cdot\mathbf n\) (수학11 5.1절 탐구 카드의 고리 적분).
  • 발산: 작은 상자 밖으로 나가는 선속을 부피로 나눈 극한. 유체의 "솟아남"의 밀도.

이 해석들은 모두 스토크스 정리(5단원)의 국소판입니다.

흔한 오해(1) 2-형식의 기저를 \(dx\wedge dz\)로 잡아 회전의 둘째 성분 부호가 틀린다. (2) 구멍이 있는 영역에서도 회전 0이면 퍼텐셜이 있다고 여긴다. \(\frac{-yU_1 + xU_2}{x^2 + y^2}\)은 \(z\)축을 뺀 곳에서 회전이 0이지만 퍼텐셜이 없다.
요약
  1. 사전: 벡터장 ↔ 1-형식 \(\sum f_idx_i\), ↔ 2-형식 \(\sum f_i\,(dx_j\wedge dx_k)\) (순환 순서).
  2. \(d\): 0-형식 → 기울기, 1-형식 → 회전, 2-형식 → 발산. 외곱: 외적과 내적.
  3. \(d^2 = 0\): curl grad = 0, div curl = 0. 별 모양 영역에서 그 역(퍼텐셜 존재).

1.3.5연습문제

기본

  1. \(V = x^2U_1 + yzU_2 + U_3\)의 발산과 회전을 형식으로 계산하여라.
    답

    \(\nabla\cdot V = 2x + z\). \(\nabla\times V = (0 - y, 0 - 0, 0 - 0) = (-y, 0, 0)\).

응용

  1. \(\phi_V\wedge\phi_W = \eta_{V\times W}\)를 \(V = U_1\), \(W = U_2\)에서 확인하여라.
    답

    \(dx\wedge dy = \eta_{U_3}\)이고 \(U_1\times U_2 = U_3\).

심화

  1. \(\nabla\cdot(g V) = \nabla g\cdot V + g\,\nabla\cdot V\)를 형식의 곱 규칙 \(d(g\eta) = dg\wedge\eta + g\,d\eta\)로 증명하여라.
    답

    \(\eta_{gV} = g\eta_V\)이고 \(d(g\eta_V) = dg\wedge\eta_V + g\,d\eta_V = (\nabla g\cdot V + g\nabla\cdot V)\,dx\wedge dy\wedge dz\) (\(\phi_{\nabla g}\wedge\eta_V = (\nabla g\cdot V)\,dx\wedge dy\wedge dz\)).
