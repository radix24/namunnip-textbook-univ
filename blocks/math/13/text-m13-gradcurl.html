외미분과 기울기, 회전, 발산

본문

벡터해석의 기울기, 회전, 발산은 공식이 서로 다르게 생겼다. 그런데 1.2절의 외미분 \(d\) 하나로 이 셋이 모두 나온다면? 그리고 외적처럼 3차원에서만 있는 이상한 곱은 형식의 언어로 무엇일까?

먼저 알아야 할 것외곱과 외미분(1.2절)을 쓴다.

1.3.1사전

벡터장 \(V = \sum f_iU_i\)에 두 형식 \(\phi_V = f_1\,dx + f_2\,dy + f_3\,dz\)와 \(\eta_V = f_1\,dy\wedge dz + f_2\,dz\wedge dx + f_3\,dx\wedge dy\)를 대응시킨다. 또 함수 \(g\)에는 0-형식 \(g\)와 3-형식 \(g\,dx\wedge dy\wedge dz\)를 대응시킨다. 여기서 2-형식의 기저를 \(dy\wedge dz\), \(dz\wedge dx\), \(dx\wedge dy\)의 순환 순서로 잡은 것이 중요하다. \(dx\wedge dz\)가 아니라 \(dz\wedge dx\)이다.

1.3.2\(d\)의 정체

정리 1.3.1

(a) \(dg = \phi_{\nabla g}\). (b) \(d\phi_V = \eta_{\nabla\times V}\). (c) \(d\eta_V = (\nabla\cdot V)\,dx\wedge dy\wedge dz\).

증명.(a)는 \(dg = g_xdx + g_ydy + g_zdz\)이다. (b) \(d(f_1dx) = -f_{1,y}\,dx\wedge dy + f_{1,z}\,dz\wedge dx\)이고, \(f_2dy\)와 \(f_3dz\)도 같이 계산해 모으면 \(dy\wedge dz\)의 계수는 \(f_{3,y} - f_{2,z}\), \(dz\wedge dx\)의 계수는 \(f_{1,z} - f_{3,x}\), \(dx\wedge dy\)의 계수는 \(f_{2,x} - f_{1,y}\)이다. 이것이 회전의 세 성분이다. (c)는 \(d(f_1dy\wedge dz) = f_{1,x}\,dx\wedge dy\wedge dz\) 등을 더한다. ∎

마찬가지로 외곱은 \(\phi_V\wedge\phi_W = \eta_{V\times W}\)이고 \(\phi_V\wedge\eta_W = (V\cdot W)\,dx\wedge dy\wedge dz\)이다. 즉 외적이라는 3차원에서만 있는 곱이 외곱과 사전의 조합으로 설명된다.

1.3.3\(d^2 = 0\)과 푸앵카레 보조정리

\(d(dg) = 0\)은 \(\nabla\times\nabla g = \mathbf 0\)이고, \(d(d\phi_V) = 0\)은 \(\nabla\cdot(\nabla\times V) = 0\)이다. 거꾸로 \(\mathbb R^3\) 전체 같은 별 모양 영역에서는 닫힌 형식이 완전 형식이라는 푸앵카레 보조정리가 두 사실을 준다. 회전이 0인 벡터장 \(V\)에는 \(V = \nabla g\)인 퍼텐셜 \(g\)가 있고, 발산이 0인 벡터장 \(V\)에는 \(V = \nabla\times W\)인 벡터 퍼텐셜 \(W\)가 있다.

예제 1.3.2

\(V = yzU_1 + xzU_2 + xyU_3\)이 보존장임을 보이고 퍼텐셜을 구하여라. 또 \(W = -yU_1 + xU_2\)의 회전과 발산을 구하여라.

풀이. \(\nabla\times V = (x - x, y - y, z - z) = \mathbf 0\)이고, \(g = xyz\)이면 \(\nabla g = V\)이다. \(W\)에 대해서는 \(\nabla\times W = (0, 0, 2)\)이고 \(\nabla\cdot W = 0\)이다. \(W\)는 \(z\)축 둘레의 강체 회전이며, 회전의 크기 2는 각속도 1의 두 배이다. 또 \(W = \nabla\times\left(-\frac12(x^2 + y^2)U_3\right)\)처럼 벡터 퍼텐셜을 가진다.

1.3.4물리적 의미

기울기는 가장 가파른 증가 방향이고 등위면에 수직이다. 회전은 축 방향 \(\mathbf n\)의 작은 원판 둘레를 도는 선적분을 넓이로 나눈 극한이 \((\nabla\times V)\cdot\mathbf n\)이 되는 양이며, 그림 1의 원이 이것이다. 발산은 작은 상자 밖으로 나가는 선속을 부피로 나눈 극한으로, 유체가 솟아나는 정도의 밀도이다. 이 해석들은 모두 5단원의 스토크스 정리를 아주 작은 영역에 쓴 것이다.

흔한 오해2-형식의 기저를 \(dx\wedge dz\)로 잡으면 회전의 둘째 성분 부호가 틀린다. 또 구멍이 있는 영역에서도 회전이 0이면 퍼텐셜이 있다고 여기는 것도 틀렸다. \(\frac{-yU_1 + xU_2}{x^2 + y^2}\)은 \(z\)축을 뺀 곳에서 회전이 0이지만 퍼텐셜이 없다.
마무리

처음 질문의 답은 "그렇다"이다. 벡터장을 1-형식 \(\phi_V\)와 순환 순서의 2-형식 \(\eta_V\)로 옮기는 사전을 쓰면, 외미분 \(d\)가 0-형식에서는 기울기, 1-형식에서는 회전, 2-형식에서는 발산이 된다. 외적은 \(\phi_V\wedge\phi_W = \eta_{V\times W}\)로 외곱의 한 모습이다. \(d^2 = 0\)은 두 항등식 \(\nabla\times\nabla g = \mathbf 0\), \(\nabla\cdot\nabla\times V = 0\)이고, 별 모양 영역에서는 그 역도 성립한다.

1.3.5연습문제

기본

  1. \(V = x^2U_1 + yzU_2 + U_3\)의 발산과 회전을 형식으로 계산하여라.
    답

    \(\nabla\cdot V = 2x + z\). \(\nabla\times V = (0 - y, 0 - 0, 0 - 0) = (-y, 0, 0)\).

응용

  1. \(\phi_V\wedge\phi_W = \eta_{V\times W}\)를 \(V = U_1\), \(W = U_2\)에서 확인하여라.
    답

    \(dx\wedge dy = \eta_{U_3}\)이고 \(U_1\times U_2 = U_3\).

심화

  1. \(\nabla\cdot(g V) = \nabla g\cdot V + g\,\nabla\cdot V\)를 형식의 곱 규칙 \(d(g\eta) = dg\wedge\eta + g\,d\eta\)로 증명하여라.
    답

    \(\eta_{gV} = g\eta_V\)이고 \(d(g\eta_V) = dg\wedge\eta_V + g\,d\eta_V = (\nabla g\cdot V + g\nabla\cdot V)\,dx\wedge dy\wedge dz\) (\(\phi_{\nabla g}\wedge\eta_V = (\nabla g\cdot V)\,dx\wedge dy\wedge dz\)).
