접벡터, 벡터장, 방향도함수

본문
이 절에서 배울 것
  • 점에 붙은 벡터(접벡터)와 접공간 \(T_p\mathbb R^3\)을 정의하고, 벡터장을 자연틀 \(U_1, U_2, U_3\)로 나타낸다.
  • 접벡터가 함수에 작용하는 방향도함수 \(\mathbf v_p[f]\)를 정의하고 계산한다.
  • 곡선의 속도가 접벡터이고 \(\alpha'(t)[f] = (f\circ\alpha)'(t)\)임을 안다.
먼저 알아야 할 것
  • 편미분과 그래디언트, 연쇄 법칙 (수학11 1.1절), 벡터의 내적.

1.1.1점에 붙은 벡터

고등학교에서는 화살표를 평행이동해도 같은 벡터로 봅니다. 미분기하에서는 "어느 점에서의 속도인가"가 중요하므로 벡터에 붙는 점을 기억합니다.

접벡터(tangent vector): 점 \(\mathbf p \in \mathbb R^3\)와 벡터 \(\mathbf v \in \mathbb R^3\)의 순서쌍 \(\mathbf v_{\mathbf p} = (\mathbf p, \mathbf v)\). \(\mathbf p\)를 붙은 점, \(\mathbf v\)를 벡터 부분이라 한다.

접공간(tangent space) \(T_{\mathbf p}\mathbb R^3\): \(\mathbf p\)에 붙은 접벡터 전체. \(\mathbf v_{\mathbf p} + \mathbf w_{\mathbf p} = (\mathbf v + \mathbf w)_{\mathbf p}\), \(c\,\mathbf v_{\mathbf p} = (c\mathbf v)_{\mathbf p}\)로 3차원 벡터공간이다.

서로 다른 점의 접벡터 \(\mathbf v_{\mathbf p}\)와 \(\mathbf w_{\mathbf q}\)는 더하지 않습니다. 평면 \(\mathbb R^3\)에서는 평행이동으로 비교할 수 있지만, 구면 같은 곡면에서는 서로 다른 점의 접평면이 다른 평면이라 이 구분이 본질적입니다(4단원).

1.1.2벡터장

벡터장(vector field) \(V\): 각 점 \(\mathbf p\)에 접벡터 \(V(\mathbf p) \in T_{\mathbf p}\mathbb R^3\)을 주는 함수.

자연틀(natural frame) \(U_1, U_2, U_3\): \(U_i(\mathbf p) = (\mathbf e_i)_{\mathbf p}\)인 세 벡터장. 모든 벡터장은 \(V = \sum_if_iU_i\) (\(f_i\)는 실함수, \(V\)의 유클리드 좌표함수)로 유일하게 쓰인다.

예: \(V = yU_1 - xU_2\)는 각 점에서 \(z\)축 둘레를 시계 방향으로 도는 벡터이고, \(W = xU_1 + yU_2 + zU_3\)은 원점에서 바깥으로 향하는 벡터장입니다. \(f_i\)가 \(C^\infty\)이면 \(V\)를 매끄러운 벡터장이라 하며, 앞으로 함수와 벡터장은 모두 매끄럽다고 약속합니다.

1.1.3방향도함수

정의 1.1.1 (방향도함수)

\(f\)가 \(\mathbb R^3\)의 매끄러운 함수이고 \(\mathbf v_{\mathbf p}\)가 접벡터이면 \(\mathbf v_{\mathbf p}[f] = \frac{d}{dt}f(\mathbf p + t\mathbf v)\Big|_{t=0}\).

연쇄 법칙으로 \(\mathbf v_{\mathbf p}[f] = \sum_iv_i\frac{\partial f}{\partial x_i}(\mathbf p) = \nabla f(\mathbf p)\cdot\mathbf v\)입니다(수학11 1.1절). 여기서 \(\mathbf v\)는 단위벡터일 필요가 없습니다. \(\mathbf v\)를 2배 하면 방향도함수도 2배가 됩니다.

예제 1.1.2

\(f = x^2y - z\), \(\mathbf p = (1, 2, 3)\), \(\mathbf v = (1, 0, -1)\)일 때 \(\mathbf v_{\mathbf p}[f]\)를 정의와 공식으로 각각 구하여라.

풀이. 정의: \(f(\mathbf p + t\mathbf v) = (1 + t)^2\cdot2 - (3 - t) = 2t^2 + 5t - 1\)이므로 \(t = 0\)에서 미분하면 5. 공식: \(\nabla f = (2xy, x^2, -1) = (4, 1, -1)\), \(\nabla f\cdot\mathbf v = 4 + 0 + 1 = 5\).

정리 1.1.3 (방향도함수의 성질)

(a) \((a\mathbf v + b\mathbf w)_{\mathbf p}[f] = a\,\mathbf v_{\mathbf p}[f] + b\,\mathbf w_{\mathbf p}[f]\). (b) \(\mathbf v_{\mathbf p}[af + bg] = a\,\mathbf v_{\mathbf p}[f] + b\,\mathbf v_{\mathbf p}[g]\). (c) \(\mathbf v_{\mathbf p}[fg] = \mathbf v_{\mathbf p}[f]\,g(\mathbf p) + f(\mathbf p)\,\mathbf v_{\mathbf p}[g]\) (라이프니츠 규칙).

증명.(a), (b)는 \(\nabla f\cdot\mathbf v\)가 \(\mathbf v\)와 \(f\)에 대해 선형이라는 것이다. (c)는 \(\nabla(fg) = g\nabla f + f\nabla g\)에 \(\mathbf v\)를 내적한다. ∎

벡터장 \(V\)를 함수에 작용시키면 \(V[f](\mathbf p) = V(\mathbf p)[f]\)라는 새 함수가 됩니다. 특히 \(U_i[f] = \frac{\partial f}{\partial x_i}\)이므로 \(V = \sum f_iU_i\)이면 \(V[g] = \sum f_i\frac{\partial g}{\partial x_i}\)입니다. 이렇게 벡터장을 "함수를 미분하는 연산자"로 보는 관점이 6단원의 다양체에서 접벡터의 정의가 됩니다.

1.1.4곡선의 속도

곡선 \(\alpha: I \to \mathbb R^3\), \(\alpha(t) = (\alpha_1(t), \alpha_2(t), \alpha_3(t))\)의 속도는 \(\alpha'(t) = \left(\frac{d\alpha_1}{dt}, \frac{d\alpha_2}{dt}, \frac{d\alpha_3}{dt}\right)_{\alpha(t)}\), 곧 \(\alpha(t)\)에 붙은 접벡터입니다. 연쇄 법칙으로

\[\alpha'(t)[f] = \frac{d}{dt}f(\alpha(t)).\]

방향도함수는 직선 \(\mathbf p + t\mathbf v\)를 쓰지 않고 같은 속도를 가진 어떤 곡선을 써도 같은 값을 줍니다. 예: 나선 \(\alpha(t) = (\cos t, \sin t, t)\)와 \(f = x^2 + y^2 + z\)이면 \(f(\alpha(t)) = 1 + t\)라 \(\alpha'(t)[f] = 1\)이고, 공식으로도 \(\nabla f\cdot\alpha' = (2\cos t, 2\sin t, 1)\cdot(-\sin t, \cos t, 1) = 1\)입니다.

흔한 오해(1) 방향도함수를 항상 단위벡터로 정의한다고 여긴다. 이 교재(오닐)의 정의는 \(\mathbf v\)의 크기를 그대로 반영한다. (2) 서로 다른 점의 접벡터를 더한다. (3) \(V[f]\)를 \(V\cdot f\) 같은 곱으로 착각한다. \(V[f]\)는 \(f\)를 \(V\) 방향으로 미분한 함수이다.
요약
  1. 접벡터 \(\mathbf v_{\mathbf p}\), 접공간 \(T_{\mathbf p}\mathbb R^3\). 벡터장 \(V = \sum f_iU_i\).
  2. \(\mathbf v_{\mathbf p}[f] = \frac{d}{dt}f(\mathbf p + t\mathbf v)|_0 = \nabla f(\mathbf p)\cdot\mathbf v\): 선형이고 라이프니츠 규칙을 만족.
  3. 곡선의 속도는 접벡터이고 \(\alpha'(t)[f] = (f\circ\alpha)'(t)\).

1.1.5연습문제

기본

  1. \(V = xU_1 + yU_2 + zU_3\)일 때 \(V[x^2 + y^2 + z^2]\)를 구하여라.
    답

    \(x\cdot2x + y\cdot2y + z\cdot2z = 2(x^2 + y^2 + z^2)\). 원점에서 바깥으로 갈수록 거리 제곱이 커지는 비율이다.

응용

  1. \(V = yU_1 - xU_2\)에 대해 \(V[f] = 0\)인 함수 \(f\)의 예를 들고 그 의미를 말하여라.
    답

    \(f = x^2 + y^2\) (또는 \(z\), \(g(x^2 + y^2, z)\)). \(V[f] = y\cdot2x - x\cdot2y = 0\). \(V\)의 흐름(\(z\)축 둘레 회전)을 따라 값이 변하지 않는 함수, 곧 회전 대칭인 함수이다.

심화

  1. 두 벡터장 \(V, W\)에 대해 \([V, W][f] = V[W[f]] - W[V[f]]\)로 정의하면 \([V, W]\)도 벡터장(2계 도함수 항이 사라짐)임을 \(V = U_1\), \(W = xU_2\)에서 확인하여라.
    답

    \(W[f] = xf_y\), \(V[W[f]] = f_y + xf_{xy}\). \(V[f] = f_x\), \(W[V[f]] = xf_{xy}\). 차는 \(f_y = U_2[f]\)이므로 \([V, W] = U_2\). 혼합 편도함수의 대칭으로 2계 항이 상쇄된다.
