제1기본형식: 곡면 위의 길이와 넓이

본문

곡면 위에 사는 작은 개미는 곡면 밖으로 나가지 못한다. 그래도 개미는 곡면 위 길의 길이와 땅의 넓이를 잴 수 있다. 이런 길이와 넓이를 좌표 \((u, v)\)만으로 계산하려면 무엇을 알아야 할까? 그리고 종이를 말아 원기둥을 만들 때 길이가 변하지 않는 것은 어떻게 설명될까?

먼저 알아야 할 것좌표조각과 접평면(4.1절), 곡선의 길이, 변수변환 공식(수학11 4.3절)을 쓴다.

4.3.1정의

접평면의 벡터는 \(\mathbf w = a\mathbf x_u + b\mathbf x_v\)로 쓰이고, 그 길이의 제곱은 \(|\mathbf w|^2 = Ea^2 + 2Fab + Gb^2\)이다. 여기서 \(E = \mathbf x_u\cdot\mathbf x_u\), \(F = \mathbf x_u\cdot\mathbf x_v\), \(G = \mathbf x_v\cdot\mathbf x_v\)이다.

정의

접평면 위의 내적을 좌표 \((a, b)\)로 나타낸 2차 형식 \(\mathrm I(\mathbf w) = Ea^2 + 2Fab + Gb^2\)를 제1기본형식이라 하고, 흔히 \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\)로 쓴다.

정칙이면 라그랑주 항등식으로 \(EG - F^2 = |\mathbf x_u\times\mathbf x_v|^2 > 0\)이므로 이 형식은 양정치이다.

4.3.2길이와 넓이

곡면 위의 곡선 \(\alpha(t) = \mathbf x(u(t), v(t))\) (\(a \le t \le b\))의 속도는 \(u'\mathbf x_u + v'\mathbf x_v\)이므로 길이는 \(L = \int_a^b\sqrt{E\,u'^2 + 2F\,u'v' + G\,v'^2}\,dt\)이다. 또 작은 사각형 \(\Delta u\times\Delta v\)는 \(\mathbf x_u\Delta u\)와 \(\mathbf x_v\Delta v\)로 만든 평행사변형이 되어 넓이가 \(|\mathbf x_u\times\mathbf x_v|\Delta u\Delta v\)이므로, 영역 \(R\)의 상의 넓이는 \(A = \iint_R\sqrt{EG - F^2}\,du\,dv\)이다. 이 값은 좌표조각을 바꿔도 같다. 수학11의 변수변환 공식에서 야코비 행렬식이 정확히 상쇄되기 때문이다.

4.3.3예

예제 4.3.1 (구면)

반지름 \(r\)인 구면 \(\mathbf x(u, v) = (r\cos u\cos v, r\cos u\sin v, r\sin u)\)의 \(E, F, G\)를 구하고, 전체 넓이와 위도 \(u_1\) 이상인 극관의 넓이를 구하여라.

풀이. \(\mathbf x_u = r(-\sin u\cos v, -\sin u\sin v, \cos u)\), \(\mathbf x_v = r(-\cos u\sin v, \cos u\cos v, 0)\)이므로 \(E = r^2\), \(F = 0\), \(G = r^2\cos^2u\)이고 \(\sqrt{EG - F^2} = r^2\cos u\)이다. 따라서 전체 넓이는 \(\int_{-\pi}^\pi\int_{-\pi/2}^{\pi/2}r^2\cos u\,du\,dv = 4\pi r^2\)이다. 극관은 \(2\pi r^2(1 - \sin u_1)\)이고, 높이 \(h = r(1 - \sin u_1)\)으로 쓰면 \(2\pi rh\)이다. 즉 그림 1처럼 같은 높이의 원기둥 띠와 넓이가 같다.

예제 4.3.2 (원환면)

원환면 \(((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\)의 넓이를 구하여라.

풀이. \(E = r^2\), \(F = 0\), \(G = (R + r\cos u)^2\)이므로 \(\sqrt{EG - F^2} = r(R + r\cos u)\)이다. 넓이는 \(\int_0^{2\pi}\int_0^{2\pi}r(R + r\cos u)\,du\,dv = 4\pi^2Rr\)이며, 이것은 단면 원의 둘레에 중심이 도는 거리를 곱한 파푸스 정리와 같다. \(R = 2\), \(r = 0.7\)이면 약 55.27이다. 같은 절의 탐구 카드에서 \(E, F, G\)로 적분한 길이와 3차원에서 직접 잰 길이를 비교한다.

4.3.4내재적 기하

\(E, F, G\)만 알면 곡면 위 곡선의 길이, 두 곡선 사이의 각, 넓이, 곡면 안의 "직선"인 측지선을 모두 계산할 수 있다. 다시 말해 곡면 위에 사는 2차원 생물이 잴 수 있는 양은 모두 제1기본형식에 들어 있다. 예를 들어 원기둥 \((\cos v, \sin v, u)\)는 \(E = 1\), \(F = 0\), \(G = 1\)로 평면과 같으므로, 종이를 말아 원기둥을 만들 때 길이와 넓이가 변하지 않는다. 반면 구면은 어떤 좌표로도 \(E = G = 1\), \(F = 0\)이 될 수 없고, 그래서 왜곡 없는 평면 지도가 불가능하다(가우스의 빼어난 정리).

흔한 오해길이 공식에서 \(2F\,u'v'\)의 2를 빼먹기 쉽다. 또 넓이 공식에 \(\sqrt{EG}\)를 쓰는 실수가 있으며, \(F \ne 0\)이면 틀린다. 제1기본형식이 평면인지 원기둥인지 같은 굽음까지 알려 준다고 여기는 것도 틀렸으며, 그것은 제2기본형식이 알려 준다.
마무리

처음 질문에 답하면, 곡면 위의 길이와 넓이를 계산하려면 제1기본형식의 세 함수 \(E, F, G\)만 알면 된다. 길이는 \(\int\sqrt{Eu'^2 + 2Fu'v' + Gv'^2}\,dt\), 넓이는 \(\iint\sqrt{EG - F^2}\,du\,dv\)이며, 구면에서 아르키메데스의 극관 넓이 \(2\pi rh\)가 바로 나온다. 원기둥은 \(E = G = 1\), \(F = 0\)으로 평면과 같아서, 종이를 말아도 길이가 변하지 않는다.

4.3.5연습문제

기본

  1. 그래프 \(\mathbf x = (u, v, f(u, v))\)의 \(E, F, G\)와 넓이 요소를 구하여라.
    답

    \(E = 1 + f_u^2\), \(F = f_uf_v\), \(G = 1 + f_v^2\), \(\sqrt{EG - F^2} = \sqrt{1 + f_u^2 + f_v^2}\).

응용

  1. 나선면 \((u\cos v, u\sin v, v)\)에서 \(0 \le u \le 1\), \(0 \le v \le 2\pi\)인 부분의 넓이를 구하여라.
    답

    \(E = 1\), \(F = 0\), \(G = 1 + u^2\). \(2\pi\int_0^1\sqrt{1 + u^2}\,du = \pi\left(\sqrt2 + \ln(1 + \sqrt2)\right) \approx 7.212\).

심화

  1. 구면 위의 항정선(경선과 일정한 각 \(\beta\)를 이루는 곡선) \(v = \tan\beta\cdot\ln\tan(\frac u2 + \frac\pi4)\)의 적도(\(u = 0\))에서 위도 \(u_1\)까지의 길이를 구하여라(단위구면).
    답

    \(u\)를 매개변수로 \(v' = \frac{\tan\beta}{\cos u}\)이므로 \(\sqrt{E + G v'^2} = \sqrt{1 + \tan^2\beta} = \sec\beta\). 길이 \(u_1\sec\beta\). 극까지(\(u_1 = \frac\pi2\)) 무한히 감기면서도 길이는 유한한 \(\frac\pi2\sec\beta\)이다.
