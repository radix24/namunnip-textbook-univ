제1기본형식: 곡면 위의 길이와 넓이

본문
이 절에서 배울 것
  • 좌표조각의 \(E = \mathbf x_u\cdot\mathbf x_u\), \(F = \mathbf x_u\cdot\mathbf x_v\), \(G = \mathbf x_v\cdot\mathbf x_v\)를 구한다.
  • 곡면 위 곡선의 길이를 \(\int\sqrt{Eu'^2 + 2Fu'v' + Gv'^2}\,dt\)로, 넓이를 \(\iint\sqrt{EG - F^2}\,du\,dv\)로 계산한다.
  • 제1기본형식이 "곡면 안에서 잴 수 있는 양"(내재적 기하)을 모두 담고 있음을 이해한다.
먼저 알아야 할 것
  • 좌표조각과 접평면 (4.1절), 곡선의 길이, 변수변환 공식 (수학11 4.3절).

4.3.1정의

접평면의 벡터는 \(\mathbf w = a\mathbf x_u + b\mathbf x_v\)로 쓰이고, 그 길이의 제곱은

\[|\mathbf w|^2 = a^2\,\mathbf x_u\cdot\mathbf x_u + 2ab\,\mathbf x_u\cdot\mathbf x_v + b^2\,\mathbf x_v\cdot\mathbf x_v = Ea^2 + 2Fab + Gb^2.\]

제1기본형식(first fundamental form): 접평면 위의 내적을 좌표 \((a, b)\)로 나타낸 2차 형식 \(\mathrm I(\mathbf w) = Ea^2 + 2Fab + Gb^2\), 행렬로 \(\begin{pmatrix}E & F\\F & G\end{pmatrix}\). 흔히 \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\)로 쓴다.

정칙이면 \(EG - F^2 = |\mathbf x_u|^2|\mathbf x_v|^2 - (\mathbf x_u\cdot\mathbf x_v)^2 = |\mathbf x_u\times\mathbf x_v|^2 > 0\)이라 이 형식은 양정치입니다(라그랑주 항등식).

4.3.2길이와 넓이

곡면 위의 곡선 \(\alpha(t) = \mathbf x(u(t), v(t))\) (\(a \le t \le b\))의 속도는 \(u'\mathbf x_u + v'\mathbf x_v\)이므로

\[L = \int_a^b\sqrt{E\,u'^2 + 2F\,u'v' + G\,v'^2}\;dt.\]

영역 \(R \subseteq D\)의 상의 넓이는 작은 사각형 \(\Delta u\times\Delta v\)가 \(\mathbf x_u\Delta u\)와 \(\mathbf x_v\Delta v\)로 만든 평행사변형(넓이 \(|\mathbf x_u\times\mathbf x_v|\Delta u\Delta v\))이 되므로

\[A = \iint_R|\mathbf x_u\times\mathbf x_v|\,du\,dv = \iint_R\sqrt{EG - F^2}\,du\,dv.\]

이 값은 좌표조각을 바꿔도 같습니다(수학11의 변수변환 공식에서 야코비 행렬식이 정확히 상쇄됨).

4.3.3예

예제 4.3.1 (구면)

반지름 \(r\)인 구면 \(\mathbf x(u, v) = (r\cos u\cos v, r\cos u\sin v, r\sin u)\)의 \(E, F, G\)를 구하고 전체 넓이와 위도 \(u_1\) 이상인 극관의 넓이를 구하여라.

풀이. \(\mathbf x_u = r(-\sin u\cos v, -\sin u\sin v, \cos u)\), \(\mathbf x_v = r(-\cos u\sin v, \cos u\cos v, 0)\)이므로 \(E = r^2\), \(F = 0\), \(G = r^2\cos^2u\). \(\sqrt{EG - F^2} = r^2\cos u\). 전체 넓이 \(\int_{-\pi}^\pi\int_{-\pi/2}^{\pi/2}r^2\cos u\,du\,dv = 4\pi r^2\). 극관은 \(2\pi r^2(1 - \sin u_1)\)이고, 이는 극관의 높이 \(h = r(1 - \sin u_1)\)에 대해 \(2\pi rh\)입니다(아르키메데스: 같은 높이의 원기둥 띠와 넓이가 같다).

예제 4.3.2 (원환면과 경선)

원환면 \(((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\)의 넓이를 구하여라.

풀이. \(E = r^2\), \(F = 0\), \(G = (R + r\cos u)^2\), \(\sqrt{EG - F^2} = r(R + r\cos u)\). 넓이 \(\int_0^{2\pi}\int_0^{2\pi}r(R + r\cos u)\,du\,dv = 4\pi^2Rr\) (파푸스 정리: 단면 원의 둘레 × 중심이 도는 거리). \(R = 2\), \(r = 0.7\)이면 약 55.27입니다.

같은 절의 탐구 카드에서 \((u, v)\) 평면의 직선을 곡면에 옮긴 곡선의 길이를 \(E, F, G\)로 적분한 값과 3차원에서 직접 잰 값을 비교합니다.

4.3.4내재적 기하

\(E, F, G\)만 알면 곡면 위 곡선의 길이, 두 곡선 사이의 각(\(\cos\theta = \frac{\mathrm I(\mathbf w_1, \mathbf w_2)}{|\mathbf w_1||\mathbf w_2|}\)), 넓이, 측지선(곡면 안의 "직선")을 모두 계산할 수 있습니다. 곡면 위에 사는 2차원 생물이 잴 수 있는 양이 모두 제1기본형식에 들어 있다는 뜻입니다. 예를 들어 원기둥 \((\cos v, \sin v, u)\)는 \(E = 1\), \(F = 0\), \(G = 1\)로 평면과 같아서, 종이를 말아 원기둥을 만들 때 길이와 넓이가 변하지 않는 것과 맞습니다. 반면 구면은 어떤 좌표로도 \(E = G = 1\), \(F = 0\)이 될 수 없고(가우스의 빼어난 정리, 미분기하(2)), 그래서 왜곡 없는 평면 지도가 불가능합니다.

흔한 오해(1) \(F\)의 2배를 빼먹는다(\(2F\,u'v'\)). (2) 넓이 공식에 \(\sqrt{EG}\)를 쓴다(\(F \ne 0\)이면 틀림). (3) 제1기본형식이 곡면의 굽음(평면인지 원기둥인지)까지 알려 준다고 여긴다. 굽음은 제2기본형식이 알려 준다.
요약
  1. \(E = \mathbf x_u\cdot\mathbf x_u\), \(F = \mathbf x_u\cdot\mathbf x_v\), \(G = \mathbf x_v\cdot\mathbf x_v\), \(EG - F^2 = |\mathbf x_u\times\mathbf x_v|^2\).
  2. 길이 \(\int\sqrt{Eu'^2 + 2Fu'v' + Gv'^2}\), 넓이 \(\iint\sqrt{EG - F^2}\).
  3. 구면 \(4\pi r^2\), 원환면 \(4\pi^2Rr\). 원기둥은 평면과 같은 제1기본형식.

4.3.5연습문제

기본

  1. 그래프 \(\mathbf x = (u, v, f(u, v))\)의 \(E, F, G\)와 넓이 요소를 구하여라.
    답

    \(E = 1 + f_u^2\), \(F = f_uf_v\), \(G = 1 + f_v^2\), \(\sqrt{EG - F^2} = \sqrt{1 + f_u^2 + f_v^2}\).

응용

  1. 나선면 \((u\cos v, u\sin v, v)\)에서 \(0 \le u \le 1\), \(0 \le v \le 2\pi\)인 부분의 넓이를 구하여라.
    답

    \(E = 1\), \(F = 0\), \(G = 1 + u^2\). \(2\pi\int_0^1\sqrt{1 + u^2}\,du = \pi\left(\sqrt2 + \ln(1 + \sqrt2)\right) \approx 7.212\).

심화

  1. 구면 위의 항정선(경선과 일정한 각 \(\beta\)를 이루는 곡선) \(v = \tan\beta\cdot\ln\tan(\frac u2 + \frac\pi4)\)의 적도(\(u = 0\))에서 위도 \(u_1\)까지의 길이를 구하여라(단위구면).
    답

    \(u\)를 매개변수로 \(v' = \frac{\tan\beta}{\cos u}\)이므로 \(\sqrt{E + G v'^2} = \sqrt{1 + \tan^2\beta} = \sec\beta\). 길이 \(u_1\sec\beta\). 극까지(\(u_1 = \frac\pi2\)) 무한히 감기면서도 길이는 유한한 \(\frac\pi2\sec\beta\)이다.
