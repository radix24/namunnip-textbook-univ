접벡터와 미분형식 연습 문제

문제 6 · 계산·증명·개념·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(f = xe^{yz}\), \(\mathbf p = (2, 1, 0)\), \(\mathbf v = (1, -1, 3)\)일 때 \(\mathbf v_{\mathbf p}[f]\)를 구하여라. [01-01]

    힌트 1

    \(\nabla f = (e^{yz}, xze^{yz}, xye^{yz})\).

    힌트 2

    \(\mathbf p\)에서 \(e^{yz} = 1\).

    풀이

    \(\nabla f(\mathbf p) = (1, 0, 2)\), \(\mathbf v_{\mathbf p}[f] = 1 + 0 + 6 = 7\) (1.1절).

  2. 계산곡선 \(\alpha(t) = (t, t^2, t^3)\)과 \(f = x^2 + y^2 + z^2\)에 대해 \(\alpha'(1)[f]\)를 두 방법으로 구하여라. [01-01]

    힌트 1

    \(f(\alpha(t)) = t^2 + t^4 + t^6\).

    힌트 2

    \(\alpha'(1) = (1, 2, 3)_{(1,1,1)}\).

    풀이

    \((2t + 4t^3 + 6t^5)|_{t=1} = 12\). 공식: \(\nabla f(1, 1, 1) = (2, 2, 2)\), \((2, 2, 2)\cdot(1, 2, 3) = 12\).

  3. 계산\(\phi = dx + z\,dy\), \(\psi = y\,dz - dx\)일 때 \(\phi\wedge\psi\)와 \(d\phi\)를 구하여라. [01-02]

    힌트 1

    \(dx\wedge dx = 0\).

    힌트 2

    \(dy\wedge dx = -dx\wedge dy\).

    풀이

    \(\phi\wedge\psi = y\,dx\wedge dz - dx\wedge dx + yz\,dy\wedge dz - z\,dy\wedge dx = -y\,dz\wedge dx + yz\,dy\wedge dz + z\,dx\wedge dy\). \(d\phi = dz\wedge dy = -dy\wedge dz\) (1.2절).

  4. 증명1-형식 \(\phi\)에 대해 \(\phi\wedge\phi = 0\)임을 보여라. 2-형식 \(\eta\)에 대해 \(\eta\wedge\eta\)는 \(\mathbb R^4\)에서 0이 아닐 수 있음을 예로 보여라. [01-02]

    힌트 1

    \(\phi\wedge\psi = -\psi\wedge\phi\).

    힌트 2

    \(\eta = dx_1\wedge dx_2 + dx_3\wedge dx_4\).

    풀이

    \(\phi\wedge\phi = -\phi\wedge\phi\)이므로 0. \(\eta = dx_1\wedge dx_2 + dx_3\wedge dx_4\)이면 \(\eta\wedge\eta = 2\,dx_1\wedge dx_2\wedge dx_3\wedge dx_4 \ne 0\) (짝수 차 형식은 서로 교환한다).

  5. 개념\(V = (2xy + z)U_1 + x^2U_2 + xU_3\)이 보존장인지 판정하고, 그렇다면 퍼텐셜을 구하여라. [01-03]

    힌트 1

    \(d\phi_V = 0\)인지 본다.

    힌트 2

    \(g = x^2y + xz\) 후보.

    풀이

    \(\nabla\times V = (0 - 0, 1 - 1, 2x - 2x) = \mathbf 0\)이고 \(\mathbb R^3\)은 별 모양이라 보존장이다. \(g = x^2y + xz\)이면 \(\nabla g = (2xy + z, x^2, x) = V\) (1.3절).

  6. 판단"\(V = \frac{-y}{x^2 + y^2}U_1 + \frac{x}{x^2 + y^2}U_2\)는 \(\nabla\times V = \mathbf 0\)이므로 \(z\)축을 뺀 공간에서 퍼텐셜을 가진다"는 옳은가? [01-03]

    힌트 1

    단위원을 도는 선적분.

    힌트 2

    푸앵카레 보조정리의 가정(별 모양).

    풀이

    옳지 않다. 단위원을 한 바퀴 도는 \(\int\phi_V = 2\pi \ne 0\)이므로 퍼텐셜이 없다(퍼텐셜이 있으면 닫힌 곡선의 적분이 0). \(z\)축을 뺀 공간은 별 모양이 아니라 푸앵카레 보조정리를 쓸 수 없다.
