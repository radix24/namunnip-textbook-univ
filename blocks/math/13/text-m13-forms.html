1-형식, 외곱, 외미분

본문
이 절에서 배울 것
  • 1-형식을 "각 점에서 접벡터를 받아 수를 내는 선형함수"로 정의하고, \(df(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[f]\)를 이해한다.
  • 외곱(쐐기곱)의 규칙으로 1-형식과 2-형식을 곱한다.
  • \(\mathbb R^3\)에서 외미분을 계산하고, 사상에 의한 당김을 계산한다.
먼저 알아야 할 것
  • 접벡터와 방향도함수 (1.1절), 미분형식의 기초 (수학11 5.1절, 함께 보면 좋음).

1.2.11-형식

1-형식(1-form) \(\phi\): 각 점 \(\mathbf p\)에서 \(T_{\mathbf p}\mathbb R^3\)의 선형함수 \(\phi_{\mathbf p}: T_{\mathbf p}\mathbb R^3 \to \mathbb R\)를 주는 것. 벡터장 \(V\)에 작용하면 함수 \(\phi(V)\)가 된다.

미분(differential) \(df\): \(df(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[f]\)로 정의되는 1-형식.

좌표함수의 미분 \(dx_1, dx_2, dx_3\)는 \(dx_i(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[x_i] = v_i\), 곧 벡터의 \(i\)번째 성분을 읽어 내는 형식입니다. \(dx_i(U_j) = \delta_{ij}\)이므로 \(\{dx_i\}\)는 자연틀 \(\{U_j\}\)의 쌍대 기저이고, 모든 1-형식은 \(\phi = \sum f_i\,dx_i\) (\(f_i = \phi(U_i)\))로 유일하게 쓰입니다. 특히

\[df = \sum_i\frac{\partial f}{\partial x_i}dx_i.\]

미적분학의 "\(df = f_x\,dx + f_y\,dy + f_z\,dz\)"가 여기서는 기호가 아니라 등식입니다. 양변이 같은 접벡터에 같은 값을 줍니다.

1.2.2외곱

2-형식은 각 점에서 두 접벡터를 받아 수를 내는 교대 쌍선형함수입니다. 1-형식 \(\phi, \psi\)의 외곱은 \((\phi\wedge\psi)(\mathbf v, \mathbf w) = \phi(\mathbf v)\psi(\mathbf w) - \phi(\mathbf w)\psi(\mathbf v)\)이고, 다음 규칙으로 계산합니다.

\[dx_i\wedge dx_i = 0, \qquad dx_j\wedge dx_i = -dx_i\wedge dx_j.\]

\(\mathbb R^3\)에서 2-형식은 \(f\,dx\wedge dy + g\,dy\wedge dz + h\,dz\wedge dx\), 3-형식은 \(f\,dx\wedge dy\wedge dz\), 4-형식 이상은 0입니다.

예제 1.2.1

\(\phi = x\,dx - y^2\,dz\), \(\psi = z\,dx + dy\)일 때 \(\phi\wedge\psi\)를 구하여라.

풀이. \(\phi\wedge\psi = xz\,dx\wedge dx + x\,dx\wedge dy - y^2z\,dz\wedge dx - y^2\,dz\wedge dy = x\,dx\wedge dy - y^2z\,dz\wedge dx + y^2\,dy\wedge dz\). (\(dx\wedge dx = 0\), \(dz\wedge dy = -dy\wedge dz\).)

두 1-형식의 외곱은 \(\phi\wedge\psi = -\psi\wedge\phi\)이고 특히 \(\phi\wedge\phi = 0\)입니다. \(\phi = \sum f_idx_i\), \(\psi = \sum g_idx_i\)이면 \(\phi\wedge\psi\)의 계수는 벡터 \((f_i)\)와 \((g_i)\)의 외적 성분과 같습니다(1.3절).

1.2.3외미분

\(d\)는 \(k\)-형식을 \((k + 1)\)-형식으로 보냅니다: 함수에는 \(df\), 1-형식 \(\phi = \sum f_idx_i\)에는 \(d\phi = \sum df_i\wedge dx_i\), 2-형식 \(\eta = \sum g_{ij}dx_i\wedge dx_j\)에는 \(d\eta = \sum dg_{ij}\wedge dx_i\wedge dx_j\).

예제 1.2.2

\(\phi = xy\,dz\), \(\eta = z\,dx\wedge dy + x\,dy\wedge dz\)의 외미분을 구하여라.

풀이. \(d\phi = d(xy)\wedge dz = y\,dx\wedge dz + x\,dy\wedge dz\). \(d\eta = dz\wedge dx\wedge dy + dx\wedge dy\wedge dz = 2\,dx\wedge dy\wedge dz\) (\(dz\wedge dx\wedge dy\)은 두 번 교환하면 \(dx\wedge dy\wedge dz\)).

주요 성질은 \(d(f\phi) = df\wedge\phi + f\,d\phi\), \(d(\phi\wedge\psi) = d\phi\wedge\psi - \phi\wedge d\psi\) (1-형식끼리), 그리고 \(d(d\omega) = 0\)입니다. 증명은 수학11 5.1절과 같습니다.

1.2.4사상과 당김

사상 \(F: \mathbb R^n \to \mathbb R^m\)은 접벡터를 옮기고(\(F_*\mathbf v_{\mathbf p} = (F'(\mathbf p)\mathbf v)_{F(\mathbf p)}\), 접사상), 형식은 거꾸로 당깁니다: \((F^*\phi)(\mathbf v_{\mathbf p}) = \phi(F_*\mathbf v_{\mathbf p})\). 실제 계산은 좌표 \(y_j\)에 \(F_j(\mathbf x)\)를 대입하고 \(dy_j\)에 \(dF_j\)를 대입하면 됩니다. 예: \(F(u, v) = (u\cos v, u\sin v, v)\) (나선면)이면 \(F^*(dx\wedge dy) = d(u\cos v)\wedge d(u\sin v) = u\,du\wedge dv\)입니다. 당김은 \(d\)와 교환합니다(\(F^*d\omega = dF^*\omega\)). 5단원에서 곡면 위의 적분을 이 당김으로 정의합니다.

흔한 오해(1) \(dx\)를 "아주 작은 수"로만 여긴다. 여기서는 벡터의 \(x\)성분을 읽는 선형함수이다. (2) 외곱의 순서를 바꾸면서 부호를 빠뜨린다. (3) \(d(f\,dx) = f'\,dx\)처럼 \(df\)의 다른 성분을 빠뜨린다.
요약
  1. 1-형식 \(\phi = \sum f_idx_i\), \(dx_i(U_j) = \delta_{ij}\), \(df(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[f]\).
  2. 외곱: \(dx_i\wedge dx_j = -dx_j\wedge dx_i\), \(dx_i\wedge dx_i = 0\).
  3. 외미분: \(d(\sum f_Idx_I) = \sum df_I\wedge dx_I\), \(d^2 = 0\). 당김은 좌표 대입이며 \(d\)와 교환한다.

1.2.5연습문제

기본

  1. \(\phi = y\,dx - x\,dy\)를 벡터장 \(V = xU_1 + yU_2\)와 \(W = -yU_1 + xU_2\)에 작용시켜라.
    답

    \(\phi(V) = yx - xy = 0\), \(\phi(W) = -y^2 - x^2\).

응용

  1. \(d(f\,dg) = df\wedge dg\)임을 보이고 \(d(x\,dy - y\,dx)\)를 구하여라.
    답

    \(d(f\,dg) = df\wedge dg + f\,d(dg) = df\wedge dg\). \(d(x\,dy - y\,dx) = dx\wedge dy - dy\wedge dx = 2\,dx\wedge dy\).

심화

  1. 구면좌표 \(F(\rho, \varphi, \theta) = (\rho\sin\varphi\cos\theta, \rho\sin\varphi\sin\theta, \rho\cos\varphi)\)에 대해 \(F^*(dx\wedge dy\wedge dz) = \rho^2\sin\varphi\,d\rho\wedge d\varphi\wedge d\theta\)임을 야코비 행렬식으로 설명하여라.
    답

    \(F^*(dx\wedge dy\wedge dz) = dF_1\wedge dF_2\wedge dF_3 = \det F'\,d\rho\wedge d\varphi\wedge d\theta\)이고 (3-형식의 당김은 행렬식), 구면좌표의 야코비 행렬식은 \(\rho^2\sin\varphi\)이다(수학11 4.3절).
