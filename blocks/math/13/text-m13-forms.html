1-형식, 외곱, 외미분

본문

미적분학에서 \(df = f_x\,dx + f_y\,dy + f_z\,dz\)라고 쓸 때 \(dx\)는 무엇일까? "아주 작은 \(x\)의 변화"라는 설명은 직관일 뿐이다. \(dx\)를 정확한 대상으로 정의해 이 식을 기호가 아닌 등식으로 만들 수 있을까?

먼저 알아야 할 것접벡터와 방향도함수(1.1절)를 쓴다. 미분형식의 기초(수학11 5.1절)를 함께 보면 좋다.

1.2.11-형식

정의

각 점 \(\mathbf p\)에서 \(T_{\mathbf p}\mathbb R^3\)의 선형함수 \(\phi_{\mathbf p}: T_{\mathbf p}\mathbb R^3 \to \mathbb R\)를 주는 것을 1-형식이라 한다. 벡터장 \(V\)에 작용하면 함수 \(\phi(V)\)가 된다. 함수 \(f\)에 대해 \(df(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[f]\)로 정의되는 1-형식을 \(f\)의 미분이라 한다.

좌표함수의 미분 \(dx_1, dx_2, dx_3\)는 \(dx_i(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[x_i] = v_i\), 곧 벡터의 \(i\)번째 성분을 읽어 내는 형식이다. \(dx_i(U_j) = \delta_{ij}\)이므로 \(\{dx_i\}\)는 자연틀 \(\{U_j\}\)의 쌍대 기저이고, 모든 1-형식은 \(f_i = \phi(U_i)\)로 \(\phi = \sum f_i\,dx_i\)처럼 유일하게 쓰인다. 특히 \(df = \sum_i\frac{\partial f}{\partial x_i}dx_i\)이며, 이것은 양변이 같은 접벡터에 같은 값을 준다는 뜻의 등식이다.

1.2.2외곱

2-형식은 각 점에서 두 접벡터를 받아 수를 내는 교대 쌍선형함수이다. 1-형식 \(\phi, \psi\)의 외곱은 \((\phi\wedge\psi)(\mathbf v, \mathbf w) = \phi(\mathbf v)\psi(\mathbf w) - \phi(\mathbf w)\psi(\mathbf v)\)이고, 계산은 \(dx_i\wedge dx_i = 0\), \(dx_j\wedge dx_i = -dx_i\wedge dx_j\)라는 규칙으로 한다. \(\mathbb R^3\)에서 2-형식은 \(f\,dx\wedge dy + g\,dy\wedge dz + h\,dz\wedge dx\), 3-형식은 \(f\,dx\wedge dy\wedge dz\)이고, 4-형식 이상은 0이다.

예제 1.2.1

\(\phi = x\,dx - y^2\,dz\), \(\psi = z\,dx + dy\)일 때 \(\phi\wedge\psi\)를 구하여라.

풀이. 분배하면 \(xz\,dx\wedge dx + x\,dx\wedge dy - y^2z\,dz\wedge dx - y^2\,dz\wedge dy\)이다. \(dx\wedge dx = 0\)이고 \(dz\wedge dy = -dy\wedge dz\)이므로 \(\phi\wedge\psi = x\,dx\wedge dy - y^2z\,dz\wedge dx + y^2\,dy\wedge dz\)이다.

두 1-형식의 외곱은 \(\phi\wedge\psi = -\psi\wedge\phi\)이고 특히 \(\phi\wedge\phi = 0\)이다. 또 \(\phi = \sum f_idx_i\), \(\psi = \sum g_idx_i\)이면 \(\phi\wedge\psi\)의 계수는 벡터 \((f_i)\)와 \((g_i)\)의 외적 성분과 같으며, 이것은 1.3절에서 쓴다.

1.2.3외미분

외미분 \(d\)는 \(k\)-형식을 \((k + 1)\)-형식으로 보낸다. 함수에는 \(df\)이고, 1-형식 \(\phi = \sum f_idx_i\)에는 \(d\phi = \sum df_i\wedge dx_i\), 2-형식 \(\eta = \sum g_{ij}dx_i\wedge dx_j\)에는 \(d\eta = \sum dg_{ij}\wedge dx_i\wedge dx_j\)이다.

예제 1.2.2

\(\phi = xy\,dz\), \(\eta = z\,dx\wedge dy + x\,dy\wedge dz\)의 외미분을 구하여라.

풀이. \(d\phi = d(xy)\wedge dz = y\,dx\wedge dz + x\,dy\wedge dz\)이다. 또 \(d\eta = dz\wedge dx\wedge dy + dx\wedge dy\wedge dz\)이고, \(dz\wedge dx\wedge dy\)는 두 번 교환하면 \(dx\wedge dy\wedge dz\)이므로 \(d\eta = 2\,dx\wedge dy\wedge dz\)이다.

주요 성질은 \(d(f\phi) = df\wedge\phi + f\,d\phi\), 1-형식끼리의 \(d(\phi\wedge\psi) = d\phi\wedge\psi - \phi\wedge d\psi\), 그리고 \(d(d\omega) = 0\)이다. 증명은 수학11 5.1절과 같다.

1.2.4사상과 당김

사상 \(F: \mathbb R^n \to \mathbb R^m\)은 접벡터를 \(F_*\mathbf v_{\mathbf p} = (F'(\mathbf p)\mathbf v)_{F(\mathbf p)}\)로 옮기고, 형식은 거꾸로 \((F^*\phi)(\mathbf v_{\mathbf p}) = \phi(F_*\mathbf v_{\mathbf p})\)로 당긴다. 실제 계산은 좌표 \(y_j\)에 \(F_j(\mathbf x)\)를, \(dy_j\)에 \(dF_j\)를 대입하면 된다. 예를 들어 나선면 \(F(u, v) = (u\cos v, u\sin v, v)\)이면 \(F^*(dx\wedge dy) = d(u\cos v)\wedge d(u\sin v) = u\,du\wedge dv\)이다. 당김은 \(d\)와 교환하며(\(F^*d\omega = dF^*\omega\)), 5단원에서 곡면 위의 적분을 이 당김으로 정의한다.

흔한 오해\(dx\)를 "아주 작은 수"로만 여기기 쉽지만, 여기서는 벡터의 \(x\)성분을 읽는 선형함수이다. 또 외곱의 순서를 바꾸면서 부호를 빠뜨리는 실수가 있다. \(d(f\,dx)\)를 \(f'\,dx\)로 쓰며 \(df\)의 다른 성분을 빠뜨리는 것도 주의한다.
마무리

처음 질문의 답은 "만들 수 있다"이다. \(dx\)는 각 점에서 접벡터의 \(x\)성분을 읽는 선형함수, 곧 1-형식이고, \(df\)는 \(df(\mathbf v_{\mathbf p}) = \mathbf v_{\mathbf p}[f]\)로 정의된다. 그러면 \(df = \sum\frac{\partial f}{\partial x_i}dx_i\)는 양변이 모든 접벡터에 같은 값을 주는 등식이다. 외곱은 교대적인 곱이고 외미분은 차수를 하나 올리며, 사상은 형식을 당겨 대입으로 계산한다.

1.2.5연습문제

기본

  1. \(\phi = y\,dx - x\,dy\)를 벡터장 \(V = xU_1 + yU_2\)와 \(W = -yU_1 + xU_2\)에 작용시켜라.
    답

    \(\phi(V) = yx - xy = 0\), \(\phi(W) = -y^2 - x^2\).

응용

  1. \(d(f\,dg) = df\wedge dg\)임을 보이고 \(d(x\,dy - y\,dx)\)를 구하여라.
    답

    \(d(f\,dg) = df\wedge dg + f\,d(dg) = df\wedge dg\). \(d(x\,dy - y\,dx) = dx\wedge dy - dy\wedge dx = 2\,dx\wedge dy\).

심화

  1. 구면좌표 \(F(\rho, \varphi, \theta) = (\rho\sin\varphi\cos\theta, \rho\sin\varphi\sin\theta, \rho\cos\varphi)\)에 대해 \(F^*(dx\wedge dy\wedge dz) = \rho^2\sin\varphi\,d\rho\wedge d\varphi\wedge d\theta\)임을 야코비 행렬식으로 설명하여라.
    답

    \(F^*(dx\wedge dy\wedge dz) = dF_1\wedge dF_2\wedge dF_3 = \det F'\,d\rho\wedge d\varphi\wedge d\theta\)이고 (3-형식의 당김은 행렬식), 구면좌표의 야코비 행렬식은 \(\rho^2\sin\varphi\)이다(수학11 4.3절).
