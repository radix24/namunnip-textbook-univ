극소곡면

본문

철사 고리를 비눗물에 담갔다 빼면 막이 생긴다. 표면장력은 막의 넓이를 줄이려 하므로 막은 넓이가 가장 작은 곡면이 된다. 이런 곡면은 곡률로 어떻게 알아볼 수 있을까?

먼저 알아야 할 것평균곡률과 Gauss 곡률(4.5절), 제1·제2기본형식(4.3절, 4.4절)을 쓴다. do Carmo 3-5절을 따른다.

4.7.1넓이의 변분과 평균곡률

곡면 \(\mathbf x(u, v)\)를 법선 방향으로 조금 밀어 \(\mathbf x^t = \mathbf x + t\,h(u, v)N\)으로 바꾸면 넓이가 어떻게 변하는지 보자. 넓이 원소는 \(\sqrt{EG - F^2}\)이고, \(\mathbf x^t_u = \mathbf x_u + thN_u + th_uN\)을 넣어 \(t\)의 일차항까지 전개하면

\[\frac{d}{dt}\Big|_{t=0}A(t) = -\iint 2hH\sqrt{EG - F^2}\,du\,dv\]

를 얻는다. 여기서 \(H\)는 평균곡률이다. 비누막처럼 경계를 고정한 모든 변형에서 넓이가 최소이면, 경계에서 0인 모든 \(h\)에 대해 이 값이 0이어야 하므로 \(H \equiv 0\)이다.

정의 4.7.1 (극소곡면)

평균곡률이 어디서나 0인 정칙 곡면을 극소곡면이라 한다.

\(H = \frac{k_1 + k_2}{2} = 0\)은 두 주곡률이 크기가 같고 부호가 반대라는 뜻이다. 따라서 극소곡면의 모든 점은 안장점이거나 평평한 점이고, Gauss 곡률은 \(K = -k_1^2 \le 0\)이다. 이름과 달리 극소곡면이 언제나 넓이를 최소로 하지는 않는다. 극소곡면은 넓이의 임계점이다.

4.7.2현수면과 나선면

예제 4.7.2

현수면 \(\mathbf x(u, v) = (\cosh v\cos u, \cosh v\sin u, v)\)의 평균곡률이 0임을 보여라.

풀이. \(\mathbf x_u = (-\cosh v\sin u, \cosh v\cos u, 0)\), \(\mathbf x_v = (\sinh v\cos u, \sinh v\sin u, 1)\)이므로 \(E = G = \cosh^2v\), \(F = 0\)이다. 단위법선은 \(N = \frac{1}{\cosh v}(\cos u, \sin u, -\sinh v)\)이다. 2계 도함수 \(\mathbf x_{uu} = (-\cosh v\cos u, -\cosh v\sin u, 0)\), \(\mathbf x_{vv} = (\cosh v\cos u, \cosh v\sin u, 0)\), \(\mathbf x_{uv} \parallel \mathbf x_u\)에서 \(e = -1\), \(g = 1\), \(f = 0\)이다. 그러면 \(H = \frac{eG - 2fF + gE}{2(EG - F^2)} = \frac{-\cosh^2v + \cosh^2v}{2\cosh^4v} = 0\)이다.

나선면 \(\mathbf y(u, v) = (v\cos u, v\sin u, u)\)도 같은 계산으로 \(H = 0\)이다. \(\mathbf y_{uu}\)와 \(\mathbf y_{vv}\)가 모두 법선과 수직이라 \(e = g = 0\)이기 때문이다. 그런데 현수면과 나선면은 국소적으로 등장이다. 현수면의 매개변수를 \(v = \sinh^{-1}\tilde v\)로 바꾸면 두 곡면의 제1기본형식이 같아진다. 그래서 나선면을 비틀지 않고 구부려 현수면으로 바꿀 수 있고, 그 과정의 곡면이 모두 극소곡면이다.

4.7.3더 알아볼 것

회전면 가운데 극소곡면은 평면과 현수면뿐이고(Euler), 선직면 가운데 극소곡면은 평면과 나선면뿐이다(Catalan). 또 극소곡면의 좌표를 등온 좌표(\(E = G\), \(F = 0\))로 잡으면 좌표 함수들이 조화함수가 되어, 복소해석학의 정칙함수로 극소곡면을 만드는 Weierstrass 표현이 생긴다.

흔한 오해극소곡면이 늘 넓이가 가장 작은 곡면이라고 여기기 쉽지만, 평균곡률이 0이라는 것은 넓이의 임계점이라는 뜻일 뿐이다. 또 평균곡률이 0이면 곡면이 평평하다고 여기는 것도 틀렸다. 두 주곡률이 부호가 반대로 같은 크기일 뿐이므로 가우스 곡률은 0 이하이며, 현수면처럼 휜 곡면도 극소곡면이다.
마무리

곡면을 법선 방향으로 조금 밀 때 넓이의 변화율은 평균곡률을 적분한 것이므로, 넓이의 임계점인 곡면은 평균곡률이 0이다. 이런 극소곡면에서는 두 주곡률의 합이 0이라 모든 점이 안장 모양이다. 현수면과 나선면이 대표적인 예이고, 둘은 국소적으로 등장이다.

4.7.4연습문제

기본

  1. 현수면의 Gauss 곡률을 구하여라.
    답

    \(K = \frac{eg - f^2}{EG - F^2} = \frac{-1}{\cosh^4v}\).

응용

  1. 그래프 곡면 \(z = f(x, y)\)가 극소곡면일 조건 \((1 + f_y^2)f_{xx} - 2f_xf_yf_{xy} + (1 + f_x^2)f_{yy} = 0\)을 유도하는 방법을 설명하여라.
    답

    \(\mathbf x = (x, y, f)\)로 \(E, F, G, e, f, g\)를 계산해 \(eG - 2fF + gE = 0\)에 넣으면 공통 인수 \(\frac{1}{\sqrt{1 + f_x^2 + f_y^2}}\)를 빼고 그 식이 남는다.
