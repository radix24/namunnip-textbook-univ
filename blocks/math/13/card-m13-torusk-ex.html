원환면의 곡률을 모두 더하면

예제 · 가우스-보네 정리를 직접 확인

먼저 예측

원환면의 바깥쪽 넓이가 안쪽보다 넓습니다. 그렇다면 양의 곡률이 이겨서 전체 곡률이 양수일까요?

예측 확인

아닙니다. 정확히 0입니다. 안쪽은 넓이가 작은 대신 곡률의 절댓값이 큽니다.

원환면 \(\mathbf x(u, v) = ((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\) (\(0 < r < R\))의 가우스 곡률이 \(K = \dfrac{\cos u}{r(R + r\cos u)}\)일 때, \(\iint K\,dA\)를 계산하고 바깥쪽(\(|u| < \frac\pi2\))만의 적분을 구하여라.

전략

4.3절 예제의 넓이 요소 \(dA = \sqrt{EG - F^2}\,du\,dv = r(R + r\cos u)\,du\,dv\)를 쓰면 분모가 지워집니다. 정리 6.4.1(6.4절)의 예측은 \(2\pi\chi = 0\)입니다.

풀이

  1. \(K\,dA = \dfrac{\cos u}{r(R + r\cos u)}\cdot r(R + r\cos u)\,du\,dv = \cos u\,du\,dv\).
    정리하면 \(R, r\)이 사라진다.
  2. \(\iint K\,dA = \int_0^{2\pi}\int_{-\pi}^{\pi}\cos u\,du\,dv = 0\).
    \(\int_{-\pi}^\pi\cos u = 0\).
  3. 바깥쪽: \(\int_0^{2\pi}\int_{-\pi/2}^{\pi/2}\cos u\,du\,dv = 2\pi\cdot2 = 4\pi\). 안쪽은 \(-4\pi\).
    \([\sin u]_{-\pi/2}^{\pi/2} = 2\).

검산

\(R = 2\), \(r = 1\)일 때 가장 바깥 원(\(u = 0\))에서 \(K = \frac13\), 가장 안쪽 원(\(u = \pi\))에서 \(K = -1\)입니다. 바깥쪽 넓이는 \(\int\int(2 + \cos u)\,du\,dv = 2\pi(2\pi + 2)\), 안쪽은 \(2\pi(2\pi - 2)\)로 바깥이 넓지만 곡률의 크기는 안쪽이 커서 정확히 상쇄됩니다.

의미

바깥쪽의 \(4\pi\)는 구면의 전체 곡률과 같습니다. 바깥쪽 반의 법벡터가 단위구면을 한 번 덮고, 안쪽 반이 반대 방향으로 한 번 더 덮기 때문입니다. 넓이나 \(R, r\)과 무관하게 정수배의 \(2\pi\)가 나오는 것이 가우스-보네 정리의 위상적 성격입니다.

이해 확인

\(K = 0\)인 점들은 어디인가?

답

\(\cos u = 0\), 곧 \(u = \pm\frac\pi2\): 원환면의 맨 위와 맨 아래 원. 포물점이다.
