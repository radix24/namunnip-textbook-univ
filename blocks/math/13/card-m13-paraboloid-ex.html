포물면은 바깥으로 갈수록 평평해진다

예제 · 그래프의 가우스 곡률 공식

먼저 예측

포물면 \(z = x^2 + y^2\)은 꼭짓점에서 가장 많이 휘었습니다. 꼭짓점에서 거리 1인 곳의 가우스 곡률은 꼭짓점의 몇 분의 1일까요?

예측 확인

25분의 1입니다. 4에서 0.16으로 줄어듭니다.

\(z = x^2 + y^2\)의 가우스 곡률을 \(r = \sqrt{x^2 + y^2}\)의 함수로 구하고, \(r = 0, 1, 2\)에서의 값을 구하여라. 모든 점이 어떤 종류의 점인가?

전략

정리 4.5.1(4.5절)에 2계 편도함수와 기울기를 넣습니다.

풀이

  1. \(f_x = 2x\), \(f_y = 2y\), \(f_{xx} = f_{yy} = 2\), \(f_{xy} = 0\).
    미분.
  2. \(K = \dfrac{4}{(1 + 4x^2 + 4y^2)^2} = \dfrac4{(1 + 4r^2)^2}\).
    공식.
  3. \(K(0) = 4\), \(K(1) = \frac4{25} = 0.16\), \(K(2) = \frac4{289} \approx 0.0138\).
    대입.
  4. 모든 점에서 \(K > 0\): 타원점.
    곡면이 각 접평면의 위쪽에 놓인다.

검산

꼭짓점의 주곡률은 \(f_{xx} = f_{yy} = 2\)라 곡률원의 반지름이 \(\frac12\)이고 \(K = 2\cdot2 = 4\)입니다. 반지름 \(\frac12\)인 구면의 \(K = \frac1{(1/2)^2} = 4\)와 같아, 꼭짓점 근처가 그 구면과 2차까지 일치합니다.

의미

\(r\)이 커지면 \(K \approx \frac1{4r^4}\)로 빠르게 0에 다가갑니다. 포물면은 멀리서 보면 원뿔처럼 거의 펼칠 수 있는 곡면이 됩니다. 전체 곡률 \(\iint K\,dA\)는 유한하며 \(2\pi\)인데, 이는 법벡터가 위쪽 반구 전체를 한 번 덮기 때문입니다(가우스 사상).

\(z = x^2 + 3y^2\)의 원점에서 \(K\)는?

답

\(2\cdot6 - 0 = 12\).
