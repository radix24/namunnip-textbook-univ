곡률과 열률로 곡선 분류하기

본문

곡률이 늘 0인 곡선은 직선일 것 같고, 열률이 늘 0인 곡선은 평면 안에 있을 것 같다. 곡률이 상수이면 원일까? 곡률과 열률이 모두 상수이면 어떤 곡선일까? 그리고 둘의 비만 일정하면?

먼저 알아야 할 것프레네 공식(2.2절)을 쓴다.

2.3.1직선과 평면곡선

정리 2.3.1

\(\beta\)가 단위속력 곡선이라 하자. (a) \(\kappa \equiv 0\)일 필요충분조건은 \(\beta\)가 직선의 일부인 것이다. (b) \(\kappa > 0\)일 때 \(\tau \equiv 0\)일 필요충분조건은 \(\beta\)가 한 평면 안에 있는 것이다.

증명.(a) \(\kappa = |T'| = 0\)이면 \(T\)가 상수 \(\mathbf u\)이고 \(\beta(s) = \beta(0) + s\mathbf u\)이다. 역은 직선의 \(T\)가 상수라 분명하다. (b) \(\tau = 0\)이면 \(B' = -\tau N = 0\)이라 \(B\)가 상수 \(B_0\)이다. \(g(s) = (\beta(s) - \beta(0))\cdot B_0\)이라 하면 \(g' = T\cdot B_0 = 0\), \(g(0) = 0\)이므로 \(g \equiv 0\)이다. 따라서 \(\beta\)는 \(\beta(0)\)을 지나고 \(B_0\)에 수직인 평면 안에 있다. 거꾸로 \(\beta\)가 법벡터 \(\mathbf n\)인 평면에 있으면 \(T\cdot\mathbf n = 0\), \(T'\cdot\mathbf n = 0\)이라 \(T\)와 \(N\)이 평면에 평행하고, \(B = \pm\mathbf n\)이 상수이므로 \(\tau = 0\)이다. ∎

(b)에는 \(\kappa > 0\)이라는 가정이 필요하다. 직선 조각과 곡선 조각을 \(\kappa = 0\)인 점에서 이어 붙이면, 그 점에서 \(B\)가 정의되지 않으므로 각 조각이 서로 다른 평면에 있을 수 있기 때문이다.

2.3.2원과 나선

정리 2.3.2

(a) \(\kappa\)가 양의 상수이고 \(\tau = 0\)이면 \(\beta\)는 반지름 \(\frac1\kappa\)인 원의 일부이다. (b) \(\kappa > 0\)과 \(\tau \ne 0\)이 모두 상수이면 \(\beta\)는 반지름 \(\frac\kappa{\kappa^2 + \tau^2}\), 피치 \(\frac{2\pi\tau}{\kappa^2 + \tau^2}\)인 원형 나선이다.

(a)의 증명은 곡률 중심 \(\mathbf c(s) = \beta(s) + \frac1\kappa N(s)\)가 상수임을 보이는 것이다. 실제로 \(\mathbf c' = T + \frac1\kappa(-\kappa T + \tau B) = 0\)이므로 \(\beta\)는 \(\mathbf c\)에서 거리 \(\frac1\kappa\)인 점들이다. (b)는 예제 2.1.2의 나선 \(\kappa = \frac a{a^2 + b^2}\), \(\tau = \frac b{a^2 + b^2}\)을 \(a, b\)에 대해 풀면 \(a = \frac\kappa{\kappa^2 + \tau^2}\), \(b = \frac\tau{\kappa^2 + \tau^2}\)이라는 것과, 3단원의 곡선의 기본정리 "같은 \(\kappa, \tau\)이면 합동"에서 나온다.

2.3.3일반 나선

정의

단위벡터 \(\mathbf u\)가 있어 \(T\cdot\mathbf u\)가 상수인 곡선을 일반 나선이라 한다. 원기둥 위의 나선뿐 아니라, 임의의 기둥면 위에서 모선과 일정한 각을 이루는 곡선이다.

정리 2.3.3 (랑크레)

\(\kappa > 0\)인 곡선이 일반 나선일 필요충분조건은 \(\tau/\kappa\)가 상수인 것이다.

증명.\(T\cdot\mathbf u = \cos\theta\)가 상수이면 미분해 \(\kappa N\cdot\mathbf u = 0\)이므로 \(\mathbf u\)는 \(T\)와 \(B\)의 결합 \(\mathbf u = \cos\theta\,T + \sin\theta\,B\)이다. 다시 미분하면 \(0 = (\kappa\cos\theta - \tau\sin\theta)N\)이므로 \(\tau/\kappa = \cot\theta\)이다. 거꾸로 \(\tau/\kappa = \cot\theta\)인 \(\theta\)를 잡고 \(\mathbf u = \cos\theta\,T + \sin\theta\,B\)로 두면, 위 계산을 거꾸로 하여 \(\mathbf u' = 0\)이고 \(T\cdot\mathbf u = \cos\theta\)이다. ∎

흔한 오해"\(\tau = 0\)이면 평면곡선"을 \(\kappa = 0\)인 점이 있어도 쓰기 쉽지만, 그 점에서 다른 평면으로 넘어갈 수 있다. 또 "곡률이 상수면 원"이라고 단정하는 것도 틀렸다. 나선도 곡률이 상수이므로 열률까지 봐야 한다.
마무리

처음 질문에 답하면, 곡률이 늘 0이면 직선이고, \(\kappa > 0\)에서 열률이 늘 0이면 평면곡선이다. 곡률만 상수인 것으로는 원이라 할 수 없고, 열률까지 0이어야 원이다. 곡률과 열률이 모두 상수이면 원형 나선이고, 비 \(\tau/\kappa\)만 일정하면 어떤 고정된 방향과 일정한 각을 이루는 일반 나선이다(랑크레 정리). 증명은 모두 프레네 공식으로 어떤 벡터가 상수임을 보이는 것이다.

2.3.4연습문제

기본

  1. \(\kappa = 1\), \(\tau = 1\)인 나선의 반지름과 피치를 구하여라.
    답

    반지름 \(\frac12\), 피치 \(\frac{2\pi}2 = \pi\).

응용

  1. \(\alpha(t) = (t + \sqrt3\sin t, 2\cos t, \sqrt3t - \sin t)\)가 평면곡선인지 판정하여라.
    답

    \(\alpha' = (1 + \sqrt3\cos t, -2\sin t, \sqrt3 - \cos t)\)의 속력은 \(2\sqrt2\)로 일정하다. \(\alpha'' = (-\sqrt3\sin t, -2\cos t, \sin t)\), \(\alpha''' = (-\sqrt3\cos t, 2\sin t, \cos t)\)로 정리 2.1.1을 쓰면 모든 \(t\)에서 \(\kappa = \frac14\), \(\tau = -\frac14\)이다((예) \(t = 0\)에서 직접 계산). \(\tau \ne 0\)이므로 평면곡선이 아니며, 정리 2.3.2에 따라 반지름 \(\frac{1/4}{1/8} = 2\)인 (왼나사) 원형 나선과 합동이다.

심화

  1. 모든 법평면(\(T\)에 수직인 평면)이 한 점을 지나는 곡선은 구면 위에 있음을 보여라.
    답

    그 점을 \(\mathbf c\)라 하면 \((\beta - \mathbf c)\cdot T = 0\)이므로 \(\frac{d}{ds}|\beta - \mathbf c|^2 = 2(\beta - \mathbf c)\cdot T = 0\). 따라서 \(|\beta - \mathbf c|\)가 상수이다.
