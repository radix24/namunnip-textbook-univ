포물면 그릇을 지나는 선속

예제 · 2-형식을 당겨 적분하기

먼저 예측

원점에서 바깥으로 뻗는 벡터장 \(\mathbf F = (x, y, z)\)가 그릇 모양 \(z = x^2 + y^2\) (\(z \le 1\))을 위쪽 방향으로 지나는 선속은 양수일까, 음수일까?

예측 확인

음수(\(-\frac\pi2\))이다. 그릇의 옆면에서 \(\mathbf F\)는 바깥(아래쪽 법선 쪽)으로 향하는 성분이 더 크기 때문이다.

\(M\): \(z = x^2 + y^2\), \(x^2 + y^2 \le 1\), 위쪽(\(z\)성분이 양수인) 단위법벡터로 방향을 준다. \(\eta_{\mathbf F} = x\,dy\wedge dz + y\,dz\wedge dx + z\,dx\wedge dy\)의 적분을 구하고, 발산 정리로 검산하여라.

전략

극좌표 조각 \(\mathbf x(r, \theta) = (r\cos\theta, r\sin\theta, r^2)\)로 당긴다. \(\mathbf x_r\times\mathbf x_\theta\)의 \(z\)성분이 양수인지 확인한다 (5.1절).

풀이

  1. \(\mathbf x_r = (\cos\theta, \sin\theta, 2r)\), \(\mathbf x_\theta = (-r\sin\theta, r\cos\theta, 0)\), \(\mathbf x_r\times\mathbf x_\theta = (-2r^2\cos\theta, -2r^2\sin\theta, r)\).
    \(z\)성분 \(r > 0\): 방향과 맞는다.
  2. \(\eta_{\mathbf F}(\mathbf x_r, \mathbf x_\theta) = \mathbf F\cdot(\mathbf x_r\times\mathbf x_\theta) = -2r^3\cos^2\theta - 2r^3\sin^2\theta + r^2\cdot r = -r^3\).
    \(\mathbf F = (r\cos\theta, r\sin\theta, r^2)\).
  3. \(\iint_M\eta_{\mathbf F} = \int_0^{2\pi}\int_0^1(-r^3)\,dr\,d\theta = -\frac\pi2 \approx -1.571\).
    \(\mathbf x^*\eta = -r^3\,dr\wedge d\theta\).

검산

그릇과 뚜껑(\(z = 1\)의 원판)으로 둘러싸인 입체 \(V\)에서 \(\nabla\cdot\mathbf F = 3\), 부피 \(\int_0^{2\pi}\int_0^1(1 - r^2)r\,dr\,d\theta = \frac\pi2\)이므로 바깥 선속 합은 \(\frac{3\pi}2\)이다. 뚜껑(바깥 = 위쪽)에서 \(\mathbf F\cdot U = z = 1\)이라 \(\pi\), 그릇(바깥 = 아래쪽)에서는 위 결과의 부호를 바꾼 \(+\frac\pi2\). 합 \(\frac{3\pi}2\)로 맞다.

의미

2-형식의 적분은 "방향을 가진 선속"이다. 같은 곡면이라도 법벡터의 방향을 바꾸면 부호가 바뀌고, 닫힌 곡면 전체의 바깥 선속은 내부의 발산의 합과 같습니다(5.2절의 스토크스 정리의 3차원판).

이해 확인

같은 그릇에서 \(\mathbf F = (0, 0, 1)\)의 (위쪽) 선속은?

답

\(\mathbf F\cdot(\mathbf x_r\times\mathbf x_\theta) = r\)이므로 \(\int_0^{2\pi}\int_0^1r\,dr\,d\theta = \pi\): \(xy\)평면에 사영한 넓이와 같다.
