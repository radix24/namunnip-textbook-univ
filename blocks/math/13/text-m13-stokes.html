곡면의 스토크스 정리

본문
이 절에서 배울 것
  • 곡면의 방향과 경계의 방향을 맞추는 규칙을 안다.
  • 스토크스 정리 \(\iint_Md\phi = \oint_{\partial M}\phi\)와 그 벡터 꼴 \(\iint(\nabla\times\mathbf F)\cdot U\,dA = \oint\mathbf F\cdot d\mathbf r\)을 적용한다.
  • 경계가 같은 곡면들에서 회전의 선속이 같고, 닫힌 곡면에서는 0임을 이해한다.
먼저 알아야 할 것
  • 곡면 위의 적분 (5.1절), 기울기·회전·발산의 사전 (1.3절), 일반화 스토크스 정리 (수학11 5.2절).

5.2.1경계의 방향

곡면 \(M\)이 경계 곡선 \(\partial M\)을 가질 때, 법벡터 \(U\) 쪽으로 머리를 두고 경계를 따라 걸으면 곡면이 왼쪽에 있도록 경계의 방향을 정합니다. 좌표조각으로 말하면 \((u, v)\) 영역의 경계를 반시계 방향으로 돈 것을 \(\mathbf x\)로 옮긴 방향입니다(\(\mathbf x\)가 방향과 맞을 때). 위쪽 방향의 위 반구라면 경계인 적도를 위에서 보아 반시계 방향으로 돕니다.

5.2.2정리

정리 5.2.1 (곡면의 스토크스 정리)

\(M\)이 방향이 있고 경계가 조각마다 매끄러운 컴팩트 곡면이며, \(\phi\)가 \(M\)의 근방에서 정의된 1-형식이면 (경계의 방향은 위의 규칙)

\[\iint_Md\phi = \oint_{\partial M}\phi.\]

벡터장으로 쓰면 \(\displaystyle\iint_M(\nabla\times\mathbf F)\cdot U\,dA = \oint_{\partial M}\mathbf F\cdot d\mathbf r\).

증명의 흐름.하나의 좌표조각 \(\mathbf x: R \to M\) (\(R\)은 직사각형)으로 덮이면 \(\iint_Md\phi = \iint_R\mathbf x^*d\phi = \iint_Rd(\mathbf x^*\phi)\) (당김과 \(d\)의 교환)이고, 평면의 그린 정리로 \(= \oint_{\partial R}\mathbf x^*\phi = \oint_{\partial M}\phi\). 일반적인 경우는 곡면을 이런 조각들로 나누고, 이웃한 조각이 공유하는 변에서는 두 방향이 반대라 선적분이 상쇄된다는 것으로 끝난다(수학11 5.2절). ∎

벡터 꼴은 \(\phi = \phi_{\mathbf F}\)이면 \(d\phi_{\mathbf F} = \eta_{\nabla\times\mathbf F}\) (1.3절)이고 \(\iint\eta_{\mathbf G} = \iint\mathbf G\cdot U\,dA\) (5.1절)라는 두 사실을 합친 것입니다.

5.2.3예와 따름정리

예제 5.2.2

\(\mathbf F = (z - y, x + z^2, xy)\)와 위쪽 방향의 위 반구 \(M\)에 대해 스토크스 정리를 확인하여라.

풀이. 경계는 \(xy\)평면의 단위원(반시계)이고 그 위에서 \(z = 0\)이라 \(\oint\mathbf F\cdot d\mathbf r = \oint(-y\,dx + x\,dy) = 2\pi\). 한편 \(\nabla\times\mathbf F = (x - 2z, 1 - y, 2)\). 5.1절의 반구 조각으로 계산하면 \(x\)와 \(-y\)의 항이 각각 \(\frac{2\pi}3\), \(-\frac{2\pi}3\)으로 상쇄되고 \(-2z\), 1의 항은 \(\cos\theta\), \(\sin\theta\)의 적분이라 0, 남는 \(2\cos\varphi\sin\varphi\)의 적분이 \(2\pi\)입니다. 두 값이 같습니다.

  • 경계가 같으면 선속이 같다. 위 반구 대신 단위원판(위쪽 방향)을 쓰면 \((\nabla\times\mathbf F)\cdot\mathbf k = 2\)이라 선속이 \(2\pi\)로 곧바로 나옵니다. 경계가 같은 어떤 곡면이든 회전의 선속은 경계의 선적분 하나로 정해집니다. 같은 절의 탐구 카드에서 그릇의 깊이를 바꿔 가며 확인합니다.
  • 닫힌 곡면에서는 0. 구면처럼 경계가 없는 컴팩트 곡면에서는 \(\iint(\nabla\times\mathbf F)\cdot U\,dA = 0\)입니다. 구면을 두 반구로 나누면 공유 경계를 반대 방향으로 돌기 때문입니다.
  • 보존장 판정. 단일연결인 곡면 영역에서 \(\nabla\times\mathbf F = \mathbf 0\)이면 모든 닫힌 곡선의 선적분이 0이고, 따라서 \(\mathbf F\)는 기울기장입니다.
흔한 오해(1) 경계의 방향을 반대로 잡아 부호가 틀린다(머리를 \(U\) 쪽에, 곡면은 왼쪽). (2) \(\mathbf F\)가 곡면 위의 어딘가에서 정의되지 않는데(특이점) 정리를 쓴다. (3) "선속이 0이면 회전이 0": 닫힌 곡면에서는 회전이 0이 아니어도 선속이 0이다.
요약
  1. 경계 방향: \(U\) 쪽으로 머리, 곡면은 왼쪽.
  2. \(\iint_Md\phi = \oint_{\partial M}\phi\), 곧 \(\iint(\nabla\times\mathbf F)\cdot U\,dA = \oint\mathbf F\cdot d\mathbf r\). 증명: 당김 + 그린 + 경계 상쇄.
  3. 회전의 선속은 경계에만 의존하고, 닫힌 곡면에서는 0.

5.2.4연습문제

기본

  1. \(\mathbf F = (-y, x, 0)\)에 대해 \(xy\)평면 위의 반지름 \(R\)인 원판(위쪽)에서 스토크스 정리를 확인하여라.
    답

    \(\nabla\times\mathbf F = (0, 0, 2)\), 선속 \(2\pi R^2\). 경계 \((R\cos t, R\sin t, 0)\)에서 \(\oint = \int_0^{2\pi}R^2\,dt = 2\pi R^2\).

응용

  1. \(\mathbf F = (y, z, x)\)의 회전이 원기둥 \(x^2 + y^2 = 1\), \(0 \le z \le 1\)의 옆면(바깥쪽)을 지나는 선속을 스토크스 정리로 구하여라.
    답

    경계는 두 원: 바깥쪽 방향이면 \(z = 0\)의 원은 위에서 보아 반시계, \(z = 1\)의 원은 시계 방향이다. \(\oint\mathbf F\cdot d\mathbf r\)에서 \(\mathbf F\cdot\gamma' = (\sin t, z, \cos t)\cdot(-\sin t, \cos t, 0) = -\sin^2t + z\cos t\), 적분하면 \(-\pi\) (z와 무관). 반시계 \(-\pi\)와 시계 \(+\pi\)를 더해 0.

심화

  1. \(\mathbf F = \frac{(-y, x, 0)}{x^2 + y^2}\)은 \(z\)축 밖에서 \(\nabla\times\mathbf F = \mathbf 0\)인데, \(z\)축을 감싸는 고리 모양 곡면(원기둥 옆면)에서 스토크스 정리를 쓰면 무엇을 알 수 있는가?
    답

    옆면에서 회전의 선속이 0이므로 두 경계 원의 선적분(방향 고려)의 합이 0, 곧 높이가 다른 두 원에서 \(\oint\mathbf F\cdot d\mathbf r\)이 같다(둘 다 \(2\pi\)). 원판에는 \(z\)축이 지나 \(\mathbf F\)가 정의되지 않으므로 원판으로 계산할 수 없다.
