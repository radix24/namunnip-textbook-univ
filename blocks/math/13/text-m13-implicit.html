음함수 꼴 곡면

본문
이 절에서 배울 것
  • 등위집합 \(M = \{g = c\}\)에서 \(\nabla g \ne \mathbf 0\)이면 \(M\)이 정칙 곡면임을 음함수정리로 증명한다.
  • 음함수 꼴 곡면의 접평면과 법벡터를 \(\nabla g\)로 구한다.
  • 정칙값과 임계값을 구별하고, 쌍곡면 족에서 곡면이 아닌 경우(원뿔)를 확인한다.
먼저 알아야 할 것
  • 음함수정리 (수학11 2.2절), 좌표조각 (4.1절).

4.2.1정리

정리 4.2.1

\(g: \mathbb R^3 \to \mathbb R\)이 매끄럽고 \(M = \{\mathbf p : g(\mathbf p) = c\}\)가 공집합이 아니며, \(M\)의 모든 점에서 \(\nabla g \ne \mathbf 0\)이면 \(M\)은 곡면이다. 이때 \(\nabla g(\mathbf p)\)는 \(T_{\mathbf p}M\)에 수직이다.

증명.\(\mathbf p \in M\)에서 예를 들어 \(\frac{\partial g}{\partial z}(\mathbf p) \ne 0\)이라 하자(다른 성분이 0이 아니면 좌표 이름만 바꾼다). 음함수정리로 \((p_1, p_2)\)의 근방 \(D\)와 매끄러운 함수 \(h: D \to \mathbb R\)이 있어, \(\mathbf p\) 근처에서 \(M\)의 점은 정확히 \((u, v, h(u, v))\)이다. 따라서 \(\mathbf x(u, v) = (u, v, h(u, v))\)는 \(\mathbf p\) 근처의 \(M\)을 덮는 그래프 꼴 좌표조각이고, 4.1절에서 보았듯 정칙이며 일대일이고 역(사영)이 연속이다. 법벡터에 대해: \(M\) 위의 곡선 \(\alpha\)에서 \(g(\alpha(t)) = c\)를 미분하면 \(\nabla g\cdot\alpha' = 0\). ∎

정칙값: \(g^{-1}(c)\)의 모든 점에서 \(\nabla g \ne \mathbf 0\)인 \(c\). 그렇지 않은 \(c\)는 임계값이다.

이 정리는 수학11의 계수정리(침몰의 경우)를 3차원에서 쓴 것입니다. 많은 곡면이 이 방법으로 바로 곡면임이 확인되며, 좌표조각을 일일이 만들 필요가 없습니다.

4.2.2예

  • 구면 \(x^2 + y^2 + z^2 = r^2\): \(\nabla g = 2(x, y, z) \ne \mathbf 0\) (원점은 구면 위에 없다). 법벡터는 위치벡터 방향.
  • 타원면 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1\): 같은 이유로 곡면.
  • 원환면 \(\left(\sqrt{x^2 + y^2} - R\right)^2 + z^2 = r^2\) (\(R > r > 0\)): \(z\)축 위(\(\sqrt{\ } = 0\))에서 \(g\)가 매끄럽지 않지만 원환면은 \(z\)축과 만나지 않으므로 상관없다.
예제 4.2.2 (쌍곡면 족)

\(g = x^2 + y^2 - z^2\)의 등위집합 \(g = c\)가 곡면이 되는 \(c\)를 구하여라.

풀이. \(\nabla g = 2(x, y, -z) = \mathbf 0\)은 원점에서만 성립하고 \(g(\mathbf 0) = 0\)이므로 임계값은 \(c = 0\) 하나입니다. \(c > 0\)이면 일엽쌍곡면(한 장), \(c < 0\)이면 이엽쌍곡면(두 장)으로 모두 곡면입니다. \(c = 0\)이면 원뿔 \(z^2 = x^2 + y^2\)이고 꼭짓점에서 곡면이 아닙니다(4.1절). 같은 절의 예제 카드에서 이 족을 자세히 봅니다.

임계값이라고 해서 등위집합이 반드시 곡면이 아닌 것은 아닙니다. \(g = z^2\)의 \(c = 0\)은 임계값이지만(\(M\) 위에서 \(\nabla g = (0, 0, 2z) = \mathbf 0\)) \(g^{-1}(0)\)은 평면 \(z = 0\)으로 곡면입니다. 정리는 충분조건입니다.

4.2.3접평면

음함수 꼴에서는 접평면이 \(\nabla g(\mathbf p)\cdot(\mathbf q - \mathbf p) = 0\)입니다. 예: 타원면 \(\frac{x^2}4 + y^2 + \frac{z^2}9 = 1\) 위의 점 \((1, \frac12, \frac{3}{\sqrt2})\)에서 \(\nabla g = (\frac12, 1, \frac{2}{9}\cdot\frac3{\sqrt2}) = (\frac12, 1, \frac{\sqrt2}3)\)이므로 접평면은 \(\frac x2 + y + \frac{\sqrt2}3z = \frac12 + \frac12 + 1 = 2\)입니다(점이 곡면 위에 있음: \(\frac14 + \frac14 + \frac12 = 1\)).

흔한 오해(1) \(\nabla g\)가 0이 되는 점이 \(M\) 위에 있는지 확인하지 않는다(정리는 \(M\) 위의 점만 본다). (2) 임계값이면 곡면이 아니라고 단정한다(\(z^2 = 0\)의 예).
요약
  1. \(c\)가 정칙값(\(M = g^{-1}(c)\) 위에서 \(\nabla g \ne \mathbf 0\))이면 \(M\)은 곡면. 증명: 음함수정리로 국소적으로 그래프.
  2. 법벡터는 \(\nabla g\), 접평면 \(\nabla g(\mathbf p)\cdot(\mathbf q - \mathbf p) = 0\).
  3. \(x^2 + y^2 - z^2 = c\): \(c \ne 0\)이면 곡면, \(c = 0\)은 원뿔(특이점).

4.2.4연습문제

기본

  1. \(xyz = 1\)이 곡면임을 보여라.
    답

    \(\nabla g = (yz, xz, xy)\). \(xyz = 1\)이면 \(x, y, z \ne 0\)이라 \(\nabla g \ne \mathbf 0\).

응용

  1. \(z = x^2 + y^2\) (포물면)의 점 \((1, 1, 2)\)에서 접평면을 음함수 꼴과 그래프 꼴 두 방법으로 구하여라.
    답

    \(g = x^2 + y^2 - z\), \(\nabla g = (2, 2, -1)\): \(2(x - 1) + 2(y - 1) - (z - 2) = 0\), 곧 \(z = 2x + 2y - 2\). 그래프 꼴: \((-f_u, -f_v, 1) = (-2, -2, 1)\)로 같은 평면.

심화

  1. \(g = (x^2 + y^2 + z^2)^2 - 4(x^2 + y^2)\)의 등위집합 \(g = 0\)은 무엇이고, 곡면인가?
    답

    \(x^2 + y^2 + z^2 = 2\sqrt{x^2 + y^2}\) (또는 원점), 곧 \((\sqrt{x^2 + y^2} - 1)^2 + z^2 = 1\): 구멍이 없는 원환면(\(R = r = 1\))과 원점. 원점에서 \(\nabla g = \mathbf 0\)이고 실제로 원환면이 원점에서 자기 자신과 닿아 곡면이 아니다. 원점을 빼면 곡면이다.
