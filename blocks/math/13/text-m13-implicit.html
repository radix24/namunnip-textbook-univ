음함수 꼴 곡면

본문

구면 \(x^2 + y^2 + z^2 = 1\)이나 타원면처럼 방정식 하나로 주어진 도형이 곡면이라는 것을, 좌표조각을 일일이 만들지 않고 확인할 수 있을까? \(x^2 + y^2 - z^2 = c\)는 어떤 \(c\)에서 곡면이고, 어떤 \(c\)에서 문제가 생길까?

먼저 알아야 할 것음함수정리(수학11 2.2절), 좌표조각(4.1절)을 쓴다.

4.2.1정리

정리 4.2.1

\(g: \mathbb R^3 \to \mathbb R\)이 매끄럽고 \(M = \{\mathbf p : g(\mathbf p) = c\}\)가 공집합이 아니며, \(M\)의 모든 점에서 \(\nabla g \ne \mathbf 0\)이면 \(M\)은 곡면이다. 이때 \(\nabla g(\mathbf p)\)는 \(T_{\mathbf p}M\)에 수직이다.

증명.\(\mathbf p \in M\)에서 예를 들어 \(\frac{\partial g}{\partial z}(\mathbf p) \ne 0\)이라 하자. 다른 성분이 0이 아니면 좌표 이름만 바꾼다. 음함수정리로 \((p_1, p_2)\)의 근방 \(D\)와 매끄러운 함수 \(h\)가 있어, \(\mathbf p\) 근처에서 \(M\)의 점은 정확히 \((u, v, h(u, v))\)이다. 따라서 \(\mathbf x(u, v) = (u, v, h(u, v))\)는 \(\mathbf p\) 근처의 \(M\)을 덮는 그래프 꼴 좌표조각이고, 4.1절에서 보았듯 정칙이며 일대일이고 역사상이 연속이다. 또 \(M\) 위의 곡선 \(\alpha\)에서 \(g(\alpha(t)) = c\)를 미분하면 \(\nabla g\cdot\alpha' = 0\)이므로 \(\nabla g\)는 접평면에 수직이다. ∎

정의

\(g^{-1}(c)\)의 모든 점에서 \(\nabla g \ne \mathbf 0\)인 \(c\)를 정칙값, 그렇지 않은 \(c\)를 임계값이라 한다.

이 정리는 수학11의 계수정리에서 침몰의 경우를 3차원에 쓴 것이다. 그래서 많은 곡면이 좌표조각을 만들지 않고 바로 곡면임이 확인된다.

4.2.2예

구면 \(x^2 + y^2 + z^2 = r^2\)은 \(\nabla g = 2(x, y, z)\)가 원점에서만 0인데 원점이 구면 위에 없으므로 곡면이고, 법벡터는 위치벡터 방향이다. 타원면 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1\)도 같은 이유로 곡면이다. 원환면 \(\left(\sqrt{x^2 + y^2} - R\right)^2 + z^2 = r^2\) (\(R > r > 0\))은 \(z\)축 위에서 \(g\)가 매끄럽지 않지만, 원환면이 \(z\)축과 만나지 않으므로 상관없다.

예제 4.2.2 (쌍곡면 족)

\(g = x^2 + y^2 - z^2\)의 등위집합 \(g = c\)가 곡면이 되는 \(c\)를 구하여라.

풀이. \(\nabla g = 2(x, y, -z) = \mathbf 0\)은 원점에서만 성립하고 \(g(\mathbf 0) = 0\)이므로 임계값은 \(c = 0\) 하나이다. \(c > 0\)이면 한 장짜리 일엽쌍곡면, \(c < 0\)이면 두 장짜리 이엽쌍곡면으로 모두 곡면이다. \(c = 0\)이면 원뿔 \(z^2 = x^2 + y^2\)이고 꼭짓점에서 곡면이 아니며, 그림 1이 이 족이다. 같은 절의 예제 카드에서 자세히 본다.

하지만 임계값이라고 해서 등위집합이 반드시 곡면이 아닌 것은 아니다. \(g = z^2\)의 \(c = 0\)은 \(M\) 위에서 \(\nabla g = (0, 0, 2z) = \mathbf 0\)이라 임계값이지만, \(g^{-1}(0)\)은 평면 \(z = 0\)으로 곡면이다. 즉 정리는 충분조건이다.

4.2.3접평면

음함수 꼴에서는 접평면이 \(\nabla g(\mathbf p)\cdot(\mathbf q - \mathbf p) = 0\)이다. 예를 들어 타원면 \(\frac{x^2}4 + y^2 + \frac{z^2}9 = 1\) 위의 점 \((1, \frac12, \frac{3}{\sqrt2})\)을 보자. 실제로 \(\frac14 + \frac14 + \frac12 = 1\)이라 곡면 위의 점이다. \(\nabla g = (\frac12, 1, \frac{\sqrt2}3)\)이므로 접평면은 \(\frac x2 + y + \frac{\sqrt2}3z = 2\)이다.

흔한 오해\(\nabla g\)가 0이 되는 점이 \(M\) 위에 있는지 확인하지 않는 실수가 있다. 정리는 \(M\) 위의 점만 보므로, \(M\) 밖에서 기울기가 0인 것은 상관없다. 또 임계값이면 곡면이 아니라고 단정하는 것도 틀렸으며, \(z^2 = 0\)이 반례이다.
마무리

처음 질문의 답은 "확인할 수 있다"이다. \(g = c\)의 모든 점에서 \(\nabla g \ne \mathbf 0\)이면, 음함수정리로 한 변수를 나머지로 풀어 그래프 꼴 좌표조각을 얻으므로 곡면이고, \(\nabla g\)가 법벡터이다. \(x^2 + y^2 - z^2 = c\)는 \(c \ne 0\)이면 쌍곡면으로 곡면이고, 임계값 \(c = 0\)에서만 원뿔의 꼭짓점이라는 문제가 생긴다. 다만 이 조건은 충분조건일 뿐이다.

4.2.4연습문제

기본

  1. \(xyz = 1\)이 곡면임을 보여라.
    답

    \(\nabla g = (yz, xz, xy)\). \(xyz = 1\)이면 \(x, y, z \ne 0\)이라 \(\nabla g \ne \mathbf 0\).

응용

  1. \(z = x^2 + y^2\) (포물면)의 점 \((1, 1, 2)\)에서 접평면을 음함수 꼴과 그래프 꼴 두 방법으로 구하여라.
    답

    \(g = x^2 + y^2 - z\), \(\nabla g = (2, 2, -1)\): \(2(x - 1) + 2(y - 1) - (z - 2) = 0\), 곧 \(z = 2x + 2y - 2\). (그래프 꼴) \((-f_u, -f_v, 1) = (-2, -2, 1)\)로 같은 평면.

심화

  1. \(g = (x^2 + y^2 + z^2)^2 - 4(x^2 + y^2)\)의 등위집합 \(g = 0\)은 무엇이고, 곡면인가?
    답

    \(x^2 + y^2 + z^2 = 2\sqrt{x^2 + y^2}\) (또는 원점), 곧 \((\sqrt{x^2 + y^2} - 1)^2 + z^2 = 1\): 구멍이 없는 원환면(\(R = r = 1\))과 원점. 원점에서 \(\nabla g = \mathbf 0\)이고 실제로 원환면이 원점에서 자기 자신과 닿아 곡면이 아니다. 원점을 빼면 곡면이다.
