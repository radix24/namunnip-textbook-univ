입체사영 두 장으로 구면 덮기

예제 · 차트와 전이사상

먼저 예측

북극 입체사영에서 적도는 평면의 어떤 곡선이 되고, 남반구와 북반구는 각각 어디로 갈까?

예측 확인

적도는 단위원으로 가고(\(z = 0\)이면 \(\frac x1, \frac y1\)), 남반구는 단위원판 안쪽, 북반구는 바깥쪽으로 갑니다. 북극에 가까울수록 무한히 멀리 갑니다.

\(\varphi_N(x, y, z) = \left(\frac x{1 - z}, \frac y{1 - z}\right)\), \(\varphi_S(x, y, z) = \left(\frac x{1 + z}, \frac y{1 + z}\right)\)에 대해 (1) \(\varphi_N^{-1}\)을 구하고, (2) 전이사상 \(\varphi_S\circ\varphi_N^{-1}(\mathbf w) = \mathbf w/|\mathbf w|^2\)을 보이며, (3) 점 \((0.48, 0.6, 0.64)\)에서 확인하여라.

전략

\(\mathbf w = (u, v)\)에 대응하는 구면의 점은 \(N\)과 \((u, v, 0)\)을 잇는 직선 위에 있다. 직선을 매개화해 구면과의 교점을 구한다 (6.3절).

풀이

  1. 직선 \((tu, tv, 1 - t)\)이 구면 위에 있으려면 \(t^2(u^2 + v^2) + (1 - t)^2 = 1\), 곧 \(t = \frac2{1 + |\mathbf w|^2}\) (\(t \ne 0\)).
    \(t = 0\)은 북극.
  2. \(\varphi_N^{-1}(u, v) = \left(\frac{2u}{1 + |\mathbf w|^2}, \frac{2v}{1 + |\mathbf w|^2}, \frac{|\mathbf w|^2 - 1}{|\mathbf w|^2 + 1}\right)\).
    \(1 - t = \frac{|\mathbf w|^2 - 1}{|\mathbf w|^2 + 1}\).
  3. \(\varphi_S\)를 적용하면 \(1 + z = \frac{2|\mathbf w|^2}{1 + |\mathbf w|^2}\)이므로 \(\frac{x}{1 + z} = \frac{2u}{1 + |\mathbf w|^2}\cdot\frac{1 + |\mathbf w|^2}{2|\mathbf w|^2} = \frac u{|\mathbf w|^2}\). 따라서 전이사상은 \(\mathbf w \mapsto \frac{\mathbf w}{|\mathbf w|^2}\).
    겹치는 곳은 \(\mathbf w \ne \mathbf 0\)(남극 제외)이고 거기서 매끄럽다.
  4. \((0.48, 0.6, 0.64)\): \(\varphi_N = (\frac{0.48}{0.36}, \frac{0.6}{0.36}) = (\frac43, \frac53)\), \(|\mathbf w|^2 = \frac{41}9\), \(\mathbf w/|\mathbf w|^2 = (\frac{12}{41}, \frac{15}{41}) \approx (0.2927, 0.3659)\). 직접 \(\varphi_S = (\frac{0.48}{1.64}, \frac{0.6}{1.64}) = (\frac{12}{41}, \frac{15}{41})\). 일치.
    \(0.48^2 + 0.6^2 + 0.64^2 = 1\)이라 구면 위의 점.

검산

적도 위의 점 \((1, 0, 0)\)은 두 차트 모두에서 \((1, 0)\)이고, \(|\mathbf w| = 1\)이면 전이사상이 항등이라 맞습니다. 북극에 가까운 점(\(|\mathbf w|\) 큼)은 남극 차트에서 원점 근처로 갑니다.

의미

두 차트와 매끄러운 전이사상만 알면 구면을 \(\mathbb R^3\) 없이 다룰 수 있습니다. 복소수로 보면 전이사상은 \(w \mapsto 1/\bar w\)이고, 켤레를 붙여 \(w \mapsto 1/w\)로 바꾸면 리만 구면(복소해석의 \(\mathbb C\cup\{\infty\}\))이 됩니다.

이해 확인

북극 차트에서 반지름 2인 원 \(|\mathbf w| = 2\)는 구면의 어떤 위선인가?

답

\(z = \frac{4 - 1}{4 + 1} = 0.6\)인 위선(북반구, 위도 약 \(36.9°\)).
