곡선의 기본정리: 곡률과 열률이 곡선을 정한다

본문
이 절에서 배울 것
  • 곡률과 열률이 같은 두 단위속력 곡선은 방향을 보존하는 등장사상으로 겹쳐짐(유일성)을 증명한다.
  • 주어진 \(\kappa(s) > 0\), \(\tau(s)\)를 가지는 곡선이 존재함(존재성)을 프레네 공식을 미분방정식으로 풀어 설명한다.
  • 곡률과 열률이 곡선의 "완전한 불변량"이라는 의미를 이해한다.
먼저 알아야 할 것
  • 프레네 공식 (2.2절), 등장사상 (3.1절), 선형 상미분방정식의 해의 존재와 유일성 (수학6 1.2절).

3.2.1정리

정리 3.2.1 (곡선의 기본정리)

(a) 유일성: 구간 \(I\)에서 정의된 단위속력 곡선 \(\beta\), \(\bar\beta\)가 \(\kappa = \bar\kappa > 0\), \(\tau = \bar\tau\)이면 방향을 보존하는 등장사상 \(F\)가 있어 \(\bar\beta = F\circ\beta\)이다. (b) 존재성: 연속함수 \(\kappa(s) > 0\), \(\tau(s)\)가 주어지면 그 곡률과 열률을 가지는 단위속력 곡선이 있다.

3.2.2유일성의 증명

증명 (a).\(s_0 \in I\)에서 두 틀 \((T, N, B)(s_0)\)와 \((\bar T, \bar N, \bar B)(s_0)\)는 모두 양의 방향 정규직교 기저이므로, 하나를 다른 하나로 보내는 회전 \(A\) (\(\det A = 1\))가 있다. 평행이동을 붙여 \(F(\mathbf p) = A\mathbf p + (\bar\beta(s_0) - A\beta(s_0))\)로 두면 \(F\circ\beta\)는 \(\bar\beta\)와 \(s_0\)에서 같은 점, 같은 틀을 가지고, 3.1절에 의해 곡률과 열률도 같다(\(\det A = 1\)이므로 열률의 부호도 보존). 이제 \(\beta\)를 \(F\circ\beta\)로 바꾸어 \(s_0\)에서 점과 틀이 같다고 하자.

\[f(s) = T\cdot\bar T + N\cdot\bar N + B\cdot\bar B\]

를 미분하고 프레네 공식을 쓰면 \(f' = \kappa N\cdot\bar T + \kappa T\cdot\bar N + (-\kappa T + \tau B)\cdot\bar N + N\cdot(-\kappa\bar T + \tau\bar B) - \tau N\cdot\bar B - \tau B\cdot\bar N = 0\) (\(\kappa = \bar\kappa\), \(\tau = \bar\tau\)이라 모든 항이 짝지어 상쇄). \(f(s_0) = 3\)이므로 \(f \equiv 3\). 각 내적은 단위벡터끼리라 1 이하이므로 셋 다 1, 곧 \(T = \bar T\) 등이다. 그러면 \((\beta - \bar\beta)' = T - \bar T = 0\)이고 \(s_0\)에서 같으므로 \(\beta = \bar\beta\). ∎

3.2.3존재성: 미분방정식으로 곡선 만들기

프레네 공식을 미지 벡터 \(T, N, B\)에 대한 선형 상미분방정식으로 봅니다.

\[T' = \kappa(s)N, \qquad N' = -\kappa(s)T + \tau(s)B, \qquad B' = -\tau(s)N.\]

초기값으로 정규직교 기저 \((\mathbf e_1, \mathbf e_2, \mathbf e_3)\)를 주면 선형 방정식이라 해가 구간 전체에서 유일하게 존재합니다. 해가 계속 정규직교라는 것은, 9개의 내적 \(T\cdot T, T\cdot N, \dots\)이 만족하는 미분방정식(위 식에서 유도)을 상수 해 "\(I\)"도 만족하고 초기값이 같으므로 유일성으로 같다는 논법으로 보입니다. 그 뒤 \(\beta(s) = \int_{s_0}^sT(u)\,du\)로 두면 \(\beta' = T\), \(|\beta'| = 1\), \(\beta'' = \kappa N\)이라 곡률이 \(\kappa\), 그리고 \(B = T\times N\)(초기에 성립하고 보존됨)이므로 열률이 \(\tau\)입니다.

이 증명은 그대로 수치 계산 방법이 됩니다. 같은 절의 탐구 카드에서 \(\kappa(s)\), \(\tau(s)\)를 정하면 프레네 방정식을 룽게-쿠타 방법으로 풀어 곡선을 그립니다. 예를 들어 \(\kappa\)를 상수, \(\tau = 0\)으로 두면 원이, \(\tau\)를 상수로 두면 나선이 나오고, \(\kappa = s\), \(\tau = 0\)이면 감기는 정도가 점점 커지는 오일러 나선(클로소이드)이 나옵니다.

3.2.4의미

곡선의 "모양"(강체운동으로 겹치면 같다고 볼 때)은 두 함수 \(\kappa(s)\), \(\tau(s)\)로 완전히 정해집니다. 이처럼 등장사상으로 변하지 않으면서 모양을 완전히 구별하는 양을 완전 불변량이라 합니다. 평면곡선은 부호 있는 곡률 하나로 충분하고, 곡면에서는 이 역할을 제1기본형식과 제2기본형식(보네 정리)이 맡습니다. 도로와 철도의 곡선부를 \(\kappa\)가 0에서 서서히 커지는 클로소이드로 설계하는 것도, 곡률을 직접 정해 곡선을 만드는 이 정리의 응용입니다.

흔한 오해(1) \(\kappa = 0\)인 점이 있어도 정리가 성립한다고 여긴다. 그 점에서 \(N, B\)가 정의되지 않아 두 조각을 다른 평면으로 이어 붙일 수 있다. (2) 반사까지 허용하면 "\(\kappa = \bar\kappa\), \(\tau = -\bar\tau\)"인 곡선도 겹쳐진다는 점을 놓친다.
요약
  1. \(\kappa = \bar\kappa > 0\), \(\tau = \bar\tau\) ⇒ 방향 보존 등장사상으로 겹친다. 증명: \(f = T\cdot\bar T + N\cdot\bar N + B\cdot\bar B\)가 상수.
  2. 주어진 \(\kappa > 0\), \(\tau\)에 대해 프레네 방정식을 풀고 \(T\)를 적분하면 곡선이 존재한다.
  3. \((\kappa, \tau)\)는 공간곡선의 완전 불변량이다.

3.2.5연습문제

기본

  1. \(\kappa = \frac3{25}\), \(\tau = \frac4{25}\)인 단위속력 곡선을 하나 써라.
    답

    \(\left(3\cos\frac s5, 3\sin\frac s5, \frac{4s}5\right)\) (나선 \(a = 3\), \(b = 4\)).

응용

  1. 유일성 증명에서 \(f' = 0\)의 계산을 항별로 적어 상쇄를 확인하여라.
    답

    \(T'\cdot\bar T + T\cdot\bar T' = \kappa N\cdot\bar T + \kappa T\cdot\bar N\). \(N'\cdot\bar N + N\cdot\bar N' = -\kappa T\cdot\bar N + \tau B\cdot\bar N - \kappa N\cdot\bar T + \tau N\cdot\bar B\). \(B'\cdot\bar B + B\cdot\bar B' = -\tau N\cdot\bar B - \tau B\cdot\bar N\). 합하면 0.

심화

  1. 평면곡선에 대해 "부호 있는 곡률 \(\kappa(s)\)가 같은 두 단위속력 평면곡선은 회전과 평행이동으로 겹친다"를 \(\theta(s) = \int\kappa\)로 증명하여라.
    답

    \(T = (\cos\theta, \sin\theta)\)이면 \(T' = \theta'(-\sin\theta, \cos\theta)\)라 부호 있는 곡률은 \(\theta'\)이다. 따라서 \(\theta(s) = \theta_0 + \int_0^s\kappa\), \(\beta(s) = \beta(0) + \int_0^s(\cos\theta, \sin\theta)\). 두 곡선의 차이는 \(\theta_0\)(회전)과 \(\beta(0)\)(평행이동)뿐이다.
