가우스 곡률과 평균 곡률

본문
이 절에서 배울 것
  • 가우스 곡률 \(K = \det S = k_1k_2\)와 평균 곡률 \(H = \frac12\mathrm{tr}\,S\)를 정의한다.
  • \(K\)의 부호로 곡면의 모양(타원점, 쌍곡점, 포물점)을 분류한다.
  • 그래프 \(z = f(x, y)\)의 가우스 곡률 공식을 쓴다.
먼저 알아야 할 것
  • 형태 연산자와 주곡률 (4.4절), 제1기본형식 (4.3절).

4.5.1정의

가우스 곡률 \(K = \det S = k_1k_2\), 평균 곡률 \(H = \frac12\mathrm{tr}\,S = \frac12(k_1 + k_2)\).

법벡터를 \(-U\)로 바꾸면 \(S\)가 \(-S\)가 되어 \(H\)는 부호가 바뀌지만 \(K\)는 그대로입니다(2×2 행렬식). 그래서 \(K\)는 곡면 자체의 성질입니다.

  • 반지름 \(r\)인 구면: \(k_1 = k_2 = -\frac1r\), \(K = \frac1{r^2}\).
  • 원기둥: \(k_1 = 0\), \(K = 0\). 평면을 구부려 만들 수 있는 곡면은 \(K = 0\)입니다.
  • \(z = xy\)의 원점: \(k = \pm1\), \(K = -1\).

4.5.2점의 분류

  • \(K > 0\) (타원점): 두 주곡률의 부호가 같아 곡면이 접평면의 한쪽에 놓인다(구면, 달걀).
  • \(K < 0\) (쌍곡점): 접평면을 가로질러 안장 모양.
  • \(K = 0\), \(S \ne 0\) (포물점): 한 방향으로만 휜다(원기둥). \(S = 0\)이면 평면점.

원환면에서 바깥쪽(타이어 바닥)은 타원점, 안쪽(구멍 쪽)은 쌍곡점, 그 경계인 위아래 두 원은 포물점입니다.

4.5.3그래프의 공식

정리 4.5.1

\(z = f(x, y)\)의 가우스 곡률은 \(K = \dfrac{f_{xx}f_{yy} - f_{xy}^2}{(1 + f_x^2 + f_y^2)^2}\)이다.

임계점(\(f_x = f_y = 0\))에서는 4.4절 예제처럼 \(S\)가 헤세 행렬(부호는 법벡터 선택에 따라)이 되므로 \(K = f_{xx}f_{yy} - f_{xy}^2\)입니다. 일반 점의 증명은 좌표조각 \((x, y, f)\)에서 \(S\)를 계산하면 되고, 분모는 기울어진 법벡터의 정규화에서 나옵니다. 수학11의 2계 판정(헤세 행렬식의 부호)과 같은 식이라는 점에 주목하세요. 극대·극소점은 타원점, 안장점은 쌍곡점입니다.

가우스는 \(K\)가 제1기본형식 \(E, F, G\)만으로 계산된다는 것을 증명했습니다(빼어난 정리). 곡면 안에 사는 존재가 길이만 재서 \(K\)를 알 수 있다는 뜻이며, 그래서 구면(\(K > 0\))의 지도를 평면(\(K = 0\))에 길이를 보존하며 그릴 수 없습니다.

흔한 오해(1) 원기둥이 휘었으니 \(K \ne 0\)이라 여긴다: 한 방향의 주곡률이 0이라 \(K = 0\)이다. (2) \(H\)도 법벡터와 무관하다고 여긴다: 부호가 바뀐다. (3) 그래프 공식의 분모를 빠뜨린다: 임계점에서만 분모가 1이다.
요약
  1. \(K = k_1k_2 = \det S\), \(H = \frac12(k_1 + k_2)\).
  2. \(K > 0\) 타원점, \(K < 0\) 쌍곡점, \(K = 0\) 포물점·평면점.
  3. 그래프: \(K = \frac{f_{xx}f_{yy} - f_{xy}^2}{(1 + f_x^2 + f_y^2)^2}\). \(K\)는 \(E, F, G\)로 정해진다(가우스).

4.5.4연습문제

기본

  1. 반지름 3인 구면의 가우스 곡률과 (바깥 법벡터에 대한) 평균 곡률은?
    답

    \(K = \frac19\), \(H = -\frac13\).

응용

  1. \(z = x^2 - y^2\)의 원점과 \((1, 0, 1)\)에서의 \(K\)를 구하여라.
    답

    \(f_{xx} = 2\), \(f_{yy} = -2\), \(f_{xy} = 0\). 원점 \(-4\), \((1, 0)\)에서 \(f_x = 2\)라 \(\frac{-4}{25} = -0.16\).

심화

  1. 원뿔 \(z = \sqrt{x^2 + y^2}\) (\(z > 0\))의 \(K\)는?
    답

    펼치면 평면이 되므로 0. 공식으로도 \(f_{xx}f_{yy} - f_{xy}^2 = \frac{y^2}{r^3}\cdot\frac{x^2}{r^3} - \frac{x^2y^2}{r^6} = 0\).
