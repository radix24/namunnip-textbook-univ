곡선과 프레네 공식 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(\alpha(t) = (3\cos t, 3\sin t, 4t)\)를 호의 길이로 다시 매개화하고 \(\kappa\), \(\tau\)를 구하여라. [02-01]

    힌트 1

    속력 \(\sqrt{9 + 16} = 5\).

    힌트 2

    나선 공식 \(\frac a{a^2 + b^2}\), \(\frac b{a^2 + b^2}\).

    풀이

    \(s = 5t\), \(\beta(s) = (3\cos\frac s5, 3\sin\frac s5, \frac{4s}5)\). \(\kappa = \frac3{25}\), \(\tau = \frac4{25}\) (2.1절).

  2. 계산\(\alpha(t) = (t, t^2/2, t^3/3)\)의 \(t = 1\)에서 \(T, N, B, \kappa, \tau\)를 구하여라. [02-01]

    힌트 1

    \(\alpha' = (1, 1, 1)\), \(\alpha'' = (0, 1, 2)\), \(\alpha''' = (0, 0, 2)\).

    힌트 2

    \(\alpha'\times\alpha'' = (1, -2, 1)\).

    풀이

    \(T = \frac1{\sqrt3}(1, 1, 1)\), \(B = \frac1{\sqrt6}(1, -2, 1)\), \(N = B\times T = \frac1{\sqrt2}(-1, 0, 1)\). \(\kappa = \frac{\sqrt6}{3\sqrt3} = \frac{\sqrt2}3 \approx 0.471\), \(\tau = \frac{(1, -2, 1)\cdot(0, 0, 2)}{6} = \frac13\).

  3. 증명단위속력 곡선에서 \(T\times T' = \kappa B\)와 \(\tau = \frac{\det(\beta', \beta'', \beta''')}{\kappa^2}\)임을 보여라. [02-02]

    힌트 1

    \(\beta'' = \kappa N\).

    힌트 2

    \(\beta''' = -\kappa^2T + \kappa'N + \kappa\tau B\).

    풀이

    \(T\times\kappa N = \kappa B\). \(\det(\beta', \beta'', \beta''') = (\beta'\times\beta'')\cdot\beta''' = \kappa B\cdot(-\kappa^2T + \kappa'N + \kappa\tau B) = \kappa^2\tau\) (2.2절). ∎

  4. 증명단위속력 곡선의 모든 접선이 한 점 \(\mathbf p\)를 지나면 직선임을 보여라. [02-03]

    힌트 1

    \(\beta(s) - \mathbf p = \lambda(s)T(s)\).

    힌트 2

    미분해서 \(N\) 성분을 보라.

    풀이

    미분하면 \(T = \lambda'T + \lambda\kappa N\)이므로 \(\lambda\kappa = 0\), \(\lambda' = 1\). \(\lambda\)는 고립된 점에서만 0일 수 있으므로 \(\kappa = 0\)(연속성으로 모든 곳에서), 따라서 직선이다(정리 2.3.1). ∎

  5. 계산\(\kappa = 2\), \(\tau = 2\)인 단위속력 곡선은 어떤 곡선인가? 접선이 고정된 방향과 이루는 각은? [02-03]

    힌트 1

    정리 2.3.2.

    힌트 2

    \(\cot\theta = \tau/\kappa\).

    풀이

    반지름 \(\frac2{8} = \frac14\), 피치 \(\frac{4\pi}8 = \frac\pi2\)인 원형 나선. \(\cot\theta = 1\)이라 축과 \(45°\)를 이룬다.

  6. 판단"곡률이 어디서나 1인 곡선은 반지름 1인 원이다"는 옳은가? [02-03]

    힌트 1

    열률은?

    힌트 2

    \(a = \frac12\), \(b = \frac12\)인 나선의 곡률.

    풀이

    옳지 않다. \((\frac12\cos t, \frac12\sin t, \frac t2)\)는 \(\kappa = \frac{1/2}{1/2} = 1\)이지만 \(\tau = 1\)인 나선이다. 열률이 0일 때만 원이다.
