곡면 위의 형식과 적분

본문
이 절에서 배울 것
  • 곡면 위의 1-형식, 2-형식을 정의하고 좌표조각으로 당겨 계산한다.
  • 곡면의 방향을 정하고, 2-형식의 적분 \(\iint_M\eta = \iint_D\mathbf x^*\eta\)를 계산한다.
  • 벡터장의 선속 \(\iint_M\mathbf F\cdot U\,dA\)가 2-형식 \(\eta_{\mathbf F}\)의 적분임을 확인한다.
먼저 알아야 할 것
  • 외곱과 당김 (1.2절), 제1기본형식과 넓이 (4.3절).

5.1.1곡면 위의 형식

곡면 \(M\) 위의 1-형식은 각 점의 접평면 \(T_{\mathbf p}M\)에서 정의된 선형함수이고, 2-형식은 \(T_{\mathbf p}M\)의 두 벡터를 받는 교대 쌍선형함수입니다. 접평면이 2차원이므로 \(M\) 위의 3-형식 이상은 모두 0입니다. \(\mathbb R^3\)의 형식을 접벡터에만 작용시키면(제한하면) \(M\) 위의 형식이 되고, 좌표조각 \(\mathbf x: D \to M\)으로 당기면 \(D\) 위의 형식이 됩니다.

예를 들어 \(M\) 위의 2-형식 \(\eta\)를 \(\mathbf x\)로 당기면 \(\mathbf x^*\eta = \eta(\mathbf x_u, \mathbf x_v)\,du\wedge dv\)입니다. 1.2절의 "좌표 대입" 규칙으로 계산해도 같은 결과가 나옵니다.

5.1.2방향

방향(orientation): 곡면 전체에서 연속인 단위법벡터장 \(U\)를 하나 고르는 것. 그런 \(U\)가 있으면 방향 가능하다고 한다.

좌표조각 \(\mathbf x\)가 방향과 맞는다는 것은 \(\frac{\mathbf x_u\times\mathbf x_v}{|\mathbf x_u\times\mathbf x_v|} = U\)라는 뜻입니다. 구면, 원환면, 음함수 꼴 곡면(\(U = \nabla g/|\nabla g|\))은 방향 가능하고, 뫼비우스 띠는 그렇지 않습니다(6.1절).

5.1.32-형식의 적분

정의 5.1.1

방향이 있는 곡면 \(M\)이 방향과 맞는 하나의 좌표조각 \(\mathbf x: D \to M\)으로 (측도 0인 집합을 빼고) 덮일 때, \(\displaystyle\iint_M\eta = \iint_D\eta(\mathbf x_u, \mathbf x_v)\,du\,dv\).

방향과 맞는 다른 좌표조각을 쓰면 변수변환 공식의 야코비 행렬식이 양수라 같은 값이 나오고, 방향을 뒤집으면 부호가 바뀝니다. 여러 조각이 필요하면 1의 분할로 나누어 더합니다.

  • 넓이 형식 \(dA\): \(dA(\mathbf v, \mathbf w) = U\cdot(\mathbf v\times\mathbf w)\). 당기면 \(|\mathbf x_u\times\mathbf x_v|\,du\wedge dv = \sqrt{EG - F^2}\,du\wedge dv\)이고 그 적분이 4.3절의 넓이이다.
  • 선속: 벡터장 \(\mathbf F\)의 2-형식 \(\eta_{\mathbf F} = F_1dy\wedge dz + F_2dz\wedge dx + F_3dx\wedge dy\) (1.3절)에 대해 \(\eta_{\mathbf F}(\mathbf v, \mathbf w) = \mathbf F\cdot(\mathbf v\times\mathbf w)\)이므로
\[\iint_M\eta_{\mathbf F} = \iint_D\mathbf F(\mathbf x)\cdot(\mathbf x_u\times\mathbf x_v)\,du\,dv = \iint_M\mathbf F\cdot U\,dA.\]

5.1.4예

예제 5.1.2

바깥쪽 방향의 단위구면에서 \(\mathbf F = (x, y, z)\)의 선속과, 위쪽 방향의 위 반구에서 \(\mathbf F = (0, 0, z)\)의 선속을 구하여라.

풀이. 단위구면에서 \(U = (x, y, z)\)이므로 \(\mathbf F\cdot U = 1\), 선속은 넓이 \(4\pi\)입니다. 반구는 \(\mathbf x(\varphi, \theta) = (\sin\varphi\cos\theta, \sin\varphi\sin\theta, \cos\varphi)\) (\(0 \le \varphi \le \frac\pi2\))로 덮이고 \(\mathbf x_\varphi\times\mathbf x_\theta = \sin\varphi\,\mathbf x\) (바깥쪽)이므로 \(\mathbf F\cdot(\mathbf x_\varphi\times\mathbf x_\theta) = \cos^2\varphi\sin\varphi\). 선속 \(\int_0^{2\pi}\int_0^{\pi/2}\cos^2\varphi\sin\varphi\,d\varphi\,d\theta = 2\pi\cdot\frac13 = \frac{2\pi}3 \approx 2.094\)입니다.

1-형식의 적분은 곡면 위의 곡선으로 당겨 선적분으로 계산합니다. 같은 절의 예제 카드에서 곡면 위의 2-형식을 직접 당겨 적분해 봅니다.

흔한 오해(1) 2-형식의 적분과 함수의 넓이 적분(\(\iint f\,dA\))을 혼동한다. 2-형식의 적분은 방향에 따라 부호가 바뀌지만 \(\iint f\,dA\)는 그렇지 않다. (2) 좌표조각이 방향과 맞는지(\(\mathbf x_u\times\mathbf x_v\)가 \(U\) 쪽인지) 확인하지 않는다.
요약
  1. 곡면 위의 형식은 접평면에서의 교대 다중선형함수. 좌표조각으로 당기면 \(\mathbf x^*\eta = \eta(\mathbf x_u, \mathbf x_v)\,du\wedge dv\).
  2. 방향 = 연속인 단위법벡터장. 방향과 맞는 조각으로 \(\iint_M\eta = \iint_D\eta(\mathbf x_u, \mathbf x_v)\,du\,dv\).
  3. 선속 \(\iint\mathbf F\cdot U\,dA = \iint_M\eta_{\mathbf F}\). 넓이는 \(dA\)의 적분.

5.1.5연습문제

기본

  1. 평면 \(z = 0\)의 단위원판(위쪽 방향)에서 \(\eta = x\,dy\wedge dz + z\,dx\wedge dy\)의 적분을 구하여라.
    답

    \(\mathbf x(u, v) = (u, v, 0)\)이면 \(dz\)가 0으로 당겨지고 \(z = 0\)이라 \(\mathbf x^*\eta = 0\). 적분 0.

응용

  1. 원기둥 \(x^2 + y^2 = 1\), \(0 \le z \le 2\) (바깥쪽)에서 \(\mathbf F = (x, y, 0)\)의 선속을 구하여라.
    답

    바깥쪽 \(U = (x, y, 0)\), \(\mathbf F\cdot U = 1\). 선속은 옆면의 넓이 \(2\pi\cdot2 = 4\pi\).

심화

  1. 방향과 맞는 두 좌표조각 \(\mathbf x\), \(\mathbf y = \mathbf x\circ\phi\) (\(\det\phi' > 0\))로 계산한 \(\iint\eta\)가 같음을 보여라.
    답

    \(\mathbf y^*\eta = \phi^*(\mathbf x^*\eta)\)이고 \(\phi^*(a\,du\wedge dv) = (a\circ\phi)\det\phi'\,ds\wedge dt\). 수학11의 변수변환 공식(\(|\det\phi'| = \det\phi'\))으로 두 적분이 같다.
