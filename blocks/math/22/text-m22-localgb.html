국소 가우스-보네 정리와 측지 삼각형

본문
이 절에서 배울 것
  • 단순 영역에서 \(\iint_RK\,dM + \oint\kappa_g\,ds + \sum\varepsilon_i = 2\pi\)를 진술하고 스토크스 정리로 증명한다.
  • 측지 삼각형의 내각 합이 \(\pi + \iint K\,dM\)임을 유도한다.
  • 구, 평면, 쌍곡면에서 삼각형의 내각 합을 비교한다.
먼저 알아야 할 것
  • 측지 곡률 (4.1절), 가우스 방정식 \(d\omega_{12} = -K\theta_1\wedge\theta_2\) (3.3절), 스토크스 정리 (수학13 5장).

5.2.1정리

곡면 위 영역 \(R\)이 원판과 위상동형이고 경계가 조각마다 매끄러운 닫힌 곡선(양의 방향)이라 합니다. 꺾이는 점에서 진행 방향이 돌아가는 각(외각)을 \(\varepsilon_i\)라 합니다.

정리 5.2.1 (국소 가우스-보네) \[\iint_RK\,dM + \oint_{\partial R}\kappa_g\,ds + \sum_i\varepsilon_i = 2\pi.\]
증명

\(R\) 위에 틀장 \(E_1, E_2\)를 잡는다. 4.1절에서 \(\kappa_g = \frac{d\phi}{ds} + \omega_{12}(T)\) (\(\phi\)는 \(T\)와 \(E_1\)의 각)이므로 \(\oint\kappa_g\,ds = \oint d\phi + \oint\omega_{12}\). 경계를 한 바퀴 돌 때 접벡터는 매끄러운 부분에서 \(\oint d\phi\), 꼭짓점에서 \(\varepsilon_i\)만큼 돌아 합이 \(2\pi\)이다(회전 지수 정리). 스토크스와 가우스 방정식으로 \(\oint\omega_{12} = \iint d\omega_{12} = -\iint K\,dM\). 합치면 된다. ∎

평면(\(K = 0\))에서는 "닫힌 곡선을 한 바퀴 돌면 방향이 \(2\pi\) 돈다"는 사실입니다. 곡면에서는 곡률이 그 일부를 대신 맡습니다.

5.2.2측지 삼각형

세 변이 측지선인 삼각형은 \(\kappa_g = 0\)이고 외각 \(\varepsilon_i = \pi - \alpha_i\) (\(\alpha_i\)는 내각)이므로

\[\alpha_1 + \alpha_2 + \alpha_3 = \pi + \iint_TK\,dM.\]
예 5.2.2 반지름 \(r\)인 구에서 북극과 적도 위 경도 0°, 90°의 점이 만드는 삼각형은 세 각이 모두 직각입니다. 넓이는 구의 \(\frac18\)인 \(\frac{\pi r^2}2\)이고 \(\iint K\,dM = \frac1{r^2}\cdot\frac{\pi r^2}2 = \frac\pi2\). 내각 합 \(\frac{3\pi}2 = \pi + \frac\pi2\)로 맞습니다.
  • \(K > 0\) (구): 내각 합 \(> \pi\), 초과량 = 넓이 × \(K\).
  • \(K = 0\) (평면, 원기둥): 내각 합 \(= \pi\).
  • \(K < 0\) (안장, 쌍곡평면): 내각 합 \(< \pi\).

가우스는 세 산꼭대기 사이의 삼각형을 측량해 공간의 곡률을 확인하려 했다고 전해집니다. 지구 표면의 큰 삼각형은 실제로 내각 합이 \(\pi\)를 넘고, 그 초과량으로 지구 반지름을 잴 수 있습니다.

흔한 오해(1) 외각 대신 내각을 더한다. 공식은 꺾이는 각(외각) \(\pi - \alpha_i\)의 합이다. (2) 측지선이 아닌 변에도 내각 합 공식을 그대로 쓴다. 그때는 \(\oint\kappa_g\) 항이 남는다.
요약
  1. \(\iint K + \oint\kappa_g + \sum\varepsilon_i = 2\pi\) (원판 모양 영역).
  2. 증명: \(\kappa_g = \phi' + \omega_{12}(T)\), 스토크스, \(d\omega_{12} = -K\,dM\).
  3. 측지 삼각형: 내각 합 \(= \pi + \iint K\,dM\).

5.2.3연습문제

기본

  1. 반지름 1인 구에서 내각이 모두 \(\frac{2\pi}3\)인 측지 삼각형의 넓이를 구하여라.
    답

    \(2\pi - \pi = \pi\).

응용

  1. 반지름 \(r\)인 구에서 북위 \(\varphi_0\) 이북의 극관(\(R\))에 국소 가우스-보네를 적용해, 경계 위선의 \(\kappa_g\)를 확인하여라.
    답

    \(\iint K = \frac1{r^2}\cdot2\pi r^2(1 - \sin\varphi_0) = 2\pi(1 - \sin\varphi_0)\). 경계 길이 \(2\pi r\cos\varphi_0\), 꼭짓점 없음. \(\kappa_g\cdot2\pi r\cos\varphi_0 = 2\pi\sin\varphi_0\)에서 \(\kappa_g = \frac{\tan\varphi_0}r\) (4.1절과 같음).

심화

  1. \(K < 0\)인 곡면에서는 두 측지선이 두 번 만나 만드는 "측지 이각형"(꼭짓점 2개, 변 2개인 원판 영역)이 있을 수 없음을 보여라.
    답

    내각 \(\alpha, \beta \in (0, \pi)\)라 외각 합 \(2\pi - \alpha - \beta\). 가우스-보네로 \(\iint K = \alpha + \beta > 0\)인데 \(K < 0\)이면 좌변이 음수라 모순.
