카르탕 구조방정식

본문

틀장에는 성분을 읽는 쌍대 1-형식 \(\theta_i\)와 틀이 기우는 비율인 접속형식 \(\omega_{ij}\)가 있다. 이 두 종류의 형식은 서로 아무렇게나 정해질 수 있을까, 아니면 외미분으로 이어지는 관계식이 있을까? 있다면 그 관계식은 공간에 대해 무엇을 말해 줄까?

먼저 알아야 할 것외미분과 외곱(수학13 1장), 쌍대 1-형식과 접속형식(1.2절, 1.3절)을 쓴다.

1.4.1정리

정리 1.4.1 (카르탕 구조방정식)

\(\mathbb R^3\)의 틀장의 쌍대 1-형식 \(\theta_i\)와 접속형식 \(\omega_{ij}\)는 다음을 만족한다. 행렬로 쓰면 \(d\theta = \omega\wedge\theta\), \(d\omega = \omega\wedge\omega\)이다.

\[d\theta_i = \sum_j\omega_{ij}\wedge\theta_j, \qquad d\omega_{ij} = \sum_k\omega_{ik}\wedge\omega_{kj}\]

증명.1.2절과 1.3절에서 \(\theta = A\,d\xi\), \(\omega = dA\,A^T\)이다. \(d(d\xi) = 0\)이므로 \(d\theta = dA\wedge d\xi\)이고, 여기에 \(A^TA = I\)를 끼우면 \(dA\wedge d\xi = dA\,A^T\wedge A\,d\xi = \omega\wedge\theta\)이다. 둘째로, \(d(dA) = 0\)이고 1-형식을 앞으로 넘기면 부호가 바뀌므로 \(d\omega = d(dA\,A^T) = -dA\wedge dA^T\)이다. 다시 \(A^TA = I\)를 끼우면 \(-dA\,A^T\wedge A\,dA^T = -\omega\wedge\omega^T\)이고, \(\omega\)가 반대칭이라 \(\omega^T = -\omega\)이므로 \(d\omega = \omega\wedge\omega\)이다. ∎

사실 \(\mathbb R^3\)이 평평하다는 사실이 둘째 방정식에 담겨 있다. 그런데 곡면으로 내려가면 이 방정식들이 곡면의 가우스 곡률과 코다치 방정식을 내놓으며, 이는 3.3절과 3.4절에서 본다.

1.4.2확인

예제 1.4.2

원기둥 틀장에서 \(\theta_1 = dr\), \(\theta_2 = r\,d\vartheta\), \(\theta_3 = dz\), \(\omega_{12} = d\vartheta\)이고 나머지 접속형식은 0이다. 구조방정식을 확인하여라.

풀이. 먼저 \(d\theta_1 = 0\)이고, 우변은 \(\omega_{12}\wedge\theta_2 = d\vartheta\wedge r\,d\vartheta = 0\)이다. 다음으로 \(d\theta_2 = dr\wedge d\vartheta\)이고, 우변은 \(\omega_{21}\wedge\theta_1 = -d\vartheta\wedge dr = dr\wedge d\vartheta\)이다. 끝으로 \(d\omega_{12} = 0\)이고 우변 \(\omega_{13}\wedge\omega_{32}\)도 0이다. 즉 둘째 식은 그림 1의 바깥 호와 안쪽 호의 길이 차를 그대로 적은 것이다.

구면 틀장에서도 확인할 수 있다. 가령 \(d\omega_{12} = d(\cos\varphi\,d\vartheta) = -\sin\varphi\,d\varphi\wedge d\vartheta\)이고, \(\omega_{13}\wedge\omega_{32} = d\varphi\wedge(-\sin\varphi\,d\vartheta)\)로 같다.

1.4.3의미

첫째 방정식은 접속형식이 쌍대 형식만으로 정해진다는 뜻이기도 하다. \(\theta_i\)를 알면 \(d\theta_i\)를 계산해 \(\omega_{ij}\)를 거꾸로 풀 수 있기 때문이다. 곡면에서는 \(\theta_1, \theta_2\)가 제1기본형식만으로 정해지므로, 이 방법으로 구한 \(\omega_{12}\)와 \(d\omega_{12}\)는 내재적이다. 이것이 3.3절에서 볼 가우스의 경이 정리의 증명이다.

흔한 오해\(d\omega = \omega\wedge\omega\)의 \(\omega\wedge\omega\)를 1-형식과 자기 자신의 외곱으로 보고 0이라고 여기기 쉽지만, 이것은 행렬의 곱이라 \((i, j)\) 성분이 \(\sum_k\omega_{ik}\wedge\omega_{kj}\)로 서로 다른 형식의 외곱이다. 또 외미분할 때 \(dA\wedge A^T\)의 순서를 마음대로 바꿔도 된다고 생각하는 것도 틀렸다. 1-형식끼리는 순서를 바꾸면 부호가 바뀐다.
마무리

처음 질문에 답하면, 두 종류의 형식은 아무렇게나 정해지지 않고 카르탕 구조방정식 \(d\theta = \omega\wedge\theta\), \(d\omega = \omega\wedge\omega\)로 묶여 있다. 첫째 식에 의해 접속형식은 쌍대 형식만으로 정해지고, 둘째 식은 \(\mathbb R^3\)이 평평하다는 사실을 담는다. 곡면으로 내려가면 이 식들이 가우스 곡률과 경이 정리를 내놓는다.

1.4.4연습문제

기본

  1. 원기둥 틀장에서 \(d\theta_3 = \sum_j\omega_{3j}\wedge\theta_j\)를 확인하여라.
    답

    \(d\theta_3 = d(dz) = 0\), \(\omega_{31} = \omega_{32} = 0\)이라 우변도 0.

응용

  1. 구면 틀장에서 \(d\theta_3 = d(\rho\,d\varphi)\)를 구조방정식의 우변 \(\omega_{31}\wedge\theta_1 + \omega_{32}\wedge\theta_2\)와 비교하여라.
    답

    좌변 \(d\rho\wedge d\varphi\). 우변 \(-d\varphi\wedge d\rho + (-\sin\varphi\,d\vartheta)\wedge\rho\cos\varphi\,d\vartheta = d\rho\wedge d\varphi + 0\).

심화

  1. 평면의 극좌표 틀 \(E_1 = (\cos\vartheta, \sin\vartheta)\), \(E_2 = (-\sin\vartheta, \cos\vartheta)\)에서 \(\theta_1 = dr\), \(\theta_2 = r\,d\vartheta\)만으로 첫째 구조방정식을 풀어 \(\omega_{12}\)를 구하여라.
    답

    \(d\theta_1 = 0 = \omega_{12}\wedge r\,d\vartheta\), \(d\theta_2 = dr\wedge d\vartheta = \omega_{21}\wedge dr\). \(\omega_{12} = f\,dr + g\,d\vartheta\)로 두면 첫 식에서 \(f = 0\), 둘째에서 \(-g\,d\vartheta\wedge dr = g\,dr\wedge d\vartheta\)라 \(g = 1\). \(\omega_{12} = d\vartheta\).
