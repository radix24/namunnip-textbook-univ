카르탕 구조방정식

본문
이 절에서 배울 것
  • 첫째 구조방정식 \(d\theta_i = \sum_j\omega_{ij}\wedge\theta_j\)와 둘째 구조방정식 \(d\omega_{ij} = \sum_k\omega_{ik}\wedge\omega_{kj}\)를 유도한다.
  • 원기둥 틀장에서 두 방정식을 확인한다.
  • 구조방정식이 곡면의 곡률 이론(2~3장)의 출발점이 됨을 안다.
먼저 알아야 할 것
  • 외미분과 외곱 (수학13 1장), 쌍대 1-형식과 접속형식 (1.2절, 1.3절).

1.4.1정리

정리 1.4.1 (카르탕 구조방정식) \(\mathbb R^3\)의 틀장의 쌍대 1-형식 \(\theta_i\)와 접속형식 \(\omega_{ij}\)는 \[d\theta_i = \sum_j\omega_{ij}\wedge\theta_j, \qquad d\omega_{ij} = \sum_k\omega_{ik}\wedge\omega_{kj}\] 를 만족한다. 행렬로 쓰면 \(d\theta = \omega\wedge\theta\), \(d\omega = \omega\wedge\omega\).
증명

\(\theta = A\,d\xi\), \(\omega = dA\,A^T\)이다(1.2절, 1.3절). \(d(d\xi) = 0\)이라 \(d\theta = dA\wedge d\xi\). \(A^TA = I\)를 끼우면 \(dA\wedge d\xi = dA\,A^T\wedge A\,d\xi = \omega\wedge\theta\).

둘째: \(d\omega = d(dA\,A^T) = -dA\wedge dA^T\) (\(d(dA) = 0\)이고 1-형식을 앞으로 넘기며 부호가 바뀜). 다시 \(A^TA = I\)를 끼우면 \(-dA\,A^T\wedge A\,dA^T = -\omega\wedge\omega^T\). \(\omega\)가 반대칭이라 \(\omega^T = -\omega\)이므로 \(d\omega = \omega\wedge\omega\). ∎

\(\mathbb R^3\)이 평평하다는 사실이 둘째 방정식에 담겨 있습니다. 곡면으로 내려가면 이 방정식들이 곡면의 가우스 곡률과 코다치 방정식을 내놓습니다(3.3~3.4절).

1.4.2확인

예 1.4.2 (원기둥 틀장) \(\theta_1 = dr\), \(\theta_2 = r\,d\vartheta\), \(\theta_3 = dz\), \(\omega_{12} = d\vartheta\), 나머지 0.
  • \(d\theta_1 = 0\), 우변 \(\omega_{12}\wedge\theta_2 = d\vartheta\wedge r\,d\vartheta = 0\).
  • \(d\theta_2 = dr\wedge d\vartheta\), 우변 \(\omega_{21}\wedge\theta_1 = -d\vartheta\wedge dr = dr\wedge d\vartheta\).
  • \(d\omega_{12} = 0\), 우변 \(\omega_{13}\wedge\omega_{32} = 0\).

구면 틀장에서도 확인할 수 있습니다. 예를 들어 \(d\omega_{12} = d(\cos\varphi\,d\vartheta) = -\sin\varphi\,d\varphi\wedge d\vartheta\)이고 \(\omega_{13}\wedge\omega_{32} = d\varphi\wedge(-\sin\varphi\,d\vartheta)\)로 같습니다.

1.4.3의미

첫째 방정식은 접속형식이 쌍대 형식만으로 정해진다는 뜻이기도 합니다. \(\theta_i\)를 알면 \(d\theta_i\)를 계산해 \(\omega_{ij}\)를 거꾸로 풀 수 있습니다. 곡면에서는 \(\theta_1, \theta_2\)가 제1기본형식만으로 정해지므로, 이 방법으로 구한 \(\omega_{12}\)와 \(d\omega_{12}\)가 내재적입니다. 이것이 가우스의 경이 정리의 증명입니다(3.3절).

흔한 오해(1) \(d\omega = \omega\wedge\omega\)에서 \(\omega\wedge\omega\)가 1-형식의 자기 자신과의 외곱이라 0이라 여긴다. 행렬의 곱이라 \((i, j)\) 성분은 \(\sum_k\omega_{ik}\wedge\omega_{kj}\)로 서로 다른 형식의 외곱이다. (2) 외미분할 때 \(dA\wedge A^T\)의 순서를 마음대로 바꾼다. 1-형식끼리는 순서를 바꾸면 부호가 바뀐다.
요약
  1. \(d\theta = \omega\wedge\theta\), \(d\omega = \omega\wedge\omega\).
  2. 증명은 \(\theta = A\,d\xi\), \(\omega = dA\,A^T\)와 \(A^TA = I\).
  3. 첫째 방정식으로 \(\theta\)에서 \(\omega\)를 결정, 곡면 이론의 출발점.

1.4.4연습문제

기본

  1. 원기둥 틀장에서 \(d\theta_3 = \sum_j\omega_{3j}\wedge\theta_j\)를 확인하여라.
    답

    \(d\theta_3 = d(dz) = 0\), \(\omega_{31} = \omega_{32} = 0\)이라 우변도 0.

응용

  1. 구면 틀장에서 \(d\theta_3 = d(\rho\,d\varphi)\)를 구조방정식의 우변 \(\omega_{31}\wedge\theta_1 + \omega_{32}\wedge\theta_2\)와 비교하여라.
    답

    좌변 \(d\rho\wedge d\varphi\). 우변 \(-d\varphi\wedge d\rho + (-\sin\varphi\,d\vartheta)\wedge\rho\cos\varphi\,d\vartheta = d\rho\wedge d\varphi + 0\).

심화

  1. 평면의 극좌표 틀 \(E_1 = (\cos\vartheta, \sin\vartheta)\), \(E_2 = (-\sin\vartheta, \cos\vartheta)\)에서 \(\theta_1 = dr\), \(\theta_2 = r\,d\vartheta\)만으로 첫째 구조방정식을 풀어 \(\omega_{12}\)를 구하여라.
    답

    \(d\theta_1 = 0 = \omega_{12}\wedge r\,d\vartheta\), \(d\theta_2 = dr\wedge d\vartheta = \omega_{21}\wedge dr\). \(\omega_{12} = f\,dr + g\,d\vartheta\)로 두면 첫 식에서 \(f = 0\), 둘째에서 \(-g\,d\vartheta\wedge dr = g\,dr\wedge d\vartheta\)라 \(g = 1\). \(\omega_{12} = d\vartheta\).
