회전면의 전곡률은 끝의 기울기만으로

예제 · 전곡률 적분

먼저 예측

회전면 조각의 전곡률은 가운데 모양이 어떻든 위아래 테두리에서 곡면이 어떤 각도로 끝나는지만으로 정해질까?

예측 확인

그렇다. \(2\pi(h'(a) - h'(b))\)이다.

단위 속력 단면 \((h(s), g(s))\), \(a \le s \le b\)인 회전면 조각의 전곡률이 \(2\pi\big(h'(a) - h'(b)\big)\)임을 보이고, 구, 원기둥 조각, 원환면에 적용하여라.

전략

\(K = -\frac{h''}h\), \(dM = h\,ds\,dv\) (2.5절, 5.1절). 곱하면 \(h\)가 지워진다.

풀이

  1. \(\iint K\,dM = \int_0^{2\pi}\int_a^b(-h'')\,ds\,dv = 2\pi\big(h'(a) - h'(b)\big)\).
    미적분학의 기본정리.
  2. 구(\(h = \cos s\), \(-\frac\pi2 \le s \le \frac\pi2\)): \(h' = -\sin s\), \(2\pi(1 - (-1)) = 4\pi\).
    5.1절과 같음.
  3. 원기둥 조각(\(h = r\)): \(h' = 0\)이라 0.
    \(K = 0\).
  4. 원환면(\(h = R + r\cos\frac sr\), 한 바퀴 \(0 \le s \le 2\pi r\)): \(h'(0) = h'(2\pi r) = 0\)이라 0.
    처음과 끝이 같은 점.

검산

\(h'\)은 단면의 접선이 축과 이루는 기울기(\(-1 \le h' \le 1\))이다. 북반구만 보면 \(h'(0) = 0\), \(h'(\frac\pi2) = -1\)이라 \(2\pi\)로 구 전체의 절반이다.

의미

영역 안의 곡률을 모두 더한 값이 경계에서의 정보(테두리의 기울기, 즉 경계 위선의 측지 곡률)로 정해진다. 이것이 국소 가우스-보네 정리(5.2절)의 특수한 경우이다. 위아래가 모두 축에 닫히는 곡면(\(h' = \pm1\)로 끝남)은 늘 \(4\pi\)이다.

이해 확인

원환면의 바깥쪽 반(\(-\frac\pi2 \le \frac sr \le \frac\pi2\))의 전곡률을 공식으로 구하여라.

답

\(h' = -\sin\frac sr\): \(2\pi(1 - (-1)) = 4\pi\).
