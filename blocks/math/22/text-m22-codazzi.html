가우스 방정식과 코다치 방정식

본문
이 절에서 배울 것
  • 적응 틀장의 구조방정식에서 가우스 방정식과 두 코다치 방정식을 얻는다.
  • 곡률선 좌표(\(F = m = 0\))에서 코다치 방정식을 쓰고 구에서 확인한다.
  • 제1·제2기본형식이 곡면을 결정한다는 보네 정리의 내용을 안다.
먼저 알아야 할 것
  • 경이 정리의 계산 (3.3절), 제2기본형식 \(l, m, n\) (2.2절).

3.4.1세 방정식

적응 틀장(\(E_3 = U\))의 둘째 구조방정식 \(d\omega_{ij} = \sum_k\omega_{ik}\wedge\omega_{kj}\)을 곡면에 제한하면 독립인 식이 셋입니다.

정리 3.4.1 (곡면의 기본방정식) \[d\omega_{12} = \omega_{13}\wedge\omega_{32}\ (\text{Gauss}), \qquad d\omega_{13} = \omega_{12}\wedge\omega_{23}, \quad d\omega_{23} = \omega_{21}\wedge\omega_{13}\ (\text{Codazzi}).\]

가우스 방정식은 3.3절의 \(d\omega_{12} = -K\theta_1\wedge\theta_2\)입니다. 코다치 방정식은 모양연산자(\(\omega_{13}, \omega_{23}\))가 곡면 위에서 어떻게 변할 수 있는지에 대한 제약입니다. 아무 \(S\)나 곡면의 모양연산자가 될 수는 없습니다.

3.4.2곡률선 좌표에서

좌표 곡선이 주방향을 따라가면(\(F = m = 0\)) 주곡률이 \(k_1 = \frac lE\), \(k_2 = \frac nG\)이고 코다치 방정식은

\[l_v = \frac{E_v}2\left(\frac lE + \frac nG\right), \qquad n_u = \frac{G_u}2\left(\frac lE + \frac nG\right).\]
예 3.4.2 반지름 \(r\)인 구, 위도·경도 좌표, 안쪽 법선: \(E = r^2\), \(G = r^2\cos^2u\), \(l = r\), \(n = r\cos^2u\) (\(\frac lE = \frac nG = \frac1r\)). 첫 식은 양변 0. 둘째 식: \(n_u = -2r\cos u\sin u\), 우변 \(\frac{-2r^2\cos u\sin u}2\cdot\frac2r = -2r\cos u\sin u\). 성립합니다.

이 식에서 배꼽점 정리(2.5절)가 나옵니다. 모든 점이 배꼽점이면 \(l = kE\), \(n = kG\)이고, 첫 식에 넣으면 \(k_vE + kE_v = \frac{E_v}2\cdot2k\), 즉 \(k_v = 0\). 마찬가지로 \(k_u = 0\)이라 \(k\)는 상수입니다.

3.4.3보네 정리

정리 3.4.3 (보네) 단순연결 영역에서 \(E, F, G\) (양의 정부호)와 \(l, m, n\)이 가우스 방정식과 코다치 방정식을 만족하면, 이를 제1·제2기본형식으로 가지는 곡면이 존재하고, 강체 운동을 빼면 유일하다.

곡선에서 곡률과 열률이 곡선을 결정했듯이(수학13), 곡면에서는 두 기본형식이 곡면을 결정합니다. 다만 곡선과 달리 두 형식을 아무렇게나 줄 수는 없고, 가우스·코다치라는 적분 가능 조건을 만족해야 합니다.

흔한 오해(1) 제1기본형식만 같으면 곡면이 합동이라 여긴다. 원기둥과 평면처럼 제2기본형식이 다르면 합동이 아니다. (2) 가우스 방정식과 코다치 방정식이 독립된 우연한 관계라 여긴다. 모두 \(\mathbb R^3\)이 평평하다는 \(d\omega = \omega\wedge\omega\)의 성분이다.
요약
  1. 가우스: \(d\omega_{12} = \omega_{13}\wedge\omega_{32}\). 코다치: \(d\omega_{13} = \omega_{12}\wedge\omega_{23}\), \(d\omega_{23} = \omega_{21}\wedge\omega_{13}\).
  2. 곡률선 좌표: \(l_v = \frac{E_v}2(\frac lE + \frac nG)\), \(n_u = \frac{G_u}2(\frac lE + \frac nG)\).
  3. 보네: 두 기본형식이 방정식을 만족하면 곡면이 유일하게 존재.

3.4.4연습문제

기본

  1. 원기둥 \((r\cos u, r\sin u, v)\) (안쪽 법선, \(E = r^2\), \(G = 1\), \(l = r\), \(n = 0\))에서 코다치 방정식을 확인하여라.
    답

    모든 계수가 상수라 \(l_v = n_u = 0\), \(E_v = G_u = 0\). 성립.

응용

  1. \(E = G = 1\), \(F = 0\), \(l = 1\), \(m = 0\), \(n = 1\)을 기본형식으로 가지는 곡면이 있는가?
    답

    코다치는 성립(모두 상수)하지만 가우스 방정식에서 \(K = \frac{ln}{EG} = 1\)인데 \(E = G = 1\)이면 내재적 \(K = 0\). 모순이라 없다.

심화

  1. 본문의 배꼽점 논증에서 \(k_v = 0\)을 유도하는 계산을 자세히 써라.
    답

    \(l = kE\)이라 \(l_v = k_vE + kE_v\). 우변 \(\frac{E_v}2(k + k) = kE_v\). 같으려면 \(k_vE = 0\), \(E > 0\)이라 \(k_v = 0\).
