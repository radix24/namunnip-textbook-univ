가우스 방정식과 코다치 방정식

본문

곡선은 곡률과 열률을 아무렇게나 주어도 그런 곡선이 존재했다. 곡면에서도 제1기본형식과 제2기본형식을 아무렇게나 주면 그런 곡면이 있을까? 아니라면 두 형식이 만족해야 하는 조건은 무엇이고, 그 조건에서 무엇을 끌어낼 수 있을까?

먼저 알아야 할 것경이 정리의 계산(3.3절), 제2기본형식 \(l, m, n\)(2.2절)을 쓴다.

3.4.1세 방정식

적응 틀장(\(E_3 = U\))의 둘째 구조방정식 \(d\omega_{ij} = \sum_k\omega_{ik}\wedge\omega_{kj}\)를 곡면에 제한하면 서로 독립인 식이 셋 나온다.

정리 3.4.1 (곡면의 기본방정식)

첫째 식을 가우스 방정식, 나머지 두 식을 코다치 방정식이라 한다.

\[d\omega_{12} = \omega_{13}\wedge\omega_{32}, \qquad d\omega_{13} = \omega_{12}\wedge\omega_{23}, \qquad d\omega_{23} = \omega_{21}\wedge\omega_{13}\]

가우스 방정식은 3.3절의 \(d\omega_{12} = -K\theta_1\wedge\theta_2\)이다. 반면 코다치 방정식은 모양연산자를 이루는 \(\omega_{13}, \omega_{23}\)이 곡면 위에서 어떻게 변할 수 있는지에 대한 제약이다. 즉 아무 \(S\)나 곡면의 모양연산자가 될 수는 없다.

3.4.2곡률선 좌표에서

좌표 곡선이 주방향을 따라가면 \(F = m = 0\)이고, 주곡률은 \(k_1 = \frac lE\), \(k_2 = \frac nG\)이다. 이때 코다치 방정식은 다음과 같다.

\[l_v = \frac{E_v}2\left(\frac lE + \frac nG\right), \qquad n_u = \frac{G_u}2\left(\frac lE + \frac nG\right)\]
예제 3.4.2

반지름 \(r\)인 구를 위도·경도 좌표로 두고 안쪽 법선을 줄 때 코다치 방정식을 확인하여라.

풀이. \(E = r^2\), \(G = r^2\cos^2u\), \(l = r\), \(n = r\cos^2u\)이고 \(\frac lE = \frac nG = \frac1r\)이다. 첫 식은 양변이 모두 0이다. 둘째 식의 좌변은 \(n_u = -2r\cos u\sin u\)이고, 우변은 \(\frac{-2r^2\cos u\sin u}2\cdot\frac2r = -2r\cos u\sin u\)이므로 성립한다.

이 식에서 2.5절의 배꼽점 정리가 나온다. 모든 점이 배꼽점이면 \(l = kE\), \(n = kG\)이고, 이를 첫 식에 넣으면 \(k_vE + kE_v = \frac{E_v}2\cdot2k\), 즉 \(k_v = 0\)이다. 마찬가지로 \(k_u = 0\)이므로 \(k\)는 상수이다.

3.4.3보네 정리

정리 3.4.3 (보네)

단순연결 영역에서 양의 정부호인 \(E, F, G\)와 \(l, m, n\)이 가우스 방정식과 코다치 방정식을 만족하면, 이를 제1, 제2기본형식으로 가지는 곡면이 존재하고 강체 운동을 빼면 유일하다.

곡선에서 곡률과 열률이 곡선을 결정했듯이, 곡면에서는 두 기본형식이 곡면을 결정한다. 다만 곡선과 달리 두 형식을 아무렇게나 줄 수는 없으며, 가우스 방정식과 코다치 방정식이라는 적분 가능 조건을 만족해야 한다.

흔한 오해제1기본형식만 같으면 곡면이 합동이라고 여기기 쉽지만, 원기둥과 평면처럼 제2기본형식이 다르면 합동이 아니다. 또 가우스 방정식과 코다치 방정식이 서로 상관없이 우연히 성립하는 관계라고 생각하는 것도 틀렸다. 이들은 모두 \(\mathbb R^3\)이 평평하다는 식 \(d\omega = \omega\wedge\omega\)의 성분이다.
마무리

처음 질문에 답하면, 두 기본형식을 아무렇게나 줄 수는 없다. \(d\omega = \omega\wedge\omega\)를 곡면에 제한하면 가우스 방정식과 코다치 방정식이 나오며, 이것이 두 형식이 만족해야 할 조건이다. 이 조건을 만족하면 보네 정리에 의해 곡면이 강체 운동을 빼고 하나로 정해지고, 코다치 방정식에서 모든 점이 배꼽점인 곡면은 평면이나 구라는 사실도 나온다.

3.4.4연습문제

기본

  1. 원기둥 \((r\cos u, r\sin u, v)\) (안쪽 법선, \(E = r^2\), \(G = 1\), \(l = r\), \(n = 0\))에서 코다치 방정식을 확인하여라.
    답

    모든 계수가 상수라 \(l_v = n_u = 0\), \(E_v = G_u = 0\). 성립.

응용

  1. \(E = G = 1\), \(F = 0\), \(l = 1\), \(m = 0\), \(n = 1\)을 기본형식으로 가지는 곡면이 있는가?
    답

    코다치는 성립(모두 상수)하지만 가우스 방정식에서 \(K = \frac{ln}{EG} = 1\)인데 \(E = G = 1\)이면 내재적 \(K = 0\). 모순이라 없다.

심화

  1. 본문의 배꼽점 논증에서 \(k_v = 0\)을 유도하는 계산을 자세히 써라.
    답

    \(l = kE\)이라 \(l_v = k_vE + kE_v\). 우변 \(\frac{E_v}2(k + k) = kE_v\). 같으려면 \(k_vE = 0\), \(E > 0\)이라 \(k_v = 0\).
