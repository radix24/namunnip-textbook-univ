곡면의 등장사상

본문

종이를 찢거나 늘리지 않고 구부리면, 종이 위의 길이와 각은 그대로이다. 이렇게 길이를 보존하는 사상은 매개화에서 어떻게 알아볼 수 있을까? 생김새가 전혀 다른 두 곡면이 곡면 위의 측정으로는 구별되지 않는 일도 있을까?

먼저 알아야 할 것제1기본형식(3.1절), 회전면(2.5절), 쌍곡선 함수를 쓴다.

3.2.1정의

곡면 \(M\)에서 \(\bar M\)으로 가는 매끄러운 사상 \(F\)의 미분 \(F_*\)가 모든 접벡터에 대해 \(F_*(v)\cdot F_*(w) = v\cdot w\)를 만족하면 국소 등장사상이라 하고, 여기에 전단사이기까지 하면 등장사상이라 한다. 등장사상은 곡면 위 곡선의 길이, 각, 넓이를 모두 보존한다. 종이를 찢거나 늘리지 않고 구부리는 변형이 국소 등장사상의 직관이다.

정리 3.2.1

매개화 \(\mathbf x : D \to M\), \(\bar{\mathbf x} : D \to \bar M\)의 제1기본형식이 같으면(\(E = \bar E\), \(F = \bar F\), \(G = \bar G\)) \(\bar{\mathbf x}\circ\mathbf x^{-1}\)은 국소 등장사상이다.

증명.\(F = \bar{\mathbf x}\circ\mathbf x^{-1}\)은 \(\mathbf x_u\)를 \(\bar{\mathbf x}_u\)로, \(\mathbf x_v\)를 \(\bar{\mathbf x}_v\)로 보낸다. 기저끼리의 내적 \(E, F, G\)가 같으므로 선형결합의 내적도 같다. ∎

3.2.2원기둥과 평면

예제 3.2.2

평면 \(\bar{\mathbf x}(u, v) = (u, v, 0)\)과 원기둥 \(\mathbf x(u, v) = (\cos u, \sin u, v)\) 사이의 관계를 조사하여라.

풀이. 둘 다 \(E = G = 1\), \(F = 0\)이므로, 평면 띠 \(0 < u < 2\pi\)를 원기둥으로 마는 사상은 국소 등장사상이다. 하지만 전체로 보면 \(u\)와 \(u + 2\pi\)가 같은 점으로 가서 전단사가 아니므로 등장사상은 아니다.

그래서 원기둥 위의 삼각형은 펼쳐 놓으면 평면 삼각형이 되어 내각의 합이 \(\pi\)이다. 이는 원기둥에서 \(K = 0\)인 것과 맞으며, 5장의 가우스-보네 정리에서 다시 본다.

3.2.3나선면과 현수면

예제 3.2.3

현수면 \(\mathbf x(u, v) = (\cosh u\cos v, \cosh u\sin v, u)\)와 나선면 \(\bar{\mathbf y}(s, t) = (s\cos t, s\sin t, t)\)가 국소 등장임을 보여라.

풀이. 현수면은 \(E = \sinh^2u + 1 = \cosh^2u\), \(F = 0\), \(G = \cosh^2u\)이다. 나선면은 \(E = 1\), \(F = 0\), \(G = 1 + s^2\)이다. 여기서 \(s = \sinh u\), \(t = v\)로 바꾸면 \(ds = \cosh u\,du\)이므로 다음과 같이 두 제1기본형식이 같아진다. 따라서 국소 등장이다.

\[ds^2 + (1 + s^2)dt^2 = \cosh^2u\,du^2 + \cosh^2u\,dv^2\]

두 곡면은 모양이 전혀 달라 보인다. 현수면은 모래시계 모양의 회전면이고, 나선면은 나선 계단 모양이다. 그런데 나선면의 한 바퀴를 잘라 구부리면 현수면이 되며, 그 사이의 모든 단계가 극소곡면이다. 내재적으로는 같은 곡면이므로 가우스 곡률도 같다. 한편 평균곡률은 둘 다 0이지만, 이는 둘이 극소곡면 가족에 속하기 때문이다. 일반적으로 \(H\)는 등장사상에서 보존되지 않으며, 원기둥은 \(H = \frac1{2r}\)이고 평면은 0이다.

흔한 오해국소 등장이면 \(\mathbb R^3\)에서 합동이라고 여기기 쉽지만, 원기둥과 평면처럼 공간에서의 모양은 다를 수 있다. 또 구의 일부를 평면에 왜곡 없이 펼칠 수 있다고 생각하는 것도 틀렸다. 3.3절에서 보듯 \(K\)가 다르므로 불가능하며, 그래서 왜곡 없는 세계 지도는 없다.
마무리

처음 질문에 답하면, 길이를 보존하는 사상은 국소 등장사상이고, 두 매개화의 제1기본형식이 같으면 대응하는 사상이 국소 등장이다. 그래서 평면 띠와 원기둥, 나선면과 현수면처럼 생김새가 전혀 다른 곡면도 곡면 위의 측정으로는 구별되지 않는다.

3.2.4연습문제

기본

  1. 원뿔 \(\mathbf x(u, v) = (u\cos v, u\sin v, u)\) (\(E = 2\), \(F = 0\), \(G = u^2\))이 평면의 한 부채꼴과 국소 등장임을 극좌표 \((\rho, \phi) = (\sqrt2u, \frac v{\sqrt2})\)로 보여라.
    답

    평면 극좌표의 계량 \(d\rho^2 + \rho^2d\phi^2 = 2du^2 + 2u^2\frac{dv^2}2 = 2du^2 + u^2dv^2\).

응용

  1. 1번에서 원뿔 한 바퀴(\(v\)가 0에서 \(2\pi\))를 펼친 부채꼴의 중심각을 구하여라.
    답

    \(\phi\)는 \(\frac{2\pi}{\sqrt2} = \sqrt2\pi\)만큼 변한다. 중심각 \(\sqrt2\pi \approx 254.6°\).

심화

  1. 등장사상이 넓이를 보존함을 \(\sqrt{EG - F^2}\)로 설명하여라.
    답

    대응하는 매개화의 \(E, F, G\)가 같으면 넓이 요소 \(\sqrt{EG - F^2}\,du\,dv\)가 같고, 같은 영역 \(D\)에서 적분하므로 넓이가 같다.
