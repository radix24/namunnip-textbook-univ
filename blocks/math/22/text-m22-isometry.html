곡면의 등장사상

본문
이 절에서 배울 것
  • 곡면 사이의 (국소) 등장사상을 접벡터의 내적을 보존하는 사상으로 정의한다.
  • 대응하는 매개화의 \(E, F, G\)가 같으면 국소 등장임을 보인다.
  • 원기둥과 평면, 나선면과 현수면이 국소 등장임을 확인한다.
먼저 알아야 할 것
  • 제1기본형식 (3.1절), 회전면 (2.5절), 쌍곡선 함수.

3.2.1정의

곡면 \(M\)에서 \(\bar M\)으로 가는 매끄러운 사상 \(F\)의 미분 \(F_*\)가 모든 접벡터에 대해 \(F_*(v)\cdot F_*(w) = v\cdot w\)를 만족하면 국소 등장사상, 여기에 전단사이면 등장사상이라 합니다. 곡면 위 곡선의 길이, 각, 넓이를 모두 보존합니다. 종이를 찢거나 늘리지 않고 구부리는 변형이 국소 등장의 직관입니다.

정리 3.2.1 매개화 \(\mathbf x : D \to M\), \(\bar{\mathbf x} : D \to \bar M\)의 제1기본형식이 같으면(\(E = \bar E\), \(F = \bar F\), \(G = \bar G\)) \(\bar{\mathbf x}\circ\mathbf x^{-1}\)은 국소 등장사상이다.
증명

\(F = \bar{\mathbf x}\circ\mathbf x^{-1}\)은 \(\mathbf x_u \mapsto \bar{\mathbf x}_u\), \(\mathbf x_v \mapsto \bar{\mathbf x}_v\)로 보낸다. 기저끼리의 내적 \(E, F, G\)가 같으므로 선형결합의 내적도 같다. ∎

3.2.2원기둥과 평면

예 3.2.2 평면 \(\bar{\mathbf x}(u, v) = (u, v, 0)\)과 원기둥 \(\mathbf x(u, v) = (\cos u, \sin u, v)\)은 모두 \(E = G = 1\), \(F = 0\)입니다. 따라서 평면 띠 \(0 < u < 2\pi\)를 원기둥으로 마는 사상은 국소 등장입니다. 전체로는 \(u\)와 \(u + 2\pi\)가 같은 점으로 가 전단사가 아니므로 등장은 아닙니다.

원기둥 위의 삼각형은 펼쳐 놓으면 평면 삼각형이 되어 내각 합이 \(\pi\)입니다. 원기둥에서 \(K = 0\)인 것과 맞습니다(5장의 가우스-보네).

3.2.3나선면과 현수면

예 3.2.3 현수면 \(\mathbf x(u, v) = (\cosh u\cos v, \cosh u\sin v, u)\)은 \(E = \sinh^2u + 1 = \cosh^2u\), \(F = 0\), \(G = \cosh^2u\)입니다. 나선면 \(\bar{\mathbf y}(s, t) = (s\cos t, s\sin t, t)\)은 \(E = 1\), \(F = 0\), \(G = 1 + s^2\)이고, \(s = \sinh u\), \(t = v\)로 바꾸면 \(ds = \cosh u\,du\)라 \[ds^2 + (1 + s^2)dt^2 = \cosh^2u\,du^2 + \cosh^2u\,dv^2.\] 두 제1기본형식이 같아 국소 등장입니다.

모양은 전혀 달라 보입니다. 현수면은 모래시계 모양의 회전면, 나선면은 나선 계단 모양입니다. 그런데 나선면의 한 바퀴를 잘라 구부리면 현수면이 되고, 그 사이 모든 단계가 극소곡면입니다. 내재적으로는 같은 곡면이므로 가우스 곡률도 같습니다. 반면 평균곡률은 둘 다 0이지만 이는 우연이 아니라 둘이 극소곡면 가족에 속하기 때문이고, 일반적으로 \(H\)는 등장사상에서 보존되지 않습니다(원기둥 \(H = \frac1{2r}\), 평면 0).

흔한 오해(1) 국소 등장이면 \(\mathbb R^3\)의 합동이라 여긴다. 원기둥과 평면처럼 공간에서의 모양은 다를 수 있다. (2) 구의 일부를 평면에 펼칠 수 있다고 여긴다. \(K\)가 다르므로 불가능하다(3.3절). 그래서 왜곡 없는 세계 지도는 없다.
요약
  1. 국소 등장: 접벡터의 내적 보존, 길이·각·넓이 보존.
  2. 같은 \(E, F, G\)의 매개화끼리는 국소 등장.
  3. 원기둥 ≈ 평면, 현수면 ≈ 나선면 (국소적으로).

3.2.4연습문제

기본

  1. 원뿔 \(\mathbf x(u, v) = (u\cos v, u\sin v, u)\) (\(E = 2\), \(F = 0\), \(G = u^2\))이 평면의 한 부채꼴과 국소 등장임을 극좌표 \((\rho, \phi) = (\sqrt2u, \frac v{\sqrt2})\)로 보여라.
    답

    평면 극좌표의 계량 \(d\rho^2 + \rho^2d\phi^2 = 2du^2 + 2u^2\frac{dv^2}2 = 2du^2 + u^2dv^2\).

응용

  1. 1번에서 원뿔 한 바퀴(\(v\)가 0에서 \(2\pi\))를 펼친 부채꼴의 중심각을 구하여라.
    답

    \(\phi\)는 \(\frac{2\pi}{\sqrt2} = \sqrt2\pi\)만큼 변한다. 중심각 \(\sqrt2\pi \approx 254.6°\).

심화

  1. 등장사상이 넓이를 보존함을 \(\sqrt{EG - F^2}\)로 설명하여라.
    답

    대응하는 매개화의 \(E, F, G\)가 같으면 넓이 요소 \(\sqrt{EG - F^2}\,du\,dv\)가 같고, 같은 영역 \(D\)에서 적분하므로 넓이가 같다.
