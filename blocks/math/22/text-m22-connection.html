접속형식

본문
이 절에서 배울 것
  • 틀장의 변화율을 1-형식 \(\omega_{ij}(V) = \nabla_VE_i\cdot E_j\)로 기록한 접속형식을 정의한다.
  • 접속형식이 반대칭 \(\omega_{ij} = -\omega_{ji}\)임을 보이고 \(\omega = dA\,A^T\)로 계산한다.
  • 원기둥 틀장과 구면 틀장의 접속형식을 구한다.
먼저 알아야 할 것
  • 공변도함수의 성질 (1.1절), 틀장과 자세 행렬 (1.2절).

1.3.1정의

틀장 \(E_1, E_2, E_3\)을 접벡터 \(V\) 방향으로 미분한 \(\nabla_VE_i\)를 다시 틀장으로 나타내면

\[\nabla_VE_i = \sum_j\omega_{ij}(V)E_j, \qquad \omega_{ij}(V) = \nabla_VE_i\cdot E_j.\]

\(\omega_{ij}\)는 \(V\)에 대해 선형이라 1-형식이고, 이를 접속형식이라 합니다. 곡선의 프레네 공식 \(T' = \kappa N\), \(N' = -\kappa T + \tau B\), \(B' = -\tau N\)을 3차원 공간 전체로 넓힌 것입니다. 프레네 공식의 계수 행렬이 반대칭이었듯이

정리 1.3.1 \(\omega_{ij} = -\omega_{ji}\). 특히 \(\omega_{ii} = 0\)이다.
증명

\(E_i\cdot E_j = \delta_{ij}\)는 상수라 \(V\)로 미분하면 0이다. 내적 호환성(정리 1.1.2)으로 \(\nabla_VE_i\cdot E_j + E_i\cdot\nabla_VE_j = 0\), 즉 \(\omega_{ij}(V) + \omega_{ji}(V) = 0\). ∎

그래서 독립인 것은 \(\omega_{12}, \omega_{13}, \omega_{23}\) 세 개뿐입니다.

1.3.2자세 행렬로 계산하기

정리 1.3.2 \(\omega = (\omega_{ij})\)이면 \(\omega = dA\,A^T\), 즉 \(\omega_{ij} = \sum_kda_{ik}\,a_{jk}\).
증명

\(E_i = \sum_ka_{ik}U_k\)이고 \(U_k\)는 상수 벡터장이라 \(\nabla_VE_i = \sum_kV[a_{ik}]U_k = \sum_kda_{ik}(V)U_k\). \(E_j = \sum_ka_{jk}U_k\)와 내적하면 된다. ∎

예 1.3.3 (원기둥 틀장) \(dE_1 = (-\sin\vartheta, \cos\vartheta, 0)d\vartheta = d\vartheta\,E_2\)이므로 \(\omega_{12} = d\vartheta\), \(\omega_{13} = \omega_{23} = 0\). 축을 돌면 \(E_1, E_2\)가 같이 돌고 \(E_3\)은 그대로라는 뜻입니다.
예 1.3.4 (구면 틀장) 1.2절의 \(E_1\)을 미분해 \(E_2\), \(E_3\)과 내적하면 \[\omega_{12} = \cos\varphi\,d\vartheta, \qquad \omega_{13} = d\varphi, \qquad \omega_{23} = \sin\varphi\,d\vartheta.\] 예를 들어 \(dE_2 = (-\cos\vartheta, -\sin\vartheta, 0)d\vartheta\)이고 \(E_3\)과의 내적이 \(\sin\varphi(\cos^2\vartheta + \sin^2\vartheta)d\vartheta\)입니다.

\(\omega_{13}(V)\)는 "\(V\) 방향으로 갈 때 \(E_1\)이 \(E_3\) 쪽으로 기우는 비율"입니다. 북쪽(\(E_3\))으로 가면 방사 방향 \(E_1\)이 북쪽으로 기울고, 그 비율이 \(d\varphi\)라는 것은 직관과 맞습니다.

흔한 오해(1) 자연 틀장 \(U_i\)에서 접속형식이 0이니 접속형식은 쓸모없다고 여긴다. 곡면에 맞춘 틀장에서는 0이 아니고, 2장에서 곡면의 곡률이 바로 이 형식들로 나타난다. (2) \(\omega = A^TdA\)로 쓴다. 행이 \(E_i\)인 관례에서는 \(dA\,A^T\)이다.
요약
  1. \(\nabla_VE_i = \sum\omega_{ij}(V)E_j\), 접속형식은 1-형식.
  2. 반대칭 \(\omega_{ij} = -\omega_{ji}\), \(\omega = dA\,A^T\).
  3. 원기둥: \(\omega_{12} = d\vartheta\). 구면: \(\cos\varphi\,d\vartheta\), \(d\varphi\), \(\sin\varphi\,d\vartheta\).

1.3.3연습문제

기본

  1. 원기둥 틀장에서 \(\nabla_{U_3}E_1\)과 \(\nabla_{E_2}E_1\)을 구하여라.
    답

    \(\omega_{12}(U_3) = d\vartheta(U_3) = 0\)이라 \(\nabla_{U_3}E_1 = 0\). \(d\vartheta(E_2) = \frac1r\)이라 \(\nabla_{E_2}E_1 = \frac1rE_2\).

응용

  1. 구면 틀장에서 \(\omega_{13} = d\varphi\)를 \(dE_1\cdot E_3\)으로 직접 계산하여라.
    답

    \(dE_1 = (-\sin\varphi\cos\vartheta\,d\varphi - \cos\varphi\sin\vartheta\,d\vartheta, -\sin\varphi\sin\vartheta\,d\varphi + \cos\varphi\cos\vartheta\,d\vartheta, \cos\varphi\,d\varphi)\). \(E_3\)과 내적하면 \(d\vartheta\) 항은 지워지고 \((\sin^2\varphi + \cos^2\varphi)d\varphi\).

심화

  1. 단위 속력 곡선 \(\beta\)를 따라 프레네 틀 \(T, N, B\)를 틀장처럼 보면 \(\omega_{12}(T) = \kappa\), \(\omega_{23}(T) = \tau\), \(\omega_{13}(T) = 0\)임을 설명하여라.
    답

    \(\nabla_TT = T' = \kappa N\)이라 \(\omega_{12}(T) = \kappa\), \(\omega_{13}(T) = 0\). \(N' = -\kappa T + \tau B\)라 \(\omega_{23}(T) = \tau\).
