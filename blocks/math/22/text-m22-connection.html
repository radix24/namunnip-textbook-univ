접속형식

본문

프레네 공식은 곡선을 따라 움직일 때 \(T, N, B\)가 서로 어느 쪽으로 기우는지를 기록했다. 공간의 틀장에서도 한 방향으로 움직일 때 각 틀 벡터가 다른 틀 벡터 쪽으로 얼마나 기우는지 기록할 수 있을까? 그 기록은 어떤 대칭을 가지며 어떻게 계산할까?

먼저 알아야 할 것공변도함수의 성질(1.1절), 틀장과 자세 행렬(1.2절)을 쓴다.

1.3.1정의

틀장 \(E_1, E_2, E_3\)을 접벡터 \(V\) 방향으로 미분한 \(\nabla_VE_i\)를 다시 틀장으로 나타내면 다음과 같다.

\[\nabla_VE_i = \sum_j\omega_{ij}(V)E_j, \qquad \omega_{ij}(V) = \nabla_VE_i\cdot E_j\]

\(\omega_{ij}\)는 \(V\)에 대해 선형이라 1-형식이며, 이를 접속형식이라 한다. 사실 이것은 곡선의 프레네 공식 \(T' = \kappa N\), \(N' = -\kappa T + \tau B\), \(B' = -\tau N\)을 3차원 공간 전체로 넓힌 것이다. 프레네 공식의 계수 행렬이 반대칭이었듯이 다음이 성립한다.

정리 1.3.1

\(\omega_{ij} = -\omega_{ji}\)이다. 특히 \(\omega_{ii} = 0\)이다.

증명.\(E_i\cdot E_j = \delta_{ij}\)는 상수이므로 \(V\)로 미분하면 0이다. 정리 1.1.2의 내적 호환성으로 \(\nabla_VE_i\cdot E_j + E_i\cdot\nabla_VE_j = 0\), 즉 \(\omega_{ij}(V) + \omega_{ji}(V) = 0\)이다. ∎

그래서 서로 독립인 것은 \(\omega_{12}, \omega_{13}, \omega_{23}\) 세 개뿐이다.

1.3.2자세 행렬로 계산하기

정리 1.3.2

\(\omega = (\omega_{ij})\)라 하면 \(\omega = dA\,A^T\)이다. 즉 \(\omega_{ij} = \sum_kda_{ik}\,a_{jk}\)이다.

증명.\(E_i = \sum_ka_{ik}U_k\)이고 \(U_k\)는 상수 벡터장이므로 \(\nabla_VE_i = \sum_kV[a_{ik}]U_k = \sum_kda_{ik}(V)U_k\)이다. 이것을 \(E_j = \sum_ka_{jk}U_k\)와 내적하면 된다. ∎

예제 1.3.3

원기둥 틀장의 접속형식을 구하여라.

풀이. \(dE_1 = (-\sin\vartheta, \cos\vartheta, 0)d\vartheta = d\vartheta\,E_2\)이므로 \(\omega_{12} = d\vartheta\)이고 \(\omega_{13} = \omega_{23} = 0\)이다. 즉 그림 1에서 보듯 축을 돌면 \(E_1, E_2\)가 같이 돌고 \(E_3\)은 그대로라는 뜻이다.

예제 1.3.4

1.2절의 구면 틀장의 접속형식을 구하여라.

풀이. 1.2절의 \(E_1\), \(E_2\)를 미분해 다른 틀 벡터와 내적하면 다음을 얻는다.

\[\omega_{12} = \cos\varphi\,d\vartheta, \qquad \omega_{13} = d\varphi, \qquad \omega_{23} = \sin\varphi\,d\vartheta\]

예를 들어 \(dE_2 = (-\cos\vartheta, -\sin\vartheta, 0)d\vartheta\)이고, 이것과 \(E_3\)의 내적이 \(\sin\varphi(\cos^2\vartheta + \sin^2\vartheta)d\vartheta = \sin\varphi\,d\vartheta\)이다.

이제 \(\omega_{13}(V)\)는 \(V\) 방향으로 갈 때 \(E_1\)이 \(E_3\) 쪽으로 기우는 비율이다. 북쪽(\(E_3\))으로 가면 방사 방향 \(E_1\)이 북쪽으로 기울고, 그 비율이 \(d\varphi\)라는 것은 직관과 맞는다.

흔한 오해자연 틀장 \(U_i\)에서는 접속형식이 0이니 접속형식은 쓸모없다고 여기기 쉽지만, 곡면에 맞춘 틀장에서는 0이 아니며 2장에서 곡면의 곡률이 바로 이 형식들로 나타난다. 또 \(\omega = A^TdA\)로 쓰는 것도 틀렸다. 행이 \(E_i\)인 이 책의 관례에서는 \(dA\,A^T\)이다.
마무리

처음 질문에 답하면, 틀 벡터가 서로 쪽으로 기우는 비율은 접속형식 \(\omega_{ij}(V) = \nabla_VE_i\cdot E_j\)로 기록된다. 내적 호환성 때문에 \(\omega_{ij} = -\omega_{ji}\)로 반대칭이라, 독립인 것은 세 개뿐이다. 계산은 자세 행렬로 \(\omega = dA\,A^T\)를 쓰며, 원기둥 틀장에서는 \(\omega_{12} = d\vartheta\)만 남는다.

1.3.3연습문제

기본

  1. 원기둥 틀장에서 \(\nabla_{U_3}E_1\)과 \(\nabla_{E_2}E_1\)을 구하여라.
    답

    \(\omega_{12}(U_3) = d\vartheta(U_3) = 0\)이라 \(\nabla_{U_3}E_1 = 0\). \(d\vartheta(E_2) = \frac1r\)이라 \(\nabla_{E_2}E_1 = \frac1rE_2\).

응용

  1. 구면 틀장에서 \(\omega_{13} = d\varphi\)를 \(dE_1\cdot E_3\)으로 직접 계산하여라.
    답

    \(dE_1 = (-\sin\varphi\cos\vartheta\,d\varphi - \cos\varphi\sin\vartheta\,d\vartheta, -\sin\varphi\sin\vartheta\,d\varphi + \cos\varphi\cos\vartheta\,d\vartheta, \cos\varphi\,d\varphi)\). \(E_3\)과 내적하면 \(d\vartheta\) 항은 지워지고 \((\sin^2\varphi + \cos^2\varphi)d\varphi\).

심화

  1. 단위 속력 곡선 \(\beta\)를 따라 프레네 틀 \(T, N, B\)를 틀장처럼 보면 \(\omega_{12}(T) = \kappa\), \(\omega_{23}(T) = \tau\), \(\omega_{13}(T) = 0\)임을 설명하여라.
    답

    \(\nabla_TT = T' = \kappa N\)이라 \(\omega_{12}(T) = \kappa\), \(\omega_{13}(T) = 0\). \(N' = -\kappa T + \tau B\)라 \(\omega_{23}(T) = \tau\).
