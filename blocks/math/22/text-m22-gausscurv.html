가우스 곡률과 평균곡률

본문
이 절에서 배울 것
  • 가우스 곡률 \(K = \det S = k_1k_2\)와 평균곡률 \(H = \frac12\operatorname{tr}S = \frac{k_1 + k_2}2\)를 정의한다.
  • \(K = \frac{ln - m^2}{EG - F^2}\), \(H = \frac{Gl + En - 2Fm}{2(EG - F^2)}\)로 계산한다.
  • 구, 원기둥, 안장면, 그래프 곡면의 곡률을 구한다.
먼저 알아야 할 것
  • 모양연산자의 행렬 (2.2절), 행렬식과 대각합.

2.4.1정의와 공식

\(K = \det S = k_1k_2\), \(H = \frac12\operatorname{tr}S = \frac{k_1 + k_2}2\)입니다. 법선을 반대로 바꾸면 \(S \to -S\)라 \(H\)는 부호가 바뀌지만 \(K\)는 그대로입니다. 주곡률은 \(k = H \pm\sqrt{H^2 - K}\)로 \(K\)와 \(H\)에서 다시 얻습니다.

정리 2.4.1 매개화에서 \(K = \frac{ln - m^2}{EG - F^2}\), \(H = \frac{Gl + En - 2Fm}{2(EG - F^2)}\).
증명

\([S] = \begin{pmatrix}E & F\\ F & G\end{pmatrix}^{-1}\begin{pmatrix}l & m\\ m & n\end{pmatrix}\)이고 행렬식은 곱이라 \(K = \frac{ln - m^2}{EG - F^2}\). 역행렬 \(\frac1{EG - F^2}\begin{pmatrix}G & -F\\ -F & E\end{pmatrix}\)을 곱해 대각합을 구하면 \(H\). ∎

2.4.2기본 예

예 2.4.2
  • 구(반지름 \(r\), 안쪽 법선): \(k_1 = k_2 = \frac1r\), \(K = \frac1{r^2}\), \(H = \frac1r\).
  • 원기둥(안쪽 법선): \(k_1 = \frac1r\), \(k_2 = 0\), \(K = 0\), \(H = \frac1{2r}\).
  • 안장면 \(z = xy\)의 원점: \(k = \pm1\), \(K = -1\), \(H = 0\).
  • 평면: \(K = H = 0\).

원기둥과 평면은 둘 다 \(K = 0\)입니다. 원기둥은 종이를 말아 만들 수 있으므로, 종이 위의 사람이 잴 수 있는 기하(길이, 각)는 평면과 같습니다. 3.3절의 경이 정리는 \(K\)가 바로 그런 "종이 위에서 잴 수 있는" 양이라고 말합니다. 반면 \(H\)는 말아 올린 방식에 따라 달라집니다.

2.4.3그래프 곡면

\(z = f(x, y)\)를 \(\mathbf x(x, y) = (x, y, f)\)로 매개화하면 \(E = 1 + f_x^2\), \(F = f_xf_y\), \(G = 1 + f_y^2\), \(EG - F^2 = 1 + f_x^2 + f_y^2 =: W^2\), 위쪽 법선으로 \(l = \frac{f_{xx}}W\), \(m = \frac{f_{xy}}W\), \(n = \frac{f_{yy}}W\)이므로

\[K = \frac{f_{xx}f_{yy} - f_{xy}^2}{(1 + f_x^2 + f_y^2)^2}.\]
예 2.4.3 안장면 \(z = xy\)는 \(f_{xx} = f_{yy} = 0\), \(f_{xy} = 1\)이라 \(K = -\frac1{(1 + x^2 + y^2)^2}\). 원점에서 \(-1\)이고 멀어질수록 0으로 갑니다. 곡면이 멀리 갈수록 덜 휘어 평평해진다는 뜻입니다.
흔한 오해(1) \(K = 0\)이면 평면이라 여긴다. 원기둥, 원뿔도 \(K = 0\)이다. (2) \(K\)도 법선 방향에 따라 부호가 바뀐다고 여긴다. 두 주곡률이 함께 부호를 바꾸므로 곱은 그대로다.
요약
  1. \(K = k_1k_2 = \frac{ln - m^2}{EG - F^2}\), \(H = \frac{k_1 + k_2}2\).
  2. 구 \(\frac1{r^2}\), 원기둥 0, 안장 \(-1\).
  3. 그래프: \(K = \frac{f_{xx}f_{yy} - f_{xy}^2}{(1 + |\nabla f|^2)^2}\).

2.4.4연습문제

기본

  1. 주곡률이 \(\frac12\)과 \(-2\)인 점의 \(K\)와 \(H\)를 구하고 점의 종류를 말하여라.
    답

    \(K = -1\), \(H = -0.75\), 쌍곡점.

응용

  1. 포물면 \(z = x^2 + y^2\)의 가우스 곡률을 구하여라.
    답

    \(f_{xx} = f_{yy} = 2\), \(f_{xy} = 0\). \(K = \frac4{(1 + 4x^2 + 4y^2)^2}\).

심화

  1. \(K\)와 \(H\)가 주어지면 \(H^2 \ge K\)임을 보이고, 등호가 성립하는 점의 의미를 말하여라.
    답

    \(H^2 - K = \frac{(k_1 - k_2)^2}4 \ge 0\). 등호는 \(k_1 = k_2\), 모든 방향의 법곡률이 같은 배꼽점(2.5절).
