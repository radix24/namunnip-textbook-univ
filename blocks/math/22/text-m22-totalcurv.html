면적 형식과 전곡률

본문
이 절에서 배울 것
  • 방향 곡면의 면적 형식 \(dM = \theta_1\wedge\theta_2\)를 정의하고 적분한다.
  • 전곡률 \(\iint_MK\,dM\)을 구와 원환면에서 계산한다.
  • 전곡률을 가우스 사상의 부호 있는 넓이로 해석한다.
먼저 알아야 할 것
  • 곡면 위 2-형식의 적분 (수학13 5장), 원환면의 곡률 (2.5절).

5.1.1면적 형식

방향이 주어진 곡면에서, 방향과 맞는 정규직교 틀 \(E_1, E_2\)의 쌍대 형식으로 \(dM = \theta_1\wedge\theta_2\)를 면적 형식이라 합니다. 양의 방향 매개화에서 \(dM = \sqrt{EG - F^2}\,du\wedge dv\)이므로 \(\iint_RdM\)은 영역의 넓이입니다. 함수 \(f\)에 대해 \(\iint_Rf\,dM\)을 같은 방식으로 정의합니다.

5.1.2전곡률

\(\iint_MK\,dM\)을 곡면의 전곡률이라 합니다.

예 5.1.1 (구) \(K = \frac1{r^2}\)이 상수라 \(\iint K\,dM = \frac1{r^2}\cdot4\pi r^2 = 4\pi\). 반지름과 무관합니다.
예 5.1.2 (원환면) \(\mathbf x = ((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\)에서 \(dM = r(R + r\cos u)\,du\,dv\), \(K = \frac{\cos u}{r(R + r\cos u)}\)이라 \(K\,dM = \cos u\,du\,dv\). \[\iint K\,dM = \int_0^{2\pi}\int_0^{2\pi}\cos u\,du\,dv = 0.\] 바깥쪽의 양의 곡률과 안쪽의 음의 곡률이 정확히 상쇄됩니다. 역시 \(R\), \(r\)과 무관합니다.

두 결과가 크기와 무관하다는 점이 5.3절 가우스-보네 정리의 예고입니다. 구 모양을 어떻게 찌그러뜨려도 \(4\pi\), 도넛 모양은 늘 0입니다.

5.1.3가우스 사상

각 점 \(p\)에 단위 법선 \(U(p)\)를 대응시키는 사상 \(G : M \to S^2\)을 가우스 사상이라 합니다. 그 미분은 \(-S\)이고 넓이 배율은 \(\det(-S) = K\)이므로

\[\iint_RK\,dM = \iint_{G(R)}(\pm1)\,dA_{S^2}.\]

즉 영역 \(R\)의 전곡률은 \(R\)의 가우스 사상 상 \(G(R)\)의 부호 있는 넓이입니다. 작은 영역에서 \(K = \lim\frac{\text{Area}(G(R))}{\text{Area}(R)}\)이라는 가우스의 원래 정의입니다. 구는 가우스 사상이 단위구를 한 번 덮어 \(4\pi\), 원환면은 바깥 반이 단위구를 양으로, 안쪽 반이 음으로 한 번씩 덮어 0입니다.

흔한 오해(1) 큰 구일수록 전곡률이 크다고 여긴다. \(K\)가 작아지고 넓이가 커져 늘 \(4\pi\)다. (2) 원환면의 곡률이 0이라 여긴다. 점마다 0이 아니고 적분만 0이다.
요약
  1. 면적 형식 \(dM = \theta_1\wedge\theta_2 = \sqrt{EG - F^2}\,du\wedge dv\).
  2. 전곡률: 구 \(4\pi\), 원환면 0 (크기 무관).
  3. 전곡률 = 가우스 사상 상의 부호 있는 넓이.

5.1.4연습문제

기본

  1. 반지름 \(r\)인 구의 북반구의 전곡률을 구하여라.
    답

    \(\frac1{r^2}\cdot2\pi r^2 = 2\pi\).

응용

  1. 원환면의 바깥쪽 반(\(-\frac\pi2 \le u \le \frac\pi2\))의 전곡률을 구하여라.
    답

    \(\int_0^{2\pi}\int_{-\pi/2}^{\pi/2}\cos u\,du\,dv = 2\pi\cdot2 = 4\pi\). 가우스 사상이 단위구를 한 번 덮는다.

심화

  1. 포물면 \(z = x^2 + y^2\) 전체의 전곡률을 구하여라(2.4절 연습문제의 \(K\)).
    답

    \(K = \frac4{(1 + 4\rho^2)^2}\), \(dM = \sqrt{1 + 4\rho^2}\,\rho\,d\rho\,d\phi\). \(2\pi\int_0^\infty\frac{4\rho}{(1 + 4\rho^2)^{3/2}}d\rho = 2\pi\). 법선이 열린 위쪽 반구만 덮는다.
