측지 극좌표와 측지선의 최단성

본문
이 절에서 배울 것
  • 한 점에서 나가는 측지선들로 측지 극좌표 \((r, \theta)\)를 만들고 \(ds^2 = dr^2 + G(r, \theta)\,d\theta^2\)임을 안다(가우스 보조정리).
  • \(K = -\frac{(\sqrt G)_{rr}}{\sqrt G}\)와 측지원의 둘레 \(C(r) = 2\pi r - \frac\pi3Kr^3 + \cdots\)를 이해한다.
  • 짧은 측지선이 최단 경로임을 증명한다.
먼저 알아야 할 것
  • 측지선의 존재 (4.2절), 직교 좌표의 곡률 공식 (3.3절).

4.4.1측지 극좌표

점 \(p\)에서 각 방향 \(\theta\)로 단위 속력 측지선을 쏘아 거리 \(r\)만큼 간 점을 \((r, \theta)\)로 부릅니다(지수사상). \(r\)이 작으면 이것이 \(p\) 근처의 좌표가 됩니다. \(\theta\)를 고정한 곡선은 측지선이라 \(E = 1\)이고, 다음이 성립합니다.

정리 4.4.1 (가우스 보조정리) 측지 극좌표에서 \(F = 0\), 즉 측지원(\(r\) = 상수)은 \(p\)에서 나가는 측지선과 수직이다. 따라서 \(ds^2 = dr^2 + G\,d\theta^2\)이고 \(\sqrt G = r + O(r^2)\).

3.3절 연습문제의 공식(\(E = 1\), \(G = g^2\)이면 \(K = -\frac{g''}g\))을 쓰면 \(K = -\frac{(\sqrt G)_{rr}}{\sqrt G}\)이고, 이를 \(r = 0\) 근처에서 풀면 \(\sqrt G = r - \frac{K(p)}6r^3 + \cdots\)입니다.

예 4.4.2 반지름 \(R\)인 구에서 북극을 \(p\)로 하면 \(r\)은 북극에서의 대원 거리, 측지원은 위선이고 \(\sqrt G = R\sin\frac rR\)입니다. \(K = -\frac{(R\sin(r/R))''}{R\sin(r/R)} = \frac1{R^2}\). 쌍곡평면(\(K = -1\))에서는 \(\sqrt G = \sinh r\)입니다.

4.4.2둘레로 곡률 재기

반지름 \(r\)인 측지원의 둘레는 \(C(r) = \int_0^{2\pi}\sqrt G\,d\theta\)이므로

\[C(r) = 2\pi r - \frac\pi3K(p)r^3 + O(r^4), \qquad K(p) = \lim_{r\to0}\frac3\pi\cdot\frac{2\pi r - C(r)}{r^3}.\]

곡면 위의 개미가 줄을 \(r\)만큼 매어 원을 그리고 둘레를 재면 곡률을 알 수 있습니다. 양의 곡률에서는 원이 평면보다 짧고(구의 위선), 음의 곡률에서는 깁니다(안장 위 원은 주름진다). 경이 정리의 가장 손에 잡히는 판입니다.

4.4.3측지선의 최단성

정리 4.4.3 측지 극좌표가 정의되는 원판 안에서, \(p\)에서 \(q = (r_0, \theta_0)\)까지 가는 곡선 가운데 반지름 측지선이 가장 짧고, 그 길이는 \(r_0\)이다.
증명

곡선 \(\alpha(t) = (r(t), \theta(t))\)의 길이는 \(\int\sqrt{r'^2 + G\theta'^2}\,dt \ge \int|r'|\,dt \ge r_0\). 등호는 \(\theta' = 0\)이고 \(r\)이 단조일 때, 즉 반지름 측지선일 때이다. ∎

구에서 대원의 긴 호는 대척점(\(r = \pi R\))을 지나 극좌표가 무너지는 곳을 넘어가므로 최단이 아닙니다.

흔한 오해(1) 측지 극좌표가 곡면 전체에서 정의된다고 여긴다. 측지선들이 다시 만나는 곳(구의 대척점)에서 무너진다. (2) 측지원의 둘레가 늘 \(2\pi r\)이라 여긴다. 곡률만큼 \(\frac\pi3Kr^3\) 차이가 난다.
요약
  1. 측지 극좌표: \(ds^2 = dr^2 + G\,d\theta^2\) (가우스 보조정리).
  2. \(K = -\frac{(\sqrt G)_{rr}}{\sqrt G}\), \(C(r) = 2\pi r - \frac\pi3Kr^3 + \cdots\).
  3. 짧은 측지선은 최단 경로.

4.4.4연습문제

기본

  1. 반지름 \(R\)인 구에서 측지 반지름 \(r\)인 원의 둘레를 구하고 \(r = \frac{\pi R}2\)일 때 값을 말하여라.
    답

    \(C = 2\pi R\sin\frac rR\). \(r = \frac{\pi R}2\)(적도)이면 \(2\pi R\).

응용

  1. \(C(r) = 2\pi\sinh r\)인 곡면의 \(K\)를 둘레 공식으로 구하여라.
    답

    \(2\pi\sinh r = 2\pi r + \frac\pi3r^3 + \cdots\). \(-\frac\pi3K = \frac\pi3\)에서 \(K = -1\).

심화

  1. 측지원 안의 넓이가 \(A(r) = \pi r^2 - \frac\pi{12}Kr^4 + \cdots\)임을 \(C(r)\)을 적분해 보여라.
    답

    \(A(r) = \int_0^rC(s)ds = \pi r^2 - \frac\pi3K\frac{r^4}4 + \cdots = \pi r^2 - \frac\pi{12}Kr^4 + \cdots\).
