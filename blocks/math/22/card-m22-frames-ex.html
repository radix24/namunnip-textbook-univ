위쪽 방향을 구면 틀장으로 읽기

예제 · 쌍대 1-형식으로 성분 구하기

먼저 예측

북위 30°의 점에 서서 "정확히 위쪽"(\(U_3\) 방향)을 가리키면, 그 방향은 바깥쪽(\(E_1\))과 북쪽(\(E_3\)) 가운데 어느 쪽에 더 가까울까요?

예측 확인

북쪽입니다. 성분이 바깥쪽 \(\sin30° = 0.5\), 북쪽 \(\cos30° \approx 0.87\)입니다.

구면 틀장(1.2절)에 대해 벡터장 \(U_3\)과 위치 벡터장 \(P = xU_1 + yU_2 + zU_3\)을 \(E_1, E_2, E_3\)으로 나타내고, \(|U_3|^2 = \sum\theta_i(U_3)^2\)을 확인하여라.

전략

\(V = \sum_i\theta_i(V)E_i\), \(\theta_i(V) = V\cdot E_i\)이므로 \(E_i\)의 성분과 내적만 하면 됩니다.

풀이

  1. \(U_3\cdot E_1 = \sin\varphi\), \(U_3\cdot E_2 = 0\), \(U_3\cdot E_3 = \cos\varphi\). 따라서 \(U_3 = \sin\varphi\,E_1 + \cos\varphi\,E_3\).
    \(E_i\)의 셋째 성분을 읽음.
  2. \(P = \rho(\cos\varphi\cos\vartheta, \cos\varphi\sin\vartheta, \sin\varphi)\)라 \(P\cdot E_1 = \rho\), \(P\cdot E_2 = P\cdot E_3 = 0\). 따라서 \(P = \rho E_1\).
    \(E_1\)은 \(P\)의 단위 벡터.
  3. \(\sin^2\varphi + 0 + \cos^2\varphi = 1 = |U_3|^2\).
    정규직교 기저의 피타고라스.

검산

적도(\(\varphi = 0\))에서 위쪽은 정확히 북쪽(\(U_3 = E_3\)), 북극(\(\varphi = \frac\pi2\))에서 위쪽은 정확히 바깥쪽(\(U_3 = E_1\))입니다. 식이 두 극단 모두와 맞습니다.

의미

같은 벡터장도 틀장을 바꾸면 성분이 점마다 달라집니다. 문제의 대칭에 맞는 틀장(\(P = \rho E_1\)처럼 성분이 하나뿐)을 고르면 계산이 단순해집니다. 곡면 이론에서는 법선을 \(E_3\)로 둔 적응 틀장이 그런 역할을 합니다.

이해 확인

원기둥 틀장으로 \(U_1\)을 나타내어라.

답

\(U_1\cdot E_1 = \cos\vartheta\), \(U_1\cdot E_2 = -\sin\vartheta\): \(U_1 = \cos\vartheta\,E_1 - \sin\vartheta\,E_2\).
