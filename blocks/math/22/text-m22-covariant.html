공변도함수

본문
이 절에서 배울 것
  • 벡터장 \(W\)를 접벡터 \(v\) 방향으로 미분한 공변도함수 \(\nabla_vW\)를 정의하고 성분으로 계산한다.
  • 공변도함수의 선형성, 곱의 법칙, 내적과의 호환성을 증명한다.
  • 곡선을 따라가는 벡터장의 미분과 공변도함수의 관계를 안다.
먼저 알아야 할 것
  • 접벡터, 벡터장, 방향도함수 \(v[f]\) (수학13 1장).

1.1.1정의

\(\mathbb R^3\)의 점 \(p\)에서의 접벡터 \(v\)와 벡터장 \(W\)에 대해

\[\nabla_vW = \frac d{dt}W(p + tv)\Big|_{t=0}\]

를 공변도함수라 합니다. 점 \(p\)에서 \(v\) 방향으로 조금 움직일 때 \(W\)가 얼마나 바뀌는지를 재는 \(p\)의 접벡터입니다. 자연 틀장 \(U_1, U_2, U_3\)(좌표축 방향의 단위 벡터장)으로 \(W = \sum w_iU_i\)라 쓰면, \(U_i\)는 상수라 미분되지 않으므로

\[\nabla_vW = \sum_iv[w_i]\,U_i(p), \qquad v[f] = \nabla f\cdot v.\]
예 1.1.1 \(W = x^2U_1 + yzU_3\), \(p = (2, 1, 0)\), \(v = (-1, 0, 2)\)이면 \(v[x^2] = (4, 0, 0)\cdot v = -4\), \(v[yz] = (0, z, y)\cdot v = (0, 0, 1)\cdot v = 2\). 따라서 \(\nabla_vW = -4U_1(p) + 2U_3(p)\).

1.1.2성질

벡터장 \(V\)에 대해서도 점마다 \(\nabla_VW(p) = \nabla_{V(p)}W\)로 정의하면 새 벡터장이 됩니다.

정리 1.1.2 벡터장 \(V, W, Y, Z\), 함수 \(f, g\), 실수 \(a, b\)에 대해
  1. \(\nabla_{fV + gW}Y = f\nabla_VY + g\nabla_WY\) (아래 첨자에 대해 함수 계수 선형)
  2. \(\nabla_V(aY + bZ) = a\nabla_VY + b\nabla_VZ\)
  3. \(\nabla_V(fY) = V[f]\,Y + f\nabla_VY\) (곱의 법칙)
  4. \(V[Y\cdot Z] = \nabla_VY\cdot Z + Y\cdot\nabla_VZ\) (내적과의 호환)
증명

성분으로 \(\nabla_VY = \sum V[y_i]U_i\)이다. (1)은 \(v[f]\)가 \(v\)에 대해 선형이라서, (3)은 \(V[fy_i] = V[f]y_i + fV[y_i]\)라서, (4)는 \(Y\cdot Z = \sum y_iz_i\)에 곱의 미분법을 써서 나온다. ∎

(4)가 특히 중요합니다. \(Y\)가 단위 벡터장이면 \(Y\cdot Y = 1\)을 미분해 \(\nabla_VY\cdot Y = 0\), 즉 단위 벡터장의 공변도함수는 자기 자신과 수직입니다. 다음 절의 접속형식이 반대칭인 이유이고, 2장의 모양연산자가 접평면 안에 있는 이유입니다.

1.1.3곡선을 따라

곡선 \(\alpha(t)\)를 따라 정의된 벡터장 \(Y(t)\)의 도함수 \(Y'(t)\)는 \(Y\)가 \(\mathbb R^3\)의 벡터장 \(W\)를 \(\alpha\)에 제한한 것이면 \(Y' = \nabla_{\alpha'}W\)입니다(연쇄 법칙). 특히 \(\alpha'' = \nabla_{\alpha'}\alpha'\)이고, 곡면 위의 곡선이 "곡면 안에서 얼마나 휘는가"(4장의 측지 곡률)를 잴 때 이 식을 씁니다.

흔한 오해(1) \(\nabla_vW\)가 \(W(p)\)의 값만으로 정해진다고 여긴다. \(p\) 근처에서 \(W\)가 어떻게 변하는지가 필요하다(도함수다). (2) \(\nabla_VW = \nabla_WV\)라 여긴다. 일반적으로 다르고, 그 차이가 괄호 \([V, W]\)이다.
요약
  1. \(\nabla_vW = \frac d{dt}W(p + tv)|_0 = \sum v[w_i]U_i\).
  2. 아래 첨자에 함수 선형, 위에 곱의 법칙, 내적과 호환.
  3. 단위 벡터장의 공변도함수는 자신과 수직.

1.1.4연습문제

기본

  1. \(W = xyU_1 + zU_2\), \(V = U_1 + U_3\)일 때 \(\nabla_VW\)를 구하여라.
    답

    \(V[xy] = y\), \(V[z] = 1\). \(\nabla_VW = yU_1 + U_2\).

응용

  1. \(W = \frac{xU_1 + yU_2 + zU_3}{\sqrt{x^2 + y^2 + z^2}}\)(바깥쪽 단위 방사 벡터장)에 대해 \(p = (0, 0, r)\)에서 \(\nabla_{U_1}W\)를 구하여라.
    답

    \(p\)에서 \(U_1[\frac x\rho] = \frac1r\), \(U_1[\frac y\rho] = 0\), \(U_1[\frac z\rho] = -\frac{zx}{\rho^3} = 0\). \(\nabla_{U_1}W = \frac1rU_1\).

심화

  1. \(\nabla_VW - \nabla_WV\)가 \(f \mapsto V[W[f]] - W[V[f]]\)로 작용하는 벡터장(괄호)임을 \(V = U_1\), \(W = xU_2\)로 확인하여라.
    답

    \(\nabla_{U_1}(xU_2) = U_2\), \(\nabla_{xU_2}U_1 = 0\). 차는 \(U_2\). 한편 \(U_1[xf_y] - xU_2[f_x] = f_y + xf_{xy} - xf_{xy} = f_y = U_2[f]\).
