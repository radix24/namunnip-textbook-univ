가우스-보네 정리 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산반지름 \(R\)인 구 위에서 세 내각이 \(\frac\pi2, \frac\pi3, \frac\pi3\)인 측지 삼각형의 넓이를 구하여라. [05-02]

    힌트 1

    넓이를 \(A\)로 두면 \(\iint K\,dM = \frac A{R^2}\)이고, 내각 합에서 \(\pi\)를 뺀 값과 같다.

    힌트 2

    \(\frac\pi2 + \frac{2\pi}3 - \pi = \frac\pi6\).

    풀이

    \(\frac A{R^2} = \frac\pi6\), \(A = \frac{\pi R^2}6\) (5.2절).

  2. 계산종수 3인 곡면의 전곡률을 구하여라. [05-03]

    힌트 1

    \(\chi = 2 - 2g\).

    힌트 2

    \(2\pi\chi\).

    풀이

    \(\chi = -4\), 전곡률 \(-8\pi\) (5.3절).

  3. 계산포물면 \(z = x^2 + y^2\)에서 \(z \le 1\)인 부분의 전곡률을 5.1절의 회전면 공식 \(2\pi(h'(a) - h'(b))\)의 생각으로 구하여라. [05-01]

    힌트 1

    꼭짓점에서 단면 접선은 수평, \(z = 1\)인 테두리에서 단면 \(z = \rho^2\)의 기울기 2.

    힌트 2

    호의 길이 매개에서 \(h' = \cos\beta\) (\(\beta\)는 단면 접선이 수평과 이루는 각).

    풀이

    꼭짓점에서 \(h' = 1\), 테두리에서 \(\tan\beta = 2\)라 \(h' = \frac1{\sqrt5}\). 전곡률 \(2\pi\left(1 - \frac1{\sqrt5}\right) \approx 3.47\).

  4. 증명\(K \le 0\)인 곡면에서 측지 삼각형의 내각 합은 \(\pi\) 이하임을 보여라. [05-02]

    힌트 1

    내각 합 \(= \pi + \iint K\).

    힌트 2

    적분이 0 이하.

    풀이

    \(\iint_TK\,dM \le 0\)이라 내각 합 \(\le \pi\). ∎

  5. 계산구 위의 벡터장이 영점 3개를 가지는데 둘이 원천(지표 1)이다. 나머지 하나의 지표는? [05-05]

    힌트 1

    푸앵카레-호프.

    힌트 2

    \(\chi(S^2) = 2\).

    풀이

    \(1 + 1 + x = 2\), \(x = 0\). 지표 0인 영점(예: 원천과 안장이 붙은 것) (5.5절).

  6. 판단"달걀 모양의 곡면(\(K > 0\))에 구멍을 하나 뚫어 손잡이를 달아도 여전히 어디서나 \(K > 0\)이게 할 수 있다." 참인지 판단하여라. [05-04]

    힌트 1

    손잡이를 달면 종수 1.

    힌트 2

    전곡률 0.

    풀이

    거짓. 종수 1이 되어 전곡률이 0이므로 \(K < 0\)인 곳이 반드시 생긴다(손잡이 안쪽) (5.4절).
