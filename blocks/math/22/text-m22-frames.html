틀장과 쌍대 1-형식

본문
이 절에서 배울 것
  • 점마다 정규직교 기저를 주는 틀장 \(E_1, E_2, E_3\)와 자세 행렬 \(A\)를 정의한다.
  • 원기둥 틀장과 구면 틀장을 만든다.
  • 쌍대 1-형식 \(\theta_i(V) = V\cdot E_i\)를 구하고 \(\theta = A\,d\xi\)로 계산한다.
먼저 알아야 할 것
  • 공변도함수 (1.1절), 1-형식과 \(dx_i\) (수학13 1장), 직교행렬.

1.2.1틀장

세 벡터장 \(E_1, E_2, E_3\)가 각 점에서 \(E_i\cdot E_j = \delta_{ij}\)이면 틀장이라 합니다. 자연 틀장 \(U_i\)로 \(E_i = \sum_ja_{ij}U_j\)라 쓰면 행렬 \(A = (a_{ij})\)는 점마다 직교행렬이고, 이를 자세 행렬이라 합니다(행이 \(E_i\)의 성분). 곡선에 프레네 틀이 있었듯이, 곡면이나 문제의 대칭에 맞춘 틀장을 쓰면 계산이 단순해집니다.

1.2.2원기둥 틀장과 구면 틀장

예 1.2.1 (원기둥 틀장) 원기둥 좌표 \((r, \vartheta, z)\)에서 \[E_1 = \cos\vartheta\,U_1 + \sin\vartheta\,U_2, \quad E_2 = -\sin\vartheta\,U_1 + \cos\vartheta\,U_2, \quad E_3 = U_3.\] \(E_1\)은 축에서 멀어지는 방향, \(E_2\)는 축을 도는 방향입니다(\(z\)축 위에서는 정의되지 않음).
예 1.2.2 (구면 틀장) 구면 좌표 \((\rho, \vartheta, \varphi)\) (\(\varphi\)는 위도)에서 \[\begin{aligned}E_1 &= \cos\varphi\cos\vartheta\,U_1 + \cos\varphi\sin\vartheta\,U_2 + \sin\varphi\,U_3,\\ E_2 &= -\sin\vartheta\,U_1 + \cos\vartheta\,U_2,\\ E_3 &= -\sin\varphi\cos\vartheta\,U_1 - \sin\varphi\sin\vartheta\,U_2 + \cos\varphi\,U_3.\end{aligned}\] \(E_1\)은 바깥쪽(방사), \(E_2\)는 동쪽, \(E_3\)은 북쪽 방향입니다. 직접 내적해 정규직교임을 확인할 수 있습니다.

1.2.3쌍대 1-형식

\(\theta_i(V) = V\cdot E_i\)로 정의한 1-형식 \(\theta_1, \theta_2, \theta_3\)을 틀장의 쌍대 1-형식이라 합니다. \(V = \sum\theta_i(V)E_i\)이므로 \(\theta_i\)는 "\(E_i\) 방향 성분을 읽는 자"입니다. \(\theta_i(U_j) = a_{ij}\)라 \(\theta_i = \sum_ja_{ij}dx_j\), 행렬로 쓰면

\[\theta = A\,d\xi, \qquad \theta = \begin{pmatrix}\theta_1\\ \theta_2\\ \theta_3\end{pmatrix},\ d\xi = \begin{pmatrix}dx\\ dy\\ dz\end{pmatrix}.\]
예 1.2.3 원기둥 틀장에서 \(\theta_1 = \cos\vartheta\,dx + \sin\vartheta\,dy\)이고 \(x = r\cos\vartheta\), \(y = r\sin\vartheta\)를 미분해 넣으면 \(\theta_1 = dr\), \(\theta_2 = r\,d\vartheta\), \(\theta_3 = dz\)입니다. 원기둥 좌표의 길이 요소 \(ds^2 = dr^2 + r^2d\vartheta^2 + dz^2\)가 \(\theta_1^2 + \theta_2^2 + \theta_3^2\)로 읽힙니다.

구면 틀장에서는 같은 계산으로 \(\theta_1 = d\rho\), \(\theta_2 = \rho\cos\varphi\,d\vartheta\), \(\theta_3 = \rho\,d\varphi\)입니다(연습문제 3).

흔한 오해(1) 틀장의 벡터들이 좌표 벡터 \(\frac{\partial}{\partial\vartheta}\) 같은 것이라 여긴다. 틀장은 길이 1로 맞춘 것이라 \(\frac{\partial}{\partial\vartheta}\)(길이 \(r\))와 크기가 다르다. (2) 자세 행렬의 열이 \(E_i\)라 여긴다. 이 책의 관례는 행이 \(E_i\)이다.
요약
  1. 틀장: 점마다 정규직교, 자세 행렬 \(A\)는 직교행렬.
  2. 원기둥 틀장, 구면 틀장.
  3. 쌍대 1-형식 \(\theta = A\,d\xi\): 원기둥에서 \(dr, r\,d\vartheta, dz\).

1.2.4연습문제

기본

  1. 원기둥 틀장의 자세 행렬 \(A\)를 쓰고 \(AA^T = I\)를 확인하여라.
    답

    \(A = \begin{pmatrix}\cos\vartheta & \sin\vartheta & 0\\ -\sin\vartheta & \cos\vartheta & 0\\ 0 & 0 & 1\end{pmatrix}\), 행끼리 정규직교.

응용

  1. 벡터장 \(V = -yU_1 + xU_2\)를 원기둥 틀장으로 나타내어라.
    답

    \(\theta_1(V) = -y\cos\vartheta + x\sin\vartheta = 0\), \(\theta_2(V) = y\sin\vartheta + x\cos\vartheta = r\). \(V = rE_2\).

심화

  1. 구면 틀장의 \(\theta_2 = \rho\cos\varphi\,d\vartheta\)를 유도하여라.
    답

    \(\theta_2 = -\sin\vartheta\,dx + \cos\vartheta\,dy\), \(x = \rho\cos\varphi\cos\vartheta\), \(y = \rho\cos\varphi\sin\vartheta\)를 미분해 넣으면 \(d\rho\), \(d\varphi\) 항이 지워지고 \(\rho\cos\varphi(\sin^2\vartheta + \cos^2\vartheta)d\vartheta\)가 남는다.
