회전면, 배꼽점, 극소곡면

본문
이 절에서 배울 것
  • 회전면의 주방향이 자오선과 위선 방향임을 알고, 단위 속력 단면 곡선에서 \(K = -\frac{h''}h\)를 유도한다.
  • 원환면(도넛)의 곡률이 바깥쪽에서 양수, 안쪽에서 음수임을 계산한다.
  • 배꼽점과 극소곡면(\(H = 0\))을 정의하고, 현수면이 극소곡면임을 확인한다.
먼저 알아야 할 것
  • 가우스 곡률 공식 (2.4절), 곡선의 곡률 (수학13 2장).

2.5.1회전면

\(xz\)평면의 곡선 \((h(u), g(u))\) (\(h > 0\))를 \(z\)축 둘레로 돌린 곡면 \(\mathbf x(u, v) = (h(u)\cos v, h(u)\sin v, g(u))\)를 회전면이라 합니다. \(u\)-곡선은 자오선, \(v\)-곡선은 위선입니다. 대칭으로 이 두 방향이 주방향이고, \(F = m = 0\)입니다. 단면 곡선이 단위 속력(\(h'^2 + g'^2 = 1\))이면 \(E = 1\), \(G = h^2\)이고

\[k_{\text{mer}} = h'g'' - h''g', \qquad k_{\text{par}} = \frac{g'}h, \qquad K = -\frac{h''}h.\]

\(k_{\text{mer}}\)은 자오선(평면 곡선)의 곡률, \(k_{\text{par}}\)은 위선 방향 법곡률입니다(부호는 축 쪽 법선 기준). \(K\)는 \(h'^2 + g'^2 = 1\)을 미분한 \(h'h'' = -g'g''\)를 써서 정리하면 나옵니다(연습문제 3).

예 2.5.1 (원환면) 중심원 반지름 \(R\), 관 반지름 \(r\) (\(R > r\)): \(h = R + r\cos\frac sr\), \(g = r\sin\frac sr\) (\(s\)는 호의 길이). \(h'' = -\frac1r\cos\frac sr\)이라 \[K = \frac{\cos(s/r)}{r(R + r\cos(s/r))}.\] 바깥 적도(\(\cos = 1\))에서 \(\frac1{r(R + r)} > 0\), 안쪽 적도(\(\cos = -1\))에서 \(-\frac1{r(R - r)} < 0\), 위아래 원에서 0입니다.

2.5.2배꼽점

\(k_1 = k_2\)인 점을 배꼽점이라 합니다. 그 점에서 \(S\)는 항등의 상수배라 모든 방향이 주방향입니다.

정리 2.5.2 연결된 곡면의 모든 점이 배꼽점이면 그 곡면은 평면 또는 구의 일부이다.

증명의 핵심은 \(S = kI\)에서 \(k\)가 상수임을 보이는 것입니다(코다치 방정식, 3.4절). \(k = 0\)이면 2.1절 연습문제처럼 평면, \(k \ne 0\)이면 \(p + \frac1kU\)가 일정한 중심이 되어 구입니다.

2.5.3극소곡면

\(H = 0\)인 곡면을 극소곡면이라 합니다. 철사 고리에 비누막을 만들면 표면장력이 넓이를 줄여 극소곡면이 됩니다. 넓이를 변분하면 첫 변분이 \(-2\int H\varphi\,dA\) 꼴이라, 넓이가 (국소적으로) 최소인 곡면은 \(H = 0\)이어야 합니다.

예 2.5.3 (현수면) 현수선 \(x = \cosh z\)를 \(z\)축으로 돌린 곡면에서 자오선의 곡률은 \(\frac1{\cosh^2z}\)(\(y = \cosh x\)의 곡률), 위선 방향 법곡률은 반대 부호 \(-\frac1{\cosh^2z}\)입니다. 따라서 \(H = 0\), \(K = -\frac1{\cosh^4z}\). 두 고리 사이의 비누막이 이 모양입니다. 평면을 빼면 극소곡면인 회전면은 현수면뿐입니다.
흔한 오해(1) 극소곡면은 넓이가 전역 최소라고 여긴다. \(H = 0\)은 국소적 임계점 조건이다. (2) 회전면이면 \(K\)가 어디서나 같은 부호라 여긴다. 원환면은 바깥 양수, 안쪽 음수다.
요약
  1. 회전면(단위 속력 단면): \(K = -\frac{h''}h\), 주방향은 자오선과 위선.
  2. 모두 배꼽점이면 평면 또는 구.
  3. 극소곡면 \(H = 0\): 비누막, 현수면.

2.5.4연습문제

기본

  1. 반지름 1인 구를 \(h = \cos s\), \(g = \sin s\)인 회전면으로 보고 \(K = -\frac{h''}h\)를 계산하여라.
    답

    \(h'' = -\cos s\), \(K = 1\).

응용

  1. \(R = 3\), \(r = 1\)인 원환면에서 가우스 곡률의 최댓값과 최솟값을 구하여라.
    답

    최대 \(\frac1{1\cdot4} = \frac14\) (바깥 적도), 최소 \(-\frac1{1\cdot2} = -\frac12\) (안쪽 적도).

심화

  1. \(k_{\text{mer}} = h'g'' - h''g'\), \(k_{\text{par}} = \frac{g'}h\)에서 \(K = -\frac{h''}h\)를 유도하여라.
    답

    \(K = \frac{g'(h'g'' - h''g')}h\). \(h'h'' + g'g'' = 0\)에서 \(g'g'' = -h'h''\)이라 \(g'h'g'' = -h'^2h''\). 따라서 \(K = \frac{-h''(h'^2 + g'^2)}h = -\frac{h''}h\).
