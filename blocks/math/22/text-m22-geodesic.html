측지선과 측지선 방정식

본문

평면에서 똑바로 가는 길은 직선이다. 곡면 위에서 가속하지도 꺾지도 않고 똑바로 간다는 것은 무엇을 뜻할까? 그런 곡선은 어떤 방정식을 만족하며, 구 위에서는 어떤 곡선일까?

먼저 알아야 할 것측지 곡률(4.1절)과 제1기본형식(3.1절), 상미분방정식의 해의 존재와 유일성을 쓴다.

4.2.1정의

곡면 \(M\) 위의 곡선 \(\gamma\)의 가속도 \(\gamma''\)가 늘 \(M\)에 수직이면 \(\gamma\)를 측지선이라 한다. 곡면 위의 개미가 보기에 가속하지도 꺾지도 않고 똑바로 가는 곡선이다. 가속도의 접성분이 0이므로 \((\gamma'\cdot\gamma')' = 2\gamma''\cdot\gamma' = 0\)이라 속력이 일정하다. 그래서 단위 속력으로 두면 측지선은 \(\kappa_g = 0\)인 곡선과 같다. 가령 평면의 측지선은 직선이다.

4.2.2측지선 방정식

\(\gamma(t) = \mathbf x(u(t), v(t))\)라 하면 \(\gamma''\)가 \(\mathbf x_u\)와 \(\mathbf x_v\)에 수직이라는 두 조건이 측지선 방정식이다. \(F = 0\)이면 이를 다음과 같이 정리할 수 있다.

\[\frac d{dt}(Eu') = \frac12\left(E_uu'^2 + G_uv'^2\right), \qquad \frac d{dt}(Gv') = \frac12\left(E_vu'^2 + G_vv'^2\right)\]

유도.\(\gamma''\cdot\mathbf x_u = \frac d{dt}(\gamma'\cdot\mathbf x_u) - \gamma'\cdot\frac d{dt}\mathbf x_u\)이고 \(\gamma'\cdot\mathbf x_u = Eu'\)이다. 또 \(F = 0\)에서 \(\mathbf x_u\cdot\mathbf x_{uu} = \frac12E_u\), \(\mathbf x_v\cdot\mathbf x_{uv} = \frac12G_u\), \(\mathbf x_u\cdot\mathbf x_{uv} = \frac12E_v\), \(\mathbf x_v\cdot\mathbf x_{uu} = -\frac12E_v\)을 써서 정리하면 \(\gamma'\cdot(\mathbf x_{uu}u' + \mathbf x_{uv}v') = \frac12(E_uu'^2 + G_uv'^2)\)이다. 둘째 식도 같은 방법으로 얻는다. ∎

방정식에 \(E, F, G\)만 나오므로 측지선은 내재적인 개념이다. 예를 들어 원기둥의 측지선은 펼친 평면의 직선을 다시 만 것이므로 나선, 원, 직선이다.

4.2.3구의 측지선

정리 4.2.1

구의 측지선은 대원, 곧 중심을 지나는 평면과 구의 교선을 일정한 속력으로 도는 곡선이다.

증명.정규직교인 \(a, b\)로 쓴 대원 \(\gamma(t) = r(\cos t\,a + \sin t\,b)\)는 \(\gamma'' = -\gamma\)이므로 가속도가 구의 법선 방향이고, 따라서 측지선이다. 한 점과 그 점의 단위 접벡터마다 이런 대원이 하나씩 있으므로, 아래의 존재와 유일성 정리에 의해 다른 측지선은 없다. ∎

정리 4.2.2

곡면의 점 \(p\)와 접벡터 \(v\)마다 \(\gamma(0) = p\), \(\gamma'(0) = v\)인 측지선이 짧은 시간 동안 꼭 하나 있다.

측지선 방정식은 \(u, v\)에 대한 이계 상미분방정식이므로, 초기 위치와 속도가 해를 결정한다. 그래서 그림 1의 위선처럼 대원이 아닌 위선은 적도를 빼면 측지선이 아니며, 이는 4.1절에서 구한 \(\kappa_g \ne 0\)과 맞는다.

흔한 오해측지선이 늘 두 점 사이의 최단 경로라고 여기기 쉽지만, 구에서 대원의 긴 호도 측지선이다. 측지선은 4.4절에서 보듯 짧은 구간에서만 최단이다. 또 속력이 변해도 자취가 같으면 측지선이라고 생각하는 것도 틀렸다. 정의상 측지선은 속력이 일정해야 한다.
마무리

처음 질문에 답하면, 곡면 위에서 똑바로 간다는 것은 가속도가 늘 곡면에 수직이라는 뜻이며, 그런 곡선이 측지선이다. 측지선은 \(E, F, G\)만으로 쓰이는 이계 상미분방정식을 만족하므로 내재적이고, 시작점과 속도마다 하나씩 있다. 구에서는 대원이 바로 측지선이다.

4.2.4연습문제

기본

  1. 원기둥 \((\cos u, \sin u, v)\) (\(E = G = 1\), \(F = 0\))의 측지선 방정식을 풀어라.
    답

    \(u'' = 0\), \(v'' = 0\). \(u = at + b\), \(v = ct + d\): 나선(특별한 경우 원, 직선).

응용

  1. 원기둥 위 두 점 \((1, 0, 0)\)과 \((1, 0, 2\pi)\)을 잇는 측지선은 몇 개인가?
    답

    펼친 평면에서 \((0, 0)\)과 \((2\pi k, 2\pi)\)를 (잇는 직선마다 하나) 무한히 많다(\(k \in \mathbb Z\)). \(k = 0\)인 직선이 가장 짧다.

심화

  1. 구의 위도 좌표(\(E = r^2\), \(G = r^2\cos^2u\))에서 둘째 측지선 방정식이 \(\cos^2u\cdot v' = c\) (상수)임을 보이고 적도가 해임을 확인하여라.
    답

    \(G_v = E_v = 0\)이라 \((Gv')' = 0\), \(r^2\cos^2u\,v' = \) 상수. 적도 \(u = 0\), \(v = t\)는 첫 식 \((r^2u')' = \frac12G_uv'^2 = -r^2\cos u\sin u\,v'^2 = 0\)도 만족.
