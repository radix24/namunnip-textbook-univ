모양연산자와 곡률 연습 문제

문제 6 · 계산·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산곡면 \(z = 2x^2 - y^2\)의 원점에서 위쪽 법선으로 주곡률, \(K\), \(H\)를 구하여라. [02-02 02-04]

    힌트 1

    원점의 \([S]\)는 헤세 행렬.

    힌트 2

    \(f_{xx} = 4\), \(f_{yy} = -2\).

    풀이

    주곡률 4(\(x\) 방향), \(-2\)(\(y\) 방향). \(K = -8\), \(H = 1\) (2.2절).

  2. 계산1번 점에서 \(x\)축과 45°인 방향의 법곡률과 점근 방향을 구하여라. [02-03]

    힌트 1

    오일러 공식.

    힌트 2

    \(\tan^2\theta = -\frac{k_1}{k_2}\).

    풀이

    \(4\cdot\frac12 - 2\cdot\frac12 = 1\). 점근 방향 \(\tan^2\theta = 2\), \(\theta \approx \pm54.7°\) (2.3절).

  3. 계산곡면 \(z = \ln\cos x - \ln\cos y\) (셰르크 곡면)이 극소곡면임을 그래프 곡면의 \(H\) 공식 \(H = \frac{(1 + f_y^2)f_{xx} - 2f_xf_yf_{xy} + (1 + f_x^2)f_{yy}}{2W^3}\)으로 확인하여라. [02-04 02-05]

    힌트 1

    \(f_x = -\tan x\), \(f_y = \tan y\), \(f_{xy} = 0\).

    힌트 2

    \(f_{xx} = -\sec^2x\), \(f_{yy} = \sec^2y\).

    풀이

    분자 \((1 + \tan^2y)(-\sec^2x) + (1 + \tan^2x)\sec^2y = -\sec^2y\sec^2x + \sec^2x\sec^2y = 0\). \(H = 0\).

  4. 계산\(R = 2\), \(r = 1\)인 원환면에서 \(K = 0\)인 점들의 위치를 말하고, 위쪽 원(관의 맨 위)에서 주곡률을 구하여라. [02-05]

    힌트 1

    \(K = \frac{\cos u}{r(R + r\cos u)}\).

    힌트 2

    위쪽 원에서 자오선(관의 단면 원) 곡률은 \(\frac1r\).

    풀이

    \(\cos u = 0\)인 위쪽 원과 아래쪽 원. 거기서 주곡률은 \(\frac1r = 1\)(관을 도는 방향)과 0(위선 방향). 포물점이다.

  5. 계산반지름 3인 구에서 안쪽 법선을 쓸 때 모양연산자, \(K\), \(H\)를 쓰고, 모든 점이 배꼽점임을 확인하여라. [02-01 02-05]

    힌트 1

    \(U = -\frac p3\).

    힌트 2

    \(S = -\nabla U\).

    풀이

    \(S = \frac13I\), \(K = \frac19\), \(H = \frac13\). \(k_1 = k_2\)라 모든 점이 배꼽점 (2.1절).

  6. 판단"평균곡률이 0이면 곡면은 평면이다." 참인지 판단하여라. [02-05]

    힌트 1

    현수면.

    힌트 2

    \(H = 0\)이면 \(k_2 = -k_1\).

    풀이

    거짓. 현수면, 나선면, 셰르크 곡면은 \(H = 0\)이지만 \(K < 0\)인 쌍곡점으로 이루어진 휘어진 곡면이다. \(K\)와 \(H\)가 모두 0일 때만 평면점이다.
