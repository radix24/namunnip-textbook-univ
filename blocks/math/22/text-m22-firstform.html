제1기본형식과 내재적 측정

본문
이 절에서 배울 것
  • 제1기본형식 \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\)으로 곡면 위 곡선의 길이를 계산한다.
  • 두 곡선이 만나는 각과 영역의 넓이 \(\iint\sqrt{EG - F^2}\,du\,dv\)를 계산한다.
  • "곡면 위의 존재가 잴 수 있는 양"이라는 내재적 기하의 뜻을 이해한다.
먼저 알아야 할 것
  • 매개곡면과 \(E, F, G\) (수학13 4장), 이중적분.

3.1.1길이

곡면 위 곡선 \(\alpha(t) = \mathbf x(u(t), v(t))\)의 속도는 \(\alpha' = u'\mathbf x_u + v'\mathbf x_v\)이므로

\[|\alpha'|^2 = Eu'^2 + 2Fu'v' + Gv'^2, \qquad L = \int_a^b\sqrt{Eu'^2 + 2Fu'v' + Gv'^2}\,dt.\]

곡선의 길이는 \(\mathbb R^3\)에서 곡면이 어떻게 놓였는지 몰라도 \(E, F, G\)만 알면 계산됩니다. 그래서 \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\)을 곡면의 계량이라고도 합니다.

예 3.1.1 반지름 \(r\)인 구를 \(\mathbf x(u, v) = r(\cos u\cos v, \cos u\sin v, \sin u)\) (\(u\)는 위도, \(v\)는 경도)로 매개화하면 \(E = r^2\), \(F = 0\), \(G = r^2\cos^2u\)입니다. 위도 \(u_0\)인 위선(\(v\)가 0에서 \(2\pi\)까지)의 길이는 \(\int_0^{2\pi}r\cos u_0\,dv = 2\pi r\cos u_0\)입니다.

3.1.2각과 넓이

두 접벡터 \(a\mathbf x_u + b\mathbf x_v\)와 \(c\mathbf x_u + d\mathbf x_v\)의 내적은 \(Eac + F(ad + bc) + Gbd\)이므로 각도도 \(E, F, G\)로 정해집니다. 특히 좌표 곡선끼리의 각은 \(\cos\theta = \frac F{\sqrt{EG}}\)이고, \(F = 0\)이면 좌표 곡선이 서로 수직입니다. 넓이는 \(|\mathbf x_u\times\mathbf x_v| = \sqrt{EG - F^2}\)에서

\[A = \iint_D\sqrt{EG - F^2}\,du\,dv.\]
예 3.1.2 구의 넓이: \(\sqrt{EG - F^2} = r^2\cos u\)라 \(\int_0^{2\pi}\int_{-\pi/2}^{\pi/2}r^2\cos u\,du\,dv = 4\pi r^2\). 원환면 \(\mathbf x = ((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\)은 \(E = r^2\), \(F = 0\), \(G = (R + r\cos u)^2\)이라 넓이 \(\int_0^{2\pi}\int_0^{2\pi}r(R + r\cos u)\,du\,dv = 4\pi^2Rr\)입니다.

3.1.3내재적 기하

곡면 위에 사는 2차원 존재(곡면 밖을 볼 수 없는 개미)는 줄자와 각도기로 길이, 각, 넓이를 잽니다. 이 모든 것이 \(E, F, G\)로 정해지므로, 제1기본형식으로 정해지는 양을 내재적이라 합니다. 법선이나 모양연산자처럼 곡면이 공간에 놓인 방식에 의존하는 양은 외재적입니다. 놀라운 점은 외재적으로 정의한 가우스 곡률이 사실 내재적이라는 것입니다(3.3절).

흔한 오해(1) 매개변수 평면의 거리 \(\sqrt{du^2 + dv^2}\)가 곡면 위의 거리라 여긴다. \(E, F, G\)로 가중해야 한다. 구의 경도 1°는 적도에서 길고 극에서 0이다. (2) 넓이 요소를 \(EG\)로 쓴다. \(\sqrt{EG - F^2}\)이다.
요약
  1. \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\).
  2. 각은 \(E, F, G\)의 내적으로, 넓이는 \(\iint\sqrt{EG - F^2}\).
  3. 제1기본형식으로 정해지는 양이 내재적.

3.1.4연습문제

기본

  1. 원뿔 \(\mathbf x(u, v) = (u\cos v, u\sin v, u)\)의 \(E, F, G\)를 구하여라.
    답

    \(\mathbf x_u = (\cos v, \sin v, 1)\), \(\mathbf x_v = (-u\sin v, u\cos v, 0)\). \(E = 2\), \(F = 0\), \(G = u^2\).

응용

  1. 반지름 1인 구에서 북위 60° 이북의 넓이를 구하여라.
    답

    \(2\pi\int_{\pi/3}^{\pi/2}\cos u\,du = 2\pi\left(1 - \frac{\sqrt3}2\right) \approx 0.842\).

심화

  1. 구 위의 곡선 \(v = \ln\tan\left(\frac\pi4 + \frac u2\right)\) (항정선)이 모든 경선과 45°로 만남을 보여라.
    답

    \(\frac{dv}{du} = \frac1{\cos u}\). 접벡터 \(\mathbf x_u + \frac1{\cos u}\mathbf x_v\)와 \(\mathbf x_u\)의 각: \(\cos\theta = \frac E{\sqrt E\sqrt{E + G/\cos^2u}} = \frac{r^2}{r\sqrt{2r^2}} = \frac1{\sqrt2}\).
