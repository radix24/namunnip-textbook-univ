제1기본형식과 내재적 측정

본문

곡면 위에 사는 개미는 곡면 밖을 볼 수 없고, 줄자와 각도기로만 곡면을 잰다. 개미가 잴 수 있는 길이, 각, 넓이는 매개화에서 어떤 양으로 정해질까? 매개변수 평면에서 같은 크기의 칸이 곡면 위에서도 같은 크기일까?

먼저 알아야 할 것매개곡면과 \(E, F, G\)(수학13 4장), 이중적분을 쓴다.

3.1.1길이

곡면 위의 곡선 \(\alpha(t) = \mathbf x(u(t), v(t))\)의 속도는 \(\alpha' = u'\mathbf x_u + v'\mathbf x_v\)이므로 다음이 성립한다.

\[|\alpha'|^2 = Eu'^2 + 2Fu'v' + Gv'^2, \qquad L = \int_a^b\sqrt{Eu'^2 + 2Fu'v' + Gv'^2}\,dt\]

즉 곡선의 길이는 곡면이 \(\mathbb R^3\)에 어떻게 놓였는지 몰라도 \(E, F, G\)만 알면 계산된다. 그래서 \(ds^2 = E\,du^2 + 2F\,du\,dv + G\,dv^2\)을 곡면의 계량이라고도 한다.

예제 3.1.1

반지름 \(r\)인 구를 위도 \(u\)와 경도 \(v\)로 \(\mathbf x(u, v) = r(\cos u\cos v, \cos u\sin v, \sin u)\)라 매개화할 때, 제1기본형식과 위도 \(u_0\)인 위선의 길이를 구하여라.

풀이. \(E = r^2\), \(F = 0\), \(G = r^2\cos^2u\)이다. 위선은 \(u = u_0\)이고 \(v\)가 0에서 \(2\pi\)까지 가므로 길이는 \(\int_0^{2\pi}r\cos u_0\,dv = 2\pi r\cos u_0\)이다.

3.1.2각과 넓이

두 접벡터 \(a\mathbf x_u + b\mathbf x_v\)와 \(c\mathbf x_u + d\mathbf x_v\)의 내적은 \(Eac + F(ad + bc) + Gbd\)이므로 각도 \(E, F, G\)로 정해진다. 특히 좌표 곡선끼리의 각은 \(\cos\theta = \frac F{\sqrt{EG}}\)이므로, \(F = 0\)이면 좌표 곡선이 서로 수직이다. 넓이는 \(|\mathbf x_u\times\mathbf x_v| = \sqrt{EG - F^2}\)에서 다음과 같다.

\[A = \iint_D\sqrt{EG - F^2}\,du\,dv\]
예제 3.1.2

구와 원환면 \(\mathbf x = ((R + r\cos u)\cos v, (R + r\cos u)\sin v, r\sin u)\)의 넓이를 구하여라.

풀이. 구에서는 \(\sqrt{EG - F^2} = r^2\cos u\)이므로 넓이는 \(\int_0^{2\pi}\int_{-\pi/2}^{\pi/2}r^2\cos u\,du\,dv = 4\pi r^2\)이다. 원환면에서는 \(E = r^2\), \(F = 0\), \(G = (R + r\cos u)^2\)이므로 넓이는 \(\int_0^{2\pi}\int_0^{2\pi}r(R + r\cos u)\,du\,dv = 4\pi^2Rr\)이다.

그림 1의 두 칸을 비교하면 넓이 요소의 뜻이 보인다. 위도 \(0°\)에서 \(15°\)까지의 칸과 \(60°\)에서 \(75°\)까지의 칸의 넓이 비는 \(\frac{\sin75° - \sin60°}{\sin15°} \approx 0.39\)이다.

3.1.3내재적 기하

곡면 위에 사는 2차원 존재는 줄자와 각도기로 길이, 각, 넓이를 잰다. 이 모든 것이 \(E, F, G\)로 정해지므로, 제1기본형식으로 정해지는 양을 내재적이라 한다. 반면 법선이나 모양연산자처럼 곡면이 공간에 놓인 방식에 의존하는 양은 외재적이다. 그런데 외재적으로 정의한 가우스 곡률이 사실은 내재적이라는 것이 3.3절의 내용이다.

흔한 오해매개변수 평면의 거리 \(\sqrt{du^2 + dv^2}\)가 곡면 위의 거리라고 여기기 쉽지만, \(E, F, G\)로 가중해야 한다. 가령 구에서 경도 1°는 적도에서 가장 길고 극에서 0이다. 또 넓이 요소를 \(EG\)나 \(\sqrt{EG}\)로 쓰는 것도 틀렸다. 넓이 요소는 \(\sqrt{EG - F^2}\)이다.
마무리

처음 질문에 답하면, 곡면 위의 길이, 각, 넓이는 모두 제1기본형식 \(E, F, G\)로 정해지며, 이렇게 정해지는 양을 내재적이라 한다. 매개변수 평면에서 같은 크기의 칸도 곡면 위에서는 넓이 요소 \(\sqrt{EG - F^2}\)에 따라 크기가 다르며, 구에서는 위도가 높을수록 작아진다.

3.1.4연습문제

기본

  1. 원뿔 \(\mathbf x(u, v) = (u\cos v, u\sin v, u)\)의 \(E, F, G\)를 구하여라.
    답

    \(\mathbf x_u = (\cos v, \sin v, 1)\), \(\mathbf x_v = (-u\sin v, u\cos v, 0)\). \(E = 2\), \(F = 0\), \(G = u^2\).

응용

  1. 반지름 1인 구에서 북위 60° 이북의 넓이를 구하여라.
    답

    \(2\pi\int_{\pi/3}^{\pi/2}\cos u\,du = 2\pi\left(1 - \frac{\sqrt3}2\right) \approx 0.842\).

심화

  1. 구 위의 곡선 \(v = \ln\tan\left(\frac\pi4 + \frac u2\right)\) (항정선)이 모든 경선과 45°로 만남을 보여라.
    답

    \(\frac{dv}{du} = \frac1{\cos u}\). 접벡터 \(\mathbf x_u + \frac1{\cos u}\mathbf x_v\)와 \(\mathbf x_u\)(의 각) \(\cos\theta = \frac E{\sqrt E\sqrt{E + G/\cos^2u}} = \frac{r^2}{r\sqrt{2r^2}} = \frac1{\sqrt2}\).
