구면 틀장에서 첫째 구조방정식 확인

예제 · 외미분과 외곱 계산

먼저 예측

\(d\theta_2 = \omega_{21}\wedge\theta_1 + \omega_{23}\wedge\theta_3\)의 우변 두 항은 각각 좌변의 어느 항과 짝이 될까요?

예측 확인

\(\omega_{21}\wedge\theta_1\)은 \(d\rho\wedge d\vartheta\) 항, \(\omega_{23}\wedge\theta_3\)은 \(d\varphi\wedge d\vartheta\) 항과 짝입니다.

구면 틀장의 \(\theta_1 = d\rho\), \(\theta_2 = \rho\cos\varphi\,d\vartheta\), \(\theta_3 = \rho\,d\varphi\), \(\omega_{12} = \cos\varphi\,d\vartheta\), \(\omega_{13} = d\varphi\), \(\omega_{23} = \sin\varphi\,d\vartheta\)에 대해 \(d\theta_2 = \sum_j\omega_{2j}\wedge\theta_j\)를 확인하여라.

전략

좌변은 곱의 외미분 \(d(f\,d\vartheta) = df\wedge d\vartheta\), 우변은 반대칭 \(\omega_{21} = -\omega_{12}\)를 쓰고 외곱의 순서를 맞춥니다(1.4절).

풀이

  1. \(d\theta_2 = d(\rho\cos\varphi)\wedge d\vartheta = \cos\varphi\,d\rho\wedge d\vartheta - \rho\sin\varphi\,d\varphi\wedge d\vartheta\).
    \(d(\rho\cos\varphi) = \cos\varphi\,d\rho - \rho\sin\varphi\,d\varphi\).
  2. \(\omega_{21}\wedge\theta_1 = -\cos\varphi\,d\vartheta\wedge d\rho = \cos\varphi\,d\rho\wedge d\vartheta\).
    순서를 바꾸면 부호가 바뀜.
  3. \(\omega_{23}\wedge\theta_3 = \sin\varphi\,d\vartheta\wedge\rho\,d\varphi = -\rho\sin\varphi\,d\varphi\wedge d\vartheta\).
    같은 이유.
  4. 두 항의 합이 1번과 같다. (\(\omega_{22} = 0\)이라 \(j = 2\) 항은 없다.)
    첫째 구조방정식 성립.

검산

둘째 구조방정식 하나도 확인합니다. \(d\omega_{23} = \cos\varphi\,d\varphi\wedge d\vartheta\), \(\omega_{21}\wedge\omega_{13} = -\cos\varphi\,d\vartheta\wedge d\varphi = \cos\varphi\,d\varphi\wedge d\vartheta\). 같습니다.

의미

구조방정식은 틀장과 무관하게 늘 성립하는 항등식이지만, 계산해 보면 접속형식의 각 항이 쌍대 형식의 어떤 변화를 담당하는지 보입니다. 반지름 \(\rho\)인 구면에 제한하면 \(d\rho = 0\)이라 \(\theta_1 = 0\)이 되고, 이것이 곡면 위의 적응 틀장(\(E_1\)이 법선)입니다.

이해 확인

\(d\theta_1 = \omega_{12}\wedge\theta_2 + \omega_{13}\wedge\theta_3\)을 확인하여라.

답

좌변 0. 우변 \(\cos\varphi\,d\vartheta\wedge\rho\cos\varphi\,d\vartheta + d\varphi\wedge\rho\,d\varphi = 0 + 0\).
