공변도함수와 틀장 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(W = yU_1 - xU_2 + z^2U_3\), \(v = (1, 2, 1)\)이 점 \(p = (0, 0, 3)\)에서의 접벡터일 때 \(\nabla_vW\)를 구하여라. [01-01]

    힌트 1

    성분마다 \(v[w_i] = \nabla w_i\cdot v\).

    힌트 2

    \(\nabla(z^2) = (0, 0, 2z)\).

    풀이

    \(v[y] = 2\), \(v[-x] = -1\), \(v[z^2] = 2\cdot3\cdot1 = 6\). \(\nabla_vW = 2U_1 - U_2 + 6U_3\) (1.1절).

  2. 증명\(Y\)가 길이가 일정한 벡터장이면 모든 \(V\)에 대해 \(\nabla_VY\cdot Y = 0\)임을 보여라. [01-01]

    힌트 1

    \(Y\cdot Y\)는 상수.

    힌트 2

    내적과의 호환성.

    풀이

    \(0 = V[Y\cdot Y] = 2\nabla_VY\cdot Y\). ∎

  3. 계산원기둥 틀장의 자세 행렬 \(A\)로 \(\omega = dA\,A^T\)를 계산해 \(\omega_{12} = d\vartheta\)를 확인하여라. [01-02 01-03]

    힌트 1

    \(A\)의 첫 행 \((\cos\vartheta, \sin\vartheta, 0)\)을 미분.

    힌트 2

    둘째 행 \((-\sin\vartheta, \cos\vartheta, 0)\)과 내적.

    풀이

    첫 행을 미분하면 \((-\sin\vartheta, \cos\vartheta, 0)d\vartheta\), 둘째 행과의 내적 \((\sin^2\vartheta + \cos^2\vartheta)d\vartheta = d\vartheta\). 셋째 행과는 0 (1.3절).

  4. 계산구면 틀장에서 \(\nabla_{E_2}E_1\)을 구하여라(점은 반지름 \(\rho\), 위도 \(\varphi\)). [01-03]

    힌트 1

    \(\nabla_VE_1 = \omega_{12}(V)E_2 + \omega_{13}(V)E_3\).

    힌트 2

    \(d\vartheta(E_2) = \frac1{\rho\cos\varphi}\), \(d\varphi(E_2) = 0\).

    풀이

    \(\omega_{12}(E_2) = \cos\varphi\cdot\frac1{\rho\cos\varphi} = \frac1\rho\), \(\omega_{13}(E_2) = 0\). \(\nabla_{E_2}E_1 = \frac1\rho E_2\). 반지름 \(\rho\)인 구에서 동쪽으로 가면 방사 방향이 동쪽으로 \(\frac1\rho\) 비율로 기운다.

  5. 증명구조방정식 \(d\omega = \omega\wedge\omega\)의 \((1, 2)\) 성분이 \(d\omega_{12} = \omega_{13}\wedge\omega_{32}\)임을 반대칭성으로 설명하여라. [01-04]

    힌트 1

    \(\sum_k\omega_{1k}\wedge\omega_{k2}\)의 \(k = 1, 2, 3\).

    힌트 2

    \(\omega_{11} = \omega_{22} = 0\).

    풀이

    \(k = 1\): \(\omega_{11} = 0\), \(k = 2\): \(\omega_{22} = 0\). 남는 것은 \(k = 3\)의 \(\omega_{13}\wedge\omega_{32}\) (1.4절).

  6. 판단"자연 틀장 \(U_1, U_2, U_3\)의 접속형식은 0이므로, 어떤 틀장이든 접속형식은 0이다." 참인지 판단하여라. [01-03]

    힌트 1

    원기둥 틀장.

    힌트 2

    접속형식은 틀장이 점마다 도는 정도.

    풀이

    거짓. 원기둥 틀장은 \(\omega_{12} = d\vartheta \ne 0\). 접속형식은 공간이 아니라 틀장이 회전하는 정도를 재며, 평행한 틀장만 0이다.
