법곡률과 측지 곡률

본문
이 절에서 배울 것
  • 곡면 위 단위 속력 곡선의 가속도를 법선 성분과 접평면 성분으로 나눈다.
  • 법곡률 \(\kappa_n\)과 측지 곡률 \(\kappa_g\)를 정의하고 \(\kappa^2 = \kappa_n^2 + \kappa_g^2\)을 보인다.
  • 구의 위선의 측지 곡률을 계산한다.
먼저 알아야 할 것
  • 곡선의 곡률 (수학13 2장), 법곡률 (2.2절).

4.1.1가속도의 분해

곡면 \(M\)(단위 법선 \(U\)) 위의 단위 속력 곡선 \(\alpha(s)\)에 대해 \(T = \alpha'\)이라 하고, 접평면에서 \(T\)에 수직인 단위 벡터 \(V = U\times T\)를 잡습니다. \(T, V, U\)는 곡선을 따라가는 정규직교 틀(다르부 틀)입니다. \(T'\cdot T = 0\)이므로

\[T' = \kappa_g\,V + \kappa_n\,U, \qquad \kappa_n = T'\cdot U = S(T)\cdot T, \qquad \kappa_g = T'\cdot V.\]

\(\kappa_n\)은 그 방향의 법곡률(2.2절)로, 곡면이 휘어서 곡선이 어쩔 수 없이 휘는 부분입니다. \(\kappa_g\)는 측지 곡률로, 곡면 위의 개미가 느끼는 "좌우로 꺾는" 정도입니다. 곡선의 곡률 \(\kappa = |T'|\)에 대해 \(\kappa^2 = \kappa_g^2 + \kappa_n^2\)입니다.

4.1.2예

예 4.1.1 (구의 위선) 반지름 \(r\)인 구의 위도 \(\varphi_0\) 위선은 반지름 \(r\cos\varphi_0\)인 원이라 \(\kappa = \frac1{r\cos\varphi_0}\)입니다. 구의 모든 방향의 법곡률은 (안쪽 법선으로) \(\kappa_n = \frac1r\)이므로 \[\kappa_g^2 = \frac1{r^2\cos^2\varphi_0} - \frac1{r^2} = \frac{\tan^2\varphi_0}{r^2}, \qquad |\kappa_g| = \frac{|\tan\varphi_0|}r.\] 적도(\(\varphi_0 = 0\))에서만 \(\kappa_g = 0\)이고, 극에 가까울수록 위선은 개미가 보기에도 심하게 꺾이는 작은 원입니다.
예 4.1.2 (평면) 평면에서는 \(\kappa_n = 0\)이라 \(\kappa_g = \pm\kappa\)로, 측지 곡률은 평면 곡선의 (부호 있는) 곡률 그대로입니다.

4.1.3내재적 성질

\(\kappa_g\)는 곡면 안에서 정해지는 양입니다. 접평면 안에서 \(T\)를 미분한 성분은 공변도함수의 접성분 \(\nabla_TT\)의 접평면 사영으로, 적응 틀장으로 쓰면 \(\kappa_g\)는 \(\omega_{12}\)와 곡선이 틀장과 이루는 각의 변화로 표현됩니다.

\[\kappa_g = \frac{d\phi}{ds} + \omega_{12}(T),\]

여기서 \(\phi\)는 \(T\)가 \(E_1\)과 이루는 각입니다. \(\omega_{12}\)는 \(\theta_1, \theta_2\)만으로 정해지므로(3.3절) \(\kappa_g\)는 내재적이고, 국소 등장사상으로 보존됩니다. 5장의 가우스-보네 정리에서 이 식을 경계를 따라 적분합니다.

흔한 오해(1) 곡면 위 곡선의 곡률이 모두 측지 곡률이라 여긴다. 곡면이 휘어 생기는 법곡률 성분이 따로 있다. (2) 구의 위선은 모두 "곧은" 길이라 여긴다. 적도만 \(\kappa_g = 0\)이다.
요약
  1. \(T' = \kappa_gV + \kappa_nU\), \(V = U\times T\).
  2. \(\kappa^2 = \kappa_g^2 + \kappa_n^2\), \(\kappa_n = S(T)\cdot T\).
  3. 구의 위선: \(|\kappa_g| = \frac{|\tan\varphi_0|}r\). \(\kappa_g\)는 내재적.

4.1.4연습문제

기본

  1. 반지름 2인 구에서 북위 45° 위선의 \(\kappa\), \(\kappa_n\), \(|\kappa_g|\)를 구하여라.
    답

    \(\kappa = \frac1{2\cos45°} = \frac1{\sqrt2}\), \(\kappa_n = \frac12\), \(|\kappa_g| = \frac{\tan45°}2 = \frac12\).

응용

  1. 반지름 \(r\)인 원기둥 위의 나선 \(\alpha(s) = (r\cos\frac sc, r\sin\frac sc, \frac{bs}c)\) (\(c = \sqrt{r^2 + b^2}\))의 측지 곡률을 구하여라.
    답

    \(\alpha'' = -\frac r{c^2}(\cos\frac sc, \sin\frac sc, 0)\)은 원기둥의 법선 방향이라 \(\kappa_g = 0\). 나선은 원기둥의 측지선이다.

심화

  1. 곡면 위 곡선이 직선이면 \(\kappa_g = \kappa_n = 0\)임을 보이고, 안장면 \(z = xy\) 위의 직선을 하나 찾아라.
    답

    직선은 \(T' = 0\)이라 두 성분이 모두 0. \(x\)축(\(y = 0\), \(z = 0\))이 곡면 위에 있다. 이 방향은 점근 방향이다(\(\kappa_n = 0\)).
