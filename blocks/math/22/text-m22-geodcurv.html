법곡률과 측지 곡률

본문

구의 위선을 따라 걷는 개미는 자기가 똑바로 간다고 느낄까, 아니면 한쪽으로 꺾는다고 느낄까? 곡면 위 곡선의 휘어짐 가운데 곡면 자체가 휘어서 생기는 부분과 곡면 안에서 꺾어서 생기는 부분을 어떻게 나눌 수 있을까?

먼저 알아야 할 것법곡률(2.2절), 곡선의 프레네 틀(수학13), 접속형식(1.3절)을 쓴다.

4.1.1가속도의 분해

단위 법선이 \(U\)인 곡면 \(M\) 위의 단위 속력 곡선 \(\alpha(s)\)에 대해 \(T = \alpha'\)이라 하고, 접평면에서 \(T\)에 수직인 단위 벡터 \(V = U\times T\)를 잡는다. 그러면 \(T, V, U\)는 곡선을 따라가는 정규직교 틀이며, 이를 다르부 틀이라 한다. \(T'\cdot T = 0\)이므로 다음과 같이 쓸 수 있다.

\[T' = \kappa_g\,V + \kappa_n\,U, \qquad \kappa_n = T'\cdot U = S(T)\cdot T, \qquad \kappa_g = T'\cdot V\]

여기서 \(\kappa_n\)은 2.2절의 법곡률로, 곡면이 휘어서 곡선이 어쩔 수 없이 휘는 부분이다. 반면 \(\kappa_g\)는 측지 곡률이라 하며, 곡면 위의 개미가 느끼는 좌우로 꺾는 정도이다. 곡선의 곡률 \(\kappa = |T'|\)에 대해 \(\kappa^2 = \kappa_g^2 + \kappa_n^2\)이다.

4.1.2예

예제 4.1.1

반지름 \(r\)인 구의 위도 \(\varphi_0\) 위선의 측지 곡률을 구하여라.

풀이. 위선은 반지름이 \(r\cos\varphi_0\)인 원이므로 \(\kappa = \frac1{r\cos\varphi_0}\)이다. 안쪽 법선을 주면 구의 모든 방향의 법곡률은 \(\kappa_n = \frac1r\)이므로 다음과 같다.

\[\kappa_g^2 = \frac1{r^2\cos^2\varphi_0} - \frac1{r^2} = \frac{\tan^2\varphi_0}{r^2}, \qquad |\kappa_g| = \frac{|\tan\varphi_0|}r\]

따라서 적도(\(\varphi_0 = 0\))에서만 \(\kappa_g = 0\)이고, 그림 1처럼 극에 가까울수록 위선은 개미가 보기에도 심하게 꺾이는 작은 원이다.

예제 4.1.2

평면 위 곡선의 측지 곡률은 무엇인가?

풀이. 평면에서는 \(\kappa_n = 0\)이므로 \(\kappa_g = \pm\kappa\)이다. 즉 측지 곡률은 평면 곡선의 부호 있는 곡률 그대로이다.

4.1.3내재적 성질

\(\kappa_g\)는 곡면 안에서 정해지는 양이다. 접평면 안에서 \(T\)를 미분한 성분은 공변도함수 \(\nabla_TT\)를 접평면에 사영한 것이므로, 적응 틀장으로 쓰면 \(\kappa_g\)는 \(\omega_{12}\)와 곡선이 틀장과 이루는 각의 변화로 표현된다. \(T\)가 \(E_1\)과 이루는 각을 \(\phi\)라 하면 다음과 같다.

\[\kappa_g = \frac{d\phi}{ds} + \omega_{12}(T)\]

그런데 3.3절에서 \(\omega_{12}\)는 \(\theta_1, \theta_2\)만으로 정해졌다. 그러므로 \(\kappa_g\)는 내재적이고 국소 등장사상으로 보존된다. 5장의 가우스-보네 정리에서 이 식을 경계를 따라 적분한다.

흔한 오해곡면 위 곡선의 곡률이 모두 측지 곡률이라고 여기기 쉽지만, 곡면이 휘어서 생기는 법곡률 성분이 따로 있다. 또 구의 위선은 모두 곧은 길이라고 생각하는 것도 틀렸다. 위선 가운데 \(\kappa_g = 0\)인 것은 적도뿐이다.
마무리

처음 질문에 답하면, 곡선의 가속도는 곡면이 휘어서 생기는 법곡률 \(\kappa_n\)과 곡면 안에서 꺾는 측지 곡률 \(\kappa_g\)로 나뉘며 \(\kappa^2 = \kappa_g^2 + \kappa_n^2\)이다. 구의 위선을 걷는 개미는 \(|\kappa_g| = \frac{|\tan\varphi_0|}r\)만큼 꺾는다고 느끼므로, 적도가 아니면 똑바로 가는 것이 아니다. 측지 곡률은 내재적인 양이다.

4.1.4연습문제

기본

  1. 반지름 2인 구에서 북위 45° 위선의 \(\kappa\), \(\kappa_n\), \(|\kappa_g|\)를 구하여라.
    답

    \(\kappa = \frac1{2\cos45°} = \frac1{\sqrt2}\), \(\kappa_n = \frac12\), \(|\kappa_g| = \frac{\tan45°}2 = \frac12\).

응용

  1. 반지름 \(r\)인 원기둥 위의 나선 \(\alpha(s) = (r\cos\frac sc, r\sin\frac sc, \frac{bs}c)\) (\(c = \sqrt{r^2 + b^2}\))의 측지 곡률을 구하여라.
    답

    \(\alpha'' = -\frac r{c^2}(\cos\frac sc, \sin\frac sc, 0)\)은 원기둥의 법선 방향이라 \(\kappa_g = 0\). 나선은 원기둥의 측지선이다.

심화

  1. 곡면 위 곡선이 직선이면 \(\kappa_g = \kappa_n = 0\)임을 보이고, 안장면 \(z = xy\) 위의 직선을 하나 찾아라.
    답

    직선은 \(T' = 0\)이라 두 성분이 모두 0. \(x\)축(\(y = 0\), \(z = 0\))이 곡면 위에 있다. 이 방향은 점근 방향이다(\(\kappa_n = 0\)).
