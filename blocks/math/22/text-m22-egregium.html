가우스의 경이 정리

본문
이 절에서 배울 것
  • 곡면에 맞춘 틀장의 구조방정식에서 \(d\omega_{12} = -K\,\theta_1\wedge\theta_2\)를 유도한다.
  • \(\omega_{12}\)가 \(\theta_1, \theta_2\)만으로 정해지므로 \(K\)가 내재적임(경이 정리)을 결론짓는다.
  • 직교 좌표(\(F = 0\))에서 \(K\)를 \(E, G\)만으로 계산하는 공식을 쓴다.
먼저 알아야 할 것
  • 구조방정식 (1.4절), 모양연산자 (2.1절), 등장사상 (3.2절).

3.3.1곡면에 맞춘 틀장

곡면 \(M\) 위에서 \(E_3 = U\)(법선)이고 \(E_1, E_2\)가 접평면에 놓인 틀장을 적응 틀장이라 합니다. \(\theta_1, \theta_2\)를 \(M\)에 제한하면 \(ds^2 = \theta_1^2 + \theta_2^2\)이고 \(\theta_3 = 0\)입니다. 모양연산자는 \(S(v) = -\nabla_vE_3 = \omega_{13}(v)E_1 + \omega_{23}(v)E_2\)이므로

\[K = \det S = \omega_{13}(E_1)\omega_{23}(E_2) - \omega_{13}(E_2)\omega_{23}(E_1),\]

즉 \(\omega_{13}\wedge\omega_{23} = K\,\theta_1\wedge\theta_2\)입니다.

3.3.2경이 정리

정리 3.3.1 (가우스 방정식) 적응 틀장에서 \(d\omega_{12} = -K\,\theta_1\wedge\theta_2\).
증명

둘째 구조방정식 \(d\omega_{12} = \omega_{13}\wedge\omega_{32} = -\omega_{13}\wedge\omega_{23} = -K\,\theta_1\wedge\theta_2\). ∎

한편 첫째 구조방정식 \(d\theta_1 = \omega_{12}\wedge\theta_2\), \(d\theta_2 = \omega_{21}\wedge\theta_1\) (\(\theta_3 = 0\))은 \(\omega_{12}\)를 \(\theta_1, \theta_2\)만으로 결정합니다(1.4절 연습문제와 같은 계산). \(\theta_1, \theta_2\)는 제1기본형식에서 나오므로

정리 3.3.2 (경이 정리, Theorema Egregium) 가우스 곡률은 제1기본형식만으로 정해진다. 따라서 국소 등장사상은 가우스 곡률을 보존한다.

가우스 자신이 "놀라운 정리"라 이름 붙였습니다. \(K = k_1k_2\)는 법선이 어떻게 기우는지로 정의한 외재적인 양인데, 곡면 위의 개미가 줄자만으로 알아낼 수 있다는 것입니다. 각각의 \(k_1\), \(k_2\)는 내재적이 아니지만(원기둥과 평면) 곱은 내재적입니다.

3.3.3직교 좌표의 공식

\(F = 0\)이면 \(\theta_1 = \sqrt E\,du\), \(\theta_2 = \sqrt G\,dv\)로 두고 위 계산을 따라가면

\[K = -\frac1{2\sqrt{EG}}\left[\left(\frac{E_v}{\sqrt{EG}}\right)_v + \left(\frac{G_u}{\sqrt{EG}}\right)_u\right].\]
예 3.3.3 구(\(E = r^2\), \(G = r^2\cos^2u\)): \(\sqrt{EG} = r^2\cos u\), \(E_v = 0\), \(\frac{G_u}{\sqrt{EG}} = \frac{-2r^2\cos u\sin u}{r^2\cos u} = -2\sin u\), 그 \(u\) 도함수는 \(-2\cos u\). \(K = -\frac{-2\cos u}{2r^2\cos u} = \frac1{r^2}\).

결론: 구의 어떤 조각도 평면(\(K = 0\))에 등장으로 펼칠 수 없습니다. 지도는 거리, 각, 넓이 가운데 무언가를 반드시 왜곡합니다(메르카토르 도법은 각을 보존하고 넓이를 왜곡).

흔한 오해(1) 경이 정리가 주곡률도 내재적이라고 말한다고 여긴다. 곱 \(K\)만 내재적이다. (2) 제1기본형식이 같으면 곡면이 합동이라 여긴다. 제2기본형식까지 같아야 한다(3.4절의 보네 정리).
요약
  1. 적응 틀장: \(\omega_{13}\wedge\omega_{23} = K\theta_1\wedge\theta_2\), \(d\omega_{12} = -K\theta_1\wedge\theta_2\).
  2. \(\omega_{12}\)가 \(\theta_1, \theta_2\)로 정해지므로 \(K\)는 내재적.
  3. \(F = 0\)이면 \(K\)를 \(E, G\)의 미분으로 계산.

3.3.4연습문제

기본

  1. \(E = 1\), \(F = 0\), \(G = 1\)인 곡면의 \(K\)를 구하여라.
    답

    모든 미분이 0이라 \(K = 0\).

응용

  1. \(E = 1\), \(F = 0\), \(G = g(u)^2\)이면 \(K = -\frac{g''}g\)임을 보이고, \(g = \sinh u\)일 때 \(K\)를 구하여라.
    답

    \(\sqrt{EG} = g\), \(\frac{G_u}g = 2g'\), 도함수 \(2g''\). \(K = -\frac{2g''}{2g} = -\frac{g''}g\). \(g = \sinh u\)이면 \(K = -1\) (쌍곡평면).

심화

  1. 현수면과 나선면의 \(K\)가 대응점에서 같음을 3.2절의 등장과 2.5절의 현수면 곡률로 확인하여라.
    답

    현수면은 \(K = -\frac1{\cosh^4u}\). 나선면 \((s\cos t, s\sin t, t)\)은 \(K = -\frac1{(1 + s^2)^2}\)이고 \(s = \sinh u\)이면 \(1 + s^2 = \cosh^2u\)라 같다.
