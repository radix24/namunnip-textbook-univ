원뿔의 모양연산자

예제 · 법선의 변화율을 직접 미분

먼저 예측

원뿔의 모선(꼭짓점에서 뻗는 직선)을 따라 내려가면 법선은 변할까?

예측 확인

변하지 않는다. 모선을 따라서는 접평면이 그대로라 그 방향의 모양연산자는 0이다.

원뿔 \(z = \sqrt{x^2 + y^2}\)에서 법선 \(U = \frac1{\sqrt2}\left(\frac x\rho, \frac y\rho, -1\right)\) (\(\rho = \sqrt{x^2 + y^2}\))를 쓴다. 점 \(p = (1, 0, 1)\)에서 모선 방향 \(a = \frac1{\sqrt2}(1, 0, 1)\)과 둘레 방향 \(b = (0, 1, 0)\)에 대해 \(S(a)\), \(S(b)\)를 구하고 대칭성을 확인하여라.

전략

\(S(v) = -\nabla_vU\)이고, \(U\)의 성분을 \(v\) 방향으로 미분합니다(2.1절). \(U\)는 \(\rho\)와 무관하게 \(\frac x\rho, \frac y\rho\)에만 의존한다는 점을 쓴다.

풀이

  1. \(a\) 방향으로 움직이면 \((x, y)\)의 방향(각)이 그대로라 \(\frac x\rho, \frac y\rho\)가 변하지 않는다. \(\nabla_aU = 0\), \(S(a) = 0\).
    \(U\)는 각 \(\vartheta\)만의 함수.
  2. \(b = U_2\) 방향: \(p\)에서 \(\partial_y\frac x\rho = -\frac{xy}{\rho^3} = 0\), \(\partial_y\frac y\rho = \frac1\rho - \frac{y^2}{\rho^3} = 1\). \(\nabla_bU = \frac1{\sqrt2}(0, 1, 0)\).
    \(p\)에서 \(x = \rho = 1\), \(y = 0\).
  3. \(S(b) = -\frac1{\sqrt2}b\).
    정의.
  4. 대칭성: \(S(a)\cdot b = 0\), \(a\cdot S(b) = -\frac1{\sqrt2}a\cdot b = 0\). 같다. 주곡률은 0과 \(-\frac1{\sqrt2}\), \(K = 0\).
    \(a \perp b\)이고 둘 다 고유벡터.

검산

둘레 방향 단면에서 법곡률 \(\frac1{\sqrt2}\)(크기)는 점 \(p\)에서 축까지의 거리 1을 반지름으로 하는 원(곡률 1)에 법선과 수평면이 이루는 각의 코사인 \(\frac1{\sqrt2}\)을 곱한 값입니다(뫼니에 정리). 맞다.

의미

원뿔은 \(K = 0\)으로, 종이 부채꼴을 말아 만들 수 있는 곡면이다. 모선 방향으로는 곧고 둘레 방향으로만 휘어 원기둥과 같은 구조이다. 축에서 멀어질수록(\(\rho\)가 커질수록) 둘레 방향 곡률이 \(\frac1{\sqrt2\rho}\)로 줄어든다.

이해 확인

점 \((2, 0, 2)\)에서 둘레 방향 주곡률은?

답

\(\partial_y\frac y\rho = \frac12\)이라 \(S(b) = -\frac1{2\sqrt2}b\), 주곡률 \(-\frac1{2\sqrt2}\).
