세운 도넛의 높이 기울기와 지표의 합

예제 · 푸앵카레-호프 확인

먼저 예측

도넛을 세워 놓고 물이 흐르는 방향(높이의 기울기)을 그리면 흐름이 멈추는 점이 몇 개일까?

예측 확인

4개이다. 꼭대기, 바닥, 그리고 구멍의 위아래 가장자리 두 곳.

원환면을 축이 수평이 되도록 세우고 높이 함수 \(f\)의 기울기 벡터장 \(\nabla f\)를 생각한다. 영점을 모두 찾고 지표를 구해 합이 \(\chi = 0\)임을 확인하여라. 또 평면 벡터장 \(X = (x^2 - y^2, -2xy)\)의 원점 지표를 구하여라.

전략

기울기는 접평면이 수평인 점에서만 0이다. 최고점·최저점은 원천·흡입(\(+1\)), 안장점은 \(-1\) (5.5절). 평면 벡터장은 원 \(x = \cos t\), \(y = \sin t\) 위에서 각을 추적한다.

풀이

  1. 접평면이 수평인 점: 바깥 꼭대기(최대), 바깥 바닥(최소), 구멍 쪽 위 가장자리와 아래 가장자리(안장점) 4개.
    세운 원환면의 높이 단면을 생각.
  2. 지표: \(+1 + 1 - 1 - 1 = 0 = \chi(\text{torus})\).
    푸앵카레-호프.
  3. \(X = (x^2 - y^2, -2xy)\)는 복소수로 \(\bar z^2\)이다. \(z = e^{it}\)이면 \(\bar z^2 = e^{-2it}\).
    \((x - iy)^2 = x^2 - y^2 - 2ixy\).
  4. 원을 반시계로 한 바퀴(\(t\): 0 → \(2\pi\)) 돌 때 \(X\)의 각은 \(-2t\)로 시계 방향 두 바퀴. 지표 \(-2\).
    감김수.

검산

원환면을 눕혀(축이 수직) 높이를 재면 최대·최소가 원 전체로 이어져 고립 영점이 아니게 된다. 이런 경우를 피하려고 세운 것이다. 원환면에는 둘레를 도는 흐름처럼 영점이 아예 없는 벡터장도 있고, 이것도 합 0과 맞다.

의미

높이 함수의 임계점을 세는 것만으로 곡면의 오일러 지표를 알 수 있습니다(모스 이론). 극대·극소는 \(+1\), 안장은 \(-1\)이라 \(\chi\)는 (극대의 수) − (안장의 수) + (극소의 수)이고, 구멍 하나마다 안장이 두 개 늘어난다.

이해 확인

구를 세워 놓은 높이 함수의 기울기 영점과 지표의 합은?

답

북극(최대)과 남극(최소), 합 \(1 + 1 = 2 = \chi(S^2)\).
