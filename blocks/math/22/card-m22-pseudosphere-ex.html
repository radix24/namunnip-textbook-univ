곡률이 늘 −1인 나팔: 의구면

예제 · 회전면의 곡률 공식

먼저 예측

구는 어디서나 \(K = 1\)입니다. 어디서나 \(K = -1\)인 회전면도 있을까요?

예측 확인

있습니다. 트락트릭스를 돌린 의구면입니다(가장자리가 있는 나팔 모양).

단면 곡선이 단위 속력이고 축까지의 거리가 \(h(s) = e^{-s}\) (\(s \ge 0\))인 회전면을 만들려 한다. (1) 높이 \(g(s)\)를 정하고, (2) 가우스 곡률을 구하고, (3) 넓이를 구하여라.

전략

단위 속력 조건 \(h'^2 + g'^2 = 1\)로 \(g\)를 정하고, \(K = -\frac{h''}h\) (2.5절), 넓이는 \(dM = h\,ds\,dv\)로 적분합니다.

풀이

  1. \(h' = -e^{-s}\)이라 \(g' = \sqrt{1 - e^{-2s}}\), \(g(s) = \int_0^s\sqrt{1 - e^{-2t}}\,dt\). \(s \ge 0\)에서 \(|h'| \le 1\)이라 정의된다.
    단위 속력.
  2. \(h'' = e^{-s}\)이라 \(K = -\frac{e^{-s}}{e^{-s}} = -1\).
    회전면의 \(K\) 공식.
  3. 넓이 \(\int_0^{2\pi}\int_0^\infty e^{-s}\,ds\,dv = 2\pi\).
    \(E = 1\), \(G = h^2\)이라 \(dM = h\,ds\,dv\).

검산

전곡률 \(\iint K\,dM = -2\pi\). 5.1절의 회전면 전곡률 공식 \(2\pi(h'(a) - h'(b))\)로도 \(2\pi(h'(0) - h'(\infty)) = 2\pi(-1 - 0) = -2\pi\)입니다. 또 \(s = 0\)에서 \(g' = 0\)이라 단면이 수평으로 시작해, 가장자리(반지름 1인 원)가 날카로운 테두리가 됩니다.

의미

의구면은 국소적으로 쌍곡평면(\(K = -1\))과 등장입니다. 쌍곡기하의 삼각형은 내각 합이 \(\pi\)보다 작고, 그 부족분이 넓이와 같습니다(5.2절). 힐베르트 정리에 따르면 쌍곡평면 전체를 \(\mathbb R^3\)에 매끄럽게 넣을 수는 없어서, 의구면처럼 테두리가 생기는 조각만 넣을 수 있습니다.

이해 확인

\(h(s) = \cos s\) (\(|s| \le \frac\pi2\))이면 어떤 곡면이고 \(K\)는?

답

\(g = \sin s\), 반지름 1인 구. \(K = -\frac{-\cos s}{\cos s} = 1\).
