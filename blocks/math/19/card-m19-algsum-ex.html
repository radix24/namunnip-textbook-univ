√2 + ∛2가 만족하는 다항식 찾기

예제 · 근호 없애기

먼저 예측

\(\gamma = \sqrt2 + \sqrt[3]2\)는 정수 계수 다항식의 근이다. 그 다항식의 차수는 얼마일까?

예측 확인

6이다. \([\mathbb Q(\sqrt2, \sqrt[3]2) : \mathbb Q] = 6\)이 상한이고, 실제로 최소다항식의 차수가 6이다.

\(\gamma = \sqrt2 + \sqrt[3]2\)를 근으로 갖는 정수 계수 6차 다항식을 구하여라.

전략

근호를 하나씩 없앤다. 먼저 \(\sqrt[3]2 = \gamma - \sqrt2\)를 세제곱해 \(\sqrt[3]{\ }\)을 없애고, 남은 \(\sqrt2\)를 한쪽으로 모아 제곱합니다(3.3절).

풀이

  1. \((\gamma - \sqrt2)^3 = 2\): \(\gamma^3 - 3\sqrt2\gamma^2 + 6\gamma - 2\sqrt2 = 2\).
    \((\sqrt2)^2 = 2\), \((\sqrt2)^3 = 2\sqrt2\).
  2. \(\sqrt2\) 항을 모으면 \(\gamma^3 + 6\gamma - 2 = \sqrt2(3\gamma^2 + 2)\).
    무리수 부분을 한쪽으로.
  3. 제곱: \((\gamma^3 + 6\gamma - 2)^2 = 2(3\gamma^2 + 2)^2\).
    이제 근호가 없다.
  4. 전개해 정리하면 \(\gamma^6 - 6\gamma^4 - 4\gamma^3 + 12\gamma^2 - 24\gamma - 4 = 0\).
    왼쪽 \(\gamma^6 + 12\gamma^4 - 4\gamma^3 + 36\gamma^2 - 24\gamma + 4\), 오른쪽 \(18\gamma^4 + 24\gamma^2 + 8\).

검산

\(\gamma \approx 1.41421 + 1.25992 = 2.67413\)을 넣으면 왼쪽이 \(10^{-13}\) 정도로 0입니다(부동소수점 오차). 2단계 식의 양변도 모두 약 33.1675로 같다.

의미

얻은 다항식의 차수 6은 \([\mathbb Q(\gamma) : \mathbb Q] \le 6\)과 맞고, \(\mathbb Q(\gamma)\)가 \(\sqrt2 = \frac{\gamma^3 + 6\gamma - 2}{3\gamma^2 + 2}\)과 \(\sqrt[3]2 = \gamma - \sqrt2\)를 모두 포함하므로 \(\mathbb Q(\gamma) = \mathbb Q(\sqrt2, \sqrt[3]2)\)이고 차수는 정확히 6이다. 따라서 이 다항식이 최소다항식이다.
