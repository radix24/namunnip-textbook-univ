환에서의 중국인의 나머지 정리

본문
이 절에서 배울 것
  • 서로소인 아이디얼(\(I + J = R\))을 정의하고, 이때 \(R/(I\cap J) \cong R/I\times R/J\)임을 증명한다.
  • 정수의 연립 합동식과 다항식 보간(라그랑주)이 같은 정리의 두 모습임을 확인한다.
  • \(\mathbb Z_{mn} \cong \mathbb Z_m\times\mathbb Z_n\) (\(\gcd(m, n) = 1\))로 오일러 함수의 곱셈성을 얻는다.
먼저 알아야 할 것
  • 환 준동형과 제1 동형정리 (수학12), 정수의 합동식 (수학10).

1.4.1진술

정리 1.4.1 (중국인의 나머지 정리) 아이디얼 \(I, J\)가 \(I + J = R\)(서로소)이면 \(I\cap J = IJ\)이고 \[R/(I\cap J) \cong R/I\times R/J, \qquad r + I\cap J \mapsto (r + I,\ r + J).\]
증명

\(\varphi : R \to R/I\times R/J\), \(\varphi(r) = (r + I, r + J)\)는 환 준동형이고 핵은 \(I\cap J\)이다. 전사: \(1 = e + f\) (\(e \in I\), \(f \in J\))로 쓰면 \(\varphi(f) = (1, 0)\), \(\varphi(e) = (0, 1)\)이므로 \(\varphi(af + be) = (a, b)\). 제1 동형정리로 결론. 또 \(x \in I\cap J\)이면 \(x = xe + xf \in JI + IJ = IJ\)라 \(I\cap J = IJ\). ∎

증명 속의 \(e, f\)가 해를 직접 만들어 줍니다. \(af + be\)는 "\(I\)에서는 \(a\), \(J\)에서는 \(b\)"인 원소입니다.

1.4.2두 가지 모습

예 1.4.2 (정수) \(x \equiv 2 \pmod 3\), \(x \equiv 3 \pmod 5\). \(1 = 2\cdot3 - 5\)이므로 \(e = 6 \in 3\mathbb Z\), \(f = -5 \in 5\mathbb Z\). 해 \(x = 2f + 3e = -10 + 18 = 8\). 확인: \(8 \equiv 2 \pmod 3\), \(8 \equiv 3 \pmod 5\). 일반해 \(x \equiv 8 \pmod{15}\).
예 1.4.3 (다항식) \(F[x]\)에서 \(I = (x - a)\), \(J = (x - b)\) (\(a \ne b\))는 서로소이고 \(F[x]/(x - a) \cong F\) (\(x \mapsto a\))입니다. 정리는 "\(p(a) = u\), \(p(b) = v\)인 다항식이 \(\bmod (x - a)(x - b)\)로 꼭 하나 있다"는 말이고, 그 해 \(u\frac{x - b}{a - b} + v\frac{x - a}{b - a}\)는 라그랑주 보간(수학16 2.1절)입니다.

1.4.3오일러 함수

\(\gcd(m, n) = 1\)이면 \(\mathbb Z_{mn} \cong \mathbb Z_m\times\mathbb Z_n\)이고, 단원군도 \(\mathbb Z_{mn}^\times \cong \mathbb Z_m^\times\times\mathbb Z_n^\times\)입니다. 따라서 \(\varphi(mn) = \varphi(m)\varphi(n)\)이고, \(\varphi(p^k) = p^k - p^{k-1}\)과 합치면 모든 \(n\)의 \(\varphi(n)\)을 계산할 수 있습니다. 이것이 6.3절 RSA의 바탕입니다.

흔한 오해(1) 서로소가 아닌 아이디얼에도 성립한다고 여긴다. \(\mathbb Z_4 \not\cong \mathbb Z_2\times\mathbb Z_2\)(앞은 위수 4인 원소가 있다). (2) 해가 하나뿐이라고 여긴다. \(I\cap J\)를 법으로 하나이다.
요약
  1. \(I + J = R\)이면 \(R/(I\cap J) \cong R/I\times R/J\), \(I\cap J = IJ\).
  2. \(1 = e + f\)로 해 \(af + be\)를 직접 만든다.
  3. 정수의 연립 합동식, 다항식 보간, \(\varphi(mn) = \varphi(m)\varphi(n)\).

1.4.4연습문제

기본

  1. \(x \equiv 1 \pmod 4\), \(x \equiv 2 \pmod 7\)을 풀어라.
    답

    \(1 = 2\cdot4 - 7\), \(e = 8\), \(f = -7\). \(x = 1\cdot(-7) + 2\cdot8 = 9\). \(x \equiv 9 \pmod{28}\).

응용

  1. \(\varphi(360)\)을 구하여라.
    답

    \(360 = 2^3\cdot3^2\cdot5\), \(\varphi = 4\cdot6\cdot4 = 96\).

심화

  1. \(\mathbb R[x]/(x^2 - 1) \cong \mathbb R\times\mathbb R\)임을 보이고, \(\mathbb R[x]/(x^2)\)는 그렇지 않음을 설명하여라.
    답

    \((x - 1) + (x + 1) \ni 2\)라 서로소이고 \((x - 1)(x + 1) = (x^2 - 1)\). \(\mathbb R[x]/(x^2)\)는 \(x \ne 0\)이지만 \(x^2 = 0\)인 멱영원이 있어 \(\mathbb R\times\mathbb R\)(멱영원 없음)과 다르다.
