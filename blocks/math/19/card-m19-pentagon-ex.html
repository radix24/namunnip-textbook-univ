정오각형은 작도할 수 있는가

예제 · 체의 탑으로 작도하기

먼저 예측

정오각형을 작도하려면 \(\cos72°\)를 작도할 수 있으면 된다. 이 수의 \(\mathbb Q\) 위 차수는 2의 거듭제곱일까?

예측 확인

그렇다. \(\cos72° = \frac{\sqrt5 - 1}4\)이라 차수 2이다. 정오각형은 작도 가능하다.

\(c = \cos72°\)가 만족하는 방정식을 구하고, \(c\)를 제곱근으로 나타내어 정오각형이 작도 가능함을 보여라.

전략

\(\theta = 72°\)는 \(5\theta = 360°\)이므로 \(\cos3\theta = \cos2\theta\)를 씁니다(\(3\theta = 360° - 2\theta\)). 삼배각·이배각 공식으로 \(c\)의 다항식을 얻고 인수분해합니다(4.1절).

풀이

  1. \(4c^3 - 3c = 2c^2 - 1\), 즉 \(4c^3 - 2c^2 - 3c + 1 = 0\).
    \(\cos3\theta = 4\cos^3\theta - 3\cos\theta\), \(\cos2\theta = 2\cos^2\theta - 1\).
  2. \(c = 1\)이 근이므로 \((c - 1)(4c^2 + 2c - 1) = 0\).
    \(\theta = 0\)도 같은 식을 만족하기 때문.
  3. \(\cos72° \ne 1\)이므로 \(4c^2 + 2c - 1 = 0\), \(c = \frac{-1 + \sqrt5}4\) (양수 근).
    \(4c^2 + 2c - 1\)은 유리근이 없어 기약, 차수 2.
  4. 체의 탑 \(\mathbb Q \subset \mathbb Q(\sqrt5)\)으로 \(c\)가 작도 가능하고, 단위원 위의 점 \((c, \sin72°)\)도 \(\sin72° = \sqrt{1 - c^2}\)로 작도 가능하다.
    \(1 - c^2 \in \mathbb Q(\sqrt5)\), 제곱근 한 번 더.

검산

\(\frac{\sqrt5 - 1}4 \approx \frac{1.23607}4 = 0.30902\)이고 \(\cos72° \approx 0.30902\)이다.

의미

\(\cos\frac{2\pi}n\)의 차수는 \(\frac{\varphi(n)}2\)이고, 가우스는 정 \(n\)각형이 작도 가능할 필요충분조건이 \(\varphi(n)\)이 2의 거듭제곱인 것(\(n\)이 2의 거듭제곱과 서로 다른 페르마 소수들의 곱)임을 보였다. 정17각형(\(\varphi(17) = 16\))은 작도 가능하고, 정7각형(\(\varphi(7) = 6\))과 정9각형(\(\varphi(9) = 6\))은 불가능하다.

이해 확인

정육각형이 작도 가능함을 \(\cos60°\)의 차수로 설명하여라.

답

\(\cos60° = \frac12 \in \mathbb Q\), 차수 1입니다(\(\varphi(6) = 2\)).
