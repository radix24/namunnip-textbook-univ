정역의 분수체

본문
이 절에서 배울 것
  • 정수에서 유리수를 만드는 방법을 일반화해, 정역 \(D\)의 순서쌍 \((a, b)\) (\(b \ne 0\))를 \(ad = bc\)로 묶어 분수체 \(\operatorname{Frac}(D)\)를 구성한다.
  • 동치관계와 연산이 잘 정의됨을 확인하고, \(D\)가 그 안에 들어감을 보인다.
  • 분수체가 \(D\)를 포함하는 가장 작은 체라는 보편 성질을 안다.
먼저 알아야 할 것
  • 동치관계와 동치류 (수학2), 정역 (1.1절).

1.3.1구성

\(S = \{(a, b) : a, b \in D,\ b \ne 0\}\)에서 \((a, b) \sim (c, d)\) ⟺ \(ad = bc\)로 정의합니다(분수 \(\frac ab = \frac cd\)의 뜻).

보조정리 1.3.1 \(\sim\)은 동치관계이다.
증명

반사·대칭은 바로 나온다. 추이: \(ad = bc\), \(cf = de\)이면 \(adf = bcf = bde\)이므로 \(d(af - be) = 0\)이고, \(d \ne 0\)이며 \(D\)가 정역이라 \(af = be\), 즉 \((a, b) \sim (e, f)\). ∎

여기서 정역(영인자 없음)이 꼭 필요합니다. \((a, b)\)의 류를 \(\frac ab\)로 쓰고

\[\frac ab + \frac cd = \frac{ad + bc}{bd}, \qquad \frac ab\cdot\frac cd = \frac{ac}{bd}\]

로 연산을 정의합니다(\(bd \ne 0\)도 정역이라서). 대표를 바꿔도 결과의 류가 같음(잘 정의됨)을 확인하면, 가환환이 되고 \(\frac ab \ne 0\) (\(a \ne 0\))의 역원은 \(\frac ba\)이므로 체입니다.

1.3.2매장과 보편 성질

\(a \mapsto \frac a1\)은 단사 환 준동형이라 \(D\)를 \(\operatorname{Frac}(D)\)의 부분환으로 봅니다.

정리 1.3.2 \(D \subset K\)인 체 \(K\)가 있으면 \(\frac ab \mapsto ab^{-1}\)은 \(\operatorname{Frac}(D)\)에서 \(K\)로 가는 단사 준동형이다. 즉 분수체는 \(D\)를 포함하는 가장 작은 체이다.
예 1.3.3 \(\operatorname{Frac}(\mathbb Z) = \mathbb Q\), \(\operatorname{Frac}(F[x]) = F(x)\) (유리함수체), \(\operatorname{Frac}(\mathbb Z[i]) = \mathbb Q(i) = \{a + bi : a, b \in \mathbb Q\}\)입니다. 마지막은 \(\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{c^2 + d^2}\)로 분모를 유리화하면 보입니다.
흔한 오해(1) 영인자가 있는 환에도 분수체를 만들 수 있다고 여긴다. \(\mathbb Z_6\)에서 \((2, 1) \sim (2\cdot3, 3) = (0, 3)\) 같은 문제로 추이성이 깨진다. (2) 분수체가 원래 환보다 "훨씬 크다"고만 여긴다. 원래 환이 체이면 분수체는 자기 자신이다.
요약
  1. \((a, b) \sim (c, d)\) ⟺ \(ad = bc\), 추이성에 정역이 필요하다.
  2. 분수의 덧셈·곱셈은 잘 정의되고 체가 된다.
  3. \(D\)를 포함하는 가장 작은 체: \(\mathbb Q\), \(F(x)\), \(\mathbb Q(i)\).

1.3.4연습문제

기본

  1. 곱셈이 잘 정의됨을 보여라: \((a, b) \sim (a', b')\)이면 \((ac, bd) \sim (a'c, b'd)\).
    답

    \(acb'd = (ab')cd = (a'b)cd = a'cbd\).

응용

  1. \(\operatorname{Frac}(\mathbb Z[\sqrt2])\)를 구하여라.
    답

    \(\frac1{a + b\sqrt2} = \frac{a - b\sqrt2}{a^2 - 2b^2}\)이므로 \(\mathbb Q(\sqrt2) = \{p + q\sqrt2 : p, q \in \mathbb Q\}\).

심화

  1. 짝수 정수의 환 \(2\mathbb Z\)(1이 없는 정역 비슷한 환)에 같은 구성을 하면 무엇이 나오는가?
    답

    \(\frac{2m}{2n}\)들의 체로, \(\mathbb Q\)와 같다(\(\frac{2m}{2n} \mapsto \frac mn\)).
