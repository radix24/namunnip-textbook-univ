작도와 유한체 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 판단\(\sqrt{3 + \sqrt5}\), \(\sqrt[3]{5}\), \(\sqrt[4]{7}\) 가운데 작도 가능한 수는? [04-01]

    힌트 1

    제곱근만 거듭 쓰는가?

    힌트 2

    \(\sqrt[4]7 = \sqrt{\sqrt7}\).

    풀이

    \(\sqrt{3 + \sqrt5}\)와 \(\sqrt[4]7\)은 제곱근을 두 번 써서 작도 가능. \(\sqrt[3]5\)는 차수 3이라 불가능 (4.1절).

  2. 증명\(120°\)를 삼등분하는 것(\(40°\) 작도)이 불가능함을 보여라. [04-02]

    힌트 1

    \(\cos120° = -\frac12 = 4c^3 - 3c\).

    힌트 2

    \(u = 2c\): \(u^3 - 3u + 1 = 0\).

    풀이

    \(c = \cos40°\)는 \(8c^3 - 6c + 1 = 0\), \(u = 2c\)로 \(u^3 - 3u + 1\). 유리근 후보 \(\pm1\)에서 값 \(-1\), \(3\)이라 근이 없어 기약 3차. 차수 3이므로 불가능 (4.2절). ∎

  3. 계산\(\mathbb F_4 = \mathbb F_2[x]/(x^2 + x + 1)\)의 덧셈표와 곱셈표를 써라. [04-03]

    힌트 1

    원소 \(0, 1, \alpha, \alpha + 1\), \(\alpha^2 = \alpha + 1\).

    힌트 2

    \(\alpha + 1 = \alpha^2\), \(\alpha^3 = 1\).

    풀이

    덧셈은 성분별 \(\bmod 2\)(예: \(\alpha + (\alpha + 1) = 1\)). 곱셈은 \(\alpha\cdot\alpha = \alpha + 1\), \(\alpha(\alpha + 1) = 1\), \((\alpha + 1)^2 = \alpha\). 곱셈군 \(\{1, \alpha, \alpha^2\}\)은 위수 3인 순환군 (4.3절).

  4. 증명표수 \(p\)인 체에서 \(\phi(a) = a^p\)(프로베니우스)가 환 준동형이고, 유한체에서는 동형임을 보여라. [04-03]

    힌트 1

    \((a + b)^p = a^p + b^p\).

    힌트 2

    체 준동형은 단사, 유한 집합.

    풀이

    \((ab)^p = a^pb^p\), \((a + b)^p = \sum\binom pka^kb^{p-k} = a^p + b^p\)(중간 이항계수는 \(p\)의 배수). 핵이 체의 아이디얼이라 0이므로 단사, 유한이라 전사. ∎

  5. 계산\(\mathbb Z_{11}\)의 원시근 하나를 찾고, 원시근의 개수를 구하여라. [04-04]

    힌트 1

    \(10 = 2\cdot5\): \(g^5 \ne 1\), \(g^2 \ne 1\).

    힌트 2

    \(g = 2\): \(2^5 = 32 \equiv 10\).

    풀이

    \(2^5 \equiv 10 \ne 1\), \(2^2 = 4 \ne 1\)이라 2는 원시근. 개수 \(\varphi(10) = 4\) (\(2, 6, 7, 8\)) (4.4절).

  6. 판단"\(\mathbb Z_9\)의 단원군 \(\mathbb Z_9^\times\)는 체의 곱셈군이 아니므로 순환군이 아니다"는 옳은가? [04-04]

    힌트 1

    \(\mathbb Z_9^\times = \{1, 2, 4, 5, 7, 8\}\).

    힌트 2

    2의 위수.

    풀이

    틀리다. 2의 거듭제곱이 \(2, 4, 8, 7, 5, 1\)로 위수 6이라 순환군이다. 정리 4.4.1은 충분조건일 뿐이고, \(\mathbb Z_{p^k}^\times\) (\(p\) 홀수 소수)는 체가 아니어도 순환군이다.
