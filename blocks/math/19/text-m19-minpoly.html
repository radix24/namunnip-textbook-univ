최소다항식과 확대 차수

본문

\(\sqrt2\)를 \(\mathbb Q\)에 붙인 체 \(\mathbb Q(\sqrt2)\)는 \(a + b\sqrt2\) 꼴의 수로 이루어진다. 그렇다면 \(\sqrt[3]2\)나 \(\sqrt2 + \sqrt3\)을 붙이면 원소는 어떤 꼴이 될까? 붙인 수가 만족하는 가장 작은 다항식은 무엇이고, 그 차수는 새 체의 크기와 어떤 관계일까?

먼저 알아야 할 것\(F[x]/(p)\)가 체라는 것(1.2절), 기약 판정(2.2절), 벡터공간의 기저와 차원(수학1)을 쓴다.

3.1.1확대 차수

체 \(F \subset E\)를 확대 \(E/F\)라 하고, \(E\)를 \(F\) 위의 벡터공간으로 본 차원을 차수 \([E : F]\)라 한다. 예를 들어 \(1, i\)가 기저이므로 \([\mathbb C : \mathbb R] = 2\)이고, \([\mathbb R : \mathbb Q] = \infty\)이다.

3.1.2최소다항식

\(\alpha \in E\)가 \(F\) 계수의 0 아닌 다항식의 근이면 대수적, 그렇지 않으면 초월적이라 한다. 대입 사상 \(\phi : F[x] \to E\), \(f \mapsto f(\alpha)\)의 핵은 \(F[x]\)의 아이디얼이므로 2.1절에 의해 \((m_\alpha)\) 꼴이고, \(\alpha\)가 대수적이면 \(m_\alpha \ne 0\)이다. 모닉으로 잡은 \(m_\alpha\)를 \(\alpha\)의 최소다항식이라 한다.

정리 3.1.1

\(\alpha\)가 \(F\) 위에서 대수적이면 (1) \(m_\alpha\)는 기약이고, (2) \(F(\alpha) = F[\alpha] \cong F[x]/(m_\alpha)\)이며, (3) \(n = \deg m_\alpha\)에 대해 \([F(\alpha) : F] = n\)이고 \(1, \alpha, \dots, \alpha^{n-1}\)이 기저이다.

증명.(1) \(F[x]/(m_\alpha) \cong \operatorname{im}\phi \subset E\)는 정역이므로 \((m_\alpha)\)는 소아이디얼이다. 주아이디얼정역에서 0 아닌 소아이디얼은 극대이므로 \(m_\alpha\)는 기약이고, 그 몫은 체이다. (2) 그 체 \(\operatorname{im}\phi = F[\alpha]\)는 \(\alpha\)를 포함하는 가장 작은 체 \(F(\alpha)\)와 같다. (3) 나눗셈 정리로 모든 \(f(\alpha)\)는 차수가 \(n\)보다 작은 다항식의 값이다. 또 \(\sum_{k<n}c_k\alpha^k = 0\)이면 \(m_\alpha\)가 차수 \(n\) 미만인 그 다항식을 나누어야 하므로 모든 \(c_k = 0\)이다. ∎

그러므로 최소다항식을 구하려면 \(\alpha\)를 근으로 갖는 모닉 기약 다항식을 찾으면 된다.

3.1.3예

예제 3.1.2

\(\sqrt2\), \(\sqrt[3]2\), \(\sqrt2 + \sqrt3\), \(e^{2\pi i/5}\)의 \(\mathbb Q\) 위 최소다항식과 차수를 구하여라.

풀이. \(\sqrt2\)는 아이젠슈타인 판정법으로 기약인 \(x^2 - 2\)이 최소다항식이라 \([\mathbb Q(\sqrt2) : \mathbb Q] = 2\)이다. \(\sqrt[3]2\)는 \(x^3 - 2\)이라 차수 3이고, 기저는 \(1, \sqrt[3]2, \sqrt[3]4\)이다. \(\alpha = \sqrt2 + \sqrt3\)은 \(\alpha^2 = 5 + 2\sqrt6\)에서 \((\alpha^2 - 5)^2 = 24\)이므로 \(x^4 - 10x^2 + 1\)의 근이다. 이 다항식은 유리근 \(\pm1\)이 근이 아니고 \(\mathbb Q\)에서 2차와 2차의 곱으로도 분해되지 않으므로 기약이며, 차수는 4이다. 그림 1이 이 다항식이다. 끝으로 \(e^{2\pi i/5}\)는 2.2절에서 기약임을 보인 \(\Phi_5 = x^4 + x^3 + x^2 + x + 1\)의 근이라 차수 4이다.

흔한 오해\(\alpha\)를 근으로 하는 다항식이면 최소다항식이라고 여기기 쉽지만, 기약이어야 한다. \(\sqrt2\)는 \(x^4 - 4\)의 근이지만 최소다항식은 \(x^2 - 2\)이다. 또 최소다항식이 기반체와 무관하다고 생각하는 것도 틀렸다. \(\sqrt2\)의 \(\mathbb R\) 위 최소다항식은 \(x - \sqrt2\)이다.
마무리

처음 질문에 답하면, 대수적인 수 \(\alpha\)가 만족하는 가장 작은 다항식은 모닉 기약 다항식인 최소다항식 \(m_\alpha\)이다. \(F(\alpha) \cong F[x]/(m_\alpha)\)이므로 새 체의 원소는 \(1, \alpha, \dots, \alpha^{n-1}\)의 일차결합이고, 체의 차수는 최소다항식의 차수 \(n\)과 같다. 그래서 \(\mathbb Q(\sqrt[3]2)\)의 원소는 \(a + b\sqrt[3]2 + c\sqrt[3]4\) 꼴이고, \(\sqrt2 + \sqrt3\)을 붙인 체는 차수가 4이다.

3.1.4연습문제

기본

  1. \(\sqrt[4]5\)의 \(\mathbb Q\) 위 최소다항식과 차수를 구하여라.
    답

    \(x^4 - 5\) (\(p = 5\) 아이젠슈타인), 차수 4.

응용

  1. \(\mathbb Q(\sqrt[3]2)\)에서 \(\frac1{1 + \sqrt[3]2}\)을 기저 \(1, \sqrt[3]2, \sqrt[3]4\)로 나타내어라.
    답

    \(\beta = \sqrt[3]2\)이면 \(1 + \beta^3 = 3\)이고 \(1 + \beta^3 = (1 + \beta)(1 - \beta + \beta^2)\)이므로 \(\frac1{1 + \beta} = \frac{1 - \beta + \beta^2}3\).

심화

  1. \(x^4 - 10x^2 + 1\)이 \(\mathbb Q\)에서 2차 다항식 둘의 곱이 아님을 보여라.
    답

    근이 \(\pm\sqrt2 \pm \sqrt3\)이므로 유리수 계수 2차 인수의 근 쌍은 합과 곱이 유리수여야 한다. 가능한 쌍의 합은 \(\pm2\sqrt2, \pm2\sqrt3, 0\), 합이 0인 쌍 \((\sqrt2 + \sqrt3, -\sqrt2 - \sqrt3)\)은 곱이 \(-(5 + 2\sqrt6)\)으로 무리수. 어느 쌍도 안 되므로 2차 인수가 없다.
