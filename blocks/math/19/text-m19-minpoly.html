최소다항식과 확대 차수

본문
이 절에서 배울 것
  • 확대체 \(E/F\)의 차수 \([E : F]\)를 \(E\)를 \(F\) 위의 벡터공간으로 본 차원으로 정의한다.
  • 대수적 원소 \(\alpha\)의 최소다항식을 정의하고, \(F(\alpha) \cong F[x]/(m_\alpha)\), \([F(\alpha) : F] = \deg m_\alpha\)임을 증명한다.
  • \(\sqrt2\), \(\sqrt[3]2\), \(\sqrt2 + \sqrt3\)의 최소다항식과 차수를 구한다.
먼저 알아야 할 것
  • \(F[x]/(p)\)가 체 (1.2절), 기약 판정 (2.2절), 벡터공간의 기저와 차원 (수학1).

3.1.1확대 차수

체 \(F \subset E\)를 확대 \(E/F\)라 하고, \(E\)를 \(F\) 위의 벡터공간으로 본 차원을 차수 \([E : F]\)라 합니다. 예를 들어 \([\mathbb C : \mathbb R] = 2\) (기저 \(1, i\)), \([\mathbb R : \mathbb Q] = \infty\)입니다.

3.1.2최소다항식

\(\alpha \in E\)가 \(F\) 계수의 0 아닌 다항식의 근이면 대수적, 아니면 초월적이라 합니다. 대입 사상 \(\phi : F[x] \to E\), \(f \mapsto f(\alpha)\)의 핵은 \(F[x]\)의 아이디얼이라 \((m_\alpha)\) 꼴이고(2.1절), \(\alpha\)가 대수적이면 \(m_\alpha \ne 0\)입니다. 모닉으로 잡은 \(m_\alpha\)를 \(\alpha\)의 최소다항식이라 합니다.

정리 3.1.1 \(\alpha\)가 \(F\) 위에서 대수적이면 (1) \(m_\alpha\)는 기약이다. (2) \(F(\alpha) = F[\alpha] \cong F[x]/(m_\alpha)\). (3) \([F(\alpha) : F] = \deg m_\alpha = n\)이고 \(1, \alpha, \dots, \alpha^{n-1}\)이 기저이다.
증명

(1) \(F[x]/(m_\alpha) \cong \operatorname{im}\phi \subset E\)는 정역이라 \((m_\alpha)\)는 소아이디얼, PID에서 0 아닌 소아이디얼은 극대이므로 \(m_\alpha\)는 기약이고 몫은 체이다. (2) 그 체 \(\operatorname{im}\phi = F[\alpha]\)는 \(\alpha\)를 포함하는 가장 작은 체 \(F(\alpha)\)와 같다. (3) 나눗셈으로 모든 \(f(\alpha)\)는 차수 \(n\) 미만의 다항식 값이고, \(\sum_{k<n}c_k\alpha^k = 0\)이면 \(m_\alpha\)가 차수 \(n\) 미만 다항식을 나누어야 하므로 모든 \(c_k = 0\). ∎

그래서 최소다항식은 "\(\alpha\)를 근으로 갖는 모닉 기약 다항식"을 찾으면 됩니다.

3.1.3예

예 3.1.2
  • \(\sqrt2\): \(x^2 - 2\) (아이젠슈타인), \([\mathbb Q(\sqrt2) : \mathbb Q] = 2\).
  • \(\sqrt[3]2\): \(x^3 - 2\), 차수 3. 기저 \(1, \sqrt[3]2, \sqrt[3]4\).
  • \(\alpha = \sqrt2 + \sqrt3\): \(\alpha^2 = 5 + 2\sqrt6\), \((\alpha^2 - 5)^2 = 24\)이라 \(x^4 - 10x^2 + 1\). 유리근(\(\pm1\))이 없고 \(\mathbb Q\)에서 2차×2차로도 분해되지 않으므로 기약, 차수 4.
  • \(e^{2\pi i/5}\): \(\Phi_5 = x^4 + x^3 + x^2 + x + 1\) (2.2절에서 기약), 차수 4.
흔한 오해(1) \(\alpha\)를 근으로 하는 다항식이면 최소다항식이라고 여긴다. 기약이어야 한다(\(\sqrt2\)는 \(x^4 - 4\)의 근이지만 최소다항식은 \(x^2 - 2\)). (2) 최소다항식이 기반체와 무관하다고 여긴다. \(\sqrt2\)의 \(\mathbb R\) 위 최소다항식은 \(x - \sqrt2\)이다.
요약
  1. \([E : F] = \dim_FE\).
  2. 최소다항식 \(m_\alpha\): 대입 사상의 핵의 모닉 생성원, 기약.
  3. \(F(\alpha) \cong F[x]/(m_\alpha)\), \([F(\alpha) : F] = \deg m_\alpha\).

3.1.4연습문제

기본

  1. \(\sqrt[4]5\)의 \(\mathbb Q\) 위 최소다항식과 차수를 구하여라.
    답

    \(x^4 - 5\) (\(p = 5\) 아이젠슈타인), 차수 4.

응용

  1. \(\mathbb Q(\sqrt[3]2)\)에서 \(\frac1{1 + \sqrt[3]2}\)을 기저 \(1, \sqrt[3]2, \sqrt[3]4\)로 나타내어라.
    답

    \(\beta = \sqrt[3]2\)이면 \(1 + \beta^3 = 3\)이고 \(1 + \beta^3 = (1 + \beta)(1 - \beta + \beta^2)\)이므로 \(\frac1{1 + \beta} = \frac{1 - \beta + \beta^2}3\).

심화

  1. \(x^4 - 10x^2 + 1\)이 \(\mathbb Q\)에서 2차 다항식 둘의 곱이 아님을 보여라.
    답

    근이 \(\pm\sqrt2 \pm \sqrt3\)이므로 유리수 계수 2차 인수의 근 쌍은 합과 곱이 유리수여야 한다. 가능한 쌍의 합은 \(\pm2\sqrt2, \pm2\sqrt3, 0\), 합이 0인 쌍 \((\sqrt2 + \sqrt3, -\sqrt2 - \sqrt3)\)은 곱이 \(-(5 + 2\sqrt6)\)으로 무리수. 어느 쌍도 안 되므로 2차 인수가 없다.
