응용대수 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산해밍 (7, 4) 부호로 정보 0110을 부호화하여라. [06-01]

    힌트 1

    정보는 자리 3, 5, 6, 7.

    힌트 2

    \(p_1 = d_1 + d_2 + d_4\), \(p_2 = d_1 + d_3 + d_4\), \(p_4 = d_2 + d_3 + d_4\).

    풀이

    \(d = (0, 1, 1, 0)\): \(p_1 = 1\), \(p_2 = 1\), \(p_4 = 0\). 부호어 \(1100110\). 확인: \(H\mathbf c = 0\) (6.1절).

  2. 계산받은 벡터 \(1000110\)을 복호하여라. [06-01]

    힌트 1

    증후의 각 성분은 자리 {1,3,5,7}, {2,3,6,7}, {4,5,6,7}의 합.

    힌트 2

    \((1 + 0 + 1 + 0, 0 + 0 + 1 + 0, 0 + 1 + 1 + 0)\).

    풀이

    증후 \((0, 1, 0)\) → 2번 비트 오류. 고치면 \(1100110\), 정보 0110.

  3. 증명최소 거리 \(d = 3\)인 부호는 한 비트 오류를 정정할 수 있음을 보여라. [06-01]

    힌트 1

    두 부호어 \(\mathbf c, \mathbf c'\)에서 거리 1 이내인 벡터가 같을 수 있는가?

    힌트 2

    삼각부등식.

    풀이

    \(\mathbf r\)이 \(\mathbf c\)와 \(\mathbf c'\) 모두에서 거리 1 이하라면 \(d(\mathbf c, \mathbf c') \le 2 < 3\)이라 모순. 따라서 거리 1 이하인 부호어는 하나뿐이고 그것으로 복호한다. ∎

  4. 계산\(p = 17\), \(g = 3\)(원시근)에서 앨리스 \(a = 4\), 밥 \(b = 7\)의 공통 키를 구하여라. [06-02]

    힌트 1

    \(A = 3^4 \bmod 17\).

    힌트 2

    \(3^4 = 81 \equiv 13\).

    풀이

    \(A = 13\), \(B = 3^7 = 2187 \equiv 11\). 키 \(B^a = 11^4 \equiv 4\), \(A^b = 13^7 \equiv 4\) (6.2절).

  5. 계산\(n = 55\), \(e = 3\)인 RSA에서 \(d\)를 구하고 \(m = 2\)를 암호화·복호화하여라. [06-03]

    힌트 1

    \(\varphi(55) = 40\).

    힌트 2

    \(3d \equiv 1 \pmod{40}\).

    풀이

    \(d = 27\). \(c = 2^3 = 8\). \(8^{27} = 2^{81} \bmod 55\): \(2^{40} \equiv 1\)이라 \(2^{81} = 2^{80}\cdot2 \equiv 2\). 복원 (6.3절).

  6. 판단"RSA에서 \(e = 1\)을 쓰면 계산이 가장 빠르므로 좋다"는 옳은가? [06-03]

    힌트 1

    \(c = m^1\).

    힌트 2

    암호문 = 평문.

    풀이

    틀리다. \(c = m\)이라 암호화가 되지 않는다. 실제로는 \(e = 65537 = 2^{16} + 1\)처럼 곱셈이 적으면서 충분히 큰 값을 쓴다.
