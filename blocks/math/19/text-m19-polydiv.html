다항식 나눗셈과 주아이디얼정역 F[x]

본문
이 절에서 배울 것
  • 체 \(F\) 위의 다항식환 \(F[x]\)에서 나눗셈 정리 \(f = qg + r\) (\(\deg r < \deg g\))를 증명한다.
  • 나눗셈 정리로 \(F[x]\)의 모든 아이디얼이 하나의 다항식으로 생성됨(주아이디얼정역)을 보인다.
  • 유클리드 호제법으로 최대공약수를 구하고, 인수정리와 근의 개수 상한을 얻는다.
먼저 알아야 할 것
  • 다항식의 나눗셈(고등학교 수학), 아이디얼 (1.1절).

2.1.1나눗셈 정리

정리 2.1.1 \(F\)가 체이고 \(g \in F[x]\), \(g \ne 0\)이면 모든 \(f \in F[x]\)에 대해 \(f = qg + r\), \(r = 0\) 또는 \(\deg r < \deg g\)인 \(q, r\)이 꼭 하나 있다.
증명

존재: \(\deg f\)에 대한 귀납법. \(\deg f < \deg g\)이면 \(q = 0\), \(r = f\). 아니면 \(f\)와 \(g\)의 최고차 계수를 \(a, b\)라 할 때 \(f_1 = f - \frac ab x^{\deg f - \deg g}g\)은 차수가 줄고(\(b^{-1}\)이 있어야 하므로 체가 필요), 귀납 가정으로 \(f_1 = q_1g + r\)이다. 유일성: \(qg + r = q'g + r'\)이면 \((q - q')g = r' - r\)이고 오른쪽의 차수가 \(\deg g\)보다 작으므로 \(q = q'\), \(r = r'\). ∎

\(g = x - a\)이면 \(r\)은 상수이고 \(x = a\)를 넣으면 \(r = f(a)\)입니다(나머지 정리). 따라서 \(f(a) = 0\) ⟺ \((x - a) \mid f\) (인수정리)이고, \(n\)차 다항식은 근이 많아야 \(n\)개입니다.

2.1.2F[x]는 주아이디얼정역

정리 2.1.2 \(F[x]\)의 모든 아이디얼 \(I\)는 \(I = (g)\) 꼴이다. \(g\)로는 \(I\)에서 차수가 가장 작은 0 아닌 다항식을 잡을 수 있다.
증명

\(I = 0\)이면 \(g = 0\). 아니면 차수가 가장 작은 \(g \in I\)를 고르고 \(f \in I\)를 \(f = qg + r\)로 나눈다. \(r = f - qg \in I\)이고 \(\deg r < \deg g\)이므로 \(g\)의 최소성으로 \(r = 0\), \(f \in (g)\). ∎

\(\mathbb Z[x]\)는 주아이디얼정역이 아닙니다. \((2, x)\)를 하나로 생성하는 다항식 \(g\)가 있다면 \(g \mid 2\)이고 \(g \mid x\)라 \(g = \pm1\)인데, \(1 \notin (2, x)\)입니다. 계수가 체가 아니라 나눗셈이 막힌 결과입니다.

2.1.3유클리드 호제법

\(\gcd(f, g)\)는 \((f, g) = (d)\)인 모닉 다항식 \(d\)이고, 정수처럼 나눗셈을 반복해 구합니다.

예 2.1.3 \(\mathbb Q[x]\)에서 \(f = x^4 - 1\), \(g = x^3 + x^2 + x + 1\)이면 \(f = (x - 1)g + 0\)이라 \(\gcd = g\)입니다. \(f = x^3 - 1\), \(g = x^2 - 1\)이면 \(f = xg + (x - 1)\), \(g = (x + 1)(x - 1) + 0\)이라 \(\gcd = x - 1\)입니다. 거꾸로 따라가면 \(x - 1 = f - xg\)로 베주 항등식을 얻습니다.
흔한 오해(1) 정수 계수 다항식에도 나눗셈 정리가 늘 된다고 여긴다. \(x^2\)을 \(2x\)로 나누면 몫 \(\frac x2\)가 \(\mathbb Z[x]\)에 없다(나누는 다항식이 모닉이면 된다). (2) 근의 개수 상한이 모든 환에서 성립한다고 여긴다. \(\mathbb Z_8\)에서 \(x^2 - 1\)은 근이 \(1, 3, 5, 7\)로 4개이다(정역이 아님).
요약
  1. \(F[x]\)의 나눗셈 정리: \(f = qg + r\), \(\deg r < \deg g\).
  2. 최소 차수 원소가 아이디얼을 생성: \(F[x]\)는 주아이디얼정역. \(\mathbb Z[x]\)는 아니다.
  3. 유클리드 호제법으로 gcd와 베주 항등식, 인수정리와 근의 개수 상한.

2.1.4연습문제

기본

  1. \(\mathbb Z_5[x]\)에서 \(x^3 + 2x + 1\)을 \(x - 2\)로 나눈 나머지를 구하여라.
    답

    나머지 정리로 \(8 + 4 + 1 = 13 \equiv 3\).

응용

  1. \(\mathbb Q[x]\)에서 아이디얼 \((x^2 - 1, x^3 - 1)\)의 생성원을 구하여라.
    답

    예 2.1.3으로 \(\gcd = x - 1\)이므로 \((x - 1)\).

심화

  1. \(F[x]\)에서 \((p)\)가 극대아이디얼 ⟺ \(p\)가 기약임을 보여라.
    답

    \((p) \subset (g)\) ⟺ \(g \mid p\). \(p\)가 기약이면 \(g\)는 단원이나 \(p\)의 상수배라 \((g)\)는 \(F[x]\) 또는 \((p)\). 반대로 \(p = gh\) (둘 다 비단원)이면 \((p) \subsetneq (g) \subsetneq F[x]\).
