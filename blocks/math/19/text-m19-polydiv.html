다항식 나눗셈과 주아이디얼정역 F[x]

본문

정수에서는 나눗셈 정리 덕분에 모든 아이디얼이 수 하나로 생성되고, 유클리드 호제법으로 최대공약수를 구했다. 체 위의 다항식에서도 같은 일이 될까? 계수가 정수이면 무엇이 달라질까?

먼저 알아야 할 것다항식의 나눗셈과 아이디얼(1.1절)을 쓴다.

2.1.1나눗셈 정리

정리 2.1.1

\(F\)가 체이고 \(g \in F[x]\), \(g \ne 0\)이면, 모든 \(f \in F[x]\)에 대해 \(f = qg + r\)이고 \(r = 0\) 또는 \(\deg r < \deg g\)인 \(q, r\)이 꼭 하나 있다.

증명.존재는 \(\deg f\)에 대한 귀납법으로 보인다. \(\deg f < \deg g\)이면 \(q = 0\), \(r = f\)로 둔다. 그렇지 않으면 \(f\)와 \(g\)의 최고차 계수를 \(a, b\)라 할 때, \(f_1 = f - \frac ab x^{\deg f - \deg g}g\)는 차수가 준다. 여기서 \(b^{-1}\)이 있어야 하므로 체가 필요하다. 귀납 가정으로 \(f_1 = q_1g + r\)이므로 \(f\)도 그런 꼴이다. 유일성은 \(qg + r = q'g + r'\)이면 \((q - q')g = r' - r\)이고, 오른쪽의 차수가 \(\deg g\)보다 작으므로 \(q = q'\), \(r = r'\)이라는 데서 나온다. ∎

\(g = x - a\)이면 \(r\)은 상수이고, \(x = a\)를 넣으면 \(r = f(a)\)이다. 이것이 나머지 정리이다. 따라서 \(f(a) = 0\)인 것은 \((x - a) \mid f\)인 것과 같고, 이 인수정리에 의해 \(n\)차 다항식은 근이 많아야 \(n\)개이다.

2.1.2\(F[x]\)는 주아이디얼정역

정리 2.1.2

\(F[x]\)의 모든 아이디얼 \(I\)는 \(I = (g)\) 꼴이다. 이때 \(g\)로는 \(I\)에서 차수가 가장 작은 0 아닌 다항식을 잡을 수 있다.

증명.\(I = 0\)이면 \(g = 0\)이다. 그렇지 않으면 차수가 가장 작은 \(g \in I\)를 고르고, \(f \in I\)를 \(f = qg + r\)로 나눈다. \(r = f - qg \in I\)이고 \(\deg r < \deg g\)이므로, \(g\)의 최소성에 의해 \(r = 0\)이고 \(f \in (g)\)이다. ∎

그러나 \(\mathbb Z[x]\)는 주아이디얼정역이 아니다. \((2, x)\)를 하나로 생성하는 \(g\)가 있다면 \(g \mid 2\)이고 \(g \mid x\)이므로 \(g = \pm1\)인데, \(1 \notin (2, x)\)이기 때문이다. 계수가 체가 아니어서 나눗셈이 막힌 결과이다.

2.1.3유클리드 호제법

\(\gcd(f, g)\)는 \((f, g) = (d)\)인 모닉 다항식 \(d\)이며, 정수에서처럼 나눗셈을 되풀이해 구한다.

예제 2.1.3

\(\mathbb Q[x]\)에서 \(\gcd(x^4 - 1, x^3 + x^2 + x + 1)\)과 \(\gcd(x^3 - 1, x^2 - 1)\)을 구하여라.

풀이. \(x^4 - 1 = (x - 1)(x^3 + x^2 + x + 1) + 0\)이므로 첫 번째 최대공약수는 \(x^3 + x^2 + x + 1\)이다. 다음으로 \(f = x^3 - 1\), \(g = x^2 - 1\)이면 \(f = xg + (x - 1)\)이고 \(g = (x + 1)(x - 1) + 0\)이므로 최대공약수는 \(x - 1\)이다. 거꾸로 따라가면 \(x - 1 = f - xg\)라는 베주 항등식을 얻으며, 그림 1이 이 경우이다.

흔한 오해정수 계수 다항식에서도 나눗셈 정리가 늘 된다고 여기기 쉽지만, \(x^2\)을 \(2x\)로 나누면 몫 \(\frac x2\)가 \(\mathbb Z[x]\)에 없다. 나누는 다항식이 모닉일 때에만 된다. 또 근의 개수의 상한이 모든 환에서 성립한다고 생각하는 것도 틀렸다. 정역이 아닌 \(\mathbb Z_8\)에서 \(x^2 - 1\)은 근이 \(1, 3, 5, 7\)로 4개이다.
마무리

처음 질문에 답하면, 체 위의 다항식에서도 최고차 계수로 나눌 수 있어 나눗셈 정리가 성립한다. 그래서 아이디얼의 차수가 가장 작은 원소가 그 아이디얼을 생성하여 \(F[x]\)는 주아이디얼정역이 되고, 유클리드 호제법으로 최대공약수와 베주 항등식을 얻는다. 계수가 정수이면 최고차 계수로 나눌 수 없어 \((2, x)\)처럼 하나로 생성되지 않는 아이디얼이 생긴다.

2.1.4연습문제

기본

  1. \(\mathbb Z_5[x]\)에서 \(x^3 + 2x + 1\)을 \(x - 2\)로 나눈 나머지를 구하여라.
    답

    나머지 정리로 \(8 + 4 + 1 = 13 \equiv 3\).

응용

  1. \(\mathbb Q[x]\)에서 아이디얼 \((x^2 - 1, x^3 - 1)\)의 생성원을 구하여라.
    답

    예 2.1.3으로 \(\gcd = x - 1\)이므로 \((x - 1)\).

심화

  1. \(F[x]\)에서 \((p)\)가 극대아이디얼 ⟺ \(p\)가 기약임을 보여라.
    답

    \((p) \subset (g)\) ⟺ \(g \mid p\). \(p\)가 기약이면 \(g\)는 단원이나 \(p\)의 상수배라 \((g)\)는 \(F[x]\) 또는 \((p)\). 반대로 \(p = gh\) (둘 다 비단원)이면 \((p) \subsetneq (g) \subsetneq F[x]\).
