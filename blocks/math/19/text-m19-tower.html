탑 법칙

본문
이 절에서 배울 것
  • \(F \subset K \subset E\)이면 \([E : F] = [E : K][K : F]\)임을 기저의 곱으로 증명한다.
  • 탑 법칙으로 확대 차수와 최소다항식의 차수를 계산한다.
  • 차수의 약수 조건으로 "이 원소는 이 체에 들어갈 수 없다"를 판정한다(작도 문제의 준비).
먼저 알아야 할 것
  • 최소다항식과 확대 차수 (3.1절).

3.2.1정리

정리 3.2.1 (탑 법칙) \(F \subset K \subset E\)가 체의 확대이면 \([E : F] = [E : K]\,[K : F]\). 더 정확히, \(\{\alpha_i\}\)가 \(K/F\)의 기저이고 \(\{\beta_j\}\)가 \(E/K\)의 기저이면 \(\{\alpha_i\beta_j\}\)는 \(E/F\)의 기저이다.
증명

생성: \(x \in E\)는 \(x = \sum_jk_j\beta_j\) (\(k_j \in K\))이고 각 \(k_j = \sum_ic_{ij}\alpha_i\) (\(c_{ij} \in F\))이므로 \(x = \sum c_{ij}\alpha_i\beta_j\). 일차독립: \(\sum c_{ij}\alpha_i\beta_j = 0\)이면 \(\sum_j\left(\sum_ic_{ij}\alpha_i\right)\beta_j = 0\)이고 \(\beta_j\)가 \(K\) 위에서 독립이라 각 \(\sum_ic_{ij}\alpha_i = 0\), \(\alpha_i\)가 \(F\) 위에서 독립이라 모든 \(c_{ij} = 0\). ∎

3.2.2계산

예 3.2.2 \([\mathbb Q(\sqrt2, \sqrt3) : \mathbb Q]\). \(\sqrt3 \notin \mathbb Q(\sqrt2)\)이면(\(\sqrt3 = a + b\sqrt2\)를 제곱하면 모순) \(x^2 - 3\)이 \(\mathbb Q(\sqrt2)\) 위에서 기약이라 \([\mathbb Q(\sqrt2, \sqrt3) : \mathbb Q(\sqrt2)] = 2\), 따라서 전체 4이고 기저는 \(1, \sqrt2, \sqrt3, \sqrt6\)입니다. 3.1절에서 \(\sqrt2 + \sqrt3\)의 차수가 4였으므로 \(\mathbb Q(\sqrt2 + \sqrt3) = \mathbb Q(\sqrt2, \sqrt3)\)입니다.
예 3.2.3 \([\mathbb Q(\sqrt[3]2, \sqrt2) : \mathbb Q]\). 두 부분체의 차수 3, 2가 모두 전체 차수를 나누므로 전체는 6의 배수이고, \(\le 3\cdot2 = 6\)이라 정확히 6입니다.

3.2.3차수로 판정하기

\(\alpha \in E\)이면 \(F \subset F(\alpha) \subset E\)라 \(\deg m_\alpha = [F(\alpha) : F]\)는 \([E : F]\)를 나눕니다. 예를 들어 \([\mathbb Q(\sqrt2) : \mathbb Q] = 2\)이므로 \(\sqrt[3]2 \notin \mathbb Q(\sqrt2)\)입니다(3은 2를 나누지 않음). 이 간단한 논법이 4단원 작도 문제의 핵심입니다.

흔한 오해(1) \([F(\alpha, \beta) : F] = [F(\alpha) : F][F(\beta) : F]\)라고 늘 여긴다. \(\beta\)가 이미 \(F(\alpha)\)에 있으면 아니다(\(\alpha = \sqrt2\), \(\beta = \sqrt8\)). 이 곱은 상한일 뿐이다. (2) 차수가 무한인 확대에는 탑 법칙이 의미가 없다고 여긴다. 기수의 곱으로 여전히 성립한다.
요약
  1. \([E : F] = [E : K][K : F]\), 기저는 곱 \(\alpha_i\beta_j\).
  2. \(\mathbb Q(\sqrt2, \sqrt3)\)은 차수 4, 기저 \(1, \sqrt2, \sqrt3, \sqrt6\).
  3. \(\alpha \in E\)이면 \(\deg m_\alpha \mid [E : F]\).

3.2.4연습문제

기본

  1. \([\mathbb Q(\sqrt[4]2) : \mathbb Q(\sqrt2)]\)를 구하여라.
    답

    \([\mathbb Q(\sqrt[4]2) : \mathbb Q] = 4\), \([\mathbb Q(\sqrt2) : \mathbb Q] = 2\)이고 \(\sqrt2 = (\sqrt[4]2)^2\)이라 탑 법칙으로 2.

응용

  1. \(\sqrt3 \notin \mathbb Q(\sqrt2)\)를 보여라.
    답

    \(\sqrt3 = a + b\sqrt2\)이면 \(3 = a^2 + 2b^2 + 2ab\sqrt2\). \(ab = 0\)이어야 하고 \(b = 0\)이면 \(a^2 = 3\), \(a = 0\)이면 \(2b^2 = 3\)으로 둘 다 유리수 해가 없다.

심화

  1. \([E : F] = p\)(소수)이면 \(F\)와 \(E\) 사이에 다른 체가 없음을 보여라.
    답

    중간체 \(K\)에 대해 \([K : F]\)는 \(p\)의 약수라 1 또는 \(p\), 즉 \(K = F\) 또는 \(K = E\).
