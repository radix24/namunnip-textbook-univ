작은 수로 RSA 한 바퀴

예제 · 키 생성에서 복호화까지

먼저 예측

\(p = 61\), \(q = 53\), \(e = 17\)로 RSA 키를 만든다. 비밀 키 \(d\)는 \(\bmod n = 3233\)의 역원일까, \(\bmod\varphi(n)\)의 역원일까?

예측 확인

\(\bmod\varphi(n) = 3120\)의 역원이다. 지수는 \(\bmod\varphi(n)\)으로 줄어들기 때문입니다(오일러 정리).

\(p = 61\), \(q = 53\), \(e = 17\)로 RSA 키를 만들고, 메시지 \(m = 65\)를 암호화한 뒤 다시 복호화하여라.

전략

\(n\), \(\varphi(n)\)을 구하고, 유클리드 호제법으로 \(17d \equiv 1 \pmod{3120}\)을 푼다. 거듭제곱은 제곱 반복으로 계산합니다(6.3절).

풀이

  1. \(n = 61\cdot53 = 3233\), \(\varphi(n) = 60\cdot52 = 3120\).
    \(\varphi(pq) = (p - 1)(q - 1)\).
  2. \(3120 = 17\cdot183 + 9\), \(17 = 9 + 8\), \(9 = 8 + 1\). 거꾸로: \(1 = 9 - 8 = 9 - (17 - 9) = 2\cdot9 - 17 = 2(3120 - 17\cdot183) - 17 = 2\cdot3120 - 367\cdot17\).
    확장 유클리드 호제법.
  3. \(d \equiv -367 \equiv 2753 \pmod{3120}\). 공개 키 \((3233, 17)\), 비밀 키 2753.
    \(17\cdot2753 = 46801 = 15\cdot3120 + 1\).
  4. 암호화 \(c = 65^{17} \bmod 3233 = 2790\). 복호화 \(2790^{2753} \bmod 3233 = 65\).
    제곱 반복으로 각각 곱셈 20번 안팎.

검산

정리 6.3.2의 증명대로 \(\bmod 61\)과 \(\bmod 53\)에서 따로 확인할 수 있다. \(ed = 46801 = 1 + 15\cdot3120\)이고 \(3120\)은 \(60\)과 \(52\)의 배수라 \(65^{ed} \equiv 65\)가 두 법에서 모두 성립한다.

의미

공개된 것은 \(n = 3233\)과 \(e = 17\)뿐이다. 이 작은 \(n\)은 쉽게 소인수분해되지만, 실제로는 수백 자리의 \(n\)을 써서 \(\varphi(n)\)과 \(d\)를 숨긴다. 계산 과정(호제법, 빠른 거듭제곱)은 자리수가 커져도 빠르다.

이해 확인

\(n = 33\), \(e = 3\), \(d = 7\)로 \(m = 4\)를 암호화하고 복호화하여라.

답

\(c = 4^3 = 64 \equiv 31\). \(31^7 \bmod 33\): \(31 \equiv -2\), \((-2)^7 = -128 \equiv -128 + 132 = 4\). 원래 메시지 4이다.
