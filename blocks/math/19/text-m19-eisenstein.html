기약 다항식과 아이젠슈타인 판정법

본문
이 절에서 배울 것
  • 2·3차 다항식은 근이 없으면 기약임을 이용하고, 유리근 정리로 근을 찾는다.
  • 아이젠슈타인 판정법을 증명하고 \(x^n - p\), 원분 다항식 \(\Phi_p(x)\)의 기약성에 적용한다.
  • \(\bmod p\) 판정법으로 기약성을 확인한다.
먼저 알아야 할 것
  • 다항식 나눗셈과 인수정리 (2.1절).

2.2.1낮은 차수와 유리근

체 위에서 2차·3차 다항식이 인수분해되면 1차 인수, 즉 근이 있습니다. 따라서 근이 없으면 기약입니다(4차부터는 2차×2차가 가능해 이 방법이 안 됩니다). 정수 계수 \(f = a_nx^n + \cdots + a_0\)의 유리근 \(\frac rs\) (기약분수)는 \(r \mid a_0\), \(s \mid a_n\)을 만족합니다(유리근 정리).

예 2.2.1 \(x^3 - 2\)의 유리근 후보는 \(\pm1, \pm2\)이고 모두 근이 아니므로 \(\mathbb Q\)에서 기약입니다.

2.2.2아이젠슈타인 판정법

정리 2.2.2 (아이젠슈타인) \(f = a_nx^n + \cdots + a_0 \in \mathbb Z[x]\)와 소수 \(p\)가 \(p \nmid a_n\), \(p \mid a_i\) (\(i < n\)), \(p^2 \nmid a_0\)을 만족하면 \(f\)는 \(\mathbb Q[x]\)에서 기약이다.
증명

가우스 보조정리(2.4절)로 \(\mathbb Z[x]\)에서의 분해 \(f = gh\) (\(\deg g, \deg h \ge 1\))만 배제하면 된다. \(\bmod p\)로 보면 \(\bar f = \bar a_nx^n\)이고 \(\mathbb Z_p[x]\)가 유일인수분해정역이므로 \(\bar g = bx^k\), \(\bar h = cx^{n-k}\) (\(k, n - k \ge 1\)). 그러면 \(g, h\)의 상수항이 모두 \(p\)의 배수라 \(a_0 = g(0)h(0)\)이 \(p^2\)의 배수가 되어 모순이다. ∎

예 2.2.3
  • \(x^n - p\)는 \(p\)로 아이젠슈타인 조건을 만족해 모든 \(n\)에서 기약입니다. 따라서 \(\mathbb Q[x]\)에는 모든 차수의 기약 다항식이 있습니다.
  • \(\Phi_p(x) = x^{p-1} + \cdots + x + 1 = \frac{x^p - 1}{x - 1}\)은 그대로는 판정이 안 되지만, \(x \to x + 1\)로 바꾸면 \(\frac{(x + 1)^p - 1}x = x^{p-1} + \binom p1x^{p-2} + \cdots + \binom p{p-1}\)이고 \(p \mid \binom pk\) (\(0 < k < p\)), 상수항 \(p\)라 아이젠슈타인 조건을 만족합니다. 기약성은 치환에 대해 보존되므로 \(\Phi_p\)는 기약입니다.

2.2.3mod p 판정법

모닉 \(f \in \mathbb Z[x]\)가 어떤 소수 \(p\)에 대해 \(\bmod p\)에서 기약이면 \(\mathbb Q\)에서도 기약입니다(분해되면 \(\bmod p\)에서도 같은 차수로 분해되므로). 예를 들어 \(x^3 + x + 1\)은 \(\mathbb Z_2\)에서 근이 없어(\(f(0) = f(1) = 1\)) 기약이므로 \(\mathbb Q\)에서도 기약입니다. 반대는 성립하지 않습니다. \(x^4 + 1\)은 \(\mathbb Q\)에서 기약이지만 모든 소수 \(p\)에서 \(\bmod p\)로 분해됩니다.

흔한 오해(1) 아이젠슈타인 조건을 만족하지 않으면 기약이 아니라고 여긴다. 판정법은 충분조건일 뿐이다(\(x^2 + 1\)). (2) 4차 다항식이 근이 없으면 기약이라고 여긴다. \(x^4 + 4 = (x^2 + 2x + 2)(x^2 - 2x + 2)\).
요약
  1. 2·3차는 근이 없으면 기약, 유리근 후보는 \(\frac rs\) (\(r \mid a_0\), \(s \mid a_n\)).
  2. 아이젠슈타인: \(p \mid\) 나머지 계수, \(p \nmid\) 최고차, \(p^2 \nmid\) 상수항 ⇒ 기약.
  3. \(x^n - p\), \(\Phi_p(x + 1)\), \(\bmod p\) 판정법.

2.2.4연습문제

기본

  1. \(2x^5 - 6x^3 + 9x^2 - 15\)이 \(\mathbb Q\)에서 기약임을 보여라.
    답

    \(p = 3\): \(3 \nmid 2\), \(3 \mid -6, 9, -15\), \(9 \nmid -15\).

응용

  1. \(x^3 + 3x + 2\)가 \(\mathbb Q\)에서 기약인지 판정하여라.
    답

    후보 \(\pm1, \pm2\): \(f(1) = 6\), \(f(-1) = -2\), \(f(2) = 16\), \(f(-2) = -12\). 근이 없으므로 기약.

심화

  1. \(x^4 + 1\)이 \(\mathbb Q\)에서 기약임을 \(x \to x + 1\)로 보여라.
    답

    \((x + 1)^4 + 1 = x^4 + 4x^3 + 6x^2 + 4x + 2\)는 \(p = 2\)로 아이젠슈타인 조건을 만족한다.
