기약 다항식과 아이젠슈타인 판정법

본문

기약 다항식은 새로운 체를 만드는 재료이다. 그런데 주어진 다항식이 \(\mathbb Q\)에서 기약인지 어떻게 판정할까? 2차와 3차는 근을 찾아보면 되지만, 차수가 높아지면 어떤 방법이 있을까?

먼저 알아야 할 것다항식 나눗셈과 인수정리(2.1절)를 쓴다.

2.2.1낮은 차수와 유리근

체 위에서 2차나 3차 다항식이 인수분해되면 1차 인수, 곧 근이 있다. 따라서 근이 없으면 기약이다. 4차부터는 2차와 2차의 곱으로 분해될 수 있으므로 이 방법이 통하지 않는다. 또 정수 계수 \(f = a_nx^n + \cdots + a_0\)의 유리근을 기약분수 \(\frac rs\)로 쓰면 \(r \mid a_0\), \(s \mid a_n\)이며, 이것을 유리근 정리라 한다.

예제 2.2.1

\(x^3 - 2\)가 \(\mathbb Q\)에서 기약임을 보여라.

풀이. 유리근의 후보는 \(\pm1, \pm2\)이고 모두 근이 아니다. 3차 다항식이 근이 없으므로 \(\mathbb Q\)에서 기약이다.

2.2.2아이젠슈타인 판정법

정리 2.2.2 (아이젠슈타인)

\(f = a_nx^n + \cdots + a_0 \in \mathbb Z[x]\)와 소수 \(p\)가 \(p \nmid a_n\), \(i < n\)에서 \(p \mid a_i\), \(p^2 \nmid a_0\)을 만족하면 \(f\)는 \(\mathbb Q[x]\)에서 기약이다.

증명.2.4절의 가우스 보조정리에 의해, \(\deg g, \deg h \ge 1\)인 \(\mathbb Z[x]\)에서의 분해 \(f = gh\)만 배제하면 된다. \(p\)로 나눈 나머지를 보면 \(\bar f = \bar a_nx^n\)이고, \(\mathbb Z_p[x]\)가 유일인수분해정역이므로 \(k, n - k \ge 1\)에 대해 \(\bar g = bx^k\), \(\bar h = cx^{n-k}\)이다. 그러면 \(g\)와 \(h\)의 상수항이 모두 \(p\)의 배수라 \(a_0 = g(0)h(0)\)이 \(p^2\)의 배수가 되어 모순이다. ∎

예제 2.2.3

\(x^n - p\)와 \(\Phi_p(x) = x^{p-1} + \cdots + x + 1\)이 기약임을 보여라.

풀이. \(x^n - p\)는 \(p\)에 대해 아이젠슈타인 조건을 만족하므로 모든 \(n\)에서 기약이다. 그러므로 \(\mathbb Q[x]\)에는 모든 차수의 기약 다항식이 있다. 한편 \(\Phi_p(x) = \frac{x^p - 1}{x - 1}\)은 그대로는 판정이 안 되지만, \(x\)를 \(x + 1\)로 바꾸면 \(\frac{(x + 1)^p - 1}x = x^{p-1} + \binom p1x^{p-2} + \cdots + \binom p{p-1}\)이 된다. \(0 < k < p\)에서 \(p \mid \binom pk\)이고 상수항이 \(p\)이므로 아이젠슈타인 조건을 만족한다. 그림 1이 \(p = 5\)인 경우이다. 기약성은 이런 치환에 대해 보존되므로 \(\Phi_p\)는 기약이다.

2.2.3\(p\)로 나눈 나머지로 판정하기

모닉 \(f \in \mathbb Z[x]\)가 어떤 소수 \(p\)에 대해 \(\mathbb Z_p\)에서 기약이면 \(\mathbb Q\)에서도 기약이다. \(\mathbb Q\)에서 분해되면 \(\mathbb Z_p\)에서도 같은 차수로 분해되기 때문이다. 예를 들어 \(x^3 + x + 1\)은 \(f(0) = f(1) = 1\)이라 \(\mathbb Z_2\)에서 근이 없어 기약이므로 \(\mathbb Q\)에서도 기약이다. 그러나 그 반대는 성립하지 않는다. \(x^4 + 1\)은 \(\mathbb Q\)에서 기약이지만 모든 소수 \(p\)에 대해 \(\mathbb Z_p\)에서는 분해된다.

흔한 오해아이젠슈타인 조건을 만족하지 않으면 기약이 아니라고 여기기 쉽지만, 판정법은 충분조건일 뿐이며 \(x^2 + 1\)이 그 예이다. 또 4차 다항식이 근이 없으면 기약이라고 생각하는 것도 틀렸다. \(x^4 + 4 = (x^2 + 2x + 2)(x^2 - 2x + 2)\)이다.
마무리

처음 질문에 답하면, 2차와 3차 다항식은 유리근 정리로 근의 후보를 확인해 근이 없으면 기약이다. 차수가 높으면 아이젠슈타인 판정법을 써서, 어떤 소수 \(p\)가 최고차 계수를 빼고 모든 계수를 나누되 \(p^2\)이 상수항을 나누지 않음을 보인다. 그대로 안 되면 \(x \to x + 1\) 같은 치환을 하거나, 어떤 소수로 나눈 나머지에서 기약임을 보이는 방법도 쓴다.

2.2.4연습문제

기본

  1. \(2x^5 - 6x^3 + 9x^2 - 15\)이 \(\mathbb Q\)에서 기약임을 보여라.
    답

    \(p = 3\): \(3 \nmid 2\), \(3 \mid -6, 9, -15\), \(9 \nmid -15\).

응용

  1. \(x^3 + 3x + 2\)가 \(\mathbb Q\)에서 기약인지 판정하여라.
    답

    후보 \(\pm1, \pm2\): \(f(1) = 6\), \(f(-1) = -2\), \(f(2) = 16\), \(f(-2) = -12\). 근이 없으므로 기약.

심화

  1. \(x^4 + 1\)이 \(\mathbb Q\)에서 기약임을 \(x \to x + 1\)로 보여라.
    답

    \((x + 1)^4 + 1 = x^4 + 4x^3 + 6x^2 + 4x + 2\)는 \(p = 2\)로 아이젠슈타인 조건을 만족한다.
