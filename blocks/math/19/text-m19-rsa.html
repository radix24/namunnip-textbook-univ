RSA 암호

본문
이 절에서 배울 것
  • 오일러 정리 \(a^{\varphi(n)} \equiv 1 \pmod n\) (\(\gcd(a, n) = 1\))을 군론으로 증명한다.
  • \(n = pq\), \(ed \equiv 1 \pmod{\varphi(n)}\)이면 \((m^e)^d \equiv m \pmod n\)임을 보이고 RSA의 암호화·복호화를 설명한다.
  • RSA의 안전성이 \(n\)의 소인수분해의 어려움에 기댄다는 것을 이해한다.
먼저 알아야 할 것
  • 중국인의 나머지 정리와 \(\varphi\) (1.4절), 라그랑주 정리, 빠른 거듭제곱 (6.2절).

6.3.1오일러 정리

정리 6.3.1 (오일러) \(\gcd(a, n) = 1\)이면 \(a^{\varphi(n)} \equiv 1 \pmod n\).
증명

\(\bar a\)는 위수 \(\varphi(n)\)인 군 \(\mathbb Z_n^\times\)의 원소이므로 라그랑주 정리로 그 위수가 \(\varphi(n)\)을 나누고, \(\bar a^{\varphi(n)} = 1\). ∎

\(n = p\)가 소수이면 페르마 소정리 \(a^{p-1} \equiv 1\)입니다.

6.3.2RSA

  1. 키 만들기: 큰 소수 \(p, q\)를 골라 \(n = pq\), \(\varphi(n) = (p - 1)(q - 1)\). \(\gcd(e, \varphi(n)) = 1\)인 \(e\)를 고르고, 유클리드 호제법으로 \(ed \equiv 1 \pmod{\varphi(n)}\)인 \(d\)를 구한다. 공개 키 \((n, e)\), 비밀 키 \(d\).
  2. 암호화: 메시지 \(m\) (\(0 \le m < n\))을 \(c = m^e \bmod n\)으로 보낸다.
  3. 복호화: \(c^d \bmod n = m\).
정리 6.3.2 \(ed \equiv 1 \pmod{\varphi(n)}\)이면 모든 \(m\)에 대해 \(m^{ed} \equiv m \pmod{pq}\).
증명

\(ed = 1 + t(p - 1)(q - 1)\). \(\bmod p\)로 보면 \(p \nmid m\)이면 페르마로 \(m^{ed} = m\cdot(m^{p-1})^{t(q-1)} \equiv m\), \(p \mid m\)이면 양변이 0. \(\bmod q\)도 같다. 중국인의 나머지 정리로 \(\bmod pq\)에서 같다. ∎

같은 절의 예제 카드에서 작은 수로 전 과정을 계산합니다.

6.3.3안전성

\(d\)를 구하려면 \(\varphi(n)\)이 필요하고, \(\varphi(n)\)을 알면 \(p + q = n - \varphi(n) + 1\)과 \(pq = n\)으로 \(p, q\)를 바로 구할 수 있으므로 \(\varphi(n)\)을 아는 것은 \(n\)을 소인수분해하는 것과 같습니다. 2048비트 \(n\)의 소인수분해는 현재 알려진 방법으로 불가능에 가깝습니다. 반면 암호화와 복호화는 빠른 거듭제곱으로 빠릅니다. 다만 양자컴퓨터의 쇼어 알고리즘은 소인수분해와 이산로그를 모두 빠르게 풀 수 있어, 양자내성 암호가 연구되고 있습니다.

흔한 오해(1) \(e\)와 \(d\)가 \(\bmod n\)에서 역원이라고 여긴다. \(\bmod\varphi(n)\)이다. (2) 공개 키로 암호문을 "거꾸로" 풀 수 있다고 여긴다. \(c \mapsto c^{1/e}\)은 \(\bmod n\)의 \(e\)제곱근 문제로, \(\varphi(n)\)을 모르면 어렵다.
요약
  1. 오일러 정리: \(a^{\varphi(n)} \equiv 1\), 라그랑주 정리의 결과.
  2. RSA: \(c = m^e\), \(m = c^d\), \(ed \equiv 1 \pmod{\varphi(n)}\).
  3. \(\varphi(n)\)을 아는 것 = \(n\)의 소인수분해: 안전성의 근거.

6.3.4연습문제

기본

  1. \(7^{40} \bmod 100\)을 오일러 정리로 구하여라.
    답

    \(\varphi(100) = 40\), \(\gcd(7, 100) = 1\)이라 1.

응용

  1. \(n = 33\), \(e = 3\)에서 비밀 키 \(d\)를 구하여라.
    답

    \(\varphi(33) = 20\), \(3d \equiv 1 \pmod{20}\)에서 \(d = 7\).

심화

  1. \(n = 3233\), \(\varphi(n) = 3120\)을 알면 \(p, q\)를 구하여라.
    답

    \(p + q = 3233 - 3120 + 1 = 114\), \(pq = 3233\). \(t^2 - 114t + 3233 = 0\)에서 \(t = 57 \pm 4\), \(p = 61\), \(q = 53\).
