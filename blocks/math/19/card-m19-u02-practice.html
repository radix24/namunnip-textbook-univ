다항식환과 인수분해 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(\mathbb Z_3[x]\)에서 \(x^4 + 1\)을 기약 인수로 분해하여라. [02-01]

    힌트 1

    근이 없음을 확인(\(0, 1, 2\)).

    힌트 2

    \((x^2 + ax + b)(x^2 - ax + b')\) 꼴을 시도.

    풀이

    \(x^4 + 1 = (x^2 + x + 2)(x^2 + 2x + 2)\). 전개하면 \(x^4 + 3x^3 + (2 + 2 + 2)x^2 + 6x + 4 \equiv x^4 + 1\). 두 2차식은 근이 없어 기약 (2.1절).

  2. 계산\(x^3 - 3x - 1\)이 \(\mathbb Q\)에서 기약임을 두 가지 방법(유리근, mod 2)으로 보여라. [02-02]

    힌트 1

    후보 \(\pm1\).

    힌트 2

    \(\bmod 2\): \(x^3 + x + 1\).

    풀이

    \(f(1) = -3\), \(f(-1) = 1\)이라 유리근이 없고 3차라 기약. 또는 \(\bmod 2\)로 \(x^3 + x + 1\)은 \(\mathbb Z_2\)에서 근이 없어 기약 (2.2절). 이 다항식은 \(2\cos\frac{2\pi}9\)의 최소다항식이다(4.2절).

  3. 계산아이젠슈타인 판정법을 쓸 수 있도록 \(x^2 + 4x + 1\)에 치환 \(x \to x - 2\)를 하고 기약성을 판정하여라. [02-02]

    힌트 1

    \((x - 2)^2 + 4(x - 2) + 1\).

    힌트 2

    \(x^2 - 3\).

    풀이

    \(x^2 - 4x + 4 + 4x - 8 + 1 = x^2 - 3\), \(p = 3\)으로 아이젠슈타인. 따라서 기약(근 \(-2 \pm \sqrt3\)은 무리수).

  4. 증명UFD에서 기약원은 소원임을 보여라. [02-03]

    힌트 1

    \(a \mid bc\)이면 \(bc = ad\).

    힌트 2

    양변을 기약원으로 분해해 비교.

    풀이

    \(bc = ad\)에서 \(b, c, d\)를 기약원으로 분해하면 유일성으로 \(a\)의 단원배가 \(b\)나 \(c\)의 분해에 나타나야 한다. 따라서 \(a \mid b\) 또는 \(a \mid c\) (2.3절). ∎

  5. 계산\(\mathbb Z[\sqrt{-3}]\)에서 \(4 = 2\cdot2 = (1 + \sqrt{-3})(1 - \sqrt{-3})\)이 서로 다른 기약 분해임을 노름으로 보여라. [02-03]

    힌트 1

    \(N(a + b\sqrt{-3}) = a^2 + 3b^2\).

    힌트 2

    노름 2인 원소?

    풀이

    모든 인수의 노름이 4이고 노름 2인 원소가 없어(\(a^2 + 3b^2 = 2\) 해 없음) 모두 기약이다. 단원은 \(\pm1\)뿐이라 \(2\)와 \(1 \pm \sqrt{-3}\)은 단원배가 아니므로 분해가 두 가지이다.

  6. 판단"\(\mathbb Z[x]\)에서 \(2x + 2\)는 기약원이다"는 옳은가? [02-04]

    힌트 1

    내용 \(c(2x + 2)\).

    힌트 2

    2는 \(\mathbb Z[x]\)의 단원인가?

    풀이

    틀리다. \(2x + 2 = 2(x + 1)\)이고 2와 \(x + 1\) 모두 단원이 아니다. \(\mathbb Q[x]\)에서는 2가 단원이라 기약이지만 \(\mathbb Z[x]\)에서는 아니다 (2.4절).
