다항식의 최대공약수와 베주 항등식

예제 · 유클리드 호제법

먼저 예측

\(f = x^4 - 1\)과 \(g = x^3 - 2x^2 + 2x - 1\)은 둘 다 \(x = 1\)에서 0이다. 최대공약수는 \(x - 1\)보다 클까?

예측 확인

아니다. \(f = (x - 1)(x + 1)(x^2 + 1)\), \(g = (x - 1)(x^2 - x + 1)\)이라 공통인 것은 \(x - 1\)뿐이다.

\(\mathbb Q[x]\)에서 \(\gcd(f, g)\)를 유클리드 호제법으로 구하고, \(\gcd = uf + vg\)인 \(u, v\)를 구하여라.

전략

나머지가 0이 될 때까지 나눗셈을 반복하고, 마지막 0이 아닌 나머지를 모닉으로 만든다. 베주 항등식은 나눗셈 식을 거꾸로 대입해 얻습니다(2.1절).

풀이

  1. \(f = (x + 2)g + r_1\), \(r_1 = 2x^2 - 3x + 1\).
    \(x\cdot g = x^4 - 2x^3 + 2x^2 - x\)를 빼고, 다시 \(2g\)를 뺀다.
  2. \(g = \left(\frac x2 - \frac14\right)r_1 + r_2\), \(r_2 = \frac34(x - 1)\).
    \(\mathbb Q\)에서 나눗셈이라 분수 계수가 나온다.
  3. \(r_1 = (2x - 1)(x - 1)\)이라 \(r_2\)로 나누어떨어진다. 따라서 \(\gcd = x - 1\).
    상수배는 무시하고 모닉으로.
  4. \(r_2 = g - q_2r_1 = g - q_2(f - q_1g) = -q_2f + (1 + q_1q_2)g\)이고 \(\frac43\)을 곱하면 \(x - 1 = \left(-\frac23x + \frac13\right)f + \left(\frac23x^2 + x + \frac23\right)g\).
    \(q_1 = x + 2\), \(q_2 = \frac x2 - \frac14\), \(1 + q_1q_2 = \frac{x^2}2 + \frac{3x}4 + \frac12\).

검산

\(x = 2\)를 넣으면 \(f = 15\), \(g = 3\)이고 오른쪽은 \((-1)\cdot15 + \frac{16}3\cdot3 = 1 = 2 - 1\). \(x = 0\)이면 \(f = -1\), \(g = -1\)이고 \(\frac13(-1) + \frac23(-1) = -1 = 0 - 1\). 맞다.

의미

베주 항등식은 아이디얼 \((f, g) = (x - 1)\)의 구체적인 증거이다. 같은 계산을 \(\mathbb Z_p[x]\)에서 하면 \(p(x)\)가 기약일 때 \(\mathbb Z_p[x]/(p)\)에서의 역원을 구하는 방법이 됩니다(유한체 계산의 기본).

이해 확인

\(\gcd(x^2 + 1, x + 1)\)과 베주 계수는?

답

\(x^2 + 1 = (x - 1)(x + 1) + 2\)라 gcd는 1이고 \(1 = \frac12(x^2 + 1) - \frac12(x - 1)(x + 1)\).
