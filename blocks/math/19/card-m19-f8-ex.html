원소 8개인 체 만들기

예제 · F₂[x]/(x³ + x + 1)

먼저 예측

\(\mathbb F_8\)의 0 아닌 원소 7개는 하나의 원소 \(\alpha\)의 거듭제곱 \(\alpha, \alpha^2, \dots, \alpha^7\)으로 모두 나타날까요?

예측 확인

그렇습니다. 곱셈군의 위수가 소수 7이라 1이 아닌 모든 원소가 생성원입니다(4.4절에서 일반적으로 순환군임을 증명).

\(\mathbb F_8 = \mathbb F_2[x]/(x^3 + x + 1)\)을 만들고 \(\alpha = \bar x\)의 거듭제곱으로 0 아닌 원소를 모두 나열한 뒤, \((\alpha^2 + \alpha)(\alpha^2 + \alpha + 1)\)과 \(\alpha^{-1}\)을 구하여라.

전략

\(x^3 + x + 1\)은 \(\mathbb F_2\)에서 근이 없어(\(f(0) = f(1) = 1\)) 3차 기약이므로 몫은 원소 \(2^3 = 8\)개인 체입니다. 계산 규칙은 \(\alpha^3 = \alpha + 1\) (계수는 \(\bmod 2\))뿐입니다(4.3절).

풀이

  1. \(\alpha^1 = \alpha\), \(\alpha^2\), \(\alpha^3 = \alpha + 1\), \(\alpha^4 = \alpha^2 + \alpha\), \(\alpha^5 = \alpha^3 + \alpha^2 = \alpha^2 + \alpha + 1\), \(\alpha^6 = \alpha^3 + \alpha^2 + \alpha = \alpha^2 + 1\), \(\alpha^7 = \alpha^3 + \alpha = 1\).
    매번 \(\alpha\)를 곱하고 \(\alpha^3\)을 \(\alpha + 1\)로 바꾼다.
  2. 7개가 모두 달라 \(\mathbb F_8^\times = \{\alpha^k : 0 \le k \le 6\}\)이고 \(\alpha\)가 생성원이다.
    \(a + b\alpha + c\alpha^2\) (\(a, b, c \in \{0, 1\}\))의 0 아닌 7개가 모두 나왔다.
  3. \((\alpha^2 + \alpha)(\alpha^2 + \alpha + 1) = \alpha^4\cdot\alpha^5 = \alpha^9 = \alpha^2\).
    거듭제곱으로 바꾸면 곱셈이 지수의 덧셈(\(\bmod 7\))이 된다.
  4. \(\alpha^{-1} = \alpha^6 = \alpha^2 + 1\).
    \(\alpha\cdot\alpha^6 = \alpha^7 = 1\).

검산

\(\alpha(\alpha^2 + 1) = \alpha^3 + \alpha = (\alpha + 1) + \alpha = 1\) (\(2\alpha = 0\)). 맞습니다. 직접 전개해도 \((\alpha^2 + \alpha)(\alpha^2 + \alpha + 1) = \alpha^4 + 2\alpha^3 + 2\alpha^2 + \alpha = \alpha^4 + \alpha = \alpha^2 + \alpha + \alpha = \alpha^2\)입니다.

의미

원소를 "벡터 \((a, b, c)\)"로 보면 덧셈이 쉽고, "\(\alpha\)의 지수"로 보면 곱셈이 쉽습니다. 이 이중 표현(로그표)이 컴퓨터의 유한체 계산, 리드-솔로몬 오류정정 부호(QR 코드, CD)와 AES 암호(\(\mathbb F_{256}\))의 바탕입니다.

이해 확인

\(\mathbb F_8\)에서 \(\alpha^3 + \alpha^5\)을 \(\alpha\)의 거듭제곱으로 나타내어라.

답

\((\alpha + 1) + (\alpha^2 + \alpha + 1) = \alpha^2\)입니다(\(2\alpha = 2 = 0\)).
