대수적 원소의 합과 곱, 대수적 수의 체

본문
이 절에서 배울 것
  • 유한 확대의 모든 원소가 대수적임을 보인다.
  • \(\alpha, \beta\)가 대수적이면 \(\alpha \pm \beta\), \(\alpha\beta\), \(\frac\alpha\beta\)도 대수적임을 탑 법칙으로 증명한다.
  • \(\mathbb C\) 안의 대수적 수 전체 \(\bar{\mathbb Q}\)가 체이고 대수적으로 닫혀 있음을 안다.
먼저 알아야 할 것
  • 최소다항식 (3.1절), 탑 법칙 (3.2절).

3.3.1유한 확대는 대수적

보조정리 3.3.1 \([E : F] = n < \infty\)이면 \(E\)의 모든 원소는 \(F\) 위에서 대수적이고 최소다항식의 차수는 \(n\)의 약수이다.
증명

\(\gamma \in E\)이면 \(n + 1\)개의 원소 \(1, \gamma, \dots, \gamma^n\)은 \(n\)차원 공간에서 일차종속이므로 \(\sum c_k\gamma^k = 0\)인 0 아닌 \(c_k \in F\)가 있다. 차수는 탑 법칙(3.2절). ∎

3.3.2합과 곱

정리 3.3.2 \(\alpha, \beta\)가 \(F\) 위에서 대수적이면 \(\alpha \pm \beta\), \(\alpha\beta\), \(\frac\alpha\beta\) (\(\beta \ne 0\))도 대수적이다.
증명

\(\beta\)는 \(F(\alpha)\) 위에서도 대수적이므로(같은 다항식) \([F(\alpha, \beta) : F] = [F(\alpha, \beta) : F(\alpha)][F(\alpha) : F] < \infty\). 네 원소는 모두 \(F(\alpha, \beta)\)에 있으므로 보조정리 3.3.1로 대수적이다. ∎

이 증명은 존재만 보여 줍니다. 실제 다항식을 구하려면 근호를 하나씩 없애는 계산이 필요하고, 같은 절의 예제 카드에서 \(\sqrt2 + \sqrt[3]2\)의 경우를 계산합니다. 차수 상한은 \([\mathbb Q(\sqrt2, \sqrt[3]2) : \mathbb Q] = 6\)입니다.

3.3.3대수적 수의 체

정리 3.3.2로 \(\bar{\mathbb Q} = \{\alpha \in \mathbb C : \alpha\text{ is algebraic over }\mathbb Q\}\)는 \(\mathbb C\)의 부분체입니다. 그 원소를 대수적 수라 합니다. 더 나아가 \(\bar{\mathbb Q}\)는 대수적으로 닫혀 있습니다. 대수적 수 계수 다항식의 근은 다시 대수적 수입니다(근 \(\gamma\)는 계수들로 만든 유한 확대 위에서 대수적이고, 탑 법칙으로 \(\mathbb Q\) 위에서도 대수적). \(\bar{\mathbb Q}\)는 \(\mathbb Q\)의 대수적 폐포이고, 일반적인 체 \(F\)의 대수적 폐포의 존재는 초른 보조정리로 보입니다.

한편 \([\bar{\mathbb Q} : \mathbb Q] = \infty\)입니다. \(\sqrt[n]2\)의 차수가 \(n\)이라(아이젠슈타인) 임의로 큰 차수의 원소가 들어 있기 때문입니다.

흔한 오해(1) 대수적 수가 근호로 나타나는 수라고 여긴다. \(x^5 - x - 1\)의 근은 대수적이지만 근호로 쓸 수 없다(5.4절). (2) 대수적 수의 합의 차수가 두 차수의 합이라고 여긴다. 곱 이하이고, \(\sqrt2 + \sqrt3\)는 \(2\times2 = 4\)이다.
요약
  1. 유한 확대의 원소는 대수적이고 차수는 확대 차수의 약수.
  2. 대수적 원소의 합·차·곱·몫은 대수적: \(F(\alpha, \beta)\)가 유한 확대이므로.
  3. \(\bar{\mathbb Q}\)는 체이고 대수적으로 닫혀 있으며 \(\mathbb Q\) 위에서 무한 차수.

3.3.4연습문제

기본

  1. \(\sqrt2\sqrt3\)의 최소다항식은?
    답

    \(\sqrt6\)이므로 \(x^2 - 6\).

응용

  1. \(\alpha = \sqrt[3]2\)일 때 \(\alpha^2 + \alpha\)가 차수 3인 다항식의 근임을 보이고 그 다항식을 구하여라.
    답

    \(\gamma = \alpha^2 + \alpha\). \(\gamma^2 = \alpha^4 + 2\alpha^3 + \alpha^2 = 2\alpha + 4 + \alpha^2\), \(\gamma^3 = \gamma\cdot\gamma^2\)을 계산해 기저 \(1, \alpha, \alpha^2\)로 정리하면 \(\gamma^3 = 6\gamma + 6\)이라 \(x^3 - 6x - 6\) (\(p = 2\) 또는 \(p = 3\)으로 아이젠슈타인 조건을 만족해 기약).

심화

  1. 초월수 \(\pi\)에 대해 \(\pi + \sqrt2\)가 초월수임을 보여라.
    답

    대수적이라면 \(\pi = (\pi + \sqrt2) - \sqrt2\)가 대수적 수의 차라 대수적이어야 하므로 모순.
