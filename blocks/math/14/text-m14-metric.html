거리공간의 연속과 열린집합

본문
이 절에서 배울 것
  • 거리공간의 열린 공과 열린집합을 다시 정리하고, 거리마다 생기는 위상을 비교한다.
  • 연속의 \(\varepsilon\)-\(\delta\) 정의가 "열린집합의 역상은 열린집합"과 동치임을 증명한다.
  • 위상동치인 거리와 그렇지 않은 거리의 예를 들고, 위상공간으로 넘어가는 동기를 이해한다.
먼저 알아야 할 것
  • 거리공간, 열린집합과 닫힌집합 (수학7 1.2절), 연속의 세 가지 얼굴 (수학7 3.1절).

1.1.1거리와 열린 공

거리(metric): 집합 \(X\) 위의 함수 \(d: X\times X \to [0, \infty)\)로 (1) \(d(x, y) = 0 \iff x = y\), (2) \(d(x, y) = d(y, x)\), (3) \(d(x, z) \le d(x, y) + d(y, z)\)를 만족하는 것.

열린 공 \(B_d(x, r) = \{y : d(x, y) < r\}\). 열린집합: 각 점을 중심으로 하는 어떤 열린 공을 포함하는 집합.

\(\mathbb R^2\)의 세 거리 \(d_1(x, y) = |x_1 - y_1| + |x_2 - y_2|\), \(d_2\) (유클리드), \(d_\infty(x, y) = \max|x_i - y_i|\)의 열린 공은 각각 마름모, 원, 정사각형입니다. 모양은 다르지만

\[d_\infty \le d_2 \le d_1 \le 2d_\infty\]

이므로 한 거리의 공 안에 다른 거리의 공이 항상 들어갑니다. 그래서 세 거리는 같은 열린집합들을 줍니다.

위상동치(topologically equivalent): 두 거리가 같은 열린집합들을 정하는 것. 상수 \(c, C > 0\)으로 \(c\,d \le d' \le C\,d\)이면(강동치) 위상동치이다.

같은 절의 탐구 카드에서 \(p\)-거리 \(d_p = (|x_1 - y_1|^p + |x_2 - y_2|^p)^{1/p}\)의 공이 서로 끼워 들어가는 모습을 봅니다. 반대로 이산거리 \(d(x, y) = 1\) (\(x \ne y\))은 한 점 \(\{x\} = B(x, \frac12)\)이 열린집합이라 유클리드 거리와 위상동치가 아닙니다.

1.1.2연속의 열린집합 특징

정리 1.1.1

거리공간 사이의 함수 \(f: (X, d) \to (Y, \rho)\)에 대해 다음은 동치이다. (a) 모든 \(x\)와 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어 \(d(x, y) < \delta \Rightarrow \rho(f(x), f(y)) < \varepsilon\). (b) \(Y\)의 모든 열린집합 \(V\)에 대해 \(f^{-1}(V)\)는 \(X\)에서 열려 있다. (c) \(Y\)의 모든 닫힌집합 \(F\)에 대해 \(f^{-1}(F)\)는 닫혀 있다.

증명.(a ⇒ b) \(V\)가 열려 있고 \(x \in f^{-1}(V)\)이면 \(B_\rho(f(x), \varepsilon) \subseteq V\)인 \(\varepsilon\)이 있다. (a)의 \(\delta\)에 대해 \(B_d(x, \delta) \subseteq f^{-1}(B_\rho(f(x), \varepsilon)) \subseteq f^{-1}(V)\). 따라서 \(f^{-1}(V)\)는 열려 있다. (b ⇒ a) \(V = B_\rho(f(x), \varepsilon)\)은 열려 있으므로 \(f^{-1}(V)\)가 열려 있고 \(x\)를 포함한다. 따라서 \(B_d(x, \delta) \subseteq f^{-1}(V)\)인 \(\delta\)가 있고 이것이 (a)이다. (b ⇔ c) \(f^{-1}(Y\setminus A) = X\setminus f^{-1}(A)\). ∎

(b)는 거리를 쓰지 않고 열린집합만으로 말합니다. 그래서 위상동치인 거리로 바꿔도 연속성은 그대로이고, 거리가 없는 공간(2단원의 위상공간)에서도 연속을 정의할 수 있습니다. 주의할 것은 순상(정방향 상)이 아니라 역상이라는 점입니다. \(f(x) = x^2\)은 연속이지만 열린집합 \((-1, 1)\)의 상 \([0, 1)\)은 열려 있지 않습니다.

1.1.3거리로 정해지지 않는 성질

열린집합만으로 정해지는 성질(연속, 수렴, 컴팩트, 연결)을 위상적 성질이라 합니다. 반면 유계성과 완비성은 거리에 따라 달라집니다. 예를 들어 \(\mathbb R\)에서 \(d'(x, y) = |\arctan x - \arctan y|\)는 유클리드 거리와 위상동치이지만 \(\mathbb R\)이 유계가 되고, 수열 \(x_n = n\)이 코시 수열인데 수렴하지 않아 완비도 아닙니다. 이 구별이 1.2절의 베르 범주 정리에서 중요합니다.

흔한 오해(1) "연속함수는 열린집합을 열린집합으로 보낸다"(역상이어야 한다). (2) "위상동치인 거리는 같은 코시 수열을 가진다"(\(\arctan\) 거리가 반례). (3) 열린 공의 모양이 다르면 위상이 다르다고 여긴다.
요약
  1. 열린집합: 각 점에서 열린 공을 포함. \(d_1, d_2, d_\infty\)는 서로 상수배로 비교되어 같은 위상.
  2. 연속 ⟺ 열린집합의 역상이 열림 ⟺ 닫힌집합의 역상이 닫힘.
  3. 연속, 컴팩트, 연결은 위상적이고, 유계와 완비는 거리에 의존한다.

1.1.4연습문제

기본

  1. \(d_2 \le d_1 \le \sqrt2\,d_2\)를 증명하여라.
    답

    \((a + b)^2 = a^2 + b^2 + 2ab \ge a^2 + b^2\)에서 첫 부등식, 코시-슈바르츠 \(a + b \le \sqrt2\sqrt{a^2 + b^2}\)에서 둘째 부등식 (\(a = |x_1 - y_1|\), \(b = |x_2 - y_2|\)).

응용

  1. 이산거리 공간에서 모든 함수 \(f: X \to Y\)가 연속임을 보여라.
    답

    이산거리에서는 모든 부분집합이 열린집합(각 점이 \(B(x, \frac12) = \{x\}\))이므로 어떤 역상도 열려 있다.

심화

  1. \(d\)가 거리이면 \(\bar d = \min(d, 1)\)도 거리이고 \(d\)와 위상동치임을 보여라.
    답

    삼각부등식: \(\bar d(x, y) + \bar d(y, z) \ge \min(d(x, y) + d(y, z), 1) \ge \min(d(x, z), 1)\). 반지름 1 미만의 공은 두 거리에서 같으므로 같은 열린집합을 준다. 따라서 모든 거리는 유계인 거리로 바꿔도 위상이 같다.
