축소사상 정리

본문

계산기에 아무 수나 넣고 cos 버튼을 계속 누르면 0.739085…에 멈춘다. 왜 시작한 수와 상관없이 같은 값에 모일까? 몇 번 누르면 소수 여섯째 자리까지 맞는지 미리 알 수 있을까? 그리고 이 현상이 미분방정식의 해의 존재와 무슨 관계일까?

먼저 알아야 할 것완비 거리공간과 코시 수열(1.2절)과 평균값 정리를 쓴다.

1.3.1정리

정의

거리공간 \((X, d)\)의 사상 \(T\)가 어떤 \(0 \le q < 1\)에 대해 \(d(Tx, Ty) \le q\,d(x, y)\)이면 축소사상이라 한다.

정리 1.3.1 (바나흐)

\(X\)가 공집합이 아닌 완비 거리공간이고 \(T\)가 축소사상이면 \(T\)는 고정점 \(x^*\)를 꼭 하나 가지며, 아무 \(x_0\)에서 시작한 \(x_{n+1} = Tx_n\)은 \(x^*\)로 수렴한다. 또 \(d(x_n, x^*) \le \frac{q^n}{1 - q}d(x_1, x_0)\)이다.

증명.\(d(x_{k+1}, x_k) \le q^kd(x_1, x_0)\)이므로 \(m > n\)이면 \(d(x_m, x_n) \le (q^n + \cdots + q^{m-1})d(x_1, x_0) \le \frac{q^n}{1 - q}d(x_1, x_0) \to 0\)이다. 따라서 코시 수열이고, \(X\)가 완비라 \(x_n \to x^*\)이다. \(T\)는 연속이므로 \(Tx^* = \lim Tx_n = \lim x_{n+1} = x^*\)이다. 고정점이 둘이면 \(d(x^*, y^*) \le q\,d(x^*, y^*)\)라 같다. 오차 한계는 위 부등식에서 \(m \to \infty\)로 보내면 나온다. ∎

1.3.2예와 오차 한계

예제 1.3.2

\(T(x) = \cos x\)가 \([0, 1]\)의 축소사상임을 보이고, \(x_0 = 0\)에서 오차 \(10^{-6}\)을 보장하는 반복 횟수를 구하여라.

풀이. \(\cos\)은 \([0, 1]\)을 \([\cos1, 1] \subset [0, 1]\)로 보내고, 평균값 정리로 \(|\cos x - \cos y| \le \sin1\cdot|x - y|\)이다. 따라서 \(q = \sin1 \approx 0.8415\)인 축소사상이고, \([0, 1]\)은 완비이므로 \(\cos x = x\)의 해가 유일하게 있다. \(x_0 = 0\)에서 \(d(x_1, x_0) = 1\)이라, 오차 \(10^{-6}\)을 보장하려면 \(\frac{0.8415^n}{0.1585} \le 10^{-6}\), 곧 \(n \ge 91\)이다. 하지만 실제로는 33번이면 된다. 고정점 근처의 기울기 \(|\sin x^*| \approx 0.674\)가 전체의 최댓값 0.8415보다 작기 때문이다.

1.3.3조건이 모두 필요하다

완비성이 필요하다. \(X = (0, 1]\)에서 \(T(x) = \frac x2\)는 축소사상이지만 고정점 0이 \(X\)에 없다. 또 균일한 \(q < 1\)도 필요하다. \(X = [1, \infty)\)에서 \(T(x) = x + \frac1x\)는 \(x \ne y\)이면 \(|Tx - Ty| < |x - y|\)이지만 균일한 \(q\)가 없고, 고정점도 없다.

한편 상미분방정식의 해의 존재와 유일성을 주는 피카르 반복(수학6 1.2절)과 역함수정리(수학11)는 모두 적당한 함수공간에서 이 정리를 쓴 것이다. 즉 "해를 찾는 문제"를 "축소사상의 고정점을 찾는 문제"로 바꾸는 것이 이 정리의 쓰임새이다.

흔한 오해\(|Tx - Ty| < |x - y|\)이면 충분하다고 여기기 쉽지만, 상수 \(q < 1\)이 필요하다. 또 오차 한계를 실제 오차라고 여기는 것도 틀렸다. 그것은 최악의 경우를 보장하는 위쪽 한계라 실제 수렴은 훨씬 빠를 수 있다.
마무리

처음 질문에 답하면, \(\cos\)은 \([0, 1]\)에서 두 점의 거리를 \(\sin 1\)배 이하로 줄이는 축소사상이므로, 바나흐 고정점 정리에 따라 어디서 시작하든 유일한 고정점 0.739085…로 모인다. 반복 횟수는 \(d(x_n, x^*) \le \frac{q^n}{1 - q}d(x_1, x_0)\)으로 미리 보장할 수 있으며, 오차 \(10^{-6}\)에는 91번이면 충분하다. 완비성과 균일한 \(q < 1\)이 모두 필요하며, 같은 원리가 피카르 반복으로 미분방정식의 해를 준다.

1.3.4연습문제

기본

  1. \(T(x) = \frac x3 + 1\)의 고정점과 축소 상수를 구하여라.
    답

    \(x = \frac x3 + 1\)에서 \(x^* = \frac32\), \(q = \frac13\).

응용

  1. 1번에서 \(x_0 = 0\)이면 오차 \(10^{-3}\)을 보장하는 \(n\)을 오차 한계로 구하여라.
    답

    \(d(x_1, x_0) = 1\): \(\frac{(1/3)^n}{2/3} \le 10^{-3}\), \(3^n \ge 1500\), \(n \ge 7\).

심화

  1. \(T\)가 축소사상이 아니어도 \(T^2\)이 축소사상이면 \(T\)는 유일한 고정점을 가짐을 보여라.
    답

    \(T^2\)의 유일한 고정점 \(x^*\)에 대해 \(T^2(Tx^*) = T(T^2x^*) = Tx^*\)라 \(Tx^*\)도 \(T^2\)의 고정점, 유일성으로 \(Tx^* = x^*\). \(T\)의 고정점은 \(T^2\)의 고정점이라 유일.
