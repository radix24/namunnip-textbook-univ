축소사상 정리

본문
이 절에서 배울 것
  • 완비 거리공간 위의 축소사상이 유일한 고정점을 가지고 반복이 그 점으로 수렴함(바나흐 고정점 정리)을 증명한다.
  • 사전 오차 한계 \(d(x_n, x^*) \le \frac{q^n}{1 - q}d(x_1, x_0)\)로 필요한 반복 횟수를 어림한다.
  • 완비성과 축소 조건이 모두 필요함을 반례로 확인한다.
먼저 알아야 할 것
  • 완비 거리공간과 코시 수열 (1.2절), 평균값 정리.

1.3.1정리

거리공간 \((X, d)\)의 사상 \(T\)가 어떤 \(0 \le q < 1\)에 대해 \(d(Tx, Ty) \le q\,d(x, y)\)이면 축소사상이라 합니다.

정리 1.3.1 (바나흐) \(X\)가 공집합이 아닌 완비 거리공간이고 \(T\)가 축소사상이면 \(T\)는 고정점 \(x^*\)를 꼭 하나 가지며, 아무 \(x_0\)에서 시작한 \(x_{n+1} = Tx_n\)은 \(x^*\)로 수렴한다. 또 \(d(x_n, x^*) \le \frac{q^n}{1 - q}d(x_1, x_0)\).
증명

\(d(x_{k+1}, x_k) \le q^kd(x_1, x_0)\)이라 \(m > n\)이면 \(d(x_m, x_n) \le (q^n + \cdots + q^{m-1})d(x_1, x_0) \le \frac{q^n}{1 - q}d(x_1, x_0) \to 0\). 코시 수열이고 \(X\)가 완비라 \(x_n \to x^*\). \(T\)는 연속이라 \(Tx^* = \lim Tx_n = \lim x_{n+1} = x^*\). 고정점이 둘이면 \(d(x^*, y^*) = d(Tx^*, Ty^*) \le q\,d(x^*, y^*)\)라 같다. 오차 한계는 위 부등식에서 \(m \to \infty\). ∎

1.3.2예와 오차 한계

예 1.3.2 \(T(x) = \cos x\)를 \([0, 1]\)에서 봅니다. \(\cos\)은 \([0, 1]\)을 \([\cos1, 1] \subset [0, 1]\)로 보내고, 평균값 정리로 \(|\cos x - \cos y| \le \sin1\cdot|x - y|\)라 \(q = \sin1 \approx 0.8415\)인 축소사상입니다. \([0, 1]\)은 완비이므로 \(\cos x = x\)의 해가 유일하게 있습니다(\(0.739085\cdots\)). \(x_0 = 0\)에서 \(d(x_1, x_0) = 1\)이라, 오차 \(10^{-6}\)을 보장하려면 \(\frac{0.8415^n}{0.1585} \le 10^{-6}\), 곧 \(n \ge 91\)입니다. 실제로는 33번이면 됩니다. 고정점 근처의 기울기 \(|\sin x^*| \approx 0.674\)가 전체의 최댓값 0.8415보다 작기 때문입니다.

1.3.3조건이 모두 필요하다

  • 완비성: \(X = (0, 1]\), \(T(x) = \frac x2\)는 축소사상이지만 고정점 0이 \(X\)에 없다.
  • \(q < 1\): \(T(x) = x + \frac1x\) (\(X = [1, \infty)\))는 \(|Tx - Ty| < |x - y|\) (\(x \ne y\))이지만 균일한 \(q\)가 없고 고정점도 없다.

상미분방정식의 해의 존재와 유일성(피카르 반복, 수학6 1.2절)과 역함수 정리(수학11)는 모두 적당한 함수공간에서 이 정리를 쓴 것입니다.

흔한 오해(1) \(|Tx - Ty| < |x - y|\)이면 충분하다고 여긴다. 상수 \(q < 1\)이 필요하다. (2) 오차 한계가 실제 오차라고 여긴다. 최악의 경우를 보장하는 위쪽 한계라 실제는 훨씬 빠를 수 있다.
요약
  1. 완비 + 축소(\(q < 1\)) ⟹ 유일한 고정점, 반복이 수렴.
  2. \(d(x_n, x^*) \le \frac{q^n}{1 - q}d(x_1, x_0)\).
  3. 완비성과 균일한 \(q\)가 모두 필요.

1.3.4연습문제

기본

  1. \(T(x) = \frac x3 + 1\)의 고정점과 축소 상수를 구하여라.
    답

    \(x = \frac x3 + 1\)에서 \(x^* = \frac32\), \(q = \frac13\).

응용

  1. 1번에서 \(x_0 = 0\)이면 오차 \(10^{-3}\)을 보장하는 \(n\)을 오차 한계로 구하여라.
    답

    \(d(x_1, x_0) = 1\): \(\frac{(1/3)^n}{2/3} \le 10^{-3}\), \(3^n \ge 1500\), \(n \ge 7\).

심화

  1. \(T\)가 축소사상이 아니어도 \(T^2\)이 축소사상이면 \(T\)는 유일한 고정점을 가짐을 보여라.
    답

    \(T^2\)의 유일한 고정점 \(x^*\)에 대해 \(T^2(Tx^*) = T(T^2x^*) = Tx^*\)라 \(Tx^*\)도 \(T^2\)의 고정점, 유일성으로 \(Tx^* = x^*\). \(T\)의 고정점은 \(T^2\)의 고정점이라 유일.
