칸토어 집합과 프랙탈 차원

본문
이 절에서 배울 것
  • 칸토어 집합이 컴팩트, 완전(고립점 없음), 완전 비연결이고 비가산이며 측도 0임을 보인다.
  • 칸토어 집합이 \(\{0, 2\}^\omega\)와 위상동형임을 3진 전개로 이해한다.
  • 자기닮음으로 프랙탈 차원 \(\log2/\log3\)을 구하고 상자 세기 차원과 비교한다.
먼저 알아야 할 것
  • 컴팩트성과 티호노프 정리 (5.3절), 연결 성분 (4.1절), 측도 0 (수학11 4.1절, 함께 보면 좋음).

7.2.1정의와 위상적 성질

\(C_0 = [0, 1]\)에서 가운데 열린 삼등분 \((\frac13, \frac23)\)을 빼면 \(C_1 = [0, \frac13]\cup[\frac23, 1]\), 남은 구간마다 다시 가운데 삼등분을 빼면 \(C_2\), …. 칸토어 집합 \(C = \bigcap_nC_n\)입니다.

  • 컴팩트: 닫힌집합들의 교집합이라 닫혀 있고 \([0, 1]\) 안에 있다.
  • 측도 0: \(C_n\)의 길이는 \((\frac23)^n \to 0\).
  • 완전 비연결: 두 점 \(x < y\)에 대해 \(\frac1{3^n} < y - x\)이면 둘은 \(C_n\)의 서로 다른 구간에 있고, 그 사이에 빠진 구간의 점 \(r\)이 있어 \(C\)를 \(r\) 왼쪽과 오른쪽으로 분리한다.
  • 고립점이 없다: 남은 구간의 끝점(예: \(\frac13, \frac29\))은 모두 \(C\)에 남고, \(C\)의 각 점 근처에 그런 끝점이 한없이 많다.

7.2.23진 전개와 \(\{0, 2\}^\omega\)

\(x \in [0, 1]\)을 3진법으로 \(0.a_1a_2a_3\cdots_{(3)}\)라 쓰면, 1단계에서 빠지는 수는 \(a_1 = 1\)인 수(끝점 \(\frac13 = 0.1_{(3)} = 0.0222\cdots_{(3)}\) 같은 경우는 1을 쓰지 않는 전개를 택함)입니다. 따라서

\[C = \{0.a_1a_2\cdots_{(3)} : a_i \in \{0, 2\}\}.\]

사상 \(h: \{0, 2\}^\omega \to C\), \(h(a) = \sum a_i3^{-i}\)는 전단사이고 연속입니다(앞의 \(n\)자리가 같으면 값의 차가 \(3^{-n}\) 이하). \(\{0, 2\}^\omega\)은 티호노프 정리로 컴팩트이고 \(C\)는 하우스도르프이므로 \(h\)는 위상동형입니다(5.1절). 이로부터 \(C\)는 비가산입니다(\(\{0, 2\}^\omega\)는 0과 1의 무한 수열 전체와 같아 비가산). 측도가 0인데도 \([0, 1]\)과 같은 "개수"의 점을 가지는 것입니다.

칸토어 함수(악마의 계단) \(\varphi(0.a_1a_2\cdots_{(3)}) = 0.\frac{a_1}2\frac{a_2}2\cdots_{(2)}\)는 \(C\)를 \([0, 1]\) 위로 보내는 연속 전사입니다. 그래서 칸토어 집합은 "모든 컴팩트 거리공간의 원천"이라 불립니다(모든 컴팩트 거리공간은 \(C\)의 연속상).

7.2.3프랙탈 차원

선분을 \(\frac13\) 크기로 줄이면 원래의 \(\frac13\)짜리 3개가 필요하고, 정사각형을 \(\frac13\)로 줄이면 9개, 정육면체는 27개가 필요합니다. 일반적으로 \(r\)배로 줄인 사본 \(N\)개로 원래 도형이 정확히 이루어지면 \(N = r^{-D}\)로 차원을 정의합니다(자기닮음 차원).

\[D = \frac{\log N}{\log(1/r)}.\]

칸토어 집합은 \(\frac13\) 크기의 사본 2개(왼쪽과 오른쪽)로 이루어지므로

\[D = \frac{\log2}{\log3} \approx 0.6309.\]

점(0차원)보다 크고 선분(1차원)보다 작은 정수가 아닌 차원입니다. 실제 계산에서는 상자 세기 차원을 씁니다. 한 변 \(\varepsilon\)인 상자로 도형을 덮는 데 필요한 최소 개수 \(N(\varepsilon)\)에 대해 \(D = \lim_{\varepsilon\to0}\frac{\log N(\varepsilon)}{\log(1/\varepsilon)}\). 칸토어 집합은 \(\varepsilon = 3^{-n}\)일 때 \(N = 2^n\)이라 같은 값 \(\frac{\log2}{\log3}\)이 나옵니다. 코흐 곡선은 \(\frac13\) 크기 사본 4개라 \(\frac{\log4}{\log3} \approx 1.2619\), 시에르핀스키 삼각형은 \(\frac12\) 크기 3개라 \(\frac{\log3}{\log2} \approx 1.585\)입니다.

흔한 오해(1) "칸토어 집합에는 끝점만 남는다": 끝점은 가산 개뿐이고, \(\frac14 = 0.0202\cdots_{(3)}\) 같은 끝점이 아닌 점이 비가산 개 남는다. (2) 위상차원과 프랙탈 차원을 혼동한다. 칸토어 집합의 위상차원은 0(완전 비연결)이고 프랙탈 차원은 0.6309이다.
요약
  1. 칸토어 집합: 컴팩트, 완전, 완전 비연결, 비가산, 측도 0.
  2. \(C = \{\sum a_i3^{-i} : a_i \in \{0, 2\}\} \cong \{0, 2\}^\omega\).
  3. 자기닮음 차원 \(\frac{\log N}{\log(1/r)}\): 칸토어 \(\frac{\log2}{\log3} \approx 0.6309\), 코흐 1.2619, 시에르핀스키 1.585.

7.2.4연습문제

기본

  1. \(\frac14\)과 \(\frac34\)이 칸토어 집합에 속함을 3진 전개로 보여라.
    답

    \(\frac14 = 0.020202\cdots_{(3)}\) (\(\frac14 = \frac{2}{9}\cdot\frac1{1 - 1/9} = \frac29\cdot\frac98\)), \(\frac34 = 1 - \frac14 = 0.202020\cdots_{(3)}\). 둘 다 0과 2로만 이루어진다.

응용

  1. \([0, 1]\)에서 가운데 \(\frac15\)을 빼는 과정을 반복해 얻는 집합의 프랙탈 차원을 구하여라.
    답

    각 단계에서 \(\frac25\) 크기의 사본 2개가 남으므로 \(D = \frac{\log2}{\log(5/2)} \approx 0.7565\).

심화

  1. \(C + C = \{x + y : x, y \in C\} = [0, 2]\)임을 3진 전개로 설명하여라.
    답

    \(\frac{x + y}2 = \sum\frac{a_i + b_i}{2}3^{-i}\)이고 \(\frac{a_i + b_i}2 \in \{0, 1, 2\}\)는 임의의 3진 숫자를 만들 수 있으므로 \(\frac{C + C}2 = [0, 1]\). 측도 0인 두 집합의 합이 길이 2인 구간이 된다.
