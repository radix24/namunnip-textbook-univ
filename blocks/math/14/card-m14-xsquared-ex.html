x²은 [0, R]에서는 균등연속, R 전체에서는 아니다

예제 · 컴팩트성이 δ를 지켜 준다

먼저 예측

\(f(x) = x^2\)에서 \(\epsilon = 1\)에 맞는 \(\delta\)를 하나로 정할 수 있을까요? 구간이 \([0, 10]\)이면? \(\mathbb R\) 전체이면?

예측 확인

\([0, 10]\)에서는 \(\delta = 0.05\)면 됩니다. \(\mathbb R\)에서는 어떤 \(\delta\)도 안 됩니다.

(1) \([0, R]\)에서 \(|x - y| < \delta\)이면 \(|x^2 - y^2| < \epsilon\)이 되는 \(\delta\)를 구하여라. (2) \(\mathbb R\)에서는 균등연속이 아님을 보여라.

전략

\(|x^2 - y^2| = |x - y||x + y|\). 컴팩트 구간에서는 \(|x + y| \le 2R\)로 막힙니다(5.5절).

풀이

  1. \([0, R]\)에서 \(|x^2 - y^2| \le 2R|x - y|\)라 \(\delta = \frac\epsilon{2R}\). \(R = 10\), \(\epsilon = 1\)이면 \(\delta = 0.05\).
    점에 무관한 \(\delta\).
  2. \(\mathbb R\)에서: \(\delta > 0\)을 아무리 작게 잡아도 \(x = \frac1\delta\), \(y = \frac1\delta + \frac\delta2\)이면 \(|x - y| < \delta\)인데 \(|x^2 - y^2| = \frac\delta2\left(\frac2\delta + \frac\delta2\right) > 1\).
    멀리 가면 기울기가 커짐.
  3. \(\epsilon = 1\)에 맞는 \(\delta\)가 없어 균등연속이 아니다.
    정의의 부정.

검산

\(\delta = 0.05\)로 \(x = 10\), \(y = 9.96\)이면 \(|x^2 - y^2| = 0.7984 < 1\) ✓. \(\delta = 0.05\), \(x = 20\), \(y = 20.025\)이면 \(|x^2 - y^2| \approx 1.0006 > 1\)로, 구간이 넓어지면 같은 \(\delta\)가 통하지 않습니다.

의미

정리 5.5.2가 말하는 것은 바로 이 차이입니다. 컴팩트 집합에서는 "가장 나쁜 곳"이 존재해 그곳에 맞춘 \(\delta\)가 모든 곳에 통합니다. 무한히 뻗은 공간에서는 점점 나빠지는 곳이 끝없이 있습니다.

이해 확인

\(f(x) = x^3\)을 \([-2, 2]\)에서 \(\epsilon = 0.1\)로 맞추는 \(\delta\)는?

답

\(|x^3 - y^3| = |x - y||x^2 + xy + y^2| \le 12|x - y|\)이라 \(\delta = \frac{0.1}{12} \approx 0.0083\).
