로랑 급수와 고립 특이점

본문
이 절에서 배울 것
  • 고리 영역에서 정칙인 함수가 음의 거듭제곱까지 포함한 로랑 급수로 쓰임을 안다.
  • 고립 특이점을 제거 가능, 극, 진성 특이점으로 분류하고 로랑 급수의 주요부로 판정한다.
  • 진성 특이점 근처에서 함숫값이 어디에나 가까이 간다는 카소라티-바이어슈트라스 정리를 증명한다.
먼저 알아야 할 것
  • 코시 적분 공식과 멱급수 (2.2절), 리우빌 정리 (2.3절).

3.1.1로랑 급수

\(f\)가 고리 \(r < |z - z_0| < R\)에서 정칙이면

\[f(z) = \sum_{n=-\infty}^\infty a_n(z - z_0)^n, \qquad a_n = \frac1{2\pi i}\oint\frac{f(\zeta)}{(\zeta - z_0)^{n+1}}d\zeta\]

로 쓰입니다(코시 적분 공식을 바깥 원과 안쪽 원에 쓰고 각각 등비급수로 전개). 음의 거듭제곱 부분 \(\sum_{n<0}\)을 주요부라 합니다.

예 3.1.1 \(e^{1/z} = \sum_{n\ge0}\frac1{n!z^n}\) (\(z \ne 0\)): 주요부가 무한히 많습니다. \(\frac{\sin z}{z^3} = \frac1{z^2} - \frac16 + \frac{z^2}{120} - \cdots\): 주요부 \(\frac1{z^2}\) 하나입니다.

3.1.2분류

\(f\)가 \(0 < |z - z_0| < R\)에서 정칙일 때 \(z_0\)은

  • 제거 가능: 주요부가 0. \(f\)를 \(z_0\)까지 정칙으로 연장할 수 있다. ⟺ \(z_0\) 근처에서 \(f\)가 유계(리만 정리). 예: \(\frac{\sin z}z\).
  • \(m\)차 극: 주요부가 유한하고 최저 차수가 \(-m\). ⟺ \(|f| \to \infty\). 예: \(\frac{\sin z}{z^3}\)은 원점에서 2차 극.
  • 진성 특이점: 주요부가 무한. 예: \(e^{1/z}\)의 원점.

3.1.3카소라티-바이어슈트라스 정리

정리 3.1.2 \(z_0\)이 \(f\)의 진성 특이점이면 \(z_0\)의 아무리 작은 근방에서도 \(f\)의 값은 \(\mathbb C\)의 모든 점에 한없이 가까이 간다(상이 조밀하다).
증명

그렇지 않다면 어떤 \(w\)와 \(\delta > 0\)이 있어 \(z_0\) 근처에서 \(|f(z) - w| \ge \delta\)이다. \(g = \frac1{f - w}\)은 유계(\(\le\frac1\delta\))라 \(z_0\)이 제거 가능하다. \(g(z_0) \ne 0\)이면 \(f = w + \frac1g\)이 \(z_0\)에서 정칙, \(g(z_0) = 0\)이면 \(f\)는 극을 가진다. 어느 쪽이든 진성 특이점이라는 가정에 모순. ∎

예 3.1.3 \(e^{1/z}\)은 \(z = \frac1{\log w + 2\pi ik}\) (\(k\)가 커질수록 0에 가까움)에서 값 \(w \ne 0\)을 정확히 가집니다. 0만 빼고 모든 값을 원점 근처에서 무한히 자주 가지며, 이것이 더 강한 피카르 정리의 예입니다.
흔한 오해(1) 분모가 0이 되는 점은 모두 극이라고 여긴다. \(\frac{\sin z}z\)의 원점은 제거 가능하다. (2) 로랑 급수가 영역에 무관하다고 여긴다. 같은 함수라도 고리마다 급수가 다르다(\(\frac1{z(z - 1)}\)의 \(0 < |z| < 1\)과 \(|z| > 1\) 전개).
요약
  1. 고리에서 로랑 급수, 음의 차수 부분이 주요부.
  2. 제거 가능(유계), 극(\(|f| \to \infty\)), 진성(주요부 무한).
  3. 진성 특이점 근처에서 상은 조밀(카소라티-바이어슈트라스).

3.1.4연습문제

기본

  1. \(\frac{1 - \cos z}{z^2}\), \(\frac{e^z}{z^3}\), \(\sin\frac1z\)의 원점 특이점을 분류하여라.
    답

    제거 가능(\(\frac12 - \frac{z^2}{24} + \cdots\)), 3차 극, 진성.

응용

  1. \(\frac1{z(z - 1)}\)을 \(0 < |z| < 1\)과 \(|z| > 1\)에서 각각 로랑 급수로 써라.
    답

    \(0 < |z| < 1\): \(-\frac1z\cdot\frac1{1 - z} = -\frac1z - 1 - z - \cdots\). \(|z| > 1\): \(\frac1{z^2}\cdot\frac1{1 - 1/z} = \frac1{z^2} + \frac1{z^3} + \cdots\).

심화

  1. \(e^{1/z} = 1\)인 \(z\)를 모두 구하고 원점으로 모임을 확인하여라.
    답

    \(\frac1z = 2\pi ik\) (\(k \ne 0\)), \(z = \frac1{2\pi ik} \to 0\).
