복소 미분과 코시-리만 방정식

본문
이 절에서 배울 것
  • 복소함수의 미분을 실함수와 같은 극한으로 정의하고, 극한이 모든 방향에서 같아야 한다는 조건이 강력함을 이해한다.
  • \(f = u + iv\)가 복소 미분 가능하면 코시-리만 방정식 \(u_x = v_y\), \(u_y = -v_x\)가 성립함을 증명하고, 역의 충분조건을 안다.
  • \(z^2\), \(e^z\)는 정칙이고 \(\bar z\), \(|z|^2\)는 그렇지 않음을 확인한다.
먼저 알아야 할 것
  • 복소수의 연산과 극형식, 미분계수의 정의(고등학교 수학).

1.1.1복소 미분

열린집합 \(\Omega \subset \mathbb C\)에서 정의된 \(f\)가 점 \(z_0\)에서

\[f'(z_0) = \lim_{h\to0}\frac{f(z_0 + h) - f(z_0)}h\]

(\(h\)는 0으로 가는 복소수)가 존재하면 복소 미분 가능하다고 하고, \(\Omega\)의 모든 점에서 미분 가능하면 정칙이라 합니다. 식은 실함수와 같지만, \(h\)가 실수축·허수축·대각선 등 모든 방향에서 0으로 갈 때 같은 값이어야 한다는 점이 다릅니다.

예 1.1.1 \(f(z) = z^2\)이면 \(\frac{(z + h)^2 - z^2}h = 2z + h \to 2z\). 정칙이고 \(f' = 2z\). 반면 \(f(z) = \bar z\)이면 \(\frac{\overline{z + h} - \bar z}h = \frac{\bar h}h\)인데, \(h\)가 실수이면 1, 순허수이면 \(-1\)이라 극한이 없습니다. \(\bar z\)는 어디서도 미분 가능하지 않습니다.

1.1.2코시-리만 방정식

\(z = x + iy\), \(f = u(x, y) + iv(x, y)\)로 쓰겠습니다. 두 변수 함수 \(u(x, y)\)에서 \(y\)를 고정하고 \(x\)로만 미분한 것을 \(u_x\)(\(x\)에 대한 편미분), \(x\)를 고정하고 \(y\)로만 미분한 것을 \(u_y\)라 씁니다. 예를 들어 \(u = x^2 - y^2\)이면 \(u_x = 2x\), \(u_y = -2y\)입니다.

정리 1.1.2 \(f = u + iv\)가 \(z_0\)에서 복소 미분 가능하면 그 점에서 \(u_x = v_y\), \(u_y = -v_x\)이고 \(f'(z_0) = u_x + iv_x\)이다.
증명

\(h = t\) (실수)로 0에 보내면 \(f'(z_0) = \lim\frac{f(z_0 + t) - f(z_0)}t = u_x + iv_x\). \(h = it\) (순허수)로 보내면 \(f'(z_0) = \lim\frac{f(z_0 + it) - f(z_0)}{it} = \frac1i(u_y + iv_y) = v_y - iu_y\). 두 값이 같으므로 실수부와 허수부를 비교한다. ∎

반대로 \(u, v\)의 편미분이 연속이고 코시-리만 방정식을 만족하면 \(f\)는 정칙입니다(편미분이 연속이면 \(u, v\)가 국소적으로 일차함수로 잘 근사되기 때문).

예 1.1.3 \(e^z = e^x\cos y + ie^x\sin y\): \(u_x = e^x\cos y = v_y\), \(u_y = -e^x\sin y = -v_x\). 정칙이고 \((e^z)' = u_x + iv_x = e^z\). \(|z|^2 = x^2 + y^2\)이면 \(v = 0\)이라 \(u_x = 2x = v_y = 0\)이 원점에서만 성립해, 원점에서만 미분 가능하고 어떤 열린집합에서도 정칙이 아닙니다.
흔한 오해(1) \(u, v\)가 매끄러우면 \(f\)가 정칙이라고 여긴다. \(\bar z = x - iy\)는 \(u, v\)가 다항식인데도 코시-리만을 어겨 정칙이 아니다. (2) 한 점에서 미분 가능하면 그 점에서 정칙이라고 여긴다. 정칙은 근방 전체에서 미분 가능해야 한다(\(|z|^2\)는 원점에서 미분 가능하지만 정칙이 아니다).
요약
  1. 복소 미분: 모든 방향에서 같은 극한.
  2. 코시-리만: \(u_x = v_y\), \(u_y = -v_x\), \(f' = u_x + iv_x\).
  3. 편미분이 연속이고 코시-리만을 만족하면 정칙. \(\bar z\), \(|z|^2\)는 정칙 아님.

1.1.4연습문제

기본

  1. \(f(z) = z^3\)의 \(u, v\)를 구하고 코시-리만 방정식을 확인하여라.
    답

    \(u = x^3 - 3xy^2\), \(v = 3x^2y - y^3\). \(u_x = 3x^2 - 3y^2 = v_y\), \(u_y = -6xy = -v_x\).

응용

  1. \(f(z) = x^2 + iy^2\)이 미분 가능한 점을 모두 구하여라.
    답

    \(u_x = 2x\), \(v_y = 2y\), \(u_y = 0 = -v_x\). 직선 \(y = x\) 위에서만 미분 가능하고, 어디서도 정칙이 아니다.

심화

  1. \(f\)가 연결된 열린집합에서 정칙이고 실수값만 가지면 상수임을 보여라.
    답

    \(v = 0\)이라 \(u_x = v_y = 0\), \(u_y = -v_x = 0\). 모든 편미분이 0이고 연결이라 \(u\)는 상수.
