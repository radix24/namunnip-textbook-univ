복소 미분과 코시-리만 방정식

본문

복소함수의 미분계수도 실함수처럼 \(\lim\frac{f(z_0 + h) - f(z_0)}h\)로 정의한다. 그런데 복소수 \(h\)는 실수축, 허수축, 대각선 등 온갖 방향에서 0으로 다가갈 수 있다. 이 차이가 미분 가능성을 얼마나 까다롭게 만들까? 실수부와 허수부로 나누어 보면 어떤 조건이 될까?

먼저 알아야 할 것복소수의 연산과 극형식, 미분계수의 정의를 쓴다.

1.1.1복소 미분

열린집합 \(\Omega \subset \mathbb C\)에서 정의된 \(f\)가 점 \(z_0\)에서 다음 극한을 가지면 복소 미분 가능하다고 한다. 여기서 \(h\)는 0으로 가는 복소수이다.

\[f'(z_0) = \lim_{h\to0}\frac{f(z_0 + h) - f(z_0)}h\]

\(\Omega\)의 모든 점에서 미분 가능하면 \(f\)를 정칙이라 한다. 식은 실함수와 같지만, 그림 1처럼 \(h\)가 모든 방향에서 0으로 갈 때 같은 값이어야 한다는 점이 다르다.

예제 1.1.1

\(f(z) = z^2\)과 \(f(z) = \bar z\)의 미분 가능성을 조사하여라.

풀이. \(f(z) = z^2\)이면 \(\frac{(z + h)^2 - z^2}h = 2z + h \to 2z\)이므로 정칙이고 \(f' = 2z\)이다. 반면 \(f(z) = \bar z\)이면 차분몫이 \(\frac{\overline{z + h} - \bar z}h = \frac{\bar h}h\)인데, \(h\)가 실수이면 1이고 순허수이면 \(-1\)이라 극한이 없다. 그러므로 \(\bar z\)는 어디서도 미분 가능하지 않다.

1.1.2코시-리만 방정식

\(z = x + iy\), \(f = u(x, y) + iv(x, y)\)로 쓰자. 두 변수 함수 \(u(x, y)\)에서 \(y\)를 고정하고 \(x\)로만 미분한 것을 \(x\)에 대한 편미분 \(u_x\), \(x\)를 고정하고 \(y\)로만 미분한 것을 \(u_y\)라 쓴다. 예를 들어 \(u = x^2 - y^2\)이면 \(u_x = 2x\), \(u_y = -2y\)이다.

정리 1.1.2

\(f = u + iv\)가 \(z_0\)에서 복소 미분 가능하면, 그 점에서 \(u_x = v_y\), \(u_y = -v_x\)이고 \(f'(z_0) = u_x + iv_x\)이다.

증명.먼저 \(h = t\)를 실수로 잡아 0으로 보내면 \(f'(z_0) = \lim\frac{f(z_0 + t) - f(z_0)}t = u_x + iv_x\)이다. 다음으로 \(h = it\)를 순허수로 잡아 보내면 \(f'(z_0) = \lim\frac{f(z_0 + it) - f(z_0)}{it} = \frac1i(u_y + iv_y) = v_y - iu_y\)이다. 두 값이 같으므로 실수부와 허수부를 비교하면 된다. ∎

거꾸로 \(u, v\)의 편미분이 연속이고 코시-리만 방정식을 만족하면 \(f\)는 정칙이다. 편미분이 연속이면 \(u, v\)가 국소적으로 일차함수로 잘 근사되기 때문이다.

예제 1.1.3

\(e^z\)와 \(|z|^2\)에 코시-리만 방정식을 적용하여라.

풀이. \(e^z = e^x\cos y + ie^x\sin y\)이면 \(u_x = e^x\cos y = v_y\), \(u_y = -e^x\sin y = -v_x\)이다. 따라서 정칙이고 \((e^z)' = u_x + iv_x = e^z\)이다. 반면 \(|z|^2 = x^2 + y^2\)이면 \(v = 0\)이라 \(u_x = 2x = v_y = 0\)이 원점에서만 성립한다. 그러므로 \(|z|^2\)은 원점에서만 미분 가능하고, 어떤 열린집합에서도 정칙이 아니다.

흔한 오해\(u, v\)가 매끄러우면 \(f\)가 정칙이라고 여기기 쉽지만, \(\bar z = x - iy\)는 \(u, v\)가 다항식인데도 코시-리만 방정식을 어겨 정칙이 아니다. 또 한 점에서 미분 가능하면 그 점에서 정칙이라고 생각하는 것도 틀렸다. 정칙이려면 근방 전체에서 미분 가능해야 하며, \(|z|^2\)은 원점에서 미분 가능하지만 정칙이 아니다.
마무리

처음 질문에 답하면, 복소 미분 가능성은 차분몫이 모든 방향에서 같은 극한을 가져야 하므로 실함수의 미분 가능성보다 훨씬 까다롭다. 실수 방향과 순허수 방향의 극한이 같다는 조건만으로도 코시-리만 방정식 \(u_x = v_y\), \(u_y = -v_x\)가 나온다. 거꾸로 편미분이 연속이고 이 방정식을 만족하면 정칙이며, \(e^z\)는 정칙이지만 \(\bar z\)와 \(|z|^2\)은 정칙이 아니다.

1.1.4연습문제

기본

  1. \(f(z) = z^3\)의 \(u, v\)를 구하고 코시-리만 방정식을 확인하여라.
    답

    \(u = x^3 - 3xy^2\), \(v = 3x^2y - y^3\). \(u_x = 3x^2 - 3y^2 = v_y\), \(u_y = -6xy = -v_x\).

응용

  1. \(f(z) = x^2 + iy^2\)이 미분 가능한 점을 모두 구하여라.
    답

    \(u_x = 2x\), \(v_y = 2y\), \(u_y = 0 = -v_x\). 직선 \(y = x\) 위에서만 미분 가능하고, 어디서도 정칙이 아니다.

심화

  1. \(f\)가 연결된 열린집합에서 정칙이고 실수값만 가지면 상수임을 보여라.
    답

    \(v = 0\)이라 \(u_x = v_y = 0\), \(u_y = -v_x = 0\). 모든 편미분이 0이고 연결이라 \(u\)는 상수.
