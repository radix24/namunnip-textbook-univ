옌센 공식

본문
이 절에서 배울 것
  • 원판 안의 영점 \(a_1, \dots, a_n\)과 경계에서의 \(\log|f|\)의 평균을 잇는 옌센 공식을 증명한다.
  • 옌센 공식에서 영점 개수의 상한 \(n(r)\)을 함수의 증가로 추정한다.
  • 정함수의 증가 차수를 정의하고 영점 분포와의 관계를 안다(하다마르 정리의 준비).
먼저 알아야 할 것
  • 조화함수의 평균값 성질 (4.1절), 원판의 자기동형 \(\varphi_a\) (4.2절).

5.1.1공식

정리 5.1.1 (옌센) \(f\)가 \(|z| \le R\)에서 정칙이고 \(f(0) \ne 0\), 경계 위에 영점이 없으며 \(|z| < R\) 안의 영점이 \(a_1, \dots, a_n\)(중복도 포함)이면 \[\log|f(0)| = \sum_{k=1}^n\log\frac{|a_k|}R + \frac1{2\pi}\int_0^{2\pi}\log|f(Re^{i\theta})|\,d\theta.\]
증명

영점이 없으면 \(\log|f| = \operatorname{Re}\log f\)가 조화라 평균값 성질 그 자체이다. 영점이 있으면 각 영점을 \(\frac{R(z - a_k)}{R^2 - \bar a_kz}\) (원판 \(|z| \le R\)의 자기동형 꼴, 경계에서 절댓값 1)로 나누어 영점 없는 \(g\)를 만든다. \(\log|g|\)의 평균값 성질에서 경계 값은 \(\log|f|\)와 같고, 원점의 값은 \(\log|f(0)| - \sum\log\frac{|a_k|}R\)이다. ∎

예 5.1.2 \(f(z) = z - \frac12\), \(R = 1\): 왼쪽 \(\log\frac12\), 오른쪽 \(\log\frac12 + \frac1{2\pi}\int\log|e^{i\theta} - \frac12|d\theta = \log\frac12 + 0\). 평균이 0인 것은 \(\log|e^{i\theta} - a| = \log|1 - \bar ae^{i\theta}|\)이 \(|a| < 1\)일 때 평균 \(\log1 = 0\)이기 때문입니다.

5.1.2영점의 개수

\(|z| \le r\)인 영점 수를 \(n(r)\), \(M(R) = \max_{|z|=R}|f|\)라 하면, 옌센 공식에서 \(|a_k| \le r\)인 항마다 \(\log\frac R{|a_k|} \ge \log\frac Rr\)이므로

\[n(r)\log\frac Rr \le \log M(R) - \log|f(0)|.\]

\(R = 2r\)로 두면 \(n(r) \le \frac{\log M(2r) - \log|f(0)|}{\log2}\). 함수가 천천히 자라면 영점이 적습니다. 예를 들어 다항식은 \(\log M \sim d\log r\)이라 영점이 유한 개입니다.

정함수 \(f\)의 증가 차수를 \(|f(z)| \le Ae^{B|z|^\rho}\)를 만족하는 \(\rho\)의 하한으로 정의하면, 위 부등식에서 \(n(r) = O(r^\rho)\)입니다. \(e^z\), \(\sin z\)는 차수 1이고 \(\sin z\)의 영점 수는 \(n(r) \approx \frac{2r}\pi\)로 \(r\)에 비례합니다.

흔한 오해(1) \(\log|f|\)이 늘 조화라고 여긴다. 영점에서 \(-\infty\)라 조화가 아니고, 그 보정이 영점 항이다. (2) 빠르게 자라는 함수는 영점이 많다고 여긴다. 상한일 뿐이다(\(e^{z^2}\)은 차수 2지만 영점이 없다).
요약
  1. 옌센: \(\log|f(0)| = \sum\log\frac{|a_k|}R + \frac1{2\pi}\int\log|f(Re^{i\theta})|d\theta\).
  2. \(n(r)\log\frac Rr \le \log M(R) - \log|f(0)|\): 느린 증가 → 적은 영점.
  3. 증가 차수 \(\rho\)이면 \(n(r) = O(r^\rho)\).

5.1.3연습문제

기본

  1. \(f(z) = (z - \frac12)(z + \frac13)\)에 \(R = 1\)로 옌센 공식을 확인하여라.
    답

    왼쪽 \(\log\frac16\). 오른쪽 \(\log\frac12 + \log\frac13 + 0 = \log\frac16\).

응용

  1. \(\cos z\)의 증가 차수와, \(|z| \le r\)인 영점 수를 어림하여라.
    답

    \(|\cos z| \le e^{|z|}\)이라 차수 1. 영점 \(\frac\pi2 + k\pi\)이라 \(n(r) \approx \frac{2r}\pi\).

심화

  1. \(|f(z)| \le e^{|z|}\)이고 \(f(0) = 1\)인 정함수의 \(|z| \le 1\) 안의 영점이 많아야 몇 개인지 \(R = e\)로 어림하여라.
    답

    \(n(1)\log e \le \log M(e) \le e\)이므로 \(n(1) \le 2\).
