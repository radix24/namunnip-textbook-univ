유수 정리와 실적분

본문
이 절에서 배울 것
  • 유수를 로랑 급수의 \(\frac1{z - z_0}\) 계수로 정의하고, 극에서 유수를 계산하는 공식을 쓴다.
  • 유수 정리 \(\oint_\gamma f\,dz = 2\pi i\sum\operatorname{Res}\)를 증명한다.
  • 유리함수의 실적분, 삼각함수 적분, \(\int\frac{\cos x}{1 + x^2}dx\) 같은 적분을 복소 경로로 계산한다.
먼저 알아야 할 것
  • 로랑 급수 (3.1절), 코시 정리 (2.1절).

3.2.1유수와 유수 정리

고립 특이점 \(z_0\)에서 로랑 급수의 \(a_{-1}\)을 유수 \(\operatorname{Res}_{z_0}f\)라 합니다. \(z_0\) 둘레의 작은 원에서 항별로 적분하면 \(\oint(z - z_0)^n\,dz\)는 \(n = -1\)일 때만 \(2\pi i\)이므로 \(\oint f\,dz = 2\pi ia_{-1}\)입니다.

  • 단순극: \(\operatorname{Res}_{z_0}f = \lim_{z\to z_0}(z - z_0)f(z)\). \(f = \frac gh\), \(h(z_0) = 0\), \(h'(z_0) \ne 0\)이면 \(\frac{g(z_0)}{h'(z_0)}\).
  • \(m\)차 극: \(\frac1{(m - 1)!}\lim\frac{d^{m-1}}{dz^{m-1}}\left[(z - z_0)^mf(z)\right]\).
정리 3.2.1 (유수 정리) 단순 닫힌 곡선 \(\gamma\)(양의 방향)의 안쪽에서 유한 개의 고립 특이점 \(z_1, \dots, z_k\)를 빼고 \(f\)가 정칙이면 \(\oint_\gamma f\,dz = 2\pi i\sum_j\operatorname{Res}_{z_j}f\).

각 특이점을 작은 원으로 둘러싸고 열쇠구멍 경로로 이으면, 코시 정리로 \(\gamma\) 위 적분이 작은 원들의 적분의 합과 같아집니다.

3.2.2실적분

예 3.2.2 \(\int_{-\infty}^\infty\frac{dx}{1 + x^2} = \pi\). 반지름 \(R\)인 위쪽 반원 경로를 쓰면 안의 극은 \(i\) 하나, 유수 \(\frac1{2i}\). \(2\pi i\cdot\frac1{2i} = \pi\). 원호 위 적분은 \(\le\frac{\pi R}{R^2 - 1} \to 0\).
예 3.2.3 \(\int_{-\infty}^\infty\frac{\cos x}{1 + x^2}dx = \frac\pi e\). \(f = \frac{e^{iz}}{1 + z^2}\)은 위쪽 반평면에서 \(|e^{iz}| = e^{-y} \le 1\)이라 원호 적분이 0으로 가고, \(\operatorname{Res}_i = \frac{e^{-1}}{2i}\). \(2\pi i\cdot\frac{e^{-1}}{2i} = \frac\pi e\)이고 실수부가 원하는 적분입니다(\(\approx 1.1557\)).
예 3.2.4 \(\int_0^{2\pi}\frac{d\theta}{2 + \cos\theta} = \frac{2\pi}{\sqrt3}\). \(z = e^{i\theta}\)로 두면 \(\cos\theta = \frac{z + z^{-1}}2\), \(d\theta = \frac{dz}{iz}\)이고 적분은 \(\oint_{|z|=1}\frac{2\,dz}{i(z^2 + 4z + 1)}\). 원 안의 극 \(z = -2 + \sqrt3\)에서 유수 \(\frac2{i\cdot2\sqrt3}\), 결과 \(\frac{2\pi}{\sqrt3} \approx 3.6276\).
흔한 오해(1) 원 밖의 극까지 유수를 더한다. 곡선 안쪽의 특이점만 센다. (2) \(\int\frac{\cos x}{1 + x^2}\)에 \(\frac{\cos z}{1 + z^2}\)을 그대로 쓴다. \(\cos z\)는 허수 방향으로 커져 원호 적분이 사라지지 않는다. \(e^{iz}\)를 쓰고 실수부를 취한다.
요약
  1. 유수 = \(a_{-1}\), 단순극은 \(\frac{g(z_0)}{h'(z_0)}\).
  2. \(\oint f\,dz = 2\pi i\sum\operatorname{Res}\) (안쪽 특이점만).
  3. 반원 경로(유리함수, \(e^{iz}\))와 단위원 치환(삼각함수)으로 실적분.

3.2.3연습문제

기본

  1. \(\frac{e^z}{z^2}\)의 원점 유수와 \(\oint_{|z|=1}\frac{e^z}{z^2}dz\)를 구하여라.
    답

    \(e^z/z^2 = \frac1{z^2} + \frac1z + \cdots\)라 유수 1, 적분 \(2\pi i\).

응용

  1. \(\int_{-\infty}^\infty\frac{dx}{1 + x^4}\)을 구하여라.
    답

    위쪽 극 \(e^{i\pi/4}, e^{3i\pi/4}\)에서 유수 \(\frac1{4z^3}\)은 \(\frac{e^{-3i\pi/4}}4\), \(\frac{e^{-i\pi/4}}4\)이고 합은 \(\frac{-\sqrt2i}4 = -\frac i{2\sqrt2}\). 적분 \(2\pi i\cdot\left(-\frac i{2\sqrt2}\right) = \frac\pi{\sqrt2} \approx 2.2214\).

심화

  1. \(\int_0^\infty\frac{\sin x}xdx = \frac\pi2\)를 \(\frac{e^{iz}}z\)과 원점을 피하는 작은 반원으로 유도하는 과정을 설명하여라.
    답

    큰 반원과 작은 반원(반지름 \(\varepsilon\))으로 원점을 피한 경로 안은 정칙이라 적분 0. 큰 반원은 조르당 보조정리로 0, 작은 반원은 \(-\pi i\cdot\operatorname{Res}_0 = -\pi i\). 따라서 \(\int_{-\infty}^\infty\frac{e^{ix}}xdx\)(주값) \(= \pi i\), 허수부의 절반이 \(\frac\pi2\).
