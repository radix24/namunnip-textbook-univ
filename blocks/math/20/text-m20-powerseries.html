멱급수는 수렴 원판에서 정칙이다

본문
이 절에서 배울 것
  • 멱급수 \(\sum a_nz^n\)의 수렴 반지름 \(R\)을 정하고, \(|z| < R\)에서 절대수렴, \(|z| > R\)에서 발산함을 안다.
  • 멱급수를 항별로 미분한 급수가 같은 반지름을 가지며 실제 도함수임을 증명한다.
  • \(e^z\), \(\sin z\), \(\cos z\)를 멱급수로 정의하고 오일러 공식을 얻는다.
먼저 알아야 할 것
  • 등비급수와 비교 판정(고등학교 수학), 복소 미분 (1.1절).

1.2.1수렴 반지름

멱급수 \(\sum_{n\ge0}a_nz^n\)이 어떤 \(z_1\)에서 수렴하면 항 \(a_nz_1^n\)이 유계(\(\le M\))이므로, \(|z| < |z_1|\)이면 \(|a_nz^n| \le M\left|\frac z{z_1}\right|^n\)이라 등비급수와 비교해 절대수렴합니다. 그래서 수렴하는 \(z\)는 원판 모양을 이루고 그 반지름을 수렴 반지름 \(R\)이라 합니다. 공식으로는

\[\frac1R = \limsup_{n\to\infty}|a_n|^{1/n}\]

입니다(코시-아다마르). \(\limsup\)은 수열이 한없이 자주 다가가는 값 가운데 가장 큰 것으로, 수열이 수렴하면 그 극한과 같습니다. 실제 계산에서는 \(\left|\frac{a_{n+1}}{a_n}\right|\)이 수렴하면 그 극한의 역수가 \(R\)이라는 비 판정을 주로 씁니다.

예 1.2.1 \(\sum z^n\): \(R = 1\). \(\sum\frac{z^n}{n!}\): 비 \(\frac1{n + 1} \to 0\)이라 \(R = \infty\). \(\sum n!z^n\): \(R = 0\) (원점에서만 수렴).

1.2.2항별 미분

정리 1.2.2 \(f(z) = \sum a_nz^n\)의 수렴 반지름이 \(R > 0\)이면 \(f\)는 \(|z| < R\)에서 정칙이고 \(f'(z) = \sum na_nz^{n-1}\)이다. 이 급수의 수렴 반지름도 \(R\)이다.
증명

\(|n a_n|^{1/n} = n^{1/n}|a_n|^{1/n}\)이고 \(n^{1/n} \to 1\)이라 반지름이 같다. \(|z| < r < R\)을 고정하고 \(g(z) = \sum na_nz^{n-1}\)이라 하자. 항마다 \(\frac{(z + h)^n - z^n}h - nz^{n-1}\)을 이항정리로 펼치면 크기가 \(|h|\binom n2r^{n-2}\) 정도 이하이고(\(|z + h| < r\)일 때), \(\sum|a_n|\binom n2r^{n-2}\)은 수렴한다(두 번 미분한 급수). 따라서 \(\left|\frac{f(z + h) - f(z)}h - g(z)\right| \le C|h| \to 0\). ∎

되풀이하면 멱급수는 수렴 원판에서 무한 번 미분 가능하고 \(a_n = \frac{f^{(n)}(0)}{n!}\)(테일러 계수)입니다.

1.2.3지수함수와 삼각함수

모든 복소수 \(z\)에 대해

\[e^z = \sum_{n\ge0}\frac{z^n}{n!}, \qquad \cos z = \sum\frac{(-1)^nz^{2n}}{(2n)!}, \qquad \sin z = \sum\frac{(-1)^nz^{2n+1}}{(2n + 1)!}\]

로 정의합니다(\(R = \infty\)). 급수에 \(iz\)를 넣어 짝·홀 차수로 나누면 오일러 공식 \(e^{iz} = \cos z + i\sin z\)이고, 정리 1.2.2로 \((e^z)' = e^z\)입니다. 특히 \(e^{i\pi} = -1\)입니다.

흔한 오해(1) 수렴 반지름 위(\(|z| = R\))에서의 수렴도 \(R\)이 정한다고 여긴다. 경계에서는 점마다 다르다(\(\sum\frac{z^n}n\)은 \(z = -1\)에서 수렴, \(z = 1\)에서 발산). (2) \(\sin z\)가 복소수에서도 \(|\sin z| \le 1\)이라고 여긴다. \(\sin(iy) = i\sinh y\)는 무한히 커진다.
요약
  1. 수렴 영역은 원판, \(\frac1R = \limsup|a_n|^{1/n}\).
  2. 멱급수는 수렴 원판에서 정칙이고 항별 미분 가능, \(a_n = \frac{f^{(n)}(0)}{n!}\).
  3. \(e^z\), \(\sin z\), \(\cos z\)는 \(R = \infty\), \(e^{iz} = \cos z + i\sin z\).

1.2.4연습문제

기본

  1. \(\sum\frac{z^n}{2^n}\)과 \(\sum n^2z^n\)의 수렴 반지름을 구하여라.
    답

    2와 1.

응용

  1. \(\frac1{1 - z} = \sum z^n\)을 미분해 \(\sum nz^{n-1}\)의 합을 구하여라.
    답

    \(\frac1{(1 - z)^2}\) (\(|z| < 1\)).

심화

  1. \(\cos(iy) = \cosh y\)임을 보이고 \(\cos z = 2\)인 \(z\)를 하나 구하여라.
    답

    급수에 \(iy\)를 넣으면 \((iy)^{2n} = (-1)^ny^{2n}\)이라 \(\sum\frac{y^{2n}}{(2n)!} = \cosh y\). \(\cosh y = 2\)인 \(y = \ln(2 + \sqrt3)\)으로 \(z = i\ln(2 + \sqrt3)\).
