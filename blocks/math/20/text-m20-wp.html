바이어슈트라스 ℘ 함수

본문
이 절에서 배울 것
  • \(\wp(z) = \frac1{z^2} + \sum_{\lambda\ne0}\left(\frac1{(z - \lambda)^2} - \frac1{\lambda^2}\right)\)을 정의하고 수렴과 이중 주기성을 확인한다.
  • 로랑 전개를 비교해 미분방정식 \(\wp'^2 = 4\wp^3 - g_2\wp - g_3\)을 유도한다.
  • \(z \mapsto (\wp(z), \wp'(z))\)가 토러스와 삼차 곡선을 잇는다는 의미를 안다.
먼저 알아야 할 것
  • 이중 주기 함수 (8.1절), 로랑 급수 (3.1절).

8.2.1정의

단순히 \(\sum_\lambda\frac1{(z - \lambda)^2}\)으로 정의하면 \(\sum_{\lambda\ne0}\frac1{|\lambda|^2}\)이 발산(반지름 \(R\)인 원 안의 격자점이 \(R^2\)에 비례)해 수렴하지 않습니다. 그래서 각 항에서 상수 \(\frac1{\lambda^2}\)을 빼면 항이 \(O(|\lambda|^{-3})\)이 되고, \(\sum|\lambda|^{-3} < \infty\)라 수렴합니다.

\[\wp(z) = \frac1{z^2} + \sum_{\lambda\ne0}\left(\frac1{(z - \lambda)^2} - \frac1{\lambda^2}\right).\]

\(\wp\)는 짝함수이고 각 격자점에서 2차 극을 가집니다. \(\wp'(z) = -2\sum_\lambda\frac1{(z - \lambda)^3}\)은 그대로 이중 주기이고, 이를 적분하면 \(\wp(z + \omega_i) - \wp(z)\)가 상수인데 \(z = -\frac{\omega_i}2\)를 넣고 짝함수임을 쓰면 그 상수가 0이라 \(\wp\)도 이중 주기입니다.

8.2.2미분방정식

원점 근처에서 \(G_k = \sum_{\lambda\ne0}\lambda^{-k}\) (홀수 \(k\)는 대칭으로 0)라 하면

\[\wp(z) = \frac1{z^2} + 3G_4z^2 + 5G_6z^4 + \cdots, \qquad \wp'(z) = -\frac2{z^3} + 6G_4z + 20G_6z^3 + \cdots.\]
정리 8.2.1 \(g_2 = 60G_4\), \(g_3 = 140G_6\)이라 하면 \(\wp'(z)^2 = 4\wp(z)^3 - g_2\wp(z) - g_3\).
증명

로랑 전개로 \(\wp'^2 = \frac4{z^6} - \frac{24G_4}{z^2} - 80G_6 + \cdots\), \(4\wp^3 = \frac4{z^6} + \frac{36G_4}{z^2} + 60G_6 + \cdots\). 차 \(h = \wp'^2 - 4\wp^3 + 60G_4\wp + 140G_6\)은 \(z^{-6}, z^{-2}\), 상수항이 모두 0이라 원점에서 정칙이고 0이다. \(h\)는 타원함수이고 극이 격자점에만 있을 수 있는데 거기서 정칙이므로 이중 주기 정함수, 정리 8.1.1로 상수이고 그 값은 \(h(0) = 0\). ∎

8.2.3타원곡선

정리는 점 \((x, y) = (\wp(z), \wp'(z))\)이 삼차 곡선 \(y^2 = 4x^3 - g_2x - g_3\) 위에 있다는 뜻입니다. 사상 \(z \mapsto [\wp(z) : \wp'(z) : 1]\)은 토러스 \(\mathbb C/\Lambda\)를 이 사영 곡선으로 보내는 동형이고(격자점은 무한원점 \([0 : 1 : 0]\)으로), 곡선 위의 덧셈(타원곡선의 군 법칙)은 토러스의 덧셈 \(z_1 + z_2\)와 같습니다. 이것이 수학17에서 본 "종수 1의 리만 곡면 = 삼차 곡선"의 해석적 증명입니다.

흔한 오해(1) \(\frac1{\lambda^2}\)을 빼는 것이 함수를 바꾼다고 여긴다. 상수만큼 빼는 것이라 극과 주기성은 그대로이고 수렴만 보장한다. (2) \(g_2, g_3\)이 아무 값이나 된다고 여긴다. 판별식 \(g_2^3 - 27g_3^2 \ne 0\)이어야 곡선이 매끄럽고, 격자에서 나온 값은 늘 그렇다.
요약
  1. \(\wp = \frac1{z^2} + \sum\left(\frac1{(z - \lambda)^2} - \frac1{\lambda^2}\right)\): 짝, 이중 주기, 격자점에 2차 극.
  2. \(\wp'^2 = 4\wp^3 - g_2\wp - g_3\), \(g_2 = 60G_4\), \(g_3 = 140G_6\).
  3. \(z \mapsto (\wp, \wp')\): 토러스 ≅ 타원곡선.

8.2.4연습문제

기본

  1. \(\wp\)가 짝함수임을 정의에서 보여라.
    답

    \(z \to -z\)이면 \(\lambda \to -\lambda\)로 합의 순서를 바꾸어 같은 식이 된다(\(\Lambda = -\Lambda\)).

응용

  1. \(\wp'\)는 기본 평행사변형 안에 영점이 몇 개인가? 그 위치를 짝·홀성으로 찾아라.
    답

    \(\wp'\)는 3차 극 하나라 영점 3개. 홀함수이고 이중 주기라 \(\wp'(\frac{\omega_1}2) = -\wp'(-\frac{\omega_1}2) = -\wp'(\frac{\omega_1}2)\), 따라서 반주기 \(\frac{\omega_1}2, \frac{\omega_2}2, \frac{\omega_1 + \omega_2}2\)가 영점.

심화

  1. 정사각형 격자 \(\Lambda = \mathbb Z[i]\)에서 \(g_3 = 0\)임을 보여라.
    답

    \(i\Lambda = \Lambda\)라 \(G_6 = \sum\lambda^{-6} = \sum(i\lambda)^{-6} = i^{-6}G_6 = -G_6\), 따라서 \(G_6 = 0\), \(g_3 = 0\). 곡선은 \(y^2 = 4x^3 - g_2x\).
