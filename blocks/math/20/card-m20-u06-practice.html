프라그멘-린델뢰프 원리 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산상반평면에서 \(f(z) = e^{-iz}\)의 절댓값을 실수축과 \(z = iy\)에서 구하여라. [06-01]

    힌트 1

    \(|e^{-iz}| = e^{\operatorname{Im}z}\).

    힌트 2

    실수축 \(y = 0\).

    풀이

    실수축에서 1, \(iy\)에서 \(e^y \to \infty\). 경계(실수축)에서 유계여도 안에서 무한할 수 있다(증가 차수 1, 반평면의 임계값).

  2. 증명띠 \(|\operatorname{Im}z| \le \frac\pi2\)에서 \(h(z) = \exp(-\varepsilon\cosh(dz))\) (\(0 < d < 1\))가 \(|h| \le 1\)임을 보여라. [06-01]

    힌트 1

    \(\operatorname{Re}\cosh(dz) = \cosh(dx)\cos(dy)\).

    힌트 2

    \(|dy| \le \frac{d\pi}2 < \frac\pi2\).

    풀이

    \(\cos(dy) > 0\)이라 \(\operatorname{Re}\cosh(dz) > 0\)이고 \(|h| = e^{-\varepsilon\operatorname{Re}\cosh(dz)} \le 1\) (6.1절). ∎

  3. 판단띠에서 \(|f(z)| \le \exp(e^{0.9|x|})\)이고 경계에서 \(|f| \le 2\)이면 띠 전체에서 \(|f| \le 2\)인가? [06-01]

    힌트 1

    \(\frac f2\)에 정리 적용.

    힌트 2

    \(c = 0.9 < 1\).

    풀이

    그렇다. \(\frac f2\)는 경계에서 1 이하이고 같은 증가 조건(\(c = 0.9\))을 만족해 정리 6.1.2로 \(|f/2| \le 1\).

  4. 판단위 문제에서 증가 조건이 \(\exp(e^{1.1|x|})\)이면 결론이 성립하는가? [06-01]

    힌트 1

    \(\exp(e^z)\)의 증가.

    힌트 2

    \(c = 1\)에서 이미 반례.

    풀이

    보장되지 않는다. \(2\exp(e^z)\)는 \(\exp(e^{1.1|x|})\) 이하로 자라고(\(|x|\)가 클 때) 경계에서 2이지만 안에서 무한히 크다.

  5. 계산띠 \(|\operatorname{Im}z| < \frac\pi2\)를 오른쪽 반평면으로 보내는 등각사상을 구하여라. [06-01]

    힌트 1

    \(e^z\)는 띠를 각 \(|\arg w| < \frac\pi2\)로.

    힌트 2

    그것이 오른쪽 반평면.

    풀이

    \(w = e^z\). \(\arg w = y \in (-\frac\pi2, \frac\pi2)\)라 오른쪽 반평면이다. 띠의 원리와 반평면(각 영역)의 원리는 이 사상으로 서로 옮겨진다.

  6. 증명띠에서 정칙이고 유계인 \(f\)가 아래 경계 \(y = -\frac\pi2\)에서 \(|f| \le M_0\), 위 경계 \(y = \frac\pi2\)에서 \(|f| \le M_1\)이면 실수축에서 \(|f| \le \sqrt{M_0M_1}\)임을 \(s(z) = \frac12 - \frac{iz}\pi\)와 \(g = fM_0^{s-1}M_1^{-s}\)으로 보여라(세 직선 정리의 특수한 경우). [06-01]

    힌트 1

    \(\operatorname{Re}s = \frac12 + \frac y\pi\)는 아래 경계에서 0, 위 경계에서 1.

    힌트 2

    \(|M^{w}| = M^{\operatorname{Re}w}\) (\(M > 0\)).

    풀이

    \(|g| = |f|M_0^{\operatorname{Re}s - 1}M_1^{-\operatorname{Re}s}\). 아래 경계(\(\operatorname{Re}s = 0\))에서 \(\frac{|f|}{M_0} \le 1\), 위 경계(\(\operatorname{Re}s = 1\))에서 \(\frac{|f|}{M_1} \le 1\). \(g\)는 유계이므로 연습 3의 논리(\(c = 0\))로 띠 전체에서 \(|g| \le 1\). 실수축에서 \(\operatorname{Re}s = \frac12\)이라 \(|f| \le M_0^{1/2}M_1^{1/2}\). ∎
