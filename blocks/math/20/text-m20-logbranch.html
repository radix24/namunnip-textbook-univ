복소로그와 분지

본문

실수에서 \(\log x\)는 \(e^x\)의 역함수로 하나뿐이다. 복소수에서는 \(e^{z + 2\pi i} = e^z\)이라 \(e^w = z\)를 만족하는 \(w\)가 무한히 많다. 그 가운데 하나를 연속으로, 나아가 정칙으로 고를 수 있는 영역은 어떤 영역인가?

먼저 알아야 할 것Cauchy 정리(2.1절), 멱급수와 정칙성(1.2절)을 쓴다. Stein 3장 6절을 따른다.

3.4.1무엇이 문제인가

\(z = re^{i\theta}\)이면 \(e^w = z\)의 해는 \(w = \log r + i(\theta + 2\pi k)\)이다. 그러면 실수부는 하나로 정해지고 허수부, 곧 편각만 \(2\pi\)의 정수배만큼 모호하다. 그림 1처럼 원점을 감는 원을 따라 편각을 연속으로 바꾸어 가면 한 바퀴 뒤에 \(2\pi\)가 늘어나 출발점의 값과 맞지 않는다. 따라서 원점을 감는 곡선을 품은 영역에서는 연속인 로그가 있을 수 없다.

3.4.2단순연결 영역의 로그

정리 3.4.1

\(\Omega\)가 단순연결이고 \(1 \in \Omega\), \(0 \notin \Omega\)이면 \(\Omega\) 위에 \(e^{F(z)} = z\), \(F(1) = 0\)인 정칙함수 \(F\)가 있다. 또 \(\Omega\) 위의 0이 아닌 정칙함수 \(f\)에 대해서도 \(e^{g} = f\)인 정칙함수 \(g\)가 있다.

증명.\(F(z) = \int_1^z\frac{d\zeta}{\zeta}\)로 정의한다. 단순연결 영역에서는 Cauchy 정리로 적분이 경로에 무관하므로 \(F\)는 잘 정의되고 \(F' = 1/z\)이다. 이제 \(h(z) = ze^{-F(z)}\)를 미분하면 \(e^{-F} - zF'e^{-F} = 0\)이라 \(h\)는 상수이고, \(h(1) = 1\)이므로 \(e^{F(z)} = z\)이다. 뒤의 주장은 \(1/\zeta\) 대신 \(f'/f\)를 적분하고, 상수를 \(f(z_0) = e^{c}\)가 되게 맞추면 같다. ∎

이렇게 정한 \(F\)를 로그의 한 분지라 한다. 단순연결이라는 조건이 정확히 그림 1의 "감는 곡선"을 없앤다. 가장 흔한 선택은 음의 실축을 잘라 낸 영역 \(\mathbb C \setminus (-\infty, 0]\)에서의 주분지 \(\operatorname{Log}z = \log r + i\theta\)(\(-\pi < \theta < \pi\))이다.

3.4.3거듭제곱과 계산

분지를 정하면 \(z^\alpha = e^{\alpha\operatorname{Log}z}\)도 정칙함수가 된다. 하지만 지수 법칙은 조심해야 한다. \(\operatorname{Log}(zw) = \operatorname{Log}z + \operatorname{Log}w\)는 두 편각의 합이 \((-\pi, \pi)\)를 벗어나면 \(2\pi i\)만큼 틀린다. 가령 \(z = w = e^{3\pi i/4}\)이면 왼쪽은 \(\operatorname{Log}(e^{3\pi i/2}) = -\frac{\pi i}{2}\)이고 오른쪽은 \(\frac{3\pi i}{2}\)이다.

예제 3.4.2

주분지로 \(i^i\)를 계산하고, \(\int_0^\infty\frac{\log x}{1 + x^2}dx = 0\)을 반원 경로와 로그 분지로 보여라.

풀이. \(\operatorname{Log}i = \frac{\pi i}{2}\)이므로 \(i^i = e^{i\cdot\pi i/2} = e^{-\pi/2} \approx 0.208\)로 실수이다. 적분은 위 반평면에서 정칙인 분지 \(\log z = \log|z| + i\arg z\)(\(-\frac\pi2 < \arg z < \frac{3\pi}{2}\))를 쓴다. 원점 근처를 작은 반원으로 피하고 큰 반원으로 닫은 경로에서 \(\frac{\log z}{1 + z^2}\)의 유일한 극점은 \(z = i\)이고, 유수는 \(\frac{\log i}{2i} = \frac{\pi}{4}\)이다. 음의 실축에서는 \(\log z = \log|x| + \pi i\)이므로 실축 부분의 합은 \(2I + \pi i\int_0^\infty\frac{dx}{1 + x^2} = 2I + \frac{\pi^2i}{2}\)이다. 두 반원의 적분은 0으로 가므로 \(2I + \frac{\pi^2i}{2} = 2\pi i\cdot\frac\pi4\)이고, \(I = 0\)이다.

마무리

복소로그는 편각이 \(2\pi\)만큼 모호해서, 원점을 감는 곡선이 있는 영역에서는 연속으로 고를 수 없다. 원점을 담지 않는 단순연결 영역에서는 \(1/z\)를 적분해 정칙인 분지를 만들 수 있고, 0이 아닌 정칙함수도 같은 방법으로 로그를 가진다. 분지를 정하면 복소 거듭제곱이 정의되지만, 지수 법칙은 편각의 범위를 확인해야 한다.
