코시 적분 공식과 무한 미분 가능성

본문
이 절에서 배울 것
  • 원 \(C\) 안의 점에서 정칙함수의 값이 원둘레 위의 값으로 정해진다는 코시 적분 공식 \(f(z) = \frac1{2\pi i}\oint_C\frac{f(\zeta)}{\zeta - z}d\zeta\)를 증명한다.
  • 적분 기호 아래 미분으로 \(f^{(n)}(z) = \frac{n!}{2\pi i}\oint\frac{f(\zeta)}{(\zeta - z)^{n+1}}d\zeta\)를 얻고, 정칙함수가 무한 번 미분 가능함을 결론짓는다.
  • 정칙함수가 국소적으로 멱급수와 같음(정칙 = 해석)과 코시 부등식을 안다.
먼저 알아야 할 것
  • 원판의 코시 정리 (2.1절), 멱급수 (1.2절).

2.2.1공식

정리 2.2.1 (코시 적분 공식) \(f\)가 닫힌 원판 \(\bar D\)를 포함하는 열린집합에서 정칙이고 \(C = \partial D\)(양의 방향)이면 \(z \in D\)에 대해 \[f(z) = \frac1{2\pi i}\oint_C\frac{f(\zeta)}{\zeta - z}\,d\zeta.\]
증명

열쇠구멍 모양의 경로(큰 원 \(C\), \(z\) 둘레의 작은 원 \(C_\varepsilon\), 둘을 잇는 좁은 통로)를 따르면 \(\frac{f(\zeta)}{\zeta - z}\)는 그 안에서 정칙이라 적분이 0이고, 통로의 두 변은 지워진다. 따라서 \(\oint_C = \oint_{C_\varepsilon}\). 작은 원에서 \(\frac{f(\zeta)}{\zeta - z} = \frac{f(\zeta) - f(z)}{\zeta - z} + \frac{f(z)}{\zeta - z}\)이고 첫 항은 유계라 적분이 \(\varepsilon \to 0\)에서 0, 둘째 항은 \(f(z)\cdot2\pi i\). ∎

원 안의 모든 값이 원둘레의 값으로 정해진다는 것은 실함수에는 없는 놀라운 강성입니다.

2.2.2무한 미분 가능성

공식의 피적분함수는 \(z\)에 대해 매끄러우므로 적분 기호 아래에서 미분할 수 있습니다.

정리 2.2.2 정칙함수는 무한 번 미분 가능하고 \(f^{(n)}(z) = \dfrac{n!}{2\pi i}\oint_C\dfrac{f(\zeta)}{(\zeta - z)^{n+1}}\,d\zeta\).

한 번 미분 가능하면 무한 번 미분 가능하다는 것입니다. 더 나아가 \(\frac1{\zeta - z} = \sum\frac{(z - z_0)^n}{(\zeta - z_0)^{n+1}}\)(등비급수)을 공식에 넣으면 \(f(z) = \sum a_n(z - z_0)^n\)이 원판 전체에서 성립하므로, 정칙함수는 멱급수로 쓰이고(해석적) 수렴 반지름은 적어도 가장 가까운 특이점까지의 거리입니다.

따름정리 2.2.3 (코시 부등식) \(|z - z_0| \le R\)에서 \(|f| \le M\)이면 \(|f^{(n)}(z_0)| \le \frac{n!M}{R^n}\).
예 2.2.4 \(\oint_{|z|=2}\frac{e^z}{z - 1}dz = 2\pi ie^1\), \(\oint_{|z|=2}\frac{e^z}{(z - 1)^3}dz = \frac{2\pi i}{2!}e^1 = \pi ie\)입니다(\(f = e^z\), \(n = 2\)).
흔한 오해(1) 공식이 원 바깥의 점에도 적용된다고 여긴다. \(z\)가 원 밖이면 적분은 0이다(코시 정리). (2) 실함수도 한 번 미분 가능하면 무한 번 미분 가능하다고 여긴다. \(x|x|\)는 한 번만 미분 가능하다. 복소 미분 가능성이 훨씬 강한 조건이다.
요약
  1. \(f(z) = \frac1{2\pi i}\oint\frac{f(\zeta)}{\zeta - z}d\zeta\): 둘레가 안을 정한다.
  2. \(f^{(n)} = \frac{n!}{2\pi i}\oint\frac{f}{(\zeta - z)^{n+1}}\): 무한 미분 가능, 멱급수 전개.
  3. 코시 부등식 \(|f^{(n)}(z_0)| \le \frac{n!M}{R^n}\).

2.2.4연습문제

기본

  1. \(\oint_{|z|=3}\frac{\cos z}{z}dz\)를 구하여라.
    답

    \(2\pi i\cos0 = 2\pi i\).

응용

  1. \(\oint_{|z|=2}\frac{z^2 + 1}{z(z - 3)}dz\)를 구하여라.
    답

    \(z = 3\)은 원 밖. \(f(z) = \frac{z^2 + 1}{z - 3}\)에 공식: \(2\pi if(0) = 2\pi i\cdot\left(-\frac13\right) = -\frac{2\pi i}3\).

심화

  1. \(\frac1{1 + z^2}\)의 원점 중심 테일러 급수의 수렴 반지름을 실수만 보고는 알기 어려운 이유와 함께 구하여라.
    답

    실수축에서는 매끄럽지만 복소수 \(\pm i\)에서 분모가 0이라 반지름은 \(|\pm i| = 1\)이다. 실수 그래프만 보면 특이점이 보이지 않는다.
