푸아송 적분과 디리클레 문제

본문

원판 모양 철판의 테두리 위쪽 절반은 100도, 아래쪽 절반은 0도로 고정하면, 판 안쪽의 평형 온도는 어떻게 분포할까? 경계의 온도만 주어졌을 때 안쪽의 조화함수를 실제로 만드는 공식이 있을까? 원판이 아닌 영역에서는 어떻게 할까?

먼저 알아야 할 것조화함수와 최대 원리(4.1절), 케일리 변환(4.3절)을 쓰고, 좋은 핵(수학15 1.3절)을 함께 보면 좋다.

4.4.1디리클레 문제

영역 \(\Omega\)와 경계 위의 연속함수 \(g\)가 주어질 때, \(\Omega\)에서 조화이고 경계에서 \(g\)와 같은 \(u\)를 찾는 것을 디리클레 문제라 한다. 경계 온도를 고정했을 때의 평형 온도를 구하는 문제이며, 4.1절의 최대 원리에 의해 해는 하나뿐이다.

4.4.2원판에서의 푸아송 적분

\(|\zeta| = 1\)일 때 \(\frac{\zeta + z}{\zeta - z}\)는 \(z\)에 대해 정칙이다. \(\zeta = e^{i\theta}\), \(z = re^{i\varphi}\)로 쓰면 그 실수부는 다음과 같으며, 이것은 조화함수이다.

\[P_r(\varphi - \theta) = \operatorname{Re}\frac{e^{i\theta} + z}{e^{i\theta} - z} = \frac{1 - r^2}{1 - 2r\cos(\varphi - \theta) + r^2}\]

그러므로 다음 푸아송 적분은 조화함수이다.

\[u(re^{i\varphi}) = \frac1{2\pi}\int_0^{2\pi}P_r(\varphi - \theta)g(\theta)\,d\theta\]

또 \(P_r > 0\)이고 \(\frac1{2\pi}\int P_r = 1\)이며, \(r \to 1\)이면 \(\theta = \varphi\) 근처로 몰리는 좋은 핵이다. 그러므로 경계에서 \(u \to g\)가 성립한다. 같은 절의 탐구 카드에서 경계 온도를 바꿔 가며 원판 안의 온도 분포를 본다.

예제 4.4.1

경계값이 \(0 < \theta < \pi\)인 위쪽 반원에서 1, 아래쪽 반원에서 0일 때 원판 안의 온도를 구하여라.

풀이. 원점의 온도는 경계값의 평균인 \(\frac12\)이다. 일반적으로 해는 \(u(z) = \frac12 + \frac1\pi\arg\frac{1 + z}{1 - z}\)의 꼴이다. 즉 점 \(z\)에서 경계의 두 점 \(\pm1\)을 바라보는 각도로 온도가 정해지며, 그래서 그림 1의 등온선은 \(\pm1\)을 지나는 원호이다.

4.4.3반평면

상반평면에서 경계값이 \(g(x)\)이면 해는 다음과 같다. \(\operatorname{Im}\frac{-1}{z - t}\)이 조화이고, 이것을 정규화한 것이 핵이다.

\[u(x, y) = \frac1\pi\int_{-\infty}^\infty\frac{y}{(x - t)^2 + y^2}g(t)\,dt\]

예를 들어 경계값이 \(x > 0\)에서 1, \(x < 0\)에서 0이면 \(u = 1 - \frac{\arg z}\pi\)이므로, 온도가 원점을 바라보는 각도에 비례한다. 이제 다른 영역은 리만 사상으로 원판이나 반평면에 옮겨 풀면 된다. 조화함수와 정칙함수의 합성은 다시 조화함수이기 때문이다.

흔한 오해경계값이 불연속이면 해가 없다고 여기기 쉽지만, 푸아송 적분은 조각마다 연속인 경계값에도 조화 해를 주고, 연속인 점에서 경계값을 맞춘다. 또 반평면에서는 유계 조건 없이도 해가 하나뿐이라고 생각하는 것도 틀렸다. \(u = y\)는 경계값이 0인 0 아닌 해이므로, 유계 해로 제한해야 유일하다.
마무리

처음 질문에 답하면, 원판에서는 경계 온도 \(g\)를 푸아송 핵 \(\frac{1 - r^2}{1 - 2r\cos(\varphi - \theta) + r^2}\)으로 평균한 푸아송 적분이 안쪽의 평형 온도이다. 위쪽 반원 1, 아래쪽 반원 0이면 온도는 점에서 \(\pm1\)을 바라보는 각도로 정해지고, 등온선은 \(\pm1\)을 지나는 원호이다. 원판이 아닌 영역에서는 리만 사상으로 원판이나 반평면에 옮겨 같은 공식을 쓴다.

4.4.4연습문제

기본

  1. \(P_0(\theta)\)는 무엇이고, \(u(0)\)이 경계값의 평균임을 확인하여라.
    답

    \(P_0 = 1\)이라 \(u(0) = \frac1{2\pi}\int g\), 평균값 성질과 같다.

응용

  1. 원판에서 경계값 \(g = \cos2\theta\)인 해를 구하여라.
    답

    \(u = \operatorname{Re}z^2 = r^2\cos2\varphi = x^2 - y^2\).

심화

  1. 상반평면에서 경계값이 \(|x| < 1\)에서 1, 나머지에서 0인 유계 해를 구하여라.
    답

    \(u = \frac1\pi\left(\arg(z - 1) - \arg(z + 1)\right)\), 점 \(z\)에서 선분 \([-1, 1]\)을 바라보는 각도를 \(\pi\)로 나눈 것.
