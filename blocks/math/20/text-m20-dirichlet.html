푸아송 적분과 디리클레 문제

본문
이 절에서 배울 것
  • 단위원판에서 경계값 \(g(\theta)\)가 주어지면 푸아송 적분 \(u(re^{i\varphi}) = \frac1{2\pi}\int P_r(\varphi - \theta)g(\theta)\,d\theta\)가 조화이고 경계값을 가짐을 안다.
  • 푸아송 핵 \(P_r(\theta) = \frac{1 - r^2}{1 - 2r\cos\theta + r^2}\)을 정칙함수의 실수부로 얻는다.
  • 반평면의 디리클레 문제를 등각사상으로 원판의 문제로 옮기거나 반평면 푸아송 공식으로 푼다.
먼저 알아야 할 것
  • 조화함수와 최대 원리 (4.1절), 케일리 변환 (4.3절), 좋은 핵(수학15 1.3절 함께 보면 좋음).

4.4.1디리클레 문제

영역 \(\Omega\)와 경계 위의 연속함수 \(g\)가 주어질 때, \(\Omega\)에서 조화이고 경계에서 \(g\)와 같은 \(u\)를 찾는 것이 디리클레 문제입니다(경계 온도를 고정했을 때의 평형 온도). 최대 원리로 해는 유일합니다(4.1절).

4.4.2원판: 푸아송 적분

\(\frac{\zeta + z}{\zeta - z}\) (\(|\zeta| = 1\))는 \(z\)에 대해 정칙이고, \(\zeta = e^{i\theta}\), \(z = re^{i\varphi}\)일 때 실수부는

\[P_r(\varphi - \theta) = \operatorname{Re}\frac{e^{i\theta} + z}{e^{i\theta} - z} = \frac{1 - r^2}{1 - 2r\cos(\varphi - \theta) + r^2}\]

로 조화입니다. 따라서

\[u(re^{i\varphi}) = \frac1{2\pi}\int_0^{2\pi}P_r(\varphi - \theta)g(\theta)\,d\theta\]

는 조화이고, \(P_r > 0\), \(\frac1{2\pi}\int P_r = 1\), \(r \to 1\)이면 \(\theta = \varphi\) 근처로 몰리는 좋은 핵이라 \(u \to g\)가 경계에서 성립합니다. 같은 절의 탐구 카드에서 경계 온도를 바꿔 가며 원판 안의 온도 분포를 봅니다.

예 4.4.1 경계값 \(g = 1\) (\(0 < \theta < \pi\), 위쪽 반원), \(g = 0\) (아래쪽)이면 원점의 온도는 평균 \(\frac12\)이고, 일반적으로 \(u(z) = \frac12 + \frac1\pi\arg\frac{1 + z}{1 - z}\)의 꼴입니다. 점 \(z\)에서 경계의 두 점 \(\pm1\)을 바라보는 각도로 온도가 정해집니다.

4.4.3반평면

상반평면에서 경계값 \(g(x)\)이면 해는

\[u(x, y) = \frac1\pi\int_{-\infty}^\infty\frac{y}{(x - t)^2 + y^2}g(t)\,dt\]

입니다(\(\operatorname{Im}\frac{-1}{z - t}\)이 조화이고 정규화된 핵). 경계값이 \(x > 0\)에서 1, \(x < 0\)에서 0이면 \(u = 1 - \frac{\arg z}\pi\)로, 원점을 바라보는 각도에 비례합니다. 다른 영역은 리만 사상으로 원판이나 반평면에 옮기면 됩니다(조화함수와 정칙함수의 합성은 조화).

흔한 오해(1) 경계값이 불연속이면 해가 없다고 여긴다. 푸아송 적분은 불연속 경계값(조각마다 연속)에도 조화 해를 주고, 연속인 점에서 경계값을 맞춘다. (2) 반평면에서는 유계 조건 없이도 유일하다고 여긴다. \(u = y\)는 경계값 0을 갖는 0 아닌 해라, 유계 해로 제한해야 유일하다.
요약
  1. 디리클레 문제: 경계값을 가진 조화함수, 최대 원리로 유일.
  2. 원판: 푸아송 핵 \(\frac{1 - r^2}{1 - 2r\cos + r^2}\)은 좋은 핵, \(u\) = 경계값의 가중평균.
  3. 반평면: \(\frac1\pi\frac{y}{(x - t)^2 + y^2}\). 다른 영역은 등각사상으로.

4.4.4연습문제

기본

  1. \(P_0(\theta)\)는 무엇이고, \(u(0)\)이 경계값의 평균임을 확인하여라.
    답

    \(P_0 = 1\)이라 \(u(0) = \frac1{2\pi}\int g\), 평균값 성질과 같다.

응용

  1. 원판에서 경계값 \(g = \cos2\theta\)인 해를 구하여라.
    답

    \(u = \operatorname{Re}z^2 = r^2\cos2\varphi = x^2 - y^2\).

심화

  1. 상반평면에서 경계값이 \(|x| < 1\)에서 1, 나머지에서 0인 유계 해를 구하여라.
    답

    \(u = \frac1\pi\left(\arg(z - 1) - \arg(z + 1)\right)\), 점 \(z\)에서 선분 \([-1, 1]\)을 바라보는 각도를 \(\pi\)로 나눈 것.
