반사 공식 Γ(s)Γ(1 − s) = π / sin πs

본문
이 절에서 배울 것
  • \(0 < s < 1\)에서 \(\Gamma(s)\Gamma(1 - s)\)을 베타 적분 \(\int_0^\infty\frac{v^{s-1}}{1 + v}dv\)로 바꾼다.
  • 그 적분을 유수로 계산해 \(\frac\pi{\sin\pi s}\)를 얻고, 일치 정리로 모든 \(s\)에 확장한다.
  • \(\frac1\Gamma\)이 정함수이고 영점이 \(0, -1, -2, \dots\)임을 결론짓는다.
먼저 알아야 할 것
  • 감마함수의 연장 (7.1절), 유수로 실적분 (3.2절), 이중적분의 치환.

7.2.1베타 적분으로

\(0 < s < 1\)이면

\[\Gamma(1 - s)\Gamma(s) = \int_0^\infty\int_0^\infty e^{-u - t}u^{-s}t^{s-1}\,du\,dt.\]

\(u = tv\)로 치환하면(\(du = t\,dv\)) \(\int_0^\infty\int_0^\infty e^{-t(1 + v)}v^{-s}\,dt\,dv = \int_0^\infty\frac{v^{-s}}{1 + v}dv\)이고, \(v \to \frac1v\)이나 \(x = \log v\)로 쓰면

\[\Gamma(s)\Gamma(1 - s) = \int_{-\infty}^\infty\frac{e^{sx}}{1 + e^x}\,dx.\]

7.2.2유수로 계산

보조정리 7.2.1 \(0 < s < 1\)이면 \(\int_{-\infty}^\infty\frac{e^{sx}}{1 + e^x}dx = \frac\pi{\sin\pi s}\).
증명

직사각형 \([-R, R]\times[0, 2\pi]\) 경로를 쓴다. 위 변에서 \(x \mapsto x + 2\pi i\)이면 분자가 \(e^{2\pi is}\)배, 분모는 그대로라 위 변의 적분은 \(-e^{2\pi is}I\)이고, 세로 변은 \(0 < s < 1\)이라 \(R \to \infty\)에서 0이다. 안의 극은 \(x = \pi i\) 하나, 유수 \(\frac{e^{s\pi i}}{e^{\pi i}} = -e^{\pi is}\). 따라서 \(I(1 - e^{2\pi is}) = 2\pi i(-e^{\pi is})\), \(I = \frac{2\pi i}{e^{\pi is} - e^{-\pi is}} = \frac\pi{\sin\pi s}\). ∎

정리 7.2.2 (반사 공식) 모든 \(s \notin \mathbb Z\)에 대해 \(\Gamma(s)\Gamma(1 - s) = \dfrac\pi{\sin\pi s}\).

양변은 \(\mathbb C\setminus\mathbb Z\)에서 정칙이고 \((0, 1)\)에서 같으므로 일치 정리로 어디서나 같습니다. \(s = \frac12\)이면 \(\Gamma\left(\frac12\right)^2 = \pi\)로 7.1절의 값이 다시 나옵니다. \(s = 0.3\)이면 \(\Gamma(0.3)\Gamma(0.7) \approx 2.9916\times1.2981 \approx 3.8832 = \frac\pi{\sin54°}\)입니다.

7.2.3결과

\(\frac1{\Gamma(s)} = \frac{\Gamma(1 - s)\sin\pi s}\pi\)이고, 오른쪽은 \(\Gamma(1 - s)\)의 극(\(s = 1, 2, \dots\))이 \(\sin\pi s\)의 영점과 지워져 정칙입니다. 그래서 \(\frac1\Gamma\)은 정함수이고, 영점은 \(\Gamma\)의 극인 \(0, -1, -2, \dots\)뿐입니다. 따라서 \(\Gamma\)는 영점이 없습니다. 하다마르 정리(5.2절)를 쓰면 \(\frac1{\Gamma(s)} = se^{\gamma s}\prod\left(1 + \frac sn\right)e^{-s/n}\) (\(\gamma\)는 오일러 상수)도 얻습니다.

흔한 오해(1) 반사 공식이 \(0 < s < 1\)에서만 성립한다고 여긴다. 증명은 그 구간에서 했지만 일치 정리로 모든 비정수에서 성립한다. (2) \(\Gamma\)가 0이 되는 점이 있다고 여긴다. \(\frac1\Gamma\)이 정함수이고 \(\Gamma\)에는 영점이 없다.
요약
  1. \(\Gamma(s)\Gamma(1 - s) = \int_{-\infty}^\infty\frac{e^{sx}}{1 + e^x}dx\) (\(0 < s < 1\)).
  2. 높이 \(2\pi\)인 직사각형 경로의 유수로 \(\frac\pi{\sin\pi s}\), 일치 정리로 전체에.
  3. \(\frac1\Gamma\)은 정함수, 영점은 \(0, -1, -2, \dots\).

7.2.4연습문제

기본

  1. \(\Gamma\left(\frac14\right)\Gamma\left(\frac34\right)\)를 구하여라.
    답

    \(\frac\pi{\sin(\pi/4)} = \pi\sqrt2\).

응용

  1. \(\Gamma\left(\frac12 + it\right)\Gamma\left(\frac12 - it\right) = \frac\pi{\cosh\pi t}\)를 보이고 \(\left|\Gamma\left(\frac12 + it\right)\right|^2\)를 구하여라.
    답

    \(\sin\pi\left(\frac12 + it\right) = \cos(i\pi t) = \cosh\pi t\). \(\Gamma(\bar s) = \overline{\Gamma(s)}\)이라 \(|\Gamma(\frac12 + it)|^2 = \frac\pi{\cosh\pi t}\).

심화

  1. \(\int_0^\infty\frac{v^{-1/3}}{1 + v}dv\)를 구하여라.
    답

    \(s = \frac13\)일 때의 베타 적분이라 \(\frac\pi{\sin(\pi/3)} = \frac{2\pi}{\sqrt3} \approx 3.628\).
