감마함수와 해석적 연장

본문

계승 \(n!\)은 자연수에서만 정의된다. 이것을 \(\frac12\)이나 복소수에서도 정의할 수 있을까? 적분으로 정의하면 일부 복소수에서만 수렴하는데, 수렴하지 않는 곳의 값은 어떻게 정할까? 그렇게 넓힌 함수는 어디에서 정의되지 않을까?

먼저 알아야 할 것이상적분과 부분적분(수학7), 일치 정리(2.4절), 유수(3.2절)를 쓴다.

7.1.1정의

\(\operatorname{Re}s > 0\)일 때 감마함수를 다음 적분으로 정의한다.

\[\Gamma(s) = \int_0^\infty e^{-t}t^{s-1}\,dt\]

\(|t^{s-1}| = t^{\operatorname{Re}s - 1}\)이므로 이 적분은 0 근처와 무한대에서 모두 수렴하고, 적분 기호 아래에서 미분하면 \(s\)에 대해 정칙이다. 부분적분하면 다음을 얻는다.

\[\Gamma(s + 1) = \int_0^\infty e^{-t}t^s\,dt = \left[-e^{-t}t^s\right]_0^\infty + s\int_0^\infty e^{-t}t^{s-1}dt = s\Gamma(s)\]

\(\Gamma(1) = 1\)이므로 \(\Gamma(n + 1) = n!\)이다. 즉 감마함수는 계승을 복소수로 넓힌 것이다. 한편 \(t = u^2\)로 치환하면 \(\Gamma\left(\frac12\right) = 2\int_0^\infty e^{-u^2}du = \sqrt\pi\)이다.

7.1.2해석적 연장

정리 7.1.1

\(\Gamma\)는 \(\mathbb C\setminus\{0, -1, -2, \dots\}\)에서 정칙인 함수로 유일하게 연장되고, \(s = -n\)은 단순극이며 \(\operatorname{Res}_{s=-n}\Gamma = \frac{(-1)^n}{n!}\)이다.

증명.\(\Gamma(s) = \frac{\Gamma(s + n + 1)}{s(s + 1)\cdots(s + n)}\)의 오른쪽은 \(\operatorname{Re}s > -n - 1\)에서 \(s = 0, -1, \dots, -n\)을 빼고 정칙이므로, 이것으로 \(\Gamma\)를 더 넓은 영역에 정의한다. 서로 다른 \(n\)으로 정의한 것들은 \(\operatorname{Re}s > 0\)에서 같으므로 일치 정리에 의해 겹치는 곳에서 모두 같고, 연장은 유일하다. \(s = -n\) 근처에서는 분모의 인수 가운데 \((s + n)\) 하나만 0이므로 단순극이고, 유수는 \(\frac{\Gamma(1)}{(-n)(-n + 1)\cdots(-1)} = \frac{(-1)^n}{n!}\)이다. ∎

예제 7.1.2

\(\Gamma\left(-\frac12\right)\)와 \(\Gamma\left(\frac32\right)\)을 구하여라.

풀이. \(\Gamma\left(-\frac12\right) = \frac{\Gamma(1/2)}{-1/2} = -2\sqrt\pi \approx -3.545\)이고, \(\Gamma\left(\frac32\right) = \frac12\sqrt\pi \approx 0.886\)이다.

사실 함수 방정식으로 정의역을 넓히는 이 방법은 7.3절에서 제타함수를 연장할 때에도 같은 정신으로 쓰인다. 그림 1처럼 실수축 위에서 \(\Gamma\)는 양수 쪽에서 \(x \approx 1.4616\)에 최솟값 0.8856을 가지고, 음수 쪽에서는 극을 지날 때마다 부호가 바뀐다.

그런데 계승을 넓히는 함수는 감마함수 말고도 많다. 예를 들어 \(\Gamma(s)\)에 \(1 + \sin^2\pi s\)처럼 정수에서 1이 되는 함수를 곱해도 정수에서의 값은 그대로이다. 그래서 감마함수를 하나로 정하려면 조건이 더 필요하며, 양의 실수에서 \(\log\Gamma\)가 볼록하다는 조건을 더하면 \(\Gamma(s + 1) = s\Gamma(s)\), \(\Gamma(1) = 1\)과 함께 감마함수가 유일하게 정해진다. 이것을 보어-몰레루프 정리라 한다.

흔한 오해\(\Gamma(n) = n!\)이라고 여기기 쉽지만, \(\Gamma(n) = (n - 1)!\)이다. 또 적분 정의가 \(\operatorname{Re}s \le 0\)에서도 수렴한다고 생각하는 것도 틀렸다. 적분은 0 근처에서 발산하며, 그곳의 값은 함수 방정식을 이용한 연장으로 정의한다.
마무리

처음 질문에 답하면, 계승은 감마함수 \(\Gamma(s) = \int_0^\infty e^{-t}t^{s-1}dt\)로 복소수까지 넓힐 수 있으며, 부분적분에서 \(\Gamma(s + 1) = s\Gamma(s)\)와 \(\Gamma(n + 1) = n!\)이 나온다. 적분이 수렴하지 않는 \(\operatorname{Re}s \le 0\)의 값은 함수 방정식 \(\Gamma(s) = \frac{\Gamma(s + n + 1)}{s(s + 1)\cdots(s + n)}\)로 정하며, 일치 정리로 연장은 유일하다. 이렇게 넓힌 감마함수는 0과 음의 정수에서만 정의되지 않고, 그곳은 단순극이다.

7.1.3연습문제

기본

  1. \(\Gamma\left(\frac52\right)\)를 구하여라.
    답

    \(\frac32\cdot\frac12\sqrt\pi = \frac34\sqrt\pi \approx 1.329\).

응용

  1. \(\Gamma\)의 \(s = -2\)에서의 유수를 구하여라.
    답

    \(\frac{(-1)^2}{2!} = \frac12\).

심화

  1. \(\int_0^\infty e^{-t}t^{s-1}dt\)를 \(\int_0^1 + \int_1^\infty\)로 나누고 \(e^{-t} = \sum\frac{(-t)^n}{n!}\)을 첫 적분에 넣어, \(\Gamma(s) = \sum_n\frac{(-1)^n}{n!(s + n)} + \int_1^\infty e^{-t}t^{s-1}dt\)임을 보이고 이것이 연장을 직접 준다는 것을 설명하여라.
    답

    \(\int_0^1t^{n+s-1}dt = \frac1{s + n}\). 둘째 적분은 모든 \(s\)에서 정칙(정함수), 첫 급수는 \(s = -n\)에서만 극을 가지며 그 유수가 \(\frac{(-1)^n}{n!}\). 이 식이 \(\mathbb C\) 전체에서 의미를 가지므로 연장이다.
