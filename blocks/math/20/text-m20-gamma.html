감마함수와 해석적 연장

본문
이 절에서 배울 것
  • \(\operatorname{Re}s > 0\)에서 \(\Gamma(s) = \int_0^\infty e^{-t}t^{s-1}dt\)로 정의하고 정칙임을 안다.
  • \(\Gamma(s + 1) = s\Gamma(s)\), \(\Gamma(n + 1) = n!\)을 부분적분으로 얻는다.
  • 이 함수 방정식으로 \(\Gamma\)를 \(s = 0, -1, -2, \dots\)를 뺀 복소평면 전체로 연장하고, 그 점들이 단순극이며 유수가 \(\frac{(-1)^n}{n!}\)임을 보인다.
먼저 알아야 할 것
  • 이상적분과 부분적분 (수학7), 일치 정리 (2.4절), 유수 (3.2절).

7.1.1정의

\(\operatorname{Re}s > 0\)이면 \(|t^{s-1}| = t^{\operatorname{Re}s - 1}\)이라 적분이 0 근처와 무한대에서 모두 수렴하고, \(s\)에 대해 정칙입니다(적분 기호 아래 미분, 또는 모레라 정리). 부분적분하면

\[\Gamma(s + 1) = \int_0^\infty e^{-t}t^s\,dt = \left[-e^{-t}t^s\right]_0^\infty + s\int_0^\infty e^{-t}t^{s-1}dt = s\Gamma(s).\]

\(\Gamma(1) = 1\)이므로 \(\Gamma(n + 1) = n!\)입니다. 감마함수는 계승을 복소수로 넓힌 것입니다. 또 \(t = u^2\)로 치환하면 \(\Gamma\left(\frac12\right) = 2\int_0^\infty e^{-u^2}du = \sqrt\pi\)입니다.

7.1.2해석적 연장

정리 7.1.1 \(\Gamma\)는 \(\mathbb C\setminus\{0, -1, -2, \dots\}\)에서 정칙인 함수로 유일하게 연장되고, \(s = -n\)은 단순극이며 \(\operatorname{Res}_{s=-n}\Gamma = \frac{(-1)^n}{n!}\)이다.
증명

\(\Gamma(s) = \frac{\Gamma(s + n + 1)}{s(s + 1)\cdots(s + n)}\)의 오른쪽은 \(\operatorname{Re}s > -n - 1\)에서 \(s = 0, -1, \dots, -n\)을 빼고 정칙이므로, 이것으로 \(\Gamma\)를 넓은 영역에 정의한다. 서로 다른 \(n\)의 정의는 겹치는 곳에서 같고(\(\operatorname{Re}s > 0\)에서 같으니 일치 정리로), 연장은 유일하다. \(s = -n\) 근처에서 분모의 인수 \((s + n)\) 하나만 0이라 단순극이고 유수는 \(\frac{\Gamma(1)}{(-n)(-n + 1)\cdots(-1)} = \frac{(-1)^n}{n!}\). ∎

예 7.1.2 \(\Gamma\left(-\frac12\right) = \frac{\Gamma(1/2)}{-1/2} = -2\sqrt\pi \approx -3.545\). \(\Gamma\left(\frac32\right) = \frac12\sqrt\pi \approx 0.886\).

이 방법(함수 방정식으로 정의역을 넓힘)은 제타함수(7.3절)를 연장하는 데도 같은 정신으로 쓰입니다. 실수축 위에서 \(\Gamma\)의 그래프는 양수 쪽에서 \(x \approx 1.4616\)에 최솟값 0.8856을 가지고, 음수 쪽에서는 극마다 부호가 바뀝니다.

흔한 오해(1) \(\Gamma(n) = n!\)이라고 여긴다. \(\Gamma(n) = (n - 1)!\)이다. (2) 적분 정의가 \(\operatorname{Re}s \le 0\)에서도 수렴한다고 여긴다. 0 근처에서 발산하고, 그곳의 값은 연장으로 정의된다.
요약
  1. \(\Gamma(s) = \int_0^\infty e^{-t}t^{s-1}dt\) (\(\operatorname{Re}s > 0\)), \(\Gamma(s + 1) = s\Gamma(s)\), \(\Gamma(n + 1) = n!\).
  2. \(\Gamma(s) = \frac{\Gamma(s + n + 1)}{s(s + 1)\cdots(s + n)}\)로 연장, 일치 정리로 유일.
  3. \(s = -n\)에서 단순극, 유수 \(\frac{(-1)^n}{n!}\). \(\Gamma(\frac12) = \sqrt\pi\).

7.1.3연습문제

기본

  1. \(\Gamma\left(\frac52\right)\)를 구하여라.
    답

    \(\frac32\cdot\frac12\sqrt\pi = \frac34\sqrt\pi \approx 1.329\).

응용

  1. \(\Gamma\)의 \(s = -2\)에서의 유수를 구하여라.
    답

    \(\frac{(-1)^2}{2!} = \frac12\).

심화

  1. \(\int_0^\infty e^{-t}t^{s-1}dt\)를 \(\int_0^1 + \int_1^\infty\)로 나누고 \(e^{-t} = \sum\frac{(-t)^n}{n!}\)을 첫 적분에 넣어, \(\Gamma(s) = \sum_n\frac{(-1)^n}{n!(s + n)} + \int_1^\infty e^{-t}t^{s-1}dt\)임을 보이고 이것이 연장을 직접 준다는 것을 설명하여라.
    답

    \(\int_0^1t^{n+s-1}dt = \frac1{s + n}\). 둘째 적분은 모든 \(s\)에서 정칙(정함수), 첫 급수는 \(s = -n\)에서만 극을 가지며 그 유수가 \(\frac{(-1)^n}{n!}\). 이 식이 \(\mathbb C\) 전체에서 의미를 가지므로 연장이다.
