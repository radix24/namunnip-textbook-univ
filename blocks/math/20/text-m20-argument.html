편각 원리와 루셰 정리

본문
이 절에서 배울 것
  • \(\frac1{2\pi i}\oint\frac{f'}fdz = Z - P\) (안쪽의 영점 수 − 극 수)를 유수 정리로 증명한다.
  • 이 값이 \(f(\gamma)\)가 원점을 감는 횟수와 같다는 편각 원리를 이해한다.
  • 루셰 정리로 다항식의 영점이 어떤 원 안에 몇 개 있는지 센다.
먼저 알아야 할 것
  • 유수 정리 (3.2절), 감는 횟수(수학17 4.3절 함께 보면 좋음).

3.3.1로그 미분의 유수

\(f = (z - z_0)^mg\) (\(g(z_0) \ne 0\))이면 \(\frac{f'}f = \frac m{z - z_0} + \frac{g'}g\)이므로 \(\frac{f'}f\)는 \(z_0\)에서 유수 \(m\)을 가집니다. \(m\)차 극이면 유수 \(-m\)입니다.

정리 3.3.1 (편각 원리) \(f\)가 단순 닫힌 곡선 \(\gamma\)와 그 안쪽에서 극을 빼고 정칙이고 \(\gamma\) 위에 영점·극이 없으면 \[\frac1{2\pi i}\oint_\gamma\frac{f'(z)}{f(z)}dz = Z - P\] (중복도 포함). 이 값은 곡선 \(f(\gamma)\)가 원점을 감는 횟수와 같다.

뒷부분은 치환 \(w = f(z)\)로 \(\oint\frac{f'}fdz = \oint_{f(\gamma)}\frac{dw}w\)가 되기 때문입니다. 즉 경계에서 \(\arg f\)가 몇 바퀴 도는지만 보면 안의 영점 수를 압니다. 같은 절의 탐구 카드에서 영점과 극을 움직이며 확인합니다.

3.3.2루셰 정리

정리 3.3.2 (루셰) \(f, g\)가 \(\gamma\)와 그 안쪽에서 정칙이고 \(\gamma\) 위에서 \(|g| < |f|\)이면, \(f\)와 \(f + g\)는 \(\gamma\) 안에 같은 개수의 영점을 가진다.
증명

\(\gamma\) 위에서 \(f + g = f\left(1 + \frac gf\right)\)이고 \(\left|\frac gf\right| < 1\)이라 \(1 + \frac gf\)의 값은 원판 \(|w - 1| < 1\) 안에 있어 원점을 감지 않는다. 감는 횟수(편각의 변화)는 곱에서 더해지므로 \(f + g\)와 \(f\)의 감는 횟수가 같다. ∎

예 3.3.3 \(p(z) = z^5 + 3z + 1\)의 영점 수.
  • \(|z| = 2\): \(|z^5| = 32 > |3z + 1| \le 7\)이라 \(z^5\)과 같은 5개(모두 \(|z| < 2\) 안).
  • \(|z| = 1\): \(|3z| = 3 > |z^5 + 1| \le 2\)이라 \(3z\)와 같은 1개.
따라서 영점 1개는 \(|z| < 1\), 4개는 \(1 < |z| < 2\)에 있습니다.
흔한 오해(1) 루셰 정리에서 \(|g| \le |f|\)이면 된다고 여긴다. 등호가 있으면 \(f + g\)가 경계에서 0이 될 수 있어 엄격한 부등식이 필요하다. (2) 편각 원리가 영점의 위치까지 알려 준다고 여긴다. 개수만 알려 준다.
요약
  1. \(\frac{f'}f\)의 유수: 영점에서 \(+m\), 극에서 \(-m\).
  2. 편각 원리: \(\frac1{2\pi i}\oint\frac{f'}f = Z - P\) = \(f(\gamma)\)의 감는 횟수.
  3. 루셰: 경계에서 \(|g| < |f|\)이면 \(f\)와 \(f + g\)의 영점 수가 같다.

3.3.3연습문제

기본

  1. \(\frac1{2\pi i}\oint_{|z|=2}\frac{f'}fdz\)를 \(f = \frac{z^2(z - 1)}{(z - 3)(z + 1)}\)에 대해 구하여라.
    답

    안쪽 영점 \(0\)(2), \(1\)(1)로 \(Z = 3\), 극 \(-1\)(1)로 \(P = 1\) (\(3\)은 밖). 답 2.

응용

  1. \(z^4 - 6z + 3\)의 영점이 \(|z| < 1\)과 \(1 < |z| < 2\)에 각각 몇 개인지 구하여라.
    답

    \(|z| = 2\): \(16 > 12 + 3\)이라 4개. \(|z| = 1\): \(6 > 1 + 3\)이라 \(-6z\)와 같은 1개. 따라서 1개와 3개.

심화

  1. 루셰 정리로 대수학의 기본정리를 다시 증명하여라.
    답

    \(p = a_nz^n + q\) (\(\deg q < n\))이면 충분히 큰 \(R\)에서 \(|q| < |a_nz^n|\)이라 \(p\)는 \(|z| < R\)에 \(a_nz^n\)과 같은 \(n\)개의 영점을 가진다.
