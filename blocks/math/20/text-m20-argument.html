편각 원리와 루셰 정리

본문

다항식 \(z^5 + 3z + 1\)의 근을 직접 구하지 않고, 단위원 안에 근이 몇 개 있는지 알 수 있을까? 경계 위에서 함숫값이 어떻게 도는지만 보고 안쪽의 영점 수를 셀 수 있다면, 그 원리는 무엇일까? 복잡한 함수를 간단한 함수와 비교해 영점 수를 셀 수도 있을까?

먼저 알아야 할 것유수 정리(3.2절)를 쓰고, 감는 횟수(수학17 4.3절)를 함께 보면 좋다.

3.3.1로그 미분의 유수

\(g(z_0) \ne 0\)인 \(g\)로 \(f = (z - z_0)^mg\)라 쓰면 \(\frac{f'}f = \frac m{z - z_0} + \frac{g'}g\)이다. 그러므로 \(\frac{f'}f\)는 \(m\)차 영점에서 유수 \(m\)을 가진다. 같은 계산으로 \(m\)차 극에서는 유수가 \(-m\)이다.

정리 3.3.1 (편각 원리)

\(f\)가 단순 닫힌 곡선 \(\gamma\)와 그 안쪽에서 극을 빼고 정칙이고, \(\gamma\) 위에 영점과 극이 없다고 하자. 그러면 안쪽의 영점의 수를 \(Z\), 극의 수를 \(P\)라 할 때 중복도를 세어 \(\frac1{2\pi i}\oint_\gamma\frac{f'(z)}{f(z)}dz = Z - P\)이다. 이 값은 곡선 \(f(\gamma)\)가 원점을 감는 횟수와 같다.

뒷부분은 \(w = f(z)\)로 치환하면 \(\oint\frac{f'}fdz = \oint_{f(\gamma)}\frac{dw}w\)가 되기 때문이다. 즉 경계에서 \(\arg f\)가 몇 바퀴 도는지만 보면 안쪽의 영점의 수를 안다. 같은 절의 탐구 카드에서 영점과 극을 움직이며 확인한다.

3.3.2루셰 정리

정리 3.3.2 (루셰)

\(f, g\)가 \(\gamma\)와 그 안쪽에서 정칙이고 \(\gamma\) 위에서 \(|g| < |f|\)이면, \(f\)와 \(f + g\)는 \(\gamma\) 안에 같은 개수의 영점을 가진다.

증명.\(\gamma\) 위에서 \(f + g = f\left(1 + \frac gf\right)\)이고 \(\left|\frac gf\right| < 1\)이다. 그러므로 \(1 + \frac gf\)의 값은 원판 \(|w - 1| < 1\) 안에 있어 원점을 감지 않는다. 감는 횟수, 곧 편각의 변화는 곱에서 더해지므로 \(f + g\)와 \(f\)의 감는 횟수가 같다. ∎

예제 3.3.3

\(p(z) = z^5 + 3z + 1\)의 영점이 \(|z| < 1\)과 \(1 < |z| < 2\)에 각각 몇 개 있는지 구하여라.

풀이. \(|z| = 2\)에서는 \(|z^5| = 32\)이고 \(|3z + 1| \le 7\)이므로, 루셰 정리에 의해 \(p\)는 \(z^5\)과 같이 \(|z| < 2\) 안에 영점 5개를 가진다. \(|z| = 1\)에서는 \(|3z| = 3\)이고 \(|z^5 + 1| \le 2\)이므로, \(p\)는 \(3z\)와 같이 \(|z| < 1\) 안에 영점 1개를 가진다. 따라서 영점 1개는 \(|z| < 1\)에, 4개는 \(1 < |z| < 2\)에 있다. 그림 1의 곡선이 원점을 한 번 감는 것도 같은 사실을 보여 준다.

흔한 오해루셰 정리에서 \(|g| \le |f|\)이면 된다고 여기기 쉽지만, 등호가 있으면 \(f + g\)가 경계에서 0이 될 수 있으므로 엄격한 부등식이 필요하다. 또 편각 원리가 영점의 위치까지 알려 준다고 생각하는 것도 틀렸다. 이 원리는 개수만 알려 준다.
마무리

처음 질문에 답하면, 로그 미분 \(\frac{f'}f\)가 영점에서 그 차수만큼의 유수를 가지므로, 유수 정리에서 편각 원리를 얻는다. 곧 안쪽의 영점 수에서 극의 수를 뺀 값은 경계의 상 \(f(\gamma)\)가 원점을 감는 횟수이다. 루셰 정리를 쓰면 경계에서 더 큰 간단한 함수와 비교해 영점 수를 세며, \(z^5 + 3z + 1\)은 단위원 안에 영점이 하나이다.

3.3.3연습문제

기본

  1. \(\frac1{2\pi i}\oint_{|z|=2}\frac{f'}fdz\)를 \(f = \frac{z^2(z - 1)}{(z - 3)(z + 1)}\)에 대해 구하여라.
    답

    안쪽 영점 \(0\)(2), \(1\)(1)로 \(Z = 3\), 극 \(-1\)(1)로 \(P = 1\) (\(3\)은 밖). 답 2.

응용

  1. \(z^4 - 6z + 3\)의 영점이 \(|z| < 1\)과 \(1 < |z| < 2\)에 각각 몇 개인지 구하여라.
    답

    \(|z| = 2\): \(16 > 12 + 3\)이라 4개. \(|z| = 1\): \(6 > 1 + 3\)이라 \(-6z\)와 같은 1개. 따라서 1개와 3개.

심화

  1. 루셰 정리로 대수학의 기본정리를 다시 증명하여라.
    답

    \(p = a_nz^n + q\) (\(\deg q < n\))이면 충분히 큰 \(R\)에서 \(|q| < |a_nz^n|\)이라 \(p\)는 \(|z| < R\)에 \(a_nz^n\)과 같은 \(n\)개의 영점을 가진다.
