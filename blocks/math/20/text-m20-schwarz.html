슈바르츠 보조정리와 원판의 자기동형

본문
이 절에서 배울 것
  • 원판에서 원판으로 가며 원점을 고정하는 정칙함수가 \(|f(z)| \le |z|\), \(|f'(0)| \le 1\)을 만족함(슈바르츠 보조정리)을 최대 원리로 증명한다.
  • 등호이면 회전 \(f(z) = e^{i\theta}z\)임을 보인다.
  • 원판의 모든 자기동형이 \(e^{i\theta}\frac{z - a}{1 - \bar az}\) 꼴임을 결론짓는다.
먼저 알아야 할 것
  • 최대 절댓값 원리와 제거 가능 특이점 (2.4절, 3.1절).

4.2.1슈바르츠 보조정리

정리 4.2.1 \(f\)가 단위원판 \(\mathbb D\)에서 \(\mathbb D\)로 가는 정칙함수이고 \(f(0) = 0\)이면 \(|f(z)| \le |z|\), \(|f'(0)| \le 1\)이다. 어떤 \(z \ne 0\)에서 \(|f(z)| = |z|\)이거나 \(|f'(0)| = 1\)이면 \(f(z) = e^{i\theta}z\)(회전)이다.
증명

\(g(z) = \frac{f(z)}z\)는 원점이 제거 가능(\(g(0) = f'(0)\))이라 \(\mathbb D\)에서 정칙이다. \(|z| = r < 1\)에서 \(|g| \le \frac1r\)이므로 최대 원리로 \(|z| \le r\)에서 \(|g| \le \frac1r\), \(r \to 1\)이면 \(|g| \le 1\). 등호가 내부에서 성립하면 \(|g|\)가 내부 최댓값을 가져 \(g\)는 절댓값 1인 상수. ∎

4.2.2원판의 자기동형

\(|a| < 1\)에 대해 \(\varphi_a(z) = \frac{z - a}{1 - \bar az}\)는 \(\mathbb D\)를 \(\mathbb D\)로 보내는 정칙 전단사(뫼비우스 변환)이고 \(a\)를 0으로, 0을 \(-a\)로 보냅니다. \(|z| = 1\)이면 \(|z - a| = |\bar z||z - a| = |1 - \bar az|\)라 원둘레를 원둘레로 보냅니다.

정리 4.2.2 \(\mathbb D\)의 정칙 자기동형은 모두 \(f(z) = e^{i\theta}\varphi_a(z)\) 꼴이다.
증명

\(f(a) = 0\)이라 하자. \(h = f\circ\varphi_a^{-1}\)은 원점을 고정하는 자기동형이라 슈바르츠로 \(|h'(0)| \le 1\), 역함수에도 적용하면 \(|(h^{-1})'(0)| = \frac1{|h'(0)|} \le 1\)이므로 \(|h'(0)| = 1\), \(h\)는 회전이다. 따라서 \(f = e^{i\theta}\varphi_a\). ∎

예 4.2.3 \(\frac12\)을 0으로 보내는 자기동형: \(\varphi_{1/2}(z) = \frac{z - 1/2}{1 - z/2} = \frac{2z - 1}{2 - z}\). \(z = 1\)은 1로, \(z = -1\)은 \(-1\)로, \(z = i\)는 \(\frac{2i - 1}{2 - i} = \frac{(2i - 1)(2 + i)}5 = \frac{-4 + 3i}5\)(절댓값 1)로 갑니다.

그래서 원판의 자기동형군은 실 3차원(\(\theta\)와 \(a\))입니다. 이 군이 원판을 쌍곡기하의 모형(푸앵카레 원판)으로 만드는 등거리변환군입니다.

흔한 오해(1) 원판의 자기동형이 회전뿐이라고 여긴다. 원점을 고정하는 것만 회전이고, 다른 점을 원점으로 옮기는 \(\varphi_a\)도 있다. (2) 슈바르츠 보조정리가 \(f(0) = 0\) 없이도 성립한다고 여긴다. 그 경우는 \(\varphi_{f(0)}\circ f\)에 적용한 슈바르츠-픽 정리가 된다.
요약
  1. 슈바르츠: \(f : \mathbb D \to \mathbb D\), \(f(0) = 0\)이면 \(|f(z)| \le |z|\), 등호이면 회전.
  2. \(\varphi_a(z) = \frac{z - a}{1 - \bar az}\): \(a\)를 0으로 보내는 자기동형.
  3. \(\operatorname{Aut}(\mathbb D) = \{e^{i\theta}\varphi_a\}\).

4.2.3연습문제

기본

  1. \(\varphi_a\)의 역함수가 \(\varphi_{-a}\)임을 확인하여라.
    답

    \(w = \frac{z - a}{1 - \bar az}\)를 \(z\)에 대해 풀면 \(z = \frac{w + a}{1 + \bar aw} = \varphi_{-a}(w)\).

응용

  1. \(f : \mathbb D \to \mathbb D\) 정칙, \(f(0) = 0\)이면 \(\left|f\left(\frac12\right)\right|\)의 최댓값은?
    답

    \(\frac12\) (회전에서 등호).

심화

  1. \(\mathbb D\)의 자기동형 중 \(\frac12\)을 \(\frac12\)로 고정하는 것을 모두 구하여라.
    답

    \(\varphi_{1/2}^{-1}\circ(e^{i\theta}z)\circ\varphi_{1/2}\), 즉 \(\varphi_{-1/2}(e^{i\theta}\varphi_{1/2}(z))\) (\(\theta \in \mathbb R\)). 원점을 고정하는 회전들을 옮겨 놓은 것이다.
