프라그멘-린델뢰프 원리

본문
이 절에서 배울 것
  • 유계가 아닌 영역에서는 경계에서 유계여도 최대 원리가 실패할 수 있음을 예로 본다.
  • 띠 영역에서 함수가 너무 빨리 자라지 않으면 최대 원리가 다시 성립함(프라그멘-린델뢰프)을 증명한다.
  • 보조 함수 \(e^{-\varepsilon\cosh}\) 같은 "벌점 함수" 기법을 이해한다.
먼저 알아야 할 것
  • 최대 절댓값 원리 (2.4절), 지수함수와 쌍곡함수 (1.2절).

6.1.1최대 원리가 실패하는 예

예 6.1.1 띠 \(S = \{|\operatorname{Im}z| < \frac\pi2\}\)에서 \(f(z) = \exp(e^z)\)을 봅시다. 경계 \(y = \pm\frac\pi2\)에서 \(e^z = e^x(\pm i)\)라 \(|f| = |e^{\pm ie^x}| = 1\)이지만, 실수축에서 \(f(x) = e^{e^x}\)는 한없이 커집니다. 경계에서 1 이하인데 안에서 무한히 크므로, 유계가 아닌 영역에서는 최대 원리가 그대로 성립하지 않습니다.

이 함수는 \(e^{e^{|x|}}\)처럼 매우 빨리 자랍니다. 증가 속도를 제한하면 최대 원리가 되살아납니다.

6.1.2띠에서의 원리

정리 6.1.2 (프라그멘-린델뢰프) \(f\)가 닫힌 띠 \(\bar S = \{|\operatorname{Im}z| \le \frac\pi2\}\)에서 연속이고 내부에서 정칙이며, 경계에서 \(|f| \le 1\), 그리고 어떤 \(c < 1\), \(A\)에 대해 \(|f(z)| \le \exp(Ae^{c|x|})\)이면 \(\bar S\) 전체에서 \(|f| \le 1\)이다.
증명

\(c < d < 1\)을 고르고 \(\varepsilon > 0\)에 대해 \(h_\varepsilon(z) = \exp(-\varepsilon(e^{dz} + e^{-dz}))\)를 둔다. \(\operatorname{Re}(e^{dz} + e^{-dz}) = (e^{dx} + e^{-dx})\cos(dy) \ge \cos\frac{d\pi}2\cdot e^{d|x|}\)이고 \(\cos\frac{d\pi}2 > 0\)이므로 \(|h_\varepsilon| \le \exp(-\varepsilon\delta e^{d|x|})\) (\(\delta > 0\))로 \(|x| \to \infty\)에서 매우 빨리 0으로 간다. 또 \(|h_\varepsilon| \le 1\). 그래서 \(fh_\varepsilon\)은 경계에서 \(\le 1\)이고, \(d > c\)라 \(|x|\)가 크면 \(|fh_\varepsilon| \le \exp(Ae^{c|x|} - \varepsilon\delta e^{d|x|}) < 1\)이다. 충분히 긴 직사각형에 최대 원리를 쓰면 \(|fh_\varepsilon| \le 1\). \(\varepsilon \to 0\)이면 \(h_\varepsilon \to 1\)이라 \(|f| \le 1\). ∎

예 6.1.1의 \(\exp(e^z)\)은 \(c = 1\)인 경계 경우라 조건을 아슬아슬하게 어기고, 실제로 결론이 거짓입니다. 조건이 최선이라는 뜻입니다.

6.1.3쓰임

같은 기법을 각 영역 \(\{|\arg z| < \frac\pi{2\alpha}\}\)에 쓰면 "\(|f| \le e^{|z|^\beta}\) (\(\beta < \alpha\))이면 최대 원리"가 됩니다. 해석적 정수론에서 제타함수를 세로 직선 사이에서 추정할 때(볼록성 추정), 그리고 하다마르의 세 직선 정리와 리스-토린 보간 정리 같은 해석학의 부등식에서 쓰입니다.

흔한 오해(1) 경계에서 유계이면 어떤 영역에서든 안에서도 유계라고 여긴다. 유계가 아닌 영역에서는 증가 조건이 필요하다. (2) 보조 함수가 아무 함수나 된다고 여긴다. 경계에서 절댓값 1 이하이고, 무한대에서 \(f\)보다 빨리 줄어야 한다.
요약
  1. 띠에서 \(\exp(e^z)\)은 경계에서 1인데 안에서 무한: 최대 원리 실패.
  2. \(|f| \le \exp(Ae^{c|x|})\), \(c < 1\)이면 경계의 상한이 띠 전체에 성립.
  3. 벌점 함수 \(\exp(-\varepsilon\cosh dz)\)를 곱해 직사각형 최대 원리 후 \(\varepsilon \to 0\).

6.1.4연습문제

기본

  1. \(\exp(e^z)\)이 띠의 경계 \(y = \frac\pi2\)에서 절댓값 1임을 계산하여라.
    답

    \(e^{x + i\pi/2} = ie^x\), \(|\exp(ie^x)| = 1\).

응용

  1. 띠에서 \(f(z) = e^{z}\)이 경계에서 유계가 아님을 보이고 정리의 가정을 확인하여라.
    답

    경계에서 \(|e^z| = e^x\)로 유계가 아니므로 가정(경계에서 \(\le 1\))을 만족하지 않는다.

심화

  1. 띠에서 정칙이고 경계에서 \(|f| \le 1\), 안에서 유계인 \(f\)는 \(|f| \le 1\)임을 정리 6.1.2로 설명하여라.
    답

    유계 \(|f| \le M\)이면 \(|f| \le \exp(\log M) \le \exp(Ae^{0\cdot|x|})\)로 \(c = 0 < 1\)인 조건을 만족해 결론이 성립한다.
