프라그멘-린델뢰프 원리

본문

유계 영역에서는 정칙함수의 절댓값이 경계에서 최대였다. 그런데 끝없이 뻗은 띠 같은 영역에서도 경계에서 1 이하이면 안쪽에서도 1 이하일까? 그렇지 않다면, 함수가 자라는 빠르기에 어떤 제한을 두어야 최대 원리가 되살아날까?

먼저 알아야 할 것최대 절댓값 원리(2.4절)와 지수함수, 쌍곡함수(1.2절)를 쓴다.

6.1.1최대 원리가 실패하는 예

예제 6.1.1

띠 \(S = \{|\operatorname{Im}z| < \frac\pi2\}\)에서 \(f(z) = \exp(e^z)\)의 경계와 안쪽에서의 크기를 비교하여라.

풀이. 경계 \(y = \pm\frac\pi2\)에서는 \(e^z = \pm ie^x\)라 \(|f| = |e^{\pm ie^x}| = 1\)이다. 그러나 실수축에서는 \(f(x) = e^{e^x}\)가 한없이 커진다. 경계에서 1 이하인데 안쪽에서 무한히 크므로, 유계가 아닌 영역에서는 최대 원리가 그대로 성립하지 않는다. 그림 1이 이 상황이다.

이 함수는 \(e^{e^{|x|}}\)처럼 매우 빨리 자란다. 그래서 증가 속도를 제한하면 최대 원리가 되살아난다.

6.1.2띠에서의 원리

정리 6.1.2 (프라그멘-린델뢰프)

\(f\)가 닫힌 띠 \(\bar S = \{|\operatorname{Im}z| \le \frac\pi2\}\)에서 연속이고 안쪽에서 정칙이며 경계에서 \(|f| \le 1\)이라 하자. 어떤 \(c < 1\)과 \(A\)에 대해 \(|f(z)| \le \exp(Ae^{c|x|})\)이면 \(\bar S\) 전체에서 \(|f| \le 1\)이다.

증명.\(c < d < 1\)을 고르고 \(\varepsilon > 0\)에 대해 \(h_\varepsilon(z) = \exp(-\varepsilon(e^{dz} + e^{-dz}))\)로 둔다. \(\operatorname{Re}(e^{dz} + e^{-dz}) = (e^{dx} + e^{-dx})\cos(dy) \ge \cos\frac{d\pi}2\cdot e^{d|x|}\)이고 \(\cos\frac{d\pi}2 > 0\)이다. 그러므로 어떤 \(\delta > 0\)으로 \(|h_\varepsilon| \le \exp(-\varepsilon\delta e^{d|x|})\)이라 \(|x| \to \infty\)에서 매우 빨리 0으로 가고, 또 \(|h_\varepsilon| \le 1\)이다. 그래서 \(fh_\varepsilon\)은 경계에서 1 이하이고, \(d > c\)이므로 \(|x|\)가 크면 \(|fh_\varepsilon| \le \exp(Ae^{c|x|} - \varepsilon\delta e^{d|x|}) < 1\)이다. 충분히 긴 직사각형에 최대 원리를 쓰면 \(|fh_\varepsilon| \le 1\)이다. 끝으로 \(\varepsilon \to 0\)이면 \(h_\varepsilon \to 1\)이므로 \(|f| \le 1\)이다. ∎

예제 6.1.1의 \(\exp(e^z)\)은 \(c = 1\)인 경계의 경우라서 조건을 아슬아슬하게 어기고, 실제로 결론이 거짓이다. 곧 조건 \(c < 1\)은 더 약하게 할 수 없는 최선의 조건이다.

6.1.3쓰임

같은 기법을 각 영역 \(\{|\arg z| < \frac\pi{2\alpha}\}\)에 쓰면, \(\beta < \alpha\)일 때 \(|f| \le e^{|z|^\beta}\)이면 최대 원리가 성립한다. 이 원리는 해석적 정수론에서 제타함수를 세로 직선 사이에서 추정하는 볼록성 추정에 쓰인다. 또 하다마르의 세 직선 정리와 리스-토린 보간 정리 같은 해석학의 부등식에서도 쓰인다.

흔한 오해경계에서 유계이면 어떤 영역에서든 안쪽에서도 유계라고 여기기 쉽지만, 유계가 아닌 영역에서는 증가 조건이 필요하다. 또 보조 함수로 아무 함수나 써도 된다고 생각하는 것도 틀렸다. 보조 함수는 경계에서 절댓값이 1 이하이고, 무한대에서 \(f\)가 자라는 것보다 빨리 줄어야 한다.
마무리

처음 질문에 답하면, 끝없이 뻗은 띠에서는 경계에서 1 이하여도 \(\exp(e^z)\)처럼 안쪽에서 한없이 커질 수 있다. 그러나 함수가 \(\exp(Ae^{c|x|})\), \(c < 1\)보다 느리게 자라면 프라그멘-린델뢰프 원리에 따라 최대 원리가 되살아난다. 증명은 무한대에서 더 빨리 줄어드는 보조 함수를 곱해 유계 영역의 최대 원리로 바꾸는 것이며, 조건 \(c < 1\)은 최선이다.

6.1.4연습문제

기본

  1. \(\exp(e^z)\)이 띠의 경계 \(y = \frac\pi2\)에서 절댓값 1임을 계산하여라.
    답

    \(e^{x + i\pi/2} = ie^x\), \(|\exp(ie^x)| = 1\).

응용

  1. 띠에서 \(f(z) = e^{z}\)이 경계에서 유계가 아님을 보이고 정리의 가정을 확인하여라.
    답

    경계에서 \(|e^z| = e^x\)로 유계가 아니므로 가정(경계에서 \(\le 1\))을 만족하지 않는다.

심화

  1. 띠에서 정칙이고 경계에서 \(|f| \le 1\), 안에서 유계인 \(f\)는 \(|f| \le 1\)임을 정리 6.1.2로 설명하여라.
    답

    유계 \(|f| \le M\)이면 \(|f| \le \exp(\log M) \le \exp(Ae^{0\cdot|x|})\)로 \(c = 0 < 1\)인 조건을 만족해 결론이 성립한다.
