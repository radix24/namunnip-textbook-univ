구르사 정리와 원판의 코시 정리

본문
이 절에서 배울 것
  • 복소 선적분 \(\int_\gamma f(z)\,dz\)를 정의하고 원둘레 위의 \(\oint\frac{dz}z = 2\pi i\)를 계산한다.
  • 정칙함수의 삼각형 둘레 적분이 0이라는 구르사 정리를 삼각형을 4등분하는 논법으로 증명한다.
  • 원판에서 원시함수를 만들어 모든 닫힌 곡선의 적분이 0임(코시 정리)을 얻는다.
먼저 알아야 할 것
  • 정칙함수 (1.1절), 매개변수 곡선과 정적분, 축소구간 정리 (수학7).

2.1.1복소 선적분

곡선 \(\gamma : [a, b] \to \mathbb C\)를 따른 적분을 \(\int_\gamma f(z)\,dz = \int_a^bf(\gamma(t))\gamma'(t)\,dt\)로 정의합니다. \(F' = f\)인 원시함수가 있으면 \(\int_\gamma f\,dz = F(\gamma(b)) - F(\gamma(a))\)이고, 닫힌 곡선이면 0입니다.

예 2.1.1 단위원 \(\gamma(t) = e^{it}\) (\(0 \le t \le 2\pi\))에서 \(\oint\frac{dz}z = \int_0^{2\pi}\frac{ie^{it}}{e^{it}}dt = 2\pi i\), \(\oint z^n\,dz = 0\) (\(n \ne -1\)). \(\frac1z\)은 \(\mathbb C\setminus\{0\}\)에서 원시함수(로그)가 없습니다.

2.1.2구르사 정리

정리 2.1.2 (구르사) \(f\)가 열린집합 \(\Omega\)에서 정칙이고 삼각형 \(T\)와 그 내부가 \(\Omega\)에 들어 있으면 \(\oint_{\partial T}f\,dz = 0\).
증명

\(T\)의 변의 중점을 이어 4개의 삼각형으로 나누면 안쪽 변의 적분은 서로 지워져 \(\oint_{\partial T} = \sum_{j=1}^4\oint_{\partial T_j}\)이다. 그중 적분의 절댓값이 가장 큰 \(T^{(1)}\)을 고르면 \(|\oint_{\partial T}| \le 4|\oint_{\partial T^{(1)}}|\). 반복하면 둘레 \(p_n = 2^{-n}p\), 지름 \(d_n = 2^{-n}d\)이고 \(|\oint_{\partial T}| \le 4^n|\oint_{\partial T^{(n)}}|\). 축소구간 정리로 \(T^{(n)}\)들은 한 점 \(z_0\)으로 모인다. \(f(z) = f(z_0) + f'(z_0)(z - z_0) + \psi(z)(z - z_0)\), \(\psi \to 0\)이고, 앞의 두 항은 원시함수가 있어 적분이 0이므로 \(|\oint_{\partial T^{(n)}}f| \le \sup|\psi|\,d_np_n\). 따라서 \(|\oint_{\partial T}| \le \sup_{T^{(n)}}|\psi|\cdot dp \to 0\). ∎

2.1.3원판의 코시 정리

정리 2.1.3 \(f\)가 열린 원판 \(D\)에서 정칙이면 \(D\)에서 원시함수 \(F\)를 가지고, 따라서 \(D\) 안의 모든 닫힌 곡선 \(\gamma\)에 대해 \(\oint_\gamma f\,dz = 0\).
증명

중심 \(c\)에서 \(z\)까지, 먼저 가로로 그다음 세로로 가는 경로를 따라 \(F(z) = \int_c^zf\)로 정의한다. \(F(z + h) - F(z)\)는 구르사 정리(직사각형은 삼각형 둘로 나뉨)로 \(z\)에서 \(z + h\)까지의 선분 적분과 같고, 이는 \(hf(z) + o(h)\)라 \(F' = f\). ∎

원판 대신 "구멍이 없는"(단순연결) 영역이면 같은 결론이 성립합니다. 예 2.1.1의 \(\frac1z\)은 원점이 빠진 구멍 때문에 적분이 0이 아닙니다.

흔한 오해(1) 정칙이기만 하면 어떤 닫힌 곡선의 적분이든 0이라고 여긴다. 곡선 안쪽에 정칙이 아닌 점이 있으면 아니다(\(\oint\frac{dz}z = 2\pi i\)). (2) 구르사 정리가 \(f'\)의 연속성을 가정한다고 여긴다. 구르사의 공로는 그 가정을 없앤 것이다.
요약
  1. \(\int_\gamma f\,dz = \int f(\gamma(t))\gamma'(t)\,dt\), \(\oint\frac{dz}z = 2\pi i\).
  2. 구르사: 4등분을 반복해 한 점으로 모아 \(\oint_{\partial T}f = 0\).
  3. 원판에서 원시함수가 있어 모든 닫힌 곡선 적분이 0.

2.1.4연습문제

기본

  1. \(\int_\gamma z^2\,dz\)를 \(0\)에서 \(1 + i\)까지 임의의 경로로 계산하여라.
    답

    원시함수 \(\frac{z^3}3\)으로 \(\frac{(1 + i)^3}3 = \frac{-2 + 2i}3\).

응용

  1. 원 \(|z - 1| = 1\)을 따른 \(\oint\frac{dz}{z + 2}\)를 구하여라.
    답

    \(\frac1{z + 2}\)는 원판 \(|z - 1| < 1.5\)에서 정칙이므로 0.

심화

  1. \(\oint_{|z|=1}\bar z\,dz\)를 계산하고, 왜 0이 아닌지 설명하여라.
    답

    \(\bar z = e^{-it}\), \(dz = ie^{it}dt\)라 \(\int_0^{2\pi}i\,dt = 2\pi i\). \(\bar z\)는 정칙이 아니라 코시 정리가 적용되지 않는다.
