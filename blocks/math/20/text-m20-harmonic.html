조화함수의 평균값 성질과 최대 원리

본문
이 절에서 배울 것
  • 라플라스 방정식 \(u_{xx} + u_{yy} = 0\)을 만족하는 조화함수를 정의하고, 정칙함수의 실수부가 조화함수임을 안다.
  • 단순연결 영역의 조화함수는 어떤 정칙함수의 실수부임(켤레 조화함수의 존재)을 이해한다.
  • 조화함수의 평균값 성질과 최대·최소 원리를 증명한다.
먼저 알아야 할 것
  • 코시-리만 방정식 (1.1절), 평균값 성질과 최대 절댓값 원리 (2.4절).

4.1.1조화함수

두 번 연속 미분 가능한 실함수 \(u(x, y)\)가 \(\Delta u = u_{xx} + u_{yy} = 0\)이면 조화함수라 합니다. 평형 상태의 온도, 전위, 비압축성 흐름의 퍼텐셜이 조화함수입니다.

정리 4.1.1 \(f = u + iv\)가 정칙이면 \(u\)와 \(v\)는 조화함수이다. 반대로 단순연결 영역에서 조화함수 \(u\)는 어떤 정칙함수의 실수부이다.
증명

정칙함수는 무한 번 미분 가능하므로(2.2절) 코시-리만 \(u_x = v_y\), \(u_y = -v_x\)를 미분하면 \(u_{xx} = v_{yx}\), \(u_{yy} = -v_{xy}\)이고 혼합 편미분이 같아 \(\Delta u = 0\). 반대로 \(g = u_x - iu_y\)는 코시-리만을 만족해(\(\Delta u = 0\) 사용) 정칙이고, 단순연결이라 원시함수 \(F\)를 가지며 \(\operatorname{Re}F\)와 \(u\)는 상수 차이이다. ∎

예 4.1.2 \(u = x^2 - y^2 = \operatorname{Re}z^2\), \(u = e^x\cos y = \operatorname{Re}e^z\)은 조화함수입니다. \(u = \log|z| = \operatorname{Re}\log z\)는 \(\mathbb C\setminus\{0\}\)에서 조화이지만, 이 영역은 단순연결이 아니라 전체에서 정의된 켤레(\(\arg z\))가 없습니다.

4.1.2평균값 성질과 최대 원리

원판에서 \(u = \operatorname{Re}f\)로 쓰고 정칙함수의 평균값 성질(2.4절)의 실수부를 취하면

\[u(z_0) = \frac1{2\pi}\int_0^{2\pi}u(z_0 + re^{it})\,dt.\]
정리 4.1.3 (최대 원리) 연결 영역에서 조화함수가 내부에서 최댓값(또는 최솟값)을 가지면 상수이다. 유계 영역에서 경계까지 연속이면 최댓값과 최솟값은 경계에서 얻는다.
증명

내부의 최대점 \(z_0\)에서 평균값 성질의 평균이 최댓값과 같으므로 원 위의 모든 값이 최댓값이다(평균이 최댓값이면 모두 최댓값). 최댓값을 가지는 점의 집합이 열려 있고 닫혀 있어 영역 전체이다. 최솟값은 \(-u\)에 적용. ∎

그래서 조화함수는 경계값으로 유일하게 정해집니다(두 해의 차는 경계에서 0이라 안에서도 0). 경계값에서 실제로 해를 만드는 것이 4.4절의 디리클레 문제입니다.

흔한 오해(1) 조화함수의 곱도 조화라고 여긴다. \(x\)와 \(x\)는 조화지만 \(x^2\)은 \(\Delta = 2\)이다. (2) 조화함수의 최댓값이 내부의 "봉우리"에 있을 수 있다고 여긴다. 조화함수에는 내부 극대·극소가 없고, 그래프는 안장 모양이다.
요약
  1. 조화: \(u_{xx} + u_{yy} = 0\). 정칙함수의 실·허수부는 조화.
  2. 단순연결 영역의 조화함수는 정칙함수의 실수부.
  3. 평균값 성질과 최대·최소 원리: 경계값이 해를 결정한다.

4.1.3연습문제

기본

  1. \(u = x^3 - 3xy^2\)가 조화임을 확인하고 켤레 조화함수를 구하여라.
    답

    \(u_{xx} = 6x\), \(u_{yy} = -6x\). \(u = \operatorname{Re}z^3\)이라 켤레는 \(v = 3x^2y - y^3\).

응용

  1. 단위원판에서 조화이고 경계에서 \(u = \cos\theta\)인 함수를 구하여라.
    답

    \(u = x = \operatorname{Re}z\). 경계에서 \(x = \cos\theta\)이고 조화, 유일성으로 이것이 해.

심화

  1. \(u = x^2 + y^2\)는 조화가 아님을 보이고, 원판 \(|z| \le 1\)에서 최댓값은 경계에, 최솟값은 내부(원점)에 있음을 확인하여라. 최소 원리와 모순인가?
    답

    \(\Delta u = 4 \ne 0\)이라 조화가 아니어서 모순이 아니다. 실제로 \(\Delta u > 0\)인 함수(아래로 볼록)는 내부 최댓값이 없지만 내부 최솟값은 가질 수 있다.
