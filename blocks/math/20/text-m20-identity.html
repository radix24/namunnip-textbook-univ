일치 정리와 최대 절댓값 원리

본문
이 절에서 배울 것
  • 연결된 영역에서 정칙함수의 영점이 집적점을 가지면 함수가 0임(일치 정리)을 증명한다.
  • 정칙함수의 절댓값이 영역 내부에서 최대가 될 수 없음(최대 절댓값 원리)을 평균값 성질로 증명한다.
  • 두 정리를 함수 등식의 확장과 최댓값 위치 찾기에 적용한다.
먼저 알아야 할 것
  • 코시 적분 공식과 멱급수 전개 (2.2절), 연결 집합 (수학14).

2.4.1일치 정리

정리 2.4.1 \(\Omega\)가 연결된 열린집합이고 \(f\)가 \(\Omega\)에서 정칙이며, \(f\)의 영점 집합이 \(\Omega\) 안에 집적점을 가지면 \(f \equiv 0\)이다.
증명

집적점 \(z_0\)에서 \(f(z_0) = 0\)(연속). \(f\)가 \(z_0\) 근처에서 0이 아니라면 \(f = \sum_{n\ge m}a_n(z - z_0)^n = (z - z_0)^mg(z)\), \(g(z_0) = a_m \ne 0\)이고, \(g\)는 연속이라 \(z_0\) 근처에서 0이 아니므로 \(z_0\) 근처에 다른 영점이 없어 모순. 따라서 \(f\)는 \(z_0\) 근처에서 0이다. "근처에서 \(f \equiv 0\)인 점"의 집합 \(U\)는 열려 있고, 같은 논법으로 닫혀 있으며, 비어 있지 않으므로 연결성으로 \(U = \Omega\). ∎

그래서 두 정칙함수가 한 선분(또는 수렴하는 점열) 위에서 같으면 연결 영역 전체에서 같습니다. 예를 들어 \(\sin^2z + \cos^2z = 1\)은 실수축에서 참이므로 모든 복소수에서 참입니다. 반면 정칙함수의 영점은 고립되어 있습니다(상수 0이 아니면).

2.4.2최대 절댓값 원리

코시 적분 공식을 원 \(|\zeta - z_0| = r\)에 매개화하면 평균값 성질

\[f(z_0) = \frac1{2\pi}\int_0^{2\pi}f(z_0 + re^{it})\,dt\]

를 얻습니다. 중심의 값은 둘레 값의 평균입니다.

정리 2.4.2 (최대 절댓값 원리) \(f\)가 연결된 열린집합 \(\Omega\)에서 정칙이고 \(|f|\)가 내부의 점 \(z_0\)에서 최대이면 \(f\)는 상수이다. 따라서 유계 영역에서 \(\bar\Omega\)까지 연속이면 \(|f|\)의 최댓값은 경계에서 얻는다.
증명

평균값 성질로 \(|f(z_0)| \le \frac1{2\pi}\int|f(z_0 + re^{it})|\,dt \le |f(z_0)|\)이므로 등호이고, 연속성으로 원 위에서 \(|f| = |f(z_0)|\)이다. 모든 작은 \(r\)에 대해 그러므로 \(z_0\) 근처에서 \(|f|\)가 상수이고, 그러면 \(f\)가 상수(코시-리만으로)이며 일치 정리로 \(\Omega\) 전체에서 상수이다. ∎

예 2.4.3 닫힌 단위원판에서 \(|e^z|\)의 최댓값은 경계에서 \(|e^z| = e^{\operatorname{Re}z} \le e^1\)이고 \(z = 1\)에서 얻습니다. \(|z^2 - 1|\)의 최댓값은 경계 \(z = e^{it}\)에서 \(|e^{2it} - 1| = 2|\sin t|\)의 최댓값 2(\(z = \pm i\))입니다.
흔한 오해(1) 영점이 무한히 많으면 함수가 0이라고 여긴다. 집적점이 영역 안에 있어야 한다. \(\sin\frac1z\)은 영점 \(\frac1{n\pi}\)이 \(0\)으로 모이지만 0은 정의역 밖이다. (2) 최소 절댓값도 경계에서 얻는다고 여긴다. 영점이 있으면 내부에서 0이 최소이다(영점이 없으면 \(\frac1f\)에 적용해 경계에서).
요약
  1. 일치 정리: 영점이 영역 안에 집적하면 \(f \equiv 0\). 등식은 실수축에서 복소평면으로 확장된다.
  2. 평균값 성질 \(f(z_0) = \frac1{2\pi}\int f(z_0 + re^{it})dt\).
  3. 최대 절댓값 원리: \(|f|\)의 최댓값은 경계에서.

2.4.4연습문제

기본

  1. 정칙함수 \(f\)가 \(f\left(\frac1n\right) = 0\) (\(n = 1, 2, \dots\))이고 원판 \(|z| < 2\)에서 정칙이면 \(f\)는?
    답

    영점이 0으로 모이고 0이 원판 안에 있으므로 \(f \equiv 0\).

응용

  1. \(|z| \le 1\)에서 \(|z^3 + 2z + 1|\)의 최댓값의 상한을 구하고, 그 값이 \(z = 1\)에서 얻어짐을 확인하여라.
    답

    삼각부등식으로 경계에서 \(\le 1 + 2 + 1 = 4\), \(z = 1\)에서 \(4\)이므로 최댓값 4.

심화

  1. \(f\)가 원판에서 정칙이고 영점이 없으며 경계에서 \(|f| = 1\)이면 \(f\)는 상수임을 보여라.
    답

    최대 원리로 \(|f| \le 1\), \(\frac1f\)에 적용하면 \(|f| \ge 1\). 따라서 \(|f| = 1\)이 내부에서도 성립해 내부 최대가 되므로 상수.
