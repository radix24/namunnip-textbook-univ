리만 제타함수의 연장과 함수 방정식

본문
이 절에서 배울 것
  • \(\operatorname{Re}s > 1\)에서 \(\zeta(s) = \sum\frac1{n^s}\)와 오일러 곱 \(\prod_p(1 - p^{-s})^{-1}\)을 안다.
  • 세타 함수와 감마함수로 \(\zeta\)를 \(s = 1\)의 단순극을 뺀 전체로 연장하는 흐름과 함수 방정식 \(\xi(s) = \xi(1 - s)\)를 설명한다.
  • 자명한 영점, 임계띠, 리만 가설의 내용을 안다.
먼저 알아야 할 것
  • 감마함수 (7.1절), 세타 함수의 함수방정식(수학15 4.3절), 일치 정리.

7.3.1정의와 오일러 곱

\(\operatorname{Re}s = \sigma > 1\)이면 \(\left|\frac1{n^s}\right| = \frac1{n^\sigma}\)의 합이 수렴해 \(\zeta(s) = \sum_{n\ge1}n^{-s}\)는 정칙입니다. 소인수분해의 유일성으로

\[\zeta(s) = \prod_p\frac1{1 - p^{-s}}\]

(오일러 곱)이고, 이 곱의 인수는 0이 아니므로 \(\operatorname{Re}s > 1\)에서 \(\zeta(s) \ne 0\)입니다. \(\zeta(2) = \frac{\pi^2}6\) (5.2절), \(\zeta(4) = \frac{\pi^4}{90}\)입니다.

7.3.2연장과 함수 방정식

\(\Gamma\left(\frac s2\right)\pi^{-s/2}n^{-s} = \int_0^\infty e^{-\pi n^2t}t^{s/2-1}dt\) (치환)를 \(n\)에 대해 더하면

\[\xi(s) := \pi^{-s/2}\Gamma\!\left(\frac s2\right)\zeta(s) = \int_0^\infty\frac{\vartheta(t) - 1}2t^{s/2-1}dt, \qquad \vartheta(t) = \sum_{n\in\mathbb Z}e^{-\pi n^2t}.\]

적분을 \(\int_0^1 + \int_1^\infty\)로 나누고, \(\int_0^1\) 쪽에 세타 함수의 함수방정식 \(\vartheta(t) = t^{-1/2}\vartheta(1/t)\)(푸아송 합 공식)를 쓰면

\[\xi(s) = \frac1{s - 1} - \frac1s + \int_1^\infty\frac{\vartheta(t) - 1}2\left(t^{s/2} + t^{(1-s)/2}\right)\frac{dt}t.\]

남은 적분은 \(\vartheta(t) - 1\)이 \(e^{-\pi t}\)처럼 빨리 줄어 모든 \(s\)에서 정칙입니다. 그래서

정리 7.3.1 (리만) \(\zeta\)는 \(s = 1\)에서 유수 1인 단순극을 빼고 \(\mathbb C\) 전체로 정칙 연장되고, \(\xi(s) = \pi^{-s/2}\Gamma\left(\frac s2\right)\zeta(s)\)는 \(\xi(s) = \xi(1 - s)\)를 만족한다.

대칭성은 위 식이 \(s \leftrightarrow 1 - s\)에서 그대로라는 데서 바로 보입니다. \(\frac1s\)의 극은 \(\Gamma\left(\frac s2\right)\)의 \(s = 0\) 극과 지워져 \(\zeta(0) = -\frac12\)이 됩니다.

7.3.3영점

  • 자명한 영점: \(\Gamma\left(\frac s2\right)\)는 \(s = -2, -4, \dots\)에서 극이고 \(\xi\)는 그곳에서 유한하므로 \(\zeta(-2k) = 0\).
  • 임계띠: \(\operatorname{Re}s > 1\)에서 영점이 없고, 함수 방정식으로 \(\operatorname{Re}s < 0\)에는 자명한 영점뿐이다. 나머지 영점은 \(0 \le \operatorname{Re}s \le 1\)에 있고 \(\operatorname{Re}s = \frac12\)에 대해 대칭이다. 첫 영점은 \(\frac12 + 14.1347i\)이다.
  • 리만 가설: 자명하지 않은 영점은 모두 \(\operatorname{Re}s = \frac12\) 위에 있다(미해결, 밀레니엄 문제). 소수의 분포 오차와 직결된다.
흔한 오해(1) \(\zeta(-1) = 1 + 2 + 3 + \cdots = -\frac1{12}\)이라는 식을 급수의 합으로 여긴다. 급수는 발산하고, \(-\frac1{12}\)은 해석적 연장의 값이다. (2) \(\zeta(1)\)이 유한하다고 여긴다. 조화급수가 발산하고, \(s = 1\)은 극이다.
요약
  1. \(\zeta(s) = \sum n^{-s} = \prod(1 - p^{-s})^{-1}\) (\(\operatorname{Re}s > 1\)).
  2. 세타 함수와 감마함수로 연장: \(s = 1\)의 단순극만, \(\xi(s) = \xi(1 - s)\).
  3. 자명한 영점 \(-2, -4, \dots\), 나머지는 임계띠, 리만 가설은 \(\operatorname{Re}s = \frac12\).

7.3.4연습문제

기본

  1. 오일러 곱에서 \(\zeta(2) = \prod_p\frac{p^2}{p^2 - 1}\)의 처음 세 인수(\(p = 2, 3, 5\))의 곱을 \(\frac{\pi^2}6\)과 비교하여라.
    답

    \(\frac43\cdot\frac98\cdot\frac{25}{24} = 1.5625\), \(\frac{\pi^2}6 \approx 1.6449\).

응용

  1. 함수 방정식으로 \(\zeta(-1)\)을 \(\zeta(2)\)로 나타내는 계산의 뼈대를 써라(\(\Gamma(-\frac12) = -2\sqrt\pi\), \(\Gamma(1) = 1\)).
    답

    \(\xi(-1) = \xi(2)\): \(\pi^{1/2}\Gamma(-\frac12)\zeta(-1) = \pi^{-1}\Gamma(1)\zeta(2)\). \(-2\pi\zeta(-1) = \frac1\pi\cdot\frac{\pi^2}6\)이라 \(\zeta(-1) = -\frac1{12}\).

심화

  1. \(\operatorname{Re}s > 1\)에서 \(\zeta(s) \ne 0\)임을 오일러 곱으로 설명하여라.
    답

    \(\log\zeta(s) = -\sum_p\log(1 - p^{-s})\)이 절대수렴하므로(\(\sum p^{-\sigma} < \infty\)) \(\zeta = e^{\log\zeta} \ne 0\).
