하다마르 인수분해와 sin의 곱 공식

본문
이 절에서 배울 것
  • 바이어슈트라스 곱으로 주어진 영점을 갖는 정함수를 만드는 방법을 안다.
  • 유한 차수 \(\rho\)인 정함수가 \(e^{P(z)}\times\)(영점의 곱) 꼴(\(\deg P \le \rho\))이라는 하다마르 정리를 진술한다.
  • \(\sin\pi z = \pi z\prod_{n\ge1}\left(1 - \frac{z^2}{n^2}\right)\)을 유도하고 \(\sum\frac1{n^2} = \frac{\pi^2}6\)을 얻는다.
먼저 알아야 할 것
  • 옌센 공식과 증가 차수 (5.1절), 무한곱의 수렴(\(\sum|a_n| < \infty\)이면 \(\prod(1 + a_n)\) 수렴).

5.2.1영점에서 함수 만들기

다항식은 영점으로 \(c\prod(z - a_k)\)로 정해집니다. 정함수에서도 영점 \(a_n \to \infty\)이 주어지면 그 영점만 갖는 정함수가 있습니다(바이어슈트라스). 단순히 \(\prod\left(1 - \frac z{a_n}\right)\)은 수렴하지 않을 수 있어, 수렴 인자 \(E_k(u) = (1 - u)e^{u + u^2/2 + \cdots + u^k/k}\)를 씁니다.

정리 5.2.1 (하다마르) 정함수 \(f\)의 증가 차수가 \(\rho\)이고 \(k = \lfloor\rho\rfloor\)이면 \[f(z) = e^{P(z)}z^m\prod_n E_k\!\left(\frac z{a_n}\right)\] 이다. 여기서 \(a_n\)은 0이 아닌 영점, \(m\)은 원점의 영점 차수, \(P\)는 차수 \(k\) 이하의 다항식이다.

요점은 지수 부분 \(e^{P}\)가 다항식의 지수라는 것입니다. 영점이 없는 정함수는 일반적으로 \(e^{g(z)}\) (\(g\) 정함수)인데, 차수가 유한하면 \(g\)가 다항식으로 제한됩니다.

5.2.2sin의 곱 공식

정리 5.2.2 \(\sin\pi z = \pi z\prod_{n=1}^\infty\left(1 - \frac{z^2}{n^2}\right)\).
증명

\(\sin\pi z\)는 차수 1이고 영점은 정수(단순)이므로 \(k = 1\)에서 \(\sin\pi z = e^{az + b}z\prod_{n\ne0}\left(1 - \frac zn\right)e^{z/n}\). \(\pm n\)의 항을 짝지으면 \(e^{z/n}e^{-z/n} = 1\)이라 \(\prod_{n\ge1}\left(1 - \frac{z^2}{n^2}\right)\)이 남는다. 좌변이 홀함수이므로 \(a = 0\), \(z \to 0\)에서 \(\frac{\sin\pi z}z \to \pi\)이므로 \(e^b = \pi\). ∎

예 5.2.3 \(z = 0.3\)에서 곱을 \(N = 10, 100, 1000\)까지 하면 \(0.8160, 0.8097, 0.8091\)이고 \(\sin(0.3\pi) = 0.80902\)로 다가갑니다(오차는 약 \(\frac{z^2}N\sin\pi z\)로 천천히 줄어듦).

양변의 \(z^3\) 계수를 비교하면 왼쪽 \(-\frac{\pi^3}6\), 오른쪽 \(-\pi\sum\frac1{n^2}\)이므로 \(\sum_{n\ge1}\frac1{n^2} = \frac{\pi^2}6\)(오일러, 바젤 문제)입니다. \(z = \frac12\)을 넣으면 월리스 곱 \(\frac\pi2 = \prod\frac{(2n)^2}{(2n - 1)(2n + 1)}\)도 나옵니다.

흔한 오해(1) 영점이 같으면 함수가 같다고 여긴다. \(e^{P}\)만큼 다를 수 있다(\(\sin\pi z\)와 \(e^z\sin\pi z\)). (2) \(\prod\left(1 - \frac zn\right)\) (\(n \in \mathbb Z\setminus0\))이 그대로 수렴한다고 여긴다. 양·음을 짝짓거나 수렴 인자 \(e^{z/n}\)이 필요하다.
요약
  1. 바이어슈트라스: 주어진 영점을 가진 정함수, 수렴 인자 \(E_k\).
  2. 하다마르: 차수 \(\rho\)이면 \(f = e^{P}z^m\prod E_{\lfloor\rho\rfloor}(z/a_n)\), \(\deg P \le \rho\).
  3. \(\sin\pi z = \pi z\prod(1 - z^2/n^2)\), \(\sum\frac1{n^2} = \frac{\pi^2}6\).

5.2.4연습문제

기본

  1. 영점이 없고 차수가 2 이하인 정함수의 꼴은?
    답

    \(e^{az^2 + bz + c}\).

응용

  1. \(\cos\pi z\)의 곱 공식을 써라.
    답

    영점 \(\pm\frac12, \pm\frac32, \dots\), 짝함수, \(\cos0 = 1\)이므로 \(\prod_{n\ge1}\left(1 - \frac{4z^2}{(2n - 1)^2}\right)\).

심화

  1. 곱 공식에 \(z = \frac12\)을 넣어 월리스 곱을 유도하여라.
    답

    \(1 = \frac\pi2\prod\left(1 - \frac1{4n^2}\right) = \frac\pi2\prod\frac{(2n - 1)(2n + 1)}{(2n)^2}\), 따라서 \(\frac\pi2 = \prod\frac{(2n)^2}{(2n - 1)(2n + 1)}\).
