Riemann 곡면 위의 유리형 미분형식과 유수 정리

본문

복소평면에서는 \(f(z)\,dz\)를 닫힌 곡선을 따라 적분해 유수를 셌다. Riemann 곡면에는 좌표가 하나로 정해져 있지 않다. 그러면 "점에서의 유수"는 좌표를 바꿔도 같은 값일까? 그리고 컴팩트한 곡면 전체에서 유수를 모두 더하면 무엇이 되는가?

먼저 알아야 할 것Riemann 곡면과 좌표조각(0.1절), 복소해석학의 유수 정리, 미분형식과 Stokes 정리(미분기하)를 쓴다. 교재 3장(미분형식)을 따른다.

6.1.1유리형 함수와 1-형식

Riemann 곡면 \(X\) 위의 유리형 함수는 각 좌표조각에서 유리형인 함수이다. 점 \(p\)에서의 위수 \(\operatorname{ord}_p f\)는 국소 좌표 \(z\)(\(z(p) = 0\))에서 \(f = z^m\cdot(\text{0이 아닌 정칙함수})\)의 \(m\)이다. 좌표를 \(z = \phi(w)\)로 바꾸어도 \(\phi'(0) \ne 0\)이라 \(m\)은 그대로이다. 그러면 위수는 점만의 성질이다.

유리형 1-형식은 각 좌표에서 \(\omega = f(z)\,dz\)(\(f\)는 유리형)로 쓰이고, 좌표가 바뀌면 \(f(z)\,dz = f(\phi(w))\phi'(w)\,dw\)로 바뀌는 대상이다. 함수와 달리 1-형식은 좌표 변환에서 도함수 인수 \(\phi'\)를 함께 가진다. 이 인수 덕분에 \(\omega\)의 선적분이 좌표에 무관하게 정의된다.

6.1.2유수

정의 6.1.1 (유수)

\(\omega = f(z)\,dz\)의 점 \(p\)에서의 유수는 \(f\)의 Laurent 전개에서 \(z^{-1}\)의 계수이다. 이것은 \(p\) 주위의 작은 원 \(\gamma\)에 대해 \(\frac{1}{2\pi i}\oint_\gamma\omega\)와 같다.

뒤의 적분 표현이 좌표 무관성을 준다. 선적분은 좌표에 무관하고, 작은 원을 다른 작은 원으로 바꾸어도 극점을 하나만 감으면 Cauchy 정리로 값이 같기 때문이다. 반면 함수 \(f\) 자체의 "유수"는 좌표에 따라 달라진다. 가령 \(\mathbb P^1\)의 \(\infty\)에서 \(w = 1/z\)를 쓰면 \(dz = -w^{-2}dw\)라서, \(\omega = \frac{dz}{z}\)는 \(-\frac{dw}{w}\)가 되어 \(\infty\)에서 유수 \(-1\)을 가진다.

정리 6.1.2 (유수 정리)

컴팩트 Riemann 곡면 위의 유리형 1-형식의 유수를 모든 극점에서 더하면 0이다.

증명.극점은 컴팩트성으로 유한 개 \(p_1, \dots, p_k\)이다. 각 극점 주위의 작은 좌표 원판 \(D_j\)를 빼면 \(X' = X \setminus \bigcup D_j\)에서 \(\omega\)는 정칙이고, 정칙 1-형식은 \(d\omega = \partial_{\bar z}f\,d\bar z \wedge dz = 0\)이다. Stokes 정리로 \(0 = \iint_{X'}d\omega = \int_{\partial X'}\omega = -\sum_j\oint_{\partial D_j}\omega\)이다. 경계의 방향이 원판 쪽에서 보면 반대이기 때문에 부호가 붙는다. 따라서 \(\sum_j2\pi i\operatorname{Res}_{p_j}\omega = 0\)이다. ∎

예제 6.1.3

\(\mathbb P^1\) 위에서 \(\omega = \frac{dz}{z(z - 1)}\)의 모든 유수를 구하고 합이 0인지 확인하여라.

풀이. \(z = 0\)에서 유수는 \(\frac{1}{0 - 1} = -1\), \(z = 1\)에서 \(\frac11 = 1\)이다. \(\infty\)에서는 \(z = 1/w\)를 넣어 \(\omega = \frac{-w^{-2}dw}{w^{-1}(w^{-1} - 1)} = \frac{-dw}{1 - w}\)이고, \(w = 0\)에서 정칙이라 유수가 0이다. 합은 \(-1 + 1 + 0 = 0\)이다. 같은 계산을 유리함수의 부분분수 분해로 해석하면, 정리 6.1.2는 "유한한 극점들의 유수의 합과 무한대에서의 유수가 상쇄된다"는 복소해석학의 사실을 일반화한 것이다.

마무리

유리형 함수의 위수는 좌표에 무관하지만, 유수를 좌표에 무관하게 말하려면 함수가 아니라 1-형식을 써야 한다. 유수는 작은 원 위의 적분으로 정의되어 좌표와 상관없이 정해진다. 컴팩트 곡면에서는 극점 주위를 빼고 Stokes 정리를 쓰면 유수의 합이 0이 된다.

6.1.4연습문제

기본

  1. \(\mathbb P^1\) 위의 \(dz\)가 \(\infty\)에서 위수 \(-2\)인 극점을 가짐을 보여라.
    답

    \(z = 1/w\)이면 \(dz = -w^{-2}dw\).

응용

  1. 컴팩트 Riemann 곡면의 영이 아닌 유리형 함수 \(f\)에 대해 \(\frac{df}{f}\)의 유수를 이용해 \(\sum_p\operatorname{ord}_pf = 0\)을 보여라.
    답

    \(f = z^m g\)이면 \(\frac{df}{f} = \frac{m}{z}dz + \frac{dg}{g}\)이라 유수가 \(m = \operatorname{ord}_pf\)이다. 유수 정리로 합이 0이다.
