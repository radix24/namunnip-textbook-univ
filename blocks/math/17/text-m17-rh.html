리만-후르비츠 공식

본문
이 절에서 배울 것
  • 컴팩트 리만 곡면 사이의 차수 \(d\)인 정칙사상에서 종수가 \(2g_X - 2 = d(2g_Y - 2) + \sum_p(m_p - 1)\)로 연결됨을 안다.
  • 삼각분할을 끌어올려 오일러 지표를 세는 방법으로 공식을 증명한다.
  • 초타원 곡선 \(y^2 = f(x)\)의 종수를 계산한다.
먼저 알아야 할 것
  • 분기 지수와 차수 (0.3절), 오일러 지표와 종수 \(\chi = 2 - 2g\) (수학13 6.2절).

0.4.1공식

정리 0.4.1 (리만-후르비츠) \(F : X \to Y\)가 컴팩트 리만 곡면 사이의 차수 \(d\)인 비상수 정칙사상이면 \[2g_X - 2 = d(2g_Y - 2) + \sum_{p\in X}(m_p - 1).\] 합은 유한 개의 분기점에 대해서만 0이 아니다.
증명

\(Y\)를 삼각분할하되 모든 분지점이 꼭짓점이 되게 한다(꼭짓점 \(V\), 변 \(E\), 면 \(T\)개, \(V - E + T = 2 - 2g_Y\)). 분지점이 아닌 곳에서 \(F\)는 \(d\)겹 피복이라 각 변과 면은 원상이 정확히 \(d\)개씩이고, 이들이 \(X\)의 삼각분할을 이룬다. 꼭짓점 \(q\)의 원상 개수는 \(\sum_{F(p) = q}1 = d - \sum_{F(p) = q}(m_p - 1)\)이다. 따라서

\[\chi(X) = \left(dV - \sum_p(m_p - 1)\right) - dE + dT = d\chi(Y) - \sum_p(m_p - 1).\]

\(\chi = 2 - 2g\)를 넣으면 공식이 된다. ∎

0.4.2예

예 0.4.2 \(F(z) = z^d\) (\(\hat{\mathbb C} \to \hat{\mathbb C}\))는 \(0\)과 \(\infty\)에서 지수 \(d\)이므로 \(2\cdot0 - 2 = d(-2) + 2(d - 1)\)로 \(-2 = -2\). 맞습니다.
예 0.4.3 (초타원 곡선) \(y^2 = (x - a_1)\cdots(x - a_{n})\) (\(a_i\)는 서로 다름)이 정하는 컴팩트 곡면 \(X\)에서 \((x, y) \mapsto x\)는 \(\hat{\mathbb C}\)로의 차수 2인 사상입니다. \(x = a_i\)에서 \(y\)가 하나라 분기(지수 2)이고, \(n\)이 홀수이면 \(x = \infty\)에서도 분기합니다. 분지점의 개수를 \(b\)라 하면(\(n\)이 짝수면 \(n\), 홀수면 \(n + 1\)) \[2g - 2 = 2(-2) + b, \qquad g = \frac b2 - 1.\] \(n = 3, 4\)이면 \(b = 4\), \(g = 1\)(타원곡선, 토러스). \(n = 5, 6\)이면 \(g = 2\)입니다.

공식의 오른쪽에서 \(\sum(m_p - 1) \ge 0\)이므로 \(g_X \ge g_Y\) (\(d \ge 1\))입니다. 종수가 큰 곡면에서 작은 곡면으로는 사상이 가능하지만 반대는 (상수 외에) 없습니다. 예를 들어 토러스에서 리만 구로 가는 비상수 사상은 있지만, 리만 구에서 토러스로 가는 비상수 정칙사상은 없습니다. 같은 절의 탐구 카드에서 분지점 개수에 따른 종수를 계산합니다.

흔한 오해(1) 분기점의 개수를 그냥 센다. 각 분기점이 \(m_p - 1\)만큼 기여한다. (2) \(y^2 = f(x)\)에서 \(x = \infty\)를 빼먹는다. \(\deg f\)가 홀수이면 \(\infty\)도 분지점이다.
요약
  1. \(2g_X - 2 = d(2g_Y - 2) + \sum(m_p - 1)\): 오일러 지표를 피복으로 세면 나온다.
  2. 초타원 곡선 \(y^2 = f(x)\): 분지점 \(b\)개, \(g = \frac b2 - 1\).
  3. \(g_X \ge g_Y\): 종수가 작은 곳에서 큰 곳으로 비상수 정칙사상은 없다.

0.4.3연습문제

기본

  1. \(y^2 = x^7 - 1\)의 종수를 구하여라.
    답

    분지점 7개(1의 7제곱근) + \(\infty\) = 8, \(g = 3\).

응용

  1. 종수 2인 곡면에서 리만 구로 가는 차수 2 사상의 분기점은 몇 개인가?
    답

    \(2 = 2(-2) + \sum(m_p - 1)\), \(m_p = 2\)이므로 분기점 6개.

심화

  1. 토러스에서 토러스로 가는 비상수 정칙사상은 분기점이 없음을 보여라.
    답

    \(0 = d\cdot0 + \sum(m_p - 1)\)이므로 모든 \(m_p = 1\). (실제로 이런 사상은 격자를 보존하는 \(z \mapsto az + b\) 꼴이다.)
