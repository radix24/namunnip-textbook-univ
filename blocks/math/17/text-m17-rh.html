리만-후르비츠 공식

본문

곡선 \(y^2 = (x - a_1)(x - a_2)(x - a_3)(x - a_4)\)는 \(x\)마다 \(y\)가 두 개이므로 리만 구를 두 겹으로 덮는다. 그런데 이 곡선은 구가 아니라 토러스라고 한다. 두 겹으로 덮는 곡면의 모양, 곧 종수를 분기점의 정보만으로 계산할 수 있을까?

먼저 알아야 할 것분기 지수와 차수(0.3절), 오일러 지표와 종수의 관계 \(\chi = 2 - 2g\)(수학13 6.2절)를 쓴다.

0.4.1공식

정리 0.4.1 (리만-후르비츠)

\(F : X \to Y\)가 컴팩트 리만 곡면 사이의 차수 \(d\)인 비상수 정칙사상이면 \(2g_X - 2 = d(2g_Y - 2) + \sum_{p\in X}(m_p - 1)\)이다. 합은 유한 개의 분기점에서만 0이 아니다.

증명.모든 분지점이 꼭짓점이 되도록 \(Y\)를 삼각분할하고, 꼭짓점, 변, 면의 수를 \(V, E, T\)라 하자. 그러면 \(V - E + T = 2 - 2g_Y\)이다. 분지점이 아닌 곳에서 \(F\)는 \(d\)겹 피복이므로 각 변과 면은 원상이 정확히 \(d\)개씩이고, 이 원상들이 \(X\)의 삼각분할을 이룬다. 한편 꼭짓점 \(q\)의 원상의 개수는 \(\sum_{F(p) = q}1 = d - \sum_{F(p) = q}(m_p - 1)\)이다. 따라서 \(\chi(X) = \left(dV - \sum_p(m_p - 1)\right) - dE + dT = d\chi(Y) - \sum_p(m_p - 1)\)이고, \(\chi = 2 - 2g\)를 넣으면 공식이 된다. ∎

0.4.2예

예제 0.4.2

\(F(z) = z^d\) (\(\hat{\mathbb C} \to \hat{\mathbb C}\))에서 공식을 확인하여라.

풀이. \(0\)과 \(\infty\)에서 분기 지수가 \(d\)이고 나머지에서는 1이므로, 오른쪽은 \(d(-2) + 2(d - 1) = -2\)이다. 왼쪽도 \(2\cdot0 - 2 = -2\)라 공식이 맞는다.

예제 0.4.3 (초타원 곡선)

서로 다른 \(a_i\)에 대해 \(y^2 = (x - a_1)\cdots(x - a_{n})\)이 정하는 컴팩트 곡면 \(X\)의 종수를 구하여라.

풀이. \((x, y) \mapsto x\)는 \(\hat{\mathbb C}\)로 가는 차수 2인 사상이다. \(x = a_i\)에서는 \(y\)가 하나뿐이라 분기 지수가 2이고, \(n\)이 홀수이면 \(x = \infty\)에서도 분기한다. 분지점의 개수를 \(b\)라 하면 \(n\)이 짝수일 때 \(b = n\), 홀수일 때 \(b = n + 1\)이다. 그러면 \(2g - 2 = 2(-2) + b\)에서 \(g = \frac b2 - 1\)이다. 따라서 \(n = 3, 4\)이면 \(b = 4\), \(g = 1\)로 그림 1의 토러스, 곧 타원곡선이다. 또 \(n = 5, 6\)이면 \(g = 2\)이다.

공식의 오른쪽에서 \(\sum(m_p - 1) \ge 0\)이므로 \(d \ge 1\)이면 \(g_X \ge g_Y\)이다. 곧 종수가 큰 곡면에서 작은 곡면으로는 사상이 있을 수 있지만, 그 반대로는 상수 말고는 없다. 예를 들어 토러스에서 리만 구로 가는 비상수 사상은 있지만, 리만 구에서 토러스로 가는 비상수 정칙사상은 없다. 같은 절의 탐구 카드에서 분지점의 개수에 따른 종수를 계산해 본다.

흔한 오해분기점의 개수를 그냥 세기 쉽지만, 각 분기점은 \(m_p - 1\)만큼 기여한다. 또 \(y^2 = f(x)\)에서 \(x = \infty\)를 빼먹는 실수가 잦다. \(\deg f\)가 홀수이면 \(\infty\)도 분지점이다.
마무리

처음 질문에 답하면, 덮는 곡면의 종수는 리만-후르비츠 공식 \(2g_X - 2 = d(2g_Y - 2) + \sum(m_p - 1)\)으로 분기점의 정보만 가지고 계산할 수 있다. 증명은 분지점을 꼭짓점으로 하는 삼각분할을 끌어올려 오일러 지표를 세는 것이다. \(y^2 = (x - a_1)\cdots(x - a_4)\)는 리만 구를 두 겹으로 덮고 분지점이 4개이므로 \(2g - 2 = -4 + 4\), 곧 종수 1인 토러스이다.

0.4.3연습문제

기본

  1. \(y^2 = x^7 - 1\)의 종수를 구하여라.
    답

    분지점 7개(1의 7제곱근) + \(\infty\) = 8, \(g = 3\).

응용

  1. 종수 2인 곡면에서 리만 구로 가는 차수 2 사상의 분기점은 몇 개인가?
    답

    \(2 = 2(-2) + \sum(m_p - 1)\), \(m_p = 2\)이므로 분기점 6개.

심화

  1. 토러스에서 토러스로 가는 비상수 정칙사상은 분기점이 없음을 보여라.
    답

    \(0 = d\cdot0 + \sum(m_p - 1)\)이므로 모든 \(m_p = 1\). (실제로 이런 사상은 격자를 보존하는 \(z \mapsto az + b\) 꼴이다.)
