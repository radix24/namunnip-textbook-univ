정칙사상의 국소 꼴과 분기

본문
이 절에서 배울 것
  • 리만 곡면 사이의 비상수 정칙사상은 각 점 근처에서 좌표를 잘 고르면 \(z \mapsto z^m\) 꼴임을 안다.
  • 이 \(m\)을 분기 지수로 정의하고, \(m \ge 2\)인 점을 분기점이라 한다.
  • 컴팩트 곡면 사이의 사상에서 \(\sum_{p\in F^{-1}(q)}m_p\)가 \(q\)에 관계없는 상수(차수)임을 이해한다.
먼저 알아야 할 것
  • 리만 곡면과 유리형 함수 (0.2절), 정칙함수의 영점의 차수 (수학20).

0.3.1국소 표준형

정리 0.3.1 \(F : X \to Y\)가 리만 곡면 사이의 비상수 정칙사상이고 \(p \in X\)이면, \(p\) 근처의 좌표 \(z\) (\(z(p) = 0\))와 \(F(p)\) 근처의 좌표 \(w\) (\(w(F(p)) = 0\))를 골라 \(F\)가 \(w = z^m\)이 되게 할 수 있다. 이 \(m \ge 1\)은 좌표에 관계없이 정해진다.
증명의 흐름

임의의 좌표에서 \(F\)는 \(w = h(z)\), \(h(0) = 0\)이고 \(h\)의 영점의 차수를 \(m\)이라 하면 \(h(z) = z^mg(z)\), \(g(0) \ne 0\)이다. \(g\)는 0 근처에서 \(m\)제곱근 \(g = k^m\)을 가지므로 새 좌표 \(\tilde z = zk(z)\)를 쓰면 \(w = \tilde z^m\)이다(\(\tilde z'(0) = k(0) \ne 0\)이라 좌표가 된다). ∎

이 \(m = m_p\)를 \(p\)에서의 분기 지수라 합니다. \(m_p \ge 2\)이면 \(p\)를 분기점, \(F(p)\)를 분지점이라 합니다. \(w = z^m\)은 \(w \ne 0\) 근처의 점마다 원상이 \(m\)개이고 \(w = 0\)에서 하나로 모입니다. 좌표에서 \(m_p\)는 \(F'\)이 \(p\)에서 \(m_p - 1\)차로 0이 되는 것과 같으므로, 분기점은 고립되어 있고 컴팩트 곡면에서는 유한 개입니다.

0.3.2차수

정리 0.3.2 \(X, Y\)가 컴팩트이고 \(F : X \to Y\)가 비상수 정칙사상이면 \(d_q = \sum_{p\in F^{-1}(q)}m_p\)는 \(q \in Y\)에 관계없이 일정하다. 이 값을 \(F\)의 차수 \(\deg F\)라 한다.
증명의 흐름

각 \(p \in F^{-1}(q)\) 근처에서 \(w = z^m\)이므로 \(q\) 근처의 \(q'\)은 그 근처에 원상을 정확히 \(m_p\)개(중복도 포함) 가진다. \(X\)가 컴팩트라 \(F^{-1}(q)\) 밖의 점이 \(q\) 근처로 가지 않도록 할 수 있어 \(d_{q'} = d_q\)이다. 국소적으로 일정하고 \(Y\)가 연결이라 일정하다. ∎

예 0.3.3 리만 구의 \(F(z) = z^3\)은 차수 3입니다. \(z = 0\)에서 \(m = 3\), \(z = \infty\)에서도 \(w = \frac1z\)로 보면 \(\frac1{F} = w^3\)이라 \(m = 3\), 나머지 점은 \(m = 1\)입니다. \(q = 8\)의 원상은 \(2, 2\omega, 2\omega^2\) (\(\omega = e^{2\pi i/3}\))로 세 개, \(q = 0\)은 \(0\) 하나지만 지수 3이라 합이 3입니다. 같은 절의 예제 카드에서 유리함수의 분기를 구하고, 탐구 카드에서 \(z^m\)의 모양을 봅니다.

유리형 함수 \(f : X \to \hat{\mathbb C}\)의 차수는 영점의 수(= 극의 수)입니다. 0.2절 연습 3의 결과가 여기서 다시 나옵니다.

흔한 오해(1) 분기 지수가 좌표에 따라 달라진다고 여긴다. \(F'\)이 0이 되는 차수로 정해져 좌표와 무관하다. (2) 차수가 원상의 개수라고 여긴다. 분기점이 있으면 원상의 개수는 차수보다 적고, 중복도를 세야 한다.
요약
  1. 비상수 정칙사상은 국소적으로 \(w = z^m\): \(m\)은 분기 지수.
  2. 분기점은 \(m \ge 2\)인 점, 고립되어 있다.
  3. 컴팩트 곡면 사이에서 \(\sum_{F(p) = q}m_p = \deg F\)는 일정하다.

0.3.3연습문제

기본

  1. \(F(z) = z^2 + 1\) (\(\hat{\mathbb C} \to \hat{\mathbb C}\))의 차수와 분기점을 구하여라.
    답

    차수 2. \(F' = 2z\)이므로 \(z = 0\)에서 \(m = 2\), \(\infty\)에서도 2차 극이라 \(m = 2\).

응용

  1. 차수 \(d\)인 다항식 \(p(z)\)를 \(\hat{\mathbb C} \to \hat{\mathbb C}\)로 볼 때 \(\infty\)의 분기 지수는?
    답

    \(\infty\)의 원상은 \(\infty\) 하나뿐이고 \(d\)차 극이라 \(m_\infty = d\).

심화

  1. 컴팩트 리만 곡면 사이의 차수 1인 정칙사상은 동형사상임을 설명하여라.
    답

    모든 점의 원상이 정확히 하나이고 분기 지수 1이라 국소적으로 \(w = z\)이다. 따라서 정칙인 전단사이고 역사상도 정칙이다.
