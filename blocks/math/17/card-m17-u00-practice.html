리만 곡면 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산리만 구에서 \(f(z) = \frac{z^3}{(z - 1)^2}\)의 모든 영점과 극을 차수와 함께 구하고, 개수가 같음을 확인하여라. [00-02]

    힌트 1

    \(\infty\)에서는 \(w = \frac1z\)로 본다.

    힌트 2

    \(f(\frac1w) = \frac{1}{w(1 - w)^2}\).

    풀이

    영점: \(z = 0\) (3차). 극: \(z = 1\) (2차), \(\infty\) (1차). 영점 3개, 극 3개로 같다 (0.2절).

  2. 증명컴팩트 리만 곡면 \(X\)에서 \(\hat{\mathbb C}\)로 가는 차수 1인 유리형 함수가 있으면 \(X \cong \hat{\mathbb C}\)임을 보여라. [00-03]

    힌트 1

    차수 1 = 모든 점의 원상이 하나, 분기 없음.

    힌트 2

    0.3절 연습 3.

    풀이

    차수 1이면 정칙 전단사이고 국소적으로 \(w = z\)라 역사상도 정칙이므로 동형이다 (0.3절). ∎

  3. 계산\(F(z) = z^4\)와 \(F(z) = z^4 - 2z^2\)의 리만 구 위 분기점과 지수를 구하고, 리만-후르비츠 공식을 확인하여라. [00-04]

    힌트 1

    \(z^4\): \(0\)과 \(\infty\)에서 지수 4.

    힌트 2

    \(z^4 - 2z^2\): \(F' = 4z(z^2 - 1)\).

    풀이

    \(z^4\): \(\sum(m - 1) = 3 + 3 = 6\), \(-2 = 4(-2) + 6\). \(z^4 - 2z^2\): \(z = 0, \pm1\)에서 지수 2, \(\infty\)에서 4, 합 \(1 + 1 + 1 + 3 = 6\), 역시 \(-2 = -8 + 6\) (0.4절).

  4. 계산\(y^3 = x^4 - 1\)이 정하는 컴팩트 곡면의 종수를 \((x, y) \mapsto x\)로 구하여라(무한원점에서는 원상이 하나이고 완전히 분기한다고 가정). [00-04]

    힌트 1

    차수 3.

    힌트 2

    \(x^4 = 1\)인 4점과 \(\infty\)에서 지수 3.

    풀이

    \(2g - 2 = 3(-2) + 5\cdot2 = 4\), \(g = 3\). 이 곡선은 매끄러운 사차 평면 곡선과 같은 종수이다.

  5. 계산\(y^2 = x^3\)의 특이점을 구하고, \(t \mapsto (t^2, t^3)\)이 정규화를 줌을 설명하여라. [00-05]

    힌트 1

    \(f_x = -3x^2\), \(f_y = 2y\).

    힌트 2

    \(t = \frac yx\).

    풀이

    원점이 유일한 특이점(첨점). \(t \mapsto (t^2, t^3)\)은 \(\mathbb C\)에서 곡선으로 가는 전단사 정칙사상이고 원점 밖에서는 역사상 \(t = \frac yx\)가 정칙이다. 따라서 정규화는 \(\mathbb C\)(닫으면 \(\hat{\mathbb C}\), 종수 0) (0.5절).

  6. 판단"종수 2인 컴팩트 리만 곡면은 \(\mathbb P^2\)의 매끄러운 곡선으로 나타낼 수 있다"는 옳은가? [00-06]

    힌트 1

    \(\frac{(d - 1)(d - 2)}2 = 2\)인 정수 \(d\)?

    힌트 2

    값은 0, 0, 1, 3, 6, ….

    풀이

    틀리다. \(\frac{(d - 1)(d - 2)}2 = 2\)인 정수 \(d\)가 없다. 종수 2인 곡면은 \(y^2 = f(x)\) (\(\deg f = 5, 6\))처럼 특이점이 있는 평면 모형으로만 나타난다 (0.6절).
