다변수 멱급수와 라인하르트 영역

본문

변수가 하나인 멱급수는 언제나 원판에서 수렴했다. 변수가 둘인 멱급수 \(\sum c_{jk}z_1^jz_2^k\)는 어떤 모양의 영역에서 수렴할까? 늘 다원판일까, 아니면 다른 모양도 가능할까? 가능하다면 그 모양들에 공통된 성질은 무엇일까?

먼저 알아야 할 것다원판 코시 공식과 멱급수(1.1절), 등비급수와 근 판정법을 쓴다.

1.2.1수렴 영역의 대칭

멱급수 \(\sum_{j,k}c_{jk}z_1^jz_2^k\)가 절대수렴하는지는 \(|z_1|\)과 \(|z_2|\)에만 달려 있다. 그래서 점 \((z_1, z_2)\)에서 절대수렴하면 \((e^{i\theta_1}z_1, e^{i\theta_2}z_2)\)에서도 절대수렴한다. 이런 회전에 대해 불변인 영역을 라인하르트 영역이라 한다. 또 아벨 보조정리에 의해 \((w_1, w_2)\)에서 수렴하면 \(|z_1| \le |w_1|\), \(|z_2| \le |w_2|\)인 모든 점에서 수렴한다. 따라서 수렴 영역은 \((r_1, r_2) = (|z_1|, |z_2|)\) 평면에서 아래쪽으로 닫힌 영역으로 그릴 수 있다.

1.2.2예

예제 1.2.1

\(\sum z_1^jz_2^k\), \(\sum\binom{j + k}jz_1^jz_2^k\), \(\sum(z_1z_2)^m\)의 절대수렴 영역을 구하여라.

풀이. 먼저 \(\sum z_1^jz_2^k = \frac1{(1 - z_1)(1 - z_2)}\)은 \(r_1 < 1\), \(r_2 < 1\)인 정사각형, 곧 다원판에서 수렴한다. 다음으로 \(\sum_m(z_1 + z_2)^m\)을 펼친 급수 \(\sum\binom{j + k}jz_1^jz_2^k\)는 절대값을 넣으면 \(\sum(r_1 + r_2)^m\)이므로, 절대수렴 영역은 \(r_1 + r_2 < 1\)인 삼각형이다. 끝으로 \(\sum_m(z_1z_2)^m\)은 \(r_1r_2 < 1\)이라 쌍곡선 아래의 무한 영역이다.

세 영역 모두 \((\log r_1, \log r_2)\) 평면으로 옮기면 볼록이다. 정사각형은 사분면, 삼각형은 \(e^{u} + e^{v} < 1\)인 볼록 영역, 쌍곡선 아래는 반평면 \(u + v < 0\)이 된다. 일반적으로 멱급수의 수렴 영역은 로그 볼록인 라인하르트 영역이고, 거꾸로 로그 볼록인 완전 라인하르트 영역은 어떤 멱급수의 수렴 영역이다. 같은 절의 예제 카드에서 수렴 영역을 직접 구해 본다.

1.2.31변수와의 차이

1변수에서 수렴 영역은 늘 원판이고, 그 경계 어딘가에 반드시 특이점이 있다. 반면 다변수에서는 수렴 영역의 모양이 다양하고, 이 모양 자체가 정칙함수가 자연스럽게 사는 영역인 정칙 영역을 결정한다. 실제로 로그 볼록이 아닌 라인하르트 영역에서 정칙인 함수는 모두 더 큰 로그 볼록 영역으로 연장된다. 이것이 다음 절에서 볼 하르톡스 현상의 한 모습이다.

흔한 오해다변수 멱급수의 수렴 영역이 늘 다원판이라고 여기기 쉽지만, 그림 1처럼 삼각형이나 쌍곡선 아래 등 다양한 모양이 있다. 또 급수를 묶는 순서가 수렴에 영향을 주지 않는다고 생각하는 것도 틀렸다. \(\sum(z_1 + z_2)^m\)은 묶은 채로는 \(|z_1 + z_2| < 1\)에서 수렴하지만, 펼친 급수의 절대수렴 영역은 \(|z_1| + |z_2| < 1\)이다.
마무리

처음 질문에 답하면, 두 변수 멱급수의 수렴 영역은 늘 다원판인 것은 아니며, 정사각형, 삼각형, 쌍곡선 아래처럼 다양한 모양이 가능하다. 그래도 절대수렴이 \(|z_1|, |z_2|\)에만 달려 있어 수렴 영역은 회전에 불변인 라인하르트 영역이다. 게다가 로그 좌표로 옮기면 늘 볼록이며, 이 로그 볼록성이 정칙함수가 사는 영역의 모양을 결정한다.

1.2.4연습문제

기본

  1. \(\sum_{j,k}\frac{z_1^jz_2^k}{2^j3^k}\)의 수렴 영역을 구하여라.
    답

    \(|z_1| < 2\), \(|z_2| < 3\)인 다원판.

응용

  1. \(\sum_mz_1^mz_2^{2m}\)의 수렴 영역을 \((r_1, r_2)\) 평면과 \((\log r_1, \log r_2)\) 평면에 나타내어라.
    답

    \(r_1r_2^2 < 1\). 로그 평면에서는 반평면 \(u + 2v < 0\)으로 볼록이다.

심화

  1. 영역 \(\{r_1 < 1, r_2 < 1\}\cup\{r_1 < 2, r_2 < \frac12\}\)(두 다원판의 합)이 로그 볼록이 아님을 보여라.
    답

    로그 평면에서 \((0, 0)\) 근처와 \((\log2, \log\frac12)\) 근처의 점을 잇는 선분의 가운데 \((\frac{\log2}2, -\frac{\log2}2)\), 즉 \(r_1 = \sqrt2\), \(r_2 = \frac1{\sqrt2}\)는 어느 다원판에도 없다. 이 영역의 정칙함수는 로그 볼록 껍질로 연장된다.
