다변수 멱급수와 라인하르트 영역

본문
이 절에서 배울 것
  • 다변수 멱급수 \(\sum c_{jk}z_1^jz_2^k\)의 수렴 영역이 \((z_1, z_2) \mapsto (e^{i\theta_1}z_1, e^{i\theta_2}z_2)\)에 대해 불변인 라인하르트 영역임을 안다.
  • 수렴 영역을 \((|z_1|, |z_2|)\)의 평면에 그리고, \((\log|z_1|, \log|z_2|)\)로 보면 볼록 집합이 됨을 예로 확인한다.
  • 1변수의 "수렴 원판"이 다변수에서는 다양한 모양이 될 수 있음을 이해한다.
먼저 알아야 할 것
  • 다원판 코시 공식과 멱급수 (1.1절), 등비급수와 근 판정법.

1.2.1수렴 영역의 대칭

멱급수 \(\sum_{j,k}c_{jk}z_1^jz_2^k\)는 절대수렴 여부가 \(|z_1|, |z_2|\)에만 달려 있습니다. 그래서 점 \((z_1, z_2)\)에서 절대수렴하면 \((e^{i\theta_1}z_1, e^{i\theta_2}z_2)\)에서도 절대수렴합니다. 이런 회전에 대해 불변인 영역을 라인하르트 영역이라 합니다. 또 \((w_1, w_2)\)에서 수렴하면 \(|z_1| \le |w_1|\), \(|z_2| \le |w_2|\)인 모든 점에서 수렴합니다(아벨 보조정리). 따라서 수렴 영역은 \((r_1, r_2) = (|z_1|, |z_2|)\)의 평면 위 "아래로 닫힌" 영역으로 그릴 수 있습니다.

1.2.2예

예 1.2.1
  • \(\sum z_1^jz_2^k = \frac1{(1 - z_1)(1 - z_2)}\): \(r_1 < 1\), \(r_2 < 1\)인 정사각형(다원판).
  • \(\sum_m(z_1 + z_2)^m\)을 펼친 급수 \(\sum\binom{j + k}jz_1^jz_2^k\): 절대수렴 영역은 \(r_1 + r_2 < 1\)인 삼각형.
  • \(\sum_m(z_1z_2)^m\): \(r_1r_2 < 1\)로 쌍곡선 아래의 무한 영역.

세 영역 모두 \((\log r_1, \log r_2)\)의 평면으로 옮기면 볼록입니다(정사각형은 사분면, 삼각형은 \(e^{u} + e^{v} < 1\)의 볼록 영역, 쌍곡선은 반평면 \(u + v < 0\)). 일반적으로 멱급수의 수렴 영역은 로그 볼록 라인하르트 영역이고, 반대로 로그 볼록인 완전 라인하르트 영역은 어떤 멱급수의 수렴 영역입니다. 같은 절의 예제 카드에서 수렴 영역을 직접 구합니다.

1.2.31변수와의 차이

1변수에서 수렴 영역은 늘 원판이고 경계 어딘가에 반드시 특이점이 있습니다. 다변수에서는 수렴 영역의 모양이 다양하고, 이 모양 자체가 "정칙함수가 자연스럽게 사는 영역"(정칙 영역)을 결정합니다. 로그 볼록이 아닌 라인하르트 영역에서 정칙인 함수는 모두 더 큰 로그 볼록 영역으로 연장됩니다. 이것이 다음 절의 하르톡스 현상의 한 모습입니다.

흔한 오해(1) 다변수 멱급수의 수렴 영역이 항상 다원판이라고 여긴다. 삼각형, 쌍곡선 꼴 등 다양하다. (2) 급수를 묶는 순서가 수렴에 영향이 없다고 여긴다. \(\sum(z_1 + z_2)^m\)은 묶은 채로는 \(|z_1 + z_2| < 1\)에서 수렴하지만, 펼친 절대수렴 영역은 \(|z_1| + |z_2| < 1\)이다.
요약
  1. 멱급수의 수렴 영역은 회전 불변(라인하르트)이고 \((|z_1|, |z_2|)\) 평면에 그린다.
  2. 예: 정사각형, 삼각형 \(r_1 + r_2 < 1\), 쌍곡선 \(r_1r_2 < 1\).
  3. 수렴 영역은 로그 볼록이다.

1.2.4연습문제

기본

  1. \(\sum_{j,k}\frac{z_1^jz_2^k}{2^j3^k}\)의 수렴 영역을 구하여라.
    답

    \(|z_1| < 2\), \(|z_2| < 3\)인 다원판.

응용

  1. \(\sum_mz_1^mz_2^{2m}\)의 수렴 영역을 \((r_1, r_2)\) 평면과 \((\log r_1, \log r_2)\) 평면에 나타내어라.
    답

    \(r_1r_2^2 < 1\). 로그 평면에서는 반평면 \(u + 2v < 0\)으로 볼록이다.

심화

  1. 영역 \(\{r_1 < 1, r_2 < 1\}\cup\{r_1 < 2, r_2 < \frac12\}\)(두 다원판의 합)이 로그 볼록이 아님을 보여라.
    답

    로그 평면에서 \((0, 0)\) 근처와 \((\log2, \log\frac12)\) 근처의 점을 잇는 선분의 가운데 \((\frac{\log2}2, -\frac{\log2}2)\), 즉 \(r_1 = \sqrt2\), \(r_2 = \frac1{\sqrt2}\)는 어느 다원판에도 없다. 이 영역의 정칙함수는 로그 볼록 껍질로 연장된다.
