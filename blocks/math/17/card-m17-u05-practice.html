호지 이론 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(\mathbb C\)에서 \(h = (1 + |z|^2)\,dz\otimes d\bar z\)의 기본 형식을 쓰고 케일러인지 판정하여라. [05-01]

    힌트 1

    \(\omega = \frac i2(1 + |z|^2)dz\wedge d\bar z\).

    힌트 2

    실 2차원.

    풀이

    \(\omega = \frac i2(1 + |z|^2)dz\wedge d\bar z\). 1차원 복소다양체에서 \(d\omega\)는 3-형식이라 0이므로 케일러이다 (5.1절).

  2. 증명케일러 형식 \(\omega\)에 대해 컴팩트 \(n\)차원 케일러 다양체에서 \([\omega]^n \ne 0\)이고, 따라서 \(b_2 \ge 1\)임을 보여라. [05-01]

    힌트 1

    \(\frac{\omega^n}{n!}\)은 부피 형식.

    힌트 2

    완전 형식의 적분은 0.

    풀이

    \(\int_X\omega^n = n!\,\mathrm{vol}(X) > 0\)이다. \([\omega] = 0\)이면 \(\omega = d\eta\)이고 \(\omega^n = d(\eta\wedge\omega^{n-1})\)이라 적분이 0이어야 하므로 모순. 따라서 \([\omega] \ne 0\), \(b_2 \ge 1\). ∎

  3. 판단"\(S^1\times S^3\)는 복소다양체 구조를 가지므로(호프 곡면) 케일러 계량도 가질 수 있다"는 옳은가? [05-02]

    힌트 1

    \(b_1(S^1\times S^3)\)?

    힌트 2

    또는 \(b_2\).

    풀이

    틀리다. \(b_1 = 1\)(홀수)이고 \(b_2 = 0\)이라 케일러일 수 없다(호지 분해, 위 문제 2) (5.2절).

  4. 계산종수 2인 곡선 \(C\)와 \(\mathbb P^1\)의 곱 곡면 \(C\times\mathbb P^1\)의 호지 다이아몬드를 퀴네트 공식으로 구하여라. [05-03]

    힌트 1

    \(C\): \(h^{0,0} = h^{1,1} = 1\), \(h^{1,0} = h^{0,1} = 2\).

    힌트 2

    \(h^{p,q}(C\times\mathbb P^1) = \sum h^{a,b}(C)h^{c,d}(\mathbb P^1)\) (\(a + c = p\), \(b + d = q\)).

    풀이

    위부터 \(1;\ 2, 2;\ 0, 2, 0;\ 2, 2;\ 1\). 즉 \(h^{1,0} = h^{0,1} = 2\), \(h^{1,1} = 2\), \(h^{2,0} = 0\), \(h^{2,1} = h^{1,2} = 2\). 베티 수 \(1, 4, 2, 4, 1\), 오일러 지표 \(-4 = (-2)\cdot2\) (5.3절).

  5. 계산\(\mathbb P^3\)에서 직선 \(L\)과 평면 \(H\)의 류는 각각 \(H^4\), \(H^2\)의 생성원이다. 곡선 \(C\)가 일반적인 평면과 5점에서 만나면 \([C]\)는? [05-04]

    힌트 1

    \(\int_X[C]\wedge[H] = \#(C\cap H)\).

    힌트 2

    \(\int[L]\wedge[H] = 1\).

    풀이

    \([C] = 5[L]\). 곡선의 류는 차수(평면과의 교점 수)로 정해진다 (5.4절).

  6. 판단"호지 추측은 모든 컴팩트 케일러 다양체에서 성립할 것으로 예상된다"는 옳은가? [05-04]

    힌트 1

    사영이 아닌 케일러 다양체.

    힌트 2

    부아쟁의 반례.

    풀이

    틀리다. 추측은 사영 다양체에 대한 것이다. 사영이 아닌 케일러 다양체(예: 일반적인 복소 토러스)에서는 부분다양체가 거의 없어 호지 류가 대수적이 아닌 반례가 있다.
