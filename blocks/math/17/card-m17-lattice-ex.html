두 격자가 같은 토러스를 주는가

예제 · 기본 영역으로 옮기기

먼저 예측

격자 \(\langle1, 2 + i\rangle\)과 \(\langle1, i\rangle\)은 모양이 달라 보입니다. 같은 복소 토러스를 줄까요?

예측 확인

줍니다. \(2 + i\)에서 1을 두 번 빼면 \(i\)이고, 같은 격자의 다른 기저일 뿐입니다.

\(\tau_1 = \frac{2 + i}{5}\), \(\tau_2 = 2 + i\), \(\tau_3 = 2i\)에 대해, \(SL_2(\mathbb Z)\) 작용으로 각 \(\tau\)를 기본 영역 \(F = \{|\operatorname{Re}\tau| \le \frac12,\ |\tau| \ge 1\}\)으로 옮겨 어느 것끼리 같은 토러스인지 판정하여라.

전략

\(\tau \mapsto \tau + n\)으로 실수부를 \([-\frac12, \frac12]\)에 넣고, \(|\tau| < 1\)이면 \(\tau \mapsto -\frac1\tau\)로 바깥으로 보내기를 반복합니다. 기본 영역 안의 점(경계 일부의 동일시를 빼면)이 같으면 같은 토러스입니다(2.2절).

풀이

  1. \(\tau_2 = 2 + i \mapsto 2 + i - 2 = i\). \(|i| = 1\)이라 기본 영역 안.
    평행이동 \(\begin{pmatrix}1 & -2\\ 0 & 1\end{pmatrix}\).
  2. \(\tau_1 = \frac{2 + i}5 = 0.4 + 0.2i\), \(|\tau_1|^2 = 0.2 < 1\). \(-\frac1{\tau_1} = -\frac{5}{2 + i} = -\frac{5(2 - i)}5 = -2 + i\).
    \(\begin{pmatrix}0 & -1\\ 1 & 0\end{pmatrix}\).
  3. \(-2 + i \mapsto -2 + i + 2 = i\). 기본 영역 안.
    다시 평행이동.
  4. \(\tau_3 = 2i\)는 이미 기본 영역 안(\(\operatorname{Re} = 0\), \(|2i| = 2\))이고 \(i\)와 다르다.
    기본 영역 내부의 서로 다른 점은 다른 토러스.

검산

\(\tau_1\)과 \(\tau_2\)는 모두 \(i\)로 가므로 정사각형 격자 토러스와 동형입니다. 직접 보면 \(\langle1, \frac{2 + i}5\rangle\)에 \(2 - i\)를 곱하면 \(\langle2 - i, 1\rangle\)이고, 이는 \(\langle1, i\rangle\)과 같은 격자입니다(\(2 - i\)와 1로 \(i\)를 만들 수 있음).

의미

기본 영역은 "토러스의 복소 구조 전체를 한 번씩만 나열한 목록"입니다. 위 계산은 유클리드 호제법과 같은 구조로, 언제나 유한 번에 끝납니다.

이해 확인

\(\tau = \frac12 + \frac i2\)는 어느 \(\tau\)와 같은 토러스인가요?

답

\(|\tau|^2 = \frac12 < 1\)이라 \(-\frac1\tau = -\frac{2}{1 + i} = -1 + i\), 평행이동하면 \(i\)입니다. 정사각형 격자입니다.
