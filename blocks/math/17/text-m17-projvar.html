사영 다양체와 아핀 조각

본문
이 절에서 배울 것
  • 동차 다항식의 공통 영점으로 \(\mathbb P^n\)의 사영 대수적 집합과 사영 다양체를 정의한다.
  • 사영 다양체를 아핀 조각 \(U_i\)로 제한하면 아핀 다양체가 되고, 반대로 아핀 다양체를 동차화해 사영 폐포를 얻는 과정을 이해한다.
  • 사영 다양체가 컴팩트이고, 사영 곡선끼리는 반드시 만난다는 사실(베주 정리)을 예로 확인한다.
먼저 알아야 할 것
  • 아핀 다양체 (3.1절), 복소사영공간과 \(\mathcal O(d)\) (2.1절, 2.3절).

3.2.1사영 대수적 집합

\(d\)차 동차 다항식 \(F\)는 \(F(\lambda z) = \lambda^dF(z)\)이므로 값은 정해지지 않지만 "\(F([z]) = 0\)인가"는 잘 정해집니다. 동차 다항식들의 집합 \(S\)에 대해 \(V(S) = \{[z] \in \mathbb P^n : F(z) = 0\ \forall F \in S\}\)를 사영 대수적 집합, 기약인 것을 사영 다양체라 합니다. \(\mathbb P^n\)이 컴팩트이고 \(V(S)\)는 닫힌집합이므로 사영 다양체는 컴팩트입니다.

3.2.2아핀 조각과 사영 폐포

  • 제한: \(X = V(F_1, \dots, F_k) \subset \mathbb P^n\)을 \(U_0 = \{z_0 \ne 0\} \cong \mathbb C^n\)에 제한하면 \(z_0 = 1\)로 놓은 \(f_j(x) = F_j(1, x_1, \dots, x_n)\)의 영점 집합, 즉 아핀 대수적 집합이다.
  • 동차화: 아핀 다항식 \(f\) (차수 \(d\))에 대해 \(F = z_0^df\left(\frac{z_1}{z_0}, \dots\right)\). 아핀 다양체 \(Y\)의 사영 폐포 \(\bar Y\)는 \(Y\)의 이데알의 모든 원소를 동차화해 얻은 사영 다양체이고, \(\bar Y\setminus Y\)는 무한 초평면 \(\{z_0 = 0\}\) 위의 점들이다.
예 3.2.1 아핀 쌍곡선 \(xy = 1\)의 사영 폐포는 \(XY = Z^2\)입니다. \(Z = 0\)이면 \(XY = 0\)이라 무한원점 \([1 : 0 : 0]\), \([0 : 1 : 0]\)이 더해지고, 이는 두 점근선 방향입니다. 포물선 \(y = x^2\)의 폐포 \(YZ = X^2\)는 무한원점이 \([0 : 1 : 0]\) 하나입니다. 사영평면에서는 쌍곡선, 포물선, 타원이 모두 같은 원뿔곡선 \(\cong \mathbb P^1\)이고, 무한 직선과 만나는 방식만 다릅니다.

3.2.3베주 정리

\(\mathbb P^2\)의 차수 \(d, e\)인 두 곡선이 공통 성분이 없으면 교점은 중복도를 세어 정확히 \(de\)개입니다. 아핀 평면에서는 평행한 두 직선이 만나지 않지만 사영평면에서는 무한원점에서 만나 "직선 두 개는 늘 한 점에서 만난다"가 됩니다. 같은 절의 예제 카드에서 원과 직선, 두 원의 교점을 세어 봅니다.

흔한 오해(1) 사영 폐포를 구할 때 생성원만 동차화하면 된다고 여긴다. 일반적으로 이데알 전체를 동차화해야 하고(예: 꼬인 삼차 곡선), 생성원만 하면 무한원에 성분이 더 붙을 수 있다. (2) 동차 다항식이 아닌 것도 사영 집합을 정의한다고 여긴다. \(z_0 + z_1^2\)은 \(\lambda\)배에 따라 영점 여부가 바뀐다.
요약
  1. 사영 다양체: 동차 다항식들의 영점, 컴팩트.
  2. \(U_0\)에 제한하면 \(z_0 = 1\)로 아핀, 동차화로 사영 폐포.
  3. 베주: \(\mathbb P^2\)의 차수 \(d, e\) 곡선은 \(de\)개의 점에서 만난다.

3.2.4연습문제

기본

  1. 직선 \(y = 2x + 1\)의 사영 폐포와 무한원점을 구하여라.
    답

    \(Y = 2X + Z\), 무한원점 \([1 : 2 : 0]\)(기울기 2의 방향).

응용

  1. 평행한 두 직선 \(y = 2x\)와 \(y = 2x + 1\)이 \(\mathbb P^2\)에서 만나는 점은?
    답

    \(Y = 2X\)와 \(Y = 2X + Z\)에서 \(Z = 0\), 교점 \([1 : 2 : 0]\).

심화

  1. 원 \(x^2 + y^2 = 1\)과 \(x^2 + y^2 = 4\)는 아핀 평면에서 만나지 않는다. 베주 정리의 4개 교점은 어디에 있는가?
    답

    동차화 \(X^2 + Y^2 = Z^2\), \(X^2 + Y^2 = 4Z^2\)에서 \(Z = 0\), \(X^2 + Y^2 = 0\)이라 원형점 \([1 : \pm i : 0]\) 두 곳에서 각각 중복도 2로 만나 합 4개이다.
