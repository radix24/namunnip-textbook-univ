케일러 다양체

본문

복소다양체에 길이와 넓이를 재는 계량을 주면 리만 기하를 할 수 있다. 그런데 복소 구조와 계량이 서로 잘 맞물리는 특별한 경우가 있다고 한다. 맞물린다는 것은 정확히 어떤 조건이고, 어떤 다양체가 그 조건을 만족할까?

먼저 알아야 할 것\((p, q)\)-형식과 \(\partial, \bar\partial\)(4.4절), 리만 계량(수학13), 복소사영공간(2.1절)을 쓴다.

5.1.1에르미트 계량과 기본 형식

복소다양체의 각 접공간에 양의 정부호 에르미트 내적 \(h = \sum h_{j\bar k}dz_j\otimes d\bar z_k\) (\(h_{j\bar k} = \overline{h_{k\bar j}}\))를 매끄럽게 주면 이것을 에르미트 계량이라 한다. 그 실수부는 리만 계량 \(g\)이고, 허수부에서 다음 실 \((1, 1)\)-형식을 얻는다.

\[\omega = \frac i2\sum_{j,k}h_{j\bar k}\,dz_j\wedge d\bar z_k\]

이것을 기본 형식이라 한다. 예를 들어 \(\mathbb C\)의 표준 계량 \(h = dz\otimes d\bar z\)이면 \(\omega = \frac i2dz\wedge d\bar z = dx\wedge dy\)로 넓이 형식이다.

5.1.2케일러 조건

정의 5.1.1

기본 형식이 \(d\omega = 0\)을 만족하는 에르미트 계량을 케일러 계량이라 하고, 케일러 계량을 가진 복소다양체를 케일러 다양체라 한다.

케일러 조건은 국소적으로 \(\omega = \frac i2\partial\bar\partial\phi\)인 실함수 \(\phi\), 곧 케일러 퍼텐셜이 있다는 것과 동치이다. 또 각 점에서 정칙 좌표를 잘 골라 계량이 2차까지 표준 계량과 같게 할 수 있다는 것과도 동치이다. 곧 복소 구조와 리만 기하가 잘 맞물린다는 조건이다.

예제 5.1.2

\(\mathbb C^n\), 복소 토러스, 리만 곡면이 케일러임을 보여라.

풀이. \(\mathbb C^n\)에서 \(\omega = \frac i2\sum dz_j\wedge d\bar z_j\)는 계수가 상수라 \(d\omega = 0\)이고, 퍼텐셜은 \(\phi = |z|^2\)이다. 복소 토러스 \(\mathbb C^n/\Lambda\)에서는 이 형식이 평행이동에 불변이라 토러스로 내려와 케일러 계량이 된다. 리만 곡면에서는 \(\omega\)가 2-형식이고 실 2차원에서 3-형식 \(d\omega\)는 저절로 0이므로, 모든 리만 곡면은 케일러이다.

5.1.3푸비니-스터디 계량

\(\mathbb P^n\)에서 \(\omega_{FS} = \frac i2\partial\bar\partial\log(|z_0|^2 + \cdots + |z_n|^2)\)을 생각하자. \(z\)를 \(\lambda z\)로 바꾸면 \(\log|z|^2\)에 \(\log|\lambda|^2\)이 더해지는데, \(\partial\bar\partial\log|\lambda|^2 = 0\)이므로 \(\omega_{FS}\)는 \(\mathbb P^n\) 위에서 잘 정의된다. 또 \(d = \partial + \bar\partial\)이고 \(\partial^2 = \bar\partial^2 = 0\), \(\partial\bar\partial = -\bar\partial\partial\)이므로 \(d(\partial\bar\partial\phi) = 0\)이라 닫혀 있다. 양의 정부호임은 아핀 조각에서 \(\phi = \log(1 + |w|^2)\)로 계산해 확인할 수 있다.

정리 5.1.3

\(\mathbb P^n\)은 푸비니-스터디 계량으로 케일러이다. 케일러 다양체의 복소 부분다양체는 제한한 계량으로 케일러이므로, 모든 매끄러운 사영 다양체는 케일러이다.

\(n = 1\)이면 \(\omega_{FS} = \frac i2\frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\)이고, 그림 1처럼 전체 넓이가 \(\pi\)이다. 이것은 반지름 \(\frac12\)인 구면의 표준 계량과 같다.

흔한 오해모든 복소다양체가 케일러라고 여기기 쉽지만, 호프 곡면 \((\mathbb C^2\setminus0)/(z \sim 2z)\)는 \(b_1 = 1\)로 홀수라서 5.2절에 따라 케일러가 아니다. 또 케일러 조건을 계량의 곡률에 대한 조건으로 생각하는 것도 틀렸다. 이것은 \(d\omega = 0\)이라는 1계 조건이다.
마무리

처음 질문에 답하면, 복소 구조와 계량이 맞물린다는 것은 에르미트 계량의 기본 형식 \(\omega\)가 닫혀 있다는 케일러 조건 \(d\omega = 0\)이다. 이것은 국소적으로 \(\omega = \frac i2\partial\bar\partial\phi\)인 퍼텐셜이 있다는 것과 같다. \(\mathbb C^n\), 복소 토러스, 모든 리만 곡면이 케일러이고, \(\mathbb P^n\)은 푸비니-스터디 계량으로 케일러이므로 모든 매끄러운 사영 다양체도 케일러이다.

5.1.4연습문제

기본

  1. \(\phi = |z|^2\)이면 \(\frac i2\partial\bar\partial\phi = \frac i2dz\wedge d\bar z\)임을 확인하여라.
    답

    \(\bar\partial(z\bar z) = z\,d\bar z\), \(\partial(z\,d\bar z) = dz\wedge d\bar z\).

응용

  1. \(\mathbb P^1\)의 아핀 조각에서 \(\phi = \log(1 + |w|^2)\)에 대해 \(\partial\bar\partial\phi = \frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\)임을 보여라.
    답

    \(\bar\partial\phi = \frac{w\,d\bar w}{1 + |w|^2}\), \(\partial\)를 취하면 \(\frac{(1 + |w|^2) - w\bar w}{(1 + |w|^2)^2}dw\wedge d\bar w = \frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\).

심화

  1. \(\mathbb P^1\)의 푸비니-스터디 넓이 \(\int\frac{dx\,dy}{(1 + x^2 + y^2)^2}\)가 \(\pi\)임을 극좌표로 계산하여라.
    답

    \(\int_0^{2\pi}\int_0^\infty\frac{r\,dr}{(1 + r^2)^2}d\theta = 2\pi\cdot\frac12 = \pi\).
