케일러 다양체

본문
이 절에서 배울 것
  • 에르미트 계량 \(h\)와 그 기본 형식 \(\omega = \frac i2\sum h_{j\bar k}dz_j\wedge d\bar z_k\)를 정의한다.
  • \(d\omega = 0\)인 에르미트 계량을 케일러 계량이라 하고, \(\mathbb C^n\), 토러스, 리만 곡면이 케일러임을 확인한다.
  • \(\mathbb P^n\)의 푸비니-스터디 형식 \(\omega = \frac i2\partial\bar\partial\log|z|^2\)이 케일러임을 보이고, 그래서 모든 사영 다양체가 케일러임을 안다.
먼저 알아야 할 것
  • \((p, q)\)-형식과 \(\partial, \bar\partial\) (4.4절), 리만 계량 (수학13), 복소사영공간 (2.1절).

5.1.1에르미트 계량과 기본 형식

복소다양체의 각 접공간에 양의 정부호 에르미트 내적 \(h = \sum h_{j\bar k}dz_j\otimes d\bar z_k\) (\(h_{j\bar k} = \overline{h_{k\bar j}}\))을 매끄럽게 주면 에르미트 계량입니다. 실수부는 리만 계량 \(g\)이고, 허수부에서 실 \((1, 1)\)-형식

\[\omega = \frac i2\sum_{j,k}h_{j\bar k}\,dz_j\wedge d\bar z_k\]

를 얻습니다(기본 형식). \(\mathbb C\)의 표준 계량 \(h = dz\otimes d\bar z\)이면 \(\omega = \frac i2dz\wedge d\bar z = dx\wedge dy\)로 넓이 형식입니다.

5.1.2케일러 조건

정의 5.1.1 \(d\omega = 0\)인 에르미트 계량을 케일러 계량, 이를 가진 복소다양체를 케일러 다양체라 한다.

케일러 조건은 국소적으로 \(\omega = \frac i2\partial\bar\partial\phi\)인 실함수 \(\phi\)(케일러 퍼텐셜)가 있다는 것, 또는 각 점에서 정칙 좌표를 잘 골라 계량이 2차까지 표준 계량과 같게 할 수 있다는 것과 동치입니다. 복소 구조와 리만 기하가 잘 맞물린다는 조건입니다.

예 5.1.2
  • \(\mathbb C^n\): \(\omega = \frac i2\sum dz_j\wedge d\bar z_j\), 계수가 상수라 \(d\omega = 0\). 퍼텐셜 \(\phi = |z|^2\).
  • 복소 토러스 \(\mathbb C^n/\Lambda\): 위 형식이 평행이동 불변이라 내려와 케일러.
  • 리만 곡면: \(\omega\)는 2-형식이고 실 2차원에서 \(d\omega\)는 3-형식이라 자동으로 0. 모든 리만 곡면은 케일러.

5.1.3푸비니-스터디 계량

\(\mathbb P^n\)에서 \(\omega_{FS} = \frac i2\partial\bar\partial\log(|z_0|^2 + \cdots + |z_n|^2)\)를 생각합니다. \(z\)를 \(\lambda z\)로 바꾸면 \(\log|z|^2\)에 \(\log|\lambda|^2\)이 더해지는데 \(\partial\bar\partial\log|\lambda|^2 = 0\)이라 \(\omega_{FS}\)는 \(\mathbb P^n\) 위에서 잘 정의됩니다. \(d = \partial + \bar\partial\)이고 \(\partial^2 = \bar\partial^2 = 0\), \(\partial\bar\partial = -\bar\partial\partial\)이므로 \(d(\partial\bar\partial\phi) = 0\)이라 닫혀 있고, 양의 정부호임을 계산으로 확인할 수 있습니다(아핀 조각에서 \(\phi = \log(1 + |w|^2)\)).

정리 5.1.3 \(\mathbb P^n\)은 푸비니-스터디 계량으로 케일러이다. 케일러 다양체의 복소 부분다양체는 제한한 계량으로 케일러이므로, 모든 매끄러운 사영 다양체는 케일러이다.

\(n = 1\)이면 \(\omega_{FS} = \frac i2\frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\)이고 전체 넓이는 \(\pi\)로, 반지름 \(\frac12\)인 구면의 표준 계량과 같습니다.

흔한 오해(1) 모든 복소다양체가 케일러라고 여긴다. 호프 곡면 \((\mathbb C^2\setminus0)/(z \sim 2z)\)는 \(b_1 = 1\)(홀수)이라 케일러가 아니다(5.2절). (2) 케일러 조건이 계량의 곡률 조건이라고 여긴다. \(d\omega = 0\)이라는 1계 조건이다.
요약
  1. 에르미트 계량 → 기본 형식 \(\omega = \frac i2\sum h_{j\bar k}dz_j\wedge d\bar z_k\).
  2. 케일러: \(d\omega = 0\). \(\mathbb C^n\), 토러스, 모든 리만 곡면.
  3. 푸비니-스터디 \(\frac i2\partial\bar\partial\log|z|^2\)로 \(\mathbb P^n\)과 모든 사영 다양체가 케일러.

5.1.4연습문제

기본

  1. \(\phi = |z|^2\)이면 \(\frac i2\partial\bar\partial\phi = \frac i2dz\wedge d\bar z\)임을 확인하여라.
    답

    \(\bar\partial(z\bar z) = z\,d\bar z\), \(\partial(z\,d\bar z) = dz\wedge d\bar z\).

응용

  1. \(\mathbb P^1\)의 아핀 조각에서 \(\phi = \log(1 + |w|^2)\)에 대해 \(\partial\bar\partial\phi = \frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\)임을 보여라.
    답

    \(\bar\partial\phi = \frac{w\,d\bar w}{1 + |w|^2}\), \(\partial\)를 취하면 \(\frac{(1 + |w|^2) - w\bar w}{(1 + |w|^2)^2}dw\wedge d\bar w = \frac{dw\wedge d\bar w}{(1 + |w|^2)^2}\).

심화

  1. \(\mathbb P^1\)의 푸비니-스터디 넓이 \(\int\frac{dx\,dy}{(1 + x^2 + y^2)^2}\)가 \(\pi\)임을 극좌표로 계산하여라.
    답

    \(\int_0^{2\pi}\int_0^\infty\frac{r\,dr}{(1 + r^2)^2}d\theta = 2\pi\cdot\frac12 = \pi\).
