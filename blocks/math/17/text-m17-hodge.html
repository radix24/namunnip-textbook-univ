조화형식과 호지 분해

본문
이 절에서 배울 것
  • 라플라스 연산자 \(\Delta = dd^* + d^*d\)의 핵인 조화형식이 각 드람 코호몰로지 류의 유일한 대표임(호지 정리)을 안다.
  • 컴팩트 케일러 다양체에서 \(H^k(X, \mathbb C) = \bigoplus_{p+q=k}H^{p,q}\), \(\overline{H^{p,q}} = H^{q,p}\)(호지 분해)를 진술한다.
  • 그 결과로 홀수 베티 수가 짝수임을 보이고, 리만 곡면에서 \(b_1 = 2g\)를 해석한다.
먼저 알아야 할 것
  • 드람과 돌보 코호몰로지 (4.3절, 4.4절), 케일러 다양체 (5.1절).

5.2.1조화형식

컴팩트 리만 다양체에서는 형식들 사이에 내적 \((\alpha, \beta) = \int\langle\alpha, \beta\rangle\,dV\)이 있고, \(d\)의 수반 \(d^*\)를 정의할 수 있습니다. 라플라스 연산자 \(\Delta = dd^* + d^*d\)에 대해 \(\Delta\alpha = 0\)인 형식을 조화형식이라 합니다. \((\Delta\alpha, \alpha) = \|d\alpha\|^2 + \|d^*\alpha\|^2\)이므로 조화 ⟺ \(d\alpha = 0\)이고 \(d^*\alpha = 0\)입니다.

정리 5.2.1 (호지) 컴팩트 리만 다양체 \(M\)에서 모든 드람 코호몰로지 류에는 조화형식 대표가 꼭 하나 있다. 즉 \(H^k_{dR}(M) \cong \mathcal H^k\) (조화 \(k\)-형식의 공간).

각 류에서 노름이 가장 작은 대표가 조화형식입니다. 예를 들어 평평한 토러스 \(\mathbb R^2/\mathbb Z^2\)에서 \(dx\), \(dy\)가 \(H^1\)의 조화 대표입니다.

5.2.2호지 분해

케일러 다양체에서는 \(\Delta_d = 2\Delta_{\bar\partial}\)이 성립해, 조화형식의 \((p, q)\) 성분이 각각 조화입니다. 그 결과

정리 5.2.2 (호지 분해) \(X\)가 컴팩트 케일러 다양체이면 \[H^k(X, \mathbb C) = \bigoplus_{p+q=k}H^{p,q}(X), \qquad \overline{H^{p,q}} = H^{q,p}.\] \(h^{p,q} = \dim H^{p,q}\)(호지 수)라 하면 \(b_k = \sum_{p+q=k}h^{p,q}\), \(h^{p,q} = h^{q,p}\).

여기서 \(H^{p,q}\)는 돌보 코호몰로지이고, 정리 4.4.2로 \(\check H^q(X, \Omega^p)\)와 같습니다.

5.2.3결과

  • 홀수 베티 수는 짝수: \(b_{2m+1} = \sum_{p+q=2m+1}h^{p,q}\)에서 \(h^{p,q} = h^{q,p}\)이고 \(p \ne q\)라 항이 짝지어진다. 호프 곡면은 \(b_1 = 1\)이라 케일러가 아니다.
  • 리만 곡면: \(b_1 = h^{1,0} + h^{0,1} = 2g\)이므로 \(h^{1,0} = g\). 즉 종수는 정칙 1-형식 공간의 차원이다. 토러스의 \(dz\)가 그 예이다.
  • 사영공간: \(h^{p,p}(\mathbb P^n) = 1\) (\(0 \le p \le n\)), 나머지 0. \(\omega_{FS}^p\)가 \(H^{p,p}\)를 생성한다.
흔한 오해(1) 호지 분해가 모든 컴팩트 복소다양체에서 성립한다고 여긴다. 케일러 조건이 필요하다. (2) 조화형식이 닫힌 형식과 같다고 여긴다. 조화는 \(d\alpha = 0\)과 \(d^*\alpha = 0\)을 모두 요구하며, 각 류에서 하나뿐이다.
요약
  1. 호지 정리: 각 코호몰로지 류에 유일한 조화 대표.
  2. 케일러: \(H^k = \bigoplus_{p+q=k}H^{p,q}\), \(h^{p,q} = h^{q,p}\).
  3. 홀수 베티 수는 짝수, 리만 곡면에서 \(h^{1,0} = g\).

5.2.4연습문제

기본

  1. 종수 3인 리만 곡면의 \(h^{0,0}, h^{1,0}, h^{0,1}, h^{1,1}\)을 구하여라.
    답

    \(1, 3, 3, 1\). \(b_0 = 1\), \(b_1 = 6\), \(b_2 = 1\).

응용

  1. \(b_3 = 3\)인 컴팩트 복소다양체는 케일러일 수 있는가?
    답

    없다. 케일러이면 홀수 베티 수는 짝수이다.

심화

  1. 2차원 복소 토러스 \(\mathbb C^2/\Lambda\)의 호지 수 \(h^{p,q}\)를 \(dz_1, dz_2, d\bar z_1, d\bar z_2\)로 구하여라.
    답

    \(H^{p,q}\)는 \(dz\) \(p\)개와 \(d\bar z\) \(q\)개의 쐐기곱으로 생성되어 \(h^{p,q} = \binom2p\binom2q\). \(h^{1,0} = h^{0,1} = 2\), \(h^{1,1} = 4\), \(h^{2,0} = h^{0,2} = 1\) 등. \(b_1 = 4\), \(b_2 = 6\).
