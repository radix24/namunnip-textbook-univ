평면 대수 곡선이 리만 곡면이 되는 조건

본문
이 절에서 배울 것
  • 다항식 \(f(x, y)\)의 영점 집합 \(C = \{f = 0\} \subset \mathbb C^2\)이 특이점이 없으면 리만 곡면임을 음함수 정리로 보인다.
  • 특이점(\(f = f_x = f_y = 0\))을 찾고, 특이점에서 곡면 구조가 깨지는 예를 안다.
  • 사영평면에서 닫아 컴팩트 곡면을 얻는 과정과 무한원점을 확인하는 법을 이해한다.
먼저 알아야 할 것
  • 음함수 정리 (수학11 2.2절), 리만 곡면 (0.1절).

0.5.1매끄러운 아핀 곡선

\(f(x, y)\)가 복소계수 다항식일 때 \(C = \{(x, y) \in \mathbb C^2 : f(x, y) = 0\}\)을 평면 대수 곡선이라 합니다. 점 \(p \in C\)에서 \(\frac{\partial f}{\partial y}(p) \ne 0\)이면 정칙 음함수 정리로 \(p\) 근처에서 \(C\)는 정칙함수의 그래프 \(y = g(x)\)이고, \(x\)가 좌표가 됩니다. \(\frac{\partial f}{\partial x}(p) \ne 0\)이면 \(y\)가 좌표가 됩니다.

정리 0.5.1 \(f\)가 기약이고 \(C\)의 모든 점에서 \((f_x, f_y) \ne (0, 0)\)이면(매끄러움) \(C\)는 리만 곡면이다.
증명의 흐름

각 점에서 \(x\) 또는 \(y\)를 좌표로 쓴다. 두 좌표가 겹치는 곳에서는 \(f_x, f_y\)가 모두 0이 아니고, 예를 들어 \(y = g(x)\)이므로 전이 함수 \(x \mapsto y = g(x)\)는 정칙이다. 연결성은 \(f\)가 기약이라는 데서 나온다(대수기하의 결과). ∎

예 0.5.2 \(f = y^2 - x^3 + x\)이면 \(f_y = 2y\), \(f_x = -3x^2 + 1\). 둘 다 0이려면 \(y = 0\), \(x^2 = \frac13\)인데 그때 \(f = -x(x^2 - 1) = -x\cdot(-\frac23) \ne 0\)이라 곡선 위에 없습니다. 따라서 매끄럽습니다. 반면 \(y^2 = x^3\)(첨점)은 원점에서 \(f = f_x = f_y = 0\)이고, \(y^2 = x^2(x + 1)\)(마디)도 원점이 특이점입니다.

특이점에서는 곡선이 국소적으로 원판이 아닙니다. 마디 \(y^2 = x^2(x + 1)\)은 원점 근처에서 두 원판(두 가지 \(y \approx \pm x\))이 한 점에서 만나는 모양이고, 그 점을 두 점으로 떼어 놓는 것(정규화)으로 리만 곡면을 얻습니다.

0.5.2컴팩트하게 닫기

아핀 곡선은 \(\mathbb C^2\)에서 유계가 아니라 컴팩트가 아닙니다. 차수 \(d\)인 \(f\)를 동차화 \(F(X, Y, Z) = Z^df\left(\frac XZ, \frac YZ\right)\)하면 사영평면 \(\mathbb P^2\)의 곡선 \(\bar C = \{F = 0\}\)이 되고, 이것은 컴팩트입니다(\(\mathbb P^2\)가 컴팩트). 새로 더해진 점은 \(Z = 0\)인 무한원점들입니다. \(\bar C\)가 매끄러우면(모든 점에서 \(\nabla F \ne 0\)) 컴팩트 리만 곡면이 됩니다.

예 0.5.3 \(y^2 = x^3 - x\)를 동차화하면 \(Y^2Z = X^3 - XZ^2\). \(Z = 0\)이면 \(X^3 = 0\)이라 무한원점은 \([0 : 1 : 0]\) 하나이고, 그 근처 아핀 조각 \(Y = 1\)에서 \(Z = X^3 - XZ^2\)는 \(\frac{\partial}{\partial Z} = 1 - 2XZ \ne 0\)이라 매끄럽습니다. 그래서 \(\bar C\)는 컴팩트 리만 곡면(종수 1, 0.4절)입니다.

한편 \(y^2 = f(x)\)에서 \(\deg f \ge 4\)이면 무한원점이 특이점이 됩니다. 이때도 정규화로 컴팩트 리만 곡면을 얻는데, 0.4절의 초타원 곡선이 그것입니다.

흔한 오해(1) 실수 그림(실수해만 그린 곡선)으로 복소 곡선의 모양을 판단한다. \(y^2 = x^3 - x\)의 실수 그림은 두 조각이지만 복소 곡선은 연결된 토러스(점 하나 뺀)이다. (2) 아핀 곡선의 매끄러움만 확인하면 된다고 여긴다. 무한원점도 확인해야 한다.
요약
  1. \(f = 0\)이 \(f_x, f_y\)가 동시에 0인 점이 없으면 음함수 정리로 리만 곡면.
  2. 특이점(첨점, 마디)에서는 정규화가 필요하다.
  3. 동차화로 \(\mathbb P^2\)에서 닫아 컴팩트하게 하고 무한원점의 매끄러움도 확인한다.

0.5.3연습문제

기본

  1. \(x^2 + y^2 = 1\)이 \(\mathbb C^2\)에서 매끄러움을 보여라.
    답

    \(f_x = 2x\), \(f_y = 2y\)가 동시에 0이면 \((0, 0)\)인데 곡선 위에 없다.

응용

  1. \(xy = 0\)의 특이점을 구하고 기약이 아님을 설명하여라.
    답

    \(f_x = y\), \(f_y = x\)이라 원점이 특이점. \(xy\)는 두 직선 \(x = 0\), \(y = 0\)의 합이라 기약이 아니다.

심화

  1. \(x^2 + y^2 = 1\)을 동차화해 무한원점을 구하여라.
    답

    \(X^2 + Y^2 = Z^2\), \(Z = 0\)이면 \(Y = \pm iX\)라 \([1 : i : 0]\), \([1 : -i : 0]\)의 두 점. 실수 그림에서는 보이지 않는다.
