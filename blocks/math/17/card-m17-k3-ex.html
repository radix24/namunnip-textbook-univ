K3 곡면의 호지 다이아몬드 채우기

예제 · 대칭과 오일러 지표

먼저 예측

\(\mathbb P^3\)의 매끄러운 사차 곡면 \(X\)(예: \(x_0^4 + x_1^4 + x_2^4 + x_3^4 = 0\))는 복소 2차원입니다. 호지 다이아몬드의 가운데 \(h^{1,1}\)은 클까요, 작을까요?

예측 확인

20으로 큽니다. 오일러 지표가 24인데 \(b_1 = b_3 = 0\)이라 \(b_2 = 22\)가 대부분 \(h^{1,1}\)에 몰립니다.

다음 사실로부터 \(X\)의 호지 다이아몬드를 완성하여라. (가) \(X\)는 단순연결이다(따라서 \(b_1 = 0\)). (나) 오일러 지표 \(\chi(X) = 24\). (다) \(X\)에는 어디서도 0이 아닌 정칙 2-형식이 하나 있고 정칙 2-형식의 공간은 1차원이다(\(h^{2,0} = 1\)).

전략

켤레 대칭과 세르 쌍대성으로 미지수를 줄이고, 베티 수 = 가로줄의 합, \(\chi = \sum(-1)^kb_k\)를 씁니다(5.3절).

풀이

  1. \(h^{0,0} = h^{2,2} = 1\) (연결, 세르 쌍대성).
    \(h^{0,0} = \dim\) 정칙함수 = 1.
  2. \(b_1 = h^{1,0} + h^{0,1} = 0\)이므로 \(h^{1,0} = h^{0,1} = 0\). 세르 쌍대성으로 \(h^{2,1} = h^{1,2} = 0\), \(b_3 = 0\).
    (가).
  3. \(\chi = b_0 - b_1 + b_2 - b_3 + b_4 = 1 + b_2 + 1 = 24\)이므로 \(b_2 = 22\).
    (나).
  4. \(b_2 = h^{2,0} + h^{1,1} + h^{0,2} = 1 + h^{1,1} + 1 = 22\)이므로 \(h^{1,1} = 20\).
    (다)와 켤레 대칭 \(h^{0,2} = h^{2,0}\).

검산

다이아몬드(위부터): \(1;\ 0, 0;\ 1, 20, 1;\ 0, 0;\ 1\). 좌우 대칭, 점대칭이 모두 맞고 가로줄 합 \(1, 0, 22, 0, 1\)의 교대합은 24입니다.

의미

\(h^{1,1} = 20\)인 \(H^{1,1}\) 안에서 대수적 곡선의 류가 차지하는 부분(피카르 수)은 곡면에 따라 1부터 20까지 달라집니다. 어떤 \((1, 1)\) 류가 곡선에서 오는지 묻는 것이 다음 절의 호지 추측(이 차원에서는 레프셰츠 정리로 참)의 원형입니다.

이해 확인

2차원 복소 토러스의 오일러 지표가 0임을 다이아몬드 \(1;\ 2, 2;\ 1, 4, 1;\ 2, 2;\ 1\)로 확인하여라.

답

베티 수 \(1, 4, 6, 4, 1\), \(1 - 4 + 6 - 4 + 1 = 0\).
