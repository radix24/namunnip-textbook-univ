유리함수의 분기점 모두 찾기

예제 · 분기 지수와 차수

먼저 예측

\(F(z) = z + \frac1z\)는 리만 구에서 리만 구로 가는 사상이다. 차수는 얼마이고, 분기점은 몇 개일까?

예측 확인

차수 2(\(w = z + \frac1z\)는 \(z\)에 대한 이차방정식), 분기점은 \(z = \pm1\)의 두 개이다.

\(F(z) = z + \frac1z\)의 차수, 모든 분기점과 분지점을 구하고, 분지점의 원상에서 분기 지수의 합이 차수와 같음을 확인하여라.

전략

유한한 점에서는 \(F'(z) = 0\)인 곳이 분기점이다. \(z = 0\)과 \(z = \infty\)는 \(F\)가 극을 가지므로 \(\frac1F\)을 좌표로 보아 따로 확인합니다(0.3절).

풀이

  1. \(w = z + \frac1z\) ⟺ \(z^2 - wz + 1 = 0\). 일반적인 \(w\)에서 원상이 2개이므로 \(\deg F = 2\).
    근의 공식의 판별식 \(w^2 - 4 \ne 0\)이면 서로 다른 두 근.
  2. \(F'(z) = 1 - \frac1{z^2} = 0\) ⟺ \(z = \pm1\). 분기 지수 2, 분지점 \(F(1) = 2\), \(F(-1) = -2\).
    \(F''(\pm1) = \pm2 \ne 0\)이라 \(F'\)은 1차로 0, \(m = 2\).
  3. \(z = 0\): \(F = \frac{z^2 + 1}z\)는 1차 극이라 \(m = 1\). \(z = \infty\): \(\zeta = \frac1z\)로 \(F = \zeta + \frac1\zeta\), 역시 1차 극이라 \(m = 1\).
    극의 차수가 곧 \(\infty\)로 가는 분기 지수.
  4. \(w = 2\)의 원상은 \(z^2 - 2z + 1 = (z - 1)^2\)으로 \(z = 1\) 하나, 지수 2. \(w = \infty\)의 원상은 \(0, \infty\) 둘, 지수 1 + 1. 모두 합이 2.
    정리 0.3.2.

검산

\(z = e^{i\theta}\)이면 \(F = 2\cos\theta\)라 단위원이 \([-2, 2]\) 구간에 두 겹으로 접혀 들어가고, 접히는 끝점이 \(z = \pm1\) (\(w = \pm2\))이다. 분기점에서 두 겹이 만나는 모습과 일치한다.

의미

이 사상은 주코프스키 변환으로, 원을 날개 모양으로 바꾸는 데 쓰인다. 분기점 두 개, 차수 2는 다음 절의 리만-후르비츠 공식에서 \(2\cdot0 - 2 = 2(2\cdot0 - 2) + (1 + 1)\), 즉 \(-2 = -4 + 2\)로 맞아떨어진다.

이해 확인

\(F(z) = z^3 - 3z\)의 유한한 분기점과 그 분기 지수는?

답

\(F' = 3z^2 - 3 = 0\)에서 \(z = \pm1\), 각각 지수 2. 그리고 \(\infty\)에서 지수 3이다.
