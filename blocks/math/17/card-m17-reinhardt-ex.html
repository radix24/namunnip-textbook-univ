두 변수 멱급수의 수렴 영역 구하기

예제 · 라인하르트 영역

먼저 예측

\(\frac1{1 - z_1 - z_2}\)를 원점에서 멱급수로 펼치면, \((z_1, z_2) = (0.6, 0.6)\)에서 수렴할까요? 함수 자체는 그 점에서 정의되어 있습니다(\(1 - 1.2 \ne 0\)).

예측 확인

수렴하지 않습니다. 펼친 급수의 절대수렴 영역은 \(|z_1| + |z_2| < 1\)이고 \(0.6 + 0.6 > 1\)입니다. 함수가 정의된 곳과 급수가 수렴하는 곳은 다릅니다.

\(f(z_1, z_2) = \frac1{1 - z_1 - z_2}\)의 원점 중심 멱급수 \(\sum c_{jk}z_1^jz_2^k\)를 구하고, 절대수렴 영역을 \((r_1, r_2) = (|z_1|, |z_2|)\)로 나타내어라.

전략

\(\frac1{1 - w} = \sum w^m\)에 \(w = z_1 + z_2\)를 넣고 이항정리로 펼칩니다. 절대수렴은 모든 계수와 변수를 절댓값으로 바꾼 급수의 수렴으로 판정합니다(1.2절).

풀이

  1. \(\frac1{1 - (z_1 + z_2)} = \sum_m(z_1 + z_2)^m = \sum_m\sum_{j+k=m}\binom mjz_1^jz_2^k\)이므로 \(c_{jk} = \binom{j + k}j\).
    이항정리.
  2. 절댓값 급수 \(\sum\binom{j + k}jr_1^jr_2^k = \sum_m(r_1 + r_2)^m\)은 \(r_1 + r_2 < 1\)일 때만 수렴한다.
    양의 항들이라 순서를 바꿔 묶어도 된다.
  3. 절대수렴 영역은 \(\{(z_1, z_2) : |z_1| + |z_2| < 1\}\), \((r_1, r_2)\) 평면에서 삼각형 \(r_1 + r_2 < 1\).
    회전 \(z_j \to e^{i\theta_j}z_j\)에 불변: 라인하르트 영역.

검산

\(z_2 = 0\)이면 \(\sum z_1^j\)로 \(|z_1| < 1\), \(z_1 = 0\)이면 \(|z_2| < 1\)이라 삼각형의 두 꼭짓점과 맞습니다. 로그 평면에서 \(e^u + e^v < 1\)은 볼록 영역입니다(\(e^u + e^v\)가 볼록함수).

의미

\(f\)는 \(z_1 + z_2 = 1\)인 복소 직선을 뺀 곳에서 모두 정칙이지만, 원점 중심 멱급수는 그 직선에 닿지 않는 가장 큰 라인하르트 영역에서만 수렴합니다. \(r_1 + r_2 = 1\)인 점은 각 좌표를 회전해 \((r_1, r_2)\)(양의 실수)로 옮기면 직선 위의 점이 되기 때문에, 회전 불변 영역은 \(r_1 + r_2 < 1\)보다 클 수 없습니다.

이해 확인

\(\frac1{1 - z_1z_2}\)의 멱급수의 수렴 영역은?

답

\(\sum(z_1z_2)^m\)이므로 \(|z_1z_2| < 1\), 즉 \(r_1r_2 < 1\). 유계가 아닌 영역입니다.
