복소다양체 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(\mathbb P^2\)에서 \(\phi_2\circ\phi_0^{-1}\)을 구하고 정의역을 써라. [02-01]

    힌트 1

    \(\phi_0^{-1}(w_1, w_2) = [1 : w_1 : w_2]\).

    힌트 2

    셋째 성분 \(w_2\)로 나눈다.

    풀이

    \((w_1, w_2) \mapsto \left(\frac1{w_2}, \frac{w_1}{w_2}\right)\), 정의역 \(w_2 \ne 0\). 성분이 정칙이다 (2.1절).

  2. 증명\(\mathbb P^n\)이 하우스도르프임을 보이는 한 방법으로, 서로 다른 두 점 \([a], [b]\)가 어떤 하나의 아핀 조각 \(U_i\)에 함께 들어 있음을 보여라. [02-01]

    힌트 1

    \(z_0, \dots, z_n\)이 아니라 일차결합 좌표를 쓸 수도 있다.

    힌트 2

    \(\ell(a) \ne 0\), \(\ell(b) \ne 0\)인 일차형식 \(\ell\).

    풀이

    \(\ell(a) \ne 0\), \(\ell(b) \ne 0\)인 일차형식 \(\ell\)이 존재한다(두 초평면 \(\ell(a) = 0\), \(\ell(b) = 0\)의 합집합은 일차형식 공간 전체가 아님). 좌표를 바꿔 \(\ell = z_0\)으로 하면 두 점이 \(U_0 \cong \mathbb C^n\)에 함께 있고, \(\mathbb C^n\)은 하우스도르프이다. ∎

  3. 계산\(\tau = \frac{3 + 4i}{25}\)를 기본 영역으로 옮겨라. [02-02]

    힌트 1

    \(|\tau|^2 = \frac1{25}\).

    힌트 2

    \(-\frac1\tau = -\frac{25}{3 + 4i} = -(3 - 4i)\).

    풀이

    \(-\frac1\tau = -3 + 4i\), 평행이동으로 \(4i\). 기본 영역 안의 점 \(4i\)이다 (2.2절).

  4. 계산토러스 \(\mathbb C/\langle1, i\rangle\)에서 자기 자신으로 가는 \(z \mapsto (1 + i)z\)의 차수를 구하여라. [02-02]

    힌트 1

    차수 = \([\Lambda : a\Lambda]\).

    힌트 2

    곱셈 \(a\)의 실수 행렬식은 \(|a|^2\).

    풀이

    \(|1 + i|^2 = 2\)이므로 차수 2. 리만-후르비츠로 분기점이 없다(\(0 = 2\cdot0 + 0\)).

  5. 계산\(\mathbb P^1\) 위 \(\mathcal O(3)\)의 단면 \(z_0^2z_1 - z_1^3\)의 영점을 모두 구하고 개수가 3임을 확인하여라. [02-03]

    힌트 1

    \(z_1(z_0^2 - z_1^2)\).

    힌트 2

    \([z_0 : z_1]\)로 쓴다.

    풀이

    \(z_1 = 0\): \([1 : 0]\). \(z_0 = \pm z_1\): \([1 : 1]\), \([1 : -1]\). 세 개로, \(\mathcal O(d)\)의 단면의 영점 수 \(d\)와 맞다 (2.3절).

  6. 판단"\(z_0^2 + z_1^2\)은 \(\mathbb P^1\) 위의 정칙함수이다"는 옳은가? [02-03]

    힌트 1

    \([1 : 0] = [2 : 0]\)에서의 값?

    힌트 2

    컴팩트 곡면의 정칙함수는 상수.

    풀이

    틀리다. \([1 : 0]\)과 \([2 : 0]\)은 같은 점인데 값이 1, 4로 달라 함수가 아니다. \(\mathcal O(2)\)의 단면이다. 정칙함수였다면 상수여야 한다.
