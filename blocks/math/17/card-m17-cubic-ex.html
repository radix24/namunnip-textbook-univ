삼차 곡선의 종수를 두 가지로 세기

예제 · 종수 공식과 리만-후르비츠

먼저 예측

\(y^2 = x^3 - x\)는 차수 3인 평면 곡선입니다. 종수 공식으로는 종수가 얼마일까요? \((x, y) \mapsto x\)로 리만-후르비츠를 써도 같은 답이 나올까요?

예측 확인

둘 다 1입니다. 종수 공식 \(\frac{2\cdot1}2 = 1\), 리만-후르비츠에서도 분지점 4개로 \(g = 1\)입니다.

사영 곡선 \(\bar C : Y^2Z = X^3 - XZ^2\)의 종수를 (1) 종수-차수 공식으로, (2) \((x, y) \mapsto x\)의 리만-후르비츠 공식으로, (3) \((x, y) \mapsto y\)의 리만-후르비츠 공식으로 구하여라.

전략

0.5절에서 \(\bar C\)가 매끄러움을 확인했습니다. 각 투영의 차수를 정하고, 유한한 점과 무한원점 \([0 : 1 : 0]\)에서의 분기 지수를 모두 셉니다(0.4절, 0.6절).

풀이

  1. (1) 차수 3이고 매끄러우므로 \(g = \frac{(3 - 1)(3 - 2)}2 = 1\).
    정리 0.6.1.
  2. (2) \(x\)를 정하면 \(y = \pm\sqrt{x^3 - x}\)라 차수 2. \(x = 0, \pm1\)에서 \(y = 0\) 하나(지수 2), \(x = \infty\)도 원상이 \([0 : 1 : 0]\) 하나(지수 2). \(2g - 2 = 2(-2) + 4\cdot1\), \(g = 1\).
    \(\deg f = 3\)이 홀수라 \(\infty\)도 분지점.
  3. (3) \(y\)를 정하면 \(x^3 - x - y^2 = 0\)의 근이 3개라 차수 3. 중근 조건 \(3x^2 - 1 = 0\), 즉 \(x = \pm\frac1{\sqrt3}\)에서 \(y^2 = x^3 - x = \mp\frac2{3\sqrt3}\)이므로 \(y\)는 4개 값이고 각각 지수 2인 점 하나씩.
    \(f_x = 0\)인 점이 \(y\)로의 투영의 분기점.
  4. \(y = \infty\)의 원상은 \([0 : 1 : 0]\) 하나이고, 그 근처에서 \(x \sim y^{2/3}\)이라 지수 3. 합: \(4\cdot1 + 2 = 6\). \(2g - 2 = 3(-2) + 6 = 0\), \(g = 1\).
    무한원점에서 \(\frac xy \to 0\)이 \(y^{-1/3}\) 꼴.

검산

세 방법 모두 \(g = 1\). (3)에서 분기 지수의 합 6이 \(\deg = 3\)에 대해 정리 0.3.2와도 맞습니다(\(y = \infty\)의 원상의 지수 합 = 3).

의미

종수는 곡면의 위상 불변량이라 어떤 사상을 써서 세도 같아야 합니다. 투영을 바꾸면 분기의 모양이 달라지지만 리만-후르비츠 공식의 계산은 같은 답으로 수렴합니다. 이 곡선은 복소 토러스 \(\mathbb C/\Lambda\)와 동형이고, 바이어슈트라스 \(\wp\) 함수가 그 동형을 줍니다.

이해 확인

\(y^2 = x^4 - 1\)에 \((x, y) \mapsto x\)를 쓰면 분지점은 몇 개이고 종수는?

답

\(x^4 = 1\)의 4개(\(\deg f = 4\)가 짝수라 \(\infty\)는 분지점 아님). \(2g - 2 = -4 + 4\), \(g = 1\).
