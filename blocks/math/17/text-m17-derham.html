드람 코호몰로지

본문
이 절에서 배울 것
  • 닫힌 형식(\(d\omega = 0\))을 완전 형식(\(\omega = d\eta\))으로 나눈 드람 코호몰로지 \(H^k_{dR}(M)\)을 정의한다.
  • \(\mathbb R^2\setminus\{0\}\)의 각 형식 \(d\theta\)가 닫혀 있지만 완전하지 않음을 선적분으로 보이고, \(H^1_{dR} = \mathbb R\)을 계산한다.
  • 토러스와 구면의 드람 코호몰로지와 베티 수를 안다.
먼저 알아야 할 것
  • 미분형식과 외미분, 스토크스 정리 (수학11 5.1절, 5.2절), 체흐 코호몰로지 (4.2절).

4.3.1정의

매끄러운 다양체 \(M\)의 \(k\)-형식 공간 \(\Omega^k(M)\)과 외미분 \(d : \Omega^k \to \Omega^{k+1}\)은 \(d\circ d = 0\)을 만족합니다. 그래서 완전 형식은 모두 닫혀 있고,

\[H^k_{dR}(M) = \frac{\{\omega \in \Omega^k : d\omega = 0\}}{\{d\eta : \eta \in \Omega^{k-1}\}}\]

로 정의합니다. 그 차원 \(b_k\)를 \(k\)번째 베티 수라 합니다. \(H^0_{dR}\)은 \(df = 0\)인 함수, 즉 국소 상수 함수라 \(b_0\)는 연결 성분의 개수입니다.

4.3.2구멍 뚫린 평면

예 4.3.1 \(M = \mathbb R^2\setminus\{0\}\)에서 \(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)는 \(d\omega = 0\)이고 국소적으로 \(d\theta\)(각도의 미분)입니다. 단위원을 따라 적분하면 \(\oint\omega = 2\pi\)입니다. 만약 \(\omega = df\)라면 닫힌 곡선을 따라 적분이 \(f\)(끝) − \(f\)(처음) = 0이어야 하므로 \(\omega\)는 완전하지 않습니다.
정리 4.3.2 \(H^1_{dR}(\mathbb R^2\setminus\{0\}) \cong \mathbb R\)이고, 닫힌 1-형식 \(\alpha\)의 류는 \(\frac1{2\pi}\oint_{|z|=1}\alpha\)로 정해진다.
증명의 흐름

닫힌 \(\alpha\)에 대해 \(c = \frac1{2\pi}\oint\alpha\)로 두면 \(\alpha - c\omega\)는 단위원 위의 적분이 0이다. 스토크스 정리로 원점을 감는 횟수가 같은 닫힌 곡선들의 적분은 모두 같으므로 \(\alpha - c\omega\)의 모든 닫힌 곡선 적분이 0이고, \(f(p) = \int_{p_0}^p(\alpha - c\omega)\)가 경로에 무관하게 정의되어 \(df = \alpha - c\omega\)이다. 따라서 \([\alpha] = c[\omega]\). ∎

적분 \(\frac1{2\pi}\oint\omega\)은 곡선이 원점을 감는 횟수입니다. 같은 절의 탐구 카드에서 곡선을 움직이며 이 값을 셉니다.

4.3.3예

  • \(\mathbb R^n\) (또는 축약 가능한 열린집합): \(H^0 = \mathbb R\), \(H^k = 0\) (\(k \ge 1\)). 푸앵카레 보조정리.
  • 원 \(S^1\): \(b_0 = b_1 = 1\).
  • 구면 \(S^2\): \(b_0 = b_2 = 1\), \(b_1 = 0\). 넓이 형식이 \(H^2\)을 생성한다.
  • 토러스 \(T^2 = \mathbb R^2/\mathbb Z^2\): \(b_0 = 1\), \(b_1 = 2\) (\(dx\), \(dy\)), \(b_2 = 1\) (\(dx\wedge dy\)). 종수 \(g\)인 곡면은 \(b_1 = 2g\).

드람 정리에 의해 \(H^k_{dR}(M)\)은 국소 상수 층의 체흐 코호몰로지 \(\check H^k(M, \underline{\mathbb R})\)와 같습니다. 4.2절의 \(\check H^1(S^1, \underline{\mathbb Z}) = \mathbb Z\)와 여기의 \(H^1_{dR}(S^1) = \mathbb R\)은 같은 꼬임을 정수와 실수로 센 것입니다. 오일러 지표는 \(\chi = \sum(-1)^kb_k\)입니다.

흔한 오해(1) 닫힌 형식은 늘 완전하다고 여긴다. 구멍이 있으면 아니다(\(d\theta\)). (2) \(\omega = d\theta\)이니 완전하다고 여긴다. \(\theta\)는 \(\mathbb R^2\setminus\{0\}\) 전체에서 정의된 매끄러운 함수가 아니다(한 바퀴 돌면 \(2\pi\) 어긋남).
요약
  1. \(H^k_{dR} = \) 닫힌 형식 / 완전 형식, \(b_k = \dim H^k_{dR}\).
  2. \(d\theta\)는 닫혀 있지만 완전하지 않다: \(H^1_{dR}(\mathbb R^2\setminus0) = \mathbb R\), 감는 횟수로 측정.
  3. \(S^2\): \(1, 0, 1\). \(T^2\): \(1, 2, 1\). 종수 \(g\): \(1, 2g, 1\).

4.3.4연습문제

기본

  1. \(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)가 닫혀 있음을 계산하여라.
    답

    \(\frac{\partial}{\partial x}\frac{x}{x^2 + y^2} = \frac{y^2 - x^2}{(x^2 + y^2)^2}\), \(\frac{\partial}{\partial y}\frac{-y}{x^2 + y^2} = \frac{y^2 - x^2}{(x^2 + y^2)^2}\). 차가 0이므로 \(d\omega = 0\).

응용

  1. 원점을 중심으로 하지 않는 원 \(|z - 3| = 1\)을 따른 \(\oint\omega\)는?
    답

    원점을 감지 않으므로 0. 이 원 안쪽은 원점을 포함하지 않아 \(\omega\)가 그 위에서 완전하다(스토크스).

심화

  1. 종수 2인 곡면의 베티 수와 오일러 지표를 구하여라.
    답

    \(b_0 = 1\), \(b_1 = 4\), \(b_2 = 1\), \(\chi = 1 - 4 + 1 = -2 = 2 - 2g\).
