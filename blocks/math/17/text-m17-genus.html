평면 곡선의 종수 공식

본문

사영평면의 매끄러운 곡선은 컴팩트 리만 곡면이 된다. 그렇다면 그 곡면의 종수는 곡선의 차수만으로 정해질까? 정해진다면 어떤 식이며, 모든 종수의 곡면을 매끄러운 평면 곡선으로 나타낼 수 있을까?

먼저 알아야 할 것리만-후르비츠 공식(0.4절)과 평면 곡선의 무한원점(0.5절)을 쓴다.

0.6.1공식

정리 0.6.1 (종수-차수 공식)

\(\mathbb P^2\)의 차수 \(d\)인 매끄러운 곡선의 종수는 \(g = \frac{(d - 1)(d - 2)}2\)이다.

\(d = 1, 2\)인 직선과 원뿔곡선은 \(g = 0\)이라 리만 구이고, \(d = 3\)인 삼차 곡선은 \(g = 1\)이라 토러스이다. 또 \(d = 4\)이면 \(g = 3\), \(d = 5\)이면 \(g = 6\)이다. 특이점이 있으면 특이점마다 종수가 줄어들며, 마디나 첨점 하나마다 1씩 준다.

0.6.2페르마 곡선으로 확인

곡선 \(\bar C : X^d + Y^d = Z^d\)은 \(\nabla F = d(X^{d-1}, Y^{d-1}, -Z^{d-1})\)이 \([0 : 0 : 0]\)에서만 0이므로 매끄럽다. 사상 \([X : Y : Z] \mapsto [X : Z]\), 곧 아핀 조각에서 \((x, y) \mapsto x\)는 \(\mathbb P^1\)로 가는 차수 \(d\)인 사상이다. \(x\)를 정하면 \(y^d = 1 - x^d\)의 해가 \(d\)개이기 때문이다.

증명.이 사상의 분기점을 찾는다. 먼저 \(x^d = 1\)인 \(d\)개의 \(x\)에서는 \(y = 0\) 하나뿐이고, \(y^d = 1 - x^d\)가 \(y\)에 대해 \(d\)중근이라 분기 지수가 \(d\)이다. 다음으로 \(Z = 0\)인 무한원점은 \(X^d + Y^d = 0\)의 \(d\)개 점이고, 거기서 \(\frac yx\)가 서로 다른 \(d\)개의 값으로 가므로 분기하지 않는다. 리만-후르비츠 공식에 넣으면 \(2g - 2 = d(-2) + d(d - 1)\)이므로 \(g = \frac{d^2 - 3d + 2}2 = \frac{(d - 1)(d - 2)}2\)이다. 끝으로 차수 \(d\)인 매끄러운 곡선들은 서로 연속적으로 변형되어 종수가 같으므로, 페르마 곡선의 계산이 일반 공식이 된다. ∎

같은 절의 예제 카드에서 다른 투영을 써서 같은 값을 다시 확인한다.

0.6.3결과

\(\frac{(d - 1)(d - 2)}2\)는 그림 1처럼 \(0, 0, 1, 3, 6, 10, \dots\)의 값만 가진다. 그래서 종수 2, 4, 5인 곡면은 매끄러운 평면 곡선으로 나타낼 수 없다. 예를 들어 종수 2인 곡면은 \(\deg f = 5, 6\)인 초타원 곡선 \(y^2 = f(x)\)처럼 특이점을 가진 평면 모형으로 나타내거나, 더 높은 차원의 사영공간에 넣어 나타낸다.

흔한 오해특이점이 있어도 공식을 그대로 쓰기 쉽지만, 차수 3이고 첨점을 가진 \(y^2 = x^3\)은 종수가 1이 아니라 0이다. 또 무한원점에서의 분기를 빠뜨리는 실수도 있다. 투영을 바꾸면 무한원점이 분기점이 될 수 있으므로 따로 확인해야 한다.
마무리

처음 질문에 답하면, 매끄러운 평면 곡선의 종수는 차수만으로 정해지며 \(g = \frac{(d - 1)(d - 2)}2\)이다. 페르마 곡선을 \(\mathbb P^1\)로 투영하면 \(d\)개의 점에서 지수 \(d\)로 분기하므로, 리만-후르비츠 공식에서 이 값이 나온다. 이 식은 \(0, 1, 3, 6, \dots\)만 가지므로 종수 2, 4, 5인 곡면은 매끄러운 평면 곡선으로 나타낼 수 없다.

0.6.4연습문제

기본

  1. 매끄러운 사차 곡선과 육차 곡선의 종수를 구하여라.
    답

    \(\frac{3\cdot2}2 = 3\), \(\frac{5\cdot4}2 = 10\).

응용

  1. 오일러 지표가 \(-10\)인 매끄러운 평면 곡선의 차수는?
    답

    \(2 - 2g = -10\)에서 \(g = 6\), \((d - 1)(d - 2) = 12\)이므로 \(d = 5\).

심화

  1. 마디를 하나 가진 기약 삼차 곡선(예: \(y^2 = x^2(x + 1)\))의 정규화의 종수는?
    답

    \(1 - 1 = 0\). 실제로 \(y = tx\)로 두면 \(x = t^2 - 1\), \(y = t^3 - t\)로 리만 구에서 매개화된다.
