돌보 코호몰로지

본문
이 절에서 배울 것
  • 복소다양체의 미분형식을 \((p, q)\)-형식으로 나누고 \(d = \partial + \bar\partial\)로 분해한다.
  • \(\bar\partial^2 = 0\)을 이용해 돌보 코호몰로지 \(H^{p,q}_{\bar\partial}(X)\)를 정의한다.
  • \(H^{p,0}\)이 정칙 \(p\)-형식이고, 돌보 정리 \(H^{p,q}_{\bar\partial} \cong \check H^q(X, \Omega^p)\)가 성립함을 안다.
먼저 알아야 할 것
  • 드람 코호몰로지 (4.3절), 체흐 코호몰로지 (4.2절), \(\frac{\partial}{\partial\bar z}\) (1.1절).

4.4.1(p, q)-형식

복소 좌표 \(z_j = x_j + iy_j\)에서 \(dz_j = dx_j + i\,dy_j\), \(d\bar z_j = dx_j - i\,dy_j\)를 쓰면 모든 복소값 미분형식은

\[\omega = \sum f_{IJ}\,dz_{i_1}\wedge\cdots\wedge dz_{i_p}\wedge d\bar z_{j_1}\wedge\cdots\wedge d\bar z_{j_q}\]

꼴의 합으로 쓰입니다. \(dz\)가 \(p\)개, \(d\bar z\)가 \(q\)개인 것을 \((p, q)\)-형식이라 하고, 정칙 좌표 바꾸기에서 \(dz\)는 \(dz\)들로만 바뀌므로 이 분해는 좌표에 무관합니다. \(\Omega^k = \bigoplus_{p+q=k}\Omega^{p,q}\).

외미분은 \(df = \sum\frac{\partial f}{\partial z_j}dz_j + \sum\frac{\partial f}{\partial\bar z_j}d\bar z_j = \partial f + \bar\partial f\)로 갈라지고, 일반적으로 \(d = \partial + \bar\partial\), \(\bar\partial : \Omega^{p,q} \to \Omega^{p,q+1}\)입니다. \(d^2 = 0\)을 차수별로 나누면 \(\partial^2 = 0\), \(\bar\partial^2 = 0\), \(\partial\bar\partial + \bar\partial\partial = 0\)입니다.

4.4.2정의

정의 4.4.1 \(H^{p,q}_{\bar\partial}(X) = \dfrac{\ker(\bar\partial : \Omega^{p,q} \to \Omega^{p,q+1})}{\operatorname{im}(\bar\partial : \Omega^{p,q-1} \to \Omega^{p,q})}\)를 돌보 코호몰로지라 한다.
  • \(H^{0,0}\): \(\bar\partial f = 0\)인 함수 = 정칙함수. 컴팩트이면 상수뿐이라 \(\mathbb C\).
  • \(H^{p,0}\): \(\bar\partial\omega = 0\)인 \((p, 0)\)-형식 = 정칙 \(p\)-형식 \(\sum f_I\,dz_I\) (\(f_I\) 정칙).
  • \(H^{0,1}\): \(\bar\partial u = \alpha\)를 풀 수 있는지의 방해. \(\mathbb C\)에서는 늘 풀리므로(\(\bar\partial\)-포앵카레 보조정리) \(H^{0,1}(\mathbb C) = 0\).
정리 4.4.2 (돌보) \(H^{p,q}_{\bar\partial}(X) \cong \check H^q(X, \Omega^p)\). 여기서 \(\Omega^p\)는 정칙 \(p\)-형식의 층이다.

드람 정리가 "형식으로 계산한 코호몰로지 = 국소 상수 층의 코호몰로지"였듯이, 돌보 정리는 "\(\bar\partial\)로 계산한 코호몰로지 = 정칙 형식 층의 코호몰로지"입니다. 4.2절 예제의 \(\check H^1(\mathbb P^1, \mathcal O) = 0\)은 \(H^{0,1}(\mathbb P^1) = 0\)과 같은 내용입니다.

예 4.4.3 토러스 \(X = \mathbb C/\Lambda\)에서 \(dz\)와 \(d\bar z\)는 격자 평행이동에 불변이라 \(X\) 위의 형식입니다. \(dz\)는 정칙 1-형식이라 \(H^{1,0}\)을, \(d\bar z\)는 \(H^{0,1}\)을 생성하고, 각각 1차원입니다. \(H^1_{dR}(X) = \mathbb C^2\)가 \(H^{1,0}\oplus H^{0,1}\)으로 쪼개지는 것이 다음 단원 호지 분해의 가장 간단한 예입니다.
흔한 오해(1) \(\bar\partial\)-닫힌 형식이 \(d\)-닫힌 형식이라고 여긴다. \(\partial\omega\)는 0이 아닐 수 있다. (2) 돌보 코호몰로지가 위상 불변량이라고 여긴다. 복소 구조에 따라 달라질 수 있다(케일러이면 차원만은 위상으로 정해진다).
요약
  1. \(\Omega^k = \bigoplus\Omega^{p,q}\), \(d = \partial + \bar\partial\), \(\bar\partial^2 = 0\).
  2. \(H^{p,q}_{\bar\partial} = \ker\bar\partial/\operatorname{im}\bar\partial\), \(H^{p,0}\) = 정칙 \(p\)-형식.
  3. 돌보 정리: \(H^{p,q}_{\bar\partial} \cong \check H^q(X, \Omega^p)\).

4.4.4연습문제

기본

  1. \(\mathbb C\)에서 \(f = |z|^2\)의 \(\partial f\)와 \(\bar\partial f\)를 구하여라.
    답

    \(f = z\bar z\)이므로 \(\partial f = \bar z\,dz\), \(\bar\partial f = z\,d\bar z\).

응용

  1. \(dx\wedge dy = \frac i2dz\wedge d\bar z\)임을 보이고, 이것이 \((1, 1)\)-형식임을 확인하여라.
    답

    \(dz\wedge d\bar z = (dx + i\,dy)\wedge(dx - i\,dy) = -2i\,dx\wedge dy\)이므로 \(dx\wedge dy = \frac i2dz\wedge d\bar z\). \(dz\) 하나, \(d\bar z\) 하나라 \((1, 1)\).

심화

  1. \(\mathbb P^1\)에 0이 아닌 정칙 1-형식이 없음을 보여 \(H^{1,0}(\mathbb P^1) = 0\)을 확인하여라.
    답

    \(U_0\)에서 \(f(z)\,dz\)이고 \(w = \frac1z\)이면 \(dz = -\frac{dw}{w^2}\)이라 \(-f(\frac1w)\frac1{w^2}dw\)가 \(w = 0\)에서 정칙이어야 한다. \(f\)가 정함수이고 \(f(z) = O(z^{-2})\)이어야 하므로 리우빌로 \(f = 0\).
