리만 구 위 정칙함수 층의 코호몰로지

예제 · 로랑 급수로 쪼개기

먼저 예측

\(\mathbb P^1\)을 \(U_0 = \mathbb C\)와 \(U_1 = \mathbb P^1\setminus\{0\}\)으로 덮는다. 겹치는 곳 \(\mathbb C^\times\)의 정칙함수 \(c\)를 언제나 "\(U_1\)의 정칙함수 − \(U_0\)의 정칙함수"로 쓸 수 있을까?

예측 확인

쓸 수 있다. 로랑 급수를 음의 차수 부분과 음이 아닌 차수 부분으로 나누면 된다. 그래서 \(\check H^1(\mathbb P^1, \mathcal O) = 0\)이다.

덮개 \(\{U_0, U_1\}\)으로 \(\check H^0(\mathbb P^1, \mathcal O)\)와 \(\check H^1(\mathbb P^1, \mathcal O)\)를 계산하여라.

전략

\(U_0, U_1\)은 각각 \(\mathbb C\)와 같아 그 위의 정칙함수는 \(z\) 또는 \(w = \frac1z\)의 멱급수이다. 겹치는 곳의 정칙함수는 로랑 급수 \(\sum_{n\in\mathbb Z}a_nz^n\)이다. \(\delta(s_0, s_1) = s_1 - s_0\)의 핵과 상을 구합니다(4.2절).

풀이

  1. \(s_0 = \sum_{n\ge0}a_nz^n\) (\(\mathbb C\)에서 정칙), \(s_1 = \sum_{n\ge0}b_nz^{-n}\) (\(w = \frac1z\)의 멱급수).
    \(U_1\)의 좌표는 \(w\).
  2. \(\check H^0\): \(s_0 = s_1\)이면 양의 차수와 음의 차수 계수가 모두 0이고 상수항만 같아야 하므로 \(s_0 = s_1 = a_0\). \(\check H^0 = \mathbb C\).
    정리 0.2.1과 같은 결론.
  3. \(\check H^1\): 임의의 \(c = \sum_{n\in\mathbb Z}c_nz^n \in \mathcal O(\mathbb C^\times)\)에 대해 \(s_1 = \sum_{n\le0}c_nz^n\), \(s_0 = -\sum_{n>0}c_nz^n\)으로 두면 \(c = s_1 - s_0\). 두 급수는 각각 \(U_1\), \(U_0\)에서 수렴하므로 \(\delta\)가 전사이고 \(\check H^1 = 0\).
    로랑 급수는 \(\mathbb C^\times\) 전체에서 수렴하므로 각 부분도 해당 영역에서 수렴한다.

검산

\(c = e^z + e^{1/z}\)의 로랑 계수는 \(c_0 = 2\), \(c_n = c_{-n} = \frac1{n!}\) (\(n \ge 1\))이다. 풀이대로 \(s_1 = \sum_{n\le0}c_nz^n = e^{1/z} + 1\) (\(w\)의 정함수 \(e^w + 1\)), \(s_0 = -\sum_{n>0}c_nz^n = -(e^z - 1)\)이고, \(s_1 - s_0 = e^{1/z} + 1 + e^z - 1 = c\)이다.

의미

\(\check H^1(X, \mathcal O)\)의 차원은 리만 곡면의 종수 \(g\)와 같습니다(리만-로흐와 세르 쌍대성의 결과). 리만 구는 \(g = 0\)이라 0이고, 토러스 \(\mathbb C/\Lambda\)에서는 1차원이다. 위상적 불변량(종수)이 해석적 계산(정칙함수의 붙이기 방해)으로 나타나는 예이다.

이해 확인

같은 덮개에서 \(c = \frac1z\)을 \(s_1 - s_0\)으로 쓰면?

답

\(s_1 = \frac1z = w\) (\(U_1\)에서 정칙), \(s_0 = 0\). 음의 차수 항이라 \(U_1\) 쪽에 넣는다.
