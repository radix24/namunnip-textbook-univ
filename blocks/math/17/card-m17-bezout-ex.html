사라진 교점 찾기

예제 · 사영 폐포와 베주 정리

먼저 예측

쌍곡선 \(xy = 1\)과 직선 \(y = 0\)은 실수 평면에서 만나지 않는다. 베주 정리에 따르면 교점은 몇 개여야 하고, 어디에 있을까?

예측 확인

\(2\times1 = 2\)개이다. 둘 다 무한원점 \([1 : 0 : 0]\)에 있습니다(중복도 2: 직선이 그 점에서 쌍곡선에 접함).

(1) \(xy = 1\)과 \(y = 0\), (2) \(xy = 1\)과 \(y = x\), (3) \(y = x^2\)과 \(x = 0\)의 교점을 \(\mathbb P^2\)에서 중복도와 함께 모두 구하고 베주 정리를 확인하여라.

전략

곡선을 동차화하고 아핀 교점(\(Z = 1\))과 무한원 교점(\(Z = 0\))을 따로 센다. 중복도는 한 변수로 정리한 다항식의 근의 중복도로 셉니다(3.2절).

풀이

  1. (1) \(XY = Z^2\), \(Y = 0\)이면 \(Z^2 = 0\). 교점 \([1 : 0 : 0]\), \(Z\)에 대한 이중근이라 중복도 2. 합 2 = 2·1.
    아핀 교점 없음(\(Z = 1\)이면 \(0 = 1\)).
  2. (2) \(Y = X\)를 넣으면 \(X^2 = Z^2\), \(X = \pm Z\). 교점 \([1 : 1 : 1]\), \([-1 : -1 : 1]\) (아핀 점 \((1, 1)\), \((-1, -1)\)), 각각 중복도 1. 합 2.
    무한원 교점 없음(\(Z = 0\)이면 \(X = Y = 0\)).
  3. (3) \(YZ = X^2\), \(X = 0\)이면 \(YZ = 0\). 아핀 점 \([0 : 0 : 1]\) (원점)과 무한원점 \([0 : 1 : 0]\), 각각 중복도 1. 합 2.
    포물선의 축과 평행한 직선은 무한원점에서 한 번 더 만난다.

검산

세 경우 모두 교점 수(중복도 포함)가 \(2\times1 = 2\)이다. (1)의 중복도 2는 \(y = 0\)이 쌍곡선의 점근선, 즉 무한원점에서의 접선이라서이다.

의미

아핀 평면에서 교점이 "사라지는" 이유는 두 가지이다. 실수가 아니라서(복소 교점), 그리고 무한원에 있어서이다. 복소수와 사영공간을 함께 쓰면 교점 수가 차수의 곱으로 고정되어, 대수기하의 많은 정리가 예외 없이 깔끔해진다.

이해 확인

원 \(x^2 + y^2 = 1\)과 직선 \(x = 2\)의 교점 2개는 어디에 있나요?

답

\(y^2 = -3\), \(y = \pm i\sqrt3\): 아핀 평면의 두 복소 점 \((2, \pm i\sqrt3)\)이다. 무한원에는 교점이 없다.
