쌍곡선 위에서 원점에 가장 가까운 점

예제 · 유계 헤세 행렬식으로 극소 판정

먼저 예측

쌍곡선 \(xy = 1\) 위에서 \(x^2 + y^2\)의 임계점 \((1, 1)\)은 극대일까, 극소일까?

예측 확인

극소이다. 쌍곡선은 멀리 갈수록 원점에서 멀어지므로 최댓값은 없다.

제약 \(g(x, y) = xy = 1\) 위에서 \(f(x, y) = x^2 + y^2\)의 임계점을 모두 구하고, 유계 헤세 행렬식으로 종류를 판정하여라.

전략

승수법으로 후보를 찾고(3.2절), \(L = f - \lambda(g - 1)\)의 2계 도함수로 \(\bar H\)를 계산합니다(3.3절).

풀이

  1. \(2x = \lambda y\), \(2y = \lambda x\), \(xy = 1\). 두 식을 곱하면 \(4xy = \lambda^2xy\)이라 \(\lambda^2 = 4\).
    \(xy = 1 \ne 0\).
  2. \(\lambda = 2\)이면 \(x = y\), 후보 \((1, 1)\), \((-1, -1)\). \(\lambda = -2\)이면 \(y = -x\)라 \(xy = -x^2 = 1\)이 불가능.
    실수해 없음.
  3. \(L_{xx} = 2\), \(L_{yy} = 2\), \(L_{xy} = -\lambda = -2\), \((1, 1)\)에서 \(g_x = y = 1\), \(g_y = x = 1\).
    \(L = x^2 + y^2 - 2(xy - 1)\).
  4. \(\bar H = -(2\cdot1 - 2(-2)\cdot1\cdot1 + 2\cdot1) = -8 < 0\): 극소. \((-1, -1)\)도 같은 계산으로 \(-8\), 극소. 극솟값 2, 최단 거리 \(\sqrt2\).
    따름정리 3.3.2.

검산

\(y = \frac1x\)로 대입하면 \(h(x) = x^2 + x^{-2}\), \(h'(1) = 0\), \(h''(1) = 2 + 6 = 8 > 0\)으로 극소이다. 산술-기하 평균으로도 \(x^2 + x^{-2} \ge 2\).

의미

\(f\)의 헤세 행렬 \(2I\)만 봐도 극소처럼 보이지만, 그것은 우연이다. \(L\)의 헤세 행렬은 \(\begin{pmatrix}2 & -2\\-2 & 2\end{pmatrix}\)로 퇴화했는데, 접벡터 \((1, -1)\) 방향에서는 \(8 > 0\)이다. 판정에 필요한 것은 접선 방향의 부호뿐이다.

이해 확인

\(xy = 1\) 위에서 \(f = x + y\)의 임계점 \((1, 1)\)은?

답

\(\lambda = 1\), \(L_{xx} = L_{yy} = 0\), \(L_{xy} = -1\), \(\bar H = -(0 + 2 + 0) = -2 < 0\): 극소(값 2). \((-1, -1)\)은 \(\lambda = -1\), \(\bar H = 2 > 0\): 극대(값 \(-2\)).
