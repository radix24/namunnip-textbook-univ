모든 방향도함수가 있는데 미분가능하지 않은 함수

예제 · 방향도함수가 선형이 아니면 미분 불가능

먼저 예측

\(f(x, y) = \frac{x^2y}{x^2 + y^2}\) (\(f(0, 0) = 0\))는 원점에서 연속이고 모든 방향의 방향도함수가 있다. 미분가능할까?

예측 확인

아니다. 방향도함수가 방향에 대해 선형이 아니기 때문이다.

위의 \(f\)에 대해 (1) 원점에서 연속임을 보이고, (2) 단위벡터 \(\mathbf u = (a, b)\) 방향의 방향도함수를 구하고, (3) 미분가능하지 않음을 보여라.

전략

미분가능하면 \(D_{\mathbf u}f(\mathbf 0) = \nabla f(\mathbf 0)\cdot\mathbf u\)로 \(\mathbf u\)에 대해 선형이어야 합니다(1.4절). 직접 계산한 방향도함수와 비교한다.

풀이

  1. \(|f(x, y)| = |y|\frac{x^2}{x^2 + y^2} \le |y| \to 0\)이므로 연속.
    분수가 1 이하.
  2. \(D_{\mathbf u}f(\mathbf 0) = \lim_{t\to0}\frac{f(ta, tb)}t = \lim\frac{t^3a^2b}{t\cdot t^2} = a^2b\).
    \(a^2 + b^2 = 1\).
  3. 축 방향에서 \(f_x(\mathbf 0) = 0\) (\(a = 1, b = 0\)), \(f_y(\mathbf 0) = 0\) (\(a = 0, b = 1\)). 미분가능하면 모든 방향도함수가 \(\nabla f\cdot\mathbf u = 0\)이어야 한다.
    \(\nabla f(\mathbf 0) = \mathbf 0\).
  4. 그러나 \(\mathbf u = (\frac1{\sqrt2}, \frac1{\sqrt2})\)이면 \(a^2b = \frac1{2\sqrt2} \approx 0.354 \ne 0\). 미분가능하지 않다.
    모순.

검산

정리 1.4.2와 모순이 없는지 확인한다. \(f_x = \frac{2xy^3}{(x^2 + y^2)^2}\)은 \(y = x\) 위에서 \(\frac12\)이라 원점에서 0으로 가지 않는다. 편도함수가 연속이 아니므로 정리가 적용되지 않는다.

의미

그래프를 그리면 원점을 지나는 각 직선 위에서는 \(f\)가 직선(\(t \mapsto ta^2b\))이지만, 그 기울기들이 하나의 평면을 이루지 않는다. 미분가능성은 "모든 방향의 접선이 한 접평면에 놓인다"는 조건이고, 방향별 정보만으로는 보장되지 않는다.

이해 확인

\(\mathbf u = (\frac35, \frac45)\) 방향의 방향도함수는?

답

\(a^2b = \frac9{25}\cdot\frac45 = \frac{36}{125} = 0.288\).
