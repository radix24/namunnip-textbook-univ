푸앵카레 보조정리

본문

회전이 0인 벡터장은 늘 어떤 함수의 기울기일까? 형식의 말로 하면, 닫힌 형식은 늘 완전할까? 5.1절에서 \(\mathbb R^2\setminus\{\mathbf 0\}\)의 반례를 보았다. 그렇다면 어떤 영역에서 닫힘과 완전이 같아질까?

먼저 알아야 할 것닫힌 형식과 완전 형식(5.1절), 적분 기호 아래 미분(4.4절)을 쓴다.

5.3.1진술

모든 \(\mathbf x \in U\)에 대해 선분 \(\{t\mathbf x : 0 \le t \le 1\}\)이 \(U\)에 들어가면 열린집합 \(U \subset \mathbb R^n\)이 원점에 대해 별 모양이라고 한다. 볼록 집합은 별 모양이다.

정리 5.3.1 (푸앵카레 보조정리, 1-형식)

\(U\)가 별 모양이고 \(\omega = \sum_ia_i\,dx_i\)가 \(U\)에서 \(C^1\)인 닫힌 형식, 곧 \(\frac{\partial a_i}{\partial x_j} = \frac{\partial a_j}{\partial x_i}\)이면 \(f(\mathbf x) = \int_0^1\sum_ia_i(t\mathbf x)\,x_i\,dt\)는 \(df = \omega\)를 만족한다. 따라서 \(\omega\)는 완전 형식이다.

여기서 \(f(\mathbf x)\)는 원점에서 \(\mathbf x\)까지의 선분을 따라 \(\omega\)를 적분한 값이다. 그림 1의 주황 선분들이 이 적분 경로이다.

5.3.2증명

증명.4.4절의 라이프니츠 규칙으로 \(\frac{\partial f}{\partial x_j} = \int_0^1\left[a_j(t\mathbf x) + \sum_it\frac{\partial a_i}{\partial x_j}(t\mathbf x)\,x_i\right]dt\)이다. 닫힘 조건으로 \(\frac{\partial a_i}{\partial x_j}\)를 \(\frac{\partial a_j}{\partial x_i}\)로 바꾸면 \(\sum_it\,x_i\frac{\partial a_j}{\partial x_i}(t\mathbf x) = t\frac{d}{dt}\big[a_j(t\mathbf x)\big]\)이다. 따라서 피적분함수는 \(a_j(t\mathbf x) + t\frac d{dt}a_j(t\mathbf x) = \frac d{dt}\big[t\,a_j(t\mathbf x)\big]\)이고, 0부터 1까지 적분하면 \(a_j(\mathbf x)\)이다. ∎

2-형식과 3-형식에도 같은 방식의 공식이 있어, 별 모양 영역에서는 모든 차수에서 닫힘과 완전이 같다. \(\mathbb R^3\)의 말로 하면 "회전이 0인 벡터장은 기울기장"이고 "발산이 0인 벡터장은 회전장"이다.

예제 5.3.2

\(\omega = 2xy\,dx + x^2\,dy\)가 닫혀 있음을 확인하고 정리의 공식으로 퍼텐셜을 구하여라.

풀이. \(\frac{\partial(2xy)}{\partial y} = 2x = \frac{\partial(x^2)}{\partial x}\)이므로 닫혀 있다. 공식에 넣으면 \(f(x, y) = \int_0^1\big[2(tx)(ty)\,x + (tx)^2\,y\big]dt = 3x^2y\int_0^1t^2\,dt = x^2y\)이고, 실제로 \(d(x^2y) = 2xy\,dx + x^2\,dy\)이다.

5.3.3구멍이 있으면

5.1절의 \(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)은 \(\mathbb R^2\setminus\{\mathbf 0\}\)에서 닫혀 있지만 완전하지 않았다. 이 영역은 원점을 지나는 선분이 빠지므로 별 모양이 아니고, 따라서 정리와 모순되지 않는다. 그런데 원점을 지나지 않는 반평면 \(x > 0\)으로 줄이면 점 \((1, 0)\)에 대해 별 모양이 되고, 거기서는 \(\omega = d\left(\arctan\frac yx\right)\)로 완전하다. 즉 닫힌 형식이 완전이 되지 못하는 정도가 영역의 구멍을 재며, 이것이 드람 코호몰로지의 출발점이다(수학17 4.3절).

흔한 오해닫힌 형식은 어디서나 완전하다고 여기기 쉽지만 영역의 모양이 중요하다. 또 별 모양을 볼록과 같다고 여기는 것도 틀렸으며, 별 모양 다각형처럼 별 모양이 더 넓은 개념이다. 퍼텐셜이 유일하다고 여기는 것도 주의한다. 연결된 영역에서 퍼텐셜은 상수 차이만큼 다를 수 있다.
마무리

처음 질문에 답하면, 닫힌 형식이 늘 완전한 것은 아니지만 별 모양 영역에서는 그렇다(푸앵카레 보조정리). 퍼텐셜은 중심에서 각 점까지의 선분을 따라 적분한 \(f(\mathbf x) = \int_0^1\sum a_i(t\mathbf x)x_i\,dt\)이고, 닫힘 조건이 피적분함수를 \(\frac d{dt}[t\,a_j(t\mathbf x)]\)로 만들어 \(df = \omega\)가 나온다. 구멍이 있는 영역에서는 선분이 영역을 벗어나 이 구성이 깨지며, 실제로 완전하지 않은 닫힌 형식이 생길 수 있다.

5.3.4연습문제

기본

  1. \(\omega = y\,dx + x\,dy\)의 퍼텐셜을 정리의 공식으로 구하여라.
    답

    \(\int_0^1(ty\cdot x + tx\cdot y)dt = xy\).

응용

  1. \(\omega = 2xy\,dx + (x^2 + 3y^2)\,dy\)가 닫혀 있음을 확인하고 퍼텐셜을 구하여라.
    답

    \(\partial_y(2xy) = 2x = \partial_x(x^2 + 3y^2)\). \(\int_0^1(2t^2xy\cdot x + (t^2x^2 + 3t^2y^2)y)dt = x^2y + y^3\).

심화

  1. \(\mathbb R^2\setminus\{(x, 0) : x \le 0\}\)(음의 \(x\)축을 뺀 평면)은 별 모양인가? 이 영역에서 \(d\theta\)형식은 완전인가?
    답

    점 \((1, 0)\)에 대해 별 모양이다. 따라서 완전이며 퍼텐셜은 \((-\pi, \pi)\) 값을 갖는 편각 함수다.
