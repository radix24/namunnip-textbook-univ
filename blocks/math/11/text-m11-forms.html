미분형식과 외미분

본문
이 절에서 배울 것
  • \(\mathbb R^n\)의 \(k\)-형식을 \(dx_{i_1}\wedge\cdots\wedge dx_{i_k}\)의 함수 계수 일차결합으로 정의하고 쐐기곱의 규칙을 익힌다.
  • 외미분 \(d\)를 계산하고 \(d^2 = 0\)을 확인한다.
  • \(\mathbb R^3\)에서 \(d\)가 그래디언트, 회전, 발산과 같다는 것을 대응표로 정리한다.
먼저 알아야 할 것
  • 편도함수와 슈바르츠 정리 (1.2절), 행렬식의 교대성 (수학1 5.1절), 선적분.

5.1.1형식은 "적분할 수 있는 것"

선적분 \(\int_\gamma P\,dx + Q\,dy\)의 피적분 식 \(P\,dx + Q\,dy\)는 곡선 위의 작은 변위 \((\Delta x, \Delta y)\)에 수 \(P\Delta x + Q\Delta y\)를 주는 규칙입니다. 면적분의 피적분 식은 작은 평행사변형(두 벡터)에 수를 주는 규칙이고, 넓이처럼 방향이 있어 두 벡터의 순서를 바꾸면 부호가 바뀌어야 합니다. 이것을 일반화한 것이 미분형식입니다.

\(k\)-형식(\(k\)-form): 열린집합 \(E \subseteq \mathbb R^n\) 위에서 \(\omega = \sum_{I}a_I(\mathbf x)\,dx_{i_1}\wedge\cdots\wedge dx_{i_k}\) (\(I = (i_1 < \cdots < i_k)\), \(a_I\)는 \(C^1\) 함수)로 쓰이는 대상. 각 점에서 \(k\)개의 벡터를 받아 수를 내는 교대 다중선형 함수이다.

\(dx_i\wedge dx_j\)는 두 벡터 \(\mathbf u, \mathbf v\)에 \(\det\begin{pmatrix}u_i & v_i\\u_j & v_j\end{pmatrix}\)를 주는 2-형식입니다. 행렬식처럼 교대적이라 다음 규칙이 성립합니다.

\[dx_j\wedge dx_i = -dx_i\wedge dx_j, \qquad dx_i\wedge dx_i = 0.\]

0-형식은 함수, \(n\)-형식은 \(a(\mathbf x)\,dx_1\wedge\cdots\wedge dx_n\) 하나뿐이고, \(k > n\)이면 0입니다. 쐐기곱은 분배법칙과 위 규칙으로 계산하며, \(k\)-형식 \(\alpha\)와 \(l\)-형식 \(\beta\)에 대해 \(\beta\wedge\alpha = (-1)^{kl}\alpha\wedge\beta\)입니다.

예: \((x\,dx + y\,dy)\wedge(y\,dx - x\,dy) = -x^2\,dx\wedge dy + y^2\,dy\wedge dx = -(x^2 + y^2)\,dx\wedge dy\).

5.1.2외미분

정의 5.1.1 (외미분)

함수 \(f\)에 대해 \(df = \sum_iD_if\,dx_i\). \(k\)-형식 \(\omega = \sum_Ia_I\,dx_I\)에 대해 \(d\omega = \sum_Ida_I\wedge dx_I\) (\((k + 1)\)-형식).

예제 5.1.2

(a) \(\omega = xy\,dx + x^2\,dy\), (b) \(\omega = yz\,dx + xz\,dy + xy\,dz\)의 외미분을 구하여라.

풀이. (a) \(d(xy)\wedge dx = (y\,dx + x\,dy)\wedge dx = x\,dy\wedge dx = -x\,dx\wedge dy\), \(d(x^2)\wedge dy = 2x\,dx\wedge dy\). 합하면 \(d\omega = x\,dx\wedge dy\). 일반적으로 \(d(P\,dx + Q\,dy) = (Q_x - P_y)\,dx\wedge dy\)입니다. (b) 계산하면 \(d\omega = (x - x)\,dy\wedge dz + (y - y)\,dz\wedge dx + (z - z)\,dx\wedge dy = 0\). 실제로 \(\omega = d(xyz)\)입니다.

정리 5.1.3 (\(d^2 = 0\))

\(C^2\) 계수의 형식 \(\omega\)에 대해 \(d(d\omega) = 0\).

증명.함수 \(f\)에 대해 \(d(df) = \sum_{i,j}D_{ji}f\,dx_j\wedge dx_i\). \(i = j\)인 항은 \(dx_i\wedge dx_i = 0\)이고, \(i \ne j\)인 항은 \((i, j)\)와 \((j, i)\)가 짝을 이루어 \((D_{ji}f - D_{ij}f)\,dx_j\wedge dx_i\)가 되는데 슈바르츠 정리로 0이다. 일반 형식은 \(d(a\,dx_I) = da\wedge dx_I\)이고 \(d(dx_I) = 0\)이므로 \(d(d(a\,dx_I)) = d(da)\wedge dx_I = 0\). ∎

\(d^2 = 0\)은 혼합 편도함수의 대칭(1.2절)을 형식의 언어로 말한 것입니다.

5.1.3\(\mathbb R^3\)의 대응표

형식벡터해석\(d\)의 결과
0-형식 \(f\)함수 \(f\)\(df \leftrightarrow \nabla f\)
1-형식 \(F_1dx + F_2dy + F_3dz\)벡터장 \(\mathbf F\) (선적분)\(\leftrightarrow \nabla\times\mathbf F\)
2-형식 \(F_1dy\wedge dz + F_2dz\wedge dx + F_3dx\wedge dy\)벡터장 \(\mathbf F\) (선속)\((\nabla\cdot\mathbf F)\,dx\wedge dy\wedge dz\)

이 표에서 \(d^2 = 0\)은 두 항등식 \(\nabla\times(\nabla f) = \mathbf 0\), \(\nabla\cdot(\nabla\times\mathbf F) = 0\)이 됩니다. 세 가지 서로 다른 미분 연산이 하나의 \(d\)로 통일된다는 것이 미분형식의 첫 이점입니다.

5.1.4닫힌 형식과 완전 형식

닫힌 형식: \(d\omega = 0\)인 형식. 완전 형식: 어떤 \(\eta\)에 대해 \(\omega = d\eta\)인 형식.

\(d^2 = 0\)이므로 완전 ⇒ 닫힘입니다. 역은 영역의 모양에 달렸습니다. \(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)은 \(\mathbb R^2\setminus\{\mathbf 0\}\)에서 닫혀 있지만(\(d\omega = 0\)), 단위원을 따라 적분하면 \(2\pi\)라 완전하지 않습니다(완전이면 닫힌 곡선의 적분이 0). 별 모양 영역(어떤 점에서 모든 점이 선분으로 보이는 영역)에서는 닫힌 형식이 모두 완전하다는 것이 푸앵카레 보조정리입니다.

흔한 오해(1) \(dx\wedge dy = dy\wedge dx\)로 계산한다(부호가 바뀐다). (2) \(d(f\,dx) = df\cdot dx\)로 쓰고 \(dx\wedge dx\) 항을 남긴다. (3) "닫힌 형식은 항상 완전하다": 영역에 구멍이 있으면 거짓.
요약
  1. \(k\)-형식: \(\sum a_I\,dx_I\). 쐐기곱은 교대적: \(dx_j\wedge dx_i = -dx_i\wedge dx_j\).
  2. \(d(a\,dx_I) = da\wedge dx_I\), \(d^2 = 0\) (슈바르츠 정리).
  3. \(\mathbb R^3\): \(d\)는 grad, curl, div. \(d^2 = 0\)은 curl grad = 0, div curl = 0.
  4. 완전 ⇒ 닫힘. 역은 구멍 없는(별 모양) 영역에서 성립.

5.1.5연습문제

기본

  1. \(\omega = e^x\sin y\,dx + e^x\cos y\,dy\)의 \(d\omega\)를 구하고 \(\omega = df\)인 \(f\)를 찾아라.
    답

    \(d\omega = (e^x\cos y - e^x\cos y)\,dx\wedge dy = 0\). \(f = e^x\sin y\).

응용

  1. \(\mathbb R^3\)에서 \(\omega = x\,dy\wedge dz + y\,dz\wedge dx + z\,dx\wedge dy\)의 \(d\omega\)를 구하여라.
    답

    \(d\omega = (1 + 1 + 1)\,dx\wedge dy\wedge dz = 3\,dx\wedge dy\wedge dz\) (\(\nabla\cdot(x, y, z) = 3\)).

심화

  1. 극좌표 \(x = r\cos\theta\), \(y = r\sin\theta\)를 대입하면 \(dx\wedge dy = r\,dr\wedge d\theta\)이고, \(\frac{-y\,dx + x\,dy}{x^2 + y^2} = d\theta\)임을 보여라.
    답

    \(dx = \cos\theta\,dr - r\sin\theta\,d\theta\), \(dy = \sin\theta\,dr + r\cos\theta\,d\theta\). \(dx\wedge dy = r\cos^2\theta\,dr\wedge d\theta - r\sin^2\theta\,d\theta\wedge dr = r\,dr\wedge d\theta\) (변수변환의 야코비 행렬식). \(-y\,dx + x\,dy = r^2\,d\theta\). 다만 \(\theta\)는 \(\mathbb R^2\setminus\{\mathbf 0\}\) 전체에서 연속인 함수로 정의되지 않으므로 \(d\theta\)는 완전 형식이 아니다.
