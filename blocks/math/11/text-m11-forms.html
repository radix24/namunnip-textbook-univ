미분형식과 외미분

본문

벡터해석에는 기울기, 회전, 발산이라는 세 가지 미분 연산과 \(\nabla\times\nabla f = \mathbf 0\), \(\nabla\cdot(\nabla\times\mathbf F) = 0\)이라는 두 항등식이 있다. 이것들을 하나로 묶는 언어가 있을까? 선적분과 면적분의 피적분 식은 정확히 무엇일까?

먼저 알아야 할 것편도함수와 슈바르츠 정리(1.2절), 행렬식의 교대성(수학1 5.1절)과 선적분을 쓴다.

5.1.1형식은 적분할 수 있는 것

선적분 \(\int_\gamma P\,dx + Q\,dy\)의 피적분 식 \(P\,dx + Q\,dy\)는 곡선 위의 작은 변위 \((\Delta x, \Delta y)\)에 수 \(P\Delta x + Q\Delta y\)를 주는 규칙이다. 면적분의 피적분 식은 작은 평행사변형, 곧 두 벡터에 수를 주는 규칙이고, 넓이와 같이 방향이 있어 두 벡터의 순서를 바꾸면 부호가 바뀌어야 한다. 이것을 일반화한 것이 미분형식이다.

정의

열린집합 \(E \subseteq \mathbb R^n\) 위에서 \(\omega = \sum_{I}a_I(\mathbf x)\,dx_{i_1}\wedge\cdots\wedge dx_{i_k}\) (\(I = (i_1 < \cdots < i_k)\), \(a_I\)는 \(C^1\))로 쓰이는 대상을 \(k\)-형식이라 한다. 각 점에서 \(k\)개의 벡터를 받아 수를 내는 교대 다중선형 함수이다.

\(dx_i\wedge dx_j\)는 두 벡터 \(\mathbf u, \mathbf v\)에 \(\det\begin{pmatrix}u_i & v_i\\u_j & v_j\end{pmatrix}\)를 주는 2-형식이다. 행렬식처럼 교대적이므로 \(dx_j\wedge dx_i = -dx_i\wedge dx_j\)이고 \(dx_i\wedge dx_i = 0\)이다. 0-형식은 함수이고, \(n\)-형식은 \(a(\mathbf x)\,dx_1\wedge\cdots\wedge dx_n\) 하나뿐이며, \(k > n\)이면 0이다. 쐐기곱은 분배법칙과 위 규칙으로 계산하고, \(k\)-형식 \(\alpha\)와 \(l\)-형식 \(\beta\)에 대해 \(\beta\wedge\alpha = (-1)^{kl}\alpha\wedge\beta\)이다. 예를 들어 \((x\,dx + y\,dy)\wedge(y\,dx - x\,dy) = -(x^2 + y^2)\,dx\wedge dy\)이다.

5.1.2외미분

정의 5.1.1 (외미분)

함수 \(f\)에 대해 \(df = \sum_iD_if\,dx_i\)라 한다. \(k\)-형식 \(\omega = \sum_Ia_I\,dx_I\)에 대해서는 \(d\omega = \sum_Ida_I\wedge dx_I\)라 하며, 이것은 \((k + 1)\)-형식이다.

예제 5.1.2

(a) \(\omega = xy\,dx + x^2\,dy\), (b) \(\omega = yz\,dx + xz\,dy + xy\,dz\)의 외미분을 구하여라.

풀이. (a) \(d(xy)\wedge dx = x\,dy\wedge dx = -x\,dx\wedge dy\)이고 \(d(x^2)\wedge dy = 2x\,dx\wedge dy\)이므로 \(d\omega = x\,dx\wedge dy\)이다. 일반적으로 \(d(P\,dx + Q\,dy) = (Q_x - P_y)\,dx\wedge dy\)이다. (b) 계산하면 세 성분의 계수가 모두 \(x - x\), \(y - y\), \(z - z\)라 \(d\omega = 0\)이다. 실제로 \(\omega = d(xyz)\)이다.

정리 5.1.3 (\(d^2 = 0\))

\(C^2\) 계수의 형식 \(\omega\)에 대해 \(d(d\omega) = 0\)이다.

증명.함수 \(f\)에 대해 \(d(df) = \sum_{i,j}D_{ji}f\,dx_j\wedge dx_i\)이다. \(i = j\)인 항은 \(dx_i\wedge dx_i = 0\)이고, \(i \ne j\)인 항은 \((i, j)\)와 \((j, i)\)가 짝을 이루어 \((D_{ji}f - D_{ij}f)\,dx_j\wedge dx_i\)가 되는데 슈바르츠 정리로 0이다. 일반 형식은 \(d(a\,dx_I) = da\wedge dx_I\)이고 \(d(dx_I) = 0\)이므로 \(d(d(a\,dx_I)) = d(da)\wedge dx_I = 0\)이다. ∎

즉 \(d^2 = 0\)은 혼합 편도함수의 대칭(1.2절)을 형식의 언어로 말한 것이다.

5.1.3\(\mathbb R^3\)의 대응표

형식벡터해석\(d\)의 결과
0-형식 \(f\)함수 \(f\)\(df \leftrightarrow \nabla f\)
1-형식 \(F_1dx + F_2dy + F_3dz\)벡터장 \(\mathbf F\) (선적분)\(\leftrightarrow \nabla\times\mathbf F\)
2-형식 \(F_1dy\wedge dz + F_2dz\wedge dx + F_3dx\wedge dy\)벡터장 \(\mathbf F\) (선속)\((\nabla\cdot\mathbf F)\,dx\wedge dy\wedge dz\)

이 표에서 \(d^2 = 0\)은 두 항등식 \(\nabla\times(\nabla f) = \mathbf 0\)과 \(\nabla\cdot(\nabla\times\mathbf F) = 0\)이 된다. 다시 말해 세 가지 서로 다른 미분 연산이 하나의 \(d\)로 통일되며, 이것이 미분형식의 첫 이점이다.

5.1.4닫힌 형식과 완전 형식

\(d\omega = 0\)인 형식을 닫힌 형식, 어떤 \(\eta\)에 대해 \(\omega = d\eta\)인 형식을 완전 형식이라 한다. \(d^2 = 0\)이므로 완전 형식은 닫혀 있다. 하지만 역은 영역의 모양에 달렸다. \(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)은 \(\mathbb R^2\setminus\{\mathbf 0\}\)에서 닫혀 있지만, 단위원을 따라 적분하면 \(2\pi\)라 완전하지 않다. 완전이면 닫힌 곡선의 적분이 0이어야 하기 때문이다. 반면 별 모양 영역에서는 닫힌 형식이 모두 완전하며, 이것이 5.3절의 푸앵카레 보조정리이다.

흔한 오해\(dx\wedge dy = dy\wedge dx\)로 계산하기 쉽지만 부호가 바뀐다. 또 \(d(f\,dx)\)를 계산하며 \(dx\wedge dx\) 항을 남기는 실수가 있으며, 그 항은 0이다. "닫힌 형식은 늘 완전하다"는 것도 영역에 구멍이 있으면 거짓이다.
마무리

처음 질문에 답하면, 미분형식이 그 언어이다. \(k\)-형식은 \(k\)개의 벡터에 교대적으로 수를 주는 규칙이며, 선적분과 면적분의 피적분 식이 각각 1-형식과 2-형식이다. 외미분 \(d\) 하나가 \(\mathbb R^3\)에서 기울기, 회전, 발산의 역할을 모두 하고, \(d^2 = 0\)이 두 항등식을 한꺼번에 준다. 완전 형식은 늘 닫혀 있지만 그 역은 영역의 모양에 달렸다.

5.1.5연습문제

기본

  1. \(\omega = e^x\sin y\,dx + e^x\cos y\,dy\)의 \(d\omega\)를 구하고 \(\omega = df\)인 \(f\)를 찾아라.
    답

    \(d\omega = (e^x\cos y - e^x\cos y)\,dx\wedge dy = 0\). \(f = e^x\sin y\).

응용

  1. \(\mathbb R^3\)에서 \(\omega = x\,dy\wedge dz + y\,dz\wedge dx + z\,dx\wedge dy\)의 \(d\omega\)를 구하여라.
    답

    \(d\omega = (1 + 1 + 1)\,dx\wedge dy\wedge dz = 3\,dx\wedge dy\wedge dz\) (\(\nabla\cdot(x, y, z) = 3\)).

심화

  1. 극좌표 \(x = r\cos\theta\), \(y = r\sin\theta\)를 대입하면 \(dx\wedge dy = r\,dr\wedge d\theta\)이고, \(\frac{-y\,dx + x\,dy}{x^2 + y^2} = d\theta\)임을 보여라.
    답

    \(dx = \cos\theta\,dr - r\sin\theta\,d\theta\), \(dy = \sin\theta\,dr + r\cos\theta\,d\theta\). \(dx\wedge dy = r\cos^2\theta\,dr\wedge d\theta - r\sin^2\theta\,d\theta\wedge dr = r\,dr\wedge d\theta\) (변수변환의 야코비 행렬식). \(-y\,dx + x\,dy = r^2\,d\theta\). 다만 \(\theta\)는 \(\mathbb R^2\setminus\{\mathbf 0\}\) 전체에서 연속인 함수로 정의되지 않으므로 \(d\theta\)는 완전 형식이 아니다.
