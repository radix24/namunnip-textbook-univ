6.2.1평균수렴과 완비성

평균수렴(mean convergence, \(L^2\) 수렴): \(\|f - f_N\| = \left(\frac1\pi\int_{-\pi}^\pi|f - f_N|^2\right)^{1/2} \to 0\).

완비(complete) 정규직교계: 모든 적분 가능한 \(f\)에 대해 \(\|f - S_Nf\| \to 0\)인 계. 동치로, 베셀 부등식이 항상 등식이 되는 계.

정리 6.1.1의 식 \(\|f - S_Nf\|^2 = \|f\|^2 - \sum_{n\le N}c_n^2\)에서 두 정의가 같은 말임을 바로 알 수 있습니다. 6.1절의 "사인만 모은 계"는 \(\cos x\)를 근사하지 못하므로 완비가 아닙니다.

정리 6.2.1 (삼각함수계의 완비성, 파서벌)

\(f\)가 \([-\pi, \pi]\)에서 리만 적분 가능하면 \(\|f - S_Nf\| \to 0\)이고

\[\frac1\pi\int_{-\pi}^\pi f^2 = \frac{a_0^2}2 + \sum_{n=1}^\infty(a_n^2 + b_n^2).\]

6.2.2증명의 흐름

  1. 연속 주기함수를 삼각다항식으로 균등 근사. \(f\)가 연속이고 \(f(-\pi) = f(\pi)\)이면, 부분합의 평균(체사로 평균) \(\sigma_Nf = \frac1{N + 1}\sum_{k=0}^NS_kf\)가 \(f\)로 균등수렴한다(페예르 정리). 핵심은 \(\sigma_Nf\)가 \(f\)와 페예르 핵 \(F_N(t) = \frac1{N + 1}\left(\frac{\sin\frac{(N + 1)t}2}{\sin\frac t2}\right)^2\)의 합성곱이고, \(F_N\)이 음이 아니며 적분이 일정하고 0 밖에서 0으로 균등하게 줄어든다는 것이다. (디리클레 핵은 음수 값을 가져 이 논법이 안 된다.)
  2. 최소제곱으로 부분합에 옮기기. \(\sigma_Nf\)는 \(N\)차 삼각다항식이므로 정리 6.1.1로 \(\|f - S_Nf\| \le \|f - \sigma_Nf\| \le \sqrt2\sup|f - \sigma_Nf| \to 0\) (\(\|g\|^2 \le \frac1\pi\cdot2\pi\sup|g|^2\)). 그리고 \(\|f - S_Nf\|\)는 \(N\)에 대해 감소하므로 전체 수열이 0으로 간다.
  3. 적분 가능 함수로 넓히기. 리만 적분 가능한 \(f\)는 연속 주기함수 \(g\)로 \(\|f - g\| < \varepsilon\)이 되게 근사할 수 있다(계단함수로 근사한 뒤 모서리를 기울기로 잇고 끝점을 맞춘다). \(S_Ng\)도 \(N\)차 삼각다항식이므로 정리 6.1.1(최소제곱)을 \(f\)에 쓰면 \(\|f - S_Nf\| \le \|f - S_Ng\| \le \|f - g\| + \|g - S_Ng\| < 2\varepsilon\) (\(N\)이 크면, 2단계).

파서벌 등식은 \(\|f - S_Nf\|^2 = \|f\|^2 - \left(\frac{a_0^2}2 + \sum_{n\le N}(a_n^2 + b_n^2)\right) \to 0\)에서 바로 나옵니다.

6.2.3응용: 급수의 합

예제 6.2.2 (바젤 문제)

\(\sum_{n=1}^\infty\frac1{n^2} = \frac{\pi^2}6\)임을 파서벌 등식으로 보여라.

풀이. \(f(x) = x\)이면 \(b_n = \frac{2(-1)^{n+1}}n\), \(a_n = 0\) (6.1절 연습문제 1). \(\frac1\pi\int_{-\pi}^\pi x^2\,dx = \frac{2\pi^2}3\)이므로 파서벌 등식은 \(\sum\frac4{n^2} = \frac{2\pi^2}3\), 곧 \(\sum\frac1{n^2} = \frac{\pi^2}6 \approx 1.644934\)입니다. 같은 방법으로 \(|x|\)에서 \(\sum\frac1{n^4} = \frac{\pi^4}{90}\)을 얻습니다(같은 절의 예제 카드).

두 함수의 파서벌 등식(분극 항등식)으로 \(\frac1\pi\int fg = \frac{a_0\alpha_0}2 + \sum(a_n\alpha_n + b_n\beta_n)\)도 성립합니다. 이것은 "직교 좌표에서 내적은 좌표의 곱의 합"이라는 사실의 무한차원판입니다.

6.2.4무엇을 얻었나

  • 유일성: 두 연속 주기함수의 푸리에 계수가 모두 같으면 \(\|f - g\| = 0\)이고 연속이므로 \(f = g\)입니다.
  • \(\ell^2\)과의 대응: \(f \mapsto (a_0/\sqrt2, a_1, b_1, \dots)\)는 내적을 보존합니다. 리만 적분 가능 함수 공간은 완비가 아니라서 이 대응이 전사는 아니며, 전사가 되게 하려면 르베그 적분(\(L^2\) 공간)이 필요합니다(리스-피셔 정리).
흔한 오해(1) 완비성(평균수렴)을 점별수렴으로 착각한다. 파서벌 등식이 성립해도 특정 점에서 부분합이 수렴하지 않을 수 있다. (2) 상수항의 정규화를 틀린다: 이 교재의 약속에서는 \(\frac{a_0^2}2\)이다.
요약
  1. 완비 ⟺ 모든 \(f\)에서 \(\|f - S_Nf\| \to 0\) ⟺ 베셀이 항상 등식.
  2. 삼각함수계는 완비: 페예르(양의 핵) → 최소제곱 → 연속함수로 근사.
  3. 파서벌: \(\frac1\pi\int f^2 = \frac{a_0^2}2 + \sum(a_n^2 + b_n^2)\). \(f = x\)에서 \(\sum\frac1{n^2} = \frac{\pi^2}6\).

6.2.5연습문제

기본

  1. 사각파 \(\operatorname{sgn}x\)의 파서벌 등식에서 홀수 \(n\)에 대한 합 \(\sum\frac1{n^2}\)을 구하여라.
    답

    홀수 \(n\)에 대해 더한 \(\sum\frac{16}{\pi^2n^2}\)이 \(\|f\|^2 = 2\)와 같으므로, 홀수 \(n\)에 대한 \(\sum\frac1{n^2}\)은 \(\frac{\pi^2}8 \approx 1.2337\)이다.

응용

  1. 연속 주기함수 \(f\)의 푸리에 계수가 모두 0이면 \(f = 0\)임을 보여라.
    답

    파서벌로 \(\int f^2 = 0\). \(f^2\)은 연속이고 음이 아니므로 \(f = 0\).

심화

  1. 페예르 핵이 음이 아니라는 사실이 2단계 증명에서 왜 중요한가? 디리클레 핵 \(D_N\)으로는 왜 같은 논법이 안 되는가?
    답

    \(|\sigma_Nf(x) - f(x)| \le \frac1{2\pi}\int F_N(t)|f(x - t) - f(x)|\,dt\)에서 \(F_N \ge 0\)이고 적분이 \(2\pi\)라 가중평균이 되어, \(t\)가 작을 때는 \(|f(x - t) - f(x)|\)이 작고 \(t\)가 클 때는 \(F_N\)이 작다는 것으로 끝난다. \(D_N\)은 음수 값을 가지고 \(\int|D_N| \to \infty\) (로그로 증가)라 가중평균의 부등식이 성립하지 않는다.
