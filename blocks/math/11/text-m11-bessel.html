직교 함수계와 베셀 부등식

본문
이 절에서 배울 것
  • 함수 공간의 내적과 직교 함수계를 정의하고, 삼각함수계가 정규직교임을 확인한다.
  • 푸리에 계수로 만든 부분합이 같은 차수의 일차결합 중 가장 좋은 근사(최소제곱)임을 증명한다.
  • 베셀 부등식과 그 따름정리(리만-르베그 보조정리)를 증명한다.
먼저 알아야 할 것
  • 리만 적분 (수학7 5.2절), 내적과 정규직교 기저, 직교 사영 (수학1 7.3절).

6.1.1함수의 내적

\([-\pi, \pi]\)에서 리만 적분 가능한 실함수들에 대해

\[\langle f, g\rangle = \frac1\pi\int_{-\pi}^\pi f(x)g(x)\,dx, \qquad \|f\| = \sqrt{\langle f, f\rangle}\]

로 둡니다(엄밀히는 \(\|f\| = 0\)인 0이 아닌 함수가 있어 "준"내적이지만 아래 논의에는 지장이 없습니다). 수학1의 \(\mathbb R^n\) 내적에서 합을 적분으로 바꾼 것입니다.

정규직교 함수계: \(\langle\varphi_m, \varphi_n\rangle = 0\) (\(m \ne n\)), \(\|\varphi_n\| = 1\)인 함수열 \(\{\varphi_n\}\).

삼각함수계 \(\left\{\frac1{\sqrt2}, \cos x, \sin x, \cos2x, \sin2x, \dots\right\}\)는 이 내적에 대해 정규직교입니다. 예를 들어 \(m \ne n\)이면 \(\int_{-\pi}^\pi\cos mx\cos nx\,dx = \frac12\int(\cos(m - n)x + \cos(m + n)x)\,dx = 0\)이고, \(\frac1\pi\int\cos^2nx\,dx = 1\)입니다. 이 계에 대한 푸리에 계수는

\[a_n = \frac1\pi\int_{-\pi}^\pi f(x)\cos nx\,dx, \qquad b_n = \frac1\pi\int_{-\pi}^\pi f(x)\sin nx\,dx,\]

부분합은 \(S_Nf(x) = \frac{a_0}2 + \sum_{n=1}^N(a_n\cos nx + b_n\sin nx)\)입니다.

6.1.2가장 좋은 근사

정리 6.1.1 (최소제곱 근사)

\(\{\varphi_1, \dots, \varphi_N\}\)이 정규직교이고 \(c_n = \langle f, \varphi_n\rangle\)이면, 모든 실수 \(\gamma_1, \dots, \gamma_N\)에 대해

\[\Big\|f - \sum_{n=1}^N\gamma_n\varphi_n\Big\|^2 = \|f\|^2 - \sum_{n=1}^Nc_n^2 + \sum_{n=1}^N(\gamma_n - c_n)^2.\]

따라서 \(\gamma_n = c_n\)일 때(푸리에 계수일 때) 오차가 최소이고, 그 최소는 \(\|f\|^2 - \sum c_n^2\)이다.

증명.\(g = \sum\gamma_n\varphi_n\)이라 하면 정규직교성으로 \(\langle f, g\rangle = \sum\gamma_nc_n\), \(\|g\|^2 = \sum\gamma_n^2\)이다. 따라서 \(\|f - g\|^2 = \|f\|^2 - 2\sum\gamma_nc_n + \sum\gamma_n^2 = \|f\|^2 - \sum c_n^2 + \sum(\gamma_n - c_n)^2\) (완전제곱). ∎

기하적으로 \(S_Nf\)는 \(f\)를 \(\varphi_1, \dots, \varphi_N\)이 생성하는 부분공간에 직교 사영한 것이고, 오차 \(f - S_Nf\)는 그 부분공간에 수직입니다. 수학4 3.2절의 다항식 최소제곱과 같은 원리이며, 정규직교 기저를 쓰니 정규방정식이 "계수 = 내적"으로 단순해진 것입니다.

6.1.3베셀 부등식

정리 6.1.2 (베셀 부등식)

정규직교 함수계 \(\{\varphi_n\}\)과 적분 가능한 \(f\)에 대해 \(\sum_{n=1}^\infty c_n^2 \le \|f\|^2\). 삼각함수계에서는

\[\frac{a_0^2}2 + \sum_{n=1}^\infty(a_n^2 + b_n^2) \le \frac1\pi\int_{-\pi}^\pi f^2.\]

증명.정리 6.1.1에서 \(\gamma_n = c_n\)으로 두면 \(0 \le \|f - S_Nf\|^2 = \|f\|^2 - \sum_{n\le N}c_n^2\). 부분합이 \(\|f\|^2\)로 위로 유계인 양항급수이므로 수렴하고 합도 \(\|f\|^2\) 이하이다. ∎

따름정리 6.1.3 (리만-르베그)

\(f\)가 \([-\pi, \pi]\)에서 적분 가능하면 \(a_n \to 0\), \(b_n \to 0\). 곧 \(\int f(x)\sin nx\,dx \to 0\).

수렴하는 급수의 항은 0으로 가기 때문입니다. 빠르게 진동하는 \(\sin nx\)를 곱하면 양수 부분과 음수 부분이 상쇄된다는 직관의 엄밀한 형태이며, 6.3절에서 점별수렴을 증명할 때 핵심 도구가 됩니다.

6.1.4예: 사각파

\(f(x) = \operatorname{sgn}x\)이면 홀함수라 \(a_n = 0\), \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2(1 - (-1)^n)}{\pi n}\), 곧 홀수 \(n\)에서 \(\frac4{\pi n}\), 짝수 \(n\)에서 0입니다. \(\|f\|^2 = \frac1\pi\cdot2\pi = 2\)이고, 오차 \(\|f - S_Nf\|^2 = 2 - \sum_{n\le N}b_n^2\)은 \(N = 1, 5, 10, 50\)에서 약 0.379, 0.134, 0.081, 0.016입니다. 같은 절의 탐구 카드에서 다른 함수와 비교합니다.

흔한 오해(1) 베셀 부등식의 등호(파서벌 등식)가 항상 성립한다고 여긴다. 등호는 함수계가 완비일 때이며, 예를 들어 사인만 모은 계 \(\{\sin nx\}\)로는 짝함수 \(\cos x\)의 계수가 모두 0이라 \(0 < \|\cos x\|^2 = 1\)이다. (2) 정규화 상수(\(\frac1\pi\)와 \(\frac1{2\pi}\), 상수항의 \(\frac{a_0}2\))를 교재마다 다르게 쓰므로 섞으면 틀린다.
요약
  1. \(\langle f, g\rangle = \frac1\pi\int fg\)에 대해 \(\{\frac1{\sqrt2}, \cos nx, \sin nx\}\)는 정규직교.
  2. 푸리에 부분합은 직교 사영이며, 같은 차수의 삼각다항식 중 평균제곱오차가 최소.
  3. 베셀: \(\sum c_n^2 \le \|f\|^2\). 따라서 계수는 0으로 간다(리만-르베그).

6.1.5연습문제

기본

  1. \(f(x) = x\)의 푸리에 계수를 구하여라.
    답

    홀함수라 \(a_n = 0\). 부분적분으로 \(b_n = \frac2\pi\int_0^\pi x\sin nx\,dx = \frac{2(-1)^{n+1}}n\).

응용

  1. \(f = x\)에 대해 베셀 부등식을 쓰면 \(\sum\frac1{n^2}\)에 대해 무엇을 얻는가?
    답

    \(\sum\frac4{n^2} \le \frac1\pi\int x^2 = \frac{2\pi^2}3\)이므로 \(\sum\frac1{n^2} \le \frac{\pi^2}6\). 6.2절에서 등호임을 본다.

심화

  1. \(f\)가 \(C^1\)이고 \(2\pi\)-주기이면 \(\sum(|a_n| + |b_n|) < \infty\)임을 보여라.
    답

    부분적분으로 \(f'\)의 계수가 \(nb_n\), \(-na_n\)이다. 코시-슈바르츠와 베셀로 \(\sum|b_n| = \sum\frac1n\cdot n|b_n| \le \left(\sum\frac1{n^2}\right)^{1/2}\left(\sum n^2b_n^2\right)^{1/2} \le \frac\pi{\sqrt6}\|f'\| < \infty\). \(a_n\)도 같다. 따라서 푸리에 급수는 균등수렴한다(M-판정법).
