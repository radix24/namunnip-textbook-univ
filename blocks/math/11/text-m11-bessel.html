직교 함수계와 베셀 부등식

본문

함수를 \(\cos nx\)와 \(\sin nx\)의 합으로 근사하려 한다. 계수를 어떻게 고르면 가장 잘 맞을까? \(\mathbb R^n\)에서 벡터를 정규직교 기저로 전개하듯 함수도 전개할 수 있을까? 그리고 계수들의 제곱의 합에는 어떤 한계가 있을까?

먼저 알아야 할 것리만 적분(수학7 5.2절), 내적과 정규직교 기저, 직교 사영(수학1 7.3절)을 쓴다.

6.1.1함수의 내적

\([-\pi, \pi]\)에서 리만 적분 가능한 실함수들에 대해 \(\langle f, g\rangle = \frac1\pi\int_{-\pi}^\pi f(x)g(x)\,dx\), \(\|f\| = \sqrt{\langle f, f\rangle}\)로 둔다. 엄밀히는 \(\|f\| = 0\)인 0이 아닌 함수가 있어 준내적이지만 아래 논의에는 지장이 없다. 즉 수학1의 \(\mathbb R^n\) 내적에서 합을 적분으로 바꾼 것이다.

정의

\(m \ne n\)이면 \(\langle\varphi_m, \varphi_n\rangle = 0\)이고 \(\|\varphi_n\| = 1\)인 함수열 \(\{\varphi_n\}\)을 정규직교 함수계라 한다.

삼각함수계 \(\left\{\frac1{\sqrt2}, \cos x, \sin x, \cos2x, \sin2x, \dots\right\}\)는 이 내적에 대해 정규직교이다. 예를 들어 \(m \ne n\)이면 \(\int_{-\pi}^\pi\cos mx\cos nx\,dx = \frac12\int(\cos(m - n)x + \cos(m + n)x)\,dx = 0\)이고, \(\frac1\pi\int\cos^2nx\,dx = 1\)이다. 이 계에 대한 푸리에 계수는 \(a_n = \frac1\pi\int_{-\pi}^\pi f(x)\cos nx\,dx\), \(b_n = \frac1\pi\int_{-\pi}^\pi f(x)\sin nx\,dx\)이고, 부분합은 \(S_Nf(x) = \frac{a_0}2 + \sum_{n=1}^N(a_n\cos nx + b_n\sin nx)\)이다.

6.1.2가장 좋은 근사

정리 6.1.1 (최소제곱 근사)

\(\{\varphi_1, \dots, \varphi_N\}\)이 정규직교이고 \(c_n = \langle f, \varphi_n\rangle\)이면, 모든 실수 \(\gamma_1, \dots, \gamma_N\)에 대해 \(\Big\|f - \sum_{n=1}^N\gamma_n\varphi_n\Big\|^2 = \|f\|^2 - \sum_{n=1}^Nc_n^2 + \sum_{n=1}^N(\gamma_n - c_n)^2\)이다. 따라서 \(\gamma_n = c_n\)일 때 오차가 최소이고, 그 최소는 \(\|f\|^2 - \sum c_n^2\)이다.

증명.\(g = \sum\gamma_n\varphi_n\)이라 하면 정규직교성으로 \(\langle f, g\rangle = \sum\gamma_nc_n\)이고 \(\|g\|^2 = \sum\gamma_n^2\)이다. 따라서 \(\|f - g\|^2 = \|f\|^2 - 2\sum\gamma_nc_n + \sum\gamma_n^2\)이고, 완전제곱으로 정리하면 주어진 식이 된다. ∎

기하적으로 \(S_Nf\)는 \(f\)를 \(\varphi_1, \dots, \varphi_N\)이 생성하는 부분공간에 직교 사영한 것이고, 오차 \(f - S_Nf\)는 그 부분공간에 수직이다. 이것은 수학4 3.2절의 다항식 최소제곱과 같은 원리이며, 정규직교 기저를 쓰니 정규방정식이 "계수 = 내적"으로 단순해진 것이다.

6.1.3베셀 부등식

정리 6.1.2 (베셀 부등식)

정규직교 함수계 \(\{\varphi_n\}\)과 적분 가능한 \(f\)에 대해 \(\sum_{n=1}^\infty c_n^2 \le \|f\|^2\)이다. 삼각함수계에서는 \(\frac{a_0^2}2 + \sum_{n=1}^\infty(a_n^2 + b_n^2) \le \frac1\pi\int_{-\pi}^\pi f^2\)이다.

증명.정리 6.1.1에서 \(\gamma_n = c_n\)으로 두면 \(0 \le \|f - S_Nf\|^2 = \|f\|^2 - \sum_{n\le N}c_n^2\)이다. 따라서 부분합이 \(\|f\|^2\)로 위로 유계인 양항급수이므로 수렴하고, 합도 \(\|f\|^2\) 이하이다. ∎

따름정리 6.1.3 (리만-르베그)

\(f\)가 \([-\pi, \pi]\)에서 적분 가능하면 \(a_n \to 0\), \(b_n \to 0\)이다. 곧 \(\int f(x)\sin nx\,dx \to 0\)이다.

수렴하는 급수의 항은 0으로 가기 때문이다. 다시 말해 빠르게 진동하는 \(\sin nx\)를 곱하면 양수 부분과 음수 부분이 상쇄된다는 직관의 엄밀한 형태이며, 6.3절에서 점별수렴을 증명할 때 중요한 도구가 된다.

6.1.4예, 사각파

\(f(x) = \operatorname{sgn}x\)는 홀함수라 \(a_n = 0\)이고 \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2(1 - (-1)^n)}{\pi n}\)이다. 곧 홀수 \(n\)에서 \(\frac4{\pi n}\), 짝수 \(n\)에서 0이다. \(\|f\|^2 = \frac1\pi\cdot2\pi = 2\)이고, 오차 \(\|f - S_Nf\|^2 = 2 - \sum_{n\le N}b_n^2\)은 \(N = 1, 5, 10, 50\)에서 약 0.379, 0.134, 0.081, 0.016이다. 그림 1의 누적합이 2에 다가가는 모습이 이것이며, 같은 절의 탐구 카드에서 다른 함수와 비교한다.

흔한 오해베셀 부등식의 등호, 곧 파서벌 등식이 늘 성립한다고 여기기 쉽다. 등호는 함수계가 완비일 때이며, 예를 들어 사인만 모은 계 \(\{\sin nx\}\)로는 짝함수 \(\cos x\)의 계수가 모두 0이라 \(0 < \|\cos x\|^2 = 1\)이다. 또 정규화 상수 \(\frac1\pi\)와 \(\frac1{2\pi}\), 상수항의 \(\frac{a_0}2\)를 교재마다 다르게 쓰므로 섞으면 틀린다.
마무리

처음 질문에 답하면, 계수를 푸리에 계수 \(c_n = \langle f, \varphi_n\rangle\)로 고를 때 평균제곱 오차가 가장 작으며, 이때 부분합은 \(f\)의 직교 사영이다. 즉 함수도 정규직교 함수계로 벡터처럼 전개한다. 계수들의 제곱의 합은 \(\|f\|^2\)을 넘지 못하며(베셀 부등식), 그래서 계수는 0으로 간다(리만-르베그). 등호가 성립하는지는 함수계의 완비성에 달렸고, 이것은 6.2절에서 다룬다.

6.1.5연습문제

기본

  1. \(f(x) = x\)의 푸리에 계수를 구하여라.
    답

    홀함수라 \(a_n = 0\). 부분적분으로 \(b_n = \frac2\pi\int_0^\pi x\sin nx\,dx = \frac{2(-1)^{n+1}}n\).

응용

  1. \(f = x\)에 대해 베셀 부등식을 쓰면 \(\sum\frac1{n^2}\)에 대해 무엇을 얻는가?
    답

    \(\sum\frac4{n^2} \le \frac1\pi\int x^2 = \frac{2\pi^2}3\)이므로 \(\sum\frac1{n^2} \le \frac{\pi^2}6\). 6.2절에서 등호임을 본다.

심화

  1. \(f\)가 \(C^1\)이고 \(2\pi\)-주기이면 \(\sum(|a_n| + |b_n|) < \infty\)임을 보여라.
    답

    부분적분으로 \(f'\)의 계수가 \(nb_n\), \(-na_n\)이다. 코시-슈바르츠와 베셀로 \(\sum|b_n| = \sum\frac1n\cdot n|b_n| \le \left(\sum\frac1{n^2}\right)^{1/2}\left(\sum n^2b_n^2\right)^{1/2} \le \frac\pi{\sqrt6}\|f'\| < \infty\). \(a_n\)도 같다. 따라서 푸리에 급수는 균등수렴한다(M-판정법).
