승수법으로 제약 극값 문제 풀기

본문

닫힌 원판 \(x^2 + y^2 \le 1\)에서 \(f = x^2 + 2y^2 - x\)의 최댓값과 최솟값은 얼마일까? 원판 안에서도, 테두리에서도 극값이 생길 수 있다. 후보를 빠짐없이 모으고 그 가운데서 답을 고르는 절차는 어떻게 될까?

먼저 알아야 할 것라그랑주 승수 정리(3.1절), 임계점의 판정(1.3절), 최대·최소 정리(수학7 3.2절)를 쓴다.

3.2.1절차

승수법은 네 단계로 쓴다. 먼저 최대와 최소가 존재하는지 확인한다. 제약 집합이 유계이고 닫힌 컴팩트 집합이면 연속함수의 최대와 최소가 있다. 다음으로 \(\nabla f = \sum\lambda_i\nabla g_i\)와 제약식 \(g_i = 0\)을 연립해 후보를 모두 구한다. 이때 \(\nabla g_i\)가 일차종속이 되는 점, 곧 정리의 가정이 깨지는 점도 후보에 넣는다. 끝으로 후보에서의 값을 비교한다.

3.2.2예제

예제 3.2.1 (타원체에 내접하는 상자)

\(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1\)에 내접하고 모서리가 좌표축에 평행한 직육면체의 최대 부피를 구하여라.

풀이. 꼭짓점을 \((x, y, z)\) (\(x, y, z > 0\))라 하면 부피는 \(V = 8xyz\)이다. \(\nabla V = \lambda\nabla g\)는 \(8yz = \frac{2\lambda x}{a^2}\), \(8xz = \frac{2\lambda y}{b^2}\), \(8xy = \frac{2\lambda z}{c^2}\)이다. 각각에 \(x, y, z\)를 곱하면 \(8xyz = \frac{2\lambda x^2}{a^2} = \frac{2\lambda y^2}{b^2} = \frac{2\lambda z^2}{c^2}\)이므로 \(\frac{x^2}{a^2} = \frac{y^2}{b^2} = \frac{z^2}{c^2} = \frac13\)이다. 따라서 \(x = \frac a{\sqrt3}\) 등이고 \(V = \frac{8abc}{3\sqrt3}\)이다. \(a = b = c = 1\)이면 약 1.5396으로 구의 부피의 약 37%이다. 제약 집합의 \(x, y, z \ge 0\) 부분은 컴팩트이고 경계에서는 \(V = 0\)이므로 이 후보가 최대이다.

예제 3.2.2 (제약 둘)

원기둥 \(x^2 + y^2 = 1\)과 평면 \(x + y + z = 1\)의 교선 위에서 \(z\)의 최댓값과 최솟값을 구하여라.

풀이. \(\nabla z = (0, 0, 1) = \lambda(2x, 2y, 0) + \mu(1, 1, 1)\)이다. 셋째 성분에서 \(\mu = 1\)이고, 앞의 두 성분에서 \(2\lambda x = 2\lambda y = -1\)이므로 \(x = y\)이다. 그러면 \(x^2 + y^2 = 1\)에서 \(x = y = \pm\frac1{\sqrt2}\)이고 \(z = 1 \mp \sqrt2\)이다. 따라서 최댓값은 \(1 + \sqrt2\), 최솟값은 \(1 - \sqrt2\)이다. 두 그래디언트 \((2x, 2y, 0)\)과 \((1, 1, 1)\)은 교선 위에서 늘 일차독립이므로 다른 후보는 없다.

3.2.3닫힌 영역, 내부와 경계

부등식 제약 \(g \le 0\)이 있으면 영역의 내부에서는 제약 없는 임계점 \(\nabla f = \mathbf 0\)을, 경계 \(g = 0\)에서는 승수법을 쓴다.

예제 3.2.3

닫힌 원판 \(x^2 + y^2 \le 1\)에서 \(f = x^2 + 2y^2 - x\)의 최댓값과 최솟값을 구하여라.

풀이. 내부에서는 \(\nabla f = (2x - 1, 4y) = \mathbf 0\)에서 \((\frac12, 0)\)이고 \(f = -\frac14\)이다. 경계에서는 \((2x - 1, 4y) = \lambda(2x, 2y)\)이고, 둘째 식에서 \(y = 0\) 또는 \(\lambda = 2\)이다. \(y = 0\)이면 \(x = \pm1\)이고 \(f(1, 0) = 0\), \(f(-1, 0) = 2\)이다. \(\lambda = 2\)이면 \(2x - 1 = 4x\)에서 \(x = -\frac12\), \(y = \pm\frac{\sqrt3}2\)이고 \(f = \frac94\)이다. 후보를 비교하면 최댓값은 \(\frac94\), 최솟값은 \(-\frac14\)이며, 그림 1이 이 후보들이다. 격자 \(1001\times1001\)점에서 직접 계산한 값과도 맞는다.

3.2.4승수의 뜻

제약을 \(g(\mathbf x) = c\)로 두고 최적값을 \(V(c)\), 최적점을 \(\mathbf x(c)\)라 하자. 최적점이 매끄럽게 움직인다면 \(V(c) = f(\mathbf x(c))\), \(g(\mathbf x(c)) = c\)이므로 \(V'(c) = \nabla f\cdot\mathbf x'(c) = \lambda\nabla g\cdot\mathbf x'(c) = \lambda\)이다. 다시 말해 제약을 한 단위 느슨하게 할 때 최적값이 \(\lambda\)만큼 늘어난다. 3.1절의 탐구 카드에서 \(f = x + y\), \(g = x^2 + 4y^2\)으로, 같은 절의 예제 카드에서 예산 제약 문제로 확인한다.

흔한 오해연립방정식을 풀 때 \(x\)나 \(\lambda\)로 나누면서 0인 경우를 빠뜨리기 쉽다. 예제 3.2.3의 \(y = 0\)이 그런 경우이다. 또 닫힌 영역에서 경계만 보거나 내부만 보는 실수가 있다. 컴팩트하지 않은 제약 집합에서 후보 가운데 가장 큰 값을 최댓값이라 하는 것도 틀렸으며, 최댓값이 아예 없을 수도 있다.
마무리

처음 질문에 답하면, 원판에서 최솟값은 내부의 \((\frac12, 0)\)에서 \(-\frac14\)이고 최댓값은 경계의 \((-\frac12, \pm\frac{\sqrt3}2)\)에서 \(\frac94\)이다. 절차는 최대와 최소의 존재를 확인하고, 내부의 임계점과 경계의 승수 조건과 가정이 깨지는 점을 모두 후보로 모은 뒤, 값을 비교하는 것이다. 승수 \(\lambda\)는 제약을 느슨하게 할 때 최적값이 변하는 비율이다.

3.2.5연습문제

기본

  1. \(xy = 1\) (\(x, y > 0\)) 위에서 원점까지의 거리의 최솟값을 구하여라.
    답

    \(f = x^2 + y^2\), \((2x, 2y) = \lambda(y, x)\)에서 \(x = y = 1\). 거리 \(\sqrt2\). (컴팩트하지 않지만 \(x \to 0\) 또는 \(\infty\)이면 \(f \to \infty\)라 최소가 존재한다.)

응용

  1. 둘레가 \(p\)인 삼각형 중 넓이가 최대인 것은 정삼각형임을 헤론 공식과 승수법으로 보여라.
    답

    \(s = p/2\), 넓이² \(= s(s - a)(s - b)(s - c)\)를 \(a + b + c = p\)에서 최대화. \(\ln\)을 취해 \(\sum\ln(s - a)\)의 승수 조건 \(\frac{-1}{s - a} = \lambda\) (모든 변에서 같음)이므로 \(a = b = c\).

심화

  1. \(\sum_{i=1}^nx_i = 1\), \(x_i > 0\)에서 \(-\sum x_i\ln x_i\)(엔트로피)의 최댓값을 구하여라.
    답

    \(-\ln x_i - 1 = \lambda\)가 모든 \(i\)에서 같으므로 \(x_i = \frac1n\). 최댓값 \(\ln n\). (경계 \(x_i \to 0\)에서 \(x\ln x \to 0\)이라 연속 확장하면 컴팩트한 단체 위의 최대이고, 함수가 오목이라 이 점이 최대이다.)
