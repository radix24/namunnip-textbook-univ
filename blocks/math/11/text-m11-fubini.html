푸비니 정리: 다중적분을 반복적분으로

본문
이 절에서 배울 것
  • 직사각형 위의 다중적분을 반복적분으로 계산하는 푸비니 정리를 진술하고 증명의 핵심을 안다.
  • 곡선으로 둘러싸인 영역에서 적분 순서를 바꾸는 방법을 익힌다.
  • 가정(적분 가능성)이 없으면 두 반복적분이 다를 수 있음을 반례로 확인한다.
먼저 알아야 할 것
  • 직사각형 위의 적분과 르베그 판정법 (4.1절).

4.2.1정리

정리 4.2.1 (푸비니)

\(A \subseteq \mathbb R^n\), \(B \subseteq \mathbb R^m\)이 닫힌 직사각형이고 \(f: A\times B \to \mathbb R\)이 적분 가능하다고 하자. \(\mathbf x \in A\)마다 \(\underline{\mathcal I}(\mathbf x) = \underline{\int_B}f(\mathbf x, \mathbf y)\,d\mathbf y\) (하적분), \(\overline{\mathcal I}(\mathbf x)\) (상적분)라 하면 두 함수는 \(A\)에서 적분 가능하고

\[\int_{A\times B}f = \int_A\underline{\mathcal I} = \int_A\overline{\mathcal I}.\]

특히 모든 \(\mathbf x\)에서 \(\mathbf y \mapsto f(\mathbf x, \mathbf y)\)가 적분 가능하면(예: \(f\)가 연속) \(\int_{A\times B}f = \int_A\left(\int_Bf(\mathbf x, \mathbf y)\,d\mathbf y\right)d\mathbf x\)이고, 순서를 바꾼 반복적분과도 같다.

증명의 핵심.분할 \(P = (P_A, P_B)\)의 작은 직사각형은 \(S\times T\) (\(S\)는 \(A\)의, \(T\)는 \(B\)의 조각) 꼴이다. \(\mathbf x \in S\)이면 \(\underline{\mathcal I}(\mathbf x) \ge \sum_T m_T(f(\mathbf x, \cdot))v(T) \ge \sum_Tm_{S\times T}(f)\,v(T)\)이므로

\[L(f, P) = \sum_S\sum_Tm_{S\times T}(f)\,v(T)\,v(S) \le \sum_Sm_S(\underline{\mathcal I})\,v(S) = L(\underline{\mathcal I}, P_A).\]

같은 방법으로 \(U(\overline{\mathcal I}, P_A) \le U(f, P)\)이고, \(\underline{\mathcal I} \le \overline{\mathcal I}\)이므로 \(L(f, P) \le L(\underline{\mathcal I}, P_A) \le U(\underline{\mathcal I}, P_A) \le U(\overline{\mathcal I}, P_A) \le U(f, P)\) (가운데 부등식도 같은 식). \(f\)가 적분 가능하므로 양 끝의 차가 임의로 작아져, \(\underline{\mathcal I}\)와 \(\overline{\mathcal I}\) 모두 적분 가능하고 적분이 \(\int f\)와 같다. ∎

4.2.2영역 위의 적분과 순서 바꾸기

영역 \(D = \{(x, y) : a \le x \le b,\ \varphi_1(x) \le y \le \varphi_2(x)\}\) (\(\varphi_i\) 연속)에서 연속함수 \(f\)의 적분은 \(f\chi_D\)에 푸비니 정리를 써서

\[\iint_Df = \int_a^b\left(\int_{\varphi_1(x)}^{\varphi_2(x)}f(x, y)\,dy\right)dx\]

입니다(\(\partial D\)는 그래프와 선분이라 측도 0). 같은 영역을 \(y\)를 바깥으로 해서 다시 묘사하면 순서를 바꿀 수 있습니다.

예제 4.2.2

\(D\)가 \(y = x^2\)과 \(y = \sqrt x\) 사이(\(0 \le x \le 1\))일 때 \(\iint_Dxy^2\,dA\)를 두 순서로 계산하여라.

풀이. \(x\) 먼저 고정: \(\int_0^1\int_{x^2}^{\sqrt x}xy^2\,dy\,dx = \int_0^1\frac x3(x^{3/2} - x^6)\,dx = \frac13\left(\frac27 - \frac18\right) = \frac3{56}\). \(y\) 먼저 고정: \(D = \{y^2 \le x \le \sqrt y,\ 0 \le y \le 1\}\)이므로 \(\int_0^1\int_{y^2}^{\sqrt y}xy^2\,dx\,dy = \int_0^1\frac{y^2}2(y - y^4)\,dy = \frac12\left(\frac14 - \frac17\right) = \frac3{56}\). 수치로는 약 0.053571입니다.

예제 4.2.3 (순서를 바꿔야 풀리는 적분)

\(\int_0^1\int_y^1e^{x^2}\,dx\,dy\)를 계산하여라.

풀이. \(e^{x^2}\)의 원시함수는 기본함수가 아니지만, 영역 \(\{0 \le y \le x \le 1\}\)을 \(x\) 바깥으로 쓰면 \(\int_0^1\int_0^xe^{x^2}\,dy\,dx = \int_0^1xe^{x^2}\,dx = \frac{e - 1}2 \approx 0.8591\).

4.2.3가정이 깨지면

\(f(x, y) = \frac{x^2 - y^2}{(x^2 + y^2)^2}\)을 \([0, 1]^2\)에서 봅시다(원점에서는 아무 값). \(\frac{\partial}{\partial y}\frac{y}{x^2 + y^2} = f\)이므로 \(\int_0^1f(x, y)\,dy = \frac1{1 + x^2}\)이고 \(\int_0^1\frac{dx}{1 + x^2} = \frac\pi4\). 대칭으로 다른 순서는 \(-\frac\pi4\)입니다. 두 반복적분이 다른 이유는 \(f\)가 원점 근처에서 유계가 아니라 리만 적분 가능하지 않고, \(|f|\)의 적분이 발산하기 때문입니다(극좌표로 \(\int\int\frac{|\cos2\theta|}{r^2}r\,dr\,d\theta = \infty\)). 같은 절의 탐구 카드에서 두 경우를 비교합니다.

흔한 오해(1) 순서를 바꿀 때 적분 한계를 그대로 바꿔 쓴다. 영역을 그림으로 다시 묘사해야 한다. (2) "반복적분이 둘 다 존재하면 같다": 위의 반례가 보여 주듯 \(f\)의 (절대) 적분 가능성이 필요하다. (3) 반복적분이 존재해도 다중적분이 존재하지 않을 수 있다.
요약
  1. \(f\)가 \(A\times B\)에서 적분 가능하면 \(\int f = \int_A\int_B f\) (안쪽은 하적분이나 상적분).
  2. 영역 위의 적분은 영역을 경계 곡선으로 묘사해 반복적분으로 계산하고, 순서를 바꿀 때 영역을 다시 묘사한다.
  3. 적분 가능성이 없으면 두 반복적분이 다를 수 있다(\(\pm\pi/4\)).

4.2.4연습문제

기본

  1. \(\int_0^2\int_0^1(x + 2y)\,dy\,dx\)를 계산하고 순서를 바꿔 확인하여라.
    답

    안쪽 \(x + 1\), 바깥 \(\int_0^2(x + 1)\,dx = 4\). 반대로 안쪽 \(2 + 4y\), 바깥 \(\int_0^1(2 + 4y)\,dy = 4\).

응용

  1. \(\int_0^1\int_{\sqrt y}^1\sin(x^3)\,dx\,dy\)를 순서를 바꿔 계산하여라.
    답

    영역 \(\{0 \le y \le x^2,\ 0 \le x \le 1\}\). \(\int_0^1x^2\sin(x^3)\,dx = \frac{1 - \cos1}3 \approx 0.1532\).

심화

  1. \(f\)가 \([a, b]\times[c, d]\)에서 연속이고 \(F(x) = \int_c^df(x, y)\,dy\)이면 \(F\)가 연속임을 보여라. 이것이 푸비니 정리의 "안쪽 적분이 적분 가능" 부분을 어떻게 보완하는가?
    답

    \(f\)는 컴팩트 집합에서 균등연속이라 \(|x - x'| < \delta\)이면 모든 \(y\)에서 \(|f(x, y) - f(x', y)| < \varepsilon\), 따라서 \(|F(x) - F(x')| \le \varepsilon(d - c)\). 연속이면 적분 가능하므로 반복적분이 의미를 가진다.
