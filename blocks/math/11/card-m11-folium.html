곡선을 따라가며 음함수정리 확인하기

탐구 · 데카르트의 엽선

질문

엽선 \(x^3 + y^3 = 3xy\) 위에서 점을 움직입니다. 어느 점 근처에서 곡선이 \(y = g(x)\)의 그래프이고, 어느 점에서 그렇지 않을까요?

복원

\(F_y \ne 0\)이면 \(y = g(x)\)로 풀리고 \(g' = -F_x/F_y\). \(F_x \ne 0\)이면 \(x = h(y)\)로 풀린다 (2.2절). 매개변수 표시 \(\left(\frac{3t}{1 + t^3}, \frac{3t^2}{1 + t^3}\right)\).

해 보기

  1. \(t = 1\)은 점 \((1.5, 1.5)\)이고 \(F_x = F_y = 2.25\), 기울기 \(-1\)입니다(예제 2.2.2).
  2. \(t\)를 0.794로 맞추면 점 \((1.5874, 1.260)\) 근처에서 \(F_y \approx 0\): 접선이 수직이고 \(y\)를 \(x\)로 풀 수 없습니다. 그 점의 좌우로 \(x\)가 1.587을 넘지 못하는 것을 곡선에서 확인하세요.
  3. \(t = 1.26\) 근처에서는 \(F_x = 0\)인 수평 접선입니다. 이번에는 \(y\)를 \(x\)로 풀 수 있지만 \(x\)를 \(y\)로 풀 수 없습니다.
  4. \(t = 0\)(원점)에서는 \(F_x = F_y = 0\)입니다. 원점으로는 \(t \to 0\)과 \(t \to \infty\)의 두 가지가 지나가므로 어느 쪽으로도 풀 수 없습니다.

설명

  1. 그래디언트와 접선\(\nabla F = (F_x, F_y)\)는 곡선에 수직이므로 접선 방향은 \((-F_y, F_x)\)입니다. \(F_y = 0\)이면 접선이 \(y\)축과 평행해 곡선이 \(x\)에 대해 "되돌아"갑니다.
  2. 조건은 충분조건\(F_y \ne 0\)이면 반드시 풀리지만, \(F_y = 0\)인 점에서 꼭 못 푸는 것은 아닙니다. 여기서는 실제로 못 푸는 경우만 나왔을 뿐입니다(본문의 흔한 오해 (2)).

판단

"곡선 전체가 \(y = g(x)\)의 그래프로 쓰인다"는 음함수정리의 결론이 아닙니다. 정리는 \(F_y \ne 0\)인 점마다 그 근처의 작은 창에서만 \(g\)를 줍니다. 엽선은 하나의 \(x\)에 \(y\)가 셋까지 대응하므로 전체적으로는 함수의 그래프가 아닙니다.
