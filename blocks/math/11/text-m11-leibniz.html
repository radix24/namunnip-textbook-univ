적분 기호 아래에서 미분하기

본문
이 절에서 배울 것
  • 매개변수를 가진 적분 \(F(t) = \int_a^bf(x, t)\,dx\)가 연속이고 미분가능할 조건을 증명한다.
  • \(F'(t) = \int_a^b\frac{\partial f}{\partial t}(x, t)\,dx\)를 써서 직접 구하기 어려운 적분을 계산한다.
  • 적분 구간도 \(t\)에 따라 변할 때의 공식을 유도한다.
먼저 알아야 할 것
  • 균등연속(수학7), 평균값 정리, 푸비니 정리 (4.2절), 연쇄 법칙 (1.1절).

4.4.1연속성

정리 4.4.1

\(f\)가 \([a, b]\times[c, d]\)에서 연속이면 \(F(t) = \int_a^bf(x, t)\,dx\)는 \([c, d]\)에서 연속이다.

증명.컴팩트 집합 위의 연속함수라 \(f\)는 균등연속이다. \(\epsilon > 0\)에 대해 \(|t - s| < \delta\)이면 모든 \(x\)에서 \(|f(x, t) - f(x, s)| < \epsilon\)이고, \(|F(t) - F(s)| \le (b - a)\epsilon\). ∎

4.4.2미분가능성

정리 4.4.2 (라이프니츠 규칙)

\(f\)와 \(\frac{\partial f}{\partial t}\)가 \([a, b]\times[c, d]\)에서 연속이면 \(F'(t) = \displaystyle\int_a^b\frac{\partial f}{\partial t}(x, t)\,dx\).

증명 방향: 차분몫을 평균값 정리로 \(\frac{\partial f}{\partial t}\)의 값으로 바꾸고, 다시 균등연속으로 극한과 적분을 바꿉니다.

증명.\(\frac{F(t + h) - F(t)}h = \int_a^b\frac{f(x, t + h) - f(x, t)}h\,dx = \int_a^bf_t(x, t + \theta_xh)\,dx\) (\(0 < \theta_x < 1\), 평균값 정리). \(f_t\)의 균등연속으로 \(|h| < \delta\)이면 피적분함수가 모든 \(x\)에서 \(f_t(x, t)\)와 \(\epsilon\) 이내이므로, 차분몫과 \(\int_a^bf_t(x, t)\,dx\)의 차는 \((b - a)\epsilon\) 이하이다. ∎

푸비니로도 증명할 수 있습니다. \(G(t) = \int_a^bf_t\,dx\)를 \(c\)부터 \(t\)까지 적분하고 순서를 바꾸면 \(\int_a^b[f(x, t) - f(x, c)]dx = F(t) - F(c)\)이므로, 미적분의 기본정리로 \(F' = G\)입니다.

예 4.4.3

\(\int_0^1x^t\,dx = \frac1{t + 1}\) (\(t > -1\))을 \(t\)로 미분하면 \(\int_0^1x^t\ln x\,dx = -\frac1{(t + 1)^2}\). 다시 미분하면 \(\int_0^1x^t(\ln x)^2dx = \frac2{(t + 1)^3}\). 부분적분 없이 얻었습니다. (\(x = 0\) 근처에서 정리의 가정이 깨지는 부분은 \([\epsilon, 1]\)에서 적용한 뒤 \(\epsilon \to 0\)으로 처리합니다.)

4.4.3구간도 움직일 때

\(F(t) = \int_{a(t)}^{b(t)}f(x, t)\,dx\)는 세 변수 함수 \(\Phi(u, v, t) = \int_u^vf(x, t)\,dx\)에 \(u = a(t)\), \(v = b(t)\)를 넣은 것이므로 연쇄 법칙과 미적분의 기본정리로

\[F'(t) = f(b(t), t)\,b'(t) - f(a(t), t)\,a'(t) + \int_{a(t)}^{b(t)}\frac{\partial f}{\partial t}(x, t)\,dx.\]
흔한 오해(1) 언제나 미분과 적분을 바꿀 수 있다고 여긴다: 무한 구간이나 피적분함수가 발산할 때는 균등 수렴 같은 추가 조건이 필요하다. (2) 구간이 \(t\)에 의존할 때 경계 항을 빠뜨린다. (3) \(x\)에 대한 편미분과 \(t\)에 대한 편미분을 혼동한다.
요약
  1. \(f\) 연속이면 \(F\) 연속(균등연속).
  2. \(f, f_t\) 연속이면 \(F' = \int f_t\,dx\)(평균값 정리 또는 푸비니).
  3. 구간이 움직이면 경계 항 \(f(b, t)b' - f(a, t)a'\)이 더해진다.

4.4.4연습문제

기본

  1. \(F(t) = \int_0^t\sin(tx)\,dx\)의 도함수를 구하여라.
    답

    \(F' = \sin(t^2) + \int_0^tx\cos(tx)\,dx\). 직접 계산하면 \(F = \frac{1 - \cos t^2}t\)이고 미분해서 같은 값을 확인할 수 있다.

응용

  1. \(\int_0^\pi\ln(1 - 2t\cos x + t^2)\,dx\) (\(|t| < 1\))를 \(t\)로 미분하는 방법을 써서 구하여라.
    답

    도함수의 피적분함수를 계산하면 적분이 0이 되어(\(|t| < 1\)) 값은 \(t = 0\)일 때의 값 0이다.

심화

  1. \(I(t) = \int_0^\infty e^{-x^2}\cos(2tx)\,dx\)가 \(I' = -2tI\)를 만족함을 보이고 \(I(t)\)를 구하여라(미분과 적분의 교환은 인정).
    답

    \(I' = -\int2xe^{-x^2}\sin(2tx)dx\)를 부분적분하면 \(-2tI\). \(I(0) = \frac{\sqrt\pi}2\)이므로 \(I = \frac{\sqrt\pi}2e^{-t^2}\). \(t = 1\)에서 약 0.3260.
