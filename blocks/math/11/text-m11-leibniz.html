적분 기호 아래에서 미분하기

본문

\(\int_0^1x^t\ln x\,dx\)는 부분적분으로 구할 수 있지만 조금 번거롭다. 그런데 \(\int_0^1x^t\,dx = \frac1{t + 1}\)을 \(t\)로 미분하면 바로 답이 나올 것 같다. 적분 기호 안에서 미분해도 될까? 된다면 어떤 조건에서일까?

먼저 알아야 할 것균등연속(수학7), 평균값 정리, 푸비니 정리(4.2절), 연쇄 법칙(1.1절)을 쓴다.

4.4.1연속성

정리 4.4.1

\(f\)가 \([a, b]\times[c, d]\)에서 연속이면 \(F(t) = \int_a^bf(x, t)\,dx\)는 \([c, d]\)에서 연속이다.

증명.컴팩트 집합 위의 연속함수이므로 \(f\)는 균등연속이다. 따라서 \(\epsilon > 0\)에 대해 \(\delta\)가 있어 \(|t - s| < \delta\)이면 모든 \(x\)에서 \(|f(x, t) - f(x, s)| < \epsilon\)이고, 그러면 \(|F(t) - F(s)| \le (b - a)\epsilon\)이다. ∎

4.4.2미분 가능성

정리 4.4.2 (라이프니츠 규칙)

\(f\)와 \(\frac{\partial f}{\partial t}\)가 \([a, b]\times[c, d]\)에서 연속이면 \(F'(t) = \displaystyle\int_a^b\frac{\partial f}{\partial t}(x, t)\,dx\)이다.

증명의 방향은 차분몫을 평균값 정리로 \(\frac{\partial f}{\partial t}\)의 값으로 바꾸고, 다시 균등연속으로 극한과 적분을 바꾸는 것이다.

증명.평균값 정리로 \(\frac{F(t + h) - F(t)}h = \int_a^b\frac{f(x, t + h) - f(x, t)}h\,dx = \int_a^bf_t(x, t + \theta_xh)\,dx\)이고 \(0 < \theta_x < 1\)이다. \(f_t\)가 균등연속이므로 \(|h| < \delta\)이면 피적분함수가 모든 \(x\)에서 \(f_t(x, t)\)와 \(\epsilon\) 이내이다. 따라서 차분몫과 \(\int_a^bf_t(x, t)\,dx\)의 차는 \((b - a)\epsilon\) 이하이다. ∎

푸비니 정리로도 증명할 수 있다. \(G(t) = \int_a^bf_t\,dx\)를 \(c\)부터 \(t\)까지 적분하고 순서를 바꾸면 \(\int_a^b[f(x, t) - f(x, c)]dx = F(t) - F(c)\)이므로, 미적분의 기본정리로 \(F' = G\)이다.

예제 4.4.3

\(\int_0^1x^t\,dx = \frac1{t + 1}\) (\(t > -1\))을 써서 \(\int_0^1x^t\ln x\,dx\)와 \(\int_0^1x^t(\ln x)^2dx\)를 구하여라.

풀이. \(t\)로 미분하면 \(\int_0^1x^t\ln x\,dx = -\frac1{(t + 1)^2}\)이고, 다시 미분하면 \(\int_0^1x^t(\ln x)^2dx = \frac2{(t + 1)^3}\)이다. 부분적분 없이 얻었으며 그림 1이 이 함수들이다. 다만 \(x = 0\) 근처에서는 정리의 가정이 깨지므로, 정확히는 \([\epsilon, 1]\)에서 적용한 뒤 \(\epsilon \to 0\)으로 처리한다.

4.4.3구간도 움직일 때

\(F(t) = \int_{a(t)}^{b(t)}f(x, t)\,dx\)는 세 변수 함수 \(\Phi(u, v, t) = \int_u^vf(x, t)\,dx\)에 \(u = a(t)\), \(v = b(t)\)를 넣은 것이다. 그러므로 연쇄 법칙과 미적분의 기본정리로 다음을 얻는다.

\[F'(t) = f(b(t), t)\,b'(t) - f(a(t), t)\,a'(t) + \int_{a(t)}^{b(t)}\frac{\partial f}{\partial t}(x, t)\,dx.\]

예를 들어 \(F(t) = \int_0^te^{-tx}\,dx\)이면 경계 항 \(e^{-t^2}\)과 적분 항 \(-\int_0^txe^{-tx}\,dx\)를 더해 \(F'(t)\)를 얻는다. 즉 구간이 움직이면 경계에서 들어오고 나가는 양을 함께 세어야 한다.

흔한 오해언제나 미분과 적분을 바꿀 수 있다고 여기기 쉽다. 하지만 무한 구간이거나 피적분함수가 발산할 때는 균등 수렴 같은 추가 조건이 필요하다. 또 구간이 \(t\)에 의존할 때 경계 항을 빠뜨리는 실수가 많다. \(x\)에 대한 편미분과 \(t\)에 대한 편미분을 혼동하는 것도 주의한다.
마무리

처음 질문의 답은 "된다"이다. \(f\)와 \(\partial f/\partial t\)가 닫힌 직사각형에서 연속이면 \(\frac{d}{dt}\int_a^bf\,dx = \int_a^b\frac{\partial f}{\partial t}\,dx\)이며, 증명은 평균값 정리와 균등연속이다. 그래서 \(\int_0^1x^t\,dx = \frac1{t + 1}\)을 미분하면 \(\int_0^1x^t\ln x\,dx = -\frac1{(t + 1)^2}\)이 나온다. 구간이 \(t\)에 따라 움직이면 경계 항 \(f(b, t)b' - f(a, t)a'\)을 더한다.

4.4.4연습문제

기본

  1. \(F(t) = \int_0^t\sin(tx)\,dx\)의 도함수를 구하여라.
    답

    \(F' = \sin(t^2) + \int_0^tx\cos(tx)\,dx\). 직접 계산하면 \(F = \frac{1 - \cos t^2}t\)이고 미분해서 같은 값을 확인할 수 있다.

응용

  1. \(\int_0^\pi\ln(1 - 2t\cos x + t^2)\,dx\) (\(|t| < 1\))를 \(t\)로 미분하는 방법을 써서 구하여라.
    답

    도함수의 피적분함수를 계산하면 적분이 0이 되어(\(|t| < 1\)) 값은 \(t = 0\)일 때의 값 0이다.

심화

  1. \(I(t) = \int_0^\infty e^{-x^2}\cos(2tx)\,dx\)가 \(I' = -2tI\)를 만족함을 보이고 \(I(t)\)를 구하여라(미분과 적분의 교환은 인정).
    답

    \(I' = -\int2xe^{-x^2}\sin(2tx)dx\)를 부분적분하면 \(-2tI\). \(I(0) = \frac{\sqrt\pi}2\)이므로 \(I = \frac{\sqrt\pi}2e^{-t^2}\). \(t = 1\)에서 약 0.3260.
