다변수 테일러 정리와 극값 판정

본문

일변수에서는 \(f'(a) = 0\)이고 \(f''(a) > 0\)이면 극소였다. 두 변수 함수 \(x^3 + y^3 - 3xy\)는 \((0, 0)\)과 \((1, 1)\)에서 기울기가 0이다. 이 두 점은 극대일까, 극소일까, 둘 다 아닐까? 2계 도함수가 여러 개일 때는 무엇을 보아야 할까?

먼저 알아야 할 것일변수 테일러 정리(수학7 4.1절), 연쇄 법칙(1.1절), 혼합 편도함수의 대칭(1.2절)과 대칭 행렬의 대각화를 쓴다.

1.3.1선분 위로 줄이기

\(f\)가 \(\mathbf p\)를 포함하는 볼록 열린집합에서 \(C^k\)라 하고 \(\varphi(t) = f(\mathbf p + t\mathbf h)\)로 둔다. 연쇄 법칙을 되풀이하면 \(\varphi'(t) = \sum_i h_iD_if(\mathbf p + t\mathbf h)\)이고 \(\varphi''(t) = \mathbf h^TH(\mathbf p + t\mathbf h)\mathbf h\)이다. 여기서 \(H = (D_{ij}f)\)는 헤세 행렬이며 \(C^2\)이므로 대칭이다. 일변수 테일러 정리를 \(\varphi\)에 쓰면 다음을 얻는다.

정리 1.3.1 (2차 테일러 정리)

\(f\)가 \(C^2\)이고 선분 \([\mathbf p, \mathbf p + \mathbf h]\)가 정의역 안에 있으면, 어떤 \(c \in (0, 1)\)에 대해 \(f(\mathbf p + \mathbf h) = f(\mathbf p) + \nabla f(\mathbf p)\cdot\mathbf h + \tfrac12\mathbf h^TH(\mathbf p + c\mathbf h)\mathbf h\)이다. 또 \(f(\mathbf p + \mathbf h) = f(\mathbf p) + \nabla f(\mathbf p)\cdot\mathbf h + \tfrac12\mathbf h^TH(\mathbf p)\mathbf h + o(|\mathbf h|^2)\)이다.

증명.첫 식은 \(\varphi(1) = \varphi(0) + \varphi'(0) + \frac12\varphi''(c)\)이다. 둘째 식은 \(|\mathbf h^T(H(\mathbf p + c\mathbf h) - H(\mathbf p))\mathbf h| \le \|H(\mathbf p + c\mathbf h) - H(\mathbf p)\|\,|\mathbf h|^2\)이고, \(H\)의 연속성으로 그 노름이 0으로 가기 때문이다. ∎

예를 들어 \(f = e^x\cos y\)의 원점에서 \(\nabla f = (1, 0)\)이고 \(H = \mathrm{diag}(1, -1)\)이므로 2차 근사는 \(1 + x + \frac12(x^2 - y^2)\)이다. \((0.1, 0.2)\)에서 참값은 1.083141, 근사는 1.085이고, 차 \(-0.00186\)은 3차 항 \(\frac{x^3}6 - \frac{xy^2}2 = -0.00183\)과 거의 같다. 일반적으로 \(C^k\)이면 \(\varphi^{(m)}(0) = (\mathbf h\cdot\nabla)^mf(\mathbf p)\)로 \(k\)차 테일러 다항식을 쓴다.

1.3.2임계점의 판정

\(\nabla f(\mathbf p) = \mathbf 0\)인 점을 임계점이라 한다. 각 좌표 방향의 일변수 함수가 극값을 가져야 하므로, 미분 가능한 함수의 극값은 임계점에서만 생긴다. 임계점에서는 테일러 정리의 1차 항이 사라지므로 2차 형식 \(Q(\mathbf h) = \mathbf h^TH(\mathbf p)\mathbf h\)가 모양을 정한다.

정리 1.3.2 (2계 판정법)

\(f\)가 \(C^2\)이고 \(\nabla f(\mathbf p) = \mathbf 0\)이라 하자. (a) \(H(\mathbf p)\)가 양정치, 곧 고유값이 모두 양수이면 \(\mathbf p\)는 엄격한 극소점이다. (b) 음정치이면 엄격한 극대점이다. (c) 양수와 음수 고유값이 모두 있으면 극값이 아닌 안장점이다.

증명.(a) \(\lambda > 0\)을 \(H(\mathbf p)\)의 가장 작은 고유값이라 하면 직교대각화로 \(Q(\mathbf h) \ge \lambda|\mathbf h|^2\)이다. 정리 1.3.1의 나머지 \(r(\mathbf h)\)가 \(o(|\mathbf h|^2)\)이므로 \(\delta > 0\)이 있어 \(0 < |\mathbf h| < \delta\)이면 \(|r(\mathbf h)| < \frac\lambda4|\mathbf h|^2\)이다. 그러면 \(f(\mathbf p + \mathbf h) - f(\mathbf p) \ge \frac\lambda2|\mathbf h|^2 - \frac\lambda4|\mathbf h|^2 > 0\)이다. (b)는 \(-f\)에 (a)를 쓴다. (c) 고유값 \(\lambda_1 > 0 > \lambda_2\)의 단위 고유벡터 방향으로 \(t \mapsto f(\mathbf p + t\mathbf u_i)\)를 보면, \(\varphi_i''(0) = \lambda_i\)이므로 각각 엄격한 극소와 엄격한 극대를 가진다. 따라서 \(\mathbf p\) 근방에 \(f(\mathbf p)\)보다 큰 값과 작은 값이 모두 있다. ∎

2변수에서는 고유값 대신 \(D = f_{xx}f_{yy} - f_{xy}^2 = \det H\)와 \(f_{xx}\)를 본다. \(\det H\)는 두 고유값의 곱이므로, \(D > 0\)이고 \(f_{xx} > 0\)이면 극소, \(D > 0\)이고 \(f_{xx} < 0\)이면 극대, \(D < 0\)이면 안장점이다.

예제 1.3.3

\(f(x, y) = x^3 + y^3 - 3xy\)의 임계점을 모두 찾아 판정하여라.

풀이. \(f_x = 3x^2 - 3y = 0\), \(f_y = 3y^2 - 3x = 0\)에서 \(y = x^2\)이고 \(x = y^2 = x^4\)이므로, 실수 범위에서 \(x = 0\) 또는 \(x = 1\)이다. 임계점은 \((0, 0)\)과 \((1, 1)\)이다. \(H = \begin{pmatrix}6x & -3\\-3 & 6y\end{pmatrix}\)이고 \((0, 0)\)에서 \(D = -9 < 0\)이므로 안장점이다. \((1, 1)\)에서는 \(D = 36 - 9 = 27 > 0\), \(f_{xx} = 6 > 0\)이므로 극소점이고 극솟값은 \(f(1, 1) = -1\)이다. 하지만 \(x \to -\infty\)이면 \(f \to -\infty\)이므로 이 극소는 전역 최소가 아니다.

1.3.3판정이 안 될 때

\(H(\mathbf p)\)에 0인 고유값이 있으면, 곧 \(D = 0\)이면 2차 항만으로는 알 수 없다. 예를 들어 원점에서 \(x^2 + y^4\)은 극소이고 \(x^2 - y^4\)과 \(x^2 + y^3\)은 안장점인데, 세 함수의 헤세 행렬은 모두 \(\mathrm{diag}(2, 0)\)이다. 이때는 고차 항이나 직접적인 부등식으로 판단해야 한다. 또 고유값이 모두 0 이상인 양의 준정치는 극소의 필요조건일 뿐 충분조건이 아니다. 같은 절의 탐구 카드에서 헤세 행렬의 성분과 고차항을 바꾸며 등고선이 타원, 쌍곡선, 평행선으로 바뀌는 것을 본다.

흔한 오해"모든 좌표축 방향으로 극소이면 극소"는 틀렸다. \(f = (y - x^2)(y - 3x^2)\)은 원점을 지나는 모든 직선 위에서 원점이 극소이지만, 포물선 \(y = 2x^2\) 위에서는 \(f = -x^4 < 0\)이라 극소가 아니다. 이때 \(H\)는 퇴화한다. 또 \(D > 0\)만 보고 극소라 하는 실수도 있으며, \(f_{xx}\)의 부호도 봐야 한다.
마무리

처음 질문에 답하면, \(x^3 + y^3 - 3xy\)에서 \((0, 0)\)은 \(D = -9 < 0\)이라 안장점이고 \((1, 1)\)은 \(D = 27 > 0\), \(f_{xx} > 0\)이라 극소점이다. 여러 변수에서는 2계 도함수들을 모은 헤세 행렬을 보아야 하며, 2차 테일러 정리에 따라 임계점 근처의 모양은 2차 형식 \(\mathbf h^TH\mathbf h\)가 정한다. 고유값이 모두 양수이면 극소, 모두 음수이면 극대, 부호가 섞이면 안장점이고, 0인 고유값이 있으면 판정이 안 된다.

1.3.4연습문제

기본

  1. \(f = x^2 + xy + y^2 - 3x\)의 임계점을 찾아 판정하여라.
    답

    \(2x + y = 3\), \(x + 2y = 0\)에서 \((2, -1)\). \(H = \begin{pmatrix}2 & 1\\1 & 2\end{pmatrix}\), \(D = 3 > 0\), \(f_{xx} > 0\): 극소, \(f(2, -1) = -3\).

응용

  1. \(f = \sin x\sin y\)의 2차 테일러 다항식을 \((\frac\pi2, \frac\pi2)\)에서 구하고 그 점을 판정하여라.
    답

    \(\nabla f = (\cos x\sin y, \sin x\cos y) = \mathbf 0\), \(H = \begin{pmatrix}-1 & 0\\0 & -1\end{pmatrix}\). 2차 다항식 \(1 - \frac12(u^2 + v^2)\) (\(u = x - \frac\pi2\), \(v = y - \frac\pi2\)). 극대점.

심화

  1. 흔한 오해 (1)의 \(f = (y - x^2)(y - 3x^2)\)이 원점을 지나는 모든 직선 위에서 원점에 극소를 가짐을 보여라.
    답

    \(y\)축 위에서 \(f = y^2\). 직선 \(y = mx\) 위에서 \(f = (mx - x^2)(mx - 3x^2)\)이고 \(m \ne 0\)이면 작은 \(x\)에서 두 인수가 모두 \(mx\)와 같은 부호라 \(f > 0\) (\(x \ne 0\)). \(m = 0\)이면 \(f = 3x^4 > 0\).
