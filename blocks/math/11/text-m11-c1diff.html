편도함수가 연속이면 미분가능하다

본문

일변수에서는 도함수가 있으면 미분 가능했다. 두 변수 함수 \(f = \frac{xy}{x^2 + y^2}\)는 원점에서 두 편도함수가 모두 0으로 존재하지만, 원점에서 연속조차 아니다. 그렇다면 편도함수에 무엇을 더 요구해야 미분 가능성이 보장될까?

먼저 알아야 할 것전미분의 정의(1.1절)와 일변수 평균값 정리를 쓴다.

1.4.1편도함수만으로는 부족하다

편도함수 \(f_x, f_y\)는 좌표축 방향의 변화만 본다. 그러므로 다른 방향에서 함수가 엉뚱하게 움직여도 알 수 없다.

예 1.4.1

\(f(x, y) = \frac{xy}{x^2 + y^2}\), \(f(0, 0) = 0\)이라 하자. 두 축 위에서 \(f = 0\)이므로 \(f_x(0, 0) = f_y(0, 0) = 0\)이다. 그러나 직선 \(y = x\) 위에서 \(f = \frac12\)이라 원점에서 연속도 아니고, 따라서 미분 가능하지 않다.

연속이어도 부족하다. 같은 절의 예제에서는 모든 방향도함수가 있고 함수가 연속인데도 미분 가능하지 않은 경우를 본다. 즉 편도함수의 존재는 미분 가능성에 관해 거의 아무것도 말해 주지 않는다.

1.4.2충분조건

정리 1.4.2

열린집합 \(U \subset \mathbb R^n\)에서 \(f: U \to \mathbb R\)의 편도함수들이 \(\mathbf a\)의 근방에서 존재하고 \(\mathbf a\)에서 연속이면, \(f\)는 \(\mathbf a\)에서 미분 가능하고 \(Df(\mathbf a) = (f_{x_1}(\mathbf a), \dots, f_{x_n}(\mathbf a))\)이다.

증명의 방향은 \(\mathbf a\)에서 \(\mathbf a + \mathbf h\)까지 한 번에 한 좌표씩 움직이는 계단 경로를 만들고, 각 계단에서 일변수 평균값 정리를 쓰는 것이다. 그러면 각 계단의 변화가 근처 점의 편도함수로 표현되고, 연속성이 그것을 \(\mathbf a\)의 편도함수에 묶어 준다.

증명.\(n = 2\)로 쓴다. \(\mathbf h = (h, k)\)에 대해 \(f(a + h, b + k) - f(a, b) = [f(a + h, b + k) - f(a, b + k)] + [f(a, b + k) - f(a, b)]\)이다. 평균값 정리로 첫째 괄호는 \(f_x(a + \theta h, b + k)h\)이고 둘째 괄호는 \(f_y(a, b + \theta'k)k\)이다(\(0 < \theta, \theta' < 1\)). 따라서 \(f(\mathbf a + \mathbf h) - f(\mathbf a) - f_x(\mathbf a)h - f_y(\mathbf a)k = [f_x(a + \theta h, b + k) - f_x(\mathbf a)]h + [f_y(a, b + \theta'k) - f_y(\mathbf a)]k\)이다. \(|h|, |k| \le |\mathbf h|\)이고 대괄호들은 \(\mathbf h \to \mathbf 0\)에서 편도함수의 연속성으로 0으로 가므로, 우변을 \(|\mathbf h|\)로 나눈 것이 0으로 간다. ∎

여기서 연속성이 필요한 것은 평균값 정리가 주는 점 \((a + \theta h, b + k)\)가 \(\mathbf a\)가 아니라 그 근처이기 때문이다. 다시 말해 근처의 편도함수가 \(\mathbf a\)의 편도함수에 가까워야 오차가 \(|\mathbf h|\)보다 빨리 작아진다.

1.4.3세 조건의 관계

세 조건 사이에는 한 방향의 함의만 있다. 편도함수가 모두 존재하고 연속인 \(C^1\)이면 미분 가능하고, 미분 가능하면 연속이며 모든 방향도함수가 \(D_{\mathbf u}f = \nabla f\cdot\mathbf u\)로 존재한다. 하지만 역 방향은 모두 거짓이며, 미분 가능하지만 \(C^1\)이 아닌 예는 연습문제 3에 있다. 그래도 실제로 쓰는 함수 대부분은 \(C^1\)이라, 정리 1.4.2가 미분 가능성을 확인하는 가장 흔한 방법이다.

흔한 오해편도함수가 있으면 미분 가능하다고 여기기 쉽지만, 일변수와 달리 예 1.4.1처럼 거짓이다. 또 정리 1.4.2의 역을 쓰는 실수가 있으며, 미분 가능해도 편도함수가 연속이 아닐 수 있다. 모든 방향의 방향도함수가 있으면 미분 가능하다는 것도 틀렸다. 방향도함수가 \(\mathbf u\)에 대해 선형이어야 하고, 그래도 충분하지 않다.
마무리

처음 질문에 답하면, 편도함수가 \(\mathbf a\)의 근방에서 존재하고 \(\mathbf a\)에서 연속이면 \(f\)는 \(\mathbf a\)에서 미분 가능하다. 증명은 한 좌표씩 움직이는 계단 경로에서 평균값 정리를 쓰고, 연속성으로 오차를 \(|\mathbf h|\)보다 작게 만드는 것이다. 편도함수의 존재만으로는 \(\frac{xy}{x^2 + y^2}\)처럼 연속조차 보장되지 않는다. 그래서 \(C^1\)이면 미분 가능하고, 미분 가능하면 연속이며 방향도함수가 있지만, 역은 모두 거짓이다.

1.4.4연습문제

기본

  1. \(f(x, y) = e^x\sin y + x^2y\)가 \(\mathbb R^2\)의 모든 점에서 미분가능함을 보여라.
    답

    \(f_x = e^x\sin y + 2xy\), \(f_y = e^x\cos y + x^2\)이 연속이므로 정리 1.4.2.

응용

  1. \(f(x, y) = \sqrt{|xy|}\)는 원점에서 편도함수가 있는가? 미분가능한가?
    답

    축 위에서 0이라 \(f_x = f_y = 0\). 미분가능하면 \(Df = 0\)이어야 하는데 \(y = x\) 위에서 \(f = |x|\)이고 \(\frac{|x|}{\sqrt2|x|} \not\to 0\)이므로 미분가능하지 않다.

심화

  1. \(f(x, y) = (x^2 + y^2)\sin\frac1{\sqrt{x^2 + y^2}}\), \(f(0, 0) = 0\)이 원점에서 미분가능하지만 \(f_x\)가 원점에서 연속이 아님을 보여라.
    답

    \(|f| \le |\mathbf h|^2\)이라 \(Df(\mathbf 0) = 0\). \(x\)축 위에서 \(f_x = 2x\sin\frac1{|x|} - \frac{x}{|x|}\cos\frac1{|x|}\)이고 둘째 항이 0 근처에서 진동하므로 극한이 없다.
