편도함수가 연속이면 미분가능하다

본문
이 절에서 배울 것
  • 편도함수가 존재해도 미분가능하지 않은 예를 본다.
  • 편도함수가 한 점의 근방에서 존재하고 그 점에서 연속이면 미분가능함을 증명한다.
  • 미분가능, 편미분 가능, \(C^1\)의 관계를 정리한다.
먼저 알아야 할 것
  • 전미분의 정의 (1.1절), 일변수 평균값 정리.

1.4.1편도함수만으로는 부족하다

편도함수 \(f_x, f_y\)는 좌표축 방향의 변화만 봅니다. 다른 방향에서 함수가 엉뚱하게 움직여도 알 수 없습니다.

예 1.4.1

\(f(x, y) = \frac{xy}{x^2 + y^2}\), \(f(0, 0) = 0\). 두 축 위에서 \(f = 0\)이므로 \(f_x(0, 0) = f_y(0, 0) = 0\). 그러나 직선 \(y = x\) 위에서 \(f = \frac12\)이라 원점에서 연속도 아니고, 따라서 미분가능하지 않다.

연속이어도 부족합니다. 같은 절의 예제에서 모든 방향도함수가 있고 연속인데도 미분가능하지 않은 함수를 봅니다.

1.4.2충분조건

정리 1.4.2

\(f: U \to \mathbb R\) (\(U \subset \mathbb R^n\) 열린집합)의 편도함수들이 \(\mathbf a\)의 근방에서 존재하고 \(\mathbf a\)에서 연속이면 \(f\)는 \(\mathbf a\)에서 미분가능하고 \(Df(\mathbf a) = (f_{x_1}(\mathbf a), \dots, f_{x_n}(\mathbf a))\)이다.

증명 방향: \(\mathbf a\)에서 \(\mathbf a + \mathbf h\)까지 한 번에 한 좌표씩 움직이는 계단 경로를 만들고, 각 계단에서 일변수 평균값 정리를 씁니다.

증명.\(n = 2\)로 쓴다. \(\mathbf h = (h, k)\)에 대해 \(f(a + h, b + k) - f(a, b) = [f(a + h, b + k) - f(a, b + k)] + [f(a, b + k) - f(a, b)]\). 평균값 정리로 첫째 괄호는 \(f_x(a + \theta h, b + k)h\), 둘째는 \(f_y(a, b + \theta'k)k\) (\(0 < \theta, \theta' < 1\)). 따라서

\[f(\mathbf a + \mathbf h) - f(\mathbf a) - f_x(\mathbf a)h - f_y(\mathbf a)k = [f_x(a + \theta h, b + k) - f_x(\mathbf a)]h + [f_y(a, b + \theta'k) - f_y(\mathbf a)]k.\]

\(|h|, |k| \le |\mathbf h|\)이고 대괄호들은 \(\mathbf h \to \mathbf 0\)에서 편도함수의 연속성으로 0으로 가므로, 우변을 \(|\mathbf h|\)로 나눈 것이 0으로 간다. ∎

1.4.3세 조건의 관계

\(C^1\) (편도함수가 모두 존재하고 연속) ⟹ 미분가능 ⟹ 연속이고 모든 방향도함수 존재(\(D_{\mathbf u}f = \nabla f\cdot\mathbf u\)). 역 방향은 모두 거짓입니다. 미분가능하지만 \(C^1\)이 아닌 예는 연습문제 3에 있습니다. 실제로 쓰는 함수 대부분은 \(C^1\)이라, 정리 1.4.2가 미분가능성을 확인하는 가장 흔한 방법입니다.

흔한 오해(1) 편도함수가 있으면 미분가능하다고 여긴다: 일변수와 달리 거짓이다(예 1.4.1). (2) 정리 1.4.2의 역을 쓴다: 미분가능해도 편도함수가 연속이 아닐 수 있다. (3) 방향도함수가 모든 방향에서 있으면 미분가능하다고 여긴다: 방향도함수가 \(\mathbf u\)에 대해 선형이어야 하고, 그래도 충분하지 않다.
요약
  1. 편도함수가 존재해도 연속조차 아닐 수 있다.
  2. 편도함수가 근방에서 존재하고 그 점에서 연속 ⟹ 미분가능(계단 경로와 평균값 정리).
  3. \(C^1\) ⟹ 미분가능 ⟹ 방향도함수 존재, 역은 거짓.

1.4.4연습문제

기본

  1. \(f(x, y) = e^x\sin y + x^2y\)가 \(\mathbb R^2\)의 모든 점에서 미분가능함을 보여라.
    답

    \(f_x = e^x\sin y + 2xy\), \(f_y = e^x\cos y + x^2\)이 연속이므로 정리 1.4.2.

응용

  1. \(f(x, y) = \sqrt{|xy|}\)는 원점에서 편도함수가 있는가? 미분가능한가?
    답

    축 위에서 0이라 \(f_x = f_y = 0\). 미분가능하면 \(Df = 0\)이어야 하는데 \(y = x\) 위에서 \(f = |x|\)이고 \(\frac{|x|}{\sqrt2|x|} \not\to 0\)이므로 미분가능하지 않다.

심화

  1. \(f(x, y) = (x^2 + y^2)\sin\frac1{\sqrt{x^2 + y^2}}\), \(f(0, 0) = 0\)이 원점에서 미분가능하지만 \(f_x\)가 원점에서 연속이 아님을 보여라.
    답

    \(|f| \le |\mathbf h|^2\)이라 \(Df(\mathbf 0) = 0\). \(x\)축 위에서 \(f_x = 2x\sin\frac1{|x|} - \frac{x}{|x|}\cos\frac1{|x|}\)이고 둘째 항이 0 근처에서 진동하므로 극한이 없다.
