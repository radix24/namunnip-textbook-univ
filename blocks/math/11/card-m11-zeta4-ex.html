파서벌 등식으로 Σ1/n⁴ 구하기

예제 · 삼각파의 푸리에 계수

먼저 예측

\(\sum\frac1{n^4} = 1 + \frac1{16} + \frac1{81} + \cdots\)는 1.05보다 클까, 작을까?

예측 확인

약 1.0823으로 크다. 첫 세 항만 더해도 1.0748이다.

\(f(x) = |x|\) (\(-\pi \le x \le \pi\))의 푸리에 계수를 구하고 파서벌 등식으로 \(\sum_{n=1}^\infty\frac1{n^4} = \frac{\pi^4}{90}\)을 보여라.

전략

짝함수라 코사인 계수만 있다. 파서벌로 홀수 \(n\)에 대한 \(\sum\frac1{n^4}\)을 얻고, 짝수 항을 \(\frac1{16}\sum\frac1{n^4}\)로 보충한다 (6.2절).

풀이

  1. \(a_0 = \frac1\pi\int_{-\pi}^\pi|x|\,dx = \pi\). \(n \ge 1\)이면 \(a_n = \frac2\pi\int_0^\pi x\cos nx\,dx = \frac2\pi\cdot\frac{(-1)^n - 1}{n^2}\), 곧 홀수 \(n\)에서 \(-\frac4{\pi n^2}\), 짝수에서 0.
    부분적분: \(\int_0^\pi x\cos nx\,dx = \left[\frac{x\sin nx}n\right]_0^\pi + \left[\frac{\cos nx}{n^2}\right]_0^\pi\).
  2. \(\frac1\pi\int_{-\pi}^\pi x^2\,dx = \frac{2\pi^2}3\).
    \(\|f\|^2\).
  3. 파서벌 등식 \(\frac{2\pi^2}3 = \frac{\pi^2}2 + \sum a_n^2\)에서 홀수 \(n\)에 대한 \(\sum\frac{16}{\pi^2n^4}\)이 \(\frac{2\pi^2}3 - \frac{\pi^2}2 = \frac{\pi^2}6\)과 같다. 따라서 홀수 \(n\)에 대한 \(\sum\frac1{n^4} = \frac{\pi^4}{96}\).
    \(\frac{a_0^2}2 = \frac{\pi^2}2\).
  4. 전체 합 \(Z = \sum\frac1{n^4}\)에서 짝수 항의 합은 \(\frac Z{16}\)이므로 \(Z - \frac Z{16} = \frac{\pi^4}{96}\), \(Z = \frac{\pi^4}{96}\cdot\frac{16}{15} = \frac{\pi^4}{90}\).
    \(\frac{\pi^4}{90} \approx 1.082323\).

검산

홀수 \(n < 200000\)까지 \(\frac1{n^4}\)을 더하면 1.0146780316으로 \(\frac{\pi^4}{96} \approx 1.0146780316\)과 소수 열째 자리까지 같다. 6.1절 탐구 카드의 삼각파에서 \(N = 10\)일 때 평균제곱오차가 0.00026으로 작았던 것도 계수가 \(\frac1{n^2}\)로 빨리 줄기 때문이다.

의미

\(\zeta(2) = \frac{\pi^2}6\), \(\zeta(4) = \frac{\pi^4}{90}\)처럼 짝수에서의 제타 값은 \(\pi\)의 거듭제곱의 유리수배이다. \(x^3\), \(x^4\) 같은 다항식에 같은 방법을 쓰면 \(\zeta(6), \zeta(8), \dots\)도 얻는다. 홀수 \(\zeta(3)\)은 이런 꼴로 알려져 있지 않는다.

이해 확인

\(|x|\)의 푸리에 급수에 \(x = 0\)을 넣어 홀수 \(n\)에 대한 \(\sum\frac1{n^2}\)을 구하여라(급수는 연속이고 조각마다 매끄러운 함수에서 점별수렴한다, 6.3절).

답

\(|0| = 0 = \frac\pi2 - \frac4\pi S\) (\(S\)는 홀수 \(n\)에 대한 \(\sum\frac1{n^2}\))이므로 \(S = \frac{\pi^2}8\). 6.2절 연습문제 1과 같은 값이다.
