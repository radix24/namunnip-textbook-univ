|x|에 가장 가까운 이차식

예제 · 르장드르 전개로 최소제곱 근사

먼저 예측

\(|x|\)는 0에서 미분할 수 없어 테일러 다항식이 없습니다. \([-1, 1]\)에서 평균제곱오차가 가장 작은 이차식 \(a + bx^2\)의 \(a\)는 0보다 클까요?

예측 확인

그렇습니다. \(a = \frac3{16}\)으로, 0 근처에서는 위로 떠 있고 대신 양 끝을 덜 넘칩니다.

\([-1, 1]\)에서 \(f(x) = |x|\)의 차수 2 이하 최소제곱 근사 \(p\)와 오차 \(\int_{-1}^1(f - p)^2\)를 구하고, 상수 근사의 오차와 비교하여라.

전략

\(c_k = \frac{2k + 1}2\int_{-1}^1fP_k\) (6.4절)를 \(k = 0, 1, 2\)에 대해 계산합니다. \(f\)가 짝함수라 \(c_1 = 0\)입니다.

풀이

  1. \(c_0 = \frac12\int_{-1}^1|x|dx = \frac12\).
    \(\int|x| = 1\).
  2. \(c_1 = 0\), \(c_2 = \frac52\cdot2\int_0^1x\cdot\frac{3x^2 - 1}2dx = \frac52\cdot\left(\frac34 - \frac12\right) = \frac58\).
    짝함수라 \([0, 1]\)의 두 배.
  3. \(p = \frac12 + \frac58\cdot\frac{3x^2 - 1}2 = \frac3{16} + \frac{15}{16}x^2\).
    정리.
  4. 오차 \(= \|f\|^2 - c_0^2\cdot2 - c_2^2\cdot\frac25 = \frac23 - \frac12 - \frac{5}{32} = \frac1{96} \approx 0.0104\).
    \(\|f\|^2 = \int x^2 = \frac23\).

검산

\(\int_{-1}^1(|x| - p)^2dx\)를 수치 적분하면 0.0104167로 \(\frac1{96}\)과 같습니다. 상수 근사(\(p = \frac12\))의 오차는 \(\frac23 - \frac12 = \frac16 \approx 0.167\)이라 이차항을 넣으면 오차가 16분의 1로 줄어듭니다.

의미

미분할 수 없는 점이 있어도 평균적으로 가장 좋은 다항식 근사는 언제나 있습니다. 계수를 내적으로 하나씩 구할 수 있는 것은 직교 기저 덕분이며, 같은 생각이 푸리에 급수(6.1절)와 수치해석의 스펙트럴 방법에 쓰입니다.

답
