일반화 스토크스 정리

본문

미적분학의 기본정리, 그린 정리, 스토크스 정리, 발산 정리는 모두 "안쪽에서의 미분을 적분하면 경계에서의 값과 같다"는 모양이다. 이것들은 정말 하나의 정리일까? 그렇다면 그 증명의 알맹이는 무엇일까?

먼저 알아야 할 것미분형식과 외미분(5.1절), 변수변환 공식(4.3절), 푸비니 정리(4.2절)를 쓴다.

5.2.1형식의 적분

\(k\)차원 매개화 \(\Phi: D \to \mathbb R^n\) (\(D \subseteq \mathbb R^k\))가 있을 때 \(k\)-형식 \(\omega\)의 적분은 \(\omega\)를 \(D\)로 당겨서 \(k\)차원 적분으로 계산한다. 여기서 당김 \(\Phi^*\omega\)는 \(\omega\)의 \(x_i\)에 \(\Phi_i(\mathbf u)\)를, \(dx_i\)에 \(d\Phi_i = \sum_j\frac{\partial\Phi_i}{\partial u_j}du_j\)를 대입한 \(D\) 위의 형식이다.

그러면 \(\int_\Phi\omega = \int_D\Phi^*\omega\)이고, \(D\) 위의 \(a(\mathbf u)\,du_1\wedge\cdots\wedge du_k\)의 적분은 보통의 적분 \(\int_Da\)이다. 예를 들어 곡선 \(\gamma\)에서 \(\gamma^*(P\,dx + Q\,dy) = (P\gamma_1' + Q\gamma_2')\,dt\)로 익숙한 선적분이 된다. 또 \(\Phi^*(dx\wedge dy) = \det\Phi'\,du\wedge dv\)이므로 변수변환 공식이 형식의 언어에 자연스럽게 들어 있으며, 절댓값 대신 방향이 부호를 정한다. 한편 \(\Phi\)의 경계 \(\partial\Phi\)는 \(D\)의 경계를 방향을 맞추어 \(\Phi\)로 옮긴 것이다. 정사각형 \(D = [0, 1]^2\)이면 네 변을 반시계 방향으로 도는 곡선들의 형식적 합이다.

5.2.2정리

정리 5.2.1 (일반화 스토크스 정리)

\(\Omega\)가 방향이 있는 \(k\)차원 \(C^2\) 체인이고 \(\omega\)가 그 근방에서 \(C^1\)인 \((k - 1)\)-형식이면 \(\int_{\partial\Omega}\omega = \int_\Omega d\omega\)이다.

정사각형에서의 계산.\(\Omega = [0, 1]^2\), \(\omega = P\,dx\)라 하자. \(Q\,dy\)도 같다. \(d\omega = -P_y\,dx\wedge dy\)이므로 푸비니 정리와 미적분학의 기본정리로 \(\int_\Omega d\omega = -\int_0^1\int_0^1P_y\,dy\,dx = -\int_0^1(P(x, 1) - P(x, 0))\,dx\)이다. 경계에서 \(dx\)는 아래 변(\(x\)가 0에서 1로)과 위 변(\(x\)가 1에서 0으로)에서만 0이 아니므로 \(\int_{\partial\Omega}\omega = \int_0^1P(x, 0)\,dx - \int_0^1P(x, 1)\,dx\)이다. 두 값이 같다. ∎

일반적인 경우는 세 단계로 끝난다. 먼저 단위 정육면체에서 위와 같은 계산을 한다. 다음으로 당김이 \(d\)와 교환된다는 사실 \(\Phi^*d\omega = d\Phi^*\omega\)와 변수변환으로 일반 매개화에 옮긴다. 끝으로 조각들을 붙일 때 맞닿은 변의 적분이 반대 방향이라 상쇄된다는 것을 쓴다. 그러므로 정리의 증명은 결국 일변수 기본정리를 한 방향으로 쓰는 것이다.

5.2.3고전 정리들

\(k\)\(\Omega\)정리식
1구간 \([a, b]\)미적분학의 기본정리\(f(b) - f(a) = \int_a^bf'\)
1곡선 \(\gamma\)선적분의 기본정리\(f(\gamma(b)) - f(\gamma(a)) = \int_\gamma\nabla f\cdot d\mathbf r\)
2평면 영역 \(D\)그린 정리\(\oint_{\partial D}P\,dx + Q\,dy = \iint_D(Q_x - P_y)\,dA\)
2곡면 \(S\)스토크스 정리\(\oint_{\partial S}\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S\)
3입체 \(V\)발산 정리(가우스)\(\iint_{\partial V}\mathbf F\cdot d\mathbf S = \iiint_V\nabla\cdot\mathbf F\,dV\)

각 줄은 5.1절의 대응표에 따라 \(\omega\)를 0-형식, 1-형식, 2-형식으로 고른 것이다. 예를 들어 그린 정리는 \(\omega = P\,dx + Q\,dy\), \(d\omega = (Q_x - P_y)\,dx\wedge dy\)인 경우이다.

예제 5.2.2

그린 정리로 타원 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} \le 1\)의 넓이를 구하여라.

풀이. \(\omega = \frac12(-y\,dx + x\,dy)\)이면 \(d\omega = dx\wedge dy\)이므로 넓이는 \(\oint_{\partial D}\omega\)이다. \(\gamma(t) = (a\cos t, b\sin t)\)이면 \(\gamma^*\omega = \frac12(ab\sin^2t + ab\cos^2t)\,dt = \frac{ab}2dt\)이고, 적분하면 \(\pi ab\)이다. 경계의 정보만으로 넓이를 재는 것이 측면계(플라니미터)의 원리이다.

5.2.4구멍과 위상

\(\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}\)은 \(d\omega = 0\)인데 단위원에서 \(\oint\omega = 2\pi\)이다. 이것이 스토크스 정리에 모순이 아닌 이유는 원점에서 \(\omega\)가 정의되지 않아 단위원판 전체에서 쓸 수 없기 때문이다. 원점을 감싸지 않는 닫힌 곡선에서는 적분이 0이고, 감싸는 곡선에서는 감는 횟수에 \(2\pi\)를 곱한 값이다. 즉 닫힌 형식의 적분이 영역의 구멍을 감지하며, 이 관찰이 드람 코호몰로지(수학23 대수적위상수학)의 출발점이다. 같은 절의 탐구 카드에서 확인한다.

흔한 오해영역을 왼쪽에 두고 도는 경계의 방향을 무시해 부호가 틀리는 실수가 많다. 또 형식이 영역 전체에서 매끄러운지 확인하지 않고 정리를 쓰기 쉬운데, 구멍이 있으면 틀린다. "\(\partial\partial\Omega = \varnothing\)"과 "\(d^2 = 0\)"이 서로 짝이라는 점도 놓치기 쉽다. 실제로 \(\int_\Omega d(d\eta) = \int_{\partial\partial\Omega}\eta = 0\)이다.
마무리

처음 질문의 답은 "하나의 정리이다"이다. 일반화 스토크스 정리 \(\int_{\partial\Omega}\omega = \int_\Omega d\omega\)에서 \(\omega\)를 0-형식, 1-형식, 2-형식으로 고르면 기본정리, 그린 정리, 스토크스 정리, 발산 정리가 나온다. 증명의 알맹이는 정사각형에서 푸비니 정리와 일변수 기본정리를 쓰는 계산이며, 당김과 변수변환으로 일반 영역에 옮기고 맞닿은 변의 상쇄로 조각을 붙인다. 형식이 정의되지 않는 구멍이 있으면 정리를 쓸 수 없다.

5.2.5연습문제

기본

  1. 그린 정리로 \(\oint_C(x^2 - y)\,dx + (x + y^2)\,dy\)를 구하여라. \(C\)는 단위원(반시계).
    답

    \(Q_x - P_y = 1 - (-1) = 2\). \(\iint 2\,dA = 2\pi\).

응용

  1. 발산 정리로 \(\mathbf F = (x, y, z)\)의 단위구면 밖으로 나가는 선속을 구하고 직접 계산과 비교하여라.
    답

    \(\nabla\cdot\mathbf F = 3\), \(\iiint 3\,dV = 3\cdot\frac43\pi = 4\pi\). (직접) 구면에서 \(\mathbf F\cdot\mathbf n = |\mathbf x|^2 = 1\)이므로 선속 = 겉넓이 \(4\pi\).

심화

  1. \(\Phi(u, v)\)가 곡면을 매개화하면 \(\Phi^*(d\omega) = d(\Phi^*\omega)\)를 1-형식 \(\omega = f\,dx_i\)에 대해 확인하여라.
    답

    \(\Phi^*\omega = (f\circ\Phi)\,d\Phi_i\). \(d(\Phi^*\omega) = d(f\circ\Phi)\wedge d\Phi_i\) (\(d(d\Phi_i) = 0\)). 한편 \(\Phi^*(df\wedge dx_i) = \Phi^*(df)\wedge d\Phi_i = d(f\circ\Phi)\wedge d\Phi_i\) (연쇄 법칙이 \(\Phi^*df = d(f\circ\Phi)\)). 같다.
