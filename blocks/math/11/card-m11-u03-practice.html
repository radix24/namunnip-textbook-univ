라그랑주 승수 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(x^2 + y^2 + z^2 = 9\) 위에서 \(f = x + 2y + 2z\)의 최댓값과 최솟값을 구하여라. [03-02]

    힌트 1

    \((1, 2, 2) = 2\lambda(x, y, z)\).

    힌트 2

    \((x, y, z)\)는 \((1, 2, 2)\)의 배수.

    풀이

    \((x, y, z) = t(1, 2, 2)\), \(9t^2 = 9\), \(t = \pm1\). 최댓값 \(f(1, 2, 2) = 9\), 최솟값 \(-9\) (3.2절).

  2. 계산곡선 \(x^2 + xy + y^2 = 3\) 위에서 원점까지 거리의 최댓값과 최솟값을 구하여라. [03-02]

    힌트 1

    \(f = x^2 + y^2\), \((2x, 2y) = \lambda(2x + y, x + 2y)\).

    힌트 2

    두 식을 빼고 더하면 \(y = x\) 또는 \(y = -x\).

    풀이

    \(y = x\)이면 \(3x^2 = 3\), 점 \(\pm(1, 1)\), 거리 \(\sqrt2\). \(y = -x\)이면 \(x^2 = 3\), 점 \(\pm(\sqrt3, -\sqrt3)\), 거리 \(\sqrt6\). 최대 \(\sqrt6\), 최소 \(\sqrt2\) (타원이라 컴팩트).

  3. 계산정사각형 \([0, 2]^2\)에서 \(f = x^2 - 2x + y^2 - 4y\)의 최댓값과 최솟값을 구하여라. [03-02]

    힌트 1

    내부 임계점, 네 변, 네 꼭짓점.

    힌트 2

    \(f = (x - 1)^2 + (y - 2)^2 - 5\).

    풀이

    최솟값은 \((1, 2)\)(변 위)에서 \(-5\). 최댓값은 \((1, 2)\)에서 가장 먼 꼭짓점 \((0, 0)\), \((2, 0)\)에서 \(1 + 4 - 5 = 0\). 완성제곱으로 보면 거리의 제곱에서 5를 뺀 것이다.

  4. 증명산술-기하 평균 부등식 \(\sqrt[n]{x_1\cdots x_n} \le \frac{x_1 + \cdots + x_n}n\) (\(x_i > 0\))을 승수법으로 증명하여라. [03-01]

    힌트 1

    \(\sum x_i = n\)에서 \(\prod x_i\)의 최댓값.

    힌트 2

    \(\prod_{j \ne i}x_j = \lambda\)가 모든 \(i\)에서 같다.

    풀이

    동차성으로 \(\sum x_i = n\)일 때 \(\prod x_i \le 1\)을 보이면 된다. 집합 \(\{x_i \ge 0, \sum x_i = n\}\)은 컴팩트라 최대가 있고, 경계(어떤 \(x_i = 0\))에서는 곱이 0이므로 최대는 내부에서 승수 조건 \(\frac{P}{x_i} = \lambda\) (\(P = \prod x_j\))를 만족한다. 따라서 모든 \(x_i\)가 같아 \(x_i = 1\), 최댓값 1. ∎

  5. 계산예산 \(x + 4y = c\)에서 \(f = \sqrt{xy}\)를 최대로 하는 점과 승수를 구하고 \(V'(c) = \lambda\)를 확인하여라. [03-02]

    힌트 1

    \(\frac{f_x}{f_y} = \frac yx = \frac14\).

    힌트 2

    \(x = 4y\), 예산을 반씩.

    풀이

    \(x = \frac c2\), \(y = \frac c8\), \(V = \sqrt{c^2/16} = \frac c4\). \(\lambda = f_x = \frac12\sqrt{y/x} = \frac12\cdot\frac12 = \frac14 = V'(c)\).

  6. 판단\(y^2 = x^3\) 위에서 \(f = x\)의 최솟값을 승수법으로 구했더니 \((1, 0) = \lambda(-3x^2, 2y)\)를 만족하는 점이 없어 "최솟값이 없다"고 결론지었다. 옳은가? [03-01]

    힌트 1

    \(\nabla g = \mathbf 0\)인 점.

    힌트 2

    곡선 위에서 \(x = |y|^{2/3} \ge 0\).

    풀이

    옳지 않다. 원점에서 \(\nabla g = (-3x^2, 2y) = \mathbf 0\)이라 승수 정리의 가정이 깨지며, 원점이 최솟점(\(f = 0\))이다. \(\nabla g = \mathbf 0\)인 점은 따로 후보에 넣어야 한다 (3.1절).
