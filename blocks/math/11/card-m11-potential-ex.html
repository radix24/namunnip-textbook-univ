공간의 닫힌 형식에서 퍼텐셜 만들기

예제 · 선분 적분 공식으로 퍼텐셜 구하기

먼저 예측

\(\omega = (2xy + z)\,dx + x^2\,dy + x\,dz\)가 어떤 함수 \(f\)의 \(df\)일까? 그렇다면 \(f\)는?

예측 확인

그렇다. \(f = x^2y + xz\) (상수 차이).

\(\omega\)가 \(\mathbb R^3\)에서 닫혀 있음을 확인하고, 푸앵카레 보조정리의 공식으로 퍼텐셜 \(f\)를 구하여라. 또 점 \((0, 0, 0)\)에서 \((1, 2, 3)\)까지 아무 곡선을 따라 \(\omega\)를 적분한 값을 구하여라.

전략

닫힘 조건 세 개를 확인한 뒤 \(f(\mathbf x) = \int_0^1\sum a_i(t\mathbf x)x_i\,dt\)(5.3절)를 계산한다. 완전 형식의 선적분은 끝점의 \(f\) 값 차이이다.

풀이

  1. \(a_1 = 2xy + z\), \(a_2 = x^2\), \(a_3 = x\). \(\partial_ya_1 = 2x = \partial_xa_2\), \(\partial_za_1 = 1 = \partial_xa_3\), \(\partial_za_2 = 0 = \partial_ya_3\).
    닫힘(\(\mathbb R^3\)의 말로 회전이 0).
  2. \(\sum a_i(t\mathbf x)x_i = (2t^2xy + tz)x + t^2x^2\cdot y + tx\cdot z = 3t^2x^2y + 2txz\).
    각 \(a_i\)에 \(t\mathbf x\)를 넣음.
  3. \(f = \int_0^1(3t^2x^2y + 2txz)\,dt = x^2y + xz\).
    \(\int_0^13t^2 = 1\), \(\int_0^12t = 1\).
  4. 선적분 \(= f(1, 2, 3) - f(0, 0, 0) = 2 + 3 = 5\).
    스토크스 정리의 0차원 판(경로 무관).

검산

\(df = (2xy + z)\,dx + x^2\,dy + x\,dz\)로 \(\omega\)와 같다. 직선 \((t, 2t, 3t)\)를 따라 직접 적분해도 \(\int_0^1[(4t^2 + 3t) + 2t^2 + 3t]dt = 2 + 3 = 5\)이다.

의미

물리에서 보존력의 위치 에너지를 구하는 것과 같은 계산이다. 선분 공식은 "원점에서 출발해 곧장 가는 경로"를 정해 놓은 것으로, 영역이 별 모양이기만 하면 언제나 쓸 수 있다.

이해 확인

\(\omega = (2xy + z)\,dx + x^2\,dy + y\,dz\)는 완전인가?

답

\(\partial_za_1 = 1 \ne 0 = \partial_xa_3\)이라 닫혀 있지 않으므로 완전이 아니다.
