혼합 편도함수의 대칭성

본문

\(x\)로 먼저 미분하고 \(y\)로 미분한 것과, 순서를 바꾼 것은 늘 같을까? 대부분의 함수에서는 같지만, 2계 편도함수가 모두 존재하는데도 두 값이 다른 함수가 있다. 그렇다면 순서를 바꿔도 되는 조건은 무엇일까?

먼저 알아야 할 것평균값 정리(수학7 4.1절), 편도함수와 연속미분가능성(수학7 8.2절)을 쓴다.

1.2.1순서가 중요한 예

\(D_1 = \partial/\partial x\), \(D_2 = \partial/\partial y\)로 쓰고, 먼저 \(x\)로, 다음 \(y\)로 미분한 것을 \(D_{21}f = D_2(D_1f)\)로 약속한다. 교재마다 \(f_{xy}\)의 순서 약속이 다르므로 이 표기를 쓴다.

예제 1.2.1

\(f(x, y) = \frac{xy(x^2 - y^2)}{x^2 + y^2}\) (\((x, y) \ne \mathbf 0\)), \(f(\mathbf 0) = 0\)이면 \(D_{21}f(\mathbf 0) = -1\), \(D_{12}f(\mathbf 0) = 1\)임을 보여라.

풀이. \(y \ne 0\)일 때 \(D_1f(0, y) = \lim_{h\to0}\frac{f(h, y) - f(0, y)}h = \lim_{h\to0}\frac{y(h^2 - y^2)}{h^2 + y^2} = -y\)이고, \(D_1f(0, 0) = 0\)도 \(-y\)에 맞는다. 따라서 \(D_{21}f(\mathbf 0) = \frac{d}{dy}(-y) = -1\)이다. 같은 방법으로 \(D_2f(x, 0) = x\)이므로 \(D_{12}f(\mathbf 0) = 1\)이다. 수치로 확인해도 중심 차분으로 \(-0.999998\)과 \(0.999998\)이 나온다.

이 함수는 \(C^1\)이다. 원점 밖에서 매끄럽고 \(|D_1f|, |D_2f| \le |\mathbf x|\)라 원점에서도 연속이기 때문이다. 문제는 2계 편도함수가 원점에서 연속이 아니라는 데 있다. 극좌표로 쓰면 \(f = \frac{r^2}4\sin 4\theta\)이고, 2계 편도함수는 \(\theta\)만의 함수가 되어 원점으로 다가가는 방향마다 다른 값을 가진다.

1.2.22차 차분

두 순서를 공평하게 다루는 양으로 \(\Delta(h, k) = f(a + h, b + k) - f(a + h, b) - f(a, b + k) + f(a, b)\)를 생각한다. 이 식은 \(x\)와 \(y\)에 대해 대칭인 모양이다. \(\frac{\Delta(h, k)}{hk} = \frac1k\left[\frac{f(a + h, b + k) - f(a, b + k)}h - \frac{f(a + h, b) - f(a, b)}h\right]\)에서 먼저 \(h \to 0\)으로 보내면 대괄호가 \(D_1f(a, b + k) - D_1f(a, b)\)가 되고, 다음 \(k \to 0\)이면 \(D_{21}f(a, b)\)가 나온다. 반대 순서이면 존재할 때 \(D_{12}f(a, b)\)이다. 예제 1.2.1에서 \((a, b) = \mathbf 0\)이면 \(\frac{\Delta(h, k)}{hk} = \frac{h^2 - k^2}{h^2 + k^2}\)로 방향에만 의존하므로, 그림 1처럼 극한의 순서에 따라 \(\pm1\)이 된다. 같은 절의 탐구 카드에서 이 값을 방향별로 본다.

1.2.3슈바르츠 정리

정리 1.2.2 (슈바르츠, 클레로)

\(E \subseteq \mathbb R^2\)이 열린집합이고 \(D_1f\), \(D_2f\), \(D_{21}f\)가 \(E\)에서 존재하며 \(D_{21}f\)가 \((a, b) \in E\)에서 연속이면, \(D_{12}f(a, b)\)가 존재하고 \(D_{12}f(a, b) = D_{21}f(a, b)\)이다.

생각은 이렇다. \(\Delta(h, k)\)에 평균값 정리를 두 번 써서 근처의 한 점 \((\xi, \eta)\)에서의 값 \(hk\,D_{21}f(\xi, \eta)\)로 만들면, \(D_{21}f\)의 연속성으로 \(\Delta/(hk)\)가 \(h, k\)를 함께 작게 할 때 \(D_{21}f(a, b)\)에 가까워진다. 그 뒤에 \(h\)를 고정하고 \(k \to 0\)을 먼저 보내면 \(D_{12}f\)의 정의가 나온다.

증명.\(A = D_{21}f(a, b)\), \(\varepsilon > 0\)이라 하자. 연속성으로 \(\delta > 0\)이 있어 \(|x - a|, |y - b| < \delta\)이면 \((x, y) \in E\)이고 \(|D_{21}f(x, y) - A| < \varepsilon\)이다. \(0 < |h|, |k| < \delta\)를 고정하고 \(u(t) = f(t, b + k) - f(t, b)\)라 하면 \(\Delta(h, k) = u(a + h) - u(a)\)이다. \(u\)는 미분 가능하므로 평균값 정리로 \(a\)와 \(a + h\) 사이의 \(\xi\)가 있어 \(\Delta(h, k) = h\,[D_1f(\xi, b + k) - D_1f(\xi, b)]\)이다. 다시 \(y \mapsto D_1f(\xi, y)\)에 평균값 정리를 쓰면 \(b\)와 \(b + k\) 사이의 \(\eta\)가 있어 \(\Delta(h, k) = hk\,D_{21}f(\xi, \eta)\)이다. \((\xi, \eta)\)는 \((a, b)\)에서 가로세로 \(\delta\) 이내에 있으므로 \(\left|\frac{\Delta(h, k)}{hk} - A\right| < \varepsilon\)이다. 이제 \(\Delta\)를 거꾸로 묶어 \(\frac{\Delta(h, k)}{hk} = \frac1h\left[\frac{f(a + h, b + k) - f(a + h, b)}k - \frac{f(a, b + k) - f(a, b)}k\right]\)로 쓴다. \(h\)를 고정하고 \(k \to 0\)으로 보내면 대괄호는 \(D_2f(a + h, b) - D_2f(a, b)\)로 가고, 부등식은 극한에서 \(\le\)로 남는다. 따라서 \(0 < |h| < \delta\)이면 \(\left|\frac{D_2f(a + h, b) - D_2f(a, b)}h - A\right| \le \varepsilon\)이고, \(\varepsilon\)이 임의이므로 \(D_{12}f(a, b)\)가 존재하고 \(A\)와 같다. ∎

정리는 \(D_{21}f\) 한쪽의 연속성만 가정하고 다른 쪽의 존재까지 결론으로 얻는다. 실제로 쓸 때는 대개 "\(f \in C^2\)이면 혼합 편도함수는 순서와 무관하다"로 충분하다.

1.2.4고계 도함수

\(k\)계까지의 모든 편도함수가 존재하고 연속인 함수를 \(C^k\) 함수라 하고, 모든 \(k\)에 대해 그러면 \(C^\infty\)라 한다. 정리 1.2.2를 되풀이하면 \(f \in C^k\)일 때 \(k\)계 이하의 편도함수는 미분하는 순서와 무관하다. 예를 들어 \(D_{112}f = D_{121}f = D_{211}f\)이다. 그래서 다중지표 \(\alpha = (\alpha_1, \dots, \alpha_n)\)로 \(D^\alpha f = D_1^{\alpha_1}\cdots D_n^{\alpha_n}f\)처럼 쓸 수 있다.

좌표 없이 보면 2계 도함수 \(f''(\mathbf p)\)는 쌍선형 사상 \((\mathbf u, \mathbf v) \mapsto \sum_{i,j}D_{ij}f(\mathbf p)u_iv_j = \mathbf u^TH\mathbf v\)이고, 그 행렬 \(H\)가 헤세 행렬이다. 다시 말해 슈바르츠 정리는 "\(C^2\)이면 헤세 행렬이 대칭"이라는 뜻이며, 대칭 행렬이므로 직교대각화되어 1.3절의 극값 판정에 쓰인다.

흔한 오해"편도함수가 모두 존재하면 순서를 바꿔도 된다"는 틀렸다. 예제 1.2.1은 원점을 포함해 2계 편도함수가 모두 존재하지만 순서에 따라 값이 다르다. 필요한 것은 존재가 아니라 연속성이다.
마무리

처음 질문에 답하면, 혼합 편도함수가 늘 같은 것은 아니다. 예제 1.2.1에서는 \(D_{21}f(\mathbf 0) = -1\), \(D_{12}f(\mathbf 0) = 1\)이며, 2차 차분 몫이 방향에만 의존하기 때문이다. 순서를 바꿔도 되는 조건은 한쪽 혼합 편도함수의 연속성이고(슈바르츠 정리), 증명은 2차 차분에 평균값 정리를 두 번 쓰는 것이다. 그래서 \(C^2\) 함수의 헤세 행렬은 대칭이다.

1.2.5연습문제

기본

  1. \(f = x^3y^2 + e^{xy}\)의 \(D_{12}f\)와 \(D_{21}f\)를 직접 계산해 같음을 확인하여라.
    답

    \(D_1f = 3x^2y^2 + ye^{xy}\), \(D_{21}f = 6x^2y + e^{xy} + xye^{xy}\). \(D_2f = 2x^3y + xe^{xy}\), \(D_{12}f = 6x^2y + e^{xy} + xye^{xy}\). 같다.

응용

  1. 예제 1.2.1의 \(f\)가 극좌표로 \(\frac{r^2}4\sin4\theta\)임을 보여라.
    답

    \(xy = \frac{r^2}2\sin2\theta\), \(\frac{x^2 - y^2}{x^2 + y^2} = \cos2\theta\)이므로 \(f = \frac{r^2}2\sin2\theta\cos2\theta = \frac{r^2}4\sin4\theta\).

심화

  1. \(\mathbf F = (P, Q)\)가 \(C^1\)이고 어떤 \(C^2\) 함수 \(f\)에 대해 \(\mathbf F = \nabla f\)이면 \(D_2P = D_1Q\)임을 보여라. 역은 \(\mathbb R^2 \setminus \{\mathbf 0\}\)에서 성립하는가?
    답

    \(P = D_1f\), \(Q = D_2f\)이므로 \(D_2P = D_{21}f\), \(D_1Q = D_{12}f\)이고, \(f \in C^2\)이므로 슈바르츠 정리로 같다. (역은 일반적으로 거짓) \(\mathbf F = \left(\frac{-y}{x^2 + y^2}, \frac{x}{x^2 + y^2}\right)\)은 조건을 만족하지만 단위원을 한 바퀴 도는 선적분이 \(2\pi\)라 그래디언트가 아니다(5단원).
