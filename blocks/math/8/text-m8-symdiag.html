실대칭 행렬의 직교 대각화

본문
이 절에서 배울 것
  • 실대칭 행렬이 실직교 행렬로 대각화된다는 실 스펙트럼 정리를 안다.
  • 고유값, 고유공간, 고유공간 안의 그람-슈미트로 \(A = QDQ^T\)를 구한다.
  • 스펙트럼 분해 \(A = \sum\lambda_i\mathbf q_i\mathbf q_i^T\)의 기하학적 뜻을 안다.
먼저 알아야 할 것
  • 스펙트럼 정리 (3.2절), 에르미트 행렬의 고유값은 실수 (2.2절), 그람-슈미트.

3.3.1실 스펙트럼 정리

정리 3.3.1

실정사각행렬 \(A\)가 대칭(\(A^T = A\))일 필요충분조건은 \(A = QDQ^T\)인 실직교 행렬 \(Q\)와 실대각행렬 \(D\)가 있는 것이다.

⇐는 \((QDQ^T)^T = QDQ^T\)로 바로 나옵니다. ⇒: 실대칭은 에르미트이므로 고유값이 모두 실수입니다. 실고유값이면 실고유벡터를 잡을 수 있으므로 슈어 정리의 증명을 모두 실수 범위에서 할 수 있고(\(U\)가 실직교), 3.2절의 보조정리로 \(T\)가 대각입니다.

3.3.2계산 절차

  1. 특성방정식으로 고유값 \(\lambda_1, \dots, \lambda_k\)를 구한다(모두 실수).
  2. 각 고유공간 \(N(A - \lambda_jI)\)의 기저를 구한다.
  3. 각 고유공간 안에서 그람-슈미트로 정규직교화한다. 서로 다른 고유공간은 이미 직교하므로(정리 2.2.2) 따로 할 필요가 없다.
  4. 모두 모아 \(Q\)의 열로, 고유값을 같은 순서로 \(D\)의 대각에 놓는다.
예제 3.3.2

\(A = \begin{pmatrix}2 & 1 & 1\\1 & 2 & 1\\1 & 1 & 2\end{pmatrix}\)를 직교 대각화하여라.

풀이. \(A = I + J\) (\(J\)는 모든 성분이 1). \(J\)의 고유값은 3(벡터 \((1,1,1)\))과 0(중복도 2, 합이 0인 벡터들)이므로 \(A\)의 고유값은 4, 1, 1입니다.

  • \(\lambda = 4\): \(\mathbf q_1 = \frac1{\sqrt3}(1, 1, 1)\).
  • \(\lambda = 1\): 고유공간은 \(x + y + z = 0\). 기저 \((1, -1, 0)\), \((1, 0, -1)\)에 그람-슈미트: \(\mathbf q_2 = \frac1{\sqrt2}(1, -1, 0)\), \((1, 0, -1) - \frac12(1, -1, 0) = (\frac12, \frac12, -1)\)을 정규화해 \(\mathbf q_3 = \frac1{\sqrt6}(1, 1, -2)\).

\(Q = (\mathbf q_1\ \mathbf q_2\ \mathbf q_3)\), \(D = \mathrm{diag}(4, 1, 1)\). 검산: \(\mathbf q_1\)은 \(\mathbf q_2, \mathbf q_3\)과 자동으로 직교하고, \(\operatorname{tr}A = 6 = 4 + 1 + 1\), \(\det A = 4\)입니다.

3.3.3스펙트럼 분해의 그림

\(A = \sum\lambda_i\mathbf q_i\mathbf q_i^T\)를 벡터 \(\mathbf x\)에 적용하면 \(A\mathbf x = \sum\lambda_i(\mathbf q_i^T\mathbf x)\mathbf q_i\)입니다. 곧 (1) \(\mathbf x\)를 서로 수직인 고유 방향 성분으로 나누고, (2) 각 성분을 고유값 배로 늘이거나 줄이고, (3) 다시 더합니다. 대칭 행렬은 "직교하는 축을 따라 각자 늘이는" 변환이고 회전 성분이 없습니다. 예제에서 \(A\)는 \((1,1,1)\) 방향을 4배, 그에 수직인 평면을 그대로(1배) 둡니다. 같은 절의 탐구 카드에서 벡터를 끌어 이 분해를 볼 수 있습니다.

흔한 실수(1) 중복 고유값의 고유공간에서 아무 기저나 \(Q\)에 넣는다: 같은 고유공간 안에서는 직교화해야 한다. (2) 고유벡터를 정규화하지 않아 \(Q^TQ \ne I\)가 된다. (3) \(D\)의 고유값 순서와 \(Q\)의 열 순서를 맞추지 않는다.
요약
  1. 실대칭 ⇔ \(A = QDQ^T\) (실직교 \(Q\), 실대각 \(D\)).
  2. 절차: 고유값 → 고유공간 기저 → 고유공간 안에서만 그람-슈미트 → 모으기.
  3. \(A\mathbf x = \sum\lambda_i(\mathbf q_i^T\mathbf x)\mathbf q_i\): 직교 축을 따라 늘이기.

3.3.4연습문제

기본

  1. \(A = \begin{pmatrix}5 & 2\\2 & 2\end{pmatrix}\)를 직교 대각화하여라.
    답

    \(\lambda^2 - 7\lambda + 6 = 0\), \(\lambda = 6, 1\). \(\mathbf q_1 = \frac1{\sqrt5}(2, 1)\), \(\mathbf q_2 = \frac1{\sqrt5}(1, -2)\). \(D = \mathrm{diag}(6, 1)\).

응용

  1. 문제 1의 \(A\)에 대해 \(A^{10}\mathbf x\) (\(\mathbf x = (1, 0)\))을 스펙트럼 분해로 구하여라.
    답

    \(\mathbf x = \frac2{\sqrt5}\mathbf q_1 + \frac1{\sqrt5}\mathbf q_2\). \(A^{10}\mathbf x = \frac{2\cdot6^{10}}{\sqrt5}\mathbf q_1 + \frac1{\sqrt5}\mathbf q_2 = \frac15(4\cdot6^{10} + 1,\ 2\cdot6^{10} - 2)\).

심화

  1. 실대칭 \(A\)의 가장 큰 고유값이 \(\max_{\|\mathbf x\| = 1}\mathbf x^TA\mathbf x\)임을 보여라(레일리 몫).
    답

    \(\mathbf x = \sum c_i\mathbf q_i\), \(\sum c_i^2 = 1\)이면 \(\mathbf x^TA\mathbf x = \sum\lambda_ic_i^2 \le \lambda_{\max}\), 등호는 \(\mathbf x = \mathbf q_{\max}\). 거듭제곱법(7.3절)과 4단원 이차형식의 기초.
