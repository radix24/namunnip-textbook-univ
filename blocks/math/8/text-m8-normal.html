최소제곱과 정규방정식

본문
이 절에서 배울 것
  • 해가 없는 연립방정식 \(A\mathbf x = \mathbf b\)의 "가장 가까운 해"를 최소제곱 문제로 정식화한다.
  • 직교 사영으로 정규방정식 \(A^TA\hat{\mathbf x} = A^T\mathbf b\)를 유도하고, 해의 존재와 유일성 조건을 증명한다.
  • 자료에 직선을 맞추는 문제를 정규방정식으로 푼다.
먼저 알아야 할 것
  • 직교 사영과 최소제곱 근사 (수학1 7.3절), 열공간과 영공간, 차원 정리 (수학1 3.1절).

1.1.1해가 없는 방정식

실험으로 점 \((0, 1), (1, 2), (2, 2), (3, 4)\)를 얻었고 이를 직선 \(y = c_0 + c_1x\)로 설명하고 싶다고 합시다. 네 점이 모두 직선 위에 있으려면 \(c_0 + c_1x_i = y_i\) 네 식이 동시에 성립해야 하는데, 미지수 두 개에 식이 넷이라 일반적으로 해가 없습니다. 행렬로 쓰면

\[A = \begin{pmatrix}1 & 0\\1 & 1\\1 & 2\\1 & 3\end{pmatrix},\quad \mathbf x = \begin{pmatrix}c_0\\c_1\end{pmatrix},\quad \mathbf b = \begin{pmatrix}1\\2\\2\\4\end{pmatrix}.\]

\(A\mathbf x = \mathbf b\)가 풀리지 않으면 차선책으로 오차 \(\|A\mathbf x - \mathbf b\|\)를 가장 작게 하는 \(\mathbf x\)를 찾습니다. 오차의 제곱 \(\sum(c_0 + c_1x_i - y_i)^2\)을 최소화하므로 최소제곱이라 부릅니다.

정의 1.1.1

최소제곱 해: \(m\times n\) 실행렬 \(A\)와 \(\mathbf b \in \mathbb R^m\)에 대해 모든 \(\mathbf x\)에서 \(\|A\hat{\mathbf x} - \mathbf b\| \le \|A\mathbf x - \mathbf b\|\)인 \(\hat{\mathbf x}\).

잔차: \(\mathbf r = \mathbf b - A\hat{\mathbf x}\).

1.1.2정규방정식

\(A\mathbf x\)가 움직이는 범위는 열공간 \(C(A)\)입니다. 따라서 문제는 "\(C(A)\)에서 \(\mathbf b\)에 가장 가까운 점 찾기"이고, 그 점은 직교 사영 \(\mathbf p = \mathrm{proj}_{C(A)}\mathbf b\)입니다(수학1 7.3절). 사영의 특징은 잔차 \(\mathbf b - \mathbf p\)가 \(C(A)\)에 수직이라는 것이고, 이 수직 조건을 식으로 쓰면 정규방정식이 됩니다.

정리 1.1.2 (정규방정식)

(a) \(\hat{\mathbf x}\)가 최소제곱 해일 필요충분조건은 \(A^TA\hat{\mathbf x} = A^T\mathbf b\)이다. (b) 최소제곱 해는 항상 존재한다. (c) \(A\)의 열이 일차독립이면 \(A^TA\)가 가역이고 해는 \(\hat{\mathbf x} = (A^TA)^{-1}A^T\mathbf b\)로 유일하다.

(a) 수학1의 사영 정리에 의해 \(\|A\mathbf x - \mathbf b\|\)가 최소 ⇔ \(A\hat{\mathbf x} = \mathrm{proj}_{C(A)}\mathbf b\) ⇔ \(\mathbf b - A\hat{\mathbf x} \perp C(A)\). \(C(A)\)는 \(A\)의 열들 \(\mathbf a_j\)로 생성되므로 이는 모든 \(j\)에 대해 \(\mathbf a_j^T(\mathbf b - A\hat{\mathbf x}) = 0\), 곧 \(A^T(\mathbf b - A\hat{\mathbf x}) = \mathbf 0\)과 같다.

(b) 사영 \(\mathbf p\)는 \(C(A)\)에 있으므로 \(A\hat{\mathbf x} = \mathbf p\)인 \(\hat{\mathbf x}\)가 있다.

(c) \(A^TA\mathbf x = \mathbf 0\)이면 \(0 = \mathbf x^TA^TA\mathbf x = \|A\mathbf x\|^2\)이므로 \(A\mathbf x = \mathbf 0\), 열이 독립이므로 \(\mathbf x = \mathbf 0\). 정사각행렬 \(A^TA\)의 영공간이 자명하므로 가역이다. ∎

(c)의 증명에서 쓴 \(N(A^TA) = N(A)\)는 자주 쓰이는 사실입니다. 열이 독립이 아니면 최소제곱 해가 무수히 많지만, 사영 \(A\hat{\mathbf x}\) 자체는 하나뿐입니다.

예제 1.1.3

위의 네 점에 최소제곱 직선을 맞추어라.

풀이. \(A^TA = \begin{pmatrix}4 & 6\\6 & 14\end{pmatrix}\) (성분은 \(n\), \(\sum x_i\), \(\sum x_i^2\)), \(A^T\mathbf b = \begin{pmatrix}9\\18\end{pmatrix}\) (\(\sum y_i\), \(\sum x_iy_i\)). 행렬식 \(56 - 36 = 20\)이므로 \(c_0 = \frac{14\cdot9 - 6\cdot18}{20} = 0.9\), \(c_1 = \frac{4\cdot18 - 6\cdot9}{20} = 0.9\). 직선 \(y = 0.9 + 0.9x\). 잔차 \((0.1, 0.2, -0.7, 0.4)\)의 제곱합은 0.70이고, 잔차의 합 0과 \(\sum x_ir_i = 0\)이 정규방정식(잔차 ⊥ 두 열)을 확인해 줍니다. 같은 절의 탐구 카드에서 점을 끌어 직선과 잔차의 변화를 볼 수 있습니다.

흔한 실수(1) \((A^TA)^{-1}A^T\)를 \(A^{-1}(A^T)^{-1}A^T = A^{-1}\)로 "간단히" 한다: \(A\)는 정사각이 아니라 역행렬이 없다. (2) 가로 거리(\(x\) 방향 오차)를 최소화한다고 여긴다: 세로 오차 \(y_i - \hat y_i\)의 제곱합이다. (3) 수치 계산에서 \(A^TA\)를 직접 만든다: 조건수가 제곱되어 정확도를 잃는다. 실제로는 QR 분해를 쓴다(1.2절).
요약
  1. 최소제곱 = 열공간으로의 직교 사영. 잔차는 열공간에 수직.
  2. 정규방정식 \(A^TA\hat{\mathbf x} = A^T\mathbf b\). 해는 항상 있고, 열이 독립이면 유일.
  3. 직선 맞춤에서 \(A^TA\)는 \(n, \sum x, \sum x^2\), \(A^T\mathbf b\)는 \(\sum y, \sum xy\).

1.1.3연습문제

기본

  1. 점 \((0, 0), (1, 1), (2, 1)\)에 최소제곱 직선을 맞추어라.
    답

    \(A^TA = \begin{pmatrix}3 & 3\\3 & 5\end{pmatrix}\), \(A^T\mathbf b = (2, 3)\). \(c_0 = (10 - 9)/6 = 1/6\), \(c_1 = (9 - 6)/6 = 1/2\). \(y = \frac16 + \frac12x\).

응용

  1. 상수 함수 \(y = c\)로 자료 \(y_1, \dots, y_n\)을 맞추면 최소제곱 해는 평균임을 정규방정식으로 보여라.
    답

    \(A = (1, \dots, 1)^T\). \(A^TA = n\), \(A^T\mathbf b = \sum y_i\). \(c = \bar y\).

심화

  1. \(N(A^TA) = N(A)\)를 이용해 \(\operatorname{rank}(A^TA) = \operatorname{rank}A\)임을 보여라.
    답

    두 행렬은 열의 수 \(n\)이 같고 영공간이 같으므로 차원 정리로 \(\operatorname{rank} = n - \dim N\)이 같다.
