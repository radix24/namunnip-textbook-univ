쌍대 문제와 약쌍대성

본문

공장 문제의 최댓값 36을 단체법으로 구했다. 그런데 문제를 풀지 않고도 "이익은 36을 넘을 수 없다"는 것을 확인할 방법이 있을까? 그리고 작업장의 시간을 한 시간 더 산다면 그 시간은 얼마의 가치가 있을까?

먼저 알아야 할 것선형계획 표준형(6.1절), 단체법(6.2절), 행렬의 전치를 쓴다.

6.3.1상한 찾기

공장 문제 \(\max\ 3x + 5y\) (\(x \le 4\), \(2y \le 12\), \(3x + 2y \le 18\), \(x, y \ge 0\))에서 셋째 제약에 1, 둘째에 1.5를 곱해 더하면 \(3x + 2y + 3y \le 18 + 18\), 곧 \(3x + 5y \le 36\)이다. 일반적으로 가중치 \(u_1, u_2, u_3 \ge 0\)을 곱해 더하면 \((u_1 + 3u_3)x + (2u_2 + 2u_3)y \le 4u_1 + 12u_2 + 18u_3\)이다. 이때 \(x, y \ge 0\)이므로 왼쪽 계수가 3, 5 이상이면 오른쪽이 목적함수의 상한이 된다. 그러므로 가장 좋은 상한을 찾는 문제가 생기며, 이것이 쌍대 문제이다.

정의 6.3.1

원문제 (P)는 \(\max\ \mathbf c^T\mathbf x\), \(A\mathbf x \le \mathbf b\), \(\mathbf x \ge 0\)이고, 그 쌍대 문제 (D)는 \(\min\ \mathbf b^T\mathbf u\), \(A^T\mathbf u \ge \mathbf c\), \(\mathbf u \ge 0\)이다.

원문제의 제약 하나가 쌍대 변수 하나에, 원문제의 변수 하나가 쌍대 제약 하나에 대응한다. 또 쌍대의 쌍대는 원문제이다.

6.3.2약쌍대성

정리 6.3.2 (약쌍대성)

\(\mathbf x\)가 (P)의 실행 가능해이고 \(\mathbf u\)가 (D)의 실행 가능해이면 \(\mathbf c^T\mathbf x \le \mathbf b^T\mathbf u\)이다.

증명.\(\mathbf x \ge 0\)이고 \(A^T\mathbf u - \mathbf c \ge 0\)이므로 \(\mathbf x^T(A^T\mathbf u - \mathbf c) \ge 0\), 곧 \(\mathbf c^T\mathbf x \le \mathbf x^TA^T\mathbf u = (A\mathbf x)^T\mathbf u\)이다. 또 \(\mathbf u \ge 0\)이고 \(\mathbf b - A\mathbf x \ge 0\)이므로 \((A\mathbf x)^T\mathbf u \le \mathbf b^T\mathbf u\)이다. 두 부등식을 이으면 결론이 나온다. ∎

증명에서 부등식이 두 번 쓰였다. 두 곳 모두 등호이면 \(\mathbf c^T\mathbf x = \mathbf b^T\mathbf u\)이고, 그러면 어느 쪽도 더 좋아질 수 없으므로 두 해가 모두 최적이다. 이 등호 조건이 아래의 상보 여유 조건이다.

따름정리 6.3.3

(a) (P)가 무계이면 (D)는 실행 불가능하다. (b) \(\mathbf c^T\mathbf x = \mathbf b^T\mathbf u\)인 실행 가능해 쌍이 있으면 둘 다 최적이다.

정리 6.3.4 (강쌍대성과 상보 여유)

(P)가 최적해를 가지면 (D)도 최적해를 가지고 최적값이 같다. 실행 가능해 \(\mathbf x, \mathbf u\)가 최적일 필요충분조건은 모든 \(i, j\)에서 \(u_i(b_i - (A\mathbf x)_i) = 0\), \(x_j((A^T\mathbf u)_j - c_j) = 0\)인 것이다.

강쌍대성의 증명은 단체법의 종료 조건이나 파르카스 보조정리를 쓰며, 여기서는 생략한다.

예제 6.3.5

공장 문제의 쌍대를 쓰고, \(\mathbf x = (2, 6)\)과 \(\mathbf u = (0, 1.5, 1)\)이 최적임을 확인하여라.

풀이. 쌍대는 \(\min\ 4u_1 + 12u_2 + 18u_3\), \(u_1 + 3u_3 \ge 3\), \(2u_2 + 2u_3 \ge 5\), \(\mathbf u \ge 0\)이다. \(\mathbf u = (0, 1.5, 1)\)은 \(0 + 3 = 3\), \(3 + 2 = 5\)로 실행 가능하고 값이 \(18 + 18 = 36\)이다. 원문제 값도 36이므로 따름정리 (b)로 둘 다 최적이다. 상보 여유도 맞는다. 첫 제약 \(x \le 4\)에 여유 2가 있으므로 \(u_1 = 0\)이고, \(x, y > 0\)이므로 쌍대 제약이 모두 등호이다. 사실 이 값들은 단체법의 마지막 목적식 계수와 같다(6.2절).

쌍대해는 그림자 가격으로 읽는다. \(u_2 = 1.5\)는 작업장 2의 시간을 1시간 늘릴 때 최대 이익이 1.5 늘어난다는 뜻이다. 실제로 \(2y \le 13\)으로 풀면 \(y = 6.5\), \(x = 5/3\)이고 이익은 \(5 + 32.5 = 37.5\)이다. 한편 \(u_1 = 0\)은 작업장 1의 시간이 이미 남아 있어 늘려도 소용없다는 뜻이다. 같은 절의 탐구 카드에서 쌍대 가중치를 바꾸며 상한을 직접 만들어 볼 수 있다.

흔한 오해쌍대를 쓸 때 \(A\)를 전치하지 않는 실수가 흔하다. 또 부등호 방향을 그대로 두는 것도 틀렸으며, 최대 문제의 \(\le\) 제약은 최소 문제의 \(\ge\) 제약이 된다. 약쌍대성의 부등식을 반대로 쓰는 것도 오해이다. 최대 문제의 값은 늘 최소 문제의 값 이하이다.
마무리

처음 질문의 답은 "있다"이다. 제약에 음이 아닌 가중치를 곱해 더하면 목적함수의 상한이 되고, 가장 좋은 상한을 찾는 것이 쌍대 문제 \(\min\ \mathbf b^T\mathbf u\), \(A^T\mathbf u \ge \mathbf c\), \(\mathbf u \ge 0\)이다. 약쌍대성에 따라 쌍대의 값은 늘 원문제 값의 상한이고, 가중치 \((0, 1.5, 1)\)이 상한 36을 주므로 이익은 36을 넘을 수 없다. 강쌍대성으로 두 최적값은 같으며, 쌍대해는 그림자 가격이므로 작업장 2의 한 시간은 1.5, 작업장 1의 한 시간은 0의 가치가 있다.

6.3.4연습문제

기본

  1. \(\max\ x + 2y\), \(x + y \le 3\), \(y \le 2\), \(x, y \ge 0\)의 쌍대를 써라.
    답

    \(\min\ 3u_1 + 2u_2\), \(u_1 \ge 1\), \(u_1 + u_2 \ge 2\), \(u_1, u_2 \ge 0\).

응용

  1. 문제 1의 원문제와 쌍대를 풀어 최적값이 같음을 확인하여라.
    답

    (원문제) \((1, 2)\)에서 5. (쌍대) \((1, 1)\)에서 \(3 + 2 = 5\). 같다.

심화

  1. (P)와 (D)가 모두 실행 불가능한 예를 들어라.
    답

    \(\max\ x_1 + x_2\), \(x_1 - x_2 \le -1\), \(-x_1 + x_2 \le -1\), \(\mathbf x \ge 0\): 두 식을 더하면 \(0 \le -2\)라 불가능. 쌍대 \(\min\ -u_1 - u_2\), \(u_1 - u_2 \ge 1\), \(-u_1 + u_2 \ge 1\): 더하면 \(0 \ge 2\)라 불가능.
