쌍대 문제와 약쌍대성

본문
이 절에서 배울 것
  • 제약식에 음이 아닌 가중치를 곱해 더하는 생각으로 쌍대 문제를 유도한다.
  • 약쌍대성(쌍대 실행 가능해의 값은 원문제 값의 상한)을 증명한다.
  • 강쌍대성과 상보 여유 조건으로 최적성을 확인하고, 쌍대해를 그림자 가격으로 해석한다.
먼저 알아야 할 것
  • 선형계획 표준형 (6.1절), 단체법 (6.2절), 행렬의 전치.

6.3.1상한 찾기

공장 문제 \(\max\ 3x + 5y\) (\(x \le 4\), \(2y \le 12\), \(3x + 2y \le 18\), \(x, y \ge 0\))의 최댓값을 풀지 않고 위에서 누를 수 있을까요? 셋째 제약에 1, 둘째에 1.5를 곱해 더하면 \(3x + 2y + 3y \le 18 + 18\), 곧 \(3x + 5y \le 36\)입니다. 일반적으로 가중치 \(u_1, u_2, u_3 \ge 0\)을 곱해 더하면 \((u_1 + 3u_3)x + (2u_2 + 2u_3)y \le 4u_1 + 12u_2 + 18u_3\)이고, 왼쪽 계수가 3, 5 이상이면(\(x, y \ge 0\)이므로) 목적함수의 상한이 됩니다. 가장 좋은 상한을 찾는 문제가 쌍대 문제입니다.

정의 6.3.1

원문제(P): \(\max\ \mathbf c^T\mathbf x\), \(A\mathbf x \le \mathbf b\), \(\mathbf x \ge 0\).

쌍대 문제(D): \(\min\ \mathbf b^T\mathbf u\), \(A^T\mathbf u \ge \mathbf c\), \(\mathbf u \ge 0\).

원문제의 제약 하나가 쌍대 변수 하나, 원문제의 변수 하나가 쌍대 제약 하나에 대응합니다. 쌍대의 쌍대는 원문제입니다.

6.3.2약쌍대성

정리 6.3.2 (약쌍대성)

\(\mathbf x\)가 (P)의 실행 가능해이고 \(\mathbf u\)가 (D)의 실행 가능해이면 \(\mathbf c^T\mathbf x \le \mathbf b^T\mathbf u\).

\(\mathbf x \ge 0\)이고 \(A^T\mathbf u - \mathbf c \ge 0\)이므로 \(\mathbf x^T(A^T\mathbf u - \mathbf c) \ge 0\), 곧 \(\mathbf c^T\mathbf x \le \mathbf x^TA^T\mathbf u = (A\mathbf x)^T\mathbf u\). 또 \(\mathbf u \ge 0\)이고 \(\mathbf b - A\mathbf x \ge 0\)이므로 \((A\mathbf x)^T\mathbf u \le \mathbf b^T\mathbf u\). 두 부등식을 이으면 결론. ∎

증명에서 부등식이 두 번 쓰였습니다. 두 곳 모두 등호이면 \(\mathbf c^T\mathbf x = \mathbf b^T\mathbf u\)이고, 그러면 두 해가 모두 최적입니다(어느 쪽도 더 좋아질 수 없음). 이 등호 조건이 다음의 상보 여유 조건입니다.

따름정리 6.3.3

(a) (P)가 무계이면 (D)는 실행 불가능하다. (b) \(\mathbf c^T\mathbf x = \mathbf b^T\mathbf u\)인 실행 가능해 쌍이 있으면 둘 다 최적이다.

정리 6.3.4 (강쌍대성과 상보 여유, 증명 생략)

(P)가 최적해를 가지면 (D)도 최적해를 가지고 최적값이 같다. 실행 가능해 \(\mathbf x, \mathbf u\)가 최적일 필요충분조건은 모든 \(i, j\)에서 \(u_i(b_i - (A\mathbf x)_i) = 0\), \(x_j((A^T\mathbf u)_j - c_j) = 0\)이다.

예제 6.3.5

공장 문제의 쌍대를 쓰고, \(\mathbf x = (2, 6)\)과 \(\mathbf u = (0, 1.5, 1)\)이 최적임을 확인하여라.

풀이. 쌍대: \(\min\ 4u_1 + 12u_2 + 18u_3\), \(u_1 + 3u_3 \ge 3\), \(2u_2 + 2u_3 \ge 5\), \(\mathbf u \ge 0\). \(\mathbf u = (0, 1.5, 1)\): \(0 + 3 = 3 \ge 3\), \(3 + 2 = 5 \ge 5\)로 실행 가능, 값 \(18 + 18 = 36\). 원문제 값도 36이므로 따름정리 (b)로 둘 다 최적입니다. 상보 여유: 첫 제약 \(x \le 4\)에 여유(2)가 있으니 \(u_1 = 0\), \(x, y > 0\)이니 쌍대 제약이 모두 등호. 이 값들은 단체법의 마지막 목적식 계수와 같습니다(6.2절).

그림자 가격: \(u_2 = 1.5\)는 작업장 2의 시간을 1시간 늘릴 때 최대 이익이 약 1.5 늘어난다는 뜻입니다(\(2y \le 13\)으로 풀면 \(y = 6.5\), \(x = 5/3\), 이익 \(5 + 32.5 = 37.5\)). \(u_1 = 0\)은 작업장 1의 시간이 남아 있어 늘려도 소용없다는 뜻입니다. 같은 절의 탐구 카드에서 쌍대 가중치를 바꾸며 상한을 직접 만들어 볼 수 있습니다.

흔한 실수(1) 쌍대에서 \(A\)를 전치하지 않는다. (2) 부등호 방향을 그대로 둔다: 최대 문제의 \(\le\) 제약은 최소 문제의 \(\ge\) 제약이 된다. (3) 약쌍대성의 부등식을 반대로 쓴다: 최대 문제의 값은 늘 최소 문제의 값 이하이다.
요약
  1. 쌍대 = 제약의 음 아닌 가중합으로 만들 수 있는 가장 좋은 상한. (P) \(\max\ \mathbf c^T\mathbf x\) ↔ (D) \(\min\ \mathbf b^T\mathbf u\), \(A^T\mathbf u \ge \mathbf c\).
  2. 약쌍대성 \(\mathbf c^T\mathbf x \le \mathbf b^T\mathbf u\): 두 줄 증명. 같으면 둘 다 최적.
  3. 강쌍대성: 최적값이 같다. 상보 여유: 여유가 있는 제약의 쌍대 변수는 0. 쌍대해 = 그림자 가격.

6.3.4연습문제

기본

  1. \(\max\ x + 2y\), \(x + y \le 3\), \(y \le 2\), \(x, y \ge 0\)의 쌍대를 써라.
    답

    \(\min\ 3u_1 + 2u_2\), \(u_1 \ge 1\), \(u_1 + u_2 \ge 2\), \(u_1, u_2 \ge 0\).

응용

  1. 문제 1의 원문제와 쌍대를 풀어 최적값이 같음을 확인하여라.
    답

    원문제: \((1, 2)\)에서 5. 쌍대: \((1, 1)\)에서 \(3 + 2 = 5\). 같다.

심화

  1. (P)와 (D)가 모두 실행 불가능한 예를 들어라.
    답

    \(\max\ x_1 + x_2\), \(x_1 - x_2 \le -1\), \(-x_1 + x_2 \le -1\), \(\mathbf x \ge 0\): 두 식을 더하면 \(0 \le -2\)라 불가능. 쌍대 \(\min\ -u_1 - u_2\), \(u_1 - u_2 \ge 1\), \(-u_1 + u_2 \ge 1\): 더하면 \(0 \ge 2\)라 불가능.
