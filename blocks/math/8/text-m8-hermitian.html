에르미트, 유니타리, 정규 작용소

본문
이 절에서 배울 것
  • 에르미트(자기수반), 유니타리, 정규 작용소를 수반으로 정의한다.
  • 에르미트 작용소의 고유값이 실수이고, 서로 다른 고유값의 고유벡터가 직교함을 증명한다.
  • 유니타리 작용소의 고유값이 단위원 위에 있음을 보이고, 세 부류의 관계를 안다.
먼저 알아야 할 것
  • 수반 작용소 (2.1절), 고유값과 고유벡터 (수학1 6.1절).

2.2.1세 가지 부류

정의 2.2.1

에르미트(자기수반): \(T^* = T\). 행렬로 \(A^* = A\). 실행렬이면 대칭행렬.

유니타리: \(T^*T = TT^* = I\). 실행렬이면 직교 행렬.

정규: \(T^*T = TT^*\).

에르미트와 유니타리는 모두 정규입니다. 복소수에 비유하면 에르미트는 실수(\(\bar z = z\)), 유니타리는 절댓값 1인 수(\(\bar zz = 1\)), 정규는 "켤레와 교환하는" 일반 복소수에 해당합니다. 이 비유는 고유값에서 정확해집니다.

2.2.2에르미트 작용소의 고유값

정리 2.2.2

\(T\)가 에르미트이면 (a) 모든 고유값은 실수이고, (b) 서로 다른 고유값에 속하는 고유벡터는 직교한다.

증명은 \(\langle Tx, x\rangle\)를 두 가지 방법으로 계산하는 것입니다. \(T\)를 왼쪽에서 계산하면 \(\lambda\), 수반으로 오른쪽에 넘기면 \(\bar\lambda\)가 나옵니다.

(a) \(Tx = \lambda x\), \(x \ne 0\)이라 하자. \(\lambda\|x\|^2 = \langle\lambda x, x\rangle = \langle Tx, x\rangle = \langle x, T^*x\rangle = \langle x, Tx\rangle = \langle x, \lambda x\rangle = \bar\lambda\|x\|^2\). \(\|x\| \ne 0\)이므로 \(\lambda = \bar\lambda\), 곧 \(\lambda\)는 실수.

(b) \(Tx = \lambda x\), \(Ty = \mu y\), \(\lambda \ne \mu\). \(\lambda\langle x, y\rangle = \langle Tx, y\rangle = \langle x, Ty\rangle = \bar\mu\langle x, y\rangle = \mu\langle x, y\rangle\) (\(\mu\)는 실수). \((\lambda - \mu)\langle x, y\rangle = 0\)이므로 \(\langle x, y\rangle = 0\). ∎

(a)의 중요한 귀결: 실대칭 행렬의 고유값은 모두 실수입니다. 실행렬은 일반적으로 복소 고유값을 가질 수 있는데(회전 행렬), 대칭이면 그런 일이 없습니다. 이 사실이 3.3절의 직교 대각화, 4단원의 이차형식의 출발점입니다.

예제 2.2.3

\(A = \begin{pmatrix}2 & 1 - i\\1 + i & 3\end{pmatrix}\)의 고유값과 고유벡터를 구하고 직교함을 확인하여라.

풀이. \(A^* = A\)이다. 특성다항식 \(\lambda^2 - 5\lambda + (6 - |1 - i|^2) = \lambda^2 - 5\lambda + 4\)이므로 \(\lambda = 1, 4\) (실수). \(\lambda = 1\): \((A - I)v = 0\)에서 \(v_1 + (1 - i)v_2 = 0\), \(v = (-(1 - i), 1) = (-1 + i, 1)\). \(\lambda = 4\): \(-2v_1 + (1 - i)v_2 = 0\), \(w = (1 - i, 2)\). 내적 \(\langle v, w\rangle = (-1 + i)\overline{(1 - i)} + 1\cdot2 = (-1 + i)(1 + i) + 2 = -2 + 2 = 0\).

2.2.3유니타리 작용소

정리 2.2.4

다음은 동치이다. (a) \(T\)는 유니타리. (b) 모든 \(x, y\)에서 \(\langle Tx, Ty\rangle = \langle x, y\rangle\). (c) 모든 \(x\)에서 \(\|Tx\| = \|x\|\). 또 유니타리 작용소의 고유값은 \(|\lambda| = 1\)이다.

(a)⇒(b)는 \(\langle Tx, Ty\rangle = \langle x, T^*Ty\rangle\), (b)⇒(c)는 \(x = y\). (c)⇒(a)는 편극 항등식으로 내적을 길이로 나타내 보입니다. 고유값: \(Tx = \lambda x\)이면 \(\|x\| = \|Tx\| = |\lambda|\|x\|\). 예: \(U = \frac1{\sqrt2}\begin{pmatrix}1 & i\\i & 1\end{pmatrix}\)의 고유값은 \(\frac{1 \pm i}{\sqrt2}\)로 절댓값 1입니다. 같은 절의 탐구 카드에서 행렬이 에르미트 조건에서 벗어나면 고유값이 어떻게 복소평면으로 나가는지 볼 수 있습니다.

흔한 실수(1) 대칭인 복소 행렬(\(A^T = A\))을 에르미트로 여긴다: 에르미트는 \(A^* = A\)이고 대각성분이 실수여야 한다. (2) 고유값이 실수이면 에르미트라고 거꾸로 결론낸다: \(\begin{pmatrix}1 & 1\\0 & 2\end{pmatrix}\)은 고유값이 실수지만 에르미트가 아니다. (3) 증명 (a)에서 \(\langle x, \lambda x\rangle = \lambda\|x\|^2\)로 켤레를 빠뜨린다.
요약
  1. 에르미트 \(T^* = T\), 유니타리 \(T^*T = I\), 정규 \(T^*T = TT^*\).
  2. 에르미트: 고유값 실수, 다른 고유값의 고유벡터는 직교. 증명은 \(\langle Tx, x\rangle\)를 양쪽에서 계산.
  3. 유니타리: 내적·길이 보존, 고유값의 절댓값 1.

2.2.4연습문제

기본

  1. \(\begin{pmatrix}1 & 2 + i\\2 - i & -1\end{pmatrix}\)의 고유값을 구하여라.
    답

    대각합 0, 행렬식 \(-1 - |2 + i|^2 = -6\)이므로 \(\lambda^2 - 6 = 0\), \(\lambda = \pm\sqrt6\).

응용

  1. 에르미트 \(T\)에 대해 모든 \(x\)에서 \(\langle Tx, x\rangle\)가 실수임을 보여라.
    답

    \(\overline{\langle Tx, x\rangle} = \langle x, Tx\rangle = \langle T^*x, x\rangle = \langle Tx, x\rangle\).

심화

  1. 반에르미트(\(T^* = -T\)) 작용소의 고유값은 순허수임을 보이고, \(e^{T}\)가 유니타리임을 설명하여라.
    답

    \(iT\)가 에르미트이므로 \(i\lambda\)가 실수, 곧 \(\lambda\)는 순허수. \((e^T)^* = e^{T^*} = e^{-T}\)이고 \(T\)와 \(-T\)가 교환하므로 \(e^{-T}e^T = I\). (양자역학의 시간 변화 \(e^{-iHt}\))
