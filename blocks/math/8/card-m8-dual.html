제약을 섞어 상한 만들기

탐구 · 쌍대 문제와 약쌍대성

질문

공장 문제의 세 제약에 가중치 \(u_1, u_2, u_3 \ge 0\)을 곱해 더하면 새 부등식이 생긴다. 언제 그 부등식이 이익 \(3x + 5y\)의 상한이 될까? 가장 낮은 상한은 무엇일까?

복원

\((u_1 + 3u_3)x + (2u_2 + 2u_3)y \le 4u_1 + 12u_2 + 18u_3\). 계수가 3, 5 이상이면 상한: 쌍대 실행 가능 (6.3절).

해 보기

  1. 처음 값 \(\mathbf u = (1, 2, 1)\): 계수 4, 6으로 실행 가능하고 상한은 46이다. 파란 선이 영역 바깥에 있다.
  2. \(u_1 = 0\), \(u_2 = 1.5\), \(u_3 = 1\)로 맞추면 계수가 정확히 3, 5가 되고 상한이 36으로 최댓값과 같아진다. 파란 선이 빨간 점선과 겹치고 \((2, 6)\)을 지난다.
  3. \(u_2\)를 1.4로 내리면 \(y\) 계수가 4.8 < 5가 되어 상한이 되지 못한다. 36보다 작은 상한은 만들 수 없습니다(약쌍대성).

설명

  1. 쌍대 실행 가능 = 지배\(x, y \ge 0\)이므로 계수가 3, 5 이상인 일차식은 \(3x + 5y\) 이상이다. 그래서 섞은 부등식의 오른쪽 값이 이익의 상한이 된다.
  2. 상보 여유최적 가중치에서 \(u_1 = 0\)인 것은 첫째 제약 \(x \le 4\)가 최적해 \((2, 6)\)에서 여유가 있기 때문이다. 여유가 있는 제약을 섞으면 상한이 느슨해진다.

판단

"상한 46을 찾았으니 이익을 46까지 낼 수 있다"는 틀린다. 쌍대 실행 가능해의 값은 상한일 뿐이고, 최적 상한(36)과 최적 이익(36)이 같다는 것은 강쌍대성이라는 별도의 정리가 보장한다.
