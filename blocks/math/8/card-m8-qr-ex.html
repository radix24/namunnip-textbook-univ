포물선 맞추기를 QR로

예제 · QR 분해로 최소제곱 풀기

먼저 예측

점 \((-1, 1), (0, 0), (1, 1), (2, 3)\)에 \(y = c_0 + c_1x + c_2x^2\)를 맞춘다. \(x^2\)의 계수는 양수일까, 음수일까?

예측 확인

양수이다. 점들이 아래로 볼록한 모양으로 놓여 있다.

\(A = \begin{pmatrix}1 & -1 & 1\\1 & 0 & 0\\1 & 1 & 1\\1 & 2 & 4\end{pmatrix}\), \(\mathbf b = (1, 0, 1, 3)^T\)의 최소제곱 해를 QR 분해로 구하여라.

전략

열에 그람-슈미트를 적용해 \(Q\), \(R\)을 만들고, \(R\hat{\mathbf x} = Q^T\mathbf b\)를 후진 대입으로 풉니다(1.2절). 각 \(\mathbf q_k\)는 앞의 열과 직교하도록 "중심화"된 다항식 값이다.

풀이

  1. \(\mathbf q_1 = \frac12(1, 1, 1, 1)\), \(r_{11} = 2\).
    \(\|\mathbf a_1\| = 2\).
  2. \(r_{12} = \mathbf q_1^T\mathbf a_2 = 1\). \(\mathbf a_2 - \mathbf q_1 = (-1.5, -0.5, 0.5, 1.5)\), 길이 \(\sqrt5\). \(r_{22} = \sqrt5\).
    \(x\)에서 평균 0.5를 뺀 것.
  3. \(r_{13} = \mathbf q_1^T\mathbf a_3 = 3\), \(r_{23} = \mathbf q_2^T\mathbf a_3 = \frac{-1.5 + 0.5 + 6}{\sqrt5} = \sqrt5\). \(\mathbf a_3 - 3\mathbf q_1 - \sqrt5\mathbf q_2 = (1, -1, -1, 1)\), 길이 2. \(r_{33} = 2\).
    \(\mathbf a_3 = (1, 0, 1, 4)\)에서 \((1.5, 1.5, 1.5, 1.5)\)와 \((-1.5, -0.5, 0.5, 1.5)\)를 뺀다.
  4. \(Q^T\mathbf b = \left(\frac52,\ \frac{-1.5 + 0.5 + 4.5}{\sqrt5},\ \frac{1 - 0 - 1 + 3}2\right) = \left(2.5,\ \frac{3.5}{\sqrt5},\ 1.5\right)\).
    \(\mathbf q_3 = \frac12(1, -1, -1, 1)\).
  5. 후진 대입: \(2c_2 = 1.5\) → \(c_2 = 0.75\). \(\sqrt5c_1 + \sqrt5(0.75) = 3.5/\sqrt5\) → \(c_1 = 0.7 - 0.75 = -0.05\). \(2c_0 + c_1 + 3c_2 = 2.5\) → \(c_0 = (2.5 + 0.05 - 2.25)/2 = 0.15\).
    \(R = \begin{pmatrix}2 & 1 & 3\\0 & \sqrt5 & \sqrt5\\0 & 0 & 2\end{pmatrix}\).

검산

\(y = 0.15 - 0.05x + 0.75x^2\)의 값은 \(x = -1, 0, 1, 2\)에서 \(0.95, 0.15, 0.85, 3.05\), 잔차 \((0.05, -0.15, 0.15, -0.05)\). 잔차와 세 열의 내적이 \(0\), \(-0.05 + 0.15 - 0.1 = 0\), \(0.05 + 0.15 - 0.2 = 0\)으로 모두 0이다.

의미

\(\mathbf q_3\)은 \(x^2\)에서 상수와 일차 성분을 뺀 "직교 다항식"의 값이다. 점이 많고 차수가 높으면 \(1, x, x^2, \dots\)의 열이 거의 평행해져 \(A^TA\)가 거의 특이해지는데, QR은 이 직교화를 안정적으로 해 준다. 르장드르 다항식 같은 직교 다항식(수학15)이 같은 생각이다.

이해 확인

같은 점에 직선만 맞추면 계수는? (힌트: \(R\)의 왼쪽 위 \(2\times2\)만 쓴다)

답

\(\sqrt5c_1 = 3.5/\sqrt5\) → \(c_1 = 0.7\), \(2c_0 + 0.7 = 2.5\) → \(c_0 = 0.9\). \(y = 0.9 + 0.7x\). QR은 차수를 늘릴 때 앞의 계산을 다시 쓸 수 있다.
