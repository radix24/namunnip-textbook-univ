피보나치 행렬의 거듭제곱을 한 줄로

예제 · 케일리-해밀턴으로 차수 줄이기

먼저 예측

\(F = \begin{pmatrix}1 & 1\\1 & 0\end{pmatrix}\)의 10제곱을 구하려면 행렬 곱을 몇 번 해야 할까? 케일리-해밀턴을 쓰면?

예측 확인

그대로는 9번(제곱을 되풀이하면 4번)이지만, 케일리-해밀턴을 쓰면 행렬 곱 없이 수열 계산만으로 됩니다.

\(F = \begin{pmatrix}1 & 1\\1 & 0\end{pmatrix}\)에 대해 \(F^n = f_nF + f_{n-1}I\) (\(f_n\)은 피보나치 수, \(f_0 = 0\), \(f_1 = 1\))임을 보이고 \(F^{10}\)을 구하여라.

전략

케일리-해밀턴으로 \(F^2\)을 \(F\)와 \(I\)로 쓰고(5.1절), 그 관계를 되풀이 적용해 \(F^n\)의 계수가 따르는 점화식을 얻습니다.

풀이

  1. \(p_F(\lambda) = \lambda^2 - \lambda - 1\)이므로 \(F^2 = F + I\).
    대각합 1, 행렬식 \(-1\). 케일리-해밀턴.
  2. \(F^n = a_nF + b_nI\)라 하면 \(F^{n+1} = a_nF^2 + b_nF = (a_n + b_n)F + a_nI\).
    \(F^2\)를 1단계로 바꿈.
  3. \(a_{n+1} = a_n + b_n\), \(b_{n+1} = a_n\)이므로 \(a_{n+1} = a_n + a_{n-1}\). \(a_1 = 1\), \(a_2 = 1\) (\(F^2 = F + I\))이므로 \(a_n = f_n\), \(b_n = a_{n-1} = f_{n-1}\).
    피보나치 점화식과 같은 초기값.
  4. \(F^{10} = f_{10}F + f_9I = 55F + 34I = \begin{pmatrix}89 & 55\\55 & 34\end{pmatrix}\).
    \(f_9 = 34\), \(f_{10} = 55\), \(f_{11} = 89\).

검산

\(F^n = \begin{pmatrix}f_{n+1} & f_n\\f_n & f_{n-1}\end{pmatrix}\)이라는 잘 알려진 공식과 맞습니다(\(f_n + f_{n-1} = f_{n+1}\)). 행렬식을 취하면 \(f_{n+1}f_{n-1} - f_n^2 = (\det F)^n = (-1)^n\) (카시니 항등식): \(89\cdot34 - 55^2 = 3026 - 3025 = 1\).

의미

\(n\times n\) 행렬의 모든 거듭제곱은 \(I, A, \dots, A^{n-1}\)의 일차결합이고, 계수들은 특성다항식이 정하는 선형 점화식을 따릅니다. 반대로 선형 점화식은 동반행렬의 거듭제곱입니다(수학3 3.2절의 점화관계, 수학1 6.4절).

이해 확인

\(A = \begin{pmatrix}0 & 1\\-1 & 0\end{pmatrix}\)에 대해 \(A^{2026}\)을 구하여라.

답

\(p_A = \lambda^2 + 1\)이므로 \(A^2 = -I\), \(A^4 = I\). \(2026 = 4\cdot506 + 2\)이므로 \(A^{2026} = A^2 = -I\).
