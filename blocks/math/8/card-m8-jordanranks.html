계수 수열이 조르당 형을 알려 준다

탐구 · 점 도표와 rank(A − λI)ᵏ

질문

한 고유값의 조르당 블록 크기를 정하면 \(\operatorname{rank}(A - \lambda I)^k\)의 수열이 정해집니다. 거꾸로 계수 수열만 보고 블록 크기를 되살릴 수 있을까요?

복원

크기 \(k\) 이상인 블록의 개수 \(= r_{k-1} - r_k\) (5.3절 정리 5.3.3). 여기서는 고유값 \(\lambda\)의 일반화 고유공간만 본다(\(r_0 = n\)).

해 보기

  1. 처음 값 \(J_3 \oplus J_1\) (\(n = 4\)): 계수 수열 4, 2, 1, 0. 5.3절 연습문제 2의 멱영 행렬과 같습니다.
  2. 블록을 \(J_2 \oplus J_2\)로 바꾸면 수열이 4, 2, 0. 첫 차이(블록 개수)는 같고 둘째 차이가 다릅니다: 기하적 중복도만으로는 조르당 형이 정해지지 않습니다.
  3. 점 도표의 \(k\)번째 행에 있는 점의 개수가 \(r_{k-1} - r_k\)와 같은지 여러 경우로 확인하세요.

설명

  1. 한 번 곱할 때마다 한 행이 사라진다\(N = A - \lambda I\)를 한 번 적용하면 각 사슬의 맨 아래 벡터가 0이 되어 계수가 블록 개수만큼 줄어듭니다. 이미 사라진 짧은 블록은 더 줄지 않으므로, 감소량이 "아직 살아 있는 블록의 개수"입니다.
  2. 닮음 불변량계수는 닮음에 대해 불변이므로, 두 행렬의 모든 고유값에서 계수 수열이 같으면 조르당 형이 같아 두 행렬은 닮음입니다.

판단

"특성다항식과 극소다항식이 같으면 두 행렬은 닮음이다"는 일반적으로 틀립니다. \(J_3 \oplus J_3 \oplus J_1\)과 \(J_3 \oplus J_2 \oplus J_2\) (\(n = 7\))은 둘 다 \(p = \lambda^7\), \(m = \lambda^3\)이지만 계수 수열이 7, 4, 2, 0과 7, 4, 1, 0으로 다릅니다.
