선형계획 문제와 표준형

본문
이 절에서 배울 것
  • 자원 배분 같은 최적화 문제를 결정변수, 목적함수, 제약식으로 정식화한다.
  • 여유변수를 넣어 표준형 \(\max\ \mathbf c^T\mathbf x\), \(A\mathbf x = \mathbf b\), \(\mathbf x \ge 0\)으로 바꾼다.
  • 실행 가능 영역이 볼록 다면체이고 최적해가 꼭짓점에서 나타남(꼭짓점 정리)을 안다.
먼저 알아야 할 것
  • 연립일차방정식과 기본해 (수학1 1.2절), 고교의 부등식 영역과 최대·최소.

6.1.1문제를 식으로

공장에서 제품 A, B를 만듭니다. A 한 묶음은 이익 3, B 한 묶음은 이익 5(백만 원)입니다. 작업장 1은 A만 쓰며 주당 4시간, 작업장 2는 B만 쓰며 B 한 묶음에 2시간씩 주당 12시간, 작업장 3은 A에 3시간, B에 2시간이 들고 주당 18시간 쓸 수 있습니다. 이익을 최대로 하려면?

A, B의 생산량을 \(x, y\)라 두면 (1) 목적함수 \(3x + 5y\)를 최대로, (2) 제약 \(x \le 4\), \(2y \le 12\), \(3x + 2y \le 18\), (3) 부호 제약 \(x, y \ge 0\). 목적함수와 제약이 모두 일차식이므로 선형계획 문제입니다.

정의 6.1.1

부등식 꼴: \(\max\ \mathbf c^T\mathbf x\), \(A\mathbf x \le \mathbf b\), \(\mathbf x \ge \mathbf 0\).

표준형(등식 꼴): \(\max\ \mathbf c^T\mathbf x\), \(A\mathbf x = \mathbf b\), \(\mathbf x \ge \mathbf 0\), \(\mathbf b \ge \mathbf 0\).

실행 가능 영역: 모든 제약을 만족하는 \(\mathbf x\)의 집합. 그 원소가 실행 가능해.

6.1.2표준형으로 바꾸기

  • 여유변수: \(a^T\mathbf x \le b\)는 \(a^T\mathbf x + s = b\), \(s \ge 0\)으로. 예: \(3x + 2y + s_3 = 18\). \(s_3\)은 작업장 3의 남는 시간입니다.
  • 잉여변수: \(a^T\mathbf x \ge b\)는 \(a^T\mathbf x - s = b\), \(s \ge 0\)으로.
  • 최소화: \(\min\ \mathbf c^T\mathbf x\)는 \(\max\ (-\mathbf c)^T\mathbf x\)로.
  • 부호 제한 없는 변수: \(x = x^+ - x^-\), \(x^\pm \ge 0\)으로 나눈다.

공장 문제의 표준형은 변수 5개 \((x, y, s_1, s_2, s_3)\), 등식 3개입니다. 등식 3개에서 변수 2개를 0으로 두고 나머지 3개를 풀면 "기본해"가 나오고, 그것이 모두 0 이상이면 실행 가능한 꼭짓점입니다.

6.1.3꼭짓점 정리

정리 6.1.2 (꼭짓점 정리)

실행 가능 영역은 볼록 다면체이다. 최적값이 유한하고 영역에 꼭짓점이 있으면, 최적해 중 하나는 꼭짓점이다.

볼록성: 두 실행 가능해 \(\mathbf x, \mathbf y\)와 \(0 \le t \le 1\)에 대해 \(A(t\mathbf x + (1-t)\mathbf y) \le t\mathbf b + (1-t)\mathbf b = \mathbf b\). 꼭짓점이 아닌 점은 영역 안의 어떤 선분의 내부에 있고, 선분 위에서 일차함수 \(\mathbf c^T\mathbf x\)는 한쪽 끝을 향해 커지거나(아니면 일정하므로) 끝쪽으로 옮겨도 손해가 없습니다. 이를 되풀이하면 꼭짓점에 닿습니다.

예제 6.1.3

공장 문제를 꼭짓점을 모두 조사해 풀어라.

풀이. 꼭짓점과 목적함수 값: \((0, 0)\): 0, \((4, 0)\): 12, \((4, 3)\): 27, \((2, 6)\): 36, \((0, 6)\): 30. 최적해 \((2, 6)\), 최대 이익 36. \((2, 6)\)은 \(2y = 12\)와 \(3x + 2y = 18\)의 교점으로, 작업장 2와 3을 꽉 채우고 작업장 1은 2시간이 남습니다(\(s_1 = 2\)). 같은 절의 탐구 카드에서 목적함수 계수를 바꾸면 최적 꼭짓점이 옮겨 가는 것을 볼 수 있습니다.

꼭짓점의 수는 변수와 제약이 늘면 폭발적으로 많아지므로(최대 \(\binom{n+m}m\)개), 모두 조사하는 대신 좋아지는 방향으로만 이웃 꼭짓점을 따라가는 단체법(6.2절)을 씁니다.

흔한 실수(1) 부호 제약 \(x, y \ge 0\)을 빠뜨린다. (2) 여유변수를 목적함수에 넣는다: 계수는 0이다. (3) 실행 가능 영역이 비었거나 위로 유계가 아닌 경우를 생각하지 않는다: 최적해가 없을 수 있다.
요약
  1. 결정변수, 일차 목적함수, 일차 제약, 부호 제약으로 정식화.
  2. 여유·잉여변수와 변수 분할로 표준형 \(A\mathbf x = \mathbf b\), \(\mathbf x \ge 0\).
  3. 실행 가능 영역은 볼록 다면체, 최적해는 꼭짓점에서.

6.1.4연습문제

기본

  1. \(\min\ 2x - y\), \(x + y \ge 1\), \(x - y \le 3\), \(x, y \ge 0\)을 표준형으로 써라.
    답

    \(\max\ -2x + y\), \(x + y - s_1 = 1\), \(x - y + s_2 = 3\), \(x, y, s_1, s_2 \ge 0\).

응용

  1. 사료 A(1kg에 단백질 2, 지방 1, 값 3), B(단백질 1, 지방 2, 값 2)로 단백질 8 이상, 지방 7 이상을 가장 싸게 맞추는 문제를 세우고 풀어라.
    답

    \(\min\ 3a + 2b\), \(2a + b \ge 8\), \(a + 2b \ge 7\), \(a, b \ge 0\). 꼭짓점 \((0, 8)\): 16, \((3, 2)\): 13, \((7, 0)\): 21. 최소 13, \(a = 3\), \(b = 2\).

심화

  1. \(\max\ x + y\), \(x - y \le 1\), \(x, y \ge 0\)은 왜 최적해가 없는가?
    답

    \((0, t)\)는 모든 \(t \ge 0\)에서 실행 가능하고 목적함수가 \(t \to \infty\). 영역이 그 방향으로 유계가 아니다.
