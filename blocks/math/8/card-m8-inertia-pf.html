부호의 개수는 좌표에 따라 변하지 않는다

증명 · 실베스터 관성 법칙
정리

실대칭 \(A\)와 가역 \(P, Q\)에 대해 \(P^TAP = D_1\), \(Q^TAQ = D_2\)가 모두 대각이면 \(D_1\)과 \(D_2\)의 양수 대각성분의 개수가 같다(음수, 0의 개수도 같다).

쓰는 것

  • 차원 공식: 부분공간 \(W_1, W_2 \subseteq \mathbb R^n\)에서 \(\dim W_1 + \dim W_2 > n\)이면 \(W_1 \cap W_2 \ne \{0\}\) (수학1 2.5절).
  • 좌표 변환: \(\mathbf x = P\mathbf y\)이면 \(\mathbf x^TA\mathbf x = \mathbf y^TD_1\mathbf y\) (4.1절).

아이디어

양수의 개수는 "\(q\)가 양정치인 부분공간의 최대 차원"으로 좌표 없이 특징지을 수 있습니다. 두 좌표계가 서로 다른 개수를 준다면, 한쪽의 "양수 공간"과 다른 쪽의 "0 이하 공간"이 차원이 너무 커서 겹치고, 겹친 벡터에서 \(q\)가 양수이면서 0 이하라는 모순이 생깁니다.

증명

  1. \(q(\mathbf x) = \mathbf x^TA\mathbf x\). \(D_1\)의 양수 개수를 \(p\), \(D_2\)의 양수 개수를 \(p'\)이라 하고 \(p > p'\)이라 가정한다. 대각의 순서는 양수가 앞에 오도록 \(P, Q\)의 열을 바꿔 둔다.
    \(p < p'\)이면 역할을 바꾸면 된다.
  2. \(W_1 = \mathrm{span}(P\mathbf e_1, \dots, P\mathbf e_p)\). \(\mathbf x = P\mathbf y \in W_1\), \(\mathbf x \ne 0\)이면 \(q(\mathbf x) = \sum_{i\le p}d_iy_i^2 > 0\).
    \(\mathbf y\)는 앞 \(p\)성분만 있고 \(d_i > 0\). \(\dim W_1 = p\) (\(P\) 가역).
  3. \(W_2 = \mathrm{span}(Q\mathbf e_{p'+1}, \dots, Q\mathbf e_n)\). \(\mathbf x = Q\mathbf z \in W_2\)이면 \(q(\mathbf x) = \sum_{i>p'}d_i'z_i^2 \le 0\).
    \(i > p'\)인 \(d_i' \le 0\). \(\dim W_2 = n - p'\).
  4. \(\dim W_1 + \dim W_2 = p + n - p' > n\)이므로 0이 아닌 \(\mathbf x \in W_1\cap W_2\)가 있다.
    차원 공식.
  5. 그 \(\mathbf x\)에서 \(q(\mathbf x) > 0\)이면서 \(q(\mathbf x) \le 0\): 모순. 따라서 \(p = p'\). 음수의 개수는 \(-A\)에 같은 논증, 0의 개수는 \(n\)에서 뺀 것.
    2, 3단계.

되짚기

  • 직교일 필요가 없습니다. \(P, Q\)는 가역이기만 하면 됩니다. 그래서 완전제곱(라그랑주 방법)처럼 직교가 아닌 방법으로 대각화해도 부호의 개수는 고유값의 부호 개수와 같습니다.
  • 예. \(x^2 + 4xy + y^2 = (x + 2y)^2 - 3y^2\): 양 하나, 음 하나. 고유값 3, −1과 부호 개수가 같습니다(4.1절).

직접 써 보기

\(q = 2xy\)를 완전제곱으로 대각화하고 관성을 구하여라.

힌트

\(x = u + v\), \(y = u - v\)로 두세요.

답안

\(2xy = 2(u^2 - v^2)\). 양 하나, 음 하나(부정치). 행렬 \(\begin{pmatrix}0 & 1\\1 & 0\end{pmatrix}\)의 고유값 \(\pm1\)과 일치한다.
