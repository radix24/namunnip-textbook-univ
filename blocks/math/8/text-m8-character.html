지표와 직교관계

본문

표현은 행렬 묶음이라 다루기 번거롭다. 각 행렬의 대각합만 남기면 정보를 잃을 것 같지만, 유한군에서는 그 대각합 목록만으로 표현이 완전히 정해진다. 왜 그런가?

먼저 알아야 할 것Schur 보조정리(9.3절), 대각합의 성질(선형대수(1)), 켤레류(현대대수(1))를 쓴다.

9.4.1지표

정의 9.4.1 (지표)

표현 \(\rho\)의 지표는 함수 \(\chi(g) = \operatorname{tr}\rho(g)\)이다.

대각합은 기저 변환에 불변이므로 동형인 표현은 지표가 같다. 또 \(\operatorname{tr}(AB) = \operatorname{tr}(BA)\)이므로 \(\chi(hgh^{-1}) = \chi(g)\), 곧 지표는 켤레류 위에서 상수이다. \(\chi(e) = \dim V\)이고, 직합의 지표는 지표의 합이다. 그리고 \(\rho(g)\)는 유한 위수라 고유값이 1의 거듭제곱근이므로 \(\chi(g^{-1}) = \overline{\chi(g)}\)이다.

9.4.2직교관계

\(G\) 위의 복소 함수에 내적 \(\langle\phi, \psi\rangle = \frac1{|G|}\sum_g\phi(g)\overline{\psi(g)}\)를 주자.

정리 9.4.2 (지표의 직교관계)

\(\chi\), \(\chi'\)가 기약표현의 지표이면 두 표현이 동형일 때 \(\langle\chi, \chi'\rangle = 1\), 동형이 아닐 때 0이다.

증명의 흐름.아무 일차사상 \(h : V \to V'\)를 잡아 \(h_0 = \frac1{|G|}\sum_g\rho'(g)h\rho(g)^{-1}\)으로 평균내면 교환 사상이 된다. Schur 보조정리로 동형이 아니면 \(h_0 = 0\)이고, \(V = V'\)이면 \(h_0 = \frac{\operatorname{tr}h}{\dim V}I\)이다. \(h\)로 행렬 단위를 넣고 성분을 비교하면 행렬 성분들 사이의 직교관계가 나오고, 대각 성분을 더하면 지표의 직교관계가 된다. ∎

이 정리에서 바로 여러 결론이 나온다. 표현 \(V\)를 기약표현의 직합 \(V = m_1W_1 \oplus \dots \oplus m_kW_k\)로 쓰면 \(\chi_V = \sum m_i\chi_i\)이고, 내적을 취하면 \(m_i = \langle\chi_V, \chi_i\rangle\)이다. 그러면 중복도가 지표로 정해지므로 지표가 같은 표현은 동형이다. 또 \(\langle\chi_V, \chi_V\rangle = \sum m_i^2\)이므로 \(V\)가 기약인 것은 \(\langle\chi_V, \chi_V\rangle = 1\)과 동치이다.

9.4.3S₃의 지표표 만들기

\(S_3\)에는 켤레류가 셋(항등, 호환 3개, 3-순환 2개)이다. 자명 표현과 부호 표현이 그림 1의 첫 두 행이다. 정칙표현의 지표는 \(\chi_{\text{reg}}(e) = 6\)이고 나머지에서 0이므로 \(\langle\chi_{\text{reg}}, \chi_i\rangle = \chi_i(e) = \dim W_i\)이다. 따라서 정칙표현에는 각 기약표현이 차수만큼 들어 있고, 차원을 세면 \(\sum(\dim W_i)^2 = |G| = 6\)이다. \(1^2 + 1^2 = 2\)이므로 남은 기약표현의 차수 제곱의 합이 4이고, 기약표현의 개수가 켤레류 개수 3과 같다는 정리를 쓰면 차수 2인 기약표현이 하나 남는다.

그 지표를 \((2, a, b)\)라 하면 첫 행, 둘째 행과의 직교관계가 \(2 + 3a + 2b = 0\), \(2 - 3a + 2b = 0\)이다. 두 식을 빼면 \(a = 0\), 더하면 \(b = -1\)이다. 이것이 그림 1의 셋째 행이고, 정삼각형의 2차원 표현에서 반사의 대각합 0, 120도 회전의 대각합 \(2\cos120° = -1\)과 맞는다.

예제 9.4.3

\(S_3\)의 3차원 치환표현을 기약표현으로 분해하여라.

풀이. 치환표현의 지표는 고정점의 개수이므로 \((3, 1, 0)\)이다. 자명 표현과의 내적은 \(\frac16(3 + 3\cdot1 + 0) = 1\), 부호 표현과는 \(\frac16(3 - 3 + 0) = 0\), 2차원 표현과는 \(\frac16(6 + 0 + 0) = 1\)이다. 따라서 치환표현은 자명 표현과 2차원 표현의 직합이고, 9.1절의 예제와 맞는다.

마무리

지표는 표현의 각 행렬의 대각합이며 켤레류 위에서 상수이다. 기약 지표들은 정규직교이므로, 표현의 기약 분해에서 각 중복도는 지표와의 내적으로 계산되고 지표가 같은 표현은 동형이다. 이 규칙과 \(\sum(\dim W_i)^2 = |G|\)로 \(S_3\)의 지표표를 계산 몇 줄로 만들 수 있다.

9.4.4연습문제

기본

  1. 그림 1의 셋째 행이 자기 자신과의 내적 1을 가짐을 확인하여라.
    답

    \(\frac16(4 + 3\cdot0 + 2\cdot1) = 1\).

응용

  1. \(S_3\)의 2차원 표현과 자기 자신의 텐서곱(지표 \(\chi^2 = (4, 0, 1)\))을 분해하여라.
    답

    자명과 내적 \(\frac16(4 + 2) = 1\), 부호와 \(\frac16(4 + 2) = 1\), 2차원과 \(\frac16(8 - 2) = 1\). 세 기약표현이 하나씩.
