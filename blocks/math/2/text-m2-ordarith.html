순서수의 연산

본문
이 절에서 배울 것
  • 순서수의 덧셈(이어 붙이기)과 곱셈(복사해 늘어놓기)을 정의한다.
  • \(1 + \omega = \omega \ne \omega + 1\), \(2\cdot\omega = \omega \ne \omega\cdot2\)로 교환법칙이 깨짐을 보인다.
  • 결합법칙과 왼쪽 분배법칙은 성립함을 안다. 기수 연산과 비교한다.
먼저 알아야 할 것
  • 순서수와 순서형 (5.2절), 기수의 연산 (4.4절).

5.3.1이어 붙이기

정의 5.3.1 (순서수 덧셈, 곱셈)

덧셈 \(\alpha + \beta\): \(\alpha\) 모양의 줄 뒤에 \(\beta\) 모양의 줄을 이어 붙인 정렬순서의 순서형. (\(\{0\}\times\alpha \cup \{1\}\times\beta\)에 앞 성분 우선 사전식 순서)

곱셈 \(\alpha\cdot\beta\): \(\alpha\) 모양의 줄을 \(\beta\)번(\(\beta\) 모양으로) 늘어놓은 것. (\(\beta\times\alpha\)에 앞 성분 우선 사전식 순서)

유한 순서수에서는 보통의 덧셈·곱셈과 같습니다. 무한이 끼면 순서가 중요해집니다.

예제 5.3.2

(a) \(1 + \omega\)와 \(\omega + 1\) (b) \(2\cdot\omega\)와 \(\omega\cdot2\)를 비교하여라.

풀이. (a) \(1 + \omega\)는 점 하나 뒤에 \(0, 1, 2, \dots\)을 붙인 \(\ast, 0, 1, 2, \dots\)입니다. 맨 뒤 원소가 없고 \(\ast \mapsto 0\), \(n \mapsto n + 1\)로 \(\omega\)와 순서동형이라 \(1 + \omega = \omega\). 반면 \(\omega + 1\)은 \(0, 1, 2, \dots, \ast\)로 맨 뒤 원소가 있어 \(\omega\)가 아닙니다(\(\omega\)에는 최대 원소가 없음). 따라서 \(1 + \omega = \omega < \omega + 1\).

(b) \(2\cdot\omega\)는 "두 점짜리 묶음을 \(\omega\)번": \(a_0, b_0, a_1, b_1, a_2, b_2, \dots\)로 \(\omega\)와 같습니다. \(\omega\cdot2\)는 "\(\omega\) 줄을 두 번": \(0, 1, 2, \dots, 0', 1', 2', \dots\)로 \(\omega + \omega\)이고 \(\omega\)보다 큽니다(\(0'\)은 무한히 많은 원소 뒤에 옴). 따라서 \(2\cdot\omega = \omega < \omega\cdot2\).

규칙은 "앞에 붙은 유한한 것은 뒤의 무한에 흡수된다"입니다. 덧셈에서 왼쪽 끝에 놓인 유한 줄은 뒤의 \(\omega\)가 삼키지만, 오른쪽 끝에 놓인 것은 마지막에 남습니다.

5.3.2성립하는 법칙

정리 5.3.3

(a) \((\alpha + \beta) + \gamma = \alpha + (\beta + \gamma)\), \((\alpha\beta)\gamma = \alpha(\beta\gamma)\). (b) \(\alpha(\beta + \gamma) = \alpha\beta + \alpha\gamma\) (왼쪽 분배). (c) \(\beta < \gamma \Rightarrow \alpha + \beta < \alpha + \gamma\). 그러나 교환법칙, 오른쪽 분배 \((\alpha + \beta)\gamma = \alpha\gamma + \beta\gamma\), 오른쪽 덧셈의 순서 보존은 일반적으로 성립하지 않는다.

(a)는 세 줄을 이어 붙이는 순서가 괄호와 무관하다는 것입니다. 오른쪽 분배의 반례: \((1 + 1)\cdot\omega = 2\cdot\omega = \omega\)인데 \(1\cdot\omega + 1\cdot\omega = \omega\cdot2\). 오른쪽 순서 보존의 반례: \(1 < 2\)이지만 \(1 + \omega = 2 + \omega = \omega\).

\(\omega^2\)보다 작은 순서수는 모두 \(\omega\cdot a + b\) (\(a, b\)는 자연수) 꼴로 하나뿐인 표현을 가집니다(칸토어 표준형의 시작). 이 꼴의 덧셈 규칙은

\[(\omega a_1 + b_1) + (\omega a_2 + b_2) = \begin{cases}\omega(a_1 + a_2) + b_2 & a_2 > 0\\ \omega a_1 + (b_1 + b_2) & a_2 = 0\end{cases}\]

입니다. \(a_2 > 0\)이면 \(b_1\)이 사라지는 것이 "흡수"입니다. 같은 절의 탐구 카드에서 그림으로 확인할 수 있습니다.

5.3.3기수 연산과의 차이

기수 연산은 순서를 잊고 개수만 봅니다. 그래서 \(|1 + \omega| = |\omega + 1| = \aleph_0\)이고 기수 덧셈·곱셈은 교환됩니다. 순서수는 순서의 모양까지 기억하므로 더 세밀하고, 그 대가로 교환법칙을 잃습니다.

흔한 실수(1) \(\omega + 1 = 1 + \omega\)로 쓴다: 순서수에서는 다르다. (2) \(\omega\cdot2\)를 "\(2\)를 \(\omega\)번"으로 읽는다: 이 교재(와 대부분의 교재)에서 \(\alpha\cdot\beta\)는 \(\alpha\)를 \(\beta\)번 늘어놓은 것이다. (3) \(\omega + \omega\)와 \(\omega\)가 기수로 다르다고 한다: 둘 다 가산이다.
요약
  1. \(\alpha + \beta\): 이어 붙이기, \(\alpha\cdot\beta\): \(\alpha\)를 \(\beta\)번 늘어놓기.
  2. \(1 + \omega = \omega < \omega + 1\), \(2\omega = \omega < \omega2\): 교환법칙 실패.
  3. 결합법칙, 왼쪽 분배는 성립. 기수 연산은 교환적이다.

5.3.4연습문제

기본

  1. \(3 + \omega + 5\)와 \(\omega + 5 + \omega\)를 \(\omega a + b\) 꼴로 쓰라.
    답

    \(\omega + 5\)와 \(\omega\cdot2\).

응용

  1. \((\omega + 1)\cdot2\)와 \(\omega\cdot2 + 2\)를 비교하여라.
    답

    \((\omega + 1) + (\omega + 1) = \omega + (1 + \omega) + 1 = \omega\cdot2 + 1 < \omega\cdot2 + 2\).

심화

  1. \(\alpha + \beta = \beta + \alpha\)인 무한 순서수 \(\alpha \ne \beta\)의 예를 들어라.
    답

    \(\alpha = \omega\), \(\beta = \omega\cdot2\): 둘 다 \(\omega\cdot3\).
