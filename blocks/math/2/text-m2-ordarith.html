순서수의 연산

본문

자연수의 덧셈에서는 \(1 + n = n + 1\)이다. 그런데 순서수 \(\omega\) 앞에 점 하나를 붙인 줄과 뒤에 점 하나를 붙인 줄은 같은 모양일까? 줄을 이어 붙이는 것으로 덧셈을 정의하면 교환법칙은 어떻게 될까?

먼저 알아야 할 것순서수와 순서동형(5.2절)을 쓴다.

5.3.1이어 붙이기

정의 5.3.1 (순서수 덧셈, 곱셈)

\(\alpha + \beta\)는 \(\alpha\) 모양의 줄 뒤에 \(\beta\) 모양의 줄을 이어 붙인 정렬순서의 순서형이다. 정확히는 \(\{0\}\times\alpha \cup \{1\}\times\beta\)에 앞 성분을 먼저 비교하는 사전식 순서를 준 것이다. \(\alpha\cdot\beta\)는 \(\alpha\) 모양의 줄을 \(\beta\) 모양으로 늘어놓은 것, 곧 \(\beta\times\alpha\)에 앞 성분 우선 사전식 순서를 준 것의 순서형이다.

유한 순서수에서는 보통의 덧셈·곱셈과 같다. 그러나 무한이 끼면 순서가 중요해진다.

예제 5.3.2

(1) \(1 + \omega\)와 \(\omega + 1\) (2) \(2\cdot\omega\)와 \(\omega\cdot2\)를 비교하여라.

풀이. (1) \(1 + \omega\)는 점 하나 뒤에 \(0, 1, 2, \dots\)을 붙인 \(\ast, 0, 1, 2, \dots\)이다. 맨 뒤 원소가 없고 \(\ast \mapsto 0\), \(n \mapsto n + 1\)로 \(\omega\)와 순서동형이라 \(1 + \omega = \omega\)이다. 반면 \(\omega + 1\)은 \(0, 1, 2, \dots, \ast\)로 맨 뒤 원소가 있으므로, 최대 원소가 없는 \(\omega\)와 다르다. 따라서 \(1 + \omega = \omega < \omega + 1\)이다.

(2) \(2\cdot\omega\)는 두 점짜리 묶음을 \(\omega\)번 늘어놓은 \(a_0, b_0, a_1, b_1, a_2, b_2, \dots\)라 \(\omega\)와 같다. \(\omega\cdot2\)는 \(\omega\) 줄을 두 번 늘어놓은 \(0, 1, 2, \dots, 0', 1', 2', \dots\)라 \(\omega + \omega\)이고, \(0'\)이 무한히 많은 원소 뒤에 오므로 \(\omega\)보다 크다. 따라서 \(2\cdot\omega = \omega < \omega\cdot2\)이다.

그러므로 규칙은 "앞에 붙은 유한한 것은 뒤의 무한에 흡수된다"이다. 덧셈에서 왼쪽 끝의 유한한 줄은 뒤의 \(\omega\)가 삼키지만, 오른쪽 끝에 놓인 것은 마지막에 남는다. 그림 1에서 \((\omega + 2) + \omega\)를 고르면 가운데의 두 점이 뒤의 \(\omega\)에 삼켜져 결과가 \(\omega\cdot2\)가 되는 것을 볼 수 있다.

5.3.2성립하는 법칙

정리 5.3.3

(1) \((\alpha + \beta) + \gamma = \alpha + (\beta + \gamma)\)이고 \((\alpha\beta)\gamma = \alpha(\beta\gamma)\)이다. (2) 왼쪽 분배법칙 \(\alpha(\beta + \gamma) = \alpha\beta + \alpha\gamma\)가 성립한다. (3) \(\beta < \gamma \Rightarrow \alpha + \beta < \alpha + \gamma\)이다. 그러나 교환법칙, 오른쪽 분배법칙 \((\alpha + \beta)\gamma = \alpha\gamma + \beta\gamma\), 오른쪽 덧셈의 순서 보존은 일반적으로 성립하지 않는다.

(1)은 세 줄을 이어 붙이는 순서가 괄호와 무관하다는 것이다. 오른쪽 분배법칙의 반례로 \((1 + 1)\cdot\omega = 2\cdot\omega = \omega\)인데 \(1\cdot\omega + 1\cdot\omega = \omega\cdot2\)이다. 오른쪽 순서 보존의 반례로는 \(1 < 2\)이지만 \(1 + \omega = 2 + \omega = \omega\)이다.

\(\omega^2\)보다 작은 순서수는 모두 \(\omega\cdot a + b\) (\(a, b\)는 자연수) 꼴의 하나뿐인 표현을 가지며, 이것이 칸토어 표준형의 시작이다. 이 꼴의 덧셈 규칙은 다음과 같다.

\[(\omega a_1 + b_1) + (\omega a_2 + b_2) = \begin{cases}\omega(a_1 + a_2) + b_2 & a_2 > 0\\ \omega a_1 + (b_1 + b_2) & a_2 = 0\end{cases}\]

즉 \(a_2 > 0\)이면 \(b_1\)이 사라지며, 이것이 흡수이다.

5.3.3기수 연산과의 차이

기수 연산은 순서를 잊고 개수만 본다. 그래서 \(|1 + \omega| = |\omega + 1| = \aleph_0\)이고 기수의 덧셈과 곱셈은 교환된다. 하지만 순서수는 순서의 모양까지 기억하므로 더 세밀하고, 그 대가로 교환법칙을 잃는다.

흔한 오해\(\omega + 1 = 1 + \omega\)로 쓰기 쉽지만 순서수에서는 둘이 다르다. 또 \(\omega\cdot2\)를 "2를 \(\omega\)번"으로 읽는 실수가 있는데, 이 교재와 대부분의 교재에서 \(\alpha\cdot\beta\)는 \(\alpha\)를 \(\beta\)번 늘어놓은 것이다. \(\omega + \omega\)와 \(\omega\)가 기수로 다르다고 여기는 것도 틀렸으며, 둘 다 가산이다.
마무리

처음 질문의 두 줄은 같은 모양이 아니다. 앞에 붙인 점은 \(\omega\)에 흡수되어 \(1 + \omega = \omega\)이지만, 뒤에 붙인 점은 마지막 원소로 남아 \(\omega + 1\)이 된다. 그래서 순서수 덧셈은 이어 붙이기, 곱셈 \(\alpha\cdot\beta\)는 \(\alpha\)를 \(\beta\)번 늘어놓기로 정의되며 교환법칙이 성립하지 않는다. 결합법칙과 왼쪽 분배법칙은 성립하고, 순서를 잊는 기수 연산은 교환적이다.

5.3.4연습문제

기본

  1. \(3 + \omega + 5\)와 \(\omega + 5 + \omega\)를 \(\omega a + b\) 꼴로 쓰라.
    답

    \(\omega + 5\)와 \(\omega\cdot2\).

응용

  1. \((\omega + 1)\cdot2\)와 \(\omega\cdot2 + 2\)를 비교하여라.
    답

    \((\omega + 1) + (\omega + 1) = \omega + (1 + \omega) + 1 = \omega\cdot2 + 1 < \omega\cdot2 + 2\).

심화

  1. \(\alpha + \beta = \beta + \alpha\)인 무한 순서수 \(\alpha \ne \beta\)의 예를 들어라.
    답

    \(\alpha = \omega\), \(\beta = \omega\cdot2\): 둘 다 \(\omega\cdot3\).
