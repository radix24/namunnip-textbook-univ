공집합에서 자연수 만들기

본문
이 절에서 배울 것
  • 폰 노이만 방식 \(0 = \varnothing\), \(n + 1 = n \cup \{n\}\)으로 자연수를 만든다.
  • 무한 공리로 \(\omega\)를 "가장 작은 귀납 집합"으로 정의하고 귀납법이 정리가 됨을 본다.
  • 자연수의 순서와 덧셈을 집합으로 정의한다.
먼저 알아야 할 것
  • ZF 공리 (7.2절), 순서수 (5.2절), 수학적 귀납법 (1.3절).

7.3.1무에서 수를

ZF에는 집합만 있습니다. 그렇다면 수 3은 무엇일까요? 폰 노이만은 "\(n\)은 원소가 \(n\)개인 표준 집합"이 되도록 정했습니다.

  • \(0 = \varnothing\)
  • \(1 = \{0\} = \{\varnothing\}\)
  • \(2 = \{0, 1\} = \{\varnothing, \{\varnothing\}\}\)
  • \(3 = \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}\)
정의 7.3.1 (후속, 귀납 집합)

후속 \(S(x) = x \cup \{x\}\). 짝 공리와 합집합 공리로 집합이다.

귀납 집합: \(\varnothing\)을 포함하고 \(x \in I \Rightarrow S(x) \in I\)인 집합 \(I\). 무한 공리가 이런 집합이 하나 있다고 보장한다.

자연수 전체 \(\omega\): 모든 귀납 집합의 교집합(가장 작은 귀납 집합). 무한 공리의 집합 \(I_0\) 안에서 분리로 "모든 귀납 집합에 속하는 원소"를 골라낸다.

이 정의에서 \(n\)의 원소는 정확히 \(0, 1, \dots, n - 1\)이라 원소가 \(n\)개이고, \(m < n \iff m \in n \iff m \subsetneq n\)입니다. 순서가 \(\in\)으로, 크기 비교가 포함으로 바로 표현됩니다. 같은 절의 탐구 카드에서 중괄호가 얼마나 빨리 늘어나는지 볼 수 있습니다.

7.3.2귀납법은 정리가 된다

정리 7.3.2 (귀납 원리)

\(A \subseteq \omega\)가 \(0 \in A\)이고 \(n \in A \Rightarrow S(n) \in A\)이면 \(A = \omega\).

증명.가정으로 \(A\)는 귀납 집합이다. \(\omega\)는 모든 귀납 집합의 교집합이므로 \(\omega \subseteq A\). 따라서 \(A = \omega\). ∎

1.3절에서 귀납법을 "받아들인 원리"로 썼다면, ZF에서는 \(\omega\)의 정의에서 바로 나오는 정리입니다. "가장 작게" 정의했기 때문에 그 안에 귀납으로 닿지 않는 원소가 있을 수 없습니다.

7.3.3연산

덧셈은 재귀적으로 정의합니다(재귀 정리로 이런 함수가 하나뿐임을 보장).

\[m + 0 = m, \qquad m + S(n) = S(m + n).\]

예: \(2 + 1 = 2 + S(0) = S(2 + 0) = S(2) = 3\), \(2 + 2 = S(2 + 1) = S(3) = 4\). 곱셈도 \(m\cdot0 = 0\), \(m\cdot S(n) = m\cdot n + m\)으로 정의하고, 교환법칙·결합법칙·분배법칙을 귀납법으로 증명합니다(8.1절의 페아노 공리). 이 정의는 5.3절의 순서수 덧셈을 \(\omega\)에 제한한 것과 같습니다.

흔한 실수(1) \(\varnothing\)과 \(\{\varnothing\}\)을 같다고 본다: 0과 1이다. (2) "3이 정말 \(\{0, 1, 2\}\)인가"를 묻는다: 이것은 표준 모델일 뿐이고, 수학에서 쓰는 성질(페아노 공리)만 만족하면 다른 구성(체르멜로의 \(n + 1 = \{n\}\))도 된다. 중요한 것은 구조다.
요약
  1. \(0 = \varnothing\), \(S(n) = n\cup\{n\}\): \(n = \{0, \dots, n - 1\}\), \(m < n \iff m \in n\).
  2. \(\omega\) = 가장 작은 귀납 집합(무한 공리 + 분리). 귀납 원리는 정리.
  3. 덧셈·곱셈은 재귀로 정의한다.

7.3.4연습문제

기본

  1. \(\bigcup 3\)과 \(\mathcal P(1)\)을 구하여라.
    답

    \(\bigcup\{0, 1, 2\} = 0 \cup 1 \cup 2 = \{0, 1\} = 2\). \(\mathcal P(1) = \{\varnothing, \{0\}\} = \{0, 1\} = 2\).

응용

  1. 재귀 정의로 \(1 + 1 = 2\)와 \(2\cdot2 = 4\)를 계산하여라.
    답

    \(1 + S(0) = S(1 + 0) = S(1) = 2\). \(2\cdot S(1) = 2\cdot1 + 2\), \(2\cdot1 = 2\cdot S(0) = 0 + 2 = 2\), 그래서 \(2 + 2 = 4\).

심화

  1. 모든 \(n \in \omega\)에 대해 \(n \subseteq \omega\) (\(\omega\)가 추이적)임을 귀납법으로 보여라.
    답

    \(0 = \varnothing \subseteq \omega\). \(n \subseteq \omega\)이면 \(S(n) = n\cup\{n\} \subseteq \omega\) (\(n \in \omega\)). 이 성질을 가진 \(n\)의 집합이 귀납 집합이라 \(\omega\) 전체.
