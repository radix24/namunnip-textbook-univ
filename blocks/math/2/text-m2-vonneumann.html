공집합에서 자연수 만들기

본문

ZF에는 집합만 있고 수는 따로 없다. 그렇다면 수 3은 무엇일까? 그리고 지금까지 원리로 받아들여 온 수학적 귀납법은 ZF에서 어떻게 정당화될까?

먼저 알아야 할 것ZF 공리(7.2절), 순서수(5.2절), 강한 귀납법(1.3절)을 쓴다.

7.3.1무에서 수를

폰 노이만은 "\(n\)은 원소가 \(n\)개인 표준 집합"이 되도록 자연수를 정했다. 곧 \(0 = \varnothing\), \(1 = \{0\} = \{\varnothing\}\), \(2 = \{0, 1\} = \{\varnothing, \{\varnothing\}\}\), \(3 = \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}\)이다. 그림 1에서 보듯 중괄호는 빠르게 겹쳐 쌓인다.

정의 7.3.1 (후속, 귀납 집합)

\(x\)의 후속은 \(S(x) = x \cup \{x\}\)이며, 짝 공리와 합집합 공리로 집합이다. \(\varnothing\)을 포함하고 \(x \in I \Rightarrow S(x) \in I\)인 집합 \(I\)를 귀납 집합이라 하며, 무한 공리가 이런 집합이 하나 있다고 보장한다. 모든 귀납 집합의 교집합, 곧 가장 작은 귀납 집합을 자연수 전체 \(\omega\)라 한다. 이것은 무한 공리의 집합 \(I_0\) 안에서 분리 공리로 "모든 귀납 집합에 속하는 원소"를 골라내 얻는다.

이 정의에서 \(n\)의 원소는 정확히 \(0, 1, \dots, n - 1\)이라 원소가 \(n\)개이고, \(m < n \iff m \in n \iff m \subsetneq n\)이다. 즉 순서가 \(\in\)으로, 크기 비교가 포함으로 바로 표현된다.

7.3.2귀납법은 정리가 된다

정리 7.3.2 (귀납 원리)

\(A \subseteq \omega\)가 \(0 \in A\)이고 \(n \in A \Rightarrow S(n) \in A\)이면 \(A = \omega\)이다.

증명.가정으로 \(A\)는 귀납 집합이다. \(\omega\)는 모든 귀납 집합의 교집합이므로 \(\omega \subseteq A\)이다. 따라서 \(A = \omega\)이다. ∎

1.3절에서는 귀납법을 받아들인 원리로 썼지만, ZF에서는 \(\omega\)의 정의에서 바로 나오는 정리이다. \(\omega\)를 가장 작게 정의했기 때문에 그 안에 귀납으로 닿지 않는 원소가 있을 수 없다.

7.3.3연산

덧셈은 재귀적으로 \(m + 0 = m\), \(m + S(n) = S(m + n)\)으로 정의하며, 재귀 정리가 이런 함수가 하나뿐임을 보장한다. 예를 들어 \(2 + 1 = 2 + S(0) = S(2 + 0) = S(2) = 3\)이고 \(2 + 2 = S(2 + 1) = S(3) = 4\)이다. 곱셈도 \(m\cdot0 = 0\), \(m\cdot S(n) = m\cdot n + m\)으로 정의하고, 교환법칙·결합법칙·분배법칙을 귀납법으로 증명한다(8.1절의 페아노 공리). 이 정의는 5.3절의 순서수 덧셈을 \(\omega\)에 제한한 것과 같다.

흔한 오해\(\varnothing\)과 \(\{\varnothing\}\)을 같다고 보기 쉽지만, 앞의 것은 0이고 뒤의 것은 1이다. 또 "3이 정말 \(\{0, 1, 2\}\)인가"를 묻는 경우가 있는데, 이것은 표준 모델일 뿐이다. 수학에서 쓰는 성질(페아노 공리)만 만족하면 체르멜로의 \(n + 1 = \{n\}\) 같은 다른 구성도 되며, 중요한 것은 구조이다.
마무리

처음 질문에 답하면, 폰 노이만의 구성에서 3은 집합 \(\{0, 1, 2\}\)이다. \(0 = \varnothing\)에서 시작해 후속 \(S(n) = n \cup \{n\}\)을 되풀이하면 \(n = \{0, \dots, n - 1\}\)이 되고, 순서는 \(\in\)으로 표현된다. 자연수 전체 \(\omega\)를 가장 작은 귀납 집합으로 정의하므로 귀납 원리는 정리가 되며, 덧셈과 곱셈은 재귀로 정의한다.

7.3.4연습문제

기본

  1. \(\bigcup 3\)과 \(\mathcal P(1)\)을 구하여라.
    답

    \(\bigcup\{0, 1, 2\} = 0 \cup 1 \cup 2 = \{0, 1\} = 2\). \(\mathcal P(1) = \{\varnothing, \{0\}\} = \{0, 1\} = 2\).

응용

  1. 재귀 정의로 \(1 + 1 = 2\)와 \(2\cdot2 = 4\)를 계산하여라.
    답

    \(1 + S(0) = S(1 + 0) = S(1) = 2\). \(2\cdot S(1) = 2\cdot1 + 2\), \(2\cdot1 = 2\cdot S(0) = 0 + 2 = 2\), 그래서 \(2 + 2 = 4\).

심화

  1. 모든 \(n \in \omega\)에 대해 \(n \subseteq \omega\) (\(\omega\)가 추이적)임을 귀납법으로 보여라.
    답

    \(0 = \varnothing \subseteq \omega\). \(n \subseteq \omega\)이면 \(S(n) = n\cup\{n\} \subseteq \omega\) (\(n \in \omega\)). 이 성질을 가진 \(n\)의 집합이 귀납 집합이라 \(\omega\) 전체.
