증명 방법: 직접 증명, 대우, 귀류법

본문

\(n^2 + n + 41\)에 \(n = 0, 1, 2, \dots\)를 차례로 넣으면 41, 43, 47, 53, …으로 소수만 나온다. 마흔 번을 확인해도 소수가 이어진다면 "모든 자연수 \(n\)에서 소수"라고 말해도 될까? 예를 아무리 많이 모아도 증명이 되지 않는다면, 증명은 무엇으로 하는 것일까?

먼저 알아야 할 것명제와 한정기호, 대우(1.1절)와 짝수·홀수, 약수의 뜻을 쓴다.

1.2.1증명의 뼈대

그림 1의 슬라이더를 40까지 밀면 \(40^2 + 40 + 41 = 1681 = 41 \times 41\)이 나온다. 마흔 개의 예가 모두 맞아도 "모든 \(n\)"은 거짓이었던 것이다. 그래서 "모든"을 보이려면 예를 모으는 대신 아무 원소에나 통하는 논증이 필요하다.

대부분의 정리는 "\(\forall x,\ P(x) \Rightarrow Q(x)\)" 꼴이고, 그 증명은 늘 "임의의 \(x\)를 잡고 \(P(x)\)를 가정하자"로 시작한다. 특정한 \(x\)가 아니라 아무 \(x\)나 잡았으므로, 끝에서 \(Q(x)\)를 얻으면 모든 \(x\)에 대해 보인 것이 된다.

정의 1.2.1 (세 가지 증명 방법)

직접 증명은 \(P\)를 가정하고 정의와 이미 아는 사실로 \(Q\)를 이끈다. 대우에 의한 증명은 \(P \Rightarrow Q \equiv \neg Q \Rightarrow \neg P\)를 써서 \(\neg Q\)를 가정하고 \(\neg P\)를 이끈다. 귀류법은 \(P\)와 \(\neg Q\)를 함께 가정하고 어떤 \(R\)과 \(\neg R\)이 함께 성립하는 모순을 이끌어, \(\neg(P \Rightarrow Q) \equiv P \wedge \neg Q\)가 불가능함을 보인다.

1.2.2예로 보는 선택

예제 1.2.2 (직접 증명)

두 홀수의 곱은 홀수임을 보여라.

풀이. 홀수의 정의 "\(n = 2k + 1\)인 정수 \(k\)가 있다"를 그대로 쓴다. 임의의 홀수 \(m = 2a + 1\), \(n = 2b + 1\)에 대해 \(mn = 4ab + 2a + 2b + 1 = 2(2ab + a + b) + 1\)이고 \(2ab + a + b\)는 정수이므로 \(mn\)은 홀수이다. 그러므로 가정과 결론이 모두 "있다"로 정의되어 다루기 쉬울 때 직접 증명이 자연스럽다.

예제 1.2.3 (대우)

정수 \(n\)에 대해 \(n^2\)이 짝수이면 \(n\)도 짝수임을 보여라.

풀이. 직접 하면 \(n^2 = 2k\)에서 \(n\)에 대해 말하기 어렵다(\(n = \sqrt{2k}\)로는 아무것도 알 수 없다). 대우 "\(n\)이 홀수이면 \(n^2\)이 홀수"는 예제 1.2.2에서 \(m = n\)인 경우라 바로 끝난다. 따라서 결론이 부정형이거나 가정이 다루기 어려울 때 대우가 편하다.

예제 1.2.4 (귀류법)

\(\sqrt2\)는 유리수가 아님을 보여라.

풀이. "유리수가 아니다"는 부정형이라 직접 다룰 대상이 없다. 유리수라고 가정해 \(\sqrt2 = \frac pq\) (\(p, q\)는 서로소인 정수, \(q \ne 0\))로 둔다. 제곱하면 \(p^2 = 2q^2\)이라 \(p^2\)이 짝수이고, 예제 1.2.3으로 \(p = 2r\)이다. 대입하면 \(4r^2 = 2q^2\), 곧 \(q^2 = 2r^2\)이라 \(q\)도 짝수이다. \(p, q\)가 모두 짝수이므로 서로소라는 가정과 모순이다. 따라서 \(\sqrt2\)는 무리수이다.

예제 1.2.5 (존재와 반례)

(1) 무리수 \(a, b\)로 \(a^b\)가 유리수인 것이 있음을 보여라. (2) "모든 소수 \(p\)에 대해 \(2^p - 1\)은 소수"를 반박하여라.

풀이. (1) \(x = \sqrt2^{\sqrt2}\)가 유리수이면 \(a = b = \sqrt2\)로 끝난다. 무리수이면 \(a = x\), \(b = \sqrt2\)로 잡아 \(a^b = \sqrt2^{2} = 2\)이다. 어느 경우인지 몰라도 어느 경우든 그런 \(a, b\)가 있으므로 존재는 증명된다. (2) 한편 반박에는 반례 하나면 된다. \(2^{11} - 1 = 2047 = 23\times89\)이다.

1.2.3방법 고르기

가정을 정의로 풀어 쓴 식이 그대로 결론으로 이어지면 직접 증명을 쓴다. 결론이 "~가 아니다" 꼴이거나 결론의 부정이 다루기 쉬우면 대우를 쓴다. "~는 없다", "무리수이다", "무한히 많다"처럼 직접 붙잡을 대상이 없으면 귀류법이 알맞다. 마지막으로 "모든"이 거짓임을 보일 때는 그림 1의 \(n = 40\)처럼 반례 하나를 들고, "존재"를 보일 때는 하나를 만들어 보인다.

흔한 오해예 몇 개를 확인하고 "모든"을 증명했다고 여기기 쉽지만, 그림 1처럼 마흔 개의 예도 증명이 되지 못한다. "\(P \Rightarrow Q\)" 대신 역 "\(Q \Rightarrow P\)"를 보이는 실수도 흔하다. 또 귀류법에서는 무엇과 모순인지 밝혀야 한다. 모순은 가정 중 하나나 이미 증명된 사실과 맞서야 한다.
마무리

처음 질문에 답하면, 마흔 번의 확인으로는 "모든 \(n\)"을 말할 수 없고 실제로 \(n = 40\)에서 깨진다. "모든 \(x\)"는 임의의 \(x\)를 잡아 보이고, "존재"는 만들어 보이며, "모든"의 반박은 반례 하나로 한다. 증명 방법은 직접 증명, 대우(\(\neg Q \Rightarrow \neg P\)), 귀류법(\(P \wedge \neg Q\)에서 모순)이 있고, 결론이 부정형이면 대우나 귀류법이 편하다.

1.2.4연습문제

기본

  1. 정수 \(a, b\)에 대해 \(ab\)가 홀수이면 \(a\)와 \(b\)가 모두 홀수임을 대우로 보여라.
    답

    대우는 \(a\)나 \(b\)가 짝수이면 \(ab\)가 짝수. \(a = 2k\)이면 \(ab = 2(kb)\).

응용

  1. 소수가 무한히 많음을 귀류법으로 보여라.
    답

    유한하다면 \(p_1, \dots, p_k\)가 전부. \(N = p_1\cdots p_k + 1\)의 소인수 \(p\)는 어떤 \(p_i\)인데 \(p_i\)는 \(N\)을 나누면 1도 나눠 모순.

심화

  1. \(\log_2 3\)이 무리수임을 보여라.
    답

    \(\log_23 = \frac pq\) (\(p, q > 0\))이면 \(2^p = 3^q\)인데 왼쪽은 짝수, 오른쪽은 홀수.
