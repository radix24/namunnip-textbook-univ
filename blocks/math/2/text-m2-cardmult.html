기수의 덧셈과 곱셈

본문

자연수 집합과 그 순서쌍 집합 \(\mathbb N \times \mathbb N\)은 크기가 같다. 실수와 평면도 크기가 같다. 무한 집합은 제곱해도 커지지 않는 것일까? 모든 무한 기수 \(\kappa\)에서 \(\kappa\cdot\kappa = \kappa\)일까?

먼저 알아야 할 것순서수와 초한귀납법(5.1절, 5.2절), 기수의 비교와 Cantor-Bernstein 정리(4.3절)를 쓴다. 기수는 그와 크기가 같은 가장 작은 순서수(초기 순서수)로 정해 둔다.

9.1.1정의

두 기수 \(\kappa = |A|\), \(\lambda = |B|\)에 대해 \(\kappa + \lambda = |A \sqcup B|\), \(\kappa\cdot\lambda = |A \times B|\), \(\kappa^\lambda = |A^B|\)로 정한다. 여기서 \(A \sqcup B\)는 서로소로 만든 합집합이고 \(A^B\)는 \(B\)에서 \(A\)로 가는 함수 전체이다. 대표 집합을 바꾸어도 전단사로 옮겨지므로 값은 잘 정의된다. 유한 기수에서는 보통의 덧셈, 곱셈, 거듭제곱과 같다.

자연수 산술의 법칙 가운데 결합·교환·분배 법칙과 \(\kappa^{\lambda + \mu} = \kappa^\lambda\kappa^\mu\), \((\kappa^\lambda)^\mu = \kappa^{\lambda\mu}\)는 대표 집합 사이의 자연스러운 전단사로 그대로 성립한다. 가령 \((A^B)^C\)의 원소는 \(C\)에서 \(A^B\)로 가는 함수이고, 이것은 \(B \times C\)에서 \(A\)로 가는 함수와 일대일로 대응한다. 무한에서 새로 생기는 현상은 덧셈과 곱셈이 거의 아무 일도 하지 않는다는 것이다.

9.1.2κ·κ = κ

정리 9.1.1 (Hessenberg)

모든 무한 기수 \(\kappa\)에서 \(\kappa\cdot\kappa = \kappa\)이다.

증명.\(\kappa\)에 대한 초한귀납법이다. \(\kappa\)보다 작은 모든 무한 기수 \(\lambda\)에서 \(\lambda\cdot\lambda = \lambda\)라고 하자. 순서수 쌍 \(\kappa \times \kappa\)에 그림 1의 순서를 준다. 곧 \((\alpha, \beta) < (\gamma, \delta)\)를 \(\max(\alpha, \beta) < \max(\gamma, \delta)\)이거나, 최댓값이 같고 사전식으로 앞설 때로 정한다. 이것은 정렬순서이다. 이제 쌍 \((\alpha, \beta)\)보다 앞선 쌍들을 보자. \(\gamma = \max(\alpha, \beta) + 1 < \kappa\)라 하면 앞선 쌍은 모두 \(\gamma \times \gamma\) 안에 있다. \(\gamma\)가 유한이면 그 개수는 유한이고, 무한이면 귀납 가정으로 \(|\gamma \times \gamma| = |\gamma|\cdot|\gamma| = |\gamma| < \kappa\)이다. 따라서 모든 쌍의 앞선 부분이 \(\kappa\)보다 작고, 정렬순서의 순서형은 \(\kappa\) 이하이다. 그러면 \(\kappa\cdot\kappa \le \kappa\)이고, \(\kappa \le \kappa\cdot\kappa\)는 자명하므로 등호이다. ∎

증명에서 \(\kappa\)가 초기 순서수라는 사실이 쓰였다. \(\kappa\)보다 작은 순서수는 크기가 \(\kappa\)보다 작다는 것이 바로 초기 순서수의 정의이기 때문이다.

9.1.3덧셈과 곱셈은 최댓값이다

정리 9.1.1에서 곧바로 덧셈과 곱셈이 계산된다. \(\kappa\), \(\lambda\) 가운데 적어도 하나가 무한이고 둘 다 0이 아니면 \(\mu = \max(\kappa, \lambda)\)에 대해 \(\mu \le \kappa + \lambda \le \mu + \mu = 2\mu \le \mu\cdot\mu = \mu\)이다. 곱셈도 같은 사슬로 \(\kappa\cdot\lambda = \mu\)이다.

예제 9.1.2

\(\aleph_0 + \mathfrak c\), \(\aleph_0\cdot\mathfrak c\), \(\mathfrak c\cdot\mathfrak c\)를 구하고, 평면 \(\mathbb R^2\)이 직선 \(\mathbb R\)과 크기가 같음을 설명하여라. 여기서 \(\mathfrak c = 2^{\aleph_0}\)이다.

풀이. 셋 다 최댓값 \(\mathfrak c\)이다. 그러면 \(|\mathbb R^2| = \mathfrak c\cdot\mathfrak c = \mathfrak c = |\mathbb R|\)이다. 거듭제곱 법칙으로도 \(\mathfrak c\cdot\mathfrak c = 2^{\aleph_0}2^{\aleph_0} = 2^{\aleph_0 + \aleph_0} = 2^{\aleph_0}\)이 나온다. Cantor가 이 사실을 처음 보았을 때 "보지만 믿을 수 없다"고 적었다는 일화가 남아 있다.

반면 거듭제곱은 최댓값이 아니다. Cantor 정리로 \(2^\kappa > \kappa\)이고, \(2^{\aleph_0}\)이 어느 \(\aleph\)인지는 ZFC로 정해지지 않는다(연속체 가설의 독립성). 다음 절에서 거듭제곱에 걸리는 몇 안 되는 제약 가운데 하나를 본다.

마무리

순서쌍을 최댓값 순서로 늘어놓으면 \(\kappa \times \kappa\)가 순서형 \(\kappa\) 이하로 정렬되어 \(\kappa\cdot\kappa = \kappa\)이다. 그 결과 무한 기수의 덧셈과 곱셈은 둘 가운데 큰 쪽을 돌려줄 뿐이다. 무한 기수 산술의 어려움은 모두 거듭제곱에 남는다.

9.1.4연습문제

기본

  1. \(\aleph_0^{\aleph_0} = 2^{\aleph_0}\)임을 보여라.
    답

    \(2^{\aleph_0} \le \aleph_0^{\aleph_0} \le (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0\cdot\aleph_0} = 2^{\aleph_0}\).

응용

  1. 무한 집합 \(A\)의 유한 부분집합 전체의 크기가 \(|A|\)임을 보여라.
    답

    크기 \(n\)인 부분집합은 \(|A^n| = |A|\)개 이하이고, \(n\)에 대해 합하면 \(\aleph_0\cdot|A| = |A|\). 한원소 집합만으로도 \(|A|\)개이다.
