1 + ω와 ω + 1은 왜 다른가

탐구 · 순서수 덧셈과 흡수

질문

순서수의 덧셈은 줄을 이어 붙이는 것입니다. 붙이는 순서를 바꾸면 길이가 달라질까요? 무엇이 사라지고 무엇이 남을까요?

복원

\((\omega a_1 + b_1) + (\omega a_2 + b_2)\)는 \(a_2 > 0\)이면 \(\omega(a_1 + a_2) + b_2\), 아니면 \(\omega a_1 + (b_1 + b_2)\) (5.3절).

해 보기

  1. 처음 화면은 \(\alpha = 1\), \(\beta = \omega\)입니다. 위 줄 \(1 + \omega\)는 파란 막대 하나 뒤에 \(\omega\) 블록이 이어져 결국 \(\omega\)이고, 아래 줄 \(\omega + 1\)은 \(\omega\) 블록 뒤에 막대 하나가 남아 더 깁니다.
  2. \(\alpha\)의 낱개를 5로 늘려도 \(\alpha + \beta = \omega\) 그대로입니다. 앞에 놓인 유한 개는 몇 개든 뒤의 \(\omega\)에 흡수됩니다.
  3. \(\alpha = \omega + 3\), \(\beta = \omega + 2\)로 두면 \(\alpha + \beta = \omega\cdot2 + 2\), \(\beta + \alpha = \omega\cdot2 + 3\)입니다. 각 줄에서 마지막 블록의 낱개만 살아남습니다.
  4. \(\alpha = \omega\), \(\beta = \omega\cdot2\)처럼 낱개가 없으면 순서를 바꿔도 같습니다(\(\omega\cdot3\)).

설명

  1. 흡수가 일어나는 이유\(b + \omega\)는 \(b\)개 뒤에 \(0, 1, 2, \dots\)이 오는 줄입니다. 번호를 \(b\)칸씩 당기면 \(\omega\)와 순서동형입니다. 반면 \(\omega + b\)는 무한히 많은 원소 뒤에 \(b\)개가 있어 최대 원소가 있고, 어떻게 번호를 다시 붙여도 \(\omega\)가 되지 않습니다.
  2. 기수로 보면위아래 두 줄의 원소 수(기수)는 늘 같습니다. 모두 가산이기 때문입니다. 순서수는 원소 수가 아니라 줄의 모양(무엇이 무엇 뒤에 오는가)을 기록합니다.

판단

"\(\omega\)는 무한이니 \(\omega + 1 = \omega\)"는 틀립니다. 기수로는 \(\aleph_0 + 1 = \aleph_0\)이 맞지만 순서수로는 \(\omega + 1 > \omega\)입니다. 같아지는 것은 \(1 + \omega = \omega\)입니다.
