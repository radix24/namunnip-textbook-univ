같은 자연수, 다른 순서수

예제 · 순서형 찾기

먼저 예측

자연수 전체를 (가) \(3, 4, 5, \dots, 0, 1, 2\) (나) \(0, 2, 4, \dots, 1, 3, 5, \dots\) (다) \(1, 0, 3, 2, 5, 4, \dots\)로 늘어놓았습니다. 각각 어떤 순서수와 순서동형일까요?

예측 확인

(가) \(\omega + 3\), (나) \(\omega\cdot2\), (다) \(\omega\). 모두 기수는 \(\aleph_0\)입니다.

(가), (나), (다)의 순서형을 구하고, 서로 순서동형이 아님을 보여라.

전략

순서형은 정렬순서에서 순서수로 가는 순서동형으로 정해집니다(5.2절). 순서동형이 아님을 보일 때는 순서동형이 보존하는 성질(최대 원소의 유무, 극한 원소의 개수)을 비교합니다.

풀이

  1. (가) \(3 + k \mapsto k\) (\(k \ge 0\)), \(0 \mapsto \omega\), \(1 \mapsto \omega + 1\), \(2 \mapsto \omega + 2\)는 순서동형이다. 순서형 \(\omega + 3\).
    앞부분 \(3, 4, \dots\)이 \(\omega\), 뒤에 세 개.
  2. (나) \(2k \mapsto k\), \(2k + 1 \mapsto \omega + k\). 순서형 \(\omega + \omega = \omega\cdot2\).
    짝수 줄과 홀수 줄이 각각 \(\omega\).
  3. (다) \(n\)번째 자리의 원소를 \(n\)으로 보내면 순서동형. 순서형 \(\omega\).
    이웃끼리 바꿔도 줄의 모양은 그대로.
  4. (가)는 최대 원소(2)가 있고, (나)와 (다)는 없다. 따라서 (가)는 나머지와 순서동형이 아니다.
    순서동형은 최대 원소를 최대 원소로 보낸다.
  5. (나)에는 극한 원소(1, 앞에 무한히 많은 원소가 있고 직전이 없음)가 있고 (다)에는 없다. 따라서 (나)와 (다)도 다르다.
    (다)의 모든 원소는 앞에 유한개만 있다.

검산

(가)에서 0의 앞에는 \(3, 4, 5, \dots\) 무한히 많은 원소가 있고 직전 원소가 없으므로 0은 극한 원소, 순서수 \(\omega\)에 대응합니다. 대소도 맞습니다: \(\omega < \omega + 3 < \omega\cdot2\).

의미

가산 정렬순서는 모두 기수가 \(\aleph_0\)이지만 순서형은 \(\omega, \omega + 1, \dots, \omega\cdot2, \dots, \omega^2, \dots\) 끝없이 다릅니다. 이 가산 순서수 전체의 상한이 첫 비가산 순서수 \(\omega_1\)입니다.

이해 확인

\(\mathbb N\)을 "5로 나눈 나머지가 작은 것부터, 같으면 크기순"으로 늘어놓으면 순서형은?

답

\(\omega\cdot5\).
