아무것도 없는 것에서 3을 만들기

탐구 · 폰 노이만 자연수

질문

공집합 \(\varnothing\) 하나와 중괄호만으로 자연수를 만들면 어떤 모양일까요? 수가 커질수록 그 집합을 펼쳐 쓴 글은 얼마나 길어질까요?

복원

\(0 = \varnothing\), \(S(n) = n \cup \{n\}\)이라 \(n = \{0, 1, \dots, n - 1\}\)이다 (7.3절).

해 보기

  1. \(n = 3\)이면 \(\{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}\), 18글자에 \(\varnothing\)이 4개입니다. 큰 원 안에 0(빈 원), 1(빈 원 하나를 품은 원), 2가 있습니다.
  2. \(n\)을 하나씩 늘리면 \(\varnothing\)의 개수가 1, 1, 2, 4, 8, 16, 32로 두 배씩 늘어납니다. \(n + 1\)은 \(n\)의 원소를 모두 가지고 \(n\) 자신도 가지므로 \(\varnothing\)이 \(n\)의 두 배입니다.
  3. \(n = 6\)이면 158글자입니다. 원소는 6개뿐인데 펼쳐 쓰면 길어지는 것은, 각 원소가 다시 자기보다 작은 수들을 품고 있기 때문입니다.
  4. 그림에서 원 \(m\)이 원 \(n\) 안에 직접 들어 있는 것(\(m \in n\))과 \(m < n\)이 같은 뜻임을 확인하세요.

설명

  1. 순서가 소속으로\(m < n \iff m \in n \iff m \subsetneq n\). 대소, 소속, 포함이 한 가지로 정리되어, 자연수의 성질을 집합의 공리만으로 증명할 수 있습니다.
  2. 길이는 상관없다수학에서 3을 쓸 때 이 긴 표현을 쓰지는 않습니다. 이 구성은 "자연수가 집합론 안에 존재한다"는 것을 보여 주는 모델이고, 실제 계산은 페아노 공리(8.1절)의 성질만 씁니다.

판단

"\(2 = \{\varnothing, \varnothing\}\)"은 틀립니다. 외연 공리로 \(\{\varnothing, \varnothing\} = \{\varnothing\} = 1\)입니다. \(2\)의 두 원소는 \(\varnothing\)과 \(\{\varnothing\}\)으로 서로 다릅니다.
