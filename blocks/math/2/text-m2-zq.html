자연수에서 정수와 유리수로

본문

자연수 안에서는 \(3 - 5\)도 \(3 \div 5\)도 할 수 없다. 음수와 분수가 아직 없는 세계에서, 집합만 가지고 정수와 유리수를 어떻게 만들어 낼 수 있을까?

먼저 알아야 할 것동치관계와 동치류(3.1절), 폰 노이만 자연수(7.3절)를 쓴다.

8.1.1페아노 공리

공리 8.1.1 (페아노)

집합 \(\mathbb N\), 원소 \(0\), 함수 \(S: \mathbb N \to \mathbb N\)이 다음을 만족한다. (P1) \(0\)은 어떤 수의 후속도 아니다. (P2) \(S\)는 단사이다. (P3) \(0\)을 포함하고 \(S\)에 닫힌 부분집합은 \(\mathbb N\) 전체이다(귀납 공리).

7.3절의 \(\omega\)가 이 공리를 만족한다. 덧셈과 곱셈을 재귀로 정의하면 교환·결합·분배법칙, 소거법칙(\(a + c = b + c \Rightarrow a = b\)), 순서의 성질이 모두 귀납법으로 증명된다. 하지만 \(\mathbb N\)에서는 처음 질문처럼 \(3 - 5\)나 \(3 \div 5\)를 할 수 없다.

8.1.2정수는 빼기의 결과를 미리 만든 것

"\(a - b\)"를 아직 수로 쓸 수 없으니 쌍 \((a, b)\)로 기록해 둔다. 그런데 \(5 - 3\)과 \(7 - 5\)는 같은 수여야 한다. \(a - b = c - d\)를 빼기 없이 쓰면 \(a + d = b + c\)이다.

정의 8.1.2 (정수)

\(\mathbb N\times\mathbb N\)에서 \((a, b) \sim (c, d) \iff a + d = b + c\)로 정하고, 동치류 \([(a, b)]\) 전체를 \(\mathbb Z\)라 한다. 연산은 \([(a, b)] + [(c, d)] = [(a + c, b + d)]\), \([(a, b)]\cdot[(c, d)] = [(ac + bd, ad + bc)]\)이다.

여기서 곱셈 공식은 \((a - b)(c - d) = (ac + bd) - (ad + bc)\)에서 왔다. \(\mathbb N\)의 \(n\)은 \([(n, 0)]\)으로, 음수 \(-n\)은 \([(0, n)]\)으로 들어간다. 그림 1에서 각 대각선이 정수 하나이다.

정리 8.1.3

\(\sim\)는 동치관계이고, 덧셈은 대표원에 무관하게 잘 정의된다.

증명.추이를 보이자. \(a + d = b + c\)와 \(c + f = d + e\)를 더하면 \(a + d + c + f = b + c + d + e\)이고, \(\mathbb N\)의 소거법칙으로 \(c + d\)를 지우면 \(a + f = b + e\)이다. 이제 \((a, b) \sim (a', b')\), \((c, d) \sim (c', d')\)이면 \(a + b' = b + a'\), \(c + d' = d + c'\)이다. 두 식을 더하면 \((a + c) + (b' + d') = (b + d) + (a' + c')\), 곧 \((a + c, b + d) \sim (a' + c', b' + d')\)이므로 덧셈이 잘 정의된다. ∎

8.1.3유리수는 나누기의 결과를 미리 만든 것

정의 8.1.4 (유리수)

\(\mathbb Z\times(\mathbb Z\setminus\{0\})\)에서 \((a, b) \sim (c, d) \iff ad = bc\)로 정한다. 동치류 \([(a, b)]\)를 \(\frac ab\)로 쓰고 전체를 \(\mathbb Q\)라 하며, \(\frac ab + \frac cd = \frac{ad + bc}{bd}\), \(\frac ab\cdot\frac cd = \frac{ac}{bd}\)로 연산한다.

정리 8.1.5

\(\mathbb Q\)의 덧셈과 곱셈은 잘 정의되고, \(\mathbb Q\)는 체이다.

증명.\(ab' = a'b\), \(cd' = c'd\)라 하자. 덧셈에서 보일 것은 \((ad + bc)b'd' = (a'd' + b'c')bd\)이다. 왼쪽은 \(ab'dd' + bb'cd'\)이고, 가정을 대입하면 \(a'bdd' + bb'c'd = (a'd' + b'c')bd\)이다. 곱셈의 \(acb'd' = a'bc'd\)는 두 가정을 곱한 것이다. 끝으로 \(\frac ab \ne 0\)이면 \(a \ne 0\)이고 \(\frac ab\cdot\frac ba = \frac{ab}{ab} = \frac11\)이므로 \(\frac ba\)가 역원이다. ∎

여기서 잘 정의됨이 요점이다. \(\frac12 = \frac24\)이므로 \(\frac12 + \frac13\)과 \(\frac24 + \frac13\)의 결과가 같아야 한다. 실제로 \(\frac56\)과 \(\frac{10}{12}\)은 \(5\cdot12 = 6\cdot10\)이라 같은 동치류이다. 유리수에서도 그림 1처럼 동치류는 격자 위의 직선, 곧 원점을 지나는 직선으로 보인다.

흔한 오해동치류 대신 기약분수로 유리수를 정의하면 연산 결과를 매번 약분해야 한다. 기약분수끼리 더해도 \(\frac16 + \frac13 = \frac36\)처럼 기약이 아닐 수 있기 때문이며, 동치류로 정의하면 이 문제가 없다. 또 \(\frac ab + \frac cd = \frac{a + c}{b + d}\)로 정의하면 잘 정의되지 않는다. \(\frac12 + \frac11 = \frac23\)이지만 \(\frac24 + \frac11 = \frac35\)이다.
마무리

처음 질문에 답하면, 정수와 유리수는 아직 할 수 없는 계산의 결과를 쌍으로 기록하고 같은 결과를 뜻하는 쌍들을 동치류로 묶어 만든다. \(\mathbb Z\)는 \(a + d = b + c\)로 묶은 \(\mathbb N\times\mathbb N\)의 동치류이고, \(\mathbb Q\)는 \(ad = bc\)로 묶은 \(\mathbb Z\times(\mathbb Z\setminus\{0\})\)의 동치류이다. 연산은 대표원에 무관하게 잘 정의되며, 그 바탕인 자연수의 산술은 페아노 공리에서 나온다.

8.1.4연습문제

기본

  1. 정수의 정의로 \([(2, 5)] + [(4, 1)]\)과 \([(2, 5)]\cdot[(4, 1)]\)을 계산하고 보통의 정수로 확인하여라.
    답

    \([(6, 6)] = 0\) (\(-3 + 3\)). \([(8 + 5, 2 + 20)] = [(13, 22)] = -9\) (\(-3\cdot3\)).

응용

  1. 정수의 곱셈이 잘 정의됨을 보여라.
    답

    한 인수씩 바꾸면 충분. \((a, b) \sim (a', b')\)이면 \((ac + bd) + (a'd + b'c) = (ad + bc) + (a'c + b'd)\)를 보이면 된다. 좌변 \(-\) 우변 \(= c(a + b' - b - a') - d(a + b' - b - a') = 0\) (\(\mathbb N\)에서는 양변에 같은 것을 더해 정리).

심화

  1. \(\mathbb Z\)에서 \([(a, b)] \le [(c, d)] \iff a + d \le b + c\)가 잘 정의된 전순서임을 보여라.
    답

    \((a, b) \sim (a', b')\)이면 \(a + d \le b + c \iff a' + d \le b' + c\) (\(a + d \le b + c\)의 양변에 \(b'\)을 더하고 \(a + b' = b + a'\)를 쓰면 \(b + a' + d \le b + b' + c\), \(b\)를 소거). 전순서는 \(\mathbb N\)의 전순서에서.
