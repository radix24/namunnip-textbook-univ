모든 자연수는 이진법으로 하나뿐인 표현을 가진다

증명 · 강한 귀납법과 정렬 원리
정리 모든 양의 정수 \(n\)은 서로 다른 2의 거듭제곱의 합으로 쓸 수 있고, 그 방법은 하나뿐이다.

쓰는 것

  • 강한 귀납법과 정렬 원리 (1.3절).
  • 등비수열의 합 \(1 + 2 + \dots + 2^{k-1} = 2^k - 1\).

아이디어

존재: \(n\) 이하인 가장 큰 2의 거듭제곱 \(2^k\)를 떼어 내면 남는 \(n - 2^k\)가 더 작고 \(2^k\)보다도 작아, 강한 귀납법으로 처리된다. 유일성: 표현이 둘인 수가 있다면 그런 수 중 가장 작은 것(정렬 원리)을 잡아 모순을 낸다.

  1. (존재) \(n = 1 = 2^0\)이면 성립. \(n \ge 2\)이고 \(n\)보다 작은 모든 양의 정수가 표현을 가진다고 하자.
    강한 귀납법의 가정.
  2. \(2^k \le n < 2^{k+1}\)인 \(k\)를 잡는다. \(n = 2^k\)이면 끝. 아니면 \(m = n - 2^k\)는 \(0 < m < 2^k\).
    \(n < 2^{k+1} = 2\cdot2^k\)에서 뺌.
  3. \(m < n\)이라 가정으로 \(m\)은 서로 다른 2의 거듭제곱의 합이고, 각 항은 \(m < 2^k\) 이하라 \(2^k\)와 다르다. 따라서 \(n = 2^k + m\)도 서로 다른 거듭제곱의 합.
    \(2^k\)가 이미 쓰였다면 \(m \ge 2^k\)가 되어 모순.
  4. (유일성) 표현이 둘인 양의 정수가 있다면, 그런 수 중 최소인 \(n\)을 잡는다.
    정렬 원리.
  5. 두 표현의 가장 큰 항을 \(2^a\), \(2^b\) (\(a < b\))라 하면 첫 표현의 합은 \(1 + 2 + \dots + 2^a = 2^{a+1} - 1 < 2^b \le n\)이라 \(n\)이 될 수 없다. 따라서 \(a = b\).
    서로 다른 거듭제곱의 합은 같은 최고항의 등비합 이하.
  6. 두 표현에서 \(2^a\)를 떼면 \(n - 2^a\)가 서로 다른 두 표현을 가진다. \(n - 2^a = 0\)이면 두 표현이 같았고, 아니면 \(n\)보다 작은 반례라 최소성에 모순.
    최소 반례 논법.

되짚기

존재는 강한 귀납법(바로 앞이 아니라 \(n - 2^k\)라는 훨씬 작은 수를 씀), 유일성은 정렬 원리(최소 반례)로 보였다. 두 원리가 동치라서 어느 쪽으로 써도 되고, 증명하기 편한 쪽을 고르면 된다. 예: \(45 = 32 + 8 + 4 + 1 = 101101_{(2)}\).

이해 확인

같은 논법으로 "모든 양의 정수는 서로 다른 3의 거듭제곱의 합"이라 할 수 있는가?

답

아니다. 2는 1과 3으로 만들 수 없다. 3진법에서는 각 자리 숫자가 0, 1, 2라 같은 거듭제곱을 두 번까지 써야 한다. 2진법의 증명에서 \(m < 2^k\)가 "같은 항을 다시 쓰지 않음"을 보장한 부분이 3진법에서는 깨진다.
