완전 방정식의 초기값 문제

예제 · 등고선 하나 고르기

먼저 예측

완전 방정식의 해는 등고선 \(F = C\)들의 모임이다. 초기 조건 \(y(0) = 1\)은 무엇을 정할까?

예측 확인

상수 \(C\), 곧 그 점을 지나는 등고선 하나이다.

\((2xy + 1)\,dx + (x^2 + 3y^2)\,dy = 0\), \(y(0) = 1\)을 풀고, \(x = 1\)에서 \(y\)가 만족하는 식을 구하여라.

전략

완전 방정식(1.3절 예 1.3.2)이라 해는 \(x^2y + x + y^3 = C\). 초기 조건으로 \(C\)를 정한다.

풀이

  1. \(M_y = 2x = N_x\), \(F = x^2y + x + y^3\).
    완전성 확인과 퍼텐셜.
  2. \((0, 1)\)에서 \(F = 0 + 0 + 1 = 1\). 해 곡선 \(x^2y + x + y^3 = 1\).
    \(C = 1\).
  3. \(x = 1\)이면 \(y + 1 + y^3 = 1\), 곧 \(y^3 + y = 0\), \(y(y^2 + 1) = 0\)이라 \(y = 0\).
    실근은 0 하나.

검산

음함수 미분으로 \(\frac{dy}{dx} = -\frac{2xy + 1}{x^2 + 3y^2}\)이 원래 방정식과 같다. \((0, 1)\)에서 기울기 \(-\frac13\), \((1, 0)\)에서 \(-1\)로, 곡선이 \((0, 1)\)에서 \((1, 0)\)으로 내려가는 모양과 맞다.

의미

해를 \(y = \)의 꼴로 풀지 못해도 음함수 \(F = C\)로 해를 완전히 알 수 있다. \(F\)는 물리에서 보존량(에너지 같은)의 역할을 한다.

이해 확인

같은 방정식에서 \(y(1) = 1\)이면 해 곡선은?

답

\(F(1, 1) = 1 + 1 + 1 = 3\): \(x^2y + x + y^3 = 3\).
