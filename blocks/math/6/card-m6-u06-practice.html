경계치 문제와 그린 함수 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(y'' + \lambda y = 0\), \(y(0) = 0\), \(y'(L) = 0\)의 고유값과 고유함수를 구하여라. [06-01]

    힌트 1

    \(y = \sin\mu x\)에서 \(\cos\mu L = 0\)(6.1절).

    힌트 2

    \(\mu L = \frac\pi2, \frac{3\pi}2, \dots\).

    풀이

    \(\lambda_n = \left(\frac{(2n - 1)\pi}{2L}\right)^2\), \(y_n = \sin\frac{(2n-1)\pi x}{2L}\). 한쪽이 자유로운 막대(오른쪽 끝 기울기 0)의 진동 모드.

  2. 증명\(-y'' = \lambda y\), \(y(0) = y(\pi) = 0\)에서 \(\lambda \le 0\)이면 해가 0뿐임을 에너지 방법(\(y\)를 곱해 적분)으로 보여라. [06-01]

    힌트 1

    \(-\int y''y = \int(y')^2\) (부분적분, 경계항 0).

    힌트 2

    \(\int(y')^2 = \lambda\int y^2\).

    풀이

    \(\int_0^\pi(y')^2 = \lambda\int_0^\pi y^2\). \(\lambda < 0\)이면 왼쪽 \(\ge 0\), 오른쪽 \(\le 0\)이라 둘 다 0, \(y = 0\). \(\lambda = 0\)이면 \(y' = 0\), \(y\) 상수, \(y(0) = 0\)이라 0. ∎

  3. 개념\(\int_0^\pi\sin2x\sin3x\,dx\)와 \(\int_0^\pi\sin^22x\,dx\)를 직교성으로 바로 말하여라. [06-01]

    힌트 1

    서로 다른 고유값의 고유함수.

    힌트 2

    \(\sin^2 = \frac{1 - \cos2\theta}2\).

    풀이

    0과 \(\frac\pi2\).

  4. 계산\(-u'' = 1\), \(u(0) = 0\), \(u'(1) = 0\)을 그린 함수 \(G = \min(x, s)\)로 풀어라. [06-02]

    힌트 1

    \(u = \int_0^1\min(x, s)\,ds\)(6.2절).

    힌트 2

    \(\int_0^xs\,ds + \int_x^1x\,ds\).

    풀이

    \(\frac{x^2}2 + x(1 - x) = x - \frac{x^2}2\). 검산 \(-u'' = 1\), \(u(0) = 0\), \(u'(1) = 0\).

  5. 증명\(-u'' = f\), \(u(0) = u(1) = 0\)의 그린 함수가 \(G(x, s) \ge 0\)임을 보이고, \(f \ge 0\)이면 \(u \ge 0\)임을 결론지어라. [06-02]

    힌트 1

    \(x(1 - s)\), \(s(1 - x)\)는 \([0,1]\)에서 음이 아님.

    힌트 2

    음이 아닌 것의 적분.

    풀이

    \(G \ge 0\)이라 \(u = \int Gf \ge 0\). 아래로 누르면 늘 아래로 처진다(최대원리의 한 형태). ∎

  6. 판단한 학생이 "\(-u'' = 1\), \(u'(0) = u'(1) = 0\)도 그린 함수로 풀면 된다"고 썼다. 맞는가? [06-02]

    힌트 1

    동차 문제 \(-u'' = 0\), \(u'(0) = u'(1) = 0\)의 해는?

    힌트 2

    방정식을 \([0,1]\)에서 적분해 보세요.

    풀이

    틀렸다. 상수가 동차해라 0이 고유값이고 그린 함수가 없다. 실제로 \(\int_0^1-u'' = u'(0) - u'(1) = 0\)인데 \(\int1 = 1\)이라 해가 없다. 양 끝이 단열된 막대에 열을 계속 넣으면 정상상태가 없다는 물리적 뜻과 맞다.
