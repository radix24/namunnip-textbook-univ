아벨 공식과 계수 축소법

본문

\(t^2y'' - 3ty' + 4y = 0\)의 해 \(y = t^2\)은 대입해 보면 쉽게 찾는다. 그런데 이계 방정식에는 해가 둘 필요하다. 해 하나를 알 때 둘째 해를 체계적으로 찾을 수 있을까? 그리고 해를 다 모르면서도 론스키안을 미리 알 수 있을까?

먼저 알아야 할 것론스키안과 기본해(2.1절), 일계 선형 방정식(1.1절)을 쓴다.

2.2.1아벨 공식

정리 2.2.1 (아벨)

\(y_1, y_2\)가 \(y'' + p(t)y' + q(t)y = 0\)의 해이면 \(W(t) = W(t_0)\exp\left(-\int_{t_0}^tp(s)\,ds\right)\)이다.

증명.\(W = y_1y_2' - y_1'y_2\)를 미분하면 \(y_1'y_2'\)항이 지워져 \(W' = y_1y_2'' - y_1''y_2\)이다. 여기에 \(y_i'' = -py_i' - qy_i\)를 넣으면 \(q\)가 들어간 항도 지워져 \(W' = -p(y_1y_2' - y_1'y_2) = -pW\)이다. 이 일계 선형 방정식의 해가 위 식이다. ∎

지수함수는 0이 되지 않으므로, \(W\)는 늘 0이거나 한 번도 0이 아니다. 따라서 2.1절의 "한 점이면 모든 점"이 식으로 확인된다. 또 해를 모르고도 \(W\)를 안다. 예를 들어 \(y'' + 2y' + 5y = 0\)이면 \(W = Ce^{-2t}\)이고, 예제 2.1.3의 \(2e^{-2t}\)와 맞는다.

2.2.2계수 축소법

해 하나 \(y_1\)을 알면 둘째 해를 \(y_2 = v(t)y_1(t)\)로 놓는다. 대입하면 \(y_1\)이 해이므로 \(v\)의 계수는 \(L[y_1] = 0\)이 되어 사라지고, \(v'\)과 \(v''\)만 남아 \(w = v'\)에 대한 일계 방정식이 된다.

\[y_1v'' + (2y_1' + py_1)v' = 0.\]

또는 아벨 공식으로 바로 구할 수도 있다. \(\left(\frac{y_2}{y_1}\right)' = \frac{y_1y_2' - y_1'y_2}{y_1^2} = \frac{W}{y_1^2}\)이고 \(W = e^{-\int p\,dt}\)로 잡을 수 있으므로 다음을 얻는다.

\[y_2 = y_1\int\frac{e^{-\int p\,dt}}{y_1^2}\,dt.\]
예제 2.2.2

(a) \(y'' - 2y' + y = 0\)의 해 \(y_1 = e^t\)로 둘째 해를 구하여라. (b) \(t^2y'' - 3ty' + 4y = 0\) (\(t > 0\))의 해 \(y_1 = t^2\)로 둘째 해를 구하여라.

풀이. (a) \(p = -2\)이므로 \(e^{-\int p} = e^{2t}\)이고 \(y_2 = e^t\int\frac{e^{2t}}{e^{2t}}dt = te^t\)이다. 중근일 때의 \(te^{rt}\)가 이렇게 나온다. (b) 표준형으로 나누면 \(p = -\frac3t\)이므로 \(e^{-\int p} = e^{3\ln t} = t^3\)이고 \(y_2 = t^2\int\frac{t^3}{t^4}dt = t^2\ln t\)이다. 검산하면 \(y_2' = 2t\ln t + t\), \(y_2'' = 2\ln t + 3\)이므로 \(t^2(2\ln t + 3) - 3t(2t\ln t + t) + 4t^2\ln t = 0\)이다. 이때 론스키안은 \(t^3\)으로 그림 1의 점선이다.

2.2.3코시-오일러 방정식

(b)는 \(at^2y'' + bty' + cy = 0\) 꼴이며 코시-오일러 방정식이라 한다. \(y = t^m\)을 넣으면 \(am(m - 1) + bm + c = 0\)이다. 근이 서로 다른 실근 \(m_1, m_2\)이면 해는 \(t^{m_1}\)과 \(t^{m_2}\)이다. 중근 \(m\)이면 예제 (b)처럼 \(t^m\)과 \(t^m\ln t\)이고, 복소근 \(\alpha \pm i\beta\)이면 \(t^\alpha\cos(\beta\ln t)\)와 \(t^\alpha\sin(\beta\ln t)\)이다. 같은 절의 예제 카드가 중근과 복소근의 경우를 더 다룬다.

왜 로그가 나올까? \(t = e^x\)로 치환하면 \(t\frac{d}{dt} = \frac{d}{dx}\)이므로 코시-오일러 방정식은 상수계수 방정식이 된다. 그러므로 상수계수의 \(e^{rx}\)와 \(xe^{rx}\)가 \(t^r\)과 \(t^r\ln t\)로 바뀐 것이다.

흔한 오해아벨 공식에서 \(p\)를 표준형, 곧 최고차 계수가 1인 꼴로 만들지 않고 쓰기 쉽다. 예제 (b)에서 \(p\)는 \(-3t\)가 아니라 \(-\frac3t\)이다. 또 계수 축소에서 \(v\) 자체가 식에 남는다고 여기는 것도 틀렸으며, \(y_1\)이 해이므로 \(v\)의 계수는 0이 된다.
마무리

처음 질문의 답은 둘 다 "그렇다"이다. 아벨 공식 \(W = Ce^{-\int p\,dt}\)가 해를 모르고도 론스키안을 주며, 그래서 \(W\)는 늘 0이거나 한 번도 0이 아니다. 해 하나 \(y_1\)을 알면 계수 축소 \(y_2 = y_1\int\frac{e^{-\int p}}{y_1^2}\,dt\)로 둘째 해를 얻고, 처음 방정식에서는 \(y_2 = t^2\ln t\)이다. 코시-오일러 방정식의 해는 \(t^m\)이며, 중근이면 \(t^m\ln t\)가 더해진다.

2.2.4연습문제

기본

  1. \(ty'' + y' + ty = 0\)의 두 해의 론스키안을 해를 모른 채 구하여라.
    답

    \(p = \frac1t\), \(W = \frac Ct\).

응용

  1. \(y'' + y = 0\)의 해 \(\cos t\)로 계수 축소를 하여 둘째 해를 구하여라.
    답

    \(\cos t\int\sec^2t\,dt = \cos t\tan t = \sin t\).

심화

  1. \(t^2y'' + ty' + y = 0\)의 일반해를 구하여라.
    답

    \(m(m-1) + m + 1 = m^2 + 1 = 0\), \(m = \pm i\). \(c_1\cos(\ln t) + c_2\sin(\ln t)\).
