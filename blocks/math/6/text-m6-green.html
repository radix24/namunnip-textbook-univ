그린 함수

본문

양 끝을 고정한 팽팽한 줄 위에 하중이 고르게, 또는 제멋대로 놓여 있다. 하중의 모양이 바뀔 때마다 미분방정식을 새로 풀어야 할까? 줄의 한 점만 눌렀을 때의 처짐을 알면 어떤 하중에 대해서도 처짐을 바로 적을 수 있지 않을까?

먼저 알아야 할 것매개변수 변환법과 합성곱 해(2.3절), 충격 반응(5.1절), 경계치 문제(6.1절)를 쓴다.

6.2.1한 점을 누르기

양 끝을 고정한 팽팽한 줄에 하중 \(f(x)\)가 걸리면 처짐 \(u\)는 \(-u'' = f\), \(u(0) = u(1) = 0\)을 따른다. 하중을 점 하중들의 모음으로 보면, 점 \(s\)에 단위 하중이 걸릴 때의 처짐 \(G(x, s)\)만 알면 된다. 왜냐하면 선형성에 따라 일반 하중의 처짐은 그것들을 더한 것, 곧 적분한 것이기 때문이다.

\[u(x) = \int_0^1G(x, s)f(s)\,ds.\]
정의 6.2.1 (그린 함수)

경계조건을 만족하는 \(L[u] = f\)의 해가 \(u(x) = \int_a^bG(x, s)f(s)\,ds\)로 주어지는 \(G\)를 그린 함수라 한다.

\(L = -(pu')' + qu\)일 때, \(x\)의 함수로 본 \(G(\cdot, s)\)는 \(x \ne s\)에서 \(L[G] = 0\)을 만족하고 경계조건도 만족한다. 또 \(x = s\)에서 연속이고, 도함수는 \(-\frac{1}{p(s)}\)만큼 뛴다. 이 도약은 점 \(s\)에 몰린 단위 하중, 곧 \(\delta(x - s)\)를 양변에 놓고 \(s\) 근처에서 적분한 결과이다.

6.2.2구성

왼쪽 경계조건을 만족하는 동차해 \(u_1\)과 오른쪽 경계조건을 만족하는 동차해 \(u_2\)를 잡는다. 그러면 \(G\)는 \(x < s\)에서 \(u_1\)의 배수이고 \(x > s\)에서 \(u_2\)의 배수이며, 두 배수는 \(x = s\)의 연속 조건과 도약 조건으로 정해진다.

정리 6.2.2

\(L[u] = -(pu')' + qu\)이고 \(u_1, u_2\)가 위와 같으며 \(p(u_1u_2' - u_1'u_2) = -C\)가 0이 아닌 상수이면 다음이 그린 함수이다.

\[G(x, s) = \frac{1}{C}\begin{cases} u_1(x)u_2(s) & x \le s \\ u_1(s)u_2(x) & x \ge s\end{cases}\]

증명.두 식은 \(x = s\)에서 모두 \(\frac1Cu_1(s)u_2(s)\)이므로 연속이다. 도함수의 도약은 \(\frac1C(u_1(s)u_2'(s) - u_1'(s)u_2(s)) = \frac1C\cdot\frac{-C}{p(s)} = -\frac1{p(s)}\)이므로 정의의 조건을 만족한다. \(x \ne s\)에서는 동차해의 배수이므로 \(L[G] = 0\)이고, 경계조건은 \(u_1\), \(u_2\)가 각각 만족한다. 이제 \(u = \int Gf\,ds\)를 두 번 미분하면 도약에서 \(f(x)\)가 나와 \(L[u] = f\)이다. ∎

\(pW\)가 상수인 것은 아벨 공식(2.2절)에서 나온다. 한편 \(C = 0\)이면 \(u_1\)과 \(u_2\)가 서로 배수이므로 0이 고유값이 되고, 그때는 그린 함수가 없어 해가 없거나 하나가 아니다.

예제 6.2.3

\(-u'' = f\), \(u(0) = u(1) = 0\)의 그린 함수를 구하고 \(f = 1\)일 때 풀어라.

풀이. \(p = 1\), \(q = 0\)이다. \(u_1(0) = 0\)인 \(u_1 = x\)와 \(u_2(1) = 0\)인 \(u_2 = 1 - x\)를 잡으면 \(u_1u_2' - u_1'u_2 = -x - (1 - x) = -1\)이므로 \(C = 1\)이다.

\[G(x, s) = \begin{cases} x(1 - s) & x \le s \\ s(1 - x) & x \ge s\end{cases}\]

\(f = 1\)이면 \(u(x) = \int_0^x s(1 - x)\,ds + \int_x^1x(1 - s)\,ds = (1 - x)\frac{x^2}2 + x\frac{(1 - x)^2}{2} = \frac{x(1 - x)}{2}\)이다. 검산하면 \(-u'' = 1\)이고 양 끝이 0이며, 가운데 처짐은 \(u(\frac12) = \frac18\)이다.

그림 1처럼 \(G(x, s)\)는 \(s\)를 누른 줄의 모양인 꺾인 삼각형이고, \(G(x, s) = G(s, x)\)로 대칭이다. 즉 \(s\)를 누를 때 \(x\)의 처짐은 \(x\)를 누를 때 \(s\)의 처짐과 같으며, 이것을 맥스웰 상반 정리라 한다. 이 대칭은 작용소의 대칭, 곧 라그랑주 항등식에서 나온다.

흔한 오해\(u_1\), \(u_2\)로 아무 동차해나 고르기 쉬운데, 각각 한쪽 경계조건을 만족해야 한다. 또 \(x \le s\)와 \(x \ge s\)의 식을 바꿔 쓰는 실수가 있으며, \(x\)가 왼쪽에 있으면 왼쪽 조건의 \(u_1(x)\)가 붙는다. 0이 고유값인데 그린 함수를 쓰는 것도 틀렸다. 가령 \(-u'' = f\), \(u'(0) = u'(1) = 0\)은 상수가 동차해이므로 그린 함수가 없고, \(\int f = 0\)일 때만 해가 있다.
마무리

처음 질문의 답은 "그렇다"이다. 점 \(s\)의 단위 하중에 대한 처짐 \(G(x, s)\), 곧 그린 함수를 한 번 구해 두면 어떤 하중 \(f\)에 대해서도 처짐은 \(u = \int G(x, s)f(s)\,ds\)이다. 그린 함수는 왼쪽 조건의 \(u_1\)과 오른쪽 조건의 \(u_2\)로 \(G = \frac1Cu_1(x_<)u_2(x_>)\)처럼 만든다. 줄 \(-u'' = f\), \(u(0) = u(1) = 0\)에서는 \(G = x_<(1 - x_>)\)인 꺾인 삼각형이고 대칭이다.

6.2.4연습문제

기본

  1. 예제의 그린 함수로 \(f = x\)일 때의 해를 구하여라.
    답

    \(u = \frac{x(1 - x^2)}{6}\). 검산 \(-u'' = x\).

응용

  1. \(-u'' = f\), \(u(0) = 0\), \(u'(1) = 0\)의 그린 함수를 구하여라.
    답

    \(u_1 = x\), \(u_2 = 1\). \(u_1u_2' - u_1'u_2 = -1\). \(G = \min(x, s)\).

심화

  1. \(-u'' - k^2u = f\), \(u(0) = u(1) = 0\)의 그린 함수를 구하고, \(k = \pi\)에서 무슨 일이 생기는지 설명하여라.
    답

    \(u_1 = \sin kx\), \(u_2 = \sin k(1 - x)\), \(C = k\sin k\). \(G = \frac{\sin kx_<\sin k(1 - x_>)}{k\sin k}\). \(k = \pi\)이면 \(\sin k = 0\): \(\pi^2\)이 고유값이라 그린 함수가 없다(공명).
