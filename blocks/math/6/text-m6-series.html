멱급수해와 수렴 반지름

본문

\((1 + t^2)y'' + 2ty' = 0\)의 한 해는 \(\arctan t\)이고, 이 함수는 모든 실수에서 매끄럽다. 그런데 원점에서 멱급수로 구한 해는 \(|t| > 1\)에서 발산한다. 실수축 어디에도 문제가 없는데, 왜 급수는 1에서 멈출까? 계수가 변하는 방정식의 해를 멱급수로 구할 때 수렴 범위는 무엇이 정할까?

먼저 알아야 할 것멱급수와 수렴 반지름, 비율판정법(수학7 2.4절 또는 미적분의 급수), 이계 선형 방정식(2.1절)을 쓴다.

4.1.1계수가 변하는 방정식

무지개와 양자역학에 나오는 에어리 방정식 \(y'' - ty = 0\)처럼 계수가 상수가 아니면 특성방정식을 쓸 수 없다. 대신 해를 멱급수로 가정하고 계수를 하나씩 정한다.

정의 4.1.1 (정상점, 특이점)

\(P(t)y'' + Q(t)y' + R(t)y = 0\)에서 \(P, Q, R\)이 다항식일 때, \(P(t_0) \ne 0\)이면 \(t_0\)을 정상점, \(P(t_0) = 0\)이면 특이점이라 한다. 여기서 \(t_0\)은 복소수여도 된다.

정리 4.1.2

\(t_0\)이 정상점이면 일반해는 \(t_0\) 중심의 멱급수 \(\sum a_n(t - t_0)^n\)이고, 그 수렴 반지름은 \(t_0\)에서 가장 가까운 복소 특이점까지의 거리 이상이다.

증명은 복소해석에서 해석함수의 성질로 하므로 여기서는 생략한다. 증명의 방향은 방정식을 \(P\)로 나눈 계수 \(\frac QP\), \(\frac RP\)가 특이점을 피하는 원판 안에서 멱급수로 쓰이고, 해도 그 원판 안에서 멱급수가 된다는 것이다.

4.1.2점화식 만들기

예제 4.1.3 (에어리)

\(y'' - ty = 0\)의 멱급수해를 \(t = 0\)에서 구하여라.

풀이. \(y = \sum_{n\ge0}a_nt^n\)이면 \(y'' = \sum_{n\ge0}(n + 2)(n + 1)a_{n+2}t^n\)이고 \(ty = \sum_{n\ge1}a_{n-1}t^n\)이다. 차수별로 비교하면 상수항에서 \(2a_2 = 0\)이고, \(n \ge 1\)인 \(t^n\)에서 다음 점화식을 얻는다.

\[(n + 2)(n + 1)a_{n+2} = a_{n-1}.\]

\(a_0, a_1\)은 초기값으로 자유롭고, \(a_2 = 0\)이므로 \(a_5 = a_8 = \dots = 0\)이다. \(a_0\) 계열은 \(a_3 = \frac{a_0}{6}\), \(a_6 = \frac{a_3}{30} = \frac{a_0}{180}\)이고, \(a_1\) 계열은 \(a_4 = \frac{a_1}{12}\), \(a_7 = \frac{a_4}{42} = \frac{a_1}{504}\)이다.

\[y = a_0\left(1 + \frac{t^3}{6} + \frac{t^6}{180} + \cdots\right) + a_1\left(t + \frac{t^4}{12} + \frac{t^7}{504} + \cdots\right).\]

계수가 \(\frac1{n^2}\)보다 빨리 줄어 모든 \(t\)에서 수렴한다. \(P = 1\)이라 특이점이 없으므로 정리 4.1.2와 맞는다.

4.1.3수렴 반지름은 복소평면이 정한다

예제 4.1.4

\((1 + t^2)y'' + 2ty' = 0\), \(y(0) = 0\), \(y'(0) = 1\)의 멱급수해와 수렴 반지름을 구하여라.

풀이. 왼쪽은 \(((1 + t^2)y')'\)이므로 \((1 + t^2)y' = 1\), 곧 \(y = \arctan t\)이다. 멱급수는 \(t - \frac{t^3}3 + \frac{t^5}5 - \cdots\)이고 수렴 반지름은 1이다. 그런데 \(\arctan t\)는 모든 실수에서 매끄럽다. 급수가 \(|t| > 1\)에서 발산하는 이유는 실수축이 아니라 복소평면에 있다. 즉 \(P = 1 + t^2\)이 \(t = \pm i\)에서 0이고, 원점에서 그 점까지의 거리가 1이다. 그림 1과 같은 절의 탐구 카드에서 부분합이 \(|t| = 1\)을 넘으며 갈라지는 모습을 볼 수 있다.

예제 4.1.5 (르장드르)

\((1 - t^2)y'' - 2ty' + \alpha(\alpha + 1)y = 0\)의 점화식을 구하고, \(\alpha\)가 자연수이면 다항식 해가 있음을 보여라.

풀이. 같은 방법으로 \(a_{n+2} = \frac{(n - \alpha)(n + \alpha + 1)}{(n + 2)(n + 1)}a_n\)이다. \(\alpha = m\)이 자연수이면 \(n = m\)에서 분자가 0이므로 같은 짝홀 계열이 끊기고, 차수 \(m\)인 다항식 해가 나온다. 이것이 르장드르 다항식(4.3절)이다. 한편 특이점 \(\pm1\)까지 거리가 1이므로 다른 해의 수렴 반지름은 1이다.

흔한 오해첨자를 맞추지 않고 차수를 비교하기 쉽다. \(y''\)의 합과 \(ty\)의 합은 시작하는 차수가 다르므로, 첨자를 옮겨 같은 \(t^n\)끼리 모아야 한다. 또 실수 특이점만 보는 것도 틀렸다. \(1 + t^2\)처럼 실근이 없어도 복소 특이점이 수렴 반지름을 제한한다.
마무리

처음 질문에 답하면, 멱급수해의 수렴 반지름은 중심에서 가장 가까운 복소 특이점, 곧 \(P = 0\)인 복소수까지의 거리 이상이다. \(1 + t^2\)은 \(\pm i\)에서 0이므로 \(\arctan t\)의 급수는 실수에서 아무 문제가 없어도 \(|t| = 1\)에서 멈춘다. 정상점에서는 \(y = \sum a_nt^n\)을 대입해 차수별로 점화식을 얻고, \(a_0, a_1\)이 초기값으로 자유롭다. 르장드르 방정식은 \(\alpha\)가 자연수이면 다항식 해를 가진다.

4.1.4연습문제

기본

  1. \(y'' + y = 0\)의 점화식을 구하고 \(\cos t\), \(\sin t\)의 급수를 확인하여라.
    답

    \(a_{n+2} = -\frac{a_n}{(n+2)(n+1)}\). \(a_0 = 1, a_1 = 0\)이면 \(1 - \frac{t^2}2 + \frac{t^4}{24} - \cdots\).

응용

  1. \((t^2 - 2t + 5)y'' + ty' + y = 0\)의 \(t = 0\) 중심 급수해의 수렴 반지름의 하한은?
    답

    근 \(1 \pm 2i\), 거리 \(\sqrt5\).

심화

  1. 르장드르 점화식으로 \(\alpha = 2\)의 다항식 해를 구하여라.
    답

    \(a_2 = \frac{(0-2)(3)}{2}a_0 = -3a_0\), \(a_4 = 0\). \(1 - 3t^2\) (정규화하면 \(P_2 = \frac12(3t^2 - 1)\)).
