존재와 유일성: 피카르 반복

본문

\(y' = t^2 + y^2\)은 어떤 공식으로도 풀리지 않는다. 그래도 컴퓨터는 해 곡선을 그려 준다. 그 곡선이 정말 하나뿐인 해를 근사하는 것일까, 아니면 해가 여럿이라 컴퓨터가 아무거나 고른 것일까? 해를 구하지 않고 해가 있고 하나뿐임을 보일 수 있을까?

먼저 알아야 할 것일계 방정식(1.1절), 미적분의 기본정리, 테일러 급수 \(e^t = \sum\frac{t^k}{k!}\)를 쓴다. 축소사상 원리(수학7 7.3절)를 알면 증명이 짧아진다.

1.2.1왜 존재를 묻는가

\(y' = t^2 + y^2\)은 1.1절의 어느 유형에도 맞지 않고, 해를 초등함수로 쓸 수 없다. 그런데 수치해를 그리면 곡선이 보인다. 그 곡선을 믿으려면 해가 있고 하나뿐이라는 것을 먼저 증명해야 하며, 다음 정리가 그 조건을 준다.

정리 1.2.1 (피카르-린델뢰프)

\(f(t, y)\)가 직사각형 \(R = \{|t - t_0| \le a, |y - y_0| \le b\}\)에서 연속이고 \(y\)에 대해 립시츠 조건 \(|f(t, y) - f(t, z)| \le L|y - z|\)를 만족하면, 어떤 \(h > 0\)에 대해 \(|t - t_0| \le h\)에서 \(y' = f(t, y)\), \(y(t_0) = y_0\)의 해가 정확히 하나 있다.

\(\frac{\partial f}{\partial y}\)가 \(R\)에서 연속이면 평균값 정리로 \(L = \max|f_y|\)인 립시츠 조건이 성립한다. 그래서 실제로는 "\(f\)와 \(f_y\)가 연속이면 해가 하나"로 기억해도 된다. 가령 \(f = t^2 + y^2\)은 \(f_y = 2y\)가 연속이므로, 처음 질문의 방정식은 어느 초기값에서든 짧은 구간에서 해가 하나뿐이다.

1.2.2적분방정식과 반복

미적분의 기본정리로, 연속인 \(y\)가 초기값 문제의 해라는 것은 다음과 같다.

\[y(t) = y_0 + \int_{t_0}^tf(s, y(s))\,ds.\]

오른쪽을 함수 \(y\)를 새 함수로 보내는 규칙 \(T\)로 보면, 해는 \(T(y) = y\)인 고정점이다. 피카르는 상수함수 \(y_0(t) \equiv y_0\)에서 시작해 \(y_{n+1} = T(y_n)\)을 되풀이했다.

예제 1.2.2

\(y' = 2t(1 + y)\), \(y(0) = 0\)에 피카르 반복을 세 번 적용하고 극한을 추측하여라.

풀이. \(y_0 = 0\)이다. \(y_1 = \int_0^t2s\,ds = t^2\)이고, \(y_2 = \int_0^t2s(1 + s^2)\,ds = t^2 + \frac{t^4}{2}\)이며, \(y_3 = \int_0^t2s\left(1 + s^2 + \frac{s^4}2\right)ds = t^2 + \frac{t^4}2 + \frac{t^6}{6}\)이다. 규칙은 \(\sum_{k=1}^n\frac{t^{2k}}{k!}\)이므로 극한은 \(e^{t^2} - 1\)이다. 실제로 변수분리로 풀면 \(\ln(1 + y) = t^2\), 곧 \(y = e^{t^2} - 1\)로 같다. 그림 1에서 \(y_3\)은 \(t = 0.8\) 근처까지 참 해와 거의 겹친다.

1.2.3증명

증명의 방향은 반복이 상자 \(R\)을 벗어나지 않게 구간 \(h\)를 정하고, 이웃한 두 반복의 차이가 계승으로 줄어드는 것을 보여 균등수렴을 얻는 것이다. 그러면 극한이 해이고, 같은 어림이 유일성도 준다.

증명.\(M = \max_R|f|\)로 두고 \(h \le \min(a, \frac bM)\)로 잡으면 \(|y_n(t) - y_0| \le M|t - t_0| \le b\)이므로, 모든 반복이 상자 안에 있어 다음 단계에서 \(f\)를 쓸 수 있다. 다음으로 귀납법으로 \(|y_{n+1}(t) - y_n(t)| \le \frac{ML^n|t - t_0|^{n+1}}{(n+1)!}\)을 보인다. 립시츠 조건이 매 단계 \(L\)을 곱하고, 적분이 \(\frac{|t - t_0|}{n+1}\)을 곱하기 때문이다. 이제 \(\sum\frac{ML^nh^{n+1}}{(n+1)!}\)은 지수급수이므로 수렴하고, 바이어슈트라스 M-판정법으로 \(y_n\)은 연속함수 \(y\)로 균등수렴한다. 균등수렴이므로 적분과 극한을 바꿀 수 있어 \(y = T(y)\)이다. 끝으로 해가 둘 \(y, z\)이면 \(|y - z| \le L\int|y - z|\)이고, 같은 귀납 어림을 되풀이하면 \(|y - z| \le \frac{C(Lh)^n}{n!} \to 0\)이므로 \(y = z\)이다. ∎

계승 \((n+1)!\) 덕분에 \(h\)를 아주 작게 잡지 않아도 수렴한다. 그래서 선형 방정식이면 해가 계수가 연속인 구간 전체에서 존재한다.

1.2.4조건이 깨지면

예제 1.2.3

(a) \(y' = 3y^{2/3}\), \(y(0) = 0\)과 (b) \(y' = y^2\), \(y(0) = 1\)의 해를 살펴라.

풀이. (a)에서는 \(y \equiv 0\)과 \(y = t^3\)이 모두 해이고, 더 나아가 임의의 \(c \ge 0\)에 대해 \(t \le c\)에서 0, \(t > c\)에서 \((t - c)^3\)인 함수도 해이다. 여기서 \(f_y = 2y^{-1/3}\)이 \(y = 0\)에서 발산하므로 립시츠 조건이 깨졌다. (b)의 해 \(y = \frac{1}{1 - t}\)은 \(t \to 1\)에서 발산한다. 즉 \(f = y^2\)은 매끄럽지만, 정리는 짧은 구간 \(h\)에서의 존재만 보장한다. 이것을 유한 시간 폭발이라 한다.

흔한 오해"\(f\)가 연속이면 해가 하나"라고 쓰기 쉽지만, 연속성만으로는 존재(페아노 정리)까지이고 유일성에는 립시츠 조건이 필요하다. 예제 1.2.3 (a)가 반례이다. 또 해가 \(f\)가 정의된 구간 전체에서 존재한다고 여기는 것도 틀렸으며, 비선형 방정식은 (b)처럼 유한 시간에 폭발할 수 있다.
마무리

처음 질문의 답은 "보일 수 있다"이다. \(f = t^2 + y^2\)과 \(f_y = 2y\)가 연속이므로 피카르-린델뢰프 정리에 따라 짧은 구간에서 해가 하나뿐이고, 컴퓨터의 곡선은 그 해를 근사한다. 초기값 문제는 적분방정식 \(y = y_0 + \int f(s, y)\,ds\)와 같으며, 피카르 반복의 차이가 \(\frac{ML^nh^{n+1}}{(n+1)!}\)로 줄어 균등수렴하고 극한이 유일한 해가 된다. 립시츠 조건이 없으면 해가 여럿일 수 있고, 비선형이면 유한 시간 폭발이 있을 수 있다.

1.2.5연습문제

기본

  1. \(y' = y\), \(y(0) = 1\)의 피카르 반복 \(y_3\)을 구하여라.
    답

    \(1 + t + \frac{t^2}2 + \frac{t^3}6\).

응용

  1. \(y' = \sqrt{|y|}\), \(y(0) = 0\)의 해를 둘 이상 찾아라.
    답

    \(y = 0\)과 \(y = \frac{t^2}4\) (\(t \ge 0\)), \(0\) (\(t < 0\)).

심화

  1. 본문 2단계의 부등식을 \(n = 1\)에서 확인하여라.
    답

    \(|y_2 - y_1| = \left|\int(f(s, y_1) - f(s, y_0))\right| \le L\int|y_1 - y_0| \le L\int M|s - t_0| = \frac{ML|t - t_0|^2}{2}\).
