1.2.1왜 존재를 묻는가

\(y' = t^2 + y^2\)은 1.1절의 어느 유형에도 맞지 않고, 해를 초등함수로 쓸 수 없습니다. 그래도 컴퓨터로 수치해를 그리면 곡선이 보입니다. 그 곡선이 정말 하나의 해를 근사하는지, 해가 둘이라서 컴퓨터가 아무거나 고른 것은 아닌지 확인하려면 존재와 유일성을 증명해야 합니다.

정리 1.2.1 (피카르-린델뢰프)

\(f(t, y)\)가 직사각형 \(R = \{|t - t_0| \le a, |y - y_0| \le b\}\)에서 연속이고 \(y\)에 대해 립시츠 조건 \(|f(t, y) - f(t, z)| \le L|y - z|\)를 만족하면, 어떤 \(h > 0\)에 대해 \(|t - t_0| \le h\)에서 \(y' = f(t, y)\), \(y(t_0) = y_0\)의 해가 정확히 하나 있다.

\(\frac{\partial f}{\partial y}\)가 \(R\)에서 연속이면 평균값 정리로 \(L = \max|f_y|\)인 립시츠 조건이 성립합니다. 그래서 실제로는 "\(f\)와 \(f_y\)가 연속이면 해가 하나"로 기억해도 됩니다.

1.2.2적분방정식과 반복

미적분의 기본정리로, 연속인 \(y\)가 초기값 문제의 해라는 것은 다음과 같습니다.

\[y(t) = y_0 + \int_{t_0}^tf(s, y(s))\,ds.\]

오른쪽을 함수 \(y\)를 새 함수로 보내는 규칙 \(T\)로 보면 해는 \(T(y) = y\)인 고정점입니다. 피카르는 아무 함수 \(y_0(t) \equiv y_0\)에서 시작해 \(y_{n+1} = T(y_n)\)을 되풀이했습니다.

예제 1.2.2

\(y' = 2t(1 + y)\), \(y(0) = 0\)에 피카르 반복을 세 번 적용하고 극한을 추측하여라.

풀이. \(y_0 = 0\). \(y_1 = \int_0^t2s\,ds = t^2\). \(y_2 = \int_0^t2s(1 + s^2)\,ds = t^2 + \frac{t^4}{2}\). \(y_3 = \int_0^t2s\left(1 + s^2 + \frac{s^4}2\right)ds = t^2 + \frac{t^4}2 + \frac{t^6}{6}\). 규칙은 \(\sum_{k=1}^n\frac{t^{2k}}{k!}\)이고 극한은 \(e^{t^2} - 1\)입니다. 실제로 변수분리로 풀면 \(\ln(1 + y) = t^2\), \(y = e^{t^2} - 1\)로 같습니다.

1.2.3증명의 흐름

  1. 반복이 상자를 벗어나지 않음: \(M = \max_R|f|\), \(h \le \min(a, \frac bM)\)이면 \(|y_n(t) - y_0| \le M|t - t_0| \le b\). 그래야 다음 단계에서 \(f\)를 쓸 수 있다.
  2. 차이가 빨리 줄어듦: 귀납법으로 \(|y_{n+1}(t) - y_n(t)| \le \frac{ML^n|t - t_0|^{n+1}}{(n+1)!}\). 립시츠 조건이 매 단계 \(L\)을 곱하고, 적분이 \(\frac{|t - t_0|}{n+1}\)을 곱한다.
  3. 균등수렴: \(\sum\frac{ML^nh^{n+1}}{(n+1)!}\)는 지수급수라 수렴하므로 \(y_n\)은 균등수렴한다(바이어슈트라스 M-판정법). 극한 \(y\)는 연속.
  4. 극한이 해: 균등수렴이라 적분과 극한을 바꿔 \(y = T(y)\).
  5. 유일성: 해가 둘 \(y, z\)이면 \(|y - z| \le L\int|y - z|\)에서 그론월 부등식(또는 같은 귀납 어림)으로 \(y = z\).

2단계의 계승 \((n+1)!\) 덕분에 \(h\)를 작게 잡지 않아도 수렴하며, 선형 방정식이면 해가 계수가 연속인 구간 전체에서 존재합니다.

1.2.4조건이 깨지면

예제 1.2.3

(a) \(y' = 3y^{2/3}\), \(y(0) = 0\) (b) \(y' = y^2\), \(y(0) = 1\)

풀이. (a) \(y \equiv 0\)과 \(y = t^3\)이 모두 해이고, 더 나아가 임의의 \(c \ge 0\)에 대해 "\(t \le c\)에서 0, \(t > c\)에서 \((t - c)^3\)"도 해입니다. \(f_y = 2y^{-1/3}\)이 \(y = 0\)에서 발산해 립시츠 조건이 깨졌습니다. (b) 해 \(y = \frac{1}{1 - t}\)은 \(t \to 1\)에서 발산합니다. \(f = y^2\)은 매끄럽지만 정리는 짧은 구간 \(h\)에서의 존재만 보장합니다(폭발).

흔한 실수(1) "\(f\)가 연속이면 해가 하나"라고 쓴다: 연속성만으로는 존재(페아노 정리)까지이고, 유일성에는 립시츠 조건이 필요하다(예제 (a)). (2) 존재 구간이 \(f\)가 정의된 구간 전체라고 생각한다: 비선형이면 유한 시간에 폭발할 수 있다(예제 (b)).
요약
  1. 초기값 문제 ⇔ 적분방정식 \(y = y_0 + \int f(s, y)\,ds\).
  2. 피카르 반복의 차이는 \(\frac{ML^nh^{n+1}}{(n+1)!}\)로 줄어 균등수렴하고, 극한이 유일한 해다.
  3. 립시츠가 없으면 해가 여러 개, 비선형이면 유한 시간 폭발이 있을 수 있다.

1.2.5연습문제

기본

  1. \(y' = y\), \(y(0) = 1\)의 피카르 반복 \(y_3\)을 구하여라.
    답

    \(1 + t + \frac{t^2}2 + \frac{t^3}6\).

응용

  1. \(y' = \sqrt{|y|}\), \(y(0) = 0\)의 해를 둘 이상 찾아라.
    답

    \(y = 0\)과 \(y = \frac{t^2}4\) (\(t \ge 0\)), \(0\) (\(t < 0\)).

심화

  1. 본문 2단계의 부등식을 \(n = 1\)에서 확인하여라.
    답

    \(|y_2 - y_1| = \left|\int(f(s, y_1) - f(s, y_0))\right| \le L\int|y_1 - y_0| \le L\int M|s - t_0| = \frac{ML|t - t_0|^2}{2}\).
