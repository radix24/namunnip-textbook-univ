완전 미분방정식과 적분인자

본문
이 절에서 배울 것
  • \(M\,dx + N\,dy = 0\)이 어떤 함수 \(F\)의 전미분이면(완전) 해가 \(F(x, y) = C\)임을 안다.
  • 완전성 판정 \(M_y = N_x\)를 쓰고 \(F\)를 적분으로 구한다.
  • 완전하지 않을 때 \(x\)나 \(y\)만의 함수인 적분인자를 찾는다.
먼저 알아야 할 것
  • 편미분과 전미분, 일계 방정식의 유형 (1.1절).

1.3.1완전 방정식

\(F(x, y) = C\)를 따라 \(dF = F_x\,dx + F_y\,dy = 0\)입니다. 그러니 방정식 \(M\,dx + N\,dy = 0\)에서 \(M = F_x\), \(N = F_y\)인 \(F\)가 있으면 해는 등고선 \(F = C\)입니다. 이런 방정식을 완전하다고 합니다.

정리 1.3.1 \(M, N\)이 직사각형 영역에서 연속인 편도함수를 가지면, 완전할 필요충분조건은 \(M_y = N_x\)이다.

필요성은 \(F_{xy} = F_{yx}\)입니다. 충분성은 \(F = \int M\,dx + g(y)\)로 두고 \(F_y = N\)에서 \(g'(y)\)를 정해 보입니다.

예 1.3.2 \((2xy + 1)\,dx + (x^2 + 3y^2)\,dy = 0\): \(M_y = 2x = N_x\)라 완전. \(F = \int(2xy + 1)dx = x^2y + x + g(y)\), \(F_y = x^2 + g'(y) = x^2 + 3y^2\)에서 \(g = y^3\). 해 \(x^2y + x + y^3 = C\).

1.3.2적분인자

완전하지 않으면 적당한 \(\mu(x, y)\)를 곱해 완전하게 만듭니다. \(\mu\)가 \(x\)만의 함수이려면 \(\frac{M_y - N_x}N\)이 \(x\)만의 함수여야 하고, 그때

\[\mu(x) = \exp\left(\int\frac{M_y - N_x}N\,dx\right).\]

마찬가지로 \(\frac{N_x - M_y}M\)이 \(y\)만의 함수이면 \(\mu(y) = \exp\int\frac{N_x - M_y}M\,dy\). 일계 선형 방정식 \(y' + p(x)y = q(x)\)의 적분인자 \(e^{\int p}\)도 이 경우입니다.

예 1.3.3 \((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\): \(M_y - N_x = (3x + 2y) - (2x + y) = x + y\), \(\frac{x + y}{x(x + y)} = \frac1x\)이라 \(\mu = x\). 곱하면 \((3x^2y + xy^2)dx + (x^3 + x^2y)dy = 0\)은 완전하고 \(F = x^3y + \frac12x^2y^2\). 해 \(x^3y + \frac12x^2y^2 = C\).
흔한 오해(1) \(F = \int M\,dx + \int N\,dy\)로 두 적분을 그냥 더한다. 겹치는 항을 두 번 센다. \(g(y)\)로 맞춘다. (2) 적분인자를 곱하면 해가 바뀐다고 여긴다. \(\mu \ne 0\)인 곳에서는 같은 해이고, \(\mu = 0\)인 곳(위에서 \(x = 0\))만 따로 확인한다.
요약
  1. 완전: \(M = F_x\), \(N = F_y\), 해 \(F = C\). 판정 \(M_y = N_x\).
  2. \(F = \int M\,dx + g(y)\), \(F_y = N\)으로 \(g\) 결정.
  3. 적분인자 \(\mu(x) = e^{\int(M_y - N_x)/N\,dx}\) 등.

1.3.4연습문제

기본

  1. \((y\cos x + 2x)\,dx + \sin x\,dy = 0\)을 풀어라.
    답

    \(M_y = \cos x = N_x\). \(F = y\sin x + x^2\), 해 \(y\sin x + x^2 = C\).

응용

  1. \(y\,dx - x\,dy = 0\)에 적분인자 \(\frac1{y^2}\)를 곱해 풀어라.
    답

    \(\frac{dx}y - \frac x{y^2}dy = d\left(\frac xy\right) = 0\), 해 \(x = Cy\).

심화

  1. \(y' + p(x)y = q(x)\)를 \((py - q)dx + dy = 0\)으로 쓰고 \(x\)만의 적분인자가 \(e^{\int p}\)임을 보여라.
    답

    \(M = py - q\), \(N = 1\): \(\frac{M_y - N_x}N = p(x)\). 따라서 \(\mu = e^{\int p\,dx}\).
