완전 미분방정식과 적분인자

본문

\((2xy + 1)\,dx + (x^2 + 3y^2)\,dy = 0\)은 변수분리형도 선형도 아니다. 그런데 이 식의 왼쪽이 어떤 함수 \(F(x, y)\)의 전미분 \(dF\)라면, 해는 \(F\)의 등고선이 된다. 그런 \(F\)가 있는지 어떻게 알아보고, 없으면 어떻게 만들 수 있을까?

먼저 알아야 할 것편미분과 전미분, 일계 방정식의 유형(1.1절)을 쓴다.

1.3.1완전 방정식

\(F(x, y) = C\)를 따라 \(dF = F_x\,dx + F_y\,dy = 0\)이다. 그러므로 방정식 \(M\,dx + N\,dy = 0\)에서 \(M = F_x\), \(N = F_y\)인 \(F\)가 있으면 해는 등고선 \(F = C\)이다. 이런 방정식을 완전하다고 한다.

정리 1.3.1

\(M, N\)이 직사각형 영역에서 연속인 편도함수를 가지면, \(M\,dx + N\,dy = 0\)이 완전할 필요충분조건은 \(M_y = N_x\)이다.

증명.완전하면 \(M_y = F_{xy} = F_{yx} = N_x\)이다(혼합 편도함수의 대칭). 거꾸로 \(M_y = N_x\)이면 \(F = \int M\,dx + g(y)\)로 둔다. 이때 \(F_x = M\)이고, \(F_y = \int M_y\,dx + g'(y) = \int N_x\,dx + g'(y)\)이다. 그러므로 \(g'(y) = N - \int N_x\,dx\)로 정하면 되는데, 오른쪽을 \(x\)로 미분하면 \(N_x - N_x = 0\)이라 오른쪽은 \(y\)만의 함수이고 \(g\)가 존재한다. ∎

예제 1.3.2

\((2xy + 1)\,dx + (x^2 + 3y^2)\,dy = 0\)을 풀어라.

풀이. \(M_y = 2x = N_x\)이므로 완전하다. \(F = \int(2xy + 1)dx = x^2y + x + g(y)\)이고, \(F_y = x^2 + g'(y) = x^2 + 3y^2\)에서 \(g = y^3\)이다. 따라서 해는 \(x^2y + x + y^3 = C\)이며, 그림 1의 등고선들이 바로 이것이다.

1.3.2적분인자

완전하지 않으면 적당한 \(\mu(x, y)\)를 곱해 완전하게 만든다. 이때 \(\mu\)가 만족해야 할 식 \((\mu M)_y = (\mu N)_x\)는 편미분방정식이라 일반적으로 풀기 어렵다. 그런데 \(\mu\)가 \(x\)만의 함수라고 가정하면 \(\mu M_y = \mu' N + \mu N_x\)가 되어 상미분방정식으로 줄어든다. 따라서 \(\frac{M_y - N_x}N\)이 \(x\)만의 함수이면 다음 적분인자가 있다.

\[\mu(x) = \exp\left(\int\frac{M_y - N_x}N\,dx\right).\]

마찬가지로 \(\frac{N_x - M_y}M\)이 \(y\)만의 함수이면 \(\mu(y) = \exp\int\frac{N_x - M_y}M\,dy\)이다. 일계 선형 방정식 \(y' + p(x)y = q(x)\)의 적분인자 \(e^{\int p}\)도 이 경우이다.

예제 1.3.3

\((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\)을 풀어라.

풀이. \(M_y - N_x = (3x + 2y) - (2x + y) = x + y\)이고 \(\frac{x + y}{x(x + y)} = \frac1x\)이므로 \(\mu = x\)이다. 곱하면 \((3x^2y + xy^2)dx + (x^3 + x^2y)dy = 0\)은 완전하고 \(F = x^3y + \frac12x^2y^2\)이다. 즉 해는 \(x^3y + \frac12x^2y^2 = C\)이다.

정리하면 풀이 순서는 세 단계이다. 먼저 두 편도함수를 비교해 완전한지 확인한다. 완전하지 않으면 두 몫 가운데 한 변수만의 함수가 되는 것을 찾아 적분인자를 곱한다. 이제 완전해진 식에서 한 변수로 적분하고 남은 함수를 다른 편도함수로 맞추어 등고선의 식을 얻는다. 물론 두 몫이 모두 한 변수만의 함수가 아니면 이 방법은 통하지 않으며, 그때는 다른 치환을 찾아야 한다.

흔한 오해\(F = \int M\,dx + \int N\,dy\)로 두 적분을 그냥 더하기 쉬운데, 그러면 겹치는 항을 두 번 센다. 예제 1.3.2에서 \(x^2y\)가 두 적분에 모두 나오는 것이 그 예이며, \(g(y)\)로 맞추어야 한다. 또 적분인자를 곱하면 해가 바뀐다고 여기는 것도 틀렸다. \(\mu \ne 0\)인 곳에서는 같은 해이고, 예제 1.3.3의 \(x = 0\)처럼 \(\mu = 0\)인 곳만 따로 확인한다.
마무리

처음 질문에 답하면, \(M_y = N_x\)이면 그런 \(F\)가 있고 \(F = \int M\,dx + g(y)\)에서 \(F_y = N\)으로 \(g\)를 정해 구한다. 처음 식은 \(M_y = 2x = N_x\)이므로 해가 \(x^2y + x + y^3 = C\)라는 등고선이다. 완전하지 않으면 \(\frac{M_y - N_x}N\)이 \(x\)만의 함수인지 살펴 적분인자 \(\mu(x) = e^{\int(M_y - N_x)/N\,dx}\)를 곱하고, \(y\)에 대해서도 같은 방법을 쓴다.

1.3.4연습문제

기본

  1. \((y\cos x + 2x)\,dx + \sin x\,dy = 0\)을 풀어라.
    답

    \(M_y = \cos x = N_x\). \(F = y\sin x + x^2\), 해 \(y\sin x + x^2 = C\).

응용

  1. \(y\,dx - x\,dy = 0\)에 적분인자 \(\frac1{y^2}\)를 곱해 풀어라.
    답

    \(\frac{dx}y - \frac x{y^2}dy = d\left(\frac xy\right) = 0\), 해 \(x = Cy\).

심화

  1. \(y' + p(x)y = q(x)\)를 \((py - q)dx + dy = 0\)으로 쓰고 \(x\)만의 적분인자가 \(e^{\int p}\)임을 보여라.
    답

    \(M = py - q\), \(N = 1\): \(\frac{M_y - N_x}N = p(x)\). 따라서 \(\mu = e^{\int p\,dx}\).
