경계치 문제와 스투름-리우빌 이론

본문

양 끝을 고정한 기타 줄은 아무 진동수로나 울리지 않고 기본음과 그 정수배 배음으로만 울린다. 초기값 문제는 늘 해가 하나 있었는데, 양 끝에 조건을 주면 왜 특정한 값에서만 해가 생길까? 그리고 그 해들이 서로 직교한다는 것은 무엇을 뜻할까?

먼저 알아야 할 것이계 선형 방정식(2.1절), 르장드르 직교성의 증명(4.3절), 대칭행렬의 고유값이 실수인 이유(수학1 7단원), 복소수의 켤레를 쓴다.

6.1.1경계치 문제

양 끝을 고정한 줄의 처짐이나 막대의 온도처럼, 조건이 한 점이 아니라 구간의 양 끝에 주어지는 문제를 경계치 문제라 한다. 초기값 문제와 달리 해가 늘 하나 있지는 않다.

예제 6.1.1

\(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(\pi) = 0\)의 0이 아닌 해가 있는 \(\lambda\)를 모두 구하여라.

풀이. \(\lambda < 0\)이면 \(\mu = \sqrt{-\lambda}\)로 \(y = c_1\cosh\mu t + c_2\sinh\mu t\)이고, \(y(0) = 0\)에서 \(c_1 = 0\), \(y(\pi) = c_2\sinh\mu\pi = 0\)에서 \(c_2 = 0\)이다. \(\lambda = 0\)이면 \(y = c_1 + c_2t\)도 0뿐이다. \(\lambda = \mu^2 > 0\)이면 \(y = c_2\sin\mu t\)이고 \(\sin\mu\pi = 0\)이 필요하므로 \(\mu = n\)이다. 따라서 고유값은 \(\lambda_n = n^2\), 고유함수는 \(y_n = \sin nt\) (\(n = 1, 2, \dots\))이고, 다른 \(\lambda\)에서는 해가 0뿐이다.

이것은 행렬의 고유값 문제 \(A\mathbf v = \lambda\mathbf v\)와 같은 꼴이며, 작용소 \(-\frac{d^2}{dt^2}\)의 고유값을 찾은 것이다. 줄의 진동수는 \(\sqrt{\lambda_n} = n\)에 비례하므로 기본음과 정수배 배음이 된다.

6.1.2스투름-리우빌 문제

정의 6.1.2 (정칙 스투름-리우빌 문제)

\([a, b]\)에서 \(p > 0\), \(p'\), \(q\), \(w > 0\)이 연속일 때 다음 문제를 정칙 스투름-리우빌 문제라 하고, \(w\)를 가중치라 한다.

\[-(p(t)y')' + q(t)y = \lambda w(t)y, \qquad \alpha_1y(a) + \alpha_2y'(a) = 0,\ \ \beta_1y(b) + \beta_2y'(b) = 0.\]

르장드르 방정식(\(p = 1 - t^2\))과 베셀 방정식(\(p = t\), \(w = t\))이 모두 이 꼴이다. 이 이론을 떠받치는 것은 작용소 \(L[y] = -(py')' + qy\)가 경계조건 아래에서 대칭이라는 사실이다.

정리 6.1.3 (라그랑주 항등식)

\(u, v\)가 경계조건을 만족하면 \(\int_a^bL[u]\,v\,dt = \int_a^bu\,L[v]\,dt\)이다.

증명.두 번 부분적분하면 두 적분의 차이는 \(\left[p(uv' - u'v)\right]_a^b\)이다. \(t = a\)에서 \((u(a), u'(a))\)와 \((v(a), v'(a))\)는 모두 \((\alpha_1, \alpha_2)\)에 수직이므로 서로 평행하고, 따라서 \(uv' - u'v = 0\)이다. \(t = b\)에서도 같다. ∎

정리 6.1.4

스투름-리우빌 문제의 고유값은 실수이고, 서로 다른 고유값의 고유함수는 \(\int_a^by_my_nw\,dt = 0\)으로 직교한다.

증명.먼저 실수임을 보인다. \(L[y] = \lambda wy\)에서 계수가 실수이므로 켤레를 취하면 \(L[\bar y] = \bar\lambda w\bar y\)이다. 라그랑주 항등식으로 \(\int L[y]\bar y = \int yL[\bar y]\), 곧 \(\lambda\int w|y|^2 = \bar\lambda\int w|y|^2\)이고, \(\int w|y|^2 > 0\)이므로 \(\lambda = \bar\lambda\)이다. 다음으로 직교성은 \(\lambda_m\int wy_my_n = \int L[y_m]y_n = \int y_mL[y_n] = \lambda_n\int wy_my_n\)에서 \(\lambda_m \ne \lambda_n\)이므로 적분이 0이다. ∎

대칭행렬의 고유값이 실수이고 고유벡터가 직교하는 것과 같은 논법이다. 더 나아가 고유값은 \(\lambda_1 < \lambda_2 < \cdots \to \infty\)이고, \(n\)번째 고유함수는 구간 안에서 \(n - 1\)번 0이 된다. 그림 1에서 \(\sin 3t\)가 구간 안에서 두 번 0이 되는 것이 그 예이며, 같은 절의 탐구 카드에서 사격법으로 확인할 수 있다.

6.1.3고유함수 전개

고유함수들은 완비 직교계를 이루므로, 조건이 맞는 \(f\)를 \(f = \sum c_ny_n\), \(c_n = \frac{\int fy_nw}{\int y_n^2w}\)로 쓸 수 있다. 예제 6.1.1에서는 이것이 푸리에 사인 급수 \(f(t) = \sum b_n\sin nt\), \(b_n = \frac2\pi\int_0^\pi f\sin nt\,dt\)이다. 예를 들어 \(f(t) = t(\pi - t)\)이면 \(n\)이 홀수일 때 \(b_n = \frac{8}{\pi n^3}\)이고 짝수일 때 0이다.

흔한 오해경계치 문제도 해가 늘 하나라고 여기기 쉽다. 그러나 \(y'' + y = 0\), \(y(0) = y(\pi) = 0\)은 해가 무한히 많고, 조건을 \(y(\pi) = 1\)로 바꾸면 해가 없다. 또 직교성에서 가중치 \(w\)를 빠뜨리는 실수가 있으며, 베셀 함수에서는 \(w = t\)가 꼭 필요하다.
마무리

처음 질문에 답하면, 양 끝 조건을 모두 만족하는 0이 아닌 해는 특정한 \(\lambda\), 곧 고유값에서만 생긴다. 고정된 줄 \(y'' + \lambda y = 0\), \(y(0) = y(\pi) = 0\)에서는 \(\lambda = n^2\)이고 고유함수가 \(\sin nt\)이므로 진동수가 정수배이다. 작용소가 라그랑주 항등식의 뜻에서 대칭이므로 고유값은 실수이고 고유함수는 가중치 \(w\)에 대해 직교하며, 그래서 함수를 고유함수로 전개할 수 있다. 이것이 푸리에 급수의 일반화이다.

6.1.4연습문제

기본

  1. \(y'' + \lambda y = 0\), \(y'(0) = 0\), \(y'(\pi) = 0\)의 고유값과 고유함수를 구하여라.
    답

    \(\lambda = n^2\) (\(n = 0, 1, 2, \dots\)), \(y = \cos nt\). \(\lambda = 0\)도 고유값(상수함수).

응용

  1. \(f(t) = t(\pi - t)\)의 사인 급수 계수 \(b_1\), \(b_3\)을 구하고 \(t = \frac\pi2\)에서 두 항까지의 합을 \(f(\frac\pi2)\)와 비교하여라.
    답

    \(b_1 = \frac8\pi \approx 2.546\), \(b_3 = \frac{8}{27\pi} \approx 0.0943\). \(b_1 - b_3 \approx 2.452\), \(f(\frac\pi2) = \frac{\pi^2}4 \approx 2.467\).

심화

  1. \(-y'' = \lambda y\), \(y(0) = 0\), \(y(1) + y'(1) = 0\)의 고유값이 \(\tan\sqrt\lambda = -\sqrt\lambda\)의 해임을 보여라.
    답

    \(y = \sin\mu t\) (\(\mu = \sqrt\lambda\)), \(\sin\mu + \mu\cos\mu = 0\). 고유값은 \(\mu \approx 2.029, 4.913, \dots\)의 제곱(초월방정식, 수치로 구함).
