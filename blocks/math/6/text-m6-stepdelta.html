계단함수, 디랙 델타, 합성곱 정리

본문
이 절에서 배울 것
  • 단위 계단함수 \(u(t - a)\)와 이동 정리 \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\)를 쓴다.
  • 순간 충격을 나타내는 디랙 델타 \(\delta(t - a)\)의 변환 \(e^{-as}\)을 쓴다.
  • 합성곱 정리 \(\mathcal L\{f * g\} = F(s)G(s)\)로 역변환을 구한다.
먼저 알아야 할 것
  • Laplace 변환과 초기값 문제 (5.1절).

5.3.1계단함수

\(u(t - a) = 0\) (\(t < a\)), \(1\) (\(t \ge a\))는 스위치를 시각 \(a\)에 켜는 것을 나타냅니다. \(\mathcal L\{u(t - a)\} = \frac{e^{-as}}s\)이고, 함수를 시간 \(a\)만큼 늦춰 그때 켜면

\[\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s).\]

거꾸로, 변환에 \(e^{-as}\)가 곱해져 있으면 역변환을 \(a\)만큼 늦추고 \(u(t - a)\)를 곱합니다.

예 5.3.1 \(y' + y = u(t - 1)\), \(y(0) = 0\): \(sY + Y = \frac{e^{-s}}s\)라 \(Y = e^{-s}\frac1{s(s + 1)} = e^{-s}\left(\frac1s - \frac1{s + 1}\right)\). 따라서 \(y = u(t - 1)\left(1 - e^{-(t - 1)}\right)\). 시각 1까지는 0이다가 그 뒤 1로 다가갑니다.

5.3.2디랙 델타

시각 \(a\)에 아주 짧고 센 힘(망치질)을 넣는 것을 \(\delta(t - a)\)로 나타냅니다. 넓이 1인 좁은 직사각형 펄스 \(\frac1\epsilon[u(t - a) - u(t - a - \epsilon)]\)의 \(\epsilon \to 0\) 극한으로 이해하며, 변환은 \(\frac{e^{-as}(1 - e^{-\epsilon s})}{\epsilon s} \to e^{-as}\)입니다. 특히 \(\mathcal L\{\delta(t)\} = 1\)입니다.

5.3.3합성곱 정리

\[(f * g)(t) = \int_0^tf(\tau)g(t - \tau)\,d\tau, \qquad \mathcal L\{f * g\} = F(s)G(s).\]

역변환이 두 변환의 곱이면 합성곱으로 씁니다. 예를 들어 \(y'' + y = g(t)\), \(y(0) = y'(0) = 0\)의 해는 \(Y = \frac{G(s)}{s^2 + 1}\)이라 \(y = \int_0^t\sin(t - \tau)g(\tau)\,d\tau\)입니다. \(\sin t\)는 \(\delta\)에 대한 반응(충격 반응)이고, 임의의 입력에 대한 반응은 충격 반응과 입력의 합성곱입니다(5.1절의 탐구 카드).

흔한 오해(1) \(\mathcal L\{f(t)u(t - a)\} = e^{-as}F(s)\)라 여긴다. \(f\)도 \(a\)만큼 늦춘 \(f(t - a)\)여야 한다. (2) 델타를 보통의 함수처럼 값으로 다룬다. 적분 안에서만 의미가 있고 \(\int\delta(t - a)g(t)dt = g(a)\)로 쓴다.
요약
  1. \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F\): 스위치와 지연.
  2. \(\mathcal L\{\delta(t - a)\} = e^{-as}\): 순간 충격.
  3. \(\mathcal L\{f * g\} = FG\): 반응 = 충격 반응 \(*\) 입력.

5.3.4연습문제

기본

  1. \(\frac{e^{-2s}}{s^2}\)의 역변환은?
    답

    \((t - 2)u(t - 2)\).

응용

  1. \(1 * 1\)과 \(t * 1\)을 계산하고 합성곱 정리로 확인하여라.
    답

    \(1 * 1 = t\) (\(\frac1s\cdot\frac1s = \frac1{s^2}\)), \(t * 1 = \frac{t^2}2\) (\(\frac1{s^2}\cdot\frac1s = \frac1{s^3}\)).

심화

  1. 예 5.3.1을 합성곱으로 다시 풀어라(충격 반응 \(e^{-t}\)).
    답

    \(y = \int_0^te^{-(t - \tau)}u(\tau - 1)d\tau = \int_1^te^{-(t - \tau)}d\tau = 1 - e^{-(t - 1)}\) (\(t \ge 1\)).
