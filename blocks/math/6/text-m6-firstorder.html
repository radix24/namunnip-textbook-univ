일계 미분방정식의 해법

본문

어떤 생물의 개체 수가 처음에는 빠르게 늘다가 환경이 감당할 수 있는 크기에 가까워지면 늘어나는 속도가 줄어든다. "늘어나는 속도가 지금의 크기로 정해진다"는 이 규칙만 알 때, 개체 수가 시간에 따라 어떻게 변하는지 함수로 구할 수 있을까?

먼저 알아야 할 것고등학교 미적분의 미분법과 적분법(치환적분, 부분적분), 지수함수와 로그함수를 쓴다. 편미분은 이 절에서 쓰는 만큼 설명한다.

1.1.1미분방정식이란

물리 법칙은 대개 "변화율이 현재 상태로 정해진다"는 꼴이다. 예를 들어 방사성 물질은 남은 양에 비례해 줄고(\(\frac{dN}{dt} = -\lambda N\)), 뜨거운 커피는 주변과의 온도 차에 비례해 식는다(\(\frac{dT}{dt} = -k(T - T_0)\)). 이렇게 미지의 함수와 그 도함수 사이의 관계식을 미분방정식이라 한다.

정의 1.1.1

한 변수 \(t\)의 함수 \(y(t)\)와 그 도함수들의 관계식을 상미분방정식이라 하고, 가장 높은 도함수의 차수를 계수라 한다. 구간에서 미분 가능하고 대입하면 식이 성립하는 함수를 해라 한다. 방정식 \(y' = f(t, y)\)와 조건 \(y(t_0) = y_0\)의 쌍을 초기값 문제라 한다. 평면의 각 점 \((t, y)\)에 기울기 \(f(t, y)\)인 짧은 선분을 그린 그림을 방향장이라 한다.

일계 방정식 \(y' = f(t, y)\)는 점 \((t, y)\)를 지나는 해의 기울기가 \(f(t, y)\)라는 뜻이다. 그래서 공식을 몰라도 방향장을 따라가면 해의 모양을 알 수 있다. 그림 1에서 \(0 < y < 1\)인 곳의 선분은 오른쪽 위를 향하고, \(y > 1\)인 곳의 선분은 오른쪽 아래를 향한다. 따라서 해를 구하기 전에도 모든 양의 해가 1로 다가간다고 짐작할 수 있다. 같은 절의 탐구 카드에서 점을 찍어 해 곡선을 직접 그려 볼 수 있다.

1.1.2변수분리형

\(y' = g(t)h(y)\) 꼴이면 \(y\)가 들어간 것과 \(t\)가 들어간 것을 양변으로 나눈다.

\[\frac{dy}{h(y)} = g(t)\,dt \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(t)\,dt.\]

엄밀하게는 \(h(y(t)) \ne 0\)일 때 \(\frac{y'(t)}{h(y(t))} = g(t)\)의 양변을 \(t\)로 적분하고 왼쪽에 치환적분을 쓴 것이다. 한편 \(h(y_0) = 0\)인 \(y_0\)에서는 상수함수 \(y = y_0\)도 해이므로 따로 챙긴다.

예제 1.1.2 (로지스틱 방정식)

\(y' = y(1 - y)\), \(y(0) = 0.1\)을 풀어라.

풀이. \(y \ne 0, 1\)일 때 \(\frac{dy}{y(1 - y)} = dt\)이다. 부분분수 \(\frac1{y(1-y)} = \frac1y + \frac1{1 - y}\)로 적분하면 \(\ln\left|\frac{y}{1 - y}\right| = t + C\), 곧 \(\frac{y}{1 - y} = Ae^t\)이다. \(t = 0\)을 넣으면 \(A = \frac{0.1}{0.9} = \frac19\)이고, 정리하면 다음과 같다.

\[y(t) = \frac{1}{1 + 9e^{-t}}.\]

\(t \to \infty\)이면 \(y \to 1\)이므로, 개체 수가 환경 용량으로 수렴하는 S자 곡선이다. 가령 \(y(2) = \frac1{1 + 9e^{-2}} \approx 0.451\)이다. 이때 나눗셈에서 빠진 \(y = 0\)과 \(y = 1\)도 해이며, 그림 1의 주황 점선이 그것이다.

1.1.3일계 선형 방정식

\(y' + p(t)y = q(t)\) 꼴은 왼쪽을 한 함수의 도함수로 만드는 곱수, 곧 적분인자 \(\mu(t) = e^{\int p\,dt}\)를 곱해 푼다. \(\mu' = p\mu\)이므로 다음이 성립한다.

\[\mu y' + \mu p y = (\mu y)' = \mu q \quad\Longrightarrow\quad y = \frac{1}{\mu}\left(\int\mu q\,dt + C\right).\]
예제 1.1.3

\(y' + 2y = e^{-t}\), \(y(0) = 0\)을 풀어라.

풀이. \(\mu = e^{2t}\)이다. \((e^{2t}y)' = e^{t}\)이므로 \(e^{2t}y = e^t + C\), 곧 \(y = e^{-t} + Ce^{-2t}\)이다. \(y(0) = 1 + C = 0\)에서 \(C = -1\)이므로 \(y = e^{-t} - e^{-2t}\)이다. 검산하면 \(y' + 2y = -e^{-t} + 2e^{-2t} + 2e^{-t} - 2e^{-2t} = e^{-t}\)이다.

1.1.4완전방정식과 치환

\(M(t, y) + N(t, y)y' = 0\)에서 어떤 함수 \(F\)가 \(F_t = M\), \(F_y = N\)을 만족한다고 하자. 여기서 편도함수 \(F_t\)는 \(y\)를 상수로 보고 \(t\)로 미분한 것이다. 그러면 연쇄 법칙으로 \(\frac{d}{dt}F(t, y(t)) = M + Ny' = 0\)이므로, 해는 \(F(t, y) = C\)인 곡선이다. 그런 \(F\)가 있을 필요충분조건은 단순연결 영역에서 \(M_y = N_t\)이며, 1.3절에서 자세히 다룬다.

예제 1.1.4

\((2ty + 1) + (t^2 + 3y^2)y' = 0\)을 풀어라.

풀이. \(M_y = 2t = N_t\)이므로 완전하다. \(F_t = 2ty + 1\)을 \(t\)로 적분하면 \(F = t^2y + t + g(y)\)이고, \(F_y = t^2 + g'(y) = t^2 + 3y^2\)에서 \(g = y^3\)이다. 따라서 해는 \(t^2y + t + y^3 = C\)이다.

치환으로 앞의 유형이 되는 방정식도 있다. 동차형 \(y' = f\left(\frac yt\right)\)은 \(v = \frac yt\)로 두면 변수분리형이 되고, 베르누이 방정식 \(y' + py = qy^n\)은 \(v = y^{1-n}\)으로 두면 선형이 된다.

흔한 오해변수분리에서 \(h(y)\)로 나눌 때 \(h(y) = 0\)인 상수해를 빠뜨리기 쉬운데, 로지스틱에서는 \(y = 0\)과 \(y = 1\)도 해이다. 또 적분인자를 왼쪽에만 곱하고 오른쪽에 곱하는 것을 잊는 실수가 있다. 적분상수를 마지막에 붙여 \(y = \frac1\mu\int\mu q + C\)로 쓰는 것도 틀렸으며, 올바른 꼴은 \(\frac1\mu\left(\int\mu q + C\right)\)이다.
마무리

처음 질문의 답은 "구할 수 있다"이다. 규칙 \(y' = y(1 - y)\)는 변수분리형이고, 풀면 \(y = \frac{1}{1 + 9e^{-t}}\)라는 S자 곡선이 나와 환경 용량 1로 다가간다. 일계 방정식은 방향장으로 해의 모양을 먼저 읽을 수 있으며, 변수분리형은 \(\int\frac{dy}{h(y)} = \int g\,dt\)에 상수해를 더하고, 선형은 적분인자 \(\mu = e^{\int p}\)로 \((\mu y)' = \mu q\)를 만들며, 완전방정식은 \(F = C\)로 푼다.

1.1.5연습문제

기본

  1. \(y' = ty^2\), \(y(0) = 1\)을 풀고 해가 존재하는 구간을 말하여라.
    답

    \(-\frac1y = \frac{t^2}2 + C\), \(C = -1\). \(y = \frac{2}{2 - t^2}\), 구간 \((-\sqrt2, \sqrt2)\).

  2. \(y' - y = t\)의 일반해를 구하여라.
    답

    \(\mu = e^{-t}\), \((e^{-t}y)' = te^{-t}\), \(y = -t - 1 + Ce^t\).

응용

  1. 뉴턴 냉각 법칙 \(T' = -k(T - 20)\)에서 90°C 커피가 10분 뒤 60°C가 되었다. 40°C가 되는 시각은?
    답

    \(T - 20 = 70e^{-kt}\), \(40 = 70e^{-10k}\)에서 \(e^{-10k} = \frac47\). \(20 = 70e^{-kt}\)이면 \(e^{-kt} = \frac27\), \(t = 10\frac{\ln(7/2)}{\ln(7/4)} \approx 22.4\)분.

심화

  1. 베르누이 방정식 \(y' + y = y^2\)을 \(v = y^{-1}\)로 풀어라.
    답

    \(v' = -y^{-2}y' = -y^{-2}(y^2 - y) = -1 + v\). \(v = 1 + Ce^t\), \(y = \frac{1}{1 + Ce^t}\).
