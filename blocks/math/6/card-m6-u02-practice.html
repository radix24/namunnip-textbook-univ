고계 선형 방정식 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(y'' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 2\)를 풀어라. [02-01]

    힌트 1

    \(r = \pm2i\)(2.1절).

    힌트 2

    \(y = c_1\cos2t + c_2\sin2t\).

    풀이

    \(c_1 = 1\), \(2c_2 = 2\). \(y = \cos2t + \sin2t = \sqrt2\sin(2t + \frac\pi4)\).

  2. 개념\(e^t, e^{-t}, \cosh t\)는 \(y'' - y = 0\)의 해다. 이 셋이 기저인가? [02-01]

    힌트 1

    해공간의 차원은?

    힌트 2

    \(\cosh t = \frac{e^t + e^{-t}}2\).

    풀이

    아니다. 해공간은 2차원이라 세 해는 일차종속(\(\cosh t\)가 앞의 둘의 일차결합). \(\{e^t, e^{-t}\}\)나 \(\{\cosh t, \sinh t\}\)가 기저.

  3. 계산\((1 - t^2)y'' - 2ty' + 2y = 0\)의 해 \(y_1 = t\)로 둘째 해를 구하여라 (\(|t| < 1\)). [02-02]

    힌트 1

    \(p = -\frac{2t}{1 - t^2}\), \(e^{-\int p} = \frac{1}{1 - t^2}\)(2.2절).

    힌트 2

    \(\int\frac{dt}{t^2(1 - t^2)} = \int\left(\frac1{t^2} + \frac1{1 - t^2}\right)dt\).

    풀이

    \(y_2 = t\left(-\frac1t + \frac12\ln\frac{1 + t}{1 - t}\right) = \frac t2\ln\frac{1 + t}{1 - t} - 1\). (르장드르 방정식 \(n = 1\)의 둘째 해, 4단원)

  4. 증명\(y'' + q(t)y = 0\)의 두 해의 론스키안은 상수임을 보여라. [02-02]

    힌트 1

    아벨 공식에서 \(p = 0\).

    힌트 2

    또는 \(W'\)을 직접 계산.

    풀이

    \(W' = y_1y_2'' - y_1''y_2 = y_1(-qy_2) - (-qy_1)y_2 = 0\). ∎

  5. 계산\(y'' - 3y' + 2y = e^{t}\)의 일반해를 구하여라. [02-03]

    힌트 1

    동차해 \(e^t, e^{2t}\). 우변 \(e^t\)가 동차해와 겹칩니다(2.3절).

    힌트 2

    \(y_p = Ate^t\).

    풀이

    \(y_p = Ate^t\): \(y_p' = A(1 + t)e^t\), \(y_p'' = A(2 + t)e^t\). \(A[(2 + t) - 3(1 + t) + 2t]e^t = -Ae^t = e^t\), \(A = -1\). \(y = c_1e^t + c_2e^{2t} - te^t\).

  6. 판단한 학생이 "\(y'' + y = \cos t\)의 특수해는 \(A\cos t + B\sin t\)로 두면 된다"고 썼다. 무엇이 잘못되었고 바른 답은? [02-03]

    힌트 1

    \(\cos t\)는 동차해입니다.

    힌트 2

    \(t\)를 곱하세요.

    풀이

    추측이 동차해라 대입하면 0이 되어 \(\cos t\)를 만들 수 없다. \(t(A\cos t + B\sin t)\)로 두면 \(y_p = \frac t2\sin t\). 진폭이 자라는 공명이다.
