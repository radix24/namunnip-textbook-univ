반정수 차수의 베셀 방정식

예제 · 근의 차가 정수인 프로베니우스 방법

먼저 예측

\(t^2y'' + ty' + \left(t^2 - \frac14\right)y = 0\)의 지표근은 \(\pm\frac12\)로 차가 1(정수)이다. 둘째 해에 \(\ln t\)가 나타날까?

예측 확인

나타나지 않는다. 두 해가 \(\frac{\sin t}{\sqrt t}\), \(\frac{\cos t}{\sqrt t}\)로 초등함수이다. 정리 4.2.2(d)의 상수 \(C\)가 0인 경우이다.

\(t^2y'' + ty' + \left(t^2 - \frac14\right)y = 0\) (\(t > 0\))의 두 해를 프로베니우스 방법으로 구하여라.

전략

\(y = \sum a_nt^{n + r}\)을 대입해 점화식을 만들고(4.2절), 작은 근 \(r = -\frac12\)에서 분모가 0이 되는 단계가 실제로 모순을 일으키는지 확인한다.

풀이

  1. 대입하면 \(\left[(n + r)^2 - \frac14\right]a_n + a_{n-2} = 0\) (\(a_{-1} = a_{-2} = 0\)).
    \(t^2y'' + ty'\)이 \((n + r)^2\)을, \(t^2y\)가 첨자를 2 옮긴다.
  2. \(n = 0\): \(r^2 = \frac14\), \(r = \pm\frac12\). \(n = 1\): \(\left[(1 + r)^2 - \frac14\right]a_1 = 0\).
    지표방정식과 첫 계수.
  3. \(r = \frac12\): \(n(n + 1)a_n = -a_{n-2}\), \(a_1 = 0\). \(a_{2k} = \frac{(-1)^k}{(2k + 1)!}a_0\). 해 \(t^{1/2}\sum\frac{(-1)^kt^{2k}}{(2k+1)!} = \frac{\sin t}{\sqrt t}\).
    \(\sin t = \sum\frac{(-1)^kt^{2k+1}}{(2k+1)!}\)를 \(t\)로 나눈 것.
  4. \(r = -\frac12\): \(n(n - 1)a_n = -a_{n-2}\). \(n = 1\)에서 \(0\cdot a_1 = 0\)이라 \(a_1\)은 자유롭다(모순 없음). \(a_1 = 0\)으로 두면 \(a_{2k} = \frac{(-1)^k}{(2k)!}a_0\).
    분모가 0이 되는 단계에서 오른쪽도 0이라 \(\ln\) 항이 필요 없다.
  5. 둘째 해 \(t^{-1/2}\sum\frac{(-1)^kt^{2k}}{(2k)!} = \frac{\cos t}{\sqrt t}\). 일반해 \(y = \frac{c_1\sin t + c_2\cos t}{\sqrt t}\).
    \(a_1 \ne 0\)으로 두면 첫째 해가 더해질 뿐이다.

검산

\(y = t^{-1/2}u\)로 두면 방정식이 \(u'' + u = 0\)이 되어 \(u = \sin t, \cos t\)이다. 표준 기호로 \(J_{1/2}(t) = \sqrt{\frac{2}{\pi t}}\sin t\), \(J_{-1/2}(t) = \sqrt{\frac2{\pi t}}\cos t\)이다.

의미

근의 차가 정수여도 \(\ln t\)가 늘 나오는 것은 아니다. 점화식에서 분모가 0이 되는 순간 분자도 0이면 그 계수가 자유로워지고, 그렇지 않으면 모순이 생겨 \(\ln t\) 항이 필요하다. 정수 차수의 베셀 방정식(\(\nu = 1, 2, \dots\))은 후자라서 둘째 해 \(Y_\nu\)에 \(\ln t\)가 있다.

답
