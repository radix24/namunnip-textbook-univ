미정계수법

본문
이 절에서 배울 것
  • 우변이 다항식, 지수함수, 사인·코사인과 그 곱일 때 특수해의 꼴을 추측하고 계수를 정한다.
  • 추측한 꼴이 동차해와 겹치면(공명) \(x\)를 곱해야 함을 안다.
  • 매개변수 변환법과 비교해 언제 미정계수법을 쓰는지 판단한다.
먼저 알아야 할 것
  • 상수계수 동차 방정식과 특성방정식, 매개변수 변환법 (2.3절).

2.4.1방법

\(L[y] = y'' + ay' + by = g(x)\)의 일반해는 동차해 + 특수해입니다. \(g\)가 미분해도 꼴이 유지되는 함수(다항식, \(e^{kx}\), \(\sin\omega x\), \(\cos\omega x\), 그 곱)이면 특수해도 같은 꼴일 것이라 추측하고 계수를 대입으로 정합니다.

\(g(x)\)추측 \(y_p\)
\(n\)차 다항식\(n\)차 다항식 \(A_nx^n + \cdots + A_0\)
\(e^{kx}\)\(Ae^{kx}\)
\(\cos\omega x\) 또는 \(\sin\omega x\)\(A\cos\omega x + B\sin\omega x\)
예 2.4.1 \(y'' - 3y' + 2y = 4x\): \(y_p = Ax + B\)를 넣으면 \(-3A + 2Ax + 2B = 4x\)라 \(A = 2\), \(B = 3\). \(y_p = 2x + 3\). 동차해 \(c_1e^x + c_2e^{2x}\)와 더하면 일반해.

2.4.2공명: x를 곱하기

추측한 꼴이 동차해이면 \(L[y_p] = 0\)이라 맞출 수 없습니다. 그때는 \(x\)를 곱합니다(두 번 겹치면 \(x^2\)).

예 2.4.2 \(y'' - 3y' + 2y = e^x\): \(e^x\)는 동차해. \(y_p = Axe^x\)이면 \(y_p' = A(x + 1)e^x\), \(y_p'' = A(x + 2)e^x\)이고 \(L[y_p] = A[(x + 2) - 3(x + 1) + 2x]e^x = -Ae^x\). \(A = -1\), \(y_p = -xe^x\).

물리적으로 이것이 공명입니다. 고유 진동수와 같은 진동수로 밀면(\(y'' + y = \cos x\)) 특수해가 \(\frac x2\sin x\)처럼 진폭이 시간에 비례해 커집니다.

2.4.3언제 쓰나

미정계수법은 계산이 대입뿐이라 빠르지만, \(g = \tan x\)나 \(\frac1x\)처럼 미분하면 새 꼴이 계속 생기는 함수에는 쓸 수 없고 계수가 상수여야 합니다. 그럴 때는 2.3절의 매개변수 변환법을 씁니다.

흔한 오해(1) \(g = \cos\omega x\)이면 \(A\cos\omega x\)만 추측한다. 1계 도함수 항 때문에 \(\sin\)도 필요하다. (2) 동차해와 겹치는지 확인하지 않는다. 겹치면 계수 방정식이 \(0 = 1\) 꼴로 모순이 된다.
요약
  1. 우변과 같은 꼴로 \(y_p\)를 추측, 대입해 계수 결정.
  2. 동차해와 겹치면 \(x\) (또는 \(x^2\))를 곱한다: 공명.
  3. 상수계수·특정 우변에만, 그 밖에는 매개변수 변환법.

2.4.4연습문제

기본

  1. \(y'' + 4y = 8\)의 특수해를 구하여라.
    답

    \(y_p = A\): \(4A = 8\), \(y_p = 2\).

응용

  1. \(y'' + y = \cos x\)의 특수해를 구하여라.
    답

    공명. \(y_p = x(A\cos x + B\sin x)\)를 넣으면 \(-2A\sin x + 2B\cos x = \cos x\), \(A = 0\), \(B = \frac12\). \(y_p = \frac x2\sin x\).

심화

  1. \(y'' - 2y' + y = e^x\)의 특수해의 꼴과 계수를 구하여라.
    답

    특성근 1이 중근이라 \(e^x\), \(xe^x\) 모두 동차해. \(y_p = Ax^2e^x\), 대입하면 \(2Ae^x = e^x\), \(A = \frac12\).
