미정계수법

본문

\(y'' - 3y' + 2y = 4x\)의 특수해를 찾을 때, 우변이 일차식이니 특수해도 일차식일 것이라 짐작하고 계수만 맞추면 될까? 그런데 같은 방법을 \(y'' + y = \cos x\)에 쓰면 실패한다. 언제 짐작이 통하고, 실패할 때는 무엇을 고쳐야 할까?

먼저 알아야 할 것상수계수 동차 방정식과 특성방정식(2.1절), 매개변수 변환법(2.3절)을 쓴다.

2.4.1방법

\(L[y] = y'' + ay' + by = g(x)\)의 일반해는 동차해에 특수해를 더한 것이다. \(g\)가 미분해도 꼴이 유지되는 함수, 곧 다항식, \(e^{kx}\), \(\sin\omega x\), \(\cos\omega x\)와 그 곱이면 \(L[y_p]\)도 같은 꼴이다. 그러므로 특수해를 같은 꼴로 짐작하고 계수를 대입으로 정한다. 다음 표가 기본 짐작이다.

\(g(x)\)추측 \(y_p\)
\(n\)차 다항식\(n\)차 다항식 \(A_nx^n + \cdots + A_0\)
\(e^{kx}\)\(Ae^{kx}\)
\(\cos\omega x\) 또는 \(\sin\omega x\)\(A\cos\omega x + B\sin\omega x\)
예제 2.4.1

\(y'' - 3y' + 2y = 4x\)의 일반해를 구하여라.

풀이. \(y_p = Ax + B\)를 넣으면 \(-3A + 2Ax + 2B = 4x\)이므로 \(A = 2\), \(B = 3\)이고 \(y_p = 2x + 3\)이다. 동차해 \(c_1e^x + c_2e^{2x}\)와 더하면 일반해 \(y = c_1e^x + c_2e^{2x} + 2x + 3\)이다.

2.4.2공명과 x 곱하기

짐작한 꼴이 동차해이면 \(L[y_p] = 0\)이므로 우변을 맞출 수 없다. 그때는 \(x\)를 곱하고, 특성방정식의 중근이라 두 번 겹치면 \(x^2\)을 곱한다.

예제 2.4.2

\(y'' - 3y' + 2y = e^x\)의 특수해를 구하여라.

풀이. \(e^x\)는 동차해이므로 \(y_p = Axe^x\)로 둔다. \(y_p' = A(x + 1)e^x\), \(y_p'' = A(x + 2)e^x\)이므로 \(L[y_p] = A[(x + 2) - 3(x + 1) + 2x]e^x = -Ae^x\)이다. 따라서 \(A = -1\)이고 \(y_p = -xe^x\)이다.

물리적으로 이것이 공명이다. 고유 진동수와 같은 진동수로 밀면, 곧 \(y'' + y = \cos x\)이면 특수해가 \(\frac x2\sin x\)처럼 진폭이 시간에 비례해 커진다. 그림 1에서 진동수가 조금만 달라도 진폭이 유한한 범위에서 오르내리는 것과 대조된다.

2.4.3언제 쓰나

미정계수법은 계산이 대입뿐이라 빠르다. 하지만 \(g = \tan x\)나 \(\frac1x\)처럼 미분하면 새 꼴이 계속 생기는 함수에는 쓸 수 없고, 계수도 상수여야 한다. 그럴 때는 2.3절의 매개변수 변환법을 쓴다.

짐작이 왜 통하는지도 짚어 두자. 다항식, 지수함수, 사인과 코사인으로 이루어진 함수 모임은 미분해도 그 안에 머문다. 그래서 상수계수 작용소는 이 유한차원 공간을 자기 자신으로 보내는 선형사상이고, 특수해를 찾는 일은 그 공간에서 연립일차방정식을 푸는 일이 된다. 이때 짐작한 꼴이 동차해를 포함하면 그 사상이 가역이 아니므로 풀리지 않는 것이다.

흔한 오해\(g = \cos\omega x\)이면 \(A\cos\omega x\)만 짐작하기 쉬운데, 일계 도함수 항이 \(\sin\omega x\)를 만들므로 \(B\sin\omega x\)도 넣어야 한다. 또 동차해와 겹치는지 확인하지 않는 실수가 있으며, 겹치면 계수 방정식이 \(0 = 1\) 꼴의 모순이 된다.
마무리

처음 질문에 답하면, 상수계수이고 우변이 다항식, 지수함수, 사인, 코사인과 그 곱이면 짐작이 통하며, \(y'' - 3y' + 2y = 4x\)의 특수해는 \(2x + 3\)이다. 짐작한 꼴이 동차해와 겹치면 \(L[y_p] = 0\)이라 실패하므로 \(x\)(두 번 겹치면 \(x^2\))를 곱해야 하고, \(y'' + y = \cos x\)에서는 \(\frac x2\sin x\)라는 공명 해가 나온다. 그 밖의 우변이나 변수계수에는 매개변수 변환법을 쓴다.

2.4.4연습문제

기본

  1. \(y'' + 4y = 8\)의 특수해를 구하여라.
    답

    \(y_p = A\): \(4A = 8\), \(y_p = 2\).

응용

  1. \(y'' + y = \cos x\)의 특수해를 구하여라.
    답

    공명. \(y_p = x(A\cos x + B\sin x)\)를 넣으면 \(-2A\sin x + 2B\cos x = \cos x\), \(A = 0\), \(B = \frac12\). \(y_p = \frac x2\sin x\).

심화

  1. \(y'' - 2y' + y = e^x\)의 특수해의 꼴과 계수를 구하여라.
    답

    특성근 1이 중근이라 \(e^x\), \(xe^x\) 모두 동차해. \(y_p = Ax^2e^x\), 대입하면 \(2Ae^x = e^x\), \(A = \frac12\).
