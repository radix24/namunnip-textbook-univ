비동차 방정식과 매개변수 변환법

본문

그네를 미는 박자를 그네가 스스로 흔들리는 박자에 맞추면 그네가 점점 높이 올라간다. 바깥에서 힘 \(g(t)\)가 더해진 방정식 \(y'' + py' + qy = g(t)\)의 해는 어떻게 구하고, 미는 박자가 고유 박자와 같을 때 왜 흔들림이 끝없이 커질까?

먼저 알아야 할 것기본해와 론스키안(2.1절), 연립일차방정식과 크라머 공식(수학1 5단원)을 쓴다.

2.3.1해의 구조

\(L[y] = g\)의 해 두 개 \(y_p, \tilde y\)의 차는 \(L[y_p - \tilde y] = g - g = 0\)이므로 동차 방정식의 해이다. 그래서 특수해 하나만 찾으면 모든 해를 안다.

\[y = c_1y_1 + c_2y_2 + y_p.\]

연립일차방정식의 해집합이 특수해에 핵을 더한 것이었던 것(수학1)과 같은 구조이다.

2.3.2매개변수 변환법

\(y'' + p(t)y' + q(t)y = g(t)\)의 동차 기본해 \(y_1, y_2\)를 안다고 하자. 상수 \(c_1, c_2\)를 함수로 바꿔 \(y_p = u_1(t)y_1 + u_2(t)y_2\)로 둔다. 미지 함수가 둘이므로 조건 하나를 마음대로 정할 수 있고, 계산이 편하도록 \(u_1'y_1 + u_2'y_2 = 0\)으로 정한다. 그러면 \(y_p' = u_1y_1' + u_2y_2'\)이고, 대입하면 \(L[y_1] = L[y_2] = 0\)이므로 다음 연립방정식만 남는다.

\[\begin{cases} u_1'y_1 + u_2'y_2 = 0 \\ u_1'y_1' + u_2'y_2' = g\end{cases}\quad\Longrightarrow\quad u_1' = -\frac{y_2g}{W},\quad u_2' = \frac{y_1g}{W}\]

여기서 오른쪽은 크라머 공식으로 푼 것이고, 계수 행렬식이 론스키안 \(W \ne 0\)이므로 늘 풀린다. 이제 적분하면 특수해가 나온다.

\[y_p(t) = -y_1\int\frac{y_2g}{W}\,dt + y_2\int\frac{y_1g}{W}\,dt.\]
예제 2.3.1

\(y'' + y = \sec t\) (\(|t| < \frac\pi2\))의 일반해를 구하여라.

풀이. \(y_1 = \cos t\), \(y_2 = \sin t\), \(W = 1\)이다. \(u_1' = -\sin t\sec t = -\tan t\)이므로 \(u_1 = \ln|\cos t|\)이고, \(u_2' = \cos t\sec t = 1\)이므로 \(u_2 = t\)이다. 따라서 \(y = c_1\cos t + c_2\sin t + \cos t\ln(\cos t) + t\sin t\)이다. \(\sec t\)는 미분할수록 새 꼴이 생기므로 미정계수법으로 다룰 수 없고, 그래서 이 방법이 필요하다.

2.3.3미정계수법과 공명

상수계수이고 우변이 다항식, 지수함수, 사인, 코사인과 그 곱이면, 같은 꼴의 함수로 특수해를 추측하는 미정계수법(2.4절)이 더 빠르다. 다만 추측한 꼴이 동차해와 겹치면 \(t\)를 곱해야 한다.

예제 2.3.2 (강제 진동과 공명)

\(y'' + y = \cos\omega t\)의 특수해를 \(\omega \ne 1\)과 \(\omega = 1\)에서 구하여라.

풀이. \(\omega \ne 1\)이면 \(y_p = A\cos\omega t\)를 넣어 \(A(1 - \omega^2) = 1\)이므로 \(y_p = \frac{\cos\omega t}{1 - \omega^2}\)이다. 즉 \(\omega\)가 1에 가까울수록 진폭이 커진다. \(\omega = 1\)이면 \(\cos t\)가 동차해이므로 \(y_p = t(A\cos t + B\sin t)\)로 두고, 계산하면 \(y_p = \frac t2\sin t\)이다. 진폭이 시간에 비례해 끝없이 커지는 이 현상을 공명이라 한다. 한편 감쇠항 \(2\zeta y'\)이 있으면 진폭은 \(\frac1{\sqrt{(1 - \omega^2)^2 + (2\zeta\omega)^2}}\)로 유한하지만, 그림 1처럼 \(\omega \approx 1\)에서 크게 솟는다. 같은 절의 탐구 카드에서 감쇠를 바꾸어 볼 수 있다.

흔한 오해표준형으로 만들지 않고 공식에 \(g\)를 넣기 쉬운데, \(ay'' + \dots = f\)이면 \(g = \frac fa\)이다. 또 미정계수법에서 동차해와 겹치는데 \(t\)를 곱하지 않는 실수가 있다. 가령 \(y'' + y = \cos t\)에 \(A\cos t + B\sin t\)를 넣으면 왼쪽이 0이 되어 \(0 = \cos t\)라는 모순이 나온다.
마무리

처음 질문에 답하면, 비동차 방정식의 일반해는 동차 일반해에 특수해 하나를 더한 것이고, 특수해는 매개변수 변환 \(u_1' = -\frac{y_2g}{W}\), \(u_2' = \frac{y_1g}{W}\)로 어떤 연속 \(g\)에 대해서도 구한다. 미는 박자가 고유 박자와 같으면 \(\cos t\)가 동차해와 겹쳐 특수해가 \(\frac t2\sin t\)가 되므로 흔들림이 시간에 비례해 커지며, 이것이 공명이다. 감쇠가 있으면 진폭은 유한하지만 고유 진동수 근처에서 크게 솟는다.

2.3.4연습문제

기본

  1. \(y'' - y = e^{2t}\)의 특수해를 미정계수법으로 구하여라.
    답

    \(Ae^{2t}\): \(4A - A = 1\), \(y_p = \frac13e^{2t}\).

응용

  1. \(y'' - 2y' + y = \frac{e^t}{t}\) (\(t > 0\))을 매개변수 변환법으로 풀어라.
    답

    \(y_1 = e^t\), \(y_2 = te^t\), \(W = e^{2t}\). \(u_1' = -1\), \(u_2' = \frac1t\). \(y_p = -te^t + te^t\ln t\). 일반해 \((c_1 + c_2t + t\ln t)e^t\) (\(-te^t\)는 동차해에 흡수).

심화

  1. \(y'' + y = g(t)\), \(y(0) = y'(0) = 0\)의 해가 \(y(t) = \int_0^t\sin(t - s)g(s)\,ds\)임을 매개변수 변환법으로 보여라.
    답

    \(u_1 = -\int_0^t\sin s\,g\), \(u_2 = \int_0^t\cos s\,g\). \(y = \int_0^t(\sin t\cos s - \cos t\sin s)g\,ds = \int_0^t\sin(t - s)g(s)\,ds\). (6단원 그린 함수의 원형)
