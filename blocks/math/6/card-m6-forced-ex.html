감쇠 진동자에 사인 힘을 가할 때

예제 · 미정계수법과 초기값

먼저 예측

감쇠가 있는 용수철에 주기적인 힘을 가하면, 오래 지난 뒤의 운동은 처음 상태에 따라 달라질까요?

예측 확인

달라지지 않습니다. 처음 상태에서 온 동차해는 감쇠로 사라지고, 힘을 따라가는 특수해만 남습니다.

\(y'' + 2y' + 2y = 5\sin t\), \(y(0) = 0\), \(y'(0) = 0\)을 풀어라.

전략

특성근 \(-1 \pm i\)라 \(\sin t\)는 동차해와 겹치지 않습니다. \(y_p = A\cos t + B\sin t\) (2.4절), 동차해 \(e^{-t}(c_1\cos t + c_2\sin t)\).

풀이

  1. \(y_p'' + 2y_p' + 2y_p = (A + 2B)\cos t + (B - 2A)\sin t = 5\sin t\). \(A + 2B = 0\), \(B - 2A = 5\)에서 \(A = -2\), \(B = 1\).
    \(y_p'' = -y_p\).
  2. \(y = e^{-t}(c_1\cos t + c_2\sin t) - 2\cos t + \sin t\).
    일반해.
  3. \(y(0) = c_1 - 2 = 0\)에서 \(c_1 = 2\). \(y'(0) = -c_1 + c_2 + 1 = 0\)에서 \(c_2 = 1\).
    초기 조건.
  4. \(y = e^{-t}(2\cos t + \sin t) - 2\cos t + \sin t\).
    해.

검산

\(t = 0\)에서 \(2 - 2 = 0\) ✓. 오래 지나면 \(y \approx -2\cos t + \sin t = \sqrt5\sin(t - \delta)\) (\(\tan\delta = 2\))로 진폭 \(\sqrt5\)의 정상 진동입니다.

의미

해가 "사라지는 과도 응답 + 남는 정상 응답"으로 나뉩니다. 정상 응답의 진폭과 위상 지연은 힘의 진동수로 정해지며, 이것이 공학의 주파수 응답입니다.

이해 확인

우변이 \(5\cos t\)이면 \(y_p\)는?

답

\(A + 2B = 5\), \(B - 2A = 0\): \(A = 1\), \(B = 2\). \(y_p = \cos t + 2\sin t\).
