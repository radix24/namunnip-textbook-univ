라플라스 변환으로 초기값 문제 풀기

본문

\(y'' + 3y' + 2y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 2.1절처럼 풀면 일반해를 먼저 구하고 초기값으로 상수 둘을 정해야 한다. 미분을 곱셈으로 바꾸는 변환이 있다면, 미분방정식을 분수식의 계산으로 바꿔 초기값까지 한 번에 처리할 수 있지 않을까?

먼저 알아야 할 것이상적분과 부분적분, 부분분수 분해, 상수계수 이계 방정식(2.1절)을 쓴다.

5.1.1정의와 변환표

정의 5.1.1 (라플라스 변환)

\(t \ge 0\)에서 정의된 \(f\)에 대해, 적분이 수렴하는 \(s\)에서 \(F(s) = \mathcal L[f](s) = \int_0^\infty e^{-st}f(t)\,dt\)를 \(f\)의 라플라스 변환이라 한다.

함수 \(f(t)\)를 다른 변수 \(s\)의 함수 \(F(s)\)로 바꾸는 변환이다. \(f\)가 \(|f| \le Me^{at}\) 정도로만 자라면 \(s > a\)에서 적분이 수렴한다.

기본 함수의 변환은 직접 적분해 얻는다. 예를 들어 \(\int_0^\infty e^{-(s-a)t}dt = \frac1{s - a}\)이므로 \(\mathcal L[e^{at}] = \frac{1}{s - a}\)이고(\(s > a\)), 특히 \(a = 0\)이면 \(\mathcal L[1] = \frac1s\)이다. 부분적분을 되풀이하면 \(\mathcal L[t^n] = \frac{n!}{s^{n+1}}\)이다. 또 \(e^{i\omega t}\)의 변환 \(\frac{1}{s - i\omega} = \frac{s + i\omega}{s^2 + \omega^2}\)의 실수부와 허수부에서 \(\mathcal L[\cos\omega t] = \frac{s}{s^2 + \omega^2}\), \(\mathcal L[\sin\omega t] = \frac{\omega}{s^2 + \omega^2}\)를 얻는다. 끝으로 \(e^{at}\)를 곱하면 변환이 옮겨져 \(\mathcal L[e^{at}f] = F(s - a)\)이다.

5.1.2미분이 곱셈이 된다

정리 5.1.2

\(\mathcal L[f'] = sF(s) - f(0)\)이고 \(\mathcal L[f''] = s^2F(s) - sf(0) - f'(0)\)이다.

증명.부분적분하면 \(\int_0^\infty e^{-st}f'\,dt = [e^{-st}f]_0^\infty + s\int_0^\infty e^{-st}f\,dt = -f(0) + sF\)이다. 둘째 식은 첫째 식을 \(f'\)에 다시 쓰면 된다. ∎

초기값이 공식에 저절로 들어가는 것이 장점이다. 그래서 풀이는 세 단계이다. 먼저 방정식을 변환하면 \(Y(s)\)에 대한 일차방정식이 된다. 다음으로 \(Y(s)\)를 풀어 부분분수로 쪼갠다. 끝으로 표를 거꾸로 읽어 \(y(t)\)를 얻는다.

예제 5.1.3

\(y'' + 3y' + 2y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.

풀이. 변환하면 \(s^2Y - s + 3(sY - 1) + 2Y = 0\)이므로 \(Y = \frac{s + 3}{(s + 1)(s + 2)} = \frac{2}{s + 1} - \frac{1}{s + 2}\)이다. 따라서 \(y = 2e^{-t} - e^{-2t}\)이다. 검산하면 \(y(0) = 1\)이고 \(y'(0) = -2 + 2 = 0\)이다.

5.1.3계단, 충격, 합성곱

정의 5.1.4

계단함수 \(u_c(t)\)는 \(t < c\)에서 0, \(t \ge c\)에서 1인 함수이며 \(\mathcal L[u_c(t)f(t - c)] = e^{-cs}F(s)\)이다. 디랙 델타 \(\delta(t - c)\)는 아주 짧은 시간에 크기 1의 충격을 주는 것을 이상화한 것이며 \(\mathcal L[\delta(t - c)] = e^{-cs}\)이다. 합성곱은 \((f * g)(t) = \int_0^tf(t - \tau)g(\tau)\,d\tau\)이며 \(\mathcal L[f * g] = FG\)이다.

예제 5.1.5

정지한 용수철 \(y'' + y = \delta(t - \pi)\), \(y(0) = y'(0) = 0\)을 \(t = \pi\)에서 망치로 쳤다. \(y\)를 구하여라.

풀이. \((s^2 + 1)Y = e^{-\pi s}\)이므로 \(Y = e^{-\pi s}\frac{1}{s^2 + 1}\)이다. 이동 공식으로 \(y = u_\pi(t)\sin(t - \pi) = -u_\pi(t)\sin t\)이다. 즉 \(t < \pi\)에서는 가만히 있다가 \(t = \pi\)에 속도 1을 받아 진동한다. 일반적으로 \(y'' + y = g\)의 해는 합성곱 \(\int_0^t\sin(t - \tau)g(\tau)\,d\tau\)이며(2.3절 연습문제 3), 이때 \(\sin t\)를 충격 반응이라 한다. 5.3절에서 이 세 도구를 자세히 다룬다.

흔한 오해\(\mathcal L[f'] = sF\)로 써서 초기값을 빠뜨리기 쉽다. 또 \(\mathcal L[fg] = FG\)로 쓰는 실수가 있는데, \(FG\)가 되는 것은 곱이 아니라 합성곱의 변환이다. 부분분수로 쪼개기 전에 거꾸로 읽으려 하는 것도 안 되며, \(\frac{s+3}{(s+1)(s+2)}\)은 표에 없다.
마무리

처음 질문의 답은 "그렇다"이다. 라플라스 변환은 \(\mathcal L[y''] = s^2Y - sy(0) - y'(0)\)처럼 미분을 \(s\)의 곱셈으로 바꾸고 초기값을 저절로 넣으므로, 미분방정식이 대수방정식이 된다. 처음 문제는 \(Y = \frac{2}{s + 1} - \frac{1}{s + 2}\)를 거꾸로 읽어 \(y = 2e^{-t} - e^{-2t}\)이다. 변환표의 기본은 \(\mathcal L[e^{at}] = \frac1{s - a}\), \(\mathcal L[\sin\omega t] = \frac{\omega}{s^2 + \omega^2}\), \(\mathcal L[\cos\omega t] = \frac{s}{s^2 + \omega^2}\)이고, 계단과 충격은 \(e^{-cs}\), 합성곱은 곱 \(FG\)가 된다.

5.1.4연습문제

기본

  1. \(\mathcal L[te^{2t}]\)과 \(\mathcal L^{-1}\left[\frac{3}{s^2 + 9}\right]\)을 구하여라.
    답

    \(\frac{1}{(s - 2)^2}\), \(\sin3t\).

응용

  1. \(y' + y = u_1(t)\), \(y(0) = 0\)을 풀어라.
    답

    \(Y = \frac{e^{-s}}{s(s + 1)} = e^{-s}\left(\frac1s - \frac1{s+1}\right)\). \(y = u_1(t)(1 - e^{-(t - 1)})\).

심화

  1. 합성곱 정리로 \(\mathcal L^{-1}\left[\frac{1}{s^2(s^2 + 1)}\right]\)을 구하여라.
    답

    \(t * \sin t = \int_0^t(t - \tau)\sin\tau\,d\tau = t - \sin t\). (부분분수 \(\frac1{s^2} - \frac1{s^2+1}\)과 일치)
