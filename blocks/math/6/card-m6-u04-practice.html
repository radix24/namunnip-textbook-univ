급수해와 특수함수 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산\(y'' - 2ty' - 2y = 0\)의 점화식을 구하고, \(y(0) = 1\), \(y'(0) = 0\)인 해를 닫힌 꼴로 추측하여라. [04-01]

    힌트 1

    \(t^n\)의 계수: \((n + 2)(n + 1)a_{n+2} - 2na_n - 2a_n = 0\)(4.1절).

    힌트 2

    \(a_{n+2} = \frac{2a_n}{n + 2}\).

    풀이

    \(a_2 = 1\), \(a_4 = \frac12\), \(a_6 = \frac16\): \(a_{2k} = \frac1{k!}\). \(y = e^{t^2}\). 검산: \(y' = 2te^{t^2}\), \(y'' = (2 + 4t^2)e^{t^2}\), \(y'' - 2ty' - 2y = 0\).

  2. 개념\((t^2 + 4)y'' + y = 0\)의 \(t = 1\) 중심 급수해의 수렴 반지름 하한은? [04-01]

    힌트 1

    특이점 \(\pm2i\).

    힌트 2

    \(|1 - 2i|\).

    풀이

    \(\sqrt{1 + 4} = \sqrt5\).

  3. 계산\(4ty'' + 2y' + y = 0\)의 지표방정식과 근을 구하고, 큰 근에 대한 해를 닫힌 꼴로 구하여라. [04-02]

    힌트 1

    \(t\)를 곱해 \(4t^2y'' + 2ty' + ty = 0\), \(p_0 = \frac12\), \(q_0 = 0\)(4.2절).

    힌트 2

    \(r = \frac12\): \(a_n = -\frac{a_{n-1}}{2n(2n + 1)}\).

    풀이

    \(r(r-1) + \frac r2 = 0\), \(r = 0, \frac12\). \(r = \frac12\): \(a_n = \frac{(-1)^n}{(2n+1)!}\), \(y = \sum\frac{(-1)^nt^{n + 1/2}}{(2n+1)!} = \sin\sqrt t\). (둘째 해 \(\cos\sqrt t\))

  4. 증명르장드르 다항식의 직교성을 써서, \(\int_{-1}^1P_n(t)q(t)\,dt = 0\)임을 보여라(\(q\)는 차수가 \(n\)보다 작은 다항식). [04-03]

    힌트 1

    \(q\)를 \(P_0, \dots, P_{n-1}\)의 일차결합으로 쓰세요(4.3절).

    힌트 2

    \(P_k\)의 차수는 정확히 \(k\).

    풀이

    \(P_0, \dots, P_{n-1}\)은 차수가 서로 달라 \(n-1\)차 이하 다항식 공간의 기저. \(q = \sum_{k<n}c_kP_k\)이고 각 \(\int P_nP_k = 0\). ∎

  5. 계산점화식으로 \(P_4(t) = \frac18(35t^4 - 30t^2 + 3)\)을 확인하고 \(P_4(1)\)을 구하여라. [04-03]

    힌트 1

    \(4P_4 = 7tP_3 - 3P_2\).

    힌트 2

    \(P_3 = \frac12(5t^3 - 3t)\), \(P_2 = \frac12(3t^2 - 1)\).

    풀이

    \(7t\cdot\frac12(5t^3 - 3t) - \frac32(3t^2 - 1) = \frac12(35t^4 - 21t^2 - 9t^2 + 3)\), 4로 나누면 맞다. \(P_4(1) = \frac{35 - 30 + 3}8 = 1\).

  6. 판단한 학생이 "\(t = 0\)이 특이점이면 그곳 근처의 해는 반드시 발산한다"고 썼다. 맞는가? [04-02]

    힌트 1

    베셀 방정식 \(\nu = 0\)의 \(J_0\)를 보아라.

    힌트 2

    큰 지표근이 0 이상이면?

    풀이

    틀렸다. \(t = 0\)은 베셀 방정식의 특이점이지만 \(J_0(0) = 1\)로 유계다. 지표근 \(r \ge 0\)인 해는 유계일 수 있고, 발산하는 것은 둘째 해(\(Y_0 \sim \ln t\))다.
