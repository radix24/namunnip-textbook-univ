르장드르 다항식과 베셀 함수

본문

피아노 줄의 배음은 기본음의 2배, 3배, 4배로 정수비를 이루어 화음처럼 들린다. 그런데 원형 북을 치면 배음이 정수비가 아니어서 음높이가 흐릿하게 들린다. 이 차이는 어떤 함수에서 나올까? 구나 원통 모양에서 미분방정식을 풀 때 나타나는 특별한 함수들은 어떤 성질을 가질까?

먼저 알아야 할 것멱급수해와 르장드르 점화식(4.1절), 프로베니우스 방법(4.2절), 내적과 직교(수학1 7단원)를 쓴다.

4.3.1르장드르 다항식

4.1절에서 르장드르 방정식 \((1 - t^2)y'' - 2ty' + n(n + 1)y = 0\)은 \(n\)이 자연수이면 \(n\)차 다항식 해를 가졌다. 그 해를 \(P_n(1) = 1\)이 되도록 맞춘 것이 르장드르 다항식이다.

정의 4.3.1 (로드리게스 공식)

\(P_n(t) = \frac{1}{2^nn!}\frac{d^n}{dt^n}(t^2 - 1)^n\)을 르장드르 다항식이라 한다.

처음 몇 개는 \(P_0 = 1\), \(P_1 = t\), \(P_2 = \frac12(3t^2 - 1)\), \(P_3 = \frac12(5t^3 - 3t)\), \(P_4 = \frac18(35t^4 - 30t^2 + 3)\)이다.

정리 4.3.2

르장드르 다항식은 점화식 \((n + 1)P_{n+1} = (2n + 1)tP_n - nP_{n-1}\)을 만족한다. 또 \(m \ne n\)이면 \(\int_{-1}^1P_mP_n\,dt = 0\)이고, \(\int_{-1}^1P_n^2\,dt = \frac{2}{2n + 1}\)이다.

직교성의 증명.방정식을 \(((1 - t^2)P_n')' = -n(n + 1)P_n\)으로 쓴다. \(P_m\)을 곱하고 \([-1, 1]\)에서 부분적분하면, \(1 - t^2\)이 양 끝에서 0이므로 경계항이 사라져 \(-n(n+1)\int P_mP_n = -\int(1 - t^2)P_m'P_n'\)이다. 오른쪽은 \(m\)과 \(n\)에 대해 대칭이므로, \(m\)과 \(n\)을 바꾼 식과 빼면 \([m(m+1) - n(n+1)]\int P_mP_n = 0\)이다. \(m \ne n\)이면 괄호가 0이 아니므로 적분이 0이다. ∎

이 증명은 6단원 스투름-리우빌 이론의 원형이다. 직교성 덕분에 \([-1, 1]\)의 함수를 \(f = \sum c_nP_n\), \(c_n = \frac{2n + 1}{2}\int fP_n\)으로 전개할 수 있으며, 푸리에 급수와 같은 원리이다. 예를 들어 구 좌표에서 라플라스 방정식을 풀면 각도 \(\theta\) 방향의 해가 \(P_n(\cos\theta)\)이다.

4.3.2베셀 함수

정의 4.3.3 (제1종 베셀 함수)

\(J_\nu(t) = \sum_{k\ge0}\frac{(-1)^k}{k!\,\Gamma(k + \nu + 1)}\left(\frac t2\right)^{2k + \nu}\)을 제1종 베셀 함수라 한다. 이것은 베셀 방정식 \(t^2y'' + ty' + (t^2 - \nu^2)y = 0\)의 프로베니우스 해(\(r = \nu\))이다.

여기서 \(\Gamma\)는 계승을 실수로 넓힌 감마 함수이며 \(\Gamma(n + 1) = n!\)이다. \(J_0(t) = 1 - \frac{t^2}4 + \frac{t^4}{64} - \cdots\)는 코사인처럼 진동하지만, 진폭이 \(\sqrt{\frac{2}{\pi t}}\)처럼 줄어든다.

베셀 함수에도 점화식이 있다. \(J_{\nu-1} + J_{\nu+1} = \frac{2\nu}{t}J_\nu\)이고, 특히 \(J_0' = -J_1\)이므로 그림 1에서 \(J_1\)의 영점은 \(J_0\)의 극값 위치와 같다. \(J_0\)의 양의 영점은 \(j_{0,1} \approx 2.405\), \(j_{0,2} \approx 5.520\), \(j_{0,3} \approx 8.654\)이며, 간격이 점점 \(\pi\)에 가까워진다. 또 \(j_{\nu,m}\)이 \(J_\nu\)의 영점이면 \(m \ne n\)일 때 \(\int_0^1tJ_\nu(j_{\nu,m}t)J_\nu(j_{\nu,n}t)\,dt = 0\)이다. 즉 베셀 함수도 직교하지만, 가중치 \(t\)가 붙는다.

원형 북의 진동을 원통 좌표로 풀면 반지름 방향 모양이 \(J_0(j_{0,m}r)\)이고, 진동수는 영점 \(j_{0,m}\)에 비례한다. 그래서 북소리의 배음은 피아노 줄과 달리 \(2.405 : 5.520 : 8.654\)로 정수비가 아니다.

흔한 오해르장드르 직교성을 \([0, 1]\)에서 쓰기 쉽지만, 구간은 \([-1, 1]\)이다. 또 베셀 직교성에서 가중치 \(t\)를 빠뜨리는 실수가 있다. \(J_0\)의 영점을 \(\pi\)의 배수로 여기는 것도 틀렸으며, 근사적으로 \(\left(m - \frac14\right)\pi\)이다.
마무리

처음 질문에 답하면, 원형 북의 배음은 베셀 함수 \(J_0\)의 영점 \(2.405, 5.520, 8.654, \dots\)에 비례하고, 이 수들은 정수비가 아니므로 음높이가 흐릿하게 들린다. 르장드르 다항식 \(P_n\)은 로드리게스 공식으로 주어지고 \((n+1)P_{n+1} = (2n+1)tP_n - nP_{n-1}\)을 만족하며 \([-1, 1]\)에서 직교한다. 베셀 함수 \(J_\nu\)는 베셀 방정식의 프로베니우스 해로, 진동하며 감쇠하고 영점들로 가중 직교한다. 둘 다 구와 원통 좌표의 편미분방정식에서 나온다.

4.3.3연습문제

기본

  1. 점화식으로 \(P_2\)에서 \(P_3\)을 구하여라.
    답

    \(3P_3 = 5tP_2 - 2P_1 = \frac52(3t^3 - t) - 2t\), \(P_3 = \frac12(5t^3 - 3t)\).

응용

  1. \(\int_{-1}^1P_2^2\,dt = \frac25\)을 직접 계산하여라.
    답

    \(\frac14\int(9t^4 - 6t^2 + 1) = \frac14\left(\frac{18}5 - 4 + 2\right) = \frac25\).

심화

  1. \(t^2\)을 르장드르 다항식으로 전개하여라.
    답

    \(t^2 = \frac23P_2 + \frac13P_0\).
