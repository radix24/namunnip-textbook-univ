정칙 특이점과 프로베니우스 방법

본문
이 절에서 배울 것
  • 정칙 특이점을 정의하고, 그 근처에서 해가 \(t^r\sum a_nt^n\) 꼴임을 안다.
  • 지표방정식의 근 \(r_1, r_2\)로 해의 형태를 정한다(근의 차가 정수가 아닐 때, 같을 때, 정수일 때).
  • 베셀 방정식에 적용한다.
먼저 알아야 할 것
  • 멱급수해 (4.1절), 코시-오일러 방정식 (2.2절).

4.2.1특이점 근처의 해

특이점에서는 해가 멱급수가 아닐 수 있습니다. 코시-오일러 방정식 \(t^2y'' + bty' + cy = 0\)의 해 \(t^m\), \(t^m\ln t\)는 \(m\)이 자연수가 아니면 \(t = 0\)에서 멱급수로 쓸 수 없습니다. 프로베니우스는 계수가 0 근처에서 코시-오일러를 "닮은" 방정식이면 해가 \(t^r\)×(멱급수) 꼴임을 보였습니다.

정의 4.2.1 (정칙 특이점)

\(y'' + p(t)y' + q(t)y = 0\)에서 \(t = 0\)이 특이점이고 \(tp(t)\), \(t^2q(t)\)가 \(t = 0\)에서 멱급수로 쓰이면(해석적이면) 정칙 특이점이라 한다. \(p_0 = \lim tp\), \(q_0 = \lim t^2q\)로 두고

\[r(r - 1) + p_0r + q_0 = 0\]

을 지표방정식이라 한다.

지표방정식은 0 근처의 방정식을 \(t^2y'' + p_0ty' + q_0y = 0\)(코시-오일러)으로 근사했을 때의 \(t^r\) 조건입니다.

정리 4.2.2 (프로베니우스)

지표방정식의 근을 \(r_1 \ge r_2\) (실수)라 하면 \(t > 0\)에서

(a) \(y_1 = t^{r_1}\sum_{n\ge0}a_nt^n\) (\(a_0 = 1\))은 늘 해이다.

(b) \(r_1 - r_2\)가 정수가 아니면 \(y_2 = t^{r_2}\sum b_nt^n\)도 해이다.

(c) \(r_1 = r_2\)이면 \(y_2 = y_1\ln t + t^{r_1}\sum c_nt^n\).

(d) \(r_1 - r_2\)가 양의 정수이면 \(y_2 = Cy_1\ln t + t^{r_2}\sum d_nt^n\) (\(C\)는 0일 수도 있음).

4.2.2계산

예제 4.2.3

\(2t^2y'' + ty' - (1 + t)y = 0\)의 지표방정식과 해의 형태를 구하고 첫 해의 앞 세 항을 구하여라.

풀이. \(y'' + \frac{1}{2t}y' - \frac{1 + t}{2t^2}y = 0\)이라 \(p_0 = \frac12\), \(q_0 = -\frac12\). 지표방정식 \(r(r - 1) + \frac12r - \frac12 = 0\), 곧 \(2r^2 - r - 1 = 0\), \(r = 1, -\frac12\). 차가 \(\frac32\)(정수 아님)이라 (b)의 경우: 두 해가 모두 \(t^r\sum\) 꼴입니다. \(y = \sum a_nt^{n + r}\)을 넣으면

\[[2(n + r)(n + r - 1) + (n + r) - 1]a_n = a_{n-1}.\]

\(r = 1\): \(a_n = \frac{a_{n-1}}{n(2n + 3)}\). \(a_1 = \frac15\), \(a_2 = \frac{1}{5\cdot14} = \frac{1}{70}\). \(y_1 = t\left(1 + \frac t5 + \frac{t^2}{70} + \cdots\right)\). \(r = -\frac12\)의 해는 \(t = 0\)에서 \(t^{-1/2}\)처럼 발산합니다.

베셀 방정식 \(t^2y'' + ty' + (t^2 - \nu^2)y = 0\)은 \(p_0 = 1\), \(q_0 = -\nu^2\)이라 지표방정식 \(r^2 = \nu^2\), \(r = \pm\nu\)입니다. \(\nu = 0\)이면 중근이라 둘째 해에 \(\ln t\)가 나타나고(\(Y_0\)), \(\nu = \frac12\)이면 차가 1(정수)인데도 \(C = 0\)이라 \(\frac{\sin t}{\sqrt t}\), \(\frac{\cos t}{\sqrt t}\)가 됩니다(같은 절의 예제 카드).

흔한 실수(1) \(p_0, q_0\)을 표준형으로 바꾸지 않고 읽는다: \(2t^2y''\)의 2로 나눠야 한다. (2) 큰 근부터 쓰지 않는다: 작은 근으로 점화식을 쓰면 \(n = r_1 - r_2\)에서 분모가 0이 될 수 있다. 큰 근의 해는 늘 문제가 없다.
요약
  1. 정칙 특이점: \(tp\), \(t^2q\)가 해석적. 지표방정식 \(r(r-1) + p_0r + q_0 = 0\).
  2. 큰 근의 해는 늘 \(t^{r_1}\sum a_nt^n\).
  3. 둘째 해: 근의 차가 정수 아님 → 같은 꼴, 같음 → \(\ln t\) 항, 양의 정수 → \(\ln t\) 항이 있을 수도.

4.2.3연습문제

기본

  1. \(t^2y'' + 3ty' + (1 + t)y = 0\)의 지표방정식과 근은?
    답

    \(r(r-1) + 3r + 1 = (r + 1)^2\), \(r = -1\) (중근). 둘째 해에 \(\ln t\).

응용

  1. \(t = 0\)이 \(t^3y'' + y = 0\)의 정칙 특이점인가?
    답

    아니다. \(t^2q = \frac1t\)이 0에서 해석적이지 않다(비정칙 특이점).

심화

  1. 베셀 방정식 \(\nu = 0\)의 프로베니우스 해 \(J_0 = \sum\frac{(-1)^k}{(k!)^2}\left(\frac t2\right)^{2k}\)를 점화식으로 확인하여라.
    답

    \(r = 0\), \(n^2a_n = -a_{n-2}\). \(a_{2k} = \frac{(-1)^k}{4^k(k!)^2}a_0\).
