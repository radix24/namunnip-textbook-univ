정칙 특이점과 프로베니우스 방법

본문

\(2t^2y'' + ty' - (1 + t)y = 0\)은 \(t = 0\)에서 최고차 계수가 0이 되는 특이점을 가진다. 그곳에서는 해가 \(t^{-1/2}\)처럼 발산하기도 하므로 4.1절의 멱급수로는 해를 쓸 수 없다. 특이점 근처의 해는 어떤 꼴이고, 그 꼴을 어떻게 미리 알 수 있을까?

먼저 알아야 할 것멱급수해(4.1절), 코시-오일러 방정식(2.2절)을 쓴다.

4.2.1특이점 근처의 해

특이점에서는 해가 멱급수가 아닐 수 있다. 예를 들어 코시-오일러 방정식 \(t^2y'' + bty' + cy = 0\)의 해 \(t^m\), \(t^m\ln t\)는 \(m\)이 자연수가 아니면 \(t = 0\)에서 멱급수로 쓸 수 없다. 프로베니우스는 계수가 0 근처에서 코시-오일러 방정식을 닮은 방정식이면 해가 \(t^r\)에 멱급수를 곱한 꼴임을 보였다.

정의 4.2.1 (정칙 특이점)

\(y'' + p(t)y' + q(t)y = 0\)에서 \(t = 0\)이 특이점이고 \(tp(t)\), \(t^2q(t)\)가 \(t = 0\)에서 멱급수로 쓰이면(해석적이면) 정칙 특이점이라 한다. \(p_0 = \lim tp\), \(q_0 = \lim t^2q\)로 두고, 다음 식을 지표방정식이라 한다.

\[r(r - 1) + p_0r + q_0 = 0\]

지표방정식은 0 근처의 방정식을 코시-오일러 방정식 \(t^2y'' + p_0ty' + q_0y = 0\)으로 근사했을 때 \(t^r\)이 해일 조건이다.

정리 4.2.2 (프로베니우스)

지표방정식의 근을 실수 \(r_1 \ge r_2\)라 하면 \(t > 0\)에서 \(y_1 = t^{r_1}\sum_{n\ge0}a_nt^n\) (\(a_0 = 1\))은 늘 해이다. 둘째 해는 근의 차에 따라 정해진다. \(r_1 - r_2\)가 정수가 아니면 \(y_2 = t^{r_2}\sum b_nt^n\)이고, \(r_1 = r_2\)이면 \(y_2 = y_1\ln t + t^{r_1}\sum c_nt^n\)이며, \(r_1 - r_2\)가 양의 정수이면 \(y_2 = Cy_1\ln t + t^{r_2}\sum d_nt^n\)이다. 마지막 경우 \(C\)는 0일 수도 있다.

왜 근의 차가 정수일 때 문제가 생길까? \(y = \sum a_nt^{n + r}\)을 넣으면 \(a_n\)의 계수는 지표다항식에 \(r + n\)을 넣은 값이 된다. 따라서 작은 근 \(r_2\)로 점화식을 쓰면 \(n = r_1 - r_2\)에서 그 계수가 0이 되어 \(a_n\)을 정할 수 없고, 그 자리를 \(\ln t\) 항이 메운다. 그러나 큰 근 \(r_1\)에서는 \(r_1 + n\)이 다시 근이 될 수 없으므로 늘 문제가 없다.

4.2.2계산

예제 4.2.3

\(2t^2y'' + ty' - (1 + t)y = 0\)의 지표방정식과 해의 형태를 구하고 첫 해의 앞 세 항을 구하여라.

풀이. 표준형은 \(y'' + \frac{1}{2t}y' - \frac{1 + t}{2t^2}y = 0\)이므로 \(p_0 = \frac12\), \(q_0 = -\frac12\)이다. 지표방정식 \(r(r - 1) + \frac12r - \frac12 = 0\), 곧 \(2r^2 - r - 1 = 0\)에서 \(r = 1, -\frac12\)이다. 차가 \(\frac32\)로 정수가 아니므로 두 해가 모두 \(t^r\sum\) 꼴이다. \(y = \sum a_nt^{n + r}\)을 넣으면 다음 점화식을 얻는다.

\[[2(n + r)(n + r - 1) + (n + r) - 1]a_n = a_{n-1}.\]

\(r = 1\)이면 \(a_n = \frac{a_{n-1}}{n(2n + 3)}\)이므로 \(a_1 = \frac15\), \(a_2 = \frac{1}{5\cdot14} = \frac{1}{70}\)이고 \(y_1 = t\left(1 + \frac t5 + \frac{t^2}{70} + \cdots\right)\)이다. 한편 \(r = -\frac12\)의 해는 그림 1처럼 \(t = 0\)에서 \(t^{-1/2}\)처럼 발산한다.

베셀 방정식 \(t^2y'' + ty' + (t^2 - \nu^2)y = 0\)은 \(p_0 = 1\), \(q_0 = -\nu^2\)이므로 지표방정식이 \(r^2 = \nu^2\), 곧 \(r = \pm\nu\)이다. \(\nu = 0\)이면 중근이므로 둘째 해 \(Y_0\)에 \(\ln t\)가 나타난다. 그런데 \(\nu = \frac12\)이면 차가 1로 정수인데도 \(C = 0\)이어서 해가 \(\frac{\sin t}{\sqrt t}\), \(\frac{\cos t}{\sqrt t}\)가 된다. 같은 절의 예제 카드가 이 경우를 자세히 다룬다.

흔한 오해\(p_0, q_0\)을 표준형으로 바꾸지 않고 읽기 쉬운데, 예제에서는 \(2t^2y''\)의 2로 먼저 나눠야 한다. 또 작은 근부터 점화식을 쓰는 실수가 있다. 그러면 \(n = r_1 - r_2\)에서 분모가 0이 될 수 있으므로, 큰 근의 해를 먼저 구한다.
마무리

처음 질문에 답하면, 정칙 특이점 근처의 해는 \(t^r\)에 멱급수를 곱한 꼴이고, 지수 \(r\)은 지표방정식 \(r(r - 1) + p_0r + q_0 = 0\)으로 미리 안다. 예제에서는 \(r = 1, -\frac12\)이라 하나는 \(t\)처럼 0으로 가고 다른 하나는 \(t^{-1/2}\)처럼 발산한다. 큰 근의 해는 늘 \(t^{r_1}\sum a_nt^n\)이며, 둘째 해는 근의 차가 정수가 아니면 같은 꼴, 같으면 \(\ln t\) 항이 붙고, 양의 정수이면 \(\ln t\) 항이 붙을 수도 있다.

4.2.3연습문제

기본

  1. \(t^2y'' + 3ty' + (1 + t)y = 0\)의 지표방정식과 근은?
    답

    \(r(r-1) + 3r + 1 = (r + 1)^2\), \(r = -1\) (중근). 둘째 해에 \(\ln t\).

응용

  1. \(t = 0\)이 \(t^3y'' + y = 0\)의 정칙 특이점인가?
    답

    아니다. \(t^2q = \frac1t\)이 0에서 해석적이지 않다(비정칙 특이점).

심화

  1. 베셀 방정식 \(\nu = 0\)의 프로베니우스 해 \(J_0 = \sum\frac{(-1)^k}{(k!)^2}\left(\frac t2\right)^{2k}\)를 점화식으로 확인하여라.
    답

    \(r = 0\), \(n^2a_n = -a_{n-2}\). \(a_{2k} = \frac{(-1)^k}{4^k(k!)^2}a_0\).
