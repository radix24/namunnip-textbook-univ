구간추정 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 열어 보자.

  1. 계산정규 표본 \(n = 9\), \(\bar x = 20\), \(s = 3\)에서 \(\mu\)의 90% 신뢰구간은? (\(t_{0.05, 8} = 1.860\)) [03-01]

    힌트 1

    \(s/\sqrt n = 1\)(3.1절).

    힌트 2

    \(20 \pm 1.860\).

    풀이

    \([18.14, 21.86]\).

  2. 계산400명 중 120명이 어떤 제품을 써 봤다. 비율의 99% 신뢰구간은? (\(z_{0.005} = 2.576\)) [03-01]

    힌트 1

    \(\hat p = 0.3\), 표준오차 \(\sqrt{0.21/400}\).

    힌트 2

    표준오차 0.0229.

    풀이

    \(0.3 \pm 2.576\cdot0.0229 = [0.241, 0.359]\).

  3. 계산정규 표본 \(n = 15\), \(s^2 = 4\)에서 \(\sigma^2\)의 90% 신뢰구간은? (\(\chi^2_{14}\)의 5%, 95% 분위수 6.571, 23.685) [03-01]

    힌트 1

    \((n-1)s^2 = 56\).

    힌트 2

    큰 분위수가 왼쪽 끝.

    풀이

    \([56/23.685, 56/6.571] = [2.36, 8.52]\).

  4. 계산공장 A 8개 제품 무게 평균 101.2, 표준편차 2.0, 공장 B 8개 평균 98.6, 표준편차 2.4. 등분산을 가정하고 차이의 95% 신뢰구간을 구하여라. (\(t_{0.025, 14} = 2.145\)) [03-02]

    힌트 1

    \(s_p^2 = (4 + 5.76)/2\)(3.2절).

    힌트 2

    표준오차 \(s_p\sqrt{2/8} = s_p/2\).

    풀이

    \(s_p^2 = 4.88\), \(s_p = 2.209\), 표준오차 1.105. \(2.6 \pm 2.145\cdot1.105 = [0.23, 4.97]\).

  5. 증명\(\sigma\)를 아는 정규 표본에서 \([\bar X - z_{\alpha/2}\sigma/\sqrt n, \bar X + z_{\alpha/2}\sigma/\sqrt n]\)이 \(1 - \alpha\) 신뢰구간임을 추축량으로 보여라. [03-01]

    힌트 1

    \(Q = (\bar X - \mu)/(\sigma/\sqrt n) \sim N(0,1)\).

    힌트 2

    \(-z \le Q \le z\)를 \(\mu\)에 대해 풀기.

    풀이

    \(Q\)의 분포는 \(\mu\)와 무관하고 \(P(-z_{\alpha/2} \le Q \le z_{\alpha/2}) = 1 - \alpha\). 부등식에 \(\sigma/\sqrt n\)을 곱하고 \(\bar X\)를 옮기면 \(\bar X - z\sigma/\sqrt n \le \mu \le \bar X + z\sigma/\sqrt n\). 같은 사건이므로 확률 \(1 - \alpha\). ∎

  6. 판단한 학생이 "두 집단 각각의 95% 신뢰구간이 겹치므로 두 평균은 차이가 없다"고 결론냈다. 맞는가? [03-02]

    힌트 1

    차이의 표준오차는 \(\sqrt{se_1^2 + se_2^2}\).

    힌트 2

    \(se_1 = se_2 = 1\), 평균 차 3인 경우.

    풀이

    틀렸다. 각 구간의 반폭은 1.96, 차이 3이면 구간이 겹친다(3 < 3.92). 그러나 차이의 표준오차는 \(\sqrt2 \approx 1.414\)이고 \(3 > 1.96\cdot1.414 = 2.77\)이라 차이의 구간은 0을 포함하지 않는다. 차이는 차이의 구간으로 판단해야 한다.
