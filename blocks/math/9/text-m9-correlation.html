표본상관계수와 그 검정

본문
이 절에서 배울 것
  • 표본상관계수 \(r = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i - \bar x)^2\sum(y_i - \bar y)^2}}\)의 성질과 해석을 안다.
  • \(r^2\)이 회귀에서 설명된 변동의 비율(결정계수)임을 안다.
  • \(H_0 : \rho = 0\)을 \(t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}} \sim t_{n-2}\)로 검정한다.
먼저 알아야 할 것
  • 최소제곱 회귀와 기울기의 검정 (5.1절, 5.2절).

5.3.1성질

\(r\)은 \(-1\)과 1 사이이고(코시-슈바르츠 부등식), 점들이 기울기가 양인 직선 위에 있으면 1, 음인 직선이면 \(-1\)입니다. 단위를 바꿔도(\(x\)를 cm에서 m로) 변하지 않습니다. 회귀 기울기와는 \(\hat\beta_1 = r\frac{s_y}{s_x}\)의 관계입니다.

\(r\)은 직선적 관계의 세기만 잽니다. \(y = x^2\) (\(x\)가 \(-1\)부터 1까지 대칭)처럼 완전히 정해진 관계도 \(r = 0\)일 수 있고, 이상값 하나가 \(r\)을 크게 바꿀 수 있습니다. 그래서 산점도를 먼저 봅니다.

5.3.2결정계수

단순회귀에서 전체 변동 \(\sum(y_i - \bar y)^2\) 가운데 회귀직선이 설명하는 부분의 비율이 \(R^2 = r^2\)입니다. \(r = 0.4\)이면 \(r^2 = 0.16\)으로 변동의 16%만 설명합니다. 상관이 "있다"와 "강하다"는 다른 말입니다.

5.3.3검정

두 변수가 이변량 정규분포를 따르고 \(\rho = 0\)이면

\[t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}} \sim t_{n-2}.\]

이 통계량은 5.2절의 기울기 검정 \(\frac{\hat\beta_1}{\operatorname{SE}(\hat\beta_1)}\)과 정확히 같아, "상관이 0"과 "기울기가 0"은 같은 검정입니다. 표본이 크면 아주 약한 상관도 유의해지므로 \(r\)의 크기와 함께 해석합니다.

흔한 오해(1) 상관이 인과라고 여긴다. 아이스크림 판매와 익사 사고는 상관이 있지만 둘 다 기온의 영향이다. (2) \(r = 0\)이면 관계가 없다고 여긴다. 곡선 관계는 \(r\)로 잡히지 않는다.
요약
  1. \(-1 \le r \le 1\), 직선 관계의 세기, 단위 무관.
  2. \(r^2\): 설명된 변동의 비율.
  3. 검정 \(t = \frac{r\sqrt{n - 2}}{\sqrt{1 - r^2}}\), 기울기 검정과 동일.

5.3.4연습문제

기본

  1. \(r = -0.9\)이면 결정계수와 해석은?
    답

    \(r^2 = 0.81\). 강한 음의 직선 관계, 변동의 81%를 설명.

응용

  1. 점 \((-1, 1), (0, 0), (1, 1)\)의 상관계수를 구하여라.
    답

    \(\bar x = 0\), \(\sum x_i(y_i - \bar y) = -1\cdot\frac13 + 0 + 1\cdot\frac13 = 0\)이라 \(r = 0\). 그러나 \(y = x^2\)으로 완전히 정해진다.

심화

  1. \(n = 1000\), \(r = 0.08\)이면 검정통계량은? 결과를 어떻게 해석하는가?
    답

    \(t = \frac{0.08\sqrt{998}}{\sqrt{0.9936}} \approx 2.54\), 5%에서 유의. 그러나 \(r^2 = 0.0064\)로 설명력이 1%도 안 되는 아주 약한 관계다.
