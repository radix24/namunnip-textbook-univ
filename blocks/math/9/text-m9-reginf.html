회귀계수의 검정과 예측구간

본문
이 절에서 배울 것
  • 기울기에 대한 t 검정과 신뢰구간을 수행한다.
  • 평균 반응의 신뢰구간과 새 관측값의 예측구간을 구별해 계산한다.
  • 회귀의 분산분석표와 F 검정이 기울기의 t 검정과 같음을 안다.
먼저 알아야 할 것
  • 최소제곱 추정량의 분포 (5.1절), t 검정 (4.1절).

5.2.1기울기의 추론

정규 오차 모형에서 \(\hat\beta_1 \sim N(\beta_1, \sigma^2/S_{xx})\)이고, \((n-2)\hat\sigma^2/\sigma^2 \sim \chi^2_{n-2}\)이며 둘은 독립입니다. 1.2절과 같은 논리로

\[T = \frac{\hat\beta_1 - \beta_1}{\hat\sigma/\sqrt{S_{xx}}} \sim t_{n-2}.\]

이 추축량으로 신뢰구간 \(\hat\beta_1 \pm t_{\alpha/2, n-2}\,\hat\sigma/\sqrt{S_{xx}}\)를 만들고, \(H_0: \beta_1 = 0\) ("\(x\)가 \(y\)와 직선 관계가 없다")을 검정합니다.

예제 5.2.1

5.1절 예제 자료로 \(H_0: \beta_1 = 0\)을 검정하고 \(\beta_1\)의 95% 신뢰구간을 구하여라.

풀이. 표준오차 0.1299, \(t = 0.65/0.1299 \approx 5.005\), 자유도 6. \(p \approx 0.0024\)로 기각합니다. \(t_{0.025, 6} = 2.447\)이므로 구간은 \(0.65 \pm 0.318 = [0.332, 0.968]\).

5.2.2평균 반응과 새 관측값

\(x_0\)에서 예측값 \(\hat y_0 = \hat\beta_0 + \hat\beta_1x_0\)의 불확실성에는 두 가지가 있습니다. 하나는 직선 자체의 추정 오차, 다른 하나는 새 관측값에 붙는 오차 \(\varepsilon\)입니다.

정리 5.2.2

(a) 평균 반응 \(\beta_0 + \beta_1x_0\)의 신뢰구간: \(\hat y_0 \pm t_{\alpha/2}\,\hat\sigma\sqrt{\frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}}\). (b) 새 관측값 \(Y_0\)의 예측구간: \(\hat y_0 \pm t_{\alpha/2}\,\hat\sigma\sqrt{1 + \frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}}\).

근호 안의 \(\frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}\)는 \(\mathrm{Var}(\hat y_0)/\sigma^2\)입니다(\(\hat y_0 = \bar Y + \hat\beta_1(x_0 - \bar x)\), 두 항이 무상관). 예측구간에는 새 오차의 분산 \(\sigma^2\)이 더해져 "1 +"가 붙습니다. \(x_0\)이 \(\bar x\)에서 멀수록 두 구간 모두 넓어집니다.

예제 5.2.3

같은 자료로 \(x_0 = 9\)에서 평균 반응의 95% 신뢰구간과 새 관측값의 95% 예측구간을 구하여라.

풀이. \(\hat y_0 = 2.2 + 0.65\cdot9 = 8.05\). \(\frac18 + \frac{4.5^2}{42} = 0.607\). 평균 반응: \(0.842\sqrt{0.607} = 0.656\), 구간 \(8.05 \pm 1.605 = [6.45, 9.65]\). 예측: \(0.842\sqrt{1.607} = 1.067\), 구간 \(8.05 \pm 2.611 = [5.44, 10.66]\). 개별 값의 예측은 평균의 추정보다 훨씬 불확실합니다. 또 \(x_0 = 9\)는 자료 범위 밖이라 직선이 계속 유지된다는 가정에 기대고 있습니다(외삽).

5.2.3분산분석표

\(S_{yy} = SSR + SSE\) (설명된 제곱합 + 잔차 제곱합)로 나누고 \(F = \frac{SSR/1}{SSE/(n-2)}\)을 \(F_{1, n-2}\)과 비교하는 것이 회귀의 F 검정입니다. 단순회귀에서는 \(F = t^2\)이라 기울기의 t 검정과 같습니다. 예제에서 \(SSR = 21.995 - 4.25 = 17.745\), \(F = 17.745/0.708 \approx 25.05 = 5.005^2\).

흔한 실수(1) 예측구간 대신 신뢰구간으로 개별 값을 예측한다(너무 좁다). (2) 자료 범위 밖으로 외삽하면서 같은 구간을 믿는다. (3) 기울기가 유의하면 \(x\)가 \(y\)의 원인이라고 결론낸다.
요약
  1. \((\hat\beta_1 - \beta_1)/(\hat\sigma/\sqrt{S_{xx}}) \sim t_{n-2}\): 기울기의 검정과 구간.
  2. 평균 반응 구간: \(\sqrt{1/n + (x_0 - \bar x)^2/S_{xx}}\). 예측구간: 그 안에 1을 더함.
  3. 회귀 F 검정 = 기울기 t 검정의 제곱(단순회귀).

5.2.4연습문제

기본

  1. 예제 자료에서 \(x_0 = 4.5\)일 때 평균 반응 신뢰구간의 반폭은? 왜 가장 좁은가?
    답

    \(\hat y_0 = 5.125\), 반폭 \(2.447\cdot0.842/\sqrt8 \approx 0.728\). \(x_0 = \bar x\)에서 기울기 오차의 영향이 사라진다.

응용

  1. 예제 자료에서 \(H_0: \beta_0 = 0\)의 t 값을 구하여라. (\(\mathrm{se}(\hat\beta_0) = \hat\sigma\sqrt{1/n + \bar x^2/S_{xx}}\))
    답

    \(\mathrm{se} = 0.842\sqrt{0.125 + 20.25/42} \approx 0.656\). \(t = 2.2/0.656 \approx 3.35\), \(p \approx 0.015\).

심화

  1. 단순회귀에서 \(F = t^2\)임을 \(SSR = \hat\beta_1^2S_{xx}\)를 써서 보여라.
    답

    \(SSR = \sum(\hat y_i - \bar y)^2 = \hat\beta_1^2\sum(x_i - \bar x)^2 = \hat\beta_1^2S_{xx}\). \(F = \hat\beta_1^2S_{xx}/\hat\sigma^2 = (\hat\beta_1/(\hat\sigma/\sqrt{S_{xx}}))^2 = t^2\).
