부트스트랩

본문
이 절에서 배울 것
  • 표본에서 복원추출로 같은 크기의 재표본을 여러 번 뽑아 통계량의 분포를 흉내 내는 부트스트랩을 구현한다.
  • 공식이 없는 통계량(중앙값 등)의 표준오차를 부트스트랩으로 구한다.
  • 백분위 부트스트랩 신뢰구간을 만들고 한계를 안다.
먼저 알아야 할 것
  • 표준오차와 신뢰구간 (3.1절), 통계 소프트웨어 (7.1절).

7.2.1생각

표본평균의 표준오차는 \(\frac s{\sqrt n}\)이라는 공식이 있지만, 중앙값이나 상관계수의 비 같은 통계량은 공식이 복잡하거나 없습니다. 부트스트랩은 "모집단 대신 표본을 모집단으로 보고" 표본에서 복원추출로 크기 \(n\)인 재표본을 \(B\)번 뽑아 통계량을 계산합니다. 그 \(B\)개 값의 흩어짐이 표준오차의 추정값입니다.

7.2.2구현

import random, statistics as st
data = [12, 15, 9, 20, 14, 11, 30, 13, 16, 10]
random.seed(5)
B = 2000
meds = [st.median(random.choices(data, k=len(data))) for _ in range(B)]
print(st.median(data))           # 13.5
print(st.pstdev(meds))           # 부트스트랩 표준오차 약 1.67
meds.sort()
print(meds[49], meds[1949])      # 백분위 95% 구간 (11.0, 17.5)

random.choices는 복원추출입니다(같은 값이 여러 번 뽑힐 수 있음). 표본평균에 같은 방법을 쓰면 부트스트랩 표준오차가 약 1.84로, 공식 \(\frac s{\sqrt n} = 1.95\)과 비슷합니다(부트스트랩은 \(n\)으로 나눈 분산을 쓰는 셈이라 조금 작음). R에서는 boot 패키지가 같은 일을 합니다.

7.2.3신뢰구간과 한계

재표본 통계량의 2.5%와 97.5% 백분위수를 양 끝으로 하는 것이 백분위 구간입니다. 위에서 중앙값의 95% 구간은 \((11.0, 17.5)\)입니다. 자료 하나 30이 커서 구간이 위로 길게 비대칭입니다.

  • 표본이 작으면(\(n = 10\)) 재표본이 원래 값들로만 이루어져 분포가 거칠다. 중앙값은 몇 가지 값만 나온다.
  • 최댓값 같은 극단 통계량에는 잘 맞지 않는다(재표본 최댓값이 표본 최댓값을 넘을 수 없음).
  • 자료가 독립이라는 가정이 필요하다. 시계열처럼 이어진 자료는 블록으로 뽑는다.
흔한 오해(1) 부트스트랩이 자료를 늘려 준다고 여긴다. 새 정보는 없고 표본 안의 흩어짐을 재활용할 뿐이다. (2) 비복원추출로 재표본을 만든다. 크기 \(n\)을 비복원으로 뽑으면 늘 원래 표본과 같아 흩어짐이 0이다.
요약
  1. 표본에서 복원추출로 재표본 \(B\)개, 통계량의 분포를 흉내.
  2. 재표본 통계량의 표준편차 = 부트스트랩 표준오차.
  3. 백분위 구간, 작은 표본·극단 통계량·종속 자료에서 주의.

7.2.4연습문제

기본

  1. 자료 \(\{1, 2, 3\}\)에서 크기 3의 복원추출 재표본은 순서를 생각하면 몇 가지인가?
    답

    \(3^3 = 27\)가지.

응용

  1. 1번 자료에서 재표본 평균이 3이 될 확률은?
    답

    \((3, 3, 3)\) 하나뿐이라 \(\frac1{27}\).

심화

  1. 본문 자료에서 이상값 30을 15로 바꾸면 중앙값의 부트스트랩 구간은 어떻게 변할지 예상하여라.
    답

    중앙값은 이상값에 둔감하지만, 큰 값 쪽의 재표본 중앙값이 줄어 위쪽 끝이 조금 내려가고 구간이 덜 비대칭이 된다. (평균의 구간은 훨씬 크게 변한다.)
