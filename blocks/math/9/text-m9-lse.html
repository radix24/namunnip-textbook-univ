단순회귀와 최소제곱 추정량의 성질

본문
이 절에서 배울 것
  • 단순선형회귀 모형 \(Y_i = \beta_0 + \beta_1x_i + \varepsilon_i\)를 세우고 최소제곱 추정량을 구한다.
  • \(\hat\beta_1\)이 \(Y_i\)의 일차결합임을 이용해 기대값과 분산을 유도한다.
  • 표본상관계수와 결정계수의 관계를 안다.
먼저 알아야 할 것
  • 정규방정식 (수학8 1.1절), 기대값과 분산의 성질 (수학5 3.1절).

5.1.1모형

수학8에서는 점들에 직선을 맞추는 계산을 했습니다. 통계학에서는 한 걸음 더 나가 "자료가 어떤 확률 모형에서 나왔다"고 보고, 맞춘 직선이 참 직선에서 얼마나 벗어날 수 있는지 묻습니다.

정의 5.1.1

단순선형회귀 모형: \(Y_i = \beta_0 + \beta_1x_i + \varepsilon_i\), \(x_i\)는 고정된 값, 오차 \(\varepsilon_i\)는 독립이고 \(E[\varepsilon_i] = 0\), \(\mathrm{Var}(\varepsilon_i) = \sigma^2\). 추론에는 \(\varepsilon_i \sim N(0, \sigma^2)\)을 덧붙인다.

기호: \(S_{xx} = \sum(x_i - \bar x)^2\), \(S_{xy} = \sum(x_i - \bar x)(y_i - \bar y)\), \(S_{yy} = \sum(y_i - \bar y)^2\).

정규방정식을 풀면(수학8 1.1절) 최소제곱 추정량은

\[\hat\beta_1 = \frac{S_{xy}}{S_{xx}},\qquad \hat\beta_0 = \bar y - \hat\beta_1\bar x.\]

5.1.2기대값과 분산

정리 5.1.2

(a) \(E[\hat\beta_1] = \beta_1\), \(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\). (b) \(E[\hat\beta_0] = \beta_0\), \(\mathrm{Var}(\hat\beta_0) = \sigma^2\left(\frac1n + \frac{\bar x^2}{S_{xx}}\right)\). (c) \(\hat\sigma^2 = \frac{SSE}{n-2}\)는 \(\sigma^2\)의 불편 추정량이다(\(SSE = \sum(y_i - \hat y_i)^2\)).

핵심은 \(\hat\beta_1\)이 \(Y_i\)들의 일차결합이라는 것입니다. 그러면 기대값과 분산을 선형성과 독립성으로 바로 계산할 수 있습니다.

(a) \(\sum(x_i - \bar x) = 0\)이므로 \(S_{xy} = \sum(x_i - \bar x)Y_i\). 따라서 \(\hat\beta_1 = \sum c_iY_i\), \(c_i = \frac{x_i - \bar x}{S_{xx}}\). 이 계수는 \(\sum c_i = 0\), \(\sum c_ix_i = \sum c_i(x_i - \bar x) = 1\), \(\sum c_i^2 = 1/S_{xx}\)을 만족한다. 선형성으로 \(E[\hat\beta_1] = \sum c_i(\beta_0 + \beta_1x_i) = \beta_0\cdot0 + \beta_1\cdot1 = \beta_1\). 독립이므로 \(\mathrm{Var}(\hat\beta_1) = \sum c_i^2\sigma^2 = \sigma^2/S_{xx}\).

(b) \(\hat\beta_0 = \bar Y - \hat\beta_1\bar x\)이므로 \(E[\hat\beta_0] = \beta_0 + \beta_1\bar x - \beta_1\bar x = \beta_0\). 분산은 \(\mathrm{Cov}(\bar Y, \hat\beta_1) = \frac{\sigma^2}n\sum c_i = 0\)을 써서 \(\frac{\sigma^2}n + \bar x^2\frac{\sigma^2}{S_{xx}}\).

(c) 잔차 벡터는 \(n\)차원에서 2차원 열공간에 수직인 \(n - 2\)차원 공간으로의 사영이므로 \(E[SSE] = (n-2)\sigma^2\) (1.1절의 직교 회전 논법과 같음; 정규 오차면 \(SSE/\sigma^2 \sim \chi^2_{n-2}\)). ∎

\(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\)는 실험 설계에 대해 말해 줍니다: \(x\)값을 넓게 퍼뜨릴수록(\(S_{xx}\)가 클수록) 기울기를 정밀하게 추정합니다.

5.1.3예제와 상관계수

예제 5.1.3

\(x = 1, \dots, 8\), \(y = 2.8, 3.1, 4.9, 4.0, 6.2, 5.5, 7.9, 6.6\)에 회귀직선을 맞추고 \(\hat\sigma^2\), \(\hat\beta_1\)의 표준오차를 구하여라.

풀이. \(\bar x = 4.5\), \(\bar y = 5.125\), \(S_{xx} = 42\), \(S_{xy} = 27.3\). \(\hat\beta_1 = 0.65\), \(\hat\beta_0 = 5.125 - 0.65\cdot4.5 = 2.2\). 잔차 \(-0.05, -0.4, 0.75, -0.8, 0.75, -0.6, 1.15, -0.8\), \(SSE = 4.25\), \(\hat\sigma^2 = 4.25/6 \approx 0.708\), \(\hat\sigma \approx 0.842\). 표준오차 \(\hat\sigma/\sqrt{42} \approx 0.130\).

정의 5.1.4

표본상관계수: \(r = \dfrac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}\). 결정계수: \(R^2 = 1 - SSE/S_{yy}\).

단순회귀에서는 \(R^2 = r^2\)입니다. 예제에서 \(S_{yy} = 21.995\), \(r \approx 0.898\), \(R^2 \approx 0.807\): \(y\)의 변동 중 약 81%가 \(x\)와의 직선 관계로 설명됩니다. 같은 절의 탐구 카드에서 같은 모형으로 자료를 여러 번 만들어 \(\hat\beta_1\)의 흩어짐을 볼 수 있습니다.

흔한 실수(1) \(\hat\sigma^2\)를 \(SSE/n\)이나 \(SSE/(n-1)\)로 계산한다: 모수 두 개를 추정했으니 \(n - 2\). (2) 상관이 크면 인과가 있다고 여긴다. (3) \(R^2\)가 크면 모형이 옳다고 여긴다: 곡선 관계도 \(R^2\)가 클 수 있고, 잔차 그림을 함께 봐야 한다.
요약
  1. \(\hat\beta_1 = S_{xy}/S_{xx} = \sum c_iY_i\), \(c_i = (x_i - \bar x)/S_{xx}\).
  2. 불편, \(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\), \(\mathrm{Var}(\hat\beta_0) = \sigma^2(1/n + \bar x^2/S_{xx})\), \(\hat\sigma^2 = SSE/(n-2)\).
  3. \(R^2 = r^2\) = 설명된 변동의 비율.

5.1.4연습문제

기본

  1. \(x\)값을 1, 2, …, 8 대신 1, 1, 1, 1, 8, 8, 8, 8로 실험하면 \(\mathrm{Var}(\hat\beta_1)\)은 몇 배가 되는가?
    답

    \(S_{xx} = 8\cdot3.5^2 = 98\) (원래 42). 분산은 \(42/98 \approx 0.43\)배. 다만 직선성을 확인할 수 없게 된다.

응용

  1. \(\mathrm{Cov}(\bar Y, \hat\beta_1) = 0\)임을 보여라.
    답

    \(\mathrm{Cov}(\frac1n\sum Y_i, \sum c_jY_j) = \frac1n\sum_ic_i\sigma^2 = 0\) (\(\sum c_i = 0\)).

심화

  1. \(\hat\beta_1 = r\cdot\frac{s_y}{s_x}\)임을 보이고, \(x\)와 \(y\)의 역할을 바꾼 회귀의 기울기와의 곱이 \(r^2\)임을 보여라.
    답

    \(S_{xy}/S_{xx} = r\sqrt{S_{yy}/S_{xx}} = rs_y/s_x\). 거꾸로 회귀의 기울기 \(S_{xy}/S_{yy}\). 곱 \(S_{xy}^2/(S_{xx}S_{yy}) = r^2\). 두 회귀선은 \(|r| = 1\)일 때만 같다(평균으로의 회귀, 수학5 4.1절).
