추축량과 신뢰구간

본문
이 절에서 배울 것
  • 추축량(분포가 모수에 의존하지 않는 양)을 정의하고, 그것으로 신뢰구간을 유도한다.
  • 평균(분산을 알 때·모를 때), 비율, 분산의 신뢰구간을 구한다.
  • "95% 신뢰"의 올바른 해석을 안다.
먼저 알아야 할 것
  • 표본분포와 t분포 (1.1절, 1.2절), 중심극한정리 (수학5 6.3절).

3.1.1점 하나 대신 구간

점추정값 \(\bar x = 103\)은 참값과 거의 확실히 다릅니다. 그래서 "참값이 이 범위에 있다고 얼마나 확신하는가"를 함께 말하는 구간을 냅니다. 핵심 도구는 모수와 통계량을 함께 담되 분포는 모수와 무관한 양, 곧 추축량입니다.

정의 3.1.1

추축량: 표본과 모수 \(\theta\)의 함수 \(Q(X_1, \dots, X_n; \theta)\)로서 분포가 \(\theta\)에 의존하지 않는 것.

신뢰구간: 통계량 \(L, U\)로 \(P(L \le \theta \le U) = 1 - \alpha\)가 모든 \(\theta\)에서 성립하는 구간 \([L, U]\). \(1 - \alpha\)를 신뢰수준이라 한다.

정리 3.1.2 (추축량 방법)

\(Q\)가 추축량이고 \(P(a \le Q \le b) = 1 - \alpha\)이며 부등식 \(a \le Q(\mathbf X; \theta) \le b\)를 \(L(\mathbf X) \le \theta \le U(\mathbf X)\)로 풀 수 있으면 \([L, U]\)는 \(1 - \alpha\) 신뢰구간이다.

두 사건 \(\{a \le Q \le b\}\)와 \(\{L \le \theta \le U\}\)는 같은 사건(같은 부등식을 다시 쓴 것)이므로 확률이 같고, 앞의 확률은 \(Q\)의 분포가 \(\theta\)와 무관하므로 모든 \(\theta\)에서 \(1 - \alpha\)이다. ∎

3.1.2대표적인 신뢰구간

  • 평균, \(\sigma\)를 앎: \(Q = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)\). \(-z_{\alpha/2} \le Q \le z_{\alpha/2}\)를 \(\mu\)로 풀면 \(\bar X \pm z_{\alpha/2}\sigma/\sqrt n\).
  • 평균, \(\sigma\)를 모름: \(Q = \frac{\bar X - \mu}{S/\sqrt n} \sim t_{n-1}\). \(\bar X \pm t_{\alpha/2, n-1}S/\sqrt n\).
  • 비율(큰 표본): 중심극한정리로 \(\frac{\hat p - p}{\sqrt{p(1-p)/n}} \approx N(0,1)\). 분모의 \(p\)를 \(\hat p\)로 바꾸면 \(\hat p \pm z_{\alpha/2}\sqrt{\hat p(1 - \hat p)/n}\) (왈드 구간).
  • 분산: \(Q = (n-1)S^2/\sigma^2 \sim \chi^2_{n-1}\). \(\chi^2_{1-\alpha/2} \le Q \le \chi^2_{\alpha/2}\)를 풀면 \(\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2}}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}}\right]\) (위쪽 분위수가 왼쪽 끝에 감에 주의).
예제 3.1.3

(a) 정규 표본 \(n = 16\), \(\bar x = 103\), \(s = 8\)에서 \(\mu\)의 95% 신뢰구간 (b) 1000명 중 520명 찬성일 때 \(p\)의 95% 신뢰구간 (c) 정규 표본 \(n = 10\), \(s^2 = 20\)에서 \(\sigma^2\)의 95% 신뢰구간.

풀이. (a) \(t_{0.025, 15} = 2.131\), \(s/\sqrt n = 2\). \(103 \pm 4.26 = [98.74, 107.26]\). (b) 표준오차 \(\sqrt{0.52\cdot0.48/1000} \approx 0.0158\). \(0.52 \pm 0.031 = [0.489, 0.551]\). 구간이 0.5를 포함하므로 "과반"이라 단정하기 어렵습니다. (c) \(\chi^2_9\)의 2.5%, 97.5% 분위수 2.700, 19.023. \([180/19.023, 180/2.700] = [9.46, 66.66]\). 표본 10개로는 분산이 7배 가까운 범위에서밖에 정해지지 않습니다.

3.1.3"95% 신뢰"의 뜻

한 번 계산한 구간 \([98.74, 107.26]\)은 고정된 수이고 \(\mu\)도 고정된 (모르는) 수이므로, 이 구간이 \(\mu\)를 포함할 확률을 말하는 것은 의미가 없습니다(포함하거나 안 하거나). 95%는 방법의 성질입니다: 표본을 다시 뽑아 같은 방법으로 구간을 만들기를 되풀이하면, 그 구간들 중 95%가 \(\mu\)를 포함합니다. 같은 절의 탐구 카드에서 구간 100개를 만들어 확인할 수 있습니다.

흔한 실수(1) "\(\mu\)가 이 구간에 있을 확률이 95%"라고 말한다. (2) 분산 구간에서 분위수의 자리를 바꾼다: 큰 분위수가 왼쪽 끝(분모)에 간다. (3) 소표본 평균 구간에 \(z\)를 쓴다(1.2절의 탐구 카드).
요약
  1. 추축량: 모수를 담지만 분포는 모수와 무관. \(P(a \le Q \le b) = 1 - \alpha\)를 모수로 풀면 신뢰구간.
  2. \(\bar x \pm z\sigma/\sqrt n\), \(\bar x \pm ts/\sqrt n\), \(\hat p \pm z\sqrt{\hat p(1-\hat p)/n}\), \([(n-1)s^2/\chi^2_{\alpha/2}, (n-1)s^2/\chi^2_{1-\alpha/2}]\).
  3. 신뢰수준은 반복했을 때 구간이 참값을 포함하는 비율.

3.1.4연습문제

기본

  1. \(\sigma = 10\)을 아는 정규 모집단에서 \(n = 25\), \(\bar x = 70\)이다. \(\mu\)의 90% 신뢰구간은? (\(z_{0.05} = 1.645\))
    답

    \(70 \pm 1.645\cdot2 = [66.71, 73.29]\).

응용

  1. 오차 한계를 절반으로 줄이려면 표본 크기를 몇 배로 해야 하는가?
    답

    오차 한계가 \(1/\sqrt n\)에 비례하므로 4배.

심화

  1. 지수분포(\(\lambda\)) 표본에서 \(2\lambda\sum X_i \sim \chi^2_{2n}\)임을 이용해 \(\lambda\)의 신뢰구간을 만들어라.
    답

    \(\lambda\sum X_i \sim \Gamma(n, 1)\)이고 \(2\Gamma(n,1) = \Gamma(n, 1/2) = \chi^2_{2n}\)이므로 추축량. \(\left[\frac{\chi^2_{1-\alpha/2, 2n}}{2\sum x_i}, \frac{\chi^2_{\alpha/2, 2n}}{2\sum x_i}\right]\).
