추정량의 편향과 평균제곱오차

본문

정규 모집단의 분산을 추정할 때 편차제곱합을 \(n - 1\)로 나누는 \(S^2\)는 평균적으로 정확히 맞고, \(n\)으로 나누는 MLE는 평균적으로 조금 작게 나온다. 그렇다면 \(S^2\)가 늘 더 좋은 추정량일까? 같은 모수에 여러 추정량이 있을 때 무엇으로 좋고 나쁨을 가릴까?

먼저 알아야 할 것적률법과 MLE(2.1절), 기대값과 분산(수학5 3.1절), 표본분산의 분포(1.1절)를 쓴다.

2.2.1좋은 추정량의 기준

추정값 하나로는 비교할 수 없으므로 다시 뽑으면 평균적으로 얼마나 틀리는가로 본다. 과녁에 비유하면 편향은 조준점이 과녁 중심에서 벗어난 정도이고, 분산은 탄착점이 흩어진 정도이다.

정의 2.2.1

\(\mathrm{bias}(\hat\theta) = E[\hat\theta] - \theta\)를 편향이라 하고, 모든 \(\theta\)에서 0이면 불편이라 한다. \(\mathrm{MSE}(\hat\theta) = E[(\hat\theta - \theta)^2]\)을 평균제곱오차라 한다. \(n \to \infty\)일 때 \(\hat\theta_n \xrightarrow{P} \theta\)이면 일치 추정량이라 한다.

정리 2.2.2

\(\mathrm{MSE}(\hat\theta) = \mathrm{Var}(\hat\theta) + \mathrm{bias}(\hat\theta)^2\)이다.

증명.\(m = E[\hat\theta]\)라 하면 \(\hat\theta - \theta = (\hat\theta - m) + (m - \theta)\)이다. 제곱의 기대값에서 교차항 \(2(m - \theta)E[\hat\theta - m]\)은 0이므로 \(E[(\hat\theta - \theta)^2] = E[(\hat\theta - m)^2] + (m - \theta)^2\)이다. ∎

MSE가 0으로 가면 체비쇼프 부등식의 형태 \(P(|\hat\theta - \theta| \ge \varepsilon) \le \mathrm{MSE}/\varepsilon^2\)(수학5 5.1절)으로 일치성이 따라온다.

2.2.2정규 분산의 예

\(S^2 = \frac1{n-1}\sum(X_i - \bar X)^2\)는 불편이고 \(\mathrm{Var}(S^2) = \frac{2\sigma^4}{n-1}\)이다(1.1절 연습문제). 한편 MLE \(\hat\sigma^2 = \frac{n-1}nS^2\)는 \(E[\hat\sigma^2] = \frac{n-1}n\sigma^2\)이므로 편향이 \(-\sigma^2/n\)이고 분산은 \(\frac{2(n-1)\sigma^4}{n^2}\)이다. 따라서 다음을 얻는다.

\[\mathrm{MSE}(S^2) = \frac{2\sigma^4}{n-1},\qquad \mathrm{MSE}(\hat\sigma^2) = \frac{2(n-1)}{n^2}\sigma^4 + \frac{\sigma^4}{n^2} = \frac{2n-1}{n^2}\sigma^4.\]

\(n = 10\), \(\sigma^2 = 1\)이면 0.2222와 0.19이다. 즉 편향이 있는 MLE가 MSE는 더 작다. 불편성은 좋은 성질이지만 유일한 기준은 아니다. 실제로 \(n + 1\)로 나누면 MSE가 \(2/(n+1) \approx 0.1818\)로 가장 작으며, 그림 1이 세 추정량을 비교한다.

2.2.3균등분포 θ의 예

예제 2.2.3

\(U(0, \theta)\) 표본에서 \(T_1 = 2\bar X\), \(T_2 = \max X_i = M\), \(T_3 = \frac{n+1}nM\)의 MSE를 비교하여라.

풀이. \(T_1\)은 불편이고 \(\mathrm{Var} = 4\cdot\frac{\theta^2}{12n} = \frac{\theta^2}{3n}\)이다. \(M\)의 분포함수는 \((m/\theta)^n\)이므로 밀도가 \(nm^{n-1}/\theta^n\)이고, \(E[M] = \frac{n}{n+1}\theta\), \(E[M^2] = \frac n{n+2}\theta^2\)이다. 따라서 \(T_2\)는 편향이 \(-\frac{\theta}{n+1}\)이고 \(\mathrm{MSE} = \frac{2\theta^2}{(n+1)(n+2)}\)이다. \(T_3\)은 불편이고 \(\mathrm{Var} = \frac{\theta^2}{n(n+2)}\)이다.

\(n = 5\), \(\theta = 10\)이면 MSE가 차례로 6.667, 4.762, 2.857이다. 게다가 \(T_1\)은 \(1/n\)로, \(T_2, T_3\)은 \(1/n^2\)로 줄어 \(n\)이 크면 차이가 커진다. 최댓값이 \(\theta\)에 대한 정보를 거의 다 담고 있기 때문이며, 이런 통계량을 충분통계량이라 한다. 같은 절의 탐구 카드에서 모의실험으로 비교할 수 있다.

2.2.4효율

지지 집합이 \(\theta\)에 의존하지 않는 등의 정칙 조건 아래에서 불편 추정량의 분산은 \(\frac{1}{nI(\theta)}\) 이상이다. 이것을 크라메르-라오 하한이라 하며, \(I(\theta) = E[(\partial_\theta\ln f)^2]\)는 피셔 정보이다(2.3절). 이 하한에 닿는 추정량을 효율적이라 한다. 예를 들어 정규 평균의 \(\bar X\)는 \(I = 1/\sigma^2\)이고 분산이 \(\sigma^2/n\)이라 효율적이다. 한편 균등분포는 정칙 조건을 어기므로 \(1/n^2\) 속도가 가능하다.

흔한 오해불편 추정량이 늘 더 좋다고 여기기 쉽지만, \(S^2\)와 \(\hat\sigma^2\)의 비교가 반례이다. 또 \(S\)가 \(\sigma\)의 불편 추정량이라 여기는 것도 틀렸으며, 옌센 부등식으로 \(E[S] < \sigma\)이다. 한 번의 추정값이 참값에 가까우면 좋은 추정량이라 판단하는 것도 오해이다. 추정량의 좋고 나쁨은 분포로 판단한다.
마무리

처음 질문의 답은 "그렇지 않다"이다. 추정량은 평균제곱오차 \(\mathrm{MSE} = \mathrm{Var} + \mathrm{bias}^2\)로 비교하며, 불편성과 작은 분산 사이에는 거래가 있다. 정규 분산에서 \(\mathrm{MSE}(S^2) = 2\sigma^4/(n-1)\)은 편향이 있는 MLE의 \((2n-1)\sigma^4/n^2\)보다 크다. 균등분포의 \(\theta\)에서는 \(2\bar X\)의 MSE가 \(1/n\)로, 최댓값에 기초한 추정량은 \(1/n^2\)로 줄어든다. 정칙일 때 불편 추정량의 분산에는 크라메르-라오 하한이 있다.

2.2.5연습문제

기본

  1. 베르누이 표본의 \(\hat p = \bar X\)의 편향과 MSE는?
    답

    불편, MSE = 분산 = \(p(1-p)/n\).

응용

  1. \(\tilde p = (\sum X_i + 1)/(n + 2)\)의 편향과 MSE를 구하고 \(p = 0.5\), \(n = 10\)에서 \(\bar X\)와 비교하여라.
    답

    \(E = (np + 1)/(n + 2)\), 편향 \((1 - 2p)/(n+2)\). 분산 \(np(1-p)/(n+2)^2\). \(p = 0.5\), \(n = 10\): 편향 0, MSE \(2.5/144 \approx 0.0174\), \(\bar X\)는 0.025. 이 \(p\)에서는 \(\tilde p\)가 낫다(\(p\)가 0이나 1에 가까우면 반대).

심화

  1. 지수분포에서 \(\hat\lambda = 1/\bar X\)가 편향되어 있음을 보이고 불편하게 보정하여라. (\(\sum X_i \sim \Gamma(n, \lambda)\), \(E[1/\sum X_i] = \lambda/(n-1)\))
    답

    \(E[1/\bar X] = nE[1/\sum X_i] = \frac{n}{n-1}\lambda\). 불편 추정량 \(\frac{n-1}{\sum X_i}\).
