추정량의 편향과 평균제곱오차

본문
이 절에서 배울 것
  • 편향, 불편성, 평균제곱오차(MSE)를 정의하고 MSE = 분산 + 편향²를 증명한다.
  • 정규 분산의 추정량 \(S^2\)와 \(\hat\sigma^2\), 균등분포 \(\theta\)의 세 추정량의 MSE를 계산해 비교한다.
  • 일치성과 효율(크라메르-라오 하한)의 뜻을 안다.
먼저 알아야 할 것
  • 적률법과 MLE (2.1절), 기대값과 분산 (수학5 3.1절), 표본분산의 분포 (1.1절).

2.2.1좋은 추정량의 기준

같은 모수에 여러 추정량이 있을 때 어느 것이 좋을까요? 추정값 하나로는 비교할 수 없으므로 "다시 뽑으면 평균적으로 얼마나 틀리는가"로 봅니다. 과녁에 비유하면 편향은 조준점이 과녁 중심에서 벗어난 정도, 분산은 탄착점이 흩어진 정도입니다.

정의 2.2.1

편향: \(\mathrm{bias}(\hat\theta) = E[\hat\theta] - \theta\). 모든 \(\theta\)에서 0이면 불편.

평균제곱오차: \(\mathrm{MSE}(\hat\theta) = E[(\hat\theta - \theta)^2]\).

일치성: \(n \to \infty\)일 때 \(\hat\theta_n \xrightarrow{P} \theta\).

정리 2.2.2

\(\mathrm{MSE}(\hat\theta) = \mathrm{Var}(\hat\theta) + \mathrm{bias}(\hat\theta)^2\).

\(m = E[\hat\theta]\)라 하면 \(\hat\theta - \theta = (\hat\theta - m) + (m - \theta)\). 제곱의 기대값에서 교차항 \(2(m - \theta)E[\hat\theta - m] = 0\)이므로 \(E[(\hat\theta - \theta)^2] = E[(\hat\theta - m)^2] + (m - \theta)^2\). ∎

MSE가 0으로 가면 체비쇼프 부등식(수학5 5.1절의 형태 \(P(|\hat\theta - \theta| \ge \varepsilon) \le \mathrm{MSE}/\varepsilon^2\))으로 일치성이 따라옵니다.

2.2.2예: 정규 분산

\(S^2 = \frac1{n-1}\sum(X_i - \bar X)^2\)는 불편이고 \(\mathrm{Var}(S^2) = \frac{2\sigma^4}{n-1}\) (1.1절 연습문제). MLE \(\hat\sigma^2 = \frac{n-1}nS^2\)는 \(E = \frac{n-1}n\sigma^2\)으로 편향 \(-\sigma^2/n\), 분산 \(\frac{2(n-1)\sigma^4}{n^2}\). 따라서

\[\mathrm{MSE}(S^2) = \frac{2\sigma^4}{n-1},\qquad \mathrm{MSE}(\hat\sigma^2) = \frac{2(n-1)}{n^2}\sigma^4 + \frac{\sigma^4}{n^2} = \frac{2n-1}{n^2}\sigma^4.\]

\(n = 10\), \(\sigma^2 = 1\)이면 0.2222와 0.19입니다. 편향이 있는 MLE가 MSE는 더 작습니다. 불편성은 좋은 성질이지만 유일한 기준은 아닙니다. (\(n + 1\)로 나누면 MSE가 \(2/(n+1) \approx 0.1818\)로 가장 작습니다.)

2.2.3예: 균등분포의 \(\theta\)

예제 2.2.3

\(U(0, \theta)\) 표본에서 \(T_1 = 2\bar X\), \(T_2 = \max X_i = M\), \(T_3 = \frac{n+1}nM\)의 MSE를 비교하여라.

풀이. \(T_1\): 불편, \(\mathrm{Var} = 4\cdot\frac{\theta^2}{12n} = \frac{\theta^2}{3n}\). \(M\)의 분포함수는 \((m/\theta)^n\)이므로 밀도 \(nm^{n-1}/\theta^n\), \(E[M] = \frac{n}{n+1}\theta\), \(E[M^2] = \frac n{n+2}\theta^2\). \(T_2\): 편향 \(-\frac{\theta}{n+1}\), \(\mathrm{MSE} = \frac{2\theta^2}{(n+1)(n+2)}\). \(T_3\): 불편, \(\mathrm{Var} = \frac{\theta^2}{n(n+2)}\).

\(n = 5\), \(\theta = 10\)이면 MSE가 6.667, 4.762, 2.857입니다. \(T_1\)은 \(1/n\)로, \(T_2, T_3\)은 \(1/n^2\)로 줄어 \(n\)이 크면 차이가 커집니다. 최댓값이 \(\theta\)에 대한 정보를 거의 다 담고 있기 때문입니다(충분통계량). 같은 절의 탐구 카드에서 모의실험으로 비교할 수 있습니다.

2.2.4효율

정칙 조건(지지 집합이 \(\theta\)에 의존하지 않는 등) 아래에서 불편 추정량의 분산은 \(\frac{1}{nI(\theta)}\) 이상입니다(크라메르-라오 하한, \(I(\theta) = E[(\partial_\theta\ln f)^2]\)는 피셔 정보). 이 하한에 닿는 추정량을 효율적이라 합니다. 예: 정규 평균의 \(\bar X\) (\(I = 1/\sigma^2\), 분산 \(\sigma^2/n\)). 균등분포는 정칙 조건을 어겨 \(1/n^2\) 속도가 가능합니다. MLE는 표본이 크면 근사적으로 불편이고 이 하한에 닿습니다.

흔한 실수(1) 불편 추정량이 항상 더 좋다고 여긴다(\(S^2\) vs \(\hat\sigma^2\)). (2) \(S\)가 \(\sigma\)의 불편 추정량이라 여긴다: \(E[S] < \sigma\) (옌센 부등식). (3) 한 번의 추정값이 참값에 가까우면 좋은 추정량이라 판단한다: 추정량의 좋고 나쁨은 분포로 판단한다.
요약
  1. MSE = 분산 + 편향². 불편과 작은 분산 사이에 거래가 있다.
  2. 정규 분산: \(\mathrm{MSE}(S^2) = 2\sigma^4/(n-1)\) > \(\mathrm{MSE}(\hat\sigma^2) = (2n-1)\sigma^4/n^2\).
  3. 균등 \(\theta\): \(2\bar X\)는 \(1/n\), 최댓값 기반은 \(1/n^2\). 크라메르-라오는 정칙일 때의 하한.

2.2.5연습문제

기본

  1. 베르누이 표본의 \(\hat p = \bar X\)의 편향과 MSE는?
    답

    불편, MSE = 분산 = \(p(1-p)/n\).

응용

  1. \(\tilde p = (\sum X_i + 1)/(n + 2)\)의 편향과 MSE를 구하고 \(p = 0.5\), \(n = 10\)에서 \(\bar X\)와 비교하여라.
    답

    \(E = (np + 1)/(n + 2)\), 편향 \((1 - 2p)/(n+2)\). 분산 \(np(1-p)/(n+2)^2\). \(p = 0.5\), \(n = 10\): 편향 0, MSE \(2.5/144 \approx 0.0174\), \(\bar X\)는 0.025. 이 \(p\)에서는 \(\tilde p\)가 낫다(\(p\)가 0이나 1에 가까우면 반대).

심화

  1. 지수분포에서 \(\hat\lambda = 1/\bar X\)가 편향되어 있음을 보이고 불편하게 보정하여라. (\(\sum X_i \sim \Gamma(n, \lambda)\), \(E[1/\sum X_i] = \lambda/(n-1)\))
    답

    \(E[1/\bar X] = nE[1/\sum X_i] = \frac{n}{n-1}\lambda\). 불편 추정량 \(\frac{n-1}{\sum X_i}\).
