파이썬으로 자료 요약하기

본문

앞 대단원에서 손으로 한 요약 통계와 그래프를 수백 개의 자료로 하려면 도구가 필요하다. 이 과목의 첫 주에 배우는 파이썬으로 자료를 읽고, 요약하고, 그래프를 그리는 최소한의 순서는 무엇인가?

먼저 알아야 할 것자료 요약(8.1절)과 회귀선(8.3절)을 쓴다. 통계 소프트웨어 출력 읽기는 7.1절에 있다.

7.3.1읽기와 확인하기

표 자료는 Pandas로 읽는다. 그런데 읽은 다음에는 바로 계산하지 말고 처음 몇 줄과 열마다의 자료형, 빠진 값의 개수를 본다. 그러면 숫자여야 할 열이 문자로 읽혔거나 빈칸이 있는 것을 계산 전에 찾을 수 있다.

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")     # 열 혈액형, 키, 공부시간, 점수
print(df.head())
df.info()                            # 열마다 자료형과 빠지지 않은 값의 수

7.3.2요약하기

이제 양적 변수는 describe로 다섯 수치와 평균, 표준편차를 한 번에 본다. 범주형 변수는 value_counts로 도수를 세고, 두 범주형 변수는 crosstab으로 분할표를 만든다. 상관계수는 corr이다.

print(df["키"].describe())
print(df["혈액형"].value_counts(normalize=True))   # 상대도수
print(df[["공부시간", "점수"]].corr())

7.3.3그리기

다음으로 그래프는 자료의 종류에 맞게 고른다. 양적 변수 하나는 히스토그램이나 상자그림, 범주형 변수는 막대그래프, 두 양적 변수는 산점도이다. 한편 회귀선은 numpy.polyfit으로 기울기와 절편을 구해 산점도 위에 겹쳐 그린다.

import numpy as np
b1, b0 = np.polyfit(df["공부시간"], df["점수"], 1)
plt.scatter(df["공부시간"], df["점수"])
xs = np.linspace(df["공부시간"].min(), df["공부시간"].max(), 50)
plt.plot(xs, b0 + b1 * xs)
plt.xlabel("공부 시간"); plt.ylabel("점수")
plt.show()
예제 7.3.1

위 코드에서 np.polyfit이 준 기울기가 \(r s_y/s_x\)와 같은지 확인하는 코드를 써라.

r = df["공부시간"].corr(df["점수"])
print(b1, r * df["점수"].std() / df["공부시간"].std())   # 두 값이 같다

풀이. 두 값은 반올림 오차 안에서 같다. 이렇게 공식으로 구한 값과 도구가 준 값을 맞춰 보면 도구를 바르게 썼는지와 공식을 바르게 이해했는지를 함께 확인할 수 있다. 표준편차를 \(n - 1\)로 나누든 \(n\)으로 나누든 비율에서는 약분되어 결과가 같다는 것도 알 수 있다.

마무리

파이썬 자료 분석은 read_csv로 읽고 head와 info로 확인한 뒤, describe, value_counts, corr로 요약하고 자료 종류에 맞는 그래프를 그리는 순서로 한다. 도구가 준 숫자는 손으로 한 공식과 맞춰 확인한다.
