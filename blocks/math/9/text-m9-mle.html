적률법과 최대가능도법

본문
이 절에서 배울 것
  • 표본 적률을 모적률에 맞추는 적률법으로 추정량을 구한다.
  • 가능도함수를 최대화하는 최대가능도 추정량(MLE)을 구한다.
  • 균등분포 \(U(0, \theta)\)처럼 미분으로 풀리지 않는 경우와 MLE의 불변성을 안다.
먼저 알아야 할 것
  • 대표 분포와 적률 (수학5 3.2절), 로그 미분과 극값.

2.1.1점추정

모집단 분포의 꼴은 알지만 모수 \(\theta\)를 모를 때, 표본으로 \(\theta\)의 값 하나를 내놓는 것이 점추정입니다. 추정 규칙(통계량) \(\hat\theta = T(X_1, \dots, X_n)\)을 추정량, 실제 자료를 넣은 값을 추정값이라 합니다. 규칙을 만드는 대표적인 방법이 둘 있습니다.

2.1.2적률법

정의 2.1.1

적률법: 모적률 \(E[X^j] = \mu_j(\theta)\)를 표본 적률 \(\frac1n\sum X_i^j\)와 같게 놓은 방정식(모수 개수만큼)의 해를 추정량으로 한다.

대수의 법칙으로 표본 적률은 모적률에 가까우므로 자연스러운 방법입니다. 예: 지수분포 \(E[X] = 1/\lambda\)이면 \(\bar X = 1/\hat\lambda\), \(\hat\lambda = 1/\bar X\). 균등분포 \(U(0, \theta)\)이면 \(E[X] = \theta/2\)이므로 \(\hat\theta = 2\bar X\).

2.1.3최대가능도법

관측한 자료가 "가장 그럴듯하게" 나오게 하는 모수를 고르는 방법입니다. 자료를 고정하고 결합밀도를 모수의 함수로 본 것이 가능도입니다.

정의 2.1.2

가능도함수: \(L(\theta) = \prod_{i=1}^nf(x_i; \theta)\). 로그를 취한 \(\ell(\theta) = \sum\ln f(x_i; \theta)\)를 로그가능도라 한다.

최대가능도 추정량: \(L(\theta)\)를 최대로 하는 \(\hat\theta\).

곱은 미분하기 어려우므로 로그를 취해 합으로 바꿉니다. 로그는 증가함수라 최대점이 같습니다.

예제 2.1.3

(a) 베르누이(\(p\)) 표본 (b) 지수(\(\lambda\)) 표본 (c) 정규(\(\mu, \sigma^2\)) 표본의 MLE를 구하여라.

풀이. (a) \(\ell(p) = k\ln p + (n - k)\ln(1 - p)\) (\(k = \sum x_i\)). \(\ell'(p) = k/p - (n-k)/(1-p) = 0\)에서 \(\hat p = k/n = \bar x\). 동전 20번에 앞면 7번이면 \(\hat p = 0.35\).

(b) \(\ell(\lambda) = n\ln\lambda - \lambda\sum x_i\), \(\ell' = n/\lambda - \sum x_i = 0\)에서 \(\hat\lambda = 1/\bar x\) (적률법과 같다). 대기 시간 0.8, 2.1, 0.4, 1.5, 0.7, 3.0, 1.1, 0.4이면 \(\bar x = 1.25\), \(\hat\lambda = 0.8\).

(c) \(\ell = -\frac n2\ln(2\pi\sigma^2) - \frac1{2\sigma^2}\sum(x_i - \mu)^2\). \(\mu\)로 미분하면 \(\hat\mu = \bar x\), \(\sigma^2\)로 미분하면 \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\). 분모가 \(n - 1\)이 아니라 \(n\)임에 주의합니다(2.2절).

2.1.4미분이 통하지 않는 경우

예제 2.1.4

\(U(0, \theta)\) 표본 1.2, 3.5, 0.7, 2.9, 4.1로 \(\theta\)를 적률법과 MLE로 추정하여라.

풀이. 적률법: \(\bar x = 2.48\), \(\hat\theta = 4.96\). MLE: \(L(\theta) = \theta^{-n}\) (모든 \(x_i \le \theta\)일 때), 아니면 0. \(\theta\)가 가장 큰 관측값보다 작으면 가능도가 0이고, 그 이상에서는 \(\theta^{-n}\)이 감소하므로 최대점은 \(\hat\theta = \max x_i = 4.1\)입니다. 미분이 0인 점이 아니라 경계에서 최대가 됩니다. MLE는 항상 참값보다 작거나 같다는 약점이 있어 2.2절에서 보정합니다.

정리 2.1.5 (불변성)

\(\hat\theta\)가 \(\theta\)의 MLE이면 \(g(\hat\theta)\)는 \(g(\theta)\)의 MLE이다.

예: 정규 표본에서 \(\sigma\)의 MLE는 \(\sqrt{\hat\sigma^2}\), 지수분포의 평균 \(1/\lambda\)의 MLE는 \(\bar x\). 같은 절의 탐구 카드에서 가능도 곡선의 모양과 최댓점을 볼 수 있습니다.

흔한 실수(1) 가능도를 \(\theta\)의 확률분포로 여긴다: \(L(\theta)\)를 \(\theta\)로 적분해도 1이 아니다. (2) 지지 집합이 \(\theta\)에 의존하는데(균등분포) 미분만 한다. (3) 로그가능도의 임계점이 최대인지 확인하지 않는다(2계 도함수나 경계 비교).
요약
  1. 적률법: 표본 적률 = 모적률. 간단하지만 효율이 낮을 수 있다.
  2. MLE: \(\ell(\theta) = \sum\ln f(x_i;\theta)\) 최대화. 베르누이 \(\bar x\), 지수 \(1/\bar x\), 정규 \((\bar x, \frac1n\sum(x_i - \bar x)^2)\).
  3. 지지 집합이 모수에 의존하면 경계 최대(균등: \(\max x_i\)). MLE는 함수 변환에 불변.

2.1.5연습문제

기본

  1. 포아송(\(\lambda\)) 표본의 MLE를 구하여라.
    답

    \(\ell = \sum x_i\ln\lambda - n\lambda - \sum\ln x_i!\). \(\hat\lambda = \bar x\).

응용

  1. 밀도 \(f(x; \theta) = \theta x^{\theta - 1}\) (\(0 < x < 1\))의 적률 추정량과 MLE를 구하여라.
    답

    \(E[X] = \theta/(\theta + 1)\)이므로 적률 \(\hat\theta = \bar x/(1 - \bar x)\). \(\ell = n\ln\theta + (\theta - 1)\sum\ln x_i\), MLE \(\hat\theta = -n/\sum\ln x_i\).

심화

  1. 기하분포(첫 성공까지 시행 수, 성공 확률 \(p\)) 표본의 MLE를 구하고 적률 추정량과 비교하여라.
    답

    \(\ell = n\ln p + (\sum x_i - n)\ln(1 - p)\), \(\hat p = n/\sum x_i = 1/\bar x\). \(E[X] = 1/p\)이므로 적률 추정량도 \(1/\bar x\)로 같다.
