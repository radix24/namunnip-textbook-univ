적률법과 최대가능도법

본문

동전을 20번 던져 앞면이 7번 나왔다. 이 동전의 앞면 확률 \(p\)는 얼마라고 추측해야 할까? 0.35라는 답은 당연해 보이지만, 그 답을 내는 일반적인 규칙은 무엇일까? 그리고 그 규칙은 미분으로 풀리지 않는 모형에서도 쓸 수 있을까?

먼저 알아야 할 것대표 분포와 적률(수학5 3.2절), 로그 미분과 극값을 쓴다.

2.1.1점추정

모집단 분포의 꼴은 알지만 모수 \(\theta\)를 모를 때, 표본으로 \(\theta\)의 값 하나를 내놓는 것이 점추정이다. 추정 규칙인 통계량 \(\hat\theta = T(X_1, \dots, X_n)\)을 추정량이라 하고, 실제 자료를 넣은 값을 추정값이라 한다. 규칙을 만드는 대표적인 방법이 둘 있다.

2.1.2적률법

정의 2.1.1

모적률 \(E[X^j] = \mu_j(\theta)\)를 표본 적률 \(\frac1n\sum X_i^j\)와 같게 놓은, 모수 개수만큼의 방정식의 해를 추정량으로 하는 방법을 적률법이라 한다.

대수의 법칙으로 표본 적률은 모적률에 가까우므로 자연스러운 방법이다. 예를 들어 지수분포는 \(E[X] = 1/\lambda\)이므로 \(\bar X = 1/\hat\lambda\), 곧 \(\hat\lambda = 1/\bar X\)이다. 균등분포 \(U(0, \theta)\)는 \(E[X] = \theta/2\)이므로 \(\hat\theta = 2\bar X\)이다.

2.1.3최대가능도법

관측한 자료가 가장 그럴듯하게 나오게 하는 모수를 고르는 방법이다. 자료를 고정하고 결합밀도를 모수의 함수로 본 것이 가능도이다.

정의 2.1.2

\(L(\theta) = \prod_{i=1}^nf(x_i; \theta)\)를 가능도함수라 하고, 로그를 취한 \(\ell(\theta) = \sum\ln f(x_i; \theta)\)를 로그가능도라 한다. \(L(\theta)\)를 최대로 하는 \(\hat\theta\)를 최대가능도 추정량(MLE)이라 한다.

곱은 미분하기 어려우므로 로그를 취해 합으로 바꾼다. 로그는 증가함수이므로 최대점이 같다.

예제 2.1.3

(a) 베르누이(\(p\)) 표본, (b) 지수(\(\lambda\)) 표본, (c) 정규(\(\mu, \sigma^2\)) 표본의 MLE를 구하여라.

풀이. (a) \(k = \sum x_i\)로 두면 \(\ell(p) = k\ln p + (n - k)\ln(1 - p)\)이고, \(\ell'(p) = k/p - (n-k)/(1-p) = 0\)에서 \(\hat p = k/n = \bar x\)이다. 동전 20번에 앞면 7번이면 \(\hat p = 0.35\)이며, 그림 1의 왼쪽이 이 로그가능도이다. (b) \(\ell(\lambda) = n\ln\lambda - \lambda\sum x_i\)이고 \(\ell' = n/\lambda - \sum x_i = 0\)에서 \(\hat\lambda = 1/\bar x\)로 적률법과 같다. 가령 대기 시간 0.8, 2.1, 0.4, 1.5, 0.7, 3.0, 1.1, 0.4이면 \(\bar x = 1.25\), \(\hat\lambda = 0.8\)이다. (c) \(\ell = -\frac n2\ln(2\pi\sigma^2) - \frac1{2\sigma^2}\sum(x_i - \mu)^2\)을 \(\mu\)로 미분하면 \(\hat\mu = \bar x\)이고, \(\sigma^2\)로 미분하면 \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\)이다. 분모가 \(n - 1\)이 아니라 \(n\)인 것에 주의한다(2.2절).

2.1.4미분이 통하지 않는 경우

예제 2.1.4

\(U(0, \theta)\) 표본 1.2, 3.5, 0.7, 2.9, 4.1로 \(\theta\)를 적률법과 MLE로 추정하여라.

풀이. 적률법으로는 \(\bar x = 2.48\)이므로 \(\hat\theta = 4.96\)이다. MLE를 위해 가능도를 보면, 모든 \(x_i \le \theta\)일 때 \(L(\theta) = \theta^{-n}\)이고 그렇지 않으면 0이다. 즉 \(\theta\)가 가장 큰 관측값보다 작으면 가능도가 0이고, 그 이상에서는 \(\theta^{-n}\)이 감소하므로 최대점은 \(\hat\theta = \max x_i = 4.1\)이다. 그림 1의 오른쪽처럼 미분이 0인 점이 아니라 경계에서 최대가 된다. 다만 이 MLE는 늘 참값 이하라는 약점이 있어 2.2절에서 보정한다.

정리 2.1.5 (불변성)

\(\hat\theta\)가 \(\theta\)의 MLE이면 \(g(\hat\theta)\)는 \(g(\theta)\)의 MLE이다.

증명.\(g\)가 일대일인 경우를 보인다. \(\eta = g(\theta)\)로 매개변수를 바꾸면 가능도는 \(L^*(\eta) = L(g^{-1}(\eta))\)이고, 이것은 \(g^{-1}(\eta) = \hat\theta\), 곧 \(\eta = g(\hat\theta)\)에서 최대이다. 일대일이 아니면 \(L^*(\eta) = \sup_{g(\theta) = \eta}L(\theta)\)로 정의해 같은 결론을 얻는다. ∎

예를 들어 정규 표본에서 \(\sigma\)의 MLE는 \(\sqrt{\hat\sigma^2}\)이고, 지수분포의 평균 \(1/\lambda\)의 MLE는 \(\bar x\)이다. 같은 절의 탐구 카드에서 가능도 곡선의 모양과 최댓점을 볼 수 있다.

흔한 오해가능도를 \(\theta\)의 확률분포로 여기기 쉽지만, \(L(\theta)\)를 \(\theta\)로 적분해도 1이 아니다. 또 균등분포처럼 지지 집합이 \(\theta\)에 의존하는데 미분만 하는 실수가 있다. 로그가능도의 임계점이 최대인지 확인하지 않는 것도 위험하며, 2계 도함수나 경계 비교로 확인해야 한다.
마무리

처음 질문에 답하면, 0.35는 최대가능도법, 곧 로그가능도 \(\ell(\theta) = \sum\ln f(x_i;\theta)\)를 최대로 하는 규칙이 주는 답이다. 이 규칙은 베르누이에서 \(\bar x\), 지수분포에서 \(1/\bar x\), 정규분포에서 \((\bar x, \frac1n\sum(x_i - \bar x)^2)\)을 준다. 지지 집합이 모수에 의존하는 균등분포처럼 미분이 통하지 않으면 경계에서 최대가 되어 \(\max x_i\)가 MLE이다. 또 다른 방법인 적률법은 표본 적률을 모적률과 같게 놓으며, MLE는 함수 변환에 불변이다.

2.1.5연습문제

기본

  1. 포아송(\(\lambda\)) 표본의 MLE를 구하여라.
    답

    \(\ell = \sum x_i\ln\lambda - n\lambda - \sum\ln x_i!\). \(\hat\lambda = \bar x\).

응용

  1. 밀도 \(f(x; \theta) = \theta x^{\theta - 1}\) (\(0 < x < 1\))의 적률 추정량과 MLE를 구하여라.
    답

    \(E[X] = \theta/(\theta + 1)\)이므로 적률 \(\hat\theta = \bar x/(1 - \bar x)\). \(\ell = n\ln\theta + (\theta - 1)\sum\ln x_i\), MLE \(\hat\theta = -n/\sum\ln x_i\).

심화

  1. 기하분포(첫 성공까지 시행 수, 성공 확률 \(p\)) 표본의 MLE를 구하고 적률 추정량과 비교하여라.
    답

    \(\ell = n\ln p + (\sum x_i - n)\ln(1 - p)\), \(\hat p = n/\sum x_i = 1/\bar x\). \(E[X] = 1/p\)이므로 적률 추정량도 \(1/\bar x\)로 같다.
