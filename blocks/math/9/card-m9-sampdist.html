표본을 3000번 다시 뽑아 보면

탐구 · 표본평균과 표본분산의 분포

질문

같은 모집단에서 표본을 다시 뽑을 때마다 \(\bar x\)와 \(s^2\)는 달라집니다. 3000번 다시 뽑아 히스토그램을 그리면 이론 분포 \(N(\mu, \sigma^2/n)\), \(\chi^2_{n-1}\)과 맞을까요? 표본 크기는 무엇을 바꿀까요?

복원

정규 표본에서 \(\bar X \sim N(\mu, \sigma^2/n)\), \((n-1)S^2/\sigma^2 \sim \chi^2_{n-1}\) (1.1절 정리 1.1.2).

해 보기

  1. 표본평균, \(n = 10\): 히스토그램이 \(N(50, 1.6)\)과 맞고, \(P(\bar X > 52)\)의 모의실험 값이 이론 0.0569에 가깝습니다.
  2. \(n\)을 40으로 늘리면 폭이 절반으로 줄고(\(1/\sqrt n\)) \(P(\bar X > 52)\)가 거의 0이 됩니다.
  3. \((n-1)S^2/\sigma^2\)로 바꾸세요. \(n = 10\)에서 오른쪽으로 기운 \(\chi^2_9\) 모양이고 \(P(S^2 > 27.5)\)는 이론 0.0788에 가깝습니다.
  4. \(n = 2\)이면 \(\chi^2_1\)이라 0 근처에 몰립니다. \(n\)이 커지면 대칭에 가까워집니다.

설명

  1. 표본분포는 "다시 뽑으면"의 분포실제로는 표본을 한 번만 뽑지만, 추론의 정확도는 "다시 뽑았다면 얼마나 달라졌을까"로 판단합니다. 히스토그램이 그 가상의 반복입니다.
  2. 분산은 평균보다 불안정하다\(S^2\)의 상대 표준편차는 \(\sqrt{2/(n-1)}\)이라 \(n = 10\)이면 약 47%입니다. 표본분산은 표본평균보다 훨씬 큰 표본이 있어야 정확해집니다.

판단

"표본분산이 모분산보다 크게 나왔으니 이 표본은 잘못 뽑혔다"는 근거가 부족합니다. \(n = 10\)이면 \(S^2\)가 모분산의 1.7배를 넘을 확률이 약 8%로, 정상적인 표본에서도 흔히 일어납니다.
