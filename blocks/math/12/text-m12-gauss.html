가우스 정수

본문
이 절에서 배울 것
  • 가우스 정수 \(\mathbb Z[i]\)와 노름 \(N(a + bi) = a^2 + b^2\)의 성질을 안다.
  • 가장 가까운 격자점으로 몫을 잡아 \(\mathbb Z[i]\)가 유클리드정역임을 증명한다.
  • 유클리드 호제법으로 최대공약수를 구하고, 페르마의 두 제곱수 정리와 연결한다.
먼저 알아야 할 것
  • 유클리드정역 (7.1절), 복소수의 곱과 절댓값(고등학교 수학 또는 수학20 1단원).

7.2.1복소평면의 격자

가우스 정수 \(\mathbb Z[i] = \{a + bi : a, b \in \mathbb Z\}\)는 복소평면의 정수 격자점입니다. 덧셈·곱셈에 닫혀 있고 \(\mathbb C\)의 부분환이라 정역입니다.

정의 7.2.1 (노름)

\(N(a + bi) = a^2 + b^2 = |a + bi|^2\). \(N(\alpha\beta) = N(\alpha)N(\beta)\) (\(|zw| = |z||w|\)).

노름이 곱을 보존하므로 약수 문제를 정수 문제로 바꿀 수 있습니다. 예를 들어 \(\alpha\)가 가역원이면 \(N(\alpha)N(\alpha^{-1}) = 1\)이라 \(N(\alpha) = 1\), 곧 가역원은 \(\pm1, \pm i\) 넷뿐입니다.

7.2.2나눗셈 정리

정리 7.2.2

\(\alpha, \beta \in \mathbb Z[i]\), \(\beta \ne 0\)이면 \(\alpha = q\beta + r\), \(N(r) \le \frac12N(\beta) < N(\beta)\)인 \(q, r \in \mathbb Z[i]\)가 있다. 따라서 \(\mathbb Z[i]\)는 유클리드정역이다.

생각. 정수에서 몫은 \(\frac ab\)에 가장 가까운 정수입니다. 복소수에서도 \(\frac\alpha\beta\)를 계산해 가장 가까운 격자점을 몫으로 잡습니다. 단위 정사각형 안의 점에서 가장 가까운 꼭짓점까지는 많아야 대각선의 절반 \(\frac{\sqrt2}{2}\)입니다.

증명.\(\frac\alpha\beta = x + yi\) (\(x, y \in \mathbb Q\))라 하고, \(x, y\)에 가장 가까운 정수 \(m, n\)을 잡아 \(q = m + ni\)로 둔다. \(|x - m| \le \frac12\), \(|y - n| \le \frac12\)이므로 \(\left|\frac\alpha\beta - q\right|^2 \le \frac14 + \frac14 = \frac12\). \(r = \alpha - q\beta\)는 \(\mathbb Z[i]\)의 원소이고 \(N(r) = |\beta|^2\left|\frac\alpha\beta - q\right|^2 \le \frac12N(\beta)\). ∎

예제 7.2.3

\(\alpha = 11 + 3i\)를 \(\beta = 1 + 2i\)로 나누고, 유클리드 호제법으로 \(\gcd(11 + 3i, 1 + 8i)\)를 구하여라.

풀이. \(\frac{11 + 3i}{1 + 2i} = \frac{(11 + 3i)(1 - 2i)}{5} = \frac{17 - 19i}{5} = 3.4 - 3.8i\). 가장 가까운 격자점 \(q = 3 - 4i\), \(r = 11 + 3i - (3 - 4i)(1 + 2i) = 11 + 3i - (11 + 2i) = i\). \(N(r) = 1 < N(\beta) = 5\).

호제법: \(\frac{1 + 8i}{11 + 3i} = \frac{(1 + 8i)(11 - 3i)}{130} = \frac{35 + 85i}{130} \approx 0.27 + 0.65i\), 몫 \(i\), 나머지 \(1 + 8i - i(11 + 3i) = 4 - 3i\) (노름 25). \(\frac{11 + 3i}{4 - 3i} = \frac{(11 + 3i)(4 + 3i)}{25} = \frac{35 + 45i}{25} = 1.4 + 1.8i\), 몫 \(1 + 2i\), 나머지 \(11 + 3i - (1 + 2i)(4 - 3i) = 11 + 3i - (10 + 5i) = 1 - 2i\) (노름 5). \(\frac{4 - 3i}{1 - 2i} = \frac{(4 - 3i)(1 + 2i)}{5} = \frac{10 + 5i}{5} = 2 + i\), 나머지 0. 따라서 \(\gcd = 1 - 2i\) (가역원 배수 차이를 무시). 검산: \(N(11 + 3i) = 130 = 5\cdot26\), \(N(1 + 8i) = 65 = 5\cdot13\), 공통 노름 5와 맞습니다.

7.2.3두 제곱수의 합

\(\mathbb Z[i]\)가 PID라 기약원 = 소원이 되면 정수론의 고전 정리가 짧게 나옵니다.

정리 7.2.4 (페르마의 두 제곱수 정리)

홀수 소수 \(p\)가 \(p = a^2 + b^2\)으로 쓰인다 \(\iff p \equiv 1 \pmod 4\).

증명의 뼈대.(⇒) 제곱수는 \(\bmod 4\)로 0 또는 1이라 \(a^2 + b^2 \not\equiv 3\). (⇐) \(U(p)\)는 위수 \(p - 1\)인 순환군이고 \(4 \mid p - 1\)이라 \(x^2 \equiv -1\)인 \(x\)가 있다. \(p \mid x^2 + 1 = (x + i)(x - i)\)인데 \(p\)는 \(x \pm i\)를 나누지 않으므로(\(\frac xp \pm \frac ip \notin \mathbb Z[i]\)) 소원이 아니고, PID라 기약원도 아니다. \(p = \alpha\beta\), \(N(\alpha), N(\beta) > 1\)이면 \(p^2 = N(\alpha)N(\beta)\)에서 \(N(\alpha) = p\), 곧 \(p = a^2 + b^2\). ∎

예: \(13 \equiv 1\)이라 \(13 = 4 + 9\), \(29 = 4 + 25\). 반면 \(7, 11, 19\)는 두 제곱수의 합이 아닙니다. 같은 절의 탐구 카드에서 나눗셈의 기하를 볼 수 있습니다.

흔한 실수(1) 몫을 실수부·허수부를 내림해서 잡는다: 그러면 \(\left|\frac\alpha\beta - q\right|^2\)이 최대 \(1 + 1 = 2\)까지 커져 \(N(r) < N(\beta)\)가 보장되지 않는다. 반올림(가장 가까운 점)이어야 한다. (2) \(\mathbb Z\)의 소수는 \(\mathbb Z[i]\)에서도 소원이라 생각한다: \(5 = (1 + 2i)(1 - 2i)\), \(2 = -i(1 + i)^2\)이다. \(p \equiv 3 \pmod 4\)인 소수만 그대로 소원이다.
요약
  1. \(N(a+bi) = a^2 + b^2\)는 곱셈적. 가역원은 \(\pm1, \pm i\).
  2. 가장 가까운 격자점을 몫으로 잡으면 \(N(r) \le \frac12N(\beta)\): 유클리드정역.
  3. PID 성질로 \(p \equiv 1 \pmod 4\)인 소수는 두 제곱수의 합.

7.2.4연습문제

기본

  1. \(7 + i\)를 \(2 - i\)로 나눈 몫과 나머지를 구하여라.
    답

    \(\frac{(7+i)(2+i)}{5} = \frac{13 + 9i}{5} = 2.6 + 1.8i\), 몫 \(3 + 2i\), 나머지 \(7 + i - (3+2i)(2-i) = 7 + i - (8 + i) = -1\).

응용

  1. \(65\)를 두 제곱수의 합으로 두 가지 방법으로 쓰고, \(\mathbb Z[i]\)의 인수분해로 설명하여라.
    답

    \(65 = 1 + 64 = 16 + 49\). \(5 = (2+i)(2-i)\), \(13 = (3+2i)(3-2i)\)이고 \((2+i)(3+2i) = 4 + 7i\), \((2+i)(3-2i) = 8 - i\).

심화

  1. \(\mathbb Z[\sqrt{-2}]\)도 유클리드정역임을 같은 방법으로 보여라.
    답

    격자 직사각형 \(1\times\sqrt2\) 안에서 가장 가까운 꼭짓점까지 거리 제곱 \(\le \frac14 + \frac24 = \frac34 < 1\).
