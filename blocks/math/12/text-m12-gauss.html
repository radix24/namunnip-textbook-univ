가우스 정수

본문

복소평면의 격자점 \(a + bi\)도 정수처럼 나눗셈을 할 수 있을까? \(11 + 3i\)를 \(1 + 2i\)로 나누면 몫과 나머지는 무엇일까? 그리고 이 나눗셈이 "\(4k + 1\) 꼴 소수는 두 제곱수의 합"이라는 정수론의 정리를 어떻게 증명해 줄까?

먼저 알아야 할 것유클리드정역(7.1절)과 복소수의 곱과 절댓값(고등학교 수학 또는 수학20 1단원)을 쓴다.

7.2.1복소평면의 격자

가우스 정수 \(\mathbb Z[i] = \{a + bi : a, b \in \mathbb Z\}\)는 복소평면의 정수 격자점이다. 덧셈과 곱셈에 닫혀 있고 \(\mathbb C\)의 부분환이므로 정역이다.

정의 7.2.1 (노름)

\(N(a + bi) = a^2 + b^2 = |a + bi|^2\)을 노름이라 한다. \(|zw| = |z||w|\)이므로 \(N(\alpha\beta) = N(\alpha)N(\beta)\)이다.

노름이 곱을 보존하므로 약수 문제를 정수 문제로 바꿀 수 있다. 예를 들어 \(\alpha\)가 가역원이면 \(N(\alpha)N(\alpha^{-1}) = 1\)이라 \(N(\alpha) = 1\)이고, 따라서 가역원은 \(\pm1, \pm i\) 넷뿐이다.

7.2.2나눗셈 정리

정리 7.2.2

\(\alpha, \beta \in \mathbb Z[i]\), \(\beta \ne 0\)이면 \(\alpha = q\beta + r\), \(N(r) \le \frac12N(\beta) < N(\beta)\)인 \(q, r \in \mathbb Z[i]\)가 있다. 따라서 \(\mathbb Z[i]\)는 유클리드정역이다.

생각은 이렇다. 정수에서 몫은 \(\frac ab\)에 가까운 정수이다. 복소수에서도 \(\frac\alpha\beta\)를 계산해 가장 가까운 격자점을 몫으로 잡는다. 단위 정사각형 안의 점에서 가장 가까운 꼭짓점까지는 많아야 대각선의 절반 \(\frac{\sqrt2}{2}\)이기 때문이다.

증명.\(\frac\alpha\beta = x + yi\) (\(x, y \in \mathbb Q\))라 하고, \(x, y\)에 가장 가까운 정수 \(m, n\)을 잡아 \(q = m + ni\)로 둔다. \(|x - m| \le \frac12\), \(|y - n| \le \frac12\)이므로 \(\left|\frac\alpha\beta - q\right|^2 \le \frac12\)이다. \(r = \alpha - q\beta\)는 \(\mathbb Z[i]\)의 원소이고 \(N(r) = |\beta|^2\left|\frac\alpha\beta - q\right|^2 \le \frac12N(\beta)\)이다. ∎

예제 7.2.3

\(\alpha = 11 + 3i\)를 \(\beta = 1 + 2i\)로 나누고, 유클리드 호제법으로 \(\gcd(11 + 3i, 1 + 8i)\)를 구하여라.

풀이. \(\frac{11 + 3i}{1 + 2i} = \frac{(11 + 3i)(1 - 2i)}{5} = 3.4 - 3.8i\)이므로 가장 가까운 격자점은 \(q = 3 - 4i\)이고, \(r = 11 + 3i - (11 + 2i) = i\)이다. \(N(r) = 1 < N(\beta) = 5\)이며, 그림 1이 이 나눗셈이다.

이제 호제법을 쓴다. \(\frac{1 + 8i}{11 + 3i} \approx 0.27 + 0.65i\)이므로 몫은 \(i\)이고 나머지는 \(1 + 8i - i(11 + 3i) = 4 - 3i\)이다. 다음으로 \(\frac{11 + 3i}{4 - 3i} = 1.4 + 1.8i\)이므로 몫은 \(1 + 2i\)이고 나머지는 \(11 + 3i - (10 + 5i) = 1 - 2i\)이다. 끝으로 \(\frac{4 - 3i}{1 - 2i} = 2 + i\)라 나머지가 0이다. 따라서 가역원 배수의 차이를 무시하면 \(\gcd = 1 - 2i\)이다. 검산하면 \(N(11 + 3i) = 130 = 5\cdot26\), \(N(1 + 8i) = 65 = 5\cdot13\)으로 공통 노름 5와 맞는다.

7.2.3두 제곱수의 합

\(\mathbb Z[i]\)가 PID라 기약원과 소원이 같아지면, 정수론의 고전 정리가 짧게 나온다.

정리 7.2.4 (페르마의 두 제곱수 정리)

홀수 소수 \(p\)가 \(p = a^2 + b^2\)으로 쓰일 필요충분조건은 \(p \equiv 1 \pmod 4\)이다.

증명의 뼈대.제곱수는 법 4로 0 또는 1이라 \(a^2 + b^2 \not\equiv 3\)이다. 거꾸로 \(p \equiv 1 \pmod 4\)이면, \(U(p)\)가 위수 \(p - 1\)인 순환군이고 \(4 \mid p - 1\)이라 \(x^2 \equiv -1\)인 \(x\)가 있다. 그러면 \(p \mid x^2 + 1 = (x + i)(x - i)\)인데, \(\frac xp \pm \frac ip \notin \mathbb Z[i]\)라 \(p\)는 \(x \pm i\)를 나누지 않으므로 소원이 아니다. PID에서 소원이 아니면 기약원도 아니므로 \(p = \alpha\beta\), \(N(\alpha), N(\beta) > 1\)이고, \(p^2 = N(\alpha)N(\beta)\)에서 \(N(\alpha) = p\), 곧 \(p = a^2 + b^2\)이다. ∎

예를 들어 \(13 \equiv 1\)이라 \(13 = 4 + 9\)이고 \(29 = 4 + 25\)이다. 반면 \(7, 11, 19\)는 두 제곱수의 합이 아니다. 같은 절의 탐구 카드에서 나눗셈의 기하를 볼 수 있다.

흔한 오해몫을 실수부와 허수부를 내림해서 잡는 실수가 있다. 그러면 \(\left|\frac\alpha\beta - q\right|^2\)이 최대 2까지 커져 \(N(r) < N(\beta)\)가 보장되지 않으므로, 가장 가까운 점으로 반올림해야 한다. 또 \(\mathbb Z\)의 소수는 \(\mathbb Z[i]\)에서도 소원이라 생각하는 것도 틀렸다. \(5 = (1 + 2i)(1 - 2i)\)이고 \(2 = -i(1 + i)^2\)이며, 그대로 소원인 것은 \(p \equiv 3 \pmod 4\)인 소수뿐이다.
마무리

처음 질문에 답하면, 가우스 정수도 몫을 \(\frac\alpha\beta\)에 가장 가까운 격자점으로 잡으면 노름이 줄어드는 나눗셈이 되며, \(11 + 3i = (3 - 4i)(1 + 2i) + i\)이다. 그래서 \(\mathbb Z[i]\)는 유클리드정역이고 PID이므로 호제법과 유일 인수분해가 성립한다. 이 구조에서 \(p \equiv 1 \pmod 4\)인 소수는 \(x^2 + 1 = (x + i)(x - i)\)를 나누지만 인수를 나누지 못해 쪼개지고, 그 쪼개짐이 \(p = a^2 + b^2\)을 준다.

7.2.4연습문제

기본

  1. \(7 + i\)를 \(2 - i\)로 나눈 몫과 나머지를 구하여라.
    답

    \(\frac{(7+i)(2+i)}{5} = \frac{13 + 9i}{5} = 2.6 + 1.8i\), 몫 \(3 + 2i\), 나머지 \(7 + i - (3+2i)(2-i) = 7 + i - (8 + i) = -1\).

응용

  1. \(65\)를 두 제곱수의 합으로 두 가지 방법으로 쓰고, \(\mathbb Z[i]\)의 인수분해로 설명하여라.
    답

    \(65 = 1 + 64 = 16 + 49\). \(5 = (2+i)(2-i)\), \(13 = (3+2i)(3-2i)\)이고 \((2+i)(3+2i) = 4 + 7i\), \((2+i)(3-2i) = 8 - i\).

심화

  1. \(\mathbb Z[\sqrt{-2}]\)도 유클리드정역임을 같은 방법으로 보여라.
    답

    격자 직사각형 \(1\times\sqrt2\) 안에서 가장 가까운 꼭짓점까지 거리 제곱 \(\le \frac14 + \frac24 = \frac34 < 1\).
