원소가 4개인 군은 몇 가지인가

예제 · 라그랑주 정리로 위수 제한하기

먼저 예측

원소가 4개인 군의 곱셈표를 채우는 방법은 많아 보인다. 구조가 본질적으로 다른 것은 몇 가지일까?

예측 확인

두 가지이다. 순환군 \(\mathbb Z_4\)와, 항등원 아닌 원소가 모두 위수 2인 클라인 4원군 \(V = \mathbb Z_2\times\mathbb Z_2\).

\(|G| = 4\)이면 \(G\)는 순환군이거나, 항등원이 아닌 세 원소 \(a, b, c\)가 \(a^2 = b^2 = c^2 = e\), \(ab = c\), \(bc = a\), \(ca = b\)를 만족함을 보여라. 두 경우 모두 \(G\)는 가환이다.

전략

라그랑주 정리(2.1절)로 원소의 위수는 1, 2, 4뿐이다. 위수 4인 원소가 있느냐로 나누고, 없으면 곱셈표를 소거법칙(각 행에 각 원소 한 번)으로 채운다.

풀이

  1. 위수 4인 원소 \(g\)가 있으면 \(\langle g\rangle\)의 원소가 4개라 \(G = \langle g\rangle\), 순환군이다.
    \(|\langle g\rangle| = \) \(g\)의 위수.
  2. 없으면 \(e\) 아닌 원소 \(a, b, c\)는 모두 위수 2, 곧 \(a^2 = b^2 = c^2 = e\).
    위수는 4의 약수 1, 2, 4 중 하나이고, 1은 \(e\)뿐.
  3. \(ab\)는 \(e\)가 아니고 \(a\)도 \(b\)도 아니다. 따라서 \(ab = c\).
    \(ab = e\)이면 \(b = a^{-1} = a\), \(ab = a\)이면 \(b = e\), \(ab = b\)이면 \(a = e\). 모두 모순.
  4. 같은 논리로 \(ba = c\), \(bc = cb = a\), \(ca = ac = b\).
    세 원소의 역할은 대칭이다.
  5. 두 경우 모두 \(G\)는 가환이다.
    순환군은 가환. 둘째 경우는 \(ab = c = ba\) 등으로 모든 쌍이 교환된다.

검산

\(\mathbb Z_4\)에는 위수 2인 원소가 2 하나뿐이고, \(V\)에는 셋이다. 위수별 원소 수가 달라 두 군은 같은 구조일 수 없다. 예: \(U(8) = \{1, 3, 5, 7\}\)은 \(3^2 = 5^2 = 7^2 = 1\)이라 \(V\)이고, \(U(10) = \{1, 3, 7, 9\}\)는 \(3\)의 거듭제곱 \(3, 9, 7, 1\)이 전부라 \(\mathbb Z_4\)이다.

의미

라그랑주 정리 하나로 가능한 위수를 좁히고 나면, 작은 군은 손으로 분류할 수 있다. 같은 방법으로 원소 \(p\)개(소수)인 군은 \(\mathbb Z_p\)뿐이고, 원소 6개인 군은 \(\mathbb Z_6\)과 \(S_3\) 두 가지임을 보일 수 있다. 4단원은 가환군 전체를, 5단원(실로우)은 더 큰 위수를 다룬다.

이해 확인

원소가 4개 이하인 군은 모두 가환군인가?

답

예. 위수 1, 2, 3은 소수 또는 1이라 순환군이고, 위수 4는 위의 예제. 가장 작은 비가환군은 원소 6개인 \(S_3\)이다.
