군의 공리와 기본 성질

본문

정수의 덧셈, 0이 아닌 실수의 곱셈, 가역 행렬의 곱셈, 정삼각형 대칭을 이어 하기는 대상이 전혀 다르다. 그런데 이것들에 공통인 성질이 있다면, 그 성질만으로 한 번 증명한 사실이 모두에 한꺼번에 성립하지 않을까? 그 공통 성질은 무엇일까?

먼저 알아야 할 것함수와 합성(수학2 3.3절), 행렬의 곱과 역행렬(수학1 1.3절), 정수의 나눗셈(수학10 1.1절)을 쓴다. 나눗셈은 없어도 이 절 안에서 설명한다.

1.1.1여러 곳에 같은 구조가 있다

처음 질문의 예들은 모두 두 원소를 합쳐 같은 집합의 원소를 만들고, 괄호를 어디 치든 결과가 같고, "아무것도 안 하는" 원소가 있고, 모든 원소를 되돌릴 수 있다. 이 네 가지만 가정하고 증명한 사실은 위의 모든 예에 한꺼번에 성립한다. 이것이 군론의 경제성이다.

정의 1.1.1 (이항연산, 모노이드, 군)

집합 \(G\)의 함수 \(*: G \times G \to G\)를 이항연산이라 하고 \(*(a, b)\)를 \(a * b\) 또는 \(ab\)로 쓴다. 결과가 \(G\) 안에 있다는 닫힘이 정의에 들어 있다. 결합법칙 \((ab)c = a(bc)\)를 만족하고 항등원 \(e\) (\(ea = ae = a\))가 있으면 \((G, *)\)를 모노이드라 한다. 모노이드이면서 모든 \(a\)에 역원 \(a^{-1}\) (\(aa^{-1} = a^{-1}a = e\))이 있으면 군이라 한다. 모든 \(a, b\)에서 \(ab = ba\)인 군을 가환군(아벨군)이라 하며, 흔히 연산을 \(+\), 항등원을 0, 역원을 \(-a\)로 쓴다.

예제 1.1.2

다음이 군인지 판정하여라. (a) \((\mathbb Z, +)\) (b) \((\mathbb N, +)\) (c) \((\mathbb Z, \times)\) (d) \((\mathbb Q\setminus\{0\}, \times)\) (e) 가역 \(2\times2\) 실행렬 전체 \(GL_2(\mathbb R)\)와 곱 (f) \(\mathbb Z_6 = \{0, 1, \dots, 5\}\)와 "더한 뒤 6으로 나눈 나머지"

풀이. (a)는 항등원 0, 역원 \(-a\)인 가환군이다. (b)는 \(\mathbb N = \{0, 1, 2, \dots\}\)이면 모노이드이지만 1의 역원이 없어 군이 아니다. (c)도 모노이드이지만 2의 곱셈 역원 \(\frac12\)이 \(\mathbb Z\)에 없어 군이 아니다. (d)는 가환군이다. (e)는 가역 행렬의 곱이 가역이고 항등원이 \(I\)이므로 군이다. 하지만 \(\begin{pmatrix}1&1\\0&1\end{pmatrix}\)과 \(\begin{pmatrix}1&0\\1&1\end{pmatrix}\)의 곱이 순서에 따라 달라 가환이 아니다. (f)는 군이다. 예를 들어 \(4 + 5 = 9\)의 나머지는 3이고, 4의 역원은 2이다. 이 \(\mathbb Z_n\)은 앞으로 가장 자주 쓰는 군이다.

1.1.2공리만으로 증명하기

정의에는 "항등원이 있다"고만 했지 "하나뿐"이라고 하지 않았다. 그런데 \(a^{-1}\) 같은 기호를 쓰려면 하나뿐이어야 한다. 그래서 이것을 공리로부터 증명하며, 아래 증명에서 쓰는 것은 결합법칙, 항등원, 역원의 성질뿐이다.

정리 1.1.3

군 \(G\)에서 (a) 항등원은 하나뿐이다. (b) 각 원소의 역원은 하나뿐이다. (c) \(ab = ac\)이면 \(b = c\)이고, \(ba = ca\)이면 \(b = c\)이다(소거법칙). (d) \((ab)^{-1} = b^{-1}a^{-1}\), \((a^{-1})^{-1} = a\)이다.

증명.(a) \(e, e'\)이 모두 항등원이면 \(e = ee' = e'\)이다. 첫 등호는 \(e'\)이 항등원이라서, 둘째 등호는 \(e\)가 항등원이라서다. (b) \(b, c\)가 모두 \(a\)의 역원이면 결합법칙으로 \(b = be = b(ac) = (ba)c = ec = c\)이다. (c) 왼쪽에 \(a^{-1}\)을 곱하면 \(b = (a^{-1}a)b = a^{-1}(ab) = a^{-1}(ac) = c\)이고, 오른쪽도 같다. (d) \((ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = e\)이고 반대 순서도 같으므로, (b)의 유일성으로 \(b^{-1}a^{-1}\)이 \(ab\)의 역원이다. 또 \(a^{-1}a = e\)는 \(a\)가 \(a^{-1}\)의 역원이라는 말이다. ∎

(d)에서 순서가 바뀌는 것은 "양말을 신고 신발을 신었으면, 벗을 때는 신발부터"와 같다. 행렬에서 \((AB)^{-1} = B^{-1}A^{-1}\)이었던 것이 이 정리의 한 예이다. 또 (c)의 결과로, 그림 1처럼 군의 곱셈표의 각 행과 각 열에는 모든 원소가 정확히 한 번씩 나온다. 같은 행에 같은 원소가 두 번 나오면 소거법칙에 어긋나기 때문이다.

1.1.3거듭제곱과 위수

정의 1.1.4 (거듭제곱, 위수)

\(a^0 = e\), \(a^{n} = a^{n-1}a\) (\(n \ge 1\)), \(a^{-n} = (a^{-1})^n\)으로 거듭제곱을 정의하며, 덧셈으로 쓰면 \(na\)이다. 원소의 개수 \(|G|\)를 군의 위수라 한다. \(a^n = e\)인 가장 작은 양의 정수 \(n\)을 원소의 위수라 하고 \(|a|\)로 쓰며, 그런 \(n\)이 없으면 위수가 무한이다.

거듭제곱 법칙 \(a^ma^n = a^{m+n}\), \((a^m)^n = a^{mn}\)은 결합법칙에서 귀납법으로 나온다. 그러나 \((ab)^n = a^nb^n\)은 가환군에서만 성립한다. \((ab)^2 = abab\)이고 \(a^2b^2 = aabb\)이므로, 같으려면 소거법칙으로 \(ba = ab\)여야 하기 때문이다.

예제 1.1.5

\(\mathbb Z_{12}\)에서 원소 8의 위수, \(GL_2(\mathbb R)\)에서 \(R = \begin{pmatrix}0&-1\\1&0\end{pmatrix}\)의 위수를 구하여라.

풀이. 8, 16 → 4, 24 → 0이므로 \(3\cdot8 = 0\)이고 위수는 3이다. 일반적으로 \(\mathbb Z_n\)에서 \(k\)의 위수는 \(\frac{n}{\gcd(n, k)}\)이며, 여기서는 \(\frac{12}{4} = 3\)이다. \(R\)은 90° 회전이라 \(R^2 = -I\), \(R^4 = I\)이므로 위수는 4이다.

정리 1.1.6

\(a\)의 위수가 \(n\)이면, \(a^m = e\)일 필요충분조건은 \(n \mid m\)이다.

증명.나눗셈으로 \(m = qn + r\), \(0 \le r < n\)이라 하자. \(a^m = (a^n)^qa^r = a^r\)이므로 \(a^m = e\)는 \(a^r = e\)와 같다. 그런데 \(n\)이 가장 작은 양의 지수이므로 \(a^r = e\)는 \(r = 0\)과 같다. ∎

흔한 오해닫힘 확인을 빠뜨리기 쉽다. 홀수 전체는 덧셈에 대해 닫혀 있지 않아(\(1 + 1 = 2\)) 이항연산조차 아니다. 또 항등원을 늘 "곱셈의 1"로 단정하는 것도 틀렸다. 덧셈 군의 항등원은 0이고, 연산이 \(a * b = a + b - 1\)이면 항등원은 1이다. 한쪽 역원만 확인하고 끝내는 것도 주의하며, 정의는 양쪽을 요구한다.
마무리

처음 질문에 답하면, 공통 성질은 닫힌 이항연산이 결합법칙을 만족하고 항등원과 역원이 있다는 것이며, 이것을 갖춘 구조가 군이다. 이 공리만으로 항등원과 역원의 유일성, 소거법칙, \((ab)^{-1} = b^{-1}a^{-1}\)이 나오고, 이 사실들은 정수, 행렬, 대칭 등 모든 군에 한꺼번에 성립한다. 원소의 위수가 \(n\)이면 \(a^m = e\)일 조건은 \(n \mid m\)이다.

1.1.4연습문제

기본

  1. \(\mathbb Z_8\)의 각 원소의 위수를 구하여라.
    답

    0:1, 1:8, 2:4, 3:8, 4:2, 5:8, 6:4, 7:8.

  2. \(\mathbb R\)에서 \(a * b = a + b + ab\)는 군인가? \(\mathbb R\setminus\{-1\}\)에서는?
    답

    항등원 0, 역원 \(-\frac{a}{1 + a}\)이 \(a = -1\)에서 없어 \(\mathbb R\)에서는 아니다. \(a * b + 1 = (a + 1)(b + 1)\)이라 \(\mathbb R\setminus\{-1\}\)에서는 닫혀 있고 군이다.

응용

  1. 모든 원소가 \(a^2 = e\)를 만족하는 군은 가환군임을 보여라.
    답

    \(a = a^{-1}\)이므로 \(ab = (ab)^{-1} = b^{-1}a^{-1} = ba\).

심화

  1. 유한 집합 \(G\)에 결합적인 이항연산이 있고 양쪽 소거법칙이 성립하면 \(G\)는 (공집합이 아니면) 군임을 보여라.

    \(x \mapsto ax\)는 소거법칙으로 일대일, 유한이라 전단사. \(ae' = a\)인 \(e'\)을 잡고, 임의의 \(b = ya\)에 대해 \(be' = yae' = ya = b\)라 \(e'\)은 오른쪽 항등원. 마찬가지로 왼쪽 항등원이 있고 둘은 같다. 역원은 \(ax = e\)의 해.
