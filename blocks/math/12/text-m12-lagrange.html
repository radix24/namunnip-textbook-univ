잉여류와 라그랑주 정리

본문
이 절에서 배울 것
  • 왼쪽 잉여류 \(aH\)를 정의하고, 잉여류들이 \(G\)를 크기가 같은 조각으로 분할함을 증명한다.
  • 라그랑주 정리 \(|G| = [G : H]\,|H|\)와 그 따름정리(원소의 위수는 \(|G|\)의 약수, 소수 위수의 군은 순환군)를 증명한다.
  • 라그랑주 정리의 역은 성립하지 않음을 안다.
먼저 알아야 할 것
  • 부분군과 순환군 (1.2절, 1.3절), 동치관계와 분할 (수학2 3.1절), 합동식 (수학10 2단원).

2.1.1부분군을 옮겨 놓은 조각

정수를 3으로 나눈 나머지에 따라 \(3\mathbb Z\), \(1 + 3\mathbb Z\), \(2 + 3\mathbb Z\) 세 묶음으로 나누면, 각 묶음은 부분군 \(3\mathbb Z\)를 1이나 2만큼 옮겨 놓은 것입니다. 이 생각을 모든 군으로 넓힌 것이 잉여류입니다.

정의 2.1.1 (잉여류, 지수)

왼쪽 잉여류: \(H \le G\), \(a \in G\)에 대해 \(aH = \{ah : h \in H\}\). 오른쪽 잉여류 \(Ha\)도 같은 방식으로 정의한다. 덧셈 군에서는 \(a + H\)로 쓴다.

지수 \([G : H]\): 서로 다른 왼쪽 잉여류의 개수.

보조정리 2.1.2

\(H \le G\)일 때 (a) \(aH = bH \iff a^{-1}b \in H\). (b) 두 왼쪽 잉여류는 같거나 서로소이다. (c) \(h \mapsto ah\)는 \(H\)에서 \(aH\)로 가는 전단사이다. 따라서 왼쪽 잉여류들은 \(G\)를 크기 \(|H|\)인 조각으로 분할한다.

증명.\(a \sim b \iff a^{-1}b \in H\)로 두면 이는 동치관계다: \(a^{-1}a = e \in H\) (반사), \(a^{-1}b \in H \Rightarrow b^{-1}a = (a^{-1}b)^{-1} \in H\) (대칭), \(a^{-1}b, b^{-1}c \in H \Rightarrow a^{-1}c = (a^{-1}b)(b^{-1}c) \in H\) (추이). \(a\)의 동치류는 \(\{b : a^{-1}b \in H\} = \{b : b \in aH\} = aH\)이다. 동치류는 같거나 서로소이므로 (a), (b)가 나온다. (c) \(ah = ah'\)이면 소거법칙으로 \(h = h'\)(단사), 전사는 정의에서. ∎

세 가지 부분군 공리(항등원, 역원, 닫힘)가 동치관계의 세 공리(반사, 대칭, 추이)에 하나씩 대응한다는 점을 눈여겨보세요.

2.1.2라그랑주 정리

정리 2.1.3 (라그랑주)

\(G\)가 유한군이고 \(H \le G\)이면 \(|G| = [G : H]\cdot|H|\). 특히 \(|H|\)는 \(|G|\)의 약수이다.

증명.보조정리 2.1.2로 \(G\)는 서로소인 잉여류 \([G : H]\)개의 합집합이고 각각의 크기가 \(|H|\)이다. ∎

증명은 짧지만 결과는 강력합니다. 원소가 12개인 군에는 원소 5개, 7개, 8개인 부분군이 있을 수 없습니다.

따름정리 2.1.4

유한군 \(G\)에서 (a) 원소의 위수는 \(|G|\)의 약수이다. (b) 모든 \(a\)에서 \(a^{|G|} = e\). (c) \(|G| = p\)가 소수이면 \(G\)는 순환군이고 \(e\)가 아닌 모든 원소가 생성자이다.

증명.(a) \(a\)의 위수 \(= |\langle a\rangle|\)이고 \(\langle a\rangle \le G\). (b) 위수 \(d\)가 \(|G|\)를 나누므로 \(a^{|G|} = (a^d)^{|G|/d} = e\). (c) \(a \ne e\)이면 \(|\langle a\rangle|\)은 \(p\)의 약수이고 1이 아니므로 \(p\), 곧 \(\langle a\rangle = G\). ∎

예제 2.1.5

(a) \(S_3\)의 \(H = \{e, (1\,2)\}\)에 대한 왼쪽 잉여류를 모두 구하여라. (b) \(U(15)\)(15와 서로소인 수의 곱셈 군)에서 \(a^8 = 1\)임을 설명하여라.

풀이. (a) \(|S_3| = 6\), \(|H| = 2\)이므로 잉여류는 3개입니다. \(eH = \{e, (1\,2)\}\), \((1\,3)H = \{(1\,3), (1\,3)(1\,2)\} = \{(1\,3), (1\,2\,3)\}\), \((2\,3)H = \{(2\,3), (2\,3)(1\,2)\} = \{(2\,3), (1\,3\,2)\}\). 여섯 원소가 겹치지 않게 셋으로 나뉩니다. (b) \(U(15) = \{1, 2, 4, 7, 8, 11, 13, 14\}\)는 원소가 \(\varphi(15) = 8\)개이므로 따름정리 (b)로 \(a^8 \equiv 1 \pmod{15}\). 예: \(2^8 = 256 = 17\cdot15 + 1\). 이것이 오일러 정리 \(a^{\varphi(n)} \equiv 1\)이고, 6단원에서 다시 봅니다.

2.1.3역은 성립하지 않는다

\(d\)가 \(|G|\)의 약수라고 위수 \(d\)인 부분군이 있는 것은 아닙니다. 교대군 \(A_4\)(원소 12개)에는 위수 6인 부분군이 없습니다.

이유.\(A_4\)의 원소는 \(e\), 위수 2인 \((1\,2)(3\,4)\) 꼴 3개, 위수 3인 3-순환 8개다. 위수 6인 \(H\)가 있다면 지수가 2라 \(g \notin H\)이면 \(G = H \cup gH\)이고, \(g^2 \in H\)이다(\(g^2 \in gH\)이면 \(g \in H\)가 되어 모순). 3-순환 \(g\)는 \(g = (g^2)^2\)이므로 모든 3-순환이 \(H\)에 들어가 8개가 넘는다. 모순이다. ∎

그렇다면 어떤 약수에는 부분군이 보장될까요? 소수 \(p\)에 대해서는 코시 정리, 소수 거듭제곱의 최대 지수에 대해서는 실로우 정리가 답합니다(5단원).

흔한 실수(1) 잉여류를 부분군으로 착각한다: \(aH\)는 \(a \in H\)일 때만 부분군이다(\(e \in aH \iff a \in H\)). (2) \(aH = bH\)이면 \(a = b\)라고 생각한다: 같은 잉여류의 대표원은 여러 개다. \(1 + 3\mathbb Z = 4 + 3\mathbb Z\). (3) 무한군에 라그랑주 정리를 그대로 쓴다: \([\mathbb Z : 3\mathbb Z] = 3\)이지만 \(|\mathbb Z| = 3|3\mathbb Z|\) 같은 개수 비교는 의미가 없다.
요약
  1. 잉여류는 동치관계 \(a^{-1}b \in H\)의 동치류이고, 모두 크기 \(|H|\)이다.
  2. 라그랑주: \(|G| = [G:H]|H|\). 원소의 위수는 \(|G|\)의 약수, \(a^{|G|} = e\), 소수 위수의 군은 순환군.
  3. 역은 거짓: \(A_4\)에는 위수 6인 부분군이 없다.

2.1.4연습문제

기본

  1. 위수 35인 군의 원소가 가질 수 있는 위수를 모두 쓰라.
    답

    1, 5, 7, 35.

  2. \(\mathbb Z_{12}\)에서 \(H = \langle 4\rangle\)의 잉여류를 모두 쓰라.
    답

    \(\{0,4,8\}, \{1,5,9\}, \{2,6,10\}, \{3,7,11\}\). 지수 4.

응용

  1. \(H, K \le G\)이고 \(|H| = 8\), \(|K| = 15\)이면 \(H \cap K = \{e\}\)임을 보여라.
    답

    \(H \cap K\)는 \(H\)와 \(K\)의 부분군이라 위수가 8과 15의 공약수, 곧 1.

심화

  1. \(K \le H \le G\)이고 지수가 유한이면 \([G : K] = [G : H][H : K]\)임을 보여라.
    답

    \(G = \bigsqcup a_iH\), \(H = \bigsqcup b_jK\)이면 \(G = \bigsqcup a_ib_jK\). 서로 다름: \(a_ib_jK = a_{i'}b_{j'}K\)이면 오른쪽에 \(H\)를 곱해 \(a_iH = a_{i'}H\), \(i = i'\), 소거해 \(b_jK = b_{j'}K\).
