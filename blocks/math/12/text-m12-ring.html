환, 정역, 체

본문

정수, 다항식, 행렬, 나머지 \(\mathbb Z_n\)에는 덧셈과 곱셈이 함께 있다. 그런데 \(\mathbb Z_{12}\)에서는 \(3\cdot4 = 0\)처럼 0이 아닌 두 수의 곱이 0이 되고, \(\mathbb Z_7\)에서는 그런 일이 없다. 이 차이는 무엇이 정할까? 그리고 0이 아닌 모든 원소로 나눌 수 있는 \(\mathbb Z_n\)은 어떤 것일까?

먼저 알아야 할 것군과 가환군(1.1절), \(U(n)\)(1.1절 탐구 카드), 행렬의 곱(수학1 1.3절)을 쓴다.

6.1.1연산이 두 개인 구조

처음 질문의 예들에는 덧셈과 곱셈이 함께 있고 분배법칙으로 이어져 있다. 군이 연산 하나의 구조였다면, 환은 덧셈과 곱셈의 구조이다.

정의 6.1.1 (환)

집합 \(R\)과 두 이항연산 \(+, \cdot\)에서 \((R, +)\)가 가환군이고, 곱셈이 결합적이며, 분배법칙 \(a(b + c) = ab + ac\), \((a + b)c = ac + bc\)가 성립하면 환이라 한다. 곱셈이 가환이면 가환환이라 한다. 곱셈의 항등원 \(1 \ne 0\)을 단위원이라 하며, 이 교재의 환은 특별한 말이 없으면 단위원이 있다. \(ab = ba = 1\)인 \(b\)가 있는 \(a\)를 가역원이라 하고, 가역원 전체 \(R^\times\)는 곱셈군이다. \(a \ne 0\)인데 \(ab = 0\)인 \(b \ne 0\)이 있으면 \(a\)를 영인자라 한다. 영인자가 없는 가환환을 정역, 0이 아닌 모든 원소가 가역원인 가환환을 체라 한다.

공리에서 바로 \(0\cdot a = 0\)이 나온다. \(0a = (0 + 0)a = 0a + 0a\)에서 소거하면 되기 때문이다. 같은 방법으로 \((-a)b = -(ab)\)이고 \((-1)(-1) = 1\)이다. 즉 "음수 곱하기 음수는 양수"는 분배법칙의 결과이다.

예제 6.1.2

다음을 환, 정역, 체로 분류하여라. (a) \(\mathbb Z\) (b) \(\mathbb Q, \mathbb R, \mathbb C\) (c) \(\mathbb Z_6\) (d) \(\mathbb Z_7\) (e) \(M_2(\mathbb R)\) (f) \(\mathbb R[x]\) (g) \(2\mathbb Z\)

풀이. (a)는 정역이지만 2의 역원이 없어 체가 아니다. (b)는 체이다. (c)는 가환환이지만 \(2\cdot3 = 0\)이라 영인자가 있어 정역이 아니다. (d)는 0 아닌 원소마다 역원이 있어 체이며, 가령 \(3\cdot5 = 15 \equiv 1\)이다. (e)는 비가환환이고 \(\begin{pmatrix}1&0\\0&0\end{pmatrix}\begin{pmatrix}0&0\\0&1\end{pmatrix} = O\)이라 영인자가 있다. (f)는 최고차항끼리 곱하면 0이 아니므로 정역이지만, \(x\)의 역원이 없어 체가 아니다. (g)는 \(1 \notin 2\mathbb Z\)이라 단위원이 없는 환이다.

6.1.2소거법칙과 유한 정역

정리 6.1.3

가환환 \(R\)이 정역일 필요충분조건은 \(a \ne 0\)이고 \(ab = ac\)이면 \(b = c\)라는 곱셈 소거법칙이다.

증명.정역에서 \(ab = ac\)이면 \(a(b - c) = 0\)이고 \(a \ne 0\)이라 \(b - c = 0\)이다. 거꾸로 소거법칙이 성립하면 \(ab = 0 = a\cdot0\)에서 \(b = 0\)이다. ∎

체는 정역이다. \(ab = 0\), \(a \ne 0\)이면 \(b = a^{-1}ab = 0\)이기 때문이다. 거꾸로는 \(\mathbb Z\)에서 보듯 성립하지 않지만, 유한이면 성립한다.

정리 6.1.4

유한 정역은 체이다.

생각은 이렇다. \(a \ne 0\)에 대해 \(ax = 1\)을 풀어야 한다. "곱하기 \(a\)"라는 함수가 일대일이면 유한집합에서는 전사이고, 그러면 1도 어떤 \(ax\)로 나온다.

증명.\(R\)이 유한 정역이고 \(a \ne 0\)이라 하자. \(f(x) = ax\)는 \(R \to R\)이고, 소거법칙으로 \(ax = ay\)이면 \(x = y\)이므로 단사이다. \(R\)이 유한이므로 전사이고, 따라서 \(ab = 1\)인 \(b\)가 있다. 가환이므로 \(ba = 1\)도 성립한다. ∎

따름정리 6.1.5

\(\mathbb Z_n\)이 체일 필요충분조건과 정역일 필요충분조건은 모두 \(n\)이 소수인 것이다.

증명.\(n = ab\) (\(1 < a, b < n\))이면 \(a\cdot b = 0\)이라 영인자가 있다. \(n = p\)가 소수이면 \(ab \equiv 0 \pmod p\)에서 \(p \mid ab\)이고, 유클리드 보조정리로 \(p \mid a\) 또는 \(p \mid b\)이므로 정역이다. 유한이므로 체이다. ∎

더 일반적으로 \(\mathbb Z_n\)의 0 아닌 원소 \(a\)는 \(\gcd(a, n) = 1\)이면 가역원이고 아니면 영인자이다. 그림 1이 \(n = 12\)인 경우이며, 같은 절의 탐구 카드에서 다른 \(n\)을 볼 수 있다. 사실 유한 가환환에서는 이 이분법이 늘 성립한다.

흔한 오해\(ab = 0\)에서 곧바로 \(a = 0\) 또는 \(b = 0\)이라 쓰기 쉽지만, 정역에서만 맞다. \(\mathbb Z_{12}\)에서 \(x^2 = 0\)의 해는 0과 6이다. 또 \(x^2 = x\)의 해를 0과 1뿐이라 하는 것도 틀렸으며, \(\mathbb Z_6\)에서는 3과 4도 해이다. "무한 정역도 체"라고 일반화하는 것도 주의하며, \(\mathbb Z\)와 \(\mathbb R[x]\)가 반례이다.
마무리

처음 질문에 답하면, 0이 아닌 두 수의 곱이 0이 되는지는 영인자의 유무이고, \(\mathbb Z_n\)에서 0 아닌 \(a\)는 \(\gcd(a, n) = 1\)이면 가역원, 아니면 영인자이다. 영인자가 없는 가환환이 정역, 모든 0 아닌 원소가 가역인 것이 체이다. 유한 정역은 곱하기 \(a\)가 단사라 전사이므로 체이며, 그래서 \(\mathbb Z_n\)이 체일 필요충분조건은 \(n\)이 소수인 것이다. \(\mathbb Z_7\)은 체이고 \(\mathbb Z_{12}\)는 아니다.

6.1.3연습문제

기본

  1. \(\mathbb Z_{10}\)의 가역원과 영인자를 모두 쓰라.
    답

    가역원 1, 3, 7, 9. 영인자 2, 4, 5, 6, 8.

  2. \(\mathbb Z_{11}\)에서 \(4\)의 역원은?
    답

    3 (\(12 \equiv 1\)).

응용

  1. \(\mathbb Z[i] = \{a + bi : a, b \in \mathbb Z\}\)는 정역임을 보이고 가역원을 모두 구하여라.
    답

    \(\mathbb C\)의 부분환이라 영인자가 없다. \(\alpha\beta = 1\)이면 \(|\alpha|^2|\beta|^2 = 1\)이고 \(|\alpha|^2 = a^2 + b^2\)는 양의 정수라 1, 곧 \(\pm1, \pm i\).

심화

  1. 원소가 \(n\)개인 체의 표수(1을 몇 번 더하면 0이 되는가)는 소수임을 보여라.
    답

    \(m\cdot1 = 0\)인 최소 \(m\)이 \(m = ab\)이면 \((a\cdot1)(b\cdot1) = 0\)이고 정역이라 \(a\cdot1 = 0\) 또는 \(b\cdot1 = 0\), 최소성에 모순. 따라서 \(m\)은 소수.
