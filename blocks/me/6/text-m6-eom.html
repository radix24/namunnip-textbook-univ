질점의 운동 방정식과 좌표계 선택

본문
이 절에서 배울 것
  • 자유물체도와 운동학 그림(\(m\vec a\))을 나란히 그려 운동 방정식을 세운다.
  • 문제에 맞는 좌표계(직교, 법선-접선, 극좌표)를 고른다.
  • 경사면, 경사진 커브, 회전하는 막대 위 고리에 적용한다.
먼저 알아야 할 것
  • 자유물체도와 마찰 (일반물리학및실험(1) 3.1절, 3.2절, 고체역학 1.1절).
  • 세 좌표계의 가속도 (1.1절, 1.2절).

2.1.1세우는 순서

뉴턴 제2법칙 \(\sum\vec F = m\vec a\)는 관성 좌표계(지면에 고정, 또는 등속 이동)에서 성립합니다. 문제마다 같은 순서를 지키면 실수가 줄어듭니다.

  1. 좌표계를 고른다. 운동이 직선이면 직교, 경로가 정해진 곡선이면 법선-접선, 회전 중심이 있고 거리가 변하면 극좌표.
  2. 자유물체도: 질점을 떼어 내고 작용하는 힘을 모두 그린다(무게, 수직항력, 마찰, 장력, 용수철 힘).
  3. 운동학 그림: 같은 좌표계로 \(m\vec a\)의 성분을 그린다(예: \(ma_t\), \(mv^2/\rho\)).
  4. 두 그림의 성분을 같다고 놓는다. 미지수 수와 식의 수를 센다. 모자라면 운동학 관계(구속 조건)나 마찰 법칙을 더한다.

마찰은 미끄러지는 중이면 \(F = \mu_kN\)(운동 반대 방향), 미끄러지지 않으면 \(F \le \mu_sN\)이라는 부등식입니다. 미끄러지는지 모를 때는 먼저 정지(또는 미끄러지지 않음)를 가정하고 필요한 마찰을 구해 \(\mu_sN\)과 비교합니다.

2.1.2직교 좌표: 경사면

예제 2.1.1 (미끄러지는 상자)

30° 경사면(\(\mu_k = 0.2\))을 따라 상자가 미끄러져 내려간다. 가속도는?

풀이. 경사면 방향을 \(x\)(아래), 수직을 \(y\)로 잡으면 \(a_y = 0\)이므로 식이 간단합니다. \(y\): \(N - mg\cos30° = 0\). \(x\): \(mg\sin30° - \mu_kN = ma\). 따라서 \(a = g(\sin30° - 0.2\cos30°) = 3.21\) m/s². 질량은 사라집니다.

2.1.3법선-접선 좌표: 경사진 커브

예제 2.1.2 (경사진 커브의 한계 속도)

반지름 100 m, 경사각 15°인 커브에서 마찰 없이 돌 수 있는 속도(설계 속도)는? \(\mu_s = 0.3\)이면 미끄러지지 않는 최대 속도는?

풀이. 수평한 원을 도므로 \(\vec e_n\)은 수평으로 중심을 향하고 연직은 가속도가 0입니다. 마찰 없으면 연직: \(N\cos\theta = mg\), 법선: \(N\sin\theta = mv^2/R\). 나누면 \(v^2 = gR\tan\theta\), \(v = 16.2\) m/s(58 km/h). 최대 속도에서는 마찰이 경사면 아래로 \(\mu_sN\)만큼 작용합니다.

\[N\cos\theta - \mu_sN\sin\theta = mg\] \[N\sin\theta + \mu_sN\cos\theta = m\frac{v^2}{R}\] \[v_{\max}^2 = gR\frac{\sin\theta + \mu_s\cos\theta}{\cos\theta - \mu_s\sin\theta}\]

값을 넣으면 \(v_{\max} = 24.6\) m/s(89 km/h)입니다. 최소 속도는 분자 \(\sin\theta - \mu_s\cos\theta\)가 음수라 없습니다. 즉 멈춰 있어도 미끄러져 내려가지 않습니다.

2.1.4극좌표: 회전하는 막대 위의 고리

예제 2.1.3 (밖으로 빨려 나가는 고리)

수평면에서 3 rad/s로 일정하게 도는 매끈한 막대에 0.5 kg 고리가 끼워져 있다. 반지름 0.1 m에서 막대에 대해 정지 상태로 놓았다. 0.4 m에 이를 때 고리의 바깥 방향 속도와, 막대가 고리를 미는 옆 방향 힘은?

풀이. 매끈하므로 반지름 방향 힘이 없습니다: \(m(\ddot r - r\dot\theta^2) = 0\), \(\ddot r = 9r\). 해는 \(r = 0.1\cosh3t\)(1.2절 연습문제 3)이고 \(r = 0.4\)일 때 \(\cosh3t = 4\), \(\dot r = 0.3\sinh3t = 0.3\sqrt{15} = 1.16\) m/s. 원주 방향: 막대가 미는 힘 \(F_\theta = m(r\ddot\theta + 2\dot r\dot\theta) = 0.5(0 + 2\times1.16\times3) = 3.49\) N. 이 힘을 막대가 낼 수 있어야 각속도가 유지되므로, 막대를 돌리는 모터는 고리가 바깥으로 갈수록 더 큰 토크(\(F_\theta r\))를 내야 합니다.

주의(1) "원심력"은 회전하는 관찰자가 쓰는 겉보기 힘입니다. 관성 좌표계의 자유물체도에는 넣지 않고, 대신 운동학 그림에 \(mv^2/\rho\)를 넣습니다. (2) 마찰 방향은 미끄러지려는 방향의 반대이므로, 최대 속도와 최소 속도 문제에서 반대입니다. (3) 식의 수가 미지수보다 적으면 빠진 운동학 관계를 찾으세요.
요약
  1. 좌표계 고르기 → 자유물체도 → 운동학 그림(\(m\vec a\)) → 성분별 등식.
  2. 경사진 커브: 설계 속도 \(v^2 = gR\tan\theta\), 마찰이 있으면 범위가 생긴다.
  3. 극좌표 문제에서는 \(2\dot r\dot\theta\) 때문에 옆 방향 힘이 필요하다.

2.1.5연습문제

기본

  1. 엘리베이터가 2 m/s²로 위로 가속할 때 안의 70 kg 사람이 바닥에서 받는 힘은?
    답

    \(N = m(g + a) = 70\times11.81 = 827\) N.

응용

  1. 반지름 50 m 평평한 커브에서 \(\mu_s = 0.7\)이면 미끄러지지 않는 최대 속도는?
    답

    \(\mu_smg = mv^2/R\), \(v = \sqrt{0.7\times9.81\times50} = 18.5\) m/s(67 km/h).

심화

  1. 예제 2.1.2의 커브가 빙판이 되어 \(\mu_s = 0.05\)가 되었다. 미끄러지지 않는 속도 범위는?
    답

    \(v_{\min}^2 = gR(\sin\theta - \mu\cos\theta)/(\cos\theta + \mu\sin\theta) = 981\times0.2105/0.9789\), \(v_{\min} = 14.5\) m/s. \(v_{\max}^2 = 981\times0.3071/0.9530\), \(v_{\max} = 17.8\) m/s. 14.5~17.8 m/s 사이로만 돌 수 있어, 너무 느려도 안쪽으로 미끄러진다.
