강체 위 점의 상대 가속도

본문
이 절에서 배울 것
  • 상대 속도식을 미분해 상대 가속도식 \(\vec a_B = \vec a_A + \vec\alpha\times\vec r_{B/A} - \omega^2\vec r_{B/A}\)를 얻는다.
  • 구르는 바퀴의 접촉점 가속도가 0이 아님을 확인한다.
  • 크랭크-슬라이더의 피스톤 가속도와 로드의 각가속도를 구한다.
먼저 알아야 할 것
  • 상대 속도식과 순간 중심 (4.1절), 법선-접선 가속도 (1.1절).

4.2.1상대 가속도식

4.1절에서 A에서 본 B는 반지름 \(AB\)인 원운동을 했습니다. 원운동의 가속도는 접선 성분 \(r\alpha\)와 중심을 향하는 법선 성분 \(r\omega^2\)이므로

강체의 상대 가속도식 \[\vec a_B = \vec a_A + \vec\alpha\times\vec r_{B/A} - \omega^2\vec r_{B/A}\]

\(\vec\alpha\times\vec r_{B/A}\): \(AB\)에 수직(접선), 크기 \(\alpha\cdot AB\). \(-\omega^2\vec r_{B/A}\): B에서 A를 향함(법선), 크기 \(\omega^2\cdot AB\).

평면에서 미지수는 보통 둘(어떤 각가속도, 어떤 점의 가속도 크기)이고, 벡터식의 \(x\), \(y\) 두 성분으로 풉니다. 속도 해석(각속도)을 먼저 끝내야 \(\omega^2\) 항을 쓸 수 있습니다.

4.2.2구르는 바퀴

반지름 \(r\)인 바퀴가 미끄러지지 않고 구르면 \(v_G = r\omega\)이고, 미분하면 \(a_G = r\alpha\)입니다. 접촉점 C에 상대 가속도식을 쓰면, 접선 성분 \(r\alpha\)가 \(a_G\)를 정확히 지우고 법선 성분만 남습니다.

\[\vec a_C = r\omega^2\ (\text{바퀴 중심을 향해 위로})\]

접촉점은 순간 속도가 0이지만 가속도는 0이 아닙니다. 중심 속도 6 m/s, 반지름 0.3 m인 바퀴(\(\omega = 20\))의 접촉점 가속도는 120 m/s²입니다. 그래서 순간 중심을 가속도 계산에 쓰면 안 됩니다.

4.2.3크랭크-슬라이더의 가속도

예제 4.2.1 (피스톤 가속도)

예제 4.1.2(크랭크 0.1 m, 로드 0.3 m, 크랭크 100 rad/s 일정, 60°)에서 로드의 각가속도와 피스톤의 가속도는?

풀이. 4.1절에서 \(\omega_{AB} = 17.41\) rad/s(시계 방향, \(-17.41\vec k\))였습니다. \(\vec r_{B/A} = (0.287, -0.0866)\).

  1. A는 등속 원운동: \(\vec a_A = -\omega^2\vec r_A = -10^4(0.05, 0.0866) = (-500, -866)\) m/s².
  2. \(\vec\alpha\times\vec r_{B/A} = \alpha_{AB}(0.0866, 0.287)\), \(-\omega_{AB}^2\vec r_{B/A} = -303(0.287, -0.0866) = (-87.0, 26.2)\).
  3. B는 수평으로만 움직이므로 \(y\) 성분 0: \(-866 + 0.287\alpha_{AB} + 26.2 = 0\), \(\alpha_{AB} = 2924\) rad/s²(반시계).
  4. \(x\) 성분: \(a_B = -500 + 0.0866(2924) - 87.0 = -334\) m/s².

피스톤 가속도는 중력의 34배입니다. 엔진 회전 속도의 제곱에 비례해 커지므로, 고속 엔진에서는 피스톤과 로드의 관성력이 베어링과 볼트를 지배하는 하중이 됩니다(힘의 계산은 5.1절).

주의(1) 법선 항 \(-\omega^2\vec r_{B/A}\)의 방향은 언제나 B에서 A 쪽입니다. (2) \(\vec\alpha\)의 방향을 모르면 반시계(+)로 가정하고 풀어 부호로 판단합니다. (3) 순간 중심의 가속도는 0이 아닙니다.
요약
  1. \(\vec a_B = \vec a_A + \vec\alpha\times\vec r_{B/A} - \omega^2\vec r_{B/A}\).
  2. 속도 해석 → \(\omega\) → 가속도식 두 성분 → 미지수 둘.
  3. 구르는 바퀴: \(a_G = r\alpha\), 접촉점 가속도 \(r\omega^2\)(위로).

4.2.4연습문제

기본

  1. 고정축 주위로 \(\omega = 4\) rad/s, \(\alpha = 3\) rad/s²로 도는 원판에서 축으로부터 0.5 m인 점의 가속도 크기는?
    답

    \(a_t = 1.5\), \(a_n = 8\), 크기 8.14 m/s².

응용

  1. 반지름 0.4 m 바퀴가 미끄러지지 않고 구르며 중심이 오른쪽으로 2 m/s, 가속도 1 m/s²이다. 꼭대기 점의 가속도는?
    답

    \(\omega = 5\), \(\alpha = 2.5\)(시계). 꼭대기: \(\vec a = (1, 0) + (2.5\times0.4, 0) + (0, -25\times0.4) = (2, -10)\) m/s².

심화

  1. 예제 4.2.1의 피스톤 가속도를 \(x_B(\theta)\)를 두 번 미분해 확인하여라(크랭크 \(\omega\) 일정, \(\ddot x_B = \omega^2\,d^2x_B/d\theta^2\)).
    답

    수치 미분 \(d^2x_B/d\theta^2 = -0.0334\) m, \(\ddot x_B = -334\) m/s²로 같다. 근사식 \(a_B \approx -r\omega^2(\cos\theta + (r/l)\cos2\theta) = -1000(0.5 - 0.167) = -333\) m/s²도 가깝다.
