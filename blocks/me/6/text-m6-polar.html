극좌표: 반지름 방향과 원주 방향

본문

돌아가는 회전목마의 가운데에서 바깥쪽 가장자리로 일정한 걸음으로 걸어가면, 몸이 자꾸 옆으로 밀려 똑바로 걷기 어렵다. 걸음도 일정하고 회전도 일정한데 왜 옆으로 힘을 써야 할까? 거리와 각도로 주어진 운동의 가속도는 어떻게 구할까?

먼저 알아야 할 것법선-접선 좌표(1.1절), 고등학교 수학의 극좌표 \(x = r\cos\theta\), \(y = r\sin\theta\)를 쓴다.

1.2.1언제 극좌표를 쓰나

운동이 어떤 고정점에서의 거리와 각도로 주어지거나 측정될 때 극좌표를 쓴다. 회전하는 팔의 홈을 따라 미끄러지는 고리, 거리와 고도각을 재는 레이더 속 비행기, 행성 궤도가 그런 예이다. 원점에서 질점을 향하는 단위 벡터를 \(\vec e_r = (\cos\theta, \sin\theta)\)라 하고, 이것을 반시계로 90° 돌려 \(\theta\)가 커지는 방향을 가리키는 단위 벡터를 \(\vec e_\theta = (-\sin\theta, \cos\theta)\)라 한다.

1.2.2속도와 가속도의 유도

찾는 것은 위치 \(\vec r = r\vec e_r\)의 1, 2계 미분이다. 1.1절과 마찬가지로 단위 벡터 자체가 \(\theta\)에 따라 돌기 때문에 미분이 생기며, 성분을 직접 미분하면 다음과 같다.

\[\dot{\vec e}_r = \dot\theta(-\sin\theta, \cos\theta) = \dot\theta\,\vec e_\theta\] \[\dot{\vec e}_\theta = \dot\theta(-\cos\theta, -\sin\theta) = -\dot\theta\,\vec e_r\]

식을 써서 차례로 미분하면 먼저 \(\vec v = \dot r\vec e_r + r\dot{\vec e}_r = \dot r\vec e_r + r\dot\theta\vec e_\theta\)이다. 이것을 한 번 더 미분하면 \(\vec a = \ddot r\vec e_r + \dot r\dot\theta\vec e_\theta + (\dot r\dot\theta + r\ddot\theta)\vec e_\theta + r\dot\theta(-\dot\theta\vec e_r)\)이고, 성분끼리 모으면 다음을 얻는다.

극좌표의 속도와 가속도 \[v_r = \dot r\] \[v_\theta = r\dot\theta\] \[a_r = \ddot r - r\dot\theta^2\] \[a_\theta = r\ddot\theta + 2\dot r\dot\theta\]

각 항의 뜻을 보자. \(\ddot r\)은 반지름 방향으로 빨라지는 것이고, \(-r\dot\theta^2\)은 구심 가속도로 원운동이면 이것만 남는다. 또 \(r\ddot\theta\)는 회전이 빨라져 생기는 원주 방향 가속도이다.

마지막 \(2\dot r\dot\theta\)가 Coriolis 항이며, 처음 질문의 답이다. 돌고 있는 팔에서 바깥으로 움직이면 원주 속도 \(r\dot\theta\)가 큰 곳으로 옮겨 가므로 그만큼 옆으로 밀어 주어야 한다. 그 절반은 \(\dot r\)이 \(\vec e_r\)의 회전으로 방향을 바꾼 몫이고, 나머지 절반은 \(r\)이 커져 \(r\dot\theta\)가 커진 몫이다.

예제 1.2.1 (돌아가는 팔 위의 고리)

수평면에서 2 rad/s로 일정하게 도는 팔의 홈을 따라 고리가 바깥으로 0.5 m/s로 일정하게 미끄러진다. \(r = 0.6\) m일 때 고리의 가속도는?

풀이. \(\dot r = 0.5\), \(\ddot r = 0\), \(\dot\theta = 2\), \(\ddot\theta = 0\)이다. 따라서 \(a_r = 0 - 0.6\times4 = -2.4\) m/s²로 중심 쪽이고, \(a_\theta = 0 + 2\times0.5\times2 = 2.0\) m/s²이며, 크기는 3.12 m/s²이다(그림 1). 즉 팔은 고리를 원주 방향으로 \(m\times2.0\)의 힘으로 밀어야 한다. 일정한 속도로 미끄러지고 일정하게 도는데도 옆 방향 힘이 필요하다는 것이 Coriolis 효과이다.

예제 1.2.2 (레이더 추적)

고도 3 km에서 200 m/s로 수평 등속 비행하는 비행기를 지상 레이더가 추적한다. 고도각 \(\theta = 60°\)일 때(비행기가 레이더에서 멀어지는 중) 레이더가 읽는 \(\dot r\), \(\dot\theta\), \(\ddot r\), \(\ddot\theta\)는?

풀이. \(r = 3000/\sin60° = 3464\) m이다. 비행기 속도 \((200, 0)\)을 \(\vec e_r\), \(\vec e_\theta\)에 투영하면 \(\dot r = 200\cos60° = 100\) m/s, \(r\dot\theta = -200\sin60° = -173.2\) m/s이므로 \(\dot\theta = -0.0500\) rad/s이다. 또 등속 직선이라 가속도가 0이므로, \(a_r = \ddot r - r\dot\theta^2 = 0\)에서 \(\ddot r = 3464\times0.0025 = 8.66\) m/s²이다. 마찬가지로 \(a_\theta = r\ddot\theta + 2\dot r\dot\theta = 0\)에서 \(\ddot\theta = -2(100)(-0.05)/3464 = 2.89\times10^{-3}\) rad/s²이다.

즉 비행기는 가속하지 않는데 레이더의 \(\ddot r\), \(\ddot\theta\)는 0이 아니다. 좌표값의 2계 미분과 가속도 성분은 다른 것이다.

흔한 실수\(a_r\)을 \(\ddot r\)로, \(a_\theta\)를 \(r\ddot\theta\)로 쓰는 실수가 흔하다. 빠뜨리기 쉬운 \(-r\dot\theta^2\)과 \(2\dot r\dot\theta\)를 꼭 넣어야 한다. 또 \(\theta\)의 단위는 라디안이므로 rpm은 \(2\pi/60\)을 곱해 바꾼다. 단위 벡터가 위치에 따라 바뀌므로, 다른 점의 극좌표 성분끼리 더하면 안 된다.
마무리

극좌표의 단위 벡터는 \(\dot{\vec e}_r = \dot\theta\vec e_\theta\), \(\dot{\vec e}_\theta = -\dot\theta\vec e_r\)로 돌며, 이로부터 속도는 \(\vec v = \dot r\vec e_r + r\dot\theta\vec e_\theta\)이다. 가속도는 \(a_r = \ddot r - r\dot\theta^2\), \(a_\theta = r\ddot\theta + 2\dot r\dot\theta\)이고, \(2\dot r\dot\theta\)는 회전하는 팔을 따라 바깥으로 움직일 때 생기는 Coriolis 항이다.

1.2.3연습문제

기본

  1. 질점이 \(r = 2\) m인 원 위를 \(\dot\theta = 3\) rad/s, \(\ddot\theta = 1\) rad/s²로 돈다. 가속도 성분은?
    답

    \(a_r = -2\times9 = -18\) m/s², \(a_\theta = 2\times1 = 2\) m/s²이다.

응용

  1. 나선 \(r = 0.1\theta\) (m)를 따라 \(\dot\theta = 2\) rad/s로 일정하게 움직이는 점의 \(\theta = \pi\)에서 가속도 크기는?
    답

    \(r = 0.314\), \(\dot r = 0.2\), \(\ddot r = 0\)이므로 \(a_r = -0.314\times4 = -1.26\), \(a_\theta = 2\times0.2\times2 = 0.8\)이고 크기는 1.49 m/s²이다.

심화

  1. 예제 1.2.1의 팔(\(\dot\theta = 2\) rad/s 일정)에서 고리가 마찰 없이 자유롭게 미끄러진다면 반지름 방향 힘이 없으므로 \(a_r = \ddot r - r\dot\theta^2 = 0\), 곧 \(\ddot r = 4r\)이다. \(r(t) = 0.05(e^{2t} + e^{-2t})\)가 이 관계와 \(r(0) = 0.1\) m, \(\dot r(0) = 0\)을 모두 만족함을 미분해서 확인하고, 1초 뒤의 \(r\)을 구하여라.
    답

    \(\dot r = 0.1(e^{2t} - e^{-2t})\), \(\ddot r = 0.2(e^{2t} + e^{-2t}) = 4r\)이고 \(r(0) = 0.1\), \(\dot r(0) = 0\)이다. 1초 뒤 \(r = 0.05(e^2 + e^{-2}) = 0.376\) m이며, 고리는 지수함수처럼 점점 빨리 바깥으로 빨려 나간다.
