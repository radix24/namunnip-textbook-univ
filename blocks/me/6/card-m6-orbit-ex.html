저궤도에서 정지 궤도로: Hohmann 전이

예제 · vis-viva · 두 번의 가속 · 전이 시간
문제 해결 전략 · 두 원궤도를 잇는 타원
  1. 전이 타원의 장반경 \(a = (r_1 + r_2)/2\).
  2. vis-viva로 근지점과 원지점 속도를 구한다.
  3. 원궤도 속도와의 차이가 두 번의 \(\Delta v\), 전이 시간은 주기의 절반.

문제. 반지름 6771 km 원궤도(고도 400 km)에서 42164 km 정지 궤도로 Hohmann 전이할 때 두 번의 속도 증가량과 전이 시간은? (궤도면 변경은 무시)

전략

원궤도 속도는 예제 2.4.1 값 7.67, 3.07 km/s.

풀이

  1. \(a = (6771 + 42164)/2 = 24468\) km.
    전이 타원.
  2. 근지점 \(v_p = \sqrt{\mu(2/r_1 - 1/a)} = 10.07\) km/s → \(\Delta v_1 = 10.07 - 7.67 = 2.40\) km/s.
    첫 번째 가속.
  3. 원지점 \(v_a = \sqrt{\mu(2/r_2 - 1/a)} = 1.62\) km/s → \(\Delta v_2 = 3.07 - 1.62 = 1.46\) km/s.
    두 번째 가속.
  4. 합 3.86 km/s. 전이 시간 \(\pi\sqrt{a^3/\mu} = 5.29\) h.
    반 주기.

검산

각운동량 보존 \(r_1v_p = r_2v_a\): \(6771\times10.07 = 68{,}200\), \(42164\times1.62 = 68{,}300\)으로 반올림 안에서 같습니다.

의미

\(\Delta v\) 3.86 km/s는 로켓 방정식으로 추진제 양을 정합니다(전자기학및응용 5.2절). 화학 추진(\(I_{sp}\) 300 s)이면 위성 질량의 약 73%가 추진제여야 해, 정지 궤도 위성은 보통 발사체가 타원 전이 궤도까지 올려 주고 위성은 \(\Delta v_2\)만 냅니다.

바꿔 보기

전기 추진으로 천천히 나선을 그리며 올라가면 \(\Delta v\)는 두 원궤도 속도의 차 \(7.67 - 3.07 = 4.6\) km/s로 오히려 크지만, 비추력이 10배라 추진제는 훨씬 적습니다. 대신 몇 달이 걸립니다.

이해 확인

원지점에서 \(\Delta v_2\)를 주지 않으면 위성은 어떻게 되는가?

답

전이 타원을 따라 다시 근지점(400 km)으로 돌아온다.
