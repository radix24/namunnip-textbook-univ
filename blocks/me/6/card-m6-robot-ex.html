늘어나며 도는 로봇 팔 끝의 가속도

예제 · 극좌표 · 네 가지 가속도 항
문제 해결 전략 · 극좌표 운동학
  1. \(r(t)\), \(\theta(t)\)를 시간으로 두 번 미분해 그 순간의 \(r\), \(\dot r\), \(\ddot r\), \(\dot\theta\), \(\ddot\theta\)를 표로 만든다.
  2. \(v_r = \dot r\), \(v_\theta = r\dot\theta\).
  3. \(a_r = \ddot r - r\dot\theta^2\), \(a_\theta = r\ddot\theta + 2\dot r\dot\theta\). 네 항을 하나씩 채운다.
먼저 예상해 보기. 팔이 줄어들면서(\(\dot r < 0\)) 회전이 빨라지면, Coriolis 항 \(2\dot r\dot\theta\)는 원주 방향 가속도를 키울까, 줄일까?

문제. 수평면에서 도는 로봇 팔의 회전각이 \(\theta = 0.5t^2\) (rad), 팔 길이가 \(r = 1.5 - 0.2t^2\) (m)로 변한다. \(t = 1\) s에서 팔 끝(집게)의 속도와 가속도는?

전략

미분해 값을 모은 뒤 공식에 넣는다. 각 항의 부호를 따로 확인하면 실수가 줄어든다.

풀이

  1. \(t = 1\): \(r = 1.3\), \(\dot r = -0.4t = -0.4\), \(\ddot r = -0.4\); \(\dot\theta = t = 1\), \(\ddot\theta = 1\).
    시간 미분.
  2. \(v_r = -0.4\), \(v_\theta = 1.3\), \(v = 1.36\) m/s.
    \(\vec v = \dot r\vec e_r + r\dot\theta\vec e_\theta\).
  3. \(a_r = -0.4 - 1.3(1)^2 = -1.70\) m/s².
    \(\ddot r\)과 구심 항 모두 안쪽.
  4. \(a_\theta = 1.3(1) + 2(-0.4)(1) = 1.3 - 0.8 = 0.50\) m/s².
    Coriolis 항이 음수.
  5. \(a = \sqrt{1.70^2 + 0.50^2} = 1.77\) m/s².
    두 성분은 수직.

의미

팔이 줄어들면 집게는 원주 속도 \(r\dot\theta\)가 작은 안쪽으로 옮겨 가므로, 회전을 빠르게 하는 효과(\(r\ddot\theta = 1.3\))의 상당 부분(0.8)을 Coriolis 항이 깎아 낸다. 피겨 선수가 팔을 오므리면 저절로 빨리 도는 것(각운동량 보존)과 같은 운동학이다. 로봇 제어에서는 이 항 때문에 팔을 접으며 돌 때 모터 토크를 따로 보정한다.

검산

직교 좌표로 확인한다. \(x = r\cos\theta\), \(y = r\sin\theta\)를 두 번 미분해 \(t = 1\)에 넣으면 \((\ddot x, \ddot y) = (-1.73, -0.38)\) m/s²이다. \(\theta = 0.5\) rad에서 \(\vec e_r = (0.878, 0.479)\), \(\vec e_\theta = (-0.479, 0.878)\)이므로 \(-1.70\vec e_r + 0.50\vec e_\theta = (-1.73, -0.38)\)로 일치한다.

이해 확인

같은 팔이 \(t = 2\) s에서의 \(a_\theta\)는?

답

\(r = 0.7\), \(\dot r = -0.8\), \(\dot\theta = 2\), \(\ddot\theta = 1\): \(a_\theta = 0.7 - 3.2 = -2.5\) m/s². Coriolis 항이 이겨 원주 방향 가속도가 거꾸로 된다.
