이동 평균과 IIR 필터 견주기

예제 · 잡음 감소 · 지연
문제 해결 전략 · 디지털 필터 비교
  1. 잡음 표준편차 감소: 이동 평균 \(1/\sqrt N\), 1차 IIR \(\sqrt{(1 - a)/(1 + a)}\).
  2. 저주파 지연: 이동 평균 \((N - 1)/2\) 표본, IIR \(a/(1 - a)\) 표본.
  3. 계산량과 메모리도 비교한다.

문제. 1 kHz 표본화 신호에 계수 \(a\) = 0.939인 1차 IIR 필터를 쓴다. 잡음 감소와 지연을 같은 정도로 내는 이동 평균의 길이는? 두 필터의 메모리와 계산량을 비교하라.

전략

표본마다 독립인 잡음(백색 잡음)으로 봅니다.

풀이

  1. IIR 잡음 감소 \(\sqrt{0.061/1.939} = 0.177\).
    분산 비 \((1 - a)/(1 + a)\).
  2. 같은 감소의 이동 평균: \(1/\sqrt N = 0.177\) → \(N = 32\).
    \(1/\sqrt{32} = 0.177\).
  3. 지연: IIR \(0.939/0.061 = 15.4\) 표본, 이동 평균 \((32 - 1)/2 = 15.5\) 표본. 거의 같다.
    약 15 ms.
  4. 메모리: IIR 변수 1개, 이동 평균 32개(원형 버퍼). 계산: IIR 곱셈 2번, 이동 평균은 합을 갱신하면 덧셈·뺄셈 각 1번.
    IIR이 메모리에서 유리.

검산

IIR의 \(a = e^{-T/\tau}\)에서 \(\tau = 15.9\) ms이고 지연 15.4 ms와 거의 같습니다. 1차 필터의 저주파 지연은 시정수와 같습니다.

의미

잡음을 줄이는 만큼 지연이 생긴다는 교환은 필터 종류를 바꿔도 크게 달라지지 않습니다. 제어에서는 지연을, 표시에서는 잡음을 우선하는 식으로 용도에 따라 정합니다.

바꿔 보기

이동 평균은 길이 \(N\)의 주기 성분(여기서 1000/32 = 31.25 Hz와 그 배수)을 완전히 지웁니다. 60 Hz 전원 잡음을 지우려면 1 kHz에서 \(N\)을 1000/60의 배수에 가깝게 고릅니다.

이해 확인

\(a = 0.5\)인 IIR의 잡음 감소와 지연은?

답

\(\sqrt{0.5/1.5} = 0.577\), 지연 1 표본.
