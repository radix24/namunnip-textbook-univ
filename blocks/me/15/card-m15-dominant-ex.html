PD 제어가 만든 영점과 오버슈트

예제 · 영점 위치 · 오버슈트 비교
문제 해결 전략 · 영점 없는 응답을 기준으로
  1. 영점이 없을 때 오버슈트를 공식으로 구한다.
  2. 영점이 있으면 응답 \(= y_0 + \dot y_0/a\)임을 쓴다.
  3. 영점 위치별 오버슈트를 비교한다.

문제. 폐루프 \(T(s) = \dfrac{4(s/a + 1)}{s^2 + 2s + 4}\)(\(\omega_n\) = 2, \(\zeta\) = 0.5)에서 영점이 없을 때, \(a\) = 4일 때, \(a\) = 1일 때 계단 응답 오버슈트는? (영점이 있는 경우는 수치 시뮬레이션 값)

전략

영점 항 \(\dot y_0/a\)는 응답이 빠르게 오를 때 크게 더해져 첫 봉우리를 키운다.

풀이

  1. 영점 없음: \(M_p = e^{-\pi\times0.5/\sqrt{0.75}} = 16.3\%\).
    2차 공식.
  2. \(a\) = 4(영점이 극점 실수부의 4배 왼쪽): 약 19%.
    조금 증가.
  3. \(a\) = 1(극점 실수부와 같은 곳): 약 70%.
    크게 증가.

검산

세 경우 모두 \(T(0) = 1\)이라 정상상태 값은 1로 같고, 영점은 과도 응답만 바꾼다. \(a \to \infty\)이면 영점 항이 사라져 16.3%로 돌아간다.

의미

PD나 PID 제어기는 폐루프에 영점을 만든다. 극점만 보고 감쇠비 0.5를 맞췄는데 실제 오버슈트가 훨씬 크다면 영점을 의심한다. 기준 입력에는 미분을 걸지 않는 구조(측정값에만 D 적용)로 이 영점을 피하기도 한다.

바꿔 보기

영점을 오른쪽 반평면(\(s/a\) 대신 \(-s/a\))에 두면 응답이 처음에 반대 방향으로 갔다가 돌아온다. 자전거를 왼쪽으로 돌리려면 핸들을 먼저 오른쪽으로 살짝 트는 현상, 보일러 수위 제어의 역응답이 그 예이다.

이해 확인

영점 효과를 무시해도 되려면 \(a\)는 대략 얼마 이상이어야 하는가? (오버슈트 증가 3%p 이내 기준)

답

\(a\) = 4에서 약 2.8%p 증가이므로 극점 실수부의 4~5배(\(a \gtrsim 4\)) 이상.
