가제어성과 적분 동작을 넣은 상태 피드백

본문

똑같은 수레 두 대에 같은 힘을 걸면 두 수레를 함께 밀고 당길 수는 있지만, 둘 사이의 간격은 어떻게 해도 바꿀 수 없다. 입력으로 모든 상태를 움직일 수 있는지를 미리 판정하는 방법은 무엇일까? 그리고 상태 피드백에 정상상태 오차가 남을 때는 무엇을 더해야 할까?

먼저 알아야 할 것상태방정식과 극점 배치(6.1절), 관측기와 가관측성(6.2절)을 쓴다.

6.3.1가제어성 판정

\(\dot{\mathbf x} = A\mathbf x + B u\)(상태 \(n\)개)에서 입력이 모든 상태 방향에 영향을 줄 수 있어야 극점을 원하는 곳으로 옮길 수 있다. 이 성질을 가제어성이라 하고, 아래 행렬의 계수로 판정한다. 처음 질문의 첫째 답이 이것이다.

가제어성 행렬

\[\mathcal C = [\,B\ \ AB\ \ A^2B\ \cdots\ A^{n-1}B\,],\qquad \operatorname{rank}\mathcal C = n \iff \text{가제어}\]

\(B\)는 입력이 상태를 처음 미는 방향이고, \(AB\), \(A^2B\)는 그 움직임이 계의 동역학을 타고 퍼져 나가는 방향이다. 그래서 이 방향들이 상태 공간 전체를 덮어야 모든 상태에 닿는다.

처음 질문의 두 수레가 가제어하지 않은 예이다(그림 1). 평균 위치는 움직일 수 있지만, 두 수레의 차이는 입력으로 바꿀 수 없다. 그러므로 가제어성은 구동기를 어디에 몇 개 달지 정하는 단계에서 확인할 일이다.

6.3.2적분 동작 추가

상태 피드백 \(u = -K\mathbf x\)만 쓰면, 플랜트 이득이 바뀌거나 외란이 있을 때 정상상태 오차가 남는다. 그래서 오차의 적분 \(z = \int(r - y)\,dt\)를 새 상태로 더하고 \(u = -K\mathbf x + k_iz\)로 둔다. 그러면 정상상태에서 \(\dot z = 0\)이므로 \(y = r\)이 된다. 처음 질문의 둘째 답이 이것이며, 3.2절에서 적분기가 오차를 없앤 것과 같은 원리이다.

이때 늘어난 계(상태 \(n + 1\)개)가 가제어해야 적분 상태까지 포함한 극점을 모두 배치할 수 있다.

예제 6.3.1 (이중 적분기)

마찰 없는 질량 \(\ddot x = u\)(상태 \(x\), \(\dot x\))가 가제어한지 판정하고 극점을 −2, −2에 두는 이득을 구하여라.

풀이. \(A = \begin{bmatrix}0&1\\0&0\end{bmatrix}\), \(B = \begin{bmatrix}0\\1\end{bmatrix}\)이고 \(AB = \begin{bmatrix}1\\0\end{bmatrix}\)이다. \(\mathcal C\)의 계수가 2이므로 가제어하다. \(u = -k_1x - k_2\dot x\)이면 특성식이 \(s^2 + k_2s + k_1 = (s + 2)^2\)이므로 \(k_1\) = 4, \(k_2\) = 4이다.

여기서 \(B\)는 속도만 밀지만, \(AB\)가 그 속도가 위치로 번지는 방향을 더해 두 방향이 평면을 덮는다. 즉 힘을 위치에 직접 걸 수 없어도, 속도를 거쳐 위치까지 닿으므로 가제어하다.

흔한 오해계수 판정에서 가제어로 나오면 실제로도 제어가 쉽다고 여기기 쉽다. 계수 판정은 예 또는 아니오만 알려 준다. 가제어성 행렬이 특이에 가까워 계수가 수치상 겨우 채워지는 경우에는, 이론상 가제어해도 어떤 방향을 움직이려면 아주 큰 입력이 필요해 실제로는 제어가 어렵다.
마무리

\(\operatorname{rank}[B\ AB\ \cdots] = n\)이면 가제어하고, 극점을 모두 배치할 수 있다. 가제어하지 않은 모드는 피드백으로 옮길 수 없다. 적분 상태를 더하면 정상상태 오차가 0이 된다.

6.3.3연습문제

기본

  1. \(A = \begin{bmatrix}-1&0\\0&-2\end{bmatrix}\), \(B = \begin{bmatrix}1\\0\end{bmatrix}\)은 가제어한가?
    답

    \(AB = (-1, 0)^T\)로 \(B\)와 평행하여 계수가 1이므로 가제어가 아니다. 두 번째 상태에 입력이 닿지 않는다.

응용

  1. 같은 질량 두 개에 같은 힘 \(u\)가 걸린다(\(\ddot x_1 = u\), \(\ddot x_2 = u\)). 가제어성 행렬의 계수는?
    답

    상태 4개인데 \(B = (0,1,0,1)^T\), \(AB = (1,0,1,0)^T\), \(A^2B = 0\)이므로 계수는 2이다. \(x_1 - x_2\)는 바꿀 수 없다.

심화

  1. 예제에서 극점을 −4, −4로 옮기면 이득은? 이득과 극점 거리의 관계를 말하여라.
    답

    \((s + 4)^2\)에서 \(k_1\) = 16, \(k_2\) = 8이다. 극점을 두 배 멀리 보내면 위치 이득이 4배라, 빠른 응답은 큰 입력을 요구한다.
