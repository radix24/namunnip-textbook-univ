근궤적과 PID 이득 조정

본문
이 절에서 배울 것
  • 이득 \(K\)를 0에서 무한대로 키울 때 폐루프 극점이 그리는 길(근궤적)의 뜻을 안다.
  • 작도 규칙(시작·끝, 실수축 구간, 점근선, 이탈점, 허수축 교차)으로 근궤적을 어림한다.
  • 원하는 감쇠비의 극점을 주는 이득을 찾고, P·I·D 동작이 극점을 어떻게 옮기는지 안다.
먼저 알아야 할 것
  • 2차 응답 지표와 극점 (2.2절), Routh 판별법 (3.1절).

4.1.1근궤적이란

루프 전달함수 \(KG(s)H(s)\)에서 폐루프 극점은 \(1 + KGH = 0\)의 근입니다. \(K\)를 바꾸며 근을 \(s\)평면에 찍으면 곡선이 되고, 이것이 근궤적입니다. 근궤적 위의 점은 \(GH\)의 각이 180°(홀수 배)인 점이고, 그 점의 \(K = 1/|GH|\)입니다.

작도 규칙 (요약)
  1. 개루프 극점(\(K = 0\))에서 출발해 개루프 영점 또는 무한대(\(K \to \infty\))로 간다.
  2. 실수축에서는 오른쪽에 있는 극점·영점 수의 합이 홀수인 구간이 근궤적.
  3. 무한대로 가는 가지 수 \(n - m\), 점근선 각 \(\pm180°(2k + 1)/(n - m)\), 중심 \((\sum\text{극점} - \sum\text{영점})/(n - m)\).
  4. 두 극점 사이에서 갈라지는 이탈점은 \(dK/ds = 0\).
  5. 허수축과 만나는 점과 이득은 Routh 표로.
예제 4.1.1 (3차 계의 근궤적)

\(KG = K/[s(s + 2)(s + 4)]\)의 근궤적을 어림하고, 우세 극점의 감쇠비가 0.5가 되는 \(K\)를 구하여라.

풀이. 극점 0, −2, −4에서 출발, 영점 없음 → 세 가지 모두 무한대로. 실수축 구간: 0~−2, −4 왼쪽. 점근선 중심 \(-6/3 = -2\), 각 60°, 180°, 300°. 이탈점 \(3s^2 + 12s + 8 = 0\)에서 \(s = -0.85\)(\(K = 3.08\)). 허수축 교차 \(\pm2.83i\)(\(K = 48\), 3.1절). 감쇠비 0.5 선(실수축과 120°)과 만나는 점을 각 조건으로 찾으면 \(s = -0.67 \pm 1.15i\), \(K = 8.3\). 셋째 극점은 \(-6 - 2(-0.67) = -4.67\)로 멀리 있어 우세 극점 근사가 맞습니다.

4.1.2PID와 극점

P(비례): \(K_P\)를 키우면 근궤적을 따라 극점이 움직여 빨라지지만 감쇠가 줄고, 결국 불안정.

I(적분): 원점에 극점을 더해 정상상태 오차를 없앤다. 근궤적을 오른쪽으로 끌어 안정성을 해치기 쉬워 작게 쓴다.

D(미분): 영점을 더해 근궤적을 왼쪽으로 끌어당겨 감쇠와 안정 여유를 늘린다. 잡음을 키우므로 필터와 함께 쓴다.

실무에서는 Ziegler-Nichols 규칙(한계 이득 \(K_u\)와 진동 주기 \(T_u\)로 \(K_P = 0.6K_u\), \(T_i = T_u/2\), \(T_d = T_u/8\))로 출발해 응답을 보며 조정합니다. 예제 계는 \(K_u = 48\), \(T_u = 2\pi/2.83 = 2.22\) s입니다(PID 실습).

주의(1) 우세 극점 근사는 다른 극점이 우세 극점보다 실수부가 5배 정도 이상 왼쪽에 있을 때 잘 맞습니다. (2) 폐루프 영점은 근궤적에 나타나지 않지만 응답 모양(오버슈트)에 영향을 줍니다.
요약
  1. 근궤적: \(K\)에 따른 폐루프 극점의 길, 각 조건 180°, \(K = 1/|GH|\).
  2. 규칙으로 어림하고 원하는 감쇠비 선과의 교점에서 \(K\).
  3. P: 빨라짐·감쇠 감소, I: 오차 제거·안정성 감소, D: 감쇠 증가.

4.1.3연습문제

기본

  1. \(K/[s(s + 4)]\)의 근궤적에서 이탈점과, 그 뒤 극점이 움직이는 방향은?
    답

    극점 0, −4 사이 중점 −2에서 만나(\(K = 4\)) 위아래로 갈라져 실수부 −2인 수직선을 따라 올라간다.

응용

  1. 1번 계에서 감쇠비 0.707을 주는 \(K\)는?
    답

    극점 \(-2 \pm 2i\), \(K = |s||s + 4| = \sqrt8\times\sqrt8 = 8\).

심화

  1. 예제 계에 Ziegler-Nichols PID를 쓰면 \(K_P\), \(K_I\), \(K_D\)는?
    답

    \(K_P = 28.8\), \(T_i = 1.11\) s → \(K_I = K_P/T_i = 25.9\), \(T_d = 0.28\) s → \(K_D = K_PT_d = 8.0\). 보통 오버슈트가 커서 이득을 낮춰 다듬는다.
