피드포워드를 더한 제어계의 전달함수

예제 · 전방 경로 두 개 · 정상상태 오차
문제 해결 전략 · 경로와 루프를 모두 적는다
  1. 기준 입력에서 출력까지 전방 경로를 모두 찾는다.
  2. 루프와 각 경로의 접촉 여부를 확인한다.
  3. Mason 공식에 넣고 DC 이득으로 효과를 본다.

문제. 플랜트 \(G = 2/(s + 2)\)에 비례 제어기 \(K\) = 8을 피드백으로 쓰고, 기준 입력 \(r\)을 이득 \(G_{ff}\)로 플랜트 입력에 직접 더한다(\(u = Ke + G_{ff}r\)). 전달함수 \(Y/R\)과, \(G_{ff}\) = 0일 때와 1일 때 계단 응답의 정상상태 값은?

전략

경로 \(P_1 = KG\), \(P_2 = G_{ff}G\), 루프 \(L_1 = -KG\).

풀이

  1. 두 경로 모두 루프(플랜트 마디)에 닿으므로 \(\Delta_1 = \Delta_2 = 1\).
    공유 마디.
  2. \(T = (K + G_{ff})G/(1 + KG)\).
    Mason.
  3. \(G(0) = 1\): \(G_{ff} = 0\)이면 \(T(0) = 8/9 = 0.889\)(오차 11%), \(G_{ff} = 1\)이면 \(9/9 = 1\)(오차 0).
    \(G_{ff} = 1/G(0)\).

검산

정상상태에서 \(y = 1\)이면 \(e = 0\)이라 \(u = G_{ff}r = 1\)이고, \(G(0) = 1\)이므로 \(y = 1\)로 스스로 맞다.

의미

피드포워드는 필요한 입력을 미리 넣어 주고, 피드백은 모델 오차와 외란만 고친다. 적분기 없이도 정상상태 오차를 없앨 수 있지만, 플랜트 이득을 정확히 알아야 한다. 루프 \(\Delta\)는 바뀌지 않으므로 안정성은 피드포워드와 무관하다.

바꿔 보기

실제 플랜트 DC 이득이 1.2로 20% 틀리면 \(T(0) = 1.2\times9/(1 + 9.6) = 1.019\), 오차 1.9%이다. 피드포워드만 썼다면 20% 오차였을 것을 피드백이 약 10분의 1로 줄이다.

이해 확인

피드포워드 없이 오차를 2% 이하로 하려면 \(K\)는?

답

\(1/(1 + K) \le 0.02\)에서 \(K \ge 49\).
