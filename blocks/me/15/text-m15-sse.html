정상상태 오차와 시스템 형

본문
이 절에서 배울 것
  • 오래 지난 뒤 남는 오차를 최종값 정리로 구한다.
  • 루프 전달함수가 원점에 가진 극점 수(시스템 형)와 위치·속도 오차 상수의 관계를 안다.
  • 적분 동작이 정상상태 오차를 없애는 이유를 안다.
먼저 알아야 할 것
  • 블록선도와 폐루프 (2.1절), 안정도 (3.1절).

3.2.1최종값 정리

단위 피드백에서 오차 \(E = R/(1 + G)\)입니다. 안정한 계에서 \(t \to \infty\)의 값은 \(\lim_{s\to0}sE(s)\)로 구합니다(최종값 정리). 계단 입력 \(R = 1/s\), 램프 입력 \(R = 1/s^2\)을 넣으면 다음을 얻습니다.

정상상태 오차 \[e_{\text{계단}} = \frac{1}{1 + K_p},\ K_p = \lim_{s\to0}G(s);\] \[e_{\text{램프}} = \frac{1}{K_v},\ K_v = \lim_{s\to0}sG(s)\]

시스템 형 = \(G\)가 원점에 가진 극점(적분기) 수. 0형: 계단 오차 유한, 램프 무한. 1형: 계단 오차 0, 램프 유한. 2형: 램프 오차 0.

적분기가 하나 있으면 오차가 조금이라도 남는 한 출력이 계속 커지므로, 계단 입력에서는 오차가 0이 될 때까지 멈추지 않습니다. PI 제어의 I가 정상상태 오차를 없애는 원리입니다.

예제 3.2.1 (0형과 1형)

(가) \(G = 10/[(s + 2)(s + 5)]\)의 계단 오차는? (나) \(G = K/[s(s + 2)(s + 4)]\)(\(K = 20\))의 계단·램프 오차는?

풀이. (가) 0형, \(K_p = 10/10 = 1\), 계단 오차 50%. 이득을 키우면 줄지만 0은 아니고, 너무 키우면 불안정합니다. (나) 1형이라 계단 오차 0. \(K_v = 20/8 = 2.5\), 단위 램프에 오차 0.4. \(K\)를 키우면 줄지만 3.1절에서 \(K < 48\)이 한계라 최소 \(8/48 = 0.17\)입니다. 오차와 안정성은 서로 맞바꾸는 관계입니다.

주의(1) 최종값 정리는 폐루프가 안정할 때만 씁니다. (2) 외란에 대한 정상 오차는 외란이 들어오는 위치 앞에 적분기가 있어야 0이 됩니다.
요약
  1. 계단 \(1/(1 + K_p)\), 램프 \(1/K_v\).
  2. 형이 하나 오를 때마다 한 단계 높은 입력까지 오차 0.
  3. 적분 동작으로 형을 올린다(안정성 확인 필요).

3.2.2연습문제

기본

  1. 예제 (가)에서 계단 오차를 10% 이하로 하려면 앞에 곱할 이득은?
    답

    \(K_p \ge 9\), 원래 1이므로 9배.

응용

  1. 예제 (나)에서 램프 오차 0.25를 원하면 \(K\)는? 안정한가?
    답

    \(K_v = 4\) → \(K = 32 < 48\), 안정.

심화

  1. 예제 (가)에 PI 제어기 \(K_P + K_I/s\)를 쓰면 계단 오차는? 그 대가는?
    답

    1형이 되어 계단 오차 0. 대가로 위상이 늦어져 오버슈트가 늘고 안정 여유가 줄 수 있어 \(K_I\)를 적당히 고른다.
