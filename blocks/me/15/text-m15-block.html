블록선도와 간략화

본문
이 절에서 배울 것
  • 신호가 흐르는 길을 블록(전달함수), 합산점, 분기점으로 그린다.
  • 직렬, 병렬, 피드백 연결을 하나의 전달함수로 바꾼다.
  • 폐루프 전달함수 \(G/(1 + GH)\)의 뜻과 피드백의 효과를 안다.
먼저 알아야 할 것
  • 전달함수 (1.1절).

2.1.1기본 연결

블록선도 간략화

직렬: \(G_1G_2\). 병렬(합): \(G_1 + G_2\).

음의 피드백(앞먹임 \(G\), 되먹임 \(H\)): \[\frac{Y}{R} = \frac{G}{1 + GH}\]

피드백 식은 이렇게 얻습니다. 오차 \(E = R - HY\), 출력 \(Y = GE\)이므로 \(Y = G(R - HY)\), 정리하면 \(Y(1 + GH) = GR\)입니다. \(GH\)를 루프 전달함수(고리 이득)라 합니다.

2.1.2간략화 요령

복잡한 선도는 합산점·분기점을 블록 앞뒤로 옮겨(옮길 때 해당 블록을 곱하거나 나눠 신호를 보존) 기본 연결만 남게 한 뒤 안쪽 고리부터 차례로 줄입니다. 신호 흐름도와 Mason 공식을 쓰면 여러 고리가 얽힌 경우를 한 번에 풀 수 있습니다.

예제 2.1.1 (모터 위치 제어)

비례 제어기 \(K\)가 DC 모터 위치 모델 \(G_p = \frac{10}{s(0.1s + 1)}\)를 구동하고, 위치 센서(이득 1)로 되먹인다. 폐루프 전달함수와 \(K = 2.5\)일 때 고유진동수·감쇠비는?

풀이. 앞먹임 \(KG_p\), \(H = 1\): \(\frac{Y}{R} = \frac{10K}{0.1s^2 + s + 10K} = \frac{100K}{s^2 + 10s + 100K}\). \(K = 2.5\)면 \(\omega_n^2 = 250\), \(\omega_n = 15.8\) rad/s, \(2\zeta\omega_n = 10\)에서 \(\zeta = 0.32\). 제어기 이득으로 폐루프 극점(응답의 빠르기와 감쇠)을 옮길 수 있습니다(2.2절, 4단원).

2.1.3피드백의 효과

루프 이득 \(GH\)가 크면 \(Y/R \approx 1/H\)로, 플랜트 \(G\)가 조금 바뀌어도(부하, 온도, 노화) 출력이 거의 영향을 받지 않습니다. 외란이 플랜트에 들어와도 \(1/(1 + GH)\)배로 줄어듭니다. 대가로 이득이 크면 진동하거나 불안정해질 수 있어(3단원) 그 사이 균형을 찾는 것이 제어 설계입니다.

주의(1) 피드백 부호를 확인합니다. 양의 피드백이면 \(G/(1 - GH)\)입니다. (2) 블록선도는 신호의 흐름이지 에너지나 물질의 흐름이 아닙니다.
요약
  1. 직렬 곱, 병렬 합, 피드백 \(G/(1 + GH)\).
  2. 합산점·분기점을 옮겨 안쪽 고리부터 줄인다.
  3. 큰 루프 이득: 플랜트 변화·외란에 둔감, 대신 안정성 주의.

2.1.4연습문제

기본

  1. \(G = 5/(s + 1)\), \(H = 1\)인 폐루프 전달함수와 정상 상태 이득은?
    답

    \(5/(s + 6)\), 정상 이득 \(5/6 = 0.83\).

응용

  1. 예제에서 감쇠비 0.5를 얻으려면 \(K\)는?
    답

    \(2\zeta\omega_n = 10\) → \(\omega_n = 10\), \(100K = 100\), \(K = 1\).

심화

  1. 1번 계에서 플랜트 이득이 5에서 4로 20% 떨어지면 폐루프 정상 이득은 몇 % 바뀌는가?
    답

    \(4/5 = 0.80\), 0.833에서 4% 감소. 피드백이 플랜트 변화를 5분의 1로 줄였다.
