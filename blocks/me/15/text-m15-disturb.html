  • 정상상태 오차와 최종값 정리 (3.2절).

3.3.1외란 전달함수

제어기 \(C\), 플랜트 \(G\)의 단위 피드백 계에서 플랜트 입력에 외란 \(d\)(마찰, 경사 하중 등)가 더해지면

외란 응답

\[\frac YD = \frac G{1 + CG},\qquad \frac ER = S = \frac1{1 + CG}\]

계단 외란의 정상상태 출력은 \(G(0)/(1 + C(0)G(0))\). 제어기에 적분기가 있으면 \(C(0) \to \infty\)라 0이 된다.

감도 함수 \(S\)는 플랜트 변화가 폐루프에 미치는 비율이기도 합니다(\(dT/T = S\,dG/G\)). 루프 이득이 큰 주파수에서는 외란과 모델 오차가 함께 줄어듭니다.

예제 3.3.1 (컨베이어 속도)

\(G = 1/(s + 1)\), 비례 제어 \(K\) = 9. 크기 1인 계단 부하 외란이 플랜트 입력에 걸리면 속도는 정상상태에서 얼마나 떨어지는가? PI 제어 \(C = 9 + 5/s\)이면?

풀이. 비례: \(Y_{ss} = 1/(1 + 9) = 0.1\), 제어 없을 때(1)의 10분의 1입니다. PI: \(C(0) = \infty\)라 \(Y_{ss} = 0\), 적분기가 외란을 상쇄할 만큼 입력을 계속 키웁니다.

주의모든 주파수에서 \(S\)를 작게 할 수는 없습니다. 안정한 계에서 \(\log|S|\)의 주파수 적분은 0 이상이라(Bode 감도 적분), 낮은 주파수에서 외란을 줄이면 높은 주파수 어딘가에서 \(|S| > 1\)로 오히려 키우게 됩니다(물침대 효과).
요약
  1. \(Y/D = G/(1 + CG)\).
  2. 적분기가 계단 외란을 정상상태에서 없앤다.
  3. \(S = 1/(1 + L)\): 외란·모델 오차 감쇠율, 전 대역에서 작게 할 수는 없음.

3.3.2연습문제

기본

  1. 예제에서 외란 영향을 2% 이하로 하려면 비례 이득은?
    답

    \(1/(1 + K) \le 0.02\), \(K \ge 49\).

응용

  1. 외란이 플랜트 출력에 직접 더해지면(\(Y = GU + D\)) 비례 제어 \(K\) = 9에서 정상상태 영향은?
    답

    \(Y/D = 1/(1 + KG) = S\), \(1/10 = 0.1\).

심화

  1. 예제 비례 제어에서 플랜트 이득이 1에서 0.8로 20% 줄면 폐루프 DC 이득 \(T(0) = KG/(1 + KG)\)은 몇 % 바뀌는가? \(S\)로 어림한 값과 비교하여라.
    답

    정확히 \(0.9\to7.2/8.2 = 0.878\), 2.4% 감소. \(S(0) = 0.1\)이라 어림 \(0.1\times20\% = 2\%\)로 비슷하다.
