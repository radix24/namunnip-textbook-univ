적분 상태로 모터 속도 오차 없애기

예제 · 확장 상태 · 극점 배치
문제 해결 전략 · 상태를 하나 늘린다
  1. 오차 적분 \(z\)를 상태로 더한 확장 방정식을 쓴다.
  2. \(u = -k_1x + k_iz\)로 폐루프 특성식을 구한다.
  3. 원하는 극점과 계수를 비교해 이득을 정하고 정상상태를 확인한다.

문제. 모터 속도 \(\dot x = -x + u\)(\(y = x\))에 적분 동작을 더한 상태 피드백을 설계해 폐루프 극점을 −2, −2에 두어라. 플랜트 이득이 0.8배로 바뀌어도(\(\dot x = -x + 0.8u\)) 정상상태 오차가 0인지 확인하여라.

전략

\(\dot z = r - x\), \(u = -k_1x + k_iz\).

풀이

  1. \(\dot x = -(1 + k_1)x + k_iz\), \(\dot z = -x + r\).
    확장 상태 \((x, z)\).
  2. 특성식 \(s^2 + (1 + k_1)s + k_i = s^2 + 4s + 4\)에서 \(k_1\) = 3, \(k_i\) = 4.
    계수 비교.
  3. 이득 0.8: 특성식 \(s^2 + 3.4s + 3.2\)(극점 −1.7 ± 0.56j, 안정). 정상상태에서 \(\dot z = 0\)이므로 \(x = r\), 오차 0.
    적분기가 보장.

검산

적분 없이 \(u = -k_1x + Nr\)로 \(N\)을 맞춘 경우(\(k_1\) = 3, \(N\) = 4)라면, 이득 0.8에서 정상상태 \(x = 0.8\times4/(1 + 2.4)\,r = 0.94r\)로 6% 오차가 남습니다. 적분 상태가 이 오차를 없앱니다.

의미

상태 피드백에 적분 상태를 더한 구조는 PI 제어를 상태공간에서 체계적으로 설계한 것입니다. 상태가 많아져도 극점 배치나 최적 제어(LQR)를 같은 방식으로 확장 상태에 적용합니다.

바꿔 보기

극점을 −4, −4로 빠르게 하면 \(k_1\) = 7, \(k_i\) = 16입니다. 계단 기준 입력 순간 \(u = -7x + 16z\)는 처음에 0이지만, 적분이 빠르게 쌓여 구동기 포화를 확인해야 합니다.

이해 확인

확장 계 \(A_a = \begin{bmatrix}-1&0\\-1&0\end{bmatrix}\), \(B_a = \begin{bmatrix}1\\0\end{bmatrix}\)이 가제어한지 판정하여라.

답

\(A_aB_a = (-1, -1)^T\), \([B_a\ A_aB_a] = \begin{bmatrix}1&-1\\0&-1\end{bmatrix}\)의 행렬식 −1 ≠ 0이라 가제어.
