전달함수: 질량-스프링-감쇠기와 DC 모터

본문
이 절에서 배울 것
  • 미분방정식을 Laplace 변환하면 미분이 \(s\) 곱하기가 되어 대수식이 된다는 것을 안다.
  • 입력과 출력의 비인 전달함수를 정의하고 질량-스프링-감쇠기 계의 전달함수를 구한다.
  • DC 모터의 전기·기계 방정식을 합쳐 전압-속도 전달함수를 구한다.
먼저 알아야 할 것
  • 질량-스프링-감쇠기 운동 방정식 (기계진동 1.1절), 옴의 법칙과 기전력(고등학교 물리).

1.1.1Laplace 변환과 \(s\)

제어에서는 미분방정식을 그대로 풀기보다 Laplace 변환으로 바꿔 대수식으로 다룹니다. 변환의 계산 방법보다 중요한 성질은 다음 하나입니다.

미분 = \(s\) 곱하기: 처음 값이 0이면 \(\dot x \to sX(s)\), \(\ddot x \to s^2X(s)\). 적분은 \(1/s\) 곱하기.

전달함수 \(G(s) = Y(s)/U(s)\): 처음 상태가 0일 때 출력과 입력의 Laplace 변환 비. 시스템의 성질만 담고 입력과 무관하다.

왜 이렇게 하나 \(\dot x\)가 \(sX\)로 바뀌면 미분방정식이 \(X\)에 대한 일차식이 되어 나눗셈만으로 풀립니다. 여러 장치를 이어 붙인 계의 전체 전달함수는 각 전달함수를 곱하면 됩니다(2단원). 시간 응답은 표를 보고 되돌리거나 시뮬레이션으로 구합니다.

1.1.2질량-스프링-감쇠기

\(m\ddot x + c\dot x + kx = f(t)\)을 변환하면 \((ms^2 + cs + k)X = F\)이므로

\[G(s) = \frac{X(s)}{F(s)} = \frac{1}{ms^2 + cs + k} = \frac{1/m}{s^2 + 2\zeta\omega_ns + \omega_n^2}\]

입니다. 분모를 0으로 두는 근(극점)이 기계진동 2.1절의 특성 방정식 근과 같습니다. 극점이 응답의 모양(진동수, 감쇠)을 정합니다.

1.1.3DC 모터

전압 \(V\)를 넣으면 전기자 전류 \(i\)가 흘러 토크 \(K_ti\)를 내고, 회전하면 역기전력 \(K_e\omega\)가 생깁니다. 전기 회로와 회전 운동 방정식은

\[L\frac{di}{dt} + Ri = V - K_e\omega\] \[J\dot\omega + b\omega = K_ti\]

입니다(SI 단위에서 \(K_t = K_e = K\)). 인덕턴스 \(L\)이 작아 전기 응답이 기계 응답보다 훨씬 빠르면 \(L = 0\)으로 두고 \(i = (V - K\omega)/R\)을 넣어

DC 모터 전압-속도 전달함수 (\(L\) 무시) \[\frac{\Omega(s)}{V(s)} = \frac{K_m}{\tau s + 1}\] \[K_m = \frac{K}{Rb + K^2},\quad \tau = \frac{RJ}{Rb + K^2}\]
예제 1.1.1 (소형 DC 모터)

\(J = 2\times10^{-5}\) kg·m², \(b = 1\times10^{-5}\) N·m·s, \(K = 0.05\) N·m/A, \(R = 2\) Ω인 모터에 12 V를 갑자기 걸었다. 정상 속도와 시간 상수는?

풀이. \(Rb + K^2 = 2\times10^{-5} + 0.0025 = 0.00252\). \(K_m = 19.8\) rad/(s·V), 정상 속도 238 rad/s(2270 rpm). \(\tau = 4\times10^{-5}/0.00252 = 0.016\) s. 약 0.05 s(3τ) 만에 거의 정상 속도에 이릅니다. 역기전력(\(K^2\) 항)이 마찰(\(Rb\))보다 훨씬 커서 속도를 주로 정합니다.

주의(1) 전달함수는 선형·시불변 계에만 정의됩니다(비선형은 1.2절에서 선형화). (2) 위치를 출력으로 하면 속도를 한 번 적분해 \(\Theta/V = K_m/[s(\tau s + 1)]\)이 됩니다.
요약
  1. 미분 → \(s\), \(G = Y/U\).
  2. 질량-스프링-감쇠기 \(1/(ms^2 + cs + k)\).
  3. DC 모터 \(K_m/(\tau s + 1)\), \(K_m = K/(Rb + K^2)\), \(\tau = RJ/(Rb + K^2)\).

1.1.4연습문제

기본

  1. \(m = 1\), \(c = 2\), \(k = 20\)인 계의 \(\omega_n\)과 \(\zeta\)는?
    답

    \(\omega_n = 4.47\) rad/s, \(\zeta = 2/(2\times4.47) = 0.224\).

응용

  1. 예제 모터에 관성 모멘트 \(8\times10^{-5}\) kg·m² 원판을 달면 시간 상수는?
    답

    \(J = 10^{-4}\), \(\tau = 2\times10^{-4}/0.00252 = 0.079\) s. 정상 속도는 그대로.

심화

  1. 예제 모터 축을 손으로 꽉 잡아 멈추면(\(\omega = 0\)) 흐르는 전류와 토크는? 왜 모터가 뜨거워지는가?
    답

    역기전력이 0이라 \(i = 12/2 = 6\) A, 토크 0.3 N·m(구속 토크). 정상 운전 전류(약 \((12 - 0.05\times238)/2 = 0.05\) A)의 100배 이상이 흘러 \(i^2R = 72\) W가 모두 열이 된다.
