2차원 절삭: 전단각과 절삭력

본문

선반으로 강봉을 깎으면 공구 앞에서 칩이 돌돌 말려 나온다. 그런데 칩을 재 보면 깎은 두께보다 두 배 넘게 두껍다. 금속은 공구 끝에서 어떻게 잘려 나가길래 두꺼워질까? 그리고 깎는 데 드는 힘과 동력은 어떻게 어림할까?

먼저 알아야 할 것힘의 분해와 마찰(공통 역학), 절삭 실험(기계공학실험(1) 4.1절)을 쓴다.

3.1.1직교 절삭 모델

날이 이동 방향에 수직인 공구가 두께 \(t_0\)를 깎는다고 하자. 그러면 재료는 공구 끝에서 비스듬히 뻗은 얇은 면, 곧 전단면에서 전단되어 더 두꺼운 칩(\(t_c\))이 되고, 공구 경사면을 타고 올라간다(그림 1). 처음 질문의 첫째 답이 이것이다. 이때 경사면이 수직에서 기운 각이 경사각 α, 전단면이 이동 방향과 이루는 각이 전단각 φ이다.

칩 두께 비와 전단각

\[r = \frac{t_0}{t_c}, \qquad \tan\phi = \frac{r\cos\alpha}{1 - r\sin\alpha}\]

전단각이 클수록 전단면이 짧아 적은 힘으로 깎인다. 그리고 경사각을 키우거나 공구와 칩 사이의 마찰을 줄이면(윤활, 날카로운 공구) 전단각이 커진다.

3.1.2힘

공구 동력계로 이동 방향의 절삭력 \(F_c\)와 그에 수직인 배분력 \(F_t\)를 잰다. 그러면 나머지 힘은 기하로 구한다. 처음 질문의 둘째 답이 이것이다.

절삭의 힘과 동력

경사면의 마찰각은 \(\beta = \alpha + \arctan(F_t/F_c)\), 전단력은 \(F_s = F_c\cos\phi - F_t\sin\phi\)이다.

절삭 동력은 \(P = F_cV\)이고, 비절삭 에너지는 \(F_c/(t_0w)\)이다.

한편 Merchant는 절삭 에너지가 최소가 되도록 전단각이 정해진다고 보아 \(\phi = 45° + \alpha/2 - \beta/2\)를 얻었다. 경향은 맞지만, 실제 값은 이보다 작은 경우가 많다.

예제 3.1.1 (측정값으로 해석)

경사각 10°, 절삭 두께 0.2 mm, 폭 4 mm로 강을 깎았더니 칩 두께 0.5 mm, \(F_c\) = 1000 N, \(F_t\) = 400 N이었다. 전단각, 마찰각, 전단력, Merchant 예측과 비교, 절삭 속도 150 m/min일 때 동력은?

풀이. r = 0.4이므로 \(\tan\phi = 0.4\times0.985/(1 - 0.4\times0.174) = 0.423\), 곧 φ = 22.9°이다. 또 \(\beta = 10° + \arctan0.4 = 31.8°\)이고, \(F_s = 1000\cos22.9° - 400\sin22.9° = 765\) N이다. 그런데 Merchant 예측 45 + 5 − 15.9 = 34.1°는 측정값보다 크다. 마지막으로 동력은 1000 × 2.5 = 2.5 kW, 비절삭 에너지는 1000/(0.2 × 4) = 1250 N/mm², 곧 1.25 J/mm³이다.

흔한 오해2차원 모델은 실제 선삭과 너무 달라 쓸모없다고 여기기 쉽다. 실제 선삭은 날이 비스듬한 3차원 절삭이지만, 직교 모델로도 힘과 동력의 크기를 충분히 어림한다. 다만 공구 끝에 붙는 구성인선이나, 칩이 연속인지(연성 재료) 끊어지는지(주철)가 결과에 영향을 준다.
마무리

칩 두께 비는 r = t₀/t_c이고 전단각은 tan φ = r cos α/(1 − r sin α)이다. 마찰각은 β = α + arctan(F_t/F_c), 전단력은 F_s = F_c cos φ − F_t sin φ이다. 동력은 F_cV이며, Merchant 식은 경향만 맞는다.

3.1.3연습문제

기본

  1. 경사각 0°, 칩 두께 비 0.5이면 전단각은?
    답

    \(\tan\phi = 0.5\), \(\phi = 26.6°\)이다.

응용

  1. 예제에서 전단면의 넓이와 평균 전단 응력은? (전단면 길이 \(t_0/\sin\phi\))
    답

    넓이 \(0.2\times4/\sin22.9° = 2.06\) mm², \(\tau = 765/2.06 = 372\) MPa. 큰 변형 속도에서의 전단 유동 응력에 해당한다.

심화

  1. 예제에서 윤활로 칩 두께가 0.4 mm로 줄었다. 전단각은 어떻게 되며, 절삭력은 대략 어떻게 변하겠는가?
    답

    \(r = 0.5\), \(\tan\phi = 0.492/0.913 = 0.539\), \(\phi = 28.3°\). 전단면이 짧아져 전단 응력이 같다면 전단력이 약 \(\sin22.9°/\sin28.3° = 0.82\)배로 줄고 절삭력도 대략 그만큼 줄어든다.
