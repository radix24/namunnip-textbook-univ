2차원 절삭: 전단각과 절삭력

본문
이 절에서 배울 것
  • 2차원(직교) 절삭 모델의 용어(경사각, 전단면, 칩 두께 비)를 안다.
  • 칩 두께 비로 전단각을 구한다.
  • 절삭력과 배분력에서 마찰각, 전단력, 절삭 동력을 구한다.
먼저 알아야 할 것
  • 힘의 분해와 마찰(공통 역학), 절삭 실험 (기계공학실험(1) 4.1절).

3.1.1직교 절삭 모델

날이 이동 방향에 수직인 공구가 두께 \(t_0\)를 깎으면, 재료는 공구 끝에서 비스듬히 뻗은 얇은 면(전단면)에서 전단되어 더 두꺼운 칩(\(t_c\))이 되어 공구 경사면을 타고 올라갑니다. 경사면이 수직에서 기운 각이 경사각 \(\alpha\), 전단면이 이동 방향과 이루는 각이 전단각 \(\phi\)입니다.

칩 두께 비와 전단각

\[r = \frac{t_0}{t_c}\]

\[\tan\phi = \frac{r\cos\alpha}{1 - r\sin\alpha}\]

전단각이 클수록 전단면이 짧아 적은 힘으로 깎입니다. 경사각을 키우거나 공구-칩 마찰을 줄이면(윤활, 날카로운 공구) 전단각이 커집니다.

3.1.2힘

공구 동력계로 이동 방향의 절삭력 \(F_c\)와 그에 수직인 배분력 \(F_t\)를 잽니다. 경사면의 마찰각 \(\beta\)는 \(\beta = \alpha + \arctan(F_t/F_c)\)이고, 전단면을 따라가는 전단력은 \(F_s = F_c\cos\phi - F_t\sin\phi\)입니다. 절삭 동력은 \(P = F_cV\), 단위 부피당 에너지(비절삭 에너지)는 \(F_c/(t_0w)\)입니다.

Merchant는 절삭 에너지가 최소가 되도록 전단각이 정해진다고 보아 \(\phi = 45° + \alpha/2 - \beta/2\)를 얻었습니다. 경향은 맞지만 실제 값은 이보다 작은 경우가 많습니다.

예제 3.1.1 (측정값으로 해석)

경사각 10°, 절삭 두께 0.2 mm, 폭 4 mm로 강을 깎았더니 칩 두께 0.5 mm, \(F_c\) = 1000 N, \(F_t\) = 400 N이었다. 전단각, 마찰각, 전단력, Merchant 예측과 비교, 절삭 속도 150 m/min일 때 동력은?

풀이. \(r = 0.4\), \(\tan\phi = 0.4\times0.985/(1 - 0.4\times0.174) = 0.423\), \(\phi = 22.9°\). \(\beta = 10° + \arctan0.4 = 31.8°\). \(F_s = 1000\cos22.9° - 400\sin22.9° = 765\) N. Merchant 예측 \(45 + 5 - 15.9 = 34.1°\)는 측정값보다 큽니다. 동력 \(1000\times2.5 = 2.5\) kW, 비절삭 에너지 \(1000/(0.2\times4) = 1250\) N/mm² = 1.25 J/mm³.

주의실제 선삭은 날이 비스듬한 3차원 절삭이지만, 직교 모델로 힘과 동력의 크기를 어림하는 데 충분합니다. 공구 끝에 붙는 구성인선이나 칩이 연속인지(연성 재료) 끊어지는지(주철)도 결과에 영향을 줍니다.
요약
  1. \(r = t_0/t_c\), \(\tan\phi = r\cos\alpha/(1 - r\sin\alpha)\).
  2. \(\beta = \alpha + \arctan(F_t/F_c)\), \(F_s = F_c\cos\phi - F_t\sin\phi\).
  3. 동력 \(F_cV\). Merchant 식은 경향만.

3.1.3연습문제

기본

  1. 경사각 0°, 칩 두께 비 0.5이면 전단각은?
    답

    \(\tan\phi = 0.5\), \(\phi = 26.6°\).

응용

  1. 예제에서 전단면의 넓이와 평균 전단 응력은? (전단면 길이 \(t_0/\sin\phi\))
    답

    넓이 \(0.2\times4/\sin22.9° = 2.06\) mm², \(\tau = 765/2.06 = 372\) MPa. 큰 변형 속도에서의 전단 유동 응력에 해당한다.

심화

  1. 예제에서 윤활로 칩 두께가 0.4 mm로 줄었다. 전단각은 어떻게 되며, 절삭력은 대략 어떻게 변하겠는가?
    답

    \(r = 0.5\), \(\tan\phi = 0.492/0.913 = 0.539\), \(\phi = 28.3°\). 전단면이 짧아져 전단 응력이 같다면 전단력이 약 \(\sin22.9°/\sin28.3° = 0.82\)배로 줄고 절삭력도 대략 그만큼 줄어든다.
