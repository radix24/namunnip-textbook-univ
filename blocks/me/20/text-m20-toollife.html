Taylor 공구 수명식과 절삭 속도 결정

본문
이 절에서 배울 것
  • 공구 마모의 형태와 수명 판정 기준을 안다.
  • Taylor 식 \(VT^n = C\)로 속도에 따른 수명을 계산한다.
  • 최소 원가 속도와 최대 생산율 속도를 구한다.
먼저 알아야 할 것
  • 절삭 모델 (3.1절), 로그 그래프와 미분으로 최솟값 찾기.

3.2.1공구 마모

공구는 칩과 공작물에 문질러지고 높은 온도(수백 °C)에 놓여 닳습니다. 여유면이 닳는 플랭크 마모와 경사면이 패이는 크레이터 마모가 대표적이며, 보통 플랭크 마모 폭이 정해진 값(예: 0.3 mm)에 이르면 수명이 다한 것으로 봅니다. 마모가 커지면 치수가 틀어지고 표면이 거칠어지며 절삭력과 열이 늘어납니다.

3.2.2Taylor 식

절삭 속도를 높이면 온도가 올라 마모가 급격히 빨라집니다. Taylor는 실험으로 다음 관계를 찾았습니다.

Taylor 공구 수명식

\[ VT^n = C \]

\(V\): 절삭 속도(m/min), \(T\): 공구 수명(min), \(C\): 수명 1분인 속도. \(n\): 고속도강 약 0.1~0.15, 초경 0.2~0.3, 세라믹 0.4~0.6.

로그를 취하면 \(\log V + n\log T = \log C\)로, 양 로그 그래프에서 직선입니다. 두 속도에서 수명을 재면 \(n\)과 \(C\)를 구할 수 있습니다.

3.2.3경제적 절삭 속도

부품당 원가 = 기계·인건비(취급 + 가공 시간) + 공구 관련 비용(공구 교환 시간 + 공구비)입니다. 속도를 높이면 앞쪽은 줄고 뒤쪽은 늘어나므로 원가가 최소인 속도가 있습니다. 미분해서 0으로 두면

최적 공구 수명

최소 원가: \(T = \left(\dfrac1n - 1\right)\left(t_c + \dfrac{C_t}{M}\right)\). 최대 생산율: \(T = \left(\dfrac1n - 1\right)t_c\).

\(t_c\): 공구 교환 시간, \(C_t\): 공구 날 하나 비용, \(M\): 분당 기계·인건비.

예제 3.2.1 (초경 공구)

\(n = 0.25\), \(C = 400\) m/min인 초경 공구에서 \(t_c = 2\) min, \(C_t = 12000\)원, \(M = 2000\)원/min이다. 200 m/min의 수명, 최소 원가 속도, 최대 생산율 속도는?

풀이. 200 m/min: \(T = (400/200)^4 = 16\) min. 최소 원가: \(T = 3\times(2 + 6) = 24\) min, \(V = 400/24^{0.25} = 181\) m/min. 최대 생산율: \(T = 3\times2 = 6\) min, \(V = 400/6^{0.25} = 256\) m/min. 실습에서 원가 곡선과 함께 확인할 수 있습니다.

주의Taylor 식은 이송과 절삭 깊이를 고정한 결과입니다. 이송을 늘리는 것이 속도를 올리는 것보다 공구 수명을 덜 깎으므로, 먼저 이송과 깊이를 기계 출력과 표면 거칠기가 허락하는 만큼 키우고 속도를 정합니다.
요약
  1. \(VT^n = C\), 양 로그 직선.
  2. 최소 원가 \(T = (1/n - 1)(t_c + C_t/M)\).
  3. 최대 생산율 \(T = (1/n - 1)t_c\), 더 빠른 속도.

3.2.4연습문제

기본

  1. 예제 공구로 수명 60분을 얻으려면 속도는?
    답

    \(400/60^{0.25} = 143\) m/min.

응용

  1. 시험에서 150 m/min일 때 수명 40분, 250 m/min일 때 5분이었다. \(n\)과 \(C\)는?
    답

    \(n = \ln(250/150)/\ln(40/5) = 0.511/2.079 = 0.246\). \(C = 150\times40^{0.246} = 372\) m/min.

심화

  1. 최소 원가 공구 수명 식을 유도하여라. (힌트: 부품당 공구 비용은 \((t_m/T)(Mt_c + C_t)\), \(t_m ∝ 1/V\), \(T = (C/V)^{1/n}\))
    답

    원가 \(= M(t_h + k/V) + (k/V)(V/C)^{1/n}(Mt_c + C_t)\). \(V\)로 미분해 0으로 두면 \(Mk/V^2 = (1/n - 1)(k/V^2)(V/C)^{1/n}(Mt_c + C_t)\). \((V/C)^{1/n} = 1/T\)이므로 \(T = (1/n - 1)(t_c + C_t/M)\).
