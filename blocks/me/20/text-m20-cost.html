고정비, 변동비, 단위 원가

본문

같은 알루미늄 하우징을 CNC로 깎으면 금형이 필요 없지만 개당 값이 비싸고, 다이캐스팅으로 만들면 개당 값은 싸지만 금형에 수천만 원이 든다. 몇 개를 만들 때부터 금형을 사는 편이 이득일까? 수량이 늘면 단위 원가는 어떻게 변할까?

먼저 알아야 할 것공정의 특징(1.1절, 5.1절), 일차함수를 쓴다.

6.2.1두 종류의 비용

고정비는 수량과 관계없이 드는 비용으로, 금형, 지그, 설비 투자, 프로그래밍이 여기에 든다. 반면 변동비는 개당 드는 비용으로, 재료, 가공 시간, 에너지, 공구 마모가 여기에 든다. 그러면 수량 Q일 때 비용은 아래와 같다.

총비용과 단위 원가

\[C_{\text{총}} = F + vQ, \qquad c = \frac FQ + v\]

두 공정의 손익 분기 수량은 \(Q^* = \dfrac{F_2 - F_1}{v_1 - v_2}\)이다.

수량이 늘면 고정비가 많은 개수로 나뉘어, 단위 원가가 변동비에 가까워진다. 처음 질문의 둘째 답이 이것이다. 그래서 금형이 비싼 다이캐스팅과 사출 성형이 대량 생산에서 싸진다.

예제 6.2.1 (공정 고르기)

알루미늄 하우징을 (A) CNC 절삭(지그와 프로그램 고정비 1000만원, 개당 5000원) 또는 (B) 다이캐스팅 + 간단 가공(금형 고정비 4000만원, 개당 2000원)으로 만들 수 있다. 손익 분기 수량은? 연 5000개, 2만 개일 때 각각 단위 원가는?

풀이. \(Q^* = (4000 - 1000)\text{만}/(5000 - 2000) = 10000\)개이다(그림 1). 처음 질문의 첫째 답이 이것이다. 5000개면 A는 2000 + 5000 = 7000원, B는 8000 + 2000 = 10000원이므로 A가 싸다. 그런데 2만 개면 A는 500 + 5000 = 5500원, B는 2000 + 2000 = 4000원이므로 B가 싸다.

흔한 오해단위 원가만 비교하면 공정을 고를 수 있다고 여기기 쉽다. 금형 제작에 몇 달이 걸리는 납기, 설계 변경 가능성, 품질 요구도 함께 따져야 한다. 그래서 시장 반응이 불확실한 초기에는 절삭이나 3D 프린팅으로 시작하고, 수량이 확정되면 금형으로 옮기는 전략을 흔히 쓴다.
마무리

단위 원가는 c = F/Q + v이다. 두 공정의 손익 분기 수량은 Q* = (F₂ − F₁)/(v₁ − v₂)이다. 수량이 적으면 고정비가 작은 공정이, 많으면 변동비가 작은 공정이 유리하다.

6.2.2연습문제

기본

  1. 고정비 300만원, 개당 1500원일 때 1000개와 1만 개의 단위 원가는?
    답

    1000개면 4500원, 1만 개면 1800원이다.

응용

  1. 예제에 (C) 3D 프린팅(고정비 0, 개당 25000원)을 더하면 C가 가장 싼 수량 범위는?
    답

    C와 A의 분기는 \(1000\text{만}/(25000 - 5000) = 500\)개. 500개 미만에서 C가 가장 싸다.

심화

  1. 예제의 금형은 2만 개마다 400만원을 들여 고쳐야 하고, 수명은 10만 개이다. 연 2만 개를 5년 만들 때 B의 단위 원가는?
    답

    총 10만 개이고 고정비 4000만 + 보수 4회 1600만 = 5600만이므로 단위 원가는 \(560 + 2000 = 2560\)원이다.
