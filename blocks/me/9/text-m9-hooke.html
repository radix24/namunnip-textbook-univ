일반화 Hooke 법칙: 세 방향 응력과 변형률 주고받기

본문
이 절에서 배울 것
  • 세 방향 응력이 있을 때 각 방향의 변형률을 구한다(Poisson 효과의 겹침).
  • 거꾸로 변형률에서 응력을 구하고, 막힌 방향에 생기는 응력을 이해한다.
  • 부피 변형률과 체적 탄성 계수, 세 탄성 상수의 관계를 안다.
먼저 알아야 할 것
  • Hooke 법칙과 Poisson 비 (고체역학 1단원), 3차원 응력 (1.1절).

1.2.1겹침으로 만드는 식

막대를 \(x\) 방향으로 당기면 \(x\)로 \(\sigma_x/E\)만큼 늘고, 옆 방향(\(y\), \(z\))으로는 Poisson 비 \(\nu\)만큼 줄어 \(-\nu\sigma_x/E\)입니다. 탄성 범위에서는 원인이 여럿이면 결과를 더해도 되므로(겹침), \(\sigma_x\), \(\sigma_y\), \(\sigma_z\)가 함께 있을 때 \(x\) 방향 변형률은 세 몫의 합입니다.

일반화 Hooke 법칙 (등방성 재료) \[\varepsilon_x = \frac{1}{E}\left[\sigma_x - \nu(\sigma_y + \sigma_z)\right]\] \[\varepsilon_y = \frac{1}{E}\left[\sigma_y - \nu(\sigma_z + \sigma_x)\right]\] \[\varepsilon_z = \frac{1}{E}\left[\sigma_z - \nu(\sigma_x + \sigma_y)\right]\] \[\gamma_{xy} = \frac{\tau_{xy}}{G},\quad \gamma_{yz} = \frac{\tau_{yz}}{G},\quad \gamma_{zx} = \frac{\tau_{zx}}{G}\] \[G = \frac{E}{2(1 + \nu)}\]

수직 응력은 전단 변형률을 만들지 않고, 전단 응력은 수직 변형률을 만들지 않습니다(등방성 재료에서). 그래서 수직 셋, 전단 셋이 따로 놉니다.

예제 1.2.1 (두 방향으로 당긴 강판)

강판(\(E = 200\) GPa, \(\nu = 0.3\))에 \(\sigma_x = 100\), \(\sigma_y = 50\) MPa, \(\sigma_z = 0\)이 작용한다. 세 방향 변형률은? \(z\) 방향을 단단한 벽으로 막아 \(\varepsilon_z = 0\)이 되게 하면 \(\sigma_z\)와 \(\varepsilon_x\)는?

풀이. \(\varepsilon_x = (100 - 0.3\times50)/200000 = 425\times10^{-6}\), \(\varepsilon_y = (50 - 30)/200000 = 100\times10^{-6}\), \(\varepsilon_z = -0.3\times150/200000 = -225\times10^{-6}\). 두께가 줄어듭니다. 막으면 \(\varepsilon_z = 0\)에서 \(\sigma_z = \nu(\sigma_x + \sigma_y) = 45\) MPa(벽이 미는 압축이 아니라, 판이 줄어들려는 것을 벽이 붙잡아 생기는 인장)이고, \(\varepsilon_x = (100 - 0.3\times95)/200000 = 357.5\times10^{-6}\)으로 줄어듭니다. 옆이 막히면 같은 하중에서 덜 늘어나, 더 단단해 보입니다.

평면 응력: \(\sigma_z = 0\)(얇은 판). \(\varepsilon_z\)는 0이 아니다.

평면 변형률: \(\varepsilon_z = 0\)(길고 두꺼운 물체, 댐, 긴 관). \(\sigma_z = \nu(\sigma_x + \sigma_y)\)가 생긴다.

1.2.2부피 변형률과 체적 탄성 계수

작은 정육면체의 부피 변화율은 세 변의 변형률의 합입니다(작은 변형에서 \((1+\varepsilon_x)(1+\varepsilon_y)(1+\varepsilon_z) \approx 1 + \varepsilon_x + \varepsilon_y + \varepsilon_z\)). 세 식을 더하면

\[e = \varepsilon_x + \varepsilon_y + \varepsilon_z = \frac{1 - 2\nu}{E}(\sigma_x + \sigma_y + \sigma_z)\]

입니다. 모든 방향에서 같은 압력 \(p\)를 받으면 \(e = -3(1 - 2\nu)p/E\)이고, 비 \(K = p/(-e) = E/[3(1 - 2\nu)]\)를 체적 탄성 계수라 합니다. \(\nu\)가 0.5에 가까우면(고무) \(K\)가 매우 커져 부피가 거의 변하지 않습니다. 그래서 \(\nu\)는 0.5를 넘을 수 없습니다.

거꾸로 변형률에서 응력을 구할 때는 세 식을 연립해 풀면 됩니다. 결과는

\[\sigma_x = \frac{E}{(1+\nu)(1-2\nu)}\left[(1-\nu)\varepsilon_x + \nu(\varepsilon_y + \varepsilon_z)\right]\]

이고 \(y\), \(z\)도 같은 꼴입니다(스트레인 게이지로 잰 변형률에서 응력을 구할 때 씁니다).

주의(1) 이 식은 등방성(방향에 따라 성질이 같은) 재료의 탄성 범위에서만 맞습니다. 복합재, 목재, 압연판은 방향마다 상수가 다릅니다. (2) 온도가 바뀌면 각 수직 변형률에 \(\alpha\Delta T\)를 더합니다. (3) 얇은 판의 표면에 붙인 게이지 두 개로 \(\varepsilon_x\), \(\varepsilon_y\)를 쟀다면 평면 응력 식 \(\sigma_x = \frac{E}{1-\nu^2}(\varepsilon_x + \nu\varepsilon_y)\)를 씁니다.
요약
  1. \(\varepsilon_x = [\sigma_x - \nu(\sigma_y + \sigma_z)]/E\), \(\gamma = \tau/G\), \(G = E/[2(1+\nu)]\).
  2. 막힌 방향(평면 변형률)에는 \(\sigma_z = \nu(\sigma_x + \sigma_y)\)가 생긴다.
  3. \(e = (1-2\nu)(\sigma_x+\sigma_y+\sigma_z)/E\), \(K = E/[3(1-2\nu)]\).

1.2.3연습문제

기본

  1. 알루미늄(\(E = 70\) GPa, \(\nu = 0.33\))의 \(G\)와 \(K\)는?
    답

    \(G = 70/2.66 = 26.3\) GPa, \(K = 70/(3\times0.34) = 68.6\) GPa.

응용

  1. 얇은 강판 표면의 게이지가 \(\varepsilon_x = 500\times10^{-6}\), \(\varepsilon_y = -150\times10^{-6}\)을 읽었다(\(E = 200\) GPa, \(\nu = 0.3\)). \(\sigma_x\), \(\sigma_y\)는?
    답

    \(E/(1-\nu^2) = 219.8\) GPa. \(\sigma_x = 219.8\times(500 - 45)\times10^{-6}\times10^3 = 100\) MPa, \(\sigma_y = 219.8\times(-150 + 150)\times10^{-3} = 0\). 한 방향 인장이었다.

심화

  1. 강 블록(\(E = 200\) GPa, \(\nu = 0.3\))을 \(y\), \(z\) 방향 모두 단단한 벽 사이에 끼우고 \(x\) 방향으로 100 MPa 압축했다. 옆 벽이 받는 응력과 \(x\) 방향 변형률은? 벽이 없을 때와 비교하여라.
    답

    \(\varepsilon_y = \varepsilon_z = 0\)에서 대칭으로 \(\sigma_y = \sigma_z = s\): \(s - 0.3(s - 100) = 0\) → \(s = -42.9\) MPa(압축). \(\varepsilon_x = [-100 - 0.3(-85.7)]/200000 = -371\times10^{-6}\). 벽이 없으면 \(-500\times10^{-6}\), 옆을 막으면 26% 덜 줄어든다.
