일반화 Hooke 법칙: 세 방향 응력과 변형률 주고받기

본문

강판을 x 방향으로만 당기면 x로 늘고 옆으로는 Poisson 비만큼 준다. 그런데 x와 y 두 방향으로 함께 당기면 각 방향의 변형률은 어떻게 될까? 또 두께 방향을 단단한 벽으로 막아 줄어들지 못하게 하면, 판은 같은 하중에서 덜 늘어날까?

먼저 알아야 할 것Hooke 법칙과 Poisson 비(고체역학 1단원), 3차원 응력(1.1절)을 쓴다.

1.2.1겹침으로 만드는 식

막대를 \(x\) 방향으로 당기면 \(x\)로 \(\sigma_x/E\)만큼 늘고, 옆 방향(\(y\), \(z\))으로는 Poisson 비 \(\nu\)만큼 줄어 \(-\nu\sigma_x/E\)가 된다. 탄성 범위에서는 원인이 여럿이면 결과를 더해도 되므로(겹침), \(\sigma_x\), \(\sigma_y\), \(\sigma_z\)가 함께 있을 때 \(x\) 방향 변형률은 세 몫의 합이다. 처음 질문의 첫째 답이 이것이다.

일반화 Hooke 법칙 (등방성 재료) \[\varepsilon_x = \frac{1}{E}\left[\sigma_x - \nu(\sigma_y + \sigma_z)\right]\] \[\varepsilon_y = \frac{1}{E}\left[\sigma_y - \nu(\sigma_z + \sigma_x)\right]\] \[\varepsilon_z = \frac{1}{E}\left[\sigma_z - \nu(\sigma_x + \sigma_y)\right]\] \[\gamma_{xy} = \frac{\tau_{xy}}{G},\quad \gamma_{yz} = \frac{\tau_{yz}}{G},\quad \gamma_{zx} = \frac{\tau_{zx}}{G}\] \[G = \frac{E}{2(1 + \nu)}\]

등방성 재료에서는 수직 응력이 전단 변형률을 만들지 않고, 전단 응력도 수직 변형률을 만들지 않는다. 그래서 수직 셋과 전단 셋이 따로 논다.

예제 1.2.1 (두 방향으로 당긴 강판)

강판(\(E = 200\) GPa, \(\nu = 0.3\))에 \(\sigma_x = 100\), \(\sigma_y = 50\) MPa, \(\sigma_z = 0\)이 작용한다. 세 방향 변형률은? \(z\) 방향을 단단한 벽으로 막아 \(\varepsilon_z = 0\)이 되게 하면 \(\sigma_z\)와 \(\varepsilon_x\)는?

풀이. \(\varepsilon_x = (100 - 0.3\times50)/200000 = 425\times10^{-6}\), \(\varepsilon_y = (50 - 30)/200000 = 100\times10^{-6}\), \(\varepsilon_z = -0.3\times150/200000 = -225\times10^{-6}\)이므로 두께가 줄어든다. 막으면 \(\varepsilon_z = 0\)에서 \(\sigma_z = \nu(\sigma_x + \sigma_y) = 45\) MPa이다. 이 응력은 벽이 미는 압축이 아니라, 판이 줄어들려는 것을 벽이 붙잡아 생기는 인장이다. 그러면 \(\varepsilon_x = (100 - 0.3\times95)/200000 = 357.5\times10^{-6}\)으로 줄어든다(그림 1). 즉 옆이 막히면 같은 하중에서 덜 늘어나 더 단단해 보이며, 처음 질문의 둘째 답이 이것이다.

이 두 경우에는 이름이 있다. 얇은 판처럼 \(\sigma_z = 0\)인 상태가 평면 응력이며, 이때 \(\varepsilon_z\)는 0이 아니다. 길고 두꺼운 물체, 댐, 긴 관처럼 \(\varepsilon_z = 0\)인 상태는 평면 변형률이며, \(\sigma_z = \nu(\sigma_x + \sigma_y)\)가 생긴다.

1.2.2부피 변형률과 체적 탄성 계수

작은 정육면체의 부피 변화율은 세 변의 변형률의 합이다. 작은 변형에서 \((1+\varepsilon_x)(1+\varepsilon_y)(1+\varepsilon_z) \approx 1 + \varepsilon_x + \varepsilon_y + \varepsilon_z\)이기 때문이다. 그래서 세 식을 더하면 부피 변형률을 얻는다.

\[e = \varepsilon_x + \varepsilon_y + \varepsilon_z = \frac{1 - 2\nu}{E}(\sigma_x + \sigma_y + \sigma_z)\]

모든 방향에서 같은 압력 \(p\)를 받으면 \(e = -3(1 - 2\nu)p/E\)이고, 비 \(K = p/(-e) = E/[3(1 - 2\nu)]\)를 체적 탄성 계수라 한다. \(\nu\)가 고무처럼 0.5에 가까우면 \(K\)가 매우 커져 부피가 거의 변하지 않는다. 그래서 \(\nu\)는 0.5를 넘을 수 없다.

거꾸로 변형률에서 응력을 구할 때는 세 식을 연립해 푼다. 결과는 다음과 같고 \(y\), \(z\)도 같은 꼴이며, 스트레인 게이지로 잰 변형률에서 응력을 구할 때 쓴다.

\[\sigma_x = \frac{E}{(1+\nu)(1-2\nu)}\left[(1-\nu)\varepsilon_x + \nu(\varepsilon_y + \varepsilon_z)\right]\]
흔한 실수이 식을 아무 재료에나 쓰는 실수가 흔하다. 이 식은 등방성, 곧 방향에 따라 성질이 같은 재료의 탄성 범위에서만 맞으며, 복합재, 목재, 압연판은 방향마다 상수가 다르다. 또 온도가 바뀌면 각 수직 변형률에 \(\alpha\Delta T\)를 더한다. 얇은 판의 표면에 붙인 게이지 두 개로 \(\varepsilon_x\), \(\varepsilon_y\)를 쟀다면 평면 응력 식 \(\sigma_x = \frac{E}{1-\nu^2}(\varepsilon_x + \nu\varepsilon_y)\)를 쓴다.
마무리

일반화 Hooke 법칙은 \(\varepsilon_x = [\sigma_x - \nu(\sigma_y + \sigma_z)]/E\), \(\gamma = \tau/G\), \(G = E/[2(1+\nu)]\)이다. 막힌 방향(평면 변형률)에는 \(\sigma_z = \nu(\sigma_x + \sigma_y)\)가 생긴다. 부피 변형률은 \(e = (1-2\nu)(\sigma_x+\sigma_y+\sigma_z)/E\)이고, 체적 탄성 계수는 \(K = E/[3(1-2\nu)]\)이다.

1.2.3연습문제

기본

  1. 알루미늄(\(E = 70\) GPa, \(\nu = 0.33\))의 \(G\)와 \(K\)는?
    답

    \(G = 70/2.66 = 26.3\) GPa이고, \(K = 70/(3\times0.34) = 68.6\) GPa이다.

응용

  1. 얇은 강판 표면의 게이지가 \(\varepsilon_x = 500\times10^{-6}\), \(\varepsilon_y = -150\times10^{-6}\)을 읽었다(\(E = 200\) GPa, \(\nu = 0.3\)). \(\sigma_x\), \(\sigma_y\)는?
    답

    \(E/(1-\nu^2) = 219.8\) GPa이다. 그러면 \(\sigma_x = 219.8\times(500 - 45)\times10^{-6}\times10^3 = 100\) MPa, \(\sigma_y = 219.8\times(-150 + 150)\times10^{-3} = 0\)이므로 한 방향 인장이었다.

심화

  1. 강 블록(\(E = 200\) GPa, \(\nu = 0.3\))을 \(y\), \(z\) 방향 모두 단단한 벽 사이에 끼우고 \(x\) 방향으로 100 MPa 압축했다. 옆 벽이 받는 응력과 \(x\) 방향 변형률은? 벽이 없을 때와 비교하여라.
    답

    \(\varepsilon_y = \varepsilon_z = 0\)에서 대칭으로 \(\sigma_y = \sigma_z = s\)로 두면 \(s - 0.3(s - 100) = 0\)에서 \(s = -42.9\) MPa(압축)이다. 그러면 \(\varepsilon_x = [-100 - 0.3(-85.7)]/200000 = -371\times10^{-6}\)이다. 벽이 없으면 \(-500\times10^{-6}\)이므로, 옆을 막으면 26% 덜 줄어든다.
