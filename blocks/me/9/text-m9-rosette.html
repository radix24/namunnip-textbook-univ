변형률 변환과 변형률 로제트

본문
이 절에서 배울 것
  • 평면 변형률을 회전 좌표로 변환하고 주변형률을 구한다.
  • 세 방향 게이지(로제트) 측정값에서 \(\varepsilon_x\), \(\varepsilon_y\), \(\gamma_{xy}\)를 되살린다.
  • 주변형률에서 일반화 Hooke 법칙으로 주응력을 구한다.
먼저 알아야 할 것
  • 3차원 응력과 주응력 (1.1절), 일반화 Hooke 법칙 (1.2절).

1.3.1변형률 변환

변형률 게이지는 붙인 방향의 수직 변형률 하나만 잽니다. 응력 상태를 알려면 세 방향을 재야 하며, 변환식으로 원하는 좌표의 변형률을 얻습니다. 응력 변환과 같은 꼴에서 \(\tau\) 자리에 \(\gamma/2\)가 들어갑니다.

변형률 변환과 로제트

\[\varepsilon_\theta = \frac{\varepsilon_x + \varepsilon_y}2 + \frac{\varepsilon_x - \varepsilon_y}2\cos2\theta + \frac{\gamma_{xy}}2\sin2\theta\]

0°-45°-90° 로제트: \(\varepsilon_x = \varepsilon_a\), \(\varepsilon_y = \varepsilon_c\), \(\gamma_{xy} = 2\varepsilon_b - \varepsilon_a - \varepsilon_c\)

주변형률 \(\varepsilon_{1,2} = \dfrac{\varepsilon_x + \varepsilon_y}2 \pm\sqrt{\left(\dfrac{\varepsilon_x - \varepsilon_y}2\right)^2 + \left(\dfrac{\gamma_{xy}}2\right)^2}\), \(\tan2\theta_p = \dfrac{\gamma_{xy}}{\varepsilon_x - \varepsilon_y}\)

예제 1.3.1 (강 부품 표면)

0°-45°-90° 로제트가 \(\varepsilon_a = 600\), \(\varepsilon_b = 400\), \(\varepsilon_c = -200\) (μ)을 읽었다. 주변형률과 방향, 주응력은? (\(E\) = 200 GPa, \(\nu\) = 0.3, 평면 응력)

풀이. \(\gamma_{xy} = 800 - 600 + 200 = 400\) μ. 중심 200, 반지름 \(\sqrt{400^2 + 200^2} = 447\) → \(\varepsilon_1 = 647\), \(\varepsilon_2 = -247\) μ, \(\theta_p = 13.3°\)(a 게이지에서 반시계). 주응력 \(\sigma_1 = \dfrac{E}{1 - \nu^2}(\varepsilon_1 + \nu\varepsilon_2) = 126\) MPa, \(\sigma_2 = \dfrac{E}{1 - \nu^2}(\varepsilon_2 + \nu\varepsilon_1) = -11.7\) MPa.

주의평면 응력(표면)에서도 두께 방향 변형률 \(\varepsilon_z = -\nu(\varepsilon_x + \varepsilon_y)/(1 - \nu)\)은 0이 아닙니다. 주변형률에서 주응력으로 갈 때 평면 응력 식(\(E/(1 - \nu^2)\))을 써야지, 단축 \(\sigma = E\varepsilon\)을 쓰면 틀립니다.
요약
  1. 변형률 변환은 응력 변환에서 \(\tau \to \gamma/2\).
  2. 0-45-90 로제트: \(\gamma_{xy} = 2\varepsilon_b - \varepsilon_a - \varepsilon_c\).
  3. 주응력은 평면 응력 Hooke 법칙으로.

1.3.2연습문제

기본

  1. \(\varepsilon_a = 300\), \(\varepsilon_b = 300\), \(\varepsilon_c = 300\) μ이면 전단 변형률과 주방향은?
    답

    \(\gamma_{xy} = 0\), 모든 방향이 주방향(등방 변형, 예: 온도 팽창).

응용

  1. 순수 비틀림을 받는 축 표면에 축 방향과 45°로 게이지를 붙이면 무엇을 읽는가?
    답

    순수 전단에서 주방향이 45°이므로 \(\varepsilon_{45} = \gamma/2\)(주변형률)를 읽는다. 비틀림 측정 게이지를 45°로 붙이는 이유다.

심화

  1. 0°-60°-120° 로제트에서 \(\varepsilon_x\)를 세 측정값으로 나타내어라.
    답

    \(\varepsilon_x = \varepsilon_0\). 나머지는 변환식 두 개를 풀어 \(\varepsilon_y = (2\varepsilon_{60} + 2\varepsilon_{120} - \varepsilon_0)/3\), \(\gamma_{xy} = 2(\varepsilon_{60} - \varepsilon_{120})/\sqrt3\).
