변형률 변환과 변형률 로제트

본문

부품 표면에 붙인 변형률 게이지 하나는 붙인 방향으로 얼마나 늘었는지만 알려 준다. 그런데 표면의 응력 상태를 정하려면 \(\varepsilon_x\), \(\varepsilon_y\), \(\gamma_{xy}\) 세 값이 필요하고, 가장 크게 늘어나는 방향은 미리 알 수도 없다. 게이지를 몇 개, 어떤 각도로 붙이면 주응력과 그 방향을 모두 구할 수 있을까?

먼저 알아야 할 것3차원 응력과 주응력(1.1절), 일반화 Hooke 법칙(1.2절)을 쓴다.

1.3.1변형률 변환

변형률 게이지는 붙인 방향의 수직 변형률 하나만 잰다. 그래서 응력 상태를 알려면 세 방향을 재야 하며, 변환식으로 원하는 좌표의 변형률을 얻는다. 변환식은 응력 변환과 같은 꼴이고, \(\tau\) 자리에 \(\gamma/2\)가 들어간다.

변형률 변환과 로제트

\[\varepsilon_\theta = \frac{\varepsilon_x + \varepsilon_y}2 + \frac{\varepsilon_x - \varepsilon_y}2\cos2\theta + \frac{\gamma_{xy}}2\sin2\theta\]

0°-45°-90° 로제트에서는 \(\varepsilon_x = \varepsilon_a\), \(\varepsilon_y = \varepsilon_c\), \(\gamma_{xy} = 2\varepsilon_b - \varepsilon_a - \varepsilon_c\)이다.

주변형률은 \(\varepsilon_{1,2} = \dfrac{\varepsilon_x + \varepsilon_y}2 \pm\sqrt{\left(\dfrac{\varepsilon_x - \varepsilon_y}2\right)^2 + \left(\dfrac{\gamma_{xy}}2\right)^2}\)이고, 방향은 \(\tan2\theta_p = \dfrac{\gamma_{xy}}{\varepsilon_x - \varepsilon_y}\)이다.

미지수가 \(\varepsilon_x\), \(\varepsilon_y\), \(\gamma_{xy}\) 셋이므로 서로 다른 방향의 게이지 세 개면 충분하다. 처음 질문의 답이 이것이다. 세 게이지를 한 받침에 정해진 각도로 겹쳐 만든 것을 로제트라 하며, 0°-45°-90°와 0°-60°-120°가 흔하다. 0°와 90° 게이지는 \(\varepsilon_x\), \(\varepsilon_y\)를 바로 주고, 45° 게이지가 전단 변형률을 알려 준다.

예제 1.3.1 (강 부품 표면)

0°-45°-90° 로제트가 \(\varepsilon_a = 600\), \(\varepsilon_b = 400\), \(\varepsilon_c = -200\) (μ)을 읽었다. 주변형률과 방향, 주응력은? (\(E\) = 200 GPa, \(\nu\) = 0.3, 평면 응력)

풀이. \(\gamma_{xy} = 800 - 600 + 200 = 400\) μ이다. 모어 원의 중심은 200, 반지름은 \(\sqrt{400^2 + 200^2} = 447\)이므로 \(\varepsilon_1 = 647\), \(\varepsilon_2 = -247\) μ이고, \(\theta_p = 13.3°\)(a 게이지에서 반시계)이다. 그러면 주응력은 \(\sigma_1 = \dfrac{E}{1 - \nu^2}(\varepsilon_1 + \nu\varepsilon_2) = 126\) MPa, \(\sigma_2 = \dfrac{E}{1 - \nu^2}(\varepsilon_2 + \nu\varepsilon_1) = -11.7\) MPa이다(그림 1).

주변형률 방향과 주응력 방향은 등방성 재료에서 같다. 그래서 a 게이지에서 13.3° 돌아간 방향이 가장 크게 당겨지는 방향이며, 균열이 생긴다면 그에 수직으로 자랄 가능성이 크다.

흔한 실수주변형률에 바로 \(\sigma = E\varepsilon\)을 곱하는 실수가 흔하다. 평면 응력인 표면에서도 두께 방향 변형률 \(\varepsilon_z = -\nu(\varepsilon_x + \varepsilon_y)/(1 - \nu)\)은 0이 아니며, 두 방향 응력이 서로 영향을 준다. 그러므로 주변형률에서 주응력으로 갈 때는 \(E/(1 - \nu^2)\)이 든 평면 응력 식을 써야 한다.
마무리

변형률 변환은 응력 변환에서 \(\tau\)를 \(\gamma/2\)로 바꾼 꼴이다. 0-45-90 로제트에서는 \(\gamma_{xy} = 2\varepsilon_b - \varepsilon_a - \varepsilon_c\)로 전단 변형률을 얻는다. 주변형률을 구한 뒤 평면 응력 Hooke 법칙으로 주응력을 계산한다.

1.3.2연습문제

기본

  1. \(\varepsilon_a = 300\), \(\varepsilon_b = 300\), \(\varepsilon_c = 300\) μ이면 전단 변형률과 주방향은?
    답

    \(\gamma_{xy} = 0\)이고 모든 방향이 주방향이다. 가령 온도 팽창 같은 등방 변형이 그렇다.

응용

  1. 순수 비틀림을 받는 축 표면에 축 방향과 45°로 게이지를 붙이면 무엇을 읽는가?
    답

    순수 전단에서 주방향이 45°이므로 \(\varepsilon_{45} = \gamma/2\)(주변형률)를 읽는다. 비틀림 측정 게이지를 45°로 붙이는 이유가 이것이다.

심화

  1. 0°-60°-120° 로제트에서 \(\varepsilon_x\)를 세 측정값으로 나타내어라.
    답

    \(\varepsilon_x = \varepsilon_0\)이다. 나머지는 변환식 두 개를 풀어 \(\varepsilon_y = (2\varepsilon_{60} + 2\varepsilon_{120} - \varepsilon_0)/3\), \(\gamma_{xy} = 2(\varepsilon_{60} - \varepsilon_{120})/\sqrt3\)을 얻는다.
