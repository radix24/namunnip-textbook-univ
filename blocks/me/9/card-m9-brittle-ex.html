주철 브래킷: 굽힘과 비틀림이 함께

예제 · 주응력 · Coulomb-Mohr · 연성 기준 비교
문제 해결 전략 · 주응력부터
  1. 위험점의 \(\sigma\)와 \(\tau\)로 주응력을 구한다.
  2. Coulomb-Mohr로 안전계수를 구한다.
  3. 연성 기준(von Mises)을 잘못 쓰면 어떻게 되는지 비교한다.

문제. 회주철(\(S_{ut}\) = 200, \(S_{uc}\) = 700 MPa) 축의 표면 한 점에 굽힘 \(\sigma = 60\) MPa와 비틀림 \(\tau = 50\) MPa가 함께 걸린다. Coulomb-Mohr 안전계수는? \(S_y\) 대신 \(S_{ut}\)를 넣은 von Mises 계산과 비교하여라.

전략

\(\sigma_{1,3} = \sigma/2 \pm\sqrt{(\sigma/2)^2 + \tau^2}\).

풀이

  1. \(\sigma_{1,3} = 30\pm\sqrt{900 + 2500} = 30\pm58.3\) → \(\sigma_1 = 88.3\), \(\sigma_3 = -28.3\) MPa.
    주응력.
  2. Coulomb-Mohr: \(88.3/200 + 28.3/700 = 0.482\) → \(n = 2.07\).
    취성 기준.
  3. von Mises: \(\sqrt{\sigma^2 + 3\tau^2} = \sqrt{3600 + 7500} = 105\) MPa, \(200/105 = 1.90\).
    연성 기준(부적절).

검산

이 경우는 두 값이 비슷하지만, von Mises는 압축 강도가 큰 취성 재료의 성질을 반영하지 못한다. 압축 성분이 큰 점에서는 von Mises가 지나치게 보수적이고, 인장 성분이 큰 점에서는 근거가 없다. 재료에 맞는 기준을 고르는 것이 우선이다.

의미

주철은 진동을 잘 흡수하고 주조가 쉬워 공작 기계 베드, 브레이크 디스크, 하우징에 쓰인다. 인장에 약하므로 설계에서 인장 응력이 생기는 부위(필렛, 리브 끝)를 줄이고 압축을 받도록 형상을 잡는다.

바꿔 보기

굽힘이 압축(−60 MPa)이 되는 반대편 점이라면 \(\sigma_1 = 28.3\), \(\sigma_3 = -88.3\): \(28.3/200 + 88.3/700 = 0.268\), \(n = 3.7\)로 훨씬 안전하다. 같은 크기라도 인장 쪽이 위험점이다.
