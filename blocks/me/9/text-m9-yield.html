파손 이론: 인장 시험 하나로 복잡한 응력의 항복을 판정하기

본문

강재의 항복 강도 350 MPa는 막대를 한 방향으로 당기는 인장 시험에서 얻은 값이다. 그런데 실제 축은 굽힘 응력과 비틀림 전단 응력을 함께 받는다. 그 축이 언제 항복할지를 인장 시험 숫자 하나로 판정할 수 있을까? 판정에 쓸 "같은 양"으로는 무엇을 골라야 할까?

먼저 알아야 할 것주응력과 최대 전단 응력(1.1절), 인장 시험의 항복 강도(고체역학 1단원)를 쓴다.

2.1.1왜 기준이 필요한가

재료의 항복 강도 \(S_y\)는 막대를 한 방향으로 당기는 인장 시험에서 얻는다. 그런데 실제 부품은 굽힘과 비틀림이 함께 걸린 축, 안팎 압력을 받는 용기처럼 여러 방향의 응력을 동시에 받는다. 모든 조합으로 시험할 수는 없으므로, "복잡한 응력 상태의 어떤 양이 인장 시험에서 항복할 때의 같은 양에 이르면 항복한다"고 가정한다. 처음 질문의 첫째 답이 이 가정이며, 어떤 양을 고르느냐가 기준마다 다르다.

연성 금속(강, 알루미늄)이 항복하는 것은 원자 면이 미끄러지기 때문이고, 미끄러짐은 전단 응력이 일으킨다. 그래서 두 기준 모두 전단과 관계된 양을 쓰며, 처음 질문의 둘째 답이 이것이다. 모든 방향에서 같은 압력(정수압)만으로는 전단이 없어 항복하지 않는다는 실험 사실과도 맞는다.

2.1.2Tresca 기준 (최대 전단 응력)

Tresca 기준은 최대 전단 응력 \(\tau_{\max} = (\sigma_1 - \sigma_3)/2\)가 인장 시험의 항복 순간 값 \(S_y/2\)에 이르면 항복한다고 본다.

Tresca 기준 \[\sigma_1 - \sigma_3 = S_y\quad(\text{항복})\] \[n = \frac{S_y}{\sigma_1 - \sigma_3}\]

2.1.3von Mises 기준 (변형 에너지)

재료에 저장된 변형 에너지는 부피를 바꾸는 몫과 모양을 바꾸는(찌그러뜨리는) 몫으로 나눌 수 있다. 정수압은 부피만 바꾸고 항복을 일으키지 않으므로, von Mises 기준은 모양을 바꾸는 에너지가 인장 시험의 항복 순간 값에 이르면 항복한다고 본다. 이 조건을 정리하면 다음 등가 응력이 나온다.

von Mises 등가 응력과 기준 \[\sigma_v = \sqrt{\frac{(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2}{2}}\] \[\sigma_v = S_y\quad(\text{항복})\] \[n = \frac{S_y}{\sigma_v}\]

성분으로 쓰면 \(\sigma_v = \sqrt{\sigma_x^2 + \sigma_y^2 + \sigma_z^2 - \sigma_x\sigma_y - \sigma_y\sigma_z - \sigma_z\sigma_x + 3(\tau_{xy}^2 + \tau_{yz}^2 + \tau_{zx}^2)}\)이다.

식에는 세 주응력의 차이만 들어 있다. 그래서 세 주응력에 같은 값을 더해도, 곧 정수압을 더해도 \(\sigma_v\)는 변하지 않는다. 한 방향 인장(\(\sigma_1 = S_y\), 나머지 0)을 넣으면 \(\sigma_v = S_y\)가 되어 인장 시험과 맞는다.

예제 2.1.1 (굽힘과 비틀림을 받는 축)

축 표면에 굽힘 응력 \(\sigma = 120\) MPa와 비틀림 전단 응력 \(\tau = 80\) MPa가 함께 작용한다. 재료의 \(S_y = 350\) MPa일 때 두 기준의 안전 계수는?

풀이. 평면 응력(\(\sigma_x = 120\), \(\tau_{xy} = 80\))의 모어 원은 중심 60, 반지름 \(\sqrt{60^2 + 80^2} = 100\)이므로 주응력은 160, 0, −40 MPa이다. Tresca로는 \(\sigma_1 - \sigma_3 = 200\)이어서 \(n = 1.75\)이다. von Mises로는 \(\sigma_v = \sqrt{\sigma^2 + 3\tau^2} = \sqrt{14400 + 19200} = 183.3\)이어서 \(n = 1.91\)이다(그림 1). 즉 Tresca가 약 9% 더 보수적이다. 축 설계에서 자주 쓰는 \(\sqrt{\sigma^2 + 4\tau^2}\)(Tresca)와 \(\sqrt{\sigma^2 + 3\tau^2}\)(von Mises)이 여기서 나온다.

1.1절 예제의 응력(주응력 70.2, 21.9, −22.1 MPa)이면 Tresca 92.3 MPa, von Mises 80.0 MPa이다. 두 기준의 차이가 가장 큰 경우는 순수 전단이다. Tresca는 \(\tau_y = 0.5S_y\), von Mises는 \(\tau_y = S_y/\sqrt3 = 0.577S_y\)로 약 15% 다르다.

흔한 실수두 기준을 취성 재료에 쓰는 실수가 흔하다. 두 기준은 연성 재료용이며, 인장보다 압축에 훨씬 강한 주철이나 세라믹 같은 취성 재료에는 최대 주응력이나 Mohr-Coulomb 기준을 쓴다(2.2절). 실험 자료는 대부분 von Mises 쪽에 더 가깝지만, Tresca는 계산이 간단하고 언제나 조금 보수적이라 압력 용기 규정 등에서 쓴다. 또 반복 하중에서는 항복이 아니라 피로가 문제이다(기계요소설계).
마무리

Tresca 기준은 \(\sigma_1 - \sigma_3 = S_y\), von Mises 기준은 \(\sigma_v = S_y\)에서 항복한다고 본다. 두 기준 모두 주응력의 차이만 보므로 정수압에는 반응하지 않는다. 두 기준의 차이는 순수 전단에서 최대 15%이고, Tresca가 보수적이다.

2.1.4연습문제

기본

  1. 주응력 200, 100, 0 MPa, \(S_y = 300\) MPa이다. 두 기준의 안전 계수는?
    답

    Tresca로는 \(300/200 = 1.5\)이다. von Mises로는 \(\sqrt{(100^2 + 100^2 + 200^2)/2} = 173.2\)이므로 \(n = 1.73\)이다.

응용

  1. 얇은 압력 용기의 원주 응력 \(\sigma\), 축 응력 \(\sigma/2\), 반지름 응력 0이다. \(S_y = 250\) MPa로 안전 계수 2를 확보하려면 \(\sigma\)는 얼마 이하인가(두 기준)?
    답

    Tresca로는 \(\sigma - 0 \le 125\)에서 \(\sigma \le 125\) MPa이다. von Mises로는 \(\sigma_v = \sigma\sqrt{(0.25 + 0.25 + 1)/2} = 0.866\sigma \le 125\)에서 \(\sigma \le 144\) MPa이다.

심화

  1. 깊은 바닷속 강 부품에 주응력 \(-50, -50, -350\) MPa가 걸렸다(\(S_y = 350\) MPa). 압축 350 MPa는 항복 강도와 같은데 항복하는가?
    답

    Tresca로는 \(\sigma_1 - \sigma_3 = 300 < 350\), von Mises로는 \(\sqrt{(0 + 300^2 + 300^2)/2} = 300 < 350\)이다. 그래서 둘 다 항복하지 않는다(\(n = 1.17\)). 주위 압력 50 MPa가 전단을 줄여 주었기 때문이다.
