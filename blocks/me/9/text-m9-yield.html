파손 이론: 인장 시험 하나로 복잡한 응력의 항복을 판정하기

본문
이 절에서 배울 것
  • 왜 복잡한 응력 상태의 항복을 판정할 "기준"이 필요한지 안다.
  • 최대 전단 응력 기준(Tresca)과 변형 에너지 기준(von Mises)으로 항복 여부와 안전 계수를 구한다.
  • 두 기준의 차이(최대 약 15%)와 각각을 쓰는 곳을 안다.
먼저 알아야 할 것
  • 주응력과 최대 전단 응력 (1.1절), 인장 시험의 항복 강도 (고체역학 1단원).

2.1.1왜 기준이 필요한가

재료의 항복 강도 \(S_y\)는 막대를 한 방향으로 당기는 인장 시험에서 얻습니다. 그런데 실제 부품은 굽힘과 비틀림이 함께 걸린 축, 안팎 압력을 받는 용기처럼 여러 방향의 응력을 동시에 받습니다. 모든 조합으로 시험할 수는 없으므로, "복잡한 응력 상태의 어떤 양이 인장 시험에서 항복할 때의 같은 양에 이르면 항복한다"는 가정을 세웁니다. 어떤 양을 고르느냐가 기준마다 다릅니다.

연성 금속(강, 알루미늄)이 항복하는 것은 원자 면이 미끄러지기 때문이고, 미끄러짐은 전단 응력이 일으킵니다. 그래서 두 기준 모두 전단과 관계된 양을 씁니다. 모든 방향에서 같은 압력(정수압)만으로는 전단이 없어 항복하지 않는다는 실험 사실과도 맞습니다.

2.1.2Tresca 기준 (최대 전단 응력)

최대 전단 응력 \(\tau_{\max} = (\sigma_1 - \sigma_3)/2\)가 인장 시험의 항복 순간 값 \(S_y/2\)에 이르면 항복한다고 봅니다.

Tresca 기준 \[\sigma_1 - \sigma_3 = S_y\quad(\text{항복})\] \[n = \frac{S_y}{\sigma_1 - \sigma_3}\]

2.1.3von Mises 기준 (변형 에너지)

재료에 저장된 변형 에너지는 부피를 바꾸는 몫과 모양을 바꾸는(찌그러뜨리는) 몫으로 나눌 수 있습니다. 정수압은 부피만 바꾸고 항복을 일으키지 않으므로, 모양을 바꾸는 에너지가 인장 시험의 항복 순간 값에 이르면 항복한다고 봅니다. 이 조건을 정리하면 다음과 같은 등가 응력이 나옵니다.

von Mises 등가 응력과 기준 \[\sigma_v = \sqrt{\frac{(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2}{2}}\] \[\sigma_v = S_y\quad(\text{항복})\] \[n = \frac{S_y}{\sigma_v}\]

성분으로 쓰면 \(\sigma_v = \sqrt{\sigma_x^2 + \sigma_y^2 + \sigma_z^2 - \sigma_x\sigma_y - \sigma_y\sigma_z - \sigma_z\sigma_x + 3(\tau_{xy}^2 + \tau_{yz}^2 + \tau_{zx}^2)}\).

식의 모양을 보면 세 주응력의 차이만 들어 있습니다. 세 주응력에 같은 값을 더해도(정수압을 더해도) \(\sigma_v\)는 변하지 않습니다. 한 방향 인장(\(\sigma_1 = S_y\), 나머지 0)을 넣으면 \(\sigma_v = S_y\)가 되어 인장 시험과 맞습니다.

예제 2.1.1 (굽힘과 비틀림을 받는 축)

축 표면에 굽힘 응력 \(\sigma = 120\) MPa와 비틀림 전단 응력 \(\tau = 80\) MPa가 함께 작용한다. 재료의 \(S_y = 350\) MPa일 때 두 기준의 안전 계수는?

풀이. 평면 응력(\(\sigma_x = 120\), \(\tau_{xy} = 80\))의 모어 원: 중심 60, 반지름 \(\sqrt{60^2 + 80^2} = 100\). 주응력 160, 0, −40 MPa. Tresca: \(\sigma_1 - \sigma_3 = 200\), \(n = 1.75\). von Mises: \(\sigma_v = \sqrt{\sigma^2 + 3\tau^2} = \sqrt{14400 + 19200} = 183.3\), \(n = 1.91\). Tresca가 약 9% 더 보수적입니다. 축 설계에서 자주 쓰는 \(\sqrt{\sigma^2 + 4\tau^2}\)(Tresca), \(\sqrt{\sigma^2 + 3\tau^2}\)(von Mises)이 여기서 나옵니다.

1.1절 예제의 응력(주응력 70.2, 21.9, −22.1 MPa)이면 Tresca 92.3 MPa, von Mises 80.0 MPa입니다. 두 기준의 차이가 가장 큰 경우는 순수 전단으로, Tresca는 \(\tau_y = 0.5S_y\), von Mises는 \(\tau_y = S_y/\sqrt3 = 0.577S_y\)라 약 15% 다릅니다.

주의(1) 두 기준은 연성 재료용입니다. 주철·세라믹 같은 취성 재료는 최대 주응력이나 Mohr-Coulomb 기준을 씁니다(인장보다 압축에 훨씬 강함). (2) 실험 자료는 대부분 von Mises 쪽에 더 가깝고, Tresca는 계산이 간단하고 항상 조금 보수적이라 압력 용기 규정 등에서 씁니다. (3) 반복 하중에서는 항복이 아니라 피로가 문제입니다(기계요소설계).
요약
  1. Tresca: \(\sigma_1 - \sigma_3 = S_y\). von Mises: \(\sigma_v = S_y\).
  2. 두 기준 모두 정수압에는 반응하지 않는다(주응력의 차이만 들어감).
  3. 차이는 순수 전단에서 최대 15%, Tresca가 보수적.

2.1.4연습문제

기본

  1. 주응력 200, 100, 0 MPa, \(S_y = 300\) MPa이다. 두 기준의 안전 계수는?
    답

    Tresca \(300/200 = 1.5\). von Mises \(\sqrt{(100^2 + 100^2 + 200^2)/2} = 173.2\), \(n = 1.73\).

응용

  1. 얇은 압력 용기의 원주 응력 \(\sigma\), 축 응력 \(\sigma/2\), 반지름 응력 0이다. \(S_y = 250\) MPa로 안전 계수 2를 확보하려면 \(\sigma\)는 얼마 이하인가(두 기준)?
    답

    Tresca: \(\sigma - 0 \le 125\) → \(\sigma \le 125\). von Mises: \(\sigma_v = \sigma\sqrt{(0.25 + 0.25 + 1)/2} = 0.866\sigma \le 125\) → \(\sigma \le 144\) MPa.

심화

  1. 깊은 바닷속 강 부품에 주응력 \(-50, -50, -350\) MPa가 걸렸다(\(S_y = 350\) MPa). 압축 350 MPa는 항복 강도와 같은데 항복하는가?
    답

    Tresca \(\sigma_1 - \sigma_3 = 300 < 350\), von Mises \(\sqrt{(0 + 300^2 + 300^2)/2} = 300 < 350\). 둘 다 항복하지 않는다(\(n = 1.17\)). 주위 압력 50 MPa가 전단을 줄여 주었기 때문이다.
