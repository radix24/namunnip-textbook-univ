3차원 응력과 변형률 단원 마무리 연습

문제 8 · 개념·계산·판단·도전 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념응력 텐서에는 숫자가 9개 있는데 왜 독립인 값은 6개뿐일까요? [01-01]

    힌트 1

    작은 정육면체에 작용하는 모멘트를 생각하세요. 1.1절

    힌트 2

    \(\tau_{xy}\)와 \(\tau_{yx}\)는 정육면체를 같은 방향으로 돌리나요?

    풀이

    마주 보는 면의 전단 응력 짝 \(\tau_{xy}\)와 \(\tau_{yx}\)는 정육면체를 서로 반대 방향으로 돌리려 합니다. 정육면체가 돌지 않으려면(모멘트 평형) 둘의 크기가 같아야 합니다. 세 쌍이 모두 그러므로 9개 중 3개가 겹치고 독립 값은 6개입니다.

  2. 계산\(\sigma_x = 40\), \(\sigma_y = -20\), \(\sigma_z = 10\), \(\tau_{xy} = 30\), \(\tau_{yz} = \tau_{zx} = 0\) (MPa)의 주응력과 최대 전단 응력은? [01-01]

    힌트 1

    \(z\)면에 전단이 없으므로 \(\sigma_z\)가 이미 주응력 하나입니다.

    힌트 2

    나머지 둘은 \(xy\) 평면의 모어 원: 중심 10, 반지름 \(\sqrt{30^2 + 30^2}\).

    풀이

    반지름 42.4이므로 평면 안 주응력 52.4와 −32.4. 세 주응력은 \(\sigma_1 = 52.4\), \(\sigma_2 = 10\), \(\sigma_3 = -32.4\) MPa. 합 30.0이 \(I_1 = 30\)과 맞습니다. \(\tau_{\max} = (52.4 + 32.4)/2 = 42.4\) MPa.

  3. 판단얇은 압력 용기 바깥 표면에서 원주 응력 100 MPa, 축 응력 50 MPa, 반지름 방향 응력은 0이다. 한 학생이 최대 전단 응력을 \((100 - 50)/2 = 25\) MPa로 계산했다. 맞나요? [01-01]

    힌트 1

    주응력이 몇 개인지 세어 보세요.

    힌트 2

    0도 주응력입니다.

    풀이

    틀렸습니다. 주응력은 100, 50, 0이므로 \(\tau_{\max} = (100 - 0)/2 = 50\) MPa입니다. 최대 전단은 원주 방향과 반지름 방향을 포함한 면, 벽 두께를 45°로 자르는 면에서 생깁니다(응력 실습의 "평면 응력의 함정").

  4. 계산한 변 20 mm 강 정육면체(\(E = 200\) GPa, \(\nu = 0.3\))를 깊은 바다에서처럼 모든 방향으로 100 MPa 압력을 받게 했다. 부피는 몇 mm³ 줄어드는가? [01-02]

    힌트 1

    \(e = (1 - 2\nu)(\sigma_x + \sigma_y + \sigma_z)/E\). 1.2절

    힌트 2

    세 응력 모두 −100 MPa.

    풀이

    \(e = 0.4\times(-300)/200000 = -6.0\times10^{-4}\). 부피 8000 mm³의 0.06%, 4.8 mm³ 줄어듭니다. 체적 탄성 계수 \(K = 200/1.2 = 167\) GPa로도 \(100/167000 = 6.0\times10^{-4}\)입니다.

  5. 판단고무(\(\nu \approx 0.49\)) 받침을 강판 사이에 붙여 옆으로 부풀지 못하게 하면, 붙이지 않았을 때보다 위아래로 훨씬 단단해진다. 이유를 일반화 Hooke 법칙으로 설명하세요. [01-02]

    힌트 1

    옆이 막히면 \(\varepsilon_y = \varepsilon_z \approx 0\)입니다.

    힌트 2

    그때 \(\sigma_x/\varepsilon_x = E(1-\nu)/[(1+\nu)(1-2\nu)]\).

    풀이

    옆이 막히면 옆 방향 압축 응력이 생겨 세로 변형을 막습니다. 세로 강성은 \(E(1-\nu)/[(1+\nu)(1-2\nu)]\)이고, \(\nu = 0.49\)면 \(1 - 2\nu = 0.02\)라 \(E\)의 약 17배가 됩니다. 고무는 부피가 거의 변하지 않아(\(K\)가 매우 큼) 옆으로 부풀 수 없으면 거의 눌리지 않습니다. 건물 지진 격리 받침이 고무와 강판을 겹겹이 쌓는 이유입니다.

  6. 도전두꺼운 강판(\(E = 200\) GPa, \(\nu = 0.3\)) 안쪽은 두께 방향 변형이 막혀 \(\varepsilon_z = 0\)이다. \(\sigma_x = 120\), \(\sigma_y = -40\) MPa, 전단 0일 때 \(\sigma_z\), 세 주응력, 최대 전단 응력, \(\varepsilon_x\)는? 같은 \(\sigma_x\), \(\sigma_y\)의 얇은 판과 최대 전단 응력을 비교하세요. [01-01, 01-02]

    힌트 1

    평면 변형률: \(\sigma_z = \nu(\sigma_x + \sigma_y)\).

    힌트 2

    \(\sigma_z = 24\) MPa, 전단이 없으므로 세 수직 응력이 곧 주응력입니다.

    풀이

    주응력 120, 24, −40 MPa, \(\tau_{\max} = 80\) MPa. \(\varepsilon_x = [120 - 0.3(-40 + 24)]/200000 = 624\times10^{-6}\). 얇은 판(주응력 120, 0, −40)도 \(\tau_{\max} = 80\)으로 같습니다. \(\sigma_z\)가 가장 큰 값과 가장 작은 값 사이에 놓였기 때문이며, \(\sigma_x\), \(\sigma_y\)가 같은 부호일 때는 \(\sigma_z\)가 최대 전단을 줄일 수 있습니다(2단원의 파손 판정과 연결).

  7. 계산0°-45°-90° 로제트가 \(\varepsilon_a = 500\), \(\varepsilon_b = 100\), \(\varepsilon_c = 100\) μ을 읽었다. \(\gamma_{xy}\)와 주변형률은? [01-03]

    힌트 1

    \(\gamma_{xy} = 2\varepsilon_b - \varepsilon_a - \varepsilon_c\). 1.3절

    힌트 2

    중심 300, 반지름 \(\sqrt{200^2 + 200^2}\).

    풀이

    \(\gamma_{xy} = -400\) μ, \(\varepsilon_{1,2} = 300\pm283\) = 583, 17 μ.

  8. 계산넓은 판이 \(\sigma_1 = 80\), \(\sigma_2 = 40\) MPa 이축 인장을 받고 작은 원형 구멍이 있다. 구멍 가장자리 최대 응력은? [01-04]

    힌트 1

    \(3\sigma_1 - \sigma_2\). 1.4절

    힌트 2

    \(240 - 40\).

    풀이

    200 MPa.
