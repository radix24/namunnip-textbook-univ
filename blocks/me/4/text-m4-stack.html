공차 누적 해석: 최악 조건과 통계적 방법

본문
이 절에서 배울 것
  • 조립품의 틈(간극)을 부품 치수의 합과 차로 나타내는 치수 고리를 세운다.
  • 최악 조건법으로 틈의 최대·최소를 구한다.
  • 통계적 방법(제곱합의 제곱근)으로 현실적인 틈의 범위를 구하고 두 방법을 비교한다.
먼저 알아야 할 것
  • 치수 공차 (3.1절), 직렬 치수의 오차 누적 (1.3절), 표준편차(확률과 통계).

3.3.1치수 고리

하우징(안쪽 길이 \(H\)) 안에 부품 세 개(길이 \(a\), \(b\), \(c\))를 나란히 넣으면 남는 틈은

\[g = H - (a + b + c)\]

입니다. 틈이 늘 0보다 커야 조립되고, 너무 크면 덜컹거립니다. 각 치수의 공차가 틈에 어떻게 모이는지가 공차 누적 해석입니다.

예제 3.3.1 (세 부품의 틈)

\(H = 50 \pm 0.10\), \(a = b = c = 16 \pm 0.05\) mm. 틈의 최악 범위와 통계적 범위는?

3.3.2최악 조건법

모든 치수가 동시에 틈을 가장 작게(또는 크게) 하는 쪽 끝에 있다고 봅니다. 틈의 공차는 각 공차의 합입니다.

\[t_g = t_H + t_a + t_b + t_c\]

예제: 기준 틈 \(50 - 48 = 2\) mm, \(t_g = 0.10 + 3\times0.05 = 0.25\). 틈은 1.75~2.25 mm. 어떤 부품을 골라 조립해도 보장되지만, 부품이 많으면 각 공차를 매우 좁혀야 해 비쌉니다.

3.3.3통계적 방법

실제로는 모든 부품이 한꺼번에 최악 쪽 끝에 몰릴 확률이 매우 낮습니다. 각 치수가 서로 독립으로 흩어지고, 공차를 표준편차의 3배(±3σ, 정규분포에서 99.73%가 들어오는 범위)로 정했다면, 독립인 양의 합의 분산은 분산의 합이므로

\[t_g = \sqrt{t_H^2 + t_a^2 + t_b^2 + t_c^2}\]

입니다(기계공학실험 1.2절의 불확도 전파와 같은 식). 예제: \(\sqrt{0.10^2 + 3\times0.05^2} = 0.132\). 틈은 대부분(99.73%) 1.87~2.13 mm입니다. 최악 조건보다 폭이 약 절반입니다. 바꾸어 말하면 같은 틈 범위를 요구할 때 각 부품의 공차를 더 넓혀(싸게) 만들 수 있습니다. 대신 아주 드물게(0.27%) 범위를 벗어나는 조립품이 생길 수 있다는 것을 받아들입니다(공차 누적 실습).

주의(1) 통계적 방법은 부품이 많이 만들어지고 치수가 정규분포에 가깝게 흩어질 때 맞습니다. 몇 개만 만들거나 공정이 한쪽으로 치우치면(공구 마모) 맞지 않습니다. (2) 안전과 직결된 곳(브레이크, 항공)은 최악 조건을 씁니다. (3) 치수 고리에서 틈을 늘리는 치수(+)와 줄이는 치수(−)의 부호를 바르게 정해야 기준 틈이 맞게 나옵니다. 공차는 부호와 상관없이 더합니다.
요약
  1. 치수 고리: 틈 = (늘리는 치수의 합) − (줄이는 치수의 합).
  2. 최악 조건: \(t_g = \sum t_i\), 언제나 보장, 비쌈.
  3. 통계적: \(t_g = \sqrt{\sum t_i^2}\), 대량 생산에서 현실적, 드문 불량을 허용.

3.3.4연습문제

기본

  1. 공차가 각각 ±0.02인 부품 9개를 쌓았다. 전체 길이의 최악 공차와 통계적 공차는?
    답

    최악 ±0.18, 통계적 \(\pm0.02\sqrt9 = \pm0.06\).

응용

  1. 예제 3.3.1에서 틈을 최악 조건으로 1.8 mm 이상 보장하려면, 하우징 공차를 ±0.10으로 둘 때 부품 공차는 얼마 이하여야 하는가?
    답

    \(0.10 + 3t \le 0.2\), \(t \le 0.033\) mm.

심화

  1. 문제 2를 통계적 방법으로 풀면 부품 공차를 얼마까지 넓힐 수 있는가? 그 대가는?
    답

    \(\sqrt{0.10^2 + 3t^2} \le 0.2\), \(3t^2 \le 0.03\), \(t \le 0.1\) mm로 세 배 넓어진다. 대신 틈이 1.8~2.2 mm를 벗어나는 조립품이 약 0.27% 생기고, 그중 1.8 mm보다 작은 쪽은 절반인 약 0.135%(약 740개 중 1개)이므로 검사로 걸러야 한다.
