여러 점 자료로 m과 h 구하기

예제 · 로그 직선 맞춤 · 핀 열량
문제 해결 전략 · 로그를 취해 직선
  1. 각 점의 \(\ln(\theta/\theta_b)\)를 계산한다.
  2. 원점을 지나는 직선으로 기울기 \(-m\)을 맞춘다.
  3. \(h\)와 핀 열량을 구한다.

문제. 예제 3.2.1 핀에서 \(x\) = 0, 25, 50, 75 mm의 \(\theta\)가 60.0, 42.6, 30.0, 21.4 K였다. \(m\), \(h\), 핀 열량(긴 핀)은?

전략

\(\ln(\theta/60)\): 0, −0.343, −0.693, −1.031.

풀이

  1. 원점 직선 기울기 \(\sum xy/\sum x^2 = -(0.025\times0.343 + 0.05\times0.693 + 0.075\times1.031)/(0.025^2 + 0.05^2 + 0.075^2) = -13.8\) m⁻¹.
    최소제곱.
  2. \(h = 13.8^2\times200\times0.01/4 = 95\) W/m²·K.
    역산.
  3. 핀 열량 \(kA_cm\theta_b = 200\times7.85\times10^{-5}\times13.8\times60 = 13.0\) W.
    긴 핀.

검산

네 점이 한 직선(잔차 0.01 이하) 위에 있어 긴 핀 지수 분포와 잘 맞다. 두 점만 쓴 예제 3.2.1의 \(m\) = 13.9와도 거의 같다.

의미

핀이 없을 때 뿌리 단면적(\(7.85\times10^{-5}\) m²)으로만 내보낼 열은 \(95\times7.85\times10^{-5}\times60 = 0.45\) W이다. 핀이 열 방출을 약 29배로 키운 셈입니다(핀 유효도).

바꿔 보기

바람을 끄고 다시 쟀더니 \(m\)이 6.0 m⁻¹이었다면 \(h = 18\) W/m²·K로 자연 대류 수준이다. 이때 \(mL = 1.2\)라 긴 핀 근사가 맞지 않아 유한 핀 식으로 맞춰야 한다.

뿌리 \(\theta_b\)를 두 배로 하면 핀 열량은?

답

두 배(\(h\)가 일정하면 열량은 \(\theta_b\)에 비례).
