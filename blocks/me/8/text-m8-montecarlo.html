몬테카를로 불확도 전파

본문
이 절에서 배울 것
  • 입력 값을 확률 분포에서 많이 뽑아 결과의 분포를 얻는 몬테카를로 방법을 안다.
  • 선형 불확도 전파와 결과를 비교한다.
  • 식이 복잡하거나 비선형이 클 때 몬테카를로가 필요한 경우를 판단한다.
먼저 알아야 할 것
  • 불확도 전파(기계공학실험(1) 1.2절), 불확도 예산 (4.1절).

4.5.1방법

  1. 각 입력의 분포(정규, 균일 등)와 표준 불확도를 정한다.
  2. 난수로 입력 값 한 벌을 뽑아 결과를 계산한다.
  3. 수만~수십만 번 되풀이해 결과의 평균, 표준 편차, 2.5~97.5% 구간을 구한다.
선형 전파와 비교 (곱·나눗셈 꼴)

\(y = c\,x_1^ax_2^b\)이면 \(\dfrac{u_y}{y} \approx \sqrt{\left(a\dfrac{u_1}{x_1}\right)^2 + \left(b\dfrac{u_2}{x_2}\right)^2}\)

불확도가 작고 식이 거의 선형이면 두 방법이 같은 값을 준다. 불확도가 크거나 식이 크게 굽으면(분모가 0 근처, 큰 지수) 몬테카를로가 정확하다.

예제 4.5.1 (진자로 g 재기)

\(g = 4\pi^2L/T^2\), \(L = 1.000 \pm 0.002\) m, \(T = 2.006 \pm 0.010\) s(표준 불확도, 정규 분포). 선형 전파와 몬테카를로(20만 번)의 상대 불확도는?

풀이. 선형: \(\sqrt{0.002^2 + (2\times0.010/2.006)^2} = 1.02\)%. 몬테카를로: 평균 9.812, 표준 편차 0.0998 m/s², 1.02%. 공칭값 \(4\pi^2/2.006^2 = 9.811\)과 평균도 거의 같습니다. 이 정도 불확도에서는 두 방법이 일치합니다.

주의입력들이 서로 상관되어 있으면(같은 자로 잰 두 길이처럼) 따로 뽑으면 안 되고 함께 움직이게 뽑아야 합니다. 난수 개수가 적으면 결과 자체가 흔들리므로, 개수를 두 배로 해도 결과가 변하지 않는지 확인합니다.
요약
  1. 입력을 분포에서 뽑아 결과 분포를 얻는다.
  2. 작고 선형적인 불확도에서는 선형 전파와 같다.
  3. 비선형·큰 불확도·상관 입력에서 몬테카를로가 유리.

4.5.2연습문제

기본

  1. 예제에서 \(T\)의 불확도를 절반(0.005 s)으로 줄이면 선형 상대 불확도는?
    답

    \(\sqrt{0.002^2 + (2\times0.005/2.006)^2} = 0.54\)%.

응용

  1. \(y = 1/(x - 1)\)에서 \(x = 1.10 \pm 0.05\)일 때 선형 전파가 왜 믿기 어려운가?
    답

    분모가 0에 가까워 \(x\)가 1.05~1.15 사이에서 \(y\)가 20~6.7로 크게, 비대칭으로 변한다. 결과 분포가 한쪽으로 길게 늘어져 선형 근사가 맞지 않으므로 몬테카를로를 쓴다.

심화

  1. 몬테카를로 결과의 2.5~97.5% 구간이 평균 ± 2σ와 다르게 비대칭이면 무엇을 뜻하는가?
    답

    결과 분포가 정규가 아니다(비선형 때문). 보고할 때 대칭 ±가 아니라 구간(하한, 상한)으로 적는다.
