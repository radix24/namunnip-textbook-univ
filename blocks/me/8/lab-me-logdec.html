자유 진동 기록 한 장으로 감쇠비를 잴 수 있을까?

실습 · 대수 감쇠율과 측정 잡음 (가상 측정)

목표

외팔보 끝을 툭 쳐서 가속도계로 기록한 자유 진동 신호를 흉내 낸 가상 측정 자료에서 봉우리 높이를 읽어 감쇠비를 추정합니다. 몇 주기를 건너뛰어 비교해야 잡음에 덜 흔들리는지 확인합니다. 성취기준 [기계8-02-01], [기계13-02-02].

준비

감쇠 자유 진동은 \(x(t) = x_0 e^{-\zeta\omega_n t}\cos\omega_d t\), \(\omega_d = \omega_n\sqrt{1-\zeta^2}\)입니다. 한 주기 \(T_d = 2\pi/\omega_d\)마다 봉우리는 같은 비율로 줄어듭니다. 그 비의 로그가 대수 감쇠율입니다.

\[\delta = \ln\frac{x_k}{x_{k+1}} = \frac1n\ln\frac{x_0}{x_n} = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}}\]

마지막 식을 \(\zeta\)에 대해 풀면 \(\zeta = \delta/\sqrt{4\pi^2+\delta^2}\)입니다. 가상 자료는 고유진동수 5 Hz, 처음 진폭 10 mm, 표본화 500 Hz로 만들고, 측정 잡음(정규분포, 처음 진폭에 대한 %)을 더합니다. 장치는 실험실에서 하듯 먼저 11점 이동 평균(22 ms)으로 잡음을 줄인 뒤, 앞뒤 1/4 주기 안에서 가장 높은 점을 봉우리로 찾아 점으로 표시하고, 빨간 두 점(처음과 n번째 뒤)으로 \(\delta\)를 계산합니다.

절차

  1. 잡음 0%, ζ = 0.05에서 n을 1, 5, 10으로 바꾸며 추정 감쇠비를 적습니다.
  2. 잡음을 3%로 올리고, n = 1과 n = 3에서 "새 측정"을 열 번씩 눌러 추정값을 표로 적습니다.
  3. 두 경우의 평균과 흩어진 정도(최댓값 − 최솟값)를 비교합니다.
  4. ζ = 0.15, 잡음 3%로 바꾸고 n을 1, 2, 4, 8로 키우며 추정값이 어느 쪽으로 치우치는지 봅니다.

기대 결과

아래 값은 이 장치로 "새 측정"을 20번씩 해서 얻은 가상 측정 결과입니다. 잡음은 매번 달라지므로 여러분의 값은 조금씩 다릅니다.

  • 잡음이 없으면 n과 상관없이 0.0500으로 참값과 0.1% 안에서 맞습니다. 첫 봉우리는 한 주기 뒤(약 0.2 s)의 7.17 mm입니다. t = 0의 출발점은 봉우리로 세지 않고, 이동 평균 때문에 봉우리가 모두 약 2% 낮게 읽히지만 비는 변하지 않습니다.
  • ζ = 0.05, 잡음 3%: n = 1이면 0.044~0.057로 흩어지고(평균 0.049), n = 3이면 0.048~0.053으로 흩어짐이 절반 이하로 줄어듭니다. n = 8에서는 다시 0.045~0.054로 넓어지고 평균이 0.0485로 조금 낮아집니다.
  • ζ = 0.15, 잡음 3%: n = 1, 2에서는 평균 0.148, 0.144로 참값에 가깝지만, n = 4에서 평균 0.119, n = 8에서 0.065로 크게 낮게 나옵니다. 감쇠가 크면 몇 주기 만에 봉우리가 잡음 수준(0.3 mm)으로 작아지고, 잡음 위에서 가장 높은 점을 고르면 작은 봉우리가 실제보다 크게 읽혀 감쇠가 작게 계산됩니다.
  • 정리하면 봉우리가 처음 진폭의 1/3~1/5 정도로 줄어드는 n을 고르는 것이 알맞습니다. ζ = 0.05면 n = 3~5, ζ = 0.15면 n = 1~2입니다.

분석

  1. \(x_0/x_n\)에 잡음 \(\pm e\)가 섞이면 \(\delta\)의 오차는 대략 \((e/x_0 + e/x_n)/n\)입니다. n이 클 때 좋아지다가 너무 크면 나빠지는 이유를 이 식으로 설명해 보세요.
  2. 실제 실험에서 같은 측정을 여러 번 하고 평균을 내면 불확도는 어떻게 줄어들까요([기계7-01-02])?
  3. 감쇠비가 0.01 이하로 아주 작으면 대수 감쇠율 방법 말고 어떤 방법(반전력 대역폭 등)이 쓰일까요?
