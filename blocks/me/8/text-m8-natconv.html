자연 대류 실험: 수직 가열판

본문
이 절에서 배울 것
  • 가열판의 전력과 표면 온도로 자연 대류 열전달 계수를 구한다.
  • 복사 손실을 빼 대류 몫만 분리한다.
  • Rayleigh 수 상관식과 비교한다.
먼저 알아야 할 것
  • 대류 열전달 계수 측정 (3.1절), 방사율 (3.4절).

3.5.1측정과 분리

세운 가열판에 일정 전력을 넣고 정상 상태 표면 온도를 잽니다. 판에서 나가는 열은 자연 대류와 복사 둘이고, 뒷면과 가장자리는 단열합니다. 표면 온도가 주위보다 수십 K 높으면 복사가 대류와 비슷한 크기라 반드시 빼야 합니다.

대류 분리와 상관식 (수직 평판, 층류)

\[h = \frac{\dot Q - \varepsilon\sigma A(T_s^4 - T_\infty^4)}{A(T_s - T_\infty)}\]

\[Ra_L = \frac{g\beta(T_s - T_\infty)L^3}{\nu\alpha},\qquad \overline{Nu} = 0.59Ra_L^{1/4}\quad(10^4 < Ra < 10^9)\]

이상기체 \(\beta = 1/T_f\)(막 온도, K), 물성은 막 온도에서.

예제 3.5.1 (상관식 예측)

높이 0.2 m 수직판, 표면 60 °C, 공기 20 °C(막 온도 40 °C: \(\nu = 1.70\times10^{-5}\), Pr = 0.71, \(k\) = 0.0271). 상관식 \(h\)와 0.2 × 0.2 m 한 면의 대류 열량은?

풀이. \(\alpha = \nu/\text{Pr} = 2.39\times10^{-5}\), \(Ra = 9.81\times(1/313)\times40\times0.008/(1.70\times10^{-5}\times2.39\times10^{-5}) = 2.5\times10^7\)(층류). \(Nu = 0.59\times(2.5\times10^7)^{1/4} = 41.6\), \(h = 41.6\times0.0271/0.2 = 5.6\) W/m²·K. 한 면 대류 \(5.6\times0.04\times40 = 9.0\) W.

주의자연 대류는 주위 공기 흐름에 매우 민감합니다. 문 여닫힘, 사람 움직임, 환기 바람이 \(h\)를 크게 흔들므로, 판 주위를 가림막으로 둘러싸고 측정 중 움직임을 줄입니다.
요약
  1. 전력에서 복사 몫을 빼 대류 \(h\)를 구한다.
  2. \(Ra = g\beta\Delta TL^3/(\nu\alpha)\), 층류 \(Nu = 0.59Ra^{1/4}\).
  3. 주위 바람을 막는다.

3.5.2연습문제

기본

  1. 예제 판(한 면 0.04 m², \(\varepsilon\) = 0.9)의 복사 열량은?
    답

    \(0.9\times5.67\times10^{-8}\times0.04\times(333^4 - 293^4) = 10.1\) W로 대류(9.0 W)보다 크다.

응용

  1. 한 면 전력 18.6 W를 넣었더니 표면이 60 °C였다. 복사(10.1 W)를 빼면 측정 \(h\)는? 상관식과 비교하여라.
    답

    대류 8.5 W, \(h = 8.5/(0.04\times40) = 5.3\) W/m²·K. 상관식 5.6과 5% 차이.

심화

  1. 판 높이를 2배로 하면 상관식 \(h\)는 몇 배인가(층류)?
    답

    \(Nu \propto L^{3/4}\), \(h = Nu\,k/L \propto L^{-1/4}\): \(2^{-1/4} = 0.84\)배.
