차원해석과 Buckingham π 정리

본문
이 절에서 배울 것
  • 물리 법칙이 차원적으로 동차여야 한다는 원리로 변수의 관계를 줄인다.
  • Buckingham π 정리로 무차원 변수(π 묶음)의 개수와 모양을 구한다.
  • 레이놀즈수, 프루드수, 마하수 같은 대표 무차원수의 물리적 뜻을 안다.
먼저 알아야 할 것
  • 단위와 차원 (일반물리학및실험(1) 1.1절), N-S 방정식의 각 항 (5.2절).
  • 연립일차방정식 풀기(고등학교 수학).

6.1.1왜 차원해석인가

공에 작용하는 항력 \(F\)가 지름 \(D\), 속도 \(V\), 밀도 \(\rho\), 점도 \(\mu\)에 어떻게 달려 있는지 실험으로 알아내려 한다고 합시다. 변수마다 10개 값씩 바꾸면 \(10^4\)번 실험해야 합니다. 그런데 어떤 물리 관계도 양변의 차원이 같아야 하므로, 변수들은 차원이 없는 몇 개의 묶음으로만 결합할 수 있습니다. 이 사실을 쓰면 실험 횟수가 극적으로 줄고, 작은 모형의 결과를 실물로 옮길 수 있습니다(6.2절).

6.1.2Buckingham π 정리

Buckingham π 정리

\(n\)개의 변수 사이의 물리 관계가 \(k\)개의 기본 차원(보통 질량 M, 길이 L, 시간 T)으로 표현되면, 그 관계는 \(n - k\)개의 독립된 무차원 묶음 \(\Pi_1, \Pi_2, \ldots\) 사이의 관계로 바꾸어 쓸 수 있다.

\[\Pi_1 = \phi(\Pi_2, \ldots, \Pi_{n-k})\]

π 묶음을 만드는 순서(반복 변수법):

  1. 변수를 모두 적고 각각의 차원을 M, L, T로 쓴다. \(n\)과 \(k\)를 센다.
  2. 반복 변수 \(k\)개를 고른다. 이들끼리는 무차원 묶음을 만들 수 없어야 하고, 보통 기하(\(D\)), 운동(\(V\)), 유체(\(\rho\))를 하나씩 고른다. 구하려는 변수(종속 변수)는 고르지 않는다.
  3. 나머지 변수마다 \(\Pi = (\text{변수})D^a V^b \rho^c\)로 두고, M, L, T의 지수가 모두 0이 되도록 \(a\), \(b\), \(c\)를 연립방정식으로 푼다.
  4. 결과를 잘 알려진 무차원수 모양으로 다듬는다(역수, 거듭제곱을 취해도 무차원).
예제 6.1.1 (구의 항력)

항력 \(F = f(D, V, \rho, \mu)\)의 무차원 관계를 구하여라.

풀이. 차원: \(F\) [MLT⁻²], \(D\) [L], \(V\) [LT⁻¹], \(\rho\) [ML⁻³], \(\mu\) [ML⁻¹T⁻¹]. \(n = 5\), \(k = 3\)이므로 π는 2개. 반복 변수 \(D\), \(V\), \(\rho\).

  • \(\Pi_1 = FD^aV^b\rho^c\): M: \(1 + c = 0\), T: \(-2 - b = 0\), L: \(1 + a + b - 3c = 0\). 풀면 \(c = -1\), \(b = -2\), \(a = -2\). \(\Pi_1 = F/(\rho V^2D^2)\).
  • \(\Pi_2 = \mu D^aV^b\rho^c\): M: \(1 + c = 0\), T: \(-1 - b = 0\), L: \(-1 + a + b - 3c = 0\). \(c = -1\), \(b = -1\), \(a = -1\). \(\Pi_2 = \mu/(\rho VD)\), 역수를 취해 \(\text{Re} = \rho VD/\mu\).
\[\frac{F}{\rho V^2D^2} = \phi(\text{Re})\]

변수 다섯 개짜리 함수가 변수 하나짜리 함수가 되었습니다. 레이놀즈수만 바꾸며 실험해 곡선 하나를 얻으면 어떤 구, 어떤 유체에도 씁니다. 이 곡선이 7.2절의 항력계수 그래프입니다(\(F/(\rho V^2D^2)\)에 상수를 곱해 \(C_D\)로 씀).

예제 6.1.2 (관의 압력 강하)

곧은 관의 압력 강하 \(\Delta P = f(V, D, L, \rho, \mu, \varepsilon)\)(\(\varepsilon\)은 벽 거칠기)의 무차원 관계는?

풀이. \(n = 7\), \(k = 3\), π는 4개. 반복 변수 \(D\), \(V\), \(\rho\)로 앞 예제와 같이 풀면 \(\Delta P/(\rho V^2)\), \(\text{Re}\), \(L/D\), \(\varepsilon/D\). 압력 강하는 관 길이에 비례하므로 \(\Delta P/(\rho V^2) = (L/D)\,\phi(\text{Re}, \varepsilon/D)\)로 쓸 수 있고, 이것이 4.4절 Darcy 식 \(h_f = f(L/D)V^2/2g\)이며 \(f = f(\text{Re}, \varepsilon/D)\)가 Moody 선도입니다.

6.1.3대표 무차원수

무차원수는 대부분 두 힘의 비입니다. 5.2절 N-S 식의 각 항의 크기를 비교한 것으로 볼 수 있습니다.

레이놀즈수 \(\text{Re} = \rho VL/\mu\): 관성력/점성력. 크면 난류, 작으면 점성이 지배(층류, 미생물의 세계).

프루드수 \(\text{Fr} = V/\sqrt{gL}\): 관성력/중력의 제곱근. 자유 표면 흐름(배의 파도, 개수로, 댐 여수로).

마하수 \(\text{Ma} = V/c\): 흐름 속도/음속. 0.3 이상이면 압축성 효과.

압력계수·오일러수 \(C_p = \Delta P/(\tfrac12\rho V^2)\): 압력/동압.

웨버수 \(\text{We} = \rho V^2L/\sigma\): 관성력/표면장력. 물방울, 분무.

주의(1) π 정리는 묶음의 모양을 줄 뿐 함수 \(\phi\)는 실험이나 해석으로 구해야 합니다. (2) 중요한 변수를 빠뜨리면 틀린 결론이 나오고, 상관없는 변수를 넣으면 쓸모없는 π가 늘어납니다. 어떤 변수가 중요한지는 물리적 판단입니다. (3) 반복 변수로 서로 무차원 묶음을 만드는 것(예: \(D\)와 \(L\))을 함께 고르면 안 됩니다.
요약
  1. 변수 \(n\)개, 기본 차원 \(k\)개이면 무차원 묶음 \(n - k\)개.
  2. 반복 변수(보통 \(D\), \(V\), \(\rho\))로 나머지를 무차원화한다.
  3. Re(관성/점성), Fr(관성/중력), Ma(속도/음속), \(C_p\)(압력/동압).

6.1.4연습문제

기본

  1. 진자의 주기 \(T\)가 길이 \(L\), 질량 \(m\), 중력 가속도 \(g\)에 달려 있다고 하자. 차원해석으로 관계를 구하여라.
    답

    \(n = 4\), \(k = 3\), π 하나: \(T\sqrt{g/L}\) = 상수. 질량은 다른 변수와 묶일 수 없어 빠진다. \(T \propto \sqrt{L/g}\)(실제 상수는 \(2\pi\)).

응용

  1. 펌프의 양정 \(gH\)(단위 질량당 에너지)가 유량 \(Q\), 회전 속도 \(N\), 회전차 지름 \(D\), \(\rho\), \(\mu\)에 달려 있다. 반복 변수 \(N\), \(D\), \(\rho\)로 π 묶음을 구하여라.
    답

    \(gH/(N^2D^2)\)(양정 계수), \(Q/(ND^3)\)(유량 계수), \(\rho ND^2/\mu\)(레이놀즈수). 6.2절 상사 법칙에 씁니다.

심화

  1. 작은 물방울이 공기 중에서 떨어지는 종단 속도 \(V\)는 \(D\), \(\rho_{\text{물}} - \rho_{\text{공기}}\)에 의한 \(\Delta\rho g\)(단위 부피당 알짜 무게), \(\mu\)에만 달려 있다(점성이 지배, 관성 무시). \(V\)의 꼴을 구하여라.
    답

    변수 \(V\), \(D\), \(\Delta\rho g\)[ML⁻²T⁻²], \(\mu\): \(n = 4\), \(k = 3\), π 하나. \(V\mu/(\Delta\rho gD^2)\) = 상수. Stokes 해석으로 상수는 1/18이다: \(V = \Delta\rho gD^2/(18\mu)\).
