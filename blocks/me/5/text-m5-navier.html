5.2.1작은 덩어리의 F = ma

찾는 것은 속도장 자체입니다. 5.1절의 작은 상자에 뉴턴 제2법칙을 씁니다: 질량 × 가속도(물질도함수) = 압력 힘 + 점성 힘 + 중력. 단위 부피당으로 쓰면

\[\rho\frac{D\vec V}{Dt} = -\nabla P + \mu\nabla^2\vec V + \rho\vec g\]

이 비압축성 뉴턴 유체의 Navier-Stokes 방정식입니다. \(x\) 성분을 2차원으로 풀어 쓰면

\[\rho\Bigl(\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y}\Bigr) = -\frac{\partial P}{\partial x} + \mu\Bigl(\frac{\partial^2u}{\partial x^2} + \frac{\partial^2u}{\partial y^2}\Bigr) + \rho g_x\]

각 항의 뜻은 다음과 같습니다.

왼쪽: 입자의 가속도(국소 + 대류, 3.1절). 대류 항이 속도의 곱이라 방정식이 비선형이다.

\(-\partial P/\partial x\): 압력이 높은 쪽에서 낮은 쪽으로 미는 힘.

\(\mu\nabla^2u\): 점성 힘. 이웃 층과의 전단 응력 차이로, 속도 분포가 휘어 있을 때 생긴다(곧은 직선 분포면 0).

\(\rho g_x\): 중력.

점성 항을 빼면(\(\mu = 0\)) Euler 방정식이고, 이것을 유선을 따라 적분한 것이 3.2절의 Bernoulli 식입니다. 미지수는 \(u\), \(v\), \(w\), \(P\) 넷이고 식은 N-S 세 성분과 연속 방정식으로 넷이라 닫혀 있습니다. 그러나 비선형이라 일반해는 없고, 대류 항이 0이 되는 단순한 경우에만 정확히 풀립니다.

5.2.2평행판 사이 흐름

간격 \(h\)인 무한히 넓은 두 평판 사이의 정상 흐름을 봅니다. 가정: 흐름은 \(x\) 방향으로만(\(v = 0\)), 속도는 \(y\)에만 따라 변함(\(u = u(y)\), 완전 발달). 그러면

  1. 연속 방정식: \(\partial u/\partial x = 0\), 가정과 맞다.
  2. 대류 항: \(u\,\partial u/\partial x + v\,\partial u/\partial y = 0\). 비선형 항이 사라진다.
  3. \(x\) 성분 N-S(수평, 정상): \(0 = -dP/dx + \mu\,d^2u/dy^2\).

압력 기울기 \(dP/dx\)는 상수입니다(\(y\) 성분 식에서 \(P\)는 \(y\)에 따라 정수압 분포만 하므로). 두 번 적분하면

\[u(y) = \frac{1}{2\mu}\frac{dP}{dx}y^2 + C_1y + C_2\]

두 경계 조건(벽에서 유체는 벽과 같은 속도, 미끄럼 없음 조건)으로 상수를 정합니다. 아래판은 정지(\(u(0) = 0\)), 윗판은 속도 \(U\)(\(u(h) = U\))이면

Couette-Poiseuille 유동 \[u(y) = U\frac{y}{h} + \frac{G}{2\mu}y(h - y)\] \[q = \frac{Uh}{2} + \frac{Gh^3}{12\mu}\]

\(G = -dP/dx\)(하류로 압력이 떨어지면 양수), \(q\)는 깊이당 유량.

  • Couette 유동(\(G = 0\)): 직선 분포 \(u = Uy/h\). 1.1절에서 가정했던 분포가 N-S의 정확해임이 확인된다. 베어링, 점도계.
  • 평판 Poiseuille 유동(\(U = 0\)): 포물선 분포, 최대 속도 \(Gh^2/(8\mu)\)는 가운데, 평균 속도는 최대의 2/3.
  • 역압력 기울기(\(G < 0\)): 압력이 하류로 오르면 정지한 벽 근처에서 흐름이 거꾸로 갈 수 있다. \(G < -2\mu U/h^2\)이면 아랫벽에서 역류가 시작된다. 7.2절의 박리와 같은 원리다.
예제 5.2.1 (얇은 틈의 물 흐름)

간격 1 mm 평판 사이에 물(\(\mu = 10^{-3}\) Pa·s)이 \(-dP/dx = 1000\) Pa/m로 흐른다. 최대 속도, 깊이 1 m당 유량, 벽 전단 응력은?

풀이. \(u_{\max} = 1000\times10^{-6}/(8\times10^{-3}) = 0.125\) m/s, \(q = 1000\times10^{-9}/(12\times10^{-3}) = 8.33\times10^{-5}\) m²/s(0.083 L/s). 벽에서 \(du/dy = Gh/(2\mu)\)이므로 \(\tau_w = Gh/2 = 0.5\) Pa. 힘의 평형으로 검산합니다: 두 벽의 마찰 \(2\tau_w = 1\) Pa/m = 압력 기울기 × 간격 \(1000\times0.001\). 맞습니다.

5.2.3원관의 Hagen-Poiseuille 유동

원관은 원통 좌표의 N-S를 써야 하지만, 같은 결과를 힘의 평형으로 얻을 수 있습니다. 반지름 \(r\), 길이 \(L\)인 유체 원기둥(관과 같은 축)을 생각합니다. 완전 발달 정상 흐름이면 가속도가 없으므로 앞뒤 압력 차가 옆면의 전단 응력과 평형입니다.

\[\Delta P\,\pi r^2 = \tau(2\pi rL) \Rightarrow \tau = \frac{\Delta P}{2L}r\]

전단 응력은 중심에서 0, 벽에서 최대로 직선적으로 커집니다. 뉴턴 유체이면 \(\tau = -\mu\,du/dr\)(바깥으로 갈수록 느려지므로 음의 부호)이고, 적분하여 벽(\(r = R\))에서 \(u = 0\)을 쓰면

Hagen-Poiseuille 유동 \[u(r) = \frac{\Delta P}{4\mu L}(R^2 - r^2)\] \[Q = \frac{\pi R^4\Delta P}{8\mu L}\]

평균 속도는 최대 속도(중심)의 1/2. 층류(레이놀즈수 약 2300 이하)에서만 성립한다(7.1절).

유량이 반지름의 네제곱에 비례합니다. 혈관 반지름이 10% 줄면 같은 압력에서 혈류가 34% 줄어, 동맥 경화가 위험한 이유입니다.

주의(1) 정확해는 "완전 발달"(입구에서 멀리 떨어져 분포가 더 변하지 않음)과 층류를 가정합니다. (2) 미끄럼 없음 조건은 연속체 유체의 실험 사실이며, 매우 희박한 기체나 나노 규모 틈에서는 깨집니다. (3) 압력 기울기의 부호: 압력이 하류로 떨어질 때 \(dP/dx < 0\), \(G > 0\)입니다.
요약
  1. N-S: 질량 × 가속도 = 압력 힘 + 점성 힘 \(\mu\nabla^2\vec V\) + 중력. \(\mu = 0\)이면 Euler 방정식.
  2. 평행판: \(u = Uy/h + (G/2\mu)y(h - y)\), \(q = Uh/2 + Gh^3/(12\mu)\).
  3. 원관: \(u = \frac{\Delta P}{4\mu L}(R^2 - r^2)\), \(Q = \pi R^4\Delta P/(8\mu L)\).

5.2.4연습문제

기본

  1. 평판 Poiseuille 유동에서 평균 속도가 최대 속도의 2/3임을 보여라.
    답

    \(\bar u = q/h = Gh^2/(12\mu)\), \(u_{\max} = Gh^2/(8\mu)\). 비 \(8/12 = 2/3\).

응용

  1. Couette-Poiseuille 유동에서 알짜 유량이 0이 되는 압력 기울기는? 그때의 속도 분포 모양은?
    답

    \(q = 0\)에서 \(G = -6\mu U/h^2\). 윗판 근처는 판을 따라 가고 아래쪽은 거꾸로 흘러 합이 0이다. 판으로 막힌 홈 속에서 끌려 도는 흐름(스크루 압출기)이다.

심화

  1. 원관 Hagen-Poiseuille 흐름의 벽 전단 응력을 평균 속도로 나타내고, 마찰계수 \(f = 8\tau_w/(\rho\bar V^2)\)가 \(64/\text{Re}\)임을 보여라(\(\text{Re} = \rho\bar VD/\mu\)).
    답

    \(\tau_w = \Delta P R/(2L)\), \(\bar V = \Delta PR^2/(8\mu L)\)이므로 \(\tau_w = 4\mu\bar V/R = 8\mu\bar V/D\). \(f = 64\mu/(\rho\bar VD) = 64/\text{Re}\). 7.1절에서 씁니다.
