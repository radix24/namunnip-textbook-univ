미분형 연속 방정식, 유동함수, 와도

본문
이 절에서 배울 것
  • 작은 상자에 질량 보존을 써서 미분형 연속 방정식을 유도한다.
  • 2차원 비압축성 흐름의 유동함수를 정의하고, 유선과 유량을 읽는다.

  • 검사체적 질량 보존 (4.1절), 속도장과 유선 (3.1절).
  • 편미분 (미분적분학과벡터해석(2) 4.2절), 발산과 회전 (7.5절).

5.1.1왜 미분형인가

4단원의 적분형 식은 입출구에서 전체 힘과 유량을 주지만, 흐름 속의 속도 분포나 벽의 전단 응력은 알려 주지 않습니다. 그것을 알려면 아주 작은 상자(크기 \(dx\), \(dy\), \(dz\))에 같은 법칙을 쓰고 크기를 0으로 보내 편미분방정식을 얻습니다. 이것이 미분 해석입니다.

5.1.2연속 방정식의 유도

찾는 것은 속도장이 질량 보존을 만족할 조건입니다. 고정된 작은 상자에서 \(x\) 방향만 먼저 봅니다.

  1. 왼쪽 면(넓이 \(dy\,dz\))으로 매초 들어오는 질량: \(\rho u\,dy\,dz\).
  2. 오른쪽 면으로 나가는 질량: \(\bigl(\rho u + \frac{\partial(\rho u)}{\partial x}dx\bigr)dy\,dz\). 테일러 전개의 1차 항만 남긴다.
  3. \(x\) 방향의 알짜 유출: \(\frac{\partial(\rho u)}{\partial x}dx\,dy\,dz\). \(y\), \(z\) 방향도 같다.
  4. 상자 안 질량의 증가율 \(\frac{\partial\rho}{\partial t}dx\,dy\,dz\)와 알짜 유출의 합이 0(4.1절).
연속 방정식 \[\frac{\partial\rho}{\partial t} + \frac{\partial(\rho u)}{\partial x} + \frac{\partial(\rho v)}{\partial y} + \frac{\partial(\rho w)}{\partial z} = 0\]

비압축성(\(\rho\) 일정)이면

\[\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} = 0\]

비압축성 식의 왼쪽을 속도의 발산 \(\nabla\cdot\vec V\)라 합니다. 한 점에서 흐름이 퍼져 나가는 정도인데, 액체는 압축되지 않으니 어느 점에서나 0이어야 합니다. 한 방향으로 빨라지면(\(\partial u/\partial x > 0\)) 다른 방향으로는 그만큼 좁혀져야 합니다.

예제 5.1.1 (속도장 검사)

2차원 속도장 \(u = x^2 + y\), \(v = -2xy\)는 비압축성 흐름이 될 수 있는가? \(u = 2x\), \(v = 2y\)는?

풀이. 첫째: \(\partial u/\partial x + \partial v/\partial y = 2x - 2x = 0\). 가능합니다. 둘째: \(2 + 2 = 4 \neq 0\). 모든 점에서 유체가 퍼져 나가므로 비압축성 흐름일 수 없습니다(밀도가 줄어드는 기체라면 가능).

5.1.3유동함수

2차원 비압축성 흐름에서는 두 속도 성분을 함수 하나 \(\psi(x, y)\)로 쓸 수 있습니다.

정의 5.1.1 (유동함수) \[u = \frac{\partial\psi}{\partial y}\] \[v = -\frac{\partial\psi}{\partial x}\]

이렇게 두면 \(\partial u/\partial x + \partial v/\partial y = \psi_{yx} - \psi_{xy} = 0\)이라 연속 방정식이 저절로 만족됩니다(혼합 편미분의 순서는 바꿀 수 있음). 미지수 둘이 하나로 줄어드는 셈입니다. 유동함수에는 두 가지 뜻이 있습니다.

  • \(\psi\) = 일정인 곡선이 유선이다. 곡선을 따라 \(d\psi = \psi_xdx + \psi_ydy = -v\,dx + u\,dy = 0\)이면 \(dy/dx = v/u\)로, 속도에 접한다.
  • 두 유선 사이의 유량은 \(\psi\) 값의 차이다. 단위 깊이당 \(q = \psi_2 - \psi_1\). 유선이 촘촘한 곳일수록 같은 유량이 좁은 틈을 지나므로 빠르다.
예제 5.1.2 (정체점 유동의 유동함수)

3.1절의 \(u = kx\), \(v = -ky\)(\(k = 2\) s⁻¹)의 유동함수를 구하고, 유선 \(\psi = 1\)과 \(\psi = 3\) m²/s 사이의 유량을 구하여라.

풀이. \(\partial\psi/\partial y = kx\)를 \(y\)로 적분하면 \(\psi = kxy + g(x)\). \(-\partial\psi/\partial x = -ky - g'(x) = -ky\)에서 \(g' = 0\)이므로 \(\psi = 2xy\)(상수는 버림). 유선은 \(xy = C\)인 쌍곡선으로 3.1절 연습문제의 답과 같습니다. 두 유선 사이로는 깊이 1 m당 2 m³/s가 흐릅니다.

5.1.4와도와 비회전 흐름

유체 입자는 움직이면서 스스로 돌 수 있습니다. 그 회전의 세기를 재는 양이 와도입니다.

정의 5.1.2 (2차원 와도) \[\omega_z = \frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\]

유체 입자 각속도의 두 배이다. 어디서나 \(\omega_z = 0\)이면 비회전 흐름이라 한다.

예를 들어 보겠습니다.

  • 강체 회전 \(u = -\Omega y\), \(v = \Omega x\): \(\omega_z = 2\Omega\). 통째로 도는 물은 각 입자도 돈다.
  • 평행판 사이 전단 \(u = Uy/h\): \(\omega_z = -U/h\). 곧게 흐르지만 위아래 속도 차 때문에 입자가 굴러 간다.
  • 정체점 유동 \(u = kx\), \(v = -ky\): \(\omega_z = 0\). 입자는 찌그러지기만 하고 돌지 않는다.

비회전 흐름에서는 속도를 속도 퍼텐셜 \(\phi\)의 기울기로 쓸 수 있습니다: \(u = \partial\phi/\partial x\), \(v = \partial\phi/\partial y\). 비압축성까지 겹치면 \(\psi\)와 \(\phi\)가 모두 Laplace 방정식 \(\partial^2\psi/\partial x^2 + \partial^2\psi/\partial y^2 = 0\)을 만족해, 균일 흐름, 원천, 와류 같은 기본 흐름을 더해서 복잡한 흐름(원주 주위 흐름)을 만들 수 있습니다. 점성의 영향이 얇은 경계층에 갇히는 물체 바깥 흐름을 이렇게 근사합니다(퍼텐셜 유동 탐구).

주의(1) 유동함수는 2차원(또는 축대칭) 흐름에서만 정의됩니다. (2) \(v = -\partial\psi/\partial x\)의 음의 부호를 빠뜨리기 쉽습니다. (3) 곧게 흐르는 흐름(전단)도 와도가 있고, 원을 그리는 흐름(자유 와류 \(V_\theta = \Gamma/2\pi r\))도 중심 밖에서는 와도가 0입니다. 와도는 입자의 경로가 아니라 입자 자신의 회전입니다.
요약
  1. 연속 방정식 \(\partial\rho/\partial t + \nabla\cdot(\rho\vec V) = 0\), 비압축성이면 \(\nabla\cdot\vec V = 0\).
  2. \(u = \psi_y\), \(v = -\psi_x\). \(\psi\) 일정 = 유선, 유선 사이 유량 = \(\psi\)의 차.
  3. 와도 \(\omega_z = v_x - u_y\). 비회전이면 속도 퍼텐셜이 있고, 기본 흐름을 겹쳐 쓸 수 있다.

5.1.5연습문제

기본

  1. 비압축성 2차원 흐름에서 \(u = 3x\)이고 \(y = 0\)에서 \(v = 0\)이다. \(v\)는?
    답

    \(\partial v/\partial y = -3\), \(v = -3y\).

응용

  1. \(\psi = 4x^2 - 4y^2\)의 속도장을 구하고, 비회전인지 판단하여라.
    답

    \(u = -8y\), \(v = -8x\). \(\omega_z = -8 - (-8) = 0\), 비회전이다.

심화

  1. 균일 흐름 \(\psi = Uy\)와 원점의 원천 \(\psi = (m/2\pi)\theta\)를 더한 흐름에서, 하류 멀리 원천에서 나온 유체가 차지하는 폭이 \(m/U\)임을 유량으로 설명하여라.
    답

    원천은 깊이당 \(m\)의 유량을 내보내고, 하류 멀리에서는 속도가 \(U\)로 균일해진다. 폭 \(w\)에서 \(Uw = m\), \(w = m/U\)(위아래 반씩).
