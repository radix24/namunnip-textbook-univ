가스통 벽의 응력과 비스듬한 면

예제 · 원주·축 응력 · Mohr 원 · 면외 전단
문제 해결 전략 · 응력 변환
  1. 점의 응력 요소를 그린다: \(\sigma_x\), \(\sigma_y\), \(\tau_{xy}\)와 부호(인장 +, 양의 \(x\)면에서 \(+y\) 방향 전단 +).
  2. \(C = (\sigma_x + \sigma_y)/2\), \(R = \sqrt{((\sigma_x - \sigma_y)/2)^2 + \tau_{xy}^2}\)를 구한다.
  3. 주응력 \(C \pm R\), 최대 면내 전단 \(R\). 특정 방향이 필요하면 변환식에 \(\theta\)를 넣는다(Mohr 원에서는 \(2\theta\)).
  4. 평면 응력에서는 \(\sigma_3 = 0\)도 생각해, 면외 최대 전단 응력 \(\max(|\sigma_1|, |\sigma_2|, |\sigma_1 - \sigma_2|)/2\)를 확인한다.

문제. 안지름 300 mm, 벽 두께 3 mm인 원통형 가스통에 1.8 MPa의 압력이 걸린다. (1) 원주 응력과 축 응력, (2) 축과 40°를 이루는 방향(그 방향이 법선인 면)의 수직 응력과 전단 응력, (3) 벽의 최대 전단 응력을 구하라.

풀이

  1. \(r/t = 150/3 = 50 > 10\)이므로 얇은 벽. \(\sigma_y = pr/t = 1.8\times150/3 = 90\) MPa(원주), \(\sigma_x = 45\) MPa(축).
    6.2절 정리 6.2.1. \(x\)를 축 방향으로 잡았다.
  2. \(C = 67.5\), \((\sigma_x - \sigma_y)/2 = -22.5\), \(\tau_{xy} = 0\), \(R = 22.5\) MPa.
    대칭이라 전단이 없으므로 두 응력이 곧 주응력.
  3. \(\theta = 40°\): \(\sigma_{x'} = 67.5 - 22.5\cos80° = 63.6\) MPa, \(\tau_{x'y'} = 22.5\sin80° = 22.2\) MPa.
    변환식에 \(\cos80° = 0.174\), \(\sin80° = 0.985\).
  4. 면내 최대 전단 22.5 MPa, 면외까지 보면 \(\sigma_1/2 = 45\) MPa가 실제 최대 전단 응력.
    \(\sigma_3 = 0\)과 \(\sigma_1 = 90\)이 만드는 원의 반지름.

검산

\(\theta = 40°\)와 \(130°\)의 수직 응력 합: \(\sigma_{y'} = 135 - 63.6 = 71.4\)이고, 직접 \(\theta = 130°\)를 넣으면 \(67.5 - 22.5\cos260° = 71.4\) MPa. 합이 \(\sigma_x + \sigma_y = 135\)로 일정합니다. 탐구 카드(6.1절)에 \(\sigma_x = 45\), \(\sigma_y = 90\), \(\tau_{xy} = 0\), \(\theta = 40°\)를 넣어 보아도 됩니다.

의미

원통 벽의 가장 큰 수직 응력은 원주 방향(90 MPa)이고, 비스듬한 면에서는 그보다 작습니다. 그런데 최대 전단 응력은 벽 면 안이 아니라 벽 두께 방향으로 기운 면(면외)에서 45 MPa로 면내 값의 두 배입니다. 연성 금속은 전단으로 항복하므로, 압력 용기를 설계할 때는 이 면외 전단까지 확인합니다.

바꿔 보기

허용 수직 응력 140 MPa로 정하면 최대 압력은 \(140\times3/150 = 2.8\) MPa입니다. 면외 최대 전단 응력이 허용 전단 70 MPa 이하여야 한다는 조건(\(\sigma_1/2 \le 70\))도 같은 2.8 MPa를 줍니다. 구형 용기였다면 응력이 절반이므로 5.6 MPa까지 견딥니다.

이해 확인

같은 가스통에서 축과 45°인 방향의 수직 응력과 전단 응력은?

답

\(\cos90° = 0\), \(\sin90° = 1\): \(\sigma_{x'} = C = 67.5\) MPa, \(\tau = R = 22.5\) MPa(면내 최대 전단 응력의 방향).
