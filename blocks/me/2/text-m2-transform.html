평면 응력 변환과 Mohr 원

본문
이 절에서 배울 것
  • 한 점의 응력 상태를 작은 정사각형 요소에 그린다.
  • 요소를 돌렸을 때의 응력을 변환식으로 구하고, 주응력과 최대 전단 응력을 찾는다.
  • 같은 계산을 Mohr 원으로 그림으로 한다.
먼저 알아야 할 것
  • 수직 응력과 전단 응력, 짝 전단 응력 (2.2절, 5.3절).
  • 삼각함수의 배각 공식: \(\cos^2\theta = \frac{1 + \cos2\theta}{2}\), \(\sin^2\theta = \frac{1 - \cos2\theta}{2}\), \(2\sin\theta\cos\theta = \sin2\theta\) (고교 수학I·미적분).

6.1.1왜 방향을 바꿔 보아야 하는가

분필을 당기면 축에 수직으로 똑 끊어지지만, 비틀면 45° 나선 모양으로 끊어집니다. 축에 수직인 단면만 보면 비틀림에는 전단 응력만 있고 수직 응력은 없는데, 왜 비스듬한 면으로 끊어질까요? 같은 점이라도 어느 방향의 면을 보느냐에 따라 응력이 다르기 때문입니다. 분필(취성 재료)은 인장 응력이 가장 큰 면으로 끊어지고, 비틀림에서는 그 면이 45°에 있습니다. 재료가 견디는지 판단하려면 모든 방향 중 응력이 가장 큰 방향을 찾아야 합니다.

6.1.2응력 요소와 부호

한 점 둘레에서 \(x\), \(y\)축에 나란한 아주 작은 정사각형(요소)을 떼어 냅니다. 얇은 판처럼 \(z\) 방향 면에는 응력이 없는 상태를 평면 응력이라 하고, 세 성분으로 나타냅니다.

\(\sigma_x\): \(x\)면(법선이 \(x\)방향인 면)의 수직 응력. 인장이 양.

\(\sigma_y\): \(y\)면의 수직 응력.

\(\tau_{xy}\): \(x\)면에서 \(+y\) 방향으로 작용하는 전단 응력. 양의 \(x\)면에서 \(+y\) 방향이면 양. 짝 전단 응력이므로 \(y\)면에도 같은 크기로 작용한다.

6.1.3변환식

요소를 반시계 방향으로 \(\theta\)만큼 돌린 축 \(x'\), \(y'\)에서의 응력을 구합니다. 원래 요소를 비스듬한 면으로 잘라 삼각형 쐐기를 만들고, 그 쐐기의 힘 평형을 씁니다(응력 × 넓이 = 힘). 비스듬한 면의 넓이를 \(A\)라 하면 \(x\)면 쪽 넓이는 \(A\cos\theta\), \(y\)면 쪽 넓이는 \(A\sin\theta\)입니다. 비스듬한 면의 법선 방향 힘 평형을 정리하고 배각 공식을 쓰면 다음 식이 나옵니다.

정리 6.1.1 (평면 응력 변환식) \[\sigma_{x'} = \frac{\sigma_x + \sigma_y}{2} + \frac{\sigma_x - \sigma_y}{2}\cos2\theta + \tau_{xy}\sin2\theta\] \[\tau_{x'y'} = -\frac{\sigma_x - \sigma_y}{2}\sin2\theta + \tau_{xy}\cos2\theta\]

\(\sigma_{y'}\)은 첫 식에 \(\theta + 90°\)를 넣은 값이며, \(\sigma_{x'} + \sigma_{y'} = \sigma_x + \sigma_y\)이다.

식에 \(2\theta\)가 나오는 것에 주목하세요. 요소를 180° 돌리면 같은 면을 다시 보는 것이므로, 응력은 180°마다(\(2\theta\)로는 360°마다) 반복되어야 합니다.

6.1.4주응력과 최대 전단 응력

\(\sigma_{x'}\)가 가장 크거나 작아지는 방향을 찾으려면 \(\theta\)로 미분해 0으로 둡니다. 그 조건은 \(\tau_{x'y'} = 0\)과 같습니다. 곧 수직 응력이 극값인 면에는 전단 응력이 없습니다.

정리 6.1.2 (주응력) \[\tan2\theta_p = \frac{2\tau_{xy}}{\sigma_x - \sigma_y}\] \[\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm R\] \[R = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}\]

최대 면내 전단 응력은 \(\tau_{\max} = R\)이고, 주방향에서 45° 돌아간 면에 생긴다. 그 면의 수직 응력은 평균값 \((\sigma_x + \sigma_y)/2\)이다.

주응력: 전단 응력이 0인 면의 수직 응력. 가장 큰 것이 \(\sigma_1\), 가장 작은 것이 \(\sigma_2\).

주방향: 주응력이 걸리는 면의 법선 방향. 서로 90° 떨어진 두 방향이다.

6.1.5Mohr 원

변환식 두 개를 제곱해 더하면 \(\theta\)가 사라지고 다음 식이 남습니다.

\[\left(\sigma_{x'} - \frac{\sigma_x + \sigma_y}{2}\right)^2 + \tau_{x'y'}^2 = R^2\]

이것은 \((\sigma, \tau)\) 평면에서 중심 \(C = ((\sigma_x + \sigma_y)/2, 0)\), 반지름 \(R\)인 원입니다. 요소를 돌리면 응력 점이 이 원 위를 움직입니다. 그리는 순서는 다음과 같습니다.

  1. 가로축 \(\sigma\), 세로축 \(\tau\)를 그린다. 이 책은 \(\tau\)축을 아래쪽이 양이 되게 그린다(그래야 요소를 반시계로 돌릴 때 점도 반시계로 돈다).
  2. 점 X\((\sigma_x, \tau_{xy})\)와 Y\((\sigma_y, -\tau_{xy})\)를 찍는다. 두 점을 잇는 선분이 지름이고, 가로축과 만나는 점이 중심 \(C\)이다.
  3. 원과 가로축의 교점이 주응력 \(\sigma_1\), \(\sigma_2\), 맨 위·아래 점이 최대 전단 응력 \(\pm R\)이다.
  4. 요소를 \(\theta\) 돌린 면의 응력은 X에서 같은 방향으로 \(2\theta\) 돈 점이다.
예제 6.1.3

\(\sigma_x = 80\), \(\sigma_y = -20\), \(\tau_{xy} = 30\) MPa인 점의 주응력, 주방향, 최대 전단 응력을 구하고, 30° 돌린 면의 응력을 구하여라.

풀이. 중심 \(C = 30\) MPa, \(R = \sqrt{50^2 + 30^2} = 58.3\) MPa. 주응력은 \(\sigma_1 = 88.3\), \(\sigma_2 = -28.3\) MPa. \(\tan2\theta_p = 60/100 = 0.6\)에서 \(2\theta_p = 31.0°\), \(\theta_p = 15.5°\)(\(\sigma_1\)의 방향). 최대 전단 응력은 58.3 MPa로 \(\theta = 15.5° + 45° = 60.5°\) 면에 생기고, 그 면의 수직 응력은 30 MPa입니다.

\(\theta = 30°\)이면 \(\cos60° = 0.5\), \(\sin60° = 0.866\)이므로

\[\sigma_{x'} = 30 + 50(0.5) + 30(0.866) = 81.0\ \text{MPa}\] \[\tau_{x'y'} = -50(0.866) + 30(0.5) = -28.3\ \text{MPa}\]

\(\sigma_{y'} = 60 - 81.0 = -21.0\) MPa. 이 절의 탐구 카드에서 θ = 30°로 놓고 확인해 보세요.

주의(1) Mohr 원 위의 각은 요소 회전각의 두 배입니다. (2) \(\tan2\theta_p\)는 두 각(90° 차이)을 주므로, 어느 것이 \(\sigma_1\)인지 변환식에 넣어 확인하세요. (3) 평면 응력에서도 \(z\) 방향 주응력 \(\sigma_3 = 0\)이 있으므로, 두 면내 주응력의 부호가 같으면 실제 최대 전단 응력은 \(\sigma_1/2\)(면외)일 수 있습니다. 압력 용기(6.2절)가 그런 경우입니다.
요약
  1. 같은 점이라도 면의 방향에 따라 응력이 다르다. 변환식은 \(2\theta\)의 삼각함수이다.
  2. 주응력 \(\sigma_{1,2} = C \pm R\)이 걸리는 면에는 전단 응력이 없다. \(\tan2\theta_p = 2\tau_{xy}/(\sigma_x - \sigma_y)\).
  3. 최대 면내 전단 응력 \(R\)은 주방향에서 45° 떨어진 면에 생긴다.
  4. Mohr 원: 중심 \((\sigma_x + \sigma_y)/2\), 반지름 \(R\). 요소를 \(\theta\) 돌리면 원 위에서 \(2\theta\) 돈다.

6.1.6연습문제

기본

  1. \(\sigma_x = 60\), \(\sigma_y = 20\), \(\tau_{xy} = 0\) MPa. 주응력과 최대 면내 전단 응력은?
    답

    이미 전단이 없으므로 \(\sigma_1 = 60\), \(\sigma_2 = 20\). \(R = 20\) MPa(45° 면).

  2. 순수 전단 \(\tau_{xy} = 40\) MPa의 주응력과 주방향은?
    답

    \(C = 0\), \(R = 40\). \(\sigma_1 = 40\)(45°), \(\sigma_2 = -40\)(135°).

응용

  1. \(\sigma_x = -50\), \(\sigma_y = 10\), \(\tau_{xy} = -40\) MPa. 주응력, \(\theta_p\), 최대 전단 응력을 구하여라.
    답

    \(C = -20\), \(R = \sqrt{30^2 + 40^2} = 50\). \(\sigma_1 = 30\), \(\sigma_2 = -70\). \(\tan2\theta_p = -80/(-60) = 1.333\): \(2\theta_p = 53.1°\) 또는 \(233.1°\). \(\theta = 26.6°\)를 넣으면 \(\sigma_{x'} = -20 - 30(0.6) - 40(0.8) = -70\)이므로 이것이 \(\sigma_2\) 방향, \(\sigma_1\)은 116.6°. \(\tau_{\max} = 50\) MPa.

심화

  1. 변환식의 첫째 식을 쐐기의 힘 평형에서 직접 유도하여라.
    힌트

    비스듬한 면의 법선 방향 성분: \(\sigma_{x'}A = \sigma_x(A\cos\theta)\cos\theta + \tau_{xy}(A\cos\theta)\sin\theta + \sigma_y(A\sin\theta)\sin\theta + \tau_{xy}(A\sin\theta)\cos\theta\).

    답

    \(\sigma_{x'} = \sigma_x\cos^2\theta + \sigma_y\sin^2\theta + 2\tau_{xy}\sin\theta\cos\theta\)에 배각 공식을 넣으면 정리 6.1.1의 첫 식이 된다.
