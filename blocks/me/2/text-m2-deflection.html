탄성 곡선과 적분법

본문
이 절에서 배울 것
  • 보의 처짐 곡선이 만족하는 미분방정식 \(EIv'' = M(x)\)을 곡률 식에서 얻는다.
  • 경계 조건(받침에서의 처짐·기울기)으로 적분 상수를 정해 처짐을 구한다.
  • 외팔보와 단순보의 대표 처짐 공식을 유도하고 크기를 가늠한다.
먼저 알아야 할 것
  • 굽힘 모멘트 식 \(M(x)\) (5.1절)과 곡률 \(1/\rho = M/(EI)\) (5.2절).
  • 부정적분과 적분 상수, 다항함수의 미분(고교 수학II).

7.1.1왜 처짐을 계산하는가

보가 부러지지 않아도 너무 많이 휘면 쓸 수 없습니다. 바닥이 출렁이면 사람이 불안해하고, 공작 기계의 주축이 휘면 가공 정밀도가 떨어지며, 기어 축이 휘면 기어가 제대로 물리지 않습니다. 건축 설계에서는 흔히 처짐을 길이의 1/360 이하로 제한합니다. 이 절의 목표는 하중이 주어질 때 보의 각 점이 얼마나 내려가는지, 곧 처짐 \(v(x)\)를 구하는 것입니다.

7.1.2처짐 곡선의 미분방정식

5.2절에서 보의 곡률이 \(1/\rho = M/(EI)\)임을 보였습니다. 한편 처짐이 작으면(기울기가 작으면) 곡선 \(v(x)\)의 곡률은 2계 도함수 \(v''\)와 거의 같습니다. 정확한 곡률은 \(v''/(1 + v'^2)^{3/2}\)인데, 기울기 \(v'\)가 0.01 정도이면 분모는 1.00015로 1과 다르지 않기 때문입니다. 따라서

정리 7.1.1 (탄성 곡선 방정식) \[EI\,\frac{d^2v}{dx^2} = M(x)\]

\(v\)는 위쪽을 양으로 한 처짐, \(M\)은 5.1절의 부호 규약(아래로 볼록이 양)을 따른다. 미분하면 \(EIv''' = V\), \(EIv'''' = -w\).

부호를 확인해 봅시다. 양의 모멘트는 보를 아래로 볼록하게 휘게 하므로 곡선이 위로 열린 모양(\(v'' > 0\))입니다. 맞습니다. \(EI\)를 굽힘 강성이라 하며, 클수록 덜 휩니다.

푸는 순서는 다음과 같습니다.

  1. 5.1절처럼 \(M(x)\)을 식으로 구한다.
  2. \(EIv'' = M\)을 두 번 적분한다. 적분 상수 \(C_1\), \(C_2\)가 생긴다.
  3. 경계 조건으로 상수를 정한다: 핀·롤러에서 \(v = 0\), 고정단에서 \(v = 0\)이고 \(v' = 0\).
  4. 최대 처짐은 \(v' = 0\)인 점이나 자유 끝에서 찾는다.
예제 7.1.2 (끝에 하중을 받는 외팔보)

길이 \(L\), 굽힘 강성 \(EI\)인 외팔보(왼쪽 끝 고정)의 자유 끝에 \(P\)가 아래로 걸린다. 처짐 곡선과 끝 처짐을 구하여라.

풀이. 자유 끝에서 거리 \(L - x\)인 오른쪽 조각을 보면 \(M(x) = -P(L - x)\)입니다(외팔보는 위로 볼록하므로 음).

\[EIv'' = -P(L - x)\] \[EIv' = -P\left(Lx - \frac{x^2}{2}\right) + C_1\] \[EIv = -P\left(\frac{Lx^2}{2} - \frac{x^3}{6}\right) + C_1x + C_2\]

고정단 \(x = 0\)에서 \(v' = 0\)이므로 \(C_1 = 0\), \(v = 0\)이므로 \(C_2 = 0\). 따라서

\[v(x) = -\frac{Px^2}{6EI}(3L - x)\] \[\delta_{\text{끝}} = |v(L)| = \frac{PL^3}{3EI}\]

처짐이 길이의 세제곱에 비례합니다. 길이를 2배로 하면 처짐은 8배입니다. 수치 예: 길이 1 m, 폭 20 mm, 높이 40 mm 강철 외팔보(\(I = 20\times40^3/12 = 106\,700\) mm⁴, \(E = 200\) GPa)의 끝에 500 N을 걸면 \(\delta = 500\times1000^3/(3\times200\,000\times106\,700) = 7.8\) mm입니다.

예제 7.1.3 (등분포 하중을 받는 단순보)

길이 \(L\) 단순보에 등분포 하중 \(w\)가 전체에 걸린다. 최대 처짐을 구하여라.

풀이. 5.1절 연습문제 1에서 \(M = \frac{wx(L - x)}{2}\). 두 번 적분하면

\[EIv = \frac{w}{2}\left(\frac{Lx^3}{6} - \frac{x^4}{12}\right) + C_1x + C_2\]

\(v(0) = 0\)에서 \(C_2 = 0\), \(v(L) = 0\)에서 \(C_1 = -wL^3/24\). 정리하면

\[v(x) = -\frac{wx}{24EI}(L^3 - 2Lx^2 + x^3)\]

대칭이므로 가운데(\(x = L/2\))에서 기울기가 0이고 처짐이 최대입니다.

\[\delta_{\max} = \frac{5wL^4}{384EI}\]

길이의 네제곱에 비례합니다. 5.2절 예제 카드의 I형 보(길이 5 m, 8 kN/m, \(I = 24.87\times10^6\) mm⁴)는 \(\delta = 5\times8\times5000^4/(384\times200\,000\times24.87\times10^6) = 13.1\) mm로, 길이의 1/382입니다. 굽힘 응력은 허용값의 2/3였지만 처짐은 1/360 제한에 아슬아슬합니다.

7.1.3하중이 구간마다 다를 때

집중 하중이 보 중간에 걸리면 \(M(x)\)이 하중점 왼쪽과 오른쪽에서 다른 식입니다. 이때는 구간마다 따로 적분하고, 하중점에서 처짐과 기울기가 이어진다는 연속 조건(\(v\)와 \(v'\)이 양쪽에서 같다)을 더해 상수 네 개를 정합니다. 계산이 번거로워 실무에서는 다음 절의 공식표와 중첩을 씁니다.

주의(1) \(M(x)\)의 부호를 틀리면 처짐 방향이 뒤집힙니다. 외팔보에 아래 하중이면 \(M < 0\)입니다. (2) 경계 조건은 받침 종류에 맞게: 단순 받침은 \(v = 0\)만, 고정단은 \(v = 0\), \(v' = 0\) 둘 다. 자유 끝에서는 \(v\)를 모르므로 조건으로 쓰지 않습니다. (3) 단위: \(EI\)가 N·mm²면 \(P\)는 N, 길이는 mm로 넣어야 처짐이 mm로 나옵니다.
요약
  1. \(EIv'' = M(x)\). 두 번 적분하고 경계 조건으로 상수를 정한다.
  2. 외팔보 끝 하중: \(\delta = PL^3/(3EI)\). 단순보 등분포: \(\delta_{\max} = 5wL^4/(384EI)\).
  3. 처짐은 길이의 세제곱·네제곱에 비례해 긴 보에서 급격히 커진다.
  4. 구간이 나뉘면 연속 조건을 더한다.

7.1.4연습문제

기본

  1. 예제 7.1.2의 외팔보의 끝 기울기를 구하여라.
    답

    \(v'(L) = -PL^2/(2EI)\).

  2. 등분포 하중 \(w\)를 받는 외팔보의 끝 처짐이 \(wL^4/(8EI)\)임을 보여라.
    답

    \(M = -w(L - x)^2/2\). 두 번 적분하고 \(v(0) = v'(0) = 0\)을 쓰면 \(v(L) = -wL^4/(8EI)\).

응용

  1. 길이 4 m 단순보 가운데에 10 kN이 걸린다(\(EI = 2\times10^{12}\) N·mm²). 가운데 처짐은 \(PL^3/(48EI)\)이다. 값을 구하고 1/360 제한과 비교하여라.
    답

    \(10\,000\times4000^3/(48\times2\times10^{12}) = 6.67\) mm. 제한 \(4000/360 = 11.1\) mm 이하로 만족.

심화

  1. 단순보 가운데의 집중 하중 공식 \(\delta = PL^3/(48EI)\)을 적분법과 대칭(가운데 기울기 0)으로 유도하여라.
    힌트

    왼쪽 절반만 본다: \(M = Px/2\) (\(0 \le x \le L/2\)), 조건 \(v(0) = 0\), \(v'(L/2) = 0\).

    답

    \(EIv' = Px^2/4 + C_1\), \(v'(L/2) = 0\)에서 \(C_1 = -PL^2/16\). \(EIv = Px^3/12 - PL^2x/16\). \(x = L/2\): \(EIv = PL^3/96 - PL^3/32 = -PL^3/48\).
