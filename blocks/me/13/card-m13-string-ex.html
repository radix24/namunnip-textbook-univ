진동 와이어 센서로 장력 재기

예제 · 고유진동수에서 장력 · 변형률 환산
문제 해결 전략 · 식을 거꾸로
  1. 측정한 기본 진동수에서 장력 \(T = 4L^2f^2\mu\)를 구한다.
  2. 와이어 응력과 변형률로 바꾼다.
  3. 진동수 변화로 구조물 변형률 변화를 구한다.

문제. 콘크리트 구조물에 묻은 진동 와이어 변형계(강선 길이 150 mm, 지름 0.25 mm, \(E\) = 200 GPa, 밀도 7850)의 기본 진동수가 800 Hz에서 820 Hz로 올랐다. 와이어 장력 변화와 구조물 변형률 변화는?

전략

\(\mu = \rho A\), \(T = 4L^2f^2\mu\), 변형률 \(\varepsilon = T/(EA)\).

풀이

  1. \(A = 4.91\times10^{-8}\) m², \(\mu = 3.85\times10^{-4}\) kg/m.
    단위 길이 질량.
  2. \(T_1 = 4\times0.0225\times640000\times3.85\times10^{-4} = 22.2\) N, \(T_2 = 23.3\) N.
    \(T \propto f^2\).
  3. \(\Delta\varepsilon = \Delta T/(EA) = 1.12/9.82\times10^3 = 114\times10^{-6}\) (114 μ변형률, 늘어남).
    변형률 변화.

검산

\(\varepsilon = 4L^2\rho f^2/E\)라 \(\Delta\varepsilon = 4L^2\rho(f_2^2 - f_1^2)/E = 4\times0.0225\times7850\times32400/2\times10^{11} = 114\times10^{-6}\)으로 같습니다. 단면적이 약분되어 지름을 몰라도 됩니다.

의미

진동 와이어 센서는 신호가 주파수라 긴 케이블에서도 잡음과 저항 변화에 강하고, 수십 년 동안 댐, 터널, 교량 감시에 쓰입니다. 전기 저항식 게이지보다 장기 안정성이 좋습니다.

바꿔 보기

진동수가 800에서 780 Hz로 내려가면 \(\Delta\varepsilon = 4\times0.0225\times7850\times(608400 - 640000)/2\times10^{11} = -112\) μ변형률(줄어듦)입니다.

이해 확인

진동수가 1% 오르면 장력은 몇 % 오르는가?

답

\(T \propto f^2\)라 약 2%.
