2자유도계의 고유진동수와 모드 형상

본문
이 절에서 배울 것
  • 두 질량이 스프링으로 이어진 계의 운동 방정식을 질량·강성 행렬로 쓴다.
  • 조화 운동을 가정해 고유진동수(행렬식 = 0)와 모드 형상(진폭 비)을 구한다.
  • 모드마다 두 질량이 같은 방향·반대 방향으로 움직이는 뜻을 안다.
먼저 알아야 할 것
  • 1자유도 자유 진동 (2.1절), 연립 일차방정식과 2×2 행렬식 \(ad - bc\).

5.1.1운동 방정식

벽 – \(k_1\) – \(m_1\) – \(k_2\) – \(m_2\)로 이어진 계에서 각 질량의 자유 물체도를 그리면(감쇠 무시) 다음 두 식이 나옵니다.

\[m_1\ddot x_1 + (k_1 + k_2)x_1 - k_2x_2 = 0\] \[m_2\ddot x_2 - k_2x_1 + k_2x_2 = 0\]

두 식이 \(x_1\)과 \(x_2\)로 얽혀 있어(연성) 따로 풀 수 없습니다. 계수를 표로 모으면 \([M]\{\ddot x\} + [K]\{x\} = 0\) 꼴이고, \([M] = \begin{pmatrix}m_1 & 0\\0 & m_2\end{pmatrix}\), \([K] = \begin{pmatrix}k_1 + k_2 & -k_2\\-k_2 & k_2\end{pmatrix}\)입니다.

5.1.2고유진동수와 모드

두 질량이 같은 진동수 \(\omega\)로 함께 움직인다고(\(x_i = X_i\cos\omega t\)) 가정하면 \(\ddot x_i = -\omega^2x_i\)이므로

\[(k_1 + k_2 - m_1\omega^2)X_1 - k_2X_2 = 0\] \[-k_2X_1 + (k_2 - m_2\omega^2)X_2 = 0\]

입니다. \(X_1 = X_2 = 0\)이 아닌 해가 있으려면 이 연립방정식의 계수 행렬식이 0이어야 합니다(두 식이 같은 직선이 되어야 함).

진동수 방정식 \[(k_1 + k_2 - m_1\omega^2)(k_2 - m_2\omega^2) - k_2^2 = 0\]

\(\omega^2\)에 대한 이차방정식, 두 근이 두 고유진동수. 각 \(\omega\)를 첫 식에 넣으면 모드 형상 \(X_2/X_1 = (k_1 + k_2 - m_1\omega^2)/k_2\).

예제 5.1.1 (같은 질량, 같은 스프링)

\(m_1 = m_2 = 10\) kg, \(k_1 = k_2 = 4000\) N/m이다. 고유진동수와 모드 형상은?

풀이. \(\lambda = m\omega^2/k\)로 두면 \((2 - \lambda)(1 - \lambda) - 1 = 0\), \(\lambda^2 - 3\lambda + 1 = 0\), \(\lambda = (3 \mp \sqrt5)/2 = 0.382, 2.618\). \(\omega_1 = \sqrt{0.382\times400} = 12.4\) rad/s(1.97 Hz), \(\omega_2 = 32.4\) rad/s(5.15 Hz). 모드 형상 \(X_2/X_1 = 2 - \lambda\): 1차 1.618(두 질량이 같은 방향, 위 질량이 더 크게), 2차 −0.618(반대 방향).

모드 형상: 그 고유진동수로만 진동할 때 각 질량의 진폭 비. 크기는 정해지지 않고 비율만 정해진다.

처음 상태를 어떻게 주느냐에 따라 두 모드가 섞여 움직입니다. 한 모드 모양 그대로 당겼다 놓으면 그 모드 하나로만 진동합니다.

주의(1) 자유도가 \(n\)이면 고유진동수와 모드가 \(n\)개입니다. 큰 계는 컴퓨터로 행렬의 고윳값 문제를 풉니다. (2) 가장 낮은 모드가 보통 가장 쉽게 가진되고 중요합니다.
요약
  1. \([M]\ddot x + [K]x = 0\), 연성된 두 식.
  2. \(\det([K] - \omega^2[M]) = 0\) → 고유진동수 두 개.
  3. 모드 형상: 진폭 비, 1차는 같은 방향, 2차는 반대 방향.

5.1.3연습문제

기본

  1. 예제 1차 모드에서 \(X_1 = 1\) mm면 \(X_2\)는?
    답

    1.618 mm, 같은 방향.

응용

  1. 두 질량 \(m\)이 양쪽 벽과 가운데에 같은 스프링 \(k\)로 이어진 계(벽–k–m–k–m–k–벽)의 고유진동수와 모드는?
    답

    \((2k - m\omega^2)^2 = k^2\): \(\omega_1 = \sqrt{k/m}\)(같은 방향, 가운데 스프링 안 늘어남), \(\omega_2 = \sqrt{3k/m}\)(반대 방향).

심화

  1. 예제 계의 위 질량만 1 mm 당겼다 놓으면 두 모드가 어떻게 섞이는가? (모드 벡터 \(\{1, 1.618\}\), \(\{1, -0.618\}\))
    답

    \(\{0, 1\} = a\{1, 1.618\} + b\{1, -0.618\}\): \(a + b = 0\), \(1.618a - 0.618b = 1\) → \(a = 0.447\), \(b = -0.447\). 두 모드가 같은 크기로 섞여, 두 진동수가 합쳐진 맥놀이 같은 운동이 된다.
