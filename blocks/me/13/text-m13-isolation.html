전달률과 방진 설계

본문
이 절에서 배울 것
  • 기계에서 바닥으로 전해지는 힘의 비(힘 전달률)와 바닥 진동이 기계로 전해지는 비(변위 전달률)가 같은 식임을 안다.
  • 방진이 되려면 \(r > \sqrt2\)여야 한다는 것을 이해한다.
  • 목표 전달률에서 방진 받침의 강성과 정적 처짐을 정한다.
먼저 알아야 할 것
  • 조화 가진 응답 (3.1절).

3.2.1전달률

기계가 받침(스프링 + 감쇠기) 위에서 진동하면, 바닥으로 가는 힘은 스프링 힘과 감쇠기 힘의 합 \(kx + c\dot x\)입니다. 이 힘의 진폭과 가진력 진폭의 비가 힘 전달률입니다. 바닥이 흔들리고 기계를 보호해야 하는 경우(정밀 장비)의 변위 전달률도 같은 식이 됩니다.

전달률 \[T = \sqrt{\frac{1 + (2\zeta r)^2}{(1 - r^2)^2 + (2\zeta r)^2}}\]

\(r = \sqrt2\)에서 감쇠와 무관하게 \(T = 1\). \(r < \sqrt2\)이면 \(T > 1\)(증폭), \(r > \sqrt2\)이면 \(T < 1\)(방진).

방진하려면 받침을 부드럽게 해 고유진동수를 가진 진동수의 \(1/\sqrt2\)보다 충분히 낮춰야 합니다. 이 영역에서는 감쇠가 오히려 전달률을 조금 키웁니다(분자의 \(2\zeta r\) 항). 그러나 기동·정지 때 공진을 지나므로 적당한 감쇠는 필요합니다.

예제 3.2.1 (펌프 방진 받침 설계)

1500 rpm으로 도는 펌프의 바닥 전달 힘을 10%로 줄이려 한다(감쇠 무시로 설계하고 \(\zeta = 0.05\)로 확인). 필요한 고유진동수와 받침의 정적 처짐은?

풀이. \(\omega = 157\) rad/s. 감쇠 없이 \(T = 1/(r^2 - 1) = 0.1\) → \(r = \sqrt{11} = 3.32\). \(\omega_n = 47.4\) rad/s(7.5 Hz), 정적 처짐 \(g/\omega_n^2 = 4.4\) mm. \(\zeta = 0.05\)로 확인하면 \(T = 0.105\)로 거의 같습니다. 처짐 4~5 mm쯤 눌리는 고무 받침이면 됩니다.

주의(1) 낮은 회전수 기계는 같은 \(r\)을 얻으려면 받침이 아주 부드러워야 해(처짐이 커짐) 스프링 받침이나 관성 블록을 씁니다. (2) 받침이 받치는 바닥 자체가 부드러우면(위층 바닥) 계산과 다르게 됩니다.
요약
  1. \(T = \sqrt{(1 + (2\zeta r)^2)/((1 - r^2)^2 + (2\zeta r)^2)}\).
  2. \(r > \sqrt2\)이어야 방진, 감쇠 무시 \(T \approx 1/(r^2 - 1)\).
  3. 필요 \(r\) → \(\omega_n\) → 정적 처짐 \(g/\omega_n^2\)으로 받침을 고른다.

3.2.2연습문제

기본

  1. \(r = 2\)(감쇠 무시)이면 전달률은?
    답

    \(1/3\), 33%.

응용

  1. 600 rpm 기계를 전달률 10%로 방진하려면 정적 처짐은?
    답

    \(\omega = 62.8\), \(\omega_n = 62.8/3.32 = 18.9\) rad/s, 처짐 \(9.81/357 = 27\) mm. 고무로는 어려워 코일 스프링 받침이 필요하다.

심화

  1. 정밀 현미경을 바닥 진동(주로 30 Hz)에서 보호하려고 고유진동수 3 Hz 공기 스프링 위에 올렸다. 변위 전달률은? (\(\zeta = 0.1\))
    답

    \(r = 10\): \(T = \sqrt{(1 + 4)/(99^2 + 4)} = 0.0226\), 바닥 진동의 약 2%만 전달된다.
