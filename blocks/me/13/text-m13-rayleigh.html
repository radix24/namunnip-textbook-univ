에너지법으로 고유진동수 구하기

본문
이 절에서 배울 것
  • 보존계에서 최대 운동 에너지와 최대 위치 에너지가 같다는 조건으로 고유진동수를 구한다.
  • 스프링 자체 질량을 등가 질량으로 넣는다(\(m_s/3\)).
  • 가정한 변위 모양으로 연속계 고유진동수를 어림한다(Rayleigh 방법).
먼저 알아야 할 것
  • 등가 강성과 등가 질량 (1.2절).

1.3.1에너지 보존

감쇠가 없으면 진동하는 동안 운동 에너지와 위치 에너지가 서로 바뀌기만 합니다. 조화 운동 \(x = X\sin\omega t\)에서 변위가 최대일 때 위치 에너지가 최대, 속도가 최대일 때 운동 에너지가 최대이고 둘이 같으므로 \(\omega\)를 얻습니다. 운동 방정식을 세우지 않아도 되어 복잡한 계에 편리합니다.

에너지법

\[T_{\max} = U_{\max},\qquad \tfrac12m_{eq}(\omega X)^2 = \tfrac12k_{eq}X^2 \Rightarrow \omega = \sqrt{k_{eq}/m_{eq}}\]

스프링 질량 \(m_s\)(끝 속도에 비례해 선형 분포 가정): \(m_{eq} = m + m_s/3\).

Rayleigh: 가정한 모양 \(y(x)\)로 \(\omega^2 = U_{\max}/T^*\) — 실제보다 크거나 같은 값(상한).

예제 1.3.1 (스프링 질량의 영향)

강성 2000 N/m 스프링에 1 kg이 달려 있고 스프링 자체 질량이 0.3 kg이다. 스프링 질량을 무시할 때와 넣을 때의 고유진동수는?

풀이. 무시: \(\sqrt{2000/1}/(2\pi) = 7.12\) Hz. 넣으면 \(m_{eq} = 1.1\) kg, \(6.79\) Hz로 약 5% 낮습니다. 스프링 질량이 매단 질량의 30%라도 영향은 \(1/3\)만 들어갑니다.

주의Rayleigh 방법은 가정한 모양이 실제 모드와 비슷할수록 정확하고, 항상 실제보다 높은(같거나) 값을 줍니다. 정적 처짐 모양을 쓰면 첫 모드를 대개 1~2% 이내로 맞춥니다.
요약
  1. \(T_{\max} = U_{\max}\)로 \(\omega\).
  2. 스프링 질량은 \(m_s/3\)만큼 더한다.
  3. Rayleigh 값은 상한.

1.3.2연습문제

기본

  1. 질량 \(m\)인 단진자를 에너지법으로 풀면(\(U = mgL(1 - \cos\theta) \approx mgL\theta^2/2\)) \(\omega\)는?
    답

    \(T_{\max} = \tfrac12mL^2\omega^2\Theta^2\), \(U_{\max} = \tfrac12mgL\Theta^2\) → \(\omega = \sqrt{g/L}\).

응용

  1. 외팔보 끝에 질량 \(M\)이 있고 보 자체 질량이 \(m_b\)다. 등가 질량은 \(M + 0.24m_b\)다. \(m_b = M\)이면 고유진동수는 질량 없는 보의 몇 배인가?
    답

    \(1/\sqrt{1.24} = 0.90\)배.

심화

  1. 스프링 질량이 \(m_s/3\)으로 들어가는 이유를 운동 에너지 적분으로 보여라.
    답

    위치 \(s\)(0~\(L\))의 스프링 요소 속도를 \(\dot x\,s/L\)로 두면 \(T = \int_0^L\tfrac12(m_s/L)(\dot xs/L)^2ds = \tfrac12(m_s/3)\dot x^2\).
