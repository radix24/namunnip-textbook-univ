진동 모델링: 질량, 스프링, 감쇠기로 기계를 나타내기

본문
이 절에서 배울 것
  • 진동을 일으키는 세 요소(관성, 복원력, 에너지 소산)를 질량·스프링·감쇠기로 나타낸다.
  • 자유 물체도와 Newton 법칙으로 1자유도 운동 방정식 \(m\ddot x + c\dot x + kx = F(t)\)를 유도한다.
  • 중력이 있을 때 정적 평형점을 기준으로 잡으면 중력이 사라지는 이유를 안다.
먼저 알아야 할 것
  • Newton 운동 법칙과 단진동(고등학교 물리), 동역학의 자유 물체도 (동역학 2단원).

1.1.1세 요소

진동은 위치 에너지(스프링)와 운동 에너지(질량)가 서로 주고받으며 생기고, 그 사이 에너지가 조금씩 빠져나가며(감쇠) 줄어듭니다. 실제 기계는 모든 부분이 질량과 탄성을 함께 가지지만, 관심 있는 운동만 남기고 단순화합니다.

질량 \(m\): 가속도에 저항하는 관성. 힘 \(m\ddot x\).

스프링 \(k\): 변위에 비례하는 복원력 \(kx\). 코일 스프링뿐 아니라 보, 축, 고무 받침의 탄성.

점성 감쇠기 \(c\): 속도에 비례하는 저항력 \(c\dot x\). 쇼크 업소버, 재료 내부 마찰, 공기 저항을 이것으로 근사.

자유도: 계의 위치를 정하는 데 필요한 독립 좌표의 수. 질량 하나가 한 방향으로만 움직이면 1자유도.

1.1.2운동 방정식

질량을 평형 위치에서 \(x\)만큼 움직이고 속도 \(\dot x\)로 움직인다고 하면, 스프링은 \(-kx\), 감쇠기는 \(-c\dot x\)의 힘을 질량에 줍니다. 외력 \(F(t)\)까지 Newton 제2법칙에 넣으면

\[m\ddot x + c\dot x + kx = F(t)\]

입니다. 세로로 매단 질량은 중력 \(mg\)도 받지만, 스프링이 이미 \(\delta_{st} = mg/k\)만큼 늘어나 중력과 균형을 이룬 정적 평형점에서 \(x\)를 재면, \(k(\delta_{st} + x) - mg = kx\)가 되어 중력이 식에서 사라집니다.

예제 1.1.1 (자동차 1/4 모델)

자동차 바퀴 하나가 받치는 차체 질량 400 kg, 서스펜션 스프링 20 kN/m, 쇼크 업소버 1500 N·s/m이다. 운동 방정식, 고유진동수, 감쇠비, 정적 처짐은?

풀이. \(400\ddot x + 1500\dot x + 20000x = F(t)\). \(\omega_n = \sqrt{k/m} = 7.07\) rad/s(1.13 Hz). 감쇠비 \(\zeta = c/(2\sqrt{km}) = 0.27\). 정적 처짐 \(mg/k = 0.196\) m. 승용차 차체의 고유진동수는 보통 1~1.5 Hz로, 사람이 걸을 때 몸이 흔들리는 진동수와 비슷해 편안하게 느껴집니다(2단원).

주의(1) 모델이 단순할수록 계산은 쉽지만 놓치는 운동이 생깁니다. 바퀴의 진동까지 보려면 2자유도(5단원)가 필요합니다. (2) 실제 감쇠는 점성이 아닌 경우가 많아(마찰, 재료 내부) 등가 점성 감쇠로 근사합니다. (3) 질량과 강성은 1.2절처럼 실제 구조에서 "등가값"으로 구합니다.
요약
  1. 질량(관성), 스프링(복원), 감쇠기(소산) → \(m\ddot x + c\dot x + kx = F(t)\).
  2. 정적 평형점에서 재면 중력은 식에서 사라진다.
  3. \(\omega_n = \sqrt{k/m}\), \(\zeta = c/(2\sqrt{km})\).

1.1.3연습문제

기본

  1. 예제에서 승객 4명(300 kg, 바퀴 하나당 75 kg)이 타면 고유진동수는?
    답

    \(\sqrt{20000/475}/(2\pi) = 1.03\) Hz.

응용

  1. 정적 처짐 \(\delta_{st}\)만 알면 고유진동수를 구할 수 있음을 보이고, 예제 값으로 확인하여라.
    답

    \(k/m = g/\delta_{st}\)이므로 \(\omega_n = \sqrt{g/\delta_{st}} = \sqrt{9.81/0.196} = 7.07\) rad/s.

심화

  1. 길이 \(l\)인 단진자(작은 각)의 운동 방정식을 \(\theta\)로 세우고 1자유도 질량-스프링 꼴과 대응시켜라.
    답

    \(ml^2\ddot\theta + mgl\theta = 0\). "질량" \(ml^2\)(관성 모멘트), "강성" \(mgl\), \(\omega_n = \sqrt{g/l}\).
