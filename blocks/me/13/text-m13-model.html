진동 모델링: 질량, 스프링, 감쇠기로 기계를 나타내기

본문

자동차가 과속 방지턱을 넘으면 차체가 몇 번 출렁이다 멈춘다. 차체, 바퀴, 스프링, 쇼크 업소버, 타이어가 모두 얽힌 이 움직임을 계산하려면 어디서부터 시작해야 할까? 복잡한 기계를 몇 개의 단순한 요소로 줄여도 출렁임의 빠르기를 맞힐 수 있을까?

먼저 알아야 할 것Newton 운동 법칙과 단진동(고등학교 물리), 동역학의 자유 물체도(동역학 2단원)를 쓴다.

1.1.1세 요소

진동은 스프링에 저장된 위치 에너지와 질량의 운동 에너지가 서로 주고받으며 생기고, 그 사이 에너지가 조금씩 빠져나가며 줄어든다. 실제 기계는 모든 부분이 질량과 탄성을 함께 가지지만, 관심 있는 운동만 남기고 이 세 요소로 단순화한다. 처음 질문의 첫째 답이 이것이다.

질량 \(m\)은 가속도에 저항하는 관성으로, 힘 \(m\ddot x\)를 만든다.

스프링 \(k\)는 변위에 비례하는 복원력 \(kx\)를 낸다. 코일 스프링뿐 아니라 보, 축, 고무 받침의 탄성도 스프링으로 본다.

점성 감쇠기 \(c\)는 속도에 비례하는 저항력 \(c\dot x\)를 낸다. 쇼크 업소버, 재료 내부 마찰, 공기 저항을 이것으로 근사한다.

자유도는 계의 위치를 정하는 데 필요한 독립 좌표의 수이다. 질량 하나가 한 방향으로만 움직이면 1자유도이다.

1.1.2운동 방정식

질량이 평형 위치에서 \(x\)만큼 벗어나 속도 \(\dot x\)로 움직인다고 하자. 그러면 스프링은 \(-kx\), 감쇠기는 \(-c\dot x\)의 힘을 질량에 준다. 여기에 외력 \(F(t)\)까지 Newton 제2법칙에 넣으면 다음 식을 얻는다.

\[m\ddot x + c\dot x + kx = F(t)\]

그런데 세로로 매단 질량은 중력 \(mg\)도 받는다. 하지만 스프링이 이미 \(\delta_{st} = mg/k\)만큼 늘어나 중력과 균형을 이룬 정적 평형점에서 \(x\)를 재면, \(k(\delta_{st} + x) - mg = kx\)가 되어 중력이 식에서 사라진다. 그래서 진동 문제에서는 늘 정적 평형점을 원점으로 잡는다.

예제 1.1.1 (자동차 1/4 모델)

자동차 바퀴 하나가 받치는 차체 질량 400 kg, 서스펜션 스프링 20 kN/m, 쇼크 업소버 1500 N·s/m이다. 운동 방정식, 고유진동수, 감쇠비, 정적 처짐은?

풀이. 운동 방정식은 \(400\ddot x + 1500\dot x + 20000x = F(t)\)이다. 고유진동수는 \(\omega_n = \sqrt{k/m} = 7.07\) rad/s, 곧 1.13 Hz이고, 감쇠비는 \(\zeta = c/(2\sqrt{km}) = 0.27\)이다. 정적 처짐은 \(mg/k = 0.196\) m이다(그림 1).

즉 질량, 스프링, 감쇠기 하나씩으로도 출렁임의 빠르기와 잦아드는 정도를 얻으며, 처음 질문의 둘째 답이 이것이다. 실제로 승용차 차체의 고유진동수는 보통 1~1.5 Hz로, 사람이 걸을 때 몸이 흔들리는 진동수와 비슷해 편안하게 느껴진다(2단원).

흔한 실수세로 진동에서 중력을 따로 더해 \(m\ddot x + kx = mg\)로 두고 진동수를 바꾸는 실수가 흔하다. 중력은 평형 위치만 옮길 뿐 고유진동수를 바꾸지 않으므로, 정적 평형점에서 재면 식에서 사라진다. 또 1/4 모델은 타이어 강성과 바퀴 질량을 뺀 것이어서, 바퀴가 크게 튀는 높은 진동수 운동은 설명하지 못한다.
마무리

질량(관성), 스프링(복원), 감쇠기(소산)로 운동 방정식 \(m\ddot x + c\dot x + kx = F(t)\)를 세운다. 정적 평형점에서 변위를 재면 중력은 식에서 사라진다. 고유진동수는 \(\omega_n = \sqrt{k/m}\), 감쇠비는 \(\zeta = c/(2\sqrt{km})\)이다.

1.1.3연습문제

기본

  1. 예제에서 승객 4명(300 kg, 바퀴 하나당 75 kg)이 타면 고유진동수는?
    답

    \(\sqrt{20000/475}/(2\pi) = 1.03\) Hz이다.

응용

  1. 정적 처짐 \(\delta_{st}\)만 알면 고유진동수를 구할 수 있음을 보이고, 예제 값으로 확인하여라.
    답

    \(k/m = g/\delta_{st}\)이므로 \(\omega_n = \sqrt{g/\delta_{st}} = \sqrt{9.81/0.196} = 7.07\) rad/s이다.

심화

  1. 길이 \(l\)인 단진자(작은 각)의 운동 방정식을 \(\theta\)로 세우고 1자유도 질량-스프링 꼴과 대응시켜라.
    답

    \(ml^2\ddot\theta + mgl\theta = 0\)이다. "질량"은 \(ml^2\)(관성 모멘트), "강성"은 \(mgl\)이고 \(\omega_n = \sqrt{g/l}\)이다.
