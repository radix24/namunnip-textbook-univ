모드 해석: 얽힌 식을 1자유도 여러 개로 풀기

본문
이 절에서 배울 것
  • 모드 형상끼리 질량·강성에 대해 직교한다는 성질을 안다.
  • 모드 좌표로 바꾸면 연성된 운동 방정식이 독립된 1자유도 식으로 분리됨을 이해한다.
  • 모드 좌표로 강제 진동 응답을 구하고 원래 좌표로 되돌린다.
먼저 알아야 할 것
  • 2자유도 고유진동수와 모드 (5.1절), 1자유도 강제 진동 (3.1절).

5.2.1모드의 직교성

서로 다른 두 모드 \(\{u_1\}\), \(\{u_2\}\)는 질량과 강성에 대해 "직교"합니다: \(\{u_1\}^T[M]\{u_2\} = 0\), \(\{u_1\}^T[K]\{u_2\} = 0\). 5.1절 예제(\(m_1 = m_2 = m\))로 확인하면 \(m(1\times1 + 1.618\times(-0.618)) = m(1 - 1.000) = 0\)입니다. 물리적으로는 한 모드로 진동할 때 다른 모드에 에너지를 넘겨주지 않는다는 뜻입니다.

5.2.2모드 좌표

운동을 모드들의 합 \(\{x\} = q_1(t)\{u_1\} + q_2(t)\{u_2\}\)로 쓰고 운동 방정식에 넣은 뒤 각 모드 벡터를 앞에서 곱하면, 직교성 때문에 다른 모드 항이 모두 사라지고 다음과 같이 분리됩니다.

모드 분리 \[M_i\ddot q_i + K_iq_i = Q_i(t)\] \[M_i = \{u_i\}^T[M]\{u_i\},\ K_i = \{u_i\}^T[K]\{u_i\},\ Q_i = \{u_i\}^T\{F\}\]

\(K_i/M_i = \omega_i^2\). 각 모드는 독립된 1자유도계처럼 푼다(감쇠도 모드마다 \(\zeta_i\)로 넣는다).

예제 5.2.1 (위 질량에 정적 힘)

5.1절 예제 계(\(m = 10\), \(k = 4000\))의 위 질량에 정적 힘 10 N을 걸었다. 모드 좌표로 처짐을 구하고 직접 계산과 비교하여라.

풀이. \(M_1 = 10(1 + 2.618) = 36.18\), \(K_1 = M_1\omega_1^2 = 36.18\times152.8 = 5528\), \(Q_1 = 1.618\times10 = 16.18\), \(q_1 = 16.18/5528 = 2.927\) mm. \(M_2 = 10(1 + 0.382) = 13.82\), \(K_2 = 13.82\times1047 = 14472\), \(Q_2 = -6.18\), \(q_2 = -0.427\) mm. \(x_1 = q_1 + q_2 = 2.50\) mm, \(x_2 = 1.618q_1 - 0.618q_2 = 5.00\) mm. 직접 계산(아래 스프링 처짐 10/4000 = 2.5 mm, 위 스프링 2.5 mm 더함)과 같습니다. 대부분(1차 모드 몫)이 낮은 모드에서 옵니다.

큰 구조물(자동차 차체, 건물)은 자유도가 수백만이지만, 가진 진동수 근처의 몇 개 모드만 남겨도 응답을 잘 근사할 수 있어 모드 해석이 매우 강력합니다(모드 절단).

주의(1) 감쇠 행렬이 질량·강성 행렬의 조합(비례 감쇠)일 때만 감쇠까지 깔끔히 분리됩니다. 실제로는 모드 감쇠비를 실험으로 정해 넣습니다. (2) 모드 벡터의 크기(정규화)는 마음대로 정해도 되지만 \(M_i\), \(K_i\), \(Q_i\)에 같은 벡터를 씁니다.
요약
  1. 모드는 \([M]\), \([K]\)에 대해 직교.
  2. \(\{x\} = \sum q_i\{u_i\}\) → \(M_i\ddot q_i + K_iq_i = Q_i\)로 분리.
  3. 각 모드를 1자유도로 풀고 더해 원래 좌표로 되돌린다.

5.2.3연습문제

기본

  1. 예제 계에서 두 모드가 강성에 대해서도 직교함을 확인하여라.
    답

    \([K]\{u_2\} = 4000\{2 - (-0.618), -1 + (-0.618)\} = 4000\{2.618, -1.618\}\). \(\{1, 1.618\}\cdot\{2.618, -1.618\} = 2.618 - 2.618 = 0\).

응용

  1. 예제 계의 위 질량에 \(10\cos(12.4t)\) N(1차 고유진동수) 힘이 걸리면 어느 모드가 크게 응답하는가? 모드 감쇠비 0.02로 \(q_1\)의 진폭은?
    답

    1차 모드가 공진한다. \(q_1 = (Q_1/K_1)/(2\zeta) = 2.927/0.04 = 73\) mm. 2차 모드는 \(r = 0.38\)이라 정적값의 약 1.17배 정도로 작다.

심화

  1. 2번 상황에서 위 질량 진폭은 대략 얼마인가? 모드 해석의 장점을 말하여라.
    답

    \(x_2 \approx 1.618\times73 = 118\) mm(2차 몫은 작음). 공진 근처에서는 해당 모드 하나만으로 응답을 잘 어림할 수 있어, 큰 계도 몇 개 모드로 빠르게 계산한다.
