모드 해석: 얽힌 식을 1자유도 여러 개로 풀기

본문

질량이 수백만 개로 이뤄진 자동차 차체나 건물의 진동을 계산해야 한다. 식이 모두 서로 얽혀 있으니 한꺼번에 풀어야 할까? 얽힌 식을 서로 독립된 1자유도 문제 여러 개로 바꿀 수 있다면, 그 열쇠는 무엇일까?

먼저 알아야 할 것2자유도 고유진동수와 모드(5.1절), 1자유도 강제 진동(3.1절)을 쓴다.

5.2.1모드의 직교성

서로 다른 두 모드 \(\{u_1\}\), \(\{u_2\}\)는 질량과 강성에 대해 직교한다. 곧 \(\{u_1\}^T[M]\{u_2\} = 0\)이고 \(\{u_1\}^T[K]\{u_2\} = 0\)이다. 5.1절 예제(\(m_1 = m_2 = m\))로 확인하면 \(m(1\times1 + 1.618\times(-0.618)) = m(1 - 1.000) = 0\)이다.

물리적으로는 한 모드로 진동할 때 다른 모드에 에너지를 넘겨주지 않는다는 뜻이다. 그래서 각 모드는 다른 모드와 상관없이 따로 움직일 수 있으며, 처음 질문의 열쇠가 이것이다.

5.2.2모드 좌표

이제 운동을 모드들의 합 \(\{x\} = q_1(t)\{u_1\} + q_2(t)\{u_2\}\)로 쓰고 운동 방정식에 넣은 뒤, 각 모드 벡터를 앞에서 곱해 보자. 직교성 때문에 다른 모드 항이 모두 사라지고, 모드마다 다음과 같이 분리된다.

모드 분리 \[M_i\ddot q_i + K_iq_i = Q_i(t)\] \[M_i = \{u_i\}^T[M]\{u_i\},\ K_i = \{u_i\}^T[K]\{u_i\},\ Q_i = \{u_i\}^T\{F\}\]

\(K_i/M_i = \omega_i^2\)이다. 각 모드는 독립된 1자유도계처럼 풀고, 감쇠도 모드마다 \(\zeta_i\)로 넣는다.

즉 얽힌 \(n\)개의 식이 서로 독립된 1자유도 식 \(n\)개로 바뀐다. 처음 질문의 답이 이것이다.

예제 5.2.1 (위 질량에 정적 힘)

5.1절 예제 계(\(m = 10\), \(k = 4000\))의 위 질량에 정적 힘 10 N을 걸었다. 모드 좌표로 처짐을 구하고 직접 계산과 비교하여라.

풀이. 1차 모드는 \(M_1 = 10(1 + 2.618) = 36.18\), \(K_1 = M_1\omega_1^2 = 36.18\times152.8 = 5528\), \(Q_1 = 1.618\times10 = 16.18\)이므로 \(q_1 = 16.18/5528 = 2.927\) mm이다. 2차 모드는 \(M_2 = 10(1 + 0.382) = 13.82\), \(K_2 = 13.82\times1047 = 14472\), \(Q_2 = -6.18\)이므로 \(q_2 = -0.427\) mm이다.

원래 좌표로 되돌리면 \(x_1 = q_1 + q_2 = 2.50\) mm, \(x_2 = 1.618q_1 - 0.618q_2 = 5.00\) mm이다(그림 1). 직접 계산하면 아래 스프링 처짐 10/4000 = 2.5 mm에 위 스프링 2.5 mm가 더해져 같다. 또 대부분이 1차 모드 몫에서 온다.

그래서 자유도가 수백만인 자동차 차체나 건물도, 가진 진동수 근처의 몇 개 모드만 남기면 응답을 잘 근사할 수 있다. 이것을 모드 절단이라 하며, 모드 해석이 강력한 이유이다.

흔한 실수모드 좌표 \(q_i\)를 그대로 질량의 변위로 읽는 실수가 흔하다. \(q_i\)는 모드 모양에 곱하는 계수일 뿐이어서, 실제 변위는 \(\{x\} = \sum q_i\{u_i\}\)로 되돌려야 한다. 또 모드 질량과 모드 강성은 모드 벡터의 크기를 어떻게 정했는지에 따라 값이 달라지지만, 둘의 비인 \(\omega_i^2\)와 최종 변위는 바뀌지 않는다.
마무리

모드는 \([M]\)과 \([K]\)에 대해 직교한다. \(\{x\} = \sum q_i\{u_i\}\)로 두면 운동 방정식이 \(M_i\ddot q_i + K_iq_i = Q_i\)로 모드마다 분리된다. 각 모드를 1자유도로 풀고 더해 원래 좌표로 되돌린다.

5.2.3연습문제

기본

  1. 예제 계에서 두 모드가 강성에 대해서도 직교함을 확인하여라.
    답

    \([K]\{u_2\} = 4000\{2 - (-0.618), -1 + (-0.618)\} = 4000\{2.618, -1.618\}\). \(\{1, 1.618\}\cdot\{2.618, -1.618\} = 2.618 - 2.618 = 0\)이다.

응용

  1. 예제 계의 위 질량에 \(10\cos(12.4t)\) N(1차 고유진동수) 힘이 걸리면 어느 모드가 크게 응답하는가? 모드 감쇠비 0.02로 \(q_1\)의 진폭은?
    답

    1차 모드가 공진한다. \(q_1 = (Q_1/K_1)/(2\zeta) = 2.927/0.04 = 73\) mm. 2차 모드는 \(r = 0.38\)이라 정적값의 약 1.17배 정도로 작다.

심화

  1. 2번 상황에서 위 질량 진폭은 대략 얼마인가? 모드 해석의 장점을 말하여라.
    답

    \(x_2 \approx 1.618\times73 = 118\) mm(2차 몫은 작음). 공진 근처에서는 해당 모드 하나만으로 응답을 잘 어림할 수 있어, 큰 계도 몇 개 모드로 빠르게 계산한다.
