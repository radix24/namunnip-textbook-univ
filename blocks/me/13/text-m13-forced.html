조화 가진: 정상 상태 진폭, 위상, 공진

본문

  • 사인파 힘을 받는 1자유도계의 정상 상태 응답을 구한다.

  • 회전 불평형 가진의 응답을 구한다.
먼저 알아야 할 것
  • 감쇠 자유 진동 (2.1절), 삼각함수의 합성(고등학교 수학).

3.1.1정상 상태 응답

\(m\ddot x + c\dot x + kx = F_0\cos\omega t\)의 해는 자유 진동(감쇠로 사라짐)과 가진 진동수로 계속 흔들리는 정상 상태 응답의 합입니다. 정상 상태는 같은 진동수의 \(x = X\cos(\omega t - \phi)\)로 가정해 넣으면 구해집니다.

조화 가진 응답 (\(r = \omega/\omega_n\)) \[\frac{X}{F_0/k} = \frac{1}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}}\] \[\tan\phi = \frac{2\zeta r}{1 - r^2}\]

\(F_0/k\)는 같은 힘을 천천히 걸었을 때의 정적 처짐이고, 앞의 분수는 동적 확대 계수입니다. \(r \ll 1\)이면 1(스프링이 지배, 위상 0°), \(r = 1\)이면 \(1/(2\zeta)\)(감쇠만이 진폭을 막음, 위상 90°), \(r \gg 1\)이면 \(1/r^2\)로 줄어듭니다(질량이 지배, 위상 180°).

예제 3.1.1 (진동수에 따른 진폭)

2.1절 계(\(m = 10\), \(k = 4000\), \(\zeta = 0.1\), \(\omega_n = 20\) rad/s)에 진폭 50 N 힘을 (가) 3 Hz, (나) 공진, (다) 40 rad/s로 가한다. 정상 상태 진폭과 위상은?

풀이. 정적 처짐 12.5 mm. (가) \(r = 0.94\): 57 mm, 59°. (나) \(r = 1\): 62.5 mm(5배), 90°. (다) \(r = 2\): 4.1 mm, 172°. 공진 근처에서는 정적 처짐의 몇 배로 커지고, 고유진동수의 두 배 위로 가면 정적 처짐보다도 작아집니다(공진 실습).

3.1.2회전 불평형

모터·펌프·세탁기처럼 회전체의 무게 중심이 축에서 \(e\)만큼 벗어나 있으면(불평형 질량 \(m_0\)), 힘의 크기가 \(m_0e\omega^2\)로 진동수 제곱에 비례합니다. 응답은 다음과 같습니다(\(M\): 전체 질량).

\[\frac{MX}{m_0e} = \frac{r^2}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}}\]

낮은 회전수에서는 진폭이 작고, 공진에서 커졌다가, 높은 회전수에서는 \(m_0e/M\)로 일정해집니다. 회전 기계를 기동·정지할 때 공진 회전수를 빨리 지나치게 하는 이유입니다.

주의(1) 정상 상태 식은 과도 응답이 사라진 뒤의 값입니다. 감쇠가 작으면 오래 걸립니다. (2) 최대 진폭은 정확히는 \(r = \sqrt{1 - 2\zeta^2}\)에서 나지만 감쇠가 작으면 \(r = 1\)과 거의 같습니다.
요약
  1. \(X/(F_0/k) = 1/\sqrt{(1 - r^2)^2 + (2\zeta r)^2}\), \(\tan\phi = 2\zeta r/(1 - r^2)\).
  2. 공진(\(r = 1\)): 배율 \(1/(2\zeta)\), 위상 90°.
  3. 회전 불평형: \(MX/(m_0e) = r^2/\sqrt{\cdots}\), 고속에서 \(m_0e/M\)로 수렴.

3.1.3연습문제

기본

  1. 감쇠비 0.02인 구조물의 공진 배율은?
    답

    \(1/(2\times0.02) = 25\)배.

응용

  1. 질량 50 kg 기계(고유진동수 10 Hz, \(\zeta = 0.05\))의 회전체에 불평형 \(m_0e = 0.01\) kg·m이 있다. 600 rpm(공진)과 3000 rpm에서 진폭은?
    답

    600 rpm은 \(r = 1\): \(X = (0.01/50)\times10 = 2\) mm. 3000 rpm은 \(r = 5\): \(X = 0.2\times25/\sqrt{576 + 0.25} = 0.21\) mm.

심화

  1. 예제 계에서 위상이 90°인 진동수를 재면 무엇을 알 수 있는가? 진폭 최대점으로 공진을 찾는 것보다 나은 점은?
    답

    위상 90°는 정확히 \(r = 1\)(\(\omega = \omega_n\))이다. 진폭 최대점은 감쇠에 따라 조금 낮은 쪽으로 옮겨 가고 봉우리가 넓으면 찾기 어렵지만, 위상은 90°를 지나며 빠르게 바뀌어 고유진동수를 정확히 잡을 수 있다.
