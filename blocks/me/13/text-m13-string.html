줄과 막대의 파동 진동

본문
이 절에서 배울 것
  • 당긴 줄의 횡진동이 파동방정식을 따르고 고유진동수가 \(n\)배수로 늘어섬을 안다.
  • 막대의 축방향 진동 고유진동수를 경계 조건별로 구한다.
  • 장력, 길이, 밀도로 고유진동수를 조절한다.
먼저 알아야 할 것
  • 연속계와 외팔보 진동 (6.1절).

6.2.1파동방정식과 고유진동수

장력 \(T\), 단위 길이 질량 \(\mu\)인 줄의 작은 횡변위 \(y(x,t)\)는 \(T\,\partial^2y/\partial x^2 = \mu\,\partial^2y/\partial t^2\)를 따릅니다. 파동 속도는 \(c = \sqrt{T/\mu}\)이고, 양 끝 고정 줄은 반파장의 정수배가 길이에 맞는 진동만 남습니다.

고유진동수

줄(양 끝 고정): \(f_n = \dfrac n{2L}\sqrt{\dfrac T\mu}\), \(n = 1, 2, 3, \ldots\)

막대 축방향(\(c = \sqrt{E/\rho}\)): 양 끝 자유·고정 \(f_n = \dfrac{nc}{2L}\), 한쪽 고정 \(f_n = \dfrac{(2n - 1)c}{4L}\)

줄과 막대는 고유진동수가 기본음의 정수배(배음)로 늘어서 악기 소리가 조화롭습니다. 보(굽힘)는 고유진동수가 \(1 : 6.27 : 17.5\)처럼 정수배가 아니어서 소리가 다릅니다.

예제 6.2.1 (기타 줄)

길이 0.65 m, 단위 길이 질량 0.4 g/m인 줄을 장력 70 N으로 당겼다. 기본 진동수와 2배음은?

풀이. \(c = \sqrt{70/0.0004} = 418\) m/s, \(f_1 = 418/1.3 = 322\) Hz, \(f_2 = 644\) Hz. 줄을 프렛으로 짧게 누르면 \(L\)이 줄어 음이 높아집니다.

주의실제 줄은 굽힘 강성이 조금 있어 높은 배음이 정확한 정수배보다 약간 높습니다(비조화성). 피아노 조율사가 높은 음을 조금 높게 맞추는 이유입니다.
요약
  1. 줄: \(f_n = (n/2L)\sqrt{T/\mu}\).
  2. 막대 축방향: \(c = \sqrt{E/\rho}\), 경계에 따라 \(nc/2L\) 또는 \((2n - 1)c/4L\).
  3. 정수배 배음 → 조화로운 소리.

6.2.2연습문제

기본

  1. 예제 줄의 장력을 4배로 하면 기본 진동수는?
    답

    두 배인 644 Hz(한 옥타브 위).

응용

  1. 길이 1 m 강 막대(\(c\) = 5000 m/s)를 한쪽 고정으로 두면 축방향 1차 고유진동수는?
    답

    \(5000/4 = 1250\) Hz.

심화

  1. 현수교 케이블(길이 100 m, \(\mu\) = 50 kg/m, 장력 \(5\times10^6\) N)의 1차 횡진동수는? 바람 와류와 공진할 수 있는가?
    답

    \(c = \sqrt{10^5} = 316\) m/s, \(f_1 = 316/200 = 1.58\) Hz. 낮은 진동수라 바람 와류(케이블 지름에 따라 수 Hz 이하)와 맞을 수 있어 감쇠기를 단다.
