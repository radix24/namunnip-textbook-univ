전동 연필깎이의 기능 구조도 그리기

예제 · 블랙박스 · 하위 기능 · 해법 찾기
문제 해결 전략 · 기능 분해
  1. 블랙박스의 입력과 출력을 물질, 에너지, 신호로 적는다.
  2. 흐름을 따라가며 "무엇이 일어나야 하는가"를 동사 + 명사로 쓴다.
  3. 하위 기능을 화살표로 잇고, 각 기능에 해법을 3개 이상 찾는다.
먼저 예상해 보기. 연필깎이가 하는 일은 "연필을 깎는다" 하나뿐일까요?

문제. 연필을 꽂으면 저절로 깎고 다 깎이면 멈추는 전동 연필깎이의 기능 구조도를 그리고, 하위 기능 두 개의 해법을 찾아라.

전략

"연필을 깎는다"는 블랙박스 전체입니다. 그 안에서 물질(연필, 깎인 부스러기), 에너지(전기 → 회전), 신호(꽂힘, 다 깎임)가 어떻게 흐르는지 따라가면 하위 기능이 드러납니다.

풀이

  1. 블랙박스: 입력 — 무딘 연필(물질), 전기(에너지), 꽂음 동작(신호). 출력 — 뾰족한 연필, 부스러기(물질), 소리·열(에너지).
    세 흐름.
  2. 하위 기능: 연필을 받아 정렬한다 → 연필이 꽂힌 것을 감지한다 → 전기를 회전으로 바꾼다 → 연필 둘레를 깎는다 → 다 깎인 것을 감지해 멈춘다 → 부스러기를 모은다.
    흐름 순서대로.
  3. "꽂힘을 감지한다"의 해법: 누름 스위치, 광센서, 연필 지름으로 벌어지는 집게.
    신호 흐름.
  4. "다 깎인 것을 감지한다"의 해법: 깎는 힘(모터 전류)이 줄어드는 것 감지, 연필 끝이 정해진 위치를 지나면 스위치, 정해진 시간 타이머.
    세 원리가 다르다.

의미

"깎는다" 하나로 보면 칼날 모양만 고민하게 되지만, 기능으로 나누면 감지, 정렬, 수거처럼 사용자 만족을 좌우하는 기능들이 드러납니다. 실제 불만은 칼날보다 "너무 많이 깎여 연필이 빨리 닳는다"(멈춤 감지)에서 많이 나옵니다. 각 줄의 해법은 2.1절 형태 분석표의 줄이 됩니다.

검산

블랙박스의 모든 입력이 어떤 하위 기능에서 쓰이고, 모든 출력이 어떤 하위 기능에서 만들어지는지 확인합니다. 부스러기(출력)를 다루는 기능이 빠져 있다면 구조도가 덜 된 것입니다.

답
