Freudenstein 식으로 함수 생성 링크 설계

본문

자동차 조향 링크는 핸들을 돌린 각에 맞춰 바퀴가 정해진 각만큼 꺾여야 한다. 입력 각과 출력 각 사이의 원하는 관계를 4절 링크로 만들려면 네 길이를 어떻게 정할까? 커플러 각까지 얽힌 식을 피해, 입력과 출력만으로 된 식을 세울 수 있을까?

먼저 알아야 할 것벡터 루프(2.1절), 연립 1차방정식(공학수치해석 3.1절)을 쓴다.

3.3.1Freudenstein 식

벡터 루프의 두 성분 식에서 커플러 각 \(\theta_3\)를 지우면, 곧 두 식을 정리해 제곱해 더하면, 입력각 \(\theta_2\)와 출력각 \(\theta_4\)만의 관계가 남는다. 처음 질문의 둘째 답이 이 식이다.

Freudenstein 식

\[ K_1\cos\theta_4 - K_2\cos\theta_2 + K_3 = \cos(\theta_2 - \theta_4) \]

\[ K_1 = \frac da, \quad K_2 = \frac dc, \quad K_3 = \frac{a^2 - b^2 + c^2 + d^2}{2ac} \]

원하는 입력-출력 관계에서 정밀점 세 쌍 \((\theta_2, \theta_4)\)를 고르면, 미지수 \(K_1, K_2, K_3\)에 대한 연립 1차방정식이 된다. 이것을 풀고 지면 길이 d를 정하면, \(a = d/K_1\), \(c = d/K_2\), \(b^2 = a^2 + c^2 + d^2 - 2acK_3\)으로 나머지 길이가 정해진다. 처음 질문의 첫째 답이 이것이다.

예제 3.3.1 (입력 30°, 60°, 90°)

입력각 30°, 60°, 90°에서 출력각이 77.4°, 82.7°, 95.5°가 되는 4절 링크를 \(d = 4\)로 설계하여라.

풀이. 세 식의 계수(\(\cos\theta_4\), \(-\cos\theta_2\), 1 | \(\cos(\theta_2 - \theta_4)\))는 (0.2181, −0.8660, 1 | 0.6769), (0.1271, −0.5, 1 | 0.9225), (−0.0958, 0, 1 | 0.9954)이다. 이것을 풀면 \(K_1 = 2.667\), \(K_2 = 1.335\), \(K_3 = 1.251\)이다. 따라서 a = 1.50, c = 3.00, b = 4.00이다.

즉 1.2절의 크랭크-로커를 그대로 되찾았다. 정밀점을 그 링크의 입출력 곡선에서 뽑았기 때문이다(그림 1). 실제 설계에서는 원하는 함수에서 정밀점을 뽑으므로, 결과 링크가 그 함수를 정밀점에서만 정확히 따른다.

흔한 오해계산이 풀리면 언제나 쓸 수 있는 링크가 나온다고 여기기 쉽다. 결과 길이가 음수이거나 \(b^2 < 0\)이면 그 정밀점으로는 링크가 존재하지 않으므로, 정밀점이나 각도 기준을 바꿔야 한다. 또 정밀점 사이에서는 원하는 함수와 어긋나는 구조 오차가 생기므로 Chebyshev 점에 정밀점을 두고, Grashof 조건과 분기도 함께 확인한다.
마무리

Freudenstein 식은 \(K_1\cos\theta_4 - K_2\cos\theta_2 + K_3 = \cos(\theta_2 - \theta_4)\)이다. 정밀점 세 개로 3 × 3 연립 1차방정식을 세운다. 길이는 \(a = d/K_1\), \(c = d/K_2\), \(b^2 = a^2 + c^2 + d^2 - 2acK_3\)로 되찾는다.

3.3.2연습문제

기본

  1. \(d = 10\), \(a = 2\), \(b = 8\), \(c = 6\)인 링크의 \(K_1, K_2, K_3\)는?
    답

    \(K_1 = 5\), \(K_2 = 1.667\), \(K_3 = (4 - 64 + 36 + 100)/24 = 3.167\)이다.

응용

  1. 예제 링크의 \(\theta_2 = 60°\), \(\theta_4 = 82.7°\)를 Freudenstein 식에 넣어 성립하는지 확인하여라.
    답

    \(2.667\times0.1271 - 1.333\times0.5 + 1.25 = 0.922\), \(\cos(-22.7°) = 0.923\). 성립한다.

심화

  1. 정밀점을 네 개 주면 어떻게 되는가?
    답

    미지수 셋에 식이 넷이라 일반적으로 정확한 해가 없다. 최소제곱으로 가장 잘 맞는 \(K\)를 찾거나(공학수치해석 4.2절), 각도 기준(\(\theta_2\), \(\theta_4\)의 출발각)을 추가 미지수로 두어 비선형 문제로 푼다.
