링크 합성 단원 마무리 연습

문제 8 · 개념·계산·판단·도전 · 힌트 2단계

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념다음을 운동 생성, 경로 생성, 함수 생성으로 분류하세요: (가) 영화 필름을 한 칸씩 당기는 갈고리, (나) 차를 뒤집어 짐칸을 비우는 덤프 기구, (다) 앞바퀴 두 개의 조향각 관계를 맞추는 조향 링크. [03-01]

    힌트 1

    점의 궤적인가, 물체의 자세인가, 각도 관계인가? 3.1절

    힌트 2

    조향은 입력 각과 출력 각.

    풀이

    (가) 갈고리 끝이 정해진 궤적을 그려야 하므로 경로 생성, (나) 짐칸 전체의 위치와 자세이므로 운동 생성, (다) 왼쪽 바퀴 각과 오른쪽 바퀴 각의 관계(Ackermann)이므로 함수 생성입니다.

  2. 계산커플러 점 A가 \((0, 0)\)과 \((4, 0)\) 두 위치를 지나야 한다. 지면 핀을 \(y = -3\) 위에 두면 위치와 크랭크 길이는? [03-01]

    힌트 1

    두 점의 수직이등분선은 \(x = 2\).

    힌트 2

    \((2, -3)\)까지 거리.

    풀이

    \(O_2 = (2, -3)\), 크랭크 길이 \(\sqrt{4 + 9} = 3.61\). 두 위치 합성은 수직이등분선 위 어디든 되므로 자유롭게 고를 수 있습니다.

  3. 계산커플러 점이 \((1, 0)\), \((0, 1)\), \((-1, 0)\)을 지나야 할 때 지면 핀과 크랭크 길이는? [03-01]

    힌트 1

    첫 두 점의 수직이등분선은 \(y = x\).

    힌트 2

    뒤 두 점은 \(y = -x\).

    풀이

    두 직선의 교점 \((0, 0)\), 크랭크 길이 1. 세 점이 원점 중심 단위원 위에 있으니 당연한 결과입니다.

  4. 판단세 위치 합성으로 링크를 만들었는데, 시뮬레이션해 보니 1번째, 2번째 위치는 지나지만 3번째 위치에 가려면 기구를 분해했다 다시 조립해야 했다. 원인과 대책은? [03-01]

    힌트 1

    열린·교차 조립(2.1절).

    힌트 2

    부착점을 바꿔 다시.

    풀이

    세 번째 위치가 다른 조립 쪽(분기)에 있는 분기 결함입니다. 작도는 각 위치에서 길이 조건만 맞추므로 연속 운동으로 이어지는지는 보장하지 않습니다. 커플러의 부착점 A, B를 바꿔 다시 합성하고, 결과를 반드시 크랭크 각 전체로 시뮬레이션해 확인합니다.

  5. 판단합성으로 얻은 지면 핀이 기계 프레임 밖 2 m 떨어진 곳에 생겼다. 어떻게 하나요? [03-01]

    힌트 1

    세 점이 거의 일직선이면 원의 중심은?

    힌트 2

    설계 자유도는 부착점에 있습니다.

    풀이

    세 위치의 A점이 거의 일직선이면 원이 매우 커져 중심이 멀어집니다. 커플러 위 다른 점을 A로 골라 세 점이 휘어진 배치가 되게 하거나, 정밀점을 두 개로 줄여 남는 자유도로 지면 핀을 원하는 곳에 둡니다. 거의 직선 운동이 필요하면 슬라이더(무한 반지름)를 쓰는 것도 방법입니다.

  6. 도전Freudenstein 식 \(K_1\cos\theta_4 - K_2\cos\theta_2 + K_3 = \cos(\theta_2 - \theta_4)\)에서 \(K_1 = d/a\), \(K_2 = d/c\), \(K_3 = (a^2 - b^2 + c^2 + d^2)/(2ac)\)이다. 세 정밀점으로 \(K_1 = 2\), \(K_2 = 1.5\), \(K_3 = 1\)을 얻었다면 \(d = 1\)일 때 링크 길이는? [03-01]

    힌트 1

    \(a = d/K_1\), \(c = d/K_2\).

    힌트 2

    \(b^2 = a^2 + c^2 + d^2 - 2acK_3\).

    풀이

    \(a = 0.5\), \(c = 0.667\), \(b^2 = 0.25 + 0.444 + 1 - 0.667 = 1.028\), \(b = 1.014\). Grashof 판정: \(s + l = 0.5 + 1.014 = 1.51 < p + q = 1.67\), 가장 짧은 것이 크랭크이므로 크랭크-로커입니다. 세 정밀점 관계를 정확히 만족하는 링크가 연립 1차방정식 하나로 나옵니다.

  7. 계산로커 길이 120 mm, 흔들림 각 70°인 시간비 1 크랭크-로커의 크랭크 길이는? [03-02]

    힌트 1

    \(a = c\sin(\psi/2)\). 3.2절

    힌트 2

    \(120\sin35°\).

    풀이

    68.8 mm.

  8. 계산Freudenstein 식을 풀어 \(K_1 = 2.5\), \(K_2 = 1.25\), \(K_3 = 1.1\)을 얻었다. \(d = 5\)일 때 \(a\), \(b\), \(c\)는? [03-03]

    힌트 1

    \(a = d/K_1\), \(c = d/K_2\). 3.3절

    힌트 2

    \(b^2 = a^2 + c^2 + d^2 - 2acK_3\).

    풀이

    \(a = 2\), \(c = 4\), \(b^2 = 4 + 16 + 25 - 17.6 = 27.4\), \(b = 5.23\).
