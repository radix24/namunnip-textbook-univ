와이퍼 크랭크-로커 설계

예제 · 2위치 합성 · 전달각 검토
문제 해결 전략 · 2위치 합성
  1. 로커 길이와 흔들림 각에서 로커 끝 두 위치 \(B_1\), \(B_2\)를 정한다.
  2. 시간비 1이면 \(a = \overline{B_1B_2}/2\), \(O_2\)는 \(B_1B_2\) 연장선 위.
  3. \(O_2\) 위치로 \(b\)와 지면 길이를 정한다.
  4. Grashof 조건과 최소 전달각을 확인한다.

문제. 와이퍼 축(로커)이 100° 왕복해야 한다. 로커 길이 60 mm, 시간비 1로 하고 \(O_2\)를 \(B_1\)에서 150 mm 떨어진 곳(연장선 위)에 둔다. 크랭크와 커플러 길이, 지면 길이를 구하라.

전략

\(O_4\)를 원점, 두 끝 위치를 대칭으로 \(\theta_4 = 90° \pm 50°\)에 둔다. \(B_1 = 60(\cos140°, \sin140°)\), \(B_2 = 60(\cos40°, \sin40°)\).

풀이

  1. \(\overline{B_1B_2} = 2\times60\sin50° = 91.9\) mm, \(a = 46.0\) mm.
    현의 절반.
  2. \(B_1 = (-46.0, 38.6)\), \(B_2 = (46.0, 38.6)\). 연장선은 \(y = 38.6\). \(O_2\)는 \(B_1\) 왼쪽 150 mm: \((-196.0, 38.6)\).
    두 끝 위치가 수평선 위.
  3. \(\overline{O_2B_1} = 150 = b - a\) → \(b = 196.0\) mm. 검산 \(\overline{O_2B_2} = 241.9 = b + a\) ✓.
    펴진·접힌 토글.
  4. 지면 \(d = \overline{O_2O_4} = \sqrt{196.0^2 + 38.6^2} = 199.7\) mm.
    \(O_4\)는 원점.

검산

Grashof: \(s + l = 46.0 + 199.7 = 245.7 < p + q = 196.0 + 60 = 256\), 가장 짧은 것이 크랭크라 크랭크-로커이다. 전달각 \(\cos\mu = \{b^2 + c^2 - (d \mp a)^2\}/(2bc)\)에서 38.7°~141.3°로, 기준 40°(140°)를 조금 벗어난다.

의미

시간비 1 설계에서는 전달각 범위가 \(O_2\) 위치보다 흔들림 각에 거의 정해진다. 흔들림 각이 크면(100°) 전달각을 좋게 하기 어려워, 실제 와이퍼는 이 링크 뒤에 두 번째 링크를 달아 각을 키우거나, 흔들림 각을 줄이고 와이퍼 팔을 길게 한다.

바꿔 보기

\(O_2\)를 300 mm로 멀리 두면 \(b = 346.0\), \(d = 348.1\)이지만 전달각은 39.6°~140.4°로 거의 나아지지 않고 기구만 길어진다. 흔들림 각을 80°로 줄이면 최소 전달각이 약 49°로 크게 좋아진다.

이해 확인

흔들림 각을 80°로 줄이면 크랭크 길이는?

답

\(60\sin40° = 38.6\) mm.
