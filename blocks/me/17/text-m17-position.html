벡터 루프로 4절 링크의 위치 구하기

본문

크랭크를 60°로 돌려 놓았을 때 4절 링크의 커플러와 로커는 정확히 어느 각도에 있을까? 삼각함수가 얽힌 연립방정식을 정면으로 풀어야 할까, 아니면 더 쉬운 길이 있을까? 그리고 같은 크랭크 각에 답이 하나뿐일까?

먼저 알아야 할 것Grashof 조건(1.2절), 벡터의 성분과 삼각함수(고등학교 수학)를 쓴다.

2.1.1벡터 루프 방정식

지면 핀 \(O_2\)를 원점에, 다른 지면 핀 \(O_4\)를 x축 위 (d, 0)에 둔다. 크랭크 \(O_2A\)(길이 a, 각 \(\theta_2\)), 커플러 AB(b, \(\theta_3\)), 로커 \(O_4B\)(c, \(\theta_4\))를 벡터로 보면, \(O_2\)에서 B까지 가는 두 경로가 같아야 한다.

\[ \vec a + \vec b = \vec d + \vec c \]

이것을 x, y 성분으로 나누면 다음 두 식이 된다.

\[a\cos\theta_2 + b\cos\theta_3 = d + c\cos\theta_4\]

\[a\sin\theta_2 + b\sin\theta_3 = c\sin\theta_4\]

\(\theta_2\)를 알면 미지수는 \(\theta_3\), \(\theta_4\) 둘이고 식도 둘이므로, 자유도 1과 맞는다.

2.1.2두 원의 교점으로 풀기

그런데 삼각함수 식을 직접 풀기보다 그림으로 보면 쉽다. \(A = (a\cos\theta_2, a\sin\theta_2)\)가 정해지면, B는 A에서 거리 b이고 \(O_4\)에서 거리 c인 점, 곧 두 원의 교점이다(그림 1). 처음 질문의 첫째 답이 이것이다.

계산 절차

먼저 \(e = |O_4 - A|\)를 구한다. \(e > b + c\)이거나 \(e < |b - c|\)이면 그 크랭크 각에서는 조립할 수 없다. 다음으로 A에서 \(O_4\) 방향으로 \(m = (b^2 - c^2 + e^2)/(2e)\)만큼 간 점에서, 수직으로 \(\pm\sqrt{b^2 - m^2}\) 떨어진 두 점이 B의 후보이다. 끝으로 \(\theta_3 = \operatorname{atan2}(B - A)\), \(\theta_4 = \operatorname{atan2}(B - O_4)\)로 각을 구한다.

두 후보는 열린(open) 조립과 교차(crossed) 조립이다. 처음 질문의 둘째 답이 이것이다. 실제 기구는 조립할 때 정한 쪽을 계속 따라가며, 크랭크-로커는 운전 중에 다른 쪽으로 넘어가지 않는다.

예제 2.1.1 (크랭크 60°)

\(d = 4\), \(a = 1.5\), \(b = 4\), \(c = 3\)(1.2절 예제)에서 \(\theta_2 = 60°\)일 때 열린 조립의 \(\theta_3\), \(\theta_4\)를 구하여라.

풀이. A = (0.75, 1.299)이고 \(O_4 - A = (3.25, -1.299)\)이므로 e = 3.500이다. m = (16 − 9 + 12.25)/7 = 2.750이고 \(\sqrt{16 - 7.5625} = 2.905\)이다. 단위 벡터는 u = (0.9286, −0.3712), 그 수직은 (0.3712, 0.9286)이다.

위쪽 해는 B − A = 2.750u + 2.905(0.3712, 0.9286) = (3.632, 1.677)이므로 B = (4.382, 2.976)이다. 따라서 \(\theta_3 = \operatorname{atan2}(1.677, 3.632) = 24.8°\), \(\theta_4 = \operatorname{atan2}(2.976, 0.382) = 82.7°\)이다. 검산하면 \(1.5\cos60° + 4\cos24.8° = 4.38 = 4 + 3\cos82.7°\)로 맞는다. 교차 조립은 \(\theta_3 = -68.4°\), \(\theta_4 = -126.3°\)이다.

흔한 실수각을 구할 때 arctan을 쓰는 실수가 흔하다. arctan은 −90°~90°만 돌려주므로, 로커가 둘째·셋째 사분면에 있으면 엉뚱한 각이 나온다. 그래서 사분면을 구별하는 atan2(y, x)를 쓴다. Freudenstein 식이나 반각 공식으로 \(\theta_4\)를 닫힌 꼴로 구해도 같은 두 해가 나온다.
마무리

벡터 루프 \(\vec a + \vec b = \vec d + \vec c\)는 성분 식 2개에 미지수 2개이다. B는 두 원의 교점이며, 조립할 수 없으면 그 크랭크 각에는 닿지 못한다. 해는 열린 조립과 교차 조립 둘이다.

2.1.3연습문제

기본

  1. 예제 링크에서 \(\theta_2 = 0\)이면 \(e\)는? 조립 가능한가?
    답

    \(A = (1.5, 0)\), \(e = 2.5\). \(|b - c| = 1 \le 2.5 \le 7\)이므로 조립할 수 있다.

응용

  1. 슬라이더-크랭크(크랭크 \(r\), 커넥팅 로드 \(l\), 오프셋 0)에서 피스톤 위치 \(x\)를 크랭크 각 \(\theta\)로 나타내어라.
    답

    루프 \(r\cos\theta + l\cos\phi = x\), \(r\sin\theta = l\sin\phi\)에서 \(x = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}\)이다. (동역학의 크랭크 기구와 같다.)

심화

  1. 비Grashof 링크(\(a = b = c = 3\), \(d = 4.5\))에서 크랭크가 도달할 수 있는 최대 각은?
    답

    \(e = b + c = 6\)일 때가 한계이다. \(e^2 = a^2 + d^2 - 2ad\cos\theta_2 = 36\)에서 \(\cos\theta_2 = (9 + 20.25 - 36)/27 = -0.25\), \(\theta_2 = 104.5°\). 크랭크는 −104.5°~104.5° 사이를 왕복한다.
