순간 중심으로 피스톤 속도 구하기

예제 · 슬라이더-크랭크 · \(I_{13}\)
문제 해결 전략 · 순간 중심
  1. 핀 조인트와 미끄럼 조인트로 바로 보이는 순간 중심을 적는다.
  2. Kennedy 정리로 필요한 숨은 중심을 두 직선의 교점으로 찾는다.
  3. 그 중심을 공유하는 두 링크에서 속도가 같다는 식으로 속도를 구한다.

문제. 크랭크 50 mm, 커넥팅 로드 200 mm인 슬라이더-크랭크(오프셋 0)가 크랭크 각 60°에서 100 rad/s로 돈다. 커넥팅 로드의 순간 중심 \(I_{13}\)을 찾아 피스톤 속도를 구하라.

전략

링크 1 지면, 2 크랭크, 3 로드, 4 피스톤. \(I_{14}\)는 미끄럼 방향(수평)에 수직인 무한원점이므로, \(I_{13}\)은 크랭크 연장선(\(I_{12}I_{23}\))과 피스톤 핀을 지나는 수직선(\(I_{34}I_{14}\))의 교점입니다.

풀이

  1. A = (25.0, 43.3) mm, 로드 각 \(\phi = \sin^{-1}(43.3/200) = 12.5°\), B = (25.0 + 195.3, 0) = (220.3, 0) mm.
    위치 해석.
  2. 크랭크 연장선 \(y = \sqrt3x\)와 수직선 \(x = 220.3\)의 교점 \(I_{13} = (220.3, 381.5)\) mm.
    Kennedy 정리.
  3. A의 속도 \(r\omega = 5\) m/s. 로드는 \(I_{13}\) 둘레로 돌므로 \(\omega_3 = 5/\overline{I_{13}A} = 5/0.3905 = 12.8\) rad/s.
    \(\overline{I_{13}A}\) = 390.5 mm.
  4. \(v_B = \omega_3\cdot\overline{I_{13}B} = 12.8\times0.3815 = 4.88\) m/s.
    B는 \(I_{13}\)에서 수직으로 381.5 mm 아래.

검산

해석식 \(v = r\omega\sin\theta(1 + r\cos\theta/\sqrt{l^2 - r^2\sin^2\theta}) = 5\times0.866\times1.128 = 4.88\) m/s로 같습니다.

의미

계산기 없이 그림 한 장으로 속도를 얻는 방법이라 설계 초기의 빠른 검토와 해석 결과 검증에 좋습니다. 크랭크 90°에서는 \(I_{13}\)이 무한히 멀어져(크랭크와 수직선이 나란) 로드가 순간 병진하고 \(v_B = r\omega\)입니다.

바꿔 보기

크랭크 각 0°(상사점)이면 \(I_{13}\)이 B와 겹쳐 \(v_B = 0\)입니다. 피스톤이 방향을 바꾸는 순간입니다.

이해 확인

같은 순간 커넥팅 로드 중점의 속도 크기는?

답

중점 (122.6, 21.7) mm에서 \(I_{13}\)까지 거리 약 373 mm, \(12.8\times0.373 = 4.77\) m/s.
