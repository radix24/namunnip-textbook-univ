정밀점 세 개로 링크 길이 찾기

예제 · Freudenstein 식 · 연립 1차방정식 · 민감도
문제 해결 전략 · 함수 생성 합성
  1. 정밀점마다 \(\cos\theta_4\), \(-\cos\theta_2\), 1을 계수로, \(\cos(\theta_2 - \theta_4)\)를 오른쪽 항으로 하는 식을 쓴다.
  2. 3 × 3 연립방정식을 풀어 \(K_1, K_2, K_3\).
  3. \(d\)를 정해 \(a = d/K_1\), \(c = d/K_2\), \(b = \sqrt{a^2 + c^2 + d^2 - 2acK_3}\).
  4. Grashof 조건과 각 정밀점의 조립 쪽을 확인한다.

문제. 입력각 40°, 70°, 100°에서 출력각이 107.6°, 111.7°, 120.2°가 되는 4절 링크를 지면 \(d\) = 10으로 설계하라.

전략

세 식의 계수를 계산해 Cramer 공식이나 가우스 소거로 푼다.

풀이

  1. 계수 행렬과 오른쪽: (−0.3024, −0.7660, 1 | 0.3811), (−0.3697, −0.3420, 1 | 0.7466), (−0.5030, 0.1736, 1 | 0.9385).
    각 정밀점의 Freudenstein 식.
  2. 풀면 \(K_1 = 4.923\), \(K_2 = 1.644\), \(K_3 = 3.129\).
    3 × 3 소거.
  3. \(a = 10/4.923 = 2.03\), \(c = 10/1.644 = 6.08\), \(b = \sqrt{2.03^2 + 6.08^2 + 100 - 2\times2.03\times6.08\times3.129} = 7.99\).
    길이 복원.

검산

이 정밀점은 \(a = 2\), \(b = 8\), \(c = 6\), \(d = 10\)인 링크에서 0.1° 단위로 반올림해 뽑은 것이다. 결과가 2.03, 7.99, 6.08로 1% 정도 어긋난 것은 반올림 0.05° 오차가 증폭되었기 때문이다. Grashof: \(2.03 + 10 < 7.99 + 6.08\), 크랭크-로커이다.

의미

정밀점의 출력각이 서로 가까우면(여기서 13° 범위) 연립방정식의 조건수가 커져 입력 오차에 민감합니다(공학수치해석 3.2절). 정밀점을 넓게 펼치면 결과가 안정하다.

바꿔 보기

출력각을 정확한 값(107.63°, 111.69°, 120.19° 등)으로 넣으면 2.000, 8.000, 6.000이 정확히 나온다.
