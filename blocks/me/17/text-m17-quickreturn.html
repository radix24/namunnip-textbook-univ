급속 귀환과 시간비

본문

셰이퍼는 공구가 금속을 깎으며 나아갈 때는 천천히, 깎지 않고 돌아올 때는 빠르게 움직인다. 모터는 일정한 속도로 도는데 어떻게 가는 시간과 오는 시간이 다를까? 그 차이는 링크 길이에서 어떻게 계산할까?

먼저 알아야 할 것Grashof 조건과 전달각(1.2절), 코사인 법칙을 쓴다.

1.4.1토글 위치

크랭크-로커에서 로커가 방향을 바꾸는 두 끝 위치는 크랭크와 커플러가 일직선이 될 때이다. 이것을 토글 위치라 한다. 펴진 상태에서는 \(\overline{O_2B} = a + b\)이고, 접힌 상태에서는 b − a이다. 그러면 삼각형 \(O_2BO_4\)의 세 변을 모두 알게 되므로, 코사인 법칙으로 두 위치를 구한다.

1.4.2시간비

급속 귀환 시간비

\[ Q = \frac{\text{느린 행정의 크랭크 각}}{\text{빠른 행정의 크랭크 각}} = \frac{180° + \alpha}{180° - \alpha} \]

α는 두 토글 위치의 크랭크 각 차가 180°에서 벗어난 만큼이다. 크랭크가 일정 속도로 돌면 시간도 같은 비가 된다.

처음 질문의 첫째 답이 이것이다. 두 토글 위치의 크랭크가 정반대(180°)를 향하지 않으면 한쪽 행정에 더 큰 크랭크 각이 걸린다(그림 1). 이 성질은 절삭하는 행정은 천천히, 돌아오는 행정은 빠르게 해서 전체 시간을 줄이는 셰이퍼, 포장기, 재봉틀에 쓰인다. 반면 두 토글 위치가 지면 핀을 지나는 한 직선 위에 있는 링크는 Q = 1이다(3.2절).

예제 1.4.1 (1.2절 크랭크-로커)

\(d = 4\), \(a = 1.5\), \(b = 4\), \(c = 3\)의 로커 흔들림 각과 시간비를 구하여라.

풀이. 펴진 위치에서 \(\cos\phi_1 = (5.5^2 + 4^2 - 3^2)/(2\times5.5\times4)\)이므로 크랭크 각은 \(\phi_1 = 32.2°\)이고, 로커 각은 77.4°이다. 접힌 위치에서 \(\cos\phi_2 = (2.5^2 + 16 - 9)/(2\times2.5\times4)\)이므로 \(\phi_2 = 48.5°\)이고, 크랭크는 반대쪽이라 228.5°, 로커는 141.4°이다.

따라서 로커 흔들림은 64.0°이다. 두 위치 사이 크랭크 각은 196.4°와 163.6°이므로 시간비는 Q = 1.20이다. 처음 질문의 둘째 답이 이것이다.

흔한 오해시간비는 클수록 좋다고 여기기 쉽다. 시간비를 키우면 빠른 행정에서 로커의 가속도와 관성력이 커지고, 전달각도 나빠진다. 그래서 큰 시간비가 필요하면 4절 링크를 무리하게 바꾸기보다, 셰이퍼의 슬롯 링크(Whitworth) 같은 다른 구조를 쓴다(2.3절).
마무리

토글 위치는 크랭크와 커플러가 일직선인 자세로, 펴진 길이 a + b와 접힌 길이 b − a로 구한다. 시간비는 Q = (180° + α)/(180° − α)이다. 느린 행정은 일하는 행정, 빠른 행정은 귀환 행정으로 쓴다.

1.4.3연습문제

기본

  1. \(\alpha = 20°\)이면 시간비는?
    답

    200/160 = 1.25이다.

응용

  1. 예제 크랭크가 60 rpm으로 돌면 전진과 귀환 시간은?
    답

    한 바퀴가 1 s이므로 전진은 196.4/360 = 0.546 s, 귀환은 163.6/360 = 0.454 s이다.

심화

  1. 오프셋이 \(e\)인 슬라이더-크랭크(크랭크 \(r\), 커넥팅 로드 \(l\))에서 두 끝 위치의 크랭크 각 차가 180°가 아닌 이유를 설명하여라.
    답

    끝 위치는 크랭크와 로드가 일직선일 때인데, 오프셋 때문에 펴진 직선과 접힌 직선이 서로 다른 방향을 향한다(\(\sin^{-1}\frac{e}{l + r}\)와 \(\sin^{-1}\frac e{l - r}\)이 다름). 그래서 \(\alpha \ne 0\)이 되어 급속 귀환이 생긴다.
