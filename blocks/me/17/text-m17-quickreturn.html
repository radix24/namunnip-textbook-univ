급속 귀환과 시간비

본문
이 절에서 배울 것
  • 로커의 두 끝 위치(토글 위치)를 찾는다.
  • 전진과 귀환의 크랭크 각으로 시간비를 계산한다.
  • 급속 귀환 기구가 쓰이는 곳을 안다.
먼저 알아야 할 것
  • Grashof 조건과 전달각 (1.2절), 코사인 법칙.

1.4.1토글 위치

크랭크-로커에서 로커가 방향을 바꾸는 두 끝 위치는 크랭크와 커플러가 일직선이 될 때입니다. 펴진 상태(\(\overline{O_2B} = a + b\))와 접힌 상태(\(b - a\))에서 삼각형 \(O_2BO_4\)의 세 변을 알므로 코사인 법칙으로 두 위치를 구합니다.

1.4.2시간비

급속 귀환 시간비

\[ Q = \frac{\text{느린 행정의 크랭크 각}}{\text{빠른 행정의 크랭크 각}} = \frac{180° + \alpha}{180° - \alpha} \]

\(\alpha\)는 두 토글 위치의 크랭크 각 차가 180°에서 벗어난 만큼. 크랭크가 일정 속도로 돌면 시간도 같은 비.

절삭하는 행정은 천천히, 돌아오는 행정은 빠르게 해서 전체 시간을 줄이는 셰이퍼, 포장기, 재봉틀에 씁니다. 지면 핀이 일직선 위에 있는 대칭 링크는 \(Q = 1\)입니다.

예제 1.4.1 (1.2절 크랭크-로커)

\(d = 4\), \(a = 1.5\), \(b = 4\), \(c = 3\)의 로커 흔들림 각과 시간비를 구하여라.

풀이. 펴진 위치: \(\cos\phi_1 = (5.5^2 + 4^2 - 3^2)/(2\times5.5\times4)\), \(\phi_1 = 32.2°\)(크랭크 각), 로커 각 77.4°. 접힌 위치: \(\cos\phi_2 = (2.5^2 + 16 - 9)/(2\times2.5\times4)\), \(\phi_2 = 48.5°\), 크랭크는 반대쪽이라 228.5°, 로커 141.4°. 흔들림 64.0°. 크랭크 각 차 196.4°와 163.6°로 \(Q = 1.20\)입니다.

주의시간비를 크게 할수록 빠른 행정에서 로커의 가속도와 관성력이 커지고 전달각이 나빠집니다. 셰이퍼의 슬롯 링크(Whitworth) 같은 다른 구조는 더 큰 시간비를 냅니다.
요약
  1. 토글 위치: 크랭크와 커플러 일직선(\(a + b\), \(b - a\)).
  2. \(Q = (180° + \alpha)/(180° - \alpha)\).
  3. 느린 일 행정, 빠른 귀환 행정.

1.4.3연습문제

기본

  1. \(\alpha = 20°\)이면 시간비는?
    답

    200/160 = 1.25.

응용

  1. 예제 크랭크가 60 rpm으로 돌면 전진과 귀환 시간은?
    답

    한 바퀴 1 s. 196.4/360 = 0.546 s, 163.6/360 = 0.454 s.

심화

  1. 오프셋이 \(e\)인 슬라이더-크랭크(크랭크 \(r\), 커넥팅 로드 \(l\))에서 두 끝 위치의 크랭크 각 차가 180°가 아닌 이유를 설명하여라.
    답

    끝 위치는 크랭크와 로드가 일직선일 때인데, 오프셋 때문에 펴진 직선과 접힌 직선이 서로 다른 방향을 향한다(\(\sin^{-1}\frac{e}{l + r}\)와 \(\sin^{-1}\frac e{l - r}\)이 다름). 그래서 \(\alpha \ne 0\)이 되어 급속 귀환이 생긴다.
