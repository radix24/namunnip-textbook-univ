웜 기어의 효율과 자동 잠김

예제 · 리드각 · 마찰각
문제 해결 전략 · 웜 기어
  1. 웜의 리드각 \(\lambda\)와 마찰각 \(\rho = \tan^{-1}f\)를 구한다.
  2. 웜 구동 효율 \(\eta \approx \tan\lambda/\tan(\lambda + \rho)\)(압력각 무시, 동력 나사와 같은 꼴).
  3. \(\lambda \le \rho\)이면 휠 쪽에서 웜을 돌릴 수 없다(자동 잠김).

문제. 리드각 10°인 웜 기어의 마찰계수가 0.05이다. 효율은? 자동 잠김인가? 감속비 30, 입력 1 kW, 1500 rpm일 때 출력 토크는?

전략

웜과 휠의 접촉은 나사와 너트처럼 미끄럼이므로 동력 나사(기계요소설계 3.1절)의 효율 식을 쓴다.

풀이

  1. \(\rho = \tan^{-1}0.05 = 2.86°\).
    마찰각.
  2. \(\eta = \tan10°/\tan12.86° = 0.1763/0.2283 = 0.772\).
    77%.
  3. \(\lambda = 10° > \rho = 2.86°\)이므로 자동 잠김이 아니다(휠에서 거꾸로 돌릴 수 있다).
    잠김 조건 불만족.
  4. 출력 동력 772 W, 출력 50 rpm(5.24 rad/s), 토크 \(772/5.24 = 147\) N·m.
    \(T = P/\omega\).

검산

마찰이 없으면 출력 토크는 \(1000/5.24 = 191\) N·m이다. 23%가 미끄럼 열로 사라졌다.

의미

리드각을 키우면 효율은 오르지만 자동 잠김이 사라진다. 승강기처럼 멈췄을 때 하중이 되돌아가면 안 되는 곳에는 리드각을 마찰각보다 작게(효율 50% 이하) 하거나 별도 브레이크를 둔다.

바꿔 보기

리드각 3°(1줄 웜, 큰 감속비)로 하면 \(\eta = \tan3°/\tan5.86° = 0.51\)이고 \(3° > 2.86°\)라 아슬아슬하게 잠김이 아니다. 마찰계수가 조금만 커져도 잠김이 되어, 설계 여유가 없는 경계 상태이다.
