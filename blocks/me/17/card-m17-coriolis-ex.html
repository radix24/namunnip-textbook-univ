슬롯 링크 기구의 속도와 가속도

예제 · 상대 속도 · Coriolis · 각가속도
문제 해결 전략 · 미끄럼 조인트
  1. 미끄럼쇠(크랭크 핀) P의 절대 속도·가속도를 크랭크로부터 구한다.
  2. 슬롯 방향 단위 벡터 \(\hat u\)와 수직 \(\hat n\)으로 나눈다.
  3. 속도: \(\hat u\) 성분 = 상대 속도, \(\hat n\) 성분 = \(\omega_3L\).
  4. 가속도: \(\hat n\) 성분 = \(\alpha_3L + 2\omega_3v_{\text{rel}}\), \(\hat u\) 성분 = \(a_{\text{rel}} - \omega_3^2L\).

문제. 슬롯 링크의 피벗 \(O_3\) = (0, 0), 크랭크 피벗 \(O_2\) = (0, 0.2) m, 크랭크 0.1 m가 반시계로 10 rad/s(일정)로 돈다. 크랭크가 수평(오른쪽, \(\theta_2 = 0\))인 순간 슬롯 링크의 각속도와 각가속도, 미끄럼쇠의 상대 속도를 구하라.

전략

핀 P = (0.1, 0.2) m, \(L = \overline{O_3P} = 0.2236\) m, \(\hat u = (0.447, 0.894)\), \(\hat n = (-0.894, 0.447)\).

풀이

  1. P의 속도 \(r\omega_2 = 1\) m/s, 방향 +y: \(\vec v_P = (0, 1)\).
    크랭크에 수직.
  2. \(v_{\text{rel}} = \vec v_P\cdot\hat u = 0.894\) m/s(바깥으로), \(\omega_3L = \vec v_P\cdot\hat n = 0.447\) → \(\omega_3 = 2.0\) rad/s(반시계).
    성분 분해.
  3. P의 가속도(구심) \(\vec a_P = (-10, 0)\) m/s². \(\hat n\) 성분: \(8.94 = \alpha_3L + 2\times2\times0.894\) → \(\alpha_3 = (8.94 - 3.58)/0.2236 = 24.0\) rad/s².
    Coriolis 3.58 m/s²를 빼야 한다.
  4. \(\hat u\) 성분: \(-4.47 = a_{\text{rel}} - 2^2\times0.2236\) → \(a_{\text{rel}} = -3.58\) m/s²(안쪽으로 감속).
    구심 성분 0.894 m/s².

검산

Coriolis 항을 빼먹으면 \(\alpha_3 = 8.94/0.2236 = 40\) rad/s²로 67% 크게 나온다. 두 성분의 합을 다시 조립하면 \(\vec a_P = (-10, 0)\)이 되는지 확인할 수 있다.

의미

셰이퍼와 Whitworth 급속 귀환 기구의 해석이 이 방법이다. 슬롯 링크의 각가속도는 링크와 공구대의 관성력, 곧 기계의 진동과 하중을 결정한다.

바꿔 보기

크랭크가 위(\(\theta_2\) = 90°)에 오면 P = (0, 0.3)으로 슬롯과 크랭크가 일직선이 되어 \(v_{\text{rel}} = 0\)이고 \(\omega_3 = 1/0.3 = 3.33\) rad/s로 가장 빠릅니다(Coriolis 0).

이해 확인

미끄럼쇠 질량이 0.3 kg이면 이 순간 슬롯 벽이 수직으로 주는 힘은?

답

\(\hat n\) 방향 가속도 8.94 m/s² × 0.3 = 2.68 N.
