링크의 각속도와 각가속도

본문

크랭크는 일정한 속도로 도는데, 로커는 빨라졌다 느려졌다 하다가 방향까지 바꾼다. 로커의 각속도를 크랭크 각마다 공식 하나로 구할 수 있을까? 각속도가 0이 되는 순간과 갑자기 커지는 순간은 기구의 어떤 자세와 관련이 있을까?

먼저 알아야 할 것위치 해석(2.1절), 순간 중심과 상대 속도(동역학 4.1절), 합성함수의 미분을 쓴다.

2.2.1속도: 루프를 미분하기

루프 성분 식 \(a\cos\theta_2 + b\cos\theta_3 - c\cos\theta_4 = d\), \(a\sin\theta_2 + b\sin\theta_3 - c\sin\theta_4 = 0\)을 시간으로 미분한다. \(\frac{d}{dt}\cos\theta = -\sin\theta\cdot\omega\)이므로(\(\omega = \dot\theta\)) 다음 두 식을 얻는다.

\[-a\omega_2\sin\theta_2 - b\omega_3\sin\theta_3 + c\omega_4\sin\theta_4 = 0\]

\[a\omega_2\cos\theta_2 + b\omega_3\cos\theta_3 - c\omega_4\cos\theta_4 = 0\]

위치가 이미 풀려 있으면 이것은 \(\omega_3\), \(\omega_4\)에 대한 연립 1차방정식이다. 처음 질문의 첫째 답이 이것이며, 풀면 아래 공식이 된다.

4절 링크의 각속도

\[\omega_3 = \frac{a\omega_2\sin(\theta_4 - \theta_2)}{b\sin(\theta_3 - \theta_4)}\]

\[\omega_4 = \frac{a\omega_2\sin(\theta_2 - \theta_3)}{c\sin(\theta_4 - \theta_3)}\]

분모의 \(\sin(\theta_3 - \theta_4)\)는 전달각의 사인이다. 그래서 전달각이 0에 가까우면, 곧 커플러와 로커가 일직선이면 작은 입력에도 각속도가 커지거나 정해지지 않는다. 반대로 \(\sin(\theta_2 - \theta_3) = 0\)이면, 곧 크랭크와 커플러가 일직선이면 \(\omega_4 = 0\)이 되어 로커가 왕복의 끝인 토글 위치에 있다(그림 1). 처음 질문의 둘째 답이 이것이다.

예제 2.2.1 (크랭크 60°, 10 rad/s)

2.1절 예제(\(\theta_2 = 60°\), \(\theta_3 = 24.8°\), \(\theta_4 = 82.7°\))에서 크랭크가 \(\omega_2 = 10\) rad/s로 일정하게 돌 때 \(\omega_3\), \(\omega_4\)를 구하여라.

풀이. \(\omega_3 = 15\sin22.7°/(4\sin(-57.9°)) = 5.79/(-3.39) = -1.71\) rad/s로 시계 방향이다. \(\omega_4 = 15\sin35.2°/(3\sin57.9°) = 8.65/2.54 = 3.40\) rad/s로 반시계 방향이다. 위치를 0.001 rad 바꿔 수치 미분한 값과도 일치한다.

2.2.2가속도

속도 식을 한 번 더 미분하면 \(\alpha_3\), \(\alpha_4\)에 대한 연립 1차방정식이 된다. 이때 복소수 표기 \(\vec a = ae^{i\theta_2}\)를 쓰면 정리가 쉽다. \(\frac{d}{dt}e^{i\theta} = i\omega e^{i\theta}\)이고, 한 번 더 미분하면 \((i\alpha - \omega^2)e^{i\theta}\)이기 때문이다.

\[ a(i\alpha_2 - \omega_2^2)e^{i\theta_2} + b(i\alpha_3 - \omega_3^2)e^{i\theta_3} = c(i\alpha_4 - \omega_4^2)e^{i\theta_4} \]

여기서 iα 항은 링크에 수직인 접선 가속도이고, −ω² 항은 핀을 향하는 구심 가속도이다. 실수부와 허수부를 나누면 두 식이 나오며, 예제(\(\alpha_2 = 0\))에서는 \(\alpha_3 = 32.4\) rad/s², \(\alpha_4 = 45.5\) rad/s²이다.

흔한 오해크랭크가 일정한 속도로 돌면 다른 링크의 가속도도 없다고 여기기 쉽다. 커플러와 로커는 크랭크 각에 따라 각속도가 바뀌므로 각가속도가 있고, 이것이 관성력과 진동의 원인이 된다(기계진동). 손으로는 속도 다각형이나 순간 중심을 쓰고, 컴퓨터로는 이 해석식을 크랭크 각마다 반복한다.
마무리

루프를 미분하면 \(\omega_3\), \(\omega_4\)의 연립 1차식이 된다. 분모는 전달각의 사인이며, 크랭크와 커플러가 일직선이면 \(\omega_4 = 0\)이다. 가속도는 접선 성분 iα와 구심 성분 −ω²로 이루어진다.

2.2.3연습문제

기본

  1. 크랭크 길이 0.1 m, \(\omega_2 = 20\) rad/s로 일정할 때 크랭크 끝 A의 속도와 가속도 크기는?
    답

    속도는 2 m/s, 가속도(구심)는 \(0.1\times400 = 40\) m/s²이다.

응용

  1. 예제에서 \(\omega_4/\omega_2\)는? 이 비는 무엇을 뜻하는가?
    답

    0.34이다. 순간적인 속도비(기계적 이득의 역수)로, 같은 동력에서 로커 토크는 크랭크 토크의 약 1/0.34 = 2.9배이다(마찰 무시).

심화

  1. 예제의 교차 조립(\(\theta_3 = -68.4°\), \(\theta_4 = -126.3°\))에서 \(\omega_4\)는?
    답

    \(\omega_4 = 15\sin(128.4°)/(3\sin(-57.9°)) = 11.75/(-2.54) = -4.63\) rad/s. 같은 크랭크 각이라도 조립에 따라 속도가 다르다.
