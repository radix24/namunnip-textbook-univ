링크의 각속도와 각가속도

본문
이 절에서 배울 것
  • 벡터 루프 방정식을 시간으로 미분해 각속도 식을 얻는다.
  • 4절 링크의 커플러·로커 각속도를 공식으로 구한다.
  • 한 번 더 미분해 각가속도를 연립 1차식으로 구한다.
먼저 알아야 할 것
  • 위치 해석 (2.1절), 순간 중심과 상대 속도 (동역학 4.1절), 합성함수의 미분.

2.2.1속도: 루프를 미분하기

루프 성분 식 \(a\cos\theta_2 + b\cos\theta_3 - c\cos\theta_4 = d\), \(a\sin\theta_2 + b\sin\theta_3 - c\sin\theta_4 = 0\)을 시간으로 미분합니다. \(\frac{d}{dt}\cos\theta = -\sin\theta\cdot\omega\)이므로(\(\omega = \dot\theta\))

\[-a\omega_2\sin\theta_2 - b\omega_3\sin\theta_3 + c\omega_4\sin\theta_4 = 0\]

\[a\omega_2\cos\theta_2 + b\omega_3\cos\theta_3 - c\omega_4\cos\theta_4 = 0\]

위치가 이미 풀려 있으면 \(\omega_3\), \(\omega_4\)에 대한 연립 1차방정식입니다. 풀면

4절 링크의 각속도

\[\omega_3 = \frac{a\omega_2\sin(\theta_4 - \theta_2)}{b\sin(\theta_3 - \theta_4)}\]

\[\omega_4 = \frac{a\omega_2\sin(\theta_2 - \theta_3)}{c\sin(\theta_4 - \theta_3)}\]

분모의 \(\sin(\theta_3 - \theta_4)\)는 전달각의 사인입니다. 전달각이 0에 가까우면(커플러와 로커가 일직선) 작은 입력에도 각속도가 커지거나 정해지지 않습니다. 반대로 \(\sin(\theta_2 - \theta_3) = 0\)(크랭크와 커플러가 일직선)이면 \(\omega_4 = 0\)으로, 로커가 왕복의 끝(토글 위치)에 있습니다.

예제 2.2.1 (크랭크 60°, 10 rad/s)

2.1절 예제(\(\theta_2 = 60°\), \(\theta_3 = 24.8°\), \(\theta_4 = 82.7°\))에서 크랭크가 \(\omega_2 = 10\) rad/s로 일정하게 돌 때 \(\omega_3\), \(\omega_4\)를 구하여라.

풀이. \(\omega_3 = 15\sin22.7°/(4\sin(-57.9°)) = 5.79/(-3.39) = -1.71\) rad/s(시계 방향). \(\omega_4 = 15\sin35.2°/(3\sin57.9°) = 8.65/2.54 = 3.40\) rad/s(반시계). 위치를 0.001 rad 바꿔 수치 미분한 값과도 일치합니다.

2.2.2가속도

속도 식을 한 번 더 미분하면 \(\alpha_3\), \(\alpha_4\)에 대한 연립 1차방정식이 됩니다. 복소수 표기 \(\vec a = ae^{i\theta_2}\)를 쓰면 정리가 쉽습니다. \(\frac{d}{dt}e^{i\theta} = i\omega e^{i\theta}\)이고, 한 번 더 미분하면 \((i\alpha - \omega^2)e^{i\theta}\)입니다.

\[ a(i\alpha_2 - \omega_2^2)e^{i\theta_2} + b(i\alpha_3 - \omega_3^2)e^{i\theta_3} = c(i\alpha_4 - \omega_4^2)e^{i\theta_4} \]

\(i\alpha\) 항은 링크에 수직인 접선 가속도, \(-\omega^2\) 항은 핀을 향하는 구심 가속도입니다. 실수부와 허수부를 나누면 두 식이 나옵니다. 예제의 경우(\(\alpha_2 = 0\)) \(\alpha_3 = 32.4\) rad/s², \(\alpha_4 = 45.5\) rad/s²입니다.

주의(1) 크랭크가 일정 속도로 돌아도 커플러와 로커는 각가속도가 있으며, 이것이 관성력과 진동의 원인입니다(기계진동). (2) 손으로는 속도 다각형·순간 중심, 컴퓨터로는 이 해석식을 크랭크 각마다 반복해 씁니다.
요약
  1. 루프를 미분 → \(\omega_3\), \(\omega_4\)의 연립 1차식.
  2. 분모 = 전달각의 사인. 크랭크·커플러 일직선이면 \(\omega_4 = 0\).
  3. 가속도: 접선 \(i\alpha\) + 구심 \(-\omega^2\).

2.2.3연습문제

기본

  1. 크랭크 길이 0.1 m, \(\omega_2 = 20\) rad/s로 일정할 때 크랭크 끝 A의 속도와 가속도 크기는?
    답

    속도 2 m/s, 가속도(구심) \(0.1\times400 = 40\) m/s².

응용

  1. 예제에서 \(\omega_4/\omega_2\)는? 이 비는 무엇을 뜻하는가?
    답

    0.34. 순간적인 속도비(기계적 이득의 역수)로, 같은 동력에서 로커 토크는 크랭크 토크의 약 1/0.34 = 2.9배이다(마찰 무시).

심화

  1. 예제의 교차 조립(\(\theta_3 = -68.4°\), \(\theta_4 = -126.3°\))에서 \(\omega_4\)는?
    답

    \(\omega_4 = 15\sin(128.4°)/(3\sin(-57.9°)) = 11.75/(-2.54) = -4.63\) rad/s. 같은 크랭크 각이라도 조립에 따라 속도가 다르다.
