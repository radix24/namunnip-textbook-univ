열전대 보정 결과로 측정값 고치기

예제 · 두 점 보정 · 잔차 · 보정식 적용
문제 해결 전략 · 기준점 두 개
  1. 기준 온도 두 점(얼음물, 끓는 물)에서 센서 표시값을 기록한다.
  2. 표시값 → 참값의 직선 보정식을 만든다.
  3. 중간 점에서 기준 온도계와 비교해 남은 오차를 확인한다.

문제. K형 열전대 표시기가 얼음물(0.0 °C)에서 0.8 °C, 끓는 물(대기압 99.6 °C로 확인)에서 98.4 °C를 보였다. 보정식은? 같은 표시기가 55.0 °C를 보이면 참값은? 기준 온도계 50.2 °C와 비교하면 남은 오차는?

전략

참값 \(T = a + b\,T_{\text{표시}}\)로 두 점을 지나는 직선을 만든다.

풀이

  1. \(b = (99.6 - 0)/(98.4 - 0.8) = 1.0205\), \(a = -0.8\times1.0205 = -0.82\) °C.
    두 점 직선.
  2. 표시 55.0 → \(T = -0.82 + 1.0205\times55.0 = 55.3\) °C.
    보정식 적용.
  3. 표시 50.0일 때 보정값 \(50.2\) °C로 기준 50.2 °C와 맞는다. 남은 오차는 기준 온도계 불확도(±0.1 °C) 수준.
    중간 점 확인.

검산

보정 전 끓는 물 오차는 −1.2 °C, 얼음물 +0.8 °C로 영점과 감도가 모두 어긋나 있었다. 두 점 보정이 둘 다 고친다. 끓는점은 기압에 따라 변하므로(1 kPa에 약 0.28 °C) 그날 기압으로 참값을 정했다.

의미

열전대 자체는 비선형이라(3.1절) 넓은 범위에서는 두 점 직선으로 부족하다. 사용 범위가 좁으면 두 점으로, 넓으면 여러 점으로 다항식 보정을 한다.

바꿔 보기

끓는 물 참값을 확인 없이 100.0 °C로 두면 \(b = 1.0246\)이 되어 표시 55.0에서 55.5 °C로 0.2 °C 다르게 고친다. 기준값의 정확도가 보정의 정확도를 정한다.

이해 확인

표시값 0.8 °C를 보정식에 넣으면?

답

\(-0.82 + 1.0205\times0.8 = 0.0\) °C(기준점이므로 그대로 맞음).
