수직 충격파 전후의 상태량

본문

마하 2.5로 나는 전투기의 흡입구 앞에서는 공기가 머리카락 두께보다 얇은 층을 지나며 갑자기 느려지고 뜨거워진다. 그 얇은 층 뒤의 속도, 압력, 온도는 무엇으로 정해질까? 그 과정에서 무엇을 잃으며, 거꾸로 아음속이 갑자기 초음속으로 뛰는 일은 왜 일어나지 않을까?

먼저 알아야 할 것마하수와 등엔트로피 관계(응용열역학 6.1절), 운동량 방정식(유체역학 3단원)을 쓴다.

4.1.1세 보존식

수직 충격파는 두께가 분자 평균 자유 행로의 몇 배, 공기에서 1 μm 정도인 얇은 층이다. 그래서 그 앞뒤를 하나의 검사체적으로 보고, 넓이가 같은 정상 흐름으로 다룬다. 질량, 운동량, 에너지 보존은 다음과 같다.

\[\rho_1V_1 = \rho_2V_2\] \[p_1 + \rho_1V_1^2 = p_2 + \rho_2V_2^2\] \[h_1 + \frac{V_1^2}{2} = h_2 + \frac{V_2^2}{2}\]

이상기체 식과 함께 풀면 하류 상태가 상류 마하수 \(M_1\)만의 함수로 나오며, 처음 질문의 첫째 답이 이것이다. 해는 변화가 없는 \(M_1 = 1\)과 다음 결과 두 가지이다. 그런데 제2법칙, 곧 엔트로피 증가를 만족하는 것은 \(M_1 > 1\)에서 \(M_2 < 1\)로 가는 압축 충격파뿐이다. 아음속에서 초음속으로 뛰는 "팽창 충격파"는 엔트로피가 줄어 일어날 수 없으며, 처음 질문의 셋째 답이 이것이다.

수직 충격파 관계 (이상기체, \(k\) 일정) \[M_2^2 = \frac{M_1^2 + \frac{2}{k-1}}{\frac{2k}{k-1}M_1^2 - 1}\] \[\frac{p_2}{p_1} = 1 + \frac{2k}{k+1}(M_1^2 - 1)\] \[\frac{\rho_2}{\rho_1} = \frac{V_1}{V_2} = \frac{(k+1)M_1^2}{(k-1)M_1^2 + 2}\] \[\frac{T_2}{T_1} = \frac{p_2/p_1}{\rho_2/\rho_1}\] \[T_{02} = T_{01}\]
예제 4.1.1 (초음속 흡입구 앞의 충격파)

고도의 공기(30 kPa, 220 K)가 \(M_1 = 2.5\)로 흐르다 수직 충격파를 지난다. 하류 마하수, 압력, 온도, 속도, 정체 압력 손실과 엔트로피 증가는?

풀이. \(M_2 = 0.513\)이다. \(p_2/p_1 = 7.13\)이므로 \(p_2 = 214\) kPa이고, \(\rho_2/\rho_1 = 3.33\), \(T_2/T_1 = 2.14\)이므로 \(T_2 = 470\) K이다. 속도는 \(V_1 = 2.5\sqrt{1.4\times287\times220} = 743\) m/s에서 \(V_2 = 743/3.33 = 223\) m/s로 준다. 정체 압력 비는 \(p_{02}/p_{01} = 0.499\)로 절반을 잃으며(그림 1), 엔트로피 증가는 \(c_p\ln(T_2/T_1) - R\ln(p_2/p_1) = 0.200\) kJ/(kg·K)이다. 처음 질문의 둘째 답이 이 손실이다. 그래서 충격파 하나로 속도를 줄이면 손실이 너무 커서, 초음속 흡입구는 경사 충격파 여러 개로 나눠 감속한다(4.2절).

4.1.2초음속 피토관

초음속 흐름에 피토관을 넣으면 관 앞에 수직 충격파가 서므로, 관이 재는 압력은 충격파 뒤의 정체 압력 \(p_{02}\)이다. 예제에서 \(p_{02} = p_2(1 + 0.2M_2^2)^{3.5} = 256\) kPa로, 등엔트로피로 멈췄을 때(\(p_{01} = 513\) kPa)의 절반이다. 그래서 정압 \(p_1\)과 \(p_{02}/p_1 = 8.53\)을 알면, \(p_{02}/p_1\)을 \(M_1\)의 함수로 쓴 Rayleigh 피토관 식을 거꾸로 풀어 \(M_1\)을 얻는다. 아음속 Bernoulli 식을 그대로 쓰면 크게 틀린다.

흔한 오해충격파를 지나도 정체 상태가 그대로라고 여기기 쉽지만, 단열이어서 정체 온도는 그대로이고 정체 압력은 줄어든다. 또 계산 결과는 \(k\)에 민감하므로 고온 연소 가스에는 맞는 \(k\)를 쓴다. 노즐 속 충격파의 위치는 응용열역학 6.2절 노즐 탐구에서 볼 수 있다.
마무리

질량·운동량·에너지 보존과 이상기체 식을 풀면 수직 충격파 하류 상태는 \(M_1\)의 함수로 정해진다. 충격파는 초음속을 아음속으로만 바꾸며, 압력·밀도·온도를 올리고 정체 압력을 잃게 하며 엔트로피를 늘린다. 초음속 피토관은 충격파 뒤의 정체 압력을 잰다.

4.1.3연습문제

기본

  1. \(M_1 = 1.5\)인 수직 충격파의 \(M_2\)와 \(p_2/p_1\)은?
    답

    \(M_2^2 = (2.25 + 5)/(7\times2.25 - 1) = 0.4915\), \(M_2 = 0.701\)이다. \(p_2/p_1 = 1 + 1.1667\times1.25 = 2.458\)이다.

응용

  1. \(M_1 = 1.5\)일 때 정체 압력 손실은 몇 %인가? \(M_1 = 2.5\)와 비교하여라.
    답

    \(p_{02}/p_{01} = 0.930\)이므로 손실은 7%이다. \(M_1 = 2.5\)에서는 50%이므로, 약한 충격파는 손실이 작다.

심화

  1. 정지한 공기(300 K) 속으로 수직 충격파가 들어온다. 충격파 뒤 압력이 앞의 2배라면 충격파 속도는? (충격파와 함께 움직이는 좌표에서 생각)
    답

    \(1 + 1.1667(M_1^2 - 1) = 2\)에서 \(M_1 = 1.36\)이다. 충격파 속도는 \(1.36\times347 = 473\) m/s이다.
