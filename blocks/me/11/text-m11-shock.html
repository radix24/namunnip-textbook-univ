수직 충격파 전후의 상태량

본문
이 절에서 배울 것
  • 수직 충격파를 질량·운동량·에너지 보존으로 다루는 방법을 안다.
  • 상류 마하수로 하류 마하수, 압력·밀도·온도 비, 정체 압력 손실을 구한다.
  • 초음속 흐름 속 피토관이 재는 압력을 해석한다.
먼저 알아야 할 것
  • 마하수와 등엔트로피 관계 (응용열역학 6.1절), 운동량 방정식 (유체역학 3단원).

4.1.1세 보존식

수직 충격파는 두께가 분자 평균 자유 행로의 몇 배(공기에서 1 μm 정도)인 얇은 층이라, 그 앞뒤를 하나의 검사체적으로 보고 넓이가 같은 정상 흐름으로 다룹니다.

\[\rho_1V_1 = \rho_2V_2\] \[p_1 + \rho_1V_1^2 = p_2 + \rho_2V_2^2\] \[h_1 + \frac{V_1^2}{2} = h_2 + \frac{V_2^2}{2}\]

이상기체 식과 함께 풀면 하류 상태가 상류 마하수 \(M_1\)만의 함수로 나옵니다. 해는 \(M_1 = 1\)(변화 없음)과 다음 결과 두 가지인데, 제2법칙(엔트로피 증가)을 만족하는 것은 \(M_1 > 1\)에서 \(M_2 < 1\)로 가는 압축 충격파뿐입니다. 아음속에서 초음속으로 뛰는 "팽창 충격파"는 엔트로피가 줄어 일어날 수 없습니다.

수직 충격파 관계 (이상기체, \(k\) 일정) \[M_2^2 = \frac{M_1^2 + \frac{2}{k-1}}{\frac{2k}{k-1}M_1^2 - 1}\] \[\frac{p_2}{p_1} = 1 + \frac{2k}{k+1}(M_1^2 - 1)\] \[\frac{\rho_2}{\rho_1} = \frac{V_1}{V_2} = \frac{(k+1)M_1^2}{(k-1)M_1^2 + 2}\] \[\frac{T_2}{T_1} = \frac{p_2/p_1}{\rho_2/\rho_1}\] \[T_{02} = T_{01}\]
예제 4.1.1 (초음속 흡입구 앞의 충격파)

고도의 공기(30 kPa, 220 K)가 \(M_1 = 2.5\)로 흐르다 수직 충격파를 지난다. 하류 마하수, 압력, 온도, 속도, 정체 압력 손실과 엔트로피 증가는?

풀이. \(M_2 = 0.513\). \(p_2/p_1 = 7.13\), \(p_2 = 214\) kPa. \(\rho_2/\rho_1 = 3.33\), \(T_2/T_1 = 2.14\), \(T_2 = 470\) K. 속도 \(V_1 = 2.5\sqrt{1.4\times287\times220} = 743\) m/s → \(V_2 = 743/3.33 = 223\) m/s. 정체 압력 비 \(p_{02}/p_{01} = 0.499\), 절반을 잃습니다. 엔트로피 증가 \(c_p\ln(T_2/T_1) - R\ln(p_2/p_1) = 0.200\) kJ/(kg·K). 충격파 하나로 속도를 줄이면 손실이 너무 커서, 초음속 흡입구는 경사 충격파 여러 개로 나눠 감속합니다.

4.1.2초음속 피토관

초음속 흐름에 피토관을 넣으면 관 앞에 수직 충격파가 서고, 관이 재는 압력은 충격파 뒤의 정체 압력 \(p_{02}\)입니다. 예제에서 \(p_{02} = p_2(1 + 0.2M_2^2)^{3.5} = 256\) kPa로, 등엔트로피로 멈췄을 때(\(p_{01} = 513\) kPa)의 절반입니다. 정압 \(p_1\)과 \(p_{02}/p_1 = 8.53\)을 알면 Rayleigh 피토관 식(\(p_{02}/p_1\)을 \(M_1\)의 함수로 쓴 식)을 거꾸로 풀어 \(M_1\)을 얻습니다. 아음속 Bernoulli 식을 그대로 쓰면 크게 틀립니다.

주의(1) 정체 온도는 충격파를 지나도 그대로지만 정체 압력은 줄어듭니다. (2) 계산 결과는 \(k\)에 민감하므로 고온 연소 가스는 \(k\)를 맞게 씁니다. (3) 노즐 속 충격파의 위치는 응용열역학 6.2절 노즐 탐구에서 볼 수 있습니다.
요약
  1. 질량·운동량·에너지 보존 + 이상기체 → 하류 상태는 \(M_1\)의 함수.
  2. 초음속 → 아음속만 가능, 압력·밀도·온도 상승, 정체 압력 손실, 엔트로피 증가.
  3. 초음속 피토관은 충격파 뒤 정체 압력을 잰다.

4.1.3연습문제

기본

  1. \(M_1 = 1.5\)인 수직 충격파의 \(M_2\)와 \(p_2/p_1\)은?
    답

    \(M_2^2 = (2.25 + 5)/(7\times2.25 - 1) = 0.4915\), \(M_2 = 0.701\). \(p_2/p_1 = 1 + 1.1667\times1.25 = 2.458\).

응용

  1. \(M_1 = 1.5\)일 때 정체 압력 손실은 몇 %인가? \(M_1 = 2.5\)와 비교하여라.
    답

    \(p_{02}/p_{01} = 0.930\), 손실 7%. \(M_1 = 2.5\)는 50%. 약한 충격파는 손실이 작다.

심화

  1. 정지한 공기(300 K) 속으로 수직 충격파가 들어온다. 충격파 뒤 압력이 앞의 2배라면 충격파 속도는? (충격파와 함께 움직이는 좌표에서 생각)
    답

    \(1 + 1.1667(M_1^2 - 1) = 2\) → \(M_1 = 1.36\). 충격파 속도 \(1.36\times347 = 473\) m/s.
