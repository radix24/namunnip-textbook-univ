경사 충격파와 팽창파

본문
이 절에서 배울 것
  • 초음속 흐름이 오목한 모서리에서 경사 충격파, 볼록한 모서리에서 팽창파를 만듦을 안다.
  • 경사 충격파를 충격파에 수직한 성분의 수직 충격파로 보고 계산한다.
  • 같은 마하수의 수직 충격파와 압력 상승, 손실을 비교한다.
먼저 알아야 할 것
  • 수직 충격파 (4.1절).

4.2.1수직 성분으로 보기

초음속 흐름이 쐐기에 부딪히면 흐름을 꺾는 경사 충격파가 생깁니다. 충격파에 나란한 속도 성분은 변하지 않고, 수직 성분만 수직 충격파처럼 줄어듭니다. 그래서 \(M_{n1} = M_1\sin\beta\)(\(\beta\): 충격파 각)로 수직 충격파 식을 그대로 씁니다.

경사 충격파 (\(\beta\): 충격파 각, \(\theta\): 꺾이는 각)

\(M_{n1} = M_1\sin\beta\), \(M_{n2}\)와 \(p_2/p_1\)은 수직 충격파 식에 \(M_{n1}\)을 넣어 얻는다.

\[\tan\theta = 2\cot\beta\,\frac{M_1^2\sin^2\beta - 1}{M_1^2(k + \cos2\beta) + 2},\qquad M_2 = \frac{M_{n2}}{\sin(\beta - \theta)}\]

경사 충격파는 수직 성분만 줄여 하류도 초음속인 경우가 많고, 정체압 손실이 수직 충격파보다 훨씬 작습니다. 초음속 흡입구가 여러 개의 경사 충격파로 감속하는 이유입니다. 볼록 모서리에서는 반대로 흐름이 부채꼴 팽창파를 지나며 가속되고 압력이 떨어집니다(등엔트로피).

예제 4.2.1 (쐐기)

\(M_1\) = 2 공기가 충격파 각 40°의 경사 충격파를 지난다. 꺾임 각, 압력비, 하류 마하수는? 같은 \(M_1\)의 수직 충격파와 비교하여라.

풀이. \(M_{n1} = 2\sin40° = 1.286\). 수직 충격파 식: \(M_{n2} = 0.793\), \(p_2/p_1 = 1 + \tfrac{2k}{k + 1}(M_{n1}^2 - 1) = 1.76\). \(\theta = 10.6°\), \(M_2 = 0.793/\sin29.4° = 1.62\)(여전히 초음속). 수직 충격파는 \(p_2/p_1 = 4.5\), \(M_2 = 0.577\).

주의주어진 \(M_1\)과 꺾임 각에 대해 경사 충격파 해는 보통 약한 해와 강한 해 두 개가 있고, 실제로는 대개 약한 해가 생깁니다. 꺾임 각이 최대값을 넘으면 충격파가 쐐기에서 떨어져 앞에 휜 충격파(분리 충격파)가 생깁니다.
요약
  1. \(M_{n1} = M_1\sin\beta\)로 수직 충격파 식 적용.
  2. 경사 충격파는 압력 상승과 손실이 작고 하류가 초음속일 수 있다.
  3. 볼록 모서리는 팽창파(가속, 압력 하강).

4.2.2연습문제

기본

  1. \(M_1\) = 3, \(\beta\) = 30°이면 \(M_{n1}\)은?
    답

    1.5.

응용

  1. \(M_{n1}\) = 1.5인 충격파의 압력비는(\(k\) = 1.4)?
    답

    \(1 + 1.167\times1.25 = 2.46\).

심화

  1. \(\beta\)가 마하각 \(\sin^{-1}(1/M_1)\)에 가까워지면 경사 충격파는 어떻게 되는가?
    답

    \(M_{n1} \to 1\)이라 압력 변화가 0인 약한 마하파가 된다(꺾임 각도 0).
