경사 충격파와 팽창파

본문

마하 2 흐름이 수직 충격파를 지나면 압력이 4.5배로 뛰고 흐름은 아음속이 된다. 그런데 뾰족한 쐐기 앞에서는 충격파가 비스듬히 서고, 압력은 훨씬 덜 오르며 흐름도 초음속으로 남는다. 비스듬한 충격파는 왜 더 약할까? 그 강도는 어떻게 계산할까?

먼저 알아야 할 것수직 충격파(4.1절)를 쓴다.

4.2.1수직 성분으로 보기

초음속 흐름이 쐐기에 부딪히면 흐름을 꺾는 경사 충격파가 생긴다. 이때 충격파에 나란한 속도 성분은 변하지 않고, 수직 성분만 수직 충격파처럼 줄어든다. 그래서 충격파 각을 \(\beta\)라 하면 \(M_{n1} = M_1\sin\beta\)를 수직 충격파 식에 그대로 넣는다. 처음 질문의 둘째 답이 이것이다.

경사 충격파 (\(\beta\): 충격파 각, \(\theta\): 꺾이는 각)

\(M_{n1} = M_1\sin\beta\)이며, \(M_{n2}\)와 \(p_2/p_1\)은 수직 충격파 식에 \(M_{n1}\)을 넣어 얻는다.

\[\tan\theta = 2\cot\beta\,\frac{M_1^2\sin^2\beta - 1}{M_1^2(k + \cos2\beta) + 2},\qquad M_2 = \frac{M_{n2}}{\sin(\beta - \theta)}\]

즉 경사 충격파가 실제로 겪는 마하수는 \(M_1\)보다 작은 \(M_{n1}\)이다. 그래서 수직 성분만 줄어 하류도 초음속인 경우가 많고, 정체 압력 손실이 수직 충격파보다 훨씬 작다. 처음 질문의 첫째 답이 이것이며, 초음속 흡입구가 여러 개의 경사 충격파로 감속하는 이유이다. 반대로 볼록 모서리에서는 흐름이 부채꼴 팽창파를 지나며 가속되고 압력이 떨어지는데, 이 과정은 등엔트로피이다.

예제 4.2.1 (쐐기)

\(M_1\) = 2 공기가 충격파 각 40°의 경사 충격파를 지난다. 꺾임 각, 압력비, 하류 마하수는? 같은 \(M_1\)의 수직 충격파와 비교하여라.

풀이. \(M_{n1} = 2\sin40° = 1.286\)이다. 수직 충격파 식으로 \(M_{n2} = 0.793\)이고, \(p_2/p_1 = 1 + \tfrac{2k}{k + 1}(M_{n1}^2 - 1) = 1.76\)이다. 꺾임 각은 \(\theta = 10.6°\)이고, \(M_2 = 0.793/\sin29.4° = 1.62\)로 여전히 초음속이다(그림 1). 같은 \(M_1\)의 수직 충격파는 \(p_2/p_1 = 4.5\), \(M_2 = 0.577\)이므로, 경사 충격파가 훨씬 약하다.

정체 압력으로 비교하면 차이가 더 분명하다. 수직 충격파는 마하 2에서 정체 압력의 28%를 잃지만, 이 경사 충격파는 \(M_{n1} = 1.286\)에 해당하는 약 2%만 잃는다. 그래서 흡입구를 쐐기 여러 단으로 만들어 약한 경사 충격파 몇 개로 나눠 감속하면, 같은 감속에 손실을 크게 줄일 수 있다.

흔한 실수경사 충격파 해가 하나뿐이라고 여기는 실수가 흔하다. 주어진 \(M_1\)과 꺾임 각에 대해 보통 약한 해와 강한 해 두 개가 있고, 실제로는 대개 약한 해가 생긴다. 또 꺾임 각이 최대값을 넘으면 충격파가 쐐기에서 떨어져, 앞에 휜 분리 충격파가 생긴다.
마무리

경사 충격파는 \(M_{n1} = M_1\sin\beta\)로 수직 충격파 식을 적용해 푼다. 수직 충격파보다 압력 상승과 손실이 작고, 하류가 초음속일 수 있다. 볼록 모서리에서는 팽창파가 흐름을 가속하고 압력을 낮춘다.

4.2.2연습문제

기본

  1. \(M_1\) = 3, \(\beta\) = 30°이면 \(M_{n1}\)은?
    답

    1.5이다.

응용

  1. \(M_{n1}\) = 1.5인 충격파의 압력비는(\(k\) = 1.4)?
    답

    \(1 + 1.167\times1.25 = 2.46\)이다.

심화

  1. \(\beta\)가 마하각 \(\sin^{-1}(1/M_1)\)에 가까워지면 경사 충격파는 어떻게 되는가?
    답

    \(M_{n1} \to 1\)이라 압력 변화가 0인 약한 마하파가 된다(꺾임 각도 0).
