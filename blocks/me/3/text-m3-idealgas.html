이상기체와 압축성 인자

본문
이 절에서 배울 것
  • 이상기체 상태식 \(Pv = RT\)와 기체 상수 \(R = R_u/M\)을 쓴다.
  • 압축성 인자 \(Z = Pv/(RT)\)로 실제 기체가 이상기체에서 얼마나 벗어나는지 잰다.
  • 환산 압력·환산 온도로 이상기체 근사를 써도 되는지 판단한다.
먼저 알아야 할 것
  • 포화 돔과 임계점 (3.1절).
  • 절대 압력과 절대 온도 (1.2절).

3.2.1이상기체 상태식

공기 같은 기체는 증기표 없이 간단한 식으로 성질을 계산합니다.

이상기체 상태식 \[Pv = RT\] \[PV = mRT\]

\(R = R_u/M\)은 기체마다 다른 기체 상수이다. \(R_u = 8.314\) kJ/kmol·K는 모든 기체에 같은 일반 기체 상수, \(M\)은 몰질량(kg/kmol)이다.

공기는 \(M = 28.97\)이므로 \(R = 0.287\) kJ/kg·K, 수증기는 \(M = 18.015\)이므로 \(R = 0.4615\), 이산화탄소는 \(R = 0.1889\)입니다. 고교 화학의 \(PV = nRT\)와 같은 식인데, 공학에서는 몰수 대신 질량을 쓰는 것이 편리해 이렇게 씁니다.

이상기체는 분자의 크기와 분자 사이 인력을 무시한 모형입니다. 분자들이 서로 멀리 떨어져 있을 때, 곧 압력이 낮거나 온도가 높을 때 잘 맞습니다.

3.2.2압축성 인자

정의 3.2.1 (압축성 인자) \[Z = \frac{Pv}{RT}\]

이상기체이면 \(Z = 1\)이다. \(Z\)가 1에서 멀수록 이상기체 근사의 오차가 크다.

\(Z < 1\)이면 실제 비체적이 이상기체보다 작습니다. 분자 사이 인력이 분자들을 끌어당겨 더 촘촘하게 만들기 때문입니다. 압력이 아주 높으면 분자 자체의 크기 때문에 \(Z > 1\)이 되기도 합니다.

놀랍게도 서로 다른 기체도 임계점으로 나눈 값이 같으면 \(Z\)가 거의 같습니다(대응 상태 원리). 그래서 다음 환산 성질로 하나의 그래프(일반화 압축성 선도)를 씁니다.

환산 압력 \(P_R = P/P_{cr}\), 환산 온도 \(T_R = T/T_{cr}\).

그래프의 결론은 다음과 같이 기억하면 됩니다.

  • \(P_R \ll 1\)(임계 압력보다 훨씬 낮음)이면 온도와 상관없이 \(Z \approx 1\).
  • \(T_R > 2\)(임계 온도의 두 배 넘음)이면 \(P_R < 4\) 정도까지 \(Z \approx 1\).
  • 임계점 근처(\(P_R \approx 1\), \(T_R \approx 1\))에서 가장 크게 벗어난다(\(Z\)가 0.3 가까이).

공기(주성분 질소 \(T_{cr} = 126\) K, \(P_{cr} = 3.39\) MPa)는 상온·수 기압에서 \(T_R \approx 2.4\), \(P_R \approx 0.03\)이라 이상기체로 아주 잘 맞습니다. 반대로 증기 발전소의 고압 수증기, 냉동기의 냉매처럼 포화 돔 근처에서 쓰는 물질은 이상기체로 다루면 안 되고 표를 써야 합니다.

예제 3.2.2

1 MPa, 300 °C 수증기의 비체적을 이상기체 식으로 구하고 증기표 값(0.25799 m³/kg)과 비교하여라. 100 kPa 포화 증기에서도 같은 비교를 하여라.

풀이. \(v = RT/P = 0.4615\times573.15/1000 = 0.2645\) m³/kg. 표 값보다 2.5% 큽니다(\(Z = 0.975\)). 100 kPa 포화 증기는 \(Z = 100\times1.6941/(0.4615\times372.76) = 0.985\)로 1.5% 차이입니다. 수증기는 저압에서는 이상기체로 다뤄도 큰 오차가 없지만(공기 중 수증기를 다루는 공기조화, 응용열역학), 발전소의 수 MPa 증기에서는 오차가 커집니다.

3.2.3더 정확한 상태식

이상기체 식에 분자의 크기와 인력을 보정한 가장 간단한 식이 반데르발스 상태식입니다.

\[\left(P + \frac{a}{v^2}\right)(v - b) = RT\]

\(b\)는 분자 자체가 차지하는 부피, \(a/v^2\)은 분자 사이 인력의 효과입니다. 상수는 임계점 자료로 정합니다: \(a = 27R^2T_{cr}^2/(64P_{cr})\), \(b = RT_{cr}/(8P_{cr})\). 정확도는 높지 않지만 실제 기체가 임계점 근처에서 어떻게 벗어나는지 정성적으로 잘 보여 줍니다(실습 카드). 실무에서는 더 정교한 식이나 표를 씁니다.

주의(1) 이상기체 식에는 절대 압력, 절대 온도(K)를 넣습니다. (2) \(R_u\)와 \(R\)을 헷갈리지 마세요. 질량 기준 식에는 기체마다 다른 \(R\)을 씁니다. (3) "기체니까 이상기체"가 아닙니다. 포화 돔 근처의 증기는 기체 상태여도 표를 써야 합니다.
요약
  1. \(Pv = RT\), \(R = R_u/M\). 공기 0.287, 수증기 0.4615 kJ/kg·K.
  2. \(Z = Pv/(RT)\). 이상기체면 1.
  3. \(P_R \ll 1\) 또는 \(T_R > 2\)이면 이상기체 근사가 잘 맞고, 임계점 근처에서 크게 틀린다.
  4. 반데르발스 식은 분자 크기(\(b\))와 인력(\(a\))을 보정한 간단한 식이다.

3.2.4연습문제

기본

  1. 부피 0.1 m³ 탱크에 20 °C, 계기 압력 500 kPa(대기 100 kPa)의 공기가 있다. 질량은?
    답

    \(m = PV/(RT) = 600\times0.1/(0.287\times293.15) = 0.713\) kg.

  2. 헬륨(\(M = 4.003\))의 기체 상수는?
    답

    \(8.314/4.003 = 2.077\) kJ/kg·K.

응용

  1. 이산화탄소(\(T_{cr} = 304.1\) K, \(P_{cr} = 7.38\) MPa)를 300 K, 5 MPa로 저장한다. 이상기체 근사를 써도 되는지 환산 성질로 판단하여라.
    답

    \(T_R = 0.99\), \(P_R = 0.68\). 임계점에 가까워 이상기체로는 크게 틀린다(실습 카드의 반데르발스 계산에서 \(Z \approx 0.73\)).
