제트 엔진은 터빈 일을 어디에 쓸까?

예제 · Brayton 사이클과 노즐
문제 해결 전략 · 기체동력 사이클
  1. 사이클의 각 과정을 정한다(등엔트로피, 정적, 정압)와 장치(밀폐계 또는 정상유동).
  2. 등엔트로피 과정은 \(T_2/T_1 = (v_1/v_2)^{k-1} = (P_2/P_1)^{(k-1)/k}\)로 온도를 구한다.
  3. 가열·방열은 정적이면 \(c_v\Delta T\), 정압이면 \(c_p\Delta T\). 일은 제1법칙으로.
  4. 장치 효율이 있으면 등엔트로피 온도를 먼저 구하고 효율로 실제 온도를 구한다.

문제. 지상에 서 있는 이상 터보제트 엔진(공기 표준)에서 공기가 100 kPa, 300 K로 압축기에 들어가 압력비 10으로 압축되고, 연소기에서 1400 K로 데워진다. 터빈은 압축기를 돌릴 만큼만 일을 하고, 나머지 압력으로 노즐에서 100 kPa까지 팽창한다. 터빈 출구 온도·압력과 노즐 출구 속도는?

전략

발전용 가스 터빈은 터빈에서 끝까지 팽창시켜 축 일을 얻지만(8.2절), 제트 엔진은 터빈이 압축기 몫만 가져가고 남은 엔탈피를 노즐에서 속도로 바꿉니다(5.1절). 정상유동 장치를 차례로 푼다.

풀이

  1. 압축기: \(T_2 = 300\times10^{0.2857} = 579.2\) K, \(w_c = 1.005\times279.2 = 280.6\) kJ/kg.
    등엔트로피 압축.
  2. 터빈: \(w_t = w_c\)이므로 \(T_4 = 1400 - 280.6/1.005 = 1120.8\) K.
    터빈 일 = 압축기 일.
  3. 터빈 출구 압력: \(P_4 = 1000\times(1120.8/1400)^{3.5} = 459\) kPa.
    등엔트로피 관계를 압력으로: \(P_4/P_3 = (T_4/T_3)^{k/(k-1)}\).
  4. 노즐 출구(100 kPa): \(T_5 = 1400\times0.1^{0.2857} = 725.1\) K.
    터빈 + 노즐 전체가 1000 → 100 kPa 등엔트로피 팽창.
  5. \(\mathcal V_5 = \sqrt{2\times1005\times(1120.8 - 725.1)} = 892\) m/s.
    노즐: \(h_4 = h_5 + \mathcal V_5^2/2\) (입구 속도 무시).

의미

공기 1 kg/s가 0에서 892 m/s로 빨라지므로 추력은 약 892 N(정지 상태 기준)이다. 발전용 가스 터빈이 축으로 내던 순일 397.6 kJ/kg가, 제트 엔진에서는 운동 에너지 \(892^2/2 = 397.6\) kJ/kg로 같은 양만큼 나온다. 같은 Brayton 사이클의 순일을 축 동력으로 쓰느냐 분사 속도로 쓰느냐의 차이이다.

검산

\(\mathcal V_5^2/2 = 891.8^2/2 = 397.6\) kJ/kg가 이상 Brayton 순일 \(w_t - w_c = 678.2 - 280.6 = 397.6\)과 같다. 에너지가 맞다.

이해 확인

비행기가 250 m/s로 날고 있다면(공기가 250 m/s로 들어옴) 공기 1 kg/s당 추력은 대략 얼마로 줄어들까요(같은 노즐 출구 속도라고 가정)?

답

추력 ≈ \(\dot m(\mathcal V_{\text{출구}} - \mathcal V_{\text{비행}}) = 892 - 250 = 642\) N. 빨리 날수록 같은 분사 속도의 추력은 줄어든다.
