같은 부피 변화라도 과정이 다르면 일과 열이 달라질까?

실습 · P-V 선도의 넓이와 제1법칙

목표

피스톤-실린더 속 공기 10 g을 등압, 등온, 폴리트로픽, 정적 과정으로 바꾸며 P-V 선도에서 경계일(곡선 아래 넓이)을 보고, 내부에너지 변화와 열을 제1법칙으로 계산한다. 성취기준 [기계3-02-01], [기계3-04-01].

준비

공기는 이상기체(\(R = 0.287\) kJ/kg·K, \(c_v = 0.718\) kJ/kg·K)로 보고 처음 온도는 300 K로 고정한다. 장치는 2.1절의 경계일 식과 4단원의 제1법칙 \(Q = \Delta U + W_b\), \(\Delta U = mc_v(T_2 - T_1)\)을 계산한다. 칠한 넓이가 경계일이며, 파란색은 팽창(계가 일을 함), 빨간색은 압축(일을 받음)이다.

절차

  1. 등압, V₂/V₁ = 2에서 W, ΔU, Q를 적는다.
  2. 같은 부피비 2로 등온, 폴리트로픽 n = 1.4를 차례로 해 세 과정의 W, ΔU, Q를 표로 비교한다.
  3. V₂/V₁ = 0.2(압축)로 바꿔 등온과 n = 1.4를 비교한다. 끝 압력과 일은?
  4. 정적 과정에서 압력을 두 배로 올린다. 일은 얼마이고, 열은 어디로 가나요?

기대 결과

  • 처음 부피는 8.61 L이다.
  • 등압 팽창(×2): W = 861 J, 온도 600 K로 ΔU = 2154 J, Q = 3015 J. 들어온 열의 약 29%만 일이 된다.
  • 등온 팽창(×2): W = 597 J, ΔU = 0, Q = W = 597 J. 들어온 열이 모두 일이 된다.
  • n = 1.4 팽창(×2): W = 521 J, 온도 227 K로 떨어져 ΔU = −522 J, Q ≈ 0. 공기의 단열 가역 과정이 n = 1.4이기 때문입니다(일은 내부에너지에서 나옴).
  • 압축(×0.2): 등온은 끝 압력 500 kPa, W = −1386 J(열 1386 J가 나감), n = 1.4는 952 kPa, 571 K, W = −1945 J. 단열 압축이 일을 더 많이 필요로 합니다(2.1절 예제와 같은 결론).
  • 정적(압력 ×2): W = 0, 온도 600 K, Q = ΔU = 2154 J. 들어온 열이 모두 내부에너지가 된다.

분석

  1. 같은 처음 상태에서 같은 부피로 팽창하는데 일이 등압 > 등온 > 단열 순서인 이유를 P-V 곡선의 높이로 설명해 보자.
  2. 등압 과정에서 \(Q = mc_p\Delta T\) (\(c_p = c_v + R = 1.005\))임을 출력의 숫자로 확인해 보자.
  3. 열과 일이 "경로 함수"이고 ΔU는 "상태 함수"라는 말을 이 실습의 결과로 설명해 보자.

더 해 보기

디젤 엔진의 압축 행정을 n = 1.35, 압축비 18(V₂/V₁ = 1/18)로 생각하면 끝 온도는 얼마일까? 장치 범위(0.2)를 넘으니 손으로 \(T_2 = T_1(V_1/V_2)^{n-1}\)로 계산하고, 경유의 자연 발화 온도(약 500 K 이상)와 비교해 보자.
