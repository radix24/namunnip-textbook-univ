평판 비정상 전도의 1항 근사

본문
이 절에서 배울 것
  • Biot 수가 커서 집중 용량법을 못 쓸 때 평판의 중심 온도를 1항 근사로 구한다.
  • 고유값 방정식 \(\zeta\tan\zeta = \text{Bi}\)를 풀어 \(\zeta_1\), \(C_1\)을 얻는다.
  • Fourier 수로 냉각 시간을 계산한다.
먼저 알아야 할 것
  • Biot 수 (4.1절), 집중 용량법 (4.2절).

4.4.11항 근사

두께 \(2L\) 평판을 대류로 식히면 정확한 해는 무한 급수입니다. Fourier 수 \(\text{Fo} = \alpha t/L^2\)가 약 0.2보다 크면 첫 항만으로 오차 2% 이내가 되어 계산이 간단해집니다.

평판 1항 근사 (\(\text{Bi} = hL/k\), \(L\): 반두께)

\[\theta_0 = \frac{T_0 - T_\infty}{T_i - T_\infty} = C_1e^{-\zeta_1^2\text{Fo}}\]

\(\zeta_1\tan\zeta_1 = \text{Bi}\), \(C_1 = \dfrac{4\sin\zeta_1}{2\zeta_1 + \sin2\zeta_1}\)

표 값: Bi = 0.1 → \(\zeta_1\) = 0.311, \(C_1\) = 1.016; Bi = 0.25 → 0.480, 1.038; Bi = 1 → 0.860, 1.119.

Bi가 작으면 \(\zeta_1^2 \approx \text{Bi}\), \(C_1 \approx 1\)이 되어 집중 용량 식 \(e^{-\text{Bi}\,\text{Fo}}\)와 같아집니다. 원통과 구도 같은 꼴의 식(다른 고유값 방정식)을 씁니다.

예제 4.4.1 (강판 냉각)

두께 40 mm 강판(\(k\) = 40, \(\alpha = 1.17\times10^{-5}\) m²/s)을 \(h\) = 500 W/m²·K로 식힌다. 중심의 \(\theta_0\)가 0.1이 되는 시간은?

풀이. \(\text{Bi} = 500\times0.02/40 = 0.25\) → \(\zeta_1 = 0.480\), \(C_1 = 1.038\). \(\text{Fo} = \ln(1.038/0.1)/0.480^2 = 10.15\), \(t = 10.15\times0.02^2/1.17\times10^{-5} = 347\) s(약 6분).

주의Bi = 0.25면 집중 용량법(Bi < 0.1)을 쓰기엔 크지만 아주 크지도 않아, 집중 용량법(\(\theta = e^{-\text{Bi}\,\text{Fo}}\))으로 풀면 \(\text{Fo} = \ln10/0.25 = 9.2\), \(t = 315\) s로 10% 짧게 나옵니다. 표면과 중심 온도 차가 생기는 만큼 오차가 생깁니다.
요약
  1. \(\theta_0 = C_1e^{-\zeta_1^2\text{Fo}}\) (Fo > 0.2).
  2. \(\zeta_1\tan\zeta_1 = \text{Bi}\)로 고유값.
  3. Bi가 작으면 집중 용량법과 같아짐.

4.4.2연습문제

기본

  1. Bi = 1, Fo = 1인 평판의 중심 \(\theta_0\)는?
    답

    \(1.119e^{-0.740} = 0.53\).

응용

  1. 예제에서 \(\theta_0\) = 0.5가 되는 시간은?
    답

    \(\text{Fo} = \ln(1.038/0.5)/0.2304 = 3.17\), \(t = 108\) s.

심화

  1. 예제 판 두께를 두 배(80 mm)로 하면(같은 \(h\)) \(\theta_0\) = 0.1까지 걸리는 시간은 몇 배인가?
    답

    Bi = 0.5 → \(\zeta_1^2 = 0.427\), \(C_1 = 1.070\), \(\text{Fo} = 5.55\), \(t = 5.55\times0.04^2/1.17\times10^{-5} = 760\) s로 약 2.2배. \(L^2\)은 4배지만 \(\zeta_1^2\)도 커져 필요한 Fo가 줄기 때문이다.
