평판 비정상 전도의 1항 근사

본문

두께 40 mm 강판을 담금질하면 Bi가 0.25여서 판 전체를 온도 하나로 볼 수 없다. 정확한 해는 끝없는 급수인데, 공장에서 "중심이 충분히 식을 때까지 몇 분 담가야 하는가"를 매번 급수로 풀어야 할까? 급수의 첫 항 하나로 충분한 때는 언제일까?

먼저 알아야 할 것Biot 수(4.1절), 집중 용량법(4.2절)을 쓴다.

4.4.11항 근사

두께 \(2L\)인 평판을 대류로 식히면 정확한 해는 무한 급수이다. 급수의 각 항은 시간에 따라 지수적으로 줄어드는데, 뒤의 항일수록 훨씬 빨리 준다. 그래서 Fourier 수 \(\text{Fo} = \alpha t/L^2\)가 약 0.2보다 크면 첫 항만 남아 오차가 2% 이내가 된다. 처음 질문의 답이 이것이다.

평판 1항 근사 (\(\text{Bi} = hL/k\), \(L\): 반두께)

\[\theta_0 = \frac{T_0 - T_\infty}{T_i - T_\infty} = C_1e^{-\zeta_1^2\text{Fo}}\]

고유값 \(\zeta_1\)은 \(\zeta_1\tan\zeta_1 = \text{Bi}\)의 첫 근이고, \(C_1 = \dfrac{4\sin\zeta_1}{2\zeta_1 + \sin2\zeta_1}\)이다.

표 값은 Bi = 0.1이면 \(\zeta_1\) = 0.311, \(C_1\) = 1.016, Bi = 0.25이면 0.480, 1.038, Bi = 1이면 0.860, 1.119이다.

Bi가 작으면 \(\zeta_1^2 \approx \text{Bi}\), \(C_1 \approx 1\)이 되어, 1항 근사는 집중 용량 식 \(e^{-\text{Bi}\,\text{Fo}}\)와 같아진다(그림 1). 즉 집중 용량법은 1항 근사의 Bi가 작은 극한이다. 원통과 구도 같은 꼴의 식을 쓰며, 고유값 방정식만 다르다.

예제 4.4.1 (강판 냉각)

두께 40 mm 강판(\(k\) = 40, \(\alpha = 1.17\times10^{-5}\) m²/s)을 \(h\) = 500 W/m²·K로 식힌다. 중심의 \(\theta_0\)가 0.1이 되는 시간은?

풀이. 반두께 \(L = 0.02\) m이므로 \(\text{Bi} = 500\times0.02/40 = 0.25\)이고, 표에서 \(\zeta_1 = 0.480\), \(C_1 = 1.038\)이다. 따라서 \(\text{Fo} = \ln(1.038/0.1)/0.480^2 = 10.15\)이고, \(t = 10.15\times0.02^2/1.17\times10^{-5} = 347\) s, 약 6분이다. Fo가 0.2보다 훨씬 크므로 1항 근사로 충분하다.

같은 문제를 집중 용량법으로 풀면 \(e^{-0.25\,\text{Fo}} = 0.1\)에서 Fo = 9.2, 약 315 s가 나온다. 집중 용량법은 표면과 중심의 차를 무시하므로 중심이 식는 시간을 10% 가까이 짧게 본다.

흔한 실수Bi를 정의할 때 판의 전체 두께를 넣는 실수가 흔하다. 양면으로 식는 평판의 1항 근사는 반두께 \(L\)로 Bi와 Fo를 정의하므로, 전체 두께를 넣으면 Bi는 2배, Fo는 4분의 1이 되어 시간이 크게 틀린다. 또 Fo가 0.2보다 작은 초기에는 첫 항만으로 부족해 급수나 반무한체 해를 써야 한다.
마무리

평판 중심 온도는 Fo > 0.2이면 1항 근사 \(\theta_0 = C_1e^{-\zeta_1^2\text{Fo}}\)로 구한다. 고유값은 \(\zeta_1\tan\zeta_1 = \text{Bi}\)로 정한다. Bi가 작으면 1항 근사는 집중 용량법과 같아진다.

4.4.2연습문제

기본

  1. Bi = 1, Fo = 1인 평판의 중심 \(\theta_0\)는?
    답

    \(1.119e^{-0.740} = 0.53\)이다.

응용

  1. 예제에서 \(\theta_0\) = 0.5가 되는 시간은?
    답

    \(\text{Fo} = \ln(1.038/0.5)/0.2304 = 3.17\)이므로 \(t = 108\) s이다.

심화

  1. 예제 판 두께를 두 배(80 mm)로 하면(같은 \(h\)) \(\theta_0\) = 0.1까지 걸리는 시간은 몇 배인가?
    답

    Bi = 0.5이면 \(\zeta_1^2 = 0.427\), \(C_1 = 1.070\), \(\text{Fo} = 5.55\)이므로 \(t = 5.55\times0.04^2/1.17\times10^{-5} = 760\) s로 약 2.2배이다. \(L^2\)은 4배지만 \(\zeta_1^2\)도 커져 필요한 Fo가 줄기 때문이다.
