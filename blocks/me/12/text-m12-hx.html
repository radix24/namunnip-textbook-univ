열교환기: LMTD 방법과 ε-NTU 방법

본문
이 절에서 배울 것
  • 평행류와 대향류 열교환기의 온도 분포와 총괄 열전달 계수 \(U\)를 안다.
  • 출구 온도를 알 때 필요한 크기를 LMTD 방법으로 구한다(설계).
  • 크기를 알 때 출구 온도를 ε-NTU 방법으로 구한다(평가).

6.2.1총괄 계수와 온도 분포

열교환기는 뜨거운 유체와 찬 유체를 벽으로 나눠 열만 옮깁니다. 벽을 지나는 저항(안쪽 대류 + 벽 전도 + 바깥 대류 + 물때)을 합쳐 \(1/(UA)\)로 씁니다. 두 유체의 온도 차는 위치에 따라 바뀌므로 평균 온도 차가 필요합니다.

열용량률 \(C = \dot mc_p\) (W/K): 유체가 1 K 바뀌는 데 필요한 열전달률. \(C\)가 작은 유체의 온도가 더 많이 바뀐다.

평행류(같은 방향)는 입구에서 온도 차가 크고 출구로 갈수록 작아지며, 찬 유체 출구는 뜨거운 유체 출구보다 뜨거워질 수 없습니다. 대향류(반대 방향)는 온도 차가 고르고, 찬 유체 출구가 뜨거운 유체 출구보다 뜨거워질 수 있어 더 효율적입니다(열교환기 탐구).

6.2.2LMTD 방법

로그 평균 온도 차 \[\dot Q = UA\,\Delta T_{lm}\] \[\Delta T_{lm} = \frac{\Delta T_1 - \Delta T_2}{\ln(\Delta T_1/\Delta T_2)}\]

\(\Delta T_1\), \(\Delta T_2\): 양 끝의 두 유체 온도 차. 대향류는 (뜨거운 입구 − 찬 출구), (뜨거운 출구 − 찬 입구).

예제 6.2.1 (설계: 필요한 UA)

뜨거운 물 1 kg/s(\(c_p = 4.18\))를 90 °C에서 40 °C로 식히려 한다. 찬 물 1.5 kg/s가 20 °C로 들어온다. 대향류로 필요한 \(UA\)는?

풀이. \(\dot Q = 4.18\times50 = 209\) kW. 찬 물 출구 \(20 + 209/6.27 = 53.3\) °C. \(\Delta T_1 = 90 - 53.3 = 36.7\), \(\Delta T_2 = 40 - 20 = 20\), \(\Delta T_{lm} = 27.5\) °C. \(UA = 209/27.5 = 7.6\) kW/K. \(U = 1000\) W/(m²·K)이면 넓이 7.6 m²입니다.

6.2.3ε-NTU 방법

크기(\(UA\))는 알고 출구 온도를 모를 때 LMTD 방법은 반복이 필요합니다. 대신 효율을 씁니다.

유용도와 NTU \[\varepsilon = \frac{\dot Q}{C_{\min}(T_{h,i} - T_{c,i})}\] \[\text{NTU} = \frac{UA}{C_{\min}}\] \[C_r = \frac{C_{\min}}{C_{\max}}\] \[\text{대향류: }\varepsilon = \frac{1 - e^{-\text{NTU}(1 - C_r)}}{1 - C_re^{-\text{NTU}(1 - C_r)}}\] \[\text{평행류: }\varepsilon = \frac{1 - e^{-\text{NTU}(1 + C_r)}}{1 + C_r}\]
예제 6.2.2 (평가: 출구 온도)

예제 6.2.1의 유체를 \(UA = 5\) kW/K 열교환기에 넣으면 출구 온도는? 대향류와 평행류를 비교하여라.

풀이. \(C_{\min} = 4.18\), \(C_r = 0.667\), NTU = 1.20. 대향류 \(\varepsilon = 0.595\), \(\dot Q = 0.595\times4.18\times70 = 174\) kW, 뜨거운 물 출구 48.3 °C, 찬 물 47.8 °C. 평행류 \(\varepsilon = 0.518\), 152 kW, 53.7 °C와 44.2 °C. 같은 넓이로 대향류가 15% 더 옮깁니다. 대향류 결과로 LMTD를 계산하면 34.8 °C, \(UA\times\Delta T_{lm} = 174\) kW로 같아 검산이 됩니다.

주의(1) 쉘-튜브, 직교류 열교환기는 다른 ε 식이나 LMTD 보정 계수를 씁니다. (2) 시간이 지나면 물때로 \(U\)가 줄어드므로 설계에 오염 저항을 넣습니다. (3) NTU를 아주 크게 해도 ε은 1(평행류는 \(1/(1+C_r)\))을 넘지 못합니다.
요약
  1. \(\dot Q = UA\Delta T_{lm}\): 출구 온도를 알 때(설계).
  2. \(\dot Q = \varepsilon C_{\min}\Delta T_{max}\), \(\varepsilon(\text{NTU}, C_r)\): 크기를 알 때(평가).
  3. 대향류가 평행류보다 효율적이다.

6.2.4연습문제

기본

  1. 한쪽 유체가 응축(온도 일정, \(C_{\max} \to \infty\))하는 열교환기의 ε은?
    답

    \(C_r = 0\)이라 두 식 모두 \(\varepsilon = 1 - e^{-\text{NTU}}\).

응용

  1. 예제 6.2.1을 평행류로 하면 뜨거운 물을 40 °C까지 식힐 수 있는가?
    답

    평행류 최대 \(\varepsilon = 1/(1 + 0.667) = 0.6\), 최대 \(\dot Q = 0.6\times4.18\times70 = 176\) kW로 필요한 209 kW에 못 미친다. 아무리 커도 불가능하다.

심화

  1. \(U = 800\) W/(m²·K), 넓이 10 m²로 예제 유체를 대향류로 처리하면 뜨거운 물 출구 온도는?
    답

    \(UA = 8\), NTU = 1.91, \(\varepsilon = (1 - e^{-0.638})/(1 - 0.667e^{-0.638}) = 0.472/0.648 = 0.728\). \(\dot Q = 213\) kW, 출구 39.0 °C.
