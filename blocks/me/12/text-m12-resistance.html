열저항 회로: 복합벽의 열전달

본문
이 절에서 배울 것
  • 1차원 정상 전도에서 온도 분포가 직선인 이유를 안다.
  • 전도·대류의 열저항을 정의하고, 직렬·병렬 회로로 복합벽의 열전달률을 구한다.
  • 원통 벽의 열저항과 층별 온도를 구한다.
먼저 알아야 할 것
  • 세 열전달 법칙 (1.1절), 전기 회로의 직렬·병렬 저항(고등학교 물리).

2.1.1평면 벽

열 발생이 없는 평면 벽에서 정상 상태라면 어느 단면을 지나는 열전달률도 같아야 합니다(중간에 쌓이면 온도가 바뀌므로). Fourier 법칙 \(\dot Q = -kA\,dT/dx\)에서 \(\dot Q\), \(k\), \(A\)가 일정하므로 \(dT/dx\)가 일정, 곧 온도가 직선으로 바뀝니다. 그래서 \(\dot Q = kA(T_1 - T_2)/L\)입니다.

2.1.2열저항

전기에서 전류 = 전압 차 / 저항이듯, 열전달률 = 온도 차 / 열저항으로 씁니다.

열저항 (K/W) \[R_{전도} = \frac{L}{kA}\] \[R_{대류} = \frac{1}{hA}\] \[R_{원통} = \frac{\ln(r_2/r_1)}{2\pi kL}\]

직렬: \(R = R_1 + R_2 + \cdots\), \(\dot Q = \Delta T_{전체}/R\). 병렬: \(1/R = 1/R_1 + 1/R_2 + \cdots\).

예제 2.1.1 (단열한 벽)

넓이 10 m² 벽: 안쪽 공기 20 °C(\(h = 8\)), 회반죽 2 cm(\(k = 0.5\)), 벽돌 20 cm(\(k = 0.72\)), 단열재 5 cm(\(k = 0.04\)), 바깥 공기 −5 °C(\(h = 25\)). 열 손실과 각 경계 온도는? 단열재가 없다면?

풀이. 넓이 1 m² 기준 저항(m²·K/W): 0.125 + 0.040 + 0.278 + 1.250 + 0.040 = 1.733. 열유속 \(25/1.733 = 14.4\) W/m², 벽 전체 144 W. 온도는 저항을 하나씩 지날 때마다 \(q\times R\)만큼 내려가 18.2 → 17.6 → 13.6 → −4.4 → −5.0 °C. 온도 차의 대부분(18 °C)이 단열재에 걸립니다. 단열재가 없으면 저항 0.483, 손실 518 W로 3.6배가 됩니다.

2.1.3병렬 경로와 접촉 저항

벽에 나무 기둥과 단열재가 번갈아 있으면 두 경로가 병렬입니다. 저항이 작은 기둥 쪽으로 열이 많이 새는 열교(thermal bridge)가 생깁니다. 또 두 고체를 붙여도 표면 거칠기 때문에 실제 접촉 면적이 작아 접촉 열저항이 생기며, 전자 칩과 방열판 사이에 열전도 그리스를 바르는 이유입니다.

주의(1) 열저항은 넓이에 반비례하므로, 넓이 1 m² 기준 값(m²·K/W, 건축의 R값)과 전체 값(K/W)을 구분합니다. (2) 원통 벽은 넓이가 반지름에 따라 커져 온도 분포가 로그 곡선이 됩니다.
요약
  1. 1차원 정상 전도: 온도 직선, \(\dot Q = \Delta T/R\).
  2. \(R_{전도} = L/(kA)\), \(R_{대류} = 1/(hA)\), \(R_{원통} = \ln(r_2/r_1)/(2\pi kL)\).
  3. 직렬은 더하고, 병렬은 역수를 더한다. 가장 큰 저항이 온도 차를 가장 많이 차지한다.

2.1.4연습문제

기본

  1. 예제에서 단열재를 10 cm로 두껍게 하면 열 손실은?
    답

    저항 \(1.733 + 1.25 = 2.983\), 열유속 8.4 W/m², 84 W.

응용

  1. 강관(안지름 50 mm, 바깥지름 60 mm, \(k = 50\)) 1 m에 150 °C 증기가 흐르고(안쪽 \(h = 1000\)), 바깥 공기 20 °C(\(h = 10\))이다. 관 1 m당 열 손실은?
    답

    \(R_i = 1/(1000\times\pi\times0.05) = 0.00637\), \(R_{관} = \ln(1.2)/(2\pi\times50) = 0.00058\), \(R_o = 1/(10\times\pi\times0.06) = 0.531\). 합 0.538, \(\dot Q = 130/0.538 = 242\) W. 바깥 대류가 거의 모든 저항이다.

심화

  1. 2번 관에 두께 3 cm 단열재(\(k = 0.05\))를 감으면 열 손실은?
    답

    바깥 반지름 0.06 m. \(R_{단열} = \ln(2)/(2\pi\times0.05) = 2.206\), \(R_o = 1/(10\times2\pi\times0.06) = 0.265\). 합 \(0.0064 + 0.0006 + 2.206 + 0.265 = 2.478\), \(\dot Q = 52\) W. 약 5분의 1로 준다.
