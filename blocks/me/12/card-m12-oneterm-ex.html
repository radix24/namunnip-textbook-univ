오븐에서 고기 중심이 익는 시간

예제 · 1항 근사 · 표면 온도 · 두께 효과
문제 해결 전략 · 중심과 표면 둘 다
  1. Bi로 \(\zeta_1\), \(C_1\)을 구한다.
  2. 목표 중심 온도의 \(\theta_0\)에서 Fo와 시간을 구한다.
  3. 그때 표면 온도 \(\theta_s = \theta_0\cos\zeta_1\)도 확인한다.

문제. 두께 3 cm 고기(\(k\) = 0.45, \(\alpha = 1.3\times10^{-7}\) m²/s, 처음 5 °C)를 180 °C 오븐(\(h\) = 30 W/m²·K, 양면)에 넣는다. 중심이 70 °C가 되는 시간과 그때 표면 온도는? 두께가 1.5 cm면?

전략

\(L\) = 0.015 m, \(\text{Bi} = 30\times0.015/0.45 = 1.0\), \(\theta_0 = (70 - 180)/(5 - 180) = 0.629\).

풀이

  1. Bi = 1: \(\zeta_1 = 0.860\), \(C_1 = 1.119\). \(\text{Fo} = \ln(1.119/0.629)/0.740 = 0.78\).
    Fo > 0.2 확인.
  2. \(t = 0.78\times0.015^2/1.3\times10^{-7} = 1350\) s ≈ 22분.
    시간.
  3. 표면 \(\theta_s = 0.629\times\cos0.860 = 0.410\) → \(180 - 175\times0.410 = 108\) °C.
    표면은 훨씬 뜨거움.

검산

두께 1.5 cm(\(L\) = 0.0075, Bi = 0.5): \(\zeta_1 = 0.653\), \(C_1 = 1.070\), Fo = 1.25, \(t\) = 9.0분. 두께가 절반이면 시간이 약 0.4배로 줄어든다.

의미

두꺼운 고기는 중심이 익을 때 표면이 과하게 익기 쉬워, 낮은 온도로 오래 굽거나(표면-중심 차이 줄임) 굽기 전에 미리 데운다. 같은 원리가 강재 열처리(중심까지 경화)와 콘크리트 양생에도 적용된다.

바꿔 보기

대류 오븐(팬)으로 \(h\)를 60으로 키우면 Bi = 2라 시간이 줄지만 표면과 중심 온도 차는 더 커진다.
