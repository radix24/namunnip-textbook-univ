실험계획법과 응답 표면

본문
이 절에서 배울 것
  • 2수준 완전 요인 설계로 해석 실행 조합을 정한다.
  • 주효과와 교호작용을 계산하고 영향이 큰 설계 변수를 고른다.
  • 회귀 모델(응답 표면)로 해석 없이 결과를 예측하고 설계점을 찾는다.
먼저 알아야 할 것
  • 매개변수 최적화 (5.2절), 최소제곱 회귀(공학통계).

5.3.1요인 설계

설계 변수를 하나씩 바꾸는 방식은 변수끼리의 상호 영향을 놓치고 실행 수도 비효율적입니다. 각 변수를 낮음(−1)과 높음(+1) 두 수준으로 정하고 모든 조합을 해석하는 것이 2수준 완전 요인 설계입니다. 변수 \(k\)개면 \(2^k\)번입니다.

효과와 회귀 모델 (2수준, 코드화 변수 \(x = \pm1\))

주효과 \(E_A = \bar y_{A+} - \bar y_{A-}\), 교호작용 \(E_{AB} = \bar y_{(AB)+} - \bar y_{(AB)-}\)

\[\hat y = b_0 + b_Ax_A + b_Bx_B + b_{AB}x_Ax_B,\qquad b = E/2,\ b_0 = \bar y\]

\(x_Ax_B = +1\)인 실행은 두 변수가 같은 수준(둘 다 낮음 또는 둘 다 높음)인 경우입니다. 교호작용이 크면 한 변수의 효과가 다른 변수 값에 따라 달라집니다.

예제 5.3.1 (브래킷 응력)

두께 \(t\)(−1: 3 mm, +1: 5 mm)와 필렛 반지름 \(r\)(−1: 2 mm, +1: 6 mm)로 FEM 4번을 돌려 최대 응력(MPa)을 얻었다: \((-,-)\) 220, \((+,-)\) 160, \((-,+)\) 180, \((+,+)\) 130. 효과와 회귀 모델은?

풀이. 평균 172.5. \(E_t = (160 + 130)/2 - (220 + 180)/2 = -55\), \(E_r = (180 + 130)/2 - (220 + 160)/2 = -35\), \(E_{tr} = (220 + 130)/2 - (160 + 180)/2 = 5\). 모델 \(\hat y = 172.5 - 27.5x_t - 17.5x_r + 2.5x_tx_r\). 두께 영향이 가장 크고, 교호작용은 작습니다.

5.3.2응답 표면과 곡률

2수준 설계는 직선(과 꼬임)만 표현합니다. 중앙점을 한 번 더 해석해 모델 예측(\(b_0\))과 비교하면 곡률이 있는지 알 수 있고, 곡률이 크면 중심 합성 설계(CCD) 같은 3수준 이상 설계로 2차 응답 표면을 만듭니다. 변수가 많으면 부분 요인 설계로 영향이 큰 변수를 먼저 골라냅니다.

주의응답 표면은 실험(해석)한 범위 안에서만 믿을 수 있습니다. 범위 밖으로 외삽해 최적점을 찾으면 크게 틀릴 수 있으므로, 찾은 설계점은 반드시 FEM으로 다시 확인합니다.
요약
  1. \(2^k\) 요인 설계: 모든 조합, 교호작용까지.
  2. 효과 = 높음 평균 − 낮음 평균, 회귀 계수 = 효과/2.
  3. 중앙점으로 곡률 확인, 범위 안에서만 예측, 최종 확인 해석.

5.3.3연습문제

기본

  1. 설계 변수 5개의 2수준 완전 요인 설계는 몇 번 해석인가?
    답

    \(2^5 = 32\)번.

응용

  1. 예제 모델로 \(x_t = 0\), \(x_r = 0\)(두께 4 mm, 필렛 4 mm)의 응력을 예측하여라. 중앙점 FEM이 160 MPa였다면 무엇을 뜻하는가?
    답

    예측 172.5 MPa. 실제 160으로 12.5 MPa 낮아 응답에 곡률이 있다. 2차 모델이 필요하다.

심화

  1. 변수를 하나씩 바꾸는 방식(기준 \((-,-)\)에서 \(t\)만, \(r\)만)으로 예제를 풀면 어떤 정보를 놓치는가?
    답

    \((+,+)\) 조합을 해석하지 않아 교호작용을 알 수 없고, 효과가 기준점에서만의 값이라 다른 조건에서 틀릴 수 있다. 같은 4번 실행이라면 요인 설계가 더 많은 정보를 준다.
