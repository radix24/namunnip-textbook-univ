경계 조건, 변위, 반력

본문
이 절에서 배울 것
  • 고정 경계와 하중 경계를 강성 방정식에 넣는다.
  • 축소된 방정식으로 미지 변위를 구하고, 원래 방정식으로 반력을 구한다.
  • 요소 변위에서 응력을 계산한다.
먼저 알아야 할 것
  • 강성 행렬 조립 (1.1절).

1.2.1경계 조건 넣기

각 절점에서는 변위나 힘 중 하나만 알고 있습니다. 고정 절점은 변위가 0(반력은 모름), 자유 절점은 하중을 알고 변위를 모릅니다. 변위를 아는 행과 열을 지우면 미지 변위만의 축소된 방정식이 남습니다.

풀이 순서

① 변위가 정해진 자유도의 행과 열을 지운다. ② 남은 \([K_{ff}]\{u_f\} = \{F_f\}\)를 푼다. ③ 지운 행에 \(\{u\}\)를 넣어 반력을 구한다. ④ 요소마다 변위 차로 변형률 \(\varepsilon = (u_j - u_i)/L\), 응력 \(\sigma = E\varepsilon\)를 구한다.

예제 1.2.1 (1.1절 스프링, 끝에 하중)

1.1절 예제에서 절점 1을 고정하고 절점 3에 600 N을 가했다. 변위와 반력은?

풀이. 1행·1열을 지우면 \(\begin{bmatrix}300 & -100\\ -100 & 100\end{bmatrix}\begin{Bmatrix}u_2\\ u_3\end{Bmatrix} = \begin{Bmatrix}0\\ 600\end{Bmatrix}\). 둘째 식에서 \(u_3 = u_2 + 6\), 첫째에 넣으면 \(200u_2 = 600\), \(u_2 = 3\) mm, \(u_3 = 9\) mm. 반력은 1행: \(R_1 = -200\times3 = -600\) N으로 하중과 평형입니다. 직렬 스프링으로 손 계산(\(600/200 + 600/100\))한 값과 같습니다.

예제 1.2.2 (양 끝 고정 막대)

양 끝이 벽에 고정된 강 막대(\(E\) = 200 GPa)가 길이 500 mm씩 두 구간으로 되어 있고, 왼쪽 단면 200 mm², 오른쪽 100 mm²이다. 가운데 절점에 오른쪽으로 10 kN을 가하면 변위, 반력, 응력은?

풀이. \(k_1 = 200000\times200/500 = 80000\), \(k_2 = 40000\) N/mm. 절점 1, 3 고정 → \(120000u_2 = 10000\), \(u_2 = 0.0833\) mm. \(R_1 = -80000u_2 = -6667\) N, \(R_3 = -40000u_2 = -3333\) N(합 −10 kN). 응력: 왼쪽 \(6667/200 = 33.3\) MPa(인장), 오른쪽 \(-3333/100 = -33.3\) MPa(압축). 강한 쪽이 더 많은 하중을 받습니다.

주의구속이 부족하면(강체 운동 가능) 행렬이 특이해 풀리지 않거나 터무니없는 결과가 나옵니다. 3차원 해석에서는 이동 3개, 회전 3개를 모두 막았는지 확인합니다. 반대로 실제보다 과하게 고정하면 강성이 과대 평가되고 응력이 틀립니다.
요약
  1. 변위 아는 자유도 행·열 제거 → 축소 방정식.
  2. 변위 → 지운 행으로 반력 → 요소 응력.
  3. 반력 합 = 하중 합으로 검산.

1.2.3연습문제

기본

  1. 예제 1.2.1에서 하중을 절점 2에 가하면 \(u_2\), \(u_3\)는?
    답

    스프링 2에는 힘이 없으므로 \(u_2 = u_3 = 600/200 = 3\) mm.

응용

  1. 예제 1.2.2에서 오른쪽 단면도 200 mm²로 바꾸면 반력은?
    답

    대칭이므로 각각 5 kN, 응력은 ±25 MPa.

심화

  1. 예제 1.2.2의 오른쪽 벽이 0.05 mm 미끄러져 있다면(절점 3에 정해진 변위 \(u_3\) = 0.05 mm), 어떻게 푸는가?
    답

    2행 식 \(-80000u_1 + 120000u_2 - 40000u_3 = 10000\)에 \(u_1 = 0\), \(u_3 = 0.05\)를 넣어 \(u_2 = (10000 + 2000)/120000 = 0.1\) mm. 정해진 변위는 오른쪽 항으로 옮겨 하중처럼 다룬다.
