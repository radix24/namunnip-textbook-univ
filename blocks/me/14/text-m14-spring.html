코일 압축 스프링 설계

본문
이 절에서 배울 것
  • 코일 스프링의 선이 주로 비틀림 전단을 받음을 안다.
  • 스프링 지수와 Wahl 계수로 최대 전단 응력을 구한다.
  • 강성 식으로 유효 감김 수를 정하고 허용 응력과 비교한다.
먼저 알아야 할 것
  • 원형 단면 비틀림 응력, 응력 집중 (1.1절).

3.4.1응력과 Wahl 계수

선 지름 \(d\), 평균 코일 지름 \(D\)인 스프링을 힘 \(F\)로 누르면 선 단면에 토크 \(FD/2\)가 걸립니다. 스프링 지수 \(C = D/d\)(보통 4~12)가 작을수록 곡률과 직접 전단 때문에 안쪽 응력이 커집니다.

코일 스프링

\[\tau = K_W\frac{8FD}{\pi d^3},\qquad K_W = \frac{4C - 1}{4C - 4} + \frac{0.615}C\]

\[k = \frac{d^4G}{8D^3N_a}\qquad (N_a\text{: 유효 감김 수})\]

강성이 \(d^4\)과 \(D^{-3}\)에 비례하므로 선 지름을 조금만 바꿔도 강성이 크게 바뀝니다. 피아노선 같은 스프링 강의 인장 강도는 선이 가늘수록 높아 \(S_{ut} \approx A/d^m\)(피아노선 \(A\) = 2211 MPa·mm\(^m\), \(m\) = 0.145)으로 나타냅니다.

예제 3.4.1 (피아노선 스프링)

\(d\) = 3 mm, \(D\) = 24 mm, \(N_a\) = 10, \(G\) = 79.3 GPa. 강성과 150 N에서의 최대 전단 응력은?

풀이. \(k = 3^4\times79300/(8\times24^3\times10) = 5.81\) N/mm. \(C = 8\), \(K_W = 1.184\), \(\tau = 1.184\times8\times150\times24/(\pi\times27) = 402\) MPa. \(S_{ut} = 2211/3^{0.145} = 1885\) MPa이므로 정적 허용 \(0.45S_{ut} = 848\) MPa에 비해 여유가 있습니다.

주의스프링을 끝까지 눌렀을 때(밀착 높이)의 응력도 허용 응력 이하여야 조립이나 과부하 때 영구 변형이 생기지 않습니다. 반복 하중을 받는 스프링(밸브 스프링 등)은 피로 기준으로 따로 검토합니다.
요약
  1. \(\tau = K_W\cdot8FD/(\pi d^3)\), \(C = D/d\).
  2. \(k = d^4G/(8D^3N_a)\).
  3. 밀착 응력과 피로를 따로 확인.

3.4.2연습문제

기본

  1. \(C\) = 6일 때 Wahl 계수는?
    답

    \(23/20 + 0.615/6 = 1.150 + 0.103 = 1.253\).

응용

  1. 예제 스프링에서 \(D\)만 20 mm로 줄이면 강성은?
    답

    \(D^{-3}\) 비례이므로 \(5.81\times(24/20)^3 = 10.0\) N/mm.

심화

  1. 예제 스프링이 밀착까지 30 mm 눌릴 수 있다. 밀착 응력은 허용 848 MPa를 넘는가?
    답

    \(F = 5.81\times30 = 174\) N이므로 \(\tau = 402\times174/150 = 467\) MPa, 넘지 않는다.
