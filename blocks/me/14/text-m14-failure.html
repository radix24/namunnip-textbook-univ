정적 파손 이론: 연성 재료와 취성 재료

본문
이 절에서 배울 것
  • 복합 응력 상태를 인장 시험 결과와 비교하는 파손 이론이 왜 필요한지 안다.
  • 연성 재료에 von Mises(최대 변형 에너지)와 Tresca(최대 전단 응력) 기준을 적용한다.
  • 취성 재료에 Coulomb-Mohr 기준을 적용해 안전계수를 구한다.
먼저 알아야 할 것
  • 주응력과 Mohr 원, 응력 집중 (1.1절).

1.2.1왜 파손 이론인가

재료 시험은 대개 단순 인장 하나로 항복 강도 \(S_y\), 인장 강도 \(S_{ut}\)를 줍니다. 그런데 축 표면처럼 굽힘 응력과 비틀림 전단 응력이 함께 있는 점은 어떻게 판정할까요? 파손 이론은 복합 응력을 하나의 등가 응력으로 바꿔 시험 강도와 비교하게 해 줍니다. 재료가 늘어나다 끊어지는 연성 재료와, 거의 늘어나지 않고 깨지는 취성 재료는 다른 이론을 씁니다.

1.2.2연성 재료: von Mises와 Tresca

연성 재료 기준 (평면 응력 \(\sigma_x\), \(\tau_{xy}\))

von Mises: \(\sigma' = \sqrt{\sigma_x^2 + 3\tau_{xy}^2}\), \(n = S_y/\sigma'\)

Tresca: \(\tau_{\max} = \sqrt{(\sigma_x/2)^2 + \tau_{xy}^2}\), \(n = S_y/(2\tau_{\max})\)

von Mises는 시험 결과와 잘 맞고, Tresca는 조금 더 보수적(안전계수가 작게 나옴)입니다. 순수 전단에서 von Mises는 전단 항복 강도를 \(S_{sy} = 0.577S_y\), Tresca는 \(0.5S_y\)로 봅니다.

1.2.3취성 재료: Coulomb-Mohr

주철처럼 압축 강도 \(S_{uc}\)가 인장 강도 \(S_{ut}\)보다 훨씬 큰 재료는 인장과 압축을 따로 봐야 합니다. 주응력이 \(\sigma_1 \ge 0 \ge \sigma_3\)일 때

Coulomb-Mohr

\[\frac{\sigma_1}{S_{ut}} - \frac{\sigma_3}{S_{uc}} = \frac1n\]

예제 1.2.1 (축 표면)

\(S_y\) = 350 MPa 강축 표면에 굽힘 응력 120 MPa, 비틀림 전단 응력 60 MPa가 있다. 두 기준의 안전계수는?

풀이. von Mises \(\sigma' = \sqrt{120^2 + 3\times60^2} = 158.7\) MPa, \(n = 2.21\). Tresca \(\tau_{\max} = \sqrt{60^2 + 60^2} = 84.9\) MPa, \(n = 350/169.7 = 2.06\). Tresca가 약 7% 보수적입니다.

주의연성 재료에 최대 주응력 기준을 쓰면 전단이 큰 경우를 위험하게 과대평가합니다. 반대로 취성 재료에 von Mises를 쓰면 인장 쪽을 과대평가합니다. 재료 거동에 맞는 기준을 고릅니다.
요약
  1. 파손 이론 = 복합 응력을 시험 강도와 비교하는 방법.
  2. 연성: von Mises \(\sqrt{\sigma^2 + 3\tau^2}\), Tresca는 더 보수적.
  3. 취성: Coulomb-Mohr \(\sigma_1/S_{ut} - \sigma_3/S_{uc} = 1/n\).

1.2.4연습문제

기본

  1. \(S_y\) = 250 MPa 강의 순수 전단 항복 강도를 von Mises로 구하여라.
    답

    \(0.577\times250 = 144\) MPa.

응용

  1. 예제 축에서 안전계수 2.5(von Mises)를 얻으려면 굽힘 응력을 얼마로 낮춰야 하는가? (전단은 그대로)
    답

    \(\sigma' = 140\) MPa이므로 \(\sigma^2 = 140^2 - 3\times60^2 = 8800\), \(\sigma = 93.8\) MPa.

심화

  1. 순수 전단 \(\tau\)를 받는 주철(\(S_{ut}\) = 200, \(S_{uc}\) = 700 MPa)이 견디는 전단 강도를 Coulomb-Mohr로 구하여라.
    답

    \(\sigma_1 = \tau\), \(\sigma_3 = -\tau\)이므로 \(\tau(1/200 + 1/700) = 1\), \(\tau = 156\) MPa. 인장 강도보다 작다.
