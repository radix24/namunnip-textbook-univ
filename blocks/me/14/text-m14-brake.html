브레이크: 밴드 브레이크와 제동 에너지

본문
이 절에서 배울 것
  • 밴드 브레이크의 양 끝 장력비를 벨트 마찰 식으로 구한다.

  • 마찰 클러치 (4.2절), 벨트 장력비 (6.2절).

4.4.1밴드 브레이크

회전하는 드럼(반지름 \(r\))에 띠를 감아 당기면 띠와 드럼 사이 마찰이 토크를 흡수합니다. 감은 각 \(\theta\), 마찰 계수 \(\mu\)일 때 팽팽한 쪽 \(T_1\)과 느슨한 쪽 \(T_2\)는 벨트와 같은 관계입니다.

밴드 브레이크

\[\frac{T_1}{T_2} = e^{\mu\theta},\qquad T_{\text{brake}} = (T_1 - T_2)r\]

느슨한 쪽 끝을 레버(받침점에서 거리 \(a\))에 걸고 레버 끝(거리 \(l\))을 누르면 조작력 \(P = T_2a/l\).

장력비가 지수적으로 커지므로 느슨한 쪽의 작은 힘으로 큰 제동 토크를 얻습니다. 드럼이 반대로 돌면 \(T_1\)과 \(T_2\)가 바뀌어 같은 레버 힘으로 제동 토크가 크게 줄어듭니다.

4.4.2제동 에너지와 온도

정지할 때까지 흡수한 운동 에너지는 거의 전부 브레이크의 열이 됩니다. 짧은 정지에서는 열이 빠져나갈 시간이 적어 \(\Delta T \approx E/(mc)\)로 어림합니다.

예제 4.4.1 (윈치 밴드 브레이크)

드럼 반지름 0.15 m, 감은 각 270°, \(\mu\) = 0.3, 필요한 제동 토크 300 N·m. 양 끝 장력과, \(a\) = 50 mm, \(l\) = 400 mm일 때 조작력은?

풀이. \(e^{0.3\times4.712} = 4.11\). \(T_1 - T_2 = 300/0.15 = 2000\) N이므로 \(T_2 = 2000/3.11 = 643\) N, \(T_1 = 2643\) N. 조작력 \(P = 643\times50/400 = 80\) N으로 손으로 충분합니다.

주의마찰 계수는 온도, 습기, 마모로 크게 변합니다. \(\mu\)가 0.3에서 0.2로 떨어지면 장력비가 4.11에서 2.57로 줄어 같은 조작력으로 얻는 제동 토크가 약 절반으로 떨어집니다. 마찰 계수는 보수적으로 잡습니다.
요약
  1. \(T_1/T_2 = e^{\mu\theta}\), 토크 \((T_1 - T_2)r\).
  2. 조작력 \(P = T_2a/l\), 회전 방향에 민감.
  3. 제동 에너지 → 열, \(\Delta T \approx E/(mc)\).

4.4.3연습문제

기본

  1. 감은 각 180°, \(\mu\) = 0.25일 때 장력비는?
    답

    \(e^{0.785} = 2.19\).

응용

  1. 예제에서 \(\mu\) = 0.2로 떨어지면 조작력 80 N으로 얻는 제동 토크는?
    답

    \(T_2 = 643\) N, 장력비 \(e^{0.942} = 2.57\), \(T_1 - T_2 = 643\times1.57 = 1008\) N, 토크 151 N·m(원래의 약 50%).

심화

  1. 질량 500 kg 짐을 3 m/s로 내리던 윈치를 멈춘다. 드럼 강 부분 질량 20 kg(\(c\) = 460 J/kg·K)의 온도 상승은? 짐이 정지 거리 2 m를 더 내려가는 위치 에너지도 넣어라.
    답

    운동 에너지 2250 J, 위치 에너지 \(500\times9.81\times2 = 9810\) J, 합 12.1 kJ. \(\Delta T = 12060/(20\times460) = 1.3\) K.
