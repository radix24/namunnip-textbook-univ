주철 브래킷의 안전계수

예제 · Coulomb-Mohr · 주응력
문제 해결 전략 · 주응력을 먼저
  1. 위험점의 주응력 \(\sigma_1\), \(\sigma_3\)를 구한다.
  2. 재료가 취성이므로 Coulomb-Mohr 식에 넣는다.
  3. 연성 기준을 잘못 썼을 때와 비교한다.

문제. 회주철(\(S_{ut}\) = 200 MPa, \(S_{uc}\) = 700 MPa) 브래킷의 위험점에서 주응력이 \(\sigma_1\) = 80 MPa, \(\sigma_3\) = −120 MPa이다. 안전계수는? von Mises를 잘못 적용하면(\(S_{ut}\)를 강도로) 얼마가 나오는가?

전략

\(\sigma_1 \ge 0 \ge \sigma_3\)이므로 Coulomb-Mohr 식을 그대로 씁니다.

풀이

  1. \(1/n = 80/200 + 120/700 = 0.400 + 0.171 = 0.571\).
    인장 몫이 크다.
  2. \(n = 1.75\).
    Coulomb-Mohr.
  3. 잘못된 von Mises: \(\sigma' = \sqrt{80^2 + 80\times120 + 120^2} = 174\) MPa, \(n = 200/174 = 1.15\).
    \(\sqrt{\sigma_1^2 - \sigma_1\sigma_3 + \sigma_3^2}\).

검산

\(\sigma_3\)를 0으로 두면 \(n = 200/80 = 2.5\)로, 압축 주응력이 더해지면서 안전계수가 줄어드는 방향이 맞습니다. 압축 강도가 커서 줄어드는 폭이 작습니다.

의미

von Mises는 인장과 압축을 똑같이 다루므로 취성 재료의 큰 압축 강도를 살리지 못합니다. 이 경우 보수적으로 나왔지만, 인장이 지배적인 다른 조합에서는 위험하게 나올 수도 있습니다.

바꿔 보기

같은 주응력의 부호를 바꿔 \(\sigma_1\) = 120, \(\sigma_3\) = −80 MPa이면 \(1/n = 0.6 + 0.114 = 0.714\), \(n = 1.40\)입니다. 인장 쪽 응력이 커질수록 주철은 훨씬 불리합니다.

이해 확인

안전계수 2.5를 얻으려면 두 주응력을 같은 비율로 몇 %까지 줄여야 하는가?

답

\(1.75/2.5 = 0.70\), 즉 70%(30% 감소).
