신뢰도로 정하는 안전계수

본문
이 절에서 배울 것
  • 강도와 응력이 모두 흩어지는 확률 변수라는 관점을 안다.
  • 두 정규 분포의 간섭으로 파손 확률과 신뢰도를 구한다.
  • 목표 신뢰도에서 허용 평균 응력과 평균 안전계수를 정한다.
먼저 알아야 할 것
  • 정규 분포와 표준 정규 변수 \(z\), 파손 이론 (1.2절).

1.3.1강도-응력 간섭

같은 규격의 강재도 강도가 수 % 흩어지고, 하중도 사용자마다 다릅니다. 강도 \(S\)(평균 \(\mu_S\), 표준편차 \(\sigma_S\))와 응력 \(s\)(\(\mu_s\), \(\sigma_s\))가 정규 분포이면 여유 \(m = S - s\)도 정규 분포이고, \(m < 0\)일 확률이 파손 확률입니다.

신뢰도

\[z = \frac{\mu_S - \mu_s}{\sqrt{\sigma_S^2 + \sigma_s^2}},\qquad R = \Phi(z)\]

평균 안전계수 \(\bar n = \mu_S/\mu_s\). \(z\) = 3.09이면 \(R\) = 0.999, 3.72이면 0.9999.

같은 평균 안전계수라도 흩어짐이 크면 신뢰도가 낮습니다. 안전계수 하나만으로는 위험을 다 말하지 못하는 이유입니다.

예제 1.3.1 (연결봉)

강도 평균 400 MPa(표준편차 30), 응력 평균 280 MPa(표준편차 25)이다. 평균 안전계수와 신뢰도는?

풀이. \(\bar n = 400/280 = 1.43\). \(z = 120/\sqrt{900 + 625} = 120/39.1 = 3.07\), \(R = 0.9989\)(1000개 중 약 1개 파손).

주의정규 분포의 꼬리는 자료가 적은 곳이라, 0.9999 같은 높은 신뢰도는 분포 가정에 민감합니다. 안전이 중요한 부품은 시험과 검사로 꼬리를 직접 확인합니다.
요약
  1. 여유 \(S - s\)의 분포로 파손 확률을 구한다.
  2. \(z = (\mu_S - \mu_s)/\sqrt{\sigma_S^2 + \sigma_s^2}\), \(R = \Phi(z)\).
  3. 흩어짐이 크면 같은 \(\bar n\)에서도 신뢰도가 낮다.

1.3.2연습문제

기본

  1. \(z\) = 2.33이면 신뢰도와 파손 확률은?
    답

    \(R = 0.990\), 파손 확률 1%.

응용

  1. 예제에서 응력 표준편차를 10 MPa로 줄이면(하중 관리) 신뢰도는?
    답

    \(z = 120/\sqrt{1000} = 3.79\), \(R = 0.99992\). 평균은 그대로인데 파손 확률이 약 14분의 1이 된다.

심화

  1. 강도 변동 계수 8%, 응력 변동 계수 10%일 때 \(R\) = 0.999에 필요한 평균 안전계수는? (\(\mu_S = \bar n\mu_s\)로 놓고 풀어라.)
    답

    \(\bar n - 1 = 3.09\sqrt{(0.08\bar n)^2 + 0.1^2}\)를 풀면 \(\bar n \approx 1.48\).
