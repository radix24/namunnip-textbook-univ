양적·음적 방법과 안정 조건

본문
이 절에서 배울 것
  • 1차원 비정상 열전도의 양적 방법과 음적 방법을 세운다.
  • 양적 방법의 안정 조건 \(r = \alpha\Delta t/\Delta x^2 \le 1/2\)을 이끌어 낸다.
  • 안정성과 정확도를 구별해 시간 간격을 정한다.
먼저 알아야 할 것
  • 2차원 열전도 차분 (7.1절), Euler 방법의 안정 조건 (6.1절).

7.2.1양적 방법

막대의 열전도 \(\partial T/\partial t = \alpha\,\partial^2T/\partial x^2\)에서 시간은 전진 차분, 공간은 중심 차분으로 바꾸면

양적(FTCS) 방법

\[T_i^{n+1} = T_i^n + r\left(T_{i-1}^n - 2T_i^n + T_{i+1}^n\right)\]

\[r = \frac{\alpha\Delta t}{\Delta x^2}\]

안정 조건: \(r \le 1/2\) (2차원 정사각 격자는 \(r \le 1/4\)).

새 값이 옛 값만으로 바로 계산되어(양적) 간단하지만, 간격 조건이 붙습니다. 식을 \(T_i^{n+1} = rT_{i-1} + (1 - 2r)T_i + rT_{i+1}\)로 쓰면 이유가 보입니다. \(r > 1/2\)이면 자기 자신의 계수 \(1 - 2r\)가 음수가 되어, 지금 뜨거운 절점이 다음 걸음에 오히려 차가워지는 비물리적 결과가 생깁니다.

7.2.2안정 조건 이끌어 내기

절점마다 부호가 바뀌는 가장 거친 톱니 모양 오차 \(+\varepsilon, -\varepsilon, +\varepsilon, \dots\)를 넣어 봅니다. 한 절점에서 \(T_{i\pm1} = -\varepsilon\)이므로 새 값은 \(\varepsilon + r(-\varepsilon - 2\varepsilon - \varepsilon) = (1 - 4r)\varepsilon\)입니다. 걸음마다 \(|1 - 4r|\)배가 되므로 커지지 않으려면 \(|1 - 4r| \le 1\), 곧 \(r \le 1/2\)입니다. 일반적인 파형으로 같은 계산을 하는 것이 von Neumann 안정성 해석입니다.

예제 7.2.1 (강철 막대)

강철(\(\alpha = 1.2\times10^{-5}\) m²/s) 막대를 \(\Delta x = 1\) cm로 나눴다. 양적 방법의 최대 시간 간격은? \(\Delta x\)를 5 mm로 하면?

풀이. \(\Delta t \le 0.5\times(0.01)^2/1.2\times10^{-5} = 4.2\) s. \(\Delta x = 5\) mm이면 \(\Delta t\)가 4분의 1인 1.04 s로 줄고, 절점이 2배라 같은 시간까지 계산량이 8배입니다.

7.2.3음적 방법

공간 차분을 새 시간에서 계산하면 \(-rT_{i-1}^{n+1} + (1 + 2r)T_i^{n+1} - rT_{i+1}^{n+1} = T_i^n\)입니다. 걸음마다 삼중 대각 연립방정식(Thomas 알고리듬, 계산량은 절점 수에 비례)을 풀어야 하지만 어떤 \(r\)에서도 안정합니다. 두 방법의 평균인 Crank-Nicolson은 시간 정확도가 2차입니다. 단, 안정하다고 정확한 것은 아니어서 큰 간격은 변화를 늦게 따라갑니다(실습).

주의(1) 안정 조건은 가장 작은 격자 간격이 정하므로, 한 곳만 격자를 촘촘히 해도 양적 방법 전체의 시간 간격이 줄어듭니다. (2) 상용 열해석 프로그램이 음적 방법을 기본으로 쓰는 이유입니다.
요약
  1. 양적 방법: 간단, \(r = \alpha\Delta t/\Delta x^2 \le 1/2\) (2차원 1/4).
  2. 톱니 오차가 \(|1 - 4r|\)배씩 변함 → 안정 조건.
  3. 음적 방법: 연립방정식, 무조건 안정, 정확도는 따로 확인.

7.2.4연습문제

기본

  1. \(r = 0.5\)인 양적 방법에서 \(T_{i-1} = 20\), \(T_i = 50\), \(T_{i+1} = 40\)이면 \(T_i^{n+1}\)은?
    답

    \(0.5\times20 + 0\times50 + 0.5\times40 = 30\). \(r = 1/2\)이면 두 이웃의 평균이 된다.

응용

  1. \(r = 0.6\)이면 톱니 오차가 한 걸음에 몇 배가 되는가? 60걸음 뒤에는?
    답

    \(1 - 2.4 = -1.4\), 크기 1.4배로 부호가 바뀐다. \(1.4^{60}\approx6\times10^8\)배로 발산한다.

심화

  1. 알루미늄(\(\alpha = 9.7\times10^{-5}\) m²/s) 판을 \(h = 2\) mm 정사각 격자로 양적 2차원 계산할 때 최대 시간 간격은?
    답

    \(\Delta t \le 0.25\times(0.002)^2/9.7\times10^{-5} = 0.010\) s. 10초를 계산하려면 1000걸음이 필요하다.
