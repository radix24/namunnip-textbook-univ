수치 미분과 적분: 차분 공식과 Simpson 공식

본문

자동차의 속도계 기록이 1초 간격으로 남아 있다. 이 숫자 몇 개만으로 이동 거리와 가속도를 구할 수 있을까? 그리고 측정값에 잡음이 섞여 있을 때, 거리는 믿을 만하게 나오는데 가속도는 엉망이 되는 까닭은 무엇일까?

먼저 알아야 할 것절단 오차(1.1절), 정적분과 넓이(고등학교 미적분)를 쓴다.

5.1.1차분 공식

1차 도함수 근사 (간격 \(h\))

전진 \(\dfrac{f_{i+1} - f_i}{h}\)와 후진 \(\dfrac{f_i - f_{i-1}}{h}\)는 오차가 \(O(h)\)이고, 중심 \(\dfrac{f_{i+1} - f_{i-1}}{2h}\)는 오차가 \(O(h^2)\)이다.

2차 도함수의 중심 차분은 \(\dfrac{f_{i+1} - 2f_i + f_{i-1}}{h^2}\)이며, 오차는 \(O(h^2)\)이다.

중심 차분은 앞뒤가 대칭이라 오차의 1차 항이 상쇄되어, 같은 간격에서 훨씬 정확하다(1.3절). 다만 자료의 끝점에서는 한쪽 이웃이 없으므로 전진이나 후진 차분을 쓴다.

5.1.2적분 공식

등간격 자료의 적분

사다리꼴은 \(I \approx h\left[\dfrac{f_0}{2} + f_1 + \cdots + f_{n-1} + \dfrac{f_n}{2}\right]\)이며, 오차는 \(O(h^2)\)이다.

Simpson 1/3(\(n\) 짝수)은 \(I \approx \dfrac h3[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 4f_{n-1} + f_n]\)이며, 오차는 \(O(h^4)\)이고 3차 다항식까지 정확하다.

예제 5.1.1 (속도 기록에서 이동 거리)

1초마다 잰 속도가 0, 3, 8, 15, 24 m/s(실제 \(v = t^2 + 2t\))이다. 0~4 s 이동 거리를 사다리꼴과 Simpson으로, \(t = 2\) s의 가속도를 중심 차분으로 구하여라.

풀이. 사다리꼴은 \(1\times(0 + 3 + 8 + 15 + 12) = 38.0\) m이다. Simpson은 \(\frac13(0 + 12 + 16 + 60 + 24) = 37.33\) m로, 정확한 값 \(64/3 + 16 = 37.33\)과 같다(그림 1). 속도가 2차식이라 Simpson이 정확한 것이다. 가속도는 중심 차분으로 \((15 - 3)/2 = 6\) m/s²이며, 정확한 \(2t + 2 = 6\)과 같다. 처음 질문의 첫째 답이 이것이다.

5.1.3잡음과 미분

측정값에 \(\pm\delta\)의 잡음이 있으면 차분은 잡음을 \(\delta/h\) 크기로 키운다. 즉 간격을 줄일수록 잡음이 커진다. 반대로 적분은 이웃 값들을 더하므로 잡음을 평균해 줄인다. 처음 질문의 둘째 답이 이것이다.

그래서 위치 기록에서 가속도를 구할 때는 먼저 회귀나 필터로 매끈하게 맞춘 뒤 미분하거나, 아예 가속도계로 직접 잰다. 차분을 두 번 하면 잡음이 한 번 더 \(1/h\)배로 불어나기 때문이다.

흔한 실수Simpson 1/3 공식을 구간 수와 상관없이 쓰는 실수가 흔하다. 이 공식은 두 구간씩 묶어 포물선을 맞추므로 구간 수가 짝수여야 하며, 홀수면 마지막 세 구간에 Simpson 3/8 공식을 쓴다. 또 간격이 고르지 않은 자료에는 등간격 공식을 쓸 수 없으므로, 구간별 사다리꼴이나 스플라인 적분을 쓴다.
마무리

중심 차분은 \(O(h^2)\)이라 전진·후진 차분의 \(O(h)\)보다 정확하다. 사다리꼴은 \(O(h^2)\), Simpson은 \(O(h^4)\)이며 Simpson은 3차까지 정확하다. 미분은 잡음을 키우고 적분은 잡음을 줄인다.

5.1.4연습문제

기본

  1. 예제 자료로 \(t = 0\)의 가속도를 전진 차분으로 구하면? 참값과 비교하여라.
    답

    \((3 - 0)/1 = 3\)이고 참값은 2이다. \(O(h)\)라 오차가 크다.

응용

  1. \(\int_0^\pi\sin x\,dx = 2\)를 4구간 사다리꼴과 Simpson으로 계산하여라.
    답

    \(h = \pi/4\)이고 함숫값은 0, 0.7071, 1, 0.7071, 0이다. 사다리꼴은 \(0.7854\times2.4142 = 1.896\)(5.2% 오차), Simpson은 \(0.2618\times(4\times0.7071 + 2 + 4\times0.7071) = 2.0046\)(0.23% 오차)이다.

심화

  1. 위치를 0.01 s마다 ±1 mm 잡음으로 잰다. 중심 차분 속도의 잡음 크기와, 그 속도를 다시 차분한 가속도의 잡음 크기를 어림하여라.
    답

    속도 잡음 \(\approx\sqrt2\times1/(2\times0.01) = 71\) mm/s. 가속도(\(f_{i+1} - 2f_i + f_{i-1}\)) 잡음 \(\approx\sqrt6\times1/0.01^2 = 2.4\times10^4\) mm/s² = 24 m/s², 쓸 수 없을 만큼 크다.
