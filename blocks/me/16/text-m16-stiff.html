뻣뻣한 방정식과 음적 Euler 방법

본문
이 절에서 배울 것
  • 시간 규모가 매우 다른 과정이 섞인 뻣뻣한 방정식을 판별한다.
  • 양적 방법의 안정 한계와 음적 Euler 방법의 무조건 안정성을 비교한다.
  • 음적 방법의 한 걸음을 연립방정식으로 푼다.
먼저 알아야 할 것
  • Euler와 RK4 (6.1절), 양적·음적 열전도 (7.2절).

6.3.1뻣뻣함

\(\dot y = -\lambda y\)를 양적 Euler로 풀면 \(y_{n+1} = (1 - \lambda h)y_n\)이라 \(h < 2/\lambda\)여야 안정합니다. 계에 아주 빠르게 사라지는 과정(큰 \(\lambda\))과 느리게 변하는 관심 과정이 함께 있으면, 이미 사라진 빠른 과정이 간격을 지배해 엄청나게 많은 걸음이 필요합니다. 이런 계를 뻣뻣하다고 합니다. 예: 매우 단단한 스프링이 낀 다자유도 계, 화학 반응 속도, 작은 시정수 회로.

6.3.2음적 Euler

음적(후진) Euler 방법

\[ y_{n+1} = y_n + hf(t_{n+1}, y_{n+1}) \]

\(\dot y = -\lambda y\)이면 \(y_{n+1} = y_n/(1 + \lambda h)\): 어떤 \(h\)에서도 크기가 줄어 안정. 대신 매 걸음 \(y_{n+1}\)에 대한 방정식(연립이면 연립방정식, 비선형이면 Newton)을 푼다.

예제 6.3.1 (\(\lambda\) = 50)

\(\dot y = -50y\), \(y(0) = 1\)을 \(h = 0.05\)로 4걸음(\(t = 0.2\)) 양적·음적 Euler로 풀어라. 참값 \(e^{-10} = 4.5\times10^{-5}\).

풀이. 양적: 배율 \(1 - 2.5 = -1.5\), 4걸음 뒤 \(1.5^4 = 5.06\)으로 진동하며 커집니다(발산). 음적: 배율 \(1/3.5 = 0.286\), 4걸음 뒤 0.0067로 0에 다가갑니다. 정확도는 거칠지만(빠른 과정은 어차피 금방 사라짐) 안정해서, 느린 과정에 맞춘 큰 간격을 쓸 수 있습니다.

주의음적 Euler는 1차라 정확도가 낮고 진동을 지나치게 감쇠시킵니다. 실무에서는 2차 음적 방법(사다리꼴, BDF2)이나 구조 동역학의 Newmark 방법, 계산 프로그램의 뻣뻣한 문제 전용 풀이기(ode15s 등)를 씁니다.
요약
  1. 뻣뻣함: 빠른 과정이 양적 방법의 간격을 제한.
  2. 음적 Euler: \(y_{n+1} = y_n + hf(y_{n+1})\), 무조건 안정.
  3. 매 걸음 방정식 풀이 필요, 정확도는 따로 확인.

6.3.3연습문제

기본

  1. \(\lambda\) = 1000인 과정을 양적 Euler로 풀 때 최대 간격은?
    답

    \(h < 0.002\).

응용

  1. \(\dot y = -2y + 1\)을 음적 Euler(\(h = 0.5\))로 한 걸음 풀어라(\(y_0 = 0\)).
    답

    \(y_1 = 0 + 0.5(-2y_1 + 1)\), \(2y_1 = 0.5\), \(y_1 = 0.25\). 참값 \(0.5(1 - e^{-1}) = 0.316\).

심화

  1. 고유진동수가 1 Hz와 1000 Hz인 두 모드가 있는 구조의 10초 응답을 구한다. 양적 방법과 음적 방법의 걸음 수를 대략 비교하여라. (양적은 빠른 모드 주기의 1/π 이하, 음적은 느린 모드 주기의 1/20 간격)
    답

    양적: 간격 약 0.3 ms, 약 3만 걸음. 음적: 간격 50 ms, 200걸음. 걸음당 연립방정식을 풀어도 음적이 훨씬 싸다(빠른 모드 응답은 부정확해지지만 관심 대상이 아니라면 괜찮다).
