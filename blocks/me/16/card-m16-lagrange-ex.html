통나무에서 가장 강한 보 켜기

예제 · Lagrange 승수 · 단면 계수
문제 해결 전략 · 등식 제약 최적화
  1. 목적 함수 \(f\)와 제약 \(g = 0\)을 설계 변수로 쓴다.
  2. \(\mathcal L = f - \lambda g\)의 편미분을 0으로 두고 제약과 연립한다.
  3. \(\lambda\)를 지워 변수 사이의 관계를 얻은 뒤 제약에 넣는다.
  4. 경계(한 변이 0)의 값과 비교해 최댓값인지 확인한다.

문제. 지름 \(D\)인 둥근 통나무에서 직사각형 단면(폭 \(b\), 높이 \(h\)) 보를 켠다. 굽힘 강도는 단면 계수 \(Z = bh^2/6\)에 비례한다. \(Z\)를 최대로 하는 \(b\), \(h\)는?

전략

직사각형의 대각선이 지름이어야 하므로 제약은 \(b^2 + h^2 = D^2\)입니다. 상수 1/6은 최적점에 영향이 없으니 \(f = bh^2\)를 최대화합니다.

풀이

  1. \(\mathcal L = bh^2 - \lambda(b^2 + h^2 - D^2)\).
    Lagrange 함수.
  2. \(\partial/\partial b\): \(h^2 = 2\lambda b\). \(\partial/\partial h\): \(2bh = 2\lambda h\) → \(\lambda = b\).
    \(h \ne 0\)으로 나눴다.
  3. 첫 식에 넣으면 \(h^2 = 2b^2\), \(h = \sqrt2\,b\).
    높이가 폭의 √2배.
  4. 제약 \(b^2 + 2b^2 = D^2\): \(b = D/\sqrt3 = 0.577D\), \(h = \sqrt{2/3}D = 0.816D\), \(Z = 0.0642D^3\).
    경계(\(b = 0\) 또는 \(h = 0\))에서는 \(Z = 0\)이므로 최대.

검산

같은 통나무에서 정사각형(\(b = h = D/\sqrt2\))을 켜면 \(Z = 0.0589D^3\)으로 최적보다 8% 작습니다. 높이를 키우는 쪽이 유리하다는 직관과 맞습니다.

의미

목재 제재의 오래된 규칙(높이 : 폭 ≈ 7 : 5)이 이 결과입니다. 강성(\(I = bh^3/12\))을 최대로 하려면 \(h = \sqrt3\,b\)로 더 높고 좁아집니다. 목적 함수에 따라 최적 형상이 달라집니다.

바꿔 보기

강성 \(bh^3\)을 최대로 하면 \(\partial/\partial b\): \(h^3 = 2\lambda b\), \(\partial/\partial h\): \(3bh^2 = 2\lambda h\)에서 \(h^2 = 3b^2\), \(b = D/2\), \(h = 0.866D\)입니다.

이해 확인

지름 30 cm 통나무에서 최대 강도 보의 폭과 높이는?

답

폭 17.3 cm, 높이 24.5 cm.
