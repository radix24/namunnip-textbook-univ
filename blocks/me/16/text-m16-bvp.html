경계값 문제: 사격법과 유한차분법

본문
이 절에서 배울 것
  • 조건이 한쪽 끝이 아니라 양 끝에 주어진 경계값 문제의 특징을 안다.
  • 모르는 처음 기울기를 근 찾기로 맞추는 사격법을 쓴다.
  • 미분을 차분으로 바꿔 연립방정식으로 푸는 유한차분법을 쓴다.
먼저 알아야 할 것
  • RK4 (6.1절), 근 찾기 (2.1절), 연립방정식 (3.1절), 핀 방정식 (열전달 3.1절).

6.2.1경계값 문제

핀의 온도 \(\theta'' = m^2\theta\)는 밑동 온도 \(\theta(0)\)와 끝 조건(단열이면 \(\theta'(L) = 0\))이 양 끝에 주어집니다. 보의 처짐, 축의 비틀림도 그렇습니다. 처음 값 문제처럼 한쪽에서 출발하려면 처음 기울기 \(\theta'(0)\)를 모르는 것이 문제입니다.

6.2.2사격법

처음 기울기 \(s\)를 가정해 RK4로 끝까지 풀고, 끝 조건이 얼마나 어긋났는지(\(\theta'(L) - 0\))를 \(s\)의 함수로 보아 근 찾기(할선법)로 맞춥니다. 대포를 쏘아 보고 각도를 고쳐 가는 것과 같아 사격법이라 합니다. 선형 방정식이면 두 번 쏘고 선형 보간 한 번으로 정답이 나옵니다.

6.2.3유한차분법

구간을 \(N\)등분하고 절점마다 \(\theta'' \approx (\theta_{i-1} - 2\theta_i + \theta_{i+1})/\Delta x^2\)을 넣으면 \(\theta_{i-1} - (2 + m^2\Delta x^2)\theta_i + \theta_{i+1} = 0\)인 삼중 대각 연립방정식이 됩니다. 단열 끝은 거울 대칭 가상 절점(\(\theta_{N+1} = \theta_{N-1}\))으로 처리합니다.

예제 6.2.1 (핀 온도, 4구간)

열전달 3.1절 핀(\(m = 10\) 1/m, \(L = 50\) mm, 밑동 온도 차 75 K, 끝 단열)을 유한차분 4구간으로 풀고 끝 온도 차를 정확한 해와 비교하여라. 사격법이라면 처음 기울기는 얼마가 되어야 하는가?

풀이. \(\Delta x = 12.5\) mm, \(2 + (m\Delta x)^2 = 2.0156\). 네 식을 풀면 \(\theta_1 = 71.25\), \(\theta_2 = 68.61\), \(\theta_3 = 67.04\), \(\theta_4 = 66.52\) K. 정확한 끝 값 \(75/\cosh0.5 = 66.51\) K와 0.02% 차이입니다. 사격법은 정확한 처음 기울기 \(\theta'(0) = -75m\tanh(mL) = -347\) K/m를 찾아냅니다(선형이라 두 번 쏘면 정확히).

주의(1) 비선형 경계값 문제(복사 핀 등)는 사격법에 반복이 필요하고, 유한차분법은 비선형 연립방정식(Newton 반복)이 됩니다. (2) 해가 빠르게 커지는 문제는 사격법이 민감하므로 유한차분법이 안정적입니다.
요약
  1. 경계값 문제: 조건이 양 끝에.
  2. 사격법: 처음 기울기를 근 찾기로 맞춤.
  3. 유한차분: 삼중 대각 연립방정식, 미분 경계는 가상 절점.

6.2.4연습문제

기본

  1. \(y'' = 0\), \(y(0) = 1\), \(y(1) = 3\)을 사격법으로 풀 때 처음 기울기는?
    답

    해가 직선 \(y = 1 + sx\)이므로 \(s = 2\).

응용

  1. 예제를 2구간으로 풀면 끝 온도는?
    답

    \(\Delta x = 25\) mm, \(a = 2.0625\). \(75 - a\theta_1 + \theta_2 = 0\), \(2\theta_1 - a\theta_2 = 0\) → \(\theta_2 = 2\theta_1/a\), \(\theta_1(a - 2/a) = 75\), \(\theta_1 = 75/(2.0625 - 0.9697) = 68.6\), \(\theta_2 = 66.55\) K. 정확한 값 66.51 K와 0.06% 차이로, 2구간으로도 충분히 정확하다.

심화

  1. 예제를 사격법으로 풀 때 \(s_1 = -300\), \(s_2 = -400\)으로 쏘아 끝 기울기가 각각 \(+52.5\)와 \(-60.2\) K/m가 나왔다. 할선법으로 다음 \(s\)는?
    답

    \(s = -300 - 52.5\times(-100)/(-60.2 - 52.5) = -346.6\). 끝 기울기가 \(s\)에 대해 선형이므로 이것이 바로 정확한 값 \(-75m\tanh(mL) = -346.6\)이다.
