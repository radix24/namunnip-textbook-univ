2차원 열전도의 유한차분 풀이

본문
이 절에서 배울 것
  • 편미분방정식(열전도 방정식)의 뜻과 편미분 기호를 읽는다.
  • 격자와 5점 공식으로 정상 2차원 열전도를 연립방정식으로 바꾼다.
  • Gauss-Seidel 반복으로 판의 온도 분포를 구한다.
먼저 알아야 할 것
  • 2차 중심 차분 (5.1절), Gauss-Seidel (3.1절), 열전도 유한차분 (열전달 3.2절).

7.1.1편미분방정식

판의 온도 \(T(x, y)\)처럼 변수가 둘 이상인 함수에서, 다른 변수는 고정하고 한 변수로만 미분한 것을 편미분이라 하고 \(\partial T/\partial x\)로 씁니다. 내부 발열이 없는 정상 2차원 열전도는

\[ \frac{\partial^2T}{\partial x^2} + \frac{\partial^2T}{\partial y^2} = 0 \]

(Laplace 방정식)입니다. \(x\) 방향 곡률과 \(y\) 방향 곡률이 서로 상쇄된다는 뜻으로, 들어오는 열과 나가는 열이 균형을 이룬 상태입니다.

7.1.25점 공식

간격 \(h\)의 정사각 격자를 깔고 두 2차 편미분을 각각 중심 차분으로 바꾸면

5점 공식 (정상, 발열 없음)

\[ T_{i,j} = \frac{T_{i+1,j} + T_{i-1,j} + T_{i,j+1} + T_{i,j-1}}{4} \]

내부 절점의 온도는 동서남북 네 이웃의 평균.

내부 절점마다 식이 하나씩 생겨 연립방정식이 됩니다. 절점이 수천 개여도 각 식에 미지수가 다섯 개뿐(성긴 행렬)이라, 네 이웃의 평균으로 계속 덮어쓰는 Gauss-Seidel 반복이 간단하고 잘 수렴합니다. 단열 경계는 6.2절처럼 거울 대칭 가상 절점으로 처리합니다.

예제 7.1.1 (윗변만 뜨거운 정사각 판)

정사각 판의 윗변이 100 °C, 나머지 세 변이 0 °C이다. 각 변을 3등분해 내부 절점 네 개(위 두 개, 아래 두 개)로 풀어라.

풀이. 좌우 대칭이라 위 두 절점은 \(T_1\), 아래 두 절점은 \(T_3\)로 같습니다. 위 절점: \(4T_1 = 100 + T_1 + T_3 + 0\), 아래 절점: \(4T_3 = T_1 + T_3 + 0 + 0\). 둘째에서 \(T_1 = 3T_3\), 첫째에 넣으면 \(8T_3 = 100\), \(T_3 = 12.5\), \(T_1 = 37.5\) °C. 네 절점 평균은 25 °C인데, 네 변을 차례로 100 °C로 한 네 문제를 겹치면 전체가 100 °C가 되므로 대칭상 판 중심의 정확한 값도 25 °C입니다.

7.1.3비정상 문제

시간에 따라 변하는 경우는 \(\partial T/\partial t = \alpha(\partial^2T/\partial x^2 + \partial^2T/\partial y^2)\)이고, 양적 방법은 \(T_{i,j}^{\text{new}} = T_{i,j} + r(\text{네 이웃 합} - 4T_{i,j})\), \(r = \alpha\Delta t/h^2\)입니다. 2차원에서는 \(r \le 1/4\)이어야 안정합니다(다음 절).

주의(1) 모서리처럼 경계 온도가 갑자기 바뀌는 곳은 해가 매끈하지 않아 격자를 촘촘히 해야 합니다. (2) 격자를 반으로 줄여 결과가 수렴하는지 확인하는 습관은 컴퓨터 해석(기계22)에서도 그대로 쓰입니다.
요약
  1. 정상 2차원 열전도: \(\partial^2T/\partial x^2 + \partial^2T/\partial y^2 = 0\).
  2. 5점 공식: 내부 절점 = 네 이웃의 평균.
  3. 성긴 연립방정식은 Gauss-Seidel 반복, 격자 수렴 확인.

7.1.4연습문제

기본

  1. 내부 절점의 네 이웃이 20, 40, 60, 80 °C이면 정상 상태 그 절점의 온도는?
    답

    평균 50 °C.

응용

  1. 예제를 Gauss-Seidel로 처음값 0에서 시작해 한 번 돌리면(위 절점 먼저, 대칭 이용)?
    답

    \(T_1 = (100 + T_1 + T_3)/4\)에 옛 값 0을 넣으면 25, \(T_3 = (25 + 0)/4 = 6.25\). 반복할수록 37.5와 12.5로 다가간다.

심화

  1. 격자 간격을 반으로 하면 2차원 내부 절점 수와 양적 방법의 안정 시간 간격은 각각 몇 배가 되는가?
    답

    절점 약 4배, 시간 간격 \(1/4\)배(\(r = \alpha\Delta t/h^2\) 고정). 같은 시간까지 계산량은 약 16배이다.
