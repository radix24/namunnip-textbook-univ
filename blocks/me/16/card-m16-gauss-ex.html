3점 Gauss로 사인 함수 적분

예제 · 구간 변환 · Simpson과 비교
문제 해결 전략 · Gauss 구적
  1. 적분 구간 \([a, b]\)를 \(t \in [-1, 1]\)로 바꾼다: \(x = \frac{a + b}2 + \frac{b - a}2t\).
  2. 표의 점 \(t_i\)에서 \(f(x(t_i))\)를 계산해 가중치를 곱해 더한다.
  3. 마지막에 \(\frac{b - a}2\)를 곱한다.

문제. \(\int_0^\pi\sin x\,dx = 2\)를 3점 Gauss 공식으로 계산하고, 함수 계산 수가 같은 Simpson 2구간과 비교하라.

전략

\(a = 0\), \(b = \pi\)이므로 \(x = \frac\pi2(1 + t)\), 배율 \(\frac\pi2\). 3점 공식의 점은 \(t = 0, \pm\sqrt{0.6}\), 가중치 8/9, 5/9, 5/9이다.

풀이

  1. \(t = 0\): \(x = \pi/2\), \(\sin = 1\).
    가운데 점.
  2. \(t = \pm0.7746\): \(x = 0.3540, 2.7876\), \(\sin = 0.3467\)(둘 다).
    대칭이라 값이 같다.
  3. 합: \(\frac89\times1 + \frac59\times0.3467\times2 = 0.8889 + 0.3852 = 1.2741\).
    가중합.
  4. \(\frac\pi2\times1.2741 = 2.0014\), 오차 0.07%.
    배율을 곱한다.

검산

Simpson 2구간(점 0, π/2, π): \(\frac{\pi/2}3(0 + 4 + 0) = 2.0944\), 오차 4.7%. 같은 3번 계산으로 Gauss가 약 70배 정확하다.

의미

함수값을 아무 곳에서나 얻을 수 있으면 점을 잘 고르는 것이 계산 수를 늘리는 것보다 훨씬 효과적이다. FEM 프로그램이 요소마다 Gauss 점에서만 응력과 변형률을 계산하는 이유이다.

바꿔 보기

2점 Gauss(\(t = \pm1/\sqrt3\))로 하면 \(\frac\pi2\times2\sin(0.6638) = 1.936\), 오차 3.2%로 Simpson 3점보다 좋고 3점 Gauss보다 나쁘다.

이해 확인

3점 Gauss는 몇 차 다항식까지 정확한가? \(\int_0^1x^5dx\)는 정확히 나오는가?

답

5차까지. 1/6이 정확히 나온다.
