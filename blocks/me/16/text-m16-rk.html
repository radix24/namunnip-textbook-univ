Runge-Kutta 방법으로 진동계 풀기

본문
이 절에서 배울 것
  • 2계 운동 방정식을 1계 연립방정식(상태 변수)으로 바꾼다.
  • Euler 방법과 4차 Runge-Kutta(RK4)의 계산 절차와 정확도 차수를 안다.

먼저 알아야 할 것
  • 질량-스프링-감쇠기와 자유 진동 (기계진동 2.1절), 상태방정식 (기계시스템제어 6.1절).

6.1.11계 연립으로 바꾸기

\(m\ddot x + c\dot x + kx = F(t)\)는 \(y_1 = x\), \(y_2 = \dot x\)로 두면 \(\dot y_1 = y_2\), \(\dot y_2 = (F - cy_2 - ky_1)/m\)입니다. 모든 상미분방정식 풀이법은 이렇게 \(\dot y = f(t, y)\) 꼴을 다룹니다.

6.1.2Euler와 RK4

시간 전진 방법 (간격 \(h\))

Euler: \(y_{n+1} = y_n + hf(t_n, y_n)\). 지금 기울기로 직선으로 나아감. 전역 오차 \(O(h)\).

RK4: \(k_1 = f(t_n, y_n)\), \(k_2 = f(t_n + \tfrac h2, y_n + \tfrac h2k_1)\), \(k_3 = f(t_n + \tfrac h2, y_n + \tfrac h2k_2)\), \(k_4 = f(t_n + h, y_n + hk_3)\), \(y_{n+1} = y_n + \tfrac h6(k_1 + 2k_2 + 2k_3 + k_4)\). 구간 안 네 기울기의 가중 평균. 전역 오차 \(O(h^4)\).

예제 6.1.1 (감쇠 없는 진동자)

\(\ddot x + x = 0\)(\(\omega_n = 1\)), \(x(0) = 1\), \(\dot x(0) = 0\)을 다섯 주기(\(t = 10\pi\)) 동안 풀었다. 에너지 \(x^2 + \dot x^2\)(참값 1을 유지)는 Euler와 RK4에서 각각 어떻게 되는가? (\(h = 0.1\), 0.01)

풀이. Euler는 매 걸음 에너지가 \(1 + h^2\)배씩 늘어 \(h = 0.1\)이면 다섯 주기에 22.7배(진폭 4.8배)로 터지고, \(h = 0.01\)도 1.37배입니다. RK4는 \(h = 0.1\)에서 0.999996으로 거의 정확합니다. 계산량은 RK4가 걸음마다 4배지만, 같은 정확도를 훨씬 큰 간격으로 얻습니다(RK4 실습).

6.1.3간격과 안정성

간격은 가장 빠른 운동의 주기보다 충분히 작아야 합니다(진동 주기의 1/20 이하가 대략의 기준). 진동자에서 RK4는 \(\omega h < 2.83\)이면 안정하지만 그 위로는 발산합니다. 다자유도 계는 가장 높은 고유진동수가 간격을 정하므로, 아주 빠른 모드가 섞인 "뻣뻣한" 계는 음적 방법이 필요합니다.

주의(1) 간격을 반으로 해서 결과가 거의 같은지 확인합니다. 계산 프로그램의 ode45는 이 비교로 간격을 자동 조절합니다. (2) 에너지 보존이 중요한 장시간 계산(궤도, 분자 동역학)은 심플렉틱 방법을 씁니다.
요약
  1. 2계 → 1계 연립(위치, 속도).
  2. Euler \(O(h)\), 진동자에서 에너지가 불어남. RK4 \(O(h^4)\).
  3. 간격은 가장 빠른 주기의 1/20 이하, 반으로 줄여 확인.

6.1.4연습문제

기본

  1. \(\dot y = -2y\), \(y(0) = 1\)을 Euler \(h = 0.1\)로 두 걸음 가면? 참값과 비교하여라.
    답

    \(y_1 = 0.8\), \(y_2 = 0.64\). 참값 \(e^{-0.4} = 0.670\), 4.5% 작다.

응용

  1. 1번을 \(h = 1.5\)로 Euler 계산하면? 이유는?
    답

    \(y_{n+1} = (1 - 3)y_n = -2y_n\): 1, −2, 4, −8로 발산. Euler는 \(|1 - 2h| < 1\), 곧 \(h < 1\)이어야 안정하다.

심화

  1. RK4의 오차가 \(h^4\)에 비례하면, 간격을 반으로 할 때 오차는 몇 분의 1이 되는가? 계산 시간은?
    답

    오차 16분의 1, 계산 시간 2배. Euler는 오차 2분의 1에 시간 2배라 정확도가 필요하면 RK4가 훨씬 유리하다.
