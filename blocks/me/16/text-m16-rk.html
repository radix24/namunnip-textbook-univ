Runge-Kutta 방법으로 진동계 풀기

본문

감쇠 없는 진동자는 영원히 같은 진폭으로 흔들려야 한다. 그런데 이 운동 방정식을 가장 단순한 방법으로 시간 전진했더니 진폭이 다섯 주기 만에 다섯 배 가까이 불어났다. 무엇이 잘못된 것일까? 같은 계산을 더 정확하게 하려면 어떤 방법을 쓰고, 시간 간격은 얼마로 잡아야 할까?

먼저 알아야 할 것질량-스프링-감쇠기와 자유 진동(기계진동 2.1절), 상태방정식(기계시스템제어 6.1절)을 쓴다.

6.1.11계 연립으로 바꾸기

\(m\ddot x + c\dot x + kx = F(t)\)는 \(y_1 = x\), \(y_2 = \dot x\)로 두면 \(\dot y_1 = y_2\), \(\dot y_2 = (F - cy_2 - ky_1)/m\)이 된다. 모든 상미분방정식 풀이법은 이렇게 바꾼 \(\dot y = f(t, y)\) 꼴을 다룬다.

6.1.2Euler와 RK4

시간 전진 방법 (간격 \(h\))

Euler 방법은 \(y_{n+1} = y_n + hf(t_n, y_n)\)으로, 지금 기울기로 직선을 따라 나아간다. 전역 오차는 \(O(h)\)이다.

RK4는 \(k_1 = f(t_n, y_n)\), \(k_2 = f(t_n + \tfrac h2, y_n + \tfrac h2k_1)\), \(k_3 = f(t_n + \tfrac h2, y_n + \tfrac h2k_2)\), \(k_4 = f(t_n + h, y_n + hk_3)\)을 구한 뒤 \(y_{n+1} = y_n + \tfrac h6(k_1 + 2k_2 + 2k_3 + k_4)\)로 둔다. 구간 안 네 기울기의 가중 평균이며, 전역 오차는 \(O(h^4)\)이다.

예제 6.1.1 (감쇠 없는 진동자)

\(\ddot x + x = 0\)(\(\omega_n = 1\)), \(x(0) = 1\), \(\dot x(0) = 0\)을 다섯 주기(\(t = 10\pi\)) 동안 풀었다. 에너지 \(x^2 + \dot x^2\)(참값 1을 유지)는 Euler와 RK4에서 각각 어떻게 되는가? (\(h = 0.1\), 0.01)

풀이. Euler는 매 걸음 에너지가 \(1 + h^2\)배씩 늘어, \(h = 0.1\)이면 다섯 주기에 22.7배(진폭 4.8배)로 터지고 \(h = 0.01\)도 1.37배가 된다. 반면 RK4는 \(h = 0.1\)에서 0.999996으로 거의 정확하다(그림 1). 처음 질문의 첫째 답이 이것이다.

즉 RK4는 걸음마다 계산량이 Euler의 4배이지만, 같은 정확도를 훨씬 큰 간격으로 얻으므로 전체 계산은 오히려 적다(RK4 실습).

6.1.3간격과 안정성

간격은 가장 빠른 운동의 주기보다 충분히 작아야 하며, 진동 주기의 1/20 이하가 대략의 기준이다. 처음 질문의 둘째 답이 이것이다. 또 진동자에서 RK4는 \(\omega h < 2.83\)이면 안정하지만 그 위로는 발산한다.

그런데 다자유도 계는 가장 높은 고유진동수가 간격을 정한다. 그래서 아주 빠른 모드가 섞인 뻣뻣한 계는 양적 방법으로는 걸음이 지나치게 많아지므로, 음적 방법이 필요하다(6.3절).

흔한 실수한 가지 간격으로만 계산하고 결과를 믿는 실수가 흔하다. 간격을 반으로 해서 결과가 거의 같은지 확인해야 하며, 계산 프로그램의 ode45는 이런 비교로 간격을 스스로 조절한다(6.4절). 또 궤도나 분자 동역학처럼 에너지 보존이 중요한 장시간 계산에는 RK4로도 에너지가 조금씩 새므로, 심플렉틱 방법을 쓴다.
마무리

2계 운동 방정식은 위치와 속도의 1계 연립으로 바꾼다. Euler는 \(O(h)\)이며 진동자에서 에너지가 불어나고, RK4는 \(O(h^4)\)이다. 간격은 가장 빠른 주기의 1/20 이하로 잡고, 반으로 줄여 확인한다.

6.1.4연습문제

기본

  1. \(\dot y = -2y\), \(y(0) = 1\)을 Euler \(h = 0.1\)로 두 걸음 가면? 참값과 비교하여라.
    답

    \(y_1 = 0.8\), \(y_2 = 0.64\). 참값 \(e^{-0.4} = 0.670\), 4.5% 작다.

응용

  1. 1번을 \(h = 1.5\)로 Euler 계산하면? 이유는?
    답

    \(y_{n+1} = (1 - 3)y_n = -2y_n\): 1, −2, 4, −8로 발산. Euler는 \(|1 - 2h| < 1\), 곧 \(h < 1\)이어야 안정하다.

심화

  1. RK4의 오차가 \(h^4\)에 비례하면, 간격을 반으로 할 때 오차는 몇 분의 1이 되는가? 계산 시간은?
    답

    오차 16분의 1, 계산 시간 2배. Euler는 오차 2분의 1에 시간 2배라 정확도가 필요하면 RK4가 훨씬 유리하다.
