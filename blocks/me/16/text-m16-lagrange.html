Lagrange 승수와 제약 최적화

본문
이 절에서 배울 것
  • 등식 제약이 있는 최적화 문제를 세운다.
  • Lagrange 함수의 기울기를 0으로 두어 최적점을 구한다.
  • 승수의 뜻(제약을 조금 풀 때 목적 함수의 변화율)을 해석한다.
먼저 알아야 할 것
  • 경사법과 다차원 최적화 (4.1절), 편미분.

4.3.1제약이 있는 최적화

설계에는 거의 늘 조건이 붙습니다: 부피는 1 L, 길이는 정해져 있음. 제약 \(g(\vec x) = 0\)을 만족하면서 \(f(\vec x)\)를 최소화하는 점에서는 \(f\)의 등고선이 제약 곡선에 접하므로, 두 함수의 기울기가 나란합니다: \(\nabla f = \lambda\nabla g\).

Lagrange 승수법

\(\mathcal L(\vec x, \lambda) = f(\vec x) - \lambda g(\vec x)\)로 두고 \(\partial\mathcal L/\partial x_i = 0\), \(g(\vec x) = 0\)을 연립해 푼다.

\(\lambda\)는 제약을 한 단위 풀 때 최적 목적 함수 값이 바뀌는 비율(그림자 가격)이다.

예제 4.3.1 (1 L 캔)

부피 1000 cm³인 원통 캔의 겉넓이(재료)를 최소로 하는 반지름과 높이는?

풀이. \(f = 2\pi r^2 + 2\pi rh\), \(g = \pi r^2h - 1000\). \(\partial/\partial r\): \(4\pi r + 2\pi h = \lambda2\pi rh\), \(\partial/\partial h\): \(2\pi r = \lambda\pi r^2\)에서 \(\lambda = 2/r\). 첫 식에 넣으면 \(4\pi r + 2\pi h = 4\pi h\), 곧 \(h = 2r\). 부피에서 \(r = (1000/2\pi)^{1/3} = 5.42\) cm, \(h = 10.84\) cm, 겉넓이 554 cm². 높이가 지름과 같은 캔이 가장 적은 재료를 씁니다.

4.3.2수치적으로 풀기

손으로 풀기 어려우면 연립 비선형방정식으로 보고 Newton 방법(2.2절)으로 풀거나, 제약을 어길수록 큰 값을 더하는 벌칙 함수 \(f + \mu g^2\)를 경사법으로 최소화합니다. 부등식 제약(응력 ≤ 허용값)은 KKT 조건이나 계산 프로그램의 최적화 함수로 다룹니다.

주의기울기가 0인 점은 최솟값이 아니라 최댓값이나 안장점일 수도 있습니다. 이웃 점에서 값을 비교하거나 이계 조건으로 확인합니다.
요약
  1. 최적점에서 \(\nabla f = \lambda\nabla g\).
  2. \(\partial\mathcal L = 0\)과 제약을 연립.
  3. \(\lambda\) = 제약의 그림자 가격. 수치로는 Newton, 벌칙 함수.

4.3.3연습문제

기본

  1. 둘레 4 m인 직사각형의 넓이를 최대로 하는 변의 길이는?
    답

    \(\nabla(xy) = \lambda\nabla(2x + 2y)\)에서 \(y = 2\lambda\), \(x = 2\lambda\), 정사각형 1 m × 1 m.

응용

  1. 예제에서 뚜껑 재료가 옆면보다 두 배 비싸면(뚜껑 위아래 모두) 최적 \(h/r\)은?
    답

    \(f = 4\pi r^2 + 2\pi rh\). 같은 과정으로 \(h = 4r\). 비싼 뚜껑을 작게 하려고 더 길쭉해진다.

심화

  1. 예제의 \(\lambda = 2/r = 0.369\) cm⁻¹의 뜻을 부피를 1001 cm³로 늘릴 때로 설명하여라.
    답

    부피를 1 cm³ 늘리면 최소 겉넓이가 약 0.369 cm² 늘어난다(\(d f_{\min}/dV = \lambda\)). 용량 변경의 재료 비용을 바로 어림할 수 있다.
