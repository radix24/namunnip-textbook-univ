텅스텐의 회절 봉우리 예측

예제 · 허용 반사 · Bragg 법칙
문제 해결 전략 · 회절 봉우리
  1. 결정 구조(BCC/FCC)로 나타나는 면을 고른다.
  2. \(h^2 + k^2 + l^2\)가 작은 순서로 \(d = a/\sqrt{h^2 + k^2 + l^2}\)를 계산한다.
  3. \(\theta = \sin^{-1}(\lambda/2d)\), 봉우리 위치 \(2\theta\).

문제. BCC 텅스텐(\(a\) = 0.3165 nm)을 Cu Kα(\(\lambda\) = 0.1542 nm)로 잴 때 처음 세 회절선의 \(2\theta\)를 구하라.

전략

BCC는 \(h + k + l\)이 짝수인 면만: (110), (200), (211) 순서입니다(\(h^2 + k^2 + l^2\) = 2, 4, 6).

풀이

  1. (110): \(d = 0.3165/\sqrt2 = 0.2238\) nm, \(\sin\theta = 0.3445\), \(2\theta = 40.3°\).
    첫 허용면.
  2. (200): \(d = 0.1583\) nm, \(2\theta = 58.3°\).
    \(\sqrt4 = 2\).
  3. (211): \(d = 0.1292\) nm, \(2\theta = 73.3°\).
    \(\sqrt6\).

검산

\(\sin^2\theta\)의 비가 2 : 4 : 6 = 1 : 2 : 3이어야 한다: \(\sin^2(20.15°) = 0.1187\), \(\sin^2(29.16°) = 0.2374\), \(\sin^2(36.63°) = 0.356\) → 1 : 2.00 : 3.00 ✓.

의미

측정 봉우리의 \(\sin^2\theta\) 비가 1 : 2 : 3이면 BCC, 3 : 4 : 8이면 FCC이다. 봉우리 위치가 표준값보다 조금 옮겨 있으면 격자가 늘거나 줄어든 것이므로 잔류 응력이나 합금 원소 고용량을 알 수 있다.

바꿔 보기

텅스텐 시편 표면이 압축 잔류 응력으로 (211) 간격이 0.1% 줄었다면 \(2\theta\)는 약 0.08° 커진다. 잔류 응력 측정은 이런 작은 이동을 잰다.

이해 확인

(100)면 봉우리가 BCC에서 나타나지 않는 이유는?

답

격자 중심 원자가 만드는 (100)면 사이의 중간면이 반대 위상으로 산란해 상쇄되기 때문이다(\(h + k + l\) 홀수 소멸).
