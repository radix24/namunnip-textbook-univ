시험 결과에서 Weibull 계수 구하기

예제 · 이중 로그 · 특성 강도
문제 해결 전략 · Weibull 맞춤
  1. \(\ln[-\ln(1 - P_f)] = m\ln\sigma - m\ln\sigma_0\): 이중 로그를 \(\ln\sigma\)에 대해 그리면 직선, 기울기가 \(m\).
  2. 두 점(또는 여러 점의 최소제곱)으로 \(m\)과 \(\sigma_0\)를 구한다.
  3. 원하는 파괴 확률의 응력을 계산한다.

문제. 질화규소 시편을 여러 개 시험해 순위를 매겼더니 250 MPa에서 20%, 320 MPa에서 80%가 깨졌다. Weibull 계수 \(m\)과 특성 강도 \(\sigma_0\)는? 파괴 확률 0.1%의 응력은?

전략

두 점의 이중 로그 값을 계산해 직선 기울기를 구합니다.

풀이

  1. \(P_f\) = 0.2: \(\ln[-\ln0.8] = \ln0.2231 = -1.500\). \(P_f\) = 0.8: \(\ln[-\ln0.2] = \ln1.609 = 0.476\).
    이중 로그.
  2. \(m = (0.476 + 1.500)/(\ln320 - \ln250) = 1.976/0.2469 = 8.0\).
    직선 기울기.
  3. \(\sigma_0 = 250/0.2231^{1/8} = 250/0.829 = 302\) MPa.
    \((\sigma/\sigma_0)^m = -\ln(1 - P_f)\).
  4. 0.1%: \(\sigma = 302\times(-\ln0.999)^{1/8} = 302\times0.422 = 127\) MPa.
    \((0.0010)^{0.125} = 0.422\).

검산

\(\sigma = \sigma_0 = 302\) MPa에서 \(P_f = 63\)%로, 20%(250)와 80%(320) 사이에 들어갑니다.

의미

평균 강도가 약 285 MPa여도 1000개 중 1개만 깨지게 하려면 127 MPa, 절반 이하로 써야 합니다. \(m\)이 작을수록 이 차이가 커지므로, 세라믹 제조에서는 흠을 줄여 \(m\)을 높이는 것이 강도를 높이는 것만큼 중요합니다.

바꿔 보기

같은 특성 강도에서 \(m\) = 16이면 0.1% 응력은 \(302\times0.001^{1/16} = 196\) MPa로 크게 오릅니다.

이해 확인

시편 부피의 100배인 부품에서 0.1% 파괴 응력은? (\(m\) = 8)

답

\(127\times100^{-1/8} = 127\times0.562 = 71\) MPa.
