밀러 지수와 X선 회절

본문

금속 조각 안의 원자 배열은 현미경으로도 직접 볼 수 없다. 그런데 X선을 쏘면 특정 각도에서만 강한 반사가 나오고, 그 각도로 결정 구조와 격자 상수를 알아낸다. 원자면을 어떻게 이름 붙이고, 반사 각도는 무엇으로 정해질까?

먼저 알아야 할 것결정 구조와 격자 상수(1.2절), 파동의 간섭(고등학교 물리)을 쓴다.

1.3.1밀러 지수

결정면을 나타내려면 먼저 그 면이 x, y, z축과 만나는 절편을 격자 상수 단위로 읽는다. 그다음 역수를 취해 가장 작은 정수비로 만들면 밀러 지수가 된다. 처음 질문의 첫째 답이 이것이다. 예를 들어 x축과만 1에서 만나고 다른 축과 나란한 면은 절편이 (1, ∞, ∞), 역수가 (1, 0, 0)이므로 (100)면이다. 정육면체의 대각면은 (111)이고, 방향은 대괄호 [uvw]로 쓴다.

1.3.2Bragg 법칙

파장이 원자 간격과 비슷한 X선을 결정에 쏘면, 나란한 원자면들에서 반사된 파동이 경로 차가 파장의 정수배일 때만 보강 간섭해 강한 회절선이 나온다(그림 1). 처음 질문의 둘째 답이 이것이다.

Bragg 법칙과 입방 결정의 면 간격

\[n\lambda = 2d\sin\theta\]

\[d_{hkl} = \frac a{\sqrt{h^2 + k^2 + l^2}}\]

BCC에서는 h + k + l이 짝수인 면만 나타난다(110, 200, 211 …). FCC에서는 h, k, l이 모두 홀수이거나 모두 짝수인 면만 나타난다(111, 200, 220 …).

이 규칙은 단위 격자 안의 원자들이 낸 반사가 서로 지워지기 때문에 생긴다. 예를 들어 BCC의 (100)면 사이 한가운데에는 중심 원자가 만든 면이 하나 더 있어, 그 반사가 반 파장 어긋나 (100) 반사를 지운다.

예제 1.3.1 (철의 첫 회절선)

BCC 철(\(a\) = 0.2866 nm)을 Cu Kα X선(\(\lambda\) = 0.1542 nm)으로 잴 때 첫 회절선의 \(2\theta\)는?

풀이. BCC의 첫 허용면은 (110)이므로 \(d = 0.2866/\sqrt2 = 0.2027\) nm이다. 따라서 \(\sin\theta = 0.1542/(2\times0.2027) = 0.380\), θ = 22.4°이고 2θ = 44.7°이다. 다음 회절선은 (200)으로, d = 0.1433 nm, 2θ = 65.1°이다.

즉 측정된 봉우리 위치를 이런 계산과 비교하면 어떤 상인지와 격자 상수를 알아낸다. 처음 질문의 셋째 답이 이것이다.

흔한 오해X선 회절은 결정 구조만 알려 준다고 여기기 쉽다. 실제로는 잔류 응력(격자 간격의 미세한 변화), 결정립 크기(봉우리 폭), 상의 분율(봉우리 세기)도 알려 준다. 그래서 용접부와 열처리 부품의 잔류 응력 측정에도 쓴다.
마무리

밀러 지수는 절편의 역수를 정수비로 만든 것이다. Bragg 법칙은 nλ = 2d sin θ이고, 입방 결정의 면 간격은 \(d = a/\sqrt{h^2 + k^2 + l^2}\)이다. BCC는 h + k + l이 짝수인 면, FCC는 모두 홀수이거나 모두 짝수인 면만 나타난다.

1.3.3연습문제

기본

  1. 절편이 \((1, 1, \infty)\)인 면의 밀러 지수는?
    답

    (110)이다.

응용

  1. FCC 알루미늄(\(a\) = 0.405 nm)의 첫 회절선 \(2\theta\)는? (Cu Kα)
    답

    (111)이며, \(d = 0.2338\) nm, \(2\theta = 38.5°\)이다.

심화

  1. 미지 시료의 첫 두 회절선 \(\sin^2\theta\) 비가 3 : 4였다. BCC인가 FCC인가?
    답

    \(\sin^2\theta ∝ h^2 + k^2 + l^2\). FCC의 (111), (200)은 3 : 4, BCC의 (110), (200)은 2 : 4 = 1 : 2. 따라서 FCC.
