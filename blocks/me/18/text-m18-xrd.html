밀러 지수와 X선 회절

본문
이 절에서 배울 것
  • 결정면과 방향을 밀러 지수로 쓴다.
  • 입방 결정의 면 간격 \(d_{hkl} = a/\sqrt{h^2 + k^2 + l^2}\)를 계산한다.
  • Bragg 법칙으로 X선 회절 봉우리 위치를 구하고 결정 구조를 판별한다.
먼저 알아야 할 것
  • 결정 구조와 격자 상수 (1.2절), 파동의 간섭(고등학교 물리).

1.3.1밀러 지수

결정면을 나타내려면 그 면이 \(x, y, z\)축과 만나는 절편을 격자 상수 단위로 읽고, 역수를 취해 가장 작은 정수비로 만듭니다. 예를 들어 \(x\)축만 1에서 만나고 다른 축과 나란한 면은 절편 \((1, \infty, \infty)\), 역수 \((1, 0, 0)\)이라 (100)면입니다. 정육면체의 대각면은 (111), 모서리 둘을 지나는 면은 (110)입니다. 방향은 대괄호 [uvw]로 씁니다.

1.3.2Bragg 법칙

파장이 원자 간격과 비슷한 X선을 결정에 쏘면, 나란한 원자면들에서 반사된 파동이 경로 차가 파장의 정수배일 때만 보강 간섭해 강한 회절선이 나옵니다.

Bragg 법칙과 입방 결정의 면 간격

\[n\lambda = 2d\sin\theta\]

\[d_{hkl} = \frac a{\sqrt{h^2 + k^2 + l^2}}\]

BCC: \(h + k + l\)이 짝수인 면만 나타난다(110, 200, 211 …). FCC: \(h, k, l\)이 모두 홀수이거나 모두 짝수인 면만(111, 200, 220 …).

예제 1.3.1 (철의 첫 회절선)

BCC 철(\(a\) = 0.2866 nm)을 Cu Kα X선(\(\lambda\) = 0.1542 nm)으로 잴 때 첫 회절선의 \(2\theta\)는?

풀이. BCC의 첫 허용면은 (110): \(d = 0.2866/\sqrt2 = 0.2027\) nm. \(\sin\theta = 0.1542/(2\times0.2027) = 0.380\), \(\theta = 22.4°\), \(2\theta = 44.7°\). 다음은 (200): \(d = 0.1433\), \(2\theta = 65.1°\). 측정된 봉우리 위치를 이와 비교해 상과 격자 상수를 알아냅니다.

주의X선 회절은 결정 구조뿐 아니라 잔류 응력(격자 간격 변화), 결정립 크기(봉우리 폭), 상의 분율(봉우리 세기)도 알려 줍니다. 용접부와 열처리 부품의 잔류 응력 측정에 씁니다.
요약
  1. 밀러 지수: 절편의 역수를 정수비로.
  2. \(n\lambda = 2d\sin\theta\), \(d = a/\sqrt{h^2 + k^2 + l^2}\).
  3. BCC는 \(h + k + l\) 짝수, FCC는 모두 홀수 또는 모두 짝수.

1.3.3연습문제

기본

  1. 절편이 \((1, 1, \infty)\)인 면의 밀러 지수는?
    답

    (110).

응용

  1. FCC 알루미늄(\(a\) = 0.405 nm)의 첫 회절선 \(2\theta\)는? (Cu Kα)
    답

    (111): \(d = 0.2338\) nm, \(2\theta = 38.5°\).

심화

  1. 미지 시료의 첫 두 회절선 \(\sin^2\theta\) 비가 3 : 4였다. BCC인가 FCC인가?
    답

    \(\sin^2\theta ∝ h^2 + k^2 + l^2\). FCC의 (111), (200)은 3 : 4, BCC의 (110), (200)은 2 : 4 = 1 : 2. 따라서 FCC.
