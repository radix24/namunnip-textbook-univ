이상기체 혼합물: 공기는 몇 가지 기체의 평균인가

본문

공기를 하나의 기체처럼 다루며 기체 상수 0.287 kJ/(kg·K)를 쓰지만, 공기는 사실 질소와 산소 등의 혼합물이다. 그 숫자는 성분들의 어떤 평균일까? "산소 21%"는 부피로 21%일까, 질량으로 21%일까? 두 기체를 섞기만 해도 엔트로피가 늘어날까?

먼저 알아야 할 것이상기체 상태식 \(Pv = RT\), 몰과 몰 질량(고등학교 화학), 엔트로피 변화(열역학 6단원)를 쓴다.

3.1.1조성 나타내기

혼합물의 조성은 두 가지로 나타낸다. 몰분율 \(y_i = N_i/N\)은 전체 몰수 가운데 성분 \(i\)의 몰수 비율이고, 질량분율 \(\mathrm{mf}_i = m_i/m\)은 전체 질량 가운데 성분 \(i\)의 질량 비율이다.

혼합물 1 kmol의 질량을 겉보기 몰 질량 \(M = \sum y_iM_i\)라 하며, 혼합물의 기체 상수는 \(R = R_u/M\)(\(R_u = 8.314\) kJ/(kmol·K))이다. 처음 질문의 첫째 답이 이것이다. 두 분율은 \(\mathrm{mf}_i = y_iM_i/M\)으로 바꾸며, 무거운 성분일수록 질량분율이 몰분율보다 크다.

3.1.2분압과 분체적

이상기체 분자는 서로 영향을 주지 않으므로, 혼합물 속 각 성분은 혼자 그 용기를 채운 것처럼 행동한다.

Dalton과 Amagat 법칙 (이상기체) \[P = \sum P_i,\quad P_i = y_iP\] \[(\text{같은 } T, V\text{에서 각 성분의 압력: 분압})\] \[V = \sum V_i,\quad V_i = y_iV\] \[(\text{같은 } T, P\text{에서 각 성분의 부피: 분체적})\]

그래서 이상기체 혼합물에서는 몰분율과 압력 분율과 부피 분율이 모두 같다. 즉 "공기 중 산소 21%(부피)"는 몰분율도 21%라는 뜻이며, 처음 질문의 둘째 답이 이것이다.

예제 3.1.1 (공기를 N₂와 O₂로 보기)

공기를 몰분율로 N₂ 79%, O₂ 21%로 본다(\(M\) = 28.013, 31.999; \(c_p\) = 1.039, 0.918 kJ/(kg·K)). 겉보기 몰 질량, 기체 상수, 질량분율, \(c_p\)를 구하고, 101.325 kPa에서 산소의 분압은?

풀이. \(M = 0.79\times28.013 + 0.21\times31.999 = 28.85\) kg/kmol이고, \(R = 8.314/28.85 = 0.2882\) kJ/(kg·K)이다. 이는 표의 공기 값 0.287과 거의 같으며, 아르곤 1%를 넣으면 맞아진다. 질량분율은 N₂가 \(0.79\times28.013/28.85 = 0.767\), O₂가 0.233이다. \(c_p\)는 질량 가중 평균이므로 \(0.767\times1.039 + 0.233\times0.918 = 1.011\) kJ/(kg·K)이다. 산소 분압은 \(0.21\times101.325 = 21.3\) kPa이다(그림 1).

3.1.3성질과 혼합 엔트로피

혼합물의 내부 에너지, 엔탈피, 비열은 성분 값의 가중 평균이다. 단위 질량당이면 질량분율로, 몰당이면 몰분율로 가중한다. 이상기체의 \(u\), \(h\)는 온도만의 함수여서 섞여도 바뀌지 않는다.

하지만 엔트로피는 다르다. 각 성분의 엔트로피는 자기 분압에서 계산하므로, 같은 온도·압력의 순수 기체 두 개를 섞으면 각 성분의 압력이 분압으로 내려가 엔트로피가 늘어난다. 처음 질문의 셋째 답이 이것이다.

\[\Delta S_{\text{혼합}} = -R_u\sum N_i\ln y_i \;(> 0)\]

칸막이를 걷으면 기체가 저절로 섞이지만 저절로 나뉘지는 않으므로, 혼합은 비가역 과정이다. 거꾸로 공기에서 산소를 분리하려면 적어도 이 엔트로피 감소에 해당하는 일이 든다.

흔한 실수질량 가중과 몰 가중을 섞는 실수가 흔하다. \(c_p\)(kJ/(kg·K))는 질량분율로, \(\bar c_p\)(kJ/(kmol·K))는 몰분율로 평균한다. 또 천연가스 배관이나 고압 반응기처럼 높은 압력의 혼합물은 이상기체가 아니어서, Kay 규칙 같은 실제 기체 방법을 쓴다.
마무리

혼합물은 \(\mathrm{mf}_i = y_iM_i/M\), \(M = \sum y_iM_i\), \(R = R_u/M\)으로 다룬다. 이상기체 혼합물에서는 몰분율이 분압 비, 분체적 비와 같다. \(u\), \(h\), \(c_p\)는 가중 평균이고, 혼합 엔트로피는 \(-R_u\sum N_i\ln y_i > 0\)이다.

3.1.4연습문제

기본

  1. 질량으로 CO₂ 20%, N₂ 80%인 혼합물의 몰분율은? (\(M\) = 44.01, 28.01)
    답

    100 kg당 몰수는 0.454, 2.856 kmol이므로 \(y_{CO_2} = 0.137\), \(y_{N_2} = 0.863\)이다.

응용

  1. 1번 혼합물이 300 K, 200 kPa에서 2 m³를 차지한다. 질량과 CO₂ 분압은?
    답

    \(M = 0.137\times44.01 + 0.863\times28.01 = 30.2\), \(R = 0.2753\)이다. \(m = PV/(RT) = 400/82.6 = 4.84\) kg이고, CO₂ 분압은 \(0.137\times200 = 27.4\) kPa이다.

심화

  1. 같은 온도·압력의 N₂ 0.79 kmol과 O₂ 0.21 kmol을 섞을 때 엔트로피 증가와, 25 °C에서 이것을 다시 나누는 데 필요한 최소 일은?
    답

    \(\Delta S = -8.314(0.79\ln0.79 + 0.21\ln0.21) = 4.27\) kJ/K이다. 최소 일은 \(T_0\Delta S = 298\times4.27 = 1.27\) MJ(공기 1 kmol당)이다.
