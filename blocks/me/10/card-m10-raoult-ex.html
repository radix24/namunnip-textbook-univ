두 단 증류로 얼마나 진해질까

예제 · 상대 휘발도 · 단 계산
문제 해결 전략 · 평형 단 반복
  1. 상대 휘발도 \(\alpha\)로 \(y = \alpha x/(1 + (\alpha - 1)x)\)를 쓴다.
  2. 한 단의 증기를 모두 응축해 다음 단의 액체로 쓴다(이상적).
  3. 단마다 조성을 갱신한다.

문제. 예제 5.2.1 조건(\(\alpha = 101/38.9 = 2.60\))에서 벤젠 0.5인 액체를 끓여 증기를 응축하고, 그 액체를 다시 끓이는 과정을 두 번 하면 벤젠 분율은? 세 번이면?

전략

Raoult 식을 정리하면 \(y = \alpha x/(1 + (\alpha - 1)x)\)입니다(\(P\)와 무관).

풀이

  1. 1단: \(y_1 = 2.6\times0.5/(1 + 1.6\times0.5) = 0.722\).
    예제와 같음.
  2. 2단: \(y_2 = 2.6\times0.722/(1 + 1.6\times0.722) = 0.871\).
    반복.
  3. 3단: \(y_3 = 0.946\).
    점점 진해짐.

검산

몰비 \(y/(1 - y)\)는 단마다 \(\alpha\)배: \(1 \to 2.6 \to 6.76 \to 17.6\)이고, \(17.6/18.6 = 0.946\)으로 맞다.

의미

실제 증류탑은 단마다 증기를 일부만 올려 보내고 액체를 내려 보내는 연속 과정이지만, "단마다 몰비가 \(\alpha\)배"라는 그림이 필요한 단 수를 어림하게 해 준다. 99% 순도(몰비 99)까지는 \(\ln99/\ln2.6 = 4.8\), 약 5단이 필요하다.

바꿔 보기

\(\alpha = 1.2\)인 혼합물이면 99%까지 \(\ln99/\ln1.2 = 25\)단이 필요하다. 휘발도 차이가 작을수록 증류탑이 높아진다.

이해 확인

\(\alpha = 1\)이면 몇 단을 해도 조성이 바뀌는가?

답

바뀌지 않는다(공비 혼합물처럼 증류로 분리 불가).
