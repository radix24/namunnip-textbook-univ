Maxwell 관계식: 잴 수 없는 엔트로피를 잴 수 있는 양으로

본문
이 절에서 배울 것
  • 여러 변수의 함수에서 "하나만 바꾸고 나머지는 고정한 변화율"(편미분)의 뜻과 표기를 안다.
  • Gibbs 관계식과 네 가지 열역학 퍼텐셜에서 Maxwell 관계식을 유도한다.
  • Maxwell 관계식으로 엔트로피 변화와 \(c_p - c_v\)를 측정 가능한 \(P\), \(v\), \(T\) 자료로 계산한다.
먼저 알아야 할 것
  • 엔트로피와 \(T\,ds = du + P\,dv\) (열역학 6단원), 미분(고등학교 미적분).

2.1.1왜 필요한가

온도, 압력, 비체적은 온도계, 압력계, 부피와 질량으로 직접 잴 수 있습니다. 그런데 엔트로피, 내부 에너지, 엔탈피를 직접 재는 계기는 없습니다. 증기표의 \(s\), \(h\) 값은 잴 수 있는 \(P\)-\(v\)-\(T\) 자료와 비열로부터 계산한 것입니다. 그 계산의 다리가 Maxwell 관계식입니다.

2.1.2편미분: 하나만 바꾸기

단순 압축성 물질의 상태는 독립 상태량 두 개로 정해집니다. 그래서 \(z = z(x, y)\)처럼 변수가 둘인 함수를 다룹니다. 이때 "\(y\)는 고정하고 \(x\)만 바꿀 때 \(z\)의 변화율"을 다음과 같이 씁니다.

편미분 \(\left(\dfrac{\partial z}{\partial x}\right)_y\): \(y\)를 상수로 보고 \(x\)로 미분한 값. 아래 첨자는 고정한 변수.

예를 들어 이상기체 \(P = RT/v\)에서 \((\partial P/\partial T)_v = R/v\)(부피 고정 가열), \((\partial P/\partial v)_T = -RT/v^2\)(온도 고정 팽창)입니다. 두 변수가 모두 조금씩 바뀌면 전체 변화는 각 몫의 합입니다.

\[dz = \left(\frac{\partial z}{\partial x}\right)_ydx + \left(\frac{\partial z}{\partial y}\right)_xdy = M\,dx + N\,dy\]

그리고 미분 순서를 바꿔도 결과가 같다는 성질(두 번 미분할 때 \(x\) 먼저든 \(y\) 먼저든 같음)에서 다음 조건이 나옵니다. 이것이 Maxwell 관계식의 열쇠입니다.

상태량의 미분 조건 \[\left(\frac{\partial M}{\partial y}\right)_x = \left(\frac{\partial N}{\partial x}\right)_y\]
확인해 보기 \(z = x^2y^3\)이면 \(M = 2xy^3\), \(N = 3x^2y^2\). \(\partial M/\partial y = 6xy^2\), \(\partial N/\partial x = 6xy^2\)로 같습니다.

2.1.3네 개의 Gibbs 관계식과 Maxwell 관계식

열역학 6단원의 \(du = T\,ds - P\,dv\)에서 출발해 엔탈피 \(h = u + Pv\), Helmholtz 함수 \(a = u - Ts\), Gibbs 함수 \(g = h - Ts\)를 정의하면 다음 네 식이 나옵니다(각각 정의를 미분해 \(du\)를 넣으면 됩니다).

\[du = T\,ds - P\,dv,\quad dh = T\,ds + v\,dP,\quad da = -s\,dT - P\,dv,\quad dg = -s\,dT + v\,dP\]

각 식에 미분 조건 \((\partial M/\partial y)_x = (\partial N/\partial x)_y\)를 쓰면 네 Maxwell 관계식을 얻습니다.

Maxwell 관계식 \[\left(\frac{\partial T}{\partial v}\right)_s = -\left(\frac{\partial P}{\partial s}\right)_v\] \[\left(\frac{\partial T}{\partial P}\right)_s = \left(\frac{\partial v}{\partial s}\right)_P\] \[\left(\frac{\partial s}{\partial v}\right)_T = \left(\frac{\partial P}{\partial T}\right)_v\] \[\left(\frac{\partial s}{\partial P}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_P\]

실제로 많이 쓰는 것은 아래 두 식입니다. 왼쪽은 잴 수 없는 엔트로피의 변화율, 오른쪽은 \(P\)-\(v\)-\(T\) 자료로 잴 수 있는 변화율입니다.

예제 2.1.1 (이상기체 등온 팽창의 엔트로피)

이상기체가 온도를 유지하며 \(v_1\)에서 \(v_2\)로 팽창할 때 엔트로피 변화를 Maxwell 관계식으로 구하여라.

풀이. \((\partial s/\partial v)_T = (\partial P/\partial T)_v = R/v\). 온도가 일정하므로 \(v\)만으로 적분: \(\Delta s = \int R/v\,dv = R\ln(v_2/v_1)\). 열역학 6단원의 식과 같습니다.

예제 2.1.2 (물을 누르면 엔트로피가 얼마나 줄까)

20 °C 물(\(v = 1.002\times10^{-3}\) m³/kg, 부피 팽창 계수 \(\beta = 2.07\times10^{-4}\)/K)을 온도를 유지하며 0.1 MPa에서 10 MPa로 압축하면 엔트로피 변화는?

풀이. \(\beta = \frac1v(\partial v/\partial T)_P\)이므로 \((\partial s/\partial P)_T = -(\partial v/\partial T)_P = -v\beta = -2.07\times10^{-7}\) m³/(kg·K). \(\Delta s = -2.07\times10^{-7}\times9.9\times10^6 = -2.05\) J/(kg·K). 물을 100배로 눌러도 엔트로피는 거의 변하지 않습니다. 압축 액체를 같은 온도의 포화 액체 값으로 근사하는 근거입니다.

2.1.4\(c_p - c_v\)

같은 방법으로 비열의 차를 \(P\)-\(v\)-\(T\) 자료만으로 쓸 수 있습니다(유도는 연습문제 심화).

비열 차 \[c_p - c_v = \frac{Tv\beta^2}{\kappa}\] \[\beta = \frac1v\left(\frac{\partial v}{\partial T}\right)_P,\quad \kappa = -\frac1v\left(\frac{\partial v}{\partial P}\right)_T\]

\(\kappa\)(등온 압축률)는 항상 양수이므로 \(c_p \ge c_v\)입니다. 20 °C 물은 \(\kappa = 4.59\times10^{-10}\)/Pa로 \(c_p - c_v = 293\times1.002\times10^{-3}\times(2.07\times10^{-4})^2/4.59\times10^{-10} = 27\) J/(kg·K), \(c_p\)(4182)의 0.7%뿐입니다. 액체·고체에서 "비열 하나"만 쓰는 이유입니다. 이상기체를 넣으면 \(\beta = 1/T\), \(\kappa = 1/P\)이므로 \(c_p - c_v = R\)이 됩니다.

주의(1) 편미분에서 고정한 변수가 다르면 다른 양입니다. \((\partial s/\partial P)_T\)와 \((\partial s/\partial P)_h\)는 다릅니다. (2) Maxwell 관계식은 단순 압축성 물질(일이 \(P\,dv\)뿐)에 대한 것입니다.
요약
  1. \((\partial z/\partial x)_y\): \(y\) 고정, \(x\)만 바꾼 변화율. 미분 순서 무관 → \(\partial M/\partial y = \partial N/\partial x\).
  2. \((\partial s/\partial v)_T = (\partial P/\partial T)_v\), \((\partial s/\partial P)_T = -(\partial v/\partial T)_P\).
  3. \(c_p - c_v = Tv\beta^2/\kappa \ge 0\), 이상기체면 \(R\).

2.1.5연습문제

기본

  1. \(dg = -s\,dT + v\,dP\)에서 Maxwell 관계식 하나를 유도하여라.
    답

    \(M = -s\)(\(T\)의 계수), \(N = v\)(\(P\)의 계수). \((\partial(-s)/\partial P)_T = (\partial v/\partial T)_P\), 곧 \((\partial s/\partial P)_T = -(\partial v/\partial T)_P\).

응용

  1. 구리(\(T = 300\) K, \(\rho = 8930\) kg/m³, \(\beta = 5.0\times10^{-5}\)/K, \(\kappa = 7.3\times10^{-12}\)/Pa, \(c_p = 385\) J/(kg·K))의 \(c_p - c_v\)는 \(c_p\)의 몇 %인가?
    답

    \(300\times(1/8930)\times(5.0\times10^{-5})^2/7.3\times10^{-12} = 11.5\) J/(kg·K), 약 3%.

심화

  1. van der Waals 기체 \(P = RT/(v - b) - a/v^2\)의 등온 팽창(\(v_1 \to v_2\)) 엔트로피 변화를 구하여라. 이상기체와 무엇이 다른가?
    답

    \((\partial P/\partial T)_v = R/(v - b)\), \(\Delta s = R\ln\frac{v_2 - b}{v_1 - b}\). 분자 자체의 부피 \(b\)만큼 움직일 공간이 작아진 효과이고, 인력 항 \(a\)는 온도와 무관해 엔트로피 변화에 들어가지 않는다.
