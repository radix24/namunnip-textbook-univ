Maxwell 관계식: 잴 수 없는 엔트로피를 잴 수 있는 양으로

본문

증기표에는 온도와 압력마다 엔트로피와 엔탈피 값이 빼곡히 적혀 있다. 그런데 엔트로피계라는 계기는 없다. 그 숫자들은 무엇을 재서 얻은 것일까? 물을 100배 압력으로 눌렀을 때 엔트로피가 얼마나 변하는지를, 엔트로피를 재지 않고 알아낼 수 있을까?

먼저 알아야 할 것엔트로피와 \(T\,ds = du + P\,dv\)(열역학 6단원), 미분(고등학교 미적분)을 쓴다.

2.1.1왜 필요한가

온도, 압력, 비체적은 온도계, 압력계, 부피와 질량으로 직접 잴 수 있다. 그런데 엔트로피, 내부 에너지, 엔탈피를 직접 재는 계기는 없다. 증기표의 \(s\), \(h\) 값은 잴 수 있는 \(P\)-\(v\)-\(T\) 자료와 비열로부터 계산한 것이며, 처음 질문의 첫째 답이 이것이다. 그 계산의 다리가 Maxwell 관계식이다(그림 1).

2.1.2편미분: 하나만 바꾸기

단순 압축성 물질의 상태는 독립 상태량 두 개로 정해진다. 그래서 \(z = z(x, y)\)처럼 변수가 둘인 함수를 다룬다. 이때 "\(y\)는 고정하고 \(x\)만 바꿀 때 \(z\)의 변화율"을 편미분 \(\left(\dfrac{\partial z}{\partial x}\right)_y\)로 쓰며, 아래 첨자는 고정한 변수이다.

가령 이상기체 \(P = RT/v\)에서 부피를 고정하고 가열하면 \((\partial P/\partial T)_v = R/v\)이고, 온도를 고정하고 팽창하면 \((\partial P/\partial v)_T = -RT/v^2\)이다. 두 변수가 모두 조금씩 바뀌면 전체 변화는 각 몫의 합이다.

\[dz = \left(\frac{\partial z}{\partial x}\right)_ydx + \left(\frac{\partial z}{\partial y}\right)_xdy = M\,dx + N\,dy\]

그리고 두 번 미분할 때 \(x\) 먼저든 \(y\) 먼저든 결과가 같다는 성질에서 다음 조건이 나온다. 이것이 Maxwell 관계식의 열쇠이다.

상태량의 미분 조건 \[\left(\frac{\partial M}{\partial y}\right)_x = \left(\frac{\partial N}{\partial x}\right)_y\]
확인해 보기\(z = x^2y^3\)이면 \(M = 2xy^3\), \(N = 3x^2y^2\)이다. 그러면 \(\partial M/\partial y = 6xy^2\), \(\partial N/\partial x = 6xy^2\)로 같다.

2.1.3네 개의 Gibbs 관계식과 Maxwell 관계식

열역학 6단원의 \(du = T\,ds - P\,dv\)에서 출발해 엔탈피 \(h = u + Pv\), Helmholtz 함수 \(a = u - Ts\), Gibbs 함수 \(g = h - Ts\)를 정의한다. 각 정의를 미분해 \(du\)를 넣으면 다음 네 식이 나온다.

\[du = T\,ds - P\,dv,\quad dh = T\,ds + v\,dP,\quad da = -s\,dT - P\,dv,\quad dg = -s\,dT + v\,dP\]

각 식에 미분 조건 \((\partial M/\partial y)_x = (\partial N/\partial x)_y\)를 쓰면 네 Maxwell 관계식을 얻는다.

Maxwell 관계식 \[\left(\frac{\partial T}{\partial v}\right)_s = -\left(\frac{\partial P}{\partial s}\right)_v\] \[\left(\frac{\partial T}{\partial P}\right)_s = \left(\frac{\partial v}{\partial s}\right)_P\] \[\left(\frac{\partial s}{\partial v}\right)_T = \left(\frac{\partial P}{\partial T}\right)_v\] \[\left(\frac{\partial s}{\partial P}\right)_T = -\left(\frac{\partial v}{\partial T}\right)_P\]

실제로 많이 쓰는 것은 아래 두 식이다. 왼쪽은 잴 수 없는 엔트로피의 변화율이고, 오른쪽은 \(P\)-\(v\)-\(T\) 자료로 잴 수 있는 변화율이다.

예제 2.1.1 (이상기체 등온 팽창의 엔트로피)

이상기체가 온도를 유지하며 \(v_1\)에서 \(v_2\)로 팽창할 때 엔트로피 변화를 Maxwell 관계식으로 구하여라.

풀이. \((\partial s/\partial v)_T = (\partial P/\partial T)_v = R/v\)이다. 온도가 일정하므로 \(v\)만으로 적분하면 \(\Delta s = \int R/v\,dv = R\ln(v_2/v_1)\)이며, 열역학 6단원의 식과 같다.

예제 2.1.2 (물을 누르면 엔트로피가 얼마나 줄까)

20 °C 물(\(v = 1.002\times10^{-3}\) m³/kg, 부피 팽창 계수 \(\beta = 2.07\times10^{-4}\)/K)을 온도를 유지하며 0.1 MPa에서 10 MPa로 압축하면 엔트로피 변화는?

풀이. \(\beta = \frac1v(\partial v/\partial T)_P\)이므로 \((\partial s/\partial P)_T = -(\partial v/\partial T)_P = -v\beta = -2.07\times10^{-7}\) m³/(kg·K)이다. 그러면 \(\Delta s = -2.07\times10^{-7}\times9.9\times10^6 = -2.05\) J/(kg·K)이다. 즉 물을 100배로 눌러도 엔트로피는 거의 변하지 않으며, 처음 질문의 둘째 답이 이것이다. 압축 액체를 같은 온도의 포화 액체 값으로 근사하는 근거도 여기에 있다.

2.1.4\(c_p - c_v\)

같은 방법으로 비열의 차를 \(P\)-\(v\)-\(T\) 자료만으로 쓸 수 있다(유도는 연습문제 심화).

비열 차 \[c_p - c_v = \frac{Tv\beta^2}{\kappa}\] \[\beta = \frac1v\left(\frac{\partial v}{\partial T}\right)_P,\quad \kappa = -\frac1v\left(\frac{\partial v}{\partial P}\right)_T\]

등온 압축률 \(\kappa\)는 항상 양수이므로 \(c_p \ge c_v\)이다. 20 °C 물은 \(\kappa = 4.59\times10^{-10}\)/Pa이어서 \(c_p - c_v = 293\times1.002\times10^{-3}\times(2.07\times10^{-4})^2/4.59\times10^{-10} = 27\) J/(kg·K)이며, \(c_p\)(4182)의 0.7%뿐이다. 그래서 액체와 고체에서는 비열을 하나만 쓴다. 한편 이상기체를 넣으면 \(\beta = 1/T\), \(\kappa = 1/P\)이므로 \(c_p - c_v = R\)이 된다.

흔한 실수고정한 변수를 무시하는 실수가 흔하다. 편미분에서 고정한 변수가 다르면 다른 양이어서, \((\partial s/\partial P)_T\)와 \((\partial s/\partial P)_h\)는 다르다. 또 Maxwell 관계식은 일이 \(P\,dv\)뿐인 단순 압축성 물질에 대한 것이다.
마무리

편미분 \((\partial z/\partial x)_y\)는 \(y\)를 고정하고 \(x\)만 바꾼 변화율이며, 미분 순서와 무관하다는 데서 \(\partial M/\partial y = \partial N/\partial x\)가 나온다. 많이 쓰는 Maxwell 관계식은 \((\partial s/\partial v)_T = (\partial P/\partial T)_v\)와 \((\partial s/\partial P)_T = -(\partial v/\partial T)_P\)이다. 비열 차는 \(c_p - c_v = Tv\beta^2/\kappa \ge 0\)이고, 이상기체이면 \(R\)이다.

2.1.5연습문제

기본

  1. \(dg = -s\,dT + v\,dP\)에서 Maxwell 관계식 하나를 유도하여라.
    답

    \(M = -s\)(\(T\)의 계수), \(N = v\)(\(P\)의 계수)이다. 그러면 \((\partial(-s)/\partial P)_T = (\partial v/\partial T)_P\), 곧 \((\partial s/\partial P)_T = -(\partial v/\partial T)_P\)이다.

응용

  1. 구리(\(T = 300\) K, \(\rho = 8930\) kg/m³, \(\beta = 5.0\times10^{-5}\)/K, \(\kappa = 7.3\times10^{-12}\)/Pa, \(c_p = 385\) J/(kg·K))의 \(c_p - c_v\)는 \(c_p\)의 몇 %인가?
    답

    \(300\times(1/8930)\times(5.0\times10^{-5})^2/7.3\times10^{-12} = 11.5\) J/(kg·K)로, 약 3%이다.

심화

  1. van der Waals 기체 \(P = RT/(v - b) - a/v^2\)의 등온 팽창(\(v_1 \to v_2\)) 엔트로피 변화를 구하여라. 이상기체와 무엇이 다른가?
    답

    \((\partial P/\partial T)_v = R/(v - b)\)이므로 \(\Delta s = R\ln\frac{v_2 - b}{v_1 - b}\)이다. 분자 자체의 부피 \(b\)만큼 움직일 공간이 작아진 효과이고, 인력 항 \(a\)는 온도와 무관해 엔트로피 변화에 들어가지 않는다.
