폴리트로프 모형으로 간단한 항성 구조 구하기

본문 · 1.3절

1.1절의 네 방정식을 모두 풀려면 상태 방정식, 불투명도, 핵반응률까지 갖춘 컴퓨터 프로그램이 필요하다. 그런데 태양의 중심 밀도가 평균 밀도의 몇 배인지 정도는 연필로도 알 수 있지 않을까? 계산을 확 줄이면서도 별의 모양을 잡아 주는 단순한 모형이 있을까?

먼저 알아야 할 것항성 구조 방정식(1.1절)과 2계 미분방정식의 수치 풀이(천우6 5.1절)를 쓴다.

처음 질문의 단순한 모형이 폴리트로프이다. 압력이 밀도만의 함수라고 가정하면 에너지 방정식을 떼어 내고, 질량 보존과 정역학 평형만으로 구조를 구할 수 있다. 19세기 말 레인과 엠덴이 만든 이래 별 구조의 감을 잡는 가장 좋은 도구로 쓰인다.

1.3.1폴리트로프 관계

정의 1.3.1 (폴리트로프)

압력과 밀도가 \(P = K\rho^{1 + 1/n}\)의 관계를 따르는 구조를 폴리트로프 지수 \(n\)인 폴리트로프라 한다.

대표적인 지수는 둘이다. \(n = 1.5\)는 완전히 대류하는 별(단열, \(\gamma = 5/3\))과 비상대론적 축퇴 기체(백색왜성, 저질량 별)에 맞는다. 한편 \(n = 3\)은 복사압의 비율이 일정한 별(에딩턴 표준 모형, 태양과 비슷함)과 상대론적 축퇴 기체(찬드라세카르 한계)에 맞는다.

1.3.2레인-엠덴 방정식

유도. 정역학 평형과 질량 보존을 합치면 \(\frac{1}{r^2}\frac{d}{dr}\big(\frac{r^2}{\rho}\frac{dP}{dr}\big) = -4\pi G\rho\)이다. 밀도를 \(\rho = \rho_c\theta^n\), 반지름을 \(r = \alpha\xi\)로 두고 \(\alpha^2 = (n+1)K\rho_c^{1/n - 1}/(4\pi G)\)로 고르면 상수들이 모두 지워져 아래 식이 된다. 중심 조건은 \(\theta(0) = 1\), \(\theta'(0) = 0\)이고, \(\theta\)가 처음 0이 되는 \(\xi_1\)이 표면이다. ∎

\[ \frac{1}{\xi^2}\frac{d}{d\xi}\left(\xi^2\frac{d\theta}{d\xi}\right) = -\theta^n \]

여기서 \(\theta^n\)은 밀도에, \(\theta\)는 (이상 기체이고 \(\mu\)가 일정하면) 온도에 비례한다. 이 방정식은 \(n = 0, 1, 5\)에서만 식으로 풀리고 나머지는 수치로 푼다. 예를 들어 \(n = 0\)이면 \(\theta = 1 - \xi^2/6\), \(\xi_1 = \sqrt6 = 2.449\)로 밀도가 고른 공이고, \(n = 1\)이면 \(\theta = \sin\xi/\xi\), \(\xi_1 = \pi\)이다. 수치로 풀면 \(n = 1.5\)에서 \(\xi_1 = 3.654\), \(n = 3\)에서 \(\xi_1 = 6.897\)이고, \(n \ge 5\)이면 반지름이 무한대라 유한한 별이 되지 않는다.

또 중심 밀도와 평균 밀도의 비는 \(\rho_c/\bar\rho = -\xi_1/(3\theta'(\xi_1))\)이며, \(n = 1.5\)에서 5.99, \(n = 3\)에서 54.2이다. 즉 \(n\)이 클수록 질량이 중심에 몰린다(그림 1).

예제 1.3.1

태양을 \(n = 3\) 폴리트로프로 보면 중심 밀도는 얼마인가? 정밀 모형의 값(\(1.5\times10^5\) kg/m³)과 비교하여라.

풀이. \(\bar\rho = 1410\) kg/m³이므로 \(\rho_c = 54.2\times1410 = 7.6\times10^4\) kg/m³이다. 정밀 모형의 절반 정도이며, 중심에 헬륨이 쌓여 더 진해진 효과를 생각하면 꽤 가깝다. 처음 질문의 답처럼, 연필로 구한 값이 평균 밀도로 어림한 것(천우4 2.1절)보다 훨씬 낫다.

주의폴리트로프는 \(P\)와 \(\rho\)의 관계를 가정한 것이지 에너지 생성과 수송을 푼 것이 아니다. 그래서 광도나 진화는 알려 주지 않으며, 실제 별은 층마다 다른 \(n\)에 가깝다. 태양은 중심 쪽 복사층이 \(n \approx 3\), 바깥 대류층이 \(n = 1.5\)에 가깝다.
마무리

폴리트로프 \(P = K\rho^{1+1/n}\)을 가정하면 에너지 방정식 없이 구조를 구할 수 있고, 구조는 레인-엠덴 방정식 \(\xi^{-2}(\xi^2\theta')' = -\theta^n\), \(\theta(0) = 1\), \(\theta'(0) = 0\)의 해로 정해진다. \(n = 1.5\)이면 \(\xi_1 = 3.654\), \(\rho_c/\bar\rho = 5.99\)이고 \(n = 3\)이면 6.897과 54.2이다. \(n\)이 클수록 질량이 중심에 몰리며, \(n \ge 5\)는 유한한 별이 아니다.

1.3.3연습문제

기본

  1. \(n = 0\)의 해 \(\theta = 1 - \xi^2/6\)이 레인-엠덴 방정식을 만족함을 확인하여라.
    답

    \(\theta' = -\xi/3\)이므로 \(\xi^2\theta' = -\xi^3/3\)이고, 이를 미분하면 \(-\xi^2\), 여기에 \(\xi^{-2}\)을 곱하면 \(-1 = -\theta^0\)이다.

응용

  1. \(n = 1\)에서 \(\rho_c/\bar\rho\)를 구하여라(\(\theta = \sin\xi/\xi\)).
    답

    \(\theta'(\pi) = (\pi\cos\pi - \sin\pi)/\pi^2 = -1/\pi\)이므로 \(\rho_c/\bar\rho = -\pi/(3\times(-1/\pi)) = \pi^2/3 = 3.29\)이다.

  2. 비상대론적 백색왜성(\(n = 1.5\))의 반지름이 질량의 −1/3제곱에 비례함을 폴리트로프 척도 관계로 설명하여라.
    답

    \(R \propto \alpha \propto \rho_c^{(1-n)/2n} = \rho_c^{-1/6}\)이고 \(M \propto \rho_cR^3\)이므로 \(M \propto \rho_c^{1/2}\), 따라서 \(R \propto M^{-1/3}\)이다(천우4 2.4절과 같다).
