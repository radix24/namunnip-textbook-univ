폴리트로프 모형으로 간단한 항성 구조 구하기

본문 · 1.3절
이 절에서 배울 것
  • 폴리트로프 관계 \(P = K\rho^{1+1/n}\)를 안다.
  • Lane-Emden 방정식을 유도하고 해의 성질을 안다.
  • n = 1.5(대류)와 n = 3(Eddington 표준 모형)의 중심 밀도 비를 비교한다.
먼저 알아야 할 것
  • 항성 구조 방정식 (1.1절), 2계 미분방정식의 수치 풀이 (천우6 5.1절).

온도 없이 풀어 보기

네 방정식을 모두 풀려면 컴퓨터가 필요합니다. 그런데 압력이 밀도만의 함수라고 가정하면 에너지 방정식을 따로 떼어 내고 질량 보존과 정역학 평형만으로 구조를 구할 수 있습니다. 이런 모형을 폴리트로프라 하며, 19세기 말 레인과 엠덴이 만든 이래 별 구조의 감을 잡는 가장 좋은 도구입니다.

1.3.1폴리트로프 관계

정의 1.3.1 (폴리트로프)

압력과 밀도가 \(P = K\rho^{1 + 1/n}\)의 관계를 따르는 구조를 폴리트로프 지수 \(n\)인 폴리트로프라 한다.

  • \(n = 1.5\): 완전히 대류하는 별(단열, \(\gamma = 5/3\)), 비상대론적 축퇴 기체(백색왜성, 저질량 별).
  • \(n = 3\): 복사압 비율이 일정한 별(Eddington 표준 모형, 태양과 비슷), 상대론적 축퇴 기체(찬드라세카르 한계).

1.3.2Lane-Emden 방정식

유도. 정역학 평형과 질량 보존을 합치면 \(\frac{1}{r^2}\frac{d}{dr}\left(\frac{r^2}{\rho}\frac{dP}{dr}\right) = -4\pi G\rho\)입니다. 밀도를 \(\rho = \rho_c\theta^n\), 반지름을 \(r = \alpha\xi\)로 두고 \(\alpha^2 = (n+1)K\rho_c^{1/n - 1}/(4\pi G)\)로 고르면 상수들이 모두 지워져 \[ \frac{1}{\xi^2}\frac{d}{d\xi}\left(\xi^2\frac{d\theta}{d\xi}\right) = -\theta^n \] 이 됩니다. 중심 조건은 \(\theta(0) = 1\), \(\theta'(0) = 0\)이고, \(\theta\)가 처음 0이 되는 \(\xi_1\)이 표면입니다. ∎

\(\theta^n\)은 밀도, \(\theta\)는 (이상 기체이고 \(\mu\)가 일정하면) 온도에 비례합니다. \(n = 0, 1, 5\)에서만 식으로 풀리고, 나머지는 수치로 풉니다. 아래 실습 카드에서 \(n\)을 바꾸며 해를 볼 수 있습니다.

  • \(n = 0\): \(\theta = 1 - \xi^2/6\), \(\xi_1 = \sqrt6 = 2.449\) (밀도가 고른 공).
  • \(n = 1\): \(\theta = \sin\xi/\xi\), \(\xi_1 = \pi\).
  • \(n = 1.5\): \(\xi_1 = 3.654\), \(\rho_c/\bar\rho = 5.99\).
  • \(n = 3\): \(\xi_1 = 6.897\), \(\rho_c/\bar\rho = 54.2\).
  • \(n \ge 5\): 반지름이 무한대(유한한 별이 안 됨).

중심 밀도와 평균 밀도의 비는 \(\rho_c/\bar\rho = -\xi_1/(3\theta'(\xi_1))\)입니다. \(n\)이 클수록 질량이 중심에 몰립니다.

예제 1.3.2

태양을 \(n = 3\) 폴리트로프로 보면 중심 밀도는? 정밀 모형 값(\(1.5\times10^5\) kg/m³)과 비교하세요.

풀이. \(\bar\rho = 1410\) kg/m³이므로 \(\rho_c = 54.2\times1410 = 7.6\times10^4\) kg/m³입니다. 정밀 모형의 절반 정도로, 중심에서 헬륨이 쌓여 더 진해진 효과를 빼면 꽤 가깝습니다. 천우4 2.1절에서 평균 밀도로 어림했을 때보다 훨씬 낫습니다.

주의 폴리트로프는 \(P\)와 \(\rho\)의 관계를 가정한 것이지 에너지 생성과 수송을 푼 것이 아닙니다. 광도나 진화는 알려 주지 않으며, 실제 별은 층마다 다른 \(n\)에 가깝습니다(태양: 중심 쪽 복사층 \(n \approx 3\), 바깥 대류층 \(n = 1.5\)).
요약
  1. 폴리트로프 \(P = K\rho^{1+1/n}\): 에너지 방정식 없이 구조를 구한다.
  2. Lane-Emden: \(\xi^{-2}(\xi^2\theta')' = -\theta^n\), \(\theta(0) = 1\), \(\theta'(0) = 0\).
  3. n = 1.5: \(\xi_1 = 3.654\), \(\rho_c/\bar\rho = 5.99\). n = 3: 6.897, 54.2.
  4. n이 클수록 질량이 중심에 몰린다. n ≥ 5는 유한한 별이 아니다.

1.3.3연습문제

기본

  1. \(n = 0\) 해 \(\theta = 1 - \xi^2/6\)이 Lane-Emden 방정식을 만족함을 확인하세요.
    답

    \(\theta' = -\xi/3\), \(\xi^2\theta' = -\xi^3/3\), 미분 \(-\xi^2\), \(\xi^{-2}\)을 곱하면 \(-1 = -\theta^0\).

  2. 완전 대류하는 적색왜성에 알맞은 폴리트로프 지수는?
    답

    n = 1.5.

응용

  1. \(n = 1\)에서 \(\rho_c/\bar\rho\)를 구하세요(\(\theta = \sin\xi/\xi\)).
    답

    \(\theta'(\pi) = (\pi\cos\pi - \sin\pi)/\pi^2 = -1/\pi\). \(\rho_c/\bar\rho = -\pi/(3\times(-1/\pi)) = \pi^2/3 = 3.29\).

  2. 백색왜성(n = 1.5, 비상대론)의 반지름이 질량의 −1/3제곱에 비례함을 폴리트로프 척도 관계로 설명하세요.
    답

    \(R \propto \alpha \propto \rho_c^{(1-n)/2n} = \rho_c^{-1/6}\), \(M \propto \rho_cR^3\)이므로 \(M \propto \rho_c^{1/2}\), \(R \propto M^{-1/3}\)(천우4 2.4절과 같음).
