이상 기체, 복사압, 축퇴 기체의 압력 비교

본문 · 2.1절
이 절에서 배울 것
  • 항성 내부 압력의 세 성분(기체, 복사, 축퇴)을 식으로 쓴다.
  • 평균 입자 질량 \(\mu\)를 성분비로 계산한다.
  • 밀도-온도 평면에서 어느 압력이 지배하는지 판단한다.
먼저 알아야 할 것
  • 이상 기체 \(P = nkT\), 축퇴압 (천우4 2.4절), 흑체 복사 (천우3 2.1절).

별을 떠받치는 압력은 무엇인가

정역학 평형에는 압력이 필요하고, 그 압력이 밀도와 온도로 어떻게 정해지는지가 상태 방정식입니다. 별 내부의 압력은 세 가지가 더해진 것입니다.

2.1.1이상 기체

완전히 전리된 기체에서 원자핵과 전자 모두 입자로 셉니다. 질량 비율 수소 \(X\), 헬륨 \(Y\), 금속 \(Z\)일 때 입자 하나의 평균 질량(원자 질량 단위)은

\[ \frac1\mu \approx 2X + \frac34Y + \frac12Z, \qquad P_{gas} = \frac{\rho kT}{\mu m_H} \]

입니다(수소 원자 하나는 양성자+전자 2개, 헬륨 하나는 4u에 입자 3개, 금속은 질량수의 약 절반만큼 입자). 태양 표면 성분(\(X = 0.74\), \(Y = 0.25\), \(Z = 0.01\))이면 \(1/\mu = 1.48 + 0.1875 + 0.005 = 1.67\), \(\mu = 0.60\)입니다.

2.1.2복사압

광자도 운동량을 나르므로 압력을 줍니다. 흑체 복사에서

\[ P_{rad} = \frac13aT^4, \qquad a = 7.566\times10^{-16}\text{ J m}^{-3}\text{ K}^{-4} \]

입니다. 온도의 4제곱이라 뜨겁고 묽은 무거운 별에서 중요해집니다. 기체 압력의 비율을 \(\beta = P_{gas}/P\)로 씁니다.

예제 2.1.1

태양 중심(\(T = 1.57\times10^7\) K, \(P = 2.5\times10^{16}\) Pa)에서 복사압의 비율은?

풀이. \(P_{rad} = 7.566\times10^{-16}\times(1.57\times10^7)^4/3 = 7.566\times10^{-16}\times6.08\times10^{28}/3 = 1.53\times10^{13}\) Pa. 비율 \(1.53\times10^{13}/2.5\times10^{16} = 0.06\%\), 곧 \(\beta = 0.9994\)입니다. 태양에서는 복사압이 무시할 만하지만, 수십 태양 질량의 별에서는 수십 %가 됩니다.

2.1.3전자 축퇴압

밀도가 아주 높으면 전자의 축퇴압(천우4 2.4절)이 지배합니다. 비상대론적으로 \(P_e \approx 1.0\times10^7(\rho/\mu_e)^{5/3}\) Pa(\(\rho\)는 kg/m³, \(\mu_e = 2/(1+X)\)는 전자 하나당 질량), 상대론적으로 \(P_e \approx 1.24\times10^{10}(\rho/\mu_e)^{4/3}\)입니다. 축퇴가 중요한지는 전자의 페르미 에너지와 \(kT\)를 비교해 판단합니다. 태양 중심에서 페르미 에너지는 약 0.6 keV로 \(kT = 1.35\) keV보다 작아 거의 이상 기체입니다. 백색왜성과 적색거성의 헬륨 핵에서는 축퇴압이 지배합니다.

2.1.4지배 영역

  • 밀도가 낮고 온도가 매우 높음: 복사압(무거운 별의 바깥층).
  • 보통: 이상 기체(대부분의 주계열성 내부).
  • 밀도가 매우 높고 온도가 상대적으로 낮음: 전자 축퇴(백색왜성, 거성의 핵). 밀도가 더 높으면 상대론적 축퇴.
주의 축퇴 기체는 압력이 온도에 거의 의존하지 않아, 핵반응으로 데워져도 팽창하지 않습니다. 그래서 축퇴된 핵에서 헬륨이 불붙으면 반응이 폭주합니다(헬륨 섬광, 5.1절).
요약
  1. \(P = P_{gas} + P_{rad} + P_{deg}\).
  2. \(P_{gas} = \rho kT/(\mu m_H)\), \(1/\mu \approx 2X + \frac34Y + \frac12Z\). 태양 \(\mu \approx 0.60\).
  3. \(P_{rad} = aT^4/3\): 태양 중심 0.06%, 무거운 별에서 중요.
  4. 축퇴압은 고밀도·저온에서 지배, 온도에 둔감하다.

2.1.5연습문제

기본

  1. 순수 헬륨(\(Y = 1\))이 완전 전리되었을 때 \(\mu\)는?
    답

    4/3.

  2. 온도가 2배가 되면 복사압은 몇 배?
    답

    16배.

응용

  1. 중심 수소가 절반 소모되어 \(X = 0.35\), \(Y = 0.64\)가 되면 \(\mu\)는?
    답

    \(1/\mu = 0.70 + 0.48 + 0.005 = 1.185\), \(\mu = 0.84\).

  2. 같은 밀도·온도에서 \(\mu\)가 0.6에서 0.84로 커지면 기체 압력은 몇 배? 그 결과는?
    답

    0.71배. 압력이 모자라 중심이 수축하며 데워지고, 그래서 주계열 동안 별이 밝아집니다.
