조성이 바뀌면 압력과 찬드라세카르 질량도 바뀐다

예제 · 평균 분자량 · 전자당 분자량
문제 해결 전략 · 조성에서 \(\mu\), \(\mu_e\)로
  1. 질량 비율에서 단위 질량당 입자 수(핵 + 전자)를 센다.
  2. 이상 기체 압력에는 \(\mu\), 축퇴압에는 \(\mu_e\)를 쓴다.
  3. 압력이나 질량 한계가 \(\mu\)의 어떤 거듭제곱에 비례하는지 보고 비율로 비교한다.

문제 1. 같은 온도와 밀도에서 (가) 처음 태양 중심(\(X = 0.71\), \(Y = 0.27\), \(Z = 0.02\)), (나) 지금 태양 중심(\(X = 0.34\), \(Y = 0.64\)), (다) 순수 헬륨의 기체 압력을 비교하세요(완전 이온화).

풀이

  1. (가) \(1/\mu = 1.42 + 0.2025 + 0.01 = 1.63\), \(\mu = 0.61\).
    결과 2.3.1.
  2. (나) \(1/\mu = 0.68 + 0.48 + 0.01 = 1.17\), \(\mu = 0.85\).
    수소가 절반 넘게 탔다.
  3. (다) \(\mu = 4/3\). 압력 비 \(P \propto 1/\mu\): 1 : 0.72 : 0.46.
    입자 수가 줄면 같은 조건의 압력이 준다.

의미

수소가 타면 같은 조건에서 압력이 30% 가까이 떨어집니다. 압력이 모자라면 중심은 수축해 온도를 올려 다시 버팁니다. 수소를 다 쓴 헬륨 핵은 압력이 처음의 절반 아래라, 핵만 계속 수축하며 뜨거워지는 적색거성 단계로 갑니다.

먼저 예상해 보기. 탄소·산소 백색왜성과 무거운 별의 철 핵은 찬드라세카르 질량이 같을까요?

문제 2. 찬드라세카르 질량은 \(M_{\text{Ch}} \approx 5.83/\mu_e^2\ M_\odot\)입니다. 탄소·산소 백색왜성(\(\mu_e = 2\))과 철-56 핵(양성자 26개, 질량수 56)의 값은?

풀이

  1. 탄소·산소: \(5.83/4 = 1.46\,M_\odot\).
    탄소-12, 산소-16 모두 핵자 2개당 전자 1개.
  2. 철-56: \(\mu_e = 56/26 = 2.15\), \(M_{\text{Ch}} = 5.83/4.64 = 1.26\,M_\odot\).
    중성자가 더 많아 전자당 질량이 크다.

검산

\(\mu_e\)가 8% 크면 \(M_{\text{Ch}}\)는 \(1/1.08^2 = 0.86\)배, 곧 14% 작습니다. 철 핵이 탄소·산소 백색왜성보다 작은 질량에서 무너진다는 결론과 같습니다. 실제 무거운 별의 철 핵은 뜨거워 조금 더 큰 질량까지 버팁니다.

이해 확인

순수 수소(\(X = 1\))로 된 축퇴 천체가 있다면 \(\mu_e\)와 찬드라세카르 질량은?

답

\(\mu_e = 1\), \(M_{\text{Ch}} = 5.83\,M_\odot\). 전자당 질량이 작을수록 같은 질량에 전자가 많아 축퇴압이 더 많은 질량을 받칠 수 있습니다.
