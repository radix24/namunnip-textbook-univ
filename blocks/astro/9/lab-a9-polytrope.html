Lane-Emden 방정식을 풀어 폴리트로프 별 만들기

실습 · 폴리트로프

목표

폴리트로프 지수 n을 바꾸며 Lane-Emden 방정식을 수치로 풀고, 표면 위치 ξ₁과 중심/평균 밀도 비를 구합니다. 성취기준 [천우9-01-03].

준비

브라우저가 4차 Runge-Kutta 방법(간격 0.002)으로 \(\theta'' = -\theta^n - 2\theta'/\xi\)를 중심 근처 급수 해 \(\theta \approx 1 - \xi^2/6\)에서 출발해 적분합니다. 파란 선이 θ(온도에 비례), 빨간 점선이 θⁿ(밀도에 비례)입니다.

절차

  1. n = 0, 1, 1.5, 3, 4로 바꾸며 ξ₁과 밀도 비를 기록합니다.
  2. n = 0과 1의 결과를 해석해 \(\sqrt6\), π와 비교합니다.
  3. n을 4.9까지 올리면 무엇이 일어나는지 봅니다.

기대 결과

  • n = 0: ξ₁ = 2.4495(=√6), 밀도 비 1.00. n = 1: 3.1416(=π), 3.29.
  • n = 1.5: 3.6538, 5.99. n = 3: 6.8968, 54.18. n = 4: 14.97, 622.
  • n이 5에 가까워지면 ξ₁이 급격히 커져 ξ = 40 안에서 표면에 닿지 않습니다.

분석

  1. n이 커질수록 밀도 곡선(빨간 점선)이 중심에 몰리는 모습을 설명하세요.
  2. 태양(평균 밀도 1,410 kg/m³)을 n = 3으로 보면 중심 밀도는 얼마입니까(1.3절 예제)?
  3. n = 1.5인 대류 별과 n = 3인 복사 별에서 중심 온도/평균 온도 비는 어느 쪽이 큽니까?
