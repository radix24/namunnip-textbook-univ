천체 좌표 보정(astrometry)으로 영상에 좌표 부여하기

본문 · 4.3절
이 절에서 배울 것
  • WCS 머리말(CRPIX, CRVAL, CD 행렬)과 접평면 투영을 안다.
  • 픽셀 좌표를 적경·적위로 바꾸는 계산을 한다.
  • 기준 성표(Gaia)와 맞춰 WCS를 구하는 절차를 안다.
먼저 알아야 할 것
  • FITS 머리말 (1.2절), 천구 좌표 (천우1 1.1절).

픽셀을 하늘 좌표로

영상의 (x, y) 픽셀이 하늘의 어느 (α, δ)인지 알려 주는 규칙을 WCS(World Coordinate System)라 하며, FITS 머리말에 적습니다. 이 규칙을 구하는 일이 천체 좌표 보정입니다. 좌표가 있어야 다른 파장의 영상과 겹치고, 성표와 비교하고, 새 천체를 보고할 수 있습니다.

4.3.1접평면 투영

망원경은 하늘의 구면을 평평한 검출기에 투영합니다. 기준점(시야 중심 근처의 \(\alpha_0, \delta_0\))에서 구에 접하는 평면으로 중심 투영한 것이 그노몬(TAN) 투영이고, 접평면 좌표 \((\xi, \eta)\)는

\[ \xi = \frac{\cos\delta\sin(\alpha - \alpha_0)}{\cos c}, \quad \eta = \frac{\cos\delta_0\sin\delta - \sin\delta_0\cos\delta\cos(\alpha - \alpha_0)}{\cos c} \]

(\(\cos c = \sin\delta_0\sin\delta + \cos\delta_0\cos\delta\cos(\alpha - \alpha_0)\))입니다.

4.3.2WCS 키워드

  • CTYPE1 = 'RA---TAN', CTYPE2 = 'DEC--TAN': 투영 종류.
  • CRPIX1, CRPIX2: 기준 픽셀(1부터 셈).
  • CRVAL1, CRVAL2: 기준 픽셀의 \(\alpha_0, \delta_0\)(도).
  • CD1_1, CD1_2, CD2_1, CD2_2: 픽셀 차이를 접평면 좌표(도)로 바꾸는 행렬. 척도와 회전, 뒤집힘을 담는다: \(\begin{pmatrix}\xi\\\eta\end{pmatrix} = CD\begin{pmatrix}x - x_0\\y - y_0\end{pmatrix}\).
  • 광학 왜곡이 크면 SIP 다항식 계수(A_p_q, B_p_q)를 더한다.

북쪽이 위, 동쪽이 왼쪽이고 회전이 없으면 \(CD = \begin{pmatrix}-s&0\\0&s\end{pmatrix}\)입니다(\(s\)는 도/픽셀, 적경은 동쪽인 왼쪽으로 증가).

예제 4.3.1

픽셀 척도 0.35″, 회전 없음, 기준점 \(\delta_0 = +60°\)인 영상에서 기준 픽셀보다 오른쪽으로 100픽셀 떨어진 별의 적경 차는?

풀이. \(\xi = -100\times0.35″ = -35″\)(오른쪽은 서쪽). 작은 각에서 \(\Delta\alpha \approx \xi/\cos\delta_0 = -70″\), 시간 단위로 \(-4.67\) s입니다. 적위가 높을수록 같은 거리가 큰 적경 차가 됩니다.

4.3.3WCS 구하기

  1. 영상의 별을 검출하고 위치를 잰다(4.1절).
  2. 대략의 위치를 모르면 astrometry.net처럼 별 네 개의 기하 모양(쿼드)을 미리 만든 색인과 맞춰 하늘 위치를 찾는다(블라인드 풀이). 대략 알면 그 근처 성표 별과 바로 짝짓는다.
  3. Gaia 성표의 별(관측 날짜로 고유 운동 보정)과 짝지어 CRVAL, CD(와 SIP)를 최소제곱으로 맞춘다.
  4. 잔차 rms(보통 0.05~0.2″)를 확인하고 머리말에 쓴다.
from astropy.wcs import WCS
from astropy.io import fits
w = WCS(fits.getheader("field_wcs.fits"))
ra, dec = w.pixel_to_world_values(511.0, 383.0)   # 0부터 세는 픽셀 좌표
주의 astropy의 pixel_to_world는 0부터 세는 픽셀을, FITS의 CRPIX는 1부터 세는 픽셀을 씁니다. 또 성표 별의 고유 운동을 보정하지 않으면 수십 년 차이에서 수 ″의 오차가 생깁니다.
요약
  1. WCS: CRPIX(기준 픽셀), CRVAL(그 좌표), CD 행렬(척도·회전), 투영(TAN), 왜곡(SIP).
  2. 접평면 좌표 \((\xi, \eta) = CD(x - x_0, y - y_0)\), 적경 차 \(\approx \xi/\cos\delta\).
  3. 블라인드 풀이(쿼드 색인) 또는 성표와 짝지어 최소제곱으로 맞춘다.
  4. Gaia 고유 운동 보정, 0·1 시작 차이에 주의.

4.3.4연습문제

기본

  1. CRVAL1, CRVAL2는 무엇입니까?
    답

    기준 픽셀의 적경과 적위(도).

  2. 픽셀 척도 1″, 회전 없음이면 CD1_1과 CD2_2는(도 단위)?
    답

    \(-2.78\times10^{-4}\)과 \(+2.78\times10^{-4}\).

응용

  1. 적위 0°에서 기준 픽셀보다 왼쪽으로 50픽셀(척도 0.5″) 떨어진 별의 적경 차는?
    답

    \(+25″\) = \(+1.67\) s.

  2. 잔차 rms가 0.1″이고 별 50개로 맞췄다면 기준점 위치의 불확도는 대략?
    답

    \(0.1/\sqrt{50} \approx 0.014″\).
