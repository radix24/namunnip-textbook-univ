겹친 두 별의 밝기 가르기

예제 · PSF 측광 · 정규 방정식
문제 해결 전략 · 두 별을 함께 맞추기
  1. 두 별의 PSF \(P_1\), \(P_2\)를 픽셀마다 적는다.
  2. 정규 방정식의 계수 \(\sum P_kP_l\)과 우변 \(\sum P_kd\)를 계산한다.
  3. 2×2 연립 방정식을 풀고, 구경 측광 결과와 비교한다.
먼저 예상해 보기. 한 픽셀 떨어진 두 별에서, 밝은 별 둘레 세 픽셀을 더하면 그 별의 밝기를 얼마나 크게 잴까?

문제. 한 줄 영상(픽셀 0~5)에서 PSF는 \((0.25, 0.5, 0.25)\)이다. 별 1은 픽셀 2, 별 2는 픽셀 3에 중심이 있고, 배경을 뺀 값은 \(d = (0, 25, 65, 55, 15, 0)\)입니다(잡음 없음). (가) 정규 방정식을 세우고 두 밝기를 구하여라. (나) 픽셀 1~3을 더한 구경 측광 값과 비교하여라.

풀이

  1. \(P_1 = (0, 0.25, 0.5, 0.25, 0, 0)\), \(P_2 = (0, 0, 0.25, 0.5, 0.25, 0)\).
    중심 픽셀에 0.5.
  2. \(\sum P_1^2 = \sum P_2^2 = 0.375\), \(\sum P_1P_2 = 0.125 + 0.125 = 0.25\).
    겹치는 픽셀 2, 3.
  3. \(\sum P_1d = 6.25 + 32.5 + 13.75 = 52.5\), \(\sum P_2d = 16.25 + 27.5 + 3.75 = 47.5\).
    우변.
  4. \(0.375F_1 + 0.25F_2 = 52.5\), \(0.25F_1 + 0.375F_2 = 47.5\). 행렬식 0.078125.
    크라메르 공식.
  5. \(F_1 = (52.5\times0.375 - 0.25\times47.5)/0.078125 = 100\), \(F_2 = (0.375\times47.5 - 0.25\times52.5)/0.078125 = 60\).
    정확히 되살아남.
  6. (나) 구경 측광: \(25 + 65 + 55 = 145\). 별 2의 빛 45가 섞여 45% 크게 잰다.
    \(60\times(0.25 + 0.5)\).

의미

구상성단 중심이나 은하면 영상에서 구경 측광은 이웃 별 때문에 체계적으로 밝게 잰다. PSF 측광은 모양을 알고 있다는 정보로 겹친 빛을 나눠 준다. 허블 우주망원경으로 구상성단의 색등급도(천우12 3.1절)를 중심부까지 그릴 수 있는 것도 이 방법 덕분이다.

검산

\(100P_1 + 60P_2 = (0, 25, 65, 55, 15, 0)\)으로 자료와 정확히 같아 잔차가 0이다. 전체 합 \(160 = 100 + 60\)도 맞다.

이해 확인

픽셀 잡음이 \(\sigma\)일 때, 겹친 별 1의 밝기 오차는 외톨이일 때의 몇 배인가? (\(\sigma_{F_1}^2 = \sigma^2(A^{-1})_{11}\))

답

\((A^{-1})_{11} = 0.375/0.078125 = 4.8\), 외톨이는 \(1/0.375 = 2.67\). 분산 1.8배, 오차 1.34배. 겹친 별은 밝기를 나눠 갖는 만큼 덜 정확하다.
