한 줄 영상의 상호상관으로 별 이동 구하기

예제 · 상호상관 · 포물선 맞춤
문제 해결 전략 · 상관 봉우리 찾기
  1. 모든 이동 \(u\)에 대해 \(c(u) = \sum_n f(n)g(n + u)\)를 계산한다.
  2. 가장 큰 \(c\)의 위치가 정수 이동이다.
  3. 양옆 값으로 포물선을 맞춰 픽셀보다 작은 이동을 더한다.
먼저 예상해 보기. 두 번째 영상의 별 밝기 분포가 오른쪽으로 치우쳤다면, 이동은 정수보다 클까요 작을까요?

문제. 8픽셀짜리 한 줄 영상 \(f = (0, 1, 4, 1, 0, 0, 0, 0)\)과 다음 노출 \(g = (0, 0, 0, 1, 3, 2, 0, 0)\)이 있습니다(픽셀 번호 0~7). (가) \(u = 0\)~4에서 \(c(u)\)는? (나) 정수 이동과 포물선 맞춤으로 구한 이동은? (다) 무게중심 차이와 비교하세요.

풀이

  1. (가) \(c(0) = 4\times0 + 1\times1 = 1\)… 차례로 계산하면 \(c = (1, 7, 15, 11, 2)\).
    예: \(c(2) = f_1g_3 + f_2g_4 + f_3g_5 = 1 + 12 + 2 = 15\).
  2. (나) 봉우리는 \(u = 2\). \(\delta = (7 - 11)/(2(7 - 30 + 11)) = -4/(-24) = 0.17\). 이동 2.17픽셀.
    3.3.3절의 식.
  3. (다) 무게중심: \(f\)는 \((1 + 8 + 3)/6 = 2.00\), \(g\)는 \((3 + 12 + 10)/6 = 4.17\). 차이 2.17픽셀로 같다.
    두 방법이 같은 답.

의미

별 하나만 있으면 무게중심으로도 충분하지만, 상호상관은 영상 속 모든 천체의 정보를 한꺼번에 써서 어두운 별이 많은 영상이나 퍼진 성운에서도 이동을 구합니다. 우주망원경의 지향 흔들림을 재거나, 태양 영상에서 흑점의 움직임을 추적할 때 이 방법을 씁니다.

검산

\(g\)의 밝기가 4번(3)보다 5번(2) 쪽에 더 있어 정수 이동 2보다 조금 크게 나와야 하는데, 0.17만큼 크게 나왔습니다. 두 영상의 전체 밝기(6)가 같으니 밝기 차이로 인한 치우침은 없습니다.

이해 확인

\(g\)의 모든 값을 두 배로 하면(노출 두 배) (나)의 이동은 바뀝니까?

답

바뀌지 않습니다. \(c\)가 모두 두 배가 되어 포물선 식의 분자와 분모가 같이 두 배가 됩니다.
