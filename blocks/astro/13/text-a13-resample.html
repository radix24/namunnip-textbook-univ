보간과 재표본화: 영상을 옮기고 돌리고 늘릴 때

본문 · 1.3절
이 절에서 배울 것
  • 최근접, 쌍선형, 고차(sinc, 3차) 보간을 비교한다.
  • 쌍선형 보간 값을 손으로 계산한다.
  • 보간이 잡음을 줄여 보이게 하고 이웃 픽셀끼리 상관시키는 효과를 계산한다.
  • 픽셀 크기를 바꿀 때 전체 빛(플럭스)을 보존하는 방법과 드리즐을 안다.
먼저 알아야 할 것
  • 표본화 (1.1절), 영상 정합 (4.2절).

1.3.1왜 재표본화가 필요한가

여러 장을 합성하려면 영상을 서로 맞게 옮기고(정합, 4.2절), 하늘 좌표 격자에 맞게 돌리고 늘려야 합니다(4.3절). 새 격자의 픽셀 중심은 대개 옛 픽셀 사이에 떨어지므로, 그 자리의 값을 이웃 픽셀로 어림해야 합니다. 이것이 보간입니다.

1.3.2보간 방법

  • 최근접: 가장 가까운 픽셀 값을 그대로 쓴다. 빠르지만 위치가 최대 반 픽셀 어긋나고 계단이 생긴다.
  • 쌍선형: 둘러싼 네 픽셀을 거리에 따라 섞는다. 픽셀 안의 위치 \((x, y)\)(0~1)에서 \[f = (1 - x)(1 - y)f_{00} + x(1 - y)f_{10} + (1 - x)yf_{01} + xyf_{11}.\]
  • sinc와 3차: 나이퀴스트 조건을 만족하는 영상이면 sinc 보간이 원래 연속 영상을 되살린다. 실제로는 sinc를 몇 픽셀에서 끊은 란초시 커널이나 3차 스플라인을 쓴다. 밝은 별 옆에 작은 물결(링잉)이 생길 수 있다.

1.3.3보간은 잡음을 섞는다

픽셀 잡음이 서로 독립이고 표준편차 \(\sigma\)일 때, 가중치 \(w_i\)로 섞은 값의 잡음은 \(\sigma\sqrt{\sum w_i^2}\)입니다.

결과 1.3.1

쌍선형으로 반 픽셀씩(\(x = y = 0.5\)) 옮기면 네 가중치가 모두 1/4이므로 새 픽셀의 잡음은 \(\sigma\sqrt{4/16} = 0.5\sigma\)입니다.

잡음이 줄어든 것처럼 보이지만 정보가 늘어난 것은 아닙니다. 이웃 픽셀이 같은 옛 픽셀을 나눠 쓰므로 잡음이 서로 상관됩니다. 재표본화한 영상에서 픽셀값의 표준편차로 측광 오차를 재면 오차를 작게 잡게 되므로, 원래 영상에서 잡음을 재거나 상관을 보정해야 합니다.

1.3.4빛을 보존하기

픽셀값이 '픽셀당 전자 수'라면, 픽셀을 반 크기(넓이 1/4)로 나눌 때 값도 1/4로 줄여야 전체 빛이 보존됩니다. 보간은 '표면 밝기'를 옮기는 것이므로 넓이 비를 곱해야 합니다. 허블 우주망원경처럼 픽셀이 커 과소 표본인 영상은, 반 픽셀씩 어긋나게(디더링) 여러 장 찍은 뒤 옛 픽셀을 줄여 새 고운 격자에 떨어뜨려 더하는 드리즐로 해상도를 되찾습니다. 각 옛 픽셀이 새 픽셀과 겹친 넓이만큼 빛을 나눠 주므로 빛이 보존됩니다.

예제 1.3.1

네 픽셀 \(f_{00} = 10\), \(f_{10} = 20\), \(f_{01} = 30\), \(f_{11} = 40\)일 때 \((x, y) = (0.25, 0.5)\)의 쌍선형 보간 값은?

풀이. \(0.375\times10 + 0.125\times20 + 0.375\times30 + 0.125\times40 = 3.75 + 2.5 + 11.25 + 5 = 22.5\). 이 네 값은 평면 \(10 + 10x + 20y\) 위에 있으므로 \(10 + 2.5 + 10 = 22.5\)로 검산됩니다.

요약
  1. 최근접(빠름, 계단), 쌍선형(네 픽셀 섞기), sinc·란초시(정확, 링잉).
  2. 보간은 잡음을 \(\sigma\sqrt{\sum w_i^2}\)로 줄여 보이게 하고 이웃끼리 상관시킨다.
  3. 픽셀 넓이가 바뀌면 값에 넓이 비를 곱한다. 드리즐은 디더링 영상으로 해상도를 되찾는다.

1.3.5연습문제

기본

  1. 한 방향으로만 반 픽셀(\(x = 0.5\), \(y = 0\)) 옮기면 쌍선형 보간 후 잡음은 몇 배입니까?
    답

    가중치 0.5, 0.5이므로 \(\sqrt{0.5} = 0.71\)배.

  2. 픽셀 척도 0.4″의 영상을 0.2″ 격자로 다시 표본화했습니다. '픽셀당 전자 수' 영상이라면 값에 무엇을 곱해야 합니까?
    답

    넓이 비 \((0.2/0.4)^2 = 1/4\).

응용

  1. 최근접 보간으로 정합한 영상 여러 장을 합성하면 별상이 어떻게 됩니까?
    답

    영상마다 최대 반 픽셀씩 위치가 어긋난 채 더해져 별상이 조금 넓어지고 모양이 일그러집니다. 정밀 측광과 위치 측정에는 고차 보간이나 드리즐이 낫습니다.

  2. 우주선(cosmic ray)이 맞은 픽셀이 있는 영상을 sinc로 보간하면 어떤 문제가 생깁니까? 해결책은?
    답

    날카로운 한 픽셀이 주변으로 물결처럼 퍼져(링잉) 여러 픽셀을 오염시킵니다. 보간 전에 우주선을 찾아 가려 두고(4.2절의 자름), 가린 픽셀은 가중치 0으로 처리합니다.
