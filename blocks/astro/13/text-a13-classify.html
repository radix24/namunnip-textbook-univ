다중 분광 자료로 간단한 분류하기

본문 · 5.2절
이 절에서 배울 것
  • 띠별 반사율의 차이(분광 특성)로 지표를 구별한다.
  • 식생 지수 NDVI를 계산하고 해석한다.
  • 무감독(k-평균)·감독(최소 거리) 분류와 정확도 평가를 안다.
먼저 알아야 할 것
  • 방사 보정 (5.1절), 색지수 (천우3 1.3절).

색으로 땅을 나누기

별을 색지수로 분류하듯, 지표도 띠별 반사율로 나눌 수 있습니다. 식물은 엽록소가 빨간 빛을 흡수하고 잎 구조가 근적외선을 강하게 반사하며, 물은 근적외선을 거의 흡수하고, 흙은 파장에 따라 완만히 밝아집니다.

5.2.1식생 지수

\[ \text{NDVI} = \frac{\rho_{NIR} - \rho_{Red}}{\rho_{NIR} + \rho_{Red}} \]
예제 5.2.1

건강한 식물(근적외선 0.45, 적색 0.05), 물(0.02, 0.04), 맨흙(0.30, 0.25)의 NDVI는?

풀이. 식물 \(0.40/0.50 = 0.80\), 물 \(-0.02/0.06 = -0.33\), 흙 \(0.05/0.55 = 0.09\)입니다. 이처럼 NDVI 하나로도 세 지표가 뚜렷이 나뉩니다. 차와 합의 비라서 조명(그늘, 태양 각) 차이가 상당 부분 지워지는 장점이 있습니다.

5.2.2분류 방법

  • 특징 공간: 픽셀 하나를 띠 \(n\)개의 반사율로 된 \(n\)차원 점으로 본다. 같은 지표는 한 무리로 모인다.
  • 무감독 분류(k-평균): 무리 수 \(k\)를 정하고, 무작위 중심에서 시작해 '가장 가까운 중심에 배정 → 중심 다시 계산'을 반복. 나중에 각 무리가 무엇인지 사람이 이름을 붙인다.
  • 감독 분류: 지표를 아는 훈련 영역에서 무리별 평균(와 공분산)을 구한 뒤, 각 픽셀을 가장 가까운 평균(최소 거리) 또는 가능도가 가장 큰 무리(최대 가능도, 공분산 고려)에 배정. 요즘은 랜덤 포레스트, 신경망도 쓴다.
예제 5.2.2

무리 평균(적색, 근적외선)이 식물 (0.05, 0.45), 물 (0.04, 0.02), 흙 (0.25, 0.30)일 때 픽셀 (0.10, 0.35)는 최소 거리 분류로 무엇입니까?

풀이. 거리 제곱: 식물 \(0.0025 + 0.01 = 0.0125\), 물 \(0.0036 + 0.1089 = 0.1125\), 흙 \(0.0225 + 0.0025 = 0.025\). 가장 가까운 식물입니다(NDVI 0.56, 덜 무성한 식물이나 흙과 섞인 픽셀).

5.2.3정확도 평가

훈련에 쓰지 않은 검증 픽셀로 혼동 행렬(실제 무리 × 분류된 무리의 개수 표)을 만들고, 대각 성분의 합 ÷ 전체로 전체 정확도를 구합니다. 무리마다 놓친 비율(생산자 정확도)과 잘못 넣은 비율(사용자 정확도)도 봅니다. 천문학의 별·은하·퀘이사 색 분류에서 완전성과 순도를 따지는 것과 같습니다.

주의 한 픽셀에 여러 지표가 섞이면(혼합 픽셀) 어느 무리에도 잘 맞지 않습니다. 해상도가 낮을수록 심하며, 혼합 비율을 푸는 분광 분리(선형 혼합 모형)를 쓰기도 합니다.
요약
  1. 지표마다 띠별 반사율이 다르다: 식물은 근적외선 밝음, 물은 어두움.
  2. NDVI = (NIR − Red)/(NIR + Red): 식물 약 0.8, 흙 약 0.1, 물 음수.
  3. 무감독(k-평균)과 감독(최소 거리, 최대 가능도) 분류.
  4. 검증 자료의 혼동 행렬로 정확도를 평가한다.

5.2.4연습문제

기본

  1. NDVI의 범위는?
    답

    −1~+1.

  2. k-평균 분류에서 사람이 하는 일은?
    답

    무리 수를 정하고, 결과 무리에 지표 이름을 붙이는 일.

응용

  1. 근적외선 0.35, 적색 0.10의 NDVI는?
    답

    0.25/0.45 = 0.56.

  2. 검증 픽셀 200개 가운데 대각 성분 합이 172이면 전체 정확도는?
    답

    86%.
