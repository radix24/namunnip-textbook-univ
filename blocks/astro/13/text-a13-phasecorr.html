상호상관과 위상 상관으로 두 영상의 어긋남 구하기

본문 · 3.3절
이 절에서 배울 것
  • 상호상관의 최댓값 위치로 두 영상 사이의 평행 이동을 구한다.
  • 회선 정리로 상호상관을 FFT로 빠르게 계산한다.
  • 위상 상관이 봉우리를 날카롭게 만드는 원리를 안다.
  • 포물선 맞춤으로 픽셀보다 작은 이동을 구한다.
먼저 알아야 할 것
  • 2차원 푸리에 변환과 회선 정리 (3.1절), 영상 정합 (4.2절).

3.3.1상호상관

영상 \(g\)가 \(f\)를 \(\mathbf s\)만큼 옮긴 것이라면(\(g(\mathbf x) = f(\mathbf x - \mathbf s)\)), 상호상관

\[c(\mathbf u) = \sum_{\mathbf x} f(\mathbf x)\,g(\mathbf x + \mathbf u)\]

은 \(\mathbf u = \mathbf s\)에서 가장 큽니다. 별 목록 없이 영상 전체를 쓰므로 별이 적거나 은하처럼 퍼진 천체만 있어도 됩니다. \(N\times N\) 영상에서 모든 \(\mathbf u\)를 직접 계산하면 \(N^4\)번 곱해야 하지만, 회선 정리에 따라

결과 3.3.1 \[c = \mathcal F^{-1}\!\left[F^*G\right], \qquad F = \mathcal F[f],\ G = \mathcal F[g]\]

이므로 FFT 세 번(\(N^2\log N\)에 비례)으로 끝납니다.

3.3.2위상 상관

이동 정리에 따라 \(G(\mathbf k) = F(\mathbf k)e^{-2\pi i\mathbf k\cdot\mathbf s/N}\)이므로 이동 정보는 모두 위상에 있습니다. 진폭을 지워

\[R(\mathbf k) = \frac{F^*G}{|F^*G|} = e^{-2\pi i\mathbf k\cdot\mathbf s/N}\]

로 만든 뒤 역변환하면 \(\mathbf s\)에서 날카로운 델타 함수가 나옵니다. 저주파가 강한 천체 영상에서 상호상관 봉우리는 넓지만, 위상 상관 봉우리는 좁아 위치가 분명하고 두 영상의 밝기 차이(구름, 노출 시간)에도 흔들리지 않습니다. 대신 잡음이 지배하는 고주파까지 같은 무게로 쓰므로, 실제로는 높은 주파수를 줄이는 창을 곱합니다.

3.3.3픽셀보다 작은 이동

봉우리 픽셀 \(c_0\)와 양옆 \(c_{-1}\), \(c_{+1}\)에 포물선을 맞추면 꼭짓점은

\[\delta = \frac{c_{-1} - c_{+1}}{2(c_{-1} - 2c_0 + c_{+1})}\]

만큼 봉우리 픽셀에서 떨어져 있습니다. 두 방향에 따로 적용하면 0.1픽셀 정도의 정밀도를 얻습니다. 회전과 크기 차이는 진폭 스펙트럼을 극좌표(로그 반지름, 각)로 바꾸어 같은 방법으로 구할 수 있습니다.

예제 3.3.1

상호상관의 봉우리가 \(u = 5\)에서 0.90이고, \(u = 4\)에서 0.30, \(u = 6\)에서 0.50입니다. 이동은?

풀이. \(\delta = (0.30 - 0.50)/(2(0.30 - 1.80 + 0.50)) = -0.20/(-2.0) = 0.10\). 이동은 5.10픽셀입니다. 큰 쪽 이웃(\(u = 6\)) 쪽으로 조금 치우친 것이 맞습니다.

요약
  1. 상호상관의 봉우리 = 이동. FFT로 \(c = \mathcal F^{-1}[F^*G]\).
  2. 위상 상관 \(R = F^*G/|F^*G|\)은 날카로운 봉우리를 주고 밝기 차이에 강하다.
  3. 포물선 맞춤 \(\delta = (c_{-1} - c_{+1})/[2(c_{-1} - 2c_0 + c_{+1})]\)로 픽셀보다 작은 이동.

3.3.4연습문제

기본

  1. 2,048 × 2,048 영상에서 직접 상호상관과 FFT 방법의 계산량 비는 대략?
    답

    \(N^4/(3N^2\log_2N^2) = N^2/66 \approx 6\times10^4\)배. FFT가 수만 배 빠릅니다.

  2. 양옆 값이 같으면(\(c_{-1} = c_{+1}\)) 픽셀보다 작은 이동은?
    답

    0. 봉우리가 정확히 픽셀 위에 있습니다.

응용

  1. FFT 상호상관은 영상이 주기적으로 이어진다고 봅니다. 한쪽 끝의 밝은 별이 반대쪽 끝으로 넘어가 엉뚱한 봉우리를 만들지 않게 하려면?
    답

    영상 둘레를 0으로 채워(제로 패딩) 두 배 크기로 만들거나, 가장자리를 부드럽게 0으로 줄이는 창(예: 한 창)을 곱합니다.

  2. 우주선이 많은 영상 두 장을 위상 상관으로 맞출 때 생길 문제는?
    답

    우주선은 한 장에만 있어 상관에 기여하지 않지만, 위상 상관은 모든 주파수를 같은 무게로 쓰므로 날카로운 우주선의 고주파가 잡음을 키웁니다. 먼저 우주선을 지우거나 고주파를 줄이는 창을 씁니다.
