별 두 개의 이동으로 세 축 각속도 구하기

예제 · 별 추적기 · 각속도
문제 해결 전략 · 이동을 평행 이동과 롤로 나누기
  1. 시야 중심 기준 위치 \((x, y)\)와 이동 \((\Delta x, \Delta y)\)를 결과 6.4.1에 넣는다.
  2. 축 위에 있는 별부터 미지수를 하나씩 풀고, 남는 식으로 검산한다.
  3. 판 척도와 시간 간격으로 각속도로 바꾼다.
먼저 예상해 보기. 두 별의 이동이 서로 다르다면 그 차이는 무엇 때문일까요?

문제. 판 척도 70″/픽셀인 추적기에서 0.2초 간격의 두 영상 사이에, 별 A(위치 (300, 0))는 \((2.0, 1.6)\)픽셀, 별 B(위치 (0, 300))는 \((1.4, 1.0)\)픽셀 움직였습니다. (가) \(t_x\), \(t_y\), \(\theta\)는? (나) 시선에 수직인 각속도와 롤 각속도는?

풀이

  1. (가) A: \(\Delta x = t_x - 0 = 2.0\) → \(t_x = 2.0\). B: \(\Delta y = t_y + 0 = 1.0\) → \(t_y = 1.0\).
    축 위의 별은 한 항이 0.
  2. A의 \(\Delta y\): \(1.0 + 300\theta = 1.6\) → \(\theta = 0.002\) rad.
    지렛대 팔 300픽셀.
  3. 검산: B의 \(\Delta x = 2.0 - 300\times0.002 = 1.4\). 맞다.
    미지수 3, 식 4.
  4. (나) 수직: \(\sqrt{2.0^2 + 1.0^2} = 2.24\)픽셀 × 70″ = 157″를 0.2초에 → 783″/s ≈ 0.22°/s. 롤: 0.002 rad = 0.115°를 0.2초에 → 0.57°/s.
    1 rad = 57.3°.

의미

별 두 개면 세 축의 회전을 모두 구할 수 있고, 남는 식 하나가 검산(또는 잘못 대응된 별 찾기)에 쓰입니다. 실제 추적기는 별 10~30개로 최소제곱을 풀어 각속도와 그 오차를 함께 내고, 이것이 자세 제어기의 되먹임으로 들어갑니다.

검산

\(\theta = 0.002\) rad이면 반지름 300픽셀의 별이 접선 방향으로 0.6픽셀 움직여야 하는데, A는 \(y\) 방향으로, B는 \(-x\) 방향으로 각각 0.6픽셀씩 평행 이동과 다르게 움직였습니다. 반시계 방향 회전의 모습과 맞습니다.

이해 확인

노출 시간이 0.1초라면 A의 별상은 몇 픽셀 끌립니까?

답

0.2초에 \(\sqrt{2.0^2 + 1.6^2} = 2.56\)픽셀이므로 0.1초에 약 1.3픽셀.
