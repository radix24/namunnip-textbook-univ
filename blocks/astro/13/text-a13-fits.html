FITS 형식과 머리말 정보 읽기

본문 · 1.2절

40년 전 천문대에서 찍은 영상 파일을 오늘 파이썬으로 그대로 열 수 있을까? 일상의 그림 파일 형식은 그사이 여러 번 바뀌었다. 천문학자들은 영상과 함께 노출 시간, 필터, 관측 시각, 좌표 같은 정보를 어떻게 한 파일에 담아 왔을까?

먼저 알아야 할 것표 자료 읽기(천우6 1.2절)를 쓴다.

FITS(Flexible Image Transport System)는 1981년 천문학자들이 정한 자료 형식이다. 지금도 거의 모든 천문 영상, 스펙트럼, 표가 이 형식으로 오간다. 처음 질문의 답은, 사람이 읽을 수 있는 머리말과 기계가 읽는 자료를 한 파일에 담고 형식을 바꾸지 않아 40년 전 파일도 그대로 읽힌다는 것이다(그림 1).

1.2.1구조

FITS 파일은 머리말과 자료로 된 HDU(Header Data Unit)들로 이루어지며, 기본 HDU 하나와 확장 HDU 여러 개를 가질 수 있다. 머리말은 한 줄 80글자의 카드들로, 키워드 = 값 / 설명 꼴이며 END로 끝난다. 자료는 큰 끝(big-endian) 순서의 이진수 배열이다. 그리고 머리말과 자료 모두 2,880바이트, 곧 카드 36장 단위로 채운다.

1.2.2키워드

필수 키워드는 표준 FITS임을 밝히는 SIMPLE, 픽셀 자료형 BITPIX(8, 16, 32, −32 실수, −64 배정밀도), 차원 수 NAXIS, 각 축 길이 NAXIS1, NAXIS2이다. 관측 정보로는 UTC 관측 시각 DATE-OBS, 초 단위 노출 시간 EXPTIME, FILTER, OBJECT, AIRMASS, GAIN, RDNOISE가 흔하다. 또 좌표 정보 CTYPE1/2, CRPIX1/2, CRVAL1/2, CD1_1 등은 WCS(4.3절)를 이룬다. 한편 BZERO와 BSCALE은 물리 값 = BZERO + BSCALE × 저장 값의 변환을 정한다.

예제 1.2.1

16비트 부호 있는 정수(BITPIX = 16, −32,768~32,767)로 0~65,535의 CCD 값을 저장하려고 BZERO = 32768, BSCALE = 1을 쓴다. 저장 값이 −12,000이면 실제 ADU는 얼마인가? 1,024×1,024 영상의 자료 부분은 몇 바이트인가?

풀이. \(32768 + (-12000) = 20{,}768\) ADU이다. 자료는 \(1024^2\times2 = 2{,}097{,}152\)바이트이고, 2,880의 배수로 채우면 729블록, 곧 2,099,520바이트이다. 파이썬에서는 astropy로 다음과 같이 읽는다.

from astropy.io import fits
with fits.open("ngc1234_V_001.fits") as hdul:
    hdul.info()                       # HDU 목록
    h = hdul[0].header; d = hdul[0].data   # BZERO/BSCALE은 자동 적용
    print(h["EXPTIME"], h["FILTER"], h["DATE-OBS"], d.shape, d.dtype)

numpy 배열은 d[y, x], 곧 (행, 열) 순서이고 0부터 센다. 그러나 FITS 머리말의 픽셀 좌표(CRPIX 등)는 1부터 센다. 이 한 칸 차이는 흔한 실수의 원인이다.

주의머리말의 값은 관측 프로그램이 자동으로 적은 것이라 필터 바퀴 위치 오류나 시계 오차로 틀릴 수 있다. 그러므로 노출 시간, 필터, 시각 같은 중요한 값은 관측 일지와 대조하고, 처리 단계마다 HISTORY 카드로 무엇을 했는지 남긴다.
마무리

FITS는 80글자 머리말 카드와 이진 자료를 2,880바이트 블록으로 담으며, HDU를 여러 개 가질 수 있다. 필수 키워드는 SIMPLE, BITPIX, NAXIS, NAXISn이고, DATE-OBS, EXPTIME, FILTER 같은 관측 정보가 따른다. 물리 값은 BZERO + BSCALE × 저장 값이며, numpy는 [y, x] 순서로 0부터, FITS 좌표는 1부터 센다.

1.2.3연습문제

기본

  1. BITPIX = −32는 어떤 자료형인가?
    답

    32비트 부동소수점, 곧 단정밀도 실수이다.

응용

  1. BZERO = 100, BSCALE = 0.5, 저장 값 400이면 물리 값은 얼마인가?
    답

    \(100 + 0.5\times400 = 300\)이다.

  2. 2,048×4,096 영상을 BITPIX = −32로 저장하면 자료는 약 몇 MB인가?
    답

    \(2048\times4096\times4 = 33.6\times10^6\)바이트, 약 32 MiB이다.
