옛 성도의 좌표로 오늘 별 찾기

예제 · 세차 보정 · 회귀년
문제 해결 전략 · 세차 보정
  1. 기준 시점에서 지금까지 몇 년이 흘렀는지 센다.
  2. 연간 변화 \(\Delta\alpha = m + n\sin\alpha\tan\delta\), \(\Delta\delta = n\cos\alpha\)를 각초 단위로 구한다. 적경을 각도로 바꿔 사인·코사인을 계산한다(1시 = 15°).
  3. 햇수를 곱하고, 적경 변화는 시간 단위(15″ = 1초)로 바꾼다.
먼저 예상해 보기. 50년 전 성도에 적힌 시리우스의 좌표를 그대로 망원경에 넣으면, 시야 지름이 10′인 망원경 안에 시리우스가 들어올까요?

문제 1. 시리우스의 J2000.0 좌표는 적경 \(6^h45^m\), 적위 \(-16.7°\)입니다. 고유 운동은 무시하고, 세차만으로 50년 뒤(2050년) 좌표가 얼마나 바뀌는지 구하세요(\(m = 46.1''\), \(n = 20.0''\)).

풀이

  1. 적경을 각도로: \(6^h45^m = 6.75 \times 15° = 101.25°\). \(\sin\alpha = 0.981\), \(\cos\alpha = -0.195\), \(\tan(-16.7°) = -0.300\).
    삼각함수에는 각도(또는 라디안)를 넣는다.
  2. \(\Delta\alpha = 46.1 + 20.0\times0.981\times(-0.300) = 46.1 - 5.9 = 40.2''\)/년.
    남쪽 별(\(\tan\delta < 0\))이라 둘째 항이 음수.
  3. \(\Delta\delta = 20.0\times(-0.195) = -3.9''\)/년.
    \(\cos\alpha < 0\)이므로 적위는 남쪽으로 조금씩 간다.
  4. 50년이면 \(\Delta\alpha = 2010'' \approx 33.5'\) (적경 시간으로 \(2010/15 = 134\)초 ≈ 2분 14초), \(\Delta\delta = -195'' \approx -3.3'\).
    적경 1초 = 15″.

의미

적위 방향 어긋남은 3′ 정도지만, 적경 방향으로는 하늘에서 \(33.5'\times\cos\delta = 33.5'\times0.958 \approx 32'\), 곧 보름달 지름만큼 어긋납니다. 시야 10′인 망원경에서는 시리우스가 시야 밖에 있습니다. 그래서 망원경 제어 프로그램은 성도의 기준 시점에서 오늘 날짜로 좌표를 바꾼 뒤 가리킵니다.

문제 2. 춘분점은 해마다 50.3″씩 서쪽으로 움직입니다. 이 사실만으로 회귀년(춘분에서 춘분까지)이 항성년(365.2564일)보다 얼마나 짧은지 구하세요.

전략

태양이 황도를 따라 동쪽으로 가는 동안 춘분점이 서쪽에서 마중 나옵니다. 태양이 50.3″를 덜 가도 되므로, 그만큼의 시간이 줄어듭니다.

풀이

  1. 태양의 하루 이동량: \(1\,296\,000''/365.2564 = 3548.2''\)/일.
    별 기준 한 바퀴가 항성년.
  2. 줄어드는 시간: \(50.3/3548.2 = 0.01418\)일 = 20.4분.
    거리 ÷ 속력.
  3. 회귀년 ≈ \(365.2564 - 0.0142 = 365.2422\)일.
    측정값 365.2422일과 일치.

검산

세차 한 바퀴(25,800년) 동안 줄어든 시간을 모두 더하면 \(25\,800 \times 0.01418 \approx 366\)일, 곧 정확히 1년 남짓입니다. 춘분점이 한 바퀴를 마중 나오는 동안 회귀년을 25,800번 세면 항성년으로는 25,799번이 되는 셈이라, 1년이 남는 것이 맞습니다.

이해 확인

적경 \(18^h\), 적위 \(+60°\)인 별의 1년 적경 변화는? 적경 \(6^h\), 같은 적위인 별과 비교하세요.

답

\(\alpha = 270°\): \(\sin\alpha = -1\)이라 \(\Delta\alpha = 46.1 - 20.0\times1.732 = 11.5''\). \(\alpha = 90°\): \(46.1 + 34.6 = 80.7''\). 적위가 높은 별은 적경에 따라 변화량이 크게 다릅니다.
