오늘 밤 그 별은 언제, 얼마나 높이 뜨나

예제 · 항성시 · 시간각 · 고도
문제 해결 전략 · 날짜와 시각에서 별의 위치로
  1. 날짜에서 자정의 항성시를 어림한다: \(\text{LST}_{\text{자정}} \approx 0.0657^h\times\)(추분 뒤 날수).
  2. 표준시를 지방 평균시로 바꾸고(서울은 32분 빼기), 자정에서 몇 시간 떨어졌는지 더하거나 빼 그 시각의 항성시를 구한다.
  3. \(H = \text{LST} - \alpha\)를 −12시~+12시로 맞춘 뒤 각도로 바꾼다(1시 = 15°).
  4. \(\sin h = \sin\delta\sin\varphi + \cos\delta\cos\varphi\cos H\)로 고도를 구한다.

문제 1. 10월 1일(추분 뒤 8일), 서울(위도 37.6°)에서 베가(\(\alpha = 18^h37^m\), \(\delta = +38.8°\))는 KST 몇 시에 남중하며, 그때 고도는? 자정의 고도는?

풀이

  1. 자정의 항성시: \(0.0657\times8 = 0.53^h = 0^h32^m\).
    결과 1.5.2.
  2. 자정의 시간각: \(0^h32^m - 18^h37^m = -18^h05^m\), 24시를 더하면 \(+5^h55^m\). 자정에는 이미 남중한 지 5시간 55분(항성시) 지났다.
    −12시~+12시로 맞추기.
  3. 남중 시각: 자정에서 5시간 54분(태양시) 전 = 지방 평균시 18시 06분 = KST 18시 38분.
    \(5^h55^m\times0.99727 \approx 5^h54^m\), KST = 지방시 + 32분.
  4. 남중 고도: \(90° - 37.6° + 38.8° = 91.2°\). 90°를 넘으므로 천정에서 1.2° 북쪽을 지나며 고도는 88.8°.
    적위가 위도보다 크면 천정 북쪽으로 남중한다.
  5. 자정(\(H = 5^h55^m = 88.75°\)): \(\sin h = 0.627\times0.610 + 0.779\times0.792\times0.0218 = 0.382 + 0.013 = 0.396\), \(h \approx 23.3°\). 북서쪽 하늘에 낮게 있다.
    고도 식에 \(\cos H\)를 넣는다.

의미

가을 초저녁에 '여름의 대삼각형'(베가, 데네브, 알타이르)이 머리 위에 있는 까닭이다. 같은 별이 계절마다 다른 시각에 남중하는 것은 자정의 항성시가 하루 4분씩 늘기 때문이다.

먼저 예상해 보기. 12월 1일 저녁 9시에 오리온자리 베텔게우스는 벌써 남쪽 하늘 높이 있을까, 아직 동쪽에 낮게 있을까?

문제 2. 12월 1일(추분 뒤 69일) KST 21시, 서울에서 베텔게우스(\(\alpha = 5^h55^m\), \(\delta = +7.4°\))의 시간각과 고도를 구하여라.

풀이

  1. 자정의 항성시: \(0.0657\times69 = 4.53^h = 4^h32^m\).
    결과 1.5.2.
  2. KST 21시 = 지방 평균시 20시 28분, 자정보다 3시간 32분(태양시) 전 = 항성시로 3시간 33분 전. 그때 항성시 \(4^h32^m - 3^h33^m = 0^h59^m\).
    태양시 간격 ÷ 0.99727 = 항성시 간격.
  3. \(H = 0^h59^m - 5^h55^m = -4^h56^m = -74.0°\). 남중까지 약 5시간 남았다.
    음수면 남중 전(동쪽).
  4. \(\sin h = \sin7.4°\sin37.6° + \cos7.4°\cos37.6°\cos74.0° = 0.079 + 0.786\times0.276 = 0.295\), \(h \approx 17°\). 동쪽 하늘에 낮게 떠 있다.
    \(\cos H\)는 \(H\)의 부호와 무관.

검산

베텔게우스의 남중 시각은 21시 + 약 4시간 55분 ≈ 새벽 2시 무렵이다. 문제 1의 방법으로 바로 구해도 자정의 시간각 \(4^h32^m - 5^h55^m = -1^h23^m\), 곧 자정 뒤 1시간 23분(지방시 1시 23분, KST 1시 55분)에 남중한다. 두 답이 몇 분 안에서 맞다.

이해 확인

같은 날(12월 1일) 자정에 남중하는 별의 적경은?

답

지방 평균시 자정의 항성시인 약 \(4^h32^m\)이다. KST 자정이라면 지방시 23시 28분이므로 그보다 약 32분 작은 \(4^h00^m\) 근처이다. 황소자리 알데바란(\(4^h36^m\))은 그보다 약 36분 뒤에 남중한다.
