사다리꼴 공식과 Simpson 공식으로 적분하기

본문 · 4.2절

초신성 광도 곡선 아래의 넓이는 폭발이 내놓은 총 에너지이고, 필터 투과율과 별빛 스펙트럼을 곱한 곡선의 넓이는 검출기에 닿는 빛의 양이다. 그런데 이런 곡선의 원시함수를 식으로 구할 수 있는 경우는 드물다. 넓이를 조각으로 나누어 더한다면, 조각을 어떤 도형으로 어림해야 빨리 정확해질까?

먼저 알아야 할 것정적분과 리만 합(공통1 4단원)과 유한 차분(4.1절)을 쓴다.

4.2.1사다리꼴 공식

구간을 잘게 나누고 조각마다 넓이를 간단한 도형으로 어림해 더하는 것이 수치 적분이다. 먼저 \([a, b]\)를 \(n\)등분(간격 \(h = (b-a)/n\))하고 조각마다 곡선을 직선으로 이어 사다리꼴 넓이를 더하자.

\[\int_a^bf\,dx \approx h\left[\frac{f_0}{2} + f_1 + f_2 + \cdots + f_{n-1} + \frac{f_n}{2}\right]\]

오차는 \(-\frac{(b-a)h^2}{12}f''\) 정도로 \(h^2\)에 비례하므로, 구간 수를 2배로 하면 오차는 1/4이 된다.

4.2.2Simpson 공식

처음 질문의 답은 직선보다 곡선을 잘 따르는 도형을 쓰는 것이다. 조각 두 개씩 묶어 세 점을 지나는 포물선으로 어림하면(\(n\)은 짝수) 다음과 같다.

\[\int_a^bf\,dx \approx \frac h3\left[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 4f_{n-1} + f_n\right]\]

오차는 \(-\frac{(b-a)h^4}{180}f''''\)로 \(h^4\)에 비례해, 구간 수를 2배로 하면 1/16이 된다. 계산량은 사다리꼴과 거의 같은데 훨씬 정확하다(그림 1).

import math

def trap(f, a, b, n):
    h = (b - a) / n
    return h * (0.5 * f(a) + sum(f(a + i * h) for i in range(1, n)) + 0.5 * f(b))

def simpson(f, a, b, n):          # n은 짝수
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return s * h / 3

exact = 2.0                        # ∫0^π sin x dx
for n in (4, 8, 16, 32):
    et = abs(trap(math.sin, 0, math.pi, n) - exact)
    es = abs(simpson(math.sin, 0, math.pi, n) - exact)
    print(f"n={n:3d}  사다리꼴 오차 {et:.2e}   Simpson 오차 {es:.2e}")
n=  4  사다리꼴 오차 1.04e-01   Simpson 오차 4.56e-03
n=  8  사다리꼴 오차 2.58e-02   Simpson 오차 2.69e-04
n= 16  사다리꼴 오차 6.43e-03   Simpson 오차 1.66e-05
n= 32  사다리꼴 오차 1.61e-03   Simpson 오차 1.03e-06

\(n\)을 2배로 할 때마다 사다리꼴 오차는 약 4배(\(0.104 \to 0.0258\)), Simpson 오차는 약 16배(\(4.56\times10^{-3} \to 2.69\times10^{-4}\)) 줄어 예상한 차수와 맞는다.

4.2.3방법 고르기

함수가 매끄러우면 Simpson이나 더 높은 차수의 가우스 구적법이 유리하다. 자료가 등간격 관측값이면 사다리꼴이나 Simpson을 쓰고, 간격이 고르지 않으면 사다리꼴을 쓴다. 그런데 함수가 꺾이거나 끊기는 곳이 있으면 높은 차수의 장점이 사라지므로 그 점에서 구간을 나누어 적분한다. 그리고 결과를 믿으려면 \(n\)을 2배로 해 답이 얼마나 바뀌는지 본다. 바뀐 양이 오차의 어림이다.

예제 4.2.1

\(\int_0^1x^2dx\)를 \(n = 2\)로 사다리꼴 공식과 Simpson 공식으로 계산하여라.

풀이. \(h = 0.5\), \(f_0 = 0\), \(f_1 = 0.25\), \(f_2 = 1\)이다. 사다리꼴은 \(0.5\times(0/2 + 0.25 + 1/2) = 0.375\)로 참값 1/3보다 크다. 반면 Simpson은 \((0.5/3)(0 + 4\times0.25 + 1) = 1/3\)으로 정확하다. 포물선으로 어림하므로 2차 이하 다항식은(사실 3차까지도) 정확히 적분한다.

주의Simpson 공식은 구간 수 \(n\)이 짝수여야 한다. 홀수로 쓰면 마지막 조각이 빠져 답이 크게 틀린다.
마무리

수치 적분은 구간을 조각으로 나누어 넓이를 간단한 도형으로 어림해 더한다. 조각을 직선으로 잇는 사다리꼴 공식은 오차가 \(h^2\)에, 두 조각씩 포물선으로 잇는 Simpson 공식(\(n\) 짝수)은 \(h^4\)에 비례해, \(n\)을 2배로 하면 오차가 각각 1/4, 1/16로 준다. 꺾이는 점에서는 구간을 나누고, \(n\)을 2배로 해 답의 변화로 오차를 어림한다.

4.2.4연습문제

기본

  1. 사다리꼴 오차가 \(n = 10\)에서 \(10^{-3}\)이면 \(10^{-6}\)을 얻으려면 \(n\)은 대략 얼마여야 하는가?
    답

    \(h^2\)이 1/1000이 되어야 하므로 \(n \approx 10\times\sqrt{1000} = 316\)이다.

응용

  1. 사다리꼴 \(T(h)\)와 \(T(h/2)\)로 \([4T(h/2) - T(h)]/3\)을 계산하면 무엇이 되는가?
    답

    \(h^2\) 오차가 지워져 Simpson 공식과 같은 값(오차 \(h^4\))이 된다. 이것이 Richardson 외삽이다(4.4절).
