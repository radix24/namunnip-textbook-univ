사다리꼴 공식과 Simpson 공식으로 적분하기

본문 · 4.2절
이 절에서 배울 것
  • 사다리꼴 공식과 Simpson 공식을 유도하고 코드로 짠다.
  • 구간 수에 따른 오차가 \(h^2\), \(h^4\)로 줄어듦을 확인한다.
  • 적분 방법을 고르는 기준을 안다.
먼저 알아야 할 것
  • 정적분과 리만 합 (공통1 4단원), 유한 차분 (4.1절).

넓이를 조각으로 더하기

광도 곡선 아래 넓이(총 에너지), 필터를 통과한 별빛의 양, 별 내부의 질량처럼 천문학에는 적분할 일이 많지만 원시함수를 식으로 구할 수 있는 경우는 드뭅니다. 구간을 잘게 나누고 각 조각의 넓이를 간단한 도형으로 어림해 더하는 것이 수치 적분입니다.

4.2.1사다리꼴 공식

\([a, b]\)를 \(n\)등분(간격 \(h = (b-a)/n\))하고 조각마다 곡선을 직선으로 이어 사다리꼴 넓이를 더합니다.

\[ \int_a^bf\,dx \approx h\left[\frac{f_0}{2} + f_1 + f_2 + \cdots + f_{n-1} + \frac{f_n}{2}\right] \]

오차는 \(-\frac{(b-a)h^2}{12}f''\) 정도로 \(h^2\)에 비례합니다. 구간 수를 2배로 하면 오차는 1/4입니다.

4.2.2Simpson 공식

조각 두 개씩 묶어 세 점을 지나는 포물선으로 어림하면(\(n\)은 짝수)

\[ \int_a^bf\,dx \approx \frac h3\left[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 4f_{n-1} + f_n\right] \]

입니다. 오차는 \(-\frac{(b-a)h^4}{180}f''''\)로 \(h^4\)에 비례해, 구간 수를 2배로 하면 1/16이 됩니다. 계산량은 사다리꼴과 거의 같은데 훨씬 정확합니다.

import math

def trap(f, a, b, n):
    h = (b - a) / n
    return h * (0.5 * f(a) + sum(f(a + i * h) for i in range(1, n)) + 0.5 * f(b))

def simpson(f, a, b, n):          # n은 짝수
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return s * h / 3

exact = 2.0                        # ∫0^π sin x dx
for n in (4, 8, 16, 32):
    et = abs(trap(math.sin, 0, math.pi, n) - exact)
    es = abs(simpson(math.sin, 0, math.pi, n) - exact)
    print(f"n={n:3d}  사다리꼴 오차 {et:.2e}   Simpson 오차 {es:.2e}")
n=  4  사다리꼴 오차 1.04e-01   Simpson 오차 4.56e-03
n=  8  사다리꼴 오차 2.58e-02   Simpson 오차 2.69e-04
n= 16  사다리꼴 오차 6.43e-03   Simpson 오차 1.66e-05
n= 32  사다리꼴 오차 1.61e-03   Simpson 오차 1.03e-06

\(\int_0^\pi\sin x\,dx = 2\)에서 \(n\)을 2배로 할 때마다 사다리꼴 오차는 약 4배(\(0.104 \to 0.0258\)), Simpson 오차는 약 16배(\(4.56\times10^{-3} \to 2.69\times10^{-4}\)) 줄어 예상한 차수와 맞습니다. 아래 실습 카드에서 다른 함수로도 확인할 수 있습니다.

4.2.3방법 고르기

  • 함수가 매끄러우면 Simpson이나 더 높은 차수(가우스 구적법)가 유리하다.
  • 자료가 등간격 관측값이면 사다리꼴이나 Simpson을 쓴다. 간격이 고르지 않으면 사다리꼴을 쓴다.
  • 함수가 꺾이거나 끊기는 곳이 있으면 그 점에서 구간을 나누어 적분한다. 높은 차수의 장점이 사라지기 때문이다.
  • 결과를 믿으려면 \(n\)을 2배로 해 답이 얼마나 바뀌는지 본다. 바뀐 양이 오차의 어림이다.
주의 Simpson 공식은 구간 수 \(n\)이 짝수여야 합니다. 홀수로 쓰면 마지막 조각이 빠져 답이 크게 틀립니다.
요약
  1. 사다리꼴: 조각을 직선으로, 오차 \(\propto h^2\).
  2. Simpson: 두 조각씩 포물선으로(\(n\) 짝수), 오차 \(\propto h^4\).
  3. \(n\)을 2배로 하면 오차가 1/4, 1/16로 준다.
  4. \(n\)을 2배로 해 답의 변화로 오차를 어림한다.

4.2.4연습문제

기본

  1. 사다리꼴 공식으로 \(\int_0^1x^2dx\)를 \(n = 2\)로 계산하세요.
    답

    \(0.5\times(0/2 + 0.25 + 1/2) = 0.375\)(참값 1/3).

  2. Simpson 공식으로 같은 적분을 \(n = 2\)로 계산하세요.
    답

    \((0.5/3)(0 + 4\times0.25 + 1) = 1/3\). 2차 이하 다항식은 정확합니다.

응용

  1. 사다리꼴 오차가 \(n = 10\)에서 \(10^{-3}\)이면 \(10^{-6}\)을 얻으려면 \(n\)은 대략?
    답

    \(h^2\)이 1/1000이 되어야 하므로 \(n \approx 10\times\sqrt{1000} = 316\).

  2. Richardson 외삽: 사다리꼴 \(T(h)\)와 \(T(h/2)\)로 \([4T(h/2) - T(h)]/3\)을 계산하면 무엇이 됩니까?
    답

    \(h^2\) 오차가 지워져 Simpson 공식과 같은 값(오차 \(h^4\))이 됩니다.
