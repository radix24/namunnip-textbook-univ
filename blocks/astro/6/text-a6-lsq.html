최소제곱법으로 관측 자료에 직선과 곡선 맞추기

본문 · 6.1절

은하 일곱 개의 거리와 후퇴 속도를 찍으면 점들이 대체로 한 직선 둘레에 놓이지만, 정확히 한 직선 위에 있지는 않다. 허블 상수는 그 직선의 기울기이다. 흩어진 점들에서 "가장 가까운 직선"은 무엇이고, 그 기울기는 얼마나 믿을 만할까?

먼저 알아야 할 것편미분과 극값(공통2 5단원), 평균과 표준편차(공통7 2단원), Python(1.1절)을 쓴다.

6.1.1직선 맞춤

관측값에는 늘 잡음이 섞여 있다. 그래도 거리와 후퇴 속도의 관계, 주기와 광도의 관계처럼 숨은 직선을 찾아야 한다. 처음 질문의 "가장 가까운 직선"을 정하는 표준적인 방법이 최소제곱법으로, 1805년 무렵 르장드르와 가우스가 소행성 궤도 계산을 위해 만들었다. 자료 \((x_i, y_i)\), \(i = 1, \dots, n\)에 직선 \(y = a + bx\)를 맞출 때, 각 점의 잔차 \(r_i = y_i - (a + bx_i)\)의 제곱합 \(S(a, b) = \sum r_i^2\)이 가장 작은 \(a\), \(b\)를 고른다.

결과 6.1.1 (최소제곱 직선) \[b = \frac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \qquad a = \frac{\sum y_i - b\sum x_i}{n}\]

유도. 극소에서 \(\partial S/\partial a = -2\sum r_i = 0\), \(\partial S/\partial b = -2\sum x_ir_i = 0\)이다. 풀어 쓰면 \(na + b\sum x_i = \sum y_i\), \(a\sum x_i + b\sum x_i^2 = \sum x_iy_i\)인 연립방정식이고, 이를 풀면 위의 해가 나온다. ∎

제곱을 쓰는 까닭은 양과 음의 잔차가 상쇄되지 않게 하고, 미분해 식으로 풀 수 있게 하기 위해서이다. 또 잡음이 정규분포를 따르면 최소제곱 해는 가장 그럴듯한(최대가능도) 해이기도 하다(천우10 5.1절).

6.1.2예, 허블 상수

# 가상 자료: 은하 거리(Mpc)와 후퇴 속도(km/s)
d = [10, 20, 35, 50, 70, 90, 120]
v = [820, 1310, 2650, 3420, 5100, 6150, 8500]
n = len(d)
sx, sy = sum(d), sum(v)
sxx = sum(x * x for x in d); sxy = sum(x * y for x, y in zip(d, v))
b = (n * sxy - sx * sy) / (n * sxx - sx * sx)     # 기울기
a = (sy - b * sx) / n                             # 절편
H0_origin = sxy / sxx                             # 원점을 지나는 직선의 기울기
res = [y - (a + b * x) for x, y in zip(d, v)]
s = (sum(r * r for r in res) / (n - 2)) ** 0.5
sb = s * (n / (n * sxx - sx * sx)) ** 0.5
print(f"직선 v = a + b d, a = {a:.0f} km/s, b = {b:.1f} ± {sb:.1f} km/s/Mpc")
print(f"원점을 지나는 직선, H0 = {H0_origin:.1f} km/s/Mpc")
직선 v = a + b d, a = 55 km/s, b = 69.8 ± 1.7 km/s/Mpc
원점을 지나는 직선, H0 = 70.5 km/s/Mpc

처음 질문의 둘째 부분, 곧 기울기를 얼마나 믿을지는 잔차의 흩어짐이 말해 준다. 잔차의 표준편차 \(s = \sqrt{\sum r_i^2/(n-2)}\)를 구하는데, 직선의 두 매개변수를 정하느라 자유도 2를 썼으므로 \(n - 2\)로 나눈다. 그러면 기울기의 불확도는 \(\sigma_b = s\sqrt{n/[n\sum x^2 - (\sum x)^2]}\)이다. 한편 허블-르메트르 법칙은 원점을 지나야 하므로 \(a = 0\)으로 두고 \(b = \sum xy/\sum x^2\)로 맞추기도 한다. 이렇게 물리적으로 정해진 조건이 있으면 맞춤에 넣는 것이 좋다.

6.1.3곡선 맞춤

같은 방법을 곡선으로 넓힐 수 있다. 먼저 \(y = Ax^k\)는 로그를 취하면 \(\log y = \log A + k\log x\)로 직선이 되므로, 케플러 제3법칙이나 질량-광도 관계를 이렇게 맞춘다. 다음으로 \(y = a_0 + a_1x + a_2x^2\) 같은 다항식도 매개변수에 대해 선형이라 같은 방법(정규 방정식)으로 푼다. 반면 가우스 선 모양처럼 매개변수가 비선형으로 들어가면 반복 계산(scipy.optimize.curve_fit)으로 푼다.

예제 6.1.1

점 (0, 1), (1, 3), (2, 5)에 맞춘 직선을 결과 6.1.1로 구하여라.

풀이. \(n = 3\), \(\sum x = 3\), \(\sum y = 9\), \(\sum x^2 = 5\), \(\sum xy = 13\)이므로 \(b = (3\times13 - 3\times9)/(3\times5 - 9) = 2\), \(a = (9 - 6)/3 = 1\)이다. 따라서 \(y = 1 + 2x\)이며, 세 점이 한 직선 위에 있으므로 잔차가 모두 0이다.

주의점마다 오차가 다르면 각 잔차를 그 점의 오차 \(\sigma_i\)로 나눈 \(\chi^2 = \sum(r_i/\sigma_i)^2\)을 최소화한다(가중 최소제곱, 6.3절). 또 동떨어진 점 하나(이상값)가 결과를 크게 끌 수 있으므로, 맞춘 뒤 잔차를 그려 확인한다.
마무리

최소제곱법은 잔차 제곱합 \(\sum(y_i - a - bx_i)^2\)을 최소로 하는 직선을 고르며, 그 해는 \(b = [n\sum xy - \sum x\sum y]/[n\sum x^2 - (\sum x)^2]\), \(a = (\sum y - b\sum x)/n\)이다. 기울기의 불확도는 자유도 \(n - 2\)로 구한 잔차 표준편차에서 얻고, 원점을 지나는 것 같은 물리적 조건은 맞춤에 넣는다. 로그 변환과 다항식으로 곡선에 넓히며, 맞춘 뒤에는 잔차를 그려 확인한다.

6.1.4연습문제

기본

  1. 원점을 지나는 직선 맞춤에서 \(b = \sum xy/\sum x^2\)임을 보여라.
    답

    \(S = \sum(y - bx)^2\)에서 \(dS/db = -2\sum x(y - bx) = 0\)이므로 \(b\sum x^2 = \sum xy\)이다.

응용

  1. 케플러 제3법칙 \(P = Ka^k\)를 맞추려면 무엇에 직선을 맞춰야 하는가?
    답

    \(\log P = \log K + k\log a\)이므로 \((\log a, \log P)\)에 직선을 맞춘다. 1.2절 자료로 하면 \(k \approx 1.500\)이다.

  2. 같은 범위, 같은 잡음에서 점 수를 4배로 늘리면 기울기 불확도는 대략 몇 배가 되는가?
    답

    약 1/2배(\(1/\sqrt n\))이다.
