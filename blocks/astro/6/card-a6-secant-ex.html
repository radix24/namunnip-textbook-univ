Wien 변위 법칙의 상수를 할선법으로 구하기

예제 · 할선법 · 초월방정식
문제 해결 전략 · 근 찾기 문제로 바꾸기
  1. 구하려는 조건을 \(f(x) = 0\) 꼴로 쓴다.
  2. \(f\)의 부호가 바뀌는 곳 근처에서 처음 두 점을 고른다.
  3. 연속된 두 값의 차가 원하는 정밀도보다 작아지면 멈추고, \(f(x)\)가 0에 가까운지 확인한다.
먼저 예상해 보기. \(\lambda_{\max}T = 2.898\times10^{-3}\) m·K의 2.898은 어디서 나온 수일까?

문제. 파장으로 쓴 Planck 함수 \(B_\lambda \propto \lambda^{-5}/(e^{x} - 1)\)(\(x = hc/\lambda kT\))의 봉우리 조건은 \(x = 5(1 - e^{-x})\)이다. 할선법으로 \(x\)를 구하고 Wien 상수 \(b = hc/(kx)\)를 계산하여라.

import math

f = lambda x: x - 5 * (1 - math.exp(-x))     # Planck 함수 봉우리 조건

x0, x1 = 4.0, 5.0
for n in range(1, 8):
    x2 = x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0))
    print(f"{n}: x = {x2:.12f}   f(x) = {f(x2):+.1e}")
    x0, x1 = x1, x2
    if abs(x1 - x0) < 1e-14:
        break

h, c, k = 6.62607015e-34, 2.99792458e8, 1.380649e-23
print(f"Wien 상수 b = hc/(k x) = {h * c / (k * x1):.6e} m K")
1: x = 4.964240184367   f(x) = -8.4e-04
2: x = 4.965113687178   f(x) = -5.3e-07
3: x = 4.965114231753   f(x) = +8.3e-12
4: x = 4.965114231744   f(x) = +0.0e+00
5: x = 4.965114231744   f(x) = +0.0e+00
Wien 상수 b = hc/(k x) = 2.897772e-03 m K

풀이

  1. 봉우리 조건 유도: \(B_\lambda \propto x^5/(e^x - 1)\)(\(\lambda \propto 1/x\))를 \(x\)로 미분해 0으로 두면 \(5(e^x - 1) = xe^x\), 곧 \(x = 5(1 - e^{-x})\).
    \(\lambda\)에 대한 극대는 \(x\)에 대한 극대와 같다.
  2. \(f(4) = -0.908\), \(f(5) = +0.034\)로 부호가 바뀌므로 4와 5에서 시작한다.
    근 근처의 두 점.
  3. 네 걸음 만에 \(x = 4.965114231744\), \(b = 2.8978\times10^{-3}\) m·K.
    할선법의 초선형 수렴.

의미

Wien 상수는 실험으로 잰 숫자가 아니라 Planck 함수에서 나온 수학적 결과이고, 그 핵심은 초월방정식 \(x = 5(1 - e^{-x})\)의 근 4.965이다. 도함수를 쓰지 않고도 몇 걸음 만에 기계 정밀도까지 구했다.

검산

\(x\)가 5에 가까운 까닭: \(e^{-x}\)가 작으므로 \(x \approx 5\), 한 번 고치면 \(5(1 - e^{-5}) = 4.966\)으로 거의 맞다. 고정점 반복 \(x \leftarrow 5(1 - e^{-x})\)도 이 문제에서는 잘 수렴한다. 상수 값도 교과서의 \(2.898\times10^{-3}\) m·K와 같다.

이해 확인

주파수로 쓴 Planck 함수 \(B_\nu \propto x^3/(e^x - 1)\)의 봉우리 조건과 그 근은? (같은 코드에서 5를 3으로)

답

\(x = 3(1 - e^{-x})\), 근 \(x \approx 2.821\). 그래서 \(B_\nu\)의 봉우리 주파수는 \(\nu_{\max} = 2.821kT/h\)이고, \(c/\nu_{\max} \ne \lambda_{\max}\)입니다(봉우리 위치는 어떤 변수로 그리느냐에 따라 다름).
