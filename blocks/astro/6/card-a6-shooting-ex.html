선형 경계값 문제는 두 번 쏘면 끝난다

예제 · 사격법 · 선형성
문제 해결 전략 · 선형 문제의 사격법
  1. 방정식이 선형이면 끝값 \(y(1)\)은 모르는 처음 기울기 \(s\)의 일차함수다.
  2. 아무 두 \(s\)로 쏘아 \(F(s)\)를 얻으면, 할선법 한 걸음이 정확한 답을 준다.
  3. 정확한 해가 있으면 비교해 검산한다.
먼저 예상해 보기. 할선법은 보통 여러 번 되풀이해야 합니다. 방정식이 선형이면 몇 번이면 될까요?

문제. \(y'' = y\), \(y(0) = 0\), \(y(1) = 1\)을 사격법으로 푸세요. 정확한 해는 \(y = \sinh x/\sinh 1\)입니다.

import math

def shoot(s, n=1000):
    """y'' = y, y(0) = 0, y'(0) = s 를 x = 1까지 RK4로 적분해 y(1)을 돌려준다"""
    y, p, h = 0.0, s, 1.0 / n
    for _ in range(n):
        k1 = (p, y)
        k2 = (p + 0.5 * h * k1[1], y + 0.5 * h * k1[0])
        k3 = (p + 0.5 * h * k2[1], y + 0.5 * h * k2[0])
        k4 = (p + h * k3[1], y + h * k3[0])
        y += h / 6 * (k1[0] + 2 * k2[0] + 2 * k3[0] + k4[0])
        p += h / 6 * (k1[1] + 2 * k2[1] + 2 * k3[1] + k4[1])
    return y

target = 1.0
s0, s1 = 0.0, 2.0
F0, F1 = shoot(s0) - target, shoot(s1) - target
s2 = s1 - F1 * (s1 - s0) / (F1 - F0)
print(f"추측 {s0}: F = {F0:+.6f},  추측 {s1}: F = {F1:+.6f}")
print(f"할선법 한 걸음: s = {s2:.10f},  F = {shoot(s2) - target:+.1e}")
print(f"정확한 답 1/sinh(1) = {1 / math.sinh(1):.10f}")
추측 0.0: F = -1.000000,  추측 2.0: F = +1.350402
할선법 한 걸음: s = 0.8509181282,  F = +1.1e-15
정확한 답 1/sinh(1) = 0.8509181282

풀이

  1. \(y'(0) = s\)로 쏘면 해는 \(y = s\sinh x\)이므로 \(y(1) = s\sinh1\), 곧 \(F(s) = s\sinh1 - 1\)은 \(s\)의 일차함수다.
    선형 방정식의 해는 처음 조건에 비례.
  2. \(s = 0\)에서 \(F = -1\), \(s = 2\)에서 \(F = 2\sinh1 - 1 = 1.3504\).
    수치 적분 결과와 같다.
  3. 직선 위의 두 점을 지나는 할선은 \(F\) 자체이므로 한 걸음에 \(s = 1/\sinh1 = 0.85092\).
    할선법이 정확해진다.

의미

비선형 문제(본문의 공기 저항)는 여러 번 되풀이해야 하지만, 선형 문제는 두 번 쏘고 한 번 고치면 끝납니다. 끝값의 오차 \(10^{-15}\)는 RK4의 적분 오차가 아니라 반올림 수준인데, 이 해는 매끄러워 1,000걸음 RK4의 오차(\(\sim h^4 = 10^{-12}\))도 이미 매우 작기 때문입니다.

검산

\(\sinh1 = 1.17520\)이므로 \(F(2) = 2.35040 - 1 = 1.35040\)으로 출력과 같습니다. 답 0.8509181282도 정확한 값과 10자리까지 같습니다.
