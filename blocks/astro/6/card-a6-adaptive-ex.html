이심률이 커지면 걸음 수는 얼마나 늘어나나

예제 · 적응 간격 · 계산량 어림
문제 해결 전략 · 걸음 수를 적분으로
  1. 한 바퀴의 걸음 수는 \(N = \oint dt/\Delta t\)이다.
  2. 궤도 위치를 이심 근점 이각 \(E\)로 쓰면 \(r = a(1 - e\cos E)\), \(dt = (r/a)\,dE\)(단위 \(a = GM = 1\)).
  3. \(\Delta t = \eta r^{3/2}\)을 넣으면 \(N = \eta^{-1}\oint r^{-1/2}dE\). 이것을 수치 적분한다.
먼저 예상해 보기. 이심률을 0.9에서 0.99로 올리면, 적응 간격으로 한 바퀴 도는 걸음 수는 10배 넘게 늘어날까?

문제. \(\eta = 0.0105\)로 적응 간격을 쓸 때 이심률 0, 0.5, 0.9, 0.99 궤도의 한 바퀴 걸음 수를 구하고, 근일점의 간격으로 고정 간격을 쓸 때와 비교하여라.

import math

def steps_per_orbit(e, eta, n=200000):
    """dt = eta r^1.5 일 때 한 바퀴 걸음 수 = (1/eta) ∮ r^(-1/2) dE  (a = GM = 1)"""
    s = 0.0
    for i in range(n):
        E = 2 * math.pi * (i + 0.5) / n
        s += (1 - e * math.cos(E)) ** -0.5
    return s * 2 * math.pi / n / eta

eta = 0.0105
for e in (0.0, 0.5, 0.9, 0.99):
    fixed = 2 * math.pi / (eta * (1 - e) ** 1.5)     # 근일점 간격으로 고정했을 때
    print(f"e = {e:4.2f}: 적응 {steps_per_orbit(e, eta):8.0f}걸음,  근일점 간격으로 고정하면 {fixed:10.0f}걸음")
e = 0.00: 적응      598걸음,  근일점 간격으로 고정하면        598걸음
e = 0.50: 적응      631걸음,  근일점 간격으로 고정하면       1693걸음
e = 0.90: 적응      797걸음,  근일점 간격으로 고정하면      18923걸음
e = 0.99: 적응     1090걸음,  근일점 간격으로 고정하면     598399걸음

풀이

  1. \(dt = r\,dE\): 케플러 방정식 \(M = E - e\sin E\)를 미분하면 \(dM = (1 - e\cos E)dE = r\,dE\), 평균 근점 이각 \(M\)은 시간에 비례(\(a = GM = 1\)이면 \(dM = dt\)).
    시간 대신 \(E\)로 적분하면 근일점 근처도 고르게 나뉜다.
  2. \(N = \eta^{-1}\oint r\cdot r^{-3/2}dE = \eta^{-1}\oint r^{-1/2}dE\).
    \(dt/\Delta t\).
  3. 이심률 0.9에서 적응 간격은 797걸음(본문의 실험과 같음), 0.99에서도 1,090걸음이다. 고정 간격은 각각 약 1만 9천, 60만 걸음이 필요하다.
    고정 간격 걸음 수 \(\propto(1 - e)^{-3/2}\).

의미

적응 간격의 걸음 수는 이심률에 거의 상관없이 원 궤도의 1~2배에 머문다. 고정 간격은 \((1 - e)^{-3/2}\)로 폭발한다. 혜성이나 태양 가까이 오는 소행성(\(e \sim 0.97\sim0.999\))을 적분할 때 적응 간격이 아니면 사실상 계산할 수 없는 까닭이다.

검산

\(e = 0\)이면 \(r = 1\)이라 \(N = 2\pi/\eta = 598\)로 두 방법이 같다. \(e = 0.9\)의 적응 걸음 수 797은 본문에서 RK4로 실제 적분할 때 센 걸음 수와 같다.

이해 확인

핼리 혜성(\(e = 0.967\))을 근일점 간격으로 고정해 적분하면 원 궤도보다 몇 배의 걸음이 필요한가?

답

\((1 - 0.967)^{-3/2} = 0.033^{-1.5} \approx 170\)배.
