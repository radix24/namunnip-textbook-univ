경계값 문제와 사격법

본문 · 5.4절

공기 저항이 있을 때 물체를 위로 쏘아 정확히 10초 뒤에 땅에 떨어지게 하려면 처음 속도가 얼마여야 할까? 지금까지의 궤도 적분은 처음 위치와 속도를 모두 알고 출발했다. 그런데 이 문제는 처음 높이와 10초 뒤 높이만 알고 처음 속도는 모른다. 출발 조건을 모르는데 어떻게 적분할까?

먼저 알아야 할 것Runge-Kutta 방법(5.1절)과 할선법(3.3절)을 쓴다.

5.4.1두 종류의 문제

처음 위치와 속도를 모두 알고 앞으로 나아가는 문제를 초기값 문제라 한다. 반면 처음 질문처럼 조건이 양 끝에 나뉘어 있는 문제를 경계값 문제라 한다. 천문학에도 이런 문제가 많다. 예를 들어 별의 구조는 중심에서 질량이 0이고 압력이 유한하며, 표면에서 압력이 0이라는 조건을 함께 만족해야 한다(천우9). 또 두 시각의 위치를 알 때 그 사이를 잇는 궤도를 찾는 궤도 결정(Lambert 문제, 천우11)도 그렇다. 이런 문제는 처음 조건 일부를 모르기 때문에 바로 적분할 수 없다.

5.4.2사격법

처음 질문의 답은 대포를 쏘아 과녁을 맞히는 사람처럼 하는 것이다. 모르는 처음 조건 \(s\)(여기서는 처음 속도)를 추측해 끝까지 적분하고, 끝에서 빗나간 양 \(F(s) = y_{\text{끝}}(s) - y_{\text{목표}}\)를 잰다. 그러면 문제가 \(F(s) = 0\)인 \(s\)를 찾는 근 찾기 문제가 되므로 할선법이나 이분법을 쓴다. 이것이 사격법이며, 함수 \(F\)를 한 번 계산할 때마다 미분방정식 적분이 한 번 들어간다.

5.4.3예, 공기 저항이 있는 수직 발사

속도의 제곱에 비례하는 공기 저항이 있으면 \(\ddot y = -g - kv|v|\)이고 해를 식으로 쓰기 어렵다. 10초 뒤 땅으로 돌아오게 하는 처음 속도를 사격법으로 찾자(\(k = 0.005\) m⁻¹).

g, k, T = 9.8, 0.005, 10.0      # 중력, 항력 계수(1/m), 비행 시간

def height_at_T(v0, n=2000):
    """처음 속도 v0로 쏜 물체의 t = T 높이 (RK4)"""
    y, v, dt = 0.0, v0, T / n
    f = lambda v: -g - k * v * abs(v)
    for _ in range(n):
        k1y, k1v = v, f(v)
        k2y, k2v = v + 0.5 * dt * k1v, f(v + 0.5 * dt * k1v)
        k3y, k3v = v + 0.5 * dt * k2v, f(v + 0.5 * dt * k2v)
        k4y, k4v = v + dt * k3v, f(v + dt * k3v)
        y += dt / 6 * (k1y + 2 * k2y + 2 * k3y + k4y)
        v += dt / 6 * (k1v + 2 * k2v + 2 * k3v + k4v)
    return y

print(f"항력 없을 때의 답 v0 = gT/2 = {g * T / 2:.2f} m/s")
a, b = 49.0, 80.0                      # 처음 두 추측
for i in range(1, 9):
    ya, yb = height_at_T(a), height_at_T(b)
    print(f"{i}  v0 = {b:9.5f} m/s  ->  y(T) = {yb:+.3e} m")
    if abs(yb) < 1e-9:
        break
    a, b = b, b - yb * (b - a) / (yb - ya)   # 할선법
항력 없을 때의 답 v0 = gT/2 = 49.00 m/s
1  v0 =  80.00000 m/s  ->  y(T) = +3.486e+01 m
2  v0 =  69.61903 m/s  ->  y(T) = +4.222e+00 m
3  v0 =  68.18838 m/s  ->  y(T) = -2.994e-01 m
4  v0 =  68.28312 m/s  ->  y(T) = +2.395e-03 m
5  v0 =  68.28237 m/s  ->  y(T) = +1.347e-06 m
6  v0 =  68.28237 m/s  ->  y(T) = -5.696e-12 m

공기 저항이 없으면 49 m/s면 되지만, 저항이 있으면 68.28 m/s가 필요하다. 할선법이 다섯 번 만에 \(10^{-11}\) m까지 맞췄다. 또 처음 추측으로 저항이 없을 때의 답을 쓴 것도 좋은 습관이다. 간단한 극한에서 얻은 답은 좋은 출발점이기 때문이다.

5.4.4주의할 점

적분이 불안정한 방향(예를 들어 별 표면 근처에서 바깥으로)이면 작은 차이가 크게 불어나 \(F(s)\)가 매끄럽지 않을 수 있다. 이때는 양 끝에서 안쪽으로 적분해 가운데에서 맞추는 방법을 쓴다. 또 모르는 처음 조건이 둘 이상이면 근 찾기가 여러 변수 문제가 되어 Newton 방법을 행렬로 넓힌다. 별 구조 계산의 표준 방법인 Henyey 방법은 아예 전체 격자를 한꺼번에 푼다.

예제 5.4.1

공기 저항이 없을 때 \(y(0) = 0\), \(y(T) = 0\)인 수직 발사의 처음 속도를 사격법 없이 구하고, 위 프로그램에서 49 m/s로 쏘면 \(F = 0\)이 되지 않는 까닭을 설명하여라.

풀이. \(y(T) = v_0T - \tfrac12gT^2 = 0\)에서 \(v_0 = gT/2 = 49\) m/s이다. 하지만 프로그램은 저항이 있는 운동을 적분하므로, 49 m/s로 쏘면 저항 때문에 덜 올라가고 일찍 떨어져 \(y(10) < 0\)이 된다(그림 1의 파랑, 약 −69 m). 그래서 이 값은 답이 아니라 할선법의 첫 추측으로만 쓰인다.

흔한 오해공기 저항이 있으면 올라가는 시간과 내려오는 시간이 같다고 생각하기 쉽다. 실제로는 올라갈 때 중력과 저항이 모두 아래로 작용해 빨리 느려지고, 내려올 때는 저항이 위로 작용해 천천히 떨어지므로 내려오는 시간이 더 길다.
마무리

조건이 양 끝에 나뉜 경계값 문제는 처음 조건 일부를 모르므로 바로 적분할 수 없다. 사격법은 모르는 처음 조건을 추측해 적분하고, 끝에서 빗나간 양 \(F(s)\)를 근 찾기로 0으로 만들어 이 문제를 푼다. 처음 추측은 간단한 극한의 답에서 얻으며, 별 구조(천우9)와 궤도 결정(천우11)에 쓰이고, 적분이 불안정하면 양쪽에서 쏘아 가운데에서 맞춘다.

5.4.5연습문제

기본

  1. 프로그램에서 \(k\)를 0으로 바꾸면 어떤 답을 내야 하는가?
    답

    49.00 m/s이다. 이것이 극한값 검산이다(1.3절).

응용

  1. 별 구조 계산에서 중심 압력을 추측해 바깥으로 적분했더니 표면(\(P = 0\))에 이르렀을 때 질량이 목표보다 컸다. 중심 압력을 어느 쪽으로 고쳐야 하는가? (같은 중심 온도)
    답

    대체로 중심 압력(밀도)이 크면 질량이 크게 나오므로 중심 압력을 낮춘다. 정확한 방향은 \(F(s)\)의 부호 변화를 보고 할선법이 알아서 정한다.
