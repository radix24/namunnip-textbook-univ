경계값 문제와 사격법

본문
이 절에서 배울 것
  • 처음 조건만 주는 초기값 문제와, 양 끝의 조건을 주는 경계값 문제를 구별한다.
  • 모르는 처음 조건을 추측해 적분하고, 끝 조건이 맞을 때까지 근 찾기로 고치는 사격법을 쓴다.
  • 사격법이 천문학의 별 구조 계산, 궤도 결정에 쓰이는 방식을 안다.
먼저 알아야 할 것
  • Runge-Kutta 방법 (5.1절), 할선법 (3.3절).

5.4.1두 종류의 문제

지금까지의 궤도 적분은 처음 위치와 속도를 모두 알고 앞으로 나아가는 초기값 문제였습니다. 그런데 많은 문제는 조건이 양 끝에 나뉘어 있습니다.

  • '10초 뒤에 땅에 다시 떨어지도록' 위로 쏘려면 처음 속도는? (\(y(0) = 0\), \(y(10) = 0\))
  • 별의 구조: 중심에서는 질량이 0이고 압력이 유한하며, 표면에서는 압력이 0이다(천우9).
  • 궤도 결정: 두 시각의 위치를 알 때 그 사이를 잇는 궤도는?(Lambert 문제, 천우11)

이런 경계값 문제는 처음 조건 일부를 모르기 때문에 바로 적분할 수 없습니다.

5.4.2사격법

대포를 쏘아 과녁을 맞히는 사람처럼 합니다. 모르는 처음 조건 \(s\)(예: 처음 속도)를 추측해 끝까지 적분하고, 끝에서 빗나간 양 \(F(s) = y_{\text{끝}}(s) - y_{\text{목표}}\)을 잽니다. 그러면 문제가 \(F(s) = 0\)인 \(s\)를 찾는 근 찾기 문제가 되므로, 할선법이나 이분법을 씁니다. 함수 \(F\) 한 번 계산에 미분방정식 적분이 한 번 들어갑니다.

5.4.3예: 공기 저항이 있는 수직 발사

속도의 제곱에 비례하는 공기 저항이 있으면 \(\ddot y = -g - kv|v|\)이고 해를 식으로 쓰기 어렵습니다. 10초 뒤 땅으로 돌아오게 하는 처음 속도를 사격법으로 찾습니다(\(k = 0.005\) m⁻¹).

g, k, T = 9.8, 0.005, 10.0      # 중력, 항력 계수(1/m), 비행 시간

def height_at_T(v0, n=2000):
    """처음 속도 v0로 쏜 물체의 t = T 높이 (RK4)"""
    y, v, dt = 0.0, v0, T / n
    f = lambda v: -g - k * v * abs(v)
    for _ in range(n):
        k1y, k1v = v, f(v)
        k2y, k2v = v + 0.5 * dt * k1v, f(v + 0.5 * dt * k1v)
        k3y, k3v = v + 0.5 * dt * k2v, f(v + 0.5 * dt * k2v)
        k4y, k4v = v + dt * k3v, f(v + dt * k3v)
        y += dt / 6 * (k1y + 2 * k2y + 2 * k3y + k4y)
        v += dt / 6 * (k1v + 2 * k2v + 2 * k3v + k4v)
    return y

print(f"항력 없을 때의 답 v0 = gT/2 = {g * T / 2:.2f} m/s")
a, b = 49.0, 80.0                      # 처음 두 추측
for i in range(1, 9):
    ya, yb = height_at_T(a), height_at_T(b)
    print(f"{i}: v0 = {b:9.5f} m/s  ->  y(T) = {yb:+.3e} m")
    if abs(yb) < 1e-9:
        break
    a, b = b, b - yb * (b - a) / (yb - ya)   # 할선법
항력 없을 때의 답 v0 = gT/2 = 49.00 m/s
1: v0 =  80.00000 m/s  ->  y(T) = +3.486e+01 m
2: v0 =  69.61903 m/s  ->  y(T) = +4.222e+00 m
3: v0 =  68.18838 m/s  ->  y(T) = -2.994e-01 m
4: v0 =  68.28312 m/s  ->  y(T) = +2.395e-03 m
5: v0 =  68.28237 m/s  ->  y(T) = +1.347e-06 m
6: v0 =  68.28237 m/s  ->  y(T) = -5.696e-12 m

공기 저항이 없으면 49 m/s면 되지만, 저항이 있으면 68.28 m/s가 필요합니다. 할선법이 다섯 번 만에 \(10^{-11}\) m까지 맞췄습니다. 처음 추측으로 '저항이 없을 때의 답'을 쓴 것도 좋은 습관입니다. 간단한 극한에서 얻은 답은 좋은 출발점입니다.

5.4.4주의할 점

  • 적분이 불안정한 방향(예: 별 표면 근처에서 바깥으로)이면 작은 차이가 크게 불어나 \(F(s)\)가 매끄럽지 않을 수 있습니다. 이때는 양 끝에서 안쪽으로 적분해 가운데에서 맞추는 방법을 씁니다.
  • 모르는 처음 조건이 둘 이상이면 근 찾기가 여러 변수 문제가 되어 Newton 방법을 행렬로 확장합니다. 별 구조 계산의 표준 방법(Henyey 방법)은 아예 전체 격자를 한꺼번에 풉니다.
예제 5.4.1

공기 저항이 없을 때 \(y(0) = 0\), \(y(T) = 0\)인 수직 발사의 처음 속도를 사격법 없이 구하고, 위 프로그램의 처음 추측 49.0이 왜 \(F = 0\)이 아닌지 설명하세요.

풀이. \(y(T) = v_0T - \tfrac12gT^2 = 0\)에서 \(v_0 = gT/2 = 49\) m/s. 프로그램은 저항이 있는 운동을 적분하므로 49 m/s로 쏘면 저항 때문에 일찍 떨어져 \(y(10) < 0\)이 됩니다. 처음 추측은 '답 근처'일 뿐 답이 아닙니다.

요약
  1. 경계값 문제는 양 끝에 조건이 나뉜 문제. 처음 조건 일부를 모른다.
  2. 사격법: 모르는 처음 조건을 추측 → 적분 → 끝에서 빗나간 양 \(F(s)\) → 근 찾기로 \(F(s) = 0\).
  3. 별 구조(천우9), 궤도 결정(천우11)에 쓰인다. 불안정하면 양쪽에서 쏘아 가운데에서 맞춘다.

5.4.5연습문제

기본

  1. 사격법에서 할선법 한 걸음에 미분방정식을 몇 번 적분합니까?
    답

    새 추측값으로 한 번(이전 값의 결과는 다시 쓸 수 있음). 위 코드는 간단히 하려고 두 번씩 적분합니다.

  2. \(k\)를 0으로 바꾸면 프로그램은 어떤 답을 내야 합니까?
    답

    49.00 m/s. 극한값 검산입니다(1.3절).

응용

  1. 공기 저항이 있을 때 같은 높이까지 올라갔다 내려오는 시간이 올라가는 시간보다 긴 까닭은?
    답

    올라갈 때는 중력과 저항이 모두 아래로 작용해 빨리 느려지고, 내려올 때는 저항이 위로 작용해 가속이 작아 천천히 떨어지기 때문입니다.

  2. 별 구조 계산에서 중심 압력을 추측해 바깥으로 적분했더니 표면(\(P = 0\))에 이르렀을 때 질량이 목표보다 컸습니다. 중심 압력을 어느 쪽으로 고쳐야 할까요? (같은 중심 온도)
    답

    대체로 중심 압력(밀도)이 크면 질량이 크게 나오므로 중심 압력을 낮춥니다. 정확한 방향은 \(F(s)\)의 부호 변화를 보고 할선법이 알아서 정합니다.
