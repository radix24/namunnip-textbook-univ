표 자료 사이의 값, 보간과 스플라인

본문 · 3.2절

항성 대기 모형의 표에는 온도 4000 K, 5000 K, 6000 K, …의 색지수만 있다. 그런데 태양의 온도 5772 K에서의 값이 필요하다. 이웃한 값으로 사이를 메우면 될 텐데, 점을 많이 쓸수록 정확해질까?

먼저 알아야 할 것Python 함수와 반복문(1.1절)과 다항함수를 쓴다.

3.2.1선형 보간

별 대기 모형의 불투명도, 진화 모형의 등연령곡선, 필터 투과율처럼 천문학의 많은 자료는 띄엄띄엄한 표로 주어진다. 표에 없는 값을 이웃한 값들로 메우는 일을 보간이라 한다. 가장 간단한 방법은 이웃한 두 점을 직선으로 잇는 것이다. \(x_i \le x \le x_{i+1}\)이면 \(t = (x - x_i)/(x_{i+1} - x_i)\)로 두고 \(y = y_i + t(y_{i+1} - y_i)\)이다. 빠르고 안전하지만, 곡선이 휘는 곳에서는 표 간격 \(h\)에 대해 \(h^2|f''|/8\) 정도의 오차가 생기고 꺾인 곳에서 기울기가 끊긴다.

3.2.2라그랑주 다항식 보간

점 \(n\)개를 모두 지나는 \(n-1\)차 다항식은 하나뿐이고, 다음과 같이 쓸 수 있다.

\[p(x) = \sum_{i} y_i\,L_i(x), \qquad L_i(x) = \prod_{j\ne i}\frac{x - x_j}{x_i - x_j}\]

\(L_i\)는 \(x_i\)에서 1, 다른 점에서 0인 다항식이라 \(p(x_i) = y_i\)가 된다. 아래는 온도와 색지수의 가상 표에 두 방법을 쓴 예이다.

xs = [4000, 5000, 6000, 7000, 8000]          # 온도 (K)
ys = [1.38, 0.89, 0.58, 0.39, 0.25]          # B-V (흑체 어림, 가상 표)

def linear(x, xs, ys):
    for i in range(len(xs) - 1):
        if xs[i] <= x <= xs[i + 1]:
            t = (x - xs[i]) / (xs[i + 1] - xs[i])
            return ys[i] + t * (ys[i + 1] - ys[i])

def lagrange(x, xs, ys):
    s = 0.0
    for i in range(len(xs)):
        L = 1.0
        for j in range(len(xs)):
            if j != i:
                L *= (x - xs[j]) / (xs[i] - xs[j])
        s += ys[i] * L
    return s

for T in (4500, 5772, 7500):
    print(T, round(linear(T, xs, ys), 3), round(lagrange(T, xs, ys), 3))
4500 1.135 1.109
5772 0.651 0.638
7500 0.32 0.319

곡선이 가장 휘는 곳(4,500 K)에서 두 방법의 차이가 0.026으로 가장 크다. 매끄러운 함수라면 다항식 보간이 대개 더 정확하다.

3.2.3Runge 현상과 스플라인

그렇다면 처음 질문처럼 점을 많이 쓸수록 좋을까? 그렇지 않다. 고르게 놓인 점에 고차 다항식을 맞추면 양 끝에서 크게 진동하는 일이 생긴다. 그림 1처럼 \(f(x) = 1/(1 + 25x^2)\)을 \([-1, 1]\)의 고른 점 11개로 보간하면 끝 근처에서 참값보다 훨씬 크게 튀며, 점을 늘릴수록 더 심해진다. 이것을 Runge 현상이라 한다.

해결책은 3차 스플라인이다. 이웃한 두 점 사이마다 3차 다항식을 따로 쓰되, 점에서 값, 기울기, 곡률(2차 도함수)이 이어지도록 맞춘다. 각 조각은 낮은 차수라 진동하지 않고, 이어진 곡선은 매끄럽다. 조건을 세우면 각 점의 2차 도함수에 대한 삼중대각 연립방정식이 되어 빠르게 풀린다(천우10 2.1절). Python에서는 scipy.interpolate.CubicSpline을 쓴다.

예제 3.2.1

점 \(x_0 = 0\), \(x_1 = 1\), \(x_2 = 2\)에 대한 \(L_0(x)\)를 쓰고 \(x = 0.5\)에서의 값을 구하여라.

풀이. \(L_0 = \dfrac{(x-1)(x-2)}{(0-1)(0-2)} = \dfrac{(x-1)(x-2)}{2}\)이므로 \(L_0(0.5) = (-0.5)(-1.5)/2 = 0.375\)이다. 또 \(L_0(0) = 1\), \(L_0(1) = L_0(2) = 0\)임을 확인할 수 있다.

주의보간은 표의 범위 안에서만 쓴다. 범위 밖으로 늘이는 외삽은 다항식이 급격히 벗어나므로 매우 위험하다. 또 표 간격보다 자세한 구조(좁은 흡수선 등)는 어떤 보간으로도 되살릴 수 없다.
마무리

표에 없는 값은 보간으로 메운다. 선형 보간은 이웃 두 점을 직선으로 이어 안전하지만 휘는 곳에서 \(h^2|f''|/8\) 정도 틀리고, 라그랑주 다항식은 모든 점을 지나는 하나의 다항식이라 매끄러운 함수에 정확하다. 하지만 고른 점의 고차 다항식은 끝에서 진동하므로(Runge 현상), 구간마다 3차 다항식을 쓰고 값, 기울기, 곡률을 이은 3차 스플라인이 매끄럽고 안정한 선택이다.

3.2.4연습문제

기본

  1. (4000, 1.38)과 (5000, 0.89) 사이에서 4,200 K의 선형 보간 값은 얼마인가?
    답

    \(1.38 + 0.2\times(0.89 - 1.38) = 1.282\)이다.

응용

  1. 선형 보간의 최대 오차 \(h^2|f''|/8\)로, \(\sin x\)를 간격 0.1로 표로 만들 때 오차를 어림하여라.
    답

    \(|f''| \le 1\)이므로 \(0.01\times1/8 = 1.25\times10^{-3}\)이다.
