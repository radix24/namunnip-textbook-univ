변수, 배열, 반복문, 함수로 계산 프로그램 짜기

본문 · 1.1절

별 세 개의 거리는 계산기로 거리 지수를 풀어 구할 수 있다. 그런데 가이아 목록에는 별이 10억 개 넘게 있다. 같은 식을 10억 번 손으로 계산할 수는 없다. 천문학자는 이런 되풀이 계산을 어떻게 맡길까?

먼저 알아야 할 것프로그래밍 기초(공통10 1단원)와 거리 지수(천우3 1.3절)를 쓴다.

1.1.1준비

천문학은 자료가 많고 계산이 되풀이되는 학문이라 프로그래밍이 기본 도구이며, 많은 천문학과가 Python을 기본 언어로 쓴다. 그래서 이 절에서는 Python의 가장 기본적인 네 가지, 곧 변수, 리스트, 반복문, 함수를 천문 계산 하나로 익힌다. 먼저 python.org에서 Python 3을 설치하거나, 설치 없이 웹 브라우저에서 쓰는 Google Colab이나 Jupyter를 쓴다. 한편 아래 코드는 표준 라이브러리만 쓰므로 어디서나 그대로 돌아간다. 코드를 파일(예를 들어 dist.py)로 저장하고 명령창에서 python dist.py로 실행한다.

1.1.2예제 프로그램

거리 지수 \(m - M = 5\log_{10}(d/10\text{ pc}) + A\)를 \(d\)에 대해 풀면 다음과 같다.

\[d = 10^{(m - M - A + 5)/5}\ \text{pc}\]

이제 이 식을 별 세 개에 적용하는 프로그램이다.

import math

def distance_pc(m, M, A=0.0):
    """겉보기 등급 m, 절대 등급 M, 소광 A로 거리(pc)를 구한다."""
    return 10 ** ((m - M - A + 5) / 5)

stars = [("시리우스", -1.46, 1.43), ("베가", 0.03, 0.58), ("리겔", 0.13, -7.84)]
for name, m, M in stars:
    d = distance_pc(m, M)
    print(f"{name:5s} m={m:6.2f} M={M:6.2f}  d = {d:8.1f} pc")

total = 0.0
for name, m, M in stars:
    total += distance_pc(m, M)
print("평균 거리", round(total / len(stars), 1), "pc")

그러면 실행 결과는 다음과 같다.

시리우스  m= -1.46 M=  1.43  d =      2.6 pc
베가    m=  0.03 M=  0.58  d =      7.8 pc
리겔    m=  0.13 M= -7.84  d =    392.6 pc
평균 거리 134.3 pc

1.1.3한 줄씩 읽기

맨 위의 import math는 수학 함수 모음을 불러온다. 이 예제에서는 쓰지 않았지만 log, sin 등을 쓸 때 필요하다. 다음으로 def distance_pc(m, M, A=0.0)는 함수를 정의한다. 들여쓴 줄이 함수의 몸체이고 return이 결과를 돌려주며, A=0.0은 값을 주지 않으면 0을 쓰는 기본값이다. 몸체의 10 ** x는 거듭제곱인데, ^는 거듭제곱이 아니니 주의한다.

이어서 stars는 리스트이며, 여기에는 (이름, \(m\), \(M\)) 묶음, 곧 튜플 세 개를 담았다. 그리고 for name, m, M in stars:는 리스트의 원소를 하나씩 꺼내 세 변수에 나누어 담고 들여쓴 줄을 되풀이한다. 끝으로 f"...{d:8.1f}..."는 f-문자열로, 중괄호 안의 값을 지정한 형식(전체 8칸, 소수 한 자리)으로 끼워 넣는다.

처음 질문의 답이 바로 이 짜임이다. 계산을 함수로 묶어 두면 별이 10억 개여도 반복문이 함수를 그만큼 부를 뿐이고, 고칠 때도 한 곳만 고치면 된다. 소광을 넣으려면 distance_pc(m, M, A=0.5)처럼 부르기만 하면 된다.

예제 1.1.1

위 프로그램의 목록에 데네브(\(m = 1.25\), \(M = -8.38\))를 더하면 거리는 얼마인가?

풀이. \(10^{(1.25 + 8.38 + 5)/5} = 10^{2.926} = 843\) pc이다. 목록에 ("데네브", 1.25, -8.38) 한 줄을 더하는 것 말고는 코드를 바꿀 필요가 없다(그림 1).

흔한 실수Python은 들여쓰기로 블록을 나눈다. for 아래 줄의 들여쓰기가 하나라도 어긋나면 반복에서 빠지거나 오류가 난다. 또 나눗셈 7 / 2는 3.5이지만 7 // 2는 몫인 3이다.
마무리

계산 프로그램은 변수에 값을 넣고, 여러 값을 리스트로 묶고, for 반복문으로 원소마다 같은 계산을 하는 짜임이다. 되풀이하는 계산은 def로 함수로 만들어 다시 쓰며, 기본값으로 선택적인 입력(소광)을 받는다. 결과는 f-문자열로 보기 좋게 출력한다. 이렇게 짜 두면 별의 수가 늘어나도 목록만 길어질 뿐이다.

1.1.4연습문제

기본

  1. 거리(pc)를 받아 광년으로 돌려주는 함수 pc_to_ly(d)를 써라(1 pc = 3.2616 ly).
    답

    def pc_to_ly(d): return d * 3.2616이다.

응용

  1. 목록의 별 가운데 거리가 10 pc보다 가까운 별의 이름만 출력하도록 고쳐라.
    답

    반복문 안에 if distance_pc(m, M) < 10: print(name)를 넣는다. 시리우스와 베가가 나온다.

  2. 평균 거리를 구하는 부분을 sum과 생성식으로 한 줄로 써라.
    답

    sum(distance_pc(m, M) for _, m, M in stars) / len(stars)이다.
