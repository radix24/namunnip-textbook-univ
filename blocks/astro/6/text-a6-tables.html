표 자료를 읽고 그래프로 그리기

본문 · 1.2절

천문 자료 보관소에서 행성의 긴반지름과 공전 주기 표를 내려받았다. 케플러 제3법칙 \(P^2 \propto a^3\)이 정말 성립하는지 확인하려면, 표를 프로그램으로 어떻게 읽고 어떤 그래프를 그려야 한눈에 보일까?

먼저 알아야 할 것Python 기초(1.1절)와 케플러 제3법칙(천우1 1.3절)을 쓴다.

1.2.1CSV 읽기

보관소의 자료는 대개 쉼표로 열을 나눈 CSV, 고정 폭 텍스트, FITS 표 형식으로 온다. 그래서 첫 단계는 그 표를 프로그램으로 읽어 숫자 목록으로 바꾸는 것이다. 여기서는 표준 라이브러리의 csv 모듈로 행성 자료를 읽는다. 실제로는 open("planets.csv", encoding="utf-8")로 파일을 열지만, 예제를 그대로 실행할 수 있게 표를 문자열로 넣고 io.StringIO로 파일처럼 다룬다.

import csv, io
data = """name,a_AU,P_yr
수성,0.387,0.241
금성,0.723,0.615
지구,1.000,1.000
화성,1.524,1.881
목성,5.203,11.862
토성,9.537,29.457
"""
rows = list(csv.DictReader(io.StringIO(data)))
for r in rows:
    a, P = float(r["a_AU"]), float(r["P_yr"])
    print(f'{r["name"]} a^3/P^2 = {a**3 / P**2:.4f}')

실행하면 다음이 나온다.

수성 a^3/P^2 = 0.9979
금성 a^3/P^2 = 0.9992
지구 a^3/P^2 = 1.0000
화성 a^3/P^2 = 1.0004
목성 a^3/P^2 = 1.0010
토성 a^3/P^2 = 0.9997

csv.DictReader는 첫 줄을 열 이름으로 쓰고, 각 행을 r["a_AU"]처럼 이름으로 꺼내는 사전으로 준다. 그런데 읽은 값은 문자열이므로 float()로 숫자로 바꿔야 한다. 결과의 \(a^3/P^2\)이 모두 1에 가까우므로 AU와 년 단위의 케플러 제3법칙이 확인된다. 1에서 벗어난 0.1% 안팎은 표의 반올림과 행성 질량(\(M_\odot + m\))의 효과이다.

1.2.2그래프 그리기

이제 처음 질문의 둘째 부분이다. 그림은 matplotlib으로 그린다(설치는 pip install matplotlib). 거듭제곱 관계 \(P = a^k\)는 양변에 로그를 취하면 \(\log P = k\log a\)가 되므로, 로그-로그 그래프에서 기울기 \(k\)인 직선이 된다.

import matplotlib.pyplot as plt
a = [float(r["a_AU"]) for r in rows]
P = [float(r["P_yr"]) for r in rows]
plt.loglog(a, P, "o", label="행성")
plt.loglog([0.3, 12], [0.3**1.5, 12**1.5], "--", label="P = a^1.5")
plt.xlabel("긴반지름 a (AU)"); plt.ylabel("주기 P (년)")
plt.legend(); plt.savefig("kepler.png", dpi=150)

그림 1처럼 점들이 기울기 1.5인 직선 위에 놓여, 표의 숫자를 하나하나 보지 않아도 법칙이 한눈에 보인다. 또 그래프에는 늘 축 이름과 단위를 적는다.

예제 1.2.1

두 점의 로그로 기울기 \(\log(P_2/P_1)/\log(a_2/a_1)\)를 수성과 토성으로 계산하여라.

풀이. \(\log_{10}(29.457/0.241)/\log_{10}(9.537/0.387) = 2.087/1.392 = 1.499\)이다. 즉 그림 1의 기울기는 3/2이며, 이것이 \(P^2 \propto a^3\)과 같은 말이다.

흔한 실수표에 빈칸이나 "N/A" 같은 글자가 있으면 float()에서 오류가 난다. 읽기 전에 자료를 눈으로 확인하고 빈칸을 건너뛰는 처리를 넣는다. 또 한글이 든 파일은 인코딩(utf-8)을 꼭 지정한다.
마무리

열 이름이 있는 CSV 표는 csv.DictReader로 읽고, 문자열로 읽힌 값은 float()로 바꾼다. 읽은 자료로 \(a^3/P^2\) 같은 물리량을 계산해 관계를 확인하고, 거듭제곱 관계는 로그-로그 그래프에 그려 기울기로 지수를 읽는다. 그래프에는 축 이름과 단위를 적는다.

1.2.3연습문제

기본

  1. 표에 천왕성(\(a = 19.19\) AU, \(P = 84.01\)년)을 더하면 \(a^3/P^2\)은 얼마인가?
    답

    \(19.19^3/84.01^2 = 7067/7058 = 1.0013\)이다.

응용

  1. 열 구분이 공백인 표를 읽으려면 어떻게 고치는가?
    답

    csv.reader(f, delimiter=" ", skipinitialspace=True)를 쓰거나, 줄마다 line.split()으로 나눈다.
