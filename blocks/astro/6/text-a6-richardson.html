Richardson 외삽, 오차의 모양을 알면 오차를 지운다

본문 · 4.4절

사다리꼴 공식으로 적분을 \(n = 16\)과 \(n = 32\)에서 계산했다. 둘 다 오차가 \(10^{-3}\) 수준이라 더 정확하게 하려면 \(n\)을 수백으로 늘려야 할 것 같다. 그런데 오차가 \(h^2\)에 비례한다는 것을 안다면, 이미 구한 두 값만 섞어서 오차를 지울 수는 없을까?

먼저 알아야 할 것사다리꼴 공식과 Simpson 공식(4.2절)과 유한 차분(4.1절)을 쓴다.

4.4.1오차의 모양

간격 \(h\)로 계산한 근사값 \(A(h)\)의 오차가 \(h\)의 거듭제곱으로 쓰인다고 하자.

\[A(h) = A_{\text{참}} + Ch^p + O(h^{p+2})\]

사다리꼴 공식은 \(p = 2\)이고, 오차에 짝수 거듭제곱만 남아 그다음 항은 \(h^4\)이다. 그러면 간격을 반으로 할 때 첫 오차 항이 \(2^p\)배 작아진다. 처음 질문의 답이 여기 있다. 두 값을 알면 \(C\)를 몰라도 이 항을 지울 수 있다.

결과 4.4.1 (Richardson 외삽) \[A_{\text{참}} \approx \frac{2^pA(h/2) - A(h)}{2^p - 1}\]

유도. \(A(h) = A_{\text{참}} + Ch^p\), \(A(h/2) = A_{\text{참}} + Ch^p/2^p\)에서 둘째 식에 \(2^p\)를 곱해 첫째 식을 빼면 \(Ch^p\)가 지워져 \(2^pA(h/2) - A(h) = (2^p - 1)A_{\text{참}}\)이다. ∎

사다리꼴(\(p = 2\))이면 \((4T(h/2) - T(h))/3\)이고, 이것은 Simpson 공식과 같다. 남은 \(h^4\) 항도 같은 방법으로 \((16R(h/2) - R(h))/15\)로 지울 수 있으며, 이를 되풀이하는 것이 Romberg 적분이다.

4.4.2실험

\(\int_0^\pi\sin x\,dx = 2\)를 사다리꼴 공식과 외삽으로 계산한다.

import math

def trap(f, a, b, n):
    h = (b - a) / n
    return h * (0.5 * f(a) + sum(f(a + i * h) for i in range(1, n)) + 0.5 * f(b))

f, a, b, exact = math.sin, 0.0, math.pi, 2.0
T = [trap(f, a, b, 2**k) for k in range(2, 6)]          # n = 4, 8, 16, 32
print("  n    사다리꼴 T(n)        오차")
for k, t in enumerate(T):
    print(f"{2**(k + 2):3d}  {t:.12f}  {t - exact:+.2e}")
print("Richardson R = (4 T(2n) - T(n)) / 3")
R = [(4 * T[k + 1] - T[k]) / 3 for k in range(len(T) - 1)]
for k, r in enumerate(R):
    print(f"{2**(k + 3):3d}  {r:.12f}  {r - exact:+.2e}")
print("한 번 더 (16 R(2n) - R(n)) / 15")
R2 = [(16 * R[k + 1] - R[k]) / 15 for k in range(len(R) - 1)]
for k, r in enumerate(R2):
    print(f"{2**(k + 4):3d}  {r:.12f}  {r - exact:+.2e}")

사다리꼴 오차는 \(n\)을 두 배로 할 때마다 4배씩(\(h^2\)), 한 번 외삽하면 16배씩(\(h^4\)), 두 번 외삽하면 64배씩(\(h^6\)) 줄어든다(그림 1). 함숫값 33개(\(n = 32\))로 사다리꼴만 쓰면 오차가 \(10^{-3}\)이지만, 같은 함숫값으로 두 번 외삽하면 \(4\times10^{-9}\)이다. 즉 계산을 더 하지 않고 이미 있는 값을 섞기만 했다.

4.4.3오차 어림과 주의점

참값을 모를 때도 쓸모가 있다. \(T(h/2) - T(h) = C(h/2)^2 - Ch^2 = -3C(h/2)^2\)이므로 두 값의 차는 \(T(h/2)\)의 오차의 약 3배이다. 그래서 \((T(h/2) - T(h))/3\)이 \(T(h/2)\)의 오차 어림이 된다(부호는 반대). 하지만 외삽은 오차가 \(h^p\) 꼴이라는 가정이 맞을 때만 통한다. 함수에 꺾이는 점이나 특이점이 있거나, \(h\)가 너무 작아 반올림 오차가 지배하면(2.2절) 외삽이 오히려 결과를 망친다. 그러므로 연속한 외삽값의 차가 예상대로 줄어드는지 늘 확인한다.

예제 4.4.1

어떤 적분을 사다리꼴로 \(n = 10\)에서 0.4952, \(n = 20\)에서 0.4988로 얻었다. 외삽값과, \(n = 20\) 결과의 오차 어림은 얼마인가?

풀이. \(R = (4\times0.4988 - 0.4952)/3 = 0.5000\)이다. \(n = 20\) 결과의 오차 어림은 \((0.4988 - 0.4952)/3 = 0.0012\)로, 참값이 0.5000 근처라는 것과 맞는다.

흔한 실수\(\int_0^1\sqrt x\,dx\)처럼 끝점에서 도함수가 무한대인 함수에 외삽을 쓰면 기대만큼 좋아지지 않는다. 오차가 \(h^2\)이 아니라 \(h^{3/2}\) 꼴이 되어, 가정한 \(p\)로는 맞는 항을 지우지 못하기 때문이다.
마무리

근사값의 오차가 \(Ch^p\) 꼴이면, 간격 \(h\)와 \(h/2\)의 결과를 \((2^pA(h/2) - A(h))/(2^p - 1)\)로 섞어 \(C\)를 몰라도 첫 오차 항을 지울 수 있다. 사다리꼴에 한 번 외삽하면 Simpson 공식이 되고, 되풀이하면 Romberg 적분이 되어 같은 함숫값으로 오차가 \(h^4\), \(h^6\)으로 빠르게 준다. 두 값의 차를 \(2^p - 1\)로 나누면 오차 어림이 되지만, 매끄럽지 않은 함수나 반올림 영역에서는 쓰지 않는다.

4.4.4연습문제

기본

  1. 중앙 차분 도함수 \(D(h)\)는 오차가 \(h^2\)이다. \(D(h)\)와 \(D(h/2)\)를 섞는 외삽 식을 써라.
    답

    \((4D(h/2) - D(h))/3\)이다.

  2. 표에서 사다리꼴의 오차가 \(n\)을 두 배로 할 때 몇 배씩 줄었는지 읽고 \(p\)를 확인하여라.
    답

    \(1.04\times10^{-1}/2.58\times10^{-2} \approx 4.0\)배이므로 \(2^p = 4\), \(p = 2\)이다.

응용

  1. 표의 두 번 외삽 값의 오차가 \(2.48\times10^{-7} \to 3.81\times10^{-9}\)으로 줄었다. 이론상 몇 배여야 하는가?
    답

    \(h^6\) 오차이므로 \(2^6 = 64\)배이다. 실제로 \(2.48\times10^{-7}/3.81\times10^{-9} = 65\)배로 맞는다.
