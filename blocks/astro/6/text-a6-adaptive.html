바쁠 때는 잘게, 한가할 때는 크게: 적응 시간 간격

본문
이 절에서 배울 것
  • 이심률이 큰 궤도에서 고정 시간 간격이 비효율적인 까닭을 안다.
  • 그 자리의 궤도 시간에 비례하는 간격 \(\Delta t = \eta\,r^{3/2}/\sqrt{GM}\)으로 적분한다.
  • 같은 계산량에서 고정 간격과 적응 간격의 정확도를 비교한다.
  • 간격 두 배 비교로 오차를 재며 간격을 조절하는 일반적인 방법을 안다.
먼저 알아야 할 것
  • 4차 Runge-Kutta 방법 (5.1절), 에너지로 정확도 재기 (5.2절).

5.3.1고정 간격의 낭비

이심률 0.9인 궤도는 원일점 거리가 근일점의 19배이고, 근일점에서는 원일점보다 19배 빨리 움직입니다. 궤도 대부분의 시간은 멀리서 천천히 보내고, 근일점 근처는 순식간에 지나갑니다. 고정 간격으로 적분하면 근일점에서 정확도를 맞추느라 간격을 아주 작게 해야 하고, 그 작은 간격을 한가한 원일점에서도 그대로 써서 계산을 낭비합니다.

5.3.2궤도 시간에 맞춘 간격

반지름 \(r\)에서 운동이 바뀌는 시간 규모는 그 자리의 원 궤도 주기에 비례하는 \(\sqrt{r^3/GM}\)입니다. 그래서 간격을

규칙 5.3.1 \[\Delta t = \eta\sqrt{\frac{r^3}{GM}}\]

로 정하면, 걸음마다 궤도를 비슷한 비율만큼 나아갑니다. \(\eta\)는 정확도를 정하는 작은 수(0.001~0.05)입니다. 단위를 \(GM = 1\), 긴반지름 1로 두고, 이심률 0.9 궤도를 원일점에서 출발해 한 바퀴(\(2\pi\)) 적분합니다.

import math

# 단위: GM = 1, 긴반지름 a = 1, 주기 2π
e = 0.9
def acc(x, y):
    r3 = (x * x + y * y) ** 1.5
    return -x / r3, -y / r3

def rk4(s, dt):
    def d(s):
        ax, ay = acc(s[0], s[1])
        return (s[2], s[3], ax, ay)
    k1 = d(s)
    k2 = d([s[i] + 0.5 * dt * k1[i] for i in range(4)])
    k3 = d([s[i] + 0.5 * dt * k2[i] for i in range(4)])
    k4 = d([s[i] + dt * k3[i] for i in range(4)])
    return [s[i] + dt / 6 * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]) for i in range(4)]

def energy(s):
    return 0.5 * (s[2]**2 + s[3]**2) - 1 / math.hypot(s[0], s[1])

start = [1 + e, 0.0, 0.0, math.sqrt((1 - e) / (1 + e))]   # 원일점에서 출발
E0 = energy(start)
P = 2 * math.pi

# 고정 간격
for N in (1000, 4000):
    s, dt = start[:], P / N
    for _ in range(N):
        s = rk4(s, dt)
    print(f"고정 간격  {N:5d}걸음: 에너지 상대 오차 {abs(energy(s) / E0 - 1):.1e}, 끝 위치 x = {s[0]:.4f}")

# 적응 간격: dt = eta * r^1.5 (그 자리의 궤도 시간에 비례)
for eta in (0.0105, 0.0026):
    s, t, n = start[:], 0.0, 0
    while t < P:
        r = math.hypot(s[0], s[1])
        dt = min(eta * r**1.5, P - t)
        s = rk4(s, dt); t += dt; n += 1
    print(f"적응 간격  {n:5d}걸음: 에너지 상대 오차 {abs(energy(s) / E0 - 1):.1e}, 끝 위치 x = {s[0]:.4f}")
고정 간격   1000걸음: 에너지 상대 오차 3.5e-04, 끝 위치 x = 1.8993
고정 간격   4000걸음: 에너지 상대 오차 3.5e-07, 끝 위치 x = 1.9000
적응 간격    797걸음: 에너지 상대 오차 6.4e-10, 끝 위치 x = 1.9000
적응 간격   3219걸음: 에너지 상대 오차 6.1e-13, 끝 위치 x = 1.9000

적응 간격은 고정 간격보다 적은 걸음(797 대 1,000)으로 에너지 오차가 50만 배 작습니다. 고정 간격에서 오차는 거의 모두 근일점을 지나는 몇 걸음에서 생기는데, 적응 간격은 바로 그곳에서 간격을 \(r^{3/2}\)에 따라 약 80배 줄였기 때문입니다(원일점 대비 \((1.9/0.1)^{3/2} = 83\)).

5.3.3일반적인 방법: 오차를 재며 조절하기

궤도 문제가 아니어서 '알맞은 시간 규모'를 모를 때는, 한 걸음 \(\Delta t\)로 간 결과와 반 걸음 두 번(\(\Delta t/2\) × 2)으로 간 결과를 비교해 그 차이로 오차를 잽니다. 오차가 허용값보다 크면 간격을 줄여 다시 하고, 작으면 다음 간격을 늘립니다. RK4의 한 걸음 오차는 \(\Delta t^5\)에 비례하므로, 오차를 허용값에 맞추는 새 간격은 \(\Delta t_{\text{새}} = \Delta t\,(\text{허용값}/\text{오차})^{1/5}\)입니다. 실제 라이브러리는 한 번에 4차와 5차 결과를 함께 얻는 Runge-Kutta-Fehlberg(RK45) 같은 방법으로 계산을 아낍니다.

주의 적응 간격은 걸음마다 간격이 달라, 도약 개구리(leapfrog) 같은 대칭 적분기의 '오차가 쌓이지 않는' 장점(5.2절)을 깨뜨립니다. 아주 오랜 시간 적분하는 태양계 모의실험에서는 고정 간격의 대칭 적분기를 쓰거나, 대칭성을 지키는 특별한 시간 변환을 씁니다.
예제 5.3.1

이심률 0.99 궤도에서 근일점의 간격은 원일점의 몇 분의 1이 됩니까? (규칙 5.3.1)

풀이. 원일점 \(1.99a\), 근일점 \(0.01a\)이므로 \((1.99/0.01)^{3/2} = 199^{1.5} \approx 2{,}800\)분의 1. 고정 간격이라면 근일점에 맞춘 작은 간격으로 궤도 전체를 돌아야 해 계산이 수천 배 듭니다.

요약
  1. 이심률이 크면 고정 간격은 근일점에서 부정확하거나 원일점에서 낭비한다.
  2. \(\Delta t = \eta\sqrt{r^3/GM}\): 적은 걸음으로 훨씬 정확하다.
  3. 일반적으로는 간격 두 배 비교로 오차를 재며 \(\Delta t \propto (\text{허용}/\text{오차})^{1/5}\)로 조절한다(RK45).
  4. 적응 간격은 대칭 적분기의 장기 안정성을 깨뜨릴 수 있다.

5.3.4연습문제

기본

  1. 원 궤도(\(e = 0\))에서 적응 간격 규칙은 어떤 간격을 줍니까?
    답

    \(r\)이 일정하므로 간격도 일정합니다. 고정 간격과 같습니다.

  2. RK4에서 한 걸음 오차가 허용값의 32배였다면 간격을 몇 배로 줄여야 합니까?
    답

    \((1/32)^{1/5} = 1/2\), 곧 절반.

응용

  1. 표에서 에너지 오차 \(10^{-7}\) 정도를 얻는 데 고정 간격과 적응 간격은 각각 몇 걸음이 필요했습니까? 계산량은 몇 배 차이입니까?
    답

    고정 간격은 4,000걸음에서 \(3.5\times10^{-7}\), 적응 간격은 797걸음에서 이미 \(6.4\times10^{-10}\)입니다. 적응 간격이 5분의 1 걸음으로 500배 넘게 정확하므로, 같은 정확도로 따지면 계산량 차이는 5배보다 훨씬 큽니다.

  2. 코드에서 dt = min(eta * r**1.5, P - t)의 min은 왜 필요합니까?
    답

    마지막 걸음이 정확히 \(t = 2\pi\)에서 끝나도록 하기 위해서입니다. 없으면 한 바퀴를 조금 넘어가 위치와 에너지를 비교하는 기준 시각이 어긋납니다.
