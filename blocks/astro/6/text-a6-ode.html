힘을 알면 미래가 보인다

뉴턴 운동 방정식은 지금의 위치와 속도에서 다음 순간의 위치와 속도를 정해 줍니다. 식으로 풀리지 않는 궤도(3체 문제, 섭동, 대기 저항)도 시간을 잘게 나누어 한 걸음씩 나아가면 따라갈 수 있습니다. 이것이 상미분방정식의 수치 풀이입니다.

5.1.11차 연립 방정식으로 바꾸기

태양 둘레 행성의 운동 \(\ddot{\vec r} = -GM\vec r/r^3\)은 2차 방정식입니다. 속도를 새 변수로 두면 1차 방정식 네 개가 됩니다(평면 운동).

\[ \dot x = v_x,\quad \dot y = v_y,\quad \dot v_x = -\frac{GMx}{r^3},\quad \dot v_y = -\frac{GMy}{r^3} \]

상태 \(\vec s = (x, y, v_x, v_y)\)와 그 변화율 \(\vec f(\vec s)\)로 쓰면 \(\dot{\vec s} = \vec f(\vec s)\)입니다. AU, 년, 태양 질량 단위에서 \(GM = 4\pi^2\)이고, 지구 궤도는 \((1, 0)\)에서 속도 \((0, 2\pi)\)로 출발합니다.

5.1.2Euler 방법

지금의 변화율로 간격 \(\Delta t\)만큼 곧장 나아갑니다: \(\vec s_{n+1} = \vec s_n + \Delta t\,\vec f(\vec s_n)\). 가장 간단하지만 한 걸음 오차가 \(\Delta t^2\), 전체 오차가 \(\Delta t\)에 비례하는 1차 방법입니다. 곡선 궤도에서 늘 접선 방향으로 나가므로 바깥으로 벗어나 에너지가 계속 늡니다.

5.1.34차 Runge-Kutta 방법

한 걸음 안에서 변화율을 네 번 계산해 가중 평균합니다.

\[ \begin{aligned} k_1 &= f(s_n), & k_2 &= f(s_n + \tfrac{\Delta t}2k_1),\\ k_3 &= f(s_n + \tfrac{\Delta t}2k_2), & k_4 &= f(s_n + \Delta t\,k_3),\\ s_{n+1} &= s_n + \tfrac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4) \end{aligned} \]

시작, 가운데(두 번), 끝의 기울기를 Simpson 공식(4.2절)처럼 1 : 2 : 2 : 1로 섞은 것입니다. 전체 오차가 \(\Delta t^4\)에 비례합니다.

import math
GM = 4 * math.pi**2            # AU, 년, 태양 질량

def acc(x, y):
    r3 = (x * x + y * y) ** 1.5
    return -GM * x / r3, -GM * y / r3

def energy(x, y, vx, vy):
    return 0.5 * (vx * vx + vy * vy) - GM / math.hypot(x, y)

def euler(dt, years):
    x, y, vx, vy = 1.0, 0.0, 0.0, 2 * math.pi
    for _ in range(round(years / dt)):
        ax, ay = acc(x, y)
        x, y, vx, vy = x + vx * dt, y + vy * dt, vx + ax * dt, vy + ay * dt
    return x, y, vx, vy

def rk4(dt, years):
    s = [1.0, 0.0, 0.0, 2 * math.pi]
    def f(s):
        ax, ay = acc(s[0], s[1])
        return [s[2], s[3], ax, ay]
    for _ in range(round(years / dt)):
        k1 = f(s)
        k2 = f([s[i] + dt / 2 * k1[i] for i in range(4)])
        k3 = f([s[i] + dt / 2 * k2[i] for i in range(4)])
        k4 = f([s[i] + dt * k3[i] for i in range(4)])
        s = [s[i] + dt / 6 * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]) for i in range(4)]
    return s

E0 = energy(1.0, 0.0, 0.0, 2 * math.pi)
for dt in (0.01, 0.001):
    e1 = energy(*euler(dt, 10)); e2 = energy(*rk4(dt, 10))
    print(f"dt={dt}: 오일러 상대 에너지 오차 {abs((e1 - E0) / E0):.2e}, RK4 {abs((e2 - E0) / E0):.2e}")
dt=0.01: 오일러 상대 에너지 오차 6.69e-01, RK4 1.71e-06
dt=0.001: 오일러 상대 에너지 오차 3.33e-01, RK4 1.71e-11

지구 궤도를 10년(10바퀴) 적분한 뒤의 상대 에너지 오차입니다. Euler 방법은 \(\Delta t = 0.001\)년(한 바퀴에 1,000걸음)에도 에너지가 33% 틀려 궤도가 크게 벗어납니다. RK4는 \(\Delta t = 0.01\)년에서 이미 \(10^{-6}\)이고, 간격을 10배 줄이면 약 \(10^5\)배 더 정확해집니다. 1년만 적분하면 Euler의 오차가 \(\Delta t = 0.01, 0.001, 0.0001\)에서 0.35, 0.068, 0.0078로 대략 \(\Delta t\)에 비례해 줄어드는 것도 확인할 수 있습니다. 아래 실습 카드에서 궤도 모양을 직접 비교합니다.

주의 이 예제의 RK4 코드는 이해하기 쉽게 리스트로 짰습니다. 실전에서는 scipy.integrate.solve_ivp처럼 간격을 자동으로 조절하는 검증된 도구를 쓰고, 직접 짠 코드는 에너지 보존 같은 검산으로 확인합니다.
요약
  1. 2차 운동 방정식은 속도를 변수로 넣어 1차 연립 방정식으로 바꾼다.
  2. Euler: \(s_{n+1} = s_n + \Delta tf(s_n)\), 1차 정확도, 궤도에서 에너지가 계속 는다.
  3. RK4: 기울기 네 번을 1:2:2:1로 평균, 4차 정확도.
  4. 지구 궤도 10년: Euler(\(\Delta t = 0.001\)) 33% vs RK4(0.01) \(10^{-6}\).

5.1.4연습문제

기본

  1. 한 바퀴(1년)를 \(\Delta t = 0.01\)년으로 적분하면 몇 걸음입니까? RK4는 힘을 몇 번 계산합니까?
    답

    100걸음, 400번.

  2. Euler 방법의 전체 오차가 \(\Delta t\)에 비례하면 간격을 1/10로 할 때 오차는?
    답

    1/10.

응용

  1. 단진자 \(\ddot\theta = -(g/L)\sin\theta\)를 1차 연립 방정식으로 쓰세요.
    답

    \(\dot\theta = \omega\), \(\dot\omega = -(g/L)\sin\theta\).

  2. RK4의 전체 오차가 \(\Delta t^4\)이면 간격을 1/10로 할 때 오차는? 위 표의 \(10^5\)배와 다른 까닭을 생각해 보세요.
    답

    \(10^{-4}\)배가 예상입니다. 표는 에너지 오차이고, 원 궤도에서는 RK4의 에너지 오차가 \(\Delta t^5\)처럼 줄어드는 성질이 있어 더 빨리 줄어듭니다(측정량에 따라 차수가 다르게 보일 수 있음).
