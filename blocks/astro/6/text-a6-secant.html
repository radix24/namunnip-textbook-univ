할선법과 수렴 차수, 얼마나 빨리 근에 다가가나

본문 · 3.3절

Newton 방법은 빠르지만 도함수가 필요하다. 그런데 함숫값이 복잡한 수치 적분의 결과라면 도함수를 식으로 쓸 수 없다. 도함수 없이도 Newton 방법만큼 빠른 방법이 있을까? 그리고 방법마다 빠르기를 어떻게 한 숫자로 비교할까?

먼저 알아야 할 것이분법과 Newton 방법(3.1절)과 Kepler 방정식을 쓴다.

3.3.1할선법

처음 질문의 첫째 답은 도함수를 최근 두 점을 잇는 직선, 곧 할선의 기울기로 대신하는 것이다.

정의 3.3.1 (할선법) \[x_{n+1} = x_n - f(x_n)\,\frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}\]

처음 두 점이 필요하고, 한 걸음에 함숫값 계산이 한 번뿐이다(Newton은 함수와 도함수 두 번). 다만 근을 사이에 두는 보장이 없어 이분법처럼 항상 수렴하지는 않는다.

3.3.2수렴 차수

둘째 질문에 답하려면 오차가 줄어드는 빠르기를 정해야 한다. \(n\)번째 오차 \(\varepsilon_n = |x_n - x^*|\)가 \(\varepsilon_{n+1} \approx C\varepsilon_n^p\)로 줄면 수렴 차수가 \(p\)라 한다. 이분법은 \(p = 1\)(선형)로, 한 걸음에 오차가 대략 절반이라 열 걸음에 약 1,000분의 1이 된다. Newton 방법은 \(p = 2\)로 맞는 자릿수가 걸음마다 두 배가 된다. 할선법은 \(p = (1 + \sqrt5)/2 \approx 1.618\)로, 걸음마다 맞는 자릿수가 약 1.6배가 된다.

3.3.3실험, Kepler 방정식

\(E - e\sin E = M\)(\(e = 0.5\), \(M = 1\) rad)을 세 방법으로 풀어 오차를 비교한다. 이분법은 \([0, \pi]\)에서, Newton은 \(E_0 = M\)에서, 할선법은 0과 \(M\)에서 시작한다.

import math
e, M = 0.5, 1.0
f = lambda E: E - e * math.sin(E) - M
df = lambda E: 1 - e * math.cos(E)

E_true = M                       # 기준값
for _ in range(50):
    E_true -= f(E_true) / df(E_true)

def bisect(a, b, n):
    out = []
    for _ in range(n):
        c = 0.5 * (a + b)
        if f(a) * f(c) <= 0: b = c
        else: a = c
        out.append(abs(0.5 * (a + b) - E_true))
    return out

def newton(x, n):
    out = []
    for _ in range(n):
        x -= f(x) / df(x)
        out.append(abs(x - E_true))
    return out

def secant(x0, x1, n):
    out = []
    for _ in range(n):
        if f(x1) == f(x0): break
        x0, x1 = x1, x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0))
        out.append(abs(x1 - E_true))
    return out

print(f"E = {E_true:.15f}")
rows = zip(bisect(0, math.pi, 7), newton(M, 7), secant(0.0, M, 7))
print(" 반복   이분법      Newton      할선법")
for i, (a, b, c) in enumerate(rows, 1):
    print(f"{i:4d}  {a:9.2e}  {b:9.2e}  {c:9.2e}")

Newton 방법의 오차는 \(1.5\times10^{-3} \to 5.9\times10^{-7} \to 8.9\times10^{-14}\)으로 지수가 두 배씩(3 → 6.2 → 13) 늘고, 할선법은 \(1.4\times10^{-5} \to 6.2\times10^{-9} \to 2.2\times10^{-14}\)으로 약 1.6배씩 는다. 한편 이분법은 구간이 절반씩 줄지만 가운데 점과 근의 거리는 들쭉날쭉해 오차가 단조롭게 줄지 않는다. 그래서 그림 1에는 꾸준히 절반이 되는 구간 폭을 그렸다.

3.3.4방법 고르기

근을 사이에 둔 구간을 알고 안전이 최우선이면 이분법을 쓴다. 도함수를 쉽게 계산할 수 있고 좋은 처음 값이 있으면 Newton 방법이 좋다. 반면 도함수가 없거나 비싸면 할선법을 쓴다. 함숫값 계산 횟수로 따지면 할선법이 Newton보다 빠른 경우도 많다. Newton의 한 걸음은 계산 두 번이라 계산 한 번당 차수가 \(\sqrt2 \approx 1.41\)인데, 할선법은 1.618이기 때문이다. 실제 라이브러리의 Brent 방법은 이분법의 안전과 할선법, 역보간의 속도를 섞어 쓴다.

예제 3.3.1

표의 할선법 오차 \(\varepsilon_4 = 1.39\times10^{-5}\), \(\varepsilon_5 = 6.19\times10^{-9}\), \(\varepsilon_6 = 2.22\times10^{-14}\)으로 수렴 차수를 어림하여라.

풀이. \(\varepsilon_{n+1} \approx C\varepsilon_n^p\)의 비를 취하면 \(\varepsilon_6/\varepsilon_5 \approx (\varepsilon_5/\varepsilon_4)^p\)이다. 따라서 \(p \approx \log(\varepsilon_6/\varepsilon_5)/\log(\varepsilon_5/\varepsilon_4) = \log(3.6\times10^{-6})/\log(4.5\times10^{-4}) = (-5.45)/(-3.35) \approx 1.63\)으로, 이론값 1.618과 맞는다.

흔한 실수할선법에서 두 점의 함숫값이 같아지면 분모가 0이 된다. 근에 거의 닿아 \(f(x_n) = f(x_{n-1})\)이 되는 경우도 있으므로, 위 코드처럼 확인하고 멈춘다.
마무리

할선법은 최근 두 점의 할선으로 도함수를 대신해, 처음 두 점과 걸음당 함숫값 한 번으로 근을 찾는다. 빠르기는 \(\varepsilon_{n+1} \approx C\varepsilon_n^p\)의 수렴 차수 \(p\)로 비교하며, 이분법은 1, 할선법은 1.618, Newton 방법은 2이다. 실제로는 안전한 이분법과 빠른 Newton, 할선법을 상황에 맞게 고르거나 Brent 방법처럼 섞어 쓴다.

3.3.5연습문제

기본

  1. 이분법으로 처음 구간 폭 \(\pi\)를 \(10^{-10}\)보다 좁히려면 몇 걸음이 필요한가?
    답

    \(\pi/2^n < 10^{-10}\)에서 \(n > \log_2(3.14\times10^{10}) = 34.9\)이므로 35걸음이다.

응용

  1. 이심률이 0.99로 아주 큰 궤도에서 \(M\)이 작으면 Newton 방법이 \(E_0 = M\)에서 잘 수렴하지 않을 수 있다. 어떻게 하면 좋은가?
    답

    이분법으로 몇 걸음 먼저 근을 좁힌 뒤 Newton으로 넘어가거나, 처음 값을 \(E_0 = \pi\)처럼 바꾼다. \(e\)가 크면 \(E_0 = M + e\sin M\)이나 \(\pi\)가 안전한 선택으로 알려져 있다.
