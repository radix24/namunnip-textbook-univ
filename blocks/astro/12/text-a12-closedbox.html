단순 닫힌 상자 모형으로 금속 함량 분포 예측하기

본문 · 4.2절

별은 기체에서 태어나고, 죽을 때 금속을 섞은 기체를 돌려준다. 그래서 시간이 갈수록 기체의 금속 함량이 늘고, 나중에 태어난 별일수록 금속이 많다. 이 과정을 가장 단순한 가정으로 계산하면, 지금 태양 근처 별들의 금속 함량은 어떻게 분포해야 할까?

먼저 알아야 할 것항성종족과 금속 함량(4.1절), 원소 합성(천우9 4.2절), 미분방정식을 쓴다.

이 과정을 가장 단순하게 계산한 것이 1970년대에 Talbot과 Arnett, Searle과 Sargent가 쓴 단순 닫힌 상자 모형이다. 처음 질문의 답은 금속이 적은 별이 꽤 많아야 한다는 것이다(그림 1). 이 예측이 관측과 맞는지는 4.3절에서 본다.

4.2.1가정

모형은 네 가지를 가정한다. 첫째, 처음에 모두 금속이 없는 기체이고 바깥과 물질을 주고받지 않아 전체 질량이 일정한 닫힌 상자이다. 둘째, 무거운 별은 별의 수명을 무시하고 곧바로 금속을 섞어 기체로 돌려주는 순간 재활용이다. 셋째, 기체는 늘 고르게 섞여 있다. 넷째, 별로 들어간 질량 1당 새로 만들어져 기체로 돌아오는 금속의 질량인 수득률 \(p\)가 일정하다.

4.2.2유도

유도. 기체 질량을 \(g\), 기체의 금속 질량 비율을 \(Z\), 오래 사는 별에 갇힌 질량을 \(s\)라 하자. 별에 \(ds\)만큼 갇히면, 기체의 금속은 새로 만든 \(p\,ds\)만큼 늘고 별에 갇힌 \(Z\,ds\)만큼 준다. 곧 \(d(gZ) = p\,ds - Z\,ds\)이다. 닫힌 상자에서는 \(dg = -ds\)이므로 \(g\,dZ + Z\,dg = -p\,dg + Z\,dg\)이고, 정리하면 \(dZ = -p\,dg/g\)이다. 처음 기체 질량 \(g_0\), \(Z = 0\)에서 적분하면 다음을 얻는다. \[ Z = p\ln\frac{g_0}{g} = p\ln\frac1\mu \] 여기서 \(\mu = g/g_0\)는 지금 남은 기체 비율이다. ∎

4.2.3별의 금속 함량 분포

기체의 금속 함량이 \(Z\)보다 작았을 때 태어난 별의 질량은 \(s(<Z) = g_0 - g(Z) = g_0(1 - e^{-Z/p})\)이다. 지금의 기체 비율을 \(\mu_1\), 지금의 금속 함량을 \(Z_1 = p\ln(1/\mu_1)\)이라 하면, 금속 함량이 \(Z\)보다 작은 별의 비율은 다음과 같다.

\[ \frac{s(<Z)}{s(Z_1)} = \frac{1 - \mu_1^{Z/Z_1}}{1 - \mu_1} \]
예제 4.2.1

태양 근처 원반의 기체 비율을 \(\mu_1 = 0.1\), 지금 기체의 금속 함량을 \(Z_1 = Z_\odot\)으로 두면 수득률은 얼마이고, \(Z < 0.25Z_\odot\)인 별의 비율은 얼마인가?

풀이. \(p = Z_\odot/\ln10 = 0.434Z_\odot\)이다. 비율은 \((1 - 0.1^{0.25})/(1 - 0.1) = (1 - 0.562)/0.9 = 48.6\%\)이고, \(Z < 0.5Z_\odot\)이면 \((1 - 0.316)/0.9 = 76.0\%\)이다. 즉 별의 절반 가까이가 태양의 1/4보다 금속이 적어야 한다는 예측이다(그림 1).

주의순간 재활용 가정은 수명이 짧은 무거운 별이 만드는 산소 같은 원소에는 잘 맞는다. 그러나 Ia형 초신성이 10억 년쯤 걸려 만드는 철에는 맞지 않는다. 그러므로 산소로 계산한 결과와 철([Fe/H])로 잰 관측을 비교할 때는 조심해야 한다.
마무리

단순 닫힌 상자 모형은 물질 출입이 없고, 순간 재활용하며, 잘 섞이고, 수득률 \(p\)가 일정하다고 가정한다. 그러면 기체의 금속 함량은 \(Z = p\ln(1/\mu)\)이고, 별의 누적 분포는 \(s(<Z)/s_1 = (1 - \mu_1^{Z/Z_1})/(1 - \mu_1)\)이다. \(\mu_1 = 0.1\), \(Z_1 = Z_\odot\)이면 \(Z < 0.25Z_\odot\)인 별이 48.6%나 되어야 한다.

4.2.4연습문제

기본

  1. 기체가 절반 남았을 때(\(\mu = 0.5\)) 기체의 금속 함량은 수득률의 몇 배인가?
    답

    \(\ln2 = 0.69\)배이다.

응용

  1. \(\mu_1 = 0.2\), \(Z_1 = Z_\odot\)이면 \(p\)와 \(Z < 0.25Z_\odot\)인 별의 비율은 얼마인가?
    답

    \(p = 1/\ln5 = 0.621Z_\odot\)이고, 비율은 \((1 - 0.2^{0.25})/0.8 = (1 - 0.669)/0.8 = 41.4\%\)이다.

  2. 수득률이 0.01(질량 비율)이고 기체가 10% 남았다면 기체의 \(Z\)는 얼마인가?
    답

    \(0.01\ln10 = 0.023\)이다.
