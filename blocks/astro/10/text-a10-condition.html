조건수: 연립방정식이 오차를 얼마나 키우나

본문 · 2.3절

변광성의 밝기 변화를 2차식으로 맞추려 한다. 시각을 율리우스일(약 246만) 그대로 넣었더니 잔차가 잡음의 37배로 맞춤이 망가졌다. 그런데 평균 시각을 빼고 같은 계산을 하면 완벽하게 맞는다. 같은 자료, 같은 2차식인데 숫자 하나를 빼는 것이 왜 이렇게 큰 차이를 낼까?

먼저 알아야 할 것가우스 소거와 LU 분해(2.1절), 최소제곱법(천우6 6.1절), 부동소수점(천우6 2.1절)을 쓴다.

처음 질문의 답은 조건수이다. 조건수는 입력의 작은 오차, 반올림까지 포함한 오차를 해가 얼마나 키우는지 나타내는 배율이다.

2.3.1조건수

결과 2.3.1

\(A\mathbf x = \mathbf b\)에서 \(\mathbf b\)에 작은 상대 오차가 있으면, 해의 상대 오차는 다음과 같이 최대 \(\kappa(A)\)배까지 커진다. 여기서 \(\sigma\)는 \(A\)의 특이값이며, 대칭 양정치 행렬이면 고유값이다.

\[\frac{\|\delta\mathbf x\|}{\|\mathbf x\|} \le \kappa(A)\,\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}, \qquad \kappa(A) = \frac{\sigma_{\max}}{\sigma_{\min}}\]

배정밀도의 반올림 오차는 약 \(10^{-16}\)이므로, \(\kappa = 10^{10}\)이면 해에 \(10^{-6}\) 정도의 오차가 생기고 \(\kappa \gtrsim 10^{16}\)이면 해를 전혀 믿을 수 없다. 이때 조건수는 알고리즘이 아니라 문제 자체의 성질이다. 그래서 좋은 알고리즘도 나쁜 조건의 문제를 고칠 수는 없지만, 나쁜 알고리즘은 조건을 더 나쁘게 만들 수 있다.

2.3.2정규방정식은 조건수를 제곱한다

최소제곱 \(\min\|A\mathbf c - \mathbf y\|\)를 정규방정식 \(A^TA\mathbf c = A^T\mathbf y\)로 풀면 \(\kappa(A^TA) = \kappa(A)^2\)이다. 예를 들어 \(\kappa(A) = 10^6\)이면 \(10^{12}\)이 되어 유효숫자 12자리를 잃는다. 천문 자료에서 흔한 예가 시각을 율리우스일 그대로 쓰는 다항식 맞춤이다.

import random

def solve(A, b):
    """부분 피벗 가우스 소거"""
    n = len(A)
    M = [row[:] + [b[i]] for i, row in enumerate(A)]
    for k in range(n):
        p = max(range(k, n), key=lambda r: abs(M[r][k]))
        M[k], M[p] = M[p], M[k]
        for r in range(k + 1, n):
            f = M[r][k] / M[k][k]
            for c in range(k, n + 1):
                M[r][c] -= f * M[k][c]
    x = [0.0] * n
    for k in range(n - 1, -1, -1):
        x[k] = (M[k][n] - sum(M[k][c] * x[c] for c in range(k + 1, n))) / M[k][k]
    return x

def polyfit_normal(t, y, deg):
    """정규방정식 (A^T A) c = A^T y"""
    m = deg + 1
    ATA = [[sum(ti**(i + j) for ti in t) for j in range(m)] for i in range(m)]
    ATy = [sum(yi * ti**i for ti, yi in zip(t, y)) for i in range(m)]
    return solve(ATA, ATy)

random.seed(4)
t = [2461000.0 + 0.1 * i for i in range(50)]          # 율리우스일
t0 = sum(t) / len(t)
y = [3 + 0.5 * (ti - t0) + 0.2 * (ti - t0)**2 + random.gauss(0, 0.01) for ti in t]

c_raw = polyfit_normal(t, y, 2)
c_cen = polyfit_normal([ti - t0 for ti in t], y, 2)
rms = lambda c, tt: (sum((yi - sum(ck * ti**k for k, ck in enumerate(c)))**2 for ti, yi in zip(tt, y)) / len(y))**0.5
print(f"t를 그대로: 잔차 rms = {rms(c_raw, t):.3e}")
print(f"t - t0로  : 잔차 rms = {rms(c_cen, [ti - t0 for ti in t]):.3e},  계수 = {[round(c, 4) for c in c_cen]}")
t를 그대로: 잔차 rms = 3.742e-01
t - t0로  : 잔차 rms = 8.634e-03,  계수 = [2.9978, 0.4996, 0.201]

같은 자료, 같은 2차식인데 율리우스일을 그대로 쓰면 잔차가 잡음(0.01)의 37배로 맞춤이 망가지고, 평균 시각을 빼면 잡음 수준의 잔차와 참값(3, 0.5, 0.2)에 가까운 계수를 얻는다. \(A^TA\)의 원소가 1부터 \(t^4 \sim 10^{25}\)까지 퍼져 조건수가 기계 정밀도의 역수를 훨씬 넘기 때문이다(그림 1).

2.3.3피하는 법

가장 쉽고 효과가 큰 방법은 중심화와 규격화이다. 독립 변수에서 평균을 빼고 범위로 나누어 \(u = (t - \bar t)/\Delta t\)를 쓴다. 다음으로 QR 분해 \(A = QR\)(직교 행렬과 위 삼각 행렬의 곱)을 쓰면 \(R\mathbf c = Q^T\mathbf y\)만 풀면 되고 조건수는 \(\kappa(A)\) 그대로이다. numpy.linalg.lstsq 같은 라이브러리 함수가 이렇게, 또는 특이값 분해로 푼다. 또 높은 차수가 필요하면 \(1, t, t^2, \ldots\) 대신 르장드르나 체비셰프 다항식을 써서 기저끼리 거의 직교하게 한다.

예제 2.3.1

\(\kappa(A) = 10^5\)인 최소제곱 문제를 정규방정식으로 풀면 배정밀도에서 대략 몇 자리가 맞는가? QR이면 어떤가?

풀이. 정규방정식은 \(\kappa^2 = 10^{10}\)이므로 16자리 중 약 6자리가 맞는다. QR은 \(\kappa = 10^5\)이므로 약 11자리이다. 측정 오차가 0.1%(3자리)인 자료라면 둘 다 충분하지만, 조건수가 \(10^8\)을 넘으면 정규방정식은 쓸 수 없다.

마무리

조건수 \(\kappa = \sigma_{\max}/\sigma_{\min}\)은 상대 오차를 최대 \(\kappa\)배로 키우는 문제의 성질이다. 정규방정식은 조건수를 제곱하므로, 율리우스일처럼 큰 변수를 그대로 쓰면 맞춤이 무너진다. 중심화와 규격화, QR이나 특이값 분해, 직교 다항식으로 이 문제를 피한다.

2.3.4연습문제

기본

  1. 대각 행렬 \(\text{diag}(1000, 1, 0.001)\)의 조건수는 얼마인가? 입력 오차가 \(10^{-8}\)이면 해의 상대 오차는 최대 얼마인가?
    답

    조건수는 \(1000/0.001 = 10^6\)이고, 해의 상대 오차는 최대 \(10^{-2}\)이다.

응용

  1. 위 코드에서 \(t\) 대신 \(t - 2461000\)(평균이 아닌 어림값)을 빼도 크게 좋아지는가?
    답

    그렇다. 값의 범위가 0~5로 작아져 조건수가 크게 줄어든다(그림 1의 왼쪽). 정확히 평균을 빼면 1차와 2차 기저가 더 직교해 조금 더 좋아진다.

  2. 조건수를 알고리즘이 아니라 문제의 성질이라고 하는 까닭은 무엇인가?
    답

    \(\kappa\)는 행렬 \(A\)만으로 정해지며, 입력의 작은 변화가 정확한 해를 얼마나 바꾸는지 나타낸다. 어떤 알고리즘을 써도 정확한 해 자체가 그만큼 민감하므로 줄일 수 없다. 다만 변수를 바꾸면(중심화) 다른 문제가 되어 조건수가 달라진다.
