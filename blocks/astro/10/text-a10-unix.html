Unix/Linux 명령과 스크립트로 계산 자동화하기

본문 · 1.1절
이 절에서 배울 것
  • Unix 셸의 기본 명령과 파이프로 파일과 자료를 다룬다.
  • 반복 작업을 셸 스크립트로 자동화한다.
  • 여러 작업을 나눠 동시에 돌리는 시간을 어림한다.
먼저 알아야 할 것
  • Python 기초 (천우6 1.1절).

왜 터미널을 배우는가

천문학 자료는 관측 영상 수천 장, 시뮬레이션 출력 수백 GB처럼 크고 많습니다. 마우스로 파일을 하나씩 열 수는 없습니다. 연구용 계산 서버와 슈퍼컴퓨터는 거의 모두 Linux이고 화면 없이 터미널로만 접속합니다. 전산천문학 수업이 흔히 Unix/Linux 프로그래밍으로 시작하는 까닭입니다. Windows에서는 WSL이나 Git Bash로 같은 환경을 쓸 수 있습니다.

1.1.1기본 명령

  • pwd, ls -l, cd 경로: 현재 위치 보기, 목록 보기, 이동.
  • mkdir, cp, mv, rm: 폴더 만들기, 복사, 이동·이름 바꾸기, 지우기(rm은 휴지통이 없으므로 조심).
  • cat, head, tail, less: 파일 내용 보기.
  • grep 패턴 파일: 패턴이 들어 있는 줄 찾기.
  • wc -l, sort, uniq, awk: 줄 세기, 정렬, 중복 제거, 열 단위 처리.
  • 파이프 |: 앞 명령의 출력을 뒤 명령의 입력으로 넘긴다. 방향 바꾸기 >: 출력을 파일로 저장.
예제 1.1.1

관측 기록 파일 log.txt의 각 줄이 "영상이름 필터 노출시간"입니다. V 필터 영상의 노출시간 합계를 구하는 명령은?

풀이. grep " V " log.txt | awk '{s += $3} END {print s}'. grep이 V 필터 줄만 골라 넘기고, awk가 셋째 열을 더해 끝에 출력합니다. 몇만 줄이어도 1초 안에 끝납니다.

1.1.2셸 스크립트

같은 명령을 파일마다 되풀이할 때는 스크립트에 적어 둡니다.

#!/bin/bash
# reduce.sh: raw/ 안의 모든 FITS 영상을 처리해 out/에 저장
mkdir -p out
for f in raw/*.fits; do
    name=$(basename "$f" .fits)
    python reduce.py "$f" "out/${name}_red.fits" > "out/${name}.log" 2>&1
    echo "끝: $name"
done

chmod +x reduce.sh로 실행 권한을 주고 ./reduce.sh로 돌립니다. 접속이 끊겨도 계속 돌게 하려면 nohup ./reduce.sh &이나 tmux를 쓰고, 계산 서버에서는 작업 관리자(Slurm 등)에 sbatch로 제출합니다.

1.1.3나눠서 동시에

파일마다 독립인 작업은 여러 코어에 나눠 동시에 돌릴 수 있습니다(xargs -P 8, GNU parallel).

예제 1.1.2

영상 400장을 한 장에 90초씩 처리합니다. 한 코어로 차례로 하면, 8코어로 나누면 각각 얼마나 걸립니까?

풀이. 차례로 \(400\times90 = 36{,}000\) s = 10시간. 8코어면 이상적으로 1.25시간입니다. 실제로는 디스크 읽기·쓰기가 몰려 조금 더 걸립니다.

주의 스크립트에서 rm *이나 덮어쓰는 >를 쓰기 전에 echo로 대상 목록을 먼저 출력해 확인하세요. 원본 자료(raw)는 읽기 전용으로 두고 결과는 다른 폴더에 쓰는 것이 안전합니다.
요약
  1. 기본 명령: ls, cd, cp, mv, rm, cat, head, grep, wc, sort, awk.
  2. 파이프 |와 방향 바꾸기 >로 명령을 이어 붙인다.
  3. 반복 작업은 for 반복문을 쓴 셸 스크립트로 자동화한다.
  4. 독립 작업은 여러 코어에 나눠 동시에 돌린다.

1.1.4연습문제

기본

  1. 현재 폴더의 .fits 파일 개수를 세는 명령은?
    답

    ls *.fits | wc -l.

  2. head -n 20 a.txt > b.txt는 무엇을 합니까?
    답

    a.txt의 처음 20줄을 b.txt에 저장합니다(b.txt가 있으면 덮어씀).

응용

  1. catalog.csv에서 셋째 열(등급)이 15보다 밝은(작은) 줄만 세는 명령을 쓰세요(쉼표 구분).
    답

    awk -F, '$3 < 15' catalog.csv | wc -l.

  2. 작업 1,000개(각 3분)를 16코어에서 돌리면 대략 얼마나 걸립니까?
    답

    \(1000\times3/16 = 187.5\)분, 약 3시간.
