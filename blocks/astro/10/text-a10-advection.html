이류 방정식과 CFL 조건

본문 · 4.3절

강물에 떨어뜨린 잉크 방울은 모양을 거의 그대로 유지한 채 물결을 따라 흘러간다. 그런데 이 흐름을 컴퓨터로 계산하면, 한 바퀴 돌린 잉크 방울이 절반 높이로 뭉개지거나 거꾸로 점점 커져 터져 버린다. 무엇이 모양을 망가뜨릴까? 시간 간격과 격자 간격 사이에는 어떤 약속이 있어야 할까?

먼저 알아야 할 것확산 방정식의 유한 차분과 안정 조건(4.1절)을 쓴다.

처음 질문의 답은 두 가지이다. 뭉개짐은 차분이 몰래 더한 인위적 확산 때문이고, 폭발은 정보가 한 걸음에 한 칸보다 멀리 가서 생긴다. 뒤의 것이 CFL 조건이다.

4.3.1이류 방정식

\(u_t + cu_x = 0\)의 해는 \(u(x, t) = u_0(x - ct)\)로, 처음 모양이 속력 \(c\)로 그대로 옮겨 간다. 기체 흐름의 밀도, 충격파, 별 대기의 파동 같은 쌍곡형 방정식의 가장 단순한 원형이다. 확산 방정식(4.1절)과 달리 모양이 퍼지지 않아야 하므로, 수치 방법이 만드는 퍼짐이나 진동이 바로 눈에 띈다.

4.3.2두 가지 차분

Courant 수를 \(C = c\Delta t/\Delta x\)라 하자. 중앙 차분(FTCS)은 \(u_i^{n+1} = u_i^n - \tfrac C2(u_{i+1}^n - u_{i-1}^n)\)으로 공간 2차 정확도이지만, 어떤 \(\Delta t\)에서도 불안정하다. 반면 \(c > 0\)일 때 상류 차분은 \(u_i^{n+1} = u_i^n - C(u_i^n - u_{i-1}^n)\)으로 정보가 오는 쪽, 곧 상류의 값만 쓰며 \(C \le 1\)이면 안정하다.

결과 4.3.1 (CFL 조건) \[C = \frac{c\,\Delta t}{\Delta x} \le 1\]

참해에서 \(u_i^{n+1}\)은 한 걸음 전 \(x_i - c\Delta t\)의 값이다. 이 점이 차분이 쓰는 격자점 \(x_{i-1}\)과 \(x_i\) 사이에 있어야 하므로 \(c\Delta t \le \Delta x\)여야 한다. 다시 말해 정보가 한 걸음에 한 칸보다 멀리 가면, 수치 방법은 그 정보를 볼 수 없다.

4.3.3실험

격자 100칸의 주기 경계에서 높이 1의 가우스 봉우리를 한 바퀴 돌려 보자. 참해라면 한 바퀴 뒤에도 높이가 1이다.

import math

def advect(C, scheme="upwind", N=100, laps=1.0):
    """u_t + c u_x = 0, 주기 경계, 격자 N개, Courant 수 C = c dt/dx"""
    dx = 1.0 / N
    u = [math.exp(-((i * dx - 0.5) / 0.05)**2) for i in range(N)]
    steps = round(laps * N / C)
    for _ in range(steps):
        if scheme == "upwind":
            u = [u[i] - C * (u[i] - u[i - 1]) for i in range(N)]
        else:  # 중앙 차분(FTCS)
            u = [u[i] - 0.5 * C * (u[(i + 1) % N] - u[i - 1]) for i in range(N)]
        if max(abs(x) for x in u) > 1e6:
            return steps, float("inf")
    return steps, max(u)

for C in (0.5, 0.9, 1.0, 1.1):
    steps, peak = advect(C)
    print(f"상류 차분 C = {C:3.1f}: {steps:4d}걸음 뒤 봉우리 높이 {peak:.3f}" if peak != float('inf') else f"상류 차분 C = {C:3.1f}: 발산")
steps, peak = advect(0.5, "ftcs")
print(f"중앙 차분 C = 0.5: " + ("발산" if peak == float('inf') else f"{steps}걸음 뒤 봉우리 {peak:.3f}"))
상류 차분 C = 0.5:  200걸음 뒤 봉우리 높이 0.447
상류 차분 C = 0.9:  111걸음 뒤 봉우리 높이 0.746
상류 차분 C = 1.0:  100걸음 뒤 봉우리 높이 1.000
상류 차분 C = 1.1:   91걸음 뒤 봉우리 높이 1.814
중앙 차분 C = 0.5: 200걸음 뒤 봉우리 29269.651

\(C = 1\)이면 상류 차분이 \(u_i^{n+1} = u_{i-1}^n\)이 되어 한 칸씩 정확히 옮기는데, 이는 우연한 정확도이다. \(C < 1\)이면 안정하지만 봉우리가 낮고 넓게 뭉개져, \(C = 0.5\)에서는 절반 아래가 된다(그림 1). 상류 차분이 실제로는 이류에 인위적 확산을 더한 방정식을 풀기 때문이며, 이를 수치 확산이라 한다. 한편 \(C > 1\)이면 봉우리가 커지기 시작해 계속하면 발산하고(세 바퀴면 높이 \(3\times10^5\)), 중앙 차분은 \(C\)가 작아도 진동이 커져 결국 터진다.

그래서 실제 유체 코드는 수치 확산을 줄이려고 락스-벤드로프나 경사 제한자를 쓴 MUSCL 같은 2차 정확도 방법을 쓰고, CFL 조건은 \(C \approx 0.3\sim0.8\)로 여유를 둔다. 이때 음속이나 유속이 가장 빠른 곳이 \(\Delta t\)를 정한다.

예제 4.3.1

태양 대류층 모의실험에서 격자 간격이 10 km, 음속이 최대 100 km/s이면 시간 간격은 최대 얼마인가?

풀이. \(\Delta t \le \Delta x/c = 10/100 = 0.1\) s이고, 여유를 두어 0.05 s쯤 쓴다. 그러면 하루를 계산하는 데 약 170만 걸음이 든다. 또 격자를 2배 촘촘히 하면 3차원에서 칸 수가 8배, 걸음 수가 2배라 계산은 16배가 된다.

마무리

이류 방정식은 모양을 그대로 옮기는 쌍곡형 방정식의 원형이다. 중앙 차분은 늘 불안정하고, 상류 차분은 CFL 조건 \(c\Delta t \le \Delta x\), 곧 정보가 한 걸음에 한 칸을 넘지 않을 때 안정하다. 상류 차분은 수치 확산으로 모양을 뭉개므로, 실전에서는 2차 방법과 여유 있는 Courant 수를 쓴다.

4.3.4연습문제

기본

  1. \(c < 0\)(왼쪽으로 흐름)이면 상류 차분은 어느 이웃을 쓰는가?
    답

    오른쪽 이웃 \(u_{i+1}\)을 쓴다. 정보가 오른쪽에서 오기 때문이다.

응용

  1. \(C = 0.5\)에서 격자를 100칸에서 400칸으로 늘리면 수치 확산은 어떻게 되는가?
    답

    인위적 확산 계수가 \(\Delta x\)에 비례해 줄어 봉우리가 훨씬 덜 뭉개진다. 코드로 돌리면 한 바퀴 뒤 높이가 0.447에서 0.707이 된다. 대신 걸음 수와 칸 수가 각각 4배라 계산은 16배이다.

  2. 확산 방정식의 안정 조건(\(D\Delta t/\Delta x^2 \le 1/2\))과 CFL 조건은 \(\Delta x\)를 줄일 때 어떻게 다른가?
    답

    확산은 \(\Delta t \propto \Delta x^2\), 이류는 \(\Delta t \propto \Delta x\)로 줄어든다. 그래서 격자를 촘촘히 할 때 확산 문제가 시간 간격 제약을 훨씬 심하게 받으며, 암시적 방법을 쓰는 까닭이 된다.
