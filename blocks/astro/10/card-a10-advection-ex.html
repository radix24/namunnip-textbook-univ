폰 노이만 분석으로 안정 조건 유도하기

예제 · 증폭 인자 · CFL
문제 해결 전략 · 폰 노이만 안정성 분석
  1. 해를 파동 하나 \(u_j^n = G^ne^{ij\theta}\)(\(\theta = k\Delta x\))로 두고 차분식에 넣는다.
  2. 한 걸음의 증폭 인자 \(G(\theta)\)를 구한다.
  3. 모든 \(\theta\)에서 \(|G| \le 1\)이면 안정, 하나라도 \(|G| > 1\)이면 그 파동이 지수적으로 자라 불안정.
먼저 예상해 보기. 가장 먼저 터지는 파동은 긴 파장일까요, 격자 두 칸짜리 가장 짧은 파장일까요?

문제. 상류 차분 \(u_j^{n+1} = u_j^n - C(u_j^n - u_{j-1}^n)\)과 중앙 차분 \(u_j^{n+1} = u_j^n - \tfrac C2(u_{j+1}^n - u_{j-1}^n)\)의 증폭 인자를 구하고 안정 조건을 정하세요. \(C = 1.1\)에서 가장 짧은 파동(\(\theta = \pi\))은 한 걸음에 몇 배 자랍니까?

풀이

  1. 상류: \(G = 1 - C(1 - e^{-i\theta})\), \(|G|^2 = 1 - 2C(1 - C)(1 - \cos\theta)\).
    \(|a + ib|^2 = a^2 + b^2\)로 정리.
  2. \(0 \le C \le 1\)이면 \(C(1 - C) \ge 0\)이라 \(|G| \le 1\): 안정. \(C > 1\)이면 \(1 - C < 0\)이라 \(|G| > 1\): 불안정.
    CFL 조건이 수식으로 나온다.
  3. \(C = 1.1\), \(\theta = \pi\): \(|G|^2 = 1 - 2\times1.1\times(-0.1)\times2 = 1.44\), \(|G| = 1.2\). 한 걸음에 20%씩 자란다.
    \(1 - \cos\pi = 2\)로 가장 크다.
  4. 중앙: \(G = 1 - iC\sin\theta\), \(|G|^2 = 1 + C^2\sin^2\theta > 1\)(\(\theta \ne 0, \pi\)). 어떤 \(C\)에서도 불안정.
    본문 실험과 같은 결론.

의미

격자 두 칸짜리 짧은 파동이 가장 먼저 터집니다. 그래서 불안정한 계산은 결과가 '톱니 모양'으로 번쩍이다 발산합니다. 반대로 \(C < 1\)에서 짧은 파동은 \(|G| < 1\)로 줄어드는데, 이것이 봉우리가 뭉개지는 수치 확산의 정체입니다.

검산

본문에서 \(C = 1.1\)로 91걸음 돌렸을 때 봉우리가 1.8배였습니다. 가장 짧은 파동만 20%씩 자라고 매끄러운 봉우리는 대부분 긴 파동이라, 처음에는 천천히 커지다 짧은 파동이 자라면서 급히 발산합니다(세 바퀴면 \(3\times10^5\)). \(C = 1\)이면 \(|G| = 1\)로 모든 파동이 그대로 옮겨져 정확한 결과와 맞습니다.

이해 확인

상류 차분에서 \(C = 0.5\)일 때 \(\theta = \pi\) 파동은 한 걸음에 몇 배가 됩니까?

답

\(|G|^2 = 1 - 2\times0.5\times0.5\times2 = 0\), \(G = 0\). 가장 짧은 파동은 한 걸음에 완전히 지워집니다. 수치 확산이 가장 짧은 파장에서 가장 강합니다.
