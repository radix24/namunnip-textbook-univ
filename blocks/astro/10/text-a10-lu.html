가우스 소거와 LU 분해로 연립방정식 풀기

본문 · 2.1절
이 절에서 배울 것
  • 가우스 소거의 단계를 손으로 따라 하고 LU 분해와의 관계를 안다.
  • 부분 피벗이 필요한 까닭을 반올림 오차로 설명한다.
  • 계산량 \(\frac23n^3\)으로 큰 계의 계산 시간을 어림한다.
먼저 알아야 할 것
  • 행렬과 연립방정식 (수학2 선형대수), 반올림 오차 (천우6 2.1절).

천문학 속의 연립방정식

최소제곱 맞춤의 정규방정식, 측광 보정에서 여러 별을 함께 맞추는 문제, 편미분방정식의 암시적 차분(4.1절)은 모두 \(A\mathbf x = \mathbf b\) 꼴의 연립방정식이 됩니다. 미지수가 수천~수백만 개일 수 있어 효율적인 풀이가 필요합니다.

행렬과 벡터 표기 연립방정식 \(2x + y = 5\), \(4x + 3y = 13\)을 계수만 모아 \(A = \begin{pmatrix}2&1\\4&3\end{pmatrix}\), 미지수 \(\mathbf x = (x, y)\), 오른쪽 \(\mathbf b = (5, 13)\)로 적고 \(A\mathbf x = \mathbf b\)라 씁니다. 행렬과 벡터의 곱 \(A\mathbf x\)는 '각 행의 계수와 미지수를 곱해 더한 것'으로, 원래 연립방정식의 왼쪽과 같습니다. 이 절의 계산은 모두 고교에서 배운 가감법(한 식의 배수를 다른 식에서 빼기)을 표로 정리한 것입니다.

2.1.1가우스 소거

한 식의 배수를 다른 식에서 빼서 아래쪽 계수를 차례로 0으로 만들고(전진 소거), 마지막 식부터 거꾸로 푸는(후진 대입) 방법입니다.

예제 2.1.1

\(2x + y + z = 5\), \(4x + 3y + 3z = 13\), \(2x + 3y + 4z = 13\)을 가우스 소거로 푸세요.

풀이. 둘째 식에서 첫째 식의 2배를 빼면 \(y + z = 3\), 셋째 식에서 첫째 식을 빼면 \(2y + 3z = 8\). 다시 셋째에서 새 둘째의 2배를 빼면 \(z = 2\). 거꾸로 \(y = 3 - 2 = 1\), \(x = (5 - 1 - 2)/2 = 1\). 답 \((1, 1, 2)\)이고, 원래 세 식에 넣어 확인하면 5, 13, 13이 나옵니다.

2.1.2LU 분해

소거에 쓴 배수(2, 1, 2)를 아래 삼각 행렬 \(L\)에, 소거 결과를 위 삼각 행렬 \(U\)에 모으면 \(A = LU\)입니다.

\[ \begin{pmatrix}2&1&1\\4&3&3\\2&3&4\end{pmatrix} = \begin{pmatrix}1&0&0\\2&1&0\\1&2&1\end{pmatrix}\begin{pmatrix}2&1&1\\0&1&1\\0&0&1\end{pmatrix} \]

한 번 분해해 두면 오른쪽 \(\mathbf b\)가 바뀔 때마다 \(L\mathbf y = \mathbf b\)(전진), \(U\mathbf x = \mathbf y\)(후진)만 풀면 됩니다. 분해는 약 \(\frac23n^3\)번, 대입은 약 \(2n^2\)번의 연산입니다. 같은 행렬로 오른쪽만 바뀌는 문제(시간마다 같은 계수의 암시적 차분 등)에서 크게 이득입니다.

2.1.3부분 피벗

소거 중 대각 원소(피벗)가 0이거나 아주 작으면 큰 배수로 나눠 반올림 오차가 커집니다. 남은 행 가운데 그 열의 절댓값이 가장 큰 행을 올려 쓰는 것을 부분 피벗이라 합니다.

예제 2.1.2

\(10^{-20}x + y = 1\), \(x + y = 2\)를 배정밀도(유효숫자 약 16자리)로 피벗 없이 풀면?

풀이. 둘째 식에서 첫째의 \(10^{20}\)배를 빼면 \((1 - 10^{20})y = 2 - 10^{20}\)인데, 반올림으로 \(-10^{20}y = -10^{20}\), \(y = 1\). 첫째 식에서 \(x = (1 - 1)/10^{-20} = 0\). 참값은 \(x \approx 1\), \(y \approx 1\)이므로 \(x\)가 완전히 틀립니다. 두 행을 바꿔 \(x + y = 2\)를 피벗으로 쓰면 \(y = 1\), \(x = 1\)로 바르게 나옵니다.

import numpy as np, scipy.linalg as sl
A = np.array([[2., 1, 1], [4, 3, 3], [2, 3, 4]]); b = np.array([5., 13, 13])
print(np.linalg.solve(A, b))          # [1. 1. 2.]
P, L, U = sl.lu(A)                     # 부분 피벗을 쓴 LU (P는 행 바꿈)

라이브러리는 피벗을 자동으로 쓰므로 위의 손 계산과 \(L, U\)가 다를 수 있습니다(행이 바뀜).

주의 역행렬 \(A^{-1}\)을 구해 \(\mathbf b\)에 곱하는 것은 LU 풀이보다 느리고 부정확합니다. 연립방정식은 solve로 풉니다. 또 조건수 \(\kappa(A)\)가 \(10^k\)이면 답의 유효숫자를 약 \(k\)자리 잃습니다(np.linalg.cond).
요약
  1. 가우스 소거: 전진 소거 + 후진 대입.
  2. \(A = LU\): 분해 \(\frac23n^3\), 오른쪽마다 대입 \(2n^2\).
  3. 부분 피벗: 작은 피벗으로 나누는 반올림 오차를 막는다.
  4. 역행렬을 곱하지 말고 solve를 쓴다. 조건수가 정확도를 정한다.

2.1.4연습문제

기본

  1. \(x + 2y = 5\), \(3x + 4y = 11\)을 소거로 푸세요.
    답

    둘째에서 첫째의 3배를 빼면 \(-2y = -4\), \(y = 2\), \(x = 1\).

  2. \(n = 1000\)인 계의 LU 분해는 약 몇 번의 연산입니까?
    답

    \(\frac23\times10^9 \approx 6.7\times10^8\)번. 초당 \(10^{10}\)번이면 0.07초.

응용

  1. \(n\)이 10배가 되면 LU 분해 시간은?
    답

    1,000배.

  2. 같은 \(A\)로 오른쪽 \(\mathbf b\)가 1,000개인 문제(\(n = 1000\))에서 매번 소거하는 것과 LU를 한 번 하는 것의 연산량을 비교하세요.
    답

    매번: \(1000\times6.7\times10^8 = 6.7\times10^{11}\). LU 한 번: \(6.7\times10^8 + 1000\times2\times10^6 = 2.7\times10^9\). 약 250배 빠릅니다.
