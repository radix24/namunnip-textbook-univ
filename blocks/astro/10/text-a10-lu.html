가우스 소거와 LU 분해로 연립방정식 풀기

본문 · 2.1절

연립방정식은 고교에서 배운 가감법으로 푼다. 그런데 컴퓨터가 \(10^{-20}x + y = 1\), \(x + y = 2\)를 같은 방법으로 풀면 \(x = 0\)이라는 엉뚱한 답을 낸다. 참값은 \(x \approx 1\)이다. 손으로는 맞는 방법이 왜 컴퓨터에서는 틀릴까? 그리고 미지수가 수천 개면 얼마나 걸릴까?

먼저 알아야 할 것행렬과 연립방정식(수학2 선형대수)과 반올림 오차(천우6 2.1절)를 쓴다.

최소제곱 맞춤의 정규방정식, 측광 보정에서 여러 별을 함께 맞추는 문제, 편미분방정식의 암시적 차분(4.1절)은 모두 \(A\mathbf x = \mathbf b\) 꼴의 연립방정식이 된다. 미지수가 수천에서 수백만 개일 수 있어 효율적이고 안전한 풀이가 필요하다.

행렬과 벡터 표기 연립방정식 \(2x + y = 5\), \(4x + 3y = 13\)을 계수만 모아 \(A = \begin{pmatrix}2&1\\4&3\end{pmatrix}\), 미지수 \(\mathbf x = (x, y)\), 오른쪽 \(\mathbf b = (5, 13)\)으로 적고 \(A\mathbf x = \mathbf b\)라 쓴다. 행렬과 벡터의 곱 \(A\mathbf x\)는 각 행의 계수와 미지수를 곱해 더한 것으로, 원래 연립방정식의 왼쪽과 같다. 이 절의 계산은 모두 가감법을 표로 정리한 것이다.

2.1.1가우스 소거

가우스 소거는 한 식의 배수를 다른 식에서 빼서 아래쪽 계수를 차례로 0으로 만들고(전진 소거), 마지막 식부터 거꾸로 푸는(후진 대입) 방법이다.

예제 2.1.1

\(2x + y + z = 5\), \(4x + 3y + 3z = 13\), \(2x + 3y + 4z = 13\)을 가우스 소거로 풀어라.

풀이. 둘째 식에서 첫째 식의 2배를 빼면 \(y + z = 3\)이고, 셋째 식에서 첫째 식을 빼면 \(2y + 3z = 8\)이다. 다시 셋째에서 새 둘째의 2배를 빼면 \(z = 2\)이다. 거꾸로 \(y = 3 - 2 = 1\), \(x = (5 - 1 - 2)/2 = 1\)이므로 답은 \((1, 1, 2)\)이다. 원래 세 식에 넣으면 5, 13, 13이 나와 확인된다.

2.1.2LU 분해

소거에 쓴 배수(2, 1, 2)를 아래 삼각 행렬 \(L\)에, 소거 결과를 위 삼각 행렬 \(U\)에 모으면 \(A = LU\)이다.

\[ \begin{pmatrix}2&1&1\\4&3&3\\2&3&4\end{pmatrix} = \begin{pmatrix}1&0&0\\2&1&0\\1&2&1\end{pmatrix}\begin{pmatrix}2&1&1\\0&1&1\\0&0&1\end{pmatrix} \]

한 번 분해해 두면 오른쪽 \(\mathbf b\)가 바뀔 때마다 \(L\mathbf y = \mathbf b\)(전진)와 \(U\mathbf x = \mathbf y\)(후진)만 풀면 된다. 분해는 약 \(\frac23n^3\)번, 대입은 약 \(2n^2\)번의 연산이다. 그러므로 시간마다 같은 계수의 암시적 차분처럼, 같은 행렬로 오른쪽만 바뀌는 문제에서 크게 이득이다.

2.1.3부분 피벗

소거 중 대각 원소, 곧 피벗이 0이거나 아주 작으면 큰 배수로 나눠 반올림 오차가 커진다. 처음 질문의 답이 이것이다(그림 1). 그래서 남은 행 가운데 그 열의 절댓값이 가장 큰 행을 올려 쓰는데, 이를 부분 피벗이라 한다.

예제 2.1.2

\(10^{-20}x + y = 1\), \(x + y = 2\)를 배정밀도(유효숫자 약 16자리)로 피벗 없이 풀면 어떻게 되는가?

풀이. 둘째 식에서 첫째의 \(10^{20}\)배를 빼면 \((1 - 10^{20})y = 2 - 10^{20}\)인데, 반올림으로 \(-10^{20}y = -10^{20}\)이 되어 \(y = 1\)이다. 그러면 첫째 식에서 \(x = (1 - 1)/10^{-20} = 0\)이다. 참값은 \(x \approx 1\), \(y \approx 1\)이므로 \(x\)가 완전히 틀렸다. 반면 두 행을 바꿔 \(x + y = 2\)를 피벗으로 쓰면 \(y = 1\), \(x = 1\)로 바르게 나온다.

import numpy as np, scipy.linalg as sl
A = np.array([[2., 1, 1], [4, 3, 3], [2, 3, 4]]); b = np.array([5., 13, 13])
print(np.linalg.solve(A, b))          # [1. 1. 2.]
P, L, U = sl.lu(A)                     # 부분 피벗을 쓴 LU (P는 행 바꿈)

라이브러리는 피벗을 자동으로 쓰므로, 행이 바뀌어 위의 손 계산과 \(L, U\)가 다를 수 있다.

주의역행렬 \(A^{-1}\)을 구해 \(\mathbf b\)에 곱하는 것은 LU 풀이보다 느리고 부정확하므로, 연립방정식은 solve로 푼다. 또 조건수가 \(10^k\)이면 답의 유효숫자를 약 \(k\)자리 잃는다(2.3절).
마무리

가우스 소거는 전진 소거와 후진 대입으로 연립방정식을 풀며, 그 배수를 모으면 \(A = LU\)가 된다. 분해는 약 \(\frac23n^3\)번, 오른쪽마다의 대입은 \(2n^2\)번이라 오른쪽이 여러 개일 때 이득이다. 작은 피벗으로 나누면 반올림 오차가 폭주하므로 부분 피벗을 쓰고, 역행렬 대신 solve를 쓴다.

2.1.4연습문제

기본

  1. \(n = 1000\)인 계의 LU 분해는 약 몇 번의 연산인가? 초당 \(10^{10}\)번 계산하면 얼마나 걸리는가?
    답

    \(\frac23\times10^9 = 6.7\times10^8\)번이므로 약 0.07초이다.

응용

  1. 같은 \(A\)(\(n = 1000\))로 오른쪽 \(\mathbf b\)가 1,000개인 문제에서, 매번 소거하는 것과 LU를 한 번 하는 것의 연산량을 비교하여라.
    답

    매번 소거하면 \(1000\times6.7\times10^8 = 6.7\times10^{11}\)번이다. LU를 한 번 하면 \(6.7\times10^8 + 1000\times2\times10^6 = 2.7\times10^9\)번으로, 약 250배 빠르다.

  2. 그림 1에서 \(\varepsilon = 10^{-8}\)일 때 피벗 없는 풀이의 상대 오차는 대략 얼마로 예상되는가?
    답

    기계 정밀도 약 \(10^{-16}\)이 \(1/\varepsilon = 10^8\)배로 커져 약 \(10^{-8}\)이다. 실제 계산에서도 \(5\times10^{-9}\)이 나온다.
