확산 방정식을 유한 차분으로 풀고 안정 조건 판단하기

본문 · 4.1절

열이 퍼지는 계산을 하는데, 시간 간격을 조금 키웠더니 100걸음 뒤 온도가 \(10^{13}\)으로 폭발했다. 물리적으로 열은 고르게 퍼질 뿐 저절로 커질 수 없다. 그렇다면 이 폭발은 어디서 왔을까? 시간 간격을 얼마나 작게 잡아야 안전할까?

먼저 알아야 할 것유한 차분 도함수(천우6 4.1절), LU 분해(2.1절), 복사 확산(천우9 3.1절)을 쓴다.

열, 광자 에너지, 강착 원반의 질량, 자기장은 확산하며 퍼진다. 이들은 모두 확산 방정식을 따른다.

\[ \frac{\partial u}{\partial t} = D\frac{\partial^2u}{\partial x^2} \]

공간을 \(\Delta x\), 시간을 \(\Delta t\) 간격의 격자로 나누고 도함수를 차분으로 바꾸면 컴퓨터로 풀 수 있다. 처음 질문의 답은 그 차분이 반올림 오차를 키울 수 있다는 데 있다.

4.1.1명시적 방법(FTCS)

시간은 앞 차분, 공간은 가운데 차분으로 바꾸면 다음을 얻는다.

\[ u_i^{n+1} = u_i^n + r\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right), \qquad r = \frac{D\Delta t}{\Delta x^2} \]

새 값이 옛 값만으로 바로 계산되므로 간단하다.

4.1.2안정 조건

유도. 폰 노이만의 방법으로 오차를 파동 성분 \(u_i^n = G^ne^{ikx_i}\)로 나눠 넣으면 \(G = 1 + r(e^{ik\Delta x} - 2 + e^{-ik\Delta x}) = 1 - 4r\sin^2(k\Delta x/2)\)이다. 오차가 자라지 않으려면 모든 \(k\)에서 \(|G| \le 1\)이어야 하고, 가장 나쁜 성분, 곧 \(\sin^2 = 1\)인 두 칸짜리 파장에서 \(|1 - 4r| \le 1\)이어야 한다. 따라서 안정 조건은 \(r = D\Delta t/\Delta x^2 \le \frac12\)이다. ∎

처음 질문의 폭발이 이것이다(그림 1). \(r\)이 1/2을 넘으면 두 칸짜리 파장의 반올림 오차가 걸음마다 \(|1 - 4r|\)배로 자란다. 실습에서 \(r = 0.52\)로 조금만 넘겨도 100걸음 뒤 최댓값이 77로 폭발한다. 게다가 격자를 2배 촘촘히 하면 \(\Delta t\)를 4배 줄여야 하므로 계산량이 8배가 된다.

4.1.3암시적 방법(BTCS)

공간 차분을 새 시간의 값으로 쓰면 다음과 같다.

\[ -ru_{i-1}^{n+1} + (1 + 2r)u_i^{n+1} - ru_{i+1}^{n+1} = u_i^n \]

이때 \(G = 1/(1 + 4r\sin^2(k\Delta x/2))\)이라 어떤 \(r\)에서도 \(|G| \le 1\)로 무조건 안정하다. 대신 걸음마다 삼중 대각 연립방정식을 풀어야 하지만, 삼중 대각용 가우스 소거인 토마스 알고리즘은 \(N\)에 비례하는 연산으로 끝난다.

예제 4.1.1

격자 50칸의 가운데에 높이 1, 폭 11칸의 사각형을 두고 같은 시간 \(Dt = 0.016\)까지 적분한다. 명시적 방법과 암시적 방법의 결과를 비교하여라.

풀이. 실습 카드로 돌려 보면 명시적 방법(\(r = 0.4\), 100걸음)의 최댓값은 0.4608, 암시적 방법(\(r = 0.4\), 100걸음)은 0.4635이다. 암시적 방법은 \(r = 2\)로 20걸음만 가도 0.4689로 안정하며, 걸음이 5배 적은 대신 시간 오차가 조금 크다. 반면 명시적 방법을 \(r = 0.6\)으로 100걸음 가면(\(Dt = 0.024\)) \(1.5\times10^{13}\)으로 폭발한다.

천체물리에서는 별 내부의 복사 확산처럼 확산이 빠른 곳과 느린 곳이 함께 있어, 명시적 방법의 \(\Delta t\)가 지나치게 작아지기 쉽다. 그래서 확산 항은 대개 암시적으로 푼다.

흔한 오해무조건 안정이 정확하다는 뜻은 아니다. \(r\)이 크면 시간 오차가 커지고 빠르게 변하는 현상을 놓친다. 정확도가 필요하면 명시와 암시의 평균인 2차 정확도의 크랭크-니콜슨 방법을 쓴다.
마무리

명시적 방법은 \(u_i^{n+1} = u_i^n + r(u_{i+1} - 2u_i + u_{i-1})\)이고, 폰 노이만 분석의 \(G = 1 - 4r\sin^2(k\Delta x/2)\)에서 안정 조건 \(r \le 1/2\)이 나온다. 암시적 방법은 무조건 안정하며, 삼중 대각계를 토마스 알고리즘으로 \(N\)번 정도의 연산에 푼다. 격자를 2배 촘촘히 하면 명시적 방법은 계산량이 8배가 된다.

4.1.4연습문제

기본

  1. \(D = 1\), \(\Delta x = 0.02\)이면 명시적 방법의 최대 \(\Delta t\)는 얼마인가?
    답

    \(0.5\times0.0004 = 2\times10^{-4}\)이다.

응용

  1. \(r = 0.6\)에서 반올림 오차 \(10^{-16}\)이 \(10^{-2}\)까지 자라는 데 몇 걸음이 걸리는가?
    답

    \(|G| = 1.4\)이므로 \(1.4^n = 10^{14}\)에서 \(n = 14/\log1.4 = 96\)걸음이다.

  2. 1차원 격자 1,000칸의 암시적 방법 한 걸음을 일반 가우스 소거와 토마스 알고리즘으로 풀면 각각 몇 번의 연산이 드는가?
    답

    가우스 소거는 약 \(\frac23\times10^9\)번, 토마스 알고리즘은 약 \(8\times10^3\)번이다.
