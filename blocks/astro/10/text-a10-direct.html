직접 합산법으로 N체 중력 가속도 계산하기

본문 · 3.1절

성단의 진화, 은하의 충돌, 우주 거대 구조의 형성은 모두 수많은 천체가 서로 끌어당기며 움직이는 N체 문제이다. 세 천체만 되어도 해석적으로 풀 수 없으니 컴퓨터로 적분해야 한다. 그런데 별 백만 개의 성단이라면 한 걸음마다 쌍이 몇 개나 될까? 그 계산을 줄이는 길은 없을까?

먼저 알아야 할 것만유인력(천우1 1.3절)과 궤도 적분(천우6 5.1절)을 쓴다.

N체 모의실험은 전산천문학의 핵심 주제이다. 처음 질문의 첫째 답은 직접 합산의 쌍 수 \(N(N-1)/2\)이고, 둘째 답은 그림 1의 트리 방법 같은 근사이다.

3.1.1직접 합산

입자 \(i\)의 가속도는 다른 모든 입자가 주는 중력의 합이다.

\[ \mathbf a_i = -G\sum_{j \ne i} m_j\frac{\mathbf r_i - \mathbf r_j}{\left(|\mathbf r_i - \mathbf r_j|^2 + \varepsilon^2\right)^{3/2}} \]

여기서 \(\varepsilon\)은 두 입자가 아주 가까울 때 힘이 무한대가 되는 것을 막는 연화 길이이다(3.3절). 쌍마다 계산하므로 한 걸음에 \(N(N-1)\)번, 뉴턴 제3법칙(\(\mathbf F_{ij} = -\mathbf F_{ji}\))을 쓰면 \(N(N-1)/2\)번이다.

import numpy as np
def accel(r, m, eps, G=1.0):
    d = r[None, :, :] - r[:, None, :]          # d[i, j] = r_j - r_i
    r2 = (d**2).sum(-1) + eps**2
    np.fill_diagonal(r2, np.inf)                # 자기 자신 제외
    return G * (m[None, :, None] * d / r2[..., None]**1.5).sum(1)

이 코드는 numpy의 배열 연산으로 반복문 없이 모든 쌍을 한 번에 계산한다. 다만 메모리가 \(N^2\)에 비례하므로, \(N\)이 수천을 넘으면 블록으로 나누거나 C, Fortran, Numba 같은 컴파일 언어를 쓴다.

예제 3.1.1

초당 \(10^9\)쌍을 계산하는 컴퓨터에서 \(N = 10^5\)인 성단을 1만 걸음 적분하는 데 얼마나 걸리는가?

풀이. 한 걸음에 \(N^2/2 = 5\times10^9\)쌍이므로 5초이고, 1만 걸음이면 5만 초, 곧 약 14시간이다. \(N = 10^6\)이면 100배인 약 58일이라, 구상성단 규모의 직접 합산에는 GPU나 GRAPE 같은 특수 하드웨어를 쓴다.

3.1.2더 빠른 방법

트리 방법(반스-헛)은 멀리 있는 입자 무리를 무게 중심 하나로 묶어 계산하므로 계산량이 \(N\log N\)이며, 은하 모의실험에 쓴다(그림 1). 입자-격자(PM) 방법은 질량을 격자에 뿌리고 푸아송 방정식을 FFT로 풀어 힘을 구하며, 역시 \(N\log N\)으로 우주론 모의실험에 쓴다. 한편 TreePM은 가까운 힘은 트리로, 먼 힘은 격자로 구하며 GADGET 같은 공개 코드가 이 방식이다.

그러므로 근접 조우와 쌍성이 중요한 성단에는 정확한 직접 합산(NBODY6 등)이, 입자 하나가 별 수백만 개를 대표하는 은하와 우주론 모의실험에는 근사 방법이 알맞다.

주의직접 합산 코드는 두 입자, 세 입자처럼 답을 아는 경우로 먼저 시험한다. 전체 운동량이 보존되는지, 곧 \(\sum m_i\mathbf a_i\)가 0인지 확인하면 부호 실수를 쉽게 찾는다.
마무리

N체의 가속도는 \(\mathbf a_i = -G\sum m_j(\mathbf r_i - \mathbf r_j)/(r_{ij}^2 + \varepsilon^2)^{3/2}\)로 모든 쌍을 더해 구한다. 직접 합산은 한 걸음에 \(N^2/2\)쌍이라 \(N = 10^5\)이면 수 초가 든다. 트리, 입자-격자, TreePM은 \(N\log N\)으로 줄이며, 성단에는 직접 합산을, 은하와 우주론에는 근사 방법을 쓴다.

3.1.3연습문제

기본

  1. \(N = 1000\)이면 한 걸음에 쌍이 몇 개인가? 입자 수를 2배로 하면 시간은 몇 배가 되는가?
    답

    약 \(5\times10^5\)개이고, 시간은 4배가 된다.

응용

  1. \(N = 10^6\)에서 직접 합산(\(N^2/2\))과 트리(\(\approx 20N\log_2N\))의 연산 비를 어림하여라.
    답

    \(5\times10^{11}\) 대 \(20\times10^6\times20 = 4\times10^8\)이므로 약 1,250배이다.

  2. 코드에서 전체 운동량 보존을 확인하는 방법은 무엇인가?
    답

    \(\sum m_i\mathbf a_i\)가 반올림 수준에서 0인지 본다. 쌍의 힘이 서로 같고 반대이면 0이다.
