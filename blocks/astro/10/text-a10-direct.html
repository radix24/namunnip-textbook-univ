직접 합산법으로 N체 중력 가속도 계산하기

본문 · 3.1절
이 절에서 배울 것
  • N개 입자의 중력 가속도를 직접 합산으로 계산한다.
  • 계산량 \(N^2\)으로 시간을 어림하고 빠른 방법(트리, 입자-격자)을 안다.
먼저 알아야 할 것
  • 만유인력 (천우1 1.3절), 궤도 적분 (천우6 5.1절).

성단과 은하를 컴퓨터 속에

성단의 진화, 은하의 충돌, 우주 거대 구조의 형성은 수많은 천체가 서로 끌어당기며 움직이는 N체 문제입니다. 해석적으로 풀 수 없어 컴퓨터로 적분합니다. 전산천문학의 핵심 주제입니다.

3.1.1직접 합산

입자 \(i\)의 가속도는 다른 모든 입자가 주는 중력의 합입니다.

\[ \mathbf a_i = -G\sum_{j \ne i} m_j\frac{\mathbf r_i - \mathbf r_j}{\left(|\mathbf r_i - \mathbf r_j|^2 + \varepsilon^2\right)^{3/2}} \]

\(\varepsilon\)은 두 입자가 아주 가까울 때 힘이 무한대가 되는 것을 막는 연화 길이입니다(3.3절). 쌍마다 계산하므로 한 걸음에 \(N(N-1)\)번, 뉴턴 제3법칙(\(\mathbf F_{ij} = -\mathbf F_{ji}\))을 쓰면 \(N(N-1)/2\)번입니다.

import numpy as np
def accel(r, m, eps, G=1.0):
    d = r[None, :, :] - r[:, None, :]          # d[i, j] = r_j - r_i
    r2 = (d**2).sum(-1) + eps**2
    np.fill_diagonal(r2, np.inf)                # 자기 자신 제외
    return G * (m[None, :, None] * d / r2[..., None]**1.5).sum(1)

numpy의 배열 연산으로 반복문 없이 모든 쌍을 한 번에 계산합니다. 메모리가 \(N^2\)에 비례하므로 \(N\)이 수천을 넘으면 블록으로 나누거나 컴파일 언어(C, Fortran, 또는 Numba)를 씁니다.

예제 3.1.1

초당 \(10^9\)쌍을 계산하는 컴퓨터에서 \(N = 10^5\)인 성단을 1만 걸음 적분하는 시간은?

풀이. 한 걸음 \(N^2/2 = 5\times10^9\)쌍 → 5초, 1만 걸음 5만 초 ≈ 14시간입니다. \(N = 10^6\)이면 100배인 약 58일이라, 구상성단 규모의 직접 합산은 GPU나 특수 하드웨어(GRAPE)를 씁니다.

3.1.2더 빠른 방법

  • 트리 방법(Barnes-Hut): 멀리 있는 입자 무리를 무게 중심 하나로 묶어 계산한다. \(N\log N\). 은하 시뮬레이션.
  • 입자-격자(PM): 질량을 격자에 뿌리고 푸아송 방정식을 FFT로 풀어 힘을 구한다. \(N\log N\). 우주론 시뮬레이션.
  • TreePM: 가까운 힘은 트리, 먼 힘은 격자. GADGET 같은 공개 코드.

근접 조우와 쌍성이 중요한 성단은 정확한 직접 합산(NBODY6 등)이, 입자 하나가 별 수백만 개를 대표하는 은하·우주론 시뮬레이션은 근사 방법이 알맞습니다.

주의 직접 합산 코드는 두 입자, 세 입자처럼 답을 아는 경우로 먼저 시험하세요. 전체 운동량이 보존되는지(합이 0인지) 확인하면 부호 실수를 쉽게 찾습니다.
요약
  1. \(\mathbf a_i = -G\sum m_j(\mathbf r_i - \mathbf r_j)/(r_{ij}^2 + \varepsilon^2)^{3/2}\).
  2. 직접 합산은 한 걸음에 \(N^2/2\)쌍: \(N = 10^5\)이면 수 초.
  3. 트리, 입자-격자, TreePM은 \(N\log N\).
  4. 성단은 직접 합산, 은하·우주론은 근사 방법.

3.1.3연습문제

기본

  1. \(N = 1000\)이면 한 걸음에 쌍이 몇 개?
    답

    약 \(5\times10^5\)개.

  2. 입자 수를 2배로 하면 직접 합산 시간은?
    답

    4배.

응용

  1. \(N = 10^6\)에서 직접 합산(\(N^2/2\))과 트리(\(\approx 20N\log_2N\))의 연산 비를 어림하세요.
    답

    \(5\times10^{11}\) 대 \(20\times10^6\times20 = 4\times10^8\), 약 1,250배.

  2. 전체 운동량 보존을 확인하는 방법은?
    답

    \(\sum m_i\mathbf a_i\)가 0(반올림 수준)인지 봅니다. 쌍의 힘이 서로 같고 반대이면 0입니다.
