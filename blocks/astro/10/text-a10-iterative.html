큰 희소 연립방정식은 반복해서 푼다

본문
이 절에서 배울 것
  • 편미분방정식을 격자로 바꾸면 대부분이 0인 큰 희소 행렬이 생김을 안다.
  • 야코비, 가우스-자이델, SOR 반복법을 쓰고 수렴 빠르기를 비교한다.
  • 반복을 멈추는 기준과, 반복 오차와 격자(이산화) 오차를 구별한다.
먼저 알아야 할 것
  • 가우스 소거 (2.1절), 유한 차분 (4.1절).

2.4.1왜 반복법인가

중력 퍼텐셜의 푸아송 방정식 \(\nabla^2\Phi = 4\pi G\rho\)를 3차원 격자 \(100^3\)에 놓으면 미지수가 \(10^6\)개입니다. 가우스 소거는 \(O(N^3) = 10^{18}\)번 연산과 \(10^{12}\)개 원소의 메모리가 필요해 불가능합니다. 하지만 각 방정식에는 이웃 몇 개만 들어 있어(희소 행렬) 0이 아닌 원소는 수백만 개뿐입니다. 반복법은 이 원소만으로 답을 조금씩 다듬습니다.

2.4.2세 가지 반복

1차원 \(-u'' = f\)를 간격 \(h\)로 차분하면 \(-u_{i-1} + 2u_i - u_{i+1} = h^2f_i\)입니다. 각 식을 \(u_i\)에 대해 풀어 되풀이합니다.

정의 2.4.1
  • 야코비: \(u_i^{\text{새}} = \tfrac12(u_{i-1}^{\text{옛}} + u_{i+1}^{\text{옛}} + h^2f_i)\). 모두 옛 값으로.
  • 가우스-자이델: 이미 새로 고친 \(u_{i-1}\)을 바로 쓴다.
  • SOR: 가우스-자이델의 고침을 \(\omega\)배(\(1 < \omega < 2\)) 더 밀어 준다. \(u_i \leftarrow u_i + \omega(u_i^{\text{GS}} - u_i)\).

참해가 \(u = \sin\pi x\)인 문제(격자점 50개)로 비교합니다.

import math

# -u'' = pi^2 sin(pi x), u(0) = u(1) = 0, 참해 u = sin(pi x)
N = 50                       # 안쪽 격자점 수
h = 1.0 / (N + 1)
f = [math.pi**2 * math.sin(math.pi * (i + 1) * h) for i in range(N)]

def solve(method, omega=1.0, tol=1e-8, maxit=100000):
    u = [0.0] * N
    for it in range(1, maxit + 1):
        old = u[:] if method == "jacobi" else None
        diff = 0.0
        for i in range(N):
            left = (old if old else u)[i - 1] if i > 0 else 0.0
            right = (old if old else u)[i + 1] if i < N - 1 else 0.0
            new = 0.5 * (left + right + h * h * f[i])
            if method == "sor":
                new = u[i] + omega * (new - u[i])
            diff = max(diff, abs(new - u[i]))
            u[i] = new
        if diff < tol:
            return it, max(abs(u[i] - math.sin(math.pi * (i + 1) * h)) for i in range(N))
    return maxit, None

omega = 2 / (1 + math.sin(math.pi * h))     # 1차원 문제의 최적 SOR 계수
for name, m, w in (("야코비", "jacobi", 1.0), ("가우스-자이델", "gs", 1.0), (f"SOR(ω={omega:.3f})", "sor", omega)):
    it, err = solve(m, w)
    print(f"{name:16s}: {it:6d}번 반복, 참해와의 최대 차 {err:.2e}")
야코비             :   6403번 반복, 참해와의 최대 차 3.11e-04
가우스-자이델         :   3385번 반복, 참해와의 최대 차 3.14e-04
SOR(ω=1.884)    :    162번 반복, 참해와의 최대 차 3.16e-04

가우스-자이델은 야코비의 약 절반, 알맞은 \(\omega\)의 SOR은 약 40분의 1의 반복으로 끝납니다. 야코비와 가우스-자이델은 격자점 수 \(N\)에 대해 반복 횟수가 \(N^2\)으로 늘지만, 최적 SOR은 \(N\)으로만 늘어 큰 문제일수록 차이가 커집니다.

2.4.3반복 오차와 격자 오차

세 방법 모두 참해와의 차가 \(3\times10^{-4}\)에서 멈췄습니다. 반복을 \(10^{-8}\)까지 했는데도 그런 까닭은, 이것이 반복의 오차가 아니라 미분을 차분으로 바꾼 격자 오차(\(\propto h^2\))이기 때문입니다. 격자 오차보다 훨씬 작게 반복하는 것은 계산 낭비지만, 연속한 두 값의 차는 실제 반복 오차보다 훨씬 작게 나올 수 있으므로(수렴이 느릴수록 심함, 연습문제 참고) 멈춤 기준은 넉넉히 엄격하게 잡습니다. 정확도를 높이려면 반복이 아니라 격자를 촘촘히 해야 합니다.

예제 2.4.1

격자점을 50개에서 100개로 늘리면 격자 오차와 가우스-자이델의 반복 횟수는 대략 어떻게 됩니까?

풀이. \(h\)가 절반이므로 격자 오차는 \(h^2\)에 비례해 약 4분의 1(\(8\times10^{-5}\) 정도). 가우스-자이델의 반복은 \(N^2\)에 비례해 약 4배. 최적 SOR은 약 2배입니다. 실제로 돌려 보면 가우스-자이델 11,865번, SOR 309번, 참해와의 차 약 \(7\times10^{-5}\)입니다.

요약
  1. 편미분방정식의 격자 문제는 크고 희소해서 반복법으로 푼다.
  2. 야코비 → 가우스-자이델(약 2배 빠름) → SOR(최적 \(\omega\)에서 훨씬 빠름). 실전에서는 다중 격자법·켤레 기울기법.
  3. 반복 오차는 격자 오차보다 작게만 하면 된다. 정확도는 격자가 정한다.

2.4.4연습문제

기본

  1. \(100^3\) 격자의 푸아송 방정식에서 한 방정식에 들어가는 미지수는 몇 개입니까?
    답

    자신과 이웃 6개, 모두 7개. 행렬 원소 \(10^{12}\)개 가운데 0이 아닌 것은 약 \(7\times10^6\)개입니다.

  2. SOR에서 \(\omega = 1\)이면 무슨 방법입니까?
    답

    가우스-자이델.

응용

  1. 코드의 멈춤 기준 tol을 \(10^{-8}\)에서 \(10^{-5}\)로 바꾸면 결과의 정확도는 크게 나빠집니까?
    답

    방법에 따라 다릅니다. 실제로 돌려 보면 SOR은 102번 반복에 차 \(2.7\times10^{-4}\)로 거의 그대로이지만, 야코비는 2,764번에 \(4.9\times10^{-3}\), 가우스-자이델은 1,566번에 \(2.3\times10^{-3}\)으로 격자 오차보다 10배 넘게 나빠집니다. 수렴이 느린 방법은 한 번 반복할 때 값이 아주 조금씩만 바뀌어, '연속한 두 값의 차'가 작아도 참해에서는 아직 멀리 있기 때문입니다. 멈춤 기준은 수렴 빠르기를 고려해 훨씬 엄격하게 잡거나, 잔차 \(|-u_{i-1} + 2u_i - u_{i+1} - h^2f_i|\)로 판단합니다.

  2. \(\omega\)를 2보다 크게 하면 어떻게 될까요?
    답

    발산합니다. SOR은 \(0 < \omega < 2\)에서만 수렴합니다.
