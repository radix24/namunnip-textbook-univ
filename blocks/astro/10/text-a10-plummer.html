N체 모의실험의 처음 조건: 플러머 구 만들기

본문 · 3.4절

성단의 진화를 모의실험하려면 별 2만 개의 처음 위치와 속도가 필요하다. 아무렇게나 흩어 놓으면 성단은 한꺼번에 무너지거나 흩어져 버린다. 처음부터 평형에 있는 성단은 어떻게 만들까? 난수로 원하는 분포를 따르는 반지름을 뽑으려면 어떻게 해야 할까?

먼저 알아야 할 것직접 합산법과 연화 길이(3.1절, 3.3절), 비리얼 정리(천우3 3.4절), 난수(천우6 6.2절)를 쓴다.

처음 질문의 답은 평형 분포가 알려진 모형에서 위치와 속도를 뽑는 것이다. 가장 널리 쓰이는 모형이 플러머 구이고, 뽑는 방법은 역변환 표본 추출과 기각 표본 추출이다.

3.4.1플러머 구

1911년 플러머가 구상성단의 밝기 분포를 맞추려고 쓴 모형으로, 식이 간단해 N체 계산의 표준 시험 대상이다.

정의 3.4.1 (플러머 구)

전체 질량 \(M\), 척도 반지름 \(a\)인 플러머 구의 밀도, 안쪽 질량, 퍼텐셜은 다음과 같다.

\[\rho(r) = \frac{3M}{4\pi a^3}\left(1 + \frac{r^2}{a^2}\right)^{-5/2}, \qquad M(r) = M\frac{r^3}{(r^2 + a^2)^{3/2}}, \qquad \Phi(r) = -\frac{GM}{\sqrt{r^2 + a^2}}\]

퍼텐셜 에너지는 \(W = -3\pi GM^2/(32a)\)이고, 반질량 반지름은 \(r_h = a/\sqrt{2^{2/3} - 1} = 1.305a\)이다.

3.4.2반지름을 역변환 표본 추출로 뽑기

0과 1 사이의 고른 난수 \(X\)를 안쪽 질량의 비율로 보고 \(M(r)/M = X\)를 \(r\)에 대해 풀면, 그 \(r\)들은 플러머 분포를 따른다(그림 1). 단위를 \(G = M = a = 1\)로 두면 다음과 같다.

\[r = \frac{1}{\sqrt{X^{-2/3} - 1}}\]

방향은 구면 위에서 고르게 뽑는다. 이때 \(\cos\theta\)를 −1에서 1 사이에서, \(\phi\)를 0에서 \(2\pi\) 사이에서 고르게 뽑는다. \(\theta\)를 고르게 뽑으면 극 쪽에 점이 몰리므로 주의한다.

3.4.3속도를 기각 표본 추출로 뽑기

평형 상태의 플러머 구에서 그 자리의 탈출 속력 \(v_e = \sqrt2(1 + r^2)^{-1/4}\)에 대한 비 \(q = v/v_e\)는 \(g(q) \propto q^2(1 - q^2)^{7/2}\)을 따른다. 그런데 이 식은 거꾸로 풀기 어렵다. 그래서 \(q\)와 높이 \(y\)를 고르게 뽑아 \(y < g(q)\)일 때만 받아들이며, \(g\)의 최댓값이 0.1보다 작으므로 \(y\)는 0과 0.1 사이에서 뽑는다.

import math, random

def plummer(n, seed=1):
    """플러머 구 (G = 전체 질량 = 척도 반지름 a = 1). 위치와 속도 목록"""
    rng = random.Random(seed)
    def iso(r):                      # 고른 방향의 길이 r 벡터
        z = rng.uniform(-1, 1); phi = rng.uniform(0, 2 * math.pi); s = math.sqrt(1 - z * z)
        return [r * s * math.cos(phi), r * s * math.sin(phi), r * z]
    pos, vel = [], []
    for _ in range(n):
        X = rng.random()
        r = 1 / math.sqrt(X**(-2 / 3) - 1)           # 질량 분포를 거꾸로 풀기
        while True:                                   # 속도 크기: g(q) = q^2 (1-q^2)^3.5 에서 기각 표본
            q, y = rng.random(), 0.1 * rng.random()
            if y < q * q * (1 - q * q)**3.5:
                break
        vesc = math.sqrt(2) * (1 + r * r)**-0.25
        pos.append(iso(r)); vel.append(iso(q * vesc))
    return pos, vel

pos, vel = plummer(20000)
n = len(pos)
K = 0.5 * sum(vx * vx + vy * vy + vz * vz for vx, vy, vz in vel) / n     # 입자 질량 1/n
W = -3 * math.pi / 32                                                       # 플러머 구의 퍼텐셜 에너지(이론)
r_sorted = sorted(math.sqrt(x * x + y * y + z * z) for x, y, z in pos)
print(f"운동 에너지 K = {K:.4f}, 이론 퍼텐셜 에너지 W = {W:.4f}, 비리얼 비 2K/|W| = {2 * K / abs(W):.3f}")
print(f"반질량 반지름: 표본 {r_sorted[n // 2]:.3f}, 이론 {1 / math.sqrt(2**(2 / 3) - 1):.3f}")
운동 에너지 K = 0.1461, 이론 퍼텐셜 에너지 W = -0.2945, 비리얼 비 2K/|W| = 0.992
반질량 반지름: 표본 1.301, 이론 1.305

비리얼 비 \(2K/|W| = 0.99\)로 평형(1)에 가깝고, 반질량 반지름도 이론과 맞는다. 표본 수가 유한해 생기는 1% 안팎의 차는 \(1/\sqrt N\) 크기이다. 이 처음 조건으로 적분을 시작했을 때 성단이 크게 부풀거나 수축하지 않으면, 적분기와 처음 조건이 모두 맞다는 좋은 검사가 된다.

예제 3.4.1

\(X = 0.5\)를 뽑으면 반지름은 얼마인가? 이것은 무슨 반지름인가?

풀이. \(r = 1/\sqrt{0.5^{-2/3} - 1} = 1/\sqrt{1.587 - 1} = 1.305\)이다. 즉 질량의 절반이 그 안에 있는 반질량 반지름이다.

마무리

플러머 구는 \(\rho \propto (1 + r^2/a^2)^{-5/2}\)이고 \(W = -3\pi GM^2/(32a)\), \(r_h = 1.305a\)이다. 반지름은 \(M(r)/M = X\)를 거꾸로 풀어 뽑고, 방향은 \(\cos\theta\)를 고르게 뽑는다. 속도는 기각 표본 추출로 뽑으며, 비리얼 비와 반질량 반지름으로 처음 조건을 검산한다.

3.4.4연습문제

기본

  1. \(X = 0.9\)를 뽑으면 반지름은 얼마인가?
    답

    \(1/\sqrt{0.9^{-2/3} - 1} = 1/\sqrt{0.0728} = 3.71\)이다.

응용

  1. 기각 표본 추출에서 \(q\) 하나를 얻으려면 평균 몇 번 뽑는가? (\(\int_0^1 g\,dq \approx 0.043\))
    답

    받아들일 확률이 \(0.043/(1\times0.1) = 0.43\)이므로 평균 약 2.3번이다. \(g\)의 최댓값(0.092)에 더 가깝게 상자를 잡으면 조금 더 효율적이다.

  2. 속도를 모두 0으로 두고 시작하면 성단은 어떻게 되는가?
    답

    비리얼 비가 0이다. 받쳐 줄 운동이 없어 성단이 한꺼번에 무너졌다가(차가운 붕괴) 다시 튀어나오며 새로운 평형으로 간다.
