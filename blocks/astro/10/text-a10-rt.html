평행판 대기에서 복사 전달 방정식 수치로 풀기

본문 · 4.2절

태양 사진을 보면 원반의 가장자리가 가운데보다 눈에 띄게 어둡다. 태양은 고르게 뜨거운 공 같은데 왜 가장자리만 어두울까? 대기의 온도 분포를 알면 원반 위 각 지점의 밝기를 계산할 수 있을까?

먼저 알아야 할 것복사 전달 방정식(천우4 7.2절)과 수치 적분(천우6 4.2절)을 쓴다.

별의 스펙트럼과 주연 감광은 대기 속 복사 전달의 결과이다. 대기의 두께가 별의 반지름보다 훨씬 얇으면 평평한 판의 층들로 보아도 되며, 이를 평행판 근사라 한다. 복사 전달은 N체와 함께 전산천문학의 두 번째 큰 주제이다.

4.2.1방정식과 형식해

안쪽으로 증가하는 광학적 깊이 \(\tau\)와, 바깥쪽이 양수인 방향 \(\mu = \cos\theta\)에 대해 복사 전달 방정식은 \(\mu\,dI/d\tau = I - S\)이다. 여기서 \(S\)는 원천 함수로, 국소 열평형에서는 플랑크 함수 \(B\)이다. 그러면 표면(\(\tau = 0\))에서 바깥으로 나오는 세기의 형식해는 다음과 같다.

\[ I(0, \mu) = \int_0^\infty S(\tau)\,e^{-\tau/\mu}\,\frac{d\tau}{\mu} \]

즉 각 깊이의 원천이 \(e^{-\tau/\mu}\)만큼 흡수되며 더해진다.

4.2.2에딩턴-바르비에 관계와 주연 감광

\(S = a + b\tau\)처럼 선형이면 적분이 정확히 \(I(0, \mu) = a + b\mu\)가 된다. 다시 말해 \(\mu\) 방향으로 나오는 세기는 깊이 \(\tau = \mu\)의 원천 함수와 같으며, 이를 에딩턴-바르비에 관계라 한다. 회색 대기의 에딩턴 근사에서는 \(S \propto \tau + \frac23\)이므로 다음을 얻는다.

\[ \frac{I(\mu)}{I(1)} = \frac{\frac23 + \mu}{\frac53} = 0.4 + 0.6\mu \]

처음 질문의 답이 여기에 있다. 가장자리(\(\mu\)가 작음)에서는 비스듬히 보므로 얕은 깊이(\(\tau = \mu\))의 차가운 층만 보이고, 그래서 어둡다. 원반 가장자리는 가운데의 40% 밝기로, 태양에서 실제로 보이는 주연 감광과 비슷하다(그림 1).

4.2.3수치 적분

\(S(\tau)\)가 표로 주어지면 \(\tau\)를 표면 근처가 촘촘한 로그 간격 격자로 나누고, 각 칸에서 적분해 더한다.

import numpy as np
tau = np.concatenate([[0], np.logspace(-4, 1.5, 400)])
S = tau + 2/3                                    # 에딩턴 회색 대기 (상대값)
def I0(mu):
    w = np.exp(-tau / mu)
    return np.trapz(S * w, tau) / mu
print([round(I0(m) / I0(1), 4) for m in (1, 0.5, 0.2)])   # [1.0, 0.7, 0.52]

사다리꼴 공식이어도 격자가 촘촘하면 해석해 \(0.4 + 0.6\mu\)의 값 1, 0.7, 0.52와 소수 넷째 자리까지 맞는다. 이렇게 답을 아는 경우로 코드를 시험한 뒤, 실제 대기 모형의 \(S(\tau)\)를 넣는다.

4.2.4산란과 람다 반복

산란이 있으면 원천 함수가 복사장 자체에 의존해, 평균 세기를 \(J\), 흡수 비율을 \(\epsilon\)이라 할 때 \(S = (1 - \epsilon)J + \epsilon B\)가 된다. 이때 \(S\)를 추측해 \(J\)를 계산하고 다시 \(S\)를 고치는 람다 반복은, \(\epsilon\)이 작아 산란이 지배하면 매우 느리게 수렴한다. 게다가 바뀜이 작아 수렴한 것처럼 보이는 함정이 있다. 그래서 실제 코드는 가속 람다 반복(ALI)이나, 연립방정식으로 한 번에 푸는 포트리에 방법을 쓴다.

주의평행판 근사는 대기 두께가 반지름보다 훨씬 얇을 때만 맞는다. 적색 초거성처럼 대기가 두꺼운 별에는 구면 복사 전달이 필요하다.
마무리

평행판 대기의 복사 전달 방정식은 \(\mu\,dI/d\tau = I - S\)이고, 형식해는 \(I(0,\mu) = \int S e^{-\tau/\mu}d\tau/\mu\)이다. 선형 원천 함수에서는 \(I(0,\mu) = S(\tau = \mu)\)이며, 회색 에딩턴 대기의 주연 감광은 \(0.4 + 0.6\mu\)이다. 산란이 지배하면 람다 반복이 느리므로 ALI나 포트리에 방법을 쓴다.

4.2.5연습문제

기본

  1. 에딩턴-바르비에 관계로 보면 원반 중심(\(\mu = 1\))의 세기는 어느 깊이의 원천 함수인가?
    답

    \(\tau = 1\)의 원천 함수이다.

응용

  1. \(S = 1 + 3\tau\)이면 \(I(0, \mu)\)와 \(I(0.2)/I(1)\)은 얼마인가?
    답

    \(I(0,\mu) = 1 + 3\mu\)이고 \(I(0.2)/I(1) = 1.6/4 = 0.4\)이다.

  2. 파장이 짧을수록 주연 감광이 더 뚜렷한 까닭을 에딩턴-바르비에 관계로 설명하여라.
    답

    짧은 파장에서는 플랑크 함수가 온도에 더 민감해, 같은 깊이 차이(\(\tau = \mu\)와 \(\tau = 1\))에서 원천 함수의 비가 더 크다. 그래서 가장자리와 중심의 밝기 차이가 커진다.
