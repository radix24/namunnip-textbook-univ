분포 그리기: 히스토그램과 커널 밀도 추정

본문
이 절에서 배울 것
  • 히스토그램의 막대 폭과 시작점이 보이는 모양을 바꿈을 확인한다.
  • 점마다 작은 종(커널)을 놓아 더하는 커널 밀도 추정(KDE)을 쓴다.
  • 너무 작은 폭(과소 평활)과 너무 큰 폭(과다 평활)의 위험을 알고, 실버먼 규칙으로 폭을 정한다.
  • '봉우리가 둘인가'를 판단할 때 폭과 통계 흔들림을 함께 본다.
먼저 알아야 할 것
  • 표 자료와 그래프 (천우6 1.2절), 가설 검정 (5.4절), 항성 종족 (천우4 4.2절).

5.5.1막대 폭이 모양을 바꾼다

별 200개의 금속 함량 [Fe/H]가 두 종족(금속이 적은 헤일로 60개, 많은 원반 140개)에서 나온 가상 표본을 히스토그램과 KDE로 그려, 봉우리가 몇 개로 보이는지 셉니다.

import math, random, statistics

random.seed(8)
# 가상 표본: 두 종족의 금속 함량 [Fe/H]
feh = [random.gauss(-1.5, 0.3) for _ in range(60)] + [random.gauss(-0.5, 0.2) for _ in range(140)]

def peaks(xs, ys):
    """이웃보다 큰 점(봉우리)의 x"""
    return [round(xs[i], 2) for i in range(1, len(ys) - 1) if ys[i] > ys[i - 1] and ys[i] >= ys[i + 1] and ys[i] > 0]

def histogram(data, lo, hi, width):
    n = round((hi - lo) / width)
    counts = [0] * n
    for x in data:
        k = int((x - lo) / width)
        if 0 <= k < n: counts[k] += 1
    centers = [lo + (k + 0.5) * width for k in range(n)]
    return centers, counts

for w in (1.0, 0.25, 0.05):
    c, h = histogram(feh, -3, 1, w)
    print(f"막대 폭 {w:4}: 막대 {len(h):3d}개, 봉우리 {len(peaks(c, h))}개 {peaks(c, h) if len(peaks(c, h)) < 6 else '(너무 많음)'}")

def kde(data, x, bw):
    return sum(math.exp(-0.5 * ((x - d) / bw)**2) for d in data) / (len(data) * bw * math.sqrt(2 * math.pi))

bw = 1.06 * statistics.stdev(feh) * len(feh)**-0.2          # 실버먼 규칙
grid = [-3 + 0.01 * i for i in range(401)]
for b in (bw, bw / 4, 3 * bw):
    ys = [kde(feh, x, b) for x in grid]
    print(f"커널 폭 {b:.3f}: 봉우리 {peaks(grid, ys)}")
막대 폭  1.0: 막대   4개, 봉우리 1개 [-0.5]
막대 폭 0.25: 막대  16개, 봉우리 2개 [-1.38, -0.38]
막대 폭 0.05: 막대  80개, 봉우리 14개 (너무 많음)
커널 폭 0.179: 봉우리 [-1.28, -0.5]
커널 폭 0.045: 봉우리 [-2.2, -1.74, -1.32, -1.16, -0.99, -0.49, -0.04]
커널 폭 0.536: 봉우리 [-0.61]

막대 폭 1.0은 두 종족을 한 봉우리로 뭉개고(과다 평활), 0.05는 막대마다 몇 개뿐이라 우연한 흔들림이 봉우리 14개를 만듭니다(과소 평활). 0.25가 두 종족을 드러냅니다. KDE도 같습니다.

5.5.2커널 밀도 추정

히스토그램은 막대의 시작점을 조금 옮기기만 해도 모양이 바뀌고, 막대 경계에서 계단처럼 끊깁니다. KDE는 자료점 하나마다 폭 \(b\)인 가우스 종을 놓아 더합니다.

정의 5.5.1 \[\hat f(x) = \frac{1}{Nb\sqrt{2\pi}}\sum_{i=1}^Ne^{-(x - x_i)^2/(2b^2)}, \qquad b_{\text{실버먼}} \approx 1.06\,s\,N^{-1/5}.\]

\(s\)는 표본 표준편차입니다. 실버먼 규칙은 분포가 정규분포에 가까울 때 가장 좋은 폭이고, 봉우리가 여럿이면 조금 크게 나오는 경향이 있습니다.

매끄럽고 시작점에 기대지 않지만, 폭 선택의 문제는 그대로 남습니다. 폭은 자료가 많을수록 \(N^{-1/5}\)로 천천히 줄어듭니다.

5.5.3봉우리가 진짜인가

그림의 봉우리 개수는 폭에 따라 바뀌므로 그 자체로 증거가 아닙니다. 봉우리가 둘이라는 주장은 (1) 합리적인 폭의 범위에서 일관되게 나타나는지, (2) 정규분포 하나와 둘의 혼합 모형을 맞춰 비교(5.4절의 모형 선택)했을 때 둘이 의미 있게 나은지, (3) 부트스트랩으로 다시 뽑은 표본에서도 나타나는지로 확인합니다.

예제 5.5.1

위 표본(\(N = 200\), \(s = 0.486\))의 실버먼 폭을 확인하고, 표본이 2,000개라면 폭이 몇 배가 되는지 구하세요.

풀이. \(1.06\times0.486\times200^{-0.2} = 1.06\times0.486\times0.347 = 0.179\). 2,000개면 \(10^{-0.2} = 0.63\)배인 0.113. 자료가 10배여도 폭은 37%만 줄어듭니다.

요약
  1. 히스토그램은 막대 폭과 시작점에 따라 모양이 바뀐다. 너무 넓으면 뭉개고, 너무 좁으면 잡음을 봉우리로 본다.
  2. KDE \(\hat f = \tfrac1{Nb}\sum K((x - x_i)/b)\), 실버먼 폭 \(1.06sN^{-1/5}\).
  3. 봉우리의 개수는 폭의 범위, 모형 비교, 부트스트랩으로 확인한다.

5.5.4연습문제

기본

  1. KDE의 넓이(전체 적분)는 얼마입니까?
    답

    1. 종 하나의 넓이가 \(1/N\)이고 \(N\)개를 더하기 때문입니다.

  2. 막대 폭 0.05의 히스토그램에서 막대 하나에 평균 몇 개가 들어갑니까? (자료가 있는 범위 약 2.5)
    답

    200개를 약 50개 막대에 나누므로 평균 4개, 포아송 흔들림 \(\pm2\)라 우연한 봉우리가 많이 생깁니다.

응용

  1. 막대 폭 0.25를 그대로 두고 시작점을 −3.000에서 −2.875로 옮기면 봉우리 위치가 [−1.38, −0.38]에서 [−1.25, −0.50]으로 바뀝니다. 무엇을 뜻합니까?
    답

    봉우리 위치가 막대 폭만큼의 불확도를 가진다는 뜻입니다. 히스토그램의 막대 중심을 그대로 봉우리 위치로 보고하면 안 되고, KDE나 모형 맞춤으로 위치를 정합니다.

  2. KDE 대신 막대 폭을 정하는 경험 규칙으로 '막대 수 \(\approx\sqrt N\)'을 쓰면 \(N = 200\)에서 폭은 대략?
    답

    막대 약 14개, 자료 범위 약 2.5를 나누면 폭 약 0.18로, 두 종족을 드러내는 폭(0.25) 근처입니다.
