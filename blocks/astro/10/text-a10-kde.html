분포 그리기: 히스토그램과 커널 밀도 추정

본문 · 5.5절

별 200개의 금속 함량을 히스토그램으로 그렸다. 막대 폭을 1로 하면 봉우리가 하나, 0.25로 하면 둘, 0.05로 하면 열네 개가 된다. 같은 자료인데 봉우리 수가 그리는 방법에 따라 바뀐다. 그렇다면 이 별들은 한 종족일까, 두 종족일까? 그림만 보고 판단해도 될까?

먼저 알아야 할 것표 자료와 그래프(천우6 1.2절), 가설 검정(5.4절), 항성 종족(천우4 4.2절)을 쓴다.

처음 질문의 답은 그림만으로는 판단할 수 없다는 것이다. 막대 폭이나 커널 폭이 모양을 바꾸므로, 폭의 선택을 알고 봉우리를 따로 검증해야 한다.

5.5.1막대 폭이 모양을 바꾼다

금속이 적은 헤일로 별 60개와 금속이 많은 원반 별 140개가 섞인 가상 표본의 [Fe/H]를 히스토그램과 KDE로 그려, 봉우리가 몇 개로 보이는지 세어 보자.

import math, random, statistics

random.seed(8)
# 가상 표본: 두 종족의 금속 함량 [Fe/H]
feh = [random.gauss(-1.5, 0.3) for _ in range(60)] + [random.gauss(-0.5, 0.2) for _ in range(140)]

def peaks(xs, ys):
    """이웃보다 큰 점(봉우리)의 x"""
    return [round(xs[i], 2) for i in range(1, len(ys) - 1) if ys[i] > ys[i - 1] and ys[i] >= ys[i + 1] and ys[i] > 0]

def histogram(data, lo, hi, width):
    n = round((hi - lo) / width)
    counts = [0] * n
    for x in data:
        k = int((x - lo) / width)
        if 0 <= k < n: counts[k] += 1
    centers = [lo + (k + 0.5) * width for k in range(n)]
    return centers, counts

for w in (1.0, 0.25, 0.05):
    c, h = histogram(feh, -3, 1, w)
    print(f"막대 폭 {w:4}: 막대 {len(h):3d}개, 봉우리 {len(peaks(c, h))}개 {peaks(c, h) if len(peaks(c, h)) < 6 else '(너무 많음)'}")

def kde(data, x, bw):
    return sum(math.exp(-0.5 * ((x - d) / bw)**2) for d in data) / (len(data) * bw * math.sqrt(2 * math.pi))

bw = 1.06 * statistics.stdev(feh) * len(feh)**-0.2          # 실버먼 규칙
grid = [-3 + 0.01 * i for i in range(401)]
for b in (bw, bw / 4, 3 * bw):
    ys = [kde(feh, x, b) for x in grid]
    print(f"커널 폭 {b:.3f}: 봉우리 {peaks(grid, ys)}")
막대 폭  1.0: 막대   4개, 봉우리 1개 [-0.5]
막대 폭 0.25: 막대  16개, 봉우리 2개 [-1.38, -0.38]
막대 폭 0.05: 막대  80개, 봉우리 14개 (너무 많음)
커널 폭 0.179: 봉우리 [-1.28, -0.5]
커널 폭 0.045: 봉우리 [-2.2, -1.74, -1.32, -1.16, -0.99, -0.49, -0.04]
커널 폭 0.536: 봉우리 [-0.61]

막대 폭 1.0은 두 종족을 한 봉우리로 뭉개는데, 이를 과다 평활이라 한다. 반면 0.05는 막대마다 자료가 몇 개뿐이라 우연한 흔들림이 봉우리 14개를 만들며, 이를 과소 평활이라 한다. 0.25가 두 종족을 드러내며, KDE도 같은 모습을 보인다(그림 1).

5.5.2커널 밀도 추정

히스토그램은 막대의 시작점을 조금 옮기기만 해도 모양이 바뀌고, 막대 경계에서 계단처럼 끊긴다. 그래서 자료점 하나마다 폭 \(b\)인 가우스 종을 놓아 더하는 커널 밀도 추정(KDE)을 쓴다.

정의 5.5.1 (커널 밀도 추정)

표본 \(x_1, \ldots, x_N\)의 가우스 커널 밀도 추정과, 표본 표준편차 \(s\)로 정하는 실버먼 폭은 다음과 같다.

\[\hat f(x) = \frac{1}{Nb\sqrt{2\pi}}\sum_{i=1}^Ne^{-(x - x_i)^2/(2b^2)}, \qquad b_{\text{실버먼}} \approx 1.06\,s\,N^{-1/5}\]

실버먼 규칙은 분포가 정규분포에 가까울 때 가장 좋은 폭이고, 봉우리가 여럿이면 조금 크게 나오는 경향이 있다. KDE는 매끄럽고 시작점에 기대지 않지만, 폭을 고르는 문제는 그대로 남는다. 또 폭은 자료가 많을수록 \(N^{-1/5}\)로 천천히 줄어든다.

5.5.3봉우리가 진짜인가

그림의 봉우리 개수는 폭에 따라 바뀌므로 그 자체로는 증거가 아니다. 그러므로 봉우리가 둘이라는 주장은 세 가지로 확인한다. 먼저 합리적인 폭의 범위에서 일관되게 나타나는지 본다. 다음으로 정규분포 하나와 둘의 혼합 모형을 맞춰 비교해(5.4절의 모형 선택) 둘이 의미 있게 나은지 본다. 끝으로 부트스트랩으로 다시 뽑은 표본에서도 나타나는지 본다.

예제 5.5.1

위 표본(\(N = 200\), \(s = 0.486\))의 실버먼 폭을 확인하고, 표본이 2,000개라면 폭이 몇 배가 되는지 구하여라.

풀이. \(1.06\times0.486\times200^{-0.2} = 1.06\times0.486\times0.347 = 0.179\)이다. 2,000개면 \(10^{-0.2} = 0.63\)배인 0.113이다. 즉 자료가 10배여도 폭은 37%만 줄어든다.

마무리

히스토그램은 막대 폭과 시작점에 따라 모양이 바뀌어, 너무 넓으면 구조를 뭉개고 너무 좁으면 잡음을 봉우리로 보인다. KDE는 자료점마다 폭 \(b\)인 종을 더한 매끄러운 추정이며, 실버먼 폭 \(1.06sN^{-1/5}\)을 출발점으로 쓴다. 봉우리의 개수는 폭의 범위, 모형 비교, 부트스트랩으로 확인한다.

5.5.4연습문제

기본

  1. KDE의 전체 넓이(적분)는 얼마인가?
    답

    1이다. 종 하나의 넓이가 \(1/N\)이고 \(N\)개를 더하기 때문이다.

응용

  1. 막대 폭 0.25를 그대로 두고 시작점을 −3.000에서 −2.875로 옮기면 봉우리 위치가 [−1.38, −0.38]에서 [−1.25, −0.50]으로 바뀐다. 이것은 무엇을 뜻하는가?
    답

    봉우리 위치가 막대 폭만큼의 불확도를 가진다는 뜻이다. 그러므로 히스토그램의 막대 중심을 그대로 봉우리 위치로 보고하지 말고, KDE나 모형 맞춤으로 위치를 정한다.

  2. 막대 수 \(\approx\sqrt N\)이라는 경험 규칙을 쓰면 \(N = 200\)에서 막대 폭은 대략 얼마인가? (자료 범위 약 2.5)
    답

    막대가 약 14개이므로 폭은 약 0.18로, 두 종족을 드러내는 폭(0.25) 근처이다.
