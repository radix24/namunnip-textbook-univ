광자를 하나씩 따라가는 Monte Carlo 복사 전달

본문
이 절에서 배울 것
  • 광자가 다음에 상호작용할 때까지의 광학적 거리를 \(\tau = -\ln(1 - X)\)로 뽑는 까닭을 안다.
  • 산란하는 판을 지나는 광자를 따라가 투과·반사·흡수 비율을 구한다.
  • 산란이 있으면 투과율이 \(e^{-\tau}\)가 아니라 대략 \(1/\tau\)로 줄어듦을 확인한다.
  • 복잡한 모양과 산란을 다루는 Monte Carlo 방법의 장단점을 안다.
먼저 알아야 할 것
  • 평행판 대기의 복사 전달 (4.2절), Monte Carlo 계산 (천우6 6.2절).

4.4.1광자 한 개의 일생

광학적 깊이 \(\tau\)를 지나는 동안 상호작용하지 않을 확률은 \(e^{-\tau}\)입니다. 그러니 다음 상호작용까지의 광학적 거리는 지수 분포를 따르고, 고른 난수 \(X\)에서 \(\tau = -\ln(1 - X)\)로 뽑을 수 있습니다(역변환 표본 추출, 3.4절). 상호작용 지점에서 산란할 확률(알베도) \(\varpi\)로 산란하면 새 방향을 뽑고, 아니면 흡수되어 끝납니다. 이것을 판 밖으로 나갈 때까지 되풀이합니다.

방법 4.4.1
  1. \(\Delta\tau = -\ln(1 - X)\)만큼 방향 코사인 \(\mu\)를 따라 이동(판에서 깊이 변화 \(\mu\Delta\tau\)).
  2. 위쪽 경계를 넘으면 투과, 아래쪽을 넘으면 반사.
  3. 안에 있으면 확률 \(\varpi\)로 산란: 등방 산란이면 \(\mu\)를 −1~1에서 고르게 새로 뽑는다. 아니면 흡수.

4.4.2실험: 산란하는 판

import math, random

def slab(tau_total, albedo=1.0, n=20000, seed=3):
    """광학적 두께 tau_total인 판에 아래에서 수직으로 들어온 광자를 따라간다.
    등방 산란, 산란할 확률 albedo(나머지는 흡수). 투과·반사·흡수 비율을 돌려준다."""
    rng = random.Random(seed)
    T = R = A = 0
    for _ in range(n):
        tau, mu = 0.0, 1.0                      # 위치(광학적 깊이), 진행 방향 코사인
        while True:
            tau += -math.log(1.0 - rng.random()) * mu      # 다음 상호작용까지 광학적 거리
            if tau >= tau_total: T += 1; break
            if tau < 0: R += 1; break
            if rng.random() > albedo: A += 1; break
            mu = rng.uniform(-1, 1)             # 등방 산란: 새 방향
    return T / n, R / n, A / n

for tau in (0.1, 1, 3, 10):
    t, r, a = slab(tau)
    print(f"τ = {tau:4}: 투과 {t:.3f}, 반사 {r:.3f}   (산란 없이 곧바로 통과: {math.exp(-tau):.3f}, 확산 근사 {1 / (1 + 0.75 * tau):.3f})")
t, r, a = slab(3, albedo=0.9)
print(f"τ = 3, 산란 확률 0.9: 투과 {t:.3f}, 반사 {r:.3f}, 흡수 {a:.3f}")
τ =  0.1: 투과 0.953, 반사 0.047   (산란 없이 곧바로 통과: 0.905, 확산 근사 0.930)
τ =    1: 투과 0.661, 반사 0.339   (산란 없이 곧바로 통과: 0.368, 확산 근사 0.571)
τ =    3: 투과 0.381, 반사 0.619   (산란 없이 곧바로 통과: 0.050, 확산 근사 0.308)
τ =   10: 투과 0.150, 반사 0.850   (산란 없이 곧바로 통과: 0.000, 확산 근사 0.118)
τ = 3, 산란 확률 0.9: 투과 0.215, 반사 0.390, 흡수 0.395

\(\tau = 10\)이면 곧바로 지나가는 광자는 \(e^{-10} = 4.5\times10^{-5}\)뿐인데, 산란하면서 지나가는 광자는 15%나 됩니다. 산란만 하고 흡수가 없으면 광자는 결국 위나 아래로 나가므로 투과 + 반사 = 1이고, 두꺼운 판에서 투과율은 대략 \(1/\tau\)로 천천히 줄어듭니다(무작위 걸음, 천우2 2.4절). 간단한 확산 근사 \(1/(1 + 3\tau/4)\)는 경계 근처를 거칠게 다뤄 20%쯤 작게 나옵니다. 흡수가 10%만 섞여도(\(\varpi = 0.9\)) 투과가 크게 줄어드는데, 광자가 판 안에서 여러 번 산란하는 동안 흡수될 기회가 많아지기 때문입니다.

4.4.3장점과 한계

  • 장점: 3차원의 복잡한 모양(먼지 원반, 뭉친 성간 구름), 비등방 산란, 편광을 '규칙대로 광자를 움직이기'만으로 다룹니다. 복사 전달 방정식을 직접 풀기 어려운 문제에 강합니다.
  • 한계: 결과에 \(1/\sqrt N\) 잡음이 있어, 광자가 거의 빠져나오지 못하는 아주 두꺼운 영역은 엄청난 수의 광자가 필요합니다. 이때는 확산 근사를 섞거나, 가중치를 주는 기법을 씁니다.
예제 4.4.1

위 실험에서 \(\tau = 3\)의 투과율 0.381은 광자 2만 개로 얻었습니다. 통계 오차는?

풀이. 이항 분포의 표준편차 \(\sqrt{p(1-p)/N} = \sqrt{0.381\times0.619/20000} = 0.0034\). 결과는 \(0.381 \pm 0.003\)이고, 오차를 10배 줄이려면 광자가 100배(200만 개) 필요합니다.

요약
  1. 다음 상호작용까지 광학적 거리 \(-\ln(1 - X)\), 산란 확률 \(\varpi\), 새 방향을 뽑아 광자를 따라간다.
  2. 산란이 있으면 투과율은 \(e^{-\tau}\)보다 훨씬 크고 두꺼울 때 대략 \(1/\tau\).
  3. 복잡한 모양에 강하지만 \(1/\sqrt N\) 잡음이 있다.

4.4.4연습문제

기본

  1. \(X = 0.5\)를 뽑으면 광자는 광학적 거리 얼마를 갑니까?
    답

    \(-\ln0.5 = 0.69\).

  2. 산란 없는(\(\varpi = 0\)) 판에서 이 프로그램은 어떤 투과율을 내야 합니까?
    답

    \(e^{-\tau}\). 극한값 검산으로 쓸 수 있습니다.

응용

  1. 코드의 mu = rng.uniform(-1, 1)이 등방 산란이 되는 까닭은?
    답

    구면 위의 고른 방향은 \(\cos\theta\)가 −1~1에서 고르게 분포합니다(3.4절과 같은 이유). 판에서는 깊이 방향 성분 \(\mu\)만 필요합니다.

  2. 지구 대기의 구름(\(\tau \approx 10\))이 해를 가려도 낮이 어둡지 않은 까닭을 이 결과로 설명하세요.
    답

    물방울은 거의 흡수하지 않고 산란만 하므로, 곧바로 오는 햇빛은 거의 없어도 산란해서 들어오는 빛이 10~20% 남습니다. 구름 아래가 그늘지되 밝은 까닭입니다.
