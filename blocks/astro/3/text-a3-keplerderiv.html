경험 법칙을 원리에서 끌어내기

케플러의 세 법칙은 화성 관측 자료에 맞춘 경험 법칙이었습니다. 뉴턴은 "거리의 제곱에 반비례하는 인력" 하나로 세 법칙이 모두 나온다는 것을 보였고, 이것이 만유인력이 옳다는 가장 강력한 증거가 되었습니다. 이 절에서는 그 유도를 단계마다 근거를 붙여 따라갑니다. 결과는 행성뿐 아니라 쌍성, 인공위성, 은하 중심의 별에도 그대로 쓰입니다.

3.1.12체 문제를 1체 문제로

질량 \(M\)과 \(m\)인 두 천체가 서로 끌어당깁니다. 두 위치 벡터를 \(\vec r_1, \vec r_2\)라 하고, 상대 위치 \(\vec r = \vec r_2 - \vec r_1\)을 정의합니다. 뉴턴 제2법칙을 두 천체에 쓰면

\[ M\ddot{\vec r}_1 = +\frac{GMm}{r^2}\hat r, \qquad m\ddot{\vec r}_2 = -\frac{GMm}{r^2}\hat r \]

입니다(\(\hat r\)은 \(\vec r\) 방향의 단위벡터). 둘째 식을 \(m\)으로, 첫째 식을 \(M\)으로 나누어 빼면

\[ \ddot{\vec r} = -\frac{G(M+m)}{r^2}\hat r \]

이 됩니다. 곧 상대 운동은 질량 \(M + m\)인 고정된 천체 둘레를 도는 한 점의 운동과 똑같습니다. 이것을 환산 질량 \(\mu = Mm/(M+m)\)인 물체가 힘 \(GMm/r^2\)를 받는 운동이라고 말하기도 합니다. 질량 중심은 외력이 없으므로 등속도로 움직이고, 두 천체는 질량 중심을 기준으로 질량에 반비례하는 크기의 닮은 궤도를 돕니다(3.3절). 아래에서는 \(\mathcal{M} = G(M+m)\)으로 줄여 씁니다.

3.1.2각운동량 보존과 제2법칙

힘이 언제나 두 천체를 잇는 선 방향(중심력)이므로 돌림힘 \(\vec r\times\vec F = 0\)이고, 단위 질량당 각운동량 \(\vec h = \vec r\times\dot{\vec r}\)은 일정합니다. 그 결과 두 가지가 나옵니다.

  • 운동은 한 평면에서 일어난다: \(\vec r\)과 \(\dot{\vec r}\)이 늘 고정된 벡터 \(\vec h\)에 수직이기 때문이다.
  • 면적 속도가 일정하다: 평면 극좌표 \((r, \theta)\)에서 \(h = r^2\dot\theta\)이다. 짧은 시간 \(dt\) 동안 반지름이 쓸고 가는 넓이는 \(dA = \frac12r^2d\theta\)이므로 \(dA/dt = \frac12r^2\dot\theta = h/2\)로 일정하다. 이것이 Kepler 제2법칙이다.

제2법칙은 힘이 거리의 몇 제곱에 반비례하든 중심력이기만 하면 성립한다는 점에 주의하세요. 역제곱 법칙은 다음 단계에서 비로소 쓰입니다.

3.1.3궤도 방정식과 제1법칙

목표는 \(r\)을 시간이 아니라 각 \(\theta\)의 함수로 구하는 것입니다. 그러면 궤도의 모양이 바로 보입니다. 지름 방향의 운동 방정식은 극좌표의 가속도 공식으로

\[ \ddot r - r\dot\theta^2 = -\frac{\mathcal M}{r^2} \]

입니다(\(-r\dot\theta^2\)은 원운동의 구심 가속도 항). 계산을 간단하게 하는 요령은 \(u = 1/r\)로 바꾸고 시간 미분을 \(\theta\) 미분으로 바꾸는 것입니다.

유도. 연쇄법칙과 \(\dot\theta = h/r^2 = hu^2\)을 쓰면 \[ \dot r = \frac{d}{dt}\frac1u = -\frac{1}{u^2}\frac{du}{d\theta}\dot\theta = -h\frac{du}{d\theta} \] 이고, 한 번 더 미분하면 \(\ddot r = -h\frac{d^2u}{d\theta^2}\dot\theta = -h^2u^2\frac{d^2u}{d\theta^2}\)입니다. 운동 방정식에 넣으면 \[ -h^2u^2\frac{d^2u}{d\theta^2} - \frac1u\,h^2u^4 = -\mathcal M u^2 \] 이고, 양변을 \(-h^2u^2\)으로 나누면 \[ \frac{d^2u}{d\theta^2} + u = \frac{\mathcal M}{h^2} \] 입니다. 이것은 단진동 방정식에 상수가 더해진 꼴이라 일반해는 \(u = \frac{\mathcal M}{h^2}\left[1 + e\cos(\theta - \theta_0)\right]\)입니다(\(e, \theta_0\)은 적분 상수). 근점 방향을 \(\theta_0 = 0\)으로 잡고 \(p = h^2/\mathcal M\)이라 두면 \[ r = \frac{p}{1 + e\cos\theta} \] 입니다. ∎

이 식은 초점이 원점에 있는 원뿔곡선의 극방정식입니다(공통1 7단원). \(e = 0\)이면 원, \(0 < e < 1\)이면 타원, \(e = 1\)이면 포물선, \(e > 1\)이면 쌍곡선입니다. 묶인 궤도는 타원이고 중심 천체가 초점에 있다는 것, 곧 Kepler 제1법칙입니다. 타원이면 근점 거리 \(p/(1+e)\), 원점 거리 \(p/(1-e)\)를 더해 \(2a\)이므로 \(p = a(1 - e^2)\)입니다.

역제곱 법칙을 쓴 곳은 우변이 상수 \(\mathcal M/h^2\)이 된 단계입니다. 힘이 다른 꼴이면 우변이 \(u\)의 함수가 되고, 궤도는 닫히지 않고 근점이 돌아갑니다. 수성 근일점의 이동이 일반상대론의 작은 보정으로 설명되는 것이 이 때문입니다.

3.1.4제3법칙

면적 속도 \(h/2\)로 한 바퀴(주기 \(P\)) 동안 쓸고 가는 넓이는 타원의 넓이 \(\pi ab\)입니다. 곧 \(\pi ab = \frac h2P\)입니다. 여기에 \(b = a\sqrt{1-e^2}\)과 \(h^2 = \mathcal Mp = \mathcal Ma(1-e^2)\)을 넣고 제곱하면

\[ P^2 = \frac{4\pi^2a^2b^2}{h^2} = \frac{4\pi^2a^4(1-e^2)}{\mathcal Ma(1-e^2)} = \frac{4\pi^2}{G(M+m)}a^3 \]

입니다. 이심률이 지워져 주기는 긴반지름만으로 정해집니다.

예제 3.1.1

은하 중심의 별 S2는 긴반지름 1,030 AU, 주기 16.0년의 타원 궤도를 돕니다. 중심 천체의 질량은 태양의 몇 배입니까?

풀이. 태양 질량, AU, 년 단위에서 \(M + m = a^3/P^2\)입니다(지구-태양에서 \(1 = 1^3/1^2\)이 되도록 맞춘 단위). \(1030^3/16.0^2 = 1.093\times10^9/256 = 4.27\times10^6\). 별의 질량은 무시할 만하므로 중심 블랙홀의 질량은 약 430만 태양 질량입니다(2020년 노벨 물리학상의 근거).

주의 태양계에서 \(P^2 = a^3\)(년, AU)으로 쓸 수 있는 것은 \(M + m \approx M_\odot\)이기 때문입니다. 쌍성이나 다른 중심 천체에는 반드시 \(M + m\)(태양 질량 단위)을 넣어야 합니다.
요약
  1. 상대 운동은 질량 \(M + m\)인 고정 중심 둘레의 운동과 같다.
  2. 중심력 → 각운동량 보존 → 평면 운동과 면적 속도 일정(제2법칙).
  3. \(u = 1/r\)로 바꾸면 \(u'' + u = \mathcal M/h^2\), 해는 원뿔곡선 \(r = p/(1+e\cos\theta)\)(제1법칙).
  4. \(\pi ab = (h/2)P\)에서 \(P^2 = 4\pi^2a^3/G(M+m)\)(제3법칙).

3.1.5연습문제

기본

  1. 목성의 위성 이오는 반지름 421,700 km 궤도를 1.769일에 돕니다. 목성의 질량은?
    답

    \(M = 4\pi^2a^3/(GP^2) = 39.48\times7.50\times10^{25}/(6.674\times10^{-11}\times(1.528\times10^5)^2) = 1.90\times10^{27}\) kg.

  2. 궤도 방정식에서 \(e = 0.5\), \(p = 1.5\)일 때 근점 거리, 원점 거리, 긴반지름은?
    답

    근점 1.0, 원점 3.0, 긴반지름 2.0.

응용

  1. 힘이 \(F \propto 1/r^3\)이면 \(u\)의 방정식이 어떻게 바뀌는지 쓰고, 왜 타원 궤도가 나오지 않는지 말하세요.
    답

    \(F = k/r^3\)이면 우변이 \(ku/h^2\)가 되어 \(u'' + (1 - k/h^2)u = 0\). 해는 \(\cos(\sqrt{1-k/h^2}\,\theta)\) 꼴로 주기가 \(2\pi\)가 아니므로 닫힌 타원이 되지 않습니다(나선이나 도는 궤도).

  2. 질량이 같은 두 별이 서로 원 궤도를 돌며 주기가 1년, 별 사이 거리가 2 AU입니다. 한 별의 질량은?
    답

    \(M + m = 2^3/1^2 = 8\), 각 4 태양 질량.
