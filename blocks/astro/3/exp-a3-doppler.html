빠르게 멀어지는 천체의 적색이동

탐구 · 상대론적 도플러

질문

천체가 멀어지는 속도가 빛의 속도에 가까우면 \(z = v/c\)로 계산한 적색이동은 얼마나 틀릴까요? 적색이동이 7인 퀘이사는 빛보다 7배 빨리 멀어지는 걸까요?

복원

느린 경우의 도플러 효과는 \(z = v/c\)입니다. 특수 상대론의 시간 늘어남을 넣으면 시선 방향으로 멀어질 때 \(1 + z = \sqrt{(1 + \beta)/(1 - \beta)}\)(\(\beta = v/c\))입니다([천우3-02-05] 본문).

설명

β가 작으면 두 식이 거의 같지만(β = 0.1에서 5.5% 차이), β가 1에 가까워지면 상대론의 z는 끝없이 커집니다. 그래서 z가 1보다 커도 속도는 빛보다 느릴 수 있습니다.

연결

다만 먼 은하의 적색이동은 공간 팽창이 만든 것이라 이 공식(특수 상대론)으로 속도를 구하는 것도 정확하지 않습니다. 우주론적 적색이동은 척도 인자의 비 \(1 + z = 1/a\)입니다([천우16-01-02]).

적용

  1. β = 0.1: 고전 0.100, 상대론 0.106. Hα가 725.6 nm로(고전이면 721.9 nm).
  2. β = 0.5: 상대론 0.732(46% 차이).
  3. β = 0.9: 3.359, β = 0.99: 13.11.

판단

이 식은 천체가 시선 방향으로 곧게 멀어질 때입니다. 시선에 비스듬히 움직이면 시간 늘어남 때문에 옆으로 움직여도 적색이동이 생깁니다(가로 도플러 효과).
