활력 방정식으로 궤도 속력 구하기

본문 · 3.2절
이 절에서 배울 것
  • 궤도 에너지가 긴반지름만으로 정해짐(\(\varepsilon = -GM/2a\))을 유도한다.
  • 활력 방정식 \(v^2 = GM(2/r - 1/a)\)으로 궤도 위 임의의 점에서 속력을 계산한다.
  • 원 궤도 속력과 탈출 속력을 활력 방정식의 특수한 경우로 이해한다.
먼저 알아야 할 것
  • Kepler 법칙의 유도와 원뿔곡선 궤도 (3.1절).
  • 역학적 에너지 보존과 중력 퍼텐셜 에너지 \(-GMm/r\) (공통3 8단원).

궤도 위의 속력을 한 줄로

3.1절에서 궤도의 모양을 구했지만, 궤도 위 어떤 점에서 얼마나 빨리 움직이는지는 아직 모릅니다. 혜성이 태양에 가장 가까이 올 때의 속력, 우주선이 목표 궤도에 들어가려면 필요한 속력 같은 질문에 답하는 식이 활력 방정식입니다. 근거는 에너지 보존과 각운동량 보존 두 가지입니다.

3.2.1궤도 에너지

정의 3.2.1 (궤도 에너지)

단위 질량당 역학적 에너지 \(\varepsilon = \dfrac{v^2}{2} - \dfrac{GM}{r}\)을 궤도 에너지라 한다. 중력만 작용하면 일정하다. (\(M\)은 3.1절의 \(M + m\)으로 읽는다.)

이 에너지를 궤도의 크기와 잇는 것이 목표입니다. 타원의 근점(거리 \(r_p = a(1-e)\), 속력 \(v_p\))과 원점(\(r_a = a(1+e)\), \(v_a\))을 비교합니다. 두 점에서는 속도가 반지름에 수직이므로 각운동량이 \(h = r_pv_p = r_av_a\)입니다.

유도. 에너지 보존으로 \(\frac12v_p^2 - \frac{GM}{r_p} = \frac12v_a^2 - \frac{GM}{r_a}\)이고, \(v_a = v_pr_p/r_a\)를 넣으면 \[ \frac12v_p^2\left(1 - \frac{r_p^2}{r_a^2}\right) = GM\left(\frac1{r_p} - \frac1{r_a}\right) \] 입니다. 좌변 괄호는 \((r_a - r_p)(r_a + r_p)/r_a^2\), 우변 괄호는 \((r_a - r_p)/(r_pr_a)\)이므로 \((r_a - r_p)\)를 지우고 정리하면 \(v_p^2 = \frac{2GM\,r_a}{r_p(r_a + r_p)}\)입니다. 이것을 근점의 에너지에 넣으면 \[ \varepsilon = \frac{GM\,r_a}{r_p(r_a + r_p)} - \frac{GM}{r_p} = \frac{GM}{r_p}\cdot\frac{r_a - r_a - r_p}{r_a + r_p} = -\frac{GM}{r_a + r_p} = -\frac{GM}{2a} \] 입니다. ∎

결과 3.2.2 (활력 방정식) \[ \varepsilon = -\frac{GM}{2a}, \qquad v^2 = GM\left(\frac2r - \frac1a\right) \]

둘째 식은 첫째 식을 정의 3.2.1과 같다고 놓아 얻습니다. 읽는 법을 정리합니다.

  • 에너지는 긴반지름만으로 정해진다. 이심률은 상관없다.
  • 같은 거리 \(r\)에서는 궤도가 클수록(\(a\)가 클수록) 빠르다.
  • \(a\)가 무한대(포물선)이면 \(\varepsilon = 0\), 쌍곡선이면 \(a < 0\)으로 두어 같은 식을 쓴다.

3.2.2두 가지 특별한 속력

  • 원 궤도 속력: \(r = a\)이면 \(v_c = \sqrt{GM/r}\).
  • 탈출 속력: \(a \to \infty\)이면 \(v_{esc} = \sqrt{2GM/r} = \sqrt2\,v_c\).

원 궤도 속력의 √2배를 넘기면 그 천체에 다시 돌아오지 않습니다. 지구 표면에서 \(v_c = 7.9\) km/s, \(v_{esc} = 11.2\) km/s입니다. 아래 탐구 카드에서 속력을 바꾸며 궤도가 원에서 타원, 포물선, 쌍곡선으로 바뀌는 것을 볼 수 있습니다.

예제 3.2.3

핼리 혜성의 긴반지름은 17.8 AU, 근일점 거리는 0.586 AU입니다. 근일점과 원일점에서의 속력을 구하세요. 지구의 공전 속력(1 AU 원 궤도)은 29.78 km/s입니다.

풀이. \(GM_\odot\)/1 AU를 \(v_\oplus^2\)으로 쓰면 \(v = v_\oplus\sqrt{2/r - 1/a}\)(r, a는 AU)입니다. 근일점: \(\sqrt{2/0.586 - 1/17.8} = \sqrt{3.413 - 0.056} = 1.832\)이므로 \(v_p = 54.6\) km/s. 원일점 거리는 \(2\times17.8 - 0.586 = 35.0\) AU이고 \(\sqrt{2/35.0 - 1/17.8} = \sqrt{0.0571 - 0.0562} = 0.0305\)이므로 \(v_a = 0.91\) km/s입니다. 각운동량 보존 \(54.6\times0.586 = 0.91\times35.0\)(둘 다 약 32)으로 검산됩니다.

흔한 오해 "더 높은 궤도로 가려면 더 빨라져야 하니, 높은 궤도의 위성이 더 빠르다." 원 궤도 속력은 \(1/\sqrt r\)로 줄어 높은 궤도일수록 느립니다. 다만 높은 궤도로 옮겨 가는 순간에는 가속해야 하고, 올라가면서 운동 에너지가 위치 에너지로 바뀌어 느려집니다(천우11 1.1절 Hohmann 전이).
요약
  1. 궤도 에너지 \(\varepsilon = v^2/2 - GM/r = -GM/2a\)는 긴반지름만으로 정해진다.
  2. 활력 방정식 \(v^2 = GM(2/r - 1/a)\).
  3. 원 궤도 \(v_c = \sqrt{GM/r}\), 탈출 \(v_{esc} = \sqrt2 v_c\).
  4. 근점과 원점의 속력은 각운동량 보존 \(r_pv_p = r_av_a\)로 검산한다.

3.2.3연습문제

기본

  1. 고도 400 km 원 궤도 위성의 속력과 주기는? (\(GM_\oplus = 3.986\times10^{14}\) m³/s², 지구 반지름 6371 km)
    답

    \(r = 6.771\times10^6\) m, \(v = 7.67\) km/s, \(P = 2\pi r/v = 5550\) s ≈ 92.5분.

  2. 화성 궤도(1.524 AU)에서 태양계를 탈출하는 속력은?
    답

    \(\sqrt2\times29.78/\sqrt{1.524} = 34.1\) km/s.

응용

  1. 지구 궤도(1 AU)에서 태양 쪽으로 출발해 근일점 0.39 AU(수성 궤도)에 닿는 타원 궤도를 타려면 1 AU에서 속력이 얼마여야 합니까?
    답

    \(a = (1 + 0.39)/2 = 0.695\) AU. \(v = 29.78\sqrt{2 - 1/0.695} = 29.78\times0.749 = 22.3\) km/s(지구보다 7.5 km/s 느리게).

  2. 쌍곡선 궤도로 지구에 다가오는 소행성이 무한히 먼 곳에서 5 km/s였습니다. 지구 표면 높이에서의 속력은?
    답

    에너지 보존: \(v^2 = v_\infty^2 + v_{esc}^2 = 25 + 125.4\), \(v = 12.3\) km/s.
