얼마나 꺾을 수 있나, 그리고 태양계를 벗어날 수 있나

예제 · 쌍곡선 궤도 · 중력 도움 · 탈출
문제 해결 전략 · 중력 도움 설계
  1. 원하는 꺾임각 \(\delta\)에서 \(e = 1/\sin(\delta/2)\), 근점 거리 \(r_p = (e - 1)GM/v_\infty^2\)를 구한다.
  2. \(r_p\)가 행성 반지름(대기 포함)보다 커야 한다. 아니면 가장 낮은 안전 고도로 다시 계산한다.
  3. 태양 기준 속도는 벡터 합 \(\mathbf v = \mathbf V_p + \mathbf v_\infty\)로 구하고, 그 자리의 태양 탈출 속력과 비교한다.
먼저 예상해 보기. 행성 옆을 아주 가까이 지나면 탐사선의 방향을 얼마든지 크게 꺾을 수 있을까요?

문제 1. 탐사선이 금성(\(GM = 3.25\times10^5\) km³/s², 반지름 6,052 km)에 \(v_\infty = 6\) km/s로 다가갑니다. 90° 꺾으려면 근점 거리가 얼마여야 합니까? 가능하지 않다면, 고도 300 km로 지날 때의 꺾임각과 속도 변화는?

풀이

  1. 90° 꺾으려면 \(e = 1/\sin45° = 1.414\), \(r_p = 0.414\times3.25\times10^5/36 = 3{,}740\) km.
    결과 3.5.1을 \(r_p\)에 대해 푼다.
  2. 금성 반지름 6,052 km보다 작아 불가능하다(금성에 부딪친다).
    꺾임각에는 행성 크기가 정하는 한계가 있다.
  3. 고도 300 km: \(r_p = 6{,}352\) km, \(e = 1 + 6352\times36/3.25\times10^5 = 1.704\).
    가장 가까이 지나는 경우.
  4. \(\sin(\delta/2) = 0.587\), \(\delta = 71.9°\), \(|\Delta\mathbf v| = 2\times6/1.704 = 7.0\) km/s.
    결과 3.5.2.

의미

꺾임각은 \(v_\infty\)가 작고 행성이 무겁고 작을수록(표면에서의 탈출 속력이 클수록) 커집니다. 그래서 목성처럼 무거운 행성이 중력 도움에 가장 좋고, 한 번으로 모자라면 여러 행성을 차례로 들릅니다.

문제 2. 목성은 태양 둘레를 13.1 km/s로 돕니다. 탐사선이 목성 진행 방향에 수직으로 \(v_\infty = 10\) km/s로 다가와 목성 쪽으로 117.6° 꺾인다면, 나갈 때 \(\mathbf v_\infty\)는 목성 진행 방향과 27.6°를 이룹니다. 들어올 때와 나갈 때 태양 기준 속력은? 목성 궤도(5.2 AU)의 태양 탈출 속력 18.5 km/s와 비교하세요.

풀이

  1. 들어올 때: \(v^2 = 13.1^2 + 10^2 + 2\times13.1\times10\cos90° = 271.6\), \(v = 16.5\) km/s.
    벡터 합의 크기(코사인 법칙).
  2. 나갈 때: \(v^2 = 271.6 + 2\times13.1\times10\times\cos27.6° = 271.6 + 232.2 = 503.8\), \(v = 22.4\) km/s.
    \(\mathbf v_\infty\)의 방향만 바뀌었다.
  3. 들어올 때는 탈출 속력보다 느려 태양에 묶여 있었지만, 나갈 때는 22.4 > 18.5 km/s로 태양계를 벗어나는 궤도가 된다.
    탈출 속력 \(42.1/\sqrt{5.2}\) km/s.

검산

속도 변화의 크기: 두 \(\mathbf v_\infty\) 벡터 사이 각이 117.6°이므로 \(|\Delta\mathbf v| = 2\times10\times\sin58.8° = 17.1\) km/s로, 본문 예제 3.5.1과 같습니다. 목성 기준 속력은 들어올 때와 나갈 때 모두 10 km/s 그대로입니다.

이해 확인

같은 탐사선이 목성의 앞쪽으로 지나가 반대 방향으로 117.6° 꺾이면(나갈 때 목성 진행 방향과 152.4°), 태양 기준 속력은?

답

\(v^2 = 271.6 + 262\cos152.4° = 271.6 - 232.2 = 39.4\), \(v = 6.3\) km/s로 크게 줄어 태양 쪽으로 떨어집니다. 태양 가까이 가는 탐사선이 감속에 쓰는 방법입니다.
