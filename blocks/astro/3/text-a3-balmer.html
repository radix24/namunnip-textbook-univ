수소 원자의 에너지 준위와 Balmer 계열

본문 · 2.3절
이 절에서 배울 것
  • 수소의 에너지 준위 \(E_n = -13.6\text{ eV}/n^2\)를 쓰고 뜻을 안다.
  • Rydberg 식으로 Balmer 선(Hα, Hβ, …)과 계열 한계의 파장을 계산한다.
  • Lyman, Balmer, Paschen 계열이 어느 파장 영역에 있는지 구별한다.
먼저 알아야 할 것
  • 광자의 에너지 \(E = hc/\lambda\) (공통4 12단원).
  • 원자의 전자 구조와 보어 모형 (공통5 6단원), Kirchhoff 법칙 (2.2절).

우주에서 가장 흔한 원소의 지문

우주의 보통 물질 가운데 질량으로 약 4분의 3이 수소입니다. 그래서 별, 성운, 은하의 스펙트럼에서 가장 먼저 찾는 것이 수소의 선입니다. 수소 원자는 양성자 하나와 전자 하나뿐이라 선의 파장을 간단한 식 하나로 정확히 계산할 수 있습니다. 이 절에서는 그 식을 세우고 가시광에 있는 Balmer 계열의 파장을 계산합니다.

2.3.1에너지 준위

결과 2.3.1 (수소의 에너지 준위) \[ E_n = -\frac{13.6\text{ eV}}{n^2}, \qquad n = 1, 2, 3, \dots \]

보어 모형에서는 전자의 각운동량이 \(\hbar = h/2\pi\)의 정수배라는 조건으로 이 식이 나오고, 양자역학(물리8 양자역학(1))도 같은 값을 줍니다. 읽는 법은 이렇습니다.

  • \(n\)은 주양자수로, 전자가 어느 "층"에 있는지를 나타낸다.
  • 에너지가 음수인 것은 전자가 원자핵에 묶여 있다는 뜻이다. 0이 되면 전자가 떨어져 나간다(이온화).
  • 바닥 상태(\(n = 1\))에서 전자를 떼어 내는 데 13.6 eV가 든다. 이것이 수소의 이온화 에너지이다. (1 eV = \(1.602\times10^{-19}\) J)

전자가 높은 준위 \(n_u\)에서 낮은 준위 \(n_l\)로 떨어지면 에너지 차만큼의 광자 하나를 내보내고, 반대로 그 광자를 흡수하면 올라갑니다. 광자 에너지 \(hc/\lambda = E_{n_u} - E_{n_l}\)에 결과 2.3.1을 넣으면 다음 식이 됩니다.

결과 2.3.2 (Rydberg 식) \[ \frac{1}{\lambda} = R_H\left(\frac{1}{n_l^2} - \frac{1}{n_u^2}\right), \qquad R_H = 1.0968\times10^{7}\text{ m}^{-1} \]

\(R_H\)는 \(13.6\text{ eV}/(hc)\)에 해당하는 수로, 원자핵이 아주 조금 함께 움직이는 효과까지 넣은 값입니다. 이 식으로 구한 파장은 진공 파장이고, 공기 중 파장은 0.03%쯤 짧습니다(Hα 진공 656.5 nm, 공기 656.3 nm).

2.3.2Balmer 계열

아래 준위가 \(n_l = 2\)인 선들을 Balmer 계열이라 하며, 위 준위가 3, 4, 5, …인 선을 차례로 Hα, Hβ, Hγ, …라 부릅니다.

예제 2.3.3

Hα와 Hβ의 파장, Balmer 계열 한계(\(n_u \to \infty\))의 파장을 구하세요. Hα 광자의 에너지는 몇 eV입니까?

풀이. Hα: \(1/\lambda = R_H(1/4 - 1/9) = R_H\cdot5/36\), \(\lambda = 36/(5R_H) = 656.5\) nm. Hβ: \(1/4 - 1/16 = 3/16\), \(\lambda = 16/(3R_H) = 486.3\) nm. 한계: \(1/4\), \(\lambda = 4/R_H = 364.7\) nm. Hα 광자 에너지는 \(13.6\times5/36 = 1.89\) eV입니다.

위 준위가 높아질수록 선 사이가 좁아지며 364.7 nm로 몰려듭니다. 이보다 짧은 파장의 빛은 \(n = 2\)의 전자를 아예 떼어 낼 수 있어 연속적으로 흡수되고, 이것이 뜨거운 별 스펙트럼에서 보이는 "Balmer 불연속"입니다.

2.3.3다른 계열과 파장 영역

  • Lyman 계열 (\(n_l = 1\)): Lyα 121.6 nm, 한계 91.2 nm. 자외선이라 지구 대기에 막혀 우주망원경으로 관측한다.
  • Balmer 계열 (\(n_l = 2\)): 656.5 nm ~ 364.7 nm. 가시광.
  • Paschen 계열 (\(n_l = 3\)): Paα 1875 nm, 한계 820 nm. 근적외선.

수소가 Balmer 선을 흡수하려면 전자가 이미 \(n = 2\)에 있어야 합니다. 바닥 상태에서 \(n = 2\)로 올라가는 데 10.2 eV가 필요하므로, 별의 온도가 충분히 높아야 Balmer 흡수선이 강해집니다. 하지만 너무 뜨거우면 수소가 이온화되어 선이 다시 약해집니다. 이 경쟁은 천우4 1.1절의 Saha-Boltzmann 식으로 계산합니다.

주의 원자핵의 전하가 \(Z\)인 수소 같은 이온(He⁺ 등)에서는 \(E_n = -13.6Z^2/n^2\) eV입니다. He II의 선을 수소의 식으로 계산하면 파장이 4배 틀립니다.
요약
  1. 수소의 준위 \(E_n = -13.6\text{ eV}/n^2\). 이온화 에너지 13.6 eV.
  2. \(1/\lambda = R_H(1/n_l^2 - 1/n_u^2)\), \(R_H = 1.0968\times10^7\) m⁻¹.
  3. Balmer(\(n_l = 2\)): Hα 656.5, Hβ 486.3 nm, 한계 364.7 nm.
  4. Lyman은 자외선, Paschen은 적외선.

2.3.4연습문제

기본

  1. Hγ(\(n_u = 5\))의 파장은?
    답

    \(1/\lambda = R_H(1/4 - 1/25) = R_H\cdot21/100\), \(\lambda = 434.1\) nm.

  2. Lyα 광자의 에너지는 몇 eV입니까?
    답

    \(13.6\times(1 - 1/4) = 10.2\) eV.

응용

  1. \(n = 110\)에서 \(n = 109\)로 떨어질 때 나오는 선(전파 재결합선)의 파장은?
    답

    \(1/109^2 - 1/110^2 = 1.53\times10^{-6}\)이므로 \(1/\lambda = 16.8\) m⁻¹, \(\lambda \approx 6.0\) cm. 전파 망원경으로 HII 영역을 관측할 때 쓰는 선입니다.

  2. He II(Z = 2)에서 \(n = 4 \to 3\) 선의 파장은?
    답

    \(1/\lambda = 4R_H(1/9 - 1/16) = 4R_H\times7/144\)에서 \(\lambda = 468.9\) nm(He를 쓰면 \(R\)이 조금 달라 실제 468.6 nm).
