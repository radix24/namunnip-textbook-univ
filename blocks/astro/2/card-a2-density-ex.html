수성의 철과 명왕성의 얼음

예제 · 평균 밀도 · 두 성분 모형
문제 해결 전략 · 밀도에서 성분으로
  1. 질량(위성 궤도)과 반지름으로 평균 밀도를 구한다.
  2. 후보 재료 두 가지를 고르고, 부피가 더해진다는 식 \(1/\bar\rho = f/\rho_1 + (1-f)/\rho_2\)로 질량 비율 \(f\)를 푼다.
  3. 결과가 0과 1 사이인지, 다른 관측(관성 모멘트, 표면 성분)과 맞는지 점검한다.

문제 1. 압축을 뺀 수성의 밀도는 약 5.3 g/cm³이다. 철(7.9)과 암석(3.3)의 두 성분 모형으로 철의 질량 비율을 구하고, 철이 모두 가운데 핵에 모였다면 핵의 반지름이 행성 반지름의 몇 %인지 어림하여라.

풀이

  1. \(1/5.3 = 0.1887\), \(1/7.9 = 0.1266\), \(1/3.3 = 0.3030\).
    역수끼리 섞인다.
  2. \(0.1887 = 0.1266f + 0.3030(1 - f)\)에서 \(f = (0.3030 - 0.1887)/(0.3030 - 0.1266) = 0.65\).
    일차방정식.
  3. 핵의 부피 비율 = 핵 질량/핵 밀도 ÷ 전체 질량/평균 밀도 = \(f\,\bar\rho/\rho_{\text{철}} = 0.65\times5.3/7.9 = 0.44\).
    \(V = M/\rho\).
  4. 반지름 비율 = \(0.44^{1/3} = 0.76\). 핵이 반지름의 약 76%.
    부피 \(\propto R^3\).

의미

지구의 핵은 반지름의 약 55%인데, 수성은 핵이 행성 대부분을 차지한다. 메신저 탐사선의 중력장 측정으로 얻은 값은 약 83%로, 실제 핵은 압축되어 더 무겁고 황 같은 가벼운 원소도 섞여 있어 단순 모형보다 조금 크다. 그래도 '수성은 철이 유난히 많다'는 결론은 밀도 하나로 얻을 수 있다.

먼저 예상해 보기. 명왕성은 얼음 천체라고들 한다. 밀도로 따지면 얼음이 절반을 넘을까?

문제 2. 명왕성의 위성 카론은 긴반지름 19,596 km, 주기 6.387일로 돈다. 이 궤도로 명왕성-카론 계의 질량을 구하고, 명왕성이 그 89%라면 명왕성의 밀도는?(반지름 1,188 km) 암석(3.3)과 물 얼음(0.95)의 두 성분 모형으로 암석의 질량 비율을 구하여라.

풀이

  1. \(M_{\text{계}} = 4\pi^2a^3/(GP^2) = 39.48\times(1.96\times10^7)^3/(6.674\times10^{-11}\times(5.518\times10^5)^2) = 1.46\times10^{22}\) kg.
    카론은 명왕성의 약 8분의 1이라 무시할 수 없어, 먼저 계 전체 질량을 얻는다.
  2. 명왕성: \(0.89\times1.46\times10^{22} = 1.30\times10^{22}\) kg.
    두 천체의 질량 비는 공통 질량 중심 둘레 움직임에서 잰다.
  3. 부피 \(\tfrac43\pi(1.188\times10^6)^3 = 7.02\times10^{18}\) m³, 밀도 1,850 kg/m³ = 1.85 g/cm³.
    \(\bar\rho = M/V\).
  4. \(1/1.85 = 0.541 = 0.303f + 1.053(1 - f)\)에서 \(f = (1.053 - 0.541)/(1.053 - 0.303) = 0.68\). 질량의 약 3분의 2가 암석.
    작은 천체라 압축은 무시.

검산

암석 68%, 얼음 32%의 부피 비율은 \(0.68/3.3 : 0.32/0.95 = 0.206 : 0.337\)로 얼음이 부피의 약 62%이다. '얼음 천체'라는 말은 부피로는 맞고, 질량으로는 암석이 더 많다. 밀도 \(1/(0.206 + 0.337) = 1.84\)로 되돌아와 계산이 맞다.

답
