화성으로 가는 길: 호만 전이와 발사 창

본문
이 절에서 배울 것
  • 두 원 궤도를 잇는 가장 연료가 적게 드는 타원(호만 전이 궤도)의 긴반지름과 비행 시간을 구한다.
  • 출발할 때 목표 행성이 앞서 있어야 하는 각(위상각)을 계산한다.
  • 회합 주기로 발사 창이 다시 열리는 간격을 구한다.
  • 출발과 도착에 필요한 속도 변화를 활력 방정식으로 어림한다.
먼저 알아야 할 것
  • 케플러 법칙 (천우1 1.3절), 탐사 방식과 델타-v (3.1절), 원 궤도 속도 (4.1절).

3.4.1호만 전이 궤도

지구와 화성이 태양 둘레를 원에 가깝게 돈다고 합시다. 지구 궤도에서 접선 방향으로 속도를 조금 높이면, 근일점이 지구 궤도에 있고 원일점이 화성 궤도에 닿는 타원이 됩니다. 원일점에서 다시 접선 방향으로 속도를 높이면 화성 궤도에 올라탑니다. 두 번 모두 진행 방향으로만 밀기 때문에, 두 원 궤도를 잇는 방법 가운데 연료가 가장 적게 듭니다(1925년 호만).

결과 3.4.1

안쪽 궤도 반지름 \(r_1\), 바깥쪽 \(r_2\)이면 전이 궤도는

\[a_t = \frac{r_1 + r_2}{2}, \qquad t_{\text{비행}} = \frac12P_t = \frac12a_t^{3/2}\ \text{년}\ (a_t\text{는 AU}).\]

지구(1 AU)에서 화성(1.524 AU)으로 가면 \(a_t = 1.262\) AU, 비행 시간 \(\tfrac12\times1.262^{1.5} = 0.709\)년 = 259일입니다. 실제 탐사선도 대략 7~9개월 걸립니다.

3.4.2위상각: 언제 떠나야 하는가

탐사선이 원일점에 닿을 때 화성도 그 자리에 있어야 합니다. 비행하는 259일 동안 화성은 \(360°\times259/687 = 136°\) 움직이므로, 출발할 때 화성은 지구보다 \(180° - 136° = 44°\) 앞서 있어야 합니다.

결과 3.4.2 (출발 위상각) \[\phi = 180° - 360°\,\frac{t_{\text{비행}}}{P_2}.\]

\(P_2\)는 목표 행성의 공전 주기입니다. 안쪽 행성(금성 등)으로 갈 때도 같은 식을 쓰며, 이때 \(\phi\)가 음수면 목표가 뒤에 있어야 한다는 뜻입니다.

3.4.3회합 주기와 발사 창

이 배치가 다시 오려면 지구가 화성을 한 바퀴 더 따라잡아야 합니다. 그 간격이 회합 주기입니다.

\[\frac{1}{S} = \frac{1}{P_1} - \frac{1}{P_2} = \frac{1}{1} - \frac{1}{1.881} \;\Rightarrow\; S = 2.135\ \text{년} \approx 780\ \text{일}.\]

그래서 화성 탐사선은 약 26개월마다 무리 지어 떠납니다. 2020년 7월에는 아랍에미리트의 아말, 중국의 톈원 1호, 미국의 퍼서비어런스가 몇 주 사이에 모두 발사되었습니다. 발사 창은 몇 주 정도 열려 있는데, 그보다 벗어나면 필요한 델타-v가 빠르게 늘어납니다.

3.4.4필요한 속도 변화

활력 방정식 \(v^2 = GM_\odot(2/r - 1/a)\)으로 전이 궤도의 근일점과 원일점 속력을 구합니다. 지구 공전 속력은 29.78 km/s입니다.

  • 근일점(1 AU): \(v_p = 29.78\sqrt{2 - 1/1.262} = 32.73\) km/s. 지구보다 2.94 km/s 빨라야 합니다.
  • 원일점(1.524 AU): \(v_a = v_p/1.524 = 21.48\) km/s(각운동량 보존). 화성 공전 속력 \(29.78/\sqrt{1.524} = 24.13\) km/s보다 2.65 km/s 느려, 화성 궤도에 맞추려면 그만큼 더해야 합니다.

이것은 태양 기준 값이고, 실제로는 지구 저궤도에서 지구 중력을 벗어나며 내는 속도 변화(약 3.6 km/s)와 화성에 들어갈 때의 감속을 따로 계산합니다(4.1절의 탈출 속도와 함께). 화성 착륙선은 대기 마찰과 낙하산으로 대부분의 감속을 대신합니다.

예제 3.4.1

지구에서 목성(5.20 AU, 공전 주기 11.86년)으로 호만 전이로 가면 비행 시간과 출발 위상각은?

풀이. \(a_t = 3.10\) AU, \(t = \tfrac12\times3.10^{1.5} = 2.73\)년. 그동안 목성은 \(360°\times2.73/11.86 = 83°\) 움직이므로, 출발 때 목성이 \(180° - 83° = 97°\) 앞서 있어야 합니다. 실제 목성 탐사선은 중력 도움을 써서 시간을 줄이거나 연료를 아낍니다(3.1절).

요약
  1. 호만 전이: \(a_t = (r_1 + r_2)/2\), 비행 시간 = 전이 궤도 주기의 절반. 지구→화성 259일.
  2. 출발 위상각 \(\phi = 180° - 360°\,t/P_2\). 화성은 44° 앞서 있어야 한다.
  3. 발사 창은 회합 주기마다 온다. 화성은 780일(약 26개월).
  4. 활력 방정식으로 출발과 도착의 속도 변화를 구한다.

3.4.5연습문제

기본

  1. 지구에서 금성(0.723 AU)으로 가는 호만 전이의 비행 시간은?
    답

    \(a_t = 0.862\) AU, \(t = \tfrac12\times0.862^{1.5} = 0.400\)년 = 146일.

  2. 금성(공전 주기 0.615년)으로 가는 발사 창은 몇 개월마다 열립니까?
    답

    \(1/S = 1/0.615 - 1 = 0.626\), \(S = 1.60\)년 ≈ 19개월.

응용

  1. 금성으로 갈 때 출발 위상각은? 부호의 뜻은?
    답

    \(180° - 360°\times0.400/0.615 = 180° - 234° = -54°\). 출발할 때 금성이 지구보다 54° 뒤에 있어야 합니다.

  2. 화성에 도착한 탐사선이 지구로 돌아오려면 화성에서 약 450일을 기다려야 합니다. 왕복 전체는 몇 년입니까?
    답

    259 + 450 + 259 ≈ 970일, 약 2.7년. 유인 화성 탐사가 어려운 까닭 가운데 하나입니다.
