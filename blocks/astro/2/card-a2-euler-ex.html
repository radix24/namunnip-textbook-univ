지평식 망원경도 회전 두 번: 가리키는 방향과 천정의 사각지대

예제 · 회전 행렬 · 짐벌 잠김
문제 해결 전략 · 회전으로 방향 벡터 만들기
  1. 좌표축을 정한다: \(x\) = 북, \(y\) = 동, \(z\) = 천정.
  2. 처음 방향(북쪽 지평선 \((1,0,0)\))에 고도 회전과 방위 회전을 차례로 곱해 방향 벡터를 얻는다.
  3. 두 방향 사이의 각은 내적 \(\cos\Theta = \mathbf d_1\cdot\mathbf d_2\)로 구한다.

문제 1. 지평식 가대 망원경은 고도 \(h\)만큼 들어 올린 뒤 방위각 \(A\)(북에서 동쪽으로)만큼 돌립니다. 방향 벡터가 \(\mathbf d = R_z(A)R_y(-h)(1,0,0)^T = (\cos h\cos A, \cos h\sin A, \sin h)\)임을 보이세요. 망원경이 (방위 90°, 고도 30°)에서 (방위 180°, 고도 60°)로 옮겨 갈 때 하늘에서 실제로 움직이는 각은?

풀이

  1. \(R_y(-h)(1,0,0)^T = (\cos h, 0, \sin h)\).
    \(R_y\)의 첫째 열에서 \(\sin(-h) = -\sin h\), 셋째 성분 \(-\sin(-h) = \sin h\).
  2. \(R_z(A)(\cos h, 0, \sin h)^T = (\cos h\cos A, \cos h\sin A, \sin h)\).
    \(z\) 성분은 그대로, \(x, y\)만 돈다.
  3. \(\mathbf d_1 = (\cos30°\cos90°, \cos30°\sin90°, \sin30°) = (0, 0.866, 0.5)\), \(\mathbf d_2 = (\cos60°\cos180°, 0, \sin60°) = (-0.5, 0, 0.866)\).
    대입.
  4. \(\cos\Theta = 0 + 0 + 0.5\times0.866 = 0.433\), \(\Theta = 64.3°\).
    내적.

의미

방위각은 90°, 고도는 30° 바뀌었지만 하늘에서 실제로 움직인 각은 64.3°입니다. 각 좌표의 변화량을 그냥 합치면 안 되고, 회전으로 만든 벡터 사이의 각을 재야 합니다. 위성의 자세 변경(재조준)도 같은 방법으로 '얼마나 돌아야 하는지'를 계산합니다.

검산

구면 삼각법의 거리 공식 \(\cos\Theta = \sin h_1\sin h_2 + \cos h_1\cos h_2\cos(A_1 - A_2) = 0.5\times0.866 + 0.866\times0.5\times\cos90° = 0.433\)과 같습니다.

먼저 예상해 보기. 천정 바로 옆을 지나는 별을 지평식 망원경으로 따라가면, 방위각 모터는 천천히 돌까요, 빠르게 돌까요?

문제 2. 서울에서 적위 38.6°인 별은 천정에서 1° 떨어져 남중합니다. 이 별이 하늘에서 움직이는 빠르기는 \(15''/\text{s}\times\cos\delta\)입니다. 남중할 때 방위각이 바뀌는 빠르기를 어림하세요. 천정에서 0.1°만 떨어진 별이라면?

풀이

  1. 별의 각속력: \(15''\times\cos38.6° = 11.7''/\text{s} = 0.195°/\text{분}\).
    일주운동은 적도에서 가장 빠르다.
  2. 천정에서 거리 \(\zeta\)인 점을 각속력 \(v\)로 지나면 천정에서 본 방향(방위각)은 \(v/\zeta\)(라디안/시간)로 돈다.
    원 둘레 위를 지나가는 점을 중심에서 보는 것과 같다.
  3. \(\zeta = 1°\): \(0.195/1 = 0.195\) rad/분 = 11°/분.
    °/° 비는 라디안.
  4. \(\zeta = 0.1°\): 110°/분 ≈ 1.9°/s. 방위각 모터의 최대 속력이 1°/s라면 따라가지 못한다.
    \(\zeta \to 0\)이면 방위각 속력이 끝없이 커진다.

의미

고도 90°에서 방위각 회전과 '별 둘레의 회전'이 같은 축이 되어 자유도가 하나 사라지는 짐벌 잠김입니다. 그래서 큰 지평식 망원경은 천정 근처 1° 안팎을 '사각지대'로 두고, 위성은 이런 특이점을 피하려고 사원수로 자세를 계산합니다.

이해 확인

문제 1의 두 회전 순서를 바꿔 \(R_y(-h)R_z(A)(1,0,0)^T\)를 계산하면 같은 방향이 나옵니까? (\(A = 90°\), \(h = 30°\))

답

\(R_z(90°)(1,0,0) = (0,1,0)\), 여기에 \(R_y(-30°)\)를 곱하면 \(y\)축 둘레 회전이라 그대로 \((0,1,0)\)입니다. 동쪽 지평선(고도 0°)을 가리켜, 원래의 (0, 0.866, 0.5)와 다릅니다. 순서가 중요합니다.
