칼만 필터의 예측과 갱신

본문 · 5.3절

위성의 GPS 수신기는 1초마다 위치를 잰다. 측정 하나하나에는 수 m의 오차가 있다. 지금까지의 추정을 버리지 않으면서 새 측정이 들어올 때마다 조금씩 고치려면, 새 측정을 얼마나 믿어야 할까? 너무 믿으면 잡음에 흔들리고, 너무 안 믿으면 실제 변화를 놓친다.

먼저 알아야 할 것최소제곱 궤도 결정(5.1절)과 공분산의 전파(5.2절)를 쓴다.

배치 최소제곱은 관측을 모두 모은 뒤 한꺼번에 맞춘다. 반면 측정이 계속 들어오는 실시간 항법에서는 지금의 추정 \(x\)와 그 분산 \(P\)를 들고 다니며 새 측정 하나로 고치는 편이 낫다. 처음 질문의 답은 두 분산의 비, 곧 칼만 이득이 정한다.

5.3.1예측과 갱신

정의 5.3.1 (1차원 칼만 필터)

예측 단계에서는 운동 모형으로 다음 시각의 상태를 내다보고, 모형이 완벽하지 않은 만큼 분산을 키운다. 상태가 그대로라고 보면 \(x^- = x\), \(P^- = P + q\)이다. 갱신 단계에서는 분산이 \(R\)인 측정 \(z\)로 다음과 같이 고친다.

\[ K = \frac{P^-}{P^- + R}, \qquad x = x^- + K(z - x^-), \qquad P = (1 - K)P^- \]

이득 \(K\)는 0과 1 사이이다. 예측이 불확실하면(\(P^- \gg R\)) \(K \approx 1\)이어서 측정을 거의 그대로 믿는다. 거꾸로 예측이 정확하면(\(P^- \ll R\)) \(K \approx 0\)이어서 측정을 조금만 반영한다. 그리고 \(1/P = 1/P^- + 1/R\)이므로 갱신 뒤의 분산은 예측과 측정 어느 쪽보다도 작다.

예제 5.3.1

예측 분산 \(P^- = 4\), 측정 분산 \(R = 1\), 예측 \(x^- = 20\), 측정 \(z = 22\)이다. 갱신된 추정과 분산은 얼마인가?

풀이. \(K = 4/5 = 0.8\)이므로 \(x = 20 + 0.8\times2 = 21.6\), \(P = 0.2\times4 = 0.8\)이다. 측정이 예측보다 정확하므로 측정 쪽으로 많이 옮겼다. 또 분산 0.8은 4와 1 어느 것보다도 작다.

5.3.2천천히 변하는 양을 따라가는 실험

참값이 \(10 + 0.05k\)로 천천히 변하는 양을 오차 1로 100번 잰다. 그리고 값이 그대로 있다고 믿는 \(q = 0\)과 \(q = 0.01\)을 비교한다.

import random

random.seed(2)
R = 1.0**2                        # 측정 분산
truth = [10 + 0.05 * k for k in range(100)]           # 천천히 변하는 참값
z = [x + random.gauss(0, 1.0) for x in truth]

def kalman(z, q, x0=0.0, P0=100.0):
    """1차원 칼만 필터: 상태가 그대로 유지된다고 예측(분산 q만큼 불확실해짐) -> 측정으로 갱신"""
    x, P, out = x0, P0, []
    for zk in z:
        P = P + q                 # 예측: 불확실성 증가
        K = P / (P + R)           # 칼만 이득
        x = x + K * (zk - x)      # 갱신: 측정 쪽으로 K만큼
        P = (1 - K) * P
        out.append((x, P, K))
    return out

for q in (0.0, 0.01):
    res = kalman(z, q)
    err = sum(abs(res[k][0] - truth[k]) for k in range(50, 100)) / 50
    print(f"q = {q:4}: 이득 K는 1번째 {res[0][2]:.3f}, 10번째 {res[9][2]:.3f}, 100번째 {res[99][2]:.3f}; "
          f"마지막 추정 {res[99][0]:.2f} (참값 {truth[99]:.2f}), 뒤 50개 평균 오차 {err:.2f}")
q =  0.0: 이득 K는 1번째 0.990, 10번째 0.100, 100번째 0.010; 마지막 추정 12.22 (참값 14.95), 뒤 50개 평균 오차 2.21
q = 0.01: 이득 K는 1번째 0.990, 10번째 0.126, 100번째 0.095; 마지막 추정 14.66 (참값 14.95), 뒤 50개 평균 오차 0.74

\(q = 0\)이면 이득이 \(1/k\)로 계속 줄어, 필터는 모든 측정의 평균이 된다. 값이 정말 그대로라면 이것이 가장 좋은 추정이다. 그런데 참값이 변하고 있으므로 추정이 뒤처져, 마지막에 2.7만큼 틀린다(그림 1). 한편 \(q = 0.01\)은 이득이 0.1 근처에서 멈춰 최근 측정을 계속 반영하므로 변화를 따라간다. 다시 말해 과정 잡음 \(q\)는 모형이 얼마나 틀릴 수 있는지를 필터에 알려 주는 조절 손잡이이다.

5.3.3궤도 결정에서

실제 궤도용 칼만 필터의 상태는 위치와 속도 6개, 때로는 항력 계수까지 더한 벡터이다. 예측 단계에서 궤도를 적분하며 공분산 행렬을 함께 전파한다(5.2절). 궤도가 비선형이라 단계마다 선형화하는데, 이를 확장 칼만 필터라 한다. 그래서 배치 최소제곱은 사후 정밀 궤도에, 칼만 필터는 위성 GNSS 수신기나 자세 결정 같은 실시간 항법에 주로 쓴다.

흔한 실수필터가 내는 분산 \(P\)는 작은데 실제 오차가 훨씬 크면, \(q\)나 \(R\)을 너무 작게 잡아 필터가 자신을 과신하는 것이다. 이를 필터 발산이라 한다. 측정과 예측의 차, 곧 혁신이 \(\sqrt{P^- + R}\)보다 늘 크게 나오는지 확인하면 알아챌 수 있다.
마무리

칼만 필터는 예측(\(P^- = P + q\))과 갱신(\(K = P^-/(P^- + R)\), \(x = x^- + K(z - x^-)\), \(P = (1 - K)P^-\))을 되풀이한다. 이득 \(K\)는 예측과 측정의 신뢰도 비이며, 갱신하면 분산은 늘 줄어든다. 과정 잡음 \(q\)가 너무 작으면 실제 변화를 따라가지 못하고, 궤도에는 확장 칼만 필터를 쓴다.

5.3.4연습문제

기본

  1. \(P^- = R\)이면 이득은 얼마인가? 갱신된 추정은 예측과 측정 사이 어디에 놓이는가?
    답

    \(K = 0.5\)이므로 정확히 가운데에 놓인다.

  2. \(q = 0\)이고 처음 분산이 아주 크면 \(k\)번째 이득은 대략 얼마인가?
    답

    \(1/k\)이다. 필터가 누적 평균과 같아진다.

응용

  1. \(q\)를 지나치게 크게, 예컨대 10으로 잡으면 어떻게 되는가?
    답

    이득이 거의 1이 되어 측정마다 그대로 믿으므로, 추정이 측정 잡음만큼 흔들려 평균하는 이점을 잃는다.

  2. \(q = 0\)일 때 \(P^- = 1\), \(R = 1\)에서 시작해 측정 두 번을 받으면 분산은 얼마가 되는가?
    답

    첫 갱신에서 \(1/P = 1 + 1 = 2\), 둘째에서 \(1/P = 3\)이므로 \(P = 1/3\)이다.
