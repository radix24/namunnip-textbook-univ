칼만 필터: 예측하고, 측정으로 고치고, 되풀이하기

본문
이 절에서 배울 것
  • 측정이 들어올 때마다 추정을 고치는 순차 추정의 '예측-갱신' 구조를 안다.
  • 1차원 칼만 필터의 이득 \(K = P/(P + R)\)가 '예측과 측정 가운데 무엇을 더 믿을지'를 정함을 이해한다.
  • 과정 잡음 \(q\)를 너무 작게 잡으면 추정이 실제 변화를 따라가지 못함을 확인한다.
  • 궤도 결정에서 배치 최소제곱과 칼만 필터의 쓰임을 비교한다.
먼저 알아야 할 것
  • 최소제곱 궤도 결정 (5.1절), 공분산의 전파 (5.2절).

5.3.1예측과 갱신

배치 최소제곱(5.1절)은 관측을 모두 모은 뒤 한꺼번에 맞춥니다. 위성 자세 제어나 실시간 궤도 결정처럼 측정이 계속 들어오는 상황에서는, 지금까지의 추정 \(x\)와 그 분산 \(P\)를 들고 다니며 새 측정 하나로 고치는 편이 좋습니다.

정의 5.3.1 (1차원 칼만 필터)
  1. 예측: 운동 모형으로 다음 시각의 상태를 내다보고, 모형이 완벽하지 않은 만큼 분산을 키운다. 상태가 그대로라 보면 \(x^- = x\), \(P^- = P + q\).
  2. 갱신: 측정 \(z\)(분산 \(R\))가 들어오면 \[K = \frac{P^-}{P^- + R}, \qquad x = x^- + K(z - x^-),\] \[P = (1 - K)P^-.\]

이득 \(K\)는 0과 1 사이입니다. 예측이 불확실하면(\(P^- \gg R\)) \(K \approx 1\)로 측정을 거의 그대로 믿고, 예측이 정확하면(\(P^- \ll R\)) \(K \approx 0\)으로 측정을 조금만 반영합니다. 갱신 뒤의 분산은 늘 줄어듭니다.

5.3.2실험: 천천히 변하는 양 따라가기

참값이 \(10 + 0.05k\)로 천천히 변하는 양을 오차 1로 100번 잽니다. \(q = 0\)(그대로 있다고 믿음)과 \(q = 0.01\)을 비교합니다.

import random

random.seed(2)
R = 1.0**2                        # 측정 분산
truth = [10 + 0.05 * k for k in range(100)]           # 천천히 변하는 참값
z = [x + random.gauss(0, 1.0) for x in truth]

def kalman(z, q, x0=0.0, P0=100.0):
    """1차원 칼만 필터: 상태가 그대로 유지된다고 예측(분산 q만큼 불확실해짐) -> 측정으로 갱신"""
    x, P, out = x0, P0, []
    for zk in z:
        P = P + q                 # 예측: 불확실성 증가
        K = P / (P + R)           # 칼만 이득
        x = x + K * (zk - x)      # 갱신: 측정 쪽으로 K만큼
        P = (1 - K) * P
        out.append((x, P, K))
    return out

for q in (0.0, 0.01):
    res = kalman(z, q)
    err = sum(abs(res[k][0] - truth[k]) for k in range(50, 100)) / 50
    print(f"q = {q:4}: 이득 K는 1번째 {res[0][2]:.3f}, 10번째 {res[9][2]:.3f}, 100번째 {res[99][2]:.3f}; "
          f"마지막 추정 {res[99][0]:.2f} (참값 {truth[99]:.2f}), 뒤 50개 평균 오차 {err:.2f}")
q =  0.0: 이득 K는 1번째 0.990, 10번째 0.100, 100번째 0.010; 마지막 추정 12.22 (참값 14.95), 뒤 50개 평균 오차 2.21
q = 0.01: 이득 K는 1번째 0.990, 10번째 0.126, 100번째 0.095; 마지막 추정 14.66 (참값 14.95), 뒤 50개 평균 오차 0.74

\(q = 0\)이면 이득이 \(1/k\)로 계속 줄어 필터는 '모든 측정의 평균'이 됩니다. 값이 그대로라면 가장 좋은 추정이지만, 참값이 변하고 있어 추정이 뒤처집니다(마지막 오차 2.7). \(q = 0.01\)은 이득이 0.1 근처에서 멈춰 최근 측정을 계속 반영하므로 변화를 따라갑니다. 과정 잡음 \(q\)는 '모형이 얼마나 틀릴 수 있는가'를 필터에 알려 주는 조절 손잡이입니다.

5.3.3궤도 결정에서

실제 궤도용 칼만 필터는 상태가 위치·속도 6개(때로는 항력 계수 등 추가)인 벡터이고, 예측 단계에서 궤도를 적분하며 공분산 행렬을 함께 전파합니다(5.2절). 궤도가 비선형이라 매 단계 선형화하는 확장 칼만 필터를 씁니다. 배치 최소제곱은 사후 정밀 궤도, 칼만 필터는 실시간 항법(위성 GNSS 수신기, 자세 결정)에 주로 씁니다.

예제 5.3.1

예측 분산 \(P^- = 4\), 측정 분산 \(R = 1\), 예측 \(x^- = 20\), 측정 \(z = 22\)입니다. 갱신된 추정과 분산은?

풀이. \(K = 4/5 = 0.8\), \(x = 20 + 0.8\times2 = 21.6\), \(P = 0.2\times4 = 0.8\). 측정이 예측보다 정확해 측정 쪽으로 많이 옮겼고, 분산은 둘 어느 것보다도 작아졌습니다(\(1/P = 1/4 + 1/1\)).

요약
  1. 예측: \(x^- \), \(P^- = P + q\). 갱신: \(K = P^-/(P^- + R)\), \(x = x^- + K(z - x^-)\), \(P = (1 - K)P^-\).
  2. \(K\)는 예측과 측정의 신뢰도 비. 갱신하면 분산은 늘 준다.
  3. \(q\)가 너무 작으면 실제 변화를 못 따라간다. 궤도에는 확장 칼만 필터.

5.3.4연습문제

기본

  1. \(P^- = R\)이면 이득은? 갱신된 추정은 예측과 측정의 어디에 놓입니까?
    답

    \(K = 0.5\), 정확히 가운데.

  2. \(q = 0\)이고 처음 분산이 아주 크면 \(k\)번째 이득은 대략?
    답

    \(1/k\). 필터가 누적 평균과 같아집니다.

응용

  1. \(q\)를 지나치게 크게(예: 10) 잡으면 어떻게 됩니까?
    답

    이득이 거의 1이 되어 매 측정을 그대로 믿으므로, 추정이 측정 잡음만큼 흔들려 평균하는 이점을 잃습니다.

  2. 필터가 내는 분산 \(P\)는 작은데 실제 오차가 그보다 훨씬 크다면, 무엇을 의심해야 합니까?
    답

    모형이 틀렸거나 \(q\)(또는 \(R\))를 너무 작게 잡아 필터가 자신을 과신하는 것입니다(필터 발산). 측정과 예측의 차(혁신)가 \(\sqrt{P^- + R}\)보다 늘 크게 나오는지 확인합니다.
