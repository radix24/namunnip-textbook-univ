구면 삼각법으로 좌표 변환식 유도하기

본문 · 1.1절
이 절에서 배울 것
  • 구면 삼각형과 구면 코사인 법칙, 사인 법칙을 안다.
  • 천구 북극-천정-천체의 삼각형으로 적도좌표를 지평좌표로 바꾸는 식을 유도한다.
  • 같은 방법이 황도좌표, 은하좌표 변환에도 쓰임을 안다.
먼저 알아야 할 것
  • 적도좌표와 지평좌표 (천우1 1.1절), 공간벡터의 내적 (공통2 1단원).

하늘은 구면이다

천체의 위치는 관측자를 중심으로 한 커다란 구면(천구) 위의 점으로 나타냅니다. 평면 위의 삼각형에는 피타고라스 정리와 삼각비를 쓰지만, 구면 위의 삼각형은 각의 합이 180°보다 크고 다른 공식이 필요합니다. 그 공식이 구면 삼각법이고, 좌표계 사이를 오가는 모든 식이 여기서 나옵니다. 천체관측 과목이 공통으로 다루는 구면 천문학의 출발점입니다.

1.1.1구면 삼각형

구의 중심을 지나는 평면이 구면과 만나는 원을 대원이라 합니다(적도, 자오선). 세 대원의 호로 둘러싸인 도형이 구면 삼각형입니다. 단위 구면에서 변의 길이는 중심에서 본 각(라디안 또는 도)으로 잽니다.

정리 1.1.1 (구면 코사인 법칙)

변 \(a, b, c\)와 그 맞은편 꼭짓점의 각 \(A, B, C\)를 가진 구면 삼각형에서 \[ \cos a = \cos b\cos c + \sin b\sin c\cos A \]

증명. 단위 구의 중심 O에서 꼭짓점 A, B, C로 가는 단위벡터를 \(\vec A, \vec B, \vec C\)라 합니다. 변의 길이는 두 벡터 사이의 각이므로 \(\cos a = \vec B\cdot\vec C\)입니다. \(\vec A\)를 \(z\)축으로, \(\vec B\)가 \(xz\) 평면에 놓이도록 좌표를 잡으면 \(\vec B = (\sin c, 0, \cos c)\)입니다. \(\vec C\)는 \(\vec A\)에서 각 \(b\)만큼 떨어져 있고, 꼭짓점 A에서 두 변이 이루는 각이 \(A\)이므로 \(\vec C = (\sin b\cos A, \sin b\sin A, \cos b)\)입니다. 내적을 계산하면 \(\vec B\cdot\vec C = \sin c\sin b\cos A + \cos c\cos b\)입니다. ∎

벡터와 내적을 배우지 않았다면 여기서 \(\vec B\)는 '중심 O에서 점 B까지의 화살표'를 좌표 \((x, y, z)\)로 적은 것이고, 길이가 1입니다. 두 점 B\((x_1, y_1, z_1)\), C\((x_2, y_2, z_2)\)가 단위 구 위에 있을 때 내적 \(\vec B\cdot\vec C = x_1x_2 + y_1y_2 + z_1z_2\)가 왜 \(\cos a\)인지는 고교 수학으로 보일 수 있습니다. 삼각형 OBC에서 두 변이 1, 사잇각이 \(a\)이므로 코사인 법칙으로 \(\overline{BC}^2 = 2 - 2\cos a\)입니다. 한편 공간에서 두 점 사이 거리(피타고라스 정리를 세 방향으로 늘린 것)로 \(\overline{BC}^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2 = 2 - 2(x_1x_2 + y_1y_2 + z_1z_2)\)입니다(각 점에서 \(x^2 + y^2 + z^2 = 1\)). 두 식을 비교하면 \(\cos a = x_1x_2 + y_1y_2 + z_1z_2\)입니다.

같은 방법으로 사인 법칙 \(\frac{\sin a}{\sin A} = \frac{\sin b}{\sin B} = \frac{\sin c}{\sin C}\)도 얻습니다. 변이 아주 작으면 \(\cos x \approx 1 - x^2/2\), \(\sin x \approx x\)로 평면의 코사인 법칙이 됩니다.

1.1.2적도좌표에서 지평좌표로

세 꼭짓점을 천구 북극 P, 천정 Z, 천체 X로 잡은 삼각형(천문 삼각형)을 봅니다.

  • 변 PZ \(= 90^\circ - \varphi\) (\(\varphi\)는 위도. 천구 북극의 고도가 위도이므로)
  • 변 PX \(= 90^\circ - \delta\) (\(\delta\)는 적위)
  • 변 ZX \(= 90^\circ - h\) (\(h\)는 고도)
  • P에서의 각 \(= H\) (시간각), Z에서의 각 \(= 360^\circ - A\) (\(A\)는 북에서 동쪽으로 잰 방위각)

구면 코사인 법칙을 변 ZX에 쓰면 \(\cos(90^\circ - h) = \cos(90^\circ - \varphi)\cos(90^\circ - \delta) + \sin(90^\circ - \varphi)\sin(90^\circ - \delta)\cos H\), 곧

\[ \sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H \]

입니다. 방위각은 사인 법칙과 코사인 법칙을 하나 더 써서

\[ \sin A\cos h = -\cos\delta\sin H, \qquad \cos A\cos h = \sin\delta\cos\varphi - \cos\delta\sin\varphi\cos H \]

로 얻습니다. 두 식을 함께 쓰면(atan2) 방위각의 사분면이 정확히 정해집니다. 천우1에서 결과만 쓴 식을 이렇게 유도했습니다.

예제 1.1.2

서울(\(\varphi = 37.57^\circ\))에서 안드로메다 은하(\(\delta = 41.27^\circ\))가 시간각 \(H = -2.38\)h(남중 2시간 23분 전)에 있습니다. 고도와 방위각은?

풀이. \(H = -35.7^\circ\). \(\sin h = 0.6097\times0.6597 + 0.7926\times0.7516\times0.8121 = 0.4022 + 0.4838 = 0.8860\), \(h = 62.4^\circ\). 방위각은 \(\sin A\cos h = -0.7516\times(-0.5835) = 0.4386\), \(\cos A\cos h = 0.6597\times0.7926 - 0.7516\times0.6097\times0.8121 = 0.5229 - 0.3722 = 0.1507\)이므로 \(A = \text{atan2}(0.4386, 0.1507) = 71.0^\circ\)(동북동)입니다.

1.1.3다른 좌표계

같은 원리로 기준 대원만 바꾸면 됩니다. 황도좌표는 천구 북극 대신 황도 북극(천구 북극에서 \(\varepsilon = 23.44^\circ\) 기울어짐)을, 은하좌표는 은하 북극(적경 12h51m, 적위 +27.1°)을 꼭짓점으로 씁니다. 실전에서는 회전 행렬(좌표축을 돌리는 계산을 숫자 표 하나로 묶어 적은 것. 이 절을 읽는 데는 몰라도 됩니다)로 한꺼번에 계산하며(astropy.coordinates), 구면 삼각법은 그 행렬이 무엇을 하는지 이해하는 바탕입니다.

주의 방위각을 \(\arcsin\)이나 \(\arccos\) 하나만으로 구하면 사분면을 잘못 고르기 쉽습니다. 사인과 코사인을 함께 구해 atan2를 쓰세요. 또 방위각의 기준(북 0° 또는 남 0°)이 책과 프로그램마다 달라 확인이 필요합니다.
요약
  1. 구면 코사인 법칙 \(\cos a = \cos b\cos c + \sin b\sin c\cos A\)는 단위벡터 내적으로 증명한다.
  2. 천문 삼각형(천구 북극-천정-천체)에서 \(\sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H\).
  3. 방위각은 \(\sin A\cos h\)와 \(\cos A\cos h\)를 함께 구해 atan2로.
  4. 황도·은하좌표도 기준 극만 바꿔 같은 방법으로.

1.1.4연습문제

기본

  1. \(\varphi = 37.5^\circ\), \(\delta = 0\), \(H = 6\)h인 천체의 고도는?
    답

    \(\sin h = 0 + \cos\varphi\cdot1\cdot\cos90^\circ = 0\): 지평선(정서쪽에서 짐).

  2. 변이 모두 90°인 구면 삼각형의 각의 합은?
    답

    270°(모든 각이 90°).

응용

  1. 두 별의 적경·적위로 각거리 \(\theta\)를 구하는 식을 구면 코사인 법칙으로 쓰세요.
    답

    \(\cos\theta = \sin\delta_1\sin\delta_2 + \cos\delta_1\cos\delta_2\cos(\alpha_1 - \alpha_2)\).

  2. 서울과 뉴욕(위도 40.7°, 경도 −74.0°) 사이 대원 거리를 구하세요(서울 37.57°, 126.98°, 지구 반지름 6,371 km).
    답

    경도 차 201.0° → \(\cos\theta = 0.6097\times0.6521 + 0.7926\times0.7581\times\cos201^\circ = 0.3976 - 0.5610 = -0.1634\), \(\theta = 99.4^\circ\), 거리 약 11,050 km.
