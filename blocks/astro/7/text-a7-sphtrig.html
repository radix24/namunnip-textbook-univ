구면 삼각법으로 좌표 변환식 유도하기

본문 · 1.1절

천우1에서는 적위와 시간각으로 고도를 구하는 식 \(\sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H\)를 결과만 썼다. 이 식은 어디서 나올까? 하늘은 구면이라 각의 합이 180°보다 큰 삼각형이 생기고 평면의 삼각비가 통하지 않는다. 구면 위의 삼각형은 어떤 법칙을 따를까?

먼저 알아야 할 것적도좌표와 지평좌표(천우1 1.1절)와 공간벡터의 내적(공통2 1단원)을 쓴다.

1.1.1구면 삼각형

천체의 위치는 관측자를 중심으로 한 커다란 구면, 곧 천구 위의 점으로 나타낸다. 구의 중심을 지나는 평면이 구면과 만나는 원을 대원이라 하며(적도, 자오선), 세 대원의 호로 둘러싸인 도형이 구면 삼각형이다. 여기서 단위 구면의 변의 길이는 중심에서 본 각으로 잰다. 처음 질문의 답, 곧 좌표계 사이를 오가는 모든 식은 다음 법칙에서 나온다.

정리 1.1.1 (구면 코사인 법칙)

변 \(a, b, c\)와 그 맞은편 꼭짓점의 각 \(A, B, C\)를 가진 구면 삼각형에서

\[\cos a = \cos b\cos c + \sin b\sin c\cos A\]

증명. 단위 구의 중심 O에서 꼭짓점 A, B, C로 가는 단위벡터를 \(\vec A, \vec B, \vec C\)라 하자. 변의 길이는 두 벡터 사이의 각이므로 \(\cos a = \vec B\cdot\vec C\)이다. \(\vec A\)를 \(z\)축으로, \(\vec B\)가 \(xz\) 평면에 놓이도록 좌표를 잡으면 \(\vec B = (\sin c, 0, \cos c)\)이다. 또 \(\vec C\)는 \(\vec A\)에서 각 \(b\)만큼 떨어져 있고 꼭짓점 A에서 두 변이 이루는 각이 \(A\)이므로 \(\vec C = (\sin b\cos A, \sin b\sin A, \cos b)\)이다. 내적을 계산하면 \(\vec B\cdot\vec C = \sin c\sin b\cos A + \cos c\cos b\)이다. ∎

한편 내적이 왜 \(\cos a\)인지는 고교 수학으로도 보일 수 있다. 삼각형 OBC에서 두 변이 1, 사잇각이 \(a\)이므로 코사인 법칙으로 \(\overline{BC}^2 = 2 - 2\cos a\)이다. 한편 공간에서 두 점 사이 거리로 \(\overline{BC}^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2 = 2 - 2(x_1x_2 + y_1y_2 + z_1z_2)\)이므로, 두 식을 비교하면 \(\cos a = x_1x_2 + y_1y_2 + z_1z_2\)이다. 그리고 같은 방법으로 사인 법칙 \(\frac{\sin a}{\sin A} = \frac{\sin b}{\sin B} = \frac{\sin c}{\sin C}\)도 얻는다. 또 변이 아주 작으면 \(\cos x \approx 1 - x^2/2\), \(\sin x \approx x\)로 평면의 코사인 법칙이 된다.

1.1.2적도좌표에서 지평좌표로

이제 천구 북극 P, 천정 Z, 천체 X를 꼭짓점으로 하는 천문 삼각형을 보자(그림 1). 천구 북극의 고도가 위도이므로 변 PZ는 \(90^\circ - \varphi\)이고, 변 PX는 \(90^\circ - \delta\), 변 ZX는 \(90^\circ - h\)이다. 또 P에서의 각은 시간각 \(H\), Z에서의 각은 \(360^\circ - A\)이다(\(A\)는 북에서 동쪽으로 잰 방위각). 구면 코사인 법칙을 변 ZX에 쓰면 \(\cos(90^\circ - h) = \cos(90^\circ - \varphi)\cos(90^\circ - \delta) + \sin(90^\circ - \varphi)\sin(90^\circ - \delta)\cos H\), 곧 처음 질문의 식이 나온다.

\[\sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H\]

또 방위각은 사인 법칙과 코사인 법칙을 하나 더 써서 다음과 같이 얻는다. 두 식을 함께 쓰면(atan2) 방위각의 사분면이 정확히 정해진다.

\[\sin A\cos h = -\cos\delta\sin H, \qquad \cos A\cos h = \sin\delta\cos\varphi - \cos\delta\sin\varphi\cos H\]
예제 1.1.1

서울(\(\varphi = 37.57^\circ\))에서 안드로메다 은하(\(\delta = 41.27^\circ\))가 시간각 \(H = -2.38\)h(남중 2시간 23분 전)에 있다. 고도와 방위각은 얼마인가?

풀이. \(H = -35.7^\circ\)이므로 \(\sin h = 0.6097\times0.6597 + 0.7926\times0.7516\times0.8121 = 0.8860\), 곧 \(h = 62.4^\circ\)이다. 방위각은 \(\sin A\cos h = -0.7516\times(-0.5835) = 0.4386\), \(\cos A\cos h = 0.6597\times0.7926 - 0.7516\times0.6097\times0.8121 = 0.1507\)이므로 \(A = \text{atan2}(0.4386, 0.1507) = 71.0^\circ\)(동북동)이다.

1.1.3다른 좌표계

그런데 같은 원리로 기준 대원만 바꾸면 된다. 황도좌표는 천구 북극 대신 황도 북극(천구 북극에서 \(\varepsilon = 23.44^\circ\) 기울어짐)을, 은하좌표는 은하 북극(적경 12h51m, 적위 +27.1°)을 꼭짓점으로 쓴다. 실전에서는 좌표축을 돌리는 계산을 숫자 표 하나로 묶은 회전 행렬로 한꺼번에 계산하지만(astropy.coordinates), 구면 삼각법은 그 행렬이 무엇을 하는지 이해하는 바탕이다.

주의방위각을 \(\arcsin\)이나 \(\arccos\) 하나만으로 구하면 사분면을 잘못 고르기 쉽다. 사인과 코사인을 함께 구해 atan2를 쓴다. 또 방위각의 기준(북 0° 또는 남 0°)이 책과 프로그램마다 달라 확인이 필요하다.
마무리

구면 삼각형의 변과 각은 단위벡터의 내적으로 증명하는 구면 코사인 법칙 \(\cos a = \cos b\cos c + \sin b\sin c\cos A\)와 사인 법칙을 따른다. 천구 북극, 천정, 천체로 이룬 천문 삼각형에 이를 쓰면 \(\sin h = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos H\)가 나오고, 방위각은 \(\sin A\cos h\)와 \(\cos A\cos h\)를 함께 구해 atan2로 얻는다. 황도좌표와 은하좌표도 기준 극만 바꿔 같은 방법으로 변환한다.

1.1.4연습문제

기본

  1. \(\varphi = 37.5^\circ\), \(\delta = 0\), \(H = 6\)h인 천체의 고도는 얼마인가?
    답

    \(\sin h = 0 + \cos\varphi\cdot1\cdot\cos90^\circ = 0\)이므로 지평선에 있다(정서쪽에서 진다).

  2. 변이 모두 90°인 구면 삼각형의 각의 합은 얼마인가?
    답

    모든 각이 90°이므로 270°이다.

응용

  1. 두 별의 적경과 적위로 각거리 \(\theta\)를 구하는 식을 구면 코사인 법칙으로 써라.
    답

    천구 북극과 두 별로 삼각형을 만들면 \(\cos\theta = \sin\delta_1\sin\delta_2 + \cos\delta_1\cos\delta_2\cos(\alpha_1 - \alpha_2)\)이다.

  2. 서울(37.57°, 126.98°)과 뉴욕(40.7°, −74.0°) 사이 대원 거리를 구하여라(지구 반지름 6,371 km).
    답

    경도 차는 201.0°이므로 \(\cos\theta = 0.6097\times0.6521 + 0.7926\times0.7581\times\cos201^\circ = -0.1634\), \(\theta = 99.4^\circ\)이고 거리는 약 11,050 km이다.
