노출 시간 계산과 관측 시간 신청서

본문 · 7.3절

망원경 시간은 경쟁으로 배정된다. 신청서에 "대상 12개를 S/N 50으로 측광하려면 3.7시간이 필요하다"라고 쓰려면 그 숫자의 근거가 있어야 한다. 원하는 S/N에서 노출 시간을 어떻게 거꾸로 구할까? 그리고 653초를 한 장으로 찍을지 16장으로 나눠 찍을지는 어떻게 정할까?

먼저 알아야 할 것신호 대 잡음비(4.3절)와 관측 계획(7.1절)을 쓴다.

7.3.1CCD 방정식을 거꾸로

별에서 1초에 \(\dot N_*\) 전자, 하늘에서 화소당 \(\dot N_s\), 암전류 \(\dot N_d\), 구경 안 화소 \(n\)개, 읽기 잡음 \(R\)이면 다음과 같다(4.3절).

\[\frac SN = \frac{\dot N_*t}{\sqrt{\dot N_*t + n(\dot N_s + \dot N_d)t + nR^2}}\]

처음 질문의 첫째 답은 이 식을 거꾸로 푸는 것이다. 원하는 S/N을 \(Q\)라 두고 양변을 제곱하면 \(t\)에 대한 이차방정식이 된다.

결과 7.3.1 (필요 노출 시간) \[\dot N_*^2t^2 - Q^2\bigl[\dot N_* + n(\dot N_s + \dot N_d)\bigr]t - Q^2nR^2 = 0\]

양의 근을 고른다. 관측소가 제공하는 노출 시간 계산기(ETC)가 이 계산을 한다.

import math

def exposure_time(snr, star, sky, npix, rn, dark=0.0):
    """CCD 방정식을 t에 대해 푼다. star는 별 전자율(e-/s), sky와 dark는 화소당 전자율, rn은 읽기 잡음(e-)"""
    a = star**2
    b = -snr**2 * (star + npix * (sky + dark))
    c = -snr**2 * npix * rn**2
    return (-b + math.sqrt(b * b - 4 * a * c)) / (2 * a)

def snr_at(t, star, sky, npix, rn, dark=0.0):
    s = star * t
    return s / math.sqrt(s + npix * (sky * t + dark * t + rn**2))

t = exposure_time(50, star=50, sky=20, npix=30, rn=8)
print(f"S/N 50에 필요한 시간 = {t:.0f} s, 검산 S/N = {snr_at(t, 50, 20, 30, 8):.2f}")
for n in (1, 4, 16):
    tt = t / n
    total = snr_at(tt, 50, 20, 30, 8) * math.sqrt(n)
    print(f"{n:2d}장으로 나눠 찍기({tt:6.1f} s씩), 합친 S/N = {total:.2f}")
S/N 50에 필요한 시간 = 653 s, 검산 S/N = 50.00
 1장으로 나눠 찍기( 652.9 s씩), 합친 S/N = 50.00
 4장으로 나눠 찍기( 163.2 s씩), 합친 S/N = 49.67
16장으로 나눠 찍기(  40.8 s씩), 합친 S/N = 48.39

7.3.2나눠 찍기의 값

둘째 질문의 답은 손해와 이득을 견주는 것이다. 같은 총시간을 여러 장으로 나누면 장마다 읽기 잡음이 한 번씩 더해져 S/N이 조금 준다(16장이면 50에서 48.4, 그림 1). 그래도 나눠 찍는 까닭이 있다. 여러 장의 중앙값으로 우주선을 지우고, 밝은 별의 포화를 피하며, 위성 궤적이나 구름 낀 장을 버리고, 망원경을 조금씩 옮겨 불량 화소를 메우기(디더링) 위해서이다. 그리고 하늘빛이 읽기 잡음보다 충분히 크면(\(\dot N_st \gg R^2\)) 나눠도 손해가 거의 없다. 그러므로 한 장의 노출을 "하늘 잡음이 읽기 잡음을 넘는 시간" 이상으로 정하는 것이 경험 규칙이다.

7.3.3관측 시간 신청서

신청서는 보통 세 가지를 숫자로 보여야 한다. 먼저 과학 목표로, 무엇을 왜 재는지와 어떤 정밀도(예를 들어 0.02등급, 시선속도 1 km/s)가 필요한지를 쓴다. 다음으로 기술적 근거로, 그 정밀도가 요구하는 S/N, ETC로 구한 노출 시간, 그리고 대상 수 × 시간에 보정 영상과 망원경 이동 시간(오버헤드)을 더한 총시간을 쓴다. 끝으로 가능성으로, 대상의 고도와 달의 위상(7.1절), 필요한 시상, 왜 이 망원경이어야 하는지를 쓴다. 시간을 과하게 신청하면 심사에서 깎이고 모자라게 신청하면 목표를 이루지 못하므로, ETC의 가정(시상, 하늘 밝기, 대기 질량)을 신청서에 함께 적는다.

예제 7.3.1

위 계산에서 하늘빛이 달빛 때문에 화소당 20에서 80 e⁻/s로 늘면 같은 S/N에 필요한 시간은 얼마인가?

풀이. exposure_time(50, 50, 80, 30, 8)을 손으로 풀면 \(b = -2500\times(50 + 2400) = -6.125\times10^6\)이고, 읽기 잡음 항은 거의 무시되므로 \(t \approx 6.125\times10^6/2500 = 2450\) s이다. 즉 약 3.8배가 된다. 어두운 대상은 달 없는 밤을 신청하는 까닭이다.

주의ETC의 결과는 가정한 시상, 하늘 밝기, 대기 질량에서의 값이다. 시상이 1″에서 2″로 나빠지면 구경 화소 수가 4배로 늘어 하늘 잡음 지배에서는 같은 S/N에 시간이 크게 늘므로, 신청서에 여유를 숫자로 적는다.
마무리

원하는 S/N에 필요한 노출 시간은 CCD 방정식을 \(t\)의 이차방정식으로 풀어 구하며, 이것이 노출 시간 계산기(ETC)가 하는 일이다. 여러 장으로 나눠 찍으면 장마다 읽기 잡음만큼 손해이므로, 하늘 잡음이 읽기 잡음을 넘을 만큼 길게 찍고 나눈다. 관측 시간 신청서는 목표 정밀도, 필요한 S/N, 노출 시간, 오버헤드를 포함한 총시간, 관측 가능성을 숫자로 뒷받침한다.

7.3.4연습문제

기본

  1. 밝은 별(하늘과 읽기 잡음 무시)에서 S/N을 두 배로 하려면 노출 시간은 몇 배여야 하는가? 측광 정밀도 0.01등급에 필요한 S/N은?
    답

    \(S/N \propto \sqrt t\)이므로 4배이다. 또 \(\sigma_m \approx 1.086/(S/N)\)이므로 S/N은 약 109가 필요하다.

응용

  1. 대상 12개를 각각 653초씩 찍고, 대상마다 망원경 이동과 맞추기에 5분, 밤마다 보정 영상에 30분이 든다. 총 몇 시간을 신청해야 하는가?
    답

    \(12\times(653 + 300) = 11{,}436\) s ≈ 3.2시간에 0.5시간을 더해 약 3.7시간이다. 날씨 손실을 고려한 여유를 말로 덧붙인다.

  2. 읽기 잡음이 3 e⁻인 새 검출기로 바꾸면 16장으로 나눠 찍을 때의 손해는 어떻게 되는가?
    답

    \(nR^2\) 항이 \((3/8)^2 = 0.14\)배로 줄어 손해가 거의 없어진다(그림 1). 저잡음 검출기일수록 짧게 여러 장 찍기가 유리하다.
