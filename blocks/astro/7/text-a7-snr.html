신호 대 잡음비로 측광 오차 추정하기

본문 · 4.3절

15.32 ± 0.01등급과 15.32 ± 0.2등급은 전혀 다른 정보이다. 그런데 측광 오차는 관측을 마친 뒤에야 알 수 있을까? 관측 시간을 신청할 때 "이 별을 0.03등급 오차로 재려면 몇 초가 필요한가"를 미리 계산할 수는 없을까? 노출을 4배로 늘리면 오차는 4분의 1이 될까?

먼저 알아야 할 것CCD 특성(3.1절), 구경 측광(4.1절), 포아송 잡음 \(\sqrt N\)을 쓴다.

4.3.1잡음원

처음 질문의 답은 "미리 계산할 수 있다"이다. 측광 오차의 대부분은 빛과 검출기의 잡음에서 오기 때문이다. 잡음원은 네 가지이다. 별빛 전자 \(N_*\)개의 광자 잡음 \(\sqrt{N_*}\), 구경 화소 \(n_{\text{pix}}\)개에서 화소당 \(N_S\)개인 하늘 배경의 잡음 \(\sqrt{n_{\text{pix}}N_S}\), 화소당 \(N_D\)개인 암전류의 잡음 \(\sqrt{n_{\text{pix}}N_D}\), 화소당 \(R\)인 읽기 잡음 \(\sqrt{n_{\text{pix}}}\,R\)이다. 이들은 서로 독립이므로 제곱해서 더한다.

결과 4.3.1 (CCD 방정식) \[\frac SN = \frac{N_*}{\sqrt{N_* + n_{\text{pix}}(N_S + N_D + R^2)}}\]

\(N_*\), \(N_S\), \(N_D\)는 노출 시간에 비례하고 \(R^2\)은 그렇지 않다. 그래서 노출이 길면 \(S/N \propto \sqrt t\), 아주 짧으면 \(S/N \propto t\)이다(그림 1).

4.3.2등급 오차

등급 \(m = -2.5\log_{10}F + \text{상수}\)를 미분하면 \(dm = -\frac{2.5}{\ln10}\frac{dF}{F}\)이므로 다음을 얻는다.

\[\sigma_m = \frac{2.5}{\ln 10}\frac{\sigma_F}{F} = \frac{1.0857}{S/N}\]

예를 들어 S/N 100이면 0.011등급, S/N 10이면 0.11등급이다. 관측에서 검출 한계는 흔히 S/N 5(0.22등급)로 정한다.

예제 4.3.1

노출 300초에 별빛 6,000 e⁻, 구경 화소 30개, 하늘 화소당 400 e⁻, 암전류 무시, 읽기 잡음 8 e⁻이다. S/N과 등급 오차는 얼마인가? 노출을 4배로 하면?

풀이. 분모는 \(\sqrt{6000 + 30\times(400 + 64)} = \sqrt{19{,}920} = 141\)이므로 \(S/N = 42.5\), \(\sigma_m = 0.026\)등급이다. 4배 노출이면 분모가 \(\sqrt{24{,}000 + 30\times(1600 + 64)} = 272\)이므로 \(S/N = 88.3\)이다. 즉 4배가 아니라 2.08배로, 하늘이 지배해 거의 \(\sqrt4\)배가 되었다. 따라서 처음 질문의 마지막 답은 "오차는 절반쯤 된다"이다.

주의이 식은 무작위 잡음만 센다. 평탄화 보정의 오차, 하늘 값 추정의 오차, 표준 등급 변환의 오차 같은 계통 오차는 따로 더해야 하며, 밝은 별에서는 이것이 0.005~0.01등급의 바닥을 만든다.
마무리

측광 오차는 별빛, 하늘, 암전류의 포아송 잡음과 읽기 잡음을 제곱해 더한 CCD 방정식 \(S/N = N_*/\sqrt{N_* + n_{\text{pix}}(N_S + N_D + R^2)}\)로 관측 전에 계산할 수 있다. 긴 노출에서는 \(S/N \propto \sqrt t\), 읽기 잡음이 지배하면 \(S/N \propto t\)이고, 등급 오차는 \(\sigma_m = 1.0857/(S/N)\)이며 검출 한계는 흔히 S/N 5로 잡는다. 계통 오차는 따로 더한다.

4.3.3연습문제

기본

  1. S/N 50인 측광의 등급 오차는 얼마인가? 하늘 잡음 지배에서 S/N을 2배로 하려면 노출 시간은?
    답

    등급 오차는 0.022등급이고, 노출 시간은 4배가 필요하다.

응용

  1. 구경을 2배로 키우면(빛 4배) 하늘 지배에서 같은 노출의 S/N은 어떻게 되는가?
    답

    별빛 4배, 하늘 4배이므로 잡음은 2배가 되어 S/N은 2배이다.

  2. 읽기 잡음 지배(\(R = 10\), \(n_{\text{pix}} = 40\))에서 별빛 100 e⁻의 S/N은 얼마인가?
    답

    \(100/\sqrt{100 + 4000} = 1.6\)이다.
