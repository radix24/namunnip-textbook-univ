평탄 영상 두 장으로 CCD의 이득과 읽기 잡음 재기

본문 · 3.3절

측광 오차는 전자 수 \(N_e\)의 제곱근으로 계산해야 맞으므로, ADU를 전자 수로 바꾸는 이득을 모르면 S/N을 계산할 수 없다. 제조사 값은 설정과 노화로 달라진다. 전자 하나하나를 셀 수도 없는데, 관측소에서 이득을 직접 잴 방법이 있을까?

먼저 알아야 할 것CCD의 특성(3.1절), 바이어스와 평탄화(3.2절), 신호 대 잡음비(4.3절)를 쓴다.

3.3.1이득, 숫자와 전자 사이

CCD 화소에 모인 전자는 증폭기와 아날로그-디지털 변환기를 거쳐 정수(ADU)로 기록된다. 이득 \(g\)는 1 ADU에 해당하는 전자 수(e⁻/ADU)이다.

3.3.2광자 전달법의 원리

처음 질문의 답은 잡음 자체를 자로 쓰는 것이다. 평탄 영상의 화소에 평균 \(N\)개의 전자가 모이면 광자 잡음의 분산은 \(N\)이다(포아송 분포). 그런데 ADU로 재면 평균은 \(S = N/g\), 분산은 \(N/g^2\)이므로 다음이 성립한다.

\[\frac{S}{\sigma_S^2} = \frac{N/g}{N/g^2} = g\]

즉 평균과 분산만 재면 이득이 나온다. 다만 화소마다 감도가 조금씩 달라(평탄화 무늬) 한 장의 분산에는 그 차이가 섞인다. 그래서 같은 조건의 평탄 영상 두 장을 빼면 무늬는 지워지고 잡음만 남으며(분산은 두 배), 읽기 잡음은 바이어스 두 장의 차로 따로 빼 준다.

결과 3.3.1 (Janesick 방법) \[g = \frac{(\bar F_1 + \bar F_2) - (\bar B_1 + \bar B_2)}{\sigma^2_{F_1 - F_2} - \sigma^2_{B_1 - B_2}}, \qquad \text{RN} = \frac{g\,\sigma_{B_1 - B_2}}{\sqrt2}\]

\(\bar F\), \(\bar B\)는 평탄 영상과 바이어스 영상의 평균(ADU)이고, \(\sigma_{F_1-F_2}\)는 두 평탄 영상 차의 표준편차이다. 읽기 잡음 RN은 전자 단위이다.

3.3.3모의 실험으로 확인

이득 1.5 e⁻/ADU, 읽기 잡음 6 e⁻, 평탄 영상 2만 전자인 검출기를 흉내 내고 결과 3.3.1로 거꾸로 구해 보자.

import random, statistics as st
random.seed(2)
GAIN, RN, BIAS, LEVEL, N = 1.5, 6.0, 500.0, 20000.0, 20000   # e-/ADU, e-, ADU, e-, 화소 수

def bias_frame():
    return [BIAS + random.gauss(0, RN) / GAIN for _ in range(N)]

def flat_frame():
    # 광자 잡음(포아송 ≈ 정규, 분산 = 평균 전자 수) + 읽기 잡음, ADU로
    return [BIAS + (LEVEL + random.gauss(0, LEVEL**0.5) + random.gauss(0, RN)) / GAIN for _ in range(N)]

B1, B2, F1, F2 = bias_frame(), bias_frame(), flat_frame(), flat_frame()
dB = [a - b for a, b in zip(B1, B2)]
dF = [a - b for a, b in zip(F1, F2)]
signal = (st.fmean(F1) + st.fmean(F2)) - (st.fmean(B1) + st.fmean(B2))
gain = signal / (st.variance(dF) - st.variance(dB))
rn = gain * st.stdev(dB) / 2**0.5
print(f"평탄 영상 평균 - 바이어스 = {signal / 2:.1f} ADU")
print(f"추정 이득 = {gain:.3f} e-/ADU (참값 {GAIN})")
print(f"추정 읽기 잡음 = {rn:.2f} e- (참값 {RN})")
평탄 영상 평균 - 바이어스 = 13333.5 ADU
추정 이득 = 1.488 e-/ADU (참값 1.5)
추정 읽기 잡음 = 5.90 e- (참값 6.0)

화소 2만 개로 1% 안팎의 정밀도로 참값을 되찾았다. 실제로는 평탄 영상의 밝기를 여러 단계로 바꿔 평균 대 분산 그래프, 곧 광자 전달 곡선을 그린다(그림 1). 그러면 기울기로 이득을, 직선에서 벗어나 꺾이는 곳으로 포화(선형 한계)를 함께 찾는다.

3.3.4주의할 점

몇 가지를 조심해야 한다. 평탄 영상이 포화 근처면 분산이 줄어 이득이 크게 나오므로 포화의 절반 이하에서 잰다. 또 별이나 우주선이 찍힌 화소와 가장자리는 빼고 고른 영역을 쓴다. 그리고 두 평탄 영상의 밝기가 다르면(광원이 흔들림) 차의 분산에 무늬가 남으므로, 밝기를 맞추거나 비율로 맞춘 뒤 뺀다.

예제 3.3.1

이득 2.0 e⁻/ADU인 CCD에서 별의 신호가 5,000 ADU였다. 광자 잡음만 생각하면 S/N은 얼마인가? 이득을 1로 잘못 알았다면?

풀이. 전자 수는 10,000이므로 \(S/N = \sqrt{10000} = 100\)이다. 그런데 이득을 1로 알면 \(\sqrt{5000} = 71\)로 S/N을 30% 작게 어림한다. ADU의 제곱근은 아무 뜻이 없다.

흔한 실수평탄 영상 한 장의 분산으로 이득을 구하면, 화소마다 다른 감도(평탄화 무늬)가 분산에 더해져 이득이 실제보다 작게 나온다. 반드시 같은 조건의 두 장을 빼서 독립인 잡음만 남긴다.
마무리

이득 \(g\)(e⁻/ADU)를 알아야 측광 오차를 전자 수로 계산할 수 있다. 광자 잡음의 분산이 평균과 같다는 성질에서 ADU 단위로 \(g = S/\sigma^2_S\)이고, 평탄 두 장의 차와 바이어스 두 장의 차로 감도 무늬와 읽기 잡음을 지워 이득과 읽기 잡음을 구한다(결과 3.3.1). 포화의 절반 이하에서 고른 영역으로 재며, 밝기를 바꿔 광자 전달 곡선을 그리면 선형 한계도 찾는다.

3.3.5연습문제

기본

  1. 16비트 변환기(최대 65,535 ADU)와 이득 1.2 e⁻/ADU이면 기록할 수 있는 최대 전자 수는 얼마인가?
    답

    약 78,600 e⁻이다. 실제 화소의 우물 용량이 이보다 작으면 그쪽이 먼저 포화된다.

  2. 바이어스 두 장 차의 표준편차가 8.0 ADU, 이득이 1.5이면 읽기 잡음은 얼마인가?
    답

    \(1.5\times8.0/\sqrt2 = 8.5\) e⁻이다.
