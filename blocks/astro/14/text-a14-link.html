우주망원경의 자료를 땅으로: 통신 링크 예산

본문 · 5.3절
이 절에서 배울 것
  • 안테나 이득 \(G = \eta(\pi D/\lambda)^2\)과 자유 공간 손실 \((\lambda/4\pi d)^2\)을 계산한다.
  • 받는 전력 \(P_r = P_tG_tG_r(\lambda/4\pi d)^2\)과 잡음 \(kT_{\text{sys}}\)로 가능한 자료 전송률을 구한다.
  • 데시벨로 링크 예산을 더하고 뺀다.
  • 거리, 주파수, 안테나 크기가 전송률을 바꾸는 방식을 비교한다.
먼저 알아야 할 것
  • 우주 환경과 궤도 (5.1절), 시스템 온도 (4.3절).

5.3.1안테나 이득과 거리

전력 \(P_t\)를 사방으로 고르게 보내면 거리 \(d\)에서 단위 넓이당 \(P_t/4\pi d^2\)입니다. 지름 \(D\)인 접시는 빛을 \(\lambda/D\) 정도의 좁은 빔으로 모아 그만큼 세게 보내고(이득 \(G_t\)), 받는 쪽 접시는 유효 넓이 \(A_e = G_r\lambda^2/4\pi\)만큼 모읍니다.

결과 5.3.1 (프리스 전송 공식) \[P_r = P_tG_tG_r\left(\frac{\lambda}{4\pi d}\right)^2, \qquad G = \eta\left(\frac{\pi D}{\lambda}\right)^2.\]

5.3.2받은 전력에서 전송률로

받는 쪽의 잡음은 단위 대역폭당 \(N_0 = kT_{\text{sys}}\)(4.3절)입니다. 비트 하나에 실린 에너지 \(E_b = P_r/R\)(\(R\): 초당 비트 수)가 잡음에 비해 일정 배수 이상이어야 오류 없이 풀 수 있습니다.

\[R = \frac{P_r}{N_0\,(E_b/N_0)_{\text{필요}}}.\]

오류 정정 부호를 쓰면 필요한 \(E_b/N_0\)가 몇 배로 낮아지고, 실제 설계에서는 대기, 지향 오차, 회로 손실과 여유(margin)를 더해 수 배~열 배를 잡습니다.

5.3.3데시벨 예산

곱셈을 덧셈으로 하려고 모든 항을 데시벨(\(10\log\))로 바꿔 더합니다. 예를 들어 X 밴드(8.4 GHz, \(\lambda = 3.57\) cm), 지구–L2 거리 150만 km라면

항목값dB
송신 전력10 W+10.0 dBW
위성 안테나(0.5 m, η = 0.6)1,160+30.7
지상 안테나(34 m)\(5.4\times10^6\)+67.3
자유 공간 손실\(3.6\times10^{-24}\)−234.4
받는 전력\(2.2\times10^{-13}\) W−126.5 dBW

\(T_{\text{sys}} = 30\) K이면 \(N_0 = 4.1\times10^{-22}\) W/Hz, \(P_r/N_0 = 5.4\times10^8\) Hz이고, 필요한 \(E_b/N_0\)를 10(10 dB, 여유 포함)으로 잡으면 \(R \approx 54\) Mbps입니다.

5.3.4무엇이 전송률을 정하나

  • 거리: \(R \propto d^{-2}\). 화성(약 2억 km)은 L2보다 150배 멀어 같은 장비로 22,500배 느리다.
  • 주파수: 두 안테나 크기가 정해지면 \(G_tG_r \propto \lambda^{-4}\), 손실 \(\propto \lambda^2\)이라 \(R \propto \lambda^{-2}\). X(8.4 GHz)에서 Ka(32 GHz)로 바꾸면 약 14배 빨라진다. 대신 빔이 좁아 지향이 더 정밀해야 하고 비에 약하다.
  • 안테나와 전력: \(R \propto P_tD_t^2D_r^2\). 위성 쪽은 무게와 전력 제약이 커서 지상 쪽 안테나를 키우거나 여러 개를 묶는다.
요약
  1. \(P_r = P_tG_tG_r(\lambda/4\pi d)^2\), \(G = \eta(\pi D/\lambda)^2\).
  2. \(R = P_r/[kT_{\text{sys}}(E_b/N_0)]\). 예산은 데시벨로 더한다.
  3. \(R \propto P_tD_t^2D_r^2/(\lambda^2d^2)\).

5.3.5연습문제

기본

  1. 송신 전력을 10 W에서 40 W로 올리면 dB로 얼마, 전송률은 몇 배입니까?
    답

    +6 dB, 4배.

  2. 같은 장비로 달(38만 km)에서 보내면 L2(150만 km)보다 몇 배 빠릅니까?
    답

    \((150/38)^2 = 15.6\)배.

응용

  1. 하루 중 지상국과 연결되는 시간이 4시간뿐인 우주망원경이 하루 1 Tbit(약 125 GB)의 자료를 만든다면 필요한 전송률은?
    답

    \(10^{12}/14400 = 6.9\times10^7\) bps ≈ 69 Mbps. 본문의 X 밴드(54 Mbps)로는 모자라 Ka 밴드나 더 긴 연결 시간이 필요합니다.

  2. 지구 저궤도 위성은 거리가 1,000 km 남짓으로 가까운데도 전송률이 지상국 연결 시간에 크게 제약됩니다. 왜일까요?
    답

    한 지상국 위를 지나는 시간이 한 번에 약 10분이라 하루 연결 시간이 짧습니다. 그래서 여러 지상국을 쓰거나 정지 궤도 중계 위성을 거쳐 보냅니다.
