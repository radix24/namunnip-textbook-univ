흔들림의 크기에서 그날 밤의 시상 구하기

예제 · DIMM · 비례 관계
문제 해결 전략 · 기준값에 비례로 잇기
  1. 같은 기기에서는 \(\varepsilon \propto \sigma^{6/5}\)이다.
  2. 기준(\(r_0 = 10\) cm에서 \(\sigma_l = 0.54\)″, \(\varepsilon = 1.01\)″)에 비례로 잇는다.
  3. 천정 거리와 세로·가로 두 방향의 일치로 검산한다.
먼저 예상해 보기. 흔들림이 기준보다 25% 작으면 시상은 25%보다 더 좋아질까요, 덜 좋아질까요?

문제. 예제 3.3.1과 같은 DIMM(\(D = 6\) cm, \(d = 20\) cm)으로 천정 거리 30°의 별을 재었더니 세로 차이 운동의 표준편차가 0.40″였습니다. (가) 그 방향의 \(r_0\)와 시상은? (나) 천정의 시상은? (다) 가로 방향 표준편차는 얼마로 나와야 합니까?

풀이

  1. (가) \(\varepsilon = 1.01\times(0.40/0.54)^{1.2} = 1.01\times0.70 = 0.71\)″. \(r_0 = 0.98\times0.5\times10^{-6}/(0.71/206265) = 0.142\) m.
    \(\varepsilon \propto \sigma^{6/5}\).
  2. (나) \(\varepsilon_{\text{천정}} = 0.71\times(\cos30°)^{3/5} = 0.71\times0.917 = 0.65\)″.
    \(\varepsilon \propto (\sec z)^{3/5}\).
  3. (다) 가로 괄호 \(0.457 - 0.145\times0.20^{-1/3} = 0.457 - 0.248 = 0.209\). 세로와의 비 \(\sqrt{0.209/0.292} = 0.85\)이므로 \(0.40\times0.85 = 0.34\)″.
    같은 \(r_0\)에서 괄호의 비만 다름.

의미

흔들림이 26% 작아지자 시상은 30% 좋아졌습니다(지수 1.2). 세로와 가로 방향에서 따로 구한 \(r_0\)가 서로 맞으면 측정이 믿을 만하고, 다르면 망원경 진동이 한 방향에만 남았거나 노출 시간이 너무 길다는 신호입니다.

검산

결과 3.3.1에 \(r_0 = 0.142\) m를 넣으면 \(\sigma_l = 0.54\times(0.142/0.10)^{-5/6} = 0.54\times0.746 = 0.40\)″로 처음 값이 돌아옵니다.

이해 확인

세로 표준편차가 0.30″이면 시상은?

답

\(1.01\times(0.30/0.54)^{1.2} = 0.50\)″. 매우 좋은 밤입니다.
