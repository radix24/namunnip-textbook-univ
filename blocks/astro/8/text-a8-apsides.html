궤도 상수로 근지점과 원지점 구하기

본문
이 절에서 배울 것
  • 비각운동량 \(h\)와 비에너지 \(\varepsilon\), 이심률 \(e\), 긴반지름 \(a\) 사이의 관계를 정리한다.
  • 근지점·원지점 거리와 속력을 궤도 상수로 구한다.
  • 정지궤도 전이 궤도(GTO)의 수치를 계산하고 필요한 속도 변화를 어림한다.
먼저 알아야 할 것
  • 원뿔곡선 궤도 (1.2절), 궤도 에너지 (1.3절).

1.4.1두 보존량이 궤도를 정한다

2체 궤도에서 비각운동량 \(h = |\mathbf r\times\mathbf v|\)와 비에너지 \(\varepsilon = v^2/2 - \mu/r\)(\(\mu = GM\))는 궤도 내내 일정합니다. 궤도 방정식 \(r = p/(1 + e\cos\theta)\)의 반직현 \(p = h^2/\mu\)이고, 두 보존량에서 궤도의 모양과 크기가 모두 나옵니다.

결과 1.4.1 \[a = -\frac{\mu}{2\varepsilon}, \qquad e = \sqrt{1 + \frac{2\varepsilon h^2}{\mu^2}}, \qquad p = \frac{h^2}{\mu} = a(1 - e^2).\]

1.4.2근지점과 원지점

근지점(\(\theta = 0\))과 원지점(\(\theta = 180°\))에서는 속도가 반지름에 수직이라 \(h = rv\)입니다.

결과 1.4.2 \[r_p = \frac{p}{1 + e} = a(1 - e),\qquad r_a = \frac{p}{1 - e} = a(1 + e),\] \[v_p = \frac{h}{r_p},\qquad v_a = \frac{h}{r_a}.\]

거꾸로 두 거리를 알면 \(a = (r_p + r_a)/2\), \(e = (r_a - r_p)/(r_a + r_p)\)입니다.

\(v_p/v_a = r_a/r_p\)이므로 이심률이 큰 궤도일수록 근지점과 원지점의 속력 차가 큽니다(케플러 제2법칙과 같은 내용).

1.4.3정지궤도 전이 궤도

정지궤도 위성은 보통 근지점 고도 약 250 km, 원지점 고도 35,786 km(정지궤도 높이)인 타원 궤도에 먼저 올라간 뒤, 원지점에서 엔진을 켜 원 궤도로 바꿉니다. 지구 반지름 6,378 km, \(\mu = 398{,}600\) km³/s²로 계산하면

  • \(r_p = 6{,}628\) km, \(r_a = 42{,}164\) km, \(a = 24{,}396\) km, \(e = 0.7283\).
  • \(h = \sqrt{\mu a(1 - e^2)} = 67{,}573\) km²/s, \(v_p = 10.195\) km/s, \(v_a = 1.603\) km/s.
  • 주기 \(2\pi\sqrt{a^3/\mu} = 10.53\)시간.

정지궤도 원 속력은 \(\sqrt{\mu/r_a} = 3.075\) km/s이므로 원지점에서 1.47 km/s를 더해야 합니다(실제로는 경사각 변경도 함께 해서 더 큽니다). 저궤도 원 속력 7.755 km/s에서 전이 궤도로 들어가는 데는 2.44 km/s가 필요합니다. 이것이 호만 전이(천우11)의 구체적인 예입니다.

예제 1.4.1

근지점 고도 500 km, 원지점 고도 1,500 km인 궤도의 이심률, 근지점과 원지점 속력은?

풀이. \(r_p = 6{,}878\), \(r_a = 7{,}878\) km, \(a = 7{,}378\) km, \(e = 1000/14756 = 0.0678\). \(h = \sqrt{398600\times7378\times(1 - 0.0046)} = 54{,}106\) km²/s, \(v_p = 7.87\), \(v_a = 6.87\) km/s.

요약
  1. \(a = -\mu/(2\varepsilon)\), \(e = \sqrt{1 + 2\varepsilon h^2/\mu^2}\), \(p = h^2/\mu\).
  2. \(r_p = a(1-e)\), \(r_a = a(1+e)\), \(v_{p,a} = h/r_{p,a}\).
  3. GTO: \(e = 0.73\), \(v_p = 10.2\), \(v_a = 1.6\) km/s, 원지점에서 1.5 km/s 더해 정지궤도.

1.4.4연습문제

기본

  1. \(r_a/r_p = 3\)인 궤도의 이심률과 \(v_p/v_a\)는?
    답

    \(e = (3-1)/(3+1) = 0.5\), \(v_p/v_a = 3\).

  2. 비에너지가 0이면 궤도는? 이때 \(a\)는?
    답

    포물선, \(a\)는 무한대(정의되지 않음).

응용

  1. GTO의 근지점에서 엔진을 켜 속력을 0.1 km/s 높이면 원지점 고도는 대략 얼마나 올라갑니까? (\(\varepsilon\)의 변화로)
    답

    \(\Delta\varepsilon = v_p\Delta v = 1.02\) km²/s², 새 \(a = -\mu/(2(-8.169 + 1.02)) = 27{,}875\) km, 원지점 거리 \(2a - r_p = 49{,}120\) km(지금 42,164 km). 약 7,000 km 올라갑니다. 근지점에서의 작은 가속이 원지점을 크게 올립니다.

  2. 위치 7,000 km에서 속력 8.0 km/s, 비행 경로각 5°인 위성의 근지점·원지점 고도는? (예제 카드 참고)
    답

    약 405 km와 2,820 km.
