궤도 상수로 근지점과 원지점 구하기

본문 · 1.4절

정지궤도 위성은 처음부터 고도 35,786 km에 올라가지 않는다. 먼저 근지점 고도 약 250 km, 원지점이 정지궤도 높이인 길쭉한 타원(정지궤도 전이 궤도)에 오른 뒤, 원지점에서 엔진을 켜 원 궤도로 바꾼다. 이 타원의 근지점과 원지점에서 위성은 얼마나 빠를까? 원지점에서는 속력을 얼마나 더해야 할까?

먼저 알아야 할 것원뿔곡선 궤도(1.2절)와 궤도 에너지(1.3절)를 쓴다.

1.4.1두 보존량이 궤도를 정한다

2체 궤도에서 비각운동량 \(h = |\vec r\times\vec v|\)와 비에너지 \(\varepsilon = v^2/2 - \mu/r\)는 궤도 내내 일정하다. 궤도 방정식 \(r = p/(1 + e\cos\nu)\)의 반직현은 \(p = h^2/\mu\)이고, 두 보존량에서 궤도의 크기와 모양이 모두 나온다.

결과 1.4.1 (궤도 상수의 관계) \[a = -\frac{\mu}{2\varepsilon}, \qquad e = \sqrt{1 + \frac{2\varepsilon h^2}{\mu^2}}, \qquad p = \frac{h^2}{\mu} = a(1 - e^2)\]

즉 크기 \(a\)는 에너지 하나로 정해지고, 모양 \(e\)는 에너지와 각운동량을 함께 써야 정해진다.

1.4.2근지점과 원지점

근지점(\(\nu = 0\))과 원지점(\(\nu = 180°\))에서는 속도가 반지름에 수직이라 \(h = rv\)이다. 따라서 두 지점의 거리와 속력은 다음과 같다.

결과 1.4.2 (근지점과 원지점) \[r_p = \frac{p}{1 + e} = a(1 - e),\qquad r_a = \frac{p}{1 - e} = a(1 + e),\qquad v_p = \frac{h}{r_p},\qquad v_a = \frac{h}{r_a}\]

거꾸로 두 거리를 알면 \(a = (r_p + r_a)/2\), \(e = (r_a - r_p)/(r_a + r_p)\)이다. 또 \(v_p/v_a = r_a/r_p\)이므로 이심률이 큰 궤도일수록 근지점과 원지점의 속력 차가 크며, 이는 케플러 제2법칙과 같은 내용이다.

예제 1.4.1

처음 질문의 정지궤도 전이 궤도(근지점 고도 250 km, 원지점 고도 35,786 km)에서 궤도 상수와 근지점, 원지점 속력, 원지점에서 더할 속력을 구하여라(지구 반지름 6,378 km).

풀이. \(r_p = 6{,}628\) km, \(r_a = 42{,}164\) km이므로 \(a = 24{,}396\) km, \(e = 0.7283\)이다. 각운동량은 \(h = \sqrt{\mu a(1 - e^2)} = 67{,}573\) km²/s이므로 \(v_p = 10.195\) km/s, \(v_a = 1.603\) km/s이고, 주기는 \(2\pi\sqrt{a^3/\mu} = 10.53\)시간이다. 정지궤도 원 속력은 \(\sqrt{\mu/r_a} = 3.075\) km/s이므로 원지점에서 1.47 km/s를 더해야 한다(실제로는 경사각 변경을 함께 해서 더 크다). 한편 저궤도 원 속력 7.755 km/s에서 전이 궤도로 들어가는 데는 2.44 km/s가 필요하다. 이 두 번의 가속이 호만 전이(천우11)의 구체적인 예이다.

예제 1.4.2

근지점 고도 500 km, 원지점 고도 1,500 km인 궤도의 이심률과 근지점, 원지점 속력은 얼마인가?

풀이. \(r_p = 6{,}878\) km, \(r_a = 7{,}878\) km이므로 \(a = 7{,}378\) km, \(e = 1000/14756 = 0.0678\)이다. \(h = \sqrt{398600\times7378\times(1 - 0.0046)} = 54{,}106\) km²/s이므로 \(v_p = 7.87\) km/s, \(v_a = 6.87\) km/s이다.

흔한 실수고도와 지구 중심에서의 거리를 섞기 쉽다. 궤도 공식의 \(r\)은 늘 지구 중심에서 잰 거리이므로, 고도에 지구 반지름 6,378 km를 먼저 더해야 한다.
마무리

비각운동량과 비에너지 두 보존량이 궤도를 정하며, \(a = -\mu/(2\varepsilon)\), \(e = \sqrt{1 + 2\varepsilon h^2/\mu^2}\), \(p = h^2/\mu\)이다. 근지점과 원지점의 거리는 \(a(1 \mp e)\)이고 속력은 \(h\)를 그 거리로 나눈 값이다. 정지궤도 전이 궤도는 이심률 0.73, 근지점 10.2 km/s, 원지점 1.6 km/s이며, 원지점에서 약 1.5 km/s를 더해 정지궤도에 들어간다.

1.4.3연습문제

기본

  1. \(r_a/r_p = 3\)인 궤도의 이심률과 \(v_p/v_a\)는 얼마인가?
    답

    \(e = (3-1)/(3+1) = 0.5\)이고 \(v_p/v_a = 3\)이다.

  2. 비에너지가 0이면 궤도는 무엇이고, 이때 \(a\)는 어떻게 되는가?
    답

    포물선이며 \(a\)는 무한대로, 정의되지 않는다.

응용

  1. 전이 궤도의 근지점에서 엔진을 켜 속력을 0.1 km/s 높이면 원지점 거리는 대략 얼마나 커지는가? \(\varepsilon\)의 변화로 계산하여라.
    답

    \(\Delta\varepsilon \approx v_p\Delta v = 1.02\) km²/s²이므로 새 \(a = -\mu/(2(-8.169 + 1.02)) = 27{,}875\) km이다. 원지점 거리는 \(2a - r_p = 49{,}120\) km로 지금(42,164 km)보다 약 7,000 km 커진다. 근지점에서의 작은 가속이 원지점을 크게 올린다.

  2. 지구 중심에서 7,000 km인 곳에서 속력 8.0 km/s, 비행 경로각 5°인 위성의 근지점과 원지점 고도는 얼마인가?
    답

    \(h = rv\cos5° = 55{,}787\) km²/s, \(\varepsilon = 32 - 56.94 = -24.94\) km²/s²이므로 \(a = 7{,}990\) km, \(e = 0.151\)이다. 근지점 거리 6,783 km와 원지점 거리 9,198 km에서 지구 반지름을 빼면 고도는 약 405 km와 2,820 km이다.
