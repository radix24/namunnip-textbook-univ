4.2.1Jacobi 적분

유도. 첫째 운동 방정식에 \(\dot x\), 둘째에 \(\dot y\)를 곱해 더하면 코리올리 항이 지워집니다(\(-2\dot y\dot x + 2\dot x\dot y = 0\)). \[ \dot x\ddot x + \dot y\ddot y = \frac{\partial\Omega}{\partial x}\dot x + \frac{\partial\Omega}{\partial y}\dot y \;\Longrightarrow\; \frac{d}{dt}\left[\frac12(\dot x^2 + \dot y^2)\right] = \frac{d\Omega}{dt} \] 이므로 \(v^2 - 2\Omega\)는 일정합니다. 관례대로 부호를 바꿔 \[ C = 2\Omega - v^2 \] 를 Jacobi 상수라 합니다. ∎

회전 좌표계의 "에너지"(운동 에너지 − 원심·중력 퍼텐셜)에 해당합니다. \(C\)가 클수록 회전 좌표계에서의 에너지가 작습니다.

4.2.2영속도 곡선

\(v^2 = 2\Omega - C \ge 0\)이어야 하므로 물체는 \(2\Omega(x, y) \ge C\)인 곳에만 있을 수 있습니다. 경계 \(2\Omega = C\)에서는 속도가 0이라 영속도 곡선이라 합니다. \(C\)가 크면 금지 구역이 넓어 물체가 큰 천체 둘레나 작은 천체 둘레에 갇히고, \(C\)가 줄어들면 금지 구역의 목이 차례로 열립니다.

  1. \(C > C_{L1}\): 두 천체 둘레가 따로 닫혀 있다. 지구 둘레 위성은 달로 갈 수 없다.
  2. \(C_{L2} < C < C_{L1}\): L1 목이 열려 지구와 달 사이를 오갈 수 있다.
  3. \(C_{L3} < C < C_{L2}\): L2 목도 열려 달 뒤쪽으로 계를 떠날 수 있다.
  4. \(C < C_{L4}\): 금지 구역이 사라진다.

지구-달 계에서 \(C_{L1} = 3.188\), \(C_{L2} = 3.172\), \(C_{L3} = 3.012\), \(C_{L4} = 2.988\)입니다. 천우3에서 본 탐구 카드(제한 3체 문제의 영속도 곡선)로 직접 확인할 수 있습니다.

예제 4.2.1

지구-달 회전 좌표계에서 지구 중심으로부터 거리 0.1(약 38,400 km, 지구 쪽), 정지 상태인 우주선의 Jacobi 상수를 어림하고, 달로 갈 수 있는지 판단하세요.

풀이. 지구는 \((-0.0122, 0)\)이므로 우주선을 \((0.0878, 0)\)에 둡니다. \(r_1 = 0.1\), \(r_2 = 1 - 0.0122 - 0.0878 = 0.9\). \(2\Omega = 0.0878^2 + 2\times0.9878/0.1 + 2\times0.0122/0.9 = 0.0077 + 19.756 + 0.0271 = 19.79\)이고 \(v = 0\)이므로 \(C = 19.79 \gg 3.188\)입니다. 금지 구역에 둘러싸여 달로 갈 수 없습니다. 달까지 가려면 속도를 크게 늘려 \(C\)를 3.19 아래로 낮춰야 합니다(회전 좌표계 속도 약 \(\sqrt{19.79 - 3.19} = 4.07\), 실제 약 4.2 km/s).

주의 금지 구역이 열렸다고 물체가 반드시 그 목을 지나가는 것은 아닙니다. 영속도 곡선은 필요조건만 줍니다. 실제 경로는 수치 적분으로 확인해야 하며, 목 근처의 궤도는 매우 민감(혼돈적)합니다.
요약
  1. Jacobi 상수 \(C = 2\Omega - v^2\)는 회전 좌표계에서 보존된다(코리올리 항은 일을 하지 않음).
  2. 물체는 \(2\Omega \ge C\)인 곳에만 있을 수 있다. 경계가 영속도 곡선.
  3. \(C\)가 작아지면 L1 → L2 → L3 → L4·L5 순서로 목이 열린다.
  4. 지구-달: \(C_{L1} = 3.188\), \(C_{L2} = 3.172\), \(C_{L3} = 3.012\), \(C_{L4} = 2.988\).

4.2.3연습문제

기본

  1. \(C = 3.18\)인 지구-달 우주선은 지구를 떠나 계 밖으로 나갈 수 있습니까?
    답

    아니요. L1은 열렸지만(\(C < 3.188\)) L2는 닫혀 있어(\(C > 3.172\)) 지구-달 영역에 갇힙니다.

  2. Jacobi 상수가 회전 좌표계의 무엇에 해당합니까?
    답

    에너지(부호를 바꾸고 2배한 것).

응용

  1. L4에 정지한 물체의 Jacobi 상수는 \(C_{L4} = 3 - \mu + \mu^2\)입니다. 지구-달 값을 확인하세요.
    답

    \(3 - 0.0122 + 0.00015 = 2.988\).

  2. 목을 지나려면 회전 좌표계에서 에너지가 커야(C가 작아야) 합니다. 이것이 달 탐사선의 출발 속력에 주는 뜻은?
    답

    지구 둘레에서 회전 좌표계 속력을 키워 C를 3.188 아래로 낮춰야 하므로, 약 11 km/s에 가까운 출발 속력(저궤도에서 약 3.1 km/s의 Δv)이 필요합니다.
