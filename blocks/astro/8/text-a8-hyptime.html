쌍곡선 궤도의 시간 관계

본문
이 절에서 배울 것
  • 쌍곡선 궤도에서 이심 근점 이각 대신 쌍곡 근점 이각 \(F\)를 쓰는 까닭을 안다.
  • 쌍곡 Kepler 방정식 \(M_h = e\sinh F - F\)로 근지점에서 어떤 거리까지 가는 시간을 구한다.
  • 점근선 방향 \(\theta_\infty\)와, 행성을 떠나는 탐사선이 언제 영향권을 벗어나는지 계산한다.
먼저 알아야 할 것
  • 근점 이각과 Kepler 방정식 (2.1절, 2.2절), 궤도 에너지 (1.3절).

2.3.1쌍곡선의 매개변수

타원에서는 위치를 이심 근점 이각 \(E\)로 \(r = a(1 - e\cos E)\)라 쓰고, \(E\)가 시간에 대해 Kepler 방정식 \(M = E - e\sin E\)를 따랐습니다. 쌍곡선(\(e > 1\), \(\varepsilon > 0\))은 닫혀 있지 않으므로 삼각함수 대신 쌍곡선 함수를 씁니다. \(a < 0\)이 되도록 정의하면(\(a = -\mu/v_\infty^2\))

결과 2.3.1 (쌍곡 Kepler 방정식) \[r = |a|(e\cosh F - 1), \qquad \tan\frac\theta2 = \sqrt{\frac{e+1}{e-1}}\tanh\frac F2,\] \[M_h = e\sinh F - F = \sqrt{\frac{\mu}{|a|^3}}\,(t - t_p).\]

\(t_p\)는 근지점 통과 시각입니다. 진근점 이각은 점근선 방향 \(\theta_\infty = \arccos(-1/e)\)보다 커질 수 없습니다. 위치에서 시각을 구할 때는 \(F\)를 바로 구해 \(M_h\)에 넣고, 시각에서 위치를 구할 때는 Newton 방법으로 방정식을 풉니다(2.2절과 같은 방법).

2.3.2예: 지구를 떠나는 탐사선

근지점 7,000 km에서 출발해 지구에 대한 쌍곡선 초과 속력 \(v_\infty = 5\) km/s로 떠나는 탐사선입니다. \(|a| = \mu/v_\infty^2 = 15{,}944\) km, \(e = 1 + r_pv_\infty^2/\mu = 1.439\), \(\theta_\infty = 134.0°\).

예제 2.3.1

위 탐사선이 근지점에서 정지궤도 거리까지 가는 시간을 결과 2.3.1로 직접 확인하세요.

풀이. \(\cosh F = (42164/15944 + 1)/1.439 = 2.533\), \(F = 1.581\). \(M_h = 1.439\sinh1.581 - 1.581 = 1.439\times2.327 - 1.581 = 1.767\). \(n = \sqrt{398600/15944^3} = 3.136\times10^{-4}\) s⁻¹, \(t = 1.767/n = 5{,}636\) s ≈ 1.57시간.

요약
  1. 쌍곡선: \(a = -\mu/v_\infty^2\), \(r = |a|(e\cosh F - 1)\).
  2. \(M_h = e\sinh F - F = \sqrt{\mu/|a|^3}(t - t_p)\).
  3. 진근점 이각은 \(\theta_\infty = \arccos(-1/e)\)를 넘지 못한다. 멀어질수록 속력은 \(v_\infty\)로.

2.3.3연습문제

기본

  1. \(e = 2\)인 쌍곡선의 점근선 방향 \(\theta_\infty\)는?
    답

    \(\arccos(-0.5) = 120°\).

  2. \(F = 0\)이면 탐사선은 어디에 있습니까?
    답

    근지점(\(r = |a|(e - 1) = r_p\), \(\theta = 0\)).

응용

  1. \(v_\infty\)를 두 배로 하면 \(|a|\)와 근지점에서 달 거리까지의 시간은 대략 어떻게 됩니까?
    답

    \(|a|\)는 1/4. 먼 거리에서는 거의 \(v_\infty\)로 직진하므로 시간은 대략 절반쯤으로 줄어듭니다(계산하면 19.1시간 → 10.3시간).

  2. 먼 거리에서 시간이 거의 \((r - r_0)/v_\infty\)로 늘어남을 표에서 확인하세요(달 거리와 영향권 사이).
    답

    거리 차 539,600 km ÷ 5 km/s = 107,920 s = 30.0시간. 표의 차 48.3 − 19.1 = 29.2시간과 비슷합니다(속력이 5.2에서 5.1 km/s로 조금 더 빨라서 약간 짧음).
