TLE 숫자 두 개로 태양동기궤도인지 판정하기

예제 · 평균 운동 · J2 승교점 이동
문제 해결 전략 · TLE에서 궤도 성격 읽기
  1. 평균 운동으로 \(a\), 고도, 주기를 구한다.
  2. 경사각과 \(a\)로 J2에 의한 승교점 이동률 \(\dot\Omega = -\tfrac32J_2(R/a)^2n\cos i\)(\(e \approx 0\))를 구한다.
  3. 태양의 겉보기 이동률 \(360°/365.24\text{일} = 0.9856°\)/일과 비교한다.
먼저 예상해 보기. 경사각이 90°보다 조금 큰(역행) 궤도는 승교점이 동쪽으로 움직일까, 서쪽으로 움직일까?

문제. 어떤 지구 관측 위성의 TLE 2행에 경사각 98.2000°, 이심률 0001200, 평균 운동 14.57000000이 있다. 1행의 기준 시각은 26287.25000000이다. 기준 시각, 고도, 주기를 읽고, 태양동기궤도인지 판정하세요(\(J_2 = 1.0826\times10^{-3}\), \(R = 6378\) km).

풀이

  1. 기준 시각: 2026년의 287번째 날 = 10월 14일, 0.25일 = 6시 UT.
    1~9월이 273일이므로 287 − 273 = 14일.
  2. \(n = 14.57\times2\pi/86400 = 1.0596\times10^{-3}\) rad/s, \(a = (398600/n^2)^{1/3} = 7{,}081\) km, 고도 703 km, 주기 \(1440/14.57 = 98.8\)분.
    결과 3.4.1.
  3. \(\dot\Omega = -1.5\times1.0826\times10^{-3}\times(6378/7081)^2\times1.0596\times10^{-3}\times\cos98.2°\) = \(+1.141\times10^{-7}\) rad/s = +0.986°/일.
    \(\cos98.2° < 0\)이라 부호가 양: 동쪽으로 이동.
  4. 태양의 0.9856°/일과 같으므로 태양동기궤도다.
    궤도면이 태양을 따라 돌아 매일 같은 지방시에 같은 곳 위를 지난다.

의미

숫자 두 개(경사각, 평균 운동)만으로 위성의 임무 성격(태양동기 지구 관측)을 알아냈다. 고도 약 700 km에서는 경사각 98.2°가 정확히 태양동기 조건을 만족합니다(천우8 5.2절). TLE 목록에서 이런 위성을 골라 내는 것도 같은 계산이다.

검산

원 궤도 속력 \(\sqrt{398600/7081} = 7.50\) km/s로 주기를 다시 구하면 \(2\pi\times7081/7.50 = 5{,}930\) s = 98.8분으로 \(1440/n\)과 같다.

이해 확인

같은 고도에서 경사각이 51.6°라면 승교점은 하루에 몇 도, 어느 쪽으로 움직이는가?

답

\(\cos51.6° = 0.621\)이고 \(\cos98.2° = -0.1426\)이므로 \(-0.986\times0.621/0.1426 \approx -4.3°\)/일, 서쪽으로 움직입니다(태양동기가 아님).
