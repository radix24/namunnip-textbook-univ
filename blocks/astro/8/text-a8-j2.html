지구 편평도(J2)가 승교점과 근지점을 옮기는 효과

본문 · 5.2절
이 절에서 배울 것
  • J2에 의한 승교점 회귀와 근지점 이동의 식을 쓰고 계산한다.
  • 태양동기궤도의 경사각을 구한다.
  • 임계 경사각(63.4°)의 뜻을 안다.
먼저 알아야 할 것
  • 섭동의 크기 (5.1절), 궤도요소 (3.1절).

부푼 적도가 궤도면을 돌린다

지구의 적도 부풂은 위성을 적도면 쪽으로 당겨, 팽이에 돌림힘이 걸린 것처럼 궤도면이 지구 자전축 둘레로 천천히 돕니다(세차). 동시에 궤도면 안에서 근지점도 돕니다. 이 효과는 귀찮은 섭동이 아니라 위성 임무 설계의 도구입니다.

5.2.1영년 변화율

한 바퀴 평균한 변화율(영년 변화)은 다음과 같습니다(유도는 천우11 4.2절).

\[ \dot\Omega = -\frac32\,nJ_2\left(\frac{R_\oplus}{p}\right)^2\cos i, \qquad \dot\omega = \frac34\,nJ_2\left(\frac{R_\oplus}{p}\right)^2(5\cos^2i - 1) \]

(\(n\)은 평균 운동, \(p = a(1-e^2)\)). 읽는 법은 이렇습니다.

  • 순행 궤도(\(i < 90^\circ\))는 승교점이 서쪽으로(\(\dot\Omega < 0\)), 역행은 동쪽으로 돈다. 극궤도(90°)는 돌지 않는다.
  • 낮은 궤도일수록(\(n\) 크고 \(R/p\) 큼) 빠르다.
  • \(5\cos^2i = 1\), 곧 \(i = 63.4^\circ\) 또는 \(116.6^\circ\)에서 근지점이 돌지 않는다(임계 경사각).
예제 5.2.1

국제우주정거장(고도 400 km, \(i = 51.6^\circ\), 원 궤도)의 승교점 회귀율은 하루에 몇 도입니까?

풀이. \(n = \sqrt{398600/6778^3} = 1.1314\times10^{-3}\) rad/s, \((6378/6778)^2 = 0.8855\). \(\dot\Omega = -1.5\times1.1314\times10^{-3}\times1.0826\times10^{-3}\times0.8855\times\cos51.6^\circ = -1.012\times10^{-6}\) rad/s = −5.00°/일입니다. 약 72일에 한 바퀴 돌아 ISS가 지나는 시각과 햇빛 조건이 계절마다 바뀝니다.

5.2.2태양동기궤도

승교점이 하루에 정확히 \(360^\circ/365.24 = 0.9856^\circ\)씩 동쪽으로 돌면, 궤도면이 해를 따라가 위성이 늘 같은 지방시에 같은 위도를 지납니다. 지구 관측 위성은 그림자 방향이 같은 사진을 얻으려고 이 궤도를 씁니다. 동쪽으로 돌려면 \(\cos i < 0\), 곧 약간 역행인 경사각이 필요합니다.

예제 5.2.2

고도 700 km 원 궤도의 태양동기 경사각은?

풀이. \(a = 7078\) km, \(n = 1.0595\times10^{-3}\) rad/s, \((6378/7078)^2 = 0.8120\). 필요한 \(\dot\Omega = 1.991\times10^{-7}\) rad/s이므로 \(\cos i = -1.991\times10^{-7}/(1.5\times1.0595\times10^{-3}\times1.0826\times10^{-3}\times0.8120) = -0.1427\), \(i = 98.2^\circ\)입니다.

5.2.3몰니야 궤도

러시아의 통신 위성은 고위도 지역을 오래 보려고 원지점을 북반구 상공에 둔 길쭉한 궤도(\(e \approx 0.74\), 주기 12시간)를 씁니다. 근지점이 돌면 원지점이 남쪽으로 옮겨 가므로, 임계 경사각 63.4°를 써서 근지점 이동을 없앱니다.

주의 이 식은 J2만 넣은 1차 근사입니다. 수년 이상의 예측에는 고차 항(J3, J4…)과 달·해의 섭동을 함께 넣어야 합니다.
요약
  1. \(\dot\Omega = -\frac32nJ_2(R/p)^2\cos i\): 순행은 서쪽, 역행은 동쪽, 극궤도는 0.
  2. \(\dot\omega = \frac34nJ_2(R/p)^2(5\cos^2i - 1)\): 63.4°에서 0(임계 경사각).
  3. ISS(400 km, 51.6°): 약 −5.0°/일.
  4. 태양동기: \(\dot\Omega = +0.9856^\circ\)/일, 700 km에서 \(i = 98.2^\circ\).

5.2.4연습문제

기본

  1. 극궤도(\(i = 90^\circ\))의 승교점 회귀율은?
    답

    0.

  2. 임계 경사각의 두 값은?
    답

    63.4°와 116.6°.

응용

  1. ISS의 근지점 이동률을 구하세요(원 궤도라 실제 의미는 작지만 계산 연습).
    답

    \(\frac34\times1.1314\times10^{-3}\times1.0826\times10^{-3}\times0.8855\times(5\times0.3863 - 1) = 7.56\times10^{-7}\) rad/s = +3.74°/일.

  2. 고도가 높아지면 태양동기 경사각은 커집니까, 작아집니까?
    답

    커집니다. 높을수록 J2 효과가 약해 더 큰 \(|\cos i|\)(더 역행)가 필요합니다.
