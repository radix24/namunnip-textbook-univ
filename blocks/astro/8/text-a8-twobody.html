2체 문제를 상대 운동 방정식으로 바꾸기

본문 · 1.1절
이 절에서 배울 것
  • 두 천체의 운동 방정식에서 상대 운동 방정식 \(\ddot{\vec r} = -\mu\vec r/r^3\)을 유도한다.
  • 중력 상수 \(\mu = G(m_1+m_2)\)와 그 값(지구 398,600 km³/s²)을 안다.
  • 인공위성 문제에서 위성 질량을 무시할 수 있는 까닭을 안다.
먼저 알아야 할 것
  • Kepler 법칙의 유도 (천우3 3.1절), 벡터와 뉴턴 법칙 (물리1 일반역학(1)).

궤도역학의 출발점

인공위성, 행성 탐사선, 쌍성의 궤도 계산은 모두 같은 방정식에서 출발합니다. 천우3에서 Kepler 법칙을 유도하며 결과만 썼던 상대 운동 방정식을, 이 과목의 주교재(Curtis, Orbital Mechanics for Engineering Students)처럼 벡터로 다시 세웁니다. 경희대 천체역학과 우주비행역학도 같은 내용으로 시작합니다.

이 절의 기호를 고교 수학으로 읽기 화살표 \(\vec r\)는 위치를 좌표 세 개 \((x, y, z)\)로 한꺼번에 적은 것(벡터)이고, \(r\)은 그 길이 \(\sqrt{x^2 + y^2 + z^2}\)입니다. \(\hat u_r = \vec r/r\)은 같은 방향의 길이 1짜리 화살표입니다. 점 기호는 시간에 대한 미분입니다: \(\dot x = dx/dt\)(속도), \(\ddot x = d^2x/dt^2\)(가속도, 고교 미적분의 이계도함수). 그래서 아래의 \(\ddot{\vec r} = -\mu\vec r/r^3\)은 세 식 \(\ddot x = -\mu x/r^3\), \(\ddot y = -\mu y/r^3\), \(\ddot z = -\mu z/r^3\)을 한 줄로 적은 것입니다. '가속도가 늘 중심을 향하고 크기가 \(\mu/r^2\)'이라는 뜻입니다.

1.1.1두 천체의 운동 방정식

관성 좌표계에서 질량 \(m_1, m_2\)의 위치를 \(\vec R_1, \vec R_2\), 상대 위치를 \(\vec r = \vec R_2 - \vec R_1\)이라 하면 만유인력으로

\[ m_1\ddot{\vec R}_1 = \frac{Gm_1m_2}{r^2}\hat u_r, \qquad m_2\ddot{\vec R}_2 = -\frac{Gm_1m_2}{r^2}\hat u_r \]

입니다(\(\hat u_r = \vec r/r\)). 두 식을 더하면 \(m_1\ddot{\vec R}_1 + m_2\ddot{\vec R}_2 = 0\)이므로 질량 중심은 가속하지 않고 등속 직선 운동을 합니다. 그래서 질량 중심을 관성 좌표계의 원점으로 쓸 수 있습니다.

1.1.2상대 운동 방정식

유도. 둘째 식을 \(m_2\)로, 첫째 식을 \(m_1\)로 나눠 빼면 \[ \ddot{\vec r} = \ddot{\vec R}_2 - \ddot{\vec R}_1 = -\frac{Gm_1}{r^2}\hat u_r - \frac{Gm_2}{r^2}\hat u_r = -\frac{G(m_1 + m_2)}{r^2}\hat u_r \] 이고, \(\mu = G(m_1 + m_2)\)로 두면 \[ \ddot{\vec r} = -\frac{\mu}{r^3}\vec r \] 입니다. ∎

이것이 2체 문제의 기본 방정식입니다. 6개의 미지수(\(\vec R_1, \vec R_2\)의 성분)가 질량 중심(풀림)과 상대 위치(이 식)로 나뉘어, 3차원 벡터 하나의 문제가 되었습니다. 지구 둘레 위성에서는 위성 질량이 지구의 \(10^{-21}\) 수준이라 \(\mu \approx GM_\oplus = 398{,}600\) km³/s²입니다. \(G\)와 \(M_\oplus\)를 따로 쓰는 것보다 \(\mu\)를 한 숫자로 쓰는 까닭은, 위성 궤도 관측으로 \(\mu\)가 \(G\)나 \(M_\oplus\)보다 훨씬 정밀하게(10자리) 재어지기 때문입니다.

예제 1.1.1

지표(\(r = 6{,}378\) km)와 정지궤도(\(r = 42{,}164\) km)에서 지구 중력 가속도의 크기는?

풀이. \(|\ddot{\vec r}| = \mu/r^2\): 지표 \(398{,}600/6378^2 = 9.80\times10^{-3}\) km/s² = 9.80 m/s², 정지궤도 \(398{,}600/42164^2 = 0.224\) m/s²입니다. 정지궤도에서도 중력은 지표의 2%가 넘습니다. 위성이 "무중력"으로 느끼는 것은 중력이 없어서가 아니라 함께 떨어지고 있기 때문입니다.

1.1.3모형의 가정

  • 두 천체는 점(또는 구대칭)이다. 지구의 편평도(J2)는 섭동으로 따로 다룬다(5.2절).
  • 다른 천체(달, 해)의 중력과 대기 저항, 복사압은 없다(5.1절).
  • 뉴턴 역학이 맞다(GPS 위성의 시계 보정 같은 상대론 효과는 무시).
흔한 실수 단위를 섞지 마세요. \(\mu\)를 km³/s²로 쓰면 거리는 km, 속도는 km/s입니다. m³/s²(\(3.986\times10^{14}\))로 쓰면 m와 m/s입니다.
요약
  1. 질량 중심은 등속 운동, 상대 운동은 \(\ddot{\vec r} = -\mu\vec r/r^3\).
  2. \(\mu = G(m_1+m_2)\). 지구 위성은 \(\mu \approx 398{,}600\) km³/s².
  3. \(\mu\)는 \(G\), \(M\)보다 정밀하게 알려져 있다.
  4. 가정: 점 질량, 다른 힘 없음, 뉴턴 역학. 나머지는 섭동으로.

1.1.4연습문제

기본

  1. 고도 400 km에서 지구 중력 가속도는?
    답

    \(398{,}600/6778^2 = 8.68\) m/s².

  2. 달의 \(\mu\)는 약 4,903 km³/s²입니다. 달 표면(반지름 1,737 km)의 중력 가속도는?
    답

    1.62 m/s².

응용

  1. 지구-달 계의 상대 운동에서 \(\mu = G(M_\oplus + M_{달})\)은 지구만의 \(\mu\)보다 몇 % 큽니까?
    답

    \(4903/398600 = 1.2\%\).

  2. 질량 중심이 등속 운동한다는 것을 외력이 없다는 조건과 연결하세요.
    답

    두 힘이 작용-반작용이라 합이 0, 곧 계의 운동량이 보존되어 질량 중심 속도가 일정합니다.
