회전 좌표계에서 원형 제한 3체 문제의 운동 방정식

본문 · 4.1절
이 절에서 배울 것
  • 원형 제한 3체 문제의 가정을 안다.
  • 회전 좌표계의 운동 방정식(원심력, 코리올리 항)을 쓴다.
  • 무차원 단위와 질량비 \(\mu\)를 쓴다.
먼저 알아야 할 것
  • 상대 운동 방정식 (1.1절), 회전 좌표계와 겉보기 힘 (물리4 일반역학(2)).

세 번째 천체는 왜 어려운가

2체 문제는 원뿔곡선으로 완전히 풀립니다. 그러나 셋째 천체가 끼면 일반해가 없습니다(푸앵카레). 그래도 특별한 경우는 많은 것을 알려 줍니다. 지구-달 사이의 우주선, 해-목성 둘레의 소행성처럼 "작은 물체 하나가 원 궤도로 도는 두 큰 천체 사이에서 움직이는" 경우가 원형 제한 3체 문제입니다. 경희대 천체역학과 연세대 우주동력학(1)의 공통 주제입니다.

4.1.1가정과 단위

  • 두 큰 천체 \(m_1 > m_2\)는 질량 중심 둘레를 원 궤도로 돈다.
  • 셋째 물체의 질량은 무시할 만해 두 천체의 운동에 영향을 주지 않는다.
  • 단위: 두 천체 사이 거리 = 1, 질량 합 = 1, 공전 각속도 = 1(따라서 \(G = 1\), 주기 \(2\pi\)). 질량비 \(\mu = m_2/(m_1 + m_2)\).

두 천체와 함께 도는 회전 좌표계를 잡으면 두 천체가 \(x\)축 위 \((-\mu, 0)\)과 \((1 - \mu, 0)\)에 멈춰 있습니다.

4.1.2운동 방정식

각속도 \(\vec\omega = \hat z\)로 도는 좌표계에서의 가속도에는 원심 가속도 \(-\vec\omega\times(\vec\omega\times\vec r)\)와 코리올리 가속도 \(-2\vec\omega\times\dot{\vec r}\)가 더해집니다. 성분으로 쓰면(평면 운동)

\[ \ddot x - 2\dot y = x - \frac{(1-\mu)(x + \mu)}{r_1^3} - \frac{\mu(x - 1 + \mu)}{r_2^3}, \qquad \ddot y + 2\dot x = y - \frac{(1-\mu)y}{r_1^3} - \frac{\mu y}{r_2^3} \]

입니다(\(r_1, r_2\)는 두 천체까지의 거리). 우변을 유효 퍼텐셜 \(\Omega = \frac12(x^2 + y^2) + \frac{1-\mu}{r_1} + \frac{\mu}{r_2}\)의 기울기로 쓰면 \(\ddot x - 2\dot y = \partial\Omega/\partial x\), \(\ddot y + 2\dot x = \partial\Omega/\partial y\)입니다.

  • \(x, y\) 항: 원심력(회전축에서 멀어지게).
  • \(-2\dot y\), \(+2\dot x\) 항: 코리올리 힘(움직이는 방향의 옆으로). 일을 하지 않으므로 에너지를 바꾸지 않는다.
예제 4.1.1

지구-달 계의 질량비(달 질량 \(7.35\times10^{22}\) kg, 지구 \(5.97\times10^{24}\) kg), 무차원 길이·시간 단위의 실제 값은?

풀이. \(\mu = 7.35/(597 + 7.35) = 0.0122\). 길이 단위 384,400 km, 시간 단위는 공전 각속도의 역수로 \(27.32\text{일}/2\pi = 4.35\)일입니다.

주의 실제 달 궤도는 이심률 0.055의 타원이고 해의 중력도 큽니다. 원형 제한 3체 문제는 첫 근사이며, 실제 임무 설계에는 이심 궤도와 4체(해 포함) 효과를 넣어 수치 적분합니다.
요약
  1. 두 큰 천체는 원 궤도, 셋째 물체는 질량 무시. 단위: 거리·질량 합·각속도 = 1, 질량비 \(\mu\).
  2. 회전 좌표계: \(\ddot x - 2\dot y = \Omega_x\), \(\ddot y + 2\dot x = \Omega_y\).
  3. \(\Omega = \frac12(x^2+y^2) + (1-\mu)/r_1 + \mu/r_2\): 원심력 + 두 중력.
  4. 코리올리 힘은 일을 하지 않는다.

4.1.3연습문제

기본

  1. 해-목성 계의 질량비는? (목성 질량은 해의 1/1047)
    답

    \(\mu = 1/1048 = 9.54\times10^{-4}\).

  2. 회전 좌표계에서 정지한 물체에 코리올리 힘은?
    답

    0(속도가 0이므로).

응용

  1. 해-지구 계의 시간 단위는 며칠입니까?
    답

    \(365.25/2\pi = 58.1\)일.

  2. \(\mu \to 0\)이면 운동 방정식은 무엇이 됩니까?
    답

    큰 천체 하나 둘레의 2체 운동을 회전 좌표계에서 쓴 것이 됩니다.
