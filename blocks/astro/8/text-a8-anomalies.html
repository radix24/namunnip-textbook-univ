평균·이심·진근점 이각의 관계

본문 · 2.1절
이 절에서 배울 것
  • 세 근점 이각(평균 \(M\), 이심 \(E\), 진 \(\nu\))의 기하학적 뜻을 안다.
  • \(E\)와 \(\nu\), \(r\)의 관계식을 쓴다.
  • 평균 근점 이각이 시간에 비례함을 안다.
먼저 알아야 할 것
  • 궤도 방정식 (1.2절), 타원의 성질 (공통1 7단원).

궤도 위의 '어디'를 나타내는 세 각

궤도의 모양은 \(a, e\)로 정해졌습니다. 이제 "시각 \(t\)에 위성이 궤도의 어디에 있는가"를 알아야 합니다. 이 위치를 나타내는 각이 세 가지 있고, 각자 쓰임이 다릅니다.

2.1.1세 각의 정의

  • 진근점 이각 \(\nu\): 초점(지구 중심)에서 근점 방향과 위성 방향이 이루는 실제 각. 궤도 방정식에 쓴다.
  • 이심 근점 이각 \(E\): 타원을 감싸는 보조원(반지름 \(a\), 중심은 타원 중심)에 위성을 수직으로 투영한 점을, 타원의 중심에서 근점 방향으로부터 잰 각. 계산을 잇는 다리 역할을 한다.
  • 평균 근점 이각 \(M\): 위성이 같은 주기로 원 궤도를 고르게 돈다고 할 때의 각. \(M = n(t - \tau)\)로 시간에 정확히 비례한다(\(n = \sqrt{\mu/a^3}\)은 평균 운동, \(\tau\)는 근점 통과 시각).

2.1.2관계식

보조원의 기하에서 위성의 좌표는 중심 기준으로 \(x = a\cos E\), \(y = b\sin E\)이고, 초점은 중심에서 \(ae\)만큼 떨어져 있으므로

\[ r = a(1 - e\cos E), \qquad \tan\frac\nu2 = \sqrt{\frac{1+e}{1-e}}\tan\frac E2 \]

입니다. 둘째 식은 \(\cos\nu = (\cos E - e)/(1 - e\cos E)\)에서 반각 공식으로 얻습니다. \(E\)와 \(M\)의 관계는 면적 속도 일정(Kepler 제2법칙)에서 나오며, 다음 절의 Kepler 방정식입니다.

\[ M = E - e\sin E \]

계산의 흐름은 시각 → \(M\) → (Kepler 방정식) → \(E\) → \(\nu\), \(r\)입니다.

예제 2.1.1

\(e = 0.3\)인 궤도에서 \(E = 90^\circ\)이면 \(\nu\), \(r/a\), \(M\)은?

풀이. \(\tan(\nu/2) = \sqrt{1.3/0.7}\tan45^\circ = 1.3628\), \(\nu/2 = 53.73^\circ\), \(\nu = 107.5^\circ\). \(r/a = 1 - 0.3\cos90^\circ = 1\). \(M = \pi/2 - 0.3 = 1.2708\) rad = 72.8°. 세 각이 각각 72.8°, 90°, 107.5°로 다릅니다. 근점 근처에서는 위성이 빨라 \(\nu\)가 \(M\)보다 앞섭니다.

주의 \(\tan(\nu/2)\) 식에서 반각을 쓰는 까닭은 사분면 문제를 피하기 위해서입니다. \(E\)와 \(\nu\)는 늘 같은 반쪽(0~180° 또는 180~360°)에 있습니다. 코드에서는 atan2를 씁니다.
요약
  1. \(\nu\): 초점에서 본 실제 각. \(E\): 보조원을 이용한 각. \(M = n(t - \tau)\): 시간에 비례.
  2. \(r = a(1 - e\cos E)\), \(\tan(\nu/2) = \sqrt{(1+e)/(1-e)}\tan(E/2)\).
  3. Kepler 방정식 \(M = E - e\sin E\).
  4. 시각 → M → E → ν, r.

2.1.3연습문제

기본

  1. 원 궤도(\(e = 0\))에서 세 각의 관계는?
    답

    모두 같습니다.

  2. \(e = 0.5\), \(E = 180^\circ\)이면 \(\nu\)와 \(r\)은?
    답

    180°, \(r = 1.5a\)(원점).

응용

  1. \(a = 10{,}000\) km 궤도의 평균 운동과 주기는?
    답

    \(n = \sqrt{398600/10^{12}} = 6.313\times10^{-4}\) rad/s, 주기 2.764시간.

  2. \(e = 0.3\)에서 \(\nu = 90^\circ\)일 때 \(E\)는?
    답

    \(\tan(E/2) = \sqrt{0.7/1.3}\tan45^\circ = 0.7338\), \(E = 72.5^\circ\).
