궤도 에너지로 타원, 포물선, 쌍곡선 구별하기

본문 · 1.3절

탐사선이 지구 둘레를 계속 돌지, 달로 갈지, 태양계를 떠날지는 무엇이 정할까? 고도 300 km의 원 궤도에서 화성으로 떠나려면 속력을 얼마나 더해야 할까? 위치와 속력만 재고 궤도의 종류를 곧바로 판단할 수 있다면 편리할 것이다.

먼저 알아야 할 것활력 방정식(천우3 3.2절)과 이심률 벡터(1.2절)를 쓴다.

처음 질문의 답을 정하는 것은 한 숫자, 궤도 에너지 \(\varepsilon = v^2/2 - \mu/r\)이다. 이 절에서는 천우3 3.2절의 활력 방정식을 궤도의 분류와 탐사선 출발 문제로 넓힌다.

1.3.1에너지와 이심률

근점에서 \(r_p = \frac{h^2/\mu}{1+e}\), 속력 \(v_p = h/r_p\)를 에너지 식에 넣어 정리하면 다음을 얻는다.

\[ \varepsilon = -\frac{\mu^2}{2h^2}(1 - e^2) \]

따라서 에너지의 부호와 이심률이 일대일로 맞는다. 즉 \(\varepsilon < 0\)이면 \(e < 1\)인 타원(원 포함)이고, 이때 \(\varepsilon = -\mu/2a\)이다. 한편 \(\varepsilon = 0\)이면 \(e = 1\)인 포물선으로, 무한히 먼 곳에 이르면 속력이 0이 된다. 또 \(\varepsilon > 0\)이면 \(e > 1\)인 쌍곡선이며, 무한히 먼 곳에서도 속력 \(v_\infty = \sqrt{2\varepsilon}\)이 남는다. 이 \(v_\infty\)를 쌍곡선 초과 속도라 한다. 그림 1처럼 같은 근점에서 속력만 키우면 궤도가 이 순서로 바뀐다.

1.3.2행성 탈출

그러므로 지구를 떠나 다른 행성으로 가는 탐사선은 지구에 대해 쌍곡선 궤도를 탄다. 지구 중력권을 벗어난 뒤 남는 속력 \(v_\infty\)가 태양에 대한 궤도를 바꾸는 데 쓰인다. 에너지 보존 \(v^2/2 - \mu/r = v_\infty^2/2\)에서 출발 고도에 필요한 속력은 다음과 같다.

\[ v = \sqrt{v_\infty^2 + v_{esc}^2}, \qquad v_{esc} = \sqrt{2\mu/r} \]

즉 탈출 속력에 \(v_\infty\)를 제곱으로 더하는 셈이라, 작은 \(v_\infty\)는 출발 속력을 조금만 늘린다.

예제 1.3.1

고도 300 km 원 궤도(\(v_c = 7.726\) km/s)에서 화성으로 가려면 \(v_\infty = 2.94\) km/s가 필요하다. 출발할 때의 속력과 원 궤도에서 더해야 할 \(\Delta v\)는 얼마인가?

풀이. \(v_{esc} = \sqrt2\times7.726 = 10.926\) km/s이므로 \(v = \sqrt{2.94^2 + 10.926^2} = 11.315\) km/s이다. 따라서 \(\Delta v = 11.315 - 7.726 = 3.59\) km/s이다. 그런데 \(v_\infty\)는 2.94 km/s인데 더할 속력은 탈출에 필요한 3.20 km/s보다 0.39 km/s만 크다.

예제 1.3.2

근점 \(r = 7000\) km에서 속력 \(v = 11.0\) km/s인 물체의 궤도 종류와 이심률, 쌍곡선 초과 속도를 구하여라.

풀이. 먼저 \(\varepsilon = 60.5 - 56.94 = 3.56\) km²/s²로 양수이므로 쌍곡선이다. 근점에서 \(h = rv = 77{,}000\) km²/s이므로 \(e = \sqrt{1 + 2\varepsilon h^2/\mu^2} = \sqrt{1 + 2\times3.56\times5.929\times10^9/1.589\times10^{11}} = \sqrt{1.266} = 1.125\)이다. 또 \(v_\infty = \sqrt{7.12} = 2.67\) km/s이다.

주의근점이 아닌 곳의 속력으로 이심률을 구할 때는 속도의 방향(비행 경로각)이 필요하다. 에너지는 속력만으로 정해지지만 이심률은 각운동량에도 달려 있기 때문이다.
마무리

궤도 에너지와 이심률은 \(\varepsilon = -\frac{\mu^2}{2h^2}(1 - e^2)\)로 이어져, 에너지가 음수이면 타원, 0이면 포물선, 양수이면 쌍곡선이다. 타원에서는 \(\varepsilon = -\mu/2a\)이고 쌍곡선에서는 무한히 먼 곳에서 \(v_\infty = \sqrt{2\varepsilon}\)이 남는다. 행성으로 떠나는 출발 속력은 \(v = \sqrt{v_\infty^2 + v_{esc}^2}\)이며, 이심률을 구하려면 속력 말고 속도의 방향도 알아야 한다.

1.3.3연습문제

기본

  1. 고도 300 km에서의 탈출 속력은 얼마인가?
    답

    \(\sqrt{2\times398600/6678}\)이므로 10.93 km/s이다.

응용

  1. 목성으로 가는 \(v_\infty = 8.8\) km/s를 고도 300 km 원 궤도에서 얻으려면 \(\Delta v\)가 얼마나 필요한가?
    답

    \(\sqrt{8.8^2 + 10.926^2} - 7.726 = 14.03 - 7.726\)이므로 6.30 km/s이다.

  2. 포물선 궤도의 근점 거리가 \(r_p\)이면 \(h\)는 무엇인가?
    답

    \(e = 1\)이므로 \(r_p = h^2/(2\mu)\)이고 \(h = \sqrt{2\mu r_p}\)이다.
