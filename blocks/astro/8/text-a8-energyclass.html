  • 궤도 에너지와 이심률의 관계를 쓴다.

먼저 알아야 할 것
  • 활력 방정식 (천우3 3.2절), 이심률 벡터 (1.2절).

돌아올 것인가, 떠날 것인가

탐사선이 지구 둘레를 계속 돌지, 달로 갈지, 태양계를 떠날지는 한 숫자, 궤도 에너지 \(\varepsilon = v^2/2 - \mu/r\)이 정합니다. 천우3 3.2절의 활력 방정식을 궤도의 분류와 탐사선 출발 문제로 넓힙니다.

1.3.1에너지와 이심률

근점에서 \(r_p = \frac{h^2/\mu}{1+e}\), 속력 \(v_p = h/r_p\)를 에너지에 넣어 정리하면

\[ \varepsilon = -\frac{\mu^2}{2h^2}(1 - e^2) \]

입니다. 따라서 에너지의 부호와 이심률이 일대일로 맞습니다.

  • \(\varepsilon < 0\) ⇔ \(e < 1\): 타원(원 포함). \(\varepsilon = -\mu/2a\).
  • \(\varepsilon = 0\) ⇔ \(e = 1\): 포물선. 무한히 먼 곳에서 속력 0.
  • \(\varepsilon > 0\) ⇔ \(e > 1\): 쌍곡선. 무한히 먼 곳에서도 속력 \(v_\infty = \sqrt{2\varepsilon}\)이 남는다(쌍곡선 초과 속도).

1.3.2행성 탈출

지구를 떠나 다른 행성으로 가는 탐사선은 지구에 대해 쌍곡선 궤도를 탑니다. 지구 중력권을 벗어난 뒤 남는 속력 \(v_\infty\)가 태양에 대한 궤도를 바꾸는 데 쓰입니다. 에너지 보존 \(v^2/2 - \mu/r = v_\infty^2/2\)에서 출발 고도의 필요 속력은

\[ v = \sqrt{v_\infty^2 + v_{esc}^2}, \qquad v_{esc} = \sqrt{2\mu/r} \]

입니다. 탈출 속력에 \(v_\infty\)를 "제곱으로" 더하는 셈이라, 작은 \(v_\infty\)는 출발 속력을 조금만 늘립니다.

예제 1.3.1

고도 300 km 원 궤도(\(v_c = 7.726\) km/s)에서 화성으로 가려면 \(v_\infty = 2.94\) km/s가 필요합니다. 출발 때의 속력과 원 궤도에서 더해야 할 \(\Delta v\)는?

풀이. \(v_{esc} = \sqrt2\times7.726 = 10.926\) km/s, \(v = \sqrt{2.94^2 + 10.926^2} = 11.315\) km/s, \(\Delta v = 11.315 - 7.726 = 3.59\) km/s입니다.

예제 1.3.2

\(r = 7000\) km에서 \(v = 11.0\) km/s인 물체의 궤도 종류와 이심률을 판단하세요(근점에서 측정했다고 가정).

풀이. \(\varepsilon = 60.5 - 56.94 = 3.56\) km²/s² > 0이므로 쌍곡선입니다. \(h = 77{,}000\)이고 \(e = \sqrt{1 + 2\varepsilon h^2/\mu^2} = \sqrt{1 + 2\times3.56\times5.929\times10^9/1.589\times10^{11}} = \sqrt{1.266} = 1.125\), \(v_\infty = \sqrt{7.12} = 2.67\) km/s입니다.

주의 근점이 아닌 곳의 속력으로 이심률을 구할 때는 속도의 방향(비행 경로각)이 필요합니다. 에너지는 속력만으로 정해지지만 이심률은 각운동량에도 달려 있기 때문입니다.
요약
  1. \(\varepsilon = -\frac{\mu^2}{2h^2}(1 - e^2)\): 에너지 부호 ⇔ 궤도 종류.
  2. 타원 \(\varepsilon = -\mu/2a\), 포물선 0, 쌍곡선 \(v_\infty = \sqrt{2\varepsilon}\).
  3. 탈출 출발 속력 \(v = \sqrt{v_\infty^2 + v_{esc}^2}\).
  4. 이심률에는 속도의 방향(각운동량)도 필요하다.

1.3.3연습문제

기본

  1. 고도 300 km에서의 탈출 속력은?
    답

    10.93 km/s.

  2. \(\varepsilon = -20\) km²/s²인 지구 궤도의 긴반지름은?
    답

    \(398600/40 = 9{,}965\) km.

응용

  1. 목성으로 가는 \(v_\infty = 8.8\) km/s를 고도 300 km 원 궤도에서 얻는 \(\Delta v\)는?
    답

    \(\sqrt{8.8^2 + 10.926^2} - 7.726 = 14.03 - 7.726 = 6.30\) km/s.

  2. 포물선 궤도에서 근점 거리가 \(r_p\)이면 \(h\)는?
    답

    \(e = 1\)이므로 \(r_p = h^2/(2\mu)\), \(h = \sqrt{2\mu r_p}\).
