한 순간의 위치와 속도로 궤도 전체 알아내기

예제 · 비각운동량 · 비에너지 · 근지점
문제 해결 전략 · 상태에서 궤도로
  1. \(h = rv\cos\gamma\)(\(\gamma\): 비행 경로각, 국지 수평면과 속도가 이루는 각), \(\varepsilon = v^2/2 - \mu/r\).
  2. \(a = -\mu/(2\varepsilon)\), \(e = \sqrt{1 + 2\varepsilon h^2/\mu^2}\), \(p = h^2/\mu\).
  3. \(r_p = p/(1+e)\), \(r_a = p/(1-e)\). 지금 위치의 진근점 이각은 \(\cos\theta = (p/r - 1)/e\), \(\gamma > 0\)이면 근지점을 지나 멀어지는 중.
먼저 예상해 보기. 지구 중심에서 7,000 km(고도 약 620 km)인 곳을 8 km/s로 지나는 위성은 그 고도의 원 궤도 속력(7.55 km/s)보다 빠릅니다. 근지점은 지금보다 높을까요, 낮을까요?

문제. 위성이 지구 중심에서 \(r = 7{,}000\) km 지점을 속력 8.0 km/s, 비행 경로각 +5°로 지나갑니다(\(\mu = 398{,}600\) km³/s², 지구 반지름 6,378 km). 궤도의 \(a\), \(e\), 근지점·원지점 고도, 주기, 지금의 진근점 이각을 구하세요.

풀이

  1. \(h = 7000\times8.0\times\cos5° = 55{,}787\) km²/s, \(\varepsilon = 32 - 398600/7000 = -24.943\) km²/s².
    속도의 수평 성분만 각운동량에 들어간다.
  2. \(a = 398600/(2\times24.943) = 7{,}990\) km, \(e = \sqrt{1 - 2\times24.943\times55787^2/398600^2} = 0.151\).
    결과 1.4.1.
  3. \(p = h^2/\mu = 7{,}808\) km, \(r_p = 6{,}783\) km(고도 405 km), \(r_a = 9{,}198\) km(고도 2,820 km).
    결과 1.4.2.
  4. 주기 \(2\pi\sqrt{a^3/\mu} = 118.5\)분.
    케플러 제3법칙.
  5. \(\cos\theta = (7808/7000 - 1)/0.151 = 0.764\), \(\theta = 40.2°\). 경로각이 양수이므로 근지점을 40° 지나 원지점으로 올라가는 중.
    \(\gamma > 0\)이면 \(0 < \theta < 180°\).

의미

지금 위치보다 근지점이 낮습니다. 원 궤도 속력보다 빨라도 비행 경로각이 있으면, 위성은 근지점을 이미 지나 올라가는 중일 수 있습니다. 근지점 고도 405 km는 대기 항력이 의미 있는 높이라 수명 계산(5.3절)에 바로 쓰입니다.

검산

근지점에서 \(v_p = h/r_p = 8.22\) km/s, 활력 방정식 \(\sqrt{\mu(2/r_p - 1/a)} = \sqrt{398600\times(2/6783 - 1/7990)} = 8.22\) km/s로 같습니다. \(r_p + r_a = 15{,}981 = 2a\)도 맞습니다.

이해 확인

같은 위치·속력에서 비행 경로각만 0°이면 \(r = 7{,}000\) km는 근지점입니까, 원지점입니까?

답

속력 8.0 km/s가 원 속력 7.55 km/s보다 크므로 근지점입니다. 이때 원지점은 \(r_a = r_p v_p^2/(2\mu/r_p - v_p^2) = 7000\times64/(113.89 - 64) = 8{,}980\) km입니다.
