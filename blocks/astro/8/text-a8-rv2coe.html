위치와 속도 벡터에서 고전 궤도요소 구하기

본문 · 3.1절
이 절에서 배울 것
  • 여섯 고전 궤도요소(\(h\) 또는 \(a\), \(e\), \(i\), \(\Omega\), \(\omega\), \(\nu\))의 뜻을 안다.
  • 위치·속도 벡터에서 궤도요소를 계산하는 알고리즘을 따라간다.
  • 사분면을 정하는 조건을 안다.
먼저 알아야 할 것
  • 이심률 벡터 (1.2절), 궤도 요소 소개 (천우2 4.3절).

벡터 여섯 개 성분 = 궤도요소 여섯 개

레이더나 GPS로 위성의 위치와 속도(6개 숫자)를 재면 궤도가 완전히 정해집니다. 그러나 \(\vec r, \vec v\)의 숫자만 봐서는 궤도의 크기, 기울기, 방향을 알기 어렵습니다. 그래서 같은 정보를 뜻이 분명한 여섯 개의 고전 궤도요소로 바꿔 씁니다.

3.1.1여섯 요소

  • 비각운동량 \(h\) 또는 긴반지름 \(a\): 궤도의 크기.
  • 이심률 \(e\): 궤도의 모양.
  • 경사각 \(i\): 적도면에 대한 궤도면의 기울기(0~180°, 90° 넘으면 역행).
  • 승교점 적경 \(\Omega\): 위성이 남에서 북으로 적도를 지나는 점(승교점)의 방향을 춘분점에서 잰 각.
  • 근지점 인수 \(\omega\): 궤도면 안에서 승교점에서 근지점까지의 각.
  • 진근점 이각 \(\nu\): 근지점에서 위성까지의 각(시각에 따라 변하는 유일한 요소).

3.1.2알고리즘 (Curtis 알고리즘 4.2)

  1. \(r = |\vec r|\), \(v = |\vec v|\), 지름 속도 \(v_r = \vec r\cdot\vec v/r\).
  2. \(\vec h = \vec r\times\vec v\), \(h = |\vec h|\).
  3. \(i = \arccos(h_z/h)\).
  4. 교점 벡터 \(\vec N = \hat K\times\vec h\)(\(\hat K\)는 북극 방향 단위벡터), \(\Omega = \arccos(N_x/N)\). \(N_y < 0\)이면 \(\Omega = 360^\circ - \Omega\).
  5. \(\vec e = \frac1\mu\left[(v^2 - \frac\mu r)\vec r - rv_r\vec v\right]\), \(e = |\vec e|\) (1.2절의 식을 풀어 쓴 것).
  6. \(\omega = \arccos\left(\frac{\vec N\cdot\vec e}{Ne}\right)\). \(e_z < 0\)이면 \(\omega = 360^\circ - \omega\).
  7. \(\nu = \arccos\left(\frac{\vec e\cdot\vec r}{er}\right)\). \(v_r < 0\)이면 \(\nu = 360^\circ - \nu\).
  8. \(a = h^2/[\mu(1 - e^2)]\) 또는 에너지에서.

사분면 조건의 뜻: 승교점이 \(y\)가 음인 쪽이면 180°를 넘고, 근지점이 적도 남쪽이면 \(\omega > 180^\circ\), 위성이 지구로 다가가고 있으면(\(v_r < 0\)) 원지점을 지나 근지점으로 가는 중이라 \(\nu > 180^\circ\)입니다.

예제 3.1.1

\(\vec r = (7000, 0, 0)\) km, \(\vec v = (0, 7.5, 1.0)\) km/s의 궤도요소를 구하세요.

풀이. \(v_r = 0\). \(\vec h = (0, -7000, 52500)\), \(h = 52{,}965\). \(i = \arccos(52500/52965) = 7.59^\circ\). \(\vec N = (7000, 0, 0)\)이므로 \(\Omega = 0^\circ\). \(\vec e = (0.00539, 0, 0)\), \(e = 0.00539\). \(\vec N\)과 \(\vec e\)가 같은 방향이라 \(\omega = 0^\circ\), \(\vec e\)와 \(\vec r\)도 같은 방향이라 \(\nu = 0^\circ\). \(a = h^2/[\mu(1-e^2)] = 7{,}038\) km(근지점 7,000 km, 원지점 7,076 km, 주기 97.9분). 위성은 지금 승교점이자 근지점에 있습니다.

주의 원 궤도(\(e = 0\))나 적도 궤도(\(i = 0\))에서는 \(\omega\) 또는 \(\Omega\)가 정해지지 않습니다. 이때는 승교점에서 잰 위도 인수 \(u = \omega + \nu\), 춘분점에서 잰 진경도 \(\lambda = \Omega + \omega + \nu\)를 대신 씁니다.
요약
  1. 궤도요소: 크기(\(h\)/\(a\)), 모양(\(e\)), 기울기(\(i\)), 방향(\(\Omega\), \(\omega\)), 위치(\(\nu\)).
  2. \(\vec h\) → \(i\), \(\vec N = \hat K\times\vec h\) → \(\Omega\), \(\vec e\) → \(e\), \(\omega\), \(\nu\).
  3. 사분면: \(N_y < 0\), \(e_z < 0\), \(v_r < 0\)이면 360°에서 뺀다.
  4. 원·적도 궤도는 위도 인수, 진경도를 쓴다.

3.1.3연습문제

기본

  1. \(\vec h = (0, 0, 50000)\)이면 경사각은?
    답

    0°(적도 궤도).

  2. \(h_z < 0\)이면 위성은 어느 방향으로 돕니까?
    답

    \(i > 90^\circ\), 역행(지구 자전과 반대).

응용

  1. \(\vec r = (0, 8000, 0)\) km, \(\vec v = (-5.0, 0, 5.0)\) km/s의 경사각과 승교점 적경은?
    답

    \(\vec h = (8000\times5, 0, 8000\times5) = (40000, 0, 40000)\), \(i = 45^\circ\). \(\vec N = \hat K\times\vec h = (0, 40000, 0)\), \(\Omega = 90^\circ\).

  2. 위 위성의 궤도 에너지와 긴반지름은?
    답

    \(v^2 = 50\), \(\varepsilon = 25 - 49.83 = -24.83\), \(a = 8{,}027\) km.
