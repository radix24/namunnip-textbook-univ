위치와 속도 벡터에서 고전 궤도요소 구하기

본문 · 3.1절

레이더나 GPS로 위성의 위치와 속도를 재면 숫자 6개를 얻고, 그것으로 궤도는 완전히 정해진다. 그러나 \(\vec r = (7000, 0, 0)\), \(\vec v = (0, 7.5, 1.0)\)이라는 숫자만 봐서는 궤도가 얼마나 크고, 얼마나 기울었고, 어느 쪽을 향하는지 알기 어렵다. 같은 정보를 뜻이 분명한 숫자 6개로 바꿀 수 있을까?

먼저 알아야 할 것이심률 벡터(1.2절)와 궤도요소 소개(천우2 4.3절)를 쓴다.

3.1.1여섯 요소

처음 질문의 답이 고전 궤도요소 여섯 개이다. 궤도의 크기는 비각운동량 \(h\) 또는 긴반지름 \(a\)가, 모양은 이심률 \(e\)가 정한다. 궤도면의 방향은 두 각이 정한다. 경사각 \(i\)는 적도면에 대한 궤도면의 기울기(0°~180°, 90°를 넘으면 역행)이고, 승교점 적경 \(\Omega\)는 위성이 남에서 북으로 적도를 지나는 점(승교점)의 방향을 춘분점에서 잰 각이다(그림 1).

궤도면 안의 방향과 위치도 두 각이 정한다. 근지점 인수 \(\omega\)는 궤도면 안에서 승교점부터 근지점까지의 각이고, 진근점 이각 \(\nu\)는 근지점부터 위성까지의 각이다. 앞의 다섯은 2체 궤도에서 변하지 않고, \(\nu\)만 시간에 따라 변한다.

3.1.2계산 순서

위치와 속도에서 궤도요소를 구하는 계산은 다음 순서로 진행한다. 먼저 \(r = |\vec r|\), \(v = |\vec v|\), 지름 속도 \(v_r = \vec r\cdot\vec v/r\)을 구한다. 다음으로 \(\vec h = \vec r\times\vec v\)를 구하면 경사각이 \(i = \arccos(h_z/h)\)로 나온다. 이어서 북극 방향 단위벡터 \(\hat K\)로 교점 벡터 \(\vec N = \hat K\times\vec h\)를 만들면 \(\Omega = \arccos(N_x/N)\)이다.

그다음 1.2절의 이심률 벡터를 풀어 쓴 \(\vec e = \frac1\mu\big[(v^2 - \frac\mu r)\vec r - rv_r\vec v\big]\)에서 \(e = |\vec e|\)를 얻는다. 근지점 인수는 \(\omega = \arccos\big(\frac{\vec N\cdot\vec e}{Ne}\big)\), 진근점 이각은 \(\nu = \arccos\big(\frac{\vec e\cdot\vec r}{er}\big)\)이다. 끝으로 긴반지름은 \(a = h^2/[\mu(1 - e^2)]\)이나 에너지에서 구한다.

그런데 \(\arccos\)는 0°~180°만 돌려주므로 사분면을 따로 정해야 한다. 승교점이 \(y\)가 음인 쪽에 있으면(\(N_y < 0\)) \(\Omega\)는 180°를 넘는다. 근지점이 적도 남쪽에 있으면(\(e_z < 0\)) \(\omega > 180°\)이다. 또 위성이 지구로 다가가고 있으면(\(v_r < 0\)) 원지점을 지나 근지점으로 가는 중이므로 \(\nu > 180°\)이다. 세 경우 모두 360°에서 뺀다.

예제 3.1.1

처음 질문의 \(\vec r = (7000, 0, 0)\) km, \(\vec v = (0, 7.5, 1.0)\) km/s의 궤도요소를 구하여라.

풀이. \(v_r = 0\)이고 \(\vec h = (0, -7000, 52500)\), \(h = 52{,}965\)이므로 \(i = \arccos(52500/52965) = 7.59°\)이다. \(\vec N = (7000, 0, 0)\)이므로 \(\Omega = 0°\)이다. 이심률 벡터는 \(\vec e = (0.00539, 0, 0)\)이고 \(e = 0.00539\)이다. \(\vec N\)과 \(\vec e\)가 같은 방향이라 \(\omega = 0°\)이고, \(\vec e\)와 \(\vec r\)도 같은 방향이라 \(\nu = 0°\)이다. 끝으로 \(a = h^2/[\mu(1-e^2)] = 7{,}038\) km이므로 근지점 7,000 km, 원지점 7,076 km, 주기 97.9분이다. 즉 위성은 지금 승교점이자 근지점에 있다.

주의원 궤도(\(e = 0\))에서는 \(\omega\)가, 적도 궤도(\(i = 0\))에서는 \(\Omega\)가 정해지지 않는다. 이때는 승교점에서 잰 위도 인수 \(u = \omega + \nu\)나 춘분점에서 잰 진경도 \(\lambda = \Omega + \omega + \nu\)를 대신 쓴다.
마무리

고전 궤도요소는 크기(\(h\) 또는 \(a\)), 모양(\(e\)), 기울기(\(i\)), 방향(\(\Omega\), \(\omega\)), 위치(\(\nu\))를 뜻이 분명한 숫자로 나타낸다. 위치와 속도에서 \(\vec h\)로 \(i\)를, 교점 벡터 \(\vec N = \hat K\times\vec h\)로 \(\Omega\)를, 이심률 벡터로 \(e\), \(\omega\), \(\nu\)를 구한다. 각은 \(N_y\), \(e_z\), \(v_r\)이 음수이면 360°에서 빼서 사분면을 정하고, 원 궤도와 적도 궤도에서는 위도 인수나 진경도를 쓴다.

3.1.3연습문제

기본

  1. \(h_z < 0\)이면 위성은 어느 방향으로 도는가?
    답

    \(i > 90°\)이므로 지구 자전과 반대 방향으로 도는 역행 궤도이다.

응용

  1. \(\vec r = (0, 8000, 0)\) km, \(\vec v = (-5.0, 0, 5.0)\) km/s의 경사각과 승교점 적경은 얼마인가?
    답

    \(\vec h = (40000, 0, 40000)\)이므로 \(i = 45°\)이다. \(\vec N = \hat K\times\vec h = (0, 40000, 0)\)이므로 \(\Omega = 90°\)이다.

  2. 위 위성의 궤도 에너지와 긴반지름은 얼마인가?
    답

    \(v^2 = 50\)이므로 \(\varepsilon = 25 - 49.83 = -24.83\) km²/s²이고 \(a = -\mu/2\varepsilon = 8{,}027\) km이다.
