'오우무아무아는 발견 날 어디에 있었나

예제 · 쌍곡 Kepler 방정식 · Newton 방법
문제 해결 전략 · 시각에서 위치로(쌍곡선)
  1. 근일점 거리 \(q\)와 \(e\)에서 \(|a| = q/(e-1)\), 평균 운동 \(n = \sqrt{\mu/|a|^3}\).
  2. \(M_h = n(t - t_p)\)를 구하고 \(e\sinh F - F = M_h\)를 Newton 방법으로 푼다: \(F \leftarrow F - (e\sinh F - F - M_h)/(e\cosh F - 1)\).
  3. \(r = |a|(e\cosh F - 1)\), 진근점 이각, 속력 \(v = \sqrt{\mu(2/r + 1/|a|)}\)를 구한다.
먼저 예상해 보기. 태양을 스쳐 간(근일점 0.26 AU) 성간 천체가 40일 뒤에는 지구 궤도(1 AU)보다 안쪽에 있을까, 바깥에 있을까?

문제. 성간 천체 '오우무아무아는 이심률 1.201, 근일점 거리 0.2556 AU로 2017년 9월 9일 근일점을 지났고, 40일 뒤인 10월 19일 발견되었다. 그날 태양까지의 거리, 진근점 이각, 속력은? (\(\mu_\odot = 2.959\times10^{-4}\) AU³/일²)

풀이

  1. \(|a| = 0.2556/0.2011 = 1.271\) AU, \(n = \sqrt{2.959\times10^{-4}/1.271^3} = 0.01200\) rad/일, \(M_h = 0.480\).
    쌍곡선의 '평균 운동'.
  2. Newton 방법(처음 값 \(F_0 = \sinh^{-1}(M_h/e) = 0.39\)): 1.718, 1.294, 1.108, 1.0764, 1.0756으로 수렴.
    처음 값이 근에서 멀어 한 번 넘쳤다가 돌아온다.
  3. \(r = 1.271\times(1.2011\cosh1.0756 - 1) = 1.23\) AU, 진근점 이각 116.8°.
    결과 2.3.1.
  4. 속력 \(v = \sqrt{\mu(2/r + 1/|a|)} = 46.3\) km/s(먼 곳에서 \(v_\infty = 26.4\) km/s).
    쌍곡선의 활력 방정식(\(a<0\)이라 \(+1/|a|\)).

의미

발견 당시 이미 지구 궤도 바깥(1.23 AU)으로 빠르게 멀어지고 있었고, 그래서 관측할 수 있는 기간이 몇 주밖에 없었다. 실제 발견 무렵 태양 거리도 약 1.2 AU였다. 진근점 이각 117°는 점근선 방향 \(\arccos(-1/1.201) = 146°\)에 아직 못 미쳐 궤도가 휘는 중이다.

검산

\(F = 1.0756\)을 넣으면 \(1.2011\sinh1.0756 - 1.0756 = 1.2011\times1.2950 - 1.0756 = 0.4798\)로 \(M_h\)와 같다. 탈출 속력보다 빠른지도 확인: 1.23 AU에서 태양 탈출 속력은 \(42.1/\sqrt{1.23} = 38.0\) km/s < 46.3 km/s.

이해 확인

Newton 방법의 처음 값을 \(F_0 = \ln(2M_h/e)\)(큰 \(M_h\)용 근사)로 하면 이 문제에서는 좋은 선택인가?

답

아니다. \(M_h = 0.48\)은 작아 \(\ln(2\times0.48/1.2) = -0.22\)로 음수가 되어 근(1.08)에서 멀다. 작은 \(M_h\)에는 \(\sinh^{-1}(M_h/e)\)나 \(F_0 = M_h\) 같은 값이 낫고, 그래도 넘칠 수 있으니 반복 횟수와 수렴을 확인한다.
