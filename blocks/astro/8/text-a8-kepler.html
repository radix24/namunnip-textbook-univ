케플러 방정식을 풀어 임의 시각의 위치 구하기

본문 · 2.2절

긴반지름 10,000 km, 이심률 0.3인 궤도의 위성이 근점을 지난 지 1시간 뒤에는 어디에 있을까? 지상국 안테나를 언제 어디로 돌려야 할지 정하려면 이런 계산을 수없이 해야 한다. 시간에서 위치를, 거꾸로 위치에서 시간을 구하는 식은 무엇이고, 어떻게 풀까?

먼저 알아야 할 것세 근점 이각(2.1절)과 뉴턴 방법(천우6 3.1절)을 쓴다.

처음 질문에 답하는 식이 케플러 방정식이다. 1609년 케플러가 화성의 위치를 계산하려고 만들었고, 지금도 모든 궤도 프로그램에 들어 있는 기본 함수이다.

2.2.1유도

유도. 근점에서 시각 \(t - \tau\) 동안 위성이 쓸고 간 넓이는 케플러 제2법칙으로 전체 넓이 \(\pi ab\)의 \((t - \tau)/T\)배, 곧 \(\frac{ab}{2}M\)이다. 보조원 위에서 같은 넓이를 보자. 원의 부채꼴(중심 기준, 각 \(E\))의 넓이 \(\frac{a^2}{2}E\)에서 중심과 초점 사이 삼각형 \(\frac12ae\cdot a\sin E\)를 빼고, 이를 \(b/a\)배로 줄인 것이 타원 위에서 쓸고 간 넓이이다. 타원은 원을 한 방향으로 \(b/a\)배 줄인 것이기 때문이다. 그러므로 다음이 성립한다. ∎

\[ \frac{ab}{2}M = \frac ba\left(\frac{a^2}{2}E - \frac{a^2e}{2}\sin E\right) \;\Longrightarrow\; M = E - e\sin E \]

2.2.2시각에서 위치로

먼저 평균 운동 \(n = \sqrt{\mu/a^3}\)과 평균 근점 이각 \(M = n(t - \tau)\)를 구한다. 다음으로 케플러 방정식은 \(E\)에 대해 식으로 풀리지 않으므로, 뉴턴 방법 \(E_{k+1} = E_k - \frac{E_k - e\sin E_k - M}{1 - e\cos E_k}\)으로 \(E\)를 구한다. 처음 값은 \(E_0 = M\)으로 두고, \(e\)가 크면 \(\pi\)로 둔다. 끝으로 2.1절의 식으로 \(\nu\)와 \(r = a(1 - e\cos E)\)를 구한다.

예제 2.2.1

처음 질문의 궤도(\(a = 10{,}000\) km, \(e = 0.3\))에서 근점 통과 1시간 뒤의 \(E\), \(\nu\), \(r\)을 구하여라.

풀이. \(n = 6.3135\times10^{-4}\) rad/s이므로 \(M = 2.2729\) rad이다. 뉴턴 방법으로 \(E = 2.4615\) rad(141.0°)를 얻는다. \(\tan(\nu/2) = 1.3628\times\tan70.52° = 3.849\)이므로 \(\nu = 150.9°\)이고, \(r = 10000\times(1 - 0.3\cos2.4615) = 12{,}333\) km이다. 주기가 2.76시간이므로 1시간 뒤에는 원점(\(\nu = 180°\))에 조금 못 미친 곳에 있다(그림 1의 빨간 점).

2.2.3위치에서 시각으로

반대 방향은 반복 없이 바로 계산된다. \(\nu\)에서 반각 식으로 \(E\)를 구하고, \(M = E - e\sin E\)를 거쳐 \(t - \tau = M/n\)을 얻는다. 예를 들어 위 궤도에서 \(\nu = 90°\)에 이르는 시각은 \(E = 72.5°\)(1.2654 rad), \(M = 1.2654 - 0.3\sin72.5° = 0.9793\)에서 \(t - \tau = 0.9793/(6.3135\times10^{-4}) = 1{,}551\) s, 곧 25.9분이다. 즉 궤도의 첫 1/4(\(\nu\)가 0°에서 90°까지)을 지나는 데 주기(166분)의 16%밖에 걸리지 않는다.

주의쌍곡선 궤도에서는 케플러 방정식이 쌍곡 근점 이각 \(F\)를 쓴 \(M_h = e\sinh F - F\)로 바뀌고(2.3절), 포물선은 바커 방정식을 쓴다. 범용 변수를 쓰면 세 경우를 하나의 식으로 다룰 수 있다.
마무리

케플러 방정식 \(M = E - e\sin E\)는 면적 속도가 일정하다는 사실과 보조원의 넓이 비교에서 유도된다. 시각에서 위치를 구할 때는 \(M = n(t-\tau)\)를 구한 뒤 뉴턴 방법으로 \(E\)를 풀고 \(\nu\)와 \(r\)을 계산한다. 위치에서 시각을 구하는 반대 방향은 \(E\)와 \(M\)을 거쳐 반복 없이 바로 계산된다.

2.2.4연습문제

기본

  1. \(e = 0.1\), \(M = 1.0\) rad에서 \(E_0 = M\)으로 뉴턴 방법을 한 번 반복한 값은 얼마인가?
    답

    \(E_1 = 1 + 0.1\sin1/(1 - 0.1\cos1) = 1 + 0.08415/0.94597 = 1.0890\)이다.

응용

  1. 예제 2.2.1의 궤도에서 \(\nu = 270°\)에 이르는 시각은 언제인가?
    답

    \(E = 360° - 72.5° = 287.5°\)(5.0178 rad)이므로 \(M = 5.0178 + 0.2861 = 5.3039\)이고 \(t = M/n = 8{,}401\) s, 곧 2.33시간이다.

  2. 몰니야 궤도(\(a = 26{,}560\) km, \(e = 0.74\))에서 원점 근처 \(\nu = 180° \pm 60°\) 구간에 머무는 시간의 비율은 얼마인가?
    답

    \(\nu = 120°\)에서 \(\tan(E/2) = \sqrt{0.26/1.74}\tan60° = 0.6696\)이므로 \(E = 67.6°\)(1.180 rad), \(M = 1.180 - 0.684 = 0.496\)이다. 구간은 \(M\)이 0.496에서 \(2\pi - 0.496\)까지이므로 비율은 \((2\pi - 0.992)/2\pi = 84\%\)이다. 주기의 대부분을 원점 근처(북반구 상공)에서 보낸다.
