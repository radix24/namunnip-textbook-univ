3단원 마무리: 궤도요소 계산

연습 · 궤도요소

문제

쉬운 것에서 어려운 것 순서이다. 막히면 힌트 1(방향), 힌트 2(첫 단계)를 차례로 열어 보자.

  1. 개념 여섯 궤도요소 가운데 시간에 따라 변하는 것은(2체 문제)?

    힌트 1

    2체 문제에서 보존되는 양(에너지, 각운동량, 이심률 벡터)을 생각하여라.

    힌트 2

    궤도의 크기·모양·방향은 고정되고 위성의 위치만 바뀐다.

    풀이

    진근점 이각(또는 평균 근점 이각)뿐이다. 나머지 다섯은 일정하다.

  2. 계산 \(\vec h = (0, -30000, 40000)\)이면 경사각은?

    힌트 1

    \(\cos i = h_z/|\vec h|\).

    힌트 2

    \(|\vec h| = \sqrt{30000^2 + 40000^2} = 50000\).

    풀이

    \(\arccos(40000/50000) = 36.9^\circ\).

  3. 계산 \(\vec N = (-1000, -1000, 0)\)이면 승교점 적경은?

    힌트 1

    \(N_y < 0\)이면 360°에서 뺀다.

    힌트 2

    \(\cos\Omega = N_x/|N| = -1000/1414\)에서 135°를 얻은 뒤 \(N_y\)의 부호를 보아라.

    풀이

    \(\arccos(-0.7071) = 135^\circ\), \(N_y < 0\)이므로 225°.

  4. 판단 학생이 진근점 이각을 \(\arccos\)로만 구해 늘 0~180°로 적었다. 무엇이 문제인가?

    힌트 1

    arccos의 값 범위는 0~180°이다.

    힌트 2

    지름 방향 속도 \(v_r = \vec r\cdot\vec v/r\)의 부호로 근지점 전(음수)인지 후(양수)인지 판단하여라.

    풀이

    위성이 원지점을 지나 근지점으로 다가가는 동안(\(v_r < 0\))은 \(\nu\)가 180~360°여야 한다. \(v_r\)의 부호로 사분면을 고쳐야 한다.

  5. 계산 주기 12시간 궤도의 지상 궤적은 한 바퀴마다 몇 도 옮겨 가는가?

    힌트 1

    한 바퀴 동안 지구가 자전한 각만큼 서쪽으로 옮겨 간다.

    힌트 2

    720분 ÷ 항성일 1,436.1분 × 360°.

    풀이

    \(360\times720/1436.1 = 180.5^\circ\): 하루 두 바퀴 뒤 거의 같은 궤적.

  6. 도전 \(\vec r = (6500, 0, 2000)\) km, \(\vec v = (0, 7.6, 0)\) km/s의 경사각, 승교점 적경, 위도 인수를 구하여라.

    힌트 1

    \(\vec h\)와 \(\vec N\)부터.

    힌트 2

    위도 인수 \(u\)는 \(\vec N\)과 \(\vec r\) 사이의 각.

    풀이

    \(\vec h = (0\cdot0 - 2000\times7.6, 0, 6500\times7.6) = (-15200, 0, 49400)\), \(i = \arccos(49400/51686) = 17.1^\circ\). \(\vec N = \hat K\times\vec h = (0, -15200, 0)\), \(\Omega = 90^\circ\)이고 \(N_y < 0\)이므로 270°. \(u = \arccos(\vec N\cdot\vec r/(Nr)) = \arccos(0) = 90^\circ\)이고 \(r_z > 0\)이므로 90°: 위성은 궤도의 가장 북쪽에 있다.

  7. 계산 TLE의 평균 운동이 16.0회/일이면 주기와 평균 고도는? (\(\mu = 398{,}600\) km³/s²)

    힌트 1

    \(P = 1440/n\) 분.

    힌트 2

    \(a = (\mu/n^2)^{1/3}\), \(n\)은 rad/s.

    풀이

    주기 90.0분, \(n = 1.1636\times10^{-3}\) rad/s, \(a = 6{,}652\) km, 평균 고도 약 274 km.
