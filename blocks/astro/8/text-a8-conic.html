각운동량과 에너지 보존에서 원뿔곡선 궤도 유도하기

본문 · 1.2절

위성의 지금 위치 \(\vec r = (7000, 0, 0)\) km와 속도 \(\dot{\vec r} = (0, 7.5, 1.0)\) km/s를 알았다. 이 위성은 어떤 모양의 궤도를 돌고, 지금 궤도의 어디쯤에 있을까? 천우3에서는 극좌표로 궤도 방정식을 얻었지만, 3차원 위치와 속도 벡터에서 곧바로 궤도를 읽어 내는 방법이 있을까?

먼저 알아야 할 것상대 운동 방정식(1.1절), 벡터의 외적과 미분, 천우3의 극좌표 유도(천우3 3.1절)를 쓴다.

공학 궤도역학에서는 보존되는 벡터 두 개를 찾아 궤도 방정식을 짧고 3차원에 바로 쓸 수 있게 유도한다. 이 벡터들은 나중에 위치와 속도에서 궤도요소를 계산하는 데(3.1절) 그대로 쓰인다.

외적과 내적을 처음 본다면 다음 규칙만 알면 된다. 두 벡터 \(\vec a = (a_1, a_2, a_3)\), \(\vec b = (b_1, b_2, b_3)\)의 내적 \(\vec a\cdot\vec b = a_1b_1 + a_2b_2 + a_3b_3 = |\vec a||\vec b|\cos\theta\)는 숫자 하나이다. 외적 \(\vec a\times\vec b = (a_2b_3 - a_3b_2,\ a_3b_1 - a_1b_3,\ a_1b_2 - a_2b_1)\)은 두 벡터에 모두 수직인 벡터이고, 크기는 두 벡터가 만드는 평행사변형의 넓이 \(|\vec a||\vec b|\sin\theta\)이다. 같은 벡터끼리의 외적은 0이다(\(\sin0 = 0\)). 궤도면 위에서만 보면 \(h = |\vec r\times\dot{\vec r}| = r\,v_\perp\)(거리와 속도의 옆 방향 성분의 곱)이고, 이는 케플러 제2법칙의 면적 속도의 2배이다. 아래 유도는 이 계산 규칙만으로 따라갈 수 있다.

1.2.1비각운동량

\(\vec h = \vec r\times\dot{\vec r}\)을 미분하면 \(\dot{\vec h} = \dot{\vec r}\times\dot{\vec r} + \vec r\times\ddot{\vec r} = 0 + \vec r\times(-\mu\vec r/r^3) = 0\)이다. 그러므로 \(\vec h\)는 일정하고, \(\vec r\)과 \(\dot{\vec r}\)은 늘 \(\vec h\)에 수직인 한 평면, 곧 궤도면에 있다.

1.2.2이심률 벡터

유도. 운동 방정식에 \(\vec h\)를 외적한다. \(\vec h\)가 일정하므로 왼쪽은 \(\ddot{\vec r}\times\vec h = \frac{d}{dt}(\dot{\vec r}\times\vec h)\)이다. 오른쪽은 벡터 삼중곱 공식과 \(\vec r\cdot\dot{\vec r} = r\dot r\), \(\frac{d}{dt}(\vec r/r) = \dot{\vec r}/r - \vec r\dot r/r^2\)을 써서 다음과 같이 정리된다.

\[ -\frac{\mu}{r^3}\vec r\times(\vec r\times\dot{\vec r}) = -\frac{\mu}{r^3}\left[\vec r(\vec r\cdot\dot{\vec r}) - \dot{\vec r}r^2\right] = \mu\frac{d}{dt}\left(\frac{\vec r}{r}\right) \]

두 쪽을 적분하면 \(\dot{\vec r}\times\vec h = \mu\vec r/r + \vec C\)이고, 상수 벡터를 \(\vec C = \mu\vec e\)로 두면 아래의 \(\vec e\)가 일정하다. 이것을 이심률 벡터라 한다. ∎

\[ \vec e = \frac{\dot{\vec r}\times\vec h}{\mu} - \frac{\vec r}{r} \]

1.2.3궤도 방정식

유도. 위 식에 \(\vec r\)을 내적하면 \(\vec r\cdot(\dot{\vec r}\times\vec h) = \mu r + \mu\vec r\cdot\vec e\)이다. 왼쪽은 스칼라 삼중곱의 순환으로 \((\vec r\times\dot{\vec r})\cdot\vec h = h^2\)이다. \(\vec r\)과 \(\vec e\) 사이의 각을 진근점 이각 \(\nu\)라 하면 \(\vec r\cdot\vec e = re\cos\nu\)이므로 \(h^2 = \mu r(1 + e\cos\nu)\)이다. ∎

\[ r = \frac{h^2/\mu}{1 + e\cos\nu} \]

\(\nu = 0\)에서 \(r\)이 가장 작으므로 이심률 벡터는 근점 방향을 가리키고, 그 크기가 이심률이다(그림 1). 원뿔곡선의 반직현은 \(p = h^2/\mu\)이다. 결과는 천우3과 같지만, 이제 처음 질문처럼 위치와 속도 벡터만 알면 \(\vec h\), \(\vec e\), \(p\)를 곧바로 계산할 수 있다.

예제 1.2.1

처음 질문의 위성에서 \(\vec h\), 이심률 벡터, 근점 거리를 구하여라.

풀이. \(\vec h = \vec r\times\dot{\vec r} = (0\cdot1.0 - 0\cdot7.5,\ 0\cdot0 - 7000\cdot1.0,\ 7000\cdot7.5 - 0) = (0, -7000, 52500)\)이고 \(h = 52{,}965\) km²/s이다. 다음으로 \(\dot{\vec r}\times\vec h = (7.5\cdot52500 - 1.0\cdot(-7000),\ 0,\ 0) = (400{,}750, 0, 0)\)이므로 \(\vec e = (400{,}750/398{,}600 - 1, 0, 0) = (0.00539, 0, 0)\)이다. 따라서 이심률 0.0054의 거의 원인 궤도이고, \(\vec e\)가 \(\vec r\)과 같은 방향이므로 지금 근점에 있다. 근점 거리는 \(p/(1+e) = (52965^2/398600)/1.00539 \approx 7{,}000\) km로 현재 위치와 같다.

주의원 궤도(\(e = 0\))에서는 이심률 벡터가 0이라 근점 방향과 진근점 이각이 정해지지 않는다. 이때는 승교점에서 잰 각(위도 인수)을 대신 쓴다(3.1절).
마무리

비각운동량 \(\vec h = \vec r\times\dot{\vec r}\)이 보존되므로 운동은 한 평면에서 일어난다. 이심률 벡터 \(\vec e = \dot{\vec r}\times\vec h/\mu - \vec r/r\)도 보존되며, 근점을 가리키고 크기가 이심률이다. 둘에서 궤도 방정식 \(r = (h^2/\mu)/(1 + e\cos\nu)\)이 나오므로, 위치와 속도 벡터만 알면 궤도의 모양과 현재 위치를 곧바로 계산할 수 있다.

1.2.4연습문제

기본

  1. 반지름 \(r\)인 원 궤도에서 \(h\)는 무엇인가?
    답

    원 궤도 속력이 \(\sqrt{\mu/r}\)이므로 \(h = rv = \sqrt{\mu r}\)이다.

응용

  1. \(\vec r = (8000, 0, 0)\) km, \(\dot{\vec r} = (0, 6.0, 0)\) km/s의 이심률과 지금의 위치(근점 또는 원점)를 구하여라.
    답

    \(h = 48{,}000\)이고 \(\vec e = (6.0\cdot48000/398600 - 1, 0, 0) = (-0.277, 0, 0)\)이다. \(\vec e\)가 \(\vec r\)의 반대 방향이므로 지금 원점에 있고, 이심률은 0.277이다.

  2. \(|\vec e|^2 = 1 + 2\varepsilon h^2/\mu^2\)을 쓰면, 궤도 에너지 \(\varepsilon\)이 0일 때 이심률은 얼마인가?
    답

    1이므로 포물선 궤도이다(1.3절).
