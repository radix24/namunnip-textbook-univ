재결합과 탈결합의 시기를 Saha 식으로 어림하기

본문 · 4.3절
이 절에서 배울 것
  • 수소 전리 평형의 사하 식을 우주에 적용한다.
  • 전리 비율이 0.5가 되는 재결합 적색이동을 계산한다.
  • 재결합과 광자 탈결합의 차이를 안다.
먼저 알아야 할 것
  • 사하 식 (천우4 1.1절), 복사 시대의 온도 (4.1절).

우주가 투명해진 순간

뜨거운 초기 우주에서 수소는 양성자와 전자로 나뉘어 있었고, 자유 전자가 광자를 끊임없이 산란시켜 우주는 불투명했습니다. 온도가 내려가 전자가 양성자에 붙잡히자(재결합) 광자가 자유롭게 날아가게 되었고, 그 빛이 오늘의 우주배경복사입니다.

4.3.1우주의 사하 식

천우4 1.1절의 사하 식을 바리온-광자 비 \(\eta = n_b/n_\gamma\)로 쓰면, 수소 전리 비율 \(X = n_p/(n_p + n_H)\)에 대해

\[ \frac{1 - X}{X^2} = 3.84\,\eta\left(\frac{kT}{m_ec^2}\right)^{3/2}\exp\left(\frac{Q}{kT}\right), \qquad Q = 13.6\text{ eV} \]

입니다(Ryden 교재의 꼴). \(T = 2.7255(1 + z)\) K를 넣어 \(X\)를 \(z\)의 함수로 풉니다.

예제 4.3.1 (아래 실습 카드 결과, \(\eta = 6.1\times10^{-10}\))

\(X = 0.5\)가 되는 적색이동과 온도는?

풀이. \(z = 1379\), \(T = 3{,}760\) K, \(kT = 0.324\) eV입니다. 13.6 eV보다 40배나 낮은 온도에서야 재결합하는 까닭은 광자가 바리온보다 약 16억 배 많아, 평균보다 훨씬 에너지가 큰 꼬리의 광자만으로도 막 생긴 수소를 다시 전리하기 때문입니다. \(X = 0.9\)는 \(z = 1481\), \(X = 0.1\)은 \(z = 1260\)으로 재결합은 비교적 짧은 기간에 일어납니다.

4.3.2탈결합과 마지막 산란

광자가 전자와 산란하는 빈도(\(\Gamma = n_e\sigma_Tc\))가 팽창률 \(H\)보다 작아지면 광자가 물질과 떨어집니다(탈결합). 자유 전자가 충분히 줄어야 하므로 재결합보다 조금 늦은 \(z \approx 1090\)(우주 나이 약 38만 년)입니다. 우리가 보는 우주배경복사는 이 '마지막 산란면'에서 온 빛입니다.

주의 사하 식은 평형을 가정합니다. 실제 재결합은 바닥 상태로 바로 떨어질 때 나오는 라이먼 광자가 다른 원자를 다시 들뜨게 해 평형보다 늦게 진행되므로, 정밀 계산(Peebles 3준위 모형, RECFAST)은 \(z \approx 1100\) 근처를 줍니다.
요약
  1. 우주의 사하 식: \((1 - X)/X^2 = 3.84\eta(kT/m_ec^2)^{3/2}e^{Q/kT}\).
  2. \(\eta = 6.1\times10^{-10}\): \(X = 0.5\)는 \(z = 1379\), \(T = 3{,}760\) K(0.32 eV).
  3. 광자가 바리온보다 훨씬 많아 13.6 eV보다 훨씬 낮은 온도에서 재결합.
  4. 탈결합·마지막 산란 \(z \approx 1090\)(38만 년). 평형 밖 효과로 실제는 조금 늦다.

4.3.3연습문제

기본

  1. \(z = 1379\)일 때 우주의 크기는 오늘의 몇 분의 1?
    답

    1/1380.

  2. 재결합 전 우주가 불투명했던 까닭은?
    답

    자유 전자가 광자를 톰슨 산란으로 계속 흩뜨렸기 때문입니다.

응용

  1. η를 10⁻⁹로 키우면 재결합 적색이동은 어떻게 됩니까?
    답

    광자 대비 바리온이 많아 조금 일찍(z ≈ 1396) 재결합합니다.

  2. 마지막 산란면(z = 1090)의 온도는?
    답

    \(2.7255\times1091 = 2{,}970\) K.
