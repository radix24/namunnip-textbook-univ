밀도 매개변수로 팽창 역사와 우주 나이 계산하기

본문 · 2.3절
이 절에서 배울 것
  • \(t_0 = \int_0^1 da/(aH)\)로 우주 나이를 계산한다.
  • 여러 우주 모형의 나이를 비교한다.
  • 허블 상수와 나이의 관계, 구상성단 나이와의 비교를 안다.
먼저 알아야 할 것
  • 프리드만 방정식 (2.1절), 성분별 밀도 (2.2절), 구상성단 나이 (천우9 6.3절).

우주는 몇 살인가

척도 인자가 0에서 1까지 자라는 데 걸린 시간이 우주 나이입니다. \(H = \dot a/a\)(\(\dot a = da/dt\))에서 \(dt = da/(aH)\)이므로

\[ t_0 = \int_0^1\frac{da}{aH(a)} = \frac1{H_0}\int_0^1\frac{da}{\sqrt{\Omega_r/a^2 + \Omega_m/a + \Omega_k + \Omega_\Lambda a^2}} \]

입니다. 적분값이 1보다 작으면 허블 시간보다 젊고(과거에 더 빨리 팽창, 감속), 크면 늙었습니다(가속).

2.3.1모형별 나이

예제 2.3.1 (3.1절 실습 카드로 계산, \(H_0 = 70\), 복사 무시)

여러 모형의 나이를 비교하세요.

  • 평탄 물질(\(\Omega_m = 1\)): 9.31 Gyr(\(= \frac23\times13.97\)).
  • 열린 물질(\(\Omega_m = 0.3\)): 11.30 Gyr.
  • 거의 빈 우주(\(\Omega_m = 0.05\)): 13.06 Gyr(빈 우주면 허블 시간 13.97).
  • ΛCDM(\(\Omega_m = 0.3\), \(\Omega_\Lambda = 0.7\)): 13.47 Gyr. \(H_0 = 67\)이면 14.07 Gyr.

플랑크 위성의 값(\(H_0 = 67.4\), \(\Omega_m = 0.315\))으로는 13.8 Gyr입니다. 가장 오래된 구상성단(12~13 Gyr)보다 늙어 모순이 없습니다(천우9 6.3절). 물질만 있는 평탄 우주는 9.3 Gyr로 별보다 젊어 배제됩니다.

2.3.2팽창 역사

  • 복사 시대: \(a \propto t^{1/2}\)(처음 약 5만 년).
  • 물질 시대: \(a \propto t^{2/3}\), 감속.
  • 암흑 에너지 시대: \(a\)가 지수 함수에 가까워지며 가속.

천우4 6.1절의 탐구 카드에서 밀도 매개변수를 바꾸며 \(a(t)\) 곡선을 직접 볼 수 있습니다.

주의 허블 상수 측정값이 방법에 따라 다르다(초신성 거리 사다리 약 73, 우주배경복사 약 67, 허블 긴장). 나이는 \(1/H_0\)에 비례하므로 이 차이는 나이를 약 1 Gyr 바꿉니다.
요약
  1. \(t_0 = \int_0^1 da/(aH)\).
  2. \(H_0 = 70\): 평탄 물질 9.31, 열린 물질(0.3) 11.30, ΛCDM 13.47 Gyr.
  3. 플랑크 값으로 13.8 Gyr, 구상성단 나이와 맞는다.
  4. 복사 \(t^{1/2}\) → 물질 \(t^{2/3}\) → 암흑 에너지(지수적).

2.3.3연습문제

기본

  1. 나이 적분값이 0.96이고 \(H_0 = 70\)이면 나이는?
    답

    13.4 Gyr.

  2. 감속만 해 온 우주는 허블 시간보다 젊습니까, 늙었습니까?
    답

    젊습니다(과거에 더 빨리 팽창했으므로).

응용

  1. ΛCDM에서 \(H_0\)를 70에서 73으로 바꾸면 나이는?
    답

    \(13.47\times70/73 = 12.9\) Gyr.

  2. 평탄 물질 우주가 13 Gyr이려면 \(H_0\)는?
    답

    \(\frac23\times977.8/13 = 50\) km/s/Mpc.
