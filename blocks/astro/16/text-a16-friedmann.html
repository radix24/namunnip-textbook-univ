뉴턴 역학으로 프리드만 방정식 유도하기

본문 · 2.1절

우주의 팽창을 다루는 프리드만 방정식은 일반상대론에서 나온다. 그런데 위로 던진 공이 다시 떨어질지, 탈출할지를 정하는 고교 물리의 에너지 보존과 같은 꼴이라면 어떨까? 일반상대론 없이 뉴턴 역학만으로 우주의 팽창을 얼마나 설명할 수 있을까?

먼저 알아야 할 것곡률과 임계 밀도(1.3절)와 프리드만 우주 입문(천우4 6.1절)을 쓴다.

처음 질문의 답은 거의 전부라는 것이다. 균질한 우주에서 아무 점을 중심으로 공을 생각하면, 공 바깥의 물질은 대칭이라 공 안에 알짜 힘을 주지 않는다. 그러므로 공 껍질 하나의 운동만 보면 되고, 그 에너지 보존이 프리드만 방정식과 같은 꼴이 된다(그림 1). 다만 곡률 항의 해석은 일반상대론이 필요하다. 또 \(H = \dot a/a\)는 척도 인자가 1초에 자기 크기의 몇 분의 1만큼 커지는지를 뜻한다.

2.1.1유도

유도. 밀도 \(\rho(t)\)인 균질한 우주에서 반지름 \(R(t) = a(t)r_s\)인 공 껍질 위의 질량 \(m\)을 생각하자. 껍질 안의 질량 \(M = \tfrac43\pi R^3\rho\)는 팽창해도 일정하다. 껍질의 역학적 에너지는 보존되므로 다음이 성립한다.

\[ \frac12 m\dot R^2 - \frac{GMm}{R} = U \quad(\text{일정}) \]

\(R = ar_s\), \(M = \tfrac43\pi\rho a^3 r_s^3\)를 넣고 \(\tfrac12 m r_s^2 a^2\)로 나누면 다음을 얻는다.

\[ \left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho + \frac{2U}{m r_s^2}\frac{1}{a^2} \quad\Longrightarrow\quad H^2 = \frac{8\pi G}{3}\rho - \frac{kc^2}{R_0^2 a^2} \]

일반상대론에서는 \(-kc^2/R_0^2\)가 공간 곡률이고(\(k = +1, 0, -1\), \(R_0\)는 곡률 반지름), \(\rho\)는 질량만이 아니라 모든 에너지 밀도 \(\varepsilon/c^2\)이다. ∎

그러므로 \(U < 0\)이면 껍질이 묶여 있으므로 \(k = +1\)인 닫힌 우주이다. \(U = 0\)이면 탈출 속도와 같으므로 \(k = 0\)인 평탄한 우주이며, \(H^2 = 8\pi G\rho/3\)에서 임계 밀도가 나온다. \(U > 0\)이면 \(k = -1\)인 열린 우주이다(그림 1).

2.1.2밀도 매개변수로 쓰기

오늘의 값으로 나누면 \(H^2/H_0^2 = \Omega(a) + (1 - \Omega_0)/a^2\)이다. 이를 성분별로 나누면(2.2절) 다음과 같다.

\[ \frac{H^2}{H_0^2} = \frac{\Omega_r}{a^4} + \frac{\Omega_m}{a^3} + \frac{\Omega_k}{a^2} + \Omega_\Lambda \]

2.1.3유체 방정식과 가속 방정식

팽창하는 부피가 압력 \(P\)로 일을 한다는 열역학 제1법칙에서 유체 방정식 \(\dot\varepsilon + 3H(\varepsilon + P) = 0\)이 나온다. 이를 프리드만 방정식과 합치면 가속 방정식을 얻는다.

\[ \frac{\ddot a}{a} = -\frac{4\pi G}{3c^2}\left(\varepsilon + 3P\right) \]

보통 물질과 복사는 \(\varepsilon + 3P > 0\)이라 팽창을 늦춘다. 따라서 팽창이 빨라지려면 \(P < -\varepsilon/3\)인 음의 압력 성분, 곧 암흑 에너지가 필요하다.

예제 2.1.1

평탄한 물질 우주(\(\rho \propto a^{-3}\))에서 \(a(t)\)를 구하라.

풀이. \(\dot a^2 = (8\pi G\rho_0/3)a^{-1} = H_0^2 a^{-1}\)이므로 \(a^{1/2}da = H_0\,dt\)이고, 적분하면 \(\tfrac23 a^{3/2} = H_0 t\)이다. 곧 \(a = (3H_0t/2)^{2/3}\)이고, 오늘(\(a = 1\))의 나이는 \(t_0 = 2/(3H_0) = 9.3\) Gyr(\(H_0 = 70\))이다.

주의

뉴턴 유도는 압력이 중력의 원천이 된다는 사실(\(\varepsilon + 3P\))과 곡률의 기하학적 의미를 설명하지 못한다. 이 부분은 일반상대론이 필요하다.

마무리

껍질의 에너지 보존에서 \(H^2 = \tfrac{8\pi G}{3}\rho - kc^2/(R_0^2 a^2)\)가 나오며, 성분별로 \(H^2/H_0^2 = \Omega_r a^{-4} + \Omega_m a^{-3} + \Omega_k a^{-2} + \Omega_\Lambda\)이다. 유체 방정식은 \(\dot\varepsilon + 3H(\varepsilon + P) = 0\), 가속 방정식은 \(\ddot a/a \propto -(\varepsilon + 3P)\)이다. 평탄 물질 우주는 \(a \propto t^{2/3}\), 나이 \(2/(3H_0)\)이다.

2.1.4연습문제

기본

  1. 가속 팽창에 필요한 조건은 무엇인가?
    답

    \(P < -\varepsilon/3\)인 성분이 우세해야 한다.

응용

  1. 평탄한 복사 우주(\(\rho \propto a^{-4}\))의 \(a(t)\)를 구하라.
    답

    \(\dot a^2 \propto a^{-2}\)이므로 \(a\,da \propto dt\)이고, \(a \propto t^{1/2}\)이다.

  2. 우주 상수만 있는 평탄한 우주의 \(a(t)\)는 어떤가?
    답

    \(H\)가 일정하므로 \(a \propto e^{Ht}\)로 지수적으로 팽창한다.
