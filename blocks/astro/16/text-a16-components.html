물질, 복사, 우주 상수의 밀도 변화

본문 · 2.2절
이 절에서 배울 것
  • 상태 방정식 \(P = w\varepsilon\)에서 \(\varepsilon \propto a^{-3(1+w)}\)를 유도한다.
  • 물질 \(a^{-3}\), 복사 \(a^{-4}\), 우주 상수 일정의 까닭을 설명한다.
  • 물질-복사 같음, 물질-암흑 에너지 같음, 가속 시작의 시기를 계산한다.
먼저 알아야 할 것
  • 프리드만 방정식과 유체 방정식 (2.1절).

팽창하면 묽어지는 방식이 다르다

우주가 팽창하면 모든 성분이 묽어지지만 그 빠르기가 다릅니다. 그래서 우주의 역사는 복사가 지배하던 시대, 물질이 지배하던 시대, 암흑 에너지가 지배하는 지금으로 나뉩니다.

2.2.1상태 방정식과 밀도 변화

유도. \(P = w\varepsilon\)이면 유체 방정식 \(\dot\varepsilon + 3\frac{\dot a}{a}(1 + w)\varepsilon = 0\)에서 \(\frac{d\ln\varepsilon}{d\ln a} = -3(1 + w)\), 곧 \[ \varepsilon \propto a^{-3(1 + w)} \] 입니다. ∎

  • 물질(\(w = 0\), 압력 무시): \(\varepsilon \propto a^{-3}\). 입자 수는 그대로이고 부피만 커진다.
  • 복사(\(w = 1/3\)): \(\varepsilon \propto a^{-4}\). 광자 수 밀도가 \(a^{-3}\)으로 줄고, 파장이 늘어 광자 하나의 에너지가 \(a^{-1}\)로 줄어든다. 온도는 \(T \propto a^{-1}\).
  • 우주 상수(\(w = -1\)): \(\varepsilon\) 일정. 공간 자체의 에너지라 팽창해도 묽어지지 않는다.

2.2.2시대의 경계

오늘의 값(플랑크에 가까운 어림) \(\Omega_r \approx 9\times10^{-5}\)(광자 + 중성미자), \(\Omega_m \approx 0.3\), \(\Omega_\Lambda \approx 0.7\)로 계산합니다.

예제 2.2.1

물질-복사 같음, 물질-우주 상수 같음, 가속이 시작된 시기의 적색이동은?

  • 물질 = 복사: \(\Omega_r/a^4 = \Omega_m/a^3\)에서 \(a = \Omega_r/\Omega_m = 3\times10^{-4}\), \(z \approx 3{,}300\)(정밀 값 약 3,400).
  • 물질 = 우주 상수: \(a = (\Omega_m/\Omega_\Lambda)^{1/3} = 0.75\), \(z = 0.33\).
  • 가속 시작(\(\ddot a = 0\)): 물질의 \(\varepsilon + 3P = \varepsilon_m\)과 우주 상수의 \(-2\varepsilon_\Lambda\)가 같을 때, \(a = (\Omega_m/2\Omega_\Lambda)^{1/3} = 0.60\), \(z = 0.67\).

우주는 약 60억 년 전부터 가속 팽창하고 있습니다.

주의 암흑 에너지가 정말 우주 상수(\(w = -1\) 정확히)인지는 열린 질문입니다. 최근 DESI 바리온 음향 진동 결과는 \(w\)가 시간에 따라 변할 가능성을 시사해 활발히 연구되고 있습니다.
요약
  1. \(P = w\varepsilon\) → \(\varepsilon \propto a^{-3(1+w)}\).
  2. 물질 \(a^{-3}\), 복사 \(a^{-4}\)(\(T \propto 1/a\)), 우주 상수 일정.
  3. 물질-복사 같음 \(z \approx 3{,}300\), 물질-Λ 같음 \(z = 0.33\), 가속 시작 \(z = 0.67\).
  4. 암흑 에너지의 \(w\)가 정확히 −1인지는 열린 질문.

2.2.3연습문제

기본

  1. \(a = 0.1\)일 때 물질 밀도는 오늘의 몇 배?
    답

    1,000배.

  2. \(a = 0.1\)일 때 복사 온도는?
    답

    27.3 K.

응용

  1. \(\Omega_m = 0.315\), \(\Omega_\Lambda = 0.685\)이면 가속 시작 적색이동은?
    답

    \((0.315/1.37)^{1/3} = 0.612\), \(z = 0.63\).

  2. \(w = -1/3\)인 성분의 밀도는 \(a\)에 어떻게 비례하고 팽창을 가속합니까?
    답

    \(a^{-2}\). \(\varepsilon + 3P = 0\)이라 가속도 감속도 하지 않습니다(곡률 항과 같은 꼴).
