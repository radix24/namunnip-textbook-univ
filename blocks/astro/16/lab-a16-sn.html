가상 Ia형 초신성 허블 도표로 가속 팽창 찾기

실습 · 허블 도표

목표

가상 Ia형 초신성 60개의 허블 도표에 여러 우주 모형을 맞춰 χ²를 비교하고, 감속 매개변수의 부호를 판단합니다. 성취기준 [천우16-03-02].

준비

가상 자료: ΛCDM(Ω_m = 0.3, Ω_Λ = 0.7, H₀ = 70)에서 z = 0.02~1.3에 고르게 뽑은 60개, 거리 지수 오차 0.12등급. 세로축은 빈 우주(Ω = 0)의 거리 지수를 뺀 Δμ입니다. H₀는 70으로 고정합니다(실제 연구에서는 H₀와 초신성 절대 등급이 함께 묶여 지워짐).

절차

  1. 처음 모형(Ω_m = 1, Ω_Λ = 0)의 χ²와 Δμ를 봅니다.
  2. Ω_m = 0.3, Ω_Λ = 0으로 바꿉니다.
  3. Ω_Λ를 올려 χ²가 가장 작은 조합을 찾고 q₀의 부호를 확인합니다.
  4. Ω_m = 0, Ω_Λ = 0(빈 우주)과 비교합니다.

기대 결과

  • 평탄 물질: χ² = 983.6, z = 0.5에서 −0.276등급(밝음), q₀ = 0.50.
  • 열린 물질(0.3, 0): χ² = 248.1, −0.092. 빈 우주: 80.3, 0.
  • ΛCDM(0.3, 0.7): χ² = 58.9, +0.123(어두움), q₀ = −0.55. (0.2, 0.6)도 58.7로 비슷하다: Ω_m과 Ω_Λ가 엇갈려 있다.
  • (0.5, 0.5): 182.1. (0.3, 1.0): 122.8.

분석

  1. 초신성만으로 Ω_m과 Ω_Λ를 따로 정하기 어려운 까닭은? χ²가 비슷한 조합들이 어느 방향으로 늘어서 있습니까?
  2. 빈 우주보다 ΛCDM이 더 잘 맞는다는 것이 가속 팽창의 증거가 되는 까닭은?
  3. 우주배경복사의 평탄성(Ω_m + Ω_Λ ≈ 1)을 함께 쓰면 어떤 조합이 남습니까?
