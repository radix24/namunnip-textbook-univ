자료 공개와 기록 보관소가 낳는 발견

본문

허블 우주망원경으로 쓴 논문의 절반 안팎은 관측을 제안한 사람이 아니라, 몇 해 뒤 기록 보관소에서 자료를 내려받은 다른 연구자가 썼다. 한 번 찍은 영상이 어떻게 여러 번 발견을 낳을까? 그리고 관측한 사람에게 자료를 얼마 동안 독점하게 해야 할까?

먼저 알아야 할 것기술의 확산(6.1절), 새 기술과 발견(6.2절), 자료 전송(5.2절)을 쓴다.

6.3.1독점 기간과 공개

관측 제안이 뽑힌 연구자는 보통 일정 기간, 흔히 12개월 동안 자료를 혼자 쓸 수 있고, 그 뒤에는 누구나 기록 보관소에서 내려받는다. 그런데 TESS와 가이아 같은 전천 탐사 미션은 독점 기간 없이 정해진 일정에 따라 모두에게 공개하며, 변하는 천체의 경보는 실시간으로 공개하는 쪽으로 바뀌어 왔다. 세금으로 만든 자료를 빨리, 많은 사람이 쓰게 해 과학 성과를 키운다는 생각이다.

6.3.2보관소가 더하는 몫

처음 질문의 첫째 부분을 간단한 모형으로 따져 보자. 관측 한 건이 독점 연구자의 논문 \(P_0\)편을 낳고, 공개 뒤 해마다 다른 연구자들이 평균 \(r\)편씩 \(T\)년 동안 쓴다고 하자.

결과 6.3.1 (간단한 모형) \[\text{전체} = P_0 + rT, \qquad \text{보관소의 몫} = \frac{rT}{P_0 + rT}\]

예를 들어 \(P_0 = 1\), \(r = 0.1\)/년, \(T = 20\)년이면 보관소가 2편을 더해 전체의 3분의 2가 된다(그림 1). 실제로 허블에서는 보관소 자료를 쓴 논문이 전체의 절반 안팎에 이른다고 보고된다. 그러므로 오래 운영된 미션일수록 보관소의 몫이 커진다.

6.3.3보관소를 쓸 수 있게 하는 것

하지만 자료를 올려 두기만 해서는 다른 사람이 쓰지 못한다. 세 가지가 필요하다. 첫째는 보정된 자료이다. 원자료만 있으면 기기를 잘 아는 사람만 쓸 수 있으므로, 미션 팀이 바이어스, 플랫, 좌표, 측광 보정 같은 표준 처리를 마친 자료와 목록을 함께 내놓는다. 둘째는 메타데이터이다. 언제, 어디를, 어떤 거름판과 노출로 찍었는지 검색할 수 있어야 한다(FITS 머리말, 천우13 1.2절). 셋째는 여러 미션의 자료를 같은 방식으로 찾고 겹쳐 볼 수 있게 하는 가상 천문대 표준이다.

6.3.4예상하지 못한 발견

보관소 자료는 원래 목적과 다른 질문에 답하곤 한다. 다른 목적으로 찍은 영상에서 빠르게 움직이는 소행성이나 변광 천체를 찾아내고, 여러 해의 영상을 이어 별의 고유 운동을 재며, 새로 발견된 초신성의 폭발 전 모습을 옛 영상에서 찾는다. 특히 시간 영역 천문학에서는 같은 곳을 예전에 찍어 둔 영상이 그 자체로 귀중한 자료가 된다. 처음 질문의 둘째 부분은 이 득과 제안자의 동기 사이의 저울질이다.

예제 6.3.1

위 모형에서 독점 기간을 12개월에서 0으로 줄이면 보관소 이용이 1년 일찍 시작해 \(T\)가 1년 늘어난다고 하자. 전체 논문은 몇 % 늘어나는가?

풀이. \(1 + 0.1\times20 = 3.0\)에서 \(1 + 0.1\times21 = 3.1\)로 3.3% 늘어난다. 대신 독점 연구자의 동기가 줄 수 있으므로, 공개 정책은 이런 득실을 함께 따진다.

주의오랜 시간을 들여 설계한 어려운 관측은 제안자가 자료를 가장 잘 이해한다. 공개가 너무 빠르면 그런 관측을 제안할 동기가 줄어들 수 있으므로, 독점 기간에도 나름의 쓸모가 있다.
마무리

관측 자료는 독점 기간 뒤 기록 보관소에 공개되며, 전천 탐사는 즉시 공개로 바뀌어 왔다. 공개 뒤 다른 연구자들이 해마다 논문을 더하므로 보관소의 몫 \(rT/(P_0 + rT)\)은 오래 운영될수록 커져, 허블에서는 논문의 절반 안팎에 이른다. 보정된 자료, 메타데이터, 표준이 갖춰져야 다른 사람이 쓸 수 있고, 그러면 한 번 찍은 영상이 소행성, 고유 운동, 초신성 이전 모습처럼 원래 목적과 다른 발견을 여러 번 낳는다.

6.3.5연습문제

기본

  1. \(P_0 = 2\), \(r = 0.05\)/년, \(T = 20\)년이면 보관소의 몫은 얼마인가?
    답

    \(1/(2 + 1) = 33\%\)이다.

  2. 원자료만 공개하고 처리 소프트웨어를 공개하지 않으면 어떤 문제가 있는가?
    답

    기기 특성을 모르는 연구자는 보정을 다시 하기 어려워 자료를 쓰지 못하거나, 서로 다른 방식으로 보정해 결과를 비교할 수 없다.

응용

  1. 미션 비용이 10억 달러이고 독점 연구자의 논문만 3000편이라면 논문 한 편당 비용은 얼마인가? 보관소 논문이 같은 수만큼 더해지면 어떻게 되는가?
    답

    33만 달러에서 17만 달러로 절반이 된다. 전체 비용의 몇 %인 보관소 운영비보다 효과가 훨씬 크다.
