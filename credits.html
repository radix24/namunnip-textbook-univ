출처와 라이선스

QURI의 과목 설계, 대단원, 성취기준, 본문과 카드, 연습 문항, 그림은 QURI가 직접 만들었습니다. 이 페이지에는 바깥에서 가져오거나 참고한 자료를 모았습니다.

과목 정보

과목명, 학년·학기, 학점, 종별, 졸업 요건은 국내 대학이 공개한 대학요람, 수강편람, 강의계획서를 바탕으로 QURI가 정리했습니다. 학교의 공식 안내가 아니므로, 실제 수강과 졸업 판단은 소속 학교의 안내를 따라 주세요.

참고한 공개 교재

단원 범위, 정의, 표기, 표준적인 예를 확인할 때 아래처럼 공개 라이선스로 배포되거나 저자가 무료로 공개한 교재와 강의 노트를 참고했습니다. 문장, 예제, 그림은 옮기지 않았습니다. 공개 교재의 내용을 고쳐 쓴 카드에는 카드 끝에 원본의 제목, 저작자, 라이선스를 적었습니다.

  • OpenStax (Rice University) — CC BY 4.0
  • LibreTexts — 책마다 표시된 라이선스
  • MIT OpenCourseWare — CC BY-NC-SA 4.0
  • OpenIntro Statistics — 원본에 표시된 라이선스
  • Sheldon Axler, Linear Algebra Done Right, 4판 — CC BY-NC 4.0
  • Jim Hefferon, Linear Algebra — 원본에 표시된 라이선스
  • 그 밖에 저자가 공식 사이트에 공개한 교재와 강의 노트 — 카드마다 따로 적음

카드 형식을 빌린 곳

아래 학습 서비스에서는 카드의 짜임만 빌렸고 내용은 가져오지 않았습니다.

  • 예제의 의미 칸, 문제 해결 전략 상자, 결과를 따져 보는 문제: OpenStax
  • 개념 절로 돌아가는 힌트: Isaac Physics
  • 먼저 예측해 보기: Brilliant
  • 오개념으로 만든 확인 문제: Eric Mazur의 ConcepTest(Peer Instruction)

설명 방식을 참고한 곳

개념을 설명하는 순서, 직관을 먼저 보여 주는 방법, 그림으로 뜻을 드러내는 방식은 아래 자료를 참고했습니다. 문장, 예제, 그림, 코드는 가져오지 않고 모두 새로 썼습니다. 특정 글의 설명 방식에 크게 기댄 카드에는 그 글의 링크를 카드 안에 함께 적었습니다.

  • 공돌이의 수학정리노트 (angeloyeo.github.io)

더 읽을거리

3학년 이상 대단원의 "더 읽을거리"에는 논문과 프리프린트의 서지 정보만 적고, 원문은 출판사나 arXiv의 공식 주소로 연결했습니다. 각 문헌의 저작권은 저자와 출판사에 있습니다.
