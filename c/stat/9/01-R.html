1.R.1

연습조건부확률과 조건부기대값 단원 마무리 연습

문제 6 · 계산·판단 · 힌트 2단계

다루는 성취기준 [응통9-01-01] [응통9-01-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산하루 손님 수 \(N\)이 평균 20인 포아송 분포를 따르고, 손님마다 쓰는 금액 \(X_i\)는 \(N\)과 독립이며 평균 15000원, 표준편차 5000원입니다. 하루 매출 \(S = \sum_{i=1}^N X_i\)의 평균과 분산을 구하세요. [01-01]

    힌트 1

    \(E(S) = E[E(S \mid N)] = E[N\mu]\)입니다.

    힌트 2

    \(\mathrm{Var}(S) = E[\mathrm{Var}(S \mid N)] + \mathrm{Var}(E(S \mid N)) = E(N)\sigma^2 + \mu^2\mathrm{Var}(N)\)입니다.

    풀이

    \(E(S) = 20\times15000 = 300000\)원입니다.

    \(\mathrm{Var}(S) = 20\times5000^2 + 15000^2\times20 = 20\times(2.5 + 22.5)\times10^7 = 5\times10^9\)이므로 표준편차는 약 70711원입니다. 포아송 \(N\)이면 \(\mathrm{Var}(S) = \lambda E(X^2)\)로도 계산됩니다. 매출의 흔들림은 금액의 흔들림보다 손님 수의 흔들림에서 더 많이 옵니다.

  2. 계산\(X \sim U(0, 1)\)이고, \(X = x\)가 주어지면 \(Y \sim U(0, x)\)입니다. \(E(Y)\)와 \(\mathrm{Var}(Y)\)를 조건부기대값의 성질로 구하세요. [01-01]

    힌트 1

    \(E(Y \mid X) = X/2\), \(\mathrm{Var}(Y \mid X) = X^2/12\)입니다.

    힌트 2

    전분산 공식 \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y \mid X)] + \mathrm{Var}(E(Y \mid X))\)를 씁니다.

    풀이

    \(E(Y) = E(X/2) = 1/4\)입니다.

    \(\mathrm{Var}(Y) = E(X^2)/12 + \mathrm{Var}(X)/4 = \frac{1}{36} + \frac{1}{48} = \frac{7}{144} \approx 0.0486\)입니다. 결합 밀도를 구해 적분하는 것보다 훨씬 간단합니다.

  3. 계산공정한 동전을 앞면이 두 번 연속 나올 때까지 던집니다. 던지는 횟수의 기댓값을 첫 단계 조건화로 구하세요. [01-02]

    힌트 1

    처음부터의 기댓값을 \(m\), "바로 앞이 앞면"인 상태에서의 기댓값을 \(m_1\)이라 놓으세요.

    힌트 2

    \(m = 1 + \frac12m_1 + \frac12m\), \(m_1 = 1 + \frac12\cdot0 + \frac12m\)입니다.

    풀이

    둘째 식에서 \(m_1 = 1 + m/2\), 첫째 식에 넣으면 \(m = 1 + \frac12(1 + m/2) + \frac m2\), 곧 \(\frac m4 = \frac32\), \(m = 6\)입니다.

    앞면 한 번이 나올 때까지의 기댓값은 2인데, 두 번 연속은 4가 아니라 6입니다. 중간에 뒷면이 나오면 처음으로 돌아가야 하기 때문입니다. 이런 문제는 "지금 어떤 상태인가"로 나누어 식을 세우는 것이 핵심입니다.

  4. 계산주사위 두 개를 반복해서 던져, 합이 6인 경우와 7인 경우 가운데 어느 것이 먼저 나오는지 봅니다. 6이 먼저 나올 확률을 구하세요. [01-02]

    힌트 1

    한 번 던질 때 합이 6일 확률은 5/36, 7일 확률은 6/36입니다.

    힌트 2

    둘 다 아니면 처음과 같은 상황으로 돌아갑니다. "6 또는 7이 나온 시행"으로 조건화하세요.

    풀이

    \(p = \frac{5}{36} + \big(1 - \frac{11}{36}\big)p\)에서 \(p = \frac{5/36}{11/36} = \frac{5}{11} \approx 0.455\)입니다.

    "6 또는 7이 처음 나오는 순간"으로 조건화하면, 그것이 6일 조건부확률이 \(5/11\)이라고 바로 볼 수도 있습니다.

  5. 계산동전을 던지는 횟수 \(N\)이 \(\mathrm{Poisson}(\lambda)\)이고, 각 동전은 독립으로 확률 \(p\)로 앞면입니다. 앞면 수 \(H\)의 분포를 \(N\)에 조건화해 구하세요. [01-02]

    힌트 1

    \(P(H = k) = \sum_{n \ge k}P(H = k \mid N = n)P(N = n)\)입니다.

    힌트 2

    \(m = n - k\)로 바꾸면 \(e^{\lambda(1-p)}\)의 급수가 나옵니다.

    풀이

    \(P(H = k) = \sum_{n\ge k}\binom nk p^k(1-p)^{n-k}e^{-\lambda}\frac{\lambda^n}{n!} = e^{-\lambda}\frac{(\lambda p)^k}{k!}\sum_{m\ge0}\frac{(\lambda(1-p))^m}{m!} = e^{-\lambda p}\frac{(\lambda p)^k}{k!}\)이므로 \(H \sim \mathrm{Poisson}(\lambda p)\)입니다.

    뒷면 수도 \(\mathrm{Poisson}(\lambda(1-p))\)이고, 놀랍게도 앞면 수와 독립입니다. 이것이 포아송 과정의 분해(응통9-05-02)의 핵심입니다.

  6. 판단"\(E(Y \mid X)\)는 숫자이다"라는 말을 평가하세요. \(E(Y \mid X = x)\)와 \(E(Y \mid X)\)는 어떻게 다른가요? [01-01]

    힌트 1

    \(E(Y \mid X = x)\)는 \(x\)를 넣으면 값이 정해지는 함수 \(g(x)\)입니다.

    힌트 2

    \(X\)에 확률변수 \(X\)를 넣으면 무엇이 되나요?

    풀이

    \(E(Y \mid X = x) = g(x)\)는 주어진 \(x\)에서의 숫자이지만, \(E(Y \mid X) = g(X)\)는 \(X\)의 함수이므로 확률변수입니다. 그래서 \(E[E(Y \mid X)]\)처럼 다시 기댓값을 취할 수 있고, 그 값이 \(E(Y)\)입니다(반복 기대값). 앞 문제들에서 \(E(Y \mid X) = X/2\)처럼 \(X\)가 들어간 식으로 다룬 것이 이 뜻입니다.
