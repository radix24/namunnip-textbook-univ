한 걸음씩 오르내리기

매번 확률 \(p\)로 1원을 따고 \(q = 1-p\)로 1원을 잃는 게임에서 가진 돈의 변화가 단순 랜덤워크입니다. 주가 모형, 확산, 대기열의 기초가 됩니다.

2.1.1정의

정의 2.1.1

단순 랜덤워크: \(S_n = S_0 + X_1 + \cdots + X_n\), \(X_i\)는 독립이고 \(P(X_i = 1) = p\), \(P(X_i = -1) = q\). \(p = 1/2\)이면 대칭 랜덤워크.

\(E(S_n - S_0) = n(p - q)\), \(\mathrm{Var} = 4npq\). 대칭이면 평균은 0이지만 표준편차는 \(\sqrt n\)으로 커져 출발점에서 점점 멀리 퍼집니다.

2.1.2도박꾼의 파산

\(k\)원에서 시작해 \(N\)원이 되거나 0원이 되면 멈춥니다. \(N\)원에 먼저 도달할 확률 \(P_k\)는 첫 걸음으로 조건화해

\[P_k = pP_{k+1} + qP_{k-1}, \qquad P_0 = 0,\ P_N = 1.\]
정리 2.1.2

\(p \ne q\)이면 \(P_k = \dfrac{1 - (q/p)^k}{1 - (q/p)^N}\), \(p = q\)이면 \(P_k = k/N\).

\(P_k = pP_k + qP_k\)를 빼면 \(P_{k+1} - P_k = \frac qp(P_k - P_{k-1})\). 차이가 등비수열이라 \(P_{k+1} - P_k = (q/p)^kP_1\). 0부터 \(k-1\)까지 더하면 \(P_k = P_1\sum_{j=0}^{k-1}(q/p)^j\)이고, \(P_N = 1\)로 \(P_1\)을 정하면 결론이 나옵니다. ∎

예제 2.1.3

카지노 룰렛에서 빨강에 거는 승률은 \(p = 18/38\)입니다. 50만 원으로 시작해 1만 원씩 걸어 100만 원이 되면 멈추려 할 때 성공 확률은?

풀이. \(q/p = 20/18 = 1.111\). \(P_{50} = \frac{1 - 1.111^{50}}{1 - 1.111^{100}} \approx \frac{-193.9}{-37650} \approx 0.0052\). 한 판의 불리함은 작아 보여도 오래 하면 거의 확실히 잃습니다. 공정한 게임이었다면 0.5입니다.

요약
  1. 단순 랜덤워크: ±1 독립 걸음의 합.
  2. 파산 문제는 첫 걸음 조건화로 점화식.
  3. \(P_k = (1 - (q/p)^k)/(1 - (q/p)^N)\), 대칭이면 \(k/N\).

2.1.3연습문제

기본

  1. 대칭 랜덤워크에서 게임이 끝날 때까지의 평균 판 수 \(D_k\)가 \(k(N-k)\)임을 점화식 \(D_k = 1 + \frac12(D_{k+1} + D_{k-1})\)로 확인하세요.
    답

    \(k(N-k)\)를 넣으면 \(1 + \frac12[(k+1)(N-k-1) + (k-1)(N-k+1)] = 1 + k(N-k) - 1\). 경계 \(D_0 = D_N = 0\)도 만족합니다.
