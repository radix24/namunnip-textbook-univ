공정한 게임

지금까지 가진 돈이 얼마든, 다음 판 뒤 가진 돈의 기대값이 지금과 같다면 그 게임은 공정합니다. 이런 과정을 마팅게일이라 합니다. 공정한 게임에서는 언제 그만두는 전략을 쓰더라도 기대 이익이 0이라는 것이 선택 정지 정리입니다.

4.2.1정의

정의 4.2.1

\(E|M_n| < \infty\)이고 \(E(M_{n+1} \mid X_0, \ldots, X_n) = M_n\)이면 \((M_n)\)은 (\(X\)에 대한) 마팅게일.

예: (1) 대칭 랜덤워크 \(S_n\). (2) \(p\) 랜덤워크에서 \(S_n - n(p - q)\). (3) 대칭 랜덤워크에서 \(S_n^2 - n\). (4) \(p\) 랜덤워크에서 \((q/p)^{S_n}\).

(3)의 확인: \(E(S_{n+1}^2 \mid \cdot) = E((S_n + X)^2) = S_n^2 + 2S_nE(X) + 1 = S_n^2 + 1\)이므로 \(E(S_{n+1}^2 - (n+1)\mid\cdot) = S_n^2 - n\).

4.2.2선택 정지 정리

정리 4.2.2

\(M_n\)이 마팅게일이고 \(T\)가 정지시각일 때, (가) \(T\)가 유계이거나, (나) \(E(T) < \infty\)이고 증분 \(|M_{n+1} - M_n|\)이 유계이면 \(E(M_T) = E(M_0)\).

조건이 필요한 이유: 대칭 랜덤워크에서 "처음 +1에 닿으면 멈춤"은 확률 1로 끝나고 \(M_T = 1\)이라 \(E(M_T) = 1 \ne 0\)입니다. 이 정지시각의 기대값이 무한이라 조건 (나)가 깨집니다. 돈을 두 배씩 거는 마팅게일 전략이 실제로 통하지 않는 이유입니다(무한한 자금과 시간이 필요).

예제 4.2.3

대칭 랜덤워크로 2.1절 파산 문제의 확률과 평균 시간을 구하세요.

풀이. \(T\) = 0 또는 \(N\)에 닿는 시각(\(E(T) < \infty\)). \(S_n\)에 정리를 쓰면 \(k = E(S_T) = N\cdot P_k\)이므로 \(P_k = k/N\). \(S_n^2 - n\)에 쓰면 \(k^2 = E(S_T^2) - E(T) = N^2P_k - E(T)\), 곧 \(E(T) = Nk - k^2 = k(N-k)\). 점화식 없이 두 결과를 얻습니다.

요약
  1. 마팅게일: 다음 값의 조건부 기대값 = 현재 값.
  2. 선택 정지 정리: 조건 아래 \(E(M_T) = E(M_0)\).
  3. 알맞은 마팅게일을 고르면 도달 확률과 기대 시간이 바로 나옵니다.

4.2.3연습문제

응용

  1. \(p \ne q\) 랜덤워크에서 \((q/p)^{S_n}\)으로 파산 확률 공식을 다시 유도하세요.
    답

    \((q/p)^k = P_k(q/p)^N + (1 - P_k)\)에서 \(P_k = \frac{1 - (q/p)^k}{1 - (q/p)^N}\).
