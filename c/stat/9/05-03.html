아무 때나 바뀌는 상태

기계는 "작동"과 "고장" 사이를 하루 단위가 아니라 아무 순간에나 오갑니다. 무기억성을 시간 연속으로 옮기면 각 상태에 머무는 시간이 지수분포가 되고, 떠날 때 어디로 갈지는 이산 연쇄처럼 정해집니다.

5.3.1생성 행렬

정의 5.3.1

상태 \(i\)에서 \(j\)로 가는 전이율 \(q_{ij}\) (\(i \ne j\)), \(q_i = \sum_{j\ne i}q_{ij}\). 생성 행렬 \(Q\): 비대각 원소 \(q_{ij}\), 대각 원소 \(-q_i\). 각 행의 합은 0.

상태 \(i\)에 머무는 시간은 지수\((q_i)\)이고, 떠날 때 \(j\)로 갈 확률은 \(q_{ij}/q_i\)입니다. 경쟁하는 지수 시계들 가운데 가장 먼저 울리는 것으로 다음 상태가 정해진다고 생각하면 됩니다(1.2절). 짧은 시간 \(h\) 동안 \(P_{ij}(h) \approx q_{ij}h\)이고, \(P(t) = e^{tQ}\)입니다.

5.3.2정상분포

결과 5.3.2

유한 기약 연쇄의 정상분포는 \(\boldsymbol\pi Q = \mathbf 0\), \(\sum\pi_j = 1\)의 해이며 \(P_{ij}(t) \to \pi_j\)이다.

\(\boldsymbol\pi Q = \mathbf 0\)의 \(j\)번째 식은 \(\pi_jq_j = \sum_{i \ne j}\pi_iq_{ij}\), 곧 "상태 \(j\)에서 나가는 흐름 = 들어오는 흐름"(균형 방정식)입니다. 연속시간에는 주기 문제가 없습니다.

예제 5.3.2

기계가 평균 10일 작동하다 고장 나고(고장률 0.1/일), 수리에 평균 2일 걸립니다(수리율 0.5/일). 장기적으로 작동하는 비율은?

풀이. \(Q = \begin{pmatrix}-0.1 & 0.1\\ 0.5 & -0.5\end{pmatrix}\). \(0.1\pi_1 = 0.5\pi_2\)에서 \(\pi_1 = 5\pi_2\), \(\boldsymbol\pi = (5/6, 1/6)\). 평균 작동 시간/(작동 + 수리) = 10/12와 같습니다.

요약
  1. 머무는 시간 지수\((q_i)\), 점프 확률 \(q_{ij}/q_i\).
  2. 생성 행렬 \(Q\): 행 합 0, \(P(t) = e^{tQ}\).
  3. 정상분포: \(\boldsymbol\pi Q = \mathbf 0\) (흐름 균형).

5.3.3연습문제

응용

  1. 손님이 비율 \(\lambda\)로 오고 창구 하나가 비율 \(\mu\)로 처리하는 대기열(M/M/1)에서 손님 수의 정상분포를 구하세요(\(\lambda < \mu\)).
    답

    균형 \(\pi_n\lambda = \pi_{n+1}\mu\)에서 \(\pi_n = (1-\rho)\rho^n\), \(\rho = \lambda/\mu\). 기하분포입니다.
