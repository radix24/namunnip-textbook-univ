6.2색, 크기, 패널로 여러 변수를 한 그림에

그림의 문법

문법 기반 그래픽(ggplot2)은 그림을 "자료의 변수 → 시각 요소" 대응으로 봅니다. \(x\) 위치에 소득, \(y\) 위치에 기대수명, 색에 대륙, 점 크기에 인구를 대응하면 변수 네 개가 한 그림에 들어갑니다. 한스 로슬링의 유명한 "세계 건강과 부" 그림이 이렇게 만들어졌습니다.

6.2.1요소의 정확도

사람이 양을 비교할 때 정확도는 대략 다음 순서입니다(클리블랜드-맥길의 실험).

  1. 같은 축 위의 위치
  2. 길이
  3. 각도, 기울기
  4. 넓이
  5. 부피, 색의 진하기, 채도

그래서 가장 중요한 비교는 위치(같은 축)에 두고, 원그래프(각도)나 거품 크기(넓이)로 정밀한 비교를 시키지 않습니다. 범주 변수는 색상이나 모양으로, 순서 있는 수치는 한 가지 색의 진하기로 나타냅니다. 색만으로 구별하게 하면 색각 이상인 사람이 읽지 못하므로 모양이나 직접 이름표를 함께 씁니다.

6.2.2패널(작은 그림 여러 개)

한 그림에 너무 많이 넣으면 읽기 어렵습니다. 범주 변수의 수준마다 같은 축의 작은 그림을 나란히 놓으면(facet, small multiples) 비교가 쉽습니다. 축 범위를 모든 패널에서 같게 해야 공정하게 비교됩니다.

예제 6.2.1

mtcars에서 무게, 연비, 기통 수, 변속기를 한 그림에 나타내세요.

library(ggplot2)
ggplot(mtcars, aes(wt, mpg, colour = factor(cyl))) +
  geom_point(size = 2) + facet_wrap(~ am, labeller = label_both) +
  labs(x = "무게 (천 lb)", y = "연비 (mpg)", colour = "기통")

무게-연비(위치), 기통(색), 변속기(패널). 같은 무게에서 기통에 따른 차이가 작다는 것, 수동 변속기 차가 가벼운 쪽에 몰려 있다는 것이 보입니다.

요약
  1. 변수 → 시각 요소 대응.
  2. 중요한 비교는 위치·길이로.
  3. 복잡하면 패널로 나누고 축을 맞춥니다.

6.2.3연습문제

기본

  1. 정당 다섯 곳의 득표율을 원그래프 대신 무엇으로 그리면 비교가 정확해지나요?
    답

    0에서 시작하는 가로 막대그래프(길이), 크기순 정렬.
