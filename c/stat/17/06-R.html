6.R.1

연습다변량 자료의 그래프 단원 마무리 연습

문제 6 · 실습·적용·판단 · 힌트 2단계

다루는 성취기준 [응통17-06-01] [응통17-06-02] [응통17-06-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습iris 자료의 네 수치 변수로 산점도 행렬을 그리고 종에 따라 색을 칠하는 R 코드를 쓰세요. 그림에서 기대되는 특징을 쓰세요. [06-01]

    힌트 1

    pairs(iris[, 1:4], col = iris$Species)를 씁니다.

    힌트 2

    꽃잎(Petal) 변수들이 종을 잘 나눕니다.

    풀이 
    pairs(iris[, 1:4], col = as.integer(iris$Species), pch = 19)

    꽃잎 길이와 너비는 서로 강한 양의 상관이 있고, setosa가 다른 두 종과 완전히 떨어진 군집을 이룹니다. versicolor와 virginica는 일부 겹칩니다. 산점도 행렬은 모든 변수 쌍의 관계를 한눈에 보여 주지만, 변수가 많아지면 칸이 작아져 평행 좌표 그림이나 주성분 그림으로 보완합니다.

  2. 실습평행 좌표 그림이 무엇인지 설명하고, 변수 순서와 척도가 그림에 어떤 영향을 주는지 쓰세요. [06-01]

    힌트 1

    각 변수가 세로축 하나가 되고, 관측값 하나가 꺾은선 하나가 됩니다.

    힌트 2

    이웃한 축 사이의 관계만 잘 보입니다.

    풀이

    변수마다 평행한 세로축을 세우고 각 관측값을 축 위의 값을 잇는 꺾은선으로 그립니다. 같은 군집의 관측값은 비슷한 선 묶음을 이룹니다. 이웃한 두 축 사이에서 선이 평행하면 양의 상관, 엇갈리면 음의 상관입니다. 이웃한 축의 관계만 잘 보이므로 변수 순서를 바꿔 가며 보고, 단위가 다르면 각 축을 표준화(또는 0~1로)해야 비교가 됩니다(R의 MASS::parcoord).

  3. 실습ggplot2로 mtcars의 무게와 연비 산점도에 실린더 수를 색, 마력을 점 크기, 변속기 종류를 패널로 나타내는 코드를 쓰세요. 한 그림에 너무 많은 변수를 넣을 때의 위험도 쓰세요. [06-02]

    힌트 1

    aes(colour = factor(cyl), size = hp)와 facet_wrap(~ am)을 씁니다.

    힌트 2

    사람의 눈은 크기나 색의 미묘한 차이를 정확히 읽지 못합니다.

    풀이 
    ggplot(mtcars, aes(wt, mpg, colour = factor(cyl), size = hp)) +
  geom_point(alpha = 0.7) + facet_wrap(~ am)

    다섯 변수를 한 그림에 담을 수 있지만, 크기와 색의 차이는 위치보다 읽기 어렵고, 변수가 많으면 무엇을 보아야 할지 흐려집니다. 전달하려는 비교 하나에 가장 정확한 시각 요소(위치)를 주고, 나머지는 보조로 씁니다.

  4. 적용다음 그래프의 문제를 찾아 고치세요. (가) 3차원 원그래프로 시장 점유율 표시 (나) 두 개의 세로축을 써서 매출과 기온을 한 그림에 겹침 (다) 면적이 아니라 지름이 값에 비례하는 원으로 크기 비교 [06-03]

    힌트 1

    원근 때문에 앞쪽 조각이 커 보입니다.

    힌트 2

    두 축의 범위를 마음대로 정하면 어떤 관계든 만들어 보일 수 있습니다.

    풀이

    (가) 3차원 원근 때문에 앞쪽 조각이 실제보다 커 보이고 각도 비교도 어렵습니다 → 정렬한 막대그래프로 바꿉니다. (나) 두 축의 눈금을 임의로 정해 두 선이 함께 움직이는 것처럼 보이게 만들 수 있습니다 → 두 개의 패널로 나누거나 기준 시점 대비 지수로 바꿔 한 축에 그립니다. (다) 지름이 2배면 면적은 4배라 차이가 과장됩니다 → 면적이 값에 비례하게 하거나 막대로 바꿉니다.

  5. 적용코로나19 확진자 수처럼 지수적으로 늘어나는 자료를 선형 축과 로그 축으로 그릴 때 각각 무엇이 잘 보이고 무엇을 오해하기 쉬운지 쓰세요. [06-03]

    힌트 1

    로그 축에서 지수 증가는 직선이 됩니다.

    힌트 2

    로그 축의 같은 간격은 같은 "배수"를 뜻합니다.

    풀이

    선형 축은 실제 규모(얼마나 많은지)와 최근 변화의 절대 크기를 잘 보여 주지만, 초기 증가가 바닥에 붙어 보이지 않고 증가 속도 변화를 판단하기 어렵습니다. 로그 축은 증가율(배가 시간)의 변화를 직선의 기울기로 보여 주고 여러 지역의 비교에 좋지만, 비전문가는 꺾인 직선을 "거의 멈췄다"고 오해하기 쉽고 실제 규모를 과소평가할 수 있습니다. 축 척도를 명확히 표시하고 목적에 맞게 고르며, 필요하면 둘 다 보여 줍니다.

  6. 판단막대그래프의 세로축을 0이 아니라 데이터 최솟값 근처에서 시작하는 것은 언제나 잘못인가요? 선그래프와 비교해 판단하세요. [06-03]

    힌트 1

    막대그래프는 길이로 크기를 비교하게 합니다(응통5-02-02).

    힌트 2

    선그래프는 위치와 변화를 보여 줍니다.

    풀이

    막대그래프는 막대 길이가 값에 비례한다고 읽히므로 세로축은 0에서 시작해야 합니다. 반면 선그래프나 점그래프는 위치와 변화(기울기)를 보여 주는 그림이라, 체온이나 주가처럼 0이 의미 없는 자료는 관심 범위로 축을 잘라도 됩니다. 이때도 축 눈금을 분명히 표시하고, 작은 변화를 과장하지 않도록 범위를 정해야 합니다.
