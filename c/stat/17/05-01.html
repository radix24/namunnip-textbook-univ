5.1.1이동 평균과 이동 중위수

정의 5.1.1

폭 3의 이동 중위수: \(z_t = \mathrm{median}(y_{t-1}, y_t, y_{t+1})\). 이동 평균은 중앙값 대신 평균.

이동 평균은 튀는 값 하나를 이웃으로 번지게 하지만(한 값이 세 칸에 1/3씩 영향), 이동 중위수는 튀는 값 하나를 완전히 지웁니다. 반면 이동 중위수는 꺾임과 계단을 보존하는 대신 평평한 조각을 만듭니다.

5.1.2반복 평활

터키는 간단한 평활을 조합했습니다. "3R"은 폭 3 이동 중위수를 변화가 없을 때까지 반복, "S"는 두 점짜리 평평한 구간을 쪼개기, "H"(해닝)는 가중치 1/4, 1/2, 1/4의 이동 평균으로 마무리합니다. R의 smooth(x, kind = "3RS3R"), runmed(x, k). 끝점은 이웃이 부족하므로 따로 규칙(끝값 그대로, 외삽)을 씁니다.

예제 5.1.1

계열 3, 5, 4, 20, 6, 7, 6, 8에 폭 3 이동 중위수와 이동 평균을 적용하세요(끝값은 그대로).

풀이. 이동 중위수: 3, 4, 5, 6, 7, 6, 7, 8. 튀는 값 20이 사라졌습니다. 이동 평균: 3, 4, 9.67, 10, 11, 6.33, 7, 8. 20이 이웃 세 칸을 끌어올렸습니다.

요약
  1. 이동 중위수: 튀는 값 제거, 계단 보존.
  2. 이동 평균: 매끄럽지만 튀는 값이 번짐.
  3. 둘을 조합(3RSS, 해닝)해 장점을 취합니다.

5.1.3연습문제

기본

  1. 폭 3 이동 중위수로 지울 수 없는 튀는 값의 패턴은?
    답

    연속된 두 개 이상의 튀는 값. 폭을 5로 늘려야 합니다.
