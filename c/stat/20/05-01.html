모형을 미래로 굴리기

시계열 분석의 가장 큰 쓸모는 예측입니다. 현재까지의 관측이 주어졌을 때 미래 값의 조건부 기대값이 평균제곱오차를 가장 작게 하는 예측입니다.

5.1.1점예측

시점 \(n\)까지 관측했을 때 \(h\)기 뒤 예측 \(\hat x_{n+h} = E(x_{n+h} \mid x_n, x_{n-1}, \ldots)\). 계산 규칙: 모형식에서 미래 \(x\)는 예측값으로, 미래 \(e\)는 0으로, 과거 \(e\)는 잔차로 바꿉니다.

AR(1)(평균 \(\mu\)): \(\hat x_{n+h} = \mu + \phi^h(x_n - \mu)\). 시차가 커지면 평균으로 돌아갑니다. 랜덤워크: \(\hat x_{n+h} = x_n\).

5.1.2예측구간

정상 ARMA를 \(x_t - \mu = \sum_{j\ge0}\psi_je_{t-j}\)(\(\psi_0 = 1\))로 쓰면 \(h\)기 예측 오차의 분산은

\[\sigma^2\sum_{j=0}^{h-1}\psi_j^2.\]

AR(1)은 \(\psi_j = \phi^j\)라 \(\sigma^2\frac{1 - \phi^{2h}}{1 - \phi^2}\)로 계열 분산에 다가가고, 랜덤워크는 \(\psi_j = 1\)이라 \(h\sigma^2\)로 끝없이 커집니다. 95% 구간 \(\hat x_{n+h} \pm 1.96\sqrt{\text{분산}}\). 이 구간은 모형이 맞고 모수를 안다고 가정한 것이라 실제보다 좁을 수 있습니다.

예제 5.1.1

\(\mu = 50\), \(\phi = 0.6\), \(\sigma = 2\), \(x_n = 60\)인 AR(1)의 1, 2기 뒤 예측과 95% 구간은?

풀이. \(\hat x_{n+1} = 50 + 0.6\times10 = 56\), 분산 4, 구간 \(56 \pm 3.92\). \(\hat x_{n+2} = 50 + 3.6 = 53.6\), 분산 \(4(1 + 0.36) = 5.44\), 구간 \(53.6 \pm 4.57\).

fit <- arima(lh, order = c(1, 0, 0)); predict(fit, n.ahead = 6)
요약
  1. 예측 = 조건부 기대값, 미래 잡음은 0으로.
  2. 오차 분산 \(\sigma^2\sum_{j<h}\psi_j^2\): 정상이면 상한, 단위근이면 무한히 증가.
  3. 구간은 모형 불확실성을 빼서 낙관적일 수 있음.

5.1.3연습문제

기본

  1. 예제에서 \(h \to \infty\)이면 예측과 구간은?
    답

    예측 50, 분산 \(4/0.64 = 6.25\), 구간 \(50 \pm 4.9\)(계열의 무조건 분포).
