먼저 알아야 할 것
  • ARIMA 적합 (4.1절), 표본 ACF (1.2절).

모형이 의존 구조를 다 잡았나

좋은 시계열 모형은 자료의 의존성을 모두 설명해, 남은 잔차가 예측할 수 없는 백색잡음이어야 합니다. 잔차에 자기상관이 남아 있으면 그만큼 예측을 개선할 여지가 있다는 뜻입니다.

4.2.1점검 항목

  • 잔차 시계열 그림: 추세, 분산 변화, 이상점.
  • 잔차 ACF: 막대가 \(\pm2/\sqrt n\) 안에.
  • 잔차의 정규 Q-Q 그림: 예측구간이 정규 가정에 기대므로.
  • 융-박스 검정: 여러 시차의 자기상관을 한꺼번에.
결과 4.2.1 (융-박스)

\(Q = n(n+2)\sum_{h=1}^{H}\dfrac{\hat\rho_e(h)^2}{n-h}\)는 잔차가 백색잡음이면 근사적으로 \(\chi^2_{H - p - q}\)를 따른다.

p값이 작으면 잔차에 자기상관이 남은 것입니다. 남은 자기상관의 시차를 보고 항을 추가합니다(예: 시차 12의 막대가 크면 계절 항). \(H\)는 보통 10~20(계절 자료는 \(2s\)).

예제 4.2.1

4.1절의 lh AR(1) 모형을 진단하세요.

fit <- arima(lh, order = c(1, 0, 0))
tsdiag(fit)                                         # 잔차, 잔차 ACF, 융-박스 p값
Box.test(residuals(fit), lag = 10, type = "Ljung-Box", fitdf = 1)

융-박스 p값이 0.41로 커서 잔차에 남은 자기상관의 증거가 없습니다. AR(1)로 충분하다고 봅니다.

요약
  1. 잔차는 백색잡음이어야 함.
  2. 잔차 그림, ACF, Q-Q, 융-박스(자유도 \(H - p - q\)).
  3. 남은 시차에 맞춰 모형을 고침.

4.2.2연습문제

기본

  1. ARMA(1,1) 잔차로 \(H = 12\)인 융-박스 검정을 하면 자유도는?
    답

    \(12 - 1 - 1 = 10\).
