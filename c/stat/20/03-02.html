φ = 0.99와 φ = 1은 얼마나 다를까

숫자로는 0.01 차이지만 성질은 근본적으로 다릅니다. 하나는 평균으로 돌아오고, 다른 하나는 영원히 떠돕니다.

3.2.1비교

정상 AR(1), \(|\phi| < 1\)랜덤워크, \(\phi = 1\)
식\(x_t = \phi x_{t-1} + e_t\)\(x_t = x_{t-1} + e_t = x_0 + \sum e_s\)
분산\(\sigma^2/(1-\phi^2)\), 일정\(t\sigma^2\), 계속 커짐
충격의 영향\(\phi^h\)로 사라짐영원히 남음
평균 회귀있음없음
장기 예측평균으로 수렴현재 값, 예측구간이 \(\sqrt h\)로 넓어짐

회귀분석에서 서로 무관한 두 랜덤워크를 회귀하면 \(R^2\)와 t 값이 크게 나오는 가짜 회귀가 흔히 생깁니다. 비정상 계열은 차분하거나 공적분을 확인해야 합니다.

3.2.2단위근 검정

디키-풀러 검정: \(\nabla x_t = \gamma x_{t-1} + e_t\)(\(\gamma = \phi - 1\))에서 \(H_0: \gamma = 0\)(단위근) 대 \(H_1: \gamma < 0\)(정상). 귀무가설 아래 t 통계량이 t 분포를 따르지 않아 전용 임계값(5% 약 −2.86, 상수항 포함)을 씁니다. 자기상관을 흡수하려고 차분 시차를 더한 것이 ADF 검정입니다. 검정력이 낮아 \(\phi = 0.95\) 같은 계열을 단위근과 잘 구별하지 못합니다.

예제 3.2.1

\(\phi = 0.9\)인 AR(1)에서 충격의 절반이 사라지는 데 걸리는 시간(반감기)은?

풀이. \(0.9^h = 0.5\), \(h = \log0.5/\log0.9 \approx 6.6\)기. \(\phi = 0.99\)이면 약 69기, \(\phi = 1\)이면 영원히 사라지지 않습니다.

요약
  1. 랜덤워크: 분산 증가, 충격 영구, 평균 회귀 없음.
  2. 비정상 계열끼리의 회귀는 가짜 회귀 위험.
  3. ADF 검정, 검정력이 낮음에 주의.

3.2.3연습문제

기본

  1. 랜덤워크(\(\sigma = 1\))의 10기 뒤 예측구간(95%) 반폭은?
    답

    \(1.96\sqrt{10} = 6.2\).
