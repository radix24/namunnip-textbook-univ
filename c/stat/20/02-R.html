2.R.1

연습AR, MA, ARMA 모형 단원 마무리 연습

문제 6 · 증명·적용·개념·계산·판단 · 힌트 2단계

다루는 성취기준 [응통20-02-01] [응통20-02-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 증명정상 AR(1) \(X_t = \phi X_{t-1} + \varepsilon_t\) (\(|\phi| < 1\))의 분산과 자기상관함수 \(\rho(h) = \phi^h\)를 유도하세요. [02-01]

    힌트 1

    정상이면 \(\mathrm{Var}(X_t) = \mathrm{Var}(X_{t-1})\)입니다.

    힌트 2

    양변에 \(X_{t-h}\)를 곱하고 기댓값을 취하세요. \(\varepsilon_t\)는 과거 \(X\)와 무상관입니다.

    풀이

    \(\gamma(0) = \phi^2\gamma(0) + \sigma^2\)에서 \(\gamma(0) = \sigma^2/(1 - \phi^2)\)입니다. \(h \ge 1\)이면 \(\gamma(h) = E(X_tX_{t-h}) = \phi E(X_{t-1}X_{t-h}) + E(\varepsilon_tX_{t-h}) = \phi\gamma(h-1)\)이므로 \(\gamma(h) = \phi^h\gamma(0)\), 곧 \(\rho(h) = \phi^h\)입니다.

    \(\phi = 0.6\)이면 \(\rho = 0.6, 0.36, 0.216, \ldots\)으로 지수적으로 줄고, \(\phi < 0\)이면 부호가 번갈아 바뀌며 줄어듭니다.

  2. 증명MA(1) \(X_t = \varepsilon_t + \theta\varepsilon_{t-1}\)의 자기상관함수를 유도하고, \(\theta = 0.5\)일 때 값을 구하세요. [02-01]

    힌트 1

    \(\gamma(1) = E[(\varepsilon_t + \theta\varepsilon_{t-1})(\varepsilon_{t-1} + \theta\varepsilon_{t-2})]\)입니다.

    힌트 2

    시차 2 이상에서는 공통 항이 없습니다.

    풀이

    \(\gamma(0) = (1 + \theta^2)\sigma^2\), \(\gamma(1) = \theta\sigma^2\), \(h \ge 2\)이면 \(\gamma(h) = 0\)이므로 \(\rho(1) = \theta/(1 + \theta^2)\), \(\rho(h) = 0\) (\(h \ge 2\))입니다.

    \(\theta = 0.5\)이면 \(\rho(1) = 0.5/1.25 = 0.4\)이고 그 뒤는 0입니다. MA(q)의 자기상관은 시차 \(q\) 뒤에 정확히 끊깁니다. 또 \(|\rho(1)| \le 0.5\)이므로 표본 \(r_1\)이 0.5보다 크면 MA(1)은 맞지 않습니다.

  3. 적용자기상관함수(ACF)와 편자기상관함수(PACF)의 모양으로 AR(p), MA(q), ARMA의 차수를 짐작하는 규칙을 표로 정리하세요. [02-02]

    힌트 1

    AR(1)의 ACF는 지수적으로 줄고 PACF는 시차 1 뒤에 끊깁니다.

    힌트 2

    MA는 그 반대입니다.

    풀이

    AR(p): ACF는 지수적으로(또는 감쇠 진동하며) 줄어들고, PACF는 시차 \(p\) 뒤에 끊깁니다. MA(q): ACF는 시차 \(q\) 뒤에 끊기고, PACF는 서서히 줄어듭니다. ARMA(p, q): 둘 다 서서히 줄어 끊기는 곳이 없습니다. 예를 들어 AR(1) \(\phi = 0.6\)의 PACF는 0.6, 0, 0, …입니다. 실제 자료에서는 표본 오차 때문에 모양이 흐리므로 후보 몇 개를 정보기준으로 비교합니다.

  4. 개념AR(1)의 정상 조건과 MA(1)의 가역 조건을 쓰고, 가역 조건이 왜 필요한지 설명하세요. [02-01]

    힌트 1

    AR(1)은 \(|\phi| < 1\)입니다.

    힌트 2

    \(\theta\)와 \(1/\theta\)인 MA(1)의 자기상관은 같습니다.

    풀이

    AR(1)은 \(|\phi| < 1\)이어야 분산이 유한한 정상 계열입니다(\(|\phi| \ge 1\)이면 분산이 발산하거나 폭발). MA(1)은 항상 정상이지만, \(\theta\)와 \(1/\theta\)가 같은 자기상관을 주어 모형이 하나로 정해지지 않습니다. 가역 조건 \(|\theta| < 1\)을 두면 \(\varepsilon_t\)를 과거 \(X\)의 수렴하는 급수로 쓸 수 있어(AR(∞) 표현) 모형이 유일해지고 예측에 쓸 수 있습니다.

  5. 계산AR(2) \(X_t = 0.5X_{t-1} + 0.3X_{t-2} + \varepsilon_t\)의 \(\rho(1)\)과 \(\rho(2)\)를 율-워커 방정식으로 구하세요. [02-02]

    힌트 1

    \(\rho(1) = \phi_1 + \phi_2\rho(1)\), \(\rho(2) = \phi_1\rho(1) + \phi_2\)입니다.

    힌트 2

    첫 식에서 \(\rho(1) = \phi_1/(1 - \phi_2)\)입니다.

    풀이

    \(\rho(1) = 0.5/0.7 \approx 0.714\), \(\rho(2) = 0.5\times0.714 + 0.3 \approx 0.657\)입니다. 이후 \(\rho(h) = 0.5\rho(h-1) + 0.3\rho(h-2)\)로 천천히 줄어듭니다. 거꾸로 표본 자기상관을 넣어 \(\phi\)를 추정하는 것이 율-워커 추정입니다.

  6. 판단어떤 계열의 표본 ACF가 시차 1에서 0.45, 그 뒤는 범위 안이고, PACF는 0.45, −0.25, 0.12, …로 서서히 줄어듭니다. 어떤 모형을 먼저 고려할지 판단하세요. [02-02]

    힌트 1

    ACF가 시차 1 뒤에 끊깁니다.

    힌트 2

    MA(1)의 \(\rho(1)\)은 0.5를 넘을 수 없습니다.

    풀이

    ACF가 시차 1 뒤에 끊기고 PACF가 부호를 바꾸며 서서히 줄어드는 것은 MA(1)의 전형적인 모양입니다. \(r_1 = 0.45 < 0.5\)이므로 MA(1)과 모순되지 않습니다(\(\theta/(1 + \theta^2) = 0.45\)에서 \(\theta \approx 0.63\)). MA(1)을 적합한 뒤 잔차를 점검하고, AR(2)나 ARMA(1, 1)와 AIC로 비교합니다.
