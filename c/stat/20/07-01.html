보이지 않는 수준을 따라가기

여론조사 지지율은 진짜 지지율에 표본 오차가 더해진 값이고, 진짜 지지율 자체도 조금씩 움직입니다. 관측에는 잡음이 있고 참값은 숨어 변할 때, 관측이 올 때마다 참값의 추정을 갱신하는 방법이 칼만 필터입니다.

7.1.1국소 수준 모형

관측식: \(y_t = \mu_t + \varepsilon_t\), \(\varepsilon_t \sim N(0, \sigma_\varepsilon^2)\).

상태식: \(\mu_t = \mu_{t-1} + \eta_t\), \(\eta_t \sim N(0, \sigma_\eta^2)\).

숨은 수준 \(\mu_t\)는 랜덤워크로 움직이고, 우리는 잡음 섞인 \(y_t\)만 봅니다. 일반 상태공간 모형은 이것을 행렬로 넓혀 추세, 계절, 회귀 효과, ARIMA까지 모두 담습니다.

7.1.2칼만 필터

시점 \(t-1\)까지의 관측으로 \(\mu_{t-1} \sim N(m_{t-1}, P_{t-1})\)이라 합시다.

  1. 예측: \(\mu_t\)의 예측 평균 \(m_{t-1}\), 분산 \(P_{t-1} + \sigma_\eta^2\)(상태가 움직여 불확실성이 커짐).
  2. 갱신: 새 관측 \(y_t\)가 오면 \(m_t = m_{t-1} + K_t(y_t - m_{t-1})\), \(P_t = (1 - K_t)(P_{t-1} + \sigma_\eta^2)\), 칼만 이득 \(K_t = \dfrac{P_{t-1} + \sigma_\eta^2}{P_{t-1} + \sigma_\eta^2 + \sigma_\varepsilon^2}\).

새 추정은 예측과 관측의 가중평균이고, 가중치 \(K_t\)는 상대적 불확실성으로 정해집니다. 관측 잡음이 크면 관측을 덜 믿고(\(K\) 작음), 상태 변화가 크면 관측을 더 믿습니다. 정규 가정 아래 이것은 정확한 베이즈 갱신(응통6 5.3절의 조건부분포)이고, 장기적으로 \(K_t\)는 일정해져 지수평활과 같아집니다.

예제 7.1.1

\(m_{t-1} = 40\), \(P_{t-1} = 3\), \(\sigma_\eta^2 = 1\), \(\sigma_\varepsilon^2 = 4\), 새 여론조사 \(y_t = 46\)이면 갱신된 추정은?

풀이. 예측 분산 4, \(K = 4/8 = 0.5\). \(m_t = 40 + 0.5\times6 = 43\), \(P_t = 0.5\times4 = 2\). 조사 결과 46을 그대로 믿지 않고 이전 추정과 반반 섞습니다.

fit <- StructTS(Nile, type = "level"); fit$coef   # 분산 추정
plot(Nile); lines(tsSmooth(fit), col = "red")       # 숨은 수준의 평활 추정
요약
  1. 관측식 + 상태식, 숨은 상태를 추정.
  2. 예측(불확실성 증가) → 갱신(관측과 가중평균).
  3. 칼만 이득 = 상대적 불확실성, 정규면 베이즈 갱신.

7.1.3연습문제

기본

  1. 예제에서 \(\sigma_\varepsilon^2 = 0\)(관측에 잡음 없음)이면 \(K\)와 \(m_t\)는?
    답

    \(K = 1\), \(m_t = 46\). 잡음이 없으면 관측이 곧 참값입니다.
