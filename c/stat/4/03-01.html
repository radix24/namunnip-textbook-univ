이 절에서 배울 것
  • NumPy 배열을 만들고 원소별 연산, 집계, 브로드캐스팅을 쓴다.
  • 반복문을 벡터 연산으로 바꿔 빠르게 계산한다.
먼저 알아야 할 것
  • 리스트 (1.2절), 모듈 (2.1절).

리스트는 계산용이 아니다

파이썬 리스트에 [1, 2] * 2를 하면 [1, 2, 1, 2]가 됩니다. 수치 계산에는 NumPy 배열을 씁니다. 같은 자료형의 원소가 메모리에 연속으로 놓여 C 속도로 계산됩니다.

3.1.1배열

import numpy as np
x = np.array([3, 1, 4, 1, 5])
x * 2                   # array([ 6,  2,  8,  2, 10])
x.mean(), x.std(ddof=1)  # (2.8, 1.7888...)  ddof=1이면 n-1로 나눔
x[x > 2]                # 조건 인덱싱 array([3, 4, 5])
np.arange(0, 1, 0.25)   # array([0.  , 0.25, 0.5 , 0.75])
np.linspace(0, 1, 5)    # 끝 포함 5개
z = (x - x.mean()) / x.std(ddof=1)   # 표준화

주의: np.std의 기본은 \(n\)으로 나눕니다(ddof=0). 표본표준편차는 ddof=1입니다.

3.1.22차원 배열과 브로드캐스팅

X = np.array([[1, 2], [3, 4], [5, 6]])     # 3×2
X.shape; X.mean(axis=0)                     # (3, 2), 열 평균 array([3., 4.])
Xc = X - X.mean(axis=0)                     # 3×2에서 길이 2를 빼면 행마다 적용

모양이 다른 배열끼리 연산하면 작은 쪽을 늘려 맞춥니다(브로드캐스팅). axis=0은 행 방향으로 접어 열마다, axis=1은 행마다 계산합니다.

예제 3.1.1

표준정규 난수 100만 개 중 절댓값이 1.96을 넘는 비율을 반복문 없이 구하세요.

rng = np.random.default_rng(1)
z = rng.standard_normal(1_000_000)
np.mean(np.abs(z) > 1.96)          # 약 0.05

논리 배열의 평균은 True의 비율입니다. 같은 계산을 파이썬 반복문으로 하면 수십 배 느립니다.

요약
  1. 배열 연산은 원소별, 집계는 axis로.
  2. 표본표준편차는 ddof=1.
  3. 브로드캐스팅과 논리 인덱싱으로 반복문을 없앰.

3.1.3연습문제

기본

  1. 3×2 배열 X의 각 열을 표준화하는 한 줄 코드는?
    답

    (X - X.mean(axis=0)) / X.std(axis=0, ddof=1).
