방정식을 컴퓨터로 풀기

내부수익률(IRR), 분위수, 최대가능도 방정식처럼 손으로 풀 수 없는 방정식 \(f(x) = 0\)이 많습니다. 반복해서 근에 다가가는 두 가지 기본 방법을 직접 만들어 봅니다.

4.1.1이분법

\(f(a)\)와 \(f(b)\)의 부호가 다르면 중간값 정리로 사이에 근이 있습니다. 가운데 점 \(m\)에서 부호를 보고 근이 있는 절반만 남깁니다.

def bisect(f, a, b, tol=1e-10, maxit=200):
    fa = f(a)
    if fa * f(b) > 0:
        raise ValueError("f(a)와 f(b)의 부호가 같습니다.")
    for _ in range(maxit):
        m = (a + b) / 2
        fm = f(m)
        if fm == 0 or (b - a) / 2 < tol:
            return m
        if fa * fm < 0:
            b = m
        else:
            a, fa = m, fm
    return (a + b) / 2

매 단계 구간이 절반이 되므로 오차가 \(2^{-k}\)로 줄어듭니다(선형 수렴, 약 3.3단계마다 한 자리). 느리지만 부호가 바뀌는 구간만 있으면 반드시 수렴합니다.

4.1.2뉴턴 방법

현재 점에서 접선을 그어 그 접선의 근으로 옮깁니다: \(x_{k+1} = x_k - f(x_k)/f'(x_k)\).

def newton(f, df, x0, tol=1e-12, maxit=50):
    x = x0
    for k in range(maxit):
        step = f(x) / df(x)
        x -= step
        if abs(step) < tol:
            return x, k + 1
    raise RuntimeError("수렴하지 않았습니다.")

근 근처에서는 2차 수렴(맞는 자릿수가 매번 약 두 배)이라 매우 빠르지만, 출발점이 멀거나 \(f'\)이 0에 가까우면 발산할 수 있습니다. 실무에서는 이분법으로 좁힌 뒤 뉴턴으로 마무리하는 혼합 방법(브렌트 방법, scipy.optimize.brentq)을 씁니다.

예제 4.1.1

\(\sqrt2\)를 \(f(x) = x^2 - 2\)의 근으로 두 방법으로 구하고 반복 횟수를 비교하세요.

f = lambda x: x * x - 2
print(bisect(f, 1, 2))                       # 1.41421356..., 34번 반복
print(newton(f, lambda x: 2 * x, 1.0))       # (1.4142135623730951, 6)

뉴턴 방법은 1 → 1.5 → 1.4167 → 1.41422 → …로 다섯 번째에 기계 정밀도에 닿습니다.

요약
  1. 이분법: 확실하지만 느림(선형 수렴).
  2. 뉴턴: 빠르지만(2차 수렴) 좋은 출발점 필요.
  3. 실무는 혼합 방법(brentq).

4.1.3연습문제

응용

4.1.2

실습이분법과 뉴턴 방법, 어느 쪽이 얼마나 빠른가?

실습 · 근 찾기

다루는 성취기준 [응통4-04-01]

목표

같은 방정식을 이분법과 뉴턴 방법으로 풀면서, 반복할 때마다 오차가 어떻게 줄어드는지 비교합니다. 이분법은 오차가 반씩(선형 수렴), 뉴턴 방법은 맞는 자릿수가 두 배씩(이차 수렴) 늘어나는 것을 숫자로 확인하고, 뉴턴 방법이 시작값에 민감하다는 것도 봅니다. 성취기준 [응통4-04-01].

이분법: 부호가 다른 두 끝점의 구간을 반으로 나누어, 부호가 바뀌는 쪽 절반을 남기는 일을 되풀이합니다.

뉴턴 방법: 현재 점의 접선이 \(x\)축과 만나는 점으로 옮겨 갑니다. \(x_{k+1} = x_k - f(x_k)/f'(x_k)\).

준비

회색 곡선이 \(f(x)\), 회색 점선이 참 근입니다. 뉴턴 방법에서는 처음 네 걸음의 접선(빨강)을 그립니다. 출력에는 마지막 여섯 번 반복의 근사값과 참 근과의 오차를 보여 줍니다. 파이썬으로 같은 일을 하는 함수는 응통4-04-01 본문에 있습니다.

절차

  1. 이분법으로 반복을 5, 10, 20번으로 늘리며 마지막 오차를 적습니다. 반복 한 번에 오차가 대략 몇 배가 되나요?
  2. 뉴턴 방법(시작값 1)으로 바꾸어 반복 1~5번의 오차를 적습니다. 오차의 지수(e−n의 n)가 어떻게 늘어나나요?
  3. 오차 \(10^{-10}\)에 이르는 데 각 방법이 몇 번 반복하는지 비교합니다.
  4. 뉴턴 방법의 시작값을 0, −0.5, 2로 바꾸어 봅니다. 접선이 엉뚱한 곳으로 가는 경우가 있나요?
  5. 방정식을 \(\cos x - x\)로 바꾸어 같은 비교를 합니다.

기대 결과

  • 이분법은 반복마다 오차 상한이 정확히 절반이 됩니다. 실제 오차는 들쭉날쭉하지만 대략 \(2^{-k}\) 크기로 줄어, 오차 \(10^{-10}\)에 약 33번이 필요합니다.
  • 뉴턴 방법(\(x^3 + x - 1\), 시작값 1)은 \(x_1 = 0.75\), \(x_2 \approx 0.686047\), \(x_3 \approx 0.682340\), \(x_4 \approx 0.6823278\)으로, 오차가 약 \(7\times10^{-2}\), \(4\times10^{-3}\), \(1\times10^{-5}\), \(1\times10^{-10}\)처럼 지수가 거의 두 배씩 늘어납니다. 다섯 번이면 기계 정밀도에 닿습니다.
  • 시작값 0에서도 이 방정식은 빠르게 수렴합니다(\(f'(x) = 3x^2 + 1 > 0\)이라 접선이 수평이 되지 않음). 다른 함수에서는 시작값에 따라 발산하거나 다른 근으로 갈 수 있습니다(응통4 단원 연습 참조).
  • \(\cos x - x\)의 근은 0.7390851이고, 두 방법의 속도 차이는 같은 양상입니다.

분석

  1. 뉴턴 방법이 이렇게 빠른데 이분법을 쓰는 까닭은 무엇일까요? (도함수, 안정성을 생각하세요.)
  2. 최대가능도 추정에서 \(\ell'(\theta) = 0\)을 뉴턴 방법으로 풀 때 \(f\)와 \(f'\)은 각각 무엇인가요(응통15-03-01)?
  3. 반복을 멈추는 기준으로 "구간 폭 < 허용 오차"와 "\(|f(x_k)|\) < 허용 오차" 가운데 무엇이 더 안전한지 생각해 보세요.

더 해 보기
