바퀴를 다시 만들지 않기

평균, 난수, 날짜 계산은 이미 누군가 잘 만들어 두었습니다. 파이썬의 힘은 표준 라이브러리와 수십만 개의 외부 패키지에서 나옵니다.

2.1.1불러오기

import math
from statistics import mean, stdev
import random as rd
import numpy as np            # 외부 패키지: pip install numpy (Anaconda에는 포함)

math.sqrt(2); mean([1, 2, 3]); rd.seed(1); rd.random()

외부 패키지는 터미널에서 pip install 패키지명(또는 conda install)으로 설치합니다. 프로젝트마다 가상 환경(python -m venv .venv)을 만들면 패키지 버전이 섞이지 않습니다.

2.1.2나만의 모듈

같은 폴더에 mystats.py를 만들고 함수를 넣으면 다른 파일에서 불러올 수 있습니다.

# mystats.py
def mean_sd(xs):
    n = len(xs); m = sum(xs) / n
    return m, (sum((x - m) ** 2 for x in xs) / (n - 1)) ** 0.5

if __name__ == "__main__":          # 직접 실행할 때만 동작하는 시험 코드
    print(mean_sd([1, 3, 5, 7, 9]))

# analysis.py
from mystats import mean_sd
print(mean_sd([2, 4, 6]))           # (4.0, 2.0)

if __name__ == "__main__": 아래 코드는 모듈로 불러올 때는 실행되지 않습니다. 함수 정의와 시험 코드를 한 파일에 둘 수 있습니다.

요약
  1. import, from … import, as 별칭.
  2. pip/conda로 설치, 가상 환경으로 분리.
  3. 함수를 .py 파일로 나누고 __main__으로 시험.
