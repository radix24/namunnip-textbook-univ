연습파이썬 기초 문법 단원 마무리 연습

문제 6 · 실습·개념 · 힌트 2단계

다루는 성취기준 [응통4-01-01] [응통4-01-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습다음 코드의 출력을 예측하고 실행해 확인하세요. 각 연산자가 무엇을 하는지도 쓰세요. [01-01]

    print(7 // 2, 7 % 2, 7 / 2, 2 ** 10)
print([1, 2, 3, 4] * 2)
    힌트 1

    //는 몫, %는 나머지, **는 거듭제곱입니다.

    힌트 2

    리스트에 정수를 곱하면 원소마다 곱하는 것이 아니라 리스트를 이어 붙입니다.

    풀이

    첫 줄은 3 1 3.5 1024입니다. 파이썬 3에서 /는 정수끼리도 실수 나눗셈입니다.

    둘째 줄은 [1, 2, 3, 4, 1, 2, 3, 4]입니다. 원소마다 2를 곱하려면 [2 * v for v in xs]를 쓰거나 NumPy 배열을 써야 합니다(응통4-03-01). R의 벡터와 가장 크게 다른 점입니다.

  2. 실습라이브러리 없이 숫자 리스트의 평균과 표본표준편차를 튜플로 돌려주는 함수 mean_sd(xs)를 작성하고, [2, 4, 4, 5, 7, 8]로 시험하세요. 원소가 2개 미만이면 어떻게 처리할지도 정하세요. [01-01]

    힌트 1

    평균은 sum(xs) / len(xs)입니다. 표본분산은 편차 제곱합을 n - 1로 나눕니다.

    힌트 2

    원소가 1개면 n - 1 = 0으로 나누게 되므로, 미리 검사해 ValueError를 일으키는 것이 좋습니다.

    풀이 
    def mean_sd(xs):
    n = len(xs)
    if n < 2:
        raise ValueError("원소가 2개 이상 필요합니다")
    m = sum(xs) / n
    ss = sum((x - m) ** 2 for x in xs)
    return m, (ss / (n - 1)) ** 0.5

print(mean_sd([2, 4, 4, 5, 7, 8]))   # (5.0, 2.1908902300206643)

    R의 sd()와 같은 값(2.191)이 나옵니다.

  3. 개념다음 각 상황에 리스트, 튜플, 딕셔너리, 집합 가운데 무엇이 알맞은지 이유와 함께 쓰세요. (가) 학번으로 이름을 빠르게 찾기 (나) 응답에서 중복을 없앤 지역 목록 (다) 시간 순서대로 쌓이는 측정값 (라) 딕셔너리의 키로 쓸 (위도, 경도) 좌표 [01-02]

    힌트 1

    순서가 필요한지, 중복을 허용하는지, 값을 바꿀 수 있어야 하는지, 키로 찾는지를 보세요.

    힌트 2

    딕셔너리의 키는 바꿀 수 없는(해시 가능한) 값이어야 합니다.

    풀이

    (가) 딕셔너리: 키(학번)로 값(이름)을 평균적으로 일정한 시간에 찾습니다. (나) 집합: 중복을 자동으로 없애고 소속 여부 확인이 빠릅니다(순서는 보장되지 않음). (다) 리스트: 순서가 있고 append로 뒤에 덧붙이기 쉽습니다. (라) 튜플: 바꿀 수 없어 딕셔너리 키가 될 수 있습니다. 리스트는 키가 될 수 없습니다.

  4. 실습다음 코드의 출력을 예측하고, a가 바뀌지 않게 고치세요. [01-02]

    a = [1, 2]
b = a
b.append(3)
print(a)
    힌트 1

    b = a는 리스트를 복사하나요, 같은 리스트에 이름을 하나 더 붙이나요?

    힌트 2

    복사는 a.copy(), list(a), a[:]로 합니다.

    풀이

    출력은 [1, 2, 3]입니다. b = a는 같은 리스트 객체를 가리키는 이름을 하나 더 만들 뿐이라, b를 고치면 a도 바뀝니다.

    b = a.copy()로 고치면 a는 [1, 2]로 남습니다. 리스트 안에 리스트가 들어 있다면 안쪽까지 복사하는 copy.deepcopy(a)가 필요합니다. 함수에 리스트를 넘겨 안에서 고칠 때도 같은 일이 생깁니다.

  5. 실습0부터 9까지의 짝수의 제곱을 리스트 내포로 만들고 그 합을 구하세요. 같은 일을 for 반복문으로도 쓰세요. [01-01]

    힌트 1

    리스트 내포는 [식 for 변수 in 범위 if 조건] 꼴입니다.

    힌트 2

    짝수 조건은 i % 2 == 0입니다.

    풀이 
    sq = [i * i for i in range(10) if i % 2 == 0]   # [0, 4, 16, 36, 64]
print(sum(sq))                                  # 120

total = 0
for i in range(10):
    if i % 2 == 0:
        total += i * i

    range(10)은 0부터 9까지이며 10은 포함하지 않습니다.

  6. 실습문자열 "a b a c b a"에서 단어별 빈도를 딕셔너리로 세는 코드를 (1) 직접, (2) collections.Counter로 쓰세요. 가장 많이 나온 단어도 구하세요. [01-02]

    힌트 1

    문자열은 split()으로 단어 리스트가 됩니다.

    힌트 2

    d.get(w, 0)은 키가 없으면 0을 돌려줍니다.

    풀이 
    words = "a b a c b a".split()
d = {}
for w in words:
    d[w] = d.get(w, 0) + 1
print(d)                           # {'a': 3, 'b': 2, 'c': 1}

from collections import Counter
c = Counter(words)
print(c.most_common(1))            # [('a', 3)]

    가장 많이 나온 단어는 'a'(3번)입니다. 범주형 자료의 빈도표를 만드는 기본 방법입니다.
