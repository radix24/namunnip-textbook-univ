3.2.1행렬 연산

import numpy as np
A = np.array([[2., 1.], [1., 2.]])
b = np.array([3., 3.])
A @ b                      # 행렬 곱 (* 는 원소별 곱!)
np.linalg.solve(A, b)      # A x = b의 해 array([1., 1.])
np.linalg.det(A)           # 3.0
vals, vecs = np.linalg.eigh(A)   # 대칭 행렬 고유분해: vals = [1, 3]
U, s, Vt = np.linalg.svd(A)

@는 행렬 곱, *는 원소별 곱입니다. 역행렬을 직접 곱하기(inv(A) @ b)보다 solve가 빠르고 정확합니다(응통15 2.1절).

3.2.2난수

rng = np.random.default_rng(seed=2026)    # 씨앗을 정하면 재현 가능
rng.normal(loc=10, scale=2, size=5)       # 정규 (scale = 표준편차)
rng.binomial(n=20, p=0.3, size=5)
rng.exponential(scale=1/0.5, size=5)      # 비율 0.5 → scale 2
rng.choice([1, 2, 3], size=10, replace=True)
rng.permutation(10)

예전 방식 np.random.seed()와 np.random.normal()보다 생성기 객체(default_rng)를 쓰는 것이 권장됩니다. 지수분포는 비율이 아니라 평균(scale)을 받습니다.

예제 3.2.1

가상 자료 \(y = 1 + 2x + \varepsilon\)(\(n = 100\))을 만들고 정규방정식으로 회귀계수를 구하세요.

rng = np.random.default_rng(1)
x = rng.uniform(0, 10, 100)
y = 1 + 2 * x + rng.normal(0, 1, 100)
X = np.column_stack([np.ones(100), x])
beta = np.linalg.solve(X.T @ X, X.T @ y)   # 약 [1, 2]
np.linalg.lstsq(X, y, rcond=None)[0]       # QR/SVD 기반, 같은 값
요약
  1. @ 행렬 곱, solve, eigh, svd, lstsq.
  2. default_rng(seed)로 재현 가능한 난수.
  3. 분포마다 모수 이름(scale = 표준편차·평균)을 확인.

3.2.3연습문제

기본

  1. 상관 0.7인 이변량 표준정규 난수 1000쌍을 촐레스키 분해로 만드는 코드를 쓰세요.
    답

    L = np.linalg.cholesky(np.array([[1, .7], [.7, 1]])); Z = rng.standard_normal((1000, 2)); XY = Z @ L.T. np.corrcoef(XY.T)로 확인합니다.
