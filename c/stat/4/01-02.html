담는 그릇을 고르기

설문 응답 목록, (위도, 경도) 좌표, 단어별 빈도, 중복 없는 고객 ID처럼 자료의 성격에 따라 알맞은 그릇이 다릅니다.

1.2.1비교

구조예순서변경중복쓰임
리스트[3, 1, 3]있음가능허용순서 있는 값 모음
튜플(37.5, 127.0)있음불가허용고정된 묶음, 함수 반환값
딕셔너리{"서울": 3, "부산": 1}삽입 순가능열쇠는 유일열쇠로 값 찾기
집합{3, 1}없음가능없음중복 제거, 포함 여부

"이 원소가 들어 있는가"를 자주 묻는다면 리스트(원소 수에 비례해 느림)보다 집합이나 딕셔너리(거의 일정한 시간)가 빠릅니다.

1.2.2내포

squares = [x ** 2 for x in range(5)]                 # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]           # [0, 2, 4, 6, 8]
words = "가 나 가 다 나 가".split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1                       # {'가': 3, '나': 2, '다': 1}
unique = set(words)                                    # {'가', '나', '다'}
from collections import Counter
Counter(words).most_common(1)                          # [('가', 3)]
예제 1.2.1

학생 이름과 점수 쌍의 목록에서 80점 이상인 학생 이름의 집합과, 이름으로 점수를 찾는 딕셔너리를 만드세요.

records = [("민지", 85), ("서준", 72), ("하윤", 91)]
high = {name for name, s in records if s >= 80}     # {'민지', '하윤'}
score = dict(records)                               # {'민지': 85, ...}
score["하윤"]                                       # 91
요약
  1. 순서·변경: 리스트, 고정 묶음: 튜플, 열쇠-값: 딕셔너리, 중복 없음: 집합.
  2. 포함 여부 검사는 집합·딕셔너리가 빠름.
  3. 내포로 짧게 만듦.

1.2.3연습문제

기본

  1. 두 리스트 a = [1, 2, 3, 4], b = [3, 4, 5]에 공통인 원소를 구하세요.
    답

    set(a) & set(b) → {3, 4}.
