6.R.1

연습통계 계산 단원 마무리 연습

문제 6 · 실습·도전·판단 · 힌트 2단계

다루는 성취기준 [응통4-06-01] [응통4-06-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습R의 sleep 자료(두 집단 각 10개)를 파이썬으로 옮겨 scipy.stats.ttest_ind(g1, g2)를 실행했더니 R의 t.test(extra ~ group, data = sleep)와 자유도와 p값이 달랐습니다. 까닭과 R과 같은 결과를 얻는 방법을 쓰세요. [06-01]

    힌트 1

    두 함수의 등분산 가정 기본값을 비교하세요.

    힌트 2

    scipy는 equal_var 인수를 씁니다.

    풀이

    scipy의 ttest_ind는 기본이 equal_var=True(합동분산 t 검정, 자유도 18, p = 0.0792)이고, R의 t.test는 기본이 웰치 검정(자유도 17.8, p = 0.0794)입니다. t 값은 두 집단 크기가 같아 −1.861로 같습니다.

    ttest_ind(g1, g2, equal_var=False)로 쓰면 R과 같은 웰치 결과가 나옵니다. 다만 이 자료는 같은 사람의 대응 자료이므로 실제로는 ttest_rel이 알맞습니다(다음 문제).

  2. 실습같은 자료로 대응표본 t 검정을 하는 scipy 코드를 쓰고 결과를 쓰세요. 인수의 순서를 바꾸면 무엇이 달라지나요? [06-01]

    힌트 1

    대응표본 검정은 scipy.stats.ttest_rel(a, b)입니다.

    힌트 2

    차이는 a - b로 계산됩니다.

    풀이 
    from scipy import stats
res = stats.ttest_rel(g2, g1)
print(res.statistic, res.pvalue)   # 4.062..., 0.00283...

    t = 4.06, p = 0.0028로 R의 paired = TRUE 결과와 같습니다. 인수 순서를 바꾸면(ttest_rel(g1, g2)) t의 부호만 −4.06으로 바뀌고 양측 p값은 같습니다.

  3. 실습statsmodels의 수식 인터페이스로 mtcars의 mpg ~ wt 회귀를 적합하는 코드를 쓰고, 계수와 결정계수를 쓰세요. [06-01]

    힌트 1

    import statsmodels.formula.api as smf, smf.ols("mpg ~ wt", data=df).fit()을 씁니다.

    힌트 2

    fit.params, fit.rsquared, fit.summary()로 결과를 봅니다.

    풀이 
    import statsmodels.formula.api as smf
fit = smf.ols("mpg ~ wt", data=df).fit()
print(fit.params, fit.rsquared)
print(fit.summary())

    계수는 절편 37.285, 기울기 −5.344, \(R^2 = 0.753\)으로 R의 lm과 같습니다(응통3-05-02). R과 같은 수식 문법을 쓰므로 범주형 변수는 C(cyl)처럼 표시합니다.

  4. 실습"주사위를 4번 던져 6이 적어도 한 번 나올 확률"을 정확히 계산하고, NumPy 모의실험 10만 번으로 확인하는 코드를 쓰세요. [06-02]

    힌트 1

    여사건은 "4번 모두 6이 아님"입니다.

    힌트 2

    rng.integers(1, 7, size=(100000, 4))는 1~6의 정수로 된 10만×4 배열을 만듭니다.

    풀이

    정확한 값은 \(1 - (5/6)^4 \approx 0.5177\)입니다.

    import numpy as np
rng = np.random.default_rng(1)
rolls = rng.integers(1, 7, size=(100_000, 4))
print((rolls == 6).any(axis=1).mean())

    모의실험 값은 표준오차 약 0.0016 안팎에서 0.518 근처로 나옵니다. integers의 위쪽 끝(7)은 포함되지 않음에 주의하세요.

  5. 도전정규분포에서 크기 10인 표본을 뽑아 (가) \(\bar x \pm t_{0.025,9}\,s/\sqrt{10}\), (나) \(\bar x \pm 1.96\,s/\sqrt{10}\)으로 95% 신뢰구간을 만들 때, 각 구간이 참 평균을 포함하는 비율을 모의실험으로 추정하는 코드를 쓰고 이론값을 쓰세요. [06-02]

    힌트 1

    참 평균을 0으로 두고, 각 반복에서 구간이 0을 포함하는지 셉니다.

    힌트 2

    (나)의 이론 포함 확률은 \(P(|T_9| \le 1.96)\)입니다.

    풀이 
    import numpy as np
from scipy import stats
rng = np.random.default_rng(7)
x = rng.standard_normal((100_000, 10))
m, s = x.mean(axis=1), x.std(axis=1, ddof=1)
se = s / np.sqrt(10)
t = stats.t.ppf(0.975, df=9)
print((np.abs(m) <= t * se).mean(), (np.abs(m) <= 1.96 * se).mean())

    (가)는 0.95 근처, (나)는 이론값 \(P(|T_9| \le 1.96) \approx 0.918\) 근처가 나옵니다. 표본이 작을 때 \(s\)로 \(\sigma\)를 바꾸고도 \(z\) 값을 쓰면 구간이 너무 좁아 포함 확률이 명목값보다 낮아집니다(응통5-03-02).

  6. 판단모의실험으로 확률(0.5 근처)을 소수 셋째 자리까지 믿을 만하게(표준오차 0.001 이하) 추정하려면 반복을 몇 번 해야 하는지 계산하세요. 반복을 10배 늘리면 표준오차는 어떻게 되나요? [06-02]

    힌트 1

    비율 추정의 표준오차는 \(\sqrt{p(1-p)/n}\)입니다.

    힌트 2

    \(p = 0.5\)일 때 \(p(1-p) = 0.25\)로 가장 큽니다.

    풀이

    \(\sqrt{0.25/n} \le 0.001\)에서 \(n \ge 250000\)이므로 25만 번이 필요합니다. 반복을 10배 늘리면 표준오차는 \(1/\sqrt{10} \approx 0.32\)배로 줄어듭니다. 모의실험 결과를 보고할 때는 반복 횟수와 이 모의실험 오차를 함께 적는 것이 좋습니다.
