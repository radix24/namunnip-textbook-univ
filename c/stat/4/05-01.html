파이썬의 데이터프레임

pandas는 표 형태 자료를 다루는 표준 도구입니다. R의 데이터프레임과 dplyr이 하는 일을 대부분 할 수 있습니다.

5.1.1읽기와 둘러보기

import pandas as pd
df = pd.read_csv("survey.csv", encoding="cp949", na_values=["", "-", "999"])
df.head(); df.info(); df.describe()
df.shape; df.columns; df.dtypes

5.1.2고르기와 만들기

df["age"]                         # 열 하나 (Series)
df[["age", "income"]]             # 여러 열
df[df["age"] >= 30]               # 조건으로 행
df.loc[df["sex"] == "F", ["age", "income"]]   # 행 조건 + 열 이름
df.iloc[0:5, 0:2]                 # 위치로
df = df.assign(log_inc=np.log(df["income"]))  # 새 열
df["agegrp"] = pd.cut(df["age"], bins=[0, 29, 39, 49, 200],
                      labels=["20대 이하", "30대", "40대", "50대 이상"])

loc은 이름(열 이름, 행 이름표), iloc은 정수 위치입니다. 조건을 여러 개 묶을 때는 &, |와 괄호를 씁니다: df[(df.age > 30) & (df.sex == "F")].

5.1.3결측과 형

df.isna().sum()                   # 열별 결측 수
df = df.dropna(subset=["income"]) # 소득 결측 행 제거
df["income"] = pd.to_numeric(df["income"].str.replace(",", ""), errors="coerce")
df["date"] = pd.to_datetime(df["date"])
df["sex"] = df["sex"].replace({"남자": "M", "남": "M", "여자": "F", "여": "F"}).astype("category")

errors="coerce"는 숫자로 바꿀 수 없는 값을 결측(NaN)으로 만듭니다. 처리 전후의 행 수와 결측 수를 기록해 둡니다.

  2. df[조건], loc(이름), iloc(위치), assign.
  3. isna, to_numeric(errors="coerce"), to_datetime.
