계산이 맞는지 실험으로 확인

확률 문제는 직관이 자주 틀립니다. 계산 결과가 맞는지 확인하는 가장 확실한 방법은 컴퓨터로 수만 번 실험해 보는 것입니다.

6.2.1생일 문제

23명 중 생일이 같은 사람이 있을 확률은 \(1 - \frac{365\cdot364\cdots343}{365^{23}} \approx 0.507\)입니다.

import numpy as np
rng = np.random.default_rng(0)
B, n = 100_000, 23
days = rng.integers(0, 365, size=(B, n))
has_dup = np.array([len(set(r)) < n for r in days])
p = has_dup.mean(); se = np.sqrt(p * (1 - p) / B)
print(f"{p:.4f} ± {1.96 * se:.4f}")       # 약 0.507 ± 0.003

exact = 1 - np.prod((365 - np.arange(n)) / 365)
print(round(exact, 4))                    # 0.5073

모의실험 추정값은 표준오차 \(\sqrt{p(1-p)/B}\)와 함께 보고합니다. \(B = 10^5\)이면 약 ±0.003입니다.

6.2.2몬티 홀 문제

B = 100_000
car = rng.integers(0, 3, B); pick = rng.integers(0, 3, B)
stay_win = (car == pick).mean()          # 약 1/3
switch_win = 1 - stay_win                # 바꾸면 약 2/3 (사회자가 늘 염소 문을 열므로)
print(stay_win, switch_win)

처음 고른 문이 맞을 확률은 1/3이고, 바꾸는 전략은 처음 선택이 틀렸을 때(확률 2/3) 이깁니다. 많은 사람이 1/2이라고 믿었던 문제입니다.

요약
  1. 사건을 난수로 흉내 내고 비율을 셈.
  2. 표준오차 \(\sqrt{p(1-p)/B}\)와 함께 보고.
  3. 정확한 계산과 비교해 둘 다 검증.
