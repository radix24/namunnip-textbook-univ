이 절에서 배울 것
  • 적재의 회전 불확정성을 이해한다.
  • 배리맥스(직교)와 프로맥스(사교) 회전으로 단순 구조를 찾는다.
먼저 알아야 할 것
  • 인자 모형 (4.1절), 직교 행렬 (응통2 3.3절).

같은 설명, 다른 축

직교 행렬 \(T\)에 대해 \(L^* = LT\)도 \(L^*L^{*\top} = LL^\top\)이라 공분산을 똑같이 설명합니다. 축을 어떻게 돌리든 맞춤의 정도는 같으므로, 해석하기 쉬운 방향으로 돌릴 수 있습니다.

4.2.1단순 구조

해석하기 쉬운 적재는 각 변수가 인자 하나에만 크게 실리고 나머지에는 0에 가까운 모양입니다(단순 구조). 그러면 "인자 1 = 언어 과목들, 인자 2 = 수리 과목들"처럼 이름을 붙일 수 있습니다.

  • 배리맥스(직교): 각 인자 열에서 적재 제곱의 분산을 최대화해 큰 것은 더 크게, 작은 것은 0에 가깝게. 인자들은 무상관으로 유지.
  • 프로맥스, 오블리민(사교): 인자 사이 상관을 허용. 언어 능력과 수리 능력처럼 실제로 상관된 요인에 자연스럽습니다. 인자 상관 행렬도 함께 보고합니다.
예제 4.2.1

R로 6개 과목 점수 상관 행렬에 2인자 모형을 적합하고 회전 전후 적재를 비교하는 코드를 쓰세요.

fa0 <- factanal(covmat = R, factors = 2, n.obs = 220, rotation = "none")
fa1 <- factanal(covmat = R, factors = 2, n.obs = 220, rotation = "varimax")
print(fa0$loadings, cutoff = 0.3); print(fa1$loadings, cutoff = 0.3)

회전 전에는 첫 인자에 모든 과목이 크게 실리고(전반 능력) 둘째 인자는 부호가 갈리지만, 회전 뒤에는 언어 과목과 수리 과목이 각각 다른 인자에 모입니다. 고유분산과 적합도는 회전 전후가 같습니다.

요약
  1. \(LT\)도 같은 공분산 → 회전 불확정.
  2. 단순 구조를 향해 회전, 배리맥스(직교), 프로맥스(사교).
  3. 인자 이름 붙이기는 해석이므로 근거와 함께.

4.2.2연습문제

기본

  1. 회전하면 공통성은 바뀌나요?
    답

    바뀌지 않습니다. 각 행의 적재 제곱합은 직교 회전에 불변입니다.
