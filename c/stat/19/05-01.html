어느 집단에 속할까

은행이 고객의 소득, 부채, 연체 이력으로 대출 상환 여부를 예측하거나, 꽃의 크기로 종을 맞추는 문제처럼, 측정값으로 집단을 고르는 것이 분류입니다.

5.1.1피셔의 판별

두 집단의 측정값을 한 방향 \(\mathbf a\)로 사영해 점수 \(y = \mathbf a^\top\mathbf x\)를 만들 때, 집단 평균 차는 크고 집단 안 퍼짐은 작게 하고 싶습니다.

정리 5.1.1

\(\dfrac{[\mathbf a^\top(\bar{\mathbf x}_1 - \bar{\mathbf x}_2)]^2}{\mathbf a^\top S_p\mathbf a}\)를 최대화하는 방향은 \(\mathbf a \propto S_p^{-1}(\bar{\mathbf x}_1 - \bar{\mathbf x}_2)\).

코시-슈바르츠 부등식으로 보입니다. 분류 규칙: 점수가 두 집단 평균 점수의 가운데 \(\frac12\mathbf a^\top(\bar{\mathbf x}_1 + \bar{\mathbf x}_2)\)보다 크면 집단 1.

5.1.2베이즈 규칙과의 관계

두 집단이 공분산이 같은 다변량 정규이고 사전 확률이 \(\pi_1, \pi_2\)이면, 사후 확률이 큰 쪽으로 분류하는 베이즈 규칙은 \(\mathbf a^\top\mathbf x > \frac12\mathbf a^\top(\bar{\mathbf x}_1 + \bar{\mathbf x}_2) + \log(\pi_2/\pi_1)\)입니다. 피셔 판별에 사전 확률 보정이 더해진 것입니다. 공분산이 집단마다 다르면 경계가 이차 곡선인 이차판별(QDA)이 됩니다. 로그 사후 오즈가 \(\mathbf x\)의 일차식이라는 점에서 로지스틱 회귀(응통18)와 같은 꼴이지만, 판별분석은 \(\mathbf x\)의 분포를 가정하고 로지스틱은 가정하지 않습니다.

예제 5.1.2

\(\bar{\mathbf x}_1 = (2, 2)\), \(\bar{\mathbf x}_2 = (0, 0)\), \(S_p = I\)일 때 판별 방향과 \((1.5, 0.2)\)의 분류는?

풀이. \(\mathbf a = (2, 2)\). 경계 \(\frac12\mathbf a^\top(2,2) = 4\). 점수 \(2(1.5) + 2(0.2) = 3.4 < 4\), 집단 2.

library(MASS); fit <- lda(Species ~ ., data = iris); predict(fit)$class
요약
  1. 판별 방향 \(S_p^{-1}(\bar{\mathbf x}_1 - \bar{\mathbf x}_2)\).
  2. 정규·동일 공분산이면 베이즈 규칙(사전 확률 보정).
  3. 공분산이 다르면 이차판별.

기본
