2.1호텔링 T² 검정

[응통19-02-01] 호텔링 T² 검정으로 평균벡터를 검정할 수 있다. 계산 서울대 · 성균관대

이 절에서 배울 것
  • 평균벡터에 대한 일표본·이표본 호텔링 \(T^2\) 검정을 한다.
  • 변수마다 t 검정을 하는 것과의 차이를 안다.
먼저 알아야 할 것
  • 평균벡터와 공분산 (1.1절), 응통5 4.2절 t 검정.

t 검정을 여러 변수로

신약이 혈압, 콜레스테롤, 혈당 세 지표를 함께 바꾸는지 보려면 t 검정을 세 번 할 수도 있지만, 다중 비교 문제가 생기고 변수 사이 상관도 무시합니다. 세 평균을 한꺼번에 검정하는 것이 호텔링 \(T^2\)입니다.

2.1.1일표본

일변량 \(t^2 = n(\bar x - \mu_0)^2/s^2\)을 행렬로 넓히면

결과 2.1.1

\(T^2 = n(\bar{\mathbf x} - \boldsymbol\mu_0)^\top S^{-1}(\bar{\mathbf x} - \boldsymbol\mu_0)\). 다변량 정규 아래 \(H_0: \boldsymbol\mu = \boldsymbol\mu_0\)이면 \(\dfrac{n-p}{p(n-1)}T^2 \sim F(p, n-p)\).

\(T^2\)는 표본 평균의 마할라노비스 거리(표준오차 척도)입니다. 각 변수의 t가 작아도 상관 구조에 어긋나는 방향으로 벗어나면 \(T^2\)는 클 수 있고, 그 반대도 가능합니다.

2.1.2이표본

두 집단 평균벡터 비교: 합동 공분산 \(S_p = \frac{(n_1-1)S_1 + (n_2-1)S_2}{n_1 + n_2 - 2}\)로

\[T^2 = \frac{n_1n_2}{n_1 + n_2}(\bar{\mathbf x}_1 - \bar{\mathbf x}_2)^\top S_p^{-1}(\bar{\mathbf x}_1 - \bar{\mathbf x}_2),\quad \frac{n_1 + n_2 - p - 1}{p(n_1 + n_2 - 2)}T^2 \sim F(p, n_1 + n_2 - p - 1).\]

두 집단의 공분산이 같다고 가정합니다. 기각되면 어느 변수가 다른지 동시 신뢰구간(셰페형 또는 본페로니)으로 봅니다.

예제 2.1.1

iris의 versicolor와 virginica(각 50송이)를 꽃잎 길이·너비로 비교하세요.

a <- iris[iris$Species == "versicolor", 3:4]; b <- iris[iris$Species == "virginica", 3:4]
d <- colMeans(a) - colMeans(b); Sp <- (49 * cov(a) + 49 * cov(b)) / 98
T2 <- (50 * 50 / 100) * t(d) %*% solve(Sp) %*% d
F <- (100 - 2 - 1) / (2 * 98) * T2; 1 - pf(F, 2, 97)

두 종의 꽃잎 크기 평균벡터는 매우 뚜렷하게 다릅니다(p값이 사실상 0).

요약
  1. \(T^2\) = 평균벡터 차의 마할라노비스 거리 × 표본 크기.
  2. F 분포로 변환해 검정.
  3. 변수별 t 검정보다 상관을 반영하고 오류율을 지킴.

2.1.3연습문제

기본

  1. \(p = 1\)이면 \(T^2\)는 무엇과 같나요?
    답

    일변량 t 통계량의 제곱. F(1, n−1) = \(t_{n-1}^2\).
