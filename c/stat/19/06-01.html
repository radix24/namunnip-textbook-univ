이름표 없는 집단 찾기

판별분석은 집단을 알고 규칙을 만들지만, 군집분석은 집단을 모르는 상태에서 비슷한 관측끼리 묶습니다. 고객 세분화, 유전자 발현 패턴 분류에 씁니다.

6.1.1계층적 군집

  1. 모든 관측을 각자 한 군집으로 시작.
  2. 가장 가까운 두 군집을 합침.
  3. 하나가 될 때까지 반복하고, 합친 순서와 거리를 덴드로그램으로 그림.

군집 사이 거리(연결 방법): 단일(가장 가까운 점), 완전(가장 먼 점), 평균, 워드(합칠 때 군집 내 제곱합 증가가 가장 작은 것). 워드는 비슷한 크기의 둥근 군집을, 단일은 길게 이어진 사슬을 만들기 쉽습니다. 덴드로그램을 원하는 높이에서 자르면 군집이 정해집니다.

6.1.2k-평균

  1. 군집 수 \(k\)와 초기 중심을 정함.
  2. 각 관측을 가장 가까운 중심에 배정.
  3. 각 군집의 평균으로 중심을 갱신.
  4. 배정이 바뀌지 않을 때까지 2~3 반복.

군집 내 제곱합 \(\sum_k\sum_{i\in C_k}\|\mathbf x_i - \bar{\mathbf x}_k\|^2\)을 매 단계 줄이지만 국소 최소에 빠질 수 있어 여러 초기값(nstart)으로 돌립니다. \(k\)는 군집 내 제곱합의 팔꿈치, 실루엣 폭, 해석 가능성으로 고릅니다.

예제 6.1.1

iris의 측정값 4개(표준화)로 k-평균(\(k = 3\))을 하고 실제 종과 비교하세요.

X <- scale(iris[, 1:4]); set.seed(1)
km <- kmeans(X, centers = 3, nstart = 25); table(km$cluster, iris$Species)
hc <- hclust(dist(X), method = "ward.D2"); plot(hc); cutree(hc, 3)

setosa는 한 군집으로 완벽히 묶이고, versicolor와 virginica는 일부가 섞입니다. 군집은 이름표를 쓰지 않았는데도 실제 종 구조를 상당 부분 되찾습니다.

요약
  1. 계층적: 가까운 군집부터 합침, 연결 방법이 결과를 바꿈.
  2. k-평균: 배정과 중심 갱신 반복, 여러 초기값.
  3. 변수 표준화와 군집 수 선택이 핵심.

6.1.3연습문제

기본

    답
