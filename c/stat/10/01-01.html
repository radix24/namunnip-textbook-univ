자료를 만든 규칙을 모형으로

응통5에서는 자료에 직선을 맞추는 계산을 했습니다. 이제 그 직선이 무엇을 추정하는지 묻습니다. 자료가 "참 직선 + 우연한 오차"로 만들어졌다고 가정하면, 최소제곱 직선의 기울기는 참 기울기의 추정량이 되고 그 정확도를 계산할 수 있습니다.

1.1.1모형

정의 1.1.1

단순 선형회귀 모형: \(Y_i = \beta_0 + \beta_1x_i + \varepsilon_i\), \(i = 1, \ldots, n\). \(x_i\)는 주어진 상수, 오차 \(\varepsilon_i\)는 서로 독립이고 \(E(\varepsilon_i) = 0\), \(\mathrm{Var}(\varepsilon_i) = \sigma^2\). 추론을 할 때는 \(\varepsilon_i \sim N(0, \sigma^2)\)도 가정합니다.

가정은 네 가지입니다. 평균이 \(x\)의 일차식(선형성), 오차의 독립성, 분산 일정(등분산성), 정규성. 04단원에서 이 가정을 자료로 점검합니다.

1.1.2최소제곱 추정

\(Q(b_0, b_1) = \sum(y_i - b_0 - b_1x_i)^2\)을 최소화합니다. 편미분을 0으로 두면 정규방정식

\[\sum(y_i - b_0 - b_1x_i) = 0, \qquad \sum x_i(y_i - b_0 - b_1x_i) = 0\]

을 얻고, 풀면 \(S_{xx} = \sum(x_i - \bar x)^2\), \(S_{xy} = \sum(x_i - \bar x)(y_i - \bar y)\)에 대해

결과 1.1.2 \[\hat\beta_1 = \frac{S_{xy}}{S_{xx}}, \qquad \hat\beta_0 = \bar y - \hat\beta_1\bar x.\]

정규방정식은 "잔차의 합 = 0", "잔차와 \(x\)의 곱의 합 = 0"을 뜻합니다. 잔차가 \(x\)와 아무 직선 관계도 남기지 않게 직선을 고른 것입니다.

1.1.3추정량의 성질

정리 1.1.2

\(E(\hat\beta_1) = \beta_1\), \(\mathrm{Var}(\hat\beta_1) = \dfrac{\sigma^2}{S_{xx}}\). \(E(\hat\beta_0) = \beta_0\), \(\mathrm{Var}(\hat\beta_0) = \sigma^2\left(\dfrac1n + \dfrac{\bar x^2}{S_{xx}}\right)\).

\(\sum(x_i - \bar x) = 0\)이므로 \(S_{xy} = \sum(x_i - \bar x)Y_i\), 곧 \(\hat\beta_1 = \sum c_iY_i\), \(c_i = (x_i - \bar x)/S_{xx}\). \(\sum c_i = 0\), \(\sum c_ix_i = 1\)이므로 \(E(\hat\beta_1) = \sum c_i(\beta_0 + \beta_1x_i) = \beta_1\). 독립이므로 \(\mathrm{Var}(\hat\beta_1) = \sigma^2\sum c_i^2 = \sigma^2/S_{xx}\). \(\hat\beta_0\)도 \(Y_i\)의 일차식으로 써서 같은 방법으로 구합니다(\(\bar Y\)와 \(\hat\beta_1\)의 공분산이 0임을 씀). ∎

\(S_{xx}\)가 클수록, 곧 \(x\)를 넓게 퍼뜨려 실험할수록 기울기가 정확해집니다. 실험 설계에 바로 쓰이는 결론입니다.

\(\sigma^2\)의 불편추정량은 \(s^2 = \mathrm{MSE} = \frac{1}{n-2}\sum e_i^2\)입니다. 모수 두 개를 추정했으므로 자유도가 2 줄어듭니다.

예제 1.1.3

R의 cars 자료(속도 speed, 제동 거리 dist, \(n = 50\))에 직선을 적합하세요.

풀이. fit <- lm(dist ~ speed, data = cars); summary(fit). \(\hat\beta_1 = 3.932\), \(\hat\beta_0 = -17.58\), \(s = 15.38\). 속도가 1 mph 오를 때 제동 거리가 평균 약 3.9 ft 늘어납니다. 절편 −17.6은 속도 0에서의 거리라 물리적 의미가 없습니다. 자료 범위(4~25 mph) 밖으로 해석하지 않습니다.

요약
  1. \(\hat\beta_1 = S_{xy}/S_{xx}\), \(\hat\beta_0 = \bar y - \hat\beta_1\bar x\).
  2. 둘 다 불편, \(\mathrm{Var}(\hat\beta_1) = \sigma^2/S_{xx}\).
  3. \(s^2 = \mathrm{SSE}/(n-2)\).

1.1.4연습문제

기본

  1. \(x\) = 1, 2, 3, 4, 5, \(y\) = 3, 5, 4, 7, 6일 때 \(\hat\beta_0, \hat\beta_1, s^2\)을 구하세요.
    답

    \(\bar x = 3\), \(\bar y = 5\), \(S_{xx} = 10\), \(S_{xy} = (-2)(-2) + (-1)(0) + 0 + (1)(2) + (2)(1) = 8\). \(\hat\beta_1 = 0.8\), \(\hat\beta_0 = 2.6\). 적합값 3.4, 4.2, 5.0, 5.8, 6.6, 잔차 −0.4, 0.8, −1.0, 1.2, −0.6, SSE = 3.6, \(s^2 = 1.2\).

응용

  1. \(x\)를 [0, 10]에서 10개 고를 수 있다면 기울기를 가장 정확히 추정하는 배치는?
    답

    \(S_{xx}\)를 최대로: 0에 5개, 10에 5개. 다만 이렇게 하면 직선성을 점검할 수 없으므로 실제로는 가운데에도 몇 개 둡니다.
