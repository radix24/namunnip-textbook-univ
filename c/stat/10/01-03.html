평균 차와 내 차

"속도 20 mph로 달리는 차들의 평균 제동 거리"와 "지금 20 mph로 달리는 이 차의 제동 거리"는 다른 질문입니다. 앞의 것은 직선 위 한 점의 위치를 묻고, 뒤의 것은 거기에 개별 차의 우연한 차이까지 더해집니다.

1.3.1평균 반응의 신뢰구간

\(\hat\mu_0 = \hat\beta_0 + \hat\beta_1x_0 = \bar Y + \hat\beta_1(x_0 - \bar x)\). \(\bar Y\)와 \(\hat\beta_1\)이 무상관이므로

\[\mathrm{Var}(\hat\mu_0) = \sigma^2\left(\frac1n + \frac{(x_0 - \bar x)^2}{S_{xx}}\right).\]
결과 1.3.1

\(E(Y \mid x_0)\)의 신뢰구간: \(\hat\mu_0 \pm t_{\alpha/2, n-2}\,s\sqrt{\dfrac1n + \dfrac{(x_0 - \bar x)^2}{S_{xx}}}\).

1.3.2예측구간

새 관측값 \(Y_0 = \beta_0 + \beta_1x_0 + \varepsilon_0\)은 기존 자료와 독립입니다. 예측 오차 \(Y_0 - \hat\mu_0\)의 분산은 두 분산의 합입니다.

결과 1.3.2

\(Y_0\)의 예측구간: \(\hat\mu_0 \pm t_{\alpha/2, n-2}\,s\sqrt{1 + \dfrac1n + \dfrac{(x_0 - \bar x)^2}{S_{xx}}}\).

두 구간 모두 \(x_0 = \bar x\)에서 가장 좁고 멀어질수록 넓어집니다. \(n\)이 커지면 신뢰구간은 0 너비로 줄지만 예측구간은 \(\pm 1.96\sigma\)보다 좁아지지 않습니다. 개인의 우연한 차이는 자료를 아무리 모아도 없어지지 않기 때문입니다.

예제 1.3.1

cars에서 속도 20 mph일 때 두 구간을 구하세요.

풀이.

new <- data.frame(speed = 20)
predict(fit, new, interval = "confidence")   # 61.07 [55.25, 66.89]
predict(fit, new, interval = "prediction")   # 61.07 [29.60, 92.54]

20 mph 차들의 평균 제동 거리는 약 55~67 ft로 꽤 좁게 추정되지만, 한 대의 제동 거리는 30~93 ft로 훨씬 넓습니다.

요약
  1. 신뢰구간: 평균 반응, \(\sqrt{1/n + (x_0-\bar x)^2/S_{xx}}\).
  2. 예측구간: 새 관측값, 근호 안에 1이 더해짐.
  3. \(\bar x\)에서 멀어질수록, 특히 자료 범위 밖에서 넓어집니다.

1.3.3연습문제

기본

  1. 1.1절 연습 자료에서 \(x_0 = 3\)의 평균 반응 95% 신뢰구간은?
    답

    \(\hat\mu_0 = 5\), \(\mathrm{se} = \sqrt{1.2/5} = 0.49\), \(5 \pm 3.182 \times 0.49 = 5 \pm 1.56\).
