한 번 끝까지 해 보기

각 단원의 도구를 따로 배웠습니다. 실제 분석은 이 도구들을 순서대로, 때로는 되돌아가며 씁니다. R에 들어 있는 mtcars로 "연비를 무엇이 결정하는가"를 끝까지 분석해 봅니다.

7.1.1단계

  1. 질문 정하기: 예측이 목적인가(변수 선택, 교차검증 중심), 특정 변수의 효과를 아는 것이 목적인가(교란 변수 보정, 계수 해석 중심)? 여기서는 "무게가 연비에 주는 효과"를 다른 특성을 보정해 추정합니다.
  2. 탐색: pairs(mtcars[, c("mpg","wt","hp","disp","am")])로 산점도 행렬을 보고, 곡선 관계와 이상값, 설명변수끼리의 상관을 확인합니다. mpg와 wt, hp는 곡선 관계가 약간 보입니다.
  3. 첫 모형: m <- lm(mpg ~ wt + hp + am, data = mtcars).
  4. 진단: plot(m). 잔차-적합값 그림에 U자 무늬가 약하게 있고 오른쪽 끝 몇 대(Toyota Corolla, Fiat 128)의 잔차가 큽니다. VIF는 5 미만.
  5. 수정: 반응을 log(mpg)로 바꾸거나 연비 대신 연료 소비율 \(1/\text{mpg}\)(갤런/마일)을 쓰면 무게와의 관계가 직선에 가까워집니다. 물리적으로도 연료 소비는 무게에 비례하는 편이 자연스럽습니다.
  6. 추론: 최종 모형의 무게 계수와 95% 신뢰구간을 구합니다. confint(m2).
  7. 민감도 확인: 영향점을 뺀 결과, 다른 변수 조합의 결과가 결론을 바꾸는지 봅니다.
예제 7.1.1

위 흐름에서 쓰는 R 코드를 한곳에 모으세요.

d <- transform(mtcars, gpm = 100 / mpg)        # 100마일당 갤런
m1 <- lm(mpg ~ wt + hp + am, data = d)
m2 <- lm(gpm ~ wt + hp + am, data = d)
par(mfrow = c(2, 2)); plot(m1); plot(m2)
summary(m2); confint(m2)
car::vif(m2); which(cooks.distance(m2) > 4 / nrow(d))
summary(update(m2, subset = cooks.distance(m2) <= 4 / nrow(d)))
주의 32대의 1974년 자동차 자료는 관측 자료이고 표본도 작습니다. "무게를 줄이면 연비가 이만큼 오른다"는 인과 해석에는 조심해야 합니다(응통5 1.1절).
요약
  1. 질문 → 탐색 → 적합 → 진단 → 수정 → 추론 → 민감도.
  2. 진단 결과에 따라 앞 단계로 돌아갑니다.
  3. 변환은 통계적 근거와 해석 가능성을 함께 봅니다.

7.1.2연습문제

응용

  1. R의 airquality 자료로 오존(Ozone)을 태양 복사, 풍속, 기온으로 설명하는 분석을 위 단계대로 수행하세요.
    답

    결측값을 먼저 처리하고(na.omit), 진단에서 나팔 모양과 오른쪽 꼬리가 보이므로 log(Ozone)을 반응으로 쓰면 가정이 크게 개선됩니다. 풍속과 기온의 계수가 뚜렷하게 유의합니다.
