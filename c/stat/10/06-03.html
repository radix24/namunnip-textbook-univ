조금 치우치더라도 덜 흔들리게

다중공선성이 있거나 변수가 많으면 최소제곱 계수는 불편이지만 분산이 큽니다. MSE = 분산 + 치우침²이므로, 계수를 0 쪽으로 조금 당겨 치우침을 감수하고 분산을 크게 줄이면 전체 오차가 줄어들 수 있습니다.

6.3.1능형 회귀

정의 6.3.1

\(\hat{\boldsymbol\beta}_{\text{ridge}} = \arg\min_{\mathbf b}\left\{\|\mathbf y - X\mathbf b\|^2 + \lambda\sum_{j \ge 1}b_j^2\right\} = (X^\top X + \lambda I)^{-1}X^\top\mathbf y\) (설명변수는 표준화, 절편은 벌점에서 제외).

\(\lambda I\)를 더하면 \(X^\top X\)가 거의 특이할 때도 역행렬이 안정됩니다. \(\lambda = 0\)이면 최소제곱, \(\lambda \to \infty\)이면 계수가 모두 0으로 갑니다. 계수는 작아지지만 정확히 0이 되지는 않습니다.

6.3.2라쏘

정의 6.3.2

\(\hat{\boldsymbol\beta}_{\text{lasso}} = \arg\min_{\mathbf b}\left\{\|\mathbf y - X\mathbf b\|^2 + \lambda\sum_{j\ge1}|b_j|\right\}\).

절댓값 벌점은 원점에서 뾰족하기 때문에 \(\lambda\)가 적당히 크면 일부 계수를 정확히 0으로 만듭니다. 그래서 축소와 변수 선택을 한꺼번에 합니다. 기하학적으로는 제약 영역이 능형은 원(구), 라쏘는 꼭짓점이 축 위에 있는 마름모이고, SSE의 등고선이 마름모의 꼭짓점에 먼저 닿기 쉬워 일부 좌표가 0이 됩니다. 닫힌 꼴 해는 없고 좌표 하강법으로 계산합니다.

6.3.3\(\lambda\) 고르기

\(\lambda\)를 여러 값으로 바꿔 교차검증 오차가 가장 작은 값을 고르거나, 그보다 표준오차 하나만큼 큰 오차를 허용하는 가장 큰 \(\lambda\)(더 단순한 모형)를 고릅니다.

library(glmnet)
X <- scale(as.matrix(mtcars[, -1])); y <- mtcars$mpg
cvfit <- cv.glmnet(X, y, alpha = 1)     # alpha = 0이면 능형
coef(cvfit, s = "lambda.1se")           # 0이 된 계수 확인
요약
  1. 능형: 제곱 벌점, \((X^\top X + \lambda I)^{-1}X^\top\mathbf y\), 계수를 줄임.
  2. 라쏘: 절댓값 벌점, 일부 계수를 0으로(선택).
  3. \(\lambda\)는 교차검증으로. 설명변수는 표준화합니다.

6.3.4연습문제

응용

  1. 설명변수가 하나이고 표준화되어 \(\sum x_i^2 = n\)일 때 능형 추정량을 최소제곱 추정량으로 나타내세요.
    답

    \(\hat\beta_{\text{ridge}} = \frac{\sum x_iy_i}{n + \lambda} = \frac{n}{n + \lambda}\hat\beta_{LS}\). 최소제곱을 일정 비율로 줄입니다.
