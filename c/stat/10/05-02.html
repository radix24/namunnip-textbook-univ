  • 가우스-마르코프 정리 (2.2절).

정확한 자료에 더 큰 목소리를

여러 지역의 평균 소득을 자료로 쓰는데, 어떤 지역은 1000명, 어떤 지역은 10명을 조사해 구한 평균이라면 앞의 값이 훨씬 정확합니다. 모든 점을 똑같이 대하는 보통 최소제곱보다, 정확한 점에 더 큰 가중치를 주는 편이 낫습니다.

5.2.1추정량

\(\mathrm{Var}(\varepsilon_i) = \sigma^2/w_i\)(가중치 \(w_i\)는 알려짐)라 합시다. \(\sqrt{w_i}\)를 양변에 곱하면 \(\sqrt{w_i}Y_i = \sqrt{w_i}\mathbf x_i^\top\boldsymbol\beta + \sqrt{w_i}\varepsilon_i\)이고 새 오차의 분산은 \(\sigma^2\)로 같아집니다. 이 변환된 자료에 보통 최소제곱을 하면

결과 5.2.1

\(\hat{\boldsymbol\beta}_W = (X^\top WX)^{-1}X^\top W\mathbf y\), \(W = \mathrm{diag}(w_1, \ldots, w_n)\). 이것은 \(\sum w_i(y_i - \mathbf x_i^\top\mathbf b)^2\)을 최소화하며, 가우스-마르코프 정리에 따라 BLUE이다.

보통 최소제곱도 여전히 불편이지만 분산이 더 크고, 무엇보다 보통의 표준오차 공식(\(\sigma^2(X^\top X)^{-1}\))이 틀려 신뢰구간과 검정이 잘못됩니다.

5.2.2가중치 정하기

  • 평균을 자료로 쓰면 \(w_i = n_i\)(표본 크기).
  • 잔차 그림에서 표준편차가 \(x\)에 비례하면 \(w_i = 1/x_i^2\).
  • 모르면 먼저 보통 최소제곱을 하고, \(|e_i|\)를 \(x\)(또는 \(\hat y\))로 회귀해 표준편차 함수를 추정한 뒤 \(w_i = 1/\hat\sigma_i^2\)로 다시 적합합니다.
  • 가중치를 정하기 어려우면 보통 최소제곱 계수에 이분산에 강건한 표준오차(화이트 표준오차)를 쓰는 방법도 있습니다(R: sandwich 패키지).
예제 5.2.1

지역 평균 자료 \((x_i, \bar y_i, n_i)\)에 가중 회귀를 적합하는 R 코드를 쓰세요.

풀이. lm(ybar ~ x, weights = n). \(\mathrm{Var}(\bar y_i) = \sigma^2/n_i\)이므로 가중치는 \(n_i\)입니다.

요약
  1. \(\mathrm{Var}(\varepsilon_i) = \sigma^2/w_i\)이면 \((X^\top WX)^{-1}X^\top W\mathbf y\)가 BLUE.
  2. 가중치는 분산의 역수: 표본 크기, 추정한 분산 함수.
  3. 대안: 보통 최소제곱 + 강건 표준오차.

5.2.3연습문제

응용

  1. 원점을 지나는 모형 \(Y_i = \beta x_i + \varepsilon_i\), \(\mathrm{Var}(\varepsilon_i) = \sigma^2x_i\)의 가중 최소제곱 추정량은?
    답

    \(w_i = 1/x_i\). \(\sum (y_i - bx_i)^2/x_i\)를 최소화: \(\hat\beta = \sum y_i/\sum x_i\) (비 추정량, 응통8 04단원).
