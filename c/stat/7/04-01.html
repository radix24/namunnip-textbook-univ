신뢰구간을 만드는 일반적인 방법

응통5의 \(\bar x \pm t\,s/\sqrt n\)은 어디서 왔을까요? 모수와 자료가 섞여 있지만 분포는 모수와 무관한 양을 찾고, 그 양에 대한 확률 부등식을 모수에 대해 푸는 것입니다.

4.1.1추축량

정의 4.1.1

추축량 \(Q(\mathbf X, \theta)\): 자료와 모수의 함수로, 분포가 \(\theta\)에 의존하지 않는 것.

분포가 정해져 있으므로 \(P(a \le Q \le b) = 1 - \alpha\)인 \(a, b\)를 표에서 찾을 수 있고, 부등식 \(a \le Q(\mathbf X, \theta) \le b\)를 \(\theta\)에 대해 풀면 신뢰구간이 됩니다.

모형추축량분포
\(N(\mu, \sigma^2)\), \(\mu\)\(\frac{\bar X - \mu}{S/\sqrt n}\)\(t_{n-1}\)
\(N(\mu, \sigma^2)\), \(\sigma^2\)\(\frac{(n-1)S^2}{\sigma^2}\)\(\chi^2_{n-1}\)
지수 \(\lambda\)\(2\lambda\sum X_i\)\(\chi^2_{2n}\)
\(U(0,\theta)\)\(X_{(n)}/\theta\)밀도 \(nt^{n-1}\) (0, 1)
예제 4.1.2

지수분포 표본 \(n = 10\), \(\sum x_i = 25\)일 때 \(\lambda\)의 95% 신뢰구간을 구하세요.

풀이. \(\lambda X_i\)는 지수(1) = 감마(1, 1)이고 \(2\lambda X_i \sim\) 감마(1, 2) \(= \chi^2_2\). 합 \(2\lambda\sum X_i \sim \chi^2_{20}\). 분위수 \(\chi^2_{20}\)의 2.5%점 9.591, 97.5%점 34.170. \(9.591 \le 50\lambda \le 34.170\)에서 \([0.192, 0.683]\). 3.2절 근사 구간(\(0.4 \pm 0.248\), [0.152, 0.648])과 달리 비대칭이고 정확합니다.

예제 4.1.3

\(U(0,\theta)\)에서 \(X_{(n)}\)으로 95% 신뢰구간을 만드세요.

풀이. \(P(Q \le q) = q^n\). \(P(0.05^{1/n} \le Q \le 1) = 0.95\)이므로 \(X_{(n)} \le \theta \le X_{(n)}/0.05^{1/n}\). 관측된 최댓값보다 작을 수 없다는 사실을 반영해 아래쪽 끝이 \(X_{(n)}\)입니다.

요약
  1. 추축량: 분포가 모수와 무관한 자료·모수의 함수.
  2. \(P(a \le Q \le b) = 1-\alpha\)를 모수에 대해 풀면 신뢰구간.
  3. 구간은 비대칭일 수 있고, 같은 신뢰수준에서 짧은 것을 고릅니다.

4.1.2연습문제

기본

  1. 정규 표본 \(n = 10\), \(s^2 = 4\)이면 \(\sigma^2\)의 95% 신뢰구간은? (\(\chi^2_9\)의 2.5%점 2.700, 97.5%점 19.023)
    답

    \([36/19.023, 36/2.700] = [1.89, 13.33]\).
