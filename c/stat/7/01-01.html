자료에서 모수로

지금까지는 모수(\(\mu, \lambda, p\))를 안다고 두고 자료의 분포를 구했습니다. 추정은 방향이 반대입니다. 자료를 보고 모수를 짐작하는 규칙, 곧 추정량을 만듭니다. 대표적인 두 방법을 봅니다.

1.1.1적률법

모집단 적률 \(E(X^k)\)는 모수의 함수입니다. 이것을 표본 적률 \(\frac1n\sum X_i^k\)과 같다고 놓고 모수에 대해 풉니다. 모수가 \(m\)개이면 \(k = 1, \ldots, m\)까지 \(m\)개의 식을 씁니다.

예제 1.1.1

감마 \((\alpha, \beta)\) 표본으로 두 모수의 적률추정량을 구하세요.

풀이. \(E(X) = \alpha\beta\), \(\mathrm{Var}(X) = \alpha\beta^2\). 표본평균 \(\bar X\)와 \(\hat\sigma^2 = \frac1n\sum(X_i - \bar X)^2\)를 대입하면 \(\hat\beta = \hat\sigma^2/\bar X\), \(\hat\alpha = \bar X^2/\hat\sigma^2\).

1.1.2최대가능도법

정의 1.1.2

독립 표본 \(x_1, \ldots, x_n\)의 가능도함수: \(L(\theta) = \prod_{i=1}^n f(x_i; \theta)\). 자료를 고정하고 모수의 함수로 본 결합 밀도입니다. \(L(\theta)\)를 가장 크게 하는 \(\hat\theta\)를 최대가능도추정량(MLE)이라 합니다.

"이 자료가 나올 가능성을 가장 크게 만드는 모수"를 고르는 것입니다. 곱보다 합이 미분하기 쉬우므로 로그가능도 \(\ell(\theta) = \sum\log f(x_i;\theta)\)를 최대화합니다(로그는 증가함수라 최대점이 같음).

예제 1.1.3

지수분포 \(f(x;\lambda) = \lambda e^{-\lambda x}\)의 MLE를 구하세요.

풀이. \(\ell(\lambda) = n\log\lambda - \lambda\sum x_i\). \(\ell'(\lambda) = n/\lambda - \sum x_i = 0\)에서 \(\hat\lambda = 1/\bar x\). \(\ell''(\lambda) = -n/\lambda^2 < 0\)이므로 최대입니다.

예제 1.1.4

\(N(\mu, \sigma^2)\)의 두 모수 MLE를 구하세요.

풀이. \(\ell = -\frac n2\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(x_i - \mu)^2\). \(\partial\ell/\partial\mu = 0\)에서 \(\hat\mu = \bar x\). \(\partial\ell/\partial\sigma^2 = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum(x_i - \mu)^2 = 0\)에서 \(\hat\sigma^2 = \frac1n\sum(x_i - \bar x)^2\). \(n-1\)이 아니라 \(n\)으로 나눈다는 점에 주의합니다(1.2절에서 치우침을 봅니다).

예제 1.1.5 (미분이 안 되는 경우)

\(U(0, \theta)\)의 MLE는?

풀이. \(L(\theta) = \theta^{-n}\) (모든 \(x_i \le \theta\)일 때), 아니면 0. \(\theta \ge x_{(n)}\)에서 감소함수이므로 \(\hat\theta = x_{(n)}\)(최댓값). 미분해서 0으로 두는 방법은 쓸 수 없습니다. 가능도의 그래프를 그려 보는 습관이 필요합니다.

1.1.3불변성

정리 1.1.6

\(\hat\theta\)가 \(\theta\)의 MLE이면 함수 \(g(\theta)\)의 MLE는 \(g(\hat\theta)\)이다.

예: 정규분포 표준편차의 MLE는 \(\sqrt{\hat\sigma^2}\), 지수분포 평균 \(1/\lambda\)의 MLE는 \(\bar x\). 적률법이나 불편추정량(1.2절)에는 이런 성질이 일반적으로 없습니다.

요약
  1. 적률법: 표본 적률 = 모집단 적률.
  2. MLE: 로그가능도를 최대화. 경계에서 최대가 되는 경우를 확인합니다.
  3. MLE는 함수 변환에 불변입니다.

1.1.4연습문제

기본

  1. 포아송 \(\lambda\)의 MLE와 \(P(X = 0) = e^{-\lambda}\)의 MLE는?
    답

    \(\hat\lambda = \bar x\), 불변성으로 \(e^{-\bar x}\).

  2. 베르누이 \(n\)번 중 \(k\)번 성공일 때 \(p\)의 MLE는?
    답

    \(\ell = k\log p + (n-k)\log(1-p)\), \(\hat p = k/n\).

응용

  1. \(U(0, \theta)\)의 적률추정량을 구하고 MLE와 비교하세요. 표본이 1, 2, 9이면?
    답

    \(E(X) = \theta/2\)이므로 \(\tilde\theta = 2\bar x = 8\). MLE는 9. 적률추정량 8은 이미 관측된 9보다 작아 말이 안 됩니다.
