4.R.1

연습구간추정 단원 마무리 연습

문제 6 · 계산·판단 · 힌트 2단계

다루는 성취기준 [응통7-04-01] [응통7-04-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(N(\mu, 64)\)에서 \(n = 16\), \(\bar x = 50\)을 얻었습니다. 추축량을 밝히고 \(\mu\)의 95% 신뢰구간을 구하세요. [04-01]

    힌트 1

    추축량은 모수와 자료의 함수이면서 분포가 모수에 의존하지 않는 양입니다.

    힌트 2

    \(Z = (\bar X - \mu)/(\sigma/\sqrt n) \sim N(0, 1)\)입니다.

    풀이

    추축량 \(Z = \frac{\bar X - \mu}{8/4} \sim N(0, 1)\)에서 \(P(-1.96 \le Z \le 1.96) = 0.95\)를 \(\mu\)에 대해 풀면 \(\bar X \pm 1.96\times2\)입니다. 신뢰구간은 \(50 \pm 3.92 = [46.08, 53.92]\)입니다.

  2. 계산정규 표본 \(n = 10\)에서 \(s^2 = 4\)를 얻었습니다. \(\sigma^2\)의 95% 신뢰구간을 구하세요(\(\chi^2_{0.025}(9) = 19.02\), \(\chi^2_{0.975}(9) = 2.70\), 아래 첨자는 위쪽 꼬리 확률). [04-01]

    힌트 1

    추축량 \((n-1)S^2/\sigma^2 \sim \chi^2_{n-1}\)을 씁니다.

    힌트 2

    부등식을 \(\sigma^2\)에 대해 풀면 큰 분위수가 아래 끝으로 갑니다.

    풀이

    \(2.70 \le 9s^2/\sigma^2 \le 19.02\)를 풀면 \(\frac{36}{19.02} \le \sigma^2 \le \frac{36}{2.70}\), 곧 \([1.89, 13.33]\)입니다.

    구간이 \(s^2 = 4\)를 중심으로 대칭이 아니고 매우 넓습니다. 표본 10개로는 분산을 정밀하게 추정하기 어렵고, 이 구간은 정규성 가정에 크게 의존합니다.

  3. 계산지수분포 \(\mathrm{Exp}(\lambda)\)에서 \(2\lambda\sum X_i \sim \chi^2_{2n}\)임을 써서, \(n = 10\), \(\sum x_i = 25\)일 때 \(\lambda\)의 정확한 95% 신뢰구간을 구하세요(\(\chi^2_{20}\)의 2.5%, 97.5% 분위수는 9.59, 34.17). [04-01]

    힌트 1

    \(9.59 \le 2\lambda\cdot25 \le 34.17\)을 \(\lambda\)에 대해 풉니다.

    힌트 2

    \(\lambda\)의 점추정값은 \(10/25 = 0.4\)입니다.

    풀이

    \(\lambda \in [9.59/50, 34.17/50] = [0.192, 0.683]\)입니다. 점추정값 0.4를 중심으로 오른쪽이 더 긴 비대칭 구간입니다. \(n = 10\)에서 왈드 구간 \(0.4 \pm 1.96\times0.4/\sqrt{10} = [0.152, 0.648]\)과 비교하면 위치가 상당히 다릅니다.

  4. 계산\(U(0, \theta)\)에서 \(X_{(n)}/\theta\)의 분포함수가 \(t^n\) (\(0 \le t \le 1\))임을 써서, \(\theta\)의 95% 신뢰구간 \([X_{(n)}, X_{(n)}/0.05^{1/n}]\)을 유도하고 \(n = 5\), \(X_{(n)} = 4.1\)로 값을 구하세요. [04-01]

    힌트 1

    \(X_{(n)}/\theta\)는 분포가 \(\theta\)와 무관한 추축량입니다.

    힌트 2

    \(P(0.05^{1/n} \le X_{(n)}/\theta \le 1) = 1 - 0.05\)입니다.

    풀이

    \(P(X_{(n)}/\theta \ge c) = 1 - c^n = 0.95\)에서 \(c = 0.05^{1/n}\)입니다. \(c \le X_{(n)}/\theta \le 1\)을 풀면 \(X_{(n)} \le \theta \le X_{(n)}/c\)입니다.

    \(n = 5\)이면 \(c = 0.05^{0.2} \approx 0.549\)이므로 구간은 \([4.1, 7.46]\)입니다. \(\theta\)는 관측 최댓값보다 작을 수 없으므로 아래 끝을 \(X_{(n)}\)에 두는 것이 자연스럽습니다.

  5. 계산50명 중 10명이 찬성했습니다. 비율의 95% 왈드 구간을 구하고, 윌슨 구간 \([0.112, 0.330]\)과 비교하세요. [04-02]

    힌트 1

    왈드 구간은 \(\hat p \pm 1.96\sqrt{\hat p(1-\hat p)/n}\)입니다.

    힌트 2

    윌슨 구간은 점수 검정을 뒤집어 얻으며 R의 prop.test(10, 50, correct = FALSE)가 줍니다.

    풀이

    왈드 구간은 \(0.2 \pm 1.96\times0.0566 = [0.089, 0.311]\)입니다. 윌슨 구간 \([0.112, 0.330]\)은 0.5 쪽으로 조금 옮겨지고 비대칭입니다.

    왈드 구간은 \(\hat p\)로 표준오차를 추정해 대칭으로 만들기 때문에, \(\hat p\)가 0이나 1에 가까우면 실제 포함 확률이 95%보다 낮아집니다. 비율의 구간에는 윌슨 구간이나 정확(클로퍼-피어슨) 구간이 권장됩니다.

  6. 판단부작용 조사에서 20명 중 0명이 부작용을 보였습니다. 왈드 구간을 계산하면 어떻게 되는지 쓰고, 이 결과가 왜 말이 안 되는지와 대안을 쓰세요. [04-02]

    힌트 1

    \(\hat p = 0\)이면 표준오차 추정값은 얼마인가요?

    힌트 2

    "3의 규칙": 0건이면 95% 위쪽 한계가 대략 \(3/n\)입니다.

    풀이

    \(\hat p = 0\)이라 표준오차 추정값이 0이 되어 구간이 \([0, 0]\)입니다. 20명에서 0건이 나왔다고 부작용 확률이 정확히 0이라고 확신할 수는 없으므로 말이 안 됩니다.

    대안: 정확 구간(binom.test(0, 20), 위쪽 끝 약 0.168), 윌슨 구간, 또는 간단한 3의 규칙(위쪽 한계 \(\approx 3/20 = 0.15\))을 씁니다. "부작용이 관찰되지 않았지만 15% 정도까지는 배제할 수 없다"고 보고합니다.
