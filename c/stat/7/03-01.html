분산을 얼마나 줄일 수 있나

UMVUE는 불편추정량 중 최선이지만, 그 분산이 절대적으로 얼마나 작은지는 말하지 않습니다. 자료에 담긴 정보량이 정해지면 어떤 불편추정량도 넘을 수 없는 분산의 하한이 있습니다.

3.1.1점수와 정보량

정의 3.1.1

점수함수: \(U(\theta) = \frac{\partial}{\partial\theta}\log f(X;\theta)\). 피셔 정보량: \(I(\theta) = E[U(\theta)^2]\).

미분과 적분의 순서를 바꿀 수 있는 정칙 조건 아래에서 \(E[U(\theta)] = \int\frac{\partial f/\partial\theta}{f}f\,dx = \frac{\partial}{\partial\theta}\int f = 0\)이고, 한 번 더 미분하면

\[I(\theta) = \mathrm{Var}(U) = -E\left[\frac{\partial^2}{\partial\theta^2}\log f(X;\theta)\right].\]

로그가능도의 곡률이 클수록(뾰족할수록) 정보가 많습니다. 독립 표본 \(n\)개의 정보량은 \(nI(\theta)\)입니다.

3.1.2크라메르-라오 하한

정리 3.1.2

정칙 조건 아래에서 \(\tau(\theta)\)의 불편추정량 \(W\)는 \(\mathrm{Var}(W) \ge \dfrac{[\tau'(\theta)]^2}{nI(\theta)}\)를 만족한다.

표본 점수 \(U_n = \sum U_i\)는 평균 0, 분산 \(nI\). \(\mathrm{Cov}(W, U_n) = E(WU_n) = \int W\frac{\partial f_n}{\partial\theta}d\mathbf x = \frac{\partial}{\partial\theta}E(W) = \tau'(\theta)\). 상관계수가 1 이하이므로 \([\tau'(\theta)]^2 = \mathrm{Cov}^2 \le \mathrm{Var}(W)\cdot nI(\theta)\). ∎

하한과 분산이 같은 불편추정량을 효율적이라 합니다. 증명에서 등호는 \(W\)가 \(U_n\)의 일차식일 때만 성립하며, 이는 지수족에서 \(T\)의 평균을 추정할 때입니다.

예제 3.1.3

포아송 \(\lambda\)의 정보량과 하한을 구하고 \(\bar X\)가 효율적인지 보세요.

풀이. \(\log f = -\lambda + x\log\lambda - \log x!\), \(\partial^2/\partial\lambda^2 = -x/\lambda^2\), \(I = E(X)/\lambda^2 = 1/\lambda\). 하한 \(\lambda/n\). \(\mathrm{Var}(\bar X) = \lambda/n\)이므로 효율적입니다.

주의 \(U(0,\theta)\)처럼 값을 가지는 영역이 \(\theta\)에 의존하면 정칙 조건이 깨져 하한이 성립하지 않습니다. 실제로 UMVUE \(\frac{n+1}{n}X_{(n)}\)의 분산은 \(1/n^2\) 속도로 줄어 "하한"보다 작습니다.
요약
  1. \(I(\theta) = E[U^2] = -E[\partial^2\log f/\partial\theta^2]\), 표본은 \(nI\).
  2. 불편추정량의 분산 ≥ \([\tau']^2/(nI)\).
  3. 정칙 조건(영역이 모수에 무관 등)이 필요합니다.

3.1.3연습문제

기본

  1. 베르누이 \(p\)의 피셔 정보량은?
    답

    \(\partial^2\log f = -x/p^2 - (1-x)/(1-p)^2\), \(I = 1/p + 1/(1-p) = \frac{1}{p(1-p)}\).

응용

  1. \(N(\mu, \sigma^2)\)에서 \(\sigma^2\)(알려진 \(\mu\))의 하한과, \(\mu\)를 모를 때 \(S^2\)의 분산을 비교하세요.
    답

    \(I(\sigma^2) = 1/(2\sigma^4)\), 하한 \(2\sigma^4/n\). \(\mathrm{Var}(S^2) = 2\sigma^4/(n-1)\)로 하한보다 조금 큽니다. \(S^2\)은 UMVUE이지만 효율적이지는 않습니다.
