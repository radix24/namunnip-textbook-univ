불편추정량 가운데 가장 좋은 것

불편추정량끼리는 분산이 작을수록 좋습니다. 모든 \(\theta\)에서 분산이 가장 작은 불편추정량을 최소분산불편추정량(UMVUE)이라 합니다. 찾는 방법은 놀랍도록 기계적입니다. 아무 불편추정량이나 하나 잡아 충분통계량으로 조건부 기대값을 취하면 됩니다.

2.2.1라오-블랙웰 정리

정리 2.2.1 (라오-블랙웰)

\(W\)가 \(\theta\)의 불편추정량이고 \(T\)가 충분통계량이면 \(\phi(T) = E(W \mid T)\)는 (가) \(\theta\)를 포함하지 않는 통계량이고 (나) 불편이며 (다) \(\mathrm{Var}(\phi(T)) \le \mathrm{Var}(W)\).

(가) \(T\)가 충분하므로 \(T\)가 주어진 표본의 조건부분포, 따라서 \(W\)의 조건부 기대값에 \(\theta\)가 없습니다. 이 단계에서 충분성이 쓰입니다. (나) 반복 기대값: \(E[E(W\mid T)] = E(W) = \theta\). (다) 분산 분해: \(\mathrm{Var}(W) = E[\mathrm{Var}(W\mid T)] + \mathrm{Var}[E(W\mid T)] \ge \mathrm{Var}(\phi(T))\). ∎

예제 2.2.2

포아송 표본에서 \(P(X = 0) = e^{-\lambda}\)를 추정합니다. \(W = 1\{X_1 = 0\}\)에서 시작해 개선하세요.

풀이. \(E(W) = e^{-\lambda}\)로 불편. \(T = \sum X_i\)가 충분. \(T = t\)일 때 \(X_1\)의 조건부분포는 이항 \((t, 1/n)\)입니다(독립 포아송의 합에 대한 조건부분포). 따라서 \(E(W\mid T = t) = P(X_1 = 0\mid T = t) = (1 - 1/n)^t\). 개선된 추정량 \((1 - 1/n)^T\). \(n\)이 크면 \(e^{-T/n} = e^{-\bar X}\)(MLE)에 가깝습니다.

2.2.2완비성과 레만-셰페 정리

정의 2.2.3

통계량 \(T\)가 완비: 모든 \(\theta\)에서 \(E_\theta[g(T)] = 0\)이면 \(P_\theta(g(T) = 0) = 1\)인 경우.

뜻: \(T\)의 함수로 만든 불편추정량은 하나뿐입니다. 두 개 \(g_1(T), g_2(T)\)가 있으면 차의 기대값이 항상 0이므로 둘이 같아야 하기 때문입니다.

정리 2.2.4 (레만-셰페)

\(T\)가 완비 충분통계량이고 \(\phi(T)\)가 \(\theta\)의 불편추정량이면 \(\phi(T)\)는 유일한 UMVUE이다.

증명: 아무 불편추정량 \(W\)를 라오-블랙웰로 개선하면 \(T\)의 함수인 불편추정량이 되고, 완비성으로 그것은 \(\phi(T)\)와 같습니다. 따라서 \(\mathrm{Var}(\phi(T)) \le \mathrm{Var}(W)\).

예제 2.2.5

\(U(0,\theta)\)의 UMVUE는?

풀이. \(T = X_{(n)}\)은 충분이고 완비입니다(밀도 \(nt^{n-1}/\theta^n\)에서 \(\int_0^\theta g(t)t^{n-1}dt = 0\)이 모든 \(\theta\)에서 성립하면 미분해서 \(g(\theta)\theta^{n-1} = 0\)). \(E X_{(n)} = \frac{n}{n+1}\theta\)이므로 UMVUE는 \(\frac{n+1}{n}X_{(n)}\).

요약
  1. 라오-블랙웰: \(E(W\mid T)\)는 불편이고 분산이 줄어듭니다.
  2. 완비 충분통계량의 함수인 불편추정량이 UMVUE입니다.
  3. 찾는 법: \(T\)의 함수 중 불편인 것을 직접 맞추거나, 쉬운 불편추정량을 조건부 기대값으로 바꿉니다.

2.2.3연습문제

기본

  1. 베르누이 표본에서 \(p\)의 UMVUE는? (\(\sum X_i\)는 완비 충분)
    답

    \(\bar X\). \(T\)의 함수이고 불편입니다.

심화

  1. 베르누이 표본(\(n \ge 2\))에서 \(p^2\)의 UMVUE를 구하세요.
    답

    \(W = X_1X_2\)는 불편. \(E(W\mid T = t) = \frac{t(t-1)}{n(n-1)}\). UMVUE \(\frac{T(T-1)}{n(n-1)}\).
