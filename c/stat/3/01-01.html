R은 벡터의 언어

R에서는 숫자 하나도 길이 1인 벡터입니다. 대부분의 계산이 벡터 전체에 한꺼번에 적용되므로, 자료 구조를 이해하면 반복문 없이 짧은 코드로 분석할 수 있습니다.

1.1.1벡터

x <- c(3, 1, 4, 1, 5)        # 숫자 벡터
names <- c("가", "나", "다")   # 문자 벡터
ok <- x > 2                    # 논리 벡터 FALSE TRUE ...
x[2]; x[c(1, 3)]; x[-1]; x[x > 2]   # 위치, 여러 개, 제외, 조건
length(x); sum(x); mean(x)

벡터의 원소는 모두 같은 자료형이어야 합니다. 섞으면 가장 일반적인 형으로 바뀝니다(c(1, "a")는 문자 벡터). 인덱스는 1부터 시작합니다.

1.1.2행렬, 리스트, 데이터프레임

구조만들기특징
행렬matrix(1:6, nrow = 2)같은 자료형, 2차원. m[1, 2], m[, 2]
리스트list(a = 1, b = "x", c = 1:3)서로 다른 형과 길이. l$a, l[["c"]]
데이터프레임data.frame(id = 1:3, g = c("A","B","A"))열마다 다른 형, 같은 길이. 통계 자료의 기본
범주(factor)factor(c("저","고","중"), levels = c("저","중","고"))범주형 변수. 수준의 순서를 지정

데이터프레임은 "같은 길이의 벡터들의 리스트"입니다. d$g로 열을, d[d$g == "A", ]로 조건에 맞는 행을 꺼냅니다. str(d)는 구조를, summary(d)는 열별 요약을 보여 줍니다.

예제 1.1.1

내장 자료 mtcars에서 연비 25 이상인 차의 이름과 마력을 꺼내세요.

mtcars[mtcars$mpg >= 25, "hp", drop = FALSE]
rownames(mtcars)[mtcars$mpg >= 25]

Fiat 128, Honda Civic, Toyota Corolla, Fiat X1-9, Porsche 914-2, Lotus Europa 6대가 나옵니다.

요약
  1. 벡터(같은 형), 행렬(2차원 같은 형), 리스트(무엇이든), 데이터프레임(열마다 다른 형).
  2. 인덱스는 1부터, 조건 인덱싱 x[x > 2].
  3. 범주형 변수는 factor로.
