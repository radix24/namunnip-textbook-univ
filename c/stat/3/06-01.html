  • R 기초 (1.1절).

복사해 붙이지 않는 보고서

분석 결과를 워드에 손으로 옮기면 자료가 바뀔 때마다 다시 옮겨야 하고 실수가 생깁니다. 글과 코드를 한 파일에 쓰고, 문서를 만들 때 코드가 실행되어 결과가 들어가게 하면 이 문제가 사라집니다.

6.1.1구조

---
title: "연비 분석"
author: "홍길동"
format: html          # Quarto. R Markdown이면 output: html_document
---

## 자료
`mtcars`의 자동차 `r nrow(mtcars)`대를 분석했다.

```{r}
#| echo: true
fit <- lm(mpg ~ wt, data = mtcars)
summary(fit)$coefficients
```

무게가 1000 lb 늘면 연비가 평균 `r round(-coef(fit)[2], 1)` mpg 낮았다.
  • 머리말(YAML): 제목, 형식.
  • 글: 마크다운(## 제목, *기울임*, 목록).
  • 코드 덩어리: 실행되고 결과가 문서에 들어감. 옵션 echo(코드 보이기), eval(실행 여부), fig-cap(그림 설명).
  • 인라인 코드: 문장 속 숫자를 코드로.

RStudio의 Render(Knit) 버튼이나 quarto render 파일.qmd로 만듭니다. PDF에는 LaTeX(TinyTeX)가 필요합니다.

요약
  1. 머리말 + 마크다운 글 + 코드 덩어리.
  2. 인라인 코드로 숫자를 자동으로.
  3. 한 원본으로 HTML, PDF, Word.
