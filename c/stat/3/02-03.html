다섯 가지 동사

자료 정리의 대부분은 다섯 동작의 조합입니다. 고르기(행), 고르기(열), 정렬, 변수 만들기, 요약. dplyr 패키지는 이것을 동사 이름의 함수로 제공하고, 파이프 |>로 이어 씁니다.

2.3.1기본 R과 dplyr

동작기본 Rdplyr
행 고르기d[d$cyl == 4, ]filter(d, cyl == 4)
열 고르기d[, c("mpg", "wt")]select(d, mpg, wt)
정렬d[order(-d$mpg), ]arrange(d, desc(mpg))
변수 만들기d$kpl <- d$mpg * 0.425mutate(d, kpl = mpg * 0.425)
그룹 요약aggregate(mpg ~ cyl, d, mean)d |> group_by(cyl) |> summarise(m = mean(mpg), n = n())

|>(R 4.1 이상)는 왼쪽 결과를 오른쪽 함수의 첫 인수로 넘깁니다. "자료를 → 거르고 → 묶고 → 요약한다"처럼 읽힙니다.

2.3.2결합

sales <- data.frame(store = c(1, 2, 3, 4), amount = c(120, 80, 150, 60))
info  <- data.frame(store = c(1, 2, 3, 5), region = c("서울", "부산", "서울", "대구"))
merge(sales, info, by = "store")                 # 공통 열쇠만: 1, 2, 3
merge(sales, info, by = "store", all.x = TRUE)   # sales 기준: 4번은 region NA
# dplyr: inner_join(sales, info, by = "store"), left_join(...)

결합 뒤에는 행 수가 예상과 같은지 꼭 확인합니다. 열쇠가 중복되면 행이 불어납니다.

예제 2.3.1

mtcars에서 기통 수별 대수, 평균 연비, 평균 마력을 연비 순으로 구하세요.

library(dplyr)
mtcars |> group_by(cyl) |>
  summarise(n = n(), mpg = mean(mpg), hp = mean(hp)) |>
  arrange(desc(mpg))
# 4기통 11대 26.7 82.6 / 6기통 7대 19.7 122 / 8기통 14대 15.1 209
요약
  1. filter, select, arrange, mutate, group_by + summarise.
  2. 파이프로 단계를 이어 읽기 쉽게.
  3. 결합(merge, join) 뒤 행 수 확인.
