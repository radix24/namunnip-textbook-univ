연습자료 전처리 단원 마무리 연습

문제 6 · 실습 · 힌트 2단계

다루는 성취기준 [응통3-02-01] [응통3-02-02] [응통3-02-03] [응통3-02-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습유럽에서 받은 CSV 파일이 이름;점수, A;85,5처럼 세미콜론으로 구분되고 소수점이 쉼표입니다. read.csv()로 읽으면 어떤 일이 생기는지 쓰고, 바르게 읽는 코드와 결과를 쉼표 구분 파일로 저장하는 코드를 쓰세요. [02-01]

    힌트 1

    read.csv의 기본값은 sep = ",", dec = "."입니다.

    힌트 2

    read.csv2는 세미콜론 구분과 쉼표 소수점을 기본값으로 씁니다.

    풀이

    read.csv()는 쉼표를 구분자로 보므로 A;85와 5로 잘못 나누거나 한 열로 읽어, 점수가 숫자가 아닌 문자열이 됩니다.

    d <- read.csv2("data.csv", fileEncoding = "UTF-8")
# 또는 read.csv("data.csv", sep = ";", dec = ",")
str(d)                                   # 점수가 num인지 확인
write.csv(d, "data_clean.csv", row.names = FALSE)

    row.names = FALSE를 빼면 행 번호가 첫 열로 저장되어, 다시 읽을 때 쓸모없는 X 열이 생깁니다.

  2. 실습x <- c("10", "20", "삼십", "40")을 숫자로 바꾸고 평균을 구하세요. 어떤 경고가 나오고, 왜 그런지 쓰세요. [02-02]

    힌트 1

    as.numeric()은 숫자로 읽을 수 없는 문자열을 무엇으로 바꾸나요?

    힌트 2

    결측을 뺀 평균은 na.rm = TRUE로 구합니다.

    풀이

    as.numeric(x)는 10 20 NA 40을 돌려주며 "강제 변환으로 NA가 생성되었습니다(NAs introduced by coercion)"라는 경고를 냅니다. "삼십"은 숫자로 읽을 수 없기 때문입니다.

    mean(as.numeric(x), na.rm = TRUE)는 \((10+20+40)/3 \approx 23.33\)입니다. 다만 경고를 무시하지 말고 어떤 값이 NA가 되었는지(x[is.na(as.numeric(x))]) 확인해, 가능하면 원래 값(30)으로 고쳐야 합니다.

  3. 실습다음 두 출력을 예측하고, 각각 의도대로 고치는 방법을 쓰세요. [02-02]

    levels(factor(c("low", "high", "mid", "low")))
as.numeric(factor(c("10", "5", "20")))
    힌트 1

    범주의 수준은 기본적으로 문자열의 사전순으로 정해집니다.

    힌트 2

    as.numeric을 범주형에 쓰면 값이 아니라 내부 코드(수준 번호)가 나옵니다.

    풀이

    첫 번째는 "high" "low" "mid"(사전순)입니다. 순서를 지정하려면 factor(x, levels = c("low", "mid", "high"))로 씁니다(순서형이면 ordered = TRUE도).

    두 번째는 1 3 2입니다. 수준이 문자열 사전순으로 "10", "20", "5"가 되어 "10"→1, "5"→3, "20"→2가 되기 때문입니다. 원래 숫자를 얻으려면 as.numeric(as.character(f))를 씁니다.

  4. 실습mtcars에서 실린더 수(cyl)별로 차량 수와 평균 연비(mpg)를 구하세요. dplyr 방식과 기본 R 방식을 모두 쓰고, 결과를 해석하세요. [02-03]

    힌트 1

    dplyr에서는 group_by() 다음 summarise()를 씁니다.

    힌트 2

    기본 R에서는 aggregate(mpg ~ cyl, data = mtcars, FUN = mean)이나 tapply를 씁니다.

    풀이 
    library(dplyr)
mtcars |> group_by(cyl) |> summarise(n = n(), mpg = mean(mpg))
aggregate(mpg ~ cyl, data = mtcars, FUN = mean)
table(mtcars$cyl)

    결과: 4기통 11대(평균 26.7), 6기통 7대(19.7), 8기통 14대(15.1)입니다. 실린더가 많을수록 연비가 낮지만, 무게 같은 다른 요인도 함께 달라지므로 실린더만의 효과라고 단정할 수는 없습니다.

  5. 실습학생 표 st(id 1, 2, 3)와 점수 표 sc(id 2, 3, 4)를 id로 결합합니다. 내부 결합, 왼쪽 결합, 완전 결합의 행 수를 각각 쓰고, 왼쪽 결합에서 어떤 값이 NA가 되는지 설명하세요. [02-03]

    힌트 1

    내부 결합은 양쪽에 모두 있는 id만 남깁니다.

    힌트 2

    왼쪽 결합은 왼쪽 표의 행을 모두 남기고, 짝이 없으면 오른쪽 열을 NA로 채웁니다.

    풀이

    내부 결합(inner_join(st, sc, by = "id"), merge(st, sc))은 id 2, 3으로 2행, 왼쪽 결합(left_join, merge(..., all.x = TRUE))은 id 1, 2, 3으로 3행, 완전 결합(full_join, merge(..., all = TRUE))은 id 1~4로 4행입니다.

    왼쪽 결합에서 id 1은 점수 표에 없으므로 점수 열이 NA입니다. 결합 후에는 행 수가 예상과 같은지 꼭 확인하세요. 키가 중복되면 행이 불어날 수 있습니다.

  6. 실습넓은 형식 자료 w가 열 id, y2023, y2024로 되어 있고 학생이 3명입니다. 긴 형식(id, year, score)으로 바꾸는 코드를 쓰고, 결과의 행 수를 쓰세요. 긴 형식이 필요한 경우를 하나 드세요. [02-04]

    힌트 1

    tidyr의 pivot_longer(cols, names_to, values_to)를 씁니다.

    힌트 2

    학생마다 두 해의 값이 한 행씩 됩니다.

    풀이 
    library(tidyr)
long <- pivot_longer(w, cols = c(y2023, y2024),
                     names_to = "year", values_to = "score",
                     names_prefix = "y")

    결과는 \(3\times2 = 6\)행입니다. 긴 형식은 ggplot2에서 연도를 색이나 x축에 대응시킬 때, 또는 반복 측정 자료를 회귀(혼합모형)에 넣을 때 필요합니다. 다시 넓은 형식으로는 pivot_wider()로 돌아갑니다.
