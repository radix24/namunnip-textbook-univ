한 줄로 그리는 그래프

R의 기본 그래픽 함수는 자료를 넣으면 바로 그림이 나옵니다. 탐색 단계에서는 빠르게 많이 그려 보는 것이 중요합니다.

3.1.1세 가지 그래프

hist(mtcars$mpg, breaks = 10, main = "연비 분포", xlab = "mpg", col = "grey")
boxplot(mpg ~ cyl, data = mtcars, xlab = "기통", ylab = "mpg")
plot(mpg ~ wt, data = mtcars, pch = 19, col = mtcars$cyl / 2,
     xlab = "무게 (천 lb)", ylab = "연비 (mpg)")
abline(lm(mpg ~ wt, data = mtcars), col = "red")      # 회귀선 추가
legend("topright", legend = c(4, 6, 8), col = c(2, 3, 4), pch = 19, title = "기통")

공통 인수: main(제목), xlab/ylab(축 이름), col(색), pch(점 모양), xlim/ylim(축 범위). par(mfrow = c(1, 2))로 여러 그림을 한 화면에 놓습니다.

3.1.2저장

png("fig/mpg.png", width = 1600, height = 1200, res = 200)
hist(mtcars$mpg)
dev.off()

예제 3.1.1

airquality에서 월별 오존 상자그림과 기온-오존 산점도를 나란히 그리세요.

par(mfrow = c(1, 2))
boxplot(Ozone ~ Month, data = airquality, xlab = "월", ylab = "오존 (ppb)")
plot(Ozone ~ Temp, data = airquality, xlab = "기온 (°F)")

7~8월에 오존이 높고 퍼짐도 크며, 기온이 높을수록 오존이 휘어 오르는(지수적) 모양입니다. 결측 행은 자동으로 빠집니다.

요약
  1. hist, boxplot(y ~ g), plot(y ~ x).
  2. 제목, 축 이름, 단위를 항상 붙임.
  3. png() … dev.off()로 저장.

3.1.2

실습같은 자료인데 히스토그램 모양이 왜 달라 보일까?

실습 · 히스토그램의 계급

다루는 성취기준 [응통3-03-01]

목표

같은 200개 자료로 계급(막대) 수만 바꾸어 히스토그램을 그리면서, 계급이 너무 적거나 많을 때 분포의 모양을 어떻게 잘못 읽게 되는지 확인합니다. R의 hist()에서 breaks를 정하는 감각을 기릅니다. 성취기준 [응통3-03-01].

계급: 히스토그램에서 막대 하나가 맡는 값의 구간. 계급 폭 = (범위)/(계급 수).

밀도 척도: 막대 높이 = (계급 안 비율)/(계급 폭). 막대 넓이의 합이 1이 되어 계급 폭이 달라도 비교할 수 있습니다.

준비

자료는 대기 시간이 약 20분인 손님과 약 30분인 손님이 섞인 가상 자료 200개입니다(정해 둔 난수라 언제나 같은 자료). "자료 점 보기"를 켜면 막대 아래에 값 하나하나가 짧은 선으로 찍힙니다.

절차

  1. 계급 4개에서 시작해 분포가 봉우리 하나처럼 보이는지 적습니다.
  2. 계급을 8, 12, 20으로 늘리며 두 무리가 언제 뚜렷이 보이는지 적습니다.
  3. 계급을 50 이상으로 늘리고 "자료 점 보기"를 켜서 막대가 들쭉날쭉한 까닭을 봅니다.
  4. 출력의 스터지스 규칙과 프리드먼-다이아코니스 규칙이 권하는 계급 수와 직접 고른 값을 비교합니다.

기대 결과

  • 계급이 3~4개면 두 무리가 한 막대에 섞여 봉우리 하나처럼 보입니다. 이렇게 지나치게 뭉뚱그리면 중요한 구조를 놓칩니다.
  • 계급이 10~20개 사이에서는 20분과 30분 근처의 두 봉우리가 뚜렷합니다.
  • 계급이 50개를 넘으면 막대 하나에 몇 개밖에 들어가지 않아 우연한 들쭉날쭉함(잡음)이 커지고, 봉우리가 여럿 있는 것처럼 보이기도 합니다.
  • 스터지스 규칙은 \(n = 200\)에서 9개를 권하고, 프리드먼-다이아코니스 규칙은 사분위 범위를 써서 대략 비슷한 수를 권합니다. 규칙은 출발점일 뿐, 몇 가지를 그려 보고 고르는 것이 좋습니다.

분석

  1. 보고서에 히스토그램 하나만 실을 때, 계급 수 선택이 결론을 바꿀 수 있다면 어떻게 하는 것이 공정할까요?
  2. 밀도 그림(plot(density(x)))의 띠너비가 계급 폭과 같은 역할을 한다는 것을 설명해 보세요.
  3. 자료 점(러그)을 함께 그리면 어떤 오해를 막을 수 있나요?
