1.2.1조건과 반복

score <- 78
if (score >= 90) { "A" } else if (score >= 80) { "B" } else { "C 이하" }
ifelse(c(95, 82, 60) >= 80, "합격", "불합격")    # 벡터에 한꺼번에

total <- 0
for (i in 1:10) total <- total + i^2              # 1~10 제곱합 385
n <- 0; s <- 0
while (s < 100) { n <- n + 1; s <- s + n }       # 합이 100을 넘는 첫 n = 14

1.2.2함수

cv <- function(x, na.rm = TRUE) {
  sd(x, na.rm = na.rm) / mean(x, na.rm = na.rm)   # 변동계수
}
cv(mtcars$mpg)          # 약 0.30
cv(c(1, NA, 3))         # 기본값 na.rm = TRUE

함수는 마지막 식의 값을 돌려줍니다(return()은 중간에 끝낼 때). 함수 안에서 만든 변수는 밖에 영향을 주지 않습니다(지역 변수). 좋은 함수는 한 가지 일만 하고, 이름이 그 일을 말해 줍니다.

예제 1.2.1

표본 크기 \(n\)을 받아 표준정규 난수 \(n\)개의 평균을 돌려주는 함수를 만들고, \(n = 100\)으로 1000번 실행해 평균들의 표준편차를 구하세요.

mean_norm <- function(n) mean(rnorm(n))
set.seed(1)
m <- numeric(1000)
for (b in 1:1000) m[b] <- mean_norm(100)
sd(m)      # 이론값 1/sqrt(100) = 0.1 근처
요약
  1. if/else는 값 하나, ifelse는 벡터.
  2. for는 정해진 횟수, while은 조건까지.
  3. 되풀이되는 코드는 함수로, 결과 벡터는 미리 만들어 채움.
