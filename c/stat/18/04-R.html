4.R.1

연습로그선형모형 단원 마무리 연습

문제 6 · 모형·개념·판단·실습 · 힌트 2단계

다루는 성취기준 [응통18-04-01] [응통18-04-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 모형세 범주형 변수 \(X, Y, Z\)의 분할표에 대해 (가) 상호 독립 (나) \(Z\)가 주어졌을 때 \(X\)와 \(Y\)의 조건부 독립을 로그선형모형으로 쓰세요. 계층적 모형 표기도 쓰세요. [04-01]

    힌트 1

    상호 독립: \(\log\mu_{ijk} = \lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z\).

    힌트 2

    조건부 독립에는 \(XZ\)와 \(YZ\) 교호작용이 있고 \(XY\)는 없습니다.

    풀이

    (가) \(\log\mu_{ijk} = \lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z\), 표기 \((X, Y, Z)\). (나) \(\log\mu_{ijk} = \lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z + \lambda_{ik}^{XZ} + \lambda_{jk}^{YZ}\), 표기 \((XZ, YZ)\).

    계층적 모형에서는 교호작용 항이 있으면 그에 포함된 낮은 차수 항도 모두 넣습니다. \(XY\) 항이 없다는 것은 \(Z\)의 각 수준 안에서 \(X\)와 \(Y\)의 오즈비가 1이라는 뜻입니다.

  2. 개념응통5-01-01의 신장 결석 자료(작은 결석에서 A 93.1% 대 B 86.7%, 큰 결석에서 A 73.0% 대 B 68.8%, 합치면 A 78.0% 대 B 82.6%)를 조건부 오즈비와 주변 오즈비로 설명하세요. [04-02]

    힌트 1

    결석 크기별 오즈비(A 대 B 성공 오즈)는 모두 1보다 큽니다.

    힌트 2

    합친 표의 오즈비는 1보다 작습니다.

    풀이

    결석 크기별 조건부 오즈비는 작은 결석 \(\frac{81\times36}{6\times234} \approx 2.08\), 큰 결석 \(\frac{192\times25}{71\times55} \approx 1.23\)으로 둘 다 A가 유리하지만, 합친 주변 오즈비는 \(\frac{273\times61}{77\times289} \approx 0.75\)로 B가 유리해 보입니다.

    결석 크기 \(Z\)가 치료 \(X\)와 성공 \(Y\) 모두와 관련되어 있어 \(Z\)를 합치면 연관의 방향이 뒤집힙니다(심슨의 역설). 조건부 연관은 로그선형모형의 \(XY\) 항(또는 \(Z\)를 넣은 로지스틱 회귀)으로 추정합니다.

  3. 모형2×2×2 분할표에서 모형 \((XY, XZ, YZ)\)(동질 연관 모형)와 포화모형 \((XYZ)\)의 차이를 오즈비로 설명하세요. 두 모형을 비교하는 검정의 자유도는 얼마인가요? [04-01]

    힌트 1

    \(XYZ\) 항이 없으면 \(Z\)의 수준마다 \(X\)-\(Y\) 오즈비가 같습니다.

    힌트 2

    포화모형과 동질 연관 모형의 모수 수 차이를 세세요.

    풀이

    동질 연관 모형은 \(Z\)의 각 수준에서 \(X\)와 \(Y\)의 조건부 오즈비가 같다(연관이 있지만 그 크기가 \(Z\)와 무관)고 가정하고, 포화모형은 \(Z\)마다 다를 수 있게 합니다. 2×2×2에서 \(XYZ\) 항은 모수 1개이므로 비교 검정의 자유도는 1입니다(브레슬로-데이 검정과 비슷한 역할). 앞 문제 자료에서는 조건부 오즈비 2.08과 1.23이 같은지를 묻는 셈입니다.

  4. 개념로그선형모형과 로지스틱 회귀의 관계를 설명하세요. \(Y\)가 이진이고 \(X, Z\)가 설명변수일 때 어떤 로그선형모형이 로지스틱 회귀 \(\mathrm{logit}\,P(Y = 1) = \alpha + \beta_i^X + \beta_k^Z\)와 같나요? [04-01]

    힌트 1

    로지스틱 회귀는 \(\log(\mu_{i1k}/\mu_{i2k})\)를 모형화합니다.

    힌트 2

    설명변수끼리의 관계 \(XZ\)는 그대로 둡니다.

    풀이

    로그선형모형 \((XZ, XY, YZ)\)에서 \(\log(\mu_{i1k}/\mu_{i2k})\)를 계산하면 \(Y\)가 들어간 항만 남아 \(\alpha + \beta_i^X + \beta_k^Z\) 꼴이 됩니다. 곧 로지스틱 회귀는 설명변수 사이의 연관(\(XZ\))을 완전히 맞춘 로그선형모형과 같습니다. 반응 변수가 분명하면 로지스틱 회귀가 해석이 쉽고, 변수들을 대칭적으로 보는 연관 구조 탐색에는 로그선형모형이 알맞습니다.

  5. 판단대학 입시 자료에서 전체로는 여성 합격률이 낮았지만, 학과별로 보면 대부분 학과에서 여성 합격률이 비슷하거나 높았습니다. 성차별이 있는지 판단하려면 어떤 분석을 해야 하는지 쓰세요. [04-02]

    힌트 1

    여성이 경쟁률이 높은 학과에 더 많이 지원했을 수 있습니다.

    힌트 2

    학과를 조건으로 둔 비교가 필요합니다.

    풀이

    학과가 성별(지원 경향)과 합격률(경쟁률) 모두와 관련된 교란 변수이므로, 학과를 조건으로 둔 조건부 오즈비를 봐야 합니다. 학과를 넣은 로지스틱 회귀(합격 ~ 성별 + 학과)나 맨텔-헨젤 공통 오즈비로 학과 안에서의 성별 차이를 추정합니다. 이 분석은 "같은 학과 지원자 사이의 차별"에는 답하지만, 여성이 특정 학과에 지원하게 된 구조적 원인은 별도의 질문입니다.

  6. 실습R에서 3원 분할표에 로그선형모형 \((XZ, YZ)\)를 적합하는 방법을 두 가지 쓰세요. [04-01]

    힌트 1

    포아송 회귀로 적합할 수 있습니다.

    힌트 2

    MASS::loglm은 모형식을 그대로 받습니다.

    풀이 
    # 자료를 칸별 도수 형식(데이터프레임 X, Y, Z, n)으로 두고
fit1 <- glm(n ~ X*Z + Y*Z, family = poisson, data = d)
# 또는 표 객체 tab으로
fit2 <- MASS::loglm(~ X*Z + Y*Z, data = tab)

    잔차 이탈도(또는 \(G^2\))와 자유도로 적합도를 보고, 더 큰 모형과의 이탈도 차이로 조건부 독립을 검정합니다. 칸 도수가 포아송이라 가정하면 다항 표집에서도 같은 추정값을 얻습니다.
