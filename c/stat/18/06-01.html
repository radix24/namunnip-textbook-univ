  • 로지스틱 회귀 (3.1절).

만족도 1~5점을 어떻게 분석할까

순서 범주를 1~5 점수로 선형회귀하면 간격이 같다는 가정이 들어가고, 범주마다 따로 로지스틱 회귀를 하면 순서 정보를 버립니다. 누적 로짓 모형은 "몇 점 이하일 확률"을 모형화해 순서를 살립니다.

6.1.1모형

정의 6.1.1

범주 \(1 < 2 < \cdots < J\)에 대해 \(\mathrm{logit}\,P(Y \le j \mid \mathbf x) = \alpha_j - \boldsymbol\beta^\top\mathbf x\), \(j = 1, \ldots, J-1\). \(\alpha_1 < \cdots < \alpha_{J-1}\).

절편 \(\alpha_j\)는 범주 경계마다 다르지만 기울기 \(\boldsymbol\beta\)는 모든 경계에서 같습니다(비례 오즈 가정). 그래서 \(e^{\beta}\)는 "\(x\)가 1 커질 때 더 높은 범주에 있을 오즈"의 비로, 어느 경계에서 잘라도 같습니다. 잠재 연속 변수 \(Y^* = \boldsymbol\beta^\top\mathbf x + \varepsilon\)(로지스틱 오차)를 경계 \(\alpha_j\)로 자른 것으로 볼 수 있습니다. (부호 규약은 소프트웨어마다 달라 확인이 필요합니다.)

6.1.2적합과 점검

library(MASS)
fit <- polr(satisfaction ~ wait_time + staff, data = d, Hess = TRUE)
summary(fit); exp(coef(fit))      # 오즈비

비례 오즈 가정은 경계마다 따로 이진 로지스틱 회귀를 해서 계수가 비슷한지 보거나, 가정을 푼 모형과 우도비로 비교해 점검합니다. 깨지면 부분 비례 오즈 모형이나 기준범주 로짓(범주마다 다른 계수)을 씁니다.

예제 6.1.1

대기 시간 계수(10분 단위) \(\beta = -0.4\)입니다. 해석하세요.

풀이. \(e^{-0.4} = 0.67\). 대기 시간이 10분 길어질 때마다 더 높은 만족도 범주에 있을 오즈가 0.67배(33% 감소)이며, "4점 이상 대 3점 이하"로 자르든 "2점 이상 대 1점"으로 자르든 같습니다.

요약
  1. 누적 확률의 로짓 = 경계별 절편 − 공통 기울기.
  2. 비례 오즈: 한 오즈비로 순서 효과를 요약.
  3. 가정을 점검하고 깨지면 더 유연한 모형.

6.1.3연습문제

기본

  1. 범주가 5개이면 절편과 기울기(설명변수 2개) 모수는 모두 몇 개인가요?
    답

    절편 4 + 기울기 2 = 6개. 범주마다 따로 하는 기준범주 로짓이면 \(4\times3 = 12\)개.
