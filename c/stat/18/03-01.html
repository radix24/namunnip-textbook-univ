확률을 직선으로 예측하면

합격 여부(0/1)를 공부 시간으로 선형회귀하면 예측값이 1을 넘거나 0보다 작아질 수 있고, 오차의 분산도 \(\pi(1-\pi)\)라 일정하지 않습니다. 확률을 \((-\infty, \infty)\)로 펼친 뒤 직선을 맞추는 것이 로지스틱 회귀입니다.

3.1.1모형

정의 3.1.1

\(\mathrm{logit}(\pi) = \log\dfrac{\pi}{1-\pi} = \beta_0 + \beta_1x_1 + \cdots + \beta_px_p\), 곧 \(\pi = \dfrac{1}{1 + e^{-(\beta_0 + \boldsymbol\beta^\top\mathbf x)}}\).

로짓은 로그 오즈입니다. 확률 \(\pi\)는 \(x\)에 대해 S자 곡선이고, 기울기는 \(\pi = 0.5\) 근처에서 가장 큽니다(\(d\pi/dx = \beta_1\pi(1-\pi)\)).

3.1.2해석

\(x_1\)이 1 커지면(다른 변수 고정) 로그 오즈가 \(\beta_1\)만큼, 오즈가 \(e^{\beta_1}\)배가 됩니다. 곧 \(e^{\beta_1}\)이 오즈비입니다. 확률의 변화는 출발점에 따라 다르므로, 확률로 설명하려면 특정 \(x\)값에서의 예측 확률을 비교합니다.

예제 3.1.2

대학원 합격 모형 \(\mathrm{logit}(\hat\pi) = -4 + 0.8\times\text{GPA}\)(4.5 만점)에서 GPA 1점 상승의 오즈비와, GPA 3.0과 4.0의 합격 확률은?

풀이. 오즈비 \(e^{0.8} = 2.23\). GPA 3.0: 로짓 −1.6, \(\pi = 1/(1 + e^{1.6}) = 0.168\). GPA 4.0: 로짓 −0.8, \(\pi = 0.310\). 오즈는 2.23배지만 확률은 0.168 → 0.310(약 1.8배, 14%p)입니다.

요약
  1. 로짓 = 로그 오즈를 선형 모형으로.
  2. \(e^{\beta}\) = 오즈비(다른 변수 고정).
  3. 확률 변화는 \(x\) 위치에 따라 다름 → 예측 확률로 설명.

3.1.3연습문제

기본

  1. 예제에서 합격 확률이 0.5가 되는 GPA는?
    답

    로짓 0: \(-4 + 0.8x = 0\), \(x = 5\). 만점(4.5)으로도 0.5에 못 미칩니다.

3.1.2

실습로지스틱 회귀 계수는 확률을 어떻게 움직이는가?

실습 · 로짓과 오즈비

다루는 성취기준 [응통18-03-01]

목표

\(\mathrm{logit}\,P(Y = 1) = \beta_0 + \beta_1x\)의 두 계수를 바꾸면서 S자 곡선의 위치와 가파르기가 어떻게 변하는지 봅니다. \(x\)가 1 늘 때 오즈는 어디서나 \(e^{\beta_1}\)배가 되지만, 확률의 증가량은 \(x\)의 위치에 따라 다르다는 것을 숫자로 확인합니다. 성취기준 [응통18-03-01].

오즈: \(p/(1-p)\). 확률 0.8의 오즈는 4입니다.

로짓: 오즈의 로그 \(\ln\frac{p}{1-p}\). 로지스틱 회귀는 로짓을 \(x\)의 일차식으로 놓습니다.

오즈비: 두 오즈의 비. 이 모형에서 \(x\)가 1 늘 때의 오즈비는 \(e^{\beta_1}\)로 일정합니다.

준비

파란 곡선이 \(P(Y = 1 \mid x)\), 주황 세로선이 고른 \(x\), 빨간 점이 그 확률입니다. 회색 점선은 확률 0.5가 되는 곳입니다. "가상 자료 보기"를 켜면 이 모형에서 만든 0/1 자료 40개를 함께 보여 줍니다.

절차

  1. 처음 설정(\(\beta_0 = -4\), \(\beta_1 = 0.8\))에서 \(x = 5\)의 확률, 오즈, 오즈비를 적습니다.
  2. \(x\)를 1, 5, 8로 옮기며 "확률 증가"(x가 1 늘 때)를 적습니다. 오즈비는 바뀌나요?
  3. \(\beta_0\)만 −6, −2로 바꾸어 곡선이 어느 쪽으로 움직이는지 봅니다.
  4. \(\beta_1\)을 0.3, 2로 바꾸어 곡선의 가파르기와 확률 0.5인 곳의 기울기 \(\beta_1/4\)를 비교합니다.
  5. \(\beta_1\)을 음수로 바꾸면 어떻게 되나요?

기대 결과

  • 처음 설정에서 \(x = 5\)이면 로짓이 0이라 확률 0.5, 오즈 1이고, \(x = 6\)에서 확률 0.6900입니다. 오즈비는 \(e^{0.8} \approx 2.2255\)입니다.
  • 확률 증가량은 \(x = 5\)에서 약 0.19로 가장 크고, \(x = 1\)이나 \(x = 8\)처럼 곡선의 양 끝에서는 0.05 안팎으로 작습니다. 오즈비는 어디서나 2.2255로 같습니다.
  • \(\beta_0\)는 곡선을 좌우로 옮깁니다. 확률 0.5인 곳은 \(x = -\beta_0/\beta_1\)이라 \(\beta_0 = -6\)이면 7.5, \(\beta_0 = -2\)이면 2.5입니다.
  • \(\beta_1\)이 클수록 곡선이 가파르고, 확률 0.5인 곳의 기울기는 정확히 \(\beta_1/4\)입니다(\(p(1-p)\beta_1\)에서 \(p = 0.5\)).
  • \(\beta_1 < 0\)이면 곡선이 내려가는 S자가 되고 오즈비가 1보다 작습니다.

분석

  1. "\(\beta_1 = 0.8\)이므로 \(x\)가 1 늘면 확률이 0.8 늘어난다"는 해석이 틀린 까닭을 이 실습의 숫자로 설명해 보세요.
  2. "\(\beta_1/4\)는 확률 변화의 최대치"라는 경험 규칙(나누기 4 규칙)이 어디서 나오는지 설명해 보세요.
  3. 자료의 \(x\)가 모두 0~2에 있다면 곡선의 어느 부분만 보게 되나요? 그때 선형 확률 모형과 결과가 비슷할까요?

더 해 보기

R에서 plogis(-4 + 0.8 * 5)로 확률을, exp(0.8)로 오즈비를 계산합니다. 실제 자료 적합은 glm(am ~ wt, family = binomial, data = mtcars)로 해 보세요(응통18-03-02).
