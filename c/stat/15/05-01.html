정규화 상수를 모를 때

베이즈 사후분포는 \(\pi(\theta) \propto L(\theta)p(\theta)\)로, 비례 상수(주변 가능도)가 고차원 적분이라 계산할 수 없는 경우가 대부분입니다. 메트로폴리스-헤이스팅스(MH)는 밀도의 비만으로 \(\pi\)에서 표본을 만드는 마르코프 연쇄입니다.

5.1.1알고리즘

현재 상태 \(x\)에서

  1. 제안 \(y \sim q(\cdot \mid x)\).
  2. 수용 확률 \(\alpha(x, y) = \min\left\{1, \dfrac{\pi(y)q(x \mid y)}{\pi(x)q(y \mid x)}\right\}\)로 \(y\)로 옮기고, 아니면 \(x\)에 머문다(머문 것도 표본으로 센다).

제안이 대칭(\(q(y\mid x) = q(x \mid y)\), 예: \(y = x + \varepsilon\))이면 \(\alpha = \min\{1, \pi(y)/\pi(x)\}\)(메트로폴리스 알고리즘). 확률이 높은 곳으로는 항상 가고, 낮은 곳으로는 비율만큼 가끔 갑니다.

5.1.2왜 \(\pi\)로 가나

정리 5.1.1

MH 연쇄의 전이 핵 \(P(x, y) = q(y\mid x)\alpha(x, y)\) (\(y \ne x\))는 상세 균형 \(\pi(x)P(x,y) = \pi(y)P(y,x)\)를 만족한다. 따라서 \(\pi\)는 정상분포이다.

\(\pi(x)q(y\mid x)\alpha(x,y) = \min\{\pi(x)q(y\mid x), \pi(y)q(x\mid y)\}\)이고 이 식은 \(x\)와 \(y\)에 대해 대칭이므로 \(\pi(y)q(x\mid y)\alpha(y,x)\)와 같습니다. ∎

연쇄가 기약·비주기이면 에르고딕 정리로 \(\frac1n\sum h(X_t) \to E_\pi[h]\)입니다(응통9 3.3절).

5.1.3조율

랜덤워크 제안의 폭이 너무 작으면 수용률은 높지만 거의 움직이지 않고, 너무 크면 대부분 기각되어 제자리에 머뭅니다. 1차원 정규 목표에서 최적 수용률은 약 0.44, 고차원에서는 약 0.23으로 알려져 있습니다. 이 절의 실습 카드에서 폭을 바꿔 확인할 수 있습니다.

예제 5.1.2

베르누이 자료 \(n = 20\), 성공 14, 사전분포 균일일 때 사후분포 \(\pi(p) \propto p^{14}(1-p)^6\)에서 MH로 표본을 뽑는 코드를 쓰세요.

lp <- function(p) if (p <= 0 || p >= 1) -Inf else 14*log(p) + 6*log(1-p)
x <- numeric(10000); x[1] <- 0.5
for (t in 2:10000) { y <- x[t-1] + rnorm(1, 0, 0.1)
  x[t] <- if (log(runif(1)) < lp(y) - lp(x[t-1])) y else x[t-1] }
mean(x[-(1:1000)])    # 참값 15/22 = 0.682 근처

로그 척도에서 비교해 넘침을 피했습니다. 처음 1000개는 번인으로 버렸습니다.

요약
  1. 제안 → \(\min\{1, \pi(y)q(x|y)/(\pi(x)q(y|x))\}\)로 수용.
  2. 상세 균형으로 \(\pi\)가 정상분포, 정규화 상수 불필요.
  3. 제안 폭을 수용률로 조율합니다.

5.1.4연습문제

기본

  1. 독립 제안(\(q(y \mid x) = g(y)\))의 수용 확률을 쓰고, 기각법과 다른 점을 말하세요.
    답

    \(\min\{1, \frac{\pi(y)g(x)}{\pi(x)g(y)}\}\). 기각되면 다시 뽑는 기각법과 달리 현재 값을 한 번 더 셉니다. \(M\)을 몰라도 되지만 표본이 서로 상관됩니다.

5.1.2

실습Metropolis 알고리즘: 제안 폭이 너무 작아도, 너무 커도 안 되는 까닭

실습 · MCMC

다루는 성취기준 [응통15-05-01]

목표

봉우리가 두 개인 목표분포에서 Metropolis 알고리즘으로 표본을 뽑습니다. 제안 폭을 바꾸며 수용률, 경로 그림, 히스토그램이 어떻게 달라지는지 보고 알맞은 폭을 고르는 감을 익힙니다. 성취기준 [응통15-05-01].

Metropolis 알고리즘 (대칭 제안의 Metropolis-Hastings): 현재 값 \(x\)에서

  1. 후보 \(y = x + w Z\)를 제안한다(\(Z \sim N(0, 1)\), \(w\)는 제안 폭).
  2. 확률 \(\min\{1, f(y)/f(x)\}\)로 \(y\)로 옮기고, 아니면 \(x\)에 머문다.

\(f\)의 정규화 상수를 몰라도 비 \(f(y)/f(x)\)만 있으면 되는 것이 장점입니다. 이렇게 만든 값들은 \(f\)를 정상분포로 가지는 Markov 연쇄입니다.

수용률: 제안이 받아들여진 비율. 1차원 문제에서는 대략 0.2~0.5가 좋다고 알려져 있습니다.

준비

목표분포는 \(0.3\,N(-2, 0.7^2) + 0.7\,N(2, 1)\)로, 평균은 0.8이고 \(x < 0\)일 확률은 약 0.315입니다. 출발점은 0입니다. 위 그림은 반복에 따른 경로(trace), 아래 그림은 뽑은 값의 히스토그램과 목표분포(빨강)입니다. 난수는 가상이며 "다시 돌리기"는 새 난수로 처음부터 돌립니다.

절차

  1. \(w = 2\)에서 수용률, 표본 평균, \(x < 0\) 비율을 이론값(0.8, 0.315)과 비교합니다.
  2. \(w = 0.1\)로 줄이고 경로와 히스토그램을 봅니다. "다시 돌리기"를 여러 번 누릅니다.
  3. \(w = 20\)으로 늘려 경로 모양과 수용률을 봅니다.
  4. \(w = 0.1\)에서 \(N\)을 20000으로 늘리면 나아지는지 봅니다.

기대 결과

  • \(w = 2\): 수용률이 약 55%이고, 경로가 두 봉우리를 자주 오가며, 히스토그램이 빨간 곡선과 잘 맞습니다. 표본 평균과 \(x < 0\) 비율이 이론값에 가깝습니다.
  • \(w = 0.1\): 수용률은 95% 넘게 높지만 한 걸음이 너무 작아 경로가 천천히 기어갑니다. 한 봉우리에 갇혀 다른 봉우리를 거의 못 가므로 \(x < 0\) 비율이 0.315와 크게 다릅니다. 높은 수용률이 좋은 것이 아닙니다.
  • \(w = 20\): 후보가 대부분 확률이 낮은 먼 곳이라 수용률이 10% 안팎으로 떨어집니다. 경로가 계단 모양(같은 값에 오래 머묾)이 되고 히스토그램이 울퉁불퉁합니다.
  • \(w = 0.1\)에서 \(N\)을 늘리면 조금 나아지지만, 제안 폭을 고치는 것보다 훨씬 비효율적입니다.

분석

  1. 수용률만 보고 표본이 좋다고 판단하면 왜 위험한지 \(w = 0.1\)의 결과로 설명해 보세요.
  2. 출발점을 \(x = 10\)처럼 먼 곳에 두면 처음 몇백 번의 값은 어떻게 될까요? 이 값들을 버리는 것을 번인(burn-in)이라 합니다.
  3. 서로 다른 출발점에서 연쇄를 여러 개 돌려 비교하는 수렴 진단([응통15-05-03])이 이 실습의 어떤 문제를 잡아 줄지 적어 보세요.

더 해 보기

R로 직접 구현해 보세요.

f <- function(x) 0.3*dnorm(x, -2, 0.7) + 0.7*dnorm(x, 2, 1)
x <- numeric(5000); w <- 2
for (i in 2:5000) {
  y <- x[i-1] + w*rnorm(1)
  x[i] <- if (runif(1) < f(y)/f(x[i-1])) y else x[i-1]
}
mean(x); mean(x < 0); plot(x, type = "l")
