방정식을 풀 수 없을 때

감마분포의 형상 모수, 로지스틱 회귀의 계수처럼 점수 방정식 \(\ell'(\theta) = 0\)을 손으로 풀 수 없는 경우가 대부분입니다. 컴퓨터로 반복해 근을 찾습니다.

3.1.1반복식

현재 값 \(\theta_t\) 근처에서 \(\ell'(\theta) \approx \ell'(\theta_t) + \ell''(\theta_t)(\theta - \theta_t)\)를 0으로 두면

\[\theta_{t+1} = \theta_t - \frac{\ell'(\theta_t)}{\ell''(\theta_t)}.\]

다모수이면 \(\boldsymbol\theta_{t+1} = \boldsymbol\theta_t - H(\boldsymbol\theta_t)^{-1}\nabla\ell(\boldsymbol\theta_t)\)(\(H\)는 헤세 행렬). 로그가능도를 2차식으로 근사하고 그 꼭짓점으로 옮기는 것입니다.

참값 근처에서는 2차 수렴합니다. 오차가 매 단계 대략 제곱되어 맞는 자릿수가 두 배씩 늘어납니다. 반면 출발점이 멀거나 로그가능도가 오목하지 않은 곳에서는 발산하거나 최소점으로 갈 수 있으므로, 단계 크기를 줄이는 보호 장치(선 탐색)를 둡니다.

예제 3.1.1

코시 분포 위치 모수 \(\theta\)의 MLE를 자료 \(-1.2, 0.3, 0.8, 1.5, 9.0\)으로 구하세요.

풀이. \(\ell(\theta) = -\sum\log(1 + (x_i - \theta)^2)\). \(\ell' = \sum\frac{2(x_i - \theta)}{1 + (x_i - \theta)^2}\), \(\ell'' = \sum\frac{2[(x_i-\theta)^2 - 1]}{[1 + (x_i - \theta)^2]^2}\). 출발점을 중앙값 0.8로 두면 몇 번 만에 약 0.668에 수렴하고, optimize로 찾은 최대점과 같습니다. 평균 2.08은 이상값 9.0에 끌려가지만 MLE는 그렇지 않습니다. 출발점을 9.0 근처로 두면 다른 국소 최대로 갈 수 있으니 가능도를 그려 확인합니다.

x <- c(-1.2, 0.3, 0.8, 1.5, 9); th <- median(x)
for (i in 1:20) { u <- x - th
  g <- sum(2*u/(1+u^2)); h <- sum(2*(u^2-1)/(1+u^2)^2)
  th <- th - g/h }
th; optimize(function(t) -sum(log(1+(x-t)^2)), c(-5, 10), maximum = TRUE)
요약
  1. \(\theta_{t+1} = \theta_t - \ell'/\ell''\), 다모수는 헤세 행렬.
  2. 근처에서 2차 수렴, 멀면 불안정 → 좋은 출발점과 선 탐색.
  3. 수렴 뒤 \(-H^{-1}\)은 공분산 행렬의 추정값(관측 정보량).

3.1.2연습문제

기본

  1. 포아송 \(\lambda\)에 뉴턴-랩슨을 쓰면 한 단계 식은? 수렴값은?
    답

    \(\ell' = S/\lambda - n\), \(\ell'' = -S/\lambda^2\). \(\lambda_{t+1} = \lambda_t + \lambda_t^2(S/\lambda_t - n)/S = 2\lambda_t - n\lambda_t^2/S\). 수렴값 \(S/n = \bar x\).
