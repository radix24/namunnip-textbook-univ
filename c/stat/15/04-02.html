균일 난수 하나로 모든 분포를

컴퓨터의 난수 생성기는 (0, 1) 균일 난수(정확히는 결정적 수열이라 의사 난수)를 만듭니다. 다른 분포의 난수는 모두 이것을 변환해 만듭니다.

4.2.1역변환법

정리 4.2.1

\(U \sim U(0,1)\)이고 \(F^{-1}(u) = \inf\{x : F(x) \ge u\}\)이면 \(X = F^{-1}(U)\)의 분포함수는 \(F\)이다.

\(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\). 지수분포는 \(-\log(1-U)/\lambda\), 이산분포는 누적 확률표에서 \(U\)가 들어가는 칸을 찾습니다. \(F^{-1}\)이 닫힌 꼴이 아니면(정규분포) 수치로 구하거나 다른 방법을 씁니다. 정규 난수는 박스-뮬러 변환 \(\sqrt{-2\log U_1}\cos(2\pi U_2)\)로도 만듭니다.

4.2.2기각법

목표 밀도 \(f\)를 직접 뽑기 어렵지만, 뽑기 쉬운 밀도 \(g\)와 상수 \(M\)이 있어 모든 \(x\)에서 \(f(x) \le Mg(x)\)라고 합시다.

  1. \(Y \sim g\), \(U \sim U(0,1)\)을 뽑는다.
  2. \(U \le f(Y)/(Mg(Y))\)이면 \(Y\)를 받아들이고, 아니면 1로 돌아간다.
정리 4.2.2

받아들인 \(Y\)의 밀도는 \(f\)이고, 한 번 시도에서 받아들일 확률은 \(1/M\)이다.

그림으로는 \(Mg\) 아래 영역에 점을 고르게 뿌리고 \(f\) 아래에 떨어진 점의 \(x\) 좌표만 남기는 것입니다. \(f\)의 정규화 상수를 몰라도 됩니다(비만 필요). \(M\)이 1에 가까울수록 효율적입니다.

예제 4.2.3

\(\mathrm{Beta}(2, 2)\), \(f(x) = 6x(1-x)\)를 균일 제안분포로 기각법으로 뽑으세요.

풀이. \(f\)의 최댓값은 \(x = 0.5\)에서 1.5이므로 \(M = 1.5\), \(g = 1\). \(Y, U\)를 뽑아 \(U \le 4Y(1-Y)\)이면 받아들입니다. 수용률 \(1/1.5 = 2/3\).

rbeta22 <- function(n) { out <- numeric(0)
  while (length(out) < n) { y <- runif(n); u <- runif(n)
    out <- c(out, y[u <= 4 * y * (1 - y)]) }
  out[1:n] }
mean(rbeta22(1e5))   # 0.5 근처
요약
  1. 역변환: \(F^{-1}(U)\).
  2. 기각법: \(f \le Mg\)인 쉬운 \(g\)로 제안, 확률 \(f/(Mg)\)로 수용, 효율 \(1/M\).

4.2.3연습문제

기본

  1. 밀도 \(f(x) = 2x\) (\(0 < x < 1\))의 역변환 공식은?
    답

    \(F(x) = x^2\), \(X = \sqrt U\).
