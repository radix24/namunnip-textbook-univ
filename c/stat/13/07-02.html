  • 응통5 7.2절 보고서 쓰기, 7.1절.

다른 사람이 같은 실험을 할 수 있게

실험 보고서의 기준은 "읽은 사람이 같은 실험을 다시 할 수 있는가"입니다. 결과만큼 설계를 자세히 적어야 하는 이유입니다.

7.2.1구성

  1. 목적: 질문, 반응, 관심 있는 요인.
  2. 설계: 요인과 수준, 처리 수, 실험 단위와 반복, 블록, 랜덤화 방법, 실험 순서, 고정한 조건. 일부실시법이면 정의 관계와 별칭.
  3. 분석 방법: 모형식, 소프트웨어, 다중 비교 방법, 가정 점검.
  4. 결과: 셀 평균표(또는 그림)와 표준오차, 분산분석표, 효과 추정값과 신뢰구간, 교호작용 그림.
  5. 결론과 권고: 실용적 의미(어떤 조건을 쓰면 반응이 얼마나 나아지는가), 한계, 확인 실험 제안.

7.2.2결과 문장의 예

예제 7.2.1

ToothGrowth 분석(4.1, 4.2절)의 결과 문단을 쓰세요.

풀이. "기니피그 60마리를 비타민C 공급원(오렌지주스, 아스코르브산) 2가지와 용량(0.5, 1, 2 mg) 3가지의 6개 조합에 10마리씩 배정했다. 이원 분산분석 결과 용량(\(F_{2,54} = 92.0\), \(p < 0.001\))과 공급원(\(F_{1,54} = 15.6\), \(p < 0.001\))의 효과, 그리고 교호작용(\(F_{2,54} = 4.1\), \(p = 0.022\))이 유의했다. 0.5 mg과 1 mg에서는 오렌지주스가 이빨 길이를 평균 약 5~6 mm 더 늘렸으나 2 mg에서는 차이가 없었다(평균 26.1 대 26.1 mm). 따라서 저용량 투여에서는 오렌지주스가 권장된다."

주의 실험 중 계획과 달라진 점(빠진 실험 단위, 바뀐 순서, 측정 문제)은 숨기지 말고 적습니다. 결론의 신뢰도를 판단하는 데 꼭 필요한 정보입니다.
요약
  1. 설계를 재현 가능할 만큼 자세히.
  2. 평균표·그림, 분산분석표, 효과와 신뢰구간.
  3. 실용적 권고와 한계, 확인 실험.

7.2.3연습문제

기본

  1. "처리 B가 가장 좋았다(p < 0.05)"에 빠진 정보를 세 가지 들어 보세요.
    답

    무엇과 비교해 얼마나 좋았는지(효과 크기), 불확실성(신뢰구간), 어떤 검정과 다중 비교 방법을 썼는지, 설계(반복, 블록, 랜덤화).
