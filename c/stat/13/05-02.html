모든 조합을 다 할 수 없을 때

요인 7개의 \(2^7 = 128\)번 실험은 비쌉니다. 고차 교호작용은 대개 무시할 만하다는 가정 아래, 일부 조합만 골라 주효과와 2요인 교호작용을 추정할 수 있습니다.

5.2.1교락

\(2^3\) 실험을 하루 4번씩 이틀에 나눠야 한다면, 날(블록) 차이가 어떤 효과와 섞이게 됩니다. ABC 열이 +인 처리 \(a, b, c, abc\)를 첫날, −인 처리를 둘째 날 하면 블록 효과는 ABC와만 섞이고(교락) 나머지 효과는 블록과 직교합니다. 중요하지 않을 것 같은 고차 교호작용을 희생하는 것입니다.

5.2.2일부실시법

정의 5.2.1

\(2^{k-1}\) 일부실시법: \(2^k\)의 처리 가운데 정의 관계(예: \(I = ABC\))의 부호가 +인 절반만 실험하는 설계.

\(I = ABC\)이면 A열과 BC열이 똑같아져 두 효과를 구별할 수 없습니다. 이런 효과 쌍을 별칭이라 하며, 정의 관계에 곱해 구합니다(\(A \cdot ABC = A^2BC = BC\), 같은 문자의 제곱은 \(I\)). 별칭: \(A = BC\), \(B = AC\), \(C = AB\).

정의 5.2.2

해상도: 정의 관계의 가장 짧은 단어 길이. 해상도 III은 주효과가 2요인 교호작용과 별칭, IV는 주효과가 3요인과 별칭(2요인끼리는 서로 별칭), V는 2요인 교호작용이 3요인과 별칭.

예제 5.2.3

\(2^{4-1}\), \(I = ABCD\)의 별칭 구조와 해상도는?

풀이. \(A = BCD\), \(B = ACD\), \(C = ABD\), \(D = ABC\), \(AB = CD\), \(AC = BD\), \(AD = BC\). 해상도 IV. 8번 실험으로 주효과 4개를 3요인 교호작용(무시할 만함)과만 섞어 추정합니다. 2요인 교호작용끼리는 구별되지 않습니다. 만드는 법: A, B, C의 \(2^3\) 부호표를 쓰고 D = ABC 열로 둡니다.

요약
  1. 교락: 블록과 고차 교호작용을 섞어 블록 효과를 처리.
  2. 일부실시: 정의 관계로 절반(또는 1/\(2^p\))만, 별칭은 곱으로 구함.
  3. 해상도가 높을수록 주효과가 덜 섞입니다.

5.2.3연습문제

기본

  1. \(2^{3-1}\), \(I = ABC\)에서 실험할 처리 네 개는?
    답

    ABC 부호가 +인 \(a, b, c, abc\).
