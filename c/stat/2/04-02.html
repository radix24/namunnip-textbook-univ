  • 대칭 행렬의 고유값이 실수이고 고유벡터가 직교함을 안다.

먼저 알아야 할 것
  • 고유값 (4.1절), 직교 행렬 (3.3절).

통계의 행렬은 대개 대칭

공분산 행렬, \(X^\top X\), 사영 행렬은 모두 대칭입니다. 대칭 행렬은 특히 좋은 성질을 가져서, 서로 수직인 축들로 완전히 분해됩니다.

4.2.1스펙트럼 정리

정리 4.2.1 (스펙트럼 정리)

실대칭 행렬 \(A\)는 실수 고유값을 가지고, 정규직교 고유벡터로 대각화된다: \(A = Q\Lambda Q^\top\), \(Q^\top Q = I\).

서로 다른 고유값의 고유벡터가 직교하는 이유: \(A\mathbf u = \lambda\mathbf u\), \(A\mathbf v = \mu\mathbf v\)이면 \(\lambda\mathbf v^\top\mathbf u = \mathbf v^\top A\mathbf u = (A\mathbf v)^\top\mathbf u = \mu\mathbf v^\top\mathbf u\)(대칭성 사용)이므로 \(\lambda \ne \mu\)이면 \(\mathbf v^\top\mathbf u = 0\).

바꿔 쓰면 \(A = \sum_i\lambda_i\mathbf q_i\mathbf q_i^\top\): 서로 수직인 방향들로의 사영 행렬에 고유값을 곱해 더한 것입니다. 함수도 같은 방식으로 정의합니다: \(A^{1/2} = Q\Lambda^{1/2}Q^\top\), \(A^{-1} = Q\Lambda^{-1}Q^\top\).

예제 4.2.2

\(\Sigma = \begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix}\)의 스펙트럼 분해를 구하세요.

풀이. \(\lambda^2 - 4\lambda + 3 = 0\), \(\lambda = 3, 1\). 고유벡터 \((1,1)/\sqrt2\), \((1,-1)/\sqrt2\). \(\Sigma = 3\cdot\frac12\begin{pmatrix}1 & 1\\1 & 1\end{pmatrix} + 1\cdot\frac12\begin{pmatrix}1 & -1\\-1 & 1\end{pmatrix}\). 이 공분산을 가진 정규분포의 등고선은 \((1,1)\) 방향으로 긴 타원(긴 반축 비 \(\sqrt3 : 1\))입니다.

요약
  1. 대칭 → 실수 고유값, 직교 고유벡터.
  2. \(A = Q\Lambda Q^\top = \sum\lambda_i\mathbf q_i\mathbf q_i^\top\).
  3. 행렬의 제곱근, 역행렬을 고유값으로 계산.

4.2.2

실습대칭행렬은 원을 어떤 타원으로 바꾸는가?

실습 · 고유값과 스펙트럼 분해

다루는 성취기준 [응통2-04-02] [응통2-05-02]

목표

\(2\times2\) 대칭행렬 \(A = \begin{pmatrix}a & b\\ b & d\end{pmatrix}\)의 성분을 바꾸면서, 단위원 위의 점 \(\mathbf x\)를 \(A\mathbf x\)로 옮긴 모양이 타원이 되고, 그 타원의 축이 고유벡터 방향, 반축 길이가 고유값의 절댓값이 됨을 확인합니다. 양정치 여부도 고유값의 부호로 판정합니다. 성취기준 [응통2-04-02], [응통2-05-02].

고유벡터: \(A\mathbf e = \lambda\mathbf e\)를 만족하는 0이 아닌 벡터. \(A\)를 곱해도 방향이 바뀌지 않고 길이만 \(\lambda\)배가 됩니다.

스펙트럼 분해: 대칭행렬은 \(A = \lambda_1\mathbf e_1\mathbf e_1^\top + \lambda_2\mathbf e_2\mathbf e_2^\top\)으로 쓸 수 있고, \(\mathbf e_1 \perp \mathbf e_2\)입니다.

양정치: 모든 \(\mathbf x \ne \mathbf 0\)에서 \(\mathbf x^\top A\mathbf x > 0\). 대칭행렬에서는 모든 고유값이 양수인 것과 같습니다.

준비

회색 점선은 단위원, 파란 실선은 단위원을 \(A\)로 옮긴 곡선입니다. 빨강과 주황 화살표는 \(\lambda_1\mathbf e_1\), \(\lambda_2\mathbf e_2\)입니다. 작은 회색 점(각도 30도)이 \(A\)를 곱한 뒤 검은 점으로 옮겨집니다.

절차

  1. 처음 설정 \(a = d = 2\), \(b = 1\)에서 고유값과 고유벡터를 적고, 타원의 긴 축과 빨간 화살표 방향을 비교합니다.
  2. \(b = 0\)으로 바꿉니다. 타원과 고유벡터가 어떻게 되나요?
  3. \(a = 3\), \(d = 1\), \(b = 0\)에서 \(b\)를 0부터 2까지 천천히 올리며 고유벡터가 도는 모습과 \(\lambda_2\)의 부호를 봅니다.
  4. \(a = 1\), \(d = 1\), \(b = 1\)로 두면 무엇이 생기나요? 행렬식을 확인합니다.
  5. 출력의 "대각합 = λ₁ + λ₂", "행렬식 = λ₁λ₂"가 여러 설정에서 성립하는지 확인합니다.

기대 결과

  • 처음 설정에서 \(\lambda_1 = 3\), \(\lambda_2 = 1\), \(\mathbf e_1 = (0.707, 0.707)\)입니다. 타원의 긴 반축이 45도 방향으로 길이 3, 짧은 반축이 길이 1입니다(응통2-04-02 본문의 예제와 같은 행렬).
  • \(b = 0\)이면 고유벡터가 좌표축 방향이 되고 고유값은 대각 성분 그대로입니다.
  • \(a = 3\), \(d = 1\)에서 \(b\)를 키우면 \(\lambda_2 = 2 - \sqrt{1 + b^2}\)이 줄어 \(b = \sqrt3 \approx 1.73\)에서 0, 그보다 크면 음수가 됩니다. \(\lambda_2 = 0\) 근처에서 타원이 선분처럼 납작해졌다가, 음수가 되면 다시 부풀지만 \(\mathbf e_2\) 방향이 뒤집힌 타원이 됩니다(주황 화살표가 \(\mathbf e_2\)의 반대쪽을 가리킴). 출력은 부정치로 바뀝니다.
  • \(a = d = b = 1\)이면 \(\lambda_2 = 0\), 행렬식 0이라 원 전체가 한 선분으로 납작해집니다(계수 1, 양의 준정치).
  • 대각합과 행렬식 관계는 언제나 성립합니다.

분석

  2. 공분산 행렬은 왜 \(\lambda_2 < 0\)이 될 수 없나요(응통2-05-02)?
