5.R.1

연습이차형식과 양정치 행렬 단원 마무리 연습

문제 6 · 계산·개념·증명 · 힌트 2단계

다루는 성취기준 [응통2-05-01] [응통2-05-02] [응통2-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산이차형식 \(q(x, y) = 3x^2 + 4xy + y^2\)을 대칭 행렬 \(A\)로 \(q = \mathbf x^\top A\mathbf x\)처럼 나타내세요. [05-01]

    힌트 1

    대각 성분은 제곱항의 계수입니다.

    힌트 2

    교차항 \(4xy\)는 \(a_{12}xy + a_{21}yx\)로 나뉘므로, 대칭이면 \(a_{12} = a_{21} = 2\)입니다.

    풀이

    \(A = \begin{pmatrix}3 & 2\\ 2 & 1\end{pmatrix}\)입니다. \(\mathbf x^\top A\mathbf x = 3x^2 + 2xy + 2yx + y^2 = 3x^2 + 4xy + y^2\)으로 확인됩니다. 교차항 계수를 반으로 나누어 두 자리에 넣는다는 점이 핵심입니다.

  2. 계산앞 문제의 \(A\)가 양정치인지 판정하고, 양정치가 아니라면 \(q(\mathbf x) < 0\)인 \(\mathbf x\)를 하나 찾으세요. [05-02]

    힌트 1

    \(2\times2\) 대칭 행렬은 \(a_{11} > 0\)이고 \(\det A > 0\)이면 양정치입니다.

    힌트 2

    \(\det A = 3 - 4 = -1\)입니다. 고유값의 부호가 서로 다릅니다.

    풀이

    \(\det A = -1 < 0\)이므로 고유값 하나는 양수, 하나는 음수라 부정치(indefinite)입니다.

    예를 들어 \(\mathbf x = (1, -2)^\top\)이면 \(q = 3 - 8 + 4 = -1 < 0\)입니다. 반면 \(\mathbf x = (1, 0)^\top\)에서는 \(q = 3 > 0\)이므로, 방향에 따라 부호가 바뀝니다.

  3. 계산\(A = \begin{pmatrix}4 & 2\\ 2 & 5\end{pmatrix}\)의 촐레스키 분해 \(A = LL^\top\) (\(L\)은 대각 성분이 양수인 아래삼각)을 구하세요. [05-02]

    힌트 1

    \(L = \begin{pmatrix}l_{11} & 0\\ l_{21} & l_{22}\end{pmatrix}\)로 놓고 \(LL^\top\)를 전개해 성분을 맞춥니다.

    힌트 2

    \(l_{11}^2 = 4\), \(l_{11}l_{21} = 2\), \(l_{21}^2 + l_{22}^2 = 5\)입니다.

    풀이

    \(l_{11} = 2\), \(l_{21} = 1\), \(l_{22} = \sqrt{5 - 1} = 2\)이므로 \(L = \begin{pmatrix}2 & 0\\ 1 & 2\end{pmatrix}\)입니다. R의 chol()은 위삼각 \(L^\top = \begin{pmatrix}2&1\\0&2\end{pmatrix}\)를 돌려줍니다.

    촐레스키 분해는 양정치 행렬에서만 가능하므로 양정치 판정에도 쓰이고, \(\mathbf z \sim N(\mathbf 0, I)\)이면 \(L\mathbf z\)의 공분산이 \(A\)가 되어 상관된 정규 난수를 만들 때 씁니다.

  4. 개념임의의 공분산 행렬 \(\Sigma\)가 양의 준정치(\(\mathbf a^\top\Sigma\mathbf a \ge 0\))인 까닭을 분산의 성질로 설명하고, 등호가 성립하는 경우의 뜻을 쓰세요. [05-02]

    힌트 1

    확률벡터 \(\mathbf X\)의 일차결합 \(\mathbf a^\top\mathbf X\)의 분산은 \(\mathbf a^\top\Sigma\mathbf a\)입니다.

    힌트 2

    분산은 음수가 될 수 없습니다.

    풀이

    \(\mathrm{Var}(\mathbf a^\top\mathbf X) = \mathbf a^\top\Sigma\mathbf a\)이고 분산은 0 이상이므로 모든 \(\mathbf a\)에 대해 \(\mathbf a^\top\Sigma\mathbf a \ge 0\)입니다.

    어떤 \(\mathbf a \ne \mathbf 0\)에서 등호가 성립하면 \(\mathbf a^\top\mathbf X\)가 상수, 곧 변수들 사이에 정확한 일차 관계가 있다는 뜻입니다(예: 세 과목 점수와 그 합계를 함께 넣은 경우). 이때 \(\Sigma\)는 특이하여 역행렬이 없습니다.

  5. 증명\(X\)가 \(n\times p\)이고 계수가 \(p\)일 때 모자 행렬 \(H = X(X^\top X)^{-1}X^\top\)가 대칭이고 멱등(\(H^2 = H\))이며 \(\operatorname{tr}H = p\)임을 보이세요. [05-03]

    힌트 1

    \(H^2 = X(X^\top X)^{-1}X^\top X(X^\top X)^{-1}X^\top\)에서 가운데를 정리해 보세요.

    힌트 2

    대각합의 순환 성질 \(\operatorname{tr}(AB) = \operatorname{tr}(BA)\)를 씁니다.

    풀이

    \((X^\top X)^{-1}\)은 대칭이므로 \(H^\top = X(X^\top X)^{-1}X^\top = H\)입니다. \(H^2 = X(X^\top X)^{-1}(X^\top X)(X^\top X)^{-1}X^\top = X(X^\top X)^{-1}X^\top = H\)입니다. \(\operatorname{tr}H = \operatorname{tr}\big((X^\top X)^{-1}X^\top X\big) = \operatorname{tr}(I_p) = p\)입니다.

    해석: \(H\)는 \(\mathbf y\)를 \(X\)의 열공간에 사영해 \(\hat{\mathbf y} = H\mathbf y\)를 만듭니다. 멱등이라 한 번 사영한 것을 다시 사영해도 그대로이고, 대각합 \(p\)는 적합에 쓴 모수의 개수(모형의 자유도)입니다. 잔차의 자유도가 \(n - p\)인 까닭이 \(\operatorname{tr}(I - H) = n - p\)입니다.

  6. 계산\(n\times n\) 중심화 행렬 \(C = I - \frac1nJ\) (\(J\)는 모든 성분이 1)에 대해 \(C\mathbf x\), \(\mathbf x^\top C\mathbf x\), \(\operatorname{tr}C\)를 구하세요. \(\mathbf x = (1, 2, 6)^\top\)일 때 값도 계산하고, 표본분산을 \(n - 1\)로 나누는 까닭과 연결하세요. [05-03]

    힌트 1

    \(\frac1nJ\mathbf x\)는 모든 성분이 \(\bar x\)인 벡터입니다.

    힌트 2

    \(C\)는 대칭 멱등이므로 \(\mathbf x^\top C\mathbf x = (C\mathbf x)^\top(C\mathbf x)\)입니다.

    풀이

    \(C\mathbf x = \mathbf x - \bar x\mathbf 1\) (편차 벡터), \(\mathbf x^\top C\mathbf x = \sum(x_i - \bar x)^2\), \(\operatorname{tr}C = n - 1\)입니다. \(\mathbf x = (1, 2, 6)^\top\)이면 \(C\mathbf x = (-2, -1, 3)^\top\), \(\mathbf x^\top C\mathbf x = 14\), \(\operatorname{tr}C = 2\)입니다.

    \(C\)는 \(\mathbf 1\)에 직교하는 \(n-1\)차원 공간으로의 사영이므로, 편차는 \(n-1\)개의 자유로운 방향만 가집니다(편차의 합이 0이라는 제약). 그래서 편차 제곱합의 기댓값이 \((n-1)\sigma^2\)이 되어 \(n-1\)로 나눕니다.
