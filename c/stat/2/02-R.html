2.R.1

연습행렬식과 역행렬 단원 마무리 연습

문제 6 · 계산·개념·판단 · 힌트 2단계

다루는 성취기준 [응통2-02-01] [응통2-02-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(A = \begin{pmatrix}2&1&0\\1&3&1\\0&1&2\end{pmatrix}\)의 행렬식을 첫 행 여인수 전개로 구하세요. [02-01]

    힌트 1

    \(\det A = a_{11}C_{11} + a_{12}C_{12} + a_{13}C_{13}\)이고 \(C_{ij} = (-1)^{i+j}M_{ij}\)입니다.

    힌트 2

    \(a_{13} = 0\)이므로 세 번째 항은 계산할 필요가 없습니다.

    풀이

    \(\det A = 2\begin{vmatrix}3&1\\1&2\end{vmatrix} - 1\begin{vmatrix}1&1\\0&2\end{vmatrix} + 0 = 2(6-1) - (2-0) = 8\)입니다. 0이 많은 행이나 열을 골라 전개하면 계산이 줄어듭니다.

  2. 계산\(3\times3\) 행렬 \(A\)의 행렬식이 3입니다. \(\det(2A)\), \(\det(A^\top)\), \(\det(A^{-1})\), \(\det(A^2)\)을 구하세요. [02-01]

    힌트 1

    \(2A\)는 모든 행에 2를 곱한 것입니다. 한 행에 2를 곱하면 행렬식이 2배가 됩니다.

    힌트 2

    \(\det(AB) = \det A\det B\)를 씁니다.

    풀이

    \(\det(2A) = 2^3\cdot3 = 24\) (행이 3개라 \(2\)가 세 번 곱해짐), \(\det(A^\top) = 3\), \(\det(A^{-1}) = 1/3\) (\(AA^{-1} = I\)에서), \(\det(A^2) = 9\).

    \(\det(2A) = 2\det A\)라고 쓰는 실수가 흔합니다. \(n\times n\)이면 \(\det(cA) = c^n\det A\)입니다.

  3. 계산\(A = \begin{pmatrix}2 & 1\\ 5 & 3\end{pmatrix}\)의 역행렬을 구하고 \(AA^{-1} = I\)를 확인하세요. 이를 써서 \(2x + y = 4\), \(5x + 3y = 7\)을 푸세요. [02-02]

    힌트 1

    \(2\times2\)에서 \(\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1} = \dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\)입니다.

    힌트 2

    해는 \(\mathbf x = A^{-1}\mathbf b\)입니다.

    풀이

    \(\det A = 6 - 5 = 1\)이므로 \(A^{-1} = \begin{pmatrix}3 & -1\\ -5 & 2\end{pmatrix}\)입니다. \(AA^{-1} = \begin{pmatrix}6-5 & -2+2\\ 15-15 & -5+6\end{pmatrix} = I\)입니다.

    \(\mathbf x = A^{-1}\begin{pmatrix}4\\7\end{pmatrix} = \begin{pmatrix}12-7\\ -20+14\end{pmatrix} = \begin{pmatrix}5\\-6\end{pmatrix}\)이므로 \(x = 5\), \(y = -6\)입니다.

  4. 개념\(n\times n\) 행렬 \(A\)에 대해 "\(A\)가 가역이다"와 같은 뜻인 조건을 네 가지 쓰세요. [02-02]

    힌트 1

    행렬식, 계수, 연립방정식의 해, 열벡터의 관계를 생각해 보세요.

    힌트 2

    한 조건이 깨지면 나머지도 모두 깨집니다.

    풀이

    \(\det A \ne 0\).

    \(\operatorname{rank}A = n\).

    \(A\mathbf x = \mathbf 0\)의 해가 \(\mathbf x = \mathbf 0\)뿐이다.

    \(A\)의 열벡터들이 일차독립이다(열공간이 \(\mathbb R^n\) 전체이다).

    그 밖에 "0이 고유값이 아니다", "모든 \(\mathbf b\)에 대해 \(A\mathbf x = \mathbf b\)의 해가 하나뿐이다"도 같은 뜻입니다.

  5. 계산\(A = \begin{pmatrix}1&2&3\\2&4&6\\1&0&1\end{pmatrix}\)의 계수를 구하고, 가역인지 판정하세요. [02-02]

    힌트 1

    둘째 행과 첫째 행의 관계를 보세요.

    힌트 2

    계수가 3보다 작으면 가역이 아닙니다.

    풀이

    둘째 행이 첫째 행의 2배이므로 \(R_2 - 2R_1\)이 영행이 됩니다. 첫째 행과 셋째 행은 비례하지 않으므로 계수는 2입니다. 계수가 \(3\)보다 작으므로 가역이 아니며, \(\det A = 0\)입니다.

  6. 판단\(30\times30\) 행렬 \(A = 0.1I\)의 행렬식은 \(10^{-30}\)입니다. "행렬식이 거의 0이므로 거의 특이(역행렬이 불안정)하다"는 판단이 맞는지 평가하세요. [02-02]

    힌트 1

    \(A^{-1}\)을 직접 구해 보세요.

    힌트 2

    행렬식은 크기(척도)에 민감합니다. 특이에 가까운 정도는 조건수 \(\sigma_{\max}/\sigma_{\min}\)로 잽니다.

    풀이

    틀렸습니다. \(A^{-1} = 10I\)로 아무 문제 없이 구해지고, 조건수는 \(1\)(가장 좋음)입니다. 행렬식이 작은 것은 모든 방향이 0.1배로 줄었기 때문일 뿐입니다.

    행렬식은 척도를 바꾸면 \(c^n\)배로 변하므로 "얼마나 특이에 가까운가"의 척도로 쓰기 어렵습니다. 수치 계산에서는 조건수(R의 kappa())나 가장 작은 특이값, 수치 계수(qr()$rank)로 판정합니다.
