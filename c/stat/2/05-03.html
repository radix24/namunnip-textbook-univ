두 번 해도 같은 변환

사영을 한 번 한 벡터를 다시 사영해도 그대로입니다. \(P^2 = P\)인 행렬, 곧 멱등 행렬은 통계에서 "적합값을 만드는 행렬", "평균을 빼는 행렬"로 계속 나옵니다.

5.3.1성질

정리 5.3.1

대칭 멱등 행렬 \(P\)는 (가) 고유값이 0 또는 1 (나) \(\mathrm{rank}(P) = \mathrm{tr}(P)\) (다) \(I - P\)도 대칭 멱등이고 \(P(I - P) = 0\).

(가) \(P\mathbf v = \lambda\mathbf v\)이면 \(P^2\mathbf v = \lambda^2\mathbf v = P\mathbf v = \lambda\mathbf v\), \(\lambda^2 = \lambda\). (나) 대칭이라 대각화되고, 계수 = 0이 아닌 고유값 수 = 1의 개수 = 고유값 합 = 대각합. (다) 전개하면 바로 나옵니다. ∎

5.3.2모자 행렬

\(H = X(X^\top X)^{-1}X^\top\)에서 대각합의 순환성 \(\mathrm{tr}(AB) = \mathrm{tr}(BA)\)을 쓰면

\[\mathrm{tr}(H) = \mathrm{tr}((X^\top X)^{-1}X^\top X) = \mathrm{tr}(I_p) = p.\]

따라서 \(H\)의 계수는 \(p\), \(I - H\)의 계수는 \(n - p\)입니다. 적합값은 \(p\)차원, 잔차는 \(n - p\)차원 공간에 있고, 정규 오차라면 \(\mathrm{SSE}/\sigma^2 = \boldsymbol\varepsilon^\top(I-H)\boldsymbol\varepsilon/\sigma^2 \sim \chi^2_{n-p}\)입니다. \(E(\mathrm{SSE}) = \sigma^2\mathrm{tr}(I - H) = (n-p)\sigma^2\)이라서 \(\mathrm{SSE}/(n-p)\)가 불편추정량입니다. 지렛값 \(h_{ii}\)의 합이 \(p\)라 평균이 \(p/n\)인 이유도 이것입니다(응통10 4.2절).

예제 5.3.2

\(J = \mathbf 1\mathbf 1^\top/n\)이 멱등임을 보이고 대각합을 구하세요.

풀이. \(J^2 = \mathbf 1(\mathbf 1^\top\mathbf 1)\mathbf 1^\top/n^2 = \mathbf 1\mathbf 1^\top/n = J\). 대각 원소가 모두 \(1/n\)이라 대각합 1(계수 1, 평균 방향). \(I - J\)의 대각합은 \(n - 1\).

요약
  1. 멱등: 고유값 0/1, 계수 = 대각합.
  2. \(\mathrm{tr}(H) = p\), \(\mathrm{tr}(I - H) = n - p\): 회귀의 자유도.
  3. \(E(\mathbf e^\top\mathbf e) = (n-p)\sigma^2\).

5.3.3연습문제

응용

  1. \(E(\mathbf y^\top A\mathbf y) = \mathrm{tr}(A\Sigma) + \boldsymbol\mu^\top A\boldsymbol\mu\)(\(E\mathbf y = \boldsymbol\mu\), \(\mathrm{Var}\,\mathbf y = \Sigma\))를 써서 \(E(\mathrm{SSE})\)를 구하세요.
    답

    \(A = I - H\), \(\Sigma = \sigma^2I\), \(\boldsymbol\mu = X\boldsymbol\beta\). \((I - H)X = 0\)이라 둘째 항 0, 첫째 항 \(\sigma^2(n-p)\).
