인구 5000만인 나라와 50만인 도시에서 같은 정확도로 여론을 조사하려면 표본이 100배 필요할까요? 직관과 달리 거의 같은 크기면 됩니다.

2.2.1수정 계수

정의 2.2.1

유한 모집단 수정 계수(fpc): \(1 - f\), \(f = n/N\)은 추출 비율.

\(\mathrm{Var}(\bar y) = (1-f)S^2/n\)에서 \(f\)가 작으면(5% 미만) 수정 계수는 거의 1이고, 분산은 무한 모집단의 \(S^2/n\)과 같습니다. 정확도는 추출 비율이 아니라 표본 크기 \(n\)이 정합니다. 5000만 명이든 50만 명이든 1000명을 뽑으면 오차 한계는 거의 같습니다.

반대 극단에서 \(n = N\)(전수조사)이면 \(1 - f = 0\)이라 분산이 0입니다. 모두 조사했으니 표본오차가 없습니다.

2.2.2복원추출과 비교

복원추출이면 각 관측이 독립이라 \(\mathrm{Var}(\bar y) = \frac{N-1}{N}\cdot\frac{S^2}{n}\)입니다. 비복원 쪽이 \(\frac{N-n}{N-1}\)배만큼 작습니다. 같은 사람을 두 번 조사하는 것은 정보를 늘리지 않기 때문입니다.

예제 2.2.2

\(S = 10\), \(n = 400\)일 때 \(N = 1000\), 10000, \(10^7\)의 표준오차는?

풀이. 무한 모집단 기준 \(10/20 = 0.5\). \(N = 1000\): \(0.5\sqrt{0.6} = 0.387\). \(N = 10000\): \(0.5\sqrt{0.96} = 0.490\). \(N = 10^7\): 0.5. 모집단이 1만 배 커져도 표준오차는 30%도 안 늘어납니다.

요약
  1. fpc \(= 1 - n/N\), 추출 비율이 작으면 무시해도 됩니다.
  2. 정확도는 \(n\)이 정하고 \(N\)은 거의 영향이 없습니다.

2.2.3연습문제

기본

  1. 학생 300명 중 150명을 조사하면 fpc 때문에 분산이 얼마나 줄어드나요?
    답

    \(1 - 0.5 = 0.5\), 분산이 절반, 표준오차는 약 71%.
