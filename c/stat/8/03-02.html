표본을 층에 어떻게 나눌까

전체 표본 \(n\)이 정해졌을 때 층마다 몇 개씩 뽑느냐에 따라 정확도가 달라집니다. 퍼짐이 큰 층에서 더 많이 뽑는 것이 이치에 맞습니다.

3.2.1네이만 배분

정리 3.2.1

\(\sum n_h = n\) 아래 \(\mathrm{Var}(\bar y_{st})\)를 최소화하는 배분은 \(n_h = n\dfrac{W_hS_h}{\sum_k W_kS_k}\)(fpc 무시)이고, 이때 \(\mathrm{Var} = \dfrac{(\sum W_hS_h)^2}{n} - \dfrac{\sum W_hS_h^2}{N}\).

\(n_h\)에 의존하는 부분은 \(\sum W_h^2S_h^2/n_h\)입니다. \(L = \sum W_h^2S_h^2/n_h + \lambda(\sum n_h - n)\)을 \(n_h\)로 미분하면 \(-W_h^2S_h^2/n_h^2 + \lambda = 0\), 곧 \(n_h = W_hS_h/\sqrt\lambda\). 합이 \(n\)이 되도록 \(\sqrt\lambda\)를 정하면 결론이 나옵니다. ∎

3.2.2비교

배분\(n_h \propto\)필요한 정보
비례\(N_h\)층 크기
네이만\(N_hS_h\)층 크기, 층 표준편차
비용 최적\(N_hS_h/\sqrt{c_h}\)층별 조사 단가 \(c_h\)까지

분산 순서는 항상 네이만 ≤ 비례 ≤ 단순임의(근사)입니다. 층 표준편차가 모두 같으면 네이만은 비례와 같아집니다. 이 절의 실습 카드에서 층 표준편차를 바꾸며 차이를 볼 수 있습니다.

예제 3.2.2

3.1절 예제의 층(\(W = 0.3, 0.7\), \(S = 4, 6\))에 \(n = 100\)을 네이만 배분하면?

풀이. \(W_hS_h = 1.2, 4.2\), 합 5.4. \(n_1 = 100 \times 1.2/5.4 = 22.2 \to 22\), \(n_2 = 78\). 비례 배분(30, 70)보다 퍼짐이 큰 재학생 층에 더 줍니다.

요약
  1. 네이만: \(n_h \propto N_hS_h\), 라그랑주 승수법으로 유도.
  2. 비용이 다르면 \(\sqrt{c_h}\)로 나눔.
  3. 층 표준편차는 과거 자료로 어림합니다.

3.2.3연습문제

응용

  1. 예제에서 네이만 배분과 비례 배분의 분산(fpc 무시)을 비교하세요.
    답

    네이만: \(5.4^2/100 = 0.2916\). 비례: \(\sum W_hS_h^2/n = (0.3 \times 16 + 0.7 \times 36)/100 = 0.300\). 차이는 작습니다. 층 표준편차 차이가 크지 않기 때문입니다.

3.2.2

실습같은 표본 크기로 더 정확하게: 층화와 Neyman 배분

실습 · 층화추출

다루는 성취기준 [응통8-03-02]

목표

세 층으로 나뉜 가상 모집단의 평균을 추정할 때, 단순임의추출·비례 배분·Neyman 배분의 표준오차를 비교합니다. 층의 표준편차를 바꾸며 Neyman 배분이 언제 크게 이기는지 봅니다. 성취기준 [응통8-03-02].

층화추출: 모집단을 서로 겹치지 않는 층으로 나누고 층마다 따로 단순임의추출을 하는 방법. 층 \(h\)의 크기를 \(N_h\), 비중을 \(W_h = N_h/N\)이라 하면 평균의 추정량은 \(\bar y_{st} = \sum_h W_h \bar y_h\).

비례 배분: 층 크기에 비례해 표본을 나눔. \(n_h = n W_h\).

Neyman 배분: 층 크기와 층 표준편차 \(S_h\)의 곱에 비례해 나눔. \(n_h = n \dfrac{W_h S_h}{\sum_k W_k S_k}\). 분산이 큰 층에서 더 많이 뽑습니다.

분산은 \(\mathrm{Var}(\bar y_{st}) = \sum_h W_h^2 \left(1 - \dfrac{n_h}{N_h}\right)\dfrac{S_h^2}{n_h}\)로 계산합니다.

준비

가상 모집단은 어느 도시의 가구 월 소비(만 원)를 흉내 냈습니다. 층 1(6000가구, 평균 200, 표준편차 40), 층 2(3000가구, 평균 350, 표준편차 80), 층 3(1000가구, 평균 800, 표준편차는 조절기로 정함). 막대는 세 방법의 표준오차입니다.

절차

  1. 기본값에서 세 방법의 표준오차와 두 배분의 표본 수를 읽습니다.
  2. 층 3 표준편차를 40으로 줄입니다. 층마다 퍼짐이 비슷해지면 비례 배분과 Neyman 배분의 차이가 어떻게 되나요?
  3. 층 3 표준편차를 600으로 올려 Neyman 배분이 층 3에 몇 개를 주는지 봅니다.
  4. \(n\)을 400으로 늘렸을 때 세 표준오차가 대략 절반이 되는지 확인합니다.

기대 결과

  • 층 평균이 크게 달라서 층화만 해도 단순임의추출보다 표준오차가 크게 줄어듭니다. 층 사이 차이가 분산에서 빠지기 때문입니다.
  • 기본값(층 3 표준편차 300)에서 비례 배분은 층 3에 10개만 주지만, Neyman 배분은 그 층의 퍼짐이 커서 40개 가까이 주고 표준오차가 비례 배분보다 더 작습니다.
  • 층 3 표준편차가 40이면 \(S_h\)가 비슷해져 두 배분이 거의 같아지고 표준오차도 거의 같습니다.
  • \(n\)을 4배로 하면 표준오차는 모두 대략 절반이 됩니다(유한 모집단 수정 때문에 조금 더 줄어듭니다).

분석

  1. Neyman 배분을 쓰려면 층 표준편차를 미리 알아야 합니다. 실제 조사에서는 이 값을 어디서 얻을 수 있을까요?
  2. 층 평균이 모두 같고 층 표준편차도 같다면 층화로 얻는 이득이 있을까요? 분산 식으로 따져 보세요.

더 해 보기

비용까지 고려하면 최적 배분은 \(n_h \propto W_h S_h/\sqrt{c_h}\)(\(c_h\)는 층 \(h\)의 조사 단가)입니다. R의 survey 패키지에서 svydesign(strata = ~stratum, fpc = ~N, …)로 층화 표본을 분석합니다.
