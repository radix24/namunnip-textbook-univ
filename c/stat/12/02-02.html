같은 사람의 전후 찬반

토론회 전후로 같은 200명에게 찬반을 물었습니다. 찬성 비율이 45%에서 55%로 올랐다면 의견이 바뀐 것일까요? 같은 사람을 두 번 쟀으므로 독립인 두 비율의 비교(카이제곱 검정)를 쓰면 안 됩니다.

2.2.1표와 검정

후 찬성후 반대
전 찬성\(a\)\(b\)
전 반대\(c\)\(d\)

전후 찬성 비율의 차이는 \((a + c) - (a + b) = c - b\)로, 의견을 바꾼 사람(불일치 쌍)에게서만 나옵니다. \(H_0\): 두 시점의 찬성 확률이 같음. 그러면 불일치 쌍 \(b + c\)개 가운데 반대 → 찬성으로 바뀐 수 \(c\)는 \(B(b + c, 1/2)\)를 따릅니다. 부호검정과 같은 구조입니다.

결과 2.2.1 (맥니마 검정)

큰 표본 근사: \(\chi^2 = \dfrac{(b - c)^2}{b + c} \sim \chi^2_1\). 작은 표본은 이항분포로 정확한 p값을 구한다.

예제 2.2.1

200명 중 \(a = 70\), \(b = 20\), \(c = 40\), \(d = 70\)입니다. 의견이 바뀌었나요?

풀이. 찬성 90명 → 110명. \(\chi^2 = 400/60 = 6.67\), p값 약 0.0098. 반대에서 찬성으로 바꾼 사람이 그 반대보다 유의하게 많습니다. R: mcnemar.test(matrix(c(70, 40, 20, 70), 2), correct = FALSE).

요약
  1. 대응 이진 자료는 불일치 쌍 \(b, c\)만 정보가 있습니다.
  2. \(\chi^2 = (b-c)^2/(b+c)\), 작으면 이항 정확 검정.

2.2.2연습문제

기본

  1. \(b = 3\), \(c = 11\)이면 정확한 양측 p값은?
    답

    \(P(B(14, 0.5) \le 3) = (1 + 14 + 91 + 364)/16384 = 470/16384 = 0.0287\), 양측 0.057.
