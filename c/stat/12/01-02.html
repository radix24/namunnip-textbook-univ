어떤 분포든 균일분포로

비모수 방법이 분포에 의존하지 않는 근본 이유는, 연속분포를 따르는 값을 분포함수에 넣으면 언제나 균일분포가 된다는 사실입니다.

1.2.1확률적분변환

정리 1.2.1

\(X\)의 분포함수 \(F\)가 연속이면 \(U = F(X) \sim U(0, 1)\).

\(F\)가 증가하는 구간에서 \(P(F(X) \le u) = P(X \le F^{-1}(u)) = F(F^{-1}(u)) = u\). ∎

\(F\)는 단조증가라 순서를 보존하므로 \(X_{(k)}\)를 \(F\)에 넣으면 균일 표본의 \(k\)번째 순서통계량 \(\sim \mathrm{Beta}(k, n-k+1)\)이 됩니다(응통6 6.3절). 따라서 \(P(X_{(j)} \le \xi_p \le X_{(k)})\)(\(\xi_p\)는 \(p\) 분위수)는 \(F\)와 관계없이 이항분포로 계산되고, 이것이 분위수의 분포 무관 신뢰구간(2.1절)의 근거입니다.

1.2.2순위와 동점

연속분포에서는 동점 확률이 0이지만 실제 자료는 반올림 때문에 동점이 생깁니다. 동점인 값에는 그들이 차지할 순위의 평균(평균 순위)을 줍니다. 예: 3.1, 4.2, 4.2, 5.0의 순위는 1, 2.5, 2.5, 4. 동점이 많으면 검정통계량의 분산 공식에 보정이 필요하고 정확한 분포표가 맞지 않으므로 소프트웨어의 보정된 근사를 씁니다.

예제 1.2.2

연속분포 표본 \(n = 10\)에서 \([X_{(2)}, X_{(9)}]\)가 중앙값을 포함할 확률은?

풀이. 중앙값보다 작은 관측 수 \(K \sim B(10, 1/2)\). 구간이 중앙값을 포함 ⟺ \(2 \le K \le 8\). \(1 - 2(1 + 10)/1024 = 1 - 22/1024 \approx 0.979\).

요약
  1. \(F(X) \sim U(0,1)\): 순서통계량 확률이 분포와 무관.
  2. 분위수 구간은 이항분포로 계산.
  3. 동점은 평균 순위로 처리하고 분산을 보정합니다.

1.2.3연습문제

기본

  1. 자료 7, 3, 7, 1, 9, 7의 평균 순위는?
    답

    정렬 1, 3, 7, 7, 7, 9 → 7은 3, 4, 5위의 평균 4. 원래 순서로 4, 2, 4, 1, 6, 4.
