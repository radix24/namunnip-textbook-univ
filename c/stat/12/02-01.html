가장 단순한 검정

값의 크기는 버리고 기준보다 큰지 작은지만 봅니다. 정보는 많이 버리지만 가정은 거의 없습니다.

2.1.1부호검정

\(H_0\): 모집단 중앙값 \(= m_0\). 기준과 같은 값은 빼고, 남은 \(n\)개 중 \(m_0\)보다 큰 관측 수를 \(S\)라 하면 \(H_0\) 아래 \(S \sim B(n, 1/2)\). \(S\)가 너무 크거나 작으면 기각합니다. 일반적으로 \(p\) 분위수 \(\xi_p = \xi_0\)이면 \(\xi_0\) 이하 관측 수가 \(B(n, p)\)입니다(분위수 검정).

대응 자료에서는 차이 \(d_i\)의 부호로 "차이의 중앙값 = 0"을 검정합니다.

예제 2.1.1

1.1절 예제의 통증 변화 −3, −2, −5, −1, 0, −4, +1, −6. 통증이 줄었는지 단측 검정하세요.

풀이. 0은 빼서 \(n = 7\), 양수 1개. \(H_1\): 중앙값 < 0. p값 \(= P(S \le 1) = (1 + 7)/128 = 0.0625\). \(\alpha = 0.05\)에서 아깝게 기각하지 못합니다. 크기 정보를 쓰는 부호순위 검정(4.1절)은 더 작은 p값을 줍니다. R: binom.test(1, 7, alternative = "less").

2.1.2중앙값의 신뢰구간

1.2절에서 \(P(X_{(k)} \le \xi_{0.5} \le X_{(n-k+1)}) = 1 - 2P(B(n, 1/2) \le k - 1)\). 이 값이 0.95 이상이 되는 가장 큰 \(k\)를 고르면 분포 무관 신뢰구간이 됩니다. 이산이라 신뢰수준을 정확히 0.95로 맞출 수는 없습니다.

요약
  1. 부호검정: 기준보다 큰 개수 \(\sim B(n, 1/2)\).
  2. 대응 자료는 차이의 부호로.
  3. 중앙값 구간 \([X_{(k)}, X_{(n-k+1)}]\), 이항분포로 \(k\)를 정함.

2.1.3연습문제

기본

  1. \(n = 20\)에서 중앙값의 신뢰구간 \([X_{(6)}, X_{(15)}]\)의 신뢰수준은? (\(P(B(20, 0.5) \le 5) = 0.0207\))
    답

    \(1 - 2 \times 0.0207 = 0.959\).
