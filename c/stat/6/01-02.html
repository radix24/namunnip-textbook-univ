양성 판정을 받았다면

유병률 1%인 병의 검사가 환자를 95% 양성으로, 건강한 사람을 90% 음성으로 판정합니다. 양성이 나왔을 때 실제 환자일 확률은 얼마일까요? 직관은 95% 근처를 말하지만 답은 약 9%입니다. 이 절의 도구로 계산해 봅니다.

1.2.1조건부확률

정의 1.2.1

\(P(B) > 0\)일 때 \(B\)가 일어났다는 조건 아래 \(A\)의 조건부확률은 \(P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}\).

표본공간을 \(B\)로 좁히고 그 안에서 \(A\)가 차지하는 비율을 잰 것입니다. 정의를 바꿔 쓰면 곱셈 법칙 \(P(A \cap B) = P(B)P(A \mid B)\)입니다.

정리 1.2.2 (전확률 공식)

\(B_1, \ldots, B_k\)가 \(\Omega\)를 배반으로 나누고 \(P(B_i) > 0\)이면 \(P(A) = \sum_i P(B_i)P(A \mid B_i)\).

\(A = \bigcup_i (A \cap B_i)\)는 배반 합집합이므로 공리 3과 곱셈 법칙에서 바로 나옵니다. ∎

1.2.2베이즈 정리

정리 1.2.3 (베이즈 정리) \[P(B_j \mid A) = \frac{P(B_j)P(A \mid B_j)}{\sum_i P(B_i)P(A \mid B_i)}.\]

조건부확률의 정의에 곱셈 법칙(분자)과 전확률 공식(분모)을 넣은 것입니다. "원인 \(B_j\)가 결과 \(A\)를 낼 확률"에서 "결과 \(A\)를 보고 원인이 \(B_j\)일 확률"로 방향을 뒤집습니다.

예제 1.2.4

도입의 검사 문제를 푸세요.

풀이. \(D\) = 환자, \(+\) = 양성. \(P(D) = 0.01\), \(P(+ \mid D) = 0.95\), \(P(+ \mid D^c) = 0.10\). \(P(+) = 0.01 \times 0.95 + 0.99 \times 0.10 = 0.0095 + 0.099 = 0.1085\). \(P(D \mid +) = 0.0095/0.1085 \approx 0.088\). 1만 명으로 생각하면 환자 100명 중 95명, 건강한 9900명 중 990명이 양성이라, 양성 1085명 가운데 환자는 95명뿐입니다. 드문 병에서는 가짜 양성이 진짜 양성보다 많습니다.

1.2.3독립

정의 1.2.5

\(P(A \cap B) = P(A)P(B)\)이면 \(A\)와 \(B\)는 독립. 사건 여러 개는 그중 어떤 부분 모임을 골라도 곱 공식이 성립할 때 서로 독립이라 합니다.

\(P(B) > 0\)이면 독립은 \(P(A \mid B) = P(A)\), 곧 \(B\)를 알아도 \(A\)의 확률이 바뀌지 않는다는 뜻입니다. 배반(\(A \cap B = \emptyset\))과 혼동하지 않습니다. 확률이 양수인 두 배반 사건은 하나가 일어나면 다른 하나는 절대 안 일어나므로 오히려 강하게 종속입니다.

주의 둘씩 독립이어도 셋이 서로 독립이 아닐 수 있습니다. 동전 두 개에서 \(A\) = 첫째 앞, \(B\) = 둘째 앞, \(C\) = 두 결과가 같음. 둘씩은 독립(각 확률 1/2, 교집합 1/4)이지만 \(P(A \cap B \cap C) = 1/4 \ne 1/8\).
요약
  1. \(P(A \mid B) = P(A \cap B)/P(B)\), 곱셈 법칙, 전확률 공식.
  2. 베이즈 정리는 조건의 방향을 뒤집습니다. 기저율(사전 확률)을 꼭 넣습니다.
  3. 독립은 곱 공식, 배반과 다릅니다.

1.2.4연습문제

기본

  1. 예제 1.2.4에서 양성이 나온 사람이 독립인 같은 검사를 한 번 더 받아 또 양성이면 환자일 확률은?
    답

    사전 확률을 0.088로 두고 다시 계산: \(0.088 \times 0.95/(0.088 \times 0.95 + 0.912 \times 0.10) = 0.0836/0.1748 \approx 0.48\).

응용

  1. \(A\)와 \(B\)가 독립이면 \(A\)와 \(B^c\)도 독립임을 보이세요.
    답

    \(P(A \cap B^c) = P(A) - P(A \cap B) = P(A) - P(A)P(B) = P(A)P(B^c)\).
