\(X\)의 분포를 알 때 \(Y = 1.8X + 32\)나 \(Y = \pi X^2\)의 분포를 알고 싶은 일이 많습니다. 컴퓨터가 균일 난수로 다른 분포의 난수를 만드는 원리도 변환입니다.

2.2.1누적분포함수 방법

가장 일반적인 방법은 \(F_Y(y) = P(g(X) \le y)\)를 \(X\)에 대한 사건으로 바꿔 계산한 뒤 미분하는 것입니다.

예제 2.2.1

\(X \sim N(0, 1)\)일 때 \(Y = X^2\)의 밀도함수를 구하세요.

풀이. \(y > 0\)에서 \(F_Y(y) = P(-\sqrt y \le X \le \sqrt y) = \Phi(\sqrt y) - \Phi(-\sqrt y)\). 미분하면 \(f_Y(y) = \phi(\sqrt y)\frac{1}{2\sqrt y} + \phi(-\sqrt y)\frac1{2\sqrt y} = \frac{1}{\sqrt{2\pi y}}e^{-y/2}\). 이것이 자유도 1인 카이제곱 분포입니다(6.1절). \(X^2\)는 단조가 아니므로 양쪽 가지를 모두 더했습니다.

2.2.2단조 변환 공식

정리 2.2.2

\(X\)의 밀도가 \(f_X\)이고 \(g\)가 \(X\)가 가질 수 있는 값의 구간에서 미분가능하고 엄격히 단조이면, \(Y = g(X)\)의 밀도는

\[f_Y(y) = f_X\big(g^{-1}(y)\big)\left|\frac{d}{dy}g^{-1}(y)\right|.\]

\(g\)가 증가하면 \(F_Y(y) = P(X \le g^{-1}(y)) = F_X(g^{-1}(y))\)이고, 연쇄법칙으로 미분하면 \(f_X(g^{-1}(y))\frac{d}{dy}g^{-1}(y)\)입니다. \(g\)가 감소하면 \(F_Y(y) = P(X \ge g^{-1}(y)) = 1 - F_X(g^{-1}(y))\)이고 미분하면 부호가 바뀌는데, 이때 \(\frac{d}{dy}g^{-1} < 0\)이라 절댓값으로 합쳐 쓸 수 있습니다. ∎

절댓값 인자는 변환이 구간을 늘이거나 줄이는 비율입니다. 넓이(확률)는 그대로이므로 구간이 늘어난 만큼 밀도가 낮아집니다.

예제 2.2.3 (역변환법)

\(U \sim U(0, 1)\)일 때 \(Y = -\frac1\lambda\ln U\)의 분포는?

풀이. \(g(u) = -\ln u/\lambda\)는 감소, \(g^{-1}(y) = e^{-\lambda y}\), \(|dg^{-1}/dy| = \lambda e^{-\lambda y}\). \(f_U = 1\)이므로 \(f_Y(y) = \lambda e^{-\lambda y}\) (\(y > 0\)), 지수분포입니다. 일반적으로 \(F^{-1}(U)\)는 분포함수 \(F\)를 따르며, 이 방법으로 난수를 만듭니다(응통15 04단원).

요약
  1. 일반적인 방법: \(F_Y(y) = P(g(X) \le y)\)를 구해 미분.
  2. 단조 변환: \(f_Y(y) = f_X(g^{-1}(y))|dg^{-1}/dy|\).
  3. \(F^{-1}(U)\)는 분포 \(F\)를 따릅니다(역변환법).

2.2.3연습문제

기본

  1. \(X \sim N(\mu, \sigma^2)\)이면 \(Y = aX + b\) (\(a \ne 0\))의 분포는?
    답

    정리 2.2.2로 \(N(a\mu + b, a^2\sigma^2)\).

응용

  1. \(X \sim U(0, 1)\)일 때 \(Y = \sqrt X\)의 밀도는?
    답

    \(g^{-1}(y) = y^2\), \(f_Y(y) = 2y\) (\(0 \le y \le 1\)).

2.2.2

실습균일 난수 하나로 어떤 분포든 만들 수 있을까?

실습 · 확률변수의 변환

다루는 성취기준 [응통6-02-02]

목표

\(X \sim U(0, 1)\)에 함수 \(Y = g(X)\)를 적용해 만든 난수의 히스토그램을, 변환 공식으로 구한 밀도 \(f_Y(y) = f_X(g^{-1}(y))\,|dg^{-1}/dy|\)와 비교합니다. 역변환법으로 지수분포와 코시 분포를 만들 수 있음을 확인합니다. 성취기준 [응통6-02-02].

분포함수 방법: \(F_Y(y) = P(g(X) \le y)\)를 \(X\)의 확률로 바꾸어 계산한 뒤 미분합니다.

역변환법: \(F\)가 연속이고 증가하면 \(F^{-1}(U)\)는 분포함수 \(F\)를 따릅니다.

준비

막대는 컴퓨터가 만든 균일 난수(가상 자료)를 변환한 값의 히스토그램, 빨간 곡선은 이론 밀도입니다. 그림 범위 밖의 값은 막대에서 빠집니다. "새 난수"를 누르면 다른 난수로 다시 만듭니다.

절차

  1. \(Y = -\ln X\)에서 히스토그램과 지수분포 밀도 \(e^{-y}\)를 비교하고, 표본 평균을 이론 1과 비교합니다.
  2. \(Y = X^2\)으로 바꾸어 \(y = 0\) 근처 막대가 왜 높은지 생각합니다. 밀도 \(1/(2\sqrt y)\)를 분포함수 방법으로 유도해 봅니다.
  3. \(Y = \sqrt X\)에서 밀도가 \(2y\)인 까닭을 같은 방법으로 확인합니다.
  4. 코시 변환에서 "새 난수"를 여러 번 눌러 표본 평균과 표본 중앙값이 각각 얼마나 흔들리는지 적습니다. 난수 개수를 20000으로 늘려도 평균이 안정되나요?

기대 결과

  • 세 변환(\(-\ln X\), \(X^2\), \(\sqrt X\))에서 히스토그램이 빨간 곡선을 잘 따르고, 표본 평균이 이론값 1, 1/3, 2/3에 가깝습니다(2000개면 대략 ±0.02~0.03 안).
  • \(X^2\)은 0 근처 값을 더 0 쪽으로 몰아서 \(y \to 0\)에서 밀도가 무한히 커지지만, 넓이는 1입니다.
  • 코시 분포는 평균이 존재하지 않아, 표본 평균이 새 난수마다 크게 튀고(가끔 ±5 이상) 난수를 늘려도 안정되지 않습니다. 반면 표본 중앙값은 0 근처에 머뭅니다(응통6 단원 연습의 대수의 법칙 문제).
  • 그림 범위(−8~8) 안의 코시 값은 약 92%로, 나머지 8%는 아주 멀리 떨어진 값입니다. 이론값 \(P(|Y| < 8) = \frac2\pi\arctan 8 \approx 0.921\)입니다.

분석

  1. \(Y = -\ln X\)가 지수분포가 되는 것을 \(P(Y > y) = P(X < e^{-y})\)로 보여 보세요.
  2. 정규분포는 분포함수의 역함수를 닫힌 꼴로 쓸 수 없습니다. 그래도 정규 난수를 만드는 방법을 하나 들어 보세요(박스-뮬러, 응통15-04-02).
  3. 변환이 일대일이 아니면(예: \(Y = (X - 1/2)^2\)) 변환 공식을 어떻게 고쳐야 하나요?
