6.2정규 표본의 표본평균과 표본분산은 독립이다

[응통6-06-02] 정규 표본에서 표본평균과 표본분산의 독립성을 설명할 수 있다. 개념 연세대

이 절에서 배울 것
  • 정규 표본에서 \(\bar X\)와 \(S^2\)이 독립인 이유를 설명한다.
  • 이 성질이 정규분포에만 있음을 예로 확인한다.
먼저 알아야 할 것
  • 다변량 정규분포 (5.3절), 카이제곱 분포 (6.1절).

같은 자료로 만든 두 통계량이 독립이라니

\(\bar X\)와 \(S^2\)은 똑같은 \(X_1, \ldots, X_n\)으로 계산합니다. 그런데도 정규 표본이면 \(\bar X\)를 알아도 \(S^2\)에 대한 정보가 전혀 없습니다. 이 놀라운 성질 덕분에 t 분포가 깔끔하게 나옵니다.

6.2.1공분산이 0인 이유

\(\bar X\)와 각 편차 \(X_i - \bar X\)의 공분산을 구해 봅시다.

\[\mathrm{Cov}(\bar X, X_i - \bar X) = \mathrm{Cov}(\bar X, X_i) - \mathrm{Var}(\bar X) = \frac{\sigma^2}{n} - \frac{\sigma^2}n = 0.\]

\(\mathrm{Cov}(\bar X, X_i) = \frac1n\mathrm{Var}(X_i)\)인 까닭은 \(\bar X\)의 다른 항이 \(X_i\)와 독립이기 때문입니다. 이 계산은 어떤 분포에서도 성립합니다.

6.2.2정규성이 하는 일

\(X_i\)가 독립 정규이면 \((\bar X, X_1 - \bar X, \ldots, X_n - \bar X)\)는 모두 \(X_i\)들의 일차식이라 함께 다변량 정규분포를 따릅니다. 다변량 정규에서는 공분산 0이 독립을 뜻하므로(5.3절 정리 (다)) \(\bar X\)는 편차 벡터 전체와 독립이고, 편차들의 함수인 \(S^2 = \frac{1}{n-1}\sum(X_i - \bar X)^2\)과도 독립입니다.

정리 6.2.1

정규 표본에서 \(\bar X\)와 \(S^2\)은 독립이다. 거꾸로 \(\bar X\)와 \(S^2\)이 독립인 분포는 정규분포뿐이다(가이리(Geary)의 정리, 증명 생략).

예제 6.2.2

지수분포 표본에서는 \(\bar X\)와 \(S^2\)이 독립이 아님을 직관적으로 설명하세요.

풀이. 지수분포는 오른쪽 꼬리가 깁니다. 표본에 큰 값이 하나 섞이면 \(\bar X\)도 커지고 \(S^2\)도 커집니다. 그래서 \(\bar X\)가 크면 \(S^2\)도 큰 경향이 있습니다(실제로 지수분포에서 \(\mathrm{Var}(X) = \mu^2\)라 평균과 분산이 함께 움직입니다). R로 x <- matrix(rexp(5000*10), ncol = 10); cor(rowMeans(x), apply(x, 1, var))를 하면 약 0.7이 나옵니다(난수에 따라 소수 둘째 자리가 조금 달라집니다).

6.2.3\((n-1)S^2/\sigma^2\)이 \(\chi^2_{n-1}\)인 이유

항등식 \(\sum(X_i - \mu)^2 = \sum(X_i - \bar X)^2 + n(\bar X - \mu)^2\)을 \(\sigma^2\)로 나누면 왼쪽은 \(\chi^2_n\), 오른쪽 둘째 항은 \(\chi^2_1\)입니다. 두 항이 독립이므로 적률생성함수가 \((1-2t)^{-n/2} = M(t)(1-2t)^{-1/2}\)이고, 첫째 항의 적률생성함수 \(M(t) = (1-2t)^{-(n-1)/2}\)입니다. 자유도가 하나 줄어든 것은 편차들이 \(\sum(X_i - \bar X) = 0\)이라는 제약을 하나 가지기 때문입니다.

요약
  1. \(\bar X\)와 편차의 공분산은 항상 0.
  2. 정규이면 공분산 0이 독립이 되어 \(\bar X \perp S^2\).
  3. \((n-1)S^2/\sigma^2 \sim \chi^2_{n-1}\), 자유도 1은 \(\bar X\) 추정에 쓰입니다.

6.2.4연습문제

응용

  1. \(\sum(X_i - \mu)^2 = \sum(X_i - \bar X)^2 + n(\bar X - \mu)^2\)을 증명하세요.
    답

    \(X_i - \mu = (X_i - \bar X) + (\bar X - \mu)\)를 제곱해 더하면 교차항이 \(2(\bar X - \mu)\sum(X_i - \bar X) = 0\).
