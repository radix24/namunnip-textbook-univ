5.2.1공분산과 상관계수

정의 5.2.1

\(\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E(XY) - \mu_X\mu_Y\). \(\rho = \mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)\).

정리 5.2.2

(가) \(\mathrm{Var}(aX + bY) = a^2\mathrm{Var}X + b^2\mathrm{Var}Y + 2ab\,\mathrm{Cov}(X,Y)\). (나) 독립이면 \(E(XY) = E(X)E(Y)\), 따라서 \(\mathrm{Cov} = 0\). (다) \(|\rho| \le 1\).

(다)는 \(\mathrm{Var}(X/\sigma_X \pm Y/\sigma_Y) = 2(1 \pm \rho) \ge 0\)에서 나옵니다. (나)의 역은 거짓입니다. \(X \sim N(0,1)\), \(Y = X^2\)이면 \(\mathrm{Cov} = E(X^3) = 0\)이지만 \(Y\)는 \(X\)로 완전히 정해집니다.

5.2.2조건부 기대값

정의 5.2.3

\(E(Y \mid X = x) = \int y f(y \mid x)\,dy\). 이것을 \(x\)의 함수로 보아 \(x\) 자리에 \(X\)를 넣은 확률변수를 \(E(Y \mid X)\)라 씁니다.

정리 5.2.4

(가) 반복 기대값: \(E[E(Y \mid X)] = E(Y)\). (나) 분산 분해: \(\mathrm{Var}(Y) = E[\mathrm{Var}(Y \mid X)] + \mathrm{Var}[E(Y \mid X)]\).

(가) \(E[E(Y\mid X)] = \int\left(\int y f(y\mid x)dy\right)f_X(x)dx = \iint y f(x,y)\,dy\,dx = E(Y)\). (나) \(\mathrm{Var}(Y \mid X) = E(Y^2 \mid X) - [E(Y\mid X)]^2\)의 기대값에 (가)를 쓰면 \(E[\mathrm{Var}(Y\mid X)] = E(Y^2) - E\{[E(Y\mid X)]^2\}\). 한편 \(\mathrm{Var}[E(Y \mid X)] = E\{[E(Y\mid X)]^2\} - [E(Y)]^2\). 둘을 더하면 \(\mathrm{Var}(Y)\). ∎

분산 분해는 "전체 변동 = 집단 안 변동의 평균 + 집단 평균들의 변동"으로, 분산분석(응통5 5.1절)과 같은 구조입니다.

예제 5.2.5

5.1절 예제(\(0 < x < y < 1\)에서 균일)의 \(E(Y \mid X)\)와 \(E(Y)\)는?

풀이. \(Y \mid X = x\)는 \(U(x, 1)\)이므로 \(E(Y\mid X) = (1 + X)/2\). \(E(X) = \int_0^1 2x(1-x)dx = 1/3\)이므로 \(E(Y) = (1 + 1/3)/2 = 2/3\). 직접 \(\int 2y\cdot y\,dy = 2/3\)과 같습니다.

요약
  1. 합의 분산에는 \(2\mathrm{Cov}\) 항이 붙습니다. 독립이면 공분산 0, 역은 거짓.
  2. \(E[E(Y\mid X)] = E(Y)\).
  3. \(\mathrm{Var}Y = E[\mathrm{Var}(Y\mid X)] + \mathrm{Var}[E(Y\mid X)]\).

5.2.3연습문제

기본

  1. \(\mathrm{Var}X = 4\), \(\mathrm{Var}Y = 9\), \(\rho = 0.5\)이면 \(\mathrm{Var}(X - Y)\)는?
    답

    \(\mathrm{Cov} = 0.5 \times 2 \times 3 = 3\). \(4 + 9 - 6 = 7\).

응용

  1. 하루 손님 수 \(N \sim\) 포아송(10), 손님마다 독립으로 평균 2만 원, 분산 1을 씁니다. 하루 매출의 평균과 분산은?
    답

    \(E(S\mid N) = 2N\), \(\mathrm{Var}(S\mid N) = N\). 평균 20. 분산 \(E(N) + \mathrm{Var}(2N) = 10 + 40 = 50\).
