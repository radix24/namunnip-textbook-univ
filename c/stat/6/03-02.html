모든 적률을 한 함수에

\(E(X), E(X^2), E(X^3), \ldots\)를 하나씩 적분하는 대신 이것들을 모두 담은 함수 하나를 만들 수 있습니다. 게다가 이 함수는 분포를 결정하고, 독립인 변수의 합을 곱으로 바꿔 줍니다.

3.2.1정의와 적률

정의 3.2.1

적률생성함수: \(M_X(t) = E(e^{tX})\). 0을 포함하는 어떤 열린 구간 \(|t| < h\)에서 유한할 때 정의합니다.

\(e^{tX} = 1 + tX + \frac{t^2X^2}{2!} + \cdots\)의 기대값을 항별로 구하면 \(M(t) = \sum_k E(X^k)\frac{t^k}{k!}\). 그래서

\[M^{(k)}(0) = E(X^k).\]

3.2.2두 가지 핵심 성질

정리 3.2.2

(가) 유일성: 두 확률변수의 적률생성함수가 0 근처에서 같으면 분포가 같다. (나) \(X, Y\)가 독립이면 \(M_{X+Y}(t) = M_X(t)M_Y(t)\).

(가)의 증명은 이 과목 범위를 넘습니다(라플라스 변환의 유일성). (나)는 \(E(e^{t(X+Y)}) = E(e^{tX}e^{tY}) = E(e^{tX})E(e^{tY})\)로, 독립이면 곱의 기대값이 기대값의 곱이기 때문입니다(5.2절).

예제 3.2.3

\(X \sim N(\mu, \sigma^2)\)의 적률생성함수를 구하고, 독립인 \(X_1 \sim N(\mu_1, \sigma_1^2)\), \(X_2 \sim N(\mu_2, \sigma_2^2)\)의 합의 분포를 구하세요.

풀이. 표준정규 \(Z\): \(E(e^{tZ}) = \int \frac1{\sqrt{2\pi}}e^{tz - z^2/2}dz\). 지수를 완전제곱하면 \(tz - z^2/2 = -\frac12(z - t)^2 + \frac{t^2}2\)이고 남은 적분은 \(N(t, 1)\) 밀도의 적분 1이므로 \(M_Z(t) = e^{t^2/2}\). \(X = \mu + \sigma Z\)이면 \(M_X(t) = e^{\mu t}M_Z(\sigma t) = e^{\mu t + \sigma^2t^2/2}\).

합: \(M(t) = e^{\mu_1 t + \sigma_1^2t^2/2}e^{\mu_2 t + \sigma_2^2t^2/2} = e^{(\mu_1 + \mu_2)t + (\sigma_1^2 + \sigma_2^2)t^2/2}\). 유일성에서 \(X_1 + X_2 \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)\).

예제 3.2.4

포아송 분포 \(p(x) = e^{-\lambda}\lambda^x/x!\)의 적률생성함수와 평균, 분산은?

풀이. \(M(t) = \sum e^{-\lambda}\frac{(\lambda e^t)^x}{x!} = e^{\lambda(e^t - 1)}\). \(M'(t) = \lambda e^tM(t)\), \(M'(0) = \lambda\). \(M''(t) = (\lambda e^t + \lambda^2e^{2t})M(t)\), \(M''(0) = \lambda + \lambda^2\). 분산 \(\lambda\).

요약
  1. \(M(t) = E(e^{tX})\), \(M^{(k)}(0) = E(X^k)\).
  2. 적률생성함수가 같으면 분포가 같습니다.
  3. 독립인 합의 적률생성함수는 곱입니다.

3.2.3연습문제

기본

  1. 독립인 포아송 \(\lambda_1\), \(\lambda_2\) 변수의 합의 분포는?
    답

    \(e^{(\lambda_1 + \lambda_2)(e^t - 1)}\)이므로 포아송 \(\lambda_1 + \lambda_2\).

응용

  1. 지수분포 \(\lambda\)의 적률생성함수를 구하고 정의되는 \(t\)의 범위를 적으세요.
    답

    \(\int_0^\infty \lambda e^{-(\lambda - t)x}dx = \frac{\lambda}{\lambda - t}\), \(t < \lambda\).
