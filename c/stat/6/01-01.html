왜 공리부터 시작하나

고교에서는 확률을 "경우의 수 / 전체 경우의 수"로 배웠습니다. 이 정의는 모든 결과가 똑같이 가능할 때만 쓸 수 있고, 다트가 원판의 어느 점에 꽂히는지처럼 결과가 무한히 많으면 쓸 수 없습니다. 콜모고로프(Kolmogorov)는 확률이 지켜야 할 최소한의 규칙 세 가지만 정하고 나머지를 모두 증명으로 끌어냈습니다.

1.1.1표본공간과 사건

정의 1.1.1

표본공간 \(\Omega\): 실험에서 나올 수 있는 모든 결과의 집합. 사건: \(\Omega\)의 부분집합. 사건들은 여사건과 셀 수 있는 합집합에 대해 닫혀 있다고 둡니다.

주사위 하나면 \(\Omega = \{1, \ldots, 6\}\), "짝수"는 사건 \(\{2, 4, 6\}\)입니다. 첫 앞면이 나올 때까지 동전을 던지는 실험이면 \(\Omega = \{1, 2, 3, \ldots\}\)로 무한집합입니다.

1.1.2세 공리

정의 1.1.2 (확률의 공리)

사건 \(A\)마다 수 \(P(A)\)를 대응시키는 함수가 다음을 만족하면 확률이라 한다.

  1. \(P(A) \ge 0\).
  2. \(P(\Omega) = 1\).
  3. 서로 배반인(겹치지 않는) 사건 \(A_1, A_2, \ldots\)에 대해 \(P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)\).

셋째 공리가 유한 개가 아니라 셀 수 있는 무한 개에 대한 것이라는 점이 중요합니다. 무한 수열의 극한을 다루려면 이 조건이 필요합니다.

1.1.3공리에서 나오는 성질

정리 1.1.3

(가) \(P(\emptyset) = 0\). (나) \(P(A^c) = 1 - P(A)\). (다) \(A \subset B\)이면 \(P(A) \le P(B)\). (라) \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).

(가) \(A_1 = \Omega\), \(A_2 = A_3 = \cdots = \emptyset\)는 서로 배반이고 합집합은 \(\Omega\)입니다. 공리 3에서 \(1 = 1 + \sum_{i \ge 2}P(\emptyset)\)이고, 공리 1로 각 항이 0 이상이므로 \(P(\emptyset) = 0\)입니다. 이제 (가)와 공리 3에서 유한 개의 배반 사건에도 합 공식이 성립합니다(나머지를 \(\emptyset\)으로 채움). (나) \(A\)와 \(A^c\)는 배반이고 합집합이 \(\Omega\)이므로 \(P(A) + P(A^c) = P(\Omega) = 1\). (다) \(B = A \cup (B \cap A^c)\)이고 두 사건은 배반이므로 \(P(B) = P(A) + P(B \cap A^c) \ge P(A)\) (공리 1). (라) \(A \cup B = A \cup (B \cap A^c)\), \(B = (A \cap B) \cup (B \cap A^c)\)로 각각 배반 분해하면 \(P(A \cup B) = P(A) + P(B \cap A^c)\), \(P(B) = P(A\cap B) + P(B \cap A^c)\). 둘째 식에서 \(P(B \cap A^c)\)를 구해 첫째 식에 넣습니다. ∎

예제 1.1.4

\(P(A) = 0.6\), \(P(B) = 0.5\)일 때 \(P(A \cap B)\)가 가질 수 있는 범위는?

풀이. (라)에서 \(P(A\cap B) = 1.1 - P(A \cup B)\)이고 \(P(A \cup B) \le 1\)이므로 \(P(A \cap B) \ge 0.1\). 또 \(A \cap B \subset B\)이므로 (다)에서 \(P(A \cap B) \le 0.5\). 범위는 \([0.1, 0.5]\)입니다.

요약
  1. 확률은 세 공리(음이 아님, 전체 1, 셀 수 있는 가법성)를 만족하는 함수입니다.
  2. 여사건, 단조성, 합의 공식은 모두 공리에서 증명됩니다.

1.1.4연습문제

기본

  1. \(P(A \cup B) \le P(A) + P(B)\)를 증명하세요.
    답

    정리 1.1.3(라)에서 \(P(A \cap B) \ge 0\)이므로.

심화

  1. 사건 \(A_1 \subset A_2 \subset \cdots\)이면 \(P(\bigcup A_n) = \lim P(A_n)\)임을 보이세요(확률의 연속성).
    답

    \(B_1 = A_1\), \(B_n = A_n \cap A_{n-1}^c\)는 서로 배반이고 \(\bigcup B_n = \bigcup A_n\), \(\bigcup_{k \le n}B_k = A_n\). 공리 3에서 \(P(\bigcup A_n) = \sum P(B_k) = \lim_n \sum_{k \le n}P(B_k) = \lim P(A_n)\).
