두 변수를 함께 보기

키와 몸무게, 공부 시간과 점수처럼 두 양을 함께 다루려면 \(P(X \le x, Y \le y)\) 같은 결합 확률이 필요합니다.

5.1.1결합 분포와 주변 분포

정의 5.1.1

결합 밀도 \(f(x, y) \ge 0\): 평면의 영역 \(A\)에 대해 \(P((X, Y) \in A) = \iint_A f(x,y)\,dx\,dy\). 주변 밀도: \(f_X(x) = \int f(x, y)\,dy\), \(f_Y(y) = \int f(x,y)\,dx\). 이산형은 적분 대신 합.

주변 밀도는 다른 변수를 "적분해 없앤" 것입니다. 분할표에서 행 합, 열 합을 구하는 것과 같습니다.

5.1.2조건부 분포와 독립

정의 5.1.2

\(f_X(x) > 0\)일 때 \(X = x\)가 주어진 \(Y\)의 조건부 밀도: \(f(y \mid x) = \dfrac{f(x, y)}{f_X(x)}\).

\(P(X = x) = 0\)인데도 이렇게 정의할 수 있는 이유는, 조건 \(x \le X \le x + h\)로 계산한 조건부확률에서 \(h \to 0\)으로 보낸 극한이 이 식이기 때문입니다.

정리 5.1.3

\(X\)와 \(Y\)가 독립 \(\iff\) 모든 \(x, y\)에서 \(f(x, y) = f_X(x)f_Y(y)\) \(\iff\) \(f(x,y) = g(x)h(y)\)로 인수분해되고 값을 가지는 영역이 직사각형.

예제 5.1.4

\(f(x, y) = 2\) (\(0 < x < y < 1\)). 주변 밀도, \(f(y \mid x)\), 독립 여부를 구하세요.

풀이. \(f_X(x) = \int_x^1 2\,dy = 2(1 - x)\), \(f_Y(y) = \int_0^y 2\,dx = 2y\). \(f(y \mid x) = \frac{2}{2(1-x)} = \frac{1}{1-x}\) (\(x < y < 1\)), 곧 \(X = x\)이면 \(Y\)는 \((x, 1)\)의 균일분포입니다. \(f_Xf_Y = 4y(1-x) \ne 2\)이므로 독립이 아닙니다. 밀도가 상수인데도 영역이 삼각형이라 종속입니다.

요약
  1. 주변 밀도는 다른 변수에 대해 적분.
  2. 조건부 밀도 = 결합 / 주변.
  3. 독립은 결합 밀도 = 주변 밀도의 곱. 영역 모양도 확인합니다.

5.1.3연습문제

기본

  1. 예제에서 \(P(Y > 2X)\)는?
    답

    \(\int_0^{1/2}\int_{2x}^1 2\,dy\,dx = \int_0^{1/2}2(1 - 2x)dx = 1/2\).

응용

  1. \(f(x, y) = e^{-x-y}\) (\(x, y > 0\))이면 \(X, Y\)는 독립인가요? \(P(X < Y)\)는?
    답

    \(e^{-x}e^{-y}\)이고 영역이 사분면이라 독립. 대칭이므로 \(P(X < Y) = 1/2\).
