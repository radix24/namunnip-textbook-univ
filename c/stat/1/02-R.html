2.R.1

연습미분과 응용 단원 마무리 연습

문제 6 · 계산·적용·판단 · 힌트 2단계

다루는 성취기준 [응통1-02-01] [응통1-02-02] [응통1-02-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산다음을 미분하세요. (1) \(f(x) = x e^{-2x}\) (2) \(g(x) = \ln(x^2 + 1)\) (3) \(h(x) = 2^x\) [02-01]

    힌트 1

    (1)은 곱의 미분과 연쇄법칙, (2)는 \((\ln u)' = u'/u\)를 씁니다.

    힌트 2

    (3)은 \(2^x = e^{x\ln2}\)로 바꾸어 보세요.

    풀이

    (1) \(f'(x) = e^{-2x} + x\cdot(-2)e^{-2x} = e^{-2x}(1 - 2x)\).

    (2) \(g'(x) = \dfrac{2x}{x^2+1}\).

    (3) \(h(x) = e^{x\ln2}\)이므로 \(h'(x) = \ln2\cdot e^{x\ln2} = 2^x\ln2\).

  2. 계산\(x > 0\)에서 \(f(x) = x e^{-x}\)의 최댓값을 구하세요. 일계 조건과 이계 조건을 모두 확인하세요. [02-02]

    힌트 1

    \(f'(x) = e^{-x}(1 - x)\)입니다.

    힌트 2

    이계도함수 \(f''(x) = e^{-x}(x - 2)\)를 임계점에 넣어 부호를 보세요.

    풀이

    \(f'(x) = e^{-x}(1 - x) = 0\)에서 \(x = 1\)입니다. \(f''(1) = e^{-1}(1 - 2) = -1/e < 0\)이므로 극대입니다. 또 \(0 < x < 1\)에서 \(f' > 0\), \(x > 1\)에서 \(f' < 0\)이라 이 극대가 \(x > 0\) 전체의 최댓값입니다. 최댓값은 \(f(1) = 1/e \approx 0.368\)입니다.

  3. 적용베르누이 시행 \(n\)번에서 성공이 \(k\)번(\(0 < k < n\)) 나왔습니다. 가능도 \(L(p) = p^k(1-p)^{n-k}\)을 최대로 하는 \(p\)를 로그가능도로 구하세요. [02-02]

    힌트 1

    곱보다 합이 미분하기 쉬우므로 \(\ell(p) = \ln L(p) = k\ln p + (n-k)\ln(1-p)\)를 씁니다. 로그는 증가함수라 최대점이 같습니다.

    힌트 2

    \(\ell'(p) = \dfrac{k}{p} - \dfrac{n-k}{1-p} = 0\)을 풉니다.

    풀이

    \(\ell'(p) = \dfrac{k}{p} - \dfrac{n-k}{1-p} = 0\)에서 \(k(1-p) = (n-k)p\), 곧 \(\hat p = k/n\)입니다.

    \(\ell''(p) = -\dfrac{k}{p^2} - \dfrac{n-k}{(1-p)^2} < 0\)이므로 최대입니다. 최대가능도 추정값은 표본 성공 비율이라는, 직관과 맞는 결과입니다.

  4. 적용포아송 분포 \(P(X = x) = e^{-\lambda}\lambda^x/x!\)에서 관측값 2, 0, 3, 1, 4를 얻었습니다. \(\lambda\)의 최대가능도 추정값을 구하세요. [02-02]

    힌트 1

    로그가능도는 \(\ell(\lambda) = \big(\sum x_i\big)\ln\lambda - n\lambda - \sum\ln x_i!\)입니다.

    힌트 2

    마지막 항은 \(\lambda\)와 무관하므로 미분하면 사라집니다.

    풀이

    \(\ell'(\lambda) = \dfrac{\sum x_i}{\lambda} - n = 0\)에서 \(\hat\lambda = \bar x = (2+0+3+1+4)/5 = 2\)입니다. \(\ell''(\lambda) = -\sum x_i/\lambda^2 < 0\)이므로 최대입니다.

  5. 계산\(e^x\)를 \(x = 0\)에서 2차 테일러 다항식으로 근사해 \(e^{0.1}\)의 근삿값을 구하고, 라그랑주 나머지로 오차의 상한을 구하세요. [02-03]

    힌트 1

    2차 테일러 다항식은 \(1 + x + x^2/2\)입니다.

    힌트 2

    나머지는 \(R_2 = \dfrac{e^{c}}{3!}x^3\) (\(0 < c < x\))이고, \(e^c < e^{0.1} < 1.2\)로 어림할 수 있습니다.

    풀이

    근삿값은 \(1 + 0.1 + 0.005 = 1.105\)입니다. 오차는 \(|R_2| = \dfrac{e^c}{6}(0.1)^3 < \dfrac{1.2}{6}\times0.001 = 0.0002\)입니다.

    실제 값 \(e^{0.1} = 1.10517\cdots\)과의 차는 약 0.00017로, 상한 0.0002 안에 있습니다.

  6. 판단경제 자료에서 "로그 차이는 변화율과 거의 같다"고 하여 \(\ln(1+x) \approx x\)를 씁니다. \(x = 0.05\)와 \(x = 0.5\)에서 이 근사를 평가하고, 언제 써도 되는지 판단하세요. [02-03]

    힌트 1

    \(\ln(1+x)\)의 테일러 전개는 \(x - x^2/2 + x^3/3 - \cdots\)입니다.

    힌트 2

    오차는 대략 \(x^2/2\)입니다.

    풀이

    \(\ln1.05 \approx 0.0488\)로 0.05와 거의 같지만(오차 약 \(0.05^2/2 = 0.00125\)), \(\ln1.5 \approx 0.405\)는 0.5와 크게 다릅니다(오차 약 0.095).

    오차가 \(x^2/2\) 정도이므로 변화율이 몇 % 이내로 작을 때만 이 근사를 씁니다. 50% 같은 큰 변화에는 로그 차이를 그대로 변화율로 읽으면 안 됩니다.
