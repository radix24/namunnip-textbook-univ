자료를 가장 잘 설명하는 모수

동전을 10번 던져 앞면이 7번 나왔다면 앞면 확률 \(p\)는 얼마로 추정해야 할까요? "이 결과가 나올 확률을 가장 크게 만드는 \(p\)"를 고르는 것이 최대가능도 추정이고, 계산은 미분으로 하는 최적화입니다.

2.2.1극값 판정

정리 2.2.1

미분가능한 \(f\)가 내부의 점 \(c\)에서 극값을 가지면 \(f'(c) = 0\)(일계 조건). \(f'(c) = 0\)이고 \(f''(c) < 0\)이면 극대, \(f''(c) > 0\)이면 극소(이계 조건).

구간의 최댓값은 극값 후보와 끝점을 모두 비교해 찾습니다. \(f''\)이 구간 전체에서 음수(오목)이면 \(f' = 0\)인 점이 유일한 최댓값입니다. 많은 로그가능도가 오목이라 이 성질이 유용합니다.

2.2.2최대가능도

베르누이 시행 \(n\)번에서 성공 \(k\)번이면 가능도 \(L(p) = p^k(1-p)^{n-k}\)입니다. 로그는 증가함수라 \(\log L\)을 최대화해도 같은 \(p\)를 얻고, 곱이 합으로 바뀌어 미분이 쉽습니다.

예제 2.2.2

\(\ell(p) = k\log p + (n-k)\log(1-p)\)를 최대화하세요.

풀이. \(\ell'(p) = \frac kp - \frac{n-k}{1-p} = 0\)에서 \(k(1-p) = (n-k)p\), \(\hat p = k/n\). \(\ell''(p) = -\frac{k}{p^2} - \frac{n-k}{(1-p)^2} < 0\)이므로 최대. 10번 중 7번이면 \(\hat p = 0.7\)입니다. 직관과 같은 답이 원리에서 나왔습니다.

예제 2.2.3

대기 시간 자료 \(x_1, \ldots, x_n\)이 지수분포 \(f(x) = \lambda e^{-\lambda x}\)를 따를 때 \(\lambda\)의 최대가능도 추정값은?

풀이. \(\ell(\lambda) = n\log\lambda - \lambda\sum x_i\). \(\ell' = n/\lambda - \sum x_i = 0\)에서 \(\hat\lambda = 1/\bar x\). 평균 대기 시간이 5분이면 \(\hat\lambda = 0.2\)/분.

요약
  1. 극값: \(f' = 0\), \(f''\)의 부호로 판정, 끝점 확인.
  2. 로그가능도를 최대화하는 값이 최대가능도 추정값.
  3. 자세한 이론은 응통7 1.1절.

2.2.3연습문제

기본

  1. 포아송 자료(\(f(x) = e^{-\lambda}\lambda^x/x!\))의 \(\lambda\) 최대가능도 추정값은?
    답

    \(\ell = -n\lambda + \sum x_i\log\lambda + c\), \(\hat\lambda = \bar x\).
