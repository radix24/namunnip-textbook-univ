4.R.1

연습수열과 급수 단원 마무리 연습

문제 6 · 계산·판단·도전 · 힌트 2단계

다루는 성취기준 [응통1-04-01] [응통1-04-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산급수 \(\displaystyle\sum_{n=1}^\infty\frac{1}{n^2+1}\)의 수렴 여부를 비교 판정법으로 판정하세요. [04-01]

    힌트 1

    \(\frac{1}{n^2+1}\)과 크기를 비교하기 좋은, 수렴이 알려진 급수는 무엇일까요?

    힌트 2

    \(\sum 1/n^2\)은 \(p = 2 > 1\)인 \(p\)급수라 수렴합니다.

    풀이

    모든 \(n\)에서 \(0 < \dfrac{1}{n^2+1} < \dfrac{1}{n^2}\)이고 \(\sum 1/n^2\)이 수렴하므로, 비교 판정법에 따라 주어진 급수도 수렴합니다.

  2. 계산급수 \(\displaystyle\sum_{n=1}^\infty\frac{n}{2^n}\)의 수렴 여부를 비 판정법으로 판정하세요. [04-01]

    힌트 1

    비 판정법은 \(\lim |a_{n+1}/a_n|\)이 1보다 작은지 봅니다.

    힌트 2

    \(\dfrac{a_{n+1}}{a_n} = \dfrac{n+1}{2^{n+1}}\cdot\dfrac{2^n}{n} = \dfrac{n+1}{2n}\)입니다.

    풀이

    \(\dfrac{a_{n+1}}{a_n} = \dfrac{n+1}{2n} \to \dfrac12 < 1\)이므로 수렴합니다. (뒤의 문제에서 보듯 합은 2입니다.)

  3. 판단"항이 0으로 가므로 \(\sum 1/n\)은 수렴한다"는 주장을 평가하세요. [04-01]

    힌트 1

    \(a_n \to 0\)은 수렴의 필요조건인가요, 충분조건인가요?

    힌트 2

    \(\frac13 + \frac14 > \frac12\), \(\frac15 + \cdots + \frac18 > \frac12\)처럼 묶어 보세요.

    풀이

    틀렸습니다. \(a_n \to 0\)은 수렴의 필요조건일 뿐 충분조건이 아닙니다.

    조화급수는 항을 \(\frac12\), \((\frac13+\frac14)\), \((\frac15+\cdots+\frac18)\), …로 묶으면 각 묶음이 \(\frac12\)보다 크므로 부분합이 끝없이 커져 발산합니다. 실제로 부분합은 \(\ln n\) 정도로 아주 천천히 커집니다.

  4. 계산기하급수 공식으로 (1) \(\displaystyle\sum_{k=0}^\infty(2/3)^k\), (2) \(\displaystyle\sum_{k=2}^\infty(1/2)^k\)을 구하세요. [04-02]

    힌트 1

    \(|r| < 1\)이면 \(\sum_{k=0}^\infty r^k = 1/(1-r)\)입니다.

    힌트 2

    (2)는 첫 항이 \((1/2)^2\)인 기하급수입니다.

    풀이

    (1) \(1/(1 - 2/3) = 3\).

    (2) \(\dfrac{(1/2)^2}{1 - 1/2} = \dfrac{1/4}{1/2} = \dfrac12\). 또는 전체 합 2에서 \(k = 0, 1\) 항 \(1 + 1/2\)를 빼도 됩니다.

  5. 계산주사위를 6이 나올 때까지 던질 때 던진 횟수 \(X\)는 \(P(X = k) = (5/6)^{k-1}(1/6)\), \(k = 1, 2, \ldots\)입니다. \(\sum_{k=1}^\infty kx^{k-1} = 1/(1-x)^2\) (\(|x| < 1\))을 써서 \(E(X)\)를 구하세요. [04-02]

    힌트 1

    \(E(X) = \sum_k k(5/6)^{k-1}(1/6)\)입니다.

    힌트 2

    공식은 \(\sum x^k = 1/(1-x)\)를 항별 미분해 얻습니다.

    풀이

    \(E(X) = \frac16\sum_{k=1}^\infty k(5/6)^{k-1} = \frac16\cdot\frac{1}{(1 - 5/6)^2} = \frac16\cdot36 = 6\)입니다. 일반적으로 성공 확률이 \(p\)인 기하분포의 평균은 \(1/p\)입니다.

  6. 도전포아송 분포 \(P(X = k) = e^{-\lambda}\lambda^k/k!\)에서 \(e^\lambda = \sum_{k=0}^\infty\lambda^k/k!\)를 써서 \(E(X) = \lambda\), \(E[X(X-1)] = \lambda^2\)을 보이고 \(\mathrm{Var}(X)\)를 구하세요. [04-02]

    힌트 1

    \(E(X) = \sum_{k=1}^\infty k\,e^{-\lambda}\lambda^k/k! = e^{-\lambda}\lambda\sum_{k=1}^\infty\lambda^{k-1}/(k-1)!\)입니다.

    힌트 2

    \(\mathrm{Var}(X) = E[X(X-1)] + E(X) - [E(X)]^2\)입니다.

    풀이

    \(E(X) = e^{-\lambda}\lambda\sum_{j=0}^\infty\lambda^j/j! = e^{-\lambda}\lambda e^\lambda = \lambda\) (\(j = k-1\)).

    \(E[X(X-1)] = \sum_{k=2}^\infty k(k-1)e^{-\lambda}\lambda^k/k! = e^{-\lambda}\lambda^2\sum_{j=0}^\infty\lambda^j/j! = \lambda^2\) (\(j = k-2\)).

    따라서 \(\mathrm{Var}(X) = \lambda^2 + \lambda - \lambda^2 = \lambda\)입니다. 포아송 분포는 평균과 분산이 같습니다.
