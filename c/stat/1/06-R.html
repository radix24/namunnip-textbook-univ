6.R.1

연습중적분 단원 마무리 연습

문제 6 · 계산·증명 · 힌트 2단계

다루는 성취기준 [응통1-06-01] [응통1-06-02] [응통1-06-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 계산\(\displaystyle\iint_R (x + y)\,dA\), \(R = [0, 1]\times[0, 2]\)를 반복적분으로 구하세요. [06-01]

    힌트 1

    먼저 \(y\)에 대해 0부터 2까지 적분하고, 그 결과를 \(x\)에 대해 0부터 1까지 적분합니다.

    힌트 2

    \(\int_0^2(x + y)\,dy = 2x + 2\)입니다.

    풀이

    \(\displaystyle\int_0^1\!\int_0^2(x+y)\,dy\,dx = \int_0^1(2x + 2)\,dx = 1 + 2 = 3\)입니다. 직사각형 영역에서는 적분 순서를 바꾸어도 같은 값이 나옵니다(푸비니 정리).

  2. 계산영역 \(D = \{(x, y) : 0 \le y \le x \le 1\}\)에서 \(\displaystyle\iint_D xy\,dA\)를 구하세요. 적분 순서를 바꾸어 다시 계산해 같은 값이 나오는지 확인하세요. [06-01]

    힌트 1

    \(x\)를 먼저 고정하면 \(y\)는 0부터 \(x\)까지 움직입니다.

    힌트 2

    순서를 바꾸면 \(y\)를 고정했을 때 \(x\)는 \(y\)부터 1까지 움직입니다.

    풀이

    \(\displaystyle\int_0^1 x\int_0^x y\,dy\,dx = \int_0^1\frac{x^3}{2}dx = \frac18\).

    순서를 바꾸면 \(\displaystyle\int_0^1 y\int_y^1 x\,dx\,dy = \int_0^1 y\cdot\frac{1 - y^2}{2}dy = \frac12\Big(\frac12 - \frac14\Big) = \frac18\)로 같습니다. 영역을 그림으로 그려 경계를 읽는 것이 핵심입니다.

  3. 계산\(f(x, y) = c(x + y)\) (\(0 \le x, y \le 1\))가 결합 밀도함수가 되도록 \(c\)를 구하고, \(P(X + Y \le 1)\)을 구하세요. [06-01]

    힌트 1

    전체 적분 \(\int_0^1\int_0^1(x+y)\,dy\,dx = 1\)입니다.

    힌트 2

    \(X + Y \le 1\)은 \(0 \le y \le 1 - x\)인 삼각형입니다.

    풀이

    \(\int_0^1\int_0^1(x+y)\,dy\,dx = 1/2 + 1/2 = 1\)이므로 \(c = 1\)입니다.

    \(\displaystyle P(X+Y\le1) = \int_0^1\!\int_0^{1-x}(x+y)\,dy\,dx = \int_0^1\Big[x(1-x) + \frac{(1-x)^2}{2}\Big]dx = \int_0^1\frac{1-x^2}{2}dx = \frac13\)입니다. 넓이는 절반이지만 밀도가 원점 근처에서 작으므로 확률은 1/2보다 작습니다.

  4. 계산변환 \(u = x + y\), \(v = x - y\)의 역변환과 야코비안 \(\left|\dfrac{\partial(x, y)}{\partial(u, v)}\right|\)을 구하세요. 결합 밀도 \(f_{X,Y}\)가 주어졌을 때 \((U, V)\)의 결합 밀도식을 쓰세요. [06-02]

    힌트 1

    두 식을 더하고 빼면 \(x = (u+v)/2\), \(y = (u-v)/2\)입니다.

    힌트 2

    야코비안 행렬식은 \(\begin{vmatrix}x_u & x_v\\ y_u & y_v\end{vmatrix}\)입니다.

    풀이

    \(x = (u+v)/2\), \(y = (u-v)/2\)이고 \(\begin{vmatrix}1/2 & 1/2\\ 1/2 & -1/2\end{vmatrix} = -\frac14 - \frac14 = -\frac12\)이므로 절댓값은 \(1/2\)입니다.

    따라서 \(f_{U,V}(u, v) = f_{X,Y}\Big(\dfrac{u+v}{2}, \dfrac{u-v}{2}\Big)\cdot\dfrac12\)입니다. 야코비안은 \((u, v)\) 평면의 작은 넓이가 \((x, y)\) 평면에서 몇 배가 되는지를 나타내는 보정 계수입니다.

  5. 계산\(X\)가 \((0, 1)\)의 균등분포를 따를 때 \(Y = -\ln X\)의 밀도함수를 구하세요. [06-02]

    힌트 1

    \(y = -\ln x\)의 역함수는 \(x = e^{-y}\)이고, \(x \in (0, 1)\)이면 \(y \in (0, \infty)\)입니다.

    힌트 2

    일변수 변환 공식 \(f_Y(y) = f_X(x(y))\,|dx/dy|\)를 씁니다.

    풀이

    \(x = e^{-y}\), \(|dx/dy| = e^{-y}\), \(f_X = 1\)이므로 \(f_Y(y) = e^{-y}\) (\(y > 0\))입니다. 곧 \(Y\)는 비율 1인 지수분포를 따릅니다. 이 성질은 균등 난수로 지수 난수를 만드는 역변환법에 쓰입니다.

  6. 증명\(I = \int_{-\infty}^\infty e^{-x^2/2}dx\)라 할 때 \(I^2\)을 극좌표 이중적분으로 계산해 \(I = \sqrt{2\pi}\)를 보이세요. 이어서 서로 독립인 표준정규 \(X, Y\)에 대해 \(P(X^2 + Y^2 \le 1)\)을 구하세요. [06-03]

    힌트 1

    \(I^2 = \iint e^{-(x^2+y^2)/2}dx\,dy\)이고, 극좌표에서 \(dx\,dy = r\,dr\,d\theta\)입니다.

    힌트 2

    \(\int_0^\infty re^{-r^2/2}dr\)은 \(u = r^2/2\)로 치환하면 1입니다.

    풀이

    \(I^2 = \displaystyle\int_0^{2\pi}\!\int_0^\infty e^{-r^2/2}r\,dr\,d\theta = 2\pi\cdot\big[-e^{-r^2/2}\big]_0^\infty = 2\pi\). \(I > 0\)이므로 \(I = \sqrt{2\pi}\)이고, 표준정규 밀도의 규격화 상수가 \(1/\sqrt{2\pi}\)인 까닭입니다.

    결합 밀도는 \(\frac{1}{2\pi}e^{-(x^2+y^2)/2}\)이므로 \(P(X^2+Y^2\le1) = \displaystyle\frac{1}{2\pi}\int_0^{2\pi}\!\int_0^1 e^{-r^2/2}r\,dr\,d\theta = 1 - e^{-1/2} \approx 0.393\)입니다.
