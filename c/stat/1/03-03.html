계승을 실수로 넓히기

\(\int_0^\infty x^ne^{-x}dx = n!\)입니다. 이 적분은 \(n\)이 정수가 아니어도 계산할 수 있으므로, 계승을 실수로 넓힌 함수를 얻습니다. 감마분포, 카이제곱분포, t 분포의 밀도에 모두 이 함수가 들어 있습니다.

3.3.1감마 함수

정의 3.3.1

\(\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}dx\) (\(\alpha > 0\)).

정리 3.3.2

(가) \(\Gamma(\alpha + 1) = \alpha\Gamma(\alpha)\). (나) \(\Gamma(n) = (n-1)!\). (다) \(\Gamma(1/2) = \sqrt\pi\).

(가) 부분적분 \(u = x^\alpha\), \(dv = e^{-x}dx\): \([-x^\alpha e^{-x}]_0^\infty + \alpha\int x^{\alpha-1}e^{-x}dx = \alpha\Gamma(\alpha)\). (나) \(\Gamma(1) = 1\)과 (가)를 반복. (다) \(x = z^2/2\)로 치환하면 \(\Gamma(1/2) = \sqrt2\int_0^\infty e^{-z^2/2}dz = \sqrt2\cdot\frac{\sqrt{2\pi}}{2} = \sqrt\pi\)(6.3절의 가우스 적분). ∎

쓸모 있는 꼴: \(\int_0^\infty x^{\alpha-1}e^{-x/\beta}dx = \Gamma(\alpha)\beta^\alpha\) (\(x = \beta u\)로 치환).

3.3.2베타 함수

정의 3.3.3

\(B(a, b) = \int_0^1 x^{a-1}(1-x)^{b-1}dx = \dfrac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}\).

두 번째 등호는 이중적분과 변수 변환으로 증명합니다(6.2절 연습). 베타분포 밀도의 상수가 \(1/B(a, b)\)입니다.

예제 3.3.4

(가) \(\Gamma(5/2)\) (나) \(\int_0^1 x^3(1-x)^2dx\)

풀이. (가) \(\frac32\cdot\frac12\Gamma(\frac12) = \frac34\sqrt\pi \approx 1.329\). (나) \(B(4, 3) = \frac{3!\,2!}{6!} = \frac{12}{720} = \frac1{60}\).

요약
  1. \(\Gamma(\alpha+1) = \alpha\Gamma(\alpha)\), \(\Gamma(n) = (n-1)!\), \(\Gamma(1/2) = \sqrt\pi\).
  2. \(\int_0^\infty x^{\alpha-1}e^{-x/\beta} = \Gamma(\alpha)\beta^\alpha\).
  3. \(B(a,b) = \Gamma(a)\Gamma(b)/\Gamma(a+b)\).

3.3.3연습문제

기본

  1. 감마 밀도 \(\frac{1}{\Gamma(\alpha)\beta^\alpha}x^{\alpha-1}e^{-x/\beta}\)의 평균을 감마 함수로 구하세요.
    답

    \(\frac{\Gamma(\alpha+1)\beta^{\alpha+1}}{\Gamma(\alpha)\beta^\alpha} = \alpha\beta\).
