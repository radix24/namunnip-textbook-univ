넓이가 1이어야 밀도다

밀도함수는 음이 아니고 전체 넓이가 1이어야 합니다. 정규분포나 지수분포처럼 값이 무한히 뻗어 있으면 넓이는 무한 구간의 적분, 곧 이상적분입니다.

3.2.1정의

정의 3.2.1

\(\int_a^\infty f = \lim_{b\to\infty}\int_a^b f\). 극한이 있으면 수렴. \(f\)가 \(a\)에서 발산하면 \(\int_a^b f = \lim_{t\to a^+}\int_t^b f\).

결과 3.2.2

\(\int_1^\infty x^{-p}dx\)는 \(p > 1\)이면 수렴(값 \(\frac{1}{p-1}\)), \(p \le 1\)이면 발산. \(\int_0^1 x^{-p}dx\)는 \(p < 1\)이면 수렴.

정리 3.2.2 (비교 판정)

\(0 \le f \le g\)이고 \(\int g\)가 수렴하면 \(\int f\)도 수렴. \(\int f\)가 발산하면 \(\int g\)도 발산.

3.2.2규격화와 적률의 존재

예제 3.2.3

(가) \(f(x) = \frac{c}{1 + x^2}\)가 밀도가 되는 \(c\)는? (나) 이 분포의 평균은 있는가?

풀이. (가) \(\int_{-\infty}^\infty\frac{dx}{1+x^2} = [\arctan x]_{-\infty}^\infty = \pi\)이므로 \(c = 1/\pi\)(코시 분포). (나) \(\int_0^\infty\frac{x}{1+x^2}dx = \lim\frac12\log(1 + b^2) = \infty\). \(x\)가 클 때 \(\frac{x}{1+x^2} \approx \frac1x\)(\(p = 1\))이라 발산합니다. 평균이 없습니다. 꼬리가 \(x^{-2}\)처럼 두꺼우면 생기는 일입니다.

적률 \(E|X|^k\)가 있으려면 꼬리가 \(x^{-(k+1)}\)보다 빨리 줄어야 합니다. 지수적으로 줄어드는 분포(정규, 지수, 감마)는 모든 적률이 있습니다.

요약
  1. 이상적분 = 정적분의 극한.
  2. \(\int^\infty x^{-p}\)는 \(p > 1\)에서 수렴, 비교 판정.
  3. 밀도의 상수는 넓이 1로, 적률의 존재는 꼬리로 판정.

3.2.3연습문제

기본

  1. \(f(x) = cx^{-3}\) (\(x \ge 1\))이 밀도가 되는 \(c\)와 평균은? 분산은 있나요?
    답

    \(\int_1^\infty x^{-3} = 1/2\), \(c = 2\). 평균 \(\int_1^\infty 2x^{-2} = 2\). \(E(X^2) = \int 2x^{-1} = \infty\)이므로 분산은 없습니다.
