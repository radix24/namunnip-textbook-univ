점 하나보다 범위

"학생들의 평균 사용 시간은 4.2시간"이라는 말은 표본이 바뀌면 달라질 값을 하나만 보여 줍니다. "3.8시간에서 4.6시간 사이"처럼 범위로 말하고, 그 범위를 만드는 방법이 얼마나 자주 맞는지 함께 말하는 것이 신뢰구간입니다.

3.2.1평균의 신뢰구간

\(\sigma\)를 알면 \(P(-1.96 \le \frac{\bar X - \mu}{\sigma/\sqrt n} \le 1.96) \approx 0.95\)이고, 부등식을 \(\mu\)에 대해 풀면 \(\bar X \pm 1.96\,\sigma/\sqrt n\)이 \(\mu\)를 덮을 확률이 0.95입니다. 실제로는 \(\sigma\)를 모르므로 \(s\)를 씁니다. 모집단이 정규분포이면 \(T = \frac{\bar X - \mu}{S/\sqrt n}\)은 자유도 \(n-1\)인 t 분포를 따릅니다. t 분포는 0을 중심으로 대칭이고 정규분포보다 꼬리가 두꺼우며, 자유도가 커지면 정규분포에 가까워집니다.

결과 3.2.1

모평균의 \(100(1-\alpha)\%\) 신뢰구간: \(\bar x \pm t_{\alpha/2,\,n-1}\dfrac{s}{\sqrt n}\).

\(t_{0.025, 9} = 2.262\), \(t_{0.025, 29} = 2.045\), \(t_{0.025, \infty} = 1.960\)입니다. 모집단이 정규가 아니어도 \(n\)이 크면 중심극한정리 덕분에 근사적으로 맞습니다.

3.2.2비율의 신뢰구간

성공 횟수 \(X\)가 이항분포 \(B(n, p)\)를 따르면 \(\hat p = X/n\)의 표준오차는 \(\sqrt{p(1-p)/n}\)이고, \(n\)이 크면 정규분포로 근사됩니다.

결과 3.2.2

모비율의 근사 95% 신뢰구간: \(\hat p \pm 1.96\sqrt{\dfrac{\hat p(1-\hat p)}n}\). \(n\hat p\)와 \(n(1-\hat p)\)가 모두 10 이상일 때 씁니다.

예제 3.2.1

(가) 10명의 사용 시간 평균 4.2, 표준편차 1.1일 때 95% 신뢰구간. (나) 1000명 여론조사에서 지지율 42%일 때 95% 신뢰구간.

풀이. (가) \(4.2 \pm 2.262 \times 1.1/\sqrt{10} = 4.2 \pm 0.79\), 곧 [3.41, 4.99]. (나) \(\sqrt{0.42 \times 0.58/1000} \approx 0.0156\), \(0.42 \pm 0.031\), 곧 [38.9%, 45.1%]. 언론의 "오차 한계 ±3.1%p"가 이 값입니다.

3.2.3신뢰수준의 뜻

95%는 방법의 성질입니다. 이 방법으로 표본을 되풀이해 구간을 만들면 그중 약 95%가 \(\mu\)를 덮습니다. 한 번 계산한 구간 [3.41, 4.99]는 \(\mu\)를 덮었거나 못 덮었거나 둘 중 하나이고, 우리는 어느 쪽인지 모릅니다. 그래서 "\(\mu\)가 이 구간에 있을 확률이 95%"라고 하지 않고 "95% 신뢰한다"고 말합니다.

요약
  1. 평균: \(\bar x \pm t_{\alpha/2, n-1}\,s/\sqrt n\).
  2. 비율: \(\hat p \pm z_{\alpha/2}\sqrt{\hat p(1-\hat p)/n}\).
  3. 신뢰수준을 높이면 구간이 넓어지고, \(n\)을 늘리면 좁아집니다.
  4. 신뢰수준은 구간을 만드는 방법이 맞는 비율입니다.

3.2.4연습문제

기본

  1. 오차 한계를 ±2%p 이하로 하려면 여론조사 표본이 몇 명 필요한가요? (\(p\)를 모르면 0.5로 둡니다.)
    답

    \(1.96\sqrt{0.25/n} \le 0.02\)에서 \(n \ge 2401\).

응용

  1. 두 후보의 지지율이 42%와 39%이고 오차 한계가 ±3.1%p입니다. "42% 후보가 앞선다"고 단정하기 어려운 이유는?
    답

    두 구간 [38.9, 45.1]과 [35.9, 42.1]이 크게 겹치고, 지지율 차이의 표준오차는 각 비율의 표준오차보다 큽니다. 차이 3%p는 표본 오차로 충분히 생길 수 있습니다.

3.2.2

실습"95% 신뢰구간"의 95%는 무엇의 비율인가?

실습 · 신뢰구간

다루는 성취기준 [응통5-03-02]

목표

평균을 아는 가상 모집단에서 표본을 100번 뽑아 신뢰구간 100개를 그립니다. 그중 참 평균을 덮는 구간의 비율(덮임률)이 신뢰수준과 같아지는지, 언제 어긋나는지 확인합니다. 성취기준 [응통5-03-02].

평균의 신뢰구간: \(\bar x \pm q \cdot s/\sqrt n\). \(s\)는 표본표준편차, \(q\)는 신뢰수준에 맞춘 곱하는 값입니다.

t 분포를 쓰는 이유: 모집단 표준편차 \(\sigma\) 대신 표본에서 구한 \(s\)를 쓰면 \((\bar X - \mu)/(s/\sqrt n)\)은 정규분포보다 꼬리가 두꺼운 자유도 \(n-1\)인 t 분포를 따릅니다(모집단이 정규일 때). 그래서 \(q\)를 t 분포에서 찾습니다. 95%이고 \(n = 10\)이면 \(q = 2.262\)로, 정규분포의 1.960보다 큽니다.

준비

모집단 평균은 \(\mu = 50\)(세로선), 표준편차는 10입니다. 가로줄 하나가 표본 하나로 만든 구간이고, 파랑은 \(\mu\)를 덮은 구간, 빨강은 놓친 구간입니다. "100개 더"를 누르면 새 표본 100개로 다시 그리고 누적 덮임률을 갱신합니다. 조절기를 바꾸면 누적은 처음부터 다시 셉니다.

절차

  1. 기본값(정규 모집단, \(n = 10\), 95%, t 분포)에서 "100개 더"를 10번 눌러 누적 덮임률을 봅니다.
  2. 신뢰수준을 80%, 99%로 바꿔 덮임률과 평균 너비가 어떻게 바뀌는지 적습니다.
  3. 신뢰수준 95%로 돌리고 곱하는 값을 "정규분포 z"로 바꿉니다. \(n = 5\)와 \(n = 50\)에서 각각 10번 눌러 봅니다.
  4. 다시 t 분포로 두고 모집단을 "지수분포 모양"으로 바꿔 \(n = 5\), \(n = 50\)에서 비교합니다.

기대 결과

  • 정규 모집단 + t 분포이면 누적 덮임률이 신뢰수준 근처(95%이면 대략 93~97%)에 머뭅니다. 100개 한 묶음은 90~99개 사이에서 흔들립니다.
  • 신뢰수준을 올리면 덮임률이 오르는 대신 구간이 넓어집니다. \(n = 10\)에서 평균 너비는 80%일 때 약 8.5, 99%일 때 약 20입니다(평균 너비는 \(2q \cdot E(s)/\sqrt n\)이고 \(n = 10\)이면 \(E(s) \approx 9.7\)).
  • z를 잘못 쓰면 \(n = 5\)에서 덮임률이 약 88%로 떨어집니다. 자유도 4인 t 분포에서 \(|T| > 1.96\)일 확률이 약 0.12이기 때문입니다. \(n = 50\)이면 t와 z가 거의 같아 차이가 사라집니다.
  • 치우친 모집단에서는 \(n = 5\)일 때 t 구간도 덮임률이 약 88%로 내려갑니다. \(n = 50\)이면 중심극한정리 덕분에 약 94%로 95%에 가까워지지만, 치우침의 흔적이 조금 남습니다.

분석

  1. 구간 하나를 구한 뒤 "\(\mu\)가 이 구간에 있을 확률이 95%"라고 말하면 왜 틀린가요? 그림의 구간 하나는 \(\mu\)를 덮었거나 못 덮었거나 둘 중 하나입니다. 95%는 무엇의 비율인지 적어 보세요.
  2. 너비를 절반으로 줄이려면 \(n\)을 몇 배로 해야 하나요? 출력의 평균 너비로 확인해 보세요.

더 해 보기

R: ci <- replicate(1000, { x <- rnorm(10, 50, 10); t.test(x)$conf.int }), mean(ci[1, ] <= 50 & 50 <= ci[2, ]). 비율의 신뢰구간(\(\hat p \pm 1.96\sqrt{\hat p(1-\hat p)/n}\))은 \(p\)가 0이나 1에 가까우면 덮임률이 크게 떨어집니다. 같은 실험을 비율로 해 보세요.
