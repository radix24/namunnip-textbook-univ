예측하는 직선

상관계수는 관계의 강도만 말합니다. "공부 시간이 1시간 늘면 점수가 몇 점 오르나?"에 답하려면 직선 \(\hat y = b_0 + b_1x\)를 구해야 합니다. 응통10에서 이론을 자세히 다루고, 여기서는 계산과 해석을 익힙니다.

6.2.1최소제곱 직선

각 점에서 직선까지의 세로 거리 \(e_i = y_i - (b_0 + b_1x_i)\)를 잔차라 합니다. 잔차 제곱합 \(\sum e_i^2\)을 가장 작게 하는 직선을 고릅니다. \(b_0\)와 \(b_1\)로 편미분해 0으로 두면

결과 6.2.1 \[b_1 = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2} = r\frac{s_y}{s_x}, \qquad b_0 = \bar y - b_1\bar x.\]

직선은 항상 \((\bar x, \bar y)\)를 지나고, 잔차의 합은 0입니다. \(b_1 = r s_y/s_x\)는 "\(x\)가 표준편차 하나만큼 커지면 \(y\)는 표준편차의 \(r\)배만큼 커진다"는 뜻입니다. \(|r| < 1\)이라 예측값은 평균 쪽으로 당겨지며, 이것이 "평균으로의 회귀"라는 이름의 유래입니다.

6.2.2결정계수

정의 6.2.1

결정계수: \(R^2 = 1 - \dfrac{\sum e_i^2}{\sum(y_i - \bar y)^2}\). \(y\)의 변동 가운데 직선이 설명하는 비율. 단순회귀에서는 \(R^2 = r^2\).

예제 6.2.2

6.1절 예제 자료 (1, 2), (2, 4), (3, 5), (4, 4), (5, 5)에 직선을 적합하고 잔차와 \(R^2\)를 구하세요.

풀이. \(b_1 = 6/10 = 0.6\), \(b_0 = 4 - 0.6 \times 3 = 2.2\). \(\hat y\) = 2.8, 3.4, 4.0, 4.6, 5.2. 잔차 −0.8, 0.6, 1.0, −0.6, −0.2(합 0). 잔차 제곱합 \(0.64 + 0.36 + 1 + 0.36 + 0.04 = 2.4\). \(R^2 = 1 - 2.4/6 = 0.6 = 0.775^2\).

6.2.3잔차 확인

적합한 뒤에는 잔차를 \(x\)(또는 \(\hat y\))에 대해 그립니다. 잔차가 0 둘레에 무늬 없이 흩어져야 직선 모형이 알맞습니다. U자 무늬는 곡선 관계, 나팔 모양은 분산이 일정하지 않음을 뜻합니다. 자세한 진단은 응통10 04단원과 그 실습 카드에서 다룹니다.

x <- 1:5; y <- c(2, 4, 5, 4, 5)
fit <- lm(y ~ x); coef(fit); resid(fit); summary(fit)$r.squared
plot(x, resid(fit)); abline(h = 0)
요약
  1. \(b_1 = r s_y/s_x\), \(b_0 = \bar y - b_1\bar x\).
  2. 잔차 = 관측값 − 적합값, 합은 0.
  3. \(R^2 = r^2\)은 설명된 변동의 비율. 잔차 그림으로 모형을 점검합니다.

6.2.4연습문제

기본

  1. \(r = 0.8\), \(s_x = 2\), \(s_y = 5\), \(\bar x = 10\), \(\bar y = 50\)이면 회귀 직선은?
    답

    \(b_1 = 0.8 \times 5/2 = 2\), \(b_0 = 50 - 20 = 30\). \(\hat y = 30 + 2x\).

응용

  1. 예제의 직선으로 \(x = 20\)일 때 \(y\)를 예측해도 될까요?
    답

    \(\hat y = 14.2\)가 나오지만 자료 범위(1~5)를 크게 벗어난 외삽이라 믿기 어렵습니다.
