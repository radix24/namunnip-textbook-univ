  • 전체 변동을 집단 간 변동과 집단 내 변동으로 나눈다.

먼저 알아야 할 것
  • 이표본 t 검정 (4.2절), 다중 비교 (4.3절).

세 집단을 한 번에

세 가지 비료로 키운 콩의 수확량을 비교하려 합니다. 쌍마다 t 검정을 세 번 하면 다중 비교 문제가 생깁니다. "세 평균이 모두 같다"를 한 번에 검정하는 방법이 분산분석(ANOVA)입니다. 이름과 달리 평균을 비교하는 방법이며, 변동을 나누어 비교하기 때문에 이런 이름이 붙었습니다.

5.1.1변동의 분해

집단 \(i = 1, \ldots, k\)에 자료 \(y_{ij}\)가 \(n_i\)개씩, 전체 \(N\)개 있다고 합시다. 집단 평균을 \(\bar y_i\), 전체 평균을 \(\bar y\)라 하면

\[\underbrace{\sum_{i,j}(y_{ij} - \bar y)^2}_{SST} = \underbrace{\sum_i n_i(\bar y_i - \bar y)^2}_{SSB} + \underbrace{\sum_{i,j}(y_{ij} - \bar y_i)^2}_{SSW}.\]

\(y_{ij} - \bar y = (y_{ij} - \bar y_i) + (\bar y_i - \bar y)\)를 제곱해 더하면 교차항이 \(2\sum_i(\bar y_i - \bar y)\sum_j(y_{ij} - \bar y_i)\)이고, 안쪽 합은 집단 평균의 정의에 따라 0입니다. ∎

SSB는 집단 평균들이 서로 얼마나 다른지, SSW는 같은 집단 안에서 얼마나 흩어졌는지를 잽니다.

5.1.2F 검정

결과 5.1.1

\(H_0: \mu_1 = \cdots = \mu_k\). 각 집단이 같은 분산의 정규분포이고 서로 독립이면, \(H_0\) 아래에서

\[F = \frac{SSB/(k-1)}{SSW/(N-k)}\]

는 자유도 \((k-1, N-k)\)인 F 분포를 따른다. F가 크면 기각한다.

분자 MSB와 분모 MSW는 모두 \(H_0\) 아래에서 \(\sigma^2\)의 추정량입니다. 집단 평균이 다르면 MSB만 커지므로 비 F가 1보다 훨씬 커집니다.

예제 5.1.1

비료 A: 5, 6, 7. B: 8, 9, 10. C: 5, 7, 6 (단위: kg). 분산분석표를 만드세요.

풀이. 집단 평균 6, 9, 6, 전체 평균 7. SSB = \(3(1 + 4 + 1) = 18\). SSW = A \(1+0+1\) + B \(1+0+1\) + C \(1+1+0\) = 6. 자유도 2와 6.

\(F_{0.05}(2, 6) = 5.14\)보다 크므로 기각합니다(p값 약 0.016). 세 평균이 모두 같지는 않습니다. 어느 쌍이 다른지는 사후 비교(응통13 02단원)로 봅니다.

y <- c(5,6,7, 8,9,10, 5,7,6); g <- factor(rep(c("A","B","C"), each = 3))
summary(aov(y ~ g))
요약
  1. SST = SSB + SSW.
  2. \(F = \mathrm{MSB}/\mathrm{MSW}\), 자유도 \((k-1, N-k)\).
  3. 가정: 독립, 정규, 등분산. 기각 뒤에는 사후 비교.

5.1.3연습문제

기본

  1. 집단이 2개일 때 F 검정과 합동 분산 t 검정의 관계는?
    답

    \(F = t^2\)이고 p값이 같습니다.

응용

  1. 예제에서 B의 값을 6, 7, 8로 바꾸면 F는?
    답

    집단 평균 6, 7, 6, 전체 평균 6.33. SSB = \(3(0.111 + 0.444 + 0.111) = 2\), SSW = 6, \(F = (2/2)/(6/6) = 1\). 기각하지 않습니다.
