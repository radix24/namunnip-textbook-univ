함께 움직이는 정도를 하나의 수로

공부 시간이 길수록 점수가 높은 경향이 있을 때, 그 경향이 얼마나 뚜렷한지를 −1에서 1 사이의 수로 나타낸 것이 상관계수입니다.

6.1.1정의

정의 6.1.1

표본 상관계수: \(r = \dfrac{1}{n-1}\sum_{i=1}^n\left(\dfrac{x_i - \bar x}{s_x}\right)\left(\dfrac{y_i - \bar y}{s_y}\right) = \dfrac{\sum(x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i - \bar x)^2\sum(y_i - \bar y)^2}}\).

두 변수를 표준화한 값의 곱을 평균 낸 것입니다. 오른쪽 위와 왼쪽 아래(둘 다 평균보다 크거나 둘 다 작음)에 점이 많으면 곱이 양수라 \(r > 0\)입니다.

성질: (1) \(-1 \le r \le 1\)(코시-슈바르츠 부등식). (2) \(|r| = 1\)은 모든 점이 한 직선 위에 있을 때뿐. (3) 단위를 바꾸거나(cm → m) 양수를 곱해도 \(r\)은 그대로. (4) \(x\)와 \(y\)를 바꿔도 같음.

6.1.2상관계수가 말하지 않는 것

  1. 직선 관계만 잽니다. \(y = x^2\), \(x = -2, -1, 0, 1, 2\)이면 관계가 완벽한데도 \(r = 0\)입니다.
  2. 이상값 하나에 크게 흔들립니다. 관계없는 점 구름에 멀리 떨어진 점 하나만 있어도 \(r\)이 0.7을 넘을 수 있습니다.
  3. 인과를 말하지 않습니다. 아이스크림 판매량과 익사 사고의 상관은 기온이라는 교란 변수 때문입니다(1.1절).
  4. 범위를 좁히면 줄어듭니다. 합격자만 모아 입시 점수와 대학 성적의 상관을 구하면 전체보다 작게 나옵니다.

그래서 상관계수는 반드시 산점도와 함께 봅니다. 평균, 분산, 상관계수가 모두 같은데 산점도가 전혀 다른 앤스컴(Anscombe)의 네 자료가 유명한 예입니다(R의 anscombe).

예제 6.1.2

\((x, y)\) = (1, 2), (2, 4), (3, 5), (4, 4), (5, 5)의 상관계수를 구하세요.

풀이. \(\bar x = 3\), \(\bar y = 4\). 편차 \(x\): −2, −1, 0, 1, 2. \(y\): −2, 0, 1, 0, 1. 곱의 합 \(4 + 0 + 0 + 0 + 2 = 6\). \(\sum(x-\bar x)^2 = 10\), \(\sum(y - \bar y)^2 = 4 + 0 + 1 + 0 + 1 = 6\). \(r = 6/\sqrt{60} \approx 0.775\).

요약
  1. \(r\)은 직선 관계의 방향과 강도, \(-1 \le r \le 1\).
  2. 비선형 관계, 이상값, 범위 제한에 주의합니다.
  3. 상관은 인과가 아닙니다. 산점도를 함께 봅니다.

6.1.3연습문제

기본

  1. 키(cm)와 몸무게(kg)의 상관이 0.6입니다. 키를 인치로 바꾸면?
    답

    그대로 0.6입니다.

응용

  1. \(r = 0\)인데 두 변수가 강하게 관련된 예를 그려 보세요.
    답

    U자 또는 원 모양의 산점도. 예: 하루 시각과 기온을 0시 기준 대칭 구간에서 볼 때.
