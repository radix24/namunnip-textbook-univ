학생 10명의 수학 점수를 특강 전과 후에 쟀습니다. 이 20개 숫자를 "두 집단"으로 보면 이표본 검정, "10명 각각의 변화"로 보면 대응표본 검정이 됩니다. 어느 쪽이 맞는지는 자료가 어떻게 모였는지가 정합니다.

4.2.1일표본 t 검정

\(H_0: \mu = \mu_0\). 검정통계량 \(t = \dfrac{\bar x - \mu_0}{s/\sqrt n}\), 자유도 \(n-1\). 예: 과자 한 봉지 표시 중량이 100 g인데 실제 평균이 다른가?

4.2.2이표본 t 검정

서로 독립인 두 집단의 평균 비교. \(H_0: \mu_1 = \mu_2\). 두 분산이 같다고 가정하지 않는 웰치(Welch) 검정이 기본입니다.

\[t = \frac{\bar x_1 - \bar x_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}\]

자유도는 웰치-새터스웨이트 식으로 구하며 소프트웨어가 계산합니다. 두 분산이 같다고 가정하면 합동 분산 \(s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}\)을 쓰고 자유도는 \(n_1 + n_2 - 2\)입니다.

4.2.3대응표본 t 검정

같은 대상을 두 번 쟀거나 짝지은 자료(쌍둥이, 왼눈과 오른눈). 쌍마다 차이 \(d_i\)를 구해 일표본 t 검정을 합니다: \(t = \bar d/(s_d/\sqrt n)\), 자유도 \(n-1\). 사람마다 다른 기본 실력이 차이를 구할 때 빠지므로, 같은 자료를 이표본으로 분석할 때보다 검정력이 훨씬 큽니다.

예제 4.2.1

5명의 특강 전후 점수: (60, 66), (72, 75), (55, 62), (80, 81), (68, 74). 대응표본 t 검정으로 효과가 있는지 \(\alpha = 0.05\)에서 검정하세요.

풀이. 차이 6, 3, 7, 1, 6. \(\bar d = 4.6\), 편차 1.4, −1.6, 2.4, −3.6, 1.4의 제곱합 \(1.96 + 2.56 + 5.76 + 12.96 + 1.96 = 25.2\), \(s_d = \sqrt{25.2/4} \approx 2.51\). \(t = 4.6/(2.51/\sqrt5) \approx 4.10\), 자유도 4. 양측 임계값 \(t_{0.025,4} = 2.776\)보다 크므로 기각합니다(p값 약 0.015). 같은 자료를 이표본 웰치 검정으로 하면 두 평균 67.0과 71.6의 차이가 사람 사이 퍼짐(표준편차 약 9.8과 7.6)에 묻혀 \(t \approx 0.83\)으로 유의하지 않습니다.

before <- c(60, 72, 55, 80, 68); after <- c(66, 75, 62, 81, 74)
t.test(after, before, paired = TRUE)
t.test(after, before)   # 잘못된 분석: 짝을 무시함
요약
  1. 일표본: 한 평균을 기준값과 비교, 자유도 \(n-1\).
  2. 이표본(웰치): 독립인 두 집단, 분산이 달라도 됨.
  3. 대응표본: 짝의 차이로 일표본 검정. 짝을 무시하면 검정력을 잃습니다.

4.2.4연습문제

기본

  1. 다음에 알맞은 검정은? (가) 남녀 학생의 키 비교 (나) 같은 환자의 투약 전후 혈압 (다) 전구 수명이 1000시간인지
    답

    (가) 이표본, (나) 대응표본, (다) 일표본.

응용

  1. 16봉지 과자의 평균 중량 98.5 g, 표준편차 2.4 g. 표시 100 g과 다른지 \(\alpha = 0.05\)에서 검정하세요.
    답

    \(t = -1.5/(2.4/4) = -2.5\), 자유도 15, \(t_{0.025,15} = 2.131\). \(|t| > 2.131\)이므로 기각합니다. 평균이 100 g과 다르다고 봅니다.
