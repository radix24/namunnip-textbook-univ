이 절에서 배울 것
  • 평균과 분산을 모두 모르는 정규 모형의 완전 조건부분포를 유도한다.
  • 깁스 표집으로 결합 사후분포를 표집하고 요약한다.
먼저 알아야 할 것
  • 켤레 사전 (2.1절), 응통15 5.2절 깁스 표집.

모수가 둘 이상이면

정규 평균 \(\mu\)와 분산 \(\sigma^2\)을 모두 모르면 결합 사후분포가 이차원이고, 켤레 사전을 써도 주변 사후를 얻으려면 적분이 필요합니다. 한 모수씩 조건부로 번갈아 뽑는 깁스 표집이면 간단히 표본을 얻습니다.

6.1.1모형과 조건부분포

\(y_i \sim N(\mu, 1/\tau)\)(\(\tau\)는 정밀도), 사전 \(\mu \sim N(\mu_0, 1/\kappa_0)\), \(\tau \sim \mathrm{Gamma}(a, b)\) 독립.

결과 6.1.1

\(\mu \mid \tau, \mathbf y \sim N\left(\dfrac{\kappa_0\mu_0 + n\tau\bar y}{\kappa_0 + n\tau}, \dfrac{1}{\kappa_0 + n\tau}\right)\), \(\tau \mid \mu, \mathbf y \sim \mathrm{Gamma}\left(a + \dfrac n2, b + \dfrac12\sum(y_i - \mu)^2\right)\).

첫 식은 2.1절의 정규-정규 켤레(\(\tau\)를 안다고 두면), 둘째는 \(\mu\)를 안다고 두면 감마-정규 켤레입니다. 각각은 쉬운 분포라 번갈아 뽑을 수 있습니다.

6.1.2구현

y <- c(98, 105, 112, 101, 94, 108, 110, 99); n <- length(y)
mu0 <- 100; k0 <- 1 / 100; a <- 0.01; b <- 0.01
S <- 10000; mu <- tau <- numeric(S); mu[1] <- mean(y); tau[1] <- 1 / var(y)
set.seed(1)
for (s in 2:S) {
  prec <- k0 + n * tau[s - 1]
  mu[s] <- rnorm(1, (k0 * mu0 + n * tau[s - 1] * mean(y)) / prec, sqrt(1 / prec))
  tau[s] <- rgamma(1, a + n / 2, b + sum((y - mu[s])^2) / 2)
}
keep <- -(1:1000)
quantile(mu[keep], c(.025, .5, .975)); quantile(1 / sqrt(tau[keep]), c(.025, .5, .975))

번인 1000개를 버리고 \(\mu\)와 \(\sigma = 1/\sqrt\tau\)의 사후 분위수를 구합니다. 약한 사전이므로 \(\mu\)의 95% 신용구간은 [98.1, 108.1](중앙값 103.2)로, t 신뢰구간 \(103.4 \pm 2.365\times6.37/\sqrt8\) = [98.1, 108.7]과 비슷합니다. 경로 그림과 자기상관으로 수렴을 확인합니다(응통15 5.3절).

요약
  1. \(\mu \mid \tau\)는 정규, \(\tau \mid \mu\)는 감마.
  2. 번갈아 뽑아 결합 사후 표본.
  3. 표본의 분위수로 요약, 수렴 진단.

6.1.3연습문제

응용

  1. 코드로 \(P(\mu > 105 \mid \mathbf y)\)를 추정하는 한 줄은?
    답

    mean(mu[keep] > 105).
