6.R.1

연습MCMC와 베이즈 회귀 단원 마무리 연습

문제 6 · 실습·개념·판단 · 힌트 2단계

다루는 성취기준 [응통21-06-01] [응통21-06-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 [번호]는 다시 볼 절입니다.

  1. 실습정규 모형 \(y_i \sim N(\mu, \sigma^2)\)에서 \(\mu \sim N(m_0, s_0^2)\), \(1/\sigma^2 \sim \mathrm{Gamma}(a, b)\) 사전분포로 깁스 표집하는 두 조건부분포를 쓰세요. [06-01]

    힌트 1

    \(\sigma^2\)이 주어지면 \(\mu\)는 정규-정규 켤레입니다.

    힌트 2

    \(\mu\)가 주어지면 정밀도 \(\tau = 1/\sigma^2\)은 감마-정규 켤레입니다.

    풀이

    \(\mu \mid \sigma^2, y \sim N\Big(\frac{m_0/s_0^2 + n\bar y/\sigma^2}{1/s_0^2 + n/\sigma^2}, \frac{1}{1/s_0^2 + n/\sigma^2}\Big)\).

    \(\tau \mid \mu, y \sim \mathrm{Gamma}\Big(a + \frac n2, b + \frac12\sum(y_i - \mu)^2\Big)\).

    두 분포에서 번갈아 뽑으면 결합 사후분포의 표본을 얻습니다. 결합 사후분포는 닫힌 꼴이 아니지만(반켤레) 조건부분포는 모두 표준 분포라 깁스 표집이 간단합니다.

  2. 실습앞의 깁스 표집을 R로 구현하는 뼈대 코드를 쓰고, 결과 표본으로 \(\mu\)의 95% 신용구간을 구하는 방법을 쓰세요. [06-01]

    힌트 1

    반복마다 rnorm으로 \(\mu\), rgamma로 \(\tau\)를 뽑습니다.

    힌트 2

    번인 이후 표본의 분위수를 씁니다.

    풀이 
    gibbs <- function(y, n_iter = 5000, m0 = 0, s0 = 100, a = 0.01, b = 0.01) {
  n <- length(y); mu <- mean(y); tau <- 1 / var(y)
  out <- matrix(NA, n_iter, 2)
  for (t in 1:n_iter) {
    prec <- 1 / s0^2 + n * tau
    mu <- rnorm(1, (m0 / s0^2 + n * mean(y) * tau) / prec, sqrt(1 / prec))
    tau <- rgamma(1, a + n / 2, b + sum((y - mu)^2) / 2)
    out[t, ] <- c(mu, 1 / sqrt(tau))
  }
  out
}
s <- gibbs(y); quantile(s[-(1:500), 1], c(0.025, 0.975))

    약한 사전분포를 쓰면 신용구간이 t 신뢰구간과 비슷하게 나옵니다(응통21의 본문 예제 참조). 추적 그림과 유효 표본 크기로 수렴을 확인합니다(응통15-05-03).

  3. 실습베이즈 선형회귀에서 계수의 사후분포로 할 수 있는 해석 세 가지를 쓰세요. [06-02]

    힌트 1

    계수의 사후 평균과 신용구간, 부호에 대한 확률을 생각하세요.

    힌트 2

    예측에도 사후분포를 쓸 수 있습니다.

    풀이

    (1) 계수의 사후 평균과 95% 신용구간: "무게 1000 lb 증가에 따른 연비 변화는 약 −6.5 ~ −4.2일 확률이 95%(약한 사전분포일 때)". (2) 방향에 대한 확률: \(P(\beta < 0 \mid \text{자료})\)를 직접 계산. (3) 사후 예측분포: 새 차의 연비 예측과 그 불확실성(모수 불확실성 포함). 또 계수의 함수(두 계수의 비, 최적점)의 사후분포도 표본에서 바로 얻습니다.

  4. 실습베이즈 로지스틱 회귀는 켤레 사전분포가 없어 MCMC를 씁니다. R(예: rstanarm, brms)로 적합하는 코드와, 약정보 사전분포를 쓰는 실익을 쓰세요. [06-02]

    힌트 1

    stan_glm(y ~ x, family = binomial, data = d) 형태입니다.

    힌트 2

    완전 분리 문제(응통18-03-02)를 떠올리세요.

    풀이 
    library(rstanarm)
fit <- stan_glm(am ~ wt, family = binomial, data = mtcars,
                prior = normal(0, 2.5), prior_intercept = normal(0, 10))
posterior_interval(fit, prob = 0.95)

    약정보 사전분포(계수에 \(N(0, 2.5^2)\) 등)는 계수가 비현실적으로 커지지 않게 막아, 완전 분리에서도 유한하고 안정적인 추정값을 주며 작은 표본에서의 과적합을 줄입니다. 자료가 충분하면 결과는 최대가능도와 거의 같습니다.

  5. 개념베이즈 회귀에서 계수에 \(N(0, \tau^2)\) 사전분포를 두면 사후 최빈값이 능형 회귀와 같아지는 까닭을 설명하세요. 라쏘에 대응하는 사전분포는 무엇인가요? [06-02]

    힌트 1

    로그 사후 = 로그 가능도 + 로그 사전입니다.

    힌트 2

    정규 사전의 로그는 \(-\beta^2/(2\tau^2)\)입니다.

    풀이

    정규 오차 모형에서 로그 사후는 \(-\frac{1}{2\sigma^2}\sum(y_i - \mathbf x_i^\top\boldsymbol\beta)^2 - \frac{1}{2\tau^2}\sum\beta_j^2\)이므로, 이를 최대로 하는 것은 잔차제곱합 + \(\lambda\sum\beta_j^2\) (\(\lambda = \sigma^2/\tau^2\))를 최소로 하는 능형 회귀와 같습니다. 라쏘는 라플라스(이중 지수) 사전분포의 사후 최빈값에 대응합니다(베이즈 라쏘). 벌점 회귀를 사전분포로 해석할 수 있습니다.

  6. 판단MCMC 사슬 네 개를 돌렸더니 \(\hat R\)이 1.3, 유효 표본 크기가 40이었습니다. 이 결과로 사후 요약을 보고해도 되는지 판단하고 대처를 쓰세요. [06-01]

    힌트 1

    \(\hat R\)이 1.01 근처여야 수렴으로 봅니다.

    힌트 2

    유효 표본 크기가 작으면 몬테카를로 오차가 큽니다.

    풀이

    보고하면 안 됩니다. \(\hat R = 1.3\)은 사슬들이 서로 다른 영역에 있어 수렴하지 않았다는 뜻이고, 유효 표본 40은 사후 요약의 몬테카를로 오차가 크다는 뜻입니다. 대처: 반복과 번인을 늘리고, 모수를 재모수화하거나(중심화, 비중심화) 사전분포를 다시 보며, 더 효율적인 표집기(해밀토니안 몬테카를로)를 씁니다. 그래도 안 되면 모형의 식별 문제를 의심합니다.
