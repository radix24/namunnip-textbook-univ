사후가 사전과 같은 꼴일 때

사후분포의 정규화 상수는 대개 적분으로 구해야 합니다. 그런데 가능도와 사전분포가 잘 맞는 짝이면 사후분포가 사전과 같은 분포족이 되어, 모수만 갱신하면 됩니다. 이런 사전분포를 켤레라 합니다.

2.1.1세 가지 켤레

자료사전사후
이항: \(n\)번 중 \(y\)번\(\mathrm{Beta}(a, b)\)\(\mathrm{Beta}(a + y, b + n - y)\)
포아송: \(y_1, \ldots, y_n\)\(\mathrm{Gamma}(\alpha, \beta)\) (비율 \(\beta\))\(\mathrm{Gamma}(\alpha + \sum y_i, \beta + n)\)
정규(\(\sigma^2\) 앎): \(\bar y\), \(n\)\(N(\mu_0, \tau_0^2)\)\(N(\mu_n, \tau_n^2)\), \(\frac{1}{\tau_n^2} = \frac{1}{\tau_0^2} + \frac{n}{\sigma^2}\), \(\mu_n = \tau_n^2\left(\frac{\mu_0}{\tau_0^2} + \frac{n\bar y}{\sigma^2}\right)\)

베타-이항: 사후 ∝ \(\theta^y(1-\theta)^{n-y}\cdot\theta^{a-1}(1-\theta)^{b-1} = \theta^{a+y-1}(1-\theta)^{b+n-y-1}\), 베타 밀도의 핵입니다. 감마-포아송도 \(\lambda^{\sum y}e^{-n\lambda}\cdot\lambda^{\alpha-1}e^{-\beta\lambda}\)로 같은 방식입니다. ∎

정규-정규에서 정밀도(분산의 역수)가 더해지고, 사후 평균은 사전 평균과 표본 평균을 정밀도로 가중평균한 것입니다. 지수족(응통7 2.3절)에는 항상 켤레가 있습니다.

예제 2.1.1

하루 고객 불만 건수가 포아송(\(\lambda\))이고 사전 \(\mathrm{Gamma}(6, 2)\)(평균 3)입니다. 5일 동안 2, 4, 5, 3, 6건이면 사후분포와 평균은?

풀이. \(\sum y = 20\), \(n = 5\). 사후 \(\mathrm{Gamma}(26, 7)\), 평균 \(26/7 = 3.71\). 표본평균 4와 사전 평균 3 사이에 있습니다.

주의 켤레는 계산이 편할 뿐, 실제 믿음을 잘 나타낸다는 보장은 없습니다. 켤레가 아닌 사전분포는 MCMC(6.1절)로 계산합니다.
요약
  1. 베타-이항, 감마-포아송, 정규-정규.
  2. 모수만 갱신: 자료의 충분통계량을 사전 모수에 더함.
  3. 정규: 정밀도가 더해지고 평균은 가중평균.

2.1.2연습문제

기본

  1. \(\sigma = 10\), 사전 \(N(100, 5^2)\), \(n = 4\), \(\bar y = 110\)이면 사후분포는?
    답

    정밀도 \(1/25 + 4/100 = 0.08\), \(\tau_n^2 = 12.5\). \(\mu_n = 12.5(100/25 + 440/100) = 12.5\times8.4 = 105\). \(N(105, 12.5)\).
