사전분포는 얼마나 강한가

"사전 평균이 0.5"만으로는 부족합니다. 그 믿음이 동전 4번을 던져 본 정도인지, 1000번을 던져 본 정도인지가 사후에 큰 차이를 만듭니다.

2.2.1가상 표본

\(\mathrm{Beta}(a, b)\) 사전에 \(n\)번 중 \(y\)번을 더하면 \(\mathrm{Beta}(a + y, b + n - y)\)이므로, 사전분포는 "성공 \(a\)번, 실패 \(b\)번을 이미 본 것"과 같습니다. 가상 표본 크기는 \(a + b\)이고, 사후 평균은

\[\frac{a + y}{a + b + n} = \frac{a + b}{a + b + n}\cdot\frac{a}{a+b} + \frac{n}{a + b + n}\cdot\frac{y}{n}.\]

감마-포아송에서는 \(\beta\)가 가상 관측 기간(일 수), \(\alpha\)가 가상 사건 수입니다. 정규에서는 \(\sigma^2/\tau_0^2\)이 가상 표본 크기입니다.

2.2.2사전분포 고르기

  • 정보적 사전: 과거 연구, 전문가 의견을 가상 표본으로 옮김. 예: 비슷한 약의 반응률 30%를 20명 분량으로 → Beta(6, 14).
  • 약한 정보 사전: 터무니없는 값만 배제(\(N(0, 10^2)\) 같은 넓은 분포).
  • 비정보 사전: Beta(1,1)(균일), 제프리스 사전 Beta(1/2, 1/2). 적분이 1이 아닌 부적절 사전은 사후가 적절한지 확인해야 합니다.
  • 민감도 분석: 사전분포를 바꿔도 결론이 같은지 보고합니다.
예제 2.2.1

새 광고 클릭률에 대해 "평균 2%, 50명 분량의 확신"을 베타 사전으로 쓰면? 1000명 중 30명이 클릭하면 사후 평균은?

풀이. \(a + b = 50\), \(a/(a+b) = 0.02\) → Beta(1, 49). 사후 Beta(31, 1019), 평균 \(31/1050 = 2.95\%\). 표본 3%에 가까운 이유는 자료(1000명)가 사전(50명)보다 훨씬 많기 때문입니다.

요약
  1. 켤레 사전 모수 = 가상 관측(\(a + b\) = 가상 표본 크기).
  2. 사후 평균 = 사전 평균과 표본 값의 가중평균.
  3. 사전 근거를 밝히고 민감도 분석.
