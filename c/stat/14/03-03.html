"연구에 따르면"을 읽는 법

"매일 초콜릿을 먹으면 노벨상 수상자가 많아진다"는 실제로 국가별 초콜릿 소비량과 노벨상 수의 상관을 근거로 한 학술지 글이 있었습니다. 통계적으로 유의한 결과가 모두 믿을 만한 것은 아닙니다.

3.3.1흔한 오용

오용무엇이 문제인가
p-해킹변수, 하위 집단, 분석 방법을 여러 번 바꿔 p < 0.05인 것만 보고 → 실제 오류율이 훨씬 큼
출판 치우침유의한 결과만 출판 → 문헌 전체가 효과를 과대평가
유의성 = 중요성큰 표본에서는 사소한 차이도 유의
비유의 = 효과 없음검정력 부족일 수 있음
상관 = 인과교란, 역인과, 우연(국가 단위 자료의 생태학적 오류)
상대 위험만 보고"위험 두 배"가 0.001%에서 0.002%일 수 있음 → 절대 위험도 함께

3.3.2따져 묻는 질문

  1. 관측 연구인가 실험인가? 대상은 누구인가?
  2. 표본 크기와 효과 크기, 신뢰구간은?
  3. 미리 정한 분석인가, 여러 분석 중 하나인가?
  4. 절대 위험은 얼마인가?
  5. 다른 연구에서도 같은 결과가 나왔는가(재현성)?
예제 3.3.1

"새 진통제 복용자의 두통 재발이 50% 줄었다(p = 0.04, 참가자 40명)." 비판해 보세요.

풀이. 절대 수치가 없습니다(재발 4명 → 2명일 수도). 40명은 작아 신뢰구간이 매우 넓을 것이고, p = 0.04는 여러 결과 지표 중 하나만 고른 것일 수 있습니다. 무작위 배정과 맹검 여부, 다른 연구의 재현 여부를 확인해야 합니다. 작은 연구에서 유의하게 나온 효과는 실제보다 과대 추정되기 쉽습니다(승자의 저주).

요약
  1. p-해킹과 출판 치우침은 거짓 양성을 늘립니다.
  2. 효과 크기, 절대 위험, 신뢰구간, 설계를 함께 봅니다.
  3. 재현된 결과를 더 믿습니다.

3.3.3연습문제

응용

  1. 귀무가설이 참인 연구 100개 중 유의한 5개만 출판되면, 출판된 연구의 효과 추정값은 어떤 모습일까요?
    답

    모두 우연히 큰 값이 나온 것들이라 실제 효과(0)보다 크게 치우칩니다. 메타분석에서 깔때기 그림의 비대칭으로 드러납니다.
