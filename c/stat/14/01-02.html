이론을 실험으로 확인하기

표본분포는 "표본을 되풀이해 뽑으면"이라는 상상 위에 서 있습니다. 컴퓨터로 그 상상을 실제로 해 볼 수 있습니다. 이론이 맞는지, 근사가 언제 깨지는지 직접 확인하는 습관은 응용 통계가의 기본기입니다.

1.2.1기본 틀

set.seed(1)
B <- 10000; n <- 20
stat <- replicate(B, {
  x <- rexp(n, rate = 1)        # 1. 모집단에서 표본 생성
  median(x)                     # 2. 통계량 계산
})
mean(stat); sd(stat)            # 3. 표본분포 요약
hist(stat, breaks = 50)

세 단계(생성 → 계산 → 요약)만 바꾸면 거의 모든 통계량에 쓸 수 있습니다. 반복 수 \(B\)가 클수록 모의실험 오차가 작아집니다. 비율을 추정한다면 그 표준오차는 \(\sqrt{p(1-p)/B}\)로, \(B = 10000\)이면 약 ±0.005입니다.

1.2.2이론과 비교하기

예제 1.2.1

지수분포(평균 1) 표본 20개의 중앙값의 표준오차를 모의실험으로 구하고, 큰 표본 근사 \(\frac{1}{2f(m)\sqrt n}\)과 비교하세요.

풀이. 모집단 중앙값 \(m = \ln 2\), \(f(m) = e^{-\ln2} = 0.5\). 근사 표준오차 \(1/(2 \times 0.5 \times \sqrt{20}) = 0.224\). 위 코드의 sd(stat)은 0.222로 거의 같습니다. 평균은 약 0.72로 \(\ln2 = 0.693\)보다 조금 큰데, 표본 중앙값이 작은 표본에서 약간 치우치기 때문입니다.

요약
  1. 생성 → 계산 → 요약을 replicate로.
  2. set.seed로 재현 가능하게.
  3. 이론값과 비교해 근사의 질을 확인합니다.

1.2.3연습문제

응용

  1. 정규 표본 \(n = 10\)에서 \(s^2\)의 표본분포를 모의실험으로 그리고 \(\sigma^2\chi^2_9/9\)와 겹쳐 그리세요.
    답

    s2 <- replicate(1e4, var(rnorm(10))); hist(s2, freq = FALSE, 50); curve(9 * dchisq(9 * x, 9), add = TRUE). 오른쪽으로 치우친 모양이 잘 맞습니다.

1.2.2

실습평균과 중앙값, 어느 쪽이 더 정밀한가?

실습 · 통계량의 표본분포

다루는 성취기준 [응통14-01-02] [응통14-04-02]

목표

같은 모집단에서 표본을 3000번 뽑아 표본평균과 표본중앙값의 표본분포를 겹쳐 그립니다. 정규분포에서는 평균이 더 정밀하지만, 꼬리가 두껍거나 이상값이 섞인 모집단에서는 중앙값이 더 정밀해지는 것을 확인합니다. 공식이 없는 통계량도 모의실험으로 표본분포를 볼 수 있다는 것이 핵심입니다. 성취기준 [응통14-01-02], [응통14-04-02].

상대 효율: 두 추정량의 분산 비. \(\mathrm{Var}(\text{중앙값})/\mathrm{Var}(\text{평균})\)이 1보다 크면 평균이 같은 정밀도를 더 적은 표본으로 얻습니다.

준비

세 모집단은 모두 0을 중심으로 대칭이라 평균과 중앙값이 같은 값(0)을 추정합니다. 회색 막대가 표본평균, 파란 막대가 표본중앙값의 분포입니다(가상 자료). 오염 정규는 95%는 표준정규, 5%는 표준편차 10인 정규에서 나온 값으로, 측정값 가운데 가끔 엉터리가 섞이는 상황을 흉내 냅니다.

절차

  1. 정규분포, \(n = 25\)에서 두 표준편차와 분산 비를 적습니다.
  2. \(n\)을 100으로 바꾸어 분산 비가 어디에 가까워지는지 봅니다.
  3. 모집단을 t 분포, 오염 정규로 바꾸어 같은 일을 합니다. 어느 쪽이 더 넓게 퍼지나요?
  4. "새 모의실험"을 몇 번 눌러 분산 비가 얼마나 흔들리는지 확인합니다.

기대 결과

  • 정규분포에서는 분산 비가 1.4~1.6 근처로, 평균이 더 정밀합니다. 큰 \(n\)에서는 이론값 \(\pi/2 \approx 1.571\)에 가까워집니다. 평균의 표준편차는 \(1/\sqrt n\)(\(n = 25\)에서 0.2)과 맞습니다.
  • t 분포(자유도 3)에서는 분산 비가 1보다 작아져(대략 0.6~0.7) 중앙값이 더 정밀합니다. 두꺼운 꼬리의 극단값이 평균을 흔들기 때문입니다.
  • 오염 정규에서는 평균의 표준편차가 크게 늘어(이론 분산 \((0.95 + 0.05\times100)/n = 5.95/n\)) 분산 비가 0.3 안팎까지 떨어집니다. 이상값 몇 개가 평균을 크게 움직입니다.
  • 3000번 반복이라 분산 비는 ±0.05 정도 흔들립니다.

분석

  1. 자료에 이상값이 섞였을 가능성이 있다면 평균과 중앙값 가운데 무엇을 보고하는 것이 좋을까요? 그 대가는 무엇인가요?
  2. 이 결과는 응통12-07-01의 점근 상대 효율(정규에서 부호검정 0.64, 윌콕슨 0.955)과 어떻게 이어지나요?
  3. 절사평균은 두 통계량의 중간입니다. 어떤 모집단에서 가장 좋을지 예측해 보세요.
