5.R.1

연습미분 해석 단원 마무리 연습

문제 6 · 개념·계산·판단·도전 · 힌트 2단계

다루는 성취기준 [기계5-05-01] [기계5-05-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념유동함수 등고선(유선)을 일정한 \(\psi\) 간격으로 그렸을 때, 유선이 촘촘한 곳이 빠른 이유는 무엇인가요? [05-01]

    힌트 1

    이웃한 두 유선 사이의 유량은 얼마인가요? 5.1절

    힌트 2

    유량 = 속도 × 폭.

    풀이

    이웃한 두 유선 사이로는 어디서나 같은 유량 \(\Delta\psi\)가 흐릅니다. 간격(폭)이 좁으면 같은 유량을 통과시키려고 속도가 커야 합니다: \(V \approx \Delta\psi/\text{간격}\).

  2. 계산2차원 비압축성 흐름에서 \(u = 2xy\)이고 \(y = 0\)에서 \(v = 0\)이다. \(v\), 유동함수, 와도를 구하여라. [05-01]

    힌트 1

    연속 방정식 \(\partial v/\partial y = -\partial u/\partial x\).

    힌트 2

    \(\psi\)는 \(u = \psi_y\)를 \(y\)로 적분하고 \(v = -\psi_x\)로 \(x\)의 함수 부분을 정합니다.

    풀이

    \(\partial v/\partial y = -2y\), \(v = -y^2\). \(\psi = xy^2 + g(x)\), \(-\psi_x = -y^2 - g' = -y^2\)에서 \(g' = 0\), \(\psi = xy^2\). 와도 \(v_x - u_y = 0 - 2x = -2x\)로 회전 흐름입니다.

  3. 계산공기(1.2 kg/m³)가 5 m/s로 원주를 지난다. 퍼텐셜 유동으로 보면 원주 꼭대기의 압력은 멀리 앞쪽의 압력보다 얼마나 낮은가요? [05-01]

    힌트 1

    퍼텐셜 유동 탐구에서 원주 표면 속도는 \(2U\sin\theta\)입니다.

    힌트 2

    비회전 흐름이라 Bernoulli 식을 씁니다.

    풀이

    꼭대기 속도 \(2U = 10\) m/s. \(\Delta P = \tfrac12(1.2)(10^2 - 5^2) = 45\) Pa 낮습니다(\(C_p = -3\)). 실제로는 박리 때문에 이보다 덜 낮습니다.

  4. 판단한 학생이 지름 5 cm 수도관에 물이 2 m/s로 흐를 때의 압력 강하를 Hagen-Poiseuille 식으로 구했다. 맞나요? [05-02]

    힌트 1

    식의 가정을 다시 보세요. 5.2절

    힌트 2

    \(\text{Re} = VD/\nu\), 물 \(\nu = 10^{-6}\) m²/s.

    풀이

    \(\text{Re} = 2\times0.05/10^{-6} = 10^5\)으로 2300보다 훨씬 커서 난류입니다. Hagen-Poiseuille 식은 층류에서만 성립하므로 틀립니다. 난류 마찰계수(Moody 선도, 7.1절)로 Darcy 식을 써야 하며, 실제 손실이 층류 식보다 수십 배 큽니다.

  5. 계산지름 50 mm, 길이 60 mm 축이 틈새 0.05 mm인 미끄럼 베어링 안에서 3000 rpm으로 돈다. 기름 점도 0.03 Pa·s일 때 마찰 토크와 손실 동력은? [05-02]

    힌트 1

    틈새가 반지름보다 훨씬 작아 평판 Couette 유동으로 봅니다.

    힌트 2

    \(U = \omega R = 7.85\) m/s, \(\tau = \mu U/h\).

    풀이

    \(\tau = 0.03\times7.85/(5\times10^{-5}) = 4712\) Pa. 넓이 \(\pi DL = 9.42\times10^{-3}\) m², 힘 44.4 N, 토크 \(44.4\times0.025 = 1.11\) N·m, 동력 \(1.11\times314.2 = 349\) W. 이 열이 기름 온도를 올려 점도를 낮춥니다.

  6. 도전수직 벽을 따라 두께 \(h = 0.5\) mm인 물막이 정상적으로 흘러내린다. N-S 식으로 속도 분포와 폭 1 m당 유량을 구하여라(\(\mu = 10^{-3}\) Pa·s, 자유 표면의 전단 응력 0, 막 안의 압력은 대기압으로 일정). [05-02]

    힌트 1

    벽에서 바깥으로 \(y\), 아래로 \(x\). 압력 기울기 대신 중력이 민다: \(0 = \mu u'' + \rho g\).

    힌트 2

    경계 조건: \(u(0) = 0\), \(u'(h) = 0\).

    풀이

    \(u = \frac{\rho g}{2\mu}(2hy - y^2)\). 표면 속도 \(\rho gh^2/(2\mu) = 1.23\) m/s, 유량 \(q = \rho gh^3/(3\mu) = 4.09\times10^{-4}\) m²/s(0.41 L/s), 평균 속도 0.82 m/s. 두께의 세제곱에 비례하므로 유량이 조금만 늘어도 막은 거의 두꺼워지지 않습니다.
