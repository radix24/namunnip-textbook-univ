4.4.1수두 형태의 에너지 방정식

열역학 5.1절의 정상유동 에너지 식은 4.1절의 RTT에 \(B = E\)를 넣은 것입니다. 비압축성 액체에서 입구 1과 출구 2 사이에 쓰고 \(\dot mg\)로 나누면 모든 항이 길이(수두)가 됩니다.

손실이 있는 에너지 방정식 \[\frac{P_1}{\rho g} + \frac{V_1^2}{2g} + z_1 + h_p = \frac{P_2}{\rho g} + \frac{V_2^2}{2g} + z_2 + h_t + h_L\]

\(h_p\): 펌프가 유체에 준 양정, \(h_t\): 터빈이 뽑아낸 양정, \(h_L\): 마찰로 열이 된 손실 수두. 펌프·터빈·손실이 없으면 Bernoulli 식이다.

손실 \(h_L\)의 정체는 열역학의 내부 에너지 증가와 열 방출입니다. 마찰로 역학적 에너지가 열이 되어 되돌아오지 않으므로(엔트로피 생성) 늘 \(h_L \ge 0\)입니다. 엄밀히는 단면의 속도 분포가 균일하지 않아 운동 에너지 항에 보정 계수 \(\alpha\)(층류 2, 난류 약 1.05)를 곱하지만, 난류 배관에서는 보통 1로 둡니다.

4.4.2손실 수두

주 손실(마찰 손실): 곧은 관 벽의 마찰. Darcy-Weisbach 식 \(h_f = f\dfrac{L}{D}\dfrac{V^2}{2g}\). 마찰계수 \(f\)는 레이놀즈수와 벽 거칠기로 정해진다(7.1절, Moody 선도).

부차 손실: 입구, 곡관, 밸브, 급확대처럼 흐름이 흐트러지는 곳. \(h_m = K\dfrac{V^2}{2g}\), 손실계수 \(K\)는 표에서 읽는다.

대표적인 \(K\): 날카로운 입구 0.5, 둥근 입구 0.03, 90° 엘보 0.3~1.5, 열린 게이트 밸브 0.15, 열린 글로브 밸브 약 10, 탱크로 나가는 출구 1(분류의 운동 에너지가 모두 흩어짐). 긴 관에서는 주 손실이, 짧고 부속이 많은 관에서는 부차 손실이 큽니다.

4.4.3펌프가 있는 배관

예제 4.4.1 (옥상 물탱크로 퍼 올리기)

지하 저수조의 물을 20 m 위 옥상 탱크로 0.02 m³/s 퍼 올린다. 관은 지름 10 cm, 길이 100 m, \(f = 0.02\). 부차 손실계수의 합은 입구 0.5, 엘보 4개 2.0, 밸브 1.5, 출구 1로 5이다. 펌프 양정과 동력(효율 75%)은?

풀이. 1, 2를 두 탱크의 수면으로 잡으면 \(P_1 = P_2 = 0\)(계기), \(V_1 = V_2 \approx 0\), \(z_2 - z_1 = 20\) m. 에너지 식은 \(h_p = 20 + h_L\)로 줄어듭니다.

  1. 관 속 속도 \(V = 0.02/(\pi\times0.1^2/4) = 2.55\) m/s, 속도 수두 \(V^2/2g = 0.331\) m.
  2. \(h_L = (fL/D + \sum K)V^2/2g = (20 + 5)\times0.331 = 8.26\) m.
  3. \(h_p = 28.3\) m. 유체가 받는 동력 \(\rho gQh_p = 9810\times0.02\times28.3 = 5.55\) kW, 축동력 \(5.55/0.75 = 7.39\) kW.

손실이 양정의 29%를 차지합니다. 관 지름을 12.5 cm로 키우면 속도 수두가 \((10/12.5)^4 = 0.41\)배가 되어 손실이 크게 줄지만 관값이 오릅니다. 이 균형이 배관 설계의 핵심입니다(응용유체역학 1.2절).

주의(1) 두 탱크의 수면을 1, 2로 잡으면 압력과 속도가 사라져 식이 간단해집니다. 대신 출구 손실 \(K = 1\)을 빠뜨리면 안 됩니다. (2) 손실은 유량의 제곱에 비례하므로 유량을 두 배로 하면 손실은 네 배입니다. (3) \(h_p\)는 유체가 받은 양정이고, 모터 동력은 효율로 나눕니다.
요약
  1. \(P/\rho g + V^2/2g + z\)에 펌프 양정을 더하고 터빈 양정과 손실을 빼면 하류의 값이 된다.
  2. 주 손실 \(f(L/D)V^2/2g\), 부차 손실 \(KV^2/2g\).
  3. 펌프 동력 \(\rho gQh_p/\eta\).

4.4.4연습문제

기본

  1. 지름 5 cm, 길이 30 m 관에 물이 2 m/s로 흐르고 \(f = 0.025\)이다. 마찰 손실 수두와 압력 강하는?
    답

    \(h_f = 0.025\times600\times0.204 = 3.06\) m, \(\Delta P = \rho gh_f = 30.0\) kPa.

응용

  1. 예제 4.4.1에서 유량을 0.03 m³/s로 늘리면 필요한 축동력은?
    답

    손실 \(8.26\times2.25 = 18.6\) m, \(h_p = 38.6\) m, \(9810\times0.03\times38.6/0.75 = 15.1\) kW(유량 1.5배에 동력 2.05배).

심화

  1. 높이 차 50 m인 저수지에서 지름 0.5 m, 길이 1 km 관(\(f = 0.015\), 부차 손실 무시)으로 물을 떨어뜨려 터빈을 돌린다. 유량이 0.5 m³/s일 때 터빈 양정과 동력(효율 90%)은?
    답

    \(V = 2.55\) m/s, \(h_L = 0.015\times2000\times0.331 = 9.93\) m, \(h_t = 40.1\) m, \(0.9\times9810\times0.5\times40.1 = 177\) kW.

4.4.2

예제높이 차만으로 관에 얼마나 흐를까?

예제 · 손실이 있는 에너지 식 · 유량 구하기

다루는 성취기준 [기계5-04-04]

문제 해결 전략 · 배관 에너지 식
  1. 압력과 속도를 아는 두 점(보통 탱크 수면, 대기로 나가는 출구)을 1, 2로 잡는다.
  2. \(P/\rho g + V^2/2g + z\)를 양쪽에 쓰고, 펌프 양정, 터빈 양정, 손실을 넣는다.
  3. 손실을 \((fL/D + \sum K)V^2/2g\)로 써서 모르는 것(유량, 양정, 지름)을 푼다.
  4. \(f\)가 레이놀즈수에 따라 변하면 \(f\)를 가정하고 속도를 구한 뒤 다시 \(f\)를 고친다(7.1절).
먼저 예상해 보기. 높이 차 10 m로 물을 떨어뜨리면 토리첼리 식으로는 14 m/s입니다. 길이 50 m 관을 달면 얼마나 줄어들까요?

문제. 수면 높이 차가 10 m인 두 탱크를 지름 5 cm, 길이 50 m 관으로 잇는다. \(f = 0.02\), 날카로운 입구 \(K = 0.5\), 출구 \(K = 1\). 유량은? 관 지름을 두 배로 하면?

전략

두 수면에서 압력은 대기, 속도는 0이므로 높이 차가 모두 손실이 됩니다: \(\Delta z = h_L\). 손실이 \(V^2\)에 비례하므로 \(V\)를 바로 풀 수 있습니다.

풀이

  1. \(10 = (fL/D + 0.5 + 1)\dfrac{V^2}{2g}\), \(fL/D = 0.02\times50/0.05 = 20\).
    4.4절 에너지 식, 펌프·터빈 없음.
  2. \(V = \sqrt{2\times9.81\times10/21.5} = 3.02\) m/s.
    계수의 합 21.5.
  3. \(Q = 3.02\times\pi(0.05)^2/4 = 5.93\times10^{-3}\) m³/s (5.9 L/s).
    연속 방정식.
  4. 지름 10 cm: \(fL/D = 10\), \(V = \sqrt{196.2/11.5} = 4.13\) m/s, \(Q = 32.4\) L/s.
    같은 식, \(f\)는 같다고 가정.

의미

관을 달자 속도가 토리첼리 값 14.0 m/s의 22%로 줄었습니다. 마찰이 높이 차 대부분을 먹습니다. 지름을 두 배로 하면 넓이가 4배, 속도도 1.37배로 늘어 유량은 5.5배가 됩니다. 긴 관에서 유량은 대략 \(D^{2.5}\)에 비례하므로, 상수도 본관은 지름을 조금만 키워도 수송량이 크게 늡니다.

검산

손실 \(21.5\times3.02^2/19.62 = 10.0\) m로 높이 차와 같습니다. 레이놀즈수 \(VD/\nu = 3.02\times0.05/10^{-6} = 1.5\times10^5\)로 난류라, \(f = 0.02\)는 매끈한 관에 맞는 크기입니다(7.1절).

바꿔 보기

관 끝을 아래 탱크에 넣지 않고 대기로 그대로 뿜으면, 출구 손실 \(K = 1\) 대신 출구의 속도 수두 \(V^2/2g\)가 에너지 식의 오른쪽에 남습니다. 계수가 같아(1) 답이 같습니다.

이해 확인

원래 관(5 cm) 중간에 열린 글로브 밸브(\(K = 10\))를 달면 유량은?

답

계수 합 31.5, \(V = 2.50\) m/s, \(Q = 4.9\) L/s.
