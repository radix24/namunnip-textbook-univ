3.1.1기능으로 생각하기

"거치대는 플라스틱 집게다"라고 생각하면 집게 말고는 떠오르지 않습니다. "거치대는 휴대폰을 핸들에 대해 정해진 위치에 붙잡아 둔다"라고 기능으로 쓰면, 붙잡는 방법(집게, 밴드, 자석, 흡착)이 열립니다. 기능은 보통 동사 + 명사로 씁니다: "휴대폰을 붙잡는다", "진동을 줄인다", "각도를 바꾼다".

3.1.2블랙박스와 세 가지 흐름

먼저 제품 전체를 속이 보이지 않는 상자(블랙박스) 하나로 그리고, 들어가고 나오는 것을 화살표로 적습니다.

물질: 휴대폰, 손, 물, 공기 등 실제로 움직이는 것.

에너지: 손힘, 전기, 진동, 열.

신호(정보): 버튼 누름, 센서 값, 표시.

거치대의 블랙박스: 휴대폰(물질)과 손힘(에너지)이 들어가 "고정된 휴대폰"이 나오고, 자전거 진동(에너지)이 들어오지만 휴대폰에는 덜 전달되어야 합니다.

3.1.3하위 기능으로 나누기

블랙박스 안을 흐름을 따라가며 나눕니다.

  1. 핸들에 붙는다(장착부 고정).
  2. 휴대폰을 받는다(위치를 잡는다).
  3. 휴대폰을 잡는다(고정력을 만든다).
  4. 잡은 것을 풀어 준다(손힘을 받아 연다).
  5. 진동을 줄인다.
  6. 보는 각도를 바꾼다.

상자들을 흐름 화살표로 이으면 기능 구조도가 됩니다. 손힘은 4번으로, 진동은 1번에서 5번을 거쳐 휴대폰으로 가는 식입니다. 너무 잘게 나누면(나사를 돌린다 수준) 해법이 정해져 버리고, 너무 굵으면 해법을 찾기 어렵습니다. 하위 기능 하나에 해법이 3~5개 떠오르는 정도가 알맞습니다.

3.1.4하위 기능별 해결안

각 하위 기능에 2.1절의 발상 기법을 따로 적용해 해법을 찾고, 그 결과를 형태 분석표의 줄로 씁니다. 해법은 다른 분야의 제품에서 빌려 오는 경우가 많습니다: "진동을 줄인다"는 자동차 엔진 마운트(고무), 카메라 짐벌(관성), 신발 깔창(젤)에서 아이디어를 얻습니다.

주의(1) 기능은 해법을 숨기는 말로 씁니다("스프링으로 누른다"가 아니라 "고정력을 만든다"). (2) 사용자가 하는 동작도 흐름에 넣습니다(손힘, 보는 시선). (3) 안전 기능("날카로운 부분을 손에서 떨어뜨린다")도 빼먹지 마세요.
요약
  1. 기능 = 동사 + 명사, 해법을 숨긴 말.
  2. 블랙박스 → 물질, 에너지, 신호 흐름 → 하위 기능 → 기능 구조도.
  3. 하위 기능별 해법을 모아 형태 분석표를 만든다.

3.1.5연습문제

기본

  1. "전동 드릴"의 블랙박스 입출력을 물질, 에너지, 신호로 써라.
    답

    입력: 전기(에너지), 손힘(에너지), 방아쇠 누름(신호), 드릴 날과 공작물(물질). 출력: 구멍 난 공작물과 칩(물질), 열·소리(에너지).

응용

  1. 1.1절 예제의 화분 자동 급수기를 하위 기능 4~6개로 나누어라.
    답

    예: 물을 저장한다, 물을 흙으로 옮긴다, 공급량을 조절한다, 장치를 화분에 고정한다, 남은 물을 보여 준다.

심화

  1. 문제 2의 "공급량을 조절한다"에 대해 해법 세 가지를 들고, 그중 하나가 다른 하위 기능을 함께 해결하는 경우를 찾아라.
    답

    예: 구멍 크기, 심지 굵기, 흙 수분에 따라 스스로 조절되는 심지. 심지는 "물을 옮긴다"와 "조절한다"를 동시에 한다. 한 해법이 여러 기능을 맡으면 부품이 줄지만, 두 기능을 따로 조정하기 어려워진다.

3.1.2

예제전동 연필깎이의 기능 구조도 그리기

예제 · 블랙박스 · 하위 기능 · 해법 찾기

다루는 성취기준 [기계1-03-01]

문제 해결 전략 · 기능 분해
  1. 블랙박스의 입력과 출력을 물질, 에너지, 신호로 적는다.
  2. 흐름을 따라가며 "무엇이 일어나야 하는가"를 동사 + 명사로 쓴다.
  3. 하위 기능을 화살표로 잇고, 각 기능에 해법을 3개 이상 찾는다.
먼저 예상해 보기. 연필깎이가 하는 일은 "연필을 깎는다" 하나뿐일까요?

문제. 연필을 꽂으면 저절로 깎고 다 깎이면 멈추는 전동 연필깎이의 기능 구조도를 그리고, 하위 기능 두 개의 해법을 찾아라.

전략

"연필을 깎는다"는 블랙박스 전체입니다. 그 안에서 물질(연필, 깎인 부스러기), 에너지(전기 → 회전), 신호(꽂힘, 다 깎임)가 어떻게 흐르는지 따라가면 하위 기능이 드러납니다.

풀이

  1. 블랙박스: 입력 — 무딘 연필(물질), 전기(에너지), 꽂음 동작(신호). 출력 — 뾰족한 연필, 부스러기(물질), 소리·열(에너지).
    세 흐름.
  2. 하위 기능: 연필을 받아 정렬한다 → 연필이 꽂힌 것을 감지한다 → 전기를 회전으로 바꾼다 → 연필 둘레를 깎는다 → 다 깎인 것을 감지해 멈춘다 → 부스러기를 모은다.
    흐름 순서대로.
  3. "꽂힘을 감지한다"의 해법: 누름 스위치, 광센서, 연필 지름으로 벌어지는 집게.
    신호 흐름.
  4. "다 깎인 것을 감지한다"의 해법: 깎는 힘(모터 전류)이 줄어드는 것 감지, 연필 끝이 정해진 위치를 지나면 스위치, 정해진 시간 타이머.
    세 원리가 다르다.

의미

"깎는다" 하나로 보면 칼날 모양만 고민하게 되지만, 기능으로 나누면 감지, 정렬, 수거처럼 사용자 만족을 좌우하는 기능들이 드러납니다. 실제 불만은 칼날보다 "너무 많이 깎여 연필이 빨리 닳는다"(멈춤 감지)에서 많이 나옵니다. 각 줄의 해법은 2.1절 형태 분석표의 줄이 됩니다.

검산

블랙박스의 모든 입력이 어떤 하위 기능에서 쓰이고, 모든 출력이 어떤 하위 기능에서 만들어지는지 확인합니다. 부스러기(출력)를 다루는 기능이 빠져 있다면 구조도가 덜 된 것입니다.

이해 확인

안전을 위해 더할 하위 기능 하나와 그 해법은?

답

"손가락이 칼날에 닿지 않게 한다": 연필 지름보다 작은 입구, 뚜껑이 열리면 전원 차단 스위치.
