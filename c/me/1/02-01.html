2.1.1왜 많이 내야 할까

처음 떠오른 아이디어는 대개 이미 있는 제품을 닮았습니다. 좋은 개념은 수십 개의 아이디어 가운데서 나오는 경우가 많고, 버려진 아이디어의 일부가 합쳐져 생기기도 합니다. 그래서 개념 설계는 두 단계로 나눕니다.

발산: 판단을 미루고 아이디어를 최대한 많이, 다양하게 낸다.

수렴: 기준을 정해 비교하고 고른다(3단원).

두 단계를 섞으면 "그건 안 될 거야"라는 말이 새 아이디어를 막습니다.

2.1.2브레인스토밍

팀이 모여 짧은 시간(15~30분)에 아이디어를 쏟아내는 방법입니다. 규칙은 네 가지입니다.

  1. 비판 금지: 평가는 나중에.
  2. 양이 질을 낳는다: 목표 개수를 정한다(예: 30개).
  3. 엉뚱한 아이디어 환영: 현실성 없는 아이디어가 다른 사람의 좋은 아이디어를 끌어낸다.
  4. 남의 아이디어에 덧붙이기: "그것에 더해서…"로 발전시킨다.

목소리 큰 사람이 주도하는 것을 막으려면, 먼저 각자 5분 동안 포스트잇에 혼자 쓰고 나서 모아 붙이는 방식(브레인라이팅)이 효과적입니다. 스케치로 그리면 말보다 오해가 적습니다.

2.1.3SCAMPER

이미 있는 제품을 바꾸어 볼 일곱 가지 질문입니다. 거치대(1.1절)에 적용해 봅니다.

  • Substitute(대체): 다른 재료·원리로 바꾸면? → 집게 대신 진공 흡착판.
  • Combine(결합): 다른 기능과 합치면? → 거치대 + 보조 배터리, 거치대 + 전조등.
  • Adapt(적용): 다른 분야의 해법을 빌리면? → 스키 바인딩처럼 밟아서 잠그는 방식.
  • Modify(변형): 크기·모양을 바꾸면? → 휴대폰 모서리 네 곳만 잡는 작은 고리.
  • Put to other uses(다른 용도): 유모차, 러닝머신, 쇼핑 카트에도?
  • Eliminate(제거): 부품을 없애면? → 별도 거치대 없이 휴대폰 케이스 자체에 결합부.
  • Rearrange/Reverse(재배치·반대로): 순서나 방향을 바꾸면? → 휴대폰을 핸들 아래로 매달기.

2.1.4형태 분석표

제품이 해야 할 일을 하위 기능으로 나누고(3.1절에서 자세히), 기능마다 가능한 해법을 표의 한 줄에 나열합니다. 각 줄에서 하나씩 골라 조합하면 체계적으로 많은 개념안이 생깁니다.

  • 휴대폰 잡기: 집게, 고무 밴드, 자석, 케이스 결합, 흡착판 (5가지)
  • 핸들에 고정: 고무 밴드, 나사 클램프, 퀵릴리즈 레버, 케이블 타이 (4가지)
  • 방향 조절: 볼 조인트, 회전판, 고정 (3가지)
  • 충격 흡수: 없음, 고무 패드, 스프링 (3가지)

조합의 수는 곱의 법칙으로 \(5\times4\times3\times3 = 180\)가지입니다. 물론 모두 쓸 만하지는 않지만(흡착판 + 강한 진동), 혼자서는 떠올리지 못했을 조합이 나옵니다(형태 분석표 실습).

주의(1) 발산 단계에서 "비싸다, 어렵다"를 말하지 마세요. (2) 아이디어는 모두 기록합니다. 나중에 다른 문제에서 쓸모가 생깁니다. (3) 개념안은 말보다 간단한 스케치와 한 줄 설명으로 남기면 비교가 쉽습니다.
요약
  1. 발산(많이) → 수렴(고르기)을 나눈다.
  2. 브레인스토밍 네 규칙, 혼자 먼저 쓰는 브레인라이팅.
  3. SCAMPER 일곱 질문, 형태 분석표로 조합(곱의 법칙).

2.1.5연습문제

기본

  1. 하위 기능이 셋이고 각각 해법이 4, 3, 5가지이면 형태 분석표의 조합은 몇 가지인가?
    답

    \(4\times3\times5 = 60\)가지.

응용

  1. 텀블러에 SCAMPER의 세 질문을 적용해 개념안을 하나씩 내라.
    답

    예: 대체 — 이중벽 진공 대신 접이식 실리콘. 결합 — 텀블러 + 온도 표시. 제거 — 뚜껑 없이 흘림 방지 구조. 답은 여러 가지.

심화

  1. 거치대 형태 분석표에서 서로 맞지 않는 조합의 예를 두 개 들고 이유를 쓰라. 이런 조합을 빼면 개념안의 수는 어떻게 세는가?
    답

    예: 흡착판 + 충격 흡수 없음(진동에 쉽게 떨어짐), 자석 + 케이스 결합 없음(휴대폰에 철판이 필요). 맞지 않는 조합의 수를 세어 전체에서 빼거나(여사건), 조건을 두고 경우를 나누어 센다.

2.1.2

실습형태 분석표로 개념안 조합하기

실습 · 형태 분석표 · 곱의 법칙

다루는 성취기준 [기계1-02-01]

질문

2.1.4의 거치대 형태 분석표에서 하위 기능마다 해법을 하나씩 골라 개념안을 만듭니다. 전체 조합이 몇 가지인지, 서로 맞지 않는 조합을 빼면 몇 가지가 남는지 셉니다. "무작위 조합"을 눌러 스스로는 떠올리지 못했을 조합도 살펴보세요.

해 보기와 설명

  1. 조합의 수\(5\times4\times3\times3 = 180\)가지입니다. 맞지 않는 조합을 정한 세 규칙(흡착판에 충격 흡수 없음, 케이블 타이에 방향 조절, 자석에 스프링)에 걸리는 50가지를 빼면 130가지가 남습니다. 여러 규칙에 함께 걸리는 조합은 한 번만 셉니다.
  2. 규칙은 판단이다"자석 + 스프링"은 금지가 아니라 시험이 필요한 조합입니다. 발산 단계에서는 너무 일찍 지우지 말고, 지운 이유를 기록합니다.
  3. 무작위 조합"케이스 결합 + 퀵릴리즈 레버 + 회전판 + 고무 패드"처럼 기존 제품과 다른 조합이 나오면 스케치해 개념안 목록에 더합니다.

연결과 적용

하위 기능을 어떻게 나누는지는 3.1절 기능 구조도에서 다룹니다. 남은 개념안 수십 개를 모두 시제품으로 만들 수는 없으므로, 3.2절의 평가 행렬로 몇 개로 좁힙니다. 고등학교 수학의 곱의 법칙과 여사건 세기가 그대로 쓰입니다.

흔한 오해

  • "조합이 많으면 좋은 개념이 저절로 나온다." 조합은 재료일 뿐이고, 사용자 요구로 걸러야 합니다.
  • "각 줄에서 가장 좋은 해법을 고르면 최선의 개념이다." 해법끼리 잘 맞는지(조합 효과)가 더 중요할 때가 많습니다.
