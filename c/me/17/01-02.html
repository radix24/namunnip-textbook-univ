1.2.1

탐구네 막대의 길이만 보고 어느 링크가 한 바퀴 도는지 알 수 있을까?

탐구 · 4절 링크의 Grashof 조건, 커플러 곡선, 전달각

다루는 성취기준 [기계17-01-02] [기계17-02-01]

질문

4절 링크는 지면(고정 링크), 입력 크랭크, 커플러, 출력 로커 네 막대를 핀으로 이은 기구입니다. 자동차 와이퍼, 굴삭기 팔, 재봉틀 바늘 구동이 모두 4절 링크입니다. 네 막대의 길이만 보고, 입력 막대가 한 바퀴를 돌 수 있는지, 아니면 왔다 갔다만 하는지 미리 알 수 있을까요?

해 보기와 설명

  1. Grashof 조건가장 짧은 링크 \(s\), 가장 긴 링크 \(l\), 나머지 둘 \(p, q\)에 대해 \(s + l \le p + q\)이면 적어도 한 링크가 다른 링크에 대해 한 바퀴 돌 수 있습니다. 처음 값(4, 1.5, 4, 3)은 \(1.5 + 4 = 5.5 < 7\)이고 가장 짧은 것이 크랭크라서 크랭크가 한 바퀴 돌고 로커는 왕복합니다(크랭크-로커). 재생해 확인하세요.
  2. 어느 링크가 가장 짧은가길이는 그대로 두고 어느 링크를 고정하느냐(가장 짧은 링크의 위치)에 따라 운동이 바뀝니다. d = 1.5, a = 4로 바꿔 지면이 가장 짧게 하면 입력과 출력이 모두 한 바퀴 도는 이중 크랭크가 됩니다.
  3. 비Grashofa = 3, b = 3, c = 3, d = 4.5로 하면 \(3 + 4.5 = 7.5 > 6\)입니다. 이때는 어느 링크도 한 바퀴 돌지 못하고, 재생하면 크랭크가 조립 가능한 끝에서 되돌아옵니다.
  4. 위치 해석크랭크 각 \(\theta_2\)가 정해지면 A점이 정해지고, B점은 "A에서 거리 b"이면서 "O₄에서 거리 c"인 점, 곧 두 원의 교점입니다. 교점은 보통 두 개라서 같은 크랭크 각에 조립 방법(열림·교차)이 둘 있습니다. "조립 바꾸기"로 다른 쪽을 보세요. 이것이 벡터 루프 방정식 \(\vec a + \vec b = \vec d + \vec c\)를 푸는 일과 같습니다([기계17-02-01]).
  5. 커플러 곡선과 전달각커플러 위의 한 점은 직선, 8자, 물방울 같은 다양한 곡선을 그립니다. 점 거리를 바꿔 보세요. 출력의 전달각 \(\mu\)는 커플러와 로커 사이의 각으로, 40°보다 작아지면 커플러가 로커를 돌리는 힘보다 로커 핀을 누르는 힘이 커져 기구가 뻑뻑해집니다.

연결과 적용

Grübler 식으로 4절 링크의 자유도를 세면 \(3(4-1) - 2\times 4 = 1\)입니다([기계17-01-01]). 그래서 크랭크 각 하나만 정하면 나머지가 모두 정해집니다. 동역학의 순간 중심([기계6-04-01])을 쓰면 각 링크의 각속도 비도 그림에서 바로 구할 수 있습니다. 링크 합성([기계17-03-01])은 거꾸로, 원하는 커플러 곡선이나 로커 각을 얻도록 길이를 고르는 일입니다.

흔한 오해

  • "크랭크가 가장 짧으면 늘 한 바퀴 돈다." Grashof 조건 \(s + l \le p + q\)도 함께 만족해야 합니다. a = 1, b = 1.5, c = 1.5, d = 3.5이면 크랭크가 가장 짧아도 \(1 + 3.5 > 3\)이라 돌지 못합니다.
  • "Grashof이면 입력 링크가 돈다." 한 바퀴 도는 것은 가장 짧은 링크입니다. 가장 짧은 링크가 로커 위치에 있으면 출력이 돌고 입력은 왕복합니다.
