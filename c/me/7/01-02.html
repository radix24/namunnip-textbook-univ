1.2.1오차의 두 종류

계통 오차(편향): 같은 방향으로 늘 치우치는 오차. 보정이 틀린 계기, 영점이 어긋난 저울, 센서의 부하 효과. 반복해도 줄지 않고, 보정이나 다른 방법과의 비교로 찾는다.

우연 오차: 잴 때마다 무작위로 흩어지는 오차. 잡음, 눈금 읽기, 작은 환경 변화. 반복해 평균하면 줄어든다.

측정 결과는 "값 ± 불확도(신뢰 수준)"로 씁니다. 불확도는 참값이 있을 법한 범위의 크기입니다. 실험 보고서에서 불확도 없는 숫자는 반쪽 결과입니다.

1.2.2반복 측정의 평균과 신뢰 구간

같은 양을 \(n\)번 재어 \(x_1, \ldots, x_n\)을 얻으면

\[\bar x = \frac1n\sum x_i\] \[s = \sqrt{\frac{1}{n - 1}\sum(x_i - \bar x)^2}\] \[u_{\bar x} = \frac{s}{\sqrt n}\]

입니다. \(s\)는 측정 하나의 흩어짐, \(u_{\bar x}\)(평균의 표준 불확도)는 평균값의 흩어짐입니다. 평균은 \(\sqrt n\)배 덜 흩어집니다. 95% 신뢰 구간은 \(\bar x \pm t\,u_{\bar x}\)이고, \(t\)는 자유도 \(n - 1\)의 t 분포 값입니다(\(n = 5\): 2.776, \(n = 10\): 2.262, \(n = 30\): 2.045, 매우 크면 1.96). 측정 횟수가 적을수록 \(t\)가 커져 구간을 넓게 잡습니다.

예제 1.2.1 (중력 가속도 반복 측정, 가상 자료)

진자로 \(g\)를 열 번 재어 9.81, 9.79, 9.84, 9.80, 9.83, 9.78, 9.82, 9.81, 9.80, 9.83 m/s²를 얻었다. 결과를 95% 신뢰 구간으로 쓰면?

풀이. \(\bar x = 9.811\), \(s = 0.0191\), \(u_{\bar x} = 0.0191/\sqrt{10} = 0.0060\). \(t = 2.262\)이므로 \(g = 9.811 \pm 0.014\) m/s²(95%). 여기에 계기 분해능(0.01, 균일 분포 반폭 0.005, 표준 불확도 \(0.005/\sqrt3 = 0.0029\))을 합치면 \(\sqrt{0.0060^2 + 0.0029^2} = 0.0067\)로 조금 커집니다.

1.2.3불확도 전파

결과 \(R\)이 여러 측정량 \(x_1, x_2, \ldots\)로 계산된다고 합시다(예: 밀도 = 질량 ÷ 부피). 각 측정의 불확도가 결과를 얼마나 흔드는지 알고 싶습니다. 가장 쉬운 방법은 한 번에 하나씩 바꿔 보는 것입니다.

  1. 모든 측정값을 그대로 넣어 \(R\)을 계산한다.
  2. \(x_1\)만 불확도 \(u_1\)만큼 키우고 나머지는 그대로 두어 다시 계산한다. 결과의 변화를 \(\Delta R_1\)이라 한다.
  3. \(x_2\), \(x_3\), …에 대해서도 같은 일을 해 \(\Delta R_2\), \(\Delta R_3\), …를 얻는다.
불확도 전파식 (독립인 입력) \[u_R = \sqrt{\Delta R_1^2 + \Delta R_2^2 + \cdots}\]

불확도가 작으면 \(\Delta R_i\)는 "다른 값은 상수로 두고 \(x_i\)로만 미분한 기울기" × \(u_i\)와 같다. 이 기울기를 편미분 \(\partial R/\partial x_i\)라 하며 대학 미적분에서 배운다.

곱과 거듭제곱 꼴 \(R = Cx_1^ax_2^b\cdots\)이면 상대 불확도로 쓰는 것이 편하다: \(\frac{u_R}{R} = \sqrt{\bigl(a\frac{u_1}{x_1}\bigr)^2 + \bigl(b\frac{u_2}{x_2}\bigr)^2 + \cdots}\).

제곱해서 더하는(RSS) 이유는 독립인 오차들이 서로 일부 상쇄되기 때문입니다. 모두 같은 방향으로 최악이 될 가능성은 낮습니다.

예제 1.2.2 (원기둥의 밀도)

강철 원기둥의 질량 250.0 ± 0.1 g, 지름 25.00 ± 0.02 mm, 길이 60.0 ± 0.1 mm(모두 표준 불확도). 밀도와 불확도는?

풀이. \(\rho = 4m/(\pi D^2L) = 8488\) kg/m³. 상대 불확도는 질량 0.04%, 지름 \(2\times0.08\% = 0.16\%\)(제곱이므로 2배), 길이 0.17%. 합 \(\sqrt{0.04^2 + 0.16^2 + 0.17^2} = 0.23\%\), \(u_\rho = 20\) kg/m³. 결과 \(\rho = 8490 \pm 20\) kg/m³. 지름과 길이가 불확도를 지배하므로 질량을 더 정밀하게 재 봐야 소용이 없고, 지름을 더 좋은 계기로 재야 합니다. 이렇게 어느 측정이 결과를 지배하는지 찾는 것이 전파식의 실용적 쓰임입니다.

주의(1) 반복 측정으로 줄일 수 있는 것은 우연 오차뿐입니다. 계통 오차는 따로 추정해 합칩니다. (2) 불확도는 유효숫자 1~2자리로 쓰고, 결과값의 끝자리를 불확도에 맞춥니다(8488 ± 19.9가 아니라 8490 ± 20). (3) 입력들이 서로 관련되어 있으면(같은 계기로 잰 두 길이의 차) 전파식에 상관 항이 필요합니다.
요약
  1. 계통 오차는 보정으로, 우연 오차는 반복·평균으로 다룬다.
  2. \(u_{\bar x} = s/\sqrt n\), 95% 구간 \(\bar x \pm t_{n-1}u_{\bar x}\).
  3. 하나씩 바꿔 본 결과 변화 \(\Delta R_i\)로 \(u_R = \sqrt{\sum\Delta R_i^2}\), 곱·거듭제곱은 상대 불확도로.

1.2.4연습문제

기본

  1. 전압 12.0 ± 0.1 V, 전류 2.00 ± 0.03 A일 때 전력과 불확도는?
    답

    \(P = 24.0\) W, 상대 \(\sqrt{0.83^2 + 1.5^2} = 1.7\%\), \(P = 24.0 \pm 0.4\) W.

응용

  1. 예제 1.2.1에서 신뢰 구간 반폭을 0.005 m/s² 이하로 줄이려면 대략 몇 번 재야 하는가? (\(s = 0.019\)로 두고 \(t \approx 2\))
    답

    \(2(0.019)/\sqrt n \le 0.005\), \(n \ge 58\). 정밀도를 3배 올리려면 측정을 약 9배 해야 한다.

심화

  1. 진자 주기 \(T\)와 길이 \(L\)로 \(g = 4\pi^2L/T^2\)를 구한다. \(L = 1.000 \pm 0.002\) m, 주기를 20번 진동 시간으로 재어 \(20T = 40.12 \pm 0.10\) s였다. \(g\)와 불확도는? 왜 20번을 한꺼번에 재는가?
    답

    \(T = 2.006 \pm 0.005\) s, \(g = 9.810\). 상대 \(\sqrt{0.2^2 + (2\times0.25)^2} = 0.54\%\), \(g = 9.81 \pm 0.05\) m/s². 초시계의 반응 시간 오차(0.1 s)가 20번에 나뉘어 한 주기의 불확도가 1/20로 준다.

1.2.2

실습몇 번 재야 믿을 수 있을까: 신뢰 구간 실습

실습 · 평균의 불확도 · t 분포 · 계통 오차

다루는 성취기준 [기계7-01-02]

질문

참값 50.000 mm인 블록의 길이를 가상으로 반복 측정합니다(가상 자료, 정규분포 우연 오차 + 일정한 편향). 히스토그램(파랑)과 평균의 95% 신뢰 구간(아래 막대)이 참값(초록 점선)을 품는지 봅니다. 같은 조건의 실험을 1000번 되풀이했을 때 구간이 참값을 품는 비율도 계산합니다.

해 보기와 설명

  1. 포함 확률편향 0이면 n과 σ를 어떻게 바꾸어도 1000번 중 약 95%의 구간이 참값을 품습니다. "95% 신뢰 구간"의 뜻이 이것입니다. 한 번의 실험에서 구간이 참값을 놓치는 일도 20번에 한 번쯤 생깁니다(다시 재기를 여러 번 눌러 보세요).
  2. n을 늘리기n = 10에서 40으로 늘리면 구간 폭이 평균적으로 반쯤으로 줄어듭니다(한 번의 표본에서는 s가 달라 들쭉날쭉합니다)(\(\sqrt n\)). n = 2, 3처럼 아주 적으면 t 값(12.7, 4.3)이 커서 구간이 매우 넓습니다.
  3. 편향 넣기편향 0.03 mm, σ = 0.05, n = 10이면 포함 비율이 약 63%로 떨어지고, n을 100까지 늘리면 구간은 좁아지지만 참값에서 벗어난 곳에 모여 포함 비율이 거의 0%가 됩니다. 반복 측정은 계통 오차를 줄이지 못하고, 오히려 틀린 값을 자신 있게 보고하게 만듭니다.

연결과 적용

계통 오차는 기준 게이지 블록으로 보정하거나 다른 원리의 측정과 비교해 찾습니다. 보고서에는 반복 측정의 불확도(A형)와 계기 사양·보정서에서 온 불확도(B형)를 합쳐 씁니다(1.2절 예제 1.2.1). 몇 번 잴지는 필요한 구간 폭에서 거꾸로 정합니다(1.2절 연습문제 2).

흔한 오해

  • "95% 신뢰 구간이면 참값이 그 안에 있을 확률이 95%다." 참값은 고정되어 있고, 같은 방법으로 구간을 여러 번 만들면 그중 95%가 참값을 품는다는 뜻입니다.
  • "많이 재면 정확해진다." 정밀해질 뿐이며, 편향이 있으면 정확해지지 않습니다.
