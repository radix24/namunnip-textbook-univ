6.3터빈과 압축기의 등엔트로피 효율

먼저 알아야 할 것
  • 엔트로피와 등엔트로피 관계 (6.2절), 정상유동 장치 (5.1절).

6.3.1이상적인 단열 장치

터빈과 압축기는 대개 단열로 볼 수 있습니다. 단열이면 엔트로피 평형은 \(s_2 - s_1 = s_{\text{gen}} \ge 0\)입니다. 마찰 같은 비가역성이 없으면 \(s_2 = s_1\)(등엔트로피)이고, 이것이 같은 입구 상태와 같은 출구 압력에서 터빈이 가장 많은 일을 내고 압축기가 가장 적은 일을 쓰는 이상적인 경우입니다. 실제 장치의 성능을 이 이상과 비교한 것이 등엔트로피 효율입니다.

6.3.2정의

입구 1, 같은 출구 압력에서 등엔트로피로 갔을 때의 출구를 2s, 실제 출구를 2a라 하면

정의 6.3.1 (등엔트로피 효율) \[\eta_T = \frac{\text{실제 일}}{\text{등엔트로피 일}} = \frac{h_1 - h_{2a}}{h_1 - h_{2s}}\] \[\eta_C = \frac{\text{등엔트로피 일}}{\text{실제 일}} = \frac{h_{2s} - h_1}{h_{2a} - h_1}\] \[\eta_N = \frac{\mathcal V_{2a}^2/2}{\mathcal V_{2s}^2/2}\]

분자와 분모의 순서가 장치마다 다른 것에 주의하세요. 효율이 늘 1보다 작게 되도록 "작은 쪽 / 큰 쪽"으로 정했습니다. 터빈은 실제로 덜 내놓고, 압축기는 실제로 더 씁니다. 좋은 대형 터빈과 압축기는 85~92%, 노즐은 95% 이상입니다.

비가역성(마찰, 소용돌이)은 결국 유체를 데우므로 실제 출구의 엔탈피가 등엔트로피 출구보다 높습니다(\(h_{2a} > h_{2s}\)). h-s 선도에서 실제 과정은 세로선(등엔트로피)보다 오른쪽(엔트로피 증가)으로 기웁니다.

예제 6.3.2 (증기 터빈의 효율)

5.1절 예제의 터빈(1 MPa, 300 °C → 10 kPa, 실제 출구 건도 0.90)의 등엔트로피 효율은? (1 MPa, 300 °C: \(s = 7.1246\). 10 kPa: \(s_f = 0.6492\), \(s_{fg} = 7.4996\) kJ/kg·K)

풀이. 등엔트로피 출구: \(s_{2s} = 7.1246\)이므로 \(x_{2s} = (7.1246 - 0.6492)/7.4996 = 0.8634\), \(h_{2s} = 191.81 + 0.8634\times2392.1 = 2257.2\) kJ/kg. 실제 출구 \(h_{2a} = 2344.7\).

\[\eta_T = \frac{3051.6 - 2344.7}{3051.6 - 2257.2} = \frac{706.9}{794.4} = 0.890\]

등엔트로피면 794 kJ/kg를 낼 수 있었는데 707 kJ/kg만 냈습니다. 잃은 87 kJ/kg는 출구 증기를 덜 젖게(건도 0.863 → 0.90) 만드는 데 들어갔습니다.

예제 6.3.3 (공기 압축기)

공기를 100 kPa, 300 K에서 800 kPa로 압축한다. 등엔트로피 효율 85%일 때 필요한 일과 실제 출구 온도는?

풀이. 등엔트로피 출구 온도 \(T_{2s} = 300\times8^{0.4/1.4} = 543.4\) K. 등엔트로피 일 \(w_s = 1.005\times243.4 = 244.6\) kJ/kg. 실제 일 \(w_a = 244.6/0.85 = 287.8\) kJ/kg. 실제 출구 온도 \(T_{2a} = 300 + 287.8/1.005 = 586.4\) K. 효율이 낮을수록 압축 공기가 더 뜨거워지고, 그만큼 일이 더 듭니다.

주의(1) 등엔트로피 출구는 실제 출구와 압력이 같고 엔트로피가 입구와 같은 상태입니다. 온도가 같은 상태가 아닙니다. (2) 터빈과 압축기에서 효율 식의 분자·분모가 반대입니다. (3) 압축기 효율이 낮으면 Brayton 사이클의 순일이 크게 줄어 사이클 전체가 쓸모없어질 수 있습니다(8.1절 실습의 "더 해 보기").
요약
  1. 단열 장치의 이상은 등엔트로피 과정(같은 출구 압력).
  2. \(\eta_T = (h_1 - h_{2a})/(h_1 - h_{2s})\), \(\eta_C = (h_{2s} - h_1)/(h_{2a} - h_1)\).
  3. 비가역성은 출구 엔탈피를 높인다: 터빈은 일이 줄고, 압축기는 일이 늘며 출구가 더 뜨겁다.

6.3.3연습문제

기본

  1. 가스 터빈에서 공기가 1200 K, 1 MPa로 들어가 100 kPa로 팽창한다. 등엔트로피 출구 온도와, 효율 88%일 때 실제 출구 온도는?
    답

    \(T_{2s} = 1200(0.1)^{0.2857} = 621.5\) K. \(T_{2a} = 1200 - 0.88(578.5) = 691.0\) K.

응용

  1. 공기가 400 kPa, 600 K에서 노즐로 들어가(속도 무시) 100 kPa로 나간다. 노즐 효율 92%일 때 출구 속도는?
    답

    \(T_{2s} = 403.8\) K, 실제 \(\Delta h = 0.92\times1.005\times196.2 = 181.4\) kJ/kg, \(\mathcal V = \sqrt{2\times181\,400} = 602\) m/s.

심화

  1. 예제 6.3.2의 터빈에서 단열 과정의 엔트로피 생성(kJ/kg·K)을 구하여라.
    답

    \(s_{2a} = 0.6492 + 0.90\times7.4996 = 7.3988\). \(s_{\text{gen}} = 7.3988 - 7.1246 = 0.274\) kJ/kg·K.

6.3.2

실습효율이 낮은 압축기는 T-s 선도에서 어떻게 보일까?

실습 · 등엔트로피 과정과 실제 과정

다루는 성취기준 [기계3-06-03] [기계3-06-02]

목표

공기 압축기(300 K에서 시작)와 가스 터빈(1200 K에서 시작)의 압력비와 등엔트로피 효율을 바꾸며, T-s 선도에서 이상 과정(세로 점선)과 실제 과정(파란 선)을 비교하고 일과 엔트로피 생성을 계산합니다. 성취기준 [기계3-06-03], [기계3-06-02].

준비

공기는 비열 일정한 이상기체(\(c_p = 1.005\), \(R = 0.287\), \(k = 1.4\))입니다. 연회색 곡선 두 개는 입구·출구 압력의 등압선이고, 엔트로피는 300 K, 100 kPa를 기준으로 \(s = c_p\ln(T/300) - R\ln(P/100)\)로 계산합니다. 등엔트로피 출구는 \(T_{2s} = T_1(P_2/P_1)^{(k-1)/k}\), 실제 출구는 효율의 정의(6.3절)로 구합니다.

절차

  1. 압축기, 압력비 8, 효율 85%에서 출구 온도·일·엔트로피 생성을 적고 6.3절 예제 6.3.3과 비교합니다.
  2. 효율을 100%, 85%, 70%로 바꿔 실제 일과 출구 온도를 표로 적습니다.
  3. 터빈, 압력비 10, 효율 88%로 바꿔 6.3절 연습문제 1과 비교합니다. 효율 70%면 잃은 일은?

기대 결과

  • 압축기(8, 85%): 등엔트로피 출구 543.4 K, 일 244.7 kJ/kg / 실제 586.4 K, 287.8 kJ/kg, 엔트로피 생성 0.0768 kJ/kg·K. 예제와 같습니다.
  • 효율 100%면 실제 선이 점선과 겹치고 생성이 거의 0(비열비 반올림 때문에 0.0003)입니다. 70%면 647.8 K, 349.5 kJ/kg로 일이 43% 더 듭니다.
  • 터빈(10, 88%): 등엔트로피 621.5 K, 581.4 kJ/kg / 실제 691.0 K, 511.6 kJ/kg, 생성 0.106. 효율 70%면 406.9 kJ/kg로 174.5 kJ/kg를 잃습니다.
  • 압축기의 실제 선은 점선의 오른쪽 위, 터빈의 실제 선은 점선의 오른쪽 위(덜 식음)로 기웁니다. 둘 다 엔트로피가 늘어나는 쪽입니다.

분석

  1. 압축기와 터빈 모두 실제 출구 온도가 등엔트로피 출구보다 높습니다. 비가역성이 유체를 데운다는 말로 설명해 보세요.
  2. 단열 장치에서 \(s_{2a} - s_1 = s_{\text{gen}}\)인 이유를 엔트로피 평형으로 설명해 보세요.
  3. 가스 터빈은 압축기와 터빈이 같은 축에 있습니다. 압축기 효율이 85%에서 70%로 떨어지면 엔진의 순일이 어떻게 될지 숫자로 따져 보세요.
