3.2.1평형만으로는 모자랄 때

양 끝이 벽에 고정된 봉의 중간을 밀면, 두 벽이 하중을 얼마씩 나누어 받을까요? 축 방향 평형식은 \(R_A + R_B = P\) 하나뿐인데 미지수는 둘입니다. 1.1절에서 말한 부정정 문제입니다. 평형식은 "합이 \(P\)"라는 것만 말해 줄 뿐, 나누는 비율은 알려 주지 않습니다.

모자란 식은 변형에서 얻습니다. 봉이 양 끝에서 벽에 붙어 있으므로 봉 전체의 늘음은 0이어야 합니다. 이런 "기하학적으로 맞아떨어져야 하는 조건"을 적합 조건이라 합니다. 그리고 늘음과 힘을 잇는 식(\(\delta = NL/EA\))이 둘을 연결합니다.

부정정 문제의 세 단계
  1. 평형: 자유물체도로 쓸 수 있는 평형식을 모두 쓴다.
  2. 적합 조건: 받침과 연결 상태에서 변형이 만족해야 할 조건을 쓴다(예: 전체 늘음 = 0, 두 부재의 늘음이 같다).
  3. 힘-변위 관계: 각 늘음을 \(\delta_i = N_iL_i/(E_iA_i)\)로 바꾸어 적합 조건에 넣는다. 그러면 미지수와 식의 수가 같아진다.
예제 3.2.1 (양 끝 고정 봉)

길이 \(L\), 축강성 \(EA\)인 봉의 양 끝 A, B가 벽에 고정되어 있다. A에서 \(a\), B에서 \(b\)인 점 C에 축 방향 하중 \(P\)(B 쪽으로)가 걸린다. 두 반력을 구하여라.

풀이. 평형: 반력 \(R_A\), \(R_B\)를 모두 하중과 반대 방향(A 쪽)으로 가정하면 \(R_A + R_B = P\).

적합 조건: 봉 전체 길이는 변하지 않으므로 \(\delta_{AC} + \delta_{CB} = 0\).

힘-변위: AC 구간은 A가 왼쪽으로 \(R_A\)만큼 당기므로 인장 \(N_{AC} = R_A\), CB 구간은 B 쪽으로 밀려 압축 \(N_{CB} = -R_B\)입니다. 따라서

\[\frac{R_Aa}{EA} - \frac{R_Bb}{EA} = 0 \Rightarrow R_Aa = R_Bb.\]

평형식과 함께 풀면

\[R_A = \frac{Pb}{L}\] \[R_B = \frac{Pa}{L}.\]

하중에 가까운 벽이 더 많이 받습니다. 짧은 쪽 구간이 더 뻣뻣한 스프링(\(k = EA/L\)이 큼)이라, 같은 변위에서 더 큰 힘을 내기 때문입니다. 이 결과는 1.1절 단순보의 반력 식과 모양이 같아 기억하기 쉽습니다.

3.2.2나란히 놓인 두 재료

철근 콘크리트 기둥, 강철 볼트를 감싼 알루미늄 관, 두 줄로 매단 막대처럼 두 부재가 같은 만큼 변형하도록 묶여 있으면, 하중은 각 부재의 축강성 \(EA/L\)에 비례해 나뉩니다.

예제 3.2.2 (철근 콘크리트 기둥)

단면 300 mm × 300 mm인 콘크리트 기둥(\(E_c = 25\) GPa)에 지름 25 mm 철근 4개(\(E_s = 200\) GPa)가 들어 있다. 압축 하중 1000 kN이 걸릴 때 철근과 콘크리트의 응력을 구하여라.

풀이. 넓이: 철근 \(A_s = 4\times\pi(25)^2/4 = 1963\) mm², 콘크리트 \(A_c = 90\,000 - 1963 = 88\,037\) mm².

평형: \(P_s + P_c = 1000\) kN. 적합: 둘은 붙어 있어 같은 길이만큼 줄어든다: \(\delta_s = \delta_c\). 힘-변위: \(P_sL/(E_sA_s) = P_cL/(E_cA_c)\), 곧 \(P_s/P_c = E_sA_s/(E_cA_c)\).

축강성은 \(E_sA_s = 3.93\times10^8\) N, \(E_cA_c = 2.20\times10^9\) N이므로

\[P_s = 1000\times\frac{3.93}{3.93 + 22.0} = 151\ \text{kN}\] \[P_c = 1000 - 151 = 849\ \text{kN}\]

응력은 \(\sigma_s = 151\,400/1963 = 77.1\) MPa, \(\sigma_c = 848\,600/88\,037 = 9.64\) MPa(모두 압축)입니다. 넓이로는 2%뿐인 철근이 하중의 15%를 받고, 철근 응력은 콘크리트의 정확히 \(E_s/E_c = 8\)배입니다. 같은 변형률이면 응력은 \(E\)에 비례하기 때문입니다(\(\sigma = E\varepsilon\)).

3.2.3강체 막대에 매달린 여러 봉

강체 막대(변형하지 않는 막대)를 여러 줄로 매달면, 막대가 회전·이동하는 방식이 적합 조건이 됩니다. 예를 들어 한 끝이 핀인 강체 막대를 두 줄로 매달면, 각 줄의 늘음은 핀에서의 거리에 비례합니다(\(\delta_1/\delta_2 = x_1/x_2\)). 그림을 그려 작은 회전각 \(\theta\)로 \(\delta_i = x_i\theta\)라고 쓰면 됩니다. 연습문제 3에서 다룹니다.

주의(1) 적합 조건은 그림(변형 뒤의 모양)을 그려 세웁니다. 식만으로 짐작하면 부호가 자주 틀립니다. (2) 가정한 반력·부재력 방향과 늘음의 부호(인장 +)를 일관되게 맞추세요. 예제 3.2.1에서 CB 구간을 인장으로 잘못 쓰면 \(R_Aa + R_Bb = 0\)이라는 말이 안 되는 식이 나옵니다. (3) 부정정 구조는 강성 비로 하중을 나누므로, 한 부재를 더 뻣뻣하게 바꾸면 그 부재가 더 많은 하중을 받습니다. "보강하면 덜 받는다"고 생각하기 쉬운데 반대입니다.
요약
  1. 평형식보다 미지수가 많으면 변형 조건(적합 조건)을 더해야 풀린다.
  2. 세 단계: 평형 → 적합 → 힘-변위(\(\delta = NL/EA\)).
  3. 양 끝 고정 봉: \(R_A = Pb/L\), \(R_B = Pa/L\). 가까운 벽이 더 받는다.
  4. 같은 변형을 하는 나란한 부재는 축강성 \(EA/L\)에 비례해 하중을 나누고, 응력은 \(E\)에 비례한다.

3.2.4연습문제

기본

  1. 길이 1 m 양 끝 고정 봉의 A에서 0.25 m인 곳에 40 kN이 걸린다. 두 반력은?
    답

    \(R_A = 40\times0.75 = 30\) kN, \(R_B = 10\) kN.

  2. 지름 20 mm 강철 볼트(\(E = 200\) GPa)를 바깥지름 40 mm, 안지름 22 mm인 알루미늄 관(\(E = 70\) GPa)에 끼우고 양 끝을 판으로 막아 50 kN으로 누른다. 볼트와 관이 나누어 받는 힘은?
    답

    \(E_sA_s = 200\,000\times314.2 = 6.28\times10^7\), \(E_aA_a = 70\,000\times876.5 = 6.14\times10^7\). 볼트 25.3 kN, 관 24.7 kN.

응용

  1. 길이 3 m 강체 막대가 왼쪽 끝 O에서 핀으로 붙어 있고, O에서 1 m, 2 m인 곳이 같은 강철봉 두 개(길이 1.5 m, 단면 100 mm², \(E = 200\) GPa)로 위에 매달려 있다. 오른쪽 끝에 12 kN을 걸 때 두 봉의 힘을 구하여라.
    힌트

    평형: O에 대한 모멘트 \(F_1(1) + F_2(2) = 12(3)\). 적합: \(\delta_2 = 2\delta_1\), 같은 봉이므로 \(F_2 = 2F_1\).

    답

    \(F_1 + 4F_1 = 36\), \(F_1 = 7.2\) kN, \(F_2 = 14.4\) kN.

심화

  1. 예제 3.2.1에서 AC 구간과 CB 구간의 축강성이 다르면(\(E_1A_1\), \(E_2A_2\)) 반력은 어떻게 되는가? 강성 \(k_1 = E_1A_1/a\), \(k_2 = E_2A_2/b\)로 나타내어라.
    답

    \(R_A/k_1 = R_B/k_2\)이므로 \(R_A = Pk_1/(k_1 + k_2)\), \(R_B = Pk_2/(k_1 + k_2)\). 나란히 놓인 두 스프링이 변위를 공유하며 하중을 강성에 비례해 나누는 것과 같다.

3.2.2

실습벽 사이의 봉: 하중, 틈새, 온도가 반력을 어떻게 바꿀까?

실습 · 부정정 축하중과 열응력

다루는 성취기준 [기계2-03-02] [기계2-03-03]

목표

왼쪽 끝 A가 벽에 고정되고 오른쪽 끝 B 앞에 작은 틈이 있는 봉에 하중과 온도 변화를 줍니다. 틈이 닫히기 전에는 정정, 닫힌 뒤에는 부정정이 되는 것을 확인하고, 반력·축력·응력을 3.2절, 3.3절의 손 계산과 비교합니다. 성취기준 [기계2-03-02], [기계2-03-03].

준비

봉은 길이 1000 mm, 지름 25 mm(단면적 490.9 mm²)이고, 하중점 C(A에서 \(a\))를 경계로 두 구간의 재료를 따로 고를 수 있습니다. 강철 \(E = 200\) GPa, \(\alpha = 12\times10^{-6}\), 알루미늄 70 GPa, \(23\times10^{-6}\), 구리 110 GPa, \(17\times10^{-6}\)입니다.

장치는 3.2절의 세 단계를 그대로 계산합니다. 먼저 B를 막지 않았을 때 B가 움직일 거리 \(u_{\text{free}} = Pa/(E_1A) + \alpha_1\Delta T\,a + \alpha_2\Delta T\,b\)를 구하고, 이것이 틈 \(g\)보다 크면 B 벽이 \(R_B\)로 밀어 실제 변위를 \(g\)에 맞춥니다.

\[R_B = \frac{u_{\text{free}} - g}{a/(E_1A) + b/(E_2A)}\]

"B 붙음"을 켜면 B 끝이 벽에 붙어 있어(틈 0, 당기는 힘도 가능) 양 끝 고정 봉이 됩니다.

절차

  1. 처음 값(두 구간 모두 강철, a = 400 mm, P = 30 kN, 틈 0.10 mm, ΔT = 0)에서 B와 닿는지, 반력이 얼마인지 기록합니다.
  2. 틈을 0.20 mm로 늘리면 어떻게 되나요? 닿기 시작하는 하중을 \(Pa/(EA) = g\)로 손 계산해 장치와 비교합니다.
  3. "B 붙음"을 켜고 a를 200, 400, 600, 800 mm로 바꾸며 \(R_A\), \(R_B\)를 적습니다. \(R_A = Pb/L\)과 비교합니다.
  4. B 붙음, P = 0, 두 구간 강철에서 ΔT = 40 °C로 하고 응력을 읽습니다. 예제 3.3.2와 비교합니다.
  5. B 붙음을 끄고 틈 0.30 mm, P = 0에서 ΔT를 올리며 응력이 생기기 시작하는 온도를 찾습니다.
  6. B 붙음, P = 0, ΔT = 40 °C에서 CB 구간을 알루미늄으로 바꿉니다. 응력이 커지는 이유를 생각합니다.

기대 결과

  • 처음 값: B를 막지 않으면 B가 0.122 mm 움직이려 하므로 틈 0.10 mm가 닫히고, \(R_B = 2.18\) kN, \(R_A = 27.82\) kN입니다. 축력은 AC +27.82 kN(인장), CB −2.18 kN(압축)입니다.
  • 틈 0.20 mm: 닿지 않아 \(R_B = 0\), \(R_A = 30\) kN(정정). 닿기 시작하는 하중은 \(g\,EA/a = 0.2\times200\,000\times490.9/400 = 49.1\) kN입니다.
  • B 붙음: \(R_A = Pb/L\), \(R_B = Pa/L\). a = 400 mm면 18 kN과 12 kN, a = 800 mm면 6 kN과 24 kN.
  • 강철, B 붙음, ΔT = 40 °C: 응력 −96.0 MPa로 예제 3.3.2와 같습니다. 축력은 −47.1 kN입니다.
  • 틈 0.30 mm, 강철: \(\alpha\Delta TL = 0.30\)에서 \(\Delta T = 25\) °C. 그보다 높으면 압축 응력이 생깁니다(30 °C에서 −12.0 MPa).
  • CB를 알루미늄으로 바꾸면(B 붙음, ΔT = 40 °C) 응력은 약 −70.4 MPa입니다. 알루미늄이 더 늘어나려 하지만 \(E\)가 작아 되밀기 쉬워서, 강철만일 때보다 작아집니다.

분석

  1. B 붙음일 때 하중에 가까운 벽이 더 많이 받는 이유를 두 구간의 강성 \(EA/a\), \(EA/b\)로 설명해 보세요.
  2. B 붙음, 하중 없음에서 강철만인 봉의 열응력은 하중 위치 a에 따라 바뀌나요? 수식으로 이유를 말해 보세요.
  3. 틈새는 열응력을 줄이지만 하중을 받을 때 강성을 떨어뜨립니다. 철로 이음, 배관 신축 이음에서 틈 크기를 어떻게 정할지 생각해 보세요.

더 해 보기

P = 30 kN과 ΔT = 40 °C를 함께 걸고(B 붙음, 강철), 하중만 걸었을 때의 결과와 온도만 바꾸었을 때의 결과를 더한 것과 같은지 확인해 보세요. 선형 탄성 문제에서는 중첩이 성립합니다. 틈이 있으면 닿는지 여부가 하중에 따라 바뀌어 중첩이 성립하지 않는다는 것도 확인해 보세요.
