3.3.1열변형률

여름에 철로를 이어 붙인 이음매에 틈을 두고, 긴 다리에는 손가락 모양 신축 이음을 둡니다. 온도가 오르면 재료가 늘어나는데, 그 늘어남을 막으면 큰 힘이 생기기 때문입니다.

정의 3.3.1 (열변형률)

온도가 \(\Delta T\)만큼 변할 때 재료가 자유롭게 늘어나는 변형률은

\[\varepsilon_T = \alpha\,\Delta T\]

이다. \(\alpha\)를 선팽창 계수라 하며 단위는 1/°C(= 1/K)이다. 길이 \(L\)인 봉이 자유롭게 늘어나는 양은 \(\delta_T = \alpha\,\Delta T\,L\)이다.

대표값은 강철 \(12\times10^{-6}\)/°C, 알루미늄 \(23\times10^{-6}\), 구리 \(17\times10^{-6}\), 콘크리트 \(10\times10^{-6}\) 정도입니다. 강철과 콘크리트의 값이 거의 같아 철근 콘크리트가 온도 변화에도 갈라지지 않습니다.

중요한 점은 자유롭게 늘어나면 응력이 0이라는 것입니다. 열변형률은 힘 때문이 아니라 원자 사이 거리가 온도에 따라 달라져 생기기 때문입니다. 그래서 전체 변형률은 힘에 의한 부분과 온도에 의한 부분의 합으로 씁니다.

\[\varepsilon = \frac{\sigma}{E} + \alpha\,\Delta T\] \[\delta = \frac{NL}{EA} + \alpha\,\Delta T\,L\]

3.3.2늘어남이 막히면

예제 3.3.2 (양 끝이 고정된 봉)

양 끝이 움직이지 않는 벽에 붙은 강철봉(\(E = 200\) GPa, \(\alpha = 12\times10^{-6}\)/°C)의 온도가 40 °C 오른다. 봉의 응력을 구하여라.

풀이. 3.2절의 세 단계를 씁니다. 평형: 양 벽이 같은 크기의 힘 \(R\)로 봉을 누릅니다(축력 \(N = -R\)). 적합: 벽이 움직이지 않으므로 전체 늘음이 0. 힘-변위: \(\delta = NL/(EA) + \alpha\Delta TL = 0\). 따라서

\[\sigma = \frac{N}{A} = -E\alpha\Delta T = -200\,000\times12\times10^{-6}\times40 = -96\ \text{MPa}.\]

압축 96 MPa는 항복강도 250 MPa의 40%에 가까운 큰 값입니다. 그런데 이 결과에 길이와 단면적이 들어 있지 않다는 점에 주목하세요. 짧은 봉이든 긴 봉이든, 굵든 가늘든 같은 응력입니다. 막힌 늘음 \(\alpha\Delta TL\)도 길이에 비례하고, 그것을 되밀어 넣는 데 필요한 응력도 길이에 비례해, 길이가 약분되기 때문입니다. 또 이 정도 압축이면 가늘고 긴 봉은 옆으로 휘는 좌굴(1.8절)이 먼저 일어날 수 있습니다.

3.3.3틈새가 있을 때

예제 3.3.3 (철로의 틈새)

길이 12 m 철로를 3 mm 틈새를 두고 깔았다. 온도가 40 °C 오르면 철로의 응력은?

풀이. 자유롭게 늘어날 양은 \(\alpha\Delta TL = 12\times10^{-6}\times40\times12\,000 = 5.76\) mm로 틈새 3 mm보다 큽니다. 그러므로 3 mm까지는 응력 없이 늘어나고, 틈이 닫힌 뒤 남은 \(5.76 - 3 = 2.76\) mm가 막힙니다. 적합 조건은 "실제 늘음 = 3 mm"입니다.

\[\frac{NL}{EA} + 5.76 = 3 \Rightarrow \sigma = \frac{N}{A} = -\frac{E\times2.76}{L} = -\frac{200\,000\times2.76}{12\,000} = -46\ \text{MPa}.\]

틈새 하나로 응력이 96 MPa에서 46 MPa로 절반 아래로 줄었습니다. 틈새가 5.76 mm 이상이면 응력은 0입니다. 반대로 온도가 내려가면 틈이 벌어지기만 하고 응력은 생기지 않습니다(레일이 묶여 있지 않다면).

3.3.4두 재료가 묶여 있을 때

강철 볼트에 끼운 알루미늄 관을 데우면 알루미늄(\(\alpha\)가 큼)은 더 늘어나려 하고 강철은 덜 늘어나려 합니다. 둘이 양 끝에서 묶여 있으므로 결국 같은 길이만큼 늘어나야 하고, 그 사이에서 알루미늄은 눌리고 강철은 당겨집니다. 식은 3.2절의 나란한 부재와 같고, 각 늘음에 열변형 항을 더하면 됩니다(연습문제 3). 바이메탈 온도 스위치, 반도체 칩과 기판 사이의 열응력, 엔진 피스톤과 실린더의 틈 설계가 모두 이 원리입니다.

주의(1) 자유 팽창에서 \(\sigma = E\alpha\Delta T\)를 쓰는 실수가 흔합니다. 응력은 늘어남이 막혀야 생깁니다. (2) 온도 변화 \(\Delta T\)는 섭씨든 켈빈이든 같은 값입니다(차이이므로). (3) 열응력 문제도 결국 부정정 문제라, 적합 조건을 그림으로 먼저 세우세요.
요약
  1. 열변형률 \(\varepsilon_T = \alpha\Delta T\). 자유롭게 늘어나면 응력은 0.
  2. 전체 늘음 \(\delta = NL/(EA) + \alpha\Delta TL\)을 적합 조건에 넣는다.
  3. 양 끝이 완전히 막힌 봉: \(\sigma = -E\alpha\Delta T\), 길이·단면과 무관.
  4. 틈새가 있으면 틈을 넘는 만큼만 막힌다. 두 재료가 묶이면 \(\alpha\)가 큰 쪽이 눌리고 작은 쪽이 당겨진다.

3.3.5연습문제

기본

  1. 길이 50 m 강철 다리가 −10 °C에서 40 °C까지 변한다. 신축 이음이 흡수해야 할 길이 변화는?
    답

    \(12\times10^{-6}\times50\times50\,000 = 30\) mm.

  2. 양 끝이 고정된 알루미늄봉(\(E = 70\) GPa, \(\alpha = 23\times10^{-6}\))의 온도가 30 °C 내려갔다. 응력은?
    답

    \(\sigma = -E\alpha\Delta T = -70\,000\times23\times10^{-6}\times(-30) = +48.3\) MPa(인장).

응용

  1. 3.2절 연습문제 2의 볼트(강철)와 관(알루미늄)을 상온에서 하중 없이 조립한 뒤 온도를 50 °C 올린다(\(\alpha_s = 12\times10^{-6}\), \(\alpha_a = 23\times10^{-6}\)). 볼트와 관의 힘은?
    힌트

    평형: 볼트 인장 \(F\) = 관 압축 \(F\). 적합: \(F/(E_sA_s) + \alpha_s\Delta T = -F/(E_aA_a) + \alpha_a\Delta T\) (길이 \(L\)은 약분).

    답

    \(F\left(\frac{1}{6.28\times10^7} + \frac{1}{6.14\times10^7}\right) = 11\times10^{-6}\times50\). \(F = 5.5\times10^{-4}/3.22\times10^{-8} = 17.1\) kN. 볼트 인장 54 MPa, 관 압축 19.5 MPa.

심화

  1. 양 끝 고정 봉이 AC(강철, 길이 \(a\))와 CB(알루미늄, 길이 \(b\))로 이어져 있고 단면적이 같다. 온도가 \(\Delta T\) 오를 때 축력이 \(N = -\dfrac{(\alpha_1a + \alpha_2b)\Delta T}{a/E_1 + b/E_2}\cdot A\)임을 보여라.
    답

    두 구간의 축력은 같은 \(N\)(평형). 적합: \(\frac{Na}{E_1A} + \alpha_1\Delta Ta + \frac{Nb}{E_2A} + \alpha_2\Delta Tb = 0\)에서 바로 나온다.

3.3.2

예제강체 판에 묶인 두 기둥을 데우면

예제 · 열변형과 적합 조건

다루는 성취기준 [기계2-03-03] [기계2-03-02]

먼저 예측

길이가 같은 강철 기둥과 알루미늄 기둥 위에 단단한 판을 얹어 둘을 묶었습니다. 하중 없이 온도만 올리면, 두 기둥 중 어느 쪽이 당겨지고 어느 쪽이 눌릴까요?

예측 확인

알루미늄(\(\alpha\)가 큼)은 더 늘어나려다 판에 눌리고, 강철은 판에 끌려 올라가며 당겨집니다. 아래에서 크기를 구합니다.

문제. 바닥에 세운 강철 기둥(단면 400 mm², \(E_s = 200\) GPa, \(\alpha_s = 12\times10^{-6}\)/°C)과 알루미늄 기둥(단면 600 mm², \(E_a = 70\) GPa, \(\alpha_a = 23\times10^{-6}\)/°C)은 둘 다 길이 500 mm이고, 위에 강체 판을 볼트로 고정해 묶었다. 하중 없이 온도가 60 °C 오를 때 두 기둥의 응력을 구하라.

전략

판이 강체이고 수평을 유지한다고 보면(두 기둥이 판의 같은 높이를 받침) 두 기둥의 늘음이 같아야 합니다. 판에 바깥 하중이 없으므로 두 기둥의 힘은 크기가 같고 방향이 반대입니다. 3.2절의 세 단계에 열변형 항을 더합니다.

풀이

  1. 평형: 강철 축력 \(N_s\), 알루미늄 축력 \(N_a\)에 대해 \(N_s + N_a = 0\). 강철이 인장 \(F\)이면 알루미늄은 압축 \(F\).
    판의 자유물체도: 두 기둥이 판에 주는 힘의 합 = 0.
  2. 적합: \(\delta_s = \delta_a\).
    강체 판이 두 기둥 끝을 같은 높이로 묶는다.
  3. 힘-변위: \(\dfrac{F\,L}{E_sA_s} + \alpha_s\Delta TL = \dfrac{-F\,L}{E_aA_a} + \alpha_a\Delta TL\).
    전체 늘음 = 힘에 의한 늘음 + 열에 의한 늘음(3.3절).
  4. \(L\)을 약분하고 정리: \(F\left(\dfrac{1}{8\times10^7} + \dfrac{1}{4.2\times10^7}\right) = (23 - 12)\times10^{-6}\times60\).
    \(E_sA_s = 200\,000\times400 = 8\times10^7\) N, \(E_aA_a = 70\,000\times600 = 4.2\times10^7\) N.
  5. \(F = 6.6\times10^{-4}/3.631\times10^{-8} = 18.2\) kN. 강철 \(\sigma_s = +45.4\) MPa(인장), 알루미늄 \(\sigma_a = -30.3\) MPa(압축).
    응력 = 축력/넓이.

검산

공통 늘음: 강철 \(18\,200\times500/(8\times10^7) + 12\times10^{-6}\times60\times500 = 0.114 + 0.360 = 0.474\) mm, 알루미늄 \(-0.217 + 0.690 = 0.473\) mm. 반올림 안에서 같습니다. 두 기둥의 자유 늘음(0.36, 0.69 mm) 사이에 있다는 것도 맞습니다.

의미

바깥 하중이 전혀 없는데도 두 재료에 30~45 MPa의 응력이 생겼습니다. 서로 다른 재료를 단단히 묶은 부품(전자 기판의 납땜, 엔진의 알루미늄 헤드와 강철 볼트)은 온도가 오르내릴 때마다 이런 응력을 반복해서 받고, 그것이 피로 균열의 원인이 됩니다.

이해 확인

온도가 60 °C 내려가면 두 응력은?

답

부호만 바뀝니다: 강철 −45.4 MPa(압축), 알루미늄 +30.3 MPa(인장). 선형 문제이므로 \(\Delta T\)에 비례합니다.
