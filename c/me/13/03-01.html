3.1.1

실습가진 진동수가 고유진동수에 가까우면 무슨 일이 생길까?

실습 · 1자유도계의 조화 가진 응답과 공진

다루는 성취기준 [기계13-03-01] [기계8-02-02]

목표

질량 1 kg, 스프링 1000 N/m인 질량-스프링-감쇠기에 크기 10 N인 조화력 \(F_0\cos\omega t\)를 가하고, 진동수비와 감쇠비를 바꾸며 정상 상태 진폭과 위상을 이론식과 비교합니다. 성취기준 [기계13-03-01], 주파수 응답 실험 [기계8-02-02].

준비

운동 방정식은 \(m\ddot x + c\dot x + kx = F_0\cos\omega t\)입니다. 고유진동수 \(\omega_n = \sqrt{k/m} = 31.6\) rad/s(5.03 Hz), 감쇠비 \(\zeta = c/(2m\omega_n)\), 진동수비 \(r = \omega/\omega_n\)로 쓰면 오래 지난 뒤(정상 상태)의 응답은 \(x = X\cos(\omega t - \phi)\)이고

\[\frac{X}{F_0/k} = \frac{1}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}},\qquad \tan\phi = \frac{2\zeta r}{1-r^2}\]

입니다. \(F_0/k = 10\) mm는 같은 힘을 천천히(정적으로) 걸었을 때의 처짐입니다. 장치는 정지 상태에서 시작해 운동 방정식을 RK4로 풉니다([기계16-06-01]). 그래서 처음 얼마 동안은 정상 응답에 자유 진동(과도 응답)이 겹쳐 보입니다.

절차

  1. r = 0.5, ζ = 0.1에서 재생하고 3초 뒤의 "최근 한 주기 최대 변위"를 이론 진폭과 비교합니다.
  2. r을 0.2, 0.5, 0.9, 1.0, 1.1, 1.5, 2, 3으로 바꾸며(바꿀 때마다 처음부터) 이론 진폭과 위상을 표로 적습니다.
  3. r = 1.0에서 ζ를 0.05, 0.1, 0.2, 0.5로 바꾸며 진폭을 적습니다.
  4. 시간 그래프에서 r이 작을 때, 1일 때, 클 때 변위(파랑)와 힘(빨강)의 봉우리 순서를 비교합니다.
  5. r = 1, ζ = 0.02로 놓고 재생해 진폭이 어떻게 자라는지 봅니다.

기대 결과

  • r = 0.5, ζ = 0.1: 진폭비 1.322, X = 13.2 mm, 위상 7.6°. 재생 후 몇 초면 측정값이 이 값에 다가갑니다.
  • r = 1에서 진폭비는 \(1/(2\zeta)\): ζ = 0.05면 10배(100 mm), 0.1이면 5배, 0.5면 1배. 위상은 감쇠와 상관없이 90°입니다.
  • r = 2에서 진폭비 약 0.33(ζ = 0.1), r = 3에서 약 0.125. 고유진동수보다 훨씬 빨리 흔들면 질량이 따라가지 못합니다. 위상은 180°에 가까워 힘과 반대로 움직입니다.
  • ζ = 0.02, r = 1이면 진폭이 거의 직선으로 커지다가 수 초에 걸쳐 250 mm(25배)에 다가갑니다. 감쇠가 작을수록 정상 상태까지 오래 걸립니다.

분석

  1. r ≪ 1, r = 1, r ≫ 1에서 각각 스프링력, 감쇠력, 관성력 중 무엇이 가진력과 주로 맞서는지 설명해 보세요.
  2. 진폭이 가장 큰 진동수는 정확히 r = 1이 아니라 \(r = \sqrt{1-2\zeta^2}\)입니다. ζ = 0.5에서 곡선의 꼭대기가 어디 있는지 확인하세요.
  3. 세탁기 탈수처럼 회전수가 0에서 올라가는 기계는 반드시 공진을 한 번 지나갑니다. 어떻게 하면 피해를 줄일 수 있을까요?

더 해 보기

방진(진동 절연) 문제([기계13-03-02])에서는 바닥으로 전해지는 힘의 비 \(T_r = \sqrt{1+(2\zeta r)^2}/\sqrt{(1-r^2)^2+(2\zeta r)^2}\)을 봅니다. \(T_r < 1\)이 되는 r의 범위를 손으로 구하고, 이때 감쇠를 키우면 오히려 불리하다는 것을 확인해 보세요.
