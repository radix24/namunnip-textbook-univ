시간을 알면 위치를, 위치를 알면 시간을

위성이 근점을 지난 뒤 1시간 뒤에 어디 있을까요? 지상국 안테나를 언제 어디로 돌려야 할까요? 이 질문에 답하는 식이 Kepler 방정식입니다. 1609년 케플러가 화성의 위치를 계산하려고 만들었고, 지금도 모든 궤도 프로그램의 핵심 함수입니다.

2.2.1유도

유도. 근점에서 시각 \(t - \tau\) 동안 위성이 쓸고 간 넓이는 Kepler 제2법칙으로 전체 넓이 \(\pi ab\)의 \((t - \tau)/T\)배, 곧 \(\frac{ab}{2}M\)입니다. 보조원 위에서 같은 넓이를 보면, 원의 부채꼴(중심 기준, 각 \(E\))의 넓이 \(\frac{a^2}{2}E\)에서 중심과 초점 사이 삼각형 \(\frac12ae\cdot a\sin E\)를 뺀 것을 \(b/a\)배로 줄인 것이 타원 위에서 쓸고 간 넓이입니다(타원은 원을 한 방향으로 \(b/a\)배 줄인 것). 그러므로 \[ \frac{ab}{2}M = \frac ba\left(\frac{a^2}{2}E - \frac{a^2e}{2}\sin E\right) \;\Longrightarrow\; M = E - e\sin E \] 입니다. ∎

2.2.2시각에서 위치로

  1. 평균 운동 \(n = \sqrt{\mu/a^3}\), 평균 근점 이각 \(M = n(t - \tau)\).
  2. Newton 방법 \(E_{k+1} = E_k - \frac{E_k - e\sin E_k - M}{1 - e\cos E_k}\)으로 \(E\)를 구한다(처음 값 \(E_0 = M\), \(e\)가 크면 \(\pi\)).
  3. \(\nu\)와 \(r = a(1 - e\cos E)\)를 구한다.
예제 2.2.1

\(a = 10{,}000\) km, \(e = 0.3\)인 지구 궤도에서 근점 통과 1시간 뒤의 \(E\), \(\nu\), \(r\)은?

풀이. \(n = 6.3135\times10^{-4}\) rad/s, \(M = 2.2729\) rad. Newton 방법으로 \(E = 2.4615\) rad(141.0°). \(\tan(\nu/2) = 1.3628\times\tan(70.52^\circ) = 3.849\), \(\nu = 150.9^\circ\). \(r = 10000\times(1 - 0.3\cos2.4615) = 12{,}333\) km입니다. 주기가 2.76시간이므로 1시간 뒤에는 원점(\(\nu = 180^\circ\)) 조금 전입니다.

2.2.3위치에서 시각으로

반대 방향은 계산이 바로 됩니다: \(\nu\) → \(E\)(반각 식) → \(M = E - e\sin E\) → \(t - \tau = M/n\). 예를 들어 위 궤도에서 \(\nu = 90^\circ\)에 이르는 시각은 \(E = 72.5^\circ\)(1.2654 rad), \(M = 1.2654 - 0.3\sin72.5^\circ = 0.9793\), \(t - \tau = 0.9793/6.3135\times10^{-4} = 1{,}551\) s(25.9분)입니다. 궤도의 첫 1/4(\(\nu\) 0~90°)을 지나는 데 주기(166분)의 16%밖에 걸리지 않습니다.

천우6 3.1절의 실습 카드에서 Newton 방법이 근을 찾아가는 모습을 볼 수 있습니다.

주의 쌍곡선 궤도에서는 Kepler 방정식이 \(M_h = e\sinh F - F\)(쌍곡 근점 이각 \(F\))로 바뀝니다. 포물선은 바커 방정식을 씁니다. 범용 변수를 쓰면 세 경우를 하나의 식으로 다룰 수 있습니다(Curtis 3장).
요약
  1. Kepler 방정식 \(M = E - e\sin E\)는 면적 속도 일정과 보조원의 넓이 비교로 유도된다.
  2. 시각 → \(M = n(t-\tau)\) → Newton으로 \(E\) → \(\nu\), \(r\).
  3. 위치 → \(E\) → \(M\) → 시각은 직접 계산된다.
  4. 쌍곡선·포물선은 다른 형태의 방정식을 쓴다.

2.2.4연습문제

기본

  1. \(e = 0.1\), \(M = 1.0\) rad에서 \(E_0 = M\)으로 Newton 한 번 반복한 값은?
    답

    \(E_1 = 1 + 0.1\sin1/(1 - 0.1\cos1) = 1 + 0.08415/0.94597 = 1.0890\).

  2. 근점과 원점 사이 반 바퀴에 걸리는 시간은 주기의 얼마입니까?
    답

    정확히 절반(\(M\)이 0에서 \(\pi\)).

응용

  1. 예제 2.2.1의 궤도에서 \(\nu = 270^\circ\)(원점을 지나 3/4)에 이르는 시각은?
    답

    \(E = 360^\circ - 72.5^\circ = 287.5^\circ\)(5.0178 rad), \(M = 5.0178 + 0.2861 = 5.3039\), \(t = 8{,}401\) s = 2.33시간.

  2. 몰니야 궤도(\(a = 26{,}560\) km, \(e = 0.74\))에서 원점 근처 \(\nu = 180\pm60^\circ\) 구간에 머무는 시간 비율은?
    답

    \(\nu = 120^\circ\): \(\tan(E/2) = \sqrt{0.26/1.74}\tan60^\circ = 0.6696\), \(E = 67.6^\circ\)(1.180 rad), \(M = 1.180 - 0.684 = 0.496\). 구간은 \(M\)이 0.496~(2π−0.496), 비율 \((2\pi - 0.992)/2\pi = 84\%\). 주기의 대부분을 원점 근처(북반구 상공)에서 보냅니다.
