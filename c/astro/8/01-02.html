이 절에서 배울 것
  • 비각운동량 \(\vec h\)와 이심률 벡터 \(\vec e\)가 보존됨을 보인다.
  • \(\vec e\)로 궤도 방정식 \(r = (h^2/\mu)/(1 + e\cos\nu)\)을 유도한다.
  • 이심률 벡터가 근점 방향을 가리킨다는 것을 안다.
먼저 알아야 할 것
  • 상대 운동 방정식 (1.1절), 벡터의 외적과 미분, 천우3의 극좌표 유도 (천우3 3.1절).

벡터로 하는 유도

천우3에서는 극좌표와 \(u = 1/r\) 치환으로 궤도 방정식을 얻었습니다. 공학 궤도역학에서는 보존되는 벡터 두 개를 찾아 더 짧고 3차원에 바로 쓸 수 있게 유도합니다. 이 벡터들은 나중에 위치·속도에서 궤도요소를 계산하는 데(3.1절) 그대로 쓰입니다.

외적과 내적을 처음 본다면 두 벡터 \(\vec a = (a_1, a_2, a_3)\), \(\vec b = (b_1, b_2, b_3)\)에 대해 내적 \(\vec a\cdot\vec b = a_1b_1 + a_2b_2 + a_3b_3 = |\vec a||\vec b|\cos\theta\)는 숫자 하나이고, 외적 \(\vec a\times\vec b = (a_2b_3 - a_3b_2,\ a_3b_1 - a_1b_3,\ a_1b_2 - a_2b_1)\)은 두 벡터에 모두 수직인 벡터로 크기가 \(|\vec a||\vec b|\sin\theta\)(두 벡터가 만드는 평행사변형의 넓이)입니다. 같은 벡터끼리의 외적은 0입니다(\(\sin0 = 0\)). 궤도면 위에서만 보면 \(h = |\vec r\times\dot{\vec r}| = r\,v_\perp\)(거리 × 속도의 옆 방향 성분)이고, 이는 케플러 제2법칙의 면적 속도의 2배입니다. 아래 유도는 이 계산 규칙만으로 따라갈 수 있고, 같은 결과를 극좌표로 얻는 방법은 천우3 3장에 있습니다.

1.2.1비각운동량

\(\vec h = \vec r\times\dot{\vec r}\)을 미분하면 \(\dot{\vec h} = \dot{\vec r}\times\dot{\vec r} + \vec r\times\ddot{\vec r} = 0 + \vec r\times(-\mu\vec r/r^3) = 0\)입니다. 그러므로 \(\vec h\)는 일정하고, \(\vec r\)과 \(\dot{\vec r}\)은 늘 \(\vec h\)에 수직인 한 평면(궤도면)에 있습니다.

1.2.2이심률 벡터

유도. 운동 방정식에 \(\vec h\)를 외적합니다. 왼쪽은 \(\ddot{\vec r}\times\vec h = \frac{d}{dt}(\dot{\vec r}\times\vec h)\)(\(\vec h\)가 일정하므로). 오른쪽은 벡터 삼중곱 공식으로 \[ -\frac{\mu}{r^3}\vec r\times(\vec r\times\dot{\vec r}) = -\frac{\mu}{r^3}\left[\vec r(\vec r\cdot\dot{\vec r}) - \dot{\vec r}r^2\right] = \mu\frac{d}{dt}\left(\frac{\vec r}{r}\right) \] 입니다(\(\vec r\cdot\dot{\vec r} = r\dot r\)와 \(\frac{d}{dt}(\vec r/r) = \dot{\vec r}/r - \vec r\dot r/r^2\) 사용). 두 쪽을 적분하면 \(\dot{\vec r}\times\vec h = \mu\vec r/r + \vec C\)이고, 상수 벡터를 \(\vec C = \mu\vec e\)로 두면 \[ \vec e = \frac{\dot{\vec r}\times\vec h}{\mu} - \frac{\vec r}{r} \] 가 일정합니다. 이것이 이심률 벡터입니다. ∎

1.2.3궤도 방정식

유도. 위 식에 \(\vec r\)을 내적하면 \(\vec r\cdot(\dot{\vec r}\times\vec h) = \mu r + \mu\vec r\cdot\vec e\)입니다. 왼쪽은 스칼라 삼중곱의 순환으로 \((\vec r\times\dot{\vec r})\cdot\vec h = h^2\)입니다. \(\vec r\)과 \(\vec e\) 사이의 각을 진근점 이각 \(\nu\)라 하면 \(\vec r\cdot\vec e = re\cos\nu\)이므로 \(h^2 = \mu r(1 + e\cos\nu)\), 곧 \[ r = \frac{h^2/\mu}{1 + e\cos\nu} \] 입니다. ∎

\(\nu = 0\)에서 \(r\)이 가장 작으므로 이심률 벡터는 근점 방향을 가리키고, 그 크기가 이심률입니다. 원뿔곡선의 반통경은 \(p = h^2/\mu\)입니다. 천우3의 결과와 같지만, 이제 위치와 속도 벡터만 알면 \(\vec h\), \(\vec e\), \(p\)를 곧바로 계산할 수 있습니다.

예제 1.2.1

위성이 \(\vec r = (7000, 0, 0)\) km에서 \(\dot{\vec r} = (0, 7.5, 1.0)\) km/s로 움직입니다. \(\vec h\), 이심률 벡터, 근점 거리는?

풀이. \(\vec h = \vec r\times\dot{\vec r} = (0\cdot1.0 - 0\cdot7.5,\ 0\cdot0 - 7000\cdot1.0,\ 7000\cdot7.5 - 0) = (0, -7000, 52500)\), \(h = 52{,}965\) km²/s. \(\dot{\vec r}\times\vec h = (7.5\cdot52500 - 1.0\cdot(-7000),\ \ldots) = (400{,}750, 0, 0)\)이므로 \(\vec e = (400{,}750/398{,}600 - 1, 0, 0) = (0.00539, 0, 0)\). 이심률 0.0054의 거의 원 궤도이고 지금 근점에 있습니다(\(\vec e\)가 \(\vec r\) 방향). 근점 거리는 \(p/(1+e) = (52965^2/398600)/1.00539 = 7{,}038\times(1 - 0.00539) = 7{,}000\) km로 현재 위치와 같습니다.

주의 원 궤도(\(e = 0\))에서는 이심률 벡터가 0이라 근점 방향과 진근점 이각이 정해지지 않습니다. 이때는 승교점에서 잰 각(위도 인수)을 대신 씁니다(3.1절).
요약
  1. \(\vec h = \vec r\times\dot{\vec r}\) 보존 → 평면 운동.
  2. 이심률 벡터 \(\vec e = \dot{\vec r}\times\vec h/\mu - \vec r/r\) 보존, 근점 방향, 크기가 이심률.
  3. \(r = (h^2/\mu)/(1 + e\cos\nu)\): 원뿔곡선.
  4. 위치·속도에서 \(\vec h\), \(\vec e\)를 곧바로 계산한다.

1.2.4연습문제

기본

  1. 원 궤도(반지름 \(r\))에서 \(h\)는?
    답

    \(h = rv = \sqrt{\mu r}\).

  2. \(\vec r\)과 \(\dot{\vec r}\)이 수직이고 \(v\)가 원 궤도 속력보다 크면 지금 어디에 있습니까?
    답

    근점(\(\dot r = 0\)이고 속력이 원 궤도보다 크므로 바깥으로 벌어지는 궤도의 가장 가까운 점).

응용

  1. \(\vec r = (8000, 0, 0)\) km, \(\dot{\vec r} = (0, 6.0, 0)\) km/s의 이심률과 지금의 위치(근점·원점)는?
    답

    \(h = 48{,}000\), \(\vec e = (6.0\cdot48000/398600 - 1, 0, 0) = (-0.277, 0, 0)\). \(\vec e\)가 \(\vec r\)의 반대 방향이므로 지금 원점이고 이심률 0.277.

  2. \(|\vec e|^2 = 1 + 2\varepsilon h^2/\mu^2\)임을 쓰면, 에너지가 0이면 이심률은?
    답

    1(포물선).
