5.R.1

연습5단원 마무리: 섭동론 입문

연습 · 섭동

다루는 성취기준 [천우8-05]

문제

쉬운 것에서 어려운 것 순서입니다. 막히면 힌트 1(방향), 힌트 2(첫 단계)를 차례로 여세요.

  1. 개념 저궤도에서 가장 큰 섭동은? 가장 큰 섭동이 수명을 정하지 않는 까닭은?

    힌트 1

    섭동 가속도의 크기 순서표를 떠올리세요.

    힌트 2

    J2가 바꾸는 궤도요소와 대기 저항이 바꾸는 궤도요소를 비교하세요.

    풀이

    J2입니다. J2는 궤도면과 근지점을 돌릴 뿐 에너지를 바꾸지 않고, 수명은 에너지를 빼앗는 대기 저항이 정합니다.

  2. 계산 고도 800 km(\(a = 7178\) km), \(i = 98.6^\circ\) 원 궤도의 승교점 회귀율은 태양동기 조건에 가깝습니까?

    힌트 1

    \(n = 1.0382\times10^{-3}\), \((6378/7178)^2 = 0.7895\).

    힌트 2

    \(\cos98.6^\circ = -0.1495\)를 넣어 \(\dot\Omega\)를 계산하고, 태양동기 조건 0.9856°/일과 비교하세요.

    풀이

    \(\dot\Omega = -1.5\times1.0382\times10^{-3}\times1.0826\times10^{-3}\times0.7895\times\cos98.6^\circ = 1.995\times10^{-7}\) rad/s = 0.988°/일로 거의 태양동기입니다.

  3. 계산 \(\rho = 10^{-11}\) kg/m³(약 300 km), \(A/m = 0.01\), \(C_D = 2.2\), \(a = 6678\) km의 하루 고도 손실은?

    힌트 1

    \(da/dt = -\rho(C_DA/m)\sqrt{\mu a}\).

    힌트 2

    \(\sqrt{3.986\times10^{14}\times6.678\times10^6}\)를 구해 \(10^{-11}\times0.022\)를 곱하세요.

    풀이

    \(\sqrt{\mu a} = 5.16\times10^{10}\), \(da/dt = -1.14\times10^{-2}\) m/s, 하루 약 0.98 km.

  4. 판단 학생이 "극궤도 위성은 승교점이 돌지 않으니 태양동기궤도다"라고 했습니다. 판단하세요.

    힌트 1

    태양동기 조건은 승교점이 어떻게 돌아야 합니까?

    힌트 2

    극궤도(90°)에서 \(\cos i = 0\)이면 승교점이 돕니까?

    풀이

    태양동기는 승교점이 하루 +0.986°로 해를 따라 돌아야 합니다. 극궤도는 돌지 않으므로 지방시가 1년 동안 24시간 바뀝니다. 태양동기에는 약간 역행(약 98°)이 필요합니다.

  5. 계산 GPS 위성(\(a = 26{,}560\) km, \(i = 55^\circ\))의 승교점 회귀율은?

    힌트 1

    \(\dot\Omega = -\frac32nJ_2(R/a)^2\cos i\).

    힌트 2

    \(n = \sqrt{\mu/a^3}\)을 먼저 구하고, 결과를 °/일로 바꾸세요.

    풀이

    \(n = 1.458\times10^{-4}\), \((6378/26560)^2 = 0.0577\), \(\dot\Omega = -1.5\times1.458\times10^{-4}\times1.0826\times10^{-3}\times0.0577\times0.5736 = -7.8\times10^{-9}\) rad/s = −0.039°/일.

  6. 도전 몰니야 궤도가 63.4°를 쓰지 않고 70°라면 근지점이 1년에 몇 도 돕니까? (\(a = 26{,}560\) km, \(e = 0.74\))

    힌트 1

    \(p = a(1-e^2) = 12{,}016\) km.

    힌트 2

    \(\dot\omega = \frac34nJ_2(R/p)^2(5\cos^2i - 1)\)에서 \(\cos70^\circ = 0.342\)를 넣고 1년(3.156×10⁷ s)을 곱하세요.

    풀이

    \(n = 1.458\times10^{-4}\), \((6378/12016)^2 = 0.2817\), \(5\cos^270^\circ - 1 = -0.415\). \(\dot\omega = 0.75\times1.458\times10^{-4}\times1.0826\times10^{-3}\times0.2817\times(-0.415) = -1.38\times10^{-8}\) rad/s = 약 −25°/년. 원지점이 수년 만에 북반구 상공을 벗어납니다.
