이 절에서 배울 것
  • 기체 덩어리의 부력 논리로 Schwarzschild 조건을 유도한다.
  • 복사 기울기와 단열 기울기를 비교해 대류층을 판단한다.
  • 대류가 일어나기 쉬운 조건 세 가지를 안다.
먼저 알아야 할 것
  • 에너지 수송과 \(\nabla\) (1.1절), 단열 과정 (공통3 10단원).

뜬 덩어리는 계속 뜰까

별 속에서 기체 덩어리 하나가 우연히 조금 위로 밀려 올라갔다고 합시다. 덩어리는 주변보다 가벼우면 더 떠오르고(불안정, 대류), 무거우면 제자리로 돌아옵니다(안정, 복사층). 이 판단을 식으로 쓴 것이 Schwarzschild 조건입니다.

3.2.1유도

유도. 덩어리는 빨리 움직여 주변과 열을 주고받을 틈이 없으므로 단열 팽창하며, 압력은 늘 주변과 같아집니다(소리 속도로 맞춰짐). 위로 \(dr\)만큼 올라가면 압력이 \(dP\)만큼 줄고, 덩어리의 온도는 단열 관계로 \(d\ln T_{덩어리} = \nabla_{ad}\,d\ln P\)만큼, 주변의 온도는 \(d\ln T_{주변} = \nabla\,d\ln P\)만큼 바뀝니다(\(d\ln P < 0\)). 압력이 같은 이상 기체에서 밀도는 온도에 반비례하므로, 덩어리가 주변보다 뜨거우면 가볍습니다. 덩어리가 더 뜨거워질 조건은 덩어리가 덜 식는 것, 곧 \(\nabla_{ad}|d\ln P| < \nabla|d\ln P|\)입니다. 따라서 \[ \nabla_{rad} > \nabla_{ad} \quad\Longrightarrow\quad \text{대류 (불안정)} \] 입니다. 여기서 주변의 기울기로 복사만 있을 때의 \(\nabla_{rad}\)를 썼습니다. ∎

이상 단원자 기체에서 \(\nabla_{ad} = (\gamma - 1)/\gamma = 0.4\)입니다. 대류가 일어나면 열을 효율적으로 날라 실제 기울기는 \(\nabla_{ad}\)에 아주 가까워집니다.

3.2.2대류가 잘 생기는 조건

\(\nabla_{rad} = \frac{3\kappa FP}{16\pi acGmT^4}\)가 커지거나 \(\nabla_{ad}\)가 작아질 때입니다.

  • 불투명도가 클 때(\(\kappa\) 큼): 차가운 별의 외피, 적색거성.
  • 에너지가 좁은 곳에서 많이 나올 때(\(F/m\) 큼): CNO 순환이 주도하는 무거운 별의 중심(대류핵).
  • 부분 전리 영역: 수소나 헬륨이 전리되는 층에서는 열이 전리에 쓰여 \(\nabla_{ad}\)가 0.1 근처까지 작아진다(태양 대류층의 바닥 근처를 결정).
예제 3.2.1

어떤 층에서 \(\nabla_{rad} = 0.25\), \(\nabla_{ad} = 0.4\)입니다. 복사층입니까? 같은 층에서 불투명도가 2배가 되면?

풀이. \(0.25 < 0.4\)이므로 복사층입니다. 불투명도가 2배면 \(\nabla_{rad} = 0.50 > 0.4\)라 대류층이 됩니다.

결과적으로 질량에 따라 별의 구조가 나뉩니다.

  • \(M < 0.35M_\odot\): 전체가 대류.
  • \(0.35 < M < 1.2M_\odot\): 복사핵 + 대류 외피(태양).
  • \(M > 1.2M_\odot\): 대류핵 + 복사 외피.
주의 성분 기울기가 있으면(핵 바깥에서 헬륨이 줄어드는 층) 무거운 물질이 아래에 있어 안정성이 커집니다. 이것을 넣은 조건을 Ledoux 조건이라 하며, 진화한 별의 대류 경계를 정할 때 중요합니다.
요약
  1. 단열로 움직이는 덩어리가 주변보다 덜 식으면 떠오른다.
  2. Schwarzschild 조건: \(\nabla_{rad} > \nabla_{ad}\)이면 대류. 이상 단원자 \(\nabla_{ad} = 0.4\).
  3. 큰 불투명도, 좁은 곳의 큰 에너지 생성, 부분 전리가 대류를 부른다.
  4. 질량에 따라 완전 대류, 복사핵+대류 외피, 대류핵+복사 외피.

3.2.3연습문제

기본

  1. \(\gamma = 4/3\)(복사가 지배하는 기체)이면 \(\nabla_{ad}\)는?
    답

    0.25.

  2. 대류층의 실제 기울기는 대략 얼마입니까?
    답

    \(\nabla_{ad}\)에 거의 같습니다.

응용

  1. 부분 전리 영역에서 \(\nabla_{ad}\)가 작아지는 까닭은?
    답

    덩어리가 압축되거나 팽창할 때 에너지 일부가 전리·재결합에 쓰여 온도가 덜 변하기 때문입니다.

  2. 태양이 대류핵을 갖지 않는 까닭을 2.2절과 4장의 내용으로 설명하세요.
    답

    태양은 pp 연쇄(T⁴)가 주도해 에너지 생성이 중심에 덜 몰리고(F/m 작음), 중심이 뜨거워 불투명도가 작아 \(\nabla_{rad} < \nabla_{ad}\)이기 때문입니다.

3.2.2

탐구떠오른 기체 덩어리는 계속 떠오를까

탐구 · 대류 조건

다루는 성취기준 [천우9-03-02]

질문

별 속에서 기체 덩어리 하나가 우연히 조금 위로 밀렸습니다. 덩어리가 주변보다 가벼우면 계속 떠오르고(대류), 무거우면 돌아옵니다(안정). 무엇이 이를 정할까요?

복원

덩어리는 빨리 움직여 열을 주고받지 못하므로 단열로 팽창하며 식습니다. 압력은 주변과 늘 같습니다. 압력이 같을 때 더 뜨거운 기체가 더 가볍습니다([천우9-03-02] 본문).

설명

가로축은 위로 올라간 정도(압력의 로그가 줄어든 양), 세로축은 온도의 로그 변화입니다. 주변 온도는 기울기 \(\nabla\)로, 덩어리 온도는 단열 기울기 \(\nabla_{ad}\)로 떨어집니다. 주변이 더 가파르게 식으면(\(\nabla > \nabla_{ad}\)) 덩어리가 상대적으로 뜨거워 계속 떠오릅니다.

연결

이것이 Schwarzschild 조건입니다. 불투명도가 크거나 에너지가 좁은 곳에서 많이 나오면 \(\nabla\)(복사로 나르는 데 필요한 기울기)가 커져 대류가 생깁니다([천우9-01-01], [천우9-02-02]).

적용

  1. ∇ = 0.30, ∇_ad = 0.40: 덩어리가 주변보다 차가워 돌아옵니다(복사층).
  2. ∇를 0.50으로 키우면 덩어리가 0.05만큼(로그) 뜨거워 계속 떠오릅니다(대류).
  3. 부분 전리 영역처럼 ∇_ad가 0.15로 작아지면 ∇ = 0.30에서도 대류가 됩니다.

판단

이 그림은 성분이 고른 이상 기체를 가정했습니다. 아래쪽에 무거운 성분(헬륨)이 쌓인 층은 같은 기울기에서도 안정성이 커지는데, 이를 넣은 것이 Ledoux 조건입니다.
