연습2단원 마무리: 상태 방정식과 불투명도

연습 · 물질의 성질

다루는 성취기준 [천우9-02]

문제

쉬운 것에서 어려운 것 순서입니다. 막히면 힌트 1(방향), 힌트 2(첫 단계)를 차례로 여세요.

  1. 개념 축퇴된 핵에서 핵반응이 폭주하기 쉬운 까닭은?

    힌트 1

    축퇴압은 온도에 얼마나 민감합니까?

    힌트 2

    보통 기체는 데워지면 팽창해 식지만, 축퇴 기체는 어떻게 됩니까?

    풀이

    축퇴압은 온도에 둔감해 데워져도 압력이 오르지 않고 팽창하지 않습니다. 식지 않으니 온도가 계속 오르고 반응률은 온도에 매우 민감해 반응이 폭주합니다.

  2. 계산 \(X = 0.70\), \(Y = 0.28\), \(Z = 0.02\)의 \(\mu\)는?

    힌트 1

    \(1/\mu \approx 2X + \frac34Y + \frac12Z\).

    힌트 2

    2×0.70 + 0.75×0.28 + 0.5×0.02를 구해 역수를 취하세요.

    풀이

    \(1/\mu = 1.40 + 0.21 + 0.01 = 1.62\), \(\mu = 0.617\).

  3. 계산 \(T = 4\times10^7\) K에서 복사압은?

    힌트 1

    \(P_{rad} = aT^4/3\).

    힌트 2

    \((4\times10^7)^4 = 2.56\times10^{30}\).

    풀이

    \(7.566\times10^{-16}\times2.56\times10^{30}/3 = 6.5\times10^{14}\) Pa.

  4. 판단 학생이 "뜨거운 별일수록 불투명도가 커서 대류 외피가 깊다"고 했습니다. 판단하세요.

    힌트 1

    Kramers 불투명도는 온도에 어떻게 의존합니까?

    힌트 2

    \(\kappa \propto \rho T^{-3.5}\): 뜨거우면 커집니까, 작아집니까?

    풀이

    반대입니다. Kramers 불투명도는 온도가 높을수록 작아지고, 뜨거운 별의 외피는 전자 산란이 지배해 복사층입니다. 대류 외피가 깊은 것은 차가운 별입니다.

  5. 계산 온도를 그대로 두고 밀도를 2배, 그다음 온도를 2배로 하면 Kramers 불투명도는?

    힌트 1

    \(\kappa \propto \rho T^{-3.5}\).

    힌트 2

    밀도 2배로 2배, 온도 2배로 \(2^{-3.5}\)배를 곱하세요.

    풀이

    \(2\times2^{-3.5} = 0.177\)배.

  6. 도전 \(\beta = 0.5\)(기체와 복사압이 같음)인 별의 중심에서 \(\rho = 10^3\) kg/m³, \(\mu = 0.6\)이면 온도는?

    힌트 1

    \(\rho kT/(\mu m_H) = aT^4/3\).

    힌트 2

    \(T^3 = 3\rho k/(a\mu m_H)\).

    풀이

    \(T^3 = 3\times10^3\times1.381\times10^{-23}/(7.566\times10^{-16}\times1.0\times10^{-27}) = 5.48\times10^{22}\), \(T = 3.8\times10^7\) K.
