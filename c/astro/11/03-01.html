이 절에서 배울 것
  • 섭동 가속도를 더한 운동 방정식을 직접 수치 적분하는 Cowell 방법을 쓴다.
  • J2 가속도의 직교 좌표 식을 안다.
  • 수치 적분 결과를 평균화 이론과 비교해 검증한다.
먼저 알아야 할 것
  • J2 섭동 (천우8 5.2절), RK4 (천우6 5.1절).

가장 단순하고 가장 많이 쓰는 방법

특수섭동론은 섭동이 있는 운동 방정식을 특정한 처음 조건에서 수치로 적분하는 방법들을 말합니다(일반섭동론은 해석적 근사식, 4장). 그 가운데 Cowell 방법은 모든 가속도를 더해 위치와 속도를 그대로 적분합니다. 계산기가 빨라지면서 가장 널리 쓰이게 되었습니다.

3.1.1운동 방정식

\[ \ddot{\mathbf r} = -\frac{\mu}{r^3}\mathbf r + \mathbf a_{섭동}, \qquad \mathbf a_{섭동} = \mathbf a_{J2} + \mathbf a_{항력} + \mathbf a_{달·태양} + \mathbf a_{복사압} + \cdots \]

지구 편평도 J2의 가속도는 지구 중심 관성 좌표(\(z\)가 자전축)에서

\[ \mathbf a_{J2} = \frac{3J_2\mu R^2}{2r^5}\left[x\left(\frac{5z^2}{r^2} - 1\right),\ y\left(\frac{5z^2}{r^2} - 1\right),\ z\left(\frac{5z^2}{r^2} - 3\right)\right] \]

입니다(\(J_2 = 1.08263\times10^{-3}\), \(R = 6{,}378.137\) km). 위치·속도 6개 성분의 1계 방정식으로 바꿔 RK4나 더 높은 차수의 적분기(RK7(8), Adams 예측-수정)로 적분합니다.

def deriv(t, s):
    x, y, z, vx, vy, vz = s
    r2 = x*x + y*y + z*z; r = r2**0.5
    k = 1.5*J2*MU*RE**2 / r**5; q = 5*z*z/r2
    return [vx, vy, vz,
            -MU*x/r**3 + k*x*(q - 1),
            -MU*y/r**3 + k*y*(q - 1),
            -MU*z/r**3 + k*z*(q - 3)]

3.1.2검증

적분 결과에서 궤도요소를 계산해(천우8 3.1절) 해석 이론과 비교합니다. 아래 실습 카드(고도 500 km 원 궤도, 5일, 간격 20 s)에서 승교점 경도의 변화율은

  • 경사각 51.6°: 수치 \(-4.772°\)/일, 평균화 이론 \(-4.752°\)/일.
  • 경사각 97.4°: 수치 \(+0.990°\)/일, 이론 \(+0.985°\)/일(태양동기).
  • 경사각 90°: 0(극궤도는 승교점이 움직이지 않음).

입니다. 0.4% 정도의 차이는 처음 조건으로 준 원 궤도 반지름이 '접촉' 긴반지름이고, 평균화 이론의 '평균' 긴반지름과 J2의 단주기 항만큼 다르기 때문입니다.

예제 3.1.1

고도 500 km에서 J2 가속도는 중심 중력의 몇 배 정도입니까?

풀이. 크기는 대략 \(\frac32J_2(R/r)^2 = 1.5\times1.08263\times10^{-3}\times(6378/6878)^2 = 1.4\times10^{-3}\)배입니다. 작지만 하루 15바퀴씩 쌓여 승교점을 하루 수 도씩 옮깁니다.

주의 Cowell 방법은 간단하지만 큰 중심 가속도를 그대로 적분하므로 간격이 작아야 하고, 반올림 오차가 쌓입니다. 섭동이 작을 때 더 효율적인 방법이 Encke 방법(3.2절)입니다.
요약
  1. Cowell: \(\ddot{\mathbf r} = -\mu\mathbf r/r^3 + \mathbf a_{섭동}\)을 그대로 수치 적분.
  2. J2 가속도의 직교 좌표 식(\(5z^2/r^2 - 1\), \(-3\) 항).
  3. 500 km, 51.6°: 수치 −4.772°/일 대 이론 −4.752°/일(접촉·평균 요소 차이).
  4. 단순하지만 간격이 작아야 하고 반올림 오차가 쌓인다.

3.1.3연습문제

기본

  1. Cowell 방법에서 적분하는 변수는?
    답

    위치와 속도 6개 성분(직교 좌표).

  2. 극궤도(90°)에서 J2에 의한 승교점 이동은?
    답

    \(\cos90° = 0\)이라 없습니다.

응용

  1. 고도 1,000 km에서 J2 가속도의 상대 크기는?
    답

    \(1.5\times1.0826\times10^{-3}\times(6378/7378)^2 = 1.2\times10^{-3}\).

  2. J2 가속도의 \(z\) 성분이 적도면(\(z = 0\))에서 0인 것의 물리적 뜻은?
    답

    적도의 부푼 질량이 대칭이라 적도면 위의 위성은 위아래로 당겨지지 않습니다. 궤도면이 기울어 있으면 적도 쪽으로 끌려 궤도면이 돌게(세차) 됩니다.

3.1.2

실습Cowell 방법으로 J2 승교점 이동을 재고 이론과 비교하기

실습 · Cowell 적분

다루는 성취기준 [천우11-03-01]

목표

J2를 넣은 운동 방정식을 Cowell 방법으로 5일 동안 적분해 승교점 경도의 변화율을 재고, 평균화 이론의 식과 비교합니다. 태양동기 궤도의 경사각도 찾아봅니다. 성취기준 [천우11-03-01], [천우11-04-02], [천우11-04-03].

준비

원 궤도로 출발해 RK4(간격 20 s)로 적분합니다. 위성이 남에서 북으로 적도를 지날 때마다 각운동량 벡터로 접촉 승교점 경도를 계산해 파란 점으로 찍고, 직선 맞춤의 기울기를 수치 결과로 보입니다. 주황 점선은 \(-\frac32nJ_2(R/a)^2\cos i\)입니다.

절차

  1. 고도 500 km, 경사각 97.4°에서 수치·이론 값과 태양동기와의 차를 읽습니다.
  2. 경사각을 51.6°(국제우주정거장과 비슷)와 28.5°로 바꿔 봅니다.
  3. 경사각 90°와 0.1°에서 비교합니다.
  4. 고도 800 km에서 태양동기가 되는 경사각을 찾습니다(이론 98.6°).

기대 결과

  • 500 km, 97.4°: 수치 0.990°/일, 이론 0.985°/일, 태양동기와의 차 0.004°/일(승교점 통과 76번).
  • 500 km, 51.6°: −4.772 대 −4.752°/일. 400 km, 28.5°: −7.105 대 −7.077°/일.
  • 90°: 0. 1,000 km, 0.1°: −6.003 대 −5.985°/일. 800 km, 98.6°: 0.989 대 0.985°/일.
  • 수치 값이 이론보다 약 0.4% 크다(접촉 요소와 평균 요소의 차).

분석

  1. 경사각이 90°보다 크면 승교점이 동쪽으로 도는 까닭은?
  2. 수치와 이론의 0.4% 차이를 없애려면 처음 조건을 어떻게 고쳐야 합니까?
  3. 태양동기 경사각이 고도가 높을수록 커지는 까닭을 식으로 설명하세요.
