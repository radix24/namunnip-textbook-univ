먼저 알아야 할 것
  • Hohmann 전이 (1.1절), Kepler 방정식 (천우8 2.2절).

A에서 B까지 정해진 시간에

"지금 지구 위치에서 출발해 200일 뒤 화성이 있을 위치에 도착하려면 어떤 속도로 떠나야 하는가?" 이 질문이 Lambert 문제입니다. 행성 간 탐사의 발사 시기 설계(포크찹 그림), 랑데부, 관측 두 개로 궤도를 정하는 데 쓰입니다.

2.2.1문제와 해의 구조

위치 \(\mathbf r_1\), \(\mathbf r_2\), 비행 시간 \(\Delta t\), 운동 방향(순행)이 주어지면, 그 두 점을 \(\Delta t\) 만에 지나는 원뿔곡선 궤도는(한 바퀴 안에서) 하나로 정해집니다. 램버트 정리에 따르면 비행 시간은 \(r_1 + r_2\), 현의 길이 \(c = |\mathbf r_2 - \mathbf r_1|\), 긴반지름 \(a\)만으로 정해집니다.

2.2.2보편 변수 풀이

Curtis 교재의 알고리즘은 보편 변수 \(z = \alpha\chi^2\)(타원 \(z > 0\), 포물선 0, 쌍곡선 음수)에 대한 한 방정식으로 바꿉니다. 스톰프 함수 \(C(z)\), \(S(z)\)를 쓰고

\[ A = \sin\Delta\theta\sqrt{\frac{r_1r_2}{1 - \cos\Delta\theta}}, \quad y(z) = r_1 + r_2 + A\frac{zS(z) - 1}{\sqrt{C(z)}}, \quad \sqrt\mu\,\Delta t = \left(\frac{y}{C}\right)^{3/2}S + A\sqrt y \]

의 마지막 식을 \(z\)에 대해 풀면(이분법이나 뉴턴 방법), 라그랑주 계수 \(f = 1 - y/r_1\), \(g = A\sqrt{y/\mu}\), \(\dot g = 1 - y/r_2\)로

\[ \mathbf v_1 = \frac{\mathbf r_2 - f\mathbf r_1}{g}, \qquad \mathbf v_2 = \frac{\dot g\mathbf r_2 - \mathbf r_1}{g} \]

를 얻습니다. 전이각 \(\Delta\theta = 180°\)이면 \(A = 0\)이 되어 궤도면이 정해지지 않으므로(두 점과 중심이 한 줄) 따로 다룹니다.

예제 2.2.1 (아래 실습 카드 결과)

원 궤도, 한 평면으로 단순화한 지구(1 AU)→화성(1.524 AU) 전이의 결과입니다.

  • 전이각 179°, 259일(Hohmann에 가까움): 출발 초과 속도 2.95 km/s, 도착 2.65 km/s. Hohmann 값 2.946, 2.650 km/s와 맞는다.
  • 150°, 200일: 3.21, 4.01 km/s, 긴반지름 1.294 AU.
  • 179°, 200일(같은 각을 더 빨리): 6.56, 6.50 km/s로 크게 비싸진다.
  • 200°, 300일: 3.04, 3.06 km/s.

출발·도착 날짜를 바꿔 가며 이 값을 등고선으로 그린 것이 포크찹 그림입니다. 지구와 화성의 상대 위치가 Hohmann에 맞는 시기(약 26개월마다)에 가장 싼 골짜기가 나타납니다.

주의 실제 행성 궤도는 이심률과 경사각이 있어 3차원 Lambert 문제를 풀어야 하며, 그 결과가 2차원 단순화와 수백 m/s 다를 수 있습니다. 출발 초과 속도 \(v_\infty\)는 지구 중력권을 빠져나간 뒤의 속도이고, 저궤도에서 필요한 \(\Delta v\)는 \(\sqrt{v_\infty^2 + 2\mu/r} - v_c\)입니다.
요약
  1. Lambert 문제: 두 위치와 비행 시간으로 궤도(출발·도착 속도)를 정한다.
  2. 보편 변수 \(z\)의 한 방정식을 풀고 라그랑주 계수로 \(\mathbf v_1, \mathbf v_2\)를 얻는다.
  3. \(\Delta\theta = 180°\)에서는 궤도면이 정해지지 않는다.
  4. 지구→화성: Hohmann 근처(259일)에서 출발 2.95, 도착 2.65 km/s. 포크찹 그림으로 시기를 고른다.

2.2.3연습문제

기본

  1. Lambert 문제의 입력과 출력은?
    답

    입력: 두 위치 벡터, 비행 시간, 방향. 출력: 출발·도착 속도 벡터(곧 궤도).

  2. \(\Delta\theta = 90°\)일 때 \(A\)의 부호는?
    답

    \(\sin90° = 1 > 0\)이므로 양수.

응용

  1. 출발 초과 속도 2.95 km/s를 고도 200 km 원 궤도(7.784 km/s)에서 내는 \(\Delta v\)는?
    답

    \(\sqrt{2.95^2 + 2\times398600/6578} - 7.784 = \sqrt{8.70 + 121.19} - 7.784 = 11.397 - 7.784 = 3.61\) km/s.

  2. 같은 전이각에서 비행 시간을 줄이면 비용이 커지는 까닭은?
    답

    더 납작하고 빠른(긴반지름이 큰) 궤도가 필요해 출발·도착에서 행성과의 속도 차가 커지기 때문입니다.

2.2.2

실습Lambert 문제로 지구에서 화성 가는 궤도 설계하기

실습 · Lambert 문제

다루는 성취기준 [천우11-02-02]

목표

전이각과 비행 시간을 바꾸며 Lambert 문제를 풀어, 지구 출발과 화성 도착의 초과 속도가 어떻게 달라지는지 보고 Hohmann 전이와 비교합니다. 성취기준 [천우11-02-02].

준비

지구(1 AU)와 화성(1.524 AU)을 같은 평면의 원 궤도로 단순화했습니다. 지구는 x축 위에서 출발하고, 화성은 도착 때 전이각만큼 앞선 위치에 있습니다. 보편 변수 방법(Curtis 알고리즘 5.2)을 이분법으로 풀고, 얻은 출발 속도로 궤도를 RK4로 전파해 파란 선으로 그립니다. 파란 선이 빨간 점(화성)에 닿으면 풀이가 맞은 것입니다.

절차

  1. 전이각 150°, 비행 시간 200일에서 결과를 읽습니다.
  2. 전이각 179°, 비행 시간 259일로 두어 Hohmann 전이와 비교합니다(정확히 180°는 풀리지 않음).
  3. 전이각 179°에서 비행 시간을 200일로 줄여 봅니다.
  4. 전이각을 120°, 200°, 250°로 바꾸며 가장 싼 비행 시간을 찾아봅니다.

기대 결과

  • 150°, 200일: 긴반지름 1.294 AU, 이심률 0.227, 출발 v∞ 3.21 km/s, 도착 4.01 km/s, 합 7.23 km/s.
  • 179°, 259일: 1.262 AU, 0.208, 2.95와 2.65 km/s(합 5.60). Hohmann의 2.946, 2.650 km/s와 맞는다.
  • 179°, 200일: 6.56과 6.50 km/s(합 13.06). 120°, 150일: 4.16과 7.03 km/s. 200°, 300일: 3.04와 3.06 km/s.

분석

  1. Hohmann 근처에서 비용이 가장 작은 까닭을 출발·도착 속도의 방향으로 설명하세요.
  2. 전이각을 180°보다 조금 크게 하면 비행 시간이 길어지는 대신 무엇이 달라집니까?
  3. 출발 날짜를 고정하고 도착 날짜를 바꾸면 전이각과 비행 시간이 함께 바뀝니다. 포크찹 그림은 이를 어떻게 나타냅니까?

더 해 보기

행성 위치표(JPL Horizons)로 실제 지구와 화성 위치를 넣어 3차원 Lambert 문제를 풀고, 다음 화성 발사 시기의 포크찹 그림을 그려 보세요(Python poliastro나 직접 짠 코드).
