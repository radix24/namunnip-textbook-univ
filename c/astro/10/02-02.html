  • 고유값과 고유벡터 (수학2 선형대수), LU 분해 (2.1절).

고유값이 나오는 곳

\(A\mathbf v = \lambda\mathbf v\)를 만족하는 \(\lambda\)와 \(\mathbf v\)가 고유값과 고유벡터입니다. 별의 진동 모드(성진학), 궤도나 평형의 안정성(선형화한 계의 고유값의 부호), 수많은 스펙트럼을 몇 개의 기본 성분으로 요약하는 주성분 분석(공분산 행렬의 고유벡터)이 모두 고유값 문제입니다.

2.2.1거듭제곱 방법

아무 벡터 \(\mathbf v_0\)에 \(A\)를 거듭 곱하면, 가장 큰(절댓값) 고유값 \(\lambda_1\)의 고유벡터 성분이 다른 성분보다 \((\lambda_1/\lambda_2)^k\)배 빨리 자라 결국 그 방향만 남습니다. 고유값은 레일리 몫 \(\mathbf v^T A\mathbf v/\mathbf v^T\mathbf v\)로 읽습니다.

예제 2.2.1

\(A = \begin{pmatrix}2&1\\1&2\end{pmatrix}\)(고유값 3, 1)에 \(\mathbf v_0 = (1, 0)\)에서 거듭제곱 방법을 두 번 적용하고 레일리 몫을 구하세요.

풀이. \(\mathbf v_1 = A\mathbf v_0 = (2, 1)\), \(A\mathbf v_1 = (5, 4)\), 레일리 몫 \((2\cdot5 + 1\cdot4)/5 = 2.8\). \(\mathbf v_2 = (5, 4)\), \(A\mathbf v_2 = (14, 13)\), 몫 \((70 + 52)/41 = 2.976\). 오차가 0.2에서 0.024로 약 \((1/3)^2 = 1/9\)씩 줄어듭니다(대칭 행렬에서 레일리 몫은 비의 제곱으로 수렴).

두 고유값이 비슷하면(\(\lambda_2/\lambda_1 \approx 1\)) 수렴이 매우 느립니다. 원하는 값 \(\sigma\) 근처의 고유값은 \((A - \sigma I)^{-1}\)에 거듭제곱 방법을 쓰는 역반복으로 구하며, 이때 매번 LU로 연립방정식을 풉니다.

2.2.2라이브러리

모든 고유값은 QR 알고리즘(LAPACK)으로 구합니다. 계산량은 \(n^3\) 정도입니다.

import numpy as np
A = np.array([[2., 1], [1, 2]])
w, V = np.linalg.eigh(A)      # 대칭 행렬용: w = [1, 3], V의 열이 고유벡터
print(A @ V[:, 1] - w[1] * V[:, 1])   # 확인: 0에 가까워야 함

대칭 행렬에는 eigh(빠르고 고유값이 실수로 정렬됨), 일반 행렬에는 eig(복소수 고유값 가능)를 씁니다. 큰 희소 행렬에서 몇 개만 필요하면 scipy.sparse.linalg.eigsh를 씁니다.

2.2.3안정성 판단

평형점 근처에서 \(\dot{\mathbf x} = J\mathbf x\)로 선형화하면, \(J\)의 고유값 실수부가 모두 음수면 안정, 하나라도 양수면 불안정입니다. 예를 들어 삼체 문제의 라그랑주점 L1~L3에서는 양의 실수 고유값이 있어 불안정합니다(천우8 4.3절).

주의 고유벡터는 크기와 부호가 정해지지 않아 라이브러리마다 \(-\mathbf v\)를 줄 수도 있습니다. 결과를 비교할 때는 부호와 정규화를 맞추세요.
요약
  1. 거듭제곱 방법: \(A^k\mathbf v_0\)가 가장 큰 고유값의 고유벡터로 수렴, 오차 비 \(\lambda_2/\lambda_1\).
  2. 역반복으로 원하는 값 근처의 고유값을 구한다.
  3. 라이브러리: 대칭은 eigh, 일반은 eig, 희소는 eigsh.
  4. 선형화한 계의 고유값 실수부 부호로 안정성을 판단한다.

2.2.4연습문제

기본

  1. \(\begin{pmatrix}3&0\\0&1\end{pmatrix}\)에 \((1, 1)\)을 세 번 곱하면?
    답

    \((27, 1)\). 첫 성분이 지배합니다.

  2. 고유값 5와 4.9인 행렬에서 거듭제곱 방법의 수렴은 빠릅니까?
    답

    느립니다. 한 번에 오차가 0.98배밖에 줄지 않습니다.

응용

  1. 거듭제곱 방법으로 오차를 \(10^{-6}\)으로 줄이려면 \(\lambda_2/\lambda_1 = 0.5\)에서 몇 번(벡터 기준)?
    답

    \(0.5^k = 10^{-6}\), \(k = 20\)번.

  2. \(J = \begin{pmatrix}0&1\\4&0\end{pmatrix}\)인 평형점은 안정합니까?
    답

    고유값 \(\pm2\). 양수 2가 있어 불안정합니다.
