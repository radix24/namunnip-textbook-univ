포물선이 아닐 때

매개변수가 많거나 \(\chi^2\)가 포물선 모양이 아니면(구불구불한 골짜기, 봉우리 여러 개) \(\Delta\chi^2 = 1\)로 오차를 읽기 어렵습니다. 그럴 때 매개변수 공간을 무작위로 걸어 다니며 사후 분포에서 표본을 뽑는 방법이 MCMC(Markov chain Monte Carlo)입니다. 외계행성 궤도 맞춤, 우주론 매개변수 추정에 표준으로 쓰입니다.

5.2.1사후 분포

베이즈 정리로 자료 \(D\)를 본 뒤 매개변수의 확률(사후 분포)은

\[ p(\theta|D) \propto \mathcal L(D|\theta)\,p(\theta) \]

입니다. \(p(\theta)\)는 사전 분포(자료를 보기 전의 지식, 예: 질량은 양수). 사전 분포가 고르면 사후 분포는 \(e^{-\chi^2/2}\)에 비례합니다.

5.2.2Metropolis 알고리즘

  1. 현재 위치 \(\theta\)에서 무작위로 한 걸음 제안: \(\theta' = \theta + s\cdot\mathcal N(0, 1)\).
  2. 사후 확률의 비 \(\alpha = p(\theta'|D)/p(\theta|D) = e^{-(\chi'^2 - \chi^2)/2}\)를 계산한다.
  3. \(\alpha \ge 1\)이면 받아들이고, 아니면 확률 \(\alpha\)로 받아들인다(0~1 난수 \(u\)를 뽑아 \(u < \alpha\)이면). 받아들이지 않으면 제자리에 한 번 더 머문다.
  4. 되풀이한다. 처음 일부(버리는 구간, burn-in)는 출발점의 영향이 남아 버린다.

이렇게 모인 위치들의 분포가 사후 분포가 됩니다. 평균과 표준편차, 또는 16·50·84 백분위수를 매개변수 값과 불확도로 보고합니다.

5.2.3걸음 크기와 수렴

아래 실습 카드(가상 자료, 5.1절 예제와 같음, 해석해 \(a = 1.819 \pm 0.078\), \(b = 1.635 \pm 0.431\))의 결과입니다.

  • 걸음 0.1, 5,000걸음: 받아들임 41.9%, \(a = 1.810 \pm 0.073\), \(b = 1.695 \pm 0.410\). 해석해와 잘 맞는다.
  • 걸음 0.01: 받아들임 88.6%, \(b = 1.136 \pm 0.203\). 너무 조금씩 움직여 아직 출발점(0) 근처를 벗어나는 중이고, 불확도도 작게 나온다.
  • 걸음 1: 받아들임 2.9%. 거의 늘 제자리라 표본이 적어 결과가 거칠다.
  • 걸음 0.1, 20,000걸음: \(a = 1.818 \pm 0.080\), \(b = 1.642 \pm 0.449\). 길게 돌릴수록 해석해에 다가간다.

받아들임 비율은 대략 20~50%가 좋습니다. 수렴은 사슬 그림(값이 출발점의 흔적 없이 고르게 오르내리는지), 출발점을 바꾼 여러 사슬의 비교(Gelman-Rubin 지표), 자기상관 길이로 판단합니다. \(a\)와 \(b\)처럼 상관이 강한 매개변수는 둥근 걸음으로 탐색하기 어려우므로 상관을 반영한 제안 분포나 emcee 같은 앙상블 표본기를 씁니다.

주의 MCMC는 자료와 모형, 사전 분포가 정한 사후 분포를 뽑을 뿐입니다. 모형이 틀리면 MCMC 결과도 틀립니다. 사전 분포를 바꿨을 때 결과가 크게 달라지면 자료가 그 매개변수를 잘 제약하지 못한다는 뜻입니다.
요약
  1. 사후 분포 \(p(\theta|D) \propto \mathcal L\,p(\theta)\), 고른 사전 분포면 \(\propto e^{-\chi^2/2}\).
  2. Metropolis: 제안 → 비 \(\alpha\) → 확률 \(\min(1,\alpha)\)로 받아들임 → 반복, 처음 일부는 버림.
  3. 받아들임 20~50%가 알맞다. 너무 작은 걸음은 수렴이 늦고, 너무 큰 걸음은 거의 늘 거절된다.
  4. 사슬 그림, 여러 사슬 비교, 자기상관으로 수렴을 판단한다.

5.2.4연습문제

기본

  1. 현재 \(\chi^2 = 20\), 제안 \(\chi'^2 = 22\)이면 받아들일 확률은?
    답

    \(e^{-1} = 0.37\).

  2. 제안 \(\chi'^2 = 18\)이면?
    답

    1(언제나 받아들임).

응용

  1. 받아들임 비율이 95%라면 걸음 크기를 어떻게 바꿔야 합니까?
    답

    키웁니다. 너무 작은 걸음이라 사슬이 느리게 움직입니다.

  2. 사슬 10,000걸음의 자기상관 길이가 200걸음이면 독립 표본은 대략 몇 개?
    답

    약 50개.

5.2.2

실습Metropolis MCMC로 직선의 기울기와 절편 추정하기

실습 · MCMC

다루는 성취기준 [천우10-05-02]

목표

가상 자료에 직선을 Metropolis 알고리즘으로 맞추고, 걸음 크기와 걸음 수에 따라 받아들임 비율과 결과가 어떻게 바뀌는지 해석해와 비교합니다. 성취기준 [천우10-05-02].

준비

가상 자료: \(x = 0, 0.5, \ldots, 9.5\)에서 참값 \(y = 2x + 1\)에 \(\sigma = 1\)의 가우스 잡음을 더한 20개(5.1절 예제와 같음). 사슬은 \((a, b) = (0, 0)\)에서 출발하고, 앞 20%를 버립니다. 그림은 기울기 \(a\)의 사슬입니다.

절차

  1. 걸음 0.1, 5,000걸음, 씨앗 1에서 받아들임 비율과 결과를 읽고 해석해와 비교합니다.
  2. 걸음을 0.01과 1로 바꿔 봅니다.
  3. 걸음 0.1에서 20,000걸음으로 늘려 봅니다.
  4. 씨앗을 2로 바꿔 결과가 얼마나 달라지는지 봅니다.

기대 결과

  • 해석해: a = 1.819 ± 0.078, b = 1.635 ± 0.431.
  • 걸음 0.1, 5,000걸음, 씨앗 1: 받아들임 41.9%, a = 1.810 ± 0.073, b = 1.695 ± 0.410. 씨앗 2: 41.4%, a = 1.840 ± 0.071, b = 1.501 ± 0.384.
  • 걸음 0.01: 88.6%, a = 1.907 ± 0.049, b = 1.136 ± 0.203(아직 수렴하지 않음). 걸음 1: 2.9%, a = 1.820 ± 0.086, b = 1.637 ± 0.485.
  • 걸음 0.1, 20,000걸음: a = 1.818 ± 0.080, b = 1.642 ± 0.449.

분석

  1. 걸음 0.01의 사슬 그림에서 처음 부분이 어떤 모양이며, 왜 버리는 구간(20%)으로도 부족합니까?
  2. 씨앗에 따른 평균의 차이(1.810 대 1.840)는 불확도(0.07)에 비해 큰가요? 이것이 '몬테카를로 오차'입니다.
  3. b의 불확도가 a보다 해석해에 더 늦게 다가가는 까닭을 a와 b의 상관으로 설명하세요.
