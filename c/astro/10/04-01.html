퍼지는 것들의 방정식

열, 광자 에너지, 부착원반의 질량, 자기장은 확산하며 퍼집니다. 이들은 모두 확산 방정식

\[ \frac{\partial u}{\partial t} = D\frac{\partial^2u}{\partial x^2} \]

을 따릅니다. 공간을 \(\Delta x\), 시간을 \(\Delta t\) 간격의 격자로 나누고 도함수를 차분으로 바꾸면 컴퓨터로 풀 수 있습니다. 서울대·연세대·경희대 전산 과목에 공통으로 나오는 내용입니다.

4.1.1명시적 방법(FTCS)

시간은 앞 차분, 공간은 가운데 차분으로 바꾸면

\[ u_i^{n+1} = u_i^n + r\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right), \qquad r = \frac{D\Delta t}{\Delta x^2} \]

입니다. 새 값이 옛 값만으로 바로 계산되어 간단합니다.

4.1.2안정 조건

유도 (von Neumann). 오차를 파동 성분 \(u_i^n = G^ne^{ikx_i}\)로 나눠 넣으면 \(G = 1 + r(e^{ik\Delta x} - 2 + e^{-ik\Delta x}) = 1 - 4r\sin^2(k\Delta x/2)\)입니다. 오차가 자라지 않으려면 모든 \(k\)에서 \(|G| \le 1\)이어야 하고, 가장 나쁜 성분(\(\sin^2 = 1\), 격자 간격 두 칸짜리 파장)에서 \(|1 - 4r| \le 1\), 곧 \[ r = \frac{D\Delta t}{\Delta x^2} \le \frac12 \] 입니다. ∎

격자를 2배 촘촘히 하면 \(\Delta t\)를 4배 줄여야 하므로 계산량이 8배가 됩니다. 아래 실습에서 \(r = 0.52\)로 조금만 넘겨도 100걸음 뒤 최대값이 77로 폭발합니다.

4.1.3암시적 방법(BTCS)

공간 차분을 새 시간 값으로 쓰면

\[ -ru_{i-1}^{n+1} + (1 + 2r)u_i^{n+1} - ru_{i+1}^{n+1} = u_i^n \]

이고, \(G = 1/(1 + 4r\sin^2(k\Delta x/2))\)라 어떤 \(r\)에서도 \(|G| \le 1\)(무조건 안정)입니다. 걸음마다 삼중 대각 연립방정식을 풀어야 하지만, 토마스 알고리즘(삼중 대각용 가우스 소거)은 \(N\)에 비례하는 연산으로 끝납니다.

예제 4.1.1 (실습 카드 결과)

격자 50칸, 가운데 사각형(높이 1, 11칸)에서 같은 시간 \(Dt = 0.016\)까지 적분한 결과를 비교하세요.

  • 명시적, \(r = 0.4\), 100걸음: 최대 0.4608.
  • 암시적, \(r = 0.4\), 100걸음: 0.4635.
  • 암시적, \(r = 2\), 20걸음: 0.4689(5배 적은 걸음으로 안정, 시간 오차가 조금 큼).
  • 명시적, \(r = 0.6\), 100걸음(\(Dt = 0.024\)): \(1.5\times10^{13}\)(불안정).

천체물리에서는 확산이 빠른 곳(별 내부의 복사 확산)과 느린 곳이 함께 있어 명시적 방법의 \(\Delta t\)가 지나치게 작아지기 쉽습니다. 그래서 확산 항은 대개 암시적으로 풉니다.

주의 무조건 안정이 정확하다는 뜻은 아닙니다. \(r\)이 크면 시간 오차가 커지고, 빠르게 변하는 현상을 놓칩니다. 정확도가 필요하면 2차 정확도의 Crank-Nicolson(명시와 암시의 평균)을 씁니다.
요약
  1. FTCS: \(u_i^{n+1} = u_i^n + r(u_{i+1} - 2u_i + u_{i-1})\), \(r = D\Delta t/\Delta x^2\).
  2. von Neumann: \(G = 1 - 4r\sin^2(k\Delta x/2)\) → 안정 조건 \(r \le 1/2\).
  3. BTCS는 무조건 안정, 삼중 대각계를 토마스 알고리즘으로 \(N\)번 연산에 푼다.
  4. 격자를 2배 촘촘히 하면 명시적 방법은 계산량 8배.

4.1.4연습문제

기본

  1. \(D = 1\), \(\Delta x = 0.02\)이면 FTCS의 최대 \(\Delta t\)는?
    답

    \(0.5\times0.0004 = 2\times10^{-4}\).

  2. \(r = 0.6\)에서 가장 짧은 파장 성분은 한 걸음에 몇 배?
    답

    \(|1 - 2.4| = 1.4\)배.

응용

  1. \(r = 0.6\)에서 반올림 오차 \(10^{-16}\)이 \(10^{-2}\)까지 자라는 데 몇 걸음?
    답

    \(1.4^n = 10^{14}\), \(n = 14/\log1.4 = 96\)걸음.

  2. 1차원 격자 1,000칸의 암시적 방법 한 걸음은 일반 가우스 소거와 토마스 알고리즘으로 각각 몇 번의 연산?
    답

    가우스 소거 약 \(\frac23\times10^9\), 토마스 약 \(8\times10^3\).

4.1.2

실습확산 방정식의 명시적·암시적 차분과 안정 조건

실습 · 유한 차분

다루는 성취기준 [천우10-04-01]

목표

1차원 확산 방정식을 명시적(FTCS)·암시적(BTCS) 방법으로 풀어, \(r = D\Delta t/\Delta x^2\)이 1/2을 넘을 때 명시적 방법이 폭발하는 것을 확인합니다. 성취기준 [천우10-04-01].

준비

격자는 50칸(\(\Delta x = 0.02\)), 양 끝은 \(u = 0\)으로 고정합니다. 처음 상태는 가운데 11칸이 1인 사각형입니다. 사각형은 짧은 파장 성분을 많이 가져 불안정이 잘 드러납니다. 암시적 방법은 토마스 알고리즘으로 풉니다.

절차

  1. 명시적, r = 0.4, 100걸음에서 모양과 최대값, 합을 읽습니다.
  2. r을 0.5, 0.52, 0.6으로 올려 봅니다.
  3. 암시적으로 바꿔 r = 0.6, 2.0에서 다시 봅니다.
  4. 같은 무차원 시간(r × 걸음 수가 같게)에서 명시적 r = 0.4 × 100걸음과 암시적 r = 2 × 20걸음을 비교합니다.

기대 결과

  • 명시적 r = 0.4, 100걸음: 최대 0.4608, 합 10.82(처음 11, 양 끝으로 조금 빠져나감).
  • r = 0.5: 0.4493(안정의 경계). r = 0.52: 76.56. r = 0.6: 1.48×10¹³으로 지그재그 모양이 폭발한다.
  • 암시적 r = 0.4, 100걸음: 0.4635. r = 0.6, 100걸음: 0.386. r = 2, 20걸음: 0.4689로 모두 안정하다.

분석

  1. r = 0.52에서 폭발하는 모양이 칸마다 부호가 바뀌는 지그재그인 까닭을 von Neumann 분석으로 설명하세요.
  2. 같은 시간에서 암시적 r = 2의 결과(0.4689)가 r = 0.4(0.4635)와 조금 다른 까닭은?
  3. 합 Σu가 시간에 따라 줄어드는 물리적 까닭은?
