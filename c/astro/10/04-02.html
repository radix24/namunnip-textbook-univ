별의 표면에서 나오는 빛을 계산하기

별의 스펙트럼과 주연 감광은 대기 속 복사 전달의 결과입니다. 대기의 두께가 별의 반지름보다 훨씬 얇으면 평평한 판의 층들로 보아도 됩니다(평행판 근사). 서울대 전산천문학이 N체와 함께 다루는 두 번째 큰 주제입니다.

4.2.1방정식과 형식해

광학적 깊이 \(\tau\)(안쪽으로 증가)와 방향 \(\mu = \cos\theta\)(바깥쪽이 양수)에 대해

\[ \mu\frac{dI}{d\tau} = I - S \]

입니다. \(S\)는 원천 함수(국소 열평형에서 플랑크 함수 \(B\)). 표면(\(\tau = 0\))에서 바깥으로 나오는 세기의 형식해는

\[ I(0, \mu) = \int_0^\infty S(\tau)\,e^{-\tau/\mu}\,\frac{d\tau}{\mu} \]

입니다. 각 깊이의 원천이 \(e^{-\tau/\mu}\)만큼 흡수되며 더해진다는 뜻입니다.

4.2.2Eddington-Barbier와 주연 감광

\(S = a + b\tau\)(선형)이면 적분이 정확히 \(I(0, \mu) = a + b\mu\)가 됩니다. 곧 \(\mu\) 방향으로 나오는 세기는 깊이 \(\tau = \mu\)의 원천 함수와 같습니다(Eddington-Barbier 관계). 회색 대기의 에딩턴 근사에서 \(S \propto \tau + \frac23\)이므로

\[ \frac{I(\mu)}{I(1)} = \frac{\frac23 + \mu}{\frac53} = 0.4 + 0.6\mu \]

입니다. 원반 가장자리(\(\mu \to 0\))는 가운데의 40% 밝기로, 태양에서 실제로 보이는 주연 감광과 비슷합니다.

4.2.3수치 적분

\(S(\tau)\)가 표로 주어지면 \(\tau\)를 로그 간격 격자(표면 근처를 촘촘히)로 나누고, 각 칸에서 \(S\)를 선형으로 보아 정확히 적분한 값을 더합니다.

import numpy as np
tau = np.concatenate([[0], np.logspace(-4, 1.5, 400)])
S = tau + 2/3                                    # 에딩턴 회색 대기 (상대값)
def I0(mu):
    w = np.exp(-tau / mu)
    return np.trapz(S * w, tau) / mu
print([round(I0(m) / I0(1), 4) for m in (1, 0.5, 0.2)])   # [1.0, 0.7, 0.52]

사다리꼴 공식이어도 격자가 촘촘하면 해석해 \(0.4 + 0.6\mu\)(1, 0.7, 0.52)와 소수 넷째 자리까지 맞습니다. 이렇게 답을 아는 경우로 코드를 시험한 뒤 실제 대기 모형의 \(S(\tau)\)를 넣습니다.

4.2.4산란과 람다 반복

산란이 있으면 원천 함수가 복사장 자체에 의존합니다: \(S = (1 - \epsilon)J + \epsilon B\)(\(J\)는 평균 세기, \(\epsilon\)은 흡수 비율). \(S\)를 추측해 \(J\)를 계산하고 다시 \(S\)를 고치는 람다 반복은 \(\epsilon\)이 작을 때(산란이 지배) 매우 느리게 수렴하고, 바뀜이 작아 수렴한 것처럼 보이는 함정이 있습니다. 실제 코드는 가속 람다 반복(ALI)이나 연립방정식으로 한 번에 푸는 방법(Feautrier)을 씁니다.

주의 평행판 근사는 대기 두께가 반지름보다 훨씬 얇을 때만 맞습니다. 적색 초거성처럼 대기가 두꺼운 별은 구면 복사 전달이 필요합니다.
요약
  1. \(\mu\,dI/d\tau = I - S\), 형식해 \(I(0,\mu) = \int S e^{-\tau/\mu}d\tau/\mu\).
  2. 선형 \(S\)에서 \(I(0,\mu) = S(\tau = \mu)\) (Eddington-Barbier).
  3. 회색 에딩턴 대기의 주연 감광 \(I(\mu)/I(1) = 0.4 + 0.6\mu\).
  4. 산란이 지배하면 람다 반복이 느리므로 ALI나 Feautrier 방법을 쓴다.

4.2.5연습문제

기본

  1. 에딩턴 회색 대기에서 \(\mu = 0.5\)의 상대 세기는?
    답

    0.7.

  2. Eddington-Barbier 관계로 \(\mu = 1\)(원반 중심)의 세기는 어느 깊이의 원천 함수입니까?
    답

    \(\tau = 1\).

응용

  1. \(S = 1 + 3\tau\)이면 \(I(0, \mu)\)와 \(I(0.2)/I(1)\)은?
    답

    \(1 + 3\mu\), \(1.6/4 = 0.4\).

  2. 원반 가장자리가 어두운 까닭을 Eddington-Barbier로 설명하세요.
    답

    가장자리(\(\mu\) 작음)에서는 얕은 깊이(\(\tau = \mu\))의 차가운 층을 보므로 원천 함수가 작아 어둡습니다.
