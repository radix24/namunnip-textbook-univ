4.R.1

연습4단원 마무리: 수치 미분과 적분

연습 · 미분과 적분

다루는 성취기준 [천우6-04]

문제

쉬운 것에서 어려운 것 순서입니다. 막히면 힌트 1(방향), 힌트 2(첫 단계)를 차례로 여세요.

  1. 개념 Simpson 공식이 사다리꼴 공식보다 정확한 까닭은?

    힌트 1

    조각을 어떤 곡선으로 어림합니까?

    힌트 2

    직선은 휘어짐을 담지 못하고 포물선은 담습니다. 오차의 차수를 비교하세요.

    풀이

    사다리꼴은 직선, Simpson은 포물선으로 어림해 곡률까지 반영하므로 오차가 \(h^2\)에서 \(h^4\)로 줄어듭니다.

  2. 계산 \(f(x) = e^x\)의 \(x = 0\)에서 \(h = 0.1\) 중앙 차분은?

    힌트 1

    \((e^{0.1} - e^{-0.1})/0.2\).

    힌트 2

    \(e^{0.1} = 1.10517\), \(e^{-0.1} = 0.90484\)를 넣으세요.

    풀이

    \((1.10517 - 0.90484)/0.2 = 1.00167\)(참값 1).

  3. 계산 사다리꼴 공식으로 \(\int_0^2x^3dx\)를 \(n = 2\)로 계산하고 참값과 비교하세요.

    힌트 1

    \(h = 1\).

    힌트 2

    점 x = 0, 1, 2에서 값 0, 1, 8. 사다리꼴은 \(h(f_0/2 + f_1 + f_2/2)\).

    풀이

    \(1\times(0/2 + 1 + 8/2) = 5\), 참값 4. Simpson(\(n = 2\))은 \((1/3)(0 + 4 + 8) = 4\)로 정확합니다(3차까지 정확).

  4. 판단 학생이 Simpson 공식에 \(n = 7\)을 넣었더니 답이 이상했습니다. 왜?

    힌트 1

    Simpson은 조각을 두 개씩 묶습니다.

    힌트 2

    n이 홀수면 마지막 조각 하나가 짝을 이루지 못합니다.

    풀이

    Simpson 공식은 \(n\)이 짝수여야 합니다. 홀수면 마지막 조각의 가중치가 잘못되어 답이 틀립니다.

  5. 계산 4.3절 적분에서 Simpson 100구간의 상대 오차는?

    힌트 1

    \(6.494981/6.493939 - 1\).

    힌트 2

    두 값의 비에서 1을 빼세요.

    풀이

    \(1.6\times10^{-4}\).

  6. 도전 사다리꼴 \(T(h) = I + ch^2\)이면 \(T(h)\)와 \(T(h/2)\)로 \(I\)를 구하는 식을 유도하세요.

    힌트 1

    \(T(h/2) = I + ch^2/4\).

    힌트 2

    두 식에서 c를 없애도록 \(T(h/2)\)에 4를 곱해 \(T(h)\)를 빼세요.

    풀이

    \(4T(h/2) - T(h) = 3I\)이므로 \(I = [4T(h/2) - T(h)]/3\)(Richardson 외삽, Simpson 공식과 같음).
