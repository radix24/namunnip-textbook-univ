  • 무한 구간 적분을 유한 구간으로 바꾸고 특이점처럼 보이는 점을 처리한다.

교과서의 적분을 컴퓨터로

천우3 2.1절에서 Stefan-Boltzmann 법칙을 유도할 때 \(\int_0^\infty\frac{x^3}{e^x - 1}dx = \frac{\pi^4}{15}\)를 급수로 계산했습니다. 이 절에서는 같은 적분을 수치로 계산해 해석 결과를 확인합니다. 무한 구간과 \(x = 0\)에서의 \(0/0\) 꼴이라는, 수치 적분에서 흔한 두 걸림돌을 다루는 연습이기도 합니다.

4.3.1두 걸림돌

  • 무한 구간: 피적분 함수가 \(x\)가 커질수록 \(x^3e^{-x}\)로 빠르게 줄어든다. \(x = 50\)에서 \(50^3e^{-50} \approx 2.4\times10^{-17}\)이라 위끝을 50으로 끊어도 잃는 넓이는 기계 엡실론 수준이다.
  • \(x = 0\): \(x^3/(e^x - 1)\)은 0/0 꼴이지만 \(e^x - 1 \approx x\)이므로 \(x^2\)처럼 0으로 간다. 코드에서는 \(x = 0\)일 때 0을 돌려주고, 작은 \(x\)에서 상쇄 오차를 피하려 math.expm1을 쓴다.
import math

def simpson(f, a, b, n):
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return s * h / 3

g = lambda x: x**3 / math.expm1(x) if x > 0 else 0.0   # x^3/(e^x - 1), x→0에서 0
for n in (20, 100, 1000):
    print(n, simpson(g, 0.0, 50.0, n))
print("정확한 값 π^4/15 =", math.pi**4 / 15)

h, c, k = 6.62607015e-34, 2.99792458e8, 1.380649e-23
sigma = 2 * math.pi * k**4 / (h**3 * c**2) * simpson(g, 0.0, 50.0, 1000)
print("σ =", sigma)
20 6.951180115832831
100 6.494981068933492
1000 6.493939506433496
정확한 값 π^4/15 = 6.493939402266828
σ = 5.6703745101406246e-08

4.3.2결과 읽기

구간 20개(간격 2.5)로는 7% 틀리지만, 100개에서 \(1.6\times10^{-4}\), 1,000개에서 \(1.6\times10^{-8}\)의 상대 오차로 \(\pi^4/15 = 6.4939\)에 수렴합니다. 100개에서 1,000개로 10배 늘릴 때 오차가 약 \(10^4\)배 준 것은 Simpson 공식의 \(h^4\) 차수와 맞습니다. 마지막 줄은 이 적분값으로 계산한 \(\sigma = 2\pi k^4/(h^3c^2)\times\int\)로, 국제 표준값 \(5.670374\times10^{-8}\) W m\(^{-2}\) K\(^{-4}\)와 일치합니다(2019년부터 \(h, k, c\)는 정의값).

예제 4.3.1

같은 방법으로 Wien 꼬리, 곧 \(x > 10\)(봉우리보다 훨씬 짧은 파장)에서 나오는 에너지의 비율을 구하려면 코드를 어떻게 바꿉니까?

풀이. simpson(g, 10.0, 50.0, 1000) / (math.pi**4/15)를 계산합니다. 결과는 약 0.0103, 곧 1%입니다. 3,000 K 재결합 무렵 수소를 전리하는 광자가 이 꼬리에 있다는 것(천우4 6.3절)과 연결됩니다.

주의 위끝을 너무 작게(예: 10) 끊으면 꼬리를 잃어 답이 1% 작아집니다. 끊는 곳은 피적분 함수가 원하는 정밀도보다 충분히 작아지는 곳으로 고르고, 위끝을 바꿔도 답이 그대로인지 확인합니다.
요약
  1. 무한 구간은 피적분 함수가 충분히 작아지는 곳에서 끊는다(\(x = 50\)).
  2. 0/0 꼴은 극한값으로 처리하고, 작은 \(x\)에서 expm1로 상쇄 오차를 피한다.
  3. Simpson 1,000구간으로 \(\pi^4/15\)를 \(10^{-8}\) 정밀도로 얻는다.
  4. 이 값으로 \(\sigma = 5.6704\times10^{-8}\)이 나온다.

4.3.3연습문제

기본

  1. 피적분 함수의 봉우리는 어디입니까? (\(x^3/(e^x-1)\)을 미분)
    답

    \(3(1 - e^{-x}) = x\), \(x = 2.821\).

  2. 위끝 50을 30으로 바꾸면 잃는 넓이는 대략? (\(\int_{30}^\infty x^3e^{-x}dx \approx 30^3e^{-30}\))
    답

    \(2.7\times10^4\times9.4\times10^{-14} = 2.5\times10^{-9}\), 상대 \(4\times10^{-10}\).

응용

  1. V 필터(500~600 nm)에 들어오는 5,772 K 흑체 에너지의 비율을 구하는 계산을 설계하세요.
    답

    \(x = hc/(\lambda kT)\)로 바꾸면 500 nm → \(x = 4.99\), 600 nm → \(x = 4.16\). simpson(g, 4.16, 4.99, 100)/(π⁴/15)을 계산하면 약 0.12(12%).

  2. math.expm1(x) 대신 math.exp(x) - 1을 쓰면 \(x = 10^{-10}\)에서 상대 오차는 대략?
    답

    \(e^x\)가 1에 가까워 뺄셈에서 자릿수를 잃습니다. 상대 오차 \(\varepsilon/x \approx 2\times10^{-6}\).
