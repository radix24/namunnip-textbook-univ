흩어진 점들에서 법칙을 찾기

관측값은 늘 잡음이 섞여 있어 점들이 정확히 한 직선 위에 있지 않습니다. 그래도 거리와 후퇴 속도의 관계(허블 상수), 주기와 광도의 관계처럼 숨은 직선을 찾아야 합니다. "점들에서 가장 가까운 직선"을 정하는 표준적인 방법이 최소제곱법입니다. 1805년 르장드르와 가우스가 소행성 궤도 계산을 위해 만든 방법입니다.

6.1.1직선 맞춤

자료 \((x_i, y_i)\), \(i = 1, \dots, n\)에 직선 \(y = a + bx\)를 맞춥니다. 각 점의 잔차 \(r_i = y_i - (a + bx_i)\)의 제곱합 \(S(a, b) = \sum r_i^2\)이 가장 작은 \(a, b\)를 고릅니다.

유도. 극소에서 \(\partial S/\partial a = -2\sum r_i = 0\), \(\partial S/\partial b = -2\sum x_ir_i = 0\)입니다. 풀어 쓰면 \(na + b\sum x_i = \sum y_i\), \(a\sum x_i + b\sum x_i^2 = \sum x_iy_i\)인 연립방정식이고, 그 해는 \[ b = \frac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \qquad a = \frac{\sum y_i - b\sum x_i}{n} \] 입니다. ∎

제곱을 쓰는 까닭은 양과 음의 잔차가 상쇄되지 않게 하고, 미분해 식으로 풀 수 있게 하기 위해서입니다. 잡음이 정규분포를 따르면 최소제곱 해는 가장 그럴듯한(최대가능도) 해이기도 합니다(천우10 5.1절).

6.1.2예제: 허블 상수

# 가상 자료: 은하 거리(Mpc)와 후퇴 속도(km/s)
d = [10, 20, 35, 50, 70, 90, 120]
v = [820, 1310, 2650, 3420, 5100, 6150, 8500]
n = len(d)
sx, sy = sum(d), sum(v)
sxx = sum(x * x for x in d); sxy = sum(x * y for x, y in zip(d, v))
b = (n * sxy - sx * sy) / (n * sxx - sx * sx)     # 기울기
a = (sy - b * sx) / n                             # 절편
H0_origin = sxy / sxx                             # 원점을 지나는 직선의 기울기
res = [y - (a + b * x) for x, y in zip(d, v)]
s = (sum(r * r for r in res) / (n - 2)) ** 0.5
sb = s * (n / (n * sxx - sx * sx)) ** 0.5
print(f"직선 v = a + b d: a = {a:.0f} km/s, b = {b:.1f} ± {sb:.1f} km/s/Mpc")
print(f"원점을 지나는 직선: H0 = {H0_origin:.1f} km/s/Mpc")
직선 v = a + b d: a = 55 km/s, b = 69.8 ± 1.7 km/s/Mpc
원점을 지나는 직선: H0 = 70.5 km/s/Mpc

자료는 가상입니다. 기울기의 불확도는 잔차의 표준편차 \(s = \sqrt{\sum r_i^2/(n-2)}\)(직선의 두 매개변수를 빼서 \(n - 2\))로 \(\sigma_b = s\sqrt{n/[n\sum x^2 - (\sum x)^2]}\)를 계산한 것입니다. 허블-르메트르 법칙은 원점을 지나야 하므로 \(a = 0\)으로 두고 \(b = \sum xy/\sum x^2\)로 맞추기도 합니다. 물리적으로 정해진 조건이 있으면 맞춤에 넣는 것이 좋습니다. 아래 실습 카드에서 잡음과 점의 수를 바꾸며 기울기의 불확도가 어떻게 바뀌는지 볼 수 있습니다.

6.1.3곡선 맞춤

  • 로그 변환: \(y = Ax^k\)는 \(\log y = \log A + k\log x\)로 직선이 된다. 케플러 제3법칙, 질량-광도 관계 맞춤에 쓴다.
  • 다항식: \(y = a_0 + a_1x + a_2x^2\)도 매개변수에 대해 선형이라 같은 방법(정규 방정식)으로 푼다.
  • 비선형: 가우스 선 모양처럼 매개변수가 비선형으로 들어가면 반복 계산(scipy.optimize.curve_fit)으로 푼다.
주의 점마다 오차가 다르면 각 잔차를 그 점의 오차 \(\sigma_i\)로 나눈 \(\chi^2 = \sum(r_i/\sigma_i)^2\)을 최소화합니다(가중 최소제곱). 또 동떨어진 점 하나(이상값)가 결과를 크게 끌 수 있으므로 맞춘 뒤 잔차를 그려 확인합니다.
요약
  1. 잔차 제곱합 \(\sum(y_i - a - bx_i)^2\)을 최소화한다.
  2. \(b = [n\sum xy - \sum x\sum y]/[n\sum x^2 - (\sum x)^2]\), \(a = (\sum y - b\sum x)/n\).
  3. 기울기 불확도는 잔차 표준편차(자유도 \(n - 2\))에서 구한다.
  4. 로그 변환과 다항식으로 곡선에 확장하고, 잔차를 그려 확인한다.

6.1.4연습문제

기본

  1. 점 (0, 1), (1, 3), (2, 5)에 맞춘 직선은?
    답

    \(b = (3\times13 - 3\times9)/(3\times5 - 9) = 2\), \(a = (9 - 6)/3 = 1\): \(y = 1 + 2x\)(정확히 지남).

  2. 원점을 지나는 직선 맞춤에서 \(b = \sum xy/\sum x^2\)임을 보이세요.
    답

    \(S = \sum(y - bx)^2\), \(dS/db = -2\sum x(y - bx) = 0\).

응용

  1. 케플러 제3법칙 \(P = Ka^k\)를 맞추려면 무엇을 맞춰야 합니까?
    답

    \(\log P = \log K + k\log a\)이므로 \((\log a, \log P)\)에 직선을 맞춥니다. 1.2절 자료로 하면 \(k \approx 1.500\).

  2. 점 수를 4배로 늘리면 기울기 불확도는 대략 몇 배가 됩니까? (같은 범위, 같은 잡음)
    답

    약 1/2배(\(1/\sqrt n\)).

6.1.2

실습가상 허블 자료에 직선 맞추기

실습 · 최소제곱법

다루는 성취기준 [천우6-06-01]

목표

거리와 후퇴 속도의 가상 자료에 최소제곱 직선을 맞추고, 잡음과 자료 수가 기울기(허블 상수)의 불확도에 주는 영향을 확인합니다. 성취기준 [천우6-06-01].

준비

가상 자료입니다. 거리 5~150 Mpc에 은하를 무작위로 놓고 참 허블 상수로 속도를 만든 뒤 정규분포 잡음을 더했습니다. '새 가상 자료'는 같은 조건에서 다른 난수로 자료를 다시 만듭니다.

절차

  1. 처음 값(H₀ = 70, σ = 500, 20개)에서 기울기와 불확도를 기록합니다.
  2. 자료 수를 80으로 늘려 불확도가 어떻게 바뀌는지 봅니다.
  3. 자료 수를 20으로 되돌리고 잡음을 2000으로 키웁니다.
  4. '새 가상 자료'를 다섯 번 눌러 기울기가 흩어지는 폭을 출력의 불확도와 비교합니다.

기대 결과

  • 처음 값: 기울기 70.4 ± 3.0 km/s/Mpc, 원점을 지나는 직선 70.8.
  • 80개: 69.6 ± 1.5로 불확도가 약 절반(\(1/\sqrt4\))이 됩니다.
  • 잡음 2000: 71.6 ± 12.1로 불확도가 약 4배 커집니다(잡음에 비례).
  • 새 자료를 만들 때 기울기는 대개 불확도(±3) 정도 범위에서 흩어집니다.

분석

  1. 불확도가 \(\sigma/\sqrt N\)에 비례한다는 것을 위 결과로 확인하세요.
  2. 절편이 0이 아니게 나오는 까닭은 무엇입니까? 원점을 지나는 직선으로 맞추는 것이 물리적으로 정당한 이유는?
  3. 가까운 은하만 쓰면(거리 범위가 좁으면) 기울기 불확도는 커질까요, 작아질까요?
