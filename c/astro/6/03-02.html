표에 없는 값이 필요할 때

별 대기 모형의 불투명도, 진화 모형의 등연령곡선, 필터 투과율처럼 천문학의 많은 자료는 띄엄띄엄한 표로 주어집니다. 표에 없는 온도나 파장의 값이 필요하면 이웃한 값들로 사이를 메워야 합니다. 이것을 보간이라 합니다.

3.2.1선형 보간

가장 간단한 방법은 이웃한 두 점을 직선으로 잇는 것입니다. \(x_i \le x \le x_{i+1}\)이면 \(t = (x - x_i)/(x_{i+1} - x_i)\)로 두고 \(y = y_i + t(y_{i+1} - y_i)\)입니다. 빠르고 안전하지만 곡선이 휘는 곳에서는 오차가 \(h^2|f''|/8\) 정도 생기고(\(h\)는 표 간격), 꺾인 곳에서 기울기가 끊깁니다.

3.2.2라그랑주 다항식 보간

점 \(n\)개를 모두 지나는 \(n-1\)차 다항식은 하나뿐이고, 다음과 같이 쓸 수 있습니다.

\[ p(x) = \sum_{i} y_i\,L_i(x), \qquad L_i(x) = \prod_{j\ne i}\frac{x - x_j}{x_i - x_j} \]

\(L_i\)는 \(x_i\)에서 1, 다른 점에서 0인 다항식이라 \(p(x_i) = y_i\)가 됩니다. 아래는 온도와 색지수의 가상 표에 두 방법을 쓴 예입니다.

# 표 자료 사이의 값: 선형 보간과 라그랑주 다항식 보간
xs = [4000, 5000, 6000, 7000, 8000]          # 온도 (K)
ys = [1.38, 0.89, 0.58, 0.39, 0.25]          # B-V (흑체 어림, 가상 표)

def linear(x, xs, ys):
    for i in range(len(xs) - 1):
        if xs[i] <= x <= xs[i + 1]:
            t = (x - xs[i]) / (xs[i + 1] - xs[i])
            return ys[i] + t * (ys[i + 1] - ys[i])

def lagrange(x, xs, ys):
    s = 0.0
    for i in range(len(xs)):
        L = 1.0
        for j in range(len(xs)):
            if j != i:
                L *= (x - xs[j]) / (xs[i] - xs[j])
        s += ys[i] * L
    return s

for T in (4500, 5772, 7500):
    print(T, round(linear(T, xs, ys), 3), round(lagrange(T, xs, ys), 3))
4500 1.135 1.109
5772 0.651 0.638
7500 0.32 0.319

곡선이 휘는 곳(4,500 K)에서 두 방법의 차이가 0.026으로 가장 큽니다. 매끄러운 함수라면 다항식 보간이 대개 더 정확합니다.

3.2.3Runge 현상과 스플라인

점을 많이 쓸수록 좋을 것 같지만, 고르게 놓인 점에 고차 다항식을 맞추면 양 끝에서 크게 진동하는 일이 생깁니다. \(f(x) = 1/(1 + 25x^2)\)을 \([-1, 1]\)의 고른 점 11개로 보간하면 끝 근처에서 참값보다 2배 가까이 튑니다(Runge 현상). 아래 실습 카드에서 점의 수를 늘리며 확인할 수 있습니다.

해결책은 3차 스플라인입니다. 이웃한 두 점 사이마다 3차 다항식을 따로 쓰되, 점에서 값, 기울기, 곡률(2차 도함수)이 이어지도록 맞춥니다. 각 조각은 낮은 차수라 진동하지 않고, 이어진 곡선은 매끄럽습니다. 조건을 세우면 각 점의 2차 도함수에 대한 삼중대각 연립방정식이 되어 빠르게 풀립니다(천우10 2.1절). Python에서는 scipy.interpolate.CubicSpline을 씁니다.

주의 보간은 표의 범위 안에서만 씁니다. 범위 밖으로 늘이는 외삽은 다항식이 급격히 벗어나므로 매우 위험합니다. 표 간격보다 자세한 구조(좁은 흡수선 등)는 어떤 보간으로도 되살릴 수 없습니다.
요약
  1. 선형 보간: 이웃 두 점을 직선으로. 안전하지만 휘는 곳에서 오차.
  2. 라그랑주 다항식: 모든 점을 지나는 하나의 다항식. 매끄러운 함수에 정확.
  3. 고차 다항식은 끝에서 진동한다(Runge 현상).
  4. 3차 스플라인: 구간마다 3차, 값·기울기·곡률을 이어 매끄럽고 안정하다.

3.2.4연습문제

기본

  1. (4000, 1.38)과 (5000, 0.89) 사이에서 4,200 K의 선형 보간 값은?
    답

    \(1.38 + 0.2\times(0.89 - 1.38) = 1.282\).

  2. 점 4개를 지나는 다항식의 차수는?
    답

    3차.

응용

  1. \(L_0(x)\)를 점 \(x_0 = 0, x_1 = 1, x_2 = 2\)에 대해 쓰고 \(x = 0.5\)에서의 값을 구하세요.
    답

    \(L_0 = (x-1)(x-2)/((0-1)(0-2)) = (x-1)(x-2)/2\), \(L_0(0.5) = 0.375\).

  2. 선형 보간의 최대 오차 \(h^2|f''|/8\)로, \(\sin x\)를 간격 0.1로 표로 만들 때 오차를 어림하세요.
    답

    \(0.01\times1/8 = 1.25\times10^{-3}\).

3.2.2

실습점을 늘리면 보간이 좋아질까: Runge 현상

실습 · 보간과 스플라인

다루는 성취기준 [천우6-03-02]

목표

고르게 놓인 점에 다항식 보간과 자연 3차 스플라인을 맞추고, 점의 수를 늘릴 때 최대 오차가 어떻게 바뀌는지 비교합니다. 성취기준 [천우6-03-02].

준비

검은 점이 표의 값, 회색 점선이 참 함수, 빨간 선이 모든 점을 지나는 다항식, 파란 선이 3차 스플라인입니다. 자연 스플라인은 양 끝에서 2차 도함수를 0으로 둡니다.

절차

  1. 1/(1 + 25x²)에서 점의 수를 5, 11, 15로 바꾸며 두 방법의 최대 오차를 기록합니다.
  2. sin πx로 바꾸어 같은 일을 합니다.
  3. |x|(가운데가 꺾인 함수)에서는 어떻습니까?

기대 결과

  • 1/(1 + 25x²): 다항식 보간의 최대 오차는 점 5개 0.44, 11개 1.9, 15개 7.2로 점이 늘수록 끝에서 진동이 커집니다. 스플라인은 0.28, 0.022, 0.0025로 꾸준히 줄어듭니다.
  • sin πx처럼 부드럽고 완만한 함수에서는 다항식 보간도 점이 늘수록 빠르게 정확해집니다.
  • |x|는 꺾인 점 때문에 두 방법 모두 그 근처에서 오차가 남습니다.

분석

  1. Runge 함수에서 오차가 가장 큰 곳은 어디입니까? 왜 가운데가 아니라 끝일까요?
  2. 스플라인이 진동하지 않는 까닭을 '구간마다 낮은 차수'라는 말로 설명하세요.
  3. 점을 양 끝에 촘촘히 놓으면(체비쇼프 점) 다항식 보간이 좋아진다고 알려져 있습니다. 왜 그럴지 생각해 보세요.
