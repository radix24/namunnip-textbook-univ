무작위로 정답에 다가가기

다트를 정사각형 과녁에 아무렇게나 던지고, 안에 그린 원에 꽂힌 비율을 세면 원의 넓이를 알 수 있습니다. 이렇게 난수로 표본을 뽑아 평균을 내 답을 어림하는 방법을, 도박의 도시 이름을 따 Monte Carlo 방법이라 합니다. 1940년대 핵무기 개발에서 중성자의 이동을 계산하려고 쓰기 시작했고, 지금은 광자의 복사 전달, 은하 형성 모의실험, 측정 불확도 계산까지 천문학 곳곳에서 씁니다.

6.2.1의사 난수

컴퓨터의 난수는 정해진 규칙으로 만든 수열이라 의사 난수라 부릅니다. 같은 시드(첫 값)로 시작하면 늘 같은 수열이 나오므로 결과를 재현할 수 있습니다. Python의 random.random()은 0과 1 사이의 고른 난수를 주고, random.seed(1)로 시드를 정합니다. 논문에 쓰는 계산은 시드를 기록해 다른 사람이 같은 결과를 얻을 수 있게 합니다.

6.2.2\(\pi\) 어림

정사각형 \([0,1]^2\)에 고른 점을 찍으면 사분원 \(x^2 + y^2 < 1\) 안에 들어갈 확률은 넓이 비 \(\pi/4\)입니다. \(N\)개 중 \(N_{in}\)개가 들어가면 \(\pi \approx 4N_{in}/N\)입니다.

import random, math
random.seed(1)
for N in (100, 10000, 1000000):
    inside = sum(1 for _ in range(N) if random.random()**2 + random.random()**2 < 1)
    est = 4 * inside / N
    print(f"N={N:8d}  π 추정 {est:.4f}  오차 {abs(est - math.pi):.4f}  예상 오차 약 {1.64 / math.sqrt(N):.4f}")
N=     100  π 추정 3.2000  오차 0.0584  예상 오차 약 0.1640
N=   10000  π 추정 3.1396  오차 0.0020  예상 오차 약 0.0164
N= 1000000  π 추정 3.1412  오차 0.0004  예상 오차 약 0.0016

"예상 오차"는 이항 분포의 표준편차 \(4\sqrt{p(1-p)/N}\)(\(p = \pi/4\))로, \(1.64/\sqrt N\)입니다. 실제 오차는 이 값 안팎에서 흩어지며, \(N\)을 100배 늘리면 오차는 10배만 줄어듭니다. 이 \(1/\sqrt N\) 수렴은 Simpson 공식(\(h^4\))보다 훨씬 느려, 1차원 적분에는 Monte Carlo가 불리합니다. 아래 실습 카드에서 \(N\)을 바꾸며 확인할 수 있습니다.

6.2.3Monte Carlo가 유리한 곳

  • 고차원 적분: 격자 방법은 차원마다 점이 곱으로 늘지만(10차원에 축마다 10점이면 \(10^{10}\)점), Monte Carlo의 오차는 차원과 상관없이 \(1/\sqrt N\)이다.
  • 복잡한 모양: 영역 안인지 판단만 할 수 있으면 넓이와 부피를 잴 수 있다.
  • 불확도 전파: 측정값을 오차 분포에 따라 무작위로 여러 번 뽑아 계산을 되풀이하면, 복잡한 식의 결과 분포를 그대로 얻는다. 예를 들어 시차와 등급의 오차로 광도의 불확도를 구한다.
  • 확률 과정의 모의실험: 광자가 별 내부나 먼지 구름에서 무작위로 산란되는 과정(천우4 1.2절)을 그대로 흉내 낸다.
주의 난수의 질이 나쁘면 결과가 체계적으로 틀립니다. 직접 만든 간단한 난수 발생기 대신 검증된 라이브러리(random, numpy.random)를 씁니다. 또 결과에는 반드시 통계 오차 \(\sigma/\sqrt N\)를 함께 적습니다.
요약
  1. 의사 난수는 시드로 재현할 수 있다.
  2. \(\pi \approx 4N_{in}/N\), 오차 \(\approx 1.64/\sqrt N\).
  3. Monte Carlo 오차는 \(1/\sqrt N\): 1차원에는 느리지만 차원과 무관하다.
  4. 고차원 적분, 복잡한 영역, 불확도 전파, 확률 과정에 쓴다.

6.2.4연습문제

기본

  1. 오차를 0.001로 하려면 \(N\)은 대략?
    답

    \((1.64/0.001)^2 = 2.7\times10^6\).

  2. 시드를 정하지 않고 두 번 실행하면 결과가 다른 까닭은?
    답

    시드가 시각 등에서 매번 달리 정해져 다른 난수 수열이 쓰이기 때문입니다.

응용

  1. 시차 \(p = 10.0 \pm 0.5\) mas, 겉보기 등급 \(V = 12.0 \pm 0.05\)인 별의 절대 등급 불확도를 Monte Carlo로 구하는 절차를 쓰세요.
    답

    정규분포에서 \(p\)와 \(V\)를 \(10^4\)번 뽑아 매번 \(M = V + 5\log_{10}(p/100)\)(p는 mas)을 계산하고, 결과의 평균과 표준편차를 구합니다(약 \(M = 7.0 \pm 0.12\)).

  2. 단위 공 \(x^2+y^2+z^2 < 1\)의 부피를 Monte Carlo로 구하는 방법은?
    답

    \([-1,1]^3\)에 점을 찍어 안에 든 비율에 8을 곱합니다. 참값 \(4\pi/3 = 4.19\).

6.2.2

실습Monte Carlo로 π 어림하기

실습 · 난수와 통계 오차

다루는 성취기준 [천우6-06-02]

목표

정사각형에 무작위 점을 찍어 사분원 안에 든 비율로 π를 어림하고, 오차가 \(1/\sqrt N\)로 줄어드는 것을 확인합니다. 성취기준 [천우6-06-02].

준비

점은 시드로 재현되는 의사 난수로 만듭니다. 왼쪽은 처음 3,000개 점(파랑: 안, 빨강: 밖), 오른쪽은 N이 커질 때의 실제 오차와 예상 오차 1.64/√N입니다.

절차

  1. N = 10⁴(처음 값)에서 π 어림과 오차, 예상 오차를 기록합니다.
  2. N을 10², 10³, 10⁵, 10⁶으로 바꾸며 같은 기록을 합니다.
  3. '새 시드'를 눌러 같은 N에서 결과가 얼마나 흩어지는지 봅니다.

기대 결과

  • 처음 시드에서 N = 10²: 3.28, 10³: 3.14, 10⁴: 3.1432, 10⁵: 3.1374, 10⁶: 3.1408.
  • 실제 오차는 예상 오차(10⁴에서 0.016) 안팎에서 들쭉날쭉하며, 전체적으로 N이 100배 늘 때 약 10배 줄어듭니다.
  • 시드를 바꾸면 결과가 예상 오차 정도로 흩어집니다.

분석

  1. 오른쪽 그림의 점들이 점선(기울기 −1/2)을 따라 내려가는지 확인하세요.
  2. N = 10⁴에서 오차 0.001을 얻는 일이 드문 까닭을 예상 오차로 설명하세요.
  3. 같은 정밀도를 Simpson 공식(1차원 적분)으로 얻으려면 몇 개의 점이 필요할지 6.2절과 비교하세요.
