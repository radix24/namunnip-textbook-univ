왜 프로그램을 짜는가

별 세 개의 거리는 계산기로 구할 수 있지만, 관측 목록의 별 10만 개는 그럴 수 없습니다. 천문학은 자료가 많고 계산이 반복되는 학문이라 프로그래밍이 기본 도구입니다. 경희대 우주과학과는 기초프로그래밍및실습에서, 연세대는 이 과목에서 Python을 씁니다. 이 절에서는 Python의 가장 기본적인 네 가지, 곧 변수, 리스트, 반복문, 함수를 천문 계산 하나로 익힙니다.

1.1.1준비

python.org에서 Python 3을 내려받아 설치하거나, 설치 없이 웹 브라우저에서 쓰는 Google Colab, Jupyter를 씁니다. 아래 코드는 표준 라이브러리만 쓰므로 어디서나 그대로 실행됩니다. 코드를 파일(예: dist.py)로 저장하고 명령창에서 python dist.py로 실행합니다.

1.1.2예제 프로그램

거리 지수 \(m - M = 5\log_{10}(d/10\text{ pc}) + A\)를 \(d\)에 대해 풀면 \(d = 10^{(m - M - A + 5)/5}\) pc입니다. 별 세 개에 적용하는 프로그램입니다.

import math

def distance_pc(m, M, A=0.0):
    """겉보기 등급 m, 절대 등급 M, 소광 A로 거리(pc)를 구한다."""
    return 10 ** ((m - M - A + 5) / 5)

stars = [("시리우스", -1.46, 1.43), ("베가", 0.03, 0.58), ("리겔", 0.13, -7.84)]
for name, m, M in stars:
    d = distance_pc(m, M)
    print(f"{name:5s} m={m:6.2f} M={M:6.2f}  d = {d:8.1f} pc")

total = 0.0
for name, m, M in stars:
    total += distance_pc(m, M)
print("평균 거리:", round(total / len(stars), 1), "pc")

실행 결과:

시리우스  m= -1.46 M=  1.43  d =      2.6 pc
베가    m=  0.03 M=  0.58  d =      7.8 pc
리겔    m=  0.13 M= -7.84  d =    392.6 pc
평균 거리: 134.3 pc

1.1.3한 줄씩 읽기

  • import math: 수학 함수 모음을 불러온다. 이 예제에서는 쓰지 않았지만 log, sin 등을 쓸 때 필요하다.
  • def distance_pc(m, M, A=0.0): 함수를 정의한다. 들여쓴 줄이 함수의 몸체이고, return이 결과를 돌려준다. A=0.0은 값을 주지 않으면 0을 쓰는 기본값이다.
  • 10 ** x: 거듭제곱. ^는 거듭제곱이 아니니 주의한다.
  • stars = [ … ]: 리스트. 여기서는 (이름, m, M) 묶음(튜플) 세 개를 담았다.
  • for name, m, M in stars: 리스트의 원소를 하나씩 꺼내 세 변수에 나눠 담고 들여쓴 줄을 되풀이한다.
  • f"…{d:8.1f}…": f-문자열. 중괄호 안의 값을 지정한 형식(전체 8칸, 소수 한 자리)으로 끼워 넣는다.

함수로 묶으면 같은 계산을 여러 곳에서 다시 쓰고, 고칠 때 한 곳만 고치면 됩니다. 소광을 넣으려면 distance_pc(m, M, A=0.5)처럼 부르기만 하면 됩니다.

흔한 실수 Python은 들여쓰기로 블록을 구분합니다. for 아래 줄의 들여쓰기가 하나라도 어긋나면 반복에서 빠지거나 오류가 납니다. 또 정수끼리의 나눗셈 7 / 2는 3.5이지만 7 // 2는 3입니다.
요약
  1. 변수에 값을 넣고, 리스트로 여러 값을 묶는다.
  2. for 반복문으로 리스트의 원소마다 같은 계산을 한다.
  3. def로 함수를 만들어 계산을 재사용한다.
  4. f-문자열로 결과를 보기 좋게 출력한다.

1.1.4연습문제

기본

  1. 위 프로그램에 데네브(m = 1.25, M = −8.38)를 추가하면 거리는?
    답

    \(10^{(1.25 + 8.38 + 5)/5} = 10^{2.926} = 843\) pc.

  2. 함수를 바꿔 거리(pc)를 받아 광년으로 돌려주는 pc_to_ly(d)를 쓰세요(1 pc = 3.2616 ly).
    답

    def pc_to_ly(d): return d * 3.2616

응용

  1. 리스트의 별 가운데 거리가 10 pc보다 가까운 별의 이름만 출력하도록 고치세요.
    답

    반복문 안에 if distance_pc(m, M) < 10: print(name)를 넣습니다. 시리우스와 베가가 나옵니다.

  2. 평균 거리를 구하는 부분을 sum과 리스트 내포로 한 줄로 쓰세요.
    답

    sum(distance_pc(m, M) for _, m, M in stars) / len(stars)
