이 절에서 배울 것
  • CSV 형식의 표 자료를 읽어 숫자로 바꾼다.
  • 읽은 자료로 물리 관계(케플러 제3법칙)를 확인한다.
  • matplotlib으로 산점도와 로그 축 그래프를 그린다.
먼저 알아야 할 것
  • Python 기초 (1.1절), 케플러 제3법칙 (천우1 1.3절).

관측 자료는 표로 온다

천문 자료 보관소에서 내려받는 자료는 대개 쉼표로 열을 나눈 CSV, 고정 폭 텍스트, 또는 FITS 표 형식입니다. 첫 단계는 그 표를 프로그램으로 읽어 숫자 목록으로 바꾸는 것입니다. 여기서는 표준 라이브러리의 csv 모듈로 행성 자료를 읽고 케플러 제3법칙을 확인합니다.

1.2.1CSV 읽기

실제로는 파일을 열어 읽지만, 예제를 그대로 실행할 수 있도록 표를 문자열로 넣고 io.StringIO로 파일처럼 다룹니다. 파일이라면 open("planets.csv", encoding="utf-8")을 씁니다.

import csv, io

data = """name,a_AU,P_yr
수성,0.387,0.241
금성,0.723,0.615
지구,1.000,1.000
화성,1.524,1.881
목성,5.203,11.862
토성,9.537,29.457
"""
rows = list(csv.DictReader(io.StringIO(data)))
for r in rows:
    a, P = float(r["a_AU"]), float(r["P_yr"])
    print(f'{r["name"]}: a^3/P^2 = {a**3 / P**2:.4f}')

실행 결과:

수성: a^3/P^2 = 0.9979
금성: a^3/P^2 = 0.9992
지구: a^3/P^2 = 1.0000
화성: a^3/P^2 = 1.0004
목성: a^3/P^2 = 1.0010
토성: a^3/P^2 = 0.9997

csv.DictReader는 첫 줄을 열 이름으로 쓰고 각 행을 사전(r["a_AU"]처럼 이름으로 꺼냄)으로 줍니다. 읽은 값은 문자열이므로 float()로 숫자로 바꿔야 합니다. 결과의 \(a^3/P^2\)이 모두 1에 가까워 AU·년 단위의 케플러 제3법칙이 확인됩니다. 1에서 벗어난 0.1% 정도는 표의 반올림과 행성 질량(\(M_\odot + m\))의 효과입니다.

1.2.2그래프 그리기

그림은 matplotlib을 씁니다(설치: pip install matplotlib). 거듭제곱 관계는 로그 축에서 직선이 되어 확인하기 좋습니다.

import matplotlib.pyplot as plt
a = [float(r["a_AU"]) for r in rows]
P = [float(r["P_yr"]) for r in rows]
plt.loglog(a, P, "o", label="행성")
plt.loglog([0.3, 12], [0.3**1.5, 12**1.5], "--", label="P = a^1.5")
plt.xlabel("긴반지름 a (AU)"); plt.ylabel("주기 P (년)")
plt.legend(); plt.savefig("kepler.png", dpi=150)

로그-로그 그래프에서 점들이 기울기 1.5인 직선 위에 놓입니다. 기울기가 거듭제곱의 지수입니다. 그래프에는 늘 축 이름과 단위를 적습니다.

흔한 실수 표의 빈칸이나 "N/A" 같은 문자가 있으면 float()에서 오류가 납니다. 읽기 전에 자료를 눈으로 확인하고, 빈칸을 건너뛰는 처리를 넣습니다. 또 한글이 든 파일은 인코딩(utf-8)을 꼭 지정합니다.
요약
  1. csv.DictReader로 열 이름이 있는 표를 읽는다. 값은 float()로 바꾼다.
  2. 읽은 자료로 물리 관계를 계산해 확인한다(\(a^3/P^2 \approx 1\)).
  3. 거듭제곱 관계는 로그-로그 그래프에서 직선이 되고 기울기가 지수이다.
  4. 그래프에는 축 이름과 단위를 적는다.

1.2.3연습문제

기본

  1. 표에 천왕성(a = 19.19 AU, P = 84.01년)을 추가하면 \(a^3/P^2\)은?
    답

    \(19.19^3/84.01^2 = 7067/7058 = 1.0013\).

  2. plt.loglog 대신 plt.plot을 쓰면 그래프는 어떻게 보입니까?
    답

    점들이 위로 휘는 곡선(\(P \propto a^{1.5}\))으로 보여 지수를 읽기 어렵습니다.

응용

  1. 두 점의 로그로 기울기 \(\log(P_2/P_1)/\log(a_2/a_1)\)를 수성과 토성으로 계산하세요.
    답

    \(\log(29.457/0.241)/\log(9.537/0.387) = 2.087/1.392 = 1.499\).

  2. 열 구분이 공백인 표를 읽으려면 어떻게 고칩니까?
    답

    csv.reader(f, delimiter=" ", skipinitialspace=True)를 쓰거나, 줄마다 line.split()으로 나눕니다.
