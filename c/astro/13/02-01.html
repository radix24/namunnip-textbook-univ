이 절에서 배울 것
  • 픽셀 값 히스토그램으로 배경과 천체의 분포를 읽는다.
  • 자름 값(백분위)과 변환 함수(선형, 제곱근, 로그, asinh)로 영상을 표시한다.
  • 표시와 측정을 구별한다.
먼저 알아야 할 것
  • FITS 자료 (1.2절), 백분위수.

10만 단계를 256단계로

천문 영상의 픽셀 값은 배경 100 근처부터 밝은 별 수만까지 몇 자릿수에 걸칩니다. 화면은 256단계(8비트)밖에 보여 주지 못하므로, 어떤 범위를 어떤 모양으로 화면 밝기에 대응시킬지 정해야 합니다. 같은 자료도 표시 방법에 따라 전혀 다른 그림이 됩니다.

2.1.1히스토그램

픽셀 값별 개수를 그린 것이 히스토그램입니다. 천문 영상에서는 대부분의 픽셀이 하늘 배경이라 배경값 근처에 좁고 높은 봉우리(폭은 잡음)가 있고, 천체 픽셀은 오른쪽으로 길게 꼬리를 끕니다. 배경 봉우리의 중앙값과 폭은 하늘 밝기와 잡음의 좋은 추정값입니다.

2.1.2자름과 변환

  • 자름: 아래 값 \(z_1\) 이하는 검게, 위 값 \(z_2\) 이상은 하얗게. 백분위로 정하면(예: 1%와 99.5%) 영상마다 자동으로 알맞은 범위가 잡힌다. ZScale(DS9 기본)은 배경 근처를 강조하도록 정한다.
  • 선형 \(y = t\): 밝기 비가 그대로. 배경 근처의 희미한 구조는 거의 안 보인다.
  • 제곱근 \(y = \sqrt t\), 로그 \(y = \log(1 + at)/\log(1 + a)\): 어두운 부분을 늘인다.
  • asinh \(y = \sinh^{-1}(at)/\sinh^{-1}a\): 어두운 쪽은 선형, 밝은 쪽은 로그처럼. 잡음을 지나치게 키우지 않으면서 밝은 중심도 포화시키지 않아 SDSS 컬러 영상에 쓰였다(Lupton 외 2004).

여기서 \(t = (x - z_1)/(z_2 - z_1)\)을 0~1로 자른 값입니다.

예제 2.1.1 (아래 실습 카드 결과)

가상 영상(은하 하나 + 별 25개, 배경 약 100, 잡음 5, 최대 27,241)에서 자름 백분위를 바꾸면?

  • 1%~99.5%: 자름 89.8~9,205.1, 하얗게 꽉 찬 픽셀 0.52%.
  • 1%~99%: 위 자름 5,051.5, 꽉 찬 픽셀 1.02%.
  • 1%~95%: 위 자름 612.0, 꽉 찬 픽셀 5.01%(은하 원반이 잘 보이지만 중심이 다 하얗다).
  • 0%~100%: 81.6~27,240.8. 선형이면 별 몇 개만 보이고 나머지는 검다.
주의 표시 변환은 보기 위한 것일 뿐 자료를 바꾸지 않습니다. 측광, 위치 측정은 언제나 원래 값으로 하며, 논문 그림에는 어떤 자름과 변환을 썼는지 밝힙니다. 히스토그램 평활화처럼 픽셀 값의 순서만 남기는 변환은 밝기 비를 완전히 바꾸므로 특히 조심합니다.
요약
  1. 히스토그램: 배경 봉우리(중앙값 = 하늘, 폭 = 잡음) + 천체의 꼬리.
  2. 자름 \(z_1, z_2\)(백분위, ZScale)과 변환(선형, 제곱근, 로그, asinh)으로 표시.
  3. asinh는 어두운 쪽 선형, 밝은 쪽 로그: 넓은 범위를 함께 보여 준다.
  4. 표시는 측정이 아니다. 그림에 표시 방법을 밝힌다.

2.1.3연습문제

기본

  1. 히스토그램에서 배경 봉우리의 폭은 무엇을 나타냅니까?
    답

    배경 잡음.

  2. 선형 표시에서 희미한 은하 바깥 구조를 보려면 무엇을 바꿉니까?
    답

    위 자름을 낮추거나(예: 95%) 로그·asinh 변환을 씁니다.

응용

  1. \(z_1 = 100\), \(z_2 = 1100\), 픽셀 값 350의 선형·제곱근 표시 밝기(0~1)는?
    답

    \(t = 0.25\). 선형 0.25, 제곱근 0.5.

  2. 같은 픽셀의 asinh(\(a = 10\)) 표시 밝기는?
    답

    \(\sinh^{-1}(2.5)/\sinh^{-1}(10) = 1.647/2.998 = 0.55\).

2.1.2

실습자름 값과 명암 변환으로 가상 은하 영상 표시하기

실습 · 영상 표시

다루는 성취기준 [천우13-02-01]

목표

같은 가상 영상을 여러 자름 값과 변환 함수로 표시해, 히스토그램에서 자름 위치가 어디에 놓이는지와 화면에서 보이는 구조가 어떻게 달라지는지 비교합니다. 성취기준 [천우13-02-01].

준비

가상 영상 96×96: 배경 약 100, 잡음 5, 기울어진 지수 원반 은하(중심 3,000), 무작위 별 25개(최고값 100~30,000). 오른쪽 그림은 픽셀 값의 로그 히스토그램(파랑), 자름 위치(빨강), 변환 곡선(주황)입니다.

절차

  1. 선형, 1%~99.5%에서 무엇이 보이는지 확인합니다.
  2. 위 자름을 99, 95로 낮춰 봅니다.
  3. 1%~99.5%로 되돌리고 변환을 제곱근, 로그, asinh로 바꿔 봅니다.
  4. 아래 자름을 10%로 올리면 배경이 어떻게 되는지 봅니다.

기대 결과

  • 1%~99.5%: 자름 89.8~9,205.1, 꽉 찬 픽셀 0.52%. 1%~99%: 위 5,051.5, 1.02%. 1%~95%: 위 612.0, 5.01%.
  • 배경 중앙값 104.9, 가장 밝은 픽셀 27,241.
  • 선형에서는 밝은 별 몇 개와 은하 중심만 보이고, 로그·asinh에서는 은하 원반과 희미한 별, 배경 잡음까지 보인다.

분석

  1. 히스토그램의 봉우리 위치와 배경 중앙값(104.9)의 관계는?
  2. 로그 변환에서 배경 잡음이 거칠게 보이는 까닭을 변환 곡선의 기울기로 설명하세요.
  3. 논문 그림에 asinh 표시를 썼다면 무엇을 함께 밝혀야 합니까?
