이 절에서 배울 것
  • 위성 영상의 기하 왜곡 원인과 보정 절차(센서 모형, 지상 기준점, 정사 보정)를 안다.
  • DN을 복사휘도와 대기 위 반사율로 바꾸는 방사 보정을 계산한다.
  • 대기 보정의 필요성을 안다.
먼저 알아야 할 것
  • 영상 정합과 보간 (4.2절), 위성 궤도와 지상 궤적 (천우8 6.1절).

지구를 찍은 영상도 천문 영상처럼

지구 관측 위성의 영상 처리는 천문 영상 처리와 뼈대가 같습니다. 검출기 값을 물리량으로 바꾸고(방사 보정), 픽셀을 지도 좌표에 맞춥니다(기하 보정, 천문의 WCS와 같은 일). 연세대 과학영상처리론및실습의 '위성 수신 자료' 부분입니다.

5.1.1기하 보정

왜곡의 원인:

  • 위성의 궤도·자세 오차, 지구 자전(밀어 쓸기 센서는 줄마다 시각이 달라 영상이 기울어짐).
  • 지구의 곡률과 지형 기복(높은 산은 옆으로 밀려 보임).
  • 센서 광학 왜곡, 비스듬히 본 각(사각 촬영).
  1. 궤도·자세·센서 정보로 픽셀마다 시선 벡터를 계산하는 센서 모형(또는 RPC 계수)을 세운다.
  2. 지도나 정밀 영상에서 위치를 아는 지상 기준점(GCP)을 영상에서 찾아 모형의 오차를 고친다(천문의 성표 별 짝짓기와 같음).
  3. 수치 고도 모형(DEM)으로 지형 기복을 보정하는 정사 보정을 한다.
  4. 지도 격자로 다시 표본화한다: 최근린(값 보존, 분류용), 쌍선형, 3차 회선(보기 좋음).
예제 5.1.1

높이 1,000 m인 산꼭대기를 연직에서 20° 기울어진 방향으로 찍었습니다. 정사 보정을 하지 않으면 수평 위치가 얼마나 어긋납니까?

풀이. \(1000\times\tan20° = 364\) m입니다. 해상도 1 m 위성 영상에서 364픽셀이므로 산악 지역에서는 정사 보정이 꼭 필요합니다.

5.1.2방사 보정

검출기의 디지털 값(DN)을 센서에 들어온 복사휘도 \(L_\lambda\)(W m⁻² sr⁻¹ μm⁻¹)로 바꿉니다: \(L_\lambda = G\cdot DN + B\)(G, B는 메타자료의 보정 계수, 천문의 플랫·바이어스 처리 + 측광 영점에 해당). 이어서 태양 빛의 세기와 각도를 나눠 대기 위(TOA) 반사율로 바꿉니다.

\[ \rho_{TOA} = \frac{\pi L_\lambda d^2}{E_{sun,\lambda}\cos\theta_s} \]

\(d\)는 태양-지구 거리(AU), \(E_{sun}\)은 대기 위 태양 분광 조도, \(\theta_s\)는 태양 천정각입니다.

예제 5.1.2

적색 띠에서 \(L = 80\) W m⁻² sr⁻¹ μm⁻¹, \(E_{sun} = 1{,}550\) W m⁻² μm⁻¹, \(d = 1\), 태양 천정각 40°이면 반사율은?

풀이. \(\pi\times80/(1550\times0.766) = 251.3/1187 = 0.212\)입니다.

5.1.3대기 보정

대기 위 반사율에는 대기의 산란 빛(특히 파란 띠)과 흡수가 섞여 있습니다. 같은 땅도 날마다 값이 달라지므로, 시간 비교나 분류(5.2절)에는 복사 전달 모형(6S, MODTRAN)이나 어두운 물체 빼기로 지표 반사율을 구합니다. 천문의 대기 소광 보정(천우7)과 같은 생각입니다.

주의 센서의 보정 계수는 발사 후 시간이 지나며 변합니다(광학계 오염, 검출기 노화). 사막 같은 안정된 지표, 달, 기내 램프로 주기적으로 다시 보정한 최신 계수를 써야 합니다.
요약
  1. 기하 보정: 센서 모형 → 지상 기준점 → 정사 보정(DEM) → 다시 표본화.
  2. 지형 기복 오차 \(h\tan\theta\)(1 km 산, 20°에서 364 m).
  3. 방사 보정 \(L = G\cdot DN + B\), \(\rho_{TOA} = \pi Ld^2/(E_{sun}\cos\theta_s)\).
  4. 시간 비교·분류에는 대기 보정으로 지표 반사율을 쓴다.

5.1.4연습문제

기본

  1. 분류에 쓸 영상을 다시 표본화할 때 알맞은 방법은?
    답

    최근린(원래 값을 그대로 유지).

  2. TOA 반사율 식에서 \(\cos\theta_s\)로 나누는 까닭은?
    답

    태양이 비스듬히 비추면 단위 면적에 들어오는 빛이 줄기 때문입니다.

응용

  1. DN = 120, G = 0.6, B = −2이면 복사휘도는?
    답

    70 W m⁻² sr⁻¹ μm⁻¹.

  2. 같은 땅을 태양 천정각 30°와 60°에서 찍으면 복사휘도는 대략 몇 배 차이?
    답

    \(\cos30°/\cos60° = 1.73\)배(반사율이 같다면).
