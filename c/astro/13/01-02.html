천문학의 공용어

FITS(Flexible Image Transport System)는 1981년 천문학자들이 정한 자료 형식으로, 지금도 거의 모든 천문 영상, 스펙트럼, 표가 이 형식으로 오갑니다. 사람이 읽을 수 있는 머리말과 기계가 읽는 자료를 한 파일에 담고, 40년 전 파일도 지금 그대로 읽힙니다.

1.2.1구조

  • HDU(Header Data Unit): 머리말 + 자료. 파일은 기본 HDU 하나와 확장 HDU 여러 개로 이루어진다.
  • 머리말: 한 줄 80글자의 '카드'들. 키워드 = 값 / 설명 꼴이며 END로 끝난다. 2,880바이트(카드 36장) 단위로 채운다.
  • 자료: 이진수 배열. 역시 2,880바이트 단위, 큰 끝(big-endian) 순서.

1.2.2키워드

  • 필수: SIMPLE(표준 FITS), BITPIX(픽셀 자료형: 8, 16, 32, −32 실수, −64 배정밀도), NAXIS(차원 수), NAXIS1, NAXIS2(각 축 길이).
  • 관측: DATE-OBS(관측 시각, UTC), EXPTIME(노출 시간, 초), FILTER, OBJECT, AIRMASS, GAIN, RDNOISE.
  • 좌표: CTYPE1/2, CRPIX1/2, CRVAL1/2, CD1_1 등(WCS, 4.3절).
  • 변환: BZERO, BSCALE: 물리 값 = BZERO + BSCALE × 저장 값.
예제 1.2.1

16비트 부호 있는 정수(BITPIX = 16, −32,768~32,767)로 0~65,535의 CCD 값을 저장하려고 BZERO = 32768, BSCALE = 1을 씁니다. 저장 값이 −12,000이면 실제 ADU는? 1,024×1,024 영상의 자료 부분은 몇 바이트입니까?

풀이. \(32768 + (-12000) = 20{,}768\) ADU입니다. 자료는 \(1024^2\times2 = 2{,}097{,}152\)바이트이고, 2,880의 배수로 채우면 729블록 = 2,099,520바이트입니다.

from astropy.io import fits
with fits.open("ngc1234_V_001.fits") as hdul:
    hdul.info()                       # HDU 목록
    h = hdul[0].header; d = hdul[0].data   # BZERO/BSCALE은 자동 적용
    print(h["EXPTIME"], h["FILTER"], h["DATE-OBS"], d.shape, d.dtype)

numpy 배열은 d[y, x](행, 열) 순서이고 0부터 세지만, FITS 머리말의 픽셀 좌표(CRPIX 등)는 1부터 셉니다. 이 한 칸 차이는 흔한 실수의 원인입니다.

주의 머리말의 값은 관측 프로그램이 자동으로 적은 것이라 틀릴 수 있습니다(필터 바퀴 위치 오류, 시계 오차). 중요한 값(노출 시간, 필터, 시각)은 관측 일지와 대조하고, 처리 단계마다 HISTORY 카드로 무엇을 했는지 남깁니다.
요약
  1. FITS: 80글자 머리말 카드 + 이진 자료, 2,880바이트 블록. HDU 여러 개 가능.
  2. 필수 SIMPLE, BITPIX, NAXIS, NAXISn. 관측 DATE-OBS, EXPTIME, FILTER 등.
  3. 물리 값 = BZERO + BSCALE × 저장 값(16비트 무부호는 BZERO = 32768).
  4. numpy는 [y, x]·0부터, FITS 좌표는 1부터.

1.2.3연습문제

기본

  1. BITPIX = −32는 어떤 자료형?
    답

    32비트 부동소수점(단정밀도 실수).

  2. 머리말 카드 한 장은 몇 글자?
    답

    80글자.

응용

  1. BZERO = 100, BSCALE = 0.5, 저장 값 400이면 물리 값은?
    답

    \(100 + 0.5\times400 = 300\).

  2. 2,048×4,096 영상을 BITPIX = −32로 저장하면 자료는 약 몇 MB?
    답

    \(2048\times4096\times4 = 33.6\times10^6\) 바이트, 약 32 MiB.
