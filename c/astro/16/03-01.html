밝기로 잰 거리, 크기로 잰 거리

가까운 우주에서는 밝기로 잰 거리와 크기로 잰 거리가 같지만, 멀리서는 팽창과 곡률 때문에 크게 달라집니다. 관측량에 맞는 거리를 써야 합니다.

3.1.1세 가지 거리

  • 가로 공변 거리 \(d_M\): 평탄하면 공변 거리 \(d_C = \frac c{H_0}\int_0^zdz'/E(z')\)와 같고, 곡률이 있으면 \(\frac{c/H_0}{\sqrt{|\Omega_k|}}\sinh\) 또는 \(\sin(\sqrt{|\Omega_k|}d_CH_0/c)\).
  • 광도 거리 \(d_L = (1 + z)d_M\): 플럭스 \(F = L/4\pi d_L^2\)이 되게 정의. 광자 하나의 에너지가 \(1/(1 + z)\)로 줄고, 도착 간격이 \((1 + z)\)배 늘어 \((1 + z)^2\)만큼 어두워진다.
  • 각지름 거리 \(d_A = d_M/(1 + z)\): 크기 \(D\)인 물체가 각 \(\theta = D/d_A\)로 보이게 정의. 빛이 나올 때 우주가 \(1/(1 + z)\)로 작아 물체까지의 고유 거리가 짧았다.

둘의 비 \(d_L/d_A = (1 + z)^2\)는 우주 모형과 무관합니다(에서링턴 관계).

3.1.2계산 예

예제 3.1.1 (아래 실습 카드 결과, \(H_0 = 70\))

ΛCDM(\(\Omega_m = 0.3\), \(\Omega_\Lambda = 0.7\))에서 \(z = 1\) 은하의 거리들은?

풀이. \(d_C = 3{,}304\) Mpc(평탄이라 \(d_M\)도 같음), \(d_L = 6{,}608\) Mpc(거리 지수 44.10), \(d_A = 1{,}652\) Mpc로 1″가 8.01 kpc입니다. 같은 \(z\)에서 평탄 물질 우주는 \(d_L = 5{,}018\) Mpc로 0.6등급 밝게 보입니다.

3.1.3각지름 거리의 최댓값

\(d_A\)는 \(z\)가 커지며 늘다가 ΛCDM에서 \(z = 1.61\)(1,748 Mpc)에서 가장 크고, 그보다 먼 천체는 오히려 더 크게 보입니다. 아주 먼 천체의 빛은 우주가 아주 작았을 때 나와, 그때 우리와의 고유 거리가 짧았기 때문입니다. 그래서 \(z = 3\) 은하(\(d_A = 1{,}589\) Mpc)는 \(z = 1\) 은하보다 같은 크기에서 조금 더 크게 보입니다.

주의 표면 밝기는 \(L/(d_L^2)\)을 \(\theta^2 \propto 1/d_A^2\)로 나눈 것이라 \((1 + z)^{-4}\)으로 어두워집니다(톨먼 효과). 먼 은하가 크게 보여도 매우 희미한 까닭입니다.
요약
  1. \(d_L = (1 + z)d_M\)(플럭스), \(d_A = d_M/(1 + z)\)(크기), \(d_L/d_A = (1 + z)^2\).
  2. ΛCDM, \(z = 1\): \(d_C\) 3,304, \(d_L\) 6,608, \(d_A\) 1,652 Mpc(1″ = 8.0 kpc).
  3. 각지름 거리는 \(z \approx 1.6\)에서 최대: 더 먼 천체는 더 크게 보인다.
  4. 표면 밝기는 \((1 + z)^{-4}\).

3.1.4연습문제

기본

  1. \(d_M = 3000\) Mpc, \(z = 2\)면 \(d_L\)과 \(d_A\)는?
    답

    9,000 Mpc, 1,000 Mpc.

  2. \(z = 1\)에서 표면 밝기는 몇 배로 어두워집니까?
    답

    16배(3등급).

응용

  1. \(d_A = 1652\) Mpc에서 지름 30 kpc 은하의 각 크기는?
    답

    \(30/1652000\) rad = 3.7″.

  2. \(d_L = 6608\) Mpc의 거리 지수는?
    답

    \(5\log(6.608\times10^9) - 5 = 44.10\).

3.1.2

실습우주 모형에 따른 우주론적 거리 계산하기

실습 · 우주론적 거리

다루는 성취기준 [천우16-03-01]

목표

밀도 매개변수와 허블 상수를 바꾸며 공변 거리, 광도 거리, 각지름 거리를 적색이동의 함수로 계산하고, 우주 나이와 각지름 거리의 최댓값을 확인합니다. 성취기준 [천우16-03-01], [천우16-02-03].

준비

복사를 무시한 FLRW 우주에서 \(E(z) = \sqrt{\Omega_m(1+z)^3 + \Omega_k(1+z)^2 + \Omega_\Lambda}\)(\(\Omega_k = 1 - \Omega_m - \Omega_\Lambda\))를 심프슨 적분(400구간)하고, 곡률이 있으면 sinh·sin으로 바꿉니다. 나이는 \(\int_0^1da/(aH)\)를 2,000구간으로 계산합니다.

절차

  1. Ω_m = 0.3, Ω_Λ = 0.7, H₀ = 70, z = 1에서 결과를 읽습니다.
  2. Ω_m = 1, Ω_Λ = 0과 Ω_m = 0.3, Ω_Λ = 0으로 바꿔 나이와 거리를 비교합니다.
  3. ΛCDM에서 z를 0.5, 3으로 바꿔 각지름 거리를 봅니다.
  4. H₀를 67로 바꿉니다.

기대 결과

  • ΛCDM, z = 1: 나이 13.47 Gyr, 공변 3,304, 광도 6,608(거리 지수 44.10), 각지름 1,652 Mpc(1″ = 8.01 kpc). 각지름 거리 최대 z = 1.61(1,748 Mpc).
  • 평탄 물질: 9.31 Gyr, 광도 5,018 Mpc, 최대 z = 1.25. 열린 물질(0.3, 0): 11.30 Gyr, 광도 5,872 Mpc, 최대 z = 1.90.
  • ΛCDM z = 0.5: 각지름 1,259 Mpc. z = 3: 1,589 Mpc(z = 1보다 작음).
  • H₀ = 67: 14.07 Gyr, z = 1 광도 6,904 Mpc.

분석

  1. 세 거리 곡선이 z가 작을 때 모두 cz/H₀에 가까운 까닭은?
  2. 같은 z에서 ΛCDM의 광도 거리가 평탄 물질 우주보다 큰 까닭을 팽창 역사로 설명하세요.
  3. H₀를 바꾸면 거리와 나이가 모두 1/H₀에 비례해 바뀌는 까닭은?

더 해 보기

astropy.cosmology의 FlatLambdaCDM으로 같은 값을 계산해 비교하고, 복사 항을 넣었을 때 z = 1100의 가로 공변 거리가 얼마나 달라지는지 보세요.
