공 껍질 하나의 운동

일반상대론으로 얻는 프리드만 방정식은 놀랍게도 뉴턴 역학으로도 같은 꼴로 얻을 수 있습니다(곡률 항의 해석만 다름). 균질한 우주에서 아무 점을 중심으로 한 공을 생각하면, 공 바깥의 물질은 대칭이라 공 안에 알짜 힘을 주지 않기 때문입니다.

2.1.1유도

유도. 밀도 \(\rho(t)\)인 균질한 우주에서 반지름 \(R(t) = a(t)r_s\)인 공 껍질 위의 질량 \(m\)을 생각합니다. 껍질 안의 질량 \(M = \frac43\pi R^3\rho\)는 팽창해도 일정합니다. 껍질의 역학적 에너지는 보존되므로 \[ \frac12m\dot R^2 - \frac{GMm}{R} = U \quad(\text{일정}) \] 입니다. \(R = ar_s\), \(M = \frac43\pi\rho a^3r_s^3\)를 넣고 \(\frac12mr_s^2a^2\)로 나누면 \[ \left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho + \frac{2U}{mr_s^2}\frac1{a^2} \quad\Longrightarrow\quad H^2 = \frac{8\pi G}{3}\rho - \frac{kc^2}{R_0^2a^2} \] 입니다. 일반상대론에서는 \(-kc^2/R_0^2\)가 공간 곡률(\(k = +1, 0, -1\), \(R_0\)는 곡률 반지름)이고, \(\rho\)는 질량만이 아니라 모든 에너지 밀도 \(\varepsilon/c^2\)입니다. ∎

  • \(U < 0\)(\(k = +1\)): 묶인 껍질, 닫힌 우주.
  • \(U = 0\)(\(k = 0\)): 탈출 속도와 같음, 평탄 우주. \(H^2 = 8\pi G\rho/3\)에서 임계 밀도가 나온다.
  • \(U > 0\)(\(k = -1\)): 열린 우주.

2.1.2밀도 매개변수로 쓰기

오늘의 값으로 나누면 \(H^2/H_0^2 = \Omega(a) + (1 - \Omega_0)/a^2\)이고, 성분별로 나누어(2.2절)

\[ \frac{H^2}{H_0^2} = \frac{\Omega_r}{a^4} + \frac{\Omega_m}{a^3} + \frac{\Omega_k}{a^2} + \Omega_\Lambda \]

입니다.

2.1.3유체 방정식과 가속 방정식

열역학 제1법칙(팽창하는 부피가 압력 \(P\)로 일을 함)에서 유체 방정식 \(\dot\varepsilon + 3H(\varepsilon + P) = 0\)이 나오고, 이를 프리드만 방정식과 합치면 가속 방정식

\[ \frac{\ddot a}{a} = -\frac{4\pi G}{3c^2}\left(\varepsilon + 3P\right) \]

입니다. 보통 물질과 복사는 \(\varepsilon + 3P > 0\)이라 팽창을 늦춥니다. 팽창이 빨라지려면 \(P < -\varepsilon/3\)인 음의 압력 성분(암흑 에너지)이 필요합니다.

예제 2.1.1

평탄한 물질 우주(\(\rho \propto a^{-3}\))에서 \(a(t)\)를 구하세요.

풀이. \(\dot a^2 = (8\pi G\rho_0/3)a^{-1} = H_0^2a^{-1}\), \(a^{1/2}da = H_0dt\), \(\frac23a^{3/2} = H_0t\). 곧 \(a = (3H_0t/2)^{2/3}\)이고, 오늘(\(a = 1\))의 나이는 \(t_0 = \frac2{3H_0} = 9.3\) Gyr(\(H_0 = 70\))입니다.

주의 뉴턴 유도는 압력이 중력의 원천이 된다는 사실(\(\varepsilon + 3P\))과 곡률의 기하학적 의미를 설명하지 못합니다. 이 부분은 일반상대론이 필요합니다.
요약
  1. 껍질의 에너지 보존 → \(H^2 = \frac{8\pi G}{3}\rho - kc^2/(R_0^2a^2)\).
  2. \(H^2/H_0^2 = \Omega_r a^{-4} + \Omega_m a^{-3} + \Omega_k a^{-2} + \Omega_\Lambda\).
  3. 유체 방정식 \(\dot\varepsilon + 3H(\varepsilon + P) = 0\), 가속 방정식 \(\ddot a/a \propto -(\varepsilon + 3P)\).
  4. 평탄 물질 우주: \(a \propto t^{2/3}\), 나이 \(2/(3H_0)\).

2.1.4연습문제

기본

  1. 평탄 물질 우주의 나이(\(H_0 = 70\))는?
    답

    9.3 Gyr.

  2. 가속 팽창에 필요한 조건은?
    답

    \(P < -\varepsilon/3\)인 성분이 우세할 것.

응용

  1. 평탄 복사 우주(\(\rho \propto a^{-4}\))의 \(a(t)\)는?
    답

    \(\dot a^2 \propto a^{-2}\), \(a\,da \propto dt\), \(a \propto t^{1/2}\).

  2. 우주 상수만 있는 평탄 우주의 \(a(t)\)는?
    답

    \(H\)가 일정해 \(a \propto e^{Ht}\)(지수 팽창).
