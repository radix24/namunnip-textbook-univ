별의 질량은 어떻게 아는가

별의 성질 가운데 가장 중요한 것이 질량입니다. 질량이 별의 광도, 수명, 마지막 모습을 정하기 때문입니다(천우9 5.3절). 그런데 혼자 있는 별의 질량은 직접 잴 방법이 없습니다. 질량은 다른 물체를 끌어당기는 힘으로만 드러나므로, 서로 도는 두 별, 곧 쌍성을 관측해야 합니다. 별의 절반가량은 쌍성 또는 다중성계에 속해 있어 재료는 충분합니다.

3.3.1질량 중심 좌표

3.1절에서 두 별의 상대 궤도는 긴반지름 \(a\)인 타원이었습니다. 질량 중심에서 보면 두 별은 각각 긴반지름 \(a_1, a_2\)인 닮은 타원을 같은 주기로 돌고, 늘 질량 중심을 사이에 두고 반대편에 있습니다.

\[ m_1a_1 = m_2a_2, \qquad a_1 + a_2 = a \]

질량 중심의 정의 \(m_1\vec r_1 + m_2\vec r_2 = 0\)에서 바로 나옵니다. 같은 시간에 도는 거리가 궤도 크기에 비례하므로 속력도 \(m_1v_1 = m_2v_2\)입니다. 곧 무거운 별이 작고 느린 궤도를 돕니다. 그러므로 두 별의 궤도 크기나 속력의 비만 재면 질량의 비가 나오고, Kepler 제3법칙에서 질량의 합이 나옵니다. 둘을 합치면 각각의 질량을 얻습니다.

3.3.2실시 쌍성

망원경으로 두 별이 따로 보이고 궤도 운동을 직접 추적할 수 있는 쌍성을 실시 쌍성이라 합니다. 하늘에서 잰 상대 궤도의 긴반지름을 \(\alpha\)(초각), 연주시차를 \(p\)(초각)라 하면 실제 긴반지름은 \(a = \alpha/p\) AU입니다(시차 1″인 1 pc 거리에서 1″는 1 AU). 그러면

\[ m_1 + m_2 = \frac{a^3}{P^2} = \frac{(\alpha/p)^3}{P^2} \qquad (\text{태양 질량, AU, 년}) \]
예제 3.3.1

센타우루스자리 α A·B의 상대 궤도는 \(\alpha = 17.57''\), 주기 79.9년이고 시차는 0.747″입니다. 질량 중심에서 B까지의 거리가 A까지의 거리의 1.22배입니다. 두 별의 질량을 구하세요.

풀이. \(a = 17.57/0.747 = 23.5\) AU, \(m_A + m_B = 23.5^3/79.9^2 = 12{,}980/6{,}384 = 2.03\). \(m_A/m_B = a_B/a_A = 1.22\)이므로 \(m_B = 2.03/2.22 = 0.91\), \(m_A = 1.12\) 태양 질량입니다.

실제로는 궤도면이 하늘에 기울어져 있어 보이는 타원이 찌그러지는데, 초점(밝은 별)이 보이는 타원의 중심에서 벗어난 정도로 기울기를 되찾을 수 있습니다.

3.3.3분광 쌍성

대부분의 쌍성은 너무 가까워 따로 보이지 않고, 스펙트럼선이 주기적으로 흔들리는 것으로만 알 수 있습니다(분광 쌍성). 궤도면이 시선과 이루는 기울기를 궤도 경사각 \(i\)라 하면(\(i = 90^\circ\)이면 옆에서 봄), 우리가 재는 시선속도 진폭은 실제 궤도 속력의 \(\sin i\)배입니다. 원 궤도에서 두 별의 진폭을 \(K_1, K_2\)라 하면

\[ \frac{m_1}{m_2} = \frac{K_2}{K_1}, \qquad (m_1 + m_2)\sin^3 i = \frac{P(K_1 + K_2)^3}{2\pi G} \]

입니다. 둘째 식은 \(K_1 + K_2 = 2\pi a\sin i/P\)와 제3법칙 \(G(m_1+m_2)P^2 = 4\pi^2a^3\)에서 \(a\)를 지워 얻습니다(타원 궤도면 우변에 \((1-e^2)^{3/2}\)을 곱합니다). 경사각을 모르면 \(\sin^3 i \le 1\) 때문에 질량의 하한만 얻습니다. 한 별의 선만 보이면 질량비도 몰라 질량 함수 \(f = m_2^3\sin^3i/(m_1+m_2)^2 = PK_1^3/(2\pi G)\)만 구합니다. 외계행성의 시선속도법(천우2 3.3절)이 바로 이 경우입니다.

3.3.4식쌍성

궤도면이 시선과 거의 나란해(\(i \approx 90^\circ\)) 두 별이 서로 가리는 쌍성을 식쌍성이라 합니다. 밝기가 주기적으로 줄어드는 광도 곡선에서 \(i\)를 정할 수 있으므로 분광 관측과 합치면 두 별의 질량이 \(\sin^3 i\)의 모호함 없이 나옵니다. 또 가려지는 시간에서 별의 반지름까지 얻습니다. 지금 알려진 정밀한 별 질량과 반지름은 대부분 식쌍성에서 왔습니다.

주의 \(K_1, K_2\)는 질량 중심에 대한 속도입니다. 관측된 시선속도에서 쌍성계 전체의 시선속도(평균값)를 먼저 빼야 합니다.
요약
  1. 질량 중심에서 \(m_1a_1 = m_2a_2\), \(m_1v_1 = m_2v_2\): 비에서 질량비, 제3법칙에서 질량 합.
  2. 실시 쌍성: \(m_1 + m_2 = (\alpha/p)^3/P^2\).
  3. 분광 쌍성: \(m_1/m_2 = K_2/K_1\), \((m_1+m_2)\sin^3 i = P(K_1+K_2)^3/2\pi G\). 경사각을 모르면 하한.
  4. 식쌍성은 \(i \approx 90^\circ\)를 알려 주어 질량과 반지름을 직접 준다.

3.3.5연습문제

기본

  1. 시리우스 A·B의 상대 궤도는 7.50″, 주기 50.1년, 시차 0.379″입니다. 질량의 합은?
    답

    \(a = 19.8\) AU, \(19.8^3/50.1^2 = 7{,}760/2{,}510 = 3.09\) 태양 질량(실제 A 2.06, B 1.02).

  2. 분광 쌍성에서 \(K_1 = 30\) km/s, \(K_2 = 60\) km/s입니다. 질량비는?
    답

    \(m_1/m_2 = 60/30 = 2\).

응용

  1. 위 쌍성의 주기가 5.0일, 원 궤도, 식쌍성(\(i = 90^\circ\))이라면 두 별의 질량은?
    답

    \((m_1+m_2) = P(K_1+K_2)^3/(2\pi G) = 4.32\times10^5\times(9\times10^4)^3/(4.193\times10^{-10}) = 7.51\times10^{29}\) kg = 0.378 태양 질량. \(m_1 = 0.252\), \(m_2 = 0.126\) 태양 질량.

  2. 태양을 목성이 끌어당겨 태양이 질량 중심 둘레를 도는 속력은? (목성 질량은 태양의 1/1047, 목성 공전 속력 13.1 km/s)
    답

    \(v_\odot = 13.1/1047 = 0.0125\) km/s = 12.5 m/s. 외계에서 시선속도법으로 목성을 찾으려면 이 정도 정밀도가 필요합니다.

3.3.2

탐구스펙트럼선이 흔들리는 폭으로 별의 질량을 잰다

탐구 · 쌍성 시선속도

다루는 성취기준 [천우3-03-03]

질문

멀리 있는 쌍성은 두 별이 하나의 점으로 보입니다. 그래도 스펙트럼선은 두 벌이 보이고, 주기적으로 파랑 쪽과 빨강 쪽으로 엇갈려 흔들립니다. 이 흔들림에서 두 별의 질량을 얻을 수 있을까요?

복원

[천우3-02-04]에서 시선속도 \(v_r\)은 선의 Doppler 이동 \(\Delta\lambda/\lambda = v_r/c\)로 잽니다. 두 별은 공통 질량 중심을 같은 주기로 돌고, 질량 중심에서의 거리는 질량에 반비례합니다(\(m_1 a_1 = m_2 a_2\)).

설명

속력도 거리에 비례하므로 두 곡선의 진폭 \(K_1, K_2\)의 비가 질량의 반비례입니다.

\[ \frac{m_1}{m_2} = \frac{K_2}{K_1} \]

Kepler 제3법칙 \(G(m_1+m_2)P^2 = 4\pi^2 a^3\)과 \(K_1 + K_2 = 2\pi a\sin i / (P\sqrt{1-e^2})\)를 엮으면 질량의 합이 나옵니다. 다만 우리는 시선 방향 성분만 보므로 언제나 \(\sin^3 i\)가 붙습니다.

\[ (m_1+m_2)\sin^3 i = \frac{P (K_1+K_2)^3 (1-e^2)^{3/2}}{2\pi G} \]

이심률을 키우면 곡선이 사인 모양에서 벗어나 근점 근처에서 급하게 바뀝니다. 근점 인수 \(\omega\)는 그 비대칭이 어느 쪽으로 기우는지를 정합니다.

연결

한 별의 선만 보이면(어두운 짝별, 외계행성, 블랙홀 후보) 질량비를 얻을 수 없어 질량 함수 \(f = m_1^3\sin^3 i/(m_1+m_2)^2\)만 구합니다. [천우2-03-03]의 시선속도법 외계행성 탐사가 바로 이 경우입니다. 식쌍성이면 \(i \approx 90^\circ\)이므로 \(\sin^3 i\) 문제가 사라져 별의 질량을 직접 잴 수 있습니다([천우1-03-04]).

적용

  1. 처음 값(2 M☉ + 1 M☉, 10일, 원 궤도, \(i = 90^\circ\)): \(K_1 = 47.5\) km/s, \(K_2 = 95.0\) km/s, 긴반지름 0.131 AU가 나옵니다. \(K_2/K_1 = 2\)가 질량비와 맞는지 확인하세요.
  2. 경사각을 30°로 바꾸면 두 진폭이 모두 절반(\(\sin 30^\circ\))이 되고, 곡선에서 얻은 질량 합은 \(3 \times 0.125 = 0.375\) M☉로 줄어듭니다. 경사각을 모르면 질량의 하한만 얻는 까닭입니다.
  3. 이심률 0.5, \(\omega = 90^\circ\)로 바꿔 곡선이 어떻게 기우는지 보세요. 곡선에서 구한 질량 합은 \((1-e^2)^{3/2}\) 보정 덕분에 그대로입니다.
  4. 별 2를 0.1 M☉, 별 1을 1 M☉로 두고 \(K_1\)이 몇 km/s까지 작아지는지 보세요(약 9.3 km/s). 행성 질량으로 내려가면 m/s 수준이 되어 정밀 분광기가 필요합니다.

판단

출력의 질량 합이 참값과 같게 나오는 것은 경사각을 우리가 알려 주었기 때문입니다. 실제 관측에서는 \(i\)를 모르므로 분광 쌍성만으로는 \(m\sin^3 i\)까지만 말할 수 있습니다. 또 두 별이 가까우면 조석으로 궤도가 원으로 바뀌므로([천우3-04-03]) 주기가 짧은 쌍성에서 큰 이심률이 나오면 측정을 다시 의심해 봐야 합니다.
