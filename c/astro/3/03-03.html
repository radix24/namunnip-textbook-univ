3.3.1

탐구스펙트럼선이 흔들리는 폭으로 별의 질량을 잰다

탐구 · 쌍성 시선속도

다루는 성취기준 [천우3-03-03]

질문

멀리 있는 쌍성은 두 별이 하나의 점으로 보입니다. 그래도 스펙트럼선은 두 벌이 보이고, 주기적으로 파랑 쪽과 빨강 쪽으로 엇갈려 흔들립니다. 이 흔들림에서 두 별의 질량을 얻을 수 있을까요?

복원

[천우3-02-04]에서 시선속도 \(v_r\)은 선의 Doppler 이동 \(\Delta\lambda/\lambda = v_r/c\)로 잽니다. 두 별은 공통 질량 중심을 같은 주기로 돌고, 질량 중심에서의 거리는 질량에 반비례합니다(\(m_1 a_1 = m_2 a_2\)).

설명

속력도 거리에 비례하므로 두 곡선의 진폭 \(K_1, K_2\)의 비가 질량의 반비례입니다.

\[ \frac{m_1}{m_2} = \frac{K_2}{K_1} \]

Kepler 제3법칙 \(G(m_1+m_2)P^2 = 4\pi^2 a^3\)과 \(K_1 + K_2 = 2\pi a\sin i / (P\sqrt{1-e^2})\)를 엮으면 질량의 합이 나옵니다. 다만 우리는 시선 방향 성분만 보므로 언제나 \(\sin^3 i\)가 붙습니다.

\[ (m_1+m_2)\sin^3 i = \frac{P (K_1+K_2)^3 (1-e^2)^{3/2}}{2\pi G} \]

이심률을 키우면 곡선이 사인 모양에서 벗어나 근점 근처에서 급하게 바뀝니다. 근점 인수 \(\omega\)는 그 비대칭이 어느 쪽으로 기우는지를 정합니다.

연결

한 별의 선만 보이면(어두운 짝별, 외계행성, 블랙홀 후보) 질량비를 얻을 수 없어 질량 함수 \(f = m_1^3\sin^3 i/(m_1+m_2)^2\)만 구합니다. [천우2-03-03]의 시선속도법 외계행성 탐사가 바로 이 경우입니다. 식쌍성이면 \(i \approx 90^\circ\)이므로 \(\sin^3 i\) 문제가 사라져 별의 질량을 직접 잴 수 있습니다([천우1-03-04]).

적용

  1. 처음 값(2 M☉ + 1 M☉, 10일, 원 궤도, \(i = 90^\circ\)): \(K_1 = 47.5\) km/s, \(K_2 = 95.0\) km/s, 긴반지름 0.131 AU가 나옵니다. \(K_2/K_1 = 2\)가 질량비와 맞는지 확인하세요.
  2. 경사각을 30°로 바꾸면 두 진폭이 모두 절반(\(\sin 30^\circ\))이 되고, 곡선에서 얻은 질량 합은 \(3 \times 0.125 = 0.375\) M☉로 줄어듭니다. 경사각을 모르면 질량의 하한만 얻는 까닭입니다.
  3. 이심률 0.5, \(\omega = 90^\circ\)로 바꿔 곡선이 어떻게 기우는지 보세요. 곡선에서 구한 질량 합은 \((1-e^2)^{3/2}\) 보정 덕분에 그대로입니다.
  4. 별 2를 0.1 M☉, 별 1을 1 M☉로 두고 \(K_1\)이 몇 km/s까지 작아지는지 보세요(약 9.3 km/s). 행성 질량으로 내려가면 m/s 수준이 되어 정밀 분광기가 필요합니다.

판단

출력의 질량 합이 참값과 같게 나오는 것은 경사각을 우리가 알려 주었기 때문입니다. 실제 관측에서는 \(i\)를 모르므로 분광 쌍성만으로는 \(m\sin^3 i\)까지만 말할 수 있습니다. 또 두 별이 가까우면 조석으로 궤도가 원으로 바뀌므로([천우3-04-03]) 주기가 짧은 쌍성에서 큰 이심률이 나오면 측정을 다시 의심해 봐야 합니다.
