무너질 것인가, 버틸 것인가

성간 구름은 자기 중력으로 뭉치려 하고, 기체의 열운동은 흩어지려 합니다. 어느 쪽이 이기느냐에 따라 구름은 그대로 떠 있거나 무너져 별이 됩니다. 1902년 진스는 그 경계를 구름의 질량 하나로 나타냈습니다.

3.3.1Jeans 질량

유도. 질량 \(M\), 반지름 \(R\), 온도 \(T\), 밀도 \(\rho\)가 고른 구름을 생각합니다. 입자 하나의 평균 질량을 \(\mu m_H\)라 하면 입자 수는 \(N = M/(\mu m_H)\)이고 열운동 에너지는 \(K = \frac32NkT\)입니다. 위치 에너지는 \(U = -\frac35GM^2/R\)입니다(천우3 3.4절). 비리얼 정리에서 \(2K + U < 0\), 곧 중력이 열운동의 두 배를 넘으면 구름은 평형을 유지하지 못하고 수축합니다. \[ \frac{3MkT}{\mu m_H} < \frac35\frac{GM^2}{R} \] \(R = (3M/4\pi\rho)^{1/3}\)로 바꾸어 \(M\)에 대해 풀면 \[ M > M_J = \left(\frac{5kT}{G\mu m_H}\right)^{3/2}\left(\frac{3}{4\pi\rho}\right)^{1/2} \] 입니다. ∎

읽는 법: 차갑고(\(T\) 작음) 진할수록(\(\rho\) 큼) Jeans 질량이 작아 작은 구름도 무너집니다. \(M_J \propto T^{3/2}\rho^{-1/2}\)입니다.

예제 3.3.1

분자운 코어(10 K, H₂ 수 밀도 \(10^{10}\) m\(^{-3}\), \(\mu = 2\))와 차가운 중성수소 구름(100 K, H 수 밀도 \(10^8\) m\(^{-3}\), \(\mu = 1\))의 Jeans 질량을 구하세요.

풀이. 분자운 코어: \(\rho = 10^{10}\times2\times1.67\times10^{-27} = 3.35\times10^{-17}\) kg/m³. \(5kT/(G\mu m_H) = 6.91\times10^{-22}/2.23\times10^{-37} = 3.09\times10^{15}\)이고 \((3.09\times10^{15})^{3/2} = 1.72\times10^{23}\), \((3/4\pi\rho)^{1/2} = 8.45\times10^7\)이므로 \(M_J = 1.45\times10^{31}\) kg ≈ 7 \(M_\odot\)입니다. 중성수소 구름: 온도 10배, \(\mu\) 1/2, 밀도 1/200(질량 밀도)이므로 \(M_J\)는 \(10^{3/2}\times2^{3/2}\times\sqrt{200} = 31.6\times2.83\times14.1 = 1{,}260\)배, 약 9,000 \(M_\odot\)입니다.

그래서 별은 차갑고 진한 분자운 코어에서 태어납니다. 묽은 중성수소 구름은 은하 규모의 질량이 아니면 무너지지 않습니다.

3.3.2자유 낙하 시간과 분열

압력이 전혀 버티지 못하면 구름은 중력만으로 떨어집니다. 가운데까지 떨어지는 시간은

\[ t_{ff} = \sqrt{\frac{3\pi}{32G\rho}} \]

로 밀도만으로 정해집니다. 예제 3.3.1의 분자운 코어에서 \(t_{ff} = \sqrt{9.42/(32\times6.674\times10^{-11}\times3.35\times10^{-17})} = 1.15\times10^{13}\) s ≈ 36만 년입니다. 별이 생기는 시간이 별의 수명에 비해 매우 짧다는 뜻입니다.

수축하는 구름은 밀도가 커지므로 \(M_J \propto \rho^{-1/2}\)이 작아집니다. 구름이 수축하며 생긴 에너지를 빛으로 잘 내보내 온도가 거의 일정하게 유지되는 동안에는, 더 작은 조각들이 각각 Jeans 질량을 넘어 따로 무너집니다. 이것이 분열이고, 별이 혼자가 아니라 성단으로 태어나는 까닭입니다. 구름이 진해져 빛이 빠져나가지 못하면(광학적으로 두꺼워지면) 데워지면서 분열이 멈춥니다.

주의 실제 분자운은 Jeans 질량보다 훨씬 무거운데도 별이 만들어지는 효율이 낮습니다(자유 낙하 시간당 질량의 수 %). 자기장과 난류가 열운동 이상으로 구름을 떠받치기 때문입니다. Jeans 조건은 필요조건에 가까운 첫 어림입니다.
요약
  1. 비리얼 정리에서 \(M_J = (5kT/G\mu m_H)^{3/2}(3/4\pi\rho)^{1/2}\). 이보다 무거우면 무너진다.
  2. \(M_J \propto T^{3/2}\rho^{-1/2}\): 차갑고 진한 분자운 코어(수 \(M_\odot\))에서 별이 생긴다.
  3. 자유 낙하 시간 \(t_{ff} = \sqrt{3\pi/32G\rho}\), 분자운 코어에서 수십만 년.
  4. 수축하며 \(M_J\)가 줄어 분열이 일어나 성단이 생긴다.

3.3.3연습문제

기본

  1. 온도가 그대로이고 밀도가 100배가 되면 Jeans 질량은 몇 배?
    답

    \(100^{-1/2} = 1/10\)배.

  2. 밀도 \(10^{-20}\) kg/m³인 구름의 자유 낙하 시간은?
    답

    \(\sqrt{9.42/(2.136\times10^{-29})} = 6.6\times10^{14}\) s ≈ 2,100만 년.

응용

  1. 예제 3.3.1의 분자운 코어에서 Jeans 반지름(질량 \(M_J\)인 구의 반지름)은?
    답

    \(R = (3M_J/4\pi\rho)^{1/3} = (3\times1.45\times10^{31}/(4\pi\times3.35\times10^{-17}))^{1/3} = 4.7\times10^{15}\) m ≈ 0.15 pc.

  2. 구름이 수축하며 온도가 \(T \propto \rho^{1/3}\)로 오른다면 \(M_J\)는 밀도에 따라 어떻게 바뀌고, 분열은 계속됩니까?
    답

    \(M_J \propto \rho^{1/2}\rho^{-1/2} = \rho^0\): 일정해져 더 작은 조각으로 나뉘지 않습니다. 온도가 더 빨리 오르면 분열이 멈춥니다.
