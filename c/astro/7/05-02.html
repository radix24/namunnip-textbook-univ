화소 번호를 파장으로

검출기가 기록하는 것은 화소 번호마다의 세기입니다. 스펙트럼선의 파장을 알려면 "몇 번 화소가 몇 nm인가"를 정해야 합니다. 격자 방정식으로 대략은 알 수 있지만, 광학계의 작은 어긋남과 휨 때문에 정확한 관계는 직접 재야 합니다. 파장을 아는 방출선을 내는 램프(비교 광원)의 스펙트럼을 같은 설정으로 찍어 씁니다.

5.2.1비교 광원

  • 헬륨, 네온, 아르곤 램프: 가시광~근적외선에 선이 많다. 저·중분산에 쓴다.
  • 토륨-아르곤 램프: 선이 수천 개로 촘촘해 고분산 분광에 쓴다.
  • 요오드 흡수 셀, 레이저 주파수 빗: m/s 정밀도의 시선속도 측정에 쓴다.

5.2.2분산 함수 맞추기

  1. 비교 광원 스펙트럼에서 각 방출선의 중심 화소를 가우스 맞춤 등으로 화소의 1/10 이하까지 잰다.
  2. 선 목록과 맞대어 각 선의 참 파장을 짝짓는다(밝은 선 몇 개로 대략 맞춘 뒤 나머지를 찾는다).
  3. 짝지은 (화소, 파장)에 다항식 \(\lambda(p) = a_0 + a_1p + a_2p^2 + \cdots\)을 최소제곱으로 맞춘다.
  4. 잔차(참 파장 − 맞춘 파장)를 화소에 대해 그려, 무늬 없이 고르게 흩어지는지 확인한다. 휘는 무늬가 남으면 차수를 올리고, 몇몇 점만 크게 벗어나면 잘못 짝지은 선을 뺀다.

차수는 잔차의 무늬가 사라지는 가장 낮은 것을 고릅니다. 차수를 너무 높이면 선이 드문 가장자리에서 함수가 제멋대로 휘기 때문입니다(천우6 3.2절 Runge 현상과 같은 이유). 아래 실습 카드에서 1차와 2차 맞춤의 잔차를 비교할 수 있습니다.

예제 5.2.1

파장 보정 잔차의 표준편차가 0.006 nm입니다. 600 nm에서 시선속도 오차로는?

풀이. \(v = c\,\Delta\lambda/\lambda = 299{,}792\times0.006/600 = 3.0\) km/s입니다. 선 하나를 재는 오차가 이 정도이고, 여러 선을 쓰면 줄어듭니다.

5.2.3쓰는 법

망원경이 움직이면 분광기가 조금 휘어 분산 함수가 변하므로, 과학 노출 바로 앞뒤에 비교 광원을 찍습니다. 맞춘 분산 함수로 과학 스펙트럼의 화소 축을 파장 축으로 바꾸고, 하늘의 방출선(산소 557.7 nm 등)으로 보정이 맞는지 한 번 더 확인합니다.

주의 비교 광원과 별빛이 분광기 안에서 같은 길을 지나야 합니다. 비교 광원이 슬릿을 고르게 채우는 반면 별의 상은 슬릿 안에서 한쪽에 치우칠 수 있어, 그만큼 파장이 어긋나 보입니다(슬릿 중심 오차). 정밀 측정에서는 별빛과 같은 광섬유로 비교 광원을 넣습니다.
요약
  1. 비교 광원 선의 (화소, 참 파장)에 다항식을 맞춰 분산 함수를 얻는다.
  2. 잔차의 무늬가 사라지는 가장 낮은 차수를 고른다.
  3. 잔차 0.006 nm는 600 nm에서 3 km/s.
  4. 과학 노출 앞뒤로 비교 광원을 찍고 하늘 선으로 확인한다.

5.2.4연습문제

기본

  1. 화소 100에서 600.00 nm, 화소 1100에서 700.00 nm이면 1차 분산 함수는?
    답

    \(\lambda = 590 + 0.1p\) nm.

  2. 분산율 0.05 nm/화소에서 선 중심을 0.1화소 정밀도로 재면 파장 정밀도는?
    답

    0.005 nm.

응용

  1. 1차 맞춤의 잔차가 가운데에서 음, 양 끝에서 양인 포물선 무늬를 보입니다. 무엇을 해야 합니까?
    답

    분산 함수에 2차 항이 필요합니다. 2차 다항식으로 다시 맞춥니다.

  2. 고분산(\(R = 60{,}000\), 화소당 0.003 nm) 분광기로 1 m/s를 재려면 선 중심을 화소의 몇 분의 1까지 맞춰야 합니까? (500 nm)
    답

    1 m/s는 \(1.7\times10^{-6}\) nm, 화소의 약 1/1,800. 수천 개 선을 함께 써야 가능합니다.

5.2.2

실습비교 광원 선으로 분산 함수 맞추기

실습 · 파장 보정

다루는 성취기준 [천우7-05-02]

목표

가상 네온 비교 광원 선의 화소 위치에 1차와 2차 다항식을 맞추고, 잔차 그림으로 알맞은 차수를 고릅니다. 성취기준 [천우7-05-02].

준비

가상 자료입니다. 네온 선의 실제 파장(585~703 nm)을 정해 둔 분산 함수 \(\lambda = 580 + 0.06p + d_2p^2\)로 화소 위치에 놓고, 선 중심 측정 오차를 더했습니다. 그림은 맞춘 함수에 대한 각 선의 잔차입니다.

절차

  1. 처음 값(d₂ = 2×10⁻⁸, 1차 맞춤)에서 잔차의 모양과 표준편차를 봅니다.
  2. 맞춤 차수를 2차로 바꿉니다.
  3. d₂를 0으로 하면 1차 맞춤으로 충분한지 봅니다.
  4. 측정 오차를 0.3화소로 키우고 2차 맞춤의 잔차를 봅니다.

기대 결과

  • 1차 맞춤은 잔차가 포물선 무늬를 그리고, 표준편차가 5.2 pm(시선속도 2.5 km/s)입니다.
  • 2차 맞춤으로 바꾸면 무늬가 사라지고 잔차가 3.5 pm(1.7 km/s)로, 측정 오차(0.05화소 × 0.06 nm = 3 pm) 수준이 됩니다.
  • d₂ = 0이면 1차 맞춤으로도 잔차가 3.7 pm로 충분합니다.
  • 측정 오차를 0.3화소로 키우면 2차 맞춤의 잔차가 21 pm(10 km/s)로 커지지만 무늬는 없습니다.

분석

  1. 잔차에 '무늬'가 있다는 것과 '크기'가 크다는 것은 각각 무엇을 뜻합니까?
  2. 출력의 km/s 값으로, 이 분광기로 시선속도를 몇 km/s 정밀도로 잴 수 있을지 판단하세요.
  3. 선이 가운데에만 몰려 있고 양 끝에 없다면 높은 차수 맞춤에 어떤 위험이 있습니까?
