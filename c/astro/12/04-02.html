이 절에서 배울 것
  • 단순 닫힌 상자 모형의 가정을 말한다.
  • 기체 금속 함량 \(Z = p\ln(1/\mu)\)를 유도한다.
  • 금속 함량보다 낮은 별의 누적 비율을 계산한다.
먼저 알아야 할 것
  • 항성종족과 금속 함량 (4.1절), 원소 합성 (천우9 4.2절), 미분방정식.

가장 간단한 은하 화학

별은 기체에서 태어나고, 죽을 때 금속을 만든 기체를 돌려줍니다. 그래서 시간이 갈수록 기체의 금속 함량이 늘고, 나중에 태어난 별일수록 금속이 많습니다. 이 과정을 가장 단순하게 계산한 것이 단순 닫힌 상자 모형(Talbot & Arnett, Searle & Sargent, 1970년대)입니다.

4.2.1가정

  • 닫힌 상자: 처음에 모두 금속이 없는 기체이고, 바깥과 물질을 주고받지 않는다(전체 질량 일정).
  • 순간 재활용: 무거운 별은 곧바로(별의 수명을 무시) 금속을 섞어 기체로 돌려준다.
  • 잘 섞임: 기체는 늘 고르게 섞여 있다.
  • 수득률 \(p\): 별로 들어간 질량 1당 새로 만들어져 기체로 돌아오는 금속의 질량(일정).

4.2.2유도

유도. 기체 질량 \(g\), 금속 함량 \(Z\)(기체의 금속 질량 비율), 오래 사는 별에 갇힌 질량 \(s\)라 합시다. 별에 \(ds\)만큼 갇히면, 기체의 금속은 새로 만든 \(p\,ds\)만큼 늘고 별에 갇힌 \(Z\,ds\)만큼 줍니다. 곧 \(d(gZ) = p\,ds - Z\,ds\). 닫힌 상자에서 \(dg = -ds\)이므로 \(g\,dZ + Z\,dg = -p\,dg + Z\,dg\), 정리하면 \(dZ = -p\,dg/g\). 처음 기체 질량 \(g_0\), \(Z = 0\)에서 적분하면 \[ Z = p\ln\frac{g_0}{g} = p\ln\frac1\mu \] 입니다. \(\mu = g/g_0\)는 지금 남은 기체 비율입니다. ∎

4.2.3별의 금속 함량 분포

기체의 금속 함량이 \(Z\)보다 작았을 때 태어난 별의 질량은 \(s(<Z) = g_0 - g(Z) = g_0(1 - e^{-Z/p})\)입니다. 지금의 기체 비율을 \(\mu_1\), 지금의 금속 함량을 \(Z_1 = p\ln(1/\mu_1)\)이라 하면, 금속 함량이 \(Z\)보다 작은 별의 비율은

\[ \frac{s(<Z)}{s(Z_1)} = \frac{1 - \mu_1^{Z/Z_1}}{1 - \mu_1} \]

입니다.

예제 4.2.1

태양 근처 원반의 기체 비율을 \(\mu_1 = 0.1\), 지금 기체의 금속 함량을 \(Z_1 = Z_\odot\)으로 두면 수득률과 \(Z < 0.25Z_\odot\)인 별의 비율은?

풀이. \(p = Z_\odot/\ln10 = 0.434Z_\odot\). 비율 \((1 - 0.1^{0.25})/(1 - 0.1) = (1 - 0.562)/0.9 = 48.6\%\). \(Z < 0.5Z_\odot\)이면 \((1 - 0.316)/0.9 = 76.0\%\). 별의 절반 가까이가 태양의 1/4보다 금속이 적어야 한다는 예측입니다. 관측과 비교한 결과는 4.3절에서 봅니다.

주의 순간 재활용 가정은 수명이 짧은 무거운 별이 만드는 산소 같은 원소에는 잘 맞지만, Ia형 초신성이 10억 년쯤 걸려 만드는 철에는 맞지 않습니다. 그래서 산소로 계산한 결과와 철([Fe/H])로 잰 관측을 비교할 때는 조심해야 합니다.
요약
  1. 닫힌 상자: 물질 출입 없음, 순간 재활용, 잘 섞임, 수득률 \(p\) 일정.
  2. 기체 금속 함량 \(Z = p\ln(1/\mu)\).
  3. 누적 분포 \(s(<Z)/s_1 = (1 - \mu_1^{Z/Z_1})/(1 - \mu_1)\).
  4. \(\mu_1 = 0.1\), \(Z_1 = Z_\odot\)이면 \(Z < 0.25Z_\odot\)인 별이 48.6%.

4.2.4연습문제

기본

  1. 기체가 절반 남았을 때(\(\mu = 0.5\)) 기체의 금속 함량은 수득률의 몇 배?
    답

    \(\ln2 = 0.69\)배.

  2. 닫힌 상자에서 기체를 모두 쓰면(\(\mu \to 0\)) \(Z\)는?
    답

    무한대로 커진다(실제로는 기체가 다 떨어지기 전에 별 형성이 느려진다).

응용

  1. \(\mu_1 = 0.2\), \(Z_1 = Z_\odot\)이면 \(p\)와 \(Z < 0.25Z_\odot\)인 별의 비율은?
    답

    \(p = 1/\ln5 = 0.621Z_\odot\), \((1 - 0.2^{0.25})/0.8 = (1 - 0.669)/0.8 = 41.4\%\).

  2. 수득률이 \(0.01\)(질량 비율)이고 기체가 10% 남았다면 기체의 \(Z\)는?
    답

    \(0.01\ln10 = 0.023\).

4.2.2

실습닫힌 상자와 유입 모형의 금속 함량 분포를 관측과 비교하기

실습 · 화학 진화

다루는 성취기준 [천우12-04-02]

목표

단순 닫힌 상자 모형과 극단적 유입 모형의 금속 함량 누적 분포를 그려, 태양 근처 G 왜성의 분포(가상 근사)와 비교하고 G 왜성 문제를 확인합니다. 성취기준 [천우12-04-02], [천우12-04-03].

준비

두 모형 모두 지금 기체의 금속 함량을 \(Z_\odot\)으로 맞추도록 수득률 \(p\)를 정합니다. 극단적 유입 모형은 별이 되는 만큼 금속 없는 기체가 들어와 기체 질량이 일정하다고 봅니다(\(Z = p(1 - e^{-s/g})\)). 비교 곡선은 [Fe/H]가 평균 −0.1, 표준편차 0.2인 정규분포로 만든 가상 근사입니다(실제 G 왜성 분포의 대략적인 모양).

절차

  1. 닫힌 상자, μ₁ = 0.1에서 Z < 0.25 Z☉와 0.5 Z☉인 별의 비율을 모형과 관측 근사로 비교합니다.
  2. μ₁을 0.05~0.5로 바꿔도 닫힌 상자가 관측에 맞는지 봅니다.
  3. 모형을 극단적 유입으로 바꿔 같은 비교를 합니다.

기대 결과

  • 닫힌 상자, μ₁ = 0.1: p = 0.434 Z☉, Z < 0.25 Z☉ 48.6%, Z < 0.5 Z☉ 76.0%. 관측 근사는 0.6%, 15.7%.
  • 닫힌 상자, μ₁ = 0.05: 55.5%, 0.5: 31.8%. 어떤 μ₁으로도 금속이 적은 별이 너무 많다(G 왜성 문제).
  • 극단적 유입, μ₁ = 0.1: p = 1.000 Z☉, 3.2%, 7.7%. μ₁ = 0.2: 7.0%, 16.9%. 금속이 적은 별의 비율이 크게 준다.

분석

  1. 닫힌 상자 모형에서 금속이 적은 별이 많이 생기는 까닭을 처음에 기체가 많았던 것으로 설명하세요.
  2. 유입 모형이 G 왜성 문제를 줄이는 까닭은?
  3. 관측 근사와 유입 모형이 Z < 0.5 Z☉에서는 비슷하고 Z < 0.25 Z☉에서 다른 것은 무엇을 뜻할 수 있습니까?
