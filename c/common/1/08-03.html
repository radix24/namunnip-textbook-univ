8.3.1합을 넓이와 비교하기

\(\sum\frac{1}{n^2}\)의 합은 쉽게 구할 수 없지만, 수렴하는지는 알 수 있습니다. 항 \(\frac{1}{n^2}\)을 폭 1, 높이 \(\frac{1}{n^2}\)인 직사각형으로 그리면, 둘째 항부터의 직사각형들은 곡선 \(y = \frac{1}{x^2}\) 아래(\(x \ge 1\))에 들어갑니다. 그 넓이 \(\int_1^\infty\frac{dx}{x^2} = 1\)이 유한하므로 합도 유한합니다.

정리 8.3.1 (적분 판정법)

\(f\)가 \([1, \infty)\)에서 연속이고 양수이며 감소하고 \(a_n = f(n)\)이면, \(\sum a_n\)과 \(\int_1^\infty f(x)\,dx\)는 함께 수렴하거나 함께 발산한다.

따름정리 8.3.2 (\(p\)-급수)

\(\displaystyle\sum_{n=1}^\infty\frac{1}{n^p}\)은 \(p > 1\)이면 수렴하고 \(p \le 1\)이면 발산한다.

5.5절의 \(\int_1^\infty\frac{dx}{x^p}\) 결과를 그대로 옮긴 것입니다. 특히 조화급수 \(1 + \frac12 + \frac13 + \cdots\)는 발산합니다. 항은 0으로 가지만 그 속도가 느려서 합이 끝없이 커집니다(100만 항을 더해도 약 14.4에 불과하지만, 결국 어떤 수보다도 커집니다).

8.3.2비교 판정법

정리 8.3.3 (비교 판정법)

\(0 \le a_n \le b_n\)일 때, \(\sum b_n\)이 수렴하면 \(\sum a_n\)도 수렴하고, \(\sum a_n\)이 발산하면 \(\sum b_n\)도 발산한다.

정리 8.3.4 (극한 비교 판정법)

\(a_n, b_n > 0\)이고 \(\lim\dfrac{a_n}{b_n} = c\) (\(0 < c < \infty\))이면 두 급수는 함께 수렴하거나 함께 발산한다.

비교할 급수로는 등비급수와 \(p\)-급수를 씁니다. 항이 분수식이면 분자와 분모의 최고차항만 남긴 식을 \(b_n\)으로 잡는 것이 요령입니다.

예제 8.3.5

(가) \(\sum\frac{1}{2^n + 1}\) (나) \(\sum\frac{2n^2 + 3n}{\sqrt{5 + n^5}}\)

풀이. (가) \(\frac{1}{2^n + 1} < \frac{1}{2^n}\)이고 \(\sum\frac{1}{2^n}\)은 수렴하는 등비급수이므로 수렴.

(나) 최고차항만 보면 \(\frac{2n^2}{n^{5/2}} = \frac{2}{n^{1/2}}\). \(b_n = \frac{1}{n^{1/2}}\)과 극한 비교하면 \(\frac{a_n}{b_n} \to 2\)이고, \(\sum\frac{1}{n^{1/2}}\)은 \(p = \frac12 \le 1\)이라 발산하므로 발산.

주의비교 판정법에서 부등식의 방향이 중요합니다. "수렴하는 것보다 큰 급수"나 "발산하는 것보다 작은 급수"는 아무것도 알려 주지 않습니다. 그럴 때는 극한 비교 판정법을 쓰세요.
요약
  1. 적분 판정법: 양수·감소·연속인 \(f(n) = a_n\)이면 \(\sum a_n\)과 \(\int_1^\infty f\)는 함께 수렴·발산.
  2. \(\sum\frac{1}{n^p}\): \(p > 1\) 수렴, \(p \le 1\) 발산.
  3. 비교·극한 비교: 최고차항만 남긴 \(p\)-급수나 등비급수와 비교한다.

8.3.3연습문제

기본

  1. 수렴·발산을 판정하여라. (가) \(\sum\frac{1}{n^{1.01}}\) (나) \(\sum\frac{1}{\sqrt n}\) (다) \(\sum\frac{1}{n^2 + 1}\)
    답

    (가) 수렴 (나) 발산 (다) \(< \frac{1}{n^2}\), 수렴

응용

  1. \(\sum_{n=2}^\infty\frac{1}{n\ln n}\)의 수렴을 판정하여라.
    답

    적분 판정법: \(\int_2^\infty\frac{dx}{x\ln x} = \lim[\ln(\ln x)]_2^t = \infty\). 발산.

8.3.2

예제급수 판정법, 어떤 것을 고를까

발산 · 비교 · 비 · 근 · 적분 · 교대급수

다루는 성취기준 [공통1-08-03]

판정법 요약

  1. 발산 판정\(a_n \not\to 0\)이면 \(\sum a_n\)은 발산. 거꾸로는 안 됩니다(\(\sum\frac1n\)). 늘 가장 먼저 봅니다.
  2. p-급수, 기하급수\(\sum\frac{1}{n^p}\)는 \(p > 1\)에서만 수렴. \(\sum r^n\)은 \(|r| < 1\)에서만 수렴. 비교의 기준입니다.
  3. (극한) 비교양의 항. 유리식이나 근호식처럼 "최고차항끼리" 보면 p-급수와 닮은 경우.
  4. 비 판정\(\lim\left|\frac{a_{n+1}}{a_n}\right| = \rho\). \(\rho < 1\) 절대수렴, \(\rho > 1\) 발산, \(\rho = 1\) 판정 불가. 계승 \(n!\), 지수 \(c^n\)이 있을 때.
  5. 근 판정\(\lim\sqrt[n]{|a_n|} = \rho\), 결론은 비 판정과 같음. 항 전체가 \(n\)제곱 꼴 \((\cdots)^n\)일 때.
  6. 적분 판정\(a_n = f(n)\), \(f\)가 양수·연속·감소이면 \(\sum a_n\)과 \(\int_1^\infty f\)는 함께 수렴/발산. \(\frac{1}{n\ln n}\)처럼 적분하기 쉬울 때.
  7. 교대급수\(\sum(-1)^nb_n\), \(b_n\) 감소하며 \(\to 0\)이면 수렴. 오차 \(|S - S_N| \le b_{N+1}\).

비 판정의 근거 (한 줄 증명)

\(\rho < r < 1\)인 \(r\)을 고르면 충분히 큰 \(n \ge N\)에서 \(|a_{n+1}| \le r|a_n|\)이므로 \(|a_{N+k}| \le |a_N|r^k\). 수렴하는 기하급수와 비교됩니다. 결국 비 판정은 "기하급수와의 비교"입니다. \(\rho = 1\)에서 판정 못 하는 이유도 여기서 보입니다: \(\sum\frac1n\)(발산)과 \(\sum\frac{1}{n^2}\)(수렴) 모두 \(\rho = 1\)입니다.

먼저 예측

\(\sum\frac{n!}{n^n}\)은 수렴할까요? \(n!\)과 \(n^n\) 중 어느 쪽이 더 빨리 커지는지 생각해 보세요.

예측 확인

수렴합니다. \(n^n = n\cdot n\cdots n\)이 \(n! = 1\cdot2\cdots n\)보다 훨씬 빨리 커집니다.

문제. 수렴, 발산을 판정하세요.
(가) \(\displaystyle\sum\frac{n^2 + 1}{n^4 - n + 3}\) (나) \(\displaystyle\sum\frac{n!}{n^n}\) (다) \(\displaystyle\sum\left(\frac{2n}{3n + 1}\right)^n\) (라) \(\displaystyle\sum_{n\ge2}\frac{1}{n(\ln n)^2}\) (마) \(\displaystyle\sum\frac{(-1)^n}{\sqrt n}\) (바) \(\displaystyle\sum\frac{n}{2n + 5}\)

풀이

  1. (바) 먼저: \(\frac{n}{2n + 5} \to \frac12 \ne 0\). 발산.
    발산 판정. 다른 판정법을 쓸 필요가 없다.
  2. (가) 최고차항 \(\frac{n^2}{n^4} = \frac{1}{n^2}\). 극한 비교: \(\frac{(n^2 + 1)/(n^4 - n + 3)}{1/n^2} = \frac{n^4 + n^2}{n^4 - n + 3} \to 1\). \(\sum\frac{1}{n^2}\) 수렴이므로 수렴.
    유리식 → 극한 비교.
  3. (나) \(\frac{a_{n+1}}{a_n} = \frac{(n+1)!}{(n+1)^{n+1}}\cdot\frac{n^n}{n!} = \left(\frac{n}{n+1}\right)^n = \frac{1}{(1 + 1/n)^n} \to \frac1e < 1\). 수렴.
    계승 → 비 판정. \((n+1)! = (n+1)n!\)으로 약분.
  4. (다) \(\sqrt[n]{a_n} = \frac{2n}{3n + 1} \to \frac23 < 1\). 수렴.
    \(n\)제곱 꼴 → 근 판정.
  5. (라) \(f(x) = \frac{1}{x(\ln x)^2}\)은 \(x \ge 2\)에서 양수·연속·감소. \(\int_2^\infty\frac{dx}{x(\ln x)^2} = \left[-\frac{1}{\ln x}\right]_2^\infty = \frac{1}{\ln 2}\). 수렴.
    \(u = \ln x\)로 적분이 쉬움 → 적분 판정. (\(\frac{1}{n\ln n}\)은 발산했던 것과 비교.)
  6. (마) \(b_n = \frac{1}{\sqrt n}\)은 감소하고 \(\to 0\). 교대급수 판정으로 수렴. 그러나 \(\sum\frac{1}{\sqrt n}\)은 발산(\(p = \frac12\))이므로 조건수렴.
    부호가 바뀌면 먼저 절댓값 급수를 보고, 발산하면 교대급수 판정.

고르는 순서

① 항이 0으로 가나? ② 알려진 급수(p, 기하)인가? ③ \(n!\)이나 \(c^n\) → 비, \((\ )^n\) → 근 ④ 유리식·근호 → (극한) 비교 ⑤ 적분하기 쉬운 \(f(n)\) → 적분 ⑥ 부호가 바뀜 → 절대수렴부터, 안 되면 교대급수.

의미

판정법을 고르는 일은 일반항이 얼마나 빨리 줄어드는지 알아보는 일입니다. 비 판정은 "기하급수와 비교하기"이고, 극한 비교는 "p-급수와 비교하기"입니다. 결국 판정법은 몇 개의 기준 급수와 비교하는 방법들입니다.

흔한 오해

  • p-급수에 비 판정: \(\rho = 1\)이 나와 아무것도 알 수 없습니다. 다항식·유리식에는 비 판정을 쓰지 않습니다.
  • 적분값 = 급수의 합: 적분 판정은 수렴 여부만 알려 줍니다. (라)의 합은 \(\frac{1}{\ln2}\)이 아닙니다.
