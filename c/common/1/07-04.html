먼저 알아야 할 것

7.4.1부채꼴로 나누기

직교좌표에서는 넓이를 세로 띠(직사각형)로 나누었습니다. 극좌표에서는 원점에서 뻗어 나가는 가는 부채꼴로 나누는 것이 자연스럽습니다. 중심각 \(d\theta\), 반지름 \(r = f(\theta)\)인 부채꼴의 넓이는 \(\frac12r^2d\theta\)이므로

정리 7.4.1

\(r = f(\theta)\), \(a \le \theta \le b\)로 둘러싸인 부채꼴 모양 영역의 넓이는 \(\displaystyle A = \int_a^b\frac12[f(\theta)]^2d\theta\).

예제 7.4.2

심장형 \(r = 1 + \cos\theta\)로 둘러싸인 넓이를 구하여라.

풀이. \(\theta\)가 0부터 \(2\pi\)까지 돌면 곡선을 한 바퀴 그립니다.

\[A = \frac12\int_0^{2\pi}(1 + 2\cos\theta + \cos^2\theta)\,d\theta = \frac12\left(2\pi + 0 + \pi\right) = \frac{3\pi}{2}.\]

\(\int_0^{2\pi}\cos^2\theta\,d\theta = \pi\)는 5.2절의 반각 공식으로 구했습니다.

예제 7.4.3

장미 곡선 \(r = \cos2\theta\)의 잎 하나의 넓이를 구하여라.

풀이. 오른쪽 잎은 \(r \ge 0\)인 \(-\frac\pi4 \le \theta \le \frac\pi4\)에서 그려집니다. \(A = \frac12\int_{-\pi/4}^{\pi/4}\cos^22\theta\,d\theta = \frac12\cdot\frac\pi4 = \frac\pi8\).

두 곡선 사이의 넓이는 바깥 곡선의 넓이에서 안쪽 곡선의 넓이를 빼서 \(\frac12\int(r_{\text{바깥}}^2 - r_{\text{안}}^2)\,d\theta\)로 구합니다. 두 곡선이 만나는 각을 먼저 구해 적분 구간으로 씁니다.

7.4.2길이

\(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)에 7.2절의 길이 공식을 쓰고 정리하면 \(x'^2 + y'^2 = r^2 + \left(\frac{dr}{d\theta}\right)^2\)이 됩니다.

정리 7.4.4 \[L = \int_a^b\sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta.\]
예제 7.4.5

심장형 \(r = 1 + \cos\theta\)의 길이를 구하여라.

풀이. \(r^2 + r'^2 = (1 + \cos\theta)^2 + \sin^2\theta = 2 + 2\cos\theta = 4\cos^2\frac\theta2\). 대칭이므로 위쪽 절반(\(0 \le \theta \le \pi\), \(\cos\frac\theta2 \ge 0\))의 두 배: \(L = 2\int_0^\pi2\cos\frac\theta2\,d\theta = 2\left[4\sin\frac\theta2\right]_0^\pi = 8\).

주의적분 구간을 정할 때 곡선이 겹쳐 그려지지 않는지 확인하세요. \(r = \cos2\theta\)를 \(0\)부터 \(2\pi\)까지 적분하면 잎 네 개를 모두 셉니다. 또 \(r\)이 음수가 되는 구간에서는 점이 반대쪽에 찍힌다는 점을 기억하세요.
요약
  1. 넓이 \(A = \int\frac12r^2d\theta\) (부채꼴의 합).
  2. 길이 \(L = \int\sqrt{r^2 + r'^2}\,d\theta\).
  3. 적분 구간: 곡선을 한 번만 그리는 \(\theta\)의 범위.

7.4.3연습문제

기본

  1. 원 \(r = 2\sin\theta\)로 둘러싸인 넓이를 공식으로 구하여라.
    답

    \(0 \le \theta \le \pi\): \(\frac12\int_0^\pi4\sin^2\theta\,d\theta = \pi\). (반지름 1인 원)

응용

  1. \(r = 3\cos\theta\)의 안쪽, \(r = 1 + \cos\theta\)의 바깥쪽 영역의 넓이를 구하여라.
    답

    교점 \(3\cos\theta = 1 + \cos\theta\), \(\theta = \pm\frac\pi3\). \(A = 2\cdot\frac12\int_0^{\pi/3}(9\cos^2\theta - (1 + \cos\theta)^2)d\theta = \int_0^{\pi/3}(8\cos^2\theta - 2\cos\theta - 1)d\theta = \pi\).

  1. 극좌표에서 넓이와 곡선의 길이를 구할 수 있다.

7.4.2

예제극좌표 곡선의 넓이: 부채꼴로 썰기

카디오이드 · 장미 곡선

다루는 성취기준 [공통1-07-04]

극좌표 복습

점을 원점까지의 거리 \(r\)와 \(x\)축에서 잰 각 \(\theta\)로 나타냅니다. \(x = r\cos\theta\), \(y = r\sin\theta\), \(r^2 = x^2 + y^2\). 한 점의 표현은 여러 개입니다: \((r, \theta)\), \((r, \theta + 2\pi)\), \((-r, \theta + \pi)\)는 같은 점입니다.

넓이 공식의 유도

  1. 곡선 \(r = f(\theta)\), \(\alpha \le \theta \le \beta\) (\(f \ge 0\), \(\beta - \alpha \le 2\pi\))와 두 반직선이 둘러싼 영역을 각 \(\Delta\theta\)로 나눈다.
    세로 띠 대신 부채꼴 조각.
  2. 조각 하나는 반지름 약 \(f(\theta_i^*)\), 중심각 \(\Delta\theta\)인 부채꼴이고 넓이는 \(\frac12f(\theta_i^*)^2\Delta\theta\).
    부채꼴 넓이 \(\frac12r^2\theta\) (원 넓이 \(\pi r^2\)의 \(\frac{\theta}{2\pi}\)).
  3. 리만 합의 극한: \(A = \displaystyle\int_\alpha^\beta\frac12f(\theta)^2\,d\theta\).
    \(f\)가 연속이면 적분 가능.

문제. (가) 카디오이드 \(r = 1 + \cos\theta\)가 둘러싼 넓이. (나) 원 \(r = 3\cos\theta\)의 안쪽이면서 카디오이드 \(r = 1 + \cos\theta\)의 바깥쪽인 영역의 넓이.

풀이

  1. (가) 곡선은 \(\theta: 0 \to 2\pi\)에서 한 바퀴 돈다. \(A = \frac12\int_0^{2\pi}(1 + \cos\theta)^2d\theta = \frac12\int_0^{2\pi}\left(1 + 2\cos\theta + \frac{1 + \cos2\theta}{2}\right)d\theta\).
    \(r \ge 0\)이고 한 번만 지나는 범위. 반각 공식.
  2. \(\cos\theta\), \(\cos2\theta\)는 한 주기 적분이 0이므로 \(A = \frac12\cdot\frac32\cdot2\pi = \frac{3\pi}{2}\).
    상수항 \(1 + \frac12 = \frac32\)만 남는다.
  3. (나) 교점: \(3\cos\theta = 1 + \cos\theta \iff \cos\theta = \frac12 \iff \theta = \pm\frac\pi3\).
    극좌표 교점은 같은 \(\theta\)에서 \(r\)이 같은 점만 이 방법으로 나온다. 원점처럼 다른 \(\theta\)에서 지나는 교점은 그림으로 확인.
  4. \(-\frac\pi3 < \theta < \frac\pi3\)에서 \(3\cos\theta > 1 + \cos\theta\) (원이 바깥). \(A = \frac12\int_{-\pi/3}^{\pi/3}\left[(3\cos\theta)^2 - (1 + \cos\theta)^2\right]d\theta\).
    두 곡선 사이 넓이: 바깥 반지름² − 안 반지름².
  5. 괄호 \(= 8\cos^2\theta - 2\cos\theta - 1 = 4\cos2\theta - 2\cos\theta + 3\). 대칭이므로 \(A = \int_0^{\pi/3}(4\cos2\theta - 2\cos\theta + 3)\,d\theta\).
    \(8\cos^2 = 4 + 4\cos2\theta\). 우함수라 \(\frac12\cdot2\int_0\).
  6. \(= \left[2\sin2\theta - 2\sin\theta + 3\theta\right]_0^{\pi/3} = \sqrt3 - \sqrt3 + \pi = \pi\).
    \(\sin\frac{2\pi}{3} = \sin\frac\pi3 = \frac{\sqrt3}2\).

의미

원점 둘레로 도는 모양(카디오이드, 장미, 나선)은 극좌표에서 식이 간단해지고, 넓이도 부채꼴로 썰면 자연스럽게 나옵니다. 영역의 대칭에 맞는 좌표를 고르는 습관이 공통2의 극·원통·구면좌표 적분으로 이어집니다.

검산

원 \(r = 3\cos\theta\)는 중심 \((\frac32, 0)\), 반지름 \(\frac32\)인 원이라 넓이 \(\frac{9\pi}{4} \approx 7.07\). (나)의 답 \(\pi \approx 3.14\)는 그보다 작고, 원과 카디오이드가 겹치는 부분 \(\frac{9\pi}{4} - \pi = \frac{5\pi}{4}\)도 카디오이드 전체 \(\frac{3\pi}{2}\)보다 작습니다. 모순이 없습니다.

흔한 오해

  • 장미 곡선의 구간: \(r = \cos2\theta\)는 \(0 \le \theta \le 2\pi\)에서 잎 4개를 한 번씩 그리지만, \(r = \cos3\theta\)는 \(0 \le \theta \le \pi\)에서 이미 잎 3개를 다 그립니다. \(2\pi\)까지 적분하면 두 번 셉니다. 한 잎의 범위(\(r\)이 0에서 0까지)를 찾아 곱하는 것이 안전합니다.
  • \(\frac12\int(f - g)^2\)로 쓰기: 사이 넓이는 \(\frac12\int(f^2 - g^2)\)입니다.
