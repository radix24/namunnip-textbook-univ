1.4.1

설명지수, 로그, 쌍곡선 함수는 서로 어떻게 이어지는가?

초월함수 · 증가 속도 · 항등식

다루는 성취기준 [공통1-01-04]

왜 필요한가

다항함수만으로는 인구 증가, 방사성 붕괴, 매달린 줄의 모양을 나타낼 수 없습니다. 지수함수는 "변화율이 자기 자신에 비례하는 양", 로그는 그 역, 쌍곡선 함수는 지수함수 두 개의 조합으로, 미분방정식과 물리에서 계속 나옵니다. 이 카드는 세 함수의 정의와 성질을 한곳에 정리합니다.

정의

자연지수함수 \(e^x\): \(e = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \approx 2.71828\)을 밑으로 하는 지수함수. 정의역 \(\mathbb{R}\), 치역 \((0, \infty)\), 순증가.

자연로그 \(\ln x\): \(e^x\)의 역함수. 정의역 \((0, \infty)\), 치역 \(\mathbb{R}\). 곧 \(\ln x = y \iff e^y = x\).

쌍곡선 함수:

\[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x}.\]

정의를 풀어 읽기

  1. 왜 밑이 \(e\)인가모든 지수함수 \(a^x\)의 도함수는 \(a^x\)에 상수 \(\ln a\)를 곱한 것입니다. 이 상수가 1이 되는 밑이 \(e\)입니다. 그래서 \((e^x)' = e^x\)이고, 미적분에서는 \(e\)를 밑으로 쓰면 식이 가장 간단합니다.
  2. 로그의 성질은 지수법칙의 거울\(e^{a+b} = e^a e^b\)를 로그로 옮기면 \(\ln(xy) = \ln x + \ln y\). 같은 방식으로 \(\ln\frac{x}{y} = \ln x - \ln y\), \(\ln x^r = r\ln x\). 밑 바꾸기: \(\log_a x = \frac{\ln x}{\ln a}\).
  3. 쌍곡선이라는 이름\(\cos^2 t + \sin^2 t = 1\)이 원 \(x^2 + y^2 = 1\)을 그리듯, \(\cosh^2 t - \sinh^2 t = 1\)은 쌍곡선 \(x^2 - y^2 = 1\)의 오른쪽 가지를 그립니다.

쌍곡선 항등식 유도

  1. \(\cosh^2 x = \frac{e^{2x} + 2 + e^{-2x}}{4}\), \(\sinh^2 x = \frac{e^{2x} - 2 + e^{-2x}}{4}\).
    정의를 제곱. \(e^x e^{-x} = 1\).
  2. 빼면 \(\cosh^2 x - \sinh^2 x = \frac{4}{4} = 1\).
    \(e^{\pm 2x}\) 항이 지워진다.

삼각함수 항등식과 비교하면 부호 하나가 다릅니다. 이 차이가 \((\cosh x)' = \sinh x\) (삼각함수는 \((\cos x)' = -\sin x\))에도 나타납니다.

그래프와 성질 비교

  1. \(e^x\)\(x \to -\infty\)이면 0에 다가감(수평 점근선 \(y = 0\)), \(x \to \infty\)이면 어떤 다항식보다 빨리 커짐. \(e^0 = 1\).
  2. \(\ln x\)\(x \to 0^+\)이면 \(-\infty\)(수직 점근선 \(x = 0\)), \(x \to \infty\)이면 커지지만 어떤 양의 거듭제곱 \(x^p\)보다 느림. \(\ln 1 = 0\).
  3. \(\cosh x\)짝함수, 최솟값 \(\cosh 0 = 1\). 양쪽 줄을 잡고 늘어뜨린 사슬의 모양(현수선)입니다.
  4. \(\sinh x\)홀함수, 순증가, \(\sinh 0 = 0\). 큰 \(x\)에서 \(\sinh x \approx \cosh x \approx \frac{e^x}{2}\).
  5. \(\tanh x\)홀함수, 치역 \((-1, 1)\), 수평 점근선 \(y = \pm 1\). 신경망의 활성화 함수로도 씁니다.

증가 속도의 순서 (\(x \to \infty\)): \(\ln x \ll x^p \ll e^x\) (\(p > 0\)). 곧 \(\lim \frac{\ln x}{x^p} = 0\), \(\lim\frac{x^p}{e^x} = 0\). 4단원의 로피탈 정리로 증명합니다.

예: 역쌍곡선 사인을 로그로

\(y = \sinh^{-1} x\)를 구합니다. \(x = \frac{e^y - e^{-y}}{2}\)에서 \(u = e^y > 0\)으로 두면 \(u^2 - 2xu - 1 = 0\), 근의 공식으로 \(u = x \pm \sqrt{x^2 + 1}\). \(u > 0\)이어야 하는데 \(x - \sqrt{x^2+1} < 0\)이므로 \(u = x + \sqrt{x^2+1}\). 따라서

\[\sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right).\]

\(\sinh\)는 순증가라 정의역을 자를 필요가 없었습니다. 반면 \(\cosh\)는 짝함수라 \([0, \infty)\)로 잘라야 역함수 \(\cosh^{-1} x = \ln(x + \sqrt{x^2-1})\) \((x \ge 1)\)을 얻습니다.

흔한 오해

  • "\(\ln(x + y) = \ln x + \ln y\)." 로그는 곱을 합으로 바꿉니다. 합의 로그는 간단해지지 않습니다.
  • "\(\cosh x\)도 주기함수다." 아닙니다. 삼각함수와 이름이 닮았을 뿐, 지수함수로 만든 함수라 주기가 없습니다.
