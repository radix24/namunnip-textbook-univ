1.4.1끊어지지 않는다는 것

택시 요금은 거리에 따라 계단처럼 뛰어오르고, 물의 온도는 가열 시간에 따라 매끄럽게 오릅니다. 앞의 것은 어느 순간 값이 갑자기 바뀌고, 뒤의 것은 입력을 조금 바꾸면 출력도 조금만 바뀝니다. 수학에서 연속은 이 두 번째 성질, 곧 "입력의 작은 변화가 출력의 작은 변화만 만든다"를 뜻합니다. 고교에서 배운 "그래프가 끊어지지 않는다"는 이것을 그림으로 본 것입니다.

1.4.2한 점에서의 연속

정의 1.4.1 (연속)

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있고

\[\lim_{x\to a}f(x) = f(a)\]

이면 \(f\)는 \(a\)에서 연속이라 한다. 연속이 아니면 \(a\)를 \(f\)의 불연속점이라 한다.

이 한 줄의 등식 안에 세 가지 조건이 들어 있습니다. 하나라도 어기면 불연속입니다.

  1. \(f(a)\)가 정의되어 있다.
  2. \(\lim_{x\to a}f(x)\)가 존재한다(두 한쪽 극한이 존재하고 같다).
  3. 둘이 같다.

ε-δ로 쓰면 "임의의 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어서 \(|x - a| < \delta \Rightarrow |f(x) - f(a)| < \varepsilon\)"입니다. 극한의 정의와 비교하면 \(L\) 자리에 \(f(a)\)가 들어가고, \(x = a\)를 뺄 필요가 없어졌습니다(\(x = a\)이면 차이가 0이니까요). 2.3.1의 "입력을 \(\delta\) 이내로 바꾸면 출력이 \(\varepsilon\) 이내로만 바뀐다"를 그대로 식으로 쓴 것입니다.

구간의 끝점에서는 한쪽 극한을 씁니다. \(\lim_{x\to a^+}f(x) = f(a)\)이면 오른쪽 연속, \(\lim_{x\to a^-}f(x) = f(a)\)이면 왼쪽 연속입니다. \(f\)가 열린구간 \((a, b)\)의 모든 점에서 연속이면 "\((a, b)\)에서 연속", 여기에 더해 \(a\)에서 오른쪽 연속이고 \(b\)에서 왼쪽 연속이면 "\([a, b]\)에서 연속"이라고 합니다.

1.4.3불연속의 종류

세 조건 가운데 어느 것이 어떻게 깨지는지에 따라 불연속점을 나눕니다.

정의 1.4.2 (제거 가능 불연속)

\(\lim_{x\to a}f(x)\)가 존재하지만 \(f(a)\)와 다르거나 \(f(a)\)가 정의되지 않은 경우.

정의 1.4.3 (도약 불연속)

두 한쪽 극한이 모두 유한한 값으로 존재하지만 서로 다른 경우.

정의 1.4.4 (무한 불연속, 진동 불연속)

한쪽 극한 가운데 적어도 하나가 \(\pm\infty\)로 발산하면 무한 불연속, 진동하여 존재하지 않으면 진동 불연속이라 한다. 둘을 묶어 본질적 불연속이라고도 한다.

이름이 뜻을 말해 줍니다. 제거 가능 불연속은 한 점의 값만 고쳐(\(f(a)\)를 극한값으로 다시 정의해) 연속으로 만들 수 있습니다. 도약 불연속은 어떻게 고쳐도 그래프가 이어지지 않습니다. 본질적 불연속은 그래프가 위아래로 달아나거나 끝없이 흔들립니다.

예제 1.4.5

다음 함수의 불연속점을 찾고 종류를 말하여라.

  • (가) \(f(x) = \frac{x^2 - 1}{x - 1}\)
  • (나) \(g(x) = \frac{|x|}{x}\)
  • (다) \(h(x) = \frac{1}{(x - 2)^2}\)
  • (라) \(k(x) = \sin\frac1x\) (\(x \ne 0\)), \(k(0) = 0\)

풀이. (가) \(x = 1\)에서 정의되지 않습니다. \(x \ne 1\)이면 \(f(x) = x + 1\)이므로 \(\lim_{x\to1}f(x) = 2\)가 존재합니다. 제거 가능 불연속이고, \(f(1) = 2\)로 정의하면 연속인 함수 \(x + 1\)이 됩니다.

(나) \(x > 0\)이면 1, \(x < 0\)이면 \(-1\)이므로 \(x = 0\)에서 오른쪽 극한 1, 왼쪽 극한 \(-1\)입니다. 도약 불연속이고 도약의 크기는 2입니다.

(다) \(x \to 2\)일 때 분모가 0으로 가고 양수이므로 \(h(x) \to +\infty\)입니다. 무한 불연속입니다(3.3절에서 \(x = 2\)는 수직 점근선이라고 부릅니다).

(라) \(x \to 0\)일 때 \(\frac1x\)이 무한히 커지면서 \(\sin\frac1x\)은 \(-1\)과 1 사이를 끝없이 오갑니다. 예를 들어 \(x_n = \frac{1}{2n\pi}\)에서는 0, \(x_n = \frac{1}{2n\pi + \pi/2}\)에서는 1이고, 두 수열 모두 0으로 갑니다. 0에 아무리 가까워도 값 0과 1을 모두 가지므로 극한이 없습니다. 진동 불연속입니다.

1.4.4연속함수를 모으기

어떤 함수가 연속인지 매번 정의로 확인할 필요는 없습니다. 극한 법칙(정리 2.2.1)을 \(L = f(a)\), \(M = g(a)\)로 놓고 읽으면 바로 다음이 나옵니다.

정리 1.4.6

\(f, g\)가 \(a\)에서 연속이면 \(f + g\), \(cf\), \(fg\)도 \(a\)에서 연속이고, \(g(a) \ne 0\)이면 \(\frac fg\)도 \(a\)에서 연속이다.

정리 1.4.7 (합성함수의 연속)

\(g\)가 \(a\)에서 연속이고 \(f\)가 \(g(a)\)에서 연속이면 \(f \circ g\)는 \(a\)에서 연속이다. 곧 \(\lim_{x\to a}f(g(x)) = f\left(\lim_{x\to a}g(x)\right)\).

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(f\)가 \(b = g(a)\)에서 연속이므로 \(|y - b| < \eta\)이면 \(|f(y) - f(b)| < \varepsilon\)인 \(\eta > 0\)이 있다. 이 \(\eta\)를 "허용 오차"로 삼아 \(g\)의 연속을 쓰면 \(|x - a| < \delta\)이면 \(|g(x) - b| < \eta\)인 \(\delta > 0\)이 있다. 그러면 \(|x - a| < \delta\)일 때 \(y = g(x)\)가 \(|y - b| < \eta\)를 만족하므로 \(|f(g(x)) - f(g(a))| < \varepsilon\)이다. ∎

증명의 구조를 눈여겨보세요. 바깥 함수 \(f\)의 요구(\(\varepsilon\))를 먼저 처리해 \(\eta\)를 얻고, 그것을 안쪽 함수 \(g\)에 대한 요구로 넘깁니다. 바깥에서 안으로 거슬러 오는 순서입니다.

이 정리들과 아래의 기본 함수들을 합치면, 식으로 쓴 함수 대부분이 정의된 곳에서 연속임을 알 수 있습니다.

정리 1.4.8 (기본 연속함수)

다음 함수는 정의역의 모든 점에서 연속이다: 다항함수, 유리함수, \(\sqrt[n]{x}\), \(\sin x\), \(\cos x\), \(\tan x\), \(a^x\), \(\log_a x\), 역삼각함수, 쌍곡선 함수.

다항함수와 유리함수는 따름정리 2.2.2에서 이미 보았습니다. \(\sin\)과 \(\cos\)은 2.2.5에서 0에서의 연속을 보였고, 덧셈정리 \(\sin(a + h) = \sin a\cos h + \cos a\sin h\)에서 \(h \to 0\)으로 보내면 모든 점에서 연속입니다. 지수함수의 연속은 \(a^{x+h} = a^xa^h\)에서 \(\lim_{h\to0}a^h = 1\)로 귀결되며 이 사실은 받아들이겠습니다(8.8절에서 급수로 다시 확인합니다). 역함수의 연속은 "연속인 일대일 함수의 역함수는 연속"이라는 정리에서 나옵니다. 이 정리의 증명은 해석학(수학7-03)에서 다룹니다.

예제 1.4.9

\(F(x) = \frac{\ln(1 + x^2)}{\cos x - 2}\)가 실수 전체에서 연속임을 보이고 \(\lim_{x\to0}F(x)\)를 구하여라.

풀이. \(1 + x^2\)은 다항함수라 연속이고 늘 양수이므로 \(\ln\)의 정의역 안에 있어, 합성 \(\ln(1 + x^2)\)이 연속입니다(정리 1.4.7). 분모 \(\cos x - 2\)는 연속이고 \(\cos x \le 1\)이므로 늘 \(-1\) 이하, 곧 0이 아닙니다. 몫이므로 정리 1.4.6에 의해 \(F\)는 모든 점에서 연속입니다. 연속이므로 극한은 대입으로 구합니다: \(F(0) = \frac{\ln 1}{1 - 2} = 0\).

주의"정의역에서 연속"과 "실수 전체에서 연속"은 다릅니다. \(\frac1x\)은 정의역 \(x \ne 0\)의 모든 점에서 연속인 연속함수이지만, \(x = 0\)에서는 정의되지 않으므로 연속도 불연속도 논하지 않는 것이 엄밀한 표현입니다. 다만 많은 교재가 이런 점도 "불연속점"이라고 부르므로, 문제에서 무엇을 묻는지 보고 판단하세요.
요약
  1. \(a\)에서 연속: \(f(a)\)가 정의되고, 극한이 존재하고, 둘이 같다.
  2. 불연속의 종류: 제거 가능(극한은 있으나 값이 다르거나 없음), 도약(한쪽 극한이 다름), 본질적(발산 또는 진동).
  3. 연속함수의 합·상수배·곱·몫(분모 ≠ 0)·합성은 연속이다.
  4. 식으로 주어진 기본 함수는 정의역에서 연속이다. 연속이면 극한은 대입으로 구한다.

1.4.5연습문제

기본

  1. 불연속점과 종류를 말하여라. (가) \(\frac{x^2 - 9}{x + 3}\) (나) \(\frac{x}{x^2 - 4}\) (다) \(\lfloor x\rfloor\) (\(x\)를 넘지 않는 최대 정수)
    답

    (가) \(x = -3\) 제거 가능(극한 \(-6\)) (나) \(x = \pm2\) 무한 불연속 (다) 모든 정수에서 도약 불연속(도약 크기 1)

  2. \(f(x) = x^2\) (\(x < 1\)), \(f(x) = ax + 3\) (\(x \ge 1\))이 연속이 되도록 \(a\)를 정하여라.
    답

    왼쪽 극한 1, \(f(1) = a + 3\). \(a = -2\).

  3. \(\lim_{x\to\pi}\sin(x + \sin x)\)를 구하여라.
    답

    합성함수가 연속이므로 대입: \(\sin(\pi + 0) = 0\).

응용

  1. \(f(x) = \frac{\sin x}{x}\) (\(x \ne 0\))을 실수 전체에서 연속인 함수로 만들려면 \(f(0)\)을 얼마로 정해야 하는가? 이유를 정리 번호와 함께 말하여라.
    답

    정리 2.2.6에서 극한이 1이므로 \(f(0) = 1\). 그러면 0에서 정의 1.4.1을 만족하고, \(x \ne 0\)에서는 연속함수의 몫(정리 1.4.6)이라 연속이다.

  2. \(f\)가 \(a\)에서 연속이고 \(f(a) > 0\)이면 \(a\)를 포함하는 어떤 구간에서 \(f(x) > 0\)임을 보여라.
    힌트

    정의에서 \(\varepsilon = \frac{f(a)}{2}\)로 잡으세요.

    답

    \(\varepsilon = \frac{f(a)}2\)에 대한 \(\delta\)를 잡으면 \(|x - a| < \delta\)에서 \(f(x) > f(a) - \frac{f(a)}{2} = \frac{f(a)}2 > 0\).

심화

  1. 유리수에서 1, 무리수에서 0인 함수(Dirichlet 함수)는 모든 점에서 불연속임을 보여라. 한편 \(x \cdot (\text{이 함수})\)는 0에서만 연속임을 보여라.
    힌트

    어떤 구간에도 유리수와 무리수가 모두 있다는 사실을 쓰세요. 둘째는 \(|x\cdot D(x)| \le |x|\).

    답

    \(\varepsilon = \frac12\)이면 어떤 \(\delta\)에도 \((a - \delta, a + \delta)\)에 값이 0인 점과 1인 점이 모두 있어 둘 중 하나는 \(f(a)\)와 \(\frac12\) 이상 차이 난다. 둘째 함수는 \(|xD(x)| \le |x| \to 0\)이라 0에서 연속. \(a \ne 0\)이면 근처에 값이 0인 점과 \(\approx a\)인 점이 모두 있어 불연속.

1.4.6근이 있다는 것을 어떻게 아는가

방정식 \(x^5 - 3x + 1 = 0\)은 근의 공식이 없습니다(5차 이상의 방정식은 일반적인 근의 공식이 없다는 것이 증명되어 있습니다). 그래도 \([0, 1]\)에 근이 있다는 것은 확신할 수 있습니다. \(f(x) = x^5 - 3x + 1\)로 놓으면 \(f(0) = 1 > 0\)이고 \(f(1) = -1 < 0\)입니다. 그래프가 끊어지지 않고 0 위에서 0 아래로 내려갔으니 그 사이 어디선가 \(x\)축을 지났을 것입니다. 이 직관을 정리로 만든 것이 중간값 정리이고, 그 증명에 1.1절의 완비성이 필요합니다.

1.4.7중간값 정리

정리 1.4.10 (중간값 정리)

\(f\)가 닫힌구간 \([a, b]\)에서 연속이고 \(N\)이 \(f(a)\)와 \(f(b)\) 사이의 수이면, \(f(c) = N\)인 \(c \in [a, b]\)가 적어도 하나 있다.

특히 \(f(a)\)와 \(f(b)\)의 부호가 다르면 \(N = 0\)으로 놓아 \(f(c) = 0\)인 \(c\), 곧 근이 있습니다. 이것을 따로 근의 존재 정리(Bolzano 정리)라고 부르기도 합니다.

증명.\(f(a) < N < f(b)\)인 경우를 보이면 충분하다(반대 경우는 \(-f\)에 적용한다). 집합 \(S = \{x \in [a, b] \mid f(x) < N\}\)을 생각하자. \(a \in S\)이므로 공집합이 아니고, \(b\)가 상계이므로 완비성 공리(공리 1.1.5)에 의해 상한 \(c = \sup S\)가 있으며 \(a \le c \le b\)이다. \(f(c) = N\)임을 보이기 위해 다른 두 경우를 배제한다.

\(f(c) < N\)이라 하자. 그러면 \(c \ne b\)이고, \(f\)가 \(c\)에서 연속이므로 \(c\)의 오른쪽 가까이에서도 \(f(x) < N\)이다(1.4절 연습문제 5의 방법). 곧 \(c\)보다 큰 \(S\)의 원소가 있어 \(c\)가 상계라는 데 모순이다.

\(f(c) > N\)이라 하자. 그러면 \(c \ne a\)이고, 연속성에서 어떤 \(\delta > 0\)에 대해 \((c - \delta, c]\)의 모든 점에서 \(f(x) > N\)이다. 이 구간의 점은 \(S\)에 속하지 않으므로 \(c - \delta\)도 \(S\)의 상계가 되어, \(c\)가 가장 작은 상계라는 데 모순이다.

따라서 \(f(c) = N\)이다. ∎

증명에서 완비성이 쓰인 곳은 "\(\sup S\)가 있다" 한 곳입니다. 1.1절의 유리수 세계에서는 이 정리가 깨집니다. 유리수에서만 정의된 \(f(x) = x^2 - 2\)는 \(f(1) = -1\), \(f(2) = 2\)이지만 근 \(\sqrt2\)가 유리수가 아니라서 \(f(c) = 0\)인 유리수 \(c\)는 없습니다.

예제 1.4.11

\(x^5 - 3x + 1 = 0\)이 \([0, 1]\)에 근을 가짐을 보이고, 이분법으로 근을 소수 둘째 자리까지 구하여라.

풀이. \(f(x) = x^5 - 3x + 1\)은 다항함수라 연속이고 \(f(0) = 1\), \(f(1) = -1\)로 부호가 다르므로 중간값 정리에 의해 \([0, 1]\)에 근이 있습니다.

정리는 근이 "있다"고만 말하지 어디 있는지는 말하지 않습니다. 그러나 같은 정리를 되풀이하면 근의 위치를 좁힐 수 있습니다. 구간의 중점에서 부호를 보고, 부호가 바뀌는 쪽 반을 남기는 것이 이분법입니다.

구간중점 \(m\)\(f(m)\)남기는 구간
\([0, 1]\)0.5\(-0.469\)\([0, 0.5]\)
\([0, 0.5]\)0.25\(0.251\)\([0.25, 0.5]\)
\([0.25, 0.5]\)0.375\(-0.118\)\([0.25, 0.375]\)
\([0.25, 0.375]\)0.3125\(0.065\)\([0.3125, 0.375]\)
\([0.3125, 0.375]\)0.34375\(-0.027\)\([0.3125, 0.34375]\)
\([0.3125, 0.34375]\)0.328125\(0.019\)\([0.328125, 0.34375]\)

일곱 번 만에 근이 \([0.3281, 0.3359]\)에 있음을 알았고, 따라서 근은 약 0.33입니다. 한 번 할 때마다 구간의 폭이 절반이 되므로 \(n\)번 뒤 폭은 \(\frac{1}{2^n}\)입니다. 소수 여섯째 자리까지 원하면 \(2^n > 10^6\), 곧 \(n = 20\)번이면 됩니다. 단순하지만 반드시 수렴하는 방법이어서 계산기와 컴퓨터가 실제로 씁니다(공통10-06-02에서 코드로 구현합니다). 더 빠른 방법은 2.5절의 Newton 방법입니다.

예제 1.4.12

방정식 \(\cos x = x\)가 실수해를 가짐을 보여라.

풀이. 근을 찾는 문제는 한쪽으로 모아 함수의 영점 문제로 바꿉니다. \(g(x) = \cos x - x\)로 놓으면 연속함수의 차라서 연속이고, \(g(0) = 1 > 0\), \(g\left(\frac\pi2\right) = -\frac\pi2 < 0\)입니다. 중간값 정리에 의해 \(\left(0, \frac\pi2\right)\)에 \(g(c) = 0\), 곧 \(\cos c = c\)인 \(c\)가 있습니다. (실제 값은 약 0.739입니다.)

1.4.8최대·최소 정리

연속함수의 또 하나의 기본 성질은 닫힌구간에서 가장 큰 값과 가장 작은 값을 실제로 갖는다는 것입니다. 3.1절의 최적화 문제는 모두 이 정리를 바탕으로 합니다. 답이 존재한다는 것을 먼저 알아야 그것을 찾는 의미가 있으니까요.

정리 1.4.13 (최대·최소 정리)

\(f\)가 닫힌구간 \([a, b]\)에서 연속이면, \(f\)는 \([a, b]\)에서 최댓값과 최솟값을 갖는다. 곧 모든 \(x \in [a, b]\)에 대해 \(f(c) \le f(x) \le f(d)\)인 \(c, d \in [a, b]\)가 있다.

이 정리의 증명은 중간값 정리보다 조금 길고 완비성을 두 번 써야 해서 해석학(수학7-03)으로 미룹니다. 대신 가정이 하나라도 빠지면 결론이 깨진다는 것을 확인해 둡시다. 정리를 쓸 때 가정을 확인하는 습관이 여기서 생깁니다.

  • 구간이 닫혀 있지 않으면: \(f(x) = x\)는 \((0, 1)\)에서 연속이지만 최댓값이 없습니다. 상한 1에 한없이 다가가지만 1에 도달하지 않습니다(1.1절의 상한과 최댓값의 차이 그대로입니다).
  • 구간이 유계가 아니면: \(f(x) = x\)는 \([0, \infty)\)에서 최댓값이 없습니다.
  • 연속이 아니면: \(f(x) = \frac1x\) (\(x \ne 0\)), \(f(0) = 0\)은 \([-1, 1]\)에서 위로도 아래로도 유계가 아니어서 최댓값도 최솟값도 없습니다.

반대로 가정은 충분조건일 뿐 필요조건은 아닙니다. 불연속인 함수도 최댓값을 가질 수 있습니다. 정리는 "가정을 만족하면 반드시 있다"고 말할 뿐입니다.

주의중간값 정리를 쓸 때 연속성을 확인하지 않는 실수가 흔합니다. \(f(x) = \frac1x\)은 \(f(-1) = -1 < 0 < 1 = f(1)\)이지만 \([-1, 1]\)에서 \(f(c) = 0\)인 점이 없습니다. \(x = 0\)에서 연속이 아니기 때문입니다. 답안에는 "\(f\)는 \([a, b]\)에서 연속이고"를 반드시 근거와 함께 쓰세요.
요약
  1. 중간값 정리: \([a, b]\)에서 연속이면 \(f(a)\)와 \(f(b)\) 사이의 모든 값을 갖는다. 증명에 완비성을 쓴다.
  2. 부호가 다른 두 점 사이에 연속함수의 근이 있다. 이분법은 이를 되풀이해 근을 좁힌다(\(n\)번에 폭 \(\frac{1}{2^n}\)).
  3. 최대·최소 정리: 닫힌 유계 구간에서 연속이면 최댓값과 최솟값을 갖는다.
  4. 두 정리 모두 가정(닫힌구간, 연속)이 빠지면 결론이 깨지는 반례가 있다.

1.4.9연습문제

기본

  1. \(x^3 + x - 1 = 0\)이 \((0, 1)\)에 근을 가짐을 보여라.
    답

    다항함수라 연속, \(f(0) = -1 < 0\), \(f(1) = 1 > 0\). 중간값 정리.

  2. \(e^x = 3 - x\)가 실수해를 가짐을 보여라.
    답

    \(g(x) = e^x + x - 3\)은 연속, \(g(0) = -2\), \(g(1) = e - 2 > 0\). \((0, 1)\)에 근이 있다.

  3. 이분법으로 근을 오차 0.001 이내로 구하려면 폭 1인 구간에서 몇 번 나누어야 하는가?
    답

    폭 \(\frac{1}{2^n} < 0.001\)이면 \(2^n > 1000\), \(n = 10\) (\(2^{10} = 1024\)). 중점을 답으로 하면 오차가 폭의 절반이라 9번으로도 된다.

응용

  1. 홀수 차수 다항식은 적어도 하나의 실근을 가짐을 보여라.
    힌트

    \(p(x) = x^n + \cdots\) (\(n\) 홀수)는 \(x\)가 큰 양수이면 양수, 큰 음수이면 음수입니다. 최고차항이 나머지를 이기는 이유를 \(p(x) = x^n(1 + \frac{a_{n-1}}{x} + \cdots)\)로 설명하세요.

    답

    괄호 안은 \(|x| \to \infty\)일 때 1로 가므로 충분히 큰 \(R\)에서 양수다. \(p(R) > 0\), \(p(-R) = (-R)^n\cdot(\text{양수}) < 0\). \([-R, R]\)에서 중간값 정리.

  2. 아침 6시에 산 아래에서 출발해 저녁 6시에 정상에 도착했고, 다음 날 아침 6시에 정상에서 출발해 같은 길로 저녁 6시에 산 아래에 도착했다. 두 날 같은 시각에 같은 지점에 있었던 때가 있음을 보여라.
    힌트

    첫날 위치 \(u(t)\), 둘째 날 위치 \(d(t)\)(산 아래에서 잰 거리)로 놓고 \(u(t) - d(t)\)를 보세요.

    답

    \(h(t) = u(t) - d(t)\)는 연속(걷는 위치는 연속), \(h(6시) = 0 - L < 0\), \(h(18시) = L - 0 > 0\) (\(L\)은 길의 길이). 중간값 정리로 \(h(c) = 0\)인 시각 \(c\)가 있다.

심화

  1. \(f\)가 \([0, 1]\)에서 연속이고 \(0 \le f(x) \le 1\)이면 \(f(c) = c\)인 \(c\)(고정점)가 있음을 보여라.
    답

    \(g(x) = f(x) - x\)는 연속, \(g(0) = f(0) \ge 0\), \(g(1) = f(1) - 1 \le 0\). 등호이면 끝점이 고정점이고, 아니면 중간값 정리로 \((0, 1)\)에 \(g(c) = 0\)이 있다.

1.4.3

설명연속이란 무엇이고, 끊어지는 방식은 몇 가지인가?

연속 · 불연속의 분류

다루는 성취기준 [공통1-01-04]

왜 필요한가

"그래프를 펜을 떼지 않고 그릴 수 있다"는 연속의 직관입니다. 그러나 \(x\sin\frac{1}{x}\)처럼 0 근처에서 끝없이 출렁이는 그래프는 펜으로 그릴 수조차 없는데, 0에서 연속인지 판단해야 합니다. 또 중간값 정리, 최대·최소 정리 같은 중요한 정리들은 모두 "연속이면"을 가정합니다. 가정을 확인하려면 연속을 극한으로 정확히 정의해야 합니다.

정의 · 한 점에서의 연속

\(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있고 \(\lim_{x\to a} f(x) = f(a)\)이면, \(f\)는 \(a\)에서 연속이다.

ε-δ로 쓰면: 임의의 \(\varepsilon>0\)에 대해 어떤 \(\delta>0\)가 있어서 \(|x - a| < \delta \Rightarrow |f(x) - f(a)| < \varepsilon\).

정의를 풀어 읽기

  1. 세 조건이 숨어 있다① \(f(a)\)가 정의되어 있다. ② \(\lim_{x\to a} f(x)\)가 존재한다. ③ 둘이 같다. 셋 중 하나라도 깨지면 불연속입니다.
  2. 극한과 달리 \(0<\)이 없다극한의 정의는 \(0 < |x-a|\)로 \(x=a\)를 뺐지만, 연속에서는 \(x=a\)일 때 \(|f(a)-f(a)| = 0 < \varepsilon\)이 저절로 성립하므로 빼든 안 빼든 같습니다.
  3. "구간에서 연속"구간의 모든 점에서 연속이라는 뜻입니다. 닫힌구간 \([a,b]\)의 끝점에서는 한쪽 극한(\(x\to a^+\), \(x \to b^-\))으로 판정합니다.

불연속의 세 종류

  1. 제거 가능한 불연속\(\lim_{x\to a} f(x)\)는 존재하지만 \(f(a)\)와 다르거나 \(f(a)\)가 없음. 한 점의 값만 고치면 연속이 됩니다. 예: \(f(x) = \frac{x^2-1}{x-1}\)은 \(x=1\)에서 정의되지 않지만 극한은 2. \(f(1)=2\)로 정하면 연속.
  2. 도약 불연속왼쪽 극한과 오른쪽 극한이 각각 존재하지만 서로 다름. 예: 바닥 함수 \(\lfloor x \rfloor\)는 정수 \(n\)에서 왼쪽 극한 \(n-1\), 오른쪽 극한 \(n\). 한 점의 값을 고쳐서는 이을 수 없습니다.
  3. 본질적 불연속한쪽 극한 중 적어도 하나가 존재하지 않음(무한대로 가거나 진동). 예: \(\frac{1}{x}\)는 0에서 양쪽으로 무한대로 발산, \(\sin\frac{1}{x}\)는 0 근처에서 \(-1\)과 1 사이를 끝없이 진동.

분류 순서: 먼저 양쪽 극한을 각각 구합니다. 둘 다 있고 같으면 제거 가능(또는 연속), 둘 다 있고 다르면 도약, 하나라도 없으면 본질적입니다.

예와 반례

연속인 예. 다항함수, \(\sin\), \(\cos\), \(e^x\)는 실수 전체에서 연속입니다. 유리함수는 분모가 0이 아닌 모든 점에서 연속입니다.

뜻밖에 연속인 예. \(f(x) = x\sin\frac{1}{x}\ (x\ne0)\), \(f(0)=0\). 앞의 압축 정리 카드에서 \(\lim_{x\to0} x\sin\frac1x = 0\)을 보였으므로 0에서 연속입니다. 그래프를 펜으로 그릴 수는 없지만 정의는 만족합니다.

모든 점에서 불연속인 예. 디리클레 함수 \(D(x) = 1\) (\(x\) 유리수), \(0\) (\(x\) 무리수). 어느 점 근처에도 유리수와 무리수가 모두 있으므로 어디서도 극한이 없습니다.

다른 개념과의 관계

  • 연속 함수의 합·곱·몫·합성은 연속입니다(몫은 분모 ≠ 0). 극한 법칙에서 바로 나옵니다.
  • 미분 가능하면 연속이지만 거꾸로는 아닙니다. \(|x|\)는 0에서 연속이지만 미분 불가능합니다.
  • 해석학에서는 "모든 점에서 같은 δ를 쓸 수 있는가"를 묻는 균등연속으로 이어집니다.

흔한 오해

  • "\(\frac{1}{x}\)은 불연속 함수다." \(\frac{1}{x}\)의 정의역은 \(x \ne 0\)이고, 정의역의 모든 점에서 연속입니다. "0에서 불연속"이라고 할 때는 0이 정의역 밖이라는 점에 주의해야 합니다. 교재에 따라 이 경우를 불연속이라 부르지 않기도 합니다.
  • "그래프에 구멍이 없으면 연속." 구멍은 눈에 안 보일 수 있습니다(디리클레 함수). 정의로 확인해야 합니다.

\(f(x) = \dfrac{|x|}{x}\ (x \ne 0)\), \(f(0) = 0\)은 \(x = 0\)에서 어떤 불연속인가?

1.4.4

증명중간값 정리: 이분법으로 근을 붙잡는다

연속 · 실수의 완비성

다루는 성취기준 [공통1-01-04]

정리 · 중간값 정리 (근의 존재 형태)

\(f\)가 닫힌구간 \([a, b]\)에서 연속이고 \(f(a) < 0 < f(b)\)이면, \(f(c) = 0\)인 \(c \in (a, b)\)가 존재한다.

일반형 "\(f(a)\)와 \(f(b)\) 사이의 모든 값 \(k\)에 대해 \(f(c)=k\)인 \(c\)가 있다"는 \(f(x) - k\)에 이 정리를 쓰면 됩니다.

쓰는 것

  • 실수의 완비성 (축소구간 성질): 닫힌구간이 \([a_1,b_1] \supset [a_2,b_2] \supset \cdots\)처럼 줄어들고 길이 \(b_n - a_n \to 0\)이면, 모든 구간에 공통으로 들어 있는 실수 \(c\)가 정확히 하나 있고 \(a_n \to c\), \(b_n \to c\)이다. 유리수에서는 성립하지 않는 실수만의 성질이다(예: \(\sqrt{2}\)로 줄어드는 유리수 구간).
  • 연속의 수열 성질: \(f\)가 \(c\)에서 연속이고 \(x_n \to c\)이면 \(f(x_n) \to f(c)\).
  • 극한과 부등식: 모든 \(n\)에서 \(u_n \le 0\)이고 \(u_n \to u\)이면 \(u \le 0\).

아이디어

구간을 반으로 자르고, 부호가 바뀌는 쪽 절반을 남깁니다. 이 일을 끝없이 되풀이하면 구간이 한 점 \(c\)로 줄어듭니다. 남긴 구간들은 늘 "왼쪽 끝에서 음수, 오른쪽 끝에서 양수"이므로, 극한을 취하면 \(f(c) \le 0\)이면서 \(f(c) \ge 0\)이 되어 \(f(c) = 0\)입니다. 이 증명은 근을 실제로 계산하는 이분법 알고리즘과 같습니다.

그림만으로는 "곡선이 축을 건너려면 한 번은 만나야 한다"가 당연해 보입니다. 그러나 수직선에 \(\sqrt{2}\) 같은 구멍이 있다면(유리수만 있다면) 곡선이 구멍으로 빠져나갈 수 있습니다. 그 구멍이 없다는 보증이 완비성이고, 이 증명의 핵심입니다.

증명

  1. \(a_1 = a\), \(b_1 = b\)로 둔다. \(f(a_1) < 0 < f(b_1)\)이다.
    가정.
  2. \([a_n, b_n]\)이 \(f(a_n) \le 0 \le f(b_n)\)을 만족한다고 하자. 가운데 \(m_n = \frac{a_n + b_n}{2}\)에서 \(f(m_n) = 0\)이면 \(c = m_n\)으로 끝난다. \(f(m_n) < 0\)이면 \([a_{n+1}, b_{n+1}] = [m_n, b_n]\), \(f(m_n) > 0\)이면 \([a_n, m_n]\)으로 정한다.
    세 경우가 모든 가능성을 나눈다. 어느 쪽을 골라도 새 구간은 \(f(a_{n+1}) \le 0 \le f(b_{n+1})\)을 만족한다.
  3. 이렇게 만든 구간들은 \([a_1,b_1] \supset [a_2,b_2] \supset \cdots\)이고 길이는 \(b_n - a_n = \frac{b-a}{2^{n-1}} \to 0\)이다.
    매번 반을 고르므로 포함 관계가 성립하고 길이가 절반씩 준다.
  4. 축소구간 성질로, 모든 구간에 들어 있는 \(c\)가 있고 \(a_n \to c\), \(b_n \to c\)이다. \(a \le c \le b\)이다.
    실수의 완비성. 여기가 실수여야 하는 유일한 곳이다.
  5. \(f\)는 \(c\)에서 연속이므로 \(f(a_n) \to f(c)\)이고 \(f(b_n) \to f(c)\)이다.
    연속의 수열 성질. \(c\)가 끝점이면 한쪽 연속으로 충분하다.
  6. 모든 \(n\)에서 \(f(a_n) \le 0\)이므로 \(f(c) \le 0\), 모든 \(n\)에서 \(f(b_n) \ge 0\)이므로 \(f(c) \ge 0\)이다.
    극한은 부등식(≤, ≥)을 보존한다. 엄격한 부등식(<)은 보존되지 않으므로 2단계에서 ≤로 적었다.
  7. 따라서 \(f(c) = 0\). \(f(a) < 0\), \(f(b) > 0\)이므로 \(c \ne a, b\), 곧 \(c \in (a,b)\)이다.
    6단계의 두 부등식, 그리고 가정의 엄격한 부등식.

되짚기

  • 연속을 쓴 곳: 5단계 하나뿐입니다. 연속이 아니면 깨집니다. 예: \(f(x) = -1\ (x < 0)\), \(f(x) = 1\ (x \ge 0)\)은 \([-1, 1]\)에서 부호가 바뀌지만 0이 되는 점이 없습니다.
  • 완비성을 쓴 곳: 4단계. 유리수에서 \(f(x) = x^2 - 2\)는 \([1, 2]\)에서 부호가 바뀌지만 유리수 근이 없습니다.
  • 닫힌구간: 끝점에서의 값 \(f(a), f(b)\)를 써야 하므로 끝점에서 정의되고 연속이어야 합니다.

쓰는 법 (성취기준 [공통1-01-04])

\(x^5 - 3x + 1 = 0\)이 \((0, 1)\)에서 실근을 가짐을 보이세요.

  1. \(f(x) = x^5 - 3x + 1\)은 다항함수이므로 \([0, 1]\)에서 연속이다.
    다항함수는 실수 전체에서 연속. 연속이라는 가정을 반드시 먼저 확인해서 적는다.
  2. \(f(0) = 1 > 0\), \(f(1) = 1 - 3 + 1 = -1 < 0\).
    부호가 다른 두 점. 정리의 부호 방향은 \(-f\)를 쓰면 바뀌므로 상관없다.
  3. 중간값 정리에 의해 \(f(c) = 0\)인 \(c \in (0, 1)\)이 존재한다.
    정리의 이름을 적고 결론을 쓴다. 근의 값은 모르지만 존재는 보장된다. 값이 필요하면 이분법으로 원하는 만큼 좁힌다: \(f(0.5) \approx -0.47\)이므로 근은 \((0, 0.5)\)에 있다.
