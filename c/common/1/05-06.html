5.6.1

실습직선 대신 포물선으로 이으면 얼마나 정확해질까?

실습 · 사다리꼴 공식과 심프슨 공식

다루는 성취기준 [공통1-05-06]

목표

원시함수를 구할 수 없거나 측정값만 있을 때는 정적분을 수치로 어림합니다. 이웃한 두 점을 직선으로 잇는 사다리꼴 공식과, 세 점을 포물선으로 잇는 심프슨 공식의 오차를 비교합니다. 성취기준 [공통1-05-06].

준비

구간을 \(n\)등분(\(n\)은 짝수)하고 폭을 \(h = (b - a)/n\)이라 합니다.

  • 사다리꼴 공식: \(T_n = \dfrac{h}{2}\left[f(x_0) + 2f(x_1) + \cdots + 2f(x_{n-1}) + f(x_n)\right]\). 그림의 연보라 사다리꼴입니다.
  • 심프슨 공식: \(S_n = \dfrac{h}{3}\left[f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 4f(x_{n-1}) + f(x_n)\right]\). 두 칸마다 세 점을 지나는 포물선(주황 점선) 아래 넓이를 더한 것입니다.

절차

  1. \(\sin x\), \([0, \pi]\)에서 \(n = 2, 4, 8\)일 때 두 공식의 값과 오차를 기록합니다.
  2. 출력의 "n을 두 배로 하면 몇 분의 1"을 두 공식에 대해 비교합니다.
  3. \(1/(1 + x^2)\)로 바꿔 심프슨 값의 4배가 \(\pi\)에 얼마나 빨리 다가가는지 봅니다.
  4. \(\sqrt x\)로 바꿔 같은 비율을 기록합니다.

기대 결과

  • \(\sin x\), \(n = 4\): \(T_4 = 1.89611890\)(오차 \(-1.04\times10^{-1}\)), \(S_4 = 2.00455975\)(오차 \(4.56\times10^{-3}\)). 같은 다섯 점을 쓰는데 심프슨 공식이 20배 이상 정확합니다.
  • \(n\)을 두 배로 하면 사다리꼴의 오차는 약 4분의 1, 심프슨의 오차는 약 16분의 1이 됩니다. 사다리꼴의 오차는 \(h^2\)에, 심프슨의 오차는 \(h^4\)에 비례하기 때문입니다.
  • \(\sqrt x\)에서는 두 공식 모두 약 2.8분의 1밖에 줄지 않습니다. \(\sqrt x\)는 \(x = 0\)에서 기울기가 무한대라 오차 공식의 가정(도함수가 유계)이 깨집니다.

분석

  1. 심프슨 공식이 3차 다항식까지는 정확한 값을 준다는 사실을 \(\int_0^2 x^3\,dx\), \(n = 2\)로 손으로 확인해 보세요.
  2. 심프슨 값은 가운데 리만 합 \(M\)과 사다리꼴 값 \(T\)로 \(S_{2m} = \dfrac{2M_m + T_m}{3}\)이라 쓸 수 있습니다. 4.1절 리만 합 실습에서 본 두 오차의 부호와 크기를 떠올려, 왜 오차가 서로 지워지는지 설명해 보세요. (4.1절)

더 해 보기

파이썬에서는 scipy.integrate.simpson이 같은 계산을 합니다. 전자계산(공통10 6.2절)에서 사다리꼴 공식을 직접 짜 보고 이 카드의 숫자와 비교해 보세요.
