4.2.1미분과 적분을 잇는 다리

미분은 접선의 기울기 문제에서, 적분은 넓이 문제에서 따로 출발했습니다. 두 문제는 전혀 달라 보이지만, 뉴턴과 라이프니츠는 이 둘이 서로 거꾸로 된 계산이라는 것을 알아냈습니다. 이 사실이 미적분의 기본정리이고, 덕분에 리만 합의 극한을 직접 계산하지 않고 부정적분으로 정적분을 구할 수 있습니다.

4.2.2기본정리 1: 넓이 함수의 도함수

\(f\)가 연속일 때 \(g(x) = \int_a^x f(t)\,dt\)는 "\(a\)부터 \(x\)까지의 넓이"입니다. \(x\)를 조금(\(h\)만큼) 늘리면 넓이는 폭 \(h\), 높이 약 \(f(x)\)인 띠만큼 늘어납니다. 그래서 \(g(x + h) - g(x) \approx f(x)\,h\)이고, \(h\)로 나누어 극한을 취하면 \(g'(x) = f(x)\)입니다.

정리 4.2.1 (미적분의 기본정리 1)

\(f\)가 \([a, b]\)에서 연속이면 \(g(x) = \int_a^x f(t)\,dt\)는 미분 가능하고 \(g'(x) = f(x)\)이다.

예제 4.2.2

(가) \(\dfrac{d}{dx}\int_0^x\sqrt{1 + t^2}\,dt\) (나) \(\dfrac{d}{dx}\int_1^{x^2}\cos t\,dt\)

풀이. (가) 정리 그대로 \(\sqrt{1 + x^2}\). 적분을 계산할 필요가 없습니다.

(나) 위끝이 \(x^2\)이므로 연쇄법칙을 씁니다. \(u = x^2\), \(G(u) = \int_1^u\cos t\,dt\)로 놓으면 \(\dfrac{d}{dx}G(x^2) = \cos(u)\cdot\dfrac{du}{dx} = 2x\cos(x^2)\).

일반적으로 \(\dfrac{d}{dx}\int_a^{h(x)}f(t)\,dt = f(h(x))\,h'(x)\)입니다. 위끝을 넣고, 위끝의 도함수를 곱합니다.

4.2.3기본정리 2: 정적분의 계산

정리 4.2.3 (미적분의 기본정리 2)

\(f\)가 \([a, b]\)에서 연속이고 \(F' = f\)이면 \(\displaystyle\int_a^b f(x)\,dx = F(b) - F(a)\)이다.

이유는 짧습니다. 기본정리 1의 \(g\)도 \(g' = f\)이므로 \(F\)와 \(g\)는 도함수가 같고, 3.2절의 정리에 의해 \(F = g + C\)입니다. 따라서 \(F(b) - F(a) = g(b) - g(a) = \int_a^b f\,dx - 0\).

\(F' = f\)인 \(F\)를 \(f\)의 부정적분(역도함수)이라 하고 \(\int f(x)\,dx = F(x) + C\)로 씁니다. 지금까지 배운 미분 공식을 거꾸로 읽으면 부정적분 표가 됩니다.

\(f(x)\)\(\int f(x)\,dx\)\(f(x)\)\(\int f(x)\,dx\)
\(x^n\) (\(n \ne -1\))\(\frac{x^{n+1}}{n+1}\)\(\frac1x\)\(\ln|x|\)
\(e^x\)\(e^x\)\(a^x\)\(\frac{a^x}{\ln a}\)
\(\sin x\)\(-\cos x\)\(\cos x\)\(\sin x\)
\(\sec^2 x\)\(\tan x\)\(\frac{1}{1 + x^2}\)\(\arctan x\)
\(\frac{1}{\sqrt{1 - x^2}}\)\(\arcsin x\)\(\cosh x\)\(\sinh x\)

(모두 \(+C\)를 붙입니다.)

예제 4.2.4

(가) \(\int_0^1 x^2\,dx\) (나) \(\int_1^e\frac1x\,dx\) (다) \(\int_0^1\frac{dx}{1 + x^2}\)

풀이. (가) \(\left[\frac{x^3}{3}\right]_0^1 = \frac13\). 4.1절에서 리만 합의 극한으로 힘들게 구한 값과 같습니다. (나) \([\ln x]_1^e = 1\). (다) \([\arctan x]_0^1 = \frac\pi4\).

(다)의 결과를 거꾸로 쓰면 \(\pi = 4\int_0^1\frac{dx}{1 + x^2}\)입니다. 넓이를 수치로 어림하면 \(\pi\)를 계산할 수 있다는 뜻이고, 실제로 컴퓨터가 \(\pi\)를 구하는 방법 가운데 하나가 이것과 관련 있습니다(8.7절의 급수).

주의기본정리 2는 \(f\)가 구간에서 연속일 때만 씁니다. \(\int_{-1}^1\frac{1}{x^2}dx\)를 \(\left[-\frac1x\right]_{-1}^1 = -2\)로 계산하면 틀립니다. \(x = 0\)에서 불연속이라 이 적분은 5.5절의 이상적분이고, 실제로는 발산합니다. 양수 함수의 적분이 음수가 나온 것이 이상하다는 신호입니다.
요약
  1. 기본정리 1: \(\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\). 위끝이 \(h(x)\)이면 \(f(h(x))h'(x)\).
  2. 기본정리 2: \(\int_a^b f\,dx = F(b) - F(a)\) (\(F' = f\), \(f\)는 연속).
  3. 미분 공식을 거꾸로 읽으면 부정적분 공식이다.

4.2.4연습문제

기본

  1. \(\dfrac{d}{dx}\int_2^x e^{t^2}dt\)와 \(\dfrac{d}{dx}\int_0^{\sin x}\sqrt{1 - t^2}\,dt\)를 구하여라.
    답

    \(e^{x^2}\). \(\sqrt{1 - \sin^2x}\cos x = |\cos x|\cos x\) (\(\cos x \ge 0\)이면 \(\cos^2 x\)).

  2. 계산하여라. (가) \(\int_0^\pi\sin x\,dx\) (나) \(\int_1^4\sqrt x\,dx\) (다) \(\int_0^{1/2}\frac{dx}{\sqrt{1 - x^2}}\)
    답

    (가) 2 (나) \(\frac23(8 - 1) = \frac{14}{3}\) (다) \(\arcsin\frac12 = \frac\pi6\)

응용

  1. \(\dfrac{d}{dx}\int_x^{x^2}\frac{dt}{t}\)를 두 가지 방법으로 구하여라.
    답

    기본정리: \(\frac{1}{x^2}\cdot2x - \frac1x = \frac1x\). 직접: \(\ln x^2 - \ln x = \ln x\), 미분하면 \(\frac1x\).

4.2.2

증명미적분의 기본정리: 미분과 적분은 서로 거꾸로

적분 상한 함수 · FTC 1, 2

다루는 성취기준 [공통1-04-02]

정리 · 미적분의 기본정리

(1) \(f\)가 \([a,b]\)에서 연속이면 \(F(x) = \int_a^x f(t)\,dt\)는 \([a,b]\)에서 연속, \((a,b)\)에서 미분 가능하고 \(F'(x) = f(x)\).

(2) \(f\)가 \([a,b]\)에서 연속이고 \(G' = f\)이면 \(\int_a^b f(x)\,dx = G(b) - G(a)\).

읽는 법

\(F(x)\)는 "\(a\)부터 \(x\)까지 쌓인 넓이"입니다. \(x\)를 조금(\(h\)) 옮기면 넓이는 폭 \(h\), 높이 약 \(f(x)\)인 띠만큼 늘어납니다. 그래서 넓이의 증가율이 \(f(x)\)입니다. (1)은 "적분하고 미분하면 제자리", (2)는 "미분하고 적분하면 제자리(상수 차이)"입니다.

쓰는 것

  • 적분의 구간 가법성과 비교 성질 (앞 카드).
  • 최대·최소 정리, 평균값 정리의 결과 "\(G' = F'\)이면 \(G - F\)는 상수".

(1)의 증명

  1. \(h > 0\)이면 \(F(x+h) - F(x) = \int_x^{x+h} f(t)\,dt\).
    구간 가법성. \(h < 0\)도 같은 방법으로 처리한다.
  2. \([x, x+h]\)에서 \(f\)의 최솟값을 \(m_h\), 최댓값을 \(M_h\)라 하면 \(m_h\,h \le \int_x^{x+h} f \le M_h\,h\).
    최대·최소 정리(\(f\) 연속)로 \(m_h, M_h\)가 존재. 비교 성질.
  3. \(h\)로 나누면 \(m_h \le \dfrac{F(x+h) - F(x)}{h} \le M_h\).
    \(h > 0\)이라 부등호 방향 유지.
  4. \(h \to 0^+\)이면 \(m_h, M_h \to f(x)\)이므로 압축 정리로 몫 → \(f(x)\). 곧 \(F'(x) = f(x)\).
    \(m_h, M_h\)는 \([x, x+h]\) 안의 점에서의 \(f\)값이고, \(f\)가 연속이므로 \(f(x)\)로 간다.

(2)의 증명

  1. (1)에서 \(F' = f = G'\)이므로 \(G(x) = F(x) + C\).
    평균값 정리의 결과.
  2. \(G(b) - G(a) = F(b) - F(a) = \int_a^b f - 0\).
    \(C\)는 소거되고 \(F(a) = \int_a^a f = 0\).

적분 상한 함수 미분하기 (성취기준 [공통1-04-02])

상한이 \(x\)의 함수이면 연쇄 법칙을 함께 씁니다: \(\dfrac{d}{dx}\int_a^{u(x)} f(t)\,dt = f(u(x))\,u'(x)\). 양 끝이 모두 변하면 가운데 상수 \(c\)에서 나눕니다.

\(\dfrac{d}{dx}\displaystyle\int_{x^2}^{\sin x}\sqrt{1 + t^3}\,dt\)를 구하세요.

  1. \(\int_{x^2}^{\sin x} = \int_{0}^{\sin x} - \int_{0}^{x^2}\).
    구간 가법성. 피적분함수가 연속인 구간 안의 아무 상수나 된다(\(t^3 \ge -1\)이어야 하므로 \(t \ge -1\), 여기서는 \(\sin x \ge -1\), \(x^2 \ge 0\)이라 문제없음).
  2. 미분하면 \(\sqrt{1 + \sin^3 x}\,\cos x - \sqrt{1 + x^6}\cdot 2x\).
    각 항에 FTC(1)과 연쇄 법칙.

피적분함수의 부정적분을 식으로 쓸 수 없어도 도함수는 구할 수 있습니다. 이것이 (1)의 힘입니다.

흔한 오해

  • 연속성 확인 없이 (2) 쓰기: \(\int_{-1}^1\frac{1}{x^2}dx = \left[-\frac1x\right]_{-1}^1 = -2\)는 틀렸습니다. 양수 함수의 적분이 음수일 수 없습니다. \(x = 0\)에서 연속이 아니므로 (2)를 쓸 수 없고, 이것은 발산하는 이상적분입니다(6단원).
  • \(\frac{d}{dx}\int_a^{x^2} f = f(x^2)\): 안쪽 도함수 \(2x\)를 빠뜨렸습니다.
4.2.3

실습넓이 함수를 미분하면

실습 · 미적분의 기본정리

다루는 성취기준 [공통1-04-02]

목표

\(A(x) = \int_0^xf(t)\,dt\)를 그래프로 그리고, \(A\)의 접선 기울기가 언제나 \(f(x)\)와 같음(\(A' = f\))을 확인합니다. \(f\)의 부호와 \(A\)의 증감, \(f\)의 0점과 \(A\)의 극값이 어떻게 연결되는지 봅니다. 성취기준 [공통1-04-02].

준비

위 그래프는 \(f(t)\)와 0부터 \(x\)까지의 넓이(파랑은 더하고 빨강은 뺌), 아래 그래프는 넓이 함수 \(A(x)\)와 그 접선입니다.

절차

  1. \(\sin t\)에서 \(x\)를 0부터 6.3까지 천천히 움직이며 출력의 "A의 접선 기울기"와 "f(x)"를 비교한다.
  2. \(A(x)\)가 가장 큰 \(x\)를 찾아 그때 \(f(x)\)의 값을 본다.
  3. \(t^2/4 - 1\)에서 \(A\)가 감소하다 증가로 바뀌는 점을 찾는다.

기대 결과

  • 두 값이 늘 같다: \(A'(x) = f(x)\).
  • \(\sin t\): \(A\)는 \(x = \pi\)에서 최대(2), \(2\pi\)에서 다시 0. 그곳에서 \(f = 0\).
  • \(f < 0\)인 구간에서 \(A\)가 감소한다. \(t^2/4 - 1\)은 \(x = 2\)에서 \(A\)가 최소.

분석

  1. \(x\)를 \(\Delta x\)만큼 늘리면 넓이는 대략 얼마나 늘어나나요? 그것을 \(\Delta x\)로 나누면?
  2. \(A(x)\)는 \(f\)의 원시함수 가운데 어느 것인가요? \(\int_a^bf = F(b) - F(a)\)와 어떻게 이어지나요?

더 해 보기

\(\frac{d}{dx}\int_0^{x^2}\cos t\,dt\)를 연쇄법칙으로 구하고, 위끝이 \(x^2\)일 때 넓이가 변하는 빠르기가 왜 \(2x\cos x^2\)인지 그림으로 설명해 보세요.
