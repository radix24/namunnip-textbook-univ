4.2.1

증명미적분의 기본정리: 미분과 적분은 서로 거꾸로

적분 상한 함수 · FTC 1, 2

다루는 성취기준 [공통1-04-02]

정리 · 미적분의 기본정리

(1) \(f\)가 \([a,b]\)에서 연속이면 \(F(x) = \int_a^x f(t)\,dt\)는 \([a,b]\)에서 연속, \((a,b)\)에서 미분 가능하고 \(F'(x) = f(x)\).

(2) \(f\)가 \([a,b]\)에서 연속이고 \(G' = f\)이면 \(\int_a^b f(x)\,dx = G(b) - G(a)\).

읽는 법

\(F(x)\)는 "\(a\)부터 \(x\)까지 쌓인 넓이"입니다. \(x\)를 조금(\(h\)) 옮기면 넓이는 폭 \(h\), 높이 약 \(f(x)\)인 띠만큼 늘어납니다. 그래서 넓이의 증가율이 \(f(x)\)입니다. (1)은 "적분하고 미분하면 제자리", (2)는 "미분하고 적분하면 제자리(상수 차이)"입니다.

쓰는 것

  • 적분의 구간 가법성과 비교 성질 (앞 카드).
  • 최대·최소 정리, 평균값 정리의 결과 "\(G' = F'\)이면 \(G - F\)는 상수".

(1)의 증명

  1. \(h > 0\)이면 \(F(x+h) - F(x) = \int_x^{x+h} f(t)\,dt\).
    구간 가법성. \(h < 0\)도 같은 방법으로 처리한다.
  2. \([x, x+h]\)에서 \(f\)의 최솟값을 \(m_h\), 최댓값을 \(M_h\)라 하면 \(m_h\,h \le \int_x^{x+h} f \le M_h\,h\).
    최대·최소 정리(\(f\) 연속)로 \(m_h, M_h\)가 존재. 비교 성질.
  3. \(h\)로 나누면 \(m_h \le \dfrac{F(x+h) - F(x)}{h} \le M_h\).
    \(h > 0\)이라 부등호 방향 유지.
  4. \(h \to 0^+\)이면 \(m_h, M_h \to f(x)\)이므로 압축 정리로 몫 → \(f(x)\). 곧 \(F'(x) = f(x)\).
    \(m_h, M_h\)는 \([x, x+h]\) 안의 점에서의 \(f\)값이고, \(f\)가 연속이므로 \(f(x)\)로 간다.

(2)의 증명

  1. (1)에서 \(F' = f = G'\)이므로 \(G(x) = F(x) + C\).
    평균값 정리의 결과.
  2. \(G(b) - G(a) = F(b) - F(a) = \int_a^b f - 0\).
    \(C\)는 소거되고 \(F(a) = \int_a^a f = 0\).

적분 상한 함수 미분하기 (성취기준 [공통1-04-02])

상한이 \(x\)의 함수이면 연쇄 법칙을 함께 씁니다: \(\dfrac{d}{dx}\int_a^{u(x)} f(t)\,dt = f(u(x))\,u'(x)\). 양 끝이 모두 변하면 가운데 상수 \(c\)에서 나눕니다.

\(\dfrac{d}{dx}\displaystyle\int_{x^2}^{\sin x}\sqrt{1 + t^3}\,dt\)를 구하세요.

  1. \(\int_{x^2}^{\sin x} = \int_{0}^{\sin x} - \int_{0}^{x^2}\).
    구간 가법성. 피적분함수가 연속인 구간 안의 아무 상수나 된다(\(t^3 \ge -1\)이어야 하므로 \(t \ge -1\), 여기서는 \(\sin x \ge -1\), \(x^2 \ge 0\)이라 문제없음).
  2. 미분하면 \(\sqrt{1 + \sin^3 x}\,\cos x - \sqrt{1 + x^6}\cdot 2x\).
    각 항에 FTC(1)과 연쇄 법칙.

피적분함수의 부정적분을 식으로 쓸 수 없어도 도함수는 구할 수 있습니다. 이것이 (1)의 힘입니다.

흔한 오해

  • 연속성 확인 없이 (2) 쓰기: \(\int_{-1}^1\frac{1}{x^2}dx = \left[-\frac1x\right]_{-1}^1 = -2\)는 틀렸습니다. 양수 함수의 적분이 음수일 수 없습니다. \(x = 0\)에서 연속이 아니므로 (2)를 쓸 수 없고, 이것은 발산하는 이상적분입니다(6단원).
  • \(\frac{d}{dx}\int_a^{x^2} f = f(x^2)\): 안쪽 도함수 \(2x\)를 빠뜨렸습니다.
