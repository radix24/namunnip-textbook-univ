7.3.1거리와 방향으로 위치 말하기

"북동쪽으로 3 km"처럼 기준점에서의 거리와 방향으로 위치를 말할 수도 있습니다. 원점(극)에서의 거리 \(r\)과 \(x\)축 양의 방향에서 잰 각 \(\theta\)로 점을 \((r, \theta)\)로 나타내는 것이 극좌표입니다.

정리 7.3.1 (극좌표와 직교좌표) \[x = r\cos\theta, \quad y = r\sin\theta, \qquad r^2 = x^2 + y^2, \quad \tan\theta = \frac yx.\]

같은 점을 여러 극좌표로 쓸 수 있다는 점이 직교좌표와 다릅니다. \((2, \frac\pi3)\), \((2, \frac\pi3 + 2\pi)\)는 같은 점이고, \(r < 0\)이면 반대 방향으로 잽니다: \((-2, \frac\pi3)\)은 \((2, \frac{4\pi}{3})\)과 같습니다. \(\tan\theta = \frac yx\)에서 \(\theta\)를 구할 때는 점이 어느 사분면에 있는지 확인해야 합니다.

예제 7.3.2

직교좌표 \((1, -1)\)을 극좌표로, 극방정식 \(r = 2\sin\theta\)를 직교좌표 방정식으로 바꾸어라.

풀이. \(r = \sqrt2\), 점이 4사분면이므로 \(\theta = -\frac\pi4\) (또는 \(\frac{7\pi}{4}\)). 극좌표 \((\sqrt2, -\frac\pi4)\).

\(r = 2\sin\theta\)의 양변에 \(r\)을 곱하면 \(r^2 = 2r\sin\theta\), 곧 \(x^2 + y^2 = 2y\), \(x^2 + (y - 1)^2 = 1\). 중심 \((0, 1)\), 반지름 1인 원입니다.

7.3.2극곡선 그리기

\(r = f(\theta)\)는 각 \(\theta\) 방향으로 거리 \(f(\theta)\)만큼 간 점들의 자취입니다. \(\theta\)를 0부터 늘리며 \(r\)의 값을 표로 만들고 점을 찍는 것이 기본입니다. 대표적인 곡선은 다음과 같습니다.

  • \(r = a\): 원. \(\theta = c\): 원점을 지나는 직선.
  • \(r = 1 + \cos\theta\): 심장형(카디오이드). \(\theta = 0\)에서 \(r = 2\), \(\theta = \pi\)에서 \(r = 0\).
  • \(r = \cos2\theta\): 잎이 네 개인 장미 곡선. \(r = \cos n\theta\)는 \(n\)이 짝수면 잎 \(2n\)개, 홀수면 \(n\)개.

접선의 기울기는 \(\theta\)를 매개변수로 보고 \(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)에 7.1절의 공식을 씁니다: \(\dfrac{dy}{dx} = \dfrac{dy/d\theta}{dx/d\theta}\).

예제 7.3.3

심장형 \(r = 1 + \cos\theta\)의 \(\theta = \frac\pi2\)에서 접선의 기울기를 구하여라.

풀이. \(x = (1 + \cos\theta)\cos\theta\), \(y = (1 + \cos\theta)\sin\theta\). \(\frac{dx}{d\theta} = -\sin\theta - 2\sin\theta\cos\theta\), \(\frac{dy}{d\theta} = \cos\theta + \cos2\theta\). \(\theta = \frac\pi2\)에서 \(\frac{dx}{d\theta} = -1\), \(\frac{dy}{d\theta} = -1\)이므로 기울기 1.

요약
  1. \(x = r\cos\theta\), \(y = r\sin\theta\), \(r^2 = x^2 + y^2\). 같은 점의 극좌표는 여러 개다.
  2. 극방정식을 바꿀 때 양변에 \(r\)을 곱하는 요령이 유용하다.
  3. 극곡선의 접선: \(\theta\)를 매개변수로 본다.

7.3.3연습문제

기본

  1. 극좌표 \((4, \frac{5\pi}{6})\)을 직교좌표로 바꾸어라.
    답

    \((-2\sqrt3, 2)\).

  2. \(r = 4\cos\theta\)를 직교좌표 방정식으로 바꾸어라.
    답

    \(x^2 + y^2 = 4x\), \((x - 2)^2 + y^2 = 4\).

7.3.2

실습극곡선 그려 보기

실습 · r = f(θ)의 자취

다루는 성취기준 [공통1-07-03]

목표

각 \(\theta\)를 늘리며 반지름 \(r = f(\theta)\)인 점이 그리는 극곡선을 따라가 보고, 장미, 카디오이드, 리마송, 나선의 모양이 식의 어느 부분에서 오는지 확인합니다. 넓이 \(\frac12\int r^2d\theta\)도 함께 봅니다. 성취기준 [공통1-07-03].

준비

재생하면 각이 늘며 곡선이 그려집니다. 회색 점선은 각 \(\theta\) 방향, 주황 선은 원점에서 점까지의 반지름입니다. \(r < 0\)이면 점이 반대 방향에 찍힙니다.

절차

  1. 장미 곡선에서 \(k = 2, 3, 4, 5\)의 꽃잎 수를 세어 표로 만든다.
  2. \(k = 3\)을 재생해 \(r < 0\)인 동안 점이 어디에 찍히는지 본다.
  3. 카디오이드의 넓이를 출력에서 읽고 \(\frac{3\pi}{2}\)와 비교한다.
  4. 리마송에서 \(a\)를 0.5, 1, 1.5로 바꿔 안쪽 고리가 생기고 사라지는 경계를 찾는다.

기대 결과

  • \(k\)가 홀수면 꽃잎 \(k\)개(\(\theta\)가 0에서 \(\pi\)까지면 다 그려짐), 짝수면 \(2k\)개.
  • \(r < 0\)인 구간의 점은 반대편 꽃잎을 덧그린다.
  • 카디오이드 넓이 \(\frac{3\pi}{2} \approx 4.712\).
  • 리마송은 \(a < 1\)이면 안쪽 고리, \(a = 1\)이면 카디오이드, \(a > 1\)이면 고리 없음.

분석

  1. 장미 곡선에서 홀수와 짝수의 꽃잎 수가 다른 이유를 \(r(\theta + \pi) = \pm r(\theta)\)로 설명해 보세요.
  2. \(r = \cos3\theta\)의 넓이를 \(\theta\)가 0에서 \(2\pi\)까지 적분하면 실제 넓이의 몇 배가 나올까요?

더 해 보기

\(r = \cos k\theta\)의 꽃잎 하나의 넓이는 \(\frac{\pi}{4k}\)입니다. 홀수 \(k\)에서 전체 넓이가 \(\frac\pi4\), 짝수 \(k\)에서 \(\frac\pi2\)임을 확인해 보세요.
