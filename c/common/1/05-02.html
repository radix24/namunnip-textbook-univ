5.2.1지수 하나가 홀수일 때

\(\int\sin^3x\,dx\)처럼 사인이나 코사인의 거듭제곱을 적분할 때, 지수가 홀수이면 하나를 떼어 \(du\)로 쓰고 나머지 짝수 개를 \(\sin^2x + \cos^2x = 1\)로 바꿉니다.

예제 5.2.1

(가) \(\int\sin^3x\,dx\) (나) \(\int\sin^2x\cos^5x\,dx\)

풀이. (가) \(\sin^3x = \sin^2x\cdot\sin x = (1 - \cos^2x)\sin x\). \(u = \cos x\), \(du = -\sin x\,dx\)로 놓으면 \(\int(1 - u^2)(-du) = -u + \frac{u^3}{3} + C = -\cos x + \frac{\cos^3x}{3} + C\).

(나) 코사인의 지수 5가 홀수입니다. \(\cos^5x = (\cos^2x)^2\cos x = (1 - \sin^2x)^2\cos x\). \(u = \sin x\)로 놓으면 \(\int u^2(1 - u^2)^2du = \int(u^2 - 2u^4 + u^6)du = \frac{\sin^3x}{3} - \frac{2\sin^5x}{5} + \frac{\sin^7x}{7} + C\).

5.2.2두 지수가 모두 짝수일 때

둘 다 짝수이면 떼어 낼 하나가 없으므로, 반각 공식으로 차수를 낮춥니다.

\[\sin^2x = \frac{1 - \cos2x}{2}, \qquad \cos^2x = \frac{1 + \cos2x}{2}, \qquad \sin x\cos x = \frac{\sin2x}{2}.\]
예제 5.2.2

\(\int_0^\pi\sin^2x\,dx\)와 \(\int\sin^4x\,dx\)를 구하여라.

풀이. \(\int_0^\pi\frac{1 - \cos2x}{2}dx = \left[\frac x2 - \frac{\sin2x}{4}\right]_0^\pi = \frac\pi2\). 한 주기에서 \(\sin^2\)의 평균은 \(\frac12\)라는 뜻이고, 교류 전력(공통4)의 계산에 그대로 쓰입니다.

\(\sin^4x = \left(\frac{1 - \cos2x}{2}\right)^2 = \frac14(1 - 2\cos2x + \cos^22x)\)이고, \(\cos^22x = \frac{1 + \cos4x}{2}\)로 한 번 더 낮추면

\[\int\sin^4x\,dx = \frac{3x}{8} - \frac{\sin2x}{4} + \frac{\sin4x}{32} + C.\]

5.2.3탄젠트와 시컨트

\((\tan x)' = \sec^2x\), \((\sec x)' = \sec x\tan x\), \(\tan^2x = \sec^2x - 1\)을 씁니다. 예를 들어

\[\int\tan^2x\,dx = \int(\sec^2x - 1)\,dx = \tan x - x + C.\]

또 \(\int\sec x\,dx = \ln|\sec x + \tan x| + C\)는 외워 두면 편리합니다(미분해서 확인할 수 있습니다).

주의\(\int\sin^2x\,dx\)를 \(\frac{\sin^3x}{3}\)로 계산하면 틀립니다. \((\sin^3x)' = 3\sin^2x\cos x\)이므로 \(\cos x\)가 없는 식에는 거듭제곱 공식을 쓸 수 없습니다.
요약
  1. 사인·코사인의 지수 중 홀수가 있으면: 하나를 떼어 \(du\)로, 나머지는 \(\sin^2 + \cos^2 = 1\)로.
  2. 둘 다 짝수이면: 반각 공식으로 차수를 낮춘다.
  3. \(\tan^2x = \sec^2x - 1\), \(\int\sec x\,dx = \ln|\sec x + \tan x| + C\).

5.2.4연습문제

기본

  1. (가) \(\int\cos^3x\,dx\) (나) \(\int_0^{\pi/2}\cos^2x\,dx\)
    답

    (가) \(\sin x - \frac{\sin^3x}{3} + C\) (나) \(\frac\pi4\)

응용

  1. \(\int\sin^2x\cos^2x\,dx\)를 구하여라.
    답

    \(\sin x\cos x = \frac{\sin2x}{2}\)이므로 \(\frac14\int\sin^22x\,dx = \frac14\int\frac{1 - \cos4x}{2}dx = \frac x8 - \frac{\sin4x}{32} + C\).

  2. \(\int\tan x\sec^2x\,dx\)를 구하여라.
    답

    \(u = \tan x\): \(\frac{\tan^2x}{2} + C\).

5.2.2

예제사인의 세제곱과 코사인의 제곱을 곱한 함수는 어떻게 적분할까?

예제 · 삼각함수의 거듭제곱

다루는 성취기준 [공통1-05-02]

\(\displaystyle\int\sin^3x\cos^2x\,dx\)를 구하세요.

전략

사인의 지수가 홀수입니다. 사인 하나를 \(dx\) 옆에 남겨 두면 \(\sin x\,dx = -d(\cos x)\)가 되고, 남은 \(\sin^2x\)는 \(1 - \cos^2x\)로 바꿀 수 있습니다. 그러면 모든 것이 \(\cos x\)의 다항식이 되어 \(u = \cos x\)로 치환하면 끝납니다. 두 지수가 모두 짝수였다면 이 방법이 통하지 않고 반각 공식을 씁니다.

풀이

  1. \(\sin^3x\cos^2x = \sin^2x\cos^2x\cdot\sin x = (1 - \cos^2x)\cos^2x\,\sin x\).
    \(\sin^2x + \cos^2x = 1\). 사인 하나를 떼어 둠.
  2. \(u = \cos x\), \(du = -\sin x\,dx\)로 치환: \(\displaystyle\int(1 - u^2)u^2(-du) = \int(u^4 - u^2)\,du\).
    치환적분(4.3절).
  3. \(= \dfrac{u^5}5 - \dfrac{u^3}3 + C = \dfrac{\cos^5x}5 - \dfrac{\cos^3x}3 + C\).
    거듭제곱의 적분 후 \(u\)를 되돌림.

의미

삼각함수의 곱은 "홀수 지수가 있으면 하나를 떼어 치환, 모두 짝수면 반각 공식"이라는 두 갈래로 거의 다 정리됩니다. 이 적분은 교류 회로의 평균 전력이나 진동의 에너지를 계산할 때 나옵니다.

검산

답을 미분하면 \(\cos^4x(-\sin x) - \cos^2x(-\sin x) = \sin x\cos^2x(1 - \cos^2x) = \sin^3x\cos^2x\). 맞습니다.

바꿔 보기

\(\int\sin^2x\,dx\)처럼 짝수 지수만 있으면 \(\sin^2x = \dfrac{1 - \cos2x}2\)로 바꿔 \(\dfrac x2 - \dfrac{\sin2x}4 + C\)를 얻습니다. \(\int\tan^3x\sec x\,dx\)는 \(\sec x\tan x\,dx\)를 떼어 \(u = \sec x\)로 치환합니다.

이해 확인

\(\displaystyle\int_0^{\pi/2}\sin^2x\,dx\)와 \(\displaystyle\int_0^{\pi/2}\cos^3x\,dx\)를 구하세요.

답

\(\pi/4\). 둘째는 \(\cos^3x = (1 - \sin^2x)\cos x\), \(u = \sin x\)로 \(\left[u - u^3/3\right]_0^1 = 2/3\).
