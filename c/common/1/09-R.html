9.R.1

연습공간의 벡터 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통1-09-01] [공통1-09-02] [공통1-09-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산두 점 \(A(1, 2, 3)\), \(B(4, 6, 3)\) 사이의 거리와 선분 AB의 중점을 구하세요. [09-01]

    힌트 1

    공간의 거리 공식 \(\sqrt{(\Delta x)^2 + (\Delta y)^2 + (\Delta z)^2}\). 피타고라스 정리를 두 번 쓴 것입니다.

    힌트 2

    \(\Delta = (3, 4, 0)\).

    풀이

    거리 \(\sqrt{9 + 16 + 0} = 5\), 중점 \(\left(\tfrac52, 4, 3\right)\). 두 점의 z좌표가 같아서 평면의 거리 공식과 똑같아졌습니다.

  2. 계산\(x^2 + y^2 + z^2 - 2x + 4y - 6z = 2\)는 구입니다. 중심과 반지름을 구하세요. [09-01]

    힌트 1

    \(x\), \(y\), \(z\)마다 완전제곱식을 만듭니다.

    힌트 2

    \(x^2 - 2x = (x - 1)^2 - 1\), \(y^2 + 4y = (y + 2)^2 - 4\), \(z^2 - 6z = (z - 3)^2 - 9\).

    풀이

    \((x - 1)^2 + (y + 2)^2 + (z - 3)^2 = 2 + 1 + 4 + 9 = 16\). 중심 \((1, -2, 3)\), 반지름 4. 오른쪽이 음수가 나오면 그런 점은 없고, 0이면 한 점입니다.

  3. 계산\(\mathbf a = \langle1, 2, -1\rangle\), \(\mathbf b = \langle3, 0, 2\rangle\)일 때 \(2\mathbf a - \mathbf b\), \(|\mathbf a|\), \(\mathbf a\) 방향의 단위벡터를 구하세요. [09-02]

    힌트 1

    성분끼리 계산합니다. 길이는 성분 제곱의 합의 제곱근.

    힌트 2

    단위벡터는 \(\mathbf a/|\mathbf a|\).

    풀이

    \(2\mathbf a - \mathbf b = \langle-1, 4, -4\rangle\), \(|\mathbf a| = \sqrt6\), 단위벡터 \(\tfrac1{\sqrt6}\langle1, 2, -1\rangle\).

  4. 계산앞 문제의 \(\mathbf a\)와 \(\mathbf b\)가 이루는 각을 구하세요. [09-03]

    힌트 1

    \(\cos\theta = \dfrac{\mathbf a\cdot\mathbf b}{|\mathbf a||\mathbf b|}\).

    힌트 2

    \(\mathbf a\cdot\mathbf b = 3 + 0 - 2 = 1\), \(|\mathbf b| = \sqrt{13}\).

    풀이

    \(\cos\theta = \dfrac1{\sqrt{78}} = 0.113\), \(\theta \approx 83.5°\). 내적이 양수이므로 예각이지만 거의 직각입니다.

  5. 계산앞 문제에서 \(\mathbf a\)의 \(\mathbf b\) 위로의 정사영(벡터)과 스칼라 성분을 구하세요. 힘 \(\mathbf a\)(N)가 \(\mathbf b\) 방향으로 \(|\mathbf b|\) m 움직였다면 한 일은? [09-03]

    힌트 1

    스칼라 성분 \(\dfrac{\mathbf a\cdot\mathbf b}{|\mathbf b|}\), 정사영 \(\dfrac{\mathbf a\cdot\mathbf b}{|\mathbf b|^2}\mathbf b\).

    힌트 2

    일은 \(\mathbf F\cdot\mathbf d\)입니다.

    풀이

    스칼라 성분 \(1/\sqrt{13} \approx 0.277\), 정사영 \(\tfrac1{13}\langle3, 0, 2\rangle\). 일 \(= \mathbf a\cdot\mathbf b = 1\) J. 힘의 대부분이 움직이는 방향과 거의 직각이라 일이 작습니다.

  6. 판단“\(\mathbf a\cdot\mathbf b = 0\)이면 \(\mathbf a\)와 \(\mathbf b\) 가운데 하나는 영벡터다.” 판단하세요. [09-03]

    힌트 1

    \(\langle1, 2, 2\rangle\cdot\langle2, -1, 0\rangle\)을 계산해 보세요.

    힌트 2

    내적이 0이라는 것은 \(\cos\theta = 0\)일 수도 있습니다.

    풀이

    틀렸습니다. \(\langle1, 2, 2\rangle\cdot\langle2, -1, 0\rangle = 0\)이지만 둘 다 영벡터가 아닙니다. 영벡터가 아닌 두 벡터의 내적이 0이면 서로 수직입니다. 실수의 곱 \(ab = 0\)이면 \(a = 0\)이나 \(b = 0\)이지만, 내적에서는 이 성질이 성립하지 않습니다.
