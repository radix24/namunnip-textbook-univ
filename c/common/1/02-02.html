이 절에서 배울 것

  • 연쇄법칙으로 합성함수를 미분한다.
  • 연쇄법칙으로 \(a^x\), \(x^r\) 같은 함수의 도함수 공식을 얻는다.
먼저 알아야 할 것
  • 합성함수 \(f(g(x))\) (고교 수학).
  • 도함수의 정의와 기본 미분 공식 (2.1절): \((x^n)' = nx^{n-1}\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\), \((e^x)' = e^x\).

2.2.1왜 새 규칙이 필요한가

\(F(x) = (x^2 + 1)^{10}\)을 미분해 봅시다. 전개하면 11개의 항이 나오는 다항식이라 미분은 할 수 있지만, 매우 번거롭습니다. \(G(x) = \sin(x^2)\)은 전개할 방법조차 없습니다. 두 함수 모두 "어떤 함수 안에 다른 함수가 들어 있는" 합성함수입니다.

  • \(F(x) = (x^2 + 1)^{10}\): 안에서 \(u = x^2 + 1\)을 계산하고, 밖에서 \(u^{10}\)을 계산한다.
  • \(G(x) = \sin(x^2)\): 안에서 \(u = x^2\)을 계산하고, 밖에서 \(\sin u\)를 계산한다.

안쪽 함수를 속함수, 바깥 함수를 겉함수라고 부르겠습니다. 연쇄법칙은 겉함수와 속함수의 도함수만 알면 합성함수의 도함수를 구할 수 있다는 규칙입니다.

2.2.2연쇄법칙

먼저 변화율로 생각해 봅시다. 톱니바퀴 세 개가 맞물려 있는데, 바퀴 A가 한 바퀴 돌 때 B가 2바퀴, B가 한 바퀴 돌 때 C가 3바퀴 돈다면, A가 한 바퀴 돌 때 C는 \(2 \times 3 = 6\)바퀴 돕니다. 변화율은 곱해집니다. 이것을 식으로 쓴 것이 연쇄법칙입니다.

정리 2.2.1 (연쇄법칙)

\(g\)가 \(x\)에서 미분 가능하고 \(f\)가 \(g(x)\)에서 미분 가능하면, 합성함수 \(F(x) = f(g(x))\)도 \(x\)에서 미분 가능하고

\[F'(x) = f'(g(x))\cdot g'(x).\]

\(y = f(u)\), \(u = g(x)\)로 쓰면 \(\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}\)이다.

말로 읽으면 "겉함수를 미분하되 속은 그대로 두고, 거기에 속함수의 도함수를 곱한다"입니다. 라이프니츠 기호로 쓴 식은 \(du\)가 약분되는 것처럼 보여서 기억하기 쉽습니다. 실제로 약분하는 것은 아니지만, 이 기호가 맞는 결과를 주도록 만들어져 있습니다.

왜 성립하는지 간단히 보면 이렇습니다. \(x\)가 \(\Delta x\)만큼 바뀌면 \(u\)가 \(\Delta u\)만큼, 그 때문에 \(y\)가 \(\Delta y\)만큼 바뀝니다. \(\Delta u \ne 0\)이면 \(\dfrac{\Delta y}{\Delta x} = \dfrac{\Delta y}{\Delta u}\cdot\dfrac{\Delta u}{\Delta x}\)이고, \(\Delta x \to 0\)이면 \(\Delta u \to 0\)이므로 양변이 각각 \(\dfrac{dy}{dx}\), \(\dfrac{dy}{du}\cdot\dfrac{du}{dx}\)로 갑니다. \(\Delta u = 0\)이 되는 경우까지 다루는 완전한 증명은 교재 3.4절 끝에 있습니다.

예제 2.2.2

\(F(x) = (x^2 + 1)^{10}\)과 \(G(x) = \sin(x^2)\)을 미분하여라.

풀이. \(F\)의 겉함수는 \(u^{10}\), 속함수는 \(u = x^2 + 1\)입니다. 겉함수의 도함수는 \(10u^9\), 속함수의 도함수는 \(2x\)이므로

\[F'(x) = 10(x^2 + 1)^9\cdot 2x = 20x(x^2 + 1)^9.\]

\(G\)의 겉함수는 \(\sin u\), 속함수는 \(u = x^2\)입니다.

\[G'(x) = \cos(x^2)\cdot 2x = 2x\cos(x^2).\]

흔한 실수는 \(\cos(x^2)\)에서 멈추는 것, 곧 속함수의 도함수 \(2x\)를 곱하지 않는 것입니다. "속을 곱했나?"를 마지막에 꼭 확인하세요.

2.2.3자주 쓰는 꼴

연쇄법칙을 몇 가지 겉함수에 적용해 두면 공식처럼 쓸 수 있습니다. \(u\)는 \(x\)의 함수입니다.

함수도함수
\(u^n\)\(nu^{n-1}u'\)
\(\sin u\)\(\cos u\cdot u'\)
\(\cos u\)\(-\sin u\cdot u'\)
\(e^u\)\(e^u\cdot u'\)
\(\sqrt u\)\(\dfrac{u'}{2\sqrt u}\)
예제 2.2.3

(가) \(y = e^{-3x}\) (나) \(y = \sqrt{1 + x^2}\) (다) \(y = \cos^3 x\)를 미분하여라.

풀이. (가) \(u = -3x\), \(u' = -3\)이므로 \(y' = -3e^{-3x}\).

(나) \(u = 1 + x^2\), \(u' = 2x\)이므로 \(y' = \dfrac{2x}{2\sqrt{1 + x^2}} = \dfrac{x}{\sqrt{1 + x^2}}\).

(다) \(\cos^3 x = (\cos x)^3\)이므로 겉함수는 \(u^3\), 속함수는 \(u = \cos x\)입니다. \(y' = 3\cos^2 x\cdot(-\sin x) = -3\cos^2 x\sin x\).

2.2.4겹겹이 쌓인 합성

함수가 세 겹 이상 쌓여 있으면 연쇄법칙을 바깥부터 한 겹씩 반복합니다. 양파 껍질을 벗기듯, 벗길 때마다 그 껍질의 도함수를 곱합니다.

예제 2.2.4

\(y = \sin^2(3x + 1)\)을 미분하여라.

풀이. 세 겹입니다: 맨 바깥 \(u^2\), 그다음 \(\sin v\), 맨 안 \(v = 3x + 1\).

\[y' = 2\sin(3x + 1)\cdot\cos(3x + 1)\cdot 3 = 6\sin(3x + 1)\cos(3x + 1).\]

배각 공식 \(2\sin\theta\cos\theta = \sin 2\theta\)를 쓰면 \(y' = 3\sin(6x + 2)\)로 줄일 수 있습니다.

2.2.5연쇄법칙으로 얻는 새 공식

지수함수 \(a^x\)는 \(e\)의 거듭제곱으로 바꿀 수 있습니다: \(a^x = e^{x\ln a}\) (1.2절). 그러면 연쇄법칙으로

\[\frac{d}{dx}a^x = \frac{d}{dx}e^{(\ln a)x} = e^{(\ln a)x}\cdot\ln a = a^x\ln a.\]
정리 2.2.5

\(a > 0\)이면 \(\dfrac{d}{dx}a^x = a^x\ln a\)이다. 특히 \(a = e\)이면 \(\ln e = 1\)이라 \((e^x)' = e^x\)이다.

\(e\)가 특별한 이유가 여기서 다시 보입니다. 다른 밑을 쓰면 \(\ln a\)라는 상수가 따라붙습니다. 예를 들어 \((2^x)' = 2^x\ln 2 \approx 0.693\cdot2^x\)입니다.

주의\(\dfrac{d}{dx}\sin(x^2)\)과 \(\dfrac{d}{dx}\sin^2 x\)는 다릅니다. 앞의 것은 속이 \(x^2\)이라 \(2x\cos(x^2)\), 뒤의 것은 겉이 제곱이라 \(2\sin x\cos x\)입니다. 어느 것이 겉이고 어느 것이 속인지 먼저 정하세요.
요약
  1. 합성함수 \(f(g(x))\)의 도함수는 \(f'(g(x))\cdot g'(x)\): 겉을 미분하고 속의 도함수를 곱한다.
  2. 라이프니츠 꼴: \(\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}\).
  3. 여러 겹이면 바깥부터 한 겹씩 반복한다.
  4. \((a^x)' = a^x\ln a\).

2.2.6연습문제

기본

  1. 미분하여라. (가) \((3x - 5)^4\) (나) \(e^{x^2}\) (다) \(\cos(5x)\)
    답

    (가) \(12(3x - 5)^3\) (나) \(2xe^{x^2}\) (다) \(-5\sin 5x\)

  2. \(y = \sqrt[3]{1 + 2x}\)의 \(x = 0\)에서의 접선의 기울기를 구하여라.
    답

    \(y' = \frac13(1 + 2x)^{-2/3}\cdot2\). \(x = 0\)이면 \(\frac23\).

  3. \(y = 10^x\)을 미분하여라.
    답

    \(10^x\ln 10\).

응용

  1. \(y = x^2 e^{-x}\)을 미분하여라. (곱의 미분법과 연쇄법칙)
    답

    \(2xe^{-x} - x^2e^{-x} = x(2 - x)e^{-x}\).

  2. \(y = \sin(\cos(x^2))\)을 미분하여라.
    답

    \(\cos(\cos x^2)\cdot(-\sin x^2)\cdot2x = -2x\sin(x^2)\cos(\cos x^2)\).

심화

  1. \(f\)가 미분 가능하고 \(h(x) = f(f(x))\)일 때, \(f(1) = 2\), \(f'(1) = 3\), \(f'(2) = 5\)이면 \(h'(1)\)은?
    답

    \(h'(1) = f'(f(1))\cdot f'(1) = f'(2)\cdot3 = 15\).

2.2.2

증명곱의 법칙과 연쇄 법칙은 어디서 오는가?

미분법의 증명

다루는 성취기준 [공통1-02-02]

정리

\(f, g\)가 \(x\)에서 미분 가능하면

\[(fg)' = f'g + fg', \qquad \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}\ (g(x) \ne 0).\]

\(g\)가 \(x\)에서, \(f\)가 \(g(x)\)에서 미분 가능하면 \((f\circ g)'(x) = f'(g(x))\,g'(x)\) (연쇄 법칙).

쓰는 것

  • 도함수의 정의와 극한 법칙(합·곱의 극한).
  • 미분 가능하면 연속 (앞 카드): \(g(x+h) \to g(x)\).

곱의 법칙: 아이디어와 증명

\(f(x+h)g(x+h) - f(x)g(x)\)에는 "\(f\)도 변하고 \(g\)도 변한" 효과가 섞여 있습니다. 가운데 항 \(f(x+h)g(x)\)를 빼고 더해 "\(g\)만 변한 몫"과 "\(f\)만 변한 몫"으로 나눕니다. 넓이가 \(fg\)인 직사각형에서 가로와 세로가 조금씩 늘어날 때 늘어난 넓이를 두 띠로 나누는 그림과 같습니다.

  1. \(f(x+h)g(x+h) - f(x)g(x) = f(x+h)\,[g(x+h) - g(x)] + g(x)\,[f(x+h) - f(x)]\).
    \(f(x+h)g(x)\)를 빼고 더한 항등식.
  2. \(h\)로 나누면 \(f(x+h)\dfrac{g(x+h) - g(x)}{h} + g(x)\dfrac{f(x+h) - f(x)}{h}\).
    양변을 \(h \ne 0\)으로 나눔.
  3. \(h \to 0\)이면 \(f(x+h) \to f(x)\), 두 몫은 \(g'(x)\), \(f'(x)\)로 가므로 \((fg)'(x) = f(x)g'(x) + g(x)f'(x)\).
    \(f(x+h) \to f(x)\)는 \(f\)가 미분 가능해서 연속이기 때문. 나머지는 곱·합의 극한 법칙.

몫의 법칙은 \(\frac{f}{g} = f\cdot\frac1g\)로 보고, 먼저 \(\left(\frac1g\right)' = -\frac{g'}{g^2}\)을 정의로 보인 뒤(\(\frac{1}{g(x+h)} - \frac{1}{g(x)} = \frac{g(x) - g(x+h)}{g(x+h)g(x)}\)) 곱의 법칙을 쓰면 됩니다.

연쇄 법칙: 아이디어와 증명

직관은 \(\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}\)입니다. 그런데 이것을 그대로 증명으로 쓰면 \(\Delta u = g(x+h) - g(x)\)가 0이 되는 \(h\)에서 \(\frac{\Delta y}{\Delta u}\)가 정의되지 않는 문제가 있습니다(예: \(g\)가 상수 구간을 가질 때). 이 구멍을 막으려고 보조 함수를 씁니다.

  1. \(b = g(x)\)로 두고, \(Q(k) = \dfrac{f(b+k) - f(b)}{k}\ (k \ne 0)\), \(Q(0) = f'(b)\)로 정의한다.
    \(Q\)는 \(f\)의 할선 기울기를 \(k = 0\)까지 이어 붙인 함수. \(f\)가 \(b\)에서 미분 가능하므로 \(Q\)는 \(k = 0\)에서 연속이다.
  2. 모든 \(k\)(0 포함)에 대해 \(f(b+k) - f(b) = Q(k)\,k\).
    \(k \ne 0\)이면 \(Q\)의 정의, \(k = 0\)이면 양변이 0.
  3. \(k = g(x+h) - g(x)\)로 두면 \(b + k = g(x+h)\)이므로 \(f(g(x+h)) - f(g(x)) = Q(k)\,[g(x+h) - g(x)]\).
    2단계에 대입. \(k = 0\)이어도 성립한다는 점이 핵심.
  4. \(h\)로 나누면 \(\dfrac{f(g(x+h)) - f(g(x))}{h} = Q(k)\,\dfrac{g(x+h) - g(x)}{h}\).
    \(h \ne 0\)으로 나눔. 이제 \(k\)로 나누지 않는다.
  5. \(h \to 0\)이면 \(k \to 0\)이고 \(Q(k) \to Q(0) = f'(g(x))\), 뒤의 몫 → \(g'(x)\). 따라서 \((f\circ g)'(x) = f'(g(x))\,g'(x)\).
    \(k \to 0\)은 \(g\)의 연속성, \(Q(k) \to f'(b)\)는 \(Q\)의 연속성(합성함수의 극한).

쓰는 법 (성취기준 [공통1-02-02])

\(y = \dfrac{x^2 \sin(3x)}{\sqrt{1 + x^2}}\)를 미분하세요.

  1. 몫의 법칙: 분자 \(N = x^2\sin 3x\), 분모 \(D = (1 + x^2)^{1/2}\).
    가장 바깥의 연산이 나눗셈이므로 몫의 법칙부터.
  2. \(N' = 2x\sin 3x + x^2\cdot 3\cos 3x\).
    곱의 법칙, \((\sin 3x)' = 3\cos 3x\)는 연쇄 법칙.
  3. \(D' = \frac12(1+x^2)^{-1/2}\cdot 2x = \dfrac{x}{\sqrt{1+x^2}}\).
    연쇄 법칙(바깥 \(u^{1/2}\), 안 \(1 + x^2\)).
  4. \(y' = \dfrac{N'D - ND'}{D^2} = \dfrac{(2x\sin3x + 3x^2\cos3x)(1+x^2) - x^3\sin 3x}{(1+x^2)^{3/2}}\).
    \(D^2 = 1 + x^2\)이고, 분자·분모에 \(\sqrt{1+x^2}\)를 곱해 분수 속 분수를 없앴다.

흔한 오해

  • "\((fg)' = f'g'\)." 위의 직사각형 그림에서 \(f'g'\)는 두 띠가 겹치는 아주 작은 모서리에 해당하며, 극한에서 0이 됩니다.
  • 연쇄 법칙에서 안쪽 도함수를 빠뜨림: \((\sin x^2)' = \cos x^2\)가 아니라 \(2x\cos x^2\).
