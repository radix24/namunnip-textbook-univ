2.2.1

증명곱의 법칙과 연쇄 법칙은 어디서 오는가?

미분법의 증명

다루는 성취기준 [공통1-02-02]

정리

\(f, g\)가 \(x\)에서 미분 가능하면

\[(fg)' = f'g + fg', \qquad \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}\ (g(x) \ne 0).\]

\(g\)가 \(x\)에서, \(f\)가 \(g(x)\)에서 미분 가능하면 \((f\circ g)'(x) = f'(g(x))\,g'(x)\) (연쇄 법칙).

쓰는 것

  • 도함수의 정의와 극한 법칙(합·곱의 극한).
  • 미분 가능하면 연속 (앞 카드): \(g(x+h) \to g(x)\).

곱의 법칙: 아이디어와 증명

\(f(x+h)g(x+h) - f(x)g(x)\)에는 "\(f\)도 변하고 \(g\)도 변한" 효과가 섞여 있습니다. 가운데 항 \(f(x+h)g(x)\)를 빼고 더해 "\(g\)만 변한 몫"과 "\(f\)만 변한 몫"으로 나눕니다. 넓이가 \(fg\)인 직사각형에서 가로와 세로가 조금씩 늘어날 때 늘어난 넓이를 두 띠로 나누는 그림과 같습니다.

  1. \(f(x+h)g(x+h) - f(x)g(x) = f(x+h)\,[g(x+h) - g(x)] + g(x)\,[f(x+h) - f(x)]\).
    \(f(x+h)g(x)\)를 빼고 더한 항등식.
  2. \(h\)로 나누면 \(f(x+h)\dfrac{g(x+h) - g(x)}{h} + g(x)\dfrac{f(x+h) - f(x)}{h}\).
    양변을 \(h \ne 0\)으로 나눔.
  3. \(h \to 0\)이면 \(f(x+h) \to f(x)\), 두 몫은 \(g'(x)\), \(f'(x)\)로 가므로 \((fg)'(x) = f(x)g'(x) + g(x)f'(x)\).
    \(f(x+h) \to f(x)\)는 \(f\)가 미분 가능해서 연속이기 때문. 나머지는 곱·합의 극한 법칙.

몫의 법칙은 \(\frac{f}{g} = f\cdot\frac1g\)로 보고, 먼저 \(\left(\frac1g\right)' = -\frac{g'}{g^2}\)을 정의로 보인 뒤(\(\frac{1}{g(x+h)} - \frac{1}{g(x)} = \frac{g(x) - g(x+h)}{g(x+h)g(x)}\)) 곱의 법칙을 쓰면 됩니다.

연쇄 법칙: 아이디어와 증명

직관은 \(\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}\)입니다. 그런데 이것을 그대로 증명으로 쓰면 \(\Delta u = g(x+h) - g(x)\)가 0이 되는 \(h\)에서 \(\frac{\Delta y}{\Delta u}\)가 정의되지 않는 문제가 있습니다(예: \(g\)가 상수 구간을 가질 때). 이 구멍을 막으려고 보조 함수를 씁니다.

  1. \(b = g(x)\)로 두고, \(Q(k) = \dfrac{f(b+k) - f(b)}{k}\ (k \ne 0)\), \(Q(0) = f'(b)\)로 정의한다.
    \(Q\)는 \(f\)의 할선 기울기를 \(k = 0\)까지 이어 붙인 함수. \(f\)가 \(b\)에서 미분 가능하므로 \(Q\)는 \(k = 0\)에서 연속이다.
  2. 모든 \(k\)(0 포함)에 대해 \(f(b+k) - f(b) = Q(k)\,k\).
    \(k \ne 0\)이면 \(Q\)의 정의, \(k = 0\)이면 양변이 0.
  3. \(k = g(x+h) - g(x)\)로 두면 \(b + k = g(x+h)\)이므로 \(f(g(x+h)) - f(g(x)) = Q(k)\,[g(x+h) - g(x)]\).
    2단계에 대입. \(k = 0\)이어도 성립한다는 점이 핵심.
  4. \(h\)로 나누면 \(\dfrac{f(g(x+h)) - f(g(x))}{h} = Q(k)\,\dfrac{g(x+h) - g(x)}{h}\).
    \(h \ne 0\)으로 나눔. 이제 \(k\)로 나누지 않는다.
  5. \(h \to 0\)이면 \(k \to 0\)이고 \(Q(k) \to Q(0) = f'(g(x))\), 뒤의 몫 → \(g'(x)\). 따라서 \((f\circ g)'(x) = f'(g(x))\,g'(x)\).
    \(k \to 0\)은 \(g\)의 연속성, \(Q(k) \to f'(b)\)는 \(Q\)의 연속성(합성함수의 극한).

쓰는 법 (성취기준 [공통1-02-02])

\(y = \dfrac{x^2 \sin(3x)}{\sqrt{1 + x^2}}\)를 미분하세요.

  1. 몫의 법칙: 분자 \(N = x^2\sin 3x\), 분모 \(D = (1 + x^2)^{1/2}\).
    가장 바깥의 연산이 나눗셈이므로 몫의 법칙부터.
  2. \(N' = 2x\sin 3x + x^2\cdot 3\cos 3x\).
    곱의 법칙, \((\sin 3x)' = 3\cos 3x\)는 연쇄 법칙.
  3. \(D' = \frac12(1+x^2)^{-1/2}\cdot 2x = \dfrac{x}{\sqrt{1+x^2}}\).
    연쇄 법칙(바깥 \(u^{1/2}\), 안 \(1 + x^2\)).
  4. \(y' = \dfrac{N'D - ND'}{D^2} = \dfrac{(2x\sin3x + 3x^2\cos3x)(1+x^2) - x^3\sin 3x}{(1+x^2)^{3/2}}\).
    \(D^2 = 1 + x^2\)이고, 분자·분모에 \(\sqrt{1+x^2}\)를 곱해 분수 속 분수를 없앴다.

흔한 오해

  • "\((fg)' = f'g'\)." 위의 직사각형 그림에서 \(f'g'\)는 두 띠가 겹치는 아주 작은 모서리에 해당하며, 극한에서 0이 됩니다.
  • 연쇄 법칙에서 안쪽 도함수를 빠뜨림: \((\sin x^2)' = \cos x^2\)가 아니라 \(2x\cos x^2\).
