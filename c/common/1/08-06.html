8.6.1무한 차수의 다항식

다항식 \(c_0 + c_1x + c_2x^2 + \cdots + c_nx^n\)을 끝없이 이어 쓴

\[\sum_{n=0}^\infty c_nx^n = c_0 + c_1x + c_2x^2 + \cdots\]

를 거듭제곱급수라 합니다. \(x\)에 수를 넣을 때마다 하나의 급수가 되고, 그 급수가 수렴하는 \(x\)에서 함숫값이 정해집니다. 가장 간단한 예는 모든 계수가 1인 \(\sum x^n = 1 + x + x^2 + \cdots\)인데, 등비급수이므로 \(|x| < 1\)일 때만 수렴하고 합은 \(\frac{1}{1 - x}\)입니다. 곧 이 급수는 구간 \((-1, 1)\)에서 함수 \(\frac{1}{1 - x}\)과 같습니다.

\(a\)를 중심으로 하는 \(\sum c_n(x - a)^n\)도 같은 방식으로 다룹니다.

8.6.2수렴 반지름

정리 8.6.1

거듭제곱급수 \(\sum c_n(x - a)^n\)이 수렴하는 \(x\)의 모양은 다음 셋 중 하나이다.

  • \(x = a\)에서만 수렴한다.
  • 모든 \(x\)에서 수렴한다.
  • 어떤 \(R > 0\)이 있어 \(|x - a| < R\)이면 수렴하고 \(|x - a| > R\)이면 발산한다.

이 \(R\)을 수렴 반지름이라 한다(앞의 두 경우는 \(R = 0\), \(R = \infty\)).

수렴하는 \(x\)는 중심 \(a\)에서 거리 \(R\) 안에 모여 있습니다. 경계 \(x = a \pm R\)에서는 수렴할 수도 발산할 수도 있어서 따로 확인합니다. 수렴하는 \(x\) 전체를 수렴 구간이라 합니다.

구하는 방법: 비 판정법을 \(|a_{n+1}/a_n|\)에 \(x\)를 남겨 둔 채 쓰고, 그 극한이 1보다 작아지는 \(x\)의 범위를 구합니다. 그다음 양 끝점을 따로 넣어 봅니다.

예제 8.6.2

\(\displaystyle\sum_{n=1}^\infty\frac{(x - 3)^n}{n}\)의 수렴 반지름과 수렴 구간을 구하여라.

풀이. \(\left|\dfrac{(x - 3)^{n+1}/(n + 1)}{(x - 3)^n/n}\right| = \dfrac{n}{n + 1}|x - 3| \to |x - 3|\). \(|x - 3| < 1\)이면 수렴하므로 \(R = 1\), 곧 \(2 < x < 4\)에서 수렴합니다.

끝점: \(x = 4\)이면 \(\sum\frac1n\) (조화급수) 발산. \(x = 2\)이면 \(\sum\frac{(-1)^n}{n}\) 교대급수로 수렴. 수렴 구간은 \([2, 4)\).

예제 8.6.3

\(\sum\frac{x^n}{n!}\)과 \(\sum n!\,x^n\)의 수렴 반지름을 구하여라.

풀이. 앞의 것: 비 \(\frac{|x|}{n + 1} \to 0 < 1\)이 모든 \(x\)에서 성립하므로 \(R = \infty\). (이 급수는 \(e^x\)이며 8.8절에서 확인합니다.) 뒤의 것: 비 \((n + 1)|x| \to \infty\) (\(x \ne 0\))이므로 \(x = 0\)에서만 수렴, \(R = 0\).

주의비 판정법은 경계(\(L = 1\))에서는 아무것도 알려 주지 않습니다. 양 끝점을 넣어 \(p\)-급수, 교대급수 판정법 등으로 따로 판정해야 수렴 구간이 정해집니다.
요약
  1. 거듭제곱급수는 수렴하는 \(x\)에서 정의되는 함수다. \(\sum x^n = \frac{1}{1 - x}\) (\(|x| < 1\)).
  2. 수렴 반지름 \(R\): 비 판정법의 극한 \(< 1\)인 범위.
  3. 끝점은 따로 판정한다.

8.6.3연습문제

기본

  1. \(\sum\frac{x^n}{2^n}\)의 수렴 반지름과 수렴 구간은?
    답

    \(R = 2\). 끝점에서 항이 \(\pm1\)이라 발산. 구간 \((-2, 2)\).

응용

  1. \(\sum\frac{(-1)^nx^n}{n^2}\)의 수렴 구간을 구하여라.
    답

    \(R = 1\). \(x = \pm1\)에서 \(\sum\frac{1}{n^2}\)로 절대수렴. 구간 \([-1, 1]\).

8.6.2

예제거듭제곱급수의 수렴 반지름과 수렴 구간

비 판정 · 끝점 따로 확인

다루는 성취기준 [공통1-08-06]

알아 둘 사실

정리

거듭제곱급수 \(\sum c_n(x - a)^n\)에 대해 다음 중 하나가 성립한다. (i) \(x = a\)에서만 수렴 (\(R = 0\)). (ii) 모든 \(x\)에서 수렴 (\(R = \infty\)). (iii) 어떤 \(R > 0\)이 있어 \(|x - a| < R\)에서 절대수렴, \(|x - a| > R\)에서 발산.

근거의 핵심: \(x_0\)에서 수렴하면 항 \(c_nx_0^n\)이 유계이고, \(|x| < |x_0|\)인 \(x\)에서는 \(|c_nx^n| \le M\left|\frac{x}{x_0}\right|^n\)이라 기하급수와 비교됩니다. 그래서 수렴하는 영역은 \(a\)를 중심으로 한 구간입니다. 끝점 \(x = a \pm R\)에서는 무엇이든 일어날 수 있어서 따로 확인해야 합니다.

\(\displaystyle\sum_{n=1}^\infty\frac{(x - 2)^n}{n\,3^n}\)의 수렴 반지름과 수렴 구간을 구하세요.

풀이

  1. \(a_n = \frac{(x-2)^n}{n3^n}\). \(\left|\frac{a_{n+1}}{a_n}\right| = \frac{|x - 2|^{n+1}}{(n+1)3^{n+1}}\cdot\frac{n3^n}{|x-2|^n} = \frac{n}{n+1}\cdot\frac{|x - 2|}{3} \to \frac{|x-2|}{3}\).
    \(x\)를 고정하고 수열로 보아 비 판정.
  2. \(\frac{|x-2|}{3} < 1 \iff |x - 2| < 3\)에서 절대수렴, \(> 1\)이면 발산. 따라서 \(R = 3\), 중심 2.
    비 판정의 결론.
  3. 끝점 \(x = 5\): \(\sum\frac{3^n}{n3^n} = \sum\frac1n\). 발산.
    \(\rho = 1\)이라 비 판정이 말해 주지 않는다. 대입해서 알려진 급수로.
  4. 끝점 \(x = -1\): \(\sum\frac{(-3)^n}{n3^n} = \sum\frac{(-1)^n}{n}\). 교대급수 판정으로 수렴(조건수렴).
    8-03 카드.
  5. 수렴 구간 \([-1, 5)\).
    열린구간 \((-1, 5)\)에 수렴하는 끝점만 붙인다.

의미

수렴 구간 안에서 거듭제곱급수는 "끝없는 다항식"처럼 미분, 적분할 수 있습니다. 수렴 반지름은 함수가 망가지는 가장 가까운 점까지의 거리입니다. \(\frac{1}{1 + x^2}\)은 실수 전체에서 매끄러운데도 반지름이 1인데, 복소수 \(\pm i\)에서 분모가 0이 되기 때문입니다(복소해석학).

검산

\(x = 2\) (중심)에서는 모든 항이 0이라 당연히 수렴합니다. \(t = \frac{x - 2}{3}\)로 두면 급수는 \(\sum\frac{t^n}{n} = -\ln(1 - t)\)이고, 이것은 \(-1 \le t < 1\)에서 수렴하는 잘 알려진 급수입니다. \(t = -1, 1\)이 \(x = -1, 5\)에 대응하므로 결과가 맞습니다.

수렴 구간 안에서 할 수 있는 것

\(|x - a| < R\)에서 거듭제곱급수는 항별로 미분, 적분할 수 있고 수렴 반지름은 그대로입니다(끝점의 수렴 여부는 바뀔 수 있음). 예: \(\frac{1}{1 - x} = \sum x^n\) (\(|x| < 1\))을 적분하면 \(-\ln(1 - x) = \sum\frac{x^{n+1}}{n+1}\), 미분하면 \(\frac{1}{(1 - x)^2} = \sum nx^{n-1}\).

흔한 오해

  • 끝점을 확인하지 않음: \(\sum\frac{x^n}{n^2}\)은 양 끝 수렴 \([-1,1]\), \(\sum x^n\)은 양 끝 발산 \((-1,1)\), \(\sum\frac{x^n}{n}\)은 한쪽만 \([-1, 1)\). \(R\)이 같아도 구간이 다릅니다.
  • \(|x - a|\)의 계수: \(\sum(2x)^n\)은 \(|2x| < 1\), 곧 \(R = \frac12\)입니다.
