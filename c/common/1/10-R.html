10.R.1

연습미분방정식 맛보기 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통1-10-01] [공통1-10-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 모형90 °C인 커피를 20 °C인 방에 두었더니 10분 뒤 60 °C가 되었습니다. 뉴턴의 냉각 법칙 \(T' = -k(T - 20)\)으로 \(k\)를 구하고, 커피가 40 °C가 되는 때를 구하세요. [10-01]

    힌트 1

    해는 \(T = 20 + 70e^{-kt}\)입니다(10.1절 예제).

    힌트 2

    \(t = 10\)에서 \(40 = 70e^{-10k}\).

    풀이

    \(k = \tfrac1{10}\ln\tfrac74 = 0.0560\)/분. \(20 = 70e^{-kt}\)에서 \(t = \dfrac{\ln3.5}{0.0560} = 22.4\)분. 처음 10분에 30 °C 내렸지만, 다음 20 °C를 내리는 데는 12.4분이 걸립니다. 방 온도와의 차이가 줄수록 느리게 식기 때문입니다.

  2. 개념\(y' = y(2 - y)\)의 평형해를 찾고, 방향장으로 각 평형해 근처의 해가 다가오는지 멀어지는지 말하세요. [10-01]

    힌트 1

    평형해는 기울기가 0인 상수 해입니다.

    힌트 2

    \(y\)가 0과 2 사이, 2보다 큼, 0보다 작음일 때 \(y'\)의 부호를 봅니다.

    풀이

    평형해 \(y = 0\), \(y = 2\). \(0 < y < 2\)에서 \(y' > 0\), \(y > 2\)에서 \(y' < 0\)이므로 2 근처의 해는 2로 다가옵니다(안정). \(y < 0\)에서 \(y' < 0\)이므로 0 근처의 해는 0에서 멀어집니다(불안정).

  3. 계산\(y' = xy\), \(y(0) = 2\)를 푸세요. [10-02]

    힌트 1

    \(\dfrac{dy}{y} = x\,dx\)로 나누어 적분합니다.

    힌트 2

    \(\ln|y| = \tfrac{x^2}2 + C\).

    풀이

    \(y = Ae^{x^2/2}\), \(A = 2\). 해는 \(y = 2e^{x^2/2}\). 검산: \(y' = 2xe^{x^2/2} = xy\).

  4. 계산\(y' = y^2\), \(y(0) = 1\)을 푸세요. 이 해는 어디까지 정의되나요? [10-02]

    힌트 1

    \(\dfrac{dy}{y^2} = dx\).

    힌트 2

    \(-\dfrac1y = x + C\).

    풀이

    \(C = -1\)이므로 \(y = \dfrac{1}{1 - x}\). \(x \to 1^-\)일 때 \(y \to \infty\)입니다. 식 \(y' = y^2\)은 모든 점에서 멀쩡한데도 해가 유한한 시간에 무한대로 갑니다. 지수 증가(\(y' = y\))보다 훨씬 빠른 증가입니다.

  5. 계산세균이 \(P' = 0.5P(1 - P/1000)\)을 따라 자랍니다(시간 단위: 시간). \(P(0) = 10\)일 때 \(P(t)\)를 쓰고, 500이 되는 때를 구하세요. [10-02]

    힌트 1

    로지스틱 해 \(P = \dfrac{K}{1 + Ae^{-rt}}\), \(A = \dfrac{K - P_0}{P_0}\).

    힌트 2

    \(A = 99\). \(P = 500\)이면 \(1 + 99e^{-0.5t} = 2\).

    풀이

    \(P(t) = \dfrac{1000}{1 + 99e^{-0.5t}}\). \(t = \dfrac{\ln99}{0.5} = 9.19\)시간. 이때가 증가 속도가 가장 큰 때(\(rK/4 = 125\)/시간)입니다.

  6. 판단“로지스틱 방정식의 해는 모두 \(P = \dfrac{K}{1 + Ae^{-rt}}\) 꼴로 나타낼 수 있다.” 판단하세요. [10-02]

    힌트 1

    \(P = 0\)(개체가 하나도 없음)도 해인가요? 위 식에서 \(A\)를 어떻게 잡으면 0이 되나요?

    힌트 2

    변수를 나눌 때 \(P(K - P)\)로 나누었습니다. 이것이 0인 경우는?

    풀이

    틀렸습니다. 평형해 \(P = 0\)은 어떤 유한한 \(A\)로도 나오지 않습니다. 변수를 나눌 때 \(P(K - P)\)로 나누면서 \(P = 0\)인 경우를 빼 버렸기 때문입니다(\(P = K\)는 \(A = 0\)으로 나옵니다). 변수분리를 한 뒤에는 나누는 식이 0이 되는 상수 해를 따로 확인해야 합니다.
