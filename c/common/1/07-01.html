7.1.1

예제얇게 썰어 더하기: 넓이와 회전체의 부피

원판법 · 와셔법 · 원통껍질법

다루는 성취기준 [공통1-07-01]

한 가지 원리

모든 응용은 같은 순서로 세웁니다. ① 대상을 얇은 조각으로 자른다. ② 한 조각의 양을 근사한다(직사각형, 원판, 원통). ③ 리만 합으로 더하고 극한을 취해 적분한다. 공식을 외우기보다 이 순서로 매번 식을 세우면 실수가 줄어듭니다.

  • 두 곡선 사이 넓이: 폭 \(dx\), 높이 (위 − 아래) → \(\int_a^b [f(x) - g(x)]\,dx\).
  • 원판·와셔 (회전축에 수직으로 자름): 바깥 반지름 \(R\), 안 반지름 \(r\) → \(\int\pi(R^2 - r^2)\,dx\).
  • 원통껍질 (회전축에 평행으로 자름): 반지름 \(\rho\), 높이 \(h\), 두께 \(dx\)인 껍질을 펼치면 \(2\pi\rho\cdot h\cdot dx\) → \(\int 2\pi\rho h\,dx\).
먼저 예측

같은 영역을 \(x\)축 둘레로 돌린 입체와 \(y\)축 둘레로 돌린 입체 중 어느 쪽 부피가 클까요?

예측 확인

\(x\)축 쪽(\(\frac{64\pi}{15} \approx 13.4\))이 \(y\)축 쪽(\(\frac{8\pi}{3} \approx 8.4\))보다 큽니다. 영역이 \(y\) 방향으로 높이 4까지 뻗어 있어 \(x\)축에서 멀리 떨어진 부분이 많기 때문입니다.

곡선 \(y = x^2\)과 \(y = 2x\)로 둘러싸인 영역 \(D\)에 대해 (가) 넓이 (나) \(x\)축 둘레로 돌린 부피 (다) \(y\)축 둘레로 돌린 부피를 구하세요.

풀이

  1. 교점: \(x^2 = 2x \iff x = 0, 2\). \([0, 2]\)에서 \(2x \ge x^2\) (예: \(x = 1\)에서 \(2 > 1\)).
    적분 구간과 위아래를 먼저 정한다.
  2. (가) \(\int_0^2(2x - x^2)\,dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = 4 - \frac83 = \frac43\).
    세로 띠의 높이 = 위 − 아래.
  3. (나) \(x\)축에 수직으로 자르면 와셔: \(R = 2x\), \(r = x^2\). \(V = \pi\int_0^2(4x^2 - x^4)\,dx = \pi\left(\frac{32}{3} - \frac{32}{5}\right) = \frac{64\pi}{15}\).
    가운데가 비어 있다(아래 곡선과 축 사이). \((R - r)^2\)이 아니라 \(R^2 - r^2\).
  4. (다) \(y\)축 둘레: 세로 띠(\(x\)에서, 폭 \(dx\))를 돌리면 원통껍질. \(\rho = x\), \(h = 2x - x^2\).
    \(y\)축에 평행한 띠라 껍질이 된다. 와셔로 하면 \(x\)를 \(y\)로 풀어야 한다(\(x = \sqrt y\), \(x = \frac y2\)).
  5. \(V = \int_0^2 2\pi x(2x - x^2)\,dx = 2\pi\left[\frac{2x^3}{3} - \frac{x^4}{4}\right]_0^2 = 2\pi\left(\frac{16}{3} - 4\right) = \frac{8\pi}{3}\).
    껍질 공식.

의미

넓이, 부피, 그리고 7단원의 모든 응용은 "얇게 썰어 더한다"는 한 원리입니다. 부피를 구하는 방법이 둘(원판, 껍질)이라도 같은 입체이므로 값이 같아야 하고, 이것이 계산을 검산하는 좋은 방법입니다.

검산

(다)를 와셔로 다시: \(y \in [0, 4]\)에서 바깥 \(R = \sqrt y\), 안 \(r = \frac y2\). \(\pi\int_0^4\left(y - \frac{y^2}{4}\right)dy = \pi\left(8 - \frac{16}{3}\right) = \frac{8\pi}{3}\). 두 방법이 같은 값을 줍니다.

(나)를 파푸스 정리(부피 = 넓이 × 무게중심이 도는 거리)로도 확인할 수 있습니다. 무게중심의 \(y\)좌표는 7-03 카드에서 구합니다.

흔한 오해

  • 반지름을 축에서 재지 않음: 축이 \(y = -1\)이면 반지름은 \(y + 1\)입니다.
  • 위아래가 바뀌는 구간: 두 곡선이 구간 안에서 교차하면 교점에서 나눠 적분합니다.
