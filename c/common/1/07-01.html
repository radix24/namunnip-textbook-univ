7.1.1움직이는 점의 자취

운동장을 도는 사람의 위치는 시각 \(t\)에 따라 \(x\)좌표와 \(y\)좌표가 각각 정해집니다. 이렇게 셋째 변수 \(t\)(매개변수)로 \(x = f(t)\), \(y = g(t)\)를 주어 그리는 곡선을 매개변수 곡선이라 합니다. \(y = (x\text{의 식})\)으로 쓸 수 없는 곡선(원, 자기 자신과 엇갈리는 곡선)도 나타낼 수 있고, 곡선을 지나는 방향과 빠르기까지 담고 있습니다.

예제 7.1.1

\(x = \cos t\), \(y = \sin t\) (\(0 \le t \le 2\pi\))와 \(x = \sin2t\), \(y = \cos2t\) (\(0 \le t \le 2\pi\))는 어떤 곡선인가?

풀이. 둘 다 \(x^2 + y^2 = 1\)이므로 단위원 위에 있습니다. 앞의 것은 \((1, 0)\)에서 출발해 시계 반대 방향으로 한 바퀴 돕니다. 뒤의 것은 \((0, 1)\)에서 출발해 시계 방향으로 두 바퀴 돕니다. 같은 곡선이라도 매개변수가 다르면 움직임이 다릅니다.

예제 7.1.2 (사이클로이드)

반지름 \(r\)인 바퀴가 직선 위를 굴러갈 때 바퀴 테두리의 한 점이 그리는 곡선을 매개변수로 나타내어라.

풀이. 바퀴가 각 \(\theta\)만큼 돌면 중심은 \(r\theta\)만큼 앞으로 가서 \((r\theta, r)\)에 있습니다. 처음 바닥에 닿아 있던 점은 중심에서 보아 각 \(\theta\)만큼 돌아갔으므로 위치는 \(x = r\theta - r\sin\theta\), \(y = r - r\cos\theta\)입니다. 한 바퀴(\(0 \le \theta \le 2\pi\))에 아치 하나를 그립니다.

7.1.2접선의 기울기

\(y\)를 \(x\)의 함수로 보면 연쇄법칙으로 \(\dfrac{dy}{dt} = \dfrac{dy}{dx}\cdot\dfrac{dx}{dt}\)이므로

정리 7.1.3 \[\frac{dy}{dx} = \frac{dy/dt}{dx/dt} \qquad \left(\frac{dx}{dt} \ne 0\right).\]

\(\frac{dy}{dt} = 0\)이고 \(\frac{dx}{dt} \ne 0\)이면 수평 접선, \(\frac{dx}{dt} = 0\)이고 \(\frac{dy}{dt} \ne 0\)이면 수직 접선입니다.

예제 7.1.4

사이클로이드(\(r = 1\))의 \(\theta = \frac\pi3\)에서 접선의 기울기를 구하고, 수평 접선이 생기는 곳을 찾아라.

풀이. \(\frac{dx}{d\theta} = 1 - \cos\theta\), \(\frac{dy}{d\theta} = \sin\theta\). 기울기 \(\dfrac{\sin\theta}{1 - \cos\theta}\)는 \(\theta = \frac\pi3\)에서 \(\dfrac{\sqrt3/2}{1/2} = \sqrt3\). 수평 접선은 \(\sin\theta = 0\)이고 \(1 - \cos\theta \ne 0\)인 \(\theta = \pi\)(아치의 꼭대기)입니다. \(\theta = 0, 2\pi\)에서는 둘 다 0이 되어 곡선이 뾰족해집니다(첨점).

요약
  1. 매개변수 곡선은 \(x = f(t)\), \(y = g(t)\): 자취와 함께 방향·빠르기를 담는다.
  2. \(\frac{dy}{dx} = \frac{dy/dt}{dx/dt}\). 분자 0이면 수평, 분모 0이면 수직 접선.

7.1.3연습문제

기본

  1. \(x = t^2\), \(y = t^3\)에서 \(t = 1\)일 때 접선의 방정식을 구하여라.
    답

    \(\frac{dy}{dx} = \frac{3t^2}{2t} = \frac32\). 접선 \(y - 1 = \frac32(x - 1)\).

  2. \(x = 2\cos t\), \(y = 3\sin t\)는 어떤 곡선인가?
    답

    \(\frac{x^2}{4} + \frac{y^2}{9} = 1\), 타원.

7.1.2

예제매개변수로 그린 곡선의 접선과 길이

사이클로이드

다루는 성취기준 [공통1-07-01]

도구

곡선이 \(x = x(t)\), \(y = y(t)\)로 주어지면 \(t\)는 시간, \((x(t), y(t))\)는 그 시각의 위치로 읽을 수 있습니다.

  • 기울기: \(\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}\) (\(\dot x \ne 0\)). 연쇄 법칙 \(\dot y = \frac{dy}{dx}\dot x\)에서 나온다.
  • 이계도함수: \(\dfrac{d^2y}{dx^2} = \dfrac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{dx/dt}\). \(\frac{\ddot y}{\ddot x}\)가 아니다.
  • 길이: \(ds^2 = dx^2 + dy^2\)이므로 \(L = \displaystyle\int_\alpha^\beta\sqrt{\dot x^2 + \dot y^2}\,dt\) (곡선을 한 번만 지날 때). 속력 \(\sqrt{\dot x^2 + \dot y^2}\)을 시간으로 적분한 이동 거리와 같다.

반지름 \(r\)인 바퀴가 \(x\)축 위를 미끄러지지 않고 구를 때 바퀴 위 한 점이 그리는 곡선(사이클로이드) \(x = r(t - \sin t)\), \(y = r(1 - \cos t)\)에 대해 (가) \(t = \frac\pi3\)에서의 접선 (나) 접선이 수직이 되는 점 (다) 한 아치(\(0 \le t \le 2\pi\))의 길이를 구하세요.

풀이

  1. \(\dot x = r(1 - \cos t)\), \(\dot y = r\sin t\). \(\dfrac{dy}{dx} = \dfrac{\sin t}{1 - \cos t}\).
    기울기 공식. \(r\)은 약분.
  2. (가) \(t = \frac\pi3\): 점 \(\left(r\left(\frac\pi3 - \frac{\sqrt3}{2}\right), \frac r2\right)\), 기울기 \(\frac{\sqrt3/2}{1/2} = \sqrt3\). 접선 \(y - \frac r2 = \sqrt3\left(x - r\left(\frac\pi3 - \frac{\sqrt3}2\right)\right)\).
    점과 기울기를 모두 \(t\)에서 계산.
  3. (나) \(\dot x = 0 \iff \cos t = 1 \iff t = 2k\pi\). 이때 \(\dot y = 0\)도 되어 \(\frac00\)꼴.
    \(\dot x = 0\)이면서 \(\dot y \ne 0\)이면 수직 접선, 둘 다 0이면 따로 조사.
  4. \(t \to 0^+\)에서 \(\frac{\sin t}{1 - \cos t} = \frac{\cos(t/2)}{\sin(t/2)} \to +\infty\). 점 \((2k\pi r, 0)\)은 바닥에 닿는 뾰족점이고, 양쪽에서 접선 방향이 수직으로 모인다.
    반각 공식 \(\sin t = 2\sin\frac t2\cos\frac t2\), \(1 - \cos t = 2\sin^2\frac t2\).
  5. (다) \(\dot x^2 + \dot y^2 = r^2[(1 - \cos t)^2 + \sin^2t] = 2r^2(1 - \cos t) = 4r^2\sin^2\frac t2\).
    \(\cos^2 + \sin^2 = 1\), 반각 공식.
  6. \(L = \int_0^{2\pi}2r\left|\sin\frac t2\right|dt = 2r\left[-2\cos\frac t2\right]_0^{2\pi} = 8r\).
    \([0, 2\pi]\)에서 \(\sin\frac t2 \ge 0\)이라 절댓값을 뗀다. 근호를 벗길 때 늘 부호를 확인한다.

의미

매개곡선은 "점이 시간에 따라 어디 있는가"를 적은 것이라 운동을 그대로 나타냅니다. 기울기는 속도의 방향, 길이는 속력의 적분입니다. 삼각함수로 정의된 사이클로이드의 길이가 깔끔한 \(8r\)이 되는 것은 역사적으로도 놀라운 결과였습니다.

검산

한 아치의 가로 폭은 \(2\pi r \approx 6.28r\), 높이는 \(2r\)입니다. 길이 \(8r\)은 "가로로 곧게 간 길이"보다 길고, "위로 \(2r\), 옆으로 \(2\pi r\), 아래로 \(2r\)"의 합 \(10.28r\)보다 짧습니다. 맞습니다. 이 결과는 1658년 렌(Wren)이 처음 구했습니다.

흔한 오해

  • 곡선을 여러 번 지나는 구간: \(x = \cos t, y = \sin t\), \(0 \le t \le 4\pi\)로 길이를 구하면 \(4\pi\)로 원둘레의 두 배가 나옵니다.
