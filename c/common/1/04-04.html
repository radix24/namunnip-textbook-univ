왜 컴퓨터로 확인하는가

\(\int_0^2 e^{-x^2}dx\)는 원시함수를 기본 함수로 쓸 수 없고, 실험에서 얻은 자료는 식조차 없습니다. 그래도 값은 필요합니다. 또 손으로 푼 답이 맞는지 확인하는 가장 빠른 방법은 컴퓨터로 같은 양을 근사해 보는 것입니다. 다행히 미분과 적분의 정의 자체가 계산 방법을 알려 줍니다. 극한을 취하기 직전의 식을 작은 간격으로 계산하면 됩니다.

4.4.1차분으로 도함수 어림하기

도함수의 정의 \(f'(a) = \lim_{h\to0}\dfrac{f(a + h) - f(a)}h\)에서 극한을 빼면 계산할 수 있는 식이 남습니다.

앞쪽 차분 \(D_+(h) = \dfrac{f(a + h) - f(a)}h\): 정의 그대로의 식.

가운데 차분 \(D_0(h) = \dfrac{f(a + h) - f(a - h)}{2h}\): 양쪽으로 같은 거리만큼 나간 할선의 기울기.

두 식이 \(f'(a)\)와 얼마나 다른지는 테일러 전개(8.8절) \(f(a \pm h) = f(a) \pm hf'(a) + \tfrac{h^2}2f''(a) \pm \tfrac{h^3}6f'''(a) + \cdots\)로 알 수 있습니다.

정리 4.4.1 (차분의 절단 오차)

\(D_+(h) - f'(a) \approx \dfrac h2f''(a)\), \(D_0(h) - f'(a) \approx \dfrac{h^2}6f'''(a)\).

\(D_+\): \(f(a + h) - f(a) = hf'(a) + \tfrac{h^2}2f''(a) + \cdots\)를 \(h\)로 나누면 \(f'(a) + \tfrac h2f''(a) + \cdots\). \(D_0\): \(f(a + h) - f(a - h)\)에서 짝수 차 항(\(f(a)\), \(h^2\) 항)은 지워지고 \(2hf'(a) + \tfrac{h^3}3f'''(a) + \cdots\)가 남으므로, \(2h\)로 나누면 \(f'(a) + \tfrac{h^2}6f'''(a) + \cdots\). ∎

그래서 \(h\)를 10분의 1로 줄이면 앞쪽 차분의 오차는 10분의 1, 가운데 차분은 100분의 1이 됩니다. 같은 계산량으로 가운데 차분이 훨씬 정확합니다.

예제 4.4.2

\(f(x) = \sin x\), \(a = 1\), \(h = 0.01\)일 때 두 차분의 값과 오차를 구하여라.

풀이. 참값은 \(\cos1 = 0.540302\ldots\)입니다. \(D_+ = \dfrac{\sin1.01 - \sin1}{0.01} = 0.536086\), 오차 \(-4.22\times10^{-3}\)이고 정리 4.4.1의 예측 \(\tfrac{0.01}2(-\sin1) = -4.21\times10^{-3}\)과 맞습니다. \(D_0 = 0.540293\), 오차 \(-9.0\times10^{-6}\)으로 예측 \(\tfrac{0.0001}6(-\cos1) = -9.0\times10^{-6}\)과 맞습니다.

4.4.2간격을 너무 줄이면 생기는 일

그렇다면 \(h = 10^{-15}\)처럼 아주 작게 하면 될까요? 컴퓨터의 실수(배정밀도)는 유효숫자가 약 16자리입니다. \(\sin1.000000000000001\)과 \(\sin1\)은 앞의 15자리가 같아서, 빼면 믿을 수 있는 자리가 거의 남지 않습니다. 이 반올림 오차는 대략 \(\dfrac{10^{-16}}h\)이라서 \(h\)가 작을수록 커집니다. 절단 오차(\(h\)에 비례)와 반올림 오차(\(1/h\)에 비례)의 합이 가장 작은 곳은 앞쪽 차분에서 \(h \approx 10^{-8}\), 가운데 차분에서 \(h \approx 10^{-5}\) 근처입니다.

수학의 극한 \(h \to 0\)과 컴퓨터의 "작은 \(h\)"는 다릅니다. 수치 계산에서는 언제나 알맞은 크기를 골라야 하고, 결과가 \(h\)를 바꿔도 안정한지 확인해야 합니다.

4.4.3리만 합으로 정적분 어림하기

정적분은 리만 합의 극한입니다(4.1절). 구간을 \(n\)등분하고 각 칸의 가운데 점 높이를 쓰는 가운데 합 \(M_n = h\sum_{i=1}^nf\!\left(a + (i - \tfrac12)h\right)\), \(h = (b - a)/n\)이 간단하고 정확합니다. 오차는 \(h^2\)에 비례합니다. 더 정확한 사다리꼴·심프슨 공식은 5.6절에서 다룹니다.

예제 4.4.3

\(\int_0^2e^{-x^2}dx\)를 가운데 합으로 \(n = 10, 100\)일 때 계산하는 파이썬 코드를 쓰고, 결과를 해석하여라.

import math
def midpoint(f, a, b, n):
    h = (b - a) / n
    return h * sum(f(a + (i - 0.5) * h) for i in range(1, n + 1))
f = lambda x: math.exp(-x * x)
for n in (10, 100):
    print(n, midpoint(f, 0, 2, n))
# 10  0.882202...   100  0.882083...   (참값 0.882081...)

풀이. \(n = 10\)에서 0.882202, \(n = 100\)에서 0.882083으로, \(n\)을 10배 하면 오차가 약 100분의 1(\(1.2\times10^{-4} \to 1.2\times10^{-6}\))이 됩니다. 참값은 \(\tfrac{\sqrt\pi}2\operatorname{erf}(2) = 0.882081\)이고, 정규분포의 확률 계산(공통7 5.2절)이 바로 이런 적분입니다.

4.4.4검산 습관

손 계산과 컴퓨터 계산은 서로를 검산합니다. 손으로 \(\frac{d}{dx}\int_0^{x^2}\cos t\,dt = 2x\cos x^2\)을 얻었다면, \(x = 1\)에서 가운데 차분으로 \(F(x) = \int_0^{x^2}\cos t\,dt = \sin x^2\)을 미분해 \(2\cos1 = 1.0806\)과 같은지 확인할 수 있습니다. 그래프를 그려 보는 것도 좋은 검산입니다. 극값의 위치, 부호, 대칭이 답과 맞는지 눈으로 보세요.

이 절은 서강대 미적분학 실습(MAT1050, 미적분학 연습문제를 컴퓨터로 풀기)의 내용을 보충한 것입니다. 이 절 뒤의 실습 카드에서 \(h\)에 따른 오차의 V자 그래프를 직접 볼 수 있습니다.

요약
  1. 도함수는 차분, 정적분은 리만 합으로 어림한다. 가운데 차분의 오차는 \(h^2\), 앞쪽 차분은 \(h\)에 비례한다.
  2. 컴퓨터 실수의 유효숫자는 약 16자리이므로 \(h\)를 너무 줄이면 반올림 오차가 커진다.
  3. 가운데 합은 \(n\)을 10배 하면 오차가 약 100분의 1이 된다.
  4. 손 계산의 답은 수치와 그래프로 검산한다.
연습문제
  1. 기본 \(f(x) = x^3\), \(a = 2\), \(h = 0.1\)에서 앞쪽 차분과 가운데 차분을 손으로 계산하고 참값 12와 비교하여라.
    답\(D_+ = (9.261 - 8)/0.1 = 12.61\), \(D_0 = (9.261 - 6.859)/0.2 = 12.01\). 가운데 차분의 오차 0.01은 \(h^2f'''/6 = 0.01\)과 같다.
  2. 응용 \(\int_0^1\sqrt x\,dx = 2/3\)을 가운데 합으로 계산하면 \(n\)을 10배 해도 오차가 100분의 1로 줄지 않는다. 이유는?
    답\(\sqrt x\)는 \(x = 0\)에서 도함수가 무한대라 오차 공식의 가정(이계도함수가 유계)이 깨진다. 오차는 대략 \(n^{-1.5}\)로 줄어 10배마다 약 30분의 1이다.
  3. 심화 앞쪽 차분의 전체 오차를 \(E(h) = \dfrac h2M + \dfrac{\varepsilon}h\)(\(M = |f''|\), \(\varepsilon \approx 10^{-16}\))로 보고, \(E\)를 최소로 하는 \(h\)를 구하여라.
    답\(E'(h) = M/2 - \varepsilon/h^2 = 0\)에서 \(h = \sqrt{2\varepsilon/M} \approx 1.4\times10^{-8}\) (\(M \approx 1\)).

4.4.2

실습h를 아주 작게 하면 컴퓨터의 도함수는 더 정확해질까?

실습 · 컴퓨터로 도함수 어림하기

다루는 성취기준 [공통1-04-04]

목표

도함수의 정의 \(f'(a) = \lim_{h\to0}\dfrac{f(a + h) - f(a)}{h}\)를 컴퓨터로 그대로 계산하면, \(h\)를 줄일수록 좋아지다가 어느 순간 다시 나빠집니다. 수학의 극한과 컴퓨터 계산의 차이를 직접 보고, 알맞은 \(h\)를 고르는 법을 익힙니다. 성취기준 [공통1-04-04].

준비

  • 앞쪽 차분 \(\dfrac{f(a + h) - f(a)}{h}\): 정의 그대로의 식. 보라 선.
  • 가운데 차분 \(\dfrac{f(a + h) - f(a - h)}{2h}\): 양쪽 기울기의 평균. 주황 선.
  • 그래프는 가로가 \(\log_{10} h\), 세로가 \(\log_{10}|\text{오차}|\)입니다. 오른쪽이 큰 \(h\), 왼쪽이 아주 작은 \(h\)입니다.
  • 컴퓨터의 실수(배정밀도)는 유효숫자가 약 16자리입니다. 거의 같은 두 수를 빼면 앞자리가 지워지고 반올림 오차만 남습니다(공통10 6.1절).

절차

  1. \(\sin x\), \(x = 1\)에서 \(h = 10^{-1}, 10^{-2}, 10^{-4}, 10^{-8}, 10^{-12}\)일 때 두 차분의 오차를 기록합니다.
  2. 오차가 가장 작아지는 \(h\)를 두 방법에 대해 찾습니다.
  3. 아래 파이썬 코드를 실행해 화면의 값과 같은지 봅니다.
import math
a, d = 1.0, math.cos(1.0)
for k in [1, 2, 4, 5, 6, 8, 10, 12]:
    h = 10.0 ** (-k)
    fw = (math.sin(a + h) - math.sin(a)) / h
    ce = (math.sin(a + h) - math.sin(a - h)) / (2 * h)
    print(k, f"{fw - d:.2e}", f"{ce - d:.2e}")

기대 결과

  • \(\sin x\), \(x = 1\): 앞쪽 차분의 오차는 \(h = 10^{-1}, 10^{-2}, 10^{-4}\)에서 \(-4.29\times10^{-2}\), \(-4.22\times10^{-3}\), \(-4.21\times10^{-5}\)로 \(h\)에 비례해 줄고, \(h = 10^{-8}\) 근처(\(-2.97\times10^{-9}\))에서 가장 작습니다. \(h = 10^{-12}\)에서는 오히려 \(4.32\times10^{-5}\)로 커집니다.
  • 가운데 차분의 오차는 \(h^2\)에 비례해 훨씬 빨리 줄고(\(10^{-2}\)에서 \(-9.00\times10^{-6}\)), \(h = 10^{-5}\) 근처에서 \(10^{-11}\) 정도로 가장 작습니다.
  • 그래프는 V자 모양입니다. 오른쪽 경사는 식 자체의 오차(절단 오차), 왼쪽 경사는 뺄셈에서 생기는 반올림 오차입니다.

분석

  1. 앞쪽 차분의 오차가 \(\dfrac{h}{2}|f''(a)|\) 정도라는 것을 테일러 전개(8.8절)로 보이고, \(h = 10^{-2}\)일 때 \(\dfrac{h}{2}\sin 1\)과 위 값을 비교해 보세요.
  2. 반올림 오차가 대략 \(10^{-16}/h\)라면, 두 오차의 합이 가장 작은 \(h\)는 어느 정도인가요? 그래프의 V자 바닥과 비교해 보세요.
