4.4.1

예제로피탈 정리와 부정형 바꾸기

0/0 · ∞/∞ · 0·∞ · 1^∞

다루는 성취기준 [공통1-04-04]

정리 · 로피탈

\(f, g\)가 \(a\) 근처(\(a\) 제외)에서 미분 가능하고 \(g'(x) \ne 0\)이며, \(\lim_{x\to a} f = \lim_{x\to a} g = 0\) (또는 둘 다 \(\pm\infty\))일 때, \(\lim_{x\to a}\dfrac{f'(x)}{g'(x)} = L\)이 존재하면(\(\pm\infty\) 포함)

\[\lim_{x\to a}\frac{f(x)}{g(x)} = L.\]

\(a\)가 \(\pm\infty\)이거나 한쪽 극한이어도 성립한다. 증명은 코시 평균값 정리를 쓴다(아래 참고).

조건 세 가지를 매번 확인

  1. 부정형인가\(\frac00\) 또는 \(\frac\infty\infty\)여야 합니다. \(\lim\frac{x+1}{x} \ (x\to 0^+)\)에 쓰면 \(\frac{1}{1} = 1\)이라는 틀린 답이 나옵니다(실제 \(+\infty\)).
  2. \(f'/g'\)의 극한이 존재하는가존재하지 않으면 정리는 아무 말도 하지 않습니다. 예: \(\frac{x + \sin x}{x}\ (x\to\infty)\)는 1로 가지만, \(\frac{1 + \cos x}{1}\)은 극한이 없습니다.
  3. 몫의 미분이 아니다\(\left(\frac fg\right)'\)이 아니라 분자, 분모를 따로 미분합니다.

문제. (가) \(\displaystyle\lim_{x\to0}\frac{x - \sin x}{x^3}\) (나) \(\displaystyle\lim_{x\to0^+} x\ln x\) (다) \(\displaystyle\lim_{x\to\infty}\left(1 + \frac{a}{x}\right)^{x}\)

풀이

  1. (가) \(\frac00\). 로피탈: \(\dfrac{1 - \cos x}{3x^2}\), 여전히 \(\frac00\). 다시: \(\dfrac{\sin x}{6x} \to \dfrac16\).
    마지막 극한이 존재하므로 앞의 등식들이 거꾸로 차례로 정당화된다. \(\frac{\sin x}{x} \to 1\)은 2단원에서 증명.
  2. (나) \(0\cdot(-\infty)\)꼴. 몫으로 바꾼다: \(x\ln x = \dfrac{\ln x}{1/x}\), \(\frac{-\infty}{\infty}\).
    곱은 한 인수를 역수로 내려 몫으로 만든다. 미분하기 쉬운 쪽(\(\ln x\))을 분자에 남긴다.
  3. 로피탈: \(\dfrac{1/x}{-1/x^2} = -x \to 0\). 따라서 \(\lim x\ln x = 0\).
    "\(x\)는 \(\ln x\)보다 빨리 0으로 간다"는 뜻.
  4. (다) \(1^\infty\)꼴. \(y = \left(1 + \frac ax\right)^x\)이면 \(\ln y = x\ln\left(1 + \frac ax\right) = \dfrac{\ln(1 + a/x)}{1/x}\), \(\frac00\).
    지수에 변수가 있으면 로그를 취해 곱 → 몫으로 바꾼다.
  5. \(t = \frac1x \to 0^+\)로 두면 \(\dfrac{\ln(1 + at)}{t} \to \dfrac{a/(1+at)}{1}\Big|_{t=0} = a\) (로피탈).
    변수 치환으로 식이 단순해진다.
  6. \(\ln y \to a\)이므로 \(y = e^{\ln y} \to e^a\).
    \(e^x\)의 연속성. 로그의 극한을 구한 뒤 반드시 지수로 되돌린다.

검산

(가) 수치로 \(x = 0.1\): \(\frac{0.1 - 0.0998334}{0.001} \approx 0.16658\), \(\frac16 \approx 0.16667\). (다) \(a = 1\)이면 \(e\)의 정의 \(\lim(1 + \frac1x)^x = e\)와 같습니다.

왜 성립하나 (증명 개요, \(\frac00\), \(x \to a^+\))

  1. \(f(a) = g(a) = 0\)으로 정의해 \([a, x]\)에서 연속으로 만든다.
    극한이 0이므로 이 정의로 연속이 된다.
  2. 코시 평균값 정리: \(h(t) = f(t)g(x) - g(t)f(x)\)에 롤 정리를 쓰면 \(\dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)}\)인 \(c \in (a, x)\)가 있다.
    \(h(a) = 0 = h(x)\). \(h'(c) = 0\)에서 \(f'(c)g(x) = g'(c)f(x)\). \(g'\ne0\)이면 롤 정리로 \(g(x) \ne g(a) = 0\)이라 나눌 수 있다.
  3. \(x \to a^+\)이면 \(c \to a^+\)이므로 \(\dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)} \to L\).
    \(a < c < x\)라 압축된다.

흔한 오해

  • \(\infty - \infty\)에 바로 쓰기: 먼저 통분해 몫으로 바꿉니다. 예: \(\frac1x - \frac{1}{\sin x} = \frac{\sin x - x}{x\sin x}\).
  • 쓸 필요가 없는데 쓰기: \(\frac{\sin x}{x}\)에 로피탈을 쓰면 \((\sin x)' = \cos x\)를 증명할 때 이미 이 극한을 썼으므로 순환 논증입니다.
