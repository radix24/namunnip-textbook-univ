8.2.1무한히 더한다는 것

\(\frac12 + \frac14 + \frac18 + \cdots\)는 몇일까요? 길이 1인 막대를 반, 그 반, 또 그 반으로 계속 자르는 것을 생각하면 1이라고 답하고 싶어집니다. 무한히 더하는 것을 정확히 말하려면, 처음 \(n\)개만 더한 부분합 \(s_n\)을 보고 그 극한을 봅니다. 위 예에서 \(s_n = 1 - \frac{1}{2^n} \to 1\)입니다.

정의 8.2.1 (급수의 합)

\(s_n = a_1 + a_2 + \cdots + a_n\)이라 할 때 \(\lim s_n = s\)가 존재하면 급수 \(\sum_{n=1}^\infty a_n\)이 수렴하고 합이 \(s\)라 한다. 극한이 없으면 발산한다.

8.2.2등비급수

정리 8.2.2 (등비급수)

\(\displaystyle\sum_{n=1}^\infty ar^{n-1} = a + ar + ar^2 + \cdots\) (\(a \ne 0\))는 \(|r| < 1\)이면 \(\dfrac{a}{1 - r}\)로 수렴하고, \(|r| \ge 1\)이면 발산한다.

부분합 \(s_n = \dfrac{a(1 - r^n)}{1 - r}\)이고, 8.1절에서 \(|r| < 1\)이면 \(r^n \to 0\)이기 때문입니다.

예제 8.2.3

(가) \(\sum_{n=1}^\infty\frac{2}{3^n}\) (나) 순환소수 \(0.\overline{27}\)을 분수로

풀이. (가) 첫째항 \(\frac23\), 공비 \(\frac13\): \(\dfrac{2/3}{1 - 1/3} = 1\). (나) \(0.27 + 0.0027 + \cdots\)는 첫째항 \(0.27\), 공비 \(0.01\): \(\dfrac{0.27}{0.99} = \dfrac{3}{11}\).

8.2.3망원급수

항을 두 분수의 차로 쓸 수 있으면 부분합에서 중간 항이 줄줄이 지워집니다(접혀 들어가는 망원경 같다고 해서 망원급수).

예제 8.2.4

\(\sum_{n=1}^\infty\frac{1}{n(n + 1)}\)의 합을 구하여라.

풀이. \(\frac{1}{n(n + 1)} = \frac1n - \frac{1}{n + 1}\) (부분분수). \(s_n = \left(1 - \frac12\right) + \left(\frac12 - \frac13\right) + \cdots + \left(\frac1n - \frac{1}{n + 1}\right) = 1 - \frac{1}{n + 1} \to 1\).

8.2.4발산 판정법

정리 8.2.5

\(\sum a_n\)이 수렴하면 \(\lim a_n = 0\)이다. 따라서 \(\lim a_n \ne 0\)이거나 극한이 없으면 \(\sum a_n\)은 발산한다.

\(a_n = s_n - s_{n-1} \to s - s = 0\)이기 때문입니다. 그러나 거꾸로는 성립하지 않습니다. 조화급수 \(\sum\frac1n\)은 \(\frac1n \to 0\)이지만 발산합니다(8.3절).

예제 8.2.6

\(\sum\frac{n^2}{5n^2 + 4}\)은 수렴하는가?

풀이. 항의 극한이 \(\frac15 \ne 0\)이므로 발산합니다.

주의"항이 0으로 가니까 수렴한다"는 틀린 추론입니다. 발산 판정법은 발산만 보여 줄 수 있고, 수렴은 보여 주지 못합니다.
요약
  1. 급수의 합 = 부분합의 극한.
  2. 등비급수: \(|r| < 1\)이면 \(\frac{a}{1 - r}\).
  3. 망원급수: 부분분수로 나누어 중간 항을 지운다.
  4. 항이 0으로 가지 않으면 발산. 0으로 가도 수렴한다는 보장은 없다.

8.2.5연습문제

기본

  1. (가) \(\sum_{n=0}^\infty\left(-\frac12\right)^n\) (나) \(\sum_{n=1}^\infty\frac{3^n}{4^{n+1}}\)
    답

    (가) \(\frac{1}{1 + 1/2} = \frac23\) (나) 첫째항 \(\frac{3}{16}\), 공비 \(\frac34\): \(\frac34\)

응용

  1. \(\sum_{n=2}^\infty\frac{1}{n^2 - 1}\)의 합을 구하여라.
    답

    \(\frac12\left(\frac{1}{n - 1} - \frac{1}{n + 1}\right)\). 부분합 \(\frac12\left(1 + \frac12 - \frac1n - \frac{1}{n + 1}\right) \to \frac34\).

이 절의 성취기준[공통1-08-02] 계산

  1. 급수의 합을 부분합으로 이해하고 등비급수와 망원급수의 합을 구할 수 있다.
