  • 치환적분 (4.3절), 삼각함수의 적분 (5.2절).

5.3.1근호를 없애는 치환

반지름 \(a\)인 원의 넓이를 적분으로 구하려면 \(\int_{-a}^a\sqrt{a^2 - x^2}\,dx\)를 계산해야 합니다. 근호 안이 \(u\)의 도함수와 맞지 않아 4.3절의 치환은 통하지 않습니다. 그런데 \(x = a\sin\theta\)로 놓으면 \(a^2 - x^2 = a^2(1 - \sin^2\theta) = a^2\cos^2\theta\)가 되어 근호가 벗겨집니다. 이처럼 \(x\)를 삼각함수로 바꾸는 방법이 삼각치환입니다.

식에 있는 것치환쓰는 항등식
\(\sqrt{a^2 - x^2}\)\(x = a\sin\theta\), \(-\frac\pi2 \le \theta \le \frac\pi2\)\(1 - \sin^2\theta = \cos^2\theta\)
\(\sqrt{a^2 + x^2}\)\(x = a\tan\theta\), \(-\frac\pi2 < \theta < \frac\pi2\)\(1 + \tan^2\theta = \sec^2\theta\)
\(\sqrt{x^2 - a^2}\)\(x = a\sec\theta\)\(\sec^2\theta - 1 = \tan^2\theta\)
예제 5.3.1

반지름 \(a\)인 원의 넓이가 \(\pi a^2\)임을 적분으로 보여라.

풀이. 넓이는 \(4\int_0^a\sqrt{a^2 - x^2}\,dx\)입니다. \(x = a\sin\theta\), \(dx = a\cos\theta\,d\theta\). \(x = 0\)이면 \(\theta = 0\), \(x = a\)이면 \(\theta = \frac\pi2\). 이 범위에서 \(\cos\theta \ge 0\)이므로 \(\sqrt{a^2 - x^2} = a\cos\theta\).

\[4\int_0^{\pi/2}a\cos\theta\cdot a\cos\theta\,d\theta = 4a^2\int_0^{\pi/2}\cos^2\theta\,d\theta = 4a^2\cdot\frac\pi4 = \pi a^2.\]

마지막 적분은 5.2절의 반각 공식으로 구했습니다.

예제 5.3.2

\(\int\dfrac{dx}{x^2\sqrt{x^2 + 4}}\)를 구하여라.

풀이. \(x = 2\tan\theta\), \(dx = 2\sec^2\theta\,d\theta\), \(\sqrt{x^2 + 4} = 2\sec\theta\).

\[\int\frac{2\sec^2\theta\,d\theta}{4\tan^2\theta\cdot2\sec\theta} = \frac14\int\frac{\sec\theta}{\tan^2\theta}d\theta = \frac14\int\frac{\cos\theta}{\sin^2\theta}d\theta = -\frac{1}{4\sin\theta} + C.\]

(\(u = \sin\theta\)로 치환했습니다.) 이제 \(x\)로 되돌립니다. \(\tan\theta = \frac x2\)이므로 밑변 2, 높이 \(x\), 빗변 \(\sqrt{x^2 + 4}\)인 직각삼각형을 그리면 \(\sin\theta = \frac{x}{\sqrt{x^2 + 4}}\). 답은 \(-\dfrac{\sqrt{x^2 + 4}}{4x} + C\).

되돌릴 때 직각삼각형을 그리는 것이 가장 실수가 적습니다. 치환식에서 두 변을 정하고, 피타고라스 정리로 나머지 한 변을 구한 뒤 필요한 삼각비를 읽습니다.

주의근호가 있다고 늘 삼각치환을 쓰는 것은 아닙니다. \(\int x\sqrt{x^2 + 4}\,dx\)는 \(u = x^2 + 4\)로 치환하면 훨씬 간단합니다. 바깥에 근호 안의 도함수(\(x\))가 있는지 먼저 보세요.
요약
  1. \(\sqrt{a^2 - x^2}\): \(x = a\sin\theta\) / \(\sqrt{a^2 + x^2}\): \(x = a\tan\theta\) / \(\sqrt{x^2 - a^2}\): \(x = a\sec\theta\).
  2. \(x\)로 되돌릴 때는 직각삼각형을 그린다.
  3. 정적분이면 구간을 \(\theta\)로 바꾸어 되돌리지 않아도 된다.

5.3.2연습문제

기본

  1. \(\int_0^1\frac{dx}{\sqrt{4 - x^2}}\)를 구하여라.
    답

    \(x = 2\sin\theta\): \(\int_0^{\pi/6}d\theta = \frac\pi6\).

  2. \(\int\frac{dx}{1 + x^2}\)을 \(x = \tan\theta\)로 치환해 구하고 4.2절의 표와 비교하여라.
    답

    \(\int\frac{\sec^2\theta}{\sec^2\theta}d\theta = \theta = \arctan x + C\). 표와 같다.

응용

  1. \(\int\frac{x^2}{\sqrt{9 - x^2}}dx\)를 구하여라.
    답

    \(x = 3\sin\theta\): \(9\int\sin^2\theta\,d\theta = \frac92(\theta - \sin\theta\cos\theta) = \frac92\arcsin\frac x3 - \frac x2\sqrt{9 - x^2} + C\).

5.3.2

예제근호를 없애는 삼각 치환

√(a²−x²) · √(a²+x²) · √(x²−a²)

다루는 성취기준 [공통1-05-03]

아이디어

피타고라스 항등식으로 근호 안을 완전제곱으로 만듭니다.

근호치환범위근호가 되는 것
\(\sqrt{a^2 - x^2}\)\(x = a\sin\theta\)\(-\frac\pi2 \le \theta \le \frac\pi2\)\(a\cos\theta\)
\(\sqrt{a^2 + x^2}\)\(x = a\tan\theta\)\(-\frac\pi2 < \theta < \frac\pi2\)\(a\sec\theta\)
\(\sqrt{x^2 - a^2}\)\(x = a\sec\theta\)\(0 \le \theta < \frac\pi2\) (\(x \ge a\))\(a\tan\theta\)

범위를 정하는 이유: 치환이 일대일이어야 \(\theta\)로 되돌릴 수 있고(\(\theta = \arcsin\frac xa\) 등), 그 범위에서 \(\cos\theta, \sec\theta, \tan\theta \ge 0\)이라 \(\sqrt{\ \cdot\ ^2}\)의 절댓값을 떼어낼 수 있습니다.

문제 1. \(\displaystyle\int_0^{a}\sqrt{a^2 - x^2}\,dx\) \((a > 0)\)를 구하고 기하적으로 확인하세요.

풀이

  1. \(x = a\sin\theta\), \(dx = a\cos\theta\,d\theta\). \(x: 0 \to a\)이면 \(\theta: 0 \to \frac\pi2\).
    첫째 줄 치환. 구간을 \(\theta\)로 바꾼다.
  2. \(\sqrt{a^2 - a^2\sin^2\theta} = a|\cos\theta| = a\cos\theta\).
    \(\theta \in [0, \frac\pi2]\)에서 \(\cos\theta \ge 0\).
  3. \(\int_0^{\pi/2}a^2\cos^2\theta\,d\theta = a^2\int_0^{\pi/2}\frac{1 + \cos2\theta}{2}d\theta = a^2\left[\frac\theta2 + \frac{\sin2\theta}{4}\right]_0^{\pi/2}\).
    반각 공식으로 \(\cos^2\)을 일차로 내린다.
  4. \(= \dfrac{\pi a^2}{4}\).
    \(\sin\pi = \sin 0 = 0\).

검산: \(y = \sqrt{a^2 - x^2}\)은 반지름 \(a\)인 원의 위쪽 반이고, \([0, a]\)는 그 4분의 1입니다. 넓이 \(\frac{\pi a^2}{4}\). 맞습니다.

문제 2. \(\displaystyle\int\frac{dx}{x^2\sqrt{x^2 + 4}}\)를 구하세요.

풀이

  1. \(x = 2\tan\theta\), \(dx = 2\sec^2\theta\,d\theta\), \(\sqrt{x^2 + 4} = 2\sec\theta\).
    둘째 줄 치환. \(\sec\theta > 0\).
  2. \(\int\frac{2\sec^2\theta}{4\tan^2\theta\cdot2\sec\theta}d\theta = \frac14\int\frac{\sec\theta}{\tan^2\theta}d\theta = \frac14\int\frac{\cos\theta}{\sin^2\theta}d\theta\).
    \(\frac{\sec}{\tan^2} = \frac{1/\cos}{\sin^2/\cos^2} = \frac{\cos}{\sin^2}\).
  3. \(w = \sin\theta\)로 치환: \(\frac14\int w^{-2}dw = -\frac{1}{4\sin\theta} + C\).
    5단원의 치환적분.
  4. \(\tan\theta = \frac x2\)인 직각삼각형(밑변 2, 높이 \(x\), 빗변 \(\sqrt{x^2+4}\))에서 \(\sin\theta = \frac{x}{\sqrt{x^2+4}}\). 답: \(-\dfrac{\sqrt{x^2 + 4}}{4x} + C\).
    부정적분은 \(x\)로 되돌려야 한다. 삼각형을 그리면 다른 삼각비를 바로 읽는다.

의미

삼각 치환은 기하를 드러냅니다. \(\sqrt{a^2 - x^2}\)은 원, \(\sqrt{a^2 + x^2}\)과 \(\sqrt{x^2 - a^2}\)은 쌍곡선과 관련된 식이라, 이런 적분의 답에는 원의 넓이(\(\frac{\pi a^2}{4}\))나 각도(\(\arcsin\)), 로그가 나옵니다.

검산

\(\frac{d}{dx}\left(-\frac{\sqrt{x^2+4}}{4x}\right) = -\frac14\cdot\frac{\frac{x}{\sqrt{x^2+4}}\cdot x - \sqrt{x^2+4}}{x^2} = -\frac14\cdot\frac{x^2 - (x^2 + 4)}{x^2\sqrt{x^2+4}} = \frac{1}{x^2\sqrt{x^2+4}}\). 맞습니다.

미리 정리할 것

\(\sqrt{x^2 + 2x + 5}\)처럼 일차항이 있으면 완전제곱 \(\sqrt{(x+1)^2 + 4}\)로 고친 뒤 \(x + 1 = 2\tan\theta\)로 둡니다. 또 \(\int\frac{x}{\sqrt{x^2+4}}dx\)처럼 분자에 근호 속의 도함수가 있으면 삼각 치환보다 \(u = x^2 + 4\)가 훨씬 빠릅니다.
