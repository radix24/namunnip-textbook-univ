  • 이웃한 항의 비로 수렴을 판정한다(비 판정법).

먼저 알아야 할 것
  • 등비급수 (8.2절), 절대수렴 (8.4절), 계승 \(n!\) (고교 수학).

8.5.1비 판정법

등비급수는 이웃한 항의 비가 일정한 \(r\)이고, \(|r| < 1\)이면 수렴합니다. 항의 비가 일정하지는 않지만 \(n\)이 커질 때 어떤 값 \(L\)에 다가간다면, 먼 항들은 공비가 거의 \(L\)인 등비급수처럼 행동할 것입니다.

정리 8.5.1 (비 판정법)

\(\displaystyle L = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|\)이라 하자. \(L < 1\)이면 \(\sum a_n\)은 절대수렴하고, \(L > 1\)(또는 \(\infty\))이면 발산한다. \(L = 1\)이면 이 판정법으로는 알 수 없다.

계승(\(n!\))이나 \(n\)제곱(\(2^n\), \(n^n\))이 들어 있으면 비 판정법이 잘 통합니다. 비를 계산하면 대부분이 약분되기 때문입니다.

예제 8.5.2

(가) \(\sum\frac{n^3}{3^n}\) (나) \(\sum\frac{n!}{2^n}\) (다) \(\sum\frac{1}{n^2}\)에 비 판정법을 써라.

풀이. (가) \(\dfrac{(n + 1)^3/3^{n+1}}{n^3/3^n} = \dfrac13\left(1 + \dfrac1n\right)^3 \to \dfrac13 < 1\). 수렴.

(나) \(\dfrac{(n + 1)!/2^{n+1}}{n!/2^n} = \dfrac{n + 1}{2} \to \infty\). 발산.

(다) \(\dfrac{n^2}{(n + 1)^2} \to 1\). 판정할 수 없습니다. (실제로는 수렴하지만, \(L = 1\)인 \(\sum\frac1n\)은 발산합니다. \(p\)-급수에는 비 판정법이 통하지 않습니다.)

8.5.2근 판정법

정리 8.5.3 (근 판정법)

\(L = \lim\sqrt[n]{|a_n|}\)이라 하자. \(L < 1\)이면 절대수렴, \(L > 1\)이면 발산, \(L = 1\)이면 알 수 없다.

항 전체가 \(n\)제곱 꼴일 때 편리합니다.

예제 8.5.4

\(\sum\left(\dfrac{2n + 3}{3n + 2}\right)^n\)의 수렴을 판정하여라.

풀이. \(\sqrt[n]{a_n} = \dfrac{2n + 3}{3n + 2} \to \dfrac23 < 1\). 수렴.

8.5.3판정법 고르기

  1. 항이 0으로 가지 않으면 발산(8.2절).
  2. \(\frac{1}{n^p}\)이나 \(ar^{n-1}\) 꼴이면 그대로 판정.
  3. 분수식(다항식, 근호)이면 \(p\)-급수와 비교·극한 비교(8.3절).
  4. 부호가 번갈아 바뀌면 교대급수 판정법(8.4절).
  5. \(n!\)이나 \(r^n\)이 있으면 비 판정법, 항 전체가 \((\cdots)^n\)이면 근 판정법.
  6. \(f(n)\)을 쉽게 적분할 수 있으면 적분 판정법.
요약
  1. 비 판정법: \(\lim\left|\frac{a_{n+1}}{a_n}\right| < 1\) 수렴, \(> 1\) 발산, \(= 1\) 알 수 없음.
  2. 근 판정법: \(\lim\sqrt[n]{|a_n|}\)로 같은 판정.
  3. 계승·거듭제곱에는 비, \((\cdots)^n\)에는 근, 분수식에는 비교.

8.5.4연습문제

기본

  1. (가) \(\sum\frac{5^n}{n!}\) (나) \(\sum\frac{n}{2^n}\) (다) \(\sum\left(\frac{n}{2n + 1}\right)^n\)
    답

    (가) 비 \(\frac{5}{n + 1} \to 0\), 수렴 (나) 비 \(\frac{n + 1}{2n} \to \frac12\), 수렴 (다) 근 \(\to \frac12\), 수렴

응용

  1. \(\sum\frac{n^n}{n!}\)의 수렴을 판정하여라.
    답

    비 \(= \left(1 + \frac1n\right)^n \to e > 1\). 발산.

8.5.2

실습이웃한 두 항의 비만 보고 수렴을 알 수 있을까?

실습 · 비 판정법과 근 판정법

다루는 성취기준 [공통1-08-05]

목표

급수 \(\sum a_n\)에서 \(n\)이 클 때 \(a_{n+1}/a_n\)(비)이나 \(\sqrt[n]{a_n}\)(근)이 어디로 가는지 그래프로 보고, 그 극한 \(L\)로 수렴과 발산을 판정합니다. \(L = 1\)이면 판정이 안 되는 예도 확인합니다. 성취기준 [공통1-08-05].

준비

  • 보라 선: \(a_{n+1}/a_n\). 주황 선: \(\sqrt[n]{a_n}\). 빨간 점선: 높이 1.
  • 판정법: \(L < 1\)이면 (절대)수렴, \(L > 1\)이면 발산, \(L = 1\)이면 알 수 없음. 비가 \(L < 1\)에 다가가면 급수는 결국 공비 \(L\)보다 조금 큰 등비급수보다 작아지기 때문입니다.

절차

  1. \(\sum n/2^n\)에서 \(n = 10, 20, 40\)일 때 비와 근을 기록합니다.
  2. \(\sum 2^n/n!\), \(\sum n!/n^n\)으로 바꿔 두 선이 어디로 가는지 봅니다.
  3. \(\sum 1/n\)과 \(\sum 1/n^2\)에서 두 선을 비교합니다.

기대 결과

  • \(\sum n/2^n\), \(n = 10\): 비 0.5500, 근 0.6295. 둘 다 0.5에 다가가므로 수렴하고, 10항까지의 합은 1.98828(급수의 합 2)입니다. 근은 비보다 느리게 다가갑니다.
  • \(\sum 2^n/n!\)은 \(L = 0\)으로 빨리 수렴하고, \(\sum n!/n^n\)은 \(L = 1/e \approx 0.368\)으로 수렴합니다. 계승이 들어 있으면 비 판정법이 편합니다.
  • \(\sum 1/n\)과 \(\sum 1/n^2\)은 두 선이 모두 1에 다가가 그래프로는 구별되지 않지만, 앞의 것은 발산하고 뒤의 것은 수렴합니다. \(L = 1\)일 때는 적분 판정법이나 비교 판정법(8.3절)이 필요합니다.

분석

  1. \(\sum n!/n^n\)의 비가 \(\left(\dfrac{n}{n + 1}\right)^n\)임을 보이고, 이것이 \(1/e\)로 가는 이유를 \(\left(1 + \tfrac1n\right)^n \to e\)로 설명해 보세요.
  2. \(\sum 3^n/n^2\)은 항이 0으로 가지 않습니다. 비 판정법을 쓰지 않고도 발산을 알 수 있는 방법은?
