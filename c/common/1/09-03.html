9.3.1정의와 사잇각

정의 9.3.1 (내적)

\(\mathbf a = \langle a_1, a_2, a_3\rangle\), \(\mathbf b = \langle b_1, b_2, b_3\rangle\)의 내적은 \(\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + a_3b_3\). 결과는 벡터가 아니라 수(스칼라)이다.

계산은 같은 자리 성분끼리 곱해 더하면 됩니다. 이 단순한 계산이 두 벡터 사이의 각을 알려 줍니다.

정리 9.3.2

\(\theta\)가 \(\mathbf a\)와 \(\mathbf b\)의 사잇각(\(0 \le \theta \le \pi\))이면 \(\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\theta\).

이유: 두 벡터와 \(\mathbf a - \mathbf b\)가 이루는 삼각형에 코사인 법칙을 쓰면 \(|\mathbf a - \mathbf b|^2 = |\mathbf a|^2 + |\mathbf b|^2 - 2|\mathbf a||\mathbf b|\cos\theta\)입니다. 왼쪽을 성분으로 전개하면 \(|\mathbf a|^2 + |\mathbf b|^2 - 2(a_1b_1 + a_2b_2 + a_3b_3)\)이므로 비교하면 됩니다.

따라서 두 벡터가 수직(\(\theta = \frac\pi2\))일 필요충분조건은 \(\mathbf a\cdot\mathbf b = 0\)입니다. 내적이 양수이면 사잇각이 예각, 음수이면 둔각입니다.

예제 9.3.3

\(\mathbf a = \langle2, 2, -1\rangle\), \(\mathbf b = \langle5, -3, 2\rangle\)의 사잇각을 구하여라. 또 \(\langle1, 2, 2\rangle\)과 \(\langle2, -1, 0\rangle\)이 수직임을 보여라.

풀이. \(\mathbf a\cdot\mathbf b = 10 - 6 - 2 = 2\), \(|\mathbf a| = 3\), \(|\mathbf b| = \sqrt{38}\). \(\cos\theta = \dfrac{2}{3\sqrt{38}} \approx 0.108\), \(\theta \approx 1.46\) rad \(\approx 84^\circ\). 둘째: \(2 - 2 + 0 = 0\)이므로 수직.

9.3.2정사영

\(\mathbf b\)에 \(\mathbf a\) 방향으로 수직으로 빛을 비추면 \(\mathbf a\) 위에 그림자가 생깁니다. 그림자의 부호 있는 길이를 스칼라 정사영, 그림자 벡터를 벡터 정사영이라 합니다.

\[\text{comp}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|}, \qquad \text{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|^2}\mathbf a.\]

물리에서 힘 \(\mathbf F\)가 물체를 변위 \(\mathbf D\)만큼 옮길 때 한 일은 "이동 방향의 힘 성분 × 거리"이므로 \(W = \mathbf F\cdot\mathbf D\)입니다. 일반물리학(1)의 일이 바로 내적입니다.

예제 9.3.4

수평에서 30° 위쪽으로 70 N의 힘으로 썰매를 끌어 수평으로 100 m 옮겼다. 한 일은?

풀이. \(W = |\mathbf F||\mathbf D|\cos30^\circ = 70\cdot100\cdot\frac{\sqrt3}{2} \approx 6062\) J.

주의내적의 결과는 수입니다. \(\mathbf a\cdot\mathbf b\)를 벡터처럼 \(\langle a_1b_1, a_2b_2, a_3b_3\rangle\)로 쓰면 틀립니다. 벡터를 결과로 주는 곱(외적)은 공통2 1단원에서 배웁니다.
요약
  1. \(\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + a_3b_3 = |\mathbf a||\mathbf b|\cos\theta\).
  2. \(\mathbf a\cdot\mathbf b = 0 \iff\) 수직.
  3. 정사영 \(\text{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a|^2}\mathbf a\). 일 \(W = \mathbf F\cdot\mathbf D\).

9.3.3연습문제

기본

  1. \(\langle1, 1, 0\rangle\)과 \(\langle0, 1, 1\rangle\)의 사잇각은?
    답

    \(\cos\theta = \frac{1}{\sqrt2\sqrt2} = \frac12\), \(\theta = \frac\pi3\).

  2. \(\langle3, k, -2\rangle\)과 \(\langle1, 2, 4\rangle\)이 수직이 되는 \(k\)는?
    답

    \(3 + 2k - 8 = 0\), \(k = \frac52\).

응용

  1. \(\mathbf b = \langle1, 1, 2\rangle\)의 \(\mathbf a = \langle-2, 3, 1\rangle\) 위로의 벡터 정사영을 구하여라.
    답

    \(\mathbf a\cdot\mathbf b = 3\), \(|\mathbf a|^2 = 14\). \(\frac{3}{14}\langle-2, 3, 1\rangle\).

9.3.2

설명내적: 길이와 각을 계산으로 바꾸는 도구

사이각 · 정사영 · 코시-슈바르츠

다루는 성취기준 [공통1-09-03]

왜 필요한가

공간에서 "두 방향이 이루는 각", "한 벡터의 어느 방향 성분" 같은 기하적 양을 그림 없이 성분 계산만으로 구하고 싶습니다. 내적은 기하(길이, 각)와 대수(성분의 곱셈)를 잇습니다. 일(힘 · 변위), 선속, 정사영 등 이 과목 끝까지 계속 쓰입니다.

정의 · 내적

\(\mathbf a = (a_1, a_2, a_3)\), \(\mathbf b = (b_1, b_2, b_3)\)일 때 \(\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + a_3b_3\). 길이는 \(|\mathbf a| = \sqrt{\mathbf a\cdot\mathbf a}\).

정리

\(\mathbf a, \mathbf b \ne \mathbf 0\) 사이의 각을 \(\theta \in [0, \pi]\)라 하면 \(\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\theta\).

증명

  1. \(\mathbf a, \mathbf b, \mathbf a - \mathbf b\)가 삼각형의 세 변을 이룬다. 코사인 법칙: \(|\mathbf a - \mathbf b|^2 = |\mathbf a|^2 + |\mathbf b|^2 - 2|\mathbf a||\mathbf b|\cos\theta\).
    \(\mathbf a\)와 \(\mathbf b\)를 같은 점에서 그리면 끝점을 잇는 벡터가 \(\mathbf a - \mathbf b\).
  2. 왼쪽을 성분으로 전개: \(|\mathbf a - \mathbf b|^2 = (\mathbf a - \mathbf b)\cdot(\mathbf a - \mathbf b) = |\mathbf a|^2 - 2\,\mathbf a\cdot\mathbf b + |\mathbf b|^2\).
    내적의 분배법칙과 교환법칙(성분 정의에서 바로 나옴).
  3. 두 식을 비교하면 \(\mathbf a\cdot\mathbf b = |\mathbf a||\mathbf b|\cos\theta\).
    \(|\mathbf a|^2 + |\mathbf b|^2\)이 소거된다.

따름: \(|\cos\theta| \le 1\)이므로 \(|\mathbf a\cdot\mathbf b| \le |\mathbf a||\mathbf b|\) (코시-슈바르츠 부등식). 그리고 \(\mathbf a\cdot\mathbf b = 0 \iff\) 수직.

정사영

\(\mathbf b\)를 \(\mathbf a\) 방향 성분과 수직 성분으로 나눕니다. \(\mathbf a\) 방향 단위벡터 \(\hat{\mathbf a} = \frac{\mathbf a}{|\mathbf a|}\)에 대해

\[\text{성분 } \operatorname{comp}_{\mathbf a}\mathbf b = \mathbf b\cdot\hat{\mathbf a} = |\mathbf b|\cos\theta, \qquad \operatorname{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{\mathbf a\cdot\mathbf a}\,\mathbf a.\]

확인: \(\mathbf b - \operatorname{proj}_{\mathbf a}\mathbf b\)와 \(\mathbf a\)의 내적은 \(\mathbf a\cdot\mathbf b - \frac{\mathbf a\cdot\mathbf b}{\mathbf a\cdot\mathbf a}\mathbf a\cdot\mathbf a = 0\). 남은 부분이 정말 수직입니다.

예제

\(\mathbf a = (1, 2, 2)\), \(\mathbf b = (3, 0, 4)\)의 사이각과 \(\operatorname{proj}_{\mathbf a}\mathbf b\)를 구하세요.

  1. \(\mathbf a\cdot\mathbf b = 3 + 0 + 8 = 11\), \(|\mathbf a| = 3\), \(|\mathbf b| = 5\).
    성분 정의.
  2. \(\cos\theta = \frac{11}{15}\), \(\theta = \arccos\frac{11}{15} \approx 42.8°\).
    정리. 내적이 양수이면 예각.
  3. \(\operatorname{proj}_{\mathbf a}\mathbf b = \frac{11}{9}(1, 2, 2)\).
    \(\mathbf a\cdot\mathbf a = 9\).

검산: \(\mathbf b - \frac{11}{9}\mathbf a = \left(\frac{16}{9}, -\frac{22}{9}, \frac{14}{9}\right)\), \(\mathbf a\)와의 내적 \(\frac{16 - 44 + 28}{9} = 0\).

흔한 오해

  • "내적은 벡터다." 내적의 결과는 스칼라(수)입니다. 그래서 \((\mathbf a\cdot\mathbf b)\cdot\mathbf c\)는 뜻이 없습니다.
  • 성분과 정사영 혼동: 성분은 부호 있는 길이(수), 정사영은 벡터입니다.
