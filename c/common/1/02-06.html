2.6.1정의와 그래프

양 끝을 잡고 늘어뜨린 쇠사슬이나 전깃줄은 포물선처럼 보이지만 사실은 다른 곡선(현수선)입니다. 그 곡선을 나타내는 함수가 \(e^x\)와 \(e^{-x}\)의 평균입니다. 이렇게 \(e^x\)와 \(e^{-x}\)를 더하고 빼서 만든 함수들을 쌍곡선 함수라고 부릅니다.

정의 2.6.1 (쌍곡선 함수) \[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x}.\]
  • \(\cosh x\): 우함수. \(\cosh 0 = 1\)이 가장 작은 값이고 U자 모양이다.
  • \(\sinh x\): 기함수. 원점을 지나며 계속 증가한다.
  • \(\tanh x\): 기함수. 값이 \(-1\)과 \(1\) 사이에 있고, \(y = \pm1\)이 수평 점근선이다.

이름에 "사인", "코사인"이 붙은 것은 삼각함수와 닮은 항등식 때문입니다. 정의를 넣어 전개하면 \(e^xe^{-x} = 1\)이라서

\[\cosh^2 x - \sinh^2 x = 1\]

입니다. 삼각함수는 점 \((\cos t, \sin t)\)가 원 \(x^2 + y^2 = 1\) 위에 있고, 쌍곡선 함수는 점 \((\cosh t, \sinh t)\)가 쌍곡선 \(x^2 - y^2 = 1\) 위에 있습니다.

2.6.2도함수

\((e^x)' = e^x\), \((e^{-x})' = -e^{-x}\)이므로 정의를 미분하면 바로 나옵니다.

정리 2.6.2 \[(\sinh x)' = \cosh x, \qquad (\cosh x)' = \sinh x, \qquad (\tanh x)' = \frac{1}{\cosh^2 x}.\]

삼각함수와 달리 \((\cosh x)'\)에 마이너스가 없다는 점에 주의하세요. \(\tanh\)는 몫의 미분법과 \(\cosh^2 x - \sinh^2 x = 1\)로 구합니다.

예제 2.6.3

\(y = \cosh(x^2)\)과 \(y = \sinh x\cosh x\)를 미분하여라.

풀이. 연쇄법칙: \(y' = \sinh(x^2)\cdot2x\). 곱의 미분법: \(y' = \cosh^2 x + \sinh^2 x\).

쌍곡선 함수의 역함수는 로그로 나타납니다. 예를 들어 \(\sinh^{-1}x = \ln\left(x + \sqrt{x^2 + 1}\right)\)입니다. 이 식은 5.3절의 삼각치환과 함께 \(\int\frac{dx}{\sqrt{x^2 + 1}}\)을 계산할 때 쓰입니다. 유도는 이 절의 보충 카드에 있습니다.

요약
  1. \(\sinh x = \frac{e^x - e^{-x}}{2}\), \(\cosh x = \frac{e^x + e^{-x}}{2}\), \(\cosh^2x - \sinh^2x = 1\).
  2. \((\sinh x)' = \cosh x\), \((\cosh x)' = \sinh x\) (부호 변화 없음).

2.6.3연습문제

기본

  1. \(\cosh(\ln 2)\)의 값을 구하여라.
    답

    \(\frac{2 + 1/2}{2} = \frac54\).

  2. \(y = \tanh(3x)\)를 미분하여라.
    답

    \(\frac{3}{\cosh^2 3x}\).

응용

  1. \(y = \cosh x\)가 \(y'' = y\)를 만족함을 보여라.
    답

    \(y' = \sinh x\), \(y'' = \cosh x = y\).
