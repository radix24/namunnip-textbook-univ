6.R.1

연습적분의 응용 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통1-06-01] [공통1-06-02] [공통1-06-03] [공통1-06-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산곡선 \(y = \sqrt x\) (\(0 \le x \le 4\))와 x축 사이의 영역을 x축 둘레로 회전한 입체의 부피를 구하세요. [06-01]

    힌트 1

    x축에 수직으로 자르면 단면은 반지름 \(\sqrt x\)인 원입니다.

    힌트 2

    \(V = \int_0^4 \pi(\sqrt x)^2\,dx\).

    풀이

    \(V = \pi\int_0^4 x\,dx = \pi \cdot 8 = 8\pi \approx 25.13\).

  2. 계산\(y = x - x^2\)과 x축 사이의 영역(\(0 \le x \le 1\))을 y축 둘레로 회전한 입체의 부피를 원통껍질 방법으로 구하세요. [06-02]

    힌트 1

    반지름 \(x\), 높이 \(x - x^2\), 두께 \(dx\)인 껍질의 부피는 \(2\pi x(x - x^2)dx\).

    힌트 2

    \(2\pi\int_0^1(x^2 - x^3)\,dx\).

    풀이

    \(2\pi\left(\tfrac13 - \tfrac14\right) = \dfrac{\pi}{6} \approx 0.524\). 원판으로 자르려면 \(y = x - x^2\)을 \(x\)에 대해 풀어 두 곡선으로 나눠야 해서 훨씬 번거롭습니다.

  3. 계산\(y = x^{3/2}\) (\(0 \le x \le 1\))의 길이를 구하세요. [06-03]

    힌트 1

    \(L = \int_a^b \sqrt{1 + (y')^2}\,dx\).

    힌트 2

    \(y' = \tfrac32x^{1/2}\), \(1 + (y')^2 = 1 + \tfrac94x\). \(u = 1 + \tfrac94x\)로 치환합니다.

    풀이

    \(L = \int_0^1\left(1 + \tfrac94x\right)^{1/2}dx = \tfrac49\cdot\tfrac23\left[\left(1 + \tfrac94x\right)^{3/2}\right]_0^1 = \tfrac{8}{27}\left[\left(\tfrac{13}4\right)^{3/2} - 1\right] = \dfrac{13\sqrt{13} - 8}{27} \approx 1.440\).

    검산: 두 끝점 (0, 0), (1, 1)을 잇는 선분의 길이 \(\sqrt2 \approx 1.414\)보다 조금 깁니다.

  4. 계산\(y = \sqrt x\) (\(0 \le x \le 1\))를 x축 둘레로 회전해 생긴 곡면의 겉넓이를 구하세요. [06-04]

    힌트 1

    \(S = \int 2\pi y\sqrt{1 + (y')^2}\,dx\). 띠 하나는 반지름 \(y\), 기울어진 폭 \(ds\)인 고리입니다.

    힌트 2

    \(y\sqrt{1 + (y')^2} = \sqrt x\sqrt{1 + \tfrac1{4x}} = \sqrt{x + \tfrac14}\).

    풀이

    \(S = 2\pi\int_0^1\sqrt{x + \tfrac14}\,dx = 2\pi\cdot\tfrac23\left[\left(\tfrac54\right)^{3/2} - \left(\tfrac14\right)^{3/2}\right] = \dfrac{\pi}{6}(5\sqrt5 - 1) \approx 5.33\).

    \(ds\) 대신 \(dx\)를 쓰면(\(2\pi\int\sqrt x\,dx = \tfrac{4\pi}3 \approx 4.19\)) 기울어진 띠를 수평으로 본 셈이라 넓이가 작게 나옵니다. 부피에서는 \(dx\)로 충분하지만 겉넓이에서는 안 됩니다.

  5. 개념\(y = x\)와 \(y = x^2\) 사이의 영역을 x축 둘레로 회전한 입체의 부피를 구하세요. 단면은 어떤 모양인가요? [06-01]

    힌트 1

    \(0 \le x \le 1\)에서 \(x \ge x^2\)이므로 바깥 반지름 \(x\), 안쪽 반지름 \(x^2\)입니다.

    힌트 2

    단면은 가운데가 빈 고리(와셔)이고 넓이는 \(\pi(R^2 - r^2)\).

    풀이

    \(V = \pi\int_0^1(x^2 - x^4)\,dx = \pi\left(\tfrac13 - \tfrac15\right) = \dfrac{2\pi}{15} \approx 0.419\). \(\pi\int(x - x^2)^2dx\)로 쓰면 틀립니다. 두 반지름의 차를 제곱하는 것이 아니라 각각의 제곱의 차입니다.

  6. 판단한 학생이 “\(y = x^2\) (\(0 \le x \le 1\))의 길이는 \(\int_0^1x^2\,dx = \tfrac13\)이다”라고 했습니다. 판단하세요. [06-03]

    힌트 1

    두 끝점 (0, 0)과 (1, 1)을 잇는 선분의 길이는 얼마인가요? 곡선은 그보다 짧을 수 있나요?

    힌트 2

    \(\int f\,dx\)는 넓이입니다. 길이는 \(\int\sqrt{1 + (f')^2}\,dx\).

    풀이

    틀렸습니다. 1/3은 곡선 아래 넓이이고, 길이는 선분 길이 \(\sqrt2 \approx 1.414\)보다 길어야 합니다. 바른 값은 \(\int_0^1\sqrt{1 + 4x^2}\,dx = \tfrac{\sqrt5}2 + \tfrac14\ln(2 + \sqrt5) \approx 1.479\)입니다(삼각치환이나 쌍곡선 치환, 5.3절).
