방향장에서 공식으로

10.1절에서는 그림으로 해의 모양을 보았습니다. 이 절에서는 식을 직접 풀어 해를 공식으로 얻습니다. 모든 미분방정식을 풀 수 있는 것은 아니지만, 오른쪽이 \(x\)만의 함수와 \(y\)만의 함수의 곱으로 나뉘는 식은 적분 두 번으로 풀 수 있습니다.

10.2.1변수분리형

정의 10.2.1

\(\dfrac{dy}{dx} = g(x)h(y)\) 꼴의 미분방정식을 변수분리형이라 한다.

푸는 순서는 이렇습니다. \(h(y) \ne 0\)인 곳에서 양변을 \(h(y)\)로 나누면 \(\dfrac{1}{h(y)}\dfrac{dy}{dx} = g(x)\)입니다. 양변을 \(x\)로 적분하면 왼쪽은 치환적분(\(y\)를 새 변수로)에 의해 \(\int \dfrac{dy}{h(y)}\)가 되므로

\[\int \frac{dy}{h(y)} = \int g(x)\,dx + C\]

를 얻습니다. 이 등식을 \(y\)에 대해 풀면 해입니다. 흔히 "\(y\)는 왼쪽으로, \(x\)는 오른쪽으로 나눈 뒤 적분한다"고 기억합니다. \(h(y_0) = 0\)인 상수 \(y = y_0\)은 나눌 때 빠지지만 그 자체로 해입니다(평형해). 따로 확인해야 합니다.

예제 10.2.2

\(y' = ry\), \(y(0) = P_0\)을 풀어라 (\(r > 0\)).

풀이. \(\int \dfrac{dy}{y} = \int r\,dx\)에서 \(\ln|y| = rx + C\), 곧 \(|y| = e^C e^{rx}\)입니다. 부호까지 넣어 상수를 \(A\)로 쓰면 \(y = Ae^{rx}\)이고, 처음 값에서 \(A = P_0\)이므로 \(y = P_0e^{rx}\)입니다. 이것이 지수 성장입니다. 개체 수가 두 배가 되는 시간은 \(e^{rT} = 2\)에서 \(T = \ln 2 / r\)로, 개체 수와 상관없이 일정합니다.

10.2.2로지스틱 성장

지수 성장은 시간이 지나면 한없이 커집니다. 실제 생물은 먹이와 공간이 모자라 어느 수 \(K\)(환경 수용력) 근처에서 멈춥니다. 개체 수가 \(K\)에 가까워질수록 성장률이 0에 다가가게 하려면 \(r\) 대신 \(r(1 - P/K)\)를 쓰면 됩니다.

정리 10.2.3 (로지스틱 방정식의 해)

\(P' = rP\left(1 - \dfrac{P}{K}\right)\), \(P(0) = P_0 > 0\)의 해는 \(P(t) = \dfrac{K}{1 + Ae^{-rt}}\), \(A = \dfrac{K - P_0}{P_0}\)이다.

변수를 나누면 \(\displaystyle\int \frac{K\,dP}{P(K - P)} = \int r\,dt\)입니다. 부분분수(5.4절)로 \(\dfrac{K}{P(K - P)} = \dfrac1P + \dfrac{1}{K - P}\)이므로 왼쪽은 \(\ln|P| - \ln|K - P| = \ln\left|\dfrac{P}{K - P}\right|\)입니다. 따라서 \(\ln\left|\dfrac{P}{K - P}\right| = rt + C\)이고, 양변의 지수를 취하면 \(\dfrac{K - P}{P} = Ae^{-rt}\)(\(A\)는 상수)입니다. \(t = 0\)을 넣으면 \(A = \dfrac{K - P_0}{P_0}\)입니다. 이 식을 \(P\)에 대해 풀면 \(\dfrac KP - 1 = Ae^{-rt}\), 곧 \(P = \dfrac{K}{1 + Ae^{-rt}}\)입니다. 마지막으로 이 식을 미분해 원래 식에 넣으면 등식이 성립하므로 해입니다. ∎

해를 읽어 보면, \(t \to \infty\)일 때 \(e^{-rt} \to 0\)이므로 \(P \to K\)입니다. \(P_0 < K\)이면 \(A > 0\)이라 \(P\)는 \(K\) 아래에서 올라가고, \(P_0 > K\)이면 \(-1 < A < 0\)이라 위에서 내려옵니다. 처음 \(P\)가 \(K\)보다 아주 작을 때는 \(1 - P/K \approx 1\)이라 지수 성장과 거의 같습니다.

예제 10.2.4

\(r = 0.6\), \(K = 120\), \(P_0 = 5\)일 때 \(P(5)\)를 구하고, 같은 \(r\), \(P_0\)의 지수 성장과 비교하여라. 증가 속도가 가장 큰 때는 언제인가?

풀이. \(A = 115/5 = 23\)이므로 \(P(5) = \dfrac{120}{1 + 23e^{-3}} \approx 55.9\)입니다. 지수 성장이면 \(5e^{3} \approx 100.4\)입니다. 증가 속도 \(rP(1 - P/K)\)는 \(P\)의 이차함수로 \(P = K/2 = 60\)에서 가장 크고, 그 값은 \(rK/4 = 18\)입니다. \(P = 60\)이 되는 때는 \(1 + 23e^{-0.6t} = 2\)에서 \(t = \ln 23 / 0.6 \approx 5.23\)입니다.

\(\int \dfrac{dy}{y} = \ln|y|\)에서 절댓값을 빠뜨리거나, 적분상수를 한쪽에만 붙이지 않고 양쪽에 따로 붙여 두 번 쓰는 실수가 흔합니다. 상수는 한쪽에 하나면 충분합니다.

요약
  1. 변수분리형 \(y' = g(x)h(y)\)는 \(\int dy/h(y) = \int g(x)\,dx + C\)로 푼다. \(h(y_0) = 0\)인 평형해를 따로 확인한다.
  2. 지수 성장 \(P = P_0e^{rt}\): 두 배가 되는 시간이 일정하다.
  3. 로지스틱 성장 \(P = K/(1 + Ae^{-rt})\): \(K\)로 다가가고, \(P = K/2\)에서 증가 속도가 가장 크다.
연습문제
  1. 기본 \(y' = xy^2\), \(y(0) = 1\)을 풀어라.
    답\(-1/y = x^2/2 + C\), \(C = -1\). \(y = \dfrac{2}{2 - x^2}\) (\(|x| < \sqrt2\)).
  2. 기본 세균이 3시간마다 두 배가 된다. \(r\)을 구하여라.
    답\(r = \ln 2 / 3 \approx 0.231\) (1/시간).
  3. 응용 로지스틱 모형에서 \(P_0 = K/2\)이면 해는 어떻게 되는가? \(A\)의 값으로 설명하여라.
    답\(A = 1\)이므로 \(P(t) = K/(1 + e^{-rt})\). \(t = 0\)에서 증가 속도가 가장 크고 이후 느려지며 \(K\)로 간다.

10.2.2

실습개체 수는 끝없이 늘어날까?

실습 · 지수 성장과 로지스틱 성장

다루는 성취기준 [공통1-10-02]

목표

먹이와 공간이 넉넉하면 개체 수는 지금 수에 비례해 늘어납니다(지수 성장, \(P' = rP\)). 실제로는 환경이 감당할 수 있는 수 \(K\)가 있어서 증가가 느려집니다(로지스틱 성장, \(P' = rP(1 - P/K)\)). 두 해를 겹쳐 보고, 세 값 \(r\), \(K\), \(P_0\)을 움직여 가상 자료에 곡선을 맞춰 봅니다. 성취기준 [공통1-10-02].

준비

  • 보라 곡선: 로지스틱 해 \(P(t) = \dfrac{K}{1 + (K/P_0 - 1)e^{-rt}}\). 변수분리로 얻습니다(본문 10.2절).
  • 회색 점선: 같은 \(r\), \(P_0\)의 지수 성장 \(P_0 e^{rt}\).
  • 빨간 점: 가상 자료입니다. 효모를 배양하며 시간마다 센 개체 수(단위: 백만 개)라고 상상해 만든 값입니다.

절차

  1. 처음 상태에서 \(t = 5\)와 \(t = 15\)일 때 두 모형의 값을 비교합니다.
  2. \(K\)를 먼저 맞춥니다. 가상 자료가 나중에 머무는 높이를 보고 \(K\)를 움직입니다.
  3. \(r\)을 움직여 곡선이 가파르게 오르는 구간을 자료에 맞춥니다. 출력의 "오차 제곱합"이 작아지는 쪽으로 움직입니다.
  4. 가장 작은 오차 제곱합을 얻은 \(r\), \(K\), \(P_0\)을 기록합니다.

기대 결과

  • 가상 자료는 \(r = 0.6\), \(K = 120\), \(P_0 = 5\)인 곡선에 작은 흔들림을 더해 만들었습니다. 이 값으로 맞추면 오차 제곱합이 60쯤으로 가장 작아집니다. 처음 값(\(r = 0.4\), \(K = 100\))에서는 14157입니다.
  • \(r = 0.6\), \(K = 120\), \(P_0 = 5\)에서 \(P(5) = 55.9\)(지수 성장이면 100.4), \(P(15) = 119.7\)(지수 성장이면 40515). 처음에는 두 모형이 거의 같고, 개체 수가 \(K\)에 가까워질수록 크게 갈라집니다.
  • 개체 수가 \(K/2 = 60\)일 때(\(t \approx 5.23\)) 곡선이 가장 가파르고, 그때 증가 속도는 \(rK/4 = 18\)입니다.

분석

  1. 로지스틱 식의 오른쪽 \(rP(1 - P/K)\)를 \(P\)에 대한 이차함수로 보면 왜 \(P = K/2\)에서 증가 속도가 가장 큰지 설명할 수 있나요?
  2. \(P_0 > K\)로 놓으면 곡선은 어떻게 움직이나요? 방향장(10.1절)과 함께 설명해 보세요.

더 해 보기

오차 제곱합을 가장 작게 하는 값을 컴퓨터가 찾게 하는 것이 최소제곱법입니다. 회귀 직선(공통7 10.2절)도 같은 생각입니다.
