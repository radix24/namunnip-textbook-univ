4.1.1넓이를 어떻게 정할까

직사각형이나 삼각형의 넓이는 공식이 있지만, \(y = x^2\) 아래, \(0 \le x \le 1\) 부분처럼 곡선으로 둘러싸인 넓이는 어떻게 정할까요? 고등학교에서는 "부정적분을 구해 위끝과 아래끝 값을 뺀다"고 배웠지만, 그것은 계산법이고 넓이가 무엇인지에 대한 설명은 아닙니다. 아르키메데스 때부터 쓴 생각은 영역을 얇은 직사각형으로 잘라 그 넓이를 더하는 것입니다.

\([0, 1]\)을 \(n\)등분하면 각 조각의 폭은 \(\frac1n\)입니다. \(k\)번째 조각의 오른쪽 끝 \(\frac kn\)에서 높이 \(\left(\frac kn\right)^2\)인 직사각형을 세우면 넓이의 합은

\[R_n = \sum_{k=1}^{n}\left(\frac kn\right)^2\cdot\frac1n = \frac{1}{n^3}\sum_{k=1}^{n}k^2 = \frac{(n+1)(2n+1)}{6n^2}\]

입니다. \(n = 10\)이면 0.385, \(n = 100\)이면 0.33835, \(n = 1000\)이면 0.3338335로, \(n\)을 키우면 \(\frac13\)에 다가갑니다. 실제로 \(R_n = \frac16\left(1 + \frac1n\right)\left(2 + \frac1n\right) \to \frac26 = \frac13\)입니다. 이 극한을 넓이로 정의합니다.

4.1.2정적분의 정의

정의 4.1.1 (정적분)

\(f\)가 \([a, b]\)에서 정의된 함수일 때, \([a, b]\)를 폭 \(\Delta x = \frac{b - a}{n}\)인 \(n\)개의 작은 구간으로 나누고 각 작은 구간에서 점 \(x_k^*\)를 고른다. 극한

\[\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{k=1}^{n}f(x_k^*)\,\Delta x\]

가 점을 고르는 방법에 상관없이 같은 값으로 존재하면, 이를 \(f\)의 \(a\)에서 \(b\)까지의 정적분이라 한다. 합 \(\sum f(x_k^*)\Delta x\)를 리만 합이라 한다.

기호 \(\int\)는 합(Sum)의 S를 길게 늘인 것이고, \(dx\)는 폭 \(\Delta x\)가 한없이 얇아진 것을 나타냅니다. 곧 \(\int_a^b f(x)\,dx\)는 "높이 \(f(x)\) × 아주 얇은 폭 \(dx\)를 \(a\)부터 \(b\)까지 모두 더한 것"이라고 읽으면 됩니다. 이 읽는 법은 6단원(부피, 길이)과 물리(일, 질량)에서 그대로 쓰입니다.

연속함수이면 이 극한이 항상 존재합니다(증명은 해석학 과목). 그래서 이 과목에서 다루는 함수는 모두 정적분을 가집니다.

4.1.3부호 있는 넓이와 성질

\(f(x) < 0\)인 곳에서는 \(f(x_k^*)\Delta x\)가 음수입니다. 그래서 정적분은 "\(x\)축 위의 넓이 − \(x\)축 아래의 넓이"인 부호 있는 넓이입니다. 예를 들어 \(\int_0^{2\pi}\sin x\,dx = 0\)인 것은 위아래 넓이가 같기 때문입니다.

리만 합의 성질에서 다음이 나옵니다.

  • \(\int_a^b [f(x) + g(x)]\,dx = \int_a^b f\,dx + \int_a^b g\,dx\), \(\int_a^b cf\,dx = c\int_a^b f\,dx\).
  • \(\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx\).
  • \(\int_b^a f\,dx = -\int_a^b f\,dx\), \(\int_a^a f\,dx = 0\).
  • \([a, b]\)에서 \(f(x) \le g(x)\)이면 \(\int_a^b f\,dx \le \int_a^b g\,dx\).
예제 4.1.2

넓이로 해석하여 \(\int_0^3\sqrt{9 - x^2}\,dx\)와 \(\int_0^5(x - 2)\,dx\)를 구하여라.

풀이. \(y = \sqrt{9 - x^2}\)은 반지름 3인 원의 위쪽 반이고, \(0 \le x \le 3\)은 그중 \(\frac14\)입니다. 넓이 \(\frac14\pi\cdot9 = \frac{9\pi}{4}\).

\(y = x - 2\)는 직선입니다. \(0 \le x \le 2\)에서는 \(x\)축 아래에 넓이 2인 삼각형, \(2 \le x \le 5\)에서는 위에 넓이 \(\frac92\)인 삼각형이 있으므로 정적분은 \(\frac92 - 2 = \frac52\).

주의정적분과 넓이는 같지 않습니다. 함수가 음수인 부분이 있으면 정적분은 넓이보다 작습니다. "넓이"를 물으면 \(\int_a^b|f(x)|\,dx\)를 구해야 합니다.
요약
  1. 정적분은 리만 합 \(\sum f(x_k^*)\Delta x\)의 극한이다. "높이 × 얇은 폭의 합"으로 읽는다.
  2. 정적분은 부호 있는 넓이: \(x\)축 위는 +, 아래는 −.
  3. 선형성, 구간 나누기, 위끝·아래끝 바꾸면 부호 바뀜, 크기 비교가 성립한다.

4.1.4연습문제

기본

  1. 리만 합의 극한으로 \(\int_0^2 x\,dx\)를 구하여라.
    답

    \(\Delta x = \frac2n\), \(x_k = \frac{2k}{n}\). 합 \(\frac{4}{n^2}\cdot\frac{n(n+1)}{2} \to 2\).

  2. 넓이로 해석하여 \(\int_{-1}^{1}|x|\,dx\)를 구하여라.
    답

    삼각형 두 개, 각 \(\frac12\). 합 1.

응용

  1. \(\int_0^1 f(x)\,dx = 2\), \(\int_0^3 f(x)\,dx = 5\)일 때 \(\int_1^3 f(x)\,dx\)와 \(\int_3^1 2f(x)\,dx\)는?
    답

    \(5 - 2 = 3\), \(-2\cdot3 = -6\).

  2. \(\int_0^1 e^{-x^2}dx\)가 \(e^{-1}\)과 1 사이에 있음을 보여라.
    답

    \(0 \le x \le 1\)에서 \(e^{-1} \le e^{-x^2} \le 1\). 크기 비교 성질로 적분하면 \(e^{-1} \le \int \le 1\).

4.1.2

설명리만 합으로 정의하는 정적분

분할 · 표본점 · 극한

다루는 성취기준 [공통1-04-01]

왜 필요한가

고등학교에서는 정적분을 "부정적분의 차" \(F(b) - F(a)\)로 계산했습니다. 그러나 이것은 정의가 아니라 정리(미적분의 기본정리)입니다. 부정적분을 식으로 쓸 수 없는 함수(\(e^{-x^2}\))나 측정 데이터에도 적분을 쓰려면, 넓이를 "잘게 나눠 더한 것의 극한"으로 직접 정의해야 합니다.

정의 · 리만 합과 정적분

\([a, b]\)를 \(a = x_0 < x_1 < \dots < x_n = b\)로 나누고(분할 \(P\)), 각 소구간 \([x_{i-1}, x_i]\)에서 점 \(x_i^*\)를 고른다. \(\Delta x_i = x_i - x_{i-1}\)일 때

\[R(P) = \sum_{i=1}^{n} f(x_i^*)\,\Delta x_i\]

를 리만 합이라 한다. 가장 긴 소구간의 길이 \(\|P\| \to 0\)일 때 표본점의 선택과 무관하게 \(R(P)\)가 하나의 수 \(I\)로 가면, \(f\)는 \([a,b]\)에서 적분 가능하고 \(\int_a^b f(x)\,dx = I\)이다.

정의를 풀어 읽기

  1. \(f(x_i^*)\Delta x_i\)높이 \(f(x_i^*)\), 폭 \(\Delta x_i\)인 직사각형의 넓이. \(f < 0\)이면 음수입니다. 그래서 정적분은 "부호 있는 넓이"(축 위는 +, 아래는 −)입니다.
  2. 표본점 \(x_i^*\)왼쪽 끝, 오른쪽 끝, 가운데 등 아무 점이나 됩니다. 어떤 선택이든 같은 극한으로 가야 적분 가능합니다.
  3. \(\|P\| \to 0\)개수 \(n \to \infty\)만으로는 부족합니다. 모든 소구간이 가늘어져야 합니다. 계산할 때는 보통 등분할 \(\Delta x = \frac{b-a}{n}\)을 씁니다.
  4. \(dx\)\(\Delta x_i\)가 극한에서 바뀐 기호입니다. \(\int\)는 합 \(\Sigma\)의 S를 늘인 모양입니다.
정리 (증명은 해석학)

\([a,b]\)에서 연속인 함수는 적분 가능하다. 유한 개의 점에서만 불연속인 유계 함수도 적분 가능하다.

예: 정의로 \(\int_0^1 x^2\,dx\) 계산하기

  1. 등분할 \(\Delta x = \frac1n\), \(x_i = \frac in\), 오른쪽 끝을 표본점으로.
    \(x^2\)은 연속이라 적분 가능하므로, 한 가지 표본점 선택으로 극한을 구해도 된다.
  2. \(R_n = \sum_{i=1}^n \left(\frac in\right)^2\frac1n = \frac{1}{n^3}\sum_{i=1}^n i^2 = \frac{1}{n^3}\cdot\frac{n(n+1)(2n+1)}{6}\).
    제곱의 합 공식(수학적 귀납법으로 증명).
  3. \(R_n = \frac{(1 + \frac1n)(2 + \frac1n)}{6} \to \frac{2}{6} = \frac13\).
    분자, 분모를 \(n^3\)으로 나눈 뒤 극한.

왼쪽 끝을 쓰면 \(\frac{(n-1)n(2n-1)}{6n^3} \to \frac13\). 왼쪽 합은 넓이보다 작고(증가함수라 직사각형이 그래프 아래), 오른쪽 합은 크며, 둘이 같은 값으로 압축됩니다.

극한을 적분으로 읽기

거꾸로 \(\displaystyle\lim_{n\to\infty}\frac1n\sum_{i=1}^n f\!\left(\frac in\right) = \int_0^1 f(x)\,dx\)입니다. 예: \(\displaystyle\lim_{n\to\infty}\sum_{i=1}^n\frac{n}{n^2 + i^2} = \lim\frac1n\sum\frac{1}{1 + (i/n)^2} = \int_0^1\frac{dx}{1 + x^2} = \frac\pi4\).

정의에서 바로 나오는 성질

  • 선형성: \(\int(\alpha f + \beta g) = \alpha\int f + \beta\int g\) (리만 합이 선형이므로).
  • 구간 가법성: \(\int_a^b = \int_a^c + \int_c^b\). 약속: \(\int_b^a f = -\int_a^b f\).
  • 비교: \(f \le g\)이면 \(\int_a^b f \le \int_a^b g\). 특히 \(m \le f \le M\)이면 \(m(b - a) \le \int_a^b f \le M(b - a)\).

흔한 오해

  • "정적분 = 넓이." \(\int_0^{2\pi}\sin x\,dx = 0\)이지만 둘러싸인 넓이는 4입니다. 넓이는 \(\int|f|\)입니다.
  • "모든 유계 함수는 적분 가능." 유리수에서 1, 무리수에서 0인 함수는 어느 소구간에도 둘 다 있어서, 표본점을 유리수로 고르면 합이 1, 무리수로 고르면 0입니다. 적분 불가능합니다.

4.1.3

예제사다리꼴 공식과 Simpson 공식, 그리고 오차 한계

수치 적분 · 오차 추정

다루는 성취기준 [공통1-04-01]

공식

\([a,b]\)를 \(n\)등분, \(h = \frac{b-a}{n}\), \(x_i = a + ih\), \(y_i = f(x_i)\).

  • 사다리꼴: 각 소구간을 직선으로 이어 사다리꼴 넓이를 더한다. \[T_n = \frac h2\left(y_0 + 2y_1 + 2y_2 + \dots + 2y_{n-1} + y_n\right).\]
  • Simpson (\(n\) 짝수): 두 소구간마다 세 점을 지나는 포물선으로 근사한다. \[S_n = \frac h3\left(y_0 + 4y_1 + 2y_2 + 4y_3 + \dots + 4y_{n-1} + y_n\right).\]
오차 한계

\(|f''| \le K_2\)이면 \(|E_T| \le \dfrac{K_2(b-a)^3}{12n^2}\). \(|f^{(4)}| \le K_4\)이면 \(|E_S| \le \dfrac{K_4(b-a)^5}{180n^4}\).

증명은 보간 다항식의 오차 공식을 쓰므로 수치해석에서 다룹니다. 읽을 거리: 사다리꼴은 \(n\)을 2배로 하면 오차가 약 \(\frac14\), Simpson은 약 \(\frac{1}{16}\)이 됩니다. 또 사다리꼴 오차에 \(f''\)이 들어가므로 일차식에서는 정확하고, Simpson은 삼차식까지 정확합니다.

먼저 예측

같은 다섯 점으로 계산할 때 Simpson 공식은 사다리꼴 공식보다 몇 배쯤 정확할까요? 2배? 10배? 그 이상?

예측 확인

이 예에서 약 36배입니다. 직선 대신 포물선으로 이어 곡률까지 잡기 때문입니다.

\(\ln 2 = \displaystyle\int_1^2\frac{dx}{x}\)를 \(n = 4\)인 사다리꼴, Simpson 공식으로 근사하고 오차 한계와 실제 오차를 비교하세요. 또 사다리꼴로 오차를 \(10^{-6}\) 이하로 하려면 \(n\)이 얼마나 커야 하나요?

풀이

  1. \(h = 0.25\), \(y = 1,\ 0.8,\ 0.666667,\ 0.571429,\ 0.5\) (\(x = 1, 1.25, 1.5, 1.75, 2\)).
    \(y_i = \frac{1}{x_i}\).
  2. \(T_4 = \frac{0.25}{2}(1 + 2(0.8 + 0.666667 + 0.571429) + 0.5) = 0.125\times5.576190 = 0.697024\).
    가운데 점은 두 사다리꼴이 공유하므로 2배.
  3. \(S_4 = \frac{0.25}{3}(1 + 4(0.8) + 2(0.666667) + 4(0.571429) + 0.5) = \frac{0.25}{3}\times8.319048 = 0.693254\).
    계수 1, 4, 2, 4, 1.
  4. 참값 \(\ln2 = 0.693147\). 실제 오차: \(T_4\)는 \(0.003877\), \(S_4\)는 \(0.000107\).
    같은 다섯 점으로 Simpson이 약 36배 정확하다.
  5. 오차 한계: \(f'' = \frac{2}{x^3} \le 2 = K_2\), \(f^{(4)} = \frac{24}{x^5} \le 24 = K_4\) (\(x \ge 1\)). \(|E_T| \le \frac{2}{12\cdot16} = 0.0104\), \(|E_S| \le \frac{24}{180\cdot256} = 0.00052\).
    도함수의 절댓값이 구간에서 가장 큰 곳은 \(x = 1\). 한계는 실제 오차보다 크다(보장값이므로).
  6. \(\frac{2}{12n^2} \le 10^{-6}\iff n^2 \ge \frac{10^6}{6} \approx 166667 \iff n \ge 409\). (Simpson이면 \(\frac{24}{180n^4} \le 10^{-6} \iff n^4 \ge 133334 \iff n \ge 20\), 짝수 20.)
    오차 한계를 목표값 이하로 두고 \(n\)을 푼다. 올림.

의미

같은 다섯 점을 쓰고도 Simpson 공식이 약 36배 정확했습니다. 오차 한계를 쓰면 계산하기 전에 필요한 \(n\)을 정할 수 있습니다. 실제 수치 계산 프로그램은 오차가 큰 구간만 잘게 나누는 적응형 방법을 씁니다.

검산

\(\frac1x\)은 아래로 볼록(\(f'' > 0\))이라 사다리꼴의 윗변이 그래프 위에 있어 \(T_n\)은 참값보다 커야 합니다. \(0.697 > 0.693\). 맞습니다.

흔한 오해

  • Simpson에서 \(n\)을 홀수로: 두 구간씩 묶으므로 \(n\)은 짝수여야 합니다.
  • 오차 한계 = 실제 오차: 한계는 "이보다 크지 않다"는 보장일 뿐입니다.
4.1.4

실습리만 합으로 넓이 어림하기

실습 · 직사각형 수와 오차

다루는 성취기준 [공통1-04-01]

목표

구간을 \(n\)개로 나눈 직사각형(또는 사다리꼴)의 넓이 합이 정적분에 다가가는 것을 보고, 높이를 정하는 방법에 따라 오차가 줄어드는 빠르기가 다름을 확인합니다. 성취기준 [공통1-04-01].

준비

보랏빛 직사각형의 넓이 합이 리만 합입니다. \(x\)축 아래 부분은 음수로 더합니다. 출력의 마지막 줄은 \(n\)을 두 배로 했을 때 오차가 몇 분의 1이 되는지 보여 줍니다.

절차

  1. \(x^2\), \([0, 2]\), 왼쪽 끝으로 \(n = 4, 8, 16\)의 합과 오차를 기록한다.
  2. 오른쪽 끝, 가운데, 사다리꼴로 바꿔 같은 \(n\)의 오차를 비교한다.
  3. 각 방법에서 출력 마지막 줄의 "몇 분의 1"을 기록한다.
  4. \(x^3 - x\)에서 음의 넓이가 어떻게 처리되는지 본다.

기대 결과

  • 증가 함수에서 왼쪽 끝은 모자라고 오른쪽 끝은 넘친다. 두 값의 평균이 사다리꼴이다.
  • 왼쪽·오른쪽 끝: \(n\)을 두 배로 하면 오차가 약 2분의 1. 가운데와 사다리꼴: 약 4분의 1.
  • 가운데 방법의 오차는 사다리꼴의 약 절반이고 부호가 반대다.

분석

  1. 가운데 방법이 끝점 방법보다 훨씬 정확한 이유를 직사각형 위아래로 남고 모자란 조각으로 설명해 보세요.
  2. 정적분의 정의에서 "어느 점을 골라도 같은 극한"이라는 것이 왜 중요한가요?

더 해 보기

가운데 방법의 2배와 사다리꼴을 더해 3으로 나누면(심프슨 방법) 오차가 \(n\)의 4제곱으로 줄어듭니다. \(\sin x\), \(n = 4\)에서 두 출력값으로 직접 계산해 보세요.
