5.5.1

예제끝이 없는 적분: 이상적분과 비교 판정법

무한 구간 · 무한 피적분함수 · p-적분

다루는 성취기준 [공통1-05-05]

정의 · 이상적분

\(\displaystyle\int_a^\infty f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx\). 극한이 유한하면 수렴, 아니면 발산.

\(f\)가 \(b\) 근처에서 유계가 아니면 \(\displaystyle\int_a^b f = \lim_{t\to b^-}\int_a^t f\). \(\int_{-\infty}^{\infty}\)은 \(\int_{-\infty}^{0} + \int_0^\infty\)이 각각 수렴할 때만 수렴.

기준이 되는 p-적분

정리

\(\displaystyle\int_1^\infty\frac{dx}{x^p}\)는 \(p > 1\)이면 \(\frac{1}{p-1}\)로 수렴, \(p \le 1\)이면 발산. \(\displaystyle\int_0^1\frac{dx}{x^p}\)는 \(p < 1\)이면 수렴, \(p \ge 1\)이면 발산.

  1. \(p \ne 1\): \(\int_1^t x^{-p}dx = \frac{t^{1-p} - 1}{1 - p}\).
    거듭제곱의 적분.
  2. \(p > 1\)이면 \(t^{1-p} \to 0\)이라 극한 \(\frac{1}{p-1}\). \(p < 1\)이면 \(t^{1-p} \to \infty\).
    지수 \(1 - p\)의 부호.
  3. \(p = 1\): \(\int_1^t\frac{dx}{x} = \ln t \to \infty\).
    경계의 경우는 로그. \(\int_0^1\)도 같은 계산을 \(t \to 0^+\)로 한다.

기억법: 무한대 쪽에서는 빨리 줄어야(\(p > 1\)), 0 쪽에서는 천천히 커져야(\(p < 1\)) 수렴합니다. \(p = 1\)은 양쪽 모두 발산합니다.

정리 · 비교 판정법

\([a, \infty)\)에서 \(0 \le f(x) \le g(x)\)이면: \(\int_a^\infty g\)가 수렴하면 \(\int_a^\infty f\)도 수렴, \(\int_a^\infty f\)가 발산하면 \(\int_a^\infty g\)도 발산.

극한 비교: \(f, g > 0\)이고 \(\lim_{x\to\infty}\frac{f}{g} = L\), \(0 < L < \infty\)이면 둘은 함께 수렴하거나 함께 발산.

근거: \(F(t) = \int_a^t f\)는 \(f \ge 0\)이라 증가하고, \(\int_a^\infty g\)로 위가 막혀 있으므로 단조 수렴 정리(8단원)로 수렴합니다.

문제. 수렴, 발산을 판정하세요. (가) \(\displaystyle\int_1^\infty\frac{\sin^2 x}{x^2}dx\) (나) \(\displaystyle\int_1^\infty\frac{x + 1}{\sqrt{x^4 + x}}dx\) (다) \(\displaystyle\int_0^1\frac{dx}{\sqrt{x}\,(1 + x)}\) (라) \(\displaystyle\int_1^\infty e^{-x^2}dx\)

풀이

  1. (가) \(0 \le \frac{\sin^2x}{x^2} \le \frac{1}{x^2}\), \(\int_1^\infty\frac{dx}{x^2}\)은 수렴(\(p = 2\)). 따라서 수렴.
    진동하는 인수는 \(|\sin| \le 1\)로 눌러 둔다.
  2. (나) 큰 \(x\)에서 \(\frac{x + 1}{\sqrt{x^4 + x}} \approx \frac{x}{x^2} = \frac1x\). 극한 비교: \(\frac{(x+1)/\sqrt{x^4+x}}{1/x} = \frac{x^2 + x}{\sqrt{x^4 + x}} \to 1\). \(\int\frac1x\)이 발산하므로 발산.
    최고차항끼리 비교해 비교 대상을 찾는다. 분자·분모를 \(x^2\)으로 나누면 극한 1.
  3. (다) 0 근처에서 문제(\(\frac{1}{\sqrt x} \to \infty\)). \(0 < \frac{1}{\sqrt x(1+x)} \le \frac{1}{\sqrt x}\), \(\int_0^1 x^{-1/2}\)은 수렴(\(p = \frac12 < 1\)). 따라서 수렴.
    실제 값: \(u = \sqrt x\)로 치환하면 \(\int_0^1\frac{2du}{1 + u^2} = \frac\pi2\).
  4. (라) \(x \ge 1\)이면 \(x^2 \ge x\), \(e^{-x^2} \le e^{-x}\). \(\int_1^\infty e^{-x}dx = e^{-1}\) 수렴. 따라서 수렴.
    부정적분을 식으로 쓸 수 없어도 수렴은 판정할 수 있다.

의미

끝없이 뻗은 영역도 넓이가 유한할 수 있고, 그 경계가 \(p = 1\)입니다. 비교 판정법은 값을 구하지 않고 수렴만 판정합니다. 확률 밀도함수의 전체 적분이 1이 되려면 꼬리가 충분히 빨리 줄어야 하는데, (라)의 \(e^{-x^2}\)이 바로 정규분포의 꼬리입니다.

흔한 오해

  • 부등호 방향: "작은 것이 발산한다"로는 큰 것이 수렴하는지 알 수 없습니다. 수렴을 보이려면 위에서, 발산을 보이려면 아래에서 누릅니다.
  • "\(f \to 0\)이면 수렴." \(\frac1x \to 0\)이지만 \(\int_1^\infty\frac1x\)은 발산합니다.
  • 음수가 섞인 함수에 비교 판정: 조건 \(f \ge 0\)이 필요합니다. 부호가 바뀌면 \(|f|\)에 적용해 절대수렴을 봅니다.
