5.5.1끝없이 뻗은 영역의 넓이

\(y = \frac{1}{x^2}\) 아래, \(x \ge 1\)인 부분은 오른쪽으로 끝없이 뻗어 있습니다. 넓이가 무한할 것 같지만, \(1\)부터 \(t\)까지의 넓이는 \(\int_1^t\frac{dx}{x^2} = 1 - \frac1t\)이고, \(t\)를 아무리 키워도 1을 넘지 않으며 1에 다가갑니다. 그래서 이 영역의 넓이를 1로 정합니다.

정의 5.5.1 (무한 구간의 이상적분) \[\int_a^\infty f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx.\]

극한이 존재하면 수렴, 존재하지 않으면 발산한다고 한다. \(\int_{-\infty}^b\)도 같은 방법으로, \(\int_{-\infty}^\infty\)는 둘로 나누어 각각 수렴할 때 수렴한다.

정의 5.5.2 (불연속인 함수의 이상적분)

\(f\)가 \([a, b)\)에서 연속이고 \(b\)에서 무한히 커지면 \(\displaystyle\int_a^b f(x)\,dx = \lim_{t\to b^-}\int_a^t f(x)\,dx\). 구간 가운데에서 무한히 커지면 그 점에서 둘로 나눈다.

5.5.2가장 중요한 예: \(\frac{1}{x^p}\)

정리 5.5.3

\(\displaystyle\int_1^\infty\frac{dx}{x^p}\)은 \(p > 1\)이면 \(\dfrac{1}{p - 1}\)로 수렴하고, \(p \le 1\)이면 발산한다.

\(p \ne 1\)이면 \(\int_1^t x^{-p}dx = \dfrac{t^{1-p} - 1}{1 - p}\)인데, \(p > 1\)이면 \(t^{1-p} \to 0\), \(p < 1\)이면 \(t^{1-p} \to \infty\)입니다. \(p = 1\)이면 \(\int_1^t\frac{dx}{x} = \ln t \to \infty\)입니다. \(\frac1x\)과 \(\frac{1}{x^2}\)은 모양이 비슷하지만, \(\frac1x\)은 0으로 가는 빠르기가 넓이를 유한하게 만들기에 조금 모자랍니다. 이 경계(\(p = 1\))는 8단원의 급수에서 그대로 다시 나옵니다.

예제 5.5.4

(가) \(\int_0^\infty e^{-x}dx\) (나) \(\int_0^1\frac{dx}{\sqrt x}\) (다) \(\int_{-\infty}^\infty\frac{dx}{1 + x^2}\)

풀이. (가) \(\lim_{t\to\infty}(1 - e^{-t}) = 1\). 수렴. (나) \(x = 0\)에서 무한히 커집니다. \(\lim_{t\to0^+}[2\sqrt x]_t^1 = 2\). 수렴. (다) \(\int_0^\infty\frac{dx}{1 + x^2} = \lim\arctan t = \frac\pi2\)이고 왼쪽도 같으므로 \(\pi\). 수렴.

(가)는 확률·통계에서 지수분포의 확률이 모두 더해 1이 된다는 계산이고, (다)를 \(\pi\)로 나눈 \(\frac{1}{\pi(1 + x^2)}\)은 코시 분포라는 확률분포입니다.

5.5.3비교 판정법

적분을 직접 계산할 수 없을 때는 아는 함수와 크기를 비교합니다.

정리 5.5.5 (비교 판정법)

\(x \ge a\)에서 \(0 \le f(x) \le g(x)\)일 때, \(\int_a^\infty g\)가 수렴하면 \(\int_a^\infty f\)도 수렴하고, \(\int_a^\infty f\)가 발산하면 \(\int_a^\infty g\)도 발산한다.

큰 쪽의 넓이가 유한하면 작은 쪽도 유한하고, 작은 쪽이 무한하면 큰 쪽도 무한하다는 뜻입니다.

예제 5.5.6

\(\int_1^\infty e^{-x^2}dx\)와 \(\int_1^\infty\frac{1 + e^{-x}}{x}dx\)의 수렴을 판정하여라.

풀이. \(x \ge 1\)이면 \(x^2 \ge x\)이므로 \(e^{-x^2} \le e^{-x}\)이고 \(\int_1^\infty e^{-x}dx\)는 수렴합니다. 따라서 수렴합니다. (값은 기본 함수로 쓸 수 없지만 수렴한다는 것은 알 수 있습니다.)

\(\frac{1 + e^{-x}}{x} \ge \frac1x\)이고 \(\int_1^\infty\frac{dx}{x}\)는 발산하므로 발산합니다.

주의구간 안에서 무한히 커지는 점을 놓치면 틀린 계산을 합니다. \(\int_{-1}^{1}\frac{dx}{x^2}\)은 \(x = 0\)에서 무한히 커지므로 둘로 나누어야 하고, \(\int_0^1\frac{dx}{x^2}\)이 발산하므로 전체가 발산합니다(4.2절 주의 참고).
요약
  1. 이상적분은 보통 적분의 극한이다. 극한이 있으면 수렴.
  2. \(\int_1^\infty\frac{dx}{x^p}\): \(p > 1\) 수렴, \(p \le 1\) 발산. \(\int_0^1\frac{dx}{x^p}\): \(p < 1\) 수렴.
  3. 비교 판정법: 더 큰 것이 수렴하면 수렴, 더 작은 것이 발산하면 발산.

5.5.4연습문제

기본

  1. (가) \(\int_1^\infty\frac{dx}{x^3}\) (나) \(\int_0^\infty xe^{-x}dx\) (다) \(\int_0^1\ln x\,dx\)
    답

    (가) \(\frac12\) (나) 부분적분, 1 (다) \(\lim[x\ln x - x]_t^1 = -1\)

응용

  1. \(\int_1^\infty\frac{\sin^2x}{x^2}dx\)의 수렴을 판정하여라.
    답

    \(0 \le \frac{\sin^2x}{x^2} \le \frac{1}{x^2}\), 수렴.

  2. \(\int_0^1\frac{dx}{x^p}\)이 수렴하는 \(p\)의 범위를 구하여라.
    답

    \(p < 1\) (값 \(\frac{1}{1 - p}\)).

5.5.2

예제끝이 없는 적분: 이상적분과 비교 판정법

무한 구간 · 무한 피적분함수 · p-적분

다루는 성취기준 [공통1-05-05]

정의 · 이상적분

\(\displaystyle\int_a^\infty f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx\). 극한이 유한하면 수렴, 아니면 발산.

\(f\)가 \(b\) 근처에서 유계가 아니면 \(\displaystyle\int_a^b f = \lim_{t\to b^-}\int_a^t f\). \(\int_{-\infty}^{\infty}\)은 \(\int_{-\infty}^{0} + \int_0^\infty\)이 각각 수렴할 때만 수렴.

기준이 되는 p-적분

정리

\(\displaystyle\int_1^\infty\frac{dx}{x^p}\)는 \(p > 1\)이면 \(\frac{1}{p-1}\)로 수렴, \(p \le 1\)이면 발산. \(\displaystyle\int_0^1\frac{dx}{x^p}\)는 \(p < 1\)이면 수렴, \(p \ge 1\)이면 발산.

  1. \(p \ne 1\): \(\int_1^t x^{-p}dx = \frac{t^{1-p} - 1}{1 - p}\).
    거듭제곱의 적분.
  2. \(p > 1\)이면 \(t^{1-p} \to 0\)이라 극한 \(\frac{1}{p-1}\). \(p < 1\)이면 \(t^{1-p} \to \infty\).
    지수 \(1 - p\)의 부호.
  3. \(p = 1\): \(\int_1^t\frac{dx}{x} = \ln t \to \infty\).
    경계의 경우는 로그. \(\int_0^1\)도 같은 계산을 \(t \to 0^+\)로 한다.

기억법: 무한대 쪽에서는 빨리 줄어야(\(p > 1\)), 0 쪽에서는 천천히 커져야(\(p < 1\)) 수렴합니다. \(p = 1\)은 양쪽 모두 발산합니다.

정리 · 비교 판정법

\([a, \infty)\)에서 \(0 \le f(x) \le g(x)\)이면: \(\int_a^\infty g\)가 수렴하면 \(\int_a^\infty f\)도 수렴, \(\int_a^\infty f\)가 발산하면 \(\int_a^\infty g\)도 발산.

극한 비교: \(f, g > 0\)이고 \(\lim_{x\to\infty}\frac{f}{g} = L\), \(0 < L < \infty\)이면 둘은 함께 수렴하거나 함께 발산.

근거: \(F(t) = \int_a^t f\)는 \(f \ge 0\)이라 증가하고, \(\int_a^\infty g\)로 위가 막혀 있으므로 단조 수렴 정리(8단원)로 수렴합니다.

문제. 수렴, 발산을 판정하세요. (가) \(\displaystyle\int_1^\infty\frac{\sin^2 x}{x^2}dx\) (나) \(\displaystyle\int_1^\infty\frac{x + 1}{\sqrt{x^4 + x}}dx\) (다) \(\displaystyle\int_0^1\frac{dx}{\sqrt{x}\,(1 + x)}\) (라) \(\displaystyle\int_1^\infty e^{-x^2}dx\)

풀이

  1. (가) \(0 \le \frac{\sin^2x}{x^2} \le \frac{1}{x^2}\), \(\int_1^\infty\frac{dx}{x^2}\)은 수렴(\(p = 2\)). 따라서 수렴.
    진동하는 인수는 \(|\sin| \le 1\)로 눌러 둔다.
  2. (나) 큰 \(x\)에서 \(\frac{x + 1}{\sqrt{x^4 + x}} \approx \frac{x}{x^2} = \frac1x\). 극한 비교: \(\frac{(x+1)/\sqrt{x^4+x}}{1/x} = \frac{x^2 + x}{\sqrt{x^4 + x}} \to 1\). \(\int\frac1x\)이 발산하므로 발산.
    최고차항끼리 비교해 비교 대상을 찾는다. 분자·분모를 \(x^2\)으로 나누면 극한 1.
  3. (다) 0 근처에서 문제(\(\frac{1}{\sqrt x} \to \infty\)). \(0 < \frac{1}{\sqrt x(1+x)} \le \frac{1}{\sqrt x}\), \(\int_0^1 x^{-1/2}\)은 수렴(\(p = \frac12 < 1\)). 따라서 수렴.
    실제 값: \(u = \sqrt x\)로 치환하면 \(\int_0^1\frac{2du}{1 + u^2} = \frac\pi2\).
  4. (라) \(x \ge 1\)이면 \(x^2 \ge x\), \(e^{-x^2} \le e^{-x}\). \(\int_1^\infty e^{-x}dx = e^{-1}\) 수렴. 따라서 수렴.
    부정적분을 식으로 쓸 수 없어도 수렴은 판정할 수 있다.

의미

끝없이 뻗은 영역도 넓이가 유한할 수 있고, 그 경계가 \(p = 1\)입니다. 비교 판정법은 값을 구하지 않고 수렴만 판정합니다. 확률 밀도함수의 전체 적분이 1이 되려면 꼬리가 충분히 빨리 줄어야 하는데, (라)의 \(e^{-x^2}\)이 바로 정규분포의 꼬리입니다.

흔한 오해

  • 부등호 방향: "작은 것이 발산한다"로는 큰 것이 수렴하는지 알 수 없습니다. 수렴을 보이려면 위에서, 발산을 보이려면 아래에서 누릅니다.
  • "\(f \to 0\)이면 수렴." \(\frac1x \to 0\)이지만 \(\int_1^\infty\frac1x\)은 발산합니다.
  • 음수가 섞인 함수에 비교 판정: 조건 \(f \ge 0\)이 필요합니다. 부호가 바뀌면 \(|f|\)에 적용해 절대수렴을 봅니다.
