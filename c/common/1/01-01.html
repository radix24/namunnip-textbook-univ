1.1.1절댓값은 거리이다

고등학교에서 절댓값은 "부호를 떼는 것"으로 배웠습니다. 계산에는 이것으로 충분하지만, 미적분에서는 다른 읽는 법이 훨씬 쓸모 있습니다. \(|x|\)는 수직선 위에서 점 \(x\)와 원점 사이의 거리이고, 일반적으로

\[|x - a| = \text{점 } x \text{와 점 } a \text{ 사이의 거리}\]

입니다. 예를 들어 \(|3 - 7| = 4\)이고 \(|-2 - 5| = 7\)입니다. 빼는 순서는 상관없습니다: \(|x - a| = |a - x|\).

이렇게 읽으면 2장의 극한 정의에 나오는 "\(x\)가 \(a\)에 가깝다"를 숫자로 쓸 수 있습니다. "\(x\)와 \(a\)의 거리가 0.01보다 작다"는 \(|x - a| < 0.01\)입니다. 이 절은 그런 식을 자유롭게 풀고 바꾸는 연습입니다.

계산에 쓰는 기본 성질은 다음과 같습니다. 모두 \(x, y\)의 부호를 나누어 확인할 수 있습니다.

  • \(|x| \ge 0\)이고, \(|x| = 0\)인 것은 \(x = 0\)일 때뿐이다.
  • \(|xy| = |x||y|\), \(\left|\frac xy\right| = \frac{|x|}{|y|}\) (\(y \ne 0\)).
  • \(\sqrt{x^2} = |x|\). 그래서 \(\sqrt{x^2} = x\)라고 쓰면 \(x < 0\)일 때 틀린다.
  • \(-|x| \le x \le |x|\).

1.1.2절댓값 부등식의 기본형

정리 1.1.1

\(r > 0\)일 때

  1. \(|x - a| < r \iff a - r < x < a + r\), 곧 \(x \in (a - r, a + r)\).
  2. \(|x - a| > r \iff x < a - r\) 또는 \(x > a + r\).

거리로 읽으면 바로 보입니다. "\(a\)에서 거리가 \(r\)보다 작은 점"은 \(a\)를 가운데 둔 폭 \(2r\)의 열린구간이고, "거리가 \(r\)보다 큰 점"은 그 바깥입니다. 계산으로 확인하려면 \(x - a \ge 0\)인 경우와 \(x - a < 0\)인 경우로 나누면 됩니다.

증명.(1) \(x - a \ge 0\)이면 \(|x - a| < r\)은 \(x - a < r\), 곧 \(a \le x < a + r\)이다. \(x - a < 0\)이면 \(|x - a| = -(x - a) < r\)은 \(x > a - r\), 곧 \(a - r < x < a\)이다. 두 경우를 합치면 \(a - r < x < a + r\). (2)는 (1)의 부정에서 등호인 경우 \(|x - a| = r\)을 뺀 것이다. ∎

부등호에 등호가 붙으면(\(\le\), \(\ge\)) 구간의 끝점도 포함되어 닫힌구간이 됩니다.

예제 1.1.2

\(|2x - 3| \le 5\)를 풀어 구간으로 나타내어라.

풀이. 정리 1.1.1을 \(2x - 3\)에 적용하면 \(-5 \le 2x - 3 \le 5\)입니다. 세 변에 3을 더하면 \(-2 \le 2x \le 8\), 2로 나누면 \(-1 \le x \le 4\). 답은 \([-1, 4]\)입니다.

거리로 읽어 검산할 수 있습니다. \(|2x - 3| = 2\left|x - \frac32\right|\)이므로 부등식은 \(\left|x - \frac32\right| \le \frac52\), 곧 "\(\frac32\)에서 거리 \(\frac52\) 이내"입니다. \(\frac32 - \frac52 = -1\), \(\frac32 + \frac52 = 4\)로 같은 답입니다.

예제 1.1.3

\(|x + 1| > 2|x - 2|\)를 풀어라.

풀이. 양쪽에 절댓값이 있을 때는 두 가지 방법이 있습니다.

방법 1 (제곱). 양변이 모두 0 이상이므로 제곱해도 부등호 방향이 유지됩니다(\(0 \le A < B \iff A^2 < B^2\)). \((x + 1)^2 > 4(x - 2)^2\)을 정리하면 \(x^2 + 2x + 1 > 4x^2 - 16x + 16\), 곧 \(3x^2 - 18x + 15 < 0\), \(x^2 - 6x + 5 < 0\), \((x - 1)(x - 5) < 0\). 답은 \(1 < x < 5\)입니다.

방법 2 (경우 나누기). 절댓값 안이 0이 되는 \(x = -1\), \(x = 2\)로 수직선을 세 구간으로 나눕니다. \(x < -1\)이면 \(-(x + 1) > -2(x - 2)\), 곧 \(x > 5\)라서 해가 없습니다. \(-1 \le x < 2\)이면 \(x + 1 > -2(x - 2)\), 곧 \(x > 1\)이므로 \(1 < x < 2\). \(x \ge 2\)이면 \(x + 1 > 2(x - 2)\), 곧 \(x < 5\)이므로 \(2 \le x < 5\). 합치면 \(1 < x < 5\).

제곱하는 방법은 빠르지만 양변이 모두 음이 아님을 확인해야 쓸 수 있고, 경우를 나누는 방법은 느리지만 언제나 통합니다.

1.1.3삼각부등식

정리 1.1.4 (삼각부등식)

모든 실수 \(x, y\)에 대하여 \(|x + y| \le |x| + |y|\).

이름은 평면에서 "삼각형의 한 변은 나머지 두 변의 합보다 짧다"는 사실에서 왔습니다. 수직선에서는 "\(0\)에서 \(x\)로 간 뒤 다시 \(y\)만큼 가면, 같은 방향일 때만 거리가 그대로 더해지고 반대 방향이면 일부가 상쇄된다"는 뜻입니다.

증명.1.2.1의 성질에서 \(-|x| \le x \le |x|\), \(-|y| \le y \le |y|\)이다. 두 부등식을 변끼리 더하면 \(-(|x| + |y|) \le x + y \le |x| + |y|\)이다. 정리 1.1.1(등호를 포함한 판)에서 \(r = |x| + |y|\), \(a = 0\)으로 놓으면 이것은 \(|x + y| \le |x| + |y|\)와 같다. ∎

등호는 \(x\)와 \(y\)의 부호가 같을 때(또는 하나가 0일 때) 성립합니다. 삼각부등식에서 자주 쓰는 변형이 둘 있습니다.

  • \(|x - y| \le |x - z| + |z - y|\): 두 점 사이의 거리는 중간에 들른 점을 거친 거리 이하이다. (\(x - y = (x - z) + (z - y)\)에 정리 1.1.4를 쓴다.)
  • \(\big||x| - |y|\big| \le |x - y|\): 역삼각부등식. (\(|x| = |(x - y) + y| \le |x - y| + |y|\)에서 \(|x| - |y| \le |x - y|\), \(x, y\)를 바꾸어 반대쪽도 얻는다.)
예제 1.1.5 (극한 증명에서 쓰는 방식)

\(|x - 2| < 1\)이면 \(|x^2 - 4| < 5|x - 2|\)임을 보여라.

풀이. \(x^2 - 4 = (x - 2)(x + 2)\)이므로 \(|x^2 - 4| = |x - 2||x + 2|\)입니다. 남은 일은 \(|x + 2|\)를 상수로 위에서 막는 것입니다. \(|x - 2| < 1\)이면 \(1 < x < 3\)이므로 \(3 < x + 2 < 5\), 곧 \(|x + 2| < 5\)입니다. 삼각부등식으로도 \(|x + 2| = |(x - 2) + 4| \le |x - 2| + 4 < 5\)를 얻습니다. 따라서 \(|x^2 - 4| < 5|x - 2|\).

이 계산은 1.3절에서 "\(x \to 2\)일 때 \(x^2 \to 4\)"를 증명할 때 그대로 쓰입니다. \(x\)를 2 근처로 제한해 곱해지는 인수를 상수로 막는 것이 요령입니다.

주의\(|x - a| < r\)을 "\(x - a < r\) 그리고 \(x - a < -r\)"처럼 풀면 틀립니다. 올바른 꼴은 \(-r < x - a < r\)입니다. 또 \(|x| < -1\)처럼 오른쪽이 음수이면 해가 없고, \(|x| > -1\)이면 모든 실수가 해입니다. 절댓값은 음수가 될 수 없기 때문입니다.
요약
  1. \(|x - a|\)는 수직선에서 \(x\)와 \(a\) 사이의 거리이다.
  2. \(|x - a| < r \iff x \in (a - r, a + r)\), \(|x - a| > r \iff x\)가 그 구간 밖.
  3. 양변에 절댓값이 있으면 제곱하거나(양변이 0 이상일 때) 경우를 나눈다.
  4. 삼각부등식 \(|x + y| \le |x| + |y|\)와 역삼각부등식 \(\big||x| - |y|\big| \le |x - y|\).

1.1.4연습문제

기본

  1. 다음 부등식을 풀어 구간으로 나타내어라. (가) \(|x - 4| < 0.1\) (나) \(|3x + 6| \ge 9\) (다) \(|1 - 2x| \le 0\)
    답

    (가) \((3.9, 4.1)\) (나) \(3|x + 2| \ge 9\), 곧 \(|x + 2| \ge 3\): \((-\infty, -5] \cup [1, \infty)\) (다) \(1 - 2x = 0\)일 때뿐이므로 \(\{\frac12\}\).

  2. 구간 \((-3, 7)\)을 \(|x - a| < r\) 꼴로 나타내어라.
    답

    중점 \(a = 2\), 반폭 \(r = 5\): \(|x - 2| < 5\).

  3. \(\sqrt{(x - 3)^2} = x - 3\)이 성립하는 \(x\)의 범위를 구하여라.
    답

    \(\sqrt{(x-3)^2} = |x - 3|\)이므로 \(x - 3 \ge 0\), 곧 \(x \ge 3\).

응용

  1. \(|x - 1| + |x + 2| < 5\)를 풀어라.
    힌트

    \(x = -2\), \(x = 1\)로 세 구간을 나누세요. 거리로 읽으면 "1과 \(-2\)까지의 거리의 합이 5보다 작은 점"입니다.

    답

    \(x < -2\): \(-2x - 1 < 5\), \(x > -3\). \(-2 \le x \le 1\): \(3 < 5\) 항상 성립. \(x > 1\): \(2x + 1 < 5\), \(x < 2\). 답 \((-3, 2)\).

  2. \(|x - 3| < 1\)이면 \(\left|\frac1x - \frac13\right| < \frac{|x - 3|}{6}\)임을 보여라.
    힌트

    \(\frac1x - \frac13 = \frac{3 - x}{3x}\). \(|x - 3| < 1\)에서 \(x > 2\).

    답

    \(\left|\frac1x - \frac13\right| = \frac{|x - 3|}{3|x|}\)이고 \(x > 2\)이므로 \(3|x| > 6\). 따라서 \(< \frac{|x-3|}{6}\).

심화

  1. 모든 실수 \(x_1, \dots, x_n\)에 대하여 \(|x_1 + \cdots + x_n| \le |x_1| + \cdots + |x_n|\)임을 수학적 귀납법으로 증명하여라.
    힌트

    \(x_1 + \cdots + x_{n+1} = (x_1 + \cdots + x_n) + x_{n+1}\)에 정리 1.1.4를 쓰세요.

    답

    \(n = 1\)은 등식. \(n\)에서 성립하면 \(|x_1 + \cdots + x_{n+1}| \le |x_1 + \cdots + x_n| + |x_{n+1}| \le |x_1| + \cdots + |x_n| + |x_{n+1}|\). 첫 부등호는 삼각부등식, 둘째는 귀납 가정.

1.1.2

본문실수의 완비성: 상한과 하한 (보충)

보충 본문

다루는 성취기준 [공통1-01-01]

이 절에서 배울 것
  • 위로 유계, 상계, 상한(최소 상계)의 뜻을 정확히 말한다.
  • 최댓값과 상한의 차이를 예로 설명한다.
  • 실수의 완비성 공리가 무엇을 보장하는지, 유리수에서는 왜 깨지는지 이해한다.
  • 주어진 집합의 상한과 하한을 찾고, 그것이 상한임을 두 조건으로 확인한다.
먼저 알아야 할 것
  • 집합의 기호 \(\in\), \(\{x \mid \cdots\}\)와 구간 \([a, b]\), \((a, b)\) (고교 수학).
  • 부등식의 기본 성질: 양변에 같은 수를 더하거나, 같은 양수를 곱해도 부등호 방향이 같다.
  • \(\sqrt2\)가 유리수가 아니라는 사실 (고교 수학, 귀류법).

1.1.5왜 실수부터 다시 보는가

고등학교에서는 "수직선 위의 점이 실수"라고 배우고 바로 함수와 극한으로 넘어갔습니다. 그런데 미적분의 중요한 정리들, 예를 들어 "연속함수는 닫힌구간에서 최댓값을 갖는다"(1.4절)나 "증가하고 위로 막힌 수열은 수렴한다"(8.1절)는 실수가 가진 어떤 성질에 기대고 있습니다. 그 성질이 없으면 정리가 거짓이 됩니다.

무엇이 문제인지 유리수만 쓰는 세계에서 실험해 봅시다. 집합

\[A = \{x \in \mathbb{Q} \mid x > 0,\ x^2 < 2\}\]

를 생각합니다. \(\mathbb{Q}\)는 유리수 전체의 집합입니다. \(A\)에는 1, 1.4, 1.41, 1.414, … 처럼 \(\sqrt2\)에 점점 다가가는 유리수가 들어 있고, 모든 원소가 2보다 작습니다. 그러면 "\(A\)의 원소들이 다가가는 맨 끝 자리"는 어디일까요? 실수 안에서는 \(\sqrt2\)입니다. 하지만 유리수만 있는 세계에는 \(\sqrt2\)가 없으므로, 그 자리는 비어 있습니다. 수직선에 구멍이 있는 셈입니다.

실수가 유리수와 다른 핵심은 바로 이런 구멍이 없다는 것입니다. 이 절에서는 그 성질을 "상한"이라는 말로 정확히 표현합니다.

1.1.6상계와 상한

정의 1.1.6 (상계, 위로 유계)

실수의 집합 \(S\)와 실수 \(M\)에 대하여, \(S\)의 모든 원소 \(x\)가 \(x \le M\)을 만족하면 \(M\)을 \(S\)의 상계(upper bound)라 한다. 상계가 하나라도 있으면 \(S\)는 위로 유계라 한다.

상계는 "집합의 모든 원소보다 크거나 같은 수"입니다. 상계가 하나 있으면 그보다 큰 수도 모두 상계이므로, 상계는 하나가 아니라 무수히 많습니다. 예를 들어 \(S = [0, 1)\)이면 1, 2, 100이 모두 상계이고, 0.9는 상계가 아닙니다(0.95가 \(S\)에 있으니까요).

상계들 가운데 집합에 가장 바짝 붙은 것이 특별합니다.

정의 1.1.7 (상한)

실수 \(s\)가 다음 두 조건을 만족하면 \(s\)를 \(S\)의 상한(supremum, 최소 상계)이라 하고 \(\sup S\)로 쓴다.

  1. \(s\)는 \(S\)의 상계이다. 곧 모든 \(x \in S\)에 대하여 \(x \le s\).
  2. \(s\)보다 작은 수는 상계가 아니다. 곧 \(t < s\)이면 \(t < x\)인 \(x \in S\)가 있다.

조건 1은 "\(s\)는 집합 위에 있다", 조건 2는 "\(s\)를 조금이라도 내리면 집합의 어떤 원소가 그 위로 튀어나온다"는 뜻입니다. 둘을 합치면 \(s\)는 상계 가운데 가장 작은 수입니다.

조건 2는 자주 다음 꼴로 씁니다. 양수 \(\varepsilon\)(엡실론, "아주 작은 양수"를 나타낼 때 관습적으로 쓰는 그리스 문자)을 아무리 작게 잡아도

\[s - \varepsilon < x \le s\]

인 \(x \in S\)가 있다. \(t = s - \varepsilon\)으로 놓으면 정의의 조건 2와 같은 말입니다. 이 꼴은 2장의 극한 정의와 모양이 같아서, 앞으로 계속 다시 만나게 됩니다.

아래쪽도 똑같이 정의합니다.

  • 하계: 모든 \(x \in S\)에 대해 \(m \le x\)인 수 \(m\).
  • 아래로 유계: 하계가 하나라도 있는 집합.
  • 하한(infimum, 최대 하계): 하계 가운데 가장 큰 것. \(\inf S\)로 쓴다.
  • 유계: 위로도 아래로도 유계인 집합.
예제 1.1.8

\(S = [0, 1)\)의 상한과 하한을 구하고, 최댓값과 최솟값이 있는지 말하여라.

풀이. 상한이 1임을 정의의 두 조건으로 확인합니다. 조건 1: \(S\)의 모든 \(x\)는 \(x < 1\)이므로 \(x \le 1\)입니다. 조건 2: \(t < 1\)이라고 합시다. \(t < 0\)이면 \(x = 0\)이 \(t\)보다 큽니다. \(0 \le t < 1\)이면 \(t\)와 1의 중점 \(x = \frac{t + 1}{2}\)를 잡습니다. 그러면 \(t < x < 1\)이고 \(x \ge 0\)이므로 \(x \in S\)이고 \(x > t\)입니다. 따라서 \(\sup S = 1\).

하한은 0입니다. 0은 모든 원소 이하이고(하계), 0보다 큰 수 \(t\)는 원소 0보다 크므로 하계가 아닙니다.

0은 \(S\)에 들어 있으므로 최솟값입니다. 그러나 1은 \(S\)에 들어 있지 않으므로 최댓값이 아닙니다. 실제로 \(S\)에는 최댓값이 없습니다. 어떤 \(x \in S\)를 골라도 \(\frac{x + 1}{2}\)가 \(S\)에 있고 \(x\)보다 크기 때문입니다.

이 예가 보여 주듯 상한은 집합에 속하지 않을 수 있습니다. 상한이 집합에 속하면 그것이 곧 최댓값입니다. 최댓값 \(M\)은 상계이고, \(M\)보다 작은 수는 원소 \(M\)보다 작으니 상계가 아니기 때문입니다. 그래서 상한은 "최댓값이 없을 때도 쓸 수 있는 최댓값의 대용품"입니다.

정리 1.1.9 (상한은 하나뿐이다)

집합 \(S\)의 상한이 존재하면 오직 하나이다.

증명.\(s_1\)과 \(s_2\)가 모두 \(S\)의 상한이라고 하자. \(s_1\)은 상계이고 \(s_2\)는 상계 가운데 가장 작으므로(\(s_2\)의 조건 2), \(s_2 \le s_1\)이다. 역할을 바꾸면 \(s_1 \le s_2\)이다. 따라서 \(s_1 = s_2\)이다. ∎

그래서 "상한"이라고 정관사를 붙여 부르고 \(\sup S\)라는 기호를 쓸 수 있습니다.

1.1.7완비성 공리

이제 1.1.1의 구멍 이야기를 상한의 말로 옮길 수 있습니다. 유리수 집합 \(A = \{x \in \mathbb{Q} \mid x > 0, x^2 < 2\}\)는 위로 유계입니다(2가 상계). 그런데 유리수 가운데에는 \(A\)의 상한이 없습니다. 상한이 될 후보는 \(\sqrt2\)뿐인데 그것이 유리수가 아니기 때문입니다(연습문제 6). 실수에서는 이런 일이 일어나지 않는다는 것을 공리로 받아들입니다.

공리 1.1.10 (실수의 완비성, 상한 공리)

공집합이 아니고 위로 유계인 실수의 집합은 실수 안에 상한을 갖는다.

"공리"는 증명하지 않고 출발점으로 받아들이는 성질입니다. 실수를 엄밀하게 만드는 방법(데데킨트 절단, 코시 수열)도 있지만, 미적분학에서는 덧셈·곱셈·대소 관계의 익숙한 성질에 이 공리 하나를 더한 것을 실수의 정의로 씁니다. 공리 1.1.10에서 아래쪽 판(공집합이 아니고 아래로 유계인 집합은 하한을 갖는다)도 바로 나옵니다. \(S\)의 원소의 부호를 모두 바꾼 집합 \(-S\)를 생각하면 \(\inf S = -\sup(-S)\)이기 때문입니다.

"공집합이 아니고"라는 조건은 왜 필요할까요? 공집합에서는 모든 실수가 상계입니다("모든 원소가 \(M\) 이하"를 어기는 원소가 없으니까요). 그러면 상계 가운데 가장 작은 수가 없습니다. 그래서 공집합은 따로 빼 둡니다.

완비성에서 바로 나오는 결과 하나를 봅시다. 당연해 보이지만, 증명에는 완비성이 필요합니다.

정리 1.1.11 (아르키메데스 성질)

자연수 전체의 집합 \(\mathbb{N}\)은 위로 유계가 아니다. 따라서 어떤 양수 \(\varepsilon\)에 대해서도 \(\frac1n < \varepsilon\)인 자연수 \(n\)이 있다.

증명.\(\mathbb{N}\)이 위로 유계라고 가정하고 모순을 이끌어 낸다. \(\mathbb{N}\)은 공집합이 아니므로 공리 1.1.10에 의해 상한 \(s = \sup\mathbb{N}\)이 있다. \(s - 1 < s\)이므로 상한의 조건 2에 의해 \(s - 1 < n\)인 자연수 \(n\)이 있다. 그러면 \(n + 1 > s\)인데, \(n + 1\)도 자연수이므로 \(s\)가 상계라는 조건 1에 어긋난다. 따라서 \(\mathbb{N}\)은 위로 유계가 아니다. 이제 \(\varepsilon > 0\)이 주어지면 \(\frac1\varepsilon\)은 \(\mathbb{N}\)의 상계가 아니므로 \(n > \frac1\varepsilon\)인 자연수 \(n\)이 있고, 양변의 역수를 취하면 \(\frac1n < \varepsilon\)이다. ∎

"\(\frac1n\)은 얼마든지 작아진다"는 이 성질은 다음 예제와 2장의 극한 계산에서 계속 쓰입니다.

1.1.8상한을 찾고 확인하는 방법

주어진 집합의 상한을 구하는 일은 두 단계입니다. 먼저 원소를 몇 개 나열하거나 그래프를 그려 후보를 짐작합니다. 다음으로 그 후보가 정의 1.1.7의 두 조건을 만족함을 보입니다. 짐작만으로는 답이 아닙니다.

예제 1.1.12

\(S = \left\{1 - \frac1n \;\middle|\; n \in \mathbb{N}\right\}\)의 상한과 하한을 구하여라. 최댓값이 있는가?

풀이. 원소를 나열하면 \(0, \frac12, \frac23, \frac34, \dots\)로, 커지면서 1에 다가갑니다. 그래서 상한의 후보는 1, 하한의 후보는 0입니다.

조건 1: 모든 \(n\)에 대해 \(\frac1n > 0\)이므로 \(1 - \frac1n < 1\)입니다. 1은 상계입니다.

조건 2: \(\varepsilon > 0\)이 주어졌다고 합시다. \(1 - \varepsilon < 1 - \frac1n\)이 되는 \(n\)을 찾아야 하고, 이 부등식은 \(\frac1n < \varepsilon\)과 같습니다. 아르키메데스 성질(정리 1.1.11)이 바로 그런 \(n\)을 줍니다. 따라서 \(\sup S = 1\)입니다.

하한: \(n = 1\)일 때 원소 0이 있고, 모든 원소가 0 이상이므로 0은 최솟값이자 하한입니다.

최댓값은 없습니다. 상한 1이 \(S\)에 속하려면 \(\frac1n = 0\)인 \(n\)이 있어야 하는데 그런 자연수는 없기 때문입니다.

예제 1.1.13

\(S = \{x \in \mathbb{R} \mid x^2 < 3\}\)의 상한을 구하여라.

풀이. \(x^2 < 3\)은 \(-\sqrt3 < x < \sqrt3\)과 같으므로 \(S = (-\sqrt3, \sqrt3)\)이고, 예제 1.1.8과 같은 방법으로 \(\sup S = \sqrt3\)입니다. 조건 2를 확인할 때 \(t < \sqrt3\)이면 \(t\)와 \(\sqrt3\) 사이의 수(\(t \ge 0\)이면 중점 \(\frac{t + \sqrt3}{2}\), \(t < 0\)이면 0)가 \(S\)의 원소로서 \(t\)보다 큽니다. 같은 집합을 유리수 안에서 생각하면 상한이 없다는 점이 1.1.3과 대조됩니다.

주의"상한 = 가장 큰 원소"로 외우면 틀립니다. 가장 큰 원소(최댓값)는 없을 수 있지만, 공집합이 아니고 위로 유계이면 상한은 반드시 있습니다. 또 상계를 하나 찾았다고 상한을 찾은 것도 아닙니다. 조건 2(더 작은 상계가 없음)를 꼭 확인해야 합니다.
요약
  1. 상계는 모든 원소 이상인 수, 상한은 상계 가운데 가장 작은 수이다. 하한은 그 반대이다.
  2. \(s = \sup S\)임을 보이려면 (1) \(s\)가 상계이고 (2) 임의의 \(\varepsilon > 0\)에 대해 \(s - \varepsilon\)보다 큰 원소가 있음을 보인다.
  3. 상한은 집합에 속하지 않을 수 있다. 속하면 최댓값이다.
  4. 완비성 공리: 공집합이 아니고 위로 유계인 실수 집합은 상한을 갖는다. 유리수에서는 성립하지 않는다.

1.1.9연습문제

기본

  1. 다음 집합의 상한, 하한, 최댓값, 최솟값을 (있으면) 구하여라. (가) \((2, 5]\) (나) \(\{\frac{(-1)^n}{n} \mid n \in \mathbb{N}\}\) (다) \(\{x \mid x^2 \le 4\}\)
    힌트

    (나)는 원소를 나열해 보세요: \(-1, \frac12, -\frac13, \frac14, \dots\)

    답

    (가) 상한 5 = 최댓값, 하한 2, 최솟값 없음. (나) 상한 \(\frac12\) = 최댓값(\(n = 2\)), 하한 \(-1\) = 최솟값(\(n = 1\)). (다) \([-2, 2]\)이므로 상한 2 = 최댓값, 하한 \(-2\) = 최솟값.

  2. \(S = (0, 1)\)에서 0.999가 상계가 아님을 보여라.
    답

    \(0.9995 \in S\)이고 \(0.9995 > 0.999\)이다.

  3. 집합이 최댓값 \(M\)을 가지면 \(\sup S = M\)임을 정의 1.1.7의 두 조건으로 보여라.
    답

    최댓값의 뜻에 의해 모든 원소가 \(M\) 이하이므로 상계(조건 1). \(t < M\)이면 원소 \(M\)이 \(t\)보다 크므로 \(t\)는 상계가 아니다(조건 2).

응용

  1. \(S = \left\{\frac{n}{n + 1} \;\middle|\; n \in \mathbb{N}\right\}\)의 상한이 1임을 증명하여라.
    힌트

    \(\frac{n}{n+1} = 1 - \frac{1}{n+1}\). 예제 1.1.12을 따라 하세요.

    답

    조건 1: \(1 - \frac{1}{n+1} < 1\). 조건 2: \(\varepsilon > 0\)이면 아르키메데스 성질로 \(\frac1n < \varepsilon\)인 \(n\)이 있고, \(\frac{1}{n+1} < \frac1n < \varepsilon\)이므로 \(\frac{n}{n+1} > 1 - \varepsilon\).

  2. \(A, B\)가 공집합이 아니고 위로 유계이며 \(A \subset B\)이면 \(\sup A \le \sup B\)임을 보여라.
    힌트

    \(\sup B\)가 \(A\)의 상계이기도 함을 보이세요.

    답

    \(x \in A\)이면 \(x \in B\)이므로 \(x \le \sup B\). 곧 \(\sup B\)는 \(A\)의 상계이다. \(\sup A\)는 \(A\)의 상계 가운데 가장 작으므로 \(\sup A \le \sup B\).

심화

  1. 1.1.1의 집합 \(A = \{x \in \mathbb{Q} \mid x > 0, x^2 < 2\}\)에 대해, 어떤 유리수 \(r\)도 \(A\)의 상한이 될 수 없음을 보여라.
    힌트

    \(r^2 = 2\)는 불가능하므로 \(r^2 < 2\) 또는 \(r^2 > 2\)이다. \(r^2 < 2\)이면 \(r\)보다 조금 큰 유리수 \(r + \frac1n\)도 제곱이 2보다 작음을 보이세요. \((r + \frac1n)^2 \le r^2 + \frac{2r + 1}{n}\).

    답

    \(r^2 < 2\)이면 \(n\)을 \(\frac{2r + 1}{n} < 2 - r^2\)이 되게 크게 잡아 \(r + \frac1n \in A\)이고 \(r\)보다 크므로 \(r\)은 상계가 아니다. \(r^2 > 2\)이면 같은 방법으로 \((r - \frac1n)^2 \ge r^2 - \frac{2r}{n} > 2\)인 \(n\)을 잡으면 \(r - \frac1n\)도 상계이므로 \(r\)은 가장 작은 상계가 아니다. \(r^2 = 2\)인 유리수는 없다. 따라서 유리수 상한은 없다.

1.1.3

예제절댓값 부등식은 '거리'로 읽는다

절댓값 · 구간 · 삼각부등식

다루는 성취기준 [공통1-01-01]

먼저 읽는 법

\(|x - a|\)는 수직선에서 \(x\)와 \(a\) 사이의 거리입니다. 그래서

\[|x - a| < r \iff a - r < x < a + r, \qquad |x - a| > r \iff x < a - r \text{ 또는 } x > a + r.\]

앞의 것은 "\(a\)에서 \(r\)보다 가까운 점", 뒤의 것은 "\(r\)보다 먼 점"입니다. ε-δ 정의의 \(|x - a| < \delta\)가 바로 이 꼴입니다.

문제 1. \(|2x + 1| \ge 5\)를 풀어 구간으로 나타내세요.

풀이

  1. \(|2x+1| = 2\left|x + \frac12\right|\)이므로 부등식은 \(\left|x - \left(-\frac12\right)\right| \ge \frac52\)이다.
    \(|cu| = |c||u|\). 계수를 빼내야 '거리' 꼴이 된다.
  2. \(-\frac12\)에서 \(\frac52\) 이상 떨어진 점이므로 \(x \le -\frac12 - \frac52 = -3\) 또는 \(x \ge -\frac12 + \frac52 = 2\).
    \(|x-a| \ge r \iff x \le a - r\) 또는 \(x \ge a + r\).
  3. 답: \((-\infty, -3] \cup [2, \infty)\).
    등호가 있으므로 끝점 포함(닫힌 괄호).
먼저 예측

문제 2의 \(|x - 1| + |x + 2| < 5\)는 "1까지의 거리와 −2까지의 거리의 합이 5보다 작은 점"입니다. 해는 구간일까요? 길이는?

예측 확인

길이 5인 구간 \((-3, 2)\)입니다. 두 점 사이(거리 3)에서는 합이 늘 3이고, 바깥으로 1만큼씩 더 갈 수 있습니다.

문제 2. \(|x - 1| + |x + 2| < 5\)를 푸세요.

전략

절댓값이 두 개면 '거리의 합'으로 읽을 수도 있지만(1과 −2까지의 거리 합이 5보다 작은 점), 확실한 방법은 절댓값 안이 0이 되는 점에서 나누어 각 구간에서 절댓값을 벗기는 것입니다. 경계점은 \(x = -2\)와 \(x = 1\)입니다.

풀이

  1. \(x < -2\)이면 \(x - 1 < 0\), \(x + 2 < 0\)이므로 식은 \(-(x-1) - (x+2) = -2x - 1 < 5\), 곧 \(x > -3\). 이 구간과 겹치는 부분은 \(-3 < x < -2\).
    \(u < 0\)이면 \(|u| = -u\). 구한 해를 그 구간과 반드시 겹쳐 본다.
  2. \(-2 \le x < 1\)이면 \(-(x-1) + (x+2) = 3 < 5\)로 늘 참이다. 이 구간 전체가 해.
    \(x - 1 < 0\), \(x + 2 \ge 0\). 두 점 사이에서는 거리의 합이 두 점 사이 거리 3으로 일정하다.
  3. \(x \ge 1\)이면 \((x - 1) + (x + 2) = 2x + 1 < 5\), 곧 \(x < 2\). 겹치는 부분은 \(1 \le x < 2\).
    두 절댓값 안이 모두 0 이상.
  4. 세 경우를 합치면 \(-3 < x < 2\), 곧 \((-3, 2)\).
    경우 나누기의 해는 합집합.

의미

\(|x - a| < r\)를 "\(a\)에서 거리 \(r\) 안"으로 읽는 습관이 이 카드의 핵심입니다. 다음 단원의 ε-δ 정의는 처음부터 끝까지 이 문장으로 쓰여 있습니다: \(|x - a| < \delta\)이면 \(|f(x) - L| < \varepsilon\).

검산

끝점 \(x = 2\): \(|1| + |4| = 5\), 부등식 \(< 5\)가 아니므로 제외. 맞습니다. 안쪽 점 \(x = 0\): \(1 + 2 = 3 < 5\). 바깥 점 \(x = 3\): \(2 + 5 = 7\). 해의 경계와 일치합니다.

삼각부등식

정리

모든 실수 \(u, v\)에 대해 \(|u + v| \le |u| + |v|\). 따라서 \(|u - w| \le |u - v| + |v - w|\).

  1. \(-|u| \le u \le |u|\), \(-|v| \le v \le |v|\).
    절댓값의 정의(경우 \(u \ge 0\), \(u < 0\)을 나눠 확인).
  2. 더하면 \(-(|u| + |v|) \le u + v \le |u| + |v|\).
    부등식끼리 더하기.
  3. \(|y| \le c \iff -c \le y \le c\)이므로 \(|u+v| \le |u| + |v|\). 두 번째 식은 \(u \to u - v\), \(v \to v - w\)로 바꿔 넣은 것.
    절댓값 부등식의 '거리' 읽기.

두 번째 식은 "\(u\)에서 \(w\)로 곧장 가는 거리는 \(v\)를 거쳐 가는 거리보다 길지 않다"입니다. 극한 증명에서 \(|f(x) - L|\)을 쪼갤 때 매번 씁니다.

바꿔 보기

  • 문제 2에서 5를 3으로 바꾸면? 2단계의 "3 < 3"이 거짓이 되고 다른 경우도 해가 없어 해가 없습니다. 두 점까지 거리의 합은 3보다 작을 수 없기 때문입니다.
  • \(|x - 1| < |x + 2|\)는? 1보다 −2에서 더 먼 점, 곧 두 점의 가운데 \(-\frac12\)보다 오른쪽: \(x > -\frac12\).
1.1.4

설명최댓값이 없어도 '맨 위'는 있다: 상한과 하한

실수의 완비성

다루는 성취기준 [공통1-01-01]

왜 필요한가

집합 \(A = \{x : 0 \le x < 1\}\)에는 최댓값이 없습니다. 0.9, 0.99, 0.999 … 어떤 원소를 골라도 그보다 큰 원소가 \(A\) 안에 있기 때문입니다. 그래도 "\(A\)는 1까지 차 있다"는 느낌은 분명합니다. 이 '1'을 가리키는 말이 상한입니다.

미적분의 거의 모든 정리(중간값 정리, 최대·최소 정리, 단조수렴 정리)는 결국 "어떤 집합의 상한이 존재한다"는 사실 하나에 기대고 있습니다. 실수가 유리수와 다른 점도 바로 여기 있습니다.

정의 · 상계, 상한

실수의 부분집합 \(A\)에 대하여, 모든 \(a \in A\)에서 \(a \le M\)인 수 \(M\)을 \(A\)의 상계(upper bound)라 한다. 상계가 있는 집합을 위로 유계라 한다.

\(A\)의 상계 가운데 가장 작은 것을 \(A\)의 상한(supremum)이라 하고 \(\sup A\)로 쓴다. 곧 \(s = \sup A\)는 다음 두 조건을 만족한다.

\[\text{(i) } a \le s \ (\text{모든 } a \in A), \qquad \text{(ii) } M \text{이 } A\text{의 상계이면 } s \le M.\]

하계(lower bound)와 하한(infimum, \(\inf A\))은 부등호를 모두 뒤집어 같은 방식으로 정의한다.

공리 · 실수의 완비성

공집합이 아니고 위로 유계인 실수의 부분집합은 반드시 상한을 갖는다.

정의를 풀어 읽기

  1. (i) "모든 원소보다 크거나 같다"\(s\)는 상계입니다. 집합 위에 놓인 '천장' 중 하나라는 뜻입니다.
  2. (ii) "어떤 상계보다도 작거나 같다"천장 중에서 가장 낮은 천장입니다. 1.5도, 2도 \(A = [0,1)\)의 상계지만 상한은 아닙니다.
  3. 상한은 원소가 아니어도 된다\(\sup [0,1) = 1\)인데 \(1 \notin [0,1)\). 상한이 원소이면 그때 상한은 최댓값과 같습니다.
  4. 완비성은 증명하지 않는다실수를 정의하는 공리입니다. 유리수만 있는 세계에서는 \(\{x \in \mathbb{Q} : x^2 < 2\}\)의 상한이 없습니다(\(\sqrt2\)가 유리수가 아니므로). 실수는 이런 구멍이 없도록 만든 수 체계입니다.

쓰기 좋은 판정법: ε으로 확인하기

정리

\(s\)가 \(A\)의 상계일 때, \(s = \sup A\)일 필요충분조건은 "임의의 \(\varepsilon > 0\)에 대해 \(s - \varepsilon < a\)인 \(a \in A\)가 존재한다"이다.

  1. (⇒) \(s = \sup A\)이고 \(\varepsilon > 0\)이라 하자. \(s - \varepsilon < s\)이므로 \(s - \varepsilon\)은 상계일 수 없다.
    상한은 가장 작은 상계(조건 ii). \(s\)보다 작은 수는 상계가 아니다.
  2. 상계가 아니라는 것은 \(s - \varepsilon < a\)인 원소 \(a \in A\)가 있다는 뜻이다.
    "모든 \(a\)에서 \(a \le M\)"의 부정은 "어떤 \(a\)에서 \(a > M\)".
  3. (⇐) 조건이 성립하는데 \(s\)보다 작은 상계 \(M\)이 있다고 하자. \(\varepsilon = s - M > 0\)으로 두면, 조건에서 \(a > s - \varepsilon = M\)인 \(a \in A\)가 있다.
    귀류법. 가정한 조건에 특정한 ε을 넣는다.
  4. 이는 \(M\)이 상계라는 데 모순이다. 따라서 \(s\)보다 작은 상계는 없고, \(s\)는 상계이므로 \(s = \sup A\)이다.
    상한의 정의 (i), (ii).

이 판정법은 "상한은 집합에 한없이 가깝다"를 ε으로 정확히 쓴 것입니다. 극한 단원의 ε-δ 정의와 같은 방식입니다.

예와 반례

예 1. \(A = \{1 - \frac{1}{n} : n = 1, 2, 3, \dots\} = \{0, \frac12, \frac23, \frac34, \dots\}\). 모든 원소가 1보다 작으므로 1은 상계입니다. \(\varepsilon > 0\)이 주어지면 \(\frac1n < \varepsilon\)인 \(n\)을 잡을 수 있고(아르키메데스 성질), 그때 \(1 - \frac1n > 1 - \varepsilon\)입니다. 판정법으로 \(\sup A = 1\). 최댓값은 없고, 최솟값과 하한은 0입니다.

예 2. \(B = \{x : x^2 < 2\}\). \(\sup B = \sqrt2\), \(\inf B = -\sqrt2\)이고 둘 다 \(B\)의 원소가 아닙니다.

반례. \(\mathbb{N} = \{1, 2, 3, \dots\}\)은 위로 유계가 아니므로 상한이 없습니다(실수 안에서). \(\sup \mathbb{N} = \infty\)라고 쓰는 교재도 있지만, 이때 \(\infty\)는 실수가 아니라 "위로 유계가 아니다"를 줄여 쓴 기호입니다.

다른 개념과의 관계

  • 최댓값과의 관계: 최댓값이 있으면 그것이 상한입니다. 상한은 있지만 최댓값은 없을 수 있습니다.
  • 단조수렴 정리(8단원): 증가하고 위로 유계인 수열은 그 항들의 상한으로 수렴합니다. 이 판정법으로 증명합니다.
  • 중간값 정리(2단원): 축소구간 성질로 증명했는데, 축소구간 성질도 완비성에서 나옵니다.

흔한 오해

  • "상한은 가장 큰 원소다." 그것은 최댓값입니다. 상한은 원소가 아닐 수 있습니다.
  • "상한보다 조금 작은 수도 상계다." 아닙니다. 상한보다 작은 수는 모두 상계가 아닙니다. 그래서 판정법이 성립합니다.
