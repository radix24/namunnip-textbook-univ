1.1.1

설명최댓값이 없어도 '맨 위'는 있다: 상한과 하한

실수의 완비성

다루는 성취기준 [공통1-01-01]

왜 필요한가

집합 \(A = \{x : 0 \le x < 1\}\)에는 최댓값이 없습니다. 0.9, 0.99, 0.999 … 어떤 원소를 골라도 그보다 큰 원소가 \(A\) 안에 있기 때문입니다. 그래도 "\(A\)는 1까지 차 있다"는 느낌은 분명합니다. 이 '1'을 가리키는 말이 상한입니다.

미적분의 거의 모든 정리(중간값 정리, 최대·최소 정리, 단조수렴 정리)는 결국 "어떤 집합의 상한이 존재한다"는 사실 하나에 기대고 있습니다. 실수가 유리수와 다른 점도 바로 여기 있습니다.

정의 · 상계, 상한

실수의 부분집합 \(A\)에 대하여, 모든 \(a \in A\)에서 \(a \le M\)인 수 \(M\)을 \(A\)의 상계(upper bound)라 한다. 상계가 있는 집합을 위로 유계라 한다.

\(A\)의 상계 가운데 가장 작은 것을 \(A\)의 상한(supremum)이라 하고 \(\sup A\)로 쓴다. 곧 \(s = \sup A\)는 다음 두 조건을 만족한다.

\[\text{(i) } a \le s \ (\text{모든 } a \in A), \qquad \text{(ii) } M \text{이 } A\text{의 상계이면 } s \le M.\]

하계(lower bound)와 하한(infimum, \(\inf A\))은 부등호를 모두 뒤집어 같은 방식으로 정의한다.

공리 · 실수의 완비성

공집합이 아니고 위로 유계인 실수의 부분집합은 반드시 상한을 갖는다.

정의를 풀어 읽기

  1. (i) "모든 원소보다 크거나 같다"\(s\)는 상계입니다. 집합 위에 놓인 '천장' 중 하나라는 뜻입니다.
  2. (ii) "어떤 상계보다도 작거나 같다"천장 중에서 가장 낮은 천장입니다. 1.5도, 2도 \(A = [0,1)\)의 상계지만 상한은 아닙니다.
  3. 상한은 원소가 아니어도 된다\(\sup [0,1) = 1\)인데 \(1 \notin [0,1)\). 상한이 원소이면 그때 상한은 최댓값과 같습니다.
  4. 완비성은 증명하지 않는다실수를 정의하는 공리입니다. 유리수만 있는 세계에서는 \(\{x \in \mathbb{Q} : x^2 < 2\}\)의 상한이 없습니다(\(\sqrt2\)가 유리수가 아니므로). 실수는 이런 구멍이 없도록 만든 수 체계입니다.

쓰기 좋은 판정법: ε으로 확인하기

정리

\(s\)가 \(A\)의 상계일 때, \(s = \sup A\)일 필요충분조건은 "임의의 \(\varepsilon > 0\)에 대해 \(s - \varepsilon < a\)인 \(a \in A\)가 존재한다"이다.

  1. (⇒) \(s = \sup A\)이고 \(\varepsilon > 0\)이라 하자. \(s - \varepsilon < s\)이므로 \(s - \varepsilon\)은 상계일 수 없다.
    상한은 가장 작은 상계(조건 ii). \(s\)보다 작은 수는 상계가 아니다.
  2. 상계가 아니라는 것은 \(s - \varepsilon < a\)인 원소 \(a \in A\)가 있다는 뜻이다.
    "모든 \(a\)에서 \(a \le M\)"의 부정은 "어떤 \(a\)에서 \(a > M\)".
  3. (⇐) 조건이 성립하는데 \(s\)보다 작은 상계 \(M\)이 있다고 하자. \(\varepsilon = s - M > 0\)으로 두면, 조건에서 \(a > s - \varepsilon = M\)인 \(a \in A\)가 있다.
    귀류법. 가정한 조건에 특정한 ε을 넣는다.
  4. 이는 \(M\)이 상계라는 데 모순이다. 따라서 \(s\)보다 작은 상계는 없고, \(s\)는 상계이므로 \(s = \sup A\)이다.
    상한의 정의 (i), (ii).

이 판정법은 "상한은 집합에 한없이 가깝다"를 ε으로 정확히 쓴 것입니다. 극한 단원의 ε-δ 정의와 같은 방식입니다.

예와 반례

예 1. \(A = \{1 - \frac{1}{n} : n = 1, 2, 3, \dots\} = \{0, \frac12, \frac23, \frac34, \dots\}\). 모든 원소가 1보다 작으므로 1은 상계입니다. \(\varepsilon > 0\)이 주어지면 \(\frac1n < \varepsilon\)인 \(n\)을 잡을 수 있고(아르키메데스 성질), 그때 \(1 - \frac1n > 1 - \varepsilon\)입니다. 판정법으로 \(\sup A = 1\). 최댓값은 없고, 최솟값과 하한은 0입니다.

예 2. \(B = \{x : x^2 < 2\}\). \(\sup B = \sqrt2\), \(\inf B = -\sqrt2\)이고 둘 다 \(B\)의 원소가 아닙니다.

반례. \(\mathbb{N} = \{1, 2, 3, \dots\}\)은 위로 유계가 아니므로 상한이 없습니다(실수 안에서). \(\sup \mathbb{N} = \infty\)라고 쓰는 교재도 있지만, 이때 \(\infty\)는 실수가 아니라 "위로 유계가 아니다"를 줄여 쓴 기호입니다.

다른 개념과의 관계

  • 최댓값과의 관계: 최댓값이 있으면 그것이 상한입니다. 상한은 있지만 최댓값은 없을 수 있습니다.
  • 단조수렴 정리(8단원): 증가하고 위로 유계인 수열은 그 항들의 상한으로 수렴합니다. 이 판정법으로 증명합니다.
  • 중간값 정리(2단원): 축소구간 성질로 증명했는데, 축소구간 성질도 완비성에서 나옵니다.

흔한 오해

  • "상한은 가장 큰 원소다." 그것은 최댓값입니다. 상한은 원소가 아닐 수 있습니다.
  • "상한보다 조금 작은 수도 상계다." 아닙니다. 상한보다 작은 수는 모두 상계가 아닙니다. 그래서 판정법이 성립합니다.
