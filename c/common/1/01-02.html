1.2.1되돌리는 함수

섭씨 온도 \(C\)를 화씨로 바꾸는 함수는 \(F = f(C) = \frac95 C + 32\)입니다. 거꾸로 화씨를 섭씨로 바꾸려면 식을 \(C\)에 대해 풀면 됩니다: \(C = \frac59(F - 32)\). 이렇게 "출력에서 입력을 되찾는" 함수가 역함수입니다.

그런데 모든 함수를 되돌릴 수 있지는 않습니다. \(f(x) = x^2\)에서 출력이 4라면 입력은 2였을까요, \(-2\)였을까요? 알 수 없습니다. 두 입력이 같은 출력을 내면 출력만 보고는 입력을 하나로 정할 수 없습니다. 이 관찰이 역함수의 존재 조건입니다.

1.2.2일대일 함수와 역함수

정의 1.2.1 (일대일 함수)

함수 \(f\)의 정의역의 서로 다른 두 원소 \(x_1 \ne x_2\)에 대해 언제나 \(f(x_1) \ne f(x_2)\)이면 \(f\)를 일대일이라 한다. 같은 말로, \(f(x_1) = f(x_2)\)이면 \(x_1 = x_2\)이다.

정의 1.2.2 (역함수)

정의역이 \(A\), 치역이 \(B\)인 일대일 함수 \(f\)에 대하여, 각 \(y \in B\)에 \(f(x) = y\)인 단 하나의 \(x \in A\)를 대응시키는 함수를 \(f\)의 역함수라 하고 \(f^{-1}\)로 쓴다. 곧

\[f^{-1}(y) = x \iff f(x) = y.\]

정의에서 \(f^{-1}\)의 정의역은 \(f\)의 치역 \(B\)이고, \(f^{-1}\)의 치역은 \(f\)의 정의역 \(A\)입니다. 입력과 출력의 역할이 통째로 바뀝니다. 그래서 다음이 성립합니다.

\[f^{-1}(f(x)) = x \quad (x \in A), \qquad f(f^{-1}(y)) = y \quad (y \in B).\]

기호 \(f^{-1}\)의 \(-1\)은 지수가 아닙니다. \(f^{-1}(x)\)와 \(\frac{1}{f(x)}\)는 전혀 다른 것입니다. 예를 들어 \(f(x) = 2x\)이면 \(f^{-1}(x) = \frac x2\)이지만 \(\frac{1}{f(x)} = \frac{1}{2x}\)입니다.

일대일인지 그래프로 판정하는 방법이 있습니다. 수평선 판정법: 모든 수평선이 그래프와 많아야 한 번 만나면 일대일입니다. 두 번 만나는 수평선 \(y = c\)가 있으면 서로 다른 두 입력이 같은 출력 \(c\)를 낸다는 뜻이기 때문입니다. 특히 정의역 전체에서 증가하거나(\(x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\)) 감소하는 함수는 일대일입니다.

예제 1.2.3

\(f(x) = \frac{2x + 1}{x - 3}\) (\(x \ne 3\))이 일대일임을 보이고 역함수를 구하여라.

풀이. \(f(x_1) = f(x_2)\)라 하고 \(x_1 = x_2\)를 이끌어 냅니다. 분모를 곱해 정리하면

\[(2x_1 + 1)(x_2 - 3) = (2x_2 + 1)(x_1 - 3)\] \[\Rightarrow\ -6x_1 + x_2 = -6x_2 + x_1 \ \Rightarrow\ 7x_2 = 7x_1.\]

따라서 \(x_1 = x_2\)이고 일대일입니다. 역함수는 \(y = \frac{2x + 1}{x - 3}\)을 \(x\)에 대해 풉니다: \(y(x - 3) = 2x + 1\), \(x(y - 2) = 3y + 1\), \(x = \frac{3y + 1}{y - 2}\). 변수 이름을 관습대로 \(x\)로 바꾸어 \(f^{-1}(x) = \frac{3x + 1}{x - 2}\) (\(x \ne 2\))입니다. 치역에 2가 없다는 것(\(y = 2\)이면 \(0 = 7\)이 되어 풀리지 않음)도 이 계산에서 함께 나옵니다.

1.2.3정의역을 잘라 역함수 만들기

\(f(x) = x^2\)은 실수 전체에서 일대일이 아니지만, 정의역을 \([0, \infty)\)로 제한하면 증가함수가 되어 일대일입니다. 그 역함수가 \(\sqrt x\)입니다. 정의역을 \((-\infty, 0]\)으로 제한하면 역함수는 \(-\sqrt x\)가 됩니다. 어느 쪽으로 자르느냐에 따라 역함수가 달라지므로, 어디로 잘랐는지가 역함수 정의의 일부입니다.

삼각함수는 주기함수라서 같은 값을 무한히 반복합니다. 그래서 역함수를 만들려면 반드시 정의역을 잘라야 하고, 수학자들이 관습으로 정한 구간이 있습니다. 고르는 기준은 세 가지입니다. (1) 그 구간에서 증가하거나 감소할 것, (2) 함수가 가질 수 있는 모든 값을 한 번씩 가질 것, (3) 0 근처의 익숙한 각을 포함할 것.

1.2.4역삼각함수

정의 1.2.4 (역사인, 역코사인, 역탄젠트)
  • \(\sin\)을 \(\left[-\frac\pi2, \frac\pi2\right]\)로 제한한 함수의 역함수를 \(\arcsin\)이라 한다. 정의역 \([-1, 1]\), 치역 \(\left[-\frac\pi2, \frac\pi2\right]\).
  • \(\cos\)을 \([0, \pi]\)로 제한한 함수의 역함수를 \(\arccos\)이라 한다. 정의역 \([-1, 1]\), 치역 \([0, \pi]\).
  • \(\tan\)을 \(\left(-\frac\pi2, \frac\pi2\right)\)로 제한한 함수의 역함수를 \(\arctan\)이라 한다. 정의역 \(\mathbb{R}\), 치역 \(\left(-\frac\pi2, \frac\pi2\right)\).

읽는 법: \(\arcsin x\)는 "사인 값이 \(x\)인 각, 단 \(-\frac\pi2\)와 \(\frac\pi2\) 사이에서 고른 것"입니다. 각은 라디안으로 잽니다. \(\sin^{-1}x\)라고도 쓰지만, 앞에서 말했듯 \(\frac{1}{\sin x}\)과 헷갈리기 쉬워 이 책에서는 \(\arcsin\)을 씁니다.

왜 이 구간들일까요? \(\sin\)은 \(\left[-\frac\pi2, \frac\pi2\right]\)에서 \(-1\)부터 1까지 증가하며 모든 값을 한 번씩 지납니다. \(\cos\)은 그 구간에서 증가하지 않으므로(0에서 최댓값) 대신 \([0, \pi]\)에서 1부터 \(-1\)까지 감소하는 부분을 씁니다. \(\tan\)은 \(\pm\frac\pi2\)에서 정의되지 않으므로 열린구간입니다.

예제 1.2.5

다음 값을 구하여라. (가) \(\arcsin\left(-\frac12\right)\) (나) \(\arccos\left(-\frac{\sqrt2}{2}\right)\) (다) \(\arctan\sqrt3\)

풀이. 각각 "값이 주어진 수인 각"을 정해진 치역 안에서 찾습니다.

(가) \(\sin\theta = -\frac12\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)인 \(\theta\)는 \(-\frac\pi6\)입니다. \(\frac{7\pi}{6}\)도 사인 값이 \(-\frac12\)이지만 치역 밖입니다.

(나) \(\cos\theta = -\frac{\sqrt2}{2}\)이고 \(0 \le \theta \le \pi\)인 \(\theta\)는 \(\frac{3\pi}{4}\)입니다. \(-\frac{3\pi}{4}\)는 치역 밖입니다.

(다) \(\tan\theta = \sqrt3\)이고 \(-\frac\pi2 < \theta < \frac\pi2\)인 \(\theta\)는 \(\frac\pi3\)입니다.

역함수의 두 등식 \(f^{-1}(f(x)) = x\), \(f(f^{-1}(y)) = y\)는 각각 정의된 범위에서만 성립합니다. 역삼각함수에서 이 점이 특히 중요합니다.

예제 1.2.6

\(\arcsin(\sin 2)\)를 구하여라. 왜 2가 아닌가?

풀이. \(\arcsin(\sin x) = x\)는 \(x\)가 \(\left[-\frac\pi2, \frac\pi2\right]\)에 있을 때만 성립합니다. \(\frac\pi2 \approx 1.571\)이므로 \(2\)는 그 범위 밖입니다. 그래서 \(\sin\theta = \sin 2\)이고 \(\theta \in \left[-\frac\pi2, \frac\pi2\right]\)인 다른 각을 찾아야 합니다. \(\sin(\pi - x) = \sin x\)이므로 \(\theta = \pi - 2 \approx 1.142\)가 조건을 만족합니다. 따라서 \(\arcsin(\sin 2) = \pi - 2\)입니다.

반대 방향 \(\sin(\arcsin y) = y\)는 \(\arcsin\)이 정의되는 모든 \(y \in [-1, 1]\)에서 성립합니다. 두 방향이 대칭이 아니라는 점을 기억하세요.

예제 1.2.7

\(\cos(\arcsin x)\)를 \(x\)의 식으로 나타내어라 (\(-1 \le x \le 1\)).

풀이. \(\theta = \arcsin x\)로 놓으면 \(\sin\theta = x\)이고 \(-\frac\pi2 \le \theta \le \frac\pi2\)입니다. \(\sin^2\theta + \cos^2\theta = 1\)에서 \(\cos\theta = \pm\sqrt{1 - x^2}\)인데, 이 범위의 \(\theta\)에서는 \(\cos\theta \ge 0\)이므로 부호는 +입니다. 답: \(\cos(\arcsin x) = \sqrt{1 - x^2}\). 이 식은 2.4절에서 \(\arcsin\)을 미분할 때 다시 씁니다.

주의"\(\arcsin\)과 \(\sin\)은 서로 상쇄된다"고만 기억하면 예제 1.2.6 같은 문제에서 틀립니다. 역삼각함수의 값은 언제나 정해진 치역 안에 있어야 합니다. 답을 낸 뒤 치역 안에 있는지 확인하는 습관을 들이세요.
요약
  1. 역함수는 일대일 함수에만 있다. 수평선 판정법, 증가·감소로 확인한다.
  2. \(f^{-1}\)의 정의역은 \(f\)의 치역, 치역은 \(f\)의 정의역이다. \(f^{-1} \ne \frac1f\).
  3. 일대일이 아니면 정의역을 잘라 역함수를 만든다. 자른 구간이 역함수의 치역이 된다.
  4. \(\arcsin\): \([-1,1] \to [-\frac\pi2, \frac\pi2]\), \(\arccos\): \([-1,1] \to [0, \pi]\), \(\arctan\): \(\mathbb{R} \to (-\frac\pi2, \frac\pi2)\).

1.2.5연습문제

기본

  1. 다음 값을 구하여라. (가) \(\arccos\frac12\) (나) \(\arctan(-1)\) (다) \(\arcsin 1\)
    답

    (가) \(\frac\pi3\) (나) \(-\frac\pi4\) (다) \(\frac\pi2\)

  2. \(f(x) = x^3 + 1\)의 역함수를 구하여라.
    답

    \(y = x^3 + 1\)에서 \(x = \sqrt[3]{y - 1}\). \(f^{-1}(x) = \sqrt[3]{x - 1}\). \(x^3\)은 증가함수라 일대일이다.

  3. \(f(x) = x^2 - 4x\)가 일대일이 되도록 정의역을 \([a, \infty)\)로 제한할 때 가장 작은 \(a\)와 그때의 역함수를 구하여라.
    힌트

    완전제곱식 \((x - 2)^2 - 4\).

    답

    \(a = 2\). \(y = (x - 2)^2 - 4\), \(x \ge 2\)에서 \(x = 2 + \sqrt{y + 4}\). \(f^{-1}(x) = 2 + \sqrt{x + 4}\), 정의역 \([-4, \infty)\).

응용

  1. \(\arccos(\cos\frac{5\pi}{3})\)과 \(\arctan(\tan\frac{3\pi}{4})\)를 구하여라.
    답

    \(\cos\frac{5\pi}{3} = \frac12\)이므로 \(\frac\pi3\). \(\tan\frac{3\pi}{4} = -1\)이므로 \(-\frac\pi4\).

  2. \(\tan(\arcsin x)\)를 \(x\)의 식으로 나타내고 정의역을 말하여라.
    답

    예제 1.2.7에서 \(\cos(\arcsin x) = \sqrt{1 - x^2}\)이므로 \(\frac{x}{\sqrt{1 - x^2}}\). 분모가 0이 아니어야 하므로 \(-1 < x < 1\).

심화

  1. 모든 \(x \in [-1, 1]\)에 대해 \(\arcsin x + \arccos x = \frac\pi2\)임을 보여라.
    힌트

    \(\theta = \arcsin x\)이면 \(\cos(\frac\pi2 - \theta) = x\)이고 \(\frac\pi2 - \theta \in [0, \pi]\).

    답

    \(\theta = \arcsin x \in [-\frac\pi2, \frac\pi2]\)이면 \(\frac\pi2 - \theta \in [0, \pi]\)이고 \(\cos(\frac\pi2 - \theta) = \sin\theta = x\). \(\arccos x\)는 \([0, \pi]\)에서 코사인 값이 \(x\)인 유일한 각이므로 \(\arccos x = \frac\pi2 - \theta\).

1.2.6지수함수 다시 보기

세균 한 마리가 한 시간마다 둘로 나뉘면 \(t\)시간 뒤에는 \(2^t\)마리가 됩니다. 빚에 매년 5%의 이자가 붙으면 \(t\)년 뒤의 원리금은 처음의 \(1.05^t\)배입니다. 이렇게 같은 시간 동안 같은 비율로 늘거나 주는 양은 지수함수로 나타냅니다.

정의 1.2.8 (지수함수)

\(a > 0\), \(a \ne 1\)인 상수 \(a\)에 대하여 \(f(x) = a^x\)를 밑이 \(a\)인 지수함수라 한다. 정의역은 실수 전체, 치역은 \((0, \infty)\)이다.

고교 수학I에서 배운 성질을 정리하면 다음과 같습니다. 모두 지수법칙 \(a^{x+y} = a^x a^y\), \((a^x)^y = a^{xy}\)에서 나옵니다.

  • \(a > 1\)이면 증가함수, \(0 < a < 1\)이면 감소함수이다. 따라서 일대일이고 역함수가 있다.
  • 그래프는 언제나 점 \((0, 1)\)을 지나고, \(x\)축 위에 있다(\(a^x > 0\)).
  • \(a > 1\)이면 \(x \to -\infty\)일 때 \(a^x \to 0\)이다. 곧 \(x\)축이 점근선이다.
  • \(\left(\frac1a\right)^x = a^{-x}\)이므로 밑이 \(\frac1a\)인 그래프는 밑이 \(a\)인 그래프를 \(y\)축에 대해 뒤집은 것이다.

\(a^x\)에서 \(x\)가 무리수일 때, 예를 들어 \(2^{\sqrt2}\)는 무엇일까요? 고등학교에서는 넘어갔지만, 1.1절의 상한으로 정의할 수 있습니다. \(\sqrt2\)보다 작은 유리수 \(r\)에 대해 \(2^r\)들을 모은 집합의 상한이 \(2^{\sqrt2}\)입니다. 이 집합은 위로 유계(\(2^2 = 4\)가 상계)이므로 완비성 공리가 상한의 존재를 보장합니다.

1.2.7특별한 밑 \(e\)

밑으로 2나 10을 써도 되는데, 미적분에서는 거의 언제나 \(e \approx 2.718\)이라는 이상한 수를 씁니다. 이유는 접선의 기울기에 있습니다.

지수함수 \(y = a^x\)의 그래프가 점 \((0, 1)\)에서 갖는 접선의 기울기를 생각합시다. 접선의 기울기는 두 점 \((0, 1)\), \((h, a^h)\)를 잇는 직선의 기울기 \(\frac{a^h - 1}{h}\)에서 \(h\)를 0에 가깝게 보낸 값입니다(고교 수학II의 미분계수, 2.1절에서 다시 정의합니다). 계산기로 \(h = 0.0001\)을 넣어 보면

\(a\)22.52.72.723
\(\frac{a^h - 1}{h}\) (\(h = 0.0001\))0.69320.91630.99331.00071.0987

입니다. 밑이 커질수록 기울기가 커지고, 2.7과 2.72 사이 어딘가에서 기울기가 정확히 1이 됩니다. 그 밑을 \(e\)라고 부릅니다.

정의 1.2.9 (자연상수 \(e\))

\(y = a^x\)의 그래프의 \((0, 1)\)에서의 접선의 기울기가 1이 되는 밑 \(a\)를 \(e\)라 한다. 곧

\[\lim_{h\to0}\frac{e^h - 1}{h} = 1.\]

\(e = 2.71828\ldots\)이고 무리수이다.

왜 기울기 1이 좋을까요? 2.2절에서 보겠지만, 이 성질 하나 때문에 \(e^x\)의 도함수가 자기 자신 \(e^x\)가 됩니다. 다른 밑이면 \((a^x)' = (\text{상수})\cdot a^x\) 꼴로 귀찮은 상수가 붙습니다. 그래서 미적분, 물리, 화학, 통계에서 지수함수는 거의 언제나 \(e^x\)로 씁니다. \(e^x\)를 \(\exp(x)\)로 쓰기도 합니다.

같은 수 \(e\)가 이자 계산에서도 나옵니다. 연이율 100%를 1년에 \(n\)번 나누어 복리로 붙이면 1년 뒤 원리금은 \(\left(1 + \frac1n\right)^n\)배입니다. \(n = 1, 12, 365, 10^6\)이면 각각 2, 2.613, 2.7146, 2.71828로, \(n\)을 키울수록 \(e\)에 다가갑니다. 두 정의가 같은 수를 준다는 것은 8.8절에서 확인합니다.

1.2.8로그함수와 자연로그

정의 1.2.10 (로그함수)

지수함수 \(y = a^x\)의 역함수를 밑이 \(a\)인 로그함수라 하고 \(y = \log_a x\)로 쓴다. 곧 \(\log_a x = y \iff a^y = x\). 정의역은 \((0, \infty)\), 치역은 실수 전체이다.

밑이 \(e\)인 로그를 자연로그라 하고 \(\ln x\)로 씁니다. \(\ln x = y \iff e^y = x\)입니다. 역함수 관계에서 바로

\[e^{\ln x} = x \quad (x > 0), \qquad \ln(e^x) = x \quad (x \in \mathbb{R})\]

입니다. 로그의 성질(고교 수학I)은 지수법칙을 뒤집은 것입니다.

  • \(\ln(xy) = \ln x + \ln y\), \(\ln\frac xy = \ln x - \ln y\), \(\ln(x^r) = r\ln x\) (\(x, y > 0\)).
  • \(\ln 1 = 0\), \(\ln e = 1\). \(0 < x < 1\)이면 \(\ln x < 0\).
  • 밑 바꾸기: \(\log_a x = \frac{\ln x}{\ln a}\). 그래서 어떤 로그든 자연로그로 바꿔 쓸 수 있다.
  • \(a^x = e^{x\ln a}\). 어떤 지수함수든 \(e\)의 거듭제곱으로 바꿔 쓸 수 있다.

마지막 두 성질 덕분에 앞으로는 \(e^x\)와 \(\ln x\)만 다루면 됩니다. 예를 들어 1.4.2의 표에서 밑이 \(a\)일 때의 기울기가 정확히 \(\ln a\)라는 것도 2.2절에서 보입니다(\(\ln 2 = 0.6931\ldots\), \(\ln 3 = 1.0986\ldots\)으로 표와 맞습니다).

예제 1.2.11

방사성 탄소 \({}^{14}\text{C}\)의 양은 5730년마다 절반이 된다. 처음 양을 \(N_0\)이라 할 때 \(t\)년 뒤의 양 \(N(t)\)를 \(e\)를 써서 나타내고, 양이 처음의 10%가 되는 데 걸리는 시간을 구하여라.

풀이. 5730년마다 절반이므로 \(N(t) = N_0\left(\frac12\right)^{t/5730}\)입니다. \(\frac12 = e^{-\ln 2}\)이므로

\[N(t) = N_0\, e^{-kt}, \qquad k = \frac{\ln 2}{5730} \approx 1.210\times10^{-4}\ \text{/년}.\]

\(N(t) = 0.1N_0\)이면 \(e^{-kt} = 0.1\), 양변에 자연로그를 취해 \(-kt = \ln 0.1 = -\ln 10\), 따라서 \(t = \frac{\ln 10}{k} = 5730\cdot\frac{\ln 10}{\ln 2} \approx 5730 \times 3.322 \approx 19\,000\)년입니다. 검산: 반감기를 세 번 지나면 \(\frac18 = 12.5\%\), 네 번이면 \(6.25\%\)이므로, 10%는 세 번(17 190년)과 네 번(22 920년) 사이여야 합니다. 답 19 000년은 그 사이에 있습니다.

이처럼 "\(N\)이 지수적으로 줄어든다"를 \(N_0 e^{-kt}\)로 쓰는 것이 표준입니다. 공통6-02(반응 속도), 공통4-05-03(축전기 방전)에서 같은 꼴이 다시 나옵니다.

1.2.9쌍곡선 함수

\(e^x\)와 \(e^{-x}\)를 더하고 빼서 만든 함수들이 공학과 물리에 자주 나옵니다. 양 끝을 잡은 쇠사슬이 처지는 모양, 상대성 이론의 속도 덧셈, 미분방정식 \(y'' = y\)의 해가 그 예입니다.

정의 1.2.12 (쌍곡선 함수) \[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x}.\]

각각 하이퍼볼릭 사인, 하이퍼볼릭 코사인, 하이퍼볼릭 탄젠트라 읽는다.

그래프의 모양을 정의에서 읽어 봅시다.

  • \(\cosh x\): \(e^x\)와 \(e^{-x}\)의 평균이다. \(x\)를 \(-x\)로 바꿔도 같으므로 우함수이고(\(y\)축 대칭), \(\cosh 0 = 1\)이 최솟값이다. \(x\)가 커지면 \(e^{-x}\)는 0으로 가므로 \(\cosh x \approx \frac{e^x}{2}\)이다. 그래프는 U자 모양으로, 늘어진 쇠사슬의 모양(현수선)이다.
  • \(\sinh x\): 기함수이고(원점 대칭) \(\sinh 0 = 0\)이며 증가함수이다. 큰 \(x\)에서 \(\sinh x \approx \frac{e^x}{2}\), 큰 음수 \(x\)에서 \(\approx -\frac{e^{-x}}{2}\)이다.
  • \(\tanh x\): 기함수이고 증가하며, 값이 \(-1\)과 1 사이에 있다. \(x \to \infty\)일 때 1, \(x \to -\infty\)일 때 \(-1\)로 다가간다.

이름에 "사인", "코사인"이 붙은 이유는 삼각함수와 아주 닮은 항등식을 만족하기 때문입니다.

정리 1.2.13

모든 실수 \(x\)에 대하여 \(\cosh^2 x - \sinh^2 x = 1\).

증명.정의를 넣고 전개한다. \(\cosh^2 x = \frac{e^{2x} + 2 + e^{-2x}}{4}\), \(\sinh^2 x = \frac{e^{2x} - 2 + e^{-2x}}{4}\)이다. 여기서 \(e^x e^{-x} = e^0 = 1\)을 썼다. 빼면 \(\frac{4}{4} = 1\)이다. ∎

삼각함수에서는 \(\cos^2 t + \sin^2 t = 1\)이라서 점 \((\cos t, \sin t)\)가 원 \(x^2 + y^2 = 1\) 위에 있습니다. 쌍곡선 함수에서는 부호가 하나 바뀌어 점 \((\cosh t, \sinh t)\)가 쌍곡선 \(x^2 - y^2 = 1\) 위에 있습니다. "쌍곡선 함수"라는 이름이 여기서 왔습니다.

덧셈 공식도 삼각함수와 닮았습니다: \(\sinh(x + y) = \sinh x\cosh y + \cosh x\sinh y\), \(\cosh(x + y) = \cosh x\cosh y + \sinh x\sinh y\). 둘째 식은 코사인과 부호가 다릅니다(연습문제 5).

예제 1.2.14 (역쌍곡선 사인)

\(\sinh\)는 증가함수이므로 역함수가 있다. \(\sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right)\)임을 보여라.

풀이. \(y = \sinh^{-1}x\)이면 \(x = \sinh y = \frac{e^y - e^{-y}}{2}\)입니다. \(u = e^y\)로 놓으면 \(2x = u - \frac1u\), 양변에 \(u\)를 곱하면 \(u^2 - 2xu - 1 = 0\)인 \(u\)에 대한 이차방정식입니다. 근의 공식으로 \(u = x \pm \sqrt{x^2 + 1}\). \(u = e^y > 0\)이어야 하는데 \(x - \sqrt{x^2 + 1} < 0\)이므로(\(\sqrt{x^2 + 1} > \sqrt{x^2} = |x| \ge x\)) 부호는 +입니다. 따라서 \(e^y = x + \sqrt{x^2 + 1}\), \(y = \ln(x + \sqrt{x^2 + 1})\).

쌍곡선 함수가 지수함수로 정의되므로 그 역함수는 로그로 나옵니다. 이 식은 5.3절에서 \(\int\frac{dx}{\sqrt{x^2 + 1}}\)을 계산할 때 다시 만납니다.

1.2.10세 함수의 크기 비교

\(x\)가 커질 때 \(\ln x\), \(x^n\), \(e^x\)는 모두 무한히 커지지만 빠르기가 크게 다릅니다. \(x = 100\)이면 \(\ln 100 \approx 4.6\), \(100^2 = 10^4\), \(e^{100} \approx 2.7\times10^{43}\)입니다. 일반적으로

\[\ln x \ll x^p \ll e^x \qquad (x \to \infty,\ p > 0)\]

입니다. 여기서 \(f \ll g\)는 \(\frac{f(x)}{g(x)} \to 0\)이라는 뜻입니다. 이 사실은 3.3절(로피탈 정리)에서 증명합니다. 알고리즘의 실행 시간을 비교할 때(전전2 데이터구조), 확률분포의 꼬리를 비교할 때 이 순서가 기준이 됩니다.

주의\(\ln(x + y) = \ln x + \ln y\)는 틀립니다. 로그는 곱을 합으로 바꾸지 합을 바꾸지 않습니다. 또 \((\ln x)^2\)과 \(\ln(x^2) = 2\ln x\)는 다릅니다. \(\ln^2 x\)라고 쓰면 \((\ln x)^2\)을 뜻합니다.
요약
  1. 지수함수 \(a^x\)는 같은 비율로 늘거나 주는 양을 나타낸다. 증가 또는 감소하므로 역함수 \(\log_a x\)가 있다.
  2. \(e\)는 \(y = a^x\)의 \((0,1)\)에서의 접선 기울기가 1이 되는 밑이다. \(e \approx 2.71828\).
  3. \(a^x = e^{x\ln a}\), \(\log_a x = \frac{\ln x}{\ln a}\)이므로 \(e^x\)와 \(\ln x\)만 알면 된다.
  4. \(\cosh x = \frac{e^x + e^{-x}}{2}\), \(\sinh x = \frac{e^x - e^{-x}}{2}\), \(\cosh^2 x - \sinh^2 x = 1\).
  5. 크게 갈 때 \(\ln x \ll x^p \ll e^x\).

    답

    오른쪽을 \(e^x, e^y\)로 전개하면 \(e^{x+y}\)와 \(e^{-x-y}\) 항만 남습니다.

    답

    오른쪽 \(= \frac{(e^x + e^{-x})(e^y + e^{-y}) + (e^x - e^{-x})(e^y - e^{-y})}{4} = \frac{2e^{x+y} + 2e^{-x-y}}{4} = \cosh(x+y)\). 교차항 \(e^{x-y}\), \(e^{-x+y}\)는 부호가 반대라 지워진다.

심화

  1. \(\tanh^{-1}x = \frac12\ln\frac{1 + x}{1 - x}\) (\(-1 < x < 1\))임을 보여라.

1.2.3

설명역함수는 언제 있고, arcsin(sin 2)는 왜 2가 아닌가?

일대일 · 정의역 제한 · 역삼각함수

다루는 성취기준 [공통1-01-02]

왜 필요한가

\(\sin x = 0.5\)를 만족하는 \(x\)는 \(\frac\pi6, \frac{5\pi}6, \frac{13\pi}6, \dots\) 무수히 많습니다. "사인값이 0.5인 각"을 하나의 수로 돌려주는 함수를 만들려면 어느 하나를 골라야 합니다. 이 선택을 정의역 제한이라 하고, 그 결과가 \(\arcsin\)입니다. 적분 \(\int \frac{dx}{\sqrt{1-x^2}}\), \(\int\frac{dx}{1+x^2}\)의 답이 역삼각함수이므로 적분법에서 계속 씁니다.

정의 · 일대일과 역함수

함수 \(f : A \to B\)가 \(x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2)\)를 만족하면 일대일(단사)이라 한다. \(f\)가 일대일이면, 치역 \(f(A)\)의 각 \(y\)에 대해 \(f(x) = y\)인 \(x\)가 하나뿐이므로 \(f^{-1}(y) = x\)로 역함수 \(f^{-1} : f(A) \to A\)를 정의한다.

\[f^{-1}(f(x)) = x \ (x \in A), \qquad f(f^{-1}(y)) = y \ (y \in f(A)).\]

정의를 풀어 읽기

  1. "하나뿐"이어야 거꾸로 갈 수 있다\(f(x) = x^2\)에서 \(f(2) = f(-2) = 4\)이면 \(f^{-1}(4)\)를 2로 할지 −2로 할지 정할 수 없습니다. 일대일이 바로 이 모호함이 없다는 조건입니다.
  2. 판정: 수평선 판정법그래프와 모든 수평선이 많아야 한 점에서 만나면 일대일입니다.
  3. 판정: 단조함수구간에서 순증가(\(x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\))하거나 순감소하면 일대일입니다. 미분 가능하면 \(f' > 0\)(또는 \(< 0\))으로 확인합니다(4단원 평균값 정리의 결과).
  4. 두 등식의 정의역이 다르다\(f^{-1}(f(x)) = x\)는 \(x \in A\)일 때만, \(f(f^{-1}(y)) = y\)는 \(y \in f(A)\)일 때만 성립합니다. 이 조건을 빼먹는 것이 아래 오해의 원인입니다.

역삼각함수의 정의역과 치역

삼각함수는 주기함수라 일대일이 아닙니다. 그래서 순증가 또는 순감소하는 한 구간으로 정의역을 잘라 역함수를 만듭니다. 관례적으로 고르는 구간:

  1. \(\arcsin : [-1, 1] \to \left[-\frac\pi2, \frac\pi2\right]\)\(\sin\)을 \(\left[-\frac\pi2, \frac\pi2\right]\)로 제한. 이 구간에서 사인은 −1에서 1까지 순증가합니다.
  2. \(\arccos : [-1, 1] \to [0, \pi]\)\(\cos\)을 \([0, \pi]\)로 제한. 1에서 −1까지 순감소합니다.
  3. \(\arctan : \mathbb{R} \to \left(-\frac\pi2, \frac\pi2\right)\)\(\tan\)을 열린구간 \(\left(-\frac\pi2, \frac\pi2\right)\)로 제한. 끝점에서 정의되지 않으므로 치역도 열린구간입니다.

정의역과 치역이 서로 바뀐다는 점에 주목하세요. \(\arcsin\)의 정의역은 사인의 치역 \([-1,1]\), 치역은 잘라 낸 구간입니다.

예: \(\arcsin(\sin 2)\)

  1. \(2 > \frac\pi2 \approx 1.571\)이므로 2는 \(\left[-\frac\pi2, \frac\pi2\right]\) 밖이다. 따라서 \(\arcsin(\sin x) = x\)를 쓸 수 없다.
    \(f^{-1}(f(x)) = x\)는 제한한 정의역 안에서만 성립.
  2. \(\sin 2 = \sin(\pi - 2)\)이고 \(\pi - 2 \approx 1.142\)는 \(\left[-\frac\pi2, \frac\pi2\right]\) 안이다.
    \(\sin(\pi - \theta) = \sin\theta\). 같은 사인값을 갖는 각 중 구간 안의 것을 찾는다.
  3. 따라서 \(\arcsin(\sin 2) = \pi - 2\).
    \(\arcsin\)은 구간 안의 그 각을 돌려준다.

반대로 \(\sin(\arcsin y) = y\)는 \(y \in [-1, 1]\)이면 언제나 성립합니다. 예: \(\sin(\arcsin 0.3) = 0.3\). \(\sin(\arcsin 2)\)는 \(\arcsin 2\)가 정의되지 않으므로 의미가 없습니다.

다른 개념과의 관계

  • 그래프: \(f^{-1}\)의 그래프는 \(f\)의 그래프를 직선 \(y = x\)에 대해 대칭이동한 것입니다(점 \((a,b)\) ↔ \((b,a)\)).
  • 미분(3단원): \((f^{-1})'(y) = \frac{1}{f'(x)}\) (\(y = f(x)\), \(f'(x) \ne 0\)). 여기서 \((\arcsin y)' = \frac{1}{\sqrt{1-y^2}}\)이 나옵니다.
  • 지수와 로그: \(\ln\)은 \(e^x\)의 역함수입니다. \(e^x\)는 순증가하므로 정의역을 자를 필요가 없습니다.

흔한 오해

  • "\(\sin^{-1} x = \frac{1}{\sin x}\)." \(\sin^{-1}\)은 역함수 \(\arcsin\)을 뜻합니다. 역수는 \(\csc x = (\sin x)^{-1}\)입니다. 헷갈리면 \(\arcsin\)으로 쓰세요.
  • "\(\arcsin(\sin x) = x\)는 항상 성립한다." \(x \in \left[-\frac\pi2, \frac\pi2\right]\)일 때만입니다.
  • "역함수가 없는 함수는 쓸 수 없다." 정의역을 단조 구간으로 자르면 그 구간에서는 역함수가 있습니다. \(\sqrt{x}\)도 \(x^2\)을 \([0, \infty)\)로 자른 역함수입니다.

설명지수, 로그, 쌍곡선 함수는 서로 어떻게 이어지는가?

초월함수 · 증가 속도 · 항등식

다루는 성취기준 [공통1-01-02]

왜 필요한가

다항함수만으로는 인구 증가, 방사성 붕괴, 매달린 줄의 모양을 나타낼 수 없습니다. 지수함수는 "변화율이 자기 자신에 비례하는 양", 로그는 그 역, 쌍곡선 함수는 지수함수 두 개의 조합으로, 미분방정식과 물리에서 계속 나옵니다. 이 카드는 세 함수의 정의와 성질을 한곳에 정리합니다.

정의

자연지수함수 \(e^x\): \(e = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \approx 2.71828\)을 밑으로 하는 지수함수. 정의역 \(\mathbb{R}\), 치역 \((0, \infty)\), 순증가.

자연로그 \(\ln x\): \(e^x\)의 역함수. 정의역 \((0, \infty)\), 치역 \(\mathbb{R}\). 곧 \(\ln x = y \iff e^y = x\).

쌍곡선 함수:

\[\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x}.\]

정의를 풀어 읽기

  1. 왜 밑이 \(e\)인가모든 지수함수 \(a^x\)의 도함수는 \(a^x\)에 상수 \(\ln a\)를 곱한 것입니다. 이 상수가 1이 되는 밑이 \(e\)입니다. 그래서 \((e^x)' = e^x\)이고, 미적분에서는 \(e\)를 밑으로 쓰면 식이 가장 간단합니다.
  2. 로그의 성질은 지수법칙의 거울\(e^{a+b} = e^a e^b\)를 로그로 옮기면 \(\ln(xy) = \ln x + \ln y\). 같은 방식으로 \(\ln\frac{x}{y} = \ln x - \ln y\), \(\ln x^r = r\ln x\). 밑 바꾸기: \(\log_a x = \frac{\ln x}{\ln a}\).
  3. 쌍곡선이라는 이름\(\cos^2 t + \sin^2 t = 1\)이 원 \(x^2 + y^2 = 1\)을 그리듯, \(\cosh^2 t - \sinh^2 t = 1\)은 쌍곡선 \(x^2 - y^2 = 1\)의 오른쪽 가지를 그립니다.

쌍곡선 항등식 유도

  1. \(\cosh^2 x = \frac{e^{2x} + 2 + e^{-2x}}{4}\), \(\sinh^2 x = \frac{e^{2x} - 2 + e^{-2x}}{4}\).
    정의를 제곱. \(e^x e^{-x} = 1\).
  2. 빼면 \(\cosh^2 x - \sinh^2 x = \frac{4}{4} = 1\).
    \(e^{\pm 2x}\) 항이 지워진다.

삼각함수 항등식과 비교하면 부호 하나가 다릅니다. 이 차이가 \((\cosh x)' = \sinh x\) (삼각함수는 \((\cos x)' = -\sin x\))에도 나타납니다.

그래프와 성질 비교

  1. \(e^x\)\(x \to -\infty\)이면 0에 다가감(수평 점근선 \(y = 0\)), \(x \to \infty\)이면 어떤 다항식보다 빨리 커짐. \(e^0 = 1\).
  2. \(\ln x\)\(x \to 0^+\)이면 \(-\infty\)(수직 점근선 \(x = 0\)), \(x \to \infty\)이면 커지지만 어떤 양의 거듭제곱 \(x^p\)보다 느림. \(\ln 1 = 0\).
  3. \(\cosh x\)짝함수, 최솟값 \(\cosh 0 = 1\). 양쪽 줄을 잡고 늘어뜨린 사슬의 모양(현수선)입니다.
  4. \(\sinh x\)홀함수, 순증가, \(\sinh 0 = 0\). 큰 \(x\)에서 \(\sinh x \approx \cosh x \approx \frac{e^x}{2}\).
  5. \(\tanh x\)홀함수, 치역 \((-1, 1)\), 수평 점근선 \(y = \pm 1\). 신경망의 활성화 함수로도 씁니다.

증가 속도의 순서 (\(x \to \infty\)): \(\ln x \ll x^p \ll e^x\) (\(p > 0\)). 곧 \(\lim \frac{\ln x}{x^p} = 0\), \(\lim\frac{x^p}{e^x} = 0\). 4단원의 로피탈 정리로 증명합니다.

예: 역쌍곡선 사인을 로그로

\(y = \sinh^{-1} x\)를 구합니다. \(x = \frac{e^y - e^{-y}}{2}\)에서 \(u = e^y > 0\)으로 두면 \(u^2 - 2xu - 1 = 0\), 근의 공식으로 \(u = x \pm \sqrt{x^2 + 1}\). \(u > 0\)이어야 하는데 \(x - \sqrt{x^2+1} < 0\)이므로 \(u = x + \sqrt{x^2+1}\). 따라서

\[\sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right).\]

\(\sinh\)는 순증가라 정의역을 자를 필요가 없었습니다. 반면 \(\cosh\)는 짝함수라 \([0, \infty)\)로 잘라야 역함수 \(\cosh^{-1} x = \ln(x + \sqrt{x^2-1})\) \((x \ge 1)\)을 얻습니다.

흔한 오해

  • "\(\ln(x + y) = \ln x + \ln y\)." 로그는 곱을 합으로 바꿉니다. 합의 로그는 간단해지지 않습니다.
  • "\(\cosh x\)도 주기함수다." 아닙니다. 삼각함수와 이름이 닮았을 뿐, 지수함수로 만든 함수라 주기가 없습니다.
