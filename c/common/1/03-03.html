3.3.1부정형

\(\lim_{x\to0}\dfrac{\sin x}{x}\)처럼 분자와 분모가 모두 0으로 가는 극한은 대입만으로는 값이 정해지지 않습니다. \(\dfrac{x^2}{x}\to0\), \(\dfrac{x}{x^2}\to\infty\), \(\dfrac{2x}{x}\to2\)처럼 경우마다 답이 다릅니다. 이런 꼴을 부정형이라 합니다. 고교에서는 인수분해나 유리화로 정리했지만, \(\dfrac{e^x - 1}{x}\)이나 \(\dfrac{\ln x}{x}\)처럼 정리할 방법이 없는 경우가 많습니다.

3.3.2로피탈 법칙

정리 3.3.1 (로피탈 법칙)

\(f, g\)가 \(a\) 근처에서 미분 가능하고 \(g'(x) \ne 0\)이며, \(\lim_{x\to a}f(x) = \lim_{x\to a}g(x) = 0\)이거나 둘 다 \(\pm\infty\)일 때, 오른쪽 극한이 존재하면(또는 \(\pm\infty\)이면)

\[\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}.\]

\(a\) 대신 \(a^\pm\), \(\pm\infty\)여도 성립한다.

왜 맞는지 직관적으로 보면, \(f(a) = g(a) = 0\)일 때 \(a\) 근처에서 선형근사(2.5절)로 \(f(x) \approx f'(a)(x - a)\), \(g(x) \approx g'(a)(x - a)\)이므로 그 비는 \(\dfrac{f'(a)}{g'(a)}\)에 가깝습니다. 분자와 분모가 0으로 가는 "빠르기"를 비교하는 셈입니다.

예제 3.3.2

(가) \(\lim_{x\to0}\dfrac{e^x - 1}{x}\) (나) \(\lim_{x\to\infty}\dfrac{\ln x}{x}\) (다) \(\lim_{x\to\infty}\dfrac{e^x}{x^2}\)

풀이. (가) \(\frac00\) 꼴. \(\lim\dfrac{e^x}{1} = 1\).

(나) \(\frac\infty\infty\) 꼴. \(\lim\dfrac{1/x}{1} = 0\). 로그는 \(x\)보다 훨씬 느리게 자랍니다.

(다) \(\frac\infty\infty\) 꼴. \(\lim\dfrac{e^x}{2x}\)도 여전히 \(\frac\infty\infty\)라서 한 번 더 쓰면 \(\lim\dfrac{e^x}{2} = \infty\). 지수함수는 어떤 다항식보다 빨리 자랍니다.

로피탈 법칙을 쓸 때마다 "아직 \(\frac00\)이나 \(\frac\infty\infty\)인가"를 먼저 확인해야 합니다. 부정형이 아닌데 쓰면 틀린 답이 나옵니다. 예를 들어 \(\lim_{x\to0}\dfrac{x + 1}{x + 2} = \dfrac12\)인데, 분자와 분모를 미분하면 \(\dfrac11 = 1\)이 됩니다.

3.3.3다른 부정형

나머지 부정형은 식을 고쳐 \(\frac00\)이나 \(\frac\infty\infty\)로 만든 뒤 로피탈 법칙을 씁니다.

  • \(0\cdot\infty\): \(fg = \dfrac{f}{1/g}\)로 고친다.
  • \(\infty - \infty\): 통분하거나 공통인수로 묶는다.
  • \(1^\infty\), \(0^0\), \(\infty^0\): \(y = f^g\)에 로그를 취해 \(\ln y = g\ln f\)(\(0\cdot\infty\) 꼴)의 극한을 구한 뒤 \(e\)의 거듭제곱으로 되돌린다.
예제 3.3.3

(가) \(\lim_{x\to0^+}x\ln x\) (나) \(\lim_{x\to0^+}x^x\) (다) \(\lim_{x\to\infty}\left(1 + \dfrac1x\right)^x\)

풀이. (가) \(0\cdot(-\infty)\) 꼴. \(x\ln x = \dfrac{\ln x}{1/x}\)는 \(\frac{-\infty}{\infty}\) 꼴이므로 \(\lim\dfrac{1/x}{-1/x^2} = \lim(-x) = 0\).

(나) \(0^0\) 꼴. \(\ln y = x\ln x \to 0\)이므로 (가)에서 \(y \to e^0 = 1\).

(다) \(1^\infty\) 꼴. \(\ln y = x\ln\left(1 + \frac1x\right) = \dfrac{\ln(1 + 1/x)}{1/x}\). \(t = \frac1x \to 0^+\)로 놓으면 \(\dfrac{\ln(1 + t)}{t} \to \dfrac{1/(1 + t)}{1} \to 1\). 따라서 극한은 \(e^1 = e\). 1.2절에서 복리 계산으로 본 \(\left(1 + \frac1n\right)^n \to e\)가 이렇게 확인됩니다.

주의로피탈 법칙은 \(\dfrac{f'}{g'}\)이지 \(\left(\dfrac fg\right)'\)(몫의 미분)이 아닙니다. 분자와 분모를 따로 미분합니다.
요약
  1. \(\frac00\), \(\frac\infty\infty\) 꼴이면 \(\lim\frac fg = \lim\frac{f'}{g'}\). 쓸 때마다 부정형인지 확인한다.
  2. \(0\cdot\infty\)는 분수로, \(\infty - \infty\)는 통분으로, 거듭제곱 꼴은 로그를 취해 바꾼다.
  3. 크게 갈 때 \(\ln x \ll x^p \ll e^x\).

3.3.4연습문제

기본

  1. (가) \(\lim_{x\to0}\dfrac{\tan x}{x}\) (나) \(\lim_{x\to1}\dfrac{\ln x}{x - 1}\) (다) \(\lim_{x\to0}\dfrac{1 - \cos x}{x^2}\)
    답

    (가) \(\frac{\sec^2 0}{1} = 1\) (나) \(\frac{1/1}{1} = 1\) (다) \(\frac{\sin x}{2x} \to \frac12\)

  2. \(\lim_{x\to\infty}\dfrac{x^3}{e^x}\)을 구하여라.
    답

    세 번 적용: \(\frac{6}{e^x} \to 0\).

응용

  1. \(\lim_{x\to0}\left(\dfrac1x - \dfrac{1}{\sin x}\right)\)을 구하여라.
    답

    통분: \(\frac{\sin x - x}{x\sin x}\) (\(\frac00\)). 미분: \(\frac{\cos x - 1}{\sin x + x\cos x}\) (\(\frac00\)). 한 번 더: \(\frac{-\sin x}{2\cos x - x\sin x} \to 0\).

  2. \(\lim_{x\to\infty}\left(1 + \dfrac3x\right)^x\)을 구하여라.
    답

    \(\ln y = \frac{\ln(1 + 3/x)}{1/x} \to 3\). 답 \(e^3\).

3.3.5"무한대"는 수가 아니다

\(\lim_{x\to0}\frac{1}{x^2} = \infty\)라고 쓰지만, \(\infty\)는 실수가 아니므로 이 식은 1.3절의 정의 그대로의 극한이 아닙니다(정의는 \(|f(x) - L| < \varepsilon\)에서 \(L\)이 실수여야 합니다). 이 식은 "\(x\)가 0에 가까워지면 \(\frac{1}{x^2}\)이 어떤 수보다도 커진다"는 다른 종류의 진술입니다. 같은 기호 \(\lim\)을 쓰지만 별도로 정의해야 하고, 엄밀히 말하면 이때 극한은 존재하지 않으며 다만 특정한 방식으로 발산한다고 말합니다.

3.3.6정의

정의 3.3.4 (무한대로 발산)

임의의 \(M > 0\)에 대하여 어떤 \(\delta > 0\)이 있어서 \(0 < |x - a| < \delta \Rightarrow f(x) > M\)이면 \(\lim_{x\to a}f(x) = \infty\)라 쓴다. \(f(x) < -M\)으로 바꾸면 \(\lim_{x\to a}f(x) = -\infty\)이다.

정의 3.3.5 (무한대에서의 극한)

임의의 \(\varepsilon > 0\)에 대하여 어떤 \(N\)이 있어서 \(x > N \Rightarrow |f(x) - L| < \varepsilon\)이면 \(\lim_{x\to\infty}f(x) = L\)이라 쓴다. \(x < N \Rightarrow \cdots\)로 바꾸면 \(\lim_{x\to-\infty}f(x) = L\)이다.

1.3절과 비교하면 바뀐 곳이 보입니다. 정의 3.3.4에서는 "\(L\)에서 \(\varepsilon\) 이내" 대신 "\(M\)보다 크다"가 목표이고, 정의 3.3.5에서는 "\(a\)에서 \(\delta\) 이내" 대신 "\(N\)보다 크다"가 조건입니다. 도전과 응답의 구조는 같습니다. 상대가 아무리 큰 \(M\)을 불러도(정의 3.3.4), 아무리 작은 \(\varepsilon\)을 불러도(정의 3.3.5) 답할 수 있어야 합니다.

예제 3.3.6

정의로 \(\lim_{x\to\infty}\frac1x = 0\)과 \(\lim_{x\to0}\frac{1}{x^2} = \infty\)를 보여라.

풀이. 첫째: \(\varepsilon > 0\)에 대해 \(N = \frac1\varepsilon\)로 잡으면 \(x > N\)일 때 \(0 < \frac1x < \frac1N = \varepsilon\)입니다. 둘째: \(M > 0\)에 대해 \(\delta = \frac{1}{\sqrt M}\)으로 잡으면 \(0 < |x| < \delta\)일 때 \(x^2 < \frac1M\), 곧 \(\frac{1}{x^2} > M\)입니다.

극한 법칙(정리 2.2.1)은 \(x \to \pm\infty\)일 때도 그대로 성립합니다(증명은 같습니다. \(\delta\) 대신 \(N\)을 쓰고 두 \(N\) 가운데 큰 쪽을 잡습니다). 그래서 \(\lim_{x\to\infty}\frac{1}{x^n} = 0\) (\(n > 0\))을 기본으로 삼아 복잡한 식을 계산합니다.

3.3.7최고차항으로 나누기

\(x \to \pm\infty\)일 때 다항식은 최고차항이 지배합니다. \(x = 1000\)이면 \(3x^2 - 5x + 7 = 2\,995\,007\)인데 \(3x^2 = 3\,000\,000\)이어서 거의 같습니다. 그래서 유리함수는 분모의 최고차 거듭제곱으로 분자와 분모를 나누어 계산합니다.

예제 3.3.7

(가) \(\lim_{x\to\infty}\frac{3x^2 - 5x + 7}{2x^2 + 1}\) (나) \(\lim_{x\to\infty}\frac{x + 4}{x^2 - 3}\) (다) \(\lim_{x\to-\infty}\frac{x^3}{x^2 + 1}\)

풀이. (가) 분자와 분모를 \(x^2\)으로 나눕니다.

\[\frac{3 - \frac5x + \frac7{x^2}}{2 + \frac1{x^2}} \to \frac{3 - 0 + 0}{2 + 0} = \frac32.\]

(나) \(x^2\)으로 나누면 \(\frac{\frac1x + \frac4{x^2}}{1 - \frac3{x^2}} \to \frac01 = 0\). (다) \(x^2\)으로 나누면 \(\frac{x}{1 + \frac1{x^2}}\)이고, 분모는 1로, 분자는 \(-\infty\)로 가므로 \(-\infty\)로 발산합니다.

정리하면 차수가 같으면 최고차항 계수의 비, 분자의 차수가 낮으면 0, 분자의 차수가 높으면 \(\pm\infty\)로 발산합니다. 공식처럼 외우기보다 "최고차항끼리 비교"한다고 기억하세요.

예제 3.3.8

(가) \(\lim_{x\to-\infty}\frac{\sqrt{4x^2 + 1}}{x - 3}\) (나) \(\lim_{x\to\infty}\left(\sqrt{x^2 + 6x} - x\right)\)

풀이. (가) 근호 안에서 \(x^2\)을 꺼낼 때 \(\sqrt{x^2} = |x|\)이고, \(x < 0\)이면 \(|x| = -x\)라는 점(1.1절)이 핵심입니다.

\[\sqrt{4x^2 + 1} = |x|\sqrt{4 + \tfrac1{x^2}} = -x\sqrt{4 + \tfrac1{x^2}} \quad (x < 0)\]

이므로 \(\frac{-x\sqrt{4 + 1/x^2}}{x - 3} = \frac{-\sqrt{4 + 1/x^2}}{1 - 3/x} \to -2\)입니다. 부호를 놓쳐 2라고 답하기 쉽습니다. 검산: \(x = -1000\)이면 분자는 약 2000(양수), 분모는 약 \(-1003\)(음수)이므로 비는 음수여야 합니다.

(나) \(\infty - \infty\) 꼴은 극한 법칙을 쓸 수 없으므로 유리화합니다.

\[\sqrt{x^2 + 6x} - x = \frac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x} = \frac{6x}{\sqrt{x^2 + 6x} + x} = \frac{6}{\sqrt{1 + \frac6x} + 1} \to 3.\]

두 항이 각각 무한히 커지지만 그 차는 3으로 다가갑니다. \(\sqrt{x^2 + 6x} = \sqrt{(x + 3)^2 - 9} \approx x + 3\)이라는 것을 생각하면 그럴듯합니다.

3.3.8점근선

그래프가 멀리 가면서 어떤 직선에 한없이 다가가면 그 직선을 점근선이라 합니다. 세 종류를 구별합니다.

정의 3.3.9 (수직 점근선)

\(\lim_{x\to a^+}f(x)\) 또는 \(\lim_{x\to a^-}f(x)\)가 \(\pm\infty\)이면 직선 \(x = a\)를 수직 점근선이라 한다.

정의 3.3.10 (수평 점근선)

\(\lim_{x\to\infty}f(x) = L\) 또는 \(\lim_{x\to-\infty}f(x) = L\)이면 직선 \(y = L\)을 수평 점근선이라 한다.

정의 3.3.11 (비스듬한 점근선)

\(\lim_{x\to\pm\infty}[f(x) - (mx + b)] = 0\)이고 \(m \ne 0\)이면 직선 \(y = mx + b\)를 비스듬한 점근선이라 한다.

찾는 방법은 다음과 같습니다. 수직 점근선은 분모가 0이 되는 점(약분 뒤에도 남는 것), \(\ln\)의 정의역 끝, \(\tan\)의 \(\frac\pi2 + n\pi\) 같은 곳에서 찾습니다. 수평 점근선은 \(x \to \pm\infty\)의 극한을 양쪽 따로 구합니다. 비스듬한 점근선은 \(m = \lim\frac{f(x)}{x}\), \(b = \lim[f(x) - mx]\)로 구하고, 유리함수이면 나눗셈으로 바로 얻습니다.

예제 3.3.12

\(f(x) = \frac{x^2 + 1}{x - 1}\)의 점근선을 모두 구하여라.

풀이. 수직: \(x = 1\)에서 분모가 0이고 분자는 2라서 약분되지 않습니다. \(x \to 1^+\)이면 \(\frac{2}{0^+} \to \infty\), \(x \to 1^-\)이면 \(-\infty\)이므로 \(x = 1\)은 수직 점근선입니다.

비스듬한: 다항식의 나눗셈으로 \(x^2 + 1 = (x - 1)(x + 1) + 2\)이므로 \(f(x) = x + 1 + \frac{2}{x - 1}\)입니다. \(x \to \pm\infty\)일 때 \(\frac{2}{x - 1} \to 0\)이므로 \(f(x) - (x + 1) \to 0\), 곧 \(y = x + 1\)이 비스듬한 점근선입니다. 분자의 차수가 분모보다 하나 높으므로 수평 점근선은 없습니다.

예제 3.3.13

\(g(x) = \frac{2e^x}{e^x + 1}\)의 수평 점근선을 구하여라.

풀이. \(x \to \infty\): 분자와 분모를 \(e^x\)로 나누면 \(\frac{2}{1 + e^{-x}} \to 2\). \(x \to -\infty\): \(e^x \to 0\)이므로 \(\frac{0}{0 + 1} = 0\). 수평 점근선이 \(y = 2\)와 \(y = 0\) 두 개입니다. 유리함수와 달리 양쪽 극한이 다를 수 있으므로 반드시 따로 구해야 합니다. 이런 S자 곡선(로지스틱 곡선)은 개체군 성장(공통8-01-02)과 분류 모형(전전23)에 나옵니다.

주의\(\frac{\infty}{\infty} = 1\), \(\infty - \infty = 0\), \(0\cdot\infty = 0\)은 모두 틀린 계산입니다. 이런 꼴을 부정형이라 하며, 식을 정리하거나 3.3절의 로피탈 정리를 써야 값이 정해집니다. 예제 3.3.8(나)는 \(\infty - \infty\)인데 답이 3이었습니다.
요약
  1. \(\lim f = \infty\)는 "어떤 \(M\)보다도 커진다", \(\lim_{x\to\infty}f = L\)은 "\(x > N\)이면 \(L\)에서 \(\varepsilon\) 이내"라는 뜻이다.
  2. 유리함수는 분모의 최고차 거듭제곱으로 나눈다. 근호에서 꺼낼 때 \(\sqrt{x^2} = |x|\)의 부호에 주의한다.
  3. \(\infty - \infty\)는 유리화로 정리한다.
  4. 점근선: 수직(\(x = a\)에서 \(\pm\infty\)), 수평(\(x \to \pm\infty\)의 극한, 양쪽 따로), 비스듬한(나눗셈 또는 \(m = \lim\frac fx\)).

3.3.9연습문제

기본

  1. 극한을 구하여라. (가) \(\lim_{x\to\infty}\frac{5x^3 - x}{2 - x^3}\) (나) \(\lim_{x\to3^-}\frac{x}{x - 3}\) (다) \(\lim_{x\to\infty}\frac{\sin x}{x}\)
    답

    (가) \(-5\) (나) \(-\infty\) (분자 3, 분모 \(0^-\)) (다) \(|\frac{\sin x}{x}| \le \frac1x\)이므로 압축 정리로 0

  2. \(f(x) = \frac{3x - 1}{x + 2}\)의 점근선을 구하여라.
    답

    수직 \(x = -2\), 수평 \(y = 3\).

  3. \(\lim_{x\to\infty}\left(\sqrt{x^2 + x} - \sqrt{x^2 - x}\right)\)을 구하여라.
    답

    유리화: \(\frac{2x}{\sqrt{x^2 + x} + \sqrt{x^2 - x}} = \frac{2}{\sqrt{1 + 1/x} + \sqrt{1 - 1/x}} \to 1\).

응용

  1. \(f(x) = \frac{\sqrt{9x^2 + 4}}{x}\)의 수평 점근선을 \(x \to \infty\)와 \(x \to -\infty\)에서 각각 구하여라.
    답

    \(x \to \infty\): 3. \(x \to -\infty\): \(\sqrt{9x^2 + 4} = |x|\sqrt{9 + 4/x^2}\), \(|x| = -x\)이므로 \(-3\). 점근선 \(y = 3\), \(y = -3\).

  2. \(f(x) = \frac{2x^3 + x^2}{x^2 + 1}\)의 비스듬한 점근선을 구하여라.
    힌트

    나눗셈: \(2x^3 + x^2 = (x^2 + 1)(2x + 1) - 2x - 1\).

    답

    \(f(x) = 2x + 1 - \frac{2x + 1}{x^2 + 1}\)이고 마지막 항은 0으로 가므로 \(y = 2x + 1\).

심화

  1. 정의 3.3.5로 \(\lim_{x\to\infty}\frac{2x + 1}{x} = 2\)를 증명하고, \(\varepsilon = 0.01\)일 때의 \(N\)을 구하여라.
    답

    \(\left|\frac{2x + 1}{x} - 2\right| = \frac1x\) (\(x > 0\)). \(N = \frac1\varepsilon\)이면 \(x > N\)에서 \(\frac1x < \varepsilon\). \(\varepsilon = 0.01\)이면 \(N = 100\).

3.3.3

예제로피탈 정리와 부정형 바꾸기

0/0 · ∞/∞ · 0·∞ · 1^∞

다루는 성취기준 [공통1-03-03]

정리 · 로피탈

\(f, g\)가 \(a\) 근처(\(a\) 제외)에서 미분 가능하고 \(g'(x) \ne 0\)이며, \(\lim_{x\to a} f = \lim_{x\to a} g = 0\) (또는 둘 다 \(\pm\infty\))일 때, \(\lim_{x\to a}\dfrac{f'(x)}{g'(x)} = L\)이 존재하면(\(\pm\infty\) 포함)

\[\lim_{x\to a}\frac{f(x)}{g(x)} = L.\]

\(a\)가 \(\pm\infty\)이거나 한쪽 극한이어도 성립한다. 증명은 코시 평균값 정리를 쓴다(아래 참고).

조건 세 가지를 매번 확인

  1. 부정형인가\(\frac00\) 또는 \(\frac\infty\infty\)여야 합니다. \(\lim\frac{x+1}{x} \ (x\to 0^+)\)에 쓰면 \(\frac{1}{1} = 1\)이라는 틀린 답이 나옵니다(실제 \(+\infty\)).
  2. \(f'/g'\)의 극한이 존재하는가존재하지 않으면 정리는 아무 말도 하지 않습니다. 예: \(\frac{x + \sin x}{x}\ (x\to\infty)\)는 1로 가지만, \(\frac{1 + \cos x}{1}\)은 극한이 없습니다.
  3. 몫의 미분이 아니다\(\left(\frac fg\right)'\)이 아니라 분자, 분모를 따로 미분합니다.

문제. (가) \(\displaystyle\lim_{x\to0}\frac{x - \sin x}{x^3}\) (나) \(\displaystyle\lim_{x\to0^+} x\ln x\) (다) \(\displaystyle\lim_{x\to\infty}\left(1 + \frac{a}{x}\right)^{x}\)

풀이

  1. (가) \(\frac00\). 로피탈: \(\dfrac{1 - \cos x}{3x^2}\), 여전히 \(\frac00\). 다시: \(\dfrac{\sin x}{6x} \to \dfrac16\).
    마지막 극한이 존재하므로 앞의 등식들이 거꾸로 차례로 정당화된다. \(\frac{\sin x}{x} \to 1\)은 2단원에서 증명.
  2. (나) \(0\cdot(-\infty)\)꼴. 몫으로 바꾼다: \(x\ln x = \dfrac{\ln x}{1/x}\), \(\frac{-\infty}{\infty}\).
    곱은 한 인수를 역수로 내려 몫으로 만든다. 미분하기 쉬운 쪽(\(\ln x\))을 분자에 남긴다.
  3. 로피탈: \(\dfrac{1/x}{-1/x^2} = -x \to 0\). 따라서 \(\lim x\ln x = 0\).
    "\(x\)는 \(\ln x\)보다 빨리 0으로 간다"는 뜻.
  4. (다) \(1^\infty\)꼴. \(y = \left(1 + \frac ax\right)^x\)이면 \(\ln y = x\ln\left(1 + \frac ax\right) = \dfrac{\ln(1 + a/x)}{1/x}\), \(\frac00\).
    지수에 변수가 있으면 로그를 취해 곱 → 몫으로 바꾼다.
  5. \(t = \frac1x \to 0^+\)로 두면 \(\dfrac{\ln(1 + at)}{t} \to \dfrac{a/(1+at)}{1}\Big|_{t=0} = a\) (로피탈).
    변수 치환으로 식이 단순해진다.
  6. \(\ln y \to a\)이므로 \(y = e^{\ln y} \to e^a\).
    \(e^x\)의 연속성. 로그의 극한을 구한 뒤 반드시 지수로 되돌린다.

의미

부정형 극한은 "어느 쪽이 더 빨리 가는가"를 비교하는 일입니다. 이 카드의 결과를 모으면 \(x \to \infty\)에서 \(\ln x \ll x^p \ll e^x\) 순서가 나옵니다. \(\left(1 + \frac ax\right)^x \to e^a\)는 이자를 점점 자주 붙일 때(연속 복리) 원금이 \(e^a\)배가 된다는 뜻입니다.

검산

(가) 수치로 \(x = 0.1\): \(\frac{0.1 - 0.0998334}{0.001} \approx 0.16658\), \(\frac16 \approx 0.16667\). (다) \(a = 1\)이면 \(e\)의 정의 \(\lim(1 + \frac1x)^x = e\)와 같습니다.

왜 성립하나 (증명 개요, \(\frac00\), \(x \to a^+\))

  1. \(f(a) = g(a) = 0\)으로 정의해 \([a, x]\)에서 연속으로 만든다.
    극한이 0이므로 이 정의로 연속이 된다.
  2. 코시 평균값 정리: \(h(t) = f(t)g(x) - g(t)f(x)\)에 롤 정리를 쓰면 \(\dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)}\)인 \(c \in (a, x)\)가 있다.
    \(h(a) = 0 = h(x)\). \(h'(c) = 0\)에서 \(f'(c)g(x) = g'(c)f(x)\). \(g'\ne0\)이면 롤 정리로 \(g(x) \ne g(a) = 0\)이라 나눌 수 있다.
  3. \(x \to a^+\)이면 \(c \to a^+\)이므로 \(\dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)} \to L\).
    \(a < c < x\)라 압축된다.

흔한 오해

  • \(\infty - \infty\)에 바로 쓰기: 먼저 통분해 몫으로 바꿉니다. 예: \(\frac1x - \frac{1}{\sin x} = \frac{\sin x - x}{x\sin x}\).
  • 쓸 필요가 없는데 쓰기: \(\frac{\sin x}{x}\)에 로피탈을 쓰면 \((\sin x)' = \cos x\)를 증명할 때 이미 이 극한을 썼으므로 순환 논증입니다.
3.3.4

예제무한대로 가는 극한과 점근선 구하기

수직·수평·비스듬한 점근선

다루는 성취기준 [공통1-03-03]

먼저 뜻 정리

  1. \(\lim_{x\to a} f(x) = \infty\)임의의 \(M > 0\)에 대해 \(\delta > 0\)가 있어 \(0 < |x - a| < \delta \Rightarrow f(x) > M\). "아무리 높은 선을 그어도 \(a\) 근처에서는 그보다 위". 극한이 존재하지 않는 한 방식이며, \(\infty\)는 수가 아닙니다.
  2. \(\lim_{x\to\infty} f(x) = L\)임의의 \(\varepsilon > 0\)에 대해 \(N\)이 있어 \(x > N \Rightarrow |f(x) - L| < \varepsilon\). 수열의 극한과 같은 꼴입니다.
  3. 점근선수직: \(x \to a^+\) 또는 \(a^-\)에서 \(f \to \pm\infty\)이면 \(x = a\). 수평: \(x \to \pm\infty\)에서 \(f \to L\)이면 \(y = L\). 비스듬: \(f(x) - (mx + b) \to 0\)이면 \(y = mx + b\).

\(f(x) = \dfrac{3x^2 - 2}{x^2 - x - 2}\)의 모든 점근선을 구하고, 각 점근선 근처에서 그래프의 위치를 설명하세요.

전략

유리함수는 (1) 분모의 근에서 수직 점근선 후보를 찾고, 약분되는 인수가 있는지 확인합니다(약분되면 점근선이 아니라 구멍). (2) 분자·분모의 최고차항으로 \(x \to \pm\infty\)의 행동을 봅니다. 차수가 같으면 수평 점근선, 분자가 1차 높으면 비스듬한 점근선입니다.

풀이

  1. 분모를 인수분해하면 \(x^2 - x - 2 = (x - 2)(x + 1)\). 분자 \(3x^2 - 2\)는 \(x = 2\)에서 10, \(x = -1\)에서 1로 0이 아니므로 약분되는 인수가 없다.
    분모가 0이고 분자가 0이 아니면 그 점 근처에서 \(|f| \to \infty\).
  2. \(x \to 2^+\): 분자 → 10, \((x - 2) \to 0^+\), \((x+1) \to 3\)이므로 \(f(x) \to +\infty\). \(x \to 2^-\): \((x-2) \to 0^-\)이므로 \(f(x) \to -\infty\). 수직 점근선 \(x = 2\).
    부호는 각 인수의 부호를 곱해 정한다.
  3. \(x \to -1^+\): 분자 → 1, \((x-2) \to -3\), \((x+1) \to 0^+\)이므로 분모 → \(0^-\), \(f \to -\infty\). \(x \to -1^-\): 분모 → \(0^+\), \(f \to +\infty\). 수직 점근선 \(x = -1\).
    2단계와 같은 방법.
  4. \(x \to \pm\infty\): 분자·분모를 \(x^2\)으로 나누면 \(f(x) = \dfrac{3 - 2/x^2}{1 - 1/x - 2/x^2} \to \dfrac{3}{1} = 3\). 수평 점근선 \(y = 3\).
    \(\frac{1}{x^k} \to 0\). 최고차항이 같은 차수면 계수의 비.
  5. 위치: \(f(x) - 3 = \dfrac{3x^2 - 2 - 3(x^2 - x - 2)}{x^2 - x - 2} = \dfrac{3x + 4}{x^2 - x - 2}\). 큰 양수 \(x\)에서 분자·분모 모두 양수 → 점근선 위, 큰 음수 \(x\)에서 분자 음수·분모 양수 → 점근선 아래.
    차이의 부호를 보면 어느 쪽에서 다가가는지 안다. 차이가 0이 되는 \(x = -\frac43\)에서는 그래프가 수평 점근선을 가로지른다.

의미

점근선은 \(x\)가 아주 크거나 분모가 0에 가까울 때 그래프가 어떻게 행동하는지를 한 줄로 요약합니다. 수평·사선 점근선은 나눗셈의 몫(다항식 부분)이고, 나머지 항의 부호가 그래프가 점근선의 위에 있는지 아래에 있는지를 정합니다. 컴퓨터 그래프에서 놓치기 쉬운 부분을 계산으로 확인하는 도구입니다.

검산

\(f(100) = \frac{29998}{9898} \approx 3.031 > 3\), \(f(-100) = \frac{29998}{10098} \approx 2.971 < 3\). 5단계와 일치합니다. 수평 점근선을 그래프가 가로지를 수 있다는 점도 확인됩니다(수직 점근선은 가로지를 수 없음).

바꿔 보기

  • 분자를 \(x^2 - 4\)로 바꾸면 \(x = 2\)에서 약분되어 수직 점근선이 아니라 구멍이 됩니다(\(\lim_{x\to2} = \frac43\)).
  • \(g(x) = \frac{x^3}{x^2 + 1}\)이면 분자가 1차 높으므로 나눗셈 \(g(x) = x - \frac{x}{x^2+1}\)에서 비스듬한 점근선 \(y = x\).
  • \(h(x) = \frac{e^x}{x}\)는 유리함수가 아니지만 \(x \to -\infty\)에서 0(수평 점근선 \(y=0\)), \(x \to \infty\)에서 \(\infty\)이고 어떤 직선에도 다가가지 않습니다(지수가 다항식보다 빠름).
