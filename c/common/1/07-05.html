7.5.1원뿔을 자르면

원뿔을 평면으로 자르면 자르는 기울기에 따라 단면이 원, 타원, 포물선, 쌍곡선이 됩니다. 그래서 이들을 원뿔곡선(이차곡선)이라 부릅니다. 행성의 궤도(타원), 위성 안테나와 손전등 반사경(포물선), 일부 혜성의 궤도(쌍곡선)가 모두 원뿔곡선입니다. 계산에는 원뿔보다 "초점까지의 거리"로 정의하는 편이 편합니다.

7.5.2포물선

정의 7.5.1 (포물선)

한 점(초점)과 한 직선(준선)에서 같은 거리에 있는 점들의 자취.

초점 \((0, p)\), 준선 \(y = -p\)이면 점 \((x, y)\)에 대해 \(\sqrt{x^2 + (y - p)^2} = |y + p|\). 제곱해 정리하면 \(x^2 = 4py\)입니다. 꼭짓점은 원점이고, \(p > 0\)이면 위로 열립니다. 초점과 준선을 바꾸면 \(y^2 = 4px\) (오른쪽으로 열림)입니다.

축에 나란하게 들어온 빛은 포물선에서 반사되어 모두 초점에 모입니다. 위성 안테나가 포물면 모양인 이유입니다.

7.5.3타원

정의 7.5.2 (타원)

두 점(초점)까지의 거리의 합이 일정한 점들의 자취.

초점 \((\pm c, 0)\), 거리의 합 \(2a\) (\(a > c\))이면 표준형은

\[\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1, \qquad b^2 = a^2 - c^2.\]

꼭짓점은 \((\pm a, 0)\), \((0, \pm b)\)이고, \(2a\)가 장축, \(2b\)가 단축의 길이입니다. 줄의 양 끝을 압정 두 개에 고정하고 연필로 줄을 팽팽하게 당기며 돌리면 타원이 그려집니다.

7.5.4쌍곡선

정의 7.5.3 (쌍곡선)

두 점(초점)까지의 거리의 차가 일정한 점들의 자취.

초점 \((\pm c, 0)\), 거리의 차 \(2a\) (\(a < c\))이면

\[\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1, \qquad b^2 = c^2 - a^2.\]

꼭짓점은 \((\pm a, 0)\)이고, 두 직선 \(y = \pm\frac bax\)가 점근선입니다. \(x\)가 커지면 \(\frac{y^2}{b^2} = \frac{x^2}{a^2} - 1 \approx \frac{x^2}{a^2}\)이 되기 때문입니다.

예제 7.5.4

(가) \(9x^2 + 4y^2 = 36\) (나) \(9x^2 - 16y^2 = 144\)의 초점을 구하여라.

풀이. (가) 36으로 나누면 \(\frac{x^2}{4} + \frac{y^2}{9} = 1\). \(y\) 쪽이 크므로 장축이 \(y\)축 위에 있고 \(c^2 = 9 - 4 = 5\). 초점 \((0, \pm\sqrt5)\).

(나) 144로 나누면 \(\frac{x^2}{16} - \frac{y^2}{9} = 1\). \(c^2 = 16 + 9 = 25\), 초점 \((\pm5, 0)\), 점근선 \(y = \pm\frac34x\).

주의타원은 \(c^2 = a^2 - b^2\) (빼기), 쌍곡선은 \(c^2 = a^2 + b^2\) (더하기)입니다. 섞어 쓰는 실수가 흔합니다.
요약
  1. 포물선: 초점과 준선에서 같은 거리. \(x^2 = 4py\).
  2. 타원: 두 초점까지 거리의 합이 일정. \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\), \(c^2 = a^2 - b^2\).
  3. 쌍곡선: 거리의 차가 일정. \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\), \(c^2 = a^2 + b^2\), 점근선 \(y = \pm\frac bax\).

7.5.5연습문제

기본

  1. 포물선 \(y^2 = 8x\)의 초점과 준선을 구하여라.
    답

    \(4p = 8\), \(p = 2\). 초점 \((2, 0)\), 준선 \(x = -2\).

  2. 초점이 \((\pm4, 0)\), 장축의 길이가 10인 타원의 방정식은?
    답

    \(a = 5\), \(b^2 = 25 - 16 = 9\). \(\frac{x^2}{25} + \frac{y^2}{9} = 1\).
