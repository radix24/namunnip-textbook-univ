6.2.1원판으로 어려운 경우

\(y = 2x^2 - x^3\)과 \(x\)축 사이(\(0 \le x \le 2\))의 영역을 \(y\)축 둘레로 돌린다고 합시다. 원판 방법을 쓰려면 \(y\)로 썰고 \(x\)를 \(y\)의 식으로 풀어야 하는데, 삼차방정식이라 풀기 어렵습니다. 이럴 때는 \(y\)축과 나란한 세로 띠를 돌려 생기는 얇은 원통 껍질로 나누면 \(x\)로 그대로 적분할 수 있습니다.

\(x\)에 있는 폭 \(dx\), 높이 \(f(x)\)인 세로 띠를 \(y\)축 둘레로 돌리면 반지름 \(x\), 높이 \(f(x)\), 두께 \(dx\)인 원통 껍질이 됩니다. 이 껍질을 펼치면 가로 \(2\pi x\)(둘레), 세로 \(f(x)\), 두께 \(dx\)인 판이므로 부피는 \(2\pi x f(x)\,dx\)입니다.

정의 6.2.1 (원통껍질 방법)

\(y = f(x) \ge 0\) 아래, \(0 \le a \le x \le b\)인 영역을 \(y\)축 둘레로 돌린 입체의 부피는

\[V = \int_a^b 2\pi x\,f(x)\,dx.\]

읽는 법: "둘레(\(2\pi\times\)반지름) × 높이 × 두께"를 더한다.

예제 6.2.2

위의 \(y = 2x^2 - x^3\), \(0 \le x \le 2\) 영역을 \(y\)축 둘레로 돌린 부피를 구하여라.

풀이.

\[V = \int_0^2 2\pi x(2x^2 - x^3)\,dx = 2\pi\left[\frac{x^4}{2} - \frac{x^5}{5}\right]_0^2 = 2\pi\left(8 - \frac{32}{5}\right) = \frac{16\pi}{5}.\]

6.2.2어느 방법을 쓸까

원판·와셔원통껍질
띠의 방향회전축에 수직회전축에 나란
\(y\)축 회전\(dy\)로 적분, \(x = g(y)\) 필요\(dx\)로 적분, \(y = f(x)\) 그대로
\(x\)축 회전\(dx\)로 적분\(dy\)로 적분

함수를 주어진 꼴 그대로 쓸 수 있는 방법을 고르는 것이 보통 편합니다. 두 방법은 같은 답을 줍니다.

예제 6.2.3

\(y = x\)와 \(y = x^2\)으로 둘러싸인 영역을 \(y\)축 둘레로 돌린 부피를 두 방법으로 구하여라.

풀이. 원통껍질: 높이 \(x - x^2\), \(V = \int_0^1 2\pi x(x - x^2)dx = 2\pi\left(\frac13 - \frac14\right) = \frac\pi6\).

와셔: \(y\)로 썰면 바깥 반지름 \(\sqrt y\), 안쪽 반지름 \(y\). \(V = \int_0^1\pi(y - y^2)dy = \frac\pi6\). 같습니다.

주의회전축이 \(y\)축이 아니라 \(x = 2\) 같은 직선이면 반지름은 \(x\)가 아니라 회전축까지의 거리 \(|2 - x|\)입니다.
요약
  1. 원통껍질: \(V = \int 2\pi(\text{반지름})(\text{높이})\,dx\).
  2. 회전축에 나란한 띠를 쓴다. 함수를 풀기 어려울 때 편하다.

6.2.3연습문제

기본

  1. \(y = \sin x\), \(0 \le x \le \pi\)와 \(x\)축 사이 영역을 \(y\)축 둘레로 돌린 부피는?
    답

    \(\int_0^\pi2\pi x\sin x\,dx = 2\pi[\sin x - x\cos x]_0^\pi = 2\pi^2\).

응용

  1. \(y = x^2\), \(0 \le x \le 1\)과 \(x\)축 사이 영역을 직선 \(x = 2\) 둘레로 돌린 부피는?
    답

    반지름 \(2 - x\): \(\int_0^1 2\pi(2 - x)x^2dx = 2\pi\left(\frac23 - \frac14\right) = \frac{5\pi}{6}\).

6.2.2

탐구회전체를 원판으로 자를까, 껍질로 벗길까?

탐구 · 회전체의 부피

다루는 성취기준 [공통1-06-01] [공통1-06-02]

질문

곡선 아래 영역을 축 둘레로 돌리면 입체가 생깁니다. 이 입체를 얇은 조각으로 나누는 방법은 두 가지입니다. 회전축에 수직으로 잘라 동전 모양 원판을 쌓을 수도 있고, 회전축과 나란하게 양파 껍질 같은 원통을 겹칠 수도 있습니다. 조각을 늘리면 두 방법 모두 적분값에 다가갈까요?

복원

  • 원판(x축 둘레): 너비 \(\Delta x\)인 띠를 x축 둘레로 돌리면 반지름 \(f(x_i)\), 두께 \(\Delta x\)인 원판이 됩니다. 부피는 \(\pi f(x_i)^2\Delta x\)이고, 모두 더해 극한을 잡으면 \(V = \displaystyle\int_a^b \pi f(x)^2\,dx\)입니다.
  • 원통껍질(y축 둘레): 같은 띠를 y축 둘레로 돌리면 반지름 \(x_i\), 높이 \(f(x_i)\), 두께 \(\Delta x\)인 얇은 원통 껍질이 됩니다. 펼치면 가로 \(2\pi x_i\), 세로 \(f(x_i)\), 두께 \(\Delta x\)인 판이므로 부피는 \(2\pi x_i f(x_i)\Delta x\), 극한은 \(V = \displaystyle\int_a^b 2\pi x f(x)\,dx\)입니다.
  • 그림의 점선은 회전축 반대편에 비친 곡선이고, 타원은 조각 하나가 돌아가며 그리는 원을 비스듬히 본 모습입니다. 조각의 높이는 각 띠의 가운데 점 \(x_i\)에서 잽니다.

설명

\(y = \sqrt x\)를 x축 둘레로 돌리면 \(\pi\int_0^4 x\,dx = 8\pi \approx 25.1327\)입니다. 이 경우 \(\pi f(x)^2 = \pi x\)가 일차함수라서, 가운데 점으로 잰 합이 \(n\)과 상관없이 정확히 \(8\pi\)가 됩니다. 같은 영역을 y축 둘레로 돌리면 \(2\pi\int_0^4 x^{3/2}dx = \dfrac{128\pi}{5} \approx 80.4248\)이고, 껍질 4개로는 79.7425, 16개로는 80.3789로 다가갑니다. \(y = x(3 - x)\)는 원판 4개로 25.5339(정확한 값 \(8.1\pi \approx 25.4469\)), 껍질 4개로 43.7369(정확한 값 \(13.5\pi \approx 42.4115\))입니다.

연결

두 방법 모두 "작은 조각의 부피를 더하고 극한을 잡는다"는 리만 합(4.1절)입니다. 어느 방법이 쉬운지는 영역을 어느 변수로 나타내기 쉬운지에 달려 있습니다. 공통2의 중적분(공통2 6.5절)에서는 원기둥좌표로 같은 부피를 구합니다.

적용

\(y = x(3 - x)\)를 y축 둘레로 돌린 입체를 원판으로 자르려면 \(x\)를 \(y\)의 식으로 풀어야 하고, 영역이 안쪽 곡선과 바깥쪽 곡선 두 개로 나뉩니다. 왜 이 경우 원통껍질 방법이 더 편한지 설명해 보세요.

판단

한 학생이 "y축 둘레로 돌린 부피를 원판 공식 \(\pi\int_0^3 f(x)^2\,dx\)로 구했더니 \(8.1\pi\)가 나왔다"고 합니다. 위 그림과 출력으로 이 답이 틀린 이유를 찾아보세요.
