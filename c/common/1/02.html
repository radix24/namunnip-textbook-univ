2.1

설명ε-δ 정의는 무엇을 약속하는가?

극한의 정의

다루는 성취기준 [공통1-02-01]

왜 필요한가

고등학교에서는 "\(x\)가 \(a\)에 한없이 가까워질 때 \(f(x)\)가 \(L\)에 한없이 가까워진다"를 \(\lim_{x\to a} f(x) = L\)의 뜻으로 배웠습니다. 이 문장은 그림을 떠올리기에는 좋지만, 무엇을 확인하면 극한이 맞는지는 알려 주지 않습니다.

"한없이 가까워진다"를 확인하려면 \(x\)를 끝없이 움직여 봐야 할 것 같습니다. 그러나 무한히 많은 값을 하나하나 대입할 수는 없습니다. 또 \(\sin\frac{1}{x}\)처럼 0 근처에서 끝없이 출렁이는 함수가 0에서 극한을 갖는지는 그림만으로 판단하기 어렵습니다.

ε-δ 정의는 "한없이"라는 말을 쓰지 않고, 유한한 수 두 개(ε, δ)를 주고받는 약속으로 극한을 정의합니다. 그래서 극한이 맞는지를 증명할 수 있게 됩니다. 해석학, 미분방정식, 확률론의 모든 수렴 개념이 이 형식을 따릅니다.

정의 · 함수의 극한

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 (\(a\) 자신은 빼도 됨) 정의되어 있다고 하자. 임의의 \(\varepsilon > 0\)에 대하여 어떤 \(\delta > 0\)가 존재해서

\[0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon\]

가 성립하면, \(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한은 \(L\)이라 하고 \(\lim_{x\to a} f(x) = L\)로 쓴다.

정의를 풀어 읽기

  1. "임의의 \(\varepsilon > 0\)에 대하여"\(\varepsilon\)은 상대가 정하는 허용 오차입니다. "\(f(x)\)와 \(L\)의 차이를 이만큼 이하로 줄여 보라"는 요구입니다. 0.1이든 \(10^{-9}\)이든, 양수이기만 하면 어떤 요구에도 답해야 합니다. 그래서 '임의의'가 앞에 옵니다.
  2. "어떤 \(\delta > 0\)가 존재해서"\(\delta\)는 우리가 고르는 입력의 범위입니다. 요구된 \(\varepsilon\)을 보고 나서 고르므로, \(\delta\)는 \(\varepsilon\)에 따라 달라져도 됩니다(보통 \(\varepsilon\)이 작을수록 \(\delta\)도 작아집니다). 하나만 찾으면 됩니다.
  3. "\(0 < |x - a|\)"\(x = a\)는 빼고 봅니다. 극한은 \(a\) 근처의 행동을 묻는 것이지 \(f(a)\)의 값을 묻는 것이 아닙니다. \(f(a)\)가 정의되지 않거나 엉뚱한 값이어도 극한은 있을 수 있습니다.
  4. "\(|x - a| < \delta\)"입력을 \(a\)에서 \(\delta\)보다 가까운 곳으로 제한합니다. 수직선에서는 열린구간 \((a-\delta,\ a+\delta)\)입니다.
  5. "\(\implies |f(x) - L| < \varepsilon\)"그 범위의 모든 \(x\)에서 출력이 허용 오차 안에 들어와야 합니다. 몇 개의 \(x\)에서만 맞으면 안 됩니다.

순서가 중요합니다. ε이 먼저, δ가 나중입니다. 이 순서를 게임으로 생각하면 쉽습니다. 상대가 \(\varepsilon\)을 내밀면 우리가 \(\delta\)로 답합니다. 상대가 어떤 \(\varepsilon\)을 내밀어도 답할 방법(규칙)이 있으면 극한이 \(L\)입니다.

예와 반례

예 1. \(f(x) = 3x - 1\), \(a = 2\), \(L = 5\). \(|f(x) - 5| = |3x - 6| = 3|x - 2|\)이므로 \(|x-2| < \frac{\varepsilon}{3}\)이면 \(|f(x) - 5| < \varepsilon\)입니다. 규칙 "\(\delta = \frac{\varepsilon}{3}\)"이 모든 \(\varepsilon\)에 답합니다.

예 2. \(f(x) = \frac{x^2 - 4}{x - 2}\)는 \(x = 2\)에서 정의되지 않지만, \(x \ne 2\)이면 \(f(x) = x + 2\)입니다. 정의는 \(x \ne 2\)만 보므로 \(\delta = \varepsilon\)으로 \(\lim_{x\to 2} f(x) = 4\)를 보일 수 있습니다.

반례. \(g(x) = 1\ (x \ge 0)\), \(g(x) = -1\ (x < 0)\)일 때 \(\lim_{x\to 0} g(x) = 1\)이 아닌 이유: \(\varepsilon = 1\)을 받으면 어떤 \(\delta\)를 골라도 \((-\delta, 0)\)의 \(x\)에서 \(|g(x) - 1| = 2\)입니다. "모든 \(x\)에서" 구절에서 걸립니다. 같은 이유로 어떤 \(L\)도 극한이 될 수 없습니다(왼쪽과 오른쪽이 2만큼 떨어져 있어서 \(\varepsilon = 1\) 안에 둘 다 넣을 수 없음).

다른 개념과의 관계

  • 수열의 극한: \(\lim a_n = L\)은 "임의의 \(\varepsilon\)에 대해 어떤 \(N\)이 있어 \(n > N\)이면 \(|a_n - L| < \varepsilon\)". \(\delta\) 자리에 \(N\)이 들어간 같은 형식입니다.
  • 연속: \(\lim_{x\to a} f(x) = f(a)\)가 연속의 정의입니다. 이 단원 뒤쪽 설명 카드에서 다룹니다.
  • 극한 법칙(합·곱·몫의 극한)은 모두 이 정의로 증명됩니다. 한 번 증명해 두면 그다음부터는 법칙으로 계산합니다.

흔한 오해

  • "δ를 먼저 정하고 ε을 구한다." 거꾸로입니다. \(\delta\)를 먼저 고정하면 "\(\delta\)가 작을 때 오차가 작다"는 말이 되어, 극한이 아닌 함수도 통과할 수 있습니다.
  • "\(f(a) = L\)이어야 한다." 정의는 \(x = a\)를 뺍니다. 극한은 \(f(a)\)와 상관없습니다.
  • "가장 큰 δ를 찾아야 한다." 통하는 \(\delta\)를 하나만 찾으면 됩니다. 통하는 \(\delta\)보다 작은 값은 모두 통하므로, 계산이 편한 작은 값을 골라도 됩니다.

2.2

탐구ε을 받으면 δ로 답한다

ε-δ 게임 · 그래프

다루는 성취기준 [공통1-02-01]

판정
—
통하는 가장 큰 δ
—
규칙이 주는 δ
—

판정은 세로 띠 안의 2000개 점에서 \(|f(x) - L|\)을 계산한 결과입니다. 점 \(x=a\)는 빼고 봅니다.

  1. 질문\(x^2\)은 \(x=2\) 근처에서 4에 가까워 보입니다. 그런데 "가까워 보인다"를 어떻게 증명할까요? 상대가 오차 \(\varepsilon\)을 요구할 때마다 우리가 입력 범위 \(\delta\)를 내놓는 게임으로 바꿔 봅니다.
  2. 복원\(|x - a| < \delta\)는 \(a\)를 가운데로 한 폭 \(2\delta\)의 열린구간, \(|f(x) - L| < \varepsilon\)은 \(L\)을 가운데로 한 높이 \(2\varepsilon\)의 띠입니다. 앞 카드의 정의를 이 두 띠로 읽습니다.
  3. 설명세로 띠 안의 그래프 조각이 모두 가로 띠 안에 들어가면 그 \(\delta\)는 \(\varepsilon\)에 대한 답이 됩니다. \(\delta\)를 줄이면 그래프 조각이 짧아지므로 들어가기 쉬워집니다.
  4. 연결\(\varepsilon\)을 줄일 때마다 \(\delta\)도 줄여야 합니다. "통하는 가장 큰 δ"와 "규칙이 주는 δ"를 비교해 보세요. \(x^2\)의 규칙 \(\delta = \min\{1, \varepsilon/5\}\)은 가장 큰 값보다 작지만 늘 통합니다. 증명에는 통하는 규칙 하나면 충분합니다.
  5. 적용계단 함수로 바꾸고 \(L\)을 움직여 보세요. \(\varepsilon\)이 1보다 작아지면 어떤 \(\delta\), 어떤 \(L\)로도 초록이 되지 않습니다. 이것이 "극한이 없다"의 그림입니다.
  6. 판단그림은 \(\varepsilon\) 몇 개만 시험합니다. 극한을 증명하려면 모든 \(\varepsilon\)에 통하는 규칙을 식으로 보여야 합니다. 다음 증명 카드가 그 일을 합니다.
2.3

증명\(\lim_{x\to 2} x^2 = 4\)를 ε-δ로 증명하기

초안에서 정리된 증명까지

다루는 성취기준 [공통1-02-01]

정리

\(\lim_{x\to 2} x^2 = 4\).

쓰는 것

  • 극한의 정의: 임의의 \(\varepsilon>0\)에 대해 \(\delta>0\)를 찾아 \(0<|x-2|<\delta \Rightarrow |x^2-4|<\varepsilon\)을 보이면 된다.
  • 절댓값의 곱: \(|uv| = |u||v|\).
  • 삼각부등식: \(|u+v| \le |u| + |v|\).

아이디어

목표인 \(|x^2 - 4|\)를 우리가 통제하는 \(|x - 2|\)로 나타냅니다. 인수분해하면 \(|x^2-4| = |x-2|\,|x+2|\)입니다. 앞의 \(|x-2|\)는 \(\delta\)로 작게 만들 수 있습니다. 문제는 뒤의 \(|x+2|\)입니다. 이 값은 \(x\)에 따라 변하므로, \(x\)를 2 근처로 묶어 \(|x+2|\)가 어떤 상수보다 작다고 먼저 못 박습니다. 그러면 남은 일은 \(|x-2|\)를 작게 하는 것뿐입니다.

이렇게 "곤란한 인수를 상수로 누르고, 그다음 \(\delta\)를 고르는" 방법은 다항식, 유리함수의 ε-δ 증명에서 거의 언제나 씁니다.

초안: δ를 찾는 과정 (교재에는 잘 안 나오는 부분)

  1. 목표를 인수분해합니다. \(|x^2 - 4| = |x-2|\,|x+2|\).
    \(x^2-4=(x-2)(x+2)\)와 절댓값의 곱.
  2. \(|x+2|\)를 누르기 위해 일단 \(\delta \le 1\)로 정합니다. 그러면 \(|x-2|<1\), 곧 \(1 < x < 3\)이고 \(3 < x+2 < 5\)이므로 \(|x+2| < 5\)입니다.
    1은 아무 양수나 골라도 됩니다. 계산이 편한 값을 골랐습니다. 2를 고르면 \(|x+2|<6\)이 됩니다.
  3. 그러면 \(|x^2-4| < 5|x-2|\)입니다. 이것이 \(\varepsilon\)보다 작으려면 \(|x-2| < \frac{\varepsilon}{5}\)이면 됩니다.
    2단계의 부등식을 1단계 식에 대입.
  4. 두 조건 \(|x-2|<1\)과 \(|x-2|<\frac{\varepsilon}{5}\)를 동시에 만족시키려면 \(\delta = \min\{1, \frac{\varepsilon}{5}\}\)로 고릅니다.
    \(|x-2| < \min\{p, q\}\)이면 \(|x-2| < p\)이고 \(|x-2| < q\).

초안은 결론에서 출발해 거꾸로 갑니다. 정리된 증명은 초안에서 찾은 \(\delta\)를 먼저 내놓고 앞으로 갑니다.

정리된 증명

  1. \(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\{1, \frac{\varepsilon}{5}\}\)로 둔다. 그러면 \(\delta > 0\)이다.
    두 양수의 최솟값은 양수. 정의가 요구하는 "\(\delta>0\)가 존재"를 직접 만들어 보인다.
  2. \(0 < |x - 2| < \delta\)인 \(x\)를 아무거나 잡는다. \(\delta \le 1\)이므로 \(|x-2| < 1\), 따라서 \(1 < x < 3\)이고 \(|x+2| < 5\)이다.
    \(\delta\)의 정의(최솟값 ≤ 1)와 부등식의 덧셈.
  3. \(\delta \le \frac{\varepsilon}{5}\)이므로 \(|x - 2| < \frac{\varepsilon}{5}\)이다.
    \(\delta\)의 정의(최솟값 ≤ ε/5).
  4. 따라서 \(|x^2 - 4| = |x-2|\,|x+2| < \frac{\varepsilon}{5}\cdot 5 = \varepsilon\). \(\varepsilon\)이 임의였으므로 \(\lim_{x\to 2} x^2 = 4\)이다.
    2, 3단계의 두 부등식을 곱함(양수끼리이므로 방향 유지). 마지막 문장은 "임의의 ε"을 확인했다는 표시.

되짚기

  • 1을 고른 이유. \(|x+2|\)를 상수로 누르려면 \(x\)를 유계 구간에 가둬야 했습니다. 그 구간의 크기로 1을 골랐습니다. 이 제한이 없으면 \(x\)가 커질수록 \(|x+2|\)도 커져서 \(\varepsilon/|x+2|\) 같은 "\(x\)에 의존하는 δ"가 되어 버립니다. \(\delta\)는 \(\varepsilon\)에만 의존해야 합니다.
  • min을 쓴 이유. \(\varepsilon\)이 클 때(예: \(\varepsilon = 100\)) \(\varepsilon/5 = 20\)을 그대로 쓰면 2단계의 \(|x+2|<5\)가 깨집니다. min이 두 조건을 모두 지킵니다.
  • 통하는 가장 큰 δ는 아닙니다. 앞의 탐구 카드에서 본 것처럼 실제로는 더 큰 \(\delta\)도 통합니다. 증명에는 통하는 \(\delta\) 하나면 됩니다.

더 나아가기

같은 방법으로 \(\lim_{x\to a} x^2 = a^2\)을 보일 수 있습니다. \(\delta \le 1\)이면 \(|x + a| \le |x - a| + 2|a| < 1 + 2|a|\)이므로 \(\delta = \min\{1, \frac{\varepsilon}{1 + 2|a|}\}\)로 고르면 됩니다(삼각부등식을 썼습니다).

직접 써 보기

\(\lim_{x\to 3} (x^2 - x) = 6\)을 ε-δ로 증명하세요. 초안을 먼저 쓰고 정리된 증명으로 옮기세요.

힌트

\(x^2 - x - 6 = (x-3)(x+2)\). \(|x-3|<1\)이면 \(|x+2|\)는 무엇보다 작을까요?

답안

\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\{1, \frac{\varepsilon}{6}\}\)로 둔다. \(0 < |x-3| < \delta\)이면 \(|x - 3| < 1\)이므로 \(2 < x < 4\), 따라서 \(4 < x + 2 < 6\)이고 \(|x+2| < 6\)이다. 또 \(|x-3| < \frac{\varepsilon}{6}\)이다. 그러므로

\[|x^2 - x - 6| = |x-3|\,|x+2| < \tfrac{\varepsilon}{6}\cdot 6 = \varepsilon.\]

\(\varepsilon\)이 임의였으므로 \(\lim_{x\to 3}(x^2 - x) = 6\). ∎

2.4

증명압축 정리: 양쪽에서 조이면 가운데도 따라간다

극한 법칙

다루는 성취기준 [공통1-02-02]

정리 · 압축 정리 (squeeze theorem)

\(a\)를 포함하는 열린구간의 \(x \ne a\)에서 \(g(x) \le f(x) \le h(x)\)이고, \(\lim_{x\to a} g(x) = \lim_{x\to a} h(x) = L\)이면 \(\lim_{x\to a} f(x) = L\)이다.

쓰는 것

  • 극한의 정의 (ε-δ). \(g\)와 \(h\)의 극한에서 각각 \(\delta\)를 하나씩 얻는다.
  • 절댓값 부등식: \(|u - L| < \varepsilon \iff L - \varepsilon < u < L + \varepsilon\).

아이디어

\(f(x)\)를 \(L \pm \varepsilon\) 띠 안에 넣고 싶습니다. \(f\)를 직접 다룰 수는 없지만, \(f\)는 늘 \(g\)와 \(h\) 사이에 있습니다. 그러니 \(g\)는 띠의 아래쪽 경계보다 위에, \(h\)는 위쪽 경계보다 아래에 두면 \(f\)도 띠 안에 갇힙니다. \(g\)에서 얻는 \(\delta_1\), \(h\)에서 얻는 \(\delta_2\), 부등식이 성립하는 구간의 반지름 \(\delta_0\)를 모두 만족하도록 셋 중 가장 작은 것을 고릅니다.

증명

  1. 가정에서 \(0 < |x - a| < \delta_0\)이면 \(g(x) \le f(x) \le h(x)\)가 되는 \(\delta_0 > 0\)가 있다.
    "\(a\)를 포함하는 열린구간에서"라는 가정을 반지름으로 옮긴 것.
  2. \(\varepsilon > 0\)이 주어졌다고 하자. \(\lim g = L\)이므로 \(0<|x-a|<\delta_1 \Rightarrow L - \varepsilon < g(x) < L + \varepsilon\)인 \(\delta_1 > 0\)가 있다.
    \(g\)의 극한의 정의와 절댓값 부등식.
  3. 같은 이유로 \(0<|x-a|<\delta_2 \Rightarrow L - \varepsilon < h(x) < L + \varepsilon\)인 \(\delta_2 > 0\)가 있다.
    \(h\)의 극한의 정의. 같은 \(\varepsilon\)에 대해 얻는다.
  4. \(\delta = \min\{\delta_0, \delta_1, \delta_2\}\)로 둔다. \(\delta > 0\)이다.
    세 조건을 동시에 쓰기 위한 최솟값.
  5. \(0 < |x-a| < \delta\)이면 1~3단계가 모두 성립하므로 \(L - \varepsilon < g(x) \le f(x) \le h(x) < L + \varepsilon\), 곧 \(|f(x) - L| < \varepsilon\). 따라서 \(\lim_{x\to a} f(x) = L\).
    2단계의 왼쪽 부등식, 1단계, 3단계의 오른쪽 부등식을 이어 붙임. \(g\)의 위쪽 부등식과 \(h\)의 아래쪽 부등식은 쓰이지 않는다.

되짚기

  • 마지막 단계에서 \(g\)는 아래쪽만, \(h\)는 위쪽만 썼습니다. 그래서 극한이 같아야 한다는 가정이 꼭 필요합니다.
  • 가정을 빼면. \(g \to 0\), \(h \to 1\)처럼 극한이 다르면 결론이 깨집니다. 예: \(g(x) = 0\), \(h(x) = 1\), \(f(x) = \frac{1}{2}(1 + \sin\frac{1}{x})\)는 0과 1 사이에 있지만 \(x \to 0\)에서 극한이 없습니다.
  • 부등식은 \(a\) 근처에서만 성립하면 됩니다. 멀리서의 대소 관계는 극한과 상관없습니다.

더 나아가기

자주 쓰는 형태: \(|f(x) - L| \le h(x)\)이고 \(h(x) \to 0\)이면 \(f(x) \to L\). \(g = L - h\), \(h\)를 위 정리에 넣은 것입니다. 예: \(|x \sin\frac{1}{x}| \le |x|\)이므로 \(\lim_{x\to 0} x\sin\frac{1}{x} = 0\).

2.5

예제\(\lim_{x\to 0} \frac{\sin x}{x} = 1\)은 왜 성립할까?

넓이 비교 · 압축 정리

다루는 성취기준 [공통1-02-02]

\(\lim_{x\to 0} \dfrac{\sin x}{x}\)를 구하세요. 단, \(x\)는 라디안입니다.

전략

\(x = 0\)을 대입하면 \(\frac{0}{0}\)이라 극한 법칙(몫의 극한)을 쓸 수 없습니다. 로피탈 정리를 쓰면 \(\frac{\cos x}{1} \to 1\)이지만, \(\sin x\)의 도함수가 \(\cos x\)라는 사실 자체가 이 극한으로 증명되므로 순환 논법이 됩니다. 그래서 미분 없이, 단위원에서 넓이를 비교해 \(\frac{\sin x}{x}\)를 두 함수 사이에 가두고 압축 정리를 씁니다.

풀이

  1. 먼저 \(0 < x < \frac{\pi}{2}\)라 하자. 단위원에서 중심각이 \(x\)인 부채꼴을 그리고, 점 \(A = (1, 0)\), \(P = (\cos x, \sin x)\), \(OP\)의 연장선이 직선 \(x = 1\)과 만나는 점 \(T = (1, \tan x)\)를 잡는다.
    \(x\)를 양수로 두면 길이와 넓이가 모두 양수라 부등식 다루기가 쉽다. 음수는 6단계에서 처리.
  2. 삼각형 \(OAP\) ⊂ 부채꼴 \(OAP\) ⊂ 삼각형 \(OAT\)이므로 넓이도 이 순서다.
    \[\tfrac{1}{2}\sin x \;<\; \tfrac{1}{2}x \;<\; \tfrac{1}{2}\tan x\] 삼각형 넓이 \(\frac12 \cdot \text{밑변 } 1 \cdot \text{높이}\), 부채꼴 넓이 \(\frac12 r^2\theta\) (\(r=1\)). 라디안을 쓰는 이유가 여기 있다: 도(°)로 재면 부채꼴 넓이가 \(\frac{\pi}{360}\theta\)가 되어 극한값이 \(\frac{\pi}{180}\)이 된다.
  3. 각 변에 \(\frac{2}{\sin x} > 0\)을 곱하면 \(1 < \dfrac{x}{\sin x} < \dfrac{1}{\cos x}\).
    \(0 0\)이므로 부등호 방향이 유지된다.
  4. 역수를 취하면 \(\cos x < \dfrac{\sin x}{x} < 1\).
    양수끼리는 역수를 취하면 부등호가 뒤집힌다.
  5. \(\lim_{x\to 0^+} \cos x = 1\)이고 \(\lim 1 = 1\)이므로, 압축 정리로 \(\lim_{x\to 0^+} \frac{\sin x}{x} = 1\).
    \(\cos\)의 연속성(\(\cos 0 = 1\))과 앞 카드의 압축 정리(한쪽 극한에도 똑같이 성립).
  6. \(\frac{\sin(-x)}{-x} = \frac{\sin x}{x}\)이므로 함수는 짝함수이고, 왼쪽 극한도 1이다. 따라서 \(\lim_{x\to 0}\frac{\sin x}{x} = 1\).
    \(\sin\)이 홀함수. 양쪽 극한이 같으면 극한이 존재한다.

검산

\(x = 0.1\)이면 \(\frac{\sin 0.1}{0.1} \approx 0.99833\), \(x = 0.01\)이면 \(\approx 0.99998\)입니다. 4단계의 아래 경계 \(\cos 0.1 \approx 0.99500\)보다 크고 1보다 작습니다. 부등식과 수치가 맞습니다.

바꿔 보기

  • \(\lim_{x\to 0}\frac{\sin 3x}{x}\): \(u = 3x\)로 두면 \(\frac{\sin 3x}{x} = 3\cdot\frac{\sin u}{u} \to 3\).
  • \(\lim_{x\to 0}\frac{1 - \cos x}{x^2}\): 분모·분자에 \(1 + \cos x\)를 곱하면 \(\frac{\sin^2 x}{x^2}\cdot\frac{1}{1+\cos x} \to 1 \cdot \frac12 = \frac12\).
  • \(\lim_{x\to\infty}\frac{\sin x}{x}\): 이번에는 \(-\frac{1}{x} \le \frac{\sin x}{x} \le \frac{1}{x}\)로 가두면 0입니다. 같은 식이라도 \(x\)가 어디로 가는지에 따라 쓰는 부등식이 다릅니다.
2.6

설명연속이란 무엇이고, 끊어지는 방식은 몇 가지인가?

연속 · 불연속의 분류

다루는 성취기준 [공통1-02-03]

왜 필요한가

"그래프를 펜을 떼지 않고 그릴 수 있다"는 연속의 직관입니다. 그러나 \(x\sin\frac{1}{x}\)처럼 0 근처에서 끝없이 출렁이는 그래프는 펜으로 그릴 수조차 없는데, 0에서 연속인지 판단해야 합니다. 또 중간값 정리, 최대·최소 정리 같은 중요한 정리들은 모두 "연속이면"을 가정합니다. 가정을 확인하려면 연속을 극한으로 정확히 정의해야 합니다.

정의 · 한 점에서의 연속

\(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있고 \(\lim_{x\to a} f(x) = f(a)\)이면, \(f\)는 \(a\)에서 연속이다.

ε-δ로 쓰면: 임의의 \(\varepsilon>0\)에 대해 어떤 \(\delta>0\)가 있어서 \(|x - a| < \delta \Rightarrow |f(x) - f(a)| < \varepsilon\).

정의를 풀어 읽기

  1. 세 조건이 숨어 있다① \(f(a)\)가 정의되어 있다. ② \(\lim_{x\to a} f(x)\)가 존재한다. ③ 둘이 같다. 셋 중 하나라도 깨지면 불연속입니다.
  2. 극한과 달리 \(0<\)이 없다극한의 정의는 \(0 < |x-a|\)로 \(x=a\)를 뺐지만, 연속에서는 \(x=a\)일 때 \(|f(a)-f(a)| = 0 < \varepsilon\)이 저절로 성립하므로 빼든 안 빼든 같습니다.
  3. "구간에서 연속"구간의 모든 점에서 연속이라는 뜻입니다. 닫힌구간 \([a,b]\)의 끝점에서는 한쪽 극한(\(x\to a^+\), \(x \to b^-\))으로 판정합니다.

불연속의 세 종류

  1. 제거 가능한 불연속\(\lim_{x\to a} f(x)\)는 존재하지만 \(f(a)\)와 다르거나 \(f(a)\)가 없음. 한 점의 값만 고치면 연속이 됩니다. 예: \(f(x) = \frac{x^2-1}{x-1}\)은 \(x=1\)에서 정의되지 않지만 극한은 2. \(f(1)=2\)로 정하면 연속.
  2. 도약 불연속왼쪽 극한과 오른쪽 극한이 각각 존재하지만 서로 다름. 예: 바닥 함수 \(\lfloor x \rfloor\)는 정수 \(n\)에서 왼쪽 극한 \(n-1\), 오른쪽 극한 \(n\). 한 점의 값을 고쳐서는 이을 수 없습니다.
  3. 본질적 불연속한쪽 극한 중 적어도 하나가 존재하지 않음(무한대로 가거나 진동). 예: \(\frac{1}{x}\)는 0에서 양쪽으로 무한대로 발산, \(\sin\frac{1}{x}\)는 0 근처에서 \(-1\)과 1 사이를 끝없이 진동.

분류 순서: 먼저 양쪽 극한을 각각 구합니다. 둘 다 있고 같으면 제거 가능(또는 연속), 둘 다 있고 다르면 도약, 하나라도 없으면 본질적입니다.

예와 반례

연속인 예. 다항함수, \(\sin\), \(\cos\), \(e^x\)는 실수 전체에서 연속입니다. 유리함수는 분모가 0이 아닌 모든 점에서 연속입니다.

뜻밖에 연속인 예. \(f(x) = x\sin\frac{1}{x}\ (x\ne0)\), \(f(0)=0\). 앞의 압축 정리 카드에서 \(\lim_{x\to0} x\sin\frac1x = 0\)을 보였으므로 0에서 연속입니다. 그래프를 펜으로 그릴 수는 없지만 정의는 만족합니다.

모든 점에서 불연속인 예. 디리클레 함수 \(D(x) = 1\) (\(x\) 유리수), \(0\) (\(x\) 무리수). 어느 점 근처에도 유리수와 무리수가 모두 있으므로 어디서도 극한이 없습니다.

다른 개념과의 관계

  • 연속 함수의 합·곱·몫·합성은 연속입니다(몫은 분모 ≠ 0). 극한 법칙에서 바로 나옵니다.
  • 미분 가능하면 연속이지만 거꾸로는 아닙니다. \(|x|\)는 0에서 연속이지만 미분 불가능합니다.
  • 해석학에서는 "모든 점에서 같은 δ를 쓸 수 있는가"를 묻는 균등연속으로 이어집니다.

흔한 오해

  • "\(\frac{1}{x}\)은 불연속 함수다." \(\frac{1}{x}\)의 정의역은 \(x \ne 0\)이고, 정의역의 모든 점에서 연속입니다. "0에서 불연속"이라고 할 때는 0이 정의역 밖이라는 점에 주의해야 합니다. 교재에 따라 이 경우를 불연속이라 부르지 않기도 합니다.
  • "그래프에 구멍이 없으면 연속." 구멍은 눈에 안 보일 수 있습니다(디리클레 함수). 정의로 확인해야 합니다.

확인분류해 보기

\(f(x) = \dfrac{|x|}{x}\ (x \ne 0)\), \(f(0) = 0\)은 \(x = 0\)에서 어떤 불연속인가?

2.7

증명중간값 정리: 이분법으로 근을 붙잡는다

연속 · 실수의 완비성

다루는 성취기준 [공통1-02-04]

정리 · 중간값 정리 (근의 존재 형태)

\(f\)가 닫힌구간 \([a, b]\)에서 연속이고 \(f(a) < 0 < f(b)\)이면, \(f(c) = 0\)인 \(c \in (a, b)\)가 존재한다.

일반형 "\(f(a)\)와 \(f(b)\) 사이의 모든 값 \(k\)에 대해 \(f(c)=k\)인 \(c\)가 있다"는 \(f(x) - k\)에 이 정리를 쓰면 됩니다.

쓰는 것

  • 실수의 완비성 (축소구간 성질): 닫힌구간이 \([a_1,b_1] \supset [a_2,b_2] \supset \cdots\)처럼 줄어들고 길이 \(b_n - a_n \to 0\)이면, 모든 구간에 공통으로 들어 있는 실수 \(c\)가 정확히 하나 있고 \(a_n \to c\), \(b_n \to c\)이다. 유리수에서는 성립하지 않는 실수만의 성질이다(예: \(\sqrt{2}\)로 줄어드는 유리수 구간).
  • 연속의 수열 성질: \(f\)가 \(c\)에서 연속이고 \(x_n \to c\)이면 \(f(x_n) \to f(c)\).
  • 극한과 부등식: 모든 \(n\)에서 \(u_n \le 0\)이고 \(u_n \to u\)이면 \(u \le 0\).

아이디어

구간을 반으로 자르고, 부호가 바뀌는 쪽 절반을 남깁니다. 이 일을 끝없이 되풀이하면 구간이 한 점 \(c\)로 줄어듭니다. 남긴 구간들은 늘 "왼쪽 끝에서 음수, 오른쪽 끝에서 양수"이므로, 극한을 취하면 \(f(c) \le 0\)이면서 \(f(c) \ge 0\)이 되어 \(f(c) = 0\)입니다. 이 증명은 근을 실제로 계산하는 이분법 알고리즘과 같습니다.

그림만으로는 "곡선이 축을 건너려면 한 번은 만나야 한다"가 당연해 보입니다. 그러나 수직선에 \(\sqrt{2}\) 같은 구멍이 있다면(유리수만 있다면) 곡선이 구멍으로 빠져나갈 수 있습니다. 그 구멍이 없다는 보증이 완비성이고, 이 증명의 핵심입니다.

증명

  1. \(a_1 = a\), \(b_1 = b\)로 둔다. \(f(a_1) < 0 < f(b_1)\)이다.
    가정.
  2. \([a_n, b_n]\)이 \(f(a_n) \le 0 \le f(b_n)\)을 만족한다고 하자. 가운데 \(m_n = \frac{a_n + b_n}{2}\)에서 \(f(m_n) = 0\)이면 \(c = m_n\)으로 끝난다. \(f(m_n) < 0\)이면 \([a_{n+1}, b_{n+1}] = [m_n, b_n]\), \(f(m_n) > 0\)이면 \([a_n, m_n]\)으로 정한다.
    세 경우가 모든 가능성을 나눈다. 어느 쪽을 골라도 새 구간은 \(f(a_{n+1}) \le 0 \le f(b_{n+1})\)을 만족한다.
  3. 이렇게 만든 구간들은 \([a_1,b_1] \supset [a_2,b_2] \supset \cdots\)이고 길이는 \(b_n - a_n = \frac{b-a}{2^{n-1}} \to 0\)이다.
    매번 반을 고르므로 포함 관계가 성립하고 길이가 절반씩 준다.
  4. 축소구간 성질로, 모든 구간에 들어 있는 \(c\)가 있고 \(a_n \to c\), \(b_n \to c\)이다. \(a \le c \le b\)이다.
    실수의 완비성. 여기가 실수여야 하는 유일한 곳이다.
  5. \(f\)는 \(c\)에서 연속이므로 \(f(a_n) \to f(c)\)이고 \(f(b_n) \to f(c)\)이다.
    연속의 수열 성질. \(c\)가 끝점이면 한쪽 연속으로 충분하다.
  6. 모든 \(n\)에서 \(f(a_n) \le 0\)이므로 \(f(c) \le 0\), 모든 \(n\)에서 \(f(b_n) \ge 0\)이므로 \(f(c) \ge 0\)이다.
    극한은 부등식(≤, ≥)을 보존한다. 엄격한 부등식(<)은 보존되지 않으므로 2단계에서 ≤로 적었다.
  7. 따라서 \(f(c) = 0\). \(f(a) < 0\), \(f(b) > 0\)이므로 \(c \ne a, b\), 곧 \(c \in (a,b)\)이다.
    6단계의 두 부등식, 그리고 가정의 엄격한 부등식.

되짚기

  • 연속을 쓴 곳: 5단계 하나뿐입니다. 연속이 아니면 깨집니다. 예: \(f(x) = -1\ (x < 0)\), \(f(x) = 1\ (x \ge 0)\)은 \([-1, 1]\)에서 부호가 바뀌지만 0이 되는 점이 없습니다.
  • 완비성을 쓴 곳: 4단계. 유리수에서 \(f(x) = x^2 - 2\)는 \([1, 2]\)에서 부호가 바뀌지만 유리수 근이 없습니다.
  • 닫힌구간: 끝점에서의 값 \(f(a), f(b)\)를 써야 하므로 끝점에서 정의되고 연속이어야 합니다.

쓰는 법 (성취기준 [공통1-02-04])

\(x^5 - 3x + 1 = 0\)이 \((0, 1)\)에서 실근을 가짐을 보이세요.

  1. \(f(x) = x^5 - 3x + 1\)은 다항함수이므로 \([0, 1]\)에서 연속이다.
    다항함수는 실수 전체에서 연속. 연속이라는 가정을 반드시 먼저 확인해서 적는다.
  2. \(f(0) = 1 > 0\), \(f(1) = 1 - 3 + 1 = -1 < 0\).
    부호가 다른 두 점. 정리의 부호 방향은 \(-f\)를 쓰면 바뀌므로 상관없다.
  3. 중간값 정리에 의해 \(f(c) = 0\)인 \(c \in (0, 1)\)이 존재한다.
    정리의 이름을 적고 결론을 쓴다. 근의 값은 모르지만 존재는 보장된다. 값이 필요하면 이분법으로 원하는 만큼 좁힌다: \(f(0.5) \approx -0.47\)이므로 근은 \((0, 0.5)\)에 있다.
2.8

연습극한과 연속 연습 문제

문제 6 · 힌트 2단계 · 풀이

다루는 성취기준 [공통1-02-01] [공통1-02-02] [공통1-02-03] [공통1-02-04] [공통1-02-05]

먼저 혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 풀이는 시험 답안으로 그대로 낼 수 있는 수준으로 썼습니다. 마지막 두 문제를 풀 수 있으면 이 단원의 성취기준을 확인한 것입니다.

  1. \(\lim_{x\to 1} (2x + 3) = 5\)를 ε-δ로 증명하세요. [02-01]

    힌트 1

    \(|(2x+3) - 5|\)를 \(|x - 1|\)로 나타내 보세요.

    힌트 2

    \(|2x - 2| = 2|x-1|\). 이것이 \(\varepsilon\)보다 작으려면 \(|x-1|\)이 얼마보다 작아야 할까요?

    풀이

    \(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \frac{\varepsilon}{2}\)로 둔다. \(0 < |x - 1| < \delta\)이면

    \[|(2x + 3) - 5| = 2|x - 1| < 2\cdot\tfrac{\varepsilon}{2} = \varepsilon.\]

    \(\varepsilon\)이 임의였으므로 \(\lim_{x\to1}(2x+3) = 5\). ∎ (일차함수는 곤란한 인수가 없어 min이 필요 없습니다.)

  2. \(\lim_{x\to 4} \sqrt{x} = 2\)를 ε-δ로 증명하세요. [02-01]

    힌트 1

    \(\sqrt{x} - 2\)에 \(\frac{\sqrt{x}+2}{\sqrt{x}+2}\)를 곱하면 분자가 \(x - 4\)가 됩니다.

    힌트 2

    분모 \(\sqrt{x} + 2\)는 언제나 2 이상입니다. 다만 \(\sqrt{x}\)가 정의되려면 \(x \ge 0\)이어야 하므로 \(\delta \le 4\)로 제한하세요.

    풀이

    \(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\{4, 2\varepsilon\}\)로 둔다. \(0 < |x - 4| < \delta\)이면 \(|x-4|<4\)이므로 \(x > 0\)이고 \(\sqrt{x}\)가 정의된다. 또

    \[|\sqrt{x} - 2| = \frac{|x - 4|}{\sqrt{x} + 2} \le \frac{|x-4|}{2} < \frac{2\varepsilon}{2} = \varepsilon.\]

    첫 등식은 유리화, 부등식은 \(\sqrt{x} + 2 \ge 2\). 따라서 \(\lim_{x\to4}\sqrt{x} = 2\). ∎

  3. \(\lim_{x\to 0} x^2 \cos\dfrac{1}{x}\)를 구하고 근거를 쓰세요. [02-02]

    힌트 1

    \(\cos\frac1x\)는 극한이 없지만 \(-1\)과 1 사이에 있습니다.

    힌트 2

    \(-x^2 \le x^2\cos\frac1x \le x^2\)에 압축 정리를 쓰세요.

    풀이

    \(x \ne 0\)이면 \(-1 \le \cos\frac1x \le 1\)이고 \(x^2 > 0\)이므로 \(-x^2 \le x^2\cos\frac1x \le x^2\)이다. \(\lim_{x\to0}(-x^2) = \lim_{x\to0} x^2 = 0\)이므로 압축 정리에 의해 \(\lim_{x\to0} x^2\cos\frac1x = 0\).

    곱의 극한 법칙 \(\lim x^2 \cdot \lim\cos\frac1x\)는 쓸 수 없습니다. 뒤의 극한이 존재하지 않기 때문입니다.

  4. \(f(x) = \dfrac{x^2 - x - 2}{x^2 - 4}\)의 불연속점을 모두 찾고 종류를 분류하세요. 수직 점근선도 구하세요. [02-03, 02-05]

    힌트 1

    분모가 0인 점이 후보입니다. 분자와 분모를 인수분해하세요.

    힌트 2

    \(f(x) = \frac{(x-2)(x+1)}{(x-2)(x+2)}\). 약분 후 각 점에서 양쪽 극한을 구하세요.

    풀이

    \(f\)는 유리함수이므로 분모 \(x^2 - 4 \ne 0\)인 모든 점에서 연속이다. 후보는 \(x = 2, -2\)다. \(x \ne \pm 2\)이면 \(f(x) = \frac{x+1}{x+2}\).

    \(x = 2\): \(\lim_{x\to2} f(x) = \frac{3}{4}\)로 존재하지만 \(f(2)\)가 정의되지 않는다. 제거 가능한 불연속이다(\(f(2) = \frac34\)로 정하면 연속).

    \(x = -2\): 분자 \(x + 1 \to -1\), 분모 \(x + 2 \to 0\). \(x \to -2^+\)이면 분모가 양수로 0에 가까워지므로 \(f(x) \to -\infty\), \(x\to-2^-\)이면 \(+\infty\). 한쪽 극한이 존재하지 않으므로 본질적 불연속이고, 직선 \(x = -2\)가 수직 점근선이다.

    \(x=2\)는 점근선이 아닙니다. 그래프에 구멍이 하나 있을 뿐입니다.

  5. 방정식 \(\cos x = x\)가 \(\left(0, \frac{\pi}{2}\right)\)에서 해를 가짐을 보이세요. [02-04]

    힌트 1

    한 함수로 모으세요: \(g(x) = \cos x - x\).

    힌트 2

    \(g(0)\)과 \(g\!\left(\frac{\pi}{2}\right)\)의 부호를 보고, 연속인지 먼저 확인하세요.

    풀이

    \(g(x) = \cos x - x\)로 두면 \(g\)는 연속함수의 차이므로 \(\left[0, \frac\pi2\right]\)에서 연속이다. \(g(0) = 1 > 0\), \(g\!\left(\frac\pi2\right) = -\frac\pi2 < 0\). 중간값 정리에 의해 \(g(c) = 0\), 곧 \(\cos c = c\)인 \(c \in \left(0, \frac\pi2\right)\)가 존재한다. ∎

    이분법으로 계속 좁히면 \(c \approx 0.739\)입니다.

  6. \(f(x) = \dfrac{2x^2 + 3x}{x - 1}\)의 모든 점근선을 구하고, 점근선 근처에서 그래프가 어느 쪽에 있는지 설명하세요. [02-05]

    힌트 1

    분자의 차수가 분모보다 1 크면 수평 점근선 대신 비스듬한 점근선이 있습니다. 다항식 나눗셈을 하세요.

    힌트 2

    \(2x^2 + 3x = (x - 1)(2x + 5) + 5\).

    풀이

    나눗셈으로 \(f(x) = 2x + 5 + \frac{5}{x-1}\).

    수직 점근선 \(x = 1\): \(x \to 1^+\)이면 \(\frac{5}{x-1} \to +\infty\)이므로 \(f(x) \to +\infty\), \(x \to 1^-\)이면 \(-\infty\).

    비스듬한 점근선 \(y = 2x + 5\): \(f(x) - (2x+5) = \frac{5}{x-1} \to 0\ (x \to \pm\infty)\). 그래프는 \(x \to +\infty\)에서 점근선의 위쪽(차이가 양수), \(x \to -\infty\)에서 아래쪽에서 다가간다.

    수평 점근선은 없다. \(f(x) \to \pm\infty\ (x\to\pm\infty)\)이기 때문이다.
