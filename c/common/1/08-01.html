8.1.1수열의 극한

수열 \(a_n = \frac{n}{n + 1}\)은 \(\frac12, \frac23, \frac34, \dots\)로 1에 다가갑니다. \(a_n = (-1)^n\)은 \(-1\)과 1을 오가며 어디에도 다가가지 않습니다. \(n\)이 커질 때 \(a_n\)이 한 값 \(L\)에 한없이 가까워지면 \(\lim_{n\to\infty}a_n = L\)이라 쓰고 수열이 수렴한다고 합니다. 그렇지 않으면 발산합니다.

정확히는 함수의 극한(2.5절의 \(x \to \infty\))과 같은 방식입니다: 임의의 \(\varepsilon > 0\)에 대해 \(n > N\)이면 \(|a_n - L| < \varepsilon\)이 되는 \(N\)이 있다.

정리 8.1.1

\(\lim_{x\to\infty}f(x) = L\)이고 \(a_n = f(n)\)이면 \(\lim_{n\to\infty}a_n = L\)이다.

그래서 수열의 극한을 함수의 극한으로 바꾸어 로피탈 법칙 같은 도구를 쓸 수 있습니다. 극한의 합·곱·몫 법칙과 압축 정리도 수열에서 그대로 성립합니다.

예제 8.1.2

(가) \(\lim\dfrac{\ln n}{n}\) (나) \(\lim\dfrac{(-1)^n}{n}\) (다) \(\lim r^n\)

풀이. (가) \(f(x) = \frac{\ln x}{x}\)에 로피탈 법칙: \(\frac{1/x}{1} \to 0\). 따라서 0.

(나) \(-\frac1n \le \frac{(-1)^n}{n} \le \frac1n\)이고 양쪽이 0으로 가므로 압축 정리로 0.

(다) \(|r| < 1\)이면 0, \(r = 1\)이면 1, \(r > 1\)이면 발산, \(r \le -1\)이면 발산(진동). 이 결과는 다음 절의 등비급수에서 핵심입니다.

8.1.2단조이고 유계인 수열

일반항을 직접 계산할 수 없는 수열도 있습니다. 예를 들어 \(a_1 = \sqrt2\), \(a_{n+1} = \sqrt{2 + a_n}\)으로 정한 수열입니다. 이런 수열의 수렴은 다음 정리로 보입니다.

정리 8.1.3 (단조 수렴 정리)

증가하고(\(a_n \le a_{n+1}\)) 위로 유계인(모든 \(n\)에 대해 \(a_n \le M\)) 수열은 수렴한다. 감소하고 아래로 유계인 수열도 수렴한다.

계속 올라가지만 천장 \(M\)을 넘지 못하면 어떤 값에 다가갈 수밖에 없다는 뜻입니다. 이 정리는 실수에 "빈틈이 없다"는 성질(완비성)에 기대고 있으며, 그 이야기는 1.1절의 보충 본문에 있습니다.

예제 8.1.4

\(a_1 = \sqrt2\), \(a_{n+1} = \sqrt{2 + a_n}\)이 수렴함을 보이고 극한을 구하여라.

풀이. 먼저 위로 유계(\(a_n < 2\))임을 귀납법으로 보입니다. \(a_1 = \sqrt2 < 2\)이고, \(a_n < 2\)이면 \(a_{n+1} = \sqrt{2 + a_n} < \sqrt4 = 2\).

다음으로 증가함을 보입니다. \(0 < a_n < 2\)이면 \(a_{n+1}^2 - a_n^2 = 2 + a_n - a_n^2 = (2 - a_n)(1 + a_n) > 0\)이므로 \(a_{n+1} > a_n\).

단조 수렴 정리로 수렴합니다. 극한을 \(L\)이라 하면 점화식 양변의 극한에서 \(L = \sqrt{2 + L}\), 곧 \(L^2 - L - 2 = 0\), \(L = 2\) (\(L > 0\)). 수열은 \(\sqrt2 \approx 1.414\), \(1.848\), \(1.962\), \(1.990, \dots\)로 2에 다가갑니다.

주의수렴한다는 것을 보이기 전에 "\(L = \sqrt{2 + L}\)"로 극한을 구하면 안 됩니다. 발산하는 수열에 같은 계산을 하면 엉뚱한 값이 나옵니다. 예: \(a_{n+1} = 2a_n\), \(a_1 = 1\)이면 \(L = 2L\)에서 \(L = 0\)이지만 실제로는 발산합니다.
요약
  1. \(a_n = f(n)\)이면 \(\lim f(x)\)로 계산한다. 극한 법칙과 압축 정리가 성립한다.
  2. \(r^n \to 0\) (\(|r| < 1\)).
  3. 증가 + 위로 유계 ⇒ 수렴. 점화식 수열은 유계·단조를 귀납법으로 보인 뒤 극한을 구한다.

8.1.3연습문제

기본

  1. 극한을 구하여라. (가) \(\frac{3n^2 + 1}{n^2 - n}\) (나) \(\frac{n}{e^n}\) (다) \(\left(1 + \frac2n\right)^n\)
    답

    (가) 3 (나) 0 (다) \(e^2\) (3.3절)

응용

  1. \(a_1 = 1\), \(a_{n+1} = \frac{a_n + 6}{2}\)이 수렴함을 보이고 극한을 구하여라.
    답

    귀납법으로 \(a_n < 6\)이고 \(a_{n+1} - a_n = \frac{6 - a_n}{2} > 0\). 증가하고 유계이므로 수렴. \(L = \frac{L + 6}{2}\)에서 \(L = 6\).

이 절의 성취기준[공통1-08-01] 계산

  1. 수열의 극한을 구하고 단조이고 유계인 수열이 수렴함을 쓸 수 있다.

8.1.2

증명단조 수렴 정리: 극한값을 몰라도 수렴을 보이는 법

유계 · 단조 · 완비성

다루는 성취기준 [공통1-08-01]

왜 필요한가

수렴의 정의(\(|a_n - L| < \varepsilon\))를 쓰려면 극한 \(L\)을 먼저 알아야 합니다. 그런데 \(a_{n+1} = \sqrt{2 + a_n}\) 같은 점화식이나 \(\left(1 + \frac1n\right)^n\)은 극한을 모르는 상태에서 수렴부터 보여야 합니다. 단조 수렴 정리가 그 도구입니다.

정리 · 단조 수렴 정리

위로 유계인 증가수열은 수렴하고, 극한은 \(\sup\{a_n\}\)이다. 아래로 유계인 감소수열도 수렴한다.

쓰는 것

  • 완비성 공리 (1단원): 위로 유계인 공집합 아닌 실수 집합은 상한을 갖는다.
  • 상한의 ε 판정: \(s = \sup A\)이면 모든 \(\varepsilon > 0\)에 대해 \(a > s - \varepsilon\)인 \(a \in A\)가 있다.

증명

  1. \(A = \{a_n : n \in \mathbb N\}\)은 공집합이 아니고 위로 유계이므로 \(s = \sup A\)가 존재한다.
    완비성 공리. 유리수만으로는 이 단계가 실패한다(아래 참고).
  2. \(\varepsilon > 0\)이 주어지면, ε 판정으로 \(a_N > s - \varepsilon\)인 \(N\)이 있다.
    \(s - \varepsilon\)은 \(s\)보다 작으므로 상계가 아니다.
  3. \(n \ge N\)이면 \(a_n \ge a_N > s - \varepsilon\).
    증가수열.
  4. 또 \(a_n \le s < s + \varepsilon\).
    \(s\)는 상계.
  5. 따라서 \(n \ge N\)이면 \(|a_n - s| < \varepsilon\), 곧 \(a_n \to s\).
    수렴의 정의.

되짚기: 유리수에서는 성립하지 않습니다. \(3, 3.1, 3.14, 3.141, \dots\) (\(\pi\)의 소수 전개)는 유리수의 증가수열이고 4로 유계이지만, 극한 \(\pi\)가 유리수가 아닙니다. 이 정리는 "실수에는 구멍이 없다"는 완비성의 다른 얼굴입니다.

쓰는 법 (성취기준 [공통1-08-01])

\(a_1 = \sqrt2\), \(a_{n+1} = \sqrt{2 + a_n}\)이 수렴함을 보이고 극한을 구하세요.

  1. 유계: 모든 \(n\)에 대해 \(0 < a_n < 2\). (귀납법) \(a_1 = \sqrt2 < 2\). \(a_n < 2\)이면 \(a_{n+1} = \sqrt{2 + a_n} < \sqrt4 = 2\).
    상계 후보 2는 극한을 미리 짐작해서 골랐다(고정점 \(L = \sqrt{2 + L}\)).
  2. 증가: \(a_{n+1}^2 - a_n^2 = 2 + a_n - a_n^2 = (2 - a_n)(1 + a_n) > 0\).
    1단계의 \(0 < a_n < 2\)를 썼다. 양수끼리라 제곱의 대소가 원래 대소와 같다.
  3. 단조 수렴 정리로 \(a_n \to L\)이 존재한다.
    위로 유계인 증가수열.
  4. 점화식의 양변에 극한: \(L = \sqrt{2 + L}\), \(L^2 - L - 2 = 0\), \(L = 2\) 또는 \(-1\). \(a_n > 0\)이므로 \(L \ge 0\), 따라서 \(L = 2\).
    \(a_{n+1} \to L\)도 성립(같은 수열을 한 칸 민 것)하고, \(\sqrt{\ }\)이 연속이라 극한과 바꿀 수 있다.

흔한 오해

  • 수렴을 보이기 전에 극한을 대입하기: \(a_{n+1} = 2a_n\), \(a_1 = 1\)에 바로 \(L = 2L\)을 쓰면 \(L = 0\)이 나오지만, 수열은 \(2^{n-1} \to \infty\)입니다. 3단계(존재)가 4단계보다 먼저입니다.
  • "유계이면 수렴." \((-1)^n\)은 유계지만 발산합니다. 단조성이 함께 필요합니다.
