1.3.1"한없이 가까워진다"는 무슨 뜻인가

고등학교에서는 "\(x\)가 \(a\)에 한없이 가까워질 때 \(f(x)\)가 \(L\)에 한없이 가까워지면 \(\lim_{x\to a}f(x) = L\)"이라고 배웠습니다. 계산에는 이것으로 충분했지만, 이 문장은 몇 가지 질문에 답하지 못합니다.

  • "한없이 가깝다"는 얼마나 가까운 것인가? 0.001이면 충분한가?
  • \(f(x) = x\sin\frac1x\)처럼 0 근처에서 끝없이 출렁이는 함수는 0에 "가까워지는" 것인가?
  • 극한 법칙("극한의 합은 합의 극한")은 왜 성립하는가? 직관만으로는 증명할 수 없다.

19세기 수학자들(코시, 바이어슈트라스)은 "가까움"을 오차의 크기로 바꾸어 이 문제를 풀었습니다. 핵심 생각은 도전과 응답입니다. 누군가 "\(f(x)\)와 \(L\)의 차이를 0.01보다 작게 해 봐"라고 요구하면, 우리는 "\(x\)를 \(a\)에서 0.003 이내로만 잡으면 된다"고 답할 수 있어야 합니다. 요구가 0.0001로 더 까다로워져도 답할 수 있어야 하고, 어떤 양수를 요구해도 답할 수 있으면 그때 극한이 \(L\)이라고 말합니다.

예를 들어 \(f(x) = 2x + 1\)이 \(x \to 3\)일 때 7로 간다는 것을 이 방식으로 확인해 봅시다. \(|f(x) - 7| = |2x - 6| = 2|x - 3|\)입니다. 차이를 0.01보다 작게 하라는 요구에는 \(|x - 3| < 0.005\)라고 답하면 됩니다. 그러면 \(2|x - 3| < 0.01\)이니까요. 일반적으로 요구가 \(\varepsilon\)이면 답은 \(\frac\varepsilon2\)입니다.

1.3.2ε-δ 정의

정의 1.3.1 (함수의 극한)

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 (\(a\) 자신은 빼도 된다) 정의되어 있다고 하자. 임의의 \(\varepsilon > 0\)에 대하여 어떤 \(\delta > 0\)이 있어서

\[0 < |x - a| < \delta \ \Longrightarrow\ |f(x) - L| < \varepsilon\]

이 성립하면 \(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한이 \(L\)이라 하고 \(\lim_{x\to a}f(x) = L\)로 쓴다.

정의를 구절 단위로 끊어 읽습니다.

  • "임의의 \(\varepsilon > 0\)에 대하여": 상대가 허용 오차 \(\varepsilon\)을 마음대로 정합니다. 아주 작게 정할 수도 있습니다. \(\varepsilon\)은 \(f(x)\) 쪽, 곧 세로축의 오차입니다.
  • "어떤 \(\delta > 0\)이 있어서": 우리가 그 \(\varepsilon\)에 맞추어 \(x\)의 허용 범위 \(\delta\)를 고릅니다. \(\delta\)는 \(x\) 쪽, 곧 가로축의 범위입니다. \(\delta\)는 \(\varepsilon\)에 따라 달라져도 됩니다. 보통 \(\varepsilon\)이 작아지면 \(\delta\)도 작아져야 합니다.
  • "\(0 < |x - a|\)": \(x = a\)는 제외합니다. 극한은 \(a\) 근처의 행동만 보고, \(a\)에서의 값 \(f(a)\)는 상관하지 않습니다. \(f(a)\)가 정의되지 않아도, 엉뚱한 값이어도 극한은 있을 수 있습니다.
  • "\(|x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon\)": \(a\)에서 거리 \(\delta\) 이내의 모든 \(x\)(단 \(a\) 제외)에 대해 \(f(x)\)가 \(L\)에서 거리 \(\varepsilon\) 이내에 있어야 합니다. 몇몇 \(x\)만 들어오는 것으로는 부족합니다.

그림으로 보면, 높이가 \(L - \varepsilon\)부터 \(L + \varepsilon\)까지인 가로 띠를 상대가 그리면, 우리는 폭이 \(a - \delta\)부터 \(a + \delta\)까지인 세로 띠를 골라 그 안의 그래프가 (점 \(x = a\)를 빼고) 모두 가로 띠 안에 들어가게 해야 합니다. 이 절 뒤의 탐구 카드에서 직접 띠를 움직여 볼 수 있습니다.

\(\varepsilon\)과 \(\delta\)라는 그리스 문자는 관습입니다. \(\varepsilon\)은 "오차(error)"의 e, \(\delta\)는 "차이(difference)"의 d에서 왔다고들 합니다.

1.3.3정의로 증명하기: 초안과 증명

정의로 극한을 증명하는 일은 언제나 두 단계입니다. 교과서에는 보통 두 번째 단계만 실려 있어서, 처음 보면 "\(\delta = \frac\varepsilon5\)는 어디서 나왔나" 하고 당황하게 됩니다. 첫 단계를 숨기지 않고 보이겠습니다.

  1. 초안(연습장에 쓰는 것): 목표 \(|f(x) - L| < \varepsilon\)에서 출발해 식을 \(|x - a|\)의 식으로 바꾸고, 어떤 \(\delta\)를 잡으면 될지 거꾸로 찾는다.
  2. 증명(답안에 쓰는 것): 찾은 \(\delta\)를 먼저 제시하고, \(0 < |x - a| < \delta\)에서 출발해 \(|f(x) - L| < \varepsilon\)에 도착하는 순서로 쓴다.
예제 1.3.2

\(\lim_{x\to2}(5x - 3) = 7\)을 ε-δ 정의로 증명하여라.

초안. \(|f(x) - 7| = |5x - 10| = 5|x - 2|\)입니다. 이것이 \(\varepsilon\)보다 작으려면 \(|x - 2| < \frac\varepsilon5\)이면 됩니다. 그러니 \(\delta = \frac\varepsilon5\)로 잡습니다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \frac\varepsilon5\)로 놓는다. \(0 < |x - 2| < \delta\)이면 \(|(5x - 3) - 7| = 5|x - 2| < 5\delta = \varepsilon\)이다. 따라서 정의에 의해 \(\lim_{x\to2}(5x - 3) = 7\)이다. ∎

일차함수 \(mx + b\)이면 언제나 \(\delta = \frac{\varepsilon}{|m|}\)이 통합니다(\(m \ne 0\)). 기울기가 가파를수록 \(x\)를 더 좁게 잡아야 한다는 뜻입니다.

예제 1.3.3

\(\lim_{x\to3}x^2 = 9\)를 ε-δ 정의로 증명하여라.

초안. \(|x^2 - 9| = |x - 3|\cdot|x + 3|\)입니다. 일차함수와 달리 \(|x - 3|\)에 곱해진 \(|x + 3|\)이 \(x\)에 따라 변해서, 상수로 나눌 수 없습니다. 요령은 1.1절의 예제 1.2.5와 같습니다. 먼저 \(x\)를 3 근처로 제한해 \(|x + 3|\)을 상수로 막습니다.

\(\delta \le 1\)로 정하기로 하면 \(|x - 3| < 1\), 곧 \(2 < x < 4\)이므로 \(5 < x + 3 < 7\), \(|x + 3| < 7\)입니다. 그러면 \(|x^2 - 9| < 7|x - 3|\)이고, 이것이 \(\varepsilon\)보다 작으려면 \(|x - 3| < \frac\varepsilon7\)이면 됩니다. 두 조건(\(\delta \le 1\)과 \(\delta \le \frac\varepsilon7\))을 동시에 만족하도록 \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 잡습니다. \(\min\)은 둘 중 작은 쪽입니다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\left(1, \frac\varepsilon7\right)\)로 놓는다. \(0 < |x - 3| < \delta\)라 하자. \(\delta \le 1\)이므로 \(2 < x < 4\)이고 \(|x + 3| < 7\)이다. 또 \(\delta \le \frac\varepsilon7\)이므로 \(|x^2 - 9| = |x - 3||x + 3| < \frac\varepsilon7\cdot7 = \varepsilon\)이다. ∎

왜 \(\delta \le 1\)이었을까요? 1은 아무 양수나 써도 됩니다. \(\delta \le \frac12\)로 정했다면 \(|x + 3| < 6.5\)가 되어 \(\delta = \min\left(\frac12, \frac{\varepsilon}{6.5}\right)\)을 잡으면 됩니다. 중요한 것은 "먼저 \(x\)를 가둬 곱해지는 인수를 상수로 막는다"는 방법입니다. 이 방법은 다항함수, 유리함수 모두에 통합니다.

예제 1.3.4

\(\lim_{x\to2}\frac1x = \frac12\)을 증명하여라.

초안. \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2|x|}\)입니다. 이번에는 \(\frac{1}{|x|}\)을 위에서 막아야 하는데, 이는 \(|x|\)를 아래에서 막는 것과 같습니다. \(\delta \le 1\)이면 \(1 < x < 3\)이라 \(|x| > 1\), 따라서 \(\frac{|x - 2|}{2|x|} < \frac{|x - 2|}{2}\)입니다. 이것이 \(\varepsilon\) 미만이려면 \(|x - 2| < 2\varepsilon\). 그래서 \(\delta = \min(1, 2\varepsilon)\).

증명.\(\varepsilon > 0\)에 대해 \(\delta = \min(1, 2\varepsilon)\)으로 놓는다. \(0 < |x - 2| < \delta\)이면 \(x > 1\)이므로 \(\left|\frac1x - \frac12\right| = \frac{|x - 2|}{2x} < \frac{|x - 2|}{2} < \frac{2\varepsilon}{2} = \varepsilon\)이다. ∎

\(\delta \le 1\)이라는 제한이 여기서는 더 중요합니다. 제한이 없으면 \(x\)가 0에 가까워질 수 있고, 그러면 \(\frac1x\)이 폭발해서 어떤 상수로도 막을 수 없습니다.

1.3.4극한이 존재하지 않음을 보이기

정의의 부정을 정확히 써 봅시다. "모든 \(\varepsilon\)에 대해 어떤 \(\delta\)가 있어서 …"의 부정은 "어떤 \(\varepsilon\)에 대해서는 모든 \(\delta\)가 실패한다"입니다. 곧 \(\lim_{x\to a}f(x) \ne L\)은

어떤 \(\varepsilon > 0\)이 있어서, 모든 \(\delta > 0\)에 대해 \(0 < |x - a| < \delta\)이면서 \(|f(x) - L| \ge \varepsilon\)인 \(x\)가 있다

는 뜻입니다. 상대가 너무 작은 띠를 그려서, 우리가 세로 띠를 아무리 좁혀도 띠를 벗어나는 점이 남는 상황입니다.

예제 1.3.5

\(H(x) = 0\) (\(x < 0\)), \(H(x) = 1\) (\(x \ge 0\))일 때 \(\lim_{x\to0}H(x)\)가 존재하지 않음을 보여라.

풀이. 어떤 \(L\)이 극한이라고 가정하고 모순을 보입니다. \(\varepsilon = \frac12\)을 잡습니다. 어떤 \(\delta > 0\)이든, 구간 \((-\delta, \delta)\)에는 \(x_1 = -\frac\delta2\)(\(H = 0\))과 \(x_2 = \frac\delta2\)(\(H = 1\))이 모두 있습니다. 두 점에서 모두 \(|H(x) - L| < \frac12\)이려면 \(|0 - L| < \frac12\)이고 \(|1 - L| < \frac12\)이어야 하는데, 삼각부등식으로 \(1 = |1 - 0| \le |1 - L| + |L - 0| < 1\)이 되어 모순입니다. 따라서 어떤 \(L\)도 극한이 아닙니다.

이 함수는 오른쪽에서 1, 왼쪽에서 0으로 다가갑니다. 정의 1.3.1에서 \(x > a\)인 점만 보면 오른쪽 극한 \(\lim_{x\to a^+}\), \(x < a\)인 점만 보면 왼쪽 극한 \(\lim_{x\to a^-}\)이 됩니다. 극한이 존재하는 것은 두 한쪽 극한이 모두 존재하고 같을 때뿐입니다(연습문제 6).

1.3.5극한은 하나뿐이다

정의가 생겼으니 직관으로는 당연하던 것을 증명할 수 있습니다. 첫 번째로, 극한값이 둘일 수 없다는 것입니다.

정리 1.3.6 (극한의 유일성)

\(\lim_{x\to a}f(x) = L\)이고 \(\lim_{x\to a}f(x) = M\)이면 \(L = M\)이다.

증명.\(L \ne M\)이라 가정하고 \(\varepsilon = \frac{|L - M|}{2} > 0\)을 잡는다. 극한이 \(L\)이므로 \(0 < |x - a| < \delta_1\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1\)이 있고, 극한이 \(M\)이므로 같은 방식의 \(\delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 잡고 \(0 < |x - a| < \delta\)인 \(x\)를 하나 고르면, 두 부등식이 모두 성립하므로 삼각부등식에서 \(|L - M| \le |L - f(x)| + |f(x) - M| < 2\varepsilon = |L - M|\)이 되어 모순이다. 따라서 \(L = M\). ∎

"두 조건의 \(\delta\) 가운데 작은 쪽을 잡는다"는 기법은 극한 법칙의 증명(1.3절)에서도 그대로 쓰입니다.

주의\(\delta\)를 \(x\)의 식으로 잡으면 안 됩니다. 예를 들어 예제 1.3.3에서 "\(\delta = \frac{\varepsilon}{|x + 3|}\)"이라고 쓰면, \(\delta\)를 정하기 전에 \(x\)를 이미 안다는 뜻이 되어 순서가 뒤집힙니다. \(\delta\)는 \(\varepsilon\)(과 \(a\))만으로 정해야 합니다. 그래서 \(x\)를 먼저 가두어 \(|x + 3|\)을 상수로 바꾸는 단계가 필요한 것입니다.
요약
  1. \(\lim_{x\to a}f(x) = L\): 임의의 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어서 \(0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon\).
  2. 증명은 초안(\(\delta\) 찾기)과 증명(\(\delta\) 제시 후 확인) 두 단계로 한다.
  3. 곱해지는 인수가 \(x\)에 따라 변하면 \(\delta \le 1\) 같은 제한으로 먼저 가둔다. \(\delta = \min(1, \dots)\).
  4. 극한이 없음: 어떤 \(\varepsilon\)에 대해 모든 \(\delta\)가 실패함을 보인다.
  5. 극한은 하나뿐이다. 한쪽 극한이 다르면 극한은 없다.

1.3.6연습문제

기본

  1. \(\lim_{x\to-1}(4 - 3x) = 7\)을 ε-δ 정의로 증명하여라.
    답

    \(|4 - 3x - 7| = 3|x + 1|\). \(\delta = \frac\varepsilon3\)이면 \(0 < |x + 1| < \delta\)에서 \(3|x + 1| < \varepsilon\).

  2. \(\lim_{x\to5}(2x + 1) = 11\)에서 \(\varepsilon = 0.01\)일 때 쓸 수 있는 \(\delta\)를 하나 구하여라. 그보다 큰 \(\delta\)도 되는가?
    답

    \(\delta = 0.005\). \(\delta = 0.006\)이면 \(x = 5.0055\)에서 차이가 0.011이 되어 실패한다. 0.005보다 작은 \(\delta\)는 모두 된다.

  3. 상수함수 \(f(x) = c\)에 대해 \(\lim_{x\to a}f(x) = c\)임을 보여라. \(\delta\)는 얼마로 잡는가?
    답

    \(|f(x) - c| = 0 < \varepsilon\)이 언제나 성립하므로 어떤 \(\delta\)를 잡아도 된다(예: \(\delta = 1\)).

응용

  1. \(\lim_{x\to1}(x^2 + x) = 2\)를 증명하여라.
    힌트

    \(x^2 + x - 2 = (x - 1)(x + 2)\). \(\delta \le 1\)이면 \(|x + 2| < 4\).

    답

    \(\delta = \min(1, \frac\varepsilon4)\). \(0 < |x - 1| < \delta\)이면 \(0 < x < 2\)라 \(|x + 2| < 4\), \(|x^2 + x - 2| < 4\cdot\frac\varepsilon4 = \varepsilon\).

  2. \(\lim_{x\to4}\sqrt x = 2\)를 증명하여라.
    힌트

    \(\sqrt x - 2 = \frac{x - 4}{\sqrt x + 2}\)이고 \(\sqrt x + 2 \ge 2\).

    답

    \(|\sqrt x - 2| = \frac{|x - 4|}{\sqrt x + 2} \le \frac{|x - 4|}{2}\). \(\delta = \min(4, 2\varepsilon)\)으로 잡는다(\(\delta \le 4\)는 \(x \ge 0\)이 되게, 곧 \(\sqrt x\)가 정의되게 하려는 것).

심화

  1. \(\lim_{x\to a}f(x) = L\)일 필요충분조건은 \(\lim_{x\to a^+}f(x) = L\)이고 \(\lim_{x\to a^-}f(x) = L\)인 것임을 증명하여라.
    힌트

    (⇐) 두 한쪽 극한에서 얻은 \(\delta_1, \delta_2\) 중 작은 쪽을 쓰세요.

    답

    (⇒) 양쪽 조건을 만족하는 \(\delta\)는 한쪽만 보는 조건도 만족한다. (⇐) \(a < x < a + \delta_1\)이면, \(a - \delta_2 < x < a\)이면 \(|f(x) - L| < \varepsilon\)인 \(\delta_1, \delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)이면 \(0 < |x - a| < \delta\)인 \(x\)는 둘 중 한 경우에 속하므로 \(|f(x) - L| < \varepsilon\).

1.3.7매번 ε-δ를 쓸 수는 없다

1.3.8극한 법칙

정리 1.3.7 (극한 법칙)

\(\lim_{x\to a}f(x) = L\), \(\lim_{x\to a}g(x) = M\)이고 \(c\)가 상수이면

  1. \(\lim_{x\to a}[f(x) + g(x)] = L + M\)
  2. \(\lim_{x\to a}cf(x) = cL\)
  3. \(\lim_{x\to a}f(x)g(x) = LM\)
  4. \(M \ne 0\)이면 \(\lim_{x\to a}\frac{f(x)}{g(x)} = \frac LM\)

모든 법칙에 "두 극한이 존재하면"이라는 가정이 붙어 있다는 점이 중요합니다. 예를 들어 \(\lim_{x\to0}\left[\frac1x + \left(-\frac1x\right)\right] = 0\)이지만, 각각의 극한은 존재하지 않으므로 "\(\lim\frac1x + \lim\left(-\frac1x\right)\)"로 나누어 쓸 수 없습니다.

합의 법칙만 증명하겠습니다. 나머지도 같은 생각으로 증명할 수 있습니다(곱의 법칙은 연습문제 6).

증명 (1).\(\varepsilon > 0\)이 주어졌다고 하자. 핵심은 허용 오차를 반씩 나누는 것이다. \(\lim f = L\)이므로 \(0 < |x - a| < \delta_1\)이면 \(|f(x) - L| < \frac\varepsilon2\)인 \(\delta_1\)이 있다(정의에서 "\(\varepsilon\)" 자리에 \(\frac\varepsilon2\)을 넣었다). 마찬가지로 \(0 < |x - a| < \delta_2\)이면 \(|g(x) - M| < \frac\varepsilon2\)인 \(\delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 놓으면 \(0 < |x - a| < \delta\)일 때 두 부등식이 모두 성립하고, 삼각부등식(1.1절)에 의해

\[|(f + g)(x) - (L + M)| \le |f(x) - L| + |g(x) - M| < \tfrac\varepsilon2 + \tfrac\varepsilon2 = \varepsilon.\]

이다. ∎

이 법칙들과 두 가지 기본 극한 \(\lim_{x\to a}c = c\), \(\lim_{x\to a}x = a\)를 합치면 다음을 얻습니다.

따름정리 1.3.8 (대입 법칙)

\(p\)가 다항함수이면 \(\lim_{x\to a}p(x) = p(a)\)이다. \(r = \frac pq\)가 유리함수이고 \(q(a) \ne 0\)이면 \(\lim_{x\to a}r(x) = r(a)\)이다.

\(x^2 = x\cdot x\)이므로 곱의 법칙에서 \(\lim x^2 = a^2\), 같은 방식으로 \(\lim x^n = a^n\)이고, 상수배와 합의 법칙으로 다항식 전체가 처리됩니다. 고교에서 "그냥 대입"하던 것이 이렇게 정당화됩니다.

1.3.9\(\frac00\) 꼴 정리하기

대입했을 때 분모가 0이면 몫의 법칙을 쓸 수 없습니다. 분자도 0이면(\(\frac00\) 꼴) 극한이 있을 수도 없을 수도 있어서 식을 정리해야 합니다. 정리하는 근거는 다음 사실입니다.

정리 1.3.9

\(a\) 근처에서 \(x \ne a\)인 모든 \(x\)에 대해 \(f(x) = g(x)\)이고 \(\lim_{x\to a}g(x)\)가 존재하면, \(\lim_{x\to a}f(x) = \lim_{x\to a}g(x)\)이다.

정의 2.1.1이 \(x = a\)를 빼고 보기 때문에 당연히 성립합니다. 그래서 \(x \ne a\)일 때만 성립하는 약분을 해도 극한은 변하지 않습니다.

예제 1.3.10

(가) \(\lim_{x\to2}\frac{x^3 - 8}{x^2 - 4}\) (나) \(\lim_{h\to0}\frac{\sqrt{9 + h} - 3}{h}\)을 구하여라.

풀이. (가) 분자와 분모에 공통인수 \(x - 2\)가 있습니다. \(x \ne 2\)이면

\[\frac{x^3 - 8}{x^2 - 4} = \frac{(x - 2)(x^2 + 2x + 4)}{(x - 2)(x + 2)} = \frac{x^2 + 2x + 4}{x + 2}\]

이고, 오른쪽은 \(x = 2\)에서 분모가 4이므로 대입할 수 있어 극한은 \(\frac{12}{4} = 3\)입니다.

(나) 근호가 있으면 분자를 유리화합니다. \(h \ne 0\)이면

\[\frac{\sqrt{9 + h} - 3}{h} = \frac{(9 + h) - 9}{h(\sqrt{9 + h} + 3)} = \frac{1}{\sqrt{9 + h} + 3} \to \frac16.\]

마지막 단계에서 \(\sqrt{9 + h} \to 3\)을 썼는데, 이는 \(\sqrt{\ }\)가 연속이라는 사실(1.4절)입니다.

1.3.10압축 정리

대입도 약분도 안 되는 극한이 있습니다. \(x^2\sin\frac1x\)은 \(x \to 0\)일 때 \(\sin\frac1x\)이 \(-1\)과 1 사이를 끝없이 오가서 극한 법칙을 쓸 수 없습니다(\(\lim\sin\frac1x\)이 없으니까요). 하지만 \(-x^2 \le x^2\sin\frac1x \le x^2\)이고 양쪽이 모두 0으로 가므로, 가운데도 0으로 갈 수밖에 없어 보입니다. 이것을 정리로 만든 것이 압축 정리입니다.

정리 1.3.11 (압축 정리)

\(a\) 근처에서 (\(a\) 제외) \(g(x) \le f(x) \le h(x)\)이고 \(\lim_{x\to a}g(x) = \lim_{x\to a}h(x) = L\)이면 \(\lim_{x\to a}f(x) = L\)이다.

증명.\(\varepsilon > 0\)이 주어졌다고 하자. 가정에 의해 \(0 < |x - a| < \delta_1\)이면 \(L - \varepsilon < g(x)\), \(0 < |x - a| < \delta_2\)이면 \(h(x) < L + \varepsilon\)인 \(\delta_1, \delta_2\)가 있다. 또 부등식 \(g \le f \le h\)가 성립하는 범위를 \(0 < |x - a| < \delta_3\)이라 하자. \(\delta = \min(\delta_1, \delta_2, \delta_3)\)이면 \(0 < |x - a| < \delta\)일 때 \(L - \varepsilon < g(x) \le f(x) \le h(x) < L + \varepsilon\)이므로 \(|f(x) - L| < \varepsilon\)이다. ∎

압축 정리를 쓸 때 할 일은 하나입니다. 같은 극한을 갖는 두 함수 사이에 원하는 함수를 끼워 넣는 부등식을 찾는 것입니다. 진동하는 인수가 있으면 \(|\sin(\cdots)| \le 1\), \(|\cos(\cdots)| \le 1\)이 대개 그 부등식을 줍니다.

1.3.11\(\frac{\sin x}{x}\)의 극한

삼각함수의 미분(2.2절)은 모두 다음 극한 하나에 기댑니다. 고교 미적분에서 이 극한을 배웠다면 그 증명을 여기서 다시 확인하고, 배우지 않았다면 처음부터 따라오면 됩니다.

정리 1.3.12 \[\lim_{x\to0}\frac{\sin x}{x} = 1 \qquad (x\text{는 라디안}).\]

먼저 수치로 확인합니다. \(x = 0.1\)이면 \(\frac{\sin 0.1}{0.1} = 0.99833\), \(x = 0.01\)이면 \(0.9999833\)입니다. 분자와 분모가 모두 0으로 가는데 그 비가 1로 갑니다. 곧 작은 \(x\)에서 \(\sin x \approx x\)입니다.

증명.먼저 \(0 < x < \frac\pi2\)인 경우를 보자. 반지름 1인 원에서 중심 \(O\), 점 \(A = (1, 0)\), 각 \(x\)만큼 돌린 점 \(P = (\cos x, \sin x)\)를 잡고, 직선 \(OP\)가 \(A\)에서의 접선 \(x = 1\)과 만나는 점을 \(T = (1, \tan x)\)라 하자. 그림에서 세 도형이 차례로 포함된다: 삼각형 \(OAP\) ⊂ 부채꼴 \(OAP\) ⊂ 삼각형 \(OAT\). 넓이를 비교하면

\[\frac12\sin x \;<\; \frac12x \;<\; \frac12\tan x.\]

가운데는 부채꼴의 넓이 \(\frac12r^2\theta\)(\(r = 1\), \(\theta = x\))이고, 양쪽은 밑변 \(OA = 1\)과 높이 \(\sin x\), \(\tan x\)인 삼각형의 넓이이다. 각 변을 \(\frac12\sin x > 0\)으로 나누면 \(1 < \frac{x}{\sin x} < \frac{1}{\cos x}\), 역수를 취하면(양수이므로 부등호가 뒤집힌다)

\[\cos x < \frac{\sin x}{x} < 1.\]

\(-\frac\pi2 < x < 0\)이면 \(x\)를 \(-x\)로 바꿔도 \(\frac{\sin x}{x}\)과 \(\cos x\)가 변하지 않으므로 같은 부등식이 성립한다. \(x \to 0\)일 때 \(\cos x \to 1\)이므로(아래 참고), 압축 정리에 의해 \(\frac{\sin x}{x} \to 1\)이다. ∎

증명에서 \(\cos x \to 1\)을 썼습니다. 이것도 같은 그림에서 나옵니다. 호 \(AP\)의 길이는 \(|x|\)이고 현 \(AP\)는 그보다 짧으므로, \(P\)와 \(A\)의 가로 거리 \(1 - \cos x\)와 세로 거리 \(|\sin x|\)는 모두 \(|x|\) 이하입니다. 압축 정리로 \(x \to 0\)일 때 \(\sin x \to 0\), \(\cos x \to 1\)입니다.

라디안이라는 조건이 왜 중요할까요? 각을 도(°)로 재면 부채꼴 넓이가 \(\frac{\pi}{360}r^2\theta\)가 되어, 극한이 \(\frac{\pi}{180} \approx 0.01745\)로 바뀝니다. 미적분에서 각을 언제나 라디안으로 재는 것은 이 극한을 1로 만들기 위해서입니다.

예제 1.3.13

(가) \(\lim_{x\to0}\frac{\sin 3x}{x}\) (나) \(\lim_{x\to0}\frac{1 - \cos x}{x^2}\)을 구하여라.

풀이. (가) \(u = 3x\)로 놓으면 \(x \to 0\)일 때 \(u \to 0\)이고 \(\frac{\sin 3x}{x} = 3\cdot\frac{\sin u}{u} \to 3\)입니다.

(나) 분자와 분모에 \(1 + \cos x\)를 곱해 \(\sin^2x + \cos^2x = 1\)을 씁니다.

\[\frac{1 - \cos x}{x^2} = \frac{1 - \cos^2x}{x^2(1 + \cos x)} = \left(\frac{\sin x}{x}\right)^2\cdot\frac{1}{1 + \cos x} \to 1^2\cdot\frac12 = \frac12.\]

마지막에 곱의 법칙을 썼고, 각 인수의 극한이 존재하므로 쓸 수 있습니다. 이 결과는 작은 \(x\)에서 \(\cos x \approx 1 - \frac{x^2}{2}\)라는 뜻이고, 8.8절의 Taylor 다항식에서 다시 나옵니다. 공통3에서 진자의 주기를 구할 때 쓰는 "작은 각 근사"가 바로 \(\sin x \approx x\)와 이 식입니다.

주의\(\lim_{x\to0}x\sin\frac1x\)을 "\(\lim x\cdot\lim\sin\frac1x = 0\cdot(\text{무엇})= 0\)"으로 계산하면 결과는 맞아도 논리는 틀립니다. \(\lim\sin\frac1x\)이 존재하지 않으므로 곱의 법칙을 쓸 수 없습니다. 올바른 근거는 \(-|x| \le x\sin\frac1x \le |x|\)와 압축 정리입니다.
요약
  1. 두 극한이 존재하면 합, 상수배, 곱, 몫(분모의 극한 ≠ 0)의 극한은 극한의 합, 상수배, 곱, 몫이다.
  2. 다항함수와 (분모 ≠ 0인) 유리함수는 대입으로 극한을 구한다.
  3. \(\frac00\) 꼴은 \(x \ne a\)에서 약분·유리화로 정리한 뒤 대입한다.
  4. 압축 정리: \(g \le f \le h\)이고 \(g, h \to L\)이면 \(f \to L\). 진동하는 인수에는 \(|\sin| \le 1\).
  5. \(\lim_{x\to0}\frac{\sin x}{x} = 1\), \(\lim_{x\to0}\frac{1 - \cos x}{x^2} = \frac12\) (라디안).

기본

    답

    (가) \(x - 2 \to -5\) (나) \(\frac{1}{\sqrt x + 1} \to \frac12\) (다) \(\frac{\sin x}{x}\cdot\frac{1}{\cos x} \to 1\)

  2. \(\lim_{x\to0}x^2\cos\frac{1}{x^2}\)을 압축 정리로 구하여라.
    답

    \(-x^2 \le x^2\cos\frac{1}{x^2} \le x^2\)이고 양쪽이 0으로 가므로 0.

  3. \(\lim_{x\to0}\frac{\sin 5x}{\sin 2x}\)을 구하여라.
    답

    \(\frac{\sin 5x}{5x}\cdot\frac{2x}{\sin 2x}\cdot\frac52 \to \frac52\).

응용

  1. \(\lim_{x\to2}f(x) = 3\)이고 \(\lim_{x\to2}\frac{g(x)}{x - 2} = 5\)일 때 \(\lim_{x\to2}g(x)\)와 \(\lim_{x\to2}\frac{f(x)g(x)}{x^2 - 4}\)를 구하여라.
    힌트

    \(g(x) = \frac{g(x)}{x - 2}\cdot(x - 2)\).

    답

    \(\lim g = 5\cdot0 = 0\). \(\frac{fg}{x^2 - 4} = f(x)\cdot\frac{g(x)}{x - 2}\cdot\frac{1}{x + 2} \to 3\cdot5\cdot\frac14 = \frac{15}{4}\).

  2. "\(\lim(f + g)\)가 존재하면 \(\lim f\)와 \(\lim g\)도 존재한다"가 거짓임을 반례로 보여라.
    답

    \(f = \frac1x\), \(g = -\frac1x\) (\(a = 0\)). 합은 0이라 극한이 있지만 각각은 없다.

심화

  1. 곱의 법칙을 증명하여라.
    힌트

    \(fg - LM = (f - L)g + L(g - M)\). \(g\)가 \(a\) 근처에서 유계(예: \(|g| < |M| + 1\))임을 먼저 보이세요.

    답

    \(\varepsilon = 1\)에 대한 \(\delta_0\)에서 \(|g(x)| < |M| + 1 =: K\). \(|f - L| < \frac{\varepsilon}{2K}\)인 \(\delta_1\), \(|g - M| < \frac{\varepsilon}{2(|L| + 1)}\)인 \(\delta_2\)를 잡고 \(\delta = \min(\delta_0, \delta_1, \delta_2)\)이면 \(|fg - LM| \le |f - L||g| + |L||g - M| < \frac\varepsilon2 + \frac\varepsilon2\).

1.3.3

설명ε-δ 정의는 무엇을 약속하는가?

극한의 정의

다루는 성취기준 [공통1-01-03]

왜 필요한가

고등학교에서는 "\(x\)가 \(a\)에 한없이 가까워질 때 \(f(x)\)가 \(L\)에 한없이 가까워진다"를 \(\lim_{x\to a} f(x) = L\)의 뜻으로 배웠습니다. 이 문장은 그림을 떠올리기에는 좋지만, 무엇을 확인하면 극한이 맞는지는 알려 주지 않습니다.

"한없이 가까워진다"를 확인하려면 \(x\)를 끝없이 움직여 봐야 할 것 같습니다. 그러나 무한히 많은 값을 하나하나 대입할 수는 없습니다. 또 \(\sin\frac{1}{x}\)처럼 0 근처에서 끝없이 출렁이는 함수가 0에서 극한을 갖는지는 그림만으로 판단하기 어렵습니다.

ε-δ 정의는 "한없이"라는 말을 쓰지 않고, 유한한 수 두 개(ε, δ)를 주고받는 약속으로 극한을 정의합니다. 그래서 극한이 맞는지를 증명할 수 있게 됩니다. 해석학, 미분방정식, 확률론의 모든 수렴 개념이 이 형식을 따릅니다.

정의 · 함수의 극한

함수 \(f\)가 \(a\)를 포함하는 열린구간에서 (\(a\) 자신은 빼도 됨) 정의되어 있다고 하자. 임의의 \(\varepsilon > 0\)에 대하여 어떤 \(\delta > 0\)가 존재해서

\[0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon\]

가 성립하면, \(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한은 \(L\)이라 하고 \(\lim_{x\to a} f(x) = L\)로 쓴다.

정의를 풀어 읽기

  1. "임의의 \(\varepsilon > 0\)에 대하여"\(\varepsilon\)은 상대가 정하는 허용 오차입니다. "\(f(x)\)와 \(L\)의 차이를 이만큼 이하로 줄여 보라"는 요구입니다. 0.1이든 \(10^{-9}\)이든, 양수이기만 하면 어떤 요구에도 답해야 합니다. 그래서 '임의의'가 앞에 옵니다.
  2. "어떤 \(\delta > 0\)가 존재해서"\(\delta\)는 우리가 고르는 입력의 범위입니다. 요구된 \(\varepsilon\)을 보고 나서 고르므로, \(\delta\)는 \(\varepsilon\)에 따라 달라져도 됩니다(보통 \(\varepsilon\)이 작을수록 \(\delta\)도 작아집니다). 하나만 찾으면 됩니다.
  3. "\(0 < |x - a|\)"\(x = a\)는 빼고 봅니다. 극한은 \(a\) 근처의 행동을 묻는 것이지 \(f(a)\)의 값을 묻는 것이 아닙니다. \(f(a)\)가 정의되지 않거나 엉뚱한 값이어도 극한은 있을 수 있습니다.
  4. "\(|x - a| < \delta\)"입력을 \(a\)에서 \(\delta\)보다 가까운 곳으로 제한합니다. 수직선에서는 열린구간 \((a-\delta,\ a+\delta)\)입니다.
  5. "\(\implies |f(x) - L| < \varepsilon\)"그 범위의 모든 \(x\)에서 출력이 허용 오차 안에 들어와야 합니다. 몇 개의 \(x\)에서만 맞으면 안 됩니다.

순서가 중요합니다. ε이 먼저, δ가 나중입니다. 이 순서를 게임으로 생각하면 쉽습니다. 상대가 \(\varepsilon\)을 내밀면 우리가 \(\delta\)로 답합니다. 상대가 어떤 \(\varepsilon\)을 내밀어도 답할 방법(규칙)이 있으면 극한이 \(L\)입니다.

예와 반례

예 1. \(f(x) = 3x - 1\), \(a = 2\), \(L = 5\). \(|f(x) - 5| = |3x - 6| = 3|x - 2|\)이므로 \(|x-2| < \frac{\varepsilon}{3}\)이면 \(|f(x) - 5| < \varepsilon\)입니다. 규칙 "\(\delta = \frac{\varepsilon}{3}\)"이 모든 \(\varepsilon\)에 답합니다.

예 2. \(f(x) = \frac{x^2 - 4}{x - 2}\)는 \(x = 2\)에서 정의되지 않지만, \(x \ne 2\)이면 \(f(x) = x + 2\)입니다. 정의는 \(x \ne 2\)만 보므로 \(\delta = \varepsilon\)으로 \(\lim_{x\to 2} f(x) = 4\)를 보일 수 있습니다.

반례. \(g(x) = 1\ (x \ge 0)\), \(g(x) = -1\ (x < 0)\)일 때 \(\lim_{x\to 0} g(x) = 1\)이 아닌 이유: \(\varepsilon = 1\)을 받으면 어떤 \(\delta\)를 골라도 \((-\delta, 0)\)의 \(x\)에서 \(|g(x) - 1| = 2\)입니다. "모든 \(x\)에서" 구절에서 걸립니다. 같은 이유로 어떤 \(L\)도 극한이 될 수 없습니다(왼쪽과 오른쪽이 2만큼 떨어져 있어서 \(\varepsilon = 1\) 안에 둘 다 넣을 수 없음).

다른 개념과의 관계

  • 수열의 극한: \(\lim a_n = L\)은 "임의의 \(\varepsilon\)에 대해 어떤 \(N\)이 있어 \(n > N\)이면 \(|a_n - L| < \varepsilon\)". \(\delta\) 자리에 \(N\)이 들어간 같은 형식입니다.
  • 연속: \(\lim_{x\to a} f(x) = f(a)\)가 연속의 정의입니다. 이 단원 뒤쪽 설명 카드에서 다룹니다.
  • 극한 법칙(합·곱·몫의 극한)은 모두 이 정의로 증명됩니다. 한 번 증명해 두면 그다음부터는 법칙으로 계산합니다.

흔한 오해

  • "δ를 먼저 정하고 ε을 구한다." 거꾸로입니다. \(\delta\)를 먼저 고정하면 "\(\delta\)가 작을 때 오차가 작다"는 말이 되어, 극한이 아닌 함수도 통과할 수 있습니다.
  • "\(f(a) = L\)이어야 한다." 정의는 \(x = a\)를 뺍니다. 극한은 \(f(a)\)와 상관없습니다.
  • "가장 큰 δ를 찾아야 한다." 통하는 \(\delta\)를 하나만 찾으면 됩니다. 통하는 \(\delta\)보다 작은 값은 모두 통하므로, 계산이 편한 작은 값을 골라도 됩니다.

판정은 세로 띠 안의 2000개 점에서 \(|f(x) - L|\)을 계산한 결과입니다. 점 \(x=a\)는 빼고 봅니다.

  1. 질문\(x^2\)은 \(x=2\) 근처에서 4에 가까워 보입니다. 그런데 "가까워 보인다"를 어떻게 증명할까요? 상대가 오차 \(\varepsilon\)을 요구할 때마다 우리가 입력 범위 \(\delta\)를 내놓는 게임으로 바꿔 봅니다.
  2. 복원\(|x - a| < \delta\)는 \(a\)를 가운데로 한 폭 \(2\delta\)의 열린구간, \(|f(x) - L| < \varepsilon\)은 \(L\)을 가운데로 한 높이 \(2\varepsilon\)의 띠입니다. 앞 카드의 정의를 이 두 띠로 읽습니다.
  3. 설명세로 띠 안의 그래프 조각이 모두 가로 띠 안에 들어가면 그 \(\delta\)는 \(\varepsilon\)에 대한 답이 됩니다. \(\delta\)를 줄이면 그래프 조각이 짧아지므로 들어가기 쉬워집니다.
  4. 연결\(\varepsilon\)을 줄일 때마다 \(\delta\)도 줄여야 합니다. "통하는 가장 큰 δ"와 "규칙이 주는 δ"를 비교해 보세요. \(x^2\)의 규칙 \(\delta = \min\{1, \varepsilon/5\}\)은 가장 큰 값보다 작지만 늘 통합니다. 증명에는 통하는 규칙 하나면 충분합니다.
  5. 적용계단 함수로 바꾸고 \(L\)을 움직여 보세요. \(\varepsilon\)이 1보다 작아지면 어떤 \(\delta\), 어떤 \(L\)로도 초록이 되지 않습니다. 이것이 "극한이 없다"의 그림입니다.
  6. 판단그림은 \(\varepsilon\) 몇 개만 시험합니다. 극한을 증명하려면 모든 \(\varepsilon\)에 통하는 규칙을 식으로 보여야 합니다. 다음 증명 카드가 그 일을 합니다.
1.3.5

증명\(\lim_{x\to 2} x^2 = 4\)를 ε-δ로 증명하기

초안에서 정리된 증명까지

다루는 성취기준 [공통1-01-03]

정리

\(\lim_{x\to 2} x^2 = 4\).

쓰는 것

  • 극한의 정의: 임의의 \(\varepsilon>0\)에 대해 \(\delta>0\)를 찾아 \(0<|x-2|<\delta \Rightarrow |x^2-4|<\varepsilon\)을 보이면 된다.
  • 절댓값의 곱: \(|uv| = |u||v|\).
  • 삼각부등식: \(|u+v| \le |u| + |v|\).

아이디어

목표인 \(|x^2 - 4|\)를 우리가 통제하는 \(|x - 2|\)로 나타냅니다. 인수분해하면 \(|x^2-4| = |x-2|\,|x+2|\)입니다. 앞의 \(|x-2|\)는 \(\delta\)로 작게 만들 수 있습니다. 문제는 뒤의 \(|x+2|\)입니다. 이 값은 \(x\)에 따라 변하므로, \(x\)를 2 근처로 묶어 \(|x+2|\)가 어떤 상수보다 작다고 먼저 못 박습니다. 그러면 남은 일은 \(|x-2|\)를 작게 하는 것뿐입니다.

이렇게 "곤란한 인수를 상수로 누르고, 그다음 \(\delta\)를 고르는" 방법은 다항식, 유리함수의 ε-δ 증명에서 거의 언제나 씁니다.

초안: δ를 찾는 과정 (교재에는 잘 안 나오는 부분)

  1. 목표를 인수분해합니다. \(|x^2 - 4| = |x-2|\,|x+2|\).
    \(x^2-4=(x-2)(x+2)\)와 절댓값의 곱.
  2. \(|x+2|\)를 누르기 위해 일단 \(\delta \le 1\)로 정합니다. 그러면 \(|x-2|<1\), 곧 \(1 < x < 3\)이고 \(3 < x+2 < 5\)이므로 \(|x+2| < 5\)입니다.
    1은 아무 양수나 골라도 됩니다. 계산이 편한 값을 골랐습니다. 2를 고르면 \(|x+2|<6\)이 됩니다.
  3. 그러면 \(|x^2-4| < 5|x-2|\)입니다. 이것이 \(\varepsilon\)보다 작으려면 \(|x-2| < \frac{\varepsilon}{5}\)이면 됩니다.
    2단계의 부등식을 1단계 식에 대입.
  4. 두 조건 \(|x-2|<1\)과 \(|x-2|<\frac{\varepsilon}{5}\)를 동시에 만족시키려면 \(\delta = \min\{1, \frac{\varepsilon}{5}\}\)로 고릅니다.
    \(|x-2| < \min\{p, q\}\)이면 \(|x-2| < p\)이고 \(|x-2| < q\).

초안은 결론에서 출발해 거꾸로 갑니다. 정리된 증명은 초안에서 찾은 \(\delta\)를 먼저 내놓고 앞으로 갑니다.

정리된 증명

  1. \(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\{1, \frac{\varepsilon}{5}\}\)로 둔다. 그러면 \(\delta > 0\)이다.
    두 양수의 최솟값은 양수. 정의가 요구하는 "\(\delta>0\)가 존재"를 직접 만들어 보인다.
  2. \(0 < |x - 2| < \delta\)인 \(x\)를 아무거나 잡는다. \(\delta \le 1\)이므로 \(|x-2| < 1\), 따라서 \(1 < x < 3\)이고 \(|x+2| < 5\)이다.
    \(\delta\)의 정의(최솟값 ≤ 1)와 부등식의 덧셈.
  3. \(\delta \le \frac{\varepsilon}{5}\)이므로 \(|x - 2| < \frac{\varepsilon}{5}\)이다.
    \(\delta\)의 정의(최솟값 ≤ ε/5).
  4. 따라서 \(|x^2 - 4| = |x-2|\,|x+2| < \frac{\varepsilon}{5}\cdot 5 = \varepsilon\). \(\varepsilon\)이 임의였으므로 \(\lim_{x\to 2} x^2 = 4\)이다.
    2, 3단계의 두 부등식을 곱함(양수끼리이므로 방향 유지). 마지막 문장은 "임의의 ε"을 확인했다는 표시.

되짚기

  • 1을 고른 이유. \(|x+2|\)를 상수로 누르려면 \(x\)를 유계 구간에 가둬야 했습니다. 그 구간의 크기로 1을 골랐습니다. 이 제한이 없으면 \(x\)가 커질수록 \(|x+2|\)도 커져서 \(\varepsilon/|x+2|\) 같은 "\(x\)에 의존하는 δ"가 되어 버립니다. \(\delta\)는 \(\varepsilon\)에만 의존해야 합니다.
  • min을 쓴 이유. \(\varepsilon\)이 클 때(예: \(\varepsilon = 100\)) \(\varepsilon/5 = 20\)을 그대로 쓰면 2단계의 \(|x+2|<5\)가 깨집니다. min이 두 조건을 모두 지킵니다.
  • 통하는 가장 큰 δ는 아닙니다. 앞의 탐구 카드에서 본 것처럼 실제로는 더 큰 \(\delta\)도 통합니다. 증명에는 통하는 \(\delta\) 하나면 됩니다.

더 나아가기

같은 방법으로 \(\lim_{x\to a} x^2 = a^2\)을 보일 수 있습니다. \(\delta \le 1\)이면 \(|x + a| \le |x - a| + 2|a| < 1 + 2|a|\)이므로 \(\delta = \min\{1, \frac{\varepsilon}{1 + 2|a|}\}\)로 고르면 됩니다(삼각부등식을 썼습니다).

직접 써 보기

\(\lim_{x\to 3} (x^2 - x) = 6\)을 ε-δ로 증명하세요. 초안을 먼저 쓰고 정리된 증명으로 옮기세요.

힌트

\(x^2 - x - 6 = (x-3)(x+2)\). \(|x-3|<1\)이면 \(|x+2|\)는 무엇보다 작을까요?

답안

\(\varepsilon > 0\)이 주어졌다고 하자. \(\delta = \min\{1, \frac{\varepsilon}{6}\}\)로 둔다. \(0 < |x-3| < \delta\)이면 \(|x - 3| < 1\)이므로 \(2 < x < 4\), 따라서 \(4 < x + 2 < 6\)이고 \(|x+2| < 6\)이다. 또 \(|x-3| < \frac{\varepsilon}{6}\)이다. 그러므로

\[|x^2 - x - 6| = |x-3|\,|x+2| < \tfrac{\varepsilon}{6}\cdot 6 = \varepsilon.\]

\(\varepsilon\)이 임의였으므로 \(\lim_{x\to 3}(x^2 - x) = 6\). ∎
