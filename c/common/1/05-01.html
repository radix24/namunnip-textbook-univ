5.1.1곱의 미분법을 거꾸로

\(\int xe^x\,dx\)는 치환으로 풀리지 않습니다. 이런 곱의 적분에는 곱의 미분법 \((uv)' = u'v + uv'\)을 씁니다. 양변을 적분하고 정리하면

정리 5.1.1 (부분적분) \[\int u\,dv = uv - \int v\,du, \qquad \int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du.\]

적분할 식을 "\(u\)"와 "\(dv\)" 두 부분으로 나누어, \(u\)는 미분하고 \(dv\)는 적분합니다. 새로 생긴 \(\int v\,du\)가 처음 것보다 쉬워지도록 나누는 것이 요령입니다.

예제 5.1.2

(가) \(\int xe^x\,dx\) (나) \(\int\ln x\,dx\)

풀이. (가) \(u = x\), \(dv = e^xdx\)로 놓으면 \(du = dx\), \(v = e^x\). \(\int xe^xdx = xe^x - \int e^xdx = xe^x - e^x + C\). 거꾸로 \(u = e^x\), \(dv = x\,dx\)로 놓으면 \(\int\frac{x^2}{2}e^xdx\)가 남아 더 어려워집니다.

(나) 곱이 아닌 것 같지만 \(\ln x\cdot1\)로 봅니다. \(u = \ln x\), \(dv = dx\): \(du = \frac{dx}{x}\), \(v = x\). \(\int\ln x\,dx = x\ln x - \int x\cdot\frac1x dx = x\ln x - x + C\).

\(u\)로 고르기 좋은 순서를 흔히 "로-역-다-삼-지"로 외웁니다: 로그, 역삼각, 다항, 삼각, 지수 함수. 앞쪽에 있을수록 \(u\)로 고릅니다. 미분하면 간단해지는 함수가 앞쪽에 있습니다.

5.1.2두 번 쓰기와 되돌아오는 적분

예제 5.1.3

(가) \(\int x^2\sin x\,dx\) (나) \(\int e^x\sin x\,dx\)

풀이. (가) \(u = x^2\), \(dv = \sin x\,dx\): \(= -x^2\cos x + \int2x\cos x\,dx\). 남은 적분에 한 번 더(\(u = 2x\), \(dv = \cos x\,dx\)): \(\int2x\cos x\,dx = 2x\sin x - \int2\sin x\,dx = 2x\sin x + 2\cos x\). 합치면 \(-x^2\cos x + 2x\sin x + 2\cos x + C\).

(나) \(I = \int e^x\sin x\,dx\)라 하고 \(u = \sin x\), \(dv = e^xdx\): \(I = e^x\sin x - \int e^x\cos x\,dx\). 다시 \(u = \cos x\), \(dv = e^xdx\): \(\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I\). 대입하면 \(I = e^x\sin x - e^x\cos x - I\), 곧 원래 적분 \(I\)가 다시 나타납니다. 이항해서 \(2I = e^x(\sin x - \cos x)\), 따라서

\[\int e^x\sin x\,dx = \frac{e^x}{2}(\sin x - \cos x) + C.\]

원래 적분이 되돌아오면 방정식처럼 풀면 됩니다. 이때 두 번 모두 같은 종류(여기서는 삼각함수)를 \(u\)로 골라야 합니다.

주의\(\int u\,dv\)의 부호를 놓치기 쉽습니다. \(uv\) 빼기 \(\int v\,du\)입니다. 또 정적분에서는 \(uv\)에도 위끝·아래끝 값을 넣어야 합니다.
요약
  1. \(\int u\,dv = uv - \int v\,du\): \(u\)는 미분, \(dv\)는 적분.
  2. \(u\) 고르는 순서: 로그, 역삼각, 다항, 삼각, 지수.
  3. 여러 번 쓰거나, 원래 적분이 되돌아오면 방정식으로 푼다.

5.1.3연습문제

기본

  1. (가) \(\int x\cos x\,dx\) (나) \(\int x\ln x\,dx\) (다) \(\int_0^1 xe^{2x}dx\)
    답

    (가) \(x\sin x + \cos x + C\) (나) \(\frac{x^2}{2}\ln x - \frac{x^2}{4} + C\) (다) \(\left[\frac{x}{2}e^{2x} - \frac14e^{2x}\right]_0^1 = \frac{e^2 + 1}{4}\)

응용

  1. \(\int\arctan x\,dx\)를 구하여라.
    답

    \(u = \arctan x\), \(dv = dx\): \(x\arctan x - \int\frac{x}{1 + x^2}dx = x\arctan x - \frac12\ln(1 + x^2) + C\).

  2. \(\int e^x\cos x\,dx\)를 구하여라.
    답

    \(\frac{e^x}{2}(\sin x + \cos x) + C\).

5.1.2

예제부분적분: 곱의 법칙을 거꾸로

u, dv 고르기 · 되풀이 · 제자리로 돌아오기

다루는 성취기준 [공통1-05-01]

근거

곱의 법칙 \((uv)' = u'v + uv'\)를 적분하면 \(uv = \int u'v + \int uv'\), 곧

\[\int u\,dv = uv - \int v\,du, \qquad \int_a^b u\,dv = \Big[uv\Big]_a^b - \int_a^b v\,du.\]

"\(u\)는 미분하고 \(dv\)는 적분해서, 더 쉬운 적분 \(\int v\,du\)로 바꾼다"는 뜻입니다.

u를 고르는 기준

미분하면 단순해지는 것을 \(u\)로, 적분하기 쉬운 것을 \(dv\)로 둡니다. 경험칙으로 로그 → 역삼각 → 다항식 → 삼각 → 지수 순서에서 앞에 있는 것을 \(u\)로 고르면 대부분 맞습니다. 로그와 역삼각은 미분하면 유리식이 되고, 다항식은 미분할 때마다 차수가 내려가기 때문입니다.

문제. (가) \(\displaystyle\int x^2 e^{x}dx\) (나) \(\displaystyle\int_1^e\ln x\,dx\) (다) \(\displaystyle\int e^{x}\sin x\,dx\)

풀이

  1. (가) \(u = x^2\), \(dv = e^xdx\) → \(du = 2x\,dx\), \(v = e^x\). \(\int x^2e^x = x^2e^x - 2\int xe^x\,dx\).
    다항식을 \(u\)로: 차수가 2 → 1로 내려간다.
  2. 다시 \(u = x\), \(dv = e^xdx\): \(\int xe^x = xe^x - e^x\). 따라서 \(\int x^2e^x = e^x(x^2 - 2x + 2) + C\).
    한 번 더 부분적분. 차수만큼 되풀이한다.
  3. (나) \(u = \ln x\), \(dv = dx\) → \(du = \frac{dx}{x}\), \(v = x\). \(\Big[x\ln x\Big]_1^e - \int_1^e 1\,dx = e - (e - 1) = 1\).
    곱이 안 보여도 \(dv = dx\)로 두면 된다. \(\ln x\)는 미분하면 \(\frac1x\)로 단순해진다.
  4. (다) \(I = \int e^x\sin x\). \(u = \sin x\), \(dv = e^xdx\): \(I = e^x\sin x - \int e^x\cos x\,dx\).
    지수와 삼각은 미분해도 단순해지지 않는다. 대신 두 번 하면 제자리로 돌아온다.
  5. 다시 \(u = \cos x\), \(dv = e^xdx\): \(\int e^x\cos x = e^x\cos x + \int e^x\sin x = e^x\cos x + I\).
    두 번째도 같은 쪽(삼각)을 \(u\)로 골라야 한다. 바꾸면 원래 식으로 되돌아갈 뿐이다.
  6. \(I = e^x\sin x - e^x\cos x - I\)이므로 \(I = \dfrac{e^x(\sin x - \cos x)}{2} + C\).
    \(I\)에 대한 방정식으로 푼다. 적분 상수는 마지막에 붙인다.

의미

부분적분은 미분을 한 인수에서 다른 인수로 옮기는 기술입니다. 경계항 \([uv]\)가 사라지는 경우가 많아서, 공학의 라플라스 변환, 물리의 변분법, 편미분방정식의 약해(weak solution)가 모두 이 한 줄 공식 위에 서 있습니다.

검산

(가) \(\frac{d}{dx}e^x(x^2 - 2x + 2) = e^x(x^2 - 2x + 2) + e^x(2x - 2) = x^2e^x\). (다) \(\frac{d}{dx}\frac{e^x(\sin x - \cos x)}{2} = \frac{e^x(\sin x - \cos x) + e^x(\cos x + \sin x)}{2} = e^x\sin x\). 맞습니다.

표로 빠르게 (다항식 × 쉬운 함수)

(가)처럼 다항식을 여러 번 미분해야 할 때는 왼쪽 열에 \(u\)의 도함수를, 오른쪽 열에 \(dv\)의 적분을 차례로 적고 대각선으로 \(+, -, +, \dots\) 부호를 붙여 곱해 더하면 됩니다: \(x^2 \cdot e^x - 2x\cdot e^x + 2\cdot e^x\). 근거는 위 1, 2단계를 되풀이한 것과 같습니다.

흔한 오해

  • 정적분에서 \(uv\)에 구간을 안 넣기: \(\Big[uv\Big]_a^b\)도 반드시 계산합니다.
  • u를 거꾸로 고르기: (가)에서 \(u = e^x\), \(dv = x^2dx\)로 하면 \(\int\frac{x^3}{3}e^x\)이 되어 더 어려워집니다.
