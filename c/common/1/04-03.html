4.3.1연쇄법칙을 거꾸로

연쇄법칙에 따르면 \(\dfrac{d}{dx}\sin(x^2) = \cos(x^2)\cdot2x\)입니다. 이것을 거꾸로 읽으면 \(\int2x\cos(x^2)\,dx = \sin(x^2) + C\)입니다. 적분할 식 안에 "어떤 함수 \(u\)"와 "그 도함수 \(u'\)"가 함께 들어 있으면, \(u\)를 한 글자로 바꿔 간단한 적분으로 만들 수 있습니다.

정리 4.3.1 (치환적분)

\(u = g(x)\)가 미분 가능하고 \(f\)가 연속이면 \(\displaystyle\int f(g(x))\,g'(x)\,dx = \int f(u)\,du\)이다.

실제 계산에서는 \(u = g(x)\)로 놓고 \(\dfrac{du}{dx} = g'(x)\)를 "\(du = g'(x)\,dx\)"로 바꾸어 식에 넣습니다. 그러면 \(x\)가 모두 사라지고 \(u\)만 남아야 합니다.

예제 4.3.2

(가) \(\int x^3\cos(x^4 + 2)\,dx\) (나) \(\int\sqrt{2x + 1}\,dx\) (다) \(\int\tan x\,dx\)

풀이. (가) \(u = x^4 + 2\)이면 \(du = 4x^3dx\), 곧 \(x^3dx = \frac14du\). \(\int\cos u\cdot\frac14du = \frac14\sin(x^4 + 2) + C\).

(나) \(u = 2x + 1\), \(du = 2dx\). \(\int\sqrt u\cdot\frac12du = \frac12\cdot\frac23u^{3/2} + C = \frac13(2x + 1)^{3/2} + C\).

(다) \(\tan x = \dfrac{\sin x}{\cos x}\). \(u = \cos x\), \(du = -\sin x\,dx\). \(\int\dfrac{-du}{u} = -\ln|\cos x| + C = \ln|\sec x| + C\).

무엇을 \(u\)로 놓을지 고르는 요령: 괄호 안, 근호 안, 지수, 분모처럼 "안쪽에 들어 있는 식"을 \(u\)로 놓고, 그 도함수가 (상수배를 빼고) 식에 남아 있는지 봅니다. 검산은 답을 미분해서 원래 식이 나오는지 보면 됩니다.

4.3.2정적분의 치환

정적분에서는 \(u\)로 바꿀 때 적분 구간도 \(u\)의 값으로 바꿉니다. 그러면 마지막에 \(x\)로 되돌릴 필요가 없습니다.

예제 4.3.3

\(\int_0^2 xe^{-x^2}dx\)를 구하여라.

풀이. \(u = -x^2\), \(du = -2x\,dx\). \(x = 0\)이면 \(u = 0\), \(x = 2\)이면 \(u = -4\).

\[\int_0^2 xe^{-x^2}dx = \int_0^{-4}e^u\left(-\frac12\right)du = \frac12\int_{-4}^{0}e^u\,du = \frac12(1 - e^{-4}) \approx 0.491.\]

4.3.3미분방정식 맛보기: \(y' = ky\)

"늘어나는 빠르기가 지금의 양에 비례한다"는 현상은 아주 흔합니다. 세균의 증식, 예금의 복리, 방사성 원소의 붕괴, 축전기의 방전이 모두 이런 꼴입니다. 식으로는 \(\dfrac{dy}{dt} = ky\)입니다. 이런 식을 미분방정식이라 하고, 2학년 고등미적분학(1)에서 본격적으로 배웁니다. 여기서는 치환적분만으로 풀어 봅니다.

\(y > 0\)이라 하고 양변을 \(y\)로 나누면 \(\dfrac{1}{y}\dfrac{dy}{dt} = k\). 양변을 \(t\)로 적분하면 왼쪽은 치환적분으로 \(\int\dfrac{dy}{y} = \ln y\), 오른쪽은 \(kt + C\)입니다. 따라서 \(\ln y = kt + C\), 곧

\[y = e^{kt + C} = y_0e^{kt} \qquad (y_0 = e^C = y(0)).\]
예제 4.3.4

세균 수가 늘어나는 빠르기가 세균 수에 비례하고, 처음 1000마리가 3시간 뒤 8000마리가 되었다. 5시간 뒤의 수는?

풀이. \(y = 1000e^{kt}\). \(8000 = 1000e^{3k}\)에서 \(e^{3k} = 8\), \(e^k = 2\). 따라서 \(y = 1000\cdot2^t\)이고 5시간 뒤 \(32\,000\)마리입니다. 한 시간마다 두 배가 되는 셈입니다.

\(k < 0\)이면 같은 식이 지수적 감소(붕괴, 냉각, 방전)를 나타냅니다. 일반물리학(2)의 RC 회로, 일반화학(2)의 1차 반응 속도식이 이 식을 그대로 씁니다.

주의치환한 뒤 \(x\)와 \(u\)가 섞여 남으면 잘못 고른 것입니다. 또 정적분에서 구간을 바꾸지 않고 \(x\)의 구간을 그대로 쓰는 실수가 흔합니다. 구간을 바꾸든지, \(x\)로 되돌린 뒤 원래 구간을 넣든지 둘 중 하나만 하세요.
요약
  1. 안쪽 식을 \(u\)로, \(du = g'(x)dx\)로 바꾼다. \(x\)가 모두 사라져야 한다.
  2. 정적분은 구간도 \(u\)의 값으로 바꾼다.
  3. \(y' = ky\)의 해는 \(y = y_0e^{kt}\): 같은 비율로 늘거나 준다.

4.3.4연습문제

기본

  1. (가) \(\int(3x - 1)^5dx\) (나) \(\int\frac{2x}{x^2 + 1}dx\) (다) \(\int e^{\sin x}\cos x\,dx\)
    답

    (가) \(\frac{(3x - 1)^6}{18} + C\) (나) \(\ln(x^2 + 1) + C\) (다) \(e^{\sin x} + C\)

  2. \(\int_0^{\pi/2}\sin^3x\cos x\,dx\)를 구하여라.
    답

    \(u = \sin x\): \(\int_0^1 u^3du = \frac14\).

응용

  1. \(\int\frac{\ln x}{x}dx\)를 구하여라.
    답

    \(u = \ln x\), \(du = \frac{dx}{x}\). \(\frac{(\ln x)^2}{2} + C\).

  2. 반감기가 10일인 물질 80 g이 있다. 25일 뒤 남은 양을 \(y' = ky\)로 구하여라.
    답

    \(e^{10k} = \frac12\), \(y = 80\left(\frac12\right)^{t/10}\). \(y(25) = 80\cdot2^{-2.5} \approx 14.1\) g.

4.3.2

예제치환적분: 연쇄 법칙을 거꾸로

부정적분 · 정적분의 구간 바꾸기

다루는 성취기준 [공통1-04-03]

근거

연쇄 법칙 \(\frac{d}{dx}F(g(x)) = F'(g(x))g'(x)\)를 적분 쪽으로 읽으면

\[\int f(g(x))\,g'(x)\,dx = F(g(x)) + C = \int f(u)\,du\Big|_{u = g(x)}.\]

그래서 피적분함수에서 "어떤 함수 \(g(x)\)와 그 도함수 \(g'(x)\)"의 짝을 찾는 것이 핵심입니다. 기호로는 \(u = g(x)\), \(du = g'(x)\,dx\)로 바꿔 씁니다.

정적분: \(\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\). 구간도 \(u\)의 값으로 바꾸면 \(x\)로 되돌릴 필요가 없습니다.

문제. (가) \(\displaystyle\int \frac{x}{\sqrt{1 + x^2}}\,dx\) (나) \(\displaystyle\int_0^{\pi/2}\sin^3 x\cos x\,dx\) (다) \(\displaystyle\int \tan x\,dx\) (라) \(\displaystyle\int_0^1 x\sqrt{1 - x}\,dx\)

풀이

  1. (가) \(u = 1 + x^2\), \(du = 2x\,dx\), 곧 \(x\,dx = \frac12du\). \(\int\frac{1}{\sqrt u}\cdot\frac12du = \sqrt u + C = \sqrt{1 + x^2} + C\).
    분자 \(x\)가 \(1 + x^2\)의 도함수(상수배)다.
  2. (나) \(u = \sin x\), \(du = \cos x\,dx\). \(x: 0 \to \frac\pi2\)이면 \(u: 0 \to 1\). \(\int_0^1 u^3\,du = \frac14\).
    구간을 바꿨으므로 \(x\)로 되돌리지 않는다.
  3. (다) \(\tan x = \frac{\sin x}{\cos x}\), \(u = \cos x\), \(du = -\sin x\,dx\). \(\int\frac{-du}{u} = -\ln|u| + C = \ln|\sec x| + C\).
    분자가 분모의 도함수(부호 차)인 꼴 \(\int\frac{g'}{g} = \ln|g|\).
  4. (라) \(u = 1 - x\), \(x = 1 - u\), \(dx = -du\), \(x: 0 \to 1\)이면 \(u: 1 \to 0\). \(\int_1^0(1 - u)\sqrt u\,(-du) = \int_0^1(u^{1/2} - u^{3/2})\,du = \frac23 - \frac25 = \frac{4}{15}\).
    짝이 바로 보이지 않을 때는 근호 속을 \(u\)로 두고 나머지 \(x\)도 \(u\)로 쓴다. 음수 부호로 구간을 뒤집었다.

의미

치환은 "적분 변수의 이름과 눈금을 바꾸는" 일입니다. \(du = g'(x)\,dx\)는 눈금이 \(g'(x)\)배로 늘어난다는 뜻이고, 이것이 공통2에서 여러 변수의 눈금 배율인 야코비안 \(\left|\frac{\partial(x,y)}{\partial(u,v)}\right|\)이 됩니다.

검산

부정적분은 미분해서 확인합니다. (가) \(\frac{d}{dx}\sqrt{1 + x^2} = \frac{x}{\sqrt{1 + x^2}}\). (다) \(\frac{d}{dx}\ln|\sec x| = \frac{\sec x\tan x}{\sec x} = \tan x\). (라) \([0,1]\)에서 \(0 \le x\sqrt{1-x} \le \max = \frac{2}{3\sqrt3} \approx 0.385\)이므로 답 \(0.267\)은 그 범위 안입니다.

무엇을 \(u\)로 둘까

  • 합성함수의 "안쪽"(괄호 속, 근호 속, 지수, 분모).
  • 도함수가 피적분함수에 (상수배까지) 따로 곱해져 있는 것.
  • 잘못 골랐다면 \(du\)로 바꾼 뒤 \(x\)가 남습니다. 그때는 다른 \(u\)를 시도하거나 (라)처럼 \(x\)를 \(u\)로 표현합니다.

흔한 오해

  • 정적분에서 구간을 안 바꾸기: (나)에서 \(\int_0^{\pi/2}u^3du\)로 쓰면 틀립니다. 구간을 바꾸거나, \(x\)로 되돌린 뒤 원래 구간을 넣거나 둘 중 하나만 합니다.
  • \(dx\)를 빠뜨리기: \(dx\)를 \(du\)로 바꾸는 단계에서 상수 \(\frac12\), 부호 −가 생깁니다.
4.3.3

예제대칭으로 적분을 줄이기: 기함수, 우함수, 그 밖의 대칭

치환 x → −x · x → a+b−x

다루는 성취기준 [공통1-04-03]

정리

\(f\)가 \([-a, a]\)에서 연속일 때

· \(f\)가 우함수(\(f(-x) = f(x)\))이면 \(\int_{-a}^{a} f = 2\int_0^a f\).

· \(f\)가 기함수(\(f(-x) = -f(x)\))이면 \(\int_{-a}^{a} f = 0\).

증명

  1. \(\int_{-a}^a f = \int_{-a}^0 f + \int_0^a f\).
    구간 가법성.
  2. 첫 항에 \(x = -u\), \(dx = -du\): \(\int_{-a}^0 f(x)\,dx = \int_{a}^{0} f(-u)(-du) = \int_0^a f(-u)\,du\).
    치환적분. \(x: -a \to 0\)이면 \(u: a \to 0\), 음수 부호로 구간을 뒤집음.
  3. 따라서 \(\int_{-a}^a f = \int_0^a [f(-u) + f(u)]\,du\). 우함수이면 괄호가 \(2f(u)\), 기함수이면 0.
    적분 변수의 이름은 상관없다(\(u\)를 \(x\)로 바꿔도 같은 값).

3단계의 식 \(\int_{-a}^a f = \int_0^a[f(x) + f(-x)]\,dx\)는 기우와 상관없이 언제나 성립하는 일반식입니다.

먼저 예측

(나)의 피적분함수 \(\frac{1}{1 + e^x}\)는 \(x = 0\)에서 \(\frac12\)이고, 왼쪽에서는 1에, 오른쪽에서는 0에 가깝습니다. 그래프만 보고 \(\int_{-1}^1\)의 값을 짐작해 보세요.

예측 확인

1입니다. 그래프가 점 \((0, \frac12)\)에 대해 대칭이라 평균값이 \(\frac12\)이고, 구간 길이가 2입니다.

문제. (가) \(\displaystyle\int_{-2}^{2}\left(x^5\cos x + 3x^2 + \frac{\sin x}{1 + x^4}\right)dx\) (나) \(\displaystyle\int_{-1}^{1}\frac{1}{1 + e^{x}}\,dx\) (다) \(\displaystyle\int_0^{\pi/2}\frac{\sin x}{\sin x + \cos x}\,dx\)

풀이

  1. (가) \(x^5\cos x\)는 기함수×우함수 = 기함수, \(\frac{\sin x}{1+x^4}\)도 기함수. 둘의 적분은 0. 남는 것: \(\int_{-2}^2 3x^2\,dx = 2\int_0^2 3x^2\,dx = 16\).
    기함수와 우함수의 곱은 기함수: \((-x)^5\cos(-x) = -x^5\cos x\).
  2. (나) \(f(x) = \frac{1}{1 + e^x}\)은 기우 어느 쪽도 아니다. 일반식을 쓴다: \(f(x) + f(-x) = \frac{1}{1 + e^x} + \frac{1}{1 + e^{-x}} = \frac{1}{1 + e^x} + \frac{e^x}{e^x + 1} = 1\).
    \(\frac{1}{1 + e^{-x}}\)의 분자·분모에 \(e^x\)를 곱했다.
  3. 따라서 \(\int_{-1}^1 f = \int_0^1 1\,dx = 1\).
    증명 3단계의 일반식. \(f - \frac12\)이 기함수라는 뜻이기도 하다.
  4. (다) \(I = \int_0^{\pi/2}\frac{\sin x}{\sin x + \cos x}dx\). \(x = \frac\pi2 - u\)로 치환하면 \(\sin \leftrightarrow \cos\)이 바뀌어 \(I = \int_0^{\pi/2}\frac{\cos u}{\cos u + \sin u}du\).
    \(x \to a + b - x\) 대칭(\(a = 0, b = \frac\pi2\)). 구간은 그대로, 함수만 바뀐다.
  5. 두 식을 더하면 \(2I = \int_0^{\pi/2} 1\,dx = \frac\pi2\), 곧 \(I = \frac\pi4\).
    부정적분을 구하지 않고 값을 얻었다.

의미

적분하기 전에 대칭을 먼저 보면 계산이 반으로 줄거나, (나)와 (다)처럼 부정적분 없이 값이 나옵니다. 물리에서 질량 중심이 대칭축 위에 있다는 것, 신호 처리에서 사인과 코사인의 곱을 한 주기 적분하면 0이라는 것(푸리에 급수)이 모두 이 원리입니다.

검산

(나) 피적분함수는 \(\frac12\)을 중심으로 대칭이고 \(x = 0\)에서 \(\frac12\). 구간 길이 2 × 평균 \(\frac12\) = 1. (다) 피적분함수는 0에서 1로 가며 \(\frac\pi4\)에서 \(\frac12\). 평균 \(\frac12\) × 길이 \(\frac\pi2\) = \(\frac\pi4\). 둘 다 맞습니다.

흔한 오해

  • 구간이 대칭이 아닌데 쓰기: \(\int_{-1}^{2}x^3dx \ne 0\). 구간이 원점 대칭이어야 합니다.
  • 이상적분에서 쓰기: \(\int_{-\infty}^{\infty}x\,dx\)는 0이 아니라 발산입니다. 양쪽이 각각 수렴해야 합니다.
