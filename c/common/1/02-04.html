2.4.1자연로그의 도함수

\(y = \ln x\)는 \(e^y = x\)와 같은 뜻입니다. 이 관계식을 음함수 미분법으로 미분하면 \(e^y\dfrac{dy}{dx} = 1\), 따라서 \(\dfrac{dy}{dx} = \dfrac{1}{e^y} = \dfrac1x\)입니다.

정리 2.4.1

\(\dfrac{d}{dx}\ln x = \dfrac1x\) (\(x > 0\)), \(\dfrac{d}{dx}\ln|x| = \dfrac1x\) (\(x \ne 0\)), \(\dfrac{d}{dx}\log_a x = \dfrac{1}{x\ln a}\).

두 번째 식은 \(x < 0\)일 때 \(\ln|x| = \ln(-x)\)를 연쇄법칙으로 미분하면 \(\dfrac{1}{-x}\cdot(-1) = \dfrac1x\)이 되어 얻습니다. 세 번째 식은 \(\log_a x = \dfrac{\ln x}{\ln a}\)에서 나옵니다. 연쇄법칙과 합치면 \(\dfrac{d}{dx}\ln u = \dfrac{u'}{u}\)인데, 이 꼴은 적분(\(\int\frac{u'}{u}dx = \ln|u|\))에서도 계속 나옵니다.

예제 2.4.2

(가) \(y = \ln(x^2 + 1)\) (나) \(y = \ln\sqrt{\dfrac{x + 1}{x - 1}}\)을 미분하여라.

풀이. (가) \(y' = \dfrac{2x}{x^2 + 1}\).

(나) 바로 미분하면 복잡하니 먼저 로그의 성질로 풀어 둡니다: \(y = \frac12\ln(x + 1) - \frac12\ln(x - 1)\). 그러면 \(y' = \dfrac{1}{2(x + 1)} - \dfrac{1}{2(x - 1)} = \dfrac{-1}{x^2 - 1}\). 로그를 미분하기 전에 곱·몫·거듭제곱을 합·차·상수배로 바꾸면 계산이 크게 줄어듭니다.

2.4.2로그 미분법

\(y = x^x\)은 밑과 지수에 모두 \(x\)가 있어 \((x^n)' = nx^{n-1}\)도 \((a^x)' = a^x\ln a\)도 쓸 수 없습니다. 이럴 때 양변에 로그를 취하면 지수가 앞으로 내려와 곱이 됩니다.

예제 2.4.3

\(y = x^x\) (\(x > 0\))을 미분하여라.

풀이. \(\ln y = x\ln x\). 양변을 \(x\)로 미분하면(왼쪽은 음함수 미분) \(\dfrac{y'}{y} = \ln x + x\cdot\dfrac1x = \ln x + 1\). 따라서 \(y' = x^x(\ln x + 1)\).

로그 미분법은 여러 인수의 곱과 몫을 미분할 때도 편합니다. 예를 들어 \(y = \dfrac{x^{3/4}\sqrt{x^2 + 1}}{(3x + 2)^5}\)이면 \(\ln y = \frac34\ln x + \frac12\ln(x^2 + 1) - 5\ln(3x + 2)\)로 바꾸어 미분하고, 마지막에 \(y\)를 곱합니다.

2.4.3역삼각함수의 도함수

\(y = \arcsin x\)는 \(\sin y = x\), \(-\frac\pi2 \le y \le \frac\pi2\)와 같은 뜻입니다. 음함수 미분하면 \(\cos y\,\dfrac{dy}{dx} = 1\), 곧 \(\dfrac{dy}{dx} = \dfrac{1}{\cos y}\). 이 범위의 \(y\)에서 \(\cos y \ge 0\)이므로 \(\cos y = \sqrt{1 - \sin^2 y} = \sqrt{1 - x^2}\)입니다.

\(y = \arctan x\)는 \(\tan y = x\)이므로 \(\sec^2 y\,\dfrac{dy}{dx} = 1\), 그리고 \(\sec^2 y = 1 + \tan^2 y = 1 + x^2\)입니다.

정리 2.4.4 \[\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1 - x^2}}, \qquad \frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1 - x^2}}, \qquad \frac{d}{dx}\arctan x = \frac{1}{1 + x^2}.\]

\(\arccos\)는 \(\arcsin x + \arccos x = \frac\pi2\)(1.2절 연습문제)이므로 \(\arcsin\)의 도함수에 부호만 바꾼 것입니다. 이 세 공식은 거꾸로 읽으면 적분 공식이 됩니다: \(\int\dfrac{dx}{1 + x^2} = \arctan x + C\). 유리함수를 적분할 때(5.4절) 이것이 꼭 필요합니다.

예제 2.4.5

\(y = \arctan(\sqrt x)\)를 미분하여라.

풀이. 연쇄법칙으로 \(y' = \dfrac{1}{1 + (\sqrt x)^2}\cdot\dfrac{1}{2\sqrt x} = \dfrac{1}{2\sqrt x(1 + x)}\).

주의\(\ln(x^2 + 1)\)의 도함수를 \(\dfrac{1}{x^2 + 1}\)이라고 쓰면 속함수의 도함수 \(2x\)를 빠뜨린 것입니다. 또 \(x^x\)를 \(x\cdot x^{x-1}\)로 미분하면 틀립니다. 지수에 \(x\)가 있으면 로그 미분법을 씁니다.
요약
  1. \((\ln x)' = \dfrac1x\), \((\ln u)' = \dfrac{u'}{u}\), \((\log_a x)' = \dfrac{1}{x\ln a}\).
  2. 로그 미분법: 양변에 \(\ln\)을 취해 곱·몫·거듭제곱을 풀어 놓고 미분한다. \((x^x)' = x^x(\ln x + 1)\).
  3. \((\arcsin x)' = \dfrac{1}{\sqrt{1 - x^2}}\), \((\arctan x)' = \dfrac{1}{1 + x^2}\).

2.4.4연습문제

기본

  1. 미분하여라. (가) \(\ln(3x)\) (나) \(\log_2(x^2)\) (다) \(\arcsin(2x)\)
    답

    (가) \(\frac1x\) (나) \(\frac{2}{x\ln2}\) (다) \(\frac{2}{\sqrt{1 - 4x^2}}\)

  2. \(y = x\ln x - x\)를 미분하여라.
    답

    \(\ln x + 1 - 1 = \ln x\).

응용

  1. 로그 미분법으로 \(y = x^{\sin x}\)을 미분하여라.
    답

    \(\ln y = \sin x\ln x\), \(\frac{y'}{y} = \cos x\ln x + \frac{\sin x}{x}\). \(y' = x^{\sin x}\left(\cos x\ln x + \frac{\sin x}{x}\right)\).

  2. \(y = \arctan\frac1x\)과 \(y = \arctan x\)의 도함수를 비교하고 그 이유를 설명하여라.
    답

    \(\left(\arctan\frac1x\right)' = \frac{1}{1 + 1/x^2}\cdot\left(-\frac{1}{x^2}\right) = -\frac{1}{1 + x^2}\). 부호만 다르다. \(x > 0\)이면 \(\arctan x + \arctan\frac1x = \frac\pi2\)로 합이 상수이기 때문이다.

2.4.2

예제역삼각함수의 도함수와 로그 미분법

역함수 미분 · 로그 미분

다루는 성취기준 [공통1-02-04]

도구: 역함수의 도함수

\(f\)가 일대일이고 미분 가능하며 \(f'(x) \ne 0\)이면, \(y = f(x)\)에서 \((f^{-1})'(y) = \dfrac{1}{f'(x)}\)입니다. \(f(f^{-1}(y)) = y\)를 \(y\)로 미분하면 \(f'(f^{-1}(y))\cdot(f^{-1})'(y) = 1\)이 되기 때문입니다(연쇄 법칙). 그래프로는 \(y = x\)에 대칭이동하면 기울기가 역수가 된다는 뜻입니다.

문제 1. \(\dfrac{d}{dx}\arcsin x = \dfrac{1}{\sqrt{1 - x^2}}\) \((-1 < x < 1)\)를 유도하세요.

풀이

  1. \(y = \arcsin x\)로 두면 \(\sin y = x\), \(-\frac\pi2 \le y \le \frac\pi2\).
    \(\arcsin\)의 정의(앞 단원의 정의역 제한).
  2. \(x\)로 미분: \(\cos y\cdot y' = 1\), 곧 \(y' = \dfrac{1}{\cos y}\).
    음함수 미분(연쇄 법칙).
  3. \(\cos y = \pm\sqrt{1 - \sin^2 y} = \pm\sqrt{1 - x^2}\). \(y \in \left(-\frac\pi2, \frac\pi2\right)\)에서 \(\cos y > 0\)이므로 부호는 +.
    \(\sin^2 + \cos^2 = 1\). 끝점 \(y = \pm\frac\pi2\)(\(x = \pm1\))에서는 \(\cos y = 0\)이라 미분 불가능.
  4. 따라서 \((\arcsin x)' = \dfrac{1}{\sqrt{1 - x^2}}\).
    3단계를 2단계에 대입. 같은 방법으로 \((\arctan x)' = \frac{1}{1+x^2}\) (\(1 + \tan^2 y = \sec^2 y\) 사용), \((\arccos x)' = -\frac{1}{\sqrt{1-x^2}}\).

3단계에서 부호를 고르는 근거가 바로 정의역 제한입니다. \(\arcsin\)의 치역을 \(\left[-\frac\pi2, \frac\pi2\right]\)로 정한 덕에 도함수가 늘 양수로 깔끔하게 나옵니다.

문제 2. \(y = x^{x}\ (x > 0)\)과 \(y = \dfrac{(x^2+1)^3\sqrt{x-1}}{(2x+3)^4}\)를 미분하세요.

전략

\(x^x\)는 밑과 지수가 모두 변하므로 \((x^n)' = nx^{n-1}\)도, \((a^x)' = a^x\ln a\)도 쓸 수 없습니다. 둘째 식은 곱과 몫이 겹겹이라 곱·몫의 법칙으로는 길어집니다. 양변에 로그를 취하면 거듭제곱은 곱으로, 곱과 몫은 합과 차로 바뀌어 미분이 쉬워집니다(로그 미분법).

풀이

  1. \(\ln y = x\ln x\). 양변을 미분: \(\dfrac{y'}{y} = \ln x + 1\).
    \((\ln y)' = \frac{y'}{y}\) (연쇄 법칙), 오른쪽은 곱의 법칙.
  2. 따라서 \((x^x)' = x^x(\ln x + 1)\).
    양변에 \(y = x^x\)를 곱함. \(y > 0\)이라 로그를 취할 수 있었다.
  3. 둘째 식: \(\ln|y| = 3\ln(x^2+1) + \frac12\ln(x - 1) - 4\ln|2x+3|\).
    로그의 성질. 음수일 수 있는 양에는 절댓값을 붙인다(\(\frac{d}{dx}\ln|u| = \frac{u'}{u}\)도 성립).
  4. 미분하면 \(\dfrac{y'}{y} = \dfrac{6x}{x^2+1} + \dfrac{1}{2(x-1)} - \dfrac{8}{2x+3}\), 곧 \(y' = y\left(\dfrac{6x}{x^2+1} + \dfrac{1}{2(x-1)} - \dfrac{8}{2x+3}\right)\).
    각 항을 연쇄 법칙으로 미분하고 \(y\)를 곱함. 답에 \(y\)를 원래 식으로 써도 된다.

의미

초월함수 \(\arcsin x\), \(\arctan x\)의 도함수가 \(\frac{1}{\sqrt{1-x^2}}\), \(\frac{1}{1+x^2}\)처럼 대수함수라는 점이 중요합니다. 그래서 적분에서 \(\int\frac{dx}{1+x^2} = \arctan x\)가 나오고, 6단원의 삼각 치환과 부분분수가 역삼각함수로 끝납니다. 로그 미분은 곱을 합으로 바꾸는 로그의 성질을 미분에 쓴 것입니다.

검산

\(x^x\)를 \(e^{x\ln x}\)로 쓰고 연쇄 법칙을 쓰면 \(e^{x\ln x}(\ln x + 1)\). 같은 결과입니다. 수치로: \(x = 1\)에서 \(y' = 1\cdot(0 + 1) = 1\), 차분 \(\frac{1.001^{1.001} - 1}{0.001} \approx 1.0010\). 맞습니다.

흔한 오해

  • "\((x^x)' = x\cdot x^{x-1} = x^x\)." 거듭제곱 법칙은 지수가 상수일 때만 씁니다.
  • "\((\arcsin x)' = \frac{1}{\cos x}\)." 2단계의 \(\cos y\)에서 \(y\)는 \(\arcsin x\)입니다. 반드시 \(x\)로 다시 써야 합니다.
