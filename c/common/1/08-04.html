8.4.1교대급수

\(1 - \frac12 + \frac13 - \frac14 + \cdots\)처럼 부호가 번갈아 바뀌는 급수를 교대급수라 합니다. 부분합을 수직선에 찍어 보면 1, 0.5, 0.833, 0.583, 0.783, …으로 앞뒤로 흔들리면서 그 폭이 점점 줄어듭니다. 앞으로 갔다가 조금 덜 뒤로, 다시 조금 덜 앞으로 가니 어떤 값으로 모여듭니다.

정리 8.4.1 (교대급수 판정법)

\(b_n > 0\)이 감소하고(\(b_{n+1} \le b_n\)) \(\lim b_n = 0\)이면 \(\sum(-1)^{n-1}b_n\)은 수렴한다. 또 합을 \(s_n\)으로 어림한 오차는 \(|s - s_n| \le b_{n+1}\)이다.

오차 공식이 유용합니다. 다음 항의 크기보다 오차가 작다는 뜻이므로, 원하는 정확도가 될 때까지 몇 항을 더해야 하는지 바로 알 수 있습니다. 예를 들어 위 급수(합은 \(\ln 2 \approx 0.693\))를 오차 0.01 이내로 구하려면 \(\frac{1}{n + 1} < 0.01\), 곧 100항 가까이 더해야 합니다. 이 급수는 수렴은 하지만 느립니다.

8.4.2절대수렴과 조건수렴

정의 8.4.2 (절대수렴)

\(\sum|a_n|\)이 수렴하면 \(\sum a_n\)이 절대수렴한다고 한다.

정의 8.4.3 (조건수렴)

\(\sum a_n\)은 수렴하지만 \(\sum|a_n|\)은 발산하면 조건수렴한다고 한다.

정리 8.4.4

절대수렴하는 급수는 수렴한다.

부호를 모두 양수로 바꿔도 수렴한다면, 일부를 음수로 바꾸면 서로 지워지는 부분이 생겨 더 잘 수렴할 수밖에 없다는 뜻입니다.

예제 8.4.5

(가) \(\sum\frac{(-1)^{n-1}}{n}\) (나) \(\sum\frac{(-1)^{n-1}}{n^2}\) (다) \(\sum\frac{\cos n}{n^2}\)

풀이. (가) 교대급수 판정법으로 수렴하지만, 절댓값의 급수는 조화급수라 발산합니다. 조건수렴.

(나) 절댓값의 급수 \(\sum\frac{1}{n^2}\)이 수렴하므로 절대수렴.

(다) 부호가 규칙적으로 바뀌지 않아 교대급수가 아닙니다. 그러나 \(\left|\frac{\cos n}{n^2}\right| \le \frac{1}{n^2}\)이므로 비교 판정법으로 절대수렴하고, 따라서 수렴합니다.

조건수렴하는 급수는 항의 순서를 바꾸면 합이 달라질 수 있습니다(리만 재배열 정리). 절대수렴하는 급수는 순서를 어떻게 바꿔도 합이 같습니다. 그래서 무한 급수를 보통의 합처럼 마음대로 다루려면 절대수렴이 필요합니다.

요약
  1. 교대급수: 항의 크기가 감소하며 0으로 가면 수렴. 오차 \(\le\) 다음 항의 크기.
  2. 절대수렴(\(\sum|a_n|\) 수렴)이면 수렴한다.
  3. 조건수렴: 수렴하지만 절대수렴하지 않음. 예 \(\sum\frac{(-1)^{n-1}}{n}\).

8.4.3연습문제

기본

  1. 절대수렴, 조건수렴, 발산 가운데 무엇인가? (가) \(\sum\frac{(-1)^n}{\sqrt n}\) (나) \(\sum\frac{(-1)^n}{n^3}\) (다) \(\sum(-1)^n\frac{n}{n + 1}\)
    답

    (가) 조건수렴 (나) 절대수렴 (다) 항이 0으로 가지 않아 발산

응용

  1. \(\sum_{n=0}^\infty\frac{(-1)^n}{n!}\)의 합(\(e^{-1}\))을 오차 0.001 이내로 구하려면 몇 항까지 더해야 하는가?
    답

    \(\frac{1}{n!} < 0.001\)이 처음 되는 \(n = 7\) (\(7! = 5040\)). \(n = 0\)부터 6까지 7개 항을 더하면 된다: \(s \approx 0.3681\).

8.4.2

설명절대수렴과 조건수렴은 무엇이 다른가

재배열 · 리만 재배열 정리

다루는 성취기준 [공통1-08-04]

정의

\(\sum|a_n|\)이 수렴하면 \(\sum a_n\)은 절대수렴한다. \(\sum a_n\)은 수렴하지만 \(\sum|a_n|\)은 발산하면 조건수렴한다.

절대수렴하면 수렴한다

  1. \(0 \le a_n + |a_n| \le 2|a_n|\).
    \(a_n \ge 0\)이면 \(2a_n\), \(a_n < 0\)이면 0.
  2. \(\sum 2|a_n|\)이 수렴하므로 비교 판정으로 \(\sum(a_n + |a_n|)\)이 수렴한다.
    양의 항 급수의 비교 판정.
  3. \(\sum a_n = \sum(a_n + |a_n|) - \sum|a_n|\)은 수렴하는 두 급수의 차이므로 수렴한다.
    수렴 급수의 선형성.

그래서 부호가 섞인 급수는 먼저 \(\sum|a_n|\)에 양의 항 판정법(비교, 비, 근, 적분)을 씁니다. 수렴하면 끝, 발산하면 교대급수 판정 등으로 조건수렴인지 봅니다.

차이가 드러나는 곳: 순서 바꾸기

유한 합은 순서를 바꿔도 같습니다. 무한 합은 그렇지 않을 수 있습니다.

교대 조화급수 \(1 - \frac12 + \frac13 - \frac14 + \cdots = \ln 2\) (8-05 카드에서 Taylor 급수로 확인)는 조건수렴합니다. 항의 순서를 "양수 하나, 음수 둘"로 바꿔 봅니다.

\[\left(1 - \tfrac12\right) - \tfrac14 + \left(\tfrac13 - \tfrac16\right) - \tfrac18 + \left(\tfrac15 - \tfrac1{10}\right) - \tfrac1{12} + \cdots = \tfrac12 - \tfrac14 + \tfrac16 - \tfrac18 + \tfrac1{10} - \cdots\]

오른쪽은 \(\frac12\left(1 - \frac12 + \frac13 - \cdots\right) = \frac12\ln 2\)입니다. 같은 항들을 같은 횟수로 썼는데 합이 절반이 되었습니다.

정리 (증명은 해석학)

절대수렴하는 급수는 어떻게 재배열해도 같은 합으로 수렴한다.

리만 재배열 정리: 조건수렴하는 급수는 재배열해서 임의의 실수로 수렴하게 하거나 발산하게 할 수 있다.

왜 그런가 (직관)

조건수렴하는 급수에서 양수 항만 모은 급수와 음수 항만 모은 급수는 둘 다 발산합니다(하나라도 수렴하면 절대수렴하거나 원래 급수가 발산). 무한히 큰 양의 "저수지"와 음의 "저수지"가 있으니, 목표값을 넘을 때까지 양수를 더하고, 넘으면 음수를 더하기를 되풀이하면 어떤 목표에도 다가갈 수 있습니다. 항이 0으로 가므로 흔들림도 점점 작아집니다. 절대수렴하는 급수는 두 저수지가 모두 유한해서 이렇게 할 수 없습니다.

예

  • \(\sum\frac{(-1)^n}{n^2}\): \(\sum\frac1{n^2}\) 수렴 → 절대수렴.
  • \(\sum\frac{(-1)^n}{n}\): 교대급수로 수렴, \(\sum\frac1n\) 발산 → 조건수렴.
  • \(\sum\frac{\sin n}{n^2}\): 교대급수가 아니지만 \(\left|\frac{\sin n}{n^2}\right| \le \frac{1}{n^2}\) → 절대수렴, 따라서 수렴.
  • \(\sum(-1)^n\frac{n}{n+1}\): 항이 0으로 가지 않음 → 발산(절대도 조건도 아님).

흔한 오해

  • "수렴하는 급수는 괄호를 풀거나 순서를 바꿔도 된다." 괄호를 넣는 것은 괜찮지만, 순서 바꾸기는 절대수렴할 때만 안전합니다. 또 괄호를 푸는 것은 안 될 수 있습니다: \((1 - 1) + (1 - 1) + \cdots = 0\)이지만 \(1 - 1 + 1 - \cdots\)은 발산합니다.

8.4.3

실습부분합이 어디로 가는가

실습 · 수렴, 발산, 교대급수

다루는 성취기준 [공통1-08-02] [공통1-08-04]

목표

여러 급수의 부분합 \(S_N\)을 막대그래프로 그려, 수렴하는 급수와 발산하는 급수의 모습을 비교합니다. 항이 0으로 가도 발산할 수 있음(조화급수)과, 교대급수의 오차가 다음 항 이하라는 것을 확인합니다. 성취기준 [공통1-08-02], [공통1-08-04].

준비

막대 하나가 부분합 하나입니다. 극한이 알려진 급수는 주황 점선으로 극한을 표시합니다. 등비급수의 공비 \(r\)는 등비급수를 고를 때만 쓰입니다.

절차

  1. 등비급수에서 \(r = 0.5, 0.9, -0.5, 1.0\)의 부분합 모양을 비교한다.
  2. 조화급수와 \(\sum1/n^2\)을 \(N = 200\)까지 비교한다.
  3. 교대 조화급수에서 남은 오차가 출력의 "오차 한계" 이하인지 \(N\)을 바꿔 가며 확인한다.
  4. \(\sum1/n!\)이 몇 항 만에 \(e\)에 소수 여섯째 자리까지 맞는지 찾는다.

기대 결과

  • \(|r| < 1\)이면 \(\frac{1}{1 - r}\)에 다가간다. \(r\)이 음수면 위아래로 번갈아 다가간다. \(r = 1\)이면 직선으로 커진다.
  • 조화급수는 아주 느리게(\(\ln N\) 정도) 끝없이 커지고, \(\sum1/n^2\)은 \(\frac{\pi^2}{6} \approx 1.645\)에 다가간다.
  • 교대급수의 오차는 늘 \(\frac{1}{N + 1}\) 이하.
  • \(\sum1/n!\)은 10항 정도면 \(e\)에 매우 가깝다.

분석

  1. 조화급수의 항도 0으로 가는데 왜 발산할까요? 적분 판정법 \(\int_1^\infty\frac{dx}{x}\)과 연결해 보세요.
  2. 교대 조화급수는 수렴하지만 절대수렴하지 않습니다. 절댓값을 씌운 급수는 이 장치의 어느 급수인가요?

더 해 보기

조화급수의 부분합이 10을 넘으려면 대략 몇 항이 필요할까요? \(S_N \approx \ln N + 0.577\)로 어림해 보세요. 장치의 최대 \(N\)으로는 닿지 않습니다.
