8.4.1

예제거듭제곱급수의 수렴 반지름과 수렴 구간

비 판정 · 끝점 따로 확인

다루는 성취기준 [공통1-08-04]

알아 둘 사실

정리

거듭제곱급수 \(\sum c_n(x - a)^n\)에 대해 다음 중 하나가 성립한다. (i) \(x = a\)에서만 수렴 (\(R = 0\)). (ii) 모든 \(x\)에서 수렴 (\(R = \infty\)). (iii) 어떤 \(R > 0\)이 있어 \(|x - a| < R\)에서 절대수렴, \(|x - a| > R\)에서 발산.

근거의 핵심: \(x_0\)에서 수렴하면 항 \(c_nx_0^n\)이 유계이고, \(|x| < |x_0|\)인 \(x\)에서는 \(|c_nx^n| \le M\left|\frac{x}{x_0}\right|^n\)이라 기하급수와 비교됩니다. 그래서 수렴하는 영역은 \(a\)를 중심으로 한 구간입니다. 끝점 \(x = a \pm R\)에서는 무엇이든 일어날 수 있어서 따로 확인해야 합니다.

\(\displaystyle\sum_{n=1}^\infty\frac{(x - 2)^n}{n\,3^n}\)의 수렴 반지름과 수렴 구간을 구하세요.

풀이

  1. \(a_n = \frac{(x-2)^n}{n3^n}\). \(\left|\frac{a_{n+1}}{a_n}\right| = \frac{|x - 2|^{n+1}}{(n+1)3^{n+1}}\cdot\frac{n3^n}{|x-2|^n} = \frac{n}{n+1}\cdot\frac{|x - 2|}{3} \to \frac{|x-2|}{3}\).
    \(x\)를 고정하고 수열로 보아 비 판정.
  2. \(\frac{|x-2|}{3} < 1 \iff |x - 2| < 3\)에서 절대수렴, \(> 1\)이면 발산. 따라서 \(R = 3\), 중심 2.
    비 판정의 결론.
  3. 끝점 \(x = 5\): \(\sum\frac{3^n}{n3^n} = \sum\frac1n\). 발산.
    \(\rho = 1\)이라 비 판정이 말해 주지 않는다. 대입해서 알려진 급수로.
  4. 끝점 \(x = -1\): \(\sum\frac{(-3)^n}{n3^n} = \sum\frac{(-1)^n}{n}\). 교대급수 판정으로 수렴(조건수렴).
    8-03 카드.
  5. 수렴 구간 \([-1, 5)\).
    열린구간 \((-1, 5)\)에 수렴하는 끝점만 붙인다.

검산

\(x = 2\) (중심)에서는 모든 항이 0이라 당연히 수렴합니다. \(t = \frac{x - 2}{3}\)로 두면 급수는 \(\sum\frac{t^n}{n} = -\ln(1 - t)\)이고, 이것은 \(-1 \le t < 1\)에서 수렴하는 잘 알려진 급수입니다. \(t = -1, 1\)이 \(x = -1, 5\)에 대응하므로 결과가 맞습니다.

수렴 구간 안에서 할 수 있는 것

\(|x - a| < R\)에서 거듭제곱급수는 항별로 미분, 적분할 수 있고 수렴 반지름은 그대로입니다(끝점의 수렴 여부는 바뀔 수 있음). 예: \(\frac{1}{1 - x} = \sum x^n\) (\(|x| < 1\))을 적분하면 \(-\ln(1 - x) = \sum\frac{x^{n+1}}{n+1}\), 미분하면 \(\frac{1}{(1 - x)^2} = \sum nx^{n-1}\).

흔한 오해

  • 끝점을 확인하지 않음: \(\sum\frac{x^n}{n^2}\)은 양 끝 수렴 \([-1,1]\), \(\sum x^n\)은 양 끝 발산 \((-1,1)\), \(\sum\frac{x^n}{n}\)은 한쪽만 \([-1, 1)\). \(R\)이 같아도 구간이 다릅니다.
  • \(|x - a|\)의 계수: \(\sum(2x)^n\)은 \(|2x| < 1\), 곧 \(R = \frac12\)입니다.
