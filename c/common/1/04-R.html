4.R.1

연습정적분 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통1-04-01] [공통1-04-02] [공통1-04-03] [공통1-04-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산리만 합의 극한으로 \(\int_1^3 (2x + 1)\,dx\)를 구하고, 사다리꼴 넓이로 검산하세요. [04-01]

    힌트 1

    \(\Delta x = \frac2n\), \(x_i = 1 + \frac{2i}{n}\).

    힌트 2

    \(\sum_{i=1}^n i = \frac{n(n+1)}{2}\).

    풀이

    \(R_n = \sum_{i=1}^n\left(3 + \frac{4i}{n}\right)\frac2n = \frac{6n}{n} + \frac{8}{n^2}\cdot\frac{n(n+1)}{2} = 6 + 4\left(1 + \frac1n\right) \to 10\).

    검산: 높이 3과 7, 폭 2인 사다리꼴 넓이 \(\frac{(3 + 7)}{2}\cdot2 = 10\).

  2. 계산\(\displaystyle\lim_{n\to\infty}\frac{1}{n}\left(\sqrt{\frac1n} + \sqrt{\frac2n} + \cdots + \sqrt{\frac nn}\right)\)을 정적분으로 나타내고 값을 구하세요. [04-01]

    힌트 1

    \(\frac1n\sum f\left(\frac in\right)\) 꼴입니다. \(f\)는?

    힌트 2

    \([0, 1]\)의 오른쪽 끝 리만 합.

    풀이

    \(f(x) = \sqrt x\), \([0,1]\) 등분할, 오른쪽 끝. 극한은 \(\int_0^1\sqrt x\,dx = \frac23\).

  3. 계산\(F(x) = \displaystyle\int_0^{x}\frac{t}{1 + t^4}\,dt\)의 증감과, \(G(x) = \displaystyle\int_x^{3x} e^{-t^2}dt\)의 도함수를 구하세요. [04-02]

    힌트 1

    \(F'(x) = \frac{x}{1+x^4}\) (FTC 1).

    힌트 2

    \(G = \int_0^{3x} - \int_0^{x}\), 연쇄 법칙.

    풀이

    \(F'(x) = \frac{x}{1 + x^4}\): \(x < 0\)에서 감소, \(x > 0\)에서 증가, \(x = 0\)에서 최솟값 \(F(0) = 0\).

    \(G'(x) = 3e^{-9x^2} - e^{-x^2}\).

  4. 계산연속함수 \(f\)가 \(\displaystyle\int_0^{x} f(t)\,dt = x^2\sin x\)를 만족할 때 \(f\left(\frac\pi2\right)\)를 구하세요. [04-02]

    힌트 1

    양변을 \(x\)로 미분하세요.

    힌트 2

    왼쪽은 FTC(1)로 \(f(x)\).

    풀이

    \(f(x) = 2x\sin x + x^2\cos x\). \(f\left(\frac\pi2\right) = 2\cdot\frac\pi2\cdot1 + 0 = \pi\).

  5. 계산\(\displaystyle\int\frac{e^{x}}{1 + e^{2x}}\,dx\)와 \(\displaystyle\int_1^{e}\frac{(\ln x)^2}{x}\,dx\)를 구하세요. [04-03]

    힌트 1

    첫째: \(e^{2x} = (e^x)^2\). 둘째: \(\ln x\)의 도함수가 보입니다.

    힌트 2

    첫째 \(u = e^x\) → \(\int\frac{du}{1 + u^2}\). 둘째 \(u = \ln x\), 구간 \(0 \to 1\).

    풀이

    \(u = e^x\), \(du = e^x dx\): \(\int\frac{du}{1+u^2} = \arctan(e^x) + C\).

    \(u = \ln x\), \(du = \frac{dx}{x}\), \(x: 1 \to e\)이면 \(u: 0 \to 1\): \(\int_0^1 u^2du = \frac13\).

  6. 도전다음을 구하세요: \(\displaystyle\int_{-\pi/2}^{\pi/2}\left(x^3 + 1\right)\cos x\,dx\)와 \(\displaystyle\int_0^{\pi}\frac{x\sin x}{1 + \cos^2 x}\,dx\). [04-03]

    힌트 1

    첫째: \(x^3\cos x\)는 기함수. 둘째: \(x \to \pi - x\)로 치환해 원래 적분과 더하세요.

    힌트 2

    둘째는 \(2I = \pi\int_0^\pi\frac{\sin x}{1 + \cos^2 x}dx\)가 되고, \(u = \cos x\)로 치환합니다.

    풀이

    첫째: \(\int x^3\cos x = 0\), \(\int_{-\pi/2}^{\pi/2}\cos x = 2\). 답 2.

    둘째: \(x = \pi - u\)로 두면 \(\sin x = \sin u\), \(\cos^2 x = \cos^2 u\)이므로 \(I = \int_0^\pi\frac{(\pi - u)\sin u}{1 + \cos^2 u}du\). 원래 식과 더하면 \(2I = \pi\int_0^\pi\frac{\sin x}{1 + \cos^2 x}dx\). \(u = \cos x\)이면 \(\int_{-1}^{1}\frac{du}{1 + u^2} = \frac\pi2\). 따라서 \(I = \frac{\pi^2}{4}\).

  7. 개념\(\int_{-1}^{1}f(x)\,dx = 0\)이면 \(f\)는 기함수인가요? [04-03]

    힌트 1

    04-03 절: 거꾸로는 성립하나요?

    힌트 2

    우함수인데 적분이 0인 예를 찾아보세요.

    풀이

    아닙니다. 기함수이면 적분이 0이지만 거꾸로는 성립하지 않습니다. 예: \(f(x) = x^2 - \frac13\)은 우함수인데 \(\int_{-1}^1\left(x^2 - \frac13\right)dx = \frac23 - \frac23 = 0\). 축 위 넓이와 아래 넓이가 우연히 같을 뿐입니다.

  8. 판단한 학생이 \(\displaystyle\int_{-1}^{2}\frac{dx}{x^2} = \left[-\frac1x\right]_{-1}^{2} = -\frac12 - 1 = -\frac32\)라고 계산했습니다. 이 답이 말이 안 되는 이유와 실제 값을 쓰세요. [04-02]

    힌트 1

    04-02 절: 피적분함수의 부호를 보세요.

    힌트 2

    기본정리를 쓸 조건(연속)이 \(x = 0\)에서 깨집니다.

    풀이

    \(\frac{1}{x^2} > 0\)인 함수의 적분이 음수일 수 없습니다. \(x = 0\)에서 연속이 아니라 기본정리를 쓸 수 없고, 이것은 이상적분입니다. \(\int_0^2\frac{dx}{x^2} = \lim_{t\to0^+}\left(\frac1t - \frac12\right) = \infty\)이므로 발산합니다.
