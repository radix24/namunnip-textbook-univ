6.3.1짧은 선분으로 어림하기

곡선의 길이를 재려면 실을 곡선에 대고 편 다음 자로 잽니다. 수학에서는 곡선 위에 점을 촘촘히 찍고 이웃한 점을 선분으로 이어 그 길이를 더합니다. 이웃한 두 점 사이에서 \(x\)가 \(\Delta x\), \(y\)가 \(\Delta y\)만큼 변하면 선분의 길이는 \(\sqrt{\Delta x^2 + \Delta y^2} = \sqrt{1 + \left(\frac{\Delta y}{\Delta x}\right)^2}\,\Delta x\)입니다. 점을 한없이 촘촘히 하면 \(\frac{\Delta y}{\Delta x}\)는 \(f'(x)\)가 됩니다.

정의 6.3.1 (곡선의 길이)

\(f'\)이 \([a, b]\)에서 연속이면 곡선 \(y = f(x)\) (\(a \le x \le b\))의 길이는

\[L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx.\]

\(ds = \sqrt{1 + (y')^2}\,dx\)를 "아주 짧은 곡선 조각의 길이"라고 읽으면 기억하기 쉽습니다. 피타고라스 정리 \(ds^2 = dx^2 + dy^2\)을 \(dx\)로 묶은 것입니다.

예제 6.3.2

\(y = x^{3/2}\), \(0 \le x \le 1\)의 길이를 구하여라.

풀이. \(y' = \frac32x^{1/2}\), \(1 + (y')^2 = 1 + \frac94x\). \(u = 1 + \frac94x\)로 치환하면

\[L = \int_0^1\sqrt{1 + \tfrac94x}\,dx = \frac49\cdot\frac23\left[u^{3/2}\right]_1^{13/4} = \frac{8}{27}\left(\frac{13\sqrt{13}}{8} - 1\right) = \frac{13\sqrt{13} - 8}{27} \approx 1.440.\]

검산: 두 끝점 \((0, 0)\)과 \((1, 1)\)을 잇는 선분의 길이는 \(\sqrt2 \approx 1.414\)입니다. 곡선은 선분보다 조금 길어야 하므로 1.440은 그럴듯합니다.

근호 안이 완전제곱이 되지 않으면 이 적분은 대개 계산하기 어렵습니다. 그래서 교재의 예제와 연습문제는 \(1 + (y')^2\)이 완전제곱이 되도록 골라 놓은 함수가 많습니다. 실제 문제에서는 수치 적분으로 어림합니다.

주의\(\sqrt{1 + (y')^2}\)을 \(1 + y'\)로 바꾸면 틀립니다. 근호는 합에 나누어 쓸 수 없습니다.
요약
  1. \(L = \int_a^b\sqrt{1 + (y')^2}\,dx\), \(ds^2 = dx^2 + dy^2\).
  2. 곡선의 길이는 끝점을 잇는 선분보다 길다(검산).

6.3.2연습문제

기본

  1. 직선 \(y = 2x\), \(0 \le x \le 3\)의 길이를 공식으로 구하고 피타고라스 정리와 비교하여라.
    답

    \(\int_0^3\sqrt5\,dx = 3\sqrt5\). 끝점 \((0,0)\), \((3,6)\)의 거리 \(\sqrt{45} = 3\sqrt5\)와 같다.

응용

  1. \(y = \cosh x\), \(0 \le x \le 1\)의 길이를 구하여라.
    답

    \(1 + \sinh^2x = \cosh^2x\). \(\int_0^1\cosh x\,dx = \sinh1 \approx 1.175\).

  2. \(y = \frac{x^3}{6} + \frac{1}{2x}\), \(1 \le x \le 2\)의 길이를 구하여라.
    답

    \(y' = \frac{x^2}{2} - \frac{1}{2x^2}\), \(1 + y'^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2\). \(\int_1^2\left(\frac{x^2}{2} + \frac{1}{2x^2}\right)dx = \frac76 + \frac14 = \frac{17}{12}\).

이 절의 성취기준[공통1-06-03] 계산

  1. 곡선의 길이를 적분으로 구할 수 있다.

6.3.2

유도곡선의 길이와 회전면의 넓이는 어디서 오는가

꺾은선 근사 · 원뿔대 근사

다루는 성취기준 [공통1-06-03]

무엇을 유도하나

\(f\)가 \([a,b]\)에서 연속인 도함수를 가질 때(매끄러운 곡선)

\[L = \int_a^b\sqrt{1 + [f'(x)]^2}\,dx, \qquad S = \int_a^b 2\pi f(x)\sqrt{1 + [f'(x)]^2}\,dx\ (f \ge 0,\ x\text{축 회전}).\]

길이의 유도

  1. \([a,b]\)를 분할하고 점 \(P_i = (x_i, f(x_i))\)를 이은 꺾은선의 길이를 곡선 길이의 근사로 삼는다.
    곡선 길이의 정의: 분할을 가늘게 할 때 꺾은선 길이의 극한.
  2. \(|P_{i-1}P_i| = \sqrt{\Delta x_i^2 + \Delta y_i^2}\), \(\Delta y_i = f(x_i) - f(x_{i-1})\).
    피타고라스.
  3. 평균값 정리로 \(\Delta y_i = f'(x_i^*)\Delta x_i\)인 \(x_i^* \in (x_{i-1}, x_i)\)가 있다. 따라서 \(|P_{i-1}P_i| = \sqrt{1 + f'(x_i^*)^2}\,\Delta x_i\).
    \(\Delta x_i\)를 근호 밖으로 묶었다. 평균값 정리 덕에 "≈"가 아니라 "="이다.
  4. 꺾은선 길이 \(\sum\sqrt{1 + f'(x_i^*)^2}\,\Delta x_i\)는 \(\sqrt{1 + f'^2}\)의 리만 합이고, 이 함수가 연속이라 \(\|P\| \to 0\)일 때 \(\int_a^b\sqrt{1 + f'^2}\,dx\)로 간다.
    5단원의 정의와 "연속이면 적분 가능".

기억법: 아주 짧은 조각에서 \(ds^2 = dx^2 + dy^2\), 곧 \(ds = \sqrt{1 + (dy/dx)^2}\,dx\).

회전면 넓이의 유도

각 선분 \(P_{i-1}P_i\)를 \(x\)축 둘레로 돌리면 원뿔대의 옆면이 됩니다. 원뿔대 옆면의 넓이는 \(2\pi\bar r\ell\) (\(\bar r\): 두 반지름의 평균, \(\ell\): 모선의 길이)입니다. \(\bar r = \frac{f(x_{i-1}) + f(x_i)}{2} \to f(x)\), \(\ell = \sqrt{1 + f'^2}\,\Delta x\)이므로 합의 극한이 \(\int 2\pi f\sqrt{1 + f'^2}\,dx\)입니다.

원판처럼 \(2\pi f\,dx\)로 하면 틀립니다. 경사진 띠의 폭은 \(dx\)가 아니라 \(ds\)이기 때문입니다. (부피에서는 \(dx\)로 해도 극한이 같지만, 넓이에서는 다릅니다.)

예제

(가) \(y = \frac23x^{3/2}\), \(0 \le x \le 3\)의 길이. (나) 반지름 \(r\)인 구의 겉넓이를 \(y = \sqrt{r^2 - x^2}\)을 돌려서 유도.

  1. (가) \(y' = x^{1/2}\), \(1 + y'^2 = 1 + x\). \(L = \int_0^3\sqrt{1 + x}\,dx = \left[\frac23(1 + x)^{3/2}\right]_0^3 = \frac23(8 - 1) = \frac{14}{3}\).
    근호 안이 깔끔해지도록 고른 예. 대부분의 곡선 길이는 부정적분을 식으로 못 써서 수치 적분을 쓴다.
  2. (나) \(y' = \frac{-x}{\sqrt{r^2 - x^2}}\), \(1 + y'^2 = \frac{r^2}{r^2 - x^2}\), \(y\sqrt{1 + y'^2} = \sqrt{r^2 - x^2}\cdot\frac{r}{\sqrt{r^2 - x^2}} = r\).
    근호가 소거되어 피적분함수가 상수가 된다.
  3. \(S = \int_{-r}^{r}2\pi r\,dx = 4\pi r^2\).
    끝점 \(x = \pm r\)에서 \(y'\)이 발산하지만 피적분함수는 상수 \(2\pi r\)로 연속이라 문제없다.

검산

(가) 끝점 \((0,0)\), \((3, 2\sqrt3)\) 사이의 직선 거리는 \(\sqrt{9 + 12} = \sqrt{21} \approx 4.58\)이고, 곡선 길이 \(4.67\)은 그보다 조금 깁니다. 맞습니다.
