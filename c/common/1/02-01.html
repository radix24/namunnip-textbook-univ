2.1.1평균 속도에서 순간 속도로

공을 떨어뜨리면 \(t\)초 뒤 떨어진 거리가 대략 \(s(t) = 4.9t^2\) m입니다. 처음 2초 동안 공은 \(s(2) - s(0) = 19.6\) m를 갔으므로, 그동안의 평균 속도는 \(\frac{19.6}{2} = 9.8\) m/s입니다.

그런데 "정확히 \(t = 2\)인 순간의 속도"는 무엇일까요? 한 순간에는 움직인 거리도 걸린 시간도 0이라, 나눗셈 \(\frac00\)으로는 답할 수 없습니다. 대신 \(t = 2\)부터 아주 짧은 시간 \(h\) 동안의 평균 속도를 계산해 봅니다.

\[\frac{s(2 + h) - s(2)}{h} = \frac{4.9(4 + 4h + h^2) - 19.6}{h} = \frac{19.6h + 4.9h^2}{h} = 19.6 + 4.9h \qquad (h \ne 0).\]

\(h\)를 0.1, 0.01, 0.001로 줄이면 평균 속도는 20.09, 19.649, 19.6049 m/s로 19.6에 한없이 다가갑니다. \(h\)가 음수여도(2초 직전 구간) 마찬가지입니다. 이 극한값 19.6 m/s를 \(t = 2\)에서의 순간 속도라고 부르는 것이 자연스럽습니다. 핵심은 \(h \ne 0\)일 때 먼저 식을 정리해 \(h\)를 약분하고, 그다음 극한을 취했다는 것입니다.

이 생각은 속도에만 쓰이지 않습니다. 함수의 값이 입력에 따라 얼마나 빨리 변하는지 묻는 모든 곳(비용의 증가율, 반응 속도, 곡선의 기울기)에 같은 방법을 씁니다. 그래서 함수 일반에 대해 정의합니다.

2.1.2미분계수의 정의

정의 2.1.1 (미분계수)

함수 \(f\)가 점 \(a\)를 포함하는 열린구간에서 정의되어 있다고 하자. 극한

\[f'(a) = \lim_{h\to0}\frac{f(a + h) - f(a)}{h}\]

가 존재하면 \(f\)는 \(a\)에서 미분 가능하다고 하고, 이 값을 \(a\)에서의 미분계수라고 한다.

정의의 각 부분이 무엇을 뜻하는지 차례로 봅시다. 분수 \(\frac{f(a+h) - f(a)}{h}\)는 그래프 위의 두 점 \((a, f(a))\)와 \((a + h, f(a + h))\)를 잇는 직선(할선)의 기울기이고, 구간 \([a, a+h]\)에서의 평균변화율입니다. \(h \to 0\)은 두 번째 점을 첫 번째 점 쪽으로 끌어오는 것이고, 그때 할선이 다가가는 직선이 접선입니다. 그래서 미분계수는 \(x = a\)에서의 접선의 기울기이며, 접선의 방정식은 \(y = f(a) + f'(a)(x - a)\)입니다.

"열린구간에서 정의되어 있다"는 조건은 \(h\)가 양수와 음수 양쪽에서 0으로 갈 수 있게 하려는 것입니다. 극한은 양쪽 극한이 모두 존재하고 같을 때만 존재하므로(1.3절), 미분 가능하려면 오른쪽에서 잰 기울기와 왼쪽에서 잰 기울기가 같아야 합니다.

\(x = a + h\)로 바꾸어 쓰면 같은 정의를 \(f'(a) = \lim_{x\to a}\frac{f(x) - f(a)}{x - a}\)로 쓸 수도 있습니다. 문제에 따라 편한 쪽을 씁니다.

예제 2.1.2

\(f(x) = x^2 - 3x\)의 \(x = 1\)에서의 미분계수와 접선을 구하여라.

풀이. 정의에 넣고, 분자를 정리해 \(h\)를 약분한 뒤 극한을 취합니다.

\[\frac{f(1 + h) - f(1)}{h} = \frac{(1 + h)^2 - 3(1 + h) - (-2)}{h} = \frac{-h + h^2}{h} = -1 + h \;\to\; -1.\]

따라서 \(f'(1) = -1\)이고, \(f(1) = -2\)이므로 접선은 \(y = -2 - (x - 1)\), 곧 \(y = -x - 1\)입니다. 검산 삼아 접선과 곡선의 교점을 구하면 \(x^2 - 3x = -x - 1\), 곧 \((x - 1)^2 = 0\)이라 \(x = 1\)에서만 만나고(중근), 접선답게 곡선에 닿기만 합니다.

2.1.3도함수

예제 2.1.2의 계산을 점 \(1\) 대신 임의의 점 \(x\)에서 하면, 미분계수가 \(x\)에 따라 어떻게 변하는지 알려 주는 새로운 함수를 얻습니다.

정의 2.1.3 (도함수)

\(f\)가 미분 가능한 각 점 \(x\)에 미분계수 \(f'(x)\)를 대응시킨 함수 \(f'\)을 \(f\)의 도함수라 한다. 도함수를 구하는 일을 미분한다고 한다. \(f'(x)\)를 \(\frac{df}{dx}\), \(\frac{dy}{dx}\) (\(y = f(x)\)), \(Df(x)\)로도 쓴다.

표기 \(\frac{dy}{dx}\)는 라이프니츠의 것으로, "\(y\)의 아주 작은 변화 \(dy\)와 \(x\)의 아주 작은 변화 \(dx\)의 비"라는 직관을 담고 있습니다. 엄밀하게는 하나의 기호이지 분수가 아니지만, 연쇄 법칙(2.2절)과 치환적분(4.3절)에서 분수처럼 다뤄도 맞는 결과가 나오도록 잘 만들어진 기호입니다.

예제 2.1.4

\(f(x) = \sqrt x\)의 도함수를 구하고, \(x = 0\)에서 미분 가능한지 판정하여라.

풀이. \(x > 0\)일 때 분자에 근호가 있어 그대로는 \(h\)를 약분할 수 없으므로, 분자와 분모에 \(\sqrt{x + h} + \sqrt x\)를 곱해 분자를 유리화합니다.

\[\frac{\sqrt{x + h} - \sqrt x}{h} = \frac{(x + h) - x}{h\left(\sqrt{x + h} + \sqrt x\right)} = \frac{1}{\sqrt{x + h} + \sqrt x} \;\to\; \frac{1}{2\sqrt x}.\]

마지막 단계에서 \(\sqrt{\ }\)가 연속이라 \(\sqrt{x + h} \to \sqrt x\)임을 썼습니다. 따라서 \(x > 0\)에서 \(f'(x) = \frac{1}{2\sqrt x}\).

\(x = 0\)에서는 \(f\)가 \(x \ge 0\)에서만 정의되어 왼쪽 극한을 생각할 수 없고, 오른쪽에서도 \(\frac{\sqrt h - 0}{h} = \frac{1}{\sqrt h} \to \infty\)입니다. 극한이 유한하지 않으므로 미분 가능하지 않습니다. 그래프로는 원점에서 접선이 수직으로 서 있습니다.

2.1.4미분 가능성과 연속성

그래프가 "매끄럽다"는 것과 "끊어지지 않았다"는 것은 어떤 관계일까요? 다음 정리는 한쪽 방향이 늘 성립함을 말합니다.

정리 2.1.5

\(f\)가 \(a\)에서 미분 가능하면, \(f\)는 \(a\)에서 연속이다.

증명.연속임을 보이려면 \(\lim_{h\to0}f(a + h) = f(a)\), 곧 \(\lim_{h\to0}\left[f(a + h) - f(a)\right] = 0\)을 보이면 된다(\(x = a + h\)로 바꾼 연속의 정의). \(h \ne 0\)이면 \(h\)를 곱하고 나누어

\[f(a + h) - f(a) = \frac{f(a + h) - f(a)}{h}\cdot h\]

로 쓸 수 있다. 가정에 의해 \(h \to 0\)일 때 첫째 인수는 \(f'(a)\)로 수렴하고, 둘째 인수는 0으로 수렴한다. 두 극한이 모두 존재하므로 극한의 곱셈 법칙(1.3절)을 쓸 수 있고, 따라서 \(f(a + h) - f(a) \to f'(a)\cdot0 = 0\)이다. ∎

증명에서 미분 가능성 가정이 쓰인 곳은 단 한 곳, "첫째 인수의 극한이 존재한다"입니다. 이 가정이 없으면 곱셈 법칙을 쓸 수 없습니다. 실제로 거꾸로는 성립하지 않습니다.

예제 2.1.6 (연속이지만 미분 불가능)

\(f(x) = |x|\)는 \(x = 0\)에서 연속이지만 미분 가능하지 않음을 보여라.

풀이. \(\lim_{x\to0}|x| = 0 = f(0)\)이므로 연속입니다. 미분계수의 정의에서 \(\frac{|h| - 0}{h}\)는 \(h > 0\)이면 1, \(h < 0\)이면 −1입니다. 오른쪽 극한 1과 왼쪽 극한 −1이 달라 극한이 존재하지 않으므로 미분 불가능합니다. 그래프는 원점에서 꺾여 있어, 오른쪽에서 본 접선과 왼쪽에서 본 접선이 다릅니다.

정리 2.1.5의 대우 "불연속이면 미분 불가능"은 판정에 바로 쓸 수 있습니다. 그러나 "연속이니까 미분 가능"은 예제 2.1.6 때문에 쓸 수 없습니다. 19세기에 바이어슈트라스는 모든 점에서 연속이지만 어느 점에서도 미분 가능하지 않은 함수까지 만들어 보였습니다.

주의구간별로 정의된 함수의 경계점에서는 도함수 공식이 통하지 않습니다. \(f(x) = x^2\) (\(x \le 1\)), \(2x - 1\) (\(x > 1\))은 양쪽에서 공식으로 구한 기울기가 모두 2라서 미분 가능해 보이지만, 그것만으로는 부족하고 먼저 \(x = 1\)에서 연속인지(\(1 = 1\))를 확인한 뒤 정의의 양쪽 극한을 직접 계산해야 합니다. 연속이 아니면 기울기가 같아도 미분 불가능합니다.
요약
  1. 미분계수 \(f'(a) = \lim_{h\to0}\frac{f(a+h) - f(a)}{h}\)는 평균변화율의 극한, 곧 접선의 기울기이다.
  2. 계산할 때는 \(h \ne 0\)에서 식을 정리해 \(h\)를 약분한 뒤 극한을 취한다. 근호가 있으면 유리화한다.
  3. 미분 가능하면 연속이다. 거꾸로는 성립하지 않는다(\(|x|\)).
  4. 미분 불가능한 전형: 꺾인 점, 수직 접선, 불연속점.

2.1.5연습문제

기본

  1. 정의를 써서 \(f(x) = 3x^2 + 1\)의 도함수를 구하여라.
    힌트

    \(f(x + h) - f(x) = 6xh + 3h^2\).

    답

    \(f'(x) = \lim_{h\to0}(6x + 3h) = 6x\).

  2. \(f(x) = \frac1x\)의 \(x = 2\)에서의 접선의 방정식을 구하여라.
    힌트

    \(\frac{1}{2+h} - \frac12 = \frac{-h}{2(2+h)}\).

    답

    \(f'(2) = -\frac14\), 접선 \(y = \frac12 - \frac14(x - 2)\), 곧 \(y = -\frac x4 + 1\).

  3. 위치가 \(s(t) = t^3\) (m)인 물체의 \(t = 1\)에서 \(t = 1 + h\)까지의 평균 속도를 \(h\)의 식으로 쓰고, \(t = 1\)에서의 순간 속도를 구하여라.
    답

    평균 속도 \(3 + 3h + h^2\), 순간 속도 3 m/s.

응용

  1. \(f(x) = x|x|\)는 \(x = 0\)에서 미분 가능한가? 미분 가능하면 \(f'(0)\)을 구하여라.
    힌트

    \(\frac{f(h) - f(0)}{h} = |h|\).

    답

    미분 가능, \(f'(0) = 0\). \(|x|\)의 꺾인 점이 \(x\)를 곱해 펴진다.

  2. \(f(x) = ax + b\) (\(x < 1\)), \(x^2\) (\(x \ge 1\))이 \(x = 1\)에서 미분 가능하도록 \(a, b\)를 정하여라.
    힌트

    먼저 연속 조건, 다음으로 양쪽 기울기가 같다는 조건.

    답

    연속: \(a + b = 1\). 오른쪽 미분계수 2, 왼쪽 \(a\)이므로 \(a = 2\), \(b = -1\).

심화

  1. \(f(x) = x^2\sin\frac1x\) (\(x \ne 0\)), \(f(0) = 0\)이 \(x = 0\)에서 미분 가능함을 보이고, \(f'\)이 \(x = 0\)에서 연속이 아님을 보여라.
    힌트

    정의의 몫은 \(h\sin\frac1h\)이고 \(|h\sin\frac1h| \le |h|\) (압축 정리). \(x \ne 0\)에서는 곱의 법칙과 연쇄 법칙(2.2절)을 쓴다.

    답

    \(f'(0) = 0\). \(x \ne 0\)이면 \(f'(x) = 2x\sin\frac1x - \cos\frac1x\)인데 \(x \to 0\)일 때 \(\cos\frac1x\)가 진동해 극한이 없다. 도함수는 존재해도 연속이 아닐 수 있다.

2.1.2

설명도함수의 정의와, 미분 가능하면 연속인 이유

미분계수 · 미분가능성

다루는 성취기준 [공통1-02-01]

왜 필요한가

고등학교에서는 \(x^n\)의 도함수가 \(nx^{n-1}\)이라는 공식부터 썼습니다. 대학에서는 공식이 통하지 않는 함수(\(|x|\), \(x^2\sin\frac1x\), 구간별로 정의된 함수)를 다루므로, 정의로 직접 미분계수를 구하고 "미분 가능한가"를 판정할 수 있어야 합니다.

정의 · 미분계수와 도함수

\(f\)가 \(a\)를 포함하는 열린구간에서 정의되어 있을 때, 극한

\[f'(a) = \lim_{h\to 0}\frac{f(a+h) - f(a)}{h}\]

가 존재하면 \(f\)는 \(a\)에서 미분 가능하다고 하고 이 값을 미분계수라 한다. 각 점의 미분계수를 대응시킨 함수 \(f'\)을 도함수라 한다.

정의를 풀어 읽기

  1. \(\frac{f(a+h) - f(a)}{h}\)두 점 \((a, f(a))\), \((a+h, f(a+h))\)를 잇는 할선의 기울기, 곧 구간 \([a, a+h]\)의 평균변화율입니다.
  2. \(h \to 0\)\(h\)는 양수와 음수 양쪽에서 0으로 갑니다. 오른쪽 극한과 왼쪽 극한이 모두 존재하고 같아야 미분 가능합니다.
  3. 극한이 존재하지 않는 경우꺾인 점(양쪽 기울기가 다름), 수직 접선(기울기 → ∞), 진동(극한 없음)에서는 미분 불가능합니다.
  4. 다른 표기\(x = a + h\)로 두면 \(f'(a) = \lim_{x\to a}\frac{f(x) - f(a)}{x - a}\). 라이프니츠 표기 \(\frac{dy}{dx}\)는 같은 것을 "아주 작은 변화의 비"로 읽게 해 줍니다.

예: 정의로 미분하기

예 1. \(f(x) = \sqrt{x}\), \(a > 0\):

\[\frac{\sqrt{a+h} - \sqrt{a}}{h} = \frac{(a+h) - a}{h(\sqrt{a+h} + \sqrt{a})} = \frac{1}{\sqrt{a+h} + \sqrt{a}} \to \frac{1}{2\sqrt a}.\]

분자를 유리화해 \(h\)를 약분한 뒤 극한을 취했습니다. \(a = 0\)에서는 오른쪽 몫이 \(\frac{1}{\sqrt h} \to \infty\)라 미분 불가능합니다(수직 접선).

예 2. \(f(x) = |x|\), \(a = 0\): \(\frac{|h|}{h}\)는 \(h > 0\)이면 1, \(h < 0\)이면 −1. 양쪽 극한이 달라 미분 불가능합니다(꺾인 점). 그런데 \(|x|\)는 0에서 연속입니다.

예 3. \(f(x) = x^2\sin\frac1x\ (x\ne0)\), \(f(0) = 0\): \(\frac{f(h) - 0}{h} = h\sin\frac1h\)이고 \(|h\sin\frac1h| \le |h| \to 0\)이므로 압축 정리로 \(f'(0) = 0\). 그래프가 끝없이 출렁여도 미분 가능할 수 있습니다.

미분 가능하면 연속이다

정리

\(f\)가 \(a\)에서 미분 가능하면 \(a\)에서 연속이다.

  1. \(h \ne 0\)일 때 \(f(a+h) - f(a) = \dfrac{f(a+h) - f(a)}{h}\cdot h\).
    \(h\)를 곱하고 나눈 항등식. \(h \ne 0\)이라 나눌 수 있다.
  2. \(h \to 0\)일 때 앞의 인수 → \(f'(a)\), 뒤의 인수 → 0이므로 \(f(a+h) - f(a) \to f'(a)\cdot 0 = 0\).
    곱의 극한 법칙. 두 극한이 모두 존재하므로 쓸 수 있다(미분 가능성 가정을 여기서 씀).
  3. 따라서 \(\lim_{h\to0} f(a+h) = f(a)\), 곧 \(f\)는 \(a\)에서 연속이다.
    \(x = a + h\)로 바꾸면 연속의 정의 \(\lim_{x\to a} f(x) = f(a)\).

되짚기: 거꾸로는 성립하지 않습니다. 예 2의 \(|x|\)가 반례입니다. 그래서 "불연속이면 미분 불가능"(대우)은 판정에 쓸 수 있지만, "연속이니까 미분 가능"은 쓸 수 없습니다.

흔한 오해

  • "도함수의 공식을 대입해서 \(f'(a)\)를 구했으니 미분 가능하다." 구간별로 정의된 함수는 경계점에서 공식이 통하지 않습니다. 경계점은 정의(양쪽 극한)로 확인해야 합니다.
  • "\(f'(x)\)의 극한이 \(f'(a)\)다." 예 3에서 \(x \ne 0\)이면 \(f'(x) = 2x\sin\frac1x - \cos\frac1x\)인데, \(x \to 0\)일 때 극한이 없습니다. 그래도 \(f'(0) = 0\)은 존재합니다. 도함수는 연속이 아닐 수 있습니다.

확인경계점에서

\(f(x) = x^2\ (x \le 1)\), \(f(x) = 2x - 1\ (x > 1)\)은 \(x = 1\)에서?

2.1.3

증명압축 정리: 양쪽에서 조이면 가운데도 따라간다

극한 법칙

다루는 성취기준 [공통1-01-03]

정리 · 압축 정리 (squeeze theorem)

\(a\)를 포함하는 열린구간의 \(x \ne a\)에서 \(g(x) \le f(x) \le h(x)\)이고, \(\lim_{x\to a} g(x) = \lim_{x\to a} h(x) = L\)이면 \(\lim_{x\to a} f(x) = L\)이다.

쓰는 것

  • 극한의 정의 (ε-δ). \(g\)와 \(h\)의 극한에서 각각 \(\delta\)를 하나씩 얻는다.
  • 절댓값 부등식: \(|u - L| < \varepsilon \iff L - \varepsilon < u < L + \varepsilon\).

아이디어

\(f(x)\)를 \(L \pm \varepsilon\) 띠 안에 넣고 싶습니다. \(f\)를 직접 다룰 수는 없지만, \(f\)는 늘 \(g\)와 \(h\) 사이에 있습니다. 그러니 \(g\)는 띠의 아래쪽 경계보다 위에, \(h\)는 위쪽 경계보다 아래에 두면 \(f\)도 띠 안에 갇힙니다. \(g\)에서 얻는 \(\delta_1\), \(h\)에서 얻는 \(\delta_2\), 부등식이 성립하는 구간의 반지름 \(\delta_0\)를 모두 만족하도록 셋 중 가장 작은 것을 고릅니다.

증명

  1. 가정에서 \(0 < |x - a| < \delta_0\)이면 \(g(x) \le f(x) \le h(x)\)가 되는 \(\delta_0 > 0\)가 있다.
    "\(a\)를 포함하는 열린구간에서"라는 가정을 반지름으로 옮긴 것.
  2. \(\varepsilon > 0\)이 주어졌다고 하자. \(\lim g = L\)이므로 \(0<|x-a|<\delta_1 \Rightarrow L - \varepsilon < g(x) < L + \varepsilon\)인 \(\delta_1 > 0\)가 있다.
    \(g\)의 극한의 정의와 절댓값 부등식.
  3. 같은 이유로 \(0<|x-a|<\delta_2 \Rightarrow L - \varepsilon < h(x) < L + \varepsilon\)인 \(\delta_2 > 0\)가 있다.
    \(h\)의 극한의 정의. 같은 \(\varepsilon\)에 대해 얻는다.
  4. \(\delta = \min\{\delta_0, \delta_1, \delta_2\}\)로 둔다. \(\delta > 0\)이다.
    세 조건을 동시에 쓰기 위한 최솟값.
  5. \(0 < |x-a| < \delta\)이면 1~3단계가 모두 성립하므로 \(L - \varepsilon < g(x) \le f(x) \le h(x) < L + \varepsilon\), 곧 \(|f(x) - L| < \varepsilon\). 따라서 \(\lim_{x\to a} f(x) = L\).
    2단계의 왼쪽 부등식, 1단계, 3단계의 오른쪽 부등식을 이어 붙임. \(g\)의 위쪽 부등식과 \(h\)의 아래쪽 부등식은 쓰이지 않는다.

되짚기

  • 마지막 단계에서 \(g\)는 아래쪽만, \(h\)는 위쪽만 썼습니다. 그래서 극한이 같아야 한다는 가정이 꼭 필요합니다.
  • 가정을 빼면. \(g \to 0\), \(h \to 1\)처럼 극한이 다르면 결론이 깨집니다. 예: \(g(x) = 0\), \(h(x) = 1\), \(f(x) = \frac{1}{2}(1 + \sin\frac{1}{x})\)는 0과 1 사이에 있지만 \(x \to 0\)에서 극한이 없습니다.
  • 부등식은 \(a\) 근처에서만 성립하면 됩니다. 멀리서의 대소 관계는 극한과 상관없습니다.

더 나아가기

자주 쓰는 형태: \(|f(x) - L| \le h(x)\)이고 \(h(x) \to 0\)이면 \(f(x) \to L\). \(g = L - h\), \(h\)를 위 정리에 넣은 것입니다. 예: \(|x \sin\frac{1}{x}| \le |x|\)이므로 \(\lim_{x\to 0} x\sin\frac{1}{x} = 0\).

2.1.4

예제\(\lim_{x\to 0} \frac{\sin x}{x} = 1\)은 왜 성립할까?

넓이 비교 · 압축 정리

다루는 성취기준 [공통1-01-03]

먼저 예측

계산기로 \(\frac{\sin0.1}{0.1}\)을 구하면 1보다 클까요, 작을까요? 얼마나 가까울까요?

예측 확인

0.99833…으로 1보다 조금 작습니다. 차이는 약 \(\frac{x^2}{6}\)입니다(8단원 Taylor 급수).

\(\lim_{x\to 0} \dfrac{\sin x}{x}\)를 구하세요. 단, \(x\)는 라디안입니다.

전략

\(x = 0\)을 대입하면 \(\frac{0}{0}\)이라 극한 법칙(몫의 극한)을 쓸 수 없습니다. 로피탈 정리를 쓰면 \(\frac{\cos x}{1} \to 1\)이지만, \(\sin x\)의 도함수가 \(\cos x\)라는 사실 자체가 이 극한으로 증명되므로 순환 논법이 됩니다. 그래서 미분 없이, 단위원에서 넓이를 비교해 \(\frac{\sin x}{x}\)를 두 함수 사이에 가두고 압축 정리를 씁니다.

풀이

  1. 먼저 \(0 < x < \frac{\pi}{2}\)라 하자. 단위원에서 중심각이 \(x\)인 부채꼴을 그리고, 점 \(A = (1, 0)\), \(P = (\cos x, \sin x)\), \(OP\)의 연장선이 직선 \(x = 1\)과 만나는 점 \(T = (1, \tan x)\)를 잡는다.
    \(x\)를 양수로 두면 길이와 넓이가 모두 양수라 부등식 다루기가 쉽다. 음수는 6단계에서 처리.
  2. 삼각형 \(OAP\) ⊂ 부채꼴 \(OAP\) ⊂ 삼각형 \(OAT\)이므로 넓이도 이 순서다.
    \[\tfrac{1}{2}\sin x \;<\; \tfrac{1}{2}x \;<\; \tfrac{1}{2}\tan x\] 삼각형 넓이 \(\frac12 \cdot \text{밑변 } 1 \cdot \text{높이}\), 부채꼴 넓이 \(\frac12 r^2\theta\) (\(r=1\)). 라디안을 쓰는 이유가 여기 있다: 도(°)로 재면 부채꼴 넓이가 \(\frac{\pi}{360}\theta\)가 되어 극한값이 \(\frac{\pi}{180}\)이 된다.
  3. 각 변에 \(\frac{2}{\sin x} > 0\)을 곱하면 \(1 < \dfrac{x}{\sin x} < \dfrac{1}{\cos x}\).
    \(0 < x < \frac{\pi}{2}\)에서 \(\sin x > 0\)이므로 부등호 방향이 유지된다.
  4. 역수를 취하면 \(\cos x < \dfrac{\sin x}{x} < 1\).
    양수끼리는 역수를 취하면 부등호가 뒤집힌다.
  5. \(\lim_{x\to 0^+} \cos x = 1\)이고 \(\lim 1 = 1\)이므로, 압축 정리로 \(\lim_{x\to 0^+} \frac{\sin x}{x} = 1\).
    \(\cos\)의 연속성(\(\cos 0 = 1\))과 앞 카드의 압축 정리(한쪽 극한에도 똑같이 성립).
  6. \(\frac{\sin(-x)}{-x} = \frac{\sin x}{x}\)이므로 함수는 짝함수이고, 왼쪽 극한도 1이다. 따라서 \(\lim_{x\to 0}\frac{\sin x}{x} = 1\).
    \(\sin\)이 홀함수. 양쪽 극한이 같으면 극한이 존재한다.

의미

극한 1은 "작은 각에서 \(\sin x \approx x\)"라는 뜻입니다(라디안일 때만). 이 근사가 \((\sin x)' = \cos x\)의 증명, 진자의 작은 진폭 근사, 빛의 작은 각 회절 계산에 그대로 쓰입니다. 각도를 도(°)로 재면 극한이 \(\frac{\pi}{180}\)이 되어 모든 미분 공식이 지저분해집니다. 미적분에서 라디안을 쓰는 이유입니다.

검산

\(x = 0.1\)이면 \(\frac{\sin 0.1}{0.1} \approx 0.99833\), \(x = 0.01\)이면 \(\approx 0.99998\)입니다. 4단계의 아래 경계 \(\cos 0.1 \approx 0.99500\)보다 크고 1보다 작습니다. 부등식과 수치가 맞습니다.

바꿔 보기

  • \(\lim_{x\to 0}\frac{\sin 3x}{x}\): \(u = 3x\)로 두면 \(\frac{\sin 3x}{x} = 3\cdot\frac{\sin u}{u} \to 3\).
  • \(\lim_{x\to 0}\frac{1 - \cos x}{x^2}\): 분모·분자에 \(1 + \cos x\)를 곱하면 \(\frac{\sin^2 x}{x^2}\cdot\frac{1}{1+\cos x} \to 1 \cdot \frac12 = \frac12\).
  • \(\lim_{x\to\infty}\frac{\sin x}{x}\): 이번에는 \(-\frac{1}{x} \le \frac{\sin x}{x} \le \frac{1}{x}\)로 가두면 0입니다. 같은 식이라도 \(x\)가 어디로 가는지에 따라 쓰는 부등식이 다릅니다.
2.1.5

실습할선이 접선이 되는 순간

실습 · 도함수의 정의

다루는 성취기준 [공통1-02-01]

목표

\(h\)를 0에 가깝게 줄이며 할선의 기울기 \(\frac{f(a + h) - f(a)}{h}\)가 접선의 기울기 \(f'(a)\)에 다가가는 것을 숫자와 그림으로 확인합니다. 미분할 수 없는 점에서는 왼쪽과 오른쪽 극한이 다르다는 것을 봅니다. 성취기준 [공통1-02-01].

준비

파란 곡선이 함수, 주황 직선이 할선, 회색 점선이 접선입니다. \(h\)는 로그 눈금으로 조절합니다(−3이면 \(h = 0.001\)). "왼쪽에서"를 켜면 \(h < 0\)입니다.

절차

  1. \(x^2\), \(a = 1\)에서 \(\log h\)를 0, −1, −2, −3으로 바꾸며 할선 기울기와 차이를 기록한다.
  2. "왼쪽에서"를 켜고 같은 일을 한다.
  3. \(|x|\)를 고르고 \(a = 0\)에서 왼쪽과 오른쪽의 할선 기울기를 비교한다.

기대 결과

  • \(x^2\)의 할선 기울기는 \(2 + h\)로, 차이가 \(h\)에 비례해 줄어든다(\(h\)를 10분의 1로 하면 차이도 10분의 1).
  • \(|x|\)의 \(a = 0\)에서 오른쪽은 늘 1, 왼쪽은 늘 −1. 극한이 없으므로 미분 불가능.

분석

  1. \(\sqrt x\)의 \(a = 0\)에서는 무슨 일이 생기나요? 접선이 어떻게 생겼을지 생각해 보세요.
  2. \(h\)를 \(10^{-4}\)보다 더 작게 하면 컴퓨터 계산에서는 오히려 오차가 커질 수 있습니다. 왜 그럴까요?

더 해 보기

할선 대신 \(\frac{f(a + h) - f(a - h)}{2h}\)(중앙 차분)를 계산해 보면 차이가 \(h^2\)에 비례해 훨씬 빨리 줄어듭니다. \(x^3 - 3x\)에서 손으로 확인해 보세요.
