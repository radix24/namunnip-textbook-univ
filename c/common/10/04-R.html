4.R.1

연습C/C++ 기초 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통10-04-01] [공통10-04-02] [공통10-04-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산다음 C 코드의 출력은? int a = 7, b = 2; printf("%d %d %.2f\n", a / b, a % b, (double)a / b); [04-01]

    힌트 1

    정수끼리 나누면 정수 몫만 남습니다.

    힌트 2

    (double)a로 바꾸면 실수 나눗셈이 됩니다.

    풀이

    3 1 3.50. 파이썬의 7 / 2는 3.5지만 C의 7 / 2는 3입니다. 평균을 구할 때 sum / n을 정수로 계산해 소수점 아래를 잃는 실수가 흔합니다.

  2. 개념C의 int가 4바이트일 때 담을 수 있는 범위를 쓰고, INT_MAX + 1을 계산하면 어떻게 되는지 말하세요. 파이썬과 비교하세요. [04-01]

    힌트 1

    32비트 부호 있는 정수는 2의 보수로 저장합니다(6.1절).

    힌트 2

    범위는 \(-2^{31}\)부터 \(2^{31} - 1\)까지.

    풀이

    \(-2147483648\)부터 \(2147483647\)까지. INT_MAX + 1은 C 표준에서 정의되지 않은 동작(넘침)이고, 보통은 \(-2147483648\)로 돌아갑니다. 파이썬의 정수는 크기 제한이 없어 2**31도 그대로 계산합니다. 큰 수를 다루는 C 프로그램은 long long(8바이트)을 씁니다.

  3. 실습1부터 100까지의 합을 구하는 프로그램을 C와 파이썬으로 각각 쓰고, 두 코드의 차이(자료형 선언, 블록 표시, 반복문의 꼴)를 세 가지 말하세요. [04-02]

    힌트 1

    C의 for (초기; 조건; 증가)와 파이썬의 for i in range(...).

    힌트 2

    C는 중괄호와 세미콜론, 파이썬은 들여쓰기.

    풀이 
    #include <stdio.h>
int main(void) {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }
    printf("%d\n", sum);   /* 5050 */
    return 0;
}

    파이썬: print(sum(range(1, 101))). 차이: ① C는 변수의 자료형(int)을 선언해야 함 ② C는 중괄호로, 파이썬은 들여쓰기로 블록을 나타냄 ③ C의 for는 초기값·조건·증가를 직접 쓰고, 파이썬은 범위의 원소를 차례로 꺼냄. C는 컴파일해야 실행됩니다(gcc sum.c -o sum).

  4. 실습두 정수 가운데 큰 값을 돌려주는 C 함수 max2를 만들고, 함수 원형(선언)을 main 앞에 두는 이유를 말하세요. [04-03]

    힌트 1

    함수의 반환형, 이름, 매개변수의 자료형을 씁니다.

    힌트 2

    C 컴파일러는 위에서 아래로 읽습니다.

    풀이 
    #include <stdio.h>
int max2(int a, int b);            /* 원형 */
int main(void) {
    printf("%d\n", max2(3, 8));    /* 8 */
    return 0;
}
int max2(int a, int b) {
    return a > b ? a : b;
}

    컴파일러가 main에서 max2를 만났을 때 매개변수와 반환형을 알아야 호출이 맞는지 검사할 수 있습니다. 원형이 없으면 경고나 오류가 납니다.

  5. 실습정수를 0이 나올 때까지 입력받아 평균을 소수 둘째 자리까지 출력하는 C 프로그램을 쓰세요. scanf에 &를 붙이는 이유도 말하세요. [04-02]

    힌트 1

    while (1)로 돌다가 0이면 break합니다.

    힌트 2

    scanf("%d", &x)는 x의 주소를 받아 그곳에 값을 써 넣습니다.

    풀이 
    #include <stdio.h>
int main(void) {
    int x, n = 0, sum = 0;
    while (scanf("%d", &x) == 1 && x != 0) {
        sum += x;
        n++;
    }
    if (n > 0) printf("%.2f\n", (double)sum / n);
    return 0;
}

    C의 함수는 값을 복사해서 받으므로, scanf가 변수를 바꾸려면 변수의 주소가 필요합니다. &를 빼면 엉뚱한 메모리에 값을 써서 프로그램이 죽을 수 있습니다(5.2절).

  6. 판단if (x = 5) printf("five\n");가 x에 무엇이 들어 있든 늘 five를 출력합니다. 왜 그런가요? [04-01]

    힌트 1

    =와 ==는 다릅니다.

    힌트 2

    C에서 대입식 x = 5의 값은 5이고, 0이 아닌 값은 참입니다.

    풀이

    x = 5는 비교가 아니라 대입이라 x가 5로 바뀌고 식의 값 5는 참이므로 늘 실행됩니다. if (x == 5)로 고칩니다. 파이썬은 이것을 문법 오류로 막지만 C는 허용하므로, 컴파일 경고(-Wall)를 켜 두면 찾기 쉽습니다.
