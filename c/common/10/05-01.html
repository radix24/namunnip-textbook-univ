5.1.1배열 선언

C의 배열은 같은 자료형의 값을 정해진 개수만큼 메모리에 이어서 놓은 것입니다. 크기는 선언할 때 정하고 바꿀 수 없습니다(파이썬 리스트와 다른 점).

double T[5] = {20.1, 20.6, 21.3, 22.0, 22.8};
double sum = 0;
for (int i = 0; i < 5; i++) {
    sum += T[i];
}
printf("평균 %.2f\n", sum / 5);     /* 21.36 */

인덱스는 0부터 크기−1까지입니다. C는 T[5]나 T[-1]처럼 범위를 벗어나도 오류를 내지 않고 그 자리의 메모리를 읽거나 써 버립니다. 엉뚱한 값, 다른 변수가 망가짐, 프로그램 종료가 생길 수 있어 반복 범위를 늘 확인해야 합니다.

5.1.2함수에 배열 넘기기

배열을 함수에 넘기면 복사되지 않고 배열의 시작 주소가 넘어갑니다(5.2절). 그래서 함수 안에서 배열 원소를 바꾸면 원래 배열이 바뀌고, 크기는 따로 넘겨야 합니다.

double mean(const double a[], int n) {
    double s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s / n;
}

const는 이 함수가 배열을 바꾸지 않겠다는 표시입니다.

5.1.3문자열과 2차원 배열

C의 문자열은 char 배열이고, 끝에 널 문자 '\0'이 붙어 끝을 표시합니다. char s[] = "H2O";는 4칸('H' '2' 'O' '\0')입니다.

2차원 배열 double A[3][4];는 3행 4열의 표이고 A[i][j]로 씁니다. 메모리에는 0행, 1행, 2행 순서로 이어져 놓입니다(행 우선). 행렬 곱셈이나 격자 위의 계산(공통11 5단원)에 씁니다.

double A[2][2] = {{1, 2}, {3, 4}}, B[2][2] = {{0, 1}, {1, 0}}, C[2][2];
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 2; j++) {
        C[i][j] = 0;
        for (int k = 0; k < 2; k++) C[i][j] += A[i][k] * B[k][j];
    }
/* C = {{2, 1}, {4, 3}} */
요약
  1. 자료형 이름[크기], 인덱스 0 ~ 크기−1. 범위 검사 없음.
  2. 함수에는 주소가 넘어가므로 크기도 함께 넘긴다.
  3. 문자열 = '\0'로 끝나는 char 배열. 2차원 배열은 행 우선.
