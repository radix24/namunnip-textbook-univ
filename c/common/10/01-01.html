1.1.1프로그램과 파이썬

프로그램은 컴퓨터가 차례로 실행할 명령을 적은 글입니다. 컴퓨터가 직접 이해하는 것은 0과 1로 된 기계어뿐이라, 사람이 읽기 쉬운 언어로 쓴 뒤 번역해서 실행합니다. 파이썬은 한 줄씩 읽어 바로 실행하는 인터프리터 방식이고, 4단원의 C는 전체를 미리 기계어로 바꾸는 컴파일러 방식입니다.

파이썬을 설치하면 함께 오는 IDLE이나 VS Code 같은 편집기에서 파일(.py)을 만들어 실행합니다. 첫 프로그램은 화면에 글자를 내보내는 것입니다.

print("Hello, world!")
print(3 + 4)          # 7
print("3" + "4")      # 34  (문자열은 이어 붙인다)

# 뒤는 주석이라 실행되지 않습니다.

1.1.2자료형

  • 정수(int): 7, -3. 파이썬의 정수는 아무리 커도 정확하다.
  • 실수(float): 3.14, 2e-3(= 0.002). 유효숫자가 약 16자리로 제한된다(6.1절).
  • 문자열(str): 따옴표로 감싼 글자들. "화학", 'H2O'.
  • 불(bool): True, False(1.2절).

type(값)으로 자료형을 확인할 수 있습니다.

1.1.3연산자와 변수

연산자뜻예결과
+ - *더하기, 빼기, 곱하기2 * 36
/나누기 (결과는 늘 실수)7 / 23.5
//몫7 // 23
%나머지7 % 21
**거듭제곱2 ** 101024

변수는 값에 붙이는 이름입니다. =는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣는다(대입)"는 뜻이라 x = x + 1처럼 쓸 수 있습니다(x += 1로 줄여 씀).

g = 9.8           # 중력 가속도 (m/s^2)
t = 3
h = 0.5 * g * t ** 2
print("떨어진 거리:", h, "m")      # 떨어진 거리: 44.1 m
print(f"떨어진 거리: {h:.1f} m")   # f-문자열로 소수 첫째 자리까지

거듭제곱은 곱하기보다 먼저 계산합니다. 헷갈리면 괄호를 씁니다.

1.1.4문자열 다루기와 입력

  • len(s): 길이.
  • s[0]: 첫 글자(번호는 0부터), s[-1]: 마지막 글자, s[1:3]: 1번부터 3번 앞까지(2.1절).
  • s.upper(), s.replace("a", "b"), s.split(): 대문자로, 바꾸기, 쪼개기.

input()은 키보드로 입력한 내용을 언제나 문자열로 돌려줍니다. 계산하려면 int()나 float()로 바꿔야 합니다.

r = float(input("반지름(cm)? "))
area = 3.14159 * r ** 2
print(f"넓이 {area:.2f} cm^2")
자주 하는 실수. input()으로 받은 값을 그대로 더하면 "3" + "4"처럼 이어 붙어 "34"가 됩니다. 문자열과 숫자를 +로 더하면 TypeError가 납니다.
요약
  1. 자료형: int, float, str, bool.
  2. /는 실수 나누기, //는 몫, %는 나머지, **는 거듭제곱.
  3. =는 대입. input()은 문자열을 돌려주므로 int(), float()로 바꾼다.

1.1.5연습문제

기본

  1. 17 // 5, 17 % 5, -17 // 5의 값은?
    답

    3, 2, −4. 파이썬의 //는 내림이라 음수에서 −3.4를 −4로 내린다.

  2. 초 단위 시간 s = 4000을 "1시간 6분 40초"로 출력하는 코드를 써라.
    답

    print(f"{s // 3600}시간 {s % 3600 // 60}분 {s % 60}초")
