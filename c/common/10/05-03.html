5.3.1구조체

원소 기호(문자열), 원자 번호(정수), 원자량(실수)처럼 자료형이 다른 값들을 하나로 묶을 때 구조체를 씁니다.

#include <stdio.h>
struct Element {
    char symbol[3];
    int Z;
    double mass;
};

int main(void) {
    struct Element e[3] = {{"H", 1, 1.008}, {"C", 6, 12.011}, {"O", 8, 15.999}};
    for (int i = 0; i < 3; i++)
        printf("%-2s Z=%d  %.3f\n", e[i].symbol, e[i].Z, e[i].mass);
    struct Element *p = &e[1];
    printf("%s\n", p->symbol);       /* C   (*p).symbol과 같음 */
    return 0;
}
  • 멤버는 점(.)으로 쓴다: e[i].Z.
  • 구조체 포인터는 화살표(->)로 쓴다: p->mass.
  • typedef struct { ... } Element;로 이름을 줄일 수 있다.

5.3.2C++ 클래스

C++는 C에 클래스를 더한 언어입니다(C 코드 대부분이 그대로 컴파일됨). 구조체처럼 자료를 묶고, 그 자료를 다루는 함수(멤버 함수)도 함께 넣습니다.

#include <iostream>
using namespace std;

class Particle {
private:                         // 바깥에서 직접 못 건드림
    double m, x, v;
public:                          // 바깥에서 쓸 수 있음
    Particle(double m_, double x_, double v_) : m(m_), x(x_), v(v_) {}   // 생성자
    void move(double dt) { x += v * dt; }
    double kinetic() const { return 0.5 * m * v * v; }
    double pos() const { return x; }
};

int main() {
    Particle p(2.0, 0.0, 3.0);
    p.move(0.5);
    cout << p.pos() << " " << p.kinetic() << endl;    // 1.5 9
    return 0;
}

3.3절의 파이썬 Particle과 같은 일을 합니다. 차이는 다음과 같습니다.

  • C++는 멤버의 자료형을 선언한다.
  • self 대신 멤버 이름을 바로 쓴다(필요하면 this->x).
  • 생성자는 클래스와 같은 이름의 함수다(파이썬의 __init__).
  • private로 감춘 자료는 멤버 함수를 통해서만 바꿀 수 있다(캡슐화). 잘못된 값이 들어가는 것을 막는다.

입출력은 printf 대신 cout <<을 많이 씁니다.

요약
  1. struct: 서로 다른 자료형을 묶는다. .과 ->.
  2. C++ class: 자료 + 멤버 함수, 생성자, public/private.
