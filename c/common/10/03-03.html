3.3.1모듈

모듈은 함수와 변수를 모아 둔 파이썬 파일입니다. 자주 쓰는 기능은 이미 만들어져 있어 불러 쓰기만 하면 됩니다.

import math
print(math.sqrt(2), math.pi, math.exp(1))
from math import sin, radians
print(sin(radians(30)))          # 0.49999999999999994

import random
print(random.randint(1, 6))      # 주사위

import numpy as np               # 외부 패키지 (pip install numpy)
x = np.linspace(0, 1, 5)         # [0, 0.25, 0.5, 0.75, 1]
print(np.mean(x ** 2))
  • 표준 모듈: 파이썬에 들어 있음. math, random, csv, time, os.
  • 외부 패키지: pip install 이름으로 설치. 과학 계산에는 numpy(배열 계산), matplotlib(그래프), scipy(수치 해석)를 많이 쓴다.
  • 내가 만든 mytools.py도 같은 폴더에 두면 import mytools로 쓸 수 있다.

3.3.2클래스

클래스는 관련된 자료(속성)와 그 자료를 다루는 함수(메서드)를 묶은 설계도이고, 클래스로 만든 하나하나를 객체(인스턴스)라 합니다. 문자열이나 리스트도 사실 객체이고, s.upper(), a.append(x)가 메서드입니다.

class Particle:
    def __init__(self, m, x, v):     # 객체를 만들 때 실행
        self.m, self.x, self.v = m, x, v

    def kinetic(self):
        return 0.5 * self.m * self.v ** 2

    def move(self, dt):
        self.x += self.v * dt

p = Particle(2.0, 0.0, 3.0)
p.move(0.5)
print(p.x, p.kinetic())     # 1.5 9.0

self는 메서드를 부른 그 객체 자신입니다. p.move(0.5)는 Particle.move(p, 0.5)와 같은 뜻입니다. 같은 클래스로 입자를 여러 개 만들면 각자 자기 x, v를 가집니다. C++의 클래스(5.3절)도 같은 생각입니다.

요약
  1. import 모듈, from 모듈 import 이름, import 모듈 as 별명.
  2. 클래스 = 속성 + 메서드. __init__에서 self.속성을 만든다.
