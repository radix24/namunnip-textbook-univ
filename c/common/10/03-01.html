3.1.1함수 정의

같은 계산을 여러 번 쓰면 함수로 묶습니다. 프로그램이 짧아지고, 이름이 있어 읽기 쉽고, 고칠 곳이 한 군데가 됩니다.

def ideal_P(n, T, V, R=0.08206):
    """이상 기체 압력 (atm). n mol, T K, V L"""
    return n * R * T / V

print(ideal_P(1, 273.15, 22.414))   # 약 1.0
print(ideal_P(2, 300, V=10))        # 키워드로 넘기기
  • 매개변수: 함수가 받는 값의 이름(n, T, V). R=0.08206처럼 기본값을 줄 수 있다.
  • 인수: 호출할 때 실제로 넘기는 값.
  • 반환값: return 뒤의 값. return이 없으면 None을 돌려준다.
  • 여러 값은 return a, b로 돌려주면 튜플이 된다.

3.1.2지역 변수

함수 안에서 만든 변수는 함수가 끝나면 사라지고 바깥에서는 보이지 않습니다(지역 변수). 함수 밖의 같은 이름 변수와는 서로 다른 변수입니다. 함수가 바깥 값을 쓰려면 매개변수로 받고, 결과는 return으로 돌려주는 것이 깔끔합니다.

3.1.3재귀

함수가 자기 자신을 부르는 것을 재귀라 합니다. 문제를 같은 모양의 더 작은 문제로 줄이고, 더 줄일 수 없는 경우(기저 사례)는 바로 답합니다.

def fact(n):
    if n <= 1:            # 기저 사례
        return 1
    return n * fact(n - 1)

print(fact(5))   # 120

fact(5)는 fact(4)를 부르고 기다리며, 이것이 fact(1)까지 이어집니다. 호출될 때마다 컴퓨터는 그 호출의 n을 따로 기억해 두고(호출 스택), fact(1)이 1을 돌려주면 거꾸로 1·2·3·4·5를 곱하며 돌아옵니다.

  • 기저 사례가 없거나 도달하지 못하면 끝없이 부르다 RecursionError가 난다(파이썬 기본 한도 약 1000단계).
  • 피보나치 \(F(n) = F(n-1) + F(n-2)\)를 그대로 재귀로 쓰면 같은 값을 수없이 다시 계산해 호출 수가 지수적으로 는다. 반복문이나 이미 구한 값을 저장해 두는 방법(메모이제이션)으로 고친다. 아래 실습에서 호출 수를 세어 볼 수 있다.
요약
  1. def 이름(매개변수): ... return 값.
  2. 함수 안의 변수는 지역 변수.
  3. 재귀 = 기저 사례 + 더 작은 문제로 자기 호출. 호출 스택에 쌓였다가 거꾸로 돌아온다.

3.1.2

실습재귀 호출 나무와 호출 스택

실습 · 피보나치, 메모이제이션

다루는 성취기준 [공통10-03-01]

목표

재귀 함수 fib(n)이 자기 자신을 부르는 순서와 호출 스택이 쌓였다 풀리는 모습을 봅니다. 같은 값을 다시 계산하는 낭비를 메모이제이션으로 없애면 호출 수가 얼마나 줄어드는지 비교합니다. 성취기준 [공통10-03-01].

준비

def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

동그라미 하나가 호출 한 번이고 안의 숫자가 \(n\)입니다. 빨간 테두리는 지금 실행 중인 호출(스택 맨 위), 칠한 동그라미는 값을 돌려준 호출입니다. 메모이제이션을 켜면 한 번 구한 값을 저장해 두고, 다시 부르면 계산 없이 꺼냅니다(주황).

절차

  1. \(n = 5\)에서 재생하고, 호출 스택이 가장 깊어질 때 몇 층인지 본다.
  2. \(n\)을 1부터 8까지 바꾸며 전체 호출 수를 적는다.
  3. 메모이제이션을 켜고 같은 일을 한다.

기대 결과

  • \(n = 5\)에서 스택은 fib(5) → fib(4) → fib(3) → fib(2) → fib(1)까지 5층. 전체 호출 15번.
  • 호출 수는 1, 3, 5, 9, 15, 25, 41, 67로 피보나치 수처럼(약 1.6배씩) 는다.
  • 메모이제이션을 켜면 \(2n - 1\)번(1, 3, 5, 7, ..., 15)으로 줄어든다.

분석

  1. fib(3)이 \(n = 6\)일 때 몇 번 계산되는지 그림에서 세어 보세요.
  2. \(n = 40\)이면 메모이제이션 없이 호출이 약 3억 번입니다. 반복문으로 쓴 fib는 몇 번 더하면 되는지 비교해 보세요.
