5.2.1주소

메모리는 1바이트마다 번호가 붙은 긴 칸의 줄이라고 볼 수 있고, 그 번호가 주소입니다. int a = 5;를 선언하면 4바이트짜리 자리가 잡히고 그 안에 5가 들어갑니다. 주소는 실행할 때마다 달라질 수 있으며 보통 16진수로 나타냅니다.

  • &a: 변수 a의 주소.
  • int *p;: int 값이 놓인 주소를 담는 변수(포인터) p의 선언.
  • *p: p가 가리키는 자리의 값(역참조).
int a = 5;
int *p = &a;          /* p는 a를 가리킨다 */
printf("%p\n", (void *)p);   /* 예: 0x7ffd5e8c (실행마다 다름) */
*p = 9;               /* p가 가리키는 자리에 9를 쓴다 */
printf("%d\n", a);    /* 9 */

같은 기호 *가 선언에서는 "포인터 자료형", 식에서는 "가리키는 값"이라는 뜻이라 처음에 헷갈립니다.

5.2.2함수가 바깥 변수를 바꾸기

4.3절에서 C는 값을 복사해 넘긴다고 했습니다. 주소를 넘기면 함수는 그 주소로 가서 원래 변수를 바꿀 수 있습니다.

void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}
int a = 1, b = 2;
swap(&a, &b);         /* a = 2, b = 1 */

scanf("%d", &n)도 같은 원리로, 읽은 값을 n의 자리에 써 넣으려고 주소를 받습니다.

5.2.3배열과 포인터

배열 이름은 식 안에서 첫 원소의 주소로 바뀝니다. 포인터에 정수를 더하면 자료형의 크기만큼 주소가 움직입니다. int가 4바이트이면 p + 1은 4바이트 뒤입니다.

int a[4] = {10, 20, 30, 40};
int *p = a;            /* &a[0]과 같음 */
printf("%d %d\n", *(p + 2), p[2]);   /* 30 30  a[i]는 *(a + i)와 같다 */

그래서 배열을 함수에 넘기면 주소만 넘어가 복사가 일어나지 않고(5.1절), 범위를 벗어난 p[10]도 컴파일러가 막지 않습니다. 아무 곳도 가리키지 않는 포인터는 NULL로 두고, 쓰기 전에 확인합니다. 아래 실습 카드에서 포인터를 움직이며 주소와 값을 볼 수 있습니다.

파이썬에는 포인터 문법이 없지만, 모든 변수가 객체를 가리키는 이름이라는 점에서 생각은 같습니다. 2.1절에서 b = a가 리스트를 복사하지 않던 이유입니다.
요약
  1. &변수: 주소, 자료형 *p: 포인터 선언, *p: 가리키는 값.
  2. 주소를 넘기면 함수가 원래 변수를 바꿀 수 있다(swap, scanf).
  3. 배열 이름 = 첫 원소의 주소, a[i] = *(a + i). 포인터 더하기는 자료형 크기 단위.

5.2.2

실습포인터를 움직여 보기

실습 · 주소와 배열

다루는 성취기준 [공통10-05-02] [공통10-05-01]

목표

배열 a[5]와 포인터 p를 그림으로 보며 p++가 주소를 얼마나 움직이는지, *p가 무엇을 읽고 쓰는지, 범위를 벗어나면 어떤 일이 생기는지 확인합니다. 성취기준 [공통10-05-02], [공통10-05-01].

준비

칸 하나가 배열 원소 하나이고, 아래 16진수가 그 원소의 시작 주소입니다(주소는 예시값). 양 끝의 회색 칸은 배열 바깥의 메모리입니다. 빨간 화살표가 p가 가리키는 곳입니다.

절차

  1. int에서 p++를 두 번 누르고 주소와 *p를 읽는다.
  2. 자료형을 double, char로 바꿔 p++ 한 번에 주소가 몇씩 바뀌는지 본다.
  3. *p에 쓰기를 눌러 배열의 어느 원소가 바뀌는지 본다.
  4. p++를 계속 눌러 배열 끝을 넘어가 본다.

기대 결과

  • int에서 p++ 두 번이면 주소가 8 늘고 *p는 30(a[2]).
  • p++ 한 번에 double은 8, char는 1씩 주소가 바뀐다. 포인터 연산은 바이트가 아니라 원소 단위다.
  • *p에 쓰면 p가 가리키는 원소 하나만 바뀐다.
  • a + 5(끝 바로 다음)부터는 배열 밖이다. C는 이것을 막지 않는다.

분석

  1. a[i]와 *(a + i)가 같은 이유를 이 그림으로 설명해 보세요.
  2. 배열 밖에 쓰기가 위험한 이유를, 그 자리에 다른 변수가 있을 수 있다는 점으로 말해 보세요.

더 해 보기

실제 C 프로그램에서 printf("%p %p\n", (void *)&a[0], (void *)&a[1]);을 실행해 두 주소의 차이가 sizeof(a[0])과 같은지 확인해 보세요.
