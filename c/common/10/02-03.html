2.3.1for 문

for 변수 in 묶음:은 묶음(리스트, 문자열, range 등)의 값을 하나씩 변수에 넣으며 들여 쓴 부분을 되풀이합니다.

  • range(5): 0, 1, 2, 3, 4.
  • range(1, 6): 1~5 (끝은 포함하지 않음).
  • range(10, 0, -2): 10, 8, 6, 4, 2.
total = 0
for i in range(1, 101):
    total += i
print(total)       # 5050

for i, t in enumerate([20.1, 20.6, 21.3]):
    print(i, t)    # 번호와 값을 함께

반복문 안에 반복문을 넣으면(중첩) 표 같은 2차원 자료를 다룰 수 있습니다. 바깥이 \(m\)번, 안쪽이 \(n\)번이면 안쪽 몸체는 \(mn\)번 실행됩니다.

2.3.2while 문

몇 번 되풀이할지 미리 모를 때는 while 조건:을 씁니다. 몸체 안에서 조건이 언젠가 거짓이 되도록 값을 바꿔야 하며, 그렇지 않으면 끝나지 않습니다(무한 반복, Ctrl+C로 멈춤).

예제 2.3.1

예금 100만 원이 연 5% 복리로 200만 원 이상이 되는 데 몇 년 걸리는가?

money, year = 100, 0
while money < 200:
    money *= 1.05
    year += 1
print(year, round(money, 1))     # 15 207.9

2.3.3break와 continue

  • break: 반복을 곧바로 끝낸다.
  • continue: 이번 차례의 나머지를 건너뛰고 다음 차례로.
for n in range(2, 50):
    if n % 7 == 0 and n % 5 == 3:
        print("찾음:", n)       # 28
        break

반복이 어떻게 진행되는지 헷갈리면 변수 값을 줄마다 표로 적어 보는 것(추적)이 가장 좋은 방법입니다. 아래 실습 카드에서 한 줄씩 따라가 볼 수 있습니다.

요약
  1. for x in 묶음:, range(시작, 끝, 간격)은 끝을 포함하지 않는다.
  2. while 조건:은 조건이 거짓이 될 때까지. 무한 반복 주의.
  3. break는 끝내기, continue는 건너뛰기.

2.3.2

실습반복문 한 줄씩 따라가기

실습 · 프로그램 추적

다루는 성취기준 [공통10-02-03] [공통10-01-02]

목표

짧은 프로그램을 한 줄씩 실행하며 지금 실행하는 줄과 변수 값의 변화를 봅니다. for, while, if가 실제로 어떤 순서로 실행되는지 익힙니다. 성취기준 [공통10-02-03], [공통10-01-02].

준비

칠한 줄이 막 실행한 줄이고, 오른쪽은 그 줄을 실행한 뒤의 변수 값입니다. 조건을 검사하는 줄에서는 출력 줄에 조건의 참·거짓이 나옵니다. "한 줄"을 누를 때마다 한 단계 나아갑니다.

절차

  1. "for: 1부터 5까지 더하기"에서 줄을 넘기기 전에 다음에 칠해질 줄과 total 값을 먼저 예상한다.
  2. for 줄이 모두 몇 번 실행되는지 센다.
  3. "while: 10%씩 늘리기"에서 반복이 끝나는 순간의 money를 본다.
  4. 콜라츠 수열에서 n이 거쳐 가는 값을 모두 적는다.

기대 결과

  • total은 0, 1, 3, 6, 10, 15로 바뀌고 15를 출력한다.
  • for 줄은 6번 실행된다(값을 넣는 5번과 끝을 확인하는 1번).
  • money는 110, 121, 133.1이 되어 3번 만에 조건이 거짓이 된다. 실수 곱셈이라 133.10000000000002처럼 보일 수 있다(6.1절).
  • 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1, 8단계.

분석

  1. while의 조건을 money <= 130으로 바꾸면 결과가 달라지는지 예상해 보세요.
  2. 콜라츠 프로그램에서 steps += 1의 들여쓰기를 한 칸 더 넣어 else 안으로 옮기면 무엇을 세게 되는지 말해 보세요.
