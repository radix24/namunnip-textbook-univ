2.1.1리스트 만들기와 인덱스

실험값 여러 개를 변수 하나로 다루려면 리스트를 씁니다. 대괄호 안에 쉼표로 값을 늘어놓습니다.

T = [20.1, 20.5, 21.3, 22.0, 22.8]   # 온도 측정값
print(T[0])      # 20.1  첫째 (번호는 0부터)
print(T[-1])     # 22.8  마지막
print(len(T))    # 5
T[1] = 20.6      # 값 바꾸기

길이가 5이면 쓸 수 있는 인덱스는 0~4(또는 −5~−1)이고, T[5]는 IndexError입니다.

2.1.2슬라이스

a[시작:끝:간격]은 시작부터 끝 바로 앞까지 간격마다 골라 새 리스트를 만듭니다. 생략하면 처음, 마지막, 1로 봅니다.

a = [0, 10, 20, 30, 40, 50]
a[1:4]     # [10, 20, 30]
a[:3]      # [0, 10, 20]
a[::2]     # [0, 20, 40]
a[::-1]    # [50, 40, 30, 20, 10, 0]  거꾸로

끝을 빼는 규칙 덕분에 a[:k]와 a[k:]를 이으면 원래 리스트가 되고, a[i:j]의 길이는 j - i입니다. 이 카드 아래의 실습에서 직접 바꿔 볼 수 있습니다.

2.1.3추가, 삭제, 함수

쓰는 법하는 일

x in a들어 있는지 (True/False)
sum(a), max(a), min(a)합, 최댓값, 최솟값
a.sort(), sorted(a)제자리 정렬 / 정렬된 새 리스트
 
T.append(23.5)
mean = sum(T) / len(T)
print(f"평균 {mean:.2f}")
같은 리스트를 가리키는 두 이름. b = a는 리스트를 복사하지 않고 같은 리스트에 이름을 하나 더 붙입니다. b[0] = 99를 하면 a[0]도 바뀝니다. 복사하려면 b = a[:]나 b = a.copy()를 씁니다. 이것은 5.2절의 포인터와 비슷한 생각입니다.
요약
  1. 인덱스는 0부터, 음수는 뒤에서부터.
  2. 슬라이스 a[시작:끝:간격]은 끝을 포함하지 않는다.
  3. append, insert, pop, remove, sum, sorted.

2.1.2

실습인덱스와 슬라이스 맞히기

실습 · 파이썬 리스트

다루는 성취기준 [공통10-02-01]

목표

시작, 끝, 간격을 바꿔 가며 a[시작:끝:간격]이 어떤 원소를 어떤 순서로 고르는지 확인합니다. 음수 인덱스와 음수 간격의 규칙도 익힙니다. 성취기준 [공통10-02-01].

준비

원소 위의 숫자는 앞에서 센 인덱스, 아래의 회색 숫자는 뒤에서 센 음수 인덱스입니다. 고른 원소는 파랗게 칠하고 고르는 순서를 빨간 숫자로 표시합니다. 결과를 보기 전에 먼저 답을 예상해 보세요.

절차

  1. a[2:7]의 원소 수를 예상하고 확인한다.
  2. a[-3:](시작 −3, 끝 생략)와 a[:3]을 만든다.
  3. 간격 2로 a[::2], a[1::2]를 만든다.
  4. 간격 −1로 a[::-1]을 만든 뒤 a[7:2:-1]과 a[2:7:-1]을 비교한다.
  5. 시작이나 끝을 12, −12처럼 범위 밖으로 놓아 본다.

기대 결과

  • a[2:7]은 Li부터 N까지 5개. 길이는 7 − 2.
  • a[-3:]는 마지막 셋 O, F, Ne. a[:3]과 a[3:]을 이으면 원래 리스트.
  • a[::-1]은 거꾸로. a[7:2:-1]은 O부터 Be까지 5개, a[2:7:-1]은 빈 리스트.
  • 슬라이스는 범위를 넘어도 오류 없이 있는 데까지만 고른다(인덱스 하나로 읽을 때는 IndexError).

분석

  1. "끝은 포함하지 않는다"는 규칙이 편리한 이유를 두 가지 말해 보세요.
  2. 간격이 음수일 때 시작을 생략하면 어디서 시작하는지 결과로 확인하고 규칙으로 정리해 보세요.
