다루는 성취기준 [공통10-03-01] [공통10-03-02] [공통10-03-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 실습수 리스트를 받아 최솟값, 최댓값, 평균을 한꺼번에 돌려주는 함수 stats를 쓰고, [3, 9, 2, 7, 5]로 확인하세요. [03-01]

    힌트 1

    return a, b, c는 튜플 하나를 돌려줍니다.

    힌트 2

    받는 쪽에서 lo, hi, m = stats(...)로 나눠 받습니다.

    풀이 
    def stats(xs):
    return min(xs), max(xs), sum(xs) / len(xs)
lo, hi, m = stats([3, 9, 2, 7, 5])
print(lo, hi, m)   # 2 9 5.2

    빈 리스트를 넣으면 0으로 나누는 오류가 납니다. 실제 프로그램이라면 if not xs:로 먼저 확인합니다.

  2. 계산재귀 함수 def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)로 fib(5)를 계산할 때 함수가 모두 몇 번 호출되나요? [03-01]

    힌트 1

    \(C(n)\)을 fib(n)의 호출 수라 하면 \(C(0) = C(1) = 1\)이고 \(C(n) = C(n-1) + C(n-2) + 1\).

    힌트 2

    \(C(2) = 3\), \(C(3) = 5\).

    풀이

    \(C(4) = 9\), \(C(5) = 15\)번. 값은 fib(5) = 5. 같은 값(fib(2)는 세 번)을 여러 번 다시 계산하기 때문에 \(n\)이 커지면 호출 수가 지수적으로 늘어납니다. 한 번 계산한 값을 저장해 두면(메모이제이션) \(n\)번 정도로 줄어듭니다.

  3. 실습1부터 10까지의 제곱을 한 줄에 하나씩 squares.txt에 쓰고, 다시 읽어 합을 구하는 프로그램을 쓰세요. [03-02]

    힌트 1

    with open(이름, "w") as f:로 쓰고, "r"로 읽습니다. with는 끝나면 파일을 자동으로 닫습니다.

    힌트 2

    write는 문자열만 받으므로 f"{x}\n"로 바꾸고, 읽은 줄은 int()로 바꿉니다.

    풀이

    for i in range(1, 11):
        f.write(f"{i * i}\n")
with open("squares.txt") as f:
    total = sum(int(line) for line in f)
print(total)   # 385

  4. 실습math 모듈로 \(\sqrt2\)와 \(\pi\)를 소수 넷째 자리까지 출력하고, import math와 from math import sqrt의 차이를 말하세요. [03-03]

    힌트 1

    import math 뒤에는 math.sqrt처럼 모듈 이름을 붙입니다.

    힌트 2

    round(x, 4)나 f"{x:.4f}".

    풀이 
    import math
print(f"{math.sqrt(2):.4f} {math.pi:.4f}")   # 1.4142 3.1416

    from math import sqrt는 sqrt만 가져와 이름 없이 쓰게 합니다. 짧아지지만, 내가 만든 함수와 이름이 겹칠 수 있습니다. from math import *는 무엇이 들어왔는지 알기 어려워 피합니다.

  5. 실습2차원 벡터 클래스 Vector를 만들어 길이를 구하는 메서드 length와 두 벡터를 더하는 __add__를 넣으세요. Vector(3, 4).length()는 5.0이어야 합니다. [03-03]

    힌트 1

    __init__(self, x, y)에서 self.x = x처럼 속성을 저장합니다.

    힌트 2

    __add__(self, other)는 a + b를 쓸 때 불립니다. 새 Vector를 돌려줍니다.

    풀이 
    import math
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def length(self):
        return math.hypot(self.x, self.y)
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
v = Vector(3, 4) + Vector(1, -1)
print(Vector(3, 4).length(), v.x, v.y)   # 5.0 4 3

  6. 판단def add(item, box=[]): box.append(item); return box를 만들고 add(1), add(2)를 차례로 불렀더니 두 번째 결과가 [2]가 아니라 [1, 2]였습니다. 왜 그런지, 어떻게 고쳐야 하는지 말하세요. [03-01]

    힌트 1

    기본값 []는 언제 만들어지나요? 함수를 정의할 때 한 번인가요, 부를 때마다인가요?

    힌트 2

    기본값으로 None을 두고 함수 안에서 새 리스트를 만듭니다.

    풀이

    기본값은 함수를 정의할 때 한 번만 만들어져 모든 호출이 같은 리스트를 씁니다. 고친 코드: def add(item, box=None): 안에서 if box is None: box = []. 바뀔 수 있는 객체(리스트, 딕셔너리)를 기본값으로 쓰지 않는 것이 규칙입니다.
