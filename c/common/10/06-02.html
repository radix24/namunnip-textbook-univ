6.2.1사다리꼴 공식

구간 \([a, b]\)를 폭 \(h = \frac{b-a}{n}\)인 \(n\)개로 나누고, 각 조각의 넓이를 사다리꼴로 어림합니다.

\[\int_a^b f(x)\,dx \approx h\left[\frac{f(x_0)}{2} + f(x_1) + \cdots + f(x_{n-1}) + \frac{f(x_n)}{2}\right], \quad x_i = a + ih.\] 
import math

def trapezoid(f, a, b, n):
    h = (b - a) / n
    s = (f(a) + f(b)) / 2
    for i in range(1, n):
        s += f(a + i * h)
    return h * s

for n in [4, 8, 16, 32]:
    T = trapezoid(math.sin, 0, math.pi, n)
    print(n, T, 2 - T)

\(n\)을 두 배로 하면 오차가 약 \(\frac14\)이 됩니다. 사다리꼴 공식의 오차는 \(h^2\)에 비례합니다(\(f''\)이 연속일 때). 곡선을 직선으로 이었기 때문이며, 포물선으로 잇는 심프슨 공식은 \(h^4\)에 비례해 훨씬 빠르게 줄어듭니다.

6.2.2이분법

연속 함수 \(f\)가 \(f(a)\)와 \(f(b)\)의 부호가 다르면 \([a, b]\) 안에 근이 있습니다(중간값 정리). 가운데 \(m = \frac{a+b}{2}\)에서 부호를 보고 근이 있는 절반을 남기는 일을 되풀이합니다.

def bisect(f, a, b, tol=1e-6):
    if f(a) * f(b) > 0:
        raise ValueError("양 끝의 부호가 같습니다")
    steps = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
        steps += 1
    return (a + b) / 2, steps

print(bisect(lambda x: x * x - 2, 1, 2))   # (1.41421..., 20)

한 번에 구간이 절반이 되므로, 길이 \(L\)인 구간을 허용 오차 \(\varepsilon\) 아래로 줄이는 데 \(\lceil\log_2(L/\varepsilon)\rceil\)번이면 됩니다. \(L = 1\), \(\varepsilon = 10^{-6}\)이면 20번입니다. 느리지만 부호만 바뀌면 반드시 수렴하는 튼튼한 방법이라, 빠른 뉴턴 방법(공통1 3단원)의 출발점을 잡는 데도 씁니다. lambda x: ...는 이름 없는 짧은 함수입니다.

아래 실습 카드에서 \(n\)을 바꾸며 사다리꼴이 곡선을 덮는 모습과 이분법의 구간이 줄어드는 모습을 볼 수 있습니다.
요약
  1. 사다리꼴: \(h[\frac{f_0}{2} + f_1 + \cdots + \frac{f_n}{2}]\), 오차 \(\propto h^2\).
  2. 이분법: 부호가 바뀌는 절반을 남긴다. \(\lceil\log_2(L/\varepsilon)\rceil\)번.

6.2.3연습문제

기본

  1. 사다리꼴 공식으로 \(n = 4\)일 때 오차가 0.104였다. 오차를 \(10^{-4}\) 아래로 하려면 \(n\)이 대략 얼마여야 하는가?
    답

    오차가 \(1/n^2\)에 비례하므로 \(0.104 \times (4/n)^2 < 10^{-4}\), \(n > 4\sqrt{1040} \approx 129\). \(n = 130\) 정도.

  2. 구간 \([0, 4]\)에서 이분법으로 오차 \(10^{-3}\) 아래까지 몇 번 반복해야 하는가?
    답

    \(\log_2 4000 \approx 11.97\), 12번.

6.2.2

실습사다리꼴 공식과 이분법의 수렴

실습 · 수치 적분, 근 찾기

다루는 성취기준 [공통10-06-02]

목표

사다리꼴의 수 \(n\)을 늘리며 오차가 \(1/n^2\)에 비례해 줄어드는 것을, 이분법의 반복 횟수를 늘리며 구간이 절반씩 줄어드는 것을 확인합니다. 성취기준 [공통10-06-02].

준비

사다리꼴 모드에서는 파란 사다리꼴의 넓이 합이 근삿값입니다. 이분법 모드에서는 칠한 띠가 \(n\)번 반복한 뒤 남은 구간이고, 점은 지금까지 검사한 가운데 점입니다. 조절기 \(n\)은 사다리꼴 수 또는 반복 횟수입니다.

절차

  1. 사다리꼴, sin x에서 \(n\) = 4, 8, 16, 32의 오차를 적고 6.2절의 표와 비교한다.
  2. "오차 × n²" 값이 일정한지 본다. x² − 2에서도 확인한다.
  3. 이분법, x² − 2에서 \(n\) = 10, 20의 오차를 본다.
  4. cos x − x의 근을 소수 여섯째 자리까지 맞히려면 몇 번 반복해야 하는지 찾는다.

기대 결과

  • 오차가 0.104, 0.0258, 0.00643, 0.00161로 \(n\)을 두 배 할 때마다 약 1/4.
  • sin x는 오차 × n²이 약 1.65로 거의 일정하다. x² − 2는 사다리꼴이 늘 조금 크게 어림하여 오차가 음수다.
  • 이분법 \(n = 20\)이면 구간 길이 \(2^{-20} \approx 9.5\times10^{-7}\).
  • 약 20번이면 0.739085 근처로 좁혀진다.

분석

  1. x² − 2에서 사다리꼴이 늘 크게 어림하는 이유를 곡선이 아래로 볼록하다는 것으로 설명해 보세요.
  2. 이분법이 오차를 한 번에 절반으로 줄인다면, 유효숫자 한 자리를 더 얻는 데 몇 번이 필요한지 계산해 보세요(\(\log_2 10\)).
