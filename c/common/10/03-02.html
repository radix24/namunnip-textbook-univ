3.2.1파일 열기

실험 자료는 보통 파일로 주어집니다. open(파일이름, 모드)로 열고, 다 쓰면 닫아야 합니다. with를 쓰면 묶음이 끝날 때 자동으로 닫힙니다.

  • "r": 읽기(기본).
  • "w": 쓰기. 같은 이름 파일이 있으면 내용을 지우고 새로 쓴다.
  • "a": 끝에 덧붙이기.

한글이 들어 있으면 encoding="utf-8"을 함께 적어 두는 것이 안전합니다.

3.2.2읽기

파일 data.txt에 시간(s)과 온도(°C)가 한 줄에 하나씩, 공백으로 나뉘어 있다고 합시다.

# data.txt
# t  T
0   20.1
30  24.8
60  29.2
90  33.0
ts, Ts = [], []
with open("data.txt", encoding="utf-8") as f:
    for line in f:                 # 한 줄씩 (끝에 줄바꿈 문자 포함)
        line = line.strip()        # 앞뒤 공백, 줄바꿈 지우기
        if not line or line.startswith("#"):
            continue               # 빈 줄과 주석 건너뛰기
        t, T = line.split()
        ts.append(float(t))
        Ts.append(float(T))
rate = (Ts[-1] - Ts[0]) / (ts[-1] - ts[0])
print(f"평균 가열 속도 {rate:.4f} °C/s")   # 0.1433

쉼표로 나뉜 CSV 파일이면 line.split(",")을 쓰거나 표준 모듈 csv를 씁니다(3.3절).

3.2.3쓰기와 오류 처리

with open("result.txt", "w", encoding="utf-8") as f:
    for t, T in zip(ts, Ts):
        f.write(f"{t:6.1f} {T:6.2f}\n")   # write는 줄바꿈을 직접 넣어야 한다

파일이 없으면 FileNotFoundError, 숫자가 아닌 글자를 float()로 바꾸면 ValueError가 납니다. 프로그램이 멈추지 않게 하려면

try:
    f = open("data.txt", encoding="utf-8")
except FileNotFoundError:
    print("파일이 없습니다")
요약
  1. with open(이름, 모드, encoding="utf-8") as f:. 모드 r, w(덮어씀), a.
  2. 줄마다 strip() → split() → float().
  3. write는 \n을 직접. 오류는 try / except.

3.2.4연습문제

기본

  1. 위 자료에서 온도의 섭씨값을 절대 온도로 바꿔 kelvin.txt에 쓰는 코드를 써라.
    답

    쓰기 반복에서 f.write(f"{t} {T + 273.15:.2f}\n").
