연습파이썬 자료 구조와 반복 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통10-02-01] [공통10-02-02] [공통10-02-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산a = [3, 1, 4, 1, 5]에서 a.append(9), a.sort()를 차례로 한 뒤 a, a[1:3], a.count(1)은? [02-01]

    힌트 1

    append는 맨 뒤에 하나를 붙이고, sort는 리스트 자체를 오름차순으로 바꿉니다.

    힌트 2

    정렬 뒤 [1, 1, 3, 4, 5, 9].

    풀이

    a = [1, 1, 3, 4, 5, 9], a[1:3] = [1, 3], a.count(1) = 2. a.sort()는 아무것도 돌려주지 않으므로(None) a = a.sort()라고 쓰면 리스트를 잃습니다. 원본을 두고 새 리스트를 원하면 sorted(a)를 씁니다.

  2. 실습문장 "to be or not to be"에서 단어마다 나온 횟수를 딕셔너리로 세는 프로그램을 쓰세요. [02-02]

    힌트 1

    split()으로 단어 리스트를 만들고, 딕셔너리에 단어를 키로 횟수를 값으로 넣습니다.

    힌트 2

    처음 보는 단어는 0에서 시작해야 합니다. d.get(w, 0)을 쓰세요.

    풀이 
    count = {}
for w in "to be or not to be".split():
    count[w] = count.get(w, 0) + 1
print(count)

    출력: {'to': 2, 'be': 2, 'or': 1, 'not': 1}. count[w] += 1만 쓰면 처음 나온 단어에서 KeyError가 납니다.

  3. 개념점의 좌표 \((x, y)\)는 리스트 [x, y]와 튜플 (x, y) 가운데 무엇으로 저장하는 것이 알맞을까요? 딕셔너리의 키로 쓸 수 있는 것은? [02-02]

    힌트 1

    튜플은 한번 만들면 바꿀 수 없습니다.

    힌트 2

    딕셔너리의 키는 바뀌지 않는(해시할 수 있는) 값이어야 합니다.

    풀이

    좌표처럼 묶음 자체가 하나의 값이고 바뀔 일이 없으면 튜플이 알맞습니다. 실수로 원소를 바꾸는 일을 막아 주고, 딕셔너리의 키(예: grid[(2, 3)] = '벽')로도 쓸 수 있습니다. 리스트는 바뀔 수 있어서 키가 될 수 없습니다.

  4. 실습(가) 1부터 100까지의 합과 짝수만의 합을 for로 구하세요. (나) 27에서 시작해 짝수면 2로 나누고 홀수면 3배 하고 1을 더하는 일을 1이 될 때까지 되풀이할 때 몇 번 걸리는지 while로 구하세요. [02-03]

    힌트 1

    range(1, 101)은 1부터 100까지, range(2, 101, 2)는 짝수입니다.

    힌트 2

    몇 번 걸릴지 미리 모르는 반복은 while 조건:으로 씁니다.

    풀이 
    total = 0
for i in range(1, 101):
    total += i
print(total, sum(range(2, 101, 2)))   # 5050 2550
n, steps = 27, 0
while n != 1:
    n = n // 2 if n % 2 == 0 else 3 * n + 1
    steps += 1
print(steps)                          # 111

    range(1, 100)이라고 쓰면 100이 빠져 4950이 나옵니다. 끝 값은 포함되지 않습니다.

  5. 계산다음 코드의 출력을 예측하세요. for i in range(1, 4): print("*" * i)와 for i in range(3): for j in range(i): print(i, j) [02-03]

    힌트 1

    바깥 반복이 한 번 돌 때 안쪽 반복이 처음부터 끝까지 돕니다.

    힌트 2

    range(0)은 한 번도 돌지 않습니다.

    풀이

    첫째: *, **, *** 세 줄. 둘째: i = 0에서는 출력 없음, i = 1에서 1 0, i = 2에서 2 0, 2 1. 모두 세 줄입니다.

  6. 판단a = [1, 2, 3]; b = a; b.append(4) 뒤에 print(a)를 하면 [1, 2, 3]이 나올 것이라고 예상한 학생이 있습니다. 판단하고, a를 그대로 두려면 어떻게 해야 하나요? [02-01]

    힌트 1

    b = a는 리스트를 복사하나요, 같은 리스트에 이름을 하나 더 붙이나요?

    힌트 2

    a is b를 실행해 보세요.

    풀이

    틀렸습니다. b = a는 같은 리스트 객체에 이름을 하나 더 붙일 뿐이라 a도 [1, 2, 3, 4]가 됩니다. 복사본을 원하면 b = a.copy()나 b = a[:]를 씁니다. 리스트 안에 리스트가 있으면 copy.deepcopy가 필요합니다.
