5.R.1

연습C/C++ 배열, 포인터, 구조체, 클래스 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통10-05-01] [공통10-05-02] [공통10-05-03] [공통10-05-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 실습배열 int a[5] = {3, 9, 2, 7, 5};의 최댓값과 평균(소수 둘째 자리)을 출력하는 C 코드를 쓰세요. [05-01]

    힌트 1

    최댓값은 첫 원소로 시작해 더 큰 값을 만나면 바꿉니다.

    힌트 2

    배열의 원소 수는 sizeof a / sizeof a[0]로 구할 수 있습니다.

    풀이 
    int a[5] = {3, 9, 2, 7, 5};
int n = sizeof a / sizeof a[0], mx = a[0], sum = 0;
for (int i = 0; i < n; i++) {
    if (a[i] > mx) mx = a[i];
    sum += a[i];
}
printf("%d %.2f\n", mx, (double)sum / n);   /* 9 5.20 */

    배열 번호는 0부터 n − 1까지입니다. i <= n으로 쓰면 배열 밖을 읽습니다.

  2. 계산int x = 10; int *p = &x; *p = 20; 뒤에 x의 값은? 또 int a[3]에서 a[1]과 *(a + 1)은 같은가요? [05-02]

    힌트 1

    &x는 x의 주소, *p는 p가 가리키는 곳의 값입니다.

    힌트 2

    배열 이름 a는 첫 원소의 주소처럼 쓰이고, 포인터에 1을 더하면 원소 하나 크기(int면 4바이트)만큼 나아갑니다.

    풀이

    x는 20입니다. p가 x를 가리키므로 *p = 20은 x를 바꿉니다. a[1]과 *(a + 1)은 정의상 같은 것입니다. a + 1의 주소는 a보다 1바이트가 아니라 sizeof(int)만큼 큽니다.

  3. 실습두 정수를 맞바꾸는 함수 swap을 쓰세요. void swap(int a, int b)로는 왜 안 되나요? [05-02]

    힌트 1

    C는 인자의 값을 복사해서 넘깁니다.

    힌트 2

    주소를 넘겨 받으면 원래 변수를 바꿀 수 있습니다.

    풀이 
    void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
/* 쓰는 법: swap(&x, &y); */

    swap(int a, int b)는 복사본만 바꾸고 끝나므로 원래 x, y는 그대로입니다.

  4. 실습C++로 가로, 세로를 가진 클래스 Rect를 만들고 넓이를 돌려주는 멤버 함수를 넣으세요. C의 struct와 C++의 class의 차이를 하나 말하세요. [05-03]

    힌트 1

    멤버 변수와 멤버 함수를 함께 묶습니다.

    힌트 2

    public:을 쓰지 않으면 class의 멤버는 바깥에서 쓸 수 없습니다.

    풀이 
    #include <iostream>
class Rect {
public:
    double w, h;
    Rect(double w_, double h_) : w(w_), h(h_) {}
    double area() const { return w * h; }
};
int main() {
    Rect r(3.0, 4.5);
    std::cout << r.area() << "\n";   // 13.5
}

    C의 struct는 자료만 묶고, C++의 class는 자료와 그 자료를 다루는 함수를 함께 묶습니다. C++에서 struct는 멤버가 기본으로 public, class는 기본으로 private인 것만 다릅니다.

  5. 실습구조체로 연결 리스트의 노드를 정의하고, 리스트 앞에 값을 넣는 함수 push_front를 쓰세요. 원소가 \(n\)개인 배열의 맨 앞에 넣는 일과 비교해 일의 양은? [05-04]

    힌트 1

    노드는 값과 다음 노드의 주소를 가집니다: struct Node { int val; struct Node *next; };

    힌트 2

    새 노드를 malloc으로 만들고, 그 노드의 next를 지금의 head로, head를 새 노드로 바꿉니다.

    풀이 
    Node *push_front(Node *head, int v) {
    Node *p = malloc(sizeof(Node));
    p->val = v;
    p->next = head;
    return p;   /* 새 head */
}

    연결 리스트는 \(n\)과 상관없이 포인터 2개만 바꾸면 되고, 배열은 원소 \(n\)개를 모두 한 칸씩 옮겨야 합니다. 대신 연결 리스트는 \(i\)번째 원소를 읽으려면 링크를 \(i\)번 따라가야 합니다(5.4절 실습).

  6. 판단다음 함수는 무엇이 잘못되었나요? int *make(void) { int a[3] = {1, 2, 3}; return a; } [05-02]

    힌트 1

    지역 변수 a는 함수가 끝나면 어떻게 되나요?

    힌트 2

    오래 쓸 배열은 malloc으로 만들거나 호출한 쪽에서 배열을 넘겨줍니다.

    풀이

    지역 배열 a는 함수가 끝나면 사라지므로, 돌려준 주소는 이미 쓰지 않는 메모리를 가리킵니다(댕글링 포인터). 운이 좋으면 잠깐 맞는 값이 보여 더 찾기 어렵습니다. int *a = malloc(3 * sizeof(int));로 만들고 다 쓴 뒤 free하거나, void make(int a[])처럼 바깥 배열을 채웁니다.
