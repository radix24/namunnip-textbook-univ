2.2.1튜플

튜플은 괄호로 만들며, 리스트처럼 인덱스와 슬라이스를 쓰지만 만든 뒤에는 바꿀 수 없습니다. 좌표처럼 한 덩어리로 다루는 값에 씁니다.

p = (3.0, 4.0)
x, y = p              # 풀어서 두 변수에 넣기
a, b = b, a           # 두 변수 값 바꾸기 (오른쪽이 튜플)
p[0] = 1.0            # TypeError: 튜플은 바꿀 수 없다

함수가 값을 여러 개 돌려줄 때도 튜플을 씁니다(3.1절).

2.2.2딕셔너리

딕셔너리는 키와 값의 쌍을 모은 것입니다. 번호 대신 이름(키)으로 값을 찾습니다.

M = {"H": 1.008, "C": 12.011, "O": 15.999}   # 원자량
print(M["O"])          # 15.999
M["N"] = 14.007        # 새 키 추가
M["H"] = 1.00794       # 값 바꾸기
print("Na" in M)       # False  (키가 있는지)
print(M.get("Na", 0))  # 0      (없으면 기본값)
for k, v in M.items():
    print(k, v)

없는 키를 M["Na"]로 읽으면 KeyError가 납니다. 키는 문자열, 숫자, 튜플처럼 바꿀 수 없는 값이어야 합니다.

예제 2.2.1

물({"H": 2, "O": 1})의 몰질량을 위의 원자량 사전으로 구하여라.

water = {"H": 2, "O": 1}
molar = 0
for el, n in water.items():
    molar += M[el] * n
print(round(molar, 3))      # 18.015 (H = 1.008일 때)

2.2.3무엇을 고를까

자료 구조찾는 방법바꿀 수 있나알맞은 곳
리스트 [ ]번호예순서 있는 측정값 모음
튜플 ( )번호아니요좌표, 고정된 설정값, 여러 값 반환
딕셔너리 { : }키예이름으로 찾는 표 (원소 → 원자량)
요약
  1. 튜플: 바꿀 수 없는 묶음, 풀어서 대입.
  2. 딕셔너리: d[키]로 찾고, in, get, items().

2.2.4연습문제

기본

  1. 문자열 s = "banana"의 글자별 개수를 딕셔너리로 세는 코드를 써라.
    답

    c = {} 후 for ch in s: c[ch] = c.get(ch, 0) + 1. 결과 {'b': 1, 'a': 3, 'n': 2}.
