4.3.1정규분포

\(X \sim N(\mu, \sigma^2)\)의 pdf는

\[f(x) = \frac1{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right).\]

측정 오차, 가공 치수처럼 작은 원인이 많이 더해진 양이 이 분포를 따르는 경우가 많습니다(중심극한정리, 6.3절). 이 pdf의 부정적분은 초등함수로 나타낼 수 없어 표나 계산기로 구합니다.

\(Z = \frac{X - \mu}{\sigma}\)로 표준화하면 \(Z \sim N(0, 1)\)이고, 그 cdf를 \(\Phi(z)\)로 씁니다. \(\Phi(-z) = 1 - \Phi(z)\).

  • \(P(|Z| \le 1) \approx 0.683\), \(P(|Z| \le 2) \approx 0.954\), \(P(|Z| \le 3) \approx 0.997\).
  • 자주 쓰는 분위수: \(z_{0.05} = 1.645\), \(z_{0.025} = 1.960\), \(z_{0.005} = 2.576\) (오른쪽 꼬리 넓이).
예제 4.3.1

축의 지름이 \(N(25.00, 0.02^2)\) mm를 따른다. 규격 \(25.00 \pm 0.03\) mm 안에 들 확률은? 불량을 1% 이하로 하려면 \(\sigma\)가 얼마 이하여야 하는가?

풀이. \(P(|Z| \le 1.5) = 2\Phi(1.5) - 1 \approx 0.866\). 불량 13%로 많습니다. \(P(|Z| > 0.03/\sigma) \le 0.01\)이려면 \(0.03/\sigma \ge 2.576\), \(\sigma \le 0.0116\) mm.

4.3.2이항분포의 정규 근사

\(X \sim B(n, p)\)에서 \(np\)와 \(n(1-p)\)가 충분히 크면(대략 각각 5 또는 10 이상) \(X\)는 근사적으로 \(N(np, np(1-p))\)입니다. 이산 분포를 연속 분포로 어림하므로, 막대 하나가 \([k - 0.5, k + 0.5]\)를 차지한다고 보고 경계를 0.5 옮깁니다(연속성 보정).

\[P(X \le k) \approx \Phi\left(\frac{k + 0.5 - np}{\sqrt{np(1-p)}}\right).\]
예제 4.3.2

불량률 10%인 공정에서 100개를 뽑을 때 불량이 15개 이하일 확률은?

풀이. \(\mu = 10\), \(\sigma = 3\). 보정하면 \(\Phi\left(\frac{15.5 - 10}3\right) = \Phi(1.83) \approx 0.967\). 정확한 이항 확률은 0.960이고, 보정하지 않은 \(\Phi(5/3) \approx 0.952\)보다 보정한 쪽이 가깝습니다.

요약
  1. \(Z = (X - \mu)/\sigma\), \(\Phi\)로 확률, 분위수 1.645, 1.960, 2.576.
  2. 이항 ≈ \(N(np, np(1-p))\), 연속성 보정 ±0.5.

4.3.2

실습이항분포를 정규분포로 바꿀 때 왜 0.5를 더할까?

실습 · 정규 근사와 연속성 수정

다루는 성취기준 [공통12-04-03]

목표

불량률 \(p\)인 부품 \(n\)개 가운데 불량이 \(k\)개 이하일 확률처럼, 이항분포의 누적 확률은 \(n\)이 크면 정규분포로 어림합니다. 막대(이항)와 곡선(정규)을 겹쳐 보고, 막대의 폭 때문에 생기는 "0.5 수정"이 왜 필요한지 확인합니다. 성취기준 [공통12-04-03].

준비

  • \(X \sim B(n, p)\)의 평균은 \(np\), 표준편차는 \(\sqrt{np(1 - p)}\)입니다. 같은 평균과 표준편차를 가진 정규분포 곡선(주황)을 겹쳐 그립니다.
  • 진한 막대가 \(P(X \le k)\)에 들어가는 부분입니다. 막대 \(k\)는 \(k - 0.5\)부터 \(k + 0.5\)까지 폭 1을 차지하므로, 곡선 아래 넓이로 어림할 때는 \(k + 0.5\)까지 재야 합니다(세로 점선). 이것이 연속성 수정입니다.
  • \(\Phi\)는 표준정규분포의 누적분포함수입니다.

절차

  1. \(n = 20\), \(p = 0.5\), \(k = 8\)에서 세 값(정확, 정규 근사, 연속성 수정)을 기록합니다.
  2. \(n = 30\), \(p = 0.3\), \(k = 6\)과 \(n = 100\), \(p = 0.1\), \(k = 7\)에서 같은 것을 기록합니다.
  3. \(n = 10\), \(p = 0.1\), \(k = 1\)로 놓고 막대 모양과 곡선을 비교합니다.

기대 결과

  • \(n = 20\), \(p = 0.5\), \(k = 8\): 정확한 값 0.2517, 수정 없는 근사 0.1855(오차 −0.066), 연속성 수정 0.2512(오차 −0.0006). 0.5를 더하는 것만으로 오차가 100분의 1 가까이 줍니다.
  • \(n = 30\), \(p = 0.3\), \(k = 6\): 정확 0.1595, 수정 없이 0.1160, 수정하면 0.1596.
  • \(n = 100\), \(p = 0.1\), \(k = 7\): 정확 0.2061, 수정하면 0.2023.
  • \(n = 10\), \(p = 0.1\): \(np = 1\)이라 막대가 한쪽으로 치우쳐 있고 곡선은 0보다 왼쪽까지 퍼집니다. 연속성 수정을 해도 0.7009로 정확한 값 0.7361과 0.035나 다릅니다. 흔히 \(np \ge 5\), \(n(1 - p) \ge 5\)일 때 정규 근사를 씁니다.

분석

  1. \(P(X \ge k)\)나 \(P(X = k)\)를 어림할 때는 각각 어디까지 재야 하나요? 그림의 막대 폭으로 설명해 보세요.
  2. \(p\)가 0.5에서 멀어질수록 같은 \(n\)에서 근사가 나빠지는 이유를 막대 모양의 치우침으로 설명해 보세요.

더 해 보기

정규 근사가 성립하는 이유는 중심극한정리(6.3절)입니다. 이항분포는 베르누이 확률변수 \(n\)개의 합이기 때문입니다. \(p\)가 아주 작고 \(n\)이 크면 정규분포 대신 포아송 분포(4.1절)로 어림하는 것이 더 정확합니다.
