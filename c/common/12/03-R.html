3.R.1

연습확률변수의 적률 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통12-03-01] [공통12-03-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산주사위 눈 \(X\)의 기댓값과 분산을 구하세요. [03-01]

    힌트 1

    \(E[X] = \sum xp(x)\), \(\operatorname{Var}(X) = E[X^2] - (E[X])^2\).

    힌트 2

    \(E[X^2] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6\).

    풀이

    \(E[X] = 21/6 = 3.5\), \(\operatorname{Var}(X) = 91/6 - 12.25 = 35/12 \approx 2.92\), 표준편차 1.71.

  2. 계산\(f(x) = \tfrac38x^2\) (\(0 \le x \le 2\))의 기댓값과 분산을 구하세요. [03-01]

    힌트 1

    \(E[X] = \int xf(x)\,dx\), \(E[X^2] = \int x^2f(x)\,dx\).

    힌트 2

    \(\int_0^2 \tfrac38x^3dx\), \(\int_0^2 \tfrac38x^4dx\).

    풀이

    \(E[X] = \tfrac38 \cdot 4 = 1.5\), \(E[X^2] = \tfrac38 \cdot \tfrac{32}5 = 2.4\), \(\operatorname{Var}(X) = 2.4 - 2.25 = 0.15\).

  3. 계산어느 도시의 하루 기온은 평균 20 °C, 표준편차 2 °C입니다. 화씨(\(F = 1.8C + 32\))로 바꾼 기온의 평균과 표준편차를 구하세요. [03-01]

    힌트 1

    \(E[aX + b] = aE[X] + b\), \(\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)\).

    힌트 2

    표준편차는 \(|a|\)배가 되고, 더한 상수 \(b\)는 퍼짐에 영향을 주지 않습니다.

    풀이

    평균 \(1.8 \times 20 + 32 = 68\) °F, 표준편차 \(1.8 \times 2 = 3.6\) °F.

  4. 계산이항분포 \(B(n, p)\)의 적률생성함수가 \(M(t) = (1 - p + pe^t)^n\)임을 써서 평균과 분산을 구하세요. [03-02]

    힌트 1

    \(E[X] = M'(0)\), \(E[X^2] = M''(0)\).

    힌트 2

    \(M'(t) = n(1 - p + pe^t)^{n-1}pe^t\).

    풀이

    \(M'(0) = np\). \(M''(t) = n(n - 1)(\cdots)^{n-2}(pe^t)^2 + n(\cdots)^{n-1}pe^t\)에서 \(M''(0) = n(n - 1)p^2 + np\). 분산 \(= n(n-1)p^2 + np - n^2p^2 = np(1 - p)\).

  5. 계산포아송 분포의 적률생성함수 \(M(t) = e^{\lambda(e^t - 1)}\)로 평균과 분산을 구하세요. [03-02]

    힌트 1

    \(M'(t) = \lambda e^tM(t)\).

    힌트 2

    \(M''(t) = \lambda e^tM(t) + \lambda e^tM'(t)\).

    풀이

    \(M'(0) = \lambda\), \(M''(0) = \lambda + \lambda^2\), 분산 \(= \lambda\). 포아송 분포는 평균과 분산이 같습니다. 자료의 평균과 분산이 크게 다르면 포아송 모형을 의심해야 합니다.

  6. 판단“\(E[X^2] = (E[X])^2\)이다.” 주사위로 확인하고 판단하세요. [03-01]

    힌트 1

    주사위의 \(E[X^2]\)와 \((E[X])^2\)을 구해 봅니다.

    힌트 2

    둘의 차는 무엇인가요?

    풀이

    틀렸습니다. \(E[X^2] = 15.17\), \((E[X])^2 = 12.25\)로 다릅니다. 차이가 바로 분산이고, 분산은 0 이상이므로 언제나 \(E[X^2] \ge (E[X])^2\)입니다. 같은 것은 \(X\)가 상수일 때뿐입니다.
