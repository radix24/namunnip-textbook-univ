2.2.1확률밀도함수

부품의 수명, 축의 지름처럼 연속적인 양은 특정한 한 값을 가질 확률이 0입니다(지름이 정확히 25.000000...mm일 확률). 그래서 확률을 구간에 대해서만 말하고, 넓이로 나타냅니다.

정의 2.2.1

함수 \(f\)가 \(f(x) \ge 0\), \(\int_{-\infty}^{\infty} f(x)\,dx = 1\)이고 모든 \(a \le b\)에 대해

\[P(a \le X \le b) = \int_a^b f(x)\,dx\]

이면 \(f\)를 \(X\)의 확률밀도함수(pdf)라 한다.

  • \(P(X = a) = 0\)이므로 \(\le\)와 \(<\)를 구별할 필요가 없다.
  • \(f(x)\) 자체는 확률이 아니라 밀도(단위 길이당 확률)라서 1보다 클 수 있다.
  • 짧은 구간에서 \(P(x \le X \le x + \Delta x) \approx f(x)\Delta x\).

2.2.2누적분포함수와의 관계

\[F(x) = \int_{-\infty}^{x} f(t)\,dt, \qquad f(x) = F'(x) \quad (\text{미분 가능한 곳에서}).\]

연속 확률변수의 cdf는 연속 함수입니다. \(P(a < X \le b) = F(b) - F(a)\)는 이산일 때와 같습니다.

예제 2.2.2

\(f(x) = cx^2\) (\(0 \le x \le 2\)), 나머지는 0. \(c\), \(F(x)\), \(P(1 < X < 2)\), 중앙값을 구하여라.

풀이.

  • \(\int_0^2 cx^2\,dx = \frac{8c}{3} = 1\)에서 \(c = \frac38\).
  • \(0 \le x \le 2\)에서 \(F(x) = \frac{x^3}{8}\). \(x < 0\)이면 0, \(x > 2\)이면 1.
  • \(P(1 < X < 2) = F(2) - F(1) = 1 - \frac18 = \frac78\).
  • 중앙값 \(m\): \(F(m) = \frac12\)에서 \(m^3 = 4\), \(m = 4^{1/3} \approx 1.587\).

2.2.3분위수

\(F(x_p) = p\)인 \(x_p\)를 \(100p\) 백분위수라 합니다. 중앙값은 \(x_{0.5}\)입니다. 품질 관리에서 "부품의 10%가 고장 나는 시간"(\(B_{10}\) 수명)처럼 씁니다. 예를 들어 지수분포 \(F(t) = 1 - e^{-\lambda t}\)이면 \(t_p = -\frac{\ln(1-p)}{\lambda}\)입니다(4.2절). 아래 실습 카드에서 구간을 바꾸며 넓이(확률)와 누적분포함수를 함께 볼 수 있습니다.

요약
  1. \(P(a \le X \le b) = \int_a^b f\), \(f \ge 0\), 전체 넓이 1. 한 점의 확률은 0.
  2. \(F(x) = \int_{-\infty}^x f\), \(f = F'\).
  3. 분위수: \(F(x_p) = p\).

2.2.4연습문제

기본

  1. \(F(x) = 1 - e^{-x/2}\) (\(x \ge 0\))일 때 pdf와 \(P(X > 3)\)을 구하여라.
    답

    \(f(x) = \frac12e^{-x/2}\). \(P(X > 3) = e^{-1.5} \approx 0.223\).

2.2.2

실습확률은 넓이, 누적분포는 쌓인 넓이

실습 · pdf와 cdf

다루는 성취기준 [공통12-02-02] [공통12-02-01]

목표

구간 \([a, b]\)를 움직이며 pdf 아래의 넓이가 \(F(b) - F(a)\)와 같다는 것을 두 그래프로 확인합니다. 밀도와 확률의 차이도 봅니다. 성취기준 [공통12-02-02], [공통12-02-01].

준비

위는 pdf \(f(x)\)와 칠한 넓이, 아래는 cdf \(F(x)\)입니다. 주황 점선이 \(F(a)\), 빨간 점선이 \(F(b)\)이고, 두 높이의 차이가 위에서 칠한 넓이입니다.

절차

  1. 2.2절 예제(\(a = 1\), \(b = 2\))의 확률이 \(\frac78\)인지 확인한다.
  2. \(a\)와 \(b\)를 같게 놓아 한 점의 확률을 본다.
  3. 지수분포에서 \(a = 0\), \(b\)를 중앙값 근처로 놓아 확률이 0.5가 되는 곳을 찾는다.
  4. 표준정규분포에서 \([-1, 1]\), \([-2, 2]\), \([-1.96, 1.96]\)의 확률을 읽는다.

기대 결과

  • \(P(1 \le X \le 2) = 1 - 0.125 = 0.875\). 이 분포의 최대 밀도는 1.5로 1보다 크다.
  • \(a = b\)이면 확률이 0이다.
  • 지수분포의 중앙값은 \(2\ln 2 \approx 1.386\)으로 평균 2보다 작다.
  • 정규분포: 0.683, 0.954, 0.950.

분석

  1. cdf 그래프의 기울기가 가장 가파른 곳은 pdf 그래프에서 어디인지 말하고, \(f = F'\)으로 설명해 보세요.
  2. 균일분포의 cdf가 직선인 이유를 말해 보세요.
