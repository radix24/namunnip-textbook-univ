5.2.1정의와 판정

정의 5.2.1

모든 \(x, y\)에서 \(p(x, y) = p_X(x)\,p_Y(y)\) (연속이면 \(f(x, y) = f_X(x)\,f_Y(y)\))이면 \(X\)와 \(Y\)는 독립이다.

한 칸이라도 곱과 다르면 독립이 아닙니다. 5.1절 예제에서 \(p(0, 0) = 0.10 = 0.40 \times 0.25\)이지만 \(p(0, 1) = 0.20 \ne 0.40 \times 0.45 = 0.18\)이므로 독립이 아닙니다. 같은 뜻으로, 조건부분포가 조건에 따라 달라지면(\(X = 0\)일 때와 \(X = 1\)일 때 \(Y\)의 분포가 다르면) 독립이 아닙니다.

연속인 경우에 빠르게 판정하는 방법은 다음과 같습니다.

  • \(f(x, y)\)가 \(g(x)h(y)\) 꼴로 인수분해된다.
  • \(f\)가 0이 아닌 영역이 직사각형 \(a \le x \le b\), \(c \le y \le d\)이다.

두 조건이 모두 맞으면 독립입니다. 5.1절 예제 5.1.2의 \(f = 2\)는 상수라 인수분해되지만, 영역이 삼각형(\(y \le x\))이라 독립이 아닙니다. \(X\)가 작으면 \(Y\)도 작아야 하기 때문입니다.

5.2.2독립의 결과

  • \(E[XY] = E[X]\,E[Y]\), 더 일반적으로 \(E[g(X)h(Y)] = E[g(X)]\,E[h(Y)]\).
  • \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)\) (5.3절).
  • mgf: \(M_{X+Y} = M_XM_Y\) (3.2절).
예제 5.2.2

독립인 두 부품의 수명이 각각 \(\text{Exp}(\lambda_1)\), \(\text{Exp}(\lambda_2)\)이다. 직렬로 연결한 시스템의 수명 \(T = \min(T_1, T_2)\)의 분포는?

풀이. 독립이므로 \(P(T > t) = P(T_1 > t)P(T_2 > t) = e^{-(\lambda_1 + \lambda_2)t}\). \(T \sim \text{Exp}(\lambda_1 + \lambda_2)\)이고 평균 수명은 \(\frac1{\lambda_1 + \lambda_2}\)로 짧아집니다. 1.3절 직렬 신뢰도의 연속판입니다.

독립이면 공분산이 0이지만(5.3절), 공분산이 0이라고 독립인 것은 아닙니다. \(X\)가 \(\{-1, 0, 1\}\)에서 균일하고 \(Y = X^2\)이면 공분산은 0이지만 \(Y\)는 \(X\)로 완전히 정해집니다.
요약
  1. 독립 ⟺ 결합 = 주변의 곱 (모든 점에서).
  2. 연속: 인수분해 + 직사각형 영역이면 독립.
  3. 독립이면 \(E[XY] = E[X]E[Y]\), 분산이 더해진다.

5.2.3연습문제

기본

  1. \(f(x, y) = 6e^{-2x - 3y}\) (\(x, y \ge 0\))에서 \(X\)와 \(Y\)는 독립인가? 주변분포는?
    답

    \(2e^{-2x}\cdot3e^{-3y}\)로 인수분해되고 영역이 사분면이라 독립. \(X \sim \text{Exp}(2)\), \(Y \sim \text{Exp}(3)\).
