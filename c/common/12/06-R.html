6.R.1

연습확률변수의 함수 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통12-06-01] [공통12-06-02] [공통12-06-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산\(X\)가 \((0, 1)\)의 균일분포를 따를 때 \(Y = -\ln X\)의 분포를 구하세요. [06-01]

    힌트 1

    누적분포함수 방법: \(F_Y(y) = P(Y \le y)\)를 \(X\)에 대한 사건으로 바꿉니다.

    힌트 2

    \(-\ln X \le y \iff X \ge e^{-y}\).

    풀이

    \(F_Y(y) = P(X \ge e^{-y}) = 1 - e^{-y}\) (\(y \ge 0\))이므로 \(Y\)는 평균 1인 지수분포입니다. 컴퓨터가 균일 난수로 지수 난수를 만드는 방법입니다.

  2. 계산\(X\)가 \((-1, 1)\)의 균일분포를 따를 때 \(Y = X^2\)의 밀도함수를 구하세요. [06-01]

    힌트 1

    \(P(Y \le y) = P(-\sqrt y \le X \le \sqrt y)\).

    힌트 2

    균일분포이므로 길이 \(2\sqrt y\)에 밀도 \(1/2\)를 곱합니다.

    풀이

    \(F_Y(y) = \sqrt y\) (\(0 \le y \le 1\)), \(f_Y(y) = \dfrac{1}{2\sqrt y}\). 0 근처에서 밀도가 커지는 것은 \(X\)가 0 근처에 있으면 \(X^2\)이 훨씬 작은 값으로 몰리기 때문입니다.

  3. 적용길이가 평균 10, 20, 30 mm이고 표준편차 0.1, 0.2, 0.2 mm인 부품 세 개를 독립으로 이어 붙입니다. 전체 길이의 평균과 표준편차, 전체가 60.6 mm를 넘을 확률을 구하세요(정규분포로 봅니다). [06-02]

    힌트 1

    독립이면 분산이 더해집니다(표준편차가 더해지는 것이 아님).

    힌트 2

    \(\sigma^2 = 0.01 + 0.04 + 0.04 = 0.09\).

    풀이

    평균 60 mm, 표준편차 0.3 mm. \(P(> 60.6) = P(Z > 2) = 0.023\). 표준편차를 그냥 더하면 0.5 mm가 되어 공차를 지나치게 크게 잡게 됩니다.

  4. 계산구멍 지름은 \(N(25.10, 0.03^2)\), 축 지름은 \(N(25.00, 0.04^2)\) mm이고 서로 독립입니다. 축이 구멍에 들어가지 않을 확률을 구하세요. [06-02]

    힌트 1

    틈 \(D\) = 구멍 − 축의 분포를 구합니다. 차의 분산도 두 분산의 합입니다.

    힌트 2

    \(D\)의 평균 0.10, 표준편차 \(\sqrt{0.0009 + 0.0016} = 0.05\).

    풀이

    \(P(D < 0) = P(Z < -2) = 0.023\), 약 2.3%.

  5. 계산전구의 수명은 평균 1000시간, 표준편차 200시간입니다. 36개의 평균 수명이 950시간 이하일 확률을 어림하세요. [06-03]

    힌트 1

    중심극한정리: 표본평균은 근사적으로 \(N(\mu, \sigma^2/n)\).

    힌트 2

    표준오차 \(200/\sqrt{36} = 33.3\).

    풀이

    \(z = (950 - 1000)/33.3 = -1.5\), 확률 \(\Phi(-1.5) = 0.067\). 전구 하나의 수명 분포가 정규분포가 아니어도 36개의 평균은 정규분포에 가깝습니다.

  6. 판단“중심극한정리에 따르면 표본을 많이 뽑으면 각 측정값이 정규분포를 따르게 된다.” 판단하세요. [06-03]

    힌트 1

    중심극한정리는 무엇의 분포에 대한 정리인가요?

    힌트 2

    주사위 눈을 1000번 기록한 히스토그램을 생각해 보세요.

    풀이

    틀렸습니다. 주사위 눈을 아무리 많이 기록해도 1~6이 고르게 나오는 균일분포 그대로입니다. 정규분포에 가까워지는 것은 여러 값의 합이나 평균의 분포입니다(공통7 6.2절 모의실험).
