3.2.1적률

\(E[X^k]\)을 \(k\)차 적률이라 합니다. 1차 적률은 평균, 2차 적률로 분산(\(E[X^2] - \mu^2\))을 얻습니다. 3차, 4차 중심 적률은 분포의 비대칭(왜도)과 꼬리의 두께(첨도)를 나타냅니다.

3.2.2적률생성함수

정의 3.2.1

0 근처의 \(t\)에서 \(M_X(t) = E[e^{tX}]\)이 존재하면 이를 적률생성함수(mgf)라 한다.

\(e^{tX} = 1 + tX + \frac{t^2X^2}{2!} + \cdots\)의 기댓값을 취하면 \(M_X(t) = 1 + tE[X] + \frac{t^2}{2!}E[X^2] + \cdots\)이므로

\[M_X^{(k)}(0) = E[X^k].\]

적률을 하나하나 적분하는 대신, \(M\)을 한 번 구해 두고 미분만 하면 됩니다.

분포\(M_X(t)\)평균분산
이항 \((n, p)\)\((1 - p + pe^t)^n\)\(np\)\(np(1-p)\)
포아송 \((\lambda)\)\(e^{\lambda(e^t - 1)}\)\(\lambda\)\(\lambda\)
지수 \((\lambda)\)\(\frac{\lambda}{\lambda - t}\) (\(t < \lambda\))\(\frac1\lambda\)\(\frac1{\lambda^2}\)
정규 \((\mu, \sigma^2)\)\(e^{\mu t + \sigma^2t^2/2}\)\(\mu\)\(\sigma^2\)
예제 3.2.2

지수분포의 mgf \(M(t) = \frac{\lambda}{\lambda - t}\)에서 평균과 분산을 구하여라.

풀이. \(M'(t) = \frac{\lambda}{(\lambda - t)^2}\), \(M''(t) = \frac{2\lambda}{(\lambda - t)^3}\). \(E[X] = M'(0) = \frac1\lambda\), \(E[X^2] = M''(0) = \frac2{\lambda^2}\), \(\mathrm{Var} = \frac2{\lambda^2} - \frac1{\lambda^2} = \frac1{\lambda^2}\).

3.2.3두 가지 중요한 성질

  • 유일성: 두 확률변수의 mgf가 0 근처에서 같으면 분포가 같다.
  • 독립인 합: \(X\), \(Y\)가 독립이면 \(M_{X+Y}(t) = M_X(t)\,M_Y(t)\).

둘을 합치면 합의 분포를 알 수 있습니다. 예를 들어 독립인 포아송 \(X \sim \text{Poi}(\lambda_1)\), \(Y \sim \text{Poi}(\lambda_2)\)이면 \(M_{X+Y} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}\)이므로 \(X + Y \sim \text{Poi}(\lambda_1 + \lambda_2)\)입니다. 두 생산 라인의 시간당 불량 수를 합친 것도 포아송입니다. 같은 방법으로 독립인 정규분포의 합도 정규분포임을 보일 수 있습니다(6.2절). 그리고 \(aX + b\)의 mgf는 \(e^{bt}M_X(at)\)입니다.

요약
  1. \(M_X(t) = E[e^{tX}]\), \(M^{(k)}(0) = E[X^k]\).
  2. 유일성, 독립이면 곱: 합의 분포를 정한다.

3.2.4연습문제

기본

  1. 포아송 mgf를 두 번 미분해 분산이 \(\lambda\)임을 보여라.
    답

    \(M' = \lambda e^tM\), \(M'' = \lambda e^tM + \lambda^2e^{2t}M\). \(M'(0) = \lambda\), \(M''(0) = \lambda + \lambda^2\), 분산 \(\lambda\).
