1.R.1

연습확률의 기본 개념 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통12-01-01] [공통12-01-02] [공통12-01-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 증명확률의 공리(① \(P(A) \ge 0\) ② \(P(S) = 1\) ③ 서로 배반인 사건의 합의 확률은 확률의 합)만으로 \(P(A^c) = 1 - P(A)\)와 \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)를 보이세요. [01-01]

    힌트 1

    \(A\)와 \(A^c\)는 서로 배반이고 합하면 \(S\)입니다.

    힌트 2

    \(A \cup B\)를 서로 배반인 \(A\)와 \(B \cap A^c\)로 나누고, \(B\)도 \(B \cap A\)와 \(B \cap A^c\)로 나눕니다.

    풀이

    (1) \(S = A \cup A^c\)이고 배반이므로 공리 ③과 ②에서 \(1 = P(A) + P(A^c)\).

    (2) \(A \cup B = A \cup (B \cap A^c)\)(배반)이므로 \(P(A \cup B) = P(A) + P(B \cap A^c)\). 또 \(B = (B \cap A) \cup (B \cap A^c)\)(배반)이므로 \(P(B \cap A^c) = P(B) - P(A \cap B)\). 대입하면 결론입니다. ∎

  2. 계산부품을 공장 A, B, C가 50%, 30%, 20% 만들고, 불량률은 각각 1%, 2%, 3%입니다. 아무 부품이나 하나 골랐을 때 불량일 확률과, 불량품이 C 공장 것일 확률을 구하세요. [01-02]

    힌트 1

    전확률 공식 \(P(D) = \sum P(D \mid \text{공장})P(\text{공장})\).

    힌트 2

    베이즈 정리 \(P(C \mid D) = \dfrac{P(D \mid C)P(C)}{P(D)}\).

    풀이

    \(P(D) = 0.5(0.01) + 0.3(0.02) + 0.2(0.03) = 0.005 + 0.006 + 0.006 = 0.017\). \(P(C \mid D) = 0.006/0.017 = 0.353\).

    C는 20%만 만들지만 불량품의 35%를 차지합니다. 불량률이 가장 높기 때문입니다.

  3. 적용장비가 고장 나 있을 확률은 0.1%입니다. 진단 센서는 고장일 때 99% 경보를 울리고, 정상일 때도 2% 잘못 울립니다. 경보가 울렸을 때 실제로 고장일 확률은? [01-02]

    힌트 1

    고장(F), 경보(A)로 두고 \(P(F \mid A)\)를 구합니다.

    힌트 2

    \(P(A) = 0.99(0.001) + 0.02(0.999)\).

    풀이

    \(P(A) = 0.00099 + 0.01998 = 0.02097\), \(P(F \mid A) = 0.00099/0.02097 = 0.047\). 경보가 울려도 실제 고장은 약 5%뿐입니다. 고장 자체가 아주 드물어서 잘못 울린 경보가 훨씬 많기 때문입니다. 경보가 울리면 다른 검사로 한 번 더 확인해야 합니다.

  4. 계산주사위를 한 번 던질 때 \(A\) = “짝수”, \(B\) = “4 이하”입니다. \(A\)와 \(B\)는 독립인가요? \(C\) = “3 이하”와 \(A\)는? [01-03]

    힌트 1

    독립이면 \(P(A \cap B) = P(A)P(B)\).

    힌트 2

    \(A \cap B = \{2, 4\}\), \(A \cap C = \{2\}\).

    풀이

    \(P(A \cap B) = 1/3 = (1/2)(2/3)\)이므로 독립입니다. \(P(A \cap C) = 1/6 \ne (1/2)(1/2) = 1/4\)이므로 \(A\)와 \(C\)는 독립이 아닙니다.

  5. 계산신뢰도(작동할 확률) 0.9인 부품을 서로 독립으로 (가) 세 개 직렬로 (나) 두 개 병렬로 연결했을 때 시스템의 신뢰도를 구하세요. [01-03]

    힌트 1

    직렬은 모두 작동해야 하고, 병렬은 하나만 작동해도 됩니다.

    힌트 2

    병렬: 1 − (모두 고장 날 확률).

    풀이

    (가) \(0.9^3 = 0.729\). (나) \(1 - 0.1^2 = 0.99\). 중요한 장치에 같은 부품을 병렬로 두는 이유입니다(독립이라는 가정이 깨지면, 예를 들어 같은 전원을 쓰면 이 계산은 틀립니다).

  6. 판단“두 사건이 서로 배반이면 서로 영향을 주지 않으므로 독립이다.” 판단하세요. [01-03]

    힌트 1

    \(A\)와 \(B\)가 배반이고 \(P(A), P(B) > 0\)이면 \(P(A \cap B)\)는?

    힌트 2

    \(A\)가 일어났다는 것을 알면 \(B\)의 확률은 어떻게 되나요?

    풀이

    틀렸습니다. 배반이면 \(P(A \cap B) = 0\)인데 \(P(A)P(B) > 0\)이므로 독립이 아닙니다. \(A\)가 일어났다는 것을 알면 \(B\)는 일어날 수 없다는 것을 알게 되므로, 오히려 강하게 영향을 주고받습니다.
