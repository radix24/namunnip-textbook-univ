6.2.1선형 결합의 평균과 분산

정리 6.2.1 \[E\left[\sum a_iX_i\right] = \sum a_i\mu_i, \qquad \mathrm{Var}\left(\sum a_iX_i\right) = \sum a_i^2\sigma_i^2 + 2\sum_{i<j}a_ia_j\,\mathrm{Cov}(X_i, X_j).\]

독립이면 공분산 항이 사라져 \(\mathrm{Var} = \sum a_i^2\sigma_i^2\). 또 각 \(X_i\)가 정규분포이고 독립이면 \(\sum a_iX_i\)도 정규분포이다.

평균은 언제나 더해지지만, 표준편차는 더해지지 않고 분산이 더해집니다. 그래서 독립인 \(n\)개의 같은 오차를 더하면 표준편차는 \(n\)배가 아니라 \(\sqrt n\)배로 늘어납니다. 빼도 분산은 더해집니다(\(a_i = -1\)이어도 \(a_i^2 = 1\)).

6.2.2공차 누적

예제 6.2.2

길이 \(10.00 \pm 0.03\) mm인 블록 4개를 이어 붙인다. 각 블록의 길이는 서로 독립이고 \(N(10.00, 0.01^2)\)을 따른다(공차 ±0.03이 ±3σ). 전체 길이의 공차는?

풀이.

  • 최악 조건법: 모든 블록이 동시에 한쪽 끝이라고 보면 \(40.00 \pm 0.12\) mm.
  • 통계적 방법(제곱합의 제곱근, RSS): \(\sigma_{\text{전체}} = \sqrt{4 \times 0.01^2} = 0.02\) mm이므로 ±3σ는 \(40.00 \pm 0.06\) mm.

네 블록이 모두 같은 방향으로 끝까지 치우칠 확률은 아주 작으므로, 통계적 공차는 최악 조건의 절반입니다. 부품 수가 \(n\)이면 비율이 \(\frac1{\sqrt n}\)이 되어 부품이 많을수록 차이가 커집니다. 대신 독립과 정규성 가정이 맞지 않으면(같은 공구 마모로 모두 길어지는 경우) 실제 불량이 예상보다 많을 수 있습니다.

예제 6.2.3

구멍 지름 \(D \sim N(20.05, 0.02^2)\), 축 지름 \(d \sim N(20.00, 0.015^2)\)이 독립이다. 틈새 \(C = D - d\)가 음수여서(끼워지지 않아) 조립이 안 될 확률은?

풀이. \(E[C] = 0.05\), \(\sigma_C = \sqrt{0.02^2 + 0.015^2} = 0.025\). \(P(C < 0) = \Phi(-2) \approx 0.023\). 아래 실습 카드에서 부품 수와 공차를 바꾸며 최악 조건과 통계적 공차를 비교할 수 있습니다.

요약
  1. 평균은 더해지고, 독립이면 분산이 더해진다(\(\sum a_i^2\sigma_i^2\)).
  2. 최악 조건 공차는 \(\sum t_i\), 통계적 공차는 \(\sqrt{\sum t_i^2}\).

6.2.3연습문제

기본

  1. 공차 ±0.05인 부품 9개를 쌓으면 최악 조건과 RSS 공차는 각각?
    답

    ±0.45, \(\pm0.05\sqrt9 = \pm0.15\).

6.2.2

실습공차 누적 시뮬레이션

실습 · 최악 조건과 RSS

다루는 성취기준 [공통12-06-02] [공통12-06-03]

목표

공차가 있는 부품 \(n\)개를 이어 붙인 조립품을 2만 번 만들어, 전체 길이의 편차가 최악 조건 공차와 통계적 공차(RSS) 가운데 어디까지 퍼지는지 확인합니다. 성취기준 [공통12-06-02], [공통12-06-03].

준비

막대는 전체 길이와 목표의 차이의 히스토그램, 파란 곡선은 같은 평균과 분산의 정규분포입니다. 빨간 점선은 최악 조건 \(\pm nt\), 주황 점선은 RSS \(\pm t\sqrt n\)입니다. 부품 분포는 정규(공차 = 3σ) 또는 균일(공차 안에서 고르게)로 고를 수 있습니다.

절차

  1. 6.2절 예제(\(n = 4\), \(t = 0.03\), 정규)의 최악 조건과 RSS 공차, RSS를 벗어난 비율을 읽는다.
  2. \(n\)을 1에서 12까지 바꾸며 실제 최대 편차가 최악 조건의 몇 %인지 본다.
  3. 부품 분포를 균일로 바꾸고 RSS를 벗어난 비율을 비교한다.
  4. 균일, \(n = 1, 2, 3\)일 때 히스토그램 모양을 본다.

기대 결과

  • 최악 조건 ±0.12, RSS ±0.06 mm. RSS를 벗어난 조립품은 약 0.3%(정규분포의 ±3σ 밖).
  • \(n\)이 커질수록 실제 편차는 최악 조건보다 훨씬 작은 범위에 머문다.
  • 균일 부품이면 같은 공차라도 σ가 크므로(\(t/\sqrt3\)) RSS를 벗어나는 비율이 약 8%로 커진다(\(n = 4\)일 때).
  • 균일 1개는 평평하고, 2개는 삼각형, 3개부터는 종 모양에 가까워진다(중심극한정리).

분석

  1. RSS 공차를 쓸 때 부품 분포 가정이 왜 중요한지, 절차 3의 결과로 설명해 보세요.
  2. 설계 공차를 정할 때 최악 조건법이 더 알맞은 경우(부품 수가 적거나, 안전에 직결되는 경우)를 말해 보세요.
