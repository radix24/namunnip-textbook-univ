3.1.1기댓값

정의 3.1.1 \[E[X] = \sum_x x\,p(x) \quad (\text{이산}), \qquad E[X] = \int_{-\infty}^{\infty} x\,f(x)\,dx \quad (\text{연속}).\]

더 일반적으로 \(E[g(X)] = \sum g(x)p(x)\) 또는 \(\int g(x)f(x)\,dx\).

기댓값(평균) \(\mu\)는 분포의 무게중심이고, 같은 실험을 많이 되풀이했을 때 평균값이 다가가는 값입니다. 합이나 적분이 절댓값으로 수렴할 때만 정의됩니다.

정리 3.1.2 (선형성)

\(E[aX + b] = aE[X] + b\), \(E[g(X) + h(X)] = E[g(X)] + E[h(X)]\).

3.1.2분산과 표준편차

\[\mathrm{Var}(X) = E[(X - \mu)^2] = E[X^2] - \mu^2, \qquad \sigma = \sqrt{\mathrm{Var}(X)}.\]

둘째 식은 첫째 식을 전개하고 선형성을 쓰면 나오며, 계산에는 이쪽이 편합니다. 그리고

\[\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X).\]

더하는 상수 \(b\)는 분포를 옮길 뿐 퍼짐을 바꾸지 않습니다. 단위를 바꾸면(mm → cm, \(a = 0.1\)) 분산은 \(a^2\)배입니다.

예제 3.1.3

(가) 공정한 주사위 눈 \(X\)의 평균과 분산. (나) 2.2절의 \(f(x) = \frac38x^2\) (\(0 \le x \le 2\))의 평균과 분산.

풀이. (가) \(E[X] = 3.5\), \(E[X^2] = \frac{91}{6}\), \(\mathrm{Var} = \frac{91}6 - 12.25 = \frac{35}{12} \approx 2.917\). (나) \(E[X] = \int_0^2 \frac38x^3dx = \frac38\cdot4 = 1.5\), \(E[X^2] = \int_0^2\frac38x^4dx = \frac38\cdot\frac{32}5 = 2.4\), \(\mathrm{Var} = 2.4 - 2.25 = 0.15\).

주의. 일반적으로 \(E[g(X)] \ne g(E[X])\)입니다. 예를 들어 \(E[X^2] \ne (E[X])^2\)이고, 그 차이가 바로 분산입니다.

3.1.3체비쇼프 부등식

분포의 모양을 몰라도 평균과 분산만으로

\[P(|X - \mu| \ge k\sigma) \le \frac1{k^2}\]

입니다. 평균에서 \(2\sigma\) 넘게 벗어날 확률은 어떤 분포든 25% 이하입니다. 정규분포라면 약 4.6%로 훨씬 작습니다(4.3절).

요약
  1. \(E[X] = \sum xp(x)\) 또는 \(\int xf(x)dx\), 선형성.
  2. \(\mathrm{Var}(X) = E[X^2] - \mu^2\), \(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\).
  3. 체비쇼프: \(P(|X - \mu| \ge k\sigma) \le 1/k^2\).

3.1.4연습문제

기본

  1. 2.1절 예제(불량 수 \(X\), \(p\) = 0.729, 0.243, 0.027, 0.001)의 평균과 분산을 구하여라.
    답

    \(E[X] = 0.243 + 0.054 + 0.003 = 0.3\), \(E[X^2] = 0.243 + 0.108 + 0.009 = 0.36\), \(\mathrm{Var} = 0.27\). 이항분포의 \(np\), \(np(1-p)\)와 같다.
