6.1.1cdf 방법

원의 반지름 \(R\)이 확률변수이면 넓이 \(\pi R^2\)도 확률변수입니다. \(Y = g(X)\)의 분포를 구하는 가장 일반적인 방법은 cdf에서 출발하는 것입니다.

  1. \(F_Y(y) = P(g(X) \le y)\)를 \(X\)에 대한 사건으로 바꾼다.
  2. \(X\)의 분포로 그 확률을 계산한다.
  3. \(y\)로 미분해 \(f_Y\)를 얻는다.
예제 6.1.1

\(X \sim U(0, 1)\)일 때 \(Y = X^2\)의 pdf는?

풀이. \(0 \le y \le 1\)에서 \(F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \sqrt y\). 미분하면 \(f_Y(y) = \frac1{2\sqrt y}\). 0 근처에 몰린 분포가 됩니다(0.1보다 작은 \(X\)는 10%지만, 0.1보다 작은 \(Y\)는 \(\sqrt{0.1} \approx 32\%\)).

6.1.2단조 변환 공식

정리 6.1.2

\(g\)가 증가하거나 감소하는 미분 가능한 함수이고 역함수가 \(x = h(y)\)이면

\[f_Y(y) = f_X(h(y))\,\lvert h'(y)\rvert.\]

\(|h'(y)|\)는 \(g\)가 구간을 늘이거나 줄이는 비율의 역수입니다. 넓이(확률)는 보존되므로, 구간이 늘어난 곳은 밀도가 낮아집니다. 단조가 아니면(\(Y = X^2\), \(X\)가 음수도 가질 때) 구간을 나눠 각각 더합니다.

특히 선형 변환 \(Y = aX + b\)이면 \(f_Y(y) = \frac1{|a|}f_X\left(\frac{y - b}a\right)\)이고, \(X\)가 정규분포이면 \(Y\)도 정규분포입니다.

6.1.3역변환법

예제 6.1.3

\(U \sim U(0, 1)\)일 때 \(T = -\frac1\lambda\ln U\)의 분포는?

풀이. \(P(T > t) = P(\ln U < -\lambda t) = P(U < e^{-\lambda t}) = e^{-\lambda t}\). 그러므로 \(T \sim \text{Exp}(\lambda)\).

일반적으로 cdf \(F\)의 역함수에 균일 난수를 넣으면 \(F^{-1}(U)\)는 분포 \(F\)를 따릅니다. 컴퓨터 시뮬레이션(몬테카를로)에서 원하는 분포의 난수를 만드는 기본 방법이고, 공통6 방사성 붕괴 카드 같은 시뮬레이션도 이런 난수를 씁니다. 아래 실습 카드에서 균일 난수 2만 개를 변환한 히스토그램을 이론 pdf와 비교할 수 있습니다.

요약
  1. cdf 방법: \(F_Y(y) = P(g(X) \le y)\)를 구해 미분.
  2. 단조 변환: \(f_Y(y) = f_X(h(y))|h'(y)|\).
  3. 역변환법: \(F^{-1}(U)\)는 분포 \(F\)를 따른다.

6.1.4연습문제

기본

  1. 원의 반지름 \(R \sim U(1, 2)\)일 때 넓이 \(A = \pi R^2\)의 pdf를 구하여라.
    답

    \(R = \sqrt{A/\pi}\), \(\frac{dR}{dA} = \frac1{2\sqrt{\pi A}}\). \(f_A(a) = \frac1{2\sqrt{\pi a}}\) (\(\pi \le a \le 4\pi\)).

6.1.2

실습균일 난수를 변환하면

실습 · 변환 공식, 역변환법

다루는 성취기준 [공통12-06-01]

목표

\(U(0, 1)\) 난수 2만 개를 여러 함수로 변환한 히스토그램을 6.1절에서 구한 pdf와 비교합니다. \(-\ln U\)가 지수분포가 되는 역변환법도 확인합니다. 성취기준 [공통12-06-01].

준비

막대는 변환한 값 \(Y\)의 히스토그램(넓이가 1이 되게 맞춤), 빨간 선은 공식 \(f_Y(y) = f_X(h(y))\lvert h'(y)\rvert\)로 구한 이론 pdf입니다.

절차

  1. \(Y = X^2\)에서 히스토그램이 0 근처에 몰리는지, 빨간 선과 맞는지 본다.
  2. \(Y = \sqrt X\)로 바꿔 반대로 1 근처에 몰리는 것을 본다.
  3. \(Y = -\ln X\)의 표본 평균을 읽는다.
  4. \(Y = 3X + 1\)의 밀도 높이를 읽는다.

기대 결과

  • \(X^2\)은 \(\frac1{2\sqrt y}\), \(\sqrt X\)는 \(2y\)를 잘 따른다. 표본 평균은 각각 약 \(\frac13\), \(\frac23\).
  • \(-\ln X\)는 지수분포 \(e^{-y}\)를 따르고 표본 평균이 약 1이다.
  • \(3X + 1\)은 \([1, 4]\)에서 균일하고 높이가 \(\frac13\)이다(넓이 보존).

분석

  1. \(Y = X^2\)에서 \(y = 0\) 근처의 밀도가 무한대로 커지는데도 넓이가 1인 이유를 적분으로 설명해 보세요.
  2. 평균 수명 1000시간인 지수분포 난수를 만들려면 \(U\)를 어떻게 변환해야 하는지 써 보세요.
