5.R.1

연습여러 개의 확률변수 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통12-05-01] [공통12-05-02] [공통12-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산결합 확률질량함수가 \(p(0,0) = 0.1\), \(p(0,1) = 0.2\), \(p(0,2) = 0.1\), \(p(1,0) = 0.2\), \(p(1,1) = 0.3\), \(p(1,2) = 0.1\)입니다. \(X\)와 \(Y\)의 주변분포와 \(P(Y = 1 \mid X = 1)\)을 구하세요. [05-01]

    힌트 1

    주변분포는 다른 변수에 대해 모두 더한 것입니다.

    힌트 2

    \(P(Y = 1 \mid X = 1) = p(1, 1)/p_X(1)\).

    풀이

    \(p_X(0) = 0.4\), \(p_X(1) = 0.6\). \(p_Y(0) = 0.3\), \(p_Y(1) = 0.5\), \(p_Y(2) = 0.2\). \(P(Y = 1 \mid X = 1) = 0.3/0.6 = 0.5\).

  2. 계산앞 문제의 \(X\)와 \(Y\)는 독립인가요? [05-02]

    힌트 1

    모든 \((x, y)\)에서 \(p(x, y) = p_X(x)p_Y(y)\)인지 확인합니다. 하나라도 어긋나면 독립이 아닙니다.

    힌트 2

    \((0, 0)\)에서 확인해 보세요.

    풀이

    \(p(0, 0) = 0.1\)이지만 \(p_X(0)p_Y(0) = 0.4 \times 0.3 = 0.12\)이므로 독립이 아닙니다.

  3. 계산앞 문제의 \(X\)와 \(Y\)의 공분산과 상관계수를 구하세요. [05-03]

    힌트 1

    \(\operatorname{Cov}(X, Y) = E[XY] - E[X]E[Y]\).

    힌트 2

    \(E[X] = 0.6\), \(E[Y] = 0.9\), \(E[XY] = 1 \cdot 1 \cdot 0.3 + 1 \cdot 2 \cdot 0.1 = 0.5\).

    풀이

    \(\operatorname{Cov} = 0.5 - 0.54 = -0.04\). \(\operatorname{Var}(X) = 0.24\), \(E[Y^2] = 0.5 + 0.8 = 1.3\), \(\operatorname{Var}(Y) = 0.49\). \(\rho = \dfrac{-0.04}{\sqrt{0.24}\sqrt{0.49}} = -0.12\). 약한 음의 상관입니다.

  4. 계산\(f(x, y) = x + y\) (\(0 \le x, y \le 1\))가 결합 밀도함수입니다. \(X\)의 주변 밀도와 \(P(X + Y \le 1)\)을 구하세요. [05-01]

    힌트 1

    \(f_X(x) = \int_0^1 f(x, y)\,dy\).

    힌트 2

    \(P(X + Y \le 1) = \int_0^1\int_0^{1-x}(x + y)\,dy\,dx\).

    풀이

    \(f_X(x) = x + \tfrac12\). 안쪽 적분 \(= x(1 - x) + \tfrac12(1 - x)^2\), 바깥 적분 \(= \left(\tfrac12 - \tfrac13\right) + \tfrac16 = \tfrac13\).

  5. 개념키(cm)와 몸무게(kg)의 공분산이 30, 상관계수가 0.6입니다. 키를 m로 바꾸면 공분산과 상관계수는 어떻게 되나요? [05-03]

    힌트 1

    \(\operatorname{Cov}(aX, bY) = ab\operatorname{Cov}(X, Y)\).

    힌트 2

    상관계수는 공분산을 두 표준편차로 나눈 값입니다.

    풀이

    공분산은 0.01배가 되어 0.3(단위 m·kg)이 되지만, 상관계수는 단위가 없어서 0.6 그대로입니다. 두 변수의 관련 정도를 비교할 때 상관계수를 쓰는 이유입니다.

  6. 판단“\(X\)가 −1, 0, 1을 같은 확률로 갖고 \(Y = X^2\)이면, 공분산이 0이므로 \(X\)와 \(Y\)는 독립이다.” 판단하세요. [05-02]

    힌트 1

    \(\operatorname{Cov}(X, Y) = E[X^3] - E[X]E[X^2]\)을 계산해 보세요.

    힌트 2

    \(X\)를 알면 \(Y\)를 정확히 압니다.

    풀이

    공분산은 \(0 - 0 = 0\)이지만 독립이 아닙니다. \(Y\)는 \(X\)로 완전히 정해집니다(\(P(Y = 0 \mid X = 0) = 1 \ne P(Y = 0) = 1/3\)). 공분산과 상관계수는 직선 관계만 잽니다. 독립이면 공분산이 0이지만, 거꾸로는 성립하지 않습니다.
