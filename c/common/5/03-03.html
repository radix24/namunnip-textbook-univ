3.3.1실험식

실험식은 원자 수의 가장 간단한 정수비, 분자식은 분자에 실제로 든 원자 수입니다. 포도당의 분자식은 \(\text{C}_6\text{H}_{12}\text{O}_6\), 실험식은 \(\text{CH}_2\text{O}\)입니다.

  1. 시료를 100 g으로 잡아 백분율을 g으로 바꾼다.
  2. 각 원소의 몰수를 구한다.
  3. 가장 작은 몰수로 나눠 정수비를 만든다(필요하면 2, 3을 곱함).
예제 3.3.1

C 40.0%, H 6.7%, O 53.3%인 화합물의 몰질량이 180 g/mol이다. 실험식과 분자식은?

풀이. C \(\frac{40.0}{12.01} = 3.33\), H \(\frac{6.7}{1.008} = 6.65\), O \(\frac{53.3}{16.00} = 3.33\) mol. 3.33으로 나누면 1 : 2 : 1, 실험식 \(\text{CH}_2\text{O}\)(식량 30.03). \(\frac{180}{30.03} \approx 6\)이므로 분자식 \(\text{C}_6\text{H}_{12}\text{O}_6\).

3.3.2연소 분석

탄소, 수소를 포함한 화합물을 산소에서 완전히 태우면 C는 모두 \(\text{CO}_2\), H는 모두 \(\text{H}_2\text{O}\)가 됩니다. 생긴 \(\text{CO}_2\)와 \(\text{H}_2\text{O}\)의 질량을 재면 C와 H의 양을 알고, 나머지는 O로 봅니다. 예: \(\text{CO}_2\) 44.0 g이면 C 1.00 mol(12.0 g).

요약
  1. 100 g으로 잡기 → 몰수 → 가장 작은 값으로 나누기 → 실험식.
  2. 분자식 = 실험식 × (몰질량 / 실험식량).

3.3.3연습문제

기본

  1. N 30.4%, O 69.6%인 화합물(몰질량 92 g/mol)의 분자식은?
    답

    N 2.17, O 4.35 → \(\text{NO}_2\)(46). \(\text{N}_2\text{O}_4\).
