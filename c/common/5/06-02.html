  • 에너지 준위 (6.1절).

왜 필요한가

고등학교에서는 전자가 1s, 2s, 2p … 순서로 들어간다고 외웠습니다. 그런데 왜 2p는 있고 1p는 없는지, 왜 p 오비탈은 꼭 세 개인지는 설명하지 않았습니다. 양자수는 이 규칙들의 근거입니다. 양자수의 허용 범위 세 줄만 알면 껍질마다 오비탈이 몇 개이고 전자가 몇 개 들어가는지를 외우지 않고 셀 수 있습니다.

6.2.1오비탈과 양자수

양자역학에서 원자 속 전자의 상태는 파동함수로 나타내며, 파동함수의 제곱은 전자를 발견할 확률 밀도입니다. 전자가 있을 법한 공간의 모양을 오비탈이라 합니다. 오비탈은 세 양자수로, 전자 하나는 네 번째 양자수까지 넣어 정해집니다.

양자수가능한 값뜻
주양자수 \(n\)1, 2, 3, …껍질. 크기와 에너지
각운동량 양자수 \(l\)0, 1, …, \(n - 1\)버금껍질의 모양: 0 = s, 1 = p, 2 = d, 3 = f
자기 양자수 \(m_l\)\(-l, \dots, 0, \dots, +l\)오비탈의 방향. 버금껍질에 \(2l + 1\)개
스핀 양자수 \(m_s\)\(+\frac12\), \(-\frac12\)전자의 스핀 방향
  • 껍질 \(n\)에는 오비탈 \(n^2\)개, 전자 최대 \(2n^2\)개.
  • s 버금껍질 1개(2전자), p 3개(6), d 5개(10), f 7개(14).
  • 파울리 배타 원리: 한 원자 안에서 네 양자수가 모두 같은 전자는 없다. 그래서 오비탈 하나에 전자는 스핀이 반대인 두 개까지.
예제 6.2.1

\(n = 3\) 껍질의 버금껍질, 오비탈 수, 최대 전자 수는?

풀이. \(l = 0, 1, 2\): 3s(1개), 3p(3개), 3d(5개). 오비탈 9개, 전자 18개.

6.2.2전자 하나의 주소 세기

양자수 네 개는 전자 하나의 주소와 같습니다. \(n\)은 건물(껍질), \(l\)은 층(버금껍질), \(m_l\)은 방(오비탈), \(m_s\)는 방 안의 침대 두 개 가운데 하나입니다. 파울리 원리는 "한 침대에 한 사람"이라는 규칙입니다.

예제 6.2.2

3d 버금껍질에 들어갈 수 있는 전자의 양자수 조합을 모두 세어라.

풀이. 3d는 \(n = 3\), \(l = 2\)입니다. \(m_l\)은 \(-2, -1, 0, 1, 2\)의 다섯 값이고, 각각 \(m_s = \pm\frac12\) 두 값이므로 조합은 \(5\times2 = 10\)개입니다. 그래서 d 버금껍질에는 전자가 10개까지 들어가고, 주기율표의 전이 원소 한 줄이 10칸입니다.

흔한 오해

"\(n\)이 클수록 버금껍질의 에너지가 항상 높다"는 틀립니다. 다전자 원자에서는 4s가 3d보다 먼저 채워집니다. 에너지는 \(n\)과 \(l\)이 함께 정하며, 대략 \(n + l\)이 작은 쪽, 같으면 \(n\)이 작은 쪽이 먼저입니다(7.1절). 수소 원자처럼 전자가 하나뿐일 때만 에너지가 \(n\)으로만 정해집니다.

요약
  1. \(n \ge 1\), \(0 \le l \le n - 1\), \(|m_l| \le l\), \(m_s = \pm\frac12\).
  2. 오비탈 하나에 전자 둘(파울리). 껍질 \(n\)에 \(2n^2\)개.

6.2.3연습문제

기본

  1. \(n = 2\), \(l = 2\)인 오비탈이 있을 수 있는가?
    답

    없다. \(l \le n - 1 = 1\).

응용

  1. \(n = 4\) 껍질에 들어갈 수 있는 전자는 최대 몇 개인가? 버금껍질별로 나누어 써라.
    답

    4s 2, 4p 6, 4d 10, 4f 14, 합 32 \(= 2\times4^2\).

  2. 한 원자에서 \(n = 3\), \(l = 1\), \(m_l = 0\)을 가질 수 있는 전자는 몇 개인가?
    답

    2개. 오비탈 하나(3p 가운데 하나)에 스핀이 반대인 두 전자.

  3. 양자수 조합 \((n, l, m_l, m_s) = (2, 1, -2, +\frac12)\)이 불가능한 이유를 말하여라.
    답

    \(|m_l| \le l = 1\)이어야 하는데 \(m_l = -2\)이다.
