5.3.1스위치를 켜는 함수

정의 5.3.1 (단위 계단 함수)

\(u(t - a) = 0\) (\(t < a\)), \(1\) (\(t > a\)). 헤비사이드 함수라고도 한다.

시각 \(a\)에 스위치를 켜는 함수입니다. 함수에 곱하면 그 시각 이전을 지워 줍니다. 구간마다 다른 입력은 계단 함수의 합으로 씁니다. 예를 들어 \(1 \le t < 3\)에서만 전압 5를 거는 입력은 \(5[u(t - 1) - u(t - 3)]\)입니다.

\(\mathcal L\{u(t - a)\} = \int_a^\infty e^{-st}dt = \dfrac{e^{-as}}{s}\)입니다.

5.3.2t-이동

정리 5.3.2 (t-이동)

\(\mathcal L\{f(t)\} = F(s)\)이면 \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\).

그래프를 오른쪽으로 \(a\)만큼 옮기고 그 앞을 0으로 만들면, 변환에는 \(e^{-as}\)가 곱해집니다. 역변환에서 \(e^{-as}\)가 보이면 "\(a\)만큼 늦게 시작하는 함수"라고 읽습니다.

예제 5.3.3

\(f(t) = t^2\) (\(0 < t < 2\)), \(0\) (\(t > 2\))의 변환을 구하여라.

풀이. \(f = t^2[1 - u(t - 2)] = t^2 - t^2u(t - 2)\). t-이동을 쓰려면 \(t^2\)을 \((t - 2)\)로 나타내야 합니다: \(t^2 = (t - 2)^2 + 4(t - 2) + 4\). 따라서

\[F = \frac{2}{s^3} - e^{-2s}\left(\frac{2}{s^3} + \frac{4}{s^2} + \frac4s\right).\]
예제 5.3.4 (RC 회로에 펄스)

\(y' + y = u(t - 1) - u(t - 3)\), \(y(0) = 0\)을 풀어라.

풀이. \((s + 1)Y = \frac{e^{-s} - e^{-3s}}{s}\). \(\frac{1}{s(s + 1)} = \frac1s - \frac{1}{s + 1}\)의 역변환은 \(1 - e^{-t}\)이므로 t-이동으로

\[y = [1 - e^{-(t - 1)}]u(t - 1) - [1 - e^{-(t - 3)}]u(t - 3).\]

\(1 < t < 3\)에서는 1을 향해 올라가고, \(t > 3\)에서는 다시 0으로 내려옵니다. 구간마다 따로 풀어 이어 붙이지 않아도 한 번에 답이 나옵니다.

요약
  1. \(u(t - a)\): \(a\)에서 켜지는 스위치. \(\mathcal L = \frac{e^{-as}}{s}\).
  2. t-이동: \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\). 함수를 \(t - a\)의 식으로 고친 뒤 쓴다.

5.3.3연습문제

기본

  1. \(\mathcal L^{-1}\left\{\frac{e^{-2s}}{s^2}\right\}\)은?
    답

    \((t - 2)u(t - 2)\).

  2. \(t > \pi\)에서만 \(\sin t\)인 함수의 변환은?
    답

    \(\sin t\,u(t - \pi) = -\sin(t - \pi)u(t - \pi)\). \(-\frac{e^{-\pi s}}{s^2 + 1}\).

5.3.2

예제계단 함수와 델타 함수 입력의 응답 구하기

u(t − a) · t축 이동 · δ(t − a) · 충격 응답

다루는 성취기준 [공통8-05-03]

도구

  • 계단 함수 \(u(t - a)\): \(t < a\)이면 0, \(t \ge a\)이면 1. 스위치를 켜는 순간. \(\mathcal L\{u(t - a)\} = \frac{e^{-as}}{s}\).
  • \(t\)축 이동: \(\mathcal L\{f(t - a)u(t - a)\} = e^{-as}F(s)\). 시간 지연이 \(e^{-as}\) 곱하기.
  • 델타 함수 \(\delta(t - a)\): 폭 \(\varepsilon\), 높이 \(\frac1\varepsilon\)인 직사각형 펄스(넓이 1)의 \(\varepsilon \to 0\) 극한. 망치로 한 번 치는 순간적인 충격. \(\mathcal L\{\delta(t - a)\} = e^{-as}\).

델타 함수의 변환: 펄스 \(\frac1\varepsilon[u(t - a) - u(t - a - \varepsilon)]\)의 변환 \(e^{-as}\frac{1 - e^{-\varepsilon s}}{\varepsilon s} \to e^{-as}\) (로피탈).

먼저 예측

정지한 용수철 진자를 \(t = \pi\)에 망치로 한 번 톡 치면, 그 뒤의 운동은 어떤 모양일까요?

예측 확인

\(t = \pi\)까지는 가만히 있다가, 그 순간 속도를 얻어 사인 모양으로 진동합니다.

(가) \(y'' + y = \delta(t - \pi)\), \(y(0) = y'(0) = 0\) (나) \(y' + 2y = u(t - 1)\), \(y(0) = 0\) (\(t = 1\)에 일정한 입력이 켜짐)

풀이

  1. (가) \((s^2 + 1)Y = e^{-\pi s}\), \(Y = e^{-\pi s}\frac{1}{s^2 + 1}\).
    초기조건이 0이라 깔끔.
  2. \(\frac{1}{s^2 + 1} \leftrightarrow \sin t\)이고 \(e^{-\pi s}\)는 \(\pi\)만큼 지연: \(y = \sin(t - \pi)u(t - \pi) = -\sin t\cdot u(t - \pi)\).
    \(t\)축 이동 정리.
  3. (나) \((s + 2)Y = \frac{e^{-s}}{s}\), \(Y = e^{-s}\frac{1}{s(s + 2)} = e^{-s}\cdot\frac12\left(\frac1s - \frac{1}{s + 2}\right)\).
    부분분수.
  4. \(y = \frac12\left(1 - e^{-2(t - 1)}\right)u(t - 1)\).
    \(t = 1\) 전에는 0, 그 뒤 \(\frac12\)로 지수적으로 다가감.

의미

(가)에서 \(y'\)는 \(t = \pi\)에서 0에서 1로 뜁니다. 델타 함수는 "순간적으로 운동량 1을 주는 충격"(공통3 4-01의 충격량)이고, 그 응답(충격 응답)은 \(\frac{1}{s^2 + 1}\), 곧 전달함수의 역변환입니다. 계의 충격 응답을 알면 어떤 입력에 대한 응답도 다음 카드의 합성곱으로 구할 수 있습니다. 공학에서 구조물을 망치로 쳐서 고유 진동수를 재는 이유입니다.

검산

(나) \(t > 1\)에서 \(y' + 2y = e^{-2(t-1)} + 1 - e^{-2(t-1)} = 1\). \(t = 1\)에서 \(y = 0\)으로 연속. 정상 상태 \(\frac12\)은 \(2y = 1\)에서 바로 보입니다.
