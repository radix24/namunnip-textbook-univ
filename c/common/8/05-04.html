5.4.1아주 짧고 아주 센 힘

야구방망이로 공을 치거나 망치로 용수철을 때리면, 힘이 아주 짧은 시간에만 크게 작용합니다. 전체 효과는 충격량(힘 × 시간)으로 정해집니다. 폭 \(k\), 높이 \(\frac1k\)인 직사각형 펄스는 넓이(충격량)가 1이고, \(k\)를 0으로 보내면 "한 순간에 충격량 1을 주는 입력"이 됩니다. 이 극한을 디랙 델타 함수 \(\delta(t - a)\)라 부릅니다.

정의 5.4.1 (디랙 델타 함수)

\(t \ne a\)에서 0이고 \(\int_0^\infty\delta(t - a)\,dt = 1\)인 "함수". 연속함수 \(g\)에 대해 \(\int_0^\infty g(t)\delta(t - a)\,dt = g(a)\)이다.

보통의 함수는 아니지만(한 점에서 무한대), 적분 안에서 이렇게 행동하는 대상으로 다룹니다. 펄스의 변환 \(\frac{e^{-as}(1 - e^{-ks})}{ks}\)에서 \(k \to 0\)으로 보내면

\[\mathcal L\{\delta(t - a)\} = e^{-as}, \qquad \mathcal L\{\delta(t)\} = 1.\]

5.4.2충격에 대한 응답

예제 5.4.2

정지해 있던 용수철 계 \(y'' + 3y' + 2y = \delta(t - 1)\), \(y(0) = y'(0) = 0\)의 응답을 구하여라.

풀이. \((s^2 + 3s + 2)Y = e^{-s}\), \(Y = e^{-s}\left(\frac{1}{s + 1} - \frac{1}{s + 2}\right)\). t-이동으로

\[y = \left[e^{-(t - 1)} - e^{-2(t - 1)}\right]u(t - 1).\]

\(t = 1\)까지는 가만히 있다가, 충격을 받은 순간 속도가 갑자기 1이 되어 튀어 올랐다가 감쇠하며 돌아옵니다(위치는 연속, 속도는 불연속).

\(\delta(t)\)에 대한 응답 \(g(t)\)를 충격 응답이라 합니다. 계의 성질은 충격 응답에 모두 담겨 있고, 다른 입력에 대한 응답은 다음 절의 합성곱으로 구할 수 있습니다. 신호및시스템 과목의 출발점입니다.

부분분수 분해가 이 단원에서 계속 쓰입니다. 분모에 같은 인수가 거듭 있거나 복소근이 있는 경우도 공통1 5.4절의 방법 그대로입니다.

요약
  1. \(\delta(t - a)\): \(a\)에서 충격량 1을 주는 순간적 입력. \(\int g\delta(t - a) = g(a)\).
  2. \(\mathcal L\{\delta(t - a)\} = e^{-as}\).

5.4.3연습문제

기본

  1. \(y' + y = \delta(t - 2)\), \(y(0) = 0\)을 풀어라.
    답

    \(Y = \frac{e^{-2s}}{s + 1}\), \(y = e^{-(t - 2)}u(t - 2)\).

  2. \(y'' + y = \delta(t)\), \(y(0) = y'(0) = 0\)의 해(충격 응답)는?
    답

    \(Y = \frac{1}{s^2 + 1}\), \(y = \sin t\).

5.4.2

실습망치로 순간 친 힘을 식으로 어떻게 쓸까?

실습 · 디랙 델타 함수와 충격 응답

다루는 성취기준 [공통8-05-04]

목표

용수철에 매단 물체를 망치로 아주 짧게 칩니다. 힘의 모양은 몰라도 충격량(힘 × 시간)은 압니다. 폭 \(\varepsilon\), 높이 \(1/\varepsilon\)인 사각 펄스(넓이 1)를 점점 좁히면 그 극한이 델타 함수 \(\delta(t - a)\)이고, 응답도 하나의 식으로 다가갑니다. 그것을 수치해와 비교합니다. 성취기준 [공통8-05-04].

준비

  • 식: \(y'' + 2\zeta y' + y = (\text{충격})\), \(y(0) = y'(0) = 0\). \(\zeta\)는 감쇠의 세기입니다.
  • 라플라스 변환 \(\mathcal L\{\delta(t - a)\} = e^{-as}\)로 풀면 \(Y = \dfrac{e^{-as}}{s^2 + 2\zeta s + 1}\)이고, s-이동과 t-이동으로 \(y = u(t - a)\dfrac{e^{-\zeta(t-a)}\sin(\omega_d(t - a))}{\omega_d}\), \(\omega_d = \sqrt{1 - \zeta^2}\)입니다(보라).
  • 주황 점선: 사각 펄스를 그대로 넣고 룽게-쿠타 방법으로 푼 수치해. 빨간 띠: 펄스가 켜진 구간.

절차

  1. \(a = 2\), \(\zeta = 0.1\)에서 펄스 폭을 3, 1, 0.3, 0.05로 줄이며 "최대 차이"를 기록합니다.
  2. 폭이 고유 주기(약 \(2\pi \approx 6.3\))보다 훨씬 짧을 때와 비슷할 때 응답 모양을 비교합니다.
  3. \(\zeta\)를 0으로 놓아 진동이 줄지 않는 것을 봅니다.

기대 결과

  • \(a = 2\), \(\zeta = 0.1\)에서 최대 차이는 폭 3, 1, 0.3, 0.05일 때 0.8571, 0.3765, 0.1398, 0.0252로, 폭을 줄일수록 0에 다가갑니다(작은 폭에서는 대략 폭의 절반). 펄스의 가운데가 \(a + \varepsilon/2\)라서 응답이 그만큼 늦게 시작하는 것이 차이의 대부분입니다. 폭이 고유 주기의 수십 분의 1이면 그림으로는 구별되지 않습니다. 힘의 자세한 모양은 중요하지 않고 충격량만 중요하다는 뜻입니다.
  • 폭이 3쯤으로 길면 힘이 작용하는 동안 물체가 이미 움직여 응답이 작아지고 늦어집니다.
  • \(\zeta = 0\)이면 응답은 \(\sin(t - a)\)로, 진폭 1의 진동이 계속됩니다.

분석

  1. 충격 직후 속도가 \(y'(a^+) = 1\)이 되는 이유를 운동량 변화 = 충격량으로 설명해 보세요.
  2. 같은 시각에 충격을 두 번(\(a\)와 \(a + \pi\)) 주면 \(\zeta = 0\)에서 무슨 일이 일어날까요? 중첩으로 예측해 보세요.

더 해 보기

충격 응답 \(g(t)\)를 알면 아무 입력 \(r(t)\)에 대한 응답이 합성곱 \(y = (g * r)(t)\)로 나옵니다(5.5절). 입력을 짧은 충격들의 합으로 보고 응답을 더한 것입니다.
