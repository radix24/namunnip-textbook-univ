1.R.1

연습일계 상미분방정식 연습 문제

문제 7 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통8-01-01] [공통8-01-02] [공통8-01-03] [공통8-01-05] [공통8-01-02]

먼저 꼴(변수분리, 선형, 완전)을 판단하고, 풀고 나면 원래 식에 넣어 확인하세요.

  1. 개념\(y' = y^2 - 4\)의 평형해를 찾고 안정성을 판정하세요. \(y(0) = 0\)인 해는 \(t \to \infty\)에서 어디로 가나요? [01-01]

    힌트 1

    01-01 절: 위상선.

    힌트 2

    \(-2 < y < 2\)에서 \(y' < 0\).

    풀이

    평형해 \(y = \pm2\). \(y = -2\): 안정(위아래 해가 다가옴), \(y = 2\): 불안정. \(y(0) = 0\)이면 \(y' = -4 < 0\)으로 내려가 \(-2\)에 다가갑니다.

  2. 계산\(y' = \frac{x}{y}\), \(y(0) = -3\)을 푸세요. [01-02]

    힌트 1

    변수분리: \(y\,dy = x\,dx\).

    힌트 2

    \(y^2 = x^2 + C\). 부호는 초기조건으로.

    풀이

    \(y^2 = x^2 + 9\), \(y(0) = -3 < 0\)이므로 \(y = -\sqrt{x^2 + 9}\). 모든 \(x\)에서 존재.

  3. 계산\(y' - 2y = e^{3x}\), \(y(0) = 1\)을 푸세요. [01-02]

    힌트 1

    \(\mu = e^{-2x}\).

    힌트 2

    \((e^{-2x}y)' = e^{x}\).

    풀이

    \(e^{-2x}y = e^x + C\), \(y = e^{3x} + Ce^{2x}\). \(y(0) = 1 + C = 1\), \(C = 0\). \(y = e^{3x}\). 확인: \(3e^{3x} - 2e^{3x} = e^{3x}\).

  4. 계산\(y\,dx + (2x - ye^y)\,dy = 0\)을 적분인자로 푸세요. [01-03]

    힌트 1

    \(M_y = 1\), \(N_x = 2\). \(\frac{N_x - M_y}{M} = \frac1y\).

    힌트 2

    \(\mu(y) = y\).

    풀이

    곱하면 \(y^2\,dx + (2xy - y^2e^y)\,dy = 0\). \(M_y = 2y = N_x\). \(F = xy^2 + g(y)\), \(F_y = 2xy + g' = 2xy - y^2e^y\) → \(g = -\int y^2e^ydy = -(y^2 - 2y + 2)e^y\). 해: \(xy^2 - (y^2 - 2y + 2)e^y = C\).

  5. 판단한 학생이 \(y' = y^{1/3}\), \(y(0) = 0\)을 수치 프로그램으로 풀어 "해는 \(y = 0\)뿐"이라고 결론 내렸습니다. 맞나요? [01-05]

    힌트 1

    01-05 절: \(\frac{\partial f}{\partial y}\)가 \(y = 0\)에서 연속인가요?

    힌트 2

    \(y = \left(\frac{2x}{3}\right)^{3/2}\)을 넣어 보세요.

    풀이

    틀렸습니다. \(y = \left(\frac{2x}{3}\right)^{3/2}\) (\(x \ge 0\))도 해입니다: \(y' = \left(\frac{2x}{3}\right)^{1/2} = y^{1/3}\). 유일성 조건이 깨진 곳에서는 수치 방법이 여러 해 중 하나(여기서는 0)만 찾아 줍니다. 수치 결과를 믿으려면 유일성부터 확인해야 합니다.

  6. 계산방사성 탄소 \(^{14}\)C의 반감기는 5730년입니다. 나무 유물의 \(^{14}\)C 비율이 살아 있는 나무의 30%라면 몇 년 전 유물인가요? [01-02]

    힌트 1

    \(N' = -kN\), \(k = \frac{\ln2}{5730}\).

    힌트 2

    \(0.30 = e^{-kt}\).

    풀이

    \(t = \frac{\ln(1/0.30)}{\ln2}\times5730 = \frac{1.204}{0.693}\times5730 \approx 9950\)년.

  7. 판단로지스틱 모형 \(P' = 0.1P(1 - P/1000)\)으로 물고기 개체수를 예측하던 학생이 "처음 1500마리면 개체수가 계속 늘어난다"고 했습니다. 맞나요? [01-02, 01-01]

    힌트 1

    \(P > 1000\)이면 \(1 - \frac{P}{1000}\)의 부호는?

    힌트 2

    평형해 \(P = 1000\)은 안정.

    풀이

    틀렸습니다. \(P > 1000\)이면 \(P' < 0\)이라 줄어들어 1000에 다가갑니다. 수용력보다 많으면 먹이 부족 등으로 줄어든다는 모형의 가정 그대로입니다.
