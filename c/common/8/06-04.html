6.4.1사인·코사인 대신 다른 직교 함수로

푸리에 급수의 계수를 구할 수 있었던 이유는 직교성 하나였습니다. 그러므로 직교하는 함수의 모임 \(\{y_m\}\)만 있으면 같은 방법이 통합니다.

정리 6.4.1 (일반화된 푸리에 급수)

\(\{y_m\}\)이 \([a, b]\)에서 가중함수 \(r\)에 대해 직교하면, \(f = \sum a_my_m\)의 계수는

\[a_m = \frac{\int_a^brfy_m\,dx}{\int_a^bry_m^2\,dx}.\]

양변에 \(ry_n\)을 곱해 적분하면 \(m \ne n\)인 항이 모두 0이 되기 때문입니다. 분모 \(\|y_m\|^2 = \int ry_m^2\)은 \(y_m\)의 "길이의 제곱"입니다. 사인·코사인이면 6.1절의 공식이 됩니다.

예제 6.4.2 (푸리에-르장드르 급수)

\(f(x) = x^2\)을 \([-1, 1]\)에서 르장드르 다항식으로 전개하여라.

풀이. 르장드르 다항식은 \(r = 1\)로 직교하고 \(\int_{-1}^1P_m^2dx = \frac{2}{2m + 1}\)입니다. \(x^2\)은 2차이므로 \(P_0, P_1, P_2\)까지만 필요합니다. \(a_0 = \frac12\int_{-1}^1x^2dx = \frac13\), \(a_1 = 0\) (기함수), \(a_2 = \frac52\int_{-1}^1x^2\cdot\frac12(3x^2 - 1)dx = \frac54\left(\frac65 - \frac23\right) = \frac23\). 따라서 \(x^2 = \frac13P_0 + \frac23P_2\). (확인: \(\frac13 + \frac23\cdot\frac12(3x^2 - 1) = x^2\).)

일반화된 푸리에 급수는 \(f\)를 가장 잘 근사합니다. 처음 \(N\)개 항만 쓴다면, 그 계수를 위 공식으로 고를 때 오차의 제곱 적분이 가장 작아집니다(최소제곱 근사). 무한히 더해 오차가 0으로 가는 함수 모임을 "완전하다"고 합니다.

요약
  1. 직교 함수로 \(f = \sum a_my_m\), \(a_m = \frac{\int rfy_m}{\int ry_m^2}\).
  2. 사인·코사인이면 푸리에 급수, 르장드르 다항식이면 푸리에-르장드르 급수.

6.4.2연습문제

응용

  1. \(f(x) = x^3\)을 르장드르 다항식으로 전개하여라.
    답

    \(x^3 = \frac35P_1 + \frac25P_3\). (\(P_3 = \frac12(5x^3 - 3x)\))

6.4.2

예제Parseval 항등식으로 급수의 합 구하기

에너지 = 계수의 제곱합 · Σ1/n⁴ · 복소 Fourier 급수

다루는 성취기준 [공통8-06-04]

항등식과 근거

\[\frac1L\int_{-L}^Lf(x)^2dx = \frac{a_0^2}{2} + \sum_{n=1}^\infty(a_n^2 + b_n^2).\]

근거: \(f\)를 급수로 쓰고 제곱해 적분하면, 직교성 때문에 서로 다른 항의 곱은 모두 0이고 같은 항의 제곱만 남습니다. 공통2의 피타고라스 \(|\mathbf v|^2 = \sum v_i^2\)를 무한 차원으로 늘린 것입니다. 물리로 읽으면 "신호의 전체 에너지 = 진동수 성분별 에너지의 합"입니다.

복소 Fourier 급수: Euler 공식으로 \(f = \sum_{n=-\infty}^\infty c_ne^{in\pi x/L}\), \(c_n = \frac{1}{2L}\int_{-L}^Lfe^{-in\pi x/L}dx\). 사인과 코사인을 한 식에 묶고, Parseval은 \(\frac{1}{2L}\int|f|^2 = \sum|c_n|^2\)이 됩니다.

(가) 사각파(공통8-06-01 카드)에 Parseval을 써서 \(\sum\frac{1}{(2k-1)^2}\)을 구하세요. (나) \(f(x) = x^2\) (\(-\pi < x < \pi\))의 Fourier 급수 \(x^2 = \frac{\pi^2}{3} + 4\sum\frac{(-1)^n}{n^2}\cos nx\)에 Parseval을 써서 \(\sum\frac{1}{n^4}\)을 구하세요.

풀이

  1. (가) 왼쪽 \(\frac1\pi\int_{-\pi}^\pi1\,dx = 2\). 오른쪽 \(\sum_{n\text{ 홀수}}\left(\frac{4}{n\pi}\right)^2 = \frac{16}{\pi^2}\sum\frac{1}{(2k-1)^2}\).
    \(f^2 = 1\).
  2. \(\sum\frac{1}{(2k-1)^2} = \frac{2\pi^2}{16} = \frac{\pi^2}{8}\).
    공통8-06-02 카드의 검산과 같은 값.
  3. (나) \(a_0 = \frac{2\pi^2}{3}\), \(a_n = \frac{4(-1)^n}{n^2}\). 왼쪽 \(\frac1\pi\int_{-\pi}^\pi x^4dx = \frac{2\pi^4}{5}\).
    \(\frac{a_0}{2} = \frac{\pi^2}{3}\).
  4. \(\frac{2\pi^4}{5} = \frac12\cdot\frac{4\pi^4}{9} + 16\sum\frac{1}{n^4}\). \(16\sum\frac1{n^4} = \frac{2\pi^4}{5} - \frac{2\pi^4}{9} = \frac{8\pi^4}{45}\), \(\sum\frac{1}{n^4} = \frac{\pi^4}{90}\).
    \(\frac{a_0^2}{2} = \frac{2\pi^4}{9}\).

의미

\(\sum\frac{1}{n^2} = \frac{\pi^2}{6}\)과 \(\sum\frac{1}{n^4} = \frac{\pi^4}{90}\)은 오일러가 처음 구한 결과로, 정수의 합에 \(\pi\)가 나오는 놀라운 예입니다. 공학에서는 Parseval로 신호의 에너지가 어느 주파수에 몰려 있는지(파워 스펙트럼) 계산합니다. 사각파의 첫 항(기본 진동수) 하나가 전체 에너지의 \(\frac{16/\pi^2}{2} = 81\%\)를 가집니다.

검산

\(\frac{\pi^4}{90} = 1.0823\). 부분합 \(1 + \frac{1}{16} + \frac{1}{81} + \frac{1}{256} = 1.0788\), 나머지 항들이 0.0035쯤 더하는 것과 맞습니다.
