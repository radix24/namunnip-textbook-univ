4.1.1

예제가우스 소거로 연립일차방정식 풀기

첨가행렬 · 기본 행 연산 · 해가 하나·무수히·없음 · 문제 해결 전략

다루는 성취기준 [공통8-04-01]

방법

\(A\mathbf x = \mathbf b\)를 첨가행렬 \([A \mid \mathbf b]\)로 쓰고, 해를 바꾸지 않는 기본 행 연산(두 행 바꾸기, 한 행에 0 아닌 수 곱하기, 한 행에 다른 행의 배수 더하기)으로 계단꼴을 만든 뒤 뒤에서부터 대입합니다. 행 연산이 해를 바꾸지 않는 이유: 각 연산은 되돌릴 수 있고, 연립방정식에 같은 조작을 한 것과 같기 때문입니다.

문제 해결 전략 · 선형대수 계산
  1. 첨가행렬을 쓰고, 왼쪽 위부터 피벗(각 행의 첫 0 아닌 수)을 만든다. 피벗 아래를 0으로.
  2. 계단꼴에서 해의 개수를 판정한다: \([0 \cdots 0 \mid c \ne 0]\) 행이 있으면 해 없음. 피벗 없는 열(자유변수)이 있으면 무수히 많음. 아니면 하나.
  3. 뒤에서부터 대입하거나, 피벗 위도 0으로 만들어(기약 계단꼴) 바로 읽는다.
  4. 원래 식에 넣어 확인한다.

(가) \(x + 2y + z = 4\), \(2x + 5y + 3z = 9\), \(-x + y + 4z = 5\) (나) \(x + y + 2z = 3\), \(2x + 3y + 5z = 8\), \(x + 2y + 3z = 5\)

풀이

  1. (가) \(\left[\begin{array}{ccc|c}1&2&1&4\\2&5&3&9\\-1&1&4&5\end{array}\right]\). \(R_2 - 2R_1\), \(R_3 + R_1\): \(\left[\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&3&5&9\end{array}\right]\).
    첫 열의 피벗 아래를 0으로.
  2. \(R_3 - 3R_2\): \(\left[\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&0&2&6\end{array}\right]\).
    둘째 피벗 아래를 0으로. 계단꼴.
  3. 뒤에서부터: \(z = 3\), \(y = 1 - 3 = -2\), \(x = 4 + 4 - 3 = 5\). 해 \((5, -2, 3)\), 유일.
    피벗이 세 열 모두에 있음.
  4. (나) \(R_2 - 2R_1\), \(R_3 - R_1\): \(\left[\begin{array}{ccc|c}1&1&2&3\\0&1&1&2\\0&1&1&2\end{array}\right]\). \(R_3 - R_2\): 셋째 행 \([0\ 0\ 0 \mid 0]\).
    식 하나가 다른 둘의 결합이었다.
  5. \(z = t\) (자유변수), \(y = 2 - t\), \(x = 3 - (2 - t) - 2t = 1 - t\). 해 \((1, 2, 0) + t(-1, -1, 1)\), 무수히 많음.
    특수해 + 동차해(직선).

의미

(나)의 해는 "특수해 하나 + 동차 방정식 \(A\mathbf x = \mathbf 0\)의 해"로, 2단원의 미분방정식 해 구조 \(y = y_p + y_h\)와 똑같습니다. 가우스 소거는 컴퓨터가 연립방정식을 푸는 기본 방법이며, 계산량은 \(n^3\)에 비례합니다. 실제 계산에서는 반올림 오차를 줄이려고 가장 큰 수를 피벗으로 고릅니다(공통9 8단원의 피벗팅).

검산

(가) \(5 - 4 + 3 = 4\), \(10 - 10 + 9 = 9\), \(-5 - 2 + 12 = 5\). 모두 맞습니다. (나) \(t = 1\)이면 \((0, 1, 1)\): \(0 + 1 + 2 = 3\), \(0 + 3 + 5 = 8\), \(0 + 2 + 3 = 5\).
