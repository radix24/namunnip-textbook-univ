4.1.1계수가 변하는 방정식

2단원의 방법은 계수가 상수(또는 오일러-코시 꼴)일 때만 통합니다. \(y'' + xy = 0\)처럼 계수가 \(x\)에 따라 변하면 해가 우리가 아는 함수로 나오지 않는 경우가 많습니다. 그럴 때는 해를 거듭제곱급수로 놓고 계수를 하나씩 정합니다. 해가 "무한 차수의 다항식"으로 나오는 셈입니다.

4.1.2방법

  1. \(y = \sum_{m=0}^\infty a_mx^m\)으로 놓고 \(y' = \sum ma_mx^{m-1}\), \(y'' = \sum m(m - 1)a_mx^{m-2}\)를 쓴다.
  2. 방정식에 넣고, 모든 합이 같은 거듭제곱 \(x^s\)로 시작하도록 첨자를 바꾼다.
  3. \(x^s\)의 계수를 0으로 놓아 \(a_{s+2}\)를 앞의 계수로 나타내는 점화식을 얻는다.
  4. \(a_0\), \(a_1\)은 자유롭게 남는다(= 일반해의 두 상수). 점화식으로 나머지를 구한다.
예제 4.1.1

\(y'' + y = 0\)을 거듭제곱급수로 풀고, 이미 아는 해와 비교하여라.

풀이. \(\sum m(m - 1)a_mx^{m-2} + \sum a_mx^m = 0\). 첫째 합에서 \(m = s + 2\)로 바꾸면 \(\sum_{s\ge0}(s + 2)(s + 1)a_{s+2}x^s\). 둘째 합은 \(\sum_{s\ge0}a_sx^s\). \(x^s\)의 계수를 0으로:

\[a_{s+2} = -\frac{a_s}{(s + 2)(s + 1)}.\]

\(a_2 = -\frac{a_0}{2!}\), \(a_4 = \frac{a_0}{4!}\), …, \(a_3 = -\frac{a_1}{3!}\), \(a_5 = \frac{a_1}{5!}\), …이므로

\[y = a_0\left(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\right) + a_1\left(x - \frac{x^3}{3!} + \cdots\right) = a_0\cos x + a_1\sin x.\]

2.2절의 결과와 같습니다. 이 방법이 맞게 동작한다는 확인이자, 급수로 나온 해가 어떤 함수인지 알아보는 연습입니다.

예제 4.1.2 (에어리 방정식)

\(y'' = xy\)의 급수해의 처음 몇 항을 구하여라.

풀이. 넣으면 \(\sum(s + 2)(s + 1)a_{s+2}x^s = \sum a_{s-1}x^s\) (오른쪽은 \(s \ge 1\)). \(s = 0\)에서 \(a_2 = 0\), \(s \ge 1\)에서 \(a_{s+2} = \frac{a_{s-1}}{(s + 2)(s + 1)}\). \(a_3 = \frac{a_0}{6}\), \(a_4 = \frac{a_1}{12}\), \(a_5 = 0\), \(a_6 = \frac{a_0}{180}\), …

\[y = a_0\left(1 + \frac{x^3}{6} + \frac{x^6}{180} + \cdots\right) + a_1\left(x + \frac{x^4}{12} + \cdots\right).\]

이 해는 기본 함수로 쓸 수 없는 새로운 함수입니다(에어리 함수, 광학과 양자역학에서 쓰임). 급수해 방법은 이렇게 새로운 함수를 만들어 냅니다. 다음 절의 르장드르 다항식, 베셀 함수도 같은 방식으로 나옵니다.

이 방법은 계수 \(p(x)\), \(q(x)\)가 \(x = 0\)에서 테일러 급수로 전개되는(해석적인) 경우에 통하고, 급수해의 수렴 반지름은 적어도 계수들의 수렴 반지름만큼은 됩니다. 계수가 0에서 무한히 커지는 경우에는 4.3절의 프로베니우스 방법을 씁니다.

요약
  1. \(y = \sum a_mx^m\)을 넣고, 같은 거듭제곱의 계수를 맞춰 점화식을 얻는다.
  2. \(a_0\), \(a_1\)이 두 상수로 남는다.
  3. 급수해는 아는 함수가 되기도 하고(\(\cos x\)), 새로운 함수를 정의하기도 한다.

4.1.3연습문제

기본

  1. \(y' = 2xy\)를 거듭제곱급수로 풀고 어떤 함수인지 말하여라.
    답

    \((s + 1)a_{s+1} = 2a_{s-1}\), \(a_1 = 0\). \(a_2 = a_0\), \(a_4 = \frac{a_0}{2}\), …. \(y = a_0(1 + x^2 + \frac{x^4}{2!} + \cdots) = a_0e^{x^2}\).

응용

  1. \(y'' - y = 0\)의 급수해를 구하고 \(\cosh x\), \(\sinh x\)와 비교하여라.
    답

    \(a_{s+2} = \frac{a_s}{(s+2)(s+1)}\). \(y = a_0\cosh x + a_1\sinh x\).

이 절의 성취기준[공통8-04-01] 계산

  1. 거듭제곱급수를 대입해 미분방정식의 해를 구할 수 있다.

4.1.2

예제정칙점 근처에서 거듭제곱 급수해 구하기

y = Σ aₙxⁿ 대입 · 점화식 · Airy 방정식 · 문제 해결 전략

다루는 성취기준 [공통8-04-01]

방법과 근거

\(y'' + p(x)y' + q(x)y = 0\)에서 \(p, q\)가 \(x_0\)에서 해석적(거듭제곱 급수로 쓸 수 있음)이면 \(x_0\)은 정칙점이고, 해도 \(y = \sum a_n(x - x_0)^n\)로 쓸 수 있으며 수렴 반지름은 적어도 \(p, q\)의 수렴 반지름만큼입니다. 급수를 넣고 같은 거듭제곱의 계수를 0으로 두면 계수의 점화식이 나옵니다. 공통1 8단원의 거듭제곱급수를 미분방정식에 쓰는 것입니다.

문제 해결 전략 · 급수해
  1. 정칙점인지, 정칙 특이점인지 판정한다(04-03 카드).
  2. \(y = \sum a_nx^n\)과 \(y', y''\)을 넣는다.
  3. 지표를 옮겨 모든 합을 \(x^n\)으로 맞춘다(\(\sum n(n-1)a_nx^{n-2} = \sum(n+2)(n+1)a_{n+2}x^n\)).
  4. 계수를 0으로 두어 점화식을 얻고, \(a_0, a_1\)(자유)로 나머지를 쓴다.
  5. 알려진 함수와 비교하거나 수렴 반지름을 확인한다.

(가) \(y'' + y = 0\)을 급수로 풀어 \(\cos x\), \(\sin x\)가 나오는지 확인하세요. (나) Airy 방정식 \(y'' - xy = 0\)의 급수해 처음 몇 항을 구하세요.

풀이

  1. (가) \(\sum(n+2)(n+1)a_{n+2}x^n + \sum a_nx^n = 0\) → \(a_{n+2} = -\frac{a_n}{(n+2)(n+1)}\).
    전략 3, 4.
  2. \(a_2 = -\frac{a_0}{2}\), \(a_4 = \frac{a_0}{4!}\), …; \(a_3 = -\frac{a_1}{3!}\), \(a_5 = \frac{a_1}{5!}\), … 따라서 \(y = a_0\left(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\right) + a_1\left(x - \frac{x^3}{3!} + \cdots\right) = a_0\cos x + a_1\sin x\).
    공통1 8-05의 Maclaurin 급수와 일치.
  3. (나) \(\sum(n+2)(n+1)a_{n+2}x^n - \sum a_nx^{n+1} = 0\). 둘째 합을 \(\sum a_{n-1}x^n\) (\(n \ge 1\))로.
    지표를 맞춤.
  4. \(x^0\): \(2a_2 = 0\). \(n \ge 1\): \(a_{n+2} = \frac{a_{n-1}}{(n+2)(n+1)}\). 세 칸씩 뛰는 점화식.
    \(a_2 = 0\)이라 \(a_5 = a_8 = \dots = 0\).
  5. \(y = a_0\left(1 + \frac{x^3}{6} + \frac{x^6}{180} + \cdots\right) + a_1\left(x + \frac{x^4}{12} + \frac{x^7}{504} + \cdots\right)\).
    \(a_3 = \frac{a_0}{6}\), \(a_6 = \frac{a_3}{30}\), \(a_4 = \frac{a_1}{12}\), \(a_7 = \frac{a_4}{42}\).

의미

Airy 방정식의 해는 기본 함수로 쓸 수 없는 새로운 함수(Airy 함수)입니다. 급수해는 이런 "새 함수"를 정의하고 계산하는 방법입니다. Airy 함수는 무지개 가장자리의 빛 세기, 양자역학에서 일정한 힘을 받는 입자의 파동함수에 나타납니다. \(p, q\)가 다항식이라 급수는 모든 \(x\)에서 수렴합니다.

검산

(나) \(y = 1 + \frac{x^3}{6}\)까지만 넣으면 \(y'' = x\), \(xy = x + \frac{x^4}{6}\). 차이 \(-\frac{x^4}{6}\)는 다음 항 \(\frac{x^6}{180}\)의 \(y''\) 기여 \(\frac{30x^4}{180} = \frac{x^4}{6}\)이 정확히 상쇄합니다.
