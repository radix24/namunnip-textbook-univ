7.R.1

연습수치해 연습 문제

문제 5 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통8-07-01] [공통8-07-02]

손으로 한두 걸음 계산해 보면 코드가 무엇을 하는지 분명해집니다.

  1. 계산\(y' = -2y\), \(y(0) = 1\)을 Euler 방법 \(h = 0.1\)로 두 걸음 계산하고 정확한 값 \(e^{-0.4}\)과 비교하세요. [07-01]

    힌트 1

    07-01 절: \(y_{n+1} = y_n + h(-2y_n) = 0.8y_n\).

    힌트 2

    \(y_2 = 0.8^2\).

    풀이

    \(y_1 = 0.8\), \(y_2 = 0.64\). 정확한 값 \(e^{-0.2} = 0.8187\), \(e^{-0.4} = 0.6703\). 오차 0.030.

  2. 계산같은 문제를 RK4 \(h = 0.2\)로 한 걸음 계산하세요. [07-01]

    힌트 1

    \(k_1 = -2\), \(k_2 = -2(1 + 0.1k_1)\).

    힌트 2

    \(k_2 = -1.6\), \(k_3 = -2(1 - 0.16) = -1.68\), \(k_4 = -2(1 - 0.336)\).

    풀이

    \(k_4 = -1.328\). \(y_1 = 1 + \frac{0.2}{6}(-2 - 3.2 - 3.36 - 1.328) = 1 - 0.3296 = 0.6704\). 정확한 값 0.67032와 \(10^{-4}\) 이내로 맞습니다. 한 걸음 RK4가 Euler 두 걸음보다 훨씬 정확합니다.

  3. 판단\(y' = -50y\), \(y(0) = 1\)을 Euler \(h = 0.05\)로 풀었더니 값이 1, −1.5, 2.25, −3.4, …로 커지며 부호가 바뀌었습니다. 학생은 "해가 진동하며 발산한다"고 결론 내렸습니다. 맞나요? [07-01, 07-02]

    힌트 1

    정확한 해는 \(e^{-50t}\)입니다.

    힌트 2

    \(y_{n+1} = (1 - 50h)y_n\), \(|1 - 50h|\)은?

    풀이

    틀렸습니다. 정확한 해는 빠르게 0으로 줄어듭니다. \(1 - 50(0.05) = -1.5\)라 \(|{\cdot}| > 1\)이어서 수치해가 불안정해진 것입니다. Euler 방법은 \(h < \frac{2}{50} = 0.04\)여야 안정합니다. 이런 "뻣뻣한(stiff)" 방정식에는 암시적 방법을 씁니다. 수치 결과가 물리적으로 이상하면 먼저 방법을 의심합니다.

  4. 개념어떤 방법으로 \(h = 0.1\)에서 오차 \(8\times10^{-3}\), \(h = 0.05\)에서 \(1\times10^{-3}\)을 얻었습니다. 이 방법의 차수는? \(h = 0.025\)에서의 오차를 예측하세요. [07-02]

    힌트 1

    07-02 절: 비 \(= 2^p\).

    힌트 2

    비 8.

    풀이

    비가 8 = \(2^3\)이라 3차 방법. \(h = 0.025\)에서 약 \(1.25\times10^{-4}\).

  5. 판단"RK4는 한 걸음에 \(f\)를 4번 계산하니 Euler보다 4배 느리다. 그러니 같은 시간이면 Euler로 걸음을 4배 늘리는 게 낫다." 07-02 카드의 표로 반박하세요. [07-02]

    힌트 1

    같은 계산량: Euler \(h = 0.05\) 대 RK4 \(h = 0.2\).

    힌트 2

    두 오차를 비교.

    풀이

    \(f\) 계산 40번으로 Euler(\(h = 0.05\))는 오차 0.128, RK4(\(h = 0.2\))는 \(1.1\times10^{-4}\). 같은 계산량에서 RK4가 1000배 넘게 정확합니다. 정확도가 \(h^4\)로 좋아지는 효과가 계산량 4배를 압도합니다.
