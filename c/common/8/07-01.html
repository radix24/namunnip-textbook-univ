7.1.1오일러 방법

대부분의 미분방정식은 해를 식으로 구할 수 없습니다. 하지만 \(y' = f(x, y)\)는 지금 위치에서의 기울기를 알려 주므로, 그 기울기로 조금 걸어가고, 새 위치에서 다시 기울기를 보고 조금 걸어가는 식으로 해 곡선을 따라갈 수 있습니다. 한 걸음의 폭을 \(h\)라 하면

\[x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h\,f(x_n, y_n).\]

이것이 오일러 방법입니다. 한 걸음마다 선형근사를 쓰는 셈입니다.

예제 7.1.1

\(y' = x + y\), \(y(0) = 0\)을 \(h = 0.2\)로 \(x = 0.6\)까지 오일러 방법으로 풀고 정확한 해 \(y = e^x - x - 1\)과 비교하여라.

7.1.24차 룽게-쿠타 방법

한 걸음 안에서 기울기를 네 번 재고 가중 평균을 내면 훨씬 정확해집니다.

\[k_1 = hf(x_n, y_n), \quad k_2 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_1}{2}\right), \quad k_3 = hf\!\left(x_n + \tfrac h2, y_n + \tfrac{k_2}{2}\right), \quad k_4 = hf(x_n + h, y_n + k_3),\] \[y_{n+1} = y_n + \tfrac16(k_1 + 2k_2 + 2k_3 + k_4).\]

처음, 가운데(두 번), 끝의 기울기를 1:2:2:1로 평균합니다(심프슨 공식과 같은 비율). 같은 예제를 \(h = 0.2\)로 풀면 \(x = 0.6\)에서 약 0.22211로, 정확한 값 0.22212와 소수 넷째 자리까지 맞습니다. 컴퓨터가 미분방정식을 풀 때 가장 널리 쓰는 기본 방법입니다.

요약
  1. 오일러: \(y_{n+1} = y_n + hf(x_n, y_n)\). 간단하지만 오차가 크다.
  2. 4차 룽게-쿠타: 기울기 네 개를 1:2:2:1로 평균. 같은 \(h\)에서 훨씬 정확하다.

7.1.3연습문제

기본

  1. \(y' = y\), \(y(0) = 1\)을 \(h = 0.5\)로 오일러 방법을 써서 \(y(1)\)을 어림하고 \(e\)와 비교하여라.

7.1.2

실습Euler 방법과 4차 Runge-Kutta 방법을 코드로 구현하기

방향장을 따라 걷기 · 기울기 네 번 재기

다루는 성취기준 [공통8-07-01]

목표

초기값 문제 \(y' = f(t, y)\), \(y(t_0) = y_0\)을 Euler 방법과 RK4로 풀어 정확한 해와 비교합니다. 성취기준 [공통8-07-01]. 식으로 풀 수 없는 방정식(대부분의 실제 문제)을 푸는 방법입니다.

준비

Python 3 (설치 없이 Google Colab에서 실행 가능), 또는 스프레드시트. 시험 문제는 정확한 해를 아는 \(y' = y - t^2 + 1\), \(y(0) = 0.5\) (해 \(y = (t + 1)^2 - 0.5e^t\))입니다.

두 방법의 생각

  • Euler: 지금 점의 기울기로 \(h\)만큼 직선으로 간다. \(y_{n+1} = y_n + hf(t_n, y_n)\). 공통1의 선형 근사를 되풀이한 것, 01-01 카드의 방향장을 따라 걷는 것.
  • RK4: 한 걸음 안에서 기울기를 네 번 재서(시작, 가운데 두 번, 끝) 가중 평균 \(\frac{k_1 + 2k_2 + 2k_3 + k_4}{6}\)으로 간다. 공통1 6-05의 Simpson 공식과 같은 가중치입니다(\(f\)가 \(t\)만의 함수이면 정확히 Simpson 공식).

절차

  1. 아래 코드를 실행한다.
  2. \(h = 0.2\)로 \(t = 2\)까지 계산하고 표를 비교한다.
  3. \(h\)를 0.1, 0.05로 바꿔 \(t = 2\)에서의 오차를 기록한다(07-02 카드에서 분석).
import math

def f(t, y):
    return y - t**2 + 1

def exact(t):
    return (t + 1)**2 - 0.5*math.exp(t)

def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        y = y + h*f(t, y)
        t = t + h
    return y

def rk4(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2)
        k4 = f(t + h, y + h*k3)
        y = y + h*(k1 + 2*k2 + 2*k3 + k4)/6
        t = t + h
    return y

for h in (0.2, 0.1, 0.05):
    n = round(2/h)
    e, r = euler(f, 0, 0.5, h, n), rk4(f, 0, 0.5, h, n)
    print(f"h={h:<5} Euler {e:.6f} (오차 {abs(e-exact(2)):.2e})  "
          f"RK4 {r:.8f} (오차 {abs(r-exact(2)):.2e})")

기대 결과

정확한 값 \(y(2) = 9 - 0.5e^2 = 5.305472\). \(h = 0.2\)에서 Euler는 약 4.866 (오차 약 0.44), RK4는 5.305363 (오차 약 \(1\times10^{-4}\)). 같은 걸음 수로 RK4가 약 4000배 정확합니다. 계산량은 RK4가 걸음당 4배이지만 그만한 가치가 있습니다.

분석

  1. Euler의 결과가 정확한 값보다 작은 이유: 이 해는 아래로 볼록(\(y'' > 0\))이라 접선이 곡선 아래에 있습니다(공통1 4-05의 선형 근사가 작게 나오는 경우).
  2. \(h = 0.2\)에서 \(t = 2\)까지 10걸음. 한 걸음마다 생기는 오차(국소 오차)가 쌓여 전체 오차가 됩니다. 걸음 수를 늘리면 어떻게 줄어드는지가 다음 카드의 주제입니다.

더 해 보기

연립 방정식(5단원)도 \(y\)를 벡터로 바꾸면 같은 코드가 됩니다. 감쇠 진자 \(\theta'' + 0.5\theta' + \sin\theta = 0\) (03-05 카드)를 \(\theta(0) = 3\), \(\theta'(0) = 0\)으로 풀어 위상 평면에 그려 보세요(NumPy 배열로 y를 바꾸고 matplotlib으로 그림). 실제 계산에는 걸음 크기를 자동으로 조절하는 scipy.integrate.solve_ivp를 씁니다.
