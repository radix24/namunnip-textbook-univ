6.2.1주기 \(2L\)

실제 신호의 주기는 \(2\pi\)가 아닌 경우가 대부분입니다. \(x\)를 \(\frac{\pi x}{L}\)로 바꾸면 주기 \(2L\)인 함수를 다룰 수 있습니다.

\[f(x) = a_0 + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right),\] \[a_0 = \frac{1}{2L}\int_{-L}^Lf\,dx, \quad a_n = \frac1L\int_{-L}^Lf\cos\frac{n\pi x}{L}dx, \quad b_n = \frac1L\int_{-L}^Lf\sin\frac{n\pi x}{L}dx.\]

6.2.2우함수와 기함수

\(f\)가 우함수이면 \(b_n = 0\)이고 푸리에 코사인 급수, 기함수이면 \(a_0 = a_n = 0\)이고 푸리에 사인 급수가 됩니다. 이때 적분을 \([0, L]\)에서 두 배로 계산하면 됩니다: 예를 들어 기함수이면 \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\).

6.2.3반구간 전개

양 끝을 고정한 줄의 처음 모양이나 막대의 처음 온도처럼, 함수가 \([0, L]\)에서만 주어질 때가 많습니다(고등미적분학(2)의 편미분방정식). 이때는 함수를 \([-L, 0]\)으로 원하는 방식으로 넓혀서 푸리에 급수를 씁니다.

  • 우함수로 넓히면(\(y\)축 대칭) 코사인 급수: \(a_0 = \frac1L\int_0^Lf\,dx\), \(a_n = \frac2L\int_0^Lf\cos\frac{n\pi x}{L}dx\).
  • 기함수로 넓히면(원점 대칭) 사인 급수: \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\).
예제 6.2.1

\(f(x) = x\) (\(0 < x < L\))의 반구간 사인 급수를 구하여라.

풀이. \(b_n = \frac2L\int_0^Lx\sin\frac{n\pi x}{L}dx\). 부분적분하면 \(b_n = \frac{2L}{n\pi}(-1)^{n+1}\). 따라서

\[x = \frac{2L}{\pi}\left(\sin\frac{\pi x}{L} - \frac12\sin\frac{2\pi x}{L} + \frac13\sin\frac{3\pi x}{L} - \cdots\right) \quad (0 < x < L).\]

양 끝에서 0이 되는 사인 급수는 "양 끝이 고정된" 경계 조건에 잘 맞습니다. 그래서 줄의 진동 문제에서는 사인 급수를 씁니다.

요약
  1. 주기 \(2L\): \(nx\) 대신 \(\frac{n\pi x}{L}\), 계수 앞의 \(\frac1\pi\) 대신 \(\frac1L\).
  2. 우함수는 코사인 급수, 기함수는 사인 급수.
  3. \([0, L]\)의 함수는 우함수 또는 기함수로 넓혀 전개한다(반구간 전개).

6.2.4연습문제

기본

  1. \(f(x) = 1\) (\(0 < x < L\))의 반구간 코사인 급수와 사인 급수를 구하여라.
    답

    코사인 급수: \(1\) (상수 하나). 사인 급수: \(\frac4\pi\left(\sin\frac{\pi x}{L} + \frac13\sin\frac{3\pi x}{L} + \cdots\right)\).

6.2.2

예제사인, 코사인 반구간 전개

기함수·우함수 확장 · 경계 조건에 맞추기

다루는 성취기준 [공통8-06-02]

생각

\(0 < x < L\)에서만 정의된 함수(막대의 온도, 줄의 처음 모양)를 Fourier 급수로 쓰려면 \(-L < x < 0\)으로 늘려(확장) 주기 \(2L\) 함수를 만들면 됩니다. 늘리는 방법을 고를 수 있습니다.

  • 기함수로 확장 → 사인 급수 \(f = \sum b_n\sin\frac{n\pi x}{L}\), \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\). 양 끝에서 0인 문제(고정된 줄, 양 끝 온도 0)에 맞습니다.
  • 우함수로 확장 → 코사인 급수 \(f = \frac{a_0}{2} + \sum a_n\cos\frac{n\pi x}{L}\), \(a_n = \frac2L\int_0^Lf\cos\frac{n\pi x}{L}dx\). 양 끝에서 기울기가 0인 문제(단열된 끝)에 맞습니다.

두 급수는 \((0, L)\)에서 같은 \(f\)로 수렴하지만, 구간 밖에서는 다른 함수입니다. 4단원의 변수분리에서 경계 조건이 어느 쪽을 쓸지 정합니다.

\(f(x) = x\) (\(0 < x < \pi\))를 (가) 사인 급수 (나) 코사인 급수로 전개하세요.

풀이

  1. (가) \(b_n = \frac2\pi\int_0^\pi x\sin nx\,dx\). 부분적분: \(\left[-\frac{x\cos nx}{n}\right]_0^\pi + \frac1n\int_0^\pi\cos nx\,dx = -\frac{\pi(-1)^n}{n}\).
    둘째 항은 0.
  2. \(b_n = \frac{2(-1)^{n+1}}{n}\). \(x = 2\left(\sin x - \frac{\sin2x}{2} + \frac{\sin3x}{3} - \cdots\right)\).
    계수 \(\frac1n\): 기함수 확장이 \(x = \pm\pi\)에서 뛰는(톱니파) 불연속이라.
  3. (나) \(a_0 = \frac2\pi\int_0^\pi x\,dx = \pi\). \(a_n = \frac2\pi\int_0^\pi x\cos nx\,dx = \frac2\pi\cdot\frac{(-1)^n - 1}{n^2}\).
    부분적분: \(\left[\frac{x\sin nx}{n}\right] + \frac{\cos nx}{n^2}\Big|_0^\pi\).
  4. 홀수 \(n\)만 \(a_n = -\frac{4}{\pi n^2}\). \(x = \frac\pi2 - \frac4\pi\left(\cos x + \frac{\cos3x}{9} + \frac{\cos5x}{25} + \cdots\right)\).
    계수 \(\frac{1}{n^2}\): 우함수 확장은 연속인 삼각파라 더 빨리 수렴.

의미

같은 \(x\)를 나타내는데 코사인 급수가 훨씬 빨리 수렴합니다(\(\frac{1}{n^2}\) 대 \(\frac1n\)). 확장한 함수가 연속이면 계수가 빨리 줄고, 불연속이면 느리게 줄어듭니다. 문제의 경계 조건이 허락하는 한, 매끄러운 확장을 고르는 것이 계산에 유리합니다.

검산

(나)에 \(x = 0\): \(0 = \frac\pi2 - \frac4\pi\left(1 + \frac19 + \frac{1}{25} + \cdots\right)\), 곧 \(\sum\frac{1}{(2k-1)^2} = \frac{\pi^2}{8}\). 이것으로 \(\sum\frac{1}{n^2} = \frac{\pi^2}{6}\)도 얻습니다(홀수 항이 전체의 \(\frac34\)이므로).
