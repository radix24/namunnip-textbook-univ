1.2.1변수분리법

\(y' = g(x)h(y)\)처럼 오른쪽이 "\(x\)만의 식 × \(y\)만의 식"으로 나뉘면, \(y\)가 든 것은 왼쪽, \(x\)가 든 것은 오른쪽으로 모을 수 있습니다.

\[\frac{dy}{h(y)} = g(x)\,dx \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(x)\,dx + c.\]

왼쪽은 \(y\)로, 오른쪽은 \(x\)로 적분합니다. \(dy\)와 \(dx\)를 분수처럼 나눠 쓰는 것은 실제로는 치환적분(공통1 4.3절)을 줄여 쓴 것입니다.

예제 1.2.1

\(y' = -2xy\), \(y(0) = 1\)을 풀어라.

풀이. \(\dfrac{dy}{y} = -2x\,dx\). 적분하면 \(\ln|y| = -x^2 + c\), 곧 \(y = Ce^{-x^2}\) (\(C = \pm e^c\)). \(y(0) = 1\)에서 \(C = 1\). 답 \(y = e^{-x^2}\).

양변을 \(y\)로 나눌 때 \(y = 0\)인 경우가 빠집니다. \(y = 0\)도 해이고, 위 식에서 \(C = 0\)으로 놓으면 포함됩니다. 이렇게 나눗셈으로 잃어버린 해가 없는지 확인하는 것이 좋습니다.

1.2.2모델링

미분방정식을 세울 때는 "변화율 = (원인)"을 문장으로 먼저 쓰고 식으로 옮깁니다.

예제 1.2.2 (뉴턴의 냉각 법칙)

90 °C 커피를 20 °C 방에 두었더니 10분 뒤 60 °C가 되었다. 언제 30 °C가 되는가?

풀이. 식는 빠르기는 방과의 온도 차에 비례합니다: \(\dfrac{dT}{dt} = -k(T - 20)\). 변수분리하면 \(\dfrac{dT}{T - 20} = -k\,dt\), \(\ln|T - 20| = -kt + c\), 곧 \(T = 20 + Ce^{-kt}\). \(T(0) = 90\)에서 \(C = 70\). \(T(10) = 60\)에서 \(70e^{-10k} = 40\), \(e^{-10k} = \frac47\).

\(T = 30\)이면 \(70e^{-kt} = 10\), \(e^{-kt} = \frac17\), \(t = 10\cdot\dfrac{\ln7}{\ln(7/4)} \approx 34.8\)분.

예제 1.2.3 (혼합 문제)

물 1000 L에 소금 100 kg이 녹아 있는 탱크에 맑은 물이 분당 10 L 들어오고, 잘 섞인 물이 분당 10 L 나간다. \(t\)분 뒤 소금의 양 \(y(t)\)는?

풀이. 소금의 변화율 = (들어오는 양) − (나가는 양). 들어오는 물에는 소금이 없고, 나가는 물의 농도는 \(\frac{y}{1000}\) kg/L이므로 나가는 양은 \(10\cdot\frac{y}{1000} = 0.01y\) kg/분입니다. \(y' = -0.01y\), \(y(0) = 100\)이므로 \(y = 100e^{-0.01t}\). 소금이 절반이 되는 시간은 \(\frac{\ln2}{0.01} \approx 69\)분입니다.

들어오는 물에도 소금이 있으면 식이 \(y' = a - by\) 꼴이 됩니다. 이것도 변수분리로 풀 수 있고, 1.4절의 선형 미분방정식 방법으로도 풀 수 있습니다.

주의적분 상수를 마지막에 한 번만 붙이면 됩니다. 양변에 각각 붙여도 하나로 합쳐집니다. 그러나 \(\ln|y| = -x^2 + c\)를 \(y = e^{-x^2} + c\)로 바꾸면 틀립니다. \(e^{-x^2 + c} = e^ce^{-x^2}\)이므로 상수는 곱해집니다.
요약
  1. \(y' = g(x)h(y)\)이면 \(\int\frac{dy}{h(y)} = \int g(x)dx + c\).
  2. 모델링: "변화율 = 원인"을 문장으로 쓰고 식으로 옮긴다.
  3. 냉각: \(T = T_{\text{주변}} + Ce^{-kt}\). 혼합: 변화율 = 들어옴 − 나감.

1.2.3연습문제

기본

  1. \(y' = \frac{x}{y}\), \(y(0) = 2\)를 풀어라.
    답

    \(y\,dy = x\,dx\), \(\frac{y^2}{2} = \frac{x^2}{2} + c\). \(y^2 = x^2 + 4\), \(y = \sqrt{x^2 + 4}\).

  2. \(y' = y^2\), \(y(0) = 1\)을 풀고, 해가 정의되는 범위를 말하여라.
    답

    \(-\frac1y = x + c\), \(c = -1\). \(y = \frac{1}{1 - x}\). \(x < 1\)에서만 정의된다(\(x \to 1\)이면 무한대로 발산).

응용

  1. 방사성 탄소의 반감기가 5730년일 때, 원래 양의 30%가 남은 화석의 나이는?
    답

    \(y = y_0e^{-kt}\), \(k = \frac{\ln2}{5730}\). \(0.3 = e^{-kt}\), \(t = \frac{5730\ln(1/0.3)}{\ln2} \approx 9950\)년.

1.2.2

예제변수분리형, 선형, 완전 방정식을 구별하고 풀기

형태 알아보기 · 문제 해결 전략

다루는 성취기준 [공통8-01-02]

세 가지 꼴과 근거

  • 변수분리형 \(y' = g(x)h(y)\): \(\int\frac{dy}{h(y)} = \int g(x)\,dx\). 근거는 치환적분(공통1 5-03): \(\frac{1}{h(y)}\frac{dy}{dx} = g(x)\)를 \(x\)로 적분. \(h(y_0) = 0\)인 상수해를 따로 챙깁니다(나누면서 잃음).
  • 선형 \(y' + p(x)y = q(x)\): 적분인자 \(\mu = e^{\int p\,dx}\)를 곱하면 왼쪽이 \((\mu y)'\)가 되어(곱의 법칙) \(\mu y = \int\mu q\,dx + C\).
  • 완전 \(M\,dx + N\,dy = 0\), \(M_y = N_x\): \(F_x = M\), \(F_y = N\)인 \(F\)가 있어 해는 \(F(x, y) = C\). 공통2 7-02의 퍼텐셜 찾기와 같은 계산.
문제 해결 전략 · 일계 미분방정식
  1. \(y' = \)꼴로 정리해 \(g(x)h(y)\)로 쪼개지는지 본다(변수분리).
  2. \(y\)와 \(y'\)에 대해 일차인지 본다(선형). 표준형 \(y' + py = q\)로 만든다.
  3. \(M\,dx + N\,dy = 0\)으로 쓰고 \(M_y = N_x\)를 확인한다(완전). 아니면 적분인자(01-03 카드).
  4. 초기조건으로 상수를 정하고, 원래 식에 넣어 확인한다.
  5. 해가 정의되는 구간(분모 0, 로그의 정의역)을 적는다.

(가) \(y' = xy^2\), \(y(0) = 1\) (나) \(y' + \frac2xy = x\), \(y(1) = 0\) (\(x > 0\)) (다) \((2xy + 3)\,dx + (x^2 - 1)\,dy = 0\)

풀이

  1. (가) 변수분리: \(\int y^{-2}dy = \int x\,dx\), \(-\frac1y = \frac{x^2}{2} + C\). \(y(0) = 1\)이면 \(C = -1\). \(y = \frac{2}{2 - x^2}\).
    상수해 \(y = 0\)은 초기조건과 맞지 않음. 해는 \(|x| < \sqrt2\)에서만 존재(그 밖에서 터짐).
  2. (나) 선형, \(p = \frac2x\): \(\mu = e^{2\ln x} = x^2\). \((x^2y)' = x^3\), \(x^2y = \frac{x^4}{4} + C\).
    적분인자.
  3. \(y(1) = 0\)이면 \(C = -\frac14\). \(y = \frac{x^2}{4} - \frac{1}{4x^2}\).
    초기조건.
  4. (다) \(M = 2xy + 3\), \(N = x^2 - 1\). \(M_y = 2x = N_x\): 완전.
    완전성 판정.
  5. \(F = \int M\,dx = x^2y + 3x + g(y)\), \(F_y = x^2 + g'(y) = x^2 - 1\) → \(g = -y\). 해: \(x^2y + 3x - y = C\), 곧 \(y = \frac{C - 3x}{x^2 - 1}\).
    퍼텐셜 찾기.

의미

(가)는 계수가 매끄러운데도 해가 \(x = \pm\sqrt2\)에서 무한대로 터집니다. 비선형 방정식은 방정식만 보고 해의 존재 구간을 알 수 없고, 초기값에 따라 그 구간이 달라집니다. 반면 선형 방정식은 계수가 연속인 구간 전체에서 해가 존재합니다(01-05 카드).

검산

(나) \(y' = \frac x2 + \frac{1}{2x^3}\), \(\frac2xy = \frac x2 - \frac{1}{2x^3}\). 더하면 \(x\). 맞습니다. (가) \(y' = \frac{4x}{(2 - x^2)^2} = x\cdot\frac{4}{(2-x^2)^2} = xy^2\).

1.2.3

예제혼합, 냉각, 개체군 문제를 일계 방정식으로 세우기

변화율 = 들어옴 − 나감 · Newton 냉각 · 로지스틱

다루는 성취기준 [공통8-01-02]

모형 세우기의 한 원리

변화율 = 들어오는 비율 − 나가는 비율. 무엇이 변수인지, 단위가 맞는지, 어떤 가정을 했는지 적습니다.

  • 혼합: 탱크 속 소금 \(A(t)\). 들어옴 = 유입 농도 × 유입 속도, 나감 = \(\frac{A}{V}\) × 유출 속도(잘 섞였다고 가정).
  • Newton 냉각: \(\frac{dT}{dt} = -k(T - T_{\text{주변}})\). 온도차에 비례해 식음.
  • 로지스틱: \(\frac{dP}{dt} = rP\left(1 - \frac PK\right)\). 작을 때는 지수 성장, \(K\)(수용력)에 가까워지면 느려짐.
먼저 예측

소금물이 들어오고 같은 속도로 나가는 탱크에서, 아주 오래 지나면 탱크의 소금 농도는 얼마가 될까요?

예측 확인

들어오는 소금물의 농도와 같아집니다. 처음 상태는 잊혀집니다.

(가) 물 100 L에 소금 10 kg이 녹은 탱크에 농도 0.2 kg/L의 소금물이 분당 5 L 들어오고, 잘 섞인 물이 분당 5 L 나갑니다. \(A(t)\)와 오래 지난 뒤의 소금 양은? (나) 90 ℃ 커피를 20 ℃ 방에 두었더니 10분 뒤 60 ℃가 되었습니다. 40 ℃가 되는 시각은?

풀이

  1. (가) \(\frac{dA}{dt} = 0.2\times5 - \frac{A}{100}\times5 = 1 - 0.05A\).
    kg/min = (kg/L)(L/min). 부피 일정(들어옴 = 나감).
  2. 선형(또는 변수분리): \(A = 20 + Ce^{-0.05t}\). \(A(0) = 10\)이면 \(C = -10\). \(A(t) = 20 - 10e^{-0.05t}\).
    평형해 \(A = 20\) + 지수 감쇠.
  3. \(t \to \infty\)이면 \(A \to 20\) kg (농도 0.2 kg/L, 유입 농도와 같음).
    예측과 일치.
  4. (나) \(T = 20 + 70e^{-kt}\). \(60 = 20 + 70e^{-10k}\)에서 \(e^{-10k} = \frac47\), \(k = \frac{\ln(7/4)}{10} = 0.0560\) /min.
    Newton 냉각의 해.
  5. \(40 = 20 + 70e^{-kt}\): \(e^{-kt} = \frac27\), \(t = \frac{\ln3.5}{0.0560} = 22.4\) 분.
    로그를 취해 푼다.

의미

두 문제는 같은 방정식 \(y' = -k(y - y_\infty)\)입니다. 해는 언제나 "평형값 + 처음 차이 × \(e^{-kt}\)"이고, \(\frac1k\)이 시간 상수입니다(공통4 3-03의 RC 회로도 같음). 법의학에서 시신의 체온으로 사망 시각을 추정할 때 Newton 냉각을 씁니다(다만 실제로는 오차가 큰 근사).

검산

(나) 90 → 60에 10분, 60 → 40에 12.4분. 온도차가 줄수록 느리게 식으니 뒤쪽이 더 걸리는 게 맞습니다. 차이로 보면 70 → 40 → 20, 같은 비율 \(\frac47\)과 \(\frac12\)(다른 비율)이라 시간도 다릅니다. 단위: \(k\)는 /min.

모형의 한계

"잘 섞였다", "주변 온도가 일정하다", "\(K\)가 일정하다"는 이상화입니다. 탱크가 크면 섞이는 데 시간이 걸리고, 커피는 증발로도 식습니다. 모형이 예측한 값과 측정값이 어긋나면 가정을 다시 봅니다.
