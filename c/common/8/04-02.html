4.2.1

설명벡터공간, 기저, 차원, 계수의 관계

열공간 · 영공간 · rank + nullity = n

다루는 성취기준 [공통8-04-02]

왜 필요한가

04-01 카드에서 해가 하나일지, 무수히 많을지, 없을지는 계단꼴의 피벗 개수로 정해졌습니다. 그 피벗 개수(계수)가 무엇을 재는지 알면 계산 없이도 해의 구조를 말할 수 있습니다. 공통2 2단원의 기저와 차원을 행렬의 언어로 다시 씁니다.

정의

\(m\times n\) 행렬 \(A\)에 대해 열공간 \(C(A)\): 열벡터들이 생성하는 공간(\(A\mathbf x\)로 만들 수 있는 모든 벡터). 영공간 \(N(A)\): \(A\mathbf x = \mathbf 0\)의 해 전체. 계수 \(\text{rank}\,A = \dim C(A)\) = 계단꼴의 피벗 개수.

정의를 풀어 읽기

  1. 해의 존재\(A\mathbf x = \mathbf b\)는 \(\mathbf b \in C(A)\)일 때만 해가 있습니다. "열들의 일차결합으로 \(\mathbf b\)를 만들 수 있는가"가 곧 연립방정식을 푸는 일입니다.
  2. 해의 유일성해가 있다면 일반해 = 특수해 + \(N(A)\). \(N(A) = \{\mathbf 0\}\)일 때만 유일.
  3. 계수-퇴화차수 정리\(\text{rank}\,A + \dim N(A) = n\) (열의 수). 피벗 열 수 + 자유변수 수 = 전체 변수 수이기 때문입니다.
  4. 정사각행렬\(n\times n\)에서 \(\text{rank} = n\) ⇔ \(\det A \ne 0\) ⇔ 역행렬 존재 ⇔ 모든 \(\mathbf b\)에 해가 유일. 이 동치들이 선형대수의 중심입니다.

예와 반례

  • 예: 04-01 카드 (나)의 계수 행렬은 rank 2. \(n = 3\)이라 영공간 차원 1(직선 \(t(-1, -1, 1)\)). 열공간은 \(\mathbb R^3\) 안의 평면이라, 이 평면 밖의 \(\mathbf b\)에 대해서는 해가 없습니다.
  • 예(행렬이 아닌 공간): 2단원의 \(y'' + y = 0\) 해 전체는 차원 2인 벡터공간(기저 \(\cos x, \sin x\)). 미분 연산 \(L[y] = y'' + y\)를 행렬처럼 보면 해 공간은 \(L\)의 영공간입니다.
  • 반례(계수를 열 수로 착각): \(\begin{pmatrix}1&2\\2&4\end{pmatrix}\)는 열이 2개지만 둘째 열이 첫째의 2배라 rank 1. \(\det = 0\)이고 역행렬이 없습니다.

다른 개념과의 관계

행 계수 = 열 계수(행공간과 열공간의 차원이 같음)는 선형대수의 놀라운 사실 중 하나입니다. 다음 카드의 고유벡터는 \(A - \lambda I\)의 영공간이고, 고유값은 \(A - \lambda I\)의 계수가 떨어지는(\(\det = 0\)) \(\lambda\)입니다.

흔한 오해

  • "식이 미지수보다 많으면 해가 없다." 식이 많아도 서로 종속이면 해가 있을 수 있습니다. 개수가 아니라 계수가 정합니다.
