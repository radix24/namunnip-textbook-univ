4.2.1르장드르 방정식

구 모양의 물체 둘레의 전위나 온도 분포를 구하면(구면좌표에서 변수분리), 각도 부분이 다음 방정식을 만족합니다.

\[(1 - x^2)y'' - 2xy' + n(n + 1)y = 0.\]

이것을 르장드르 방정식이라 합니다(\(x = \cos\theta\)). 4.1절처럼 급수를 넣으면 점화식

\[a_{s+2} = -\frac{(n - s)(n + s + 1)}{(s + 2)(s + 1)}a_s\]

를 얻습니다.

4.2.2급수가 끊기는 경우

점화식의 분자에 \((n - s)\)가 있으므로, \(n\)이 0 이상의 정수이면 \(s = n\)에서 \(a_{n+2} = 0\)이 되고, 그 뒤로 두 칸씩 떨어진 계수가 모두 0입니다. 그래서 짝수 항 또는 홀수 항 가운데 한쪽이 \(x^n\)에서 끊겨 다항식이 됩니다. 이 다항식을 \(x = 1\)에서 값이 1이 되도록 상수를 맞춘 것이 르장드르 다항식 \(P_n(x)\)입니다.

\[P_0 = 1, \quad P_1 = x, \quad P_2 = \tfrac12(3x^2 - 1), \quad P_3 = \tfrac12(5x^3 - 3x).\]
예제 4.2.1

\(n = 2\)일 때 점화식으로 \(P_2\)를 구하여라.

풀이. 짝수 쪽: \(a_2 = -\frac{2\cdot3}{2\cdot1}a_0 = -3a_0\), \(a_4 = -\frac{0\cdot5}{4\cdot3}a_2 = 0\). 따라서 \(a_0(1 - 3x^2)\). \(x = 1\)에서 1이 되도록 \(a_0 = -\frac12\): \(P_2 = \frac12(3x^2 - 1)\).

르장드르 다항식은 \([-1, 1]\)에서 서로 직교합니다: \(m \ne n\)이면 \(\int_{-1}^1P_mP_n\,dx = 0\). 이 성질 덕분에 함수를 \(\sum c_nP_n\)으로 전개할 수 있고(6.4절의 일반화된 푸리에 급수), 원자 오비탈의 각도 모양(물리화학, 양자역학)과 전기 다중극 전개(전자기학)에 쓰입니다.

요약
  1. \((1 - x^2)y'' - 2xy' + n(n + 1)y = 0\): 구 대칭 문제에서 나온다.
  2. \(n\)이 정수이면 급수가 끊겨 다항식 \(P_n\)이 된다(\(P_n(1) = 1\)).
  3. \(P_n\)들은 \([-1, 1]\)에서 직교한다.

4.2.3연습문제

기본

  1. \(P_2\)가 \(n = 2\)인 르장드르 방정식을 만족함을 확인하여라.
    답

    \(y = \frac12(3x^2 - 1)\), \(y' = 3x\), \(y'' = 3\). \((1 - x^2)3 - 6x^2 + 3(3x^2 - 1) = 0\).

  2. \(\int_{-1}^1P_1P_2\,dx = 0\)을 확인하여라.
    답

    \(\frac12\int_{-1}^1(3x^3 - x)dx = 0\) (기함수).

4.2.2

탐구르장드르 다항식은 왜 서로 "수직"일까?

탐구 · 르장드르 다항식과 직교성

다루는 성취기준 [공통8-04-02]

질문

르장드르 방정식 \((1 - x^2)y'' - 2xy' + n(n + 1)y = 0\)의 급수해는 \(n\)이 정수일 때 다항식으로 끊깁니다. 이 다항식 \(P_n(x)\)는 구 모양 물체의 전위와 수소 원자의 오비탈에 나옵니다. 그래프를 겹쳐 보고, 두 다항식을 곱해 \(-1\)부터 1까지 적분하면 왜 0이 되는지 확인합니다.

복원

  • \(P_0 = 1\), \(P_1 = x\), \(P_2 = \tfrac12(3x^2 - 1)\), \(P_3 = \tfrac12(5x^3 - 3x)\). 다음 것은 점화식 \((n + 1)P_{n+1} = (2n + 1)xP_n - nP_{n-1}\)으로 만듭니다.
  • 모두 \(P_n(1) = 1\)이 되도록 크기를 맞춘 것입니다. 연한 선은 0~5 가운데 고르지 않은 다항식입니다.
  • 적분은 심프슨 공식(2000칸)으로 계산합니다.

설명

\(n \ne m\)이면 \(\int_{-1}^1P_nP_m\,dx = 0\)이고, \(n = m\)이면 \(\dfrac{2}{2n + 1}\)(예: \(n = m = 2\)일 때 0.4)입니다. 벡터의 내적이 성분의 곱의 합이듯, 함수의 "내적"을 곱의 적분으로 정하면 \(P_n\)들은 서로 수직인 벡터처럼 행동합니다. 그래서 \([-1, 1]\)의 함수를 푸리에 급수처럼 \(\sum c_nP_n\)으로 전개하고 계수를 적분 하나로 구할 수 있습니다.

\(P_n\)은 \([-1, 1]\) 안에 서로 다른 근을 정확히 \(n\)개 가집니다. \(P_2\)의 근은 \(\pm0.5774\)(\(\pm1/\sqrt3\)), \(P_3\)은 \(0, \pm0.7746\)(\(\pm\sqrt{3/5}\))입니다. 이 근은 가우스 수치 적분의 계산점으로 쓰입니다.

연결

직교성은 스투름-리우빌 문제의 고유함수에서 일반적으로 성립합니다(6.3절). 사인 함수의 직교성이 푸리에 급수의 바탕인 것과 같습니다(6.1절).

적용

\(x^2\)을 \(c_0P_0 + c_1P_1 + c_2P_2\)로 나타내세요. \(c_n = \dfrac{2n + 1}2\int_{-1}^1x^2P_n\,dx\)를 쓰거나, \(P_2\)의 식에서 바로 풀어도 됩니다(답: \(x^2 = \tfrac13P_0 + \tfrac23P_2\)).

판단

“\(P_1 = x\)와 \(P_3\)는 둘 다 기함수이므로 곱의 적분이 0인 것은 대칭 때문이다.” 기함수 × 기함수는 우함수입니다. 이 말이 맞는지, 출력으로 따져 보세요.
