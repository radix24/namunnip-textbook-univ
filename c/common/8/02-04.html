예제Euler-Cauchy 방정식: x^m을 대입하라

x²y″ + axy′ + by = 0 · 보조방정식 · x = e^t 치환

다루는 성취기준 [공통8-02-04]

출발점

\(x^2y'' + axy' + by = 0\) (\(x > 0\))은 계수가 변하지만, 각 항이 "미분할 때마다 \(x\)를 하나씩 곱한" 꼴이라 \(y = x^m\)을 넣으면 모든 항이 \(x^m\)의 배수가 됩니다: \(x^m[m(m - 1) + am + b] = 0\). 보조방정식 \(m^2 + (a - 1)m + b = 0\).

근일반해
서로 다른 실근 \(m_1, m_2\)\(c_1x^{m_1} + c_2x^{m_2}\)
중근 \(m\)\((c_1 + c_2\ln x)x^m\)
복소근 \(\alpha \pm i\beta\)\(x^\alpha[c_1\cos(\beta\ln x) + c_2\sin(\beta\ln x)]\)

왜 이렇게 되나: \(x = e^t\)로 치환하면 \(x\frac{dy}{dx} = \frac{dy}{dt}\), \(x^2\frac{d^2y}{dx^2} = \frac{d^2y}{dt^2} - \frac{dy}{dt}\)이라 상수계수 방정식이 됩니다. 02-02 카드의 표에서 \(x\)를 \(t = \ln x\)로 바꾼 것이 위 표입니다.

(가) \(x^2y'' - 2xy' - 4y = 0\) (나) \(x^2y'' - 3xy' + 4y = 0\), \(y(1) = 1\), \(y'(1) = 0\) (다) \(x^2y'' + xy' + 4y = 0\)

풀이

  1. (가) \(m(m - 1) - 2m - 4 = m^2 - 3m - 4 = (m - 4)(m + 1)\). \(y = c_1x^4 + c_2x^{-1}\).
    서로 다른 실근.
  2. (나) \(m^2 - 4m + 4 = (m - 2)^2\), 중근 2. \(y = (c_1 + c_2\ln x)x^2\).
    \(t = \ln x\)에서의 \(te^{2t}\)가 \(x^2\ln x\).
  3. \(y(1) = c_1 = 1\). \(y' = 2x(c_1 + c_2\ln x) + c_2x\), \(y'(1) = 2 + c_2 = 0\), \(c_2 = -2\). \(y = x^2(1 - 2\ln x)\).
    초기조건(\(\ln1 = 0\)).
  4. (다) \(m^2 + 4 = 0\), \(m = \pm2i\). \(y = c_1\cos(2\ln x) + c_2\sin(2\ln x)\).
    \(\alpha = 0\), \(\beta = 2\).

의미

(다)의 해는 \(x \to 0^+\)으로 갈수록 끝없이 빠르게 진동합니다(\(\ln x \to -\infty\)). \(x = 0\)은 계수 \(x^2\)이 0이 되는 특이점이라 해가 이상하게 행동할 수 있습니다. 이 방정식은 원판이나 구 같은 원형 영역에서 Laplace 방정식을 변수분리할 때(공통9 5단원) 지름 방향 부분으로 나타나며, 7단원의 Frobenius 방법은 이것을 일반화한 것입니다.

검산

(나) \(y = x^2 - 2x^2\ln x\): \(y' = 2x - 4x\ln x - 2x = -4x\ln x\), \(y'' = -4\ln x - 4\). \(x^2y'' - 3xy' + 4y = -4x^2\ln x - 4x^2 + 12x^2\ln x + 4x^2 - 8x^2\ln x = 0\). 맞습니다.

흔한 오해

  • 보조방정식에 \(a\)를 그대로: \(m^2 + am + b\)가 아니라 \(m(m - 1) + am + b\)입니다. \(y''\)에서 \(m(m-1)\)이 나옵니다.
