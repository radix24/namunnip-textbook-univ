2.7.1

유도강제 진동의 정상 상태 진폭과 공명

mx″ + cx′ + kx = F₀cos ωt · 진폭 곡선 · 맥놀이

다루는 성취기준 [공통8-02-07]

무엇을 유도하나

정상 상태 해 \(x_p = A\cos(\omega t - \delta)\)의 진폭

\[A(\omega) = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2}}.\]

감쇠가 작으면 \(\omega \approx \omega_0 = \sqrt{k/m}\)에서 진폭이 크게 솟는다(공명).

모형

주기적 외력 \(F_0\cos\omega t\). 일반해 = 동차해(감쇠 때문에 시간이 지나면 사라지는 과도 응답) + 특수해(남는 정상 상태 응답). 오래 지나면 외력의 진동수 \(\omega\)로 진동합니다.

유도

  1. 미정계수법(02-06 카드): \(x_p = a\cos\omega t + b\sin\omega t\).
    외력이 코사인이라 사인·코사인 둘 다 추측.
  2. 대입해 \(\cos\), \(\sin\) 계수 비교: \((k - m\omega^2)a + c\omega b = F_0\), \(-c\omega a + (k - m\omega^2)b = 0\).
    \(x_p'' = -\omega^2x_p\), \(x_p' = -a\omega\sin + b\omega\cos\).
  3. 풀면 \(a = \frac{F_0(k - m\omega^2)}{D}\), \(b = \frac{F_0c\omega}{D}\), \(D = (k - m\omega^2)^2 + (c\omega)^2\).
    2×2 연립(크라메르 공식).
  4. 진폭 \(A = \sqrt{a^2 + b^2} = \frac{F_0}{\sqrt D}\). 위상 지연 \(\tan\delta = \frac{c\omega}{k - m\omega^2}\).
    \(a\cos + b\sin = A\cos(\omega t - \delta)\).

결과 확인

  • \(\omega \to 0\): \(A \to \frac{F_0}{k}\). 아주 천천히 밀면 용수철이 정적으로 늘어나는 양.
  • \(\omega \to \infty\): \(A \to 0\). 너무 빨리 흔들면 질량이 따라가지 못함.
  • \(\omega = \omega_0\): 첫 항이 0이라 \(A = \frac{F_0}{c\omega_0}\). 감쇠가 작을수록 커짐. \(c = 0\)이면 무한대: 진폭이 \(t\)에 비례해 끝없이 커지는 해 \(\frac{F_0}{2m\omega_0}t\sin\omega_0t\) (02-R 문제 3).
  • 수치: \(m = 1\), \(k = 100\), \(c = 2\), \(F_0 = 10\)이면 \(\omega = 10\)에서 \(A = \frac{10}{20} = 0.5\) m, 정적 변위 0.1 m의 5배. \(c = 0.2\)이면 50배.

맥놀이와 한계

감쇠가 없고 \(\omega\)가 \(\omega_0\)에 가까우면, 처음 정지 상태에서 시작한 해는 \(\frac{2F_0}{m(\omega_0^2 - \omega^2)}\sin\frac{(\omega_0 - \omega)t}{2}\sin\frac{(\omega_0 + \omega)t}{2}\)로 진폭이 느리게 커졌다 작아집니다(맥놀이). 두 소리굽쇠가 조금 다른 음을 낼 때 "웅웅" 하는 소리입니다. 실제 공명에서는 진폭이 커지면 비선형 효과(재료의 한계)가 나타나 이 선형 모형이 깨집니다. 1940년 타코마 다리 붕괴는 단순 공명이 아니라 바람과 다리의 상호작용(자려 진동)이 원인이라는 것이 현재의 설명입니다.

2.7.2

예제질량-용수철 계와 RLC 회로는 같은 방정식이다

대응표 · 감쇠 판정 · 같은 수학, 다른 물리 · 문제 해결 전략

다루는 성취기준 [공통8-02-07]

두 방정식

질량-용수철-감쇠기: \(mx'' + cx' + kx = F(t)\) (뉴턴 제2법칙). 직렬 RLC 회로: \(Lq'' + Rq' + \frac1Cq = E(t)\) (Kirchhoff 고리 법칙, 공통4 3-02). 문자만 다른 같은 방정식입니다.

역학전기
변위 \(x\)전하 \(q\)
질량 \(m\)인덕턴스 \(L\)
감쇠 계수 \(c\)저항 \(R\)
용수철 상수 \(k\)\(\frac1C\)
외력 \(F(t)\)기전력 \(E(t)\)
문제 해결 전략 · 진동 모형
  1. 계의 방정식을 표준형 \(ay'' + by' + cy = g(t)\)로 세운다(역학: 힘의 합, 전기: 고리 법칙).
  2. 판별식 \(b^2 - 4ac\)로 감쇠의 종류를 정한다.
  3. 과도 응답(동차해)과 정상 상태 응답(특수해)을 따로 구한다.
  4. 필요하면 대응표로 다른 계의 직관을 빌린다.

\(L = 0.5\) H, \(R = 10\ \Omega\), \(C = 0.01\) F인 직렬 RLC 회로의 축전기가 처음에 \(q(0) = 0.1\) C로 충전되어 있고 전류가 0입니다(전원 없음). \(q(t)\)를 구하고, 감쇠의 종류와 같은 행동을 하는 질량-용수철 계를 말하세요.

풀이

  1. \(0.5q'' + 10q' + 100q = 0\), 곧 \(q'' + 20q' + 200q = 0\).
    \(\frac1C = 100\). 2를 곱함.
  2. 판별식 \(400 - 800 < 0\): 미감쇠. \(r = -10 \pm 10i\).
    02-02 카드.
  3. \(q = e^{-10t}(A\cos10t + B\sin10t)\). \(q(0) = A = 0.1\).
    일반해에 초기조건.
  4. \(q'(0) = -10A + 10B = 0\), \(B = 0.1\). \(q(t) = 0.1e^{-10t}(\cos10t + \sin10t)\).
    전류 \(I = q'\)의 초기값 0.

대응하는 역학계: \(m = 0.5\) kg, \(c = 10\) N·s/m, \(k = 100\) N/m 용수철을 0.1 m 당겼다가 놓은 것.

의미

같은 방정식이면 같은 해를 가지므로, 큰 기계 구조물의 진동을 작은 전기 회로로 흉내 내 실험할 수 있었습니다. 디지털 컴퓨터 이전의 "아날로그 컴퓨터"가 이 원리였습니다. 하나를 이해하면 다른 하나도 이해한 것이 됩니다: 저항은 마찰처럼 에너지를 열로 바꾸고, 인덕터는 질량처럼 변화에 저항합니다.

검산

감쇠비 \(\zeta = \frac{R}{2}\sqrt{\frac CL} = 5\sqrt{0.02} = 0.707 < 1\): 미감쇠. 진폭이 \(e^{-10t}\)로 줄어 약 0.5초 뒤 0.7% 미만. 차원: \(\frac RL\)은 1/s.
