3.1.1왜 행렬이 필요한가

탱크 두 개가 관으로 이어져 있으면 각 탱크의 소금 양이 서로에게 영향을 줍니다. 미지 함수가 둘 이상이고 서로 얽힌 미분방정식을 연립 미분방정식이라 하는데, 이를 깔끔하게 쓰고 풀려면 행렬이 필요합니다. 교재 4.0절은 이 단원에 필요한 행렬 지식만 짧게 모아 둔 절입니다.

3.1.2행렬의 곱과 행렬식

숫자를 직사각형으로 배열한 것을 행렬이라 합니다. 2×2 행렬과 벡터의 곱은 "행과 열을 짝지어 곱해 더하기"입니다.

\[\begin{bmatrix}a & b\\ c & d\end{bmatrix}\begin{bmatrix}x_1\\ x_2\end{bmatrix} = \begin{bmatrix}ax_1 + bx_2\\ cx_1 + dx_2\end{bmatrix}.\]

그래서 연립방정식 \(ax_1 + bx_2 = k_1\), \(cx_1 + dx_2 = k_2\)를 \(A\mathbf x = \mathbf k\)로 짧게 쓸 수 있습니다. 2×2 행렬의 행렬식은 \(\det A = ad - bc\)이고, \(\det A \ne 0\)이면 연립방정식의 해가 하나뿐이며, \(\det A = 0\)이면 해가 없거나 무수히 많습니다.

3.1.3고유값과 고유벡터

행렬을 곱하면 보통 벡터의 방향이 바뀝니다. 그런데 어떤 특별한 벡터는 방향이 그대로이고 길이만 \(\lambda\)배가 됩니다.

정의 3.1.1 (고유값과 고유벡터)

\(A\mathbf x = \lambda\mathbf x\)를 만족하는 영벡터가 아닌 \(\mathbf x\)를 고유벡터, 그때의 수 \(\lambda\)를 고유값이라 한다.

\(A\mathbf x = \lambda\mathbf x\)는 \((A - \lambda I)\mathbf x = \mathbf 0\)과 같습니다(\(I\)는 대각선이 1이고 나머지가 0인 단위행렬). 영벡터가 아닌 해가 있으려면 해가 하나뿐이면 안 되므로 \(\det(A - \lambda I) = 0\)이어야 합니다.

정리 3.1.2 (고유값 구하기)

\(A = \begin{bmatrix}a & b\\ c & d\end{bmatrix}\)의 고유값은 특성방정식 \(\det(A - \lambda I) = (a - \lambda)(d - \lambda) - bc = 0\)의 근이다.

예제 3.1.3

\(A = \begin{bmatrix}-5 & 2\\ 2 & -2\end{bmatrix}\)의 고유값과 고유벡터를 구하여라.

풀이. \((-5 - \lambda)(-2 - \lambda) - 4 = \lambda^2 + 7\lambda + 6 = (\lambda + 1)(\lambda + 6) = 0\). 고유값 \(-1\), \(-6\).

\(\lambda = -1\): \((A + I)\mathbf x = \mathbf 0\)은 \(-4x_1 + 2x_2 = 0\)이므로 \(x_2 = 2x_1\), 고유벡터 \(\begin{bmatrix}1\\2\end{bmatrix}\). \(\lambda = -6\): \(x_1 + 2x_2 = 0\), 고유벡터 \(\begin{bmatrix}2\\-1\end{bmatrix}\).

검산: \(A\begin{bmatrix}1\\2\end{bmatrix} = \begin{bmatrix}-1\\-2\end{bmatrix} = -1\cdot\begin{bmatrix}1\\2\end{bmatrix}\). 고유벡터는 상수배를 해도 고유벡터이므로 답은 하나가 아닙니다.

고유값이 복소수로 나올 수도 있습니다. 예를 들어 \(\begin{bmatrix}0 & 1\\ -1 & 0\end{bmatrix}\)은 \(\lambda^2 + 1 = 0\)에서 \(\lambda = \pm i\)입니다. 이 경우는 3.4절에서 회전하는 궤적으로 나타납니다.

요약
  1. 행렬 곱: 행과 열을 짝지어 곱해 더한다. 2×2 행렬식 \(ad - bc\).
  2. \(A\mathbf x = \lambda\mathbf x\): 방향이 그대로인 벡터와 그 배율.
  3. 고유값은 \(\det(A - \lambda I) = 0\)의 근, 고유벡터는 \((A - \lambda I)\mathbf x = \mathbf 0\)의 해.

3.1.4연습문제

기본

  1. \(A = \begin{bmatrix}2 & 1\\ 1 & 2\end{bmatrix}\)의 고유값과 고유벡터를 구하여라.
    답

    \(\lambda^2 - 4\lambda + 3 = 0\), \(\lambda = 1, 3\). 고유벡터 \(\begin{bmatrix}1\\-1\end{bmatrix}\), \(\begin{bmatrix}1\\1\end{bmatrix}\).

  2. \(\begin{bmatrix}3 & -1\\ 2 & 4\end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix}\)과 행렬식을 계산하여라.
    답

    \(\begin{bmatrix}1\\10\end{bmatrix}\), 행렬식 \(12 + 2 = 14\).

3.1.2

예제고유값과 고유벡터를 구하고 대각화하기

Av = λv · det(A − λI) = 0 · A = PDP⁻¹ · 거듭제곱

다루는 성취기준 [공통8-03-01]

정의와 근거

\(A\mathbf v = \lambda\mathbf v\) (\(\mathbf v \ne \mathbf 0\)): \(A\)가 방향을 바꾸지 않고 \(\lambda\)배만 늘리는 방향이 고유벡터, 그 배율이 고유값. \((A - \lambda I)\mathbf v = \mathbf 0\)이 영벡터 아닌 해를 가지려면 \(A - \lambda I\)의 역행렬이 없어야 하므로 특성방정식 \(\det(A - \lambda I) = 0\).

대각화: \(n\)개의 일차독립 고유벡터를 열로 한 \(P\), 고유값을 대각에 놓은 \(D\)에 대해 \(A = PDP^{-1}\). 그러면 \(A^k = PD^kP^{-1}\)이라 거듭제곱이 쉬워집니다.

먼저 예측

행렬 \(\begin{pmatrix}0&-1\\1&0\end{pmatrix}\) (90° 회전)의 실수 고유벡터가 있을까요?

예측 확인

없습니다. 90° 돌리면 모든 방향이 바뀝니다. 고유값은 \(\pm i\)로 복소수입니다.

\(A = \begin{pmatrix}4 & 1\\ 2 & 3\end{pmatrix}\)의 고유값과 고유벡터를 구하고, 대각화해서 \(A^{10}\)을 구하세요.

풀이

  1. \(\det\begin{pmatrix}4 - \lambda & 1\\ 2 & 3 - \lambda\end{pmatrix} = \lambda^2 - 7\lambda + 10 = (\lambda - 5)(\lambda - 2) = 0\).
    특성방정식.
  2. \(\lambda = 5\): \((A - 5I)\mathbf v = \begin{pmatrix}-1&1\\2&-2\end{pmatrix}\mathbf v = \mathbf 0\) → \(\mathbf v_1 = (1, 1)\).
    영공간(03-01 카드). 두 행이 비례해 rank 1.
  3. \(\lambda = 2\): \(\begin{pmatrix}2&1\\2&1\end{pmatrix}\mathbf v = \mathbf 0\) → \(\mathbf v_2 = (1, -2)\).
    같은 방법.
  4. \(P = \begin{pmatrix}1&1\\1&-2\end{pmatrix}\), \(D = \begin{pmatrix}5&0\\0&2\end{pmatrix}\), \(P^{-1} = \frac{1}{-3}\begin{pmatrix}-2&-1\\-1&1\end{pmatrix} = \frac13\begin{pmatrix}2&1\\1&-1\end{pmatrix}\).
    2×2 역행렬 공식.
  5. \(A^{10} = PD^{10}P^{-1} = \frac13\begin{pmatrix}2\cdot5^{10} + 2^{10} & 5^{10} - 2^{10}\\ 2\cdot5^{10} - 2^{11} & 5^{10} + 2^{11}\end{pmatrix}\). \(5^{10} = 9765625\): \(A^{10} = \begin{pmatrix}6510758 & 3254867\\ 6509734 & 3255891\end{pmatrix}\).
    \(D^{10}\)은 대각 성분만 10제곱.

의미

\(A^k\mathbf x\)를 고유벡터로 분해하면 \(5^k\) 성분이 \(2^k\) 성분을 압도해, 오래 지나면 거의 \(\mathbf v_1 = (1, 1)\) 방향만 남습니다. 인구 이동 모형, 구글의 페이지랭크, 진동의 주된 모드가 모두 "가장 큰 고유값의 고유벡터"를 찾는 문제입니다. 다음 단원에서는 \(e^{At}\)의 대각화로 연립 미분방정식을 풉니다.

검산

고유값의 합 = 대각합: \(5 + 2 = 7 = 4 + 3\). 곱 = 행렬식: \(10 = 12 - 2\). \(A\mathbf v_2 = (4 - 2, 2 - 6) = (2, -4) = 2\mathbf v_2\). \(A^{10}\)의 행렬식 \(10^{10}\)과 비교: \(6510758\times3255891 - 3254867\times6509734\)도 \(10^{10}\)입니다.

3.1.3

예제가우스 소거로 연립일차방정식 풀기

첨가행렬 · 기본 행 연산 · 해가 하나·무수히·없음 · 문제 해결 전략

다루는 성취기준 [공통8-03-01]

방법

\(A\mathbf x = \mathbf b\)를 첨가행렬 \([A \mid \mathbf b]\)로 쓰고, 해를 바꾸지 않는 기본 행 연산(두 행 바꾸기, 한 행에 0 아닌 수 곱하기, 한 행에 다른 행의 배수 더하기)으로 계단꼴을 만든 뒤 뒤에서부터 대입합니다. 행 연산이 해를 바꾸지 않는 이유: 각 연산은 되돌릴 수 있고, 연립방정식에 같은 조작을 한 것과 같기 때문입니다.

문제 해결 전략 · 선형대수 계산
  1. 첨가행렬을 쓰고, 왼쪽 위부터 피벗(각 행의 첫 0 아닌 수)을 만든다. 피벗 아래를 0으로.
  2. 계단꼴에서 해의 개수를 판정한다: \([0 \cdots 0 \mid c \ne 0]\) 행이 있으면 해 없음. 피벗 없는 열(자유변수)이 있으면 무수히 많음. 아니면 하나.
  3. 뒤에서부터 대입하거나, 피벗 위도 0으로 만들어(기약 계단꼴) 바로 읽는다.
  4. 원래 식에 넣어 확인한다.

(가) \(x + 2y + z = 4\), \(2x + 5y + 3z = 9\), \(-x + y + 4z = 5\) (나) \(x + y + 2z = 3\), \(2x + 3y + 5z = 8\), \(x + 2y + 3z = 5\)

풀이

  1. (가) \(\left[\begin{array}{ccc|c}1&2&1&4\\2&5&3&9\\-1&1&4&5\end{array}\right]\). \(R_2 - 2R_1\), \(R_3 + R_1\): \(\left[\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&3&5&9\end{array}\right]\).
    첫 열의 피벗 아래를 0으로.
  2. \(R_3 - 3R_2\): \(\left[\begin{array}{ccc|c}1&2&1&4\\0&1&1&1\\0&0&2&6\end{array}\right]\).
    둘째 피벗 아래를 0으로. 계단꼴.
  3. 뒤에서부터: \(z = 3\), \(y = 1 - 3 = -2\), \(x = 4 + 4 - 3 = 5\). 해 \((5, -2, 3)\), 유일.
    피벗이 세 열 모두에 있음.
  4. (나) \(R_2 - 2R_1\), \(R_3 - R_1\): \(\left[\begin{array}{ccc|c}1&1&2&3\\0&1&1&2\\0&1&1&2\end{array}\right]\). \(R_3 - R_2\): 셋째 행 \([0\ 0\ 0 \mid 0]\).
    식 하나가 다른 둘의 결합이었다.
  5. \(z = t\) (자유변수), \(y = 2 - t\), \(x = 3 - (2 - t) - 2t = 1 - t\). 해 \((1, 2, 0) + t(-1, -1, 1)\), 무수히 많음.
    특수해 + 동차해(직선).

의미

(나)의 해는 "특수해 하나 + 동차 방정식 \(A\mathbf x = \mathbf 0\)의 해"로, 2단원의 미분방정식 해 구조 \(y = y_p + y_h\)와 똑같습니다. 가우스 소거는 컴퓨터가 연립방정식을 푸는 기본 방법이며, 계산량은 \(n^3\)에 비례합니다. 실제 계산에서는 반올림 오차를 줄이려고 가장 큰 수를 피벗으로 고릅니다(공통9 8단원의 피벗팅).

검산

(가) \(5 - 4 + 3 = 4\), \(10 - 10 + 9 = 9\), \(-5 - 2 + 12 = 5\). 모두 맞습니다. (나) \(t = 1\)이면 \((0, 1, 1)\): \(0 + 1 + 2 = 3\), \(0 + 3 + 5 = 8\), \(0 + 2 + 3 = 5\).

3.1.4

설명벡터공간, 기저, 차원, 계수의 관계

열공간 · 영공간 · rank + nullity = n

다루는 성취기준 [공통8-03-01]

왜 필요한가

03-01 카드에서 해가 하나일지, 무수히 많을지, 없을지는 계단꼴의 피벗 개수로 정해졌습니다. 그 피벗 개수(계수)가 무엇을 재는지 알면 계산 없이도 해의 구조를 말할 수 있습니다. 공통2 2단원의 기저와 차원을 행렬의 언어로 다시 씁니다.

정의

\(m\times n\) 행렬 \(A\)에 대해 열공간 \(C(A)\): 열벡터들이 생성하는 공간(\(A\mathbf x\)로 만들 수 있는 모든 벡터). 영공간 \(N(A)\): \(A\mathbf x = \mathbf 0\)의 해 전체. 계수 \(\text{rank}\,A = \dim C(A)\) = 계단꼴의 피벗 개수.

정의를 풀어 읽기

  1. 해의 존재\(A\mathbf x = \mathbf b\)는 \(\mathbf b \in C(A)\)일 때만 해가 있습니다. "열들의 일차결합으로 \(\mathbf b\)를 만들 수 있는가"가 곧 연립방정식을 푸는 일입니다.
  2. 해의 유일성해가 있다면 일반해 = 특수해 + \(N(A)\). \(N(A) = \{\mathbf 0\}\)일 때만 유일.
  3. 계수-퇴화차수 정리\(\text{rank}\,A + \dim N(A) = n\) (열의 수). 피벗 열 수 + 자유변수 수 = 전체 변수 수이기 때문입니다.
  4. 정사각행렬\(n\times n\)에서 \(\text{rank} = n\) ⇔ \(\det A \ne 0\) ⇔ 역행렬 존재 ⇔ 모든 \(\mathbf b\)에 해가 유일. 이 동치들이 선형대수의 중심입니다.

예와 반례

  • 예: 03-01 카드 (나)의 계수 행렬은 rank 2. \(n = 3\)이라 영공간 차원 1(직선 \(t(-1, -1, 1)\)). 열공간은 \(\mathbb R^3\) 안의 평면이라, 이 평면 밖의 \(\mathbf b\)에 대해서는 해가 없습니다.
  • 예(행렬이 아닌 공간): 2단원의 \(y'' + y = 0\) 해 전체는 차원 2인 벡터공간(기저 \(\cos x, \sin x\)). 미분 연산 \(L[y] = y'' + y\)를 행렬처럼 보면 해 공간은 \(L\)의 영공간입니다.
  • 반례(계수를 열 수로 착각): \(\begin{pmatrix}1&2\\2&4\end{pmatrix}\)는 열이 2개지만 둘째 열이 첫째의 2배라 rank 1. \(\det = 0\)이고 역행렬이 없습니다.

다른 개념과의 관계

행 계수 = 열 계수(행공간과 열공간의 차원이 같음)는 선형대수의 놀라운 사실 중 하나입니다. 다음 카드의 고유벡터는 \(A - \lambda I\)의 영공간이고, 고유값은 \(A - \lambda I\)의 계수가 떨어지는(\(\det = 0\)) \(\lambda\)입니다.

흔한 오해

  • "식이 미지수보다 많으면 해가 없다." 식이 많아도 서로 종속이면 해가 있을 수 있습니다. 개수가 아니라 계수가 정합니다.
