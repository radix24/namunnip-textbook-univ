4.4.1원통과 원판의 방정식

북 가죽(원판)의 진동, 원통 속의 열 전도, 원형 도파관 속의 전자기파를 원통좌표로 풀면 반지름 방향 부분이 다음 식을 만족합니다.

\[x^2y'' + xy' + (x^2 - \nu^2)y = 0.\]

이것이 베셀 방정식입니다(\(\nu \ge 0\)은 상수). 지표방정식은 \(r^2 - \nu^2 = 0\), \(r = \pm\nu\)입니다.

4.4.2제1종 베셀 함수

\(r = \nu\)로 프로베니우스 방법을 쓰고 상수를 알맞게 정하면 제1종 베셀 함수를 얻습니다. 정수 \(\nu = n\)이면

\[J_n(x) = \sum_{m=0}^\infty\frac{(-1)^m}{m!\,(n + m)!}\left(\frac x2\right)^{2m + n}.\]

특히 \(J_0(x) = 1 - \frac{x^2}{4} + \frac{x^4}{64} - \cdots\)입니다. 그래프는 코사인처럼 진동하지만 진폭이 \(\frac{1}{\sqrt x}\)처럼 천천히 줄어들고, 0이 되는 점(약 2.405, 5.520, 8.654, …)의 간격이 일정하지 않습니다. 북을 쳤을 때 나는 소리의 진동수가 이 0점들로 정해지기 때문에, 북소리는 피아노 소리처럼 배음이 정수배로 맞지 않습니다.

\(\nu = \frac12\)이면 \(J_{1/2}(x) = \sqrt{\frac{2}{\pi x}}\sin x\)처럼 기본 함수로 나타납니다. 대부분의 \(\nu\)에서는 기본 함수가 아닌 새로운 함수이고, 값은 표나 컴퓨터로 구합니다.

4.4.3제2종 베셀 함수

\(\nu\)가 정수가 아니면 \(J_\nu\)와 \(J_{-\nu}\)가 기저입니다. 그러나 \(\nu = n\)이 정수이면 \(J_{-n} = (-1)^nJ_n\)이 되어 둘이 비례하므로 두 번째 해가 따로 필요합니다. 이것이 제2종 베셀 함수 \(Y_n\)이고, \(\ln x\)가 포함되어 \(x \to 0\)일 때 무한히 커집니다(교재 5.5절, 강의에서는 간단히 다룹니다). 일반해는 \(y = c_1J_n + c_2Y_n\)이며, 원판의 중심처럼 \(x = 0\)이 포함된 문제에서는 해가 유한해야 하므로 \(c_2 = 0\)으로 놓습니다.

요약
  1. \(x^2y'' + xy' + (x^2 - \nu^2)y = 0\): 원통·원판 문제에서 나온다.
  2. \(J_\nu\): 진폭이 줄어들며 진동하는 함수, 0점 간격은 일정하지 않다.
  3. 정수 \(\nu\)이면 두 번째 해 \(Y_n\)(원점에서 발산)이 필요하다.

4.4.4연습문제

기본

  1. \(J_0\)의 급수에서 \(x^6\) 항의 계수를 구하여라.
    답

    \(m = 3\): \(\frac{(-1)^3}{3!\,3!}\cdot\frac{1}{2^6} = -\frac{1}{2304}\).

4.4.2

설명Legendre 다항식과 Bessel 함수: 직교성과 쓰임

구 대칭 · 원통 대칭 · ∫PₘPₙ = 0 · 북의 진동

다루는 성취기준 [공통8-04-04]

왜 필요한가

공 모양(지구의 중력장, 수소 원자)이나 원통 모양(북, 광섬유, 원형 도파관)의 문제를 편미분방정식으로 풀면, 변수분리 뒤에 각도나 반지름 방향으로 특별한 이계 방정식이 남습니다. 그 해가 Legendre 다항식과 Bessel 함수이고, 삼각함수가 직사각형 문제에서 하는 역할을 이 함수들이 합니다.

정의

Legendre 방정식 \((1 - x^2)y'' - 2xy' + n(n + 1)y = 0\). \(n\)이 0 이상의 정수이면 다항식 해 \(P_n(x)\): \(P_0 = 1\), \(P_1 = x\), \(P_2 = \frac12(3x^2 - 1)\), \(P_3 = \frac12(5x^3 - 3x)\).

Bessel 방정식 \(x^2y'' + xy' + (x^2 - \nu^2)y = 0\). \(x = 0\)에서 유한한 해 \(J_\nu(x) = \sum_{m=0}^\infty\frac{(-1)^m}{m!\,\Gamma(m + \nu + 1)}\left(\frac x2\right)^{2m+\nu}\) (Frobenius 방법, 04-03 카드).

정의를 풀어 읽기

  1. Legendre의 급수가 다항식이 되는 이유급수해의 점화식(04-01 카드)이 \(a_{k+2} = \frac{(k - n)(k + n + 1)}{(k+2)(k+1)}a_k\)라서 \(k = n\)에서 계수가 0이 되어 급수가 끊깁니다. 다른 \(n\)에서는 \(x = \pm1\)(구의 극)에서 발산해 물리적으로 쓸 수 없습니다.
  2. 직교성\(\int_{-1}^1P_mP_n\,dx = 0\) (\(m \ne n\)), \(\int_0^1xJ_\nu(\alpha_ix)J_\nu(\alpha_jx)\,dx = 0\) (\(\alpha_i\)는 \(J_\nu\)의 서로 다른 영점). 벡터의 수직처럼 함수끼리 "수직"이라, Fourier 급수처럼 임의의 함수를 이 함수들의 합으로 전개하고 계수를 적분 하나로 구할 수 있습니다(공통9 4-03의 Sturm-Liouville 이론).
  3. Bessel 함수의 모양\(J_0\)은 감쇠하는 코사인처럼 진동하고, 영점이 2.405, 5.520, 8.654, …에 있습니다(간격이 점점 \(\pi\)에 가까워짐).

예와 반례

  • 직교성 확인: \(\int_{-1}^1P_1P_2\,dx = \frac12\int_{-1}^1(3x^3 - x)\,dx = 0\) (기함수). \(\int_{-1}^1P_0P_2\,dx = \frac12\left[x^3 - x\right]_{-1}^1 = 0\).
  • 쓰임: 북의 진동: 반지름 \(a\)인 원형 막의 기본 진동 모양은 \(J_0\left(\frac{2.405r}{a}\right)\), 진동수는 \(\frac{2.405c}{2\pi a}\). 다음 배음은 영점 5.520에서 와서 기본음의 정수배가 아닙니다. 북 소리가 기타처럼 음정이 뚜렷하지 않은 이유입니다.
  • 쓰임: 다중극 전개: 전하 분포의 먼 곳 전위를 \(\sum\frac{c_n}{r^{n+1}}P_n(\cos\theta)\)로 전개합니다(\(n = 0\): 점전하, \(n = 1\): 쌍극자, 공통4 1-03).
  • 반례: \(x^n\)들도 다항식 공간의 기저이지만 서로 직교하지 않습니다(\(\int_{-1}^1x\cdot x^3 \ne 0\)). 그래서 계수를 구하려면 연립방정식을 풀어야 합니다. Legendre 다항식은 \(x^n\)들을 그람-슈미트로 직교화한 것입니다.

흔한 오해

  • "특수함수는 외워야 하는 공식 덩어리다." 각각은 특정 대칭에서 나오는 방정식의 해일 뿐이고, 성질(직교성, 영점, 점화식)은 수치 라이브러리(scipy.special)로 바로 계산할 수 있습니다. 어떤 문제에서 어떤 함수가 나오는지 아는 것이 중요합니다.
