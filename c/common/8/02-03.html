이 절에서 배울 것
  • 용수철-질량 계의 운동 방정식 \(my'' + cy' + ky = 0\)을 세운다.
  • 감쇠가 없을 때의 조화 진동과, 감쇠가 있을 때의 세 경우(과감쇠, 임계감쇠, 미감쇠)를 구별한다.
먼저 알아야 할 것
  • 상수계수 방정식 (2.2절), 훅의 법칙과 \(F = ma\) (공통3 9.1절).

2.3.1운동 방정식

질량 \(m\)인 물체를 용수철에 매달고 평형 위치에서 아래로 \(y\)만큼 끌어당기면 세 가지 힘이 작용합니다.

  • 용수철의 복원력: \(-ky\) (훅의 법칙, \(k\)는 용수철 상수).
  • 감쇠력: \(-cy'\) (공기나 기름의 저항이 속도에 비례, \(c\)는 감쇠 상수).
  • (중력은 평형 위치를 정할 때 이미 용수철 힘과 상쇄되었으므로 식에 남지 않습니다.)

\(my'' = -ky - cy'\)이므로 운동 방정식은

\[my'' + cy' + ky = 0.\]

2.3.2감쇠가 없을 때

\(c = 0\)이면 \(y'' + \omega_0^2y = 0\) (\(\omega_0 = \sqrt{k/m}\))이고, 특성근이 \(\pm i\omega_0\)이므로

\[y = A\cos\omega_0t + B\sin\omega_0t = C\cos(\omega_0t - \delta).\]

진폭 \(C = \sqrt{A^2 + B^2}\)로 영원히 진동하는 조화 진동입니다. 고유 진동수는 \(\frac{\omega_0}{2\pi}\) Hz, 주기는 \(2\pi\sqrt{m/k}\)입니다. 무거울수록 느리게, 용수철이 셀수록 빠르게 진동합니다.

2.3.3감쇠가 있을 때: 세 경우

특성방정식 \(m\lambda^2 + c\lambda + k = 0\)의 판별식 \(c^2 - 4mk\)에 따라 나뉩니다.

  • 과감쇠 (\(c^2 > 4mk\)): 서로 다른 두 음의 실근. \(y = c_1e^{\lambda_1t} + c_2e^{\lambda_2t}\). 진동하지 않고 천천히 평형으로 돌아온다(꿀 속의 용수철).
  • 임계감쇠 (\(c^2 = 4mk\)): 중근. \(y = (c_1 + c_2t)e^{-ct/2m}\). 진동하지 않으면서 가장 빨리 평형으로 돌아온다. 자동차 충격흡수기나 닫히는 문의 완충 장치가 이 상태를 목표로 설계된다.
  • 미감쇠 (\(c^2 < 4mk\)): 복소근. \(y = e^{-ct/2m}C\cos(\omega^*t - \delta)\), \(\omega^* = \sqrt{\frac km - \frac{c^2}{4m^2}}\). 진동하면서 진폭이 지수적으로 줄어든다.
예제 2.3.1

\(m = 10\) kg, \(k = 90\) N/m인 계에서 \(c = 100\), \(60\), \(10\) kg/s일 때 각각 어떤 운동인가?

풀이. \(4mk = 3600\). \(c = 100\): \(c^2 = 10000 > 3600\), 과감쇠. \(c = 60\): \(3600\), 임계감쇠. \(c = 10\): \(100 < 3600\), 미감쇠이고 \(\omega^* = \sqrt{9 - 0.25} \approx 2.958\)로 감쇠가 없을 때의 \(\omega_0 = 3\)보다 조금 느리게 진동합니다.

요약
  1. \(my'' + cy' + ky = 0\). 감쇠 없으면 \(\omega_0 = \sqrt{k/m}\)로 조화 진동.
  2. \(c^2 > 4mk\) 과감쇠, \(= 4mk\) 임계감쇠, \(< 4mk\) 미감쇠(줄어드는 진동).

2.3.4연습문제

기본

  1. 질량 2 kg, 용수철 상수 50 N/m인 계의 주기는?
    답

    \(\omega_0 = 5\), 주기 \(\frac{2\pi}{5} \approx 1.26\) s.

  2. \(m = 1\), \(k = 4\)인 계가 임계감쇠가 되는 \(c\)는?
    답

    \(c^2 = 16\), \(c = 4\).

응용

  1. \(y'' + 2y' + 5y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀고 어떤 운동인지 말하여라.
    답

    근 \(-1 \pm 2i\). \(y = e^{-t}(\cos2t + \frac12\sin2t)\). 미감쇠 진동.

2.3.2

설명감쇠 진동: 과감쇠, 임계감쇠, 미감쇠

mx″ + cx′ + kx = 0 · 판별식 c² − 4mk · 자동차 충격흡수기

다루는 성취기준 [공통8-02-03]

왜 필요한가

공통3의 용수철 진자는 영원히 진동했지만, 실제 진동은 마찰과 공기 저항으로 멈춥니다. 저항이 얼마나 센지에 따라 "흔들리며 멈추는지", "흔들리지 않고 멈추는지"가 갈립니다. 문이 쾅 닫히지 않게 하는 도어 클로저, 자동차가 과속방지턱을 넘은 뒤 출렁이지 않게 하는 충격흡수기의 설계가 이 구분에 달려 있습니다.

정의

속도에 비례하는 저항(\(-cx'\))이 있는 진동 \(mx'' + cx' + kx = 0\). 특성근 \(r = \frac{-c \pm\sqrt{c^2 - 4mk}}{2m}\).

과감쇠 \(c^2 > 4mk\), 임계감쇠 \(c^2 = 4mk\), 미감쇠 \(c^2 < 4mk\).

정의를 풀어 읽기

  1. 미감쇠복소근 \(-\frac{c}{2m} \pm i\omega_d\), \(\omega_d = \sqrt{\frac km - \frac{c^2}{4m^2}}\). 해 \(e^{-ct/2m}(A\cos\omega_dt + B\sin\omega_dt)\): 진폭이 지수적으로 줄며 진동. 진동수는 감쇠 없는 \(\omega_0 = \sqrt{k/m}\)보다 조금 작습니다.
  2. 임계감쇠중근 \(-\frac{c}{2m}\). 해 \((A + Bt)e^{-ct/2m}\): 진동 없이 가장 빨리 평형으로 돌아옴(평형을 많아야 한 번 지남).
  3. 과감쇠음의 실근 두 개. 해는 두 지수의 합으로 진동 없이 천천히 돌아옴. 저항이 너무 세서 오히려 느립니다(꿀 속의 용수철).
  4. 에너지\(\frac{d}{dt}\left(\frac12mx'^2 + \frac12kx^2\right) = -cx'^2 \le 0\). 저항이 에너지를 빼앗아 갑니다.

예와 반례

  • 예: \(m = 1\) kg, \(k = 100\) N/m이면 임계 감쇠 계수 \(c_c = 2\sqrt{mk} = 20\) N·s/m. \(c = 4\)이면 미감쇠, \(\omega_d = \sqrt{100 - 4} = 9.80\) rad/s (\(\omega_0 = 10\)), 진폭이 \(e^{-2t}\)로 줄어 약 0.35초마다 절반.
  • 예(설계): 자동차 충격흡수기는 임계보다 조금 약하게(감쇠비 약 0.2~0.4) 설계해 승차감과 빠른 안정을 맞춥니다. 측정 기기의 바늘은 임계 근처로 맞춰 빨리, 흔들림 없이 값을 보여 줍니다.
  • 반례(감쇠가 0): \(c = 0\)이면 공통3 6-01의 단순 조화 운동. 실제로는 아무리 작아도 \(c > 0\)이라 언젠가 멈춥니다.

다른 개념과의 관계

공통4 5-03의 LC 회로에 저항을 넣은 RLC 회로가 같은 방정식입니다(3-03 카드). 감쇠비 \(\zeta = \frac{c}{2\sqrt{mk}}\)로 쓰면 \(\zeta = 1\)이 임계입니다. 5단원에서 이 방정식을 연립 일계로 바꾸면, 미감쇠는 위상 평면의 안정 나선점, 과감쇠는 안정 마디가 됩니다.

흔한 오해

  • "감쇠가 셀수록 빨리 멈춘다." 임계감쇠까지만 그렇습니다. 그보다 세면(과감쇠) 다시 느려집니다.

2.3.3

실습감쇠의 세 경우 비교하기

실습 · 특성방정식의 근과 진동

다루는 성취기준 [공통8-02-02] [공통8-02-03]

목표

질량, 감쇠 계수, 용수철 상수를 바꿔 \(mx'' + cx' + kx = 0\)의 해를 그리고, 특성방정식의 근이 서로 다른 두 실근, 중근, 복소근일 때 각각 과감쇠, 임계감쇠, 미급감쇠가 됨을 확인합니다. 성취기준 [공통8-02-02], [공통8-02-03].

준비

위 그래프는 \(x(0) = 1\), \(x'(0) = 0\)에서 놓은 변위, 아래는 같은 운동을 \((x, x')\) 평면(상평면)에 그린 것입니다. 회색 점선은 미급감쇠일 때 진폭의 덮개 \(e^{-ct/2m}\)입니다. "임계감쇠로 맞추기" 단추는 \(c = 2\sqrt{mk}\)로 맞춥니다.

절차

  1. \(c = 0\)에서 진동 주기를 \(2\pi\sqrt{m/k}\)와 비교하고, 상평면 궤적이 닫힌 곡선인지 본다.
  2. \(c\)를 조금씩 올리며 근의 종류가 바뀌는 순간을 찾고, "임계감쇠로 맞추기"로 확인한다.
  3. 임계감쇠와 그보다 큰 \(c\)(과감쇠)에서 0 근처로 돌아오는 시간을 비교한다.
  4. \(m\)이나 \(k\)를 바꾸면 임계 감쇠 값이 어떻게 바뀌는지 본다.

기대 결과

  • \(c = 0\): 진폭이 줄지 않는 단순 조화 진동, 상평면은 타원.
  • 미급감쇠: 진동하며 덮개를 따라 줄어든다. 상평면은 안으로 감기는 나선.
  • 임계감쇠(\(m = 1, k = 2\)이면 \(c \approx 2.83\))는 진동 없이 가장 빨리 돌아오고, 과감쇠는 더 느리다.

분석

  1. 자동차 충격 흡수기나 문 닫힘 장치는 어느 경우에 가깝게 설계할까요? 그 이유는?
  2. 감쇠가 있으면 진동수가 \(\omega_0\)보다 작아집니다. 출력의 두 값을 비교하고, 근의 허수부와 연결해 보세요.

더 해 보기

공통4의 RLC 회로 카드에서 같은 세 경우가 \(R = 2\sqrt{L/C}\)를 경계로 나타납니다. \(m \leftrightarrow L\), \(c \leftrightarrow R\), \(k \leftrightarrow 1/C\)로 바꿔 보세요.
