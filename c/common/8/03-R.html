3.R.1

연습진동운동 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통8-03-01] [공통8-03-02] [공통8-03-03]

먼저 판별식으로 감쇠의 종류를 정하세요.

  1. 계산질량 2 kg, 용수철 상수 50 N/m인 계를 임계감쇠로 만들려면 감쇠 계수는? 그때 \(x(0) = 0.2\) m, \(x'(0) = 0\)인 해는? [03-01]

    힌트 1

    03-01 절: \(c = 2\sqrt{mk}\).

    힌트 2

    중근 \(-\frac{c}{2m}\).

    풀이

    \(c = 2\sqrt{100} = 20\) N·s/m. 중근 \(-5\). \(x = (A + Bt)e^{-5t}\), \(A = 0.2\), \(B - 5A = 0\) → \(B = 1\). \(x = (0.2 + t)e^{-5t}\).

  2. 개념미감쇠 진동의 진동수 \(\omega_d\)는 감쇠 없는 고유 진동수 \(\omega_0\)보다 큰가요, 작은가요? 직관적으로 설명하세요. [03-01]

    힌트 1

    \(\omega_d = \sqrt{\omega_0^2 - \left(\frac{c}{2m}\right)^2}\).

    힌트 2

    저항은 운동을 늦춥니다.

    풀이

    작습니다. 저항이 질량의 움직임을 늦춰 한 번 왕복하는 데 시간이 더 걸립니다. 감쇠가 작으면 차이는 미미합니다(\(\zeta = 0.1\)이면 0.5%).

  3. 계산\(x'' + 0.4x' + 4x = 2\cos\omega t\)에서 정상 상태 진폭을 \(\omega = 1, 2, 3\)일 때 구하세요. [03-02]

    힌트 1

    \(A = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2}}\), \(m = 1\), \(c = 0.4\), \(k = 4\).

    힌트 2

    \(\omega = 2\)가 고유 진동수.

    풀이

    \(\omega = 1\): \(\frac{2}{\sqrt{9 + 0.16}} = 0.66\). \(\omega = 2\): \(\frac{2}{\sqrt{0 + 0.64}} = 2.5\). \(\omega = 3\): \(\frac{2}{\sqrt{25 + 1.44}} = 0.39\). 고유 진동수에서 약 4~6배 커집니다.

  4. 판단한 학생이 "감쇠가 있는 계에 공명 진동수로 힘을 주면 진폭이 무한히 커진다"고 했습니다. 맞나요? [03-02]

    힌트 1

    \(\omega = \omega_0\)에서 \(A = \frac{F_0}{c\omega_0}\).

    힌트 2

    \(c > 0\)이면?

    풀이

    틀렸습니다. \(c > 0\)이면 진폭은 유한한 \(\frac{F_0}{c\omega_0}\)에 머뭅니다. 외력이 한 주기에 넣는 에너지와 감쇠가 빼앗는 에너지가 맞아떨어지는 진폭입니다. 무한히 커지는 것은 \(c = 0\)인 이상화된 경우뿐입니다.

  5. 계산직렬 RLC 회로 \(L = 1\) H, \(C = 0.25\) F에서 \(R\)이 얼마 이상이면 진동하지 않나요? 대응하는 역학계의 말로 설명하세요. [03-03]

    힌트 1

    \(R^2 \ge \frac{4L}{C}\).

    힌트 2

    \(\frac{4}{0.25} = 16\).

    풀이

    \(R \ge 4\ \Omega\). 역학: 질량 1 kg, 용수철 4 N/m에서 감쇠 계수 4 N·s/m 이상이면 과감쇠 또는 임계감쇠라 진동 없이 평형으로 돌아갑니다.

  6. 판단"강제 진동에서 오래 지나면 처음 위치와 속도가 다르면 진동도 다르다." 맞나요? [03-02]

    힌트 1

    일반해 = 과도 응답 + 정상 상태 응답.

    힌트 2

    초기조건은 어느 부분에 들어가나요?

    풀이

    틀렸습니다(감쇠가 있을 때). 초기조건은 동차해(과도 응답)의 상수만 정하고, 그 부분은 \(e^{-ct/2m}\)로 사라집니다. 오래 지나면 처음 상태와 상관없이 같은 정상 상태 응답만 남습니다. 계가 처음 상태를 "잊는다"는 것이 감쇠의 효과입니다.
