먼저 알아야 할 것
  • 상수계수 동차 방정식 (2.2절).

2.6.1일반해의 구조

\(y'' + py' + qy = r(x)\)의 해 두 개를 빼면 오른쪽이 \(r - r = 0\)이 되어 동차 방정식의 해가 됩니다. 따라서 비동차 방정식의 해를 하나(\(y_p\), 특수해)만 찾으면, 모든 해는 거기에 동차 방정식의 해를 더한 것입니다.

정리 2.6.1

비동차 방정식의 일반해는 \(y = y_h + y_p\)이다. \(y_h = c_1y_1 + c_2y_2\)는 동차 방정식의 일반해, \(y_p\)는 비동차 방정식의 특수해 하나이다.

1.4절의 1계 선형 방정식에서도 같은 구조를 보았습니다. 초기 조건은 \(y_h + y_p\)를 다 만든 뒤에 넣습니다.

2.6.2미정계수법

오른쪽 \(r(x)\)가 지수함수, 다항식, 사인·코사인(과 그 곱)이면, 이 함수들은 미분해도 같은 종류로 돌아오므로 \(y_p\)도 같은 꼴로 짐작할 수 있습니다. 계수만 모르는 채로 놓고 식에 넣어 계수를 정합니다.

\(r(x)\)에 있는 항\(y_p\)로 놓을 꼴
\(ke^{\gamma x}\)\(Ce^{\gamma x}\)
\(kx^n\)\(K_nx^n + \cdots + K_1x + K_0\)
\(k\cos\omega x\) 또는 \(k\sin\omega x\)\(K\cos\omega x + M\sin\omega x\)
\(ke^{\alpha x}\cos\omega x\) 등\(e^{\alpha x}(K\cos\omega x + M\sin\omega x)\)
  • 합 규칙: \(r\)이 여러 항의 합이면 각 항에 맞는 꼴을 더한다.
  • 수정 규칙: 놓은 꼴이 이미 동차 방정식의 해이면 \(x\)를 곱한다(중근 쪽이면 \(x^2\)). 동차 해를 넣으면 왼쪽이 0이 되어 계수를 정할 수 없기 때문이다.
예제 2.6.2

\(y'' + y = 0.001x^2\), \(y(0) = 0\), \(y'(0) = 1.5\)를 풀어라.

풀이. \(y_h = A\cos x + B\sin x\). \(y_p = K_2x^2 + K_1x + K_0\)으로 놓고 넣으면 \(2K_2 + K_2x^2 + K_1x + K_0 = 0.001x^2\). 계수 비교: \(K_2 = 0.001\), \(K_1 = 0\), \(K_0 = -0.002\). 일반해 \(y = A\cos x + B\sin x + 0.001x^2 - 0.002\). \(y(0) = A - 0.002 = 0\), \(y'(0) = B = 1.5\). 답 \(y = 0.002\cos x + 1.5\sin x + 0.001x^2 - 0.002\).

예제 2.6.3 (수정 규칙)

\(y'' + 3y' + 2.25y = -10e^{-1.5x}\)의 특수해를 구하여라.

풀이. 특성방정식 \((\lambda + 1.5)^2 = 0\), 중근 \(-1.5\)이므로 \(e^{-1.5x}\)와 \(xe^{-1.5x}\)가 모두 동차 해입니다. 수정 규칙으로 \(y_p = Cx^2e^{-1.5x}\)로 놓습니다. 넣어 정리하면 \(2Ce^{-1.5x} = -10e^{-1.5x}\), \(C = -5\). \(y_p = -5x^2e^{-1.5x}\).

요약
  1. 일반해 = 동차 일반해 + 특수해. 초기 조건은 마지막에.
  2. \(r\)과 같은 종류의 함수로 \(y_p\)를 놓고 계수를 맞춘다.
  3. 놓은 꼴이 동차 해와 겹치면 \(x\)(또는 \(x^2\))를 곱한다.

2.6.3연습문제

기본

  1. \(y'' - y = 3e^{2x}\)의 일반해는?
    답

    \(y_p = Ce^{2x}\), \(4C - C = 3\), \(C = 1\). \(y = c_1e^x + c_2e^{-x} + e^{2x}\).

  2. \(y'' + 4y = 8\cos x\)의 특수해는?
    답

    \(y_p = K\cos x + M\sin x\): \(3K = 8\), \(M = 0\). \(y_p = \frac83\cos x\).

응용

  1. \(y'' + 4y = \sin2x\)의 특수해는?
    답

    \(\sin2x\)가 동차 해이므로 \(y_p = x(K\cos2x + M\sin2x)\). 넣으면 \(-4K\sin2x + 4M\cos2x = \sin2x\), \(K = -\frac14\), \(M = 0\). \(y_p = -\frac x4\cos2x\).

2.6.2

예제미정계수법과 매개변수 변환법으로 특수해 구하기

추측표 · 공명 경우 · 일반 공식

다루는 성취기준 [공통8-02-06]

두 방법

  • 미정계수법 (상수계수, 오른쪽 \(g(x)\)가 다항식·지수·사인·코사인과 그 곱): \(g\)와 같은 모양으로 계수를 모르는 \(y_p\)를 추측하고 대입해 계수를 맞춘다. 추측이 동차해와 겹치면 \(x\)를 곱한다.
  • 매개변수 변환법 (어떤 \(g\)에도, 계수가 변해도): \(y_p = u_1y_1 + u_2y_2\)로 두고 \(u_1'y_1 + u_2'y_2 = 0\)을 덧붙이면 \[u_1' = -\frac{y_2g}{W}, \qquad u_2' = \frac{y_1g}{W}\] (방정식을 \(y'' + py' + qy = g\)로 정규화했을 때).
\(g(x)\)\(y_p\) 추측
\(n\)차 다항식\(n\)차 다항식 \(A_nx^n + \dots + A_0\)
\(e^{kx}\)\(Ae^{kx}\)
\(\cos\omega x\) 또는 \(\sin\omega x\)\(A\cos\omega x + B\sin\omega x\)
위의 곱추측의 곱

(가) \(y'' - y' - 6y = 3e^{2x}\) (나) \(y'' - y' - 6y = 5e^{3x}\) (다) \(y'' + y = \sec x\) (\(|x| < \frac\pi2\))

풀이

  1. (가) 동차해 \(e^{3x}, e^{-2x}\) (02-02 카드). \(e^{2x}\)는 겹치지 않으므로 \(y_p = Ae^{2x}\): \((4A - 2A - 6A)e^{2x} = 3e^{2x}\), \(A = -\frac34\).
    대입 후 계수 비교.
  2. (나) \(e^{3x}\)는 동차해와 겹친다(대입하면 0). \(y_p = Axe^{3x}\)로: \(y_p' = A(1 + 3x)e^{3x}\), \(y_p'' = A(6 + 9x)e^{3x}\).
    \(x\)를 곱하는 규칙.
  3. 대입: \(A[(6 + 9x) - (1 + 3x) - 6x]e^{3x} = 5Ae^{3x} = 5e^{3x}\), \(A = 1\). \(y_p = xe^{3x}\).
    \(x\)항은 상쇄되어야 하고 실제로 상쇄된다.
  4. (다) \(\sec x\)는 추측표에 없다. 매개변수 변환: \(y_1 = \cos x\), \(y_2 = \sin x\), \(W = 1\).
    미정계수법을 쓸 수 없는 경우.
  5. \(u_1' = -\sin x\sec x = -\tan x\), \(u_1 = \ln|\cos x|\). \(u_2' = \cos x\sec x = 1\), \(u_2 = x\). \(y_p = \cos x\ln|\cos x| + x\sin x\).
    적분 상수는 동차해에 흡수되므로 생략.

의미

(나)의 \(xe^{3x}\)는 외력의 "진동수"가 계의 고유한 성질(특성근)과 일치할 때 해가 \(x\)에 비례해 커진다는 뜻입니다. 3단원의 공명이 바로 이 현상입니다: 그네를 고유 진동수로 밀면 진폭이 계속 커집니다.

검산

(다) \(y_p' = -\sin x\ln\cos x - \sin x + \sin x + x\cos x = -\sin x\ln\cos x + x\cos x\), \(y_p'' = -\cos x\ln\cos x + \frac{\sin^2x}{\cos x} + \cos x - x\sin x\). \(y_p'' + y_p = \frac{\sin^2x}{\cos x} + \cos x = \frac{1}{\cos x} = \sec x\). 맞습니다.

흔한 오해

  • \(\cos\)만 추측: \(g = \cos\omega x\)여도 \(y_p\)에는 \(\sin\omega x\)가 필요합니다(\(y'\)항이 사인을 만들기 때문).
