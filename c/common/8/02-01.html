2.1.1왜 2계인가

뉴턴의 제2법칙 \(F = ma\)에서 가속도 \(a\)는 위치의 2계 도함수입니다. 그래서 힘을 받아 움직이는 물체, 용수철, 진자, 전기 회로의 방정식은 대부분 2계 미분방정식입니다. 그 가운데 가장 중요하고 완전히 풀 수 있는 것이 선형 방정식입니다.

정의 2.1.1 (2계 선형 미분방정식)

\(y'' + p(x)y' + q(x)y = r(x)\) 꼴의 식. \(r(x) = 0\)이면 동차, 아니면 비동차이다.

\(y\), \(y'\), \(y''\)이 모두 1차로만 들어 있어야 선형입니다. \(y'' + y^2 = 0\)이나 \(y'' + \sin y = 0\)(진자의 정확한 식)은 비선형입니다.

2.1.2중첩 원리

정리 2.1.2 (중첩 원리)

\(y_1\), \(y_2\)가 동차 방정식 \(y'' + py' + qy = 0\)의 해이면, 임의의 상수 \(c_1, c_2\)에 대해 \(c_1y_1 + c_2y_2\)도 해이다.

식에 넣으면 \(c_1(y_1'' + py_1' + qy_1) + c_2(y_2'' + py_2' + qy_2) = 0 + 0\)이기 때문입니다. 이 원리는 동차이고 선형일 때만 성립합니다. 비동차(오른쪽이 0이 아님)이거나 비선형이면 해를 더해도 해가 되지 않습니다.

예제 2.1.3

\(y'' + y = 0\)의 해 \(\cos x\)와 \(\sin x\)로 \(y(0) = 3\), \(y'(0) = -0.5\)인 해를 구하여라.

풀이. \(y = c_1\cos x + c_2\sin x\)로 놓으면 \(y(0) = c_1 = 3\), \(y'(0) = c_2 = -0.5\). 답 \(y = 3\cos x - 0.5\sin x\).

2.1.3일반해와 기저

2계 방정식의 초기값 문제에는 조건이 두 개(\(y(x_0)\)와 \(y'(x_0)\)) 필요합니다. 그래서 일반해에도 상수가 두 개 있어야 합니다. 다만 \(y_1\)과 \(y_2\)가 서로 비례하면(예: \(y_2 = 3y_1\)) \(c_1y_1 + c_2y_2 = (c_1 + 3c_2)y_1\)이 되어 상수가 사실상 하나뿐입니다.

정의 2.1.4 (기저와 일반해)

동차 방정식의 두 해 \(y_1, y_2\)가 서로 비례하지 않을 때(일차독립), 이 두 해를 기저라 하고 \(y = c_1y_1 + c_2y_2\)를 일반해라 한다.

예제 2.1.3의 \(\cos x\)와 \(\sin x\)는 비례하지 않으므로 기저이고, 모든 해가 \(c_1\cos x + c_2\sin x\) 꼴로 쓰입니다(2.5절에서 확인합니다).

2.1.4계수 낮추기

해 하나 \(y_1\)을 알면 \(y_2 = u\,y_1\)로 놓아 \(u\)에 대한 1계 방정식으로 바꿀 수 있습니다. 표준형 \(y'' + py' + qy = 0\)이면 결과는

\[y_2 = y_1\int U\,dx, \qquad U = \frac{1}{y_1^2}e^{-\int p\,dx}.\]
예제 2.1.5

\(x^2y'' - xy' + y = 0\) (\(x > 0\))의 한 해가 \(y_1 = x\)일 때 기저를 구하여라.

풀이. \(x^2\)으로 나누면 \(p = -\frac1x\), \(e^{-\int p\,dx} = e^{\ln x} = x\). \(U = \frac{x}{x^2} = \frac1x\), \(\int U\,dx = \ln x\). \(y_2 = x\ln x\). 기저 \(x\), \(x\ln x\).

요약
  1. 2계 선형: \(y'' + py' + qy = r\). \(r = 0\)이면 동차.
  2. 동차이면 해의 일차결합도 해(중첩 원리).
  3. 비례하지 않는 두 해 = 기저, 일반해 \(c_1y_1 + c_2y_2\). 조건 두 개로 상수를 정한다.
  4. 한 해를 알면 \(y_2 = y_1\int\frac{e^{-\int p}}{y_1^2}dx\).

2.1.5연습문제

기본

  1. \(e^x\)와 \(e^{-x}\)가 \(y'' - y = 0\)의 해임을 확인하고 \(y(0) = 2\), \(y'(0) = 0\)인 해를 구하여라.
    답

    \(c_1 + c_2 = 2\), \(c_1 - c_2 = 0\). \(y = e^x + e^{-x} = 2\cosh x\).

응용

  1. \(y'' - 2y' + y = 0\)의 한 해 \(e^x\)로부터 다른 해를 구하여라.
    답

    \(p = -2\), \(e^{2x}/e^{2x} = 1\), \(\int1\,dx = x\). \(y_2 = xe^x\).

2.1.2

예제두 해를 더해도 해가 될까?

예제 · 중첩 원리와 일반해

다루는 성취기준 [공통8-02-01]

\(y'' - y = 0\)의 해 \(e^x\), \(e^{-x}\)로 일반해를 만들고 \(y(0) = 2\), \(y'(0) = 0\)인 해를 구하세요. 또 \(y'' - y = 1\)과 \(y'' = y^2\)에서는 왜 같은 일이 안 되는지 말하세요.

전략

동차 선형 방정식에서는 해들의 일차결합도 해입니다(중첩 원리). 2계이므로 서로 독립인 해 두 개로 일반해를 만들고, 초기 조건 두 개로 상수 두 개를 정합니다.

풀이

  1. \(y = c_1e^x + c_2e^{-x}\)이면 \(y'' - y = c_1e^x + c_2e^{-x} - c_1e^x - c_2e^{-x} = 0\).
    미분이 선형이라 상수배와 합이 그대로 들어감.
  2. \(y(0) = c_1 + c_2 = 2\), \(y'(0) = c_1 - c_2 = 0\)에서 \(c_1 = c_2 = 1\).
    초기 조건.
  3. \(y = e^x + e^{-x} = 2\cosh x\).
    쌍곡선 코사인(공통1 2.6절).
  4. \(y'' - y = 1\)의 해 \(y = -1\)을 두 배 한 \(-2\)는 \(y'' - y = 2\)를 만족하므로 해가 아닙니다. \(y'' = y^2\)은 \(y^2\)이 비선형이라 \((y_1 + y_2)^2 \ne y_1^2 + y_2^2\)입니다.
    중첩은 동차이고 선형일 때만.

의미

중첩 원리 덕분에 2계 선형 동차 방정식은 "독립인 해 두 개"만 찾으면 모든 해를 압니다. 비동차 방정식은 동차 해에 특수해 하나를 더해 \(y = y_h + y_p\)로 씁니다(2.6절).

검산

\(y = 2\cosh x\): \(y'' = 2\cosh x = y\), \(y(0) = 2\), \(y'(0) = 2\sinh0 = 0\). 맞습니다.

바꿔 보기

\(e^x\)와 \(2e^x\)는 둘 다 해이지만 서로 상수배라 독립이 아닙니다. 이 둘로는 \(y(0) = 0\), \(y'(0) = 1\)인 해를 만들 수 없습니다. 독립인지는 론스키안으로 확인합니다(2.5절).

이해 확인

\(y'' + 4y = 0\)의 해 \(\cos2x\), \(\sin2x\)로 \(y(0) = 1\), \(y'(0) = 6\)인 해를 구하세요.

답

\(y = \cos2x + 3\sin2x\).
