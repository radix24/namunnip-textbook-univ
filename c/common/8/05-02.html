먼저 알아야 할 것

5.2.1미분이 곱셈으로

정리 5.2.1 \[\mathcal L\{f'\} = sF(s) - f(0), \qquad \mathcal L\{f''\} = s^2F(s) - sf(0) - f'(0).\]

부분적분으로 얻습니다: \(\int_0^\infty e^{-st}f'\,dt = [e^{-st}f]_0^\infty + s\int_0^\infty e^{-st}f\,dt = -f(0) + sF\). 미분이 "\(s\)를 곱하기"로 바뀌고, 초기값이 식 안에 자동으로 들어온다는 것이 핵심입니다. 그래서 일반해를 구한 뒤 상수를 맞추는 단계가 필요 없습니다.

5.2.2세 단계로 풀기

  1. 변환: 방정식 양변을 변환해 \(Y(s)\)에 대한 대수방정식(보조방정식)을 만든다.
  2. 풀기: \(Y(s)\)에 대해 푼다. 보통 부분분수로 나눈다.
  3. 역변환: \(y = \mathcal L^{-1}\{Y\}\).
예제 5.2.2

\(y'' - y = t\), \(y(0) = 1\), \(y'(0) = 1\)을 풀어라.

풀이. 변환: \(s^2Y - s - 1 - Y = \frac{1}{s^2}\). 풀기: \((s^2 - 1)Y = s + 1 + \frac{1}{s^2}\), 따라서

\[Y = \frac{s + 1}{s^2 - 1} + \frac{1}{s^2(s^2 - 1)} = \frac{1}{s - 1} + \left(\frac{1}{s^2 - 1} - \frac{1}{s^2}\right).\]

역변환: \(y = e^t + \sinh t - t\).

검산: \(y'' = e^t + \sinh t\), \(y'' - y = t\) ✓. \(y(0) = 1\), \(y'(0) = 1 + 1 - 1 = 1\) ✓.

예제 5.2.3

감쇠 진동 \(y'' + y' + 9y = 0\), \(y(0) = 0.16\), \(y'(0) = 0\)을 풀어라.

풀이. \(s^2Y - 0.16s + sY - 0.16 + 9Y = 0\), \(Y = \dfrac{0.16(s + 1)}{s^2 + s + 9} = \dfrac{0.16(s + \frac12) + 0.08}{(s + \frac12)^2 + \frac{35}{4}}\). s-이동으로

\[y = e^{-t/2}\left(0.16\cos\tfrac{\sqrt{35}}{2}t + \tfrac{0.16}{\sqrt{35}}\sin\tfrac{\sqrt{35}}{2}t\right).\]
요약
  1. \(\mathcal L\{y'\} = sY - y(0)\), \(\mathcal L\{y''\} = s^2Y - sy(0) - y'(0)\).
  2. 변환 → \(Y\)에 대해 풀기(부분분수) → 역변환. 초기값이 처음부터 들어간다.

5.2.3연습문제

기본

  1. \(y' + 2y = 0\), \(y(0) = 3\)을 라플라스 변환으로 풀어라.
    답

    \(sY - 3 + 2Y = 0\), \(Y = \frac{3}{s + 2}\), \(y = 3e^{-2t}\).

  2. \(y'' + y = 0\), \(y(0) = 0\), \(y'(0) = 1\)을 풀어라.
    답

    \(Y = \frac{1}{s^2 + 1}\), \(y = \sin t\).

응용

  1. \(y'' + 3y' + 2y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.
    답

    \(Y = \frac{s + 3}{(s + 1)(s + 2)} = \frac{2}{s + 1} - \frac{1}{s + 2}\). \(y = 2e^{-t} - e^{-2t}\).

5.2.2

예제초기값 문제를 Laplace 변환으로 풀기

L{y′} = sY − y(0) · 대수방정식으로 · 부분분수

다루는 성취기준 [공통8-05-02]

도구와 근거

\(\mathcal L\{y'\} = \int_0^\infty e^{-st}y'\,dt = \left[e^{-st}y\right]_0^\infty + s\int_0^\infty e^{-st}y\,dt = sY(s) - y(0)\) (부분적분). 한 번 더: \(\mathcal L\{y''\} = s^2Y - sy(0) - y'(0)\). 미분이 \(s\)를 곱하는 것으로 바뀌고, 초기조건이 처음부터 식에 들어갑니다. 일반해를 구한 뒤 상수를 맞출 필요가 없습니다.

\(f(t)\)\(F(s)\)\(f(t)\)\(F(s)\)
1\(\frac1s\)\(e^{at}\)\(\frac{1}{s - a}\)
\(t^n\)\(\frac{n!}{s^{n+1}}\)\(e^{at}f(t)\)\(F(s - a)\)
\(\cos\omega t\)\(\frac{s}{s^2 + \omega^2}\)\(\sin\omega t\)\(\frac{\omega}{s^2 + \omega^2}\)

\(y'' + 3y' + 2y = e^{-3t}\), \(y(0) = 1\), \(y'(0) = 0\)을 Laplace 변환으로 푸세요.

풀이

  1. 변환: \([s^2Y - s] + 3[sY - 1] + 2Y = \frac{1}{s + 3}\).
    초기조건 \(y(0) = 1\), \(y'(0) = 0\)을 넣었다.
  2. \((s^2 + 3s + 2)Y = s + 3 + \frac{1}{s + 3}\), \(Y = \frac{s + 3}{(s + 1)(s + 2)} + \frac{1}{(s + 1)(s + 2)(s + 3)}\).
    \(Y\)에 대해 대수적으로 풂.
  3. 부분분수: \(\frac{s + 3}{(s+1)(s+2)} = \frac{2}{s + 1} - \frac{1}{s + 2}\). \(\frac{1}{(s+1)(s+2)(s+3)} = \frac{1/2}{s + 1} - \frac{1}{s + 2} + \frac{1/2}{s + 3}\).
    근을 대입하는 방법(공통1 6-03).
  4. \(Y = \frac{5/2}{s + 1} - \frac{2}{s + 2} + \frac{1/2}{s + 3}\). 역변환: \(y = \frac52e^{-t} - 2e^{-2t} + \frac12e^{-3t}\).
    표의 \(e^{at}\).

의미

\(Y\)의 분모 \((s+1)(s+2)\)는 계의 특성방정식(2단원)에서, \((s+3)\)은 입력 \(e^{-3t}\)에서 왔습니다. "계의 성질"과 "입력의 성질"이 곱셈으로 분리되는 것이 Laplace 변환의 힘이고, 공학의 전달함수 \(H(s) = \frac{1}{s^2 + 3s + 2}\)가 이 생각입니다.

검산

\(y(0) = \frac52 - 2 + \frac12 = 1\). \(y'(0) = -\frac52 + 4 - \frac32 = 0\). 방정식: \(e^{-3t}\) 계수만 보면 \(\frac12(9 - 9 + 2) = 1\), \(e^{-t}\)와 \(e^{-2t}\) 항은 동차해라 0. 맞습니다.
