6.1.1복잡한 주기 신호를 단순한 파동으로

악기의 소리, 심장 박동, 교류 전압처럼 주기적으로 되풀이되는 신호는 모양이 복잡해도 진동수가 기본 진동수의 정수배인 사인파와 코사인파의 합으로 나타낼 수 있습니다. 테일러 급수가 함수를 \(x^n\)의 합으로 나타냈다면, 푸리에 급수는 \(\cos nx\), \(\sin nx\)의 합으로 나타냅니다.

정의 6.1.1 (푸리에 급수)

주기 \(2\pi\)인 함수 \(f\)의 푸리에 급수는

\[f(x) = a_0 + \sum_{n=1}^\infty(a_n\cos nx + b_n\sin nx),\] \[a_0 = \frac{1}{2\pi}\int_{-\pi}^\pi f\,dx, \qquad a_n = \frac1\pi\int_{-\pi}^\pi f\cos nx\,dx, \qquad b_n = \frac1\pi\int_{-\pi}^\pi f\sin nx\,dx.\]

6.1.2계수 공식은 어디서 오는가: 직교성

\(m \ne n\)이면 \(\int_{-\pi}^\pi\cos mx\cos nx\,dx = 0\), \(\int_{-\pi}^\pi\sin mx\sin nx\,dx = 0\)이고, 언제나 \(\int_{-\pi}^\pi\cos mx\sin nx\,dx = 0\)입니다(곱을 합으로 바꾸는 공식으로 확인). 서로 다른 삼각함수의 곱을 한 주기 동안 적분하면 0이 된다는 이 성질을 직교성이라 합니다. 벡터의 내적이 0이면 수직인 것처럼, 적분을 "함수의 내적"으로 보면 이 함수들은 서로 수직입니다.

그래서 급수 양변에 \(\cos mx\)를 곱해 적분하면 다른 항은 모두 0이 되고 \(a_m\)의 항만 남아 \(\int f\cos mx\,dx = a_m\pi\)가 됩니다. 이것이 계수 공식입니다. 벡터의 성분을 내적으로 구하는 것(공통1 9.3절의 정사영)과 같은 원리입니다.

예제 6.1.2 (사각파)

\(f(x) = -1\) (\(-\pi < x < 0\)), \(1\) (\(0 < x < \pi\))이고 주기 \(2\pi\)인 함수의 푸리에 급수를 구하여라.

풀이. \(f\)는 기함수이므로 \(a_0 = a_n = 0\) (기함수 × 우함수의 대칭 구간 적분은 0). \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2}{n\pi}(1 - \cos n\pi)\)는 \(n\)이 짝수이면 0, 홀수이면 \(\frac{4}{n\pi}\). 따라서

\[f(x) = \frac4\pi\left(\sin x + \frac13\sin3x + \frac15\sin5x + \cdots\right).\]

\(x = \frac\pi2\)를 넣으면 \(1 = \frac4\pi\left(1 - \frac13 + \frac15 - \cdots\right)\), 곧 공통1 8.7절의 라이프니츠 급수 \(\frac\pi4 = 1 - \frac13 + \frac15 - \cdots\)가 나옵니다.

6.1.3수렴

정리 6.1.3

\(f\)가 한 주기에서 구간별로 연속이고 구간별로 매끄러우면, 푸리에 급수는 \(f\)가 연속인 점에서 \(f(x)\)로 수렴하고, 뛰어오르는 점에서는 왼쪽 극한과 오른쪽 극한의 평균으로 수렴한다.

사각파의 \(x = 0\)에서 급수는 \(\frac{-1 + 1}{2} = 0\)입니다(실제로 모든 항이 0). 항을 많이 더해도 뛰어오르는 점 근처에서 약 9% 튀어나오는 봉우리가 남는데, 이것을 기브스 현상이라 합니다. 이 절의 탐구 카드에서 직접 볼 수 있습니다.

요약
  1. \(f = a_0 + \sum(a_n\cos nx + b_n\sin nx)\). 계수는 직교성에서 나온다.
  2. 기함수는 사인항만, 우함수는 코사인항(과 상수)만 남는다.
  3. 불연속점에서는 양쪽 극한의 평균으로 수렴한다.

6.1.4연습문제

기본

  1. \(f(x) = x\) (\(-\pi < x < \pi\)), 주기 \(2\pi\)의 푸리에 급수를 구하여라.
    답

    기함수. \(b_n = \frac{2(-1)^{n+1}}{n}\). \(f = 2\left(\sin x - \frac{\sin2x}{2} + \frac{\sin3x}{3} - \cdots\right)\).

응용

  1. \(f(x) = |x|\) (\(-\pi < x < \pi\))의 푸리에 급수를 구하여라.
    답

    우함수. \(a_0 = \frac\pi2\), \(a_n = \frac{2}{\pi n^2}((-1)^n - 1)\). \(f = \frac\pi2 - \frac4\pi\left(\cos x + \frac{\cos3x}{9} + \cdots\right)\).

이 절의 성취기준[공통8-06-01] 계산

  1. 주기 2π인 함수의 푸리에 급수를 구할 수 있다.

6.1.2

예제주기 함수의 Fourier 계수 구하기

직교성 · aₙ, bₙ 공식 · 사각파 · 문제 해결 전략

다루는 성취기준 [공통8-06-01]

식의 출처

주기 \(2L\)인 함수를 \(f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right)\)로 쓰려 합니다. 핵심은 직교성: \(\int_{-L}^L\cos\frac{m\pi x}{L}\cos\frac{n\pi x}{L}dx = 0\) (\(m \ne n\)), \(\sin\)끼리도 마찬가지, \(\sin\)과 \(\cos\)은 언제나 0. 양변에 \(\cos\frac{n\pi x}{L}\)을 곱해 적분하면 다른 항이 모두 사라져

\[a_n = \frac1L\int_{-L}^Lf(x)\cos\frac{n\pi x}{L}dx, \qquad b_n = \frac1L\int_{-L}^Lf(x)\sin\frac{n\pi x}{L}dx.\]

공통2 1-01의 정사영 \(\frac{\mathbf a\cdot\mathbf b}{\mathbf a\cdot\mathbf a}\)과 같은 구조입니다: 함수를 "직교 기저 함수" 방향으로 정사영한 성분이 계수입니다.

문제 해결 전략 · Fourier 급수
  1. 주기 \(2L\)과 한 주기에서의 식을 적는다. 그래프를 그린다.
  2. 기함수면 \(a_n = 0\) (사인 급수), 우함수면 \(b_n = 0\) (코사인 급수). 계산이 반으로 준다(공통1 5-04).
  3. 계수 적분은 부분적분, \(\cos n\pi = (-1)^n\), \(\sin n\pi = 0\)을 쓴다.
  4. 불연속점에서 급수는 좌우 극한의 평균으로 수렴함을 기억한다(공통8-06-01 카드).
  5. 몇 항의 부분합을 그려 원래 함수와 비교한다.

주기 \(2\pi\)인 사각파 \(f(x) = -1\) (\(-\pi < x < 0\)), \(1\) (\(0 < x < \pi\))의 Fourier 급수를 구하세요.

풀이

  1. \(f\)는 기함수이므로 \(a_n = 0\) (\(a_0\) 포함).
    기함수 × 우함수(\(\cos\)) = 기함수, 대칭 구간 적분 0.
  2. \(b_n = \frac1\pi\int_{-\pi}^\pi f\sin nx\,dx = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2}{n\pi}(1 - \cos n\pi) = \frac{2}{n\pi}(1 - (-1)^n)\).
    기함수 × 기함수 = 우함수라 2배.
  3. \(n\) 짝수: \(b_n = 0\). 홀수: \(b_n = \frac{4}{n\pi}\).
    \(1 - (-1)^n\)이 0 또는 2.
  4. \(f(x) = \frac4\pi\left(\sin x + \frac{\sin3x}{3} + \frac{\sin5x}{5} + \cdots\right)\).
    홀수 배음만.

의미

사각파는 기본 진동수의 홀수 배음을 \(\frac1n\) 세기로 섞은 것입니다. 클라리넷 소리가 홀수 배음이 강한 것(공통3 6-03의 닫힌 관), 디지털 신호(0과 1의 사각파)를 보내려면 넓은 주파수 대역이 필요한 이유가 이것입니다. 계수가 \(\frac1n\)로 천천히 줄어드는 것은 함수가 불연속이기 때문입니다(매끄러울수록 계수가 빨리 줄어듦).

검산

\(x = \frac\pi2\)를 넣으면 \(1 = \frac4\pi\left(1 - \frac13 + \frac15 - \cdots\right)\), 곧 \(1 - \frac13 + \frac15 - \cdots = \frac\pi4\). 공통1 8-05의 \(\arctan1\) 급수(라이프니츠 급수)와 일치합니다.

6.1.3

탐구Fourier 급수의 수렴 정리와 Gibbs 현상

불연속점에서 평균값으로 · 9% 넘침은 사라지지 않는다

다루는 성취기준 [공통8-06-01]

질문

공통8-06-01 카드의 사각파 급수에서 항을 많이 더하면 부분합이 사각파에 점점 가까워질 것 같습니다. 그런데 불연속점 바로 옆의 "튀어나온 봉우리"는 항을 늘려도 줄어들까요?

수렴 정리 (Dirichlet)

\(f\)가 주기 \(2L\)이고 한 주기에서 조각마다 매끄러우면(유한 개의 점프만 있음), Fourier 급수는 \(f\)가 연속인 점에서 \(f(x)\)로, 점프가 있는 점에서는 좌우 극한의 평균 \(\frac{f(x^-) + f(x^+)}{2}\)으로 수렴한다.

해 보기와 설명

  1. 평균값\(x = 0\)에서 부분합은 항의 수와 상관없이 늘 0입니다(모든 \(\sin nx\)가 0). 0은 \(-1\)과 \(1\)의 평균입니다.
  2. Gibbs 현상막대를 끝까지 올리면 봉우리는 점점 좁아지고 불연속점으로 다가가지만 높이는 약 1.179에서 줄지 않습니다. 점프 크기 2의 약 8.95%만큼 넘칩니다. 정확한 극한은 \(\frac2\pi\int_0^\pi\frac{\sin t}{t}dt \approx 1.17898\).
  3. 모순이 아닌 이유각 점 \(x\)를 고정하면 부분합은 \(f(x)\)로 갑니다(점별 수렴). 봉우리는 \(N\)이 커질수록 불연속점 쪽으로 움직여 어느 고정된 점에도 머물지 않습니다. 다만 "최대 오차가 0으로 간다"(균등 수렴)는 성립하지 않습니다.

연결과 적용

디지털 신호 처리에서 날카로운 경계를 유한한 주파수로 자르면 경계 옆에 물결(링잉)이 생깁니다. JPEG 압축된 사진의 글자 둘레 얼룩, MRI 영상의 경계 줄무늬가 같은 현상입니다. 계수에 서서히 줄어드는 가중치를 곱하는 방법(페예르 평균, 창 함수)으로 넘침을 줄입니다.

흔한 오해

  • "항을 충분히 많이 쓰면 그래프가 정확히 같아진다." 불연속인 함수를 연속 함수(삼각함수)의 유한합으로 근사하면 불연속점 근처의 넘침은 남습니다.
