1.4.1선형 미분방정식

\(y\)와 \(y'\)이 1차로만(곱하거나 제곱하지 않고) 들어 있는 식을 선형이라 합니다. 1계 선형 방정식의 표준형은

\[y' + p(x)\,y = r(x).\]

\(r(x) = 0\)이면 동차, 아니면 비동차라 합니다. 동차이면 변수분리로 \(y = ce^{-\int p\,dx}\)를 얻습니다. 비동차일 때의 요령은, 양변에 \(F = e^{\int p\,dx}\)를 곱하면 왼쪽이 곱의 도함수로 묶인다는 것입니다.

\[Fy' + Fp\,y = (Fy)' \quad (F' = Fp\text{이기 때문}).\]
정리 1.4.1 (1계 선형 방정식의 해)

\(h = \int p(x)\,dx\)라 하면 \(y' + py = r\)의 일반해는

\[y = e^{-h}\left(\int e^{h}r\,dx + c\right).\]

공식을 외우기보다 "\(e^{\int p\,dx}\)를 곱하면 왼쪽이 \((e^{h}y)'\)이 된다"는 과정을 기억하는 편이 낫습니다.

예제 1.4.2

\(y' - y = e^{2x}\), \(y(0) = 3\)을 풀어라.

풀이. \(p = -1\), \(h = -x\), \(F = e^{-x}\). 곱하면 \((e^{-x}y)' = e^{x}\). 적분하면 \(e^{-x}y = e^x + c\), 곧 \(y = e^{2x} + ce^x\). \(y(0) = 1 + c = 3\)에서 \(c = 2\). 답 \(y = e^{2x} + 2e^x\).

일반해가 "비동차의 특수해 \(e^{2x}\)" + "동차의 일반해 \(ce^x\)"로 나뉜다는 점을 눈여겨보세요. 이 구조는 2단원의 2계 선형 방정식에서도 똑같습니다.

예제 1.4.3 (RC 회로)

저항 \(R\), 축전기 \(C\), 전압 \(E\)인 직류 전원을 \(t = 0\)에 연결했다. 축전기의 전하 \(q(t)\)를 구하여라(\(q(0) = 0\)).

풀이. 키르히호프 법칙에서 \(Rq' + \frac qC = E\), 곧 \(q' + \frac{1}{RC}q = \frac ER\). \(F = e^{t/RC}\)를 곱해 적분하면 \(q = CE + ce^{-t/RC}\), \(q(0) = 0\)에서 \(q = CE(1 - e^{-t/RC})\). 시간 상수 \(RC\)마다 남은 차이가 \(e^{-1} \approx 37\%\)로 줄어듭니다(공통4 5.3절).

1.4.2베르누이 방정식

\(y' + p(x)y = g(x)y^a\) (\(a \ne 0, 1\))은 \(y^a\) 때문에 선형이 아니지만, \(u = y^{1-a}\)로 치환하면 선형이 됩니다. \(u' = (1 - a)y^{-a}y'\)이므로 원래 식에 \((1 - a)y^{-a}\)를 곱하면

\[u' + (1 - a)p\,u = (1 - a)g.\]

1.4.3개체군 모델: 로지스틱 방정식

\(y' = ky\)는 개체 수가 끝없이 늘어난다고 예측하지만, 실제로는 먹이와 공간이 한정되어 있어 어느 수준에서 멈춥니다. 늘어나는 빠르기가 개체 수와 "남은 여유"에 함께 비례한다고 놓은 것이 로지스틱 방정식입니다.

\[y' = Ay - By^2 = Ay\left(1 - \frac{y}{K}\right), \qquad K = \frac AB.\]

\(a = 2\)인 베르누이 방정식이므로 \(u = \frac1y\)로 치환하면 \(u' + Au = B\), \(u = \frac BA + ce^{-At}\), 따라서

\[y = \frac{K}{1 + Ce^{-At}}.\]

처음에는 지수적으로 늘다가 \(K\)(환경 수용력)에 가까워지면 느려지며 \(K\)에 다가갑니다. 1.1절의 방향장(\(y' = y(1 - y)\))에서 본 S자 곡선이 바로 이것입니다.

주의적분인자를 구하기 전에 반드시 \(y'\)의 계수를 1로 만드세요. \(xy' + 2y = x^2\)이면 먼저 \(x\)로 나누어 \(y' + \frac2xy = x\)로 쓴 뒤 \(p = \frac2x\)를 씁니다.
요약
  1. \(y' + py = r\): \(e^{\int p\,dx}\)를 곱하면 왼쪽이 \((e^{\int p}y)'\).
  2. 일반해 = 비동차 특수해 + 동차 일반해.
  3. 베르누이: \(u = y^{1-a}\)로 선형화. 로지스틱 해 \(y = \frac{K}{1 + Ce^{-At}}\).

1.4.4연습문제

기본

  1. \(y' + 2y = 4\)를 풀어라.
    답

    \((e^{2x}y)' = 4e^{2x}\), \(y = 2 + ce^{-2x}\).

  2. \(xy' + 2y = x^2\) (\(x > 0\))을 풀어라.
    답

    \(y' + \frac2xy = x\), \(F = x^2\). \((x^2y)' = x^3\), \(y = \frac{x^2}{4} + \frac{c}{x^2}\).

응용

  1. \(y' = 0.5y(1 - y/1000)\), \(y(0) = 100\)일 때 \(y\)가 500이 되는 시간은?
    답

    \(y = \frac{1000}{1 + 9e^{-0.5t}}\). \(500\)이면 \(9e^{-0.5t} = 1\), \(t = 2\ln9 \approx 4.39\).

1.4.2

예제1계 선형 방정식과 베르누이 방정식은 어떻게 풀까?

예제 · 적분인자와 치환

다루는 성취기준 [공통8-01-04]

(가) \(y' + \dfrac yx = x^2\) (\(x > 0\))의 일반해를 구하세요. (나) \(y' - y = -y^2\), \(y(0) = \tfrac12\)을 푸세요.

전략

(가)는 \(y' + p(x)y = r(x)\) 꼴의 선형 방정식입니다. 양변에 적분인자 \(F = e^{\int p\,dx}\)를 곱하면 왼쪽이 \((Fy)'\) 하나로 묶입니다. (나)는 \(y^2\) 때문에 선형이 아니지만 \(y' + py = gy^a\) 꼴(베르누이 방정식)이라 \(u = y^{1-a}\)로 바꾸면 선형이 됩니다.

풀이

  1. (가) \(F = e^{\int dx/x} = x\). 양변에 곱하면 \(xy' + y = x^3\), 곧 \((xy)' = x^3\).
    곱의 미분을 거꾸로 읽음.
  2. \(xy = \dfrac{x^4}4 + C\), \(y = \dfrac{x^3}4 + \dfrac Cx\).
    양변 적분.
  3. (나) \(a = 2\)이므로 \(u = y^{-1}\). \(u' = -y'/y^2 = -(y - y^2)/y^2 = -u + 1\), 곧 \(u' + u = 1\).
    베르누이 치환으로 선형 방정식이 됨.
  4. \(u = 1 + Ce^{-x}\), \(y = \dfrac1{1 + Ce^{-x}}\). \(y(0) = \tfrac12\)에서 \(C = 1\): \(y = \dfrac1{1 + e^{-x}}\).
    선형 방정식의 해와 초기 조건.

의미

(나)는 \(K = 1\), \(r = 1\)인 로지스틱 방정식(공통1 10.2절)이고, 답은 S자 곡선입니다. 변수분리로도 풀 수 있지만 베르누이 치환은 \(y' + py = gy^a\) 꼴이면 \(p\)와 \(g\)가 \(x\)의 함수여도 쓸 수 있습니다.

검산

(가) \(y = x^3/4 + C/x\)이면 \(y' = 3x^2/4 - C/x^2\), \(y' + y/x = 3x^2/4 - C/x^2 + x^2/4 + C/x^2 = x^2\). (나) \(y = 1/(1 + e^{-x})\)에서 \(y' = e^{-x}/(1 + e^{-x})^2 = y(1 - y)\). 맞습니다.

바꿔 보기

\(y' + 2y = e^{-2x}\)처럼 오른쪽이 적분인자와 같은 모양이면 \((e^{2x}y)' = 1\)이 되어 \(y = (x + C)e^{-2x}\)로, 지수함수에 \(x\)가 곱해집니다(공명과 같은 현상).

이해 확인

\(y' - \dfrac{2y}x = x^2\) (\(x > 0\))의 일반해를 구하세요.

답

\(F = x^{-2}\), \((y/x^2)' = 1\), \(y = x^3 + Cx^2\).
