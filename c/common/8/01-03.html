이 절에서 배울 것
  • \(M\,dx + N\,dy = 0\)이 어떤 함수 \(u(x, y)\)의 전미분일 때(완전형) 해를 \(u = c\)로 구한다.
  • 완전형이 아닌 식에 적분인자를 곱해 완전형으로 만든다.
먼저 알아야 할 것
  • 편도함수 \(\frac{\partial u}{\partial x}\), \(\frac{\partial u}{\partial y}\) (공통2 4.2절).
  • 변수분리법 (1.2절).

1.3.1등고선이 해가 되는 경우

함수 \(u(x, y) = c\)의 등고선 위에서는 \(u\)가 변하지 않으므로 전미분이 0입니다: \(du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy = 0\). 거꾸로, 미분방정식 \(M(x, y)\,dx + N(x, y)\,dy = 0\)이 마침 어떤 \(u\)에 대해 \(M = u_x\), \(N = u_y\)이면, 해는 \(u(x, y) = c\)입니다. 이런 식을 완전 미분방정식이라 합니다.

완전형인지는 \(u\)를 찾기 전에 판정할 수 있습니다. \(u_{xy} = u_{yx}\)(편미분의 순서는 바꿔도 같다, 공통2 4.2절)이므로

정리 1.3.1 (완전형 판정)

\(M\,dx + N\,dy = 0\)이 완전형일 필요충분조건은 \(\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}\)이다(\(M, N\)과 편도함수가 연속인 영역에서).

1.3.2푸는 방법

  1. \(M_y = N_x\)인지 확인한다.
  2. \(u = \int M\,dx + k(y)\)로 놓는다. \(x\)로 적분할 때 \(y\)는 상수 취급이므로 적분 상수가 \(y\)의 함수 \(k(y)\)가 된다.
  3. \(u_y = N\)에서 \(k'(y)\)를 구하고 적분해 \(k(y)\)를 정한다.
  4. 해는 \(u(x, y) = c\).
예제 1.3.2

\((2xy + 3)\,dx + (x^2 - 1)\,dy = 0\)을 풀어라.

풀이. \(M_y = 2x\), \(N_x = 2x\)이므로 완전형입니다. \(u = \int(2xy + 3)\,dx = x^2y + 3x + k(y)\). \(u_y = x^2 + k'(y) = x^2 - 1\)에서 \(k'(y) = -1\), \(k = -y\). 해 \(x^2y + 3x - y = c\).

검산: 해를 음함수 미분하면 \(2xy\,dx + x^2dy + 3dx - dy = 0\)으로 원래 식이 나옵니다.

1.3.3적분인자

완전형이 아닌 식도 알맞은 함수 \(F\)를 곱하면 완전형이 될 때가 있습니다. 이 \(F\)를 적분인자라 합니다. 일반적으로 찾기는 어렵지만, \(F\)가 \(x\)만의 함수이거나 \(y\)만의 함수인 경우에는 공식이 있습니다.

정리 1.3.3

\(R = \dfrac{1}{N}\left(\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}\right)\)이 \(x\)만의 함수이면 \(F(x) = e^{\int R\,dx}\)가 적분인자이다. \(R^* = \dfrac{1}{M}\left(\dfrac{\partial N}{\partial x} - \dfrac{\partial M}{\partial y}\right)\)이 \(y\)만의 함수이면 \(F(y) = e^{\int R^*dy}\)가 적분인자이다.

예제 1.3.4

\((y + x^2)\,dx - x\,dy = 0\)을 풀어라.

풀이. \(M_y = 1\), \(N_x = -1\)이라 완전형이 아닙니다. \(R = \frac{1}{-x}(1 - (-1)) = -\frac2x\)은 \(x\)만의 함수이므로 \(F = e^{\int(-2/x)dx} = x^{-2}\). 곱하면 \(\left(\frac{y}{x^2} + 1\right)dx - \frac1x dy = 0\)이고, 이제 \(M_y = \frac{1}{x^2} = N_x\)입니다. \(u = \int\left(-\frac1x\right)dy = -\frac yx + k(x)\), \(u_x = \frac{y}{x^2} + k'(x) = \frac{y}{x^2} + 1\)에서 \(k = x\). 해 \(x - \frac yx = c\), 곧 \(y = x^2 - cx\).

요약
  1. \(M_y = N_x\)이면 완전형, 해는 \(u = c\) (\(u_x = M\), \(u_y = N\)).
  2. \(u = \int M\,dx + k(y)\)로 놓고 \(u_y = N\)으로 \(k\)를 정한다.
  3. 완전형이 아니면 \(x\)만 또는 \(y\)만의 적분인자를 찾아 곱한다.

1.3.4연습문제

기본

  1. \((3x^2 + y)\,dx + (x + 2y)\,dy = 0\)을 풀어라.
    답

    완전형. \(u = x^3 + xy + y^2\). 해 \(x^3 + xy + y^2 = c\).

응용

  1. \(y\,dx + 2x\,dy = 0\)은 완전형인가? 적분인자를 찾아 풀어라.
    답

    \(M_y = 1 \ne N_x = 2\). \(R^* = \frac1y(2 - 1) = \frac1y\), \(F = y\). \(y^2dx + 2xy\,dy = 0\)은 완전형, \(u = xy^2\). 해 \(xy^2 = c\). (변수분리로도 풀린다.)

1.3.2

예제적분인자로 비완전 방정식을 완전하게 만들기

μ(x) · μ(y) · 판정식 유도

다루는 성취기준 [공통8-01-03]

언제 \(\mu(x)\)를 찾을 수 있나 (유도)

  1. \(M\,dx + N\,dy = 0\)이 완전하지 않을 때(\(M_y \ne N_x\)), 양변에 \(\mu(x)\)를 곱해 완전하게 만들고 싶다: \((\mu M)_y = (\mu N)_x\).
    해는 같고 꼴만 바뀐다(\(\mu \ne 0\)인 곳에서).
  2. \(\mu\)가 \(x\)만의 함수이면 \(\mu M_y = \mu'N + \mu N_x\), 곧 \(\frac{\mu'}{\mu} = \frac{M_y - N_x}{N}\).
    곱의 법칙.
  3. 오른쪽이 \(x\)만의 함수 \(R(x)\)이면 \(\mu = e^{\int R\,dx}\). 마찬가지로 \(\frac{N_x - M_y}{M}\)이 \(y\)만의 함수이면 \(\mu(y) = e^{\int\frac{N_x - M_y}{M}dy}\).
    왼쪽은 \(x\)만의 함수이므로 오른쪽도 그래야 모순이 없다.

선형 방정식 \(y' + py = q\)는 \((py - q)\,dx + dy = 0\)이고 \(\frac{M_y - N_x}{N} = p(x)\)라 늘 \(\mu = e^{\int p}\)가 있습니다. 01-02 카드의 적분인자가 이 경우입니다.

\((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\)을 푸세요.

풀이

  1. \(M_y = 3x + 2y\), \(N_x = 2x + y\). 같지 않다: 완전하지 않음.
    판정.
  2. \(\frac{M_y - N_x}{N} = \frac{x + y}{x(x + y)} = \frac1x\): \(x\)만의 함수.
    인수분해로 약분.
  3. \(\mu = e^{\ln x} = x\). 곱하면 \((3x^2y + xy^2)\,dx + (x^3 + x^2y)\,dy = 0\).
    \(x > 0\)이라 가정(절댓값 생략).
  4. 확인: \((3x^2y + xy^2)_y = 3x^2 + 2xy = (x^3 + x^2y)_x\). 완전.
    이제 퍼텐셜이 있다.
  5. \(F = x^3y + \frac12x^2y^2 + g(y)\), \(F_y = x^3 + x^2y + g' = x^3 + x^2y\) → \(g = 0\). 해: \(x^3y + \frac12x^2y^2 = C\).
    01-02 카드와 같은 퍼텐셜 찾기.

의미

적분인자는 "등고선은 그대로 두고 높이의 눈금을 바꾸는" 일입니다. 해 곡선(등위선)은 같지만 그 위의 함숫값 \(F\)가 달라집니다. 열역학에서 열 \(dQ\)는 완전미분이 아니지만 \(\frac1T\)을 곱하면 완전미분 \(dS\)(엔트로피)가 되는 것이 같은 구조입니다(공통3 7-04).

검산

음함수 미분: \(3x^2y + x^3y' + xy^2 + x^2yy' = 0\), 곧 \(y'(x^3 + x^2y) = -(3x^2y + xy^2)\). \(x\)로 나누면 원래 방정식 \((3xy + y^2) + (x^2 + xy)y' = 0\). 맞습니다.

흔한 오해

  • 적분인자로 나눈 곳의 해 잃기: \(\mu = 0\)인 곳(여기서 \(x = 0\))은 따로 확인합니다. 원래 방정식에서 \(x = 0\)이면 \(y^2\,dx = 0\)이라 \(x = 0\)(수직선)도 해 곡선입니다.
