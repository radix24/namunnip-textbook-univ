이 절에서 배울 것
  • \(y'' + ay' + by = 0\)에 \(y = e^{\lambda x}\)를 넣어 특성방정식을 얻는다.
  • 특성방정식의 근이 서로 다른 실근, 중근, 복소근일 때 일반해를 쓴다.
먼저 알아야 할 것
  • 기저와 일반해 (2.1절), 이차방정식의 근의 공식 (고교 수학).
  • 오일러 공식 \(e^{i\theta} = \cos\theta + i\sin\theta\) (공통1 8.8절).

2.2.1지수함수를 넣어 보기

계수가 상수인 \(y'' + ay' + by = 0\)에서는 \(y\), \(y'\), \(y''\)이 서로 상수배만큼 다른 함수가 해일 것 같습니다. 그런 함수는 지수함수입니다. \(y = e^{\lambda x}\)를 넣으면 \(y' = \lambda e^{\lambda x}\), \(y'' = \lambda^2e^{\lambda x}\)이므로

\[(\lambda^2 + a\lambda + b)e^{\lambda x} = 0.\]

\(e^{\lambda x} \ne 0\)이므로 \(\lambda\)가 이차방정식 \(\lambda^2 + a\lambda + b = 0\)의 근이면 \(e^{\lambda x}\)가 해입니다. 이 이차방정식을 특성방정식이라 합니다. 미분방정식 풀기가 이차방정식 풀기로 바뀌었습니다. 판별식 \(a^2 - 4b\)의 부호에 따라 세 경우로 나뉩니다.

2.2.2세 가지 경우

특성근기저일반해
서로 다른 실근 \(\lambda_1, \lambda_2\)\(e^{\lambda_1x}, e^{\lambda_2x}\)\(c_1e^{\lambda_1x} + c_2e^{\lambda_2x}\)
중근 \(\lambda = -\frac a2\)\(e^{\lambda x}, xe^{\lambda x}\)\((c_1 + c_2x)e^{\lambda x}\)
복소근 \(-\frac a2 \pm i\omega\)\(e^{-ax/2}\cos\omega x, e^{-ax/2}\sin\omega x\)\(e^{-ax/2}(A\cos\omega x + B\sin\omega x)\)

중근일 때 \(e^{\lambda x}\) 하나만 나오므로 다른 해는 2.1절의 계수 낮추기로 구하면 \(xe^{\lambda x}\)가 나옵니다(2.1절 연습문제 2).

복소근 \(\lambda = \alpha \pm i\omega\)이면 오일러 공식으로 \(e^{(\alpha + i\omega)x} = e^{\alpha x}(\cos\omega x + i\sin\omega x)\)입니다. 이 복소수 해와 켤레 해를 더하고 빼서 2와 \(2i\)로 나누면 실수 해 \(e^{\alpha x}\cos\omega x\)와 \(e^{\alpha x}\sin\omega x\)를 얻습니다(중첩 원리).

예제 2.2.1

일반해를 구하여라. (가) \(y'' + y' - 2y = 0\) (나) \(y'' + 6y' + 9y = 0\) (다) \(y'' + 0.4y' + 9.04y = 0\)

풀이. (가) \(\lambda^2 + \lambda - 2 = (\lambda + 2)(\lambda - 1) = 0\). \(y = c_1e^x + c_2e^{-2x}\).

(나) \((\lambda + 3)^2 = 0\), 중근 \(-3\). \(y = (c_1 + c_2x)e^{-3x}\).

(다) \(\lambda = \dfrac{-0.4 \pm\sqrt{0.16 - 36.16}}{2} = -0.2 \pm 3i\). \(y = e^{-0.2x}(A\cos3x + B\sin3x)\). 진동하면서 진폭이 \(e^{-0.2x}\)로 줄어드는 해입니다.

예제 2.2.2

\(y'' + y' - 2y = 0\), \(y(0) = 4\), \(y'(0) = -5\)를 풀어라.

풀이. \(y = c_1e^x + c_2e^{-2x}\), \(y' = c_1e^x - 2c_2e^{-2x}\). \(c_1 + c_2 = 4\), \(c_1 - 2c_2 = -5\)에서 \(c_2 = 3\), \(c_1 = 1\). \(y = e^x + 3e^{-2x}\).

주의복소근 \(\alpha \pm i\omega\)에서 사인·코사인 안에 들어가는 것은 허수부 \(\omega\)이고, 지수에 들어가는 것은 실수부 \(\alpha\)입니다. 바꿔 쓰는 실수가 흔합니다.
요약
  1. \(y = e^{\lambda x}\)를 넣으면 특성방정식 \(\lambda^2 + a\lambda + b = 0\).
  2. 실근 두 개: \(c_1e^{\lambda_1x} + c_2e^{\lambda_2x}\) / 중근: \((c_1 + c_2x)e^{\lambda x}\) / 복소근 \(\alpha \pm i\omega\): \(e^{\alpha x}(A\cos\omega x + B\sin\omega x)\).

2.2.3연습문제

기본

  1. (가) \(y'' - 9y = 0\) (나) \(y'' + 4y' + 4y = 0\) (다) \(y'' + 2y' + 5y = 0\)
    답

    (가) \(c_1e^{3x} + c_2e^{-3x}\) (나) \((c_1 + c_2x)e^{-2x}\) (다) \(e^{-x}(A\cos2x + B\sin2x)\)

응용

  1. \(y'' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 6\)을 풀어라.
    답

    \(y = A\cos2x + B\sin2x\), \(A = 1\), \(2B = 6\). \(y = \cos2x + 3\sin2x\).

  2. 일반해가 \(c_1e^{2x} + c_2e^{-x}\)인 상수계수 방정식을 구하여라.
    답

    \((\lambda - 2)(\lambda + 1) = \lambda^2 - \lambda - 2\). \(y'' - y' - 2y = 0\).

2.2.2

예제상수계수 동차 방정식: 특성근의 세 경우

e^(rx) 대입 · 서로 다른 실근 · 중근 · 복소근 · 문제 해결 전략

다루는 성취기준 [공통8-02-02]

출발점

\(ay'' + by' + cy = 0\)에 \(y = e^{rx}\)를 넣으면 \(e^{rx}(ar^2 + br + c) = 0\). 따라서 특성방정식 \(ar^2 + br + c = 0\)의 근 \(r\)마다 해 \(e^{rx}\)가 생깁니다. 미분해도 모양이 그대로인 함수가 지수함수이기 때문에 이 추측이 통합니다.

특성근일반해
서로 다른 실근 \(r_1, r_2\)\(c_1e^{r_1x} + c_2e^{r_2x}\)
중근 \(r\)\((c_1 + c_2x)e^{rx}\)
복소근 \(\alpha \pm i\beta\)\(e^{\alpha x}(c_1\cos\beta x + c_2\sin\beta x)\)
문제 해결 전략 · 이계 선형 방정식
  1. 동차 부분의 특성방정식을 풀어 \(y_h\)를 쓴다.
  2. 비동차이면 특수해 \(y_p\)를 미정계수법이나 매개변수 변환법으로 구한다(02-06 카드).
  3. 일반해 \(y = y_h + y_p\)에 초기조건 두 개를 넣어 \(c_1, c_2\)를 정한다. 초기조건은 반드시 \(y_p\)까지 더한 뒤 넣는다.
  4. 원래 방정식에 넣어 확인한다.

(가) \(y'' - y' - 6y = 0\) (나) \(y'' + 4y' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 0\) (다) \(y'' + 2y' + 5y = 0\)

풀이

  1. (가) \(r^2 - r - 6 = (r - 3)(r + 2) = 0\). \(y = c_1e^{3x} + c_2e^{-2x}\).
    서로 다른 실근.
  2. (나) \((r + 2)^2 = 0\), 중근 \(-2\). \(y = (c_1 + c_2x)e^{-2x}\).
    두 번째 해 \(xe^{-2x}\): 대입하면 성립(차수 낮추기로 유도). \(W = e^{-4x} \ne 0\).
  3. \(y(0) = c_1 = 1\). \(y' = (c_2 - 2c_1 - 2c_2x)e^{-2x}\), \(y'(0) = c_2 - 2 = 0\), \(c_2 = 2\). \(y = (1 + 2x)e^{-2x}\).
    초기조건.
  4. (다) \(r = \frac{-2 \pm\sqrt{4 - 20}}{2} = -1 \pm 2i\). \(y = e^{-x}(c_1\cos2x + c_2\sin2x)\).
    Euler 공식 \(e^{(\alpha + i\beta)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)\)의 실수부와 허수부가 각각 실수 해.

의미

세 경우는 3단원의 진동 운동에서 그대로 물리적 뜻을 가집니다. 서로 다른 음의 실근은 진동 없이 천천히 가라앉는 과감쇠, 중근은 가장 빨리 진동 없이 멈추는 임계감쇠, 복소근은 진폭 \(e^{-x}\)로 줄며 진동하는 미감쇠입니다. 특성근의 실수부가 모두 음수이면 해는 0으로 갑니다(안정).

검산

(나) \(y = (1 + 2x)e^{-2x}\): \(y' = -4xe^{-2x}\), \(y'' = (-4 + 8x)e^{-2x}\). \(y'' + 4y' + 4y = (-4 + 8x - 16x + 4 + 8x)e^{-2x} = 0\). 맞습니다.
