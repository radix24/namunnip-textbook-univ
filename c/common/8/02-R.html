2.R.1

연습이계 선형 미분방정식 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통8-02-05] [공통8-02-02] [공통8-02-06] [공통8-02-04]

동차해 → 특수해 → 초기조건 순서를 지키세요.

  1. 계산\(y'' + 6y' + 9y = 0\), \(y(0) = 2\), \(y'(0) = -1\)을 푸세요. [02-02]

    힌트 1

    02-02 절: 중근 \(-3\).

    힌트 2

    \(y = (c_1 + c_2x)e^{-3x}\).

    풀이

    \(c_1 = 2\). \(y' = (c_2 - 3c_1 - 3c_2x)e^{-3x}\), \(y'(0) = c_2 - 6 = -1\), \(c_2 = 5\). \(y = (2 + 5x)e^{-3x}\).

  2. 계산\(y'' + 4y = 8x^2\)의 일반해를 구하세요. [02-06]

    힌트 1

    동차해 \(\cos2x, \sin2x\). 추측 \(Ax^2 + Bx + C\).

    힌트 2

    \(2A + 4(Ax^2 + Bx + C) = 8x^2\).

    풀이

    \(4A = 8\), \(4B = 0\), \(2A + 4C = 0\) → \(A = 2\), \(B = 0\), \(C = -1\). \(y = c_1\cos2x + c_2\sin2x + 2x^2 - 1\).

  3. 판단한 학생이 \(y'' + y = \cos x\)의 특수해를 \(y_p = A\cos x + B\sin x\)로 추측했더니 대입 결과가 \(0 = \cos x\)가 되어 "특수해가 없다"고 결론 내렸습니다. 무엇이 틀렸고, 바른 특수해는? [02-06]

    힌트 1

    추측이 동차해와 겹치면?

    힌트 2

    \(y_p = x(A\cos x + B\sin x)\).

    풀이

    추측이 동차해와 같아 대입하면 0이 됩니다. \(x\)를 곱해야 합니다. \(y_p = x(A\cos x + B\sin x)\)를 넣으면 \(-2A\sin x + 2B\cos x = \cos x\), \(A = 0\), \(B = \frac12\). \(y_p = \frac x2\sin x\). 진폭이 \(x\)에 비례해 커지는 공명입니다(3-02 카드).

  4. 개념\(y_1 = x\)와 \(y_2 = x^2\)이 어떤 방정식 \(y'' + p(x)y' + q(x)y = 0\)의 해라면, \(x = 0\)을 포함하는 구간에서 \(p\)나 \(q\)가 연속일 수 있나요? [02-05]

    힌트 1

    \(W(x, x^2) = x^2\).

    힌트 2

    Abel 공식: \(p, q\)가 연속이면 \(W\)는 늘 0이거나 한 번도 0이 아님.

    풀이

    \(W = x^2\)은 \(x = 0\)에서만 0입니다. \(p\)와 \(q\)가 연속인 구간에서는 그럴 수 없으므로(Abel), 그 방정식은 \(x = 0\)에서 계수가 불연속이어야 합니다. 실제로 \(x^2y'' - 2xy' + 2y = 0\) (Euler-Cauchy)을 정규화하면 \(p = -\frac2x\), \(q = \frac{2}{x^2}\)로 \(x = 0\)에서 터집니다.

  5. 계산\(x^2y'' + 3xy' + y = 0\) (\(x > 0\))의 일반해를 구하세요. [02-04]

    힌트 1

    \(m(m - 1) + 3m + 1 = 0\).

    힌트 2

    \((m + 1)^2 = 0\).

    풀이

    중근 \(m = -1\). \(y = (c_1 + c_2\ln x)x^{-1}\).

  6. 판단한 학생이 \(y'' - y = e^x\), \(y(0) = 0\), \(y'(0) = 0\)을 풀면서 동차해에만 초기조건을 넣어 \(c_1 = c_2 = 0\)을 얻고 그다음 \(y_p\)를 더했습니다. 결과가 초기조건을 만족하나요? [02-06]

    힌트 1

    \(y_p = \frac12xe^x\).

    힌트 2

    \(y = \frac12xe^x\)의 \(y'(0)\)은?

    풀이

    \(y = \frac12xe^x\)이면 \(y(0) = 0\)이지만 \(y'(0) = \frac12 \ne 0\). 초기조건은 \(y_h + y_p\) 전체에 넣어야 합니다. 바르게: \(y = c_1e^x + c_2e^{-x} + \frac12xe^x\), \(c_1 + c_2 = 0\), \(c_1 - c_2 + \frac12 = 0\) → \(c_1 = -\frac14\), \(c_2 = \frac14\). \(y = -\frac14e^x + \frac14e^{-x} + \frac12xe^x\).

2.R.2

연습진동운동 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통8-02-03] [공통8-02-07] [공통8-02-07]

먼저 판별식으로 감쇠의 종류를 정하세요.

  1. 계산질량 2 kg, 용수철 상수 50 N/m인 계를 임계감쇠로 만들려면 감쇠 계수는? 그때 \(x(0) = 0.2\) m, \(x'(0) = 0\)인 해는? [02-03]

    힌트 1

    02-03 절: \(c = 2\sqrt{mk}\).

    힌트 2

    중근 \(-\frac{c}{2m}\).

    풀이

    \(c = 2\sqrt{100} = 20\) N·s/m. 중근 \(-5\). \(x = (A + Bt)e^{-5t}\), \(A = 0.2\), \(B - 5A = 0\) → \(B = 1\). \(x = (0.2 + t)e^{-5t}\).

  2. 개념미감쇠 진동의 진동수 \(\omega_d\)는 감쇠 없는 고유 진동수 \(\omega_0\)보다 큰가요, 작은가요? 직관적으로 설명하세요. [02-03]

    힌트 1

    \(\omega_d = \sqrt{\omega_0^2 - \left(\frac{c}{2m}\right)^2}\).

    힌트 2

    저항은 운동을 늦춥니다.

    풀이

    작습니다. 저항이 질량의 움직임을 늦춰 한 번 왕복하는 데 시간이 더 걸립니다. 감쇠가 작으면 차이는 미미합니다(\(\zeta = 0.1\)이면 0.5%).

  3. 계산\(x'' + 0.4x' + 4x = 2\cos\omega t\)에서 정상 상태 진폭을 \(\omega = 1, 2, 3\)일 때 구하세요. [02-07]

    힌트 1

    \(A = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2}}\), \(m = 1\), \(c = 0.4\), \(k = 4\).

    힌트 2

    \(\omega = 2\)가 고유 진동수.

    풀이

    \(\omega = 1\): \(\frac{2}{\sqrt{9 + 0.16}} = 0.66\). \(\omega = 2\): \(\frac{2}{\sqrt{0 + 0.64}} = 2.5\). \(\omega = 3\): \(\frac{2}{\sqrt{25 + 1.44}} = 0.39\). 고유 진동수에서 약 4~6배 커집니다.

  4. 판단한 학생이 "감쇠가 있는 계에 공명 진동수로 힘을 주면 진폭이 무한히 커진다"고 했습니다. 맞나요? [02-07]

    힌트 1

    \(\omega = \omega_0\)에서 \(A = \frac{F_0}{c\omega_0}\).

    힌트 2

    \(c > 0\)이면?

    풀이

    틀렸습니다. \(c > 0\)이면 진폭은 유한한 \(\frac{F_0}{c\omega_0}\)에 머뭅니다. 외력이 한 주기에 넣는 에너지와 감쇠가 빼앗는 에너지가 맞아떨어지는 진폭입니다. 무한히 커지는 것은 \(c = 0\)인 이상화된 경우뿐입니다.

  5. 계산직렬 RLC 회로 \(L = 1\) H, \(C = 0.25\) F에서 \(R\)이 얼마 이상이면 진동하지 않나요? 대응하는 역학계의 말로 설명하세요. [02-07]

    힌트 1

    \(R^2 \ge \frac{4L}{C}\).

    힌트 2

    \(\frac{4}{0.25} = 16\).

    풀이

    \(R \ge 4\ \Omega\). 역학: 질량 1 kg, 용수철 4 N/m에서 감쇠 계수 4 N·s/m 이상이면 과감쇠 또는 임계감쇠라 진동 없이 평형으로 돌아갑니다.

  6. 판단"강제 진동에서 오래 지나면 처음 위치와 속도가 다르면 진동도 다르다." 맞나요? [02-07]

    힌트 1

    일반해 = 과도 응답 + 정상 상태 응답.

    힌트 2

    초기조건은 어느 부분에 들어가나요?

    풀이

    틀렸습니다(감쇠가 있을 때). 초기조건은 동차해(과도 응답)의 상수만 정하고, 그 부분은 \(e^{-ct/2m}\)로 사라집니다. 오래 지나면 처음 상태와 상관없이 같은 정상 상태 응답만 남습니다. 계가 처음 상태를 "잊는다"는 것이 감쇠의 효과입니다.
