5.5.1곱의 역변환

\(\mathcal L^{-1}\{FG\}\)는 \(\mathcal L^{-1}\{F\}\cdot\mathcal L^{-1}\{G\}\)가 아닙니다. 변환의 곱에 해당하는 것은 함수의 보통 곱이 아니라 다음의 합성곱입니다.

정의 5.5.1 (합성곱) \[(f * g)(t) = \int_0^t f(\tau)\,g(t - \tau)\,d\tau.\]
정리 5.5.2 (합성곱 정리)

\(\mathcal L\{f * g\} = F(s)G(s)\).

예제 5.5.3

\(\mathcal L^{-1}\left\{\dfrac{1}{s(s - a)}\right\}\)을 합성곱으로 구하여라.

풀이. \(\frac1s \to 1\), \(\frac{1}{s - a} \to e^{at}\). \(1 * e^{at} = \int_0^te^{a\tau}d\tau = \frac1a(e^{at} - 1)\). (부분분수로 구한 결과와 같습니다.)

합성곱의 뜻: 계의 충격 응답이 \(g\)이면, 입력 \(f\)를 시각 \(\tau\)마다 크기 \(f(\tau)\)인 작은 충격들의 연속으로 보고, 각 충격이 시각 \(t\)까지 남긴 효과 \(f(\tau)g(t - \tau)\)를 모두 더한 것이 응답입니다. 그래서 응답 = 입력 * 충격 응답입니다.

5.5.2적분방정식

미지 함수가 적분 안에 들어 있는 식을 적분방정식이라 합니다. 그 적분이 합성곱 꼴이면 라플라스 변환으로 쉽게 풉니다.

예제 5.5.4

\(y(t) - \int_0^ty(\tau)\sin(t - \tau)\,d\tau = t\)를 풀어라.

풀이. 적분은 \(y * \sin t\)입니다. 변환하면 \(Y - Y\frac{1}{s^2 + 1} = \frac{1}{s^2}\), 곧 \(Y\frac{s^2}{s^2 + 1} = \frac{1}{s^2}\), \(Y = \frac{s^2 + 1}{s^4} = \frac{1}{s^2} + \frac{1}{s^4}\). 따라서 \(y = t + \frac{t^3}{6}\).

요약
  1. \(f * g = \int_0^tf(\tau)g(t - \tau)d\tau\), \(\mathcal L\{f * g\} = FG\).
  2. 변환이 곱이면 역변환은 합성곱. 적분방정식도 변환으로 푼다.

5.5.3연습문제

기본

  1. \(t * t\)를 계산하고 합성곱 정리로 확인하여라.
    답

    \(\int_0^t\tau(t - \tau)d\tau = \frac{t^3}{6}\). 변환 \(\frac{1}{s^2}\cdot\frac{1}{s^2} = \frac{1}{s^4} \to \frac{t^3}{6}\).

응용

  1. \(\mathcal L^{-1}\left\{\frac{1}{(s^2 + 1)^2}\right\}\)을 합성곱으로 구하여라.
    답

    \(\sin t * \sin t = \frac12(\sin t - t\cos t)\).

5.5.2

예제합성곱 정리로 역변환 구하기

(f * g)(t) = ∫₀ᵗ f(τ)g(t − τ)dτ · L{f * g} = FG

다루는 성취기준 [공통8-05-05]

정리와 뜻

합성곱 \((f * g)(t) = \int_0^tf(\tau)g(t - \tau)\,d\tau\)에 대해 \(\mathcal L\{f * g\} = F(s)G(s)\). 곱의 역변환은 합성곱입니다(곱의 역변환은 역변환의 곱이 아닙니다).

근거(개요): \(F(s)G(s) = \int_0^\infty\int_0^\infty e^{-s(\tau + \sigma)}f(\tau)g(\sigma)\,d\tau\,d\sigma\)에서 \(t = \tau + \sigma\)로 변수를 바꾸고 적분 순서를 바꾸면(공통2 6-01, 6-03) \(\int_0^\infty e^{-st}\left[\int_0^tf(\tau)g(t - \tau)d\tau\right]dt\).

뜻: 계의 충격 응답 \(h(t)\)를 알면 입력 \(g(t)\)에 대한 응답(초기조건 0)은 \(y = h * g\). 입력을 시각 \(\tau\)마다의 작은 충격 \(g(\tau)d\tau\)로 쪼개면, 각각이 \(t - \tau\)만큼 지난 뒤의 응답 \(h(t - \tau)\)을 남기고, 그것을 모두 더한 것입니다.

(가) \(\mathcal L^{-1}\left\{\frac{1}{s^2(s^2 + 1)}\right\}\)을 합성곱으로 구하세요. (나) \(y'' + y = g(t)\), \(y(0) = y'(0) = 0\)의 해를 \(g\)에 대한 적분으로 쓰세요.

풀이

  1. (가) \(\frac{1}{s^2} \leftrightarrow t\), \(\frac{1}{s^2 + 1} \leftrightarrow \sin t\). 따라서 역변환은 \(t * \sin t = \int_0^t\tau\sin(t - \tau)\,d\tau\).
    합성곱 정리.
  2. 부분적분 \(u = \tau\), \(dv = \sin(t - \tau)d\tau\) (\(v = \cos(t - \tau)\)): \(\left[\tau\cos(t - \tau)\right]_0^t - \int_0^t\cos(t - \tau)\,d\tau = t - \sin t\).
    \(\int_0^t\cos(t - \tau)d\tau = \sin t\).
  3. (나) 충격 응답 \(h = \mathcal L^{-1}\left\{\frac{1}{s^2 + 1}\right\} = \sin t\).
    05-03 카드 (가)에서 지연 없는 경우.
  4. \(y(t) = \int_0^t\sin(t - \tau)g(\tau)\,d\tau\).
    \(Y = \frac{G(s)}{s^2 + 1}\)의 역변환. 어떤 입력 \(g\)에도 쓸 수 있는 공식.

의미

(나)의 공식은 2단원의 매개변수 변환법(02-06 카드)과 같은 결과를 더 투명하게 줍니다. \(\sin(t - \tau)\)는 "\(\tau\)에 받은 충격이 \(t\)까지 남긴 흔적"입니다. 신호 처리의 필터, 영상의 흐림 효과(블러), 확률에서 두 독립 확률변수의 합의 분포가 모두 합성곱입니다.

검산

(가) 부분분수로도: \(\frac{1}{s^2(s^2+1)} = \frac{1}{s^2} - \frac{1}{s^2 + 1}\) → \(t - \sin t\). 일치합니다.

흔한 오해

  • \(\mathcal L^{-1}\{FG\} = fg\): \(\frac{1}{s}\cdot\frac1s = \frac{1}{s^2}\)인데 \(1\cdot1 = 1 \ne t\). 곱의 역변환은 합성곱 \(1 * 1 = \int_0^t1\,d\tau = t\)입니다.
