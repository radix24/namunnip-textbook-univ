6.3.1미끄러지지 않고 구르기

바퀴가 미끄러지지 않고 구르면 한 바퀴 돌 때 둘레 \(2\pi R\)만큼 나아가므로 \(v_{\text{cm}} = R\omega\)입니다. 이때 바닥에 닿은 점은 순간적으로 정지해 있고, 꼭대기 점은 \(2v_{\text{cm}}\)으로 움직입니다.

구르는 운동은 "질량 중심의 직선 운동 + 질량 중심 둘레의 회전"이므로 운동 에너지도 둘의 합입니다.

\[K = \frac12Mv_{\text{cm}}^2 + \frac12I_{\text{cm}}\omega^2.\]

바닥의 마찰력은 정지 마찰이고 닿는 점이 움직이지 않으므로 일을 하지 않습니다. 그래서 역학적 에너지 보존을 쓸 수 있습니다.

6.3.2경사면 경주

예제 6.3.1

같은 높이 \(h\)에서 꽉 찬 구, 원판(원기둥), 고리를 굴려 내린다. 바닥에서의 속력을 비교하여라.

풀이. \(I_{\text{cm}} = cMR^2\)으로 쓰면 \(K = \frac12Mv^2(1 + c)\)이고 \(Mgh = K\)에서

\[v = \sqrt{\frac{2gh}{1 + c}}.\]
물체\(c\)\(h = 1.0\) m일 때 \(v\)
꽉 찬 구\(\frac25\)3.74 m/s
원판\(\frac12\)3.61 m/s
고리13.13 m/s

질량과 반지름은 답에 없습니다. 구가 가장 빠르고 고리가 가장 느립니다. 질량이 축 가까이 모인 물체일수록 위치 에너지가 회전에 덜 쓰이고 직선 운동에 더 많이 가기 때문입니다. (미끄러지는 물체는 \(c = 0\)으로 \(\sqrt{2gh} = 4.43\) m/s.)

요약
  1. 구르기: \(v_{\text{cm}} = R\omega\), \(K = \frac12Mv^2 + \frac12I\omega^2\).
  2. 정지 마찰은 일을 하지 않으므로 에너지 보존을 쓴다. \(I\)가 작을수록 빨리 구른다.

6.3.3연습문제

기본

  1. 2.0 m/s로 구르는 원판(질량 1.0 kg)의 전체 운동 에너지는?
    답

    \(\frac12(1)(4) + \frac12\cdot\frac12(1)R^2\cdot\frac{4}{R^2} = 2 + 1 = 3.0\) J.

응용

  1. 속이 빈 구(\(I = \frac23MR^2\))는 예제의 순위에서 어디에 들어가는가?
    답

    \(c = \frac23\)이므로 원판과 고리 사이.

6.3.2

예제굴러 내려오는 경주: 속이 찬 구, 원통, 고리

K = ½Mv² + ½Iω² · v = Rω

다루는 성취기준 [공통3-06-03]

모형

미끄러지지 않고 구르면 바닥과 닿는 점은 순간적으로 정지해 있고, 중심 속력 \(v = R\omega\)입니다. 운동에너지는 질량 중심의 병진 + 질량 중심 둘레 회전:

\[K = \tfrac12Mv^2 + \tfrac12I_{cm}\omega^2 = \tfrac12\left(M + \frac{I_{cm}}{R^2}\right)v^2.\]

\(I_{cm} = cMR^2\)으로 쓰면 \(c\)가 모양을 나타냅니다: 속이 찬 구 \(\frac25\), 원통(원판) \(\frac12\), 속이 빈 구 \(\frac23\), 고리 1.

정지 마찰은 닿는 점이 미끄러지지 않으므로 일을 하지 않습니다. 그래서 역학적 에너지가 보존됩니다.

먼저 예측

같은 빗면 꼭대기에서 속이 찬 구, 속이 빈 구, 원통을 함께 놓으면 어느 것이 먼저 바닥에 닿을까요? 질량과 크기는 영향이 있을까요?

예측 확인

속이 찬 구 → 원통 → 속이 빈 구 순서입니다. 질량과 반지름은 상관없고 모양(\(c\))만 결정합니다.

높이 \(h\)인 빗면(경사각 \(\theta\))에서 정지 상태로 굴러 내려온 물체의 바닥 속력과 가속도를 \(c\)로 나타내고, \(h = 1.0\) m일 때 세 물체의 바닥 속력을 비교하세요.

풀이

  1. \(Mgh = \frac12(1 + c)Mv^2\), \(v = \sqrt{\dfrac{2gh}{1 + c}}\).
    에너지 보존. \(M\)과 \(R\)이 소거된다.
  2. 빗면 거리 \(s = \frac{h}{\sin\theta}\), \(v^2 = 2as\)이므로 \(a = \dfrac{g\sin\theta}{1 + c}\).
    가속도가 일정하므로 등가속도 식(02-02 카드).
  3. \(h = 1.0\): 속이 찬 구 \(\sqrt{19.6/1.4} = 3.74\), 원통 \(\sqrt{19.6/1.5} = 3.61\), 속이 빈 구 \(\sqrt{19.6/1.667} = 3.43\) m/s. 미끄러지는 상자(마찰 없음, \(c = 0\))는 4.43 m/s.
    \(c\)가 작을수록 빠름.

의미

같은 위치에너지가 병진과 회전으로 나뉩니다. 병진 몫은 \(\frac{1}{1 + c}\). 질량이 축에서 먼 물체(고리, 속이 빈 구)일수록 회전에 에너지를 많이 빼앗겨 느립니다. 그래서 "속이 찬 공과 빈 공 구별하기"는 굴려 보면 됩니다(자기 점검 질문의 답).

검산

힘으로 다시: 빗면 방향 \(Mg\sin\theta - f = Ma\), 회전 \(fR = cMR^2\alpha = cMRa\) → \(f = cMa\). 더하면 \(a = \frac{g\sin\theta}{1 + c}\). 일치합니다. 필요한 마찰 \(f = \frac{c}{1 + c}Mg\sin\theta\)이 \(\mu_sMg\cos\theta\)를 넘으면 미끄러지며 구릅니다.

흔한 오해

  • "마찰이 있으니 에너지를 잃는다." 구르기만 하면 정지 마찰은 일을 하지 않습니다. 미끄러지면 운동 마찰이 열을 만듭니다.
6.3.3

실습구르기 경주: 무엇이 먼저 내려올까?

실습 · 관성 모멘트와 구르는 운동

다루는 성취기준 [공통3-06-03]

목표

같은 경사면에서 구, 원판, 속이 빈 구, 고리를 굴려 도착 순서를 예측하고 확인합니다. 순서가 질량이나 크기가 아니라 \(\frac{I}{MR^2}\)으로만 정해짐을 이해합니다. 성취기준 [공통3-06-03].

준비

장치는 경사면을 펴서 다섯 줄로 나란히 그립니다(오른쪽 빨간 점선이 도착선, 화면은 실제의 절반 속도). 굴러가는 물체에 그은 선으로 회전을 볼 수 있습니다. 맨 위의 상자는 마찰 없이 미끄러지는 비교 대상입니다.

절차

  1. 재생하기 전에 도착 순서를 예상해 적는다.
  2. 재생하고 순서와 시간을 기록한다.
  3. 경사각을 바꿔 순서가 바뀌는지, 시간의 비는 어떤지 본다.

기대 결과

  • 순서: 상자, 꽉 찬 구, 원판, 속이 빈 구, 고리. 경사각을 바꿔도 순서는 같다.
  • 시간의 비는 \(\sqrt{1 + I/MR^2}\)의 비로 일정하다. 고리는 꽉 찬 구보다 \(\sqrt{2/1.4} \approx 1.20\)배 오래 걸린다.

분석

  1. 질량이 두 배인 원판과 보통 원판을 경주시키면 어떻게 될까요? 반지름이 두 배이면?
  2. 같은 높이에서 출발하면 모두 같은 위치 에너지를 잃는데 왜 속력이 다를까요? 에너지가 어디로 나뉘는지 설명해 보세요.
  3. 캔 음료(액체가 거의 돌지 않음)와 같은 크기의 꽉 찬 원기둥 중 무엇이 빠를까요?

더 해 보기

책을 쌓아 낮은 경사면을 만들고 동전(원판), 반지(고리), 구슬(구)을 동시에 굴려 봅니다. 휴대폰 슬로 모션으로 찍으면 순서를 확실히 볼 수 있습니다.
