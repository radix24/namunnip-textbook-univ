6.3.1

예제줄과 관의 정상파: 끝 조건이 고유 진동수를 정한다

마디 · 배 · 열린관 · 닫힌관

다루는 성취기준 [공통3-06-03]

정상파는 무엇인가

같은 진동수의 두 파동이 반대 방향으로 겹치면 \(A\sin(kx - \omega t) + A\sin(kx + \omega t) = 2A\sin kx\cos\omega t\) (삼각함수의 합 → 곱). 모양이 움직이지 않고 제자리에서 커졌다 작아집니다. \(\sin kx = 0\)인 곳은 늘 정지(마디), 진폭이 최대인 곳이 배. 마디 사이 간격은 \(\frac\lambda2\).

양 끝에서 반사된 파동이 계속 겹치므로, 끝 조건을 만족하는 파장만 살아남습니다.

계끝 조건허용 파장진동수
양 끝 고정 줄, 양쪽 열린 관양 끝 같은 종류(마디-마디, 배-배)\(L = n\frac\lambda2\)\(f_n = \frac{nv}{2L}\), \(n = 1, 2, 3, \dots\)
한쪽 닫힌 관닫힌 끝 마디, 열린 끝 배\(L = (2n - 1)\frac\lambda4\)\(f = \frac{(2n-1)v}{4L}\): 홀수배만

(가) 길이 0.65 m, 선밀도 \(1.2\times10^{-3}\) kg/m인 기타 줄의 기본 진동수가 196 Hz(G3)가 되려면 장력이 얼마여야 하나요? (나) 길이 0.30 m인 관이 양쪽 열린 경우와 한쪽 닫힌 경우의 기본 진동수를 비교하세요(\(v = 343\) m/s).

풀이

  1. (가) 기본(\(n = 1\)): \(\lambda = 2L = 1.30\) m. 필요한 파속 \(v = \lambda f = 1.30\times196 = 254.8\) m/s.
    양 끝 고정: 줄 길이에 반 파장 하나.
  2. \(v = \sqrt{F_T/\mu}\)에서 \(F_T = \mu v^2 = 1.2\times10^{-3}\times(254.8)^2 \approx 77.9\) N.
    줄의 파속 공식.
  3. (나) 양쪽 열림: \(f_1 = \frac{343}{2(0.30)} = 572\) Hz.
    배-배: 반 파장.
  4. 한쪽 닫힘: \(f_1 = \frac{343}{4(0.30)} = 286\) Hz. 절반(한 옥타브 낮음). 배음은 858, 1430 Hz (홀수배)뿐.
    마디-배: 4분의 1 파장.

의미

같은 길이라도 끝을 막으면 한 옥타브 낮아지고 짝수 배음이 빠져 음색이 달라집니다. 클라리넷(한쪽 닫힌 관에 가까움)이 같은 길이의 플루트(양쪽 열림)보다 한 옥타브 낮고 독특한 소리를 내는 이유입니다. 기타는 손가락으로 줄 길이를 줄여 \(f \propto \frac1L\)로 음을 올리고, 줄감개로 장력을 바꿔 \(f \propto \sqrt{F_T}\)로 조율합니다.

검산

78 N은 약 8 kg의 무게로, 실제 기타 줄 장력(줄당 50~120 N)의 범위입니다. 단위: \(\text{kg/m}\times(\text{m/s})^2 = \text{N}\).

이해 확인

(가)의 줄을 12번째 프렛(줄 길이의 절반)에서 누르면 진동수는?

답

392 Hz, 한 옥타브 위(G4). 길이가 절반이면 진동수가 2배.
