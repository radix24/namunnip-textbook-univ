5.1.1

유도관성 모멘트를 적분과 평행축 정리로 구하기

I = ∫r² dm · 막대 · 원판 · 평행축

다루는 성취기준 [공통3-05-01]

무엇을 유도하나

(1) 길이 \(L\), 질량 \(M\)인 균일한 막대: 중심축 \(I_{cm} = \frac{1}{12}ML^2\), 끝 축 \(\frac13ML^2\). (2) 반지름 \(R\)인 균일한 원판의 중심축: \(\frac12MR^2\). (3) 평행축 정리: \(I = I_{cm} + Md^2\).

출발점

회전 운동에너지 \(K = \sum\frac12m_i(r_i\omega)^2 = \frac12\left(\sum m_ir_i^2\right)\omega^2\). 괄호 속이 관성 모멘트 \(I = \int r^2\,dm\)이고, 회전에서 질량의 역할을 합니다(\(K = \frac12mv^2\)과 비교). \(r\)은 회전축까지의 수직 거리입니다.

유도

  1. (1) 막대를 \(x\)축에 놓고 중심을 원점으로. \(dm = \frac ML\,dx\).
    균일: 선밀도 \(\lambda = \frac ML\).
  2. \(I_{cm} = \int_{-L/2}^{L/2}x^2\frac ML\,dx = \frac ML\cdot\frac{2}{3}\left(\frac L2\right)^3 = \frac{1}{12}ML^2\).
    우함수라 \(2\int_0^{L/2}\) (공통1 5-04).
  3. 끝 축: \(\int_0^Lx^2\frac ML\,dx = \frac13ML^2\).
    적분 구간만 바뀜.
  4. (2) 원판을 반지름 \(r\), 폭 \(dr\)인 고리로 나눔: \(dm = \frac{M}{\pi R^2}2\pi r\,dr\). \(I = \int_0^Rr^2\frac{2M}{R^2}r\,dr = \frac12MR^2\).
    고리 위의 모든 점이 축에서 같은 거리 \(r\).
  5. (3) 질량 중심을 원점으로, 새 축은 \((d, 0)\)을 지나는 평행축. \(I = \int[(x - d)^2 + y^2]\,dm = \int(x^2 + y^2)\,dm - 2d\int x\,dm + d^2\int dm\).
    축까지 거리의 제곱을 전개.
  6. \(\int x\,dm = Mx_{cm} = 0\)이므로 \(I = I_{cm} + Md^2\).
    질량 중심의 정의. 중심축이 아니면 이 항이 사라지지 않는다.

확인: 막대 끝 축 = \(\frac{1}{12}ML^2 + M\left(\frac L2\right)^2 = \frac13ML^2\). 3단계와 같습니다.

결과 확인

  • 차원: 모두 질량 × 길이².
  • 순서: 같은 질량·반지름이면 고리 \(MR^2\) > 원판 \(\frac12MR^2\). 질량이 축에서 멀리 있을수록 크다.
  • 최소: 평행축 중 질량 중심을 지나는 축의 \(I\)가 가장 작다(\(Md^2 \ge 0\)).

한계

평행축 정리는 한 축이 질량 중심을 지날 때만 씁니다. 두 축이 모두 질량 중심을 지나지 않으면 질량 중심을 거쳐 두 번 씁니다.
