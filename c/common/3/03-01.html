3.1.1

예제변하는 힘이 한 일은 적분이다

W = ∫F·dr · 용수철 · 문제 해결 전략

다루는 성취기준 [공통3-03-01]

정의

일정한 힘이 변위 \(\mathbf d\)만큼 옮길 때 \(W = \mathbf F\cdot\mathbf d = Fd\cos\theta\). 힘이 위치에 따라 변하면 경로를 잘게 나눠 조각마다 \(\mathbf F\cdot\Delta\mathbf r\)를 더하고 극한을 취합니다. 그 결과가 공통2의 선적분입니다.

\[W = \int_C\mathbf F\cdot d\mathbf r, \qquad \text{1차원이면 } W = \int_{x_1}^{x_2}F(x)\,dx.\]

1차원에서 \(W\)는 \(F\)-\(x\) 그래프 아래의 부호 있는 넓이입니다.

문제 해결 전략 · 일과 에너지
  1. 계(물체 또는 물체들)와 처음·나중 상태를 정한다.
  2. 각 힘이 한 일을 구한다. 힘이 변하면 적분, 보존력이면 퍼텐셜 에너지 차이로.
  3. 알짜일 = 운동에너지 변화 (일-에너지 정리), 또는 비보존력의 일 = 역학적 에너지 변화.
  4. 필요하면 \(F = ma\)로 시간·가속도를 구한다. 에너지 식에는 시간이 없다.
  5. 단위(J)와 부호(받은 일인지 한 일인지)를 확인한다.

(가) 용수철 상수 \(k = 200\) N/m인 용수철을 자연 길이에서 0.10 m 늘이는 데 필요한 일 (나) 0.10 m에서 0.20 m로 더 늘이는 데 필요한 일 (다) 힘 \(F(x) = 3x^2 - 2x\) (N, x는 m)이 \(x = 0\)에서 2 m까지 한 일

풀이

  1. 용수철을 늘이는 사람의 힘은 \(F = kx\) (용수철의 복원력 \(-kx\)와 맞섬, 천천히 늘인다고 가정).
    훅의 법칙. 천천히 = 운동에너지 변화 없음.
  2. (가) \(W = \int_0^{0.10}200x\,dx = 100(0.10)^2 = 1.0\) J.
    일반적으로 \(\int_0^xkx'\,dx' = \frac12kx^2\).
  3. (나) \(W = 100(0.20^2 - 0.10^2) = 3.0\) J.
    같은 0.10 m인데 일이 3배: 늘어날수록 힘이 크다.
  4. (다) \(W = \int_0^2(3x^2 - 2x)\,dx = [x^3 - x^2]_0^2 = 4\) J.
    \(0 < x < \frac23\)에서는 \(F < 0\)이라 그 부분의 일은 음수(\(-\frac{4}{27}\) J)이고, 전체에 포함되어 있다.

의미

\(\frac12kx^2\)는 그래프 \(F = kx\) 아래 삼각형 넓이입니다. 이 일은 사라지지 않고 용수철의 탄성 퍼텐셜 에너지로 저장되어, 놓으면 운동에너지로 돌아옵니다(03-03 카드).

검산

평균 힘으로 어림: (나)에서 힘이 20 N에서 40 N으로 일정하게 늘었으니 평균 30 N × 0.10 m = 3.0 J. 일치합니다(일차함수라 평균이 정확).

흔한 오해

  • "\(W = Fd\)에 끝점의 힘을 넣기": \(200\times0.10\times0.10 = 2.0\) J는 2배로 큽니다. 힘이 변하면 적분합니다.
  • "수직항력도 일을 한다": 운동 방향에 수직인 힘은 일을 하지 않습니다(\(\cos90° = 0\)). 원운동의 구심력도 일을 하지 않아 속력이 일정합니다.
