6.2.1돌림힘

문을 열 때 경첩 가까이를 밀면 잘 안 열리고, 손잡이(멀리)를 수직으로 밀면 잘 열립니다. 물체를 돌리는 효과는 힘의 크기뿐 아니라 축에서의 거리와 방향에 따라 다릅니다.

\[\tau = rF\sin\phi, \qquad \vec\tau = \vec r\times\vec F.\]

\(r\sin\phi\)는 축에서 힘의 작용선까지의 수직 거리(지레팔)입니다. 단위는 N·m. 보통 시계 반대 방향을 양으로 잡습니다.

6.2.2회전의 제2법칙

강체의 각 점에 \(F_{\text{tan}} = ma_{\text{tan}} = mr\alpha\)를 쓰고 \(r\)을 곱해 더하면

정리 6.2.1 \[\sum\tau = I\alpha.\]

\(F = ma\)와 짝을 이룹니다: 힘 ↔ 돌림힘, 질량 ↔ 관성 모멘트, 가속도 ↔ 각가속도. 회전에서 일률은 \(P = \tau\omega\)입니다.

예제 6.2.2

질량 2.0 kg, 반지름 0.10 m인 원판 도르래에 감긴 줄 끝에 1.0 kg 추를 매달고 놓았다. 추의 가속도와 장력은? (줄은 미끄러지지 않음)

풀이. 두 물체의 식을 따로 세웁니다.

  • 추 (아래가 양): \(mg - T = ma\).
  • 도르래: \(TR = I\alpha = \frac12MR^2\cdot\frac aR\), 곧 \(T = \frac12Ma\).

더하면 \(mg = \left(m + \frac M2\right)a\), \(a = \frac{9.8}{2.0} = 4.9\) m/s². \(T = \frac12(2.0)(4.9) = 4.9\) N. 도르래가 가벼우면 자유 낙하(\(a = g\))에 가깝고, 무거우면 느려집니다. 도르래의 관성 모멘트가 "질량 \(\frac M2\)"처럼 작용합니다.

요약
  1. \(\tau = rF\sin\phi\) = 힘 × 지레팔.
  2. \(\sum\tau = I\alpha\). 연결 문제는 물체마다 \(F = ma\) 또는 \(\tau = I\alpha\)를 세우고 \(a = R\alpha\)로 잇는다.

6.2.3연습문제

기본

  1. 길이 0.30 m 렌치 끝에 렌치와 수직으로 50 N을 준다. 돌림힘은?
    답

    15 N·m.

  2. \(I = 0.50\) kg·m²인 바퀴에 2.0 N·m의 돌림힘을 주면 각가속도는?
    답

    4.0 rad/s².

6.2.2

예제돌림힘과 각가속도: τ = Iα로 회전 문제 풀기

질량 있는 도르래 · 문제 해결 전략

다루는 성취기준 [공통3-06-02]

출발점

돌림힘 \(\boldsymbol\tau = \mathbf r\times\mathbf F\), 크기 \(rF\sin\phi = F\times\)(축에서 힘의 작용선까지 수직 거리). 고정축 회전에서 \(\sum\tau = I\alpha\) (제2법칙의 회전판). 각 질점의 접선 방향 \(F_t = m_ir_i\alpha\)에 \(r_i\)를 곱해 더하면 나옵니다.

직선회전
\(x, v, a\)\(\theta, \omega, \alpha\) (\(s = r\theta\), \(v = r\omega\), \(a_t = r\alpha\))
\(m\)\(I\)
\(F = ma\)\(\tau = I\alpha\)
\(K = \frac12mv^2\), \(p = mv\)\(K = \frac12I\omega^2\), \(L = I\omega\)
문제 해결 전략 · 회전
  1. 병진하는 물체는 \(\sum F = ma\), 회전하는 물체는 \(\sum\tau = I\alpha\)를 따로 쓴다.
  2. 회전의 + 방향을 병진의 + 방향과 맞춘다(예: 추가 내려가면 도르래가 시계 방향).
  3. 미끄러지지 않는 조건 \(a = R\alpha\)로 두 운동을 잇는다.
  4. 연립해서 푼다. 질량 없는 도르래 극한(\(I \to 0\))으로 검산.
먼저 예측

도르래에 질량이 있으면, 질량 없는 도르래일 때보다 추가 떨어지는 가속도가 커질까요, 작아질까요? 줄 양쪽의 장력은 같을까요?

예측 확인

작아지고, 양쪽 장력이 달라집니다. 도르래를 돌리는 데 돌림힘(장력의 차)이 필요하기 때문입니다.

반지름 \(R = 0.10\) m, 질량 \(M = 2.0\) kg인 원판 도르래(\(I = \frac12MR^2\))에 감긴 줄 끝에 \(m = 1.0\) kg 추가 매달려 있습니다. 추의 가속도와 장력을 구하세요.

풀이

  1. 추(아래 +): \(mg - T = ma\).
    전략 1.
  2. 도르래: 장력의 돌림힘 \(TR = I\alpha = \frac12MR^2\alpha\).
    축의 힘과 도르래 무게는 축을 지나 돌림힘 0.
  3. \(a = R\alpha\)이므로 \(T = \frac12Ma\).
    전략 3. \(R\)이 소거된다.
  4. \(mg = \left(m + \frac M2\right)a\), \(a = \frac{9.8}{2.0} = 4.9\ \text{m/s}^2\), \(T = 4.9\) N.
    1, 3단계를 더함.

의미

4단계에서 도르래는 "질량 \(\frac M2\)짜리 물체"처럼 행동합니다. 일반적으로 반지름 \(R\)에서 끄는 회전체는 유효 질량 \(\frac{I}{R^2}\)을 더합니다. 이번 예에서 도르래 질량이 추의 2배라 가속도가 \(g\)의 절반으로 줄었습니다.

검산

\(M \to 0\)이면 \(a \to g\), \(T \to 0\) (자유 낙하). 에너지로도: 추가 \(h\) 내려가면 \(mgh = \frac12mv^2 + \frac12I\omega^2 = \frac12\left(m + \frac M2\right)v^2\), 곧 \(v^2 = 2\cdot\frac{mg}{m + M/2}h\), 등가속도 \(a = 4.9\). 일치합니다.
