3.2.1두 가지 마찰

  • 정지 마찰력: 물체가 아직 미끄러지지 않을 때. 미는 힘에 맞춰 크기가 변하며 최댓값이 있다: \(f_s \le \mu_sn\).
  • 운동 마찰력: 미끄러지는 동안. 크기가 거의 일정하다: \(f_k = \mu_kn\).

\(\mu_s\), \(\mu_k\)를 정지·운동 마찰 계수라 하며, 보통 \(\mu_k < \mu_s\)입니다. 무거운 가구를 밀기 시작할 때가 가장 힘들고, 일단 움직이면 조금 쉬워지는 이유입니다. 마찰력은 수직항력 \(n\)에 비례하고, 접촉 넓이와는 거의 상관없습니다.

3.2.2수평면

예제 3.2.1

20 kg 상자를 수평으로 100 N으로 민다. \(\mu_k = 0.30\)일 때 가속도는?

풀이. \(n = mg = 196\) N, \(f_k = 0.30\times196 = 58.8\) N. \(a = \frac{100 - 58.8}{20} = 2.06\) m/s².

3.2.3경사면

경사각 \(\theta\)인 면에서는 축을 면에 평행(\(x\))과 수직(\(y\))으로 잡습니다. 무게를 나누면

  • 면을 따라 아래로: \(mg\sin\theta\).
  • 면에 수직으로 눌러 줌: \(mg\cos\theta\). 따라서 \(n = mg\cos\theta\).
예제 3.2.2

경사각을 서서히 높였더니 25°에서 물체가 미끄러지기 시작했다. \(\mu_s\)는?

풀이. 미끄러지기 직전 \(mg\sin\theta = \mu_smg\cos\theta\), \(\mu_s = \tan25^\circ \approx 0.47\). 질량과 무관합니다.

예제 3.2.3

30° 경사면을 미끄러져 내려가는 물체의 가속도는? (\(\mu_k = 0.20\))

풀이. \(ma = mg\sin30^\circ - \mu_kmg\cos30^\circ\), \(a = 9.8(0.500 - 0.173) \approx 3.2\) m/s².

요약
  1. 정지 마찰 \(f_s \le \mu_sn\) (필요한 만큼), 운동 마찰 \(f_k = \mu_kn\).
  2. 경사면: 축을 면에 맞추고 \(n = mg\cos\theta\).

3.2.4연습문제

기본

  1. \(\mu_s = 0.50\)인 바닥에서 30 kg 상자를 움직이기 시작하려면 최소 몇 N이 필요한가?
    답

    \(0.50\times294 = 147\) N.

응용

  1. 10 m/s로 미끄러지던 하키 퍽이 \(\mu_k = 0.10\)인 얼음에서 멈출 때까지 가는 거리는?
    답

    \(a = -0.98\) m/s². \(d = \frac{100}{2(0.98)} \approx 51\) m.

3.2.2

예제정지 마찰과 운동 마찰: 미끄러지기 전과 후

f_s ≤ μ_s N · f_k = μ_k N · 빗면

다루는 성취기준 [공통3-03-02]

모형

  • 정지 마찰: 미끄러지지 않게 할 만큼만 생기는 힘. 크기는 \(0 \le f_s \le \mu_sN\). 등호는 미끄러지기 직전.
  • 운동 마찰: 미끄러지는 중. \(f_k = \mu_kN\), 방향은 상대 운동의 반대. 보통 \(\mu_k < \mu_s\).
  • 둘 다 경험식(쿨롱 마찰 모형)입니다. 넓이와 속력에 거의 상관없다는 것은 대부분의 마른 표면에서 맞는 근사입니다.

그래서 정지 마찰 문제에서는 "\(f_s = \mu_sN\)"을 바로 쓰지 않습니다. 먼저 정지에 필요한 마찰을 구하고, 그것이 \(\mu_sN\) 이하인지 확인합니다.

질량 10 kg 상자가 경사각 30° 빗면 위에 있습니다. \(\mu_s = 0.40\), \(\mu_k = 0.30\). (가) 상자는 정지해 있을 수 있나요? (나) 미끄러진다면 가속도는? (다) 미끄러지기 시작하는 경사각은?

풀이

  1. 축: 빗면 아래 방향 \(+x\), 빗면에 수직 \(+y\). 중력 성분 \(mg\sin\theta\) (\(+x\)), \(-mg\cos\theta\) (\(y\)).
    가속도가 생긴다면 빗면 방향이므로 그 방향을 축으로.
  2. \(y\): \(N = mg\cos30° = 98(0.866) = 84.9\) N.
    빗면에 수직으로는 가속도 0.
  3. (가) 정지하려면 \(f_s = mg\sin30° = 49\) N 필요. 최대 정지 마찰 \(\mu_sN = 0.40(84.9) = 34.0\) N < 49 N. 정지할 수 없다.
    필요한 마찰과 가능한 최대 마찰을 비교.
  4. (나) 운동 마찰 \(f_k = 0.30(84.9) = 25.5\) N, 빗면 위쪽. \(ma = 49 - 25.5\), \(a = 2.35\ \text{m/s}^2\).
    미끄러지면 운동 마찰.
  5. (다) 미끄러지기 직전 \(mg\sin\theta = \mu_smg\cos\theta\), \(\tan\theta = \mu_s\), \(\theta = \arctan0.40 \approx 21.8°\).
    질량과 \(g\)가 소거된다.

의미

(다)는 \(\mu_s\)를 재는 간단한 실험 방법입니다. 판 위에 물체를 놓고 판을 천천히 기울여 미끄러지는 각을 재면 \(\mu_s = \tan\theta\). 질량과 상관없으므로 무거운 물체와 가벼운 물체가 같은 각에서 미끄러집니다.

검산

\(\mu_k = 0\)이면 \(a = g\sin30° = 4.9\). \(\mu_k = \tan30° = 0.577\)이면 \(a = 0\) (등속). 2.35는 그 사이. 맞습니다.

이해 확인

(가)에서 \(\mu_s = 0.70\)이면 마찰력의 크기는?

답

정지할 수 있으므로(\(0.70\times84.9 = 59.4 > 49\)) 마찰력은 필요한 만큼인 49 N입니다. 59.4 N이 아닙니다.

3.2.3

실습경사면을 얼마나 기울여야 미끄러질까?

실습 · 정지 마찰과 운동 마찰

다루는 성취기준 [공통3-03-02]

목표

경사각과 마찰 계수를 바꿔 물체가 정지하는 조건 \(\tan\theta \le \mu_s\)를 찾고, 미끄러질 때의 가속도 \(g(\sin\theta - \mu_k\cos\theta)\)를 확인합니다. 정지 마찰력이 "필요한 만큼만" 생기는 힘이라는 것을 화살표 길이로 봅니다. 성취기준 [공통3-03-02].

준비

아래 장치에서 화살표는 무게 \(mg\)(검정), 수직항력 \(N\)(파랑), 마찰력 \(f\)(주황)입니다. 길이는 무게를 기준으로 한 상대 크기입니다. 질량은 결과에 영향을 주지 않으므로 조절하지 않습니다.

절차

  1. μs = 0.50에서 경사각을 0°부터 천천히 올리며 주황 화살표(정지 마찰)의 길이가 어떻게 변하는지 본다.
  2. 물체가 미끄러지기 시작하는 각을 찾아 \(\tan^{-1}0.50\)과 비교한다.
  3. 미끄러지는 각에서 재생해 3 m를 내려가는 시간을 기록하고, \(\sqrt{2L/a}\)로 계산한 값과 비교한다.
  4. μk만 바꿔 가며 가속도가 어떻게 변하는지 본다.

기대 결과

  • 정지해 있는 동안 정지 마찰력은 \(mg\sin\theta\)와 같아 각이 커질수록 길어진다. 최댓값 \(\mu_smg\cos\theta\)를 넘는 순간 미끄러진다.
  • μs = 0.50이면 약 26.6°에서 미끄러지기 시작한다.
  • 미끄러지는 순간 마찰력이 \(\mu_kmg\cos\theta\)로 갑자기 작아져 화살표가 짧아진다.

분석

  1. 물체가 정지해 있을 때 마찰력을 \(\mu_sN\)으로 계산하면 왜 틀릴까요?
  2. 각을 올리면 수직항력은 어떻게 변하나요? 그 결과 최대 정지 마찰력은?
  3. μs와 μk가 같다면 미끄러지기 시작한 직후의 가속도는 얼마일까요? 이 장치에서 확인해 보세요.
