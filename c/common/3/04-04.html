4.4.1힘은 퍼텐셜의 기울기

보존력이 \(dx\)만큼 움직이며 한 일 \(F\,dx\)는 퍼텐셜 에너지의 감소 \(-dU\)와 같으므로

\[F(x) = -\frac{dU}{dx}.\]

확인: 용수철 \(U = \frac12kx^2\)이면 \(F = -kx\) (늘이면 되돌리는 힘). 중력 \(U = mgy\)이면 \(F = -mg\) (아래 방향). 그래프로 보면 힘은 언제나 \(U\)가 낮아지는 쪽(내리막)을 향합니다. 공이 언덕을 굴러 내려가는 모습을 떠올리면 됩니다.

4.4.2평형점

  • \(\frac{dU}{dx} = 0\)인 점에서는 힘이 0이다: 평형점.
  • \(U\)가 극소인 점: 조금 벗어나면 되돌아오는 힘. 안정 평형 (골짜기 바닥).
  • \(U\)가 극대인 점: 조금 벗어나면 더 멀어지는 힘. 불안정 평형 (언덕 꼭대기).

4.4.3운동 범위

역학적 에너지 \(E = K + U\)가 일정하고 \(K \ge 0\)이므로 물체는 \(U(x) \le E\)인 곳에서만 움직일 수 있습니다. 그래프에 높이 \(E\)인 수평선을 그으면, \(U\)가 그 아래에 있는 구간이 운동 범위입니다. \(U = E\)인 점에서 \(K = 0\)이 되어 방향을 바꿉니다(반환점).

예제 4.4.1

\(U(x) = x^4 - 2x^2\) (J, \(x\)는 m)이다. 평형점과 그 안정성을 구하고, \(E = -0.50\) J일 때 운동 범위를 구하여라.

풀이. \(\frac{dU}{dx} = 4x^3 - 4x = 4x(x^2 - 1) = 0\)에서 \(x = 0, \pm1\).

  • \(x = 0\): \(U = 0\), 극대. 불안정.
  • \(x = \pm1\): \(U = -1\), 극소. 안정.

\(E = -0.50\)이면 \(x^4 - 2x^2 \le -0.5\), 곧 \(x^2\)이 \(1 - \frac{1}{\sqrt2}\)과 \(1 + \frac{1}{\sqrt2}\) 사이입니다. 오른쪽 골짜기에 있으면 \(0.54 \le x \le 1.31\) m에서 왕복합니다. 가운데 언덕(\(U = 0\))을 넘지 못하므로 왼쪽 골짜기로 갈 수 없습니다. \(E > 0\)이면 언덕을 넘어 양쪽을 오갑니다.

원자 사이의 힘, 분자의 진동, 화학 반응의 활성화 에너지도 같은 그림으로 이해합니다(공통5 화학).

요약
  1. \(F = -dU/dx\): 힘은 \(U\)의 내리막 방향.
  2. \(U\) 극소 = 안정 평형, 극대 = 불안정 평형.
  3. 운동 범위는 \(U(x) \le E\). \(U = E\)에서 방향을 바꾼다.

4.4.4연습문제

기본

  1. \(U = 3x^2 - 2x\) (J)일 때 \(x = 1\) m에서의 힘은?
    답

    \(F = -(6x - 2) = -4\) N.

  2. 예제 4.4.1에서 \(x = 1\)에 정지해 있던 물체가 왼쪽 골짜기로 가려면 최소 얼마의 에너지를 받아야 하는가?
    답

    언덕 높이까지 \(0 - (-1) = 1\) J.

4.4.2

설명퍼텐셜 에너지 곡선 읽기: 평형, 되돌이점, 갇힌 운동

F = −dU/dx · 안정·불안정 평형 · 분자 결합

다루는 성취기준 [공통3-04-04]

왜 필요한가

운동 방정식을 풀지 않고도 \(U(x)\) 그래프 하나로 "어디서 멈추는가", "어디서 되돌아오는가", "어디가 안정한가"를 알 수 있습니다. 분자 결합, 행성 궤도, 진자처럼 식을 풀기 어려운 운동을 이해하는 기본 도구입니다.

그래프 읽는 법

  1. 힘 = 기울기의 반대\(F = -\frac{dU}{dx}\). 기울기가 양수인 곳에서 힘은 \(-x\) 방향, 곧 골짜기 쪽(내리막)으로 향합니다.
  2. 평형점\(\frac{dU}{dx} = 0\)인 점. 극소이면 안정(조금 밀면 되돌아옴), 극대이면 불안정(조금 밀면 멀어짐), 평평한 구간이면 중립.
  3. 허용 영역전체 에너지 \(E\)를 수평선으로 그립니다. \(K = E - U \ge 0\)이므로 운동은 \(U(x) \le E\)인 곳에서만 가능합니다.
  4. 되돌이점\(U(x) = E\)인 점에서 \(K = 0\): 멈췄다가 방향을 바꿉니다. 두 되돌이점 사이에 갇히면 진동합니다.
  5. 속력 읽기\(E\) 선과 곡선 사이의 높이가 운동에너지. 골짜기 바닥에서 가장 빠릅니다.

예: 이원자 분자 (Lennard-Jones 모형)

원자 사이 거리 \(r\)에서 \(U(r) = 4\varepsilon\left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6\right]\). 가까우면 강하게 밀어내고(12제곱 항), 멀면 약하게 당깁니다(6제곱 항).

  1. \(U'(r) = 4\varepsilon\left[-12\frac{\sigma^{12}}{r^{13}} + 6\frac{\sigma^6}{r^7}\right] = 0 \iff r^6 = 2\sigma^6\), \(r_0 = 2^{1/6}\sigma \approx 1.12\sigma\).
    평형 거리(결합 길이).
  2. \(U(r_0) = 4\varepsilon\left[\frac14 - \frac12\right] = -\varepsilon\). 극소라 안정.
    \(\left(\frac\sigma{r_0}\right)^6 = \frac12\).
  3. \(-\varepsilon < E < 0\)이면 두 되돌이점 사이에서 진동(결합 상태). \(E \ge 0\)이면 한쪽 되돌이점만 있어 멀리 날아감(해리). 해리 에너지 \(\varepsilon\).
    \(r \to \infty\)이면 \(U \to 0\).

다른 개념과의 관계

안정 평형 근처에서 \(U(x) \approx U(x_0) + \frac12U''(x_0)(x - x_0)^2\) (공통1의 Taylor 근사). 이것은 용수철 \(\frac12kx^2\)과 같은 꼴이라 작은 진동은 모두 단순 조화 운동이고 \(k = U''(x_0)\)입니다. 6단원 진동의 출발점입니다.

흔한 오해

  • "\(U\) 그래프는 실제 언덕 모양이다." 중력 \(mgy\)일 때만 그렇습니다. 분자의 \(U(r)\)은 거리의 함수일 뿐입니다. 다만 "공이 굴러가는 언덕"으로 상상하는 것은 운동을 예측하는 데 그대로 통합니다.
  • "\(U = 0\)인 곳에서 힘이 0." 힘은 \(U\)의 값이 아니라 기울기로 정해집니다.

확인되돌이점

입자가 \(U(x)\)의 골짜기 안에서 에너지 \(E\)로 진동합니다. 되돌이점에서 입자의 가속도는?

4.4.3

실습퍼텐셜 골짜기에 공을 놓아 보기

실습 · 에너지 그래프, 반환점, 평형

다루는 성취기준 [공통3-04-04]

목표

역학적 에너지 \(E\)를 바꿔 가며 물체가 움직이는 범위 \(U(x) \le E\)와 반환점을 찾고, 힘이 언제나 \(U\)의 내리막(\(F = -dU/dx\))을 향함을 확인합니다. 성취기준 [공통3-04-04].

준비

질량 1 kg인 물체가 그래프의 퍼텐셜 \(U(x)\) 안에서 마찰 없이 움직입니다. 물체는 오른쪽 반환점에서 정지 상태로 출발합니다. 주황 점선이 \(E\), 빨간 막대 길이가 운동 에너지 \(K = E - U\)입니다.

절차

  1. 이중 골짜기에서 \(E\)를 \(-0.5\) J 근처로 두고 재생한다. 물체가 어느 범위에서 왕복하는지 본다.
  2. \(E\)를 조금씩 올려 물체가 가운데 언덕을 넘어 왼쪽 골짜기로 가기 시작하는 \(E\)를 찾는다.
  3. \(E\)를 0 바로 위로 두고 재생해 언덕 꼭대기 근처에서 물체가 어떻게 움직이는지 본다.
  4. 용수철로 바꿔 진폭(반환점)이 \(\sqrt E\)인지 확인한다.

기대 결과

  • \(E < 0\): 오른쪽 골짜기 안에서만 왕복(4.4절 예제의 \(E = -0.5\)이면 0.54 ≤ x ≤ 1.31).
  • \(E > 0\): 언덕(\(U = 0\), 불안정 평형)을 넘어 두 골짜기를 모두 지나간다.
  • \(E\)가 0에 아주 가까우면 언덕 꼭대기에서 아주 느려진다. 정확히 0이면 꼭대기에 무한히 오래 걸려 다가간다.
  • 골짜기 바닥(\(x = \pm1\))에서 가장 빠르고 힘은 0.

분석

  1. 힘 화살표 \(F\)의 방향이 바뀌는 점은 어디인가요? 그 점들이 그래프에서 어떤 특징을 갖나요?
  2. 골짜기 바닥 근처의 작은 진동은 용수철 진동과 비슷합니다. 왜 그럴까요? (바닥 근처의 \(U\)를 이차식으로 근사)
  3. 화학 결합의 원자 사이 퍼텐셜도 이런 골짜기 모양입니다. 결합이 끊어지는 것은 그래프에서 무엇에 해당할까요?

더 해 보기

이중 골짜기의 바닥 근처 작은 진동의 주기를 장치에서 재고, \(U \approx -1 + 4(x - 1)^2\)으로 근사한 용수철 주기 \(2\pi/\sqrt{8} \approx 2.22\) s와 비교해 봅니다(\(k = 8\), \(m = 1\)).
