2.1.1평균 속도와 순간 속도

직선 위를 움직이는 물체의 위치를 \(x(t)\)라 합시다. 시간 \(\Delta t\) 동안 위치가 \(\Delta x\)만큼 변했으면

  • 평균 속도: \(v_{\text{av}} = \frac{\Delta x}{\Delta t}\).
  • 순간 속도: \(v = \lim_{\Delta t\to0}\frac{\Delta x}{\Delta t} = \frac{dx}{dt}\).

속도는 방향(부호)이 있는 양이고, 그 크기가 속력입니다. 이동 거리와 변위도 구분합니다. 3 m 갔다가 3 m 돌아오면 이동 거리는 6 m, 변위는 0입니다.

가속도는 속도가 변하는 비율입니다: \(a = \frac{dv}{dt} = \frac{d^2x}{dt^2}\). 단위는 m/s²입니다. 가속도와 속도의 부호가 같으면 빨라지고, 반대면 느려집니다.

예제 2.1.1

\(x(t) = 20 + 5t^2\) (m, s)일 때 \(t = 1\) s에서 3 s 사이의 평균 속도, \(t = 2\) s의 순간 속도, 가속도를 구하여라.

풀이. \(x(1) = 25\), \(x(3) = 65\)이므로 평균 속도 \(\frac{40}{2} = 20\) m/s. \(v = 10t\)이므로 \(v(2) = 20\) m/s. \(a = 10\) m/s² (일정).

2.1.2그래프 읽기

그래프기울기아래 넓이
위치-시간 (\(x\)-\(t\))속도(쓰지 않음)
속도-시간 (\(v\)-\(t\))가속도변위
가속도-시간 (\(a\)-\(t\))(쓰지 않음)속도 변화

\(v\)-\(t\) 그래프 아래 넓이가 변위인 이유는 \(\Delta x \approx v\Delta t\)를 모두 더한 것이 적분 \(\int v\,dt\)이기 때문입니다. 축 아래(\(v < 0\))의 넓이는 음수로 셉니다.

예제 2.1.2

속도가 0 s에서 4 s까지 0에서 8 m/s로 일정하게 늘고, 4 s에서 6 s까지 8 m/s로 일정하다. 0~6 s의 변위와 0~4 s의 가속도는?

풀이. 넓이: 삼각형 \(\frac12\cdot4\cdot8 = 16\) m + 직사각형 \(2\cdot8 = 16\) m = 32 m. 가속도 = 기울기 \(\frac84 = 2\) m/s².

요약
  1. \(v = dx/dt\), \(a = dv/dt\).
  2. \(x\)-\(t\) 기울기 = 속도, \(v\)-\(t\) 기울기 = 가속도, \(v\)-\(t\) 넓이 = 변위.

2.1.3연습문제

기본

  1. \(x = 3t - t^2\)일 때 물체가 멈추는 순간은?
    답

    \(v = 3 - 2t = 0\), \(t = 1.5\) s.

  2. \(x\)-\(t\) 그래프가 수평선이면 물체는 어떤 상태인가?

2.1.2

설명위치-시간 그래프에서 속도와 가속도 읽기

기울기 · 볼록성 · 넓이

다루는 성취기준 [공통3-02-01]

왜 필요한가

운동을 식으로 쓰기 전에 그래프로 읽을 수 있어야 합니다. 실험에서 얻는 것은 식이 아니라 측정점(그래프)이고, 식이 주어져도 그래프를 그려 보면 부호 실수를 잡을 수 있습니다. 고등학교에서 배운 "기울기 = 속도"를 미분의 언어로 정확히 다시 씁니다.

정의

위치 \(x(t)\)에 대해 평균 속도 \(\bar v = \frac{\Delta x}{\Delta t}\), (순간) 속도 \(v(t) = \frac{dx}{dt}\), 가속도 \(a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2}\). 속력은 \(|v|\).

그래프로 풀어 읽기

  1. \(x\)-\(t\) 그래프의 할선 기울기그 구간의 평균 속도.
  2. 접선 기울기그 순간의 속도. 기울기가 양수면 \(+x\) 방향으로, 0이면 그 순간 멈춤(방향이 바뀌는 점일 수 있음).
  3. 볼록성아래로 볼록(위로 열림)이면 기울기가 커지는 중 → \(a > 0\). 위로 볼록이면 \(a < 0\). 변곡점에서 가속도의 부호가 바뀝니다. 공통1의 \(f''\)과 같은 판정입니다.
  4. \(v\)-\(t\) 그래프의 넓이\(\int_{t_1}^{t_2}v\,dt = \Delta x\) (변위, 부호 있음). 이동 거리는 \(\int|v|\,dt\).

예와 반례

예. \(x(t) = t^3 - 6t^2 + 9t\) (m, s). \(v = 3t^2 - 12t + 9 = 3(t - 1)(t - 3)\), \(a = 6t - 12\).

  • \(t = 1, 3\)에서 \(v = 0\): 방향이 바뀝니다(\(v\)의 부호가 + → − → +).
  • \(t = 2\)에서 \(a = 0\): \(x\)-\(t\) 그래프의 변곡점. \(t < 2\)에서 감속하다 \(t > 2\)에서 가속 방향이 바뀝니다.
  • \(0 \le t \le 4\)에서 변위 \(x(4) - x(0) = 4\) m, 이동 거리는 \(|x(1) - x(0)| + |x(3) - x(1)| + |x(4) - x(3)| = 4 + 4 + 4 = 12\) m.

반례(속도와 가속도의 부호가 다른 경우). \(t = 1.5\)에서 \(v = -2.25\), \(a = -3\): 둘 다 음수라 빨라지는 중입니다. \(t = 2.5\)에서 \(v = -2.25\), \(a = 3\): 부호가 반대라 느려지는 중입니다. "가속도가 음수 = 감속"은 틀립니다.

다른 개념과의 관계

속력이 늘어나는지는 \(\frac{d}{dt}v^2 = 2va\)의 부호, 곧 \(v\)와 \(a\)의 부호가 같은지로 정해집니다. 이것은 3단원에서 일률 \(P = Fv\)로, 공통2의 접선 가속도 \(a_T\)로 이어집니다.

흔한 오해

  • "\(x\)-\(t\) 그래프는 물체가 지나간 길이다." 1차원 운동의 \(x\)-\(t\) 그래프는 길 모양이 아니라 시간에 따른 위치입니다.
  • "속도가 0이면 가속도도 0." 위로 던진 공의 꼭대기에서 \(v = 0\)이지만 \(a = -g\)입니다.

확인꼭대기에서

위로 던진 공이 가장 높은 점에 있는 순간, 공의 가속도는?

2.1.3

실습움직임과 그래프를 맞춰 보기

실습 · 위치-시간 기울기와 속도-시간 넓이

다루는 성취기준 [공통3-02-01]

목표

물체의 움직임과 \(x\)-\(t\), \(v\)-\(t\) 그래프를 동시에 보며, \(x\)-\(t\) 그래프의 기울기가 속도이고 \(v\)-\(t\) 그래프 아래 넓이가 변위임을 확인합니다. 성취기준 [공통3-02-01].

준비

아래 장치는 이 페이지에서 바로 움직입니다. 처음 위치 \(x_0\), 처음 속도 \(v_0\), 가속도 \(a\)를 정하고 재생합니다. 맨 위는 직선 트랙 위의 물체, 가운데는 \(x\)-\(t\) 그래프(주황 선은 그 순간의 접선), 아래는 \(v\)-\(t\) 그래프(색칠한 부분이 넓이)입니다.

절차

  1. \(v_0 = 4\), \(a = -1\)로 재생한다. 물체가 멈췄다가 되돌아오는 순간 \(x\)-\(t\) 그래프와 \(v\)-\(t\) 그래프가 각각 어떻게 생겼는지 본다.
  2. \(a = 0\)으로 바꿔 \(x\)-\(t\) 그래프가 직선이 되는지 확인한다.
  3. 재생 중에 아래 숫자 줄의 "넓이"와 "변위"가 언제나 같은지 확인한다.

기대 결과

  • 되돌아오는 순간(\(t = v_0/|a| = 4\) s): \(x\)-\(t\) 그래프의 꼭짓점(접선이 수평), \(v\)-\(t\) 그래프가 시간축을 지나는 점.
  • \(v < 0\)인 구간의 넓이는 음수로 더해져 변위가 줄어든다.
  • \(a = 0\)이면 \(v\)-\(t\)는 수평선, \(x\)-\(t\)는 기울기 \(v_0\)인 직선.

분석

  1. 속력이 0인 순간에도 가속도는 0이 아닙니다. 그래프의 어느 부분에서 그것을 읽을 수 있나요? (\(v\)-\(t\) 그래프의 기울기)
  2. 이동 거리와 변위가 달라지는 조건은 무엇인가요? 처음 위치로 돌아오는 \(t\)를 계산해 화면과 비교해 보세요.

더 해 보기

\(x_0 = -5\), \(v_0 = 5\), \(a = -2\)로 놓고 물체가 원점을 몇 번, 언제 지나는지 이차방정식으로 먼저 예상한 뒤 재생해 확인합니다.
