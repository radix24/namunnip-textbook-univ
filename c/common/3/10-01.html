10.1.1온도와 열

온도는 물체가 얼마나 뜨거운지를 나타내는 양이고, 열은 온도 차이 때문에 옮겨 가는 에너지입니다. 물체는 열을 "가지고" 있지 않습니다. 물체가 가진 것은 내부 에너지(분자들의 운동 에너지와 위치 에너지의 합)이고, 열은 이동 중인 에너지입니다. 접촉한 두 물체는 온도가 같아질 때까지 열을 주고받습니다(열평형).

과학에서는 절대온도(켈빈, K)를 씁니다: \(T(\text{K}) = T(^\circ\text{C}) + 273.15\). 0 K보다 낮은 온도는 없습니다.

10.1.2비열

질량 \(m\)인 물체의 온도를 \(\Delta T\)만큼 올리는 데 필요한 열은

\[Q = mc\Delta T.\]

\(c\)를 비열이라 합니다. 물은 4190 J/(kg·K)로 아주 큽니다. 그래서 바다는 육지보다 천천히 데워지고 식어 기후를 온화하게 합니다.

예제 10.1.1

90 °C 커피 0.20 kg에 10 °C 물 0.050 kg을 섞었다. 나중 온도는? (둘 다 물의 비열, 열 손실 무시)

풀이. 커피가 잃은 열 = 물이 얻은 열: \(0.20c(90 - T) = 0.050c(T - 10)\). \(18 - 0.20T = 0.050T - 0.5\), \(T = 74\) °C.

10.1.3숨은열

얼음이 녹거나 물이 끓는 동안에는 열을 계속 주어도 온도가 변하지 않습니다. 이 에너지는 분자 사이의 결합을 끊는 데 쓰입니다.

\[Q = mL.\]
  • 물의 녹음열 \(L_f = 3.34\times10^5\) J/kg (0 °C).
  • 물의 기화열 \(L_v = 2.26\times10^6\) J/kg (100 °C).
예제 10.1.2

20 °C 물 1.0 kg을 끓여 모두 수증기로 만드는 데 필요한 열은?

풀이. 100 °C까지 \(1.0\times4190\times80 = 3.35\times10^5\) J, 끓이기 \(2.26\times10^6\) J. 합 약 \(2.6\times10^6\) J. 끓이는 데 데우는 것의 약 7배가 듭니다. 땀이 증발하며 몸을 식히고, 수증기에 데면 같은 온도의 물보다 훨씬 심하게 다치는 이유입니다.

요약
  1. 열 = 온도 차로 옮겨 가는 에너지. \(T(\text{K}) = T(^\circ\text{C}) + 273.15\).
  2. \(Q = mc\Delta T\), 상태 변화 \(Q = mL\). 잃은 열 = 얻은 열.

10.1.4연습문제

기본

  1. 0 °C 얼음 0.10 kg을 녹이는 데 필요한 열은?
    답

    \(3.34\times10^4\) J.

응용

  1. 20 °C 물 0.50 kg에 0 °C 얼음 0.050 kg을 넣었다. 얼음이 모두 녹은 뒤의 온도는?
    답

    \(0.50(4190)(20 - T) = 0.050(3.34\times10^5) + 0.050(4190)T\). \(41900 - 2095T = 16700 + 209.5T\), \(T \approx 10.9\) °C.

10.1.2

예제비열과 숨은열로 열평형 온도 구하기

Q = mcΔT · Q = mL · 상태 변화 확인 · 문제 해결 전략

다루는 성취기준 [공통3-10-01]

출발점

  • 비열 \(c\): 1 kg을 1 K 올리는 데 드는 열. \(Q = mc\Delta T\). 물 \(c = 4186\ \text{J/(kg·K)}\), 얼음 약 2090.
  • 숨은열 \(L\): 온도 변화 없이 상태를 바꾸는 데 드는 열. \(Q = mL\). 얼음의 융해열 \(3.34\times10^5\) J/kg, 물의 기화열 \(2.26\times10^6\) J/kg.
  • 열평형: 단열된 계에서 각 부분이 받은 열의 합 = 0 (에너지 보존).
문제 해결 전략 · 열역학
  1. 계와 경계를 정한다. 열(\(Q\))과 일(\(W\))이 경계를 넘는 방향에 부호 약속을 정한다.
  2. 상태 변화가 있는지 먼저 확인한다(온도가 녹는점·끓는점을 지나는가).
  3. "받은 열 = +"로 통일하고 \(\sum Q = 0\) 또는 \(\Delta U = Q - W\)를 쓴다.
  4. 온도는 켈빈으로 넣어야 하는 식(기체 법칙, 효율, 엔트로피)과 차이만 쓰는 식(\(\Delta T\))을 구별한다.
  5. 답이 처음 온도들 사이에 있는지 등 물리적으로 확인한다.
먼저 예측

20 ℃ 물 200 g에 0 ℃ 얼음 50 g을 넣으면 얼음이 다 녹을까요?

예측 확인

아슬아슬하게 다 녹습니다. 얼음을 다 녹이는 데 16 700 J이 필요하고, 물이 0 ℃까지 식으며 낼 수 있는 열은 16 744 J입니다. 둘이 거의 같아서 결과가 0 ℃ 근처입니다. 아래에서 정확히 계산합니다.

20.0 ℃ 물 200 g에 0 ℃ 얼음 50.0 g을 넣었습니다(용기의 열용량과 열 손실 무시). 나중 상태를 구하세요. 얼음이 −10 ℃였다면?

풀이

  1. 물이 0 ℃까지 식으며 낼 수 있는 열: \(0.200(4186)(20.0) = 16744\) J.
    전략 2: 먼저 최대치를 비교한다.
  2. 얼음을 모두 녹이는 데 필요한 열: \(0.0500(3.34\times10^5) = 16700\) J.
    숨은열.
  3. 16744 > 16700이므로 얼음이 다 녹고 남는 열 44 J로 물 250 g을 올린다: \(\Delta T = \frac{44}{0.250(4186)} \approx 0.04\) ℃.
    나중 온도는 사실상 0 ℃의 물 250 g.
  4. 얼음이 −10 ℃이면 먼저 0 ℃까지 데우는 데 \(0.0500(2090)(10) = 1045\) J가 더 필요하다. 물이 낼 수 있는 16744 J로 녹일 수 있는 얼음은 \(\frac{16744 - 1045}{3.34\times10^5} = 0.0470\) kg. 나중: 0 ℃에서 얼음 3.0 g + 물 247 g.
    평형 온도가 0 ℃에 머문다. \(\sum Q = 0\)을 한 식으로 풀면 0 ℃보다 낮은 온도라는 틀린 답이 나온다.

의미

얼음 50 g을 녹이는 열로 물 50 g을 0 ℃에서 80 ℃까지 데울 수 있습니다(\(\frac{334000}{4186} \approx 80\) K). 숨은열이 크기 때문에 얼음물은 얼음이 남아 있는 동안 0 ℃를 유지합니다. 여름에 얼음을 넣는 이유이고, 온도계 눈금을 맞추는 기준점으로 쓰는 이유입니다.

검산

(가) 0.04 ℃는 0과 20 사이. (나) 남은 얼음이 양수(3 g)이고 녹은 양이 처음 얼음보다 적습니다. 에너지 수지: 1045 + 0.0470(334000) = 16743 J ≈ 물이 낸 16744 J.
