9.3.1중첩과 정상파

두 파동이 같은 곳을 지나면 각 점의 변위는 두 파동의 변위의 합입니다(중첩 원리). 파동끼리 부딪혀 튕겨 나가지 않고 서로 통과합니다.

줄의 고정된 끝에서 반사된 파동이 들어오는 파동과 겹치면, 같은 진폭으로 반대 방향으로 가는 두 파동의 합이 됩니다.

\[A\sin(kx - \omega t) + A\sin(kx + \omega t) = 2A\sin kx\cos\omega t.\]

모양 \(\sin kx\)는 움직이지 않고 제자리에서 위아래로만 진동합니다. 이것이 정상파입니다.

  • 마디: \(\sin kx = 0\)인 점. 전혀 움직이지 않는다. 간격은 \(\frac\lambda2\).
  • 배: 진폭 \(2A\)로 가장 크게 움직이는 점.

9.3.2고정된 줄의 고유 진동수

길이 \(L\)인 줄의 양 끝은 고정되어 있으므로 마디여야 합니다. 그러려면 줄 길이가 반 파장의 정수배여야 합니다.

\[L = n\frac{\lambda_n}{2}, \qquad f_n = \frac{v}{\lambda_n} = n\frac{v}{2L}, \quad n = 1, 2, 3, \dots\]

\(f_1 = \frac{v}{2L}\)을 기본 진동수, \(f_n = nf_1\)을 \(n\)번째 배음(조화 진동수)이라 합니다. 기타나 바이올린의 음높이는 기본 진동수로 정해지고, 배음의 섞인 비율이 음색을 정합니다.

예제 9.3.1

길이 0.65 m인 기타 줄의 기본 진동수가 440 Hz이다. 줄의 파동 속력과 셋째 배음은?

풀이. \(v = 2Lf_1 = 2(0.65)(440) = 572\) m/s. \(f_3 = 1320\) Hz.

줄을 조이면(장력 증가) \(v = \sqrt{F/\mu}\)가 커져 음이 높아지고, 손가락으로 눌러 길이를 줄여도 높아집니다. 굵은 줄(\(\mu\) 큼)은 낮은 음을 냅니다.

이 결과는 공통9(고등미적분학(2))에서 파동방정식을 변수분리로 풀어 다시 얻습니다.

요약
  1. 중첩: 변위를 더한다. 반대 방향 두 파의 합 = 정상파 \(2A\sin kx\cos\omega t\).
  2. 양 끝 고정: \(L = n\lambda/2\), \(f_n = nv/(2L)\).

9.3.2

예제줄과 관의 정상파: 끝 조건이 고유 진동수를 정한다

마디 · 배 · 열린관 · 닫힌관

다루는 성취기준 [공통3-09-03]

정상파는 무엇인가

같은 진동수의 두 파동이 반대 방향으로 겹치면 \(A\sin(kx - \omega t) + A\sin(kx + \omega t) = 2A\sin kx\cos\omega t\) (삼각함수의 합 → 곱). 모양이 움직이지 않고 제자리에서 커졌다 작아집니다. \(\sin kx = 0\)인 곳은 늘 정지(마디), 진폭이 최대인 곳이 배. 마디 사이 간격은 \(\frac\lambda2\).

양 끝에서 반사된 파동이 계속 겹치므로, 끝 조건을 만족하는 파장만 살아남습니다.

계끝 조건허용 파장진동수
양 끝 고정 줄, 양쪽 열린 관양 끝 같은 종류(마디-마디, 배-배)\(L = n\frac\lambda2\)\(f_n = \frac{nv}{2L}\), \(n = 1, 2, 3, \dots\)
한쪽 닫힌 관닫힌 끝 마디, 열린 끝 배\(L = (2n - 1)\frac\lambda4\)\(f = \frac{(2n-1)v}{4L}\): 홀수배만

(가) 길이 0.65 m, 선밀도 \(1.2\times10^{-3}\) kg/m인 기타 줄의 기본 진동수가 196 Hz(G3)가 되려면 장력이 얼마여야 하나요? (나) 길이 0.30 m인 관이 양쪽 열린 경우와 한쪽 닫힌 경우의 기본 진동수를 비교하세요(\(v = 343\) m/s).

풀이

  1. (가) 기본(\(n = 1\)): \(\lambda = 2L = 1.30\) m. 필요한 파속 \(v = \lambda f = 1.30\times196 = 254.8\) m/s.
    양 끝 고정: 줄 길이에 반 파장 하나.
  2. \(v = \sqrt{F_T/\mu}\)에서 \(F_T = \mu v^2 = 1.2\times10^{-3}\times(254.8)^2 \approx 77.9\) N.
    줄의 파속 공식.
  3. (나) 양쪽 열림: \(f_1 = \frac{343}{2(0.30)} = 572\) Hz.
    배-배: 반 파장.
  4. 한쪽 닫힘: \(f_1 = \frac{343}{4(0.30)} = 286\) Hz. 절반(한 옥타브 낮음). 배음은 858, 1430 Hz (홀수배)뿐.
    마디-배: 4분의 1 파장.

의미

같은 길이라도 끝을 막으면 한 옥타브 낮아지고 짝수 배음이 빠져 음색이 달라집니다. 클라리넷(한쪽 닫힌 관에 가까움)이 같은 길이의 플루트(양쪽 열림)보다 한 옥타브 낮고 독특한 소리를 내는 이유입니다. 기타는 손가락으로 줄 길이를 줄여 \(f \propto \frac1L\)로 음을 올리고, 줄감개로 장력을 바꿔 \(f \propto \sqrt{F_T}\)로 조율합니다.

검산

78 N은 약 8 kg의 무게로, 실제 기타 줄 장력(줄당 50~120 N)의 범위입니다. 단위: \(\text{kg/m}\times(\text{m/s})^2 = \text{N}\).

이해 확인

(가)의 줄을 12번째 프렛(줄 길이의 절반)에서 누르면 진동수는?

답

392 Hz, 한 옥타브 위(G4). 길이가 절반이면 진동수가 2배.

9.3.3

유도Doppler 효과: 다가오면 높게, 멀어지면 낮게

f′ = f(v ± v_o)/(v ∓ v_s) · 구급차 · 레이더

다루는 성취기준 [공통3-09-03]

무엇을 유도하나

공기에 대해 음원이 속력 \(v_s\), 관측자가 \(v_o\)로 움직일 때 관측 진동수 \(f' = f\dfrac{v + v_o}{v - v_s}\). 부호는 "서로 가까워지는 방향이면 \(f'\)이 커지도록" (관측자가 다가오면 \(+v_o\), 음원이 다가오면 \(-v_s\)).

모형과 가정

  • 소리는 공기에 대해 \(v\)로 퍼진다(바람 없음). 음원과 관측자는 둘을 잇는 직선 위에서 움직인다.
  • \(v_s < v\) (음속보다 느림).

유도

  1. 음원이 움직임: 음원은 마루 하나를 낸 뒤 다음 마루를 내기까지 \(T = \frac1f\) 동안 앞으로 \(v_sT\) 간다.
    진동수 \(f\)는 음원 자신의 진동.
  2. 그래서 앞쪽 마루 간격(파장)은 \(\lambda' = vT - v_sT = \frac{v - v_s}{f}\)로 줄어든다.
    마루는 공기 중에서 \(v\)로 가고 음원이 따라붙는다.
  3. 관측자가 움직임: 관측자가 \(v_o\)로 다가오면 마루를 만나는 상대 속력이 \(v + v_o\).
    공기에 대한 소리 속도 \(v\)는 그대로, 관측자가 마중 나감.
  4. 관측 진동수 = 만나는 속력 / 파장 \(= \dfrac{v + v_o}{(v - v_s)/f} = f\dfrac{v + v_o}{v - v_s}\).
    2, 3단계를 합침.

두 효과는 대칭이 아닙니다. 음원의 움직임은 파장을 바꾸고, 관측자의 움직임은 만나는 빈도를 바꿉니다. 매질(공기)이 기준이 되기 때문입니다.

예제

700 Hz 사이렌을 울리며 30 m/s로 달리는 구급차가 정지한 사람을 지나갑니다. 다가올 때와 멀어질 때 들리는 진동수는? (\(v = 343\) m/s)

  1. 다가올 때: \(f' = 700\frac{343}{343 - 30} = 767\) Hz.
    \(v_o = 0\), 음원이 다가옴 → 분모에서 뺌.
  2. 멀어질 때: \(f' = 700\frac{343}{343 + 30} = 644\) Hz.
    멀어짐 → 분모에 더함.

지나가는 순간 약 123 Hz, 반음 세 개 정도 뚝 떨어집니다(\(\frac{767}{644} \approx 1.19\), 반음 하나는 1.059배).

결과 확인

  • \(v_s, v_o \ll v\)이면 \(\frac{\Delta f}{f} \approx \frac{v_o + v_s}{v}\) (선형 근사). 속력이 작으면 누가 움직이든 상대 속력만 중요.
  • \(v_s \to v\)이면 \(f' \to \infty\): 앞쪽 마루가 겹쳐 충격파(소닉 붐)가 생깁니다. 모형의 한계.

한계와 확장

빛은 매질이 없으므로 이 식을 쓰지 않고 상대성 이론의 Doppler 식 \(f' = f\sqrt{\frac{1 + \beta}{1 - \beta}}\) (\(\beta = \frac{v_{\text{상대}}}{c}\))을 씁니다. 속력이 느리면 \(\frac{\Delta f}{f} \approx \beta\)로 같아집니다. 천문학의 적색편이, 경찰의 속도 측정기, 의료 초음파 혈류 측정이 모두 이 효과입니다.

9.3.4

실습기타 줄의 정상파 만들기

실습 · 배음, 장력, 선밀도

다루는 성취기준 [공통3-09-03]

목표

길이 1 m인 줄의 장력, 선밀도, 배음 번호를 바꿔 고유 진동수 \(f_n = \frac{n}{2L}\sqrt{T/\mu}\)를 확인합니다. 정상파가 반대 방향으로 가는 두 진행파의 합이라는 것을 그림으로 봅니다. 성취기준 [공통3-09-03].

준비

파란 굵은 선이 줄의 모양, 빨간 점이 마디입니다. "두 진행파 보기"를 켜면 오른쪽으로 가는 파(주황)와 왼쪽으로 가는 파(회색)가 함께 그려집니다. 실제 진동수는 수백 Hz이므로 화면에서는 아주 느리게 보여 줍니다.

절차

  1. n을 1부터 6까지 바꾸며 마디 수와 진동수를 기록한다.
  2. n = 1에서 장력을 100 N에서 400 N으로 바꿔 진동수가 몇 배가 되는지 본다.
  3. 장력은 그대로 두고 선밀도를 4배로 바꿔 본다.
  4. "두 진행파 보기"를 켜고, 두 파가 서로 지우는 점과 보강하는 점을 찾는다.

기대 결과

  • 마디 수는 \(n + 1\), 진동수는 기본 진동수의 \(n\)배.
  • 장력 4배 → 속력과 진동수 2배(한 옥타브 위). 선밀도 4배 → 진동수 절반.
  • 마디에서는 두 진행파가 언제나 크기가 같고 부호가 반대여서 합이 0.

분석

  1. 기타의 굵은 줄과 가는 줄은 같은 길이인데 왜 다른 음을 낼까요?
  2. 줄의 한가운데를 손가락으로 살짝 대고 튕기면 기본음이 사라지고 한 옥타브 높은 음이 납니다(하모닉스). 이 장치의 어느 n에 해당할까요?
  3. 파장과 진동수 중 장력을 바꿀 때 변하지 않는 것은 무엇인가요?

더 해 보기

휴대폰 주파수 분석 앱으로 기타나 고무줄 소리를 녹음하면 기본 진동수와 그 정수배 봉우리들이 보입니다. 봉우리 높이의 비가 음색입니다.
