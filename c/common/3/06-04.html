6.4.1

유도Doppler 효과: 다가오면 높게, 멀어지면 낮게

f′ = f(v ± v_o)/(v ∓ v_s) · 구급차 · 레이더

다루는 성취기준 [공통3-06-04]

무엇을 유도하나

공기에 대해 음원이 속력 \(v_s\), 관측자가 \(v_o\)로 움직일 때 관측 진동수 \(f' = f\dfrac{v + v_o}{v - v_s}\). 부호는 "서로 가까워지는 방향이면 \(f'\)이 커지도록" (관측자가 다가오면 \(+v_o\), 음원이 다가오면 \(-v_s\)).

모형과 가정

  • 소리는 공기에 대해 \(v\)로 퍼진다(바람 없음). 음원과 관측자는 둘을 잇는 직선 위에서 움직인다.
  • \(v_s < v\) (음속보다 느림).

유도

  1. 음원이 움직임: 음원은 마루 하나를 낸 뒤 다음 마루를 내기까지 \(T = \frac1f\) 동안 앞으로 \(v_sT\) 간다.
    진동수 \(f\)는 음원 자신의 진동.
  2. 그래서 앞쪽 마루 간격(파장)은 \(\lambda' = vT - v_sT = \frac{v - v_s}{f}\)로 줄어든다.
    마루는 공기 중에서 \(v\)로 가고 음원이 따라붙는다.
  3. 관측자가 움직임: 관측자가 \(v_o\)로 다가오면 마루를 만나는 상대 속력이 \(v + v_o\).
    공기에 대한 소리 속도 \(v\)는 그대로, 관측자가 마중 나감.
  4. 관측 진동수 = 만나는 속력 / 파장 \(= \dfrac{v + v_o}{(v - v_s)/f} = f\dfrac{v + v_o}{v - v_s}\).
    2, 3단계를 합침.

두 효과는 대칭이 아닙니다. 음원의 움직임은 파장을 바꾸고, 관측자의 움직임은 만나는 빈도를 바꿉니다. 매질(공기)이 기준이 되기 때문입니다.

예제

700 Hz 사이렌을 울리며 30 m/s로 달리는 구급차가 정지한 사람을 지나갑니다. 다가올 때와 멀어질 때 들리는 진동수는? (\(v = 343\) m/s)

  1. 다가올 때: \(f' = 700\frac{343}{343 - 30} = 767\) Hz.
    \(v_o = 0\), 음원이 다가옴 → 분모에서 뺌.
  2. 멀어질 때: \(f' = 700\frac{343}{343 + 30} = 644\) Hz.
    멀어짐 → 분모에 더함.

지나가는 순간 약 123 Hz, 반음 세 개 정도 뚝 떨어집니다(\(\frac{767}{644} \approx 1.19\), 반음 하나는 1.059배).

결과 확인

  • \(v_s, v_o \ll v\)이면 \(\frac{\Delta f}{f} \approx \frac{v_o + v_s}{v}\) (선형 근사). 속력이 작으면 누가 움직이든 상대 속력만 중요.
  • \(v_s \to v\)이면 \(f' \to \infty\): 앞쪽 마루가 겹쳐 충격파(소닉 붐)가 생깁니다. 모형의 한계.

한계와 확장

빛은 매질이 없으므로 이 식을 쓰지 않고 상대성 이론의 Doppler 식 \(f' = f\sqrt{\frac{1 + \beta}{1 - \beta}}\) (\(\beta = \frac{v_{\text{상대}}}{c}\))을 씁니다. 속력이 느리면 \(\frac{\Delta f}{f} \approx \beta\)로 같아집니다. 천문학의 적색편이, 경찰의 속도 측정기, 의료 초음파 혈류 측정이 모두 이 효과입니다.
