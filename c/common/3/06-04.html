6.4.1각운동량

운동량 \(\vec p\)의 회전판이 각운동량입니다.

  • 입자: \(\vec L = \vec r\times\vec p\).
  • 고정축 둘레로 도는 강체: \(L = I\omega\).

\(\vec F = \frac{d\vec p}{dt}\)에 대응해 \(\sum\vec\tau = \frac{d\vec L}{dt}\)가 성립합니다.

6.4.2보존

정리 6.4.1 (각운동량 보존)

외부 돌림힘의 합이 0이면 계의 전체 각운동량은 일정하다.

예제 6.4.2 (피겨 스케이팅)

팔을 벌린 스케이터의 관성 모멘트가 4.0 kg·m²이고 초당 1.0바퀴 돈다. 팔을 모아 1.6 kg·m²가 되면?

풀이. \(4.0\times1.0 = 1.6\omega\), \(\omega = 2.5\)바퀴/초. 운동 에너지 \(\frac12I\omega^2 = \frac{L^2}{2I}\)는 2.5배로 늘어납니다. 늘어난 에너지는 팔을 안으로 당길 때 근육이 한 일입니다. 각운동량은 보존되지만 운동 에너지는 보존되지 않습니다.

예제 6.4.3

질량 100 kg, 반지름 2.0 m인 원판 회전목마가 2.0 rad/s로 돈다. 25 kg 아이가 가장자리에 수직으로 뛰어올랐다. 나중 각속도는?

풀이. \(I_1 = \frac12(100)(4.0) = 200\) kg·m², 아이 추가 후 \(I_2 = 200 + 25(4.0) = 300\). \(200\times2.0 = 300\omega\), \(\omega = 1.33\) rad/s. 5.3절의 완전 비탄성 충돌과 같은 상황입니다.

행성이 태양에 가까울 때 빨리 도는 것(8.2절 케플러 제2법칙), 회전하는 팽이와 자이로스코프가 쓰러지지 않는 것, 중성자별이 빠르게 도는 것도 각운동량 보존으로 설명합니다.

요약
  1. \(\vec L = \vec r\times\vec p\), 강체는 \(L = I\omega\). \(\sum\vec\tau = d\vec L/dt\).
  2. 외부 돌림힘이 0이면 \(I\omega\) 일정: \(I\)가 줄면 \(\omega\)가 는다.

6.4.3연습문제

기본

  1. 2.0 kg 입자가 반지름 3.0 m 원을 4.0 m/s로 돈다. 각운동량의 크기는?
    답

    \(rmv = 24\) kg·m²/s.

응용

  1. 예제 6.4.3에서 잃은 운동 에너지는?
    답

    전 \(\frac12(200)(4) = 400\) J, 후 \(\frac12(300)(1.78) = 267\) J. 약 133 J.

6.4.2

설명각운동량 보존: 팔을 오므리면 왜 빨라지나

L = Iω · τ = dL/dt · 케플러 제2법칙

다루는 성취기준 [공통3-06-04]

왜 필요한가

피겨 선수가 팔을 오므리는 동안 몸의 모양(\(I\))이 바뀌므로 \(\tau = I\alpha\)를 그대로 쓸 수 없습니다. 바깥에서 돌림힘이 없을 때 변하지 않는 양, 각운동량을 쓰면 모양이 어떻게 바뀌든 처음과 끝을 이을 수 있습니다. 운동량 보존(4단원)의 회전판입니다.

정의

질점의 각운동량 \(\mathbf L = \mathbf r\times\mathbf p\). 고정축 둘레로 회전하는 강체는 \(L = I\omega\). 회전의 제2법칙: \(\sum\boldsymbol\tau_{\text{외}} = \dfrac{d\mathbf L}{dt}\).

정의를 풀어 읽기

  1. \(\frac{d\mathbf L}{dt} = \boldsymbol\tau\)의 근거\(\frac{d}{dt}(\mathbf r\times\mathbf p) = \mathbf v\times m\mathbf v + \mathbf r\times\mathbf F = \mathbf r\times\mathbf F\). 첫 항은 평행한 벡터의 외적이라 0 (공통2 1-02, 3-01의 곱의 법칙).
  2. 내력의 돌림힘두 질점 사이 힘이 서로를 잇는 직선 방향이면 그 돌림힘은 짝지어 상쇄됩니다. 그래서 외부 돌림힘만 남습니다.
  3. 보존외부 돌림힘이 0이면 \(\mathbf L\)이 일정. 강체가 아니어도(모양이 바뀌어도) 성립합니다.

예

  • 피겨 회전: 팔을 펴서 \(I_1 = 4.0\ \text{kg·m}^2\), 1회전/s에서 팔을 오므려 \(I_2 = 1.6\ \text{kg·m}^2\)이 되면 \(\omega_2 = \frac{I_1}{I_2}\omega_1 = 2.5\)회전/s. 회전 운동에너지는 \(\frac{K_2}{K_1} = \frac{I_1}{I_2} = 2.5\)배로 늘어납니다. 늘어난 에너지는 선수가 팔을 안으로 당기며 한 일입니다.
  • 케플러 제2법칙: 태양의 중력은 태양을 향하므로 \(\mathbf r\times\mathbf F = \mathbf 0\), 행성의 각운동량이 일정. 짧은 시간에 쓸고 지나는 넓이 \(\frac12|\mathbf r\times d\mathbf r| = \frac{L}{2m}dt\)이므로 "같은 시간에 같은 넓이". 태양에 가까울 때 빠릅니다.
  • 반례(보존되지 않는 경우): 바퀴를 손으로 돌리기 시작할 때, 바닥 마찰로 팽이가 느려질 때. 외부 돌림힘이 있습니다.

다른 개념과의 관계

회전하는 의자 위에서 돌고 있는 바퀴의 축을 뒤집으면 의자가 돌기 시작합니다. 사람+바퀴+의자 계의 수직 각운동량이 보존되기 때문입니다. 각운동량이 벡터라는 점은 팽이의 세차 운동, 자전거의 안정성으로 이어집니다(역학 과목).

흔한 오해

  • "각운동량이 보존되니 회전 운동에너지도 보존된다." 위 피겨 예처럼 에너지는 2.5배가 됩니다. 반대로 회전하는 원판 위에 다른 원판을 떨어뜨려 붙이면(회전의 비탄성 충돌) 에너지가 줄어듭니다.
  • "직선으로 움직이는 물체는 각운동량이 없다." 기준점이 직선 위에 있지 않으면 \(\mathbf r\times\mathbf p \ne \mathbf 0\)입니다.
