3.2.1반응 지수

평형이 아닌 아무 순간의 농도를 평형 상수식에 넣은 값을 반응 지수 \(Q\)라 합니다. \(Q\)와 \(K\)를 비교하면 계가 평형에 도달하기 위해 어느 쪽으로 진행할지 알 수 있습니다.

  • \(Q < K\): 생성물이 모자란다. 정반응 쪽으로 진행.
  • \(Q = K\): 평형.
  • \(Q > K\): 생성물이 너무 많다. 역반응 쪽으로 진행.
예제 3.2.1

3.1절 반응(\(K_c = 50.5\))에서 [H₂] = 0.50, [I₂] = 0.50, [HI] = 4.0 M인 혼합물은 어느 쪽으로 진행하는가?

풀이. \(Q = \frac{4.0^2}{0.50\times0.50} = 64 > 50.5\). HI가 분해되는 역반응 쪽으로 진행합니다.

\(Q\)는 6단원의 \(\Delta G = \Delta G^\circ + RT\ln Q\)에서 다시 나옵니다. \(Q < K\)이면 \(\Delta G < 0\)이 되어 정반응이 자발적입니다.

요약
  1. \(Q\) = 지금 농도로 계산한 평형 상수식.
  2. \(Q < K\) 정반응, \(Q > K\) 역반응.

3.2.2연습문제

기본

  1. 생성물만 넣고 시작하면 \(Q\)는? 어느 쪽으로 진행하는가?
    답

    \(Q = \infty\) (분모 0). 역반응 쪽.
