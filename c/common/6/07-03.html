이 절에서 배울 것
  • 네른스트 식으로 농도에 따른 전지 전위를 구한다.
  • 농도차 전지와 전지가 닳는 이유를 이해한다.
먼저 알아야 할 것
  • 표준 환원 전위 (7.2절), \(\Delta G = \Delta G^\circ + RT\ln Q\) (6.3절).

왜 필요한가

표준 환원 전위 표는 모든 농도가 1 M일 때의 값입니다. 그런데 실제 전지 안의 농도는 쓰는 동안 계속 바뀌고, 다 쓴 전지는 전압이 0이 됩니다. 몸속 신경 세포는 이온 농도 차이만으로 전압을 만들고, pH 미터는 전압으로 수소 이온 농도를 잽니다. 농도와 전압을 잇는 식이 네른스트 식입니다.

7.3.1네른스트 식

\(\Delta G = \Delta G^\circ + RT\ln Q\)에 \(\Delta G = -nFE\)를 넣으면

\[E = E^\circ - \frac{RT}{nF}\ln Q = E^\circ - \frac{0.0592\ \text{V}}{n}\log Q\quad(25\ ^\circ\text{C}).\]
예제 7.3.1

다니엘 전지에서 [Zn²⁺] = 1.0 M, [Cu²⁺] = 0.010 M이면 전위는?

풀이. \(Q = \frac{[\text{Zn}^{2+}]}{[\text{Cu}^{2+}]} = 100\). \(E = 1.10 - \frac{0.0592}{2}\log100 = 1.04\) V.

전지를 쓰면 반응물이 줄고 생성물이 늘어 \(Q\)가 커지므로 전위가 점점 떨어지고, \(Q = K\)가 되면 \(E = 0\)(평형, 다 닳은 전지)입니다.

7.3.2농도차 전지

같은 전극 두 개를 농도가 다른 용액에 넣어도 \(E^\circ = 0\)이지만 \(E \ne 0\)인 전지가 됩니다. 예: Cu | Cu²⁺(0.010 M) ‖ Cu²⁺(1.0 M) | Cu는 \(E = 0 - \frac{0.0592}{2}\log0.010 = 0.059\) V. 신경 세포의 막전위와 pH 미터가 이 원리입니다(유리 전극이 \(\text{H}^+\) 농도에 따른 전위를 잼).

7.3.3평형 상수와 pH 측정

전지가 다 닳으면 \(E = 0\), \(Q = K\)이므로 네른스트 식에서 \(E^\circ = \frac{0.0592}{n}\log K\), 곧 \(\log K = \frac{nE^\circ}{0.0592}\)입니다. 전압을 재면 아주 크거나 작은 평형 상수도 구할 수 있습니다.

예제 7.3.2

다니엘 전지(\(E^\circ = 1.10\) V, \(n = 2\))의 반응 \(\text{Zn} + \text{Cu}^{2+} \to \text{Zn}^{2+} + \text{Cu}\)의 평형 상수를 구하여라.

풀이. \(\log K = \frac{2\times1.10}{0.0592} = 37.2\), \(K \approx 10^{37}\)입니다. 평형에서 \([\text{Zn}^{2+}]/[\text{Cu}^{2+}] = 10^{37}\)이므로 구리 이온은 사실상 남지 않습니다. 농도로 직접 재기는 불가능한 값을 전압 1.10 V 하나로 얻었습니다.

수소 전극 \(2\text{H}^+ + 2e^- \to \text{H}_2\)에 네른스트 식을 쓰면(\(P_{\text{H}_2} = 1\) atm) \(E = -\frac{0.0592}{2}\log\frac{1}{[\text{H}^+]^2} = -0.0592\,\text{pH}\)입니다. pH가 1 오를 때마다 전위가 59 mV씩 내려가므로, 전위를 재면 pH를 알 수 있습니다. pH 미터의 유리 전극은 이 관계를 이용합니다.

흔한 오해

"큰 전지가 작은 전지보다 전압이 높다"는 틀립니다. \(E\)는 농도와 온도로 정해지는 세기 성질이라, 같은 반응이면 AA 건전지와 D 건전지의 전압이 똑같이 1.5 V입니다. 크기가 키우는 것은 흘릴 수 있는 전하량(용량)입니다. 반쪽 반응에 2를 곱해도 \(E^\circ\)를 2배 하지 않는 것도 같은 이유입니다.

요약
  1. \(E = E^\circ - (0.0592/n)\log Q\) (25 °C).
  2. 평형에서 \(E = 0\). 농도 차이만으로도 전위가 생긴다.

7.3.4연습문제

기본

  1. 다니엘 전지에서 [Zn²⁺] = 0.010 M, [Cu²⁺] = 1.0 M이면 전위는?
    답

    \(1.10 + 0.0592 = 1.16\) V.

응용

  1. 다니엘 전지에서 [Zn²⁺] = 1.0 M일 때 전위가 1.00 V로 떨어졌다. 이때 [Cu²⁺]는?
    답

    \(\log Q = \frac{2\times0.10}{0.0592} = 3.38\), \(Q = 2.4\times10^3\), \([\text{Cu}^{2+}] = 4.2\times10^{-4}\) M.

  2. 신경 세포 안의 \(\text{K}^+\)가 140 mM, 밖이 5.0 mM이다. 37 °C(\(\frac{2.303RT}{F} = 0.0615\) V)에서 이 농도 차이가 만드는 전위차는?
    답

    \(0.0615\times\log\frac{140}{5.0} = 0.089\) V, 약 89 mV.

7.3.2

실습농도에 따른 전지 전위

실습 · 네른스트 식

다루는 성취기준 [공통6-07-02] [공통6-07-03]

목표

두 반쪽 전지의 이온 농도를 바꿔 전위 \(E\)가 \(\log Q\)에 따라 직선으로 변하는 것을 확인하고, \(E = 0\)이 되는 곳이 평형(\(Q = K\))임을 봅니다. 성취기준 [공통6-07-02], [공통6-07-03].

준비

조절기는 농도의 로그값입니다(−2는 0.01 M). 파란 직선은 \(E = E^\circ - \frac{0.0592}{n}\log Q\)(25 °C), 빨간 점은 지금 상태, 주황 점은 \(E = 0\)인 곳입니다(그림 범위 안에 있을 때).

절차

  1. 다니엘 전지에서 [Zn²⁺] = 1 M, [Cu²⁺] = 0.01 M일 때 전위를 읽는다(7.3절 예제).
  2. 두 농도를 바꿔 \(Q\)가 10배 될 때마다 \(E\)가 얼마씩 줄어드는지 본다.
  3. 농도차 전지로 바꾸고 두 농도가 같을 때와 100배 차이 날 때를 비교한다.
  4. 농도차 전지에서 왼쪽 농도를 오른쪽보다 크게 해 본다.

기대 결과

  • \(E = 1.10 - 0.0296 \times 2 = 1.04\) V.
  • \(n = 2\)이면 \(Q\)가 10배 될 때마다 0.0296 V씩 줄어든다.
  • 농도차 전지는 농도가 같으면 0 V, 오른쪽이 100배 진하면 0.059 V.
  • 왼쪽이 더 진하면 \(E < 0\): 반대 방향으로 전류가 흐른다.
  • 다니엘 전지의 \(\log K \approx 37\)이라 실제 범위에서는 \(E\)가 거의 0이 되지 않는다.

분석

  1. 전지를 쓰면 \(Q\)가 어느 쪽으로 움직이는지, 그래프 위에서 빨간 점이 어느 방향으로 가는지 설명해 보세요.
  2. Cu | Ag 전지에서 \(\log Q\)를 계산할 때 \([\text{Ag}^+]\)가 제곱으로 들어가는 이유를 반응식으로 말해 보세요.

더 해 보기

pH 미터는 수소 이온의 농도차로 생기는 전위를 잽니다. \(n = 1\)인 농도차 전지에서 pH가 1 달라질 때 전위가 몇 V 달라지는지 계산해 보세요.
