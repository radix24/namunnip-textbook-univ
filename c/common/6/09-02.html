9.2.1d 오비탈의 분리

자유로운 금속 이온의 d 오비탈 다섯 개는 에너지가 같습니다. 팔면체 착물에서 리간드는 \(x, y, z\)축 위에서 다가옵니다. 축 방향을 향한 두 오비탈(\(d_{x^2-y^2}\), \(d_{z^2}\), \(e_g\))의 전자는 리간드 전자와 더 많이 반발해 에너지가 오르고, 축 사이를 향한 세 오비탈(\(d_{xy}, d_{yz}, d_{xz}\), \(t_{2g}\))은 낮아집니다. 두 무리의 에너지 차이를 결정장 분리 에너지 \(\Delta_o\)라 합니다.

9.2.2고스핀과 저스핀

\(d^4\)~\(d^7\) 이온에서는 전자를 넣는 방법이 두 가지입니다.

  • \(\Delta_o\)가 작으면(약한 장 리간드): 위의 \(e_g\)에도 하나씩 먼저 넣는다. 홀전자가 많은 고스핀.
  • \(\Delta_o\)가 짝짓기 에너지보다 크면(강한 장 리간드): 아래 \(t_{2g}\)를 먼저 짝지어 채운다. 저스핀.

리간드를 \(\Delta\)가 커지는 순으로 늘어놓은 것이 분광 화학 계열입니다: \(\text{I}^- < \text{Cl}^- < \text{F}^- < \text{H}_2\text{O} < \text{NH}_3 < \text{en} < \text{CN}^- < \text{CO}\).

예제 9.2.1

\([\text{Fe}(\text{H}_2\text{O})_6]^{2+}\)와 \([\text{Fe}(\text{CN})_6]^{4-}\)의 홀전자 수는?

풀이. 둘 다 \(\text{Fe}^{2+}\), \(d^6\). 물은 약한 장: \(t_{2g}^4e_g^2\), 홀전자 4(상자성). \(\text{CN}^-\)은 강한 장: \(t_{2g}^6\), 홀전자 0(반자성). 같은 금속 이온이라도 리간드에 따라 자성이 달라집니다.

요약
  1. 팔면체: \(t_{2g}\)(낮음 3개), \(e_g\)(높음 2개), 차이 \(\Delta_o\).
  2. 약한 장 → 고스핀(홀전자 많음), 강한 장 → 저스핀.

9.2.3연습문제

기본

  1. \([\text{Co}(\text{NH}_3)_6]^{3+}\)(저스핀 \(d^6\))은 상자성인가?
    답

    \(t_{2g}^6\), 홀전자 없음. 반자성.

9.2.2

실습결정장 분리, 자성, 색

실습 · 고스핀과 저스핀

다루는 성취기준 [공통6-09-02] [공통6-09-03]

목표

팔면체 착물의 d 전자 수, 분리 에너지 \(\Delta_o\), 짝짓기 에너지 \(P\)를 바꿔 전자 배치(고스핀·저스핀), 홀전자 수, 흡수하는 빛의 파장과 보이는 색을 함께 봅니다. 성취기준 [공통6-09-02], [공통6-09-03].

준비

아래 세 칸이 \(t_{2g}\), 위 두 칸이 \(e_g\)이고 두 줄 사이의 간격이 \(\Delta_o\)입니다. \(\Delta_o > P\)면 저스핀, 작으면 고스핀으로 채웁니다. 흡수 파장은 \(\lambda = \frac{hcN_A}{\Delta_o}\)로 구하며, 실제 착물의 흡수 띠는 넓고 여러 개일 수 있어 색은 대략적인 예측입니다.

절차

  1. \(d^6\), \(\Delta_o\) = 150(약한 장)에서 홀전자 수를 읽는다. \(\Delta_o\)를 천천히 올려 배치가 바뀌는 지점을 찾는다.
  2. \(d^3\)과 \(d^8\)에서도 \(\Delta_o\)를 바꿔 배치가 바뀌는지 본다.
  3. \(d^1\)로 놓고 \(\Delta_o\) = 239로 맞춰 흡수 파장과 색을 읽는다(9.3절 예제).
  4. \(d^0\)과 \(d^{10}\)을 본다.

기대 결과

  • \(d^6\) 고스핀은 \(t_{2g}^4e_g^2\), 홀전자 4. \(\Delta_o\)가 \(P\)를 넘으면 \(t_{2g}^6\), 홀전자 0(반자성).
  • \(d^1\)~\(d^3\), \(d^8\)~\(d^{10}\)은 \(\Delta_o\)와 상관없이 배치가 하나뿐이다.
  • 239 kJ/mol → 약 500 nm(초록) 흡수, 보라(자주)색으로 보인다.
  • \(d^0\), \(d^{10}\)은 d-d 전이가 없어 무색이다.

분석

  1. \(\Delta_o\)를 키우면 흡수 파장과 보이는 색이 어느 쪽으로 이동하는지, 분광 화학 계열(\(\text{H}_2\text{O} < \text{NH}_3 < \text{CN}^-\))과 이어 설명해 보세요.
  2. \(\text{Zn}^{2+}\) 화합물이 대부분 흰색인 이유를 말해 보세요.
