2.2.1

예제표준화 점수로 서로 다른 자료 비교하기

z = (x − x̄)/s · 단위 없애기 · 문제 해결 전략

다루는 성취기준 [공통7-02-02]

정의와 뜻

\(z = \dfrac{x - \bar x}{s}\): 평균에서 표준편차 몇 개만큼 떨어졌는가. 단위가 사라져(점, kg, 초가 모두 "표준편차 개수"가 됨) 다른 척도의 값끼리 비교할 수 있습니다. 모든 값을 표준화하면 평균 0, 표준편차 1인 자료가 됩니다(모양은 그대로).

문제 해결 전략 · 자료 요약
  1. 먼저 그래프를 그려 모양과 이상값을 본다.
  2. 대칭이면 평균·표준편차, 치우쳤거나 이상값이 있으면 중앙값·IQR로 요약한다.
  3. 다른 척도의 값을 비교할 때는 \(z\)점수나 백분위로 바꾼다.
  4. 요약한 수가 자료의 실제 모습과 맞는지 그래프로 다시 확인한다.

민지는 수학 시험(평균 62, 표준편차 12)에서 80점, 영어 시험(평균 75, 표준편차 5)에서 85점을 받았습니다. 어느 과목을 상대적으로 더 잘 봤나요? 분포가 대략 정규분포라면 각각 상위 몇 %인가요?

풀이

  1. 수학 \(z = \frac{80 - 62}{12} = 1.5\).
    평균보다 표준편차 1.5개 위.
  2. 영어 \(z = \frac{85 - 75}{5} = 2.0\).
    평균보다 표준편차 2개 위.
  3. 영어가 상대적으로 더 잘 봤다.
    원점수는 영어가 5점 높을 뿐이지만, 영어는 점수가 덜 퍼져 있어 10점 차이가 더 드물다.
  4. 정규분포라면 \(z = 1.5\)는 상위 약 6.7%, \(z = 2.0\)은 상위 약 2.3%.
    표준정규분포표(05-02 카드).

의미

수능의 표준점수가 이 생각을 씁니다. 과목마다 난이도가 달라 원점수를 그대로 더하면 불공평하므로, \(z\)점수를 바꿔(평균 100, 표준편차 20 등) 비교합니다. 공학에서는 측정값이 평균에서 몇 \(\sigma\) 벗어났는지로 불량을 판단합니다("6시그마").

검산

\(z\)의 단위: (점 − 점)/점 = 단위 없음. 평균인 학생은 \(z = 0\), 그래서 두 시험의 \(z = 0\)인 점수(62, 75)를 비교하는 것은 의미가 없고, 각 시험 안에서의 위치만 비교합니다.

이해 확인

키 평균 172 cm, 표준편차 6 cm인 집단에서 \(z = -1.5\)인 사람의 키는?

답

\(172 - 1.5\times6 = 163\) cm.
