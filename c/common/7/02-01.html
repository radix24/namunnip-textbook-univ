2.1중심과 퍼짐의 측도

먼저 알아야 할 것
  • 분포의 모양 (1.2절), 시그마 기호 \(\sum\) (고교 수학I).

2.1.1중심

  • 평균: \(\bar x = \frac1n\sum x_i\). 자료의 무게중심.
  • 중앙값: 크기순으로 늘어놓았을 때 가운데 값(짝수 개면 가운데 두 값의 평균).
  • 최빈값: 가장 자주 나온 값.

2.1.2퍼짐

  • 범위: 최댓값 − 최솟값.
  • 사분위수: 아래에서 25%인 값 \(Q_1\), 75%인 값 \(Q_3\). 사분위수 범위 IQR \(= Q_3 - Q_1\)은 가운데 절반이 퍼진 폭.
  • 분산: \(s^2 = \frac{1}{n - 1}\sum(x_i - \bar x)^2\). 평균에서 떨어진 정도의 제곱 평균.
  • 표준편차: \(s = \sqrt{s^2}\). 원래 자료와 단위가 같다.

표본분산에서 \(n\)이 아니라 \(n - 1\)로 나누는 이유: \(\bar x\)가 자료 자신에 맞춰 계산되어 편차 제곱합이 실제보다 조금 작게 나오므로 이를 보정합니다(이렇게 해야 표본분산의 평균이 모분산과 같아집니다).

2.1.3이상값의 영향

예제 2.1.1

자료 2, 4, 4, 5, 7, 8, 40의 평균, 중앙값, 표준편차를 구하고, 40을 뺐을 때와 비교하여라.

풀이. 평균 \(\frac{70}{7} = 10\), 중앙값 5, 표준편차 약 13.4. 40을 빼면 평균 5, 중앙값 4.5, 표준편차 약 2.2. 값 하나 때문에 평균은 두 배, 표준편차는 여섯 배가 되었지만 중앙값은 거의 그대로입니다. 중앙값과 IQR처럼 이상값에 흔들리지 않는 측도를 로버스트하다고 합니다. 소득처럼 치우친 자료는 중앙값을 함께 보고합니다.

2.1.4상자그림

최솟값, \(Q_1\), 중앙값, \(Q_3\), 최댓값(다섯 수치 요약)을 상자와 수염으로 그린 것입니다. \(Q_1 - 1.5\,\text{IQR}\)보다 작거나 \(Q_3 + 1.5\,\text{IQR}\)보다 큰 값은 이상값으로 따로 점을 찍습니다. 여러 집단을 나란히 비교할 때 좋습니다.

요약
  1. 중심: 평균(이상값에 민감), 중앙값(로버스트).
  2. 퍼짐: 표준편차(\(n - 1\)로 나눔), IQR(로버스트).
  3. 상자그림과 1.5 IQR 규칙으로 이상값을 찾는다.

2.1.5연습문제

기본

  1. 3, 5, 7의 표본분산과 표준편차는?
    답

    평균 5, 편차 제곱합 8, \(s^2 = 4\), \(s = 2\).

  2. 자료의 모든 값에 10을 더하면 평균과 표준편차는?
    답

    평균 10 증가, 표준편차 그대로.

2.1.2

예제중심과 퍼짐의 측도: 이상값 하나가 바꾸는 것

평균 · 중앙값 · 표준편차 · IQR · 저항성

다루는 성취기준 [공통7-02-01]

정의와 성질

  • 평균 \(\bar x = \frac1n\sum x_i\). 표준편차 \(s = \sqrt{\frac{1}{n-1}\sum(x_i - \bar x)^2}\).
  • 중앙값: 크기순으로 늘어놓은 가운데 값. 사분위수 \(Q_1, Q_3\), 사분위범위 IQR = \(Q_3 - Q_1\).
  • 저항성: 극단값 하나에 크게 흔들리지 않는 성질. 중앙값과 IQR은 저항적, 평균과 표준편차는 아닙니다.
  • \(n - 1\)로 나누는 이유: 편차의 합이 0이라 \(n\)개 중 \(n - 1\)개만 자유롭고, 이렇게 나누면 \(s^2\)이 모분산의 치우치지 않은 추정량이 됩니다(5단원).
먼저 예측

직원 9명의 월급이 300만 원 근처인 회사에 사장(월급 5000만 원)을 넣어 계산하면 평균과 중앙값 중 무엇이 크게 바뀔까요?

예측 확인

평균이 크게 바뀌고, 중앙값은 거의 그대로입니다.

월급(만 원) 자료 280, 290, 300, 300, 310, 320, 330, 340, 350에 대해 평균, 중앙값, 표준편차, IQR을 구하세요. 그다음 5000을 더한 10개 자료로 다시 구하고 비교하세요.

풀이

  1. 9개: 합 2820, \(\bar x = 313.3\). 중앙값(5번째) 310.
    \(n = 9\) 홀수.
  2. 편차 제곱합: \(33.3^2 + 23.3^2 + 13.3^2 + 13.3^2 + 3.3^2 + 6.7^2 + 16.7^2 + 26.7^2 + 36.7^2 = 4400\). \(s = \sqrt{4400/8} = 23.5\).
    \(n - 1 = 8\)로 나눔.
  3. \(Q_1\) = 아래 4개(280, 290, 300, 300)의 중앙값 295, \(Q_3\) = 위 4개(320, 330, 340, 350)의 중앙값 335. IQR = 40.
    중앙값을 뺀 양쪽 절반의 중앙값(교재마다 규칙이 조금 다름).
  4. 10개(5000 추가): \(\bar x = 7820/10 = 782\). 중앙값 = 5, 6번째의 평균 \(\frac{310 + 320}{2} = 315\).
    \(n = 10\) 짝수.
  5. \(s \approx 1482\). \(Q_1 = 300\), \(Q_3 = 340\), IQR = 40.
    편차 제곱합의 대부분이 \((5000 - 782)^2\) 하나에서 온다.

의미

평균은 313에서 782로 2.5배, 표준편차는 약 63배가 됐지만, 중앙값은 5, IQR은 0 바뀌었습니다. 평균 782만 원은 10명 중 누구의 월급과도 닮지 않았습니다. 치우친 분포나 이상값이 있으면 중앙값과 IQR로 요약하고, 대칭 분포면 평균과 표준편차가 계산과 이론(정규분포)에 편리합니다. "평균 소득"보다 "중위 소득"이 정책에 쓰이는 이유입니다.

검산

상자그림 기준으로 5000은 \(Q_3 + 1.5\times\text{IQR} = 340 + 60 = 400\)을 훨씬 넘으므로 이상값으로 표시됩니다. 평균이 중앙값보다 크다는 것은 오른쪽 꼬리와 일치합니다.

2.1.3

실습값 하나를 끌어당겨 보기

실습 · 이상값과 로버스트한 측도

다루는 성취기준 [공통7-02-01]

목표

자료 7개 가운데 한 값(빨간 점)을 크게 바꾸며 평균, 표준편차, 중앙값, IQR이 각각 얼마나 흔들리는지 비교합니다. 상자그림에서 이상값이 표시되는 기준을 확인합니다. 성취기준 [공통7-02-01].

준비

위쪽 점들이 자료, 아래가 상자그림입니다. 빨간 점선은 평균입니다. 나머지 6개 값은 2, 4, 4, 5, 7, 8로 고정되어 있습니다.

절차

  1. 값을 9에서 40, 60으로 바꾸며 네 측도를 기록한다(2.1절 예제는 40).
  2. 이상값으로 표시되기 시작하는 값을 찾는다.
  3. 값을 0으로 내려 작은 쪽 이상값도 확인한다.

기대 결과

  • 값을 크게 할수록 평균과 표준편차는 계속 커지지만, 중앙값과 IQR은 거의 그대로다.
  • \(Q_3 + 1.5\,\text{IQR}\)을 넘으면 상자그림에 따로 점이 찍힌다.

분석

  1. 평균은 값 하나가 끝없이 끌고 갈 수 있지만, 중앙값을 끝없이 움직이려면 자료의 몇 %를 바꿔야 할까요?
  2. 이상값을 발견하면 무조건 지워야 할까요? 입력 실수와 실제로 드문 값을 어떻게 구별할 수 있을까요?

더 해 보기

가장 큰 값과 가장 작은 값을 하나씩 빼고 평균을 내는 "절사 평균"을 손으로 계산해, 이상값에 얼마나 강한지 비교해 보세요.
