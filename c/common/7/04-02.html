4.2.1조합

서로 다른 \(n\)개 가운데 순서를 생각하지 않고 \(k\)개를 고르는 방법의 수는

\[\binom nk = \frac{n!}{k!(n - k)!}, \qquad n! = n(n - 1)\cdots2\cdot1.\]

예: 5명 중 2명을 뽑는 방법은 \(\frac{5\cdot4}{2\cdot1} = 10\)가지.

4.2.2이항분포

다음 조건을 만족하는 시행을 \(n\)번 할 때 성공 횟수 \(X\)는 이항분포 \(B(n, p)\)를 따릅니다.

  • 결과가 성공과 실패 둘뿐이다.
  • 매번 성공 확률이 \(p\)로 같다.
  • 시행들은 서로 독립이다.
\[P(X = k) = \binom nkp^k(1 - p)^{n - k}, \qquad k = 0, 1, \dots, n.\]

이유: 성공 \(k\)번, 실패 \(n - k\)번이 나오는 특정한 순서 하나의 확률은 \(p^k(1 - p)^{n - k}\)이고, 성공이 몇 번째에 나오는지 고르는 방법이 \(\binom nk\)가지입니다.

정리 4.2.1

\(X \sim B(n, p)\)이면 \(E(X) = np\), \(\text{Var}(X) = np(1 - p)\).

한 번의 시행은 평균 \(p\), 분산 \(p(1 - p)\)이고, 독립인 \(n\)번을 더했기 때문입니다.

예제 4.2.2

불량률이 30%인 공정에서 10개를 뽑는다. 불량품이 정확히 3개일 확률, 2개 이하일 확률, 평균과 표준편차는?

풀이. \(P(X = 3) = \binom{10}{3}(0.3)^3(0.7)^7 = 120\times0.027\times0.0824 \approx 0.267\). \(P(X \le 2) = P(0) + P(1) + P(2) \approx 0.028 + 0.121 + 0.233 = 0.383\). 평균 3, 표준편차 \(\sqrt{2.1} \approx 1.45\). 엑셀 =BINOM.DIST(3, 10, 0.3, FALSE), R dbinom(3, 10, 0.3), 누적은 pbinom(2, 10, 0.3).

요약
  1. \(P(X = k) = \binom nkp^k(1 - p)^{n - k}\). 조건: 두 결과, 같은 \(p\), 독립.
  2. 평균 \(np\), 분산 \(np(1 - p)\).

4.2.2

예제이항분포: n번 중 k번 성공할 확률

P(X = k) = C(n,k) p^k (1−p)^(n−k) · 조건 확인 · μ = np

다루는 성취기준 [공통7-04-02]

조건과 식

(1) 시행 횟수 \(n\)이 정해져 있고 (2) 각 시행은 성공/실패 둘 중 하나 (3) 성공 확률 \(p\)가 매번 같고 (4) 시행끼리 독립이면, 성공 횟수 \(X\sim B(n, p)\):

\[P(X = k) = \binom nk p^k(1 - p)^{n-k}, \qquad \mu = np, \quad \sigma = \sqrt{np(1 - p)}.\]

근거: 특정 순서(예: 처음 \(k\)번 성공)의 확률은 독립이라 \(p^k(1-p)^{n-k}\)이고, 성공이 들어갈 자리를 고르는 방법이 \(\binom nk\)가지입니다. 평균은 시행마다 성공 개수의 기대값 \(p\)를 \(n\)번 더한 것, 분산도 독립이라 \(p(1-p)\)를 \(n\)번 더한 것입니다.

객관식 10문항(보기 5개)을 모두 찍을 때 (가) 정확히 3개 맞힐 확률 (나) 6개 이상 맞혀 통과할 확률 (다) 맞힌 개수의 평균과 표준편차

풀이

  1. 조건 확인: \(n = 10\), 맞음/틀림, \(p = 0.2\), 문항끼리 독립(찍기). \(X\sim B(10, 0.2)\).
    네 조건을 먼저 확인.
  2. (가) \(\binom{10}{3}(0.2)^3(0.8)^7 = 120\times0.008\times0.2097 = 0.201\).
    이항 식.
  3. (나) \(P(X \ge 6) = \sum_{k=6}^{10}\binom{10}{k}0.2^k0.8^{10-k} = 0.00551 + 0.00079 + 0.00007 + \cdots \approx 0.0064\).
    \(k = 6\): \(210\times0.000064\times0.4096 = 0.0055\), \(k = 7\): \(120\times0.0000128\times0.512 = 0.00079\).
  4. (다) \(\mu = 2\), \(\sigma = \sqrt{10\times0.2\times0.8} = 1.26\).
    공식.

의미

찍어서 통과할 확률은 약 0.6%로 160명 중 1명 꼴입니다. 반대로 어떤 학생이 6개 이상 맞혔다면 "찍었다"는 설명은 그럴듯하지 않습니다. 이것이 7단원 가설검정의 생각입니다(p값 = 0.0064).

검산

스프레드시트 =BINOM.DIST(3,10,0.2,FALSE) = 0.2013, =1-BINOM.DIST(5,10,0.2,TRUE) = 0.0064. 모든 \(k\)의 확률 합이 1인지는 이항정리 \((p + (1 - p))^n = 1\)이 보장합니다.

흔한 오해

  • 비복원 추출에 이항분포: 상자 20개 중 불량 5개에서 4개를 꺼내면 매번 확률이 바뀌어 독립이 아닙니다(초기하분포). 모집단이 표본보다 훨씬 크면(10배 이상) 이항으로 근사해도 됩니다.
4.2.3

실습이항분포의 모양과 두 근사

실습 · 포아송 근사, 정규 근사

다루는 성취기준 [공통7-04-02] [공통7-04-03]

목표

\(n\)과 \(p\)를 바꿔 이항분포의 모양을 보고 누적확률을 구합니다. \(n\)이 크고 \(p\)가 작을 때의 포아송 근사, \(np\)와 \(n(1 - p)\)가 클 때의 정규 근사가 얼마나 잘 맞는지 확인합니다. 성취기준 [공통7-04-02], [공통7-04-03].

준비

막대가 \(P(X = k)\)이고, 진한 막대가 \(k \le a\)인 부분(누적확률)입니다. 주황 점은 같은 평균의 포아송 분포, 빨간 곡선은 같은 평균과 분산의 정규분포입니다.

절차

  1. 4.2절 예제(\(n = 10\), \(p = 0.3\), \(a = 2\))의 누적확률을 확인한다.
  2. \(p\)를 0.1, 0.5, 0.9로 바꿔 분포가 치우치는 방향을 본다.
  3. \(n = 100\), \(p = 0.02\)로 놓고 포아송 점을 켜 본다.
  4. \(n = 100\), \(p = 0.5\)로 놓고 정규 곡선을 켜서 누적확률과 정규 근사를 비교한다.

기대 결과

  • \(P(X \le 2) \approx 0.383\).
  • \(p < 0.5\)면 오른쪽 꼬리, \(p > 0.5\)면 왼쪽 꼬리, 0.5면 대칭.
  • \(n = 100\), \(p = 0.02\)에서는 포아송(\(\lambda = 2\)) 점이 막대와 거의 겹친다.
  • \(n = 100\), \(p = 0.5\)에서는 정규 곡선이 막대 끝을 잘 따라가고, 연속성 보정한 근사값이 정확한 값과 소수 셋째 자리 정도까지 맞는다.

분석

  1. 정규 근사에서 \(P(X \le a)\)를 \(a + 0.5\)까지의 넓이로 구하는(연속성 보정) 이유를 막대의 폭으로 설명해 보세요.
  2. \(n = 10\), \(p = 0.05\)에서는 정규 근사가 잘 맞지 않습니다. \(np\)를 계산해 이유를 말해 보세요.
