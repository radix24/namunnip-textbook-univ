3.1.1표본공간과 사건

  • 시행: 결과가 우연에 따라 정해지는 실험이나 관찰(주사위 던지기).
  • 표본공간 \(S\): 일어날 수 있는 모든 결과의 집합. 주사위면 \(\{1, 2, 3, 4, 5, 6\}\).
  • 사건: 표본공간의 부분집합. "짝수가 나온다" \(= \{2, 4, 6\}\).

사건 \(A\)의 확률 \(P(A)\)는 0과 1 사이의 수입니다. 모든 결과가 똑같이 일어날 법하면 \(P(A) = \frac{A\text{의 결과 수}}{S\text{의 결과 수}}\)입니다. 일반적으로는 같은 시행을 아주 많이 되풀이할 때 \(A\)가 일어나는 비율이 다가가는 값(상대도수의 극한)으로 이해합니다.

3.1.2법칙

  • 여사건: \(P(A^c) = 1 - P(A)\). "적어도 하나"를 구할 때 편리하다.
  • 덧셈 법칙: \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\). 겹친 부분을 두 번 세지 않게 뺀다. 동시에 일어날 수 없으면(배반) \(P(A\cap B) = 0\).
  • 독립: 한 사건이 일어나도 다른 사건의 확률이 바뀌지 않으면 \(P(A\cap B) = P(A)P(B)\).
예제 3.1.1

카드 52장에서 한 장을 뽑을 때 하트이거나 그림 카드(J, Q, K)일 확률은?

풀이. \(P(\text{하트}) = \frac{13}{52}\), \(P(\text{그림}) = \frac{12}{52}\), 겹치는 하트 그림 카드 3장. \(\frac{13 + 12 - 3}{52} = \frac{22}{52} \approx 0.42\).

예제 3.1.2

주사위를 네 번 던질 때 6이 적어도 한 번 나올 확률은?

풀이. 여사건 "네 번 모두 6이 아님"은 독립인 시행의 곱으로 \(\left(\frac56\right)^4 \approx 0.482\). 따라서 \(1 - 0.482 = 0.518\). 직관과 달리 절반을 조금 넘습니다.

배반과 독립은 다릅니다. 확률이 0보다 큰 두 사건이 배반이면 하나가 일어나면 다른 하나는 절대 일어나지 않으므로, 오히려 강하게 의존하는 관계입니다.

요약
  1. \(P(A^c) = 1 - P(A)\), \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\).
  2. 독립이면 \(P(A\cap B) = P(A)P(B)\). "적어도 하나"는 여사건으로.

3.1.3연습문제

기본

  1. 동전을 세 번 던져 앞면이 적어도 한 번 나올 확률은?
    답

    \(1 - \frac18 = \frac78\).

  2. \(P(A) = 0.5\), \(P(B) = 0.4\), \(A, B\)가 독립일 때 \(P(A\cup B)\)는?
    답

    \(0.5 + 0.4 - 0.2 = 0.7\).

3.1.2

예제덧셈 법칙과 곱셈 법칙으로 확률 계산하기

여사건 · 배반 · 독립 · 생일 문제 · 문제 해결 전략

다루는 성취기준 [공통7-03-01]

규칙

  • 여사건: \(P(A^c) = 1 - P(A)\).
  • 덧셈: \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\). 겹치는 부분을 두 번 셌으므로 뺍니다. 배반(동시에 일어날 수 없음)이면 마지막 항이 0.
  • 곱셈: \(P(A\cap B) = P(A)P(B\mid A)\). 독립(\(P(B\mid A) = P(B)\))이면 \(P(A)P(B)\).
문제 해결 전략 · 확률
  1. 표본공간(가능한 모든 결과)과 사건을 말로 정확히 쓴다.
  2. "적어도 하나"는 여사건("하나도 없음")으로 바꾼다.
  3. "또는"은 덧셈(겹침 확인), "그리고"는 곱셈(독립 확인)을 쓴다.
  4. 복잡하면 나무 그림이나 2×2 표를 그린다(03-02 카드).
  5. 답이 0과 1 사이인지, 극단의 경우에 맞는지 확인한다.
먼저 예측

23명이 모인 방에서 생일이 같은 사람이 적어도 한 쌍 있을 확률은 대략 얼마일까요? 5%? 20%? 50%?

예측 확인

약 50.7%입니다. 사람 수가 아니라 쌍의 수(253쌍)가 중요하기 때문입니다.

(가) 23명 중 생일이 같은 사람이 적어도 한 쌍 있을 확률(1년 = 365일, 모두 같은 확률, 독립) (나) 부품 하나의 고장 확률이 0.02이고 독립일 때, 부품 50개가 모두 작동해야 하는 장치가 고장 날 확률

풀이

  1. (가) 여사건: 23명 모두 생일이 다름. 첫 사람 아무 날, 둘째는 남은 364일, …
    전략 2. "적어도 한 쌍"을 직접 세면 경우가 너무 많다.
  2. \(P(\text{모두 다름}) = \frac{365}{365}\cdot\frac{364}{365}\cdots\frac{343}{365} \approx 0.493\).
    곱셈 법칙(조건부: 앞사람들과 겹치지 않을 확률).
  3. \(P(\text{적어도 한 쌍}) = 1 - 0.493 = 0.507\).
    여사건.
  4. (나) 모두 작동할 확률 \(0.98^{50} = 0.364\). 고장 확률 \(1 - 0.364 = 0.636\).
    독립이라 곱한다. 부품 하나는 98% 믿을 만해도 50개가 모두 필요하면 64% 확률로 고장.

의미

두 예 모두 "작은 확률도 기회가 많으면 크게 쌓인다"는 것을 보여 줍니다. 공학에서 직렬 연결 장치의 신뢰도가 급격히 떨어지는 이유, 그래서 중요한 부품을 병렬(여분)로 두는 이유입니다. 생일 문제는 암호학에서 해시 충돌을 찾는 공격의 이름(생일 공격)이 되었습니다.

검산

(나) 근사: 고장 확률이 작고 독립이면 \(1 - 0.98^{50} \approx 1 - e^{-1} = 0.632\). 거의 같습니다. (가) 23명이 이룰 수 있는 쌍 \(\binom{23}{2} = 253\)개, 각 쌍이 같을 확률 \(\frac{1}{365}\)이라 \(1 - e^{-253/365} = 0.50\).
