10단원은 2026학년도 진도표에는 없고, 2학년 과목으로 넘어가기 위해 보완한 단원입니다.

10.1.1상관계수

공부 시간과 점수처럼 두 변수를 한 사람씩 짝지어 점으로 찍은 것이 산점도입니다. 점들이 직선 주위에 얼마나 모여 있는지를 수로 나타낸 것이 상관계수입니다.

\[r = \frac{1}{n - 1}\sum\left(\frac{x_i - \bar x}{s_x}\right)\left(\frac{y_i - \bar y}{s_y}\right).\]
  • \(-1 \le r \le 1\). 부호가 방향(오른쪽 위로 올라가면 양), 크기가 직선에 가까운 정도.
  • 단위와 무관하다(z점수의 곱의 평균).
  • 직선 관계만 잰다. \(y = x^2\)처럼 분명한 곡선 관계도 \(r \approx 0\)일 수 있다.
  • 이상값 하나에 크게 흔들린다. 반드시 산점도를 먼저 본다.
예제 10.1.1

공부 시간 \(x\) = 1, 2, 3, 4, 5, 6시간, 점수 \(y\) = 52, 55, 61, 64, 70, 72점의 상관계수는?

풀이. 계산하면(또는 엑셀 CORREL, R cor(x, y)) \(r \approx 0.993\). 매우 강한 양의 직선 관계입니다.

10.1.2상관은 인과가 아니다

아이스크림 판매량과 물놀이 사고는 양의 상관이 있지만, 아이스크림이 사고를 일으키지는 않습니다. 둘 다 기온이라는 제3의 변수(교란 변수) 때문에 함께 늘어납니다. 관찰 자료에서 상관이 보여도 원인이라고 말하려면 다른 설명을 배제해야 하고, 가장 확실한 방법은 무작위 배정 실험입니다.

10.1.3손으로 계산해 보기, 그리고 이상값

공식의 각 항 \(\frac{x_i - \bar x}{s_x}\cdot\frac{y_i - \bar y}{s_y}\)는 점이 평균점 \((\bar x, \bar y)\)의 오른쪽 위나 왼쪽 아래에 있으면 양수, 나머지 두 사분면에 있으면 음수입니다. 그래서 \(r\)은 "평균점을 기준으로 같은 방향에 놓인 점이 얼마나 많고 멀리 있는가"를 잽니다. 실제 계산은 다음 꼴이 편합니다.

\[r = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i - \bar x)^2\,\sum(y_i - \bar y)^2}}\]
예제 10.1.2

\(x\) = 1, 2, 3, 4, 5, \(y\) = 2, 4, 5, 4, 5의 상관계수를 손으로 구하여라.

풀이. \(\bar x = 3\), \(\bar y = 4\). 편차는 \(x\): −2, −1, 0, 1, 2, \(y\): −2, 0, 1, 0, 1입니다. 곱의 합 \(4 + 0 + 0 + 0 + 2 = 6\), \(\sum(x - \bar x)^2 = 10\), \(\sum(y - \bar y)^2 = 6\)이므로 \(r = \frac{6}{\sqrt{60}} = 0.775\)입니다.

이 자료에 점 \((12, 1)\) 하나만 더하면 \(r = -0.510\)으로 부호까지 바뀝니다. 다른 점들과 멀리 떨어진 점은 편차가 커서 곱의 합을 혼자 좌우하기 때문입니다. 숫자만 보지 말고 산점도를 먼저 그려야 하는 이유입니다.

흔한 오해

"\(r = 0\)이면 두 변수는 관계가 없다"는 틀립니다. \(x\) = −2, −1, 0, 1, 2와 \(y = x^2\)은 \(y\)가 \(x\)로 완전히 정해지는데도 \(r = 0\)입니다. \(r\)은 직선 관계만 잽니다. 또 "\(r = 0.8\)은 \(r = 0.4\)보다 두 배 강하다"도 틀립니다. 설명하는 변동의 비율 \(r^2\)으로 보면 0.64와 0.16, 네 배 차이입니다.

요약
  1. \(r\)은 직선 관계의 방향과 강도, \(-1\)에서 1.
  2. 산점도를 먼저 보고, 상관을 인과로 해석하지 않는다.

10.1.4연습문제

기본

  1. 키를 cm에서 m로 바꾸면 키와 몸무게의 상관계수는?
    답

    그대로.

응용

  1. 모든 학생의 점수에 5점을 더하고 2배를 했다. 공부 시간과 점수의 상관계수는 어떻게 되는가? 점수에 −1을 곱하면?
    답

    앞의 경우 그대로. −1을 곱하면 부호만 바뀐다.

  2. 여러 나라에서 1인당 초콜릿 소비량과 노벨상 수상자 수의 상관이 높게 나왔다. 초콜릿이 노벨상을 늘린다고 말할 수 없는 이유와 가능한 교란 변수를 하나 들어라.
    답

    관찰 자료의 상관은 인과를 보여 주지 않는다. 예: 국민 소득(부유한 나라일수록 초콜릿 소비와 연구 투자가 모두 많다).

10.1.2

예제상관계수를 계산하고 인과와 구별하기

r = Σz_x z_y/(n−1) · 직선 관계만 · 상관 ≠ 인과

다루는 성취기준 [공통7-10-01]

정의와 성질

\(r = \frac{1}{n - 1}\sum z_{x_i}z_{y_i}\) (두 변수의 표준화 점수를 곱해 평균). 두 값이 함께 평균보다 크거나 함께 작으면 곱이 양수라 \(r > 0\).

  • \(-1 \le r \le 1\) (코시-슈바르츠 부등식, 공통2 1-01). \(|r| = 1\)이면 점이 정확히 한 직선 위.
  • 단위와 상관없고, \(x\)와 \(y\)를 바꿔도 같습니다.
  • 직선 관계의 세기만 잽니다. \(y = x^2\) (\(x\)가 −3~3에 대칭)처럼 강한 곡선 관계도 \(r \approx 0\)일 수 있습니다.
  • 이상값 하나에 크게 흔들립니다.
먼저 예측

나라별 1인당 초콜릿 소비량과 인구당 노벨상 수상자 수의 상관계수가 0.79라는 분석이 있습니다. 초콜릿을 많이 먹으면 노벨상을 탈까요?

예측 확인

아닙니다. 부유한 나라일수록 초콜릿도 많이 먹고 연구 투자도 많습니다(교란 변수: 국가의 부). 상관은 인과를 말해 주지 않습니다.

학생 5명의 주당 공부 시간 \(x\)와 시험 점수 \(y\): (2, 60), (4, 70), (6, 75), (8, 85), (10, 90). 상관계수를 구하세요.

풀이

  1. \(\bar x = 6\), \(\bar y = 76\). 편차 \(x\): −4, −2, 0, 2, 4. \(y\): −16, −6, −1, 9, 14.
    평균에서의 편차.
  2. \(\sum(x - \bar x)(y - \bar y) = 64 + 12 + 0 + 18 + 56 = 150\).
    곱의 합.
  3. \(\sum(x - \bar x)^2 = 40\), \(\sum(y - \bar y)^2 = 256 + 36 + 1 + 81 + 196 = 570\).
    제곱합.
  4. \(r = \frac{150}{\sqrt{40\times570}} = \frac{150}{151.0} = 0.993\).
    \(r = \frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}\) (정의를 정리한 꼴, \(n - 1\)이 소거됨).

의미

강한 양의 직선 관계입니다. 하지만 이것이 관측 자료라면 "공부를 늘리면 점수가 오른다"고 단정할 수 없습니다. 의욕이 높은 학생이 공부도 많이 하고 점수도 높을 수 있습니다(교란, 01-03 카드). 그래도 상관은 인과를 찾는 출발점이고, 실험이나 여러 증거로 이어집니다. 그리고 5명으로는 우연의 영향이 큽니다.

검산

점들이 거의 직선 위에 있어(\(y\)가 \(x\)당 약 3.75점씩 증가) \(r\)이 1에 가까운 것이 그림과 맞습니다. 스프레드시트 =CORREL().

흔한 오해

  • "\(r = 0\)이면 관계가 없다." 직선 관계가 없을 뿐입니다. 산점도부터 그립니다.
  • "\(r = 0.8\)이면 80%가 설명된다." 설명되는 비율은 \(r^2 = 0.64\)입니다(다음 카드).
