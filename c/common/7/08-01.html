8.1.1

예제상관계수를 계산하고 인과와 구별하기

r = Σz_x z_y/(n−1) · 직선 관계만 · 상관 ≠ 인과

다루는 성취기준 [공통7-08-01]

정의와 성질

\(r = \frac{1}{n - 1}\sum z_{x_i}z_{y_i}\) (두 변수의 표준화 점수를 곱해 평균). 두 값이 함께 평균보다 크거나 함께 작으면 곱이 양수라 \(r > 0\).

  • \(-1 \le r \le 1\) (코시-슈바르츠 부등식, 공통2 1-01). \(|r| = 1\)이면 점이 정확히 한 직선 위.
  • 단위와 상관없고, \(x\)와 \(y\)를 바꿔도 같습니다.
  • 직선 관계의 세기만 잽니다. \(y = x^2\) (\(x\)가 −3~3에 대칭)처럼 강한 곡선 관계도 \(r \approx 0\)일 수 있습니다.
  • 이상값 하나에 크게 흔들립니다.
먼저 예측

나라별 1인당 초콜릿 소비량과 인구당 노벨상 수상자 수의 상관계수가 0.79라는 분석이 있습니다. 초콜릿을 많이 먹으면 노벨상을 탈까요?

예측 확인

아닙니다. 부유한 나라일수록 초콜릿도 많이 먹고 연구 투자도 많습니다(교란 변수: 국가의 부). 상관은 인과를 말해 주지 않습니다.

학생 5명의 주당 공부 시간 \(x\)와 시험 점수 \(y\): (2, 60), (4, 70), (6, 75), (8, 85), (10, 90). 상관계수를 구하세요.

풀이

  1. \(\bar x = 6\), \(\bar y = 76\). 편차 \(x\): −4, −2, 0, 2, 4. \(y\): −16, −6, −1, 9, 14.
    평균에서의 편차.
  2. \(\sum(x - \bar x)(y - \bar y) = 64 + 12 + 0 + 18 + 56 = 150\).
    곱의 합.
  3. \(\sum(x - \bar x)^2 = 40\), \(\sum(y - \bar y)^2 = 256 + 36 + 1 + 81 + 196 = 570\).
    제곱합.
  4. \(r = \frac{150}{\sqrt{40\times570}} = \frac{150}{151.0} = 0.993\).
    \(r = \frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}\) (정의를 정리한 꼴, \(n - 1\)이 소거됨).

의미

강한 양의 직선 관계입니다. 하지만 이것이 관측 자료라면 "공부를 늘리면 점수가 오른다"고 단정할 수 없습니다. 의욕이 높은 학생이 공부도 많이 하고 점수도 높을 수 있습니다(교란, 01-02 카드). 그래도 상관은 인과를 찾는 출발점이고, 실험이나 여러 증거로 이어집니다. 그리고 5명으로는 우연의 영향이 큽니다.

검산

점들이 거의 직선 위에 있어(\(y\)가 \(x\)당 약 3.75점씩 증가) \(r\)이 1에 가까운 것이 그림과 맞습니다. 스프레드시트 =CORREL().

흔한 오해

  • "\(r = 0\)이면 관계가 없다." 직선 관계가 없을 뿐입니다. 산점도부터 그립니다.
  • "\(r = 0.8\)이면 80%가 설명된다." 설명되는 비율은 \(r^2 = 0.64\)입니다(다음 카드).
