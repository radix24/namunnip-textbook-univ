5.1.1확률밀도함수

기다리는 시간처럼 어떤 실수값이든 가질 수 있는 확률변수는 특정한 값 하나가 나올 확률이 0입니다(정확히 3.000…분을 기다릴 확률). 대신 구간의 확률을 다룹니다. 확률밀도함수 \(f(x)\)는 다음을 만족하는 함수입니다.

  • \(f(x) \ge 0\)이고 전체 넓이 \(\int f(x)\,dx = 1\).
  • \(P(a \le X \le b) = \int_a^bf(x)\,dx\) (그래프 아래 넓이).

히스토그램의 계급을 한없이 좁히고 넓이를 1로 맞춘 극한이 밀도함수라고 생각하면 됩니다. \(f(x)\) 자체는 확률이 아니라서 1보다 클 수도 있습니다. 평균과 분산은 합 대신 적분으로 정의합니다: \(\mu = \int xf(x)\,dx\).

5.1.2균일분포

구간 \([a, b]\)의 모든 값이 똑같이 나올 법하면 밀도함수는 높이 \(\frac{1}{b - a}\)인 직사각형입니다.

\[P(c \le X \le d) = \frac{d - c}{b - a}, \qquad \mu = \frac{a + b}{2}, \qquad \sigma^2 = \frac{(b - a)^2}{12}.\]
예제 5.1.1

버스가 10분마다 오고, 정류장에 아무 때나 도착한다. 7분 넘게 기다릴 확률, 평균 대기 시간, 표준편차는?

풀이. 대기 시간은 \([0, 10]\)의 균일분포. \(P(X > 7) = \frac{3}{10} = 0.3\). 평균 5분, 표준편차 \(\frac{10}{\sqrt{12}} \approx 2.89\)분.

요약
  1. 연속형: 확률 = 밀도함수 아래 넓이. 한 점의 확률은 0.
  2. 균일분포 \([a, b]\): 평균 \((a + b)/2\), 분산 \((b - a)^2/12\).

5.1.3연습문제

기본

  1. \(f(x) = 2x\) (\(0 \le x \le 1\))일 때 \(P(X \le 0.5)\)는?
    답

    \(\int_0^{0.5}2x\,dx = 0.25\).
