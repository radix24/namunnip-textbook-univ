3.2.1리스트 컴프리헨션

"각 원소에 무엇을 해서 새 리스트를 만든다"는 반복문을 한 줄로 쓸 수 있습니다.

T_c = [20.1, 24.8, 29.2, 33.0]
T_k = [t + 273.15 for t in T_c]             # 모두 바꾸기
hot = [t for t in T_c if t > 25]            # 조건에 맞는 것만
pairs = list(zip([0, 30, 60, 90], T_c))      # [(0, 20.1), (30, 24.8), ...]
for i, (t, T) in enumerate(pairs):
    print(i, t, T)

포트란의 암시적 do [(0.01_dp*i, i = 0, 100)]과 비슷한 생각입니다.

3.2.2딕셔너리로 모으기

예제 3.2.1

여러 조의 측정값 [("A", 9.71), ("B", 9.85), ("A", 9.78), ("B", 9.80), ("A", 9.83)]을 조별로 모아 평균을 구하여라.

data = [("A", 9.71), ("B", 9.85), ("A", 9.78), ("B", 9.80), ("A", 9.83)]
groups = {}
for team, g in data:
    groups.setdefault(team, []).append(g)    # 없으면 빈 리스트를 만들고 추가
for team, vals in sorted(groups.items()):
    print(team, len(vals), round(sum(vals) / len(vals), 3))
# A 3 9.773
# B 2 9.825

3.2.3리스트와 NumPy 배열

파이썬 리스트는 아무 자료형이나 섞어 담을 수 있는 대신, 수 계산에는 느리고 [1, 2] * 2가 [1, 2, 1, 2](반복)가 되는 등 수학 연산을 하지 않습니다. 과학 계산에는 포트란 배열처럼 같은 자료형을 이어 담는 NumPy 배열을 씁니다.

import numpy as np
x = np.array([1.0, 2.0, 3.0])
print(x * 2)            # [2. 4. 6.]   원소마다 곱하기
print(np.sin(x).sum())  # 배열 전체 연산 (포트란과 비슷)
A = np.array([[1, 2], [3, 4]])
print(A @ A)            # 행렬 곱 (포트란의 matmul)
print(A[0, 1])          # 2  (인덱스는 0부터, 행 우선)

NumPy 배열 연산은 안에서 C로 만든 코드가 돌아 파이썬 반복문보다 수십 배 이상 빠른 경우가 많습니다(5.4절에서 비교).

요약
  1. [식 for x in 묶음 if 조건], zip, enumerate.
  2. setdefault나 get으로 딕셔너리에 모은다.
  3. 수 계산은 NumPy 배열: 원소마다 연산, @는 행렬 곱.
