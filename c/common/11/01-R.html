1.R.1

연습포트란 기초 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통11-01-01] [공통11-01-02] [공통11-01-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산다음 포트란 문장이 출력하는 값을 예측하세요. print *, 7/2, 7.0/2, mod(7, 2), 2**10 [01-01]

    힌트 1

    정수끼리의 나눗셈은 정수 몫만 남깁니다(C와 같음).

    힌트 2

    7.0은 실수이므로 실수 나눗셈이 됩니다. mod는 나머지, **는 거듭제곱입니다.

    풀이

    3, 3.5(출력 형식은 컴파일러에 따라 3.50000000처럼 나옴), 1, 1024.

  2. 개념implicit none을 빼고 total = 0.0 다음 줄에 totl = totl + x라고 오타를 냈습니다. 컴파일러는 무엇을 하나요? implicit none이 있으면? [01-01]

    힌트 1

    implicit none이 없으면 선언하지 않은 이름도 첫 글자로 자료형이 정해집니다.

    힌트 2

    I~N으로 시작하면 정수, 그 밖은 실수입니다.

    풀이

    implicit none이 없으면 totl이 새 실수 변수로 조용히 만들어지고, 초기화되지 않은 값으로 계산이 진행되어 엉뚱한 결과가 나옵니다. implicit none이 있으면 "선언되지 않은 변수"라는 컴파일 오류가 나서 오타를 바로 찾습니다. 그래서 모든 프로그램 단위에 꼭 씁니다.

  3. 실습DO 반복문으로 1부터 100까지의 합과 \(\sum_{k=1}^{100} 1/k^2\)을 배정도로 계산하는 프로그램을 쓰세요. 두 번째 값은 \(\pi^2/6 \approx 1.6449\)에 가까워야 합니다. [01-02]

    힌트 1

    do k = 1, 100 … end do.

    힌트 2

    \(1/k^2\)을 1/k**2로 쓰면 정수 나눗셈이 되어 \(k \ge 2\)에서 0이 됩니다. 1.0_dp/real(k, dp)**2로 씁니다.

    풀이 
    program sums
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  integer :: k, s
  real(dp) :: t
  s = 0
  t = 0.0_dp
  do k = 1, 100
    s = s + k
    t = t + 1.0_dp / real(k, dp)**2
  end do
  print *, s, t        ! 5050  1.6349839...
end program sums

    \(\pi^2/6 = 1.6449\)과 0.0100 차이가 나는 것은 100항에서 멈췄기 때문입니다. 나머지 항의 합은 약 \(1/100\)입니다.

  4. 실습점수를 읽어 90 이상 A, 80 이상 B, 70 이상 C, 나머지 F를 출력하는 프로그램을 if … then … else if로 쓰세요. [01-02]

    힌트 1

    조건을 큰 것부터 차례로 검사합니다.

    힌트 2

    포트란의 블록 if는 if (조건) then, else if (조건) then, else, end if.

    풀이 
    program grade
  implicit none
  integer :: s
  read *, s
  if (s >= 90) then
    print *, "A"
  else if (s >= 80) then
    print *, "B"
  else if (s >= 70) then
    print *, "C"
  else
    print *, "F"
  end if
end program grade

    작은 것부터(s >= 70) 검사하면 95점도 C가 됩니다.

  5. 실습배정도 배열 x(5)에 1.5, 2.0, 3.5, 4.0, 6.0을 넣고 평균과 최댓값을 내장 함수로 구하세요. 포트란 배열의 첫 번호는 무엇인가요? [01-03]

    힌트 1

    real(dp) :: x(5), 배열 생성자 x = [1.5_dp, ...].

    힌트 2

    sum(x), maxval(x), size(x).

    풀이 
    real(dp) :: x(5)
x = [1.5_dp, 2.0_dp, 3.5_dp, 4.0_dp, 6.0_dp]
print *, sum(x) / size(x), maxval(x)   ! 3.4  6.0

    포트란 배열은 기본으로 1번부터 시작합니다(x(1) … x(5)). C와 파이썬은 0번부터라 옮겨 쓸 때 자주 틀립니다. x(0:4)처럼 범위를 직접 정할 수도 있습니다.

  6. 판단real :: a로 선언하고 a = 1/3을 했더니 0.0이 나왔습니다. 한 학생은 “실수 변수에 넣었으니 0.333…이 나와야 한다”고 합니다. 판단하세요. [01-01]

    힌트 1

    오른쪽 식은 어떤 자료형으로 계산된 뒤 왼쪽에 들어가나요?

    힌트 2

    1/3은 정수끼리의 나눗셈입니다.

    풀이

    틀렸습니다. 오른쪽 1/3이 먼저 정수 나눗셈으로 0이 되고, 그 0이 실수로 바뀌어 들어갑니다. a = 1.0/3.0이나 배정도로 1.0_dp/3.0_dp라고 써야 합니다.
