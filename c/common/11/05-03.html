5.3.1최소제곱 직선

자료 \((x_i, y_i)\)에 직선 \(y = a + bx\)를 맞출 때, 잔차의 제곱합 \(\sum(y_i - a - bx_i)^2\)이 가장 작은 \(a, b\)는

\[b = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}, \qquad a = \bar y - b\bar x.\] 
import numpy as np

def linfit(x, y):
    xm, ym = x.mean(), y.mean()
    b = np.sum((x - xm) * (y - ym)) / np.sum((x - xm) ** 2)
    a = ym - b * xm
    r2 = 1 - np.sum((y - a - b * x) ** 2) / np.sum((y - ym) ** 2)
    return a, b, r2

결정계수 \(R^2\)은 1에 가까울수록 직선이 자료를 잘 설명한다는 뜻입니다. NumPy에는 np.polyfit(x, y, 1)(기울기, 절편 순서로 돌려줌)이 있습니다.

5.3.2지수 함수 맞추기

방사성 붕괴, 1차 반응, RC 회로의 방전처럼 \(y = Ae^{-kt}\)인 자료는 로그를 취하면 \(\ln y = \ln A - kt\)로 직선이 됩니다.

예제 5.3.1

시간 \(t\) = 0, 1, 2, 3, 4 (분)에서 농도 \(y\) = 10.0, 6.1, 3.6, 2.3, 1.3을 얻었다. \(A\), \(k\), 반감기를 구하여라.

t = np.array([0, 1, 2, 3, 4], dtype=float)
y = np.array([10.0, 6.1, 3.6, 2.3, 1.3])
a, b, r2 = linfit(t, np.log(y))
A, k = np.exp(a), -b
print(A, k, np.log(2) / k, r2)     # 10.06  0.506  1.37  0.9990

\(A \approx 10.1\), \(k \approx 0.506\) /분, 반감기 \(\frac{\ln 2}{k} \approx 1.37\)분, \(R^2 \approx 0.999\)입니다. 같은 자료에 그냥 직선을 맞추면 기울기 −2.12인 직선이 나오는데, \(t = 5\)에서 음수 농도를 예측하는 등 모형이 맞지 않습니다. 자료를 그려 보고 알맞은 모형을 고르는 것이 먼저입니다.

로그를 취해 맞추면 작은 \(y\)값의 오차가 크게 부풀려져 결과에 더 큰 영향을 줍니다. 정밀한 분석에서는 scipy.optimize.curve_fit으로 원래 식을 직접 맞추기도 합니다.

5.3.3그래프 그리기

import matplotlib.pyplot as plt
tt = np.linspace(0, 5, 100)
plt.plot(t, y, "o", label="측정값")
plt.plot(tt, A * np.exp(-k * tt), "-", label=f"맞춤: {A:.2f} exp(-{k:.3f} t)")
plt.xlabel("t (min)"); plt.ylabel("y")
plt.legend(); plt.savefig("fit.png", dpi=150)

세로축을 로그 눈금(plt.yscale("log"))으로 바꾸면 지수 자료가 직선으로 보여 모형을 확인하기 좋습니다. 한글 축 이름이 깨지면 글꼴 설정이 필요합니다. 아래 실습 카드에서 잡음의 크기를 바꾸며 두 맞춤을 비교할 수 있습니다.

요약
  1. 최소제곱 직선: \(b = S_{xy}/S_{xx}\), \(a = \bar y - b\bar x\), \(R^2\).
  2. 지수 자료는 \(\ln y\)를 \(t\)에 직선으로 맞춘다.
  3. 먼저 그려 보고 모형을 고른다. matplotlib, 로그 눈금.

5.3.4연습문제

기본

  1. \(y = Ax^n\) 꼴(거듭제곱 법칙)의 자료는 무엇을 무엇에 대해 직선으로 맞추면 되는가?
    답

    \(\ln y = \ln A + n\ln x\)이므로 \(\ln y\)를 \(\ln x\)에 대해 맞춘다. 기울기가 \(n\).

5.3.2

실습잡음 섞인 붕괴 자료 맞추기

실습 · 로그 변환과 최소제곱

다루는 성취기준 [공통11-05-03]

목표

\(y = 10e^{-0.5t}\)에 잡음을 섞은 가짜 실험 자료를 만들어, \(\ln y\)를 직선으로 맞춘 결과가 참값에 얼마나 가까운지, 그냥 직선을 맞추면 어떻게 되는지 비교합니다. 성취기준 [공통11-05-03].

준비

빨간 점이 자료, 파란 곡선이 로그 변환으로 맞춘 지수 함수, 회색 점선이 그냥 맞춘 직선입니다. 잡음은 각 점에 곱하는 상대 오차의 표준편차입니다. "새 자료"를 누르면 같은 조건에서 잡음만 새로 뽑습니다.

절차

  1. 잡음 0%에서 맞춘 \(A\), \(k\)가 참값(10, 0.5)과 같은지 확인한다.
  2. 잡음 5%와 20%에서 "새 자료"를 여러 번 눌러 \(k\)가 얼마나 흔들리는지 본다.
  3. 점 수를 늘려 같은 일을 한다.
  4. 세로축 로그 눈금을 켜서 자료가 직선으로 보이는지 본다.

기대 결과

  • 잡음이 없으면 \(A = 10\), \(k = 0.5\), \(R^2 = 1\)이 정확히 나온다.
  • 잡음이 크면 \(k\)가 크게 흔들리고, 점 수가 많을수록 덜 흔들린다.
  • 그냥 직선은 \(R^2\)이 낮고, \(t = 6\)에서 음수를 예측하기도 한다.
  • 로그 눈금에서는 지수 자료가 직선 둘레에 흩어져 보인다.

분석

  1. 로그 눈금에서 \(t\)가 큰(\(y\)가 작은) 점들이 더 많이 흩어져 보이는 경우가 있습니다. 같은 상대 잡음이라도 0 근처에서 잘라 낸 값이 로그에서 크게 벗어나는 이유를 말해 보세요.
  2. 공통7의 회귀 카드에서 배운 \(R^2\)의 뜻으로, 그냥 직선의 \(R^2\)이 낮은 이유를 설명해 보세요.
