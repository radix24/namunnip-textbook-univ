2.1.1함수와 서브루틴

포트란의 부프로그램은 두 가지입니다.

  • 함수(function): 값 하나를 돌려준다. 식 안에서 y = f(x)처럼 쓴다.
  • 서브루틴(subroutine): 돌려주는 값 없이 인수를 바꾼다. call로 부른다.

둘을 모듈에 넣고 use로 불러 쓰면, 컴파일러가 인수의 개수와 자료형을 검사해 주어 실수를 줄일 수 있습니다.

module physics
  implicit none
  integer, parameter :: dp = kind(1.0d0)
contains
  function kinetic(m, v) result(K)
    real(dp), intent(in) :: m, v
    real(dp) :: K
    K = 0.5_dp * m * v**2
  end function kinetic

  subroutine polar(x, y, r, theta)
    real(dp), intent(in)  :: x, y
    real(dp), intent(out) :: r, theta
    r = sqrt(x**2 + y**2)
    theta = atan2(y, x)
  end subroutine polar
end module physics

program main
  use physics
  implicit none
  real(dp) :: r, th
  print *, kinetic(2.0_dp, 3.0_dp)      ! 9.0
  call polar(1.0_dp, 1.0_dp, r, th)
  print *, r, th                        ! 1.414..., 0.785...
end program main

2.1.2intent와 참조에 의한 전달

포트란은 인수를 넘길 때 값을 복사하지 않고 변수 자체(주소)를 넘깁니다. 그래서 서브루틴이 인수를 바꾸면 부른 쪽의 변수가 바뀝니다(C에서 포인터를 넘긴 것과 같은 효과). 의도하지 않게 바꾸는 것을 막기 위해 intent를 적습니다.

  • intent(in): 읽기만 한다. 바꾸려 하면 컴파일 오류.
  • intent(out): 결과를 써서 돌려준다.
  • intent(inout): 읽고 바꾼다.

배열도 그대로 넘어갑니다. real(dp), intent(in) :: a(:)처럼 쓰면(형태 가정 배열) 크기를 따로 넘기지 않아도 안에서 size(a)로 알 수 있습니다. 이렇게 쓰려면 부프로그램이 모듈 안에 있어야 합니다.

subroutine normalize(v)
  real(dp), intent(inout) :: v(:)
  v = v / sqrt(sum(v**2))
end subroutine normalize
요약
  1. function은 값 하나, subroutine은 call로 부르며 인수를 바꾼다.
  2. 인수는 참조로 넘어간다. intent(in/out/inout)을 적는다.
  3. module ... contains에 모으고 use로 쓴다.
