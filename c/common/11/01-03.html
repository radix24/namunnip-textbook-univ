1.3.1선언과 인덱스

real(dp) :: T(5), A(3, 3)
integer :: i
T = [20.1_dp, 20.6_dp, 21.3_dp, 22.0_dp, 22.8_dp]
print *, T(1), T(5)       ! 첫째와 마지막: 인덱스는 1부터
print *, T(2:4)           ! 구간: 2, 3, 4번 (끝 포함)
print *, T(5:1:-1)        ! 거꾸로

포트란 배열은 괄호를 쓰고, 인덱스는 기본이 1부터입니다(C, 파이썬은 0부터). real(dp) :: B(0:10)처럼 시작 번호를 정할 수도 있습니다. 구간 T(2:4)는 끝을 포함합니다.

1.3.2배열 전체 연산

포트란의 큰 장점은 반복문 없이 배열 전체를 한꺼번에 계산할 수 있다는 것입니다.

real(dp) :: x(101), y(101)
x = [(0.01_dp * i, i = 0, 100)]   ! 0, 0.01, ..., 1 (암시적 do)
y = sin(x)**2 + x                  ! 원소마다 계산
print *, sum(y) / size(y)          ! 평균
print *, maxval(y), maxloc(y)      ! 최댓값과 그 위치
where (y > 1.0_dp) y = 1.0_dp       ! 조건에 맞는 원소만 바꾸기
  • sum, product, maxval, minval, size.
  • dot_product(u, v): 내적.
  • matmul(A, B): 행렬 곱. transpose(A): 전치.

1.3.3열 우선 저장과 할당 배열

2차원 배열 A(i, j)는 메모리에 열 우선으로, 곧 A(1,1), A(2,1), A(3,1), A(1,2), ... 순서로 놓입니다(C는 행 우선). 메모리를 차례로 읽을 때 빠르므로, 이중 반복문에서는 첫째 인덱스를 안쪽 반복에 둡니다.

do j = 1, n          ! 바깥: 열
  do i = 1, n        ! 안쪽: 행 (메모리 순서대로)
    A(i, j) = 1.0_dp / (i + j - 1)
  end do
end do

크기를 실행 중에 정하려면 할당 배열을 씁니다.

real(dp), allocatable :: data(:)
read *, n
allocate(data(n))
! ... 사용 ...
deallocate(data)

아래 실습 카드에서 행 우선과 열 우선의 메모리 순서를 비교해 볼 수 있습니다.

요약
  1. 인덱스는 1부터, 구간 a(i:j)는 끝 포함.
  2. 배열 전체 연산, sum, matmul, where.
  3. 열 우선 저장: 첫째 인덱스를 안쪽 반복에. 크기를 나중에 정하면 allocatable.

1.3.4연습문제

기본

  1. real(dp) :: A(2, 3)에서 메모리의 넷째 원소는?
    답

    순서 A(1,1), A(2,1), A(1,2), A(2,2), ... 이므로 A(2, 2).

1.3.2

실습2차원 배열의 메모리 순서

실습 · 열 우선과 행 우선

다루는 성취기준 [공통11-01-03]

목표

2차원 배열이 메모리에 한 줄로 놓이는 순서를 포트란(열 우선)과 C(행 우선)에서 비교하고, 이중 반복문의 안쪽 인덱스를 무엇으로 두어야 메모리를 차례로 읽는지 확인합니다. 성취기준 [공통11-01-03].

준비

위는 행렬 모양, 아래는 같은 원소들을 실제 메모리 주소 순서로 늘어놓은 것입니다. 재생하면 이중 반복문이 원소를 방문하는 차례대로 칠하고, 막 방문한 원소는 노랗게 표시합니다.

절차

  1. 포트란, 안쪽 반복 i로 재생하고 아래 메모리 줄이 어떻게 칠해지는지 본다.
  2. 안쪽 반복을 j로 바꿔 다시 재생한다.
  3. 언어를 C로 바꿔 두 가지를 다시 해 본다.

기대 결과

  • 포트란에서 i를 안쪽에 두면 메모리를 왼쪽부터 차례로 채운다(한 걸음에 주소 1칸).
  • 포트란에서 j를 안쪽에 두면 행 수만큼씩 건너뛰며 칠한다.
  • C에서는 반대로 j(마지막 인덱스)를 안쪽에 두어야 차례로 읽는다.

분석

  1. CPU는 메모리를 한 칸씩이 아니라 이웃한 여러 칸을 묶어 캐시로 가져옵니다. 건너뛰며 읽는 것이 큰 배열에서 느린 이유를 이것으로 설명해 보세요.
  2. NumPy 배열은 기본이 행 우선입니다. 포트란 프로그램이 쓴 행렬 파일을 NumPy로 읽을 때 무엇을 조심해야 할지 말해 보세요.
