혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 실습이차방정식 \(ax^2 + bx + c = 0\)의 두 근을 돌려주는 함수를 쓰세요. 판별식이 음수여도 복소수 근을 돌려주게 하세요. [04-01]

    힌트 1

    cmath.sqrt는 음수의 제곱근을 복소수로 돌려줍니다.

    힌트 2

    return (-b + d) / (2*a), (-b - d) / (2*a).

    풀이 
    import cmath
def roots(a, b, c):
    d = cmath.sqrt(b * b - 4 * a * c)
    return (-b + d) / (2 * a), (-b - d) / (2 * a)
print(roots(1, -3, 2))   # ((2+0j), (1+0j))
print(roots(1, 2, 5))    # ((-1+2j), (-1-2j))

  2. 실습첫 줄이 머리글(t,x)인 CSV 파일 data.csv를 읽어 x 열의 평균을 구하세요. [04-01]

    힌트 1

    csv.DictReader는 줄마다 머리글을 키로 하는 딕셔너리를 줍니다.

    힌트 2

    읽은 값은 문자열이므로 float()로 바꿉니다.

    풀이 
    import csv
with open("data.csv", newline="") as f:
    xs = [float(row["x"]) for row in csv.DictReader(f)]
print(sum(xs) / len(xs))

    split(",")로 직접 나눠도 되지만, 값 안에 쉼표가 있는 경우까지 처리하려면 csv 모듈이 안전합니다.

  3. 실습자주 쓰는 함수 mean을 mystat.py에 넣고 다른 파일에서 불러 쓰세요. if __name__ == "__main__":은 왜 쓰나요? [04-02]

    힌트 1

    같은 폴더의 mystat.py는 import mystat로 불러옵니다.

    힌트 2

    모듈을 불러올 때와 직접 실행할 때 __name__의 값이 다릅니다.

    풀이 
    # mystat.py
def mean(xs):
    return sum(xs) / len(xs)
if __name__ == "__main__":
    print(mean([1, 2, 3]))   # 직접 실행할 때만 시험
          
    # main.py
import mystat
print(mystat.mean([2, 4, 9]))   # 5.0

    if __name__ == "__main__": 아래의 시험 코드는 python mystat.py로 직접 실행할 때만 돌고, 다른 파일이 불러올 때는 돌지 않습니다.

  4. 실습위치와 속도를 가진 입자 클래스 Particle을 만들고, 중력 가속도로 시간 간격 dt만큼 움직이는 메서드 step을 넣으세요(오일러 방법). [04-02]

    힌트 1

    self.v += a * dt, self.y += self.v * dt.

    힌트 2

    처음 높이 10 m, 속도 0에서 dt = 0.1로 1초(10걸음) 뒤 위치를 출력해 보세요.

    풀이 
    class Particle:
    def __init__(self, y, v):
        self.y, self.v = y, v
    def step(self, dt, a=-9.8):
        self.v += a * dt
        self.y += self.v * dt
p = Particle(10.0, 0.0)
for _ in range(10):
    p.step(0.1)
print(round(p.y, 3), round(p.v, 3))   # 4.61 -9.8

    정확한 값은 \(10 - 4.9 = 5.1\) m입니다. 속도를 먼저 고친 뒤 위치를 고치는 이 방법은 걸음마다 조금씩 더 떨어져 0.49 m 작게 나옵니다. dt를 줄이면 차이도 줄어듭니다(5.2절).

  5. 실습NumPy로 0부터 \(\pi\)까지 1001개 점에서 \(\sin x\)를 계산하고 사다리꼴 공식으로 적분하세요. 반복문 없이 쓰는 것이 왜 빠른가요? [04-02]

    힌트 1

    np.linspace(0, np.pi, 1001), np.sin(x)는 배열 전체에 한 번에 적용됩니다.

    힌트 2

    np.trapz(y, x)(NumPy 2.0부터는 np.trapezoid).

    풀이 
    import numpy as np
x = np.linspace(0, np.pi, 1001)
y = np.sin(x)
print(np.trapezoid(y, x))   # 1.99999836...

    NumPy의 배열 연산은 C로 짠 반복문이 한꺼번에 처리하므로, 파이썬 for로 원소 하나씩 계산하는 것보다 수십 배 빠릅니다(5.4절).

  6. 판단count = 0을 함수 밖에 두고 함수 안에서 count += 1을 했더니 UnboundLocalError가 났습니다. 왜 그런지, 어떻게 고치는 것이 좋은지 말하세요. [04-01]

    힌트 1

    함수 안에서 이름에 값을 대입하면 파이썬은 그 이름을 지역 변수로 봅니다.

    힌트 2

    global count로 고칠 수도 있지만, 값을 인자로 받고 돌려주는 편이 낫습니다.

    풀이

    count += 1은 대입이라 count가 지역 변수가 되는데, 값을 더하기 전에 읽으려 하니 아직 값이 없다는 오류입니다. global count를 쓰면 되지만, 전역 변수를 바꾸는 함수는 추적이 어렵습니다. def bump(count): return count + 1처럼 인자와 반환값으로 주고받는 것이 좋습니다.
