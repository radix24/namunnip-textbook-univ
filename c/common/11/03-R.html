3.R.1

연습파이썬 기초 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통11-03-01] [공통11-03-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 실습낙하 시간 \(t\)(초)를 입력받아 자유 낙하 거리 \(h = \tfrac12gt^2\)(\(g = 9.8\) m/s²)를 소수 둘째 자리까지 출력하세요. \(t = 2.5\)이면 30.62 m가 나와야 합니다. [03-01]

    힌트 1

    float(input()), f-문자열 {h:.2f}.

    힌트 2

    거듭제곱은 t ** 2입니다.

    풀이 
    g = 9.8
t = float(input("t = "))
h = 0.5 * g * t ** 2
print(f"h = {h:.2f} m")   # 30.62 (30.625를 반올림)

  2. 실습하루 기온 리스트 [12.5, 15.0, 17.5, 14.0, 11.0]의 평균과 최고 기온을 구하고, 리스트 축약으로 화씨 리스트를 만드세요. [03-02]

    힌트 1

    sum(xs) / len(xs), max(xs).

    힌트 2

    [c * 9 / 5 + 32 for c in xs].

    풀이

    평균 14.0, 최고 17.5. 화씨 [54.5, 59.0, 63.5, 57.2, 51.8]. 리스트 축약은 "각 원소에 같은 계산을 해서 새 리스트를 만든다"를 한 줄로 씁니다.

  3. 실습원자량을 딕셔너리 {"H": 1.008, "C": 12.011, "O": 15.999}로 두고, 분자식을 {"H": 2, "O": 1}처럼 주면 분자량을 계산하는 코드를 쓰세요. [03-02]

    힌트 1

    분자식 딕셔너리를 items()로 돌며 원자량 × 개수를 더합니다.

    힌트 2

    sum(mass[e] * n for e, n in formula.items()).

    풀이 
    mass = {"H": 1.008, "C": 12.011, "O": 15.999}
def molar(formula):
    return sum(mass[e] * n for e, n in formula.items())
print(molar({"H": 2, "O": 1}))          # 18.015
print(molar({"C": 6, "H": 12, "O": 6})) # 180.156

  4. 실습\(n = 1, \ldots, 5\)에 대해 \(n\), \(n^2\), \(\sqrt n\)을 열을 맞춰 출력하는 표를 만드세요. [03-02]

    힌트 1

    for n in range(1, 6):.

    힌트 2

    f-문자열의 폭 지정: {n:3d}{n*n:5d}{math.sqrt(n):9.4f}.

    풀이 
    import math
for n in range(1, 6):
    print(f"{n:3d}{n * n:5d}{math.sqrt(n):9.4f}")

    마지막 줄은 5 25 2.2361입니다. 포트란의 형식 (I3, I5, F9.4)와 같은 일을 합니다.

  5. 계산10000원을 연 5% 복리로 맡기면 처음으로 두 배 이상이 되는 해는 몇 년 뒤인가요? while로 구하세요. [03-02]

    힌트 1

    잔액이 20000원보다 작은 동안 1.05를 곱하고 해를 하나 늘립니다.

    힌트 2

    \(1.05^{14} = 1.98\), \(1.05^{15} = 2.08\).

    풀이 
    money, year = 10000, 0
while money < 20000:
    money *= 1.05
    year += 1
print(year, round(money))   # 15 20789

    "72 법칙"(72 ÷ 5 = 14.4년)으로도 어림할 수 있습니다.

  6. 판단for i in range(1, 10): total += i로 1부터 10까지의 합을 구했다고 생각한 학생이 45를 얻었습니다. 무엇이 틀렸나요? 들여쓰기를 틀리면 어떤 일이 생기나요? [03-02]

    힌트 1

    range(1, 10)에 10이 들어가나요?

    힌트 2

    파이썬은 들여쓰기로 반복문의 몸통을 정합니다.

    풀이

    range(1, 10)은 1~9라 45입니다. range(1, 11)로 고쳐야 55가 나옵니다. 들여쓰기를 잘못하면 반복 안에 있어야 할 문장이 밖으로 나가 한 번만 실행되거나, IndentationError가 납니다. 포트란의 end do처럼 끝을 표시하는 말이 없으니 들여쓰기가 곧 구조입니다.
