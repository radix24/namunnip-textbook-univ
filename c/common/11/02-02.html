2.2.1장치 번호

포트란은 파일을 장치 번호(unit)에 연결해 다룹니다. print *와 read *는 화면과 키보드에 연결된 기본 장치입니다. newunit=을 쓰면 비어 있는 번호를 저절로 골라 줍니다.

integer :: u, ios, n
real(dp) :: t, T_c
real(dp) :: tarr(1000), tcarr(1000)

open(newunit=u, file="data.txt", status="old", action="read", iostat=ios)
if (ios /= 0) stop "data.txt를 열 수 없습니다"
read(u, *)                      ! 첫 줄(제목) 건너뛰기
n = 0
do
  read(u, *, iostat=ios) t, T_c
  if (ios /= 0) exit            ! 파일 끝이면 음수, 읽기 오류면 양수
  n = n + 1
  tarr(n) = t;  tcarr(n) = T_c
end do
close(u)
print *, n, "줄을 읽었습니다"

read(u, *)의 *는 목록 지향 입력이라, 공백이나 쉼표로 나뉜 수를 차례로 읽습니다. status는 "old"(있어야 함), "new"(없어야 함), "replace"(있으면 덮어씀)입니다.

포트란에서는 변수 이름의 대소문자를 구별하지 않으므로 t와 T는 같은 변수입니다. 그래서 위에서는 온도를 T_c로, 배열을 tarr, tcarr로 썼습니다. ts와 Ts를 함께 선언하면 같은 이름이라 컴파일 오류가 납니다.

2.2.2형식을 정한 출력

open(newunit=u, file="result.txt", status="replace", action="write")
write(u, '(A8, A10)') "t(s)", "T(K)"
do i = 1, n
  write(u, '(F8.1, F10.2)') tarr(i), tcarr(i) + 273.15_dp
end do
close(u)
형식뜻예 (값 → 출력)
I5정수, 5칸42 → 42
F8.3고정 소수점, 8칸, 소수 3자리3.14159 → 3.142
ES12.4과학적 표기, 소수 4자리0.000123 → 1.2300E-04
A, A8문자열
3F8.2, 2X같은 형식 3번, 빈칸 2개

칸이 모자라면 별표(********)가 찍힙니다. 이렇게 열을 맞춘 파일은 파이썬이나 표 계산 프로그램에서 바로 읽을 수 있어, 계산은 포트란으로 하고 그래프는 파이썬(5.3절)으로 그리는 식으로 나누어 쓰기 좋습니다.

요약
  1. open(newunit=u, file=..., status=..., iostat=...), read(u, *), write(u, 형식), close(u).
  2. 파일 끝까지 읽기: do 안에서 iostat이 0이 아니면 exit.
  3. 형식 I, F, ES, A, X. 칸이 모자라면 별표.
