5.1.1알고리즘

전기 회로의 키르히호프 방정식, 화학 반응식의 계수, 최소제곱 맞춤(5.3절) 등 많은 문제가 연립일차방정식이 됩니다. 손으로 하던 소거법을 그대로 프로그램으로 옮깁니다.

  1. 전진 소거: \(k = 1, \dots, n-1\)열마다, \(k\)행 아래의 각 행 \(i\)에서 \(m = a_{ik}/a_{kk}\)배한 \(k\)행을 빼서 \(a_{ik}\)를 0으로 만든다(\(b_i\)도 함께).
  2. 후진 대입: 위 삼각 행렬이 되었으므로 마지막 행부터 \(x_i = \left(b_i - \sum_{j>i} a_{ij}x_j\right)/a_{ii}\).
예제 5.1.1

\(2x + y - z = 8\), \(-3x - y + 2z = -11\), \(-2x + y + 2z = -3\)을 풀어라.

subroutine gauss(A, b, x)
  real(dp), intent(inout) :: A(:, :), b(:)
  real(dp), intent(out)   :: x(:)
  integer :: n, i, k, p
  real(dp) :: m
  n = size(b)
  do k = 1, n - 1
    p = maxloc(abs(A(k:n, k)), dim=1) + k - 1     ! 부분 피벗팅
    if (p /= k) then
      A([k, p], :) = A([p, k], :)                  ! 두 행 맞바꾸기
      b([k, p]) = b([p, k])
    end if
    do i = k + 1, n
      m = A(i, k) / A(k, k)
      A(i, k:n) = A(i, k:n) - m * A(k, k:n)
      b(i) = b(i) - m * b(k)
    end do
  end do
  do i = n, 1, -1
    x(i) = (b(i) - sum(A(i, i+1:n) * x(i+1:n))) / A(i, i)
  end do
end subroutine gauss

답은 \(x = 2\), \(y = 3\), \(z = -1\)입니다. 파이썬에서는 같은 알고리즘을 NumPy로 쓰거나, 검증된 라이브러리 numpy.linalg.solve(A, b)를 씁니다(안에서 LAPACK이라는 포트란 라이브러리를 부름).

5.1.2부분 피벗팅

\(a_{kk}\)가 0이면 나눌 수 없고, 0은 아니어도 아주 작으면 \(m\)이 커져 반올림 오차가 크게 불어납니다. 그래서 \(k\)열의 \(k\)행 아래에서 절댓값이 가장 큰 원소가 있는 행을 \(k\)행과 바꾼 뒤 소거합니다(위 코드의 maxloc). 예를 들어 \(10^{-20}x + y = 1\), \(x + y = 2\)를 피벗팅 없이 배정도로 풀면 \(x = 0\)이 나오지만, 행을 바꾸면 올바른 \(x \approx 1\)을 얻습니다. 아래 실습 카드에서 단계마다 행렬이 바뀌는 모습을 볼 수 있습니다.

5.1.3계산량

전진 소거의 곱셈 수는 약 \(\frac{n^3}{3}\), 후진 대입은 \(\frac{n^2}{2}\)입니다. \(n\)이 10배 커지면 시간은 약 1000배가 됩니다. 같은 \(A\)에 \(\mathbf{b}\)만 바꿔 여러 번 풀 때는 소거 과정을 저장해 두는 LU 분해를 씁니다.

요약
  1. 전진 소거 → 위 삼각 → 후진 대입.
  2. 부분 피벗팅: 열에서 절댓값이 가장 큰 원소를 피벗으로.
  3. 계산량 약 \(n^3/3\).

5.1.4연습문제

기본

  1. \(n = 100\)인 연립방정식을 푸는 데 0.01초 걸렸다면 \(n = 1000\)은 대략 얼마나 걸리는가?
    답

    \(n^3\)에 비례하므로 1000배, 약 10초.

5.1.2

실습가우스 소거를 한 단계씩

실습 · 부분 피벗팅

다루는 성취기준 [공통11-05-01]

목표

첨가 행렬 \([A \mid \mathbf b]\)가 행 연산으로 위 삼각 행렬이 되는 과정을 한 단계씩 보고, 피벗팅이 있을 때와 없을 때 결과를 비교합니다. 성취기준 [공통11-05-01].

준비

칠한 행이 방금 바뀐 행이고, 빨간 수가 그 단계의 피벗입니다. 세로줄 오른쪽이 \(\mathbf b\)입니다. 마지막 단계에서 후진 대입으로 해를 구합니다.

절차

  1. 예제 5.1.1에서 다음 단계를 눌러 가며 각 행 연산의 배수를 확인한다.
  2. 피벗팅을 끄고 같은 문제를 풀어 단계와 답을 비교한다.
  3. 작은 피벗 문제를 피벗팅 없이, 그리고 피벗팅을 켜고 푼다.
  4. 4원 연립방정식에서 단계 수를 센다.

기대 결과

  • 예제 5.1.1의 해는 \(x = 2\), \(y = 3\), \(z = -1\). 피벗팅을 켜면 첫 단계에서 −3이 있는 2행이 위로 올라간다.
  • 작은 피벗 문제는 피벗팅 없이 \(x = 0\)(틀림), 피벗팅을 켜면 \(x \approx 1\), \(y \approx 1\).
  • 4원 연립방정식의 해는 \((1, 2, 3, 4)\). 소거 단계는 \(3 + 2 + 1 = 6\)번(맞바꿈 제외).

분석

  1. \(n\)원 연립방정식의 소거 단계가 \(\frac{n(n-1)}{2}\)번이고, 각 단계가 약 \(n\)번의 곱셈이라 전체가 \(n^3\)에 비례함을 설명해 보세요.
  2. 작은 피벗 문제에서 피벗팅 없이 \(y\)는 맞았는데 \(x\)만 틀린 이유를 후진 대입 식으로 말해 보세요.

더 해 보기

파이썬에서 numpy.linalg.solve로 같은 문제를 풀고 결과를 비교해 보세요. 공통2의 행렬 단원에서 배운 행렬식이 0이면 이 과정이 어디서 멈추는지도 생각해 보세요.
