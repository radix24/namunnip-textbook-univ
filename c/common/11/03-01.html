3.1.1동적 자료형

포트란과 C는 변수를 쓰기 전에 자료형을 선언하고, 그 변수에는 그 자료형만 넣습니다(정적 자료형). 파이썬은 선언 없이 값을 대입하면 변수가 생기고, 같은 이름에 다른 자료형의 값을 넣어도 됩니다(동적 자료형). 편하지만 오타나 자료형 실수가 실행해 보기 전까지 드러나지 않습니다.

특히 정수 나눗셈은 두 언어가 정반대라 옮겨 쓸 때 가장 많이 틀리는 곳입니다.

3.1.2같은 프로그램, 두 언어

예제 3.1.1

이차방정식 \(ax^2 + bx + c = 0\)의 근을 판별식에 따라 구하여라.

program quad
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  real(dp) :: a, b, c, D
  read *, a, b, c
  D = b**2 - 4*a*c
  if (D > 0) then
    print *, (-b + sqrt(D))/(2*a), (-b - sqrt(D))/(2*a)
  else if (D == 0) then
    print *, -b/(2*a)
  else
    print *, "실근 없음"
  end if
end program quad
import math
a, b, c = map(float, input().split())
D = b**2 - 4*a*c
if D > 0:
    print((-b + math.sqrt(D))/(2*a), (-b - math.sqrt(D))/(2*a))
elif D == 0:
    print(-b/(2*a))
else:
    print("실근 없음")

포트란의 4*a*c에서 정수 4는 실수 a와 곱해지며 실수로 바뀌므로 괜찮습니다. 그러나 1/2*a처럼 정수끼리 먼저 나누면 0이 됩니다. 또 \(b^2 \gg 4ac\)이면 \(-b + \sqrt D\)에서 상쇄 오차가 생기므로(공통10 6.1절) 정밀한 계산에서는 근과 계수의 관계 \(x_1x_2 = c/a\)로 작은 근을 따로 구합니다.

요약
  1. 포트란은 정적 자료형, 파이썬은 동적 자료형.
  2. 정수 나눗셈, /=와 !=, 대소문자 구별이 다르다.
