5.R.1

연습과학 계산 프로그래밍 단원 마무리 연습

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통11-05-01] [공통11-05-02] [공통11-05-03] [공통11-05-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 문제 끝의 코드는 그 문제가 확인하는 성취기준입니다.

  1. 계산가우스 소거로 연립방정식 \(2x + y - z = 8\), \(-3x - y + 2z = -11\), \(-2x + y + 2z = -3\)을 손으로 푸세요. [05-01]

    힌트 1

    첫 식으로 둘째, 셋째 식의 \(x\)를 없앱니다(둘째 + 1.5 × 첫째, 셋째 + 1 × 첫째).

    힌트 2

    그러면 \(0.5y + 0.5z = 1\), \(2y + z = 5\).

    풀이

    둘째 줄 ×4를 셋째에서 빼면 \(-z = 1\), \(z = -1\). 거꾸로 대입: \(0.5y - 0.5 = 1\), \(y = 3\). \(2x + 3 + 1 = 8\), \(x = 2\). 해 \((2, 3, -1)\). 프로그램은 이 과정을 그대로 반복문으로 씁니다(전진 소거 \(O(n^3)\), 후진 대입 \(O(n^2)\)).

  2. 계산\(y' = y\), \(y(0) = 1\)을 \(h = 0.1\)로 한 걸음 진행할 때 오일러 방법과 4차 룽게-쿠타 방법의 값을 구하고 참값 \(e^{0.1}\)과 비교하세요. [05-02]

    힌트 1

    오일러: \(y_1 = y_0 + hf(y_0)\). RK4: \(k_1 = f(y_0)\), \(k_2 = f(y_0 + \tfrac h2k_1)\), \(k_3 = f(y_0 + \tfrac h2k_2)\), \(k_4 = f(y_0 + hk_3)\).

    힌트 2

    \(k_1 = 1\), \(k_2 = 1.05\), \(k_3 = 1.0525\), \(k_4 = 1.10525\).

    풀이

    오일러: 1.1 (오차 \(5.2\times10^{-3}\)). RK4: \(1 + \tfrac{0.1}6(1 + 2.1 + 2.105 + 1.10525) = 1.10517083\). 참값 1.10517092와 \(8.5\times10^{-8}\) 차이. 한 걸음에 함수를 네 번 계산하는 대신 오차가 비교할 수 없이 작습니다.

  3. 계산측정값 (0, 1.0), (1, 3.0), (2, 5.2), (3, 6.8)에 최소제곱 직선 \(y = a + bx\)를 맞추세요. [05-03]

    힌트 1

    \(b = \dfrac{\sum(x - \bar x)(y - \bar y)}{\sum(x - \bar x)^2}\), \(a = \bar y - b\bar x\).

    힌트 2

    \(\bar x = 1.5\), \(\bar y = 4.0\), \(S_{xy} = 9.8\), \(S_{xx} = 5\).

    풀이

    \(b = 1.96\), \(a = 4.0 - 2.94 = 1.06\). 파이썬에서는 np.polyfit(x, y, 1)이 [1.96, 1.06]을 줍니다.

  4. 실습방사성 시료의 측정값 (0, 2.0), (1, 5.4), (2, 14.8), (3, 40.2)가 \(y = Ae^{bx}\)를 따른다고 봅니다. 로그를 취해 직선으로 바꾼 뒤 \(A\)와 \(b\)를 구하세요. [05-03]

    힌트 1

    \(\ln y = \ln A + bx\)이므로 \((x, \ln y)\)에 직선을 맞춥니다.

    힌트 2

    \(\ln y = 0.693, 1.686, 2.695, 3.694\).

    풀이

    기울기 \(b = 1.001\), 절편 0.6905, \(A = e^{0.6905} = 1.995\). 곧 \(y \approx 2.0e^{1.0x}\). 이 방법은 작은 \(y\)의 오차를 크게 키우므로, 정밀하게 하려면 비선형 최소제곱(scipy.optimize.curve_fit)을 씁니다.

  5. 개념같은 이중 반복문(100만 번 곱셈과 덧셈)을 포트란, 파이썬 반복문, NumPy로 실행하면 대개 어떤 순서로 빠른가요? 이유는? [05-04]

    힌트 1

    포트란은 컴파일되어 기계어로, 파이썬은 한 줄씩 해석되며 실행됩니다.

    힌트 2

    NumPy는 배열 연산을 컴파일된 코드로 처리합니다.

    풀이

    대체로 포트란 ≈ NumPy > 파이썬 반복문이고, 파이썬 반복문은 수십~수백 배 느립니다. 파이썬은 원소마다 자료형 확인과 객체 생성을 하기 때문입니다. 실제 배수는 컴퓨터와 코드에 따라 다르므로 직접 재 봐야 합니다(5.4절 본문의 시간 재기 코드).

  6. 판단\(0.0001x + y = 1\), \(x + y = 2\)를 유효숫자 3자리로만 계산하는 컴퓨터에서 첫 식을 기준으로(피벗 없이) 가우스 소거를 했더니 \(x = 0\)이 나왔습니다. 참값은 \(x \approx 1.0001\)입니다. 무엇이 잘못되었고 어떻게 고치나요? [05-01]

    힌트 1

    첫 식에 10000을 곱해 둘째에서 빼면 \(y\)의 계수와 우변이 어떻게 되나요?

    힌트 2

    두 식의 순서를 바꾸고(부분 피벗팅) 다시 해 보세요.

    풀이

    피벗 0.0001이 너무 작아 곱하는 수가 10000이 되었습니다. \((1 - 10000)y = 2 - 10000\)이 3자리 계산에서 \(-10000y = -10000\), \(y = 1.00\)이 되고, \(0.0001x = 1 - 1.00 = 0\)에서 \(x = 0\)이 됩니다. 절댓값이 가장 큰 계수를 피벗으로 삼도록 줄을 바꾸면 \(y = 1.00\), \(x = 2 - 1.00 = 1.00\)으로 바른 답이 나옵니다. 그래서 실제 프로그램은 언제나 부분 피벗팅을 씁니다(공통9 7.1절).
