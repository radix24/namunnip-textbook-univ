5.4.1

설명RLC 교류 회로의 임피던스와 공명

리액턴스 · 위상 · Z = √(R² + (X_L − X_C)²)

다루는 성취기준 [공통4-05-04]

왜 필요한가

콘센트의 전기는 교류(한국 60 Hz)입니다. 교류에서는 축전기와 인덕터도 전류를 "제한"하는데, 그 정도가 진동수에 따라 달라집니다. 이 성질로 라디오는 원하는 방송만 고르고, 스피커는 저음과 고음을 나눕니다.

정의

\(v(t) = V_0\sin\omega t\)를 직렬 RLC에 걸 때, 각 소자의 전압과 전류 진폭의 비: 저항 \(R\), 유도 리액턴스 \(X_L = \omega L\), 용량 리액턴스 \(X_C = \frac{1}{\omega C}\). 회로 전체의 임피던스 \(Z = \sqrt{R^2 + (X_L - X_C)^2}\), 전류 진폭 \(I_0 = \frac{V_0}{Z}\).

정의를 풀어 읽기

  1. \(X_L = \omega L\)\(v_L = L\frac{di}{dt}\)이고 \(i = I_0\sin\omega t\)이면 \(v_L = \omega LI_0\cos\omega t\). 진폭 비 \(\omega L\), 전압이 전류보다 90° 앞섭니다. 진동수가 높을수록 전류 변화가 빨라 더 강하게 방해합니다.
  2. \(X_C = \frac{1}{\omega C}\)\(i = C\frac{dv_C}{dt}\)에서 진폭 비 \(\frac{1}{\omega C}\), 전압이 전류보다 90° 뒤집니다. 진동수가 낮으면 충전할 시간이 길어 전압이 크게 쌓여 전류를 막습니다(직류에서는 완전히 막음).
  3. 왜 빼기인가\(v_L\)과 \(v_C\)는 위상이 180° 반대라 서로 상쇄됩니다. 저항 전압은 전류와 같은 위상이라 그것과 90°를 이룹니다. 그래서 피타고라스처럼 더합니다(위상자 그림).
  4. 공명\(X_L = X_C\), 곧 \(\omega_0 = \frac{1}{\sqrt{LC}}\)에서 \(Z = R\)로 최소, 전류 최대. 4-05-03 카드의 LC 고유 진동수와 같습니다.

예와 반례

예. \(R = 10\ \Omega\), \(L = 0.10\) H, \(C = 100\ \mu\text{F}\), \(V_0 = 10\) V. 공명 진동수 \(f_0 = \frac{1}{2\pi\sqrt{10^{-5}}} = 50.3\) Hz. 공명에서 \(I_0 = 1.0\) A. 60 Hz에서 \(X_L = 37.7\), \(X_C = 26.5\), \(Z = \sqrt{100 + 125} = 15.0\ \Omega\), \(I_0 = 0.67\) A.

반례(진폭을 그냥 더하기). 공명에서 \(V_L = I_0X_L = 31.6\) V, \(V_C = 31.6\) V, \(V_R = 10\) V로 진폭을 더하면 73 V지만 전원은 10 V입니다. 위상이 달라 순간값끼리만 더해집니다. 공명에서 축전기 전압이 전원보다 훨씬 클 수 있다는 점은 실제 회로 설계에서 위험 요소입니다.

다른 개념과의 관계

공명 곡선의 뾰족함은 \(Q = \frac{\omega_0L}{R}\) (품질 인자)로 나타냅니다. 강제 진동하는 용수철의 공명(공통8 3-02)과 같은 방정식이라, 다리가 바람에 흔들리는 문제와 라디오 동조가 같은 수학입니다. 복소수 \(Z = R + i(X_L - X_C)\)로 쓰면 계산이 간단해집니다(공통9 6단원).

흔한 오해

  • "축전기는 전류를 통과시키지 않는다." 직류에서만 그렇습니다. 교류에서는 충전·방전을 되풀이하며 회로에 전류가 흐릅니다(판 사이로 전하가 건너가지는 않음, 6-01 카드).
