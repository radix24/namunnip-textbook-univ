5.3.1충전

기전력 \(\varepsilon\)인 전지, 저항 \(R\), 빈 축전기 \(C\)를 직렬로 잇고 스위치를 닫습니다. 축전기의 전하를 \(q(t)\), 전류를 \(i = \frac{dq}{dt}\)라 하면 고리 법칙에서

\[\varepsilon - iR - \frac qC = 0 \quad\Rightarrow\quad R\frac{dq}{dt} = \varepsilon - \frac qC.\]

처음에는 \(q = 0\)이라 전류가 \(\frac{\varepsilon}{R}\)로 가장 크고, 축전기가 차오를수록 전압 \(\frac qC\)가 전지를 거슬러 전류가 줄어듭니다. 이 미분방정식(공통8의 1계 선형 방정식)을 풀면

정리 5.3.1 \[q(t) = C\varepsilon\left(1 - e^{-t/RC}\right), \qquad i(t) = \frac{\varepsilon}{R}e^{-t/RC}.\]

미분해서 대입하면 확인할 수 있습니다. \(\tau = RC\)를 시간 상수라 하며 단위는 초입니다(Ω·F = s).

  • \(t = \tau\): 최종 전하의 \(1 - e^{-1} \approx 63\%\) 충전, 전류는 처음의 37%.
  • \(t = 5\tau\): 99.3% 충전. 실용적으로 "다 찼다".

5.3.2방전

전하 \(Q_0\)인 축전기를 저항으로만 이으면 \(R\frac{dq}{dt} = -\frac qC\)이므로

\[q(t) = Q_0e^{-t/RC}.\]

같은 시간 상수로 지수적으로 줄어듭니다. 공통3에서 본 적 없는 새로운 모양의 시간 변화입니다. 방사성 붕괴, 뜨거운 물체가 식는 것도 같은 꼴입니다.

예제 5.3.2

\(R = 10\) kΩ, \(C = 100\) μF, \(\varepsilon = 9.0\) V. 시간 상수, 처음 전류, 1.0 s 뒤 축전기 전압은?

풀이. \(\tau = 10^4\times10^{-4} = 1.0\) s. 처음 전류 \(\frac{9.0}{10^4} = 0.90\) mA. 1.0 s 뒤 \(9.0(1 - e^{-1}) = 5.7\) V.

충전하는 동안 전지가 내는 에너지 \(Q\varepsilon = C\varepsilon^2\) 가운데 절반 \(\frac12C\varepsilon^2\)만 축전기에 저장되고 나머지 절반은 저항에서 열이 됩니다. 놀랍게도 \(R\)의 크기와 상관없습니다.

요약
  1. 충전 \(q = C\varepsilon(1 - e^{-t/RC})\), 방전 \(q = Q_0e^{-t/RC}\).
  2. \(\tau = RC\): 63% 충전(37%로 감소)에 걸리는 시간. \(5\tau\)면 거의 끝.

5.3.3연습문제

기본

  1. 방전에서 전하가 절반이 되는 시간은 \(\tau\)의 몇 배인가?
    답

    \(\ln2 \approx 0.69\)배.

응용

  1. \(q(t) = C\varepsilon(1 - e^{-t/RC})\)가 미분방정식을 만족함을 보여라.
    답

    \(R\dot q = \varepsilon e^{-t/RC}\), \(\varepsilon - q/C = \varepsilon e^{-t/RC}\). 같다.

5.3.2

유도RC 회로의 충전과 방전: 시간 상수 τ = RC

일계 미분방정식 · 지수 감쇠 · 카메라 플래시

다루는 성취기준 [공통4-05-03]

무엇을 유도하나

기전력 \(\mathcal E\)인 전지, 저항 \(R\), 빈 축전기 \(C\)를 \(t = 0\)에 연결하면 \(q(t) = C\mathcal E(1 - e^{-t/RC})\), \(I(t) = \frac{\mathcal E}{R}e^{-t/RC}\). 방전은 \(q(t) = Q_0e^{-t/RC}\).

모형과 출발점

도선 저항과 전지 내부 저항은 \(R\)에 포함, 인덕턴스 무시. 고리 법칙: \(\mathcal E - IR - \frac qC = 0\), 그리고 \(I = \frac{dq}{dt}\).

유도

  1. \(R\frac{dq}{dt} = \mathcal E - \frac qC = -\frac1C(q - C\mathcal E)\).
    고리 법칙 정리.
  2. 변수분리: \(\frac{dq}{q - C\mathcal E} = -\frac{dt}{RC}\).
    공통8 1단원의 변수분리형.
  3. 적분: \(\ln|q - C\mathcal E| = -\frac{t}{RC} + c\), 곧 \(q - C\mathcal E = Ae^{-t/RC}\).
    지수로 바꿈.
  4. \(q(0) = 0\)이면 \(A = -C\mathcal E\): \(q = C\mathcal E(1 - e^{-t/RC})\).
    초기조건.
  5. \(I = \frac{dq}{dt} = \frac{\mathcal E}{R}e^{-t/RC}\).
    미분.

결과 확인

  • 차원: \(RC\)의 단위 Ω·F = (V/A)(C/V) = C/A = s.
  • 처음: 빈 축전기는 전압이 0이라 도선처럼 행동, \(I(0) = \frac{\mathcal E}{R}\).
  • 나중: 꽉 차면 전류 0, 끊어진 도선처럼 행동.
  • 시간 상수의 뜻: \(t = \tau\)에 최종값의 \(1 - e^{-1} = 63\%\), \(5\tau\)에 99.3%. 실용적으로 "\(5\tau\)면 다 찼다".
  • 에너지: 전지가 낸 에너지 \(Q\mathcal E = C\mathcal E^2\) 중 축전기에 \(\frac12C\mathcal E^2\), 저항에서 열로 \(\int I^2R\,dt = \frac12C\mathcal E^2\). \(R\)과 상관없이 정확히 절반이 열이 됩니다.

예

카메라 플래시의 100 μF 축전기를 300 V로 충전하는 회로의 저항이 5.0 kΩ입니다. 시간 상수와 저장 에너지, 90%까지 충전되는 시간은?

\(\tau = 5000\times10^{-4} = 0.50\) s. \(U = \frac12(10^{-4})(300)^2 = 4.5\) J. \(1 - e^{-t/\tau} = 0.9\)에서 \(t = \tau\ln10 = 1.15\) s. 방전할 때는 저항이 수 Ω인 램프를 지나므로 \(\tau\)가 수백 μs로 짧아 순간적으로 큰 전력을 냅니다.

한계

아주 빠른 변화(나노초)에서는 도선의 인덕턴스가 중요해져 RLC 회로(5단원)로 다뤄야 합니다.

5.3.3

실습RC 회로 충전·방전 기록하기

실습 · 시간 상수

다루는 성취기준 [공통4-05-03]

목표

저항, 전기용량, 기전력을 바꿔 가며 축전기의 충전과 방전 곡선을 기록하고, 곡선 모양은 그대로이고 시간 축만 \(\tau = RC\)로 늘거나 줄어든다는 것을 확인합니다. 성취기준 [공통4-05-03].

준비

장치는 고리 법칙 \(\varepsilon - iR - q/C = 0\)을 작은 시간 간격으로 풀어 기록합니다. 가로축은 시간을 \(\tau\)로 나눈 값이고, 세로축은 최댓값에 대한 비율입니다. 실제 시간은 아래 숫자 줄에 나옵니다.

절차

  1. 5.3절 예제의 값(10 kΩ, 100 μF, 9 V)으로 충전을 시작해 \(t = \tau\)에서 축전기 전압을 읽는다.
  2. R을 두 배로 하고 다시 충전한다. 실제 시간으로 \(\tau\)가 몇 배가 되었는지 본다.
  3. 다 충전되면 방전을 시작해 전압이 절반이 되는 시간을 \(\tau\)와 비교한다.
  4. 기전력을 바꾸면 곡선 모양이 바뀌는지 본다.

기대 결과

  • \(t = \tau\)에서 약 63%(5.7 V), \(5\tau\)에서 99% 이상.
  • R이나 C를 두 배로 하면 \(\tau\)가 두 배. 곡선은 같은 모양으로 시간만 늘어난다.
  • 방전에서 절반이 되는 시간은 \(\tau\ln2 \approx 0.69\tau\).
  • 기전력은 곡선의 높이(최종 전압)만 바꾸고 시간 상수는 바꾸지 않는다.

분석

  1. 충전 처음 순간 축전기는 도선처럼, 다 충전되면 끊어진 회로처럼 행동합니다. 전류 곡선에서 확인해 보세요.
  2. 왜 지수 함수가 나올까요? "전류가 남은 전압 차이에 비례한다"는 것을 식으로 써 보세요.

더 해 보기

전자 부품 키트가 있다면 10 kΩ 저항, 100 μF 축전기, 9 V 전지, 멀티미터로 같은 실험을 하고, 5초마다 전압을 기록해 \(\ln(1 - V/\varepsilon)\) 대 \(t\) 그래프의 기울기로 \(\tau\)를 구해 봅니다(공통3 11.2절).
