7.3.1진동 방정식

충전된 축전기를 인덕터에 연결합니다. 축전기가 방전하며 전류가 흐르는데, 인덕터가 전류의 변화를 방해하므로 축전기가 다 비어도 전류는 바로 멈추지 않고 계속 흘러 반대로 충전합니다. 그 다음 반대로 방전하며 이를 되풀이합니다.

고리 법칙에서 \(-L\frac{di}{dt} - \frac qC = 0\), \(i = \frac{dq}{dt}\)이므로

\[\frac{d^2q}{dt^2} = -\frac{1}{LC}q.\]

공통3의 \(\frac{d^2x}{dt^2} = -\frac kmx\)와 같은 꼴입니다.

\[q(t) = Q\cos(\omega t + \phi), \qquad \omega = \frac{1}{\sqrt{LC}}.\]

7.3.2용수철과의 대응

용수철LC 회로
변위 \(x\)전하 \(q\)
속도 \(v\)전류 \(i\)
질량 \(m\)인덕턴스 \(L\)
용수철 상수 \(k\)\(\frac1C\)
\(\frac12kx^2\) (위치 에너지)\(\frac{q^2}{2C}\) (전기 에너지)
\(\frac12mv^2\) (운동 에너지)\(\frac12Li^2\) (자기 에너지)

에너지는 축전기의 전기장과 인덕터의 자기장 사이를 오가며, 저항이 없으면 합 \(\frac{Q^2}{2C}\)이 일정합니다. 저항이 있으면 진폭이 지수적으로 줄어드는 감쇠 진동이 되고(마찰이 있는 용수철), 이것은 공통8(고등미적분학(1))의 2계 상수계수 미분방정식으로 풉니다.

예제 7.3.1

\(L = 10\) mH, \(C = 1.0\) μF인 LC 회로의 진동수와, 처음 전하 \(Q = 2.0\) μC일 때 최대 전류는?

풀이. \(\omega = \frac{1}{\sqrt{10^{-2}\times10^{-6}}} = 1.0\times10^4\) rad/s, \(f = \frac{\omega}{2\pi} \approx 1.6\) kHz. 최대 전류 \(\omega Q = 0.020\) A (용수철의 \(v_{\max} = \omega A\)). 라디오는 이런 회로의 \(C\)를 바꿔 원하는 방송의 진동수에 맞춥니다(8단원의 공명).

요약
  1. \(\ddot q = -q/LC\), \(\omega = 1/\sqrt{LC}\).
  2. \(q \leftrightarrow x\), \(i \leftrightarrow v\), \(L \leftrightarrow m\), \(1/C \leftrightarrow k\). 에너지는 전기장과 자기장 사이를 오간다.

기본

    답

    절반.

7.3.2

유도LC 회로의 진동은 용수철 진자와 같은 방정식이다

q″ = −q/LC · ω = 1/√LC · 에너지 주고받기

다루는 성취기준 [공통4-07-03]

무엇을 유도하나

충전된 축전기 \(C\)를 인덕터 \(L\)에 연결하면 전하가 \(q(t) = Q_0\cos\omega t\)로 진동하고, \(\omega = \dfrac{1}{\sqrt{LC}}\)이다.

모형과 출발점

저항 0(이상화). 고리 법칙: 축전기 전압 \(\frac qC\)와 인덕터 기전력 \(-L\frac{dI}{dt}\)의 합이 0. 전류 \(I = \frac{dq}{dt}\).

유도

  1. \(L\frac{d^2q}{dt^2} + \frac qC = 0\), 곧 \(\ddot q = -\frac{1}{LC}q\).
    고리 법칙에 \(I = \dot q\).
  2. 공통3 6-01의 \(\ddot x = -\frac kmx\)와 같은 꼴: \(q = Q_0\cos(\omega t + \phi)\), \(\omega^2 = \frac{1}{LC}\).
    같은 미분방정식은 같은 해를 갖는다.
  3. 에너지: \(\frac{q^2}{2C} + \frac12LI^2 = \frac{Q_0^2}{2C}\cos^2 + \frac{Q_0^2}{2C}\sin^2 = \frac{Q_0^2}{2C}\). 일정.
    \(L\omega^2 = \frac1C\)를 썼다.
용수철 진자LC 회로
변위 \(x\)전하 \(q\)
속도 \(v\)전류 \(I\)
질량 \(m\) (관성)인덕턴스 \(L\)
용수철 상수 \(k\)\(\frac1C\)
퍼텐셜 \(\frac12kx^2\)전기 에너지 \(\frac{q^2}{2C}\)
운동에너지 \(\frac12mv^2\)자기 에너지 \(\frac12LI^2\)
마찰(감쇠)저항 \(R\)

결과 확인

  • 차원: \(\sqrt{LC}\)의 단위 \(\sqrt{\text{H·F}} = \sqrt{(\text{V·s/A})(\text{A·s/V})} = \text{s}\).
  • 수치: 라디오 동조 회로 \(L = 1.0\ \mu\text{H}\), \(C = 25\) pF이면 \(f = \frac{1}{2\pi\sqrt{2.5\times10^{-17}}} = 32\) MHz. \(C\)를 바꿔 방송국 주파수에 맞춥니다.
  • 위상: 축전기가 꽉 찼을 때 전류 0(진자가 끝에서 멈춤), 축전기가 빌 때 전류 최대(진자가 바닥을 지날 때 최대 속력).

한계

실제 회로에는 저항이 있어 진폭이 \(e^{-Rt/2L}\)로 줄어듭니다. 이 감쇠 진동의 분류(과감쇠, 임계감쇠, 미감쇠)는 공통8 3단원에서 미분방정식으로 다룹니다. 같은 표가 공통8 3-03 카드의 출발점입니다.

7.3.3

실습LC 회로의 에너지 주고받기

실습 · 전기 에너지와 자기 에너지, 감쇠

다루는 성취기준 [공통4-07-03]

목표

충전된 축전기를 인덕터에 연결했을 때 에너지가 전기장과 자기장 사이를 오가는 모습을 보고, 진동수 \(\frac{1}{2\pi\sqrt{LC}}\)를 확인합니다. 저항을 넣어 감쇠 진동이 되는 것과 진동이 사라지는 경계를 찾습니다. 성취기준 [공통4-07-03].

준비

처음에 축전기에 10 μC가 충전되어 있습니다. 위 막대는 전체 처음 에너지에 대한 전기 에너지, 자기 에너지, 저항에서 열로 바뀐 에너지의 비율입니다. 아래 그래프는 전하(주황)와 전류(파란 점선)입니다. 시간은 진동 주기가 화면에서 약 2초가 되도록 맞췄습니다.

절차

  1. R = 0에서 재생해 전기 에너지와 자기 에너지가 언제 각각 최대가 되는지 본다.
  2. 7.3절 예제(10 mH, 1 μF)의 진동수를 출력과 비교한다. C를 4배로 하면 진동수는?
  3. R을 10, 50, 150 Ω으로 올려 진동이 줄어드는 모습과 열로 바뀐 에너지를 본다.
  4. 진동하지 않고 바로 0으로 가라앉는 R을 찾아 \(2\sqrt{L/C}\)와 비교한다.

기대 결과

  • 전하가 최대(전류 0)일 때 전기 에너지가 전부, 전하가 0(전류 최대)일 때 자기 에너지가 전부. 합은 늘 100%.
  • 10 mH, 1 μF에서 \(f_0 \approx 1.6\) kHz. C 4배 → 진동수 절반.
  • 저항이 있으면 진폭이 지수적으로 줄고, 줄어든 에너지만큼 열이 는다(세 막대의 합은 그대로).
  • \(R \ge 2\sqrt{L/C} = 200\) Ω이면 진동 없이 가라앉는다.

분석

  1. 용수철과 대응시키면 전기 에너지와 자기 에너지는 각각 무엇에 해당하나요? 저항은?
  2. 전류가 최대인 순간 축전기의 전하는 0입니다. 그런데 왜 전류가 곧바로 멈추지 않을까요?

더 해 보기

공통8의 감쇠 진동 \(m\ddot x + c\dot x + kx = 0\)과 \(L\ddot q + R\dot q + q/C = 0\)을 나란히 쓰고, 진동이 사라지는 조건 \(c^2 = 4mk\)가 \(R = 2\sqrt{L/C}\)와 같은 식임을 확인해 보세요.
