8.1.1교류와 실효값

전압이 \(v = V\sin\omega t\)처럼 사인 모양으로 변하는 전원을 교류라 합니다. 가정용 전기는 한국에서 60 Hz입니다. 평균 전력을 계산할 때는 제곱 평균의 제곱근인 실효값을 씁니다: \(V_{\text{rms}} = \frac{V}{\sqrt2}\). "220 V"는 실효값이고 최댓값은 약 311 V입니다.

8.1.2세 소자

전류를 \(i = I\sin\omega t\)라 하면 각 소자의 전압은 다음과 같습니다.

  • 저항: \(v = IR\sin\omega t\). 전압과 전류가 같은 위상.
  • 인덕터: \(v = L\frac{di}{dt} = I\omega L\cos\omega t\). 전압이 전류보다 90° 앞선다. 크기 비 \(X_L = \omega L\) (유도 리액턴스).
  • 축전기: \(v = \frac qC\), \(q = -\frac{I}{\omega}\cos\omega t\). 전압이 전류보다 90° 늦다. 크기 비 \(X_C = \frac{1}{\omega C}\) (용량 리액턴스).

리액턴스의 단위는 Ω입니다. 인덕터는 진동수가 높을수록 전류를 막고, 축전기는 낮을수록 막습니다. 스피커의 고음·저음 분리 회로가 이 성질을 씁니다.

8.1.3RLC 직렬 회로

위상이 다른 전압들은 그냥 더할 수 없고, 회전하는 화살표(페이저)로 더합니다. 저항 전압은 전류와 같은 방향, \(L\)과 \(C\)의 전압은 서로 반대 방향(수직)이므로

\[Z = \sqrt{R^2 + (X_L - X_C)^2}, \qquad I = \frac VZ, \qquad \tan\phi = \frac{X_L - X_C}{R}.\]

\(Z\)를 임피던스, \(\phi\)를 전압과 전류의 위상차라 합니다.

예제 8.1.1

\(R = 100\) Ω, \(L = 0.50\) H, \(C = 10\) μF가 직렬이고 120 V(실효), 60 Hz 전원에 연결되었다. 임피던스, 실효 전류, 위상차는?

풀이. \(\omega = 377\) rad/s. \(X_L = 188.5\) Ω, \(X_C = 265.3\) Ω. \(Z = \sqrt{100^2 + 76.8^2} \approx 126\) Ω. \(I_{\text{rms}} = \frac{120}{126} \approx 0.95\) A. \(\phi = \tan^{-1}(-0.768) \approx -37.5^\circ\) (전류가 앞섬).

8.1.4공명과 전력

\(X_L = X_C\)이면 임피던스가 \(R\)로 가장 작아져 전류가 최대가 됩니다. 이 진동수가 공명 진동수입니다.

\[\omega_0 = \frac{1}{\sqrt{LC}}.\]

LC 회로의 고유 진동수와 같습니다. 그네를 고유 진동수에 맞춰 밀면 크게 흔들리는 것과 같습니다. 예제 8.1.1에서 \(f_0 = \frac{1}{2\pi\sqrt{0.50\times10^{-5}}} \approx 71\) Hz입니다. \(R\)이 작을수록 공명 봉우리가 뾰족해져, 라디오는 원하는 진동수만 골라 받습니다.

평균 전력은 저항에서만 소모됩니다: \(P = I_{\text{rms}}V_{\text{rms}}\cos\phi = I_{\text{rms}}^2R\). \(\cos\phi\)를 역률이라 합니다. 인덕터와 축전기는 에너지를 받았다 돌려줄 뿐 소모하지 않습니다.

요약
  1. \(X_L = \omega L\) (전압이 90° 앞섬), \(X_C = 1/\omega C\) (90° 늦음).
  2. \(Z = \sqrt{R^2 + (X_L - X_C)^2}\), \(\tan\phi = (X_L - X_C)/R\).
  3. 공명 \(\omega_0 = 1/\sqrt{LC}\), \(P = I_{\text{rms}}^2R\).

8.1.5연습문제

기본

  1. 예제 8.1.1의 회로가 공명할 때 실효 전류와 평균 전력은?
    답

    \(Z = R\), \(I = 1.2\) A, \(P = 144\) W.

8.1.2

설명RLC 교류 회로의 임피던스와 공명

리액턴스 · 위상 · Z = √(R² + (X_L − X_C)²)

다루는 성취기준 [공통4-08-01]

왜 필요한가

콘센트의 전기는 교류(한국 60 Hz)입니다. 교류에서는 축전기와 인덕터도 전류를 "제한"하는데, 그 정도가 진동수에 따라 달라집니다. 이 성질로 라디오는 원하는 방송만 고르고, 스피커는 저음과 고음을 나눕니다.

정의

\(v(t) = V_0\sin\omega t\)를 직렬 RLC에 걸 때, 각 소자의 전압과 전류 진폭의 비: 저항 \(R\), 유도 리액턴스 \(X_L = \omega L\), 용량 리액턴스 \(X_C = \frac{1}{\omega C}\). 회로 전체의 임피던스 \(Z = \sqrt{R^2 + (X_L - X_C)^2}\), 전류 진폭 \(I_0 = \frac{V_0}{Z}\).

정의를 풀어 읽기

  1. \(X_L = \omega L\)\(v_L = L\frac{di}{dt}\)이고 \(i = I_0\sin\omega t\)이면 \(v_L = \omega LI_0\cos\omega t\). 진폭 비 \(\omega L\), 전압이 전류보다 90° 앞섭니다. 진동수가 높을수록 전류 변화가 빨라 더 강하게 방해합니다.
  2. \(X_C = \frac{1}{\omega C}\)\(i = C\frac{dv_C}{dt}\)에서 진폭 비 \(\frac{1}{\omega C}\), 전압이 전류보다 90° 뒤집니다. 진동수가 낮으면 충전할 시간이 길어 전압이 크게 쌓여 전류를 막습니다(직류에서는 완전히 막음).
  3. 왜 빼기인가\(v_L\)과 \(v_C\)는 위상이 180° 반대라 서로 상쇄됩니다. 저항 전압은 전류와 같은 위상이라 그것과 90°를 이룹니다. 그래서 피타고라스처럼 더합니다(위상자 그림).
  4. 공명\(X_L = X_C\), 곧 \(\omega_0 = \frac{1}{\sqrt{LC}}\)에서 \(Z = R\)로 최소, 전류 최대. 4-05-03 카드의 LC 고유 진동수와 같습니다.

예와 반례

예. \(R = 10\ \Omega\), \(L = 0.10\) H, \(C = 100\ \mu\text{F}\), \(V_0 = 10\) V. 공명 진동수 \(f_0 = \frac{1}{2\pi\sqrt{10^{-5}}} = 50.3\) Hz. 공명에서 \(I_0 = 1.0\) A. 60 Hz에서 \(X_L = 37.7\), \(X_C = 26.5\), \(Z = \sqrt{100 + 125} = 15.0\ \Omega\), \(I_0 = 0.67\) A.

반례(진폭을 그냥 더하기). 공명에서 \(V_L = I_0X_L = 31.6\) V, \(V_C = 31.6\) V, \(V_R = 10\) V로 진폭을 더하면 73 V지만 전원은 10 V입니다. 위상이 달라 순간값끼리만 더해집니다. 공명에서 축전기 전압이 전원보다 훨씬 클 수 있다는 점은 실제 회로 설계에서 위험 요소입니다.

다른 개념과의 관계

공명 곡선의 뾰족함은 \(Q = \frac{\omega_0L}{R}\) (품질 인자)로 나타냅니다. 강제 진동하는 용수철의 공명(공통8 3-02)과 같은 방정식이라, 다리가 바람에 흔들리는 문제와 라디오 동조가 같은 수학입니다. 복소수 \(Z = R + i(X_L - X_C)\)로 쓰면 계산이 간단해집니다(공통9 6단원).

흔한 오해

  • "축전기는 전류를 통과시키지 않는다." 직류에서만 그렇습니다. 교류에서는 충전·방전을 되풀이하며 회로에 전류가 흐릅니다(판 사이로 전하가 건너가지는 않음, 6-01 카드).

확인진동수를 올리면

공명 진동수보다 훨씬 높은 진동수에서 직렬 RLC 회로의 임피던스를 주로 정하는 것은?

8.1.3

실습라디오처럼 공명 맞추기

실습 · RLC 공명 곡선과 위상

다루는 성취기준 [공통4-08-01]

목표

RLC 직렬 회로의 진동수를 바꿔 가며 전류의 공명 곡선을 그리고, 공명 진동수 \(\frac{1}{2\pi\sqrt{LC}}\)에서 임피던스가 가장 작고 위상차가 0임을 확인합니다. 저항이 공명 봉우리의 뾰족함을 정한다는 것을 봅니다. 성취기준 [공통4-08-01].

준비

전원은 120 V(실효)입니다. 위 그래프는 진동수에 따른 실효 전류, 주황 점은 지금 진동수입니다. 아래 그림은 전류 방향을 가로로 둔 전압 화살표(페이저)로, 저항 전압 \(V_R\)와 \(V_L - V_C\)를 더하면 전원 전압 \(V\)입니다.

절차

  1. 8.1절 예제의 값(100 Ω, 0.50 H, 10 μF, 60 Hz)에서 출력을 예제와 비교한다.
  2. 진동수를 바꿔 전류가 가장 큰 곳을 찾고 \(f_0\)과 비교한다. 그때 페이저의 모양을 본다.
  3. R을 20 Ω과 300 Ω으로 바꿔 공명 곡선의 높이와 폭을 비교한다.
  4. \(f_0\)보다 낮은 진동수와 높은 진동수에서 위상차의 부호를 확인한다.

기대 결과

  • 예제와 같이 \(Z \approx 126\) Ω, \(I \approx 0.95\) A, \(\phi \approx -37.5^\circ\). 공명은 약 71 Hz.
  • 공명에서 \(X_L = X_C\), \(Z = R\), 페이저의 세로 화살표가 사라지고 전압과 전류가 같은 위상.
  • R이 작을수록 봉우리가 높고 좁다(선택성이 좋다).
  • \(f < f_0\): 용량성(전류가 앞섬), \(f > f_0\): 유도성(전압이 앞섬).

분석

  1. 라디오는 여러 방송 신호가 동시에 들어올 때 하나만 골라 듣습니다. 이 장치의 어떤 성질을 이용하나요? 무엇을 조절해 방송을 바꾸나요?
  2. 공명 때도 인덕터와 축전기 각각의 전압은 0이 아닙니다. 오히려 전원 전압보다 클 수 있습니다. \(I X_L\)을 계산해 확인해 보세요.

더 해 보기

공명 곡선에서 전류가 최댓값의 \(\frac{1}{\sqrt2}\)이 되는 두 진동수의 차이(대역폭)를 R을 바꿔 가며 어림하고, 대역폭이 대략 \(\frac{R}{2\pi L}\)에 비례하는지 확인해 봅니다.
