6.3.1앙페르 법칙

긴 직선 전류를 둘러싼 반지름 \(r\)인 원을 따라 \(\vec B\)를 선적분하면 \(\frac{\mu_0I}{2\pi r}\cdot2\pi r = \mu_0I\)로 \(r\)이 사라집니다. 어떤 닫힌 경로에서든 성립합니다.

정리 6.3.1 (앙페르 법칙) \[\oint\vec B\cdot d\vec l = \mu_0I_{\text{안}}.\]

닫힌 경로를 따른 자기장의 선적분은 경로가 감싸는 전류에 \(\mu_0\)를 곱한 것이다(전류가 일정할 때).

가우스 법칙과 같은 역할입니다. 대칭이 있어 경로 위에서 \(B\)가 일정하면 자기장을 바로 구할 수 있습니다. 전류의 부호는 오른손 법칙으로 정합니다.

예제 6.3.2

반지름 \(R\)인 긴 도선에 전류 \(I\)가 고르게 흐른다. 도선 안(\(r < R\))의 자기장은?

풀이. 반지름 \(r\)인 원이 감싸는 전류는 \(I\frac{r^2}{R^2}\). \(B(2\pi r) = \mu_0I\frac{r^2}{R^2}\), \(B = \frac{\mu_0Ir}{2\pi R^2}\). 중심에서 0, 표면까지 비례해 커지고 바깥에서는 \(\frac{\mu_0I}{2\pi r}\)로 줄어듭니다(2.1절 공 모양 전하와 같은 모양).

6.3.2솔레노이드

도선을 촘촘히 감은 긴 코일을 솔레노이드라 합니다. 안에서는 각 고리의 자기장이 더해져 축 방향으로 균일하고, 바깥에서는 거의 0입니다. 안쪽과 바깥쪽을 지나는 직사각형 경로(안쪽 길이 \(l\))에 앙페르 법칙을 쓰면 \(Bl = \mu_0nlI\) (\(n\): 단위 길이당 감은 수).

\[B = \mu_0nI.\]

단면 크기와 위치에 무관합니다. 전자석, MRI, 전기 기기의 코일이 이 원리입니다. 도넛 모양으로 감은 토로이드는 안에서 \(B = \frac{\mu_0NI}{2\pi r}\)입니다.

예제 6.3.3

길이 0.50 m에 1000번 감은 솔레노이드에 2.0 A가 흐른다. 안의 자기장은?

풀이. \(n = 2000\) /m. \(B = (4\pi\times10^{-7})(2000)(2.0) \approx 5.0\times10^{-3}\) T.

요약
  1. \(\oint\vec B\cdot d\vec l = \mu_0I_{\text{안}}\). 대칭이 있으면 \(B\)를 바로 구한다.
  2. 솔레노이드 안 \(B = \mu_0nI\) (균일), 바깥 ≈ 0.

6.3.2

예제Ampère 법칙으로 솔레노이드의 자기장 구하기

∮B·dl = μ₀I · 직사각형 고리 · 토로이드

다루는 성취기준 [공통4-06-03]

출발점

Ampère 법칙(정상 전류): 닫힌 고리를 따라 자기장을 선적분하면 고리를 뚫는 전류 × \(\mu_0\).

\[\oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{뚫음}}.\]

Gauss 법칙과 같은 역할입니다. 대칭이 있으면 \(B\)를 적분 밖으로 꺼낼 수 있는 고리를 골라 적분 없이 \(B\)를 구합니다. 공통2의 Stokes 정리로 바꾸면 \(\nabla\times\mathbf B = \mu_0\mathbf J\).

먼저 예측

긴 솔레노이드 안의 자기장은 축 가까이와 벽 가까이 중 어디가 셀까요?

예측 확인

같습니다. 긴 솔레노이드 안의 자기장은 균일합니다. 아래 풀이에서 고리의 안쪽 변을 어디에 두어도 같은 답이 나오기 때문입니다.

단위 길이당 \(n\)번 감긴 긴 솔레노이드에 전류 \(I\)가 흐릅니다. 안의 자기장을 구하고, 길이 30 cm에 600번 감고 2.0 A를 흘릴 때 값을 구하세요.

풀이

  1. 대칭: 긴 솔레노이드 안의 \(\mathbf B\)는 축 방향, 바깥은 거의 0.
    이웃한 감은 선들의 자기장이 바깥에서 상쇄되고 안에서 더해진다. 길이가 반지름보다 훨씬 길 때의 근사.
  2. 직사각형 고리: 한 변(길이 \(L\))은 안쪽에 축과 나란히, 맞은편 변은 바깥에, 나머지 두 변은 축에 수직.
    안쪽 변에서 \(B\)가 일정하고 나란함.
  3. \(\oint\mathbf B\cdot d\mathbf l = BL + 0 + 0 + 0\).
    바깥 변은 \(B = 0\), 수직인 변은 \(\mathbf B\perp d\mathbf l\).
  4. 고리를 뚫는 전류 \(nLI\).
    길이 \(L\)에 감긴 선 \(nL\)개, 각각 \(I\).
  5. \(BL = \mu_0nLI\), \(B = \mu_0nI\). 수치: \(n = 2000\ \text{m}^{-1}\), \(B = 4\pi\times10^{-7}\times2000\times2.0 = 5.0\times10^{-3}\) T.
    안쪽 변의 위치가 답에 들어가지 않으므로 균일.

의미

솔레노이드는 자기장의 평행판 축전기입니다. 좁은 공간에 균일한 자기장을 만들고, 끝에서 보면 막대자석과 같은 자기장을 냅니다. MRI의 초전도 솔레노이드는 \(n\)과 \(I\)를 키워 1.5~3 T를 만듭니다. 다음 단원에서 이 자기장이 인덕턴스와 자기 에너지의 출발점이 됩니다.

검산

원형 고리 하나의 중심 자기장 \(\frac{\mu_0I}{2a}\)와 비교: 솔레노이드는 고리 \(n\)개가 촘촘히 늘어선 것이라 \(\mu_0nI\)는 크기 감각이 맞습니다. 단위 T·m/A × 1/m × A = T.

이해 확인

\(N\)번 감은 토로이드(도넛 모양) 안, 중심에서 거리 \(r\)인 곳의 자기장은?

답

반지름 \(r\)인 원 고리: \(B\cdot2\pi r = \mu_0NI\), \(B = \frac{\mu_0NI}{2\pi r}\). 토로이드 바깥은 고리를 뚫는 알짜 전류가 0이라 \(B = 0\).
