4.1.1전기용량

두 도체에 \(+Q\)와 \(-Q\)를 주면 그 사이에 전위차 \(V\)가 생기고, \(Q\)는 \(V\)에 비례합니다. 이런 장치를 축전기라 합니다.

정의 4.1.1 (전기용량)

\(C = \frac QV\). 단위 패럿 F = C/V.

평행판(넓이 \(A\), 간격 \(d\))이면 판 사이 \(E = \frac{\sigma}{\varepsilon_0} = \frac{Q}{\varepsilon_0A}\), \(V = Ed\)이므로

\[C = \frac{\varepsilon_0A}{d}.\]

판이 넓고 가까울수록 큽니다. 1 F는 아주 커서 보통 μF, pF를 씁니다.

예제 4.1.2

넓이 0.010 m², 간격 1.0 mm인 평행판 축전기에 12 V를 걸었다. \(C\), \(Q\), 저장 에너지는?

풀이. \(C = \frac{8.85\times10^{-12}\times0.010}{1.0\times10^{-3}} = 88.5\) pF. \(Q = CV = 1.06\times10^{-9}\) C. \(U = \frac12CV^2 = 6.4\times10^{-9}\) J.

4.1.2직렬과 병렬

  • 병렬: 전압이 같고 전하가 나뉜다. \(C = C_1 + C_2\).
  • 직렬: 전하가 같고 전압이 나뉜다. \(\frac1C = \frac{1}{C_1} + \frac{1}{C_2}\).

저항의 공식과 반대 꼴입니다(5.2절). 예: 2.0 μF와 4.0 μF를 병렬로 연결하면 6.0 μF, 직렬로 연결하면 \(\frac{2\times4}{2 + 4} = 1.33\) μF.

4.1.3저장 에너지

전하를 조금씩 옮겨 충전할 때 전위차 \(v = q/C\)를 거슬러 \(dq\)를 옮기는 일은 \(v\,dq\)입니다. 0에서 \(Q\)까지 적분하면

\[U = \frac{Q^2}{2C} = \frac12CV^2 = \frac12QV.\]

이 에너지는 판 사이의 전기장에 저장되어 있다고 볼 수 있습니다. 부피 \(Ad\)로 나누면 에너지 밀도는 \(u = \frac12\varepsilon_0E^2\)입니다. 카메라 플래시와 심장 제세동기는 축전기에 모은 에너지를 짧은 시간에 내보냅니다.

요약
  1. \(C = Q/V\), 평행판 \(C = \varepsilon_0A/d\).
  2. 병렬 \(C_1 + C_2\), 직렬 \(1/C = 1/C_1 + 1/C_2\).
  3. \(U = \frac12CV^2\), 에너지 밀도 \(\frac12\varepsilon_0E^2\).

4.1.4연습문제

기본

  1. 충전된 평행판 축전기를 전지에서 떼고 간격을 두 배로 하면 \(C\), \(V\), \(U\)는?
    답

    \(Q\) 일정. \(C\) 절반, \(V\) 두 배, \(U = Q^2/2C\) 두 배 (판을 벌리는 일이 저장됨).

  2. 3.0 μF 세 개를 직렬로 연결하면?
    답

    1.0 μF.

4.1.2

유도평행판 축전기의 전기용량과 저장 에너지

C = ε₀A/d · U = ½CV² · 유전체

다루는 성취기준 [공통4-04-01]

무엇을 유도하나

넓이 \(A\), 간격 \(d\)인 평행판 축전기: \(C = \dfrac{\varepsilon_0A}{d}\). 저장 에너지 \(U = \dfrac{Q^2}{2C} = \dfrac12CV^2\), 에너지 밀도 \(u = \dfrac12\varepsilon_0E^2\).

모형과 가정

  • 판 크기 ≫ 간격: 판 사이 전기장이 균일하고 가장자리 효과를 무시.
  • 전기용량의 정의 \(C = \frac QV\): 전위차 1 V당 담기는 전하. 모양과 재료만으로 정해짐.

유도

  1. 판 사이 \(E = \frac{\sigma}{\varepsilon_0} = \frac{Q}{\varepsilon_0A}\).
    02-R 문제 2의 두 판 중첩.
  2. \(V = Ed = \frac{Qd}{\varepsilon_0A}\).
    균일한 전기장의 전위차.
  3. \(C = \frac QV = \frac{\varepsilon_0A}{d}\).
    \(Q\)가 소거되어 기하만 남는다.
  4. 충전 중 전하가 \(q\)일 때 \(dq\)를 옮기는 일 \(dW = \frac qC\,dq\). \(U = \int_0^Q\frac qC\,dq = \frac{Q^2}{2C}\).
    전위차가 전하에 비례해 커지므로 적분(공통3 3-01의 용수철과 같은 구조).
  5. \(U = \frac12CV^2 = \frac12\frac{\varepsilon_0A}{d}(Ed)^2 = \frac12\varepsilon_0E^2(Ad)\). 부피 \(Ad\)로 나누면 \(u = \frac12\varepsilon_0E^2\).
    에너지가 판이 아니라 전기장 속에 저장된다고 볼 수 있다.

결과 확인

  • 수치: \(A = 1\ \text{cm}^2\), \(d = 1\) mm이면 \(C = \frac{8.85\times10^{-12}\times10^{-4}}{10^{-3}} = 0.89\) pF. 아주 작습니다. 실제 축전기는 넓은 박막을 말고 유전체를 넣어 크게 만듭니다.
  • 유전체: 유전 상수 \(\kappa\)인 물질을 채우면 분자 쌍극자가 정렬해(01-03 카드) 판 사이 전기장을 줄이므로 \(C = \kappa\varepsilon_0\frac Ad\). 물 \(\kappa \approx 80\).
  • 극한: \(d \to 0\)이면 \(C \to \infty\)이지만, 실제로는 절연이 깨지는 전기장 한계로 걸린 전압이 제한됩니다.

한계

가장자리에서는 전기장이 바깥으로 휘어(가장자리 효과) 실제 전기용량이 조금 큽니다. 원통, 구 축전기는 같은 방법(Gauss 법칙 → 전위차 → \(C\))으로 구합니다.
