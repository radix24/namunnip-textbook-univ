7.1.1자기 선속과 패러데이 법칙

코일에 자석을 넣었다 뺐다 하면, 자석이 움직이는 동안에만 전류가 흐릅니다. 패러데이가 발견한 이 현상을 전자기 유도라 합니다.

면을 지나는 자기 선속 \(\Phi_B = \int\vec B\cdot d\vec A\) (균일하면 \(BA\cos\phi\), 단위 웨버 Wb = T·m²)를 정의하면

정리 7.1.1 (패러데이 법칙) \[\varepsilon = -\frac{d\Phi_B}{dt} \quad (N\text{번 감은 코일이면 } -N\frac{d\Phi_B}{dt}).\]

선속은 세 가지 방법으로 바뀔 수 있습니다: 자기장의 세기, 고리의 넓이, 고리와 자기장 사이 각.

7.1.2렌츠 법칙

음의 부호의 뜻: 유도 전류는 자기 선속의 변화를 방해하는 방향으로 흐릅니다. 자석의 N극을 고리에 가까이 하면, 고리는 N극을 밀어내도록(고리 쪽 면이 N극이 되도록) 전류가 흐릅니다. 만약 반대로 흐른다면 자석을 끌어당겨 더 빨리 가까워지고 전류가 더 커지는 순환이 생겨 에너지 보존이 깨질 것입니다.

7.1.3운동 기전력과 발전기

예제 7.1.2

자기장 0.40 T 속에서 길이 0.50 m인 막대가 ㄷ자 레일 위를 2.0 m/s로 미끄러진다. 회로 저항은 0.20 Ω이다. 기전력, 전류, 막대를 일정한 속력으로 끄는 힘은?

풀이. 넓이가 1초에 \(Lv\)씩 늘므로 \(\varepsilon = BLv = 0.40\) V. \(I = 2.0\) A. 막대는 자기력 \(ILB = 0.40\) N을 운동 반대 방향으로 받으므로(렌츠) 같은 힘으로 끌어야 합니다. 끄는 일률 \(Fv = 0.80\) W = 저항의 전력 \(I^2R = 0.80\) W. 역학적 일이 전기 에너지로 바뀌었습니다.

넓이 \(A\), \(N\)번 감은 코일이 자기장 속에서 각속도 \(\omega\)로 돌면 \(\Phi_B = BA\cos\omega t\)이므로

\[\varepsilon = NBA\omega\sin\omega t.\]

사인 모양의 교류 기전력입니다. 발전소의 발전기가 이 원리이고, 8단원의 교류 회로가 여기서 시작합니다. 예: \(N = 100\), \(A = 0.010\) m², \(B = 0.50\) T, 60 Hz이면 최대 기전력은 약 190 V입니다.

자기장이 변하면 도선이 없어도 공간에 소용돌이 모양의 전기장이 생깁니다. 이 전기장은 보존장이 아니어서(닫힌 고리의 선적분이 0이 아님) 전위로 나타낼 수 없습니다. 이것이 9단원 맥스웰 방정식의 하나입니다.

요약
  1. \(\varepsilon = -N\,d\Phi_B/dt\). \(\Phi_B = BA\cos\phi\).
  2. 렌츠: 유도 전류는 선속 변화를 방해한다(에너지 보존).
  3. 운동 기전력 \(BLv\), 발전기 \(NBA\omega\sin\omega t\).

7.1.4연습문제

기본

  1. 넓이 0.020 m² 고리에 수직인 자기장이 0.10 s 동안 0.50 T에서 0으로 줄었다. 평균 기전력은?
    답

    \(\frac{0.010}{0.10} = 0.10\) V.

7.1.2

예제Faraday 법칙과 Lenz 법칙: 자기 선속이 바뀌면 기전력이 생긴다

ℰ = −dΦ/dt · 움직이는 막대 · 발전기 · 문제 해결 전략

다루는 성취기준 [공통4-07-01]

출발점

자기 선속 \(\Phi_B = \int\mathbf B\cdot d\mathbf A\).

Faraday 법칙: 고리를 지나는 자기 선속이 변하면 고리에 기전력 \(\mathcal E = -\frac{d\Phi_B}{dt}\)이 생긴다(\(N\)번 감으면 \(N\)배).

Lenz 법칙(음수 부호의 뜻): 유도 전류는 선속의 변화를 방해하는 방향으로 흐른다. 에너지 보존이 이 방향을 강제합니다. 반대라면 전류가 선속을 더 키우고 그것이 전류를 더 키워 공짜 에너지가 생깁니다.

문제 해결 전략 · 전자기 유도
  1. 고리와 그 넓이 벡터 방향을 정한다.
  2. \(\Phi_B(t)\)를 쓴다. 변하는 것이 \(B\)인지, 넓이인지, 각도인지 확인한다.
  3. 크기 \(|\mathcal E| = N\left|\frac{d\Phi_B}{dt}\right|\).
  4. 방향은 Lenz 법칙으로: 선속이 늘면 반대 방향, 줄면 같은 방향의 자기장을 만드는 전류.
  5. 전류 \(I = \frac{\mathcal E}{R}\), 전력 \(\mathcal EI\)가 외부에서 한 일률과 같은지 확인한다.
먼저 예측

구리관 안으로 강한 자석을 떨어뜨리면 그냥 떨어질 때보다 빨리 떨어질까요, 늦게 떨어질까요? 구리는 자석에 붙지 않습니다.

예측 확인

훨씬 늦게 떨어집니다. 관 벽에 유도 전류(맴돌이 전류)가 생겨 자석의 운동을 방해하기 때문입니다(Lenz 법칙).

자기장 \(B = 0.50\) T가 지면에 들어가는 방향으로 있는 곳에서, 간격 \(L = 0.20\) m인 두 레일 위를 저항 없는 막대가 \(v = 3.0\) m/s로 오른쪽으로 움직입니다. 레일 왼쪽 끝은 \(R = 0.60\ \Omega\) 저항으로 이어져 있습니다. 기전력, 전류와 방향, 막대를 일정한 속력으로 끄는 데 필요한 힘과 일률을 구하세요.

풀이

  1. 고리 넓이 \(A = Lx\), \(\Phi_B = BLx\). \(\mathcal E = BL\frac{dx}{dt} = BLv = 0.50(0.20)(3.0) = 0.30\) V.
    넓이가 변한다.
  2. \(I = \frac{0.30}{0.60} = 0.50\) A. 지면에 들어가는 선속이 느므로, 유도 전류는 나오는 방향의 자기장을 만든다: 고리를 반시계 방향으로 돈다.
    Lenz 법칙. 오른손: 반시계 전류는 고리 안에 나오는 자기장.
  3. 막대가 받는 자기력 \(ILB = 0.50(0.20)(0.50) = 0.050\) N, 방향은 왼쪽(운동 방해).
    \(I\mathbf L\times\mathbf B\). Lenz 법칙과 일치.
  4. 일정한 속력이려면 오른쪽으로 0.050 N. 일률 \(Fv = 0.15\) W \(= I^2R = 0.25\times0.60\).
    끄는 일률이 모두 저항의 열이 된다.

의미

4단계가 발전기의 원리입니다. 역학적 일(손, 증기 터빈, 바람)이 전기 에너지로 바뀌고, 전기를 많이 쓸수록(\(R\)이 작을수록, \(I\)가 클수록) 돌리기가 더 힘들어집니다. 거꾸로 전류를 흘려 막대를 움직이면 전동기입니다. 회생 제동은 전동기를 발전기로 바꿔 제동력과 전기를 동시에 얻습니다.

검산

단위: T·m·m/s = (N/(A·m))·m²/s = N·m/(A·s) = J/C = V. 에너지 수지가 0.15 W로 맞습니다.

7.1.3

실습발전기 돌려 보기

실습 · 선속의 변화율이 기전력

다루는 성취기준 [공통4-07-01]

목표

자기장 속에서 도는 코일의 자기 선속과 유도 기전력을 함께 그려, 기전력이 선속의 크기가 아니라 선속이 변하는 빠르기에 따라 정해짐을 확인합니다. 최대 기전력 \(NBA\omega\)가 각 요소에 어떻게 의존하는지 봅니다. 성취기준 [공통4-07-01].

준비

위 그림은 왼쪽에서 오른쪽으로 향하는 균일한 자기장 속에서 세로축 둘레로 도는 코일을 옆에서 본 모습입니다(폭이 좁아 보일 때가 자기장과 나란할 때). 아래 그래프에서 회색 점선은 선속, 주황 실선은 기전력이며 각각 최댓값으로 나눈 비율입니다.

절차

  1. 재생하고, 선속이 최대인 순간(코일 면이 자기장에 수직)의 기전력을 읽는다.
  2. 선속이 0인 순간의 기전력을 읽는다.
  3. N, B, A, f를 하나씩 두 배로 하며 최대 기전력의 변화를 기록한다.

기대 결과

  • 선속이 최대일 때 기전력은 0, 선속이 0일 때 기전력이 최대. 두 곡선은 90° 어긋난다(코사인과 사인).
  • 최대 기전력은 N, B, A, f에 각각 비례한다.
  • 실제 발전소 규모(예: N = 100, A = 100 cm², B = 0.5 T, 60 Hz)면 최대 약 190 V.

분석

  1. 미분으로 보면 \(\varepsilon = -N\frac{d}{dt}(BA\cos\omega t)\)입니다. 그래프에서 주황 곡선이 회색 곡선의 기울기(부호 반대)에 해당하는지 확인해 보세요.
  2. 코일에 전구를 연결하면 코일을 돌리기가 더 힘들어집니다. 렌츠 법칙과 에너지 보존으로 설명해 보세요.
