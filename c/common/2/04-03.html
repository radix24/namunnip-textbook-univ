4.3.1

예제다변수 연쇄 법칙: 모든 길을 따라 더한다

나무 그림 · 극좌표 변환 · 음함수 미분

다루는 성취기준 [공통2-04-03]

정리

\(z = f(x, y)\)가 미분가능하고 \(x = x(t)\), \(y = y(t)\)가 미분가능하면 \(\dfrac{dz}{dt} = \dfrac{\partial f}{\partial x}\dfrac{dx}{dt} + \dfrac{\partial f}{\partial y}\dfrac{dy}{dt}\).

\(x = x(s,t)\), \(y = y(s,t)\)이면 \(\dfrac{\partial z}{\partial s} = f_x\dfrac{\partial x}{\partial s} + f_y\dfrac{\partial y}{\partial s}\) (\(t\)도 같다).

왜 그런가

  1. \(\Delta x = x(t + \Delta t) - x(t)\), \(\Delta y\)도 같이. 미분가능성: \(\Delta z = f_x\Delta x + f_y\Delta y + \varepsilon\sqrt{\Delta x^2 + \Delta y^2}\).
    4-02 카드의 정의. 편도함수의 존재만으로는 이 식이 없다.
  2. \(\Delta t\)로 나누면 \(\frac{\Delta z}{\Delta t} = f_x\frac{\Delta x}{\Delta t} + f_y\frac{\Delta y}{\Delta t} \pm \varepsilon\sqrt{\left(\frac{\Delta x}{\Delta t}\right)^2 + \left(\frac{\Delta y}{\Delta t}\right)^2}\).
    \(|\Delta t|\)를 근호 안으로 넣었다(부호는 \(\Delta t\)의 부호).
  3. \(\Delta t \to 0\)이면 \(\Delta x, \Delta y \to 0\)이라 \(\varepsilon \to 0\), 근호 안은 \(x'^2 + y'^2\)로 유한. 마지막 항 → 0.
    \(x, y\)의 연속성(미분가능하므로).

나무 그림: \(z\)에서 중간변수(\(x, y\))로, 중간변수에서 독립변수(\(s, t\))로 가지를 그립니다. 구할 도함수는 \(z\)에서 그 독립변수까지 가는 모든 길의 도함수 곱을 더한 것입니다.

(가) \(z = f(x,y)\), \(x = r\cos\theta\), \(y = r\sin\theta\)일 때 \(z_r\), \(z_\theta\)를 \(f_x, f_y\)로 나타내고, \(f_x^2 + f_y^2 = z_r^2 + \frac{1}{r^2}z_\theta^2\)임을 보이세요. (나) \(x^3 + y^3 + z^3 + 6xyz = 1\)이 정하는 \(z(x,y)\)의 \(\frac{\partial z}{\partial x}\)를 구하세요.

풀이

  1. \(z_r = f_x\cos\theta + f_y\sin\theta\).
    \(\frac{\partial x}{\partial r} = \cos\theta\), \(\frac{\partial y}{\partial r} = \sin\theta\).
  2. \(z_\theta = -f_xr\sin\theta + f_yr\cos\theta\).
    \(\frac{\partial x}{\partial\theta} = -r\sin\theta\), \(\frac{\partial y}{\partial\theta} = r\cos\theta\).
  3. \(z_r^2 + \frac{1}{r^2}z_\theta^2 = (f_x\cos\theta + f_y\sin\theta)^2 + (-f_x\sin\theta + f_y\cos\theta)^2 = f_x^2 + f_y^2\).
    전개하면 교차항 \(\pm2f_xf_y\sin\theta\cos\theta\)가 소거되고 \(\sin^2 + \cos^2 = 1\).
  4. (나) \(F(x,y,z) = x^3 + y^3 + z^3 + 6xyz - 1 = 0\)을 \(x\)로 미분(\(y\) 고정, \(z\)는 \(x\)의 함수): \(F_x + F_z\frac{\partial z}{\partial x} = 0\).
    연쇄 법칙: \(F\)가 \(x\)에 직접, 그리고 \(z\)를 거쳐 의존. 상수 0의 도함수는 0.
  5. \(\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z} = -\dfrac{3x^2 + 6yz}{3z^2 + 6xy} = -\dfrac{x^2 + 2yz}{z^2 + 2xy}\) (\(F_z \ne 0\)).
    \(F_z \ne 0\)이면 음함수 정리로 \(z(x,y)\)가 국소적으로 존재.

의미

(가)의 결과는 기울기의 크기 \(|\nabla f|\)가 좌표계를 바꿔도 같다는 뜻입니다. 물리량은 좌표를 어떻게 잡든 같아야 하므로, 이런 "좌표에 따라 변하지 않는 양"을 찾는 것이 연쇄 법칙의 중요한 쓰임입니다.

검산

(가) \(f = x^2 + y^2 = r^2\)이면 왼쪽 \(4x^2 + 4y^2 = 4r^2\), 오른쪽 \(z_r = 2r\), \(z_\theta = 0\)이므로 \(4r^2\). 일치합니다.

흔한 오해

  • \(\partial\)를 분수처럼 약분: \(\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}\)의 음수 부호는 약분으로는 나오지 않습니다. 편도함수는 "무엇을 고정했는가"에 따라 달라지기 때문입니다.
