이 절에서 배울 것
  • 조건 \(g = k\) 아래에서 \(f\)의 최댓값·최솟값을 \(\nabla f = \lambda\nabla g\)로 구한다.
  • 등위선이 조건 곡선에 접한다는 그림으로 방법을 이해한다.
먼저 알아야 할 것
  • 기울기 벡터와 등위선 (4.5절), 닫힌 영역의 최대·최소 (5.2절).

5.3.1생각

"재료 12 m²로 뚜껑 없는 상자를 만들 때 부피를 최대로"처럼, 변수들이 어떤 조건 \(g(x, y) = k\)를 만족하며 움직일 때의 최대·최소를 구하는 문제가 많습니다.

조건 곡선 \(g = k\)를 따라 걸으며 \(f\)의 등위선을 지나간다고 생각해 봅시다. 등위선을 가로지르는 동안은 \(f\)가 계속 커지거나 작아집니다. \(f\)가 최대나 최소가 되는 곳은 조건 곡선이 등위선을 가로지르지 않고 살짝 접하는 곳입니다. 두 곡선이 접하면 법선이 평행하고, 법선은 기울기 벡터이므로(4.5절)

정리 5.3.1 (라그랑주 승수법)

\(g(x, y) = k\) 위에서 \(f\)의 최댓값·최솟값은 다음을 만족하는 점에서 나타난다(\(\nabla g \ne \mathbf 0\)).

\[\nabla f = \lambda\nabla g, \qquad g(x, y) = k.\]

\(\lambda\)를 라그랑주 승수라 합니다. 미지수 \(x, y, \lambda\) 세 개에 식 세 개(\(f_x = \lambda g_x\), \(f_y = \lambda g_y\), \(g = k\))입니다. 풀어서 나온 점들의 \(f\)값을 비교합니다. 삼변수도 같습니다.

5.3.2예제

예제 5.3.2

원 \(x^2 + y^2 = 1\) 위에서 \(f = x^2 + 2y^2\)의 최댓값과 최솟값을 구하여라.

풀이. \(2x = 2\lambda x\), \(4y = 2\lambda y\), \(x^2 + y^2 = 1\).

  • 첫 식에서 \(x = 0\) 또는 \(\lambda = 1\).
  • \(x = 0\)이면 \(y = \pm1\), \(f = 2\).
  • \(\lambda = 1\)이면 둘째 식에서 \(4y = 2y\), \(y = 0\), \(x = \pm1\), \(f = 1\).

최댓값 2, 최솟값 1. 등위선 \(x^2 + 2y^2 = c\)는 타원이고, \(c = 1\)과 \(c = 2\)인 타원이 단위원에 접합니다.

예제 5.3.3

재료 12 m²로 뚜껑 없는 직육면체 상자를 만들 때 최대 부피를 구하여라.

풀이. 가로 \(x\), 세로 \(y\), 높이 \(z\). \(V = xyz\), 조건 \(g = 2xz + 2yz + xy = 12\).

\[yz = \lambda(2z + y), \quad xz = \lambda(2z + x), \quad xy = \lambda(2x + 2y).\]

각각 \(x, y, z\)를 곱하면 좌변이 모두 \(xyz\)이므로 \(\lambda(2xz + xy) = \lambda(2yz + xy) = \lambda(2xz + 2yz)\). (\(\lambda \ne 0\)) 첫 두 식에서 \(x = y\), 뒤 두 식에서 \(xy = 2xz\), 곧 \(y = 2z\). 따라서 \(x = y = 2z\)이고 조건에 넣으면 \(12z^2 = 12\), \(z = 1\). 최대 부피 \(2\cdot2\cdot1 = 4\) m³.

경제학의 효용 최대화(예산 조건), 물리의 평형 상태, 통계의 최대가능도 추정 등에서 같은 방법을 씁니다. \(\lambda\)는 "조건 \(k\)를 1만큼 늘릴 때 최댓값이 늘어나는 비율"이라는 뜻도 있습니다.

요약
  1. 조건부 최대·최소: \(\nabla f = \lambda\nabla g\), \(g = k\)를 푼다.
  2. 뜻: \(f\)의 등위선이 조건 곡선에 접하는 점.
  3. 나온 점들의 \(f\)값을 비교한다.

5.3.3연습문제

기본

  1. \(x + y = 10\)일 때 \(xy\)의 최댓값은?
    답

    \(y = \lambda\), \(x = \lambda\)에서 \(x = y = 5\). 25.

응용

  1. 원 \(x^2 + y^2 = 1\) 위에서 \(f = x + y\)의 최댓값은?
    답

    \(1 = 2\lambda x\), \(1 = 2\lambda y\)에서 \(x = y = \pm\frac{1}{\sqrt2}\). 최댓값 \(\sqrt2\).

5.3.2

예제Lagrange 승수법: 제약 곡선과 등위선이 맞닿는 곳

∇f = λ∇g · 모형 세우기

다루는 성취기준 [공통2-05-03]

정리

\(f, g\)가 연속인 편도함수를 갖고, \(g = c\) 위에서 \(f\)가 점 \(\mathbf p\)에서 극값을 가지며 \(\nabla g(\mathbf p) \ne \mathbf 0\)이면, 어떤 \(\lambda\)에 대해 \(\nabla f(\mathbf p) = \lambda\nabla g(\mathbf p)\).

증명 (곡선 위의 일변수 문제로)

  1. \(\mathbf p\)를 지나는 제약면 \(g = c\) 위의 매끄러운 곡선 \(\mathbf r(t)\), \(\mathbf r(0) = \mathbf p\)를 아무거나 잡는다.
    \(\nabla g \ne \mathbf 0\)이면 \(g = c\)는 \(\mathbf p\) 근처에서 매끄러운 곡면(곡선)이다(음함수 정리).
  2. \(h(t) = f(\mathbf r(t))\)는 \(t = 0\)에서 극값이므로 \(h'(0) = \nabla f(\mathbf p)\cdot\mathbf r'(0) = 0\).
    일변수 페르마 정리와 연쇄 법칙.
  3. 곧 \(\nabla f(\mathbf p)\)는 제약면의 모든 접선 방향에 수직이다.
    \(\mathbf r\)은 임의였다.
  4. 제약면의 접선 방향에 모두 수직인 벡터는 법선 \(\nabla g(\mathbf p)\)에 평행하다. 따라서 \(\nabla f = \lambda\nabla g\).
    4-04 카드: \(\nabla g\)는 등위면에 수직. 접평면에 수직인 방향은 하나뿐.

그림으로: \(f\)의 등위선을 제약 곡선을 따라 움직이며 보면, 극값에서는 등위선이 제약 곡선을 가로지르지 않고 맞닿습니다. 맞닿으면 두 법선이 평행합니다.

먼저 예측

겉넓이가 정해진 뚜껑 없는 상자의 부피를 최대로 하면, 높이는 밑변 한 변과 비교해 어떨까요?

예측 확인

밑변이 정사각형이고, 높이는 한 변의 절반입니다. 뚜껑이 없어 위쪽 판을 아끼는 만큼 납작해집니다.

겉넓이가 \(12\ \text{m}^2\)인 뚜껑 없는 직육면체 상자의 부피를 최대로 하세요.

풀이

  1. 가로 \(x\), 세로 \(y\), 높이 \(z\). 최대화 \(V = xyz\), 제약 \(g = xy + 2xz + 2yz = 12\) (\(x, y, z > 0\)).
    바닥 1개, 옆면 4개. 뚜껑 없음.
  2. \(\nabla V = \lambda\nabla g\): \(yz = \lambda(y + 2z)\), \(xz = \lambda(x + 2z)\), \(xy = \lambda(2x + 2y)\).
    미지수 4개, 제약까지 방정식 4개.
  3. 첫 식에 \(x\), 둘째 식에 \(y\)를 곱하면 \(xyz = \lambda(xy + 2xz) = \lambda(xy + 2yz)\). \(\lambda \ne 0\)이므로 \(xz = yz\), \(x = y\).
    \(\lambda = 0\)이면 \(yz = 0\)이 되어 \(V = 0\), 최대가 아니다. 양변에 같은 \(xyz\)를 만드는 것이 요령.
  4. 둘째에 \(y\), 셋째에 \(z\): \(\lambda(xy + 2yz) = \lambda(2xz + 2yz)\) → \(xy = 2xz\), \(y = 2z\).
    같은 요령.
  5. \(x = y = 2z\)를 제약에 넣으면 \(4z^2 + 4z^2 + 4z^2 = 12\), \(z = 1\). \(x = y = 2\), \(V = 4\ \text{m}^3\).
    바닥은 정사각형, 높이는 한 변의 절반.

의미

승수 \(\lambda\)에도 뜻이 있습니다. 최댓값이 제약값에 따라 바뀌는 비율 \(\frac{dV^*}{dS}\)가 \(\lambda\)입니다. 이 예에서 \(\lambda = \frac12\)이므로, 겉넓이를 1 m² 늘리면 최대 부피가 약 0.5 m³ 늘어납니다. 경제학에서는 이를 잠재 가격(shadow price)이라 부릅니다.

검산

최대인 이유: 어느 변수가 0이나 무한대로 가면 제약을 지키면서 \(V \to 0\)이 되고, 후보가 하나뿐이므로 그 점이 최대입니다. 수치로: \(x = y = 2.1\)이면 \(z = \frac{12 - 4.41}{8.4} \approx 0.904\), \(V \approx 3.99 < 4\).

흔한 오해

  • 최대인지 최소인지: 승수법은 후보만 줍니다. 후보의 값을 비교하거나 끝 행동을 봐야 합니다.
  • \(\lambda\)로 나누기: \(\lambda = 0\)인 경우와 \(x = 0\)처럼 나눌 수 없는 경우를 따로 확인합니다.
5.3.3

실습조건 곡선 위에서 최댓값 찾기

실습 · 라그랑주 승수법의 그림

다루는 성취기준 [공통2-05-03]

목표

조건 곡선 \(g = k\)를 따라 점을 움직이며 \(f\)의 값을 재고, 최댓값과 최솟값이 나오는 점에서 \(\nabla f\)와 \(\nabla g\)가 평행함(\(\nabla f = \lambda\nabla g\))을 확인합니다. 성취기준 [공통2-05-03].

준비

배경은 \(f\)의 등위선 지도, 검은 곡선이 조건 곡선입니다. 주황 점을 조건 곡선 위에서 움직이면 빨간 \(\nabla f\)와 파란 \(\nabla g\)가 그려집니다. 아래 그래프는 조건 곡선을 따라 한 바퀴 돌 때 \(f\)의 값입니다.

절차

  1. 5.3절 예제(\(x^2 + 2y^2\), 단위원)에서 위치를 돌려 최댓값과 최솟값이 나오는 각을 찾는다.
  2. 그 점들에서 두 화살표의 사잇각(출력)을 읽는다.
  3. 최대·최소가 아닌 점에서 등위선이 조건 곡선을 가로지르는지 본다.
  4. \(x + y\)와 \(xy\)에서도 같은 일을 하고, \(xy\)의 경우 최댓값이 몇 번 나오는지 센다.

기대 결과

  • \(x^2 + 2y^2\): 90°, 270°에서 최댓값 2, 0°, 180°에서 최솟값 1. 그 점에서 사잇각 0° 또는 180°.
  • 극값이 아닌 점에서는 등위선이 조건 곡선을 가로지르고, 두 기울기 벡터가 평행하지 않다.
  • \(x + y\)는 45°에서 최대 \(\sqrt2\). \(xy\)는 45°와 225°에서 최대 \(\frac12\).

분석

  1. 최댓값에서 사잇각이 0°이고 최솟값에서 180°인 경우가 있습니다. \(\lambda\)의 부호와 어떤 관계일까요?
  2. 조건 곡선을 타원으로 바꾸면 \(x^2 + 2y^2\)의 최댓값과 최솟값은? 장치로 확인하고 라그랑주 방정식으로 풀어 비교해 보세요.

더 해 보기

"둘레가 정해진 직사각형 가운데 넓이가 가장 큰 것"을 \(f = xy\), 조건 \(2x + 2y = p\)로 풀고, 등위선 \(xy = c\)가 직선에 접하는 그림을 그려 보세요.
