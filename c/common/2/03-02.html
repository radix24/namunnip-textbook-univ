3.2.1도함수와 접선

도함수도 성분별로 정의합니다: \(\mathbf r'(t) = \langle f'(t), g'(t), h'(t)\rangle\). 뜻은 공통1과 같습니다. \(\frac{\mathbf r(t + h) - \mathbf r(t)}{h}\)는 곡선 위 두 점을 잇는 화살표를 \(h\)로 나눈 것이고, \(h \to 0\)이면 곡선에 접하는 방향이 됩니다.

  • \(\mathbf r'(t)\): 접선벡터. 운동에서는 속도 \(\mathbf v\).
  • \(|\mathbf r'(t)|\): 속력.
  • \(\mathbf T = \frac{\mathbf r'}{|\mathbf r'|}\): 단위접선벡터.
  • \(\mathbf r''(t)\): 가속도 \(\mathbf a\).

미분 공식은 실수 함수와 같습니다. 내적과 외적에도 곱의 미분법이 성립합니다: \((\mathbf u\cdot\mathbf v)' = \mathbf u'\cdot\mathbf v + \mathbf u\cdot\mathbf v'\), \((\mathbf u\times\mathbf v)' = \mathbf u'\times\mathbf v + \mathbf u\times\mathbf v'\) (외적은 순서 유지).

예제 3.2.1

나선 \(\mathbf r(t) = \langle\cos t, \sin t, t\rangle\)의 속도, 속력, \(t = \frac\pi2\)에서의 접선을 구하여라.

풀이. \(\mathbf r' = \langle-\sin t, \cos t, 1\rangle\), 속력 \(\sqrt{\sin^2t + \cos^2t + 1} = \sqrt2\) (일정). \(t = \frac\pi2\)에서 점 \((0, 1, \frac\pi2)\), 방향 \(\langle-1, 0, 1\rangle\). 접선: \(x = -s\), \(y = 1\), \(z = \frac\pi2 + s\).

예제 3.2.2

\(|\mathbf r(t)|\)가 일정하면 \(\mathbf r'(t)\)은 \(\mathbf r(t)\)에 수직임을 보여라.

풀이. \(\mathbf r\cdot\mathbf r = |\mathbf r|^2 = c\)를 미분하면 \(2\mathbf r\cdot\mathbf r' = 0\). 구면 위를 움직이는 점의 속도는 언제나 반지름에 수직입니다(원운동에서 속도가 접선 방향인 것과 같음).

3.2.2적분과 운동

적분도 성분별로 합니다. 가속도를 알면 적분해 속도를, 다시 적분해 위치를 구합니다. 적분상수는 처음 속도와 처음 위치로 정합니다.

예제 3.2.3 (포물선 운동)

원점에서 \(\mathbf v(0) = \langle10, 0, 10\rangle\) m/s로 던진 공의 가속도가 \(\mathbf a = \langle0, 0, -9.8\rangle\)일 때 위치와 떨어지는 지점을 구하여라.

풀이. \(\mathbf v(t) = \langle10, 0, 10 - 9.8t\rangle\), \(\mathbf r(t) = \langle10t, 0, 10t - 4.9t^2\rangle\). \(z = 0\)인 \(t = \frac{10}{4.9} \approx 2.04\) s에 \(x \approx 20.4\) m 지점에 떨어집니다.

요약
  1. 미분·적분은 성분별로. \(\mathbf r'\) = 속도(접선), \(|\mathbf r'|\) = 속력, \(\mathbf r''\) = 가속도.
  2. \(|\mathbf r|\)가 일정하면 \(\mathbf r \perp \mathbf r'\).

3.2.3연습문제

기본

  1. \(\mathbf r(t) = \langle t^2, t^3, t\rangle\)의 \(t = 1\)에서 단위접선벡터는?
    답

    \(\mathbf r'(1) = \langle2, 3, 1\rangle\), \(\frac{1}{\sqrt{14}}\langle2, 3, 1\rangle\).

  2. \(\int_0^1\langle2t, 3t^2, 1\rangle dt\)는?
    답

    \(\langle1, 1, 1\rangle\).

3.2.2

예제벡터함수의 미분과 적분: 위치, 속도, 가속도

성분별 미분 · 곱의 법칙 · 포물선 운동

다루는 성취기준 [공통2-03-02]

정의와 근거

\(\mathbf r(t) = (x(t), y(t), z(t))\)의 도함수는 \(\mathbf r'(t) = \lim_{h\to0}\frac{\mathbf r(t+h) - \mathbf r(t)}{h}\)입니다. 벡터의 극한은 성분마다의 극한이므로 성분별로 미분하면 됩니다. 적분도 성분별입니다.

  • \(\mathbf r'(t)\)는 곡선의 접선 방향(할선 방향의 극한). \(\mathbf r'(t) \ne \mathbf 0\)일 때 단위접선 \(\mathbf T = \frac{\mathbf r'}{|\mathbf r'|}\).
  • 운동으로 읽으면 속도 \(\mathbf v = \mathbf r'\), 속력 \(|\mathbf v|\), 가속도 \(\mathbf a = \mathbf r''\).
  • 곱의 법칙: \((\mathbf u\cdot\mathbf v)' = \mathbf u'\cdot\mathbf v + \mathbf u\cdot\mathbf v'\), \((\mathbf u\times\mathbf v)' = \mathbf u'\times\mathbf v + \mathbf u\times\mathbf v'\) (외적은 순서 유지). 성분으로 전개해 공통1의 곱의 법칙을 쓰면 나옵니다.
자주 쓰는 사실

\(|\mathbf r(t)|\)가 상수이면 \(\mathbf r(t)\perp\mathbf r'(t)\).

증명

  1. \(\mathbf r\cdot\mathbf r = |\mathbf r|^2 = c\).
    가정.
  2. 미분: \(2\,\mathbf r\cdot\mathbf r' = 0\).
    내적의 곱의 법칙. 원 위를 도는 점의 속도는 반지름에 수직. 속력이 일정하면 같은 논리로 \(\mathbf v\perp\mathbf a\).
먼저 예측

같은 속력으로 30°와 60°로 던진 공 중 어느 쪽이 더 멀리 갈까요?

예측 확인

같은 거리에 떨어집니다(공기 저항 없음). 도달 거리가 \(\sin2\alpha\)에 비례하고 \(\sin60° = \sin120°\)이기 때문입니다.

지면에서 속력 \(v_0\), 앙각 \(\alpha\)로 던진 공(가속도 \(\mathbf a = (0, -g)\))의 위치를 구하고, 최대 수평 도달 거리를 주는 \(\alpha\)를 구하세요(공기 저항 무시).

풀이

  1. \(\mathbf v(t) = \int\mathbf a\,dt = (0, -gt) + \mathbf C\). \(\mathbf v(0) = (v_0\cos\alpha, v_0\sin\alpha)\)이므로 \(\mathbf v(t) = (v_0\cos\alpha,\ v_0\sin\alpha - gt)\).
    성분별 적분. 적분 상수도 벡터이고 초기조건으로 정한다.
  2. \(\mathbf r(t) = \left(v_0t\cos\alpha,\ v_0t\sin\alpha - \tfrac12gt^2\right)\).
    \(\mathbf r(0) = \mathbf 0\)으로 다시 적분.
  3. 착지: \(y = 0\), \(t > 0\) → \(t^* = \frac{2v_0\sin\alpha}{g}\).
    \(t(v_0\sin\alpha - \frac12gt) = 0\).
  4. 도달 거리 \(R(\alpha) = v_0t^*\cos\alpha = \frac{v_0^2\sin2\alpha}{g}\). \(\sin2\alpha\)는 \(\alpha = 45°\)에서 최대 1, \(R_{\max} = \frac{v_0^2}{g}\).
    \(2\sin\alpha\cos\alpha = \sin2\alpha\). \(\alpha \in (0, \frac\pi2)\)에서 닫힌 꼴로 최댓값을 읽음.

의미

성분별로 적분하고 초기조건으로 상수를 정하면 운동이 완전히 정해집니다. 위치와 속도를 알면 미래가 정해진다는 뉴턴 역학의 결정론을 수학으로 쓴 것입니다. 도달 거리 \(\frac{v_0^2\sin2\alpha}{g}\)는 공통3 1-03 카드에서 높이가 다를 때로 넓어집니다.

검산

단위: \(\frac{(\text{m/s})^2}{\text{m/s}^2} = \text{m}\). 대칭: \(\alpha\)와 \(90° - \alpha\)는 \(\sin2\alpha\)가 같아 같은 거리에 떨어집니다(30°와 60°). 실제 경험과 맞습니다.
