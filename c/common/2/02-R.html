2.R.1

연습선형벡터 공간 연습 문제

문제 7 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통2-02-01] [공통2-02-02] [공통2-02-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\((1, 2, 3)\), \((2, 4, 6)\), \((0, 1, 1)\)이 생성하는 공간의 차원과 기저를 구하세요. [02-01, 02-02]

    힌트 1

    둘째는 첫째의 2배라 아무것도 보태지 않습니다.

    힌트 2

    \((1,2,3)\)과 \((0,1,1)\)은 평행하지 않습니다.

    풀이

    생성 공간은 \(\operatorname{span}\{(1,2,3), (0,1,1)\}\). 두 벡터는 독립(평행하지 않음)이므로 기저이고 차원 2. 원점을 지나는 평면이며 법선은 \((1,2,3)\times(0,1,1) = (-1, -1, 1)\), 곧 \(x + y - z = 0\).

  2. 계산\(k\)가 어떤 값일 때 \((1, k, 0)\), \((0, 1, k)\), \((k, 0, 1)\)이 일차종속인가요? [02-01]

    힌트 1

    행렬식 = 0.

    힌트 2

    전개하면 \(1 + k^3\).

    풀이

    \(\det = 1(1 - 0) - k(0 - k^2) + 0 = 1 + k^3 = 0\), 실수 \(k = -1\). 확인: \(k = -1\)이면 세 벡터의 합이 \((0, 0, 0)\).

  3. 개념다음 중 \(\mathbb R^3\)의 부분공간인 것을 고르고 이유를 쓰세요. (ㄱ) \(\{(x,y,z): x = 2y\}\) (ㄴ) \(\{(x,y,z): xy = 0\}\) (ㄷ) \(\{(x,y,z): x + y + z = 1\}\) [02-02]

    힌트 1

    영벡터가 들어 있나? 덧셈에 닫혀 있나?

    힌트 2

    (ㄴ)에서 \((1,0,0) + (0,1,0)\)을 보세요.

    풀이

    (ㄱ)만 부분공간(원점을 지나는 평면, 차원 2, 기저 \(\{(2,1,0), (0,0,1)\}\)). (ㄴ)은 \((1,0,0) + (0,1,0) = (1,1,0)\)이 \(xy = 1 \ne 0\)이라 덧셈에 닫혀 있지 않음. (ㄷ)은 \(\mathbf 0\)을 포함하지 않음.

  4. 증명\(\{1 + x, 1 - x, x^2\}\)이 \(P_2\)의 기저임을 보이고, \(3 + x + 2x^2\)의 좌표를 구하세요. [02-02]

    힌트 1

    \(\dim P_2 = 3\)이므로 세 개가 독립이면 기저입니다.

    힌트 2

    \(a(1 + x) + b(1 - x) + cx^2\)의 계수를 비교.

    풀이

    \(a(1+x) + b(1-x) + cx^2 = (a + b) + (a - b)x + cx^2\). 이것이 0이면 \(a + b = 0\), \(a - b = 0\), \(c = 0\)이라 \(a = b = c = 0\): 독립, 따라서 기저.

    \(a + b = 3\), \(a - b = 1\), \(c = 2\) → 좌표 \((2, 1, 2)\).

  5. 계산평면에서 "\(x\)축에 대한 대칭 후 반시계 90° 회전"을 나타내는 행렬을 구하고, 이것이 어떤 변환인지 말하세요. [02-03]

    힌트 1

    \(\mathbf e_1, \mathbf e_2\)를 차례로 따라가세요.

    힌트 2

    \(\mathbf e_1 \to \mathbf e_1 \to \mathbf e_2\), \(\mathbf e_2 \to -\mathbf e_2 \to \mathbf e_1\).

    풀이

    열이 \(T\mathbf e_1 = (0, 1)\), \(T\mathbf e_2 = (1, 0)\): \(\begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}\). 직선 \(y = x\)에 대한 대칭입니다. 곱으로 확인: \(R_{90°}F_x = \begin{pmatrix}0&-1\\1&0\end{pmatrix}\begin{pmatrix}1&0\\0&-1\end{pmatrix} = \begin{pmatrix}0&1\\1&0\end{pmatrix}\).

  6. 계산\(T(1, 1) = (3, 1)\), \(T(1, -1) = (1, 3)\)인 일차변환 \(T: \mathbb R^2 \to \mathbb R^2\)의 행렬을 구하세요. [02-03]

    힌트 1

    \(\mathbf e_1 = \frac12[(1,1) + (1,-1)]\).

    힌트 2

    일차성으로 \(T\mathbf e_1\), \(T\mathbf e_2\)를 구합니다.

    풀이

    \(T\mathbf e_1 = \frac12[(3,1) + (1,3)] = (2, 2)\), \(\mathbf e_2 = \frac12[(1,1) - (1,-1)]\)이므로 \(T\mathbf e_2 = \frac12[(3,1) - (1,3)] = (1, -1)\). 행렬 \(\begin{pmatrix}2 & 1\\ 2 & -1\end{pmatrix}\).

    검산: \(\begin{pmatrix}2&1\\2&-1\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}3\\1\end{pmatrix}\).

  7. 판단한 학생이 \(T(x, y) = (x + 1, y)\)를 일차변환이라 보고 행렬 \(\begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}\)로 나타냈습니다. 어디가 틀렸나요? [02-03]

    힌트 1

    02-03 절: 일차변환은 \(\mathbf 0\)을 어디로 보내나요?

    힌트 2

    행렬 곱 \(A\mathbf 0\)은 언제나 \(\mathbf 0\)입니다.

    풀이

    \(T(0,0) = (1, 0) \ne \mathbf 0\)이므로 일차변환이 아닙니다(평행이동). 학생의 행렬은 항등변환이라 \(T\)와 다릅니다. 평행이동을 행렬로 쓰려면 좌표를 하나 늘린 동차좌표 \((x, y, 1)\)를 씁니다(컴퓨터 그래픽스).
