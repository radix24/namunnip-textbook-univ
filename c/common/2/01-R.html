1.R.1

연습벡터와 공간 기하 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통1-09-03] [공통2-01-01] [공통2-01-02] [공통2-01-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산정육면체의 대각선과 한 모서리가 이루는 각을 구하세요. [공통1-09-03]

    힌트 1

    한 변이 1인 정육면체를 원점에 두면 대각선은 \((1,1,1)\), 모서리는 \((1,0,0)\).

    힌트 2

    \(\cos\theta = \frac{\mathbf a\cdot\mathbf b}{|\mathbf a||\mathbf b|}\).

    풀이

    \(\cos\theta = \frac{1}{\sqrt3\cdot1}\), \(\theta = \arccos\frac{1}{\sqrt3} \approx 54.7°\).

  2. 계산힘 \(\mathbf F = (3, -1, 2)\) N이 물체를 \(A(1, 0, 0)\)에서 \(B(4, 2, 1)\)로 옮길 때 한 일과, 변위 방향의 힘 성분을 구하세요. [공통1-09-03]

    힌트 1

    일 = \(\mathbf F\cdot\mathbf d\), \(\mathbf d = \overrightarrow{AB}\).

    힌트 2

    \(\mathbf d = (3, 2, 1)\), \(|\mathbf d| = \sqrt{14}\).

    풀이

    \(W = 9 - 2 + 2 = 9\) J (거리 단위 m 가정). 성분 \(\frac{9}{\sqrt{14}} \approx 2.41\) N.

  3. 증명\(|\mathbf a\times\mathbf b|^2 + (\mathbf a\cdot\mathbf b)^2 = |\mathbf a|^2|\mathbf b|^2\)임을 각 \(\theta\)를 써서 보이세요. 이것으로 \(\mathbf a = (1, 1, 0)\), \(\mathbf b = (0, 1, 1)\)의 \(|\mathbf a\times\mathbf b|\)를 외적 계산 없이 구하세요. [01-01]

    힌트 1

    \(\sin^2\theta + \cos^2\theta = 1\).

    힌트 2

    \(|\mathbf a|^2|\mathbf b|^2 = 4\), \(\mathbf a\cdot\mathbf b = 1\).

    풀이

    왼쪽 \(= |\mathbf a|^2|\mathbf b|^2(\sin^2\theta + \cos^2\theta) = |\mathbf a|^2|\mathbf b|^2\). 예: \(|\mathbf a\times\mathbf b|^2 = 4 - 1 = 3\), \(|\mathbf a\times\mathbf b| = \sqrt3\). 직접: \((1, -1, 1)\), 길이 \(\sqrt3\).

  4. 계산두 평면 \(x + y + z = 1\), \(x - y + 2z = 3\)의 교선의 매개방정식과 두 평면이 이루는 각을 구하세요. [01-02]

    힌트 1

    교선의 방향은 두 법선에 모두 수직: \(\mathbf n_1\times\mathbf n_2\).

    힌트 2

    교선 위 한 점은 \(z = 0\)으로 두고 연립.

    풀이

    \(\mathbf n_1\times\mathbf n_2 = (1,1,1)\times(1,-1,2) = (2 + 1, 1 - 2, -1 - 1) = (3, -1, -2)\). \(z = 0\): \(x + y = 1\), \(x - y = 3\) → \((2, -1, 0)\). 교선 \((2 + 3t, -1 - t, -2t)\).

    각: \(\cos\theta = \frac{|\mathbf n_1\cdot\mathbf n_2|}{|\mathbf n_1||\mathbf n_2|} = \frac{2}{\sqrt3\sqrt6} = \frac{\sqrt2}{3}\), \(\theta \approx 61.9°\).

  5. 계산세 점 \((1, 0, 0)\), \((0, 1, 0)\), \((0, 0, 1)\)을 지나는 평면과 원점 사이의 거리를 구하세요. [01-02]

    힌트 1

    절편이 모두 1이므로 평면은 \(x + y + z = 1\).

    힌트 2

    거리 공식에 \((0,0,0)\).

    풀이

    \(D = \frac{|0 - 1|}{\sqrt3} = \frac{1}{\sqrt3}\). 대칭으로 보면 가장 가까운 점은 \(\left(\frac13, \frac13, \frac13\right)\)이고 그 길이가 \(\frac{1}{\sqrt3}\)입니다.

  6. 계산네 점 \((0,0,0)\), \((1,2,3)\), \((2,3,1)\), \((k, 1, 2)\)가 한 평면 위에 있도록 \(k\)를 정하세요. [01-04]

    힌트 1

    원점에서 나머지 세 점으로 가는 벡터의 평행육면체 부피가 0.

    힌트 2

    행 \((1,2,3)\), \((2,3,1)\), \((k,1,2)\)의 행렬식 = 0.

    풀이

    \(\det = 1(6 - 1) - 2(4 - k) + 3(2 - 3k) = 5 - 8 + 2k + 6 - 9k = 3 - 7k = 0\), \(k = \frac37\).

  7. 개념\(\mathbf a \ne \mathbf 0\)이고 \(\mathbf a\cdot\mathbf b = \mathbf a\cdot\mathbf c\)이면 \(\mathbf b = \mathbf c\)인가요? \(\mathbf a\times\mathbf b = \mathbf a\times\mathbf c\)이면? 둘 다 성립하면? [공통1-09-03, 01-01]

    힌트 1

    공통1-09-03 절: \(\mathbf a\cdot(\mathbf b - \mathbf c) = 0\)의 뜻.

    힌트 2

    내적은 \(\mathbf a\)에 수직인 성분을, 외적은 \(\mathbf a\)에 평행한 성분을 놓칩니다.

    풀이

    내적이 같으면 \(\mathbf b - \mathbf c \perp \mathbf a\)일 뿐이라 \(\mathbf b = \mathbf c\)라고 할 수 없습니다. 외적이 같으면 \(\mathbf b - \mathbf c \parallel \mathbf a\)일 뿐입니다. 둘 다 성립하면 \(\mathbf b - \mathbf c\)가 \(\mathbf a\)에 수직이면서 평행이므로 \(\mathbf 0\), 곧 \(\mathbf b = \mathbf c\)입니다. 벡터에서는 "양변을 나누는" 계산이 없습니다.

  8. 판단한 학생이 점 \((1, 2, 3)\)과 평면 \(x + 2y + 2z = 1\) 사이의 거리를 \(\frac{|1 + 4 + 6 - 1|}{1 + 2 + 2} = 2\)라고 했습니다. 맞나요? [01-02]

    힌트 1

    01-02 절: 거리 공식의 분모는?

    힌트 2

    분모는 법선벡터의 길이입니다.

    풀이

    틀렸습니다. 분모는 계수의 합이 아니라 \(|\mathbf n| = \sqrt{1 + 4 + 4} = 3\)입니다. 답은 \(\frac{10}{3}\). 확인: 평면 위의 점 \((1, 0, 0)\)까지의 거리가 \(\sqrt{0 + 4 + 9} = \sqrt{13} \approx 3.6\)이므로 가장 짧은 거리는 그 이하여야 하고, \(\frac{10}{3} \approx 3.33\)은 이 조건을 만족합니다.
