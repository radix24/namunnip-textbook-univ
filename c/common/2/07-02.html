7.2.1함수의 선적분

휘어진 철사의 밀도가 위치에 따라 \(f(x, y)\)이면, 철사를 잘게 나누어 (밀도) × (조각의 길이 \(\Delta s\))를 더한 것이 질량입니다. 그 극한을 \(\int_Cf\,ds\)라 씁니다. 곡선을 \(\mathbf r(t)\), \(a \le t \le b\)로 매개화하면 \(ds = |\mathbf r'(t)|\,dt\)이므로

\[\int_Cf\,ds = \int_a^bf(\mathbf r(t))\,|\mathbf r'(t)|\,dt.\]
예제 7.2.1

\(C\)가 단위원의 위쪽 반일 때 \(\int_C(2 + x^2y)\,ds\)를 구하여라.

풀이. \(\mathbf r = \langle\cos t, \sin t\rangle\), \(0 \le t \le \pi\), \(|\mathbf r'| = 1\).

\[\int_0^\pi(2 + \cos^2t\sin t)\,dt = 2\pi + \left[-\frac{\cos^3t}{3}\right]_0^\pi = 2\pi + \frac23.\]

7.2.2벡터장의 선적분과 일

힘 \(\mathbf F\)를 받으며 곡선을 따라 움직일 때, 작은 변위 \(d\mathbf r\) 동안 힘이 한 일은 진행 방향 성분만 셈하므로 \(\mathbf F\cdot d\mathbf r\)입니다. 이것을 모두 더한 것이 일입니다.

정의 7.2.2 (벡터장의 선적분) \[W = \int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt.\]

성분으로 쓰면 \(\int_CP\,dx + Q\,dy + R\,dz\)입니다. 힘이 진행 방향과 수직이면(원운동의 구심력) 일은 0이고, 반대 방향이면 음수입니다.

예제 7.2.3

힘 \(\mathbf F = \langle x^2, -xy\rangle\)이 단위원 위를 \((1, 0)\)에서 \((0, 1)\)까지 움직이는 입자에 한 일을 구하여라.

풀이. \(\mathbf r = \langle\cos t, \sin t\rangle\), \(0 \le t \le \frac\pi2\), \(\mathbf r' = \langle-\sin t, \cos t\rangle\).

\[\mathbf F\cdot\mathbf r' = -\cos^2t\sin t - \cos^2t\sin t = -2\cos^2t\sin t.\] \[W = \int_0^{\pi/2}-2\cos^2t\sin t\,dt = \left[\frac23\cos^3t\right]_0^{\pi/2} = -\frac23.\]

7.2.3방향

  • \(\int_Cf\,ds\)는 곡선의 방향과 무관하다 (길이는 음수가 아님).
  • \(\int_C\mathbf F\cdot d\mathbf r\)는 방향을 바꾸면 부호가 바뀐다. 거꾸로 가면 일의 부호가 반대.
  • 값은 매개화 방법(속력)과 무관하고 곡선과 방향에만 의존한다.
요약
  1. \(\int_Cf\,ds = \int f(\mathbf r(t))|\mathbf r'|\,dt\).
  2. \(\int_C\mathbf F\cdot d\mathbf r = \int\mathbf F(\mathbf r(t))\cdot\mathbf r'\,dt\) = 일. 방향을 바꾸면 부호가 바뀐다.

7.2.4연습문제

기본

  1. \(C\): \((0, 0)\)에서 \((1, 1)\)까지의 선분. \(\int_C(x + y)\,ds\)는?
    답

    \(\mathbf r = \langle t, t\rangle\), \(|\mathbf r'| = \sqrt2\). \(\int_0^12t\sqrt2\,dt = \sqrt2\).

  2. 같은 선분에서 \(\int_Cy\,dx + x\,dy\)는?
    답

    \(\int_0^1(t + t)\,dt = 1\).

7.2.2

예제선적분: 곡선을 따라 더하기

스칼라 선적분 ds · 벡터 선적분 F·dr · 일

다루는 성취기준 [공통2-07-02]

두 가지 선적분

  • 스칼라 선적분 \(\int_Cf\,ds\): 곡선을 길이 \(ds\)인 조각으로 나눠 \(f\times ds\)를 더함. 예: 밀도 \(f\)인 철사의 질량. 계산: \(\mathbf r(t)\), \(a \le t \le b\)로 매개화하면 \(ds = |\mathbf r'(t)|\,dt\), \(\int_Cf\,ds = \int_a^bf(\mathbf r(t))|\mathbf r'(t)|\,dt\). 방향과 상관없음.
  • 벡터 선적분 \(\int_C\mathbf F\cdot d\mathbf r\): 조각마다 힘의 진행 방향 성분 × 길이, 곧 일. \(d\mathbf r = \mathbf r'(t)\,dt\), \(\int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt\). 방향을 뒤집으면 부호가 바뀜.

두 식은 \(\int_C\mathbf F\cdot d\mathbf r = \int_C(\mathbf F\cdot\mathbf T)\,ds\)로 이어집니다(\(\mathbf r'\,dt = \mathbf T|\mathbf r'|\,dt = \mathbf T\,ds\)). 성분으로 쓰면 \(\int_C P\,dx + Q\,dy\).

매개화를 바꿔도 값이 같습니다(벡터 선적분은 방향이 같을 때). 치환적분으로 확인됩니다. 그래서 가장 편한 매개화를 고르면 됩니다.

먼저 예측

(가)와 (나)의 두 경로가 같은 값을 준다면, 같은 끝점을 잇는 모든 경로가 같은 값을 줄까요?

예측 확인

아닙니다. (다)에서 세 번째 경로가 다른 값을 줍니다. 두 경로가 같은 것은 우연일 수 있습니다.

\(\mathbf F = (y, x^2)\)일 때 \(\int_C\mathbf F\cdot d\mathbf r\)를 (가) \((0,0)\)에서 \((1,1)\)까지의 선분 (나) 포물선 \(y = x^2\)을 따라 같은 두 점 사이에서 계산하세요. 또 (다) 단위원의 위쪽 반원에서 \(\int_C y\,ds\)를 구하세요.

풀이

  1. (가) \(\mathbf r(t) = (t, t)\), \(\mathbf r' = (1, 1)\), \(0 \le t \le 1\). \(\mathbf F(\mathbf r) = (t, t^2)\).
    선분의 매개화.
  2. \(\int_0^1(t + t^2)\,dt = \frac12 + \frac13 = \frac56\).
    \(\mathbf F\cdot\mathbf r'\).
  3. (나) \(\mathbf r(t) = (t, t^2)\), \(\mathbf r' = (1, 2t)\), \(\mathbf F = (t^2, t^2)\). \(\int_0^1(t^2 + 2t^3)\,dt = \frac13 + \frac12 = \frac56\).
    같은 끝점.
  4. 두 경로가 같은 값을 주었지만 이것만으로 경로 독립이라 할 수는 없다. 실제로 \((0,0) \to (1,0) \to (1,1)\)이면 \(\int_0^1 0\,dt + \int_0^1 1\,dt = 1 \ne \frac56\).
    첫 구간 \(y = 0\)이라 \(\mathbf F\cdot(1,0) = 0\), 둘째 구간 \(x = 1\)이라 \(\mathbf F\cdot(0,1) = 1\). 다음 카드에서 이유를 본다.
  5. (다) \(\mathbf r = (\cos t, \sin t)\), \(0 \le t \le \pi\), \(|\mathbf r'| = 1\). \(\int_0^\pi\sin t\,dt = 2\).
    스칼라 선적분. 밀도가 높이에 비례하는 반원 철사의 질량.

의미

벡터 선적분은 힘이 경로를 따라 한 일입니다. 같은 끝점이라도 경로에 따라 일이 달랐는데, 어떤 장에서는 경로와 상관없게 되는지가 다음 절(보존장)의 질문입니다.

검산

(다) 반원의 길이 \(\pi\), \(y\)의 평균값은 \(\frac2\pi \approx 0.64\)로 0과 1 사이. 반원 철사의 무게중심 높이 \(\frac{2}{\pi}\)와 같습니다.

흔한 오해

  • \(ds\)에서 \(|\mathbf r'|\) 빠뜨리기: 매개변수가 호의 길이일 때만 \(ds = dt\).
  • \(\int_C f\,ds\)에 방향 부호 붙이기: 스칼라 선적분은 방향과 상관없습니다(길이는 늘 양수).
7.2.3

실습벡터장 속을 걸으며 일 재기

실습 · 선적분과 경로 무관성

다루는 성취기준 [공통2-07-02] [공통2-07-03]

목표

벡터장 속에서 경로를 따라 움직이는 점이 받는 일을 누적해 선적분 \(\int_C\mathbf F\cdot d\mathbf r\)을 구하고, 같은 두 끝점 사이라도 경로에 따라 값이 다른 벡터장과 같은 벡터장(보존장)을 비교합니다. 성취기준 [공통2-07-02], [공통2-07-03].

준비

회색 화살표는 벡터장, 파란 곡선은 경로입니다. 재생하면 주황 점이 경로를 따라가며 그 점의 힘(빨강)과 진행 방향(파랑)을 보여 주고, 아래 그래프에 누적된 일이 그려집니다. 처음 세 경로는 모두 \((1, 0)\)에서 \((-1, 0)\)으로 갑니다.

절차

  1. 소용돌이 장에서 위쪽 반원, 선분, 아래쪽 반원의 일을 각각 기록한다.
  2. 같은 일을 보존장 \(\nabla(x^2y)\)에서 한다.
  3. 네 벡터장 모두에서 단위원 한 바퀴의 일을 기록한다.
  4. 퍼짐 장 \(\langle x, y\rangle\)에서 원을 따라갈 때 힘과 진행 방향의 관계를 본다.

기대 결과

  • 소용돌이 장: 위쪽 반원 \(\pi\), 선분 0, 아래쪽 반원 \(-\pi\). 경로에 따라 다르다.
  • 보존장: 세 경로 모두 0(퍼텐셜 \(x^2y\)가 두 끝점에서 같음).
  • 한 바퀴: 소용돌이 \(2\pi\), \(\langle y, 0\rangle\)은 \(-\pi\), 퍼짐 장과 보존장은 0.
  • 퍼짐 장은 원 위에서 늘 진행 방향에 수직이라 일을 하지 않는다.

분석

  1. 닫힌 경로의 일이 0이 아닌 벡터장은 보존장이 아닙니다. 이 장치에서 보존장이 아닌 것은 어느 것인가요? 7.3절의 판정 \(P_y = Q_x\)로 확인해 보세요.
  2. 누적 일 그래프가 줄어드는 구간은 힘이 진행 방향과 어떤 각을 이룰 때인가요?

더 해 보기

\(\langle y, 0\rangle\)의 한 바퀴 값 \(-\pi\)를 그린 정리 \(\iint(Q_x - P_y)\,dA\)로 확인하고, 다음 카드(7.4절)에서 다른 원으로 실험해 보세요.
