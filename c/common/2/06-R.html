6.R.1

연습중적분 연습 문제

문제 6 · 힌트 2단계 · 풀이

다루는 성취기준 [공통2-06-01] [공통2-06-02] [공통2-06-03] [공통2-06-04]

먼저 영역을 그리고, 어떤 좌표가 경계를 가장 단순하게 하는지 정하세요.

  1. \(\displaystyle\int_0^{1}\int_{\sqrt y}^{1}\sqrt{x^3 + 1}\,dx\,dy\)를 구하세요. [06-01]

    힌트 1

    영역: \(0 \le y \le 1\), \(\sqrt y \le x \le 1\), 곧 \(y \le x^2\).

    힌트 2

    세로로: \(0 \le x \le 1\), \(0 \le y \le x^2\).

    풀이

    \(\int_0^1\int_0^{x^2}\sqrt{x^3 + 1}\,dy\,dx = \int_0^1x^2\sqrt{x^3 + 1}\,dx = \frac13\cdot\frac23\left[(x^3 + 1)^{3/2}\right]_0^1 = \frac29(2\sqrt2 - 1)\).

  2. 원판 \(x^2 + y^2 \le 4\) 위, 곡면 \(z = x^2 + y^2\) 아래의 부피와, 포물면 \(z = 4 - x^2 - y^2\) 아래·\(z = x^2 + y^2\) 위의 부피를 구하세요. [06-02]

    힌트 1

    극좌표: \(z = r^2\).

    힌트 2

    두 포물면의 교선: \(r^2 = 4 - r^2\), \(r = \sqrt2\).

    풀이

    첫째: \(\int_0^{2\pi}\int_0^2r^2\cdot r\,dr\,d\theta = 2\pi\cdot4 = 8\pi\).

    둘째: \(\int_0^{2\pi}\int_0^{\sqrt2}(4 - 2r^2)r\,dr\,d\theta = 2\pi\left[2r^2 - \frac{r^4}{2}\right]_0^{\sqrt2} = 2\pi(4 - 2) = 4\pi\).

  3. 원뿔 \(z = \sqrt{x^2 + y^2}\) 위, 구 \(x^2 + y^2 + z^2 = 9\) 안쪽 영역(아이스크림 콘)의 부피를 구하세요. [06-02]

    힌트 1

    원뿔은 구면좌표로 \(\varphi = \frac\pi4\).

    힌트 2

    \(0 \le \rho \le 3\), \(0 \le \varphi \le \frac\pi4\).

    풀이

    \(\int_0^{2\pi}\int_0^{\pi/4}\int_0^3\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\left(1 - \frac{\sqrt2}{2}\right)\cdot9 = 9\pi(2 - \sqrt2) \approx 16.6\).

  4. 타원 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} \le 1\)의 넓이를 변수변환 \(x = au\), \(y = bv\)로 구하세요. [06-03]

    힌트 1

    새 영역은 단위원판.

    힌트 2

    \(J = ab\).

    풀이

    \(\iint_{u^2+v^2\le1}ab\,du\,dv = ab\cdot\pi\). 선형변환이라 넓이가 모든 곳에서 \(ab\)배가 됩니다.

  5. 곡선 \(xy = 1\), \(xy = 3\), \(y = x\), \(y = 2x\)로 둘러싸인 제1사분면 영역의 넓이를 구하세요. [06-03]

    힌트 1

    \(u = xy\), \(v = \frac yx\)로 두면 \(1 \le u \le 3\), \(1 \le v \le 2\).

    힌트 2

    \(\frac{\partial(u,v)}{\partial(x,y)}\)를 구한 뒤 역수를 쓰면 편합니다.

    풀이

    \(\frac{\partial(u,v)}{\partial(x,y)} = \begin{vmatrix}y & x\\ -\frac{y}{x^2} & \frac1x\end{vmatrix} = \frac yx + \frac yx = 2v\). 역변환의 야코비안은 역수 \(\frac{1}{2v}\) (역함수의 미분처럼, 행렬식의 곱셈성질).

    넓이 \(\int_1^2\int_1^3\frac{1}{2v}\,du\,dv = 2\cdot\frac12\ln2 = \ln2\).

  6. 밀도 \(\delta(x,y) = y\)인 반원판 \(x^2 + y^2 \le 1\), \(y \ge 0\)의 질량과 질량 중심을 구하세요. [06-04]

    힌트 1

    극좌표에서 \(\delta = r\sin\theta\).

    힌트 2

    \(M = \int_0^\pi\int_0^1r\sin\theta\cdot r\,dr\,d\theta\).

    풀이

    \(M = \frac13\cdot2 = \frac23\). 대칭으로 \(\bar x = 0\). \(\iint y\cdot y\,dA = \int_0^\pi\sin^2\theta\,d\theta\int_0^1r^3dr = \frac\pi2\cdot\frac14 = \frac\pi8\). \(\bar y = \frac{\pi/8}{2/3} = \frac{3\pi}{16} \approx 0.589\).

    균일한 반원판의 \(\bar y = \frac{4}{3\pi} \approx 0.424\)보다 위: 위쪽이 더 무겁기 때문입니다.
