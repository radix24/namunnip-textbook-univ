1.2.1

예제외적: 두 벡터에 수직이고 길이가 넓이인 벡터

법선벡터 · 평행사변형 넓이 · 오른손 규칙

다루는 성취기준 [공통2-01-02]

정의 · 외적 (3차원에서만) \[\mathbf a\times\mathbf b = (a_2b_3 - a_3b_2,\ a_3b_1 - a_1b_3,\ a_1b_2 - a_2b_1) = \begin{vmatrix}\mathbf i & \mathbf j & \mathbf k\\ a_1 & a_2 & a_3\\ b_1 & b_2 & b_3\end{vmatrix}.\]

성질과 근거

  1. 수직\(\mathbf a\cdot(\mathbf a\times\mathbf b) = a_1(a_2b_3 - a_3b_2) + a_2(a_3b_1 - a_1b_3) + a_3(a_1b_2 - a_2b_1) = 0\). 전개하면 항이 둘씩 소거됩니다. \(\mathbf b\)도 같습니다.
  2. 길이\(|\mathbf a\times\mathbf b|^2 = |\mathbf a|^2|\mathbf b|^2 - (\mathbf a\cdot\mathbf b)^2\) (라그랑주 항등식, 성분 전개로 확인) \(= |\mathbf a|^2|\mathbf b|^2\sin^2\theta\). 그래서 \(|\mathbf a\times\mathbf b| = |\mathbf a||\mathbf b|\sin\theta\) = 두 벡터가 만드는 평행사변형의 넓이(밑변 \(|\mathbf a|\), 높이 \(|\mathbf b|\sin\theta\)).
  3. 방향\(\mathbf a, \mathbf b, \mathbf a\times\mathbf b\)는 오른손 규칙을 따릅니다. 예: \(\mathbf i\times\mathbf j = \mathbf k\).
  4. 반교환\(\mathbf b\times\mathbf a = -\mathbf a\times\mathbf b\), \(\mathbf a\times\mathbf a = \mathbf 0\). 결합법칙은 성립하지 않습니다: \((\mathbf i\times\mathbf i)\times\mathbf j = \mathbf 0\), \(\mathbf i\times(\mathbf i\times\mathbf j) = \mathbf i\times\mathbf k = -\mathbf j\).

세 점 \(P(1, 0, 0)\), \(Q(0, 2, 0)\), \(R(0, 0, 3)\)에 대해 (가) 평면 \(PQR\)의 법선벡터 (나) 삼각형 \(PQR\)의 넓이를 구하세요.

풀이

  1. 평면 위의 두 벡터: \(\overrightarrow{PQ} = (-1, 2, 0)\), \(\overrightarrow{PR} = (-1, 0, 3)\).
    평면 안에 있는 서로 다른 방향 둘.
  2. \(\mathbf n = \overrightarrow{PQ}\times\overrightarrow{PR} = (2\cdot3 - 0\cdot0,\ 0\cdot(-1) - (-1)\cdot3,\ (-1)\cdot0 - 2\cdot(-1)) = (6, 3, 2)\).
    정의의 세 성분. 두 벡터에 모두 수직이므로 평면의 법선.
  3. 넓이 \(= \frac12|\mathbf n| = \frac12\sqrt{36 + 9 + 4} = \frac72\).
    삼각형은 평행사변형의 절반.

검산

\(\mathbf n\cdot\overrightarrow{PQ} = -6 + 6 + 0 = 0\), \(\mathbf n\cdot\overrightarrow{PR} = -6 + 0 + 6 = 0\). 다른 방법: 세 좌표평면에 비친 그림자 넓이는 \(1\cdot2/2 = 1\), \(2\cdot3/2 = 3\), \(1\cdot3/2 = \frac32\)이고, \(\sqrt{1 + 9 + \frac94} = \sqrt{\frac{49}{4}} = \frac72\). 일치합니다(넓이 벡터의 성분이 그림자 넓이).

흔한 오해

  • 가운데 성분의 부호: 행렬식으로 전개할 때 \(\mathbf j\) 성분은 \(-(a_1b_3 - a_3b_1)\)입니다.
  • 2차원 벡터의 외적: \(z = 0\)을 붙여 3차원으로 보면 결과는 \(z\)축 방향 \((0, 0, a_1b_2 - a_2b_1)\)입니다.
