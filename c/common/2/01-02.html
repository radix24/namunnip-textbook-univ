1.2.1직선

평면에서는 직선을 \(y = mx + b\)로 썼지만, 공간에서는 기울기 하나로 방향을 나타낼 수 없습니다. 대신 지나는 점 \(P_0(x_0, y_0, z_0)\)과 방향을 알려 주는 벡터 \(\mathbf v = \langle a, b, c\rangle\)(방향벡터)를 씁니다. 직선 위의 점은 \(P_0\)에서 \(\mathbf v\) 방향으로 \(t\)배만큼 간 곳입니다.

\[x = x_0 + at, \quad y = y_0 + bt, \quad z = z_0 + ct \quad (t\text{는 실수}).\]

이것을 직선의 매개변수방정식이라 합니다. \(t\)를 소거하면 대칭방정식 \(\frac{x - x_0}{a} = \frac{y - y_0}{b} = \frac{z - z_0}{c}\)를 얻습니다(분모가 0이 아닐 때).

예제 1.2.1

두 점 \(A(2, 4, -3)\), \(B(3, -1, 1)\)을 지나는 직선의 방정식을 구하여라.

풀이. 방향벡터 \(\overrightarrow{AB} = \langle1, -5, 4\rangle\). \(x = 2 + t\), \(y = 4 - 5t\), \(z = -3 + 4t\). \(t = 0\)이면 \(A\), \(t = 1\)이면 \(B\)입니다.

1.2.2평면

평면은 "지나는 점 \(P_0\)"과 "평면에 수직인 벡터 \(\mathbf n = \langle a, b, c\rangle\)"(법선벡터)로 정해집니다. 평면 위의 점 \(P\)에 대해 \(\overrightarrow{P_0P}\)는 평면 안에 놓이므로 \(\mathbf n\)과 수직, 곧 내적이 0입니다.

\[a(x - x_0) + b(y - y_0) + c(z - z_0) = 0, \quad \text{정리하면}\ ax + by + cz = d.\]

거꾸로 \(ax + by + cz = d\)를 보면 법선벡터가 \(\langle a, b, c\rangle\)임을 바로 읽을 수 있습니다.

예제 1.2.2

세 점 \(P(1, 4, 6)\), \(Q(-2, 5, -1)\), \(R(1, -1, 1)\)을 지나는 평면의 방정식을 구하여라.

풀이. 1.1절 예제에서 \(\overrightarrow{PQ}\times\overrightarrow{PR} = \langle-40, -15, 15\rangle\)이었습니다. 이 벡터는 두 벡터에 모두 수직이므로 법선벡터로 쓸 수 있고, \(-5\)로 나누어 \(\mathbf n = \langle8, 3, -3\rangle\)을 씁니다. \(8(x - 1) + 3(y - 4) - 3(z - 6) = 0\), 곧 \(8x + 3y - 3z = 2\). (\(Q\), \(R\)을 넣어 확인: \(-16 + 15 + 3 = 2\), \(8 - 3 - 3 = 2\).)

예제 1.2.3

직선 \(x = 2 + 3t\), \(y = -4t\), \(z = 5 + t\)와 평면 \(4x + 5y - 2z = 18\)의 교점을 구하여라.

풀이. 대입하면 \(4(2 + 3t) + 5(-4t) - 2(5 + t) = 18\), \(-2 - 10t = 18\), \(t = -2\). 교점 \((-4, 8, 3)\).

1.2.3점과 평면 사이의 거리

정리 1.2.4

점 \((x_1, y_1, z_1)\)에서 평면 \(ax + by + cz = d\)까지의 거리는

\[D = \frac{|ax_1 + by_1 + cz_1 - d|}{\sqrt{a^2 + b^2 + c^2}}.\]

이유: 평면 위의 한 점에서 주어진 점으로 가는 벡터를 법선 방향으로 정사영한 길이가 거리입니다(공통1 9.3절의 정사영). 고교에서 배운 점과 직선 사이의 거리 공식과 모양이 같습니다.

예제 1.2.5

점 \((1, 2, 3)\)에서 평면 \(2x - y + 2z = 10\)까지의 거리는?

풀이. \(\frac{|2 - 2 + 6 - 10|}{\sqrt{4 + 1 + 4}} = \frac43\).

요약
  1. 직선: 점 + 방향벡터. \(\mathbf r = \mathbf r_0 + t\mathbf v\).
  2. 평면: 점 + 법선벡터. \(ax + by + cz = d\)의 법선은 \(\langle a, b, c\rangle\).
  3. 세 점이 주어지면 외적으로 법선을 구한다.

1.2.4연습문제

기본

  1. 점 \((1, 0, -1)\)을 지나고 법선이 \(\langle2, 1, 1\rangle\)인 평면은?
    답

    \(2x + y + z = 1\).

  2. 원점에서 평면 \(x + 2y + 2z = 6\)까지의 거리는?
    답

    \(\frac63 = 2\).

응용

  1. 두 평면 \(x + y + z = 1\), \(x - 2y + 3z = 1\)의 사잇각의 코사인은? (법선벡터의 사잇각)
    답

    \(\frac{1 - 2 + 3}{\sqrt3\sqrt{14}} = \frac{2}{\sqrt{42}}\).

1.2.2

예제공간의 직선과 평면, 그리고 거리

매개방정식 · 법선 · 점과 평면 · 꼬인 직선

다루는 성취기준 [공통2-01-02]

방정식 세우기

  • 직선: 한 점 \(P_0\)과 방향 \(\mathbf v\). \(\mathbf r(t) = \mathbf r_0 + t\mathbf v\). 공간에서 직선은 방정식 하나로 쓸 수 없습니다(평면 두 개의 교선).
  • 평면: 한 점 \(P_0\)과 법선 \(\mathbf n = (a, b, c)\). 평면 위의 점 \(P\)는 \(\overrightarrow{P_0P}\perp\mathbf n\), 곧 \(\mathbf n\cdot(\mathbf r - \mathbf r_0) = 0\), 펼치면 \(ax + by + cz = d\). 계수가 곧 법선입니다.
거리 공식

점 \(P_1\)과 평면 \(ax + by + cz = d\)의 거리: \(D = \dfrac{|ax_1 + by_1 + cz_1 - d|}{\sqrt{a^2 + b^2 + c^2}}\).

유도

  1. 평면 위의 점 \(P_0\)을 하나 잡고 \(\mathbf w = \overrightarrow{P_0P_1}\)이라 한다.
    거리 = \(\mathbf w\)의 법선 방향 성분의 크기(가장 짧은 경로는 수직).
  2. \(D = |\operatorname{comp}_{\mathbf n}\mathbf w| = \frac{|\mathbf n\cdot\mathbf w|}{|\mathbf n|}\).
    앞 카드의 성분 공식.
  3. \(\mathbf n\cdot\mathbf w = a(x_1 - x_0) + b(y_1 - y_0) + c(z_1 - z_0) = ax_1 + by_1 + cz_1 - d\).
    \(P_0\)이 평면 위라 \(ax_0 + by_0 + cz_0 = d\).
먼저 예측

(다)의 두 직선 \((t, 0, 1)\)과 \((0, s, s)\) 사이의 최단 거리는 1보다 클까요, 작을까요?

예측 확인

작습니다(\(\frac{1}{\sqrt2} \approx 0.71\)). \(L_1\) 위 점 \((0,0,1)\)과 \(L_2\) 위 점 \((0,0,0)\) 사이가 이미 1이고, 더 가까운 점 쌍이 있습니다.

(가) 점 \((1, -1, 2)\)를 지나고 평면 \(2x - y + 2z = 5\)에 수직인 직선, 그리고 그 직선과 평면의 교점 (나) 원점과 이 평면의 거리 (다) 꼬인 두 직선 \(L_1: (t, 0, 1)\), \(L_2: (0, s, s)\)의 거리

풀이

  1. (가) 방향 = 법선 \((2, -1, 2)\). \(\mathbf r(t) = (1 + 2t, -1 - t, 2 + 2t)\).
    평면에 수직인 직선은 법선 방향.
  2. 대입: \(2(1 + 2t) - (-1 - t) + 2(2 + 2t) = 7 + 9t = 5\), \(t = -\frac29\). 교점 \(\left(\frac59, -\frac79, \frac{14}{9}\right)\).
    직선의 점이 평면의 방정식을 만족하는 \(t\).
  3. (나) \(D = \frac{|0 - 5|}{\sqrt{4 + 1 + 4}} = \frac53\).
    거리 공식.
  4. (다) 방향 \(\mathbf v_1 = (1, 0, 0)\), \(\mathbf v_2 = (0, 1, 1)\). 공통수직 \(\mathbf n = \mathbf v_1\times\mathbf v_2 = (0, -1, 1)\).
    두 직선을 각각 품는 평행한 두 평면의 법선.
  5. \(L_1\) 위 점 \((0,0,1)\), \(L_2\) 위 점 \((0,0,0)\), \(\mathbf w = (0, 0, 1)\). \(D = \frac{|\mathbf n\cdot\mathbf w|}{|\mathbf n|} = \frac{1}{\sqrt2}\).
    두 평행 평면 사이 거리 = 아무 두 점을 잇는 벡터의 공통수직 성분.

의미

점과 평면의 거리는 법선 방향으로의 정사영입니다. "가장 가까운 점 = 수직으로 내린 점"이라는 이 생각은 선형대수의 최소제곱법(측정 자료에 직선 맞추기)에서 그대로 쓰입니다.

검산

(가)의 교점에서 원래 점까지 거리는 \(|t|\cdot|\mathbf n| = \frac29\cdot3 = \frac23\). 거리 공식으로 \(\frac{|2 + 1 + 4 - 5|}{3} = \frac23\). 일치합니다.
