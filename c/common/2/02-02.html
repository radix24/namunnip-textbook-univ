2.2.1생성과 기저

벡터 \(\mathbf v_1, \dots, \mathbf v_k\)의 일차결합 전체의 모임을 이 벡터들이 생성하는 공간이라 합니다. 예를 들어 평행하지 않은 공간벡터 두 개는 원점을 지나는 평면을 생성합니다.

정의 2.2.1 (기저)

어떤 공간 \(V\)를 생성하면서 일차독립인 벡터의 모임을 \(V\)의 기저라 한다.

두 조건의 역할은 다음과 같습니다.

  • 생성: \(V\)의 모든 벡터를 만들 수 있다 (모자라지 않음).
  • 일차독립: 쓸모없는 벡터가 없다 (남지 않음). 그래서 만드는 방법이 한 가지뿐이다.

기저 \(\{\mathbf v_1, \dots, \mathbf v_n\}\)에 대해 \(\mathbf x = c_1\mathbf v_1 + \cdots + c_n\mathbf v_n\)의 계수 \((c_1, \dots, c_n)\)을 기저에 대한 \(\mathbf x\)의 좌표라 합니다. 평소 쓰는 좌표는 기저 \(\{\mathbf i, \mathbf j, \mathbf k\}\)(표준기저)에 대한 좌표입니다.

예제 2.2.2

\(\{\langle1, 1\rangle, \langle1, -1\rangle\}\)이 평면의 기저임을 보이고, \(\langle5, 1\rangle\)의 좌표를 구하여라.

풀이. 2.1절 연습문제에서 일차독립이었습니다. \(a\langle1, 1\rangle + b\langle1, -1\rangle = \langle5, 1\rangle\)에서 \(a + b = 5\), \(a - b = 1\)이므로 \(a = 3\), \(b = 2\). 좌표는 \((3, 2)\)입니다. 임의의 \(\langle p, q\rangle\)에 대해서도 \(a = \frac{p + q}{2}\), \(b = \frac{p - q}{2}\)로 풀리므로 평면 전체를 생성합니다.

2.2.2차원

한 공간의 기저는 여러 가지지만, 기저를 이루는 벡터의 개수는 언제나 같습니다. 이 개수를 차원이라 합니다.

  • 평면 전체: 2차원. 공간 전체: 3차원.
  • 원점을 지나는 직선: 1차원. 원점을 지나는 평면: 2차원.
예제 2.2.3

평면 \(x + y + z = 0\)의 기저와 차원을 구하여라.

풀이. \(z = -x - y\)이므로 평면 위의 점은 \(\langle x, y, -x - y\rangle = x\langle1, 0, -1\rangle + y\langle0, 1, -1\rangle\). 두 벡터는 평행하지 않아 일차독립이므로 기저이고, 차원은 2입니다.

"벡터"는 화살표만이 아닙니다. 차수가 2 이하인 다항식 \(a + bx + cx^2\)도 더하고 실수배할 수 있으며, \(\{1, x, x^2\}\)이 기저인 3차원 공간을 이룹니다. 공통8에서 미분방정식의 해 전체가 이런 공간을 이룬다는 것을 봅니다.

요약
  1. 기저 = 생성 + 일차독립. 표현이 유일하다.
  2. 차원 = 기저의 벡터 개수.

2.2.3연습문제

기본

  1. \(\{\langle1, 0\rangle, \langle1, 1\rangle\}\)에 대한 \(\langle3, 2\rangle\)의 좌표는?
    답

    \(a + b = 3\), \(b = 2\). \((1, 2)\).

  2. \(\{\langle1, 2\rangle, \langle2, 4\rangle\}\)이 평면의 기저가 아닌 이유는?
    답

    일차종속이고, 한 직선만 생성한다.

2.2.2

설명기저와 차원: 좌표를 붙이는 최소한의 방향들

생성 · 기저 · 차원 · 좌표

다루는 성취기준 [공통2-02-02]

왜 필요한가

평면 \(x + y + z = 0\)은 \(\mathbb R^3\) 안에 있지만 "2차원"입니다. 이 말을 정확히 하고, 그 평면 위의 점에 두 개의 좌표를 붙이려면 기저와 차원이 필요합니다. 또 미분방정식의 해 공간, 다항식 공간처럼 화살표가 아닌 대상도 같은 언어로 다룹니다.

정의

벡터공간: 덧셈과 스칼라배에 닫혀 있고 보통의 계산 규칙(결합, 분배, 영벡터, 역원 등)을 만족하는 집합. \(\mathbb R^n\)의 부분집합이 \(\mathbf 0\)을 포함하고 덧셈·스칼라배에 닫혀 있으면 부분공간이다.

생성: \(\operatorname{span}\{\mathbf v_1, \dots, \mathbf v_k\}\) = 모든 일차결합의 집합.

기저: \(V\)를 생성하고 일차독립인 벡터들의 모임. 차원 \(\dim V\): 기저의 개수.

정의를 풀어 읽기

  1. 생성"충분히 많다": 모든 벡터를 만들 수 있다.
  2. 일차독립"군더더기가 없다": 하나라도 빼면 생성하지 못한다.
  3. 기저 = 둘 다그래서 \(V\)의 모든 벡터는 기저의 일차결합으로 단 한 가지 방법으로 쓰입니다. 그 계수가 그 기저에 대한 좌표입니다.
  4. 차원이 잘 정의되는 이유"\(m\)개로 생성되는 공간에서 일차독립인 벡터는 \(m\)개를 넘을 수 없다"(교환 정리, 선형대수에서 증명). 그래서 어떤 기저를 골라도 개수가 같습니다.

예: 평면 \(W: x + y + z = 0\)

  1. \(W\)는 부분공간이다: \(\mathbf 0 \in W\), \(\mathbf u, \mathbf v \in W\)이면 성분의 합이 0 + 0 = 0, \(c\mathbf u\)도 \(c\cdot0 = 0\).
    부분공간의 세 조건. 원점을 지나지 않는 평면 \(x + y + z = 1\)은 부분공간이 아니다.
  2. \(z = -x - y\)이므로 \(W\)의 원소는 \((x, y, -x-y) = x(1, 0, -1) + y(0, 1, -1)\).
    자유변수 \(x, y\)로 일반 원소를 쓴다.
  3. 따라서 \(\mathbf b_1 = (1, 0, -1)\), \(\mathbf b_2 = (0, 1, -1)\)이 \(W\)를 생성한다. 또 \(c_1\mathbf b_1 + c_2\mathbf b_2 = (c_1, c_2, \cdot) = \mathbf 0\)이면 \(c_1 = c_2 = 0\)이라 독립.
    첫 두 성분만 봐도 독립.
  4. \(\{\mathbf b_1, \mathbf b_2\}\)는 기저, \(\dim W = 2\). 점 \((2, 3, -5)\)의 좌표는 \((2, 3)\).
    \(2\mathbf b_1 + 3\mathbf b_2 = (2, 3, -5)\).

다른 기저 \(\{(1, -1, 0), (1, 1, -2)\}\)도 됩니다. 기저는 여러 개지만 차원은 하나입니다.

다른 공간의 예

  • 차수 2 이하 다항식 \(P_2\): 기저 \(\{1, x, x^2\}\), 차원 3. \(3 - 2x + 5x^2\)의 좌표는 \((3, -2, 5)\).
  • \(y'' + y = 0\)의 해 전체: 기저 \(\{\cos x, \sin x\}\), 차원 2 (미분방정식 과목에서 증명).

흔한 오해

  • "\(\mathbb R^3\) 안의 평면이니 3차원." 차원은 그 공간 자신의 기저 개수입니다.
  • "\(n\)개의 독립 벡터가 있으면 기저." \(\dim V = n\)일 때만 맞습니다. 그때는 독립이기만 하면 자동으로 생성합니다.
