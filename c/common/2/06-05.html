6.5.1원기둥좌표

\(xy\)평면은 극좌표로, 높이는 그대로 \(z\)로 둡니다: \(x = r\cos\theta\), \(y = r\sin\theta\), \(z = z\). 부피 요소는 극좌표의 넓이 요소에 높이 \(dz\)를 곱한 \(dV = r\,dz\,dr\,d\theta\)입니다. \(z\)축을 둘러싼 대칭 입체(원기둥, 원뿔, 포물면)에 씁니다.

예제 6.5.1

포물면 \(z = x^2 + y^2\)과 평면 \(z = 4\) 사이 입체의 부피를 구하여라.

풀이. \(r^2 \le z \le 4\), \(0 \le r \le 2\).

\[\int_0^{2\pi}\int_0^2\int_{r^2}^4r\,dz\,dr\,d\theta = 2\pi\int_0^2(4r - r^3)\,dr = 2\pi(8 - 4) = 8\pi.\]

6.5.2구면좌표

점 \(P\)를 다음 세 수로 나타냅니다.

  • \(\rho\): 원점에서의 거리 (\(\rho \ge 0\)).
  • \(\theta\): 원기둥좌표와 같은 수평 각 (경도와 비슷).
  • \(\phi\): 양의 \(z\)축에서 내려온 각, \(0 \le \phi \le \pi\) (북극에서 잰 위도와 비슷).
\[x = \rho\sin\phi\cos\theta, \quad y = \rho\sin\phi\sin\theta, \quad z = \rho\cos\phi.\]

작은 조각은 거의 상자이고 세 변이 \(d\rho\), \(\rho\,d\phi\), \(\rho\sin\phi\,d\theta\)이므로(수평 원의 반지름이 \(\rho\sin\phi\)) 부피 요소는

\[dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta.\]
예제 6.5.2

반지름 \(a\)인 구의 부피를 구하여라.

풀이. \(\int_0^{2\pi}\int_0^\pi\int_0^a\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = 2\pi\cdot2\cdot\frac{a^3}{3} = \frac43\pi a^3\). 고교에서 공식으로 외운 값이 나옵니다.

예제 6.5.3

원뿔 \(\phi = \frac\pi4\) 안쪽, 단위구 안쪽에 있는 입체(아이스크림 모양)의 부피를 구하여라.

풀이. \(0 \le \rho \le 1\), \(0 \le \phi \le \frac\pi4\).

\[2\pi\cdot\frac13\cdot\left[-\cos\phi\right]_0^{\pi/4} = \frac{2\pi}{3}\left(1 - \frac{\sqrt2}{2}\right) \approx 0.613.\]
요약
  1. 원기둥좌표: \(dV = r\,dz\,dr\,d\theta\). \(z\)축 대칭 입체.
  2. 구면좌표: \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\). 구, 원뿔.

6.5.3연습문제

기본

  1. 점 \((0, 0, 2)\)의 구면좌표는?
    답

    \(\rho = 2\), \(\phi = 0\) (\(\theta\)는 아무 값).

  2. 반지름 1, 높이 2인 원기둥의 부피를 원기둥좌표로 구하여라.
    답

    \(\int_0^{2\pi}\int_0^1\int_0^2r\,dz\,dr\,d\theta = 2\pi\).

응용

  1. 단위구 안에서 \(\iiint(x^2 + y^2 + z^2)\,dV\)는?
    답

    \(\int\int\int\rho^4\sin\phi = 2\pi\cdot2\cdot\frac15 = \frac{4\pi}{5}\).

6.5.2

예제극좌표, 원통좌표, 구면좌표로 적분하기

dA = r dr dθ · dV = ρ² sin φ dρ dφ dθ

다루는 성취기준 [공통2-06-05]

넓이·부피 요소가 왜 그런가

  1. 극좌표 \(dA = r\,dr\,d\theta\)\(r\)이 \(dr\), \(\theta\)가 \(d\theta\)만큼 변하면 거의 직사각형인 조각이 생깁니다. 가로 \(dr\), 세로는 호의 길이 \(r\,d\theta\). 그래서 \(r\)이 곱해집니다. 원점에서 멀수록 같은 \(d\theta\)가 넓은 조각을 만듭니다.
  2. 원통좌표 \(dV = r\,dr\,d\theta\,dz\)극좌표 조각에 높이 \(dz\)를 곱함. \(x = r\cos\theta\), \(y = r\sin\theta\), \(z = z\).
  3. 구면좌표 \(dV = \rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta\)\(x = \rho\sin\varphi\cos\theta\), \(y = \rho\sin\varphi\sin\theta\), \(z = \rho\cos\varphi\) (\(\varphi\)는 \(z\)축에서 잰 각, \(0 \le \varphi \le \pi\)). 조각의 세 변은 \(d\rho\), \(\rho\,d\varphi\) (경선 방향 호), \(\rho\sin\varphi\,d\theta\) (위선 방향 호, 위선의 반지름이 \(\rho\sin\varphi\)).

정확한 근거는 다음 카드의 야코비안입니다. 좌표 선택 기준: 영역의 경계나 피적분함수에 \(x^2 + y^2\)이 있으면 극·원통, \(x^2 + y^2 + z^2\)이 있으면 구면.

(가) 반지름 \(R\)인 공의 부피를 구면좌표로 구하세요. (나) \(\displaystyle\iint_{\mathbb R^2}e^{-(x^2+y^2)}\,dA\)를 구하고, 이것으로 \(\displaystyle\int_{-\infty}^{\infty}e^{-x^2}dx = \sqrt\pi\)를 보이세요.

풀이

  1. (가) 공: \(0 \le \rho \le R\), \(0 \le \varphi \le \pi\), \(0 \le \theta \le 2\pi\). 한계가 모두 상수다.
    구면좌표가 공을 "직사각형 상자"로 바꾼다.
  2. \(V = \int_0^{2\pi}\int_0^\pi\int_0^R\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\cdot2\cdot\frac{R^3}{3} = \frac43\pi R^3\).
    한계가 상수이고 피적분함수가 곱 꼴이라 세 일변수 적분의 곱. \(\int_0^\pi\sin\varphi = 2\).
  3. (나) 극좌표: \(\int_0^{2\pi}\int_0^\infty e^{-r^2}r\,dr\,d\theta = 2\pi\cdot\left[-\frac12e^{-r^2}\right]_0^\infty = \pi\).
    \(r\,dr\)이 있어서 \(u = r^2\) 치환이 된다. 직교좌표로는 불가능했던 적분. (이상적분이지만 피적분함수가 양수라 순서·좌표를 바꿔도 된다.)
  4. \(I = \int_{-\infty}^\infty e^{-x^2}dx\)이면 \(I^2 = \int e^{-x^2}dx\int e^{-y^2}dy = \iint e^{-(x^2+y^2)}dA = \pi\). \(I > 0\)이므로 \(I = \sqrt\pi\).
    곱 꼴 피적분함수는 반복적분이 두 적분의 곱이다(Fubini).

의미

(나)의 \(\int e^{-x^2}dx = \sqrt\pi\)는 일변수로는 구할 수 없는 값을 2차원으로 올려 극좌표로 구한 것입니다. 정규분포의 정규화 상수 \(\frac{1}{\sqrt{2\pi}}\)가 여기서 나옵니다. 영역의 대칭에 맞는 좌표를 고르면 한계가 상수가 되어 계산이 곱으로 쪼개집니다.

검산

(나)는 정규분포 밀도 \(\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\)의 전체 적분이 1임을 보이는 계산과 같습니다(\(x = t/\sqrt2\)로 치환). 확률통계 과목에서 그대로 씁니다.

흔한 오해

  • \(r\)이나 \(\rho^2\sin\varphi\) 빠뜨리기: 가장 흔한 실수입니다. 빠뜨리면 공의 부피가 \(2\pi^2R\) 같은 차원이 맞지 않는 값이 됩니다.
  • \(\varphi\)의 범위: \(\varphi\)는 \(0\)부터 \(\pi\)까지입니다(\(2\pi\) 아님).
