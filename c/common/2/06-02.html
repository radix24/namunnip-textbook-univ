6.2.1두 가지 영역

영역이 직사각형이 아니면 안쪽 적분의 범위가 바깥 변수에 따라 달라집니다.

  • 세로로 자르기: \(D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_a^b\int_{g_1(x)}^{g_2(x)}f\,dy\,dx\).
  • 가로로 자르기: \(D = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}\)이면 \(\displaystyle\iint_Df\,dA = \int_c^d\int_{h_1(y)}^{h_2(y)}f\,dx\,dy\).

범위를 정하는 요령: 영역을 그리고, 바깥 변수를 하나 고정한 선(세로선 또는 가로선)이 영역에 들어가는 곳과 나오는 곳을 읽습니다. \(f = 1\)이면 \(\iint_D1\,dA\)는 \(D\)의 넓이로, 고교의 "두 곡선 사이의 넓이"와 같습니다.

예제 6.2.1

\(D\)가 포물선 \(y = 2x^2\)과 \(y = 1 + x^2\)으로 둘러싸인 영역일 때 \(\iint_D(x + 2y)\,dA\)를 구하여라.

풀이. 교점: \(2x^2 = 1 + x^2\), \(x = \pm1\). \(-1 \le x \le 1\)에서 아래가 \(2x^2\), 위가 \(1 + x^2\)입니다.

\[\int_{-1}^1\left[xy + y^2\right]_{y=2x^2}^{y=1+x^2}dx = \int_{-1}^1(-3x^4 - x^3 + 2x^2 + x + 1)\,dx.\]

홀수 차수 항은 대칭 구간에서 0이므로 \(-\frac65 + \frac43 + 2 = \frac{32}{15}\).

6.2.2적분 순서 바꾸기

예제 6.2.2

\(\displaystyle\int_0^1\int_x^1\sin(y^2)\,dy\,dx\)를 구하여라.

풀이. \(\sin(y^2)\)의 부정적분은 기본 함수로 쓸 수 없어서 이 순서로는 계산할 수 없습니다. 영역은 \(0 \le x \le 1\), \(x \le y \le 1\): 꼭짓점이 \((0, 0)\), \((0, 1)\), \((1, 1)\)인 삼각형입니다. 가로로 자르면 \(0 \le y \le 1\), \(0 \le x \le y\)입니다.

\[\int_0^1\int_0^y\sin(y^2)\,dx\,dy = \int_0^1y\sin(y^2)\,dy = \left[-\frac12\cos(y^2)\right]_0^1 = \frac{1 - \cos1}{2}.\]

같은 영역을 다르게 잘랐을 뿐인데 계산이 가능해졌습니다. 순서를 바꿀 때는 반드시 영역을 그려서 범위를 새로 읽어야 합니다.

요약
  1. 안쪽 범위는 바깥 변수의 함수. 영역을 그려 읽는다.
  2. 계산이 막히면 순서를 바꾼다.

6.2.3연습문제

기본

  1. \(y = x\)와 \(y = x^2\)으로 둘러싸인 영역의 넓이를 이중적분으로 구하여라.
    답

    \(\int_0^1\int_{x^2}^x1\,dy\,dx = \frac12 - \frac13 = \frac16\).

응용

  1. \(\displaystyle\int_0^1\int_{\sqrt y}^1e^{x^3}\,dx\,dy\)의 순서를 바꾸어 계산하여라.
    답

    영역 \(0 \le x \le 1\), \(0 \le y \le x^2\). \(\int_0^1x^2e^{x^3}dx = \frac{e - 1}{3}\).

이 절의 성취기준[공통2-06-02] 계산

  1. 일반 영역에서 이중적분을 계산하고 적분 순서를 바꿀 수 있다.

6.2.2

예제이중적분과 적분 순서 바꾸기

Fubini 정리 · 영역을 두 가지로 읽기

다루는 성취기준 [공통2-06-02]

정의와 Fubini 정리

이중적분 \(\iint_R f\,dA\)는 영역을 작은 직사각형으로 나눠 \(f(\text{표본점})\times\text{넓이}\)를 더한 리만 합의 극한입니다(공통1의 정적분을 2차원으로). \(f \ge 0\)이면 그래프 아래 부피입니다.

Fubini 정리 (증명은 해석학)

\(f\)가 영역에서 연속이면 이중적분은 반복적분과 같고, 순서와 상관없다. 예: \(R = [a,b]\times[c,d]\)이면 \(\iint_R f\,dA = \int_a^b\!\!\int_c^d f\,dy\,dx = \int_c^d\!\!\int_a^b f\,dx\,dy\).

뜻: 부피를 \(x\)에 수직인 단면 넓이 \(A(x) = \int f(x, y)\,dy\)로 썰어 \(\int A(x)\,dx\)로 더해도, \(y\)에 수직으로 썰어도 같다는 것입니다.

일반 영역

  • 세로형: \(D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\) → \(\int_a^b\int_{g_1(x)}^{g_2(x)}f\,dy\,dx\). 바깥 적분의 한계는 상수, 안쪽은 바깥 변수의 함수.
  • 가로형: \(D = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}\) → \(\int_c^d\int_{h_1(y)}^{h_2(y)}f\,dx\,dy\).

순서를 바꾸려면 영역을 그려서 다른 방식으로 다시 읽습니다. 한계만 바꿔 쓰면 틀립니다.

먼저 예측

\(\int_0^1\int_x^1e^{y^2}\,dy\,dx\)의 값은 대략 어느 범위일까요? 영역의 넓이와 피적분함수의 범위로 짐작해 보세요.

예측 확인

영역 넓이 \(\frac12\), \(1 \le e^{y^2} \le e\)이므로 0.5와 1.36 사이입니다. 실제 값은 0.859입니다.

\(\displaystyle\int_0^1\int_{x}^{1}e^{y^2}\,dy\,dx\)를 계산하세요.

풀이

  1. 안쪽 \(\int e^{y^2}dy\)는 기본 함수로 쓸 수 없다. 순서를 바꿔야 한다.
    공통1에서 본 대로 \(e^{y^2}\)의 부정적분은 식으로 쓸 수 없다.
  2. 영역: \(0 \le x \le 1\), \(x \le y \le 1\). 꼭짓점 \((0,0), (0,1), (1,1)\)인 삼각형(대각선 위쪽).
    한계에서 영역을 그린다.
  3. 가로로 읽으면: \(0 \le y \le 1\), \(0 \le x \le y\).
    높이 \(y\)에서 가로선은 \(x = 0\)부터 대각선 \(x = y\)까지.
  4. \(\int_0^1\int_0^y e^{y^2}\,dx\,dy = \int_0^1 ye^{y^2}\,dy\).
    안쪽은 \(x\)에 대해 상수의 적분이라 \(y\)가 곱해진다.
  5. \(u = y^2\): \(\frac12\int_0^1e^u\,du = \frac{e - 1}{2}\).
    곱해진 \(y\)가 치환을 가능하게 했다. 순서 바꾸기의 요점.

의미

적분 순서를 바꾸자 계산할 수 없던 적분이 쉬운 치환으로 바뀌었습니다. 같은 입체를 다른 방향으로 썬 것일 뿐이라 값은 같습니다. 순서를 바꾸기 전에 늘 영역을 그려야 하는 이유입니다.

검산

영역 넓이 \(\frac12\), 피적분함수는 1과 \(e\) 사이이므로 답은 \(\frac12\)과 \(\frac e2 \approx 1.36\) 사이여야 합니다. \(\frac{e-1}{2} \approx 0.859\). 맞습니다.

흔한 오해

  • 바깥 한계에 변수: \(\int_0^y\int_0^1 \cdots\)처럼 바깥 적분 한계에 안쪽 변수가 남으면 틀린 식입니다.
  • 순서를 바꾸며 한계를 그대로: \(\int_0^1\int_x^1 = \int_x^1\int_0^1\)이 아닙니다.
