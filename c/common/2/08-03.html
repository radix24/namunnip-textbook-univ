8.3.1정리

정리 8.3.1 (스토크스 정리)

방향이 정해진 곡면 \(S\)의 경계가 곡선 \(C\)이면

\[\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S.\]

방향 맞추기: 오른손 엄지를 법선 \(\mathbf n\) 방향으로 두면 나머지 손가락이 감기는 방향이 \(C\)의 방향입니다. 곡면이 평면 영역이고 \(\mathbf n = \mathbf k\)이면 \((\nabla\times\mathbf F)\cdot\mathbf k = Q_x - P_y\)이므로 그린 정리가 됩니다. 곧 스토크스 정리는 그린 정리를 휘어진 곡면으로 넓힌 것이고, 뜻도 같습니다: "곡면 위 소용돌이의 합 = 경계를 도는 양(순환)".

8.3.2예제

예제 8.3.2

\(\mathbf F = \langle-y^2, x, z^2\rangle\), \(C\)는 평면 \(y + z = 2\)와 원기둥 \(x^2 + y^2 = 1\)의 교선(위에서 볼 때 시계 반대 방향)이다. \(\oint_C\mathbf F\cdot d\mathbf r\)를 구하여라.

풀이. \(\nabla\times\mathbf F = \langle0, 0, 1 + 2y\rangle\). \(C\)를 경계로 하는 곡면으로 평면 \(z = 2 - y\)에서 원기둥 안쪽 부분(타원판)을 고르고 위쪽 법선을 씁니다. 그래프 \(z = g(x, y)\)에서 \(\mathbf r_x\times\mathbf r_y = \langle-g_x, -g_y, 1\rangle = \langle0, 1, 1\rangle\)이므로

\[\iint_D\langle0, 0, 1 + 2y\rangle\cdot\langle0, 1, 1\rangle\,dA = \iint_D(1 + 2y)\,dA = \pi + 0 = \pi.\]

(\(D\)는 단위원판, \(\iint_D2y\,dA = 0\)은 대칭.) 교선을 직접 매개화해 적분하는 것보다 간단합니다.

예제 8.3.3

\(\mathbf F = \langle-y, x, 0\rangle\)에 대해, 단위 반구면 \(z \ge 0\)(바깥쪽)을 지나는 \(\nabla\times\mathbf F\)의 선속을 구하여라.

풀이. 경계는 \(xy\)평면의 단위원. 스토크스 정리로 선적분 \(\oint(-y\,dx + x\,dy) = 2\pi\)(7.4절 연습문제). 경계가 같은 평평한 원판에서 \(\nabla\times\mathbf F = \langle0, 0, 2\rangle\)를 적분해도 \(2\pi\)입니다. 경계가 같으면 곡면 모양은 상관없습니다.

요약
  1. \(\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S\). 방향은 오른손 법칙.
  2. 평면이면 그린 정리. 경계가 같으면 계산하기 쉬운 곡면을 고른다.

8.3.3연습문제

기본

  1. 보존장 \(\mathbf F = \nabla f\)에 대해 \(\oint_C\mathbf F\cdot d\mathbf r = 0\)임을 스토크스 정리로 설명하여라.
    답

    \(\nabla\times\nabla f = \mathbf 0\)이므로 면적분이 0.

응용

  1. \(\mathbf F = \langle0, x, 0\rangle\), \(C\)는 \(xy\)평면의 반지름 2인 원(시계 반대 방향). 선적분은?
    답

    \(\nabla\times\mathbf F = \langle0, 0, 1\rangle\). 원판 넓이 \(4\pi\).

이 절의 성취기준[공통2-08-03] 계산

  1. 스토크스 정리로 선적분을 면적분으로 바꾸어 계산할 수 있다.

8.3.2

예제Stokes 정리와 발산 정리로 계산을 줄이기

경계 ↔ 안쪽 · 곡면 바꾸기 · 닫아서 빼기

다루는 성취기준 [공통2-08-03]

두 정리

Stokes 정리

방향이 정해진 매끄러운 곡면 \(S\)와 그 경계 \(C\) (오른손 규칙: 엄지가 \(\mathbf n\), 나머지 손가락이 \(C\)의 방향)에 대해 \(\displaystyle\oint_C\mathbf F\cdot d\mathbf r = \iint_S(\nabla\times\mathbf F)\cdot d\mathbf S\).

발산 정리 (Gauss)

닫힌 곡면 \(S\) (바깥 방향)가 둘러싼 입체 \(E\)에 대해 \(\displaystyle\oiint_S\mathbf F\cdot d\mathbf S = \iiint_E\nabla\cdot\mathbf F\,dV\).

근거는 앞 카드의 해석입니다. 입체를 작은 상자로 나누면 이웃 상자의 공유면 선속이 소거되어 바깥 겉면만 남고(발산 정리), 곡면을 작은 조각으로 나누면 공유 변의 선적분이 소거되어 경계만 남습니다(Stokes). Green 정리는 Stokes 정리에서 \(S\)가 평면인 경우입니다. 모두 공통1의 기본정리 "경계의 값 = 안쪽 도함수의 합"과 같은 꼴입니다.

요령 세 가지

  1. 어려운 쪽을 쉬운 쪽으로선적분이 길면 회전의 면적분으로, 선속이 어려우면 발산의 부피적분으로.
  2. 곡면 바꾸기Stokes에서 경계가 같으면 어떤 곡면을 써도 \(\iint(\nabla\times\mathbf F)\cdot d\mathbf S\)가 같습니다. 가장 평평한 곡면(원판)을 고릅니다.
  3. 닫아서 빼기열린 곡면의 선속은 뚜껑을 덮어 닫힌 곡면으로 만들고, 발산 정리 값에서 뚜껑의 선속을 뺍니다.

(가) \(\mathbf F = (-y^3, x^3, -z^3)\), \(C\): 원기둥 \(x^2 + y^2 = 1\)과 평면 \(x + y + z = 1\)의 교선(위에서 볼 때 반시계)에서 \(\oint_C\mathbf F\cdot d\mathbf r\). (나) \(\mathbf F = (xy, y^2 + e^{xz^2}, \sin(xy))\), \(E\): 포물기둥 \(z = 1 - x^2\)과 평면 \(z = 0, y = 0, y + z = 2\)로 둘러싸인 입체의 겉면을 지나는 바깥 선속.

풀이

  1. (가) \(\nabla\times\mathbf F = (0 - 0,\ 0 - 0,\ 3x^2 + 3y^2) = (0, 0, 3(x^2 + y^2))\).
    \(R = -z^3\)은 \(x, y\)를 포함하지 않고, \(P, Q\)는 \(z\)를 포함하지 않는다.
  2. 곡면: 평면 \(z = 1 - x - y\)의 원기둥 안쪽 부분, 위쪽 법선 \((1, 1, 1)\) (그래프 공식 \((-g_x, -g_y, 1)\)).
    경계가 \(C\)인 가장 단순한 곡면. 위쪽 법선이 반시계 방향과 오른손 규칙으로 맞는다.
  3. \(\iint_{x^2+y^2\le1}3(x^2 + y^2)\,dA = 3\int_0^{2\pi}\int_0^1r^3\,dr\,d\theta = \frac{3\pi}{2}\).
    \((0,0,3r^2)\cdot(1,1,1) = 3r^2\). 그림자는 단위원판.
  4. (나) \(\nabla\cdot\mathbf F = y + 2y + 0 = 3y\).
    복잡한 항 \(e^{xz^2}\)은 \(y\)에 대해 상수, \(\sin(xy)\)는 \(z\)에 대해 상수라 사라진다. 겉면 다섯 개를 직접 적분할 필요가 없다.
  5. \(E\): \(-1 \le x \le 1\), \(0 \le z \le 1 - x^2\), \(0 \le y \le 2 - z\). \(\iiint3y\,dV = \int_{-1}^1\int_0^{1-x^2}\frac32(2 - z)^2\,dz\,dx = \int_{-1}^1\frac12\left[8 - (1 + x^2)^3\right]dx = \frac{184}{35}\).
    \(\int_0^{2-z}3y\,dy = \frac32(2-z)^2\), \(\int_0^{1-x^2}\frac32(2 - z)^2dz = \frac12[8 - (1 + x^2)^3]\). 마지막 적분: \(\int_{-1}^1(1 + x^2)^3dx = 2\left(1 + 1 + \frac35 + \frac17\right) = \frac{192}{35}\), 그러므로 \(\frac12\left(16 - \frac{192}{35}\right) = \frac{184}{35}\).

의미

두 정리는 "경계에서 잰 것 = 안쪽에서 생긴 것의 합"이라는 한 문장입니다. 맥스웰 방정식을 적분꼴(경계의 선적분·선속)과 미분꼴(회전·발산)로 오갈 때 쓰는 정리가 바로 이 둘입니다.

검산

(가) 직접 계산으로 확인: \(C\)는 \((\cos t, \sin t, 1 - \cos t - \sin t)\). \(z\) 성분의 기여 \(\oint -z^3\,dz\)는 \(-\frac{z^4}{4}\)의 완전미분이라 닫힌 곡선에서 0. 나머지 \(\int_0^{2\pi}(\sin^4t + \cos^4t)\,dt = 2\pi\cdot\frac34 = \frac{3\pi}{2}\). 일치합니다.

흔한 오해

  • 열린 곡면에 발산 정리: 닫힌 곡면에서만 성립합니다. 열린 곡면이면 뚜껑을 덮고 빼세요.
  • 방향 짝 맞추기: Stokes에서 \(C\)의 방향과 \(\mathbf n\)이 오른손 규칙에 맞지 않으면 부호가 바뀝니다.
