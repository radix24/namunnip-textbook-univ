7.4.1정리

닫힌 곡선 \(C\)의 양의 방향은 곡선을 따라 걸을 때 둘러싸인 영역이 왼쪽에 있는 방향, 곧 시계 반대 방향입니다.

정리 7.4.1 (그린 정리)

\(C\)가 영역 \(D\)를 둘러싼 양의 방향 단순 닫힌 곡선이고 \(P, Q\)의 편도함수가 연속이면

\[\oint_CP\,dx + Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA.\]

뜻: \(Q_x - P_y\)는 각 점에서 벡터장이 얼마나 소용돌이치는지(7.5절의 회전)를 나타냅니다. \(D\)를 작은 정사각형으로 나누면 이웃한 두 정사각형이 공유하는 변에서는 서로 반대 방향으로 지나가 선적분이 지워지고, 바깥 경계 \(C\)만 남습니다. 그래서 "안쪽 소용돌이의 합 = 경계를 도는 양"입니다. 미적분의 기본정리처럼 "안쪽의 미분을 적분하면 경계의 값"이라는 구조입니다.

예제 7.4.2

\(C\)가 \((0, 0)\), \((1, 0)\), \((0, 1)\)을 잇는 삼각형(양의 방향)일 때 \(\oint_Cx^4\,dx + xy\,dy\)를 구하여라.

풀이. \(Q_x - P_y = y - 0 = y\).

\[\int_0^1\int_0^{1-x}y\,dy\,dx = \int_0^1\frac{(1 - x)^2}{2}dx = \frac16.\]

세 변을 따로 매개화하는 것보다 훨씬 간단합니다.

예제 7.4.3

원 \(x^2 + y^2 = 9\)에서 \(\oint_C(3y - e^{\sin x})\,dx + (7x + \sqrt{y^4 + 1})\,dy\)를 구하여라.

풀이. 직접은 거의 계산할 수 없지만 \(Q_x - P_y = 7 - 3 = 4\)이므로 \(4\times9\pi = 36\pi\).

7.4.2넓이 공식

\(Q_x - P_y = 1\)이 되도록 \(P = -\frac y2\), \(Q = \frac x2\)를 고르면

\[\text{넓이}(D) = \frac12\oint_C(x\,dy - y\,dx).\]
예제 7.4.4

타원 \(x = a\cos t\), \(y = b\sin t\)의 넓이를 구하여라.

풀이. \(\frac12\int_0^{2\pi}(ab\cos^2t + ab\sin^2t)\,dt = \pi ab\). 경계만 따라가며 넓이를 재는 기계(구적기)가 이 원리로 작동합니다.

요약
  1. \(\oint_CP\,dx + Q\,dy = \iint_D(Q_x - P_y)\,dA\), \(C\)는 시계 반대 방향.
  2. 넓이 \(= \frac12\oint(x\,dy - y\,dx)\).

7.4.3연습문제

기본

  1. 단위원에서 \(\oint(-y\,dx + x\,dy)\)를 그린 정리로 구하여라.
    답

    \(Q_x - P_y = 2\). \(2\pi\).

  2. 보존장의 닫힌 곡선 선적분이 0임을 그린 정리로 설명하여라.
    답

    \(P_y = Q_x\)이므로 피적분 함수가 0.

7.4.2

증명Green 정리: 경계를 도는 선적분 = 안쪽의 회전을 모두 더한 것

단순 영역에서의 증명 · 넓이 공식

다루는 성취기준 [공통2-07-04]

Green 정리

\(D\)가 조각마다 매끄러운 단순 닫힌곡선 \(C\)로 둘러싸인 영역이고 \(C\)는 반시계 방향(\(D\)가 왼쪽)이며, \(P, Q\)가 \(D\)를 포함하는 열린 영역에서 연속인 편도함수를 가지면

\[\oint_C P\,dx + Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dA.\]

뜻

\(Q_x - P_y\)는 점 근처의 작은 사각형을 한 바퀴 도는 선적분을 넓이로 나눈 것(회전의 세기)입니다. 영역을 잘게 나눠 작은 사각형마다 선적분을 더하면, 이웃한 사각형이 공유하는 변은 반대 방향으로 두 번 지나 소거되고 바깥 경계만 남습니다. 공통1의 기본정리 "구간의 끝에서의 값 = 안쪽 도함수의 합"을 2차원으로 올린 것입니다.

증명 (\(D\)가 세로형이면서 가로형인 경우)

\(\oint P\,dx = -\iint P_y\,dA\)와 \(\oint Q\,dy = \iint Q_x\,dA\)를 따로 보입니다. 앞의 것을 보입니다.

  1. \(D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\).
    세로형 영역.
  2. \(\iint_DP_y\,dA = \int_a^b\int_{g_1}^{g_2}P_y\,dy\,dx = \int_a^b[P(x, g_2(x)) - P(x, g_1(x))]\,dx\).
    Fubini와 일변수 기본정리(\(y\)에 대해).
  3. 경계는 넷: 아래 \(C_1\): \((x, g_1(x))\), \(x: a \to b\). 오른쪽 수직선 \(C_2\), 위 \(C_3\): \(x: b \to a\), 왼쪽 수직선 \(C_4\).
    반시계 방향으로.
  4. \(\int_{C_1}P\,dx = \int_a^bP(x, g_1(x))\,dx\), \(\int_{C_3}P\,dx = -\int_a^bP(x, g_2(x))\,dx\), 수직선에서는 \(dx = 0\).
    \(C_3\)은 \(x\)가 줄어드는 방향이라 부호가 바뀐다.
  5. 더하면 \(\oint_CP\,dx = -\int_a^b[P(x, g_2) - P(x, g_1)]\,dx = -\iint_DP_y\,dA\).
    2단계와 비교. \(Q\) 쪽은 가로형으로 보고 같은 방식.

일반 영역은 이런 조각으로 나눠 더합니다(공유 경계는 소거). 구멍이 있는 영역은 바깥은 반시계, 안쪽 경계는 시계 방향으로 돌면 성립합니다.

(가) \(\oint_C(3y - e^{\sin x})\,dx + (7x + \sqrt{y^4 + 1})\,dy\), \(C\): 원 \(x^2 + y^2 = 9\) 반시계. (나) Green 정리로 넓이 공식 \(A = \frac12\oint x\,dy - y\,dx\)를 얻고, 타원 넓이를 구하세요.

풀이

  1. (가) \(Q_x - P_y = 7 - 3 = 4\). 선적분 \(= \iint_D4\,dA = 4\cdot9\pi = 36\pi\).
    직접 계산하면 \(e^{\sin x}\), \(\sqrt{y^4 + 1}\)이 불가능하지만, 그 항들은 편미분에서 사라진다(\(P\)의 \(x\)만의 항, \(Q\)의 \(y\)만의 항).
  2. (나) \(P = -\frac y2\), \(Q = \frac x2\)이면 \(Q_x - P_y = 1\), 곧 \(\frac12\oint x\,dy - y\,dx = \iint1\,dA = A\).
    회전이 1인 장을 고른다.
  3. 타원 \(x = a\cos t\), \(y = b\sin t\): \(\frac12\int_0^{2\pi}(ab\cos^2t + ab\sin^2t)\,dt = \pi ab\).
    경계만 알면 넓이를 구한다. 측량용 구적기(플래니미터)가 이 원리로 작동한다.

흔한 오해

  • 방향: 시계 방향이면 부호가 반대입니다.
  • 특이점: 앞 카드의 \(\left(\frac{-y}{r^2}, \frac{x}{r^2}\right)\)는 원점에서 정의되지 않으므로 원점을 둘러싼 곡선에 Green 정리를 그대로 쓸 수 없습니다(쓰면 0이 나오지만 실제는 \(2\pi\)).
7.4.3

실습순환과 회전을 같은 저울에 달기

실습 · 그린 정리

다루는 성취기준 [공통2-07-04] [공통2-07-05]

목표

원의 위치와 크기를 바꿔 가며 경계를 도는 순환 \(\oint\mathbf F\cdot d\mathbf r\)과 안쪽의 회전 \(\iint(Q_x - P_y)\,dA\)를 따로 계산하고, 둘이 언제나 같음(그린 정리)을 확인합니다. 회전이 양수인 곳과 음수인 곳이 순환에 어떻게 기여하는지 봅니다. 성취기준 [공통2-07-04], [공통2-07-05].

준비

배경색은 회전 \(Q_x - P_y\)입니다(주황 양수, 파랑 음수). 회색 화살표는 벡터장, 검은 원이 경로입니다. 원의 중심은 끌어 옮기고 반지름은 조절기로 바꿉니다. 두 적분은 수치로 계산합니다.

절차

  1. \(\langle-y, x\rangle\)에서 반지름을 바꾸며 순환이 \(2\pi r^2\)인지 확인한다. 중심을 옮겨도 값이 같은지 본다.
  2. \(\langle\sin y, x^2\rangle\)에서 원을 주황 영역과 파랑 영역으로 옮기며 순환의 부호를 본다.
  3. \(\langle x^2y, x\rangle\)에서 원이 \(x = \pm1\)을 넘을 때 회전의 부호가 바뀌는 것을 본다.
  4. \(\langle x, y\rangle\)에서 두 값이 늘 0인지 확인한다.

기대 결과

  • 두 값은 모든 경우에 같다(수치 오차 범위 안).
  • \(\langle-y, x\rangle\)는 회전이 어디서나 2이므로 순환 = 2 × 넓이, 위치와 무관.
  • 회전이 음수인 영역만 감싸면 순환도 음수.
  • \(\langle x, y\rangle\)는 회전이 0인 보존장이라 어떤 원에서든 순환 0.

분석

  1. 원을 아주 작게 하면 순환 ÷ 넓이는 무엇에 가까워지나요? 이것이 회전의 정의입니다.
  2. 그린 정리로 넓이를 선적분으로 구하는 공식 \(\frac12\oint(x\,dy - y\,dx)\)는 이 장치의 어느 벡터장과 관계있나요?

더 해 보기

\(\langle-y^3, x^3\rangle\)의 원점 중심 원에서 순환을 극좌표 이중적분으로 계산하면 \(\frac{3\pi r^4}{2}\)입니다. 반지름 1에서 출력과 비교해 보세요.
