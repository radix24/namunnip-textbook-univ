3.1.1벡터함수

실수 \(t\)마다 벡터 하나를 대응시키는 함수 \(\mathbf r(t) = \langle f(t), g(t), h(t)\rangle\)를 벡터함수라 합니다. \(t\)를 시간으로 보면, 끝점 \((f(t), g(t), h(t))\)가 움직이며 그리는 자취가 공간곡선입니다. 공통1 7.1절의 매개변수 곡선을 3차원으로 넓힌 것입니다.

예제 3.1.1

\(\mathbf r(t) = \langle\cos t, \sin t, t\rangle\)이 그리는 곡선을 설명하여라.

풀이. \(x^2 + y^2 = 1\)이므로 점은 원기둥 위에 있습니다. \(t\)가 늘면 \((x, y)\)는 원을 돌고 높이 \(z = t\)는 계속 올라갑니다. 용수철 모양의 나선(helix)이며, 한 바퀴(\(t\)가 \(2\pi\) 증가)에 \(2\pi\)만큼 올라갑니다. DNA의 이중 나선이 이런 모양입니다.

예제 3.1.2

원기둥 \(x^2 + y^2 = 1\)과 평면 \(y + z = 2\)가 만나는 곡선을 벡터함수로 나타내어라.

풀이. 원기둥 위에서 \(x = \cos t\), \(y = \sin t\)로 놓고 평면에서 \(z = 2 - y = 2 - \sin t\). \(\mathbf r(t) = \langle\cos t, \sin t, 2 - \sin t\rangle\), \(0 \le t \le 2\pi\). 비스듬히 잘린 원기둥의 단면이므로 타원입니다.

3.1.2극한과 연속

벡터함수의 극한은 성분마다 극한을 구한 것입니다.

\[\lim_{t\to a}\mathbf r(t) = \left\langle\lim_{t\to a}f(t), \lim_{t\to a}g(t), \lim_{t\to a}h(t)\right\rangle.\]

\(\lim_{t\to a}\mathbf r(t) = \mathbf r(a)\)이면 \(\mathbf r\)은 \(a\)에서 연속이라 합니다. 성분이 모두 연속이면 됩니다. 연속인 벡터함수가 그리는 곡선은 끊어지지 않습니다.

예제 3.1.3

\(\displaystyle\lim_{t\to0}\left\langle1 + t^3, te^{-t}, \frac{\sin t}{t}\right\rangle\)을 구하여라.

풀이. 성분별로 \(1\), \(0\), \(1\) (\(\frac{\sin t}{t} \to 1\)은 공통1 1단원). 답 \(\langle1, 0, 1\rangle\).

요약
  1. \(\mathbf r(t) = \langle f, g, h\rangle\): 움직이는 점의 위치. 자취가 공간곡선.
  2. 극한과 연속은 성분별로.
  3. 두 곡면의 교선은 한 곡면을 매개화하고 다른 식에 대입해 구한다.

3.1.3연습문제

기본

  1. \(\mathbf r(t) = \langle t, t^2, t^3\rangle\)은 \(t = 2\)에서 어느 점을 지나는가?
    답

    \((2, 4, 8)\).

  2. \(\mathbf r(t) = \langle1 + t, 2 - t, 3t\rangle\)은 어떤 곡선인가?
    답

    점 \((1, 2, 0)\)을 지나고 방향 \(\langle1, -1, 3\rangle\)인 직선.

응용

  1. 원뿔 \(z = \sqrt{x^2 + y^2}\)과 평면 \(z = 1 + y\)의 교선을 매개화하여라.
    답

    제곱하면 \(x^2 + y^2 = (1 + y)^2\), \(y = \frac{x^2 - 1}{2}\). \(x = t\), \(y = \frac{t^2 - 1}{2}\), \(z = \frac{t^2 + 1}{2}\).
