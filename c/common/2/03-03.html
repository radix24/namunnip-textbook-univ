3.3.1곡선의 길이

속력을 시간에 대해 적분하면 움직인 거리입니다.

\[L = \int_a^b|\mathbf r'(t)|\,dt = \int_a^b\sqrt{f'(t)^2 + g'(t)^2 + h'(t)^2}\,dt.\]
예제 3.3.1

나선 \(\langle\cos t, \sin t, t\rangle\)의 한 바퀴(\(0 \le t \le 2\pi\)) 길이는?

풀이. 속력이 \(\sqrt2\)로 일정하므로 \(L = 2\pi\sqrt2\). 원기둥을 펼치면 나선은 밑변 \(2\pi\), 높이 \(2\pi\)인 직각삼각형의 빗변이 되므로 같은 답입니다.

3.3.2곡률

곡선이 얼마나 급히 휘는지는 "단위 길이를 갈 때 진행 방향 \(\mathbf T\)가 얼마나 빨리 바뀌는가"로 잽니다. 직선은 방향이 안 바뀌므로 0, 작은 원은 크게 바뀝니다.

정의 3.3.2 (곡률) \[\kappa = \left|\frac{d\mathbf T}{ds}\right| = \frac{|\mathbf T'(t)|}{|\mathbf r'(t)|}\quad(s\text{는 곡선의 길이}).\]

계산에는 다음 공식이 편리합니다.

정리 3.3.3 \[\kappa = \frac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|^3}, \qquad \text{평면곡선}\ y = f(x)\text{이면}\ \kappa = \frac{|f''(x)|}{(1 + f'(x)^2)^{3/2}}.\]
예제 3.3.4

(가) 반지름 \(a\)인 원 (나) 나선 \(\langle\cos t, \sin t, t\rangle\) (다) \(y = x^2\)의 원점에서 곡률을 구하여라.

풀이. (가) \(\mathbf r = \langle a\cos t, a\sin t, 0\rangle\), \(|\mathbf r'| = a\), \(\mathbf T = \langle-\sin t, \cos t, 0\rangle\), \(|\mathbf T'| = 1\). \(\kappa = \frac1a\). 작은 원일수록 많이 휩니다.

(나) \(\mathbf r' = \langle-\sin t, \cos t, 1\rangle\), \(\mathbf r'' = \langle-\cos t, -\sin t, 0\rangle\), \(\mathbf r'\times\mathbf r'' = \langle\sin t, -\cos t, 1\rangle\), 크기 \(\sqrt2\). \(\kappa = \frac{\sqrt2}{(\sqrt2)^3} = \frac12\).

(다) \(f' = 0\), \(f'' = 2\)이므로 \(\kappa = 2\). 원점 근처에서 반지름 \(\frac12\)인 원처럼 휩니다.

3.3.3가속도의 두 성분

\(\mathbf T\)가 바뀌는 방향의 단위벡터 \(\mathbf N = \frac{\mathbf T'}{|\mathbf T'|}\)를 주법선벡터라 합니다. 속력을 \(v\)라 하면 가속도는 다음처럼 나뉩니다.

\[\mathbf a = v'\,\mathbf T + \kappa v^2\,\mathbf N.\]

앞 항은 속력의 변화(가속 페달), 뒤 항은 방향의 변화(핸들)입니다. 같은 커브를 두 배 빠르게 돌면 옆으로 받는 가속도가 네 배가 되는 이유가 \(v^2\)에 있습니다. 원운동에서는 \(\kappa = \frac1r\)이므로 \(\frac{v^2}{r}\), 물리의 구심가속도입니다.

요약
  1. \(L = \int|\mathbf r'|\,dt\).
  2. \(\kappa = |\mathbf r'\times\mathbf r''|/|\mathbf r'|^3\). 원은 \(1/a\).
  3. \(\mathbf a = v'\mathbf T + \kappa v^2\mathbf N\).

3.3.4연습문제

기본

  1. \(\mathbf r(t) = \langle2t, t^2, \frac13t^3\rangle\), \(0 \le t \le 1\)의 길이는? (힌트: \(|\mathbf r'| = 2 + t^2\))
    답

    \(\int_0^1(2 + t^2)dt = \frac73\).

  2. 직선의 곡률은?
    답

    \(\mathbf T\)가 일정하므로 0.

응용

  1. \(y = \sin x\)의 \(x = \frac\pi2\)에서 곡률은?
    답

    \(f' = 0\), \(f'' = -1\). \(\kappa = 1\).

3.3.2

유도호의 길이 매개화와 곡률: 얼마나 빨리 방향을 바꾸는가

s로 다시 쓰기 · κ = |dT/ds| · 나선

다루는 성취기준 [공통2-03-03]

왜 호의 길이로 다시 쓰나

같은 곡선도 매개변수에 따라 빨리 또는 천천히 지나갑니다. "곡선이 얼마나 휘었나"는 지나가는 속도와 상관없는 곡선 자체의 성질이어야 합니다. 그래서 매개변수를 이동한 거리 \(s\)로 바꿔 속력을 늘 1로 만든 뒤 휨을 잽니다.

\(s(t) = \int_{t_0}^{t}|\mathbf r'(u)|\,du\) (공통1의 곡선 길이). \(\frac{ds}{dt} = |\mathbf r'(t)|\) (기본정리).

정의 · 곡률

\(\kappa = \left|\dfrac{d\mathbf T}{ds}\right|\): 단위 길이를 갈 때 단위접선이 회전하는 빠르기.

계산 공식 유도

  1. 연쇄 법칙: \(\dfrac{d\mathbf T}{dt} = \dfrac{d\mathbf T}{ds}\dfrac{ds}{dt}\)이므로 \(\kappa = \dfrac{|\mathbf T'(t)|}{|\mathbf r'(t)|}\).
    \(\frac{ds}{dt} = |\mathbf r'| > 0\).
  2. \(\mathbf r' = |\mathbf r'|\mathbf T\)를 미분: \(\mathbf r'' = |\mathbf r'|'\,\mathbf T + |\mathbf r'|\,\mathbf T'\).
    곱의 법칙.
  3. \(\mathbf r'\times\mathbf r'' = |\mathbf r'|^2(\mathbf T\times\mathbf T')\).
    \(\mathbf T\times\mathbf T = \mathbf 0\)이라 첫 항이 사라진다.
  4. \(|\mathbf T| = 1\)이므로 \(\mathbf T\perp\mathbf T'\) (앞 카드), 따라서 \(|\mathbf T\times\mathbf T'| = |\mathbf T'|\).
    수직이면 \(\sin 90° = 1\).
  5. \(|\mathbf r'\times\mathbf r''| = |\mathbf r'|^2|\mathbf T'| = |\mathbf r'|^3\kappa\), 곧 \(\kappa = \dfrac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|^3}\).
    1단계와 합침. \(\mathbf T\)를 구하지 않고 바로 계산할 수 있다.

평면곡선 \(y = f(x)\)이면 \(\mathbf r = (x, f(x), 0)\)으로 보고 \(\kappa = \dfrac{|f''|}{(1 + f'^2)^{3/2}}\).

나선 \(\mathbf r(t) = (a\cos t, a\sin t, bt)\) \((a > 0)\)를 호의 길이로 매개화하고 곡률을 구하세요.

풀이

  1. \(\mathbf r' = (-a\sin t, a\cos t, b)\), \(|\mathbf r'| = \sqrt{a^2 + b^2} =: c\).
    속력이 상수.
  2. \(s = ct\), \(t = \frac sc\). \(\mathbf r(s) = \left(a\cos\frac sc, a\sin\frac sc, \frac{bs}{c}\right)\).
    \(s(t) = \int_0^tc\,du\)를 \(t\)에 대해 풀었다.
  3. \(\mathbf r'' = (-a\cos t, -a\sin t, 0)\), \(\mathbf r'\times\mathbf r'' = (ab\sin t, -ab\cos t, a^2)\), 길이 \(a\sqrt{a^2 + b^2} = ac\).
    외적 성분: \((a\cos t\cdot0 - b(-a\sin t),\ b(-a\cos t) - (-a\sin t)\cdot0,\ a^2\sin^2t + a^2\cos^2t)\).
  4. \(\kappa = \dfrac{ac}{c^3} = \dfrac{a}{a^2 + b^2}\). 상수.
    공식.

검산

\(b = 0\)이면 반지름 \(a\)인 원이고 \(\kappa = \frac1a\). 원의 곡률이 반지름의 역수라는 사실과 맞습니다(곡률 반지름 = \(\frac1\kappa\)). \(b\)가 커지면 나선이 펴져 \(\kappa \to 0\), 직선에 가까워집니다.

흔한 오해

  • \(\kappa = |\mathbf T'(t)|\): \(t\)가 호의 길이가 아니면 \(|\mathbf r'|\)로 나눠야 합니다.
  • \(\kappa = |\mathbf r''|\): 속력이 1일 때만 맞습니다.
3.3.3

예제가속도를 접선 성분과 법선 성분으로 나누기

a = v′T + κv²N · TNB 틀

다루는 성취기준 [공통2-03-03]

무엇을 하는가

자동차가 굽은 길을 달릴 때 몸은 두 가지 힘을 느낍니다. 가속 페달을 밟아 빨라지는 느낌(진행 방향)과 커브에서 바깥으로 쏠리는 느낌(옆 방향)입니다. 가속도를 진행 방향 \(\mathbf T\)와 휘는 방향 \(\mathbf N\)으로 나누면 이 둘이 식으로 분리됩니다.

주법선 \(\mathbf N = \frac{\mathbf T'}{|\mathbf T'|}\) (곡선이 휘는 쪽), 종법선 \(\mathbf B = \mathbf T\times\mathbf N\). \(\{\mathbf T, \mathbf N, \mathbf B\}\)는 곡선을 따라 움직이는 직교 단위벡터 틀입니다.

정리

속력을 \(v = |\mathbf r'|\)라 하면 \(\mathbf a = v'\,\mathbf T + \kappa v^2\,\mathbf N\). 곧 \(a_T = v' = \dfrac{\mathbf r'\cdot\mathbf r''}{|\mathbf r'|}\), \(a_N = \kappa v^2 = \dfrac{|\mathbf r'\times\mathbf r''|}{|\mathbf r'|}\).

유도

  1. \(\mathbf v = v\mathbf T\). 미분: \(\mathbf a = v'\mathbf T + v\mathbf T'\).
    곱의 법칙.
  2. \(\mathbf T' = |\mathbf T'|\mathbf N = \kappa v\,\mathbf N\).
    \(\mathbf N\)의 정의와 앞 카드의 \(\kappa = \frac{|\mathbf T'|}{v}\).
  3. 따라서 \(\mathbf a = v'\mathbf T + \kappa v^2\mathbf N\). \(\mathbf B\) 성분은 없다.
    가속도는 늘 접촉평면(\(\mathbf T, \mathbf N\)이 만드는 평면) 안에 있다.
  4. \(\mathbf v\cdot\mathbf a = vv'\)이므로 \(a_T = \frac{\mathbf r'\cdot\mathbf r''}{v}\). \(\mathbf v\times\mathbf a = \kappa v^3\,\mathbf T\times\mathbf N\)이므로 \(a_N = \frac{|\mathbf r'\times\mathbf r''|}{v}\).
    \(\mathbf T\cdot\mathbf T = 1\), \(\mathbf T\cdot\mathbf N = 0\), \(\mathbf T\times\mathbf T = \mathbf 0\), \(|\mathbf T\times\mathbf N| = 1\).

\(\mathbf r(t) = (t, t^2, 0)\)를 따라 움직이는 점의 \(t = 1\)에서의 \(a_T\), \(a_N\)과 곡률을 구하세요. 또 반지름 50 m인 커브를 72 km/h로 도는 차의 법선 가속도를 구하세요.

풀이

  1. \(\mathbf r' = (1, 2t, 0)\), \(\mathbf r'' = (0, 2, 0)\). \(t = 1\): \(\mathbf r' = (1, 2, 0)\), \(v = \sqrt5\).
    성분별 미분.
  2. \(a_T = \frac{(1,2,0)\cdot(0,2,0)}{\sqrt5} = \frac{4}{\sqrt5}\).
    속력이 늘어나는 비율. 양수: 빨라지는 중.
  3. \(\mathbf r'\times\mathbf r'' = (0, 0, 2)\), \(a_N = \frac{2}{\sqrt5}\), \(\kappa = \frac{a_N}{v^2} = \frac{2}{5\sqrt5}\).
    \(a_N = \kappa v^2\). 공통1의 \(\frac{|f''|}{(1 + f'^2)^{3/2}} = \frac{2}{5^{3/2}}\)과 같다.
  4. 차: \(v = 20\) m/s, \(\kappa = \frac{1}{50}\). \(a_N = \frac{400}{50} = 8\ \text{m/s}^2 \approx 0.82g\).
    원운동의 구심가속도 \(\frac{v^2}{r}\)과 같다. 속력이 일정하면 \(a_T = 0\).

검산

\(a_T^2 + a_N^2 = \frac{16 + 4}{5} = 4 = |\mathbf r''|^2\). 두 성분은 수직이므로 피타고라스가 성립해야 합니다.

모형으로서의 뜻

도로 설계에서 \(a_N = \kappa v^2\)는 커브를 돌 때 필요한 옆 방향 힘(마찰과 경사)을 정합니다. 속력이 두 배이면 네 배의 힘이 필요합니다. 그래서 고속도로는 곡률을 작게(반지름을 크게) 하고, 직선에서 원으로 갈 때 곡률이 0에서 서서히 커지는 완화곡선(클로소이드)을 씁니다.
