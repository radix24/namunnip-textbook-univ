4.R.1

연습다변수 함수와 편미분 연습 문제

문제 8 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통2-04-01] [공통2-04-02] [공통2-04-04] [공통2-04-05]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 증명\(\displaystyle\lim_{(x,y)\to(0,0)}\frac{x^2 - y^2}{x^2 + y^2}\)이 존재하지 않음을 보이세요. [04-01]

    힌트 1

    \(x\)축과 \(y\)축을 따라가 보세요.

    힌트 2

    \(x\)축: \(\frac{x^2}{x^2}\), \(y\)축: \(\frac{-y^2}{y^2}\).

    풀이

    \(x\)축(\(y = 0\))에서 1, \(y\)축(\(x = 0\))에서 −1. 두 경로의 극한이 달라 존재하지 않습니다.

  2. 증명\(\displaystyle\lim_{(x,y)\to(0,0)}\frac{3x^2y^2}{x^2 + y^2}\)을 구하고 극좌표로 증명하세요. [04-01]

    힌트 1

    분자 차수 4, 분모 차수 2.

    힌트 2

    \(\frac{3r^4\cos^2\theta\sin^2\theta}{r^2}\).

    풀이

    \(|f| = 3r^2\cos^2\theta\sin^2\theta \le 3r^2 \to 0\). 압축 정리로 극한 0. ε-δ로 쓰면 \(\delta = \sqrt{\varepsilon/3}\).

  3. 계산\(f(x,y) = e^{x}\cos y\)의 점 \((0, 0)\)에서 접평면을 구하고, \(f(0.1, -0.1)\)을 근사하세요. [04-02]

    힌트 1

    \(f_x = e^x\cos y\), \(f_y = -e^x\sin y\).

    힌트 2

    \((0,0)\)에서 \(f = 1\), \(f_x = 1\), \(f_y = 0\).

    풀이

    접평면 \(z = 1 + x\). \(f(0.1, -0.1) \approx 1.1\). 참값 \(e^{0.1}\cos0.1 \approx 1.10517\times0.99500 \approx 1.0996\).

  4. 계산직육면체의 가로, 세로, 높이가 각각 매초 1 cm, 2 cm 늘고 3 cm 줄어듭니다. 크기가 \(x = 10\), \(y = 20\), \(z = 30\) cm인 순간 부피와 대각선 길이의 변화율을 구하세요. [04-04]

    힌트 1

    \(V = xyz\), \(\frac{dV}{dt} = V_x\dot x + V_y\dot y + V_z\dot z\).

    힌트 2

    대각선 \(D = \sqrt{x^2 + y^2 + z^2}\), \(\dot D = \frac{x\dot x + y\dot y + z\dot z}{D}\).

    풀이

    \(\dot V = yz\dot x + xz\dot y + xy\dot z = 600 + 600 - 600 = 600\ \text{cm}^3/\text{s}\).

    \(D = \sqrt{1400} = 10\sqrt{14}\), \(\dot D = \frac{10 + 40 - 90}{10\sqrt{14}} = -\frac{4}{\sqrt{14}} \approx -1.07\) cm/s.

  5. 증명\(u = f(x - y, y - z, z - x)\)이면 \(u_x + u_y + u_z = 0\)임을 보이세요(\(f\)는 미분가능). [04-04]

    힌트 1

    \(p = x - y\), \(q = y - z\), \(r = z - x\)로 두고 나무 그림.

    힌트 2

    \(u_x = f_p\cdot1 + f_q\cdot0 + f_r\cdot(-1)\).

    풀이

    \(u_x = f_p - f_r\), \(u_y = -f_p + f_q\), \(u_z = -f_q + f_r\). 더하면 0. 뜻: \(x, y, z\)를 모두 같은 양만큼 늘리면 \(p, q, r\)이 그대로라 \(u\)가 변하지 않습니다. \((1,1,1)\) 방향의 방향도함수가 0이라는 말과 같습니다.

  6. 계산온도가 \(T(x,y,z) = 200e^{-x^2 - 3y^2 - 9z^2}\)인 공간에서 점 \((2, -1, 2)\)에 있는 사람이 가장 빨리 따뜻해지려면 어느 방향으로 가야 하나요? 그 방향의 증가율은? [04-05]

    힌트 1

    \(\nabla T = T\cdot(-2x, -6y, -18z)\).

    힌트 2

    방향은 \((-4, 6, -36)\)에 평행.

    풀이

    \(\nabla T(2,-1,2) = 200e^{-43}(-4, 6, -36)\). 방향 \(\frac{(-2, 3, -18)}{\sqrt{337}}\). 증가율 \(|\nabla T| = 200e^{-43}\sqrt{16 + 36 + 1296} = 200e^{-43}\sqrt{1348} = 400\sqrt{337}\,e^{-43}\).

    \(z\) 성분이 가장 큰 것은 \(z\) 방향으로 온도가 가장 빨리 변하기 때문입니다(계수 9).

  7. 개념\(f(x, y) = \frac{xy}{x^2+y^2}\) (\(f(0,0) = 0\))은 원점에서 \(f_x = f_y = 0\)인데 연속도 아닙니다. 이 예가 "편도함수가 있으면 미분가능하다"가 틀렸음을 어떻게 보여 주나요? [04-02]

    힌트 1

    04-02 절: 미분가능하면 연속입니다.

    힌트 2

    편도함수는 축 방향 두 개만 봅니다.

    풀이

    미분가능하면 연속이어야 하는데 이 함수는 연속이 아니므로 미분가능하지 않습니다. 그런데 편도함수는 존재합니다. 편도함수는 축 위(\(f = 0\))만 보고, 대각선 방향에서 값이 \(\frac12\)인 것을 보지 못하기 때문입니다. 미분가능성은 모든 방향을 한꺼번에 근사하는 접평면의 존재입니다.

  8. 판단한 학생이 \(f = x^2 + y^2\)의 점 \((1, 1)\)에서 방향 \((3, 4)\)의 방향도함수를 \(\nabla f\cdot(3, 4) = (2, 2)\cdot(3, 4) = 14\)라고 했습니다. 이 값이 말이 안 되는 이유와 바른 값을 쓰세요. [04-05]

    힌트 1

    04-05 절: 방향도함수의 최댓값은 \(|\nabla f|\)입니다.

    힌트 2

    \(|\nabla f| = 2\sqrt2 \approx 2.83\).

    풀이

    어떤 방향의 방향도함수도 \(|\nabla f| \approx 2.83\)을 넘을 수 없는데 14는 그보다 큽니다. 방향을 단위벡터 \(\frac{(3,4)}{5}\)로 바꾸지 않았습니다. 바른 값 \(\frac{14}{5} = 2.8\). 최댓값에 가까운 이유는 \((3,4)\)가 \(\nabla f = (2,2)\)와 거의 같은 방향이기 때문입니다.
