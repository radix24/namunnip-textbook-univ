이 단원(2단원)은 요람 개요의 "선형벡터 공간"에 해당하며 2026학년도 진도표에는 없습니다. 공통8(고등미적분학)의 연립미분방정식과 2학년 전공의 선형대수를 읽기 위한 다리로 둡니다.

2.1.1일차결합

벡터 \(\mathbf v_1, \dots, \mathbf v_k\)에 실수를 곱해 더한 \(c_1\mathbf v_1 + \cdots + c_k\mathbf v_k\)를 일차결합이라 합니다. 예를 들어 평면의 모든 벡터는 \(\langle a, b\rangle = a\mathbf i + b\mathbf j\)로 \(\mathbf i, \mathbf j\)의 일차결합입니다.

2.1.2일차독립

정의 2.1.1 (일차독립, 일차종속)

\(c_1\mathbf v_1 + \cdots + c_k\mathbf v_k = \mathbf 0\)이 되는 경우가 \(c_1 = \cdots = c_k = 0\)뿐이면 일차독립, 그렇지 않으면 일차종속이라 한다.

일차종속이면 계수 하나가 0이 아니므로, 그 벡터를 나머지의 일차결합으로 쓸 수 있습니다. 곧 "쓸모없는 벡터가 끼어 있다"는 뜻입니다. 일차독립은 어느 벡터도 다른 벡터들로 만들어지지 않는다는 뜻입니다.

  • 두 벡터: 일차종속 ⟺ 평행 (한쪽이 다른 쪽의 실수배).
  • 공간의 세 벡터: 일차종속 ⟺ 한 평면 위에 있음 ⟺ 행렬식 = 0 (1.4절).
예제 2.1.2

다음 벡터들이 일차독립인지 판정하여라.

(가) \(\langle1, 2\rangle, \langle2, 4\rangle\) (나) \(\langle1, 0, 1\rangle, \langle0, 1, 1\rangle, \langle1, 1, 0\rangle\) (다) \(\langle1, 2, 3\rangle, \langle4, 5, 6\rangle, \langle7, 8, 9\rangle\)

풀이. (가) 둘째가 첫째의 2배이므로 종속. (나) 행렬식 \(1(0 - 1) - 0 + 1(0 - 1) = -2 \ne 0\)이므로 독립. (다) 행렬식이 0이므로 종속. 실제로 \(\mathbf v_1 - 2\mathbf v_2 + \mathbf v_3 = \mathbf 0\)입니다.

정의를 직접 쓰는 방법도 알아 둡니다. (나)에서 \(c_1\langle1, 0, 1\rangle + c_2\langle0, 1, 1\rangle + c_3\langle1, 1, 0\rangle = \mathbf 0\)이면 \(c_1 + c_3 = 0\), \(c_2 + c_3 = 0\), \(c_1 + c_2 = 0\)입니다. 셋을 더하면 \(c_1 + c_2 + c_3 = 0\)이고, 여기서 각 식을 빼면 \(c_1 = c_2 = c_3 = 0\)입니다.

공간에서 네 개 이상의 벡터는 언제나 일차종속입니다. 공간의 "방향의 자유도"가 3이기 때문입니다(2.2절의 차원).

요약
  1. 일차독립: \(\sum c_j\mathbf v_j = \mathbf 0\)이면 모든 \(c_j = 0\).
  2. 정사각 배열이면 행렬식 ≠ 0 ⟺ 일차독립.

2.1.3연습문제

기본

  1. \(\langle1, 1\rangle, \langle1, -1\rangle\)은 일차독립인가?
    답

    행렬식 \(-1 - 1 = -2 \ne 0\). 독립.

  2. \(\langle1, 2, 3\rangle, \langle2, 4, 6\rangle\)은?
    답

    둘째가 첫째의 2배. 종속.

응용

  1. \(\langle1, 0, 0\rangle, \langle1, 1, 0\rangle, \langle1, 1, k\rangle\)이 일차종속이 되는 \(k\)는?
    답

    행렬식 \(= k = 0\). \(k = 0\).

2.1.2

예제일차독립: 쓸모없는 벡터가 하나도 없는가

정의 · 연립방정식 · 행렬식 판정

다루는 성취기준 [공통2-02-01]

정의

벡터 \(\mathbf v_1, \dots, \mathbf v_k\)에 대해 \(c_1\mathbf v_1 + \dots + c_k\mathbf v_k = \mathbf 0\)을 만족하는 계수가 \(c_1 = \dots = c_k = 0\)뿐이면 일차독립, 0이 아닌 계수가 있으면 일차종속이다.

정의를 풀어 읽기

  1. 종속이면0이 아닌 \(c_j\)가 있으므로 그 식을 \(c_j\)로 나누면 \(\mathbf v_j\)를 나머지의 일차결합으로 쓸 수 있습니다. 곧 \(\mathbf v_j\)는 "새로운 방향을 보태지 않는" 벡터입니다.
  2. 독립이면어느 것도 나머지로 만들 수 없습니다. 같은 벡터를 일차결합으로 쓰는 방법이 하나뿐이라는 뜻도 됩니다(두 표현의 차가 0의 표현이므로).
  3. 기하\(\mathbb R^3\)에서 두 벡터가 종속 ⇔ 한 직선 위. 세 벡터가 종속 ⇔ 한 평면 위. 네 벡터는 늘 종속.

판정 방법

  • 연립방정식: \(c_1\mathbf v_1 + \dots + c_k\mathbf v_k = \mathbf 0\)을 성분별로 쓰고 가우스 소거. 자유변수가 있으면 종속.
  • 행렬식 (\(n\)개의 벡터, \(\mathbb R^n\)): 벡터를 행으로 쌓은 행렬식이 0이 아니면 독립, 0이면 종속(1-04 카드의 부피 해석).

(가) \((1, 2, 3)\), \((2, 4, 6)\), \((0, 1, 1)\) (나) \((1, 0, 1)\), \((1, 1, 0)\), \((0, 1, 1)\) (다) \((1, 2, 0, 1)\), \((0, 1, 1, 0)\), \((1, 3, 1, 2)\)의 일차독립 여부를 판정하세요.

풀이

  1. (가) \((2, 4, 6) = 2(1, 2, 3)\)이므로 \(2\mathbf v_1 - \mathbf v_2 + 0\mathbf v_3 = \mathbf 0\). 종속.
    0이 아닌 계수 하나를 찾으면 끝. 셋째 벡터와는 상관없다.
  2. (나) \(\begin{vmatrix}1&0&1\\1&1&0\\0&1&1\end{vmatrix} = 1(1\cdot1 - 0\cdot1) - 0(1\cdot1 - 0\cdot0) + 1(1\cdot1 - 1\cdot0) = 1 + 1 = 2 \ne 0\). 독립.
    첫 행을 따라 전개. 2×2 소행렬식을 하나씩 따로 적으면 부호 실수가 준다.
  3. (다) \(\mathbb R^4\)의 벡터 3개라 정사각행렬이 아니다. 연립: \(c_1 + c_3 = 0\), \(2c_1 + c_2 + 3c_3 = 0\), \(c_2 + c_3 = 0\), \(c_1 + 2c_3 = 0\).
    성분 네 개에서 방정식 네 개.
  4. 첫째와 넷째에서 \(c_3 = 0\), \(c_1 = 0\). 셋째에서 \(c_2 = 0\). 독립.
    자명한 해뿐.

의미

일차독립은 "군더더기가 없다"는 뜻이고, 판정은 결국 연립방정식 \(c_1\mathbf v_1 + \dots = \mathbf 0\)에 자명하지 않은 해가 있는지입니다. 독립인 벡터의 최대 개수가 다음 절의 차원이 됩니다.

검산

(나)에서 세 벡터의 합은 \((2, 2, 2)\)이고, 어느 하나도 나머지 둘의 평면에 있지 않습니다. 예를 들어 \((0,1,1) = a(1,0,1) + b(1,1,0)\)이면 첫 성분 \(a + b = 0\), 둘째 \(b = 1\), 셋째 \(a = 1\)로 모순입니다.

흔한 오해

  • "두 개씩 평행하지 않으면 독립." \((1,0,0), (0,1,0), (1,1,0)\)은 어느 둘도 평행하지 않지만 한 평면 위라 종속입니다.
  • 영벡터: 영벡터가 들어 있으면 늘 종속입니다(그 계수를 1로).
