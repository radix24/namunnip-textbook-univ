6.4.1삼중적분

입체 \(E\)를 작은 상자로 나누고 \(f\times\)(상자 부피)를 더한 극한이 삼중적분 \(\iiint_Ef\,dV\)입니다. 4차원 그림은 그릴 수 없으므로, \(f\)를 밀도로 생각하면 이해가 쉽습니다. 밀도를 부피에 대해 적분하면 질량입니다. \(f = 1\)이면 \(E\)의 부피입니다.

계산은 한 변수씩 차례로 합니다. 상자 \([a, b]\times[c, d]\times[r, s]\)이면 범위가 상수이고, 일반 입체는 6.2절처럼 바깥 변수에 따라 안쪽 범위를 정합니다.

예제 6.4.1

상자 \(B = [0, 1]\times[-1, 2]\times[0, 3]\)에서 \(\iiint_Bxyz^2\,dV\)를 구하여라.

풀이. 변수가 나뉘므로 \(\int_0^1x\,dx\cdot\int_{-1}^2y\,dy\cdot\int_0^3z^2\,dz = \frac12\cdot\frac32\cdot9 = \frac{27}{4}\).

예제 6.4.2

좌표평면들과 평면 \(x + y + z = 1\)로 둘러싸인 사면체의 부피를 구하여라.

풀이. 바닥은 삼각형 \(x \ge 0\), \(y \ge 0\), \(x + y \le 1\)이고 높이는 \(0 \le z \le 1 - x - y\).

\[\int_0^1\int_0^{1-x}(1 - x - y)\,dy\,dx = \int_0^1\frac{(1 - x)^2}{2}dx = \frac16.\]

밑넓이 \(\frac12\), 높이 1인 뿔의 부피 \(\frac13\cdot\frac12\cdot1\)과 같습니다.

6.4.2질량과 질량중심

밀도가 \(\rho(x, y, z)\)인 물체에서

  • 질량: \(m = \iiint_E\rho\,dV\).
  • 질량중심: \(\bar x = \frac1m\iiint_Ex\rho\,dV\), \(\bar y\), \(\bar z\)도 같은 방법.
  • \(z\)축에 대한 관성 모멘트: \(I_z = \iiint_E(x^2 + y^2)\rho\,dV\).

질량중심은 위치를 질량으로 가중평균한 것입니다. 관성 모멘트는 회전시키기 어려운 정도로, 물리(공통3)의 강체 회전에서 씁니다.

예제 6.4.3

단위정육면체 \([0, 1]^3\)의 밀도가 \(\rho = x + y + z\)일 때 질량과 \(\bar x\)를 구하여라.

풀이. \(m = \iiint(x + y + z)\,dV = \frac12 + \frac12 + \frac12 = \frac32\). \(\iiint x(x + y + z)\,dV = \frac13 + \frac14 + \frac14 = \frac56\). \(\bar x = \frac{5/6}{3/2} = \frac59\). 밀도가 큰 쪽(꼭짓점 \((1, 1, 1)\) 쪽)으로 중심 \(\frac12\)에서 조금 옮겨졌습니다.

요약
  1. 삼중적분은 한 변수씩 차례로. 범위는 입체를 그려 정한다.
  2. 질량 \(\iiint\rho\), 질량중심 \(\frac1m\iiint x\rho\), 관성 모멘트 \(\iiint(x^2 + y^2)\rho\).

6.4.3연습문제

기본

  1. \(\int_0^1\int_0^1\int_0^1(x + y + z)\,dz\,dy\,dx\)는?
    답

    \(\frac32\).

응용

  1. 예제 6.4.2의 사면체(밀도 1)의 질량중심 \(\bar z\)는? (힌트: \(\iiint z\,dV = \frac{1}{24}\))
    답

    \(\frac{1/24}{1/6} = \frac14\). 대칭으로 \(\bar x = \bar y = \frac14\).

6.4.2

예제중적분으로 질량, 질량 중심, 관성 모멘트 구하기

밀도 × 부피 요소 · 모형 세우기

다루는 성취기준 [공통2-06-04]

식 세우기

공통1 7-03 카드와 같은 원리입니다. 작은 조각의 질량 \(dm = \delta\,dV\) (\(\delta\): 밀도)를 구하고, 조각마다 알고 싶은 양을 곱해 더합니다.

양조각의 기여적분
질량\(dm\)\(M = \iiint\delta\,dV\)
질량 중심\(z\,dm\) (모멘트)\(\bar z = \frac1M\iiint z\,\delta\,dV\)
관성 모멘트(\(z\)축)\((\text{축까지 거리})^2dm\)\(I_z = \iiint(x^2 + y^2)\,\delta\,dV\)

관성 모멘트는 회전시키기 어려운 정도입니다. 회전 운동에너지가 \(\frac12I\omega^2\)이고, 각 조각의 속력이 \(r\omega\)라 \(\frac12(r\omega)^2dm\)을 더하면 \(r^2\)이 들어갑니다.

밀도가 일정한(\(\delta\)) 반지름 \(a\)인 반구 \(x^2 + y^2 + z^2 \le a^2\), \(z \ge 0\)의 (가) 질량 중심 (나) \(z\)축에 대한 관성 모멘트를 질량 \(M\)으로 나타내세요.

풀이

  1. 대칭으로 \(\bar x = \bar y = 0\). \(M = \delta\cdot\frac23\pi a^3\).
    \(z\)축 둘레로 대칭이면 질량 중심은 축 위. 공 부피의 절반.
  2. 구면좌표: \(0 \le \rho \le a\), \(0 \le \varphi \le \frac\pi2\), \(0 \le \theta \le 2\pi\). \(z = \rho\cos\varphi\).
    반구는 \(\varphi\)를 \(\frac\pi2\)까지만.
  3. \(\iiint z\,dV = \int_0^{2\pi}\int_0^{\pi/2}\int_0^a\rho\cos\varphi\cdot\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\cdot\frac12\cdot\frac{a^4}{4} = \frac{\pi a^4}{4}\).
    \(\int_0^{\pi/2}\sin\varphi\cos\varphi\,d\varphi = \frac12\).
  4. (가) \(\bar z = \frac{\delta\pi a^4/4}{\delta\cdot2\pi a^3/3} = \frac{3a}{8}\).
    \(\delta\)는 약분: 균일하면 밀도와 상관없다.
  5. \(x^2 + y^2 = \rho^2\sin^2\varphi\). \(\iiint(x^2 + y^2)\,dV = 2\pi\int_0^{\pi/2}\sin^3\varphi\,d\varphi\int_0^a\rho^4d\rho = 2\pi\cdot\frac23\cdot\frac{a^5}{5} = \frac{4\pi a^5}{15}\).
    \(\int_0^{\pi/2}\sin^3\varphi\,d\varphi = \int_0^1(1 - u^2)du = \frac23\) (\(u = \cos\varphi\)).
  6. (나) \(I_z = \delta\frac{4\pi a^5}{15} = \frac{2}{5}Ma^2\).
    \(\delta = \frac{3M}{2\pi a^3}\)을 대입.

의미

관성 모멘트는 질량이 축에서 얼마나 멀리 퍼져 있는지를 잽니다. 같은 질량과 반지름이라도 속이 찬 공(\(\frac25Ma^2\))과 속이 빈 공(\(\frac23Ma^2\))이 다르고, 이 차이 때문에 빗면에서 구르는 속도가 다릅니다(공통3 5-03 카드).

검산

(가) \(0 < \frac38a < \frac a2\): 아래쪽이 넓으니 중심이 높이의 절반보다 아래인 것이 맞습니다. (나) 꽉 찬 공의 \(I = \frac25Ma^2\)는 물리에서 잘 알려진 값이고, 반구는 공을 반으로 자른 것이라 질량과 관성 모멘트가 모두 절반이 되어 같은 식이 됩니다.

흔한 오해

  • 관성 모멘트에서 \(\rho^2\) 사용: \(z\)축까지의 거리는 \(\sqrt{x^2 + y^2} = \rho\sin\varphi\)이지 \(\rho\)가 아닙니다.
