6.4.1

예제중적분으로 질량, 질량 중심, 관성 모멘트 구하기

밀도 × 부피 요소 · 모형 세우기

다루는 성취기준 [공통2-06-04]

식 세우기

공통1 7-03 카드와 같은 원리입니다. 작은 조각의 질량 \(dm = \delta\,dV\) (\(\delta\): 밀도)를 구하고, 조각마다 알고 싶은 양을 곱해 더합니다.

양조각의 기여적분
질량\(dm\)\(M = \iiint\delta\,dV\)
질량 중심\(z\,dm\) (모멘트)\(\bar z = \frac1M\iiint z\,\delta\,dV\)
관성 모멘트(\(z\)축)\((\text{축까지 거리})^2dm\)\(I_z = \iiint(x^2 + y^2)\,\delta\,dV\)

관성 모멘트는 회전시키기 어려운 정도입니다. 회전 운동에너지가 \(\frac12I\omega^2\)이고, 각 조각의 속력이 \(r\omega\)라 \(\frac12(r\omega)^2dm\)을 더하면 \(r^2\)이 들어갑니다.

밀도가 일정한(\(\delta\)) 반지름 \(a\)인 반구 \(x^2 + y^2 + z^2 \le a^2\), \(z \ge 0\)의 (가) 질량 중심 (나) \(z\)축에 대한 관성 모멘트를 질량 \(M\)으로 나타내세요.

풀이

  1. 대칭으로 \(\bar x = \bar y = 0\). \(M = \delta\cdot\frac23\pi a^3\).
    \(z\)축 둘레로 대칭이면 질량 중심은 축 위. 공 부피의 절반.
  2. 구면좌표: \(0 \le \rho \le a\), \(0 \le \varphi \le \frac\pi2\), \(0 \le \theta \le 2\pi\). \(z = \rho\cos\varphi\).
    반구는 \(\varphi\)를 \(\frac\pi2\)까지만.
  3. \(\iiint z\,dV = \int_0^{2\pi}\int_0^{\pi/2}\int_0^a\rho\cos\varphi\cdot\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta = 2\pi\cdot\frac12\cdot\frac{a^4}{4} = \frac{\pi a^4}{4}\).
    \(\int_0^{\pi/2}\sin\varphi\cos\varphi\,d\varphi = \frac12\).
  4. (가) \(\bar z = \frac{\delta\pi a^4/4}{\delta\cdot2\pi a^3/3} = \frac{3a}{8}\).
    \(\delta\)는 약분: 균일하면 밀도와 상관없다.
  5. \(x^2 + y^2 = \rho^2\sin^2\varphi\). \(\iiint(x^2 + y^2)\,dV = 2\pi\int_0^{\pi/2}\sin^3\varphi\,d\varphi\int_0^a\rho^4d\rho = 2\pi\cdot\frac23\cdot\frac{a^5}{5} = \frac{4\pi a^5}{15}\).
    \(\int_0^{\pi/2}\sin^3\varphi\,d\varphi = \int_0^1(1 - u^2)du = \frac23\) (\(u = \cos\varphi\)).
  6. (나) \(I_z = \delta\frac{4\pi a^5}{15} = \frac{2}{5}Ma^2\).
    \(\delta = \frac{3M}{2\pi a^3}\)을 대입.

검산

(가) \(0 < \frac38a < \frac a2\): 아래쪽이 넓으니 중심이 높이의 절반보다 아래인 것이 맞습니다. (나) 꽉 찬 공의 \(I = \frac25Ma^2\)는 물리에서 잘 알려진 값이고, 반구는 공을 반으로 자른 것이라 질량과 관성 모멘트가 모두 절반이 되어 같은 식이 됩니다.

흔한 오해

  • 관성 모멘트에서 \(\rho^2\) 사용: \(z\)축까지의 거리는 \(\sqrt{x^2 + y^2} = \rho\sin\varphi\)이지 \(\rho\)가 아닙니다.
