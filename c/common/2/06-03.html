먼저 알아야 할 것

6.3.1넓이 요소 \(r\,dr\,d\theta\)

원판, 고리, 부채꼴 같은 영역은 극좌표 \(x = r\cos\theta\), \(y = r\sin\theta\)로 나타내면 범위가 상수가 되어 간단합니다. 이때 작은 조각의 넓이가 \(dr\,d\theta\)가 아니라는 점에 주의합니다. 반지름이 \(r\)에서 \(r + dr\), 각이 \(\theta\)에서 \(\theta + d\theta\)인 조각은 거의 직사각형이고, 가로가 \(dr\), 세로(호의 길이)가 \(r\,d\theta\)입니다. 바깥쪽 조각일수록 넓습니다.

정리 6.3.1 \[\iint_Df(x, y)\,dA = \int_\alpha^\beta\int_a^bf(r\cos\theta, r\sin\theta)\,r\,dr\,d\theta.\]
예제 6.3.2

포물면 \(z = 1 - x^2 - y^2\)과 \(xy\)평면으로 둘러싸인 입체의 부피를 구하여라.

풀이. \(z = 0\)이면 \(x^2 + y^2 = 1\)이므로 밑면은 단위원판, 높이는 \(1 - r^2\).

\[\int_0^{2\pi}\int_0^1(1 - r^2)\,r\,dr\,d\theta = 2\pi\left(\frac12 - \frac14\right) = \frac\pi2.\]

직교좌표로 하면 \(\int_{-1}^1\int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}\)처럼 범위가 복잡해집니다.

6.3.2가우스 적분

예제 6.3.3

\(\displaystyle\int_{-\infty}^\infty e^{-x^2}dx = \sqrt\pi\)임을 보여라.

풀이. \(e^{-x^2}\)의 부정적분은 기본 함수로 쓸 수 없습니다. 대신 이 적분을 \(I\)라 하고 제곱하면 이중적분이 됩니다.

\[I^2 = \int_{-\infty}^\infty e^{-x^2}dx\int_{-\infty}^\infty e^{-y^2}dy = \iint_{\mathbb R^2}e^{-(x^2+y^2)}dA.\]

반지름 \(a\)인 원판에서 극좌표로 계산하면 \(\int_0^{2\pi}\int_0^ae^{-r^2}r\,dr\,d\theta = \pi(1 - e^{-a^2})\)이고 (\(r\)이 붙어서 치환이 됩니다), \(a \to \infty\)이면 \(\pi\). 따라서 \(I^2 = \pi\), \(I = \sqrt\pi\).

이 값은 통계학의 정규분포 밀도함수에 \(\frac{1}{\sqrt{2\pi}}\)이 붙는 이유입니다(공통7). 극좌표의 \(r\) 덕분에 계산할 수 없던 적분이 풀렸습니다.

요약
  1. \(dA = r\,dr\,d\theta\). \(r\)을 빠뜨리지 않는다.
  2. 원 모양 영역, \(x^2 + y^2\)이 들어간 함수는 극좌표로.

6.3.3연습문제

기본

  1. 반지름 \(a\)인 원의 넓이를 극좌표 이중적분으로 구하여라.
    답

    \(\int_0^{2\pi}\int_0^ar\,dr\,d\theta = \pi a^2\).

  2. 고리 \(1 \le x^2 + y^2 \le 4\)에서 \(\iint(x^2 + y^2)\,dA\)는?
    답

    \(2\pi\int_1^2r^3dr = 2\pi\cdot\frac{15}{4} = \frac{15\pi}{2}\).

6.3.2

실습원 모양 영역은 왜 극좌표로 자르면 쉬울까?

실습 · 극좌표 이중적분

다루는 성취기준 [공통2-06-03]

목표

원판 위에서 \(\iint e^{-(x^2 + y^2)}\,dA\)를 두 가지로 어림합니다. 정사각형 조각으로 자르면 원의 둘레에서 조각이 삐져나오거나 모자라고, 극좌표 조각(부채꼴 고리)으로 자르면 원에 꼭 맞습니다. 조각의 넓이가 \(r\,\Delta r\,\Delta\theta\)인 이유도 그림으로 확인합니다. 성취기준 [공통2-06-03].

준비

  • 색이 진할수록 함숫값 \(e^{-(x^2+y^2)}\)이 큽니다. 주황 원이 적분 영역의 경계입니다.
  • 극좌표 조각은 반지름 방향으로 \(n\)개, 각 방향으로 \(4n\)개입니다. 바깥 조각일수록 넓은 것을 눈으로 확인하세요. 조각 하나의 넓이는 약 \(r_i\,\Delta r\,\Delta\theta\)입니다.
  • 정확한 값: \(\displaystyle\int_0^{2\pi}\!\!\int_0^R e^{-r^2}\,r\,dr\,d\theta = \pi(1 - e^{-R^2})\).

절차

  1. \(R = 2\)에서 극좌표 조각 \(n = 2, 4, 10\)의 합을 기록합니다.
  2. 정사각형 조각으로 바꿔 \(n = 4, 10, 40\)의 합을 기록합니다.
  3. \(R = 3\)으로 늘려 결과가 \(\pi\)에 얼마나 가까운지 봅니다.

기대 결과

  • \(R = 2\)의 정확한 값은 \(\pi(1 - e^{-4}) = 3.08405\)입니다. 극좌표 조각은 \(n = 2, 4, 10\)에서 3.44004, 3.16061, 3.09593으로 한쪽에서 차근차근 다가갑니다.
  • 정사각형 조각은 \(n = 4, 10, 40\)에서 3.08280, 3.08907, 3.08541입니다. 원 둘레에 걸친 조각을 넣었다 뺐다 하므로 오차가 들쭉날쭉합니다.
  • \(R = 3\)이면 정확한 값은 3.14120으로 \(\pi\)와 0.0004밖에 다르지 않습니다. \(R \to \infty\)이면 \(\iint_{\mathbb R^2} e^{-(x^2+y^2)}dA = \pi\)입니다.

분석

  1. 극좌표 조각의 넓이가 \(\Delta r\,\Delta\theta\)가 아니라 \(r\,\Delta r\,\Delta\theta\)인 이유를 그림의 바깥 조각과 안쪽 조각을 비교해 설명해 보세요.
  2. \(\iint_{\mathbb R^2} e^{-(x^2+y^2)}dA = \left(\int_{-\infty}^\infty e^{-x^2}dx\right)^2\)임을 이용하면 \(\int_{-\infty}^\infty e^{-x^2}dx\)는 얼마인가요? 이 값이 정규분포(공통7 5.2절)의 \(\sqrt{2\pi}\)가 나오는 곳입니다.

더 해 보기

일반적인 변수변환에서는 \(r\) 대신 야코비안(6.6절)이 조각의 넓이 비율을 알려 줍니다. 구면좌표의 \(\rho^2\sin\phi\)도 같은 생각입니다.
