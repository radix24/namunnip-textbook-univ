5.1.1임계점

\(f(a, b)\)가 근처의 모든 값보다 크거나 같으면 극댓값, 작거나 같으면 극솟값입니다. 산꼭대기와 골짜기 바닥에 해당합니다. 그런 점에서는 동서 방향으로도 남북 방향으로도 평평하므로

정리 5.1.1

\(f\)가 \((a, b)\)에서 극값을 갖고 편도함수가 있으면 \(f_x(a, b) = f_y(a, b) = 0\), 곧 \(\nabla f = \mathbf 0\)이다.

\(\nabla f = \mathbf 0\)인 점(또는 편도함수가 없는 점)을 임계점이라 합니다. 접평면이 수평인 점입니다. 그러나 임계점이 모두 극값은 아닙니다. 말안장 \(z = y^2 - x^2\)의 원점은 \(y\) 방향으로는 가장 낮고 \(x\) 방향으로는 가장 높습니다. 이런 점을 안장점이라 합니다.

5.1.2이계도함수 판정법

정리 5.1.2 (이계도함수 판정법)

\(\nabla f(a, b) = \mathbf 0\)이고 \(D = f_{xx}f_{yy} - f_{xy}^2\)을 그 점에서 계산할 때

  1. \(D > 0\), \(f_{xx} > 0\): 극소.
  2. \(D > 0\), \(f_{xx} < 0\): 극대.
  3. \(D < 0\): 안장점.
  4. \(D = 0\): 이 방법으로는 알 수 없다.

왜 이런 모양인가: 임계점 근처에서 \(f\)는 대략 \(\frac12(Ah^2 + 2Bhk + Ck^2)\) (\(A = f_{xx}\), \(B = f_{xy}\), \(C = f_{yy}\))만큼 변합니다. 이 이차식은 \(AC - B^2 > 0\)이면 부호가 \(A\)와 늘 같고(그릇 모양), \(AC - B^2 < 0\)이면 방향에 따라 부호가 바뀝니다(말안장). 고교에서 이차방정식의 판별식으로 이차식의 부호를 판정하던 것과 같은 원리입니다.

예제 5.1.3

\(f(x, y) = x^4 + y^4 - 4xy + 1\)의 극값과 안장점을 구하여라.

풀이. \(f_x = 4x^3 - 4y = 0\), \(f_y = 4y^3 - 4x = 0\). 첫 식에서 \(y = x^3\), 둘째에 넣으면 \(x^9 = x\), \(x(x^8 - 1) = 0\), \(x = 0, \pm1\). 임계점 \((0, 0)\), \((1, 1)\), \((-1, -1)\).

\(f_{xx} = 12x^2\), \(f_{yy} = 12y^2\), \(f_{xy} = -4\), \(D = 144x^2y^2 - 16\).

  • \((0, 0)\): \(D = -16 < 0\). 안장점.
  • \((\pm1, \pm1)\): \(D = 128 > 0\), \(f_{xx} = 12 > 0\). 극소, 극솟값 \(f = -1\).
요약
  1. 극값은 임계점(\(\nabla f = \mathbf 0\))에서만 생긴다.
  2. \(D = f_{xx}f_{yy} - f_{xy}^2\): 양수면 극값(\(f_{xx}\) 부호로 극대/극소), 음수면 안장점.

5.1.3연습문제

기본

  1. \(f = x^2 + y^2 - 2x - 6y + 14\)의 극값은?
    답

    임계점 \((1, 3)\), \(D = 4 > 0\), \(f_{xx} = 2 > 0\). 극솟값 4.

  2. \(f = xy\)의 원점은 어떤 점인가?
    답

    \(D = 0 - 1 < 0\). 안장점.

심화

  1. \(f = x^4 + y^4\)과 \(g = x^4 - y^4\)의 원점에서 \(D\)를 구하고, 판정법이 왜 쓸모없는지 설명하여라.
    답

    둘 다 \(D = 0\). 그러나 \(f\)는 극소, \(g\)는 안장점이다. \(D = 0\)이면 다른 방법으로 판단해야 한다.

5.1.2

예제극대, 극소, 안장점: 이계도함수 판정법

임계점 · 헤세 행렬 · D = f_xx f_yy − f_xy²

다루는 성취기준 [공통2-05-01]

판정법

\(\nabla f(a,b) = \mathbf 0\)인 임계점에서 \(D = f_{xx}f_{yy} - f_{xy}^2\) (헤세 행렬 \(H = \begin{pmatrix}f_{xx} & f_{xy}\\ f_{xy} & f_{yy}\end{pmatrix}\)의 행렬식)이라 하면

  • \(D > 0\), \(f_{xx} > 0\): 극소 / \(D > 0\), \(f_{xx} < 0\): 극대
  • \(D < 0\): 안장점 (어느 방향으로는 올라가고 어느 방향으로는 내려감)
  • \(D = 0\): 판정 불가

왜 그런가

  1. 임계점 근처에서 2차 Taylor 근사: \(f(a+h, b+k) \approx f(a,b) + \frac12Q(h,k)\), \(Q = Ah^2 + 2Bhk + Ck^2\) (\(A = f_{xx}, B = f_{xy}, C = f_{yy}\)).
    일차항은 \(\nabla f = \mathbf 0\)이라 사라진다. 그래서 2차항이 모양을 정한다.
  2. \(A \ne 0\)이면 완전제곱: \(Q = A\left(h + \frac BAk\right)^2 + \frac{AC - B^2}{A}k^2 = A\left(h + \frac BAk\right)^2 + \frac DAk^2\).
    고등학교의 이차식 완전제곱과 같은 계산.
  3. \(D > 0\)이면 두 항의 부호가 모두 \(A\)의 부호: \(A > 0\)이면 \(Q > 0\) (모든 방향으로 올라감, 극소), \(A < 0\)이면 극대.
    \((h,k) \ne (0,0)\)이면 두 제곱이 동시에 0이 될 수 없다.
  4. \(D < 0\)이면 두 항의 부호가 반대: \(k = 0\) 방향과 \(h + \frac BAk = 0\) 방향에서 \(Q\)의 부호가 다르다 → 안장점.
    \(A = 0\)인 경우도 \(D = -B^2 < 0\)이면 \(Q = 2Bhk + Ck^2\)가 부호를 바꾼다.

엄밀히는 Taylor 근사의 나머지가 2차항보다 작음을 보여야 하며, 이것은 2계 편도함수의 연속성에서 나옵니다(해석학).

\(f(x,y) = x^3 - 3xy + y^3\)의 임계점을 모두 찾고 분류하세요.

풀이

  1. \(f_x = 3x^2 - 3y = 0\), \(f_y = -3x + 3y^2 = 0\). 곧 \(y = x^2\), \(x = y^2\).
    임계점은 기울기 = 0.
  2. 대입: \(x = x^4\), \(x(x^3 - 1) = 0\), 실수해 \(x = 0, 1\). 임계점 \((0,0)\), \((1,1)\).
    \(x^3 = 1\)의 실근은 1뿐.
  3. \(f_{xx} = 6x\), \(f_{yy} = 6y\), \(f_{xy} = -3\). \(D = 36xy - 9\).
    2계 편도함수.
  4. \((0,0)\): \(D = -9 < 0\), 안장점.
    \(y = x\) 방향 \(f = 2x^3 - 3x^2\)는 0 근처에서 \(< 0\), \(y = -x\) 방향 \(f = 3x^2 > 0\). 확인됨.
  5. \((1,1)\): \(D = 27 > 0\), \(f_{xx} = 6 > 0\), 극소 \(f(1,1) = -1\).
    판정법.

의미

이계도함수 판정은 임계점 근처를 이차식(그릇, 뒤집힌 그릇, 말안장)으로 근사해 모양을 읽는 것입니다. 변수가 셋 이상이면 헤세 행렬의 고윳값의 부호로 같은 판정을 합니다(선형대수).

검산

\(f(1.1, 1) = 1.331 - 3.3 + 1 = -0.969 > -1\), \(f(1, 0.9) = 1 - 2.7 + 0.729 = -0.971 > -1\). 주변값이 더 큽니다. 다만 \(x \to -\infty\)이면 \(f \to -\infty\)이므로 이것은 극소일 뿐 최소는 아닙니다.

흔한 오해

  • \(D = 0\)에서 결론 내리기: \(x^4 + y^4\) (극소), \(-x^4 - y^4\) (극대), \(x^4 - y^4\) (안장점)은 모두 원점에서 \(D = 0\)입니다. 직접 값을 비교해야 합니다.
  • 축 방향만 보기: \(f_{xx} > 0\), \(f_{yy} > 0\)이어도 \(f_{xy}\)가 크면 안장점입니다. 예: \(x^2 + 3xy + y^2\) (\(D = 4 - 9 < 0\)).
