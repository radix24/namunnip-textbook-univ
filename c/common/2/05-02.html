5.2.1최대·최소 정리

공통1에서 닫힌구간 \([a, b]\)의 연속함수는 최댓값과 최솟값을 가지며, 그것은 임계점이나 끝점에서 나타났습니다. 평면에서는 "닫힌구간" 대신 경계를 포함하고(닫힘) 무한히 뻗지 않는(유계) 영역을 씁니다. 원판, 직사각형, 삼각형이 그런 예입니다.

정리 5.2.1 (최대·최소 정리)

닫힌 유계 영역 \(D\)에서 연속인 함수는 \(D\)에서 최댓값과 최솟값을 갖는다.

그 값은 영역 안쪽의 임계점이나 경계 위에서 나타납니다. 끝점이 두 개뿐이던 일변수와 달리 경계가 곡선이므로, 경계 위에서는 일변수 최대·최소 문제를 따로 풀어야 합니다.

  1. 안쪽의 임계점에서 \(f\)의 값을 구한다.
  2. 경계의 각 부분에서 \(f\)를 한 변수의 함수로 바꾸어 최댓값·최솟값을 구한다.
  3. 1, 2에서 나온 값 가운데 가장 큰 것이 최댓값, 가장 작은 것이 최솟값.

5.2.2예제

예제 5.2.2

직사각형 \(0 \le x \le 3\), \(0 \le y \le 2\)에서 \(f(x, y) = x^2 - 2xy + 2y\)의 최댓값과 최솟값을 구하여라.

풀이. 1단계: \(f_x = 2x - 2y = 0\), \(f_y = -2x + 2 = 0\)에서 \((1, 1)\), \(f(1, 1) = 1\).

2단계: 네 변을 차례로 봅니다.

  • 아랫변 \(y = 0\): \(f = x^2\), \(0 \le x \le 3\). 값의 범위 \([0, 9]\).
  • 오른쪽 변 \(x = 3\): \(f = 9 - 4y\), \(0 \le y \le 2\). 범위 \([1, 9]\).
  • 윗변 \(y = 2\): \(f = x^2 - 4x + 4 = (x - 2)^2\). 범위 \([0, 1]\).
  • 왼쪽 변 \(x = 0\): \(f = 2y\). 범위 \([0, 4]\).

3단계: 최댓값 9 (점 \((3, 0)\)), 최솟값 0 (점 \((0, 0)\)과 \((2, 2)\)). 안쪽 임계점의 값 1은 최대도 최소도 아닙니다.

경계가 원처럼 곡선이면 \(x = \cos t\), \(y = \sin t\)로 매개화하거나, 5.3절의 라그랑주 승수법을 씁니다.

요약
  1. 닫힌 유계 영역의 연속함수는 최댓값·최솟값을 갖는다.
  2. 후보: 안쪽 임계점 + 경계 위의 최대·최소. 모두 비교한다.

5.2.3연습문제

기본

  1. 원판 \(x^2 + y^2 \le 1\)에서 \(f = x^2 + y^2 - x\)의 최솟값과 최댓값은?
    답

    임계점 \((\frac12, 0)\), \(f = -\frac14\). 경계에서 \(f = 1 - x\), \(x\in[-1, 1]\)이므로 \([0, 2]\). 최솟값 \(-\frac14\), 최댓값 2.

응용

  1. 꼭짓점이 \((0, 0)\), \((2, 0)\), \((0, 2)\)인 삼각형에서 \(f = xy\)의 최댓값은?
    답

    안쪽 임계점 없음(원점은 꼭짓점). 빗변 \(y = 2 - x\)에서 \(x(2 - x)\)의 최대 1 (\(x = 1\)). 최댓값 1.

5.2.2

예제닫힌 유계 영역에서 최댓값과 최솟값

내부 임계점 + 경계 · 극값 정리

다루는 성취기준 [공통2-05-02]

근거와 절차

극값 정리 (증명은 해석학)

닫혀 있고 유계인 영역 \(D\)에서 연속인 함수는 최댓값과 최솟값을 갖는다.

최댓값이 내부의 점에서 생기면 그 점은 극대이므로 \(\nabla f = \mathbf 0\) (편미분 가능할 때). 아니면 경계에서 생깁니다. 그래서 후보는 두 종류뿐입니다.

  1. 내부의 임계점에서의 값.
  2. 경계에서의 최댓값·최솟값: 경계를 매개변수로 써서 일변수 문제로 바꾼다. 경계 조각의 끝점(꼭짓점)도 후보.
  3. 모든 후보의 값을 비교한다. 이계도함수 판정은 필요 없다.

\(f(x,y) = x^2 - 2xy + 2y\)의 직사각형 \(D = [0,3]\times[0,2]\)에서의 최댓값과 최솟값을 구하세요.

풀이

  1. 내부: \(f_x = 2x - 2y = 0\), \(f_y = -2x + 2 = 0\) → \((1, 1)\), \(f = 1 - 2 + 2 = 1\).
    \((1,1)\)은 \(D\)의 내부.
  2. 아래 변 \(y = 0\), \(0 \le x \le 3\): \(f = x^2\). 최소 0 (\(x = 0\)), 최대 9 (\(x = 3\)).
    일변수 함수.
  3. 오른쪽 변 \(x = 3\), \(0 \le y \le 2\): \(f = 9 - 4y\). 최소 1 (\(y = 2\)), 최대 9 (\(y = 0\)).
    감소하는 일차함수라 끝점에서 극값.
  4. 위 변 \(y = 2\), \(0 \le x \le 3\): \(f = x^2 - 4x + 4 = (x - 2)^2\). 최소 0 (\(x = 2\)), 최대 4 (\(x = 0\)).
    꼭짓점 \(x = 2\)는 구간 안의 임계점.
  5. 왼쪽 변 \(x = 0\), \(0 \le y \le 2\): \(f = 2y\). 최소 0, 최대 4.
    끝점에서.
  6. 후보값 \(1, 0, 9, 1, 0, 4, 0, 4\). 최댓값 9 (\((3,0)\)), 최솟값 0 (\((0,0)\)과 \((2,2)\)).
    비교.

의미

최댓값과 최솟값이 모두 경계에서 나왔습니다. 제약이 있는 최적화에서는 답이 경계에 있는 경우가 흔하고, 선형 계획법(일차 목적함수, 일차 제약)에서는 답이 늘 꼭짓점에 있습니다.

검산

내부 임계점 \((1,1)\)의 값 1은 최대도 최소도 아닙니다. 실제로 \(D = f_{xx}f_{yy} - f_{xy}^2 = 2\cdot0 - 4 < 0\)이라 안장점입니다. 최대·최소가 모두 경계에서 생기는 전형적인 경우입니다.

경계가 곡선이면

원판 \(x^2 + y^2 \le 1\)의 경계는 \(x = \cos t\), \(y = \sin t\)로 매개화하거나, 다음 카드의 Lagrange 승수법을 씁니다.

흔한 오해

  • 경계를 건너뜀: 위 예에서 내부만 보면 1이 답처럼 보이지만 틀립니다.
  • 열린 영역에 쓰기: \(x^2 + y^2 < 1\)에서는 최댓값이 없을 수 있습니다(\(f = x\)는 1에 다가가지만 닿지 않음).
