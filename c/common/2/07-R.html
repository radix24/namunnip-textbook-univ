7.R.1

연습선적분과 Green 정리 연습 문제

문제 7 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통2-07-02] [공통2-07-03] [공통2-07-04]

직접 계산하기 전에, 보존장인지(퍼텐셜), 닫힌 곡선인지(Green)를 먼저 확인하세요.

  1. 계산나선 \(\mathbf r(t) = (\cos t, \sin t, t)\), \(0 \le t \le 2\pi\) 위에서 \(\int_C(x^2 + y^2 + z^2)\,ds\)를 구하세요. [07-02]

    힌트 1

    \(|\mathbf r'| = \sqrt2\).

    힌트 2

    \(x^2 + y^2 + z^2 = 1 + t^2\).

    풀이

    \(\int_0^{2\pi}(1 + t^2)\sqrt2\,dt = \sqrt2\left(2\pi + \frac{8\pi^3}{3}\right)\).

  2. 계산\(\mathbf F = (x, y, z)\)가 나선 \((\cos t, \sin t, t)\), \(0 \le t \le 2\pi\)를 따라 한 일을 직접, 그리고 퍼텐셜로 구하세요. [07-02, 07-03]

    힌트 1

    \(\mathbf F\cdot\mathbf r' = -\cos t\sin t + \sin t\cos t + t\).

    힌트 2

    퍼텐셜 \(f = \frac12(x^2 + y^2 + z^2)\).

    풀이

    직접: \(\int_0^{2\pi}t\,dt = 2\pi^2\). 퍼텐셜: \(f(1, 0, 2\pi) - f(1, 0, 0) = \frac12(1 + 4\pi^2) - \frac12 = 2\pi^2\).

  3. 계산\(\mathbf F = (e^y + 2x,\ xe^y + \cos y)\)가 보존장이면 퍼텐셜을 구하고, \((0,0)\)에서 \((1, \pi)\)까지 아무 경로의 선적분을 구하세요. [07-03]

    힌트 1

    \(P_y = e^y = Q_x\).

    힌트 2

    \(f = xe^y + x^2 + g(y)\).

    풀이

    \(f_y = xe^y + g'(y) = xe^y + \cos y\) → \(g = \sin y\). \(f = xe^y + x^2 + \sin y\). 값 \(f(1,\pi) - f(0,0) = e^\pi + 1\).

  4. 개념\(\mathbf F = \left(\frac{-y}{x^2+y^2}, \frac{x}{x^2+y^2}\right)\)의 단위원(반시계) 위의 선적분을 직접 구하고, 원점 밖에서 \(P_y = Q_x\)인데도 0이 아닌 이유를 쓰세요. [07-03, 07-04]

    힌트 1

    \(\mathbf r = (\cos t, \sin t)\)이면 \(\mathbf F = (-\sin t, \cos t)\).

    힌트 2

    영역에 구멍(원점)이 있습니다.

    풀이

    \(\mathbf F\cdot\mathbf r' = \sin^2t + \cos^2t = 1\), 선적분 \(2\pi\). 원점을 뺀 평면은 단순연결이 아니고, 원점을 둘러싼 곡선 안쪽에는 \(\mathbf F\)가 정의되지 않는 점이 있어 Green 정리를 쓸 수 없습니다. 국소적으로는 \(\mathbf F = \nabla\theta\) (각도 함수)이지만, \(\theta\)는 한 바퀴 돌면 \(2\pi\)만큼 늘어나 평면 전체에서 하나의 함수로 정의되지 않습니다.

  5. 계산꼭짓점 \((0,0), (1,0), (1,1), (0,1)\)인 정사각형 경계(반시계)에서 \(\oint_C xy\,dx + x^2\,dy\)를 Green 정리로 구하고, 한 변이라도 직접 계산해 확인하세요. [07-04]

    힌트 1

    \(Q_x - P_y = 2x - x = x\).

    힌트 2

    \(\iint x\,dA = \frac12\).

    풀이

    Green: \(\int_0^1\int_0^1x\,dx\,dy = \frac12\).

    직접: 아래 변 \(y = 0\): 0. 오른쪽 \(x = 1\), \(y: 0 \to 1\): \(\int_0^11\,dy = 1\). 위 \(y = 1\), \(x: 1 \to 0\): \(\int_1^0x\,dx = -\frac12\). 왼쪽 \(x = 0\): 0. 합 \(\frac12\). 일치.

  6. 도전사이클로이드 한 아치 \(x = t - \sin t\), \(y = 1 - \cos t\) (\(0 \le t \le 2\pi\))와 \(x\)축 사이의 넓이를 Green 넓이 공식 \(A = -\oint y\,dx\)로 구하세요. [07-04]

    힌트 1

    경계: \(x\)축 위를 \(0 \to 2\pi\) (여기서 \(y = 0\)), 그다음 아치를 거꾸로(\(t: 2\pi \to 0\)).

    힌트 2

    \(-\oint y\,dx\)는 \(x\)축 부분에서 0.

    풀이

    \(A = -\int_{2\pi}^{0}(1 - \cos t)(1 - \cos t)\,dt = \int_0^{2\pi}(1 - \cos t)^2dt = \int_0^{2\pi}\left(1 - 2\cos t + \frac{1 + \cos2t}{2}\right)dt = 3\pi\).

    바퀴(반지름 1) 넓이의 정확히 3배입니다(갈릴레이가 종이를 오려 무게를 재서 추측했다고 전해지는 결과).

  7. 판단한 학생이 \(\mathbf F = (-y, x)\)의 단위원(반시계) 선적분을 Green 정리로 \(\iint2\,dA = 2\pi\)로 구한 뒤, 같은 답안에 "\(\mathbf F\)는 보존장이므로 닫힌 곡선의 선적분은 0"이라고도 썼습니다. 어느 쪽이 맞나요? [07-03, 07-04]

    힌트 1

    07-03 절: 보존장 판정 \(P_y = Q_x\).

    힌트 2

    \(P_y = -1\), \(Q_x = 1\).

    풀이

    \(2\pi\)가 맞고, 보존장이라는 말이 틀렸습니다. \(P_y = -1 \ne 1 = Q_x\)이므로 보존장이 아닙니다(회전 \(Q_x - P_y = 2\)). 두 결론이 모순될 때는 판정 조건부터 다시 확인합니다.
