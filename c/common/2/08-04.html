8.4.1정리

정리 8.4.1 (발산 정리, 가우스 정리)

입체 \(E\)의 경계가 닫힌 곡면 \(S\)(바깥쪽 방향)이면

\[\iint_S\mathbf F\cdot d\mathbf S = \iiint_E\nabla\cdot\mathbf F\,dV.\]

뜻: 발산은 각 점에서 생겨나는 양이므로, "안에서 생겨난 양의 합 = 겉면으로 빠져나가는 양"입니다. 물이 새지도 생기지도 않는다면 들어온 만큼 나갑니다.

8.4.2예제

예제 8.4.2

\(\mathbf F = \langle z, y, x\rangle\)가 단위구면을 바깥쪽으로 지나는 선속을 구하여라.

풀이. \(\nabla\cdot\mathbf F = 0 + 1 + 0 = 1\). 선속 = 단위구의 부피 \(\frac{4\pi}{3}\). 8.2절에서 대칭을 써서 구한 값과 같습니다.

예제 8.4.3

\(\mathbf F = \langle xy, y^2 + e^{xz^2}, \sin(xy)\rangle\), \(E\)는 포물기둥 \(z = 1 - x^2\)과 평면 \(z = 0\), \(y = 0\), \(y + z = 2\)로 둘러싸인 입체이다. \(E\)의 겉면을 지나는 선속을 구하여라.

풀이. 겉면이 네 조각이고 \(\mathbf F\)가 복잡해 직접 계산은 매우 어렵습니다. 그러나 \(\nabla\cdot\mathbf F = y + 2y + 0 = 3y\)로 간단합니다.

\[\int_{-1}^1\int_0^{1-x^2}\int_0^{2-z}3y\,dy\,dz\,dx = \int_{-1}^1\frac12\left[8 - (1 + x^2)^3\right]dx = \frac{184}{35}.\]

(\(\int_{-1}^1(1 + x^2)^3dx = \frac{192}{35}\)을 썼습니다.) 복잡한 성분 \(e^{xz^2}\), \(\sin(xy)\)는 발산에서 사라졌습니다.

예제 8.4.4 (가우스 법칙)

원점의 점전하 \(q\)가 만드는 전기장 \(\mathbf E = \frac{q}{4\pi\varepsilon_0}\frac{\mathbf x}{|\mathbf x|^3}\)이 원점을 둘러싼 닫힌 곡면을 지나는 선속은?

풀이. 원점이 아닌 곳에서 \(\nabla\cdot\mathbf E = 0\)입니다(직접 확인 가능). 그래서 원점을 둘러싼 어떤 곡면이든 선속은 작은 구면에서의 선속과 같고, 반지름 \(a\)인 구면에서 \(|\mathbf E| = \frac{q}{4\pi\varepsilon_0a^2}\), 넓이 \(4\pi a^2\)이므로 \(\frac{q}{\varepsilon_0}\)입니다. 전자기학의 가우스 법칙입니다.

8.4.3네 정리의 공통 구조

정리안쪽경계
미적분의 기본정리\(\int_a^bF'\,dx\)\(F(b) - F(a)\)
선적분의 기본정리\(\int_C\nabla f\cdot d\mathbf r\)\(f(B) - f(A)\)
그린·스토크스\(\iint(\nabla\times\mathbf F)\cdot d\mathbf S\)\(\oint_C\mathbf F\cdot d\mathbf r\)
발산\(\iiint\nabla\cdot\mathbf F\,dV\)\(\iint_S\mathbf F\cdot d\mathbf S\)

모두 "영역 안에서 도함수를 적분한 것 = 경계에서 원래 함수의 값"입니다. 공통1에서 시작한 미적분이 여기서 하나로 모입니다.

요약
  1. 닫힌 곡면의 바깥쪽 선속 = 안쪽 발산의 삼중적분.
  2. 네 정리 모두 "안쪽의 도함수 = 경계의 값".

8.4.4연습문제

기본

  1. \(\mathbf F = \langle x, y, z\rangle\)이 단위정육면체 \([0, 1]^3\)의 겉면을 지나는 선속은?
    답

    발산 3, 부피 1. 선속 3.

  2. \(\mathbf F = \langle y, z, x\rangle\)이 아무 닫힌 곡면을 지나는 선속은?
    답

    발산 0이므로 0.

8.4.2

예제구를 빠져나가는 선속을 두 가지로 구하면 같을까?

예제 · 발산 정리

다루는 성취기준 [공통2-08-04]

\(\mathbf F = \langle x, y, z\rangle\)가 반지름 \(a\)인 구면 \(S\)를 바깥쪽으로 지나는 선속 \(\displaystyle\iint_S\mathbf F\cdot\mathbf n\,dS\)를 면적분과 발산 정리로 각각 구하세요.

전략

면적분은 곡면 위에서 \(\mathbf F\cdot\mathbf n\)을 더하는 것이고, 발산 정리는 그것을 안쪽 부피에서 \(\operatorname{div}\mathbf F\)를 더하는 것으로 바꿉니다. 구면에서는 바깥 단위 법선이 \(\mathbf n = \langle x, y, z\rangle/a\)라 직접 계산도 쉽습니다.

풀이

  1. 구면 위에서 \(\mathbf F\cdot\mathbf n = \dfrac{x^2 + y^2 + z^2}a = \dfrac{a^2}a = a\).
    구면 위의 점은 \(x^2 + y^2 + z^2 = a^2\).
  2. 면적분 \(= a \times (\text{구의 겉넓이}) = a\cdot4\pi a^2 = 4\pi a^3\).
    피적분함수가 상수.
  3. \(\operatorname{div}\mathbf F = 1 + 1 + 1 = 3\), 발산 정리: \(\displaystyle\iiint_E3\,dV = 3\cdot\tfrac43\pi a^3 = 4\pi a^3\).
    두 방법이 같은 값.

의미

\(\operatorname{div}\mathbf F = 3\)은 부피 1마다 1초에 3만큼 흘러나오는 샘이 고르게 있다는 뜻입니다. 안에서 만들어진 양이 모두 겉면으로 나가므로 두 값이 같습니다. 전기장의 가우스 법칙(공통4 2.1절)이 바로 이 정리입니다.

검산

차원 검사: \(\mathbf F\)가 길이 단위, 넓이를 곱하면 길이³. \(4\pi a^3\)도 길이³입니다.

바꿔 보기

\(\mathbf F = \langle x^3, y^3, z^3\rangle\)이면 면적분은 어렵지만 \(\operatorname{div}\mathbf F = 3(x^2 + y^2 + z^2) = 3\rho^2\)이라 구면좌표로 \(\int_0^{2\pi}\int_0^\pi\int_0^a3\rho^4\sin\phi\,d\rho\,d\phi\,d\theta = \dfrac{12\pi a^5}5\)입니다.

이해 확인

단위 정육면체 \([0, 1]^3\)의 겉면을 바깥쪽으로 지나는 \(\mathbf F = \langle x, y, z\rangle\)의 선속은?

답

\(\operatorname{div}\mathbf F = 3\), 부피 1이므로 3. 직접 하면 \(x = 1\), \(y = 1\), \(z = 1\)인 세 면에서 각각 1, 나머지 세 면에서 0.
