7.3.1기본정리

정리 7.3.1 (선적분의 기본정리)

곡선 \(C\)가 점 \(A\)에서 \(B\)로 가면

\[\int_C\nabla f\cdot d\mathbf r = f(B) - f(A).\]

이유: 연쇄법칙으로 \(\frac{d}{dt}f(\mathbf r(t)) = \nabla f\cdot\mathbf r'(t)\)이므로, 공통1의 기본정리로 \(\int_a^b\frac{d}{dt}f(\mathbf r(t))\,dt = f(\mathbf r(b)) - f(\mathbf r(a))\)입니다.

결과는 중요합니다. 보존장에서는

  • 선적분이 경로에 무관하고 끝점에만 의존한다.
  • 닫힌 곡선을 한 바퀴 돌면 선적분이 0이다.
  • 힘이 보존장이면 운동 에너지 증가 = 퍼텐셜 에너지 감소. 곧 역학적 에너지가 보존된다(공통3).

7.3.2판정과 퍼텐셜 구하기

\(\mathbf F = \langle P, Q\rangle = \nabla f\)이면 \(P = f_x\), \(Q = f_y\)이고 클레로 정리(4.2절)에 의해 \(P_y = f_{xy} = f_{yx} = Q_x\)입니다. 거꾸로도 거의 성립합니다.

정리 7.3.2

구멍이 없는 영역(단순연결 영역)에서 \(P, Q\)의 편도함수가 연속이고 \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\)이면 \(\mathbf F = \langle P, Q\rangle\)는 보존장이다.

예제 7.3.3

\(\mathbf F = \langle3 + 2xy, x^2 - 3y^2\rangle\)이 보존장임을 보이고 퍼텐셜을 구하여라. 또 \(\mathbf r(t) = \langle e^t\sin t, e^t\cos t\rangle\), \(0 \le t \le \pi\)를 따른 선적분을 구하여라.

풀이. \(P_y = 2x = Q_x\). 퍼텐셜은 다음처럼 구합니다.

  1. \(f_x = 3 + 2xy\)를 \(x\)로 적분: \(f = 3x + x^2y + g(y)\). (\(y\)만의 함수가 상수 역할)
  2. \(y\)로 미분해 \(Q\)와 비교: \(f_y = x^2 + g'(y) = x^2 - 3y^2\), \(g = -y^3\).
  3. \(f = 3x + x^2y - y^3\).

끝점: \(\mathbf r(0) = (0, 1)\), \(\mathbf r(\pi) = (0, -e^\pi)\). 선적분 \(= f(0, -e^\pi) - f(0, 1) = e^{3\pi} - (-1) = e^{3\pi} + 1\). 복잡한 경로를 매개화할 필요가 없습니다.

7.3.3구멍이 있으면

\(\mathbf F = \left\langle\frac{-y}{x^2 + y^2}, \frac{x}{x^2 + y^2}\right\rangle\)은 원점을 뺀 곳에서 \(P_y = Q_x\)가 성립합니다(직접 확인해 보십시오). 그러나 단위원을 한 바퀴 돌면 \(\mathbf r = \langle\cos t, \sin t\rangle\)에서 \(\mathbf F\cdot\mathbf r' = \sin^2t + \cos^2t = 1\)이므로 선적분은 \(2\pi \ne 0\)입니다. 원점이라는 구멍 때문에 정리 7.3.2의 가정이 깨진 것입니다. 이 예는 공통9(고등미적분학(2))의 복소 적분 \(\oint\frac{dz}{z} = 2\pi i\)와 같은 현상입니다.

요약
  1. \(\int_C\nabla f\cdot d\mathbf r = f(B) - f(A)\): 경로 무관, 닫힌 곡선이면 0.
  2. 판정: 구멍 없는 영역에서 \(P_y = Q_x\).
  3. 퍼텐셜: 한 변수로 적분하고 다른 변수로 미분해 맞춘다.

7.3.4연습문제

기본

  1. \(\mathbf F = \langle2x, 2y\rangle\)의 퍼텐셜과, \((0, 0)\)에서 \((3, 4)\)까지의 선적분은?
    답

    \(f = x^2 + y^2\). \(25\).

  2. \(\mathbf F = \langle y, -x\rangle\)은 보존장인가?
    답

    \(P_y = 1 \ne Q_x = -1\). 아니다.

7.3.2

증명보존장과 퍼텐셜: 경로와 상관없는 일

선적분의 기본정리 · P_y = Q_x · 퍼텐셜 찾기

다루는 성취기준 [공통2-07-03]

선적분의 기본정리

\(\mathbf F = \nabla f\)이고 \(C\)가 \(A\)에서 \(B\)로 가는 매끄러운 곡선이면 \(\int_C\mathbf F\cdot d\mathbf r = f(B) - f(A)\).

증명

  1. \(\int_C\nabla f\cdot d\mathbf r = \int_a^b\nabla f(\mathbf r(t))\cdot\mathbf r'(t)\,dt\).
    벡터 선적분의 정의.
  2. 피적분함수는 \(\frac{d}{dt}f(\mathbf r(t))\)이다.
    다변수 연쇄 법칙(4-03 카드).
  3. 공통1의 미적분의 기본정리로 \(= f(\mathbf r(b)) - f(\mathbf r(a)) = f(B) - f(A)\).
    일변수 FTC. 조각마다 매끄러운 곡선이면 조각별로 더하면 된다.

따름: 기울기장(보존장)의 선적분은 경로와 상관없고, 닫힌 곡선에서는 0. 물리: 중력, 정전기력이 한 일은 위치에너지의 차이입니다(\(\mathbf F = -\nabla U\)).

보존장 판정

  1. 필요조건: \(\mathbf F = (P, Q) = \nabla f\)이면 \(P = f_x\), \(Q = f_y\), 그러므로 \(P_y = f_{xy} = f_{yx} = Q_x\).
    2계 편도함수가 연속이면 섞인 편도함수가 같다(클레로 정리).
  2. 충분조건: 영역이 단순연결(구멍이 없음)이고 \(P_y = Q_x\)이면 보존장이다.
    다음 카드의 Green 정리로 증명한다: 닫힌 곡선의 선적분 = \(\iint(Q_x - P_y) = 0\).

구멍이 있으면 실패합니다: \(\mathbf F = \left(\frac{-y}{x^2+y^2}, \frac{x}{x^2+y^2}\right)\)는 원점 밖에서 \(P_y = Q_x\)이지만 단위원을 한 바퀴 돌면 선적분이 \(2\pi\)입니다.

3차원: \(\mathbf F = (P, Q, R)\)이면 조건은 \(\nabla\times\mathbf F = \mathbf 0\) (\(R_y = Q_z\), \(P_z = R_x\), \(Q_x = P_y\)).

\(\mathbf F = (2xy + e^z,\ x^2 + z,\ xe^z + y)\)가 보존장인지 판정하고 퍼텐셜을 구한 뒤, \((0,0,0)\)에서 \((1, 2, 0)\)까지의 선적분을 구하세요. 또 앞 카드의 \(\mathbf F = (y, x^2)\)가 왜 경로에 따라 달랐는지 설명하세요.

풀이

  1. \(R_y = 1 = Q_z\), \(P_z = e^z = R_x\), \(Q_x = 2x = P_y\). \(\mathbb R^3\)은 단순연결이므로 보존장.
    회전이 0.
  2. \(f_x = 2xy + e^z\)를 \(x\)로 적분: \(f = x^2y + xe^z + g(y, z)\).
    \(x\)로 적분할 때 "상수"는 \(y, z\)의 함수.
  3. \(f_y = x^2 + g_y = x^2 + z\) → \(g_y = z\), \(g = yz + h(z)\).
    \(Q\)와 비교.
  4. \(f_z = xe^z + y + h'(z) = xe^z + y\) → \(h' = 0\). \(f = x^2y + xe^z + yz\) (+ 상수).
    \(R\)과 비교.
  5. \(\int = f(1,2,0) - f(0,0,0) = 2 + 1 + 0 - 0 = 3\).
    기본정리. 경로를 정할 필요가 없다.
  6. \(\mathbf F = (y, x^2)\): \(P_y = 1\), \(Q_x = 2x\). 같지 않으므로 보존장이 아니다.
    앞 카드에서 두 경로가 우연히 같은 값을 냈을 뿐이다.

검산

\(\nabla(x^2y + xe^z + yz) = (2xy + e^z, x^2 + z, xe^z + y)\). 원래 \(\mathbf F\)와 같습니다. 직선 경로 \((t, 2t, 0)\)로 직접 계산하면 \(P = 4t^2 + 1\), \(Q = t^2\), \(\mathbf r' = (1, 2, 0)\)이므로 \(\int_0^1(4t^2 + 1 + 2t^2)\,dt = 2 + 1 = 3\). 일치합니다.
