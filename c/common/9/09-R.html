9.R.1

연습그래프와 조합 최적화 연습 문제

문제 5 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-09-01] [공통9-09-02] [공통9-09-03]

먼저 질문이 최단 경로, 최소 신장 트리, 최대 흐름 중 무엇인지 정하세요.

  1. 개념다음을 그래프 문제로 바꾸세요. (가) 공장들 사이에 송수관을 깔아 모든 공장에 물을 공급하는 최소 공사비 (나) 응급차가 병원에서 사고 현장까지 가장 빨리 가는 길 (다) 도시 사이 도로망이 한 시간에 보낼 수 있는 최대 차량 수 [09-01]

    힌트 1

    09-01 절의 전략 2단계.

    힌트 2

    "모두 잇기", "두 점 사이", "최대량".

    풀이

    (가) 최소 신장 트리(가중치 = 공사비). (나) 최단 경로(가중치 = 이동 시간, 일방통행이면 방향 그래프). (다) 최대 흐름(가중치 = 도로 용량).

  2. 계산간선 S–A 7, S–B 3, A–B 1, A–C 2, B–C 6, C–T 1, B–T 8 (무방향)에서 S에서 T까지의 최단 경로를 Dijkstra로 구하세요. [09-02]

    힌트 1

    B(3) 확정 → A = 4.

    힌트 2

    A(4) 확정 → C = 6.

    풀이

    S 0 → B 3, A 7. B(3) 확정: A = min(7, 4) = 4, C = 9, T = 11. A(4): C = min(9, 6) = 6. C(6): T = min(11, 7) = 7. 최단 경로 S–B–A–C–T, 비용 7. 직접 연결이 비싸도 여러 번 갈아타는 길이 쌀 수 있습니다.

  3. 계산문제 2의 그래프에서 Kruskal로 최소 신장 트리를 구하세요. [09-02]

    힌트 1

    정렬: A–B 1, C–T 1, A–C 2, S–B 3, B–C 6, S–A 7, B–T 8.

    힌트 2

    정점 5개 → 간선 4개.

    풀이

    A–B ○, C–T ○, A–C ○, S–B ○ → 4개 완료. 비용 \(1 + 1 + 2 + 3 = 7\).

  4. 판단한 학생이 최대 흐름을 구하며 처음에 경로 하나를 꽉 채운 뒤 더 이상 경로가 안 보여 그 값을 답으로 냈습니다. 역방향 잔여 용량을 쓰지 않았다면 어떤 문제가 생길 수 있나요? [09-03]

    힌트 1

    09-03 절의 흔한 오해.

    힌트 2

    s→a 1, s→b 1, a→b 1, a→t 1, b→t 1에서 처음 s→a→b→t를 고르면?

    풀이

    힌트의 망에서 s→a→b→t로 1을 보내면 s→a, a→b, b→t가 포화되어 순방향으로는 더 갈 길이 없어 보입니다(답 1). 역방향 b→a(용량 1)를 쓰면 s→b→a→t로 1을 더 보낼 수 있어 실제 최대 흐름은 2입니다. 최소 절단 \(\{s\}\)의 용량도 2. 역방향 간선은 앞선 잘못된 선택을 되돌리는 장치입니다.

  5. 판단"최소 신장 트리에서 두 마을 사이의 경로는 늘 그 두 마을 사이의 최단 경로다." 반례를 만드세요. [09-01, 09-02]

    힌트 1

    삼각형 세 변이 모두 비슷한 가중치일 때.

    힌트 2

    A–B 2, B–C 2, A–C 3.

    풀이

    A–B 2, B–C 2, A–C 3이면 최소 신장 트리는 {A–B, B–C} (합 4). 그 안에서 A–C 경로는 A–B–C로 4지만, 최단 경로는 직접 연결 3입니다. 최소 신장 트리는 전체 합을 줄일 뿐 특정 쌍의 거리를 최소화하지 않습니다.
