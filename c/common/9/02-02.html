이 절에서 배울 것
  • 줄의 작은 조각에 뉴턴 법칙을 써서 파동방정식 \(u_{tt} = c^2u_{xx}\)를 끌어낸다.

먼저 알아야 할 것

2.2.1가정

양 끝을 고정한 줄을 튕기면 줄의 각 점이 위아래로 움직입니다. 위치 \(x\), 시각 \(t\)에서 줄의 높이를 \(u(x, t)\)라 하고, 다음을 가정합니다.

  • 줄의 질량은 길이당 \(\rho\)로 고르고, 줄은 완전히 휘어진다(굽힘 저항이 없다).
  • 장력 \(T\)는 매우 커서 중력은 무시한다.
  • 진동은 작아서 각 점은 위아래로만 움직이고 기울기가 작다.

2.2.2유도

\(x\)와 \(x + \Delta x\) 사이의 작은 조각을 봅니다. 양 끝에서 장력이 줄의 접선 방향으로 당기고, 그 방향이 수평과 이루는 각을 \(\alpha\), \(\beta\)라 합니다. 수평 방향으로는 움직이지 않으므로 \(T_1\cos\alpha = T_2\cos\beta = T\)입니다. 수직 방향의 힘은 \(T_2\sin\beta - T_1\sin\alpha\)이고, 뉴턴 법칙(질량 × 가속도)에서

\[T_2\sin\beta - T_1\sin\alpha = \rho\Delta x\,u_{tt}.\]

양변을 \(T\)로 나누면 \(\tan\beta - \tan\alpha = \frac{\rho\Delta x}{T}u_{tt}\)입니다. \(\tan\alpha\), \(\tan\beta\)는 두 끝에서의 기울기 \(u_x(x)\), \(u_x(x + \Delta x)\)이므로

\[\frac{u_x(x + \Delta x) - u_x(x)}{\Delta x} = \frac\rho Tu_{tt}.\]

\(\Delta x \to 0\)이면 왼쪽은 \(u_{xx}\)가 되어 1차원 파동방정식을 얻습니다.

\[u_{tt} = c^2u_{xx}, \qquad c^2 = \frac T\rho.\]

\(c\)는 속력의 단위를 가지며 실제로 파동이 줄을 따라 퍼지는 속력입니다(2.4절). 장력이 클수록, 줄이 가벼울수록 빨라집니다. 공통3 9단원의 \(v = \sqrt{T/\mu}\)와 같습니다.

읽는 법: \(u_{xx}\)는 줄의 휘어진 정도(오목함)입니다. 위로 오목한 곳(\(u_{xx} > 0\))은 위쪽으로 가속됩니다. 휘어진 줄이 펴지려고 하는 것입니다.

요약
  1. 작은 조각의 수직 방향 뉴턴 법칙 → \(u_{tt} = c^2u_{xx}\), \(c^2 = T/\rho\).
  2. 가속도는 휘어진 정도에 비례한다.

2.2.3연습문제

기본

  1. 장력 100 N, 길이당 질량 0.01 kg/m인 줄에서 파동의 속력은?
    답

    \(c = \sqrt{100/0.01} = 100\) m/s.

2.2.2

유도줄의 진동에서 파동방정식 유도하기

u_tt = c²u_xx · c² = T/ρ · 작은 진폭 근사

다루는 성취기준 [공통9-02-02]

무엇을 유도하나

장력 \(T\), 선밀도 \(\rho\)인 줄의 작은 가로 변위 \(u(x, t)\)는 \(\dfrac{\partial^2u}{\partial t^2} = c^2\dfrac{\partial^2u}{\partial x^2}\), \(c = \sqrt{T/\rho}\)를 만족한다.

모형과 가정

  • 줄은 완전히 유연(굽힘에 저항 없음), 장력은 줄을 따라 작용하고 크기가 일정.
  • 점은 가로(\(u\) 방향)로만 움직이고, 기울기가 작다: \(|u_x| \ll 1\) (작은 진폭).
  • 중력, 공기 저항 무시.

유도

  1. \(x\)와 \(x + \Delta x\) 사이의 작은 조각을 본다. 질량 \(\rho\Delta x\).
    가로 운동만 생각.
  2. 양 끝에서 장력이 접선 방향으로 당긴다. 가로 성분: 오른쪽 \(T\sin\theta(x + \Delta x)\), 왼쪽 \(-T\sin\theta(x)\).
    \(\theta\)는 줄과 \(x\)축의 각.
  3. 작은 기울기에서 \(\sin\theta \approx \tan\theta = u_x\). 가로 알짜힘 \(T[u_x(x + \Delta x) - u_x(x)]\).
    가정: \(|u_x| \ll 1\). 세로 성분 \(T\cos\theta \approx T\)는 양쪽에서 상쇄되어 \(x\) 방향 운동이 없다는 가정과 맞음.
  4. Newton 제2법칙: \(\rho\Delta x\,u_{tt} = T[u_x(x + \Delta x) - u_x(x)]\).
    질량 × 가속도 = 알짜힘.
  5. \(\Delta x\)로 나누고 \(\Delta x \to 0\): \(\rho u_{tt} = Tu_{xx}\), 곧 \(u_{tt} = \frac T\rho u_{xx}\).
    미분계수의 정의.

결과 확인

  • 차원: \(\sqrt{\frac{\text{N}}{\text{kg/m}}} = \sqrt{\frac{\text{kg·m/s}^2}{\text{kg/m}}} = \text{m/s}\). 속력입니다.
  • 파동의 속력: \(u = F(x - ct)\)가 해임을 연쇄 법칙으로 확인할 수 있어(공통3 6-02의 진행파), \(c\)가 파동이 가는 속력입니다.
  • 뜻: \(u_{xx} > 0\) (아래로 볼록)인 곳은 위로 가속. 줄이 휘어진 곳을 펴려는 복원력입니다.
  • 수치: 공통3 6-03 카드의 기타 줄(\(T = 78\) N, \(\rho = 1.2\) g/m)은 \(c = 255\) m/s.

한계

진폭이 크면 장력이 변하고 \(\sin\theta \ne \tan\theta\)라 비선형 방정식이 됩니다. 피아노 줄처럼 굵으면 굽힘 강성이 더해져 \(u_{xxxx}\)항이 생기고, 배음이 정수배에서 조금 벗어납니다(피아노 조율에서 늘인 옥타브).
