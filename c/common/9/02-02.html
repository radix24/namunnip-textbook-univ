2.2.1

예제사인, 코사인 반구간 전개

기함수·우함수 확장 · 경계 조건에 맞추기

다루는 성취기준 [공통9-02-02]

생각

\(0 < x < L\)에서만 정의된 함수(막대의 온도, 줄의 처음 모양)를 Fourier 급수로 쓰려면 \(-L < x < 0\)으로 늘려(확장) 주기 \(2L\) 함수를 만들면 됩니다. 늘리는 방법을 고를 수 있습니다.

  • 기함수로 확장 → 사인 급수 \(f = \sum b_n\sin\frac{n\pi x}{L}\), \(b_n = \frac2L\int_0^Lf\sin\frac{n\pi x}{L}dx\). 양 끝에서 0인 문제(고정된 줄, 양 끝 온도 0)에 맞습니다.
  • 우함수로 확장 → 코사인 급수 \(f = \frac{a_0}{2} + \sum a_n\cos\frac{n\pi x}{L}\), \(a_n = \frac2L\int_0^Lf\cos\frac{n\pi x}{L}dx\). 양 끝에서 기울기가 0인 문제(단열된 끝)에 맞습니다.

두 급수는 \((0, L)\)에서 같은 \(f\)로 수렴하지만, 구간 밖에서는 다른 함수입니다. 4단원의 변수분리에서 경계 조건이 어느 쪽을 쓸지 정합니다.

\(f(x) = x\) (\(0 < x < \pi\))를 (가) 사인 급수 (나) 코사인 급수로 전개하세요.

풀이

  1. (가) \(b_n = \frac2\pi\int_0^\pi x\sin nx\,dx\). 부분적분: \(\left[-\frac{x\cos nx}{n}\right]_0^\pi + \frac1n\int_0^\pi\cos nx\,dx = -\frac{\pi(-1)^n}{n}\).
    둘째 항은 0.
  2. \(b_n = \frac{2(-1)^{n+1}}{n}\). \(x = 2\left(\sin x - \frac{\sin2x}{2} + \frac{\sin3x}{3} - \cdots\right)\).
    계수 \(\frac1n\): 기함수 확장이 \(x = \pm\pi\)에서 뛰는(톱니파) 불연속이라.
  3. (나) \(a_0 = \frac2\pi\int_0^\pi x\,dx = \pi\). \(a_n = \frac2\pi\int_0^\pi x\cos nx\,dx = \frac2\pi\cdot\frac{(-1)^n - 1}{n^2}\).
    부분적분: \(\left[\frac{x\sin nx}{n}\right] + \frac{\cos nx}{n^2}\Big|_0^\pi\).
  4. 홀수 \(n\)만 \(a_n = -\frac{4}{\pi n^2}\). \(x = \frac\pi2 - \frac4\pi\left(\cos x + \frac{\cos3x}{9} + \frac{\cos5x}{25} + \cdots\right)\).
    계수 \(\frac{1}{n^2}\): 우함수 확장은 연속인 삼각파라 더 빨리 수렴.

의미

같은 \(x\)를 나타내는데 코사인 급수가 훨씬 빨리 수렴합니다(\(\frac{1}{n^2}\) 대 \(\frac1n\)). 확장한 함수가 연속이면 계수가 빨리 줄고, 불연속이면 느리게 줄어듭니다. 문제의 경계 조건이 허락하는 한, 매끄러운 확장을 고르는 것이 계산에 유리합니다.

검산

(나)에 \(x = 0\): \(0 = \frac\pi2 - \frac4\pi\left(1 + \frac19 + \frac{1}{25} + \cdots\right)\), 곧 \(\sum\frac{1}{(2k-1)^2} = \frac{\pi^2}{8}\). 이것으로 \(\sum\frac{1}{n^2} = \frac{\pi^2}{6}\)도 얻습니다(홀수 항이 전체의 \(\frac34\)이므로).
