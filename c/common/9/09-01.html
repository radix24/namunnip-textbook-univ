9.1.1직교좌표 복습

\(\nabla = \left(\frac{\partial}{\partial x}, \frac{\partial}{\partial y}, \frac{\partial}{\partial z}\right)\)로 쓰면 다음과 같습니다.

  • 기울기 \(\nabla f\): 가장 빨리 증가하는 방향과 그 비율. 스칼라 → 벡터.
  • 발산 \(\nabla\cdot\mathbf F = P_x + Q_y + R_z\): 한 점에서 퍼져 나가는 양. 벡터 → 스칼라.
  • 회전 \(\nabla\times\mathbf F\): 한 점에서 소용돌이치는 정도와 축. 벡터 → 벡터.
  • 라플라시안 \(\nabla^2f = \nabla\cdot\nabla f = f_{xx} + f_{yy} + f_{zz}\).

9.1.2원통좌표와 구면좌표

원형 막(2.7절), 원판(6.5절), 공 모양의 문제는 원통좌표 \((r, \theta, z)\)나 구면좌표 \((\rho, \theta, \phi)\)가 편합니다. 이때 공식에 \(r\)이나 \(\rho\) 같은 인수가 붙는 이유는, 각도가 \(d\theta\) 변할 때 실제로 움직이는 거리가 \(r\,d\theta\)이기 때문입니다.

원통좌표 (단위벡터 \(\mathbf e_r, \mathbf e_\theta, \mathbf e_z\)):

\[\nabla f = f_r\mathbf e_r + \frac1rf_\theta\mathbf e_\theta + f_z\mathbf e_z,\] \[\nabla\cdot\mathbf F = \frac1r(rF_r)_r + \frac1r\frac{\partial F_\theta}{\partial\theta} + \frac{\partial F_z}{\partial z},\] \[\nabla^2f = \frac1r(rf_r)_r + \frac{1}{r^2}f_{\theta\theta} + f_{zz}.\]

구면좌표에서 \(f\)가 \(\rho\)에만 의존하면

\[\nabla^2f = \frac{1}{\rho^2}\left(\rho^2f_\rho\right)_\rho.\]
예제 9.1.1

(가) \(\mathbf F = r\mathbf e_r\)(원통좌표)의 발산 (나) \(f = \ln r\)의 라플라시안 (다) \(f = \frac1\rho\)의 라플라시안을 구하여라.

풀이. (가) \(\frac1r(r^2)_r = 2\). 직교좌표로 \(\mathbf F = (x, y, 0)\)이고 발산 2와 같습니다. (나) \(\frac1r\left(r\cdot\frac1r\right)_r = 0\). 6.4절에서 쓴 동심원 사이의 퍼텐셜입니다. (다) \(\frac{1}{\rho^2}\left(\rho^2\cdot\left(-\frac{1}{\rho^2}\right)\right)_\rho = 0\) (\(\rho \ne 0\)). 점전하의 퍼텐셜 \(\frac1\rho\)이 라플라스 방정식을 만족한다는 뜻입니다.

요약
  1. 기울기·발산·회전·라플라시안은 \(\nabla\)로 쓴다.
  2. 곡선좌표 공식에는 거리 인수 \(r\), \(\rho\)가 붙는다.

9.1.3연습문제

기본

  1. \(f = r^2\)(원통좌표)의 라플라시안은?
    답

    \(\frac1r(2r^2)_r = 4\). (직교좌표 \(x^2 + y^2\)과 일치)

  2. \(f = \rho^2\)(구면좌표)의 라플라시안은?
    답

    \(\frac{1}{\rho^2}(2\rho^3)_\rho = 6\).

9.1.2

유도기울기, 발산, 회전을 곡선 좌표에서 계산하기

척도 인자 · 원통좌표 · 구면좌표 · Laplacian

다루는 성취기준 [공통9-09-01]

무엇을 유도하나

원통좌표 \((r, \theta, z)\)에서 \(\nabla f = f_r\hat{\mathbf r} + \frac1rf_\theta\hat{\boldsymbol\theta} + f_z\hat{\mathbf z}\), \(\nabla\cdot\mathbf F = \frac1r\frac{\partial(rF_r)}{\partial r} + \frac1r\frac{\partial F_\theta}{\partial\theta} + \frac{\partial F_z}{\partial z}\), \(\nabla^2f = \frac1r\frac{\partial}{\partial r}\left(r\frac{\partial f}{\partial r}\right) + \frac{1}{r^2}\frac{\partial^2f}{\partial\theta^2} + \frac{\partial^2f}{\partial z^2}\).

모형과 출발점

곡선 좌표 \((u_1, u_2, u_3)\)에서 \(u_i\)만 \(du_i\) 바꿀 때 실제로 움직이는 거리가 \(h_i\,du_i\)입니다(척도 인자 \(h_i\)). 원통좌표: \(h_r = 1\), \(h_\theta = r\) (호의 길이 \(r\,d\theta\)), \(h_z = 1\). 구면좌표: \(h_\rho = 1\), \(h_\varphi = \rho\), \(h_\theta = \rho\sin\varphi\). 공통2 6-02의 부피 요소 \(dV = h_1h_2h_3\,du_1du_2du_3\)와 같은 수입니다.

유도

  1. 기울기: 방향도함수 = 변화량 ÷ 실제 거리. \(\theta\) 방향으로 \(r\,d\theta\) 움직일 때 \(f\)는 \(f_\theta d\theta\) 변하므로 그 방향 성분은 \(\frac{f_\theta}{r}\).
    \(\nabla f\cdot\hat{\mathbf u} = \frac{df}{ds}\) (공통2 4-04).
  2. 발산: 작은 상자 \(dr\times r\,d\theta\times dz\)의 바깥 선속 ÷ 부피 (공통2 8-03의 정의). \(r\) 방향의 두 면은 넓이 \(r\,d\theta\,dz\)가 \(r\)에 따라 달라 선속 차이가 \(\frac{\partial(rF_r)}{\partial r}dr\,d\theta\,dz\).
    넓이 변화까지 미분해야 해서 \(rF_r\).
  3. 부피 \(r\,dr\,d\theta\,dz\)로 나누면 \(\frac1r\frac{\partial(rF_r)}{\partial r}\). \(\theta\), \(z\) 방향도 같은 방식.
    세 쌍의 면을 더함.
  4. Laplacian \(\nabla^2f = \nabla\cdot\nabla f\): 1단계의 성분을 2·3단계에 넣는다.
    \(F_r = f_r\), \(F_\theta = \frac{f_\theta}{r}\), \(F_z = f_z\).

구면좌표: \(\nabla^2f = \frac{1}{\rho^2}\frac{\partial}{\partial\rho}\left(\rho^2\frac{\partial f}{\partial\rho}\right) + \frac{1}{\rho^2\sin\varphi}\frac{\partial}{\partial\varphi}\left(\sin\varphi\frac{\partial f}{\partial\varphi}\right) + \frac{1}{\rho^2\sin^2\varphi}\frac{\partial^2f}{\partial\theta^2}\).

결과 확인

  • 점전하 전위 \(f = \frac1\rho\): \(\rho^2f_\rho = -1\) (상수)라 \(\nabla^2\frac1\rho = 0\) (\(\rho \ne 0\)). 전하가 없는 곳의 전위는 Laplace 방정식을 만족합니다.
  • 직선 전하 전위 \(f = \ln r\): \(rf_r = 1\)이라 \(\nabla^2\ln r = 0\) (\(r \ne 0\)). 공통4 1-02의 \(\frac{\lambda}{2\pi\varepsilon_0r}\)와 맞습니다.
  • 회전 흐름 \(\mathbf F = \frac{1}{r}\hat{\boldsymbol\theta}\): 발산 0, 회전 \(\frac1r\frac{\partial(rF_\theta)}{\partial r} = 0\) (\(r \ne 0\)). 공통2 7-02의 원점을 뺀 소용돌이 장입니다.

한계

원점(\(r = 0\), \(\rho = 0\))이나 극(\(\sin\varphi = 0\))에서는 좌표 자체가 특이해 식이 터집니다. 그곳의 물리량은 직교좌표로 확인하거나 극한으로 다룹니다. 이 식들이 5단원(원판의 Laplace 방정식)과 공통8 7-03(Bessel, Legendre)의 출발점입니다.
