예제Cauchy-Riemann 방정식으로 해석성 판정하기

복소 미분 · u_x = v_y, u_y = −v_x · 문제 해결 전략

다루는 성취기준 [공통9-03-04]

복소 미분과 조건의 출처

복소함수 \(f(z) = u(x, y) + iv(x, y)\) (\(z = x + iy\))의 도함수는 실수와 같은 식 \(f'(z) = \lim_{\Delta z\to0}\frac{f(z + \Delta z) - f(z)}{\Delta z}\)로 정의합니다. 차이는 \(\Delta z\)가 평면 위의 모든 방향에서 0으로 갈 수 있다는 점입니다(공통2 4-01의 이변수 극한처럼). 그래서 복소 미분 가능은 실수 미분 가능보다 훨씬 강한 조건입니다.

  1. 실수축 방향(\(\Delta z = \Delta x\)): \(f' = u_x + iv_x\).
    \(y\) 고정, \(\frac{\Delta f}{\Delta x}\).
  2. 허수축 방향(\(\Delta z = i\Delta y\)): \(f' = \frac{u_y + iv_y}{i} = v_y - iu_y\).
    \(\frac1i = -i\).
  3. 두 값이 같아야 하므로 실수부·허수부를 비교: \(u_x = v_y\), \(u_y = -v_x\) (Cauchy-Riemann 방정식).
    필요조건. 편도함수가 연속이면 충분조건도 된다.

열린 영역의 모든 점에서 복소 미분 가능한 함수를 해석함수(정칙함수)라 합니다.

문제 해결 전략 · 복소함수
  1. \(f\)를 \(z = x + iy\)로 써서 \(u\), \(v\)로 나눈다.
  2. 네 편도함수를 구하고 Cauchy-Riemann 방정식을 확인한다(편도함수의 연속성도).
  3. 성립하면 \(f' = u_x + iv_x\)로 도함수를 구한다.
  4. \(z\)만으로(\(\bar z\) 없이) 쓸 수 있는지 보면 빨리 짐작할 수 있다: \(\bar z\)가 들어 있으면 해석적이지 않은 경우가 많다.

(가) \(f(z) = z^2\) (나) \(f(z) = \bar z = x - iy\) (다) \(f(z) = |z|^2\)가 어디서 복소 미분 가능한지 판정하세요.

풀이

  1. (가) \(z^2 = x^2 - y^2 + 2ixy\). \(u_x = 2x = v_y\), \(u_y = -2y = -v_x\). 모든 점에서 성립: 해석함수(정함수). \(f' = 2x + 2iy = 2z\).
    실수의 \((x^2)' = 2x\)와 같은 공식.
  2. (나) \(u = x\), \(v = -y\). \(u_x = 1\), \(v_y = -1\). 어디서도 성립하지 않음.
    실수 쪽으로 보면 아주 매끄러운 함수(반사)인데도 복소 미분은 불가능.
  3. (다) \(u = x^2 + y^2\), \(v = 0\). \(u_x = 2x = 0 = v_y\), \(u_y = 2y = 0\)이 동시에 성립하는 곳은 원점뿐. 원점에서만 미분 가능하고, 어느 열린 영역에서도 해석적이지 않음.
    한 점에서 미분 가능한 것과 해석적인 것은 다르다.

의미

Cauchy-Riemann 방정식은 "복소 미분 = 회전과 확대"라는 뜻입니다. \(f'(z_0) = re^{i\varphi}\)이면 \(z_0\) 근처의 작은 도형이 \(r\)배 확대되고 \(\varphi\)만큼 회전할 뿐 찌그러지지 않습니다(각도 보존). \(\bar z\)는 도형을 뒤집으므로(반사) 이 조건을 어깁니다. 이 성질이 7단원의 등각사상으로 이어집니다.

검산

(가) 정의로: \(\frac{(z + h)^2 - z^2}{h} = 2z + h \to 2z\) (\(h\)가 어느 방향에서 오든). (나) \(\frac{\overline{z + h} - \bar z}{h} = \frac{\bar h}{h}\)는 \(h\)가 실수면 1, 순허수면 −1이라 극한이 없음. 두 결과가 Cauchy-Riemann 판정과 맞습니다.

3.4.2

증명해석함수의 실수부와 허수부는 조화함수다

∇²u = 0 · 조화 켤레 · 직교하는 등위선

다루는 성취기준 [공통9-03-04]

정리

\(f = u + iv\)가 영역 \(D\)에서 해석적이고 \(u, v\)가 2계 연속 편도함수를 가지면, \(u\)와 \(v\)는 \(D\)에서 Laplace 방정식을 만족한다: \(\nabla^2u = 0\), \(\nabla^2v = 0\).

쓰는 것

  • Cauchy-Riemann 방정식 \(u_x = v_y\), \(u_y = -v_x\) (03-04 카드).
  • 2계 편도함수가 연속이면 섞인 편도함수가 같다: \(v_{xy} = v_{yx}\) (클레로 정리, 공통2 7-02).

(해석함수는 사실 무한 번 미분 가능하다는 것이 7단원의 Cauchy 적분 공식에서 나오므로, 2계 연속이라는 가정은 결국 저절로 성립합니다.)

증명

  1. \(u_x = v_y\)를 \(x\)로 미분: \(u_{xx} = v_{yx}\).
    첫째 CR 방정식.
  2. \(u_y = -v_x\)를 \(y\)로 미분: \(u_{yy} = -v_{xy}\).
    둘째 CR 방정식.
  3. 더하면 \(u_{xx} + u_{yy} = v_{yx} - v_{xy} = 0\).
    섞인 편도함수가 같다.
  4. 같은 방법으로(첫째를 \(y\)로, 둘째를 \(x\)로 미분해 빼면) \(v_{xx} + v_{yy} = 0\).
    \(v_{xx} = -u_{yx}\), \(v_{yy} = u_{xy}\).

되짚기와 쓰임

  • 가정을 어디서 썼나: CR 방정식(해석성)과 섞인 편도함수의 대칭. \(\bar z\)처럼 CR을 어기는 함수의 실수부 \(x\)도 조화함수이긴 하지만, 그 "짝"인 허수부 \(-y\)와는 해석함수를 이루지 못합니다.
  • 조화 켤레 찾기: \(u = x^2 - y^2\)이 주어지면 \(v_y = u_x = 2x\)에서 \(v = 2xy + g(x)\), \(v_x = 2y + g' = -u_y = 2y\) → \(g = \)상수. \(v = 2xy\), 곧 \(f = z^2\). 공통2 7-02의 퍼텐셜 찾기와 같은 계산입니다.
  • 직교하는 등위선: CR에서 \(\nabla u\cdot\nabla v = u_xv_x + u_yv_y = u_xv_x - v_xu_x = 0\). \(u = \)상수 곡선과 \(v = \)상수 곡선이 서로 수직으로 만납니다. 전기장에서 등전위선과 전기력선, 흐름에서 등퍼텐셜선과 유선이 이 짝입니다.
  • 쓰임: 2차원 Laplace 방정식(5단원)을 풀려면 경계 조건에 맞는 해석함수를 찾아 실수부를 취하면 됩니다. 06-04 카드 (나)의 해 \(\frac12 + \frac12(x^2 - y^2)\)은 \(\frac12 + \frac12z^2\)의 실수부입니다.

직접 써 보기

\(u = e^x\cos y\)가 조화함수임을 확인하고 조화 켤레를 구하세요.

답안

\(u_{xx} = e^x\cos y\), \(u_{yy} = -e^x\cos y\), 합 0. \(v_y = e^x\cos y\) → \(v = e^x\sin y + g(x)\), \(v_x = e^x\sin y + g' = -u_y = e^x\sin y\) → \(g\) 상수. \(f = e^x(\cos y + i\sin y) = e^z\).
