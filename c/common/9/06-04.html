6.4.1라플라스 방정식이 나오는 곳

열방정식 \(u_t = c^2\nabla^2u\)에서 시간이 충분히 지나 온도가 변하지 않으면(정상 상태) \(u_t = 0\)이므로 \(\nabla^2u = 0\)입니다. 전하가 없는 곳의 정전기 퍼텐셜, 소용돌이 없는 이상 유체의 속도 퍼텐셜도 같은 식을 만족합니다. 그래서 2차원에서는 이 문제들이 모두 "경계값이 주어진 조화함수 찾기"가 됩니다.

해석함수 \(F = \Phi + i\Psi\)를 복소 퍼텐셜이라 부릅니다.

  • \(\Phi = \) 상수: 등퍼텐셜선 (같은 온도의 선, 등온선).
  • \(\Psi = \) 상수: 흐름선 (열이나 전기력선이 지나가는 길).
  • 두 곡선족은 서로 직각으로 만난다.

6.4.2등각사상을 쓰는 이유

정리 6.4.1

\(\Phi\)가 \(w\)평면에서 조화함수이고 \(w = f(z)\)가 해석적이면, \(\Phi(f(z))\)는 \(z\)평면에서 조화함수이다.

그래서 풀이 순서는 다음과 같습니다.

  1. 주어진 영역을 반평면이나 띠 같은 단순한 영역으로 옮기는 등각사상을 찾는다.
  2. 단순한 영역에서 조화함수를 구한다.
  3. 사상의 식을 대입해 원래 영역으로 되돌린다.
예제 6.4.2

위쪽 반평면에서, 양의 실수축의 온도가 0, 음의 실수축의 온도가 100일 때 정상 상태 온도를 구하여라.

풀이. \(\text{Ln}\,z = \ln r + i\theta\)는 해석적이므로 \(\theta = \text{Arg}\,z\)는 조화함수입니다. \(\theta = 0\)(양의 실수축)과 \(\theta = \pi\)(음의 실수축)에서 경계값을 맞추면

\[T = \frac{100}{\pi}\,\text{Arg}\,z.\]

등온선은 원점에서 나가는 반직선입니다. 예를 들어 \(z = i\)에서 \(T = 50\).

예제 6.4.3

1사분면에서, 양의 \(x\)축의 온도가 0, 양의 \(y\)축의 온도가 100일 때 정상 상태 온도를 구하여라.

풀이. \(w = z^2\)이 1사분면을 위쪽 반평면으로 옮기고(6.1절), 양의 \(x\)축은 양의 실수축, 양의 \(y\)축은 음의 실수축으로 갑니다. 예제 6.4.2의 답에 대입하면

\[T = \frac{100}{\pi}\text{Arg}(z^2) = \frac{200}{\pi}\text{Arg}\,z.\]

확인: \(y\)축(\(\text{Arg}\,z = \frac\pi2\))에서 100, \(x\)축에서 0.

요약
  1. 정상 상태 온도와 퍼텐셜은 라플라스 방정식의 해(조화함수).
  2. 해석함수로 옮겨도 조화함수는 조화함수. 단순한 영역에서 풀고 되돌린다.
  3. 반평면의 기본해: \(\text{Arg}\,z\)의 일차식.

6.4.3연습문제

기본

  1. 두 동심원 \(r = 1\) (퍼텐셜 0)과 \(r = e\) (퍼텐셜 100) 사이의 퍼텐셜을 구하여라. (힌트: \(\ln r = \text{Re}\,\text{Ln}\,z\)도 조화함수)
    답

    \(\Phi = 100\ln r\).

응용

  1. 예제 6.4.3에서 \(z = 1 + i\)의 온도는?
    답

    \(\text{Arg} = \frac\pi4\). \(\frac{200}{\pi}\cdot\frac\pi4 = 50\).

6.4.2

예제직사각형과 원판에서 Laplace 방정식 풀기

∇²u = 0 · sinh 해 · 극좌표 변수분리 · Poisson 적분

다루는 성취기준 [공통9-06-04]

무엇을 푸나

\(\nabla^2u = u_{xx} + u_{yy} = 0\)은 열방정식에서 시간이 오래 지나 \(u_t = 0\)이 된 정상 상태, 전하가 없는 곳의 전위, 비압축성 무회전 흐름의 퍼텐셜이 모두 따르는 방정식입니다. 시간이 없어 초기 조건 대신 경계 전체에서 값을 줍니다(Dirichlet 문제). 해(조화함수)는 각 점의 값이 그 점을 중심으로 한 원 위 평균값과 같다는 성질이 있어(평균값 성질), 최댓값과 최솟값은 경계에서만 나옵니다.

문제 해결 전략 · 2차원 Laplace 방정식
  1. 영역의 모양에 맞는 좌표를 고른다(직사각형: 직교, 원판: 극좌표).
  2. 경계 조건이 여러 변에서 0이 아니면, 한 변씩만 0이 아닌 문제로 나눠 풀고 더한다(중첩).
  3. 0인 경계 조건이 둘 있는 방향에서 고유값 문제를 푼다(사인 또는 코사인).
  4. 다른 방향은 \(\sinh\), \(\cosh\) (직사각형) 또는 \(r^n\) (원판)으로 정한다.
  5. 0이 아닌 경계에서 Fourier 계수를 맞춘다.

(가) 정사각형 \(0 < x < \pi\), \(0 < y < \pi\)에서 \(u = 0\) (세 변), \(u(x, \pi) = \sin x\) (윗변)인 해 (나) 단위원판에서 경계값 \(u(1, \theta) = \cos^2\theta\)인 해

풀이

  1. (가) \(u = X(x)Y(y)\): \(\frac{X''}{X} = -\frac{Y''}{Y} = -\lambda\). \(X(0) = X(\pi) = 0\)이므로 \(X_n = \sin nx\), \(\lambda = n^2\).
    0인 두 경계(좌우)가 있는 \(x\) 방향에서 고유값 문제.
  2. \(Y'' = n^2Y\), \(Y(0) = 0\): \(Y_n = \sinh ny\).
    \(\sinh0 = 0\). 사인 대신 쌍곡함수가 나오는 이유는 부호가 반대라서.
  3. \(u = \sum b_n\sin nx\sinh ny\). 윗변: \(\sum b_n\sinh(n\pi)\sin nx = \sin x\)이므로 \(b_1 = \frac{1}{\sinh\pi}\), 나머지 0. \(u = \frac{\sin x\sinh y}{\sinh\pi}\).
    계수 비교.
  4. (나) 극좌표 \(u_{rr} + \frac1ru_r + \frac{1}{r^2}u_{\theta\theta} = 0\) (1-01 카드). \(u = R(r)\Theta(\theta)\)에서 \(\Theta\)는 주기 \(2\pi\): \(\cos n\theta, \sin n\theta\). \(R\)은 Euler-Cauchy \(r^2R'' + rR' - n^2R = 0\): \(R = r^n\) (원점에서 유한한 해).
    공통8 2-04. \(r^{-n}\)과 \(\ln r\)은 원점에서 터져서 버린다.
  5. \(\cos^2\theta = \frac12 + \frac12\cos2\theta\)이므로 \(u = \frac12 + \frac12r^2\cos2\theta = \frac12 + \frac12(x^2 - y^2)\).
    \(r^2\cos2\theta = x^2 - y^2\).

의미

(나)의 중심값 \(u(0) = \frac12\)는 경계값 \(\cos^2\theta\)의 평균과 같습니다(평균값 성질). 일반적인 경계값이면 Fourier 계수를 써서 \(u = \frac{a_0}{2} + \sum r^n(a_n\cos n\theta + b_n\sin n\theta)\)이고, 이것을 적분 하나로 모은 것이 Poisson 적분 공식입니다. 높은 진동수 성분은 \(r^n\)으로 안쪽에서 빨리 사라져, 경계의 들쭉날쭉함이 안쪽에서는 매끄러워집니다. (가)의 해는 윗변에서 멀어질수록 \(\sinh y\)로 빠르게 작아집니다.

검산

(나) \(\nabla^2\left(\frac12 + \frac12(x^2 - y^2)\right) = 1 - 1 = 0\), \(r = 1\)에서 \(\frac12 + \frac12\cos2\theta = \cos^2\theta\). (가) \(\nabla^2(\sin x\sinh y) = -\sin x\sinh y + \sin x\sinh y = 0\).
