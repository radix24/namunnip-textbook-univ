7.2.1반복법의 생각

미지수가 수천, 수만 개이고 계수 대부분이 0인 연립방정식(예: 편미분방정식을 격자로 바꾼 것)은 가우스 소거보다 반복법이 효율적입니다. 각 식을 대각 원소의 미지수에 대해 풀어 놓고, 아무 출발값에서 시작해 차례로 고쳐 갑니다. 가우스-자이델 방법은 새로 구한 값을 바로 다음 식에 씁니다.

예제 7.2.1

\(10x + y = 12\), \(x + 10y = 21\)을 \((0, 0)\)에서 시작해 가우스-자이델로 풀어라. (정확한 해 \(x = 1\), \(y = 2\))

풀이. \(x = \frac{12 - y}{10}\), \(y = \frac{21 - x}{10}\).

단계\(x\)\(y\)

21.0021.9998

한 단계마다 오차가 약 100분의 1로 줄어듭니다.

새 값을 바로 쓰지 않고 한 단계가 끝난 뒤 한꺼번에 바꾸는 방법은 야코비 방법입니다. 보통 가우스-자이델이 더 빨리 수렴합니다.

7.2.2수렴 조건

반복법이 언제나 수렴하지는 않습니다. 예제 7.2.1의 두 식 순서를 바꾸어 \(x = 21 - 10y\), \(y = 12 - 10x\)로 반복하면 \((0, 0)\)에서 \(x = 21\), \(y = -198\), … 로 발산합니다.

정의 7.2.2 (대각 우세)

모든 행에서 대각 원소의 절댓값이 나머지 원소의 절댓값의 합보다 클 때, 곧 \(|a_{jj}| > \sum_{k\ne j}|a_{jk}|\)일 때 행렬이 (엄격히) 대각 우세하다고 한다.

정리 7.2.3

계수 행렬이 대각 우세이면 가우스-자이델(과 야코비) 방법은 어떤 출발값에서도 수렴한다.

예제 7.2.1은 \(10 > 1\)이 두 행 모두 성립하므로 수렴했고, 순서를 바꾼 것은 \(1 < 10\)이라 조건을 만족하지 않았습니다. 대각 우세는 충분조건이어서, 만족하지 않아도 수렴하는 경우는 있습니다.

요약
  1. 가우스-자이델: 각 식을 대각 미지수로 풀고, 새 값을 바로 쓰며 반복.
  2. 대각 우세이면 수렴한다. 식의 순서가 중요하다.

7.2.3연습문제

기본

  1. \(\begin{pmatrix}4 & 1 & 1\\ 1 & 5 & 2\\ 0 & 1 & 3\end{pmatrix}\)은 대각 우세인가?
    답

    \(4 > 2\), \(5 > 3\), \(3 > 1\). 대각 우세.

  2. \(5x + y = 7\), \(x + 4y = 6\)을 \((0, 0)\)에서 가우스-자이델로 한 단계 계산하여라.
    답

    \(x = 1.4\), \(y = \frac{6 - 1.4}{4} = 1.15\). (정확한 해 \((\frac{22}{19}, \frac{23}{19}) \approx (1.158, 1.211)\))

7.2.2

예제Gauss-Seidel 반복법과 대각 우세 조건

Jacobi · 새 값 바로 쓰기 · 수렴 판정

다루는 성취기준 [공통9-07-02]

방법과 수렴 조건

각 식을 대각 성분의 미지수에 대해 풀고, 추정값을 넣어 되풀이합니다.

  • Jacobi: 이전 단계 값만으로 모두 새로 계산. \(x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j\ne i}a_{ij}x_j^{(k)}\right)\).
  • Gauss-Seidel: 방금 구한 새 값을 바로 다음 식에 사용. 보통 Jacobi보다 약 2배 빨리 수렴하고 메모리도 덜 씁니다.
  • 대각 우세 \(|a_{ii}| > \sum_{j\ne i}|a_{ij}|\) (모든 행): 이 조건이면 두 방법 모두 어떤 초깃값에서도 수렴합니다. 대각 성분이 커서 각 단계의 오차가 일정 비율 이하로 줄기 때문입니다(축소 사상).

반복법은 큰 희소 행렬(대부분 성분이 0, 예: 편미분방정식을 격자로 이산화한 행렬)에 특히 좋습니다. 가우스 소거는 0이었던 자리를 채워 메모리를 많이 쓰지만, 반복법은 0이 아닌 성분만 씁니다.

먼저 예측

같은 연립방정식의 식 순서를 바꿔 대각 우세가 깨지면 Gauss-Seidel은 여전히 수렴할까요?

예측 확인

발산할 수 있습니다. 해는 같아도 반복법의 수렴은 식을 어떻게 배열했는지에 달려 있습니다(아래 검산).

\(4x - y + z = 7\), \(4x - 8y + z = -21\), \(-2x + y + 5z = 15\)를 Gauss-Seidel로 풀어 보세요(초깃값 \((1, 2, 2)\)). 참해는 \((2, 4, 3)\)입니다.

풀이

  1. 대각 우세 확인: \(|4| > 1 + 1\), \(|-8| > 4 + 1\), \(|5| > 2 + 1\). 수렴 보장.
    조건 먼저.
  2. \(x = \frac{7 + y - z}{4}\), \(y = \frac{21 + 4x + z}{8}\), \(z = \frac{15 + 2x - y}{5}\).
    각 식을 대각 미지수에 대해 풂.
  3. 1회: \(x = \frac{7 + 2 - 2}{4} = 1.75\), \(y = \frac{21 + 7 + 2}{8} = 3.75\), \(z = \frac{15 + 3.5 - 3.75}{5} = 2.95\).
    \(y\) 계산에 새 \(x = 1.75\), \(z\) 계산에 새 \(x, y\)를 바로 씀.
  4. 2회: \(x = \frac{7 + 3.75 - 2.95}{4} = 1.95\), \(y = \frac{21 + 7.8 + 2.95}{8} = 3.96875\), \(z = \frac{15 + 3.9 - 3.96875}{5} = 2.98625\).
    되풀이.
  5. 3회: \(x = 1.99562\), \(y = 3.99609\), \(z = 2.99903\). 참해 \((2, 4, 3)\)에 빠르게 다가간다.
    오차가 매번 약 \(\frac15\) 이하로 줄어든다.

의미

세 번 만에 오차가 0.005 이하가 되었습니다. 미지수가 수백만 개인 열전도·구조 해석 문제에서는 가우스 소거가 메모리와 시간 면에서 불가능하고, 이런 반복법(더 발전한 켤레 기울기법, 다중격자법)을 씁니다. 공통8 8단원의 수치해처럼 "정확한 공식" 대신 "충분히 정확할 때까지 반복"하는 생각입니다.

검산

3회 값을 넣은 잔차: 첫째 식 \(4(1.99562) - 3.99609 + 2.99903 = 6.98542\) (참 7). 식 순서를 바꿔 첫째와 둘째를 맞바꾸면 첫 행이 \(4x - 8y + z\)가 되어 \(x\)를 이 식에서 풀게 되는데, \(|4| < 8 + 1\)이라 대각 우세가 깨지고 실제로 반복값이 커지며 발산합니다.

7.2.3

실습두 직선 사이를 오가는 가우스-자이델

실습 · 반복법의 수렴과 대각 우세

다루는 성취기준 [공통9-07-02]

목표

2×2 연립방정식에서 가우스-자이델 반복이 두 직선 사이를 지그재그로 오가며 교점에 다가가는 모습을 보고, 식의 순서를 바꾸면(대각 우세가 깨지면) 발산하는 것을 확인합니다. 성취기준 [공통9-07-02].

준비

파란 직선이 첫째 식, 주황 직선이 둘째 식입니다. 한 번 반복할 때 첫째 식으로 \(x\)를 고치고(가로 이동, 파란 직선에 닿음) 둘째 식으로 \(y\)를 고칩니다(세로 이동, 주황 직선에 닿음). 빨간 경로가 반복의 자취입니다.

절차

  1. 첫째 연립방정식에서 "한 번 반복"을 여러 번 누르며 오차를 기록한다.
  2. 7.2절 예제(둘째)에서 같은 일을 하고 오차가 줄어드는 빠르기를 비교한다.
  3. 셋째(순서를 바꿈)에서 몇 번 반복해 본다.
  4. 출발점을 바꿔도 결과가 같은지 본다.

기대 결과

  • 첫째: 해 \((1, 2)\)로 수렴. 한 번 반복할 때마다 오차가 약 \(\frac13\).
  • 둘째: 매우 빨리 수렴(한 번에 약 100분의 1). 두 직선이 거의 수직이기 때문이다.
  • 셋째: 같은 두 직선인데도 반복할수록 경로가 밖으로 커져 발산한다.
  • 수렴하는 경우 출발점과 상관없이 같은 해로 간다.

분석

  1. 둘째와 셋째는 같은 두 직선입니다. 그런데 왜 결과가 정반대일까요? "\(x\)를 어느 식으로 고치는가"를 그림에서 보세요.
  2. 대각 우세는 충분조건입니다. 대각 우세가 아닌데도 수렴하는 예를 만들 수 있을지 생각해 보세요.

더 해 보기
