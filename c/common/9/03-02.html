3.2.1극형식

복소평면의 점을 극좌표로 쓰면 \(z = r(\cos\theta + i\sin\theta) = re^{i\theta}\)입니다. \(r = |z|\)를 절댓값, \(\theta = \arg z\)를 편각이라 합니다. 편각은 \(2\pi\)의 정수배만큼 차이 나도 같은 점을 나타내므로 값이 여러 개입니다. \(-\pi < \theta \le \pi\)인 것을 주값 \(\text{Arg}\,z\)라 합니다.

곱셈은 지수법칙으로 \(z_1z_2 = r_1r_2e^{i(\theta_1 + \theta_2)}\): 절댓값은 곱하고 편각은 더합니다. 그래서 \(i = e^{i\pi/2}\)를 곱하는 것은 원점 둘레로 90° 돌리는 것입니다.

3.2.2거듭제곱과 거듭제곱근

정리 3.2.1 (드무아브르 공식)

\((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\), 곧 \(z^n = r^ne^{in\theta}\).

거꾸로 \(w^n = z\)인 \(w\)(\(n\)제곱근)는 절댓값이 \(\sqrt[n]r\), 편각이 \(\frac{\theta + 2k\pi}{n}\) (\(k = 0, 1, \dots, n - 1\))입니다. 편각에 \(2\pi\)를 더한 것도 같은 \(z\)이므로, 그것을 \(n\)으로 나누면 서로 다른 \(n\)개의 근이 생깁니다. 이 근들은 원 위에 정\(n\)각형의 꼭짓점으로 고르게 놓입니다.

예제 3.2.2

\(z^3 = 1\)의 근을 모두 구하여라.

풀이. \(1 = e^{i0}\)이므로 근은 \(e^{2k\pi i/3}\), \(k = 0, 1, 2\): \(1\), \(-\frac12 + \frac{\sqrt3}{2}i\), \(-\frac12 - \frac{\sqrt3}{2}i\). 단위원 위의 정삼각형 꼭짓점입니다.

요약
  1. \(z = re^{i\theta}\). 곱셈: 절댓값 곱, 편각 합.
  2. \(z^n = r^ne^{in\theta}\). \(n\)제곱근은 \(n\)개, 정\(n\)각형 꼭짓점.

3.2.3연습문제

기본

  1. \((1 + i)^8\)을 계산하여라.
    답

    \(1 + i = \sqrt2e^{i\pi/4}\). \(16e^{2\pi i} = 16\).

  2. \(i\)의 제곱근을 구하여라.
    답

    \(e^{i\pi/4}\), \(e^{i5\pi/4}\): \(\pm\frac{1 + i}{\sqrt2}\).

3.2.2

탐구복소수를 n번 곱하면 평면에서 무슨 일이 일어날까?

탐구 · 극형식, 거듭제곱과 거듭제곱근

다루는 성취기준 [공통9-03-02]

질문

복소수 \(z = r(\cos\theta + i\sin\theta)\)를 곱하면 크기는 \(r\)배, 각은 \(\theta\)만큼 돌아갑니다. 그러면 \(z^n\)은 어디에 있을까요? 거꾸로 \(w^n = z\)인 \(w\)는 몇 개이고 어디에 있을까요?

복원

  • 드무아브르 공식: \(z^n = r^n(\cos n\theta + i\sin n\theta)\). 크기는 \(n\)제곱, 각은 \(n\)배입니다.
  • \(w^n = z\)인 \(w\)는 크기가 \(r^{1/n}\)이고 각이 \(\dfrac{\theta + 2\pi k}{n}\)(\(k = 0, 1, \ldots, n - 1\))인 \(n\)개입니다. 각에 \(2\pi\)를 더해도 같은 복소수이므로, \(n\)으로 나누면 서로 다른 각이 \(n\)개 생깁니다.
  • 보라는 \(z\), 주황은 \(z^n\), 빨간 점은 \(n\)제곱근들, 점선 원은 단위원입니다.

설명

\(r = 1\), \(\theta = 60°\), \(n = 3\)이면 \(z^3\)은 각 180°, 곧 \(-1\)입니다. 세제곱근은 크기 1, 각 20°, 140°, 260°인 세 점으로 정삼각형을 이룹니다. \(r = 1.2\)로 바꾸면 \(z^3\)의 크기는 \(1.728\)이 되어 단위원 밖으로 나가고, 세제곱근의 크기는 \(1.2^{1/3} \approx 1.0627\)로 단위원 가까이에 모입니다. \(r < 1\)이면 \(z^n\)은 원점 쪽으로 감겨 들어갑니다.

연결

극형식은 오일러 공식 \(e^{i\theta} = \cos\theta + i\sin\theta\)(3.5절)로 \(z = re^{i\theta}\)라 쓰면 곱셈이 지수의 덧셈이 됩니다. 복소 로그가 여러 값을 갖는 이유(3.6절)도 같은 "\(2\pi\)를 더해도 같은 점"에서 나옵니다.

적용

\(z^4 = 1\)의 해 네 개를 그림으로 찾고(\(r = 1\), \(\theta = 0°\), \(n = 4\)), 그것이 \(1, i, -1, -i\)인지 확인해 보세요.

판단

"\(\sqrt{z}\)는 하나뿐이다." 실수 \(\sqrt4 = 2\)와 비교해, \(n = 2\)일 때 그림에 점이 몇 개 나오는지로 이 말을 따져 보세요.
