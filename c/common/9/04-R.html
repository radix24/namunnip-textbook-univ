4.R.1

연습경계값 문제의 변수분리 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-04-01] [공통9-04-02] [공통9-04-03]

경계 조건 → 고유함수 → 시간 부분 → 초기 조건으로 계수, 이 순서를 지키세요.

  1. 계산\(u_t = u_{xx}\) (\(0 < x < \pi\)), \(u(0,t) = u(\pi,t) = 0\), \(u(x, 0) = 3\sin2x - \sin5x\)를 푸세요. [04-01]

    힌트 1

    04-01 절: 초기 조건이 이미 사인 급수.

    힌트 2

    \(\sin nx\) 성분은 \(e^{-n^2t}\)로 줄어듭니다.

    풀이

    \(u = 3e^{-4t}\sin2x - e^{-25t}\sin5x\).

  2. 계산양 끝이 단열된 막대 \(u_t = u_{xx}\), \(u_x(0,t) = u_x(\pi,t) = 0\), \(u(x, 0) = 1 + \cos2x\)를 푸세요. 오래 지나면 온도는? [04-01, 04-03]

    힌트 1

    Neumann이면 고유함수 \(\cos nx\) (\(n = 0\) 포함).

    힌트 2

    \(\cos nx\) 성분은 \(e^{-n^2t}\).

    풀이

    \(u = 1 + e^{-4t}\cos2x\). 오래 지나면 1 (처음 평균 온도). 3-R 문제 4의 결론과 같습니다.

  3. 계산무한한 줄(\(c = 2\))의 처음 속도가 \(g(x) = 1\) (\(|x| < 1\)), 0 (그 밖), 처음 변위가 0입니다. \(x = 0\)에서 \(u(0, t)\)를 \(t\)의 함수로 구하세요. [04-02]

    힌트 1

    d'Alembert: \(u = \frac{1}{2c}\int_{x-ct}^{x+ct}g\).

    힌트 2

    \(x = 0\)이면 구간 \([-2t, 2t]\)와 \([-1, 1]\)의 겹치는 길이.

    풀이

    \(t \le \frac12\): 겹침 \(4t\), \(u = \frac{4t}{4} = t\). \(t \ge \frac12\): 겹침 2, \(u = \frac12\). 처음 속도를 받은 부분이 올라가다가, 영향이 퍼져 나간 뒤 그 높이에 머뭅니다.

  4. 판단한 학생이 \(u_t = u_{xx}\), \(u(0,t) = 0\), \(u(1,t) = 10\)을 그대로 변수분리하려다 고유함수가 경계 조건을 만족하지 않아 막혔습니다. 무엇을 먼저 해야 하나요? [04-01]

    힌트 1

    경계 조건이 동차(0)가 아닙니다.

    힌트 2

    정상 상태 \(v(x) = 10x\)를 빼 보세요.

    풀이

    비동차 경계 조건은 변수분리를 바로 쓸 수 없습니다(해의 합이 경계 조건을 지키지 못함). 정상 상태 \(v = 10x\)를 구하고 \(w = u - v\)로 두면 \(w_t = w_{xx}\), \(w(0) = w(1) = 0\)인 동차 문제가 됩니다. \(w\)를 변수분리로 풀고 \(u = 10x + w\).

  5. 개념04-03 카드의 직교성 덕분에 Fourier 계수를 적분 하나로 구할 수 있습니다. 직교하지 않는 함수들(예: \(1, x, x^2, \dots\))로 전개하면 무엇이 어려워지나요? [04-03]

    힌트 1

    양변에 기저 함수를 곱해 적분하면?

    힌트 2

    다른 항이 사라지지 않습니다.

    풀이

    직교하면 다른 항이 모두 사라져 \(c_n = \frac{\int fy_nw}{\int y_n^2w}\)로 각각 따로 구합니다. 직교하지 않으면 모든 계수가 얽힌 연립방정식을 풀어야 하고, 항을 하나 더 넣을 때마다 앞의 계수를 다시 계산해야 합니다. 공통2 1-01의 정사영이 직교 기저에서만 단순한 것과 같은 이유입니다.

  6. 판단"줄을 정확히 가운데에서 퉁기면 짝수 배음(\(n = 2, 4, \dots\))이 생기지 않는다." 맞나요? 이유를 사인 계수로 설명하세요. [04-02]

    힌트 1

    가운데에서 퉁긴 모양은 \(x = \frac L2\)에 대해 대칭입니다.

    힌트 2

    \(\sin\frac{2\pi x}{L}\)은 가운데에 대해 반대칭(가운데가 마디).

    풀이

    맞습니다. 짝수 \(n\)의 \(\sin\frac{n\pi x}{L}\)은 가운데에 대해 반대칭이라, 대칭인 처음 모양과의 적분(계수)이 0입니다. 짝수 배음은 모두 가운데가 마디라서, 가운데를 크게 움직이는 퉁김으로는 생기지 않는다고 볼 수도 있습니다. 기타를 브리지 가까이에서 퉁기면 높은 배음이 많아 소리가 밝아지는 것도 같은 계산입니다.
