2.1.1여러 변수에 따라 변하는 양

막대의 온도는 위치 \(x\)와 시간 \(t\)에 따라, 북 가죽의 높이는 위치 \((x, y)\)와 시간에 따라 변합니다. 미지 함수가 여러 변수의 함수이고 편도함수가 들어 있는 미분방정식을 편미분방정식이라 합니다. 대표적인 식은 다음과 같습니다(\(u_{tt} = \frac{\partial^2u}{\partial t^2}\) 등으로 줄여 씁니다).

  • 파동방정식 \(u_{tt} = c^2u_{xx}\): 진동하는 줄, 소리, 전자기파.
  • 열방정식 \(u_t = c^2u_{xx}\): 열 전도, 확산.
  • 라플라스 방정식 \(u_{xx} + u_{yy} = 0\): 시간이 지나 안정된 온도 분포, 정전기 퍼텐셜.

모두 2계이고 선형이며 동차입니다(상미분방정식과 같은 뜻). 그래서 2계 상미분방정식의 중첩 원리가 그대로 성립합니다. 해 \(u_1, u_2\)가 있으면 \(c_1u_1 + c_2u_2\)도 해입니다. 이 원리가 변수분리와 푸리에 급수를 합치는 열쇠가 됩니다.

2.1.2조건이 해를 정한다

편미분방정식은 해가 매우 많습니다. 예를 들어 \(u_{xx} - u_{yy} = 0\)은 \(u = x^2 + y^2\), \(u = e^x\cosh y\), \(u = \sin x\cos y\) 등이 모두 해입니다. 상미분방정식에서는 상수 몇 개가 자유로웠지만, 편미분방정식에서는 임의의 함수가 자유롭습니다. 그래서 물리적 상황을 나타내는 조건이 필요합니다.

  • 경계 조건: 영역의 가장자리에서의 조건. 줄의 양 끝이 고정 \(u(0, t) = u(L, t) = 0\), 막대 끝의 온도가 일정 등.
  • 초기 조건: 처음 시각의 상태. 줄의 처음 모양 \(u(x, 0) = f(x)\)와 처음 속도 \(u_t(x, 0) = g(x)\), 막대의 처음 온도 분포 등.

경계에서 값을 주면 디리클레 조건, 경계에서 법선 방향 도함수(예: 열의 흐름)를 주면 노이만 조건이라 합니다. 끝이 단열되어 열이 빠져나가지 않으면 \(u_x = 0\)인 노이만 조건입니다.

요약
  1. 파동 \(u_{tt} = c^2u_{xx}\), 열 \(u_t = c^2u_{xx}\), 라플라스 \(u_{xx} + u_{yy} = 0\).
  2. 선형 동차이면 중첩 원리가 성립한다.
  3. 경계 조건과 초기 조건이 해를 하나로 정한다.

2.1.3연습문제

기본

  1. \(u = e^{-t}\sin x\)가 열방정식 \(u_t = u_{xx}\)의 해임을 확인하여라.
    답

    \(u_t = -e^{-t}\sin x\), \(u_{xx} = -e^{-t}\sin x\).

  2. \(u = x^2 - y^2\)이 라플라스 방정식의 해임을 확인하여라.
    답

    \(u_{xx} + u_{yy} = 2 - 2 = 0\).

2.1.2

설명Dirichlet 조건과 Neumann 조건은 무엇을 정하는가

경계 조건 · 초기 조건 · 잘 놓인 문제

다루는 성취기준 [공통9-02-01]

왜 필요한가

편미분방정식 하나에는 해가 무한히 많습니다. 예를 들어 \(u = 0\), \(u = x\), \(u = e^{-t}\sin x\)는 모두 열방정식 \(u_t = u_{xx}\)를 만족합니다. 이 중 실제로 일어나는 하나를 고르려면 "처음에 어떤 상태였나"(초기 조건)와 "경계에서 무슨 일이 일어나나"(경계 조건)를 함께 정해야 합니다. 상미분방정식에서 초기값 두 개로 해가 하나로 정해졌던 것(공통8 1-04)의 편미분판입니다.

정의

구간 \(0 \le x \le L\)의 경계 \(x = 0, L\)에서

Dirichlet 조건: 값을 정한다. \(u(0, t) = a\), \(u(L, t) = b\).

Neumann 조건: 기울기(법선 방향 도함수)를 정한다. \(u_x(0, t) = a\), \(u_x(L, t) = b\).

Robin(혼합) 조건: 값과 기울기의 일차결합을 정한다. \(u_x + hu = 0\).

초기 조건: 열방정식은 \(u(x, 0) = f(x)\) 하나, 파동방정식은 \(u(x, 0) = f(x)\)와 \(u_t(x, 0) = g(x)\) 두 개(시간에 대해 2계라서).

물리적 뜻으로 풀어 읽기

  1. 열: Dirichlet막대 끝을 얼음물(0 ℃)에 담가 온도를 고정. 끝의 온도가 늘 정해져 있습니다.
  2. 열: NeumannFourier 법칙 \(q = -ku_x\)라서 \(u_x = 0\)은 "열 흐름 0", 곧 끝이 단열되어 있다는 뜻입니다. \(u_x = a \ne 0\)이면 일정한 열이 들어오거나 나갑니다.
  3. 열: Robin끝이 공기와 맞닿아 온도차에 비례해 식음(Newton 냉각, 공통8 1-05).
  4. 줄: Dirichlet끝이 고정된 기타 줄, \(u = 0\).
  5. 줄: Neumann끝이 막대를 따라 위아래로 자유롭게 미끄러지는 고리에 매여 있음. 끝에서 세로 힘 \(Tu_x = 0\).

예와 반례

  • 예(정상 상태): 열방정식에서 시간이 오래 지나 \(u_t = 0\)이면 \(u_{xx} = 0\), 곧 \(u\)는 직선. Dirichlet \(u(0) = 0\), \(u(L) = 100\)이면 \(u = \frac{100x}{L}\). Neumann 양 끝 \(u_x = 0\)이면 \(u\)는 상수인데, 그 값은 경계 조건이 아니라 처음 열의 총량(평균 온도)이 정합니다. 단열된 막대는 열을 잃지 않기 때문입니다.
  • 예(경계 조건과 Fourier 급수): 양 끝 Dirichlet 0이면 해를 사인 급수로, 양 끝 Neumann 0이면 코사인 급수로 씁니다(2-02 카드). \(\sin\frac{n\pi x}{L}\)은 양 끝에서 0, \(\cos\frac{n\pi x}{L}\)은 양 끝에서 기울기 0이기 때문입니다.
  • 반례(조건이 모자라거나 넘침): 열방정식에 초기 조건 없이 경계 조건만 주면 해가 하나로 정해지지 않습니다. 반대로 Neumann 양 끝 \(u_x(0) = 0\), \(u_x(L) = 1\)인 정상 상태 \(u_{xx} = 0\)은 해가 없습니다(직선의 기울기가 양 끝에서 달라야 함). 들어오는 열이 있는데 나가는 곳이 없으니 온도가 끝없이 오르기 때문입니다.

다른 개념과의 관계

해가 존재하고, 하나뿐이고, 조건을 조금 바꾸면 해도 조금만 바뀌는 문제를 잘 놓인 문제(아다마르)라 합니다. 물리 모형은 이래야 측정 오차가 있어도 쓸모 있습니다. 4단원의 변수분리에서 경계 조건은 고유값 문제를, 초기 조건은 Fourier 계수를 정합니다.

흔한 오해

  • "경계 조건은 시간 0에서의 조건이다." 경계 조건은 공간의 끝에서 모든 시간에 성립하는 조건이고, 초기 조건은 시간 0에서 모든 위치에 대한 조건입니다.
