5.3.1특이점의 종류

\(f\)가 \(z_0\)에서는 해석적이지 않지만 그 둘레(\(0 < |z - z_0| < R\))에서는 해석적일 때 \(z_0\)을 고립 특이점이라 합니다. 로랑 급수의 주부(음의 거듭제곱 부분)를 보고 셋으로 나눕니다.

종류주부예
제거 가능 특이점없음\(\frac{\sin z}{z} = 1 - \frac{z^2}{3!} + \cdots\)
\(m\)위 극\(\frac{1}{(z - z_0)^m}\)까지 유한개\(\frac{e^z}{z^2}\): 0이 2위 극
본질적 특이점무한히 많음\(e^{1/z}\): 0

각 종류의 행동은 뚜렷이 다릅니다.

  • 제거 가능: \(f(z_0)\)을 극한값으로 정의하면 해석적이 된다. 사실상 특이점이 아니다.
  • 극: \(z \to z_0\)일 때 \(|f(z)| \to \infty\). 1위 극을 단순극이라 한다.
  • 본질적 특이점: 다가가는 방향에 따라 극한이 제멋대로다. 예를 들어 \(e^{1/z}\)은 양의 실수축으로 다가가면 \(\infty\), 음의 실수축으로 다가가면 0.

5.3.2영점과 극

\(f(z_0) = 0\)이고 \(f(z) = (z - z_0)^mg(z)\), \(g(z_0) \ne 0\)으로 쓸 수 있으면 \(z_0\)을 \(m\)위 영점이라 합니다. 미분으로 판정하면 \(f(z_0) = f'(z_0) = \cdots = f^{(m-1)}(z_0) = 0\), \(f^{(m)}(z_0) \ne 0\)입니다.

정리 5.3.1

\(z_0\)이 \(h\)의 \(m\)위 영점이면 \(\frac{1}{h}\)은 \(z_0\)에서 \(m\)위 극을 갖는다.

그래서 유리함수의 극은 분모의 근에서 찾고, 위수는 근의 중복도입니다.

예제 5.3.2

\(f(z) = \frac{z + 1}{z^2(z - 2)^3}\)과 \(g(z) = \frac{1}{\sin z}\)의 특이점과 위수를 구하여라.

풀이. \(f\): 0이 2위 극, 2가 3위 극(분자는 이 점들에서 0이 아님). \(g\): \(\sin z = 0\)인 \(z = n\pi\)에서 \((\sin z)' = \cos n\pi \ne 0\)이므로 1위 영점, 따라서 \(g\)는 \(n\pi\)에서 단순극입니다.

요약
  1. 주부가 없음 / 유한 / 무한 → 제거 가능 / 극 / 본질적.
  2. \(m\)위 영점의 역수는 \(m\)위 극.

5.3.3연습문제

기본

  1. \(\frac{1}{z^2 + 1}\)의 극과 위수는?
    답

    \(\pm i\), 모두 단순극.

  2. \(\frac{1 - \cos z}{z^2}\)의 0은 어떤 특이점인가?
    답

    \(\frac{1}{2!} - \frac{z^2}{4!} + \cdots\). 제거 가능.

5.3.2

예제특이점은 모두 같은 종류일까?

예제 · 제거 가능한 특이점, 극, 본질적 특이점

다루는 성취기준 [공통9-05-03]

\(z = 0\)에서 (가) \(\dfrac{\sin z}z\) (나) \(\dfrac{1 - \cos z}{z^4}\) (다) \(e^{1/z}\)의 특이점이 어떤 종류인지 판정하고, \(z^3\sin z\)의 영점의 위수를 구하세요.

전략

\(z = 0\) 근처의 로랑 급수를 써서 음의 거듭제곱 항이 없는지(제거 가능), 유한 개인지(극, 가장 낮은 지수가 위수), 무한히 많은지(본질적)를 봅니다. 알려진 테일러 급수를 나누거나 대입하면 됩니다.

풀이

  1. (가) \(\dfrac{\sin z}z = 1 - \dfrac{z^2}{6} + \cdots\). 음의 거듭제곱이 없어 제거 가능한 특이점(\(z = 0\)에서 값을 1로 정하면 해석적).
    \(\sin z = z - z^3/6 + \cdots\).
  2. (나) \(1 - \cos z = \dfrac{z^2}2 - \dfrac{z^4}{24} + \cdots\)이므로 \(\dfrac{1 - \cos z}{z^4} = \dfrac1{2z^2} - \dfrac1{24} + \cdots\). 2위의 극.
    가장 낮은 지수 \(-2\).
  3. (다) \(e^{1/z} = 1 + \dfrac1z + \dfrac1{2!z^2} + \dfrac1{3!z^3} + \cdots\). 음의 거듭제곱이 끝없이 있어 본질적 특이점.
    \(e^w\)의 급수에 \(w = 1/z\).
  4. \(z^3\sin z = z^4 - \dfrac{z^6}6 + \cdots\)이므로 \(z = 0\)은 4위의 영점.
    가장 낮은 지수가 4.

의미

극 근처에서는 \(|f| \to \infty\)로 가지만, 본질적 특이점 근처에서는 \(f\)가 0이 아닌 거의 모든 값을 다 가까이 지나갑니다(\(e^{1/z}\)는 실수축 오른쪽에서 \(\infty\), 왼쪽에서 0). 위수가 \(m\)인 영점의 역수는 위수 \(m\)인 극입니다.

검산

(나) \(z\)가 실수 0.1이면 \(\dfrac{1 - \cos0.1}{10^{-4}} \approx 49.96\), 예측 \(\dfrac1{2(0.01)} - \dfrac1{24} = 49.96\). 맞습니다.

바꿔 보기

\(\dfrac1{z^2\sin z}\)은 분모가 \(z = 0\)에서 3위의 영점(\(z^3 - \cdots\))이므로 3위의 극입니다.

이해 확인

\(\dfrac{z}{e^z - 1}\)의 \(z = 0\)은 어떤 특이점인가요? \(z = 2\pi i\)는?

답

\(e^z - 1 = z + z^2/2 + \cdots\)이므로 \(z = 0\)은 제거 가능(값 1). \(z = 2\pi i\)는 분모의 1위 영점, 분자는 0이 아니므로 1위의 극.
