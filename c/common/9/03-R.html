3.R.1

연습복소수와 해석함수 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-03-04] [공통9-03-04] [공통9-03-06]

먼저 \(z = x + iy\)로 써서 실수부와 허수부를 나누세요.

  1. 계산\(f(z) = z^3\)의 \(u, v\)를 구하고 Cauchy-Riemann 방정식을 확인하세요. [03-04]

    힌트 1

    03-04 절: \((x + iy)^3\)을 전개.

    힌트 2

    \(u = x^3 - 3xy^2\), \(v = 3x^2y - y^3\).

    풀이

    \(u_x = 3x^2 - 3y^2 = v_y\), \(u_y = -6xy = -v_x\). 모든 점에서 성립. \(f' = u_x + iv_x = 3(x^2 - y^2) + 6ixy = 3z^2\).

  2. 계산\(u = 2x - x^3 + 3xy^2\)가 조화함수인지 확인하고 조화 켤레 \(v\)와 해석함수 \(f(z)\)를 구하세요. [03-04]

    힌트 1

    \(u_{xx} + u_{yy} = -6x + 6x\).

    힌트 2

    \(v_y = u_x = 2 - 3x^2 + 3y^2\).

    풀이

    조화함수입니다. \(v = 2y - 3x^2y + y^3 + g(x)\), \(v_x = -6xy + g' = -u_y = -6xy\) → \(g\) 상수. \(f = 2z - z^3\) (확인: \(-z^3\)의 실수부 \(-x^3 + 3xy^2\)).

  3. 판단한 학생이 "\(f(z) = x^2 + iy^2\)는 다항식이니 어디서나 해석적"이라고 했습니다. 맞나요? [03-04]

    힌트 1

    \(x, y\)의 다항식이지 \(z\)의 다항식이 아닙니다.

    힌트 2

    \(u_x = 2x\), \(v_y = 2y\).

    풀이

    틀렸습니다. CR: \(2x = 2y\), \(0 = 0\). 직선 \(y = x\) 위에서만 미분 가능하고, 열린 영역이 아니라 어디서도 해석적이지 않습니다. 해석함수는 \(z\)만의 식으로 쓸 수 있어야 하며 \(x, y\)의 다항식이라는 것만으로는 부족합니다.

  4. 계산\(e^z = -2\)를 만족하는 \(z\)를 모두 구하세요. [03-06]

    힌트 1

    \(-2 = 2e^{i\pi}\).

    힌트 2

    \(z = \log(-2)\).

    풀이

    \(z = \ln2 + i(\pi + 2k\pi)\), \(k\)는 정수. 실수 지수함수로는 해가 없던 방정식입니다.

  5. 개념해석함수 \(f\)가 영역에서 실수 값만 가지면 상수임을 CR 방정식으로 보이세요. [03-04]

    힌트 1

    \(v = 0\)이면 CR에서 \(u_x, u_y\)는?

    힌트 2

    기울기가 0인 함수는?

    풀이

    \(v = 0\)이면 \(u_x = v_y = 0\), \(u_y = -v_x = 0\). \(\nabla u = 0\)이라 (연결된) 영역에서 \(u\)는 상수(공통1 4-01 평균값 정리의 2차원판). 해석성은 이렇게 강한 제약입니다.

  6. 판단"\((-1)^{1/2} = \pm i\)이고 \(\left((-1)^{1/2}\right)^2 = -1\)이니 \((-1)^{1/2\cdot2} = (-1)^1 = -1\)도 맞다. 따라서 \(1 = \sqrt{1} = \sqrt{(-1)(-1)} = \sqrt{-1}\sqrt{-1} = i\cdot i = -1\)." 어디가 틀렸나요? [03-06]

    힌트 1

    \(\sqrt{ab} = \sqrt a\sqrt b\)는 언제 성립하나요?

    힌트 2

    03-06 절의 \(\text{Log}(z_1z_2)\) 반례.

    풀이

    \(\sqrt{ab} = \sqrt a\sqrt b\)는 주가지에서 \(a, b \ge 0\)일 때만 보장됩니다. 복소수에서는 \(\sqrt{z} = e^{\frac12\text{Log}z}\)이고 \(\text{Log}(ab) \ne \text{Log}\,a + \text{Log}\,b\)일 수 있어(각이 \(2\pi\)만큼 다름), 다른 가지의 값이 나옵니다. 다가함수에서는 "어느 가지를 고르는가"를 늘 함께 적어야 합니다.
