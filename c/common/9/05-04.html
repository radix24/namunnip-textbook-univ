5.4.1유수

\(z_0\) 둘레의 작은 원에서 로랑 급수를 항별로 적분하면, 4.1절의 결과에 의해 \(\frac{b_1}{z - z_0}\) 항만 \(2\pi ib_1\)을 남기고 나머지는 모두 0입니다. 그래서 \(b_1\)을 \(z_0\)에서의 유수 \(\text{Res}_{z=z_0}f\)라 합니다. "적분하고 남는 것"이라는 뜻입니다.

극에서는 로랑 급수를 다 구하지 않고도 유수를 구할 수 있습니다.

  • 단순극: \(\text{Res} = \lim_{z\to z_0}(z - z_0)f(z)\).
  • 단순극, \(f = \frac{p}{q}\) (\(p(z_0) \ne 0\), \(q(z_0) = 0\), \(q'(z_0) \ne 0\)): \(\text{Res} = \frac{p(z_0)}{q'(z_0)}\).
  • \(m\)위 극: \(\text{Res} = \frac{1}{(m - 1)!}\lim_{z\to z_0}\frac{d^{m-1}}{dz^{m-1}}\left[(z - z_0)^mf(z)\right]\).
예제 5.4.1

\(\frac{1}{z^2 + 1}\)의 \(z = i\)에서의 유수와 \(\frac{e^z}{z^2}\)의 \(z = 0\)에서의 유수를 구하여라.

풀이. 첫째는 단순극: \(\frac{p}{q'} = \frac{1}{2z}\Big|_{z=i} = \frac{1}{2i} = -\frac i2\). 둘째는 2위 극: \(\frac{d}{dz}\left[z^2\cdot\frac{e^z}{z^2}\right] = e^z \to 1\). (5.2절의 전개에서 \(\frac1z\)의 계수가 1인 것과 같습니다.)

5.4.2유수 정리

정리 5.4.2 (유수 정리)

\(f\)가 닫힌 경로 \(C\)의 안쪽과 위에서 유한개의 특이점 \(z_1, \dots, z_k\)(모두 안쪽)를 빼고 해석적이면

\[\oint_Cf(z)\,dz = 2\pi i\sum_{j=1}^k\text{Res}_{z=z_j}f.\]

이유: 경로 변형(4.2절)으로 \(C\)를 각 특이점 둘레의 작은 원들로 쪼개면, 각 원의 적분이 \(2\pi i\times\)유수입니다. 코시 적분 공식과 도함수 공식은 이 정리의 특별한 경우입니다.

예제 5.4.3

원 \(|z| = 2\)에서 \(\displaystyle\oint\frac{4 - 3z}{z^2 - z}dz\)를 구하여라.

풀이. \(z^2 - z = z(z - 1)\). 단순극 0과 1이 모두 원 안에 있습니다.

  • \(z = 0\): \(\frac{4 - 3z}{z - 1}\Big|_0 = -4\).
  • \(z = 1\): \(\frac{4 - 3z}{z}\Big|_1 = 1\).

따라서 \(2\pi i(-4 + 1) = -6\pi i\). 원이 \(|z| = \frac12\)이었다면 0만 안에 있으므로 \(-8\pi i\)입니다.

요약
  1. 유수 = 로랑 급수의 \(\frac{1}{z - z_0}\) 계수. 단순극은 \(\frac{p}{q'}\).
  2. \(\oint_Cf\,dz = 2\pi i\times\)(안쪽 유수의 합).

5.4.3연습문제

기본

  1. \(\frac{1}{z(z - 3)}\)의 각 극에서 유수를 구하여라.
    답

    \(z = 0\): \(-\frac13\). \(z = 3\): \(\frac13\).

  2. 원 \(|z| = 1\)에서 \(\oint\frac{dz}{z(z - 3)}\)은?
    답

    0만 안쪽. \(2\pi i\cdot\left(-\frac13\right) = -\frac{2\pi i}{3}\).

응용

  1. 원 \(|z| = 1\)에서 \(\oint\tan z\,dz\)는?
    답

    안쪽에는 극이 없다(\(\cos z = 0\)인 점 \(\pm\frac\pi2\)는 원 밖). 0.

5.4.2

예제Cauchy 적분 공식과 유수 정리로 적분 계산하기

Cauchy 정리 · f(z₀) = (1/2πi)∮f/(z−z₀) · Laurent 급수 · 유수

다루는 성취기준 [공통9-05-04]

세 가지 도구

  • Cauchy 정리: \(f\)가 단순 닫힌곡선 \(C\)와 그 안쪽에서 해석적이면 \(\oint_Cf\,dz = 0\). (Green 정리 + CR 방정식: \(\oint(u\,dx - v\,dy) = \iint(-v_x - u_y) = 0\), 허수부도 같음.)
  • Cauchy 적분 공식: 같은 조건에서 \(z_0\)이 \(C\) 안쪽이면 \(f(z_0) = \frac{1}{2\pi i}\oint_C\frac{f(z)}{z - z_0}dz\). 경계값이 안쪽 값을 모두 정합니다.
  • 유수 정리: \(f\)가 \(C\) 안쪽의 고립 특이점 \(z_1, \dots, z_k\)를 빼고 해석적이면 \(\oint_Cf\,dz = 2\pi i\sum\text{Res}(f, z_j)\). 유수는 특이점 근처 Laurent 급수 \(\sum_{n=-\infty}^\infty a_n(z - z_0)^n\)의 \(a_{-1}\) (04-01 카드에서 \(\frac{1}{z - z_0}\) 항만 \(2\pi i\)를 남기므로).

유수 계산: 단순극(1차 극) \(\text{Res}(f, z_0) = \lim_{z\to z_0}(z - z_0)f(z)\). \(f = \frac pq\), \(q(z_0) = 0\), \(q'(z_0) \ne 0\)이면 \(\frac{p(z_0)}{q'(z_0)}\). \(m\)차 극이면 \(\frac{1}{(m-1)!}\lim\frac{d^{m-1}}{dz^{m-1}}[(z - z_0)^mf]\).

(가) \(\oint_{|z|=2}\frac{e^z}{z - 1}dz\) (나) \(\oint_{|z|=2}\frac{z}{(z - 1)(z + 3)}dz\) (다) \(\oint_{|z|=1}\frac{\sin z}{z^4}dz\)

풀이

  1. (가) \(z_0 = 1\)이 원 안. \(f = e^z\)는 해석적이므로 Cauchy 적분 공식: \(2\pi ie^1 = 2\pi ei\).
    \(\oint\frac{f}{z - z_0} = 2\pi if(z_0)\).
  2. (나) 특이점 1 (안), −3 (밖, \(|-3| > 2\)). \(\text{Res}(1) = \lim_{z\to1}\frac{z}{z + 3} = \frac14\).
    원 밖의 특이점은 세지 않는다.
  3. 적분 \(= 2\pi i\cdot\frac14 = \frac{\pi i}{2}\).
    유수 정리.
  4. (다) Laurent 급수: \(\frac{\sin z}{z^4} = \frac{1}{z^4}\left(z - \frac{z^3}{6} + \frac{z^5}{120} - \cdots\right) = \frac{1}{z^3} - \frac{1}{6z} + \frac{z}{120} - \cdots\).
    공통1 8-05의 Maclaurin 급수를 \(z^4\)로 나눔.
  5. \(a_{-1} = -\frac16\). 적분 \(= 2\pi i\left(-\frac16\right) = -\frac{\pi i}{3}\).
    3차 극 공식보다 급수가 빠르다.

의미

복소 적분이 특이점의 정보(유수) 하나로 줄어듭니다. 원의 크기나 모양을 바꿔도 같은 특이점을 둘러싸면 값이 같습니다. Cauchy 적분 공식을 \(z_0\)로 미분하면 \(f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint\frac{f}{(z - z_0)^{n+1}}dz\)라서, 한 번 복소 미분 가능하면 무한 번 미분 가능합니다. 실수 함수와 크게 다른 점입니다(공통1 3-01의 \(x^2\sin\frac1x\)는 한 번만 미분 가능했음).

검산

(나) 부분분수 \(\frac{z}{(z-1)(z+3)} = \frac{1/4}{z - 1} + \frac{3/4}{z + 3}\). 원 안에서 둘째 항은 해석적이라 적분 0, 첫째 항은 \(\frac14\cdot2\pi i\). 일치합니다. (다) 3차 극 공식: \(\frac{1}{3!}\frac{d^3}{dz^3}\sin z\Big|_0 = \frac{-\cos0}{6} = -\frac16\). 일치합니다.

5.4.3

실습원을 옮기며 유수 정리 확인하기

실습 · 닫힌 경로 적분과 극

다루는 성취기준 [공통9-05-04] [공통9-04-02]

목표

복소평면에서 원을 옮기고 크기를 바꿔 \(\oint f\,dz\)를 수치로 계산하고, 그 값이 원 안에 든 극의 유수 합에 \(2\pi i\)를 곱한 것과 같음을 확인합니다. 원 안에 극이 없으면 0(코시 적분 정리)입니다. 성취기준 [공통9-05-04], [공통9-04-02].

준비

배경의 진한 정도는 \(|f(z)|\)의 크기, 점은 극(원 안이면 빨강)입니다. 주황 원이 적분 경로이고, 원의 중심은 그림을 눌러 옮깁니다. 적분은 원을 4000조각으로 나눠 계산합니다.

절차

  1. \(\frac{1}{z^2 + 1}\)에서 원이 \(i\)만 감싸게, \(-i\)만 감싸게, 둘 다 감싸게, 아무것도 감싸지 않게 놓고 적분값을 기록한다.
  2. 5.4절 예제 \(\frac{4 - 3z}{z^2 - z}\)를 반지름 2인 원(중심 0)과 반지름 0.5인 원으로 계산한다.
  3. \(\frac{e^z}{z^2}\)에서 0을 감싼 원의 크기를 바꿔도 값이 같은지 본다.
  4. 원이 극 바로 위를 지나가게 하면 수치가 어떻게 되는지 본다.

기대 결과

  • \(i\)만: \(\pi\). \(-i\)만: \(-\pi\). 둘 다: 0(유수가 지워짐). 아무것도: 0.
  • 예제: 반지름 2이면 \(-6\pi i\), 0.5이면 \(-8\pi i\).
  • \(\frac{e^z}{z^2}\): 크기와 상관없이 \(2\pi i\)(유수 1). 경로를 바꿔도 극을 넘지 않으면 값이 같다.
  • 원이 극 위를 지나면 값이 매우 크게 흔들린다. 적분이 정의되지 않기 때문이다.

분석

  1. \(\frac{1}{z^2 + 1}\)의 두 극을 모두 감싼 원의 적분이 0인 것은 \(\int_{-\infty}^\infty\frac{dx}{1 + x^2} = \pi\)를 구할 때 왜 위쪽 반원만 써야 하는지와 어떻게 연결되나요?
  2. \(\frac{1}{z^4 + 1}\)의 위쪽 두 극의 유수를 더해 \(2\pi i\)를 곱하면 \(\int_{-\infty}^\infty\frac{dx}{1 + x^4}\)를 얻습니다. 원을 위쪽 두 극만 감싸게 놓고 값을 읽어 \(\frac{\pi}{\sqrt2}\)와 비교해 보세요.
