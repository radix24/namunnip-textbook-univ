5.2.1음의 거듭제곱이 필요한 이유

\(f\)가 \(z_0\)에서 해석적이지 않으면 \(z_0\) 중심의 테일러 급수를 쓸 수 없습니다. 예를 들어 \(\frac{e^z}{z^2}\)은 0에서 정의되지 않지만, \(e^z\)의 급수를 \(z^2\)으로 나누면

\[\frac{e^z}{z^2} = \frac{1}{z^2} + \frac{1}{z} + \frac{1}{2!} + \frac{z}{3!} + \cdots \quad (z \ne 0)\]

처럼 음의 거듭제곱을 포함한 급수가 됩니다. 이런 급수를 로랑 급수라 합니다.

정리 5.2.1 (로랑 정리)

\(f\)가 고리 모양 영역 \(r < |z - z_0| < R\)에서 해석적이면, 그 영역에서

\[f(z) = \sum_{n=0}^\infty a_n(z - z_0)^n + \sum_{n=1}^\infty\frac{b_n}{(z - z_0)^n}.\]

음의 거듭제곱 부분을 주부(principal part)라 하며, 특이점의 성질을 알려 줍니다(5.3절). 특히 \(\frac{1}{z - z_0}\)의 계수 \(b_1\)이 5.4절의 유수가 됩니다. 계수를 적분 공식으로 구할 수도 있지만, 실제로는 이미 아는 급수(등비급수, \(e^z\) 등)를 변형해서 구합니다.

5.2.2영역에 따라 다른 전개

예제 5.2.2

\(f(z) = \frac{1}{1 - z}\)을 (가) \(|z| < 1\) (나) \(|z| > 1\)에서 \(z\)의 거듭제곱으로 전개하여라.

풀이. (가) 등비급수 \(\sum_{n=0}^\infty z^n\). (나) \(|z| > 1\)이면 \(\left|\frac1z\right| < 1\)이므로 \(\frac1z\)에 대한 등비급수를 만듭니다.

\[\frac{1}{1 - z} = -\frac{1}{z}\cdot\frac{1}{1 - \frac1z} = -\frac1z - \frac{1}{z^2} - \frac{1}{z^3} - \cdots\]

같은 함수인데 어느 고리에서 전개하느냐에 따라 급수가 다릅니다. 요령: "작은 쪽을 분자에 둔 비"를 등비급수의 공비로 삼습니다.

예제 5.2.3

\(e^{1/z}\)을 \(z \ne 0\)에서 전개하여라.

풀이. \(e^w = \sum\frac{w^n}{n!}\)에 \(w = \frac1z\)을 넣으면 \(e^{1/z} = 1 + \frac1z + \frac{1}{2!z^2} + \frac{1}{3!z^3} + \cdots\). 음의 거듭제곱이 끝없이 이어집니다.

요약
  1. 로랑 급수: 고리 영역에서 양·음의 거듭제곱으로 전개.
  2. 음의 거듭제곱 부분(주부)이 특이점의 성질을 결정한다. \(b_1\)이 유수.
  3. 고리가 다르면 전개도 다르다.

5.2.3연습문제

기본

  1. \(\frac{\sin z}{z^3}\)을 \(z \ne 0\)에서 전개하여라.
    답

    \(\frac{1}{z^2} - \frac{1}{3!} + \frac{z^2}{5!} - \cdots\).

응용

  1. \(\frac{1}{z(1 - z)}\)을 \(0 < |z| < 1\)에서 전개하여라.
    답

    \(\frac1z(1 + z + z^2 + \cdots) = \frac1z + 1 + z + z^2 + \cdots\).
