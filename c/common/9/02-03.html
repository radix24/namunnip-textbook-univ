2.3.1문제

길이 \(L\)인 줄의 양 끝이 고정되어 있고, 처음 모양 \(f(x)\)로 당겼다가 놓았다고 합시다(처음 속도 \(g(x)\)).

\[u_{tt} = c^2u_{xx}, \quad u(0, t) = u(L, t) = 0, \quad u(x, 0) = f(x), \quad u_t(x, 0) = g(x).\]

2.3.21단계: 변수분리

해를 "위치만의 함수 × 시간만의 함수" \(u = F(x)G(t)\)로 놓아 봅니다. 넣으면 \(FG'' = c^2F''G\), 양변을 \(c^2FG\)로 나누면

\[\frac{G''}{c^2G} = \frac{F''}{F}.\]

왼쪽은 \(t\)만의 식, 오른쪽은 \(x\)만의 식인데 언제나 같으므로, 둘 다 같은 상수 \(-k^2\)여야 합니다. 그래서 상미분방정식 두 개가 됩니다.

\[F'' + k^2F = 0, \qquad G'' + c^2k^2G = 0.\]

2.3.32단계: 경계 조건 → 고유함수

\(u(0, t) = u(L, t) = 0\)에서 \(F(0) = F(L) = 0\)입니다. 이것은 공통8 6.3절의 고유값 문제이고, 0이 아닌 해는 \(k = \frac{n\pi}{L}\)일 때 \(F_n = \sin\frac{n\pi x}{L}\)뿐입니다. 그러면 \(G'' + \lambda_n^2G = 0\) (\(\lambda_n = \frac{cn\pi}{L}\))에서 \(G_n = B_n\cos\lambda_nt + B_n^*\sin\lambda_nt\)입니다.

해 \(u_n = (B_n\cos\lambda_nt + B_n^*\sin\lambda_nt)\sin\frac{n\pi x}{L}\)은 줄의 \(n\)번째 고유 진동입니다. \(n = 1\)이 기본음, \(n = 2, 3, \dots\)이 배음이고, 진동수 \(\frac{\lambda_n}{2\pi} = \frac{cn}{2L}\)은 기본 진동수의 정수배입니다. 그래서 현악기의 소리가 조화롭게 들립니다.

2.3.43단계: 중첩과 초기 조건 → 푸리에 급수

중첩 원리로 모든 고유 진동을 더합니다.

\[u(x, t) = \sum_{n=1}^\infty(B_n\cos\lambda_nt + B_n^*\sin\lambda_nt)\sin\frac{n\pi x}{L}.\]

\(t = 0\)이면 \(u(x, 0) = \sum B_n\sin\frac{n\pi x}{L} = f(x)\), 곧 \(B_n\)은 \(f\)의 반구간 사인 급수 계수입니다. 마찬가지로 \(u_t(x, 0) = g\)에서 \(B_n^*\)을 정합니다.

\[B_n = \frac2L\int_0^Lf(x)\sin\frac{n\pi x}{L}dx, \qquad B_n^* = \frac{2}{cn\pi}\int_0^Lg(x)\sin\frac{n\pi x}{L}dx.\]
예제 2.3.1

\(L = \pi\), \(c = 1\), \(f(x) = \sin x + 0.5\sin3x\), \(g = 0\)이면?

풀이. \(f\)가 이미 사인 급수이므로 \(B_1 = 1\), \(B_3 = 0.5\), 나머지 0. \(u = \cos t\sin x + 0.5\cos3t\sin3x\). 기본음과 셋째 배음이 섞인 진동입니다.

요약
  1. \(u = FG\)로 놓으면 상수 \(-k^2\)로 두 상미분방정식이 된다.
  2. 경계 조건 → 고유함수 \(\sin\frac{n\pi x}{L}\), 고유 진동수 \(\frac{cn}{2L}\).
  3. 중첩한 뒤 초기 조건에 반구간 사인 급수를 쓴다.

2.3.5연습문제

기본

  1. 길이 0.65 m, 파동 속력 \(c = 286\) m/s인 줄의 기본 진동수는?
    답

    \(\frac{c}{2L} = \frac{286}{1.3} = 220\) Hz.

2.3.2

예제변수분리법과 d'Alembert 공식으로 파동방정식 풀기

정상파의 합 · 진행파의 합 · 튕긴 줄

다루는 성취기준 [공통9-02-03]

두 가지 풀이

  • 변수분리(유한한 줄, 양 끝 고정 \(u(0,t) = u(L,t) = 0\)): 02-05 카드와 같은 고유값 문제에서 \(X_n = \sin\frac{n\pi x}{L}\). 시간 부분은 \(T'' = -c^2\lambda_nT\)라 진동: \(T_n = a_n\cos\omega_nt + b_n\sin\omega_nt\), \(\omega_n = \frac{n\pi c}{L}\). \[u = \sum_{n=1}^\infty\left(a_n\cos\omega_nt + b_n\sin\omega_nt\right)\sin\frac{n\pi x}{L}.\] 처음 모양 \(f\)의 사인 계수가 \(a_n\), 처음 속도 \(g\)의 사인 계수가 \(\omega_nb_n\).
  • d'Alembert(무한한 줄): \(\xi = x - ct\), \(\eta = x + ct\)로 바꾸면 \(u_{\xi\eta} = 0\)이 되어 \(u = F(x - ct) + G(x + ct)\). 초기 조건을 맞추면 \[u(x, t) = \frac{f(x - ct) + f(x + ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct}g(s)\,ds.\]

두 그림은 같은 것을 다르게 봅니다. 변수분리는 "정상파(제자리 진동)들의 합", d'Alembert는 "반대로 가는 두 진행파의 합"입니다. 정상파 하나 \(\sin kx\cos\omega t\)는 \(\frac12[\sin(kx - \omega t) + \sin(kx + \omega t)]\)로 두 진행파의 합이기도 합니다(공통3 6-03).

먼저 예측

긴 줄의 한 점을 삼각형 모양으로 들어 올렸다가 가만히 놓으면, 그 삼각형은 어떻게 될까요?

예측 확인

높이가 절반인 삼각형 두 개로 갈라져 양쪽으로 속력 \(c\)로 달려갑니다. d'Alembert 공식의 \(\frac{f(x - ct) + f(x + ct)}{2}\) 그대로입니다.

길이 \(L = \pi\), \(c = 1\)인 양 끝 고정 줄을 \(f(x) = \sin x + 0.5\sin3x\) 모양으로 당겼다가 가만히 놓았습니다(\(g = 0\)). \(u(x, t)\)를 구하고, d'Alembert 공식으로 같은 결과가 나오는지 확인하세요.

풀이

  1. \(f\)가 이미 사인 급수 꼴: \(a_1 = 1\), \(a_3 = 0.5\), 나머지 0. \(g = 0\)이라 \(b_n = 0\).
    계수를 적분할 필요가 없다.
  2. \(\omega_n = n\): \(u = \sin x\cos t + 0.5\sin3x\cos3t\).
    각 정상파가 제 진동수로 진동.
  3. d'Alembert: \(\frac12[f(x - t) + f(x + t)]\). \(\frac12[\sin(x - t) + \sin(x + t)] = \sin x\cos t\).
    삼각함수의 합 → 곱.
  4. 같은 방법으로 \(\frac12[\sin3(x - t) + \sin3(x + t)] = \sin3x\cos3t\). 두 방법이 같다.
    무한한 줄의 식을 쓸 수 있는 이유: \(f\)를 기함수·주기 \(2\pi\)로 확장하면 양 끝 0 조건이 저절로 유지된다.

의미

열방정식과 달리 높은 진동수 성분이 줄지 않고 영원히 진동합니다(감쇠 없음). 그래서 파동은 모양을 기억하고, 열은 잊습니다. 진동수 \(\omega_n = \frac{n\pi c}{L}\)가 기본 진동수의 정수배라 줄 악기의 소리는 화음이 맞는 배음으로 이루어집니다(공통3 6-03, \(f_n = \frac{nc}{2L}\)). 줄을 어디서 퉁기느냐에 따라 계수 \(a_n\)이 달라져 음색이 바뀝니다.

검산

\(t = 0\): \(u = \sin x + 0.5\sin3x = f\). \(u_t(x, 0) = 0\). 양 끝에서 \(\sin0 = \sin\pi = \sin3\pi = 0\). 주기: \(t = 2\pi\)에 두 성분이 모두 한 바퀴 돌아 처음 모양으로 돌아옵니다.
