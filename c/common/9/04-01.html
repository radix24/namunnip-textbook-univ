4.1.1정의와 계산

복소평면의 곡선 \(C\)를 \(z(t) = x(t) + iy(t)\), \(a \le t \le b\)로 나타내면, 복소 선적분은 공통2의 선적분처럼 곡선을 잘게 나누어 \(f(z)\Delta z\)를 더한 것의 극한입니다. 계산은 매개변수로 바꾸어 합니다.

정리 4.1.1 \[\int_Cf(z)\,dz = \int_a^bf(z(t))\,\dot z(t)\,dt, \qquad \dot z = \frac{dz}{dt}.\]

또 \(f\)가 해석적이고 \(F' = f\)인 \(F\)가 있으면, 기본정리처럼 \(\int_Cf\,dz = F(z_1) - F(z_0)\)으로 끝점만 보면 됩니다(경로와 무관).

예제 4.1.2 (가장 중요한 적분)

단위원 \(C\)를 시계 반대 방향으로 한 바퀴 도는 경로에서 \(\oint_C\frac{dz}{z}\)를 구하여라.

풀이. \(z(t) = e^{it}\), \(0 \le t \le 2\pi\), \(\dot z = ie^{it}\).

\[\oint_C\frac{dz}{z} = \int_0^{2\pi}\frac{ie^{it}}{e^{it}}dt = \int_0^{2\pi}i\,dt = 2\pi i.\]

0이 아닙니다! \(\frac1z\)의 "부정적분" \(\ln z\)는 한 바퀴 돌면 \(2\pi i\)만큼 다른 값이 되기 때문입니다(3.6절). 같은 계산으로, 중심이 \(z_0\)인 원에서 \(\oint\frac{dz}{(z - z_0)^m}\)은 \(m = 1\)이면 \(2\pi i\), 다른 정수 \(m\)이면 0입니다. 이 결과가 4단원과 5단원 전체의 바탕입니다.

예제 4.1.3

\(\int_C\bar z\,dz\)를 (가) 0에서 \(1 + i\)까지의 선분 (나) 0 → 1 → \(1 + i\)를 따라 구하여라.

풀이. (가) \(z = t + it\), \(\dot z = 1 + i\). \(\int_0^1(t - it)(1 + i)dt = \int_0^12t\,dt = 1\). (나) 0→1: \(z = t\), \(\int_0^1t\,dt = \frac12\). 1→\(1 + i\): \(z = 1 + it\), \(\int_0^1(1 - it)i\,dt = i + \frac12\). 합 \(1 + i\). 경로에 따라 값이 다릅니다. \(\bar z\)가 해석적이지 않기 때문입니다.

요약
  1. \(\int_Cf\,dz = \int f(z(t))\dot z\,dt\).
  2. \(\oint\frac{dz}{z - z_0} = 2\pi i\), 다른 거듭제곱은 0.
  3. 해석적이지 않으면 경로에 따라 값이 달라질 수 있다.

4.1.2연습문제

기본

  1. \(\int_Cz\,dz\)를 0에서 \(1 + i\)까지의 선분에서 구하고, 부정적분으로 확인하여라.
    답

    \(\int_0^1(1 + i)^2t\,dt = \frac{(1 + i)^2}{2} = i\). \(\left[\frac{z^2}{2}\right]_0^{1+i} = i\).

  1. 경로를 매개변수로 나타내 복소 선적분을 계산할 수 있다.

4.1.2

예제복소 선적분을 매개화하여 계산하기

∫_C f(z)dz = ∫ f(z(t))z′(t)dt · ∮dz/z = 2πi · 문제 해결 전략

다루는 성취기준 [공통9-04-01]

정의와 계산법

곡선 \(C\)를 \(z(t) = x(t) + iy(t)\), \(a \le t \le b\)로 매개화하면

\[\int_Cf(z)\,dz = \int_a^bf(z(t))\,z'(t)\,dt.\]

공통2 7-01의 벡터 선적분과 같은 생각이고, 실수부와 허수부로 나누면 실제로 두 개의 실수 선적분 \(\int(u\,dx - v\,dy) + i\int(v\,dx + u\,dy)\)입니다. 매개화를 바꿔도(방향이 같으면) 값은 같습니다.

문제 해결 전략 · 복소 적분
  1. 피적분함수가 경로를 포함하는 영역에서 해석적이고 영역에 구멍이 없으면, 닫힌 경로의 적분은 0(Cauchy 정리, 05-04 카드).
  2. 부정적분 \(F' = f\)가 있으면 \(\int_C f\,dz = F(\text{끝}) - F(\text{시작})\).
  3. 특이점을 둘러싸면 Cauchy 적분 공식이나 유수 정리(05-04 카드).
  4. 위가 모두 안 되면 매개화해서 직접 계산한다. 원은 \(z = z_0 + re^{it}\).

(가) 반지름 \(r\)인 원 \(|z| = r\) (반시계)에서 \(\oint z^n\,dz\) (\(n\)은 정수) (나) 0에서 \(1 + i\)까지 (i) 선분 (ii) 0 → 1 → \(1 + i\) 꺾은선을 따라 \(\int\bar z\,dz\)와 \(\int z\,dz\)

풀이

  1. (가) \(z = re^{it}\), \(dz = ire^{it}dt\), \(0 \le t \le 2\pi\). \(\oint z^ndz = \int_0^{2\pi}r^ne^{int}\cdot ire^{it}dt = ir^{n+1}\int_0^{2\pi}e^{i(n+1)t}dt\).
    원의 매개화.
  2. \(n \ne -1\)이면 \(\int_0^{2\pi}e^{i(n+1)t}dt = 0\) (한 바퀴 돈 진동). \(n = -1\)이면 \(\int_0^{2\pi}1\,dt = 2\pi\), 곧 \(\oint\frac{dz}{z} = 2\pi i\).
    반지름과 상관없다.
  3. (나) \(\int z\,dz\): \(z^2/2\)가 부정적분이라 두 경로 모두 \(\frac{(1+i)^2}{2} = i\).
    전략 2. 해석함수는 경로와 상관없다.
  4. \(\int\bar z\,dz\), 선분 \(z = (1 + i)t\): \(\int_0^1(1 - i)t(1 + i)\,dt = \int_0^12t\,dt = 1\).
    \(\bar z\)는 해석적이지 않아 직접 계산.
  5. 꺾은선: 0 → 1 (\(z = t\)): \(\int_0^1t\,dt = \frac12\). 1 → \(1 + i\) (\(z = 1 + it\), \(dz = i\,dt\)): \(\int_0^1(1 - it)i\,dt = i + \frac12\). 합 \(1 + i\). 선분의 값 1과 다르다.
    해석적이지 않으면 경로에 따라 다르다.

의미

(가)의 결과가 복소 적분 전체의 핵심입니다. \(z^n\)은 \(n \ne -1\)이면 부정적분 \(\frac{z^{n+1}}{n+1}\)이 있어 닫힌 경로에서 0이지만, \(\frac1z\)의 부정적분 \(\log z\)는 한 바퀴 돌면 \(2\pi i\)만큼 다른 값이 되는 다가함수라(03-06 카드) 0이 아닙니다. 다음 카드의 유수 정리는 "닫힌 경로의 적분 = \(\frac{1}{z - z_0}\) 항의 계수 × \(2\pi i\)"라는 이 사실을 일반화한 것입니다.

검산

(나) 두 경로가 둘러싼 삼각형에 Green 정리(공통2 7-03)를 쓰면 \(\oint\bar z\,dz = 2i\times\)넓이 \(= 2i\cdot\frac12 = i\). 꺾은선(반시계 방향의 앞부분) − 선분 = \((1 + i) - 1 = i\). 일치합니다.
