6.3지수함수와 삼각함수의 사상

6.3.1지수함수

\(w = e^z = e^xe^{iy}\)에서 \(|w| = e^x\), \(\arg w = y\)입니다. 실수부는 거리, 허수부는 각도가 됩니다.

  • 세로선 \(x = c\) → 원 \(|w| = e^c\).
  • 가로선 \(y = c\) → 원점에서 나가는 반직선 \(\arg w = c\).
  • 띠 \(0 < y < \pi\) → 위쪽 반평면.
  • 띠 \(-\pi < y \le \pi\) → 0을 뺀 평면 전체 (한 번씩).
  • 직사각형 \(a < x < b\), \(0 < y < \pi\) → 반 고리 \(e^a < |w| < e^b\), \(\text{Im}\,w > 0\).

\(e^z\)의 도함수는 0이 아니므로 어디서나 등각입니다. 가로선과 세로선이 직각으로 만나듯 반직선과 원도 직각으로 만납니다.

역함수 \(w = \text{Ln}\,z\)는 반대로 움직입니다. 위쪽 반평면을 띠 \(0 < \text{Im}\,w < \pi\)로, 고리를 직사각형으로 펴 줍니다. 그래서 원형 영역의 문제를 직사각형 문제로 바꿀 때 씁니다.

6.3.2사인 함수

\(\sin z = \sin x\cosh y + i\cos x\sinh y\)입니다. 반무한 띠 \(-\frac\pi2 < x < \frac\pi2\), \(y > 0\)은 \(w = \sin z\)에 의해 위쪽 반평면으로 옮겨집니다. 띠의 경계(두 세로 반직선과 밑변)가 실수축 전체로 펼쳐집니다. 끝점 \(z = \pm\frac\pi2\)에서는 \((\sin z)' = \cos z = 0\)이라 등각이 아니며, 실제로 직각 모서리가 평각으로 펴집니다.

예제 6.3.1

띠 \(0 < y < \frac\pi2\)는 \(w = e^z\)에 의해 어디로 가는가?

풀이. 각이 \(0 < \arg w < \frac\pi2\)이고 거리는 모든 양수: 1사분면.

요약
  1. \(e^z\): 세로선 → 원, 가로선 → 반직선, 띠 → 반평면.
  2. \(\text{Ln}\,z\)는 그 반대. \(\sin z\): 반무한 띠 → 반평면.

6.3.3연습문제

기본

  1. \(w = e^z\)는 직선 \(x = 0\)을 어디로 보내는가?
    답

    단위원 \(|w| = 1\).

  2. \(w = \text{Ln}\,z\)는 고리 \(1 < |z| < e\)를 어디로 보내는가?
    답

    직사각형 \(0 < u < 1\), \(-\pi < v \le \pi\).
