  • 복소 지수·삼각함수 (3.5절), 복소 로그 (3.6절), 등각사상 (6.1절).

6.3.1지수함수

\(w = e^z = e^xe^{iy}\)에서 \(|w| = e^x\), \(\arg w = y\)입니다. 실수부는 거리, 허수부는 각도가 됩니다.

  • 세로선 \(x = c\) → 원 \(|w| = e^c\).
  • 가로선 \(y = c\) → 원점에서 나가는 반직선 \(\arg w = c\).
  • 띠 \(0 < y < \pi\) → 위쪽 반평면.
  • 띠 \(-\pi < y \le \pi\) → 0을 뺀 평면 전체 (한 번씩).
  • 직사각형 \(a < x < b\), \(0 < y < \pi\) → 반 고리 \(e^a < |w| < e^b\), \(\text{Im}\,w > 0\).

\(e^z\)의 도함수는 0이 아니므로 어디서나 등각입니다. 가로선과 세로선이 직각으로 만나듯 반직선과 원도 직각으로 만납니다.

역함수 \(w = \text{Ln}\,z\)는 반대로 움직입니다. 위쪽 반평면을 띠 \(0 < \text{Im}\,w < \pi\)로, 고리를 직사각형으로 펴 줍니다. 그래서 원형 영역의 문제를 직사각형 문제로 바꿀 때 씁니다.

6.3.2사인 함수

\(\sin z = \sin x\cosh y + i\cos x\sinh y\)입니다. 반무한 띠 \(-\frac\pi2 < x < \frac\pi2\), \(y > 0\)은 \(w = \sin z\)에 의해 위쪽 반평면으로 옮겨집니다. 띠의 경계(두 세로 반직선과 밑변)가 실수축 전체로 펼쳐집니다. 끝점 \(z = \pm\frac\pi2\)에서는 \((\sin z)' = \cos z = 0\)이라 등각이 아니며, 실제로 직각 모서리가 평각으로 펴집니다.

예제 6.3.1

띠 \(0 < y < \frac\pi2\)는 \(w = e^z\)에 의해 어디로 가는가?

풀이. 각이 \(0 < \arg w < \frac\pi2\)이고 거리는 모든 양수: 1사분면.

요약
  1. \(e^z\): 세로선 → 원, 가로선 → 반직선, 띠 → 반평면.
  2. \(\text{Ln}\,z\)는 그 반대. \(\sin z\): 반무한 띠 → 반평면.

6.3.3연습문제

기본

  1. \(w = e^z\)는 직선 \(x = 0\)을 어디로 보내는가?
    답

    단위원 \(|w| = 1\).

  2. \(w = \text{Ln}\,z\)는 고리 \(1 < |z| < e\)를 어디로 보내는가?
    답

    직사각형 \(0 < u < 1\), \(-\pi < v \le \pi\).

6.3.2

실습복소함수로 격자 옮기기

실습 · 등각사상

다루는 성취기준 [공통9-06-01] [공통9-06-02] [공통9-06-03]

목표

\(z\)평면의 직사각형 격자를 여러 복소함수로 옮겨 그 모양을 보고, 해석함수가 \(f' \ne 0\)인 곳에서 직각을 직각으로 옮김(등각)을 확인합니다. 반평면, 띠, 원판 사이를 옮기는 대표 사상을 익힙니다. 성취기준 [공통9-06-01]~[공통9-06-03].

준비

위 그림은 \(z\)평면(가로선 파랑, 세로선 주황), 아래 그림은 \(w = f(z)\)로 옮긴 모습입니다. 직사각형의 범위는 조절기나 단추로 바꿉니다.

절차

  1. \(w = z^2\)에서 "1사분면 일부"를 옮겨 위쪽 반평면 쪽으로 펼쳐지는지 보고, "원점 포함"에서 원점 근처의 각을 본다.
  2. \(w = e^z\)에서 "띠"를 옮겨 가로선이 반직선, 세로선이 원이 되는지 본다.
  3. \(w = \frac{z - i}{z + i}\)에서 "위쪽 반평면 일부"가 단위원 안으로 들어가는지 본다.
  4. \(w = z + \frac1z\)에서 원점 둘레의 격자가 어떻게 되는지 본다.

기대 결과

  • 옮긴 그림에서도 파란 선과 주황 선이 직각으로 만난다. 예외는 \(f' = 0\)인 점(\(z^2\)의 원점, \(\sin z\)의 \(\pm\frac\pi2\))뿐이다.
  • \(e^z\): 띠 \(0 < y < \pi\)가 위쪽 반평면으로.
  • 일차분수변환: 위쪽 반평면이 단위원판으로, 직선과 원이 원(또는 직선)으로.

분석

  1. 6.4절에서 1사분면의 온도 문제를 \(w = z^2\)으로 반평면 문제로 바꿨습니다. 이 장치의 그림으로 경계(양의 \(x\)축, 양의 \(y\)축)가 어디로 가는지 확인해 보세요.
  2. 격자의 작은 정사각형이 옮겨진 뒤에도 거의 정사각형으로 보이는 이유(국소적으로 회전과 확대)를 \(f'(z)\)로 설명해 보세요.

더 해 보기

주코프스키 사상 \(w = z + \frac1z\)은 중심을 조금 옮긴 원을 비행기 날개 모양으로 바꿉니다. 원 둘레의 유체 흐름을 이 사상으로 옮겨 날개 둘레의 흐름을 계산했던 역사를 찾아보세요.
