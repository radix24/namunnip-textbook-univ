2.4.1새 변수로 바꾸기

\(v = x + ct\), \(w = x - ct\)로 변수를 바꾸면 연쇄법칙으로 \(u_{tt} = c^2u_{xx}\)가 \(u_{vw} = 0\)으로 단순해집니다. 이 식은 \(w\)로 적분하고 \(v\)로 적분하면 바로 풀립니다.

정리 2.4.1 (달랑베르 해)

파동방정식의 일반해는 \(u(x, t) = \phi(x + ct) + \psi(x - ct)\)이다(\(\phi, \psi\)는 임의의 두 번 미분 가능한 함수).

\(\psi(x - ct)\)는 모양 \(\psi\)가 속력 \(c\)로 오른쪽으로 이동하는 파동입니다(시각 \(t\)에 \(x\)에서 보는 값이 처음 \(x - ct\)에 있던 값). \(\phi(x + ct)\)는 왼쪽으로 이동합니다. 그래서 \(c\)가 파동의 속력입니다.

2.4.2초기 조건 맞추기

\(u(x, 0) = f(x)\), \(u_t(x, 0) = g(x)\)를 넣어 정리하면

\[u(x, t) = \frac12[f(x + ct) + f(x - ct)] + \frac{1}{2c}\int_{x - ct}^{x + ct}g(s)\,ds.\]

처음 속도가 0이면(\(g = 0\)) 처음 모양 \(f\)가 반으로 나뉘어 왼쪽과 오른쪽으로 같은 속력으로 퍼져 나갑니다. 줄 가운데를 집어 올렸다 놓으면 봉우리가 둘로 갈라져 양쪽으로 가는 모습입니다.

예제 2.4.2

\(c = 1\), \(f(x) = \frac{1}{1 + x^2}\), \(g = 0\)일 때 \(u(x, t)\)는?

풀이. \(u = \frac12\left[\frac{1}{1 + (x + t)^2} + \frac{1}{1 + (x - t)^2}\right]\). \(t = 5\)이면 \(x = \pm5\)에 높이 약 \(\frac12\)인 봉우리 두 개가 있습니다.

양 끝이 고정된 유한한 줄에서는, 2.3절의 푸리에 급수 해를 삼각함수 공식으로 정리하면 같은 꼴(끝에서 반사되어 되돌아오는 두 파동)이 됩니다.

요약
  1. \(u = \phi(x + ct) + \psi(x - ct)\): 왼쪽과 오른쪽으로 가는 두 파동.
  2. \(u = \frac12[f(x + ct) + f(x - ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct}g\).

2.4.3연습문제

기본

  1. \(c = 2\), \(f = 0\), \(g(x) = \cos x\)일 때 해를 구하여라.
    답

    \(\frac14[\sin(x + 2t) - \sin(x - 2t)] = \frac12\cos x\sin2t\).

2.4.2

실습퉁긴 줄의 달랑베르 해

실습 · 두 진행파와 고정 끝의 반사

다루는 성취기준 [공통9-02-04]

목표

양 끝이 고정된 줄을 퉁겼을 때의 운동 \(u = \frac12[f(x - ct) + f(x + ct)]\)을 애니메이션으로 보고, 처음 모양이 반씩 나뉘어 양쪽으로 진행하고 끝에서 뒤집혀 반사되는 것을 확인합니다. 성취기준 [공통9-02-04].

준비

파란 선이 줄의 모양, 점선은 오른쪽(주황)과 왼쪽(회색)으로 가는 두 반쪽입니다. 고정 끝 조건을 맞추려고 처음 모양을 홀함수로, 주기 \(2L\)로 늘인 \(f\)를 씁니다.

절차

  1. 좁은 봉우리로 재생해 봉우리가 둘로 나뉘어 양 끝으로 가는 모습과 반사 후 뒤집히는 모습을 본다.
  2. \(t = 1\)과 \(t = 2\)에서 줄 모양을 처음 모양과 비교한다.
  3. 삼각형(퉁김)으로 바꿔 줄의 모양이 사다리꼴로 변하는 것을 본다.

기대 결과

  • 봉우리는 높이가 절반인 두 봉우리로 나뉘어 속력 \(c\)로 반대로 간다. 고정 끝에서 위아래가 뒤집혀 돌아온다.
  • \(t = 1\)(반주기)이면 처음 모양을 뒤집고 좌우를 바꾼 모양, \(t = 2\)(한 주기)이면 처음 모양 그대로.
  • 퉁긴 줄은 꺾인 점들이 움직이며 사다리꼴 모양을 거친다.

분석

  1. 2.3절의 변수분리 해(사인 함수의 무한합)와 이 해는 같은 운동입니다. 어느 쪽이 꺾인 모양을 더 정확하게 나타내기 쉬울까요?
  2. 왜 끝에서 반사될 때 뒤집힐까요? 홀함수 확장과 \(u(0, t) = 0\)의 관계를 설명해 보세요.
