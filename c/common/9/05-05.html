5.5.1삼각함수의 적분

\(\int_0^{2\pi}F(\cos\theta, \sin\theta)\,d\theta\)는 \(z = e^{i\theta}\)로 놓으면 단위원 위의 적분이 됩니다.

\[\cos\theta = \frac12\left(z + \frac1z\right), \quad \sin\theta = \frac{1}{2i}\left(z - \frac1z\right), \quad d\theta = \frac{dz}{iz}.\]
예제 5.5.1

\(\displaystyle\int_0^{2\pi}\frac{d\theta}{\sqrt2 - \cos\theta}\)를 구하여라.

풀이. 대입하고 정리하면

\[\oint\frac{1}{\sqrt2 - \frac12\left(z + \frac1z\right)}\cdot\frac{dz}{iz} = \frac{-2}{i}\oint\frac{dz}{z^2 - 2\sqrt2z + 1}.\]

분모의 근은 \(z = \sqrt2 \pm 1\)이고, 단위원 안에 있는 것은 \(\sqrt2 - 1\)뿐입니다. 유수는 \(\frac{1}{2z - 2\sqrt2}\Big|_{\sqrt2 - 1} = -\frac12\). 따라서

\[\frac{-2}{i}\cdot2\pi i\cdot\left(-\frac12\right) = 2\pi.\]

5.5.2무한 구간의 적분

\(\int_{-\infty}^\infty f(x)\,dx\)는 실수축의 구간 \([-R, R]\)과 위쪽 반원 \(S_R\)을 이은 닫힌 경로에서 유수 정리를 쓰고 \(R \to \infty\)로 보냅니다. \(f = \frac{p}{q}\)에서 분모의 차수가 분자보다 2 이상 높으면 반원 위의 적분은 0으로 가므로

정리 5.5.2 \[\int_{-\infty}^\infty f(x)\,dx = 2\pi i\sum(\text{위쪽 반평면에 있는 극의 유수}).\]

(실수축 위에는 극이 없어야 합니다.)

예제 5.5.3

\(\displaystyle\int_{-\infty}^\infty\frac{dx}{1 + x^2}\)을 유수로 구하여라.

풀이. 위쪽 반평면의 극은 \(i\)뿐이고 유수는 \(\frac{1}{2i}\) (5.4절). \(2\pi i\cdot\frac{1}{2i} = \pi\). 공통1에서 \(\arctan\)으로 구한 값과 같습니다. 유수 방법은 부정적분을 모를 때도 쓸 수 있다는 것이 장점입니다.

\(\int_{-\infty}^\infty\frac{\cos x}{1 + x^2}dx\) 같은 푸리에 적분(1단원)도 \(\frac{e^{iz}}{1 + z^2}\)의 유수로 계산합니다. \(i\)에서의 유수는 \(\frac{e^{-1}}{2i}\)이므로 값은 \(\frac\pi e\)입니다.

요약
  1. \(\int_0^{2\pi}\): \(z = e^{i\theta}\)로 단위원 적분으로 바꾼다.
  2. \(\int_{-\infty}^\infty\frac pq\) (차수 차 2 이상): 위쪽 반평면 유수의 합 \(\times2\pi i\).

5.5.3연습문제

기본

  1. \(\displaystyle\int_{-\infty}^\infty\frac{dx}{x^2 + 4}\)를 구하여라.
    답

    극 \(2i\), 유수 \(\frac{1}{4i}\). \(\frac\pi2\).

응용

  1. \(\displaystyle\int_{-\infty}^\infty\frac{dx}{(x^2 + 1)^2}\)을 구하여라.
    답

    \(i\)는 2위 극. \(\frac{d}{dz}(z + i)^{-2} = -2(z + i)^{-3}\), \(z = i\)에서 \(-\frac{2}{(2i)^3} = \frac{1}{4i}\). \(2\pi i\cdot\frac{1}{4i} = \frac\pi2\).

5.5.2

예제유수 정리로 실수 이상적분 계산하기

반원 경로 · 큰 호의 기여는 0 · ∫dx/(1+x²) · 삼각함수 적분

다루는 성취기준 [공통9-05-05]

방법

\(\int_{-\infty}^\infty f(x)\,dx\) (\(f\)는 유리함수, 분모 차수 ≥ 분자 차수 + 2, 실수축 위에 극이 없음)을 구하려면 실수축의 \([-R, R]\)과 위 반원 \(C_R\)을 이은 닫힌 경로에서 \(f(z)\)를 적분합니다.

  1. 유수 정리: \(\int_{-R}^Rf(x)\,dx + \int_{C_R}f(z)\,dz = 2\pi i\sum_{\text{위 반평면}}\text{Res}\).
  2. \(R \to \infty\)이면 큰 호의 적분은 0: 호 위에서 \(|f| \le \frac{M}{R^2}\), 호의 길이 \(\pi R\)이므로 \(\left|\int_{C_R}\right| \le \frac{M\pi}{R} \to 0\).
  3. 따라서 \(\int_{-\infty}^\infty f(x)\,dx = 2\pi i\sum_{\text{위 반평면}}\text{Res}\).

삼각함수의 한 주기 적분 \(\int_0^{2\pi}R(\cos\theta, \sin\theta)d\theta\)는 \(z = e^{i\theta}\)로 두어 단위원 위의 적분으로 바꿉니다: \(\cos\theta = \frac{z + z^{-1}}{2}\), \(d\theta = \frac{dz}{iz}\).

먼저 예측

\(\int_{-\infty}^\infty\frac{dx}{1 + x^2}\)는 공통1에서 \([\arctan x]_{-\infty}^\infty = \pi\)로 구했습니다. 실수 함수 \(\frac{1}{1 + x^2}\)은 어디서도 터지지 않는데, 복소 방법에서는 무엇이 이 값을 정할까요?

예측 확인

복소평면의 \(z = i\)에 있는 극입니다. 실수축에서는 보이지 않는 특이점이 실수 적분의 값을 정합니다(공통1 8-04의 수렴 반지름 1과 같은 이유).

(가) \(\displaystyle\int_{-\infty}^\infty\frac{dx}{1 + x^2}\) (나) \(\displaystyle\int_{-\infty}^\infty\frac{dx}{(x^2 + 1)(x^2 + 4)}\) (다) \(\displaystyle\int_0^{2\pi}\frac{d\theta}{2 + \cos\theta}\)

풀이

  1. (가) 극 \(\pm i\), 위 반평면은 \(i\). \(\text{Res}\left(\frac{1}{(z - i)(z + i)}, i\right) = \frac{1}{2i}\). 적분 \(= 2\pi i\cdot\frac{1}{2i} = \pi\).
    공통1의 결과와 같다.
  2. (나) 위 반평면 극 \(i, 2i\). \(\text{Res}(i) = \frac{1}{2i(i^2 + 4)} = \frac{1}{6i}\). \(\text{Res}(2i) = \frac{1}{((2i)^2 + 1)\cdot4i} = \frac{1}{-12i}\).
    \(\frac{p}{q'}\) 공식(05-04 카드), \(q = (z^2+1)(z^2+4)\)에서 다른 인수는 그대로.
  3. 적분 \(= 2\pi i\left(\frac{1}{6i} - \frac{1}{12i}\right) = 2\pi\cdot\frac{1}{12} = \frac\pi6\).
    합.
  4. (다) \(z = e^{i\theta}\): \(\oint_{|z|=1}\frac{1}{2 + \frac{z + z^{-1}}{2}}\cdot\frac{dz}{iz} = \oint\frac{2\,dz}{i(z^2 + 4z + 1)}\).
    분모에 \(2z\)를 곱해 정리.
  5. 극 \(z = -2 \pm\sqrt3\). 원 안은 \(-2 + \sqrt3 \approx -0.27\). 유수 \(\frac{2}{i(2z + 4)} = \frac{2}{i\cdot2\sqrt3} = \frac{1}{i\sqrt3}\). 적분 \(= 2\pi i\cdot\frac{1}{i\sqrt3} = \frac{2\pi}{\sqrt3}\).
    \(-2 - \sqrt3\)은 원 밖.

의미

실수 부정적분으로는 부분분수와 \(\arctan\)을 여러 번 써야 하는 적분이, 극의 유수 몇 개로 끝납니다. 물리학(전파 함수, 산란 이론)과 공학(역 Laplace 변환의 Bromwich 적분)에서 이 방법을 일상적으로 씁니다.

검산

(나) 부분분수 \(\frac{1}{(x^2+1)(x^2+4)} = \frac13\left(\frac{1}{x^2 + 1} - \frac{1}{x^2 + 4}\right)\), 적분 \(\frac13\left(\pi - \frac\pi2\right) = \frac\pi6\). 일치합니다. (다) 피적분함수는 \(\frac13\)과 1 사이라 적분은 \(\frac{2\pi}{3} \approx 2.09\)와 \(2\pi\) 사이: \(\frac{2\pi}{\sqrt3} \approx 3.63\). 맞습니다.
