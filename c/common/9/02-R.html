2.R.1

연습Fourier 급수 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-02-01] [공통9-02-02] [공통9-02-03] [공통9-02-04]

기함수·우함수 판정으로 계산을 줄이고, 불연속점의 값을 따로 확인하세요.

  1. 계산주기 \(2\pi\)인 \(f(x) = |x|\) (\(-\pi < x < \pi\))의 Fourier 급수를 구하세요. [02-01]

    힌트 1

    02-01 절: 우함수라 \(b_n = 0\).

    힌트 2

    02-02 카드 (나)의 코사인 급수와 비교.

    풀이

    \(|x|\)는 \(x\) (\(0 < x < \pi\))를 우함수로 확장한 것이라 02-02 (나)와 같습니다: \(|x| = \frac\pi2 - \frac4\pi\sum_{k}\frac{\cos(2k-1)x}{(2k-1)^2}\).

  2. 계산\(f(x) = 1\) (\(0 < x < \pi\))의 사인 반구간 급수를 구하세요. 어떤 함수의 급수와 같나요? [02-02]

    힌트 1

    기함수 확장은?

    힌트 2

    \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx\).

    풀이

    기함수 확장은 사각파라 02-01 카드와 같습니다: \(1 = \frac4\pi\sum_{\text{홀수 }n}\frac{\sin nx}{n}\) (\(0 < x < \pi\)).

  3. 개념문제 2의 급수에 \(x = 0\)을 넣으면 0이 나옵니다. \(f(0^+) = 1\)인데 왜 0인가요? \(x = \pi\)에서는? [02-03]

    힌트 1

    02-03 절: 점프에서 평균.

    힌트 2

    기함수 확장에서 \(x = 0\)의 좌우 극한은 \(-1\)과 1.

    풀이

    기함수로 확장한 함수는 \(x = 0\)에서 −1에서 1로 뜁니다. 급수는 평균 0으로 수렴합니다. \(x = \pi\)도 1에서 −1(다음 주기)로 뛰어 0. 원래 함수 \(f = 1\)은 \((0, \pi)\) 안에서만 급수와 같습니다.

  4. 판단한 학생이 "\(f(x) = x\) 사인 급수의 부분합을 200항까지 그렸는데 \(x = \pi\) 근처에서 3.7까지 올라가는 봉우리가 보인다. 계산이 틀린 것 같다"고 했습니다. 틀렸나요? [02-03]

    힌트 1

    기함수 확장은 \(x = \pi\)에서 \(\pi\)에서 \(-\pi\)로 뜁니다(점프 \(2\pi\)).

    힌트 2

    Gibbs 넘침은 점프의 약 9%.

    풀이

    틀리지 않았습니다. 점프 \(2\pi \approx 6.28\)의 약 8.95% = 0.56만큼 \(\pi\)를 넘어 약 3.70까지 오르는 것이 Gibbs 현상입니다. 항을 늘려도 높이는 줄지 않고 봉우리만 좁아집니다.

  5. 계산문제 1의 급수에 Parseval을 써서 \(\sum\frac{1}{(2k-1)^4}\)을 구하세요. [02-04]

    힌트 1

    \(\frac1\pi\int_{-\pi}^\pi x^2dx = \frac{2\pi^2}{3}\).

    힌트 2

    \(\frac{a_0^2}{2} = \frac{\pi^2}{2}\), \(a_n^2 = \frac{16}{\pi^2n^4}\).

    풀이

    \(\frac{2\pi^2}{3} = \frac{\pi^2}{2} + \frac{16}{\pi^2}\sum\frac{1}{(2k-1)^4}\) → \(\sum = \frac{\pi^2}{16}\cdot\frac{\pi^2}{6} = \frac{\pi^4}{96}\). 검산: 전체 \(\frac{\pi^4}{90}\)의 \(\frac{15}{16}\) (짝수 항이 \(\frac{1}{16}\)).

  6. 판단"매끄러운 함수일수록 Fourier 계수가 빨리 줄어든다." 사각파, \(|x|\), 그리고 \(e^{\cos x}\) 같은 무한히 매끄러운 주기 함수로 이 말을 확인하세요. [02-01, 02-03]

    힌트 1

    사각파 \(\frac1n\), \(|x|\)은 \(\frac{1}{n^2}\).

    힌트 2

    부분적분 한 번마다 \(\frac1n\)이 하나씩 나옵니다.

    풀이

    맞습니다. 사각파(불연속): \(\frac1n\). \(|x|\) (연속, 도함수가 불연속): \(\frac{1}{n^2}\). 매끄러운 주기 함수는 모든 \(n\)보다 빠르게(지수적으로) 줄어듭니다. 계수 공식을 부분적분할 때마다 \(\frac1n\)이 나오고 경계항이 주기성으로 사라지기 때문에, 미분 가능한 횟수만큼 빨리 줄어듭니다. 그래서 매끄러운 신호는 적은 수의 주파수로 압축할 수 있습니다.
