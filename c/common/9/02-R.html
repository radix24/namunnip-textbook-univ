2.R.1

연습편미분방정식 모델링 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-02-02] [공통9-02-05] [공통9-02-01]

식을 세우기 전에 모형의 가정을 한 줄로 적으세요.

  1. 계산줄 위에 공기 저항(속도에 비례, 단위 길이당 \(-\gamma u_t\))이 있을 때 파동방정식은 어떻게 바뀌나요? [02-02]

    힌트 1

    02-02 절의 4단계에 힘을 하나 더합니다.

    힌트 2

    조각에 작용하는 저항 \(-\gamma u_t\Delta x\).

    풀이

    \(\rho u_{tt} = Tu_{xx} - \gamma u_t\), 곧 \(u_{tt} + \frac\gamma\rho u_t = c^2u_{xx}\) (감쇠 파동방정식, 전신 방정식). 공통8 3-01의 감쇠 진동을 줄 전체로 늘린 것입니다.

  2. 계산막대 안에서 단위 부피당 일정한 열 \(Q\) (W/m³)가 생깁니다(전류에 의한 줄열). 열방정식은? [02-05]

    힌트 1

    02-05 절의 에너지 수지에 "안에서 생긴 열"을 더합니다.

    힌트 2

    \(\rho cu_t = ku_{xx} + Q\).

    풀이

    \(u_t = \alpha^2u_{xx} + \frac{Q}{\rho c}\). 양 끝 0 ℃이면 정상 상태 \(ku'' = -Q\), \(u = \frac{Q}{2k}x(L - x)\): 가운데가 가장 뜨거운 포물선.

  3. 개념열방정식과 파동방정식은 각각 초기 조건이 몇 개 필요한가요? 그 이유를 시간 미분의 차수로 설명하세요. [02-01]

    힌트 1

    02-01 절.

    힌트 2

    상미분방정식에서 \(n\)계면 초기값 \(n\)개.

    풀이

    열방정식은 \(u_t\) (1계)라 처음 온도 분포 하나, 파동방정식은 \(u_{tt}\) (2계)라 처음 모양과 처음 속도 두 개. 줄을 같은 모양으로 놓아도 처음에 튕기는지(속도)에 따라 운동이 다릅니다.

  4. 판단한 학생이 "양 끝이 단열된 막대에 처음 온도가 \(u(x, 0) = x\) (\(0 \le x \le 1\))이면 오래 지나 막대 전체가 0 ℃가 된다"고 했습니다. 맞나요? [02-01]

    힌트 1

    단열이면 열이 빠져나갈 수 있나요?

    힌트 2

    총 열량 \(\int_0^1u\,dx\)가 보존됩니다.

    풀이

    틀렸습니다. 열이 빠져나가지 않아 평균 온도가 보존되므로 \(\int_0^1x\,dx = \frac12\), 곧 막대 전체가 0.5 ℃가 됩니다. 0 ℃로 가는 것은 양 끝을 0 ℃로 고정한(Dirichlet) 경우입니다. 확인: \(\frac{d}{dt}\int u\,dx = \alpha^2\int u_{xx}dx = \alpha^2[u_x]_0^1 = 0\).

  5. 계산길이 0.65 m, 장력 80 N, 선밀도 \(1.2\times10^{-3}\) kg/m인 줄의 파속과 기본 진동수를 구하세요(양 끝 고정). [02-02]

    힌트 1

    \(c = \sqrt{T/\rho}\).

    힌트 2

    기본 진동수 \(\frac{c}{2L}\).

    풀이

    \(c = \sqrt{66667} = 258\) m/s, \(f_1 = \frac{258}{1.30} = 199\) Hz (G3 근처). 4단원의 변수분리로 이 식을 유도합니다.

  6. 판단"열방정식은 시간을 거꾸로 돌려도 똑같이 성립하니, 지금의 온도 분포에서 1시간 전 분포를 정확히 계산할 수 있다." 맞나요? [02-05, 02-01]

    힌트 1

    \(t \to -t\)로 바꾸면 \(u_t = -\alpha^2u_{xx}\)가 됩니다.

    힌트 2

    Fourier 성분 \(e^{-n^2\alpha^2t}\)를 거꾸로 돌리면?

    풀이

    틀렸습니다. 시간을 뒤집으면 부호가 바뀌어 다른 방정식이 됩니다. 각 성분 \(e^{-n^2t}\)를 거꾸로 돌리면 \(e^{n^2t}\)로 높은 진동수일수록 폭발적으로 커져, 지금의 아주 작은 측정 오차가 과거 추정에서 엄청나게 커집니다(잘 놓이지 않은 문제). 열의 확산은 비가역입니다.

2.R.2

연습경계값 문제의 변수분리 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [공통9-02-05] [공통9-02-03] [공통8-06-03]

경계 조건 → 고유함수 → 시간 부분 → 초기 조건으로 계수, 이 순서를 지키세요.

  1. 계산\(u_t = u_{xx}\) (\(0 < x < \pi\)), \(u(0,t) = u(\pi,t) = 0\), \(u(x, 0) = 3\sin2x - \sin5x\)를 푸세요. [02-05]

    힌트 1

    02-05 절: 초기 조건이 이미 사인 급수.

    힌트 2

    \(\sin nx\) 성분은 \(e^{-n^2t}\)로 줄어듭니다.

    풀이

    \(u = 3e^{-4t}\sin2x - e^{-25t}\sin5x\).

  2. 계산양 끝이 단열된 막대 \(u_t = u_{xx}\), \(u_x(0,t) = u_x(\pi,t) = 0\), \(u(x, 0) = 1 + \cos2x\)를 푸세요. 오래 지나면 온도는? [02-05, 공통8-06-03]

    힌트 1

    Neumann이면 고유함수 \(\cos nx\) (\(n = 0\) 포함).

    힌트 2

    \(\cos nx\) 성분은 \(e^{-n^2t}\).

    풀이

    \(u = 1 + e^{-4t}\cos2x\). 오래 지나면 1 (처음 평균 온도). 3-R 문제 4의 결론과 같습니다.

  3. 계산무한한 줄(\(c = 2\))의 처음 속도가 \(g(x) = 1\) (\(|x| < 1\)), 0 (그 밖), 처음 변위가 0입니다. \(x = 0\)에서 \(u(0, t)\)를 \(t\)의 함수로 구하세요. [02-03]

    힌트 1

    d'Alembert: \(u = \frac{1}{2c}\int_{x-ct}^{x+ct}g\).

    힌트 2

    \(x = 0\)이면 구간 \([-2t, 2t]\)와 \([-1, 1]\)의 겹치는 길이.

    풀이

    \(t \le \frac12\): 겹침 \(4t\), \(u = \frac{4t}{4} = t\). \(t \ge \frac12\): 겹침 2, \(u = \frac12\). 처음 속도를 받은 부분이 올라가다가, 영향이 퍼져 나간 뒤 그 높이에 머뭅니다.

  4. 판단한 학생이 \(u_t = u_{xx}\), \(u(0,t) = 0\), \(u(1,t) = 10\)을 그대로 변수분리하려다 고유함수가 경계 조건을 만족하지 않아 막혔습니다. 무엇을 먼저 해야 하나요? [02-05]

    힌트 1

    경계 조건이 동차(0)가 아닙니다.

    힌트 2

    정상 상태 \(v(x) = 10x\)를 빼 보세요.

    풀이

    비동차 경계 조건은 변수분리를 바로 쓸 수 없습니다(해의 합이 경계 조건을 지키지 못함). 정상 상태 \(v = 10x\)를 구하고 \(w = u - v\)로 두면 \(w_t = w_{xx}\), \(w(0) = w(1) = 0\)인 동차 문제가 됩니다. \(w\)를 변수분리로 풀고 \(u = 10x + w\).

  5. 개념공통8-06-03 카드의 직교성 덕분에 Fourier 계수를 적분 하나로 구할 수 있습니다. 직교하지 않는 함수들(예: \(1, x, x^2, \dots\))로 전개하면 무엇이 어려워지나요? [공통8-06-03]

    힌트 1

    양변에 기저 함수를 곱해 적분하면?

    힌트 2

    다른 항이 사라지지 않습니다.

    풀이

    직교하면 다른 항이 모두 사라져 \(c_n = \frac{\int fy_nw}{\int y_n^2w}\)로 각각 따로 구합니다. 직교하지 않으면 모든 계수가 얽힌 연립방정식을 풀어야 하고, 항을 하나 더 넣을 때마다 앞의 계수를 다시 계산해야 합니다. 공통2 1-01의 정사영이 직교 기저에서만 단순한 것과 같은 이유입니다.

  6. 판단"줄을 정확히 가운데에서 퉁기면 짝수 배음(\(n = 2, 4, \dots\))이 생기지 않는다." 맞나요? 이유를 사인 계수로 설명하세요. [02-03]

    힌트 1

    가운데에서 퉁긴 모양은 \(x = \frac L2\)에 대해 대칭입니다.

    힌트 2

    \(\sin\frac{2\pi x}{L}\)은 가운데에 대해 반대칭(가운데가 마디).

    풀이

    맞습니다. 짝수 \(n\)의 \(\sin\frac{n\pi x}{L}\)은 가운데에 대해 반대칭이라, 대칭인 처음 모양과의 적분(계수)이 0입니다. 짝수 배음은 모두 가운데가 마디라서, 가운데를 크게 움직이는 퉁김으로는 생기지 않는다고 볼 수도 있습니다. 기타를 브리지 가까이에서 퉁기면 높은 배음이 많아 소리가 밝아지는 것도 같은 계산입니다.
