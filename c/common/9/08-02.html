이 절의 예제는 모두 다음 그래프를 씁니다. 꼭짓점 A, B, C, D, E와 변(가중치)은 다음과 같습니다.

A–B 4, A–C 2, B–C 1, B–D 5, C–D 8, C–E 10, D–E 2.

8.2.1다익스트라 알고리즘

출발점에서 가까운 꼭짓점부터 차례로 거리를 "확정"해 갑니다. 가중치가 음수가 아니면, 아직 확정되지 않은 꼭짓점 가운데 임시 거리가 가장 작은 것은 더 짧아질 수 없기 때문입니다.

  1. 출발점의 거리는 0, 나머지는 \(\infty\)로 둔다.
  2. 확정되지 않은 꼭짓점 가운데 임시 거리가 가장 작은 것 \(u\)를 확정한다.
  3. \(u\)의 이웃 \(v\)마다, (\(u\)의 거리 + 변 \(uv\)의 가중치)가 \(v\)의 임시 거리보다 작으면 바꾼다.
  4. 모든 꼭짓점이 확정될 때까지 2–3을 되풀이한다.
예제 8.2.1

A에서 각 꼭짓점까지의 최단 거리를 구하여라.

확정BCDE
A (0)42\(\infty\)\(\infty\)
C (2)3–1012
B (3)––812
D (8)–––10
E (10)––––

최단 거리는 B 3, C 2, D 8, E 10입니다. 예를 들어 E까지는 A–C–B–D–E입니다. B까지 직접 가는 변(4)보다 C를 거치는 길(3)이 짧다는 점에 주의합니다.

8.2.2크러스컬 알고리즘

모든 꼭짓점을 잇고 회로가 없는 변의 집합을 신장 트리라 합니다. 꼭짓점이 \(n\)개이면 신장 트리의 변은 정확히 \(n - 1\)개입니다. 가중치 합이 가장 작은 것이 최소 신장 트리입니다.

  1. 변을 가중치가 작은 것부터 나열한다.
  2. 차례로 보며, 이미 고른 변과 회로를 만들지 않으면 고른다.
  3. \(n - 1\)개를 고르면 끝낸다.
예제 8.2.2

같은 그래프의 최소 신장 트리를 구하여라.

풀이. 순서: B–C 1 (고름), A–C 2 (고름), D–E 2 (고름), A–B 4 (A–B–C 회로가 생겨 버림), B–D 5 (고름). 4개를 골랐으므로 끝. 총합 \(1 + 2 + 2 + 5 = 10\).

두 알고리즘 모두 "지금 가장 좋아 보이는 것"을 고르는 탐욕적 방법인데, 이 두 문제에서는 그것이 실제로 최적임이 증명되어 있습니다.

요약
  1. 다익스트라: 가장 가까운 꼭짓점부터 확정하며 이웃의 거리를 갱신. 음의 가중치가 없을 때.
  2. 크러스컬: 작은 변부터, 회로를 만들지 않는 것만 골라 \(n - 1\)개.

8.2.3연습문제

기본

  1. 예제 그래프에서 D를 출발점으로 할 때 A까지의 최단 거리는?
    답

    D–B–C–A: \(5 + 1 + 2 = 8\).

응용

  1. 예제 그래프에서 D–E의 가중치가 20으로 바뀌면 최소 신장 트리는?
    답

    B–C 1, A–C 2, B–D 5, C–E 10. 합 18.

8.2.2

예제Dijkstra와 Kruskal 알고리즘으로 최단 경로와 최소 신장 트리 구하기

탐욕 알고리즘 · 왜 맞는가

다루는 성취기준 [공통9-08-02]

두 알고리즘

  • Dijkstra (최단 경로, 가중치 ≥ 0): 시작점의 거리 0, 나머지 ∞. 아직 확정되지 않은 정점 중 거리가 가장 작은 것을 확정하고, 그 이웃의 거리를 "그 정점을 거쳐 가는 길"로 갱신한다. 모두 확정될 때까지 반복.
  • Kruskal (최소 신장 트리): 간선을 가중치 순으로 정렬하고, 고리를 만들지 않는 간선을 차례로 고른다. \(n - 1\)개가 되면 끝.

둘 다 매 단계 "지금 가장 좋아 보이는 것"을 고르는 탐욕 알고리즘입니다. 탐욕법은 보통 최적을 보장하지 않지만, 이 두 문제에서는 보장됩니다.

  • Dijkstra가 맞는 이유: 확정하려는 정점보다 더 짧은 길이 있다면 그 길은 다른 미확정 정점을 지나야 하는데, 그 정점까지의 거리는 이미 더 크거나 같고 가중치가 음수가 아니라 줄어들 수 없습니다.
  • Kruskal이 맞는 이유(절단 성질): 정점을 두 무리로 나누는 어떤 절단에서든, 그 사이를 잇는 가장 싼 간선은 어떤 최소 신장 트리에 들어 있습니다.

08-01 카드의 케이블망(A–B 4, A–C 2, B–C 1, B–D 5, C–D 8, C–E 10, D–E 2)에서 (가) A에서 모든 마을까지의 최단 비용 (나) 최소 신장 트리를 구하세요.

풀이

  1. (가) 시작: A = 0, 나머지 ∞. A 확정 → B = 4, C = 2.
    A의 이웃 갱신.
  2. 가장 작은 C(2) 확정 → B = min(4, 2 + 1) = 3, D = 2 + 8 = 10, E = 2 + 10 = 12.
    C를 거쳐 B로 가는 길이 더 싸다.
  3. B(3) 확정 → D = min(10, 3 + 5) = 8.
    B를 거친 D.
  4. D(8) 확정 → E = min(12, 8 + 2) = 10. E(10) 확정. 결과: B 3, C 2, D 8, E 10. A→E 경로 A–C–B–D–E.
    직접 연결 C–E(12)보다 돌아가는 길이 싸다.
  5. (나) 정렬: B–C 1, A–C 2, D–E 2, A–B 4, B–D 5, C–D 8, C–E 10. B–C ○, A–C ○, D–E ○, A–B × (A–C–B 고리), B–D ○ → 간선 4개. 비용 \(1 + 2 + 2 + 5 = 10\).
    고리를 만드는 간선은 건너뛴다.

의미

이 예에서는 최소 신장 트리의 A–E 경로(A–C–B–D–E)가 마침 최단 경로와 같지만, 일반적으로는 다를 수 있습니다(08-01 카드). 내비게이션은 Dijkstra를 더 빠르게 만든 A* 알고리즘을, 네트워크 설계는 최소 신장 트리를 씁니다. 그래프가 \(V\)개 정점, \(E\)개 간선이면 둘 다 대략 \(E\log V\)에 비례하는 시간이라 수백만 정점도 다룰 수 있습니다.

검산

(가) 다른 경로와 비교: A–C–E 12, A–B–D–E 11, A–C–D–E 12. 10이 가장 작습니다. (나) 다른 신장 트리, 예를 들어 {A–C, B–C, C–D, D–E}는 \(2 + 1 + 8 + 2 = 13 > 10\).

흔한 오해

  • 음수 가중치에 Dijkstra: 이미 확정한 거리가 나중에 음수 간선으로 줄어들 수 있어 틀린 답을 냅니다. 음수가 있으면 벨만-포드 알고리즘을 씁니다.
8.2.3

실습다익스트라와 크러스컬 한 걸음씩

실습 · 최단 경로와 최소 신장 트리

다루는 성취기준 [공통9-08-02]

목표

8.2절의 그래프에서 다익스트라 알고리즘과 크러스컬 알고리즘을 한 단계씩 실행하며, 각 단계에서 무엇을 확정하고 무엇을 고치는지 따라갑니다. 성취기준 [공통9-08-02].

준비

변 옆 숫자는 가중치입니다. 다익스트라에서는 꼭짓점 아래 주황 숫자가 지금까지의 임시 거리, 색칠한 꼭짓점이 확정된 점, 굵은 선이 최단 경로입니다. 크러스컬에서는 굵은 선이 고른 변입니다. 아래 기록에 각 단계의 판단이 나옵니다.

절차

  1. 다익스트라를 고르고, 단계를 누르기 전에 다음에 확정될 꼭짓점을 예상한 뒤 확인한다.
  2. B의 임시 거리가 4에서 3으로 바뀌는 순간을 찾는다.
  3. 끝까지 실행해 각 꼭짓점까지의 거리를 8.2절 예제와 비교한다.
  4. 크러스컬로 바꿔 버려지는 변과 그 이유를 기록한다.

기대 결과

  • 확정 순서 A(0), C(2), B(3), D(8), E(10).
  • C를 확정할 때 B의 거리가 \(2 + 1 = 3\)으로 줄어든다.
  • 크러스컬: B–C, A–C, D–E, (A–B 버림), B–D를 골라 합 10.

분석

  1. 다익스트라에서 한번 확정한 거리는 왜 다시 줄어들지 않을까요? 가중치가 음수이면 무엇이 잘못될 수 있나요?
  2. 최단 경로 트리(다익스트라의 굵은 선)와 최소 신장 트리는 같은가요? 두 그림을 비교해 보세요.
