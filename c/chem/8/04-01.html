4.1.1

탐구이동상을 빨리 흘리면 분리는 나빠지나?

탐구 · van Deemter 식, 단 수, 분리능

다루는 성취기준 [화학8-04-01] [화학8-04-02] [화학3-05-01]

목표

단 높이 \(H\)가 이동상의 선속도에 따라 어떻게 바뀌는지 van Deemter 식으로 그리고, 그 결과가 두 봉우리의 분리능에 어떻게 이어지는지 크로마토그램으로 확인합니다. 성취기준 [화학8-04-01], [화학8-04-02], [화학3-05-01].

준비

단 높이 \(H\): 봉우리가 관을 지나며 넓어지는 정도를 길이로 나타낸 값. 작을수록 좋습니다. 관 길이를 \(L\)이라 하면 단 수는 \(N = L/H\)입니다.

van Deemter 식 \(H = A + B/u + Cu\)

  • \(A\): 충전물 사이로 길이가 다른 여러 경로를 지나는 효과. 속도와 무관합니다.
  • \(B/u\): 세로 방향 확산. 천천히 흘릴수록 관 안에 오래 있어 더 퍼집니다.
  • \(Cu\): 이동상과 정지상 사이를 오가는 데 걸리는 시간(물질 전달). 빨리 흘릴수록 따라가지 못해 퍼집니다.

미분해 0으로 두면 최적 선속도 \(u_{opt} = \sqrt{B/C}\), 최소 단 높이 \(H_{min} = A + 2\sqrt{BC}\)입니다.

분리능 \(R_s = \dfrac{t_2 - t_1}{\tfrac12(w_1 + w_2)}\): 봉우리 바닥 폭 \(w = 4\sigma\)로 잰 두 봉우리 사이 거리. 1.5 이상이면 기준선까지 갈라집니다.

가상의 HPLC 관(단위: \(H\) µm, \(u\) mm/s)에서 첫 물질의 머무름 인자 \(k_1 = 2.0\), 두 번째는 \(k_2 = \alpha k_1\)입니다. 위 그림의 점선은 세 항을 따로 그린 것(회색 \(A\), 초록 \(A+B/u\), 빨강 \(A+Cu\)), 주황 점은 최적점, 빨간 점은 지금 속도입니다. 아래 그림은 그 속도의 크로마토그램이고 세로 막대는 머무르지 않는 물질이 나오는 시간 \(t_0\)입니다.

질문

분석 시간을 줄이려고 선속도를 최적값의 세 배로 올렸습니다. 단 수와 분리능은 몇 % 줄어들까요? 반대로 관 길이를 두 배로 하면 분리능은 몇 배가 될까요?

복원

  1. 처음 값에서 최적 선속도, 최소 단 높이, N, Rs를 기록한다.
  2. u를 0.3 mm/s와 3.45 mm/s로 바꿔 H와 Rs를 비교하고, 어느 항이 H를 키웠는지 점선으로 확인한다.
  3. u를 최적값으로 되돌리고 L을 150 mm에서 300 mm로 바꿔 Rs의 비를 계산한다.
  4. α를 1.050에서 1.100으로 바꿔 Rs의 변화를 같은 방식으로 비교한다.

설명

처음 값에서 \(u_{opt} = \sqrt{4/3} = 1.15\) mm/s, \(H_{min} = 4 + 2\sqrt{12} = 10.93\) µm, N = 13726이고 α = 1.050에서 Rs = 0.96으로 두 봉우리가 겹칩니다. 느리게 흘리면(0.30 mm/s) \(B/u\) 항이 커져 H = 18.23 µm, Rs = 0.74가 되고, 세 배로 빠르게 흘리면(3.45 mm/s) \(Cu\) 항이 커져 H = 15.51 µm, N = 9672(약 30% 감소), Rs = 0.81(약 16% 감소)이 됩니다. 대신 분석 시간은 404 s에서 135 s로 줄어듭니다. 최적점 오른쪽은 왼쪽보다 완만하므로 실제 분석은 시간을 아끼려고 최적값보다 조금 빠르게 흘리는 일이 많습니다.

분리능은 Purnell 식 \(R_s = \dfrac{\sqrt N}{4}\cdot\dfrac{\alpha-1}{\alpha}\cdot\dfrac{k_2}{1+k_2}\)를 따릅니다. 관 길이를 두 배로 하면 N이 두 배라 Rs는 0.96에서 1.36으로 \(\sqrt2 \approx 1.41\)배에 그치고 분석 시간은 두 배가 됩니다. 반면 α를 1.05에서 1.10으로 올리면 \((\alpha-1)/\alpha\)가 약 1.9배가 되어 Rs가 1.89로 기준선 분리에 이릅니다(장치의 Rs는 봉우리 폭의 차이까지 넣은 계산이라 Purnell 식 값과 조금 다릅니다). 그래서 분리가 안 될 때는 먼저 이동상 조성이나 정지상을 바꿔 α를 키웁니다.

연결

기체 크로마토그래피에서는 확산 계수가 액체보다 약 만 배 커서 B 항이 크고 최적 선속도가 훨씬 빠릅니다. 작은 입자의 충전물(UHPLC)은 A와 C를 함께 줄여 빠른 속도에서도 H가 작습니다. 분석화학1의 분리 원리([화학1-07-02])가 여기서 수로 바뀝니다.

적용

Rs = 1.0인 두 봉우리를 Rs = 1.5로 만들려면 관 길이만으로는 몇 배가 필요할까요? 장치로 L을 바꿔 확인하고, α를 바꾸는 쪽과 분석 시간을 비교해 보세요.

판단

"B 항은 확산 때문이니 온도를 올리면 분리가 늘 나빠진다." C 항에도 확산(정지상 안과 이동상 안의 물질 전달)이 들어 있다는 점을 들어 이 주장을 평가해 보세요.
