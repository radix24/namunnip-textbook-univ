4.2.1표준 편차로 쓰는 N과 H

가우스 모양 봉우리의 너비는 표준 편차 σ로 나타냅니다. 바탕 너비 w ≈ 4σ, 반높이 너비 w½ ≈ 2.35σ입니다. 시간 단위의 σ_t로 쓰면

식 4.2.1 (이론단 수와 단 높이)

\[ N = \left(\frac{t_R}{\sigma_t}\right)^2, \qquad H = \frac{L}{N} = \frac{\sigma_L^2}{L} \]

\(\sigma_L\)은 길이 단위의 봉우리 표준 편차(봉우리가 관 끝에 이를 때 퍼진 폭).

바탕 너비로 쓴 \(N = 16(t_R/w)^2\)와 같은 식입니다(w = 4σ이므로 16 = 4²).

4.2.2넓어짐은 분산으로 더해진다

봉우리를 넓히는 원인들이 서로 독립이면, 표준 편차가 아니라 분산이 더해집니다.

\[ \sigma_\mathrm{전체}^2 = \sigma_\mathrm{관}^2 + \sigma_\mathrm{주입}^2 + \sigma_\mathrm{연결관}^2 + \sigma_\mathrm{검출기}^2 + \cdots \]

예제 4.2.1

머무름 시간 300 s인 봉우리에서 관 자체의 넓어짐은 σ = 2.0 s이고, 주입기·연결관·검출기 셀의 관 밖 넓어짐이 σ = 1.0 s이다. 관 자체의 N과 실제로 관찰되는 N을 비교하여라.

풀이. 관 자체: N = (300/2.0)² = 22500. 관찰: σ = √(2.0² + 1.0²) = 2.24 s, N = (300/2.24)² = 18000. 관 밖 넓어짐(σ의 절반)만으로 단 수가 20% 줄었습니다. 짧고 좁은 관(UHPLC)일수록 관 자체의 σ가 작아 관 밖 넓어짐의 비중이 커지므로, 연결관을 짧고 가늘게, 검출기 셀을 작게 합니다.

4.2.3목표 분리능에서 거꾸로

구하려는 것: R_s = 1.5를 얻는 데 필요한 N과 관 길이. 퍼넬 식(화학3 5.1절)을 N에 대해 풀면

식 4.2.2 (필요 이론단 수)

\[ N_\mathrm{필요} = 16R_s^2\left(\frac{\alpha}{\alpha - 1}\right)^2\left(\frac{1 + k}{k}\right)^2 \]

예제 4.2.2

α = 1.05, k = 4인 두 물질을 R_s = 1.5로 분리하려 한다. 필요한 N은? 4.1절 예제의 관(H = 12.0 μm, u_opt = 2.0 mm/s, 불감 시간 기준)으로는 관 길이가 얼마여야 하며, 둘째 봉우리는 언제 나오는가?

풀이. N = 16 × 2.25 × (1.05/0.05)² × (5/4)² = 16 × 2.25 × 441 × 1.5625 = 24800. L = N × H = 24800 × 12.0 μm = 29.8 cm. 불감 시간 t_M = L/u = 298 mm/(2.0 mm/s) = 149 s, 둘째 봉우리 t_R = t_M(1 + k) = 745 s(약 12분)입니다. α를 1.10으로 올릴 수 있다면 (α/(α − 1))²가 441에서 121로 줄어 N 6800, 관 8.2 cm, 약 3.4분이면 됩니다. 선택성을 높이는 것이 시간을 가장 크게 줄입니다.

흔한 오해"넓어짐의 표준 편차를 더한다"가 아니라 분산(제곱)을 더합니다. 예제 4.2.1에서 2.0 + 1.0 = 3.0 s로 계산하면 N을 크게 과소평가합니다. 또 "분리능을 두 배로 하려면 관을 두 배"가 아니라 네 배입니다(R_s ∝ √N). 그리고 N은 물질마다 조금씩 다르므로(k에 따라) 관의 N을 말할 때는 어떤 물질로 쟀는지 함께 씁니다.
요약
  1. N = (t_R/σ_t)² = 16(t_R/w)², H = L/N = σ_L²/L.
  2. 독립 넓어짐은 분산으로 더한다. 관 밖 넓어짐은 짧은 관에서 특히 중요.
  3. N_필요 = 16R_s²(α/(α − 1))²((1 + k)/k)². L = N·H, t_R = (L/u)(1 + k).
  4. α를 조금만 키워도 필요 N과 시간이 크게 준다.

4.2.4연습문제

기본

  1. 25 cm 관에서 t_R = 8.0 min, σ_t = 4.0 s인 봉우리의 N과 H는?
    답

    t_R = 480 s, N = (480/4.0)² = 14400. H = 250 mm/14400 = 0.0174 mm = 17.4 μm.

응용

  1. 관 자체의 σ = 1.5 s인데 관찰된 σ가 2.5 s였다. 관 밖 넓어짐의 σ는?
    답

    √(2.5² − 1.5²) = √4.0 = 2.0 s. 관 자체보다 커서 장치 연결을 점검해야 한다.

심화

  1. α = 1.02, k = 3에서 R_s = 1.5에 필요한 N을 구하고, H = 10 μm인 관으로 가능한지 판단하시오.
    답

    N = 16 × 2.25 × (1.02/0.02)² × (4/3)² = 36 × 2601 × 1.778 = 1.66×10⁵. 관 길이 1.66 m로, 보통 HPLC 관(5~25 cm)으로는 어렵다. α를 키우는 조건을 찾아야 한다.
