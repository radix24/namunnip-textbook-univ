2.R.1

연습슈뢰딩거 방정식과 모형계 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [화학6-02-01] [화학6-02-02] [화학6-02-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념상자 속 입자에서 에너지가 양자화되는 이유를 경계 조건으로 설명하시오. 상자의 벽이 없으면(자유 입자) 어떻게 되는가? [02-01]

    힌트 1

    2.1.3의 3단계.

    힌트 2

    경계 조건이 없으면 k에 제한이 있나요?

    풀이

    벽에서 ψ = 0이어야 하므로 \(\sin ka = 0\), 곧 \(k = n\pi/a\)만 허용되어 \(E = \hbar^2k^2/2m\)도 띄엄띄엄한 값만 가집니다. 벽이 없는 자유 입자는 k에 제한이 없어 에너지가 연속입니다. 양자화는 "갇힘"에서 나옵니다.

  2. 계산헥사트라이엔(π 전자 6개)의 상자 길이를 867 pm로 놓을 때 HOMO → LUMO 흡수 파장을 구하시오. [02-01]

    힌트 1

    전자 6개는 n = 1, 2, 3을 채웁니다. 전이는 3 → 4.

    힌트 2

    \(\lambda = 8m_eca^2/(7h)\).

    풀이

    \(\Delta E = (16 - 9)h^2/8m_ea^2\), \(\lambda = 8(9.109\times10^{-31})(2.998\times10^8)(867\times10^{-12})^2/(7\times6.626\times10^{-34}) = 354\) nm. 실험값(약 258 nm)보다 길게 나옵니다. 실제 분자에서는 단일·이중 결합 길이가 번갈아 달라 전자가 "자유롭게" 움직이지 못하기 때문입니다.

  3. 계산¹H³⁵Cl의 진동 파수가 2886 cm⁻¹일 때 ²H³⁵Cl(DCl)의 영점 에너지를 kJ/mol로 구하시오. 두 분자의 영점 에너지 차이는 무엇과 관련 있는가? [02-02]

    힌트 1

    DCl의 진동 파수는 \(\tilde\nu\sqrt{\mu_\mathrm{H}/\mu_\mathrm{D}}\) = 2070 cm⁻¹.

    힌트 2

    영점 에너지 \(\tfrac12hc\tilde\nu N_A\).

    풀이

    DCl: \(\tfrac12hc(2070\ \mathrm{cm^{-1}})N_A = 12.4\) kJ/mol. HCl은 17.3 kJ/mol. 차이 약 4.9 kJ/mol. C−H를 C−D로 바꾸면 결합을 끊는 데 영점 에너지 차이만큼 더 많은 에너지가 들어 반응이 느려집니다(속도론적 동위원소 효과, [화학18-02-02]).

  4. 판단한 학생이 "N₂는 진동하므로 적외선을 흡수해 온실 기체 역할을 한다"고 썼다. 이 주장을 평가하시오. [02-02]

    힌트 1

    진동 흡수의 선택 규칙에는 두 조건이 있습니다.

    힌트 2

    N≡N이 늘어났다 줄어들 때 쌍극자 모멘트가 생기나요?

    풀이

    틀렸습니다. N₂는 같은 원자 둘로 되어 진동해도 쌍극자 모멘트가 0으로 남으므로 적외선을 흡수하지 않습니다. 대기의 온실 효과는 CO₂, H₂O, CH₄처럼 진동할 때 쌍극자가 변하는 분자가 일으킵니다(N₂의 진동은 라만 분광으로는 볼 수 있음).

  5. 계산\(\psi = \sqrt{2/a}\sin(2\pi x/a)\)에서 \(\langle x\rangle\)와 에너지 측정값을 구하시오. [02-03]

    힌트 1

    |ψ|²가 x = a/2를 중심으로 대칭인가요?

    힌트 2

    n = 2 고유함수입니다.

    풀이

    |ψ₂|²는 a/2 둘레로 대칭이라 \(\langle x\rangle = a/2\)입니다(정작 x = a/2는 마디라 그 점에서 찾을 확률 밀도는 0). 에너지는 고유함수이므로 언제나 \(E_2 = 4h^2/8ma^2 = h^2/2ma^2\).

  6. 개념운동량 연산자의 고유함수 \(e^{ikx}\)에서 위치의 확률 분포는 어떻게 되는가? 이것이 불확정성 원리와 어떻게 맞는가? [02-03]

    힌트 1

    \(|e^{ikx}|^2\)을 계산하세요.

    힌트 2

    Δp = 0이면 Δx는?

    풀이

    \(|e^{ikx}|^2 = 1\)로 모든 x에서 같습니다. 운동량은 정확히 ħk(Δp = 0)이지만 위치는 완전히 퍼져 있어(Δx = ∞) \(\Delta x\Delta p \ge \hbar/2\)와 모순되지 않습니다.
