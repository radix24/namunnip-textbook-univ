2.1.1파동을 다루는 방정식

1단원에서 전자가 파동처럼 행동한다는 것을 보았습니다. 기타 줄의 진동을 파동 방정식으로 다루듯, 전자의 파동도 그것을 다스리는 방정식이 있어야 합니다. 1926년 슈뢰딩거가 제안한 방정식이 그것이며, 이 방정식의 해를 파동함수 ψ라 부릅니다. 이 절에서는 가장 단순한 경우(벽 사이에 갇힌 입자)를 처음부터 끝까지 풀어, 에너지가 왜 양자화되는지를 직접 봅니다.

2.1.2시간에 무관한 슈뢰딩거 방정식

식 2.1.1 (1차원 슈뢰딩거 방정식)

\[ -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi \]

식을 왼쪽부터 읽으면, 첫째 항은 운동 에너지(파동함수가 얼마나 급하게 휘는지), 둘째 항은 위치 에너지 V(x)입니다. 둘의 합이 전체 에너지 E와 같아야 한다는 "에너지 보존"을 파동의 언어로 쓴 것입니다. 우리가 구하려는 것은 이 식을 만족하면서 물리적으로 말이 되는(유한하고, 연속이며, 한 값만 갖는) 함수 ψ와 그때의 E입니다. 이런 조건을 만족하는 해는 특정한 E에서만 존재하고, 그것이 양자화의 원인입니다.

보른의 해석: \(|\psi(x)|^2dx\)는 입자를 \(x\)와 \(x + dx\) 사이에서 발견할 확률이다. 그래서 전체 공간에서 적분하면 1이어야 하며(정규화), \(\int|\psi|^2dx = 1\)이 되도록 ψ의 크기를 정한다.

2.1.3상자 속 입자 풀기

길이 a인 상자 안(0 < x < a)에서는 V = 0, 벽과 바깥은 V = ∞라고 합시다. 입자는 벽 밖으로 나갈 수 없으므로 바깥에서 ψ = 0이고, ψ가 연속이어야 하므로 벽에서도 ψ(0) = ψ(a) = 0입니다(경계 조건).

  1. 상자 안에서 방정식은 \(\psi'' = -k^2\psi\), \(k^2 = 2mE/\hbar^2\)입니다. 두 번 미분하면 자기 자신의 음수배가 되는 함수이므로 일반해는 \(\psi = A\sin kx + B\cos kx\)입니다.
  2. ψ(0) = 0에서 B = 0입니다(cos 0 = 1).
  3. ψ(a) = 0에서 \(A\sin ka = 0\). A = 0이면 입자가 없으므로 \(\sin ka = 0\), 곧 \(ka = n\pi\) (n = 1, 2, 3, …)입니다. n = 0은 ψ = 0이 되어 제외합니다.
  4. \(k = n\pi/a\)를 \(k^2 = 2mE/\hbar^2\)에 넣으면 에너지가 나옵니다.
결과 2.1.2 (상자 속 입자)

\[ E_n = \frac{n^2h^2}{8ma^2}, \qquad \psi_n(x) = \sqrt{\frac2a}\sin\frac{n\pi x}{a}, \qquad n = 1, 2, 3, \dots \]

\(\sqrt{2/a}\)는 정규화에서 나옵니다(\(\int_0^a \sin^2(n\pi x/a)dx = a/2\)이므로). 양자화가 생긴 이유는 3단계의 경계 조건입니다. 상자의 양 끝이 "마디"가 되도록 반파장의 정수배만 들어갈 수 있어, 기타 줄의 배음처럼 허용되는 파동이 띄엄띄엄 정해집니다.

결과에서 알 수 있는 것들을 정리합니다.

  • 영점 에너지: 가장 낮은 에너지 \(E_1 = h^2/8ma^2\)도 0이 아닙니다. 갇힌 입자는 정지할 수 없습니다(불확정성 원리와 일치).
  • 상자가 작을수록, 입자가 가벼울수록 에너지 간격이 커집니다(\(1/ma^2\)). 1 nm 상자 속 전자는 \(E_1 = 0.38\) eV로 화학적으로 의미 있는 크기입니다.
  • 마디: ψₙ은 상자 안에 마디(ψ = 0인 점)가 n − 1개 있습니다. 마디가 많을수록 에너지가 높습니다.
  • 확률 분포: n = 1에서는 가운데에서 발견될 확률이 가장 크고, 가운데 1/3 구간에서 찾을 확률이 61%입니다. 고전 입자라면 어디서나 같은 확률(1/3)이었을 것입니다. n이 커지면 분포가 고르게 되어 고전적 결과에 다가갑니다(대응 원리).

2.1.4공액 분자에 적용하기

뷰타다이엔 CH₂=CH−CH=CH₂의 π 전자 4개는 탄소 사슬 전체에 퍼져 움직입니다. 이 전자들을 길이 a인 1차원 상자에 갇힌 입자로 보면, 한 준위에 두 개씩 채워 n = 1, 2가 차고 빛을 흡수하면 n = 2 → 3으로 올라갑니다.

\[ \Delta E = E_3 - E_2 = \frac{5h^2}{8m_ea^2}, \qquad \lambda = \frac{8m_eca^2}{5h} \]

예제 2.1.1

뷰타다이엔의 상자 길이를 578 pm(C−C, C=C 결합 길이의 합에 양 끝 반 결합씩을 더한 값)로 놓고 흡수 파장을 구하여라.

풀이. \(\lambda = 8(9.109\times10^{-31})(2.998\times10^8)(578\times10^{-12})^2/(5\times6.626\times10^{-34}) = 2.20\times10^{-7}\) m = 220 nm. 실험값 217 nm와 놀랄 만큼 가깝습니다. 사슬이 길어지면(헥사트라이엔, 전자 6개, a ≈ 867 pm) 약 354 nm로 예측되어, 공액이 길수록 긴 파장을 흡수한다는 경향이 그대로 나옵니다(실험 약 258 nm로, 긴 사슬에서는 모형이 과대 예측합니다). 시아닌 염료로 이 모형을 직접 맞춰 보는 실습 카드가 이 절에 있습니다.

흔한 오해"n = 0이면 에너지가 0인 상태"는 없습니다. n = 0이면 ψ = 0이라 입자 자체가 없는 것입니다. 또 "입자가 마디에서 갑자기 사라졌다 나타난다"고 생각하기 쉽지만, 파동함수는 입자의 궤적이 아니라 발견 확률의 분포입니다. 마디를 "지나가는" 입자라는 그림 자체가 맞지 않습니다.
요약
  1. 슈뢰딩거 방정식 \(\hat H\psi = E\psi\)는 운동 + 위치 에너지 = 전체 에너지를 파동으로 쓴 것이다. |ψ|²는 확률 밀도이다.
  2. 상자 속 입자: 경계 조건 ψ(0) = ψ(a) = 0이 에너지를 \(E_n = n^2h^2/8ma^2\)로 양자화한다.
  3. 영점 에너지가 있고, 에너지 간격은 상자가 작고 입자가 가벼울수록 크다. ψₙ의 마디는 n − 1개.
  4. 공액 분자의 π 전자를 상자에 넣으면 흡수 파장을 어림할 수 있다: \(\lambda = 8m_eca^2/(h(N+1))\).

2.1.5연습문제

기본

  1. 1 nm 상자 속 전자의 n = 1 → 2 전이에 해당하는 빛의 파장은?
    답

    ΔE = 3E₁ = 1.13 eV, λ = 1240/1.13 = 1100 nm(근적외선).

  2. ψ₂의 마디는 상자의 어디에 있는가(양 끝 제외)?
    답

    x = a/2.

응용

  1. 상자 길이를 두 배로 하면 E₁과 흡수 파장은 어떻게 바뀌는가?
    답

    E는 1/4, 같은 전이의 파장은 4배.

심화

  1. n = 1 상태에서 입자를 0 ≤ x ≤ a/4에서 발견할 확률을 적분으로 구하시오.
    힌트

    \(\int \sin^2u\,du = u/2 - \sin2u/4\).

    답

    \(\frac2a\int_0^{a/4}\sin^2(\pi x/a)dx = \frac14 - \frac1{2\pi} = 0.091\). 고전적 값 0.25보다 작다(벽 근처에서 ψ가 작음).

2.1.2

실습공액 염료의 색을 상자 속 입자로 맞힐 수 있을까?

실습 · 상자 속 입자 모형, 시아닌 염료

다루는 성취기준 [화학6-02-01] [화학15-03-02]

목표

사슬이 길어질수록 공액 염료가 긴 파장의 빛을 흡수하는 이유를 1차원 상자 속 입자 모형으로 계산하고, 가상 측정값과 비교해 모형의 상자 길이를 맞춥니다. 성취기준 [화학6-02-01], 물리화학실험 [화학15-03-02].

준비

시아닌 염료는 질소 원자 두 개 사이에 탄소 사슬이 이어진 분자입니다. π 전자들은 이 사슬 위를 자유롭게 움직인다고 보고, 길이 \(L\)인 1차원 상자에 갇힌 입자로 다룹니다(쿤(Kuhn)의 자유 전자 모형).

상자 속 입자의 에너지 \(E_n = \dfrac{n^2h^2}{8m_eL^2}\), \(n = 1, 2, 3, \dots\)

전자 채우기: 사슬 탄소 수가 \(p\)인 염료는 π 전자가 \(N = p + 3\)개입니다. 한 준위에 전자 두 개씩 채우면 가장 높이 채워진 준위(HOMO)는 \(n = N/2\)입니다.

흡수 파장: HOMO에서 LUMO(\(n = N/2 + 1\))로 옮겨 갈 때 \(\Delta E = \dfrac{(N+1)h^2}{8m_eL^2}\)이므로 \(\lambda = \dfrac{8m_ecL^2}{h(N+1)}\).

상자 길이: \(L = N\times l + 2\delta\). \(l\)은 결합 하나의 길이, \(\delta\)는 전자가 양 끝 질소 너머로 조금 더 퍼지는 길이입니다. \(\delta\)는 모형이 정하지 못하므로 실험에 맞춰 정합니다.

아래 그래프의 빨간 점은 가상 측정값입니다(p = 1, 3, 5에서 523, 604, 706 nm. 실제 시아닌 염료 실험에서 보고되는 값과 비슷한 크기로 만들었습니다). 파란 선은 지금 매개변수의 모형 예측입니다.

절차

  1. 처음 값(l = 1.39 Å, δ = 1.39 Å)에서 p를 1, 3, 5로 바꾸며 예측 λ와 가상 측정값의 차이를 기록한다.
  2. δ를 움직여 출력의 "제곱평균" 차이가 가장 작아지는 값을 찾는다.
  3. 그 δ에서 p = 7의 흡수 파장을 예측한다.
  4. δ = 0(전자가 질소 원자에서 딱 멈춤)으로 두고 예측이 얼마나 짧아지는지 본다.

기대 결과

  • 처음 값(δ = 1.39 Å)에서 예측은 p = 1, 3, 5에 459, 582, 708 nm로, 가상 측정값과 −64, −22, +2 nm 차이입니다(제곱평균 39 nm). 사슬이 길어질수록 λ가 길어지는 경향은 맞지만, 짧은 염료는 너무 짧게 예측합니다.
  • δ를 움직이면 1.52 Å 근처에서 제곱평균 차이가 26 nm로 가장 작습니다. 이때 차이는 −35, +6, +29 nm로, 짧은 염료는 여전히 짧게, 긴 염료는 길게 예측합니다. 한 개의 δ로는 세 점을 모두 맞출 수 없습니다.
  • 그 δ에서 p = 7은 860 nm로 예측되어 근적외선 영역입니다.
  • δ = 0이면 p = 3도 328 nm로 측정값보다 270 nm 이상 짧아집니다. 전자가 양 끝 질소 너머로 퍼진다는 가정이 결과에 크게 작용합니다.

분석

  1. 사슬이 길어질수록 λ가 길어지는 이유를 \(L^2/(N+1)\)이 어떻게 변하는지로 설명해 보세요.
  2. 모형이 긴 사슬에서 측정값보다 길게 예측하는 경향이 있다면, 실제 분자에서 무엇이 "자유 전자" 가정과 다를까요? (결합 길이가 번갈아 달라지는 결합 교대를 생각해 보세요.)
  3. 흡수하는 빛의 색과 용액이 보이는 색은 왜 다른가요?

더 해 보기

실험실에서는 세 염료를 메탄올에 녹여 UV-Vis 스펙트럼의 λmax를 잽니다. 측정값으로 \(L\)을 거꾸로 구해(\(L = \sqrt{h(N+1)\lambda/(8m_ec)}\)) \(N\)에 대해 그리면, 기울기가 결합 길이, 절편이 \(2\delta\)가 됩니다. 이 방법으로 δ를 구해 장치에서 찾은 값과 비교해 보세요.
