5.1.1빛으로 에너지 준위를 읽는다

분광학은 분자가 빛을 흡수하거나 내놓는 진동수를 재어, 분자의 에너지 준위 사이 간격을 알아내는 방법입니다. 흡수하는 빛의 에너지가 정확히 두 준위의 차이 \(\Delta E = h\nu\)와 같아야 하므로, 스펙트럼의 선 위치가 곧 에너지 간격입니다. 준위 간격은 운동의 종류마다 크기가 달라 서로 다른 빛 영역에 나타납니다.

  • 라디오파(MHz): 자기장 속 핵스핀의 뒤집힘 → NMR
  • 마이크로파(GHz, 수 cm⁻¹): 분자 전체의 회전 → 회전 분광
  • 적외선(수천 cm⁻¹): 결합의 진동 → IR, 라만
  • 가시·자외선(수만 cm⁻¹): 전자의 오비탈 사이 이동 → UV-Vis

5.1.2선택 규칙은 어디서 오나

두 준위의 차이와 같은 에너지의 빛이 있어도 늘 흡수되지는 않습니다. 빛의 전기장이 분자와 상호작용해 두 상태를 이어 주어야 하고, 그 세기가 전이 쌍극자 모멘트 \(\int\psi_f^*\hat\mu\,\psi_i\,d\tau\)입니다. 이 적분이 0이면 그 전이는 "금지"입니다. 강체 회전자에서는 분자에 영구 쌍극자가 있어야 하고 ΔJ = ±1일 때만 적분이 0이 아니며, 조화 진동자에서는 진동할 때 쌍극자가 변해야 하고 Δv = ±1일 때만 0이 아닙니다(2.2절). 선택 규칙은 이렇게 파동함수의 대칭에서 나옵니다.

5.1.3회전 스펙트럼에서 결합 길이 구하기

강체 회전자의 에너지 \(F(J) = BJ(J+1)\) (cm⁻¹)와 선택 규칙 ΔJ = +1에서, \(J \to J+1\) 흡수선의 위치는

\[ \tilde\nu = F(J+1) - F(J) = 2B(J+1), \qquad J = 0, 1, 2, \dots \]

입니다. 선들이 2B, 4B, 6B, …에 고른 간격 2B로 늘어섭니다. 선 간격에서 B를 얻고, \(B = h/(8\pi^2cI)\), \(I = \mu r^2\)에서 결합 길이를 구합니다.

예제 5.1.1

¹²C¹⁶O의 회전 스펙트럼에서 첫 선(J = 0 → 1)이 3.862 cm⁻¹(115.8 GHz)에 있다. 결합 길이를 구하여라.

풀이. 2B = 3.862 cm⁻¹이므로 B = 1.931 cm⁻¹. \(I = h/(8\pi^2cB) = 1.450\times10^{-46}\) kg·m². \(\mu = 12.000\times15.995/27.995\) u = 6.856 u = 1.139×10⁻²⁶ kg이므로 \(r = \sqrt{I/\mu} = 113\) pm입니다. 회전 분광은 결합 길이를 0.1 pm 수준까지 정밀하게 잴 수 있는 방법이고, 전파 망원경으로 성간 구름의 CO를 찾을 때도 이 115 GHz 선을 씁니다.

실제 스펙트럼을 자세히 보면 J가 커질수록 선 간격이 조금씩 줄어듭니다. 빨리 회전할수록 원심력으로 결합이 늘어나 I가 커지기 때문입니다(원심 뒤틀림). 강체라는 가정이 깨지는 정도를 보여 줍니다.

5.1.4선의 세기

흡수선의 세기는 처음 준위에 분자가 몇 개 있는지에 비례합니다. 회전 준위의 점유는 볼츠만 인자와 축퇴도 2J + 1의 곱입니다.

\[ \frac{N_J}{N_0} = (2J+1)\,e^{-hcBJ(J+1)/kT} \]

축퇴도는 J와 함께 커지고 볼츠만 인자는 줄어들므로, 점유는 어떤 중간 J에서 가장 큽니다. 미분하면 \(J_{max} \approx \sqrt{kT/2hcB} - \tfrac12\)입니다. HCl(B = 10.59 cm⁻¹)은 298 K에서 J = 3 근처, CO(B = 1.931 cm⁻¹)는 J = 7 근처의 선이 가장 셉니다. 진동-회전 스펙트럼에서 이 분포를 직접 바꿔 보는 실습 카드가 이 절에 있습니다.

흔한 오해"회전 스펙트럼의 선 간격은 B"가 아니라 2B입니다. 또 "가장 낮은 준위가 가장 많이 채워지니 J = 0 → 1 선이 가장 세다"도 틀립니다. 축퇴도 2J + 1 때문에 중간 J가 가장 많이 채워집니다. 그리고 영구 쌍극자가 없는 분자(N₂, CO₂, CH₄)는 순수 회전 스펙트럼이 없습니다.
요약
  1. 분광학은 ΔE = hν로 준위 간격을 잰다. 회전 → 마이크로파, 진동 → 적외선, 전자 → UV-Vis.
  2. 선택 규칙은 전이 쌍극자 모멘트가 0이 아닌 조건에서 나온다.
  3. 회전선 \(\tilde\nu = 2B(J+1)\), 간격 2B. B에서 I, I에서 결합 길이.
  4. 선 세기 ∝ (2J+1)e^{−E_J/kT}, 중간 J에서 최대.

5.1.5연습문제

기본

  1. H³⁵Cl(B = 10.59 cm⁻¹)의 순수 회전 스펙트럼 첫 세 선의 파수는?
    답

    21.18, 42.36, 63.54 cm⁻¹(원적외선).

응용

  1. ¹³C¹⁶O의 J = 0 → 1 선의 위치를 예측하시오(결합 길이는 ¹²C¹⁶O와 같다).
    답

    μ = 13.003×15.995/28.998 = 7.172 u. B ∝ 1/μ이므로 B = 1.931 × 6.856/7.172 = 1.846 cm⁻¹, 첫 선 3.692 cm⁻¹. 동위원소 치환으로 선이 옮겨 가는 것을 이용해 결합 길이를 확인한다.

심화

  1. 298 K에서 CO의 가장 센 회전 흡수선(J → J+1)의 J를 식으로 어림하고, 그 선의 파수를 구하시오.
    답

    kT/hc = 207 cm⁻¹, \(J_{max} = \sqrt{207/(2\times1.931)} - 0.5 = 6.8\), 곧 J = 7. 선의 파수 2B(J+1) = 2 × 1.931 × 8 = 30.9 cm⁻¹.

5.1.2

실습HCl 적외선 스펙트럼의 선 하나하나는 무엇인가?

실습 · 진동-회전 스펙트럼, 결합 길이

다루는 성취기준 [화학6-05-01] [화학6-02-02] [화학6-06-01] [화학15-03-01]

목표

기체 HCl의 진동-회전 스펙트럼을 계산으로 그려 P가지와 R가지가 생기는 까닭, 선 세기가 온도에 따라 바뀌는 까닭을 확인하고, 선의 위치에서 회전 상수와 결합 길이를 구합니다. 성취기준 [화학6-05-01], [화학6-02-02], [화학6-06-01], 물리화학실험 [화학15-03-01].

준비

이원자 분자는 진동하면서 동시에 회전합니다. 진동 준위가 \(v = 0 \to 1\)로 바뀔 때 회전 양자수 \(J\)도 반드시 ±1만큼 바뀌어야 합니다(선택 규칙 \(\Delta J = \pm1\)).

회전 에너지 \(F(J) = BJ(J+1)\) (파수 단위 cm⁻¹). \(B = h/(8\pi^2 c\mu r^2)\)는 결합 길이 \(r\)과 환산 질량 \(\mu\)로 정해지는 회전 상수입니다.

R가지(\(J \to J+1\)): \(\tilde\nu = \tilde\nu_0 + B_1(J+1)(J+2) - B_0J(J+1)\). 띠 중심보다 높은 파수.

P가지(\(J \to J-1\)): \(\tilde\nu = \tilde\nu_0 + B_1J(J-1) - B_0J(J+1)\). 띠 중심보다 낮은 파수.

\(\Delta J = 0\)은 금지라서 띠 중심 \(\tilde\nu_0\)에는 선이 없습니다. 진동이 들뜬 상태에서는 결합이 평균적으로 조금 늘어나 \(B_1 < B_0\)입니다. 선 세기는 처음 준위의 점유에 비례하고, 볼츠만 분포에 따라 \((2J+1)e^{-hcBJ(J+1)/kT}\)입니다.

장치는 H³⁵Cl의 분광 상수 \(B_e = 10.593\) cm⁻¹, \(\alpha_e = 0.3072\) cm⁻¹, \(\tilde\nu_0 = 2885.98\) cm⁻¹를 씁니다(\(B_v = B_e - \alpha_e(v + \tfrac12)\)). 염소 동위원소 ³⁷Cl(자연 존재비 약 24%)을 켜면 빨간 선이 더해집니다.

조합 차이: 위 상태가 같은 두 선의 차 \(R(J-1) - P(J+1) = B_0(4J+2)\)에는 \(B_1\)이 없어 \(B_0\)만 구할 수 있습니다. 아래 상태가 같은 \(R(J) - P(J) = B_1(4J+2)\)로는 \(B_1\)을 구합니다.

절차

  1. 300 K에서 띠 중심에 선이 없는 것을 확인하고, R(0), P(1)과 가운데 간격을 기록한다.
  2. 출력의 조합 차이로 구한 B₀, B₁과 결합 길이 r₀를 기록한다.
  3. R가지 선 간격이 J가 커질수록 좁아지고, P가지는 넓어지는지 그림에서 본다. "강체 회전자"를 켜면 어떻게 되는지 비교한다.
  4. 온도를 100 K, 300 K, 1000 K로 바꾸며 가장 센 R선의 J를 기록한다.
  5. H³⁷Cl을 켜고 동위원소 선이 어느 쪽으로 얼마나 밀리는지 본다.

기대 결과

  • 300 K에서 띠 중심 2886.0 cm⁻¹에는 선이 없고, 양옆에 R(0) 2906.2, P(1) 2865.1 cm⁻¹가 있습니다. 가운데 간격 41.1 cm⁻¹는 다른 이웃 선 간격(약 2B ≈ 20 cm⁻¹)의 두 배쯤입니다.
  • 조합 차이로 B₀ = 10.439 cm⁻¹, B₁ = 10.132 cm⁻¹를 얻고, B₀에서 결합 길이 r₀ = 1.284 Å가 나옵니다.
  • R가지는 J가 커질수록 선 간격이 좁아지고 P가지는 넓어집니다. "강체 회전자"를 켜면 B₁ = B₀ = 10.439가 되어 간격이 모두 같아지고 R(0)이 2906.9 cm⁻¹로 조금 옮겨 갑니다.
  • 가장 센 R선은 100 K에서 J = 1, 300 K에서 J = 3, 1000 K에서 J = 5입니다. 식 \(\sqrt{kT/2hcB} - \tfrac12\)의 값 1.3, 2.7, 5.3과 맞습니다. 온도가 오르면 높은 J가 점유되어 스펙트럼이 넓게 퍼집니다.
  • H³⁷Cl은 환산 질량이 조금 커서 띠 중심이 2883.8 cm⁻¹로 2.2 cm⁻¹ 낮아집니다. 각 선 옆에 약 1/3 세기의 빨간 선이 붙습니다.
  • 겉보기 힘 상수는 481 N/m입니다.

분석

  1. R가지는 높은 J로 갈수록 간격이 좁아지다가 결국 되돌아옵니다(띠 머리). \(B_1 < B_0\)을 써서 이유를 설명해 보세요.
  2. 가장 센 선의 J가 \(\sqrt{kT/2hcB} - \tfrac12\)에 가까운 이유를 \((2J+1)e^{-hcBJ(J+1)/kT}\)를 J로 미분해 보여 보세요.
  3. 출력의 "겉보기 힘 상수"는 \(\tilde\nu_0\)를 조화 진동자의 진동수로 보고 구한 값입니다. 비조화성을 생각하면 참 힘 상수는 이보다 클까요, 작을까요?

더 해 보기

실험에서는 FT-IR로 HCl 기체 셀의 스펙트럼을 얻고, 선 위치를 \(m\)(R가지는 \(m = J+1\), P가지는 \(m = -J\))에 대해 \(\tilde\nu(m) = \tilde\nu_0 + (B_1 + B_0)m + (B_1 - B_0)m^2\)으로 이차 맞춤합니다. 장치 출력의 선 위치 몇 개로 이 맞춤을 해 보고 조합 차이 결과와 비교해 보세요.
