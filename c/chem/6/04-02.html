4.2.1

탐구벤젠은 왜 특별히 안정하고 사이클로뷰타다이엔은 왜 불안정한가?

탐구 · Hückel 분자 오비탈, 방향족성

다루는 성취기준 [화학6-04-02] [화학5-02-03] [화학16-03-02]

목표

Hückel 방법으로 사슬과 고리 모양 공액 탄화수소의 π 오비탈 에너지를 구하고, 전자를 채워 비편재화 에너지를 계산합니다. 4n+2 규칙(방향족)과 4n 규칙(반방향족)이 오비탈 에너지 그림에서 어떻게 나오는지 봅니다. 성취기준 [화학6-04-02], 유기화학2 [화학5-02-03], 화학수학 [화학16-03-02].

준비

Hückel 방법은 각 탄소의 p 오비탈 하나씩만 생각하는 단순한 분자 오비탈 이론입니다.

α (쿨롱 적분): 탄소 p 오비탈 하나에 있는 전자의 에너지. 기준점입니다.

β (공명 적분): 이웃한 두 p 오비탈이 겹쳐 생기는 에너지. 음수입니다. 그래서 \(E = \alpha + x\beta\)에서 \(x\)가 클수록 에너지가 낮고 안정합니다.

이웃한 탄소끼리만 β로 이어진 행렬의 고유값을 구하면 됩니다. 결과는 공식으로 정리됩니다.

  • 사슬(탄소 N개): \(x_k = 2\cos\dfrac{k\pi}{N+1}\), \(k = 1,\dots,N\)
  • 고리(탄소 N개): \(x_k = 2\cos\dfrac{2\pi k}{N}\), \(k = 0,\dots,N-1\). 맨 아래 하나를 빼면 에너지가 같은 오비탈이 둘씩 짝을 이룹니다.

비편재화 에너지: 실제 π 에너지와, 이중 결합들이 서로 떨어진 에틸렌처럼 행동한다고 보았을 때(이중 결합 하나당 \(2\alpha + 2\beta\))의 에너지 차이. β 단위로 양수이면 그만큼 더 안정합니다.

그림의 가로선은 오비탈, 화살표는 전자(스핀 위·아래)입니다. 같은 에너지 오비탈은 옆으로 나란히 그렸고, 훈트 규칙에 따라 하나씩 먼저 채웁니다.

질문

벤젠(고리, N = 6)의 비편재화 에너지는 몇 β일까요? 사이클로뷰타다이엔(고리, N = 4)은 이중 결합 두 개를 가졌는데도 왜 비편재화로 얻는 것이 없을까요? 먼저 짐작해 보세요.

복원

  1. 고리 N = 6, 전하 0(벤젠)의 오비탈 에너지와 비편재화 에너지를 기록한다.
  2. 고리 N = 4(사이클로뷰타다이엔)로 바꿔 전자가 어떻게 채워지는지 본다.
  3. 고리 N = 5에서 전하 −1(사이클로펜타다이엔일 음이온), 고리 N = 7에서 전하 +1(트로필륨 양이온), 고리 N = 3에서 전하 +1을 차례로 본다.
  4. 사슬 N = 6(헥사트라이엔)의 비편재화 에너지를 벤젠과 비교한다.

설명

벤젠의 오비탈은 x = 2, 1, 1, −1, −1, −2입니다. 전자 6개가 결합성 오비탈 세 개(2, 1, 1)를 정확히 채워 \(E_\pi = 6\alpha + 8\beta\)이고, 에틸렌 세 개(\(6\alpha + 6\beta\))보다 2β만큼 더 안정합니다. 이것이 벤젠의 비편재화(공명) 에너지입니다.

사이클로뷰타다이엔은 x = 2, 0, 0, −2입니다. 전자 4개 중 둘은 x = 2에 들어가고 남은 둘은 에너지가 같은 x = 0 오비탈 두 개에 하나씩 들어갑니다. 비편재화 에너지는 0이고 홀전자가 둘인 라디칼 같은 상태라 매우 불안정합니다(반방향족). 실제 분자는 직사각형으로 찌그러져 이 상태를 피합니다.

고리에서는 맨 아래 오비탈 하나 위로 같은 에너지 오비탈이 둘씩 쌓입니다. 그래서 전자가 2개(맨 아래) + 4개씩 들어갈 때, 곧 4n+2개일 때 껍질이 꽉 찹니다. 사이클로펜타다이엔일 음이온(2.472β), 트로필륨 양이온(2.988β), 사이클로프로펜일 양이온(2.000β)이 모두 6개 또는 2개의 π 전자로 방향족입니다.

사이클로옥타테트라엔(N = 8, 전자 8개)은 비편재화 에너지가 1.657β로 양수지만 x = 0 오비탈 두 개에 홀전자가 하나씩 있어 반방향족 배치입니다. 비편재화 에너지의 부호만으로 방향족을 판정하면 안 되는 예입니다. 전자 두 개를 더한 C₈H₈²⁻(10개)는 껍질이 차서 방향족입니다.

사슬 헥사트라이엔의 비편재화 에너지는 0.988β로 벤젠(2.000β)의 절반이 안 됩니다. 고리를 닫아 양 끝이 이어지는 것이 추가 안정화를 줍니다. 알릴 라디칼(사슬 N = 3)은 0.828β이고 HOMO(x = 0)에 홀전자가 있습니다.

연결

사슬의 HOMO-LUMO 간격은 N이 커질수록 줄어듭니다. 그래서 긴 공액 사슬은 긴 파장의 빛을 흡수합니다. 같은 경향을 상자 속 입자 모형([화학6-02-01] 카드)으로도 보았습니다. 유기반도체의 띠 간격([화학14-02-01])도 같은 원리입니다.

적용

사이클로옥타테트라엔(C₈H₈)은 평면이 아니라 욕조 모양입니다. 고리 N = 8의 결과를 보고 이 분자가 평면을 피하는 이유를 설명해 보세요. 전자 두 개를 더 넣은 C₈H₈²⁻는 어떨까요?

판단

"고리에 이중 결합이 번갈아 있으면 모두 방향족이다." 이 장치의 N = 4와 N = 8 결과를 근거로 이 말을 고쳐 보세요.
