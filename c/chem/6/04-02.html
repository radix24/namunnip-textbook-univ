4.2.1π 전자만 따로 보기

공액 분자(뷰타다이엔, 벤젠)의 색, 안정성, 반응성은 주로 π 전자가 정합니다. σ 결합은 분자의 평면 안에 있고 π 오비탈은 평면에 수직이라, 둘은 거의 섞이지 않습니다. 1931년 휘켈은 이 점을 이용해 π 전자만 다루는 아주 단순한 분자 오비탈 이론을 만들었습니다. 계산은 손으로 할 수 있을 만큼 쉽지만, 방향족성이라는 중요한 결론을 줍니다.

4.2.2Hückel 근사

탄소 n개의 공액 사슬에서 각 탄소의 2p 오비탈 하나씩으로 LCAO를 만듭니다: \(\psi = \sum_i c_i\phi_i\). 변분 원리를 적용하면 영년 방정식이 나오는데, 여기에 세 가지 근사를 씁니다.

  1. 모든 쿨롱 적분이 같다: \(H_{ii} = \alpha\).
  2. 이웃한 탄소끼리만 공명 적분 \(H_{ij} = \beta\)가 있고, 이웃이 아니면 0이다.
  3. 겹침 적분은 무시한다: \(S_{ij} = 0\) (\(i \ne j\)), \(S_{ii} = 1\).

그러면 영년 행렬식은 대각선에 \(\alpha - E\), 이웃 자리에 β, 나머지는 0이 됩니다. 양변을 β로 나누고 \(x = (\alpha - E)/\beta\)로 두면 대각선이 x, 이웃 자리가 1인 깔끔한 행렬식이 됩니다.

4.2.3에틸렌과 뷰타다이엔

예제 4.2.1

에틸렌의 π 오비탈 에너지를 구하여라.

풀이. \(\begin{vmatrix} x & 1 \\ 1 & x \end{vmatrix} = x^2 - 1 = 0\)에서 \(x = \pm1\), 곧 \(E = \alpha \pm \beta\)입니다. β < 0이므로 \(\alpha + \beta\)가 결합성(π), \(\alpha - \beta\)가 반결합성(π*)입니다. 전자 둘이 π에 들어가 \(E_\pi = 2\alpha + 2\beta\)입니다.

예제 4.2.2

뷰타다이엔의 π 오비탈 에너지, π 에너지, 비편재화 에너지를 구하여라.

풀이. 사슬 탄소 1−2−3−4에서 1과 2, 2와 3, 3과 4만 이웃입니다.

\[ \begin{vmatrix} x & 1 & 0 & 0 \\ 1 & x & 1 & 0 \\ 0 & 1 & x & 1 \\ 0 & 0 & 1 & x \end{vmatrix} = x^4 - 3x^2 + 1 = 0 \]

\(x^2 = (3 \pm \sqrt5)/2\)에서 \(x = \pm1.618, \pm0.618\)입니다. 에너지는 \(\alpha + 1.618\beta\), \(\alpha + 0.618\beta\), \(\alpha - 0.618\beta\), \(\alpha - 1.618\beta\)이고, 전자 넷이 아래 두 오비탈에 차서

\[ E_\pi = 2(\alpha + 1.618\beta) + 2(\alpha + 0.618\beta) = 4\alpha + 4.472\beta \]

입니다. 이중 결합 두 개가 따로 있는 경우(에틸렌 두 개)는 \(4\alpha + 4\beta\)이므로, 비편재화로 \(0.472\beta\)만큼 더 안정합니다(β ≈ −75 kJ/mol로 어림하면 약 35 kJ/mol). HOMO-LUMO 간격은 \(1.236|\beta|\)로 에틸렌(\(2|\beta|\))보다 작아, 공액 분자가 더 긴 파장을 흡수한다는 사실(2.1절의 상자 속 입자 결론)과 일치합니다.

4.2.4고리와 방향족성

고리 분자는 처음과 끝 탄소도 이웃이므로 행렬식의 귀퉁이에도 1이 들어갑니다. 탄소 n개의 고리에서 오비탈 에너지는 일반식 \(x_k = 2\cos(2\pi k/n)\)으로 주어집니다. 벤젠(n = 6)은 \(\alpha + 2\beta\), \(\alpha + \beta\)(두 개), \(\alpha - \beta\)(두 개), \(\alpha - 2\beta\)이고, 전자 여섯이 아래 세 오비탈을 정확히 채워 \(E_\pi = 6\alpha + 8\beta\), 비편재화 에너지 \(2\beta\)입니다(뷰타다이엔의 네 배 이상).

고리에서는 가장 낮은 오비탈 하나 위로 에너지가 같은 오비탈이 둘씩 쌓입니다. 그래서 π 전자가 4n + 2개(2, 6, 10, …)일 때 껍질이 꽉 차 특히 안정하고(방향족), 4n개일 때는 마지막 두 전자가 같은 에너지 오비탈 두 개에 하나씩 들어가 불안정합니다(반방향족). 이것이 유기화학2의 Hückel 규칙([화학5-02-03])의 근거입니다. 고리 크기와 전하를 바꿔 직접 확인하는 탐구 카드가 이 절에 있습니다.

흔한 오해"E = α + β에서 β가 음수이니 에너지가 α보다 높다"고 읽는 실수가 많습니다. β < 0이므로 α + β는 α보다 낮습니다. x가 양수인 오비탈이 결합성입니다. 또 Hückel 이론의 숫자(0.472β 등)는 겹침과 σ 전자를 무시한 대략의 값이므로, 경향을 비교하는 데 쓰고 정확한 에너지로 믿지는 않습니다.
요약
  1. Hückel 근사: \(H_{ii} = \alpha\), 이웃만 \(H_{ij} = \beta\), 겹침 무시.
  2. x = (α − E)/β로 두면 대각선 x, 이웃 1인 행렬식을 푼다.
  3. 에틸렌 α ± β, 뷰타다이엔 α ± 1.618β, α ± 0.618β, 비편재화 에너지 0.472β.
  4. 고리는 \(x_k = 2\cos(2\pi k/n)\). 4n + 2 π 전자는 방향족(벤젠 2β), 4n은 반방향족.

4.2.5연습문제

기본

  1. 알릴 양이온(탄소 3개 사슬, π 전자 2개)의 오비탈 에너지와 E_π를 구하시오.
    답

    \(x^3 - 2x = 0\) → x = √2, 0, −√2. E_π = 2(α + 1.414β) = 2α + 2.828β.

응용

  1. 알릴 양이온, 라디칼, 음이온의 비편재화 에너지를 비교하시오.
    답

    추가 전자는 비결합성(x = 0) 오비탈에 들어가 에너지에 기여하지 않으므로 셋 모두 0.828β로 같다.

심화

  1. 사이클로뷰타다이엔의 Hückel 오비탈 에너지를 구하고, 비편재화 에너지가 0이며 홀전자가 둘인 이유를 설명하시오.
    답

    x = 2cos(2πk/4) = 2, 0, 0, −2. 전자 넷: 2개는 x = 2, 2개는 x = 0인 두 오비탈에 하나씩(훈트). E_π = 4α + 4β로 에틸렌 둘과 같아 비편재화 에너지 0, 홀전자 둘(반방향족).

4.2.2

탐구벤젠은 왜 특별히 안정하고 사이클로뷰타다이엔은 왜 불안정한가?

탐구 · Hückel 분자 오비탈, 방향족성

다루는 성취기준 [화학6-04-02] [화학5-02-03] [화학16-03-02]

목표

Hückel 방법으로 사슬과 고리 모양 공액 탄화수소의 π 오비탈 에너지를 구하고, 전자를 채워 비편재화 에너지를 계산합니다. 4n+2 규칙(방향족)과 4n 규칙(반방향족)이 오비탈 에너지 그림에서 어떻게 나오는지 봅니다. 성취기준 [화학6-04-02], 유기화학2 [화학5-02-03], 화학수학 [화학16-03-02].

준비

Hückel 방법은 각 탄소의 p 오비탈 하나씩만 생각하는 단순한 분자 오비탈 이론입니다.

α (쿨롱 적분): 탄소 p 오비탈 하나에 있는 전자의 에너지. 기준점입니다.

β (공명 적분): 이웃한 두 p 오비탈이 겹쳐 생기는 에너지. 음수입니다. 그래서 \(E = \alpha + x\beta\)에서 \(x\)가 클수록 에너지가 낮고 안정합니다.

이웃한 탄소끼리만 β로 이어진 행렬의 고유값을 구하면 됩니다. 결과는 공식으로 정리됩니다.

  • 사슬(탄소 N개): \(x_k = 2\cos\dfrac{k\pi}{N+1}\), \(k = 1,\dots,N\)
  • 고리(탄소 N개): \(x_k = 2\cos\dfrac{2\pi k}{N}\), \(k = 0,\dots,N-1\). 맨 아래 하나를 빼면 에너지가 같은 오비탈이 둘씩 짝을 이룹니다.

비편재화 에너지: 실제 π 에너지와, 이중 결합들이 서로 떨어진 에틸렌처럼 행동한다고 보았을 때(이중 결합 하나당 \(2\alpha + 2\beta\))의 에너지 차이. β 단위로 양수이면 그만큼 더 안정합니다.

그림의 가로선은 오비탈, 화살표는 전자(스핀 위·아래)입니다. 같은 에너지 오비탈은 옆으로 나란히 그렸고, 훈트 규칙에 따라 하나씩 먼저 채웁니다.

질문

벤젠(고리, N = 6)의 비편재화 에너지는 몇 β일까요? 사이클로뷰타다이엔(고리, N = 4)은 이중 결합 두 개를 가졌는데도 왜 비편재화로 얻는 것이 없을까요? 먼저 짐작해 보세요.

복원

  1. 고리 N = 6, 전하 0(벤젠)의 오비탈 에너지와 비편재화 에너지를 기록한다.
  2. 고리 N = 4(사이클로뷰타다이엔)로 바꿔 전자가 어떻게 채워지는지 본다.
  3. 고리 N = 5에서 전하 −1(사이클로펜타다이엔일 음이온), 고리 N = 7에서 전하 +1(트로필륨 양이온), 고리 N = 3에서 전하 +1을 차례로 본다.
  4. 사슬 N = 6(헥사트라이엔)의 비편재화 에너지를 벤젠과 비교한다.

설명

벤젠의 오비탈은 x = 2, 1, 1, −1, −1, −2입니다. 전자 6개가 결합성 오비탈 세 개(2, 1, 1)를 정확히 채워 \(E_\pi = 6\alpha + 8\beta\)이고, 에틸렌 세 개(\(6\alpha + 6\beta\))보다 2β만큼 더 안정합니다. 이것이 벤젠의 비편재화(공명) 에너지입니다.

사이클로뷰타다이엔은 x = 2, 0, 0, −2입니다. 전자 4개 중 둘은 x = 2에 들어가고 남은 둘은 에너지가 같은 x = 0 오비탈 두 개에 하나씩 들어갑니다. 비편재화 에너지는 0이고 홀전자가 둘인 라디칼 같은 상태라 매우 불안정합니다(반방향족). 실제 분자는 직사각형으로 찌그러져 이 상태를 피합니다.

고리에서는 맨 아래 오비탈 하나 위로 같은 에너지 오비탈이 둘씩 쌓입니다. 그래서 전자가 2개(맨 아래) + 4개씩 들어갈 때, 곧 4n+2개일 때 껍질이 꽉 찹니다. 사이클로펜타다이엔일 음이온(2.472β), 트로필륨 양이온(2.988β), 사이클로프로펜일 양이온(2.000β)이 모두 6개 또는 2개의 π 전자로 방향족입니다.

사이클로옥타테트라엔(N = 8, 전자 8개)은 비편재화 에너지가 1.657β로 양수지만 x = 0 오비탈 두 개에 홀전자가 하나씩 있어 반방향족 배치입니다. 비편재화 에너지의 부호만으로 방향족을 판정하면 안 되는 예입니다. 전자 두 개를 더한 C₈H₈²⁻(10개)는 껍질이 차서 방향족입니다.

사슬 헥사트라이엔의 비편재화 에너지는 0.988β로 벤젠(2.000β)의 절반이 안 됩니다. 고리를 닫아 양 끝이 이어지는 것이 추가 안정화를 줍니다. 알릴 라디칼(사슬 N = 3)은 0.828β이고 HOMO(x = 0)에 홀전자가 있습니다.

연결

사슬의 HOMO-LUMO 간격은 N이 커질수록 줄어듭니다. 그래서 긴 공액 사슬은 긴 파장의 빛을 흡수합니다. 같은 경향을 상자 속 입자 모형([화학6-02-01] 카드)으로도 보았습니다. 유기반도체의 띠 간격([화학14-02-01])도 같은 원리입니다.

적용

사이클로옥타테트라엔(C₈H₈)은 평면이 아니라 욕조 모양입니다. 고리 N = 8의 결과를 보고 이 분자가 평면을 피하는 이유를 설명해 보세요. 전자 두 개를 더 넣은 C₈H₈²⁻는 어떨까요?

판단

"고리에 이중 결합이 번갈아 있으면 모두 방향족이다." 이 장치의 N = 4와 N = 8 결과를 근거로 이 말을 고쳐 보세요.
