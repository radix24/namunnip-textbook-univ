7.2.1분광화학 계열

같은 금속 이온에 리간드만 바꾸어 흡수 스펙트럼을 재면, 리간드마다 Δ_o가 다른데 그 순서가 금속과 거의 무관하게 일정합니다. 이 순서를 분광화학 계열이라 합니다.

I⁻ < Br⁻ < S²⁻ < Cl⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < NH₃ < en < bipy < phen < NO₂⁻ < PPh₃ < CN⁻ < CO

약한 장 리간드: 계열의 왼쪽(할로젠화 이온). Δ가 작아 고스핀이 되기 쉽다.

강한 장 리간드: 계열의 오른쪽(CN⁻, CO). Δ가 커서 저스핀이 되기 쉽다.

이 순서는 점전하 모형으로는 설명되지 않습니다(음이온 F⁻가 중성 CO보다 훨씬 약함). 리간드의 π 성질이 핵심입니다. 할로젠화 이온 같은 π 주개는 t₂g를 밀어 올려 Δ를 줄이고, CO·CN⁻ 같은 π 받개는 t₂g의 전자를 받아 t₂g를 내려 Δ를 키웁니다(리간드장 이론, 화학13).

7.2.2금속도 Δ를 바꾼다

  • 산화수: 높을수록 리간드가 가까이 강하게 붙어 Δ가 크다. 같은 리간드에서 M³⁺는 M²⁺의 약 1.5~2배. [Fe(H₂O)₆]²⁺ 10400, [Fe(H₂O)₆]³⁺ 약 14000 cm⁻¹.
  • 주기: 3d → 4d → 5d로 갈수록 d 오비탈이 커서 리간드와 잘 겹쳐 Δ가 30~50%씩 커진다. 그래서 4d·5d 착물은 거의 모두 저스핀이다([Co(NH₃)₆]³⁺ 22900, [Rh(NH₃)₆]³⁺ 34100, [Ir(NH₃)₆]³⁺ 41200 cm⁻¹).

7.2.3고스핀 대 저스핀과 자기성

d⁴~d⁷ 팔면체 착물에서 Δ_o > P이면 저스핀, Δ_o < P이면 고스핀입니다. 홀전자 수 n으로 자기 모멘트를 어림합니다.

식 7.2.1 (스핀만의 자기 모멘트)

\[ \mu_\mathrm{s.o.} = \sqrt{n(n+2)}\ \mu_B \]

n = 1, 2, 3, 4, 5일 때 1.73, 2.83, 3.87, 4.90, 5.92 μ_B.

예제 7.2.1

[Fe(H₂O)₆]³⁺(Δ_o 약 14000, P 약 30000 cm⁻¹)과 [Fe(CN)₆]³⁻(Δ_o 약 35000 cm⁻¹)의 스핀 상태와 스핀만의 자기 모멘트를 예측하여라.

풀이. Fe³⁺는 d⁵. 물 착물은 Δ_o < P라 고스핀 t₂g³e_g², 홀전자 5개, μ = 5.92 μ_B. 사이안화 착물은 Δ_o > P라 저스핀 t₂g⁵, 홀전자 1개, μ = 1.73 μ_B(실측은 오비탈 기여로 약 2.3 μ_B). 자기 측정(구이 저울, 에반스 NMR법)으로 두 경우를 쉽게 구별합니다.

7.2.4착물의 색

d 전자가 t₂g에서 e_g로 옮겨 가는 d-d 전이가 가시광을 흡수해 착물에 색이 생깁니다. 흡수 파장은 λ(nm) = 10⁷/Δ(cm⁻¹)이고, 보이는 색은 흡수된 색의 보색입니다. [Ti(H₂O)₆]³⁺(d¹, Δ_o 20300 cm⁻¹)는 493 nm(청록)를 흡수해 보라색으로 보입니다. [Cu(H₂O)₆]²⁺는 주황~빨강(약 800 nm)을 흡수해 파랗게 보이고, 진한 암모니아를 넣어 [Cu(NH₃)₄(H₂O)₂]²⁺가 되면 Δ가 커져 흡수가 짧은 파장으로 옮겨 짙은 남색이 됩니다. d⁰(Ti⁴⁺)과 d¹⁰(Zn²⁺) 착물은 d-d 전이가 없어 대개 무색입니다.

흔한 오해"음전하가 큰 리간드일수록 강한 장"이 아닙니다. 분광화학 계열은 π 성질이 정합니다. 또 "착물의 색은 흡수한 빛의 색"이 아니라 그 보색입니다. 그리고 d-d 전이는 라포르테 금지(같은 패리티 사이)라 약해서, 착물의 색은 유기 염료보다 연합니다. 진한 색(MnO₄⁻의 보라, 사면체가 아닌 전하 이동)은 다른 전이(전하 이동)에서 옵니다.
요약
  1. 분광화학 계열: I⁻ < Br⁻ < Cl⁻ < F⁻ < H₂O < NH₃ < en < CN⁻ < CO. π 주개는 약하게, π 받개는 강하게.
  2. Δ: 산화수 높을수록, 3d < 4d < 5d. 4d·5d는 대개 저스핀.
  3. Δ_o > P → 저스핀. μ = √(n(n + 2)) μ_B.
  4. 색: λ = 10⁷/Δ nm의 빛을 흡수, 보색이 보인다. d⁰, d¹⁰은 무색.

7.2.5연습문제

기본

  1. [Mn(H₂O)₆]²⁺(고스핀 d⁵)의 홀전자 수와 스핀만의 자기 모멘트는?
    답

    5개, 5.92 μ_B.

응용

  1. [Co(NH₃)₆]³⁺(Δ_o 22900 cm⁻¹)가 흡수하는 빛의 파장과 보이는 색을 어림하시오.
    답

    10⁷/22900 = 437 nm(파랑-보라)를 흡수해 노랑~주황으로 보인다(실제 착물은 주황빛 노랑).

심화

  1. [CoF₆]³⁻는 상자기성이고 [Co(NH₃)₆]³⁺는 반자기성이다. 두 착물의 Δ_o와 P(약 21000 cm⁻¹)를 비교해 설명하고, 각 자기 모멘트를 예측하시오.
    답

    Co³⁺ d⁶. F⁻는 약한 장(Δ_o 약 13000 < P)이라 고스핀 t₂g⁴e_g², 홀전자 4, μ = 4.90 μ_B. NH₃는 더 강한 장(Δ_o 22900 > P)이라 저스핀 t₂g⁶, 홀전자 0, 반자기성.
