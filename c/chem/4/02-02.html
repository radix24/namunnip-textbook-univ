2.2.1분자를 고정 길이 숫자 벡터로

1단원의 모형은 샘플마다 같은 수의 숫자(특성)를 받았습니다. 그런데 분자는 원자 수도 모양도 제각각입니다. 그래서 어떤 분자든 같은 길이의 숫자 벡터로 바꾸는 방법이 필요합니다. 두 가지가 대표적입니다. 화학적 의미가 분명한 숫자 몇 개(기술자)를 계산하거나, 부분 구조가 있는지 없는지를 수천 개의 0/1로 나타냅니다(지문).

2.2.2분자 기술자

분자량(MW): 원자량의 합. 에탄올 46.069, 아스피린 180.159.

logP: 옥탄올-물 분배 계수의 로그. 클수록 기름(소수성)에 잘 녹는다. 실험값이 없으면 원자·조각별 기여를 더해 어림한다(예: Crippen 방법).

극성 표면적(TPSA): N, O와 거기 붙은 H의 표면적 합(Å²). 막 투과성과 관련이 깊다. 에탄올의 OH 하나가 20.23 Å².

수소 결합 주개·받개 수(HBD, HBA): N−H, O−H의 수와 N, O 원자의 수(정의에 따라 조금 다름).

회전 가능한 결합 수: 고리 밖의 단일 결합 가운데 말단이 아닌 것. 분자의 유연성.

신약 개발에서 경구 흡수가 잘 될 분자를 거르는 리핀스키의 "5의 규칙"(MW ≤ 500, logP ≤ 5, HBD ≤ 5, HBA ≤ 10)이 이런 기술자로 쓰여 있습니다. 기술자는 사람이 뜻을 이해할 수 있어 모형을 해석하기 쉽다는 장점이 있습니다.

2.2.3분자 지문

분자 지문: 길이가 정해진 비트 벡터(예: 2048비트). 각 비트는 어떤 부분 구조가 분자에 있으면 1, 없으면 0.

원형(Morgan, ECFP) 지문: 각 원자에서 시작해 반지름 1, 2, … 결합 안의 이웃 환경을 정수 하나(해시)로 요약하고, 그 정수를 비트 자리에 대응시킨 지문. 반지름 2는 ECFP4라고도 부른다.

원형 지문의 알고리즘은 "각 원자에 그 원자와 이웃의 정보를 합친 새 이름을 붙이는 일을 반복"합니다. 반복할 때마다 더 넓은 환경을 담습니다. 4.2절의 그래프 신경망이 하는 일과 구조가 같고, 다른 점은 이름 붙이는 규칙이 고정된 해시냐 학습된 함수냐입니다.

해시를 2048자리에 접어 넣으므로 서로 다른 부분 구조가 같은 비트에 떨어지는 충돌이 생길 수 있습니다. 비트가 1이라는 것은 "이 부분 구조가 있을 가능성이 크다"는 뜻이지 확실하다는 뜻은 아닙니다.

2.2.4타니모토 유사도

구하려는 것: 두 분자가 얼마나 비슷한지를 0~1의 숫자 하나로.

식 2.2.1 (타니모토 계수)

\[ T(A, B) = \frac{|A \cap B|}{|A \cup B|} \]

A, B는 두 지문에서 1인 비트의 집합. 공통으로 켜진 비트 ÷ 어느 쪽에든 켜진 비트.

원리를 보려고, 비트 대신 부분 구조 이름의 집합으로 계산해 봅시다(실제 지문보다 훨씬 단순한 가상의 예).

def tanimoto(a, b):
    return len(a & b) / len(a | b)

asp = {"벤젠 고리", "카르복실산", "에스터", "아세틸기", "오르토 이치환"}   # 아스피린
sal = {"벤젠 고리", "카르복실산", "페놀 OH", "오르토 이치환"}            # 살리실산
ibu = {"벤젠 고리", "카르복실산", "파라 이치환", "아이소뷰틸기"}          # 이부프로펜
print(round(tanimoto(asp, sal), 3), round(tanimoto(asp, ibu), 3))      # 0.5 0.286

아스피린과 살리실산은 공통 3개 / 합집합 6개로 0.5, 아스피린과 이부프로펜은 2/7 = 0.286입니다. 아스피린이 살리실산을 아세틸화한 것이라는 구조적 관계가 숫자로 드러납니다. 실제 원형 지문으로는 값이 다르게 나오지만 해석은 같습니다. 유사도 검색("이 약과 비슷한 분자를 찾아라")과 자료의 중복 제거, 3.2절의 자료 나누기에 씁니다.

2.2.5RDKit으로 계산하기

RDKit은 화학 정보학의 표준 오픈소스 라이브러리입니다(pip install rdkit).

from rdkit import Chem, DataStructs
from rdkit.Chem import Descriptors, AllChem

mol = Chem.MolFromSmiles("CC(=O)Oc1ccccc1C(=O)O")       # 아스피린
print(Descriptors.MolWt(mol))                             # 180.159 근처
print(Descriptors.MolLogP(mol), Descriptors.TPSA(mol))    # Crippen logP, TPSA (Å²)

fp1 = AllChem.GetMorganFingerprintAsBitVect(mol, 2, nBits=2048)
fp2 = AllChem.GetMorganFingerprintAsBitVect(Chem.MolFromSmiles("Oc1ccccc1C(=O)O"), 2, nBits=2048)
print(DataStructs.TanimotoSimilarity(fp1, fp2))           # 아스피린-살리실산 유사도

최근 판의 RDKit은 지문 함수를 rdFingerprintGenerator로 옮기는 중이라, 판에 따라 경고가 나오거나 이름이 다를 수 있습니다. 설치한 판의 문서를 확인하세요. 잘못된 SMILES를 넣으면 MolFromSmiles가 None을 돌려주므로, 많은 분자를 처리할 때는 None인지 먼저 확인해야 합니다.

흔한 오해"타니모토 1이면 같은 분자"가 꼭 맞지는 않습니다. 지문은 부분 구조만 보므로 입체 이성질체나 일부 위치 이성질체는 같은 지문을 가질 수 있습니다. 또 "타니모토 0.3이면 전혀 다른 분자"도 지문 종류에 따라 다릅니다. 원형 지문에서는 꽤 비슷한 분자도 0.3~0.5가 흔합니다. 그리고 기술자를 그대로 모형에 넣을 때는 크기가 다르므로 표준화합니다(1.2절).
요약
  1. 기술자: MW, logP, TPSA, HBD/HBA, 회전 결합 수. 해석이 쉽다.
  2. 지문: 부분 구조 유무의 비트 벡터. 원형(Morgan) 지문은 이웃 환경을 반지름별로 해시한다.
  3. 타니모토 T = |A∩B|/|A∪B|, 유사도 검색과 자료 나누기에 쓴다.
  4. RDKit: MolFromSmiles → Descriptors, 지문 함수. None 확인.

2.2.6연습문제

기본

  1. 두 지문에서 1인 비트가 각각 40개, 30개이고 공통이 20개이다. 타니모토 유사도는?
    답

    합집합 = 40 + 30 − 20 = 50. T = 20/50 = 0.40.

응용

  1. 카페인(C₈H₁₀N₄O₂)의 분자량을 원자량(C 12.011, H 1.008, N 14.007, O 15.999)으로 계산하고, 리핀스키 규칙의 MW 조건을 만족하는지 쓰시오.
    답

    8 × 12.011 + 10 × 1.008 + 4 × 14.007 + 2 × 15.999 = 194.19. 500 이하로 만족한다.

심화

  1. 본문의 가상 예에서 살리실산과 이부프로펜의 타니모토 유사도를 구하고, 세 분자 가운데 가장 비슷한 쌍을 쓰시오. 지문 길이를 64비트로 줄이면 유사도가 어떻게 바뀌는 경향이 있는지 설명하시오.
    답

    공통 2(벤젠 고리, 카르복실산), 합집합 6 → 0.333. 가장 비슷한 쌍은 아스피린-살리실산(0.5). 비트 수를 줄이면 서로 다른 부분 구조가 같은 비트에 떨어지는 충돌이 늘어 공통 비트가 많아 보이므로, 서로 다른 분자의 유사도가 실제보다 높게 나오는 경향이 있다.
