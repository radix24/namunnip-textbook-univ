1.1.1왜 화학 AI에 행렬이 나오나

기계 학습 모형은 "숫자의 표를 받아 숫자를 내놓는 함수"입니다. 분자 여러 개의 성질을 예측하려면, 분자마다 숫자 몇 개(특성, 기술자)를 뽑아 한 줄에 놓고, 분자를 줄마다 쌓은 표를 만듭니다. 이 표가 설계 행렬 X입니다.

샘플: 표의 한 줄. 여기서는 분자 하나.

특성(특징, 기술자): 표의 한 열. 분자에서 계산한 숫자(탄소 수, 분자량, 극성 표면적 등).

가중치 w: 모형이 학습으로 정하는 숫자들. 선형 모형에서는 특성마다 하나씩 곱하는 계수.

선형 모형의 예측은 각 샘플에서 "특성 × 가중치"를 더한 것이고, 모든 샘플을 한꺼번에 쓰면 행렬 곱 \(\hat{\mathbf y} = X\mathbf w\)가 됩니다. 신경망(4단원)도 이런 행렬 곱을 여러 번 쌓은 것입니다. 그래서 행렬 곱은 화학 AI의 가장 기본 연산입니다.

1.1.2행렬 곱을 직접 구현하기

구하려는 것: n×m 행렬 A와 m×p 행렬 B의 곱 C(n×p). 정의는 \(C_{ij} = \sum_k A_{ik}B_{kj}\)입니다. A의 i번째 줄과 B의 j번째 열을 짝지어 곱해 더합니다. 그래서 A의 열 수와 B의 행 수가 같아야 합니다.

def matmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    assert len(A[0]) == m, "A의 열 수와 B의 행 수가 같아야 합니다"
    C = [[0.0] * p for _ in range(n)]
    for i in range(n):
        for j in range(p):
            for k in range(m):
                C[i][j] += A[i][k] * B[k][j]
    return C

X = [[1, 1], [1, 2], [1, 3], [1, 4]]   # 첫 열은 절편용 1, 둘째 열은 탄소 수
w = [[-200.0], [60.0]]                 # [절편, 기울기]
print(matmul(X, w))                    # [[-140.0], [-80.0], [-20.0], [40.0]]

X는 메테인부터 뷰테인까지 네 알케인(4×2), w는 2×1이라 결과는 4×1, 곧 네 분자의 예측 끓는점입니다. 첫 열을 모두 1로 둔 것은 절편 b를 행렬 곱 안에 넣는 요령입니다(\(b \times 1 + a \times n_C\)). 실제 프로그램에서는 NumPy의 X @ w가 같은 일을 훨씬 빠르게 합니다. 세 겹 반복문은 원리를 보려고 쓴 것입니다.

1.1.3손실 함수

모형이 얼마나 틀렸는지를 숫자 하나로 나타내야 좋은 가중치를 찾을 수 있습니다.

평균 제곱 오차(MSE): \(L = \dfrac1N\sum_i (\hat y_i - y_i)^2\). 예측과 실제의 차이를 제곱해 평균한 값. 0이면 완벽하다.

제곱을 쓰는 이유는 양·음의 오차가 상쇄되지 않게 하고, 미분하기 쉽게 하기 위해서입니다. 실제 끓는점(메테인 −161.5, 에테인 −88.6, 프로페인 −42.1, 뷰테인 −0.5 °C)과 위 예측을 비교하면 L = 666.22(°C²)입니다.

1.1.4기울기 유도

구하려는 것: 가중치를 조금 바꿀 때 손실이 얼마나 바뀌는지, 곧 \(\partial L/\partial b\)와 \(\partial L/\partial a\). 이 방향을 알아야 손실을 줄이는 쪽으로 가중치를 움직일 수 있습니다(1.2절).

예측 \(\hat y_i = b + a x_i\)를 넣고 연쇄 법칙을 쓰면(제곱의 미분은 2 × 안쪽, 안쪽의 미분은 b에 대해 1, a에 대해 \(x_i\))

\[ \frac{\partial L}{\partial b} = \frac2N\sum_i(\hat y_i - y_i), \qquad \frac{\partial L}{\partial a} = \frac2N\sum_i(\hat y_i - y_i)\,x_i \]

n_c = [1, 2, 3, 4]
y = [-161.5, -88.6, -42.1, -0.5]      # 메테인~뷰테인 끓는점 (°C)

def loss(b, a):
    return sum((b + a * x - t) ** 2 for x, t in zip(n_c, y)) / len(y)

def grad(b, a):
    N = len(y)
    gb = sum(2 * (b + a * x - t) for x, t in zip(n_c, y)) / N
    ga = sum(2 * (b + a * x - t) * x for x, t in zip(n_c, y)) / N
    return gb, ga

print(round(loss(-200, 60), 2), grad(-200, 60))   # 666.22 (46.35, 133.5) 근처

두 기울기가 모두 양수이므로, b와 a를 줄이면 손실이 줄어듭니다. 기울기 a 쪽(133.5)이 더 큰 것은 탄소 수가 큰 샘플일수록 오차에 \(x_i\)가 곱해져 영향이 커지기 때문입니다. 실제 출력은 부동소수점 때문에 46.349999999999994처럼 보일 수 있습니다(공통10 6.1절).

1.1.5수치 미분으로 검산

손으로 유도한 기울기가 맞는지는 중심 차분 \(\dfrac{L(a+h) - L(a-h)}{2h}\)로 확인합니다.

h = 1e-5
print((loss(-200, 60 + h) - loss(-200, 60 - h)) / (2 * h))   # 133.50000003...

해석적 값 133.5와 소수 일곱째 자리까지 맞습니다. 기울기 코드를 새로 짤 때마다 이렇게 검산하는 습관이 신경망의 역전파(4.1절)를 디버깅할 때도 그대로 쓰입니다.

흔한 오해"행렬 곱은 같은 자리끼리 곱하는 것"이 아닙니다. 그것은 원소별 곱(NumPy의 *)이고, 행렬 곱은 줄과 열의 내적(@)입니다. 또 "기울기가 크면 손실이 크다"도 아닙니다. 기울기는 손실이 바뀌는 빠르기입니다. 최솟값에서는 손실이 0이 아니어도 기울기는 0입니다. 그리고 수치 미분의 h를 너무 작게(1e−15) 잡으면 반올림 오차 때문에 오히려 틀린 값이 나옵니다.
요약
  1. 자료는 샘플(줄) × 특성(열) 행렬 X. 선형 모형 예측은 \(\hat{\mathbf y} = X\mathbf w\), 절편은 1의 열로 넣는다.
  2. \(C_{ij} = \sum_k A_{ik}B_{kj}\). A의 열 수 = B의 행 수.
  3. MSE 손실 \(L = \frac1N\sum(\hat y - y)^2\), 기울기 \(\partial L/\partial a = \frac2N\sum(\hat y - y)x\).
  4. 해석적 기울기는 중심 차분으로 검산한다.

1.1.6연습문제

기본

  1. 10개 분자, 특성 5개짜리 설계 행렬 X에 가중치를 곱해 예측을 얻으려면 w의 크기와 결과의 크기는?
    답

    w는 5×1, 결과는 10×1(분자마다 예측 하나). 절편을 1의 열로 넣으면 X는 10×6, w는 6×1.

응용

  1. 본문의 자료와 (b, a) = (−200, 50)에서 손실과 ∂L/∂a의 부호를 구하고, a를 늘려야 하는지 줄여야 하는지 쓰시오.
    답

    예측 −150, −100, −50, 0. 오차 11.5, −11.4, −7.9, 0.5. L = (132.25 + 129.96 + 62.41 + 0.25)/4 = 81.22. ∂L/∂a = 2/4 × (11.5 − 22.8 − 23.7 + 2.0) = −16.5 < 0이므로 a를 늘려야 손실이 준다.

심화

  1. 손실을 평균 절대 오차 \(\frac1N\sum|\hat y - y|\)로 바꾸면 ∂L/∂a는 어떻게 되는가? 오차가 정확히 0인 점에서 어떤 문제가 있는가?
    답

    \(\frac1N\sum \mathrm{sign}(\hat y_i - y_i)\,x_i\). 오차 크기와 무관하게 부호만 쓴다. 오차가 0인 점에서 절댓값은 미분 불가능해 기울기가 정의되지 않는다(실제 코드에서는 0으로 둔다). 이상치에 덜 민감한 대신 최솟값 근처에서 수렴이 거칠다.
