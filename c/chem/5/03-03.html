이 절에서 배울 것
  • 치환기가 둘 이상일 때 새 치환기의 자리를 예측한다.
  • 치환기를 들이는 순서가 생성물을 정한다는 것을 알고, 목표 분자에서 거꾸로 순서를 정한다.
  • 배향을 바꾸는 작용기 변환(나이트로 → 아미노, 아실 → 알킬, 알킬 → 카복실)과 막음기(술폰산)를 쓴다.
먼저 알아야 할 것
  • 다섯 가지 EAS 반응 (3.1절), 배향 효과 (3.2절), 역합성 분석 (화학2 8.2절).

3.3.1치환기가 둘일 때

이미 치환기가 둘 있는 고리에 셋째가 들어갈 때 쓰는 규칙은 세 가지입니다.

  1. 두 치환기가 같은 자리를 가리키면 그 자리로 갑니다. 예: 4-나이트로톨루엔에서 CH₃(오르토·파라)와 NO₂(메타)가 둘 다 CH₃의 오르토(= NO₂의 메타)를 가리킵니다.
  2. 서로 다른 자리를 가리키면 더 강한 활성화기가 이깁니다. 순서는 3.2절의 표: −NH₂, −OH > −OR, −NHCOR > 알킬 > 할로젠 > 메타 지향기. 예: 4-메틸페놀은 OH의 오르토로 갑니다.
  3. 두 치환기 사이(서로 메타인 두 기 사이의 자리)에는 입체 장애 때문에 거의 들어가지 않습니다.

3.3.2순서가 생성물을 정한다

벤젠에서 브로모나이트로벤젠을 만든다고 합시다.

  • 먼저 브로민화, 다음 나이트로화: Br은 오르토·파라 지향이므로 오르토와 파라 이성질체가 생기고, 파라를 분리합니다. → 1-브로모-4-나이트로벤젠(와 2-이성질체).
  • 먼저 나이트로화, 다음 브로민화: NO₂는 메타 지향이므로 → 1-브로모-3-나이트로벤젠.

같은 두 반응이라도 순서에 따라 다른 이성질체가 나옵니다. 그래서 합성 설계는 목표 분자의 두 치환기 관계(오르토·파라인가 메타인가)를 보고 "어느 치환기가 먼저 들어가 다른 쪽을 그 자리로 이끌었는가"를 묻는 것에서 시작합니다.

3.3.3배향을 바꾸는 작용기 변환

원하는 순서가 배향 규칙과 맞지 않을 때는, 치환기를 일단 다른 형태로 들였다가 나중에 바꿉니다.

변환시약배향 변화
−NO₂ → −NH₂Fe 또는 Sn, HCl / 또는 H₂, Pd메타 → 오르토·파라(강한 활성화)
−COR → −CH₂RZn(Hg), HCl (클레멘젠) / H₂NNH₂, KOH (볼프-키시너)메타 → 오르토·파라
−CH₃ (알킬) → −CO₂HKMnO₄, 가열 (벤질 자리에 H가 있어야 함)오르토·파라 → 메타
−NH₂ → −NHCOCH₃(CH₃CO)₂O너무 센 활성화를 누그러뜨림, 큰 기라 파라 선호
−SO₃H 들이기·빼기SO₃/H₂SO₄ ↔ 묽은 H₂SO₄, 가열파라 자리를 잠시 막음

아미노기는 다이아조늄 염(Ar−N₂⁺)을 거쳐 −Cl, −Br, −CN, −OH, −H 등 거의 무엇으로든 바꿀 수 있습니다(산드마이어 반응 등, 아민 장에서 자세히). 그래서 "나이트로화 → 환원 → 다이아조늄"은 EAS로 직접 들일 수 없는 치환기를 원하는 자리에 놓는 표준 경로입니다.

3.3.4설계 순서

  1. 목표 분자의 치환기들 사이 관계(오르토·메타·파라)를 적는다.
  2. 마지막에 들어간 치환기를 하나 지우고, 남은 치환기가 그 자리로 이끌 수 있는지 확인한다. 안 되면 다른 치환기를 지워 본다.
  3. 이끌 수 있는 치환기가 없으면, 배향을 바꾸는 변환(위 표)으로 "나중에 바뀔 형태"를 생각한다.
  4. 각 단계가 실제로 가능한지 확인한다. 프리델-크래프츠는 강한 불활성화 고리에서 안 되고, 알킬화는 재배열이 있다(3.1절).
예제 3.3.1

벤젠에서 1-브로모-3-프로필벤젠(m-브로모프로필벤젠)을 합성하여라.

풀이. Br과 프로필기가 메타 관계입니다. 그런데 둘 다 오르토·파라 지향기라, 어느 쪽을 먼저 넣어도 다른 쪽을 메타로 이끌지 못합니다. 프로필기를 "나중에 알킬이 될 메타 지향기", 곧 아실기로 들이면 해결됩니다.

  1. CH₃CH₂COCl, AlCl₃ → 프로피오페논(C₆H₅COCH₂CH₃). 아실화라 재배열이 없습니다.
  2. Br₂, FeBr₃ → 아실기가 메타로 이끌어 3-브로모프로피오페논.
  3. Zn(Hg), HCl → C=O를 CH₂로 환원해 1-브로모-3-프로필벤젠.

순서를 바꿔 브로민화를 먼저 하면 Br이 오르토·파라로 이끌어 실패하고, 환원을 먼저 하면 프로필기가 오르토·파라로 이끌어 실패합니다.

예제 3.3.2

톨루엔에서 2-브로모톨루엔(o-브로모톨루엔)을 파라 이성질체 없이 얻는 방법을 쓰시오.

풀이. 톨루엔을 바로 브로민화하면 오르토와 파라가 섞여 나오고 파라가 더 많습니다. 파라 자리를 술폰산기로 먼저 막습니다. (1) SO₃, H₂SO₄ → 4-메틸벤젠술폰산(큰 기라 파라 선호). (2) Br₂, FeBr₃ → CH₃의 오르토로 들어감(SO₃H의 메타이기도 해 두 기가 같은 자리를 가리킴). (3) 묽은 H₂SO₄, 가열 → SO₃H를 떼어 2-브로모톨루엔.

흔한 오해"메타 관계면 메타 지향기를 먼저 넣으면 된다"는 둘 다 오르토·파라 지향기인 경우(예제 3.3.1)에는 쓸 수 없습니다. 이때는 작용기 변환을 생각해야 합니다. 또 나이트로화된 고리에 프리델-크래프츠 반응을 시도하는 실수가 흔합니다. NO₂가 있는 고리는 FC 반응을 하지 않으므로, FC 단계를 먼저 하거나 NO₂를 다른 단계 뒤로 미루세요. 그리고 KMnO₄ 산화는 벤질 탄소에 H가 하나라도 있어야 하므로 tert-뷰틸기는 산화되지 않습니다.
요약
  1. 치환기가 둘이면: 같은 자리를 가리키면 그곳, 다르면 강한 활성화기 우선, 두 기 사이는 피한다.
  2. 순서가 이성질체를 정한다. 목표 분자의 치환기 관계에서 거꾸로 생각한다.
  3. 배향 바꾸기: NO₂ → NH₂, COR → CH₂R(메타 → 오르토·파라), CH₃ → CO₂H(오르토·파라 → 메타). 막음기 SO₃H.

3.3.5연습문제

기본

  1. 3-나이트로톨루엔을 한 번 더 나이트로화할 때 주로 들어가는 자리를 예측하시오.
    답

    CH₃(활성화, 오르토·파라)가 이끈다. CH₃의 오르토(2번, 6번)와 파라(4번) 중 2번은 두 기 사이라 피하고, 4번과 6번에 주로 들어간다(4번은 NO₂의 오르토, 6번은 NO₂의 파라).

응용

  1. 톨루엔에서 4-나이트로벤조산과 3-나이트로벤조산을 각각 합성하는 순서를 쓰시오.
    답

    4-나이트로벤조산: 나이트로화(CH₃가 파라로 이끔, 이성질체 분리) → KMnO₄ 산화. 3-나이트로벤조산: KMnO₄ 산화(CO₂H는 메타 지향) → 나이트로화.

심화

  1. 벤젠에서 3-클로로아닐린(m-클로로아닐린)을 합성하시오. 왜 아닐린을 바로 염소화하면 안 되는지도 쓰시오.
    답

    나이트로화 → 염소화(Cl₂, FeCl₃, NO₂가 메타로 이끔) → 환원(Fe, HCl)으로 NH₂. 아닐린을 바로 염소화하면 NH₂가 강한 오르토·파라 지향기라 메타가 생기지 않고, 너무 활성이 커서 여러 번 염소화된다.
