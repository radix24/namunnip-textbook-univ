이 절에서 배울 것
  • 크로마토그램에서 머무름 시간, 불감 시간, 봉우리 너비를 읽는다.
  • 머무름 인자 k, 선택성 인자 α, 이론단 수 N, 분리능 R_s를 계산한다.
  • 분리능 식으로 분리를 좋게 하는 세 가지 방법(N, α, k)을 판단한다.
  • 추출과 이온 교환을 분리 실험의 다른 예로 안다.
먼저 알아야 할 것
  • 크로마토그래피의 원리와 판 이론 (화학1 7.2절), 용매 추출 (화학1 7.1절).

5.1.1크로마토그램 읽기

머무름 시간 t_R: 시료를 넣은 순간부터 봉우리 꼭대기가 나올 때까지의 시간.

불감 시간 t_M: 정지상에 전혀 붙지 않는 물질(이동상과 같은 속도)이 나오는 시간. 기체 크로마토그래피에서는 메테인, 액체 크로마토그래피에서는 우라실 같은 물질로 잰다.

봉우리 너비 w: 봉우리 양쪽 변곡점의 접선이 바탕선과 만나는 두 점 사이(바탕 너비, 약 4σ). 높이의 절반에서 잰 반높이 너비 w½(약 2.35σ)를 쓰기도 한다.

5.1.2네 가지 수

식 5.1.1 (크로마토그래피의 기본 수)

\[ k = \frac{t_R - t_M}{t_M}, \qquad \alpha = \frac{k_2}{k_1}\;(k_2 > k_1), \qquad N = 16\left(\frac{t_R}{w}\right)^2 = 5.54\left(\frac{t_R}{w_{1/2}}\right)^2 \]

\[ R_s = \frac{2(t_{R2} - t_{R1})}{w_1 + w_2} = \frac{1.18\,(t_{R2} - t_{R1})}{w_{1/2,1} + w_{1/2,2}} \]

  • k: 정지상에 머문 시간이 이동상에 있던 시간의 몇 배인가. 1~10이 알맞다.
  • α: 두 물질이 정지상과 상호작용하는 정도의 비. 1이면 아무리 해도 분리되지 않는다.
  • N: 관의 효율. 봉우리가 머무름 시간에 비해 얼마나 좁은가.
  • R_s: 두 봉우리가 얼마나 떨어졌는가. 1.0이면 약 2% 겹치고, 1.5 이상이면 바탕선까지 분리(겹침 0.1% 수준).
예제 5.1.1

불감 시간 1.20 min, 두 봉우리의 머무름 시간 6.40, 7.10 min, 바탕 너비 0.40, 0.44 min이다. k₁, k₂, α, N(둘째 봉우리), R_s를 구하여라.

풀이. k₁ = (6.40 − 1.20)/1.20 = 4.33, k₂ = (7.10 − 1.20)/1.20 = 4.92, α = 4.92/4.33 = 1.135. N = 16 × (7.10/0.44)² = 4170. R_s = 2 × 0.70/(0.40 + 0.44) = 1.67. 1.5 이상이므로 바탕선까지 분리되었습니다.

5.1.3분리를 좋게 하려면

분리능은 세 요인의 곱으로 쓸 수 있습니다(퍼넬 식).

식 5.1.2 (분리능의 세 요인)

\[ R_s = \frac{\sqrt N}{4}\cdot\frac{\alpha - 1}{\alpha}\cdot\frac{k_2}{1 + k_2} \]

  • N 키우기(관을 길게, 입자를 작게): \(R_s \propto \sqrt N\)이라 분리능을 두 배로 하려면 관이 네 배 길어야 하고 시간도 네 배.
  • α 키우기(정지상이나 이동상의 종류, 온도 바꾸기): 가장 효과적. α가 1.05에서 1.10이 되면 (α − 1)/α가 거의 두 배.
  • k 맞추기(이동상 세기 조절): k가 너무 작으면 k/(1 + k)가 작아 분리가 안 되고, 10을 넘으면 시간만 길어진다.

예제 5.1.1의 값(α = 1.135, k₂ = 4.92)을 넣으면 R_s = 1.5에 필요한 N은 약 3700이고, 이 관(N ≈ 4170)은 그것을 넘습니다.

5.1.4다른 분리 실험

분석 실험에서는 크로마토그래피 외에도 용매 추출(분배 계수, 화학1 7.1절)과 이온 교환을 씁니다. 이온 교환 수지는 고정된 전하(−SO₃⁻ 등)에 반대 전하 이온을 붙잡았다가 다른 이온과 교환합니다. 예를 들어 양이온 교환 수지(H⁺형)에 NaCl 용액을 흘리면 Na⁺가 붙고 같은 몰수의 H⁺가 나오므로, 나온 용액을 NaOH로 적정해 원래 염의 양을 구할 수 있습니다.

흔한 오해"머무름 시간이 다르면 분리된 것"이 아닙니다. 봉우리 너비와 함께 봐야 하며 R_s로 판단합니다. 또 "관을 두 배로 늘리면 분리능도 두 배"가 아니라 √2배입니다. 그리고 N을 계산할 때 반높이 너비에 16을 쓰거나 바탕 너비에 5.54를 쓰는 실수가 흔합니다. 너비의 종류와 계수를 짝지어 씁니다.
요약
  1. k = (t_R − t_M)/t_M, α = k₂/k₁, N = 16(t_R/w)² = 5.54(t_R/w½)².
  2. R_s = 2Δt_R/(w₁ + w₂). 1.5 이상이면 바탕선 분리.
  3. R_s = (√N/4)((α − 1)/α)(k/(1 + k)): α가 가장 효과적, N은 √로만 듣고, k는 1~10.
  4. 이온 교환: 이온을 다른 이온과 바꿔 분리·정량.

5.1.5연습문제

기본

  1. t_M = 0.90 min, t_R = 5.40 min인 물질의 k는?
    답

    (5.40 − 0.90)/0.90 = 5.0.

응용

  1. 반높이 너비 0.12 min, 머무름 시간 8.50 min인 봉우리의 N은?
    답

    5.54 × (8.50/0.12)² = 2.78×10⁴.

심화

  1. 어떤 두 물질의 R_s가 1.0이다. 같은 조건에서 관 길이만 바꿔 1.5로 만들려면 관을 몇 배로 해야 하며, 분석 시간은 어떻게 되는가?
    답

    R_s ∝ √N ∝ √L이므로 (1.5/1.0)² = 2.25배. 분석 시간도 약 2.25배 길어진다. α를 바꾸는 편이 대개 더 효율적이다.
