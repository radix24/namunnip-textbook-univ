4.1.1분광 광도 정량의 절차

  1. 파장 선택: 흡수 스펙트럼을 찍어 흡광도가 가장 큰 파장(λ_max)을 고릅니다. 감도가 크고, 파장이 조금 흔들려도 흡광도가 거의 변하지 않기 때문입니다.
  2. 표준 용액: 시료 농도를 둘러싸는 5~6개 농도를 만듭니다.
  3. 측정 범위: 흡광도 약 0.1~1.0에서 잽니다. 너무 작으면 상대 잡음이 크고, 너무 크면 빛이 거의 안 들어와 미광 때문에 직선에서 벗어납니다.
  4. 바탕 보정: 같은 용매와 시약을 넣은 바탕 용액으로 영점을 맞춥니다(4.2절).

철을 1,10-페난트롤린으로 붉은 착물로 만들어 510 nm에서 재는 실험이 대표적입니다. 착물의 몰 흡광 계수 약 11100 L/(mol·cm)는 철 1 mg/L당 흡광도 약 0.199(1 cm 셀)에 해당합니다.

4.1.2외부 검량선법

외부 검량선법: 시료와 따로 만든 표준 용액들의 신호로 직선(검량선)을 그리고, 시료 신호를 그 직선에서 읽는 방법.

예제 4.1.1

철 표준 0, 1.00, 2.00, 3.00, 4.00, 5.00 mg/L의 흡광도가 0.002, 0.201, 0.399, 0.597, 0.795, 0.998이었다. 시료(10.00 mL를 25.00 mL로 묽혀 발색)의 흡광도가 0.402이면 원래 시료의 철 농도는?

풀이. 최소제곱 직선은 A = 0.1989 C + 0.0015입니다. 측정 용액의 농도 = (0.402 − 0.0015)/0.1989 = 2.014 mg/L. 묽힘을 거꾸로: × 25.00/10.00 = 5.03 mg/L. 이 방법은 표준과 시료에서 분석물이 같은 감도를 낸다는 가정 위에 서 있습니다.

4.1.3표준물 첨가법

시료 속 다른 성분(매트릭스)이 감도를 바꾸면, 물 속에서 만든 검량선은 시료에 맞지 않습니다. 이때는 표준을 시료 속에 직접 넣어 시료 자신의 감도로 검량합니다.

표준물 첨가법: 같은 양의 시료 여러 개에 서로 다른 양의 표준을 넣고 같은 부피로 맞춘 뒤 신호를 재어, 신호 대 첨가량 직선을 첨가량 축까지 외삽해 시료 속 분석물의 양을 구하는 방법.

구하려는 것: 시료 농도 \(C_x\). 시료 \(V_x\)에 농도 \(C_s\)인 표준 \(V_s\)를 넣고 \(V_t\)로 맞추면 신호는 \(S = k(C_xV_x + C_sV_s)/V_t\)입니다. S를 \(V_s\)에 대해 그리면 직선이고, S = 0이 되는 x 절편은 \(V_s = -C_xV_x/C_s\)입니다. 따라서

식 4.1.1 (표준물 첨가의 x 절편)

\[ C_x = \frac{C_s\,|x\text{ 절편}|}{V_x} \]

감도 k가 얼마든 직선의 기울기에만 들어가고 x 절편에는 들어가지 않습니다. 이것이 매트릭스 효과(곱해지는 효과)를 바로잡는 원리입니다. 이 절의 탐구 카드에서 감도 인자를 바꿔 직접 확인할 수 있습니다.

예제 4.1.2

시료 10.00 mL에 10.0 mg/L 철 표준을 0, 1.00, 2.00, 3.00 mL 넣고 25.00 mL로 맞춘 용액의 흡광도가 0.159, 0.223, 0.287, 0.350이었다. 시료의 철 농도는?

풀이. 직선 A = 0.0637 V_s + 0.1592(mL 단위). x 절편 = −0.1592/0.0637 = −2.50 mL. C_x = 10.0 × 2.50/10.00 = 2.50 mg/L. 이 시료의 기울기(0.0637)는 물 속 표준으로 예상되는 0.0796(= 0.199 × 10.0/25)의 80%라, 매트릭스가 감도를 20% 줄이고 있었습니다. 같은 시료를 물 속 검량선으로 읽었다면 2.00 mg/L로 20% 낮게 나왔을 것입니다.

4.1.4언제 무엇을 쓰나

  • 검량선법: 시료가 많고 매트릭스가 단순하거나 표준에 같은 매트릭스를 흉내 낼 수 있을 때. 한 검량선으로 많은 시료를 잴 수 있어 효율적이다.
  • 표준물 첨가법: 매트릭스가 복잡하고 흉내 내기 어려울 때(혈액, 바닷물, 토양 추출액). 시료마다 여러 용액을 만들어야 하고, 외삽이라 불확도가 다소 크다. 신호가 첨가 범위 전체에서 직선이어야 한다.
흔한 오해"표준물 첨가법은 모든 오차를 바로잡는다"가 아닙니다. 기울기에 곱해지는 효과는 바로잡지만, 시료 자체의 색처럼 더해지는 신호는 직선을 통째로 올려 x 절편을 틀리게 하므로 바탕 보정이 따로 필요합니다(4.2절). 또 검량선 범위 밖의 시료를 외삽해 읽지 않습니다. 묽히거나 표준을 늘립니다.
요약
  1. λ_max에서, 흡광도 0.1~1.0 범위로, 시료를 둘러싼 표준으로 검량한다.
  2. 외부 검량선: 표준과 시료의 감도가 같다고 가정. 희석을 거꾸로 보정.
  3. 표준물 첨가: 시료에 표준을 넣어 직선, \(C_x = C_s|x\text{ 절편}|/V_x\). 곱해지는 매트릭스 효과를 바로잡는다.
  4. 많은 시료·단순 매트릭스는 검량선, 복잡한 매트릭스는 표준물 첨가.

4.1.5연습문제

기본

  1. 검량선 A = 0.150 C + 0.004(C는 mg/L)에서 흡광도 0.517인 용액의 농도는?
    답

    (0.517 − 0.004)/0.150 = 3.42 mg/L.

응용

  1. 표준물 첨가 직선의 x 절편이 −1.85 mL, 표준 농도 50.0 mg/L, 시료 부피 5.00 mL이다. 시료 농도는?
    답

    50.0 × 1.85/5.00 = 18.5 mg/L.

심화

  1. 예제 4.1.2에서 시료를 2.00 mL만 썼다면 같은 표준 첨가량에서 그래프가 어떻게 달라지고, 결과의 불확도에는 어떤 영향이 있는가?
    답

    시료 기여(절편)가 5분의 1로 줄고 기울기는 그대로라 x 절편이 −0.50 mL로 원점 가까이 온다. 첨가량 범위(0~3 mL)에 비해 외삽 거리가 짧아지는 것은 좋지만, 절편 자체가 작아 신호 대비 잡음의 상대 영향이 커진다. 보통 첨가량을 시료 기여의 1~3배 범위로 맞추는 것이 좋다(이 경우 표준을 0, 0.25, 0.5, 0.75 mL처럼 줄인다).

4.1.2

탐구시료가 신호를 바꾸면 검량선을 믿을 수 있나?

탐구 · 검량선법, 표준물 첨가법, 바탕 보정

다루는 성취기준 [화학3-04-01] [화학3-04-02]

목표

시료의 매트릭스가 분석물의 신호를 줄이거나 키우는 경우(곱해지는 효과)와, 매트릭스 자체가 흡광하는 경우(더해지는 효과)에 검량선법과 표준물 첨가법이 어떤 결과를 내는지 비교합니다. 성취기준 [화학3-04-01], [화학3-04-02].

준비

Fe²⁺-페난트롤린 착물(510 nm)로 철을 정량하는 가상 실험입니다. 순수한 물 속 표준의 감도는 0.199 흡광도/(mg/L)이고, 시료의 참 농도는 2.50 mg/L입니다. 표준물 첨가는 시료 10.00 mL에 10.0 mg/L 철 표준을 0, 1, 2, 3 mL 넣고 25.00 mL로 묽힙니다. 검량선법은 첨가 0 mL 용액의 흡광도를 물 속 검량선으로 읽고 묽힘을 보정합니다.

"매트릭스 감도 인자"는 시료 속 다른 성분이 착물 생성을 방해하거나(1보다 작음) 돕는(1보다 큼) 정도, "매트릭스 바탕 흡광도"는 시료 자체의 색이 510 nm에서 내는 흡광도(묽히기 전)입니다. "바탕 시료로 뺌"은 철 발색 시약을 넣지 않은 시료로 그 바탕을 재어 빼는 것입니다.

질문

시료 속 성분이 신호를 20% 줄인다면 두 방법 중 어느 쪽이 참값을 줄까요? 시료가 색을 띤다면요?

복원

  1. 감도 인자 1.00, 바탕 0으로 두 방법이 같은지 확인한다.
  2. 감도 인자 0.80, 1.15로 바꿔 두 결과를 비교한다.
  3. 감도 인자 1.00, 바탕 0.030으로 두 결과를 본 뒤 "바탕 시료로 뺌"을 켠다.
  4. 감도 인자 0.80, 바탕 0.030에서 바탕 보정을 껐다 켰다 한다.

설명

매트릭스 효과가 없으면 두 방법 모두 2.500 mg/L입니다. 감도 인자 0.80이면 검량선법은 2.000 mg/L로 20% 낮게, 1.15이면 2.875 mg/L로 높게 나오지만, 표준물 첨가법은 둘 다 2.500입니다. 표준물을 시료 속에 직접 넣으므로 표준과 분석물이 같은 매트릭스 효과를 받아 기울기 자체가 보정되기 때문입니다. 그래프의 x 절편(−2.50 mL × 10.0 mg/L ÷ 10.00 mL)이 시료 농도를 줍니다.

그러나 매트릭스가 색을 띠어 바탕 0.030이 더해지면, 감도 인자 1.00에서도 두 방법 모두 2.651 mg/L로 높게 나옵니다. 더해지는 신호는 기울기를 바꾸지 않고 직선 전체를 위로 올려 x 절편을 바깥으로 밀기 때문입니다. 바탕 시료로 빼면 둘 다 2.500으로 돌아옵니다. 감도 인자 0.80과 바탕 0.030이 함께 있으면 보정 없이 검량선법 2.151, 표준물 첨가법 2.688이고, 바탕을 빼면 검량선법 2.000, 표준물 첨가법 2.500입니다. 곧 바탕 시료는 더해지는 효과를, 표준물 첨가는 곱해지는 효과를 바로잡으며, 둘은 서로 대신할 수 없습니다.

연결

검량선과 최소제곱 직선은 [화학1-01-04], 베르-람베르트 법칙은 [화학1-07-03]에 있습니다. 원자 흡수 분광법이나 ICP처럼 매트릭스 효과가 큰 기기 분석([화학8])에서 표준물 첨가법과 내부 표준법을 자주 씁니다.

적용

바닷물 속 철을 정량하려 합니다. 높은 염 농도가 신호를 줄일 수 있고, 시료가 약간 노란색을 띱니다. 어떤 조합(검량선 또는 표준물 첨가, 바탕 보정 여부)을 쓰겠습니까? 장치로 근거를 확인해 보세요.

판단

"표준물 첨가법은 매트릭스 문제를 모두 해결하므로 바탕 시료가 필요 없다." 바탕 0.030의 결과를 근거로 이 말을 평가해 보세요.
