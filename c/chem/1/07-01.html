7.1.1

탐구같은 양의 용매라면 여러 번 나누어 추출하는 편이 나은가?

탐구 · 분배 계수, 분포비, 추출 효율

다루는 성취기준 [화학1-07-01] [화학7-02-01]

목표

분배 계수로 한 번 추출할 때와 여러 번 나누어 추출할 때 남는 양을 계산하고, 약산은 pH를 바꿔 추출 여부를 조절할 수 있다는 것을 확인합니다. 성취기준 [화학1-07-01]과 유기화학실험의 산-염기 추출 [화학7-02-01].

준비

분배 계수 \(K = [\mathrm{HA}]_{유기}/[\mathrm{HA}]_{물}\): 이온이 아닌 같은 화학종이 두 층에 나뉘는 비.

분포비 \(D\): 물층의 모든 형태(HA와 A⁻)에 대한 유기층 농도의 비. A⁻는 유기층에 녹지 않는다고 보면 \(D = K\dfrac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a}\).

물 100 mL에 녹은 분석물을 유기 용매 총 100 mL로 추출합니다. 한 번에 \(V_o\)를 쓰면 물층에 남는 분율은 \(q = \dfrac{V_{물}}{V_{물} + D V_o}\)입니다. \(n\)번 나누어 \(V_o/n\)씩 쓰면 \(q^n\)이 남습니다. 막대는 각 단계 뒤 물층에 남은 양, 빨간 점선은 100 mL로 한 번 추출한 결과입니다.

질문

K = 3인 분석물을 100 mL로 한 번 추출하면 25%가 남습니다. 33.3 mL씩 세 번 추출하면 몇 %가 남을까요? 더 많이 남을지, 적게 남을지 먼저 예측해 보세요.

복원

  1. K = 3, pH 1(분석물이 모두 HA)에서 n을 1, 2, 3, 6으로 바꾸며 남은 양을 기록한다.
  2. K를 20으로 키워 n = 1과 n = 3의 차이가 얼마나 줄어드는지 본다.
  3. K = 3, n = 3에 두고 pH를 1, 4.2, 7로 바꾼다. 출력의 D를 기록한다.

설명

세 번 나누면 \((100/(100+3\times33.3))^3 = 0.5^3 = 12.5\%\)가 남아, 한 번(25%)보다 절반이 줄어듭니다. 한 번 추출할 때마다 남은 것의 같은 비율을 덜어 내므로, 작은 비율이라도 여러 번 곱하면 빨리 작아지기 때문입니다. 여섯 번으로 나누면 8.79%까지 줄지만, 횟수를 늘리는 이득은 점점 작아집니다(아무리 잘게 나누어도 \(e^{-D V_o/V_{물}} = e^{-3} = 5.0\%\) 아래로는 가지 않습니다). K = 20이면 한 번에 4.76%, 세 번에 0.22%가 남습니다. 비율로는 나누는 효과가 여전히 크지만, 한 번만으로도 이미 95%를 넘게 뽑아냅니다.

pH가 pKa와 같으면 분석물의 절반이 A⁻라서 D = K/2, pH가 pKa보다 3 높으면 D는 K의 약 1/1000로 거의 추출되지 않습니다. 산성 물층에서 유기층으로 옮겼다가 염기성 물층으로 되돌려 빼내는 산-염기 추출이 이 원리입니다.

연결

크로마토그래피([화학1-07-02])는 이 추출을 관 안에서 수천 번 되풀이하는 것으로 볼 수 있습니다. 분배 계수가 조금만 달라도 많이 되풀이하면 두 물질이 갈라집니다.

적용

벤조산(pKa 4.2)과 나프탈렌(중성)이 섞인 에테르 용액에서 벤조산만 물층으로 빼내려면 물층 pH를 얼마로 해야 할까요? D가 0.01 아래가 되는 pH를 장치로 찾아보세요.

판단

"K가 1보다 작으면 유기 용매로는 전혀 추출할 수 없다." 장치로 K = 0.5, n = 6일 때 남는 양을 확인하고 이 말을 고쳐 보세요.
