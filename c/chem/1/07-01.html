7.1.1분리가 먼저다

실제 시료(혈액, 흙, 식품)에는 재려는 물질 말고도 수많은 물질이 섞여 있어, 그대로 재면 서로 방해합니다. 그래서 분석의 많은 부분은 "분리"입니다. 가장 간단한 분리법이 용매 추출입니다. 물과 섞이지 않는 유기 용매(에테르, 다이클로로메테인 등)를 분별 깔때기에 넣고 흔들면, 각 물질이 두 층 중 더 잘 녹는 쪽으로 옮겨 갑니다.

7.1.2분배 계수와 분포비

정의 7.1.1 (분배 계수)

용질 S가 같은 화학종으로 두 층에 나뉠 때 \(K = \dfrac{[\mathrm S]_{유기}}{[\mathrm S]_{물}}\)을 분배 계수라 한다.

정의 7.1.2 (분포비)

용질이 물층에서 여러 화학종(HA와 A⁻ 등)으로 있을 때 \(D = \dfrac{\text{유기층의 전체 농도}}{\text{물층의 전체 농도}}\)를 분포비라 한다.

K는 한 화학종의 성질이라 상수이지만, D는 조건(pH, 착화제)에 따라 바뀝니다. 실제로 얼마나 추출되는지는 D가 정합니다.

7.1.3추출하고 남는 양

부피 \(V_1\)의 물층에 용질이 있고, 부피 \(V_2\)의 유기 용매로 한 번 추출한다고 합시다. 물층에 남는 분율을 \(q\)라 하면, 유기층으로 간 양과 물층에 남은 양의 농도 비가 D이므로

\[ q = \frac{V_1}{V_1 + DV_2} \]

입니다. 새 용매로 \(n\)번 되풀이하면 매번 남은 것의 \(q\)만큼만 남으므로 \(q^n\)이 남습니다.

예제 7.1.3

D = 4인 용질이 물 100 mL에 있다. 유기 용매 100 mL로 한 번 추출할 때와, 25 mL씩 네 번 추출할 때 물층에 남는 비율을 비교하여라.

풀이. 한 번: \(q = 100/(100 + 4\times100) = 0.20\), 20% 남음. 네 번: \(q = 100/(100 + 4\times25) = 0.50\)이고 \(0.50^4 = 0.0625\), 6.25% 남음. 같은 용매로 나누어 여러 번 추출하는 편이 훨씬 효과적입니다. 이 장의 탐구 카드에서 D와 횟수를 바꿔 직접 확인할 수 있습니다.

7.1.4pH로 추출을 조절하기

약산 HA는 중성 분자일 때만 유기층에 녹고, 이온 A⁻는 물층에 남습니다. 그래서 분포비는 물층에서 HA로 있는 분율에 분배 계수를 곱한 것입니다.

식 7.1.4 (약산의 분포비)

\[ D = K\cdot\alpha_{\mathrm{HA}} = K\frac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a} \]

pH가 pKa보다 2 이상 낮으면 D ≈ K(거의 모두 추출), pH = pKa이면 D = K/2, pH가 pKa보다 2 높으면 D ≈ K/100로 거의 추출되지 않습니다. 벤조산(pKa 4.20, K = 50으로 가정)의 경우 D는 pH 2에서 49.7, pH 4.2에서 25, pH 6에서 0.78, pH 8에서 0.008입니다. 약염기(아민 RNH₂)는 반대로 염기성에서 잘 추출되고 산성에서는 RNH₃⁺가 되어 물층에 남습니다.

예제 7.1.4 (산-염기 추출 설계)

에테르에 벤조산(약산), 아닐린(약염기, 짝산 pKa 4.6), 나프탈렌(중성)이 녹아 있다. 세 물질을 나누는 절차를 설계하여라.

풀이. ① 묽은 HCl(pH 약 1)과 흔들면 아닐린이 아닐리늄 이온이 되어 물층으로 갑니다. 물층을 떼어 둡니다. ② 남은 에테르를 묽은 NaOH(pH 약 13)와 흔들면 벤조산이 벤조산 이온이 되어 물층으로 갑니다. ③ 에테르에는 나프탈렌만 남습니다. 떼어 둔 물층들은 각각 염기·산으로 중화하면 아닐린과 벤조산이 다시 중성 분자가 되어 침전하거나 새 에테르로 추출됩니다. 유기화학실험의 [화학7-02-01]이 이 절차입니다.

7.1.5금속 이온의 추출

금속 이온은 전하가 있어 유기 용매에 녹지 않습니다. 그런데 다이티존이나 8-하이드록시퀴놀린 같은 킬레이트제가 금속을 감싸 전하가 없는 착물을 만들면 유기층으로 추출됩니다. 킬레이트제는 약산이라 양성자를 내놓아야 금속과 결합하므로, 이때도 pH가 추출률을 정합니다. pH를 골라 특정 금속만 추출할 수 있고, 아주 묽은 금속을 작은 부피의 유기 용매로 옮겨 진하게 만드는(농축) 데도 씁니다.

흔한 오해"분배 계수가 1보다 작으면 추출이 안 된다"는 틀립니다. K = 0.5여도 여러 번 추출하면 상당량을 옮길 수 있습니다. 다만 효율이 낮아 다른 조건(pH, 용매)을 바꾸는 편이 낫습니다. 또 "같은 양의 용매로 여러 번 나누면 한없이 좋아진다"도 아닙니다. 아무리 잘게 나누어도 남는 양은 \(e^{-DV_2/V_1}\)보다 작아지지 않습니다.
요약
  1. 분배 계수 K는 한 화학종의 상수, 분포비 D는 조건에 따라 바뀌는 실제 추출의 척도이다.
  2. 한 번 추출 후 남는 분율 \(q = V_1/(V_1 + DV_2)\), n번이면 \(q^n\). 나누어 추출하는 편이 효과적이다.
  3. 약산 \(D = K[\mathrm{H^+}]/([\mathrm{H^+}] + K_a)\). pH로 추출을 켜고 끌 수 있다.
  4. 금속 이온은 중성 킬레이트로 만들어 추출한다.

7.1.6연습문제

기본

  1. D = 3인 용질이 물 50 mL에 있다. 유기 용매 50 mL로 한 번 추출하면 몇 %가 추출되는가?
    답

    \(q = 50/(50 + 150) = 0.25\), 75% 추출.

  2. K = 20, pKa = 5.0인 약산의 pH 7.0에서 분포비는?
    답

    \(20\times10^{-7}/(10^{-7} + 10^{-5}) = 0.198\).

응용

  1. D = 2인 물질을 물 100 mL에서 99% 이상 추출하려면 유기 용매 50 mL로 최소 몇 번 추출해야 하는가?
    답

    \(q = 100/(100 + 100) = 0.5\). \(0.5^n \le 0.01\)에서 \(n \ge 6.6\), 7번.

심화

  1. K = 50인 벤조산을 물층 pH 4.2에서 같은 부피의 에테르로 한 번 추출했다. 물층 pH를 2.0으로 바꾸면 남는 비율이 몇 배 줄어드는가?
    답

    pH 4.2: D = 25, q = 1/26 = 0.0385. pH 2.0: D = 49.7, q = 1/50.7 = 0.0197. 약 2배 줄어든다.

7.1.2

탐구같은 양의 용매라면 여러 번 나누어 추출하는 편이 나은가?

탐구 · 분배 계수, 분포비, 추출 효율

다루는 성취기준 [화학1-07-01] [화학7-02-01]

목표

분배 계수로 한 번 추출할 때와 여러 번 나누어 추출할 때 남는 양을 계산하고, 약산은 pH를 바꿔 추출 여부를 조절할 수 있다는 것을 확인합니다. 성취기준 [화학1-07-01]과 유기화학실험의 산-염기 추출 [화학7-02-01].

준비

분배 계수 \(K = [\mathrm{HA}]_{유기}/[\mathrm{HA}]_{물}\): 이온이 아닌 같은 화학종이 두 층에 나뉘는 비.

분포비 \(D\): 물층의 모든 형태(HA와 A⁻)에 대한 유기층 농도의 비. A⁻는 유기층에 녹지 않는다고 보면 \(D = K\dfrac{[\mathrm{H^+}]}{[\mathrm{H^+}] + K_a}\).

물 100 mL에 녹은 분석물을 유기 용매 총 100 mL로 추출합니다. 한 번에 \(V_o\)를 쓰면 물층에 남는 분율은 \(q = \dfrac{V_{물}}{V_{물} + D V_o}\)입니다. \(n\)번 나누어 \(V_o/n\)씩 쓰면 \(q^n\)이 남습니다. 막대는 각 단계 뒤 물층에 남은 양, 빨간 점선은 100 mL로 한 번 추출한 결과입니다.

질문

K = 3인 분석물을 100 mL로 한 번 추출하면 25%가 남습니다. 33.3 mL씩 세 번 추출하면 몇 %가 남을까요? 더 많이 남을지, 적게 남을지 먼저 예측해 보세요.

복원

  1. K = 3, pH 1(분석물이 모두 HA)에서 n을 1, 2, 3, 6으로 바꾸며 남은 양을 기록한다.
  2. K를 20으로 키워 n = 1과 n = 3의 차이가 얼마나 줄어드는지 본다.
  3. K = 3, n = 3에 두고 pH를 1, 4.2, 7로 바꾼다. 출력의 D를 기록한다.

설명

세 번 나누면 \((100/(100+3\times33.3))^3 = 0.5^3 = 12.5\%\)가 남아, 한 번(25%)보다 절반이 줄어듭니다. 한 번 추출할 때마다 남은 것의 같은 비율을 덜어 내므로, 작은 비율이라도 여러 번 곱하면 빨리 작아지기 때문입니다. 여섯 번으로 나누면 8.79%까지 줄지만, 횟수를 늘리는 이득은 점점 작아집니다(아무리 잘게 나누어도 \(e^{-D V_o/V_{물}} = e^{-3} = 5.0\%\) 아래로는 가지 않습니다). K = 20이면 한 번에 4.76%, 세 번에 0.22%가 남습니다. 비율로는 나누는 효과가 여전히 크지만, 한 번만으로도 이미 95%를 넘게 뽑아냅니다.

pH가 pKa와 같으면 분석물의 절반이 A⁻라서 D = K/2, pH가 pKa보다 3 높으면 D는 K의 약 1/1000로 거의 추출되지 않습니다. 산성 물층에서 유기층으로 옮겼다가 염기성 물층으로 되돌려 빼내는 산-염기 추출이 이 원리입니다.

연결

크로마토그래피([화학1-07-02])는 이 추출을 관 안에서 수천 번 되풀이하는 것으로 볼 수 있습니다. 분배 계수가 조금만 달라도 많이 되풀이하면 두 물질이 갈라집니다.

적용

벤조산(pKa 4.2)과 나프탈렌(중성)이 섞인 에테르 용액에서 벤조산만 물층으로 빼내려면 물층 pH를 얼마로 해야 할까요? D가 0.01 아래가 되는 pH를 장치로 찾아보세요.

판단

"K가 1보다 작으면 유기 용매로는 전혀 추출할 수 없다." 장치로 K = 0.5, n = 6일 때 남는 양을 확인하고 이 말을 고쳐 보세요.
