3.1.1레이저

원자는 두 준위의 에너지 차이와 같은 에너지의 광자를 흡수하거나 냅니다. 들뜬 원자가 저절로 빛을 내는 자발 방출 말고도, 같은 에너지의 광자가 지나가면 그 광자와 똑같은 방향, 위상, 진동수의 광자를 하나 더 내는 유도 방출이 있습니다(아인슈타인, 1917). 유도 방출이 흡수보다 많으려면 들뜬 원자가 바닥 상태 원자보다 많아야 하는데(밀도 반전), 보통의 열평형에서는 일어나지 않으므로 빛이나 전류로 원자를 계속 들뜨게 합니다(펌핑). 두 거울 사이에서 빛이 왕복하며 계속 증폭되고, 한쪽 거울로 일부가 새어 나온 것이 레이저 빛입니다. 첫 레이저는 1960년 루비로 만들어졌습니다.

레이저 빛은 한 가지 파장에 가깝고(단색성), 위상이 고르고(결맞음), 잘 퍼지지 않습니다(직진성). 광통신, 바코드, 정밀 가공, 의료, 중력파 검출기(1.2절)까지 쓰입니다.

3.1.2큐비트

보통 컴퓨터의 비트는 0 아니면 1입니다. 양자 컴퓨터의 큐비트는 두 상태 \(|0\rangle\)과 \(|1\rangle\)의 중첩

\[|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \qquad |\alpha|^2 + |\beta|^2 = 1\]

일 수 있습니다. 측정하면 확률 \(|\alpha|^2\)으로 0, \(|\beta|^2\)으로 1이 나오고, 측정한 뒤에는 그 상태로 바뀝니다. 한 번 측정해서는 \(\alpha\), \(\beta\)를 알 수 없고, 같은 상태를 여러 번 준비해 측정한 통계로 알아냅니다. 아래 실습 카드에서 측정을 되풀이해 볼 수 있습니다. 광자의 편광, 원자나 이온의 두 준위, 초전도 회로 등으로 큐비트를 만듭니다.

3.1.3얽힘과 응용

두 큐비트가 \(\frac1{\sqrt2}(|00\rangle + |11\rangle)\) 같은 상태에 있으면 하나만 따로 떼어 상태를 정할 수 없고, 한쪽을 측정하면 다른 쪽 결과와 언제나 일치합니다. 이를 얽힘이라 합니다(정보를 빛보다 빨리 보낼 수는 없음). 얽힘과 중첩을 이용하면

  • 양자 컴퓨터: 특정한 문제(큰 수의 소인수분해, 분자 시뮬레이션 등)를 보통 컴퓨터보다 훨씬 빨리 풀 수 있을 것으로 기대된다. 아직 큐비트가 잡음에 약해 오류 보정이 큰 과제다.
  • 양자 암호: 엿들으면 측정 때문에 상태가 바뀌어 들키므로, 안전하게 암호 열쇠를 나눌 수 있다(1984년 제안된 BB84 방식 등).

3학년 양자역학(1),(2)에서 이를 정확히 배웁니다. 2022년 노벨 물리학상은 얽힌 광자 실험에 주어졌습니다.

요약
  1. 레이저: 유도 방출 + 밀도 반전 + 공진기. 단색, 결맞음, 직진.
  2. 큐비트: \(\alpha|0\rangle + \beta|1\rangle\), 측정 확률 \(|\alpha|^2\), \(|\beta|^2\).
  3. 얽힘: 양자 컴퓨터, 양자 암호.

3.1.4연습문제

기본

  1. \(|\psi\rangle = \frac{\sqrt3}{2}|0\rangle + \frac12|1\rangle\)을 1000번 준비해 측정하면 1이 대략 몇 번 나오는가?
    답

    확률 \(\frac14\), 약 250번(표준편차 약 14).

3.1.2

실습큐비트를 측정하면

실습 · 중첩과 측정 확률

다루는 성취기준 [물리15-03-01]

목표

큐비트 상태 \(\cos\frac\theta2|0\rangle + e^{i\varphi}\sin\frac\theta2|1\rangle\)을 정하고 측정을 되풀이해, 한 번의 결과는 무작위이지만 여러 번의 비율이 이론 확률로 다가가는 것을 봅니다. 측정 방향(기저)을 바꾸면 확률이 달라지는 것도 확인합니다. 성취기준 [물리15-03-01].

준비

왼쪽 구(블로흐 구)의 빨간 화살표가 상태를 나타냅니다. 위쪽 끝이 \(|0\rangle\), 아래쪽 끝이 \(|1\rangle\)입니다. 오른쪽 막대는 측정 결과의 비율, 파란 가로선은 이론 확률입니다. Z 측정은 \(|0\rangle\)인지 \(|1\rangle\)인지, X 측정은 \(|\pm\rangle = \frac1{\sqrt2}(|0\rangle \pm |1\rangle)\) 가운데 어느 것인지를 묻습니다.

절차

  1. θ = 60°에서 "1번 측정"을 여러 번 눌러 결과가 무작위인지 본다.
  2. "100번 측정"을 몇 번 눌러 1의 비율이 이론 확률 \(\sin^2 30° = 0.25\)로 다가가는지 본다.
  3. θ = 0°, 90°, 180°에서 Z 측정을 해 본다.
  4. θ = 90°로 두고 X 측정으로 바꾼 뒤 φ를 0°, 90°, 180°로 바꾼다.

기대 결과

  • 한 번의 결과는 예측할 수 없지만, 측정 수가 늘면 비율이 0.25 근처로 모이고 흔들림은 \(1/\sqrt N\)처럼 준다.
  • θ = 0°이면 늘 0, 180°이면 늘 1, 90°이면 반반.
  • θ = 90°에서 Z 측정은 φ와 상관없이 반반이지만, X 측정은 φ = 0°이면 늘 +, 180°이면 늘 −, 90°이면 반반이다. 위상 φ는 Z 측정으로는 보이지 않는다.

분석

  1. Z 측정의 결과가 같은 두 상태(φ만 다른 상태)를 X 측정으로 구별할 수 있는 까닭을 말해 보세요.
  2. 양자 암호가 엿듣기를 알아챌 수 있는 까닭을, 엿듣는 사람이 측정 기저를 모른다는 것과 이어 설명해 보세요.

더 해 보기

공통7의 이항분포(공통7 4.2절)로, 100번 측정했을 때 1이 15번 이하로 나올 확률을 \(p = 0.25\)에서 구해 보세요.
