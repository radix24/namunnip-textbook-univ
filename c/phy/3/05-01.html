5.1.1보어 모형

보어(1913)는 전자가 원 궤도를 돌되, 각운동량이 \(L = n\hbar\)인 궤도만 허용되고, 궤도 사이를 뛸 때 에너지 차이만큼의 광자를 낸다고 가정했습니다. 쿨롱 힘 = 구심력과 합치면

\[r_n = n^2a_0,\quad a_0 = \frac{4\pi\varepsilon_0\hbar^2}{m_ee^2} = 0.0529\ \text{nm}, \qquad E_n = -\frac{13.6\ \text{eV}}{n^2}.\]

전이 \(n_i \to n_f\)의 광자는 \(\frac1\lambda = R_\infty\left(\frac1{n_f^2} - \frac1{n_i^2}\right)\), \(R_\infty = 1.097\times10^7\) m⁻¹로 경험식(뤼드베리)을 재현합니다. \(n_f = 1\)이 라이먼(자외선), 2가 발머(가시광선), 3이 파셴(적외선) 계열입니다. 환산 질량을 쓰면 더 정확해집니다(물리1 5.1절). 각운동량 조건은 둘레에 드브로이 파장이 정수 개 들어간다는 \(2\pi r = n\lambda\)와 같습니다.

예제 5.1.1

발머 계열의 첫 선(Hα, \(3 \to 2\))의 파장은?

풀이. \(\frac1\lambda = 1.097\times10^7\left(\frac14 - \frac19\right) = 1.524\times10^6\) m⁻¹, \(\lambda \approx 656\) nm(빨강).

5.1.2보어 모형의 한계

  • 전자가 둘 이상인 원자의 스펙트럼을 설명하지 못한다.
  • 선의 세기와 미세 구조를 설명하지 못한다.
  • 바닥 상태의 각운동량을 \(\hbar\)로 주지만 실제는 0이다.
  • 궤도라는 개념 자체가 불확정성 원리와 맞지 않는다.

5.1.3양자역학의 수소 원자

3차원 슈뢰딩거 방정식을 쿨롱 퍼텐셜로 풀면(물리8) 상태가 세 양자수로 정해집니다.

  • 주양자수 \(n = 1, 2, \dots\): 에너지 \(E_n = -13.6/n^2\) eV (보어와 같다).
  • 궤도 양자수 \(\ell = 0, \dots, n - 1\): 각운동량 크기 \(\sqrt{\ell(\ell + 1)}\hbar\). \(\ell = 0, 1, 2, 3\)을 s, p, d, f라 한다.
  • 자기 양자수 \(m_\ell = -\ell, \dots, \ell\): 각운동량의 \(z\) 성분 \(m_\ell\hbar\).

같은 \(n\)에 \(n^2\)개의 상태가 같은 에너지를 가집니다(전자 스핀을 넣으면 \(2n^2\)). 전자는 궤도가 아니라 확률 구름으로 퍼져 있고, 바닥 상태(1s)에서 전자를 찾을 확률이 가장 큰 반지름이 \(a_0\)입니다. 보어 모형이 에너지를 맞힌 것은 쿨롱 퍼텐셜의 특별한 성질 덕분입니다.

요약
  1. 보어: \(L = n\hbar\), \(E_n = -13.6/n^2\) eV, \(r_n = n^2a_0\), 뤼드베리 식.
  2. 양자역학: \(n, \ell, m_\ell\). 에너지는 같고, 확률 구름과 각운동량이 다르다.

5.1.2

예제수소 원자의 Balmer 선 계산

Bohr 에너지 · 전이 · 환산 질량 · 문제 해결 전략

다루는 성취기준 [물리3-05-01]

출발점

수소의 에너지 준위 \(E_n = -\frac{13.6\ \text{eV}}{n^2}\)는 Bohr 모형과 Schrödinger 방정식이 같은 값을 줍니다. 전이 \(n_i \to n_f\)에서 나오는 광자는 \(hf = E_{n_i} - E_{n_f}\)입니다.

문제 해결 전략 · 원자 스펙트럼
  1. 두 준위의 에너지 차를 구한다.
  2. \(\lambda = hc/\Delta E\)(\(hc = 1240\) eV·nm).
  3. 계열(Lyman \(n_f = 1\), Balmer \(n_f = 2\))과 파장 영역을 확인한다.
  4. 정밀 비교가 필요하면 환산 질량 보정을 넣는다.

Balmer 계열의 첫 두 선(\(3 \to 2\), \(4 \to 2\))과 계열 한계의 파장을 구하여라.

풀이

  1. \(3 \to 2\): \(\Delta E = 13.6(\frac14 - \frac19) = 1.889\) eV, \(\lambda = 1240/1.889 = 656\) nm(빨강, \(\text{H}_\alpha\)).
    가시광.
  2. \(4 \to 2\): \(\Delta E = 13.6(\frac14 - \frac1{16}) = 2.55\) eV, \(\lambda = 486\) nm(청록, \(\text{H}_\beta\)).
    두 번째 선.
  3. 한계(\(\infty \to 2\)): \(\Delta E = 3.40\) eV, \(\lambda = 365\) nm.
    선들이 이 파장으로 몰린다.
  4. 환산 질량 보정: 13.6 eV에 \(\mu/m_e = 0.99946\)이 이미 들어간 값이면 그대로, 무한 질량 Rydberg(13.606 eV)를 쓰면 0.05% 줄인다.
    물리1 예제 5.1.1.

의미

Bohr 모형은 에너지 준위는 맞히지만, 전자가 원 궤도를 돈다는 그림, 각운동량 \(n\hbar\)(바닥 상태는 실제로 \(\ell = 0\)), 선의 세기와 미세 구조는 설명하지 못합니다. 양자역학은 같은 준위를 주면서 이 문제들을 해결합니다.

검산

관측값 \(\text{H}_\alpha\) 656.3 nm, \(\text{H}_\beta\) 486.1 nm(공기 중)와 맞습니다.
