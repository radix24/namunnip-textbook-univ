4.2.1무한 우물

\(0 < x < L\)에서 \(U = 0\), 바깥은 \(U = \infty\)입니다. 바깥에서 \(\psi = 0\)이고, 안에서 \(\psi'' = -k^2\psi\) (\(k^2 = 2mE/\hbar^2\))이므로 \(\psi = A\sin kx + B\cos kx\). 연속 조건 \(\psi(0) = 0\)에서 \(B = 0\), \(\psi(L) = 0\)에서 \(kL = n\pi\)입니다.

정리 4.2.1 \[\psi_n(x) = \sqrt{\frac2L}\sin\frac{n\pi x}{L}, \qquad E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2h^2}{8mL^2},\quad n = 1, 2, 3, \dots\]
  • 에너지가 띄엄띄엄하다(양자화). 줄의 정상파와 같은 이유다.
  • 가장 낮은 에너지 \(E_1 > 0\): 갇힌 입자는 정지할 수 없다(불확정성 원리와 일치).
  • \(\psi_n\)은 마디가 \(n - 1\)개. 서로 다른 \(n\)의 파동함수는 직교한다.
  • \(n\)이 크면 \(|\psi|^2\)이 빠르게 출렁여 평균이 고르게 되어 고전적 결과(어디서나 같은 확률)에 다가간다(대응 원리).
예제 4.2.2

폭 1.0 nm 우물에 갇힌 전자의 \(E_1\)과, \(n = 2 \to 1\) 전이에서 나오는 빛의 파장은?

풀이. \(E_1 = \frac{h^2}{8m_eL^2} = \frac{(1240\ \text{eV·nm})^2}{8(511\times10^3\ \text{eV})(1.0\ \text{nm})^2} \approx 0.376\) eV. \(\Delta E = 3E_1 = 1.13\) eV, \(\lambda = 1240/1.13 \approx 1100\) nm. 양자점의 크기를 바꾸면 색이 바뀌는 까닭입니다(작을수록 파랗게).

4.2.2조화 진동자

\(U = \frac12m\omega^2x^2\)이면 슈뢰딩거 방정식을 풀어(물리8에서 자세히)

\[E_n = \left(n + \frac12\right)\hbar\omega, \qquad n = 0, 1, 2, \dots\]

준위가 같은 간격 \(\hbar\omega\)로 놓이고, 바닥 상태도 \(\frac12\hbar\omega\)의 영점 에너지를 가집니다. 바닥 상태 파동함수는 가우스 함수 \(\psi_0 \propto e^{-m\omega x^2/2\hbar}\)로, 불확정성 원리의 최소값 \(\Delta x\Delta p = \hbar/2\)를 갖습니다. 분자의 진동 스펙트럼이 거의 같은 간격의 선으로 나타나는 것이 이 결과이며, 플랑크가 가정한 \(hf\) 단위의 에너지도 이것과 이어집니다. 아래 실습 카드에서 두 퍼텐셜의 준위와 파동함수를 비교할 수 있습니다.

요약
  1. 무한 우물: \(E_n = n^2h^2/(8mL^2)\), \(\psi_n = \sqrt{2/L}\sin(n\pi x/L)\).
  2. 조화 진동자: \(E_n = (n + \frac12)\hbar\omega\), 같은 간격, 영점 에너지.

4.2.3연습문제

기본

  1. 무한 우물의 바닥 상태에서 입자를 \(0 < x < L/4\)에서 찾을 확률은?
    답

    \(\frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac14 - \frac1{2\pi} \approx 0.091\).

4.2.2

실습우물과 진동자의 에너지 준위

실습 · 고유 상태

다루는 성취기준 [물리3-04-02] [물리3-04-01]

목표

무한 우물과 조화 진동자의 에너지 준위와 파동함수(또는 확률밀도)를 나란히 보고, 준위 간격, 마디 수, 고전적으로 금지된 영역의 확률을 비교합니다. 성취기준 [물리3-04-02], [물리3-04-01].

준비

검은 선은 퍼텐셜, 가로선은 에너지 준위, 빨간 가로선은 고른 준위입니다. 파란 곡선은 그 준위의 파동함수(또는 \(|\psi|^2\))를 준위 높이에 맞춰 그린 것입니다. 무한 우물의 \(n\)은 1부터, 조화 진동자의 \(n\)은 0부터 셉니다.

절차

  1. 무한 우물에서 n을 1부터 5까지 바꾸며 마디 수와 준위 간격을 본다(n = 0은 없는 상태라 그려지지 않는다).
  2. 조화 진동자로 바꿔 같은 일을 한다.
  3. 조화 진동자에서 \(|\psi|^2\)을 켜고 되돌이점 바깥의 확률을 n마다 읽는다.
  4. n = 5의 \(|\psi|^2\)이 고전적 확률(되돌이점 근처에서 큼)과 어떻게 닮았는지 본다.

기대 결과

  • 무한 우물은 준위가 \(n^2\)으로 점점 벌어지고, 조화 진동자는 늘 같은 간격 \(\hbar\omega\)다.
  • 마디 수는 우물에서 \(n - 1\), 진동자에서 \(n\)이다(둘 다 바닥 상태는 마디 0).
  • 진동자의 바닥 상태는 금지된 영역에서 찾을 확률이 약 16%이고, n이 커지면 줄어든다.
  • n이 크면 확률이 되돌이점 근처에서 커져 고전 진동자(되돌이점에서 느려 오래 머묾)와 닮아 간다.

분석

  1. 두 퍼텐셜의 준위 간격이 다른 까닭을, 에너지가 높아질수록 우물의 벽은 그대로이고 진동자의 벽은 넓어진다는 것으로 설명해 보세요.
  2. 바닥 상태 에너지가 0이 아닌 까닭을 불확정성 원리로 말해 보세요.
