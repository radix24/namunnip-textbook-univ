3.4.1직렬 RLC

\(Z = R + i\left(\omega L - \frac1{\omega C}\right)\)이므로 전류 진폭 \(I_0 = V_0/|Z|\)는 허수부가 0인 진동수

\[\omega_0 = \frac1{\sqrt{LC}}, \qquad f_0 = \frac1{2\pi\sqrt{LC}}\]

에서 가장 크고(\(I_0 = V_0/R\)), 이때 전류와 전압의 위상이 같습니다. 저항 전압 \(V_R = I_0R\)이 전류에 비례하므로 저항 양 끝을 오실로스코프로 보면 공명 곡선을 얻습니다.

  • 품질 인자 \(Q = \frac{\omega_0L}{R} = \frac1R\sqrt{\frac LC}\).
  • 전력이 절반이 되는 두 진동수 사이(대역폭) \(\Delta f = f_0/Q = \frac{R}{2\pi L}\).
  • 공명에서 축전기와 인덕터 전압의 진폭은 각각 입력의 \(Q\)배다. \(Q\)가 크면 입력보다 훨씬 큰 전압이 생긴다.

물리1 4.3절의 역학 진동자와 \(L \leftrightarrow m\), \(R \leftrightarrow b\), \(1/C \leftrightarrow k\), 전하 \(q \leftrightarrow x\)로 정확히 대응합니다.

예제 3.4.1

\(L = 10\) mH, \(C = 10\) nF, \(R = 100\ \Omega\)(인덕터 도선 저항과 함수 발생기 출력 저항 포함)일 때 \(f_0\), \(Q\), 대역폭은?

풀이. \(f_0 = \frac1{2\pi\sqrt{10^{-2}\times10^{-8}}} \approx 15.9\) kHz. \(Q = \frac1{100}\sqrt{10^{-2}/10^{-8}} = 10\). 대역폭 약 1.59 kHz.

3.4.2측정할 때 주의할 점

  • 공명 근처에서는 진동수 간격을 좁혀 여러 점을 잰다.
  • 함수 발생기의 출력 저항(보통 50 Ω)과 인덕터 도선 저항이 \(R\)에 더해져, 측정한 \(Q\)가 이론값보다 작다.
  • 공명에서 입력 전압이 처지는지 확인하고, 입력도 함께 재어 비를 쓴다.
  • 위상차가 0이 되는 진동수로 \(f_0\)를 정하면 진폭 봉우리보다 정확하다.

병렬 RLC는 공명에서 임피던스가 가장 커져, 라디오의 동조 회로처럼 원하는 진동수만 골라 냅니다.

요약
  1. \(f_0 = 1/(2\pi\sqrt{LC})\), \(Q = \frac1R\sqrt{L/C}\), 대역폭 \(f_0/Q\).
  2. 공명에서 전류 최대, 위상 0, \(V_C = V_L = QV_0\).

3.4.3연습문제

기본

  1. 측정한 \(f_0 = 15.2\) kHz, \(C = 10.0\) nF일 때 \(L\)은?
    답

    \(L = \frac1{(2\pi f_0)^2C} \approx 11.0\) mH.
