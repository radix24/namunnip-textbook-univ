1.2.1두 종류의 불확도

  • A형: 같은 양을 \(n\)번 재어 통계로 구한다. 평균의 표준 불확도는 \(u_A = s/\sqrt n\) (\(s\)는 표본 표준편차).
  • B형: 계기의 정확도, 눈금 간격처럼 통계가 아닌 정보로 구한다. 값이 \(\pm a\) 안에 고르게 있다고 보면 \(u_B = a/\sqrt3\) (균일분포의 표준편차).
  • 합성 표준 불확도: \(u = \sqrt{u_A^2 + u_B^2}\).

결과는 "\(R = (4.72 \pm 0.03)\ \text{k}\Omega\)"처럼 쓰고, 불확도는 보통 유효숫자 한두 자리, 값은 불확도의 자리까지 반올림합니다. 신뢰수준을 높이려면 포함 인자 \(k = 2\)를 곱한 확장 불확도(약 95%)를 쓰기도 하며, 그때는 \(k\)를 함께 밝힙니다.

1.2.2불확도의 전파

\(q = f(x, y, \dots)\)이고 \(x, y\)의 불확도가 서로 독립이면

\[u_q = \sqrt{\left(\frac{\partial f}{\partial x}u_x\right)^2 + \left(\frac{\partial f}{\partial y}u_y\right)^2 + \cdots}.\]
처음 보는 수학 · 편미분과 제곱합 \(\frac{\partial f}{\partial x}\)는 편미분입니다. 다른 변수는 상수로 두고 \(x\)로만 미분한 값으로, "\(x\)가 조금 바뀔 때 \(q\)가 바뀌는 비율"입니다. 그래서 \(x\)가 \(u_x\)만큼 틀리면 \(q\)는 약 \(\frac{\partial f}{\partial x}u_x\)만큼 틀립니다. 서로 독립인 오차는 같은 쪽으로 겹칠 때도, 서로 지울 때도 있으므로 그냥 더하지 않고 제곱해 더한 뒤 제곱근을 씌웁니다. 예를 들어 \(q = xy\)이면 \(\frac{\partial q}{\partial x} = y\), \(\frac{\partial q}{\partial y} = x\)라 \(u_q = \sqrt{(yu_x)^2 + (xu_y)^2}\)이고, 양변을 \(q = xy\)로 나누면 아래 "곱과 몫" 규칙이 됩니다.

자주 쓰는 경우는 다음과 같습니다.

  • 합과 차: 절대 불확도의 제곱합. \(q = x \pm y\)이면 \(u_q = \sqrt{u_x^2 + u_y^2}\).
  • 곱과 몫: 상대 불확도의 제곱합. \(q = xy\) 또는 \(x/y\)이면 \(\frac{u_q}{|q|} = \sqrt{\left(\frac{u_x}x\right)^2 + \left(\frac{u_y}y\right)^2}\).
  • 거듭제곱: \(q = x^n\)이면 \(\frac{u_q}{|q|} = |n|\frac{u_x}{|x|}\).
예제 1.2.1

저항에 걸린 전압 \(V = 5.02\) V (\(u = 0.02\) V), 흐르는 전류 \(I = 1.063\) mA (\(u = 0.005\) mA). 저항과 그 불확도는?

풀이. \(R = 4.722\) kΩ. 상대 불확도 \(\sqrt{(0.02/5.02)^2 + (0.005/1.063)^2} = \sqrt{0.00398^2 + 0.00470^2} \approx 0.00616\). \(u_R \approx 0.029\) kΩ. \(R = (4.72 \pm 0.03)\) kΩ.

전파 공식은 불확도가 작아 \(f\)를 직선으로 어림할 수 있을 때 맞습니다. 불확도가 큰 쪽 하나가 결과를 거의 정하므로, 실험을 개선할 때는 가장 큰 기여부터 줄입니다. 측정 사이에 상관이 있으면(같은 계기로 잰 두 값) 공분산 항을 더해야 합니다(공통12 5.3절).

요약
  1. A형 \(s/\sqrt n\), B형 \(a/\sqrt3\), 합성 \(\sqrt{u_A^2 + u_B^2}\).
  2. 합·차는 절대 불확도, 곱·몫은 상대 불확도의 제곱합.

1.2.3연습문제

기본

  1. 진자의 길이 \(L = 1.000 \pm 0.002\) m, 주기 \(T = 2.006 \pm 0.004\) s일 때 \(g = 4\pi^2L/T^2\)과 그 불확도는?
    답

    \(g \approx 9.81\) m/s². 상대 불확도 \(\sqrt{0.002^2 + (2\times0.002)^2} \approx 0.0045\), \(u_g \approx 0.04\) m/s².

1.2.2

예제진자로 잰 중력 가속도의 불확도

불확도 전파 · 반복 측정 · 문제 해결 전략

다루는 성취기준 [물리2-01-02]

출발점

측정값 \(q = f(x, y)\)의 불확도는 독립인 측정에서 \(\delta q = \sqrt{(\partial_xf\,\delta x)^2 + (\partial_yf\,\delta y)^2}\)입니다. 여기서 \(\partial_xf\)는 \(y\)를 상수로 두고 \(x\)로만 미분한 값(편미분, 물리2 1.2절)으로, \(x\)가 조금 바뀔 때 \(q\)가 바뀌는 비율입니다. 거듭제곱 꼴이면 상대 불확도로 쓰면 편합니다.

문제 해결 전략 · 불확도 전파
  1. 각 측정의 불확도를 정한다(눈금의 반, 반복 측정의 표준 오차).
  2. 식을 거듭제곱 꼴로 쓰고 상대 불확도에 지수를 곱한다.
  3. 제곱합의 제곱근으로 더한다.
  4. 가장 큰 기여를 찾아 개선 방법을 정한다.

진자 길이 \(L = 1.000 \pm 0.002\) m, 20번 진동 시간 \(40.2 \pm 0.2\) s를 쟀다. \(g = 4\pi^2L/T^2\)과 그 불확도를 구하여라.

풀이

  1. \(T = 2.010 \pm 0.010\) s(20으로 나눔). \(g = 4\pi^2\times1.000/2.010^2 = 9.772\) m/s².
    여러 번 재서 시간 불확도를 줄였다.
  2. 상대 불확도: \(\delta L/L = 0.2\%\), \(2\delta T/T = 2\times0.50\% = 1.0\%\).
    \(T^2\)이라 지수 2.
  3. \(\delta g/g = \sqrt{0.2^2 + 1.0^2}\% = 1.02\%\), \(\delta g = 0.10\) m/s².
    제곱합.
  4. 결과 \(g = 9.77 \pm 0.10\) m/s². 표준값 9.80과 불확도 안에서 맞다.
    유효 숫자는 불확도에 맞춘다.

의미

시간 측정이 불확도를 지배합니다. 20번 대신 100번 진동을 재면 시간 불확도가 1/5로 줄어 \(g\)의 불확도도 거의 1/5가 됩니다. 길이를 더 정밀하게 재는 것은 별 도움이 안 됩니다.

검산

\(T\)를 0.010 s 늘려 다시 계산하면 \(g = 9.675\), 차이 0.097. 전파 공식(시간 기여 0.098)과 맞습니다.
