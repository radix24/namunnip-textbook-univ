이 절에서 배울 것
  • 연산증폭기로 신호를 더하고, 적분하고, 미분하는 회로를 해석한다.
  • 사각파와 삼각파를 넣어 출력을 예측하고 실제 회로의 한계를 안다.
먼저 알아야 할 것
  • 반전 증폭기와 가상 접지 (6.1절), 축전기 전류 \(I = C\,dV/dt\).

6.2.1가산기

반전 증폭기의 (−) 입력에 저항 여러 개로 신호를 모으면, 가상 접지 덕분에 각 입력 전류가 서로 영향 없이 더해져

\[V_{\text{out}} = -R_f\left(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots\right).\]

저항을 모두 같게 하면 단순 합(부호 반대), 2배씩 다르게 하면 2진수를 전압으로 바꾸는 D/A 변환기가 됩니다(물리6에서 다룸).

6.2.2적분기

되먹임 저항 대신 축전기 \(C\)를 쓰면, 입력 전류 \(V_{\text{in}}/R\)이 모두 축전기를 충전하므로

\[V_{\text{out}}(t) = -\frac1{RC}\int V_{\text{in}}\,dt.\]

사각파를 넣으면 일정한 기울기로 오르내리는 삼각파가 나옵니다. 입력에 아주 작은 직류 성분(오프셋)이라도 있으면 출력이 계속 쌓여 전원 전압에 붙으므로, 실제 회로에서는 축전기와 병렬로 큰 저항(예: \(10R\))을 달아 낮은 진동수의 이득을 제한합니다. 사인파 입력에 대해서는 이득이 \(\frac1{\omega RC}\)인 반전 저역 통과 회로로 볼 수 있습니다.

예제 6.2.1

\(R = 10\) kΩ, \(C = 0.1\ \mu\)F 적분기에 1 kHz, ±1 V 사각파를 넣으면 출력 삼각파의 봉우리-골짜기는?

풀이. 반주기 0.5 ms 동안 기울기 \(\frac{1}{RC} = 1000\) V/s로 바뀌므로 0.5 V.

6.2.3미분기

입력 쪽에 축전기, 되먹임에 저항을 쓰면 \(V_{\text{out}} = -RC\frac{dV_{\text{in}}}{dt}\)입니다. 삼각파는 사각파로, 사각파는 모서리마다 뾰족한 펄스로 바뀝니다. 이득이 진동수에 비례해 커지므로 높은 진동수 잡음을 크게 키우고 불안정해지기 쉬워, 입력 축전기에 작은 저항을 직렬로 달아 높은 진동수에서 이득을 제한합니다.

적분기와 가산기를 이어 붙이면 미분방정식을 전압으로 푸는 아날로그 계산기가 됩니다. 예를 들어 \(\ddot x = -\omega^2x\)는 적분기 두 개와 반전기 하나로 사인파 발진기가 됩니다. "연산증폭기"라는 이름이 여기서 왔습니다.

요약
  1. 가산기 \(-R_f\sum V_i/R_i\).
  2. 적분기 \(-\frac1{RC}\int V\,dt\) (병렬 큰 저항으로 쌓임 방지), 미분기 \(-RC\,dV/dt\) (직렬 작은 저항으로 잡음 제한).

6.2.4연습문제

기본

  1. \(R = 1\) kΩ, \(C = 1\ \mu\)F 미분기에 기울기 ±2000 V/s인 삼각파를 넣으면 출력은?
    답

    \(\mp RC\times2000 = \mp2\) V인 사각파.
