2.3.1깁스 인자

계가 큰 저장소와 에너지뿐 아니라 입자도 주고받으면, 2.2절과 같은 논증에서 \(\ln\Omega_R(U_0 - E_s, N_0 - N_s)\)를 전개해 \(\partial S_R/\partial N = -\mu/T\)를 쓰면

정리 2.3.1 \[P(s) = \frac{e^{-(E_s - \mu N_s)/kT}}{\mathcal Z}, \qquad \mathcal Z = \sum_se^{-(E_s - \mu N_s)/kT}, \qquad \bar N = kT\frac{\partial\ln\mathcal Z}{\partial\mu}.\]

\(\mu\)는 저장소가 정합니다. 입자가 들어가면 에너지가 \(\mu\)만큼 공짜로 생기는 것처럼 계산됩니다. \(\mu\)가 클수록 입자가 많이 들어옵니다. 양자 통계(4장)는 이 앙상블로 아주 쉽게 유도됩니다.

2.3.2화학 퍼텐셜의 뜻

  • 입자는 \(\mu\)가 높은 곳에서 낮은 곳으로 흐르고, 평형에서 \(\mu\)가 같아진다.
  • 이상기체: \(\mu = -kT\ln\frac{n_Q}{n}\) (\(n_Q\)는 양자 농도, 4.2절). 묽을수록 \(\mu\)가 낮다(음으로 크다).
  • 중력장 속에서는 \(\mu\)에 \(mgz\)가 더해져, 같은 \(\mu\) 조건에서 대기 밀도가 \(e^{-mgz/kT}\)로 준다(기압 공식).
예제 2.3.2

헤모글로빈의 결합 자리 하나는 비어 있거나(에너지 0) 산소 분자 하나에 결합(에너지 \(-\epsilon\))합니다. 결합 확률을 구하세요.

풀이. \(\mathcal Z = 1 + e^{(\epsilon + \mu)/kT}\). 결합 확률 \(\frac{e^{(\epsilon + \mu)/kT}}{1 + e^{(\epsilon + \mu)/kT}} = \frac1{e^{-(\epsilon + \mu)/kT} + 1}\). 폐(산소 농도 높음, \(\mu\) 큼)에서 거의 1, 조직(낮음)에서 줄어 산소를 내놓습니다. 실제 헤모글로빈은 결합 자리 넷이 서로 영향을 주어 이 곡선보다 가파릅니다.

요약
  1. 깁스 인자 \(e^{-(E - \mu N)/kT}\), 대분배함수 \(\mathcal Z\).
  2. \(\bar N = kT\,\partial_\mu\ln\mathcal Z\).
  3. 입자는 \(\mu\)가 낮은 쪽으로. 이상기체 \(\mu = -kT\ln(n_Q/n)\).

2.3.3연습문제

기본

  1. 예제 2.3.2에서 \(\mu = -\epsilon\)이면 결합 확률은?
    답

    \(1/(e^0 + 1) = 1/2\).

발전

  1. 중력장 속 이상기체에서 \(\mu_{\text{전체}} = -kT\ln(n_Q/n(z)) + mgz\)가 높이와 무관해야 함으로 기압 공식을 유도하세요.
    답

    \(kT\ln n(z) + mgz = \)상수이므로 \(n(z) = n(0)e^{-mgz/kT}\).

2.3.2

예제표면 흡착의 Langmuir 등온선

대정준 앙상블 · 화학 퍼텐셜 · 문제 해결 전략

다루는 성취기준 [물리13-02-03]

출발점

입자 수가 바뀌는 계는 대정준 앙상블로 다룹니다. 표면의 흡착 자리 하나가 비었거나(에너지 0) 분자 하나를 붙잡은(에너지 \(-\varepsilon\)) 두 상태라면 \(\mathcal Z = 1 + e^{(\varepsilon + \mu)/kT}\)이고, 채워질 확률은 \(\theta = \frac1{e^{-(\varepsilon + \mu)/kT} + 1}\)입니다.

문제 해결 전략 · 대정준 분배함수
  1. 자리 하나의 가능한 상태와 \(E\), \(N\)을 쓴다.
  2. \(\mathcal Z = \sum e^{-(E - \mu N)/kT}\).
  3. 점유 확률을 구한다.
  4. 기체의 \(\mu = kT\ln(P/P_0)\)를 넣어 압력 의존으로 바꾼다.

이상기체의 화학 퍼텐셜 \(\mu = kT\ln(P/P_0)\)를 넣어 흡착 비율 \(\theta(P)\)를 쓰고, 절반이 덮이는 압력 \(P_{1/2}\)을 구하여라.

풀이

  1. \(e^{\mu/kT} = P/P_0\).
    이상기체.
  2. \(\theta = \frac{(P/P_0)e^{\varepsilon/kT}}{1 + (P/P_0)e^{\varepsilon/kT}} = \frac P{P + P_{1/2}}\).
    Langmuir 등온선.
  3. \(P_{1/2} = P_0e^{-\varepsilon/kT}\).
    결합이 셀수록 낮은 압력에서 덮인다.
  4. 낮은 압력 \(\theta \approx P/P_{1/2}\)(비례), 높은 압력 \(\theta \to 1\)(포화).
    두 극한.

의미

혈액 속 헤모글로빈이 산소를 붙잡는 비율, 촉매 표면의 반응물 덮임, 가스 센서가 모두 이 모양을 따릅니다(실제 헤모글로빈은 협동 효과로 더 가파름).

검산

\(P = P_{1/2}\)이면 \(\theta = 1/2\). 정의와 맞습니다.
