2.1.1기본 가설

에너지 \(U\), 부피 \(V\), 입자 수 \(N\)이 고정된 고립계에서, 평형 상태는 접근할 수 있는 모든 미시 상태가 같은 확률로 나타나는 상태라고 가정합니다. 이런 계들의 모임을 미시정준 앙상블이라 합니다. 이 가설에서

정의 2.1.1 \[S = k\ln\Omega(U, V, N), \qquad \frac1T = \left(\frac{\partial S}{\partial U}\right)_{V,N}, \quad \frac PT = \left(\frac{\partial S}{\partial V}\right)_{U,N}, \quad -\frac\mu T = \left(\frac{\partial S}{\partial N}\right)_{U,V}.\]

두 계가 에너지, 부피, 입자를 주고받으면 전체 엔트로피가 최대인 곳에서 평형이 되고, 그 조건이 각각 \(T\), \(P\), \(\mu\)가 같다는 것입니다. 열역학의 모든 식이 \(\Omega\) 하나에서 나옵니다.

2.1.2이상기체의 다중도

단원자 분자 하나의 상태는 위치와 운동량의 6차원 위상 공간의 점입니다. 양자역학에 따라 위상 공간 부피 \(h^3\)마다 상태 하나로 셉니다. \(N\)개 분자의 에너지가 \(U\)이면 운동량은 \(3N\)차원 구 \(\sum p_i^2 = 2mU\) 위에 있으므로

\[\Omega \approx \frac1{N!}\frac{V^N}{h^{3N}}\cdot\frac{\pi^{3N/2}}{(3N/2)!}(2mU)^{3N/2}.\]

\(N!\)은 같은 입자들의 자리를 바꾼 상태를 하나로 세기 위한 것입니다(깁스). 로그를 취하고 스털링 근사를 쓰면 \(S = Nk\left[\ln\left(\frac VN\left(\frac{4\pi mU}{3Nh^2}\right)^{3/2}\right) + \frac52\right]\)(사쿠르-테트로드 식, 3.1절)입니다. 여기서 \(1/T = \partial S/\partial U = \frac32Nk/U\), \(P/T = Nk/V\)로 \(U = \frac32NkT\)와 \(PV = NkT\)가 나옵니다.

예제 2.1.2

이상기체의 부피를 등온으로 두 배로 할 때 엔트로피 변화를 다중도로 구하세요.

풀이. \(U\)가 그대로이고 \(\Omega \propto V^N\)이므로 \(\Delta S = k\ln2^N = Nk\ln2\). 물리11 3.4절의 자유 팽창 결과와 같습니다.

요약
  1. 고립계: 같은 에너지의 미시 상태는 같은 확률.
  2. \(S = k\ln\Omega\), \(1/T\), \(P/T\), \(-\mu/T\)는 \(S\)의 편미분.
  3. 이상기체: 위상 공간 \(h^3\)마다 한 상태, \(N!\)로 나눔.

2.1.3연습문제

기본

  1. \(N!\)로 나누지 않으면 같은 기체 두 칸 사이 칸막이를 치울 때 엔트로피가 늘어나 버림을 보이세요(깁스 역설).
    답

    \(\Omega \propto V^N\)만 쓰면 \(S\)에 \(Nk\ln V\)가 있어 \(2N\), \(2V\)로 합칠 때 \(2Nk\ln2\)가 늘어납니다. \(N!\)로 나누면 \(V/N\)의 꼴이 되어 변화가 0입니다.

2.1.2

예제상자성체 스핀의 다중도로 온도 구하기

미시정준 앙상블 · 1/T = ∂S/∂U · 음의 온도 · 문제 해결 전략

다루는 성취기준 [물리13-02-01]

출발점

미시정준 앙상블에서 온도는 \(\frac1T = \frac{\partial S}{\partial U}\)로 정의합니다. 자기장 속 스핀 \(N\)개 중 \(N_\uparrow\)개가 장 방향이면 \(\Omega = \binom{N}{N_\uparrow}\), 에너지 \(U = -\mu B(2N_\uparrow - N)\)입니다.

문제 해결 전략 · 미시정준 온도
  1. \(S = k\ln\Omega\)를 Stirling으로 쓴다.
  2. \(U\)를 \(N_\uparrow\)로 쓰고 \(\partial S/\partial U\)를 구한다.
  3. \(T\)를 \(N_\uparrow/N\)의 함수로 정리한다.
  4. \(N_\uparrow < N/2\)에서 부호를 해석한다.

스핀 1/2 \(N\)개(모멘트 \(\mu\), 장 \(B\))에서 온도와 \(N_\uparrow/N\)의 관계를 구하여라. 장 방향 스핀 비율이 75%이면 \(kT\)는 \(\mu B\)의 몇 배인가?

풀이

  1. \(S/k = N\ln N - N_\uparrow\ln N_\uparrow - N_\downarrow\ln N_\downarrow\), \(dU = -2\mu B\,dN_\uparrow\).
    Stirling.
  2. \(\frac1T = \frac{\partial S}{\partial N_\uparrow}\frac{dN_\uparrow}{dU} = \frac{k}{2\mu B}\ln\frac{N_\uparrow}{N_\downarrow}\).
    연쇄 법칙.
  3. \(\frac{N_\uparrow}{N_\downarrow} = e^{2\mu B/kT}\), 정준 앙상블의 Boltzmann 결과와 같다.
    두 앙상블 일치.
  4. 75%: \(\ln3 = 2\mu B/kT\), \(kT = 2\mu B/\ln3 = 1.82\mu B\).
    값.

의미

\(N_\uparrow < N_\downarrow\)(에너지가 높은 쪽이 더 많음)이면 \(T < 0\)이 됩니다. 에너지에 위 한계가 있는 계에서만 가능한 상태로, 레이저의 밀도 반전과 같은 상황입니다. 음의 온도는 무한대보다 "뜨거운" 상태입니다.

검산

\(N_\uparrow = N/2\)이면 \(\ln1 = 0\), \(T = \infty\). 스핀이 무작위로 반반인 것은 온도가 무한히 높을 때입니다.
