3.1.1입자 하나의 분배함수

한 변 \(L\)인 상자 속 입자의 준위는 \(E = \frac{h^2}{8mL^2}(n_x^2 + n_y^2 + n_z^2)\)입니다. 상온에서 준위 간격은 \(kT\)보다 매우 작아 합을 적분으로 바꿀 수 있고, 세 방향이 독립이라

결과 3.1.1 \[Z_1 = \frac V{v_Q}Z_{\text{내부}}, \qquad v_Q = \left(\frac{h^2}{2\pi mkT}\right)^{3/2} = \frac1{n_Q}.\]

\(v_Q\)(양자 부피)는 열적 드브로이 파장의 세제곱 정도입니다. 분배함수는 "입자가 갈 수 있는 부피를 양자 부피로 잰 수", 곧 사실상 입자가 쓸 수 있는 상태 수입니다. 상온 헬륨은 \(v_Q \approx 1.3\times10^{-31}\ \text{m}^3\)으로, 분자당 부피(약 \(4\times10^{-26}\ \text{m}^3\))보다 훨씬 작습니다.

3.1.2열역학 양

\(Z = Z_1^N/N!\), \(F = -kT\ln Z \approx -NkT\left[\ln\frac{V}{Nv_Q} + 1\right]\)(단원자, \(Z_{\text{내부}} = 1\)).

  • \(P = -\partial F/\partial V = NkT/V\): 상태방정식.
  • \(U = -\partial_\beta\ln Z = \frac32NkT\): 등분배.
  • \(\mu = \partial F/\partial N = -kT\ln\frac{V}{Nv_Q}\).
결과 3.1.2 (사쿠르-테트로드) \[S = Nk\left[\ln\left(\frac{V}{Nv_Q}\right) + \frac52\right].\]

엔트로피의 절댓값이 \(h\)를 포함해 정해집니다. 고전역학만으로는 상수를 정할 수 없었는데, 1912년 사쿠르와 테트로드가 이 식을 측정과 비교해 플랑크 상수를 확인하는 데 썼습니다.

예제 3.1.1

298 K, 1기압 아르곤(\(m = 40\) u)의 몰 엔트로피를 계산하세요.

풀이. \(v_Q = \left(\frac{h^2}{2\pi mkT}\right)^{3/2}\): \(2\pi mkT = 2\pi(6.64\times10^{-26})(4.11\times10^{-21}) = 1.716\times10^{-45}\), \(h^2/(\ldots) = 2.559\times10^{-22}\), \(v_Q \approx 4.09\times10^{-33}\ \text{m}^3\). 분자당 부피 \(kT/P = 4.06\times10^{-26}\ \text{m}^3\). \(\ln(4.06\times10^{-26}/4.09\times10^{-33}) = \ln(9.93\times10^6) \approx 16.11\). \(S = R(16.11 + 2.5) \approx 154.7\) J/(mol·K). 열량 측정으로 구한 값(약 154.8)과 매우 잘 맞습니다(확인 필요).

요약
  1. \(Z_1 = V/v_Q\), \(v_Q = (h^2/2\pi mkT)^{3/2}\).
  2. \(Z = Z_1^N/N!\)에서 \(PV = NkT\), \(U = \frac32NkT\), \(\mu = -kT\ln(V/Nv_Q)\).
  3. 사쿠르-테트로드 \(S = Nk[\ln(V/Nv_Q) + \frac52]\), 측정과 일치.

3.1.3연습문제

기본

  1. 헬륨(4 u)과 아르곤(40 u)의 같은 온도·압력 몰 엔트로피 차이는?
    답

    \(v_Q \propto m^{-3/2}\)이므로 \(\Delta S = R\cdot\frac32\ln10 \approx 28.7\) J/(mol·K). 무거운 아르곤이 큽니다(운동량 공간이 넓음).

3.1.2

예제실온 헬륨 기체의 엔트로피

Sackur-Tetrode 식 · 양자 부피 · 문제 해결 전략

다루는 성취기준 [물리13-03-01]

출발점

단원자 이상기체의 엔트로피는 \(S = Nk\left[\ln\left(\frac V{Nv_Q}\right) + \frac52\right]\), \(v_Q = \left(\frac{h^2}{2\pi mkT}\right)^{3/2}\)입니다. 분자 하나가 차지하는 부피와 양자 부피의 비가 로그 안에 들어갑니다.

문제 해결 전략 · Sackur-Tetrode 계산
  1. \(V/N = kT/P\)를 구한다.
  2. 양자 부피 \(v_Q\)(또는 열 de Broglie 파장의 세제곱)를 구한다.
  3. \(S/Nk = \ln(V/Nv_Q) + 5/2\).
  4. 표의 측정 엔트로피와 비교한다.

300 K, 1 atm 헬륨(\(m = 6.64\times10^{-27}\) kg)의 몰 엔트로피를 구하여라.

풀이

  1. \(V/N = kT/P = 4.09\times10^{-26}\) m³.
    분자당 부피.
  2. \(\lambda_{th} = h/\sqrt{2\pi mkT} = \frac{6.63\times10^{-34}}{\sqrt{2\pi\times6.64\times10^{-27}\times4.14\times10^{-21}}} = 5.04\times10^{-11}\) m, \(v_Q = 1.28\times10^{-31}\) m³.
    열 파장 0.05 nm.
  3. \(\ln(4.09\times10^{-26}/1.28\times10^{-31}) = \ln(3.2\times10^5) = 12.67\).
    로그.
  4. \(S = R(12.67 + 2.5) = 8.314\times15.17 = 126\) J/(mol·K).
    측정값 126.2와 일치.

의미

고전 이상기체의 엔트로피에 Planck 상수 \(h\)가 들어갑니다. 상태를 세려면 위상 공간을 \(h^3\) 크기 칸으로 나눠야 하기 때문입니다. 이 식이 측정값과 맞는다는 것이 양자역학의 초기 증거 가운데 하나였습니다.

검산

\(V/Nv_Q \gg 1\)(\(3\times10^5\))이라 고전 기체 조건을 만족합니다. 이 비가 1에 가까우면 양자 통계가 필요합니다(4.2절).
