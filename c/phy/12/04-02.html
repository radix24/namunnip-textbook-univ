4.2.1연속 상태로의 전이

나중 상태가 하나가 아니라 에너지 \(E_f\) 근처에 촘촘히 있는 연속 상태(빛을 내보내는 광자 상태, 이온화된 전자 등)라면, 4.1절의 1차 확률을 모든 나중 상태에 대해 더해야 합니다. 일정한 섭동(\(\omega = 0\)이라 \(\omega_0 = (E_f - E_i)/\hbar\))에서

\[P(t) = \int\frac{|V_{fi}|^2}{\hbar^2}\frac{\sin^2(\omega_0t/2)}{(\omega_0/2)^2}\,\rho(E_f)\,dE_f, \qquad dE_f = \hbar\,d\omega_0.\]

\(t\)가 크면 \(\frac{\sin^2(xt/2)}{(x/2)^2} \to 2\pi t\,\delta(x)\)이므로 적분이 \(E_f = E_i\) 근처만 골라냅니다.

정리 4.2.1 (페르미 황금률) \[\Gamma_{i\to f} = \frac{dP}{dt} = \frac{2\pi}\hbar|V_{fi}|^2\rho(E_f), \qquad E_f = E_i\ (\text{사인 섭동이면 } E_i \pm \hbar\omega).\]

확률이 \(t^2\)이 아니라 \(t\)에 비례해 자라므로, 단위 시간당 전이율이라는 개념이 의미를 갖습니다. 성립 조건: \(t\)가 \(\hbar/\)(나중 상태 띠의 폭)보다 길고, 처음 상태가 거의 비지 않을 만큼 짧아야 합니다. 지수 붕괴의 수명은 \(\tau = 1/\Gamma\)입니다.

4.2.2상태 밀도

부피 \(V\)인 상자 속 자유 입자의 상태는 \(\mathbf k\) 공간에서 \((2\pi)^3/V\)마다 하나입니다. 운동량 크기 \(p\)와 \(p + dp\) 사이의 상태 수를 에너지로 바꾸면

\[\rho(E) = \frac{V}{(2\pi\hbar)^3}4\pi p^2\frac{dp}{dE}\quad(\text{스핀 하나당}).\]

비상대론 입자면 \(\rho \propto \sqrt E\), 광자(\(E = pc\))면 \(\rho \propto E^2\). 나중 상태가 많을수록 전이가 빠릅니다. 베타 붕괴 전자의 에너지 분포 모양(페르미의 1934년 이론)이 이 상태 밀도에서 나왔습니다.

예제 4.2.2

어떤 들뜬 상태의 전이율이 \(\Gamma = 6\times10^8\ \text{s}^{-1}\)입니다. 수명과 에너지 폭(\(\Gamma\hbar\))은?

풀이. \(\tau = 1.7\) ns. 폭 \(\hbar\Gamma = 6.58\times10^{-16}\ \text{eV·s}\times6\times10^8 \approx 4\times10^{-7}\) eV. 수소 2p 상태가 대략 이 정도이며, 스펙트럼선의 자연 폭을 정합니다(에너지-시간 불확정성, 물리8 3.2절).

요약
  1. 연속 상태로의 전이 확률은 \(t\)에 비례: 전이율이 정의된다.
  2. \(\Gamma = \frac{2\pi}\hbar|V_{fi}|^2\rho(E_f)\), 수명 \(1/\Gamma\), 선폭 \(\hbar\Gamma\).
  3. 상태 밀도: 자유 입자 \(\propto\sqrt E\), 광자 \(\propto E^2\).

4.2.3연습문제

기본

  1. 나중 상태 밀도가 두 배가 되면 수명은?
    답

    전이율이 두 배이므로 수명은 절반.

  2. \(\lim_{t\to\infty}\frac{\sin^2(xt/2)}{(x/2)^2} = 2\pi t\,\delta(x)\)에서 계수 \(2\pi t\)를 확인하세요(\(\int\frac{\sin^2u}{u^2}du = \pi\)).
    답

    \(u = xt/2\)로 바꾸면 \(\int\frac{\sin^2(xt/2)}{(x/2)^2}dx = \int\frac{\sin^2u}{u^2}\cdot t^2\cdot\frac2t\,du = 2\pi t\).
