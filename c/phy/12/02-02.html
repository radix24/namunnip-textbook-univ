2.2.1좋은 상태

\(E^0\)에 상태 \(|a\rangle\), \(|b\rangle\) 두 개가 겹쳐 있으면 그 어떤 조합도 \(H^0\)의 고유상태라, 섭동이 켜졌을 때 어느 조합으로 이어지는지 미리 알 수 없습니다. 2차 공식의 분모가 0이 되는 것이 그 신호입니다. 섭동이 켜진 뒤 연속적으로 이어지는 특별한 조합을 "좋은 상태"라 합니다.

정리 2.2.1

축퇴 부분 공간에서 \(W_{ij} = \langle i|\hat H'|j\rangle\)을 대각화하면, 고윳값이 1차 에너지 보정 \(E^{(1)}_\pm\)이고 고유벡터가 좋은 상태입니다.

\[E^{(1)}_\pm = \frac12\left[W_{aa} + W_{bb} \pm \sqrt{(W_{aa} - W_{bb})^2 + 4|W_{ab}|^2}\right].\]

요령: \(H^0\)와 \(H'\) 모두와 교환하는 에르미트 연산자 \(A\)를 찾으면, \(A\)의 고유상태(고유값이 서로 다른)가 좋은 상태입니다. 그러면 \(W\)가 처음부터 대각이 되어 비축퇴 공식을 그대로 쓸 수 있습니다.

2.2.2예: 수소의 1차 슈타르크 효과

수소 \(n = 2\) 준위에는 \(|200\rangle, |210\rangle, |211\rangle, |21{-1}\rangle\) 네 상태가 겹쳐 있습니다. \(z\) 방향 전기장 \(E\)의 섭동은 \(\hat H' = eEz\)입니다.

  • \(\hat L_z\)가 \(H'\)와 교환하므로 \(m\)이 다른 상태끼리는 섞이지 않는다.
  • 패리티: \(z\)는 홀함수라 같은 \(l\)끼리의 대각 요소는 0.
  • 남는 것은 \(W_{200,210} = \langle200|eEz|210\rangle = -3eEa_0\).

2×2 블록의 고윳값은 \(\pm3eEa_0\), 좋은 상태는 \(\frac1{\sqrt2}(|200\rangle \pm |210\rangle)\)입니다. \(m = \pm1\) 상태는 1차에서 이동하지 않습니다. 에너지 이동이 전기장에 비례하는 것(선형 슈타르크 효과)은 수소처럼 서로 다른 \(l\)이 겹쳐 있는 경우의 특징이고, 다른 원자는 2차(전기장 제곱)부터 이동합니다.

예제 2.2.2

\(10^6\) V/m 전기장에서 수소 \(n = 2\) 준위의 최대 갈라짐은?

풀이. \(\pm3eEa_0\), 폭 \(6eEa_0 = 6\times10^6\times0.529\times10^{-10}\) eV \(\approx 3.2\times10^{-4}\) eV. \(H_\alpha\)선(1.89 eV) 에너지의 \(10^{-4}\) 정도로, 분광기로 관측할 수 있습니다.

요약
  1. 축퇴 부분 공간의 \(W\)를 대각화: 고윳값 = 1차 보정, 고유벡터 = 좋은 상태.
  2. \(H^0\), \(H'\)와 교환하는 연산자로 좋은 상태를 미리 고른다.
  3. 수소 \(n = 2\) 슈타르크: \(\pm3eEa_0\), 전기장에 비례.

2.2.3연습문제

기본

  1. \(W = \begin{pmatrix}0 & \delta\\ \delta & 0\end{pmatrix}\)이면 1차 보정과 좋은 상태는?
    답

    \(\pm\delta\), \(\frac1{\sqrt2}(|a\rangle \pm |b\rangle)\).

발전

  1. 한 변 \(L\)인 2차원 무한 우물에서 첫 들뜬 준위(\((1,2)\), \((2,1)\))에 섭동 \(H' = V_0\) (\(0 < x, y < L/2\))이 있을 때 갈라짐을 구하세요.
    답

    대각 요소 \(V_0/4\). 비대각 \(W_{ab} = V_0\left(\frac2L\int_0^{L/2}\sin\frac{\pi x}L\sin\frac{2\pi x}Ldx\right)^2 = V_0\left(\frac{4}{3\pi}\right)^2\). \(E^{(1)} = V_0\left(\frac14 \pm \frac{16}{9\pi^2}\right)\).

2.2.2

예제수소 n = 2의 선형 Stark 효과

축퇴 섭동 · 좋은 상태 · 문제 해결 전략

다루는 성취기준 [물리12-02-02]

출발점

축퇴된 준위에 섭동이 걸리면 축퇴된 상태들 사이의 섭동 행렬을 대각화해야 합니다. 그 고유값이 1차 에너지 이동이고, 고유벡터가 "좋은" 상태입니다.

문제 해결 전략 · 축퇴 섭동
  1. 축퇴된 상태들을 고른다.
  2. 섭동 행렬 원소 \(W_{ij} = \langle i|H'|j\rangle\)를 대칭으로 0인 것부터 걸러 구한다.
  3. 행렬을 대각화한다.
  4. 고유값으로 준위 갈라짐을 그린다.

수소 \(n = 2\)(2s, 2p\(_0\), 2p\(_{\pm1}\))에 전기장 \(E\hat{\mathbf z}\)가 걸렸다(\(H' = eEz\)). \(\langle2s|z|2p_0\rangle = -3a_0\)일 때 준위 갈라짐은?

풀이

  1. \(z\)는 홀함수라 같은 패리티끼리 0, \(m\)이 다르면 0. 남는 것은 \(\langle2s|z|2p_0\rangle\)뿐.
    선택 규칙.
  2. 2s, 2p\(_0\) 부분행렬: \(\begin{pmatrix}0 & -3eEa_0\\ -3eEa_0 & 0\end{pmatrix}\).
    2×2.
  3. 고유값 \(\pm3eEa_0\), 상태 \(\frac1{\sqrt2}(|2s\rangle \mp |2p_0\rangle)\).
    좋은 상태.
  4. 2p\(_{\pm1}\)은 이동 없음. 네 상태가 세 준위로.
    \(E = 10^7\) V/m이면 \(3ea_0E = 1.6\) meV.

의미

2s와 2p가 같은 에너지라(우연 축퇴) 전기장에 1차로 반응합니다. 좋은 상태는 전자 구름이 한쪽으로 치우친, 영구 쌍극자를 가진 상태입니다. 바닥 상태(1s)는 축퇴가 없어 1차 효과가 없습니다.

검산

\(3\times(1.6\times10^{-19})\times(5.29\times10^{-11})\times10^7 = 2.5\times10^{-22}\) J = 1.6 meV. 맞습니다.
