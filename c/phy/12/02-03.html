2.3.1미세 구조

보어 준위 \(E_n = -13.6\ \text{eV}/n^2\)에 크기 \(\alpha^2E_n\)(약 \(10^{-4}\)배) 정도의 보정이 둘 있습니다.

  • 상대론 보정: 운동 에너지 \(\sqrt{p^2c^2 + m^2c^4} - mc^2 \approx \frac{p^2}{2m} - \frac{p^4}{8m^3c^2}\)의 둘째 항.
  • 스핀-궤도 결합: 전자의 정지 좌표계에서 핵이 돌며 만드는 자기장이 전자의 스핀 자기 모멘트와 상호작용한다. \(H'_{so} \propto \frac1{r^3}\mathbf S\cdot\mathbf L\).

스핀-궤도 항 때문에 \(L_z\), \(S_z\)는 따로 보존되지 않고 \(\mathbf J = \mathbf L + \mathbf S\)가 보존됩니다. 좋은 상태는 \(|n\,l\,j\,m_j\rangle\)입니다. 두 보정을 합하면

결과 2.3.1 (미세 구조) \[E_{nj} = -\frac{13.6\ \text{eV}}{n^2}\left[1 + \frac{\alpha^2}{n^2}\left(\frac{n}{j + \frac12} - \frac34\right)\right], \qquad \alpha \approx \frac1{137}.\]

\(l\)에 무관하고 \(j\)에만 의존합니다. \(n = 2\)에서 \(2S_{1/2}\)와 \(2P_{1/2}\)는 같고 \(2P_{3/2}\)는 약 \(4.5\times10^{-5}\) eV 위입니다. 디랙 방정식도 같은 결과를 줍니다. 실제로는 \(2S_{1/2}\)가 \(2P_{1/2}\)보다 약 \(4.4\times10^{-6}\) eV 높은데(램 이동, 1947), 이는 양자전기역학의 진공 요동 효과입니다.

2.3.2제이만 효과

바깥 자기장 \(\mathbf B\)의 섭동은 \(\hat H'_Z = \frac{e}{2m}(\mathbf L + 2\mathbf S)\cdot\mathbf B\)입니다(스핀의 \(g \approx 2\)).

  • 약한 장(제이만 이동 ≪ 미세 구조): \(j\)가 좋은 양자수. \(E^{(1)}_Z = \mu_Bg_Jm_jB\), 란데 인자 \(g_J = 1 + \frac{j(j+1) - l(l+1) + \frac34}{2j(j+1)}\).
  • 강한 장(제이만 ≫ 미세 구조, 파셴-바크): \(m_l\), \(m_s\)가 좋은 양자수. \(E^{(1)}_Z = \mu_B(m_l + 2m_s)B\).

\(\mu_B = e\hbar/2m = 5.788\times10^{-5}\) eV/T입니다. 1 T에서 이동은 \(10^{-4}\) eV 정도로 미세 구조와 같은 자리여서, 수소에서 두 극한 사이의 영역도 실험에서 중요합니다.

예제 2.3.1

수소 바닥 상태(\(1S_{1/2}\))는 약한 장에서 어떻게 갈라지나요?

풀이. \(l = 0\), \(j = \frac12\): \(g_J = 1 + \frac{\frac34 - 0 + \frac34}{2\cdot\frac34} = 2\). \(m_j = \pm\frac12\)이므로 \(\pm\mu_BB\), 간격 \(2\mu_BB\). 1 T에서 약 \(1.16\times10^{-4}\) eV. 순수한 스핀 자기 모멘트만 있는 경우입니다.

요약
  1. 미세 구조 = 상대론 보정 + 스핀-궤도. 크기 \(\alpha^2E_n\).
  2. \(E_{nj}\)는 \(j\)에만 의존. 램 이동은 QED 효과.
  3. 제이만: 약한 장 \(\mu_Bg_Jm_jB\), 강한 장 \(\mu_B(m_l + 2m_s)B\).

2.3.3연습문제

기본

  1. \(2P_{3/2}\)와 \(2P_{1/2}\)의 \(g_J\)는?
    답

    \(2P_{3/2}\): \(1 + \frac{\frac{15}4 - 2 + \frac34}{2\cdot\frac{15}4} = \frac43\). \(2P_{1/2}\): \(1 + \frac{\frac34 - 2 + \frac34}{2\cdot\frac34} = \frac23\).

  2. 결과 2.3.1로 \(2P_{3/2}\)와 \(2P_{1/2}\)의 에너지 차를 계산하세요.
    답

    \(\frac{13.6}4\cdot\frac{\alpha^2}4\left(\frac2{1} - \frac2{2}\right) = 3.4\times\frac{5.33\times10^{-5}}4 \approx 4.5\times10^{-5}\) eV. 진동수 약 10.9 GHz.

2.3.2

예제약한 자기장의 Zeeman 갈라짐

Landé g 인자 · 준위 갈라짐 · 문제 해결 전략

다루는 성취기준 [물리12-02-03]

출발점

약한 자기장에서 준위 \(|j\,m_j\rangle\)는 \(\Delta E = g_J\mu_BBm_j\)만큼 이동합니다. Landé 인자 \(g_J = 1 + \frac{j(j+1) + s(s+1) - \ell(\ell+1)}{2j(j+1)}\)는 궤도와 스핀이 자기 모멘트에 기여하는 비율을 담습니다.

문제 해결 전략 · Zeeman 갈라짐 계산
  1. 준위의 \(\ell\), \(s\), \(j\)를 정한다.
  2. \(g_J\)를 계산한다.
  3. \(m_j = -j, \dots, j\)마다 이동을 구한다.
  4. 전이 선이 몇 개로 갈라지는지 본다.

수소 \(2p_{3/2}\)와 \(2p_{1/2}\), \(1s_{1/2}\)의 \(g_J\)를 구하고, 1 T에서 \(2p_{1/2}\) 준위의 갈라짐 폭을 구하여라. (\(\mu_B = 5.79\times10^{-5}\) eV/T)

풀이

  1. \(2p_{3/2}\): \(g = 1 + \frac{15/4 + 3/4 - 2}{2\cdot15/4} = 4/3\).
    \(\ell = 1\), \(j = 3/2\).
  2. \(2p_{1/2}\): \(g = 1 + \frac{3/4 + 3/4 - 2}{3/2} = 2/3\). \(1s_{1/2}\): \(g = 2\).
    \(\ell = 0\)이면 스핀만.
  3. \(2p_{1/2}\): \(m_j = \pm\frac12\), 간격 \(g\mu_BB = \frac23\times5.79\times10^{-5} = 3.9\times10^{-5}\) eV.
    두 준위.
  4. Lyman α(\(2p_{1/2} \to 1s\))는 \(g\)가 달라 네 선으로 갈라진다(이상 Zeeman 효과).
    \(\Delta m_j = 0, \pm1\).

의미

스핀의 \(g\) 인자가 2(궤도는 1)라서 갈라짐이 단순한 세 줄(정상 Zeeman)이 아닌 복잡한 무늬가 됩니다. 별빛의 Zeeman 갈라짐으로 태양 흑점의 자기장(수천 가우스)을 잽니다.

검산

\(2p_{1/2}\) 갈라짐(39 μeV)은 미세 구조 간격(\(2p_{3/2} - 2p_{1/2}\) 약 45 μeV)과 비슷해, 1 T는 이미 "약한 장" 근사의 경계입니다(대략값).
