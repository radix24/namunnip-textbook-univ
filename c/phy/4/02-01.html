  • 구속 조건이 있는 계의 자유도와 일반화 좌표를 고른다.
  • 일반화 좌표로 라그랑지안을 쓰고 라그랑주 방정식으로 운동 방정식을 얻는다.
먼저 알아야 할 것
  • 해밀턴 원리 (1.3절), 극좌표 속도 (물리1 1.1절).

뉴턴 법칙으로 진자나 구슬 문제를 풀면 장력, 수직 항력처럼 값을 모르는 구속력이 방정식에 들어와 일이 많아집니다. 라그랑주 방법은 처음부터 구속을 만족하는 좌표(진자의 각도 하나처럼)만 골라 운동 에너지와 퍼텐셜 에너지를 쓰고, 정해진 공식에 넣어 운동 방정식을 얻습니다. 힘을 그리고 성분으로 나누는 과정이 미분 계산으로 바뀌어, 복잡한 계일수록 실수가 줄어듭니다.

2.1.1구속과 자유도

진자 추는 줄 길이 때문에 원 위에서만, 구슬은 철사 위에서만 움직입니다. 이런 조건을 구속이라 합니다. 좌표 사이의 관계식 \(f(\mathbf r_1, \dots, t) = 0\)으로 쓸 수 있는 구속(홀로노믹 구속)이 \(k\)개이면, \(N\)개 입자 계의 자유도는 \(3N - k\)이고, 그만큼의 독립 좌표 \(q_1, \dots, q_n\)(일반화 좌표)로 계의 배치를 나타낼 수 있습니다. 평면 진자는 각도 \(\phi\) 하나, 이중 진자는 두 각도면 됩니다.

2.1.2라그랑주 방정식

\(T\)와 \(U\)를 일반화 좌표와 그 시간 미분으로 쓰고 \(L = T - U\)로 두면, 구속력이 일을 하지 않는 한(이상적인 구속) 해밀턴 원리에서

정리 2.1.1 \[\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} = \frac{\partial L}{\partial q_i},\qquad i = 1, \dots, n.\]

구속력이 사라지는 까닭: 이상적인 구속력(수직 항력, 늘어나지 않는 줄의 장력)은 허용된 움직임에 늘 수직이라 일을 하지 않습니다. 에너지로 만든 \(L\)에는 일을 하지 않는 힘이 들어갈 자리가 없습니다. 구속력이 필요하면 2.4절의 라그랑주 승수 방법으로 따로 구합니다.

처음 보는 수학 · \(\partial L/\partial\dot q\) 계산 요령 \(L\) 안의 \(\dot q\)를 별개의 글자(예: \(w\))로 보고 \(w\)로 미분하며, 이때 \(q\)는 상수로 둡니다. 예를 들어 \(L = \frac12ml^2w^2 + mgl\cos\phi\)이면 \(\frac{\partial L}{\partial w} = ml^2w\), \(\frac{\partial L}{\partial\phi} = -mgl\sin\phi\)입니다. 그다음 \(\frac{d}{dt}\)를 할 때 비로소 \(w = \dot\phi\)가 시간에 따라 변한다는 것을 써서 \(ml^2\ddot\phi\)를 얻습니다.

\(p_i = \partial L/\partial\dot q_i\)를 일반화 운동량, \(F_i = \partial L/\partial q_i\)를 일반화 힘이라 하면 \(\dot p_i = F_i\)로 뉴턴 법칙과 같은 꼴입니다. 각도 좌표이면 \(p_i\)는 각운동량, \(F_i\)는 토크입니다.

  1. 일반화 좌표를 고른다.
  2. 각 입자의 직교 좌표를 일반화 좌표로 쓰고 미분해 \(T\)를 구한다.
  3. \(U\)를 쓴다. \(L = T - U\).
  4. 좌표마다 라그랑주 방정식을 쓴다.
예제 2.1.2

길이 \(l\)인 단진자의 운동 방정식을 라그랑주 방법으로 구하여라.

풀이. 일반화 좌표는 각도 \(\phi\) 하나입니다. 추의 위치 \((l\sin\phi, -l\cos\phi)\)를 미분하면 속력이 \(l\dot\phi\)이므로 \(T = \frac12ml^2\dot\phi^2\), \(U = -mgl\cos\phi\)입니다. \(L = \frac12ml^2\dot\phi^2 + mgl\cos\phi\)에서 \(\frac{\partial L}{\partial\dot\phi} = ml^2\dot\phi\), \(\frac{\partial L}{\partial\phi} = -mgl\sin\phi\). 라그랑주 방정식은 \(ml^2\ddot\phi = -mgl\sin\phi\), 곧 \(\ddot\phi = -(g/l)\sin\phi\)입니다. 줄의 장력은 한 번도 나오지 않았습니다. 왼쪽 \(ml^2\ddot\phi\)는 각운동량의 변화율, 오른쪽은 중력의 토크입니다.

예제 2.1.3

수직 원뿔 \(z = \rho\cot\alpha\)의 안쪽 면을 마찰 없이 움직이는 입자의 운동 방정식을 원통 좌표 \(\rho, \phi\)로 구하여라.

풀이. \(z = \rho\cot\alpha\)이므로 \(T = \frac12m(\dot\rho^2 + \rho^2\dot\phi^2 + \dot z^2) = \frac12m(\dot\rho^2\csc^2\alpha + \rho^2\dot\phi^2)\), \(U = mg\rho\cot\alpha\). \(\phi\) 방정식: \(\frac{d}{dt}(m\rho^2\dot\phi) = 0\)(각운동량 보존). \(\rho\) 방정식: \(m\csc^2\alpha\,\ddot\rho = m\rho\dot\phi^2 - mg\cot\alpha\). 수직 항력은 어디에도 나오지 않습니다.

2.1.3이중 진자

길이 \(l_1, l_2\), 질량 \(m_1, m_2\)인 이중 진자를 두 각 \(\phi_1, \phi_2\)로 나타내면

\[L = \frac12(m_1 + m_2)l_1^2\dot\phi_1^2 + \frac12m_2l_2^2\dot\phi_2^2 + m_2l_1l_2\dot\phi_1\dot\phi_2\cos(\phi_1 - \phi_2) + (m_1 + m_2)gl_1\cos\phi_1 + m_2gl_2\cos\phi_2.\]

라그랑주 방정식 둘은 서로 얽힌 비선형 방정식이고, 진폭이 크면 처음 조건의 아주 작은 차이가 시간이 지나며 크게 벌어지는 혼돈 운동을 합니다. 작은 진동에서는 4단원의 정규 모드가 됩니다. 아래 실습 카드에서 이중 진자를 돌려 볼 수 있습니다.

요약
  1. 자유도 = \(3N\) − 구속 수, 일반화 좌표 \(q_i\).
  2. \(\frac{d}{dt}\frac{\partial L}{\partial\dot q_i} = \frac{\partial L}{\partial q_i}\). 구속력이 나오지 않는다.

2.1.4연습문제

기본

  1. 길이 \(l\)인 진자의 매단 점이 수평으로 \(x_s(t)\)만큼 움직일 때 라그랑지안과 운동 방정식을 구하여라.
    답

    추 위치 \((x_s + l\sin\phi, -l\cos\phi)\). \(L = \frac12m(\dot x_s^2 + 2\dot x_sl\dot\phi\cos\phi + l^2\dot\phi^2) + mgl\cos\phi\). 운동 방정식 \(l\ddot\phi + \ddot x_s\cos\phi + g\sin\phi = 0\).

2.1.2

실습이중 진자와 혼돈

실습 · 라그랑주 방정식

다루는 성취기준 [물리4-02-01]

목표

2.1절에서 구한 이중 진자의 운동 방정식을 수치적으로 풀어, 처음 각이 아주 조금 다른 두 진자가 작은 진폭에서는 같이 움직이지만 큰 진폭에서는 곧 완전히 달라지는 것(혼돈)을 봅니다. 성취기준 [물리4-02-01].

준비

길이 1 m, 질량이 같은 이중 진자 두 개(파랑, 주황)를 함께 그립니다. 주황 진자는 위쪽 각에 아주 작은 값을 더했습니다. 아래 그래프는 두 진자 상태 차이의 로그입니다. 에너지가 잘 보존되는지로 수치 계산의 정확도를 확인합니다.

절차

  1. θ₁ = θ₂ = 20°에서 재생하고 두 진자가 계속 겹치는지 본다.
  2. θ₁ = 120°, θ₂ = 120°로 바꿔 다시 재생한다. 두 진자가 언제 갈라지는지 본다.
  3. 큰 각에서 처음 차이를 10⁻⁹로 줄여 갈라지는 시간이 얼마나 늦어지는지 본다.

기대 결과

  • 작은 각에서는 차이가 커지지 않고 두 진자가 겹쳐 움직인다(정규 모드의 중첩, 4단원).
  • 큰 각에서는 차이가 로그 그래프에서 거의 직선으로(지수적으로) 커져 수 초 ~ 수십 초 안에 완전히 다른 운동이 된다.
  • 처음 차이를 1000배 줄여도 갈라지는 시간은 조금만 늦어진다. 지수적 증가에서는 처음 정밀도를 높여도 예측 시간은 로그로만 는다.

분석

  1. 운동 방정식은 완전히 결정되어 있는데도 장기 예측이 불가능한 까닭을 말해 보세요.
  2. 날씨 예보가 며칠 넘으면 어려워지는 것과 이 결과를 이어 생각해 보세요.
