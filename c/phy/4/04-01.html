진동자 여러 개가 용수철로 이어지면 각자의 움직임이 서로를 흔들어 운동이 복잡해 보입니다. 그런데 모든 물체가 같은 진동수로, 정해진 모양을 유지하며 함께 흔들리는 특별한 운동(정규 모드)이 있습니다. 어떤 복잡한 운동도 이 정규 모드들을 더한 것입니다. 그래서 문제는 "어떤 모양이 가능하고 각각의 진동수는 얼마인가"를 찾는 고유값 문제가 됩니다.

4.1.1두 개의 연성 진동자

질량 \(m\)인 두 물체를 벽–\(k\)–\(m\)–\(k'\)–\(m\)–\(k\)–벽 순서로 용수철로 이은 계를 생각합니다. 평형에서 잰 변위 \(x_1, x_2\)로

\[m\ddot x_1 = -kx_1 - k'(x_1 - x_2), \qquad m\ddot x_2 = -kx_2 - k'(x_2 - x_1).\]

행렬로 \(\mathsf M\ddot{\mathbf x} = -\mathsf K\mathbf x\), \(\mathsf M = m\mathsf I\), \(\mathsf K = \begin{pmatrix}k + k' & -k'\\ -k' & k + k'\end{pmatrix}\)입니다.

처음 보는 수학 · 행렬은 연립식을 줄여 쓴 것 행렬에 세로 벡터를 곱하면 "\(i\)번째 가로줄과 벡터의 내적이 \(i\)번째 성분"입니다. \(\mathsf K\mathbf x\)의 첫 성분은 \((k + k')x_1 - k'x_2\)이므로, \(\mathsf M\ddot{\mathbf x} = -\mathsf K\mathbf x\)는 위의 두 운동 방정식을 표 하나로 적은 것뿐입니다.

4.1.2정규 모드

모든 물체가 같은 진동수로 함께 진동하는 해 \(\mathbf x = \text{Re}[\mathbf ae^{i\omega t}]\)를 찾으면

\[(\mathsf K - \omega^2\mathsf M)\mathbf a = 0, \qquad \det(\mathsf K - \omega^2\mathsf M) = 0.\]

\(\mathbf a = 0\)이 아닌 해가 있으려면 행렬 \(\mathsf K - \omega^2\mathsf M\)이 역행렬을 가지면 안 되므로 행렬식이 0이어야 합니다. 위 계에서는 \((k + k' - m\omega^2)^2 - k'^2 = 0\), 곧 \(k + k' - m\omega^2 = \pm k'\)이므로

  • 모드 1: \(\omega_1 = \sqrt{k/m}\), \(\mathbf a \propto (1, 1)\). 두 물체가 같이 움직여 가운데 용수철이 늘지 않는다.
  • 모드 2: \(\omega_2 = \sqrt{(k + 2k')/m}\), \(\mathbf a \propto (1, -1)\). 서로 반대로 움직인다.

두 모드의 진동수가 다른 까닭: 모드 1에서는 가운데 용수철 \(k'\)이 늘지도 줄지도 않아 없는 것과 같으므로 각 물체는 \(k\) 하나만 느낍니다. 모드 2에서는 가운데 용수철 양 끝이 반대로 움직여 두 배로 늘어나므로, 물체마다 \(k + 2k'\)의 되돌리는 힘을 느껴 더 빨리 진동합니다.

처음 보는 수학 · 행렬식이 0이어야 하는 까닭 \((\mathsf K - \omega^2\mathsf M)\mathbf a = 0\)을 풀어 쓰면 연립일차방정식 \((k + k' - m\omega^2)a_1 - k'a_2 = 0\), \(-k'a_1 + (k + k' - m\omega^2)a_2 = 0\)입니다. 첫 식에서 \(a_2\)를 구해 둘째 식에 넣으면 \([(k + k' - m\omega^2)^2 - k'^2]a_1 = 0\)이 됩니다. 두 물체가 모두 멈춘 답(\(a_1 = a_2 = 0\))이 아니려면 대괄호가 0이어야 하고, 이것이 \(2\times2\) 행렬식(\(ad - bc\))이 0이라는 조건입니다. 이렇게 얻은 \(\omega^2\)을 고유값, 그때의 \(\mathbf a\)(모드의 모양)를 고유벡터라 부릅니다.

\(n\)개 진동자 계에는 \(n\)개의 정규 모드가 있습니다. \(\mathsf K\)와 \(\mathsf M\)이 대칭 행렬이라 \(\omega^2\)은 실수이고, 모드 벡터들은 서로 직교합니다(\(\mathsf M\)을 가중치로). 정규 좌표 \(\xi_1 = x_1 + x_2\), \(\xi_2 = x_1 - x_2\)로 바꾸면 방정식이 서로 독립인 단순 조화 진동자 둘로 갈라집니다.

예제 4.1.1

이산화탄소 분자 O=C=O를 직선 위의 세 질량(\(M_O\), \(M_C\), \(M_O\))과 두 용수철(\(k\))로 보면 세로 방향 정규 모드는?

풀이. 고유값 문제를 풀면 \(\omega = 0\)(분자 전체가 이동, 진동 아님), \(\omega = \sqrt{k/M_O}\)(대칭 신축: C는 정지, 두 O가 반대로), \(\omega = \sqrt{k(1/M_O + 2/M_C)}\)(비대칭 신축). 비대칭 신축은 쌍극자가 변해 적외선을 흡수하며, 이것이 이산화탄소가 온실 기체인 까닭 가운데 하나입니다(굽힘 모드도 기여).

요약
  1. \(\mathsf M\ddot{\mathbf x} = -\mathsf K\mathbf x\), \(\det(\mathsf K - \omega^2\mathsf M) = 0\).
  2. 정규 모드: 모두 같은 진동수로 진동하는 모양. \(n\)자유도에 \(n\)개.

4.1.3연습문제

기본

  1. 길이 \(l\)인 같은 단진자 둘을 약한 용수철 \(k'\)으로 이으면 두 정규 모드의 각진동수는?
    답

    \(\omega_1 = \sqrt{g/l}\)(같은 방향), \(\omega_2 = \sqrt{g/l + 2k'/m}\)(반대 방향).

4.1.2

예제세 질량 사슬의 정규 모드

고유값 문제 · 대칭 · 문제 해결 전략

다루는 성취기준 [물리4-04-01]

출발점

\(n\)개 진동자는 \(\det(\mathsf K - \omega^2\mathsf M) = 0\)에서 \(n\)개의 정규 진동수를 얻습니다. 계의 대칭을 이용하면 고유벡터 모양을 미리 짐작할 수 있습니다.

문제 해결 전략 · 정규 모드 구하기
  1. 각 질량의 변위로 \(\mathsf M\)과 \(\mathsf K\)를 쓴다.
  2. \(\det(\mathsf K - \omega^2\mathsf M) = 0\)을 푼다.
  3. 각 \(\omega^2\)의 고유벡터를 구한다.
  4. 대칭(좌우 대칭 모드, 반대칭 모드)으로 점검한다.

질량 \(m\) 세 개가 벽-\(k\)-\(m\)-\(k\)-\(m\)-\(k\)-\(m\)-\(k\)-벽으로 이어져 있다. 세 정규 진동수와 모양을 구하여라.

풀이

  1. \(\mathsf K/m = \frac km\begin{pmatrix}2 & -1 & 0\\ -1 & 2 & -1\\ 0 & -1 & 2\end{pmatrix}\). \(\lambda = \omega^2m/k\)로 쓰자.
    각 질량이 양옆 용수철 둘에 이어짐.
  2. \(\det = (2 - \lambda)[(2 - \lambda)^2 - 2] = 0\): \(\lambda = 2,\ 2 \pm\sqrt2\).
    첫 행으로 전개.
  3. \(\lambda = 2 - \sqrt2\): \((1, \sqrt2, 1)\) 모두 같은 방향. \(\lambda = 2\): \((1, 0, -1)\) 가운데 정지. \(\lambda = 2 + \sqrt2\): \((1, -\sqrt2, 1)\) 번갈아.
    좌우 대칭, 반대칭, 대칭.
  4. \(\omega = \sqrt{k/m}\times(0.765,\ 1.414,\ 1.848)\).
    제곱근.

의미

질량이 많아지면 정규 모드가 사인 모양 \(\sin(jn\pi/(N+1))\)으로 정렬되어 줄의 정상파가 됩니다. 결정 속 원자의 격자 진동(포논)이 이렇게 생깁니다.

검산

고유값 합 \((2 - \sqrt2) + 2 + (2 + \sqrt2) = 6\) = 대각합. 고유벡터끼리의 내적: \((1, \sqrt2, 1)\cdot(1, 0, -1) = 0\). 맞습니다.
