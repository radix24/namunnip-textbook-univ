먼저 알아야 할 것
  • 오일러-라그랑주 방정식 (1.1절), 퍼텐셜 에너지 (물리1 3.1절).

뉴턴 역학은 "지금의 힘이 다음 순간의 운동을 정한다"는 방식으로 운동을 봅니다. 해밀턴 원리는 전혀 다른 시각입니다. 출발점과 도착점, 출발 시각과 도착 시각을 정해 두고, 그 사이에 가능한 모든 경로 가운데 "작용"이라는 양을 정상값으로 만드는 경로가 실제 경로라고 말합니다. 놀랍게도 이 원리에서 뉴턴 법칙이 그대로 나옵니다. 이 절은 그것을 확인하고, 왜 이 방법이 더 쓸모 있는지 정리합니다.

1.3.1작용과 해밀턴 원리

보존력장 속의 입자에 대해 라그랑지안을

\[L(\mathbf r, \dot{\mathbf r}, t) = T - U = \frac12m\dot{\mathbf r}^2 - U(\mathbf r, t)\]

로 정의하고, 두 시각 사이의 작용을 \(S = \int_{t_1}^{t_2}L\,dt\)로 둡니다.

해밀턴 원리

입자가 시각 \(t_1\)의 위치에서 \(t_2\)의 위치로 가는 실제 경로는 작용 \(S\)를 정상값으로 만드는 경로다.

1.1절에서 \(x\)를 \(t\)로, \(y\)를 각 좌표 \(x_i\)로, \(f\)를 \(L\)로 바꾸면 오일러-라그랑주 방정식은

\[\frac{\partial L}{\partial x_i} = \frac{d}{dt}\frac{\partial L}{\partial\dot x_i}.\]

\(T - U\)인 까닭을 직관적으로 보면, 실제 경로는 운동 에너지와 퍼텐셜 에너지 사이에서 "균형"을 잡습니다. 공을 위로 던지면, 너무 빨리 올라가면 \(T\)가 커지고, 오래 아래에 머물면 \(U\)가 작아 차이 \(T - U\)는 커집니다. 두 효과를 맞춘 경로가 포물선입니다. 다만 이것은 비유이고, 정확한 근거는 아래처럼 이 원리에서 뉴턴 법칙이 나온다는 사실입니다.

\(\frac{\partial L}{\partial x_i} = -\frac{\partial U}{\partial x_i} = F_i\), \(\frac{\partial L}{\partial\dot x_i} = m\dot x_i = p_i\)이므로 \(F_i = \dot p_i\), 곧 뉴턴 제2법칙입니다. 해밀턴 원리와 뉴턴 법칙은 (보존력에 대해) 같은 내용을 다르게 표현한 것입니다.

1.3.2무엇이 좋은가

  • 좌표에 무관: \(L\)은 에너지라는 스칼라로 만들어져, 어떤 좌표로 써도 같은 꼴의 방정식을 준다. 극좌표의 복잡한 가속도(물리1 1.1절)를 따로 구할 필요가 없다(2.1절).
  • 구속력이 필요 없다: 일반화 좌표를 잘 고르면 수직 항력, 장력 같은 구속력이 방정식에 나오지 않는다.
  • 대칭과 보존: \(L\)의 대칭에서 보존량이 바로 보인다(2.3절 뇌터 정리).
  • 넓은 쓰임: 전자기학, 상대론, 양자역학(경로 적분), 장의 이론이 모두 작용 원리로 쓰인다.
예제 1.3.1

1차원 조화 진동자의 라그랑지안에서 운동 방정식을 구하여라.

풀이. \(L = \frac12m\dot x^2 - \frac12kx^2\). \(\frac{\partial L}{\partial x} = -kx\), \(\frac{d}{dt}\frac{\partial L}{\partial\dot x} = m\ddot x\). 그러므로 \(m\ddot x = -kx\).

주의라그랑지안은 \(T + U\)(전체 에너지)가 아니라 \(T - U\)입니다. 부호를 틀리면 운동 방정식에서 힘의 부호가 뒤집힙니다. 예제 1.3.1에서 \(m\ddot x = +kx\)가 나오면 부호를 틀린 것입니다.

"최소 작용"이라고 흔히 부르지만, 실제 경로는 작용이 정상값(최소, 최대, 안장점)이면 되고 늘 최소인 것은 아닙니다. 짧은 시간 구간에서는 최소입니다.

요약
  1. \(L = T - U\), \(S = \int L\,dt\), 실제 경로는 \(\delta S = 0\).
  2. \(\partial L/\partial x_i = \frac{d}{dt}\partial L/\partial\dot x_i\) ⟺ \(F = \dot p\).

1.3.3연습문제

기본

  1. 균일한 중력장에서 \(L = \frac12m(\dot x^2 + \dot y^2) - mgy\)의 운동 방정식을 구하여라.
    답

    \(m\ddot x = 0\), \(m\ddot y = -mg\). 포물선 운동.

1.3.2

실습경로를 바꾸며 작용 재기

실습 · 해밀턴 원리

다루는 성취기준 [물리4-01-03]

목표

양 끝을 고정한 채 실제 경로를 \(\epsilon\sin(n\pi t/T)\)만큼 흔들고 작용 \(S = \int L\,dt\)를 계산합니다. 실제 경로에서 \(S\)가 정상값(기울기 0)이고, 경우에 따라 최소가 아닐 수도 있음을 확인합니다. 성취기준 [물리4-01-03].

준비

질량은 1, 시간 구간은 \(T = 1\) s입니다. 위 그림의 회색 점선이 실제 경로, 파란 선이 바꾼 경로입니다. 아래 그림은 \(\epsilon\)을 −1에서 1까지 바꿀 때 \(S(\epsilon) - S(0)\)이고, 파란 점이 지금 값입니다. 작용은 심프슨 공식으로 수치 적분합니다.

절차

  1. 자유 낙하에서 ε를 바꿔 가며 \(S(\epsilon) - S(0)\)이 어디서 가장 작은지 본다. n을 바꿔도 같은지 확인한다.
  2. 조화 진동자 ω = 1, 2로 바꿔 같은 일을 한다.
  3. ω = 4.5로 바꾸고 n = 1과 n = 2에서 아래 곡선의 모양을 비교한다.

기대 결과

  • 자유 낙하: 실제 경로의 작용 \(S(0) = -4.0017\). ε = 0.5, n = 1이면 차이가 0.6169(이론 \(\frac{\pi^2}4\epsilon^2\)). 어느 n에서나 ε = 0이 최소다.
  • ω = 1, n = 1: 차이가 \(2.217\epsilon^2\)로 여전히 최소.
  • ω = 4.5, n = 1: 계수가 −2.595로 음수라 이 방향으로는 ε = 0이 최대다. n = 2에서는 계수 4.807로 최소. 실제 경로는 안장점이지만 기울기는 늘 0이다.

분석

  1. \(L\)이 \(q\), \(\dot q\)의 2차식이면 \(S(\epsilon)\)이 정확히 \(\epsilon\)의 2차식이 되는 까닭을 말해 보세요. 1차 항이 0인 것이 오일러-라그랑주 방정식과 어떻게 이어지나요?
  2. \(\omega T > \pi\)일 때 n = 1 방향으로 작용이 줄어드는 까닭을 \(\frac T4\left[(n\pi/T)^2 - \omega^2\right]\)로 설명해 보세요.
