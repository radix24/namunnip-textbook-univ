어떤 양이 보존되는지 확인하려면 시간 미분을 계산해야 합니다. 푸아송 괄호는 그 계산을 하나의 연산으로 묶어 둔 것입니다. 물리량 \(f\)와 해밀토니안 \(H\)의 괄호 \(\{f, H\}\)가 바로 \(f\)의 시간 변화율이고, 이것이 0이면 \(f\)는 보존됩니다. 이 괄호는 양자역학의 교환자로 그대로 옮겨 가므로, 고전역학과 양자역학을 잇는 다리이기도 합니다.

3.3.1정의

위상 공간 위의 두 함수 \(f(q, p)\), \(g(q, p)\)의 푸아송 괄호는

\[\{f, g\} = \sum_i\left(\frac{\partial f}{\partial q_i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q_i}\right).\]
  • 반대칭: \(\{f, g\} = -\{g, f\}\), 그래서 \(\{f, f\} = 0\).
  • 기본 괄호: \(\{q_i, p_j\} = \delta_{ij}\), \(\{q_i, q_j\} = \{p_i, p_j\} = 0\).
  • 선형성, 곱의 법칙 \(\{fg, h\} = f\{g, h\} + \{f, h\}g\), 야코비 항등식.

3.3.2시간 변화와 보존량

물리량 \(f(q, p, t)\)의 시간 미분에 해밀턴 방정식을 넣으면

정리 3.3.1 \[\frac{df}{dt} = \{f, H\} + \frac{\partial f}{\partial t}.\]

유도는 연쇄 법칙 한 줄입니다. \(\frac{df}{dt} = \sum_i\left(\frac{\partial f}{\partial q_i}\dot q_i + \frac{\partial f}{\partial p_i}\dot p_i\right) + \frac{\partial f}{\partial t}\)에 \(\dot q_i = \partial H/\partial p_i\), \(\dot p_i = -\partial H/\partial q_i\)를 넣으면 합이 정확히 \(\{f, H\}\)의 정의가 됩니다.

그러므로 시간을 직접 포함하지 않는 \(f\)가 보존되는 조건은 \(\{f, H\} = 0\)입니다. 해밀턴 방정식 자체도 \(\dot q_i = \{q_i, H\}\), \(\dot p_i = \{p_i, H\}\)로 쓸 수 있습니다. 두 보존량의 괄호도 보존량이라는 성질(푸아송 정리)이 있어, 새 보존량을 찾는 데 쓰기도 합니다.

예제 3.3.2

각운동량 성분 \(\ell_x = yp_z - zp_y\), \(\ell_y = zp_x - xp_z\)에 대해 \(\{\ell_x, \ell_y\}\)를 구하여라.

풀이. 곱의 법칙과 기본 괄호로 \(\{yp_z - zp_y, zp_x - xp_z\} = \{yp_z, zp_x\} + \{zp_y, xp_z\} = yp_x\{p_z, z\} + xp_y\{z, p_z\} = -yp_x + xp_y = \ell_z\). 중심력이면 \(\ell_x\), \(\ell_y\)가 보존되므로 푸아송 정리로 \(\ell_z\)도 보존됩니다.

양자역학에서는 푸아송 괄호 \(\{f, g\}\)가 교환자 \(\frac1{i\hbar}[\hat f, \hat g]\)로 바뀝니다(디랙). \(\{x, p\} = 1\)이 \([\hat x, \hat p] = i\hbar\)가 되며, 이것이 불확정성 원리의 바탕입니다(물리8).

요약
  1. \(\{f, g\} = \sum(\partial_qf\,\partial_pg - \partial_pf\,\partial_qg)\), \(\{q, p\} = 1\).
  2. \(df/dt = \{f, H\} + \partial f/\partial t\). 보존 ⟺ \(\{f, H\} = 0\).

3.3.3연습문제

기본

  1. 자유 입자 \(H = p^2/2m\)에서 \(f = x - pt/m\)이 보존됨을 정리 3.3.1로 보여라.
    답

    \(\{f, H\} = \{x, H\} = p/m\), \(\partial f/\partial t = -p/m\). 합이 0.

3.3.2

예제케플러 문제의 숨은 보존량: Laplace-Runge-Lenz 벡터

Poisson 괄호 · 보존 판정 · 문제 해결 전략

다루는 성취기준 [물리4-03-03]

출발점

물리량 \(f\)가 보존되는지 보려면 \(\{f, H\}\)를 계산합니다. 역제곱 힘에서는 에너지와 각운동량 말고도 근일점 방향을 가리키는 벡터 \(\mathbf A = \mathbf p\times\mathbf L - mk\hat{\mathbf r}\)가 보존됩니다.

문제 해결 전략 · Poisson 괄호로 보존 판정
  1. \(H\)를 쓴다.
  2. 기본 괄호와 곱의 법칙으로 \(\{f, H\}\)를 계산하거나, \(df/dt\)를 운동 방정식으로 직접 계산한다.
  3. 0이면 보존.
  4. 보존량의 물리적 뜻을 해석한다.

\(H = \frac{p^2}{2m} - \frac kr\)에서 \(\mathbf A = \mathbf p\times\mathbf L - mk\hat{\mathbf r}\)가 보존됨을 보여라(\(df/dt = \{f, H\}\)이므로 운동 방정식으로 시간 미분을 계산해도 된다).

풀이

  1. \(\mathbf L\)은 보존되므로 \(\frac{d}{dt}(\mathbf p\times\mathbf L) = \dot{\mathbf p}\times\mathbf L = -\frac k{r^2}\hat{\mathbf r}\times(m\mathbf r\times\dot{\mathbf r})\).
    \(\dot{\mathbf p} = -k\hat{\mathbf r}/r^2\), \(\mathbf L = m\mathbf r\times\dot{\mathbf r}\).
  2. 삼중곱: \(\hat{\mathbf r}\times(\mathbf r\times\dot{\mathbf r}) = \mathbf r(\hat{\mathbf r}\cdot\dot{\mathbf r}) - \dot{\mathbf r}(\hat{\mathbf r}\cdot\mathbf r) = \dot r\mathbf r - r\dot{\mathbf r}\).
    \(\hat{\mathbf r}\cdot\dot{\mathbf r} = \dot r\).
  3. 따라서 \(\frac{d}{dt}(\mathbf p\times\mathbf L) = mk\left(\frac{\dot{\mathbf r}}r - \frac{\dot r\mathbf r}{r^2}\right) = mk\frac{d\hat{\mathbf r}}{dt}\).
    \(\frac{d}{dt}\frac{\mathbf r}r\)를 알아본다.
  4. \(\frac{d\mathbf A}{dt} = mk\dot{\hat{\mathbf r}} - mk\dot{\hat{\mathbf r}} = 0\). 보존.
    \(\{\mathbf A, H\} = 0\).

의미

\(\mathbf A\)는 근일점을 가리키고 크기가 \(mk\epsilon\)입니다. 이것이 보존된다는 것은 타원 궤도가 돌지 않고 닫힌다는 뜻입니다. 힘이 역제곱에서 조금만 벗어나도(수성의 상대론 보정) \(\mathbf A\)가 천천히 돌아 근일점이 이동합니다.

검산

원 궤도(\(\epsilon = 0\))에서 \(\mathbf p\times\mathbf L\)은 바깥쪽 크기 \(pL = mk\)라 \(mk\hat{\mathbf r}\)과 정확히 지워져 \(\mathbf A = 0\)입니다.
