  • 라그랑주 방정식과 에너지 함수 (2.1절, 2.2절).

라그랑주 방법이 위치와 속도로 운동을 기술한다면, 해밀턴 방법은 위치와 운동량을 대등한 짝으로 놓고 기술합니다. 그러면 운동 방정식이 "위치의 변화율은 \(H\)를 운동량으로 미분한 것, 운동량의 변화율은 \(H\)를 위치로 미분한 것에 음의 부호"라는 대칭적인 1계 방정식이 됩니다. 이 대칭이 위상 공간, 통계역학, 양자역학으로 이어지는 길을 엽니다.

3.1.1해밀토니안

라그랑주 역학은 \((q, \dot q)\)를 변수로 쓰는 2계 방정식 \(n\)개입니다. 해밀턴 역학은 속도 대신 일반화 운동량 \(p_i = \partial L/\partial\dot q_i\)를 변수로 써서 1계 방정식 \(2n\)개로 바꿉니다. 변수를 바꾸는 방법이 르장드르 변환입니다.

\[H(q, p, t) = \sum_ip_i\dot q_i - L,\]

오른쪽의 \(\dot q_i\)는 모두 \(q, p\)로 바꿔 씁니다. 2.2절의 에너지 함수 \(h\)와 같은 식이며, 보통의 경우(좌표 변환이 시간에 무관) \(H = T + U\)입니다.

3.1.2정준 방정식

\(H\)의 전미분과 라그랑주 방정식을 비교합니다. \(dH = \sum_i(\dot q_i\,dp_i + p_i\,d\dot q_i) - \sum_i\left(\frac{\partial L}{\partial q_i}dq_i + \frac{\partial L}{\partial\dot q_i}d\dot q_i\right) - \frac{\partial L}{\partial t}dt\)에서 \(p_i = \partial L/\partial\dot q_i\)라 \(d\dot q_i\) 항이 지워지고(르장드르 변환을 쓰는 이유), \(\partial L/\partial q_i = \dot p_i\)를 넣으면 \(dH = \sum_i(\dot q_i\,dp_i - \dot p_i\,dq_i) - \frac{\partial L}{\partial t}dt\)입니다. \(dp_i\), \(dq_i\)의 계수를 읽으면

정리 3.1.1 (해밀턴 방정식) \[\dot q_i = \frac{\partial H}{\partial p_i}, \qquad \dot p_i = -\frac{\partial H}{\partial q_i}, \qquad \frac{dH}{dt} = \frac{\partial H}{\partial t}.\]

\(H\)가 시간을 직접 포함하지 않으면 \(H\)가 보존됩니다. \(H\)에 \(q_j\)가 없으면 \(p_j\)가 보존됩니다(순환 좌표).

예제 3.1.2

중심력 문제의 해밀토니안과 정준 방정식을 극좌표로 쓰라.

풀이. \(L = \frac12m(\dot r^2 + r^2\dot\phi^2) - U(r)\)에서 \(p_r = m\dot r\), \(p_\phi = mr^2\dot\phi\). \(H = \frac{p_r^2}{2m} + \frac{p_\phi^2}{2mr^2} + U(r)\). 정준 방정식:

  • \(\dot r = p_r/m\), \(\dot\phi = p_\phi/(mr^2)\).
  • \(\dot p_r = \frac{p_\phi^2}{mr^3} - U'(r)\), \(\dot p_\phi = 0\).

\(p_\phi\)는 각운동량으로 보존되고, \(r\)의 운동은 물리1 5.2절의 유효 퍼텐셜 문제와 같습니다.

주의\(H\)는 반드시 \(q\)와 \(p\)의 함수로 써야 합니다. \(H = \frac12m\dot r^2 + \dots\)처럼 속도가 남은 채로 \(p\)로 미분하면 틀린 답이 나옵니다. 먼저 \(p_i = \partial L/\partial\dot q_i\)를 \(\dot q_i\)에 대해 풀어 모두 바꿔 넣으세요.

3.1.3왜 해밀턴 역학인가

  • 1계 방정식이라 수치 적분과 위상 공간 분석(3.2절)에 알맞다.
  • \(q\)와 \(p\)를 대등하게 다루어, 둘을 섞는 좌표 변환(정준 변환)으로 문제를 단순하게 만들 수 있다.
  • 통계역학(위상 공간의 부피, 물리13)과 양자역학(해밀토니안 연산자, 물리8)의 출발점이다.
요약
  1. \(H = \sum p\dot q - L\), 보통 \(T + U\).
  2. \(\dot q = \partial H/\partial p\), \(\dot p = -\partial H/\partial q\).

3.1.4연습문제

기본

  1. 단진자의 해밀토니안과 정준 방정식을 쓰라.
