3.3.1페이저

선형 회로에 진동수 \(\omega\)인 사인파를 걸면, 정상 상태에서 모든 전압과 전류가 같은 \(\omega\)로 진동합니다. \(v(t) = V_0\cos(\omega t + \phi)\)를 복소수 \(\tilde V = V_0e^{i\phi}\)(페이저)로 나타내고 \(v = \mathrm{Re}(\tilde Ve^{i\omega t})\)로 되돌립니다. 미분은 \(i\omega\)를 곱하는 것이 되어 미분방정식이 대수식으로 바뀝니다.

정의 3.3.1 (임피던스) \[\tilde V = Z\tilde I, \qquad Z_R = R, \quad Z_L = i\omega L, \quad Z_C = \frac1{i\omega C}.\]

직렬은 \(Z = \sum Z_k\), 병렬은 \(1/Z = \sum1/Z_k\). 키르히호프 법칙도 페이저로 그대로 성립합니다.

인덕터에서 전압이 전류보다 \(90°\) 앞서고(\(i = e^{i\pi/2}\)), 축전기에서는 \(90°\) 뒤집니다.

3.3.2직렬 RLC

\[Z = R + i\left(\omega L - \frac1{\omega C}\right), \qquad |\tilde I| = \frac{V_0}{\sqrt{R^2 + (\omega L - 1/\omega C)^2}}, \qquad \tan\phi = \frac{\omega L - 1/\omega C}{R}.\]
  • 공명 \(\omega_0 = 1/\sqrt{LC}\)에서 \(Z = R\), 전류 최대, 위상차 0.
  • 선택도 \(Q = \omega_0L/R = \frac1R\sqrt{L/C}\). 전류 진폭이 \(1/\sqrt2\)이 되는 두 진동수의 폭(반치 전력 폭)은 \(\Delta\omega = \omega_0/Q\).
  • 공명에서 \(L\)과 \(C\) 양단 전압은 전원 전압의 \(Q\)배가 될 수 있다.

3.3.3전력

순간 전력 \(p = vi\)의 한 주기 평균은 페이저로

\[\langle P\rangle = \frac12\mathrm{Re}(\tilde V\tilde I^*) = \frac12V_0I_0\cos\phi = V_{\text{rms}}I_{\text{rms}}\cos\phi.\]

\(\cos\phi\)가 역률입니다. 순수한 \(L\)이나 \(C\)는 평균 전력을 소비하지 않고 에너지를 주고받기만 합니다. \(\langle P\rangle = \frac12|\tilde I|^2R\)로, 저항에서만 소비됩니다.

예제 3.3.2

\(R = 10\ \Omega\), \(L = 10\) mH, \(C = 1\ \mu\text{F}\) 직렬 회로에 진폭 1 V 교류를 겁니다. 공명 진동수, \(Q\), 공명에서 축전기 양단 전압 진폭은?

풀이. \(\omega_0 = 1/\sqrt{10^{-2}\times10^{-6}} = 10^4\) rad/s (\(f_0 \approx 1.59\) kHz). \(Q = \omega_0L/R = 10^4\times10^{-2}/10 = 10\). 공명 전류 \(0.1\) A, \(|V_C| = I/(\omega_0C) = 0.1/(10^4\times10^{-6}) = 10\) V. 전원의 10배입니다.

요약
  1. 페이저: \(d/dt \to i\omega\). \(Z_R = R\), \(Z_L = i\omega L\), \(Z_C = 1/i\omega C\).
  2. 직렬 RLC: 공명 \(\omega_0 = 1/\sqrt{LC}\), \(Q = \omega_0L/R\), 폭 \(\omega_0/Q\).
  3. \(\langle P\rangle = \frac12\mathrm{Re}(\tilde V\tilde I^*)\), 역률 \(\cos\phi\).

3.3.4연습문제

기본

  1. \(R\)과 \(C\)를 직렬로 연결한 회로에서 \(C\) 양단 전압의 진폭이 입력의 \(1/\sqrt2\)이 되는 진동수는?
    답

    \(|V_C/V| = 1/\sqrt{1 + (\omega RC)^2}\)이므로 \(\omega = 1/RC\). 저역 통과 필터의 차단 진동수입니다.

  2. \(L\)과 \(C\)를 병렬로 연결한 부분의 임피던스는? 공명에서는?
    답

    \(Z = \frac{i\omega L}{1 - \omega^2LC}\). \(\omega = \omega_0\)에서 무한대: 전류가 들어가지 않습니다(이상적인 경우).

발전

  1. 예제 3.3.2에서 \(\omega = 1.1\omega_0\)일 때 평균 전력을 공명 때와 비교하세요.
    답

    리액턴스 \(\omega L - 1/\omega C = 110 - 90.9 = 19.1\ \Omega\). \(|Z| = \sqrt{100 + 365} \approx 21.6\ \Omega\). 전력비 \((10/21.6)^2 \approx 0.21\). \(Q = 10\)이라 10% 벗어나면 전력이 5분의 1로 줄어듭니다.
