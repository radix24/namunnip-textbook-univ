이 절에서 배울 것
  • 도체 벽 사이에 갇힌 전자기파의 경계 조건과 모드를 구한다.
  • 차단 진동수보다 낮은 진동수는 도파관을 지나지 못함을 보인다.
  • 군속도와 위상 속도의 차이를 안다.
먼저 알아야 할 것
  • 평면파 (5.2절), 도체의 경계 조건 (5.4절), 변수 분리 (물리18 6.1절).

전자레인지나 레이더는 마이크로파를 속이 빈 금속관(도파관)으로 보냅니다. 금속 벽은 전기장의 접선 성분을 0으로 만들기 때문에, 관 안에는 벽 조건에 맞는 특정 모양(모드)의 파동만 지나갈 수 있습니다. 관이 파장에 비해 너무 좁으면 어떤 모드도 지나가지 못합니다. 그 경계가 차단 진동수입니다.

7.1.1용어

  • 도파관: 전자기파를 한 방향으로 가두어 보내는 속 빈 도체관.
  • TE 모드: 진행 방향(\(z\)) 전기장 성분이 0인 모드. TM 모드는 \(B_z = 0\).
  • 차단 진동수 \(\omega_{mn}\): 그보다 낮은 진동수에서는 모드가 진행하지 못하고 지수적으로 줄어드는 진동수.
  • 군속도 \(v_g = d\omega/dk\): 에너지와 신호가 가는 속도. 위상 속도 \(v_p = \omega/k\): 마루가 움직이는 속도.

7.1.2모드와 차단 진동수

  1. 관 단면이 \(a\times b\) (\(a > b\))라 하자. 장을 \(B_z = B(x, y)e^{i(kz - \omega t)}\)로 두면 파동 방정식이 \(\left(\partial_x^2 + \partial_y^2 + \frac{\omega^2}{c^2} - k^2\right)B = 0\)이 된다. 진행 방향은 이미 \(e^{ikz}\)로 정해 두었다.
  2. 벽에서 전기장 접선 성분 0 → \(B_z\)의 법선 도함수 0. 변수 분리로 \(B = B_0\cos\frac{m\pi x}a\cos\frac{n\pi y}b\). 벽 조건이 정수 \(m, n\)을 고른다.
  3. 대입하면 \(k^2 = \frac{\omega^2}{c^2} - \pi^2\left(\frac{m^2}{a^2} + \frac{n^2}{b^2}\right)\). \(k\)가 실수여야 진행한다.
결과 7.1.1 \[\omega_{mn} = c\pi\sqrt{\frac{m^2}{a^2} + \frac{n^2}{b^2}},\qquad k = \frac1c\sqrt{\omega^2 - \omega_{mn}^2},\qquad v_gv_p = c^2.\]

가장 낮은 모드는 TE\(_{10}\)이고 차단 진동수는 \(f_{10} = c/2a\)입니다. 관의 넓은 폭이 반 파장보다 작으면 아무 모드도 지나가지 못합니다. \(v_p > c\)이지만 \(v_g < c\)라 신호는 빛보다 느립니다.

예제 7.1.1

표준 도파관 \(a = 2.286\) cm, \(b = 1.016\) cm(X 밴드)의 TE\(_{10}\) 차단 진동수와, 10 GHz 신호의 군속도를 구하여라. TE\(_{20}\)는 지나가나?

풀이. \(f_{10} = \frac{3\times10^8}{2\times0.02286} = 6.56\) GHz. 10 GHz에서 \(v_g = c\sqrt{1 - (6.56/10)^2} = 0.755c\). TE\(_{20}\)의 차단은 13.1 GHz라 10 GHz는 지나가지 못합니다. 그래서 6.56~13.1 GHz 사이에서는 TE\(_{10}\) 한 모드만 지나가 신호가 깨끗합니다.

주의속 빈 도파관에는 TEM 모드(\(E_z = B_z = 0\))가 없습니다. 동축 케이블처럼 도체가 두 개여야 TEM 모드가 있고, 그때는 차단 진동수가 없습니다. "관만 있으면 아무 진동수나 보낼 수 있다"는 생각은 틀립니다.
요약
  1. 벽 조건이 모드 \((m, n)\)을 고르고, 각 모드에 차단 진동수.
  2. \(f_{10} = c/2a\): 넓은 폭이 반 파장보다 커야 진행.
  3. \(v_gv_p = c^2\), 신호는 \(v_g < c\).

7.1.3연습문제

기본

  1. 2.45 GHz 전자레인지 마이크로파를 TE\(_{10}\) 모드로만 보내려면 관의 넓은 폭 \(a\)는 어느 범위여야 하나(\(b < a/2\))?
    답

    \(c/2a < 2.45\) GHz < \(c/a\): \(6.1\) cm < \(a\) < \(12.2\) cm.

이 절의 성취기준[물리9-07-01] 계산 POSTECH

  1. 직사각형 도파관의 TE 모드와 차단 진동수를 구할 수 있다.

7.1.2

예제도파관 안의 마이크로파 파장

관내 파장 · 위상 속도 · 군속도 · 문제 해결 전략

다루는 성취기준 [물리9-07-01]

출발점

TE\(_{10}\) 모드의 진행 파수는 \(k = \frac1c\sqrt{\omega^2 - \omega_{10}^2}\)라 관 안 파장 \(\lambda_g = \frac{\lambda_0}{\sqrt{1 - (f_{10}/f)^2}}\)는 자유 공간 파장보다 깁니다.

문제 해결 전략 · 도파관 파장
  1. 차단 진동수 \(f_{10} = c/2a\)를 구한다.
  2. \(\lambda_g\), \(v_p = c/\sqrt{1 - (f_{10}/f)^2}\), \(v_g = c\sqrt{1 - (f_{10}/f)^2}\)를 구한다.
  3. \(v_pv_g = c^2\)으로 점검한다.
  4. 측정(정상파 마디 간격 \(\lambda_g/2\))과 연결한다.

넓은 폭 \(a = 7.2\) cm인 도파관에 2.45 GHz 마이크로파를 보낸다. 자유 공간 파장, 관내 파장, 군속도는? 관 끝을 막아 정상파를 만들면 마디 간격은?

풀이

  1. \(f_{10} = 3\times10^8/0.144 = 2.08\) GHz. \(\lambda_0 = 12.2\) cm.
    차단 아래면 진행 못 함.
  2. \(\sqrt{1 - (2.08/2.45)^2} = \sqrt{1 - 0.721} = 0.528\).
    비율.
  3. \(\lambda_g = 12.2/0.528 = 23.2\) cm, \(v_g = 0.528c = 1.58\times10^8\) m/s.
    관 안 파장이 더 길다.
  4. 정상파 마디 간격 \(\lambda_g/2 = 11.6\) cm.
    측정으로 확인 가능.

의미

관 안의 파동은 벽 사이를 지그재그로 튕기며 나아가는 두 평면파의 합으로 볼 수 있습니다. 축 방향으로 재면 마루 간격이 늘어나고(\(\lambda_g\)), 에너지는 지그재그 때문에 느리게 갑니다(\(v_g\)).

검산

\(v_p = c/0.528 = 5.68\times10^8\), \(v_pv_g = 8.98\times10^{16} \approx c^2\). 맞습니다.
