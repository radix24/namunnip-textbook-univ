이 절에서 배울 것
  • \(\mathbf B = \nabla\times\mathbf A\)로 벡터 퍼텐셜을 정의하고 쿨롱 게이지를 고른다.
  • \(\mathbf A\)를 전류 분포의 적분으로 계산한다.
  • 자기 쌍극자의 퍼텐셜과 자기장의 경계 조건을 안다.
먼저 알아야 할 것
  • 헬름홀츠 정리와 퍼텐셜 (물리5 1.3절), 앙페르 법칙 (1.2절), 다중극 전개 (물리5 4.4절).

1.3.1정의와 게이지

\(\nabla\cdot\mathbf B = 0\)이므로 \(\mathbf B = \nabla\times\mathbf A\)인 \(\mathbf A\)가 있습니다. \(\mathbf A\)에 아무 기울기 \(\nabla\lambda\)를 더해도 \(\mathbf B\)는 그대로이므로, 편한 조건을 하나 더 걸 수 있습니다. 정자기학에서는 \(\nabla\cdot\mathbf A = 0\) (쿨롱 게이지)을 고릅니다. 그러면 앙페르 법칙은

\[\nabla\times(\nabla\times\mathbf A) = \nabla(\nabla\cdot\mathbf A) - \nabla^2\mathbf A = \mu_0\mathbf J \;\Rightarrow\; \nabla^2\mathbf A = -\mu_0\mathbf J.\]

성분마다 푸아송 방정식이므로, 정전기의 해 \(V = \frac1{4\pi\epsilon_0}\int\frac\rho{\mathcal R}d\tau'\)를 그대로 옮겨 씁니다.

정리 1.3.1 \[\mathbf A(\mathbf r) = \frac{\mu_0}{4\pi}\int\frac{\mathbf J(\mathbf r')}{\mathcal R}d\tau' = \frac{\mu_0}{4\pi}\int\frac{\mathbf I}{\mathcal R}dl'.\]

\(\mathbf A\)는 대개 전류와 같은 방향을 가리킵니다. 적분에 외적이 없어 \(\mathbf B\)를 직접 구하는 것보다 쉬울 때가 많습니다.

1.3.2몇 가지 예

  • 균일한 자기장: \(\mathbf A = \frac12\mathbf B\times\mathbf r\). 회전을 계산하면 \(\mathbf B\)가 나온다.
  • 무한 솔레노이드: \(\oint\mathbf A\cdot d\mathbf l = \int\mathbf B\cdot d\mathbf a = \Phi\)를 쓰면 안에서 \(A_\phi = \frac{\mu_0nI}2s\), 밖에서 \(A_\phi = \frac{\mu_0nIR^2}{2s}\). 밖에서는 \(\mathbf B = 0\)인데 \(\mathbf A \ne 0\)이다.
  • 무한 도선: 적분이 발산하므로 기준점을 잡아 \(A_z = -\frac{\mu_0I}{2\pi}\ln\frac s{s_0}\).

솔레노이드 밖의 \(\mathbf A\)는 고전적으로는 아무 효과가 없지만, 양자역학에서는 전자의 위상을 바꿉니다(아하로노프-봄 효과, 1959년 예측, 실험으로 확인). 퍼텐셜이 계산 도구 이상일 수 있다는 예입니다.

1.3.3자기 쌍극자

작은 고리 전류의 \(\mathbf A\)를 먼 곳에서 다중극 전개하면, 홀극 항은 \(\oint d\mathbf l' = 0\)이라 사라지고 쌍극자 항이 첫 항입니다.

결과 1.3.2 \[\mathbf A_{\text{dip}} = \frac{\mu_0}{4\pi}\frac{\mathbf m\times\hat{\mathbf r}}{r^2}, \qquad \mathbf B_{\text{dip}} = \frac{\mu_0}{4\pi r^3}\left[3(\mathbf m\cdot\hat{\mathbf r})\hat{\mathbf r} - \mathbf m\right], \qquad \mathbf m = I\int d\mathbf a.\]

먼 곳의 모양은 전기 쌍극자와 같지만, 가까이에서는 다릅니다. 고리 안을 지나는 자기력선은 위로 이어져 닫힙니다.

1.3.4경계 조건

면전류 \(\mathbf K\)가 흐르는 면을 지날 때(\(\hat{\mathbf n}\)은 아래에서 위로)

\[B^\perp_{\text{위}} = B^\perp_{\text{아래}}, \qquad \mathbf B_{\text{위}} - \mathbf B_{\text{아래}} = \mu_0\mathbf K\times\hat{\mathbf n}, \qquad \mathbf A\text{는 연속}.\]

앞의 것은 \(\nabla\cdot\mathbf B = 0\)의 납작한 상자, 뒤의 것은 앙페르 법칙의 좁은 고리에서 나옵니다.

예제 1.3.2

반지름 \(R\)인 구 껍질에 전하 \(Q\)가 고르게 있고 각속도 \(\omega\)로 돕니다. 쌍극자 모멘트는?

풀이. 폭 \(R\,d\theta\)인 띠의 전류는 \(dI = \sigma(\omega R\sin\theta)R\,d\theta\), 넓이 \(\pi R^2\sin^2\theta\). \(m = \int\pi R^2\sin^2\theta\,dI = \pi\sigma\omega R^4\int_0^\pi\sin^3\theta\,d\theta = \frac43\pi\sigma\omega R^4 = \frac13QR^2\omega\). 안쪽 자기장은 균일하게 \(\frac23\mu_0\sigma R\omega\)입니다(정확한 풀이 결과).

요약
  1. \(\mathbf B = \nabla\times\mathbf A\), 쿨롱 게이지에서 \(\nabla^2\mathbf A = -\mu_0\mathbf J\), \(\mathbf A = \frac{\mu_0}{4\pi}\int\frac{\mathbf J}{\mathcal R}d\tau'\).
  2. \(\oint\mathbf A\cdot d\mathbf l = \Phi\). 균일 장 \(\mathbf A = \frac12\mathbf B\times\mathbf r\).
  3. 쌍극자 \(\mathbf A = \frac{\mu_0}{4\pi}\frac{\mathbf m\times\hat{\mathbf r}}{r^2}\). 경계에서 \(B^\perp\) 연속, \(B^\parallel\)은 \(\mu_0K\)만큼 뜀.

1.3.5연습문제

기본

  1. \(\mathbf A = \frac12\mathbf B\times\mathbf r\)의 발산과 회전을 확인하세요(\(\mathbf B = B\hat z\)).
    답

    \(\mathbf A = \frac B2(-y, x, 0)\). \(\nabla\cdot\mathbf A = 0\), \(\nabla\times\mathbf A = (0, 0, B)\).

  2. 반지름 2 cm 고리에 3 A가 흐를 때 자기 쌍극자 모멘트는?
    답

    \(m = 3\times\pi(0.02)^2 \approx 3.8\times10^{-3}\ \text{A·m}^2\).

발전

  1. \(\mathbf A' = \mathbf A + \nabla\lambda\)가 쿨롱 게이지가 되려면 \(\lambda\)가 어떤 방정식을 만족해야 하나요?
    답

    \(\nabla^2\lambda = -\nabla\cdot\mathbf A\). 푸아송 방정식이므로 늘 풀 수 있어, 쿨롱 게이지는 언제나 고를 수 있습니다.
