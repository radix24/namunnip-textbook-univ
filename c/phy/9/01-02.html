1.2.1법칙

법칙 1.2.1 (비오-사바르) \[\mathbf B(\mathbf r) = \frac{\mu_0}{4\pi}\int\frac{\mathbf I\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}dl' = \frac{\mu_0}{4\pi}\int\frac{\mathbf J(\mathbf r')\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}d\tau', \qquad \boldsymbol{\mathcal R} = \mathbf r - \mathbf r'.\]

\(\mu_0 = 4\pi\times10^{-7}\ \text{N/A}^2\) (2019년 SI 개정 뒤에는 측정값이며 이 값과 \(10^{-10}\) 수준으로 같음).

정전기의 쿨롱 법칙과 같은 \(1/\mathcal R^2\)이지만, 원천이 벡터이고 외적이 들어가 자기장은 전류에 수직으로 감깁니다. 정상 전류에서만 정확합니다.

1.2.2직선 도선 토막

도선에서 수직 거리 \(s\)인 점에서, 도선 양 끝을 보는 각을 \(\theta_1\), \(\theta_2\)(수직선에서 잼)라 하면 \(dl' \times \hat{\boldsymbol{\mathcal R}}\)의 크기는 \(dl'\cos\theta\), \(l' = s\tan\theta\), \(\mathcal R = s/\cos\theta\)이므로

\[B = \frac{\mu_0I}{4\pi}\int_{\theta_1}^{\theta_2}\frac{\cos\theta}{s}d\theta = \frac{\mu_0I}{4\pi s}(\sin\theta_2 - \sin\theta_1).\]

무한 도선(\(\theta_1 = -\pi/2\), \(\theta_2 = \pi/2\))이면 \(B = \mu_0I/(2\pi s)\)입니다.

1.2.3원형 고리의 축 위

반지름 \(R\)인 고리의 축 위 높이 \(z\)에서, 고리 각 조각의 \(d\mathbf B\)는 축에 수직인 성분이 대칭으로 상쇄되고 축 성분만 남습니다.

결과 1.2.2 \[B_z(z) = \frac{\mu_0I}{2}\frac{R^2}{(R^2 + z^2)^{3/2}}.\]

중심(\(z = 0\))에서 \(\mu_0I/2R\), 먼 곳(\(z \gg R\))에서 \(\frac{\mu_0}{2\pi}\frac{m}{z^3}\) (\(m = I\pi R^2\)). 전기 쌍극자와 같은 \(1/z^3\)입니다.

같은 고리 두 개를 반지름만큼 떨어뜨려 놓으면(헬름홀츠 코일) 가운데에서 \(B\)가 매우 고르게 됩니다. 아래 실습 카드에서 간격을 바꾸며 확인할 수 있습니다.

1.2.4자기장의 발산

비오-사바르 식에서 \(\nabla\cdot(\mathbf J\times\hat{\boldsymbol{\mathcal R}}/\mathcal R^2) = \frac{\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}\cdot(\nabla\times\mathbf J) - \mathbf J\cdot\left(\nabla\times\frac{\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}\right)\)이고, \(\mathbf J\)는 \(\mathbf r'\)의 함수라 첫 항이 0, \(\nabla\times(\hat{\boldsymbol{\mathcal R}}/\mathcal R^2) = 0\)이라 둘째 항도 0입니다. 따라서

\[\nabla\cdot\mathbf B = 0.\]

자기 홀극이 없다는 뜻이며, 자기력선은 시작도 끝도 없이 닫힙니다.

예제 1.2.1

한 변 \(a\)인 정사각형 고리에 전류 \(I\)가 흐릅니다. 중심의 자기장은?

풀이. 한 변은 중심에서 거리 \(s = a/2\), 양 끝 각 \(\pm45°\)이므로 \(B_1 = \frac{\mu_0I}{4\pi(a/2)}\cdot2\cdot\frac{\sqrt2}2 = \frac{\sqrt2\mu_0I}{2\pi a}\). 네 변이 같은 방향으로 더해져 \(B = \frac{2\sqrt2\mu_0I}{\pi a} \approx 0.90\frac{\mu_0I}{a}\). 같은 둘레의 원(\(R = 2a/\pi\))은 \(\frac{\pi\mu_0I}{4a} \approx 0.785\frac{\mu_0I}a\)입니다.

요약
  1. \(\mathbf B = \frac{\mu_0}{4\pi}\int\frac{\mathbf I\times\hat{\boldsymbol{\mathcal R}}}{\mathcal R^2}dl'\).
  2. 직선 토막 \(\frac{\mu_0I}{4\pi s}(\sin\theta_2 - \sin\theta_1)\), 고리 축 \(\frac{\mu_0IR^2}{2(R^2 + z^2)^{3/2}}\).
  3. \(\nabla\cdot\mathbf B = 0\): 자기 홀극이 없다.

1.2.5연습문제

기본

  1. 반지름 \(R\)인 반원과 두 직선으로 된 머리핀 모양 도선의 반원 중심의 자기장은?
    답

    반원 \(\frac{\mu_0I}{4R}\), 두 반무한 직선 각각 \(\frac{\mu_0I}{4\pi R}\). 합 \(\frac{\mu_0I}{4R}\left(1 + \frac2\pi\right)\).

  2. 감은 수 \(n\)/m인 무한 솔레노이드의 안쪽 자기장을 고리 결과를 적분해 구하세요.
    답

    \(B = \int\frac{\mu_0nI}{2}\frac{R^2\,dz}{(R^2 + z^2)^{3/2}} = \mu_0nI\).

발전

  1. 헬름홀츠 코일(반지름 \(R\), 간격 \(d\))에서 가운데 \(d^2B_z/dz^2 = 0\)이 되는 \(d\)를 구하세요.
    답

    한 고리의 \(B(z)\)를 \(z = d/2\)에서 두 번 미분해 0으로 두면 \(d = R\). 이때 홀수 차 미분은 대칭으로 0이라 4차까지 평평합니다.

1.2.6법칙

비오-사바르 식의 회전을 계산하면(정상 전류 \(\nabla'\cdot\mathbf J = 0\)과 \(\nabla^2(1/\mathcal R) = -4\pi\delta^3\)을 씀)

정리 1.2.2 (앙페르 법칙) \[\nabla\times\mathbf B = \mu_0\mathbf J, \qquad \oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}.\]

오른손 법칙: 손가락이 고리 방향을 따라 감기면 엄지 방향으로 지나는 전류가 양.

가우스 법칙처럼 늘 성립하지만, 계산에 쓸모 있는 것은 대칭이 커서 \(\mathbf B\)를 적분 밖으로 꺼낼 수 있을 때뿐입니다. 쓸 수 있는 경우는 사실상 넷입니다: 무한 직선, 무한 평면, 무한 솔레노이드, 토로이드.

1.2.7네 가지 대칭

  1. 무한 도선 (반지름 \(a\), 균일 전류): 밖은 \(B = \frac{\mu_0I}{2\pi s}\), 안은 감긴 전류가 \(I s^2/a^2\)이라 \(B = \frac{\mu_0Is}{2\pi a^2}\).
  2. 무한 면전류 \(\mathbf K = K\hat x\) (\(xy\)평면): 위아래로 \(B = \frac{\mu_0K}2\), 방향은 반대(\(\mp\hat y\)). 면을 지날 때 \(\mu_0K\)만큼 뛴다.
  3. 무한 솔레노이드 (\(n\)회/m): 안 \(B = \mu_0nI\), 밖 0. 직사각형 고리의 한 변만 안에 넣어 얻는다.
  4. 토로이드 (감은 수 \(N\)): 안 \(B = \frac{\mu_0NI}{2\pi s}\), 밖 0. 단면 모양과 상관없다.

대칭 논증이 핵심입니다. 예를 들어 솔레노이드 밖의 자기장이 0인 것은 "먼 곳에서 0"과 "밖의 두 지름 거리에서 같은 값"(직사각형 고리에 전류가 감기지 않음)에서 나옵니다.

정전기정자기
발산\(\nabla\cdot\mathbf E = \rho/\epsilon_0\)\(\nabla\cdot\mathbf B = 0\)
회전\(\nabla\times\mathbf E = 0\)\(\nabla\times\mathbf B = \mu_0\mathbf J\)
힘\(q\mathbf E\)\(q\mathbf v\times\mathbf B\)
예제 1.2.3

동축 케이블(안 도선 반지름 \(a\), 바깥 얇은 원통 반지름 \(b\))에 같은 전류 \(I\)가 반대로 흐릅니다. 모든 곳의 \(B\)를 구하세요(안 도선 전류는 표면에만).

풀이. \(s < a\): 감긴 전류 0, \(B = 0\). \(a < s < b\): \(B = \frac{\mu_0I}{2\pi s}\). \(s > b\): 알짜 전류 0이라 \(B = 0\). 자기장이 케이블 안에 갇혀 바깥 회로와 간섭하지 않습니다.

요약
  1. \(\nabla\times\mathbf B = \mu_0\mathbf J\), \(\oint\mathbf B\cdot d\mathbf l = \mu_0I_{\text{감김}}\).
  2. 도선 \(\mu_0I/2\pi s\), 면 \(\mu_0K/2\), 솔레노이드 \(\mu_0nI\), 토로이드 \(\mu_0NI/2\pi s\).
  3. 대칭 논증으로 \(\mathbf B\)의 방향과 크기가 일정한 고리를 고른다.

1.2.8연습문제

기본

  1. 길이 20 cm에 500회 감은 솔레노이드에 2 A가 흐릅니다. 안의 \(B\)는?
    답

    \(n = 2500\)/m, \(B = 4\pi\times10^{-7}\times2500\times2 \approx 6.3\) mT.

  2. \(J = ks\)인 무한 도선(반지름 \(a\)) 안팎의 \(B\)는?
    답

    안: \(I_{\text{감김}} = 2\pi ks^3/3\), \(B = \mu_0ks^2/3\). 밖: \(B = \mu_0ka^3/(3s)\).

발전

  1. 두께 \(2d\)인 무한 판(\(|z| < d\))에 균일한 \(\mathbf J = J\hat x\)가 흐릅니다. \(B(z)\)를 구하세요.
    답

    \(|z| < d\): \(\mathbf B = -\mu_0Jz\,\hat y\). \(|z| > d\): \(\mathbf B = \mp\mu_0Jd\,\hat y\) (\(z > 0\)이면 \(-\)). \(d \to 0\), \(2Jd = K\)이면 면전류 결과가 됩니다.

1.2.3

실습헬름홀츠 코일의 고른 자기장

실습 · 비오-사바르

다루는 성취기준 [물리9-01-02]

목표

반지름 \(R\)인 같은 고리 두 개를 축 위에 놓고 간격을 바꾸며, 가운데 자기장이 가장 고르게 되는 간격을 찾습니다. 전류를 반대로 흘린 경우(반헬름홀츠)도 봅니다. 성취기준 [물리9-01-02].

준비

고리 하나의 축 위 자기장 \(B_z = \frac{\mu_0IR^2}{2(R^2 + z^2)^{3/2}}\)(1.2절 결과 1.2.2)을 두 개 더했습니다. 연한 점선은 각 고리, 파란 선은 합, 회색 세로선은 고리 위치입니다.

절차

  1. \(d = R\)에서 가운데 자기장과 \(|z| < 0.2R\)의 변화율을 읽는다.
  2. \(d\)를 0.6R, 1.6R로 바꿔 가운데가 볼록하거나 오목해지는지 본다.
  3. 반대 방향 전류를 켜고 가운데에서 \(B = 0\)인지, 기울기가 어떤지 본다.

기대 결과

  • \(d = R\): \(B(0) = \frac{8}{5\sqrt5}\frac{\mu_0I}{R} \approx 0.7155\frac{\mu_0I}R\), \(d^2B/dz^2 \approx 0\), \(|z| < 0.2R\)에서 변화가 약 0.18%로 매우 작다(4차 항 때문).
  • 간격이 좁으면 가운데가 볼록(봉우리 하나), 넓으면 오목(봉우리 둘)해진다.
  • 반대 전류: 가운데 \(B = 0\), 그 근처에서 \(B\)가 \(z\)에 거의 비례한다.

분석

  1. 대칭 때문에 가운데에서 홀수 차 미분이 모두 0인 까닭을 설명하고, \(d = R\)이면 왜 4차 항부터 남는지 말해 보세요.
  2. 지구 자기장(약 50 μT)을 상쇄하려면 \(R = 0.5\) m, 감은 수 100인 헬름홀츠 코일에 전류가 얼마나 필요한지 계산해 보세요.

더 해 보기

1.2절 발전 문제를 직접 미분해 풀고 \(d = R\)을 확인해 보세요. 반헬름홀츠 코일은 원자를 가두는 자기 광학 트랩에 쓰입니다.
