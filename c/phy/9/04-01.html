4.1.1앙페르 법칙의 문제

회전의 발산은 늘 0이므로 \(\nabla\cdot(\nabla\times\mathbf B) = \mu_0\nabla\cdot\mathbf J\)는 0이어야 합니다. 그런데 연속 방정식은 \(\nabla\cdot\mathbf J = -\partial\rho/\partial t\)로, 전하가 쌓이는 곳에서는 0이 아닙니다. 축전기를 충전할 때 도선을 감는 고리에 대해 도선을 자르는 면을 고르면 \(I\)가 감기고, 두 판 사이를 지나는 면을 고르면 전류가 0입니다. 같은 고리인데 답이 다릅니다.

4.1.2변위 전류

가우스 법칙 \(\rho = \epsilon_0\nabla\cdot\mathbf E\)를 연속 방정식에 넣으면 \(\nabla\cdot\left(\mathbf J + \epsilon_0\frac{\partial\mathbf E}{\partial t}\right) = 0\). 맥스웰은 앙페르 법칙의 \(\mathbf J\)를 이 조합으로 바꾸었습니다(1861~1865).

정리 4.1.1 (앙페르-맥스웰 법칙) \[\nabla\times\mathbf B = \mu_0\mathbf J + \mu_0\epsilon_0\frac{\partial\mathbf E}{\partial t}.\]

\(\mathbf J_d = \epsilon_0\,\partial\mathbf E/\partial t\)를 변위 전류라 부릅니다.

축전기 판 사이에서 \(E = Q/(\epsilon_0A)\)이므로 \(\epsilon_0A\,dE/dt = dQ/dt = I\). 두 면이 같은 답을 줍니다. 패러데이 법칙의 짝: 변하는 자기장이 전기장을 만들 듯, 변하는 전기장이 자기장을 만듭니다. 이 대칭이 전자기파를 낳습니다(5장).

맥스웰 방정식 (진공) \[\nabla\cdot\mathbf E = \frac\rho{\epsilon_0}, \quad \nabla\cdot\mathbf B = 0, \quad \nabla\times\mathbf E = -\frac{\partial\mathbf B}{\partial t}, \quad \nabla\times\mathbf B = \mu_0\mathbf J + \mu_0\epsilon_0\frac{\partial\mathbf E}{\partial t}.\]

로런츠 힘 \(\mathbf F = q(\mathbf E + \mathbf v\times\mathbf B)\)와 함께 고전 전자기학 전부입니다.

4.1.3물질 속

속박 전하 \(\rho_b = -\nabla\cdot\mathbf P\), 속박 전류 \(\nabla\times\mathbf M\)에 더해, 분극이 변하면 분극 전류 \(\mathbf J_p = \partial\mathbf P/\partial t\)가 흐릅니다. 이들을 모두 넣어 정리하면

\[\nabla\cdot\mathbf D = \rho_f, \quad \nabla\cdot\mathbf B = 0, \quad \nabla\times\mathbf E = -\frac{\partial\mathbf B}{\partial t}, \quad \nabla\times\mathbf H = \mathbf J_f + \frac{\partial\mathbf D}{\partial t}.\]
경계 조건 4.1.2 \[D^\perp_1 - D^\perp_2 = \sigma_f, \quad B^\perp_1 = B^\perp_2, \quad \mathbf E^\parallel_1 = \mathbf E^\parallel_2, \quad \mathbf H^\parallel_1 - \mathbf H^\parallel_2 = \mathbf K_f\times\hat{\mathbf n}.\]

5.3절의 반사와 투과는 이 네 조건에서 나옵니다.

예제 4.1.2

반지름 \(R\)인 원판 축전기가 전류 \(I\)로 충전됩니다. 판 사이 축에서 \(s < R\)인 곳의 자기장은?

풀이. 반지름 \(s\)인 고리에 감긴 변위 전류는 \(I\cdot s^2/R^2\). \(B\cdot2\pi s = \mu_0Is^2/R^2\), \(B = \frac{\mu_0Is}{2\pi R^2}\). 같은 전류가 흐르는 굵은 도선 안과 같은 꼴입니다.

요약
  1. 앙페르 법칙은 \(\nabla\cdot\mathbf J \ne 0\)일 때 모순. 변위 전류 \(\epsilon_0\partial_t\mathbf E\)로 해결.
  2. 맥스웰 방정식 네 개 + 로런츠 힘 = 고전 전자기학.
  3. 물질 속: \(\nabla\cdot\mathbf D = \rho_f\), \(\nabla\times\mathbf H = \mathbf J_f + \partial_t\mathbf D\). 경계 조건 네 개.

4.1.4연습문제

기본

  1. 구리(\(\sigma = 6\times10^7\) S/m)에서 1 kHz 교류의 변위 전류와 전도 전류의 비를 어림하세요(\(\epsilon \approx \epsilon_0\)).
    답

    \(\omega\epsilon_0/\sigma = 2\pi\times10^3\times8.85\times10^{-12}/(6\times10^7) \approx 10^{-15}\). 도체 안에서는 변위 전류를 무시해도 됩니다.

  2. 맥스웰 방정식에서 연속 방정식을 유도하세요.
    답

    넷째 식의 발산: \(0 = \mu_0\nabla\cdot\mathbf J + \mu_0\epsilon_0\partial_t\nabla\cdot\mathbf E = \mu_0(\nabla\cdot\mathbf J + \partial_t\rho)\).

발전

  1. 자기 홀극(전하 \(q_m\))이 있다면 맥스웰 방정식이 어떻게 바뀌어야 대칭이 되는지 쓰세요.
    답

    \(\nabla\cdot\mathbf B = \mu_0\rho_m\), \(\nabla\times\mathbf E = -\mu_0\mathbf J_m - \partial_t\mathbf B\). 자기 홀극은 아직 관측되지 않았습니다.

4.1.2

예제충전 중인 축전기 사이의 자기장

변위 전류 · Ampère-Maxwell 법칙 · 문제 해결 전략

다루는 성취기준 [물리9-04-01]

출발점

축전기를 충전하는 동안 판 사이에는 전류가 흐르지 않지만 전기장이 변합니다. Maxwell은 \(\varepsilon_0\partial\mathbf E/\partial t\)를 변위 전류로 더해 Ampère 법칙을 고쳤습니다.

문제 해결 전략 · 변위 전류로 자기장 구하기
  1. 판 사이 전기장 \(E = Q/\varepsilon_0A\)의 시간 변화를 구한다.
  2. 고리 안의 변위 전류 \(\varepsilon_0\frac{d\Phi_E}{dt}\)를 구한다.
  3. \(\oint\mathbf B\cdot d\mathbf l = \mu_0I_d\).
  4. 도선 둘레의 장과 비교한다.

반지름 \(R = 5\) cm 원판 축전기를 전류 \(I = 2\) A로 충전한다. 판 사이 축에서 \(s = 2\) cm, \(s = 10\) cm인 곳의 자기장은?

풀이

  1. 전체 변위 전류 = \(I\) = 2 A(판 사이 전체).
    \(\varepsilon_0A\,dE/dt = dQ/dt = I\).
  2. \(s < R\): 고리 안 변위 전류 \(I\frac{s^2}{R^2}\), \(B = \frac{\mu_0Is}{2\pi R^2} = \frac{4\pi\times10^{-7}\times2\times0.02}{2\pi\times0.0025} = 3.2\ \mu\)T.
    넓이 비.
  3. \(s > R\): \(B = \frac{\mu_0I}{2\pi s} = 4.0\ \mu\)T.
    도선 둘레와 같다.
  4. 판 사이에서도 도선에서와 같은 자기장이 이어진다.
    변위 전류가 전류의 연속성을 지킨다.

의미

변위 전류 항이 없으면 고리를 지나는 곡면을 판 사이로 잡느냐 도선으로 잡느냐에 따라 답이 달라지는 모순이 생깁니다. 이 항이 전자기파의 존재를 예측하게 했습니다.

검산

\(s = R\)에서 두 식이 같은 값 \(\frac{\mu_0I}{2\pi R} = 8.0\ \mu\)T를 줍니다. 경계에서 이어집니다.
