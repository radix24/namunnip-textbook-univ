2.4.1교환자

두 연산자의 교환자는 \([\hat A, \hat B] = \hat A\hat B - \hat B\hat A\)입니다. 임의의 함수 \(f\)에 작용시켜 보면 \([\hat x, \hat p]f = -i\hbar xf' + i\hbar(xf)' = i\hbar f\)이므로

\[[\hat x, \hat p] = i\hbar.\]

이것이 양자역학의 가장 기본적인 관계이며, 불확정성 원리(3.2절)의 뿌리입니다.

2.4.2올림·내림 연산자

\(\hat H = \frac1{2m}\left[\hat p^2 + (m\omega\hat x)^2\right]\)를 인수분해하듯 다음을 정의합니다.

\[\hat a_\pm = \frac1{\sqrt{2\hbar m\omega}}\left(\mp i\hat p + m\omega\hat x\right).\]

곱을 계산하면 교환자 때문에 덤이 붙습니다.

정리 2.4.1 \[[\hat a_-, \hat a_+] = 1, \qquad \hat H = \hbar\omega\left(\hat a_+\hat a_- + \tfrac12\right), \qquad [\hat H, \hat a_\pm] = \pm\hbar\omega\,\hat a_\pm.\]

마지막 식에서 \(\hat H\psi = E\psi\)이면 \(\hat H(\hat a_\pm\psi) = (E \pm \hbar\omega)(\hat a_\pm\psi)\). \(\hat a_+\)는 에너지를 \(\hbar\omega\) 올리고 \(\hat a_-\)는 내립니다.

2.4.3바닥 상태와 사다리

내림을 계속하면 에너지가 음이 되어 버리는데, \(\langle H\rangle \ge 0\)이므로 어딘가에서 멈춰야 합니다. 맨 아래 상태 \(\psi_0\)는 \(\hat a_-\psi_0 = 0\)입니다.

\[\frac1{\sqrt{2\hbar m\omega}}\left(\hbar\frac{d}{dx} + m\omega x\right)\psi_0 = 0 \;\Rightarrow\; \psi_0(x) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4}e^{-m\omega x^2/2\hbar}.\]

\(\hat H\psi_0 = \hbar\omega(0 + \frac12)\psi_0\)이므로 \(E_0 = \frac12\hbar\omega\). 위로 올리면

정리 2.4.2 \[E_n = \left(n + \tfrac12\right)\hbar\omega, \qquad \psi_n = \frac1{\sqrt{n!}}(\hat a_+)^n\psi_0, \qquad \hat a_+\psi_n = \sqrt{n + 1}\,\psi_{n+1}, \quad \hat a_-\psi_n = \sqrt n\,\psi_{n-1}.\]

\(\hat a_+\hat a_-\psi_n = n\psi_n\)이므로 \(\hat N = \hat a_+\hat a_-\)를 개수 연산자라 부릅니다. 미분방정식을 풀지 않고 준위를 모두 얻었습니다. 같은 방법이 각운동량(5.1절)과 장의 양자화(광자, 포논)에 그대로 쓰입니다.

예제 2.4.3

\(\psi_n\)에서 \(\langle x^2\rangle\)과 \(\langle V\rangle\)을 구하세요.

풀이. \(\hat x = \sqrt{\frac\hbar{2m\omega}}(\hat a_+ + \hat a_-)\). \(\hat x^2\)에서 \(\hat a_+^2\), \(\hat a_-^2\) 항은 직교성 때문에 기대값이 0이고 \(\hat a_+\hat a_- + \hat a_-\hat a_+ = 2\hat N + 1\)이 남습니다. \(\langle x^2\rangle = \frac\hbar{2m\omega}(2n + 1)\), \(\langle V\rangle = \frac12m\omega^2\langle x^2\rangle = \frac12(n + \frac12)\hbar\omega = \frac12E_n\). 운동 에너지와 퍼텐셜 에너지가 반씩입니다(비리얼 정리).

요약
  1. \([\hat x, \hat p] = i\hbar\), \([\hat a_-, \hat a_+] = 1\).
  2. \(\hat H = \hbar\omega(\hat N + \frac12)\), \(E_n = (n + \frac12)\hbar\omega\).
  3. \(\hat a_-\psi_0 = 0\)에서 가우스 바닥 상태, 들뜬 상태는 \(\hat a_+\)를 거듭 작용.

2.4.4연습문제

기본

  1. \(\psi_1 = \hat a_+\psi_0\)를 계산해 \(\psi_1 \propto x\,e^{-m\omega x^2/2\hbar}\)임을 보이세요.
    답

    \(\hat a_+ = \frac1{\sqrt{2\hbar m\omega}}\left(-\hbar\frac d{dx} + m\omega x\right)\). \(\psi_0' = -\frac{m\omega x}{\hbar}\psi_0\)이므로 \(\hat a_+\psi_0 = \frac{2m\omega x}{\sqrt{2\hbar m\omega}}\psi_0 = \sqrt{\frac{2m\omega}\hbar}\,x\psi_0\).

  2. 바닥 상태에서 \(\sigma_x\sigma_p\)를 구하세요.
    답

    \(\langle x^2\rangle = \hbar/2m\omega\), 같은 방법으로 \(\langle p^2\rangle = m\hbar\omega/2\). \(\sigma_x\sigma_p = \hbar/2\), 최솟값입니다.

발전

  1. \(\hat a_-\)의 고유상태 \(\hat a_-|\alpha\rangle = \alpha|\alpha\rangle\) (결맞음 상태)를 \(\psi_n\)으로 전개하세요.
    답

    \(c_n = e^{-|\alpha|^2/2}\alpha^n/\sqrt{n!}\). \(|c_n|^2\)은 평균 \(|\alpha|^2\)인 푸아송 분포이고, 이 상태의 \(\langle x\rangle\)은 고전 진동자처럼 진동하며 모양이 퍼지지 않습니다.

2.4.2

예제사다리 연산자로 위치 기대값 구하기

생성·소멸 연산자 · 영점 진동 · 문제 해결 전략

다루는 성취기준 [물리8-02-04]

출발점

조화 진동자에서 \(\hat x = \sqrt{\frac\hbar{2m\omega}}(\hat a + \hat a^\dagger)\), \(\hat a|n\rangle = \sqrt n|n - 1\rangle\), \(\hat a^\dagger|n\rangle = \sqrt{n + 1}|n + 1\rangle\)입니다. 적분 없이 기대값을 계산할 수 있습니다.

문제 해결 전략 · 사다리 연산자 계산
  1. 물리량을 \(\hat a\), \(\hat a^\dagger\)로 쓴다.
  2. 곱을 전개해 각 항이 \(|n\rangle\)을 어디로 옮기는지 본다.
  3. \(\langle n|m\rangle = \delta_{nm}\)으로 남는 항만 계산한다.
  4. 에너지나 고전 극한으로 점검한다.

\(|n\rangle\) 상태의 \(\langle x\rangle\)와 \(\langle x^2\rangle\)을 구하고, 바닥 상태의 퍼텐셜 에너지 기대값이 전체 에너지의 절반임을 보여라.

풀이

  1. \(\langle x\rangle \propto \langle n|(\hat a + \hat a^\dagger)|n\rangle = 0\).
    \(|n \pm 1\rangle\)은 \(|n\rangle\)과 직교.
  2. \(\hat x^2 \propto \hat a^2 + \hat a\hat a^\dagger + \hat a^\dagger\hat a + \hat a^{\dagger2}\). 대각 항만: \(\langle n|\hat a\hat a^\dagger + \hat a^\dagger\hat a|n\rangle = (n + 1) + n = 2n + 1\).
    \(\hat a^2\)은 두 칸 옮겨 0.
  3. \(\langle x^2\rangle = \frac\hbar{2m\omega}(2n + 1)\).
    결과.
  4. \(n = 0\): \(\langle V\rangle = \frac12m\omega^2\cdot\frac\hbar{2m\omega} = \frac14\hbar\omega = \frac12E_0\).
    비리얼 정리.

의미

바닥 상태에도 위치가 \(\sqrt{\hbar/2m\omega}\)만큼 퍼져 있습니다(영점 진동). 이 때문에 헬륨은 상압에서 절대 0도까지 고체가 되지 않습니다.

검산

\(\langle T\rangle = \langle V\rangle = \frac12(n + \frac12)\hbar\omega\), 합은 \(E_n\). 맞습니다.
