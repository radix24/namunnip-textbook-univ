4.1.1변수분리

3차원에서는 \(\hat{\mathbf p} = -i\hbar\nabla\)이므로 \(-\frac{\hbar^2}{2m}\nabla^2\psi + V\psi = E\psi\)입니다. 구면 좌표의 라플라시안

\[\nabla^2 = \frac1{r^2}\frac\partial{\partial r}\left(r^2\frac\partial{\partial r}\right) + \frac1{r^2}\left[\frac1{\sin\theta}\frac\partial{\partial\theta}\left(\sin\theta\frac\partial{\partial\theta}\right) + \frac1{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right]\]

에서 \(\psi = R(r)Y(\theta, \phi)\)로 놓고 \(-\frac{2mr^2}{\hbar^2}\frac1{RY}\)를 곱하면, \(r\)만의 부분과 각도만의 부분으로 나뉩니다. 분리 상수를 \(l(l + 1)\)로 적습니다.

정리 4.1.1 \[\frac1{\sin\theta}\frac\partial{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac1{\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2} = -l(l + 1)Y,\] \[\frac{d}{dr}\left(r^2\frac{dR}{dr}\right) - \frac{2mr^2}{\hbar^2}\left[V(r) - E\right]R = l(l + 1)R.\]

각 방정식에는 \(V\)가 없습니다. 중심력이면 퍼텐셜이 무엇이든 각 부분의 해는 같습니다.

4.1.2각 부분: 구면 조화 함수

다시 \(Y = \Theta(\theta)\Phi(\phi)\)로 나누면 \(\Phi = e^{im\phi}\)이고, 한 바퀴 돌아 같은 값이 되려면 \(m\)은 정수입니다. \(\Theta\)는 연관 르장드르 방정식을 따르고, \(\theta = 0, \pi\)에서 유한하려면 \(l = 0, 1, 2, \dots\), \(|m| \le l\)이어야 합니다.

결과 4.1.2 \[Y_l^m(\theta, \phi) \propto e^{im\phi}P_l^{|m|}(\cos\theta), \qquad \int Y_l^{m*}Y_{l'}^{m'}\,d\Omega = \delta_{ll'}\delta_{mm'}.\]

예: \(Y_0^0 = \frac1{\sqrt{4\pi}}\), \(Y_1^0 = \sqrt{\frac3{4\pi}}\cos\theta\), \(Y_1^{\pm1} = \mp\sqrt{\frac3{8\pi}}\sin\theta\,e^{\pm i\phi}\).

5장에서 보듯 \(l\)은 각운동량 크기 \(L^2 = l(l + 1)\hbar^2\), \(m\)은 \(z\)성분 \(L_z = m\hbar\)를 정합니다. 화학의 s, p, d, f 궤도가 \(l = 0, 1, 2, 3\)입니다.

4.1.3지름 부분과 유효 퍼텐셜

\(u(r) = rR(r)\)로 바꾸면 지름 방정식이 1차원 슈뢰딩거 방정식 꼴이 됩니다.

정리 4.1.2 \[-\frac{\hbar^2}{2m}\frac{d^2u}{dr^2} + \left[V(r) + \frac{\hbar^2}{2m}\frac{l(l + 1)}{r^2}\right]u = Eu, \qquad \int_0^\infty|u|^2dr = 1, \quad u(0) = 0.\]

괄호 안 둘째 항은 원심력 장벽입니다. 고전역학에서 각운동량이 보존될 때 생기는 \(L^2/2mr^2\)(물리1 중심력)과 같습니다. \(l\)이 클수록 입자를 원점에서 밀어냅니다. 축퇴: \(E\)는 \(m\)에 무관하므로 각 \(l\)마다 \(2l + 1\)개의 상태가 같은 에너지를 가집니다.

예제 4.1.3

반지름 \(a\)인 무한 구형 우물(\(r < a\)에서 \(V = 0\))의 \(l = 0\) 준위를 구하세요.

풀이. \(l = 0\)이면 \(u'' = -k^2u\), \(u(0) = 0\)에서 \(u = A\sin kr\), \(u(a) = 0\)에서 \(ka = n\pi\). \(E_{n0} = \frac{n^2\pi^2\hbar^2}{2ma^2}\)로 1차원 무한 우물(폭 \(a\))과 같습니다. \(l \ge 1\)이면 구면 베셀 함수의 영점으로 정해집니다.

요약
  1. 중심력이면 \(\psi = R(r)Y_l^m(\theta, \phi)\)로 분리된다.
  2. \(Y_l^m\): \(l = 0, 1, \dots\), \(m = -l, \dots, l\), 정규 직교.
  3. \(u = rR\)은 유효 퍼텐셜 \(V + \hbar^2l(l + 1)/2mr^2\)의 1차원 문제, \(u(0) = 0\).

4.1.4연습문제

기본

  1. \(Y_1^0\)이 각 방정식을 \(l = 1\)로 만족함을 확인하세요.
    답

    \(\frac1{\sin\theta}\frac{d}{d\theta}(\sin\theta\cdot(-\sin\theta)) = \frac{-2\sin\theta\cos\theta}{\sin\theta} = -2\cos\theta = -1(1 + 1)\cos\theta\).

  2. \(l = 2\)인 상태는 몇 개의 \(m\) 값을 가지나요?
    답

    \(2l + 1 = 5\)개 (\(m = -2, \dots, 2\)).

발전

  1. 원점 근처에서 \(V\)가 \(1/r^2\)보다 덜 발산하면 \(u \sim r^{l+1}\)임을 보이세요.
    답

    작은 \(r\)에서 원심력 항이 지배해 \(u'' \approx l(l + 1)u/r^2\). \(u = r^s\)를 넣으면 \(s(s - 1) = l(l + 1)\), \(s = l + 1\) 또는 \(-l\). \(u(0) = 0\)이려면 \(s = l + 1\). 그래서 \(l > 0\) 상태는 원점에서 0이고 s 상태만 핵 위치에 확률이 있습니다.
