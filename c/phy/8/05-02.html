5.2.1스피너와 파울리 행렬

전자, 양성자, 중성자는 고유 각운동량 \(s = \frac12\)을 가집니다. 상태 공간은 2차원이고 기저는 \(\chi_+ = \binom10\) (\(S_z = +\hbar/2\), 위), \(\chi_- = \binom01\) (아래)입니다. 일반 상태는 \(\chi = a\chi_+ + b\chi_-\), \(|a|^2 + |b|^2 = 1\).

정리 5.2.1 \[\hat{\mathbf S} = \frac\hbar2\boldsymbol\sigma, \qquad \sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix}, \quad \sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}, \quad \sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}.\]

\(\sigma_i^2 = 1\), \(\sigma_x\sigma_y = i\sigma_z\) (순환), \(S^2 = \frac34\hbar^2\).

5.1절의 \(\hat S_\pm\)를 \(s = \frac12\)에 적용하면 바로 이 행렬이 나옵니다. 모든 성분의 고유값은 \(\pm\hbar/2\)입니다.

5.2.2임의 방향의 스핀

단위 벡터 \(\hat n = (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta)\) 방향 성분 \(\hat S_n = \frac\hbar2\hat n\cdot\boldsymbol\sigma\)의 \(+\hbar/2\) 고유 상태는

\[\chi_+^{(n)} = \begin{pmatrix}\cos(\theta/2)\\ e^{i\phi}\sin(\theta/2)\end{pmatrix}.\]
결과 5.2.2

\(\hat n\) 방향 위로 준비된 스핀을 \(\hat n'\) 방향으로 재면 위가 나올 확률은 \(\cos^2(\Theta/2)\)입니다. \(\Theta\)는 두 방향 사이 각입니다.

\(\Theta = 90°\)이면 반반, \(180°\)이면 0입니다. 반각 \(\Theta/2\)가 나오는 것이 스핀 1/2의 특징이며, 스피너를 \(2\pi\) 돌리면 부호가 바뀝니다(중성자 간섭 실험으로 확인됨).

5.2.3슈테른-게를라흐 실험

자기 모멘트 \(\boldsymbol\mu = \gamma\mathbf S\)는 불균일 자기장에서 힘 \(F_z = \mu_z\,\partial B_z/\partial z\)를 받습니다. 고전적으로 모멘트 방향이 아무렇게나면 화면에 연속 띠가 생겨야 하지만, 1922년 은 원자 빔은 두 점으로 갈라졌습니다. \(S_z\)가 \(\pm\hbar/2\) 두 값만 갖는다는 증거입니다(은 원자의 각운동량은 바깥 전자 하나의 스핀).

  • z → z: 위만 골라 다시 z로 재면 100% 위. 측정은 반복 가능하다.
  • z → x: 위만 골라 x로 재면 반반. \(\chi_+ = \frac1{\sqrt2}(\chi_+^{(x)} + \chi_-^{(x)})\).
  • z → x → z: x 위만 골라 다시 z로 재면 다시 반반. x 측정이 처음 z 정보를 지웠다. \(S_x\)와 \(S_z\)가 교환하지 않기 때문이다.

아래 실습 카드에서 두 장치의 각도를 바꾸며 이 확률을 시뮬레이션할 수 있습니다.

예제 5.2.2

\(\chi = \frac1{\sqrt5}\binom{1}{2}\)에서 \(S_z\)와 \(S_x\)를 잴 때 각 결과의 확률을 구하세요.

풀이. \(S_z\): 위 \(1/5\), 아래 \(4/5\). \(S_x\): \(\chi_\pm^{(x)} = \frac1{\sqrt2}\binom1{\pm1}\)이므로 \(|\langle\chi_+^{(x)}|\chi\rangle|^2 = \frac{(1 + 2)^2}{10} = 0.9\), 아래 0.1. \(\langle S_x\rangle = 0.8\cdot\frac\hbar2 = 0.4\hbar\).

요약
  1. 스핀 1/2: 2성분 스피너, \(\hat{\mathbf S} = \frac\hbar2\boldsymbol\sigma\).
  2. \(\hat n\) 위 상태를 \(\hat n'\)로 재면 위 확률 \(\cos^2(\Theta/2)\).
  3. 슈테른-게를라흐: 두 갈래, 교환하지 않는 성분의 측정은 서로의 정보를 지운다.

5.2.4연습문제

기본

  1. \(\sigma_y\)의 고유벡터를 구하세요.
    답

    고유값 \(\pm1\), 고유벡터 \(\frac1{\sqrt2}\binom1{\pm i}\). 결과 5.2.2의 식에서 \(\theta = 90°\), \(\phi = 90°\)인 경우입니다.

  2. z 위 → x 위만 통과 → z를 잴 때 처음 빔 중 z 아래로 나오는 비율은?
    답

    \(\frac12\times\frac12 = \frac14\). x 필터를 빼면 0인데, 필터를 넣으면 오히려 아래가 생깁니다.

발전

  1. 자기장 \(B\hat z\) 속 스핀의 해밀토니언 \(\hat H = -\gamma B\hat S_z\)에서 \(\langle\mathbf S\rangle\)이 각진동수 \(\gamma B\)로 \(z\)축 둘레를 돎(라머 세차)을 보이세요.
    답

    \(\chi(t) = \binom{\cos(\theta/2)e^{i\gamma Bt/2}}{\sin(\theta/2)e^{-i\gamma Bt/2}}\)이므로 \(\langle S_x\rangle = \frac\hbar2\sin\theta\cos\gamma Bt\), \(\langle S_y\rangle = -\frac\hbar2\sin\theta\sin\gamma Bt\), \(\langle S_z\rangle\) 일정. MRI의 원리입니다.

5.2.2

실습연속 슈테른-게를라흐 실험

실습 · 스핀 측정

다루는 성취기준 [물리8-05-02] [물리8-03-02]

목표

스핀 1/2 원자를 슈테른-게를라흐 장치에 차례로 통과시켜, 측정 확률 \(\cos^2(\Theta/2)\)와 측정이 상태를 바꾸는 효과를 시뮬레이션으로 확인합니다. 성취기준 [물리8-05-02], [물리8-03-02].

준비

스핀 방향이 고르지 않은 원자 1000개가 첫 장치(z)를 지나며 위 성분만 남습니다. 가운데 장치(선택)는 각 \(a\) 방향의 위 성분만 통과시키고, 마지막 장치는 각 \(b\) 방향으로 잽니다. 각은 \(z\)축에서 \(xz\) 평면으로 잰 방향입니다. 선의 굵기는 빔 세기에 비례합니다.

절차

  1. 가운데 장치 없이 \(b = 0°\), 90°, 180°에서 마지막 위·아래 수를 본다.
  2. 가운데 장치를 켜고 \(a = 90°\)(x 방향), \(b = 0°\)로 둔다. z 위만 남겼는데 마지막에 z 아래가 나오는지 본다.
  3. \(b = 180°\)로 바꿔 장치를 켤 때와 끌 때를 비교한다.
  4. "새 원자"로 여러 번 돌려 시뮬레이션 값이 이론값 둘레에서 얼마나 흔들리는지 본다.

기대 결과

  • 장치 없이: \(b = 0°\)이면 모두 위, 90°이면 반반, 180°이면 모두 아래.
  • \(a = 90°\), \(b = 0°\): 마지막 장치에 들어온 원자의 반이 아래. 처음 1000개 중 약 125개가 위, 125개가 아래.
  • \(b = 180°\)에서 "위"(곧 z 아래)는 가운데 장치가 없으면 0이지만, 켜면 약 125개가 생긴다. 측정이 처음 정보를 지웠다.
  • 흔들림은 \(\sqrt{Np(1 - p)}\), 여기서는 약 10개다.

분석

  1. \(b = 360°\)는 \(b = 0°\)와 같은 방향인데 결과도 같은지 확인하고, 스피너가 \(2\pi\) 회전에서 부호가 바뀐다는 사실과 모순되지 않는 까닭을 말해 보세요.
  2. 가운데 장치를 여러 개(각을 조금씩 바꿔) 넣으면 z 위를 z 아래로 거의 손실 없이 돌릴 수 있습니다. 장치 \(N\)개를 \(180°/N\)씩 돌려 놓았을 때 통과 확률을 계산해 보세요.

더 해 보기

분석 2의 결과 \(\cos^{2N}(90°/N)\)는 \(N \to \infty\)에서 1로 갑니다. 편광판 여러 장으로 빛의 편광을 돌리는 실험(공통4)과 같은 구조인지 비교해 보세요.
