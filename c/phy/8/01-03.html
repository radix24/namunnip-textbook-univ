1.3.1기대값

같은 상태 \(\Psi\)로 준비한 계를 아주 많이 만들어 위치를 재면, 측정값의 평균은

\[\langle x\rangle = \int x\,|\Psi|^2dx.\]

한 입자를 여러 번 잰 평균이 아닙니다. 첫 측정이 상태를 바꾸기 때문입니다(3.2절). 퍼짐은 표준편차 \(\sigma_x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}\)로 잽니다.

1.3.2운동량 연산자

\(\langle p\rangle = m\,d\langle x\rangle/dt\)로 정의하고 계산해 봅니다. 1.2절의 식 \(\partial_t|\Psi|^2 = -\partial_xj\)를 쓰고 부분적분하면

\[\frac{d\langle x\rangle}{dt} = -\int x\frac{\partial j}{\partial x}dx = \int j\,dx = \frac{\hbar}{m}\int\mathrm{Im}(\Psi^*\Psi')dx.\]

한 번 더 부분적분하면 \(\int\Psi\Psi^{*\prime}dx = -\int\Psi^*\Psi'dx\)라 \(\int\Psi^*\Psi'dx\)는 순허수입니다. 따라서

정리 1.3.1 \[\langle p\rangle = \int\Psi^*\left(-i\hbar\frac{\partial}{\partial x}\right)\Psi\,dx, \qquad \langle Q(x, p)\rangle = \int\Psi^*\,\hat Q\!\left(x, -i\hbar\tfrac{\partial}{\partial x}\right)\Psi\,dx.\]

물리량은 연산자로 나타내고, 기대값은 \(\Psi^*\)와 \(\hat Q\Psi\)를 곱해 적분합니다. 예를 들어 운동 에너지는 \(\hat T = -\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2}\), 해밀토니언은 \(\hat H = \hat T + V(x)\)이며, 슈뢰딩거 방정식은 \(i\hbar\,\partial_t\Psi = \hat H\Psi\)로 쓸 수 있습니다.

1.3.3에렌페스트 정리

정리 1.3.2 (에렌페스트) \[\frac{d\langle x\rangle}{dt} = \frac{\langle p\rangle}{m}, \qquad \frac{d\langle p\rangle}{dt} = \left\langle-\frac{\partial V}{\partial x}\right\rangle.\]

증명(둘째 식). \(\frac{d}{dt}\int\Psi^*(-i\hbar\Psi')dx\)에 \(\partial_t\Psi\)와 \(\partial_t\Psi^*\)를 넣으면 운동 에너지 항은 두 번의 부분적분으로 사라지고, 퍼텐셜 항에서 \(-\int\Psi^*\left[(V\Psi)' - V\Psi'\right]dx = -\int|\Psi|^2V'dx\)가 남습니다. \(\square\)

기대값이 뉴턴 법칙을 따르는 것처럼 보입니다. 다만 오른쪽은 \(\langle V'(x)\rangle\)이지 \(V'(\langle x\rangle)\)가 아닙니다. 둘이 같아지는 경우는 \(V\)가 \(x\)의 2차 이하일 때(자유 입자, 균일한 힘, 조화 진동자)입니다. 파동 묶음이 퍼텐셜이 변하는 거리보다 좁으면 근사적으로 같아져 고전역학이 나옵니다.

예제 1.3.3

\(\Psi(x, 0) = \sqrt a\,e^{-a|x|}\)에서 \(\langle x\rangle\), \(\langle x^2\rangle\), \(\langle p\rangle\)을 구하세요.

풀이. \(|\Psi|^2\)가 짝함수라 \(\langle x\rangle = 0\). \(\langle x^2\rangle = 2a\int_0^\infty x^2e^{-2ax}dx = 2a\cdot\frac{2}{(2a)^3} = \frac1{2a^2}\). \(\Psi\)가 실수이므로 \(\langle p\rangle\)는 순허수 적분에 \(-i\hbar\)를 곱한 실수여야 하는데 \(\int\Psi\Psi'dx = [\Psi^2/2] = 0\)이라 \(\langle p\rangle = 0\). 실수 파동함수는 늘 \(\langle p\rangle = 0\)입니다.

요약
  1. \(\langle Q\rangle = \int\Psi^*\hat Q\Psi\,dx\), \(\hat p = -i\hbar\,\partial_x\).
  2. 에렌페스트: \(d\langle x\rangle/dt = \langle p\rangle/m\), \(d\langle p\rangle/dt = \langle-V'\rangle\).
  3. 퍼텐셜이 2차 이하이거나 묶음이 좁으면 기대값은 고전 궤도를 따른다.

1.3.4연습문제

기본

  1. \(\Psi(x,0) = \phi(x)e^{ik_0x}\) (\(\phi\)는 실수, 규격화됨)이면 \(\langle p\rangle\)은?
    답

    \(\hbar k_0\). \(\phi\)에서 오는 부분은 0이고, 위상 \(e^{ik_0x}\)가 \(\hbar k_0\)를 줍니다.

  2. 정상 상태 \(\Psi = \psi(x)e^{-iEt/\hbar}\)에서 \(\langle x\rangle\)가 시간에 따라 변하지 않음을 보이세요.
    답

    \(|\Psi|^2 = |\psi|^2\)에 시간이 없으므로 모든 \(\langle Q(x)\rangle\)가 상수. 에렌페스트에 따라 \(\langle p\rangle = 0\)이기도 합니다.

발전

  1. \(V = \lambda x^4\)에서 \(\langle V'\rangle\)과 \(V'(\langle x\rangle)\)의 차이를 \(\langle x\rangle\)과 \(\sigma_x\)로 나타내세요(묶음이 대칭이라 \(\langle(x - \langle x\rangle)^3\rangle = 0\)이라 가정).
    답

    \(\langle4\lambda x^3\rangle - 4\lambda\langle x\rangle^3 = 12\lambda\langle x\rangle\sigma_x^2\). 묶음이 퍼질수록 고전 궤도에서 벗어납니다.

1.3.2

예제상자 속 입자의 기대값과 Ehrenfest 정리

기대값 · 운동량 연산자 · 문제 해결 전략

다루는 성취기준 [물리8-01-03]

출발점

물리량의 기대값은 \(\langle Q\rangle = \int\psi^*\hat Q\psi\,dx\)이고, Ehrenfest 정리 \(\frac{d\langle p\rangle}{dt} = \langle -V'\rangle\)는 기대값이 고전 운동 방정식을 따른다는 것을 말합니다.

문제 해결 전략 · 기대값 계산
  1. 파동함수를 규격화한다.
  2. 연산자(\(x\), \(-i\hbar\partial_x\), 해밀토니안)를 적용하고 적분한다.
  3. 대칭으로 0이 되는 항을 먼저 찾는다.
  4. 불확정성 \(\Delta x\Delta p \ge \hbar/2\)를 확인한다.

폭 \(L\) 무한 우물 바닥 상태 \(\psi = \sqrt{2/L}\sin(\pi x/L)\)에서 \(\langle x\rangle\), \(\langle p\rangle\), \(\langle p^2\rangle\), \(\Delta x\Delta p\)를 구하여라. (\(\langle x^2\rangle = L^2\left(\frac13 - \frac1{2\pi^2}\right)\))

풀이

  1. \(\langle x\rangle = L/2\).
    가운데에 대칭.
  2. \(\langle p\rangle = 0\): 실수 정상 상태라 왼쪽과 오른쪽이 같다.
    \(\int\psi\psi'dx = \frac12[\psi^2] = 0\).
  3. \(\langle p^2\rangle = \hbar^2\int|\psi'|^2 = \frac{\pi^2\hbar^2}{L^2}\) \(= 2mE_1\).
    운동 에너지에서.
  4. \(\Delta x = L\sqrt{\frac1{12} - \frac1{2\pi^2}} = 0.181L\), \(\Delta p = \pi\hbar/L\), 곱 \(0.568\hbar > 0.5\hbar\).
    불확정성 원리 만족.

의미

정지 상태에서 운동량 평균은 0이지만 \(\langle p^2\rangle\)은 0이 아닙니다. 입자는 좌우로 움직이고 있지만 평균이 지워진 것입니다. 바닥 상태 에너지가 0이 아닌 까닭도 이 운동 때문입니다.

검산

\(\langle p^2\rangle/2m = \frac{\pi^2\hbar^2}{2mL^2} = E_1\). 바닥 상태 에너지와 같습니다.
