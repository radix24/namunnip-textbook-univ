2.2.1경계 조건

시간 무관 방정식을 \(\psi'' = \frac{2m}{\hbar^2}(V - E)\psi\)로 쓰면, \(V\)가 유한한 점프만 하는 곳에서 \(\psi''\)도 유한한 점프만 하므로 \(\psi\)와 \(\psi'\)는 연속입니다. \(V\)가 무한대로 뛰면(무한 우물의 벽) \(\psi\)만 연속이고, 델타 함수가 있으면 \(\psi'\)가 정해진 만큼 끊깁니다(2.2.4).

2.2.2유한 우물

\(|x| < a\)에서 \(V = -V_0\), 바깥에서 \(V = 0\)인 우물에서 \(-V_0 < E < 0\)인 속박 상태를 찾습니다.

  • 안: \(\psi'' = -l^2\psi\), \(l = \sqrt{2m(E + V_0)}/\hbar\). 해는 \(\cos lx\)(짝) 또는 \(\sin lx\)(홀).
  • 밖: \(\psi'' = \kappa^2\psi\), \(\kappa = \sqrt{-2mE}/\hbar\). 규격화되려면 \(e^{-\kappa|x|}\).

\(x = a\)에서 \(\psi'/\psi\)가 연속이어야 합니다. 짝 상태는 \(\kappa = l\tan la\), 홀 상태는 \(\kappa = -l\cot la\). 차원 없는 변수 \(z = la\), \(z_0 = \frac a\hbar\sqrt{2mV_0}\)를 쓰면 \(z^2 + (\kappa a)^2 = z_0^2\)이므로

정리 2.2.1 \[\text{짝: } \tan z = \sqrt{\frac{z_0^2}{z^2} - 1}, \qquad \text{홀: } -\cot z = \sqrt{\frac{z_0^2}{z^2} - 1}, \qquad E = -V_0 + \frac{\hbar^2z^2}{2ma^2}.\]

오른쪽 곡선은 \(z = z_0\)에서 0이 되는 감소 함수이고, 왼쪽의 \(\tan z\)와 \(-\cot z\)는 번갈아 가지를 칩니다. 교점 하나가 속박 상태 하나입니다.

  • 짝 상태는 \(z_0\)가 아무리 작아도 하나는 있다. 1차원 대칭 우물에는 늘 속박 상태가 있다.
  • \(z_0\)가 \(\pi/2\)를 넘을 때마다 상태가 하나씩 는다: 속박 상태 수 \(N = \lfloor 2z_0/\pi\rfloor + 1\).
  • \(z_0 \to \infty\)이면 교점이 \(z = n\pi/2\)에 다가가 폭 \(2a\) 무한 우물의 준위가 된다.
  • 파동함수는 벽 바깥으로 \(1/\kappa\) 정도 스며든다. 그래서 같은 폭의 무한 우물보다 에너지가 조금 낮다.
예제 2.2.2

깊이 10 eV, 폭 \(2a = 0.5\) nm인 우물에 전자의 속박 상태는 몇 개인가요?

풀이. \(z_0 = \frac{a\sqrt{2m_ec^2V_0}}{\hbar c} = \frac{0.25\sqrt{2(511000)(10)}}{197.3} \approx 4.05\). \(2z_0/\pi \approx 2.58\)이므로 \(N = 3\)(짝 2개, 홀 1개). 아래 실습 카드에서 그래프 풀이와 파동함수를 볼 수 있습니다.

2.2.3대칭과 마디

바닥 상태는 짝이고 마디가 없습니다. 그 위로 홀, 짝이 번갈아 오며 \(n\)번째 상태는 마디가 \(n - 1\)개입니다. 1차원 속박 상태는 겹침(축퇴)이 없습니다.

요약
  1. 유한한 \(V\)에서는 \(\psi\), \(\psi'\) 모두 연속.
  2. 짝: \(\tan z = \sqrt{z_0^2/z^2 - 1}\), 홀: \(-\cot z = \sqrt{z_0^2/z^2 - 1}\), \(z_0 = a\sqrt{2mV_0}/\hbar\).
  3. 속박 상태 수 \(\lfloor2z_0/\pi\rfloor + 1\). 얕은 우물에도 하나는 있다.

2.2.4연습문제

기본

  1. 속박 상태가 정확히 하나이려면 \(V_0a^2\)가 얼마보다 작아야 하나요?
    답

    \(z_0 < \pi/2\), 곧 \(V_0a^2 < \frac{\pi^2\hbar^2}{8m}\).

  2. 우물 깊이를 4배로 하면 속박 상태 수는 대략 몇 배가 되나요?
    답

    \(z_0 \propto \sqrt{V_0}\)이므로 약 2배.

발전

  1. \(z_0 \gg 1\)일 때 바닥 상태가 \(z \approx \frac\pi2\frac{z_0}{z_0 + 1}\)임을 보이세요.
    답

    \(z = \pi/2 - \epsilon\)이라 하면 \(\tan z \approx 1/\epsilon\), 오른쪽 \(\approx z_0/z \approx 2z_0/\pi\). \(\epsilon \approx \pi/(2z_0)\)이고 \(z \approx \frac\pi2(1 - 1/z_0) \approx \frac\pi2\frac{z_0}{z_0 + 1}\). 유효 폭이 \(2a(1 + 1/z_0)\)로 늘어난 무한 우물과 같습니다.

2.2.5\(\psi'\)의 끊김

\(V(x) = -\alpha\delta(x)\) (\(\alpha > 0\))는 아주 좁고 깊은 우물의 극한입니다. 시간 무관 방정식을 \(-\epsilon\)부터 \(\epsilon\)까지 적분하면

\[-\frac{\hbar^2}{2m}\left[\psi'(\epsilon) - \psi'(-\epsilon)\right] - \alpha\psi(0) = E\int_{-\epsilon}^{\epsilon}\psi\,dx \to 0.\]
정리 2.2.3 \[\Delta\psi'\big|_{x=0} = -\frac{2m\alpha}{\hbar^2}\psi(0), \qquad \psi\text{는 연속.}\]

2.2.6속박 상태

\(x \ne 0\)에서는 자유 입자이므로 \(E < 0\)이면 \(\psi = Be^{-\kappa|x|}\) (\(\kappa = \sqrt{-2mE}/\hbar\)). 연속 조건은 저절로 맞고, 기울기는 왼쪽의 \(B\kappa\)에서 오른쪽의 \(-B\kappa\)로 \(-2B\kappa\)만큼 끊깁니다. 정리 2.2.3과 맞추면 \(\kappa = m\alpha/\hbar^2\).

결과 2.2.4 \[\psi(x) = \sqrt\kappa\,e^{-\kappa|x|}, \qquad \kappa = \frac{m\alpha}{\hbar^2}, \qquad E = -\frac{m\alpha^2}{2\hbar^2}.\]

속박 상태는 \(\alpha\)의 크기와 상관없이 정확히 하나입니다.

유한 우물에서 폭 \(2a \to 0\), 깊이 \(V_0 \to \infty\)이며 \(2aV_0 = \alpha\)로 유지하면 \(z_0^2 = 2ma^2V_0/\hbar^2 \to 0\)이라 짝 상태 하나만 남고, 그 에너지가 위 값으로 갑니다.

2.2.7산란 상태 미리 보기

\(E > 0\)이면 왼쪽에서 들어오는 파동 \(Ae^{ikx}\)이 일부 반사되고 일부 투과합니다. 같은 끊김 조건으로 풀면

\[T = \frac1{1 + \beta^2}, \qquad R = \frac{\beta^2}{1 + \beta^2}, \qquad \beta = \frac{m\alpha}{\hbar^2k}.\]

\(\alpha\)의 부호가 바뀌어도(델타 장벽) \(T\)는 같습니다. 에너지가 높을수록 \(\beta\)가 작아 잘 투과합니다. 반사율과 투과율의 정의는 다음 절에서 다룹니다.

예제 2.2.4

델타 우물의 바닥 상태에서 \(|x| > 1/\kappa\)에서 입자를 찾을 확률은?

풀이. \(2\kappa\int_{1/\kappa}^\infty e^{-2\kappa x}dx = e^{-2} \approx 0.135\).

요약
  1. 델타 퍼텐셜에서 \(\psi'\)는 \(-\frac{2m\alpha}{\hbar^2}\psi(0)\)만큼 끊긴다.
  2. 델타 우물의 속박 상태는 하나: \(E = -m\alpha^2/2\hbar^2\).
  3. 산란: \(T = 1/(1 + \beta^2)\), \(\beta = m\alpha/\hbar^2k\).

2.2.8연습문제

기본

  1. 델타 우물 바닥 상태의 \(\sigma_x\)를 구하세요(1.3절 예제 이용).
    답

    \(\langle x\rangle = 0\), \(\langle x^2\rangle = 1/(2\kappa^2)\)이므로 \(\sigma_x = 1/(\sqrt2\kappa) = \hbar^2/(\sqrt2m\alpha)\).

  2. 델타 산란에서 \(T = 1/2\)이 되는 에너지는?
    답

    \(\beta = 1\), \(k = m\alpha/\hbar^2\), \(E = \hbar^2k^2/2m = m\alpha^2/(2\hbar^2)\). 속박 에너지의 크기와 같습니다.

발전

  1. \(V = -\alpha[\delta(x + a) + \delta(x - a)]\)의 짝 속박 상태 조건을 구하세요.
    답

    \(|x| < a\)에서 \(\cosh\kappa x\), 밖에서 \(e^{-\kappa|x|}\). \(x = a\)의 끊김 조건에서 \(\kappa(1 + \tanh\kappa a) = 2m\alpha/\hbar^2\). 이원자 분자 모형의 결합 궤도에 해당합니다.

2.2.3

실습유한 우물의 그래프 풀이

실습 · 속박 상태

다루는 성취기준 [물리8-02-02]

목표

유한 우물의 속박 상태 조건을 그래프로 풀고, 우물의 세기 \(z_0 = a\sqrt{2mV_0}/\hbar\)에 따라 속박 상태의 수와 파동함수가 어떻게 바뀌는지 봅니다. 2장 자기 점검 과제입니다. 성취기준 [물리8-02-02].

준비

위 그래프에서 파란 가지는 \(\tan z\)(짝 상태), 주황 가지는 \(-\cot z\)(홀 상태), 검은 곡선은 \(\sqrt{z_0^2/z^2 - 1}\)입니다. 아래는 우물(폭 \(2a\))과 준위, 고른 상태의 파동함수입니다. \(z_0\)는 깊이의 제곱근과 폭에 비례합니다.

절차

  1. 2.2절 예제의 값 \(z_0 = 4.05\)에서 상태 수와 각 에너지를 읽는다.
  2. \(z_0\)를 0.3까지 줄여도 상태가 하나 남는지 확인한다.
  3. \(z_0\)를 천천히 키우며 \(\pi/2\), \(\pi\), \(3\pi/2\)를 지날 때 상태가 하나씩 생기는지 본다.
  4. 상태 번호를 바꾸며 마디 수와 벽 밖 확률을 비교한다.

기대 결과

  • \(z_0 = 4.05\): 상태 3개(짝, 홀, 짝).
  • 아무리 얕아도 짝 상태 하나는 있다. 얕을수록 파동함수가 벽 밖으로 넓게 퍼진다.
  • \(z_0\)가 \(\pi/2\)의 정수배를 넘을 때마다 \(E \approx 0\) 근처에 새 상태가 나타난다.
  • 위 상태일수록 마디가 많고 벽 밖 확률이 크다. 맨 위 상태는 \(E\)가 0에 가까워 많이 스며든다.

분석

  1. \(z_0\)를 크게 할수록 낮은 준위의 \(z\)가 \(\pi/2, \pi, \dots\)에 다가가는 까닭을 무한 우물과 비교해 설명해 보세요.
  2. 3차원 구형 우물에서는 얕으면 속박 상태가 없을 수 있습니다. \(l = 0\)의 \(u(r)\)가 1차원 홀 상태와 같은 조건을 따른다는 것으로 설명해 보세요.

더 해 보기

중수소핵(양성자와 중성자)은 속박 상태가 하나뿐입니다. 위 분석 2를 이용해 핵력 우물의 \(z_0\)가 어느 범위에 있어야 하는지 어림해 보세요.
