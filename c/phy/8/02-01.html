2.1.1변수분리

\(V\)가 시간에 무관하면 \(\Psi(x,t) = \psi(x)\varphi(t)\)로 놓아 봅니다. 방정식에 넣고 \(\psi\varphi\)로 나누면

\[i\hbar\frac1\varphi\frac{d\varphi}{dt} = -\frac{\hbar^2}{2m}\frac1\psi\frac{d^2\psi}{dx^2} + V.\]

왼쪽은 \(t\)만, 오른쪽은 \(x\)만의 함수이므로 둘 다 같은 상수여야 합니다. 이 상수를 \(E\)라 부르면

정리 2.1.1 \[\varphi(t) = e^{-iEt/\hbar}, \qquad -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V\psi = E\psi \quad(\hat H\psi = E\psi).\]

둘째 식이 시간에 무관한 슈뢰딩거 방정식으로, 해밀토니언의 고유값 문제입니다.

2.1.2정상 상태의 성질

  • 정상: \(|\Psi|^2 = |\psi|^2\)에 시간이 없다. 모든 기대값이 상수다.
  • 에너지가 확정: \(\langle H\rangle = E\), \(\langle H^2\rangle = E^2\)이므로 \(\sigma_H = 0\). 잴 때마다 \(E\)가 나온다.
  • 일반해의 재료: 방정식이 선형이라 정상 상태들의 중첩도 해다.
정리 2.1.2 (일반해) \[\Psi(x,t) = \sum_nc_n\psi_n(x)e^{-iE_nt/\hbar}, \qquad c_n = \int\psi_n^*(x)\Psi(x,0)\,dx, \qquad \sum_n|c_n|^2 = 1.\]

에너지를 재면 \(E_n\)이 확률 \(|c_n|^2\)로 나오고, \(\langle H\rangle = \sum|c_n|^2E_n\)입니다.

\(c_n\)을 이렇게 구할 수 있는 것은 \(\psi_n\)이 직교 규격화되어 있고(\(\int\psi_m^*\psi_n = \delta_{mn}\)) 완비이기 때문입니다(3.1절). 시간이 지나도 \(|c_n|\)는 변하지 않으므로 에너지 분포는 보존됩니다.

\(\psi\)에 대해 알아 둘 몇 가지: \(E\)는 실수로 잡을 수 있고(규격화 조건), \(\psi\)도 실수로 고를 수 있으며, \(V\)가 짝함수이면 \(\psi\)를 짝 또는 홀로 고를 수 있습니다. 규격화 가능하려면 \(E\)가 \(V\)의 최솟값보다 커야 합니다.

예제 2.1.3

폭 \(L\) 무한 우물에서 \(\Psi(x,0) = \frac1{\sqrt2}(\psi_1 + \psi_2)\)입니다. \(\langle x\rangle(t)\)를 구하세요.

풀이. \(|\Psi|^2 = \frac12\left[\psi_1^2 + \psi_2^2 + 2\psi_1\psi_2\cos(\omega t)\right]\), \(\omega = (E_2 - E_1)/\hbar = 3\pi^2\hbar/(2mL^2)\). \(\int x\psi_n^2dx = L/2\), \(\int x\psi_1\psi_2dx = -\frac{16L}{9\pi^2}\)이므로

\[\langle x\rangle = \frac L2 - \frac{16L}{9\pi^2}\cos\omega t \approx \frac L2 - 0.180L\cos\omega t.\]

확률 덩어리가 우물 안에서 진동수 \((E_2 - E_1)/h\)로 오갑니다. 중첩 상태만 시간에 따라 움직입니다. 아래 실습 카드에서 이 진동과 에렌페스트 정리를 확인할 수 있습니다.

요약
  1. 변수분리: \(\Psi = \psi(x)e^{-iEt/\hbar}\), \(\hat H\psi = E\psi\).
  2. 정상 상태는 확률 분포가 변하지 않고 에너지가 확정된다.
  3. 일반해 \(\sum c_n\psi_ne^{-iE_nt/\hbar}\), \(|c_n|^2\)은 \(E_n\)을 얻을 확률.

2.1.3연습문제

기본

  1. 예제 2.1.3에서 \(\langle H\rangle\)과 에너지를 쟀을 때 나올 수 있는 값은?
    답

    \(E_1\) 또는 \(E_2 = 4E_1\)이 각각 확률 1/2. \(\langle H\rangle = 2.5E_1\). 한 번의 측정에서 2.5E₁이 나오지는 않습니다.

  2. \(\Psi(x,0) = A x(L - x)\)를 무한 우물의 \(\psi_n\)으로 전개할 때 \(c_n\)을 구하세요.
    답

    \(A = \sqrt{30/L^5}\)로 계산하면 \(c_n = \frac{8\sqrt{15}}{(n\pi)^3}\) (홀수 \(n\)), 짝수 \(n\)은 0. \(|c_1|^2 \approx 0.9986\)이라 거의 바닥 상태입니다.

발전

  1. 무한 우물의 어떤 \(\Psi(x,0)\)도 시간 \(T = 4mL^2/(\pi\hbar)\) 뒤에 처음 상태로 돌아옴을 보이세요.
    답

    \(E_n = n^2E_1\)이고 \(E_1T/\hbar = 2\pi\)이므로 모든 \(e^{-iE_nT/\hbar} = e^{-2\pi in^2} = 1\). 양자 되돌이(revival)입니다.

2.1.2

실습정상 상태의 중첩은 움직인다

실습 · 시간 변화

다루는 성취기준 [물리8-02-01] [물리8-01-03]

목표

무한 우물의 두 정상 상태를 겹친 상태가 시간에 따라 어떻게 변하는지 보고, \(\langle x\rangle\)의 진동 주기가 두 에너지의 차로 정해짐을 확인합니다. 에렌페스트 정리 \(\langle p\rangle = m\,d\langle x\rangle/dt\)도 함께 봅니다. 성취기준 [물리8-02-01], [물리8-01-03].

준비

\(\Psi = a\psi_{n_1}e^{-iE_{n_1}t/\hbar} + b\psi_{n_2}e^{-iE_{n_2}t/\hbar}\)이고, 무게는 \(b^2\)입니다. 위는 \(|\Psi|^2\)(파랑, 연한 점선은 \(t = 0\))와 \(\langle x\rangle\)(빨간 점선), 아래는 \(\langle x\rangle\)의 시간 변화입니다. 시간 단위는 \(\hbar/E_1\)입니다.

절차

  1. n₁ = 1, n₂ = 2, b² = 0.5에서 재생해 확률 덩어리가 오가는 모습을 본다. \(\langle x\rangle\)의 진폭을 2.1절 예제(0.180L)와 비교한다.
  2. b²를 0이나 1로 하면(정상 상태 하나) 아무것도 움직이지 않음을 확인한다.
  3. n₂ = 3으로 바꿔 \(\langle x\rangle\)이 움직이지 않는 까닭을 생각한다.
  4. n₁ = 2, n₂ = 3으로 하고 주기가 \(2\pi\hbar/(E_3 - E_2)\)인지 확인한다.

기대 결과

  • 1과 2의 반반 중첩: 진폭 0.180L, 주기 \(2\pi/3 \approx 2.094\,\hbar/E_1\).
  • 정상 상태 하나는 \(|\Psi|^2\)이 변하지 않는다.
  • 1과 3은 둘 다 가운데에 대칭이라 \(\langle x\rangle = L/2\)로 고정된다. 그래도 \(|\Psi|^2\)의 모양은 숨 쉬듯 변한다.
  • 2와 3: 주기 \(2\pi/5 \approx 1.257\,\hbar/E_1\).

분석

  1. \(\langle x\rangle\)의 진폭이 \(b^2 = 0.5\)에서 가장 큰 까닭을 \(2ab\)로 설명해 보세요.
  2. 측정하면 에너지가 \(E_{n_1}\) 또는 \(E_{n_2}\)로만 나오는데도 상태가 움직이는 것은 무엇 때문인지 말해 보세요.

더 해 보기
