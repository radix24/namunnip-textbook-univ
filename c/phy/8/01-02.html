  • 슈뢰딩거 방정식과 파동함수의 통계적 해석을 안다.

먼저 알아야 할 것
  • 파동함수와 확률 밀도의 뜻 (물리3 4.1절), 복소수와 부분적분.

1.2.1슈뢰딩거 방정식과 통계적 해석

질량 \(m\)인 입자가 퍼텐셜 \(V(x)\) 속을 1차원으로 움직일 때 파동함수 \(\Psi(x,t)\)는 다음을 따릅니다.

\[i\hbar\frac{\partial\Psi}{\partial t} = -\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2} + V\Psi.\]

이 식은 유도되는 것이 아니라 실험과 맞는다는 이유로 받아들이는 기본 법칙입니다(고전역학의 \(F = ma\)와 같은 위치). 보른의 해석에 따르면 \(|\Psi(x,t)|^2dx\)는 시각 \(t\)에 입자를 \(x\)와 \(x + dx\) 사이에서 찾을 확률입니다.

1.2.2규격화

입자는 어딘가에는 있으므로

\[\int_{-\infty}^{\infty}|\Psi(x,t)|^2dx = 1.\]

슈뢰딩거 방정식은 선형이라 \(\Psi\)가 해이면 \(A\Psi\)도 해입니다. 이 상수 \(A\)를 위 조건으로 정하는 일이 규격화입니다. 적분이 무한대이면(예: \(\Psi = \) 상수) 규격화할 수 없고, 물리적 상태를 나타내지 못합니다.

정리 1.2.1 (규격화 유지)

\(\Psi\)가 슈뢰딩거 방정식을 따르고 \(x \to \pm\infty\)에서 0으로 가면, \(\frac{d}{dt}\int|\Psi|^2dx = 0\)입니다.

증명. 방정식과 그 켤레식에서 \(\partial_t\Psi = \frac{i\hbar}{2m}\Psi'' - \frac{i}{\hbar}V\Psi\), \(\partial_t\Psi^* = -\frac{i\hbar}{2m}\Psi^{*\prime\prime} + \frac{i}{\hbar}V\Psi^*\) (\(V\)는 실수). 그러면

\[\frac{\partial}{\partial t}|\Psi|^2 = \Psi^*\partial_t\Psi + \Psi\partial_t\Psi^* = \frac{i\hbar}{2m}\left(\Psi^*\Psi'' - \Psi\Psi^{*\prime\prime}\right) = \frac{\partial}{\partial x}\left[\frac{i\hbar}{2m}\left(\Psi^*\Psi' - \Psi\Psi^{*\prime}\right)\right].\]

전 구간 적분은 양 끝 값의 차이고, 끝에서 \(\Psi \to 0\)이므로 0입니다. \(\square\) 한 번 규격화하면 언제나 규격화되어 있으니, 해석이 모순 없이 유지됩니다.

1.2.3확률 흐름과 연속 방정식

정의 1.2.2 \[j(x,t) = \frac{i\hbar}{2m}\left(\Psi\frac{\partial\Psi^*}{\partial x} - \Psi^*\frac{\partial\Psi}{\partial x}\right) = \frac{\hbar}{m}\,\mathrm{Im}\left(\Psi^*\frac{\partial\Psi}{\partial x}\right), \qquad \frac{\partial|\Psi|^2}{\partial t} + \frac{\partial j}{\partial x} = 0.\]

전하의 연속 방정식과 같은 꼴입니다. 구간 \([a, b]\) 안의 확률은 \(j(a) - j(b)\)의 비율로 바뀝니다. 실수 파동함수(또는 실수에 상수 위상을 곱한 것)는 \(j = 0\)입니다.

예제 1.2.3

평면파 \(\Psi = Ae^{i(kx - \omega t)}\)의 확률 흐름을 구하세요.

풀이. \(\Psi^*\Psi' = ik|A|^2\)이므로 \(j = \frac{\hbar k}{m}|A|^2 = v|A|^2\). 밀도 \(|A|^2\)에 속도 \(v = p/m\)를 곱한 것입니다. 2.3절의 반사율과 투과율은 이 흐름의 비로 정의합니다.

예제 1.2.4

\(\Psi(x, 0) = Ae^{-a|x|}\) (\(a > 0\))를 규격화하세요.

풀이. \(\int|A|^2e^{-2a|x|}dx = |A|^2\cdot2\cdot\frac1{2a} = |A|^2/a = 1\)이므로 \(A = \sqrt a\). 이 함수는 2.2절의 델타 우물 바닥 상태입니다.

요약
  1. \(|\Psi|^2\)는 확률 밀도, 전체 적분은 1.
  2. 슈뢰딩거 방정식은 규격화를 시간에 따라 유지한다.
  3. \(j = (\hbar/m)\,\mathrm{Im}(\Psi^*\Psi')\), \(\partial_t|\Psi|^2 + \partial_xj = 0\).

1.2.4연습문제

기본

  1. \(\Psi(x, 0) = A x(L - x)\) (\(0 \le x \le L\), 바깥 0)를 규격화하세요.
    답

    \(\int_0^Lx^2(L - x)^2dx = L^5/30\)이므로 \(A = \sqrt{30/L^5}\).

  2. \(\Psi = Ae^{ikx} + Be^{-ikx}\)의 확률 흐름은?
    답

    \(j = \frac{\hbar k}{m}(|A|^2 - |B|^2)\). 교차항은 상쇄됩니다. 오른쪽 흐름에서 왼쪽 흐름을 뺀 것입니다.

발전

  1. 퍼텐셜에 허수부 \(V = V_0 - i\Gamma\) (\(\Gamma > 0\) 상수)를 넣으면 전체 확률이 어떻게 변하는지 보이세요.
    답

    증명을 다시 하면 \(\frac{dP}{dt} = -\frac{2\Gamma}{\hbar}P\), \(P = e^{-2\Gamma t/\hbar}\). 붕괴하는 불안정 입자를 흉내 내는 방법이며, 수명은 \(\tau = \hbar/2\Gamma\)입니다.
