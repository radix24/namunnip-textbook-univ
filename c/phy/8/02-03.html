2.3.1산란 상태

\(E\)가 양쪽 무한대의 퍼텐셜보다 크면 \(\psi\)는 규격화되지 않는 진동 함수입니다. 이런 해는 그대로는 물리적 상태가 아니지만, 이들을 겹친 파동 묶음은 규격화됩니다. 계산은 단색 파동으로 하고 결과를 묶음의 평균 행동으로 읽습니다. 왼쪽에서 들어오는 경우

\[\psi = \begin{cases}Ae^{ikx} + Be^{-ikx} & (\text{왼쪽})\\ Fe^{ik'x} & (\text{오른쪽})\end{cases}, \qquad R = \frac{|j_{\text{반사}}|}{j_{\text{입사}}} = \frac{|B|^2}{|A|^2}, \quad T = \frac{j_{\text{투과}}}{j_{\text{입사}}} = \frac{k'|F|^2}{k|A|^2}.\]

오른쪽 속도가 다르면 \(k'/k\)가 붙습니다. 확률 보존으로 \(R + T = 1\)입니다.

2.3.2퍼텐셜 계단

\(x < 0\)에서 \(V = 0\), \(x > 0\)에서 \(V = V_0\)입니다.

  • \(E > V_0\): \(k = \sqrt{2mE}/\hbar\), \(k' = \sqrt{2m(E - V_0)}/\hbar\). \(\psi\), \(\psi'\) 연속에서 \(A + B = F\), \(k(A - B) = k'F\).
  • \(E < V_0\): 오른쪽은 \(Fe^{-\kappa x}\)로 흐름이 0이다. \(|B| = |A|\)라 \(R = 1\). 그래도 파동함수는 \(1/\kappa\) 깊이로 스며든다.
정리 2.3.1 (계단, \(E > V_0\)) \[R = \left(\frac{k - k'}{k + k'}\right)^2, \qquad T = \frac{4kk'}{(k + k')^2}.\]

고전 입자라면 \(E > V_0\)에서 늘 넘어가지만, 파동은 일부 반사됩니다. 아래로 내려가는 계단(\(V_0 < 0\))에서도 반사가 있습니다. 공식이 \(k\)와 \(k'\)에 대칭이기 때문입니다.

2.3.3사각 장벽

폭 \(L\), 높이 \(V_0\)인 장벽에서 세 구간의 해를 두 경계에서 이으면

정리 2.3.2 (사각 장벽) \[T^{-1} = 1 + \frac{V_0^2\sinh^2\kappa L}{4E(V_0 - E)}\ (E < V_0), \qquad T^{-1} = 1 + \frac{V_0^2\sin^2k'L}{4E(E - V_0)}\ (E > V_0).\]
  • \(E < V_0\), \(\kappa L \gg 1\)이면 \(T \approx 16\frac E{V_0}\left(1 - \frac E{V_0}\right)e^{-2\kappa L}\). 폭과 \(\sqrt{V_0 - E}\)에 지수적으로 민감하다(터널링).
  • \(E > V_0\)이면 \(k'L = n\pi\)에서 \(T = 1\)(공명 투과). 장벽 안에 반파장이 정수 개 들어가 두 경계의 반사가 상쇄된다.

주사 터널링 현미경, 알파 붕괴, 플래시 메모리가 터널링을 이용하거나 그 결과입니다. 아래 실습 카드에서 계단의 파동함수와 \(R\), \(T\)를 볼 수 있습니다.

예제 2.3.3

전자가 \(E = 2V_0\)로 계단에 들어옵니다. 반사율은?

풀이. \(k'/k = \sqrt{(E - V_0)/E} = 1/\sqrt2\). \(R = \left(\frac{1 - 0.707}{1 + 0.707}\right)^2 \approx 0.0294\). 약 3%가 반사됩니다. 전자의 질량과 \(V_0\)의 크기와 상관없이 \(E/V_0\)로만 정해집니다.

요약
  1. \(R\), \(T\)는 확률 흐름의 비. \(R + T = 1\).
  2. 계단: \(E > V_0\)에서 \(R = ((k - k')/(k + k'))^2\), \(E < V_0\)에서 \(R = 1\).
  3. 장벽: 터널링 \(T \sim e^{-2\kappa L}\), \(E > V_0\)에서 공명 투과.

2.3.4연습문제

기본

  1. 계단에서 \(E = V_0\)에 가까워지면 \(R\)은 어떻게 되나요?
    답

    \(k' \to 0\)이라 \(R \to 1\). \(E < V_0\)인 경우와 이어집니다.

  2. 높이 5 eV, 폭 0.5 nm 장벽에 1 eV 전자의 투과율을 근사식으로 구하세요.
    답

    \(\kappa = \sqrt{2(511000)(4)}/197.3 \approx 10.25\ \text{nm}^{-1}\), \(2\kappa L \approx 10.25\). \(T \approx 16(0.2)(0.8)e^{-10.25} \approx 2.56\times3.5\times10^{-5} \approx 9\times10^{-5}\).

발전

  1. 계단에서 \(T = \frac{k'|F|^2}{k|A|^2}\) 대신 \(|F|^2/|A|^2\)를 쓰면 \(R + T \ne 1\)임을 \(E = 2V_0\)로 확인하세요.
    답

    \(F/A = 2k/(k + k') = 2/(1.707) \approx 1.172\), \(|F/A|^2 \approx 1.373\). \(R + |F/A|^2 \approx 1.40\). \(k'/k = 0.707\)을 곱하면 \(0.971\)로 \(R + T = 1\)입니다.

2.3.2

실습퍼텐셜 계단의 반사와 투과

실습 · 산란 상태

다루는 성취기준 [물리8-02-03]

목표

왼쪽에서 들어오는 입자가 높이 \(V_0\)인 계단을 만날 때의 파동함수와 반사율·투과율을 보고, 고전 입자와 다른 점을 확인합니다. 성취기준 [물리8-02-03].

준비

위는 계단(회색), \(|\psi|^2\)(파랑), 실수부 \(\mathrm{Re}\,\psi\)(연한 선)입니다. 입사파 진폭은 1입니다. 아래는 \(E/V_0\)에 따른 \(R\)(빨강)과 \(T\)(파랑)입니다. 길이 단위는 \(\hbar/\sqrt{2mV_0}\)이라 결과는 \(E/V_0\)로만 정해집니다.

절차

  1. \(E = 2V_0\)에서 \(R\), \(T\)를 2.3절 예제(약 3%)와 비교한다.
  2. \(E\)를 \(V_0\) 쪽으로 낮추며 \(R\)이 어떻게 변하는지 본다.
  3. \(E < V_0\)로 내려 오른쪽 파동함수가 지수적으로 줄어드는 모습과 침투 깊이를 본다.
  4. 재생을 눌러 \(E < V_0\)에서 왼쪽 무늬가 제자리에서 출렁이는 정상파인지 확인한다.

기대 결과

  • \(E = 2V_0\): \(R \approx 0.029\), \(T \approx 0.971\).
  • \(E \to V_0\)이면 \(R \to 1\). 고전 입자는 \(E > V_0\)이면 늘 넘어간다.
  • \(E < V_0\)이면 \(R = 1\)이지만 \(|\psi|^2\)은 벽 안으로 \(1/\kappa\) 정도 스며든다. \(E\)가 \(V_0\)에 가까울수록 깊다.
  • \(E < V_0\)이면 \(|r| = 1\)이라 왼쪽에 완전한 정상파가 생긴다. \(E > V_0\)이면 \(|\psi|^2\)의 출렁임이 작다(반사파가 약함).

분석

  1. \(E > V_0\)일 때 \(|F/A|^2\)이 1보다 클 수 있는데도 \(T < 1\)인 까닭을 확률 흐름으로 설명해 보세요.
  2. 계단을 아래로 내려가는 경우(\(V_0 < 0\))에도 반사가 생기는 까닭을 공식의 대칭으로 말해 보세요.

더 해 보기

계단 대신 폭이 유한한 장벽이면 \(E < V_0\)에서도 투과가 생깁니다. 물리3 4.3절의 장벽 투과 카드에서 같은 \(E/V_0\)로 비교해 보세요.
