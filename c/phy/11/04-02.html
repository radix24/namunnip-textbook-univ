4.2.1열역학 항등식

\(S(U, V, N)\)의 전미분에서 \(\partial S/\partial U = 1/T\), \(\partial S/\partial V = P/T\), \(\partial S/\partial N = -\mu/T\)로 정의하면

항등식 4.2.1 \[dU = T\,dS - P\,dV + \mu\,dN,\] \[dH = T\,dS + V\,dP + \mu\,dN, \quad dF = -S\,dT - P\,dV + \mu\,dN, \quad dG = -S\,dT + V\,dP + \mu\,dN.\]

상태 함수 사이의 관계이므로 가역·비가역과 상관없이 성립합니다. 다만 가역 과정에서만 \(T\,dS = Q\), \(-P\,dV = W\)로 읽을 수 있습니다. 각 퍼텐셜에서 미분 변수(자연 변수)가 다르고, 르장드르 변환(\(-TS\), \(+PV\)를 더함)으로 서로 바뀝니다.

4.2.2맥스웰 관계식

\(dF = -S\,dT - P\,dV\)에서 \(S = -\partial F/\partial T\), \(P = -\partial F/\partial V\). 혼합 편미분은 순서와 상관없으므로 \(\partial^2F/\partial V\partial T = \partial^2F/\partial T\partial V\).

맥스웰 관계식 \[\left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial P}{\partial S}\right)_V, \quad \left(\frac{\partial T}{\partial P}\right)_S = \left(\frac{\partial V}{\partial S}\right)_P,\] \[\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial P}{\partial T}\right)_V, \quad -\left(\frac{\partial S}{\partial P}\right)_T = \left(\frac{\partial V}{\partial T}\right)_P.\]

쓸모: 엔트로피는 직접 잴 수 없지만 오른쪽(상태방정식의 기울기)은 잴 수 있습니다. 예를 들어 등온 압축에서 엔트로피가 얼마나 줄어드는지는 열팽창 계수로 알 수 있습니다.

4.2.3응용: \(C_P - C_V\)

\(S(T, V)\)로 보고 정압에서 \(T\)로 미분하면 \(\left(\frac{\partial S}{\partial T}\right)_P = \left(\frac{\partial S}{\partial T}\right)_V + \left(\frac{\partial S}{\partial V}\right)_T\left(\frac{\partial V}{\partial T}\right)_P\). 맥스웰 관계식과 \(C = T(\partial S/\partial T)\)를 쓰고 정리하면

결과 4.2.2 \[C_P - C_V = \frac{TV\beta^2}{\kappa_T}, \qquad \beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_P, \quad \kappa_T = -\frac1V\left(\frac{\partial V}{\partial P}\right)_T.\]

이상기체이면 \(\beta = 1/T\), \(\kappa_T = 1/P\)라 \(C_P - C_V = PV/T = Nk\)로 2.3절과 같습니다. 고체는 \(\beta\)가 작아 차이가 몇 % 이하입니다.

예제 4.2.1

이상기체에서 \((\partial U/\partial V)_T = 0\)임을 맥스웰 관계식으로 보이세요.

풀이. \(dU = T\,dS - P\,dV\)에서 \(\left(\frac{\partial U}{\partial V}\right)_T = T\left(\frac{\partial S}{\partial V}\right)_T - P = T\left(\frac{\partial P}{\partial T}\right)_V - P\). 이상기체 \(P = NkT/V\)이면 \(T\cdot Nk/V - P = 0\). 이상기체의 내부 에너지가 온도만의 함수임이 상태방정식에서 나옵니다.

요약
  1. \(dU = T\,dS - P\,dV + \mu\,dN\) 등 네 미분형.
  2. 혼합 편미분의 대칭 → 맥스웰 관계식. 엔트로피 미분을 상태방정식 기울기로 바꾼다.
  3. \(C_P - C_V = TV\beta^2/\kappa_T\).

4.2.4연습문제

기본

  1. \(dG\)에서 맥스웰 관계식 하나를 유도하세요.
    답

    \(S = -\partial G/\partial T\), \(V = \partial G/\partial P\). 혼합 편미분: \(-(\partial S/\partial P)_T = (\partial V/\partial T)_P\).

발전

  1. 판데르발스 기체 \((P + aN^2/V^2)(V - Nb) = NkT\)에서 \((\partial U/\partial V)_T\)를 구하세요.
    답

    \(T(\partial P/\partial T)_V - P = \frac{NkT}{V - Nb} - P = \frac{aN^2}{V^2}\). 부피가 커지면 분자 사이 인력을 거슬러 내부 에너지가 늘어납니다.
