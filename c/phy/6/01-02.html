1.2.1가산기

  • 반가산기: 두 비트 \(A, B\)를 더해 합 \(S = A \oplus B\), 올림 \(C = AB\).
  • 전가산기: 아래 자리에서 올라온 \(C_{\text{in}}\)까지 세 비트를 더함. \(S = A \oplus B \oplus C_{\text{in}}\), \(C_{\text{out}} = AB + C_{\text{in}}(A \oplus B)\).

전가산기 \(n\)개를 올림으로 이으면 \(n\)비트 덧셈기(리플 캐리 가산기)가 됩니다. 올림이 자리마다 차례로 전달되어 비트 수가 많으면 느려지므로, 실제 프로세서는 올림을 미리 계산하는 방식을 씁니다. 뺄셈은 2의 보수(공통10 6.1절)를 더해서 합니다.

예제 1.2.1

4비트 가산기로 0110 + 0111을 계산하고 각 자리의 올림을 써라.

풀이. 0자리: 0 + 1 = 1, 올림 0. 1자리: 1 + 1 = 0, 올림 1. 2자리: 1 + 1 + 1 = 1, 올림 1. 3자리: 0 + 0 + 1 = 1, 올림 0. 결과 1101(= 13). 6 + 7 = 13이 맞습니다.

1.2.2디코더와 멀티플렉서

  • 디코더: \(n\)비트 입력에 따라 \(2^n\)개 출력 가운데 하나만 활성화. 메모리 주소 선택(3.1절), 7-세그먼트 표시에 쓴다.
  • 멀티플렉서: 선택 입력에 따라 여러 데이터 입력 가운데 하나를 출력으로 보낸다. 여러 신호를 한 줄로 번갈아 보내거나, 진리표를 그대로 구현하는 데 쓴다.

1.2.3IC로 만들기

74HC00(NAND 4개), 74HC08(AND), 74HC86(XOR) 같은 논리 IC를 브레드보드에 꽂아 회로를 만듭니다. 전원(VCC, GND) 핀을 잊지 않고, 쓰지 않는 입력은 떠 있게 두지 말고 전원이나 접지에 묶습니다(CMOS 입력이 떠 있으면 동작이 불안정하고 전류가 늘 수 있음). 각 IC 전원 핀 옆에 0.1 μF 축전기를 달아 순간 전류에 의한 잡음을 줄입니다. 동작 확인은 스위치 입력과 LED 출력으로 진리표를 한 줄씩 채우는 방법이 기본입니다. 핀 배치와 전압 조건은 반드시 사양서로 확인합니다.

요약
  1. 반가산기 \(S = A \oplus B\), \(C = AB\). 전가산기를 이어 \(n\)비트 덧셈.
  2. 디코더(하나만 선택), 멀티플렉서(여럿 중 하나를 출력).
  3. IC: 전원 핀, 안 쓰는 입력 묶기, 바이패스 축전기.

1.2.4연습문제

기본

  1. XOR을 NAND 게이트만으로 만들려면 몇 개가 필요한가?
    답

    4개. \(N = \overline{AB}\), \(A \oplus B = \overline{\overline{AN}\cdot\overline{BN}}\).
