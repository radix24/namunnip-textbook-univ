뉴턴 법칙은 매 순간의 힘과 가속도를 잇습니다. 하지만 "처음과 나중에 속력이 얼마인가"만 궁금할 때는 그 사이의 운동을 다 풀 필요가 없습니다. 힘이 한 일만 알면 운동 에너지의 변화를 알 수 있기 때문입니다. 더 나아가 일이 경로에 상관없는 힘(보존력)이면, 위치마다 퍼텐셜 에너지라는 숫자를 붙여 두고 \(T + U\)가 일정하다는 한 줄로 문제를 풉니다. 이 절은 그 과정을 정리합니다.

3.1.1일-에너지 정리

운동 에너지 \(T = \frac12mv^2 = \frac12m\dot{\mathbf r}\cdot\dot{\mathbf r}\)를 미분하면 \(\dot T = m\ddot{\mathbf r}\cdot\dot{\mathbf r} = \mathbf F\cdot\dot{\mathbf r}\)이므로, 경로를 따라 적분하면

\[\Delta T = T_2 - T_1 = \int_1^2\mathbf F\cdot d\mathbf r = W(1 \to 2).\]

일 \(W\)는 경로를 따른 선적분이므로 일반적으로 경로에 따라 값이 다릅니다. 예를 들어 상자를 바닥에서 밀어 같은 곳으로 옮겨도, 빙 돌아가면 마찰이 한 (음의) 일이 더 커집니다.

\(\mathbf F\cdot d\mathbf r\)에서 내적이 쓰이는 까닭은, 움직이는 방향의 힘 성분만 속력을 바꾸기 때문입니다. 움직임에 수직인 힘(원운동의 구심력, 자기력)은 방향만 바꾸고 속력은 바꾸지 않으므로 일이 0입니다.

3.1.2보존력과 퍼텐셜 에너지

정의 3.1.1

힘 \(\mathbf F\)가 (1) 위치만의 함수이고 (2) 두 점 사이에 한 일이 경로에 상관없으면 보존력이라 한다. 기준점 \(\mathbf r_0\)을 정하고

\[U(\mathbf r) = -\int_{\mathbf r_0}^{\mathbf r}\mathbf F(\mathbf r')\cdot d\mathbf r'\]

을 퍼텐셜 에너지라 한다.

그러면 \(W(1 \to 2) = U_1 - U_2\)이고, 일-에너지 정리와 합치면 \(T + U\)가 보존됩니다. 보존력 말고 마찰 같은 비보존력이 있으면 \(\Delta(T + U) = W_{\text{nc}}\)입니다.

\(\mathbf r\)에서 \(\mathbf r + d\mathbf r\)로 조금 움직이면 \(dU = -\mathbf F\cdot d\mathbf r\)이고, 1.3절의 \(dU = \nabla U\cdot d\mathbf r\)와 비교하면

\[\mathbf F = -\nabla U.\]

힘은 퍼텐셜 에너지가 가장 빨리 줄어드는 방향을 향합니다. 기준점을 바꾸면 \(U\)에 상수가 더해질 뿐 힘은 같습니다.

주의퍼텐셜 에너지의 정의에 붙은 음의 부호를 빠뜨리기 쉽습니다. 힘이 입자를 끌고 가며 양의 일을 하면 운동 에너지가 늘고, 그만큼 퍼텐셜 에너지는 줄어야 합니다. 그래서 \(U = -\int\mathbf F\cdot d\mathbf r\), \(\mathbf F = -\nabla U\)입니다. 물체가 떨어지면 \(U = mgh\)가 줄고 속력이 커지는 것으로 부호를 점검하세요.
예제 3.1.2

힘 \(\mathbf F = (2xy + z^3,\ x^2,\ 3xz^2)\)의 퍼텐셜 에너지를 구하여라.

풀이. \(-\partial_xU = 2xy + z^3\)에서 \(U = -x^2y - xz^3 + g(y, z)\). \(-\partial_yU = x^2 - \partial_yg = x^2\)이므로 \(g = g(z)\). \(-\partial_zU = 3xz^2 - g'(z) = 3xz^2\)이므로 \(g\)는 상수. \(U = -x^2y - xz^3\) (+ 상수). 이렇게 성분마다 적분하다 모순이 생기면 보존력이 아닙니다(3.2절에서 미리 판정).

3.1.3시간에 의존하는 퍼텐셜, 여러 입자

\(U\)가 시간에도 의존하면 \(\mathbf F = -\nabla U\)는 여전히 쓸 수 있지만 \(T + U\)는 보존되지 않습니다. 두 입자가 \(U(|\mathbf r_1 - \mathbf r_2|)\)로 상호작용하면 서로 받는 힘이 제3법칙을 만족하고, 전체 에너지 \(T_1 + T_2 + U\)가 보존됩니다(5.1절 2체 문제로 이어짐).

요약
  1. \(\Delta T = \int\mathbf F\cdot d\mathbf r\).
  2. 보존력: 위치만의 함수 + 경로 무관. \(U = -\int\mathbf F\cdot d\mathbf r\), \(\mathbf F = -\nabla U\).
  3. \(T + U\) 보존, 비보존력이 있으면 \(\Delta E = W_{\text{nc}}\).

기본

3.1.2

예제경로에 따라 다른 일, 같은 일

선적분 · 보존력 · 마찰 · 문제 해결 전략

다루는 성취기준 [물리1-03-01]

출발점

일은 \(W = \int\mathbf F\cdot d\mathbf r\)입니다. 보존력이면 경로와 상관없이 퍼텐셜 차이로 끝나고, 마찰처럼 비보존력이면 경로를 따라 실제로 적분해야 합니다.

문제 해결 전략 · 일 계산
  1. 경로를 매개변수로 쓴다.
  2. \(\mathbf F\cdot d\mathbf r\)을 매개변수의 함수로 만들어 적분한다.
  3. 보존력이면 퍼텐셜 차이로 검산한다.
  4. 두 경로의 결과를 비교해 보존력인지 판단한다.

힘 \(\mathbf F = (2xy, x^2)\) N이 원점에서 점 \((1, 1)\) m까지 (가) 직선 \(y = x\) (나) 포물선 \(y = x^2\)을 따라 한 일을 구하여라.

풀이

  1. (가) \(x = t\), \(y = t\), \(0 \le t \le 1\). \(\mathbf F\cdot d\mathbf r = (2t^2 + t^2)dt = 3t^2dt\), \(W = 1\) J.
    \(dx = dy = dt\).
  2. (나) \(x = t\), \(y = t^2\), \(dy = 2t\,dt\). \(\mathbf F\cdot d\mathbf r = 2t^3dt + t^2\cdot2t\,dt = 4t^3dt\), \(W = 1\) J.
    같은 끝점, 다른 경로.
  3. 두 경로가 같다. 퍼텐셜 \(U = -x^2y\)를 찾으면 \(W = U(0, 0) - U(1, 1) = 1\) J.
    \(-\partial_xU = 2xy\), \(-\partial_yU = x^2\).
  4. 회전 \(\partial_xF_y - \partial_yF_x = 2x - 2x = 0\)으로 보존력임을 확인.
    3.2절의 판정법.

의미

보존력은 경로를 구할 필요가 없어 계산이 쉽습니다. 반대로 마찰력은 늘 움직임의 반대라 경로가 길수록 음의 일이 커집니다. 같은 상자를 빙 돌려 옮기면 더 힘든 까닭입니다.

검산

닫힌 경로(가 → 나를 거꾸로)의 일은 \(1 - 1 = 0\)입니다. 보존력의 성질과 맞습니다.
