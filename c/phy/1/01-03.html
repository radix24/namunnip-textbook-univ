퍼텐셜 에너지처럼 공간의 각 점에 숫자가 하나씩 붙은 양을 스칼라장, 힘이나 흐름처럼 각 점에 화살표가 붙은 양을 벡터장이라 합니다. 이런 장이 점에서 점으로 어떻게 변하는지 재는 도구가 \(\nabla\)입니다. 기울기는 "어느 쪽으로 가장 가파르게 오르나", 발산은 "이 점에서 흐름이 솟아나나", 회전은 "이 점 둘레로 소용돌이치나"를 묻습니다. 역학에서는 \(\mathbf F = -\nabla U\)라는 관계 때문에 기울기가 가장 중요합니다.

1.3.1직교 좌표

연산자 \(\nabla = \hat{\mathbf x}\partial_x + \hat{\mathbf y}\partial_y + \hat{\mathbf z}\partial_z\)를 써서

처음 보는 수학 · 편미분 \(\partial_xf\)(또는 \(\frac{\partial f}{\partial x}\))는 편미분입니다. 변수가 여럿인 함수에서 하나만 움직이고 나머지는 상수로 두고 미분합니다. 예를 들어 \(f = x^2y + 3y\)이면 \(\partial_xf = 2xy\)(\(y\)는 상수로 봄), \(\partial_yf = x^2 + 3\)(\(x\)는 상수로 봄)입니다. 고등학교의 미분을 변수마다 한 번씩 하는 것뿐입니다. \(\nabla f = (\partial_xf, \partial_yf, \partial_zf)\)는 이렇게 얻은 세 방향의 기울기를 묶은 벡터이고, \(df = \partial_xf\,dx + \partial_yf\,dy + \partial_zf\,dz\)는 "조금 움직일 때 \(f\)의 변화 = 방향마다 (기울기 × 이동 거리)의 합"이라는 뜻입니다.
  • 기울기 \(\nabla f\): 스칼라 \(f\)가 가장 빨리 증가하는 방향과 그 비율. \(df = \nabla f\cdot d\mathbf r\).
  • 발산 \(\nabla\cdot\mathbf F = \partial_xF_x + \partial_yF_y + \partial_zF_z\): 한 점에서 퍼져 나가는 정도.
  • 회전 \(\nabla\times\mathbf F\): 한 점 둘레의 소용돌이 정도. 행렬식으로 계산.
  • 라플라시안 \(\nabla^2f = \nabla\cdot\nabla f = \partial_x^2f + \partial_y^2f + \partial_z^2f\).

산의 높이를 지도에 \(h(x, y)\)로 적었다고 생각해 보세요. \(\nabla h\)는 각 점에서 가장 가파른 오르막 쪽을 가리키고, 그 길이는 그 방향의 기울기입니다. 등고선을 따라 걸으면 높이가 바뀌지 않으므로 \(\nabla h\)는 언제나 등고선에 수직입니다. 공을 놓으면 \(-\nabla h\) 쪽, 곧 가장 가파른 내리막으로 굴러가기 시작합니다. \(\mathbf F = -\nabla U\)가 바로 이 그림입니다.

처음 보는 수학 · 발산과 회전을 성분으로 발산은 각 성분을 자기 방향으로 편미분해 더한 것이고, 회전은 외적(1.2절)과 같은 순서로 풀어 씁니다: \(\nabla\times\mathbf F = (\partial_yF_z - \partial_zF_y,\ \partial_zF_x - \partial_xF_z,\ \partial_xF_y - \partial_yF_x)\). 예를 들어 \(\mathbf F = (-y, x, 0)\)이면 \(z\) 성분이 \(\partial_x(x) - \partial_y(-y) = 2\)이고 나머지는 0입니다. 원점 둘레로 도는 흐름이라 \(z\)축 방향의 회전이 나온 것입니다. \(\nabla^2f\)는 같은 변수로 두 번 편미분한 것을 세 방향 모두 더한 것입니다.

항등식 \(\nabla\times(\nabla f) = 0\), \(\nabla\cdot(\nabla\times\mathbf F) = 0\)이 중요합니다. 첫째 식에서 "퍼텐셜의 기울기로 쓰이는 힘은 회전이 0"이 나오고, 이것이 3.2절 보존력 판정의 바탕입니다.

1.3.2곡선 좌표의 기울기

\(df = \nabla f\cdot d\mathbf r\)에서 출발합니다. 구면 좌표에서 \(d\mathbf r = dr\,\hat{\mathbf r} + r\,d\theta\,\hat{\boldsymbol\theta} + r\sin\theta\,d\phi\,\hat{\boldsymbol\phi}\)(1.1절)이고 \(df = \partial_rf\,dr + \partial_\theta f\,d\theta + \partial_\phi f\,d\phi\)이므로, 두 식을 맞추면

\[\nabla f = \frac{\partial f}{\partial r}\hat{\mathbf r} + \frac1r\frac{\partial f}{\partial\theta}\hat{\boldsymbol\theta} + \frac1{r\sin\theta}\frac{\partial f}{\partial\phi}\hat{\boldsymbol\phi}.\]

같은 방법으로 원통 좌표에서 \(\nabla f = \partial_\rho f\,\hat{\boldsymbol\rho} + \frac1\rho\partial_\phi f\,\hat{\boldsymbol\phi} + \partial_zf\,\hat{\mathbf z}\)입니다. 분모의 \(r\), \(r\sin\theta\)는 각도를 거리로 바꾸는 축척 인자입니다.

주의곡선 좌표의 기울기를 \((\partial_rf, \partial_\theta f, \partial_\phi f)\)로 쓰면 틀립니다. 각도는 거리가 아니어서 단위부터 맞지 않습니다. 각도로 미분한 항에는 그 각도를 거리로 바꾸는 인자 \(1/r\), \(1/(r\sin\theta)\)가 반드시 붙습니다.
예제 1.3.1

중력 퍼텐셜 에너지 \(U = -\frac{GMm}{r}\)에서 힘 \(\mathbf F = -\nabla U\)를 구하여라.

풀이. \(U\)는 \(r\)에만 의존하므로 \(\nabla U = \frac{dU}{dr}\hat{\mathbf r} = \frac{GMm}{r^2}\hat{\mathbf r}\). \(\mathbf F = -\frac{GMm}{r^2}\hat{\mathbf r}\), 중심을 향하는 역제곱 힘입니다. 직교 좌표로 하면 \(r = \sqrt{x^2 + y^2 + z^2}\)를 세 번 편미분해야 해서 훨씬 깁니다.

1.3.3발산, 회전, 라플라시안

곡선 좌표의 발산과 회전은 단위벡터의 미분까지 생각해야 해서 더 복잡합니다. 구면 좌표의 라플라시안은

\[\nabla^2f = \frac1{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial f}{\partial r}\right) + \frac1{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial f}{\partial\theta}\right) + \frac1{r^2\sin^2\theta}\frac{\partial^2f}{\partial\phi^2}\]

이고, 전자기학(물리5)과 수소 원자(물리8)에서 다시 씁니다. 외우기보다 필요할 때 표에서 찾아 쓰고, 구대칭인 경우 첫 항만 남는다는 것을 기억하면 됩니다.

요약
  1. \(\nabla f\), \(\nabla\cdot\mathbf F\), \(\nabla\times\mathbf F\), \(\nabla^2 f\). \(\nabla\times\nabla f = 0\).
  2. 곡선 좌표의 기울기는 \(df = \nabla f\cdot d\mathbf r\)에서 축척 인자로 얻는다.

1.3.4연습문제

기본

  1. \(f = r^n\)(구면 좌표)의 라플라시안을 구하고, \(\nabla^2(1/r) = 0\) (\(r \ne 0\))임을 확인하여라.
    답

    \(\frac1{r^2}\frac{d}{dr}(r^2\cdot nr^{n-1}) = n(n+1)r^{n-2}\). \(n = -1\)이면 0.

1.3.2

예제퍼텐셜의 기울기로 힘 구하기

기울기 · 등퍼텐셜면 · 곡선 좌표 · 문제 해결 전략

다루는 성취기준 [물리1-01-03]

출발점

보존력은 \(\mathbf F = -\nabla U\)입니다. 직교 좌표로 편미분해도 되지만, 대칭이 있으면 구면·원통 좌표의 기울기 공식(축척 인자 포함)이 훨씬 빠릅니다.

문제 해결 전략 · 퍼텐셜에서 힘 구하기
  1. 퍼텐셜이 어떤 좌표에 의존하는지 보고 좌표계를 고른다.
  2. 기울기 공식으로 성분을 구한다(각도 성분에는 \(1/r\) 등이 붙는다).
  3. 부호: 힘은 \(U\)가 줄어드는 쪽.
  4. 한 점에서 직교 좌표로 확인한다.

쌍극자의 퍼텐셜 에너지 \(U = \frac{k\cos\theta}{r^2}\)에서 시험 입자가 받는 힘의 \(r\), \(\theta\) 성분을 구하고, \(\theta = 0\)과 \(\theta = 90°\)에서 방향을 말하여라.

풀이

  1. \(F_r = -\partial_rU = \frac{2k\cos\theta}{r^3}\).
    구면 좌표 \(r\) 성분, 축척 인자 1.
  2. \(F_\theta = -\frac1r\partial_\theta U = -\frac1r\cdot\frac{-k\sin\theta}{r^2} = \frac{k\sin\theta}{r^3}\).
    각도 성분에는 \(1/r\)이 붙는다.
  3. \(\theta = 0\): \(F_r = 2k/r^3\), \(F_\theta = 0\). 축을 따라 바깥쪽(\(k > 0\)).
    축 위에서는 지름 방향만.
  4. \(\theta = 90°\): \(F_r = 0\), \(F_\theta = k/r^3\). \(\hat{\boldsymbol\theta}\) 방향(적도면에서 아래쪽, \(-z\) 방향).
    적도면에서는 축에 나란한 방향.

의미

축 위의 힘은 적도면의 두 배이고 방향이 다릅니다. 막대자석 둘레의 자기장 모양과 같은 구조입니다. 각도 성분의 \(1/r\)을 빼먹으면 \(F_\theta\)의 단위부터 틀립니다.

검산

\(\theta = 0\)인 \(z\)축 위에서 \(U = k/z^2\), \(F_z = -dU/dz = 2k/z^3\). \(F_r\)과 같습니다.
