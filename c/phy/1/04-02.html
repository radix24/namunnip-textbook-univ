실제 진동은 언젠가 멈춥니다. 공기 저항이나 마찰이 에너지를 조금씩 빼앗기 때문입니다. 저항이 약하면 진동하면서 진폭이 줄고, 아주 강하면 진동하지 못하고 느릿느릿 평형으로 돌아갑니다. 그 사이의 경계가 가장 빨리 멈추는 임계 감쇠입니다. 이 절은 세 경우가 특성 방정식의 근이 복소수인지, 중근인지, 실수인지로 깔끔하게 나뉘는 것을 봅니다.

4.2.1방정식과 특성근

저항 \(-b\dot x\)를 더하면 \(m\ddot x + b\dot x + kx = 0\). \(2\beta = b/m\)(감쇠 상수), \(\omega_0^2 = k/m\)로 두면

\[\ddot x + 2\beta\dot x + \omega_0^2x = 0.\]

\(x = e^{rt}\)를 넣으면 \(r^2 + 2\beta r + \omega_0^2 = 0\), \(r = -\beta \pm \sqrt{\beta^2 - \omega_0^2}\)입니다.

처음 보는 수학 · 왜 \(e^{rt}\)를 넣나 지수함수는 미분해도 모양이 그대로이고 \(r\)배만 됩니다. 그래서 \(\ddot x\), \(\dot x\), \(x\)가 모두 \(e^{rt}\)의 배수가 되어 공통인수로 묶이고, \(e^{rt} \ne 0\)이므로 \(r\)에 대한 이차방정식(근의 공식)만 풀면 됩니다. 근이 허수를 포함하면 \(e^{(-\beta \pm i\omega_1)t} = e^{-\beta t}(\cos\omega_1t \pm i\sin\omega_1t)\)(4.1절 오일러 공식)이라, 줄어들면서 진동하는 해가 나옵니다.

근을 읽는 법: 실수부 \(-\beta\)는 "얼마나 빨리 줄어드나", 허수부는 "얼마나 빨리 진동하나"입니다. \(\beta < \omega_0\)이면 제곱근 속이 음수라 허수부가 생겨 진동하고, \(\beta > \omega_0\)이면 두 근 모두 음의 실수라 진동 없이 줄기만 합니다. 마치 꿀 속의 용수철이 흔들리지 못하고 천천히 제자리로 돌아오는 것과 같습니다.

4.2.2세 경우

경우조건해모습
미감쇠\(\beta < \omega_0\)\(Ae^{-\beta t}\cos(\omega_1t - \delta)\), \(\omega_1 = \sqrt{\omega_0^2 - \beta^2}\)진폭이 지수적으로 주는 진동
임계 감쇠\(\beta = \omega_0\)\((C_1 + C_2t)e^{-\beta t}\)진동 없이 가장 빨리 평형으로
과감쇠\(\beta > \omega_0\)\(C_1e^{-(\beta - \sqrt{\beta^2 - \omega_0^2})t} + C_2e^{-(\beta + \sqrt{\beta^2 - \omega_0^2})t}\)진동 없이 천천히 평형으로
  • 미감쇠의 진동수 \(\omega_1\)은 \(\omega_0\)보다 조금 작다. 진폭이 \(1/e\)로 주는 시간은 \(1/\beta\).
  • 과감쇠에서는 느린 쪽 지수 \(\beta - \sqrt{\beta^2 - \omega_0^2}\)가 오래 남는다. 감쇠가 너무 크면 오히려 평형에 늦게 돌아온다.
  • 자동차 완충기, 저울 바늘, 문 닫힘 장치는 임계 감쇠 근처로 설계한다.
예제 4.2.1

\(m = 1\) kg, \(k = 100\) N/m인 진동자의 진폭이 10번 진동하는 동안 절반으로 줄었다. \(\beta\)와 \(b\)는?

풀이. \(\beta \ll \omega_0 = 10\) rad/s이면 주기 \(\approx 0.628\) s, 10주기 \(6.28\) s. \(e^{-6.28\beta} = 0.5\)에서 \(\beta \approx 0.110\) s⁻¹, \(b = 2m\beta \approx 0.22\) kg/s. \(\beta/\omega_0 \approx 0.011\)이라 미감쇠이고 \(\omega_1\)은 \(\omega_0\)와 거의 같습니다.

주의\(\beta\)는 \(b/m\)이 아니라 \(b/2m\)입니다. 교재에 따라 \(\gamma = b/m\)을 쓰기도 하므로, 식을 옮길 때 2배 차이에 주의하세요. 진폭이 \(1/e\)로 주는 시간은 \(1/\beta = 2m/b\)입니다.

에너지는 \(e^{-2\beta t}\)로 줄어듭니다(진폭의 제곱). 공통8의 감쇠 진동 실습 카드(공통8 2.2절)에서 세 경우를 직접 비교할 수 있습니다.

요약
  1. \(\ddot x + 2\beta\dot x + \omega_0^2x = 0\), 특성근 \(-\beta \pm \sqrt{\beta^2 - \omega_0^2}\).
  2. \(\beta < \omega_0\) 미감쇠, \(= \omega_0\) 임계, \(> \omega_0\) 과감쇠.

4.2.3연습문제

기본

  1. 임계 감쇠에서 \(x(0) = x_0\), \(\dot x(0) = 0\)일 때 \(C_1\), \(C_2\)를 구하여라.
    답

    \(C_1 = x_0\), \(\dot x(0) = C_2 - \beta C_1 = 0\)에서 \(C_2 = \beta x_0\). \(x = x_0(1 + \beta t)e^{-\beta t}\).

4.2.2

실습감쇠 진동의 세 경우 비교

실습 · 미감쇠·임계·과감쇠

다루는 성취기준 [물리1-04-02]

목표

감쇠비 \(\beta/\omega_0\)를 바꾸며 미감쇠, 임계 감쇠, 과감쇠의 운동을 그리고, 어떤 감쇠에서 가장 빨리 멈추는지 시간을 재어 확인합니다. 성취기준 [물리1-04-02].

준비

고유 주기를 1 s(\(\omega_0 = 2\pi\))로 두고, \(x = 1\)에서 가만히 놓습니다. 파란 선이 지금 감쇠의 운동, 회색 점선이 임계 감쇠입니다. 가는 점선(±0.05) 안에 머물기 시작하는 시각을 "멈춘 시각"으로 봅니다.

절차

  1. 감쇠비 0.2에서 진동 주기와 멈춘 시각을 적는다.
  2. 감쇠비를 1(임계)로 바꿔 멈춘 시각을 적는다.
  3. 감쇠비를 3으로 키워 멈춘 시각이 오히려 늘어나는 것을 확인한다.
  4. 감쇠비 0.7에서도 멈춘 시각을 재어 임계 감쇠와 비교한다.

기대 결과

  • 감쇠비 0.20: 진동 주기 1.021 s(고유 주기보다 조금 길다), 멈춘 시각 2.19 s.
  • 임계 감쇠(1.00): 진동 없이 0.76 s에 멈춘다.
  • 감쇠비 3.00: 진동은 없지만 멈춘 시각이 2.81 s로 임계보다 길다.
  • 감쇠비 0.70: 조금 넘쳤다 돌아오지만 0.46 s에 ±0.05 안으로 들어와, 이 기준으로는 임계 감쇠보다 빠르다.

분석

  1. 과감쇠에서 느린 지수 \(\beta - \sqrt{\beta^2 - \omega_0^2}\)가 \(\beta\)가 클수록 작아지는 것을 보이세요.
  2. 넘치지 않고 가장 빨리 0에 다가가는 것은 임계 감쇠지만, 조금 넘쳐도 허용 범위 안에 가장 빨리 들어오는 것은 감쇠비 0.7쯤입니다. 문 닫힘 장치와 측정 계기에서 각각 어느 쪽을 고를지 말해 보세요.
