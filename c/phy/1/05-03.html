케플러는 화성 관측 자료에서 행성 운동의 세 법칙을 찾아냈지만, 왜 그런지는 몰랐습니다. 뉴턴은 역제곱 중력에서 세 법칙이 모두 수학적으로 나온다는 것을 보였습니다. 이 절에서 그 유도를 따라갑니다. 요령은 시간 대신 각도를 변수로 쓰고, \(r\) 대신 \(u = 1/r\)을 쓰는 것입니다. 그러면 궤도 방정식이 이미 아는 조화 진동 방정식이 됩니다.

5.3.1궤도 방정식

시간 대신 각도 \(\phi\)의 함수로 궤도 \(r(\phi)\)를 구합니다. \(u = 1/r\), \(\dot\phi = \ell u^2/\mu\)를 쓰면 \(\dot r = -\frac{\ell}{\mu}u'\), \(\ddot r = -\frac{\ell^2u^2}{\mu^2}u''\) (\('\)는 \(d/d\phi\))이고, 극좌표 반지름 방향 방정식 \(\mu(\ddot r - r\dot\phi^2) = F(r)\)는

\[u''(\phi) = -u(\phi) - \frac{\mu}{\ell^2u(\phi)^2}F.\]

이것이 궤도 방정식입니다. 중간 계산을 풀어 쓰면, 연쇄 법칙으로 \(\dot r = \frac{dr}{d\phi}\dot\phi = -\frac{1}{u^2}u'\cdot\frac{\ell u^2}{\mu} = -\frac\ell\mu u'\)이고, 한 번 더 같은 방법으로 \(\ddot r = -\frac\ell\mu u''\dot\phi = -\frac{\ell^2u^2}{\mu^2}u''\)입니다. 이것과 \(r\dot\phi^2 = \frac{\ell^2u^3}{\mu^2}\)를 반지름 방향 방정식에 넣고 \(-\frac{\ell^2u^2}{\mu}\)로 나누면 위 식이 됩니다.

5.3.2역제곱 힘

\(F = -\gamma u^2\)이면 \(u'' = -u + \frac{\gamma\mu}{\ell^2}\). 단순 조화 방정식에 상수가 더해진 꼴이라

\[u = \frac{\gamma\mu}{\ell^2}(1 + \epsilon\cos\phi), \qquad r(\phi) = \frac{c}{1 + \epsilon\cos\phi}, \quad c = \frac{\ell^2}{\gamma\mu}.\]

풀이가 쉬운 까닭: 역제곱 힘에서는 \(F/u^2\)이 상수가 되어 궤도 방정식이 \(u'' + u = \)(상수)라는 단순 조화 방정식이 됩니다. 해는 "상수 + 코사인"이고, 코사인의 주기가 정확히 \(2\pi\)라서 한 바퀴 돌면 궤도가 제자리로 돌아와 닫힙니다. 힘이 역제곱에서 조금만 벗어나도 이 주기가 \(2\pi\)와 달라져 궤도가 조금씩 돌아갑니다(수성의 근일점 이동).

이것은 초점이 원점인 원뿔 곡선입니다. 이심률 \(\epsilon\)은 에너지와 \(E = \frac{\gamma^2\mu}{2\ell^2}(\epsilon^2 - 1)\)로 이어집니다: \(\epsilon = 0\) 원, \(0 < \epsilon < 1\) 타원, \(\epsilon = 1\) 포물선, \(\epsilon > 1\) 쌍곡선(5.2절 표와 같음). \(\phi\)가 \(2\pi\) 늘면 \(r\)이 제자리로 오므로 궤도가 닫힙니다.

5.3.3케플러 법칙

  • 제1법칙: 행성은 태양을 한 초점으로 하는 타원 궤도를 돈다. 위의 해 그대로다.
  • 제2법칙: 면적 속도 \(\frac{dA}{dt} = \frac12r^2\dot\phi = \frac{\ell}{2\mu}\)가 일정하다. 각운동량 보존이다(중심력이면 역제곱이 아니어도 성립).
  • 제3법칙: 타원 넓이 \(\pi ab\)를 면적 속도로 나누면 주기 \(\tau = \frac{2\pi ab\mu}{\ell}\). \(b^2 = ac\)를 쓰면
\[\tau^2 = \frac{4\pi^2\mu}{\gamma}a^3 = \frac{4\pi^2}{G(m_1 + m_2)}a^3.\]

주기의 제곱은 긴반지름의 세제곱에 비례하고, 비례 상수에는 두 질량의 합이 들어갑니다. 태양 질량이 행성보다 훨씬 크므로 모든 행성에서 거의 같은 상수가 됩니다. 쌍성의 주기와 궤도 크기를 재면 이 식으로 별의 질량을 구할 수 있습니다.

예제 5.3.1

지구 궤도(\(a = 1.496\times10^{11}\) m, \(\tau = 1\) 년 \(= 3.156\times10^7\) s)로 태양 질량을 구하여라.

풀이. \(M \approx \frac{4\pi^2a^3}{G\tau^2} = \frac{4\pi^2(1.496\times10^{11})^3}{6.674\times10^{-11}(3.156\times10^7)^2} \approx 1.99\times10^{30}\) kg.

요약
  1. 궤도 방정식 \(u'' = -u - \mu F/(\ell^2u^2)\).
  2. 역제곱: \(r = c/(1 + \epsilon\cos\phi)\), 원뿔 곡선.
  3. 케플러: 타원, 면적 속도 일정, \(\tau^2 = 4\pi^2a^3/(GM)\).

5.3.4연습문제

기본

  1. 핼리 혜성의 주기는 약 76년이다. 궤도 긴반지름은 몇 AU인가?
    답

    \(a = 76^{2/3} \approx 17.9\) AU.

5.3.2

예제근일점과 원일점으로 궤도 요소 구하기

궤도 방정식 · 이심률 · 케플러 제3법칙 · 문제 해결 전략

다루는 성취기준 [물리1-05-03]

출발점

궤도 \(r = \frac c{1 + \epsilon\cos\phi}\)에서 근일점 \(r_{\min} = \frac c{1 + \epsilon}\), 원일점 \(r_{\max} = \frac c{1 - \epsilon}\)입니다. 두 거리만 알면 긴반지름, 이심률, 주기, 각 점의 속력이 모두 나옵니다.

문제 해결 전략 · 궤도 요소 계산
  1. \(a = \frac{r_{\min} + r_{\max}}2\), \(\epsilon = \frac{r_{\max} - r_{\min}}{r_{\max} + r_{\min}}\).
  2. 케플러 제3법칙으로 주기.
  3. 각운동량 보존 \(r_{\min}v_{\max} = r_{\max}v_{\min}\)과 에너지로 속력.
  4. 알려진 값과 비교한다.

핼리 혜성의 근일점 거리는 0.586 AU, 원일점 거리는 35.1 AU이다(대략값). 긴반지름, 이심률, 주기, 근일점과 원일점의 속력 비를 구하여라.

풀이

  1. \(a = (0.586 + 35.1)/2 = 17.8\) AU.
    두 거리의 평균.
  2. \(\epsilon = (35.1 - 0.586)/(35.1 + 0.586) = 0.967\).
    1에 가까운 아주 길쭉한 타원.
  3. \(T = a^{3/2} = 17.8^{1.5} \approx 75\) 년.
    AU와 년 단위의 케플러 제3법칙.
  4. \(v_{\max}/v_{\min} = r_{\max}/r_{\min} = 35.1/0.586 \approx 60\).
    근일점과 원일점에서 속도는 지름에 수직이라 \(\ell = mrv\).

의미

혜성은 태양 근처를 아주 빠르게 지나고, 먼 곳에서는 느릿느릿 오래 머뭅니다(면적 속도 일정). 그래서 75년 주기의 대부분을 멀리서 보내고, 우리 눈에 보이는 기간은 몇 달뿐입니다.

검산

관측된 주기 약 76년(5.3절 연습문제)과 거의 같습니다. 근일점 거리 \(a(1 - \epsilon) = 17.8\times0.033 = 0.59\) AU로 처음 값과 맞습니다.
