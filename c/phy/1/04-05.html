  • 강제 진동 (4.3절), 푸리에 급수 (공통8 6.1절).

4.3절은 깔끔한 사인꼴 힘만 다뤘습니다. 실제로 미는 힘은 망치로 두드리기, 그네를 툭툭 밀기처럼 사인꼴이 아닌 경우가 많습니다. 이 절의 생각은 간단합니다. 주기적인 힘은 여러 진동수의 사인꼴로 쪼갤 수 있고(푸리에 급수), 방정식이 선형이라 각 조각의 응답을 따로 구해 더하면 됩니다. 그러면 고유 진동수와 맞는 조각 하나가 공명해 두드러지는 것이 보입니다.

4.5.1중첩 원리

운동 방정식 \(\ddot x + 2\beta\dot x + \omega_0^2x = f(t)\)는 선형입니다. 그래서 \(f_1(t)\)에 대한 해가 \(x_1\), \(f_2(t)\)에 대한 해가 \(x_2\)이면 \(f_1 + f_2\)에 대한 해는 \(x_1 + x_2\)입니다. 사인꼴 힘 하나에 대한 응답은 4.3절에서 구했으므로, 어떤 힘이든 사인꼴들의 합으로 나타낼 수 있으면 응답을 더해서 얻을 수 있습니다.

4.5.2푸리에 급수로 나누기

주기 \(\tau\)인 힘(\(\omega = 2\pi/\tau\))은

\[f(t) = \sum_{n=0}^{\infty}\left[a_n\cos n\omega t + b_n\sin n\omega t\right]\]

로 쓸 수 있습니다(\(a_n = \frac2\tau\int f\cos n\omega t\,dt\), \(a_0\)은 평균). 각 항에 4.3절을 쓰면 정상 상태 응답은

\[x(t) = \sum_n\left[A_n\cos(n\omega t - \delta_n) + B_n\sin(n\omega t - \delta_n)\right],\quad A_n = \frac{a_n}{\sqrt{(\omega_0^2 - n^2\omega^2)^2 + 4\beta^2n^2\omega^2}},\]

\(B_n\)도 \(b_n\)으로 같은 꼴, \(\delta_n\)은 진동수 \(n\omega\)에서의 위상입니다.

계수 공식의 뜻: \(\cos n\omega t\)와 \(\cos m\omega t\)(\(n \ne m\))를 곱해 한 주기 적분하면 0입니다. 그래서 \(f\)에 \(\cos n\omega t\)를 곱해 적분하면 다른 성분은 모두 지워지고 \(n\)번째 성분만 남습니다. 라디오가 여러 방송 가운데 하나만 골라 듣는 것과 같은 원리입니다.

4.5.3어느 성분이 남는가

각 성분은 \(n\omega\)가 \(\omega_0\)에 가까울수록 크게 증폭됩니다. 그래서 \(Q\)가 큰 진동자는 힘의 여러 진동수 성분 가운데 \(\omega_0\)에 가까운 하나만 골라 냅니다.

예제 4.5.1

주기 \(\tau\)마다 짧게 미는 힘(폭 \(\Delta\tau = \tau/4\), 세기 \(f_{\max}\)인 사각 펄스)으로 \(Q\)가 큰 진동자를 민다. 구동 주기가 진동자 주기의 두 배(\(\omega = \omega_0/2\))일 때 어떤 성분이 주로 응답하는가?

풀이. 펄스 열의 푸리에 계수는 \(a_n = \frac{2f_{\max}}{n\pi}\sin\frac{n\pi\Delta\tau}{\tau}\)입니다(시간 원점을 펄스 가운데에 두면 \(b_n = 0\)). \(\Delta\tau = \tau/4\)이면 \(a_2 = \frac{f_{\max}}{\pi}\sin\frac\pi2 = \frac{f_{\max}}\pi \ne 0\)이므로, \(2\omega = \omega_0\)인 둘째 성분이 공명해 진동자는 주로 진동수 \(\omega_0\)로 진동합니다. 그네를 두 번에 한 번씩 밀어도 그네가 크게 흔들리는 것과 같습니다. 반면 \(\Delta\tau = \tau/2\)이면 \(a_2 = 0\)이라 공명하지 않습니다.

이 생각은 악기의 음색(배음), 스펙트럼 분석, 전기 회로의 필터(물리학실험 A-1)에 그대로 쓰입니다. 주기가 없는 힘은 푸리에 변환(공통9 1단원)이나 그린 함수(물리4 이후)로 다룹니다.

요약
  1. 선형 방정식은 중첩: 힘을 나누고 응답을 더한다.
  2. 주기적인 힘 → 푸리에 급수 → 성분마다 4.3절의 진폭과 위상.
  3. \(n\omega \approx \omega_0\)인 성분이 공명해 두드러진다.

4.5.4연습문제

기본

  1. 예제 4.5.1에서 \(\omega = \omega_0/3\)이면 공명하는 성분은? 그 계수가 0이 되는 펄스 폭은?
    답

    셋째 성분 \(a_3 \propto \sin\frac{3\pi\Delta\tau}{\tau}\). \(\Delta\tau = \tau/3\)이면 0.
