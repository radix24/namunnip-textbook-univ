운동을 기술하려면 위치를 숫자로 적는 방법, 곧 좌표계가 필요합니다. 직교 좌표는 계산 규칙이 가장 단순합니다. 하지만 원을 그리며 도는 운동이나 한 점을 향해 당기는 힘은 극좌표나 구면 좌표로 써야 식이 짧아집니다. 곡선 좌표에는 함정이 하나 있습니다. 단위벡터의 방향이 입자를 따라 바뀌므로, 성분만 미분하면 틀린 답이 나옵니다. 이 절의 핵심은 그 바뀌는 몫을 빠뜨리지 않는 것입니다.

1.1.1직교 좌표

위치 \(\mathbf r = x\hat{\mathbf x} + y\hat{\mathbf y} + z\hat{\mathbf z}\)에서 단위벡터 \(\hat{\mathbf x}, \hat{\mathbf y}, \hat{\mathbf z}\)는 어디서나 같은 방향이라 시간에 대해 상수입니다. 그래서 성분을 그대로 미분하면 됩니다: \(\dot{\mathbf r} = \dot x\hat{\mathbf x} + \dot y\hat{\mathbf y} + \dot z\hat{\mathbf z}\). 점(\(\dot{}\))은 시간 미분입니다.

처음 보는 수학 · 벡터의 미분 벡터를 미분한다는 것은 성분마다 따로 미분한다는 뜻입니다. 예를 들어 \(\mathbf r = (3t, t^2)\)이면 \(\dot{\mathbf r} = (3, 2t)\), \(\ddot{\mathbf r} = (0, 2)\)입니다. 고등학교에서 \(x(t)\), \(y(t)\)를 따로 미분하던 것을 한 줄에 적었을 뿐입니다. 점 하나는 시간으로 한 번, 점 두 개는 두 번 미분한 것이고, 모자(\(\hat{}\))를 쓴 글자는 길이가 1인 방향 벡터(단위벡터)입니다.

1.1.22차원 극좌표

원운동이나 중심력 문제는 극좌표 \((r, \phi)\)가 편합니다. 단위벡터

\[\hat{\mathbf r} = \cos\phi\,\hat{\mathbf x} + \sin\phi\,\hat{\mathbf y}, \qquad \hat{\boldsymbol\phi} = -\sin\phi\,\hat{\mathbf x} + \cos\phi\,\hat{\mathbf y}\]

는 입자가 움직이면 방향이 바뀝니다. 미분하면

\[\dot{\hat{\mathbf r}} = \dot\phi\,\hat{\boldsymbol\phi}, \qquad \dot{\hat{\boldsymbol\phi}} = -\dot\phi\,\hat{\mathbf r}.\]

왜 이렇게 되는지는 그림으로 보면 쉽습니다. 입자가 \(d\phi\)만큼 돌면 \(\hat{\mathbf r}\)도 같은 각만큼 돌아갑니다. 길이 1인 화살표가 \(d\phi\)만큼 돌면 끝이 \(d\phi\)만큼, 도는 방향(\(\hat{\boldsymbol\phi}\))으로 움직입니다. 그래서 \(d\hat{\mathbf r} = d\phi\,\hat{\boldsymbol\phi}\)입니다. \(\hat{\boldsymbol\phi}\)도 함께 돌면서 끝이 안쪽(\(-\hat{\mathbf r}\))으로 움직입니다.

위치 \(\mathbf r = r\hat{\mathbf r}\)를 곱의 미분으로 미분합니다. 한 번 미분하면 \(\dot{\mathbf r} = \dot r\hat{\mathbf r} + r\dot{\hat{\mathbf r}} = \dot r\hat{\mathbf r} + r\dot\phi\hat{\boldsymbol\phi}\)입니다. 한 번 더 미분하면 두 항 모두에서 곱의 미분이 나옵니다.

\[\ddot{\mathbf r} = \ddot r\hat{\mathbf r} + \dot r\dot\phi\hat{\boldsymbol\phi} + (\dot r\dot\phi + r\ddot\phi)\hat{\boldsymbol\phi} - r\dot\phi^2\hat{\mathbf r}.\]

같은 방향끼리 모으면 다음 결과가 됩니다.

정리 1.1.1 \[\mathbf v = \dot r\,\hat{\mathbf r} + r\dot\phi\,\hat{\boldsymbol\phi}, \qquad \mathbf a = (\ddot r - r\dot\phi^2)\,\hat{\mathbf r} + (r\ddot\phi + 2\dot r\dot\phi)\,\hat{\boldsymbol\phi}.\]
  • \(-r\dot\phi^2\): 구심 가속도. 반지름이 일정한 원운동에서는 이것만 남는다(\(\omega^2r\)).
  • \(2\dot r\dot\phi\): 반지름 방향으로 움직이면서 돌 때 생기는 항(6.1절 코리올리 힘과 관련).
  • \(r\ddot\phi\): 각속도가 바뀔 때의 접선 가속도.
주의극좌표 가속도의 \(\hat{\mathbf r}\) 성분은 \(\ddot r\)가 아닙니다. 반지름이 변하지 않는 원운동(\(\ddot r = 0\))에서도 가속도는 0이 아니라 \(-r\dot\phi^2\)입니다. 직교 좌표처럼 성분만 두 번 미분하는 습관이 가장 흔한 실수입니다.

\(r\ddot\phi + 2\dot r\dot\phi = \frac1r\frac{d}{dt}(r^2\dot\phi)\)입니다. 중심력이면 \(\hat{\boldsymbol\phi}\) 성분의 힘이 0이므로 \(r^2\dot\phi\)가 일정하고, 이것이 각운동량 보존이며 케플러 제2법칙입니다(5.3절).

1.1.3원통 좌표와 구면 좌표

원통 좌표 \((\rho, \phi, z)\)는 극좌표에 \(z\)를 더한 것이라 \(\mathbf v = \dot\rho\hat{\boldsymbol\rho} + \rho\dot\phi\hat{\boldsymbol\phi} + \dot z\hat{\mathbf z}\)입니다(가속도도 극좌표 결과에 \(\ddot z\hat{\mathbf z}\)를 더함).

구면 좌표 \((r, \theta, \phi)\)(\(\theta\)는 \(z\)축에서 잰 극각)에서는 \(x = r\sin\theta\cos\phi\), \(y = r\sin\theta\sin\phi\), \(z = r\cos\theta\)이고

\[\mathbf v = \dot r\,\hat{\mathbf r} + r\dot\theta\,\hat{\boldsymbol\theta} + r\sin\theta\,\dot\phi\,\hat{\boldsymbol\phi}.\]

각 항은 좌표 하나만 조금 바꿀 때 움직이는 거리(\(dr\), \(r\,d\theta\), \(r\sin\theta\,d\phi\))를 시간으로 나눈 것으로 기억하면 쉽습니다. 구면 좌표의 가속도는 길어서 필요할 때 유도하거나 찾아 씁니다. 라그랑주 역학(물리4)을 쓰면 이런 복잡한 가속도를 직접 구하지 않아도 운동 방정식을 얻을 수 있습니다.

요약
  1. 극좌표 단위벡터는 시간에 따라 바뀐다: \(\dot{\hat{\mathbf r}} = \dot\phi\hat{\boldsymbol\phi}\), \(\dot{\hat{\boldsymbol\phi}} = -\dot\phi\hat{\mathbf r}\).
  2. \(\mathbf a = (\ddot r - r\dot\phi^2)\hat{\mathbf r} + (r\ddot\phi + 2\dot r\dot\phi)\hat{\boldsymbol\phi}\).
  3. 구면: \(\mathbf v = \dot r\hat{\mathbf r} + r\dot\theta\hat{\boldsymbol\theta} + r\sin\theta\dot\phi\hat{\boldsymbol\phi}\).

1.1.4연습문제

기본

  1. 개미가 일정한 각속도 \(\omega\)로 도는 판 위에서 중심으로부터 일정한 속력 \(u\)로 바깥쪽으로 기어간다(\(r = ut\)). 개미의 가속도를 극좌표로 구하여라.
    답

    \(\ddot r = 0\), \(\dot\phi = \omega\), \(\ddot\phi = 0\). \(\mathbf a = -ut\omega^2\hat{\mathbf r} + 2u\omega\hat{\boldsymbol\phi}\).

발전

  1. \(\dot{\hat{\mathbf r}} = \dot\phi\hat{\boldsymbol\phi}\)를 성분으로 미분해 확인하고, 정리 1.1.1의 가속도를 유도하여라.
    답

    \(\frac{d}{dt}(\cos\phi, \sin\phi) = \dot\phi(-\sin\phi, \cos\phi)\). \(\mathbf v = \dot r\hat{\mathbf r} + r\dot\phi\hat{\boldsymbol\phi}\)를 다시 미분해 \(\hat{\mathbf r}\), \(\hat{\boldsymbol\phi}\) 성분을 모은다.

실습극좌표 가속도의 네 항 눈으로 보기

실습 · 반지름 방향과 각 방향 성분

다루는 성취기준 [물리1-01-01]

목표

세 가지 운동에서 가속도를 반지름 방향 \(a_r = \ddot r - r\dot\phi^2\)와 각 방향 \(a_\phi = r\ddot\phi + 2\dot r\dot\phi\)로 나누어 화살표로 봅니다. 성분만 두 번 미분하면 왜 틀리는지 몸으로 익힙니다. 성취기준 [물리1-01-01].

준비

회색 선은 전체 경로, 연한 파랑은 지금까지 지나온 자취입니다. 파란 화살표는 속도, 빨간 화살표는 \(a_r\), 주황 화살표는 \(a_\phi\)입니다. 화살표 길이 배율은 보기 좋게 바꿀 수 있고, 아주 긴 화살표는 길이 1에서 자릅니다(값은 출력을 보세요). 경로를 고른 뒤 시간 막대를 움직이거나 재생하세요.

절차

  1. 회전판 위 개미에서 t = 5 s의 \(a_r\)와 \(a_\phi\)를 적는다. 개미는 판 위에서 일정한 속력으로 기어가는데(\(\ddot r = 0\)) 가속도가 0이 아님을 확인한다.
  2. 빨라지는 원운동으로 바꿔 t를 0에서 10까지 움직이며 \(a_r\)와 \(a_\phi\)가 어떻게 바뀌는지 본다.
  3. 안쪽으로 감기는 나선으로 바꿔 \(a_\phi\)와 \(r^2\dot\phi\)를 여러 시각에서 적는다.

기대 결과

  • 개미, t = 5 s: \(r = 0.5\), \(a_r = 0 - 0.5 = -0.5\), \(a_\phi = 0 + 0.2 = 0.2\). 반지름 방향으로 등속인데도 중심 쪽 가속도와 옆쪽 가속도(\(2\dot r\dot\phi\), 코리올리 항)가 있다.
  • 빨라지는 원운동: \(a_\phi = 0.1\)로 일정하고, \(a_r = -(0.1t)^2\)은 점점 커진다(t = 5 s에서 −0.250).
  • 나선: 어느 시각에서나 \(a_\phi = 0\)이고 \(r^2\dot\phi = 0.5\)가 일정하다. 안쪽으로 갈수록 빨리 돈다(t = 5 s에서 \(r = 0.6\), \(\dot\phi = 1.389\) rad/s).

분석

  1. 나선에서 \(a_\phi = 0\)인 것이 "힘이 중심을 향한다"는 뜻임을 \(a_\phi = \frac1r\frac{d}{dt}(r^2\dot\phi)\)로 설명해 보세요.
  2. 개미의 \(2\dot r\dot\phi\) 항은 판 위에 선 사람에게 어떤 힘으로 느껴질까요(6.1절)?
