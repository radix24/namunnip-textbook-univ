뉴턴은 지구 전체가 사과를 당기는 힘을 계산하면서, 지구를 중심에 있는 점 하나로 보아도 되는지 고민했습니다. 이 절의 결론은 "구대칭이면 된다"입니다. 구 껍질 바깥에서 껍질은 중심의 점 질량과 같고, 껍질 안에서는 사방에서 당기는 힘이 정확히 지워집니다. 이 사실 하나로 행성, 별, 지구 내부의 중력을 간단히 계산합니다.

7.1.1용어

  • 중력장 \(\mathbf g\): 단위 질량이 받는 중력 \(\mathbf F/m\).
  • 중력 퍼텐셜 \(\Phi\): 단위 질량당 퍼텐셜 에너지. \(\mathbf g = -\nabla\Phi\).
  • 구대칭: 밀도가 중심에서의 거리 \(r\)에만 의존하는 분포.
  • 중력의 Gauss 법칙: \(\oint\mathbf g\cdot d\mathbf A = -4\pi GM_{\text{안}}\).

7.1.2껍질의 퍼텐셜 직접 계산

목적: 껍질 바깥과 안의 퍼텐셜을 적분으로 확인하기. 반지름 \(R\), 질량 \(M\)인 껍질과 중심에서 \(r\)만큼 떨어진 점을 생각합니다.

  1. 껍질을 극각 \(\theta\)의 고리로 자른다. 고리 질량 \(dM = \frac M2\sin\theta\,d\theta\)(고리 넓이 \(2\pi R\sin\theta\cdot R\,d\theta\)를 전체 넓이 \(4\pi R^2\)로 나눈 몫만큼의 질량), 점까지의 거리 \(s = \sqrt{R^2 + r^2 - 2Rr\cos\theta}\). 고리의 모든 점이 같은 거리라 퍼텐셜은 \(-G\,dM/s\).
  2. \(ds = \frac{Rr\sin\theta}s d\theta\)로 변수를 \(s\)로 바꾸면 \(\Phi = -\frac{GM}{2Rr}\int ds\). 피적분 함수가 상수가 되도록 바꾼 것이다.
  3. 바깥(\(r > R\)): \(s\)는 \(r - R\)에서 \(r + R\)까지, \(\Phi = -\frac{GM}{2Rr}\cdot2R = -\frac{GM}r\). 안(\(r < R\)): \(s\)는 \(R - r\)에서 \(R + r\)까지, \(\Phi = -\frac{GM}R\)(상수).
정리 7.1.1 (구 껍질 정리)

균일한 구 껍질은 바깥에서 중심의 점 질량과 같은 중력을 주고, 안쪽에서는 중력이 0이다.

안쪽 퍼텐셜이 상수이므로 \(\mathbf g = -\nabla\Phi = 0\)입니다. 가까운 쪽 껍질은 적지만 가깝고, 먼 쪽은 멀지만 많아서, 거리의 제곱과 넓이의 제곱이 정확히 지워집니다.

7.1.3Gauss 법칙으로 빠르게

구대칭이면 \(\mathbf g = -g(r)\hat{\mathbf r}\)이고, 반지름 \(r\)인 구면에 Gauss 법칙을 쓰면 \(g(r) = \frac{GM(r)}{r^2}\)입니다. \(M(r)\)은 반지름 \(r\) 안의 질량입니다. 균일한 공(밀도 \(\rho\))의 안쪽에서는 \(M(r) = \frac43\pi\rho r^3\)이라 \(g = \frac43\pi G\rho r\), 중심에서 거리에 비례합니다.

처음 보는 수학 · 닫힌 곡면 적분 \(\oint\mathbf g\cdot d\mathbf A\)는 닫힌 곡면을 작은 조각으로 나누어 (조각을 수직으로 뚫고 나가는 \(\mathbf g\) 성분) × (조각 넓이)를 모두 더한 것입니다. 구대칭이면 구면 어디서나 \(g\)의 크기가 같고 면에 수직이라, 합은 그냥 \(-g\times4\pi r^2\)입니다. 이것을 \(-4\pi GM(r)\)과 같다고 놓으면 \(g = GM(r)/r^2\)이 바로 나옵니다.
예제 7.1.2

지구를 균일한 공(반지름 6370 km, 표면 \(g = 9.8\) m/s²)으로 볼 때 깊이 1000 km의 \(g\)는? 지구를 꿰뚫는 굴에 떨어뜨린 물체가 반대편까지 가는 시간은?

풀이. \(g(r) = 9.8\times\frac{5370}{6370} = 8.26\) m/s². 굴 속에서 \(\ddot r = -\frac g Rr\)은 단순 조화 운동이고 \(\omega = \sqrt{g/R} = \sqrt{9.8/6.37\times10^6} = 1.24\times10^{-3}\) rad/s. 반대편까지 반 주기 \(\pi/\omega \approx 2530\) s, 약 42분입니다(실제 지구는 중심이 더 빽빽해 조금 다름).

주의껍질 정리는 구대칭일 때만 맞습니다. 납작한 지구나 원판 은하에서는 "질량이 중심에 모인 것처럼"이 성립하지 않습니다. 또 껍질 안에서 중력이 0이지 퍼텐셜이 0인 것은 아닙니다. 퍼텐셜은 \(-GM/R\)로 일정합니다.
요약
  1. 껍질: 바깥은 점 질량, 안은 중력 0(퍼텐셜 일정).
  2. 구대칭이면 \(g(r) = GM(r)/r^2\).
  3. 균일한 공 안에서는 \(g \propto r\): 굴 속 운동은 단순 조화 운동.

7.1.4연습문제

기본

  1. 균일한 공(질량 \(M\), 반지름 \(R\)) 안쪽의 중력 퍼텐셜을 구하여라.
    답

    \(\Phi(r) = -\frac{GM}{2R^3}(3R^2 - r^2)\). 중심에서 \(-\frac{3GM}{2R}\).

7.1.2

예제속이 빈 행성 안의 무게

구 껍질 정리 · Gauss 법칙 · 문제 해결 전략

다루는 성취기준 [물리1-07-01]

출발점

구대칭 질량 분포에서 반지름 \(r\)의 중력은 그 안쪽 질량 \(M(r)\)만으로 정해집니다: \(g = GM(r)/r^2\). 바깥 껍질들은 안쪽에 아무 힘도 주지 않습니다.

문제 해결 전략 · 구대칭 중력장
  1. 반지름 \(r\) 안쪽 질량 \(M(r)\)을 구한다.
  2. \(g = GM(r)/r^2\).
  3. 영역마다(빈 곳, 껍질 속, 바깥) 반복한다.
  4. 경계에서 \(g\)가 이어지는지 확인한다.

바깥 반지름 \(R\), 안쪽 반지름 \(R/2\)인 두꺼운 껍질(균일 밀도 \(\rho\))로 된 행성이 있다. 중심, 안쪽 빈 곳, 껍질 가운데(\(r = 3R/4\)), 표면의 중력을 표면값 \(g_s\)의 비로 구하여라.

풀이

  1. 전체 질량 \(M = \frac43\pi\rho(R^3 - R^3/8) = \frac43\pi\rho\cdot\frac78R^3\), \(g_s = GM/R^2\).
    껍질 부피.
  2. 빈 곳(\(r < R/2\)): 안쪽 질량 0이라 \(g = 0\). 중심도 0.
    껍질 정리.
  3. \(r = 3R/4\): \(M(r) = \frac43\pi\rho\left(\frac{27}{64} - \frac18\right)R^3 = \frac43\pi\rho\cdot\frac{19}{64}R^3\). \(g = \frac{GM(r)}{r^2}\).
    안쪽 일부만.
  4. 비: \(\frac{g}{g_s} = \frac{19/64}{7/8}\cdot\frac{R^2}{(3R/4)^2} = \frac{19}{56}\cdot\frac{16}9 \approx 0.603\).
    표면은 1.

의미

속이 빈 행성의 안쪽 빈 곳에서는 무중력입니다. 공상 과학의 "지구 속 공동 세계"에 사람이 땅에 붙어 살 수 없는 까닭입니다.

검산

\(r = R/2\)에서 \(M(r) = 0\)이라 0, \(r = R\)에서 비가 1. 껍질 속에서 0에서 1로 이어집니다.
