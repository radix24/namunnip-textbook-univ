1.R.1

연습벡터와 좌표계 연습 문제

문제 4 · 계산·판단 · 힌트 2단계

다루는 성취기준 [물리1-01-01] [물리1-01-02] [물리1-01-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산반지름 2 m인 원을 각속도 \(\dot\phi = 3t\) (rad/s)로 도는 입자의 \(t = 1\) s 가속도 크기는? [01-01]

    힌트 1

    \(r\) 일정: \(a_r = -r\dot\phi^2\), \(a_\phi = r\ddot\phi\).

    힌트 2

    \(\ddot\phi = 3\).

    풀이

    \(a_r = -2\times9 = -18\), \(a_\phi = 6\). 크기 \(\sqrt{324 + 36} \approx 19.0\) m/s².

  2. 판단한 학생이 극좌표 속도를 \(\dot r\hat{\mathbf r} + \dot\phi\hat{\boldsymbol\phi}\)라 썼다. 무엇이 틀렸나? [01-01]

    힌트 1

    단위를 보세요.

    힌트 2

    \(\dot\phi\)는 rad/s.

    풀이

    각 성분은 \(r\dot\phi\)여야 한다. \(\dot\phi\)만 쓰면 단위가 m/s가 아니다.

  3. 계산축을 \(z\)축 둘레로 30° 돌리면 벡터 \((2, 0, 1)\)의 새 성분은? [01-02]

    힌트 1

    \(a_x' = a_x\cos\phi + a_y\sin\phi\).

    힌트 2

    \(a_y' = -a_x\sin\phi + a_y\cos\phi\).

    풀이

    \((1.732, -1, 1)\). 길이 \(\sqrt5\)로 그대로.

  4. 계산\(f = xy + yz\)의 점 \((1, 2, 3)\)에서 기울기와, 방향 \((1, 0, 0)\)으로의 방향 도함수는? [01-03]

    힌트 1

    \(\nabla f = (y, x + z, y)\).

    힌트 2

    방향 도함수 = \(\nabla f\cdot\hat{\mathbf u}\).

    풀이

    \(\nabla f = (2, 4, 2)\), 방향 도함수 2.
