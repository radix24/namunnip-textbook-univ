  • 주기가 없는 함수를 Fourier 변환으로 진동수 성분으로 나눈다.
  • 미분이 곱셈이 되는 성질로 선형 미분방정식을 대수 방정식으로 바꾼다.

먼저 알아야 할 것
  • Fourier 적분과 변환 (공통9 1.1절, 1.2절), Fourier 급수 (3.1절).

번개 한 번, 짧은 레이저 펄스, 공을 한 번 친 충격은 반복되지 않습니다. 주기를 무한히 길게 늘리면 Fourier 급수의 띄엄띄엄한 진동수가 촘촘해져 연속 변수가 되고, 합이 적분이 됩니다. 이것이 Fourier 변환입니다. 물리에서 가장 쓸모 있는 성질은 미분이 곱셈으로 바뀐다는 것, 그리고 "짧은 신호일수록 진동수가 넓게 퍼진다"는 것입니다.

3.2.1용어

  • Fourier 변환: \(\tilde f(k) = \int_{-\infty}^{\infty}f(x)e^{-ikx}dx\). 이 교재의 약속이며, 교재마다 \(2\pi\)를 두는 자리가 다르다.
  • 역변환: \(f(x) = \frac1{2\pi}\int\tilde f(k)e^{ikx}dk\).
  • 합성곱: \((f*g)(x) = \int f(x')g(x - x')dx'\). 한 함수를 다른 함수로 "번지게" 한 것.
  • 전달 함수(그린 함수의 변환): 입력의 각 진동수 성분에 곱해지는 응답 배율.

3.2.2미분방정식 풀기

목적: 미분을 없애 대수 문제로 만들기. 부분적분으로 \(\widetilde{f'}(k) = ik\tilde f(k)\)입니다(무한대에서 \(f \to 0\)이라 경계 항이 사라짐).

  1. 감쇠 진동자에 임의의 힘: \(\ddot x + \gamma\dot x + \omega_0^2x = f(t)/m\). 시간에 대한 변환에서는 \(d/dt \to i\omega\)로 쓴다.
  2. 양변을 변환하면 \((-\omega^2 + i\gamma\omega + \omega_0^2)\tilde x = \tilde f/m\). 미분이 사라졌다.
  3. \(\tilde x(\omega) = \chi(\omega)\tilde f(\omega)\), \(\chi = \frac{1/m}{\omega_0^2 - \omega^2 + i\gamma\omega}\). \(\chi\)는 물리1 4.3절의 공명 곡선 그 자체다.
  4. 역변환하면 합성곱 정리로 \(x(t) = \int G(t - t')f(t')dt'\). \(G\)는 \(\chi\)의 역변환(충격 하나에 대한 응답)이다.

3.2.3합성곱 정리와 폭

목적: 번짐(합성곱)을 곱셈으로 다루기.

정리 3.2.1 \[\widetilde{f*g} = \tilde f\,\tilde g,\qquad \int e^{-x^2/2\sigma^2}e^{-ikx}dx = \sqrt{2\pi}\sigma\,e^{-\sigma^2k^2/2}.\]

가우스 함수의 변환은 다시 가우스이고, 폭이 \(\sigma\)에서 \(1/\sigma\)로 바뀝니다. 그래서 \(\Delta x\,\Delta k \gtrsim\) (1 정도)입니다. 길이 1 ps인 레이저 펄스는 진동수가 약 \(10^{12}\) Hz 폭으로 퍼지고, 양자역학에서는 \(p = \hbar k\)라 불확정성 원리가 됩니다.

예제 3.2.2

\(f(x) = e^{-a|x|}\) (\(a > 0\))의 Fourier 변환을 구하고, \(a = 2\)일 때 \(\tilde f\)가 최댓값의 절반이 되는 \(k\)를 구하여라.

풀이. 양쪽으로 나누면 \(\int_0^\infty e^{-(a + ik)x}dx + \int_0^\infty e^{-(a - ik)x}dx = \frac1{a + ik} + \frac1{a - ik} = \frac{2a}{a^2 + k^2}\)(로런츠 꼴). 최댓값은 \(k = 0\)에서 \(2/a = 1\). 절반이 되려면 \(a^2 + k^2 = 2a^2\), \(k = \pm a = \pm2\). 함수가 \(1/a\) 정도 폭이면 변환은 \(a\) 정도 폭입니다.

주의Fourier 변환의 정의에서 \(2\pi\)와 부호의 위치는 분야마다 다릅니다(\(\frac1{\sqrt{2\pi}}\)을 양쪽에 나누는 약속, 진동수 \(\nu\)를 쓰는 약속 등). 다른 교재의 공식을 옮길 때는 정의부터 맞추세요. 또 \(\sin x\)처럼 무한히 계속되는 함수는 보통 의미의 적분이 수렴하지 않아 델타 함수로 다뤄야 합니다.
요약
  1. \(\tilde f(k) = \int fe^{-ikx}dx\), \(\widetilde{f'} = ik\tilde f\): 미분방정식 → 대수 방정식.
  2. 응답 = 전달 함수 × 입력(진동수 공간) = 그린 함수와 입력의 합성곱(시간 공간).
  3. 폭과 띠폭은 반비례: \(\Delta x\Delta k \gtrsim 1\).

3.2.4연습문제

기본

  1. 폭 \(2a\), 높이 1인 사각 펄스의 변환을 구하고, 처음 0이 되는 \(k\)를 구하여라.
    답

    \(\int_{-a}^{a}e^{-ikx}dx = \frac{2\sin ka}{k}\). 처음 0은 \(k = \pi/a\). 펄스가 좁을수록 넓게 퍼진다.

3.2.2

예제RC 저역 통과 회로의 전달 함수와 합성곱

Fourier 변환 · 전달 함수 · 그린 함수 · 문제 해결 전략

다루는 성취기준 [물리18-03-02]

출발점

선형 계는 진동수 공간에서 "출력 = 전달 함수 × 입력", 시간 공간에서 "출력 = 그린 함수와 입력의 합성곱"입니다. 두 그림은 합성곱 정리로 같습니다.

문제 해결 전략 · 선형 계의 응답
  1. 미분방정식에 \(e^{i\omega t}\)를 넣어 전달 함수 \(H(\omega)\)를 구한다.
  2. \(H\)의 역변환으로 그린 함수 \(G(t)\)(충격 응답)를 구한다.
  3. 출력 \(V(t) = \int G(t - t')V_{in}(t')dt'\)로 계산한다.
  4. 긴 시간 극한과 짧은 시간 극한을 확인한다.

저항 \(R\)과 축전기 \(C\)로 된 회로 \(RC\dot V + V = V_{in}(t)\)에 \(t = 0\)부터 \(V_0\)를 켰다. 전달 함수, 그린 함수, 출력 전압을 구하고 \(RC = 1\) ms일 때 \(t = 2\) ms의 출력을 구하여라.

풀이

  1. \(V = He^{i\omega t}\), \(V_{in} = e^{i\omega t}\)를 넣으면 \((i\omega RC + 1)H = 1\), \(H = \frac1{1 + i\omega\tau}\) (\(\tau = RC\)).
    미분이 \(i\omega\) 곱하기로 바뀐다.
  2. \(|H| = 1/\sqrt{1 + \omega^2\tau^2}\): \(\omega \ll 1/\tau\)는 통과, \(\omega \gg 1/\tau\)는 줄어든다.
    저역 통과 필터. 차단 진동수 \(1/(2\pi\tau) \approx 159\) Hz.
  3. 역변환: \(G(t) = \frac1\tau e^{-t/\tau}\) (\(t > 0\)), \(t < 0\)이면 0.
    충격을 주기 전에는 반응하지 않는다(인과율). 예제 3.2.2의 \(e^{-a|x|}\) 변환을 반쪽만 쓴 것.
  4. \(V(t) = \int_0^t\frac1\tau e^{-(t - t')/\tau}V_0\,dt' = V_0(1 - e^{-t/\tau})\). \(t = 2\tau\)이면 \(V_0(1 - e^{-2}) \approx 0.865V_0\).
    합성곱: 지난 입력을 지수 가중치로 더했다.

의미

축전기는 지난 입력을 \(\tau\) 정도 "기억"합니다. 그 기억이 그린 함수 \(e^{-t/\tau}/\tau\)이고, 진동수 공간에서는 빠른 변화를 깎아내는 필터로 보입니다. 같은 수학이 감쇠 진동자(물리1 4.3절)와 측정 장치의 응답 시간에 그대로 쓰입니다.

검산

\(V = V_0(1 - e^{-t/\tau})\)를 넣으면 \(RC\dot V + V = V_0e^{-t/\tau} + V_0 - V_0e^{-t/\tau} = V_0\). 맞고, \(V(0) = 0\)도 맞습니다.
