  • 극점에서 유수를 구한다.

먼저 알아야 할 것
  • 로랑 급수와 유수 (공통9 5.2절, 5.4절), 실수 적분 계산 (공통9 5.5절), 해석 함수 (4.1절).

\(\int_{-\infty}^{\infty}\frac{dx}{1 + x^2}\)처럼 실수만 나오는 적분을 복소수로 계산하는 것은 돌아가는 길처럼 보입니다. 그러나 해석 함수의 적분은 경로를 마음대로 바꿔도 되고, 바뀌는 것은 극점을 넘을 때뿐입니다. 그래서 적분 전체가 극점에서의 숫자 하나(유수)로 결정됩니다. 부정적분을 못 구하는 적분도 몇 줄로 끝납니다.

4.2.1용어

  • 극점: \(f\)가 무한대로 가는 고립된 점. \((z - z_0)^m f\)가 유한하면 \(m\)차 극점.
  • 유수 \(\text{Res}(f, z_0)\): 로랑 급수에서 \((z - z_0)^{-1}\) 항의 계수.
  • 유수 정리: \(\oint_Cf\,dz = 2\pi i\sum(\text{안쪽 극점의 유수})\). 경로는 시계 반대 방향.
  • Jordan 보조정리: \(e^{ikz}\) (\(k > 0\))가 붙은 적분에서 위쪽 큰 반원의 기여가 0으로 간다는 정리.

4.2.2유수 구하기

목적: 로랑 급수를 다 쓰지 않고 \(-1\)차 계수만 빨리 얻기.

  • 1차 극점: \(\text{Res} = \lim_{z\to z_0}(z - z_0)f(z)\). \(f = p/q\)이고 \(q(z_0) = 0\)이면 \(p(z_0)/q'(z_0)\).
  • \(m\)차 극점: \(\text{Res} = \frac1{(m-1)!}\lim\frac{d^{m-1}}{dz^{m-1}}[(z - z_0)^mf]\).

4.2.3실수축 적분을 반원으로 닫기

  1. 실수축의 \(-R\)부터 \(R\)까지에 위쪽 반원(반지름 \(R\))을 이어 닫힌 경로를 만든다. 유수 정리를 쓰려면 닫힌 경로가 필요하다.
  2. 반원 위의 적분이 \(R \to \infty\)에서 0으로 가는지 확인한다. \(|f| \lesssim 1/R^2\)이면 (길이 \(\pi R\)) × \(1/R^2\) → 0.
  3. 위쪽 반평면 안의 극점의 유수를 더해 \(2\pi i\)를 곱한다. 남는 것이 실수축 적분이다.
예제 4.2.1

\(I = \int_{-\infty}^{\infty}\frac{dx}{(x^2 + 1)(x^2 + 4)}\)를 구하여라.

풀이. 분모가 \(x^4\)처럼 커서 반원 기여는 0. 위쪽 극점은 \(i\)와 \(2i\)(1차). \(\text{Res}_{i} = \frac1{(2i)(i^2 + 4)} = \frac1{6i}\), \(\text{Res}_{2i} = \frac1{((2i)^2 + 1)(4i)} = \frac1{-12i}\). \(I = 2\pi i\left(\frac1{6i} - \frac1{12i}\right) = 2\pi\cdot\frac1{12} = \frac\pi6 \approx 0.5236\). 검산: 부분분수로 \(\frac13\left(\frac1{x^2 + 1} - \frac1{x^2 + 4}\right)\)를 적분하면 \(\frac13(\pi - \frac\pi2) = \frac\pi6\).

물리에서는 \(\int\frac{e^{i\omega t}d\omega}{\omega_0^2 - \omega^2 + i\gamma\omega}\)처럼 감쇠 진동자의 그린 함수를 구할 때 씁니다. 극점이 모두 위쪽 반평면에 있어, \(t < 0\)이면 아래로 닫아 결과가 0이 됩니다. "힘을 주기 전에는 반응하지 않는다"는 인과율이 극점의 위치로 나타납니다.

주의반원의 기여가 0인지 확인하지 않고 유수만 더하면 틀릴 수 있습니다. \(\int\frac{x\,dx}{x^2 + 1}\)은 반원 기여가 0으로 가지 않고 적분 자체도 수렴하지 않습니다. 또 위쪽으로 닫았으면 위쪽 극점만 셉니다. 아래쪽으로 닫으면 경로가 시계 방향이라 \(-2\pi i\)를 곱해야 합니다.
요약
  1. 1차 극점 유수 \(p(z_0)/q'(z_0)\).
  2. 실수축 + 큰 반원으로 닫고, 반원 기여 0을 확인, \(2\pi i\sum\text{Res}\).
  3. 극점 위치는 물리의 인과율과 이어진다.

4.2.4연습문제

기본

  1. \(\int_{-\infty}^{\infty}\frac{dx}{x^2 + a^2}\) (\(a > 0\))을 유수로 구하여라.
    답

    극점 \(ia\), 유수 \(\frac1{2ia}\). \(2\pi i\cdot\frac1{2ia} = \frac\pi a\).

  2. \(\int_{-\infty}^{\infty}\frac{\cos x}{x^2 + 1}dx\)를 구하여라(\(e^{iz}\)의 실수부를 쓴다).
    답

    \(\oint\frac{e^{iz}}{z^2 + 1}\): 극점 \(i\), 유수 \(\frac{e^{-1}}{2i}\). 결과 \(\pi/e \approx 1.156\).

4.2.2

예제각도 적분을 단위원 위의 유수로

유수 정리 · 단위원 치환 · 문제 해결 전략

다루는 성취기준 [물리18-04-02]

출발점

\(0\)부터 \(2\pi\)까지의 삼각함수 적분은 \(z = e^{i\theta}\)로 바꾸면 단위원을 한 바퀴 도는 복소 적분이 됩니다. \(d\theta = \frac{dz}{iz}\), \(\cos\theta = \frac12(z + z^{-1})\).

문제 해결 전략 · 삼각함수의 한 주기 적분
  1. \(z = e^{i\theta}\)로 바꾸어 유리 함수로 만든다.
  2. 단위원 안쪽에 있는 극점만 고른다.
  3. 유수를 구해 \(2\pi i\)를 곱한다.
  4. 특수한 값(예: \(b = 0\))으로 결과를 점검한다.

\(I = \int_0^{2\pi}\frac{d\theta}{a + b\cos\theta}\) (\(a > |b|\))를 구하여라. 이 적분은 이심률 있는 궤도의 시간 평균 등에 나온다.

풀이

  1. \(I = \oint\frac{dz/iz}{a + \frac b2(z + 1/z)} = \oint\frac{2\,dz}{i(bz^2 + 2az + b)}\).
    분모 분자에 \(2z\)를 곱해 정리.
  2. 극점 \(z_\pm = \frac{-a \pm\sqrt{a^2 - b^2}}b\). \(z_+z_- = 1\)이고 \(|z_+| < 1\).
    두 근의 곱이 1이라 하나는 안쪽, 하나는 바깥.
  3. \(\text{Res}_{z_+} = \frac2{i\,b(z_+ - z_-)} = \frac2{i\cdot2\sqrt{a^2 - b^2}}\).
    1차 극점: \(p/q'\).
  4. \(I = 2\pi i\cdot\frac1{i\sqrt{a^2 - b^2}} = \frac{2\pi}{\sqrt{a^2 - b^2}}\). \(a = 2\), \(b = 1\)이면 \(2\pi/\sqrt3 \approx 3.628\).
    안쪽 극점 하나의 유수만.

의미

\(b \to a\)이면 분모가 \(\theta = \pi\)에서 0에 가까워져 적분이 발산합니다. 결과의 \(\sqrt{a^2 - b^2}\)가 0으로 가는 것과 맞습니다.

검산

\(b = 0\)이면 \(\int d\theta/a = 2\pi/a\). 공식도 \(2\pi/\sqrt{a^2} = 2\pi/a\)입니다.
