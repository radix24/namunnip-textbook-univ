구 모양 문제에서 각도 \(\theta\) 방향은 Legendre 다항식, 원통 모양 문제에서 반지름 방향은 Bessel 함수가 맡습니다. 직교 좌표의 사인·코사인과 같은 역할입니다. 사인·코사인처럼 서로 직교해서, 임의의 함수를 이것들의 합으로 나누고 계수를 적분 하나로 구할 수 있습니다.

5.2.1용어

  • Legendre 다항식 \(P_\ell(x)\): \(P_0 = 1\), \(P_1 = x\), \(P_2 = \frac12(3x^2 - 1)\), \(P_\ell(1) = 1\). \(x = \cos\theta\)로 쓴다.
  • 생성 함수: 모든 \(P_\ell\)을 한 함수의 급수 계수로 담은 것. \(\frac1{\sqrt{1 - 2xt + t^2}} = \sum_\ell P_\ell(x)t^\ell\).
  • Bessel 함수 \(J_m(x)\): \(x^2y'' + xy' + (x^2 - m^2)y = 0\)의 원점에서 유한한 해. 감쇠하며 진동한다.
  • 영점 \(j_{m,n}\): \(J_m\)이 \(n\)번째로 0이 되는 \(x\). \(j_{0,1} \approx 2.405\), \(j_{0,2} \approx 5.520\).
  • 가중 직교: 적분에 가중치(Bessel은 \(\rho\))를 곱해야 직교하는 것.

5.2.2생성 함수가 나오는 곳

목적: 거리의 역수 \(1/|\mathbf r - \mathbf r'|\)을 각도 성분으로 나누기. 점전하의 퍼텐셜, 중력 퍼텐셜에 바로 쓰입니다.

  1. 코사인 법칙: \(|\mathbf r - \mathbf r'|^2 = r^2 - 2rr'\cos\theta + r'^2\). \(r' < r\)이라 하자.
  2. \(r\)을 묶으면 \(\frac1{|\mathbf r - \mathbf r'|} = \frac1r\frac1{\sqrt{1 - 2xt + t^2}}\), \(t = r'/r < 1\), \(x = \cos\theta\). 생성 함수 꼴이 되게 한 것이다.
  3. 따라서 \(\frac1{|\mathbf r - \mathbf r'|} = \sum_\ell\frac{r'^\ell}{r^{\ell+1}}P_\ell(\cos\theta)\). 멀리서 보면 \(\ell = 0\)(전하), \(\ell = 1\)(쌍극자) 순으로 작아진다(다중극 전개).

5.2.3직교성

결과 5.2.1 \[\int_{-1}^{1}P_\ell P_{\ell'}\,dx = \frac2{2\ell + 1}\delta_{\ell\ell'},\qquad \int_0^aJ_m\!\left(\frac{j_{m,n}\rho}a\right)J_m\!\left(\frac{j_{m,n'}\rho}a\right)\rho\,d\rho = \frac{a^2}2J_{m+1}^2(j_{m,n})\,\delta_{nn'}.\]

그래서 \(f(\cos\theta) = \sum a_\ell P_\ell\)이면 \(a_\ell = \frac{2\ell + 1}2\int_{-1}^{1}fP_\ell\,dx\)입니다. Bessel 쪽에 \(\rho\)가 붙는 것은 원판의 넓이 요소가 \(\rho\,d\rho\,d\phi\)이기 때문입니다.

예제 5.2.1

반지름 \(a = 0.15\) m인 북의 가죽(가장자리 고정)이 축대칭으로 진동할 때, 가장 낮은 두 모드의 진동수 비는? 파동 속력이 100 m/s이면 기본 진동수는?

풀이. 가장자리에서 0이어야 하므로 \(J_0(ka) = 0\), \(k = j_{0,n}/a\). 진동수 \(f = \frac{vk}{2\pi}\)이므로 비는 \(5.520/2.405 \approx 2.30\). 정수배가 아니라서 북 소리는 현악기처럼 맑은 음높이가 없습니다. 기본 진동수 \(\frac{100\times2.405}{2\pi\times0.15} \approx 255\) Hz.

주의Bessel 함수의 영점은 일정한 간격이 아닙니다. 처음 몇 개는 간격이 3.1보다 조금 크고, 멀어질수록 \(\pi\)에 가까워집니다. 사인 함수처럼 \(n\pi\)로 어림하면 첫 영점(2.405)부터 크게 틀립니다. 값은 표나 계산기로 확인하세요.
요약
  1. 생성 함수 \((1 - 2xt + t^2)^{-1/2} = \sum P_\ell t^\ell\) → \(1/|\mathbf r - \mathbf r'|\)의 다중극 전개.
  2. \(\int P_\ell P_{\ell'} = \frac2{2\ell+1}\delta\), Bessel은 가중치 \(\rho\)로 직교.
  3. 구는 Legendre, 원통·원판은 Bessel.

5.2.4연습문제

기본

  1. 생성 함수를 \(t\)에 대해 2차까지 전개해 \(P_0, P_1, P_2\)를 확인하여라.
    답

    \(u = 2xt - t^2\), \((1 - u)^{-1/2} = 1 + \frac u2 + \frac38u^2 + \cdots = 1 + xt + \left(-\frac12 + \frac32x^2\right)t^2 + \cdots\).

  2. \(\int_{-1}^{1}x^2P_2\,dx\)를 구하여라(\(x^2 = \frac13P_0 + \frac23P_2\) 이용).
    답

    \(\frac23\cdot\frac25 = \frac4{15}\).

5.2.2

실습Legendre 다항식과 Bessel 함수의 직교성

실습 · 직교 적분

다루는 성취기준 [물리18-05-02]

목표

두 Legendre 다항식, 또는 원판의 두 Bessel 모드를 곱해 적분하고, 서로 다르면 0이 되는 것(직교)을 수치로 확인합니다. Bessel 함수는 가중치 \(\rho\)가 있어야 직교함을 봅니다. 성취기준 [물리18-05-02].

준비

파란 선과 주황 선이 두 함수, 연한 선이 그 곱입니다. Legendre는 \(-1 \le x \le 1\), Bessel은 반지름 1인 원판에서 가장자리가 0이 되도록 \(J_m(j_{m,n}\rho)\)를 씁니다. 함수 값은 급수 \(J_m(x) = \sum_k\frac{(-1)^k}{k!\,(k + m)!}\left(\frac x2\right)^{2k+m}\)으로 계산하고, 영점은 표준 표값을 씁니다.

절차

  1. Legendre에서 (1, 2), (2, 2), (3, 3)의 적분을 적고 \(\frac2{2\ell + 1}\)과 비교한다.
  2. Bessel(m = 0)로 바꿔 (1, 2) 모드의 가중 적분과 가중치 없는 적분을 비교한다.
  3. m = 1에서 영점 \(j_{1,1}\), \(j_{1,2}\)를 읽는다.

기대 결과

  • Legendre (1, 2): 0.0000. (2, 2): 0.4000, (3, 3): 0.2857(이론 2/5, 2/7).
  • Bessel m = 0, (1, 2): 영점 2.405, 5.520, 가중 적분 0.0000, 가중치 없는 적분은 0이 아니다. (1, 1): 가중 적분 0.1348(이론 \(\frac12J_1^2(2.405)\)).
  • m = 1: \(j_{1,1} = 3.832\), \(j_{1,2} = 7.016\).

분석

  1. Bessel의 가중치 \(\rho\)가 원판 넓이 요소 \(\rho\,d\rho\,d\phi\)에서 온다는 것을 설명해 보세요.
  2. 직교성이 있으면 함수 하나를 이 함수들로 전개할 때 계수를 왜 적분 하나로 구할 수 있나요?
