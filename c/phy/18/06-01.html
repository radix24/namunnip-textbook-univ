이 절에서 배울 것
  • 변수 분리로 편미분방정식을 상미분방정식 여러 개로 나눈다.
  • 직교, 원통, 구면 좌표에서 Laplace 방정식의 분리해를 쓴다.
  • 경계 조건을 직교성으로 맞춰 계수를 구한다.
먼저 알아야 할 것
  • 편미분방정식의 기본 개념 (공통9 2.1절), 곡선 좌표의 라플라시안 (1.2절), Legendre·Bessel 함수 (5.2절).

전하가 없는 곳의 전기 퍼텐셜, 정상 상태의 온도, 소용돌이 없는 흐름의 퍼텐셜은 모두 \(\nabla^2V = 0\)을 따릅니다. 해는 경계에서 정한 값에 따라 달라집니다. 변수 분리는 "해를 좌표마다의 함수의 곱으로 놓으면 편미분방정식이 상미분방정식 여러 개로 갈라진다"는 생각입니다. 갈라진 해 하나하나는 경계 조건을 다 맞추지 못하지만, 그것들을 더하면(중첩) 맞출 수 있습니다.

6.1.1용어

  • 변수 분리: \(V(x, y) = X(x)Y(y)\)처럼 곱으로 놓는 방법.
  • 분리 상수: 갈라진 두 식이 공통으로 같아야 하는 상수 \(k^2\). 경계 조건이 허용하는 값만 남는다.
  • 디리클레 조건: 경계에서 \(V\) 값을 주는 조건. 노이만 조건: 경계에서 법선 도함수를 주는 조건.
  • 유일성 정리: 경계 조건을 모두 만족하는 Laplace 방정식의 해는 하나뿐이다. 그래서 어떤 방법으로 찾든 맞기만 하면 정답이다.

6.1.2직교 좌표: 직사각형 상자

문제: 폭 \(a\)인 홈(\(0 < x < a\), \(y > 0\)). 양 옆면(\(x = 0, a\))은 \(V = 0\), 바닥(\(y = 0\))은 \(V = V_0\), 위로 멀리 가면 \(V \to 0\).

  1. \(V = XY\)를 넣고 \(XY\)로 나누면 \(\frac{X''}X + \frac{Y''}Y = 0\). 첫 항은 \(x\)만, 둘째 항은 \(y\)만의 함수인데 합이 늘 0이므로 각각 상수여야 한다: \(X''/X = -k^2\), \(Y''/Y = k^2\).
  2. 옆면 조건 \(X(0) = X(a) = 0\)을 만족하는 해는 \(\sin(n\pi x/a)\), \(k = n\pi/a\). 부호를 \(-k^2\)로 고른 것은 0이 두 번 되는 진동 해가 필요하기 때문이다.
  3. \(Y\)는 \(e^{\pm ky}\) 가운데 멀리서 0이 되는 \(e^{-ky}\)만 남긴다.
  4. \(V = \sum c_n\sin(n\pi x/a)e^{-n\pi y/a}\)로 두고 바닥 조건 \(V_0 = \sum c_n\sin(n\pi x/a)\)를 Fourier 사인 급수로 맞추면 \(c_n = \frac{4V_0}{n\pi}\) (\(n\) 홀수).

높은 \(n\)은 \(e^{-n\pi y/a}\)로 빨리 사라지므로, 바닥에서 조금만 올라가도 첫 항이 거의 전부입니다. \(y = a/2\)에서 첫 항은 \(\frac{4V_0}\pi e^{-\pi/2} \approx 0.265V_0\), 셋째 항은 \(0.0038V_0\)입니다.

6.1.3원통 좌표와 구면 좌표

  • 원통(\(z\) 방향으로 균일): \(V = (A + B\ln\rho) + \sum(C_m\rho^m + D_m\rho^{-m})(E_m\cos m\phi + F_m\sin m\phi)\). \(z\)에도 의존하면 Bessel 함수가 나온다.
  • 구(축대칭): \(V = \sum_\ell\left(A_\ell r^\ell + \frac{B_\ell}{r^{\ell+1}}\right)P_\ell(\cos\theta)\). 원점을 포함하면 \(B_\ell = 0\), 무한대까지면 \(A_\ell = 0\)(또는 균일한 바깥 장만).
예제 6.1.1

반지름 \(R\)인 접지된 도체 구를 균일한 전기장 \(E_0\hat{\mathbf z}\) 속에 놓았다. 바깥 퍼텐셜과 표면 전하 밀도의 최댓값을 구하여라.

풀이. 멀리서 \(V \to -E_0r\cos\theta\)이므로 \(\ell = 1\)만 필요합니다. \(V = \left(-E_0r + \frac{B_1}{r^2}\right)\cos\theta\). \(r = R\)에서 0이려면 \(B_1 = E_0R^3\). 표면 전하 \(\sigma = -\varepsilon_0\partial_rV|_R = 3\varepsilon_0E_0\cos\theta\), 최댓값 \(3\varepsilon_0E_0\)(극에서). 장이 극에서 바깥 장의 3배로 몰립니다. \(E_0 = 10^4\) V/m이면 \(\sigma_{\max} \approx 2.7\times10^{-7}\) C/m².

주의분리 상수의 부호는 아무렇게나 고르는 것이 아니라 경계 조건이 정합니다. 양쪽이 0인 방향은 진동하는 해(\(\sin\))가 필요해 \(-k^2\)를, 한쪽으로 사라져야 하는 방향은 지수 해가 필요해 \(+k^2\)를 줍니다. 반대로 고르면 경계 조건을 만족하는 해가 0밖에 없습니다.
요약
  1. 곱으로 놓기 → 좌표마다 상미분방정식 → 경계가 허용하는 분리 상수만 남김.
  2. 분리해를 더하고 직교성(Fourier, Legendre)으로 계수 결정.
  3. 유일성 정리: 경계를 다 맞추면 그것이 답.

6.1.4연습문제

기본

  1. 반지름 \(R\)인 구 표면 퍼텐셜이 \(V_0\cos\theta\)일 때 안쪽과 바깥 퍼텐셜을 구하여라.
    답

    안: \(V_0\frac rR\cos\theta\). 바깥: \(V_0\frac{R^2}{r^2}\cos\theta\). 안쪽은 균일한 장, 바깥은 쌍극자 장.

6.1.2

예제원판의 정상 온도와 평균값 성질

원통 좌표 변수 분리 · 경계 맞추기 · 문제 해결 전략

다루는 성취기준 [물리18-06-01]

출발점

원판 안(\(\rho < R\))의 Laplace 방정식 해는 \(V = A_0 + \sum_m\rho^m(A_m\cos m\phi + B_m\sin m\phi)\)입니다. 원점에서 유한해야 하므로 \(\rho^{-m}\)과 \(\ln\rho\)는 뺍니다.

문제 해결 전략 · 경계값을 Fourier 성분으로 맞추기
  1. 경계 함수를 \(\cos m\phi\), \(\sin m\phi\)의 합으로 쓴다(삼각함수 공식).
  2. 같은 \(m\)끼리 계수를 맞춘다(직교성).
  3. 원점에서 유한한 해만 남긴다.
  4. 원의 중심 값이 경계 평균과 같은지 확인한다.

반지름 \(R\)인 얇은 원판의 테두리 온도가 \(T(R, \phi) = T_0\sin^2\phi\)이다. 원판 안의 정상 온도와 중심 온도를 구하여라.

풀이

  1. \(\sin^2\phi = \frac12 - \frac12\cos2\phi\).
    경계 함수를 Fourier 성분으로.
  2. \(m = 0\) 항: \(A_0 = \frac{T_0}2\). \(m = 2\) 항: \(A_2R^2 = -\frac{T_0}2\), \(A_2 = -\frac{T_0}{2R^2}\). 나머지는 0.
    같은 \(m\)끼리 맞춘다.
  3. \(T(\rho, \phi) = \frac{T_0}2\left[1 - \left(\frac\rho R\right)^2\cos2\phi\right]\).
    원점에서 유한한 \(\rho^m\)만 썼다.
  4. 중심: \(T(0) = \frac{T_0}2\). \(T_0 = 80\) °C이면 40 °C.
    \(\rho = 0\)에서 \(m \ge 1\) 항이 모두 사라진다.

의미

조화 함수의 중심 값은 둘레의 평균과 같습니다(평균값 성질). 그래서 정상 상태의 온도나 퍼텐셜은 안쪽에서 극대·극소를 가질 수 없고, 가장 뜨거운 곳과 차가운 곳은 늘 경계에 있습니다.

검산

\(\rho = R\)에서 \(\frac{T_0}2(1 - \cos2\phi) = T_0\sin^2\phi\). 경계 조건을 만족합니다. \(T = \frac{T_0}2 - \frac{T_0}{2R^2}(x^2 - y^2)\)라서 직교 좌표 라플라시안도 0입니다.
