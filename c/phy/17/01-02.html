1.2.1먼저 그려 본다

평균, 분산, 상관계수가 똑같은데 산점도는 전혀 다른 자료들이 있습니다(앤스컴의 네 자료가 유명한 예). 숫자 요약은 자료를 압축하면서 정보를 버리므로, 분석 전에 반드시 그림을 봅니다.

import seaborn as sns
import matplotlib.pyplot as plt
sns.histplot(df["g"], bins=20)                    # 분포 모양, 이상값
sns.boxplot(data=df, x="group", y="g")            # 조별 비교
sns.scatterplot(data=df, x="L_m", y="T_s", hue="group")
sns.pairplot(df[["L_m", "T_s", "g"]])             # 모든 쌍의 산점도
plt.show()

1.2.2무엇을 보나

  • 분포 모양: 봉우리가 하나인지 둘인지(두 조건이 섞였을 수 있음), 치우쳤는지, 꼬리가 긴지.
  • 이상값: 측정 실수인지, 실제 현상인지 기록을 확인한다. 이유 없이 지우지 않는다.
  • 관계: 직선인지 곡선인지. 곡선이면 변수를 변환(로그, 제곱근)해 직선이 되는지 본다. 진자의 \(T\)와 \(L\)은 \(\log T\) 대 \(\log L\)에서 기울기 1/2인 직선이다.
  • 숨은 변수: 색(hue)으로 조나 날짜를 구분하면, 전체로는 없던 관계가 조마다 나타나거나 반대로 될 수 있다(심슨의 역설).
예제 1.2.1

진자 실험에서 \(g\)의 히스토그램이 9.6과 9.9 근처에 봉우리가 둘 있었다. 무엇을 의심해야 하는가?

풀이. 두 조건이 섞였을 가능성이 큽니다. 조별(측정자, 장비, 진폭) 상자 그림을 그려 봅니다. 예를 들어 한 조만 큰 진폭으로 재어 주기가 길게 나왔다면(물리1 3.3절의 진폭 의존성) \(g\)가 작게 계산됩니다.

그래프의 축 이름과 단위, 오차 막대(무엇의 오차인지: 표준편차인지 표준오차인지)를 밝히는 것도 결과를 정직하게 전달하는 일입니다.

요약
  1. 요약 통계 전에 히스토그램, 상자 그림, 산점도를 본다.
  2. 분포 모양, 이상값, 곡선 관계, 숨은 변수를 확인한다.

1.2.2

예제로그-로그 그래프로 거듭제곱 법칙 찾기

로그 눈금 · 기울기 · 문제 해결 전략

다루는 성취기준 [물리17-01-02]

출발점

\(y = Ax^n\)이면 \(\log y = \log A + n\log x\)라 로그-로그 그래프에서 직선이 되고 기울기가 지수 \(n\)입니다. 자료가 몇 배씩 넓게 퍼져 있을 때 특히 유용합니다.

문제 해결 전략 · 거듭제곱 법칙 찾기
  1. 양축을 로그 눈금으로 그린다(ax.loglog).
  2. 직선이면 거듭제곱 법칙. 휘면 다른 꼴을 생각한다.
  3. 두 점이나 직선 맞춤으로 기울기 \(n\)을 구한다.
  4. 물리적으로 기대되는 지수와 비교한다.

행성의 궤도 긴반지름(AU)과 주기(년): 수성 0.387, 0.241 / 지구 1, 1 / 목성 5.20, 11.86 / 해왕성 30.1, 164.8. 로그-로그 기울기를 구하여라.

풀이

  1. 지구와 해왕성: \(n = \frac{\log164.8 - \log1}{\log30.1 - \log1} = \frac{2.217}{1.479} = 1.499\).
    상용로그.
  2. 수성과 목성: \(\frac{\log11.86 - \log0.241}{\log5.20 - \log0.387} = \frac{1.074 + 0.618}{0.716 + 0.412} = \frac{1.692}{1.128} = 1.500\).
    같은 기울기.
  3. \(n = 1.50\): \(T \propto a^{3/2}\).
    케플러 제3법칙.
  4. 절편 \(\log A = 0\)(지구에서 \(T = 1\), \(a = 1\)).
    단위를 AU, 년으로 잡은 덕분.

의미

보통 그래프에서는 수성과 지구가 원점 근처에 뭉쳐 보이지 않지만, 로그 그래프에서는 모든 행성이 고르게 퍼져 직선 위에 놓입니다. 그래프 선택이 자료에서 법칙을 찾는 첫걸음입니다.

검산

목성: \(5.20^{1.5} = 11.86\). 표의 값과 같습니다.
