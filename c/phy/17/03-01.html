3.1.1solve_ivp

운동 방정식을 1계 연립 방정식 \(\dot{\mathbf y} = \mathbf f(t, \mathbf y)\)로 쓰고 함수로 넘깁니다. 기본 방법(RK45)은 걸음마다 4차와 5차 결과를 비교해 오차를 어림하고, 허용 오차에 맞게 걸음 크기를 스스로 조절합니다.

from scipy.integrate import solve_ivp
GM = 4 * np.pi**2                      # AU, 년 단위 (태양)
def kepler(t, s):
    x, y, vx, vy = s
    r3 = (x*x + y*y)**1.5
    return [vx, vy, -GM*x/r3, -GM*y/r3]

s0 = [1.0, 0.0, 0.0, 2*np.pi*0.8]      # 원 궤도 속력의 0.8배로 출발 → 타원
sol = solve_ivp(kepler, (0, 10), s0, rtol=1e-9, atol=1e-12, dense_output=True)
x, y, vx, vy = sol.y
E = 0.5*(vx**2 + vy**2) - GM/np.hypot(x, y)
L = x*vy - y*vx
print(np.ptp(E)/abs(E[0]), np.ptp(L)/abs(L[0]))   # 보존량의 상대 변화
  • rtol, atol: 상대·절대 허용 오차. 기본값(1e-3, 1e-6)은 장시간 궤도 계산에 너무 느슨하다.
  • 보존량(에너지, 각운동량)의 변화가 수치 오차의 좋은 지표다. 일반적인 RK 방법은 장시간에 에너지가 조금씩 표류한다(물리1, 공통11의 오일러-크로머처럼 보존 성질을 지키는 심플렉틱 방법을 쓰기도 함).
  • 진동이 빠른 성분과 느린 성분이 섞인 강성(stiff) 방정식은 method="Radau"나 "LSODA"를 쓴다.

3.1.2연성 진동자

물리4 4.1절의 두 진동자를 같은 방법으로 풀고, 결과를 정규 모드 해와 비교해 검증합니다. 해석해가 있는 경우로 먼저 코드를 검증한 뒤, 비선형 항(큰 진폭의 진자)이나 감쇠를 넣어 해석해가 없는 문제로 넓히는 것이 좋은 순서입니다.

예제 3.1.1

위 궤도에서 처음 속력이 원 궤도의 0.8배일 때 궤도 긴반지름과 주기를 예측하고 수치해와 비교하는 방법을 말하여라.

풀이. 에너지 \(E = \frac12(0.8\cdot2\pi)^2 - 4\pi^2 = 4\pi^2(0.32 - 1) = -0.68\times4\pi^2\). \(a = -GM/2E = 1/1.36 \approx 0.735\) AU, 주기 \(a^{3/2} \approx 0.63\) 년. 수치해에서 \(x\)가 같은 방향으로 다시 지나는 시각 간격을 재어 비교합니다.

요약
  1. solve_ivp(f, t_span, y0, rtol, atol), 걸음 크기 자동 조절.
  2. 보존량과 해석해로 검증, 강성 문제는 다른 방법.

3.1.3연습문제

기본

  1. rtol을 1e-3에서 1e-9로 줄이면 계산 시간과 에너지 표류가 대략 어떻게 바뀔지 예상하여라.
    답

    5차 방법이라 걸음 수는 대략 \((10^6)^{1/5} \approx 16\)배 늘고, 에너지 표류는 크게(수백만 배 정도) 준다.

3.1.2

예제수치 궤도의 에너지 보존으로 적분기 고르기

Euler · RK4 · 대칭 적분기 · 문제 해결 전략

다루는 성취기준 [물리17-03-01]

출발점

ODE 풀이기가 맞는지 확인하는 가장 좋은 방법은 보존량을 보는 것입니다. 궤도 운동에서는 에너지와 각운동량이 보존되어야 하는데, 단순한 Euler 방법은 에너지가 계속 늘어나 궤도가 바깥으로 나선을 그립니다.

문제 해결 전략 · 적분기 점검
  1. 상태 벡터 \((x, y, v_x, v_y)\)와 미분 함수를 쓴다.
  2. 여러 방법으로 같은 시간 동안 적분한다.
  3. 에너지의 상대 변화 \(\Delta E/E\)를 비교한다.
  4. 시간 간격을 절반으로 줄여 오차가 몇 배 주는지(차수)를 확인한다.

원 궤도(\(GM = 1\), \(r = 1\), 주기 \(2\pi\))를 시간 간격 \(h = 0.01\)로 10바퀴(6283걸음) 적분했다. Euler, RK4, 속도 Verlet 방법의 에너지 변화와 마지막 반지름을 비교하고, 장기 적분에 어떤 방법이 알맞은지 말하여라.

풀이

  1. Euler: 에너지(처음 −0.5)가 \(-0.30\)까지 올라가(\(\Delta E/|E| = 41\%\)) 반지름이 1.65로 커진다.
    1차 방법은 체계적으로 에너지가 샌다(이 교재의 Python 계산 결과).
  2. RK4: \(\Delta E/|E| = 1.7\times10^{-10}\), 반지름 1.0000. \(h\)를 절반으로 하면 \(5\times10^{-12}\).
    4차라 아주 정확하지만 오차가 한쪽으로 조금씩 쌓인다.
  3. Verlet: 2차인데도 에너지 오차가 최대 \(2.5\times10^{-9}\)에서 오르내리기만 하고 10바퀴 뒤에는 거의 0으로 돌아온다.
    시간 반전 대칭인 심플렉틱 적분기.
  4. 짧고 정밀한 계산은 RK4, 수천 바퀴 이상 장기 계산은 Verlet.
    목적에 따라 고른다.

의미

행성 궤도처럼 아주 오래 돌려야 하는 시뮬레이션은 정확도보다 보존 성질이 중요합니다. 물리4의 리우빌 정리(위상 공간 넓이 보존)를 지키는 적분기가 장기적으로 믿을 만합니다.

검산

\(h = 0.005\)로 다시 돌리면 Euler의 에너지 변화는 30%로 조금만 줄고(1차), RK4는 약 1/32, Verlet의 최대 오차는 약 1/16(\(1.6\times10^{-10}\))로 줄었습니다. 직접 돌려 같은 결과가 나오는지 확인해 보세요.
