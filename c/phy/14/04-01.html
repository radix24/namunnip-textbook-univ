4.1.1왜 능동 필터인가

RC 필터 두 개를 이어 붙이면 뒤 단이 앞 단에 부하가 되어 특성이 나빠지고, 인덕터 없이는 날카로운(높은 \(Q\)) 응답을 만들 수 없습니다. OP-amp를 쓰면 입력 임피던스가 크고 출력 임피던스가 작아 단을 독립적으로 쌓을 수 있고, 되먹임으로 \(Q\)를 조절할 수 있습니다.

4.1.2살렌-키 저역 통과

두 저항 \(R_1, R_2\), 두 축전기 \(C_1, C_2\)와 이득 \(K\)인 비반전 증폭기로 된 2차 필터의 전달 함수는

\[H(s) = \frac{K\omega_0^2}{s^2 + \frac{\omega_0}Qs + \omega_0^2}, \qquad \omega_0 = \frac1{\sqrt{R_1R_2C_1C_2}}.\]

같은 값(\(R_1 = R_2 = R\), \(C_1 = C_2 = C\))이면 \(\omega_0 = 1/RC\), \(Q = \frac1{3 - K}\). \(K = 1\)(버퍼)이면 \(Q = 0.5\), \(K = 1.586\)이면 \(Q = 0.707\)(버터워스, 통과 대역이 가장 평평), \(K\)가 3에 다가가면 \(Q \to \infty\)로 발진합니다. 차단 위에서 \(-40\) dB/디케이드로 떨어집니다. 아래 실습 카드에서 \(Q\)에 따른 응답을 볼 수 있습니다.

4.1.3빈 브리지 발진기

증폭기 출력을 RC 직렬-RC 병렬 회로(빈 회로망)를 거쳐 비반전 입력으로 되먹입니다. 빈 회로망의 전달 함수는 \(\omega = 1/RC\)에서 위상 0, 크기 \(\frac13\)입니다.

바르크하우젠 조건

한 바퀴 이득 \(A\beta = 1\)(크기 1, 위상 0)이면 정상 발진. 빈 브리지에서 \(f = \frac1{2\pi RC}\), 증폭기 이득 \(A = 3\).

이득이 3보다 조금 크면 발진이 자라고, 작으면 꺼집니다. 진폭을 안정시키려면 이득이 진폭에 따라 줄어드는 소자(전구, 다이오드, JFET)를 되먹임에 넣습니다. 휼렛-팩커드의 첫 제품(1939)이 전구로 안정화한 빈 브리지 발진기였습니다.

예제 4.1.1

\(R = 10\) kΩ, \(C = 10\) nF로 살렌-키 버터워스 필터와 빈 브리지 발진기를 만들면 차단 진동수와 발진 진동수는?

풀이. 둘 다 \(\frac1{2\pi RC} = \frac1{2\pi\times10^{-4}} \approx 1.59\) kHz. 버터워스 필터의 이득은 1.586(\(R_f/R_g = 0.586\)), 발진기는 3(\(R_f/R_g = 2\))으로 맞춥니다.

요약
  1. 능동 필터: 단 사이 부하 없음, 되먹임으로 \(Q\) 조절.
  2. 살렌-키(같은 값): \(\omega_0 = 1/RC\), \(Q = 1/(3 - K)\), 버터워스 \(K = 1.586\).
  3. 빈 브리지: \(f = 1/2\pi RC\), 이득 3, 진폭 안정화 소자.

4.1.4연습문제

기본

  1. 살렌-키 필터(같은 값)에서 \(Q = 2\)를 얻으려면 \(K\)는?
    답

    \(3 - K = 0.5\), \(K = 2.5\). 차단 진동수에서 이득이 \(KQ = 5\)배로 솟습니다.

4.1.2

실습살렌-키 필터의 Q 바꾸기

실습 · 능동 필터

다루는 성취기준 [물리14-04-01]

목표

같은 값 부품으로 만든 살렌-키 2차 저역 통과 필터에서 증폭기 이득 \(K\)를 바꾸며 \(Q\), 주파수 응답, 위상을 보고, 버터워스 조건과 발진 한계를 확인합니다. 성취기준 [물리14-04-01].

준비

위는 이득(dB), 아래는 위상을 \(f/f_0\)의 로그에 대해 그렸습니다. 연한 점선은 \(Q = 0.5\)와 0.707의 기준 곡선(이득 1)입니다. \(R\)과 \(C\)는 \(f_0\)만 정합니다.

절차

  1. \(K = 1\)(버퍼)과 1.586(버터워스)에서 응답의 모양과 −3 dB 진동수를 비교한다.
  2. \(K = 2.5\)로 올려 차단 진동수 근처에서 이득이 솟는 크기를 읽는다.
  3. \(K\)를 2.95까지 올리며 봉우리가 어떻게 되는지 본다.
  4. \(R = 10\) kΩ, \(C = 10\) nF에서 \(f_0\)가 4.1절 예제와 같은지 본다.

기대 결과

  • \(K = 1\): \(Q = 0.5\), 봉우리 없이 일찍 줄어든다(−3 dB가 \(f_0\)보다 아래). \(K = 1.586\): \(Q = 0.707\), 통과 대역이 가장 평평하고 −3 dB가 정확히 \(f_0\).
  • \(K = 2.5\): \(Q = 2\), 통과 이득보다 약 6 dB 솟는다.
  • \(K \to 3\)이면 봉우리가 한없이 커진다: 필터가 발진기가 되는 경계.
  • \(f_0 \approx 1.59\) kHz. 위상은 \(f_0\)에서 −90°, 높은 진동수에서 −180°로 간다.

분석

  1. 높은 \(Q\) 필터가 부품 값의 오차에 민감한 까닭을 \(Q = 1/(3 - K)\)로 설명해 보세요(\(K\)가 1% 틀리면?).
  2. 빈 브리지 발진기의 이득 조건 3과 이 필터의 발진 한계 \(K = 3\)이 같은 숫자인 것은 우연인지 생각해 보세요.
