  • 짧은 발표(10~15분)와 포스터의 구성을 안다.

  • 질문에 근거를 들어 답하고, 모르는 것을 정직하게 다루는 법을 안다.
먼저 알아야 할 것
  • 실험 보고서 (물리10 1.2절), 연구형 실험 설계 (5.1절).

5.2.1발표의 흐름

  1. 질문과 동기(1분): 무엇을 왜 알고 싶었는가. 청중이 결과를 기다리게 만든다.
  2. 방법(2~3분): 장치 그림 하나와 핵심 원리 식 하나.
  3. 결과(4~5분): 가장 중요한 그래프. 축, 단위, 오차 막대, 맞춤선이 다 보이게.
  4. 해석과 한계(2~3분): 기준값과의 비교(\(z\) 값), 가장 큰 오차 원인.
  5. 결론(1분): 처음 질문에 한두 문장으로 답한다.

5.2.2시각 자료

  • 슬라이드 하나에 메시지 하나. 제목을 문장으로 쓴다("전류에 따라 홀 전압이 직선으로 늘었다").
  • 글자는 뒷자리에서도 읽힐 크기로. 표보다 그래프.
  • 색만으로 구별하지 않는다(색각 차이를 고려해 기호·선 모양도 다르게).
  • 포스터는 멀리서 제목과 핵심 그림이, 가까이서 세부가 보이게 위계를 둔다.

5.2.3질의응답

  • 질문을 다시 말해 확인한 뒤 답한다.
  • 근거(자료, 식, 불확도)를 들어 답한다. "그래프의 이 점들을 보면…"
  • 모르면 모른다고 하고, 어떻게 확인할 수 있을지 말한다. 추측은 추측이라고 밝힌다.
  • 비판적 질문은 실험을 개선할 기회다. 방어하기보다 받아 적는다.
  • 질문하는 쪽이라면 사람이 아니라 주장과 근거에 대해 묻는다.
예제 5.2.1

"측정값이 기준값보다 3% 큰데, 실험이 틀린 것 아닌가요?"라는 질문에 어떻게 답할까요(불확도 2%)?

풀이. "차이는 불확도의 1.5배로, 우연 오차로 설명될 수 있는 범위입니다(\(z = 1.5\)). 다만 값이 크게 나온 방향은 접촉 전위 같은 체계 오차와도 맞아서, 전류 방향을 바꿔 재는 대조 실험으로 확인해 보려 합니다." 수치 근거, 가능한 원인, 확인 계획을 함께 말합니다.

요약
  1. 질문 → 방법 → 결과 → 해석·한계 → 결론.
  2. 슬라이드 하나에 메시지 하나, 문장 제목, 읽히는 그래프.
  3. 근거를 들어 답하고, 모르는 것은 정직하게, 비판은 개선의 기회로.

5.2.4연습문제

기본

  1. "오차 막대가 왜 이렇게 큰가요?"라는 질문에 답할 때 넣어야 할 두 가지는?
    답

    오차 막대가 무엇을 나타내는지(표준편차, 표준오차, 몇 번 측정) 그리고 가장 큰 기여 원인과 줄일 방법.

5.2.2

예제두 조의 결과가 맞는지 묻는 질문에 수치로 답하기

z 값 · 가중 평균 · 문제 해결 전략

다루는 성취기준 [물리14-05-02]

출발점

두 측정값의 차이가 의미 있는지는 \(z = \frac{|x_1 - x_2|}{\sqrt{u_1^2 + u_2^2}}\)로 판단합니다. \(|z| < 2\)이면 우연 오차로 설명되는 범위입니다. 서로 맞으면 가중치 \(1/u^2\)로 평균을 내어 더 정밀한 값을 얻습니다.

문제 해결 전략 · 질문에 수치로 답하기
  1. 두 값의 차이와 합성 불확도로 \(z\)를 구한다.
  2. \(|z| < 2\)이면 서로 맞는다고 말한다.
  3. 가중 평균과 그 불확도를 구한다.
  4. 기준값과 비교해 결론을 한 문장으로 말한다.

발표 중 "두 조의 값이 다른데 어느 쪽이 맞나요?"라는 질문을 받았다. A조 \(g = 9.74 \pm 0.05\), B조 \(9.85 \pm 0.04\) m/s²이다. 수치 근거를 갖춘 답을 준비하여라(기준값 9.80).

풀이

  1. \(z = \frac{0.11}{\sqrt{0.05^2 + 0.04^2}} = \frac{0.11}{0.064} = 1.7\).
    2보다 작다.
  2. 두 값은 불확도 안에서 서로 맞는다. 어느 한쪽이 틀렸다고 할 근거는 없다.
    판단.
  3. 가중치 400, 625. 평균 \(\frac{9.74\times400 + 9.85\times625}{1025} = 9.81\), 불확도 \(1/\sqrt{1025} = 0.031\).
    정밀도가 좋아진다.
  4. 기준값과 \(z = 0.01/0.031 = 0.3\). 합친 결과는 기준값과 잘 맞는다.
    결론.

의미

답은 "차이는 합성 불확도의 1.7배로 우연 오차 범위입니다. 두 값을 합치면 9.81 ± 0.03으로 기준값과 맞습니다"처럼 수치와 판단을 함께 말합니다. \(z\)가 3을 넘었다면 체계 오차를 찾겠다고 답해야 합니다.

검산

가중 평균 불확도 0.031은 두 불확도(0.05, 0.04)보다 작습니다. 독립인 두 측정을 합치면 늘 더 정밀해집니다.
