5.2.1보존량

양값 매기기보존
에너지, 운동량4-운동량늘
전하늘
바리온 수 \(B\)쿼크 +1/3, 바리온 +1, 메손 0늘 (지금까지 관측)
렙톤 수 \(L_e, L_\mu, L_\tau\)\(e^-, \nu_e\): \(L_e = +1\), 반입자 −1, 맛별로 따로늘 (중성미자 진동은 예외)
기묘도 \(S\)s 쿼크 −1, \(\bar{\text{s}}\) +1강·전자기 상호작용에서만

또 붕괴하려면 생성물의 질량 합이 처음 입자의 질량보다 작아야 합니다(\(Q > 0\)). 양성자는 가장 가벼운 바리온이라 바리온 수 보존 때문에 붕괴하지 않습니다(양성자 붕괴는 아직 관측되지 않았고 수명 하한이 \(10^{34}\)년 수준이라고 알려짐, 값은 확인 필요).

5.2.2판정

예제 5.2.1

다음 반응이 가능한지 판정하여라. (가) \(p \to e^+ + \gamma\) (나) \(n \to p + e^- + \bar\nu_e\) (다) \(\pi^- + p \to K^0 + \Lambda^0\) (라) \(\mu^- \to e^- + \gamma\)

풀이.

  • (가) 바리온 수 1 → 0, 렙톤 수 0 → −1. 불가능.
  • (나) 전하, \(B\), \(L_e\)(0 = 0 + 1 − 1) 모두 보존, 질량도 충분. 가능(베타 붕괴, 약한 상호작용).
  • (다) 전하 0 = 0, \(B\) 1 = 1, \(S\): 0 → (+1) + (−1) = 0. 가능(강한 상호작용, 기묘 입자의 쌍생성).
  • (라) 전하·에너지는 되지만 \(L_\mu\) 1 → 0, \(L_e\) 0 → 1. 금지(실험에서도 관측되지 않음).

Λ⁰가 혼자 붕괴할 때(\(\Lambda^0 \to p + \pi^-\))는 기묘도가 −1 → 0으로 바뀌어 약한 상호작용으로만 일어나므로 수명이 약 \(10^{-10}\) s로 깁니다. 강한 상호작용으로 붕괴하는 입자는 \(10^{-23}\) s 정도로 짧습니다. 생성은 빠르고 붕괴는 느리다는 "기묘한" 성질이 기묘도라는 이름의 유래입니다. 아래 실습 카드에서 여러 반응을 판정해 볼 수 있습니다.

요약
  1. 늘 보존: 에너지·운동량, 전하, 바리온 수, 맛별 렙톤 수.
  2. 기묘도는 약한 상호작용에서 깨진다. 수명으로 상호작용을 가린다.

5.2.3연습문제

기본

  1. \(\pi^+ \to \mu^+ + \nu_\mu\)에서 렙톤 수 보존을 확인하여라.
    답

    \(\mu^+\)는 \(L_\mu = -1\), \(\nu_\mu\)는 +1. 합 0으로 처음(0)과 같다.

5.2.2

실습이 반응은 일어날까

실습 · 보존 법칙

다루는 성취기준 [물리7-05-02] [물리7-05-01]

목표

여러 입자 반응과 붕괴에 대해 전하, 바리온 수, 렙톤 수, 기묘도의 보존과 에너지 조건을 표로 확인하고, 가능 여부와 상호작용의 종류를 판정합니다. 성취기준 [물리7-05-02], [물리7-05-01].

준비

반응을 고르면 반응 전과 후의 각 양을 더해 비교합니다. 붕괴는 생성물 질량 합이 처음 입자보다 작아야 하고, 충돌은 모자란 정지 에너지를 운동 에너지로 채울 수 있습니다. 판정은 이 카드에 넣은 보존량만 따진 단순한 것입니다.

절차

  1. 중성자 베타 붕괴와 양성자 붕괴를 비교한다.
  2. \(\mu^- \to e^- + \gamma\)가 왜 금지인지 본다. \(\mu^-\)의 실제 붕괴와 비교한다.
  3. 기묘 입자 쌍생성(π⁻ + p → K⁰ + Λ⁰)과 Λ⁰의 붕괴를 비교한다.
  4. π⁻ + p → K⁻ + Σ⁺가 왜 안 되는지 본다.

기대 결과

  • 베타 붕괴는 가능(약한 상호작용), 양성자 붕괴는 바리온 수와 렙톤 수가 깨져 금지.
  • \(\mu^- \to e^-\gamma\)는 맛별 렙톤 수가 깨져 금지. 실제 붕괴는 \(\mu^- \to e^- + \bar\nu_e + \nu_\mu\).
  • 쌍생성은 기묘도가 보존되어 강한 상호작용으로 빨리 일어나고, Λ⁰ 붕괴는 기묘도가 1 바뀌어 약한 상호작용으로 느리게 일어난다.
  • K⁻ + Σ⁺는 기묘도가 0에서 −2로 바뀌어 금지.

분석

  1. p + p → p + p + p + p̄의 문턱 에너지를 물리3 1.3절 예제로 구해 이 카드의 "운동 에너지로 보충"과 이어 보세요.
  2. 중성미자 진동이 맛별 렙톤 수 보존에 대해 무엇을 말해 주는지 생각해 보세요.
