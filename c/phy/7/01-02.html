1.2.1회전

결합 길이 \(r_0\)인 이원자 분자를 강체 회전자로 보면 관성 모멘트 \(I = \mu r_0^2\)(\(\mu\)는 환산 질량)이고, 각운동량 크기가 \(\sqrt{\ell(\ell + 1)}\hbar\)로 양자화되므로

\[E_\ell = \frac{\hbar^2}{2I}\ell(\ell + 1), \qquad \ell = 0, 1, 2, \dots\]

광자 흡수의 선택 규칙 \(\Delta\ell = \pm1\)에 따라 \(\ell \to \ell + 1\) 흡수선은 \(\Delta E = \frac{\hbar^2}{I}(\ell + 1)\)로, 같은 간격 \(\frac{\hbar^2}{I}\)으로 늘어섭니다. 간격이 수 meV라 마이크로파·원적외선 영역입니다. 간격을 재면 \(I\), 곧 결합 길이를 압니다.

1.2.2진동

평형 근처의 결합 퍼텐셜을 포물선으로 어림하면(힘 상수 \(k\)) 조화 진동자이므로

\[E_n = \left(n + \frac12\right)\hbar\omega, \qquad \omega = \sqrt{k/\mu}.\]

선택 규칙 \(\Delta n = \pm1\)이라 흡수선은 \(\hbar\omega\)(수백 meV, 적외선)입니다. 실제 퍼텐셜은 비조화적이어서 높은 준위의 간격이 조금씩 좁아집니다.

1.2.3회전-진동 스펙트럼

진동이 \(n = 0 \to 1\)로 들뜰 때 회전도 \(\Delta\ell = \pm1\)로 함께 바뀌므로, 흡수선은 \(\hbar\omega\)를 가운데 두고 양쪽으로 \(\hbar^2/I\) 간격의 선들(R 가지: \(\Delta\ell = +1\), P 가지: \(\Delta\ell = -1\))로 나타납니다. 가운데(\(\Delta\ell = 0\))는 빠집니다. 선들의 세기는 처음 회전 준위의 열적 점유(볼츠만 분포, 2.1절)를 따릅니다. 아래 실습 카드에서 이 스펙트럼을 볼 수 있습니다.

예제 1.2.1

HCl(¹H³⁵Cl)의 회전선 간격이 약 2.6 meV(파수로 약 21 cm⁻¹), 진동 흡수 중심이 약 0.358 eV(약 2886 cm⁻¹)이다. 결합 길이와 힘 상수를 어림하여라.

풀이. \(\mu = \frac{1\times35}{36}\ \text{u} = 0.972\) u \(= 1.61\times10^{-27}\) kg. \(I = \hbar^2/\Delta E = \frac{(1.055\times10^{-34})^2}{2.6\times10^{-3}\times1.602\times10^{-19}} \approx 2.7\times10^{-47}\) kg·m², \(r_0 = \sqrt{I/\mu} \approx 0.13\) nm. \(\omega = 0.358\ \text{eV}/\hbar = 5.44\times10^{14}\) s⁻¹, \(k = \mu\omega^2 \approx 480\) N/m.

요약
  1. 회전 \(E_\ell = \frac{\hbar^2}{2I}\ell(\ell + 1)\), 흡수선 간격 \(\hbar^2/I\).
  2. 진동 \(E_n = (n + \frac12)\hbar\omega\), \(\omega = \sqrt{k/\mu}\).
  3. 회전-진동: 중심 \(\hbar\omega\) 양쪽에 P, R 가지.

1.2.4연습문제

기본

  1. HCl을 DCl(중수소)로 바꾸면 진동 진동수는 몇 배가 되는가? (힘 상수는 같다)
    답

    \(\mu_{\text{D}} = \frac{2\times35}{37} = 1.892\) u, \(\omega \propto 1/\sqrt\mu\)이므로 \(\sqrt{0.972/1.892} \approx 0.717\)배.

1.2.2

실습회전-진동 흡수 스펙트럼

실습 · 이원자 분자

다루는 성취기준 [물리7-01-02]

목표

회전 상수, 진동 에너지, 온도를 바꾸며 이원자 분자의 회전-진동 흡수선이 P, R 두 가지로 늘어서는 모습과 세기 분포를 보고, 선 간격에서 결합 길이를 구합니다. 성취기준 [물리7-01-02].

준비

진동이 \(n = 0 \to 1\)로 들뜨며 회전이 \(\ell \to \ell \pm 1\)로 바뀌는 선들입니다. 세기는 처음 회전 준위의 점유 \((2\ell + 1)e^{-E_\ell/kT}\)에 비례한다고 단순화했습니다. 기본값은 HCl과 비슷합니다.

절차

  1. 기본값(HCl, 300 K)에서 선 간격과 가운데의 빈자리를 본다.
  2. 출력의 결합 길이를 1.2절 예제(약 0.13 nm)와 비교한다.
  3. 온도를 50 K와 1000 K로 바꿔 세기 분포가 어떻게 바뀌는지 본다.
  4. B를 절반으로 하면(무거운 분자, 긴 결합) 선 간격이 어떻게 되는지 본다.

기대 결과

  • 선 간격 2B ≈ 2.6 meV, ħω 자리(Δℓ = 0)에는 선이 없다.
  • 결합 길이 약 0.13 nm.
  • 온도가 낮으면 낮은 ℓ만 점유되어 가운데 근처 선만 강하고, 온도가 높으면 바깥까지 넓게 퍼진다.
  • B가 절반이면 선 간격도 절반으로 촘촘해진다.

분석

  1. 세기가 가장 큰 ℓ이 온도에 따라 어떻게 바뀌는지 \((2\ell + 1)e^{-B\ell(\ell+1)/kT}\)의 최댓값으로 설명해 보세요.
  2. 실제 HCl 스펙트럼에서는 R 가지의 선 간격이 바깥으로 갈수록 좁아집니다. 진동 상태에 따라 결합 길이가 달라진다는 것으로 생각해 보세요.
