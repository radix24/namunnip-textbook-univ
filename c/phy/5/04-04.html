이 절에서 배울 것
  • 멀리 있는 전하 분포의 전위를 \(1/r\)의 거듭제곱으로 전개한다.
  • 홀극, 쌍극자, 사중극 항의 뜻과 쌍극자의 전기장을 안다.
먼저 알아야 할 것
  • 전위의 적분식 (2.3절), 르장드르 다항식 (4.3절), 테일러 전개.

4.4.1전개

원점 근처의 분포에서 멀리 떨어진 점(\(r \gg r'\))의 전위는, \(\frac1{\mathscr r}\)을 \(r'/r\)로 전개하면

\[V(\mathbf r) = \frac1{4\pi\varepsilon_0}\sum_{n=0}^\infty\frac1{r^{n+1}}\int(r')^nP_n(\cos\alpha)\rho(\mathbf r')\,d\tau'\]

(\(\alpha\)는 \(\mathbf r\)과 \(\mathbf r'\) 사이의 각). 앞의 몇 항은

  • 홀극(\(n = 0\)): \(\frac{Q}{4\pi\varepsilon_0r}\). 전체 전하.
  • 쌍극자(\(n = 1\)): \(\frac{\mathbf p\cdot\hat{\mathbf r}}{4\pi\varepsilon_0r^2}\), 쌍극자 모멘트 \(\mathbf p = \int\mathbf r'\rho\,d\tau'\).
  • 사중극(\(n = 2\)): \(1/r^3\)로 줄어든다.

멀리서는 0이 아닌 가장 낮은 차수 항이 지배합니다. 전체 전하가 0이면 쌍극자가, 쌍극자도 0이면 사중극이 주인공입니다. 전체 전하가 0일 때만 \(\mathbf p\)가 원점의 선택에 무관합니다.

4.4.2쌍극자의 전기장

\(\mathbf p = p\hat{\mathbf z}\)이면 \(V = \frac{p\cos\theta}{4\pi\varepsilon_0r^2}\)이고

\[\mathbf E = \frac{p}{4\pi\varepsilon_0r^3}\left(2\cos\theta\,\hat{\mathbf r} + \sin\theta\,\hat{\boldsymbol\theta}\right).\]

점전하(\(1/r^2\))보다 빨리(\(1/r^3\)) 줄어듭니다. 물 분자 같은 극성 분자, 안테나의 근거리장, 4.3절 도체 구의 유도 전하가 쌍극자의 예입니다.

예제 4.4.1

\(z = \pm d/2\)에 \(\pm q\)가 있는 순수한 쌍극자의 정확한 전위를 축 위(\(\theta = 0\))에서 쓰고, 쌍극자 근사와 \(r = 2d\)에서 비교하여라.

풀이. 정확: \(\frac{q}{4\pi\varepsilon_0}\left(\frac1{r - d/2} - \frac1{r + d/2}\right) = \frac{q}{4\pi\varepsilon_0}\frac{d}{r^2 - d^2/4}\). 근사: \(\frac{qd}{4\pi\varepsilon_0r^2}\). \(r = 2d\)이면 비가 \(\frac{4d^2}{4d^2 - d^2/4} = \frac{16}{15}\), 약 6.7% 차이. 다음 0이 아닌 항은 \(1/r^4\)(팔중극)입니다(대칭 때문에 사중극은 0). 아래 실습 카드에서 여러 배치의 전개 항을 비교할 수 있습니다.

요약
  1. \(V = \frac1{4\pi\varepsilon_0}\left[\frac Qr + \frac{\mathbf p\cdot\hat{\mathbf r}}{r^2} + O(r^{-3})\right]\).
  2. 쌍극자 장은 \(1/r^3\), \(2\cos\theta\hat{\mathbf r} + \sin\theta\hat{\boldsymbol\theta}\).

4.4.3연습문제

기본

  1. \(z = d\)에 \(q\), 원점에 \(-2q\), \(z = -d\)에 \(q\)인 배치의 홀극과 쌍극자 모멘트는? 멀리서 전위는 \(r\)의 몇 제곱으로 줄어드는가?
    답

    \(Q = 0\), \(\mathbf p = qd\hat{\mathbf z} - qd\hat{\mathbf z} = 0\). 사중극이 지배하여 \(1/r^3\).

4.4.2

실습멀리서 본 전하 배치

실습 · 다중극 전개

다루는 성취기준 [물리5-04-04]

목표

z축 위에 놓인 여러 전하 배치의 정확한 전위와 다중극 전개의 부분합을 로그-로그 그래프로 비교해, 멀리서 어떤 차수가 지배하는지와 근사가 언제 맞는지 확인합니다. 성취기준 [물리5-04-04].

준비

가로축은 \(\log_{10}r\), 세로축은 \(\log_{10}|V|\)입니다(\(4\pi\varepsilon_0 = 1\), 전하 단위 q, 길이 단위는 배치의 크기). 검정 곡선이 정확한 전위, 점선은 0차부터 3차까지 차례로 더한 근사입니다. 로그-로그 그래프에서 \(1/r^{n+1}\)은 기울기 \(-(n+1)\)인 직선입니다.

절차

  1. 쌍극자에서 먼 곳의 기울기가 −2인지 본다. θ = 90°로 바꿔 본다.
  2. 선형 사중극에서 홀극과 쌍극자가 0이고 기울기가 −3인 것을 본다.
  3. 원점에서 벗어난 점전하에서 차수를 늘릴수록 가까운 거리까지 근사가 맞아지는 것을 본다.
  4. 알짜 전하가 있는 배치에서 멀리서는 홀극(기울기 −1)이 지배하는 것을 본다.

기대 결과

  • 쌍극자는 멀리서 \(1/r^2\). θ = 90°에서는 \(P_1 = 0\)이라 쌍극자 항이 사라지고, 대칭 때문에 정확한 전위도 0이다.
  • 사중극은 \(1/r^3\)으로 쌍극자보다 더 빨리 줄어든다.
  • 벗어난 점전하는 홀극 항만으로도 멀리서 맞고, 차수를 더할수록 가까운 곳까지 맞는다. 배치 크기보다 가까우면(\(r < 0.5\)) 급수가 맞지 않는다.

분석

  1. 원점에서 벗어난 점전하가 쌍극자 모멘트를 가지는 까닭을 말하고, 원점을 전하 위치로 옮기면 어떻게 되는지 생각해 보세요.
  2. 중성 분자 사이의 힘이 이온 사이의 힘보다 훨씬 빨리 줄어드는 까닭을 다중극으로 설명해 보세요.
