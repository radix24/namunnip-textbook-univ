1.3.1헬름홀츠 정리

정리 1.3.1 (헬름홀츠)

벡터장 \(\mathbf F\)의 발산 \(D = \nabla\cdot\mathbf F\)와 회전 \(\mathbf C = \nabla\times\mathbf F\)가 주어지고(\(\nabla\cdot\mathbf C = 0\)이어야 함), 무한히 먼 곳에서 \(\mathbf F \to 0\)이며 \(D\), \(\mathbf C\)가 충분히 빨리 0으로 가면, \(\mathbf F\)는 하나로 정해지고

\[\mathbf F = -\nabla U + \nabla\times\mathbf W, \quad U = \frac1{4\pi}\int\frac{D(\mathbf r')}{|\mathbf r - \mathbf r'|}d\tau', \quad \mathbf W = \frac1{4\pi}\int\frac{\mathbf C(\mathbf r')}{|\mathbf r - \mathbf r'|}d\tau'.\]

전자기학이 "장의 발산과 회전"으로 쓰이는 까닭이 여기 있습니다. 맥스웰 방정식은 바로 \(\mathbf E\)와 \(\mathbf B\)의 발산과 회전을 정해 주는 네 식이고, 경계 조건과 함께 장을 완전히 정합니다. 위 적분은 1.2절의 \(\nabla^2(1/r) = -4\pi\delta^3\)에서 나옵니다.

1.3.2퍼텐셜

  • \(\nabla\times\mathbf F = 0\) (어디서나) ⟺ \(\mathbf F = -\nabla V\) ⟺ 선적분이 경로에 무관 ⟺ 닫힌 경로 적분이 0. 정전기장 \(\mathbf E\)가 이 경우다(2.3절의 전위).
  • \(\nabla\cdot\mathbf F = 0\) (어디서나) ⟺ \(\mathbf F = \nabla\times\mathbf A\) ⟺ 면적분이 경계만으로 정해짐 ⟺ 닫힌 면 적분이 0. 자기장 \(\mathbf B\)가 이 경우다(물리9의 벡터 퍼텐셜).

퍼텐셜은 유일하지 않습니다. \(V\)에 상수를 더해도, \(\mathbf A\)에 어떤 스칼라의 기울기를 더해도 장은 같습니다(게이지 자유도). 정전기학에서는 보통 무한히 먼 곳을 \(V = 0\)으로 잡습니다.

예제 1.3.2

\(\mathbf F = (yz, xz, xy)\)는 스칼라 퍼텐셜로 쓸 수 있는가? 있다면 구하여라.

풀이. \(\nabla\times\mathbf F = (x - x, y - y, z - z) = 0\). \(\mathbf F = \nabla(xyz)\)이므로 \(V = -xyz\)(\(\mathbf F = -\nabla V\) 규약).

요약
  1. 발산과 회전(+경계 조건)이 벡터장을 정한다.
  2. 회전 0 → 스칼라 퍼텐셜, 발산 0 → 벡터 퍼텐셜. 퍼텐셜은 게이지만큼 자유롭다.

1.3.3연습문제

기본

  1. \(\mathbf B = B_0\hat{\mathbf z}\)(균일)의 벡터 퍼텐셜 하나를 찾아라. 또 다른 것은?
    답

    \(\mathbf A = \frac{B_0}2(-y, x, 0)\). 또는 \(\mathbf A = (0, B_0x, 0)\). 둘은 \(\nabla(B_0xy/2)\)만큼 다르다.
