이 절에서 배울 것
  • 이상 전류원의 조건(무한 출력 저항)과 집적회로에서 저항 대신 전류원을 쓰는 이유를 안다.
  • MOS 전류 거울의 출력 전류 \(I_O = I_{REF}\frac{(W/L)_2}{(W/L)_1}\)를 유도하고, 채널 길이 변조에 의한 오차와 출력 저항 \(r_{o2}\)를 구한다.
  • BJT 전류 거울의 β 오차 \(I_O = I_{REF}/(1 + 2/\beta)\)와, 출력 저항을 높이는 캐스코드 거울의 생각을 안다.
먼저 알아야 할 것
  • MOSFET 포화 전류식과 \(\lambda\) (2.1절), \(r_o\) (2.3절), BJT 전류 관계 (3.1절), Norton 등가 (전전3 3.2절).

5.1.1왜 전류원인가

2·3단원에서는 바이어스를 저항으로 만들었습니다. 집적회로에서는 저항이 면적을 많이 차지하고 값이 ±20% 이상 흩어지지만, 같은 칩 안의 트랜지스터끼리는 매우 잘 맞습니다. 그래서 기준 전류 하나를 만들어 두고, 그 전류를 트랜지스터로 "복사"해 여러 곳에 나눠 줍니다. 이 복사기가 전류 거울입니다.

이상 전류원: 양단 전압과 관계없이 일정한 전류를 흘린다. 출력 저항(Norton 저항) 무한대.

실제 전류원의 출력 저항 \(R_o = \Delta V/\Delta I\): 전압이 변할 때 전류가 얼마나 덜 변하는가. 클수록 좋다.

5.1.2MOS 전류 거울

구조: Q1은 드레인과 게이트를 묶어(다이오드 연결) 기준 전류 \(I_{REF}\)를 받고, Q2는 Q1과 게이트·소스를 공유합니다. 출력은 Q2의 드레인 전류입니다.

구하려는 것: \(I_O\). Q1은 \(V_{DS1} = V_{GS}\) ≥ \(V_{OV}\)라 언제나 포화이고 \(I_{REF} = \frac12k_n'(W/L)_1V_{OV}^2\)입니다. Q2는 같은 \(V_{GS}\)를 받으므로 포화이기만 하면 \(I_O = \frac12k_n'(W/L)_2V_{OV}^2\). 두 식을 나누면 공정 변수와 \(V_{OV}\)가 모두 소거됩니다.

\[ I_O = I_{REF}\frac{(W/L)_2}{(W/L)_1}. \]

트랜지스터의 크기 비만으로 전류 비가 정해지므로, 같은 기준 전류에서 1배, 2배, 4배 전류를 만들 수 있습니다. 단, Q2가 포화를 유지하려면 출력 전압이 \(V_{OV}\) 이상이어야 합니다(최소 출력 전압, 전압 여유).

채널 길이 변조의 오차. \(\lambda\)를 넣으면 \(I_O/I_{REF} = \frac{(W/L)_2}{(W/L)_1}\cdot\frac{1 + \lambda V_{DS2}}{1 + \lambda V_{GS}}\). 출력 전압이 \(V_{GS}\)와 다르면 그만큼 어긋나고, 출력 전압에 따라 전류가 변합니다. 이 변화의 기울기가 출력 저항 \(R_o = r_{o2} = 1/(\lambda I_O)\)입니다.

예제 5.1.1

같은 크기 두 NMOS로 된 거울. \(I_{REF} = 100\) μA, \(V_{GS} = 0.8\) V, \(\lambda = 0.1\) V⁻¹. 출력 전압이 0.8 V, 2 V일 때 \(I_O\)와 출력 저항을 구하여라. \(V_t = 0.5\) V이면 최소 출력 전압은?

풀이. \(V_{DS2} = 0.8\) V: Q1과 조건이 같아 \(I_O = 100\) μA. \(V_{DS2} = 2\) V: \(I_O = 100 \times \frac{1.2}{1.08} \approx 111\) μA(11% 오차). 출력 저항 \(r_o \approx 1/(0.1 \times 100\,\mu) = 100\) kΩ: 1.2 V 변화에 약 12 μA 변화. 최소 출력 전압은 \(V_{OV} = 0.3\) V.

5.1.3BJT 전류 거울

같은 구조를 BJT로 만들면 같은 \(V_{BE}\)에서 같은 \(I_C\)가 흐르지만, 두 트랜지스터의 베이스 전류를 기준 전류에서 빼 가야 합니다. \(I_{REF} = I_C + 2I_C/\beta\)이므로

\[ I_O = I_C = \frac{I_{REF}}{1 + 2/\beta}. \]

β = 100이면 약 2% 작습니다. 출력 저항은 \(r_{o2} = V_A/I_O\), 최소 출력 전압은 약 0.3 V(포화 경계)입니다. 베이스 전류를 보충하는 트랜지스터를 하나 더 넣으면 오차가 \(2/\beta^2\) 수준으로 줄어듭니다.

5.1.4출력 저항 높이기: 캐스코드

\(r_o\)가 부족하면 출력 트랜지스터 위에 공통 게이트 트랜지스터를 하나 더 쌓습니다(캐스코드). 위 트랜지스터는 아래 트랜지스터의 드레인 전압을 거의 고정해 주므로, 출력 저항이 약 \(g_mr_o\)배로 커져 \(R_o \approx g_{m}r_{o}^2\)가 됩니다. 대가는 최소 출력 전압이 약 두 배(\(2V_{OV}\) 이상)로 커지는 것입니다. 예제 5.1.1의 값(\(g_m = 2I_D/V_{OV} = 0.67\) mA/V, \(r_o = 100\) kΩ)이면 \(g_mr_o \approx 67\), 출력 저항이 약 6.7 MΩ이 됩니다.

흔한 오해(1) "전류 거울은 어떤 출력 전압에서도 같은 전류를 낸다": 출력 트랜지스터가 포화에서 벗어나면(출력 전압 < \(V_{OV}\)) 전류가 급격히 줄고, 포화 안에서도 \(r_o\) 때문에 조금씩 변합니다. (2) 다이오드 연결 트랜지스터를 "다이오드"로 보고 0.7 V를 쓰는 실수: MOS에서는 \(V_{GS} = V_t + V_{OV}\)이고 전류에 따라 다릅니다. (3) 크기 비를 W만으로 맞추는 실수: 길이 L도 같아야 \(\lambda\)와 문턱 전압이 같아져 비가 정확합니다.
요약
  1. MOS 거울: \(I_O = I_{REF}(W/L)_2/(W/L)_1\), 출력 \(\ge V_{OV}\)에서 동작, \(R_o = r_{o2}\).
  2. \(\lambda\) 오차: \((1 + \lambda V_{DS2})/(1 + \lambda V_{GS})\). BJT: \(I_O = I_{REF}/(1 + 2/\beta)\).
  3. 캐스코드: \(R_o \approx g_mr_o^2\), 대가는 전압 여유.

5.1.5연습문제

기본

  1. \((W/L)_1 = 10\), \((W/L)_2 = 40\), \(I_{REF} = 50\) μA이면 \(I_O\)는(\(\lambda = 0\))?
    답

    200 μA.

  2. β = 50인 BJT 거울의 오차는 몇 %인가?
    답

    \(1/(1 + 0.04) = 0.962\), 약 3.8% 작음.

응용

  1. \(V_{DD} = 3\) V에서 \(V_{GS} = 0.8\) V가 되는 기준 전류 100 μA를 저항 하나로 만들려면 R은?
    답

    R은 \(V_{DD}\)와 다이오드 연결 Q1의 게이트 사이: \((3 - 0.8)/100\,\mu = 22\) kΩ.

심화

  1. 예제 5.1.1 거울의 출력이 0.8 V와 2.8 V 사이에서 움직이는 부하에 전류를 공급한다. 전류 변화폭은? 캐스코드로 바꾸면(\(R_o\) ≈ 6.7 MΩ)?
    답

    단순 거울: \(2\text{ V}/100\text{ k} = 20\) μA(약 20%). 캐스코드: \(2/6.7\text{ M} \approx 0.3\) μA(약 0.3%).

5.1.2

탐구전류를 복사하는 거울, 얼마나 정확한가

탐구 · 단순 거울과 캐스코드의 출력 특성

다루는 성취기준 [전전8-05-01]

질문

전류 거울의 출력 전압이 바뀌면 출력 전류는 얼마나 변할까요? 트랜지스터 하나를 더 쌓으면 얼마나 좋아질까요?

준비

NMOS 거울을 제곱 법칙(\(\lambda\) 포함, 트라이오드 포함)으로 풉니다. 기준 전류 100 μA에서 \(V_{GS} = 0.8\) V(\(V_t = 0.5\) V, \(V_{OV} = 0.3\) V)가 되도록 소자를 정했습니다. 빨강: 단순 거울, 파랑: 캐스코드 거울(위 트랜지스터의 게이트를 \(2V_{GS} = 1.6\) V로 바이어스). 점선은 목표 전류입니다. 출력 저항은 1.5~2.5 V 구간의 기울기로 잽니다.

해 보기와 설명

  1. 예제 확인처음 화면: 단순 거울은 0.8 V에서 100.0 μA, 2 V에서 111.1 μA(5.1절 예제 5.1.1), 출력 저항 약 108 kΩ입니다. 캐스코드는 2 V에서 100.05 μA, 출력 저항 약 8.4 MΩ으로 거의 80배입니다.
  2. λ를 절반으로λ = 0.05(채널 길이 두 배)이면 단순 거울의 출력 저항이 약 208 kΩ으로 두 배, 캐스코드는 약 30 MΩ으로 거의 네 배(\(r_o^2\)에 비례)가 됩니다.
  3. 크기 비 2목표 200 μA. 단순 거울은 2 V에서 222.2 μA, 출력 저항은 전류가 두 배라 약 54 kΩ으로 절반입니다.
  4. 낮은 출력 전압단순 거울은 0.3 V(\(V_{OV}\)) 아래에서 급히 떨어집니다. 캐스코드는 1.1 V 아래에서 위 트랜지스터가 포화를 벗어나 곡선이 기울기 시작합니다. 높은 출력 저항의 대가가 이 전압 여유입니다.

연결과 적용

연산증폭기 칩 안에는 기준 전류 하나에서 복사한 전류 거울이 수십 개 들어 있습니다. 6단원 차동 쌍의 꼬리 전류원과 능동 부하가 모두 전류 거울입니다.

흔한 오해

  • "캐스코드는 언제나 더 좋다." 출력 저항은 크지만 쓸 수 있는 출력 전압 범위가 줄어듭니다. 전원 전압이 1 V 근처인 최신 칩에서는 이것이 큰 제약입니다.
