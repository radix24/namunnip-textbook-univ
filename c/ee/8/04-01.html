4.1.1증폭기를 세 숫자로 나타내기

증폭기 내부가 아무리 복잡해도, 바깥에서 보면 세 가지로 충분합니다.

입력 저항 \(R_{in}\): 입력 단자에서 들여다본 저항. 신호원 저항 \(R_{sig}\)와 분압되어 입력에 실제로 들어가는 신호를 정한다.

개방 전압 이득 \(A_{vo}\): 부하가 없을 때 \(v_o/v_i\).

출력 저항 \(R_{out}\): 입력 신호를 0으로 두고 출력에서 들여다본 저항. 부하 \(R_L\)과 분압된다.

그러면 신호원부터 부하까지의 전체 이득은 분압 두 번과 이득 한 번의 곱입니다.

\[ G_v = \frac{v_o}{v_{sig}} = \frac{R_{in}}{R_{in} + R_{sig}}\cdot A_{vo}\cdot\frac{R_L}{R_L + R_{out}}. \]

좋은 전압 증폭기는 \(R_{in} \gg R_{sig}\), \(R_{out} \ll R_L\)이어야 앞뒤 손실이 없습니다. 이 식이 4.2절에서 증폭기 구조를 고르는 기준이 됩니다.

4.1.2공통 소스(CS) 증폭기

입력은 게이트, 출력은 드레인, 소스는 교류 접지. 2.3절에서 이미 이득을 구했습니다.

CS: \(R_{in} = \infty\)(실제로는 바이어스 저항 \(R_G\)), \(A_{vo} = -g_m(R_D \parallel r_o)\), \(R_{out} = R_D \parallel r_o\).

CE(BJT): \(R_{in} = r_\pi\), \(A_{vo} = -g_m(R_C \parallel r_o)\), \(R_{out} = R_C \parallel r_o\).

소스 저항을 남기면. 소스에 바이패스하지 않은 \(R_S\)가 있으면 T 모델로 \(i_d = v_i/(1/g_m + R_S)\)이므로 \(A_{vo} = -\frac{g_mR_D}{1 + g_mR_S}\) (\(r_o\) 무시). 분모 \(1 + g_mR_S\)만큼 이득이 줄지만, \(g_mR_S \gg 1\)이면 \(A_{vo} \approx -R_D/R_S\)로 소자 변수와 무관해지고 왜곡도 같은 비율로 줄어듭니다(음의 되먹임). BJT에서는 3.2절 예제 카드처럼 입력 저항도 \((\beta + 1)(r_e + R_E)\)로 커집니다.

4.1.3공통 게이트(CG) 증폭기

입력은 소스, 출력은 드레인, 게이트는 교류 접지. 소스 전압을 \(v_i\)만큼 올리면 \(v_{gs} = -v_i\)이므로 드레인 전류가 \(g_mv_i\)만큼 줄어듭니다. \(R_D\)를 지나는 전류가 줄면 드레인 전압은 \(g_mv_iR_D\)만큼 오르므로 출력은 입력과 같은 방향(비반전)입니다. 또 입력 단자로 들어가는 신호 전류가 곧 그 \(g_mv_i\)이므로 입력 저항은 \(1/g_m\)입니다.

CG(\(r_o\) 무시): \(R_{in} = 1/g_m\), \(A_{vo} = +g_mR_D\), \(R_{out} = R_D\).

CB(BJT): \(R_{in} = r_e\), \(A_{vo} = +\alpha R_C/r_e = +g_mR_C\), \(R_{out} = R_C\).

입력 저항이 수십~수백 Ω으로 매우 작아, 전압 증폭기로는 부적합하지만 전류를 받아 그대로 넘기는 전류 버퍼로 씁니다(낮은 임피던스 신호원, 캐스코드, 전전13의 고주파 증폭기).

4.1.4소스 폴로어(CD)

입력은 게이트, 출력은 소스, 드레인은 교류 접지. 출력이 입력을 거의 그대로 따라가서 폴로어라 부릅니다.

CD(\(r_o\) 무시): \(R_{in} = \infty\), 부하 \(R_L\)에서 \(A_v = \frac{R_L}{R_L + 1/g_m}\), \(A_{vo} = 1\), \(R_{out} = 1/g_m\).

CC(이미터 폴로어): \(R_{in} = (\beta + 1)(r_e + R_L)\), \(A_v = \frac{R_L}{R_L + r_e}\), \(R_{out} = r_e + \frac{R_{sig}}{\beta + 1}\).

이득은 1보다 조금 작지만 입력 저항이 크고 출력 저항이 작아, 큰 저항의 신호원으로 작은 저항의 부하를 구동하는 전압 버퍼로 씁니다.

예제 4.1.1

\(g_m = 2\) mA/V인 MOSFET으로 세 구조를 만들었다(\(R_D = 5\) kΩ, \(r_o\) 무시). 부하 \(R_L = 10\) kΩ, 신호원 저항 \(R_{sig} = 1\) kΩ일 때 각 구조의 \(G_v\)를 구하여라. (폴로어는 \(R_D\) 없이 드레인을 \(V_{DD}\)에 연결)

풀이.

구조\(R_{in}\)\(A_{vo}\)\(R_{out}\)\(G_v\)
CS∞−105 kΩ\(1 \times (-10) \times \frac{10}{15} = -6.67\)
CG500 Ω+105 kΩ\(\frac{0.5}{1.5} \times 10 \times \frac{10}{15} = +2.22\)
CD∞1500 Ω\(1 \times 1 \times \frac{10}{10.5} = 0.952\)

CG는 개방 이득이 CS와 같은 크기인데도 입력 분압 때문에 전체 이득이 1/3로 줄었습니다. 폴로어는 이득은 없지만 출력 저항이 500 Ω으로 작아, 부하가 1 kΩ으로 작아져도 \(G_v = 1/1.5 = 0.67\)을 유지합니다(CS는 \(-10 \times 1/6 = -1.67\)로 급감).

흔한 오해(1) "개방 이득이 큰 구조가 언제나 낫다": 신호원과 부하의 저항이 전체 이득을 크게 바꿉니다. 세 숫자를 함께 보세요. (2) 출력 저항을 구할 때 입력 신호원을 그대로 두는 실수: \(v_{sig} = 0\)으로 두고(단락, \(R_{sig}\)는 남김) 출력에 시험 전원을 걸어 구합니다. 이미터 폴로어의 \(R_{out}\)에 \(R_{sig}/(\beta + 1)\)이 나타나는 것이 그 때문입니다. (3) 폴로어의 이득을 정확히 1로 쓰는 실수: \(R_L\)과 \(1/g_m\)의 분압이라 1보다 작습니다.
요약
  1. \(G_v = \frac{R_{in}}{R_{in} + R_{sig}}A_{vo}\frac{R_L}{R_L + R_{out}}\).
  2. CS: ∞, \(-g_mR_D\), \(R_D\). CG: \(1/g_m\), \(+g_mR_D\), \(R_D\). CD: ∞, 1, \(1/g_m\). (BJT는 \(R_{in}\)에 \(r_\pi\), \(r_e\), \((\beta + 1)(r_e + R_L)\))
  3. 소스 저항: \(A_{vo} = -g_mR_D/(1 + g_mR_S)\). 이득을 내주고 안정성·선형성을 얻는다.

4.1.5연습문제

기본

  1. \(g_m = 4\) mA/V, \(R_D = 10\) kΩ, \(r_o = 50\) kΩ인 CS의 \(A_{vo}\)와 \(R_{out}\)은?
    답

    \(R_D \parallel r_o = 8.33\) kΩ, \(A_{vo} = -33.3\), \(R_{out} = 8.33\) kΩ.

  2. \(I_C = 2\) mA, β = 100 이미터 폴로어의 \(R_{out}\)은(\(R_{sig} = 10\) kΩ)?
    답

    \(r_e \approx 12.4\) Ω + \(10000/101 = 99\) Ω ≈ 111 Ω.

응용

  1. \(g_m = 2\) mA/V, \(R_D = 10\) kΩ인 CS에 소스 저항 1 kΩ을 남기면 \(A_{vo}\)는? \(g_m\)이 3 mA/V로 50% 늘면?
    답

    \(-20/3 = -6.67\). \(-30/4 = -7.5\)(12.5% 증가). 소스 저항이 없을 때는 −20에서 −30(50%).

심화

  1. CG 증폭기의 입력 저항을 \(r_o\)까지 넣어 구하면 \(R_{in} = \frac{r_o + R_D}{1 + g_mr_o}\)이다. \(R_D\)가 \(r_o\)에 견줄 만큼 크면(능동 부하, 5단원) 어떻게 되는가?
    답

    \(R_D = r_o\)이면 \(R_{in} \approx 2/g_m\)으로 두 배. \(R_D \to \infty\)면 \(R_{in}\)도 커져, "CG의 입력 저항은 작다"는 \(R_D \ll r_o\)일 때만 맞습니다.

4.1.2

탐구입력을 키우면 이득이 줄고 파형이 찌그러진다

탐구 · 공통 소스 증폭기의 큰 신호 동작

다루는 성취기준 [전전8-04-01]

질문

소신호 모델은 이득이 −6이라고 말합니다. 입력을 50 mV에서 400 mV로 키우면 출력도 정말 6배일까요? 소스 저항을 남기면 무엇이 달라질까요?

준비

2.1절 예제의 공통 소스 증폭기(\(k_n = 2\) mA/V², \(V_t = 0.5\) V, \(V_{DD} = 3\) V)를 제곱 법칙 그대로(트라이오드 포함) 풀어 드레인 전압 파형을 그립니다. 동작점은 \(R_S\)와 관계없이 \(I_D = 0.25\) mA(\(g_m = 1\) mA/V)가 되도록 게이트 직류 전압을 맞춥니다. 입력은 게이트의 사인파입니다(\(R_S\)는 바이패스하지 않음). 위: 출력(파랑)과 소신호 모델의 예측(회색 점선). 아래: 출력의 1~3차 고조파 진폭.

해 보기와 설명

  1. 소신호처음 화면(50 mV): 이득 6.00으로 소신호 식과 같고, 2차 고조파가 2.50%입니다. 2.3절의 \(V_p/(4V_{OV}) = 0.05/2\)와 정확히 맞습니다.
  2. 200 mV출력이 0.446~2.460 V로 위아래가 비대칭입니다. 아래쪽이 트라이오드에 들어가 눌리면서 이득이 5.40으로 줄고 3차 고조파가 6.31%로 커집니다.
  3. 소스 저항 2 kΩ같은 200 mV에서 이득은 1.98(소신호 식 2.00)로 작지만, 2차 0.38%, 3차 0.70%로 왜곡이 크게 줄었습니다. 이득을 내주고 선형성을 얻는 되먹임입니다. 대신 동작점의 \(V_{DS}\)가 1.0 V로 줄어 봉우리에서 트라이오드에 살짝 닿습니다.
  4. 600 mV\(R_S = 0\)이면 출력 위쪽이 3.0 V(차단)에, 아래쪽이 0.24 V(트라이오드)에 붙어 사각파에 가까워집니다. 이득은 2.77로 떨어집니다.
  5. R_D = 8 kΩ소신호 이득은 8이지만 직류 \(V_D\)가 1.0 V로 내려가 아래 여유가 줄어, 200 mV에서 2차 왜곡이 15.2%가 됩니다. 이득을 키우려고 \(R_D\)만 늘리면 출력 여유를 잃습니다.

연결과 적용

오디오 증폭기의 "찌그러짐(THD)" 사양이 이 고조파 비율입니다. 실제 증폭기는 소스 저항과 같은 음의 되먹임을 여러 단에 걸쳐 크게 걸어 왜곡을 줄입니다(전전13). 아날로그실험의 공통 소스·이미터 증폭기 실습(전전9 4단원)에서 오실로스코프로 이 모양을 직접 볼 수 있습니다.

흔한 오해

  • "출력이 전원 전압 안에만 있으면 왜곡이 없다." 잘리기 훨씬 전부터 제곱 법칙 때문에 2차 왜곡이 생깁니다(50 mV에서도 2.5%).
