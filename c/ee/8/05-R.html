5.R.1

연습전류원과 능동 부하 연습 문제

문제 6 · 계산·개념·판단 · 힌트 2단계

다루는 성취기준 [전전8-05-01] [전전8-05-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산NMOS 거울: \(I_{REF} = 40\) μA, \((W/L)_1 = 5\), 출력 트랜지스터 셋의 \((W/L)\)이 5, 10, 25이다. 각 출력 전류는(\(\lambda = 0\))? [05-01]

    힌트 1

    크기 비.

    힌트 2

    \(I_O = I_{REF}(W/L)_2/(W/L)_1\).

    풀이

    40, 80, 200 μA.

  2. 계산\(V_A = 80\) V인 BJT 거울(β = 100), \(I_{REF} = 1\) mA, \(V_{BE} = 0.7\) V. 출력 전압이 0.7 V와 10.7 V일 때 출력 전류는? [05-01]

    힌트 1

    β 오차 \(1/(1 + 2/\beta)\).

    힌트 2

    Early 효과로 \(\Delta I = \Delta V/r_o\), \(r_o = V_A/I_O\).

    풀이

    0.7 V: \(1/1.02 = 0.980\) mA. \(r_o \approx 80/0.98 = 81.6\) kΩ, 10 V 더 오르면 \(+0.123\) mA → 약 1.103 mA.

  3. 개념다이오드 연결 MOSFET(게이트-드레인 단락)의 소신호 저항은 얼마인가? 그래서 이것을 부하로 쓰면 이득은? [05-02]

    힌트 1

    \(v_{gs} = v_{ds}\)라 전류원 \(g_mv\)가 자기 양단 전압에 비례.

    힌트 2

    저항 \(1/g_m \parallel r_o\).

    풀이

    약 \(1/g_m\)(\(\parallel r_o\)). 구동과 부하의 \(g_m\)이 같으면 이득 약 \(-g_{m1}/g_{m2} = -1\) 정도로 작습니다. 다이오드 연결은 부하가 아니라 거울의 입력(기준)으로 씁니다.

  4. 판단학생이 능동 부하 CS 증폭기를 만들고 측정하니 출력이 전원 쪽이나 접지 쪽에 붙어 버린다고 했다. 원인과 해결책은? [05-02]

    힌트 1

    두 전류원의 전류가 정확히 같은가요?

    힌트 2

    5.2.3.

    풀이

    NMOS 전류와 PMOS 전류의 작은 불일치가 큰 출력 저항에 걸려 출력 직류 전압이 한쪽 끝까지 밀려갑니다(한 트랜지스터가 포화를 벗어날 때까지). 차동 구조나 전체 되먹임(연산증폭기의 음되먹임)으로 직류 동작점을 잡아야 합니다.

  5. 계산\(I_D = 20\) μA, \(V_{OV} = 0.1\) V, λ(NMOS) = 0.1 V⁻¹, λ(PMOS) = 0.15 V⁻¹인 능동 부하 CS의 이득은? [05-02]

    힌트 1

    \(g_m = 2I_D/V_{OV}\).

    힌트 2

    \(r_{o1} = 500\) kΩ, \(r_{o2} = 333\) kΩ.

    풀이

    \(g_m = 0.4\) mA/V, \(r_{o1} \parallel r_{o2} = 200\) kΩ, \(A_v = -80\).

  6. 도전캐스코드 전류원의 출력 저항 \(R_o \approx g_mr_o^2\)를 소신호 해석으로 유도하라(아래 트랜지스터는 \(r_o\)만, 위 트랜지스터는 \(g_m, r_o\)). [05-01]

    힌트 1

    출력에 시험 전류 \(i_x\)를 넣으면 아래 \(r_o\)에 \(v_s = i_xr_o\)가 생긴다.

    힌트 2

    위 트랜지스터의 \(v_{gs} = -v_s\).

    풀이

    위 \(r_o\)를 흐르는 전류는 \(i_x - g_m(-v_s) = i_x + g_mi_xr_o\). \(v_x = v_s + r_o(i_x + g_mi_xr_o) = i_x(2r_o + g_mr_o^2)\). \(R_o = 2r_o + g_mr_o^2 \approx g_mr_o^2\). 위 트랜지스터가 아래 트랜지스터의 저항을 \(g_mr_o\)배로 키우는 것입니다.
