  • 여러 단을 이은 증폭기의 전체 이득을 각 단의 개방 이득과 단 사이 분압의 곱으로 구한다.
  • "각 단의 부하를 다음 단의 입력 저항으로 두고 이득을 구하는" 방법과 2포트 모델 방법이 같은 결과임을 안다.

먼저 알아야 할 것
  • 2포트 모델과 \(G_v\) 식 (4.1절), 단 잇기 (4.2절), 차동 쌍 (6.1절), 이상 연산증폭기 (전전3 4.1절).

6.3.1일반 식

n단 증폭기에서 k번째 단을 \((R_{in,k}, A_{vo,k}, R_{out,k})\)로 나타내면, k번째 단의 출력은 \(k + 1\)번째 단의 입력 저항과 분압됩니다. 그래서

\[ G_v = \frac{R_{in,1}}{R_{in,1} + R_{sig}}\prod_{k=1}^{n}\left(A_{vo,k}\cdot\frac{R_{in,k+1}}{R_{in,k+1} + R_{out,k}}\right), \quad R_{in,n+1} \equiv R_L. \]

같은 결과를 "각 단의 이득을 다음 단의 입력 저항을 부하로 달고 구한다"로 얻을 수도 있습니다. 예를 들어 CS 단의 부하 이득 \(-g_m(R_D \parallel R_{in,next})\)는 \(-g_mR_D\cdot\frac{R_{in,next}}{R_{in,next} + R_D}\)와 같습니다. 어느 쪽이든 단 사이의 분압을 빠뜨리지 않는 것이 핵심입니다.

6.3.2세 단 증폭기: 연산증폭기의 뼈대

  1. 입력단: 차동 쌍. 차동 신호를 받고 공통 모드를 제거한다. 입력 저항이 크다(MOS).
  2. 이득단: CS(또는 CE)에 능동 부하. 대부분의 전압 이득.
  3. 출력단: 폴로어(또는 푸시풀). 출력 저항을 낮춰 부하를 구동한다.

이 구조에 음되먹임을 걸면 전전3에서 이상적이라 가정했던 연산증폭기가 됩니다. 이득이 클수록 이상 연산증폭기 가정(\(v_+ = v_-\))이 잘 맞습니다.

예제 6.3.1

(1) 차동 쌍(한쪽 출력, \(g_m = 2\) mA/V, \(R_D = 5\) kΩ), (2) CS(\(g_m = 4\) mA/V, \(R_D = 4\) kΩ), (3) 소스 폴로어(\(g_m = 10\) mA/V), 부하 \(R_L = 1\) kΩ, 신호원 저항 무시. \(r_o\)는 무시한다. (가) 각 단의 \(R_{in}, A_{vo}, R_{out}\)과 전체 이득, (나) 둘째 단을 BJT 공통 이미터(β = 100, \(I_C = 0.1\) mA, 같은 컬렉터 저항 4 kΩ)로 바꾸면? (다) 폴로어를 빼면?

풀이.

단\(R_{in}\)\(A_{vo}\)\(R_{out}\)
1 차동(한쪽)∞\(g_mR_D/2 = 5\)5 kΩ
2 CS∞\(-16\)4 kΩ
3 CD∞1100 Ω
  • (가) 1→2, 2→3 사이는 다음 단 입력 저항이 무한대라 손실이 없고, 마지막 분압 \(1/1.1 = 0.909\). \(G_v = 5 \times (-16) \times 0.909 \approx -72.7\).
  • (나) 둘째 단이 CE이면 \(g_m = 0.1/0.025 = 4\) mA/V로 같지만 \(R_{in,2} = r_\pi = 25\) kΩ. 1→2 분압 \(25/30 = 0.833\). \(G_v \approx -72.7 \times 0.833 = -60.6\). 이 정도면 괜찮지만, 둘째 단 전류가 1 mA였다면 \(r_\pi = 2.5\) kΩ, 분압 \(2.5/7.5 = 1/3\)로 크게 줄었을 것입니다.
  • (다) 폴로어 없이 1 kΩ을 둘째 단에 직접 달면 마지막 분압 \(1/5\), \(G_v = 5 \times (-16) \times 0.2 = -16\). 출력단의 역할이 분명합니다.

6.3.3직류 결합과 동작점

집적회로의 다단 증폭기는 결합 축전기 없이 직류로 직접 잇습니다. 그러면 앞단의 출력 직류 전압이 곧 다음 단의 입력 바이어스가 되므로, 각 단의 직류 전압이 서로 맞도록 설계해야 합니다(예: 차동 쌍 출력 직류가 둘째 단 트랜지스터를 포화에 두도록). 직류부터 증폭할 수 있다는 장점과, 앞단의 직류 오차(오프셋)도 함께 증폭된다는 단점이 있습니다.

흔한 오해(1) 각 단의 개방 이득을 곱하고 끝내는 실수: 위 (다)처럼 분압 하나가 이득을 1/5로 만듭니다. (2) 둘째 단의 이득을 구할 때 셋째 단의 입력 저항을 부하로 넣고, 또 전체 식에서 분압을 한 번 더 곱하는 이중 계산. 한 가지 방법만 일관되게 쓰세요. (3) 마지막 단에서 \(R_{sig}\)를 생각하지 않는 실수: 폴로어의 출력 저항(이미터 폴로어는 \(r_e + R_{sig}/(\beta + 1)\))에서 "\(R_{sig}\)"는 앞단의 출력 저항입니다.
요약
  1. \(G_v\) = 입력 분압 × Π(단 이득 × 단 사이 분압). 마지막 분압의 다음 단은 \(R_L\).
  2. 입력단(차동) → 이득단(능동 부하 CS) → 출력단(폴로어) = 연산증폭기의 뼈대.
  3. 직류 결합: 각 단의 직류 전압을 서로 맞춘다. 오프셋도 증폭된다.

6.3.4연습문제

기본

  1. \(A_{vo1} = -20\), \(R_{out1} = 10\) kΩ인 단 뒤에 \(R_{in2} = 40\) kΩ, \(A_{vo2} = -10\), \(R_{out2} = 2\) kΩ인 단, 부하 2 kΩ. 전체 이득(신호원 이상적)은?
    답

    \(-20 \times 0.8 \times (-10) \times 0.5 = 80\).

응용

  1. 예제 6.3.1 (가)에서 이득단의 부하를 능동 부하로 바꿔 \(A_{vo2} = -200\), \(R_{out2} = 50\) kΩ이 되었다. 폴로어(\(R_{out} = 100\) Ω)를 그대로 두면 \(G_v\)는? 폴로어 없이 1 kΩ을 달면?
    답

    폴로어: \(5 \times (-200) \times 0.909 \approx -909\). 없으면 \(5 \times (-200) \times \frac{1}{51} \approx -19.6\).

  2. CMRR이 첫째 단에서만 정해진다고 볼 수 있는 이유는?
    답

    공통 모드 성분은 첫째 단에서 이미 CMRR배 줄어든 뒤, 뒤 단에서는 차동 신호와 똑같이 증폭되기 때문입니다(뒤 단들은 둘을 구별하지 못함).

심화

  1. 세 단 증폭기의 전체 이득이 1000이고 음되먹임으로 이득 10인 비반전 증폭기를 만들었다. 이상 연산증폭기 가정과 비교한 이득 오차는? (되먹임 계수 β = 0.1, 폐루프 이득 \(A/(1 + A\beta)\))
    답

    \(1000/(1 + 100) = 9.90\), 오차 약 1%. 개루프 이득이 10만이면 0.01%. 이득단이 클수록 이상 가정이 정확해집니다(전전13 되먹임).

6.3.2

예제세 단 증폭기의 이득 배분

예제 · 이득 1000을 어디서 얻을 것인가

다루는 성취기준 [전전8-06-03]

먼저 예측

차동 입력단(능동 부하), 이득단(능동 부하), 폴로어 출력단으로 된 증폭기가 1 kΩ 부하를 구동합니다. 전체 이득 1000의 대부분은 어느 단에서 나올까요?

생각해 본 뒤 열기

입력단과 이득단이 수십씩 나눠 갖고, 폴로어는 1보다 조금 작습니다. 단 사이 분압이 없도록 설계하는 것이 중요합니다.

문제

(1) 능동 부하 차동 입력단: \(g_{m1} = 0.5\) mA/V, 출력 저항 \(R_{o1} = 100\) kΩ, 한쪽 출력 이득 \(g_{m1}R_{o1}\). (2) 능동 부하 CS 이득단: \(g_{m2} = 1\) mA/V, \(R_{o2} = 50\) kΩ. (3) 소스 폴로어: \(g_{m3} = 10\) mA/V. 부하 \(R_L = 1\) kΩ. (가) 전체 이득을 구하라. (나) 폴로어를 빼고 \(R_L\)을 이득단에 직접 달면? (다) 셋째 단을 BJT 이미터 폴로어(β = 100, \(I_C\) = 2.5 mA, \(r_e = 10\) Ω)로 바꾸면?

전략

  1. 각 단을 \((R_{in}, A_{vo}, R_{out})\)로 정리한다.
  2. 단 사이 분압을 곱한다. MOS 입력의 \(R_{in}\)은 무한대.

풀이

  1. (1) \(A_{vo1} = 0.5 \times 100 = 50\), \(R_{out1} = 100\) kΩ. (2) \(R_{in2} = \infty\), \(A_{vo2} = -50\), \(R_{out2} = 50\) kΩ. (3) \(R_{in3} = \infty\), \(A_{vo3} = 1\), \(R_{out3} = 100\) Ω. 정리
  2. (가) \(G_v = 50 \times (-50) \times 1 \times \frac{1000}{1100} \approx -2273\). 분압은 마지막 한 번
  3. (나) \(50 \times (-50) \times \frac{1}{51} \approx -49\). \(R_{out2} = 50\) kΩ과 1 kΩ의 분압
  4. (다) 폴로어 입력 저항 \(R_{in3} = (\beta + 1)(r_e + R_L) = 101 \times 1010 \approx 102\) kΩ. 이득단 출력과의 분압 \(\frac{102}{102 + 50} = 0.671\), 폴로어 이득 \(\frac{1000}{1010} = 0.990\). 곱 0.664. \(G_v = 50 \times (-50) \times 0.664 \approx -1661\). MOS 폴로어와 달리 입력 저항이 유한

의미

BJT 폴로어는 출력 저항이 작지만(\(r_e + 50\) kΩ/101 \(\approx 505\) Ω) 입력 저항이 102 kΩ으로 유한해, 출력 저항 50 kΩ인 이득단 뒤에서 이득의 약 1/3을 잃습니다. 같은 결과를 "이득단 출력 저항이 폴로어 출력에 \(1/(\beta + 1)\)로 반사된다"로 보아 \(\frac{1000}{1000 + 505} = 0.664\)로도 얻습니다. 두 방법 중 하나만 써야 이중 계산을 피합니다(6.3절 흔한 오해 (2)). 실제 연산증폭기는 출력단 앞에 버퍼를 하나 더 두거나 출력단을 푸시풀로 만들어 이 손실을 줄입니다.

검산

(가)의 이득 2273은 이상 연산증폭기에 비하면 작지만, 비반전 이득 10으로 되먹임하면 폐루프 이득 \(2273/(1 + 227.3) \approx 9.96\)으로 오차 0.4%입니다.

이해 확인

(가)에서 이득단의 출력 저항을 캐스코드로 2 MΩ으로 키우면(\(g_{m2}\) 그대로) 폴로어 포함 전체 이득은?

답

\(A_{vo2} = -2000\), \(G_v = 50 \times (-2000) \times 0.909 \approx -90{,}900\).
