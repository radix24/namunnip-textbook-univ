2.2.1D와 Gauss 법칙

전기 선속 밀도 \(\mathbf D\) [C/m²]: 자유 공간에서 \(\mathbf D = \epsilon_0\mathbf E\). 유전체에서는 분극까지 포함해 \(\mathbf D = \epsilon\mathbf E\)(3.1절). 전계는 매질에 따라 달라지지만 \(\mathbf D\)의 선속은 자유 전하로만 정해진다.

Gauss 법칙: 닫힌 면을 나가는 전기 선속은 그 안의 (자유) 전하와 같다. \(\oint_S\mathbf D\cdot d\mathbf S = Q_{enc}\). 발산 정리로 미분형 \(\nabla\cdot\mathbf D = \rho_v\).

Gauss 법칙은 언제나 성립하지만, 전계를 구하는 데 쓰려면 적분 안의 \(\mathbf D\)를 밖으로 꺼낼 수 있어야 합니다. 그러려면 Gauss 면 위에서 \(\mathbf D\)가 (1) 면에 수직이거나 평행하고, (2) 수직인 부분에서 크기가 일정해야 합니다. 이 조건을 만드는 것이 대칭입니다: 구 대칭(구면), 원통 대칭(동축 원통면), 평면 대칭(상자 모양 면).

2.2.2세 가지 대칭

예제 2.2.1 (균일 대전 구)

반지름 a = 0.1 m인 구에 전하 Q = 1 nC이 균일하게 분포한다. 구 안팎의 전계를 구하고 r = 0.05, 0.1, 0.2 m에서 값을 적어라.

풀이. 구 대칭이라 \(\mathbf D = D_r(r)\mathbf a_r\). 반지름 r인 구면을 Gauss 면으로: \(D_r\cdot4\pi r^2 = Q_{enc}\).

  • \(r > a\): \(Q_{enc} = Q\), \(E_r = \frac{Q}{4\pi\epsilon_0r^2}\)(점전하와 같음).
  • \(r < a\): \(Q_{enc} = Q\frac{r^3}{a^3}\), \(E_r = \frac{Qr}{4\pi\epsilon_0a^3}\)(중심에서 0, 직선으로 증가).

수치: r = 0.05 m에서 449 V/m, 표면 0.1 m에서 899 V/m(최대), 0.2 m에서 225 V/m. 표면에서 두 식이 같은 값으로 이어집니다.

예제 2.2.2 (동축 원통)

동축 케이블의 안 도체(반지름 a = 1 mm)에 단위 길이당 \(+\rho_L = 1\) nC/m, 바깥 도체(안쪽 반지름 b = 4 mm)에 \(-\rho_L\)이 있다. 각 영역의 전계를 구하라.

풀이. 원통 대칭: 길이 h, 반지름 \(\rho\)인 원통면. 옆면에서만 선속이 있어 \(D_\rho\cdot2\pi\rho h = Q_{enc}\).

  • \(\rho < a\)(도체 안): 0.
  • \(a < \rho < b\): \(Q_{enc} = \rho_Lh\), \(E_\rho = \frac{\rho_L}{2\pi\epsilon_0\rho}\). \(\rho = 2\) mm에서 약 8990 V/m.
  • \(\rho > b\): 전하 합 0이라 0. 바깥 도체가 전계를 가둔다(차폐).

평면 대칭(무한 면전하)은 면을 관통하는 납작한 상자를 Gauss 면으로 잡으면 \(2D_NA = \rho_SA\)에서 \(E = \rho_S/2\epsilon_0\)으로, 2.1절의 적분 결과를 한 줄에 얻습니다.

2.2.3미분형의 쓰임

전계를 알면 \(\rho_v = \nabla\cdot\mathbf D\)로 전하 분포를 거꾸로 찾을 수 있습니다. 예제 2.2.1의 구 안에서 \(D_r = \frac{Qr}{4\pi a^3}\)이면 \(\nabla\cdot\mathbf D = \frac{1}{r^2}\frac{d}{dr}\frac{Qr^3}{4\pi a^3} = \frac{3Q}{4\pi a^3}\), 곧 균일한 전하 밀도입니다. 이 방향(장 → 원천)은 3단원 Poisson 방정식으로 이어집니다.

흔한 오해(1) "Gauss 법칙은 대칭이 있을 때만 성립한다": 법칙은 언제나 성립하고, 대칭은 그것으로 전계를 "구할" 때만 필요합니다. (2) "Gauss 면 안의 전하가 0이면 면 위의 전계도 0": 선속(총합)이 0일 뿐, 바깥 전하가 만든 전계는 면 위에 있을 수 있습니다. (3) 유한한 길이의 선전하에 원통 Gauss 면을 쓰는 실수: 끝 부분에서 대칭이 깨져 \(D\)가 일정하지 않습니다(2.1절의 유한 선 결과 참고).
요약
  1. \(\oint\mathbf D\cdot d\mathbf S = Q_{enc}\), \(\nabla\cdot\mathbf D = \rho_v\). 자유 공간 \(\mathbf D = \epsilon_0\mathbf E\).
  2. 대칭이 Gauss 면에서 \(\mathbf D\)를 상수로 만들 때 전계를 바로 얻는다: 구 \(D_r4\pi r^2\), 원통 \(D_\rho2\pi\rho h\), 평면 \(2D_NA\).
  3. 균일 구: 안 \(\propto r\), 밖 \(\propto 1/r^2\). 동축: 사이 \(\propto 1/\rho\), 밖 0.

2.2.4연습문제

기본

  1. 반지름 2 cm 도체 구의 표면 전하 밀도가 10 nC/m²이다. 표면 바로 밖의 전계는?
    답

    \(\rho_S/\epsilon_0 \approx 1129\) V/m.

응용

  1. 체적 전하 \(\rho_v = \rho_0r/a\)(\(r < a\))인 구의 전계를 구하라.
    답

    \(Q_{enc} = \int_0^r\frac{\rho_0r'}{a}4\pi r'^2dr' = \frac{\pi\rho_0r^4}{a}\). \(E_r = \frac{\rho_0r^2}{4\epsilon_0a}\)(안), \(\frac{\rho_0a^3}{4\epsilon_0r^2}\)(밖).

  2. \(\mathbf D = 4\rho\,\mathbf a_\rho\) C/m²(원통 좌표)의 전하 밀도는?
    답

    \(\frac1\rho\frac{d}{d\rho}(4\rho^2) = 8\) C/m³.

심화

  1. 무한 평판(두께 2d, \(-d < z < d\))에 균일한 \(\rho_v\)가 있다. 판 안팎의 전계를 Gauss 법칙으로 구하여라.
    답

    대칭으로 z = 0에서 0. 안: \(E_z = \rho_vz/\epsilon_0\). 밖: \(\pm\rho_vd/\epsilon_0\)(면전하 \(\rho_S = 2d\rho_v\)의 \(\rho_S/2\epsilon_0\)과 같음).

2.2.2

탐구감싼 전하만이 전계를 정한다

탐구 · 대칭 분포의 E(r)

다루는 성취기준 [전전7-02-02]

질문

전체 전하가 같은 세 가지 구(균일, 껍질, 바깥으로 갈수록 진한 분포)의 바깥 전계는 같을까요? 안쪽은 어떻게 다를까요?

준비

2.2절의 방법대로 반지름 r인 Gauss 면이 감싼 전하 \(Q_{enc}(r)\)를 구하고 \(E = Q_{enc}/(4\pi\epsilon_0r^2)\)(동축선은 \(E = (Q_{enc}/\text{길이})/(2\pi\epsilon_0\rho)\))를 그립니다. 구는 반지름 a = 0.1 m, 전체 1 nC. 주황 점선은 \(Q_{enc}\)의 비율입니다.

해 보기와 설명

  1. 균일 구r = 0.05 m에서 감싼 전하 0.125 nC, 전계 449.4 V/m(2.2절 예제). 표면에서 최대 898.8 V/m.
  2. 껍질안쪽은 감싼 전하가 0이라 전계 0, 표면에서 갑자기 898.8 V/m로 뜁니다. 표면 전하가 있는 곳에서 법선 전계가 불연속입니다(3.1절 경계 조건).
  3. ρ_v ∝ r안쪽 전계가 \(r^2\)에 비례합니다. 세 분포 모두 r > a에서는 같은 곡선입니다.
  4. 동축선안 도체(0.05 m) 안과 바깥 도체(0.15 m) 밖은 0이고, 사이는 \(1/\rho\)입니다. 바깥 도체가 전계를 가둡니다.

연결과 적용

바깥에서 재는 전계만으로는 전하가 안쪽에 어떻게 분포하는지 알 수 없습니다. 반대로 원하는 전계 분포를 만들려면 전하를 어떻게 놓아야 하는지가 3단원 이후의 설계 문제입니다.

흔한 오해

  • "구 껍질 안에서도 껍질 전하가 전계를 만든다." 껍질 안의 모든 점에서 각 방향의 기여가 정확히 상쇄되어 0입니다(감싼 전하 0).
