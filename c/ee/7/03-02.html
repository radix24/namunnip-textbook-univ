3.2.1정전용량을 구하는 절차

정전용량 \(C = Q/V_0\): 두 도체에 \(+Q\), \(-Q\)를 주었을 때 두 도체 사이 전위차 \(V_0\)에 대한 비. 도체의 모양, 간격, 유전체로만 정해지고 Q와 무관하다.

  1. 한 도체에 +Q, 다른 도체에 −Q를 준다.
  2. Gauss 법칙으로 두 도체 사이의 \(\mathbf D\), 그리고 \(\mathbf E = \mathbf D/\epsilon\)를 구한다.
  3. −Q 도체에서 +Q 도체까지 \(V_0 = -\int\mathbf E\cdot d\mathbf L\).
  4. \(C = Q/V_0\). Q가 약분되는지 확인한다(검산).

3.2.2세 가지 기본 모양

평행판(넓이 A, 간격 d, 가장자리 효과 무시): 판 사이 \(D = Q/A\), \(E = Q/(\epsilon A)\), \(V_0 = Ed\).

\[ C = \frac{\epsilon A}{d}. \]

동축(안 반지름 a, 바깥 b, 길이 L): \(D_\rho = \frac{Q}{2\pi\rho L}\), \(V_0 = \frac{Q}{2\pi\epsilon L}\ln\frac ba\).

\[ C = \frac{2\pi\epsilon L}{\ln(b/a)}. \]

동심구(a < b): \(D_r = \frac{Q}{4\pi r^2}\), \(V_0 = \frac{Q}{4\pi\epsilon}\left(\frac1a - \frac1b\right)\).

\[ C = \frac{4\pi\epsilon ab}{b - a}, \qquad b \to \infty:\ C = 4\pi\epsilon a\ (\text{고립 구}). \]
예제 3.2.1

(가) 넓이 1 cm², 간격 0.1 mm, \(\epsilon_r = 4\)인 평행판, (나) a = 0.45 mm, b = 1.47 mm, \(\epsilon_r = 2.25\)(폴리에틸렌)인 동축 케이블의 단위 길이당 정전용량, (다) 지구(반지름 6370 km)를 고립 구로 볼 때의 정전용량을 구하여라.

풀이.

  • (가) \(C = \frac{4 \times 8.854\times10^{-12} \times 10^{-4}}{10^{-4}} \approx 35.4\) pF.
  • (나) \(C/L = \frac{2\pi \times 2.25 \times 8.854\times10^{-12}}{\ln(1.47/0.45)} = \frac{1.252\times10^{-10}}{1.184} \approx 106\) pF/m. 흔한 50 Ω 동축 케이블의 사양(100 pF/m 근처)과 비슷한 크기입니다(확인 필요: 실제 치수는 제조사 사양서로).
  • (다) \(4\pi\epsilon_0 \times 6.37\times10^6 \approx 709\) μF. 행성 크기여도 1 mF가 안 됩니다. 패럿이 매우 큰 단위라는 뜻입니다.

3.2.3여러 유전체

층이 판과 평행(전계가 경계에 수직): D가 층마다 같고 전압이 나뉜다 → 직렬 축전기 \(\frac1C = \frac{d_1}{\epsilon_1A} + \frac{d_2}{\epsilon_2A}\).

층이 판에 수직(전계가 경계에 평행): E가 같고 넓이가 나뉜다 → 병렬 축전기 \(C = \frac{\epsilon_1A_1 + \epsilon_2A_2}{d}\).

예: 넓이 1 cm²에 \(\epsilon_r\) = 2와 6인 층이 각 0.05 mm이면 각 35.4, 106.2 pF의 직렬로 26.6 pF입니다. 3.1절 연습 3처럼 유전율이 작은 층에 전계가 세 배 몰립니다.

흔한 오해(1) "전압을 올리면 정전용량이 커진다": Q도 같은 비율로 커질 뿐 C는 모양과 재료로만 정해집니다. (2) 동축 공식의 \(\ln(b/a)\)를 \(b/a\)나 \(b - a\)로 쓰는 실수: 전계가 \(1/\rho\)이기 때문에 로그가 나옵니다. (3) 평행판 공식은 판이 간격보다 훨씬 넓을 때 맞습니다. 판이 작으면 가장자리 전계(fringing) 때문에 실제 C가 더 큽니다.
요약
  1. ±Q 가정 → Gauss로 E → 적분으로 \(V_0\) → \(C = Q/V_0\).
  2. 평행판 \(\epsilon A/d\), 동축 \(2\pi\epsilon L/\ln(b/a)\), 동심구 \(4\pi\epsilon ab/(b - a)\), 고립 구 \(4\pi\epsilon a\).
  3. 판과 평행한 층은 직렬, 수직한 층은 병렬.

3.2.4연습문제

기본

  1. 반지름 10 cm 금속 구의 고립 정전용량과, 1 kV로 대전했을 때 전하는?
    답

    약 11.1 pF, 11.1 nC.

응용

  1. 공기 동축선(a = 1 mm)에서 C/L = 50 pF/m가 되려면 b는?
    답

    \(\ln(b/a) = 2\pi\epsilon_0/(50\text{ p}) = 1.113\), \(b \approx 3.04\) mm.

  2. 평행판의 절반 넓이만 \(\epsilon_r = 3\) 유전체로 채우면(판에 수직인 경계) 정전용량은 빈 경우의 몇 배인가?
    답

    병렬: \((1 \times 0.5 + 3 \times 0.5) = 2\)배.

심화

  1. 동축선에서 바깥 도체를 고정하고 안 도체 반지름 a를 바꿀 때, 정해진 전압에서 안 도체 표면의 전계가 가장 작아지는 a/b를 구하여라.
    힌트

    \(E(a) = \frac{V_0}{a\ln(b/a)}\)를 a에 대해 최소화.

    답

    \(a\ln(b/a)\)가 최대: 미분 \(\ln(b/a) - 1 = 0\), \(b/a = e\). 절연 파괴에 가장 강한 고전압 동축선의 설계 조건입니다.

3.2.2

예제정전용량 터치 버튼과 얇은 공기층

예제 · 직렬 유전체 층의 정전용량

다루는 성취기준 [전전7-03-02] [전전7-03-01]

먼저 예측

유리 덮개 위의 손가락과 그 아래 전극이 축전기를 이룹니다. 덮개와 전극 사이에 0.5 mm 공기 틈이 생기면 정전용량은 얼마나 줄까요? 공기층은 유리층의 절반 두께입니다.

생각해 본 뒤 열기

4.5분의 1로 줄어듭니다. 유전율이 작은 공기층이 직렬로 들어가 전압 대부분을 차지하기 때문입니다.

문제

전극 넓이 1 cm², 그 위 유리 두께 1 mm(\(\epsilon_r = 7\), 가상의 값), 손가락은 유리 위에 닿는 접지 도체로 본다. (가) 정전용량, (나) 유리와 전극 사이에 0.5 mm 공기 틈이 생겼을 때의 정전용량, (다) (나)에서 3 V를 걸 때 각 층의 전계와 전압을 구하여라. 가장자리 효과는 무시한다.

전략

  1. 층이 판과 평행하므로 직렬 축전기(3.2.3).
  2. 각 층에서 D가 같다(법선 D 연속) → \(E_i = D/\epsilon_i\).

풀이

  1. (가) \(C_g = \frac{7\epsilon_0 \times 10^{-4}}{10^{-3}} \approx 6.20\) pF. \(\epsilon A/d\)
  2. (나) 공기층 \(C_a = \frac{\epsilon_0 \times 10^{-4}}{0.5\times10^{-3}} \approx 1.77\) pF. 직렬 \(C = \frac{1}{1/6.20 + 1/1.77} \approx 1.38\) pF, 4.5분의 1. 직렬
  3. (다) D 같음: \(E_a = 7E_g\). \(3 = E_g(1\text{ mm}) + 7E_g(0.5\text{ mm})\) → \(E_g = 667\) V/m, \(E_a = 4667\) V/m. 공기층 전압 2.33 V, 유리층 0.67 V. 경계 조건

의미

얇은 공기층이 유리보다 전압을 3.5배 많이 가져갑니다. 터치 센서는 손가락이 닿을 때의 작은 정전용량 변화(수 pF)를 재므로, 조립 공차로 생긴 공기 틈 하나가 감도를 크게 떨어뜨립니다. 그래서 덮개를 전극에 접착제로 밀착시킵니다. 같은 원리로 고전압 절연에서 절연체 사이의 공기 틈(기포)은 전계가 몰려 방전이 먼저 시작되는 약점이 됩니다.

검산

전하로 확인: \(Q = CV = 1.38\text{ pF} \times 3 = 4.13\) pC, \(D = Q/A = 4.13\times10^{-8}\) C/m². \(E_g = D/(7\epsilon_0) = 667\) V/m. 일치합니다.

이해 확인

공기 틈을 \(\epsilon_r = 3\) 접착제로 채우면(두께 0.5 mm 그대로) 정전용량은?

답

접착층 5.31 pF, 직렬 \(1/(1/6.20 + 1/5.31) \approx 2.86\) pF. 공기 틈보다 두 배 이상 큽니다.

확인직렬 유전체의 전계
