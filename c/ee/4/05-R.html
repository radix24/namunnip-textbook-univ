5.R.1

연습순차 논리 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [전전4-05-01] [전전4-05-02] [전전4-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념D 래치 두 개를 이어 시프트 레지스터를 만들면 왜 제대로 동작하지 않나요? [05-01]

    힌트 1

    클록이 1인 동안 두 래치는 어떤 상태인가요?

    힌트 2

    투명한 문 두 개가 동시에 열려 있으면?

    풀이

    클록이 1인 동안 두 래치가 모두 투명해, 입력이 첫째 래치를 지나 곧바로 둘째 래치까지 통과합니다. 한 클록에 한 칸이 아니라 여러 칸이 밀립니다. 모서리에서만 저장하는 플립플롭을 써야 합니다.

  2. 계산JK 플립플롭(처음 Q = 0)에 클록 모서리마다 (J, K) = (1, 0), (0, 0), (1, 1), (1, 1), (0, 1)을 넣었다. 각 모서리 뒤의 Q를 쓰세요. [05-01]

    힌트 1

    10 셋, 00 유지, 11 뒤집기, 01 리셋.

    힌트 2

    차례로 따라가세요.

    풀이

    1, 1, 0, 1, 0.

  3. 계산D 플립플롭으로 0, 2, 4, 6, 0, …(짝수만)을 세는 3비트 카운터를 설계하세요. 홀수 상태는 무관 조건으로 두고, 홀수 상태에서 시작하면 어디로 가는지 확인하세요. [05-02]

    힌트 1

    \(Q_0\)은 늘 0이면 된다.

    힌트 2

    \(Q_2Q_1\)만 보면 2비트 상향 카운터.

    풀이

    \(D_0 = 0\), \(D_1 = Q_1'\), \(D_2 = Q_2 \oplus Q_1\). 홀수 상태(예: 011)에서는 \(D_0 = 0\), \(D_1 = 0\), \(D_2 = 0 \oplus 1 = 1\) → 100으로 짝수 순환에 들어옵니다. 어떤 홀수에서도 한 클록 뒤 짝수가 됩니다.

  4. 계산\(t_{cq} = 0.5\) ns, \(t_{su} = 0.3\) ns, \(t_h = 0.1\) ns. 조합 논리 최장 4.2 ns, 최단 0.3 ns. 최대 클록과 홀드 여유, 그리고 홀드를 지키는 최대 스큐를 구하세요. [05-03]

    힌트 1

    \(f_\text{max} = 1/(0.5 + 4.2 + 0.3)\).

    힌트 2

    홀드: \(0.5 + 0.3 \ge 0.1 + t_\text{skew}\).

    풀이

    \(f_\text{max} = 200\) MHz. 홀드 여유(스큐 0) \(0.8 - 0.1 = 0.7\) ns. 최대 스큐 0.7 ns.

  5. 판단홀드 위반이 보고된 회로에서 동료가 "클록을 100 MHz에서 50 MHz로 낮추면 된다"고 했다. 맞나요? [05-03]

    힌트 1

    홀드 조건에 T가 있나요?

    힌트 2

    5.3.3.

    풀이

    틀렸습니다. 홀드 조건 \(t_{cq} + t_{cd} \ge t_h + t_\text{skew}\)에는 클록 주기가 없어 주파수를 바꿔도 위반은 그대로입니다. 빠른 경로에 버퍼를 넣거나 스큐를 줄여야 합니다.

  6. 도전4비트 링 카운터(1000 → 0100 → 0010 → 0001 → 1000)는 플립플롭 4개로 상태 4개, 2진 카운터는 2개로 4개를 만듭니다. 그런데도 링 카운터를 쓰는 이유는? [05-02]

    힌트 1

    각 상태를 알아보는 데 게이트가 필요한가요?

    힌트 2

    다음 상태 논리는?

    풀이

    링 카운터는 상태마다 비트 하나만 1이라 상태를 알아보는 디코더가 필요 없고(원-핫), 다음 상태 논리도 없어(시프트) 매우 빠르고 글리치가 없습니다. 플립플롭을 더 쓰는 대신 논리를 줄이는 절충입니다(6.1절 원-핫 부호화).
