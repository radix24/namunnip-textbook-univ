6.2.1출력은 어디에서 나오나

무어 기계: 출력 = f(현재 상태). 상태도에서 출력을 원 안에 적는다. 출력은 클록 모서리에서만 바뀐다.

밀리 기계: 출력 = f(현재 상태, 현재 입력). 출력을 화살표 위에 "입력/출력"으로 적는다. 입력이 바뀌면 모서리를 기다리지 않고 출력이 바뀐다.

두 방식은 같은 일을 할 수 있지만, 출력이 나오는 시점과 상태 수가 다릅니다.

6.2.2순서 검출기로 비교

예제 6.2.1

직렬 입력 x에서 "11"이 나타나면(겹침 허용) 출력 1을 내는 검출기를 무어와 밀리 방식으로 설계하여라.

풀이(밀리). 기억할 것: 직전 비트가 1이었는가. 상태 A(직전 0 또는 시작), B(직전 1). 전이: A —0/0→ A, A —1/0→ B, B —0/0→ A, B —1/1→ B. 출력 \(z = Bx\)(상태 B이고 지금 입력 1). 상태 2개, 플립플롭 1개(Q = 1이 B): \(Q^+ = x\), \(z = Qx\).

풀이(무어). 출력이 상태에만 달려 있으므로 "방금 11을 완성함"을 상태로 따로 둬야 합니다. 상태 A(직전 0), B(직전 1, 아직 11 아님), C(11 완성, 출력 1). 전이: A —1→ B, B —1→ C, C —1→ C, 그리고 어디서든 0이면 A. 상태 3개, 플립플롭 2개.

시점: 입력 0, 1, 1, 1, 0에서 밀리 출력은 둘째 1이 들어온 그 클록 동안(입력이 1인 동안) 1이고, 무어 출력은 다음 클록부터 1입니다. 무어가 한 클록 늦습니다. 디지털실험의 순서 검출기 카드에서 1011 검출로 같은 비교를 볼 수 있습니다.

6.2.3무엇을 고를까

밀리의 장점: 상태가 적고(보통 하나 이상 적음), 출력이 한 클록 빠르다.

밀리의 단점: 입력이 클록과 무관하게 흔들리면 출력도 그대로 흔들린다(글리치). 출력이 다음 회로의 조합 경로에 바로 이어져 임계 경로가 길어진다.

무어의 장점: 출력이 플립플롭 뒤 논리로만 정해져 모서리 사이에 안정적이다.

실무에서는 밀리 출력 뒤에 플립플롭을 하나 달아 "등록된 출력"으로 만드는 경우가 많습니다. 그러면 무어처럼 안정적이 되고, 시점은 무어와 같아집니다.

주의무어 상태도의 화살표에는 입력만, 밀리 상태도의 화살표에는 "입력/출력"을 적습니다. 섞어 쓰면 출력이 언제 바뀌는지 읽을 수 없게 됩니다.
요약
  1. 무어: 출력 = f(상태), 모서리에서만 바뀜. 밀리: 출력 = f(상태, 입력), 입력에 바로 반응.
  2. 같은 기능에서 밀리가 상태가 적고 한 클록 빠르다. 무어는 출력이 안정적이다.
  3. 밀리 출력에 플립플롭을 달면 안정성과 단순함을 함께 얻는다(대신 한 클록 늦음).

6.2.4연습문제

기본

  1. 예제 6.2.1의 밀리 기계에 입력 1, 1, 0, 1, 1, 1을 넣었을 때 출력은?
    답

    0, 1, 0, 0, 1, 1.

응용

  1. "101" 검출기(겹침 허용)의 밀리 상태도를 그려라.
    답

    A(시작) —1/0→ B, A —0/0→ A. B("1") —0/0→ C, B —1/0→ B. C("10") —1/1→ B, C —0/0→ A. 상태 3개.

심화

  1. 예제 6.2.1의 무어 기계에서 상태 할당 A = 00, B = 01, C = 11로 두고 다음 상태 식과 출력 식을 구하여라.
    답

    \(Q_0^+ = x\), \(Q_1^+ = xQ_0\), 출력 \(z = Q_1\). (10은 쓰지 않는 부호)

6.2.2

설명출력이 한 클록 늦는 것은 결함일까?

설명 · 무어와 밀리의 시점

다루는 성취기준 [전전4-06-02]

왜 필요한가

순서 검출기를 무어로 만들면 "패턴이 끝난 다음 클록"에 출력이 나옵니다. 처음 보면 느린 것 같지만, 시스템 전체에서는 이 늦음이 오히려 안정성을 줍니다. 두 방식의 시점 차이를 정확히 알아야 다른 회로와 맞물릴 때 한 클록 어긋나는 실수를 피합니다.

정의

무어 출력은 \(z = \lambda(S)\), 밀리 출력은 \(z = \lambda(S, x)\)이다. 상태는 둘 다 \(S^+ = \delta(S, x)\)로 클록 모서리에서 바뀐다.

정의를 풀어 읽기

  1. λ(S)출력이 상태만의 함수이므로 상태가 바뀌는 모서리에서만 출력이 바뀝니다. 입력의 흔들림이 출력으로 새지 않습니다.
  2. λ(S, x)입력이 직접 출력식에 들어가므로, 입력이 바뀌는 순간 출력이 바뀝니다. 같은 클록 안에서 반응합니다.
  3. δ는 같다둘의 차이는 출력 함수뿐입니다. 그래서 밀리를 무어로 바꾸려면 "출력이 1인 전이"를 상태로 만들어야 하고, 상태가 늘어납니다.

예와 반례

  • 무어의 예: 신호등(디지털실험 카드). 등의 색은 상태로만 정해집니다.
  • 밀리의 예: 자판기에서 "동전이 들어오는 그 클록에 바로 음료 문을 연다".
  • 둘 다 아님: 출력이 이전 입력들의 평균처럼 무한한 과거에 의존하면 유한상태기계로 나타낼 수 없습니다(상태가 무한).

다른 개념과의 관계

밀리 출력이 다른 밀리 기계의 입력으로 바로 이어지면, 두 기계의 조합 논리가 한 경로로 이어져 임계 경로(5.3절)가 길어지거나, 서로의 출력이 입력이 되는 고리(조합 루프)가 생길 수 있습니다. 그래서 큰 시스템은 모듈 사이 신호를 플립플롭에서 내보내는 규칙을 둡니다.

흔한 오해

  • "밀리가 늘 낫다(상태가 적고 빠르다)." 입력이 비동기적으로 흔들리는 곳에서는 밀리 출력에 글리치가 생깁니다.
  • "무어는 입력을 무시한다." 입력은 다음 상태를 통해 한 클록 뒤 출력에 반영됩니다.

확인시점

"11" 검출기에 입력 0, 1, 1이 클록 0, 1, 2에 들어온다. 밀리와 무어의 출력이 처음 1이 되는 클록은?
