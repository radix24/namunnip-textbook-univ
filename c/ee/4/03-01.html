3.1카르노 맵으로 논리 최소화

  • 진리표를 카르노 맵에 옮기고, 이웃한 1을 2·4·8칸으로 묶어 최소 곱의 합을 얻는다.

3.1.1그림으로 줄이는 이유

2.1절에서 \(A'BC + ABC = BC\)처럼 "한 변수만 다른 두 최소항은 합치면 그 변수가 사라진다"(\(X A' + XA = X\))는 것을 보았습니다. 문제는 식이 길면 어떤 항끼리 짝지을지 눈에 잘 보이지 않는다는 것입니다. 카르노 맵은 한 변수만 다른 최소항들이 그림에서 이웃하도록 진리표를 배열해, 짝짓기를 눈으로 하게 합니다.

3.1.2맵의 배치

4변수 F(A, B, C, D)는 4×4 칸입니다. 행은 AB, 열은 CD이고, 순서는 2진수 순서가 아니라 그레이 코드 순서 00, 01, 11, 10입니다. 그래서 좌우·상하로 이웃한 칸은 한 비트만 다르고, 맨 왼쪽 열과 맨 오른쪽 열(00과 10), 맨 위 행과 맨 아래 행도 이웃입니다(종이를 말아 원통처럼 생각). 칸 번호는 \(m = 8A + 4B + 2C + D\)입니다.

3.1.3묶기 규칙

  1. 1인 칸을 직사각형으로 묶는다. 크기는 1, 2, 4, 8, 16칸(2의 거듭제곱)만 된다.
  2. 묶음은 클수록 좋다. \(2^k\)칸 묶음에서는 k개 변수가 사라진다.
  3. 모든 1이 적어도 한 번 묶여야 한다. 겹쳐 묶어도 된다(멱등 \(X + X = X\)).
  4. 묶음의 수는 가능한 한 적게.

묶음 하나는 곱 항 하나가 됩니다. 묶음 안에서 값이 바뀌지 않는 변수만 남깁니다(1이면 그대로, 0이면 NOT).

정의 3.1.1 (주항과 필수 주항)

주항은 더 크게 넓힐 수 없는 묶음이다. 어떤 1을 덮는 주항이 하나뿐이면 그 주항은 필수 주항이다.

최소화 순서: (1) 모든 주항을 찾는다. (2) 필수 주항을 먼저 고른다. (3) 아직 덮이지 않은 1을 가장 적은 수의 주항으로 덮는다.

예제 3.1.2

\(F(A,B,C,D) = \Sigma m(0, 2, 5, 7, 8, 10, 13, 15)\)를 최소화하여라.

풀이. 맵에 찍으면 0, 2, 8, 10은 네 모서리, 5, 7, 13, 15는 가운데 2×2입니다. 네 모서리는 좌우·상하가 이어져 하나의 4칸 묶음이고, B = 0, D = 0이 공통이라 \(B'D'\). 가운데 묶음은 B = 1, D = 1이라 \(BD\). 둘 다 필수 주항이고 모든 1을 덮으므로 \(F = B'D' + BD\), 곧 B와 D가 같을 때 1인 XNOR입니다. 이 단원의 카르노 맵 카드의 처음 상태가 이 함수입니다.

3.1.4무관 조건

BCD 입력(0~9)처럼 어떤 입력 조합이 절대 들어오지 않으면, 그 칸의 출력은 0이든 1이든 상관없습니다. 맵에 X로 적고, 묶음을 크게 만드는 데 도움이 되면 1로, 아니면 0으로 봅니다. 7세그먼트 디코더(디지털실험 카드)에서 10~15를 X로 두면 식이 크게 줄어드는 것이 예입니다.

예제 3.1.3

BCD 입력(ABCD, 0~9)이 5 이상이면 1인 함수를 최소화하여라.

풀이. 1: 5, 6, 7, 8, 9. X: 10~15. A = 1인 행(8~15) 전체가 1 또는 X이므로 8칸 묶음 \(A\). 5, 7, 13, 15(X 포함)는 \(BD\), 6, 7, 14, 15는 \(BC\). 따라서 \(F = A + BD + BC = A + B(C + D)\). X를 쓰지 않으면 \(AB'C' + A'BD + A'BC\)로 훨씬 깁니다.

3.1.50을 묶으면 합의 곱

0인 칸을 묶으면 \(F'\)의 최소 곱의 합을 얻고, 드 모르간으로 뒤집으면 F의 최소 합의 곱(POS)입니다. 예제 3.1.2에서 0인 칸은 \(B'D + BD'\)로 묶이므로 \(F' = B'D + BD'\), \(F = (B + D')(B' + D)\). 어느 쪽이 게이트가 적은지 비교해 고릅니다.

변수가 5~6개를 넘으면 맵을 그리기 어려워 컴퓨터가 퀸-매클러스키 방법이나 휴리스틱(Espresso)으로 최소화합니다. 이 방법들도 "한 비트 다른 항 합치기 → 주항 → 최소 덮개"라는 같은 원리입니다.

주의3칸, 6칸처럼 2의 거듭제곱이 아닌 묶음, 대각선 묶음은 안 됩니다. 묶음 안에서 사라지는 변수가 정확히 k개가 되려면 \(2^k\)칸 직사각형이어야 합니다.
요약
  1. 그레이 순서 배치로 한 비트만 다른 칸이 이웃한다. 가장자리도 이웃이다.
  2. \(2^k\)칸 직사각형 묶음 = k변수가 사라진 곱 항. 크게, 적게, 빠짐없이.
  3. 필수 주항부터 고른다. 무관 조건 X는 도움이 될 때만 1로 본다.
  4. 0을 묶으면 \(F'\) → 드 모르간으로 최소 POS.

3.1.6연습문제

기본

  1. \(F(A,B,C) = \Sigma m(0, 1, 2, 3, 6)\)을 최소화하여라.
    답

    \(A' + BC'\). (0~3은 A' 4칸, 6은 2와 묶어 \(BC'\).)

응용

  1. \(F = \Sigma m(1, 3, 4, 5, 9, 11, 12, 13)\)을 최소화하여라.
    답

    \(B'D + BC'\). 1, 3, 9, 11은 \(B'D\), 4, 5, 12, 13은 \(BC'\).

심화

  1. \(F = \Sigma m(0, 1, 5, 7, 10, 14, 15)\)에서 주항을 모두 찾고, 필수 주항과 최소 식을 구하여라.
    답

    주항: \(A'B'C'\)(0,1), \(A'C'D\)(1,5), \(A'BD\)(5,7), \(BCD\)(7,15), \(ABC\)(14,15), \(ACD'\)(10,14). 필수: \(A'B'C'\)(0을 덮는 유일한 주항), \(ACD'\)(10을 덮는 유일한 주항). 이 둘이 0, 1, 10, 14를 덮고, 남은 5, 7, 15를 주항 두 개로 덮는 방법이 셋 있다: \(A'BD + BCD\), \(A'BD + ABC\), \(A'C'D + BCD\). 예를 들어 \(F = A'B'C' + ACD' + A'BD + BCD\). 모두 항 4개, 리터럴 12개라 최소 식이 하나로 정해지지 않는다.

3.1.2

탐구칸을 눌러 만드는 카르노 맵

탐구 · 주항과 최소 곱의 합

다루는 성취기준 [전전4-03-01]

질문

손으로 묶은 답이 정말 최소일까요? 1을 하나 더 넣거나 X로 바꾸면 묶음이 어떻게 달라질까요?

준비

4변수 F(A, B, C, D)의 카르노 맵입니다(행 AB, 열 CD, 그레이 순서, 칸 번호 \(8A + 4B + 2C + D\)는 칸 오른쪽 위). 칸을 누를 때마다 0 → 1 → X(무관) → 0으로 바뀝니다. 카드는 모든 주항을 찾고, 그중 가장 적은 항(같으면 가장 적은 리터럴)으로 1을 모두 덮는 조합을 골라 색 테두리로 보여 줍니다. 먼저 손으로 묶은 뒤 비교하세요.

해 보기와 설명

  1. 네 모서리"예제 3.1.2"는 네 모서리가 하나의 4칸 묶음 \(B'D'\)이 되는 것을 보여 줍니다. 맵의 가장자리가 이웃이기 때문입니다.
  2. 무관 조건"BCD ≥ 5"에서 X를 0으로 바꿔 보세요(칸을 두 번 눌러 0). 묶음이 작아지고 식이 길어집니다.
  3. 답이 여럿"연습 3"은 최소 식이 하나로 정해지지 않는 함수입니다. 카드는 그중 하나를 보여 줍니다.
  4. 줄지 않는 함수"패리티"(1의 개수가 홀수)는 바둑판 모양이라 이웃한 1이 하나도 없습니다. 최소항 8개가 그대로 남습니다. XOR 게이트가 따로 있는 이유입니다.

연결과 적용

카드가 쓰는 방법은 퀸-매클러스키(한 비트 다른 항을 반복해서 합쳐 주항을 찾고, 최소 덮개를 고름)입니다. 변수가 많으면 덮개 고르기가 매우 어려운 문제(NP-난해)가 되어, 실제 도구는 근사 방법을 씁니다.

흔한 오해

  • "모든 주항을 다 쓰면 최소다." 주항 중 일부는 다른 주항들이 이미 덮는 1만 덮습니다(연습 3). 필수 주항부터 고르고 남은 것만 덮으세요.
