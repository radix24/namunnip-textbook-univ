2.R.1

연습불 대수와 논리 게이트 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [전전4-02-01] [전전4-02-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 답은 이 단원의 불 식 계산기 카드로 검산할 수 있습니다.

  1. 개념불 대수에서 \(A + BC = (A + B)(A + C)\)가 성립하지만 보통 대수에서는 \(a + bc \ne (a + b)(a + c)\)인 이유는? [02-01]

    힌트 1

    오른쪽을 전개해 보세요.

    힌트 2

    \(AA = A\), \(A + AB = A\).

    풀이

    전개하면 \(AA + AC + AB + BC\). 불 대수에서는 \(AA = A\)(멱등)이고 \(A + AC + AB = A\)(흡수)라 \(A + BC\)가 됩니다. 보통 대수에서는 \(a\cdot a = a^2 \ne a\)라 성립하지 않습니다.

  2. 계산\(F = AB + A(B + C) + B(B + C)\)를 간단히 하세요. [02-01]

    힌트 1

    전개하면 \(AB + AB + AC + B + BC\).

    힌트 2

    B가 있으면 B를 포함한 항은 흡수됩니다.

    풀이

    \(B(B + C) = B\)(흡수). \(F = AB + AB + AC + B = B + AC\)(AB는 B에 흡수).

  3. 계산진리표가 \(F(A,B,C) = 1\)인 줄이 1, 2, 4, 7인 함수의 SOP 표준형을 쓰고, 이것이 \(A \oplus B \oplus C\)와 같음을 보이세요. [02-01]

    힌트 1

    1이 홀수 개인 줄은?

    힌트 2

    001, 010, 100, 111.

    풀이

    \(F = A'B'C + A'BC' + AB'C' + ABC\). 네 줄 모두 1의 개수가 홀수이고, XOR 세 개는 1이 홀수 개일 때 1이므로 같습니다(홀수 패리티). 이 함수는 카르노 맵에서 바둑판 모양이라 더 줄어들지 않습니다.

  4. 증명드 모르간 법칙 \((AB)' = A' + B'\)을 진리표로 증명하세요. [02-01]

    힌트 1

    네 줄을 모두 쓰세요.

    힌트 2

    왼쪽은 둘 다 1일 때만 0.

    풀이

    (A, B) = 00: 왼쪽 1, 오른쪽 1. 01: 1, 1. 10: 1, 1. 11: 0, 0. 네 경우가 모두 같으므로 성립. 변수가 0, 1뿐이라 모든 경우를 확인하는 것이 완전한 증명입니다. ∎

  5. 판단학생이 \(F = AB + CD\)를 NAND-NAND로 바꾼 뒤 "중간 신호 \((AB)'\)을 재니 A = B = 1일 때 0이 나와 회로가 고장"이라고 했다. 맞나요? [02-02]

    힌트 1

    NAND 출력은 원래 AND 출력의 무엇?

    힌트 2

    A = B = 1이면 AB = 1.

    풀이

    틀렸습니다. 중간 신호는 \((AB)'\)이므로 A = B = 1일 때 0이 정상입니다. NAND-NAND 회로의 중간 마디는 원래 회로의 반대 값입니다.

  6. 도전2-to-1 멀티플렉서 \(F = S'X + SY\)를 2입력 NAND 4개로 만드세요. [02-02]

    힌트 1

    NAND-NAND: \(F = ((S'X)'(SY)')'\).

    힌트 2

    \(S'\)을 만드는 데 하나.

    풀이

    \(N_1 = (SS)' = S'\), \(N_2 = (N_1X)'\), \(N_3 = (SY)'\), \(F = (N_2N_3)'\). 4개. 멀티플렉서 자체도 범용 소자라는 것을 4.2절에서 봅니다.
