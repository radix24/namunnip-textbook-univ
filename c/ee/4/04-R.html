4.R.1

연습조합 논리 설계 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [전전4-04-01] [전전4-04-02] [전전4-04-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념조합 회로와 순차 회로의 차이를 "같은 입력에 같은 출력"이라는 말로 설명하세요. [04-01]

    힌트 1

    가산기는 과거 입력을 기억하나요?

    힌트 2

    카운터는?

    풀이

    조합 회로는 출력이 지금 입력만으로 정해져 같은 입력에 늘 같은 출력을 냅니다. 순차 회로는 기억(상태)이 있어, 같은 입력이라도 이전에 무엇이 들어왔는지에 따라 출력이 다릅니다(5단원).

  2. 계산8비트 리플 캐리 가산기에서 \(A = 0111\,1111\), \(B = 0000\,0001\)일 때 올림이 몇 자리를 전파하나요? 이 경우가 왜 최악인가요? [04-01]

    힌트 1

    각 자리의 P = A ⊕ B.

    힌트 2

    0자리에서 생긴 올림이 어디까지 가나요?

    풀이

    0자리는 G = 1(1 + 1), 1~6자리는 P = 1이라 올림이 7자리 위(\(C_7\))까지 전파됩니다. 7자리는 A = B = 0이라 거기서 멈춥니다. 최악은 생성된 올림이 모든 자리를 지나 맨 위까지 가는 경우인데, 이 예는 거의 그렇습니다(결과 \(1000\,0000\), 부호 있는 수로는 오버플로).

  3. 계산\(F(A,B,C,D) = \Sigma m(0, 1, 6, 7, 10, 11, 12, 15)\)를 8:1 MUX(선택 A, B, C)로 구현할 때 데이터 입력을 구하세요. [04-02]

    힌트 1

    ABC = k일 때 D = 0, 1의 출력이 \(m_{2k}\), \(m_{2k+1}\).

    힌트 2

    k = 0: m0, m1 → 1, 1.

    풀이

    k = 0: 1,1 → 1. k = 1(m2, m3): 0,0 → 0. k = 2(m4, m5): 0. k = 3(m6, m7): 1. k = 4(m8, m9): 0. k = 5(m10, m11): 1. k = 6(m12, m13): 1,0 → D′. k = 7(m14, m15): 0,1 → D.

  4. 계산8-to-3 우선순위 인코더(입력 \(I_7\)이 가장 우선)의 출력 최상위 비트 \(Y_2\)의 식을 쓰세요. [04-02]

    힌트 1

    출력 번호가 4~7이면 \(Y_2 = 1\).

    힌트 2

    우선순위 때문에 \(I_4\)~\(I_7\) 중 하나라도 1이면 답이 4 이상.

    풀이

    \(Y_2 = I_7 + I_6 + I_5 + I_4\). 아래 입력은 위 입력이 있으면 무시되므로 이 OR만으로 충분합니다. (\(Y_1\)은 \(I_7 + I_6 + I_5'I_4'(I_3 + I_2)\))

  5. 판단학생이 캐리 예측 식 \(C_2 = G_1 + P_1G_0 + P_1P_0C_0\)을 "\(C_2 = G_1 + G_0 + C_0\)"로 줄였다. 반례를 드세요. [04-03]

    힌트 1

    \(G_0 = 1\)인데 1자리가 전파하지 않으면?

    힌트 2

    A = 01, B = 01.

    풀이

    A = 01, B = 01: \(G_0 = 1\), 1자리는 A = B = 0이라 \(P_1 = 0\), \(G_1 = 0\). 실제 \(C_2 = 0\)(1 + 1 = 10, 2자리로 올림 없음)인데 학생 식은 1. 0자리의 올림은 1자리가 전파할 때만 2자리에 닿습니다.

  6. 도전두 4비트 부호 없는 수가 같은지(A = B) 판단하는 비교기를 XOR(또는 XNOR)와 게이트 하나로 설계하고, A > B 판단은 감산기의 무엇으로 알 수 있는지 설명하세요. [04-01]

    힌트 1

    자리마다 같으면 XNOR가 1.

    힌트 2

    A − B를 부호 없이 하면 빌림이 생기는 때는?

    풀이

    \(E = (A_3 \odot B_3)(A_2 \odot B_2)(A_1 \odot B_1)(A_0 \odot B_0)\)(XNOR 4개 + 4입력 AND). \(A + B' + 1\)의 맨 위 올림 \(C_4\)는 A ≥ B이면 1, A < B이면 0입니다. 따라서 A > B는 \(C_4E'\).
