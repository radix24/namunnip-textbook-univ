4.2.1디코더

n비트 입력을 받아 \(2^n\)개 출력 중 입력 번호에 해당하는 하나만 1로 만드는 회로를 n-to-\(2^n\) 디코더라 합니다. 출력 \(D_k\)는 바로 최소항 \(m_k\)입니다. 2-to-4 디코더: \(D_0 = A'B'\), \(D_1 = A'B\), \(D_2 = AB'\), \(D_3 = AB\). 메모리 주소 선택(주소 → 그 칸만 활성화), 7세그먼트 표시처럼 "번호로 하나를 고르는" 곳에 씁니다.

디코더가 모든 최소항을 만들어 주므로, 함수의 최소항 출력들을 OR로 모으면 어떤 함수든 됩니다. 예: 전가산기의 \(S = \Sigma m(1, 2, 4, 7)\)과 \(C_\text{out} = \Sigma m(3, 5, 6, 7)\)을 3-to-8 디코더 하나와 4입력 OR 두 개로 만듭니다.

4.2.2인코더

디코더의 반대로, \(2^n\)개 입력 중 1인 것의 번호를 n비트로 냅니다. 입력이 둘 이상 1이면 곤란하므로, 실제로는 번호가 큰(또는 정한) 쪽을 우선하는 우선순위 인코더와 "입력이 하나라도 있는가"를 알리는 유효 비트 V를 씁니다. 키보드의 눌린 키 찾기, CPU의 여러 인터럽트 중 가장 급한 것 고르기(전전25)가 예입니다.

4.2.3멀티플렉서

여러 입력 중 하나를 골라 출력으로 보내는 스위치입니다. \(2^n\)개 데이터 입력 \(I_0, \dots\)와 n개 선택선이 있고, 4:1 MUX(선택 S1 S0)의 식은

\[ Y = S_1'S_0'I_0 + S_1'S_0I_1 + S_1S_0'I_2 + S_1S_0I_3. \]

선택선이 만드는 최소항이 해당 입력을 "통과"시키는 꼴입니다. CPU 안에서 레지스터 여러 개 중 하나를 ALU로 보내는 일, 여러 센서를 ADC 하나로 차례로 읽는 일이 멀티플렉서입니다. 반대로 하나의 입력을 고른 출력으로 보내는 것이 디멀티플렉서(구조는 디코더와 같음)입니다.

4.2.4멀티플렉서로 함수 만들기

n변수 함수는 \(2^n\):1 MUX 하나로 됩니다. 변수를 선택선에 넣고, 데이터 입력에 진리표의 출력값(0 또는 1)을 그대로 넣으면 됩니다. 그런데 더 작은 \(2^{n-1}\):1 MUX로도 됩니다.

정리 4.2.1

n변수 함수 \(F(A, B, \dots, Z)\)는 앞의 n−1개 변수를 선택선에 넣은 \(2^{n-1}\):1 MUX로 구현할 수 있다. 각 데이터 입력은 마지막 변수 Z의 함수 0, 1, Z, Z' 중 하나이다.

증명.앞의 n−1개 변수 값을 하나 정하면(선택선이 입력 하나를 고르면) F는 Z만의 함수가 된다. 1변수 함수는 \(F(Z = 0)\)과 \(F(Z = 1)\)의 두 값으로 정해지므로 00이면 0, 11이면 1, 01이면 Z, 10이면 Z' 넷뿐이다. 그 함수를 해당 데이터 입력에 넣으면 모든 입력 조합에서 MUX 출력이 F와 같다. ∎

예제 4.2.2

다수결 함수 \(F(A,B,C) = \Sigma m(3, 5, 6, 7)\)을 4:1 MUX로 구현하여라(선택 A, B).

풀이. AB = 00: F(C=0) = 0(m0), F(C=1) = 0(m1) → \(I_0 = 0\). AB = 01: m2 = 0, m3 = 1 → \(I_1 = C\). AB = 10: m4 = 0, m5 = 1 → \(I_2 = C\). AB = 11: m6 = 1, m7 = 1 → \(I_3 = 1\). 확인: A = 1, B = 0, C = 1이면 \(I_2 = C = 1\)이 출력, F = 1(둘이 1). 맞습니다.

이 생각이 FPGA의 순람표(7.2절)의 원리입니다. 메모리에 진리표를 적어 두고 입력으로 골라 읽으면 어떤 함수든 됩니다.

주의MUX로 함수를 만들 때 선택선에 넣은 변수의 순서가 데이터 입력 번호를 정합니다. 선택선 A가 상위(S1)인지 하위(S0)인지 바꾸면 \(I_1\)과 \(I_2\)가 서로 바뀝니다.
요약
  1. 디코더 출력 = 최소항. 디코더 + OR로 어떤 함수든 구현.
  2. 우선순위 인코더는 가장 우선인 1의 번호와 유효 비트를 낸다.
  3. MUX: 선택선 최소항 × 데이터 입력의 합. n변수 함수는 \(2^{n-1}\):1 MUX + 데이터 입력 {0, 1, Z, Z'}.

4.2.5연습문제

기본

  1. 3-to-8 디코더와 OR 하나로 \(F = \Sigma m(0, 3, 5)\)를 그리면 OR 입력은 몇 개인가?
    답

    3개(D0, D3, D5).

응용

  1. \(F(A,B,C) = \Sigma m(1, 2, 4, 7)\)(홀수 패리티)를 4:1 MUX로 만들어라(선택 A, B).
    답

    \(I_0 = C\), \(I_1 = C'\), \(I_2 = C'\), \(I_3 = C\).

심화

  1. 4:1 MUX 다섯 개로 16:1 MUX를 만드는 방법을 설명하여라.
    답

    첫 단 4개가 하위 선택선 S1 S0으로 각각 4개 중 하나를 고르고, 둘째 단 1개가 상위 선택선 S3 S2로 그 넷 중 하나를 고른다.

4.2.2

탐구4:1 멀티플렉서 하나로 3변수 함수 만들기

탐구 · 데이터 입력에 0, 1, C, C′

다루는 성취기준 [전전4-04-02]

질문

3변수 함수는 256가지나 됩니다. 4:1 멀티플렉서 하나와 C의 NOT만 있으면 그 전부를 만들 수 있을까요?

준비

아래 체크 상자 여덟 개가 진리표의 출력 \(F(m_0), \dots, F(m_7)\)입니다(번호 \(m = 4A + 2B + C\)). 선택선에 A, B를 넣으면 4.2절 정리 4.2.1에 따라 각 데이터 입력 \(I_k\)는 \(F(C = 0)\)과 \(F(C = 1)\)로 정해지는 0, 1, C, C′ 중 하나입니다. 그림과 출력 줄이 그 값을 알려 줍니다.

해 보기와 설명

  1. 다수결처음 상태(3, 5, 6, 7)는 예제 4.2.2의 다수결 함수입니다: \(I_0 = 0\), \(I_1 = C\), \(I_2 = C\), \(I_3 = 1\).
  2. 패리티1, 2, 4, 7만 켜면 \(I = C, C', C', C\)로, 연습문제 2의 답입니다.
  3. 모든 함수어떤 조합을 골라도 데이터 입력은 넷 중 하나로 정해집니다. 256가지 모두 구현됩니다.

연결과 적용

데이터 입력을 0/1로만 정하는 대신 메모리 비트로 바꾸면, 어떤 함수든 메모리 값만 바꿔 구현하는 FPGA의 순람표가 됩니다(7.2절의 LUT 카드).

흔한 오해

  • "n변수 함수에는 2ⁿ:1 MUX가 필요하다." 마지막 변수를 데이터 쪽으로 넘기면 절반 크기로 충분합니다.
