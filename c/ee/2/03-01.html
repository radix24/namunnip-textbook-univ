3.1.1트리 용어

트리: 노드와 간선으로 된 계층 구조. 맨 위 하나가 뿌리이고, 뿌리가 아닌 노드는 부모가 정확히 하나다(고리가 없다).

잎: 자식이 없는 노드. 깊이: 뿌리에서 그 노드까지의 간선 수. 높이: 뿌리에서 가장 깊은 잎까지의 간선 수(빈 트리는 −1, 노드 하나는 0).

이진 트리: 각 노드의 자식이 최대 둘(왼쪽, 오른쪽). 높이 h인 이진 트리의 노드는 최대 \(2^{h+1} - 1\)개이므로, n개 노드의 높이는 적어도 \(\lfloor\log_2n\rfloor\)이다.

파일 시스템의 폴더, 컴파일러가 만드는 수식 트리, 3.2절의 탐색 트리, 3.3절의 힙이 모두 트리입니다.

3.1.2깊이 우선 순회 세 가지

"뿌리를 언제 방문하는가"로 나뉩니다. 각 노드에서 할 일은 (방문, 왼쪽 부분 트리, 오른쪽 부분 트리) 세 가지입니다.

def preorder(t):  return [] if t is None else [t.key] + preorder(t.left) + preorder(t.right)
def inorder(t):   return [] if t is None else inorder(t.left) + [t.key] + inorder(t.right)
def postorder(t): return [] if t is None else postorder(t.left) + postorder(t.right) + [t.key]

전위(뿌리 → 왼쪽 → 오른쪽): 트리 복사, 구조 출력(목차).

중위(왼쪽 → 뿌리 → 오른쪽): 이진 탐색 트리에서 정렬된 순서(3.2절).

후위(왼쪽 → 오른쪽 → 뿌리): 자식을 먼저 처리해야 하는 일. 폴더 크기 계산, 메모리 해제, 수식 트리의 계산(후위 표기, 2.2절).

각 노드를 한 번씩 방문하므로 모두 O(n)입니다. (위 코드는 리스트를 이어 붙이는 비용 때문에 실제로는 더 들 수 있지만, 결과 리스트에 append하는 방식으로 쓰면 O(n)입니다.)

3.1.3레벨 순회

깊이 0, 1, 2, … 순서로 위에서 아래, 왼쪽에서 오른쪽으로 방문합니다. 먼저 발견한 노드를 먼저 처리해야 하므로 큐를 씁니다.

from collections import deque
def levelorder(t):
    out, q = [], deque([t] if t else [])
    while q:
        n = q.popleft()
        out.append(n.key)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)
    return out
예제 3.1.1

50, 30, 70, 20, 40, 60, 80, 35를 차례로 이진 탐색 트리에 넣어 만든 트리(3.2절 규칙)의 네 순회와 높이를 구하여라.

풀이. 트리: 50(30(20, 40(35, ·)), 70(60, 80)). 실습 카드의 코드 결과와 같습니다.

  • 전위: 50, 30, 20, 40, 35, 70, 60, 80
  • 중위: 20, 30, 35, 40, 50, 60, 70, 80(정렬됨)
  • 후위: 20, 35, 40, 30, 60, 80, 70, 50(뿌리가 마지막)
  • 레벨: 50, 30, 70, 20, 40, 60, 80, 35
  • 높이: 3(50 → 30 → 40 → 35)
흔한 오해(1) "전위와 후위만 알면 트리를 되살릴 수 있다": 일반 이진 트리는 중위 순회가 함께 있어야 유일하게 정해집니다(전위 + 중위, 또는 후위 + 중위). (2) 레벨 순회를 스택으로 구현하면 깊이 우선(전위의 변형)이 됩니다. (3) 재귀 순회는 트리 높이만큼 호출이 쌓이므로, 한쪽으로 치우친 긴 트리(높이 수천 이상)에서 Python의 재귀 한도(기본 1000)를 넘을 수 있습니다.
요약
  1. 이진 트리: 자식 최대 둘. n개 노드의 높이 ≥ \(\lfloor\log_2n\rfloor\).
  2. 전위(복사), 중위(정렬 출력), 후위(아래부터 계산·해제): 재귀, O(n).
  3. 레벨 순회: 큐, O(n).

3.1.4연습문제

기본

  1. 수식 트리 *( +(3, 4), −(5, 2) )의 후위 순회와 값은?
    답

    3 4 + 5 2 − *, 값 21.

응용

  1. 전위 A B D E C F, 중위 D B E A F C인 이진 트리를 그려라.
    답

    뿌리 A(전위 첫째). 중위에서 A 왼쪽 D B E, 오른쪽 F C. 왼쪽 부분: 전위 B D E → B(D, E). 오른쪽: 전위 C F, 중위 F C → C(F, ·).

  2. 트리의 노드 수와 높이를 재귀로 구하는 함수를 쓰라.
    답

    size(t) = 0 if t is None else 1 + size(t.left) + size(t.right), height(t) = -1 if t is None else 1 + max(height(t.left), height(t.right)). 둘 다 후위 순회 꼴.

심화

  1. 재귀 없이 스택으로 중위 순회를 구현하는 방법을 설명하라.
    답

    현재 노드에서 왼쪽으로 내려가며 모두 push. 더 내려갈 수 없으면 pop해 방문하고 그 노드의 오른쪽 자식으로 이동해 반복. 스택이 비고 현재 노드가 없으면 끝.

탐구네 가지 순서로 트리를 걷기

탐구 · 전위, 중위, 후위, 레벨 순회

다루는 성취기준 [전전2-03-01]

질문

같은 트리를 네 가지 순서로 방문하면 결과가 어떻게 다를까요? 중위 순회는 왜 정렬된 순서가 될까요?

준비

3.1절 예제의 트리(50, 30, 70, 20, 40, 60, 80, 35를 넣은 이진 탐색 트리)입니다. 순회를 고르고 "다음"을 누르면 한 노드씩 방문합니다. 빨강: 방금 방문, 주황: 이미 방문.

해 보기와 설명

  1. 전위50, 30, 20, 40, 35, 70, 60, 80. 뿌리를 먼저, 왼쪽 부분 트리를 다 돈 뒤 오른쪽으로 갑니다.
  2. 중위20, 30, 35, 40, 50, 60, 70, 80. 이진 탐색 트리라서 정렬된 순서입니다.
  3. 후위20, 35, 40, 30, 60, 80, 70, 50. 뿌리가 맨 마지막입니다.
  4. 레벨50, 30, 70, 20, 40, 60, 80, 35. 깊이별로 왼쪽부터입니다(큐).

연결과 적용

파일 탐색기의 폴더 크기 계산(후위), 목차 출력(전위), 정렬된 목록(중위), 가까운 것부터 찾기(레벨, 7단원의 BFS)로 쓰입니다.

흔한 오해

  • "후위는 전위를 거꾸로 한 것" 전위를 뒤집으면 80, 60, 70, 35, 40, 20, 30, 50으로 후위(20, 35, 40, 30, 60, 80, 70, 50)와 다릅니다.
