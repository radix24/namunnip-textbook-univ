3.2.1BST 성질

이진 탐색 트리: 모든 노드에서 왼쪽 부분 트리의 키는 모두 그 노드보다 작고, 오른쪽 부분 트리의 키는 모두 크다(키는 서로 다르다고 둔다).

이 성질 때문에 중위 순회가 정렬된 순서가 되고(3.1절 예제), 탐색할 때 노드 하나와 비교해 한쪽 부분 트리를 통째로 버릴 수 있습니다. 정렬된 배열의 이진 탐색을 트리 모양으로 펼친 것이고, 배열과 달리 삽입·삭제가 쉽습니다.

3.2.2탐색과 삽입

def search(t, key):
    while t is not None and t.key != key:
        t = t.left if key < t.key else t.right
    return t                       # 없으면 None

def insert(root, key):
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = insert(root.left, key)
    elif key > root.key:
        root.right = insert(root.right, key)
    return root

둘 다 뿌리에서 아래로 한 길만 내려가므로 비교 횟수는 높이 + 1 이하, O(h)입니다. 삽입은 탐색이 실패한 자리(빈 자식 자리)에 새 잎을 붙입니다.

3.2.3삭제의 세 경우

  • 잎: 그냥 떼어 낸다.
  • 자식 하나: 그 자식을 자기 자리로 끌어올린다.
  • 자식 둘: 오른쪽 부분 트리의 최솟값(후계자, 중위 순서의 바로 다음)을 찾아 키를 복사하고, 후계자를 오른쪽 부분 트리에서 지운다. 후계자는 왼쪽 자식이 없으므로 앞의 두 경우로 끝난다.
def delete(root, key):
    if root is None:
        return None
    if key < root.key:
        root.left = delete(root.left, key)
    elif key > root.key:
        root.right = delete(root.right, key)
    else:
        if root.left is None:  return root.right
        if root.right is None: return root.left
        succ = root.right
        while succ.left:
            succ = succ.left
        root.key = succ.key
        root.right = delete(root.right, succ.key)
    return root
예제 3.2.1

3.1절 예제의 트리 50(30(20, 40(35, ·)), 70(60, 80))에서 30(자식 둘), 80(잎), 70(자식 하나)을 차례로 지운 결과를 전위 순회로 적어라.

풀이. 30: 오른쪽 부분 트리 40(35)의 최솟값 35가 후계자. 30 자리에 35를 쓰고 원래 35를 지움 → 전위 50, 35, 20, 40, 70, 60, 80. 80: 잎이라 떼어 냄. 70: 남은 자식 60이 올라옴 → 전위 50, 35, 20, 40, 60, 높이 2. 실습 카드의 코드 출력과 같습니다.

3.2.4높이가 모든 것을 정한다

모든 연산이 O(h)인데, h는 입력 순서에 달려 있습니다. 무작위 순서로 넣으면 높이가 평균적으로 \(\log n\)에 비례합니다. 무작위 순서 20가지로 직접 만들어 보면 n = 1000에서 평균 높이 약 20, 노드의 평균 깊이 약 10.9이고, n = 10000에서 약 30.6, 15.8입니다(\(\log_2n\)은 각각 10, 13.3). 그러나 이미 정렬된 순서(1, 2, …, 7)로 넣으면 오른쪽으로만 늘어난 사슬이 되어 높이가 n − 1 = 6입니다. 이때 BST는 연결 리스트와 같아져 탐색이 O(n)입니다. 4단원의 균형 탐색 트리는 회전으로 높이를 늘 O(log n)으로 유지해 이 문제를 없앱니다.

흔한 오해(1) "자식이 둘인 노드는 아무 자식이나 올리면 된다": BST 성질이 깨질 수 있습니다. 후계자(또는 선행자, 왼쪽 부분 트리의 최댓값)를 써야 합니다. (2) "BST 탐색은 언제나 O(log n)": 균형일 때만입니다. (3) 같은 키를 허용하려면 "작으면 왼쪽, 크거나 같으면 오른쪽"처럼 규칙을 정해 두어야 탐색이 일관됩니다.
요약
  1. BST: 왼쪽 < 노드 < 오른쪽. 중위 순회 = 정렬.
  2. 탐색·삽입·삭제 O(h). 삭제(자식 둘)는 후계자로 바꾼다.
  3. h는 입력 순서에 따라 log n ~ n. 정렬된 입력은 최악.

3.2.5연습문제

기본

  1. 빈 BST에 40, 20, 60, 10, 30, 50, 70을 넣으면 높이는? 30을 찾는 비교 횟수는?
    답

    완전 균형, 높이 2. 40 → 20 → 30: 3번.

응용

  1. 문제 1의 트리에서 40을 지우면 뿌리는? 전위 순회는?
    답

    후계자 50이 뿌리. 전위 50, 20, 10, 30, 60, 70.

  2. BST에서 k보다 작은 키 중 가장 큰 것(floor)을 O(h)에 찾는 방법은?
    답

    뿌리부터: 키가 k보다 크거나 같으면 왼쪽으로, 작으면 그 키를 후보로 기록하고 오른쪽으로. 마지막 후보가 답.

심화

  1. 1~n을 넣는 n!가지 순서 중 높이가 n − 1(사슬)이 되는 순서는 몇 가지인가?
    답

    \(2^{n-1}\)가지(매번 남은 키 중 최솟값이나 최댓값을 넣어야 함). n = 7이면 64/5040 ≈ 1.3%.

3.2.2

탐구넣는 순서가 트리 모양을 정한다

탐구 · 이진 탐색 트리의 높이

다루는 성취기준 [전전2-03-02]

질문

같은 15개 키라도 넣는 순서에 따라 이진 탐색 트리의 높이가 3이 될 수도 14가 될 수도 있습니다. 직접 확인해 볼까요?

준비

키를 공백으로 나눠 적으면 그 순서대로 넣은 트리를 그립니다. 찾을 값을 정하면 뿌리부터 따라간 경로를 주황(찾으면 마지막 노드는 빨강)으로 표시합니다. 버튼으로 미리 준비한 순서나 무작위 순서를 넣을 수 있습니다.

해 보기와 설명

  1. 예제처음 값은 3.1절 예제입니다: 높이 3, 35를 찾는 데 50 → 30 → 40 → 35, 비교 4번.
  2. 균형"균형 순서"(40 20 60 10 30 50 70 …)는 15개로 높이 3, 가능한 최소입니다.
  3. 정렬된 순서"정렬된 순서"(5 10 … 75)는 오른쪽으로만 뻗어 높이 14가 됩니다. 찾을 값을 75로 두면 15번 비교합니다.
  4. 무작위"무작위"를 여러 번 눌러 보세요. 대개 최소 높이보다 몇 층 높지만 사슬보다는 훨씬 낮습니다.

연결과 적용

4단원의 AVL·Red-Black 트리는 넣는 순서와 상관없이 높이를 O(log n)으로 지킵니다. 데이터베이스 색인, 언어 라이브러리의 정렬된 사전(C++ map)이 그 구현입니다.

흔한 오해

  • "BST에 넣으면 자동으로 균형이 잡힌다" 기본 BST는 넣는 순서를 그대로 따릅니다. 정렬된 자료를 그대로 넣는 것이 가장 나쁜 경우입니다.
3.2.3

실습이진 탐색 트리의 삽입, 순회, 삭제

실습 · 재귀로 구현하는 BST

다루는 성취기준 [전전2-03-02]

목표

3.1·3.2절의 BST를 구현하고 네 가지 순회, 세 가지 삭제 경우, 정렬된 입력의 높이를 확인합니다. 성취기준 [전전2-03-02].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 tree_lab.py로 저장합니다.

from collections import deque

class Node:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None

def insert(root, key):
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = insert(root.left, key)
    elif key > root.key:
        root.right = insert(root.right, key)
    return root

def delete(root, key):
    if root is None:
        return None
    if key < root.key:
        root.left = delete(root.left, key)
    elif key > root.key:
        root.right = delete(root.right, key)
    else:
        if root.left is None:
            return root.right
        if root.right is None:
            return root.left
        succ = root.right                 # 오른쪽 부분 트리의 최솟값
        while succ.left:
            succ = succ.left
        root.key = succ.key
        root.right = delete(root.right, succ.key)
    return root

def preorder(t):  return [] if t is None else [t.key] + preorder(t.left) + preorder(t.right)
def inorder(t):   return [] if t is None else inorder(t.left) + [t.key] + inorder(t.right)
def postorder(t): return [] if t is None else postorder(t.left) + postorder(t.right) + [t.key]

def levelorder(t):
    out, q = [], deque([t] if t else [])
    while q:
        n = q.popleft()
        out.append(n.key)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)
    return out

def height(t):
    return -1 if t is None else 1 + max(height(t.left), height(t.right))

root = None
for k in [50, 30, 70, 20, 40, 60, 80, 35]:
    root = insert(root, k)
print("전위", preorder(root))
print("중위", inorder(root))
print("후위", postorder(root))
print("레벨", levelorder(root))
print("높이", height(root))
root = delete(root, 30)        # 자식 둘
print("30 삭제 후 전위", preorder(root))
root = delete(root, 80)        # 잎
root = delete(root, 70)        # 자식 하나
print("80, 70 삭제 후 전위", preorder(root), "높이", height(root))

skew = None
for k in range(1, 8):
    skew = insert(skew, k)
print("정렬된 순서로 넣은 트리 높이", height(skew))

절차

  1. 실행해 출력을 적습니다.
  2. 30을 지운 뒤 트리를 종이에 그려 전위 순회 결과와 맞는지 확인합니다.
  3. 마지막 줄의 "정렬된 순서로 넣은 트리"를 무작위 순서(random.shuffle)로 바꿔 높이가 어떻게 되는지 여러 번 실행해 봅니다.
