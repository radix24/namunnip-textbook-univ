2.2.1스택 ADT

스택: 한쪽 끝(top)에서만 넣고(push) 빼는(pop) 리스트. 나중에 들어간 것이 먼저 나온다(LIFO).

Python 리스트의 끝을 top으로 쓰면 append(push)와 pop()이 분할상환 O(1)입니다. 맨 앞을 top으로 쓰면 O(n)이 되므로 끝을 씁니다. 함수 호출(되돌아갈 곳을 쌓음), 웹 브라우저의 뒤로 가기, 편집기의 실행 취소가 모두 스택입니다.

2.2.2괄호 검사

구하려는 것: 문자열의 괄호 (), [], {}가 올바르게 짝지어졌는지. 핵심 관찰은 "닫는 괄호는 가장 최근에 열린, 아직 닫히지 않은 괄호와 짝이어야 한다"는 것이고, 가장 최근 것을 꺼내는 구조가 스택입니다.

def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False      # 짝이 없거나 종류가 다름
    return not stack              # 남은 여는 괄호가 있으면 실패

세 가지 실패를 모두 잡습니다: "(a[b)c]"(종류가 엇갈림), "((x)"(여는 괄호가 남음), "x)"(닫는 괄호가 먼저). 각 문자를 한 번씩 보므로 O(n)입니다.

2.2.3후위 표기

중위 표기: 연산자가 피연산자 사이에 (3 + 4). 우선순위와 괄호가 필요하다.

후위 표기(역폴란드 표기): 연산자가 피연산자 뒤에 (3 4 +). 괄호 없이 순서만으로 계산 순서가 정해진다.

후위 표기 계산. 왼쪽부터 읽으며 수는 push, 연산자는 두 개를 pop해 계산하고 결과를 push. 끝에 남은 하나가 답입니다. 빼기·나누기는 먼저 꺼낸 것이 오른쪽 피연산자임에 주의합니다.

중위 → 후위 변환. 수는 바로 출력, 연산자는 스택에 쌓되, 새 연산자보다 우선순위가 높거나 같은 연산자를 먼저 꺼내 출력합니다(왼쪽부터 계산하는 결합 규칙). 여는 괄호는 쌓고, 닫는 괄호를 만나면 여는 괄호까지 꺼냅니다.

예제 2.2.1

3 + 4 * ( 2 - 1 ) / 2를 후위 표기로 바꾸고 계산하여라.

풀이. 변환 결과 3 4 2 1 - * 2 / +. 계산: 3, 4, 2, 1을 쌓고 − → 2 − 1 = 1, * → 4 × 1 = 4, 2를 쌓고 / → 4 / 2 = 2.0, + → 3 + 2.0 = 5.0. 이 절의 실습 카드에서 코드로 같은 결과를 확인합니다.

흔한 오해(1) 빈 스택에서 pop하는 오류를 처리하지 않는 실수: 괄호 검사에서 닫는 괄호가 먼저 오면 빈 스택에서 꺼내게 됩니다. (2) 후위 계산에서 a − b를 b − a로 계산하는 실수: 먼저 꺼낸 값이 b입니다. (3) 변환에서 같은 우선순위 연산자를 꺼내지 않으면 \(8 - 3 - 2\)가 \(8 - (3 - 2) = 7\)로 계산됩니다(정답 3).
요약
  1. 스택: top에서만 push/pop, LIFO. Python 리스트의 끝으로 O(1).
  2. 괄호 검사: 여는 괄호 push, 닫는 괄호에서 pop해 짝 확인, 끝에 비어 있어야 함.
  3. 후위 계산: 수 push, 연산자는 두 개 pop. 변환: 우선순위가 높거나 같은 연산자를 먼저 꺼냄.

2.2.4연습문제

기본

  1. 후위 표기 5 1 2 + 4 * + 3 -를 계산하라.
    답

    1 + 2 = 3, 3 × 4 = 12, 5 + 12 = 17, 17 − 3 = 14.

응용

  1. ( 1 + 2 ) * ( 3 + 4 )의 후위 표기와 값은?
    답

    1 2 + 3 4 + *, 21.

  2. 스택 두 개로 큐(먼저 넣은 것이 먼저 나옴)를 만드는 방법과 분할상환 비용은?
    답

    넣기는 스택 A에 push. 꺼낼 때 B가 비었으면 A를 모두 B로 옮긴 뒤 B에서 pop. 각 원소가 한 번씩만 옮겨지므로 분할상환 O(1).

심화

  1. 거듭제곱 ^은 오른쪽 결합(2^3^2 = 2^9)이다. 변환 알고리즘을 어떻게 고쳐야 하는가?
    답

    ^에 대해서는 우선순위가 "같은" 연산자를 꺼내지 않고 "더 높은" 것만 꺼냅니다. 그러면 2 3 2 ^ ^가 되어 오른쪽부터 계산됩니다.

실습스택으로 괄호 검사기와 계산기 만들기

다루는 성취기준 [전전2-02-02]

목표

2.2절의 괄호 검사, 중위 → 후위 변환, 후위 계산을 직접 구현하고 결과를 확인합니다. 성취기준 [전전2-02-02].

준비

Python 3만 있으면 됩니다(추가 라이브러리 없음). 아래 코드를 stack_lab.py로 저장합니다.

def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

def to_postfix(expr):
    prec = {"+": 1, "-": 1, "*": 2, "/": 2}
    out, ops = [], []
    for tok in expr.split():
        if tok.isdigit():
            out.append(tok)
        elif tok == "(":
            ops.append(tok)
        elif tok == ")":
            while ops[-1] != "(":
                out.append(ops.pop())
            ops.pop()
        else:
            while ops and ops[-1] != "(" and prec[ops[-1]] >= prec[tok]:
                out.append(ops.pop())
            ops.append(tok)
    while ops:
        out.append(ops.pop())
    return " ".join(out)

def eval_postfix(post):
    st = []
    for tok in post.split():
        if tok.isdigit():
            st.append(int(tok))
        else:
            b, a = st.pop(), st.pop()
            st.append({"+": a + b, "-": a - b, "*": a * b, "/": a / b}[tok])
    return st.pop()

for s in ["(a[b]{c})", "(a[b)c]", "((x)", "{[()()]}"]:
    print(s, balanced(s))
e = "3 + 4 * ( 2 - 1 ) / 2"
p = to_postfix(e)
print(p, "=", eval_postfix(p))
print(to_postfix("( 1 + 2 ) * ( 3 + 4 )"), "=", eval_postfix(to_postfix("( 1 + 2 ) * ( 3 + 4 )")))

절차

  1. python stack_lab.py를 실행해 출력을 적습니다.
  2. balanced에 "x)", ""(빈 문자열)을 넣어 결과를 예측한 뒤 확인합니다.
  3. to_postfix("8 - 3 - 2")의 결과와 값을 확인하고, 같은 우선순위에서 꺼내는 조건 >=를 >로 바꾸면 어떻게 되는지 봅니다.

기대 결과

Python 3.12에서 실행한 출력입니다.

(a[b]{c}) True
(a[b)c] False
((x) False
{[()()]} True
3 4 2 1 - * 2 / + = 5.0
1 2 + 3 4 + * = 21
  • 괄호 검사: 엇갈림 (a[b)c]와 남은 여는 괄호 ((x)가 False입니다.
  • 3 + 4 * ( 2 - 1 ) / 2 → 3 4 2 1 - * 2 / +, 값 5.0(예제 2.2.1). 나눗셈이 실수 나눗셈이라 5.0으로 나옵니다.
  • ( 1 + 2 ) * ( 3 + 4 ) → 1 2 + 3 4 + *, 값 21.
  • 절차 3: >=이면 8 3 - 2 - = 3, >로 바꾸면 8 3 2 - - = 7로 틀립니다(오른쪽부터 계산됨).

분석

  1. balanced와 to_postfix의 시간 복잡도를 n(문자 수)으로 쓰세요. 각 문자가 스택에 몇 번 들어가고 나오나요?
  2. 토큰을 공백으로 나눈다는 가정을 없애려면(예: 3+4*2) 어떤 부분을 바꿔야 하나요?
