2.3.1차분 방정식은 계산 절차다

디지털 필터, 이자 계산, 이동 평균은 "지금 출력 = 지난 출력 몇 개와 입력 몇 개의 가중합"으로 정의됩니다.

\[ \sum_{k=0}^{N}a_k\,y[n - k] = \sum_{k=0}^{M}b_k\,x[n - k]. \]

초기 휴지(initial rest): 입력이 처음 0이 아니게 되는 시점 전에는 출력도 0이라고 정한다. 이 조건이 있어야 시스템이 LTI이고 인과적이다.

되먹임(재귀): 우변 계산에 지난 출력 \(y[n-k]\)이 쓰인다(\(N \ge 1\)). 임펄스 응답이 무한히 이어지는 IIR이 된다.

비재귀: \(N = 0\)이면 \(y[n] = \sum b_kx[n-k]\)이고 임펄스 응답이 곧 계수 \(h[n] = b_n\)인 FIR.

블록도로는 지연 소자(\(z^{-1}\)로 표시하는 한 칸 저장소), 곱셈기, 덧셈기만 쓰면 됩니다. 연속시간의 미분 방정식은 지연 대신 적분기를 써서 같은 모양으로 그립니다.

2.3.2되풀이 계산으로 임펄스 응답 구하기

예제 2.3.1

\(y[n] - 0.5y[n - 1] = x[n] + x[n - 1]\)의 임펄스 응답 \(h[n]\)을 n = 0~4까지 구하고, 일반식을 추측하여라.

풀이. \(x = \delta\), 초기 휴지로 \(h[-1] = 0\). \(h[n] = 0.5h[n-1] + \delta[n] + \delta[n-1]\)을 차례로 씁니다.

  • \(h[0] = 0 + 1 + 0 = 1\)
  • \(h[1] = 0.5 + 0 + 1 = 1.5\)
  • \(h[2] = 0.75\), \(h[3] = 0.375\), \(h[4] = 0.1875\)

n ≥ 1에서 매번 절반이 되므로 \(h[n] = \delta[n] + 3(0.5)^n u[n - 1]\)로 쓸 수 있습니다. 확인: \(n = 1\)이면 \(3 \times 0.5 = 1.5\). 이 계산은 컴퓨터가 하는 일 그대로이고, 이 절의 탐구 카드에서 계수를 바꾸며 볼 수 있습니다.

2.3.3닫힌 식: 특성근

구하려는 것: 되풀이 없이 \(h[n]\)의 일반식. 미분방정식에서 \(e^{st}\)를 시도했듯, 차분 방정식에서는 \(r^n\)을 시도합니다.

\(n > M\)에서는(우변에 입력이 \(x[n - M]\)까지 있으므로) 입력 임펄스가 지나가 우변이 0입니다. 그러면 \(h\)는 동차 방정식 \(\sum a_k h[n-k] = 0\)을 만족하고, \(h[n] = r^n\)을 넣으면

\[ a_0r^N + a_1r^{N-1} + \cdots + a_N = 0 \quad(\text{특성 방정식}). \]

근 \(r_1, \dots, r_N\)이 서로 다르면 \(h[n] = \sum c_ir_i^n\)이고, 계수 \(c_i\)는 되풀이로 구한 첫 몇 값에 맞춥니다.

안정성과의 연결. \(\sum|h| < \infty\)가 되려면 모든 항 \(r_i^n\)이 줄어들어야 하므로, 모든 특성근이 \(|r_i| < 1\)이어야 합니다(근이 복소수여도 크기로 판정). 연속시간 미분 방정식에서는 \(e^{s_it}\)가 줄어들려면 \(\text{Re}(s_i) < 0\)입니다. 7단원에서 이 근들이 Z-변환과 Laplace 변환의 극점으로 다시 나타납니다.

예제 2.3.2

\(y[n] - y[n-1] + 0.5y[n-2] = x[n]\)의 특성근과 안정성, 임펄스 응답의 모양을 구하여라.

풀이. 특성 방정식 \(r^2 - r + 0.5 = 0\)에서 \(r = \frac{1 \pm \sqrt{1 - 2}}{2} = 0.5 \pm 0.5j\). 크기 \(|r| = \sqrt{0.5} \approx 0.707 < 1\)이므로 안정. 복소 공액근이라 \(h[n]\)은 \(0.707^n\)으로 줄어드는 진동이며, 각 \(\angle r = 45°\)이므로 8표본마다 한 번 진동합니다. 되풀이로 확인하면 \(h = 1, 1, 0.5, 0, -0.25, -0.25, -0.125, 0, \dots\)로, \(n = 3\)과 \(n = 7\)에서 0을 지나며 부호가 바뀝니다.

RLC 회로의 부족 감쇠 응답(전전3 6단원)과 같은 현상을 이산시간에서 본 것입니다.

흔한 오해(1) 초기 조건을 0이 아닌 값으로 두고 "LTI 시스템의 응답"이라 부르면 안 됩니다. 초기 휴지가 아니면 입력 0에도 출력이 있어 선형이 아닙니다. (2) 계수 \(a_k\)의 부호를 옮기며 틀리기 쉽습니다. \(y[n] - 0.5y[n-1]\)을 되풀이 식으로 쓰면 \(y[n] = +0.5y[n-1] + \cdots\)입니다. (3) 특성근의 크기가 정확히 1이면(예: 누산기 \(r = 1\)) 안정이 아닙니다.
요약
  1. 차분 방정식 + 초기 휴지 = 인과 LTI 시스템. 되먹임이 있으면 IIR, 없으면 FIR(\(h = b_n\)).
  2. 임펄스 응답은 되풀이 계산으로, 또는 특성근 \(r_i\)의 합 \(\sum c_ir_i^n\)으로 구한다.
  3. 안정 ⇔ 모든 \(|r_i| < 1\) (연속은 \(\text{Re}\,s_i < 0\)). 복소근이면 감쇠 진동.

2.3.4연습문제

기본

  1. 3점 이동 평균 \(y[n] = \frac13(x[n] + x[n-1] + x[n-2])\)의 임펄스 응답은?
    답

    \(h = \{1/3, 1/3, 1/3\}\) (n = 0, 1, 2). FIR.

  2. \(y[n] = 1.1y[n-1] + x[n]\)은 안정인가?
    답

    \(r = 1.1\), \(|r| > 1\)이라 불안정(\(h = 1.1^n u[n]\)).

응용

  1. \(y[n] - 0.75y[n-1] + 0.125y[n-2] = x[n]\)의 임펄스 응답을 닫힌 식으로 구하여라.
    힌트

    근은 0.5와 0.25. \(h[0] = 1\), \(h[1] = 0.75\)에 맞추기.

    답

    \(h[n] = (2(0.5)^n - (0.25)^n)u[n]\). 확인: n = 0이면 1, n = 1이면 \(1 - 0.25 = 0.75\).

심화

  1. 원금에 매달 0.5% 이자가 붙고 매달 x[n]원을 넣는 통장 잔액 y[n]을 차분 방정식으로 쓰고, 이 시스템이 BIBO 안정이 아닌 이유를 설명하여라.
    답

    \(y[n] = 1.005y[n-1] + x[n]\). 특성근 1.005 > 1이라 매달 같은 금액(유계 입력)만 넣어도 잔액이 끝없이 커짐. 저축자에게는 반가운 불안정입니다.

2.3.2

탐구특성근이 단위원 밖으로 나가면

탐구 · 2차 차분 방정식의 임펄스 응답

다루는 성취기준 [전전6-02-03] [전전6-02-02]

질문

\(y[n] = a_1y[n-1] + a_2y[n-2] + x[n]\)에 임펄스를 넣으면 출력이 줄어들까요, 진동할까요, 커질까요? 계수 두 개만 보고 미리 알 수 있을까요?

준비

위 그래프는 되풀이 계산으로 구한 \(h[n]\) (n = 0~30), 아래는 특성 방정식 \(r^2 - a_1r - a_2 = 0\)의 두 근(×)과 단위원(점선)입니다. 처음 값은 2.3절 예제 2.3.2(\(a_1 = 1\), \(a_2 = -0.5\))입니다. 불안정하면 색이 빨강으로 바뀝니다.

해 보기와 설명

  1. 예제 확인처음 화면: 근 \(0.5 \pm 0.5j\), 크기 0.707, 각 45°. \(h = 1, 1, 0.5, 0, -0.25, -0.25, -0.125, 0\)이고 \(\sum|h| \approx 3.333\)입니다. 8표본마다 한 번 진동하며 줄어듭니다.
  2. 1차로 만들기\(a_2 = 0\), \(a_1 = 0.5\)이면 근이 0.5와 0이고 \(h = 0.5^n\), \(\sum|h| = 2\)입니다(2.2절 예제). \(a_1 = -0.9\)이면 근 −0.9, 부호가 번갈아 바뀌며 \(\sum|h| = 10\)입니다.
  3. 단위원에 가까이\(a_1 = 1.6\), \(a_2 = -0.8\)이면 근의 크기 0.894, 진동이 오래 남고 \(\sum|h| \approx 14.05\)로 커집니다. 근이 단위원에 가까울수록 오래 울리는 시스템입니다.
  4. 경계와 밖\(a_1 = 1.8\), \(a_2 = -1\)이면 근의 크기가 정확히 1이라 진동이 줄지도 늘지도 않습니다. 합이 끝없이 커지므로 BIBO 안정이 아닙니다. \(a_2 = 0.5\), \(a_1 = 1\)이면 근 1.366이 단위원 밖에 있어 h가 지수적으로 커집니다.

연결과 적용

7단원에서 이 근들은 전달함수 \(H(z)\)의 극점이 되고, "모든 극점이 단위원 안"이 인과 이산 시스템의 안정 조건으로 다시 나옵니다. 디지털 공진기, 오디오 이퀄라이저의 피크 필터가 이렇게 단위원 가까이 극점을 둔 2차 구조(biquad)입니다.

흔한 오해

  • "계수가 모두 1보다 작으면 안정이다." \(a_1 = 1\), \(a_2 = 0.5\)는 계수가 1 이하인데도 근 1.366으로 불안정합니다. 판정은 계수가 아니라 근의 크기로 합니다.
