8.1.1이상 필터

이상 저역 통과 필터: \(|\omega| < \omega_c\)에서 \(H = 1\), 나머지에서 0. 고역 통과는 그 반대, 대역 통과는 한 구간만 1, 대역 저지는 한 구간만 0.

이상 저역 통과의 임펄스 응답은 \(h(t) = \frac{\sin\omega_ct}{\pi t}\)입니다(4.1절 연습 3). 이것은 (1) \(t < 0\)에서도 0이 아니어서 비인과이고, (2) \(\int|h| = \infty\)라 BIBO 안정도 아닙니다(2.2절 연습 4). 그래서 실제 필터는 이상 필터를 "얼마나 잘 근사하는가"로 설계합니다.

8.1.2실제 필터의 사양

통과 대역 \(0 \le \omega \le \omega_p\): 크기가 1 근처(허용 리플 \(\delta_p\), 또는 최대 감쇠 \(A_p\) dB) 안에 있어야 하는 구간.

저지 대역 \(\omega \ge \omega_s\): 크기가 \(\delta_s\) 이하(최소 감쇠 \(A_s\) dB 이상)여야 하는 구간.

전이 대역 \(\omega_p < \omega < \omega_s\): 조건이 없는 구간. 좁을수록 높은 차수가 필요하다.

예를 들어 6.2절의 오디오 앤티에일리어싱 필터는 "20 kHz까지 감쇠 0.1 dB 이하, 24 kHz부터 감쇠 90 dB 이상" 같은 사양이 됩니다(값은 예시).

8.1.3Butterworth 필터

구하려는 것: 통과 대역에서 가능한 한 평평한 크기 응답. n차 Butterworth 저역 통과 필터의 크기는

\[ |H(j\omega)| = \frac{1}{\sqrt{1 + (\omega/\omega_c)^{2n}}}. \]
  • \(\omega = \omega_c\)에서 언제나 \(1/\sqrt2\) (−3 dB).
  • \(\omega \ll \omega_c\)에서 \(1 - \frac12(\omega/\omega_c)^{2n}\)로, \(\omega = 0\)에서 \(2n - 1\)번째 도함수까지 0(최대 평탄).
  • \(\omega \gg \omega_c\)에서 \(-20n\) dB/decade로 줄어든다.

극점은 반지름 \(\omega_c\)인 원 위에 각 \(\frac{\pi}{2n}(2k + n - 1)\) 간격으로 고르게 놓이고, 그중 왼쪽 반평면의 n개를 씁니다(인과·안정). n = 2이면 극점 \(\omega_ce^{\pm j3\pi/4}\), \(H(s) = \frac{\omega_c^2}{s^2 + \sqrt2\omega_cs + \omega_c^2}\)입니다.

예제 8.1.1

\(\omega_c = 1\) kHz(차단 주파수를 Hz로)인 Butterworth 저역 통과 필터로 3 kHz에서 40 dB 이상 줄이려면 차수가 얼마여야 하는가?

풀이. 40 dB 감쇠는 \(|H| \le 0.01\), 곧 \(1 + 3^{2n} \ge 10^4\). \(3^{2n} \ge 9999\)이므로 \(2n \ge \log_3 9999 \approx 8.38\), \(n \ge 4.19\). 차수는 정수라 n = 5. 확인: n = 5이면 \(3^{10} = 59049\), \(|H| = 1/\sqrt{59050} \approx 0.0041\), 약 −47.7 dB. n = 4면 \(3^8 = 6561\), 약 −38.2 dB로 모자랍니다.

8.1.4위상 응답과 군지연

군지연 \(\tau_g(\omega) = -\frac{d\angle H}{d\omega}\): 그 주파수 근처의 좁은 대역 신호(포락선)가 늦어지는 시간.

선형 위상: \(\angle H = -\omega t_0\)이면 \(\tau_g = t_0\)로 모든 주파수가 똑같이 늦어져, 파형 모양이 지연만 되고 일그러지지 않는다(4.2절 시간 이동).

Butterworth 같은 IIR 필터는 위상이 선형이 아니어서 차단 주파수 근처의 성분이 더 오래 늦어지고, 사각파를 넣으면 출력에 울림(링잉)이 생깁니다. 대칭 계수를 가진 FIR 필터는 정확히 선형 위상이 됩니다(5.1절 이동 평균의 \(-\omega(L - 1)/2\)). 파형 모양이 중요한 심전도·데이터 통신에는 선형 위상 FIR을, 적은 계산으로 가파른 크기 응답이 필요할 때는 IIR을 많이 씁니다.

흔한 오해(1) "차단 주파수 위는 모두 0이 된다": Butterworth의 차단 주파수에서 크기는 0.707이고, 위로 갈수록 서서히 줄어듭니다. (2) "크기 응답이 1이면 신호가 그대로 나온다": 위상이 비선형이면 크기가 모두 1이어도 파형이 바뀝니다(전역 통과 필터). (3) 차수를 무작정 높이면 크기는 가팔라지지만 군지연이 커지고 차단 주파수 근처의 링잉이 심해집니다.
요약
  1. 이상 필터는 비인과·불안정이라 만들 수 없다. 실제 필터는 통과·저지·전이 대역 사양으로 근사한다.
  2. Butterworth: \(|H| = 1/\sqrt{1 + (\omega/\omega_c)^{2n}}\), \(\omega_c\)에서 −3 dB, 저지 대역 −20n dB/decade.
  3. 군지연 \(-d\angle H/d\omega\). 선형 위상이면 파형이 일그러지지 않는다(대칭 FIR).

8.1.5연습문제

기본

  1. 3차 Butterworth(\(\omega_c = 1\))의 \(\omega = 2\)에서 크기를 dB로 구하여라.
    답

    \(1/\sqrt{1 + 64} \approx 0.124\), 약 −18.1 dB.

  2. 지연기 \(e^{-j\omega t_0}\)의 군지연은?
    답

    \(t_0\)(모든 주파수에서 같음).

응용

  1. 1차 RC 저역 통과 \(H = \frac{1}{1 + j\omega\tau}\)의 군지연을 구하고, \(\omega = 0\)과 \(\omega = 1/\tau\)에서의 값을 비교하여라.
    답

    \(\angle H = -\arctan\omega\tau\), \(\tau_g = \frac{\tau}{1 + (\omega\tau)^2}\). \(\omega = 0\): \(\tau\), \(\omega = 1/\tau\): \(\tau/2\). 주파수마다 지연이 달라 위상이 비선형.

심화

  1. 통과 대역 끝(\(\omega_p = 0.9\omega_c\))에서 감쇠가 1 dB 이하가 되려면 Butterworth 차수의 상한은 없는가? n을 늘리면 \(\omega_p\)에서의 감쇠는 어떻게 되는가?
    답

    \(|H(0.9\omega_c)|^2 = 1/(1 + 0.81^n)\). n이 커질수록 \(0.81^n \to 0\)이라 감쇠가 줄어듭니다(n = 1이면 약 2.6 dB, n = 4면 약 1.6 dB, n = 6이면 약 1.08 dB, n = 7이면 약 0.89 dB로 처음 1 dB 아래). 차수를 높이면 통과 대역이 더 평평해지고 저지 대역은 더 가팔라집니다.

8.1.2

탐구차수를 올리면 가팔라지고, 늦어진다

탐구 · Butterworth 크기 응답과 군지연

다루는 성취기준 [전전6-08-01]

질문

Butterworth 필터의 차수를 높이면 크기 응답은 이상 필터에 가까워집니다. 그 대가는 무엇일까요?

준비

차단 주파수 \(\omega_c = 1\)로 정규화한 n차 Butterworth 저역 통과 필터입니다. 위: 크기(dB, 가로축은 \(\log_{10}\omega\)), 점선은 −3 dB. 아래: 군지연 \(\tau_g = -d\angle H/d\omega\) (단위 \(1/\omega_c\)). 극점은 단위원 위 왼쪽 반평면에 고르게 놓입니다(8.1.3).

해 보기와 설명

  1. −3 dB는 그대로n을 바꿔도 \(\omega = 1\)에서 언제나 −3.0 dB입니다. 4차이면 \(\omega = 2\)에서 −24.1 dB, \(\omega = 3\)에서 −38.2 dB입니다(예제 8.1.1의 4차 값과 같음).
  2. 가팔라짐1차는 \(\omega = 2\)에서 −7.0 dB, 6차는 −36.1 dB입니다. 저지 대역 기울기가 −20n dB/decade입니다.
  3. 군지연1차의 군지연은 \(\omega = 0\)에서 1, \(\omega = 1\)에서 0.5로 줄어들지만, 4차는 0에서 2.61, 차단 주파수 근처에서 최대 약 3.91로 커집니다. 6차는 최대 약 6.49입니다. 차단 주파수 근처 성분이 더 늦게 나와 사각파 출력에 울림이 생깁니다.
  4. 위상\(\omega = 1\)에서 위상은 언제나 \(-45° \times n\)입니다.

연결과 적용

파형 모양이 중요한 곳(심전도, 데이터 펄스)에서는 군지연이 평평한 Bessel 필터나 선형 위상 FIR(8.3절)을 쓰고, 크기 응답만 중요한 곳(앤티에일리어싱, 6.2절)에서는 Butterworth나 더 가파른 Chebyshev·타원 필터를 씁니다.

흔한 오해

  • "차수가 높을수록 무조건 좋은 필터다." 크기 응답은 좋아지지만 군지연과 그 변동이 커지고, 회로 소자나 계산량도 늘어납니다.
