5.3.1나누어 정복하기

구하려는 것: N점 DFT를 \(N^2\)번보다 훨씬 적은 곱셈으로 계산하는 방법. N이 짝수일 때 합을 짝수 번째와 홀수 번째 표본으로 나눕니다. \(W_N = e^{-j2\pi/N}\)이라 쓰면

\[ X[k] = \sum_{m=0}^{N/2-1}x[2m]W_{N/2}^{km} + W_N^k\sum_{m=0}^{N/2-1}x[2m+1]W_{N/2}^{km} = E[k] + W_N^kO[k]. \]

여기서 \(W_N^{2km} = W_{N/2}^{km}\)을 썼습니다. E와 O는 각각 N/2점 DFT이고 주기 N/2이므로, \(k\)와 \(k + N/2\)에서 같은 값을 다시 씁니다. 또 \(W_N^{k + N/2} = -W_N^k\)이므로

\[ X[k] = E[k] + W_N^kO[k], \qquad X[k + N/2] = E[k] - W_N^kO[k]. \]

나비(butterfly) 연산: 위 두 식. 곱셈 한 번(\(W_N^kO[k]\))으로 출력 두 개를 만든다.

회전 인자(twiddle factor): \(W_N^k\). 단위원 위의 점.

이 쪼개기를 N/2, N/4, …, 1점까지 \(\log_2N\)단계 되풀이하면 각 단계에 나비 N/2개, 곧 곱셈 \(\frac N2\log_2N\)번입니다. N = 1024이면 5120번으로, 정의대로 하는 약 100만 번보다 약 200배 빠릅니다. 이 알고리즘(Cooley-Tukey, 1965)이 디지털 신호 처리를 실용화했습니다.

5.3.2FFT 결과 읽기

표본화 주파수 \(f_s\), N점으로 \(A\cos(2\pi f_0t)\)를 표본화했고 \(f_0\)가 정확히 빈 \(k_0 = f_0N/f_s\)에 놓인다고 합시다. 코사인은 \(\pm f_0\) 두 성분으로 나뉘어 각 성분이 \(\frac A2 \times N\)의 크기로 모입니다.

  • 빈 → 주파수: \(f_k = kf_s/N\) (\(k \le N/2\)). 넘는 빈은 음의 주파수(\(k - N\)).
  • 크기 → 진폭: \(A = \frac{2|X[k_0]|}{N}\). 직류(k = 0)만은 \(|X[0]|/N\).
  • 위상: \(\angle X[k_0]\)는 코사인의 위상. 사인이면 −90°.
예제 5.3.1

\(f_s = 1000\) Hz로 1초(N = 1000) 동안 \(x = \sin(2\pi\cdot50t) + 0.5\sin(2\pi\cdot120t)\)를 표본화했다. FFT에서 봉우리가 나오는 빈과 그 크기를 예측하여라.

풀이. 간격 \(\Delta f = 1000/1000 = 1\) Hz이므로 50 Hz는 빈 50, 120 Hz는 빈 120(그리고 대칭인 950, 880). 크기는 \(|X[50]| = \frac{1 \times 1000}{2} = 500\), \(|X[120]| = 250\). 진폭으로 바꾸면 \(2 \times 500/1000 = 1\), \(0.5\). 다른 빈은 (계산 오차 수준으로) 0입니다. 이 절의 실습 카드에서 그대로 확인합니다.

5.3.3해상도

주파수 해상도: 가까운 두 주파수를 따로 보이는 봉우리로 구별하는 능력. 대략 \(\Delta f \approx 1/T\) (T = 관측 시간 = \(N/f_s\)). 직사각 창으로는 두 주파수가 약 \(2/T\) 정도 떨어져야 확실히 갈라진다(창에 따라 다름, 8.2절).

왜 그런가: 길이 T로 자르는 것은 무한한 신호에 직사각 펄스를 곱하는 것이고(4.2절 곱셈 정리), 스펙트럼은 sinc와 컨볼루션되어 폭 약 \(2/T\)의 봉우리로 퍼집니다. 두 봉우리가 이 폭보다 가까우면 겹쳐 하나로 보입니다. 50 Hz와 52 Hz를 구별하려면 적어도 0.5~1초를 관측해야 하고, 0.25초(\(\Delta f = 4\) Hz)로는 0을 아무리 채워도 51 Hz 근처의 넓은 봉우리 하나로 보입니다(실습 카드에서 확인).

흔한 오해(1) 진폭을 \(|X[k]|\)로 그대로 읽어 "50 Hz 성분의 크기가 500"이라 하는 실수: N과 2로 나눠야 합니다. 라이브러리마다 정규화가 달라 확인 필요. (2) "표본화 주파수를 높이면 해상도가 좋아진다": 같은 시간 동안이면 N과 \(f_s\)가 같이 늘어 \(\Delta f = f_s/N = 1/T\)가 그대로입니다. 해상도는 관측 시간으로 정해집니다. (3) FFT가 근사라는 오해: FFT는 DFT를 정확히 계산하는 빠른 방법일 뿐입니다.
요약
  1. FFT: 짝·홀로 나누어 나비 연산을 \(\log_2N\)단계. 곱셈 \(\frac N2\log_2N\)번.
  2. 빈 k ↔ \(kf_s/N\) Hz, 진폭 \(2|X[k]|/N\).
  3. 해상도 \(\approx 1/T\). 영 채우기나 \(f_s\) 증가로는 늘지 않는다.

5.3.4연습문제

기본

  1. N = 8 FFT는 몇 단계, 각 단계 나비 몇 개인가?
    답

    3단계, 각 4개(곱셈 12번).

  2. \(f_s = 48\) kHz, N = 4096에서 빈 간격과 관측 시간은?
    답

    약 11.72 Hz, 약 85.3 ms.

응용

  1. 440 Hz와 442 Hz 두 음의 맥놀이를 FFT로 갈라 보려면 최소 몇 초를 녹음해야 하는가(대략)?
    답

    차이 2 Hz → \(T \gtrsim 1/2\) s, 확실히 갈라 보려면 1 s 정도.

심화

  1. \(X[k + N/2] = E[k] - W_N^kO[k]\)에서 \(W_N^{k + N/2} = -W_N^k\)임을 보이고, \(E[k + N/2] = E[k]\)인 이유를 설명하여라.
    답

    \(W_N^{N/2} = e^{-j\pi} = -1\). E는 N/2점 DFT라 k에 대해 주기 N/2(5.1절의 주기성과 같은 이유).

5.3.2

실습Python FFT로 두 음을 구별하기

실습 · NumPy rfft, 관측 시간과 해상도

다루는 성취기준 [전전6-05-03]

목표

NumPy의 FFT로 정현파 합의 스펙트럼을 계산해 봉우리의 주파수와 진폭을 읽고, 관측 시간과 영 채우기가 해상도에 미치는 영향을 숫자로 확인합니다. 성취기준 [전전6-05-03].

준비

  • Python 3과 NumPy(pip install numpy). 그림을 보고 싶으면 matplotlib도 설치합니다(선택).
  • 아래 코드를 fft_lab.py로 저장합니다. 신호는 모두 계산으로 만든 가상 신호입니다.
import numpy as np

fs = 1000                      # 표본화 주파수 (Hz)

def spectrum(x, nfft=None):
    """한쪽 진폭 스펙트럼: 주파수(Hz)와 진폭 2|X|/N"""
    N = len(x)
    X = np.fft.rfft(x, nfft or N)          # nfft > N이면 뒤에 0을 채움
    f = np.fft.rfftfreq(nfft or N, 1 / fs)
    return f, 2 * np.abs(X) / N

def peaks(f, A, thr=0.2):
    """이웃보다 크고 thr보다 큰 봉우리의 (주파수, 진폭)"""
    return [(round(float(f[k]), 2), round(float(A[k]), 3))
            for k in range(1, len(A) - 1)
            if A[k] > A[k - 1] and A[k] >= A[k + 1] and A[k] > thr]

def tones(N, parts):
    t = np.arange(N) / fs
    return sum(a * np.sin(2 * np.pi * f0 * t) for f0, a in parts)

# 1. 1초(N = 1000): 50 Hz(진폭 1) + 120 Hz(진폭 0.5)
print("1:", peaks(*spectrum(tones(1000, [(50, 1), (120, 0.5)]))))
# 2. 같은 신호를 0.25초(N = 250)만
print("2:", peaks(*spectrum(tones(250, [(50, 1), (120, 0.5)]))))
# 3. 50 Hz와 52 Hz(진폭 각 1)를 0.25초와 1초로
for N in (250, 1000):
    print("3:", N, peaks(*spectrum(tones(N, [(50, 1), (52, 1)]))))
# 4. 0.25초 신호에 0을 채워 4000점으로
print("4:", peaks(*spectrum(tones(250, [(50, 1), (52, 1)]), 4000)))

절차

  1. python fft_lab.py를 실행하고 다섯 줄의 출력을 적습니다.
  2. 각 경우의 빈 간격 \(\Delta f = f_s/N\)(영 채우기 때는 \(f_s/\text{nfft}\))을 계산해 출력 옆에 적습니다.
  3. (선택) matplotlib으로 plt.stem(*spectrum(...))을 그려 봉우리 모양을 봅니다.
  4. tones의 np.sin을 np.cos로 바꾸고 2번을 다시 돌려 봅니다.

기대 결과

NumPy 2.x에서 위 코드를 실행한 출력입니다.

1: [(50.0, 1.0), (120.0, 0.5)]
2: [(48.0, 0.649), (120.0, 0.5)]
3: 250 [(52.0, 1.179)]
3: 1000 [(50.0, 1.0), (52.0, 1.0)]
4: [(44.75, 0.237), (51.0, 1.273), (57.25, 0.213)]
  • 1: \(\Delta f = 1\) Hz. 두 주파수가 빈에 정확히 놓여 진폭이 그대로(1, 0.5) 읽힙니다(5.3절 예제 5.3.1).
  • 2: \(\Delta f = 4\) Hz. 120 Hz는 빈(30번)에 놓이지만 50 Hz는 빈 12.5, 곧 두 빈의 한가운데라 에너지가 이웃 빈으로 새어 48 Hz에서 0.649로 작게 보입니다(누설, 8.2절).
  • 3: 2 Hz 차이는 0.25초 관측(\(\Delta f = 4\) Hz)으로는 봉우리 하나(52 Hz, 1.179)이고, 1초 관측(\(\Delta f = 1\) Hz)으로는 50 Hz와 52 Hz가 진폭 1로 정확히 갈라집니다.
  • 4: 0.25초 신호에 0을 채워 점 간격을 0.25 Hz로 줄여도 봉우리는 51 Hz 하나입니다. 양옆 44.75, 57.25 Hz의 작은 봉우리는 실제 성분이 아니라 직사각 창의 옆엽입니다. 영 채우기는 해상도를 늘리지 못합니다.
  • 코사인으로 바꾸면 2번이 [(52.0, 0.649), (120.0, 0.509)]가 됩니다. 50 Hz의 봉우리가 48 Hz 대신 52 Hz 쪽에 서고, 빈에 놓인 120 Hz까지 0.509로 조금 달라집니다. 50 Hz에서 새어 나온 에너지가 다른 빈에 더해질 때 위상에 따라 보강되거나 상쇄되기 때문입니다.

분석

  1. 2번에서 50 Hz의 겉보기 진폭이 0.649로 줄었습니다. 이 오차를 줄이는 방법 두 가지(관측 시간 바꾸기, 창 함수)를 제안하고, 8.2절을 읽은 뒤 확인하세요.
  2. 3번 결과로 "두 주파수를 구별하는 데 필요한 관측 시간"을 어림하는 규칙을 한 줄로 쓰세요.
