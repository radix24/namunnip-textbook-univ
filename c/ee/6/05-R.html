5.R.1

연습DTFT와 DFT 연습 문제

문제 6 · 계산·개념·판단 · 힌트 2단계

다루는 성취기준 [전전6-05-01] [전전6-05-02] [전전6-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(x[n] = (0.8)^nu[n]\)의 DTFT를 구하고 \(\omega = 0\)과 \(\pi\)에서의 크기를 구하세요. [05-01]

    힌트 1

    등비급수, 공비 \(0.8e^{-j\omega}\).

    힌트 2

    \(e^{-j\pi} = -1\).

    풀이

    \(X = \frac{1}{1 - 0.8e^{-j\omega}}\). \(\omega = 0\): 5, \(\omega = \pi\): \(1/1.8 \approx 0.556\). 저역 통과.

  2. 개념\(x[n] = \cos(1.6\pi n)\)은 어떤 주파수의 신호와 같은가? 0~π 범위의 주파수로 답하세요. [05-01]

    힌트 1

    \(2\pi\)를 빼 보세요.

    힌트 2

    코사인은 짝함수.

    풀이

    \(1.6\pi - 2\pi = -0.4\pi\), \(\cos(-0.4\pi n) = \cos(0.4\pi n)\). 주파수 \(0.4\pi\). 6단원의 에일리어싱과 같은 현상입니다.

  3. 계산\(x = \{2, 0, 1, 0\}\)의 4점 DFT를 구하세요. [05-02]

    힌트 1

    \(X[k] = 2 + e^{-j\pi k}\).

    힌트 2

    \(e^{-j\pi k} = (-1)^k\).

    풀이

    \(X = \{3, 1, 3, 1\}\). 합 확인: \(X[0] = \sum x = 3\).

  4. 판단학생이 "1초 녹음을 FFT하니 빈 간격이 1 Hz다. 0을 채워 2초 길이로 만들면 0.5 Hz 떨어진 두 음도 구별할 수 있다"고 했다. 평가하세요. [05-02, 05-03]

    힌트 1

    영 채우기는 DTFT 곡선을 바꾸나요?

    힌트 2

    실습 카드의 4번 결과.

    풀이

    틀렸습니다. 영 채우기로 점 간격은 0.5 Hz가 되지만 봉우리의 폭(약 1/T = 1 Hz 정도)은 실제 녹음 길이로 정해집니다. 0.5 Hz 차이를 구별하려면 실제로 2초 이상 녹음해야 합니다.

  5. 계산\(f_s = 8000\) Hz, N = 256 FFT에서 \(|X[k]|\)가 k = 32와 224에서 640이고 나머지는 거의 0이었다. 신호의 주파수와 진폭은? [05-03]

    힌트 1

    \(f_k = kf_s/N\), 224 = 256 − 32.

    힌트 2

    진폭 \(2|X|/N\).

    풀이

    1000 Hz(빈 224는 −1000 Hz), 진폭 \(2 \times 640/256 = 5\).

  6. 도전길이 1000인 신호와 길이 100인 FIR 필터를 FFT로 선형 컨볼루션하려 한다. 필요한 최소 FFT 길이(2의 거듭제곱)와, 정의대로 할 때와 비교한 대략의 곱셈 수를 구하세요. [05-02, 05-03]

    힌트 1

    \(N \ge 1000 + 100 - 1\).

    힌트 2

    FFT 두 번 + 곱 N번 + 역FFT 한 번.

    풀이

    N = 2048. FFT 하나 \(\frac{2048}{2}\times11 = 11264\)번, 세 번이면 약 33800번, 곱 2048번을 더해 약 3.6만 번(복소). 정의대로는 \(1000 \times 100 = 10\)만 번(실수). 이 크기에서는 몇 배 차이지만, 필터가 길수록 FFT 쪽이 훨씬 유리해집니다(필터 길이 1000이면 정의대로 100만 번, FFT는 N = 2048 그대로라 약 3.6만 번).
