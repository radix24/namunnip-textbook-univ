1.1.1신호와 시스템이라는 말

마이크가 만든 전압, 심전도, 주가, 사진의 밝기는 모두 어떤 양이 시간(또는 위치)에 따라 변하는 모습, 곧 신호입니다. 그 신호를 받아 다른 신호로 바꾸는 것이 시스템입니다. 필터는 잡음을 줄이고, 증폭기는 키우고, 통신 채널은 일그러뜨립니다. 이 과목은 신호를 수학적으로 나타내고, 시스템이 신호를 어떻게 바꾸는지를 시간 영역과 주파수 영역 두 관점에서 다룹니다. 기초회로이론에서 본 RC 회로의 계단 응답과 주파수 응답이 바로 한 시스템을 두 관점에서 본 것입니다.

연속시간 신호 \(x(t)\): 모든 실수 시간 t에서 값이 있다. 아날로그 전압.

이산시간 신호 \(x[n]\): 정수 n에서만 값이 있다. 표본화한 신호, 컴퓨터 안의 수열.

괄호 모양(\(()\)와 \([]\))으로 둘을 구별하는 것이 관례입니다.

1.1.2기본 신호

단위 계단 \(u(t)\): \(t < 0\)이면 0, \(t > 0\)이면 1. 스위치를 켜는 순간.

단위 임펄스 \(\delta(t)\): 넓이가 1인 아주 좁고 높은 펄스의 극한. \(t \ne 0\)에서 0이고 \(\int\delta(t)\,dt = 1\). 망치로 한 번 치기.

지수 신호 \(e^{st}\): s가 실수면 늘거나 주는 지수, s = jω면 복소 정현파 \(\cos\omega t + j\sin\omega t\).

이산 임펄스 \(\delta[n]\): n = 0에서 1, 나머지 0. 연속 임펄스와 달리 아무 문제 없는 보통의 수열.

임펄스는 보통의 함수가 아니어서 "다른 함수와 곱해 적분했을 때의 결과"로 뜻을 정합니다. 가장 중요한 성질이 체(sifting) 성질입니다.

\[ \int_{-\infty}^{\infty}x(\tau)\delta(t - \tau)\,d\tau = x(t). \]

임펄스가 \(\tau = t\) 한 점의 값만 골라낸다는 뜻이고, 2단원 컨볼루션의 출발점입니다. 또 \(u(t) = \int_{-\infty}^{t}\delta(\tau)d\tau\), 곧 \(\delta = du/dt\)입니다.

1.1.3시간 변환

구하려는 것: \(x(t)\)의 그래프를 알 때 \(y(t) = x(at + b)\)의 그래프. 세 가지 기본 조작이 섞여 있습니다.

시간 이동 \(x(t - t_0)\): \(t_0 > 0\)이면 오른쪽으로 \(t_0\)만큼(늦게 일어남).

시간 반전 \(x(-t)\): 세로축에 대해 뒤집기(거꾸로 재생).

척도 변환 \(x(at)\): \(|a| > 1\)이면 가로로 \(1/|a|\)배 압축(빨리 재생), \(|a| < 1\)이면 늘이기.

가장 실수가 적은 방법은 "\(y\)의 시각 t에서 x의 어느 시각을 읽는가"를 묻는 것입니다. \(y(t) = x(at + b)\)는 x의 시각 \(\tau = at + b\)의 값을 가져오므로, x의 특징점 \(\tau_k\)(모서리, 꼭짓점)가 y에서는 \(t_k = (\tau_k - b)/a\)에 나타납니다.

예제 1.1.1

\(x(t)\)는 \(0 \le t \le 2\)에서 \(x = t\)(경사), 그 밖에서 0이다. \(y(t) = x(-2t + 4)\)를 그려라.

풀이. x의 특징점: \(\tau = 0\)(값 0에서 시작), \(\tau = 2\)(값 2, 그 뒤 0으로 떨어짐). y에서의 위치: \(t = (0 - 4)/(-2) = 2\), \(t = (2 - 4)/(-2) = 1\). 따라서 y는 \(t = 1\)에서 값 2, \(t = 2\)에서 값 0인 경사이고, \(1 \le t \le 2\) 밖에서는 0입니다. 식으로 확인하면 \(1 \le t \le 2\)에서 \(-2t + 4\)가 0~2 사이라 \(y = -2t + 4\). 압축(폭 2 → 1)과 반전(경사 방향이 바뀜)이 함께 일어났습니다.

순서로 하고 싶다면 "먼저 이동, 그다음 척도·반전"입니다: \(x(t + 4)\)(왼쪽으로 4) → t를 \(-2t\)로(반전하며 1/2 압축). 거꾸로 하면 이동량이 \(b/a\)로 바뀌므로 틀리기 쉽습니다.

1.1.4신호의 분류

짝·홀: \(x(-t) = x(t)\)이면 짝, \(x(-t) = -x(t)\)이면 홀. 모든 신호는 짝 부분 \(\frac{x(t) + x(-t)}{2}\)과 홀 부분 \(\frac{x(t) - x(-t)}{2}\)의 합.

주기: 모든 t에서 \(x(t + T) = x(t)\)인 가장 작은 \(T > 0\)이 기본 주기. 이산 신호 \(\cos(\omega_0n)\)은 \(\omega_0/(2\pi)\)가 유리수일 때만 주기적이다.

에너지·전력: 에너지 \(E = \int|x|^2dt\)가 유한하면 에너지 신호(펄스), 평균 전력 \(P = \lim\frac{1}{2T}\int_{-T}^{T}|x|^2dt\)가 유한한 양수이면 전력 신호(주기 신호).

주의\(x(2t - 4)\)를 "2배 압축하고 오른쪽으로 4"로 읽는 실수가 흔합니다. \(x(2(t - 2))\)이므로 오른쪽으로 2입니다. 특징점 대입 \(t = (\tau - b)/a\)로 확인하세요.
요약
  1. 연속 \(x(t)\), 이산 \(x[n]\). 기본 신호: 계단, 임펄스(체 성질), 지수, 정현파.
  2. \(x(at + b)\): x의 특징점 \(\tau\)가 \(t = (\tau - b)/a\)로 옮겨 간다. 이동 먼저, 척도·반전 나중.
  3. 짝·홀 분해, 주기, 에너지·전력 신호.

1.1.5연습문제

기본

  1. \(\int_{-\infty}^{\infty}\cos(t)\,\delta(t - \pi)\,dt\)와 \(\int_{-\infty}^{\infty}e^{-t}\delta(2t)\,dt\)를 구하여라.
    답

    \(\cos\pi = -1\). \(\delta(2t) = \frac12\delta(t)\)이므로 \(\frac12\).

  2. \(x[n] = \cos(\pi n/4)\)와 \(\cos(n/4)\)는 주기적인가? 주기는?
    답

    첫째: \(\omega_0/2\pi = 1/8\), 주기 8. 둘째: \(1/(8\pi)\)가 무리수라 주기 아님.

응용

  1. \(x(t) = u(t) - u(t - 2)\)일 때 \(x(3 - t)\)를 식과 그림으로 나타내어라.
    답

    \(0 \le 3 - t \le 2\), 곧 \(1 \le t \le 3\)에서 1. \(u(t - 1) - u(t - 3)\).

심화

  1. \(x(t) = e^{-t}u(t)\)의 짝 부분과 홀 부분을 구하고 에너지를 구하여라.
    답

    짝: \(\frac12e^{-|t|}\), 홀: \(\frac12\,\text{sgn}(t)e^{-|t|}\). 에너지 \(\int_0^\infty e^{-2t}dt = \frac12\).

1.1.2

탐구x(at + b)는 어디로 옮겨 가는가

탐구 · 이동, 반전, 척도를 한 번에

다루는 성취기준 [전전6-01-01]

질문

\(x(2t - 4)\)는 x를 오른쪽으로 4만큼 옮긴 것일까요, 2만큼 옮긴 것일까요? a와 b를 바꿔 가며 확인해 봅시다.

준비

위 그래프는 원래 신호 \(x(\tau)\), 아래 그래프는 \(y(t) = x(at + b)\)입니다. 처음 값은 1.1절 예제 1.1.1의 \(a = -2\), \(b = 4\)입니다. 출력 줄에 x의 특징점 \(\tau\)가 y의 어느 시각 \(t = (\tau - b)/a\)로 가는지 적어 둡니다.

해 보기와 설명

  1. 예제 확인처음 화면에서 경사의 τ = 0이 t = 2로, τ = 2가 t = 1로 갑니다. y는 t = 1에서 높이 2, t = 2에서 0인 내리막입니다(예제 1.1.1).
  2. 2t − 4a = 2, b = −4로 두면 출력 줄이 \(x(2(t - 2))\)로 다시 써 줍니다. 경사의 시작점이 t = 2로 갑니다. 4가 아니라 2만큼 이동입니다.
  3. a만 바꾸기b = 0에서 a를 1 → 2 → 0.5로 바꾸면 τ = 0인 점은 움직이지 않고 나머지가 원점 쪽으로 모이거나 퍼집니다. 척도 변환의 고정점은 원점입니다.
  4. 반전a = −1, b = 0이면 세로축에 대한 대칭입니다. 지수 신호를 고르면 \(e^{t}u(-t)\)가 됩니다.

연결과 적용

2단원의 컨볼루션에서 \(h(t - \tau)\)를 \(\tau\)의 함수로 그리는 일이 바로 이 카드의 a = −1, b = t인 경우입니다. 녹음을 빠르게 재생하면(a > 1) 신호가 압축되고, 4단원에서 보듯 주파수 성분은 그만큼 높아집니다.

흔한 오해

  • "척도 먼저, 이동 나중이면 이동량이 b이다." \(x(at)\)을 먼저 만든 뒤 옮기면 \(x(a(t - t_0))\)이 되어 이동량은 \(t_0 = -b/a\)입니다. 특징점 대입이 가장 안전합니다.
