3.R.1

연습Fourier 급수 연습 문제

문제 6 · 계산·증명·판단 · 힌트 2단계

다루는 성취기준 [전전6-03-01] [전전6-03-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(x(t) = \cos^2(2t)\)의 기본 주기와 Fourier 계수를 구하세요. [03-01]

    힌트 1

    반각 공식 \(\cos^2\theta = \frac{1 + \cos2\theta}{2}\).

    힌트 2

    \(\cos 4t\)만 남으면 \(\omega_0 = 4\).

    풀이

    \(x = \frac12 + \frac12\cos4t\). \(T = \pi/2\), \(\omega_0 = 4\). \(a_0 = 1/2\), \(a_{\pm1} = 1/4\), 나머지 0.

  2. 계산주기 T인 임펄스 열 \(x(t) = \sum_m\delta(t - mT)\)의 Fourier 계수를 구하세요. [03-01]

    힌트 1

    한 주기 \([-T/2, T/2]\) 안에는 임펄스가 하나.

    힌트 2

    체 성질.

    풀이

    \(a_k = \frac1T\int_{-T/2}^{T/2}\delta(t)e^{-jk\omega_0t}dt = \frac1T\) (모든 k). 모든 고조파가 같은 크기로 들어 있습니다. 6단원 표본화에서 핵심이 됩니다.

  3. 계산듀티 50% 사각파(높이 1)의 평균 전력 중 직류와 1, 3, 5고조파가 차지하는 비율을 구하세요. [03-01]

    힌트 1

    \(a_k = \sin(k\pi/2)/(k\pi)\), 평균 전력 0.5.

    힌트 2

    각 고조파는 \(\pm k\) 두 개: \(2|a_k|^2\).

    풀이

    \(0.25 + 2(0.1013 + 0.01126 + 0.00405) = 0.25 + 0.2333 = 0.4833\), 비율 96.7%. 탐구 카드에서 N = 5로 두면 확인할 수 있습니다(N = 3에서 95.0%, N = 9에서 98.0%).

  4. 증명이산시간 LTI 시스템에서 \(x[n] = z^n\)이면 \(y[n] = H(z)z^n\)임을 보이고, \(H(z)\)를 h로 쓰세요. [03-02]

    힌트 1

    \(y[n] = \sum_kh[k]x[n - k]\).

    힌트 2

    \(z^{n-k} = z^nz^{-k}\).

    풀이

    \(y[n] = \sum_kh[k]z^{n-k} = z^n\sum_kh[k]z^{-k} = H(z)z^n\), \(H(z) = \sum_kh[k]z^{-k}\)(합이 수렴할 때). \(z^n\)은 k와 무관해 합 밖으로 나왔습니다. 7단원 Z-변환의 정의가 이것입니다.

  5. 판단미분기 \(y = dx/dt\)에 \(x = \sin t + \sin 10t\)를 넣었다. 학생은 "출력에서 두 성분의 진폭 비는 입력과 같은 1:1"이라고 했다. 평가하세요. [03-02]

    힌트 1

    미분기의 \(H(j\omega)\)는?

    힌트 2

    \(\frac{d}{dt}e^{j\omega t} = j\omega e^{j\omega t}\).

    풀이

    틀렸습니다. \(H = j\omega\)이므로 크기가 \(\omega\)배: 출력 \(\cos t + 10\cos10t\), 진폭 비 1:10. 미분기는 고주파를 키워 잡음을 증폭합니다.

  6. 도전\(h(t) = e^{-2t}u(t)\)인 시스템에 \(x(t) = \sum_k a_ke^{jkt}\)(주기 \(2\pi\))를 넣었더니 출력의 기본파 크기가 입력 기본파의 몇 배인지 묻는다. 그리고 출력의 직류가 입력 직류의 몇 배인지도 구하세요. [03-02]

    힌트 1

    \(H(j\omega) = \int_0^\infty e^{-2t}e^{-j\omega t}dt\).

    힌트 2

    \(H(j\omega) = \frac{1}{2 + j\omega}\).

    풀이

    기본파: \(|H(j1)| = 1/\sqrt5 \approx 0.447\)배. 직류: \(H(0) = 0.5\)배. 이 h는 넓이가 0.5라 직류 이득이 1이 아닙니다(직류 이득 = h의 넓이).
