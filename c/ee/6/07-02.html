7.2.1정의와 ROC

3.2절에서 \(z^n\)이 이산 LTI 시스템의 고유함수이고 고윳값이 \(H(z) = \sum h[k]z^{-k}\)임을 보았습니다. 이 합을 아무 수열에 쓴 것이 Z-변환입니다.

\[ X(z) = \sum_{n=-\infty}^{\infty}x[n]\,z^{-n}, \qquad z = re^{j\omega}. \]

ROC: 합이 절대 수렴하는 z의 집합. 수렴은 \(|z| = r\)에만 달려 있으므로 원환(두 원 사이) 모양이다.

단위원 \(|z| = 1\): \(z = e^{j\omega}\)를 넣으면 DTFT가 된다. ROC가 단위원을 포함하면 DTFT가 존재한다.

Laplace의 s평면에서 허수축이 하던 일을 z평면에서는 단위원이 합니다. 실제로 \(z = e^{sT}\)로 대응하면 허수축이 단위원으로, 왼쪽 반평면이 단위원 안쪽으로 옮겨 갑니다.

예제 7.2.1

\(x[n] = a^nu[n]\)의 Z-변환과 ROC, 극점과 영점을 구하여라.

풀이. \(\sum_{n\ge0}(az^{-1})^n = \frac{1}{1 - az^{-1}} = \frac{z}{z - a}\). 등비급수가 수렴하려면 \(|az^{-1}| < 1\), 곧 \(|z| > |a|\). ROC는 반지름 \(|a|\)인 원의 바깥입니다. 극점 \(z = a\), 영점 \(z = 0\). 7.1절과 마찬가지로 \(-a^nu[-n-1]\)도 같은 식이고 ROC만 \(|z| < |a|\)입니다.

7.2.2차분 방정식에서 H(z)로

지연 성질: \(x[n - k] \leftrightarrow z^{-k}X(z)\). 한 칸 지연은 \(z^{-1}\)을 곱하는 것(블록도의 \(z^{-1}\) 상자의 뜻).

컨볼루션 성질: \(x * h \leftrightarrow X(z)H(z)\).

차분 방정식 \(\sum a_ky[n-k] = \sum b_kx[n-k]\)의 양변을 변환하면 \(Y\sum a_kz^{-k} = X\sum b_kz^{-k}\)이므로

\[ H(z) = \frac{Y(z)}{X(z)} = \frac{b_0 + b_1z^{-1} + \cdots + b_Mz^{-M}}{a_0 + a_1z^{-1} + \cdots + a_Nz^{-N}}. \]

분모에 \(z^N\)을 곱하면 \(a_0z^N + a_1z^{N-1} + \cdots + a_N\)으로 2.3절의 특성 방정식과 같습니다. 곧 특성근 = H(z)의 극점입니다.

7.2.3안정성: 극점이 단위원 안에

인과이면 ROC는 가장 바깥 극점의 바깥, 안정이면 ROC가 단위원을 포함해야 합니다. 둘을 합치면

인과 이산 LTI 시스템의 안정 조건: 모든 극점이 단위원 안(\(|p_i| < 1\)). 2.3절의 "모든 특성근 \(|r_i| < 1\)"과 같은 말이다.

예제 7.2.2

\(y[n] = 0.9y[n-1] - 0.81y[n-2] + x[n] + x[n-2]\)의 \(H(z)\), 극점, 영점을 구하고 안정성과 주파수 응답의 모양을 설명하여라.

풀이. \(H(z) = \frac{1 + z^{-2}}{1 - 0.9z^{-1} + 0.81z^{-2}} = \frac{z^2 + 1}{z^2 - 0.9z + 0.81}\). 영점: \(z = \pm j\) (단위원 위, \(\omega = \pm\pi/2\)). 극점: \(z = \frac{0.9 \pm \sqrt{0.81 - 3.24}}{2} = 0.45 \pm 0.779j\), 크기 \(\sqrt{0.81} = 0.9\), 각 \(\pm60°\) (\(\pm\pi/3\)). 모든 극점이 단위원 안이므로 인과 시스템으로 안정합니다.

주파수 응답 \(|H(e^{j\omega})|\)는 단위원 위의 점 \(e^{j\omega}\)에서 영점까지 거리의 곱을 극점까지 거리의 곱으로 나눈 것입니다. 그래서 \(\omega\)가 극점 방향(\(\pi/3\)) 근처일 때 분모가 작아져 봉우리가 생기고, 영점 방향(\(\pi/2\))에서는 정확히 0이 됩니다. 수치: \(\omega = 0\)에서 \(|H| = \frac{2}{|1 - 0.9 + 0.81|} = \frac{2}{0.91} \approx 2.20\). 이 절의 탐구 카드에서 극점과 영점을 옮기며 확인할 수 있습니다.

흔한 오해(1) \(H(z)\)를 \(z^{-1}\)의 식으로 둔 채 극점을 찾으면 \(z = 0\)의 극점·영점을 빠뜨리기 쉽습니다. z의 양의 거듭제곱으로 바꿔서 찾으세요. (2) 극점이 단위원 위(\(|p| = 1\))이면 안정이 아닙니다(누산기의 극점 z = 1). (3) 연속시간의 기준(\(\text{Re} < 0\))을 그대로 써서 "극점 0.5 + 0.9j는 실수부가 양수라 불안정"이라 하면 틀립니다. 이산시간의 기준은 크기 \(|p| = 1.03 > 1\)이라 불안정한 것입니다.
요약
  1. \(X(z) = \sum x[n]z^{-n}\), ROC는 원환. 단위원에서 DTFT.
  2. 지연 ↔ \(z^{-1}\), 컨볼루션 ↔ 곱. 차분 방정식 → \(H(z)\) = 계수 다항식의 비. 특성근 = 극점.
  3. 인과·안정 ⇔ 모든 극점 \(|p| < 1\). 주파수 응답은 단위원 위 점에서 영점·극점까지 거리의 비.

7.2.4연습문제

기본

  1. \(\{1, 2, 3\}\) (n = 0, 1, 2)의 Z-변환과 ROC는?
    답

    \(1 + 2z^{-1} + 3z^{-2}\), \(z = 0\)을 뺀 전체.

  2. \(H(z) = \frac{1}{1 - 1.2z^{-1}}\)인 인과 시스템은 안정한가?
    답

    극점 1.2, 단위원 밖이라 불안정.

응용

  1. \(y[n] - 0.5y[n-1] = x[n] - x[n-1]\)의 H(z), 극점·영점, \(|H|\)의 \(\omega = 0, \pi\) 값을 구하고 필터 종류를 말하여라.
    답

    \(\frac{1 - z^{-1}}{1 - 0.5z^{-1}}\), 영점 1, 극점 0.5. \(\omega = 0\): 0, \(\omega = \pi\): \(2/1.5 \approx 1.33\). 고역 통과(직류 차단).

심화

  1. 극점 \(0.95e^{\pm j\pi/4}\)인 2차 공진기의 차분 방정식(분자 1)을 쓰고, 봉우리가 생기는 주파수를 \(f_s = 8\) kHz에 대해 Hz로 구하여라.
    답

    분모 \((1 - pz^{-1})(1 - p^*z^{-1}) = 1 - 2(0.95)\cos(\pi/4)z^{-1} + 0.9025z^{-2}\). \(y[n] = 1.3435y[n-1] - 0.9025y[n-2] + x[n]\). 봉우리 \(\omega \approx \pi/4\) → \(f = \frac{\pi/4}{2\pi}\times8000 = 1000\) Hz(근사).

7.2.2

탐구극점은 봉우리, 영점은 골짜기

탐구 · z평면의 극점·영점과 주파수 응답

다루는 성취기준 [전전6-07-02]

질문

단위원 위를 한 바퀴 도는 점 \(e^{j\omega}\)에서 극점과 영점까지의 거리만으로 디지털 필터의 주파수 응답을 그릴 수 있을까요?

준비

극점 한 쌍 \(re^{\pm j\theta}\)와 영점 한 쌍(없음, \(z = \pm1\), \(z = \pm j\))을 고릅니다. \(|H(e^{j\omega})| = \frac{\prod|e^{j\omega} - z_i|}{\prod|e^{j\omega} - p_i|}\)를 \(0 \le \omega \le \pi\)에서 그립니다. 처음 값은 7.2절 예제 7.2.2(\(r = 0.9\), \(\theta = 60°\), 영점 \(\pm j\))입니다.

해 보기와 설명

  1. 예제 확인\(\omega = 0\)에서 2.198, \(\pi/2\)에서 0(영점 \(\pm j\)), \(\pi\)에서 0.738. 봉우리는 6.211로 \(\omega \approx 0.326\pi\)에 있어 극점 각(\(\pi/3\))보다 조금 낮습니다. 영점이 봉우리를 살짝 밀어낸 것입니다.
  2. 영점 없음봉우리 6.077, 위치 \(0.333\pi\)로 극점 각과 거의 같습니다. r을 0.99로 올리면 봉우리가 57.9로 솟고 좁아집니다. 단위원에 가까운 극점 = 날카로운 공진.
  3. 영점 ±1\(\omega = 0\)과 \(\pi\)에서 정확히 0이 되어 대역 통과 필터가 됩니다(봉우리 10.53).
  4. r > 1극점이 단위원 밖으로 나가면 빨강으로 바뀝니다. 인과 시스템으로는 불안정해 주파수 응답이 의미가 없습니다.

연결과 적용

2.3절의 차분 방정식 카드는 같은 극점이 시간 영역에서 만드는 감쇠 진동을 보여 줍니다. 오디오 이퀄라이저의 피크 필터, 전원 잡음(60 Hz)을 지우는 노치 필터는 이렇게 극점과 영점을 가까이 두어 만듭니다.

흔한 오해

  • "봉우리는 정확히 극점 각에서 생긴다." 다른 극점과 영점까지의 거리도 함께 변하므로 조금 어긋납니다. 극점이 단위원에 가까울수록 극점 각에 가까워집니다.
