4.2.1성질이 필요한 이유

모든 신호의 변환을 적분으로 구하는 것은 번거롭습니다. 대신 몇 개의 기본쌍(4.1절)과 "신호를 이렇게 바꾸면 변환은 저렇게 바뀐다"는 성질 몇 개를 알면 대부분의 변환을 조립할 수 있습니다. 아래에서 \(x \leftrightarrow X(j\omega)\)라 씁니다.

선형성: \(ax_1 + bx_2 \leftrightarrow aX_1 + bX_2\).

시간 이동: \(x(t - t_0) \leftrightarrow e^{-j\omega t_0}X(j\omega)\). 크기 스펙트럼은 그대로, 위상만 \(-\omega t_0\) 더해진다.

주파수 이동(변조): \(e^{j\omega_0t}x(t) \leftrightarrow X(j(\omega - \omega_0))\). 스펙트럼 전체가 \(\omega_0\)만큼 옮겨 간다(4.3절).

척도: \(x(at) \leftrightarrow \frac{1}{|a|}X(j\omega/a)\).

미분·적분: \(\frac{dx}{dt} \leftrightarrow j\omega X\). 적분은 \(\frac{X}{j\omega} + \pi X(0)\delta(\omega)\).

쌍대성: \(x(t) \leftrightarrow X(j\omega)\)이면 \(X(jt) \leftrightarrow 2\pi x(-\omega)\). 펄스 ↔ sinc이므로 sinc ↔ 펄스.

Parseval: \(\int|x|^2dt = \frac{1}{2\pi}\int|X|^2d\omega\). 에너지는 어느 영역에서 재도 같다.

시간 이동의 증명 하나를 보면 나머지도 같은 방식입니다: \(\int x(t - t_0)e^{-j\omega t}dt\)에서 \(\sigma = t - t_0\)로 치환하면 \(e^{-j\omega t_0}\int x(\sigma)e^{-j\omega\sigma}d\sigma\).

4.2.2컨볼루션 정리

정리 4.2.1

\(y = x * h\)이면 \(Y(j\omega) = X(j\omega)H(j\omega)\). 쌍대로, \(x(t)p(t) \leftrightarrow \frac{1}{2\pi}X * P\).

구하려는 것은 \(Y\)를 X와 H로 쓰는 것입니다. 정의에 컨볼루션을 넣고 적분 순서를 바꿉니다.

\[ Y = \int\Big[\int x(\tau)h(t - \tau)d\tau\Big]e^{-j\omega t}dt = \int x(\tau)\Big[\int h(t - \tau)e^{-j\omega t}dt\Big]d\tau. \]

안쪽 괄호는 시간 이동 성질로 \(e^{-j\omega\tau}H(j\omega)\)입니다. H는 \(\tau\)와 무관하므로 밖으로 나오고, 남은 \(\int x(\tau)e^{-j\omega\tau}d\tau = X\)입니다. ∎

3.2절의 고유함수 성질을 모든 신호로 넓힌 결과입니다. 입력을 주파수 성분으로 쪼개고(X), 성분마다 H를 곱하고, 다시 모읍니다. 시간 영역의 어려운 컨볼루션이 주파수 영역의 곱셈이 됩니다.

예제 4.2.1

\(h(t) = e^{-2t}u(t)\)인 시스템에 \(x(t) = e^{-t}u(t)\)를 넣을 때 출력을 주파수 영역에서 구하여라.

풀이. 1단계(변환): \(X = \frac{1}{1 + j\omega}\), \(H = \frac{1}{2 + j\omega}\). 2단계(곱): \(Y = \frac{1}{(1 + j\omega)(2 + j\omega)}\). 3단계(역변환): 표에 있는 꼴로 쪼개기 위해 부분분수를 씁니다. \(v = j\omega\)로 두면 \(\frac{1}{(1 + v)(2 + v)} = \frac{A}{1 + v} + \frac{B}{2 + v}\), \(A = \frac{1}{2 - 1} = 1\) (\(v = -1\) 대입), \(B = \frac{1}{1 - 2} = -1\). 따라서 \(y(t) = (e^{-t} - e^{-2t})u(t)\).

검산: 2.1절 연습 4의 공식 \(\frac{e^{-at} - e^{-bt}}{b - a}\)에 a = 1, b = 2를 넣으면 같은 결과입니다. 수치: \(y\)는 \(t = \ln 2 \approx 0.693\)에서 최댓값 \(0.5 - 0.25 = 0.25\).

4.2.3필터링의 그림

\(|Y| = |X||H|\), \(\angle Y = \angle X + \angle H\). 그림으로는 입력 스펙트럼에 필터의 크기 응답을 "덮어씌우는" 일입니다. 이상 저역 통과 필터 \(H = 1\) (\(|\omega| < W\))를 쓰면 W 위의 성분이 완전히 사라집니다. 이 절의 예제 카드에서 두 펄스의 컨볼루션을 이 방법으로 확인합니다.

흔한 오해(1) 곱셈 정리의 \(\frac{1}{2\pi}\)를 빠뜨리기 쉽습니다(f를 쓰면 없음). (2) "시간 이동은 스펙트럼을 바꾸지 않는다"는 크기에 대해서만 맞습니다. 위상은 \(-\omega t_0\)만큼 바뀝니다. (3) 부분분수를 하지 않고 \(\frac{1}{(1 + j\omega)(2 + j\omega)}\)의 역변환을 \(e^{-t}\cdot e^{-2t}\)로 쓰는 실수: 주파수 영역의 곱은 시간 영역의 곱이 아니라 컨볼루션입니다.
요약
  1. 이동 ↔ 위상 \(e^{-j\omega t_0}\), 변조 ↔ 주파수 이동, 미분 ↔ \(j\omega\), 척도 ↔ 반비례, 쌍대성, Parseval.
  2. 컨볼루션 ↔ 곱 (\(Y = XH\)), 곱 ↔ \(\frac1{2\pi}\)컨볼루션.
  3. 출력 구하기: 변환 → 곱 → 부분분수 → 표로 역변환.

4.2.4연습문제

기본

  1. \(e^{-(t-2)}u(t - 2)\)의 변환은?
    답

    \(\frac{e^{-j2\omega}}{1 + j\omega}\).

  2. \(\frac{\sin 3t}{\pi t}\)의 변환을 쌍대성(또는 4.1절 연습 3)으로 구하여라.
    답

    \(|\omega| < 3\)에서 1, 그 밖에서 0.

응용

  1. \(h = e^{-t}u(t)\), \(x = e^{-t}u(t)\)일 때 \(Y\)와 \(y(t)\)를 구하여라.
    답

    \(Y = \frac{1}{(1 + j\omega)^2}\), \(y = te^{-t}u(t)\)(4.1절 연습 4).

심화

  1. Parseval로 \(\int_{-\infty}^{\infty}\frac{\sin^2 t}{t^2}dt\)를 구하여라.
    힌트

    \(\frac{\sin t}{t} \leftrightarrow \pi\) (\(|\omega| < 1\)).

    답

    \(\frac{1}{2\pi}\int_{-1}^{1}\pi^2d\omega = \pi\).

4.2.2

예제이상 저역 통과 필터를 지난 펄스

예제 · 곱셈으로 출력의 스펙트럼과 에너지 구하기

다루는 성취기준 [전전6-04-02]

먼저 예측

폭 1 s 직사각 펄스를 차단 주파수 1 Hz(\(2\pi\) rad/s)인 이상 저역 통과 필터에 통과시키면, 펄스 에너지의 몇 %가 남을까요? 절반? 90%?

생각해 본 뒤 열기

약 90%입니다. 펄스 스펙트럼의 주봉우리(첫 영점이 정확히 1 Hz)에 에너지 대부분이 있기 때문입니다.

문제

\(x(t) = 1\) (\(|t| < 0.5\)), 0 (그 밖), \(H(j\omega) = 1\) (\(|\omega| < 2\pi\)), 0 (그 밖). (가) 출력 스펙트럼 \(Y(j\omega)\)를 쓰고, (나) 입력과 출력의 에너지를 비교하여라.

전략

  1. 시간 영역 컨볼루션(펄스 * sinc) 대신 \(Y = XH\)를 쓴다.
  2. 에너지는 Parseval로 주파수 영역에서 잰다.

풀이

  1. 예제 4.1.1에서 \(T_1 = 0.5\): \(X = \frac{2\sin(\omega/2)}{\omega}\). 기본쌍
  2. \(Y = XH = \frac{2\sin(\omega/2)}{\omega}\) (\(|\omega| < 2\pi\)), 0 (그 밖). 주봉우리만 남고 옆엽이 모두 잘린다. 컨볼루션 정리
  3. 입력 에너지: 시간 영역에서 \(\int|x|^2dt = 1\). 정의
  4. 출력 에너지: \(E_y = \frac{1}{2\pi}\int_{-2\pi}^{2\pi}\frac{4\sin^2(\omega/2)}{\omega^2}d\omega\). \(u = \omega/2\pi\)로 바꾸면 \(\int_{-1}^{1}\text{sinc}^2(u)\,du\)이고, 수치 적분하면 약 0.903. Parseval

의미

입력 에너지의 약 90.3%가 주봉우리에 있습니다. 출력은 원래 펄스와 비슷하지만 모서리가 둥글고, 모서리 근처에서 약 9% 넘쳐 오르는 물결(Gibbs, 3.1절)이 생깁니다. 대역폭이 "첫 영점까지"인 채널로 펄스를 보내면 에너지는 거의 전해지지만 모양은 무너지기 시작합니다. 통신에서 펄스 모양과 대역폭을 함께 설계하는 이유입니다.

검산

\(\int_{-\infty}^{\infty}\text{sinc}^2(u)du = 1\)이므로 차단 주파수를 무한히 키우면 출력 에너지가 입력 에너지 1로 돌아갑니다. 차단 주파수를 0.5 Hz로 줄이면 \(\int_{-0.5}^{0.5}\text{sinc}^2 \approx 0.774\)로 줄어듭니다.

이해 확인

같은 펄스를 2초 늦춘 \(x(t - 2)\)를 넣으면 출력 에너지는?

답

같습니다(약 0.903). 시간 이동은 \(|X|\)를 바꾸지 않으므로 Parseval 적분이 그대로입니다. 출력도 2초 늦어질 뿐입니다.
