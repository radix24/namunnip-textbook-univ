4.1.1급수에서 변환으로

Fourier 급수는 주기 신호에만 쓸 수 있습니다. 펄스 하나, 음성 한 마디처럼 주기가 없는 신호를 다루려면 "주기가 무한히 긴 주기 신호"로 보면 됩니다.

구하려는 것: 주기 T → ∞일 때 급수가 무엇이 되는가. 3.1절 사각파에서 \(T a_k = \frac{2\sin(k\omega_0T_1)}{k\omega_0}\)였습니다. \(\omega = k\omega_0\)로 쓰면 \(Ta_k = \frac{2\sin(\omega T_1)}{\omega}\)로, T와 무관한 곡선 위의 점들입니다. T가 커지면 점 사이 간격 \(\omega_0 = 2\pi/T\)가 좁아져 곡선 전체를 촘촘히 채웁니다. 이 포락선 곡선이 Fourier 변환이고, 급수의 합은 적분이 됩니다.

\[ X(j\omega) = \int_{-\infty}^{\infty}x(t)\,e^{-j\omega t}\,dt, \qquad x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)\,e^{j\omega t}\,d\omega. \]

Fourier 변환 \(X(j\omega)\): 신호에 각주파수 \(\omega\)의 성분이 얼마나(밀도로) 들어 있는가. 단위는 [x의 단위 × 초].

역변환: 모든 주파수의 복소 지수를 \(X(j\omega)\,d\omega/2\pi\)의 비율로 더해 신호를 되살린다.

스펙트럼: \(|X(j\omega)|\)(크기)와 \(\angle X(j\omega)\)(위상)를 \(\omega\)의 함수로 그린 것.

3.2절의 \(H(j\omega)\)는 임펄스 응답 h의 Fourier 변환이었습니다. 주파수를 Hz로 쓰고 싶으면 \(\omega = 2\pi f\)로 바꾸면 \(2\pi\)가 사라진 대칭형 \(X(f) = \int x e^{-j2\pi ft}dt\), \(x = \int Xe^{j2\pi ft}df\)가 됩니다. 교재마다 쓰는 형태가 달라 계수 \(2\pi\)가 어디 붙는지 늘 확인해야 합니다.

4.1.2기본 변환쌍 유도

예제 4.1.1 (직사각 펄스)

\(|t| < T_1\)에서 1, 그 밖에서 0인 펄스의 변환을 구하여라.

풀이. 적분 구간이 펄스가 있는 곳뿐입니다. \(X(j\omega) = \int_{-T_1}^{T_1}e^{-j\omega t}dt = \frac{e^{j\omega T_1} - e^{-j\omega T_1}}{j\omega} = \frac{2\sin(\omega T_1)}{\omega}\). \(\omega = 0\)에서 값은 극한으로 \(2T_1\)(펄스의 넓이)이고, 첫 영점은 \(\omega = \pi/T_1\)입니다. \(T_1 = 0.5\)(폭 1)이면 \(X(0) = 1\), 첫 영점 \(\omega = 2\pi\), 곧 \(f = 1\) Hz. 폭을 두 배로 하면 첫 영점은 절반의 주파수로 옵니다.

sinc 함수: \(\text{sinc}(u) = \frac{\sin\pi u}{\pi u}\). 위 결과는 \(X = 2T_1\,\text{sinc}(\omega T_1/\pi)\). 교재마다 \(\pi\)를 넣는 방식이 달라 확인 필요.

예제 4.1.2 (지수 신호)

\(x(t) = e^{-at}u(t)\), \(a > 0\)의 변환과 크기·위상을 구하여라.

풀이. \(X = \int_0^\infty e^{-(a + j\omega)t}dt = \frac{1}{a + j\omega}\) (\(a > 0\)이라 위끝에서 0). \(|X| = \frac{1}{\sqrt{a^2 + \omega^2}}\), \(\angle X = -\arctan(\omega/a)\). \(\omega = a\)에서 크기가 최댓값 \(1/a\)의 \(1/\sqrt2\)이고 위상이 −45°입니다. RC 회로와 같은 꼴입니다. \(a \le 0\)이면 적분이 발산해 Fourier 변환이 없습니다(7단원 Laplace 변환이 이 경우를 다룹니다).

임펄스, 상수, 복소 지수. 체 성질로 \(\delta(t) \leftrightarrow 1\): 임펄스는 모든 주파수를 같은 세기로 담습니다. 거꾸로 상수 1의 변환은 일반 적분으로는 발산하지만, 역변환 식에 \(X = 2\pi\delta(\omega)\)를 넣으면 \(\frac{1}{2\pi}\cdot2\pi = 1\)이 나오므로 \(1 \leftrightarrow 2\pi\delta(\omega)\)로 받아들입니다. 같은 방법으로

\[ e^{j\omega_0t} \leftrightarrow 2\pi\delta(\omega - \omega_0), \qquad \cos\omega_0t \leftrightarrow \pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]. \]

주기 신호의 변환은 Fourier 급수 계수 자리에 \(2\pi a_k\) 크기의 임펄스를 놓은 것입니다: \(X(j\omega) = \sum_k2\pi a_k\,\delta(\omega - k\omega_0)\). 급수와 변환이 하나의 틀로 묶였습니다.

4.1.3시간 폭과 주파수 폭

예제 4.1.1에서 본 것처럼, 신호가 시간에서 좁을수록 스펙트럼은 넓게 퍼집니다. 척도 성질 \(x(at) \leftrightarrow \frac{1}{|a|}X(j\omega/a)\)가 이것을 정확히 말해 줍니다. 극단적인 두 경우가 임펄스(시간 폭 0, 스펙트럼 평평)와 상수(시간 폭 무한, 스펙트럼 한 점)입니다. 빠른 데이터 펄스를 보내려면 넓은 대역폭이 필요한 이유입니다.

흔한 오해(1) \(X(j\omega)\)의 값을 "그 주파수의 진폭"으로 읽으면 안 됩니다. 밀도라서 단위가 [V·s]이고, 실제 성분은 좁은 주파수 구간에 대해 적분해야 나옵니다. (2) \(1 \leftrightarrow 2\pi\delta(\omega)\)의 \(2\pi\)를 빠뜨리는 실수가 많습니다. f를 쓰는 형태에서는 \(1 \leftrightarrow \delta(f)\)라 \(2\pi\)가 없습니다. (3) \(e^{at}u(t)\) (\(a > 0\))의 변환을 \(\frac{1}{-a + j\omega}\)로 쓰면 안 됩니다. 적분이 발산해 변환이 존재하지 않습니다.
요약
  1. \(X(j\omega) = \int x\,e^{-j\omega t}dt\), \(x = \frac1{2\pi}\int X\,e^{j\omega t}d\omega\). 급수에서 T → ∞로 얻는다.
  2. 펄스 ↔ \(2\sin(\omega T_1)/\omega\), \(e^{-at}u(t)\) ↔ \(1/(a + j\omega)\), \(\delta\) ↔ 1, 1 ↔ \(2\pi\delta(\omega)\), \(\cos\omega_0t\) ↔ \(\pi[\delta(\omega \mp \omega_0)]\).
  3. 시간에서 좁으면 주파수에서 넓다(척도 성질).

4.1.4연습문제

기본

  1. \(\delta(t - 3)\)의 변환과 그 크기·위상은?
    답

    \(e^{-j3\omega}\). 크기 1, 위상 \(-3\omega\).

  2. \(e^{-2|t|}\)의 변환을 구하여라.
    답

    \(\frac{1}{2 + j\omega} + \frac{1}{2 - j\omega} = \frac{4}{4 + \omega^2}\). 실수이고 짝함수.

응용

  1. \(X(j\omega) = 1\) (\(|\omega| < W\)), 0 (그 밖)의 역변환을 구하여라.
    답

    \(x(t) = \frac{1}{2\pi}\int_{-W}^{W}e^{j\omega t}d\omega = \frac{\sin Wt}{\pi t}\). 이상 저역 통과 필터의 임펄스 응답(비인과, 2.2절 연습 4).

심화

  1. \(te^{-at}u(t)\)의 변환을 \(\frac{d}{d\omega}X(j\omega) \leftrightarrow -jt\,x(t)\)로 구하여라.
    답

    \(\frac{d}{d\omega}\frac{1}{a + j\omega} = \frac{-j}{(a + j\omega)^2}\)이므로 \(tx \leftrightarrow j\frac{dX}{d\omega} = \frac{1}{(a + j\omega)^2}\).

4.1.2

탐구좁은 펄스, 넓은 스펙트럼

탐구 · 시간 폭과 주파수 폭의 반비례

다루는 성취기준 [전전6-04-01]

질문

펄스를 짧게 만들면 스펙트럼은 어떻게 될까요? 시간 폭과 주파수 폭을 곱한 값이 일정하다면, 그 값은 모양에 따라 얼마일까요?

준비

세 가지 모양의 폭을 같은 조절기 p로 바꿉니다: 직사각 펄스는 반폭 \(T_1 = p\), 지수 \(e^{-at}u(t)\)는 시정수 \(1/a = p\), 가우스는 표준편차 \(\sigma = p\). 위는 \(x(t)\), 아래는 \(X(j\omega)\)(직사각은 실수값 그대로, 나머지는 크기)입니다. 4.1절의 변환쌍 공식으로 그렸습니다.

해 보기와 설명

  1. 예제 확인직사각 p = 0.5(폭 1 s): X(0) = 1, 첫 영점 \(\omega = 2\pi \approx 6.283\) rad/s(1 Hz)입니다(예제 4.1.1). p를 1로 두 배 하면 첫 영점이 3.142로 절반이 됩니다.
  2. 곱은 일정직사각에서 폭 × 첫 영점은 늘 \(2\pi\), 지수에서 시정수 × 반전력 주파수는 늘 1입니다. 폭을 줄이면 스펙트럼이 그만큼 넓어집니다.
  3. 가우스스펙트럼도 가우스입니다. 옆엽(sidelobe)이 없어 매끄럽게 줄어듭니다. 직사각 펄스의 옆엽은 모서리에서 생깁니다(3.1절의 \(1/k\) 계수와 같은 이유).

연결과 적용

데이터 통신에서 펄스를 짧게(빠르게) 보내려면 넓은 대역폭이 필요하고, 같은 대역에서 더 빨리 보내려면 펄스 모양을 다듬어야 합니다. 양자역학의 불확정성 원리도 위치와 운동량이 Fourier 변환 관계라서 생기는 같은 현상입니다.

흔한 오해

  • "높이가 같으면 스펙트럼도 같은 높이다." X(0)은 펄스의 넓이입니다. 폭을 두 배로 하면 X(0)도 두 배가 됩니다.
