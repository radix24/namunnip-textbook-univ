4.R.1

연습연속시간 Fourier 변환 연습 문제

문제 6 · 계산·적용·판단 · 힌트 2단계

다루는 성취기준 [전전6-04-01] [전전6-04-02] [전전6-04-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(x(t) = e^{-3t}u(t - 1)\)의 Fourier 변환을 구하세요. [04-01]

    힌트 1

    \(e^{-3t} = e^{-3}e^{-3(t-1)}\)로 쓰세요.

    힌트 2

    시간 이동 성질.

    풀이

    \(x = e^{-3}\cdot e^{-3(t-1)}u(t-1)\) → \(X = e^{-3}\frac{e^{-j\omega}}{3 + j\omega}\). 직접 적분 \(\int_1^\infty e^{-(3 + j\omega)t}dt = \frac{e^{-(3 + j\omega)}}{3 + j\omega}\)로도 같습니다.

  2. 계산\(X(j\omega) = 2\pi\delta(\omega) + \pi\delta(\omega - 4) + \pi\delta(\omega + 4)\)의 역변환은? [04-01]

    힌트 1

    \(1 \leftrightarrow 2\pi\delta(\omega)\).

    힌트 2

    \(\cos\omega_0t \leftrightarrow \pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]\).

    풀이

    \(x(t) = 1 + \cos4t\).

  3. 계산\(h(t) = e^{-t}u(t)\)인 시스템에 \(x(t) = e^{-3t}u(t)\)를 넣을 때 출력을 주파수 영역에서 구하세요. [04-02]

    힌트 1

    \(Y = \frac{1}{(1 + j\omega)(3 + j\omega)}\).

    힌트 2

    부분분수 계수: \(v = -1\), \(v = -3\) 대입.

    풀이

    \(Y = \frac{1/2}{1 + j\omega} - \frac{1/2}{3 + j\omega}\) → \(y = \frac12(e^{-t} - e^{-3t})u(t)\). 검산: \(t = 0\)에서 0(컨볼루션은 0에서 시작), 2.1절 연습 4 공식과 같음.

  4. 판단학생이 "\(x(t)\)와 \(x(t - 5)\)는 스펙트럼이 같으니 같은 신호로 보아도 된다"고 했다. 평가하세요. [04-02]

    힌트 1

    시간 이동 성질은 무엇을 바꾸나요?

    힌트 2

    크기 스펙트럼과 위상 스펙트럼을 나눠 생각하세요.

    풀이

    크기 스펙트럼만 같습니다. 위상이 \(-5\omega\)만큼 다르고, 위상까지 있어야 신호가 정해집니다. 크기만으로는 시각 정보(언제 일어났는지)를 알 수 없습니다.

  5. 적용대역폭 \(W = 2\pi\cdot5\) kHz인 m(t)를 \(\cos(2\pi\cdot100\text{k}\,t)\)로 DSB-SC 변조한 뒤, 수신 측에서 \(\cos(2\pi\cdot100\text{k}\,t)\)를 다시 곱했다. 곱한 결과에 있는 성분의 주파수 범위를 모두 쓰고, 필요한 저역 통과 필터의 차단 주파수 범위를 구하세요. [04-03]

    힌트 1

    \(\cos^2 = \frac12 + \frac12\cos2\theta\).

    힌트 2

    200 kHz 근처에 복사본.

    풀이

    0~5 kHz(크기 \(\frac12M\))와 195~205 kHz(크기 \(\frac14M\), 양쪽). 차단 주파수는 5 kHz 초과 195 kHz 미만.

  6. 도전\(x(t) = \frac{\sin(2\pi t)}{\pi t}\)에 \(\cos(10\pi t)\)를 곱한 신호의 스펙트럼을 그리고, 이 신호의 에너지를 Parseval로 구하세요. [04-02, 04-03]

    힌트 1

    \(X\)는 \(|\omega| < 2\pi\)에서 1인 직사각형.

    힌트 2

    곱한 뒤에는 높이 1/2인 직사각형 두 개.

    풀이

    \(\omega = \pm10\pi\)를 중심으로 폭 \(4\pi\), 높이 1/2인 직사각형 두 개(겹치지 않음). 에너지 \(\frac{1}{2\pi}\cdot2\cdot\frac14\cdot4\pi = 1\). 원래 x의 에너지는 \(\frac{1}{2\pi}\cdot4\pi = 2\)이므로, 코사인을 곱하면 에너지가 절반이 됩니다(\(\cos^2\)의 평균 1/2).
