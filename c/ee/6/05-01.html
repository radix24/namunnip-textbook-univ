이 절에서 배울 것
  • 수열의 DTFT \(X(e^{j\omega}) = \sum x[n]e^{-j\omega n}\)과 역변환을 쓴다.
  • DTFT가 \(2\pi\) 주기 함수인 이유와, 낮은 주파수(\(\omega \approx 0\))와 높은 주파수(\(\omega \approx \pi\))의 뜻을 설명한다.
  • 직사각 수열, 지수 수열의 DTFT와 이동 평균 필터의 주파수 응답을 계산한다.
먼저 알아야 할 것
  • 연속시간 Fourier 변환 (4.1절), DTFS (3.1절), 등비급수의 합 공식.

5.1.1정의

컴퓨터 안의 신호는 수열 \(x[n]\)입니다. 연속시간 변환의 적분을 합으로 바꾸면 이산시간 Fourier 변환이 됩니다.

\[ X(e^{j\omega}) = \sum_{n=-\infty}^{\infty}x[n]\,e^{-j\omega n}, \qquad x[n] = \frac{1}{2\pi}\int_{2\pi}X(e^{j\omega})\,e^{j\omega n}\,d\omega. \]

이산 각주파수 \(\omega\): 단위는 [rad/표본]. 표본 사이에 위상이 얼마나 도는가.

표기 \(X(e^{j\omega})\): 7단원의 Z-변환 \(X(z)\)를 단위원 \(z = e^{j\omega}\) 위에서 잰 것이라는 뜻.

DTFT가 존재하려면(보통의 함수로) \(\sum|x[n]| < \infty\)이면 충분합니다. 2.2절의 안정 조건 \(\sum|h| < \infty\)와 같으므로, 안정한 시스템은 언제나 주파수 응답 \(H(e^{j\omega})\)를 가집니다.

5.1.2왜 주기 \(2\pi\)인가

구하려는 것: \(X(e^{j(\omega + 2\pi)})\)와 \(X(e^{j\omega})\)의 관계. 각 항의 지수에서 \(e^{-j(\omega + 2\pi)n} = e^{-j\omega n}e^{-j2\pi n} = e^{-j\omega n}\)입니다(n이 정수라 \(e^{-j2\pi n} = 1\)). 따라서 모든 항이 같아 \(X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})\).

물리적인 뜻: 정수 n에서만 보면 \(\cos(0.1\pi n)\)과 \(\cos(2.1\pi n)\)은 같은 수열입니다. 이산시간에는 \(2\pi\)보다 큰 주파수가 따로 없습니다. 그래서 \(-\pi < \omega \le \pi\) 한 구간만 보면 됩니다.

  • \(\omega \approx 0\) (또는 \(2\pi\)의 정수배): 천천히 변하는 신호, 낮은 주파수.
  • \(\omega = \pi\): \((-1)^n = e^{j\pi n}\), 매 표본마다 부호가 바뀌는 가장 빠른 신호.

표본화 주기가 \(T_s\)이면 연속 주파수와 \(\omega = \Omega T_s\) (Ω는 rad/s)로 연결됩니다. \(\omega = \pi\)가 표본화 주파수의 절반에 해당하며, 6단원에서 다시 봅니다.

5.1.3기본 DTFT 계산

예제 5.1.1

\(x[n] = a^nu[n]\) (\(|a| < 1\))의 DTFT를 구하고, \(a = 0.5\)일 때 \(\omega = 0\)과 \(\omega = \pi\)에서의 크기를 구하여라.

풀이. 등비급수: \(X = \sum_{n\ge0}(ae^{-j\omega})^n = \frac{1}{1 - ae^{-j\omega}}\) (공비의 크기 \(|a| < 1\)이라 수렴). \(a = 0.5\): \(\omega = 0\)이면 \(\frac{1}{0.5} = 2\), \(\omega = \pi\)이면 \(\frac{1}{1.5} \approx 0.667\). 양의 a는 저역 통과입니다. \(a = -0.5\)이면 값이 뒤바뀌어 고역 통과가 됩니다(2.2절 예제 카드의 시스템).

예제 5.1.2

L점 이동 평균 \(h[n] = \frac1L\) (\(0 \le n \le L - 1\))의 주파수 응답 크기를 구하고, L = 4일 때 영점을 찾아라.

풀이. 유한 등비합: \(H = \frac1L\sum_{n=0}^{L-1}e^{-j\omega n} = \frac1L\cdot\frac{1 - e^{-j\omega L}}{1 - e^{-j\omega}}\). 분자와 분모에서 반각 지수를 묶어 내면 \(\frac{e^{-j\omega L/2}(e^{j\omega L/2} - e^{-j\omega L/2})}{e^{-j\omega/2}(e^{j\omega/2} - e^{-j\omega/2})}\)이므로

\[ |H(e^{j\omega})| = \frac{1}{L}\left|\frac{\sin(\omega L/2)}{\sin(\omega/2)}\right|, \qquad \angle H = -\omega\frac{L - 1}{2}. \]

\(\omega = 0\)에서 1(직류 그대로), 영점은 \(\sin(\omega L/2) = 0\), 곧 \(\omega = 2\pi k/L\) (k ≠ 0). L = 4이면 \(\omega = \pi/2, \pi\). 한 주기 4표본인 진동은 4점 평균으로 정확히 지워집니다. 위상이 직선(\(-1.5\omega\))이라 모든 성분이 똑같이 1.5표본 늦어집니다(선형 위상, 8단원).

흔한 오해(1) "\(\omega\)를 키우면 더 높은 주파수"는 \(\pi\)까지만 맞습니다. \(\omega = 1.9\pi\)는 \(-0.1\pi\)와 같은, 낮은 주파수입니다. (2) DTFT는 \(\omega\)에 대해 연속 함수입니다. 수열이 이산이라 변환도 이산이라고 생각하기 쉬운데, 이산이 되는 것은 신호가 주기일 때(DTFS)나 다음 절의 DFT입니다. (3) 연속 Fourier 변환과 혼동해 \(X(j\omega)\)라 쓰면 주기성이 사라진 것처럼 보이므로 \(X(e^{j\omega})\) 표기를 지키세요.
요약
  1. \(X(e^{j\omega}) = \sum x[n]e^{-j\omega n}\), 역변환은 \(2\pi\) 한 주기 적분.
  2. DTFT는 \(2\pi\) 주기. \(\omega \approx 0\)이 저주파, \(\omega = \pi\)가 최고 주파수.
  3. \(a^nu[n] \leftrightarrow \frac1{1 - ae^{-j\omega}}\). L점 평균: \(|H| = \frac{|\sin(\omega L/2)|}{L|\sin(\omega/2)|}\), 영점 \(2\pi k/L\).

5.1.4연습문제

기본

  1. \(x = \delta[n] + 2\delta[n-1] + \delta[n-2]\)의 DTFT와 \(\omega = 0, \pi/2, \pi\)에서의 크기는?
    답

    \(X = 1 + 2e^{-j\omega} + e^{-j2\omega} = e^{-j\omega}(2 + 2\cos\omega)\). 크기 4, 2, 0.

  2. \(\cos(0.3\pi n)\)과 같은 수열이 되는 \(\cos(\omega n)\)을 \(\pi < \omega < 3\pi\)에서 모두 찾아라.
    답

    \(\omega = 1.7\pi\)(\(= 2\pi - 0.3\pi\)), \(2.3\pi\).

응용

  1. \(y[n] = x[n] - x[n-1]\)(차분기)의 \(|H|\)를 구하고 어떤 필터인지 말하여라.
    답

    \(|1 - e^{-j\omega}| = 2|\sin(\omega/2)|\). \(\omega = 0\)에서 0, \(\pi\)에서 2. 고역 통과.

심화

  1. \(x[n] = (-1)^na^nu[n]\)의 DTFT가 \(X(e^{j(\omega - \pi)})\)임을 보이고, 이것으로 저역 통과 필터를 고역 통과로 바꾸는 방법을 설명하여라.
    답

    \((-1)^n = e^{j\pi n}\)이므로 주파수 이동 성질로 \(\pi\)만큼 이동. 임펄스 응답에 \((-1)^n\)을 곱하면 응답 곡선이 \(\pi\)만큼 옮겨 저역 통과가 고역 통과가 됩니다.

5.1.2

탐구2π마다 되풀이되는 주파수 응답

탐구 · 이동 평균과 1차 되먹임의 DTFT

다루는 성취기준 [전전6-05-01]

질문

디지털 필터의 주파수 응답을 \(-3\pi\)부터 \(3\pi\)까지 그리면 어떤 모양일까요? 가장 높은 주파수는 어디일까요?

준비

두 시스템의 \(|H(e^{j\omega})|\)를 그립니다. 이동 평균: \(\frac{|\sin(\omega L/2)|}{L|\sin(\omega/2)|}\) (예제 5.1.2). 1차 되먹임 \(h = a^nu[n]\): \(\frac{1}{|1 - ae^{-j\omega}|}\) (예제 5.1.1). 색칠한 띠가 \(-\pi\)~\(\pi\)입니다. 선택하지 않은 시스템의 조절기는 쓰이지 않습니다.

해 보기와 설명

  1. 4점 평균\(\omega = 0, \pi/2, \pi\)에서 1, 0, 0. 영점이 \(0.5\pi\)와 \(\pi\)입니다. 색칠한 띠 밖의 모양은 띠 안을 그대로 옮긴 것입니다.
  2. L을 늘리기L = 8이면 주봉우리가 좁아져 영점이 \(0.25\pi\)부터 시작합니다. 더 많이 평균하면 더 낮은 주파수만 통과합니다.
  3. 되먹임 a = 0.5\(\omega = 0\)에서 2, \(\pi/2\)에서 0.894, \(\pi\)에서 0.667. a를 −0.5로 바꾸면 값이 뒤바뀌어 \(\pi\)에서 2가 됩니다(고역 통과, 2.2절 예제 카드).
  4. a를 0.95로\(\omega = 0\)에서 20으로 솟습니다. 극점이 단위원에 가까워 좁고 높은 봉우리가 생긴 것입니다(7단원).

연결과 적용

\(\omega = \pi\)는 표본화 주파수의 절반, 곧 그 시스템이 다룰 수 있는 최고 주파수입니다. 표본화 주파수가 48 kHz인 오디오라면 \(\omega = \pi\)가 24 kHz입니다(6단원).

흔한 오해

  • "\(\omega = 2\pi\)는 \(\pi\)보다 높은 주파수다." \(2\pi\)는 0과 같은, 직류입니다. 이산시간에서 가장 높은 주파수는 \(\pi\)입니다.
