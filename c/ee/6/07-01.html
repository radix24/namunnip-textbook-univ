7.1.1Fourier 변환이 없는 신호

\(e^{2t}u(t)\)나 불안정한 시스템의 임펄스 응답은 Fourier 적분이 발산합니다. 신호에 \(e^{-\sigma t}\)를 곱해 충분히 줄여 주면 적분이 수렴합니다. 이것이 Laplace 변환입니다.

\[ X(s) = \int_{-\infty}^{\infty}x(t)\,e^{-st}\,dt, \qquad s = \sigma + j\omega. \]

양방향 Laplace 변환: 적분이 \(-\infty\)부터. 공통8에서 배운 단방향(0부터) 변환은 \(t < 0\)에서 0인 신호에 대해 이것과 같다.

수렴 영역(ROC): 적분이 절대 수렴하는 s의 집합. 수렴 여부는 \(\sigma = \text{Re}(s)\)에만 달려 있으므로 s평면의 세로 띠 모양이다.

극점과 영점: 유리 함수 \(X(s) = N(s)/D(s)\)에서 \(D = 0\)인 점(극점, ×), \(N = 0\)인 점(영점, ○).

ROC가 허수축(\(\sigma = 0\))을 포함하면 \(X(j\omega) = X(s)|_{s = j\omega}\)로 Fourier 변환이 존재합니다.

7.1.2같은 식, 다른 ROC

예제 7.1.1

\(x_1(t) = e^{-at}u(t)\)와 \(x_2(t) = -e^{-at}u(-t)\)의 Laplace 변환과 ROC를 구하여라.

풀이. \(x_1\): \(\int_0^\infty e^{-(s + a)t}dt = \frac{1}{s + a}\). 위끝에서 \(e^{-(\sigma + a)t} \to 0\)이려면 \(\sigma > -a\). ROC: \(\text{Re}(s) > -a\) (극점의 오른쪽).

\(x_2\): \(-\int_{-\infty}^{0}e^{-(s + a)t}dt = -\left[\frac{e^{-(s + a)t}}{-(s + a)}\right]_{-\infty}^{0} = \frac{1}{s + a}\). 아래끝 \(t \to -\infty\)에서 \(e^{-(\sigma + a)t} \to 0\)이려면 \(\sigma < -a\). ROC: \(\text{Re}(s) < -a\) (극점의 왼쪽).

두 변환은 식이 똑같고 ROC만 다릅니다. 그래서 Laplace 변환은 "식 + ROC"를 함께 적어야 신호가 정해집니다. 단방향 변환만 다룰 때 ROC를 신경 쓰지 않았던 것은, 신호가 늘 오른쪽(인과)이라 ROC가 자동으로 정해졌기 때문입니다.

7.1.3ROC의 성질

  • ROC 안에는 극점이 없다(극점에서 X가 무한대).
  • 오른쪽 신호(어떤 시각 이후에만 0이 아님)의 ROC는 가장 오른쪽 극점의 오른쪽 반평면.
  • 왼쪽 신호의 ROC는 가장 왼쪽 극점의 왼쪽 반평면.
  • 양쪽 신호의 ROC는 두 극점 사이의 띠(또는 없음).
  • 유한 길이 신호의 ROC는 s평면 전체.

7.1.4인과성과 안정성 판정

구하려는 것: 전달함수 \(H(s)\)와 ROC만 보고 시스템의 성질을 판정하는 규칙. 2.2절의 조건을 ROC로 옮깁니다.

인과: h가 오른쪽 신호이므로 ROC가 가장 오른쪽 극점의 오른쪽 반평면(유리 함수인 경우).

안정: \(\int|h| < \infty\)이면 \(\sigma = 0\)에서 적분이 절대 수렴하므로, ROC가 허수축을 포함한다.

인과이고 안정: 두 조건을 합치면 모든 극점이 왼쪽 반평면(\(\text{Re} < 0\))에 있다.

예제 7.1.2

\(H(s) = \frac{1}{(s + 1)(s - 2)}\)일 때 가능한 ROC를 모두 적고, 각각의 인과성과 안정성을 판정하여라.

풀이. 극점 −1, 2. 가능한 ROC는 극점이 나누는 세 영역입니다.

  • \(\text{Re}(s) > 2\): 인과(오른쪽), 허수축 미포함 → 불안정.
  • \(-1 < \text{Re}(s) < 2\): 허수축 포함 → 안정, 양쪽 신호 → 비인과.
  • \(\text{Re}(s) < -1\): 왼쪽 신호(반인과), 불안정.

인과이면서 안정한 것은 없습니다. 극점 2가 오른쪽 반평면에 있기 때문입니다. 실시간 제어에서 이런 플랜트를 다룰 때는 되먹임으로 극점을 옮겨야 합니다(전전22 제어공학).

흔한 오해(1) "극점이 오른쪽 반평면에 있으면 불안정"은 인과 시스템일 때만 맞습니다. 비인과를 허용하면 위 둘째 ROC처럼 안정할 수 있습니다. (2) 허수축 위의 극점(예: \(1/s\), 적분기)은 ROC가 허수축을 포함할 수 없으므로 BIBO 안정이 아닙니다(2.2절 예제의 \(u(t)\)). (3) 공통8의 단방향 변환은 초기 조건을 다루기 좋고, 양방향 변환은 비인과 신호와 ROC 논의에 쓰입니다. 인과 신호에 대해서는 둘이 같습니다.
요약
  1. \(X(s) = \int x\,e^{-st}dt\), ROC는 \(\text{Re}(s)\)의 띠. 식 + ROC가 신호를 정한다.
  2. 오른쪽 신호 → 가장 오른쪽 극점의 오른쪽, 왼쪽 신호 → 가장 왼쪽 극점의 왼쪽.
  3. 안정 ⇔ ROC가 허수축 포함. 인과·안정 ⇔ 모든 극점의 실수부 < 0.

7.1.5연습문제

기본

  1. \(e^{-2|t|}\)의 Laplace 변환과 ROC는?
    답

    \(\frac{1}{s + 2} - \frac{1}{s - 2} = \frac{-4}{s^2 - 4}\), ROC \(-2 < \text{Re}(s) < 2\). 허수축 포함이라 Fourier 변환 \(\frac{4}{4 + \omega^2}\)과 일치(4.1절 연습 2).

  2. \(\delta(t - 1)\)의 변환과 ROC는?
    답

    \(e^{-s}\), s평면 전체.

응용

  1. 인과 시스템 \(H(s) = \frac{s + 3}{s^2 + 2s + 5}\)은 안정한가?
    답

    극점 \(-1 \pm 2j\), 실수부 −1 < 0이므로 안정.

심화

  1. \(X(s) = \frac{1}{s + 1}\)이고 ROC가 \(\text{Re}(s) < -1\)이면 \(x(t)\)는? 이 신호의 Fourier 변환이 없는 이유는?
    답

    \(-e^{-t}u(-t)\)(예제 7.1.1의 \(x_2\)). \(t \to -\infty\)에서 \(e^{-t}\)가 발산하므로 Fourier 적분이 발산(ROC가 허수축을 포함하지 않음).

7.1.2

탐구극점을 옮기면 임펄스 응답이 바뀐다

탐구 · s평면 극점, ROC, 안정성

다루는 성취기준 [전전6-07-01]

질문

전달함수의 극점이 s평면의 어디에 있느냐에 따라 임펄스 응답은 어떻게 달라질까요? 극점이 허수축을 넘어가는 순간 무슨 일이 생길까요?

준비

극점 \(\sigma \pm j\omega_d\) (\(\omega_d = 0\)이면 실수 극점 하나)인 인과 시스템의 임펄스 응답 \(h(t) = e^{\sigma t}\cos(\omega_dt)u(t)\)를 그립니다(실수 극점이면 \(e^{\sigma t}u(t)\)). 위: s평면의 극점(×)과 인과 시스템의 ROC(색칠, 가장 오른쪽 극점의 오른쪽). 아래: \(h(t)\)와 포락선 \(e^{\sigma t}\)(점선).

해 보기와 설명

  1. 처음 화면극점 \(-0.5 \pm 3j\). ROC \(\text{Re}(s) > -0.5\)가 허수축을 포함해 안정합니다. 주기 2.09 s로 진동하며, 2 s마다 포락선이 1/e로 줄어듭니다.
  2. σ를 0으로극점이 허수축 위에 놓이면 진동이 줄지 않습니다. ROC가 허수축을 포함하지 못해 BIBO 안정이 아닙니다(같은 주파수의 입력을 넣으면 공진으로 출력이 끝없이 커짐).
  3. σ를 양수로ROC가 허수축 오른쪽으로 물러나고 h가 지수적으로 커집니다. 색이 빨강으로 바뀝니다.
  4. ω_d를 0으로진동 없이 \(e^{\sigma t}\)로 줄거나 커지는 1차 시스템이 됩니다. 극점의 허수부가 진동 주파수, 실수부가 감쇠 속도를 정합니다.

연결과 적용

RLC 회로의 부족 감쇠(전전3 6단원)는 극점이 왼쪽 반평면의 복소 공액 쌍인 경우이고, 저항을 0으로 하면 극점이 허수축 위로 와서 LC 발진이 됩니다. 제어공학(전전22)에서는 되먹임으로 이 극점을 원하는 자리에 옮깁니다.

흔한 오해

  • "극점이 허수축 위에 있으면 진동이 일정하니 안정하다." 임펄스 응답은 유계이지만 \(\int|h| = \infty\)라 BIBO 안정이 아닙니다. 공진 주파수의 유계 입력이 무한한 출력을 만듭니다.
