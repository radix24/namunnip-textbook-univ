1.2.1왜 성질을 따지는가

시스템 하나하나를 따로 공부하면 끝이 없습니다. 대신 "이 시스템은 선형이고 시불변이다" 같은 성질만 알면, 다음 단원부터 나올 강력한 도구(컨볼루션, Fourier 변환, Laplace 변환)를 한꺼번에 쓸 수 있습니다. 그래서 새 시스템을 만나면 가장 먼저 성질을 판정합니다. 표기는 연속시간으로 쓰지만 이산시간에도 그대로 적용됩니다.

1.2.2여섯 가지 성질의 정의

무기억(memoryless): 각 시각의 출력이 같은 시각의 입력에만 의존한다. 저항 \(v = Ri\)는 무기억, 축전기 \(v = \frac1C\int i\,dt\)는 기억이 있다.

인과(causal): 출력이 현재와 과거의 입력에만 의존한다(미래를 보지 않는다). 실시간으로 동작하는 물리 시스템은 모두 인과적이다.

안정(BIBO stable): 유계인 입력(\(|x| \le B\))에 대해 출력도 언제나 유계이다.

시불변(time-invariant): 입력을 \(t_0\)만큼 늦추면 출력도 똑같이 \(t_0\)만큼 늦어질 뿐 모양은 같다.

선형(linear): 가산성 \(T\{x_1 + x_2\} = T\{x_1\} + T\{x_2\}\)과 동차성 \(T\{ax\} = aT\{x\}\)이 모두 성립한다. 한 줄로 \(T\{ax_1 + bx_2\} = aT\{x_1\} + bT\{x_2\}\).

가역(invertible): 출력에서 입력을 유일하게 되살릴 수 있다. \(y = 2x\)는 가역, \(y = x^2\)는 아니다(부호를 잃음).

1.2.3판정하는 방법

구하려는 것: 주어진 식이 각 성질을 만족하는지. 증명할 때와 부정할 때 방법이 다릅니다.

  • 성립을 보일 때: 아무 입력(임의의 \(x_1, x_2, a, b, t_0\))에 대해 정의의 등식을 일반적으로 보입니다.
  • 성립하지 않음을 보일 때: 등식이 깨지는 구체적인 입력 하나(반례)를 찾으면 끝입니다.

시불변 판정의 요령. 두 출력을 따로 계산해 비교합니다. (가) 입력을 먼저 늦춘 \(x_2(t) = x(t - t_0)\)을 시스템에 넣은 출력 \(y_2(t)\). (나) 원래 출력을 나중에 늦춘 \(y(t - t_0)\). 둘이 모든 경우에 같으면 시불변입니다. 식에서 t가 입력 밖에 따로 나타나면(\(t\,x(t)\)처럼) 대개 시변이고, 입력의 시간 인자가 \(x(2t)\)처럼 바뀌어도 시변입니다.

선형 판정의 빠른 점검. 입력 0을 넣으면 선형 시스템의 출력은 반드시 0입니다(동차성에서 a = 0). \(y = 2x + 3\)은 \(x = 0\)일 때 \(y = 3\)이므로 선형이 아닙니다(이런 것을 증분 선형이라 합니다).

예제 1.2.1

다음 시스템의 성질(무기억, 인과, 안정, 시불변, 선형)을 판정하여라. (가) \(y(t) = t\,x(t)\) (나) \(y[n] = x[n] + x[n-1]\) (다) \(y(t) = x(2t)\) (라) \(y(t) = e^{x(t)}\)

풀이.

  • (가) 같은 시각만 쓰므로 무기억·인과. \(x = 1\)(유계)이면 \(y = t\)가 무한히 커지므로 불안정. 시불변 점검: \(x_2 = x(t - t_0)\)이면 \(y_2 = t\,x(t - t_0)\)인데 \(y(t - t_0) = (t - t_0)x(t - t_0)\). 다르므로 시변. 선형: \(t(ax_1 + bx_2) = a\,tx_1 + b\,tx_2\)이므로 선형.
  • (나) 과거 값 \(x[n-1]\)을 쓰므로 기억이 있고, 미래는 쓰지 않으므로 인과. \(|y| \le 2B\)로 안정. 시불변이고 선형입니다. 이것이 2단원의 LTI 시스템(이동 평균)입니다.
  • (다) \(y(1) = x(2)\): 미래 값을 쓰므로 비인과이고 기억이 있습니다. 유계 입력이면 유계 출력이라 안정, 선형. 시불변 점검: \(y_2 = x_2(2t) = x(2t - t_0)\), \(y(t - t_0) = x(2t - 2t_0)\). 다르므로 시변.
  • (라) 무기억, 인과. \(|x| \le B\)이면 \(y \le e^B\)라 안정. 시불변. \(x = 0\)이면 \(y = 1\)이므로 비선형.

1.2.4LTI 시스템이 중심인 이유

선형이고 시불변인 시스템을 LTI 시스템이라 합니다. 저항·인덕터·축전기·연산증폭기로 만든 회로, 대부분의 필터와 통신 채널이 (근사적으로) LTI입니다. LTI 시스템은 임펄스 하나에 대한 응답만 알면 모든 입력에 대한 응답을 알 수 있다는 놀라운 성질이 있고(2단원), 복소 지수 입력에 대해 같은 주파수의 복소 지수를 내놓습니다(3단원). 이 과목의 나머지는 거의 이 두 사실에서 나옵니다.

흔한 오해"식에 t가 들어 있으면 시변이다"는 반만 맞습니다. \(y(t) = \int_{-\infty}^{t}x(\tau)d\tau\)는 적분 한계에 t가 있지만 시불변입니다(\(\tau\)를 바꿔 확인). 반대로 "선형 미분방정식이면 선형 시스템이다"도 초기 조건이 0일 때만 맞습니다. 초기 전압이 남은 축전기 회로는 입력 0에서도 출력이 있으므로 엄밀히는 선형이 아닙니다.
요약
  1. 무기억, 인과(미래 안 씀), BIBO 안정(유계 입력 → 유계 출력), 시불변(늦춘 입력 → 늦춘 출력), 선형(중첩), 가역.
  2. 성립은 일반적으로, 부정은 반례 하나로 보인다. 시불변은 "입력 먼저 늦추기"와 "출력 나중 늦추기"를 비교한다.
  3. 선형이면 입력 0 → 출력 0. LTI가 이 과목의 중심이다.

1.2.5연습문제

기본

  1. \(y[n] = x[-n]\)은 인과적인가? 시불변인가?
    답

    \(y[-3] = x[3]\)이라 비인과. \(x[n - n_0]\)을 넣으면 \(x[-n - n_0]\), \(y[n - n_0] = x[-n + n_0]\). 다르므로 시변.

  2. \(y(t) = x(t)\cos(\omega_c t)\)(변조기)는 선형인가? 시불변인가?
    답

    선형, 시변(코사인의 위상이 입력과 함께 늦춰지지 않음).

응용

  1. \(y[n] = \sum_{k=-\infty}^{n}x[k]\)(누산기)가 BIBO 안정이 아님을 반례로 보여라.
    답

    \(x[n] = u[n]\)(유계 1)이면 \(y[n] = n + 1\)로 무한히 커짐.

심화

  1. 가산성은 만족하지만 동차성은 만족하지 않는 시스템의 예를 들어라. (힌트: 복소수 입력)
    답

    \(y = \text{Re}\{x\}\). 더하기는 그대로지만 \(a = j\)이면 \(\text{Re}\{jx\} \ne j\,\text{Re}\{x\}\).

예제이동 평균 필터와 자동 이득 조절기의 성질

예제 · 정의대로 판정하고 반례 찾기

다루는 성취기준 [전전6-01-02]

먼저 예측

소리가 크면 줄이고 작으면 키우는 자동 이득 조절기 \(y(t) = \frac{x(t)}{1 + |x(t)|}\)는 선형일까요? 시불변일까요?

생각해 본 뒤 열기

시불변이지만 비선형입니다. 이득이 입력 크기에 따라 달라지므로 "두 배 입력 → 두 배 출력"이 성립하지 않습니다.

문제

다음 두 시스템의 무기억, 인과, 안정, 시불변, 선형 여부를 판정하여라. (가) 중앙 이동 평균 \(y[n] = \frac13(x[n-1] + x[n] + x[n+1])\) (나) \(y(t) = \frac{x(t)}{1 + |x(t)|}\)

전략

  1. 무기억·인과: 출력 식에 나타나는 입력의 시각을 본다.
  2. 안정: \(|x| \le B\)에서 \(|y|\)의 상한을 찾는다.
  3. 시불변: "입력 먼저 늦추기"와 "출력 나중 늦추기"를 비교한다.
  4. 선형: 성립하면 일반적으로, 깨지면 반례 하나로.

풀이

  1. (가) \(x[n+1]\)(미래 값)을 쓰므로 비인과이고 기억이 있다. 정의
  2. (가) \(|y| \le \frac13(B + B + B) = B\)이므로 안정. 삼각부등식
  3. (가) \(x_2[n] = x[n - n_0]\)을 넣으면 \(\frac13(x[n-1-n_0] + x[n-n_0] + x[n+1-n_0]) = y[n - n_0]\). 시불변. 각 항이 입력의 일차식이라 선형. 정의대로 대입
  4. (나) 같은 시각만 쓰므로 무기억, 인과. \(|y| = \frac{|x|}{1 + |x|} < 1\)이라 어떤 입력에도 유계, 안정. 식에 t가 따로 없어 시불변. 정의
  5. (나) 반례: \(x = 1\)이면 \(y = 0.5\), \(x = 2\)이면 \(y = 2/3 \approx 0.667\). 입력이 두 배인데 출력은 1.33배이므로 동차성이 깨져 비선형. 반례 하나

의미

(가)는 LTI이지만 비인과라서 실시간으로는 쓸 수 없고, 다 녹음한 뒤 처리할 때(사진, 저장된 데이터) 씁니다. 한 표본 늦춘 \(\frac13(x[n-2] + x[n-1] + x[n])\)로 바꾸면 인과가 됩니다. (나)는 출력이 늘 \(\pm1\) 안에 있는 포화(saturation) 특성으로, 증폭기가 전원 전압에 부딪힐 때의 모습과 비슷합니다.

검산

(가)에 \(x = \{\dots, 0, 3, 0, \dots\}\)(n = 0에 3)을 넣으면 \(y[-1] = y[0] = y[1] = 1\). 입력보다 한 칸 앞선 \(y[-1]\)이 이미 1이라 비인과가 눈에 보입니다. (나)에 \(x = 0\)이면 \(y = 0\)이지만, 이것만으로는 선형이 아닙니다(필요조건일 뿐).

이해 확인

\(y(t) = x(t) + x(t - 1)\cdot x(t - 2)\)는 시불변인가? 선형인가?

답

시불변(모든 항이 같이 늦춰짐), 비선형(입력끼리의 곱이 있어 두 배 입력이면 둘째 항이 네 배).

확인선형의 빠른 점검
