7.R.1

연습Laplace 변환과 Z-변환 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [전전6-07-01] [전전6-07-02] [전전6-07-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념\(H(s) = \frac{s - 1}{(s + 2)(s + 4)}\)인 시스템이 인과이고 안정하도록 ROC를 정하세요. 영점 s = 1은 안정성에 영향을 주나요? [07-01]

    힌트 1

    인과: 가장 오른쪽 극점의 오른쪽.

    힌트 2

    안정성은 극점과 ROC로만 정해집니다.

    풀이

    ROC \(\text{Re}(s) > -2\). 허수축을 포함하므로 안정. 영점은 안정성과 무관합니다(오른쪽 반평면 영점은 응답 모양에 영향을 주는 비최소 위상 시스템을 만듭니다).

  2. 계산\(x(t) = e^{-t}u(t) + e^{2t}u(-t)\)의 Laplace 변환과 ROC를 구하세요. [07-01]

    힌트 1

    각 항의 ROC를 따로 구해 교집합.

    힌트 2

    \(e^{2t}u(-t) \leftrightarrow -\frac{1}{s - 2}\), ROC \(\text{Re} < 2\).

    풀이

    \(\frac{1}{s + 1} - \frac{1}{s - 2} = \frac{-3}{(s + 1)(s - 2)}\), ROC \(-1 < \text{Re}(s) < 2\).

  3. 계산\(y[n] = 0.6y[n-1] + x[n] + x[n-1]\)의 \(H(z)\), 극점과 영점, \(|H(e^{j0})|\)와 \(|H(e^{j\pi})|\)를 구하세요. [07-02]

    힌트 1

    \(H = \frac{1 + z^{-1}}{1 - 0.6z^{-1}}\).

    힌트 2

    \(z = 1\)과 \(z = -1\)을 대입.

    풀이

    극점 0.6, 영점 −1. \(|H(1)| = 2/0.4 = 5\), \(|H(-1)| = 0\). 저역 통과, 안정.

  4. 판단학생이 "극점이 \(-0.5 \pm 0.9j\)인 이산 시스템은 실수부가 음수이니 안정하다"고 했다. 평가하세요. [07-02]

    힌트 1

    이산 시스템의 기준은 무엇인가요?

    힌트 2

    \(|p| = \sqrt{0.25 + 0.81}\).

    풀이

    틀렸습니다. 이산(인과) 시스템은 \(|p| < 1\)로 판정합니다. \(|p| = \sqrt{1.06} \approx 1.03 > 1\)이라 불안정입니다. 실수부 기준은 연속시간 s평면의 것입니다.

  5. 계산\(Y(s) = \frac{10}{s(s + 2)(s + 5)}\)(인과)의 역변환을 구하고 최종값을 확인하세요. [07-03]

    힌트 1

    극점 0, −2, −5에서 덮개 방법.

    힌트 2

    최종값 정리 \(\lim_{s\to0}sY(s)\).

    풀이

    \(A_0 = \frac{10}{2\cdot5} = 1\), \(A_{-2} = \frac{10}{(-2)(3)} = -\frac53\), \(A_{-5} = \frac{10}{(-5)(-3)} = \frac23\). \(y = (1 - \frac53e^{-2t} + \frac23e^{-5t})u(t)\). 최종값 1 = \(\lim sY = 10/10\). 검산: \(y(0) = 1 - 5/3 + 2/3 = 0\).

  6. 도전\(X(z) = \frac{1 + z^{-1}}{1 - 0.25z^{-2}}\)(인과)의 역변환을 구하세요. [07-03]

    힌트 1

    \(1 - 0.25z^{-2} = (1 - 0.5z^{-1})(1 + 0.5z^{-1})\).

    힌트 2

    분자 차수가 분모와 같지 않으니(\(z^{-1}\)의 1차 대 2차) 바로 쪼갤 수 있습니다.

    풀이

    극점 0.5: \(A = \frac{1 + 2}{1 + 0.5\cdot2} = \frac32\). 극점 −0.5: \(B = \frac{1 - 2}{1 - 0.5\cdot(-2)} = -\frac12\). \(x[n] = (\frac32(0.5)^n - \frac12(-0.5)^n)u[n]\). 검산: \(x[0] = 1\), \(x[1] = 0.75 + 0.25 = 1\)(긴 나눗셈: \(1 + z^{-1} + 0.25z^{-2} + \cdots\)).
