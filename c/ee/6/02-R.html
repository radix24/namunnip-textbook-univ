2.R.1

연습LTI 시스템과 컨볼루션 연습 문제

문제 6 · 계산·개념·판단 · 힌트 2단계

다루는 성취기준 [전전6-02-01] [전전6-02-02] [전전6-02-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(x[n] = \{2, 1, -1\}\)(n = 0, 1, 2), \(h[n] = \{1, 2\}\)(n = 1, 2)일 때 \(y = x * h\)를 구하세요. [02-01]

    힌트 1

    h가 n = 1에서 시작합니다. 결과는 n = 0 + 1 = 1에서 시작.

    힌트 2

    다항식 \((2 + z - z^2)(1 + 2z)\)처럼 곱하고 위치를 한 칸 미세요.

    풀이

    계수 곱: \(2, 4 + 1, 2 - 1, -2\) = \(\{2, 5, 1, -2\}\), n = 1, 2, 3, 4. 합 확인: \(2 \times 3 = 6 = 2 + 5 + 1 - 2\).

  2. 계산\(x(t) = u(t) - u(t - 2)\), \(h(t) = e^{-t}u(t)\)일 때 \(y(t)\)를 구간별로 구하고 \(y(2)\)를 수치로 적으세요. [02-01]

    힌트 1

    \(x = u(t) - u(t - 2)\)이므로 계단 응답 \(s(t) = (1 - e^{-t})u(t)\)의 차.

    힌트 2

    \(y = s(t) - s(t - 2)\).

    풀이

    \(t < 0\): 0. \(0 \le t < 2\): \(1 - e^{-t}\). \(t \ge 2\): \((1 - e^{-t}) - (1 - e^{-(t-2)}) = (e^{2} - 1)e^{-t}\). \(y(2) = 1 - e^{-2} \approx 0.865\). 컨볼루션을 직접 하지 않고 선형·시불변을 쓴 것이 요령입니다.

  3. 개념임펄스 응답이 \(h_1 = \delta[n] - \delta[n-1]\)인 시스템과 \(h_2 = u[n]\)인 시스템을 직렬로 이으면 전체 임펄스 응답은? 순서를 바꾸면? [02-01]

    힌트 1

    직렬 연결 = 컨볼루션(결합 법칙).

    힌트 2

    \(u[n] - u[n-1]\)은?

    풀이

    \(h_1 * h_2 = u[n] - u[n - 1] = \delta[n]\). 순서를 바꿔도 교환 법칙으로 같음. 차분기와 누산기는 서로의 역시스템입니다.

  4. 판단\(h(t) = e^{-2|t|}\)인 시스템을 학생이 "넓이가 유한하니 안정이고, 실제로 만들 수 있다"고 했다. 평가하세요. [02-02]

    힌트 1

    \(\int e^{-2|t|}dt\)는?

    힌트 2

    \(t < 0\)에서 h는?

    풀이

    안정은 맞습니다(\(\int|h| = 1\)). 그러나 \(t < 0\)에서 h가 0이 아니라 비인과이므로 실시간으로는 만들 수 없습니다. 저장된 데이터에 대해서는(오프라인 처리) 쓸 수 있습니다.

  5. 계산\(y[n] - 0.6y[n-1] = 2x[n]\)의 임펄스 응답과 \(\sum|h|\)를 구하고, 출력의 상한(\(|x| \le 1\))을 적으세요. [02-02, 02-03]

    힌트 1

    \(h[0] = 2\), 그다음은 매번 0.6배.

    힌트 2

    등비급수 \(2/(1 - 0.6)\).

    풀이

    \(h[n] = 2(0.6)^nu[n]\), \(\sum|h| = 2/0.4 = 5\). 안정, \(|y| \le 5\). 모든 h가 양수이므로 상수 입력 1이 이 상한에 닿습니다.

  6. 도전\(y[n] = 1.2y[n-1] - 0.72y[n-2] + x[n]\)의 특성근을 구하고, 임펄스 응답이 몇 표본마다 한 번 진동하며 얼마나 빨리 줄어드는지 설명하세요. [02-03]

    힌트 1

    \(r^2 - 1.2r + 0.72 = 0\).

    힌트 2

    복소근 \(re^{\pm j\theta}\)이면 \(h \sim r^n\cos(\theta n + \phi)\), 주기 \(2\pi/\theta\).

    풀이

    \(r = 0.6 \pm 0.6j\), 크기 \(0.6\sqrt2 \approx 0.849\), 각 45°. 8표본마다 한 번 진동하고, 한 번 진동할 때마다 \(0.849^8 \approx 0.27\)배로 줄어듭니다. 안정. 탐구 카드에서 \(a_1 = 1.2\), \(a_2 = -0.7\)(가장 가까운 값)으로 모양을 확인할 수 있습니다.
