4.R.1

연습연산증폭기 회로 연습 문제

문제 6 · 개념·계산·판단 · 힌트 2단계

다루는 성취기준 [전전3-04-01] [전전3-04-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요. 연산증폭기는 따로 말이 없으면 이상적이고 전원은 ±12 V(출력 한계 약 ±10.5 V)입니다.

  1. 개념비교기(되먹임 없음)에서는 왜 가상 단락을 쓸 수 없나요? [04-01]

    힌트 1

    가상 단락은 어떤 가정에서 나왔나요? (4.1.2)

    힌트 2

    출력이 유한한 값에 머무르는 것은 무엇 덕분인가요?

    풀이

    \(v_+ - v_- = v_o/A \approx 0\)은 출력이 전원 범위 안의 값에 머문다는 가정에서 나왔고, 그렇게 출력을 묶어 두는 것이 음의 되먹임입니다. 되먹임이 없으면 작은 입력 차도 \(A\)배로 커져 출력이 포화되고, 이때 \(v_+ - v_-\)는 입력이 정하는 대로 남습니다.

  2. 계산반전 증폭기 \(R_1 = 4.7\ \text{k}\Omega\), \(R_f = 47\ \text{k}\Omega\)에 \(v_i = 1.5\) V를 넣었다. 출력, \(R_f\)의 전류, 연산증폭기 출력 단자가 내보내는 전류(부하 10 kΩ)를 구하세요. [04-01]

    힌트 1

    출력 −15 V가 전원 범위 안인가요?

    힌트 2

    포화되면 출력은 −10.5 V이고 가상 단락은 깨집니다.

    풀이

    이상 출력은 −15 V이지만 출력 한계 때문에 약 −10.5 V에서 포화됩니다. 이때 반전 입력은 0 V가 아니라 \(R_1, R_f\) 분압으로 \(v_- = 1.5 + (-10.5 - 1.5)\frac{4.7}{51.7} \approx 0.41\) V. \(R_f\) 전류는 \((0.41 + 10.5)/47 \approx 0.232\) mA(반전 입력 → 출력). 출력 단자는 이 전류를 받아들이고 부하 10 kΩ으로 1.05 mA를 끌어오므로 약 1.28 mA를 흡수(싱크)합니다. 입력을 1 V 아래로 줄이면 선형으로 돌아옵니다.

  3. 계산비반전 증폭기 \(R_1 = 10\ \text{k}\Omega\), \(R_f = 90\ \text{k}\Omega\)의 이득을, 열린 루프 이득 \(A = 2000\)일 때 정확히 구하고 이상 이득과의 오차를 쓰세요. [04-01]

    힌트 1

    \(\frac{A}{1 + A\beta}\), \(\beta = R_1/(R_1 + R_f)\).

    힌트 2

    \(\beta = 0.1\), \(A\beta = 200\).

    풀이

    \(2000/201 \approx 9.950\). 이상 10에 대해 −0.5%. 오차는 대략 \(1/(A\beta)\)입니다.

  4. 계산\(v_o = 3v_1 - 2v_2\)를 연산증폭기 하나로 만드세요(차동 증폭기를 변형). [04-02]

    힌트 1

    \(v_2\)는 반전 입력으로 \(-R_f/R_a\) = −2.

    힌트 2

    비반전 쪽 이득은 \(1 + R_f/R_a = 3\)이므로 \(v_1\)을 비반전 입력에 바로 넣으면 됩니다.

    풀이

    \(R_a = 10\ \text{k}\Omega\)(\(v_2\) → 반전 입력), \(R_f = 20\ \text{k}\Omega\)(반전 입력 → 출력), \(v_1\)은 비반전 입력에 직접. 중첩: \(v_2\)만 → \(-2v_2\), \(v_1\)만 → \((1 + 2)v_1 = 3v_1\). 합 \(3v_1 - 2v_2\).

  5. 판단학생이 "반전 증폭기의 입력 저항은 연산증폭기 입력처럼 무한대"라고 썼다. 무엇이 틀렸고, 그 결과 \(R_1 = 1\ \text{k}\Omega\) 반전 증폭기를 내부 저항 1 kΩ인 신호원에 달면 이득이 어떻게 되는가? [04-02]

    힌트 1

    입력 전류는 \(v_i/R_1\)로 흘러 가상 접지로 갑니다.

    힌트 2

    신호원 내부 저항은 \(R_1\)과 직렬.

    풀이

    반전 입력 단자 자체는 전류를 받지 않지만, 입력 신호는 \(R_1\)을 지나 가상 접지로 전류를 보내므로 입력 저항은 \(R_1\)입니다. 신호원 내부 저항 1 kΩ이 더해져 실효 \(R_1\)이 2 kΩ이 되고, 이득은 의도한 값의 절반이 됩니다.

  6. 도전4비트 가중 저항형 DAC: 디지털 비트 \(b_3b_2b_1b_0\)가 1이면 5 V, 0이면 0 V를 내고, 각각 \(R, 2R, 4R, 8R\)을 거쳐 가상 접지로 들어간다. \(R_f\)는 얼마로 해야 출력이 \(-\frac{5}{16}\times(\text{2진수 값})\), 곧 1111일 때 −4.6875 V가 되는가? \(R = 10\ \text{k}\Omega\)으로 하라. [04-02]

    힌트 1

    가산 증폭기: \(v_o = -R_f\sum v_k/R_k\).

    힌트 2

    \(b_3\)만 1이면 \(-R_f\cdot5/R\), 이것이 \(-5\cdot8/16 = -2.5\) V가 되어야 합니다.

    풀이

    \(b_3\)만 1일 때 \(-5R_f/R = -2.5\) → \(R_f = R/2 = 5\ \text{k}\Omega\). 그러면 \(b_k\)의 기여는 \(-5\cdot\frac{R/2}{2^{3-k}R} = -\frac{5}{16}2^k\)이고, 1111이면 \(-\frac{5}{16}\times15 = -4.6875\) V. 비트 수가 늘면 저항 비가 커져(8비트면 128배) 정밀하게 만들기 어려워 실제로는 R-2R 사다리를 씁니다.
