6.2.1최종값 + 자연 응답

\(t = 0\)에 직류 전원 \(V_s\)를 직렬 RLC에 연결하면 KVL은 \(LC\ddot v_C + RC\dot v_C + v_C = V_s\)입니다. 1차 회로(5.2절)에서처럼 \(u = v_C - V_s\)로 두면 \(u\)는 전원 없는 방정식(6.1절)을 만족합니다. 따라서

\[ v_C(t) = \underbrace{V_s}_{\text{최종값}} + \underbrace{u(t)}_{\text{자연 응답 꼴}}, \]

\(u\)는 감쇠 유형에 따라 6.1절의 세 꼴 중 하나이고, 상수 둘은 \(v_C(0^+)\)와 \(\dot v_C(0^+) = i(0^+)/C\)로 정합니다. 최종값은 직류 정상 상태(C 개방, L 단락)에서 구합니다. 이것은 일반적인 규칙입니다: 2차 회로의 계단 응답 = 최종값 + (특성근으로 정해지는 지수·진동).

6.2.2부족감쇠의 계단 응답

처음에 모든 에너지가 0(\(v_C(0) = 0\), \(i(0) = 0\))이면 \(u = e^{-\alpha t}(B_1\cos\omega_dt + B_2\sin\omega_dt)\)에서 \(u(0) = -V_s\)이므로 \(B_1 = -V_s\), \(\dot u(0) = 0\)이므로 \(-\alpha B_1 + \omega_dB_2 = 0\), \(B_2 = -\frac{\alpha}{\omega_d}V_s\). 정리하면

\[ v_C(t) = V_s\Big[1 - e^{-\alpha t}\Big(\cos\omega_dt + \frac{\alpha}{\omega_d}\sin\omega_dt\Big)\Big]. \]

이 응답에서 쓰임새가 큰 세 지표를 구합니다.

첫 봉우리 시각: \(\dot v_C = 0\)인 첫 \(t > 0\). 미분해 정리하면 \(\dot v_C = V_s\frac{\omega_0^2}{\omega_d}e^{-\alpha t}\sin\omega_dt\)이므로 \(t_p = \pi/\omega_d\).

넘침(overshoot): \(t_p\)를 넣으면 \(\cos = -1\), \(\sin = 0\)이라 \(v_C(t_p) = V_s(1 + e^{-\alpha\pi/\omega_d})\). 넘침 비율 \(e^{-\pi\zeta/\sqrt{1 - \zeta^2}}\).

2% 정착 시간: 포락선 \(e^{-\alpha t}\)이 0.02 아래가 되는 때, 대략 \(t_s \approx 4/\alpha\).

예제 6.2.1

직렬 RLC, \(R = 50\ \Omega\), \(L = 10\) mH, \(C = 1\ \mu\text{F}\), 처음 에너지 0. \(t = 0\)에 5 V를 연결한다. \(v_C\)의 첫 봉우리 시각과 값, 정착 시간을 구하여라.

풀이. 6.1절 예제 6.1.1에서 \(\alpha = 2500\), \(\omega_d \approx 9682\), \(\zeta = 0.25\). \(t_p = \pi/9682 \approx 0.324\) ms. 넘침 \(e^{-\pi\times0.25/0.968} \approx e^{-0.811} \approx 0.444\), 첫 봉우리 \(5\times1.444 \approx 7.22\) V. 정착 시간 \(4/2500 = 1.6\) ms.

전원 전압이 5 V인데 축전기가 7.2 V까지 올라갑니다. 인덕터에 쌓인 에너지가 전류를 계속 밀어 축전기를 더 충전하기 때문입니다. 전원 회로에서 이런 넘침은 부품 내압을 넘을 수 있어, 저항(감쇠)을 더해 임계감쇠 근처로 맞춥니다.

6.2.3과감쇠와 임계감쇠

예제 6.2.2

같은 회로에서 \(R = 200\ \Omega\)(임계감쇠)이면 \(v_C(t)\)는?

풀이. \(\alpha = \omega_0 = 10^4\). \(u = (A_1 + A_2t)e^{-10^4t}\), \(u(0) = -5\) → \(A_1 = -5\). \(\dot u(0) = A_2 - 10^4A_1 = 0\) → \(A_2 = -5\times10^4\). \(v_C = 5\big[1 - (1 + 10^4t)e^{-10^4t}\big]\) V. 넘침 없이 다가가고, \(t = 0.5\) ms에 \(5[1 - 6e^{-5}] \approx 4.80\) V(96%)입니다.

주의계단 응답에서 \(\dot v_C(0^+) = 0\)인 것은 이 회로에서 \(i_L(0^+) = 0\)이고 축전기 전류가 인덕터 전류와 같기 때문입니다. 병렬 RLC나 다른 연결에서는 0⁺ 회로를 풀어 따로 구해야 합니다.
요약
  1. 계단 응답 = 최종값(직류 정상 상태) + 자연 응답 꼴(특성근으로 정해짐). 상수는 \(x(0^+)\), \(\dot x(0^+)\)로.
  2. 부족감쇠: \(t_p = \pi/\omega_d\), 넘침 \(e^{-\pi\zeta/\sqrt{1 - \zeta^2}}\), \(t_s \approx 4/\alpha\).
  3. 넘침이 싫으면 \(\zeta \ge 1\), 빠르면서도 넘침이 작으려면 \(\zeta \approx 0.7\)을 고른다.

6.2.4연습문제

기본

  1. \(\zeta = 0.5\)인 계단 응답의 넘침은 몇 %인가?
    답

    \(e^{-\pi\times0.5/0.866} \approx 16.3\%\).

응용

  1. \(L = 10\) mH, \(C = 1\ \mu\text{F}\) 직렬 RLC에서 넘침을 5% 이하로 하려면 \(R\)은 최소 얼마인가?
    힌트

    \(e^{-\pi\zeta/\sqrt{1 - \zeta^2}} = 0.05\)에서 \(\zeta \approx 0.69\).

    답

    \(\zeta \ge 0.69\), \(R = 2\zeta\sqrt{L/C} \ge 2\times0.69\times100 \approx 138\ \Omega\).

심화

  1. 예제 6.2.1에서 축전기 전압의 봉우리 값을 에너지로 따져 보아라. 봉우리에서 인덕터 에너지는 얼마인가? 전원이 그때까지 공급한 에너지와 비교하여라.
    힌트

    봉우리에서 \(\dot v_C = 0\)이면 전류도 0. 전원이 낸 에너지 = \(V_s\times\)(옮겨진 전하) = \(V_s\,Cv_C(t_p)\).

    답

    봉우리에서 \(i = 0\)이라 인덕터 에너지 0. 축전기 에너지 \(\frac12(10^{-6})(7.22)^2 \approx 26.1\ \mu\text{J}\). 전원 에너지 \(5\times10^{-6}\times7.22 \approx 36.1\ \mu\text{J}\). 차이 10 μJ가 저항에서 열이 되었다.

6.2.2

예제병렬 RLC의 계단 응답: 인덕터 전류 구하기

예제 · 최종값과 초기 조건 정하기

다루는 성취기준 [전전3-06-02]

먼저 예측

1 A 전류원을 \(t = 0\)에 병렬 RLC에 연결하면, 처음 순간 1 A는 R, L, C 중 어디로 갈까요?

생각해 본 뒤 열기

인덕터 전류는 0에서 바로 바뀔 수 없고, 축전기 전압이 0이라 저항 전류도 0입니다. 그래서 처음 순간 1 A는 모두 축전기로 갑니다.

문제

\(R = 500\ \Omega\), \(L = 0.1\) H, \(C = 0.1\ \mu\text{F}\)가 같은 두 마디 사이에 병렬로 있고, 처음 에너지는 0이다. \(t = 0\)에 1 mA 전류원을 연결한다. 인덕터 전류 \(i_L(t)\)를 구하여라.

문제 해결 전략

  1. 감쇠 유형: 병렬이므로 \(\alpha = 1/(2RC)\), \(\omega_0 = 1/\sqrt{LC}\).
  2. 최종값: 직류 정상 상태에서 인덕터 단락 → 모든 전류가 인덕터로.
  3. 초기 조건: \(i_L(0^+) = 0\), \(di_L/dt(0^+) = v_L(0^+)/L = v_C(0^+)/L = 0\).
  4. 최종값 + 자연 응답 꼴에 넣어 상수를 정한다.

풀이

  1. \(\alpha = 1/(2\times500\times10^{-7}) = 10^4\), \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\). \(\zeta = 1\), 임계감쇠. 6.1절
  2. 최종값 \(i_L(\infty) = 1\) mA. L 단락이면 R, C에는 전압 0
  3. \(i_L = 1 + (A_1 + A_2t)e^{-10^4t}\) mA. \(i_L(0) = 0\) → \(A_1 = -1\). 연속성
  4. \(\dot i_L(0) = A_2 - 10^4A_1 = 0\) → \(A_2 = -10^4\). \(v_C(0^+) = 0\)
  5. \(i_L(t) = 1 - (1 + 10^4t)e^{-10^4t}\) mA. 정리

의미

1 mA는 처음에 축전기로 들어가 전압을 세우고, 그 전압이 인덕터 전류를 키워 결국 모두 인덕터로 넘어갑니다. 임계감쇠라 넘침 없이 0.5 ms 만에 96% 도달합니다. 같은 회로에서 \(R\)을 키우면(병렬이라 감쇠가 줄어) 인덕터 전류가 1 mA를 넘어 출렁입니다.

검산

암페어로 쓰면 \(i_L = 10^{-3}[1 - (1 + 10^4t)e^{-10^4t}]\)이고, 미분하면 \(di_L/dt = 10^{-3}\cdot10^8\,t\,e^{-10^4t} = 10^5\,t\,e^{-10^4t}\) A/s입니다. 따라서 \(v_C = L\,di_L/dt = 10^4\,t\,e^{-10^4t}\) V로, \(t = 0\)과 \(t \to \infty\)에서 0이고 \(t = 0.1\) ms에서 최대 \(e^{-1} \approx 0.37\) V입니다. 0⁺에서 축전기 전류 \(C\,dv_C/dt(0) = 10^{-7}\times10^4 = 1\) mA로, 처음 1 mA가 모두 축전기로 간다는 예측과 같습니다.

바꿔 보기

\(R = 2\ \text{k}\Omega\)이면 \(\alpha = 2500\), \(\zeta = 0.25\)로 부족감쇠가 되어 인덕터 전류의 첫 봉우리는 약 1.44 mA입니다(6.2절의 넘침 식).
