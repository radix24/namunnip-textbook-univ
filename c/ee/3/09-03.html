9.3.1주기 신호 = 사인파들의 합

컴퓨터 클록(구형파), 전원 장치의 정류 출력, 기타 소리는 사인파가 아닙니다. 그런데 7, 8단원의 페이저는 사인파 하나에만 씁니다. 다리를 놓는 것이 Fourier 급수입니다. 주기 \(T\)(기본 각주파수 \(\omega_0 = 2\pi/T\))인 신호는

\[ f(t) = a_0 + \sum_{n=1}^{\infty}\big(a_n\cos n\omega_0t + b_n\sin n\omega_0t\big) \]

로 쓸 수 있고, 계수는 \(a_0 = \frac1T\int_0^Tf\,dt\)(평균), \(a_n = \frac2T\int_0^Tf\cos n\omega_0t\,dt\), \(b_n = \frac2T\int_0^Tf\sin n\omega_0t\,dt\)입니다. 이 공식은 서로 다른 \(n\)의 사인·코사인을 곱해 한 주기 적분하면 0이 된다는 직교성에서 나옵니다. \(n\omega_0\) 성분을 \(n\)차 고조파라 합니다.

예제 9.3.1 (구형파)

한 주기의 앞 절반은 \(+V\), 뒤 절반은 \(-V\)인 구형파의 Fourier 급수를 구하여라.

풀이. 평균 0이라 \(a_0 = 0\). 원점에 대해 홀함수(\(t \to -t\)이면 부호가 바뀜)라 코사인 항도 0. \(b_n = \frac2T\Big[\int_0^{T/2}V\sin n\omega_0t\,dt - \int_{T/2}^{T}V\sin n\omega_0t\,dt\Big] = \frac{2V}{n\pi}(1 - \cos n\pi)\). \(n\)이 짝수면 0, 홀수면 \(\frac{4V}{n\pi}\). 따라서

\[ f(t) = \frac{4V}{\pi}\Big(\sin\omega_0t + \frac13\sin3\omega_0t + \frac15\sin5\omega_0t + \cdots\Big). \]

고조파 진폭이 \(1/n\)로 천천히 줄어듭니다. 날카로운 모서리를 만들려면 높은 주파수가 많이 필요하다는 뜻입니다.

9.3.2회로의 응답: 고조파마다 페이저

회로가 선형이면 중첩이 성립하므로, 각 고조파를 따로 넣어 정상상태 응답을 구하고 더하면 됩니다. 고조파마다 주파수가 다르므로 임피던스를 고조파마다 다시 계산합니다.

  1. 입력을 Fourier 급수로 쓴다.
  2. 직류 성분: C 개방, L 단락으로 푼다.
  3. \(n\)차 고조파: \(\omega = n\omega_0\)에서 전달함수 \(H(jn\omega_0)\)를 구해 진폭을 \(|H|\)배, 위상을 \(\angle H\)만큼 바꾼다.
  4. 시간 함수로 바꾸어 모두 더한다(페이저끼리 더하지 않는다).
예제 9.3.2

±1 V, 1 kHz 구형파를 RC 저역 통과 필터(차단 주파수 1 kHz)에 넣었다. 출력의 1차, 3차, 5차 고조파 진폭을 구하여라.

풀이. \(|H(f)| = 1/\sqrt{1 + (f/1\,\text{kHz})^2}\). 1차: 입력 \(4/\pi = 1.273\), \(|H| = 0.707\) → 0.900 V, 위상 −45°. 3차: 입력 0.424, \(|H| = 1/\sqrt{10} = 0.316\) → 0.134 V, −71.6°. 5차: 입력 0.255, \(|H| = 0.196\) → 0.050 V, −78.7°. 높은 고조파가 많이 깎여 출력은 모서리가 둥근, 사인파에 가까운 모양이 됩니다.

9.3.3실효값과 평균 전력

서로 다른 주파수의 곱은 평균이 0이므로(직교성), 비정현 신호의 제곱 평균은 각 성분의 제곱 평균의 합입니다.

\[ V_\text{rms}^2 = a_0^2 + \sum_n\frac{a_n^2 + b_n^2}{2}, \qquad P = V_0I_0 + \sum_n\frac{V_nI_n}{2}\cos\theta_n. \]

평균 전력도 같은 주파수끼리만 만들어집니다. 3.1절에서 전력은 중첩되지 않는다고 했지만, 주파수가 다른 성분끼리는 교차 항의 평균이 0이라 예외적으로 더할 수 있습니다.

확인: 구형파 ±V의 실효값은 분명히 \(V\)입니다. 급수로 계산하면 \(\sum_{n\ \text{홀수}}\frac{1}{2}\big(\frac{4V}{n\pi}\big)^2 = \frac{8V^2}{\pi^2}\sum\frac{1}{n^2} = \frac{8V^2}{\pi^2}\cdot\frac{\pi^2}{8} = V^2\)로 같습니다(\(1 + \frac19 + \frac1{25} + \cdots = \frac{\pi^2}{8}\)).

주의고조파 페이저 \(\mathbf V_1\)과 \(\mathbf V_3\)을 더해 하나의 페이저로 만들면 안 됩니다. 주파수가 다르면 회전 속도가 달라 "같은 순간의 화살표"라는 페이저의 전제가 깨집니다. 반드시 시간 함수로 바꾼 뒤 더합니다.
요약
  1. 주기 신호 = 직류 + 고조파들. 구형파는 홀수 고조파 \(4V/(n\pi)\).
  2. 선형 회로: 고조파마다 \(H(jn\omega_0)\)로 페이저 해석 → 시간 함수로 바꿔 합.
  3. 실효값의 제곱과 평균 전력은 주파수 성분별 합(같은 주파수끼리만).

9.3.4연습문제

기본

  1. \(v(t) = 3 + 4\cos100t + 3\sin300t\) V의 실효값은?
    답

    \(\sqrt{9 + 8 + 4.5} = \sqrt{21.5} \approx 4.64\) V.

응용

  1. 위 전압을 2 Ω 저항과 1 mH 인덕터 직렬에 걸었다. 평균 전력은?
    답

    직류: 인덕터 단락, \(9/2 = 4.5\) W. 100 rad/s: \(|Z| = |2 + j0.1| \approx 2.0025\), 전류 진폭 1.998, \(\frac12\times1.998^2\times2 \approx 3.99\) W. 300: \(|Z| = |2 + j0.3| = 2.022\), 전류 1.484, \(\frac12\times1.484^2\times2 \approx 2.20\) W. 합 약 10.7 W.

심화

  1. 0/V 구형파(듀티 50%)의 Fourier 급수는 ±V/2 구형파와 어떤 관계인가? 직류 성분과 1차 고조파 진폭을 구하여라.
    답

    0/V 구형파 = \(V/2\) + (±V/2 구형파). 직류 \(V/2\), 1차 고조파 \(\frac{4}{\pi}\cdot\frac V2 = \frac{2V}{\pi}\).

9.3.2

탐구구형파를 필터에 넣으면: 고조파마다 따로 계산하기

탐구 · Fourier 급수와 중첩

다루는 성취기준 [전전3-09-03]

질문

구형파를 RC 저역 통과 필터에 넣으면 모서리가 둥글어진다는 것을 5.3절에서 시간 영역으로 보았습니다. 같은 결과를 "고조파마다 줄어드는 비율이 다르다"는 주파수 영역의 말로 설명할 수 있을까요?

준비

±1 V, 1 kHz 구형파를 홀수 고조파 \(\frac{4}{n\pi}\sin(2\pi n f_0t)\)의 합으로 만들고(회색), 각 고조파에 RC 필터의 \(|H(nf_0)|\)와 \(\angle H(nf_0)\)를 적용해 더한 출력(파랑)을 그립니다(9.3절). 아래 막대그림은 고조파별 진폭입니다.

해 보기와 설명

  1. 부분합최고 차수를 1, 3, 15, 99로 늘리면 회색 입력이 구형파에 가까워지지만 모서리 옆의 약 9% 넘침(Gibbs 현상)은 사라지지 않습니다.
  2. 필터 출력차단 1 kHz에서 1차 고조파는 0.707배, 3차는 0.316배, 5차는 0.196배로 줄어(9.3절 예제 9.3.2) 출력이 둥근 삼각파 같은 모양이 됩니다.
  3. 차단 주파수를 올리면f_c를 30 kHz(log 4.5)로 올리면 15차(15 kHz)까지 거의 그대로 통과해 출력이 구형파에 가깝습니다. 100 Hz(log 2)로 낮추면 1차 고조파만 작게 남아 거의 사인파가 됩니다.
  4. 전력출력 줄의 평균 전력은 고조파별 전력의 합입니다. 입력은 차수를 늘릴수록 1 W(구형파의 실효값 1 V)에 다가갑니다.

연결과 적용

디지털 회로의 빠른 모서리는 높은 고조파를 많이 품고 있어 전자파 잡음의 원인이 됩니다. 반대로 구형파를 필터로 걸러 사인파를 만드는 것이 간단한 신호 발생기의 원리입니다. 이 생각은 신호및시스템(전전6)의 Fourier 해석으로 이어집니다.

흔한 오해

  • "필터는 신호의 모양을 바꾸지 않고 크기만 줄인다." 고조파마다 줄어드는 비율과 위상 지연이 달라서 모양이 바뀝니다. 모든 주파수에서 같은 비율이어야 모양이 유지됩니다.
