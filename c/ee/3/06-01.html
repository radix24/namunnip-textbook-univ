이 절에서 배울 것
  • 직렬·병렬 RLC 회로의 2계 미분방정식을 세운다.
  • 특성방정식의 근으로 과감쇠·임계감쇠·부족감쇠를 판정하고 자연 응답을 쓴다.
  • \(\alpha\), \(\omega_0\), \(\omega_d\), 감쇠비 \(\zeta\)의 뜻을 안다.
먼저 알아야 할 것
  • 축전기·인덕터와 연속성 (5.1절), 1차 회로 (5.2절).
  • 복소수와 오일러 공식 \(e^{j\theta} = \cos\theta + j\sin\theta\) (공통1 8.8절). 전기공학에서는 전류 \(i\)와 헷갈리지 않게 허수 단위를 \(j\)로 씁니다.
  • 이차방정식의 근의 공식 (고교 수학).

6.1.1방정식 세우기

축전기와 인덕터가 함께 있으면 에너지가 두 소자 사이를 오갈 수 있어, 1차 회로에 없던 진동이 생깁니다. 직렬 RLC 회로(전원 없음)에서 출발합시다. 고리를 도는 전류 \(i\)에 대해 KVL은

\[ Ri + L\frac{di}{dt} + v_C = 0, \qquad i = C\frac{dv_C}{dt}. \]

둘째 식을 첫째 식에 넣어 \(v_C\) 하나로 쓰면

\[ LC\frac{d^2v_C}{dt^2} + RC\frac{dv_C}{dt} + v_C = 0 \quad\Longleftrightarrow\quad \frac{d^2v_C}{dt^2} + 2\alpha\frac{dv_C}{dt} + \omega_0^2v_C = 0, \]

\(\alpha = \dfrac{R}{2L}\) (감쇠 계수), \(\omega_0 = \dfrac{1}{\sqrt{LC}}\) (공진 각주파수). 병렬 RLC(R, L, C가 같은 두 마디 사이)는 마디 전압 \(v\)에 KCL을 써서 같은 꼴을 얻고, 이때 \(\alpha = \dfrac{1}{2RC}\)입니다. 병렬에서는 R이 클수록 감쇠가 작습니다.

6.1.2특성방정식

1차 회로의 해가 지수였으니, \(v = Ae^{st}\)로 놓아 봅니다. 미분하면 \(s\)가 곱해지므로 \(Ae^{st}(s^2 + 2\alpha s + \omega_0^2) = 0\), 곧

\[ s^2 + 2\alpha s + \omega_0^2 = 0, \qquad s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}. \]

이를 특성방정식이라 합니다. 근이 두 개이면 \(A_1e^{s_1t} + A_2e^{s_2t}\)도 해이고(방정식이 선형이라 중첩), 두 상수는 초기 조건 둘(\(v_C(0)\)과 \(i_L(0)\), 곧 \(dv_C/dt(0)\))로 정합니다. 근호 안의 부호에 따라 세 경우로 나뉩니다. 감쇠비 \(\zeta = \alpha/\omega_0\)로 판정하면 편리합니다.

과감쇠 (\(\zeta > 1\)): 서로 다른 두 음의 실근. \(v = A_1e^{s_1t} + A_2e^{s_2t}\). 출렁임 없이 천천히 0으로.

임계감쇠 (\(\zeta = 1\)): 중근 \(s = -\alpha\). \(v = (A_1 + A_2t)e^{-\alpha t}\). 출렁임 없이 가장 빨리 0으로.

부족감쇠 (\(\zeta < 1\)): 켤레 복소근 \(s = -\alpha \pm j\omega_d\), \(\omega_d = \sqrt{\omega_0^2 - \alpha^2}\). \(v = e^{-\alpha t}(B_1\cos\omega_dt + B_2\sin\omega_dt)\). 줄어들며 진동.

부족감쇠의 해가 실수 함수로 바뀌는 과정: \(e^{(-\alpha + j\omega_d)t} = e^{-\alpha t}(\cos\omega_dt + j\sin\omega_dt)\)(오일러 공식). 두 켤레 근의 해를 더하고 빼면 \(e^{-\alpha t}\cos\omega_dt\)와 \(e^{-\alpha t}\sin\omega_dt\)가 나오므로, 이 둘의 일차결합으로 실수 해를 씁니다.

임계감쇠의 \(te^{-\alpha t}\)는 중근일 때 두 번째 독립 해가 필요해서 나옵니다. 대입하면 실제로 방정식을 만족합니다(연습문제).

예제 6.1.1

직렬 RLC, \(L = 10\) mH, \(C = 1\ \mu\text{F}\). \(R = 50\ \Omega\), 200 Ω, 400 Ω 각각에서 감쇠 유형과 근을 구하여라.

풀이. \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\) rad/s. \(\alpha = R/(2L) = 50R\).

  • \(R = 50\): \(\alpha = 2500\), \(\zeta = 0.25\), 부족감쇠, \(\omega_d = \sqrt{10^8 - 6.25\times10^6} \approx 9682\) rad/s. 근 \(-2500 \pm j9682\).
  • \(R = 200\): \(\alpha = 10^4 = \omega_0\), 임계감쇠, 중근 \(-10^4\).
  • \(R = 400\): \(\alpha = 2\times10^4\), \(\zeta = 2\), 과감쇠. 근 \(-2\times10^4 \pm \sqrt{4\times10^8 - 10^8} = -2678,\ -37321\).

임계 저항은 \(R = 2\sqrt{L/C} = 200\ \Omega\)입니다. 과감쇠에서 두 근 중 작은 쪽(−2678)이 응답을 지배해 오히려 임계감쇠보다 느리게 끝납니다.

6.1.3초기 조건으로 상수 정하기

예제 6.1.2

예제 6.1.1의 \(R = 50\ \Omega\) 회로에서 축전기가 \(v_C(0) = 10\) V, 인덕터 전류 \(i(0) = 0\)이다. \(v_C(t)\)를 구하여라.

풀이. \(v_C = e^{-2500t}(B_1\cos9682t + B_2\sin9682t)\). \(t = 0\): \(B_1 = 10\). 둘째 조건은 \(i = C\,dv_C/dt\)이므로 \(dv_C/dt(0) = i(0)/C = 0\). 미분해 \(t = 0\)을 넣으면 \(-2500B_1 + 9682B_2 = 0\), \(B_2 \approx 2.58\). 따라서

\[ v_C(t) = e^{-2500t}\big(10\cos9682t + 2.58\sin9682t\big)\ \text{V}. \]

진동 주기 \(2\pi/\omega_d \approx 0.65\) ms마다 진폭이 \(e^{-2500\times0.00065} \approx 0.20\)배로 줄어듭니다. 축전기와 인덕터가 에너지를 주고받는 동안 저항이 조금씩 열로 빼앗아 가는 모습입니다.

주의둘째 초기 조건을 "\(dv_C/dt(0) = 0\)이니까 아무 회로에서나 0"이라고 쓰면 틀립니다. \(dv_C/dt(0) = i_C(0^+)/C\)이고, \(i_C(0^+)\)는 0⁺ 회로(5.1절)를 풀어 구합니다. 연속인 것은 \(v_C\)와 \(i_L\)이지 그 도함수가 아닙니다.
요약
  1. RLC 회로: \(\ddot x + 2\alpha\dot x + \omega_0^2x = 0\). 직렬 \(\alpha = R/2L\), 병렬 \(\alpha = 1/2RC\), \(\omega_0 = 1/\sqrt{LC}\).
  2. \(\zeta = \alpha/\omega_0\): \(> 1\) 과감쇠(두 실근), \(= 1\) 임계(중근, \(te^{-\alpha t}\)), \(< 1\) 부족감쇠(\(e^{-\alpha t}\)와 \(\omega_d\) 진동).
  3. 상수는 \(x(0)\)과 \(\dot x(0)\)으로 정하고, \(\dot x(0)\)은 \(i_C(0^+)/C\) 또는 \(v_L(0^+)/L\)에서 구한다.

6.1.4연습문제

기본

  1. 병렬 RLC, \(R = 1\ \text{k}\Omega\), \(L = 0.1\) H, \(C = 0.1\ \mu\text{F}\)의 \(\alpha\), \(\omega_0\), 감쇠 유형은?
    답

    \(\alpha = 1/(2RC) = 5000\), \(\omega_0 = 1/\sqrt{10^{-8}} = 10^4\). \(\zeta = 0.5\), 부족감쇠.

응용

  1. \(x = te^{-\alpha t}\)가 \(\alpha = \omega_0\)일 때 \(\ddot x + 2\alpha\dot x + \alpha^2x = 0\)을 만족함을 대입으로 확인하여라.
    답

    \(\dot x = (1 - \alpha t)e^{-\alpha t}\), \(\ddot x = (-2\alpha + \alpha^2t)e^{-\alpha t}\). 더하면 \([-2\alpha + \alpha^2t + 2\alpha - 2\alpha^2t + \alpha^2t]e^{-\alpha t} = 0\).

심화

  1. 부족감쇠 직렬 RLC에서 \(R \to 0\)이면 응답은 어떻게 되는가? 에너지 관점에서 설명하여라.
    답

    \(\alpha \to 0\), \(\omega_d \to \omega_0\). 줄지 않는 진동 \(v_C = V_0\cos\omega_0t\). 에너지가 \(\frac12Cv^2\)과 \(\frac12Li^2\) 사이를 오가며 합이 일정(LC 진동, 공통4의 LC 회로).

6.1.2

탐구특성근이 움직이면 응답이 바뀐다

탐구 · s 평면과 감쇠 유형

다루는 성취기준 [전전3-06-01]

질문

직렬 RLC의 저항을 줄여 가면 특성방정식의 두 근은 복소평면(s 평면)에서 어떻게 움직이고, 그때 축전기 전압의 모양은 어떻게 바뀔까요?

준비

특성근 \(s = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}\)를 \(\omega_0\)로 나누어 그립니다. 그러면 근의 위치는 감쇠비 \(\zeta\)로만 정해집니다. 부족감쇠의 두 근은 반지름 \(\omega_0\)인 원 위에 있고, 실수부 \(-\alpha\)가 줄어드는 빠르기, 허수부 \(\omega_d\)가 진동의 빠르기입니다. 아래 그래프는 \(v_C(0) = 10\) V, \(i(0) = 0\)에서의 자연 응답(6.1절 예제 6.1.2)이고, 주황 점선은 포락선 \(e^{-\alpha t}\)입니다.

해 보기와 설명

  1. 부족감쇠처음 값(R ≈ 50 Ω)은 예제 6.1.2입니다. 두 근이 원 위 −0.25 ± j0.97(ω₀ 단위)에 있고 응답은 줄어들며 진동합니다.
  2. R을 키우면근이 원을 따라 실수축 쪽으로 내려오다가 R = 200 Ω(log 2.30)에서 −1에서 만납니다(임계감쇠). 더 키우면 실수축 위에서 하나는 원점 쪽, 하나는 왼쪽으로 갈라집니다(과감쇠). 원점 쪽 근 때문에 응답이 다시 느려집니다.
  3. R을 줄이면R → 1 Ω(log 0)이면 근이 거의 허수축(±j)에 붙어 진동이 오래 갑니다. R = 0이면 허수축 위에 놓여 줄지 않는 LC 진동이 됩니다.

연결과 적용

근이 왼쪽 반평면에 있으면 응답이 줄어 안정하고, 오른쪽으로 넘어가면 커져 불안정합니다. 수동 소자만으로는 근이 오른쪽으로 갈 수 없지만, 증폭기가 들어가면 갈 수 있습니다. 이 그림이 제어공학(전전22)의 근궤적과 신호및시스템(전전6)의 극점으로 이어집니다.

흔한 오해

  • "저항이 클수록 늘 빨리 끝난다." 과감쇠에서는 저항을 키울수록 원점 쪽 근이 0에 가까워져 오히려 느려집니다. 가장 빨리 출렁임 없이 끝나는 것은 임계감쇠입니다.
