  • 테브난 등가 (3.2절).
  • 몫의 미분법과 극대·극소 판정 (공통1 2단원, 고교 수학II·미적분).

3.3.1질문: 부하를 얼마로 하면 가장 많이 받나

안테나에서 들어온 약한 신호를 증폭기 입력에 최대한 많이 전달하고 싶습니다. 신호원은 테브난 등가 \(V_\text{Th}\), \(R_\text{Th}\)로 고정되어 있고, 우리가 고를 수 있는 것은 부하 \(R_L\)뿐입니다. 부하가 0이면 전류는 크지만 전압이 0이라 전력이 0, 부하가 무한대면 전압은 크지만 전류가 0이라 역시 0입니다. 그 사이 어딘가에 최대가 있습니다.

3.3.2정리와 증명

정리 3.3.1 (최대 전력 전달)

테브난 등가 \(V_\text{Th}\), \(R_\text{Th} > 0\)인 회로에 저항 부하 \(R_L \ge 0\)을 달 때, 부하 전력은 \(R_L = R_\text{Th}\)에서 최대이고 그 값은 \(P_\text{max} = \dfrac{V_\text{Th}^2}{4R_\text{Th}}\)이다.

증명.부하 전류는 \(i = \frac{V_\text{Th}}{R_\text{Th} + R_L}\)이므로 부하 전력은

\[ P(R_L) = i^2R_L = \frac{V_\text{Th}^2\,R_L}{(R_\text{Th} + R_L)^2}. \]

몫의 미분법으로 \(R_L\)에 대해 미분한다. 분자 \(V_\text{Th}^2R_L\)의 도함수는 \(V_\text{Th}^2\), 분모 \((R_\text{Th} + R_L)^2\)의 도함수는 \(2(R_\text{Th} + R_L)\)이므로

\[ P'(R_L) = V_\text{Th}^2\frac{(R_\text{Th} + R_L)^2 - 2R_L(R_\text{Th} + R_L)}{(R_\text{Th} + R_L)^4} = V_\text{Th}^2\frac{R_\text{Th} - R_L}{(R_\text{Th} + R_L)^3}. \]

분모는 늘 양수이므로 \(P'\)의 부호는 \(R_\text{Th} - R_L\)의 부호와 같다. 따라서 \(0 \le R_L < R_\text{Th}\)에서 \(P\)는 증가하고 \(R_L > R_\text{Th}\)에서 감소하므로 \(R_L = R_\text{Th}\)에서 최대이다. 대입하면 \(P = \frac{V_\text{Th}^2R_\text{Th}}{4R_\text{Th}^2} = \frac{V_\text{Th}^2}{4R_\text{Th}}\). ∎

가정 \(R_\text{Th} > 0\)을 어디서 썼는지 보세요. 증가·감소가 바뀌는 점이 \(R_L \ge 0\) 범위 안에 있으려면 \(R_\text{Th}\)가 양수여야 합니다. \(R_\text{Th} = 0\)(이상 전압원)이면 \(P = V^2/R_L\)이 \(R_L \to 0\)으로 끝없이 커져 최대가 없습니다.

3.3.3효율은 50%

정합(\(R_L = R_\text{Th}\))일 때 같은 전류가 \(R_\text{Th}\)와 \(R_L\)에 흐르므로 두 저항이 같은 전력을 씁니다. 등가 전원이 내는 전력의 절반만 부하로 갑니다. 효율 \(\eta = \frac{R_L}{R_\text{Th} + R_L}\)은 \(R_L\)이 클수록 1에 가까워지지만, 그때 부하 전력은 작아집니다.

최대 전력이 목표인 곳: 작은 신호를 다루는 통신·센서 회로. 신호 에너지가 귀하고, 버려지는 전력의 크기는 문제가 아니다. 안테나와 수신기를 50 Ω으로 정합하는 이유(전전19).

최대 효율이 목표인 곳: 전력 계통, 충전기, 전원 장치. 발전기 내부 저항을 부하에 맞추면 절반을 열로 버리게 된다. 내부 저항을 부하보다 훨씬 작게 만든다.

예제 3.3.2

3.2절 예제 3.2.2의 회로(\(V_\text{Th} = 18\) V, \(R_\text{Th} = 6\ \Omega\))에서 최대 전력과 그때의 원래 24 V 전원의 공급 전력을 구하여라.

풀이. \(R_L = 6\ \Omega\), \(P_\text{max} = 18^2/24 = 13.5\) W, 부하 전류 1.5 A. 원래 회로로 돌아가면 마디 a 전압은 \(1.5\times(3 + 6) = 13.5\) V이므로 24 V 원의 전류는 \((24 - 13.5)/4 = 2.625\) A, 공급 전력 63 W. 실제 효율은 \(13.5/63 \approx 21\%\)로, 테브난 등가에서 계산한 50%가 아닙니다.

이 예제가 보여 주는 것: 테브난 등가는 바깥에서 같을 뿐, 안에서 쓰이는 전력은 다릅니다(3.1절 전원 변환의 주의와 같은 이야기). 50%는 등가 회로 안의 효율입니다.

주의"\(R_\text{Th}\)를 줄이면 부하 전력이 커진다"는 맞지만, "\(R_\text{Th}\)를 \(R_L\)에 맞추면 부하 전력이 커진다"는 틀립니다. 정리는 부하를 고를 수 있을 때의 답입니다. 전원 쪽을 고를 수 있다면 \(R_\text{Th} = 0\)이 언제나 가장 좋습니다.
요약
  1. \(P = V_\text{Th}^2R_L/(R_\text{Th} + R_L)^2\)는 \(R_L = R_\text{Th}\)에서 최대 \(V_\text{Th}^2/(4R_\text{Th})\).
  2. 증명의 핵심: \(P'\)의 부호가 \(R_\text{Th} - R_L\)의 부호와 같다.
  3. 정합 효율은 등가 회로 기준 50%. 신호 회로는 최대 전력, 전력 회로는 최대 효율을 목표로 한다.

3.3.4연습문제

기본

  1. 내부 저항 8 Ω의 앰프 출력(개방 전압 진폭 16 V)에 스피커를 달 때 최대 전력이 되는 스피커 저항과 그 전력(진폭 기준 순간 최대)은?
    답

    8 Ω, \(16^2/32 = 8\) W.

응용

  1. \(R_L = 2R_\text{Th}\)와 \(R_L = R_\text{Th}/2\)일 때 부하 전력은 최대의 몇 %인가?
    답

    둘 다 \(4\cdot\frac{2}{9} = 88.9\%\). 정합에서 2배 벗어나도 11%만 줄어 최대 근처는 평평하다.

심화

  1. 부하 전력이 최대의 50% 이상이 되는 \(R_L/R_\text{Th}\)의 범위를 구하여라.
    힌트

    \(x = R_L/R_\text{Th}\)이면 \(P/P_\text{max} = 4x/(1 + x)^2\).

    답

    \(4x \ge \frac12(1 + x)^2\) → \(x^2 - 6x + 1 \le 0\) → \(3 - 2\sqrt2 \le x \le 3 + 2\sqrt2\), 약 0.17 ~ 5.83.

3.3.2

탐구최대 전력과 최대 효율은 같은 곳에 있지 않다

탐구 · 부하 저항 고르기

다루는 성취기준 [전전3-03-03]

질문

부하를 테브난 저항에 맞추면 전력은 가장 크게 받지만, 효율은 50%입니다. 효율을 90%로 올리려면 전력을 얼마나 포기해야 할까요?

준비

가로축은 \(x = R_L/R_\text{Th}\)의 로그입니다. 이렇게 두면 곡선 모양이 \(V_\text{Th}, R_\text{Th}\)와 상관없어집니다.

\[ \frac{P}{P_\text{max}} = \frac{4x}{(1 + x)^2}, \qquad \eta = \frac{x}{1 + x}. \]

해 보기와 설명

  1. 정합막대를 0에 두면 전력 100%, 효율 50%입니다.
  2. 효율 90%\(x = 9\)(막대 약 0.95)로 하면 효율 90%, 전력은 최대의 36%입니다. 효율 99%(\(x = 99\), 막대 2)면 전력은 약 4%만 남습니다.
  3. 평평한 꼭대기막대를 ±0.3(2배, 1/2배)으로 움직여도 전력은 약 89%로, 꼭대기 근처는 평평합니다. 정합을 완벽히 맞추지 않아도 손해가 크지 않습니다.

연결과 적용

교류 회로에서는 저항뿐 아니라 리액턴스도 있어, 최대 전력 조건이 \(Z_L = Z_\text{Th}^*\)(켤레 복소수)가 됩니다(8단원, 전전19 임피던스 정합). 전력 계통은 반대로 효율을 위해 발전기와 선로의 저항을 부하보다 훨씬 작게 만듭니다.

흔한 오해

  • "최대 전력 전달은 가장 효율적인 전달이다." 정합 효율은 50%입니다. 효율과 전력은 맞바꾸는 관계입니다.
