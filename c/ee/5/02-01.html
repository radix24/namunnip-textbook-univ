2.1.1파동함수와 Schrödinger 방정식

파동함수 ψ(x): 입자의 상태를 나타내는 함수. \(|\psi(x)|^2dx\)는 입자를 x 근처 dx에서 찾을 확률이고, 전체 확률이 1이 되도록 \(\int|\psi|^2dx = 1\)(규격화).

시간에 무관한 Schrödinger 방정식: 퍼텐셜 에너지 U(x) 안에서 에너지 E인 정상 상태가 만족하는 식.

\[ -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + U(x)\psi = E\psi. \]

왼쪽 첫 항은 운동 에너지(파동함수가 많이 휠수록, 곧 파장이 짧을수록 큼), 둘째 항은 위치 에너지입니다. 이 식과 경계 조건을 함께 만족하는 해는 특정한 E에서만 존재하고, 그래서 에너지가 띄엄띄엄(양자화)해집니다.

2.1.2무한 우물

구하려는 것: \(0 < x < L\)에서 U = 0, 밖에서 U = ∞인 우물의 E와 ψ. 밖에서는 ψ = 0이고, ψ는 연속이어야 하므로 \(\psi(0) = \psi(L) = 0\). 안에서는 \(\psi'' = -k^2\psi\) (\(k = \sqrt{2mE}/\hbar\))라 \(\psi = A\sin kx + B\cos kx\). \(\psi(0) = 0\)에서 B = 0, \(\psi(L) = 0\)에서 \(kL = n\pi\).

\[ E_n = \frac{\hbar^2\pi^2n^2}{2mL^2} = \frac{n^2h^2}{8mL^2}, \qquad \psi_n = \sqrt{\frac2L}\sin\frac{n\pi x}{L},\quad n = 1, 2, \dots \]

줄의 정상파(양 끝이 고정)와 같은 모양입니다. 가장 낮은 에너지 \(E_1\)도 0이 아닙니다(1.2절의 가둠 에너지).

예제 2.1.1

(가) 폭 1 nm, (나) 10 nm 우물에 갇힌 자유 전자의 \(E_1\), (다) GaAs 양자 우물(폭 10 nm, 유효 질량 \(0.067m_0\))의 \(E_1\)과 \(E_2 - E_1\) 전이 빛의 파장을 구하라(무한 우물 근사).

풀이. (가) \(E_1 = 0.376\) eV. (나) L이 10배라 1/100: 3.76 meV. (다) 질량이 0.067배라 \(E_1 = 3.76/0.067 \approx 56\) meV, \(E_2 - E_1 = 3E_1 \approx 168\) meV → 파장 \(1240/168 \approx 7.4\) μm(중적외선). 우물 폭을 바꿔 파장을 조절하는 양자 우물 레이저·적외선 검출기의 원리입니다. 실제 우물은 장벽이 유한해 준위가 조금 낮습니다(확인 필요: 정확한 값은 유한 우물 계산으로).

흔한 오해(1) "n = 0도 가능하다": ψ = 0이 되어 입자가 없는 상태입니다. (2) \(|\psi|^2\)가 아니라 ψ를 확률로 읽는 실수. (3) 우물 폭을 반으로 줄이면 에너지는 두 배가 아니라 네 배입니다(\(1/L^2\)).
요약
  1. \(-\frac{\hbar^2}{2m}\psi'' + U\psi = E\psi\), \(|\psi|^2\)는 확률 밀도.
  2. 무한 우물: \(E_n = n^2h^2/(8mL^2)\), \(\psi_n \propto \sin(n\pi x/L)\). 1 nm 전자 \(E_1 = 0.376\) eV.
  3. 반도체 양자 우물은 유효 질량으로 계산하고, 폭으로 빛의 파장을 조절한다.

2.1.3연습문제

기본

  1. 폭 2 nm 무한 우물 전자의 \(E_1\), \(E_2\), \(E_3\)는?
    답

    \(E_1 = 0.376/4 = 0.094\) eV, \(E_2 = 0.376\), \(E_3 = 0.846\) eV.

응용

  1. \(\psi_1\)에서 입자를 우물 왼쪽 1/4 구간(0 < x < L/4)에서 찾을 확률은?
    답

    \(\frac2L\int_0^{L/4}\sin^2\frac{\pi x}{L}dx = \frac14 - \frac{1}{2\pi} \approx 0.091\).

심화

  1. \(E_2 \to E_1\) 전이로 파장 1 μm 빛을 내려면 자유 전자 우물의 폭은?
    답

    \(3E_1 = 1.24\) eV → \(E_1 = 0.413\) eV → \(L = 1\text{ nm}\times\sqrt{0.376/0.413} \approx 0.95\) nm.

2.1.2

탐구무한 우물의 준위: 폭과 질량

탐구 · 작게 가둘수록 띄엄띄엄

다루는 성취기준 [전전5-02-01]

질문

우물 폭을 10배로 넓히면 준위 간격은 몇 배가 될까요? 가벼운 전자(GaAs)는 어떻게 다를까요?

준비

폭 L의 무한 우물에서 \(E_n = \dfrac{n^2h^2}{8m^*L^2} = \dfrac{0.376\,n^2}{(m^*/m_0)L^2}\) eV(L은 nm, 2.1절)입니다. 그래프는 네 준위의 높이와, 그 높이에 그린 확률 밀도 \(|\psi_n|^2\)입니다. 출력 줄에 \(E_2 - E_1\) 전이의 광자 파장과 실온 열에너지 비교를 적습니다.

해 보기와 설명

  1. 예제 확인처음 화면(L = 1 nm, 자유 전자): \(E_1 = 376\) meV, \(E_2 = 1504\) meV, \(E_2 - E_1 = 1128\) meV → 1.10 μm. 원자 크기 상자에서는 준위가 eV 단위입니다.
  2. 넓히기L = 10 nm이면 \(E_1 = 3.76\) meV로 1/100입니다. \(E_2 - E_1 = 11.3\) meV가 kT(25.9 meV)보다 작아 "열로 섞입니다"가 뜹니다.
  3. GaAsL = 10 nm, GaAs(0.067)이면 \(E_1 = 56.1\) meV, \(E_2 - E_1 = 168.4\) meV → 7.37 μm(예제 2.1.1). 가벼운 질량이 간격을 15배 키워 실온에서도 준위가 뚜렷합니다.
  4. 마디 세기n번째 곡선에 n − 1개의 마디(확률 0인 점)가 있습니다. 바닥 상태도 에너지가 0이 아닌 것(영점 에너지)은 가둔 대가입니다.

연결과 적용

양자 우물 레이저와 적외선 검출기(QWIP)는 우물 폭으로 파장을 고릅니다. 같은 원리가 3차원으로 가두는 양자점의 색(5.2절)과, 아주 얇은 채널의 트랜지스터에서 문턱 전압이 바뀌는 현상에 나타납니다. 실제 우물은 장벽이 유한해 준위가 이 값보다 조금 낮습니다(확인 필요).

흔한 오해

  • "준위 간격은 L에 반비례한다." \(L^2\)에 반비례합니다. 폭 2배면 간격 1/4입니다.
  • "바닥 상태의 전자는 우물 가운데에 멈춰 있다." 가운데에서 발견될 확률이 가장 클 뿐, 운동 에너지 \(E_1\)을 가지고 우물 전체에 퍼져 있습니다.
