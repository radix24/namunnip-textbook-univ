2.2.1

탐구어디서 출발해도 같은 분포로 간다

탐구 · 마르코프 연쇄의 정상분포

다루는 성취기준 [수학21-02-02]

질문

날씨가 맑음, 흐림, 비 세 상태를 하루하루 확률적으로 옮겨 다닌다고 합시다. 오늘이 맑음인지 비인지에 따라 100일 뒤의 날씨 확률이 달라질까요?

복원

전이행렬 \(P\)의 \((i, j)\) 성분은 상태 \(i\)에서 다음 단계에 \(j\)로 갈 확률이고, 행마다 합이 1입니다. 지금 분포가 행벡터 \(\pi_k\)이면 다음 분포는 \(\pi_{k+1} = \pi_k P\)입니다. \(\pi P = \pi\)인 분포를 정상분포라고 합니다.

한 행의 두 확률 합이 1을 넘으면 합이 1이 되도록 줄여서 씁니다. 남는 확률은 제자리에 머무를 확률입니다.

해 보기

  1. 출발 상태를 1, 2, 3으로 바꿔 보세요. 처음 몇 단계는 곡선이 다르지만 5~6단계면 세 경우 모두 같은 점선 값에 붙습니다.
  2. 3→1과 3→2를 모두 0으로 하면 상태 3에서 나갈 수 없습니다(흡수 상태). 어디서 출발해도 결국 상태 3의 확률이 1로 갑니다.
  3. 1→2 = 1, 2→3 = 1, 3→1 = 1로 하고 나머지를 0으로 하면 1→2→3→1로 도는 주기 3의 연쇄입니다. 분포가 수렴하지 않고 계속 돕니다. 하지만 긴 시간 평균은 (1/3, 1/3, 1/3)입니다.
  4. 1→3, 2→3, 3→1, 3→2를 모두 0으로 하면 {1, 2}와 {3}이 서로 오가지 못합니다. 이제 출발 상태에 따라 긴 시간 평균이 달라집니다(3에서 출발하면 (0, 0, 1)).

설명

  1. 극한 정리모든 상태가 서로 오갈 수 있고(기약), 돌아오는 단계 수에 공통 주기가 없으면(비주기), 정상분포 \(\pi\)가 하나뿐이고 출발과 상관없이 \(\pi_k \to \pi\)입니다.
  2. 조건이 깨질 때해 보기 3은 비주기가 깨진 경우(수렴하지 않음), 해 보기 4는 기약이 깨진 경우(정상분포가 여러 개)입니다.
  3. 긴 시간 평균\(\frac1n\sum_{k<n}\pi_k\)는 주기가 있어도 수렴하고, 그 극한은 정상분포입니다. 상태 \(i\)의 정상확률은 "오래 지켜볼 때 \(i\)에 머무는 시간의 비율"입니다.

연결

정상분포는 \(P^{\mathsf T}\)의 고유값 1에 대한 고유벡터입니다(수학1 6단원). 수렴 속도는 둘째로 큰 고유값의 절댓값이 정합니다. 웹 페이지 순위를 매기는 페이지랭크와 MCMC 표본 추출이 이 정리를 씁니다.

판단

"정상분포에 도달하면 연쇄가 한 상태에 멈춘다"는 틀립니다. 정상이 되는 것은 확률 분포이지 상태가 아닙니다. 연쇄는 계속 상태를 옮겨 다니고, 각 상태에 있을 확률만 더 이상 변하지 않습니다.
