3.2.1함수의 정의

정의 3.2.1 (함수, 상, 역상)

함수 \(f: X \to Y\): \(X\times Y\)의 부분집합 \(f\)로, 모든 \(x \in X\)에 대해 \((x, y) \in f\)인 \(y\)가 정확히 하나 있는 것. 그 \(y\)를 \(f(x)\)로 쓴다.

상: \(S \subseteq X\)에 대해 \(f(S) = \{f(x) : x \in S\}\).

역상: \(T \subseteq Y\)에 대해 \(f^{-1}(T) = \{x \in X : f(x) \in T\}\).

역상 \(f^{-1}(T)\)는 \(f\)가 역함수를 갖지 않아도 늘 정의됩니다. 예: \(f(x) = x^2\)이면 \(f^{-1}([1, 4]) = [-2, -1] \cup [1, 2]\), \(f^{-1}(\{-1\}) = \varnothing\). 상은 "보내 본 결과", 역상은 "그곳으로 오는 출발점 전체"입니다.

3.2.2무엇이 보존되는가

정리 3.2.2 (역상)

\(f^{-1}\left(\bigcup T_i\right) = \bigcup f^{-1}(T_i)\), \(f^{-1}\left(\bigcap T_i\right) = \bigcap f^{-1}(T_i)\), \(f^{-1}(Y \setminus T) = X \setminus f^{-1}(T)\).

증명.세 번째: \(x \in f^{-1}(Y\setminus T) \iff f(x) \notin T \iff x \notin f^{-1}(T)\). 나머지는 2.2절 연습 3. ∎

정리 3.2.3 (상)

\(f\left(\bigcup S_i\right) = \bigcup f(S_i)\)이지만 \(f\left(\bigcap S_i\right) \subseteq \bigcap f(S_i)\)이고 등호는 일반적으로 성립하지 않는다. \(f\)가 단사이면 등호가 성립한다.

증명.합: \(y \in f(\bigcup S_i) \iff \exists x\,(x \in \bigcup S_i \wedge f(x) = y) \iff \exists i\,\exists x \in S_i\,(f(x) = y) \iff y \in \bigcup f(S_i)\). 교의 포함: \(y = f(x)\), \(x\)가 모든 \(S_i\)에 있으면 \(y\)는 모든 \(f(S_i)\)에 있다. 반례: \(f(x) = x^2\), \(S_1 = \{-1\}\), \(S_2 = \{1\}\)이면 \(f(S_1 \cap S_2) = \varnothing\)인데 \(f(S_1) \cap f(S_2) = \{1\}\). 단사이면 \(y \in \bigcap f(S_i)\)의 원상이 각 \(S_i\)에서 같은 \(x\)라 \(x \in \bigcap S_i\). ∎

차이의 원인은 한정기호입니다. 상의 정의에는 \(\exists x\)가 있고, \(\exists\)는 \(\vee\)(합)와는 교환되지만 \(\wedge\)(교)와는 교환되지 않습니다. 각 \(S_i\)에서 서로 다른 \(x\)가 같은 \(y\)로 갈 수 있기 때문입니다. 역상에는 한정기호가 없어 모든 연산과 잘 맞습니다. 위상수학에서 연속을 "열린집합의 역상이 열린집합"으로 정의하는 이유이기도 합니다.

3.2.3보냈다 되돌리기

정리 3.2.4

(a) \(S \subseteq f^{-1}(f(S))\), 단사이면 등호. (b) \(f(f^{-1}(T)) \subseteq T\), 전사이면 등호(일반적으로 \(f(f^{-1}(T)) = T \cap f(X)\)).

증명.(a) \(x \in S\)이면 \(f(x) \in f(S)\)라 \(x \in f^{-1}(f(S))\). 단사이면 \(f(x') \in f(S)\), 곧 \(f(x') = f(x)\) (\(x \in S\))에서 \(x' = x \in S\). (b) \(y = f(x)\), \(f(x) \in T\)이면 \(y \in T\). 전사이면 \(y \in T\)의 원상 \(x\)가 있어 \(x \in f^{-1}(T)\), \(y = f(x)\). ∎

예제 3.2.5

\(f(x) = x^2\) (\(\mathbb R \to \mathbb R\))에서 \(f^{-1}(f([0, 1]))\)과 \(f(f^{-1}([-1, 4]))\)를 구하여라.

풀이. \(f([0, 1]) = [0, 1]\), \(f^{-1}([0, 1]) = [-1, 1] \supsetneq [0, 1]\) (단사가 아니라서 커짐). \(f^{-1}([-1, 4]) = [-2, 2]\), \(f([-2, 2]) = [0, 4] \subsetneq [-1, 4]\) (전사가 아니라서 작아짐).

흔한 실수(1) \(f^{-1}(T)\)를 쓰려면 역함수가 있어야 한다고 생각한다: 역상은 늘 있다. (2) \(f(A \cap B) = f(A) \cap f(B)\)를 당연히 쓴다: 단사일 때만 맞다. (3) \(f^{-1}(f(S)) = S\)로 약분한다: 단사가 아니면 더 크다.
요약
  1. 역상은 합·교·여집합을 모두 보존한다.
  2. 상은 합만 보존하고, 교는 \(\subseteq\)만(단사이면 등호).
  3. \(S \subseteq f^{-1}f(S)\) (단사이면 =), \(ff^{-1}(T) \subseteq T\) (전사이면 =).

3.2.4연습문제

기본

  1. \(f(x) = \sin x\)에 대해 \(f^{-1}(\{0\})\)과 \(f([0, \pi])\)를 구하여라.
    답

    \(\{n\pi : n \in \mathbb Z\}\)와 \([0, 1]\).

응용

  1. \(f(A \setminus B) \supseteq f(A) \setminus f(B)\)임을 보이고 등호가 성립하지 않는 예를 들어라.
    답

    \(y = f(a)\), \(a \in A\), \(y \notin f(B)\)이면 \(a \notin B\). 반례: \(f(x) = x^2\), \(A = \{-1\}\), \(B = \{1\}\): 왼쪽 \(\{1\}\), 오른쪽 \(\varnothing\).

심화

  1. \(f\)가 단사 \(\iff\) 모든 \(A, B\)에서 \(f(A \cap B) = f(A) \cap f(B)\)임을 보여라.
    답

    (⇐) \(f(a) = f(b)\)이면 \(A = \{a\}\), \(B = \{b\}\)에서 오른쪽이 공집합이 아니라 \(\{a\}\cap\{b\} \ne \varnothing\), \(a = b\).

3.2.2

예제역상은 정직하고 상은 겹친다

예제 · 상과 역상의 성질

다루는 성취기준 [수학2-03-02]

먼저 예측

\(f(x) = |x|\)에 대해 \(A = [-2, 1]\), \(B = [-1, 2]\)일 때 \(f(A \cap B)\)와 \(f(A) \cap f(B)\)는 같을까요? 또 \(f(A \setminus B)\)와 \(f(A) \setminus f(B)\)는?

예측 확인

둘 다 다릅니다. 앞의 것은 \([0, 1]\)과 \([0, 2]\), 뒤의 것은 \((1, 2]\)와 \(\varnothing\)입니다.

\(f(x) = |x|\) (\(\mathbb R \to \mathbb R\)), \(A = [-2, 1]\), \(B = [-1, 2]\)에 대해 (a) \(f(A \cap B)\), \(f(A) \cap f(B)\) (b) \(f(A \setminus B)\), \(f(A) \setminus f(B)\) (c) \(f^{-1}(f(A))\)를 구하고 정리 3.2.3, 3.2.4와 비교하여라.

전략

상은 구간의 각 점을 \(|x|\)로 보낸 범위를, 역상은 "\(|x|\)가 그 범위에 드는 \(x\) 전체"를 구합니다(3.2절). \(f\)는 \(x\)와 \(-x\)를 같은 곳으로 보내 단사가 아니므로 차이가 생길 것입니다.

풀이

  1. \(A \cap B = [-1, 1]\)이라 \(f(A \cap B) = [0, 1]\).
    \(|x|\)는 \([-1, 1]\)에서 0부터 1까지.
  2. \(f(A) = [0, 2]\), \(f(B) = [0, 2]\)이라 \(f(A) \cap f(B) = [0, 2] \supsetneq [0, 1]\).
    \(f(A)\)는 \(x = -2\) 덕분에, \(f(B)\)는 \(x = 2\) 덕분에 2까지 닿는다. 서로 다른 \(x\)가 같은 값을 만든다.
  3. \(A \setminus B = [-2, -1)\), \(f(A \setminus B) = (1, 2]\). \(f(A) \setminus f(B) = \varnothing\).
    \(f(A) = f(B)\)라 차가 비었다. \(f(A\setminus B) \supseteq f(A)\setminus f(B)\)만 성립(3.2절 연습 2).
  4. \(f^{-1}(f(A)) = f^{-1}([0, 2]) = [-2, 2] \supsetneq A\).
    \(|x| \le 2\)인 \(x\) 전체. \(A\)에 없던 \((1, 2]\)가 끌려 들어왔다.
  5. 세 경우 모두 등호가 깨진 원인은 \(f\)가 단사가 아니라는 것 하나다.
    정리 3.2.3, 3.2.4의 등호 조건.

검산

(a)의 차이는 원소 하나(\(y = 2\))로 확인됩니다: \(2 \in f(A) \cap f(B)\)이지만 \(2 = |x|\)인 \(x = \pm2\)는 \(A \cap B = [-1, 1]\)에 없습니다. 단사인 \(g(x) = x^3\)으로 바꾸면 (a), (b), (c) 모두 등호가 성립합니다.

의미

역상은 합·교·차를 모두 보존하므로 "조건을 만족하는 \(x\)의 집합"을 계산할 때 안심하고 쪼갤 수 있습니다: \(f^{-1}(T_1 \cap T_2) = f^{-1}(T_1) \cap f^{-1}(T_2)\). 상은 그렇지 않으므로 상을 쪼갤 때는 단사인지 먼저 확인해야 합니다.

이해 확인

같은 \(f\)에서 \(f^{-1}([1, 4] \cap [3, 9])\)를 두 가지 방법(먼저 교집합, 먼저 역상)으로 구해 같은지 확인하여라.

답

\(f^{-1}([3, 4]) = [-4, -3] \cup [3, 4]\). 역상 먼저: \(([-4,-1]\cup[1,4]) \cap ([-9,-3]\cup[3,9]) = [-4,-3]\cup[3,4]\). 같다.
