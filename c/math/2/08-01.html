8.1.1페아노 공리

공리 8.1.1 (페아노)

집합 \(\mathbb N\), 원소 \(0\), 함수 \(S: \mathbb N \to \mathbb N\)이 다음을 만족한다.

(P1) \(0\)은 어떤 수의 후속도 아니다. (P2) \(S\)는 단사이다. (P3) \(0\)을 포함하고 \(S\)에 닫힌 부분집합은 \(\mathbb N\) 전체이다(귀납 공리).

7.3절의 \(\omega\)가 이 공리를 만족합니다. 덧셈과 곱셈을 재귀로 정의하면 교환·결합·분배법칙, 소거법칙(\(a + c = b + c \Rightarrow a = b\)), 순서의 성질이 모두 귀납법으로 증명됩니다. 문제는 \(\mathbb N\)에서 \(3 - 5\)나 \(3 \div 5\)를 할 수 없다는 것입니다.

8.1.2정수: 빼기의 결과를 미리 만들기

"\(a - b\)"를 아직 수로 쓸 수 없으니 쌍 \((a, b)\)로 기록해 둡니다. 그런데 \(5 - 3\)과 \(7 - 5\)는 같은 수여야 합니다. \(a - b = c - d\)를 빼기 없이 쓰면 \(a + d = b + c\)입니다.

정의 8.1.2 (정수)

\(\mathbb N\times\mathbb N\)에서 \((a, b) \sim (c, d) \iff a + d = b + c\). 동치류 \([(a, b)]\) 전체를 \(\mathbb Z\)라 한다. 연산은 \([(a, b)] + [(c, d)] = [(a + c, b + d)]\), \([(a, b)]\cdot[(c, d)] = [(ac + bd, ad + bc)]\).

곱셈 공식은 \((a - b)(c - d) = (ac + bd) - (ad + bc)\)에서 왔습니다. \(\mathbb N\)의 \(n\)은 \([(n, 0)]\)으로, 음수 \(-n\)은 \([(0, n)]\)으로 들어갑니다.

정리 8.1.3

\(\sim\)는 동치관계이고, 덧셈은 대표원에 무관하게 잘 정의된다.

증명.(추이) \(a + d = b + c\), \(c + f = d + e\)를 더하면 \(a + d + c + f = b + c + d + e\)이고, \(\mathbb N\)의 소거법칙으로 \(c + d\)를 지우면 \(a + f = b + e\). (잘 정의됨) \((a, b) \sim (a', b')\), \((c, d) \sim (c', d')\)이면 \(a + b' = b + a'\), \(c + d' = d + c'\). 더하면 \((a + c) + (b' + d') = (b + d) + (a' + c')\), 곧 \((a + c, b + d) \sim (a' + c', b' + d')\). ∎

8.1.3유리수: 나누기의 결과를 미리 만들기

정의 8.1.4 (유리수)

\(\mathbb Z\times(\mathbb Z\setminus\{0\})\)에서 \((a, b) \sim (c, d) \iff ad = bc\). 동치류 \([(a, b)]\)를 \(\frac ab\)로 쓰고 전체를 \(\mathbb Q\)라 한다. \(\frac ab + \frac cd = \frac{ad + bc}{bd}\), \(\frac ab\cdot\frac cd = \frac{ac}{bd}\).

정리 8.1.5

\(\mathbb Q\)의 덧셈과 곱셈은 잘 정의되고, \(\mathbb Q\)는 체이다.

증명.(덧셈) \(ab' = a'b\), \(cd' = c'd\)라 하자. 보일 것: \((ad + bc)b'd' = (a'd' + b'c')bd\). 왼쪽 \(= ab'dd' + bb'cd' = a'bdd' + bb'c'd\) (가정 대입) \(= (a'd' + b'c')bd\). (곱셈) \(acb'd' = a'bc'd\)는 두 가정을 곱한 것. (체) \(\frac ab \ne 0\)이면 \(a \ne 0\)이고 \(\frac ba\)가 역원: \(\frac ab\cdot\frac ba = \frac{ab}{ab} = \frac11\). ∎

"잘 정의됨"이 핵심입니다. \(\frac12 = \frac24\)이므로 \(\frac12 + \frac13\)과 \(\frac24 + \frac13\)의 결과가 같아야 합니다: \(\frac56\)과 \(\frac{10}{12}\)은 \(5\cdot12 = 6\cdot10\)으로 같은 동치류입니다. 같은 절의 탐구 카드에서 동치류가 격자의 직선으로 보이는 모습을 볼 수 있습니다.

흔한 실수(1) 동치류 대신 "기약분수"로 유리수를 정의하고 연산 결과를 약분하지 않는다: 기약분수끼리 더해도 기약이 아닐 수 있다(\(\frac16 + \frac13 = \frac36\)). 동치류로 정의하면 이 문제가 없다. (2) \(\frac ab + \frac cd = \frac{a + c}{b + d}\)로 정의한다: 잘 정의되지 않는다. \(\frac12 + \frac11 = \frac23\)이지만 \(\frac24 + \frac11 = \frac35\)이다.
요약
  1. 페아노 공리(0, 단사 후속, 귀납)에서 자연수의 산술이 나온다.
  2. \(\mathbb Z = (\mathbb N\times\mathbb N)/(a + d = b + c)\): 빼기의 형식적 결과.
  3. \(\mathbb Q = (\mathbb Z\times\mathbb Z^*)/(ad = bc)\): 나누기의 형식적 결과. 연산은 대표원에 무관하게 잘 정의된다.

8.1.4연습문제

기본

  1. 정수의 정의로 \([(2, 5)] + [(4, 1)]\)과 \([(2, 5)]\cdot[(4, 1)]\)을 계산하고 보통의 정수로 확인하여라.
    답

    \([(6, 6)] = 0\) (\(-3 + 3\)). \([(8 + 5, 2 + 20)] = [(13, 22)] = -9\) (\(-3\cdot3\)).

응용

  1. 정수의 곱셈이 잘 정의됨을 보여라.
    답

    한 인수씩 바꾸면 충분. \((a, b) \sim (a', b')\)이면 \((ac + bd) + (a'd + b'c) = (ad + bc) + (a'c + b'd)\)를 보이면 된다. 좌변 \(-\) 우변 \(= c(a + b' - b - a') - d(a + b' - b - a') = 0\) (\(\mathbb N\)에서는 양변에 같은 것을 더해 정리).

심화

  1. \(\mathbb Z\)에서 \([(a, b)] \le [(c, d)] \iff a + d \le b + c\)가 잘 정의된 전순서임을 보여라.
    답

    \((a, b) \sim (a', b')\)이면 \(a + d \le b + c \iff a' + d \le b' + c\) (\(a + d \le b + c\)의 양변에 \(b'\)을 더하고 \(a + b' = b + a'\)를 쓰면 \(b + a' + d \le b + b' + c\), \(b\)를 소거). 전순서는 \(\mathbb N\)의 전순서에서.

이 절의 성취기준[수학2-08-01] 증명 서울대

  1. 자연수의 순서쌍에 동치관계를 주어 정수를, 정수의 순서쌍으로 유리수를 만들 수 있다.

8.1.2

탐구수 하나는 직선 하나다

탐구 · 순서쌍의 동치류로 만든 정수와 유리수

다루는 성취기준 [수학2-08-01]

질문

정수 \(-2\)를 "자연수 쌍 \((a, b)\) 중 \(a - b = -2\)인 것 전체"로, 유리수 \(\frac23\)을 "정수 쌍 \((a, b)\) 중 \(\frac ab = \frac23\)인 것 전체"로 정의하면, 이 동치류들은 평면에서 어떤 모양일까요?

복원

정수: \((a, b) \sim (c, d) \iff a + d = b + c\). 유리수: \((a, b) \sim (c, d) \iff ad = bc\) (\(b, d \ne 0\)). 수는 동치류다 (8.1절).

해 보기

  1. 처음 화면 \(\frac23\)의 동치류는 \((3, 2)\), \((6, 4)\)로, 분모 8 이하에서는 두 점입니다(가로축이 분모). 원점을 지나는 기울기 \(\frac23\) 직선 위에 있습니다. \(p = 4\), \(q = 6\)으로 바꿔도 같은 직선입니다.
  2. \(p\)를 음수로 바꾸면 직선이 아래로 기웁니다. \(\frac{-2}{3}\)과 \(\frac{2}{-3}\)이 같은 수인 것은 \((a, b)\)와 \((-a, -b)\)가 같은 직선 위에 있기 때문입니다(여기서는 분모를 양수로만 그립니다).
  3. "정수 p"로 바꾸고 \(p = -2\)로 두면 \((0, 2), (1, 3), (2, 4), \dots\)이 기울기 1인 직선을 이룹니다. 모두 "\(0 - 2\)", "\(1 - 3\)"처럼 결과가 \(-2\)인 빼기입니다.
  4. \(p = 0\)이면 두 경우 모두 동치류가 축이나 대각선이 됩니다. 각각 0이라는 수입니다.

설명

  1. 직선 = 같은 값유리수의 조건 \(ad = bc\)는 \((a, b)\)와 \((c, d)\)가 원점에서 같은 방향에 있다는 것, 곧 같은 직선 위에 있다는 뜻입니다. 정수의 조건 \(a - b = c - d\)는 같은 대각선 위에 있다는 뜻입니다.
  2. 연산이 잘 정의되는 이유더하기는 "직선 위의 아무 점 두 개를 골라 정해진 식으로 새 점을 만드는 것"인데, 어느 점을 골라도 결과 점이 같은 직선 위에 떨어진다는 것이 정리 8.1.3, 8.1.5입니다.

판단

"유리수 \(\frac23\)은 순서쌍 \((2, 3)\)이다"는 정확하지 않습니다. \((2, 3)\)은 \(\frac23\)의 대표원 하나일 뿐이고, 수 \(\frac23\)은 직선 위의 모든 쌍의 모임(동치류)입니다. 그래서 \(\frac23 = \frac46\)이 정의상 참입니다.
