8.R.1

연습수의 체계 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학2-08-01] [수학2-08-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산정수의 정의로 \([(1, 4)]\cdot[(0, 2)]\)을 계산하고 보통의 정수로 확인하여라. [08-01]

    힌트 1

    \([(a,b)][(c,d)] = [(ac + bd, ad + bc)]\)(8.1절).

    힌트 2

    \((1,4) = -3\), \((0,2) = -2\).

    풀이

    \([(0 + 8, 2 + 0)] = [(8, 2)] = 6\). \((-3)(-2) = 6\). 음수 곱하기 음수가 양수인 것이 정의에서 자동으로 나온다.

  2. 증명유리수의 동치관계 \(ad = bc\)가 추이적임을 보여라. [08-01]

    힌트 1

    \(ad = bc\), \(cf = de\) (\(b, d, f \ne 0\))에서 \(af = be\).

    힌트 2

    곱해서 \(d\)로 소거, \(c = 0\)인 경우 따로.

    풀이

    두 식을 곱하면 \(adcf = bcde\). \(c \ne 0\)이면 \(cd \ne 0\)으로 소거해 \(af = be\). \(c = 0\)이면 \(ad = 0\)에서 \(a = 0\), \(de = 0\)에서 \(e = 0\)이라 \(af = 0 = be\). ∎ (\(\mathbb Z\)가 정역이라 소거가 된다.)

  3. 판단"\(\frac ab \oplus \frac cd = \frac{a + c}{b + d}\)"를 유리수 덧셈으로 정의할 수 없는 이유를 반례로 보여라. [08-01]

    힌트 1

    같은 수의 다른 대표원으로 계산해 보세요.

    힌트 2

    \(\frac11 = \frac22\).

    풀이

    \(\frac12 = \frac24\)인데 \(\frac12 \oplus \frac11 = \frac23\), \(\frac24 \oplus \frac11 = \frac35\)로 다르다. 대표원에 따라 결과가 달라 잘 정의되지 않는다.

  4. 개념다음 중 데데킨트 절단은? (a) \(\{q : q < 0\}\) (b) \(\{q : q^3 < 2\}\) (c) \(\{q : q^2 < 4\}\) (d) \(q < 1\)이고 \(q \ne 0\)인 유리수 전체 [08-02]

    힌트 1

    아래로 닫혔는지, 최대가 없는지(8.2절).

    힌트 2

    (c)에서 \(-3\)은?

    풀이

    (a) 절단(\(0^*\)). (b) 절단(\(q^3\)이 증가함수라 아래로 닫힘, 최대 없음): \(\sqrt[3]2\). (c) 아님(\(-3 \notin\), 아래로 닫히지 않음). (d) 아님(\(-1\)과 \(\frac12\) 사이의 0이 빠져 아래로 닫히지 않음).

  5. 증명절단 \(\alpha, \beta\)에 대해 \(\alpha + \beta\)가 아래로 닫혀 있음을 보여라. [08-02]

    힌트 1

    \(r < p + q\)이면 \(r = (r - q) + q\).

    힌트 2

    \(r - q < p\)라 \(r - q \in \alpha\).

    풀이

    \(r < p + q\) (\(p \in \alpha\), \(q \in \beta\))이면 \(r - q < p\)이고 \(\alpha\)가 아래로 닫혀 \(r - q \in \alpha\). 따라서 \(r = (r - q) + q \in \alpha + \beta\). ∎

  6. 판단한 학생이 "실수의 완비성은 공리이므로 증명할 수 없다"고 썼다. 맞는가? [08-02]

    힌트 1

    해석학에서는 공리로 받아들였습니다(수학7 1.1절).

    힌트 2

    절단으로 실수를 만들면?

    풀이

    관점에 따라 다르다. 실수를 "완비 순서체"로 공리적으로 정의하면 완비성은 공리다. 그러나 유리수에서 절단으로 실수를 만들면 완비성은 정리 8.2.3이다(상한 = 합집합). 구성은 그런 공리를 만족하는 대상이 존재함을 보여 준다.
