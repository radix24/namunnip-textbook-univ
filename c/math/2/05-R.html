5.R.1

연습순서와 순서수 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학2-05-01] [수학2-05-02] [수학2-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념다음 중 정렬순서는? (a) 음이 아닌 유리수, 보통 순서 (b) \(\{-\frac1n : n \ge 1\}\), 보통 순서 (c) \(\{n - \frac1k : n, k \ge 1\}\), 보통 순서 [05-01]

    힌트 1

    최소 원소가 없는 부분집합을 찾으세요(5.1절).

    힌트 2

    (b)는 \(-1 < -\frac12 < \cdots\)?

    풀이

    (a) 아님(양의 유리수에 최소 없음). (b) 정렬순서: \(-1 < -\frac12 < -\frac13 < \cdots\), 순서형 \(\omega\). (c) 정렬순서: 각 \(n\) 아래로 \(n - 1, n - \frac12, \dots\)이 모여 \(\omega\)개 블록이 \(\omega\)번, 순서형 \(\omega^2\).

  2. 증명초한귀납법으로 "\(\omega\cdot2\) 모양 순서의 모든 원소는 앞에 많아야 가산개의 원소를 가진다"를 보여라. [05-01]

    힌트 1

    \(\operatorname{seg}(a) = \bigcup_{x < a}(\operatorname{seg}(x) \cup \{x\})\).

    힌트 2

    가산개의 가산집합의 합은 가산(4.1절).

    풀이

    앞의 모든 \(x\)에서 \(\operatorname{seg}(x)\)가 가산이라 하자. 전체 집합이 가산이라 \(x < a\)인 \(x\)는 가산개이고, 힌트 1의 합은 가산개의 가산집합의 합이라 가산. ∎

  3. 계산순서수 \(\{0, 1, 2, \dots\} \cup \{\omega\}\)를 \(\omega\)와 \(\cup\)로 쓰고, 그 원소 수(기수)를 말하여라. [05-02]

    힌트 1

    후속 \(\alpha + 1 = \alpha\cup\{\alpha\}\)(5.2절).

    힌트 2

    가산집합에 한 원소를 더하면?

    풀이

    \(\omega \cup \{\omega\} = \omega + 1\). 기수 \(\aleph_0\).

  4. 계산\(\omega\cdot a + b\) 꼴로 쓰라. (a) \(\omega + 2 + \omega\) (b) \(5 + \omega + 5\) (c) \((\omega + 2) + (\omega + 3) + 4\) [05-03]

    힌트 1

    \(b + \omega = \omega\)(5.3절).

    힌트 2

    결합법칙으로 괄호를 옮기세요.

    풀이

    (a) \(\omega\cdot2\). (b) \(\omega + 5\). (c) \(\omega\cdot2 + 7\).

  5. 증명\(n\)이 양의 자연수이면 \(n\cdot\omega = \omega\)임을 보여라. [05-03]

    힌트 1

    \(n\cdot\omega\)는 길이 \(n\) 묶음을 \(\omega\)번.

    힌트 2

    \((k, i)\) (\(k\)번째 묶음의 \(i\)번째)를 \(nk + i\)로.

    풀이

    \(\omega\times n\)의 사전식 순서에서 \((k, i) \mapsto nk + i\) (\(0 \le i < n\))는 \(\mathbb N\)으로 가는 순서동형(나눗셈 정리로 전단사, 사전식 순서가 크기 순서와 일치). ∎

  6. 판단한 학생이 "\(\omega + 1\)과 \(1 + \omega\)는 원소 수가 같으므로 같은 순서수"라고 썼다. 맞는가? [05-02, 05-03]

    힌트 1

    순서수가 같다는 것은 순서동형이라는 뜻입니다.

    힌트 2

    최대 원소를 보세요.

    풀이

    틀렸다. 원소 수(기수)는 둘 다 \(\aleph_0\)로 같지만, \(\omega + 1\)에는 최대 원소가 있고 \(1 + \omega = \omega\)에는 없어 순서동형이 아니다. 기수가 같다고 순서수가 같지는 않다.
