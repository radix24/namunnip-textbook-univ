7.R.1

연습역설과 공리적 집합론 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학2-07-01] [수학2-07-02] [수학2-07-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념분리 공리 \(\{x \in A : P(x)\}\)가 무제한 내포 \(\{x : P(x)\}\)와 다른 점과, 그 차이가 러셀의 역설을 막는 이유를 쓰라. [07-01]

    힌트 1

    바탕 집합 \(A\)가 있느냐(7.1절).

    힌트 2

    \(R_A \in A\)라고 가정하면?

    풀이

    분리는 이미 있는 \(A\) 안에서만 고른다. 그래서 \(R_A = \{x \in A : x \notin x\}\)에서 모순 대신 "\(R_A \notin A\)"라는 결론이 나온다. 무제한 내포는 \(R\)이 모든 것 중에서 골라져 "\(R\)이 바탕 집합 밖에 있다"는 탈출구가 없다.

  2. 증명모든 집합 \(A\)에 대해 \(A\)에 속하지 않는 집합이 있음을 보여라. [07-01]

    힌트 1

    \(R_A\)를 쓰세요.

    힌트 2

    정리 7.1.4.

    풀이

    \(R_A = \{x \in A : x \notin x\}\)는 분리로 집합이고 \(R_A \notin A\). ∎

  3. 개념다음 각 구성에 필요한 공리를 말하여라. (a) \(\mathcal P(A)\setminus\{\varnothing\}\) (b) \(A \cup \{A\}\) (c) \(\{(a, a) : a \in A\}\) [07-02]

    힌트 1

    바탕 집합을 먼저 만들고 분리(7.2절).

    힌트 2

    (c)는 \(A\times A\) 안에서.

    풀이

    (a) 멱집합 + 분리. (b) 짝(\(\{A\}\), \(\{A, \{A\}\}\)) + 합집합. (c) 짝·합집합·멱집합으로 \(A\times A\), 분리로 대각선.

  4. 계산폰 노이만 자연수에서 \(4 \cap 2\), \(4 \setminus 2\), \(\bigcup 4\)를 구하여라. [07-03]

    힌트 1

    \(n = \{0, \dots, n-1\}\)(7.3절).

    힌트 2

    \(\bigcup n = n - 1\) (\(n \ge 1\)).

    풀이

    \(4 \cap 2 = 2\), \(4 \setminus 2 = \{2, 3\}\), \(\bigcup 4 = 0 \cup 1 \cup 2 \cup 3 = 3\).

  5. 증명재귀 정의 \(m + 0 = m\), \(m + S(n) = S(m + n)\)으로 \(0 + n = n\)을 귀납법으로 보여라. [07-03]

    힌트 1

    \(n = 0\)부터.

    힌트 2

    \(0 + S(n) = S(0 + n)\).

    풀이

    \(0 + 0 = 0\). \(0 + n = n\)이면 \(0 + S(n) = S(0 + n) = S(n)\). 귀납 원리(정리 7.3.2). ∎ (정의는 오른쪽 0만 다루므로 왼쪽 0은 증명이 필요하다.)

  6. 판단한 학생이 "러셀의 역설 때문에 현대 수학의 집합론에는 모순이 있다"고 썼다. 맞는가? [07-01, 07-02]

    힌트 1

    역설이 생기는 원리는 ZF에 있나요?

    힌트 2

    분리 공리.

    풀이

    틀렸다. 러셀의 역설은 무제한 내포 원리의 모순을 보인 것이고, ZF는 그 원리 대신 분리 공리를 써서 같은 논법이 "모든 집합의 집합은 없다"는 정리가 된다. ZF에서 알려진 모순은 없다(다만 무모순성을 ZF 안에서 증명할 수는 없다).
