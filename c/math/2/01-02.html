1.2.1증명의 뼈대

대부분의 정리는 "\(\forall x,\ P(x) \Rightarrow Q(x)\)" 꼴입니다. 그 증명은 늘 같은 문장으로 시작합니다: "임의의 \(x\)를 잡고 \(P(x)\)를 가정하자." 특정한 \(x\)가 아니라 아무 \(x\)나 잡았으므로, 끝에서 \(Q(x)\)를 얻으면 모든 \(x\)에 대해 보인 것이 됩니다.

정의 1.2.1 (세 가지 증명 방법)

직접 증명: \(P\)를 가정하고 정의와 이미 아는 사실로 \(Q\)를 이끈다.

대우에 의한 증명: \(\neg Q\)를 가정하고 \(\neg P\)를 이끈다(\(P \Rightarrow Q \equiv \neg Q \Rightarrow \neg P\)).

귀류법: \(P\)와 \(\neg Q\)를 함께 가정하고 모순(어떤 \(R\)과 \(\neg R\))을 이끈다(\(\neg(P \Rightarrow Q) \equiv P \wedge \neg Q\)이 불가능함을 보임).

1.2.2예로 보는 선택

예제 1.2.2 (직접 증명)

두 홀수의 곱은 홀수임을 보여라.

풀이. 홀수의 정의 "\(n = 2k + 1\)인 정수 \(k\)가 있다"를 그대로 씁니다. 임의의 홀수 \(m = 2a + 1\), \(n = 2b + 1\)에 대해 \(mn = 4ab + 2a + 2b + 1 = 2(2ab + a + b) + 1\)이고 \(2ab + a + b\)는 정수이므로 \(mn\)은 홀수입니다. 가정과 결론이 모두 "있다"로 정의되어 다루기 쉬울 때 직접 증명이 자연스럽습니다.

예제 1.2.3 (대우)

정수 \(n\)에 대해 \(n^2\)이 짝수이면 \(n\)도 짝수임을 보여라.

풀이. 직접 하면 "\(n^2 = 2k\)"에서 \(n\)에 대해 말하기 어렵습니다(\(n = \sqrt{2k}\)?). 대우 "\(n\)이 홀수이면 \(n^2\)이 홀수"는 예제 1.2.2에서 \(m = n\)인 경우라 바로 끝납니다. 결론이 "부정형"이거나 가정이 다루기 어려울 때 대우가 편합니다.

예제 1.2.4 (귀류법)

\(\sqrt2\)는 유리수가 아님을 보여라.

풀이. "유리수가 아니다"는 부정형이라 직접 다룰 대상이 없습니다. 유리수라고 가정해 \(\sqrt2 = \frac pq\) (\(p, q\)는 서로소인 정수, \(q \ne 0\))로 둡니다. 제곱하면 \(p^2 = 2q^2\)이라 \(p^2\)이 짝수, 예제 1.2.3으로 \(p = 2r\). 대입하면 \(4r^2 = 2q^2\), \(q^2 = 2r^2\)이라 \(q\)도 짝수. \(p, q\)가 모두 짝수라 서로소라는 가정과 모순입니다. 따라서 \(\sqrt2\)는 무리수입니다.

예제 1.2.5 (존재와 반례)

(a) 무리수 \(a, b\)로 \(a^b\)가 유리수인 것이 있음을 보여라. (b) "모든 소수 \(p\)에 대해 \(2^p - 1\)은 소수"를 반박하여라.

풀이. (a) \(x = \sqrt2^{\sqrt2}\)가 유리수이면 \(a = b = \sqrt2\)로 끝. 무리수이면 \(a = x\), \(b = \sqrt2\)로 \(a^b = \sqrt2^{2} = 2\). 어느 경우든 있습니다(어느 경우인지 몰라도 존재는 증명됨). (b) 반례 하나면 됩니다: \(2^{11} - 1 = 2047 = 23\times89\).

1.2.3방법 고르기 요령

  • 가정을 정의로 풀어 쓴 식이 결론으로 이어지면 → 직접 증명.
  • 결론이 "~가 아니다", "~이면 ~가 아니다" 꼴이거나, 결론의 부정이 다루기 쉬우면 → 대우.
  • "~는 없다", "무리수", "무한히 많다"처럼 직접 붙잡을 대상이 없으면 → 귀류법.
  • "모든"이 거짓임을 보일 때 → 반례 하나. "존재"를 보일 때 → 하나 만들어 보이기.
흔한 실수(1) 예 몇 개를 확인하고 "모든"을 증명했다고 한다: \(n^2 + n + 41\)은 \(n = 0, \dots, 39\)에서 모두 소수지만 \(n = 40\)에서 \(41^2\)이다. (2) 역을 증명한다: "\(P \Rightarrow Q\)" 대신 "\(Q \Rightarrow P\)"를 보이는 실수. (3) 귀류법에서 무엇과 모순인지 밝히지 않는다: 모순은 가정 중 하나나 이미 증명된 사실과 맞서야 한다.
요약
  1. "모든 \(x\)"는 임의의 \(x\)를 잡아 보이고, "존재"는 만들어 보이며, "모든"의 반박은 반례 하나.
  2. 직접 증명, 대우(\(\neg Q \Rightarrow \neg P\)), 귀류법(\(P \wedge \neg Q\)에서 모순).
  3. 부정형 결론에는 대우나 귀류법이 편하다.

1.2.4연습문제

기본

  1. 정수 \(a, b\)에 대해 \(ab\)가 홀수이면 \(a\)와 \(b\)가 모두 홀수임을 대우로 보여라.
    답

    대우: \(a\)나 \(b\)가 짝수이면 \(ab\)가 짝수. \(a = 2k\)이면 \(ab = 2(kb)\).

응용

  1. 소수가 무한히 많음을 귀류법으로 보여라.
    답

    유한하다면 \(p_1, \dots, p_k\)가 전부. \(N = p_1\cdots p_k + 1\)의 소인수 \(p\)는 어떤 \(p_i\)인데 \(p_i\)는 \(N\)을 나누면 1도 나눠 모순.

심화

  1. \(\log_2 3\)이 무리수임을 보여라.
    답

    \(\log_23 = \frac pq\) (\(p, q > 0\))이면 \(2^p = 3^q\)인데 왼쪽은 짝수, 오른쪽은 홀수.

예제같은 명제, 세 가지 증명

예제 · 증명 방법 고르기

다루는 성취기준 [수학2-01-02]

먼저 예측

"정수 \(n\)에 대해 \(n^2 - 6n + 5\)가 짝수이면 \(n\)은 홀수이다." 직접 증명, 대우, 귀류법 중 어느 것이 가장 짧을까요?

예측 확인

대우입니다. 결론의 부정 "\(n\)이 짝수"는 \(n = 2k\)로 바로 식에 넣을 수 있습니다.

위 명제를 대우로 증명하고, 직접 증명과 귀류법으로는 어떻게 되는지 비교하여라.

전략

가정 "\(n^2 - 6n + 5\)가 짝수"는 \(n\)에 대한 정보를 꺼내기 어렵습니다. 대우 "\(n\)이 짝수이면 \(n^2 - 6n + 5\)가 홀수"는 \(n = 2k\)를 대입하면 끝납니다(1.2절).

풀이

  1. (대우) \(n\)이 짝수라 하고 \(n = 2k\)로 둔다.
    짝수의 정의.
  2. \(n^2 - 6n + 5 = 4k^2 - 12k + 5 = 2(2k^2 - 6k + 2) + 1\)은 홀수다.
    \(2k^2 - 6k + 2\)는 정수.
  3. 따라서 대우가 참이고, 원래 명제도 참이다.
    \(P \Rightarrow Q \equiv \neg Q \Rightarrow \neg P\).
  4. (직접 증명) \(n^2 - 6n + 5 = (n - 1)(n - 5)\)가 짝수이면 \(n - 1\) 또는 \(n - 5\)가 짝수, 어느 쪽이든 \(n\)은 홀수.
    곱이 짝수이면 인수 중 하나가 짝수(예제 1.2.2의 대우). 인수분해를 알아채야 한다.
  5. (귀류법) \(n^2 - 6n + 5\)가 짝수인데 \(n\)이 짝수라 가정하면 1–2단계로 홀수가 되어 모순.
    내용은 대우와 같고 문장만 길어진다.

검산

\(n = 3\): \(9 - 18 + 5 = -4\) (짝수), \(n\) 홀수 ✓. \(n = 4\): \(16 - 24 + 5 = -3\) (홀수)라 가정이 거짓, 명제는 그대로 참. 실제로 \(n\)이 홀수이면 늘 짝수, 짝수이면 늘 홀수입니다.

의미

대우와 귀류법은 논리적으로 가까운 경우가 많습니다. 귀류법이 꼭 필요한 것은 \(\sqrt2\)의 무리성처럼 결론의 부정 외에 가정 \(P\)도 함께 써야 모순이 나는 경우입니다. 대우로 끝나는 증명을 귀류법으로 쓰면 읽는 사람이 무엇과 모순인지 찾느라 시간을 씁니다.

이해 확인

"\(a + b \ge 10\)이면 \(a \ge 5\) 또는 \(b \ge 5\)" (실수 \(a, b\))는 어떤 방법이 편한가?

답

대우: \(a < 5\)이고 \(b < 5\)이면 \(a + b < 10\). 드모르간으로 "또는"의 부정이 "그리고"가 된다.
