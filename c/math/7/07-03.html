7.3.1계산기로 cos를 반복해 누르면

계산기에 아무 수나 넣고 cos(라디안)를 계속 누르면 값이 0.739085…로 모입니다. 이 수는 \(\cos x = x\)의 해, 곧 cos의 고정점입니다. 왜 늘 같은 값으로 모일까요? \(\cos\)이 거리를 줄이는 함수이기 때문입니다(\(|\cos x - \cos y| \le \sin 1\cdot|x - y|\), \([-1, 1]\)에서). 이 생각을 일반화한 것이 축소사상 원리이고, 방정식의 해가 "있고, 하나뿐이고, 반복으로 구할 수 있다"를 한꺼번에 줍니다.

정의 7.3.1 (축소사상)

거리공간 \(X\)의 함수 \(T: X \to X\)가 어떤 \(c < 1\)에 대해 모든 \(x, y\)에서 \(d(T(x), T(y)) \le c\,d(x, y)\)이면 축소사상이라 한다.

정리 7.3.2 (축소사상 원리)

\(X\)가 공집합이 아닌 완비 거리공간이고 \(T\)가 축소사상이면 \(T(x) = x\)인 \(x\)가 정확히 하나 있다. 또 임의의 \(x_0\)에서 \(x_{n+1} = T(x_n)\)은 그 고정점으로 수렴하고 \(d(x_n, x) \le \frac{c^n}{1 - c}d(x_1, x_0)\).

증명.(유일성) 고정점 \(x, y\)가 둘이면 \(d(x, y) = d(T(x), T(y)) \le c\,d(x, y)\)이고 \(c < 1\)이라 \(d(x, y) = 0\). (존재) \(d(x_{n+1}, x_n) \le c\,d(x_n, x_{n-1}) \le \dots \le c^nd(x_1, x_0)\)이다. \(m > n\)이면 삼각부등식과 등비급수로

\[d(x_m, x_n) \le \sum_{k=n}^{m-1}c^kd(x_1, x_0) < \frac{c^n}{1 - c}d(x_1, x_0) \to 0.\]

따라서 \((x_n)\)은 코시 수열이고, 완비성으로 \(x_n \to x\). \(T\)는 연속(축소이므로)이라 \(T(x) = \lim T(x_n) = \lim x_{n+1} = x\). 오차 공식은 위 부등식에서 \(m \to \infty\). ∎

세 가정이 각각 필요합니다. 완비: \((0, 1]\)에서 \(T(x) = \frac x2\)는 축소지만 고정점 0이 공간 밖. \(c < 1\) 고정: \([1, \infty)\)에서 \(T(x) = x + \frac1x\)는 \(d(T(x), T(y)) < d(x, y)\)이지만 고정점이 없습니다(비율이 1에 다가감). \(T(X) \subseteq X\): 반복이 공간을 벗어나면 안 됩니다.

7.3.2미분방정식의 해의 존재

\(y' = F(t, y)\), \(y(0) = y_0\)는 기본정리로 적분방정식 \(y(t) = y_0 + \int_0^tF(s, y(s))\,ds\)와 같습니다. 오른쪽을 함수 \(y\)를 함수로 보내는 사상 \(T\)로 보면, 해는 \(T\)의 고정점입니다.

정리 7.3.3 (피카르)

\(F\)가 연속이고 \(y\)에 대해 립시츠(\(|F(t, y) - F(t, z)| \le L|y - z|\))이면, 충분히 작은 \(h > 0\)에 대해 \([0, h]\)에서 해가 정확히 하나 있다.

증명의 뼈대.\(X = C[0, h]\)(상한 거리, 완비)에서 \(T(y)(t) = y_0 + \int_0^tF(s, y(s))\,ds\)로 두면 \(|T(y)(t) - T(z)(t)| \le \int_0^tL|y - z|\,ds \le Lh\,d(y, z)\)이다. \(h < \frac1L\)로 고르면 축소사상이라 고정점, 곧 해가 하나 있다. ∎

예제 7.3.4

\(y' = y\), \(y(0) = 1\)에 피카르 반복 \(y_{n+1} = 1 + \int_0^ty_n\)을 \(y_0 = 1\)에서 시작해 적용하여라.

풀이. \(y_1 = 1 + t\), \(y_2 = 1 + t + \frac{t^2}2\), …, \(y_n = \sum_{k=0}^n\frac{t^k}{k!}\). 반복할 때마다 \(e^t\)의 테일러 다항식의 항이 하나씩 붙고, 극한이 해 \(e^t\)입니다. 같은 절의 탐구 카드에서 이 반복과 cos 반복을 볼 수 있습니다.

주의립시츠 조건이 없으면 해가 하나가 아닐 수 있습니다. \(y' = \sqrt{|y|}\), \(y(0) = 0\)은 \(y = 0\)과 \(y = \frac{t^2}4\)가 모두 해입니다. \(\sqrt{|y|}\)는 0 근처에서 립시츠가 아니라 축소사상 원리를 쓸 수 없습니다(존재는 아르첼라-아스콜리로 보이는 페아노 정리가 보장).
요약
  1. 완비 공간의 축소사상은 고정점이 하나뿐이고, 반복이 그것으로 등비급수 속도로 수렴한다.
  2. 완비, \(c < 1\), 자기 자신으로 가기가 모두 필요하다.
  3. 미분방정식을 적분방정식으로 바꾸면 해는 고정점이다(피카르). 립시츠 조건이 축소를 준다.

7.3.3연습문제

기본

  1. \(T(x) = \frac x3 + 1\)의 고정점과 \(c\)를 구하여라.
    답

    \(x = \frac32\), \(c = \frac13\).

응용

  1. \(x = \cos x\)가 \([0, 1]\)에서 해를 하나뿐 가짐을 축소사상 원리로 보이고, \(x_0 = 1\)에서 20번 반복한 오차를 어림하여라.
    답

    \(\cos\)은 \([0, 1]\)을 \([\cos1, 1] \subseteq [0, 1]\)로 보내고 \(|\cos' | \le \sin1 \approx 0.841\). 오차 \(\le \frac{0.841^{20}}{0.159}|\cos1 - 1| \approx 0.09\). (실제로는 훨씬 작음, 약 \(10^{-4}\).)

심화

  1. \(\sqrt2\)를 구하는 반복 \(x_{n+1} = \frac12(x_n + \frac2{x_n})\)이 \([1, 2]\)에서 축소사상임을 보여라.
    답

    \(T'(x) = \frac12(1 - \frac2{x^2})\), \([1, 2]\)에서 \(|T'| \le \frac12\). \(T(1) = 1.5\), \(T(2) = 1.5\), 최솟값 \(T(\sqrt2) = \sqrt2\)라 \([1, 2]\)로 간다. (실제 수렴은 뉴턴 방법이라 제곱 속도로 더 빠르다.)

7.3.2

탐구반복하면 고정점으로 빨려 든다

탐구 · 축소사상과 거미줄 그림

다루는 성취기준 [수학7-07-03]

질문

\(x_{n+1} = T(x_n)\)을 되풀이하면 값들은 어디로 갈까요? 시작점을 바꾸면 도착점도 바뀔까요? 축소사상이 아니면 무슨 일이 생길까요?

복원

완비 공간의 축소사상(\(d(Tx, Ty) \le c\,d(x, y)\), \(c < 1\))은 고정점이 하나뿐이고, 반복이 등비급수 속도로 그것에 수렴한다 (7.3절).

해 보기

  1. cos에서 시작점을 아무 데로나 끌어도 거미줄이 0.739085…(곡선과 대각선의 교점)로 감깁니다.
  2. \(\frac x3 + 1\)은 기울기 \(\frac13\)이라 몇 번 만에 1.5에 붙습니다. 오차가 매번 \(\frac13\)로 줄어듭니다.
  3. \(\frac12(x + \frac2x)\)는 아주 빠르게 \(\sqrt2\)에 붙습니다. 고정점에서 기울기가 0이라 오차가 제곱으로 줄어듭니다(뉴턴 방법).
  4. \(3.3x(1 - x)\)는 축소사상이 아닙니다. 고정점 근처의 기울기 절댓값이 1보다 커서, 값들이 고정점으로 가지 않고 두 값 사이를 오갑니다(주기 2).

설명

  1. 거미줄 그리는 법\(x\)에서 세로로 곡선까지 가면 \(T(x)\), 가로로 대각선까지 가면 그 값이 다음 \(x\)가 됩니다.
  2. 기울기와 수렴고정점에서 \(|T'| < 1\)이면 그 근처에서 축소사상이라 끌려 들고, \(|T'| > 1\)이면 밀려납니다. 로지스틱 사상은 매개변수를 키우면 주기 배가를 거쳐 혼돈에 이릅니다(수학6 7단원의 동역학과 이어짐).

판단

"\(T\)가 연속이고 고정점이 있으면 반복이 늘 그 고정점으로 수렴한다"는 틀립니다. \(3.3x(1 - x)\)는 연속이고 고정점(약 0.697)이 있지만, 반복은 그 근처를 맴돌 뿐 수렴하지 않습니다. 수렴을 보장하는 것은 축소성입니다.
