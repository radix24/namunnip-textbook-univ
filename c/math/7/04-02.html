4.2.1도함수는 아무 함수나 될 수 있을까

연속함수는 중간값 성질을 가집니다. 그런데 도함수는 연속이 아닐 수 있습니다. 예를 들어 \(f(x) = x^2\sin\frac1x\) (\(f(0) = 0\))은 모든 점에서 미분 가능하지만 \(f'\)은 0에서 불연속입니다(공통1 3.1절 연습 6). 그렇다면 도함수는 아무렇게나 불연속일 수 있을까요? 예를 들어 계단 함수(\(x < 0\)에서 0, \(x \ge 0\)에서 1)가 어떤 함수의 도함수일 수 있을까요? 다르부 정리는 그럴 수 없다고 답합니다.

정리 4.2.1 (다르부)

\(f\)가 \([a, b]\)에서 미분 가능하고 \(f'(a) < \lambda < f'(b)\)이면 \(f'(x) = \lambda\)인 \(x \in (a, b)\)가 있다.

아이디어: \(g(t) = f(t) - \lambda t\)를 보면 \(g'(a) < 0 < g'(b)\)입니다. 왼쪽 끝에서는 내려가는 중이고 오른쪽 끝에서는 올라가는 중이므로, 최솟값은 끝점이 아니라 안쪽에서 생겨야 합니다. 그 안쪽 최소점에서 페르마 정리로 \(g' = 0\)입니다.

증명.\(g(t) = f(t) - \lambda t\)는 \([a, b]\)에서 미분 가능하므로 연속이고, 최대·최소 정리로 최솟값을 갖는 점 \(x\)가 있다. \(g'(a) = f'(a) - \lambda < 0\)이므로 미분계수의 정의에서 \(a\)의 오른쪽 가까이에 \(g(t) < g(a)\)인 \(t\)가 있다(그렇지 않으면 오른쪽 차분몫이 모두 0 이상이라 \(g'(a) \ge 0\)). 따라서 \(x \ne a\). 같은 이유로 \(g'(b) > 0\)에서 \(b\)의 왼쪽 가까이에 \(g(t) < g(b)\)인 \(t\)가 있어 \(x \ne b\). 곧 \(x \in (a, b)\)이고 페르마 정리로 \(g'(x) = 0\), \(f'(x) = \lambda\). ∎

증명에 \(f'\)의 연속성은 전혀 쓰이지 않았습니다. 쓴 것은 "\(f\)가 미분 가능 ⇒ \(f\)가 연속 ⇒ 최솟값 존재"와 페르마 정리뿐입니다.

4.2.2따름정리: 도함수에는 점프가 없다

따름정리 4.2.2

도함수 \(f'\)이 어떤 점에서 좌극한과 우극한을 모두 가진다면, 그 두 극한과 함숫값은 모두 같다. 곧 도함수는 점프 불연속(1종 불연속)을 갖지 않는다.

예를 들어 \(f'(x) \to 0\) (\(x \to 0^-\)), \(f'(x) \to 1\) (\(x \to 0^+\))이라면 \(0\)과 \(1\) 사이의 값 \(\frac12\)을 0 근처의 작은 구간에서 취하지 못하므로 다르부 정리에 어긋납니다. 그래서 계단 함수는 어떤 함수의 도함수도 아닙니다. 도함수의 불연속은 \(x^2\sin\frac1x\)의 도함수처럼 "진동하는" 형태(2종 불연속)뿐입니다.

예제 4.2.3

\(f(x) = x^2\sin\frac1x\) (\(x \ne 0\)), \(f(0) = 0\)의 도함수가 0 근처의 아주 작은 구간 \((0, \delta)\)에서 \([-1, 1]\)의 모든 값을 취함을 보여라.

풀이. \(x \ne 0\)에서 \(f'(x) = 2x\sin\frac1x - \cos\frac1x\), \(f'(0) = 0\)입니다. \(x_k = \frac1{2k\pi}\)에서 \(f'(x_k) = -1\), \(y_k = \frac1{(2k+1)\pi}\)에서 \(f'(y_k) = 1\)이고, 둘 다 큰 \(k\)에서 \((0, \delta)\)에 들어갑니다. \(f\)는 \([y_k, x_k]\)에서 미분 가능하므로 다르부 정리로 \(-1\)과 \(1\) 사이의 모든 값을 그 사이에서 취합니다. 불연속이지만 "건너뛰지는" 않습니다.

주의"미분 가능한 함수의 도함수는 연속이다"는 틀립니다(예제 4.2.3). 그래서 해석학에서는 "\(C^1\) 함수"(미분 가능하고 도함수가 연속)를 따로 이름 붙입니다. 8단원의 "편도함수가 연속이면 미분 가능" 정리도 이 구별에 기댑니다.
요약
  1. 다르부: 도함수는 연속이 아니어도 중간값 성질을 가진다.
  2. 증명은 \(f(t) - \lambda t\)의 최솟값이 안쪽에 있음을 보이고 페르마 정리를 쓴다.
  3. 그래서 도함수에는 점프 불연속이 없고, 계단 함수는 도함수가 될 수 없다.

4.2.3연습문제

기본

  1. 부호 함수 \(\operatorname{sgn}x\)는 어떤 함수의 도함수인가?
    답

    아니다. 0에서 점프가 있어 다르부 정리에 어긋난다. (\(|x|\)는 0에서 미분 불가능이라 후보가 아니다.)

응용

  1. \(f\)가 미분 가능하고 \(f'(x) \ne 0\)이 모든 \(x\)에서 성립하면 \(f\)는 단조함수임을 보여라.
    답

    \(f'\)이 양수인 점과 음수인 점이 모두 있으면 다르부로 그 사이에서 0을 취한다. 따라서 \(f'\)의 부호가 하나라 평균값 정리로 단조.

심화

  1. \(f'\)이 존재하고 단조함수이면 \(f'\)은 연속임을 보여라.
    답

    단조함수의 불연속은 점프뿐(좌우 극한이 존재)인데, 도함수는 점프를 가질 수 없다(따름정리 4.2.2).

4.2.2

증명도함수는 값을 건너뛰지 않는다

증명 · 다르부 정리를 한 단계씩

다루는 성취기준 [수학7-04-02]

정리

\(f\)가 \([a, b]\)에서 미분 가능하고 \(f'(a) < 0 < f'(b)\)이면 \(f'(x) = 0\)인 \(x \in (a, b)\)가 있다.

쓰는 것

  • 미분 가능 ⇒ 연속 (공통1 정리 3.1.5).
  • 최대·최소 정리 (3.2절).
  • 페르마 정리: 내부 극값에서 도함수는 0 (4.1절).

아이디어

\(f'(a) < 0\)은 "출발할 때 내려간다", \(f'(b) > 0\)은 "도착할 때 올라간다"는 뜻입니다. 그러면 가장 낮은 곳은 출발점도 도착점도 아닌 안쪽입니다. 안쪽 최저점에서 접선은 수평입니다. 일반 \(\lambda\)는 \(f(t) - \lambda t\)로 바꾸면 이 경우가 됩니다.

증명

  1. \(f\)는 \([a, b]\)에서 연속이므로 최솟값을 갖는 점 \(x \in [a, b]\)가 있다.
    미분 가능하면 연속, 그리고 최대·최소 정리.
  2. \(f'(a) = \lim_{t\to a^+}\frac{f(t) - f(a)}{t - a} < 0\)이므로, \(a\)에 충분히 가까운 \(t > a\)에서 \(\frac{f(t) - f(a)}{t - a} < 0\), 곧 \(f(t) < f(a)\).
    극한이 음수이면 극한에 가까운 값들도 음수(ε = \(|f'(a)|/2\)로 극한의 정의). \(t - a > 0\)을 곱해도 부등호 방향 유지.
  3. 따라서 \(f(a)\)는 최솟값이 아니고 \(x \ne a\).
    더 작은 값 \(f(t)\)가 있다.
  4. 같은 방법으로 \(f'(b) > 0\)에서 \(b\)에 가까운 \(t < b\)는 \(f(t) < f(b)\)이므로 \(x \ne b\).
    \(t - b < 0\)이라 차분몫이 양수이려면 \(f(t) - f(b) < 0\).
  5. \(x \in (a, b)\)는 내부 최소점이므로 페르마 정리로 \(f'(x) = 0\).
    내부 극값 + 미분 가능.

되짚기

  • \(f'\)의 연속성은 어디에도 쓰지 않았습니다. 그래서 결론이 도함수가 불연속이어도 성립합니다. 만약 \(f'\)이 연속이라면 중간값 정리 한 줄이면 끝났을 것입니다.
  • \([a, b]\) 전체에서의 미분 가능성이 필요합니다. 한 점에서라도 미분 가능하지 않으면 깨집니다: \(f(x) = |x|\)는 \([-1, 1]\)에서 \(f'(-1) = -1 < 0 < 1 = f'(1)\)이지만 \(f' = 0\)인 점이 없습니다(최소점 0에서 미분 불가능이라 5단계 실패).

직접 써 보기

위 정리를 써서 일반적인 다르부 정리(\(f'(a) < \lambda < f'(b)\)이면 \(f'(x) = \lambda\)인 \(x\)가 있다)를 증명하여라. \(f'(a) > \lambda > f'(b)\)인 경우도 다뤄라.

답안

\(g(t) = f(t) - \lambda t\)는 \([a, b]\)에서 미분 가능하고 \(g'(a) = f'(a) - \lambda < 0 < g'(b)\). 위 정리로 \(g'(x) = 0\), 곧 \(f'(x) = \lambda\). 반대 경우는 \(-f\)에 같은 논증을 쓰거나 최댓값을 쓴다. ∎
