6.3.1함수급수를 수 급수로 누르기

함수급수 \(\sum f_n(x)\)가 균등수렴하는지 보려면 부분합의 차를 모든 \(x\)에서 한꺼번에 어림해야 합니다. 각 항이 \(x\)와 상관없는 수 \(M_n\)으로 눌리고 \(\sum M_n\)이 수렴하면, 그 어림이 자동으로 됩니다.

정리 6.3.1 (바이어슈트라스 M-판정법)

모든 \(x \in E\)에서 \(|f_n(x)| \le M_n\)이고 \(\sum M_n\)이 수렴하면 \(\sum f_n\)은 \(E\)에서 (절대) 균등수렴한다.

증명.\(\sum M_n\)이 수렴하므로 코시 조건으로 \(m \ge n \ge N\)이면 \(\sum_{k=n}^mM_k < \varepsilon\)인 \(N\)이 있다. 그러면 모든 \(x\)에서 \(\left|\sum_{k=n}^mf_k(x)\right| \le \sum_{k=n}^mM_k < \varepsilon\)이고, 균등 코시 판정(정리 6.1.4)으로 균등수렴한다. ∎

예제 6.3.2

\(f(x) = \sum_{n=1}^\infty\frac{\sin nx}{n^2}\)은 \(\mathbb R\)에서 연속이고, \(\int_0^\pi f(x)\,dx = \sum_{n\text{ 홀수}}\frac{2}{n^3}\)임을 보여라.

풀이. \(\left|\frac{\sin nx}{n^2}\right| \le \frac1{n^2}\)이고 \(\sum\frac1{n^2}\)이 수렴하므로 M-판정법으로 균등수렴합니다. 각 항이 연속이므로 정리 6.2.1로 \(f\)는 연속입니다. 균등수렴이라 항별로 적분할 수 있고(정리 6.2.2), \(\int_0^\pi\sin nx\,dx = \frac{1 - \cos n\pi}{n}\)은 \(n\)이 홀수면 \(\frac2n\), 짝수면 0이므로 결과가 나옵니다.

반면 이 급수를 항별로 미분하면 \(\sum\frac{\cos nx}{n}\)인데, 이것은 \(x = 0\)에서 조화급수라 발산합니다. M-판정법이 \(f\)에는 통하지만 \(f'\)의 급수에는 통하지 않아 정리 6.2.3을 쓸 수 없습니다.

6.3.2거듭제곱급수

정리 6.3.3

거듭제곱급수 \(\sum c_nx^n\)의 수렴반경이 \(R > 0\)이면, \(0 < r < R\)인 모든 \(r\)에 대해 \([-r, r]\)에서 균등수렴한다. 따라서 합 \(f\)는 \((-R, R)\)에서 연속이고 미분 가능하며 \(f'(x) = \sum nc_nx^{n-1}\)이다.

증명.\(r < s < R\)인 \(s\)를 잡으면 \(\sum c_ns^n\)이 절대수렴하고(근 판정), \(|x| \le r\)에서 \(|c_nx^n| \le |c_n|r^n \le |c_n|s^n\)이므로 M-판정법으로 균등수렴한다. 도함수의 급수 \(\sum nc_nx^{n-1}\)도 \(\limsup\sqrt[n]{n|c_n|} = \limsup\sqrt[n]{|c_n|}\)(\(\sqrt[n]{n} \to 1\))이라 수렴반경이 같으므로 같은 이유로 균등수렴하고, 정리 6.2.3으로 항별 미분이 정당화된다. 모든 점은 그런 \([-r, r]\)에 들어가므로 \((-R, R)\) 전체에서 성립한다. ∎

"수렴반경 안의 닫힌 부분구간에서" 균등수렴한다는 점에 주의하세요. \(\sum x^n\)은 \((-1, 1)\) 전체에서는 균등수렴하지 않습니다(\(x \to 1\)에서 합이 \(\infty\)로).

주의M-판정법은 충분조건입니다. \(\sum\frac{(-1)^n}{n + x^2}\)은 \(\mathbb R\)에서 균등수렴하지만(교대급수 오차 \(\le \frac{1}{n + 1}\)), 각 항의 크기의 상한 \(\frac1n\)의 합이 발산해 M-판정법으로는 보일 수 없습니다. 이런 경우 교대급수 판정이나 아벨·디리클레 판정을 씁니다.
요약
  1. \(|f_n(x)| \le M_n\) (모든 \(x\))이고 \(\sum M_n\) 수렴이면 균등수렴.
  2. 거듭제곱급수는 수렴반경 안의 닫힌 부분구간에서 균등수렴하고, 항별로 미분·적분할 수 있다.
  3. M-판정법이 실패해도 균등수렴할 수 있다.

6.3.3연습문제

기본

  1. \(\sum\frac{x^n}{n^2}\)은 \([-1, 1]\)에서 균등수렴함을 보여라.
    답

    \(|x^n/n^2| \le 1/n^2\). M-판정.

응용

  1. \(\zeta(x) = \sum\frac{1}{n^x}\)은 \([1.1, \infty)\)에서 연속임을 보여라.
    답

    \(x \ge 1.1\)에서 \(n^{-x} \le n^{-1.1}\), \(\sum n^{-1.1}\) 수렴. M-판정으로 균등수렴, 연속.

  2. \(\sum_{n=0}^\infty x^n\)을 항별 미분해 \(\sum nx^{n-1} = \frac{1}{(1-x)^2}\)을 얻는 것이 \(|x| < 1\)에서 정당함을 보여라.
    답

    정리 6.3.3 (\(R = 1\)).

심화

  1. \(\sum_{n=1}^\infty\frac{x}{n(1 + nx^2)}\)이 \(\mathbb R\)에서 균등수렴함을 보여라.
    힌트

    \(\frac{|x|}{1 + nx^2}\)의 최댓값은 \(\frac{1}{2\sqrt n}\).

    답

    \(\left|\frac{x}{n(1+nx^2)}\right| \le \frac{1}{2n^{3/2}}\), \(\sum n^{-3/2}\) 수렴. M-판정.

6.3.2

예제항별 미분이 허락되는가

예제 · M-판정법을 도함수 급수에

다루는 성취기준 [수학7-06-03]

먼저 예측

\(f(x) = \sum_{n=1}^\infty\frac{\cos nx}{n^3}\)를 항별로 미분하면 \(-\sum\frac{\sin nx}{n^2}\)입니다. 이 계산은 믿어도 될까요? \(\sum\frac{\cos nx}{n^2}\)을 항별 미분한 \(-\sum\frac{\sin nx}{n}\)은요?

예측 확인

앞의 것은 됩니다(도함수 급수에 M-판정법이 통함). 뒤의 것은 이 방법으로는 정당화되지 않습니다(\(\sum\frac1n\) 발산).

\(f(x) = \sum_{n=1}^\infty\frac{\cos nx}{n^3}\)이 \(\mathbb R\)에서 미분 가능하고 \(f'(x) = -\sum\frac{\sin nx}{n^2}\)임을 보여라.

전략

정리 6.2.3은 (i) 한 점에서 수렴하고 (ii) 도함수의 급수가 균등수렴할 것을 요구합니다. (ii)를 M-판정법으로 확인합니다.

풀이

  1. \(x = 0\)에서 \(\sum\frac1{n^3}\)은 수렴한다.
    조건 (i). \(p = 3 > 1\)인 \(p\)-급수.
  2. 항의 도함수는 \(-\frac{\sin nx}{n^2}\)이고 \(\left|-\frac{\sin nx}{n^2}\right| \le \frac{1}{n^2}\).
    \(|\sin| \le 1\). \(x\)와 상관없는 상한.
  3. \(\sum\frac1{n^2}\)이 수렴하므로 도함수의 급수는 \(\mathbb R\)에서 균등수렴한다.
    M-판정법(정리 6.3.1).
  4. 정리 6.2.3으로 \(\sum\frac{\cos nx}{n^3}\)은 균등수렴하고 그 합 \(f\)는 미분 가능하며 \(f' = -\sum\frac{\sin nx}{n^2}\).
    각 유계 구간에서 적용하면 \(\mathbb R\) 전체.

검산

\(x = 0\)에서 \(f'(0) = 0\)이어야 합니다. \(f\)는 우함수(\(\cos\)의 합)라 0에서 미분 가능하면 기울기가 0이고, 급수 \(-\sum\frac{\sin 0}{n^2} = 0\)과 같습니다.

의미

푸리에 급수의 계수가 빨리 줄수록(\(\frac1{n^3}\)) 함수가 매끄럽습니다. \(\frac1{n^3}\)이면 한 번 미분할 수 있고, \(\frac1{n^2}\)이면 연속까지는 보장되지만 미분은 이 방법으로 보장되지 않습니다. "계수의 감소 속도 ↔ 매끄러움"은 푸리에 해석(수학15)의 중심 주제입니다.

이해 확인

\(\sum\frac{\cos nx}{n^4}\)은 몇 번까지 항별 미분을 이 방법으로 정당화할 수 있나요?

답

두 번. 두 번 미분한 급수의 항은 \(\frac{1}{n^2}\)으로 눌리고, 세 번이면 \(\frac1n\)이라 M-판정이 실패합니다.
