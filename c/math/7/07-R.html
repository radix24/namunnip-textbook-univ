7.R.1

연습함수공간의 정리들 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학7-07-01] [수학7-07-02] [수학7-07-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 개념\(f(x) = \sqrt x\)를 \([0, 1]\)에서 다항식으로 오차 0.01 이내로 근사할 수 있는가? \(f(x) = \frac1x\)를 \((0, 1]\)에서는? [07-01]

    힌트 1

    바이어슈트라스 정리의 가정을 확인하세요(7.1절).

    힌트 2

    다항식은 \([0, 1]\)에서 유계입니다.

    풀이

    \(\sqrt x\)는 닫힌구간에서 연속이라 가능하다(0에서 미분 불가능해도). \(\frac1x\)는 유계가 아니라 불가능하다: 다항식 \(P\)는 \([0, 1]\)에서 유계(\(|P| \le M\))인데 \(\frac1x\)는 \(x \to 0\)에서 \(M + 1\)을 넘으므로 차가 1 이상인 점이 있다.

  2. 증명\(f\)가 \([0, 1]\)에서 연속이고 \(\int_0^1f(x)x^n\,dx = 0\) (모든 \(n \ge 0\))이면 \(f = 0\)임을 보여라. [07-01]

    힌트 1

    모든 다항식 \(P\)에 대해 \(\int fP = 0\)입니다.

    힌트 2

    \(P_k \to f\) 균등이면 \(\int f^2 = \lim\int fP_k\).

    풀이

    바이어슈트라스로 \(P_k \to f\) 균등. \(fP_k \to f^2\)도 균등(\(|fP_k - f^2| \le \sup|f|\cdot\sup|P_k - f|\))이라 \(\int f^2 = \lim\int fP_k = 0\). \(f^2 \ge 0\)이고 연속이므로 \(f = 0\)(5.2절 연습 2). ∎

  3. 개념다음 함수열이 \([0, 1]\)에서 동등연속인지 말하여라. (a) \(f_n(x) = \sin(x + n)\) (b) \(f_n(x) = x^n\) (c) \(f_n(x) = \frac{\sin(nx)}{n}\) [07-02]

    힌트 1

    도함수가 함께 유계인지 보세요(7.2절).

    힌트 2

    (b)는 1 근처를 보세요.

    풀이

    (a) 예(\(|f_n'| \le 1\)). (b) 아니오(\(x = 1 - \frac1n\)과 1 사이에서 차가 \(1 - (1 - \frac1n)^n \to 1 - \frac1e\)). (c) 예(\(|f_n'| = |\cos nx| \le 1\)).

  4. 계산\(y' = 2ty\), \(y(0) = 1\)에 피카르 반복을 \(y_0 = 1\)에서 세 번 적용하고, 극한이 무엇인지 추측하여라. [07-03]

    힌트 1

    \(y_{n+1}(t) = 1 + \int_0^t2sy_n(s)\,ds\)(7.3절).

    힌트 2

    \(y_1 = 1 + t^2\).

    풀이

    \(y_1 = 1 + t^2\), \(y_2 = 1 + t^2 + \frac{t^4}2\), \(y_3 = 1 + t^2 + \frac{t^4}{2} + \frac{t^6}{6}\). 극한은 \(\sum\frac{t^{2k}}{k!} = e^{t^2}\), 실제로 해이다(\((e^{t^2})' = 2te^{t^2}\)).

  5. 증명\(T: [0, 1] \to [0, 1]\)이 미분 가능하고 \(|T'| \le \frac12\)이면 \(T\)는 고정점을 정확히 하나 가짐을 보여라. [07-03]

    힌트 1

    평균값 정리로 축소사상임을 보이세요.

    힌트 2

    \([0, 1]\)은 \(\mathbb R\)의 닫힌 부분집합이라 완비입니다.

    풀이

    \(|T(x) - T(y)| = |T'(c)||x - y| \le \frac12|x - y|\)이라 축소사상(\(c = \frac12\)). \([0, 1]\)은 완비(닫힌 부분집합의 코시 수열의 극한은 그 안에). 축소사상 원리로 고정점이 하나뿐. ∎

  6. 판단한 학생이 "\(T(x) = x + e^{-x}\)는 \([0, \infty)\)에서 \(|T(x) - T(y)| < |x - y|\) (\(x \ne y\))이므로 고정점이 있다"고 썼다. 맞는가? [07-03]

    힌트 1

    \(T(x) = x\)를 풀어 보세요.

    힌트 2

    축소사상 원리는 고정된 \(c < 1\)을 요구합니다.

    풀이

    틀렸다. \(T(x) = x\)이면 \(e^{-x} = 0\)이라 해가 없다. 부등식 \(|T(x) - T(y)| < |x - y|\)는 맞지만(\(0 < T' = 1 - e^{-x} < 1\)), 비율이 \(x \to \infty\)에서 1로 다가가 하나의 \(c < 1\)로 누를 수 없다. 축소사상 원리의 가정이 깨졌다.
