5.R.1

연습리만-스틸체스 적분 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학7-05-01] [수학7-05-02] [수학7-05-03]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(\alpha(x) = 0\) (\(x < 1\)), \(2\) (\(1 \le x < 2\)), \(3\) (\(x \ge 2\))일 때 \(\int_0^3x^2\,d\alpha\)를 구하여라. [05-01]

    힌트 1

    \(\alpha\)가 뛰는 점에서만 기여합니다(5.1절 예제 5.1.4).

    힌트 2

    점 1에서 2만큼, 점 2에서 1만큼 뜁니다.

    풀이

    \(\int x^2\,d\alpha = 2\cdot1^2 + 1\cdot2^2 = 6\). (\(x^2\)이 뛰는 점에서 연속이라 잘 정의된다.)

  2. 증명\(f\)가 \([a, b]\)에서 유계이고 유한 개의 점을 빼면 연속이면 적분 가능함을 보여라. [05-02]

    힌트 1

    불연속점을 아주 작은 구간으로 감싸고 나머지는 균등연속을 씁니다.

    힌트 2

    감싼 구간들의 기여는 (진동 \(\le 2M\)) × (폭의 합)입니다.

    풀이

    \(|f| \le M\), 불연속점 \(k\)개. 각각을 폭 \(\frac{\varepsilon}{4kM}\) 이하의 구간으로 감싸면 그 기여는 \(\le 2M\cdot k\cdot\frac{\varepsilon}{4kM} = \frac\varepsilon2\). 나머지는 유한 개의 닫힌구간이고 \(f\)가 연속이라 균등연속이므로, 진동 \(< \frac{\varepsilon}{2(b-a)}\)이 되게 잘게 나누면 기여 \(< \frac\varepsilon2\). 합해서 \(U - L < \varepsilon\). ∎

  3. 계산\(\displaystyle\lim_{n\to\infty}\sum_{k=1}^n\frac{n}{n^2 + k^2}\)를 적분으로 바꿔 구하여라. [05-01, 05-03]

    힌트 1

    \(\frac{n}{n^2 + k^2} = \frac1n\cdot\frac{1}{1 + (k/n)^2}\).

    힌트 2

    \(f(x) = \frac1{1 + x^2}\)의 \([0, 1]\) 리만 합입니다.

    풀이

    오른쪽 끝점 리만 합이고 \(f\)가 연속(적분 가능)이므로 극한은 \(\int_0^1\frac{dx}{1+x^2} = \frac\pi4\).

  4. 계산\(F(x) = \int_0^x|t - 1|\,dt\)를 구간별로 구하고, \(F'(1)\)이 존재하는지 판정하여라. [05-03]

    힌트 1

    피적분함수가 연속이므로 기본정리 1이 모든 점에서 통합니다.

    힌트 2

    \(F'(x) = |x - 1|\).

    풀이

    \(x \le 1\): \(F = x - \frac{x^2}2\). \(x \ge 1\): \(F = \frac12 + \frac{(x - 1)^2}2\). \(F'(1) = |1 - 1| = 0\)이 존재한다(양쪽 공식의 도함수도 1에서 0). 피적분함수가 꺾여도 연속이면 \(F\)는 미분 가능하다.

  5. 개념다음 중 \([0, 1]\)에서 리만 적분 가능한 것은? (a) \(\sin\frac1x\) (\(f(0) = 0\)) (b) \(\frac1x\) (\(f(0) = 0\)) (c) 칸토어 집합의 지시함수(칸토어 집합 위에서 1, 밖에서 0) [05-02]

    힌트 1

    리만 적분은 유계 함수에만 정의됩니다.

    힌트 2

    칸토어 집합은 길이가 0인 닫힌집합입니다.

    풀이

    (a) 가능: 유계이고 불연속점이 0 하나(연습 2). (b) 불가능: 유계가 아니다(이상적분으로는 발산). (c) 가능: 불연속점이 칸토어 집합(길이 0)이고, 그 집합을 덮는 구간들의 길이 합을 원하는 만큼 작게 할 수 있다.

  6. 판단한 학생이 "\(F(x) = x^2\sin\frac1{x^2}\) (\(F(0) = 0\))은 \([0, 1]\)에서 미분 가능하므로 기본정리 2로 \(\int_0^1F' = F(1) - F(0)\)"이라고 썼다. 무엇이 빠졌는가? [05-03]

    힌트 1

    기본정리 2의 가정을 다시 읽으세요(5.3절).

    힌트 2

    \(F'(x) = 2x\sin\frac1{x^2} - \frac2x\cos\frac1{x^2}\)은 0 근처에서 유계입니까?

    풀이

    기본정리 2는 \(F'\)이 적분 가능할 것을 요구한다. 여기서 \(F'\)은 0 근처에서 유계가 아니라(\(\frac2x\cos\frac1{x^2}\)) 리만 적분 가능하지 않다. 그래서 등식은 리만 적분으로는 의미가 없다(이상적분으로도 절대수렴하지 않음).
