5.2.1연속이면 적분 가능

리만 조건은 "진동 × 폭의 합"을 작게 만드는 분할을 요구합니다. 연속함수라면 조각을 잘게 만들수록 각 조각의 진동 \(M_i - m_i\)가 작아질 것 같습니다. 그런데 "모든 조각에서 동시에" 작아지려면, 조각의 위치와 상관없이 같은 폭으로 진동을 누를 수 있어야 합니다. 바로 균등연속입니다.

정리 5.2.1

\(f\)가 \([a, b]\)에서 연속이면 모든 증가함수 \(\alpha\)에 대해 \(f \in \mathcal R(\alpha)\)이다.

증명.\(\varepsilon > 0\)이 주어지면 \(\eta[\alpha(b) - \alpha(a)] < \varepsilon\)인 \(\eta > 0\)을 고른다. \([a, b]\)는 컴팩트이므로 \(f\)는 균등연속이고(정리 3.3.3), \(|x - t| < \delta\)이면 \(|f(x) - f(t)| < \eta\)인 \(\delta\)가 있다. 모든 조각의 폭이 \(\delta\)보다 작은 분할 \(P\)를 잡으면, 각 조각에서 최댓값과 최솟값이 있고(최대·최소 정리) 그 두 점의 거리가 \(\delta\)보다 작으므로 \(M_i - m_i < \eta\)이다. 따라서 \(U - L = \sum(M_i - m_i)\Delta\alpha_i < \eta\sum\Delta\alpha_i = \eta[\alpha(b) - \alpha(a)] < \varepsilon\). 리만 조건으로 적분 가능. ∎

균등연속 대신 그냥 연속만 쓰면 \(\delta\)가 점마다 달라 "모든 조각의 폭이 \(\delta\)보다 작은 분할"을 정할 수 없습니다. 3.3절의 정리가 여기서 결정적으로 쓰였습니다.

5.2.2단조이면 적분 가능

정리 5.2.2

\(f\)가 \([a, b]\)에서 단조함수이면 \(f \in \mathcal R\) (\(\alpha(x) = x\))이다.

증명.\(f\)가 증가한다고 하자. \(n\)등분 분할에서 각 조각의 최댓값은 오른쪽 끝, 최솟값은 왼쪽 끝의 값이므로

\[U - L = \sum_{i=1}^n[f(x_i) - f(x_{i-1})]\frac{b - a}{n} = \frac{b - a}{n}[f(b) - f(a)].\]

이것은 \(n\)을 키우면 \(\varepsilon\)보다 작아진다(합이 앞뒤로 지워지는 망원급수). ∎

단조함수는 불연속점이 가산 무한 개일 수 있습니다(예: \(\frac1{n+1} < x \le \frac1n\)에서 \(f(x) = \frac1n\)인 계단). 그래도 적분 가능합니다. 증명에서 진동의 합이 전체 높이 \(f(b) - f(a)\)로 묶이는 것이 핵심입니다.

5.2.3적분의 성질

다음 성질들은 모두 상합·하합의 부등식에서 나옵니다(Rudin 6.12).

  • 선형성: \(f, g \in \mathcal R(\alpha)\)이면 \(\int(cf + g)\,d\alpha = c\int f\,d\alpha + \int g\,d\alpha\).
  • 단조성: \(f \le g\)이면 \(\int f\,d\alpha \le \int g\,d\alpha\). 특히 \(|f| \le M\)이면 \(\left|\int f\,d\alpha\right| \le M[\alpha(b) - \alpha(a)]\).
  • 구간 가법성: \(a < c < b\)이면 \(\int_a^b = \int_a^c + \int_c^b\).
  • 곱과 절댓값: \(f, g \in \mathcal R\)이면 \(fg\), \(|f|\)도 \(\mathcal R\)이고 \(\left|\int f\right| \le \int|f|\).
예제 5.2.3

\(\displaystyle\left|\int_0^1\frac{\sin(100x)}{1 + x^2}\,dx\right| \le \frac\pi4\)임을 보여라.

풀이. 피적분함수는 연속이라 적분 가능하고, \(|\sin(100x)| \le 1\)이므로 \(\left|\frac{\sin100x}{1+x^2}\right| \le \frac{1}{1+x^2}\). 단조성과 \(\left|\int f\right| \le \int|f|\)로 \(\left|\int\right| \le \int_0^1\frac{dx}{1+x^2} = \arctan1 = \frac\pi4\). 실제 값은 약 0.006으로 훨씬 작습니다(빠른 진동이 서로 지움, 6단원 리만-르베그와 수학15).

주의"적분 가능한 함수의 합성은 적분 가능하다"는 일반적으로 틀립니다. 연속함수 \(\varphi\)와 적분 가능한 \(f\)의 합성 \(\varphi\circ f\)는 적분 가능하지만(Rudin 6.11), 적분 가능한 함수끼리의 합성은 아닐 수 있습니다: 토매 함수(적분 가능)에 \(\varphi(t) = 1\) (\(t \ne 0\)), \(\varphi(0) = 0\)(적분 가능)을 합성하면 디리클레 함수가 됩니다.
요약
  1. 연속함수는 적분 가능: 균등연속으로 모든 조각의 진동을 한꺼번에 누른다.
  2. 단조함수는 적분 가능: 진동의 합이 전체 높이로 묶인다.
  3. 적분은 선형, 단조, 구간 가법적이고, \(\left|\int f\right| \le \int|f|\).

5.2.4연습문제

기본

  1. \(f(x) = \lfloor 3x\rfloor\)는 \([0, 1]\)에서 적분 가능한가? 값은?
    답

    증가함수라 적분 가능. 값 \(0\cdot\frac13 + 1\cdot\frac13 + 2\cdot\frac13 + 3\cdot0 = 1\).

응용

  1. \(f\)가 \([a, b]\)에서 연속이고 \(f \ge 0\), \(\int_a^bf = 0\)이면 \(f = 0\)임을 보여라.
    답

    \(f(c) > 0\)이면 연속성으로 \(c\) 근처의 길이 \(\ell > 0\)인 구간에서 \(f > \frac{f(c)}2\)라 \(\int f \ge \frac{f(c)}2\ell > 0\). 모순.

심화

  1. 적분 가능한 \(f, g\)에 대해 \(\left(\int fg\right)^2 \le \int f^2\int g^2\)(코시-슈바르츠)를 증명하여라.
    답

    모든 \(t\)에서 \(\int(f - tg)^2 \ge 0\)을 전개해 판별식(선형대수(1) 7.1절과 같은 논법).

5.2.2

예제정의로 적분 계산하기: x²의 상합과 하합

예제 · 리만 조건으로 값까지

다루는 성취기준 [수학7-05-02]

먼저 예측

\(\int_0^1x^2\,dx = \frac13\)은 고교에서 미적분의 기본정리로 구했습니다. 기본정리 없이 상합과 하합만으로 이 값을 얻을 수 있을까요?

예측 확인

있습니다. \(n\)등분 분할의 상합과 하합을 정확히 계산하면 둘 다 \(\frac13\)로 수렴합니다.

\(f(x) = x^2\)의 \([0, 1]\) \(n\)등분 분할에 대한 \(U_n, L_n\)을 구하고, \(f \in \mathcal R\)이며 \(\int_0^1x^2\,dx = \frac13\)임을 보여라.

전략

증가함수라 각 조각의 최댓값은 오른쪽 끝, 최솟값은 왼쪽 끝에서의 값입니다(5.2절). 제곱의 합 공식 \(\sum_{k=1}^nk^2 = \frac{n(n+1)(2n+1)}6\)을 씁니다.

풀이

  1. \(U_n = \sum_{k=1}^n\left(\frac kn\right)^2\frac1n = \frac{n(n+1)(2n+1)}{6n^3}\).
    조각 \([\frac{k-1}n, \frac kn]\)의 최댓값 \((\frac kn)^2\).
  2. \(L_n = \sum_{k=1}^n\left(\frac{k-1}n\right)^2\frac1n = \frac{(n-1)n(2n-1)}{6n^3}\).
    최솟값 \((\frac{k-1}n)^2\), 합은 \(0^2 + \dots + (n-1)^2\).
  3. \(U_n - L_n = \frac1n\).
    \(U_n - L_n = \frac{1}{n^3}\cdot n^2 = \frac1n\) (마지막 항 \(n^2\)만 남음).
  4. \(\frac1n < \varepsilon\)인 \(n\)이 있으므로 리만 조건으로 적분 가능하다.
    정리 5.1.3, 아르키메데스 성질.
  5. \(L_n \le \int \le U_n\)이고 \(U_n, L_n \to \frac{2}{6} = \frac13\)이므로 \(\int_0^1x^2\,dx = \frac13\).
    압축 정리. 최고차항의 비 \(\frac{2n^3}{6n^3}\).

검산

\(n = 10\)이면 \(U = 0.385\), \(L = 0.285\)이고 \(\frac13 \approx 0.333\)이 그 사이에 있습니다. 미적분의 기본정리(다음 절)로 \(\left[\frac{x^3}3\right]_0^1 = \frac13\)과도 같습니다.

의미

정의만으로 적분을 계산하려면 이렇게 합 공식이 필요해 일반 함수에서는 거의 불가능합니다. 그래서 다음 절의 미적분학 기본정리가 "적분을 미분의 역으로 계산할 수 있다"고 말해 주는 것이 결정적입니다.

이해 확인

같은 방법으로 \(\int_0^1x\,dx\)의 \(U_n - L_n\)은?

답

\(\frac1n\). 증가함수의 \(n\)등분에서 \(U - L = \frac{b-a}{n}[f(b) - f(a)] = \frac1n\).
