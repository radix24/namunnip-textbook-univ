2.2.1극한을 모르고 수렴을 판정하기

\(1 + \frac1{2^2} + \frac1{3^2} + \cdots\)의 부분합은 수렴할까요? 극한(\(\frac{\pi^2}6\))을 모르면 ε-N 정의를 쓸 수 없습니다. 극한값 없이 수열 자신의 항들만 보고 수렴을 판정하는 기준이 필요합니다. 그것이 "먼 항들끼리 서로 가까워진다"는 코시의 조건입니다.

2.2.2부분수열과 볼차노-바이어슈트라스

부분수열: 번호 \(n_1 < n_2 < \cdots\)을 골라 만든 수열 \((p_{n_k})\). 원래 수열이 \(p\)로 수렴하면 모든 부분수열도 \(p\)로 수렴합니다.

정리 2.2.1 (볼차노-바이어슈트라스)

\(\mathbb R^n\)의 유계 수열은 수렴하는 부분수열을 가진다.

증명.항이 유한 개의 값만 가지면 어떤 값이 무한히 자주 나오므로 그 값을 반복하는 부분수열을 잡는다. 아니면 값의 집합 \(E\)는 무한집합이고 유계라 닫힌 상자 \(K\) 안에 있다. \(K\)는 컴팩트이므로(하이네-보렐) \(E\)는 극한점 \(p\)를 가진다(정리 1.3.3). 각 \(k\)에 대해 \(B_{1/k}(p)\)에는 \(E\)의 점이 무한히 많으므로 \(n_k > n_{k-1}\)이고 \(d(p_{n_k}, p) < \frac1k\)인 번호를 고를 수 있다. 그러면 \(p_{n_k} \to p\). ∎

2.2.3코시 수열

정의 2.2.2 (코시 수열)

모든 \(\varepsilon > 0\)에 대해 \(N\)이 있어 \(m, n \ge N\)이면 \(d(p_m, p_n) < \varepsilon\)인 수열을 코시 수열이라 한다.

수렴의 정의에서 극한 \(p\) 자리에 "다른 항 \(p_m\)"을 넣은 것입니다. 이웃한 항만이 아니라 \(N\) 이후의 모든 두 항이 가까워야 합니다. 그래서 \(\sqrt n\)은 코시 수열이 아닙니다(\(\sqrt{4n} - \sqrt n = \sqrt n\)은 커짐).

정리 2.2.3

(a) 거리공간에서 수렴하는 수열은 코시 수열이다. (b) \(\mathbb R^n\)에서 코시 수열은 수렴한다.

증명.(a) \(p_n \to p\)이면 \(n \ge N\)에서 \(d(p_n, p) < \varepsilon/2\)이고, \(m, n \ge N\)이면 \(d(p_m, p_n) \le d(p_m, p) + d(p, p_n) < \varepsilon\). (b) 세 단계로 한다. ① 코시 수열은 유계다(\(\varepsilon = 1\)로 \(N\) 이후는 \(p_N\)에서 1 이내, 그 앞은 유한 개). ② 볼차노-바이어슈트라스로 \(p_{n_k} \to p\)인 부분수열이 있다. ③ 수열 전체가 \(p\)로 간다: \(\varepsilon > 0\)에 대해 \(m, n \ge N\)이면 \(d(p_m, p_n) < \varepsilon/2\)인 \(N\)을 잡고, \(n_k \ge N\)이고 \(d(p_{n_k}, p) < \varepsilon/2\)인 \(k\)를 고르면 \(n \ge N\)에서 \(d(p_n, p) \le d(p_n, p_{n_k}) + d(p_{n_k}, p) < \varepsilon\). ∎

완비 거리공간: 모든 코시 수열이 그 공간 안에서 수렴하는 공간. \(\mathbb R^n\)은 완비이고, \(\mathbb Q\)는 완비가 아닙니다(\(\sqrt2\)의 소수 근삿값 1, 1.4, 1.41, …은 \(\mathbb Q\)의 코시 수열이지만 \(\mathbb Q\)에 극한이 없음). 1.1절의 완비성 공리와 같은 "구멍 없음"을 수열로 말한 것입니다.

예제 2.2.4

\(s_n = \sum_{k=1}^n\frac{1}{k^2}\)이 수렴함을 코시 조건으로 보여라.

풀이. \(m > n\)이면 \(\frac1{k^2} < \frac1{k(k-1)} = \frac1{k-1} - \frac1k\)이므로

\[0 < s_m - s_n = \sum_{k=n+1}^m\frac1{k^2} < \sum_{k=n+1}^m\left(\frac1{k-1} - \frac1k\right) = \frac1n - \frac1m < \frac1n.\]

\(N > \frac1\varepsilon\)이면 \(m > n \ge N\)에서 \(|s_m - s_n| < \varepsilon\). 코시 수열이므로 수렴합니다(극한값은 몰라도 됩니다). 반면 \(\sum\frac1k\)은 \(s_{2n} - s_n \ge n\cdot\frac1{2n} = \frac12\)이라 코시 수열이 아니고 발산합니다.

완비성은 6~7단원에서 결정적입니다. 함수공간 \(C[a, b]\)도 상한 거리로 완비라는 사실(균등수렴의 코시 판정)이 축소사상 원리(7.3절)와 미분방정식 해의 존재를 떠받칩니다.

주의코시 조건은 \(m, n\)이 둘 다 \(N\) 이상이기만 하면 됩니다. "\(m = n + 1\)일 때만" 확인하면 부족합니다(2.1절의 주의). 반대로 \(|p_{n+1} - p_n| \le r^n\) (\(0 < r < 1\))처럼 이웃 차가 기하급수적으로 줄면, 등비급수의 합으로 모든 먼 차를 누를 수 있어 코시 수열이 됩니다.
요약
  1. 볼차노-바이어슈트라스: \(\mathbb R^n\)의 유계 수열은 수렴하는 부분수열을 가진다.
  2. 코시 수열: 먼 항들끼리 서로 가까워진다. 극한값 없이 판정한다.
  3. 수렴 ⇒ 코시는 어디서나, 코시 ⇒ 수렴은 완비 공간(\(\mathbb R^n\))에서만.

2.2.4연습문제

기본

  1. \(a_n = \frac1n\)이 코시 수열임을 정의로 보여라.
    답

    \(|\frac1m - \frac1n| < \max(\frac1m, \frac1n) \le \frac1N\). \(N > \frac1\varepsilon\).

응용

  1. \(|a_{n+1} - a_n| \le \frac{1}{2^n}\)이면 \((a_n)\)은 수렴함을 보여라.
    답

    \(m > n\)이면 \(|a_m - a_n| \le \sum_{k=n}^{m-1}2^{-k} < 2^{1-n}\). 코시 수열이고 \(\mathbb R\)이 완비.

  2. \((0, 1)\)에 보통 거리를 주면 완비가 아님을 보여라.
    답

    \(\frac1n\)은 코시 수열이지만 극한 0이 \((0, 1)\)에 없다.

심화

  1. 모든 실수열은 단조인 부분수열을 가짐을 보이고(꼭대기 점 논법), 이로써 \(\mathbb R\)의 볼차노-바이어슈트라스 정리를 다시 증명하여라.
    답

    \(a_m \ge a_n\) (\(n > m\))인 \(m\)을 꼭대기라 하자. 꼭대기가 무한히 많으면 그것들이 감소 부분수열. 유한하면 마지막 꼭대기 뒤의 항에서 출발해 늘 더 큰 뒤 항을 고를 수 있어 증가 부분수열. 유계 단조 부분수열은 단조수렴 정리로 수렴.

2.2.2

탐구극한을 몰라도 수렴을 알아보는 법

탐구 · 코시 조건의 띠

다루는 성취기준 [수학7-02-02]

질문

\(\sum\frac1{k^2}\)과 \(\sum\frac1k\)의 부분합은 둘 다 증가하고 이웃한 항의 차가 0으로 갑니다. 그런데 하나는 수렴하고 하나는 발산합니다. 극한값을 모른 채 그 차이를 그림에서 볼 수 있을까요?

복원

코시 수열: 모든 \(\varepsilon\)에 대해 \(N\)이 있어 \(m, n \ge N\)이면 \(|s_m - s_n| < \varepsilon\). \(\mathbb R\)에서는 코시 ⇔ 수렴 (2.2절).

해 보기

  1. \(\sum\frac1{k^2}\)에서 N을 10, 20, 40, 80으로 늘리면 노란 띠의 폭은 약 0.071, 0.036, 0.019, 0.0093으로 반씩 줄어듭니다(대략 \(\frac{3}{4N}\)).
  2. \(\sum\frac1k\)로 바꾸면 띠의 폭이 N과 상관없이 1.35~1.38 근처(\(\ln 4 \approx 1.386\)에 다가감)에 머뭅니다. 먼 항들이 서로 가까워지지 않으니 코시 수열이 아닙니다.
  3. \(\sum\frac{(-1)^{k+1}}{k}\)은 부분합이 위아래로 흔들리지만 띠는 좁아집니다. 증가하지 않아도 코시 수열일 수 있습니다.
  4. 등비급수 \(\sum 0.8^k\)은 띠가 아주 빨리 좁아집니다.

설명

  1. 그림의 한계카드는 \(N\)부터 \(4N\)까지만 봅니다. 코시 조건은 \(N\) 이후 모든 \(m, n\)에 대한 것이라, 증명에는 본문 예제 2.2.4처럼 모든 \(m > n\)에 통하는 부등식(\(s_m - s_n < \frac1n\))이 필요합니다.
  2. ln 4의 이유\(\sum_{k=N+1}^{4N}\frac1k \approx \int_N^{4N}\frac{dx}{x} = \ln 4\). 구간의 비가 같으면 조화급수의 조각 합은 줄지 않습니다.

판단

"부분합이 증가하고 그래프가 점점 평평해지니 수렴한다"는 틀립니다. 조화급수의 부분합 그래프도 점점 평평해 보이지만 \(\ln n\)처럼 끝없이 자랍니다. 평평함(이웃 차)이 아니라 띠의 폭(먼 항끼리의 차)을 봐야 합니다.
