6.2.1극한의 순서를 바꾸는 문제

"연속함수의 극한은 연속인가?"는 \(\lim_{x\to p}\lim_{n\to\infty}f_n(x) = \lim_{n\to\infty}\lim_{x\to p}f_n(x)\)인가, 곧 두 극한의 순서를 바꿀 수 있는가의 문제입니다. 적분과 극한, 미분과 극한도 마찬가지입니다. 점별수렴만으로는 순서를 바꿀 수 없고(6.1절의 \(x^n\)), 균등수렴이 대부분의 경우를 해결합니다.

6.2.2연속성

정리 6.2.1

연속함수 \(f_n\)이 \(E\)에서 \(f\)로 균등수렴하면 \(f\)는 연속이다.

증명.\(p \in E\), \(\varepsilon > 0\)이라 하자. 균등수렴으로 모든 \(x\)에서 \(|f_N(x) - f(x)| < \frac\varepsilon3\)인 \(N\)을 고정하고, \(f_N\)의 \(p\)에서의 연속성으로 \(d(x, p) < \delta\)이면 \(|f_N(x) - f_N(p)| < \frac\varepsilon3\)인 \(\delta\)를 잡는다. 그러면 \(d(x, p) < \delta\)에서

\[|f(x) - f(p)| \le |f(x) - f_N(x)| + |f_N(x) - f_N(p)| + |f_N(p) - f(p)| < \tfrac\varepsilon3 + \tfrac\varepsilon3 + \tfrac\varepsilon3.\]

∎

첫째 항에서 균등수렴을 씁니다. \(x\)가 \(\delta\)에 따라 움직이는 점이라, 점별수렴이면 \(N\)을 \(x\)보다 먼저 고정할 수 없습니다. 같은 절의 증명 카드에 초안과 단계별 근거가 있습니다.

6.2.3적분

정리 6.2.2

\(f_n \in \mathcal R\)이 \([a, b]\)에서 \(f\)로 균등수렴하면 \(f \in \mathcal R\)이고 \(\int_a^bf = \lim\int_a^bf_n\).

증명.\(\varepsilon_n = \sup|f_n - f| \to 0\)으로 두자. \(f_n - \varepsilon_n \le f \le f_n + \varepsilon_n\)이므로 \(f\)의 상적분과 하적분은 \(\int f_n\)에서 \(\varepsilon_n(b - a)\) 이내에 있다. 따라서 상적분 − 하적분 \(\le 2\varepsilon_n(b - a) \to 0\)이라 \(f\)는 적분 가능하고, \(\left|\int f - \int f_n\right| \le \varepsilon_n(b - a) \to 0\). ∎

점별수렴만이면 깨집니다: \(h_n(x) = n^2xe^{-nx}\)는 \([0, 1]\)에서 0으로 점별수렴하지만 \(\int_0^1h_n = 1 - (n + 1)e^{-n} \to 1 \ne 0\). 봉우리가 높아지고 좁아지며 넓이 1을 유지한 채 원점으로 몰립니다.

6.2.4미분은 더 까다롭다

정리 6.2.3

\([a, b]\)에서 미분 가능한 \(f_n\)이 어떤 한 점에서 수렴하고, \(f_n'\)이 균등수렴하면, \(f_n\)은 어떤 \(f\)로 균등수렴하고 \(f' = \lim f_n'\)이다.

요구되는 것은 \(f_n\)이 아니라 도함수 \(f_n'\)의 균등수렴입니다. 6.1절 연습 3의 \(\frac{\sin nx}{\sqrt n}\)은 균등수렴하지만 도함수가 발산합니다. 증명은 평균값 정리로 \(|[f_n(x) - f_m(x)] - [f_n(t) - f_m(t)]| \le |x - t|\sup|f_n' - f_m'|\)를 얻어 균등 코시를 보이는 것입니다(Rudin 7.17). 도함수가 연속이라면 더 간단히, \(f_n(x) = f_n(a) + \int_a^xf_n'\)에 정리 6.2.2를 쓰면 됩니다.

주의균등수렴은 연속성과 적분을 보존하는 충분조건이지 필요조건이 아닙니다. 6.1절의 \(nxe^{-nx}\)는 균등수렴하지 않지만 극한 0은 연속이고, \(\int_0^1nxe^{-nx}dx \to 0\)으로 적분의 극한도 맞습니다. 균등수렴이 깨졌다고 결론이 반드시 깨지는 것은 아닙니다.
요약
  1. 연속함수의 균등극한은 연속(ε/3 논법).
  2. 균등수렴하면 \(\int\lim = \lim\int\).
  3. 미분과 극한의 교환에는 도함수의 균등수렴(과 한 점에서의 수렴)이 필요하다.

6.2.5연습문제

기본

  1. \(\lim_{n\to\infty}\int_0^1\frac{x^n}{1 + x}\,dx\)를 구하여라. (균등수렴하지 않으니 직접 어림)
    답

    \(0 \le \int\frac{x^n}{1+x} \le \int x^n = \frac{1}{n+1} \to 0\).

응용

  1. \(h_n(x) = n^2xe^{-nx}\)의 \(\int_0^1h_n\)을 계산해 \(1 - (n+1)e^{-n}\)임을 확인하여라.
    답

    \(u = nx\)로 치환하면 \(\int_0^nue^{-u}du = 1 - (n + 1)e^{-n}\).

심화

  1. 거듭제곱급수 \(\sum x^n = \frac1{1-x}\) (\(|x| < 1\))를 항별로 적분해 \(\ln(1 + t)\)의 급수를 얻고, 그 근거를 말하여라.
    답

    \(\frac{1}{1 + x} = \sum(-1)^nx^n\)이 \([0, t]\) (\(t < 1\))에서 균등수렴(M-판정, \(t^n\))하므로 항별 적분: \(\ln(1 + t) = \sum(-1)^n\frac{t^{n+1}}{n+1}\).

  1. 균등수렴이 연속성과 적분을 보존함을 증명할 수 있다.

6.2.2

증명연속함수의 균등극한은 연속이다

증명 · ε/3 논법, 초안에서 정리된 증명까지

다루는 성취기준 [수학7-06-02]

정리

\(E \subseteq \mathbb R\) 위의 함수열 \(f_n\)이 모두 점 \(a \in E\)에서 연속이고 \(E\)에서 \(f\)로 균등수렴하면, \(f\)도 \(a\)에서 연속이다.

쓰는 것

  • 연속의 정의: 모든 \(\varepsilon > 0\)에 대해 \(\delta > 0\)이 있어 \(x \in E,\ |x - a| < \delta\)이면 \(|f(x) - f(a)| < \varepsilon\).
  • 균등수렴의 정의: 모든 \(\varepsilon > 0\)에 대해 \(N\)이 있어 \(n \ge N\)이면 모든 \(x \in E\)에서 \(|f_n(x) - f(x)| < \varepsilon\) (탐구 카드의 "관").
  • 삼각부등식: \(|p + q + r| \le |p| + |q| + |r|\).

아이디어

\(f(x) - f(a)\)를 직접 다룰 수는 없지만, 연속인 \(f_n\)을 사이에 끼우면 세 조각으로 나뉩니다.

\[f(x) - f(a) = \underbrace{[f(x) - f_n(x)]}_{\text{균등수렴}} + \underbrace{[f_n(x) - f_n(a)]}_{f_n\text{의 연속}} + \underbrace{[f_n(a) - f(a)]}_{\text{균등수렴}}\]

세 조각을 각각 \(\varepsilon/3\)보다 작게 만들면 합이 \(\varepsilon\)보다 작습니다. 핵심은 첫 조각입니다. \(x\)가 움직이는 점이라 "그 점에서만" 가까우면 소용이 없고, 모든 \(x\)에서 한꺼번에 가까워야 합니다. 바로 균등수렴이 주는 것입니다.

초안: 무엇을 어떤 순서로 고르나

  1. 먼저 \(n\)을 하나 고정해야 합니다. 둘째 조각의 \(\delta\)가 \(n\)에 따라 달라지므로, \(n\)을 정하기 전에는 \(\delta\)를 고를 수 없습니다.
    고르는 순서: ε → N (그리고 n 하나) → δ.
  2. \(n\)은 첫째·셋째 조각이 \(\varepsilon/3\)보다 작게 되도록, 균등수렴의 \(N\)으로 고릅니다. 그러면 \(x\)가 어디에 있든 첫째 조각이 작습니다.
    균등수렴은 x와 상관없는 N을 준다. 점별수렴이면 N이 x에 따라 달라져 여기서 막힌다.
  3. 이제 고정된 \(f_n\)의 연속성으로 둘째 조각을 \(\varepsilon/3\)보다 작게 하는 \(\delta\)를 고릅니다.
    \(f_n\)이 a에서 연속(가정).

정리된 증명

  1. \(\varepsilon > 0\)이 주어졌다고 하자.
    연속의 정의를 확인하려면 임의의 ε에 대해 δ를 내놓아야 한다.
  2. \(f_n \to f\)가 \(E\)에서 균등수렴하므로, 어떤 \(N\)이 있어 \(n \ge N\)이면 모든 \(x \in E\)에 대해 \(|f_n(x) - f(x)| < \varepsilon/3\)이다. \(n = N\)으로 고정한다.
    균등수렴의 정의를 ε/3에 적용. N 하나로 모든 x를 덮는다.
  3. \(f_N\)이 \(a\)에서 연속이므로, 어떤 \(\delta > 0\)이 있어 \(x \in E,\ |x - a| < \delta\)이면 \(|f_N(x) - f_N(a)| < \varepsilon/3\)이다.
    연속의 정의를 ε/3에 적용. δ는 N에 따라 정해지지만 N은 이미 고정했다.
  4. \(x \in E,\ |x - a| < \delta\)라 하자. 2단계를 \(x\)와 \(a\)에 각각 쓰면 \(|f(x) - f_N(x)| < \varepsilon/3\), \(|f_N(a) - f(a)| < \varepsilon/3\)이다.
    2단계는 모든 x에서 성립하므로 이 x에서도, 그리고 a에서도 성립한다. 이것이 균등수렴을 쓴 자리다.
  5. 삼각부등식으로 \(|f(x) - f(a)| \le |f(x) - f_N(x)| + |f_N(x) - f_N(a)| + |f_N(a) - f(a)| < \frac\varepsilon3 + \frac\varepsilon3 + \frac\varepsilon3 = \varepsilon\). 따라서 \(f\)는 \(a\)에서 연속이다.
    아이디어의 세 조각 분해와 3, 4단계의 세 부등식.

되짚기

  • 균등수렴은 4단계에서 썼습니다. 점별수렴만 있으면 2단계의 \(N\)이 \(x\)마다 달라지고, 움직이는 \(x\)에 대해 한 번에 고정할 \(n\)이 없습니다. 반례: \([0, 1]\)에서 \(f_n(x) = x^n\)은 모두 연속이지만 점별극한은 \(x = 1\)에서 불연속입니다.
  • \(f_n\)의 연속성은 3단계에서 썼습니다. \(f_n\) 중 하나라도(정확히는 \(f_N\)이) 연속이 아니면 둘째 조각을 누를 수 없습니다.
  • ε/3인 이유는 조각이 셋이기 때문일 뿐입니다. 각 조각을 ε보다 작게 해도 증명은 되지만 결론이 "3ε보다 작다"가 되어 한 번 더 바꿔 말해야 합니다.

더 나아가기

같은 생각으로 "균등수렴하면 적분과 극한의 순서를 바꿀 수 있다"(\(\int_a^b f_n \to \int_a^b f\))를 보입니다. \(|\int f_n - \int f| \le (b-a)\sup|f_n - f|\)이기 때문입니다. 미분은 다릅니다. 도함수가 균등수렴해야 극한과 미분의 순서를 바꿀 수 있습니다.

직접 써 보기

\(f_n\)이 모두 \(E\)에서 유계이고 \(f\)로 균등수렴하면 \(f\)도 \(E\)에서 유계임을 증명하세요.

힌트

ε = 1로 균등수렴의 정의를 쓰고 \(f_N\) 하나의 한계를 빌려 오세요.

답안

균등수렴의 정의를 \(\varepsilon = 1\)에 쓰면 어떤 \(N\)이 있어 모든 \(x \in E\)에서 \(|f_N(x) - f(x)| < 1\)이다. \(f_N\)이 유계이므로 모든 \(x\)에서 \(|f_N(x)| \le M\)인 \(M\)이 있다. 그러면 삼각부등식으로 \(|f(x)| \le |f(x) - f_N(x)| + |f_N(x)| < 1 + M\)이 모든 \(x \in E\)에서 성립한다. ∎
