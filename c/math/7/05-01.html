5.1.1넓이를 위아래에서 조이기

공통1에서는 리만 합 \(\sum f(x_i^*)\Delta x_i\)의 극한으로 적분을 정의했습니다. 이 정의는 표본점 \(x_i^*\)를 고르는 방법이 무한히 많아 다루기 까다롭습니다. 다르부(Darboux)의 방법은 각 조각에서 가장 큰 값과 가장 작은 값을 써서 넓이를 위아래에서 조입니다. 위 어림과 아래 어림이 한 값으로 모이면 그 값이 넓이입니다.

분할 \(P = \{a = x_0 < x_1 < \dots < x_n = b\}\). \(\Delta\alpha_i = \alpha(x_i) - \alpha(x_{i-1})\)로 둡니다(\(\alpha\)는 증가함수, 보통의 적분은 \(\alpha(x) = x\)).

상합 \(U(P, f, \alpha) = \sum M_i\Delta\alpha_i\), \(M_i = \sup_{[x_{i-1}, x_i]}f\).

하합 \(L(P, f, \alpha) = \sum m_i\Delta\alpha_i\), \(m_i = \inf_{[x_{i-1}, x_i]}f\).

\(f\)는 유계라고 가정합니다(상한과 하한이 있어야 하므로). 늘 \(L \le U\)입니다.

5.1.2세분과 적분의 정의

정리 5.1.1 (세분)

\(P^*\)가 \(P\)에 점을 보탠 분할(세분)이면 \(L(P, f, \alpha) \le L(P^*, f, \alpha)\), \(U(P^*, f, \alpha) \le U(P, f, \alpha)\).

증명.점 하나 \(y\)를 \([x_{i-1}, x_i]\)에 보탠 경우만 보면 된다. 하합에서 그 조각의 기여 \(m_i\Delta\alpha_i\)가 두 조각 \(w_1[\alpha(y) - \alpha(x_{i-1})] + w_2[\alpha(x_i) - \alpha(y)]\)로 바뀐다(\(w_1, w_2\)는 각 작은 조각의 하한). 작은 집합의 하한은 큰 집합의 하한 이상이므로 \(w_1, w_2 \ge m_i\)이고, 따라서 기여가 늘거나 같다. 상합도 같다. ∎

두 분할 \(P_1, P_2\)를 합친 공통 세분을 쓰면 \(L(P_1) \le L(P_1\cup P_2) \le U(P_1\cup P_2) \le U(P_2)\)입니다. 곧 모든 하합은 모든 상합 이하입니다. 그래서 하합들의 상한과 상합들의 하한을 비교할 수 있습니다.

정의 5.1.2 (리만-스틸체스 적분)

하적분 \(\underline{\int} = \sup_PL(P, f, \alpha)\)와 상적분 \(\overline{\int} = \inf_PU(P, f, \alpha)\)가 같으면 \(f\)는 \(\alpha\)에 대해 적분 가능하다고 하고(\(f \in \mathcal R(\alpha)\)), 그 값을 \(\int_a^bf\,d\alpha\)로 쓴다.

5.1.3리만 조건

정리 5.1.3 (리만 조건)

\(f \in \mathcal R(\alpha)\) ⇔ 모든 \(\varepsilon > 0\)에 대해 \(U(P, f, \alpha) - L(P, f, \alpha) < \varepsilon\)인 분할 \(P\)가 있다.

증명.(⇐) 늘 \(L(P) \le \underline\int \le \overline\int \le U(P)\)이므로 \(0 \le \overline\int - \underline\int < \varepsilon\). \(\varepsilon\)이 임의이므로 같다. (⇒) 공통값 \(I\)에 대해 상한·하한의 성질로 \(U(P_1) < I + \frac\varepsilon2\), \(L(P_2) > I - \frac\varepsilon2\)인 분할이 있다. 공통 세분 \(P\)에서 \(U(P) - L(P) \le U(P_1) - L(P_2) < \varepsilon\). ∎

이 판정법이 적분 가능성을 증명하는 기본 도구입니다. "조각마다의 진동 \(M_i - m_i\)에 조각 크기를 곱해 더한 것이 작게 되는 분할"을 찾으면 됩니다.

예제 5.1.4

(a) 디리클레 함수 \(D(x) = 1\) (유리수), \(0\) (무리수)는 \([0, 1]\)에서 리만 적분 가능하지 않다. (b) \(\alpha\)가 \(x = c\)에서 1만큼 뛰는 계단함수이면 연속인 \(f\)에 대해 \(\int f\,d\alpha = f(c)\)이다.

풀이. (a) 어느 조각에나 유리수와 무리수가 있어 \(M_i = 1\), \(m_i = 0\)이므로 모든 분할에서 \(U = 1\), \(L = 0\)입니다. (b) \(c\)를 포함하는 조각에서만 \(\Delta\alpha_i = 1\)이고 나머지는 0이라, 상합과 하합은 그 조각의 \(\sup f\)와 \(\inf f\)입니다. 조각을 줄이면 \(f\)의 연속성으로 둘 다 \(f(c)\)로 갑니다. 스틸체스 적분은 "점에 몰린 질량"을 다룰 수 있어, 확률론에서 이산 분포와 연속 분포를 한 식 \(E[X] = \int x\,dF(x)\)로 쓰는 데 쓰입니다.

주의"리만 합이 어떤 특정한 표본점(예: 왼쪽 끝점)에서 수렴하면 적분 가능하다"는 틀립니다. 디리클레 함수는 표본점을 모두 유리수로 고르면 리만 합이 늘 1이지만 적분 가능하지 않습니다. 적분 가능성은 모든 표본 선택에 대해, 곧 상합과 하합이 함께 모일 때입니다.
요약
  1. 상합·하합은 조각마다 최대·최소로 넓이를 위아래에서 어림한다.
  2. 세분하면 상합은 줄고 하합은 는다. 모든 하합 ≤ 모든 상합.
  3. 적분 가능 ⇔ 상적분 = 하적분 ⇔ \(U - L < \varepsilon\)인 분할이 있다(리만 조건).
  4. 적분기 \(\alpha\)가 뛰면 그 점의 함숫값이 적분에 들어간다(스틸체스).

5.1.4연습문제

기본

  1. \(f(x) = x\)의 \([0, 1]\) 등분할 \(P_n\)에 대한 \(U - L\)을 구하고 적분 가능함을 보여라.
    답

    \(U - L = \sum\frac1n\cdot\frac1n = \frac1n \to 0\).

응용

  1. \(\alpha(x) = x^2\)일 때 \(\int_0^1x\,d\alpha\)를 구하여라.
    힌트

    \(\alpha\)가 미분 가능하면 \(\int f\,d\alpha = \int f\alpha'\,dx\).

    답

    \(\int_0^1x\cdot2x\,dx = \frac23\).

  2. \([0, 1]\)에서 \(f(x) = 0\) (\(x \ne \frac12\)), \(f(\frac12) = 5\)는 적분 가능하고 적분이 0임을 보여라.
    답

    \(\frac12\)을 담는 조각의 길이를 \(\delta\)로 하면 \(U = 5\delta\), \(L = 0\). \(\delta < \frac\varepsilon5\).

심화

  1. \(\alpha\)가 \(x = \frac12\)에서 뛰는 계단함수이고 \(f\)도 \(\frac12\)에서 불연속이면 \(\int f\,d\alpha\)가 존재하지 않을 수 있음을 예로 보여라.
    답

    \(\alpha = 0\) (\(x < \frac12\)), \(1\) (\(x \ge \frac12\)), \(f = \alpha\). \(\frac12\)을 담는 조각은 \([x_{i-1}, x_i]\)이고 \(\Delta\alpha = 1\), \(\sup f = 1\), \(\inf f = 0\) (\(x_{i-1} < \frac12\)일 때). \(\frac12\)이 분할점이면 왼쪽 조각 \([x_{i-1}, \frac12]\)에서 \(\Delta\alpha = 1\), \(M = 1\), \(m = 0\). 늘 \(U - L = 1\).

5.1.2

탐구위아래에서 조이면 넓이가 정해지는가

탐구 · 상합과 하합, 리만 조건

다루는 성취기준 [수학7-05-01]

질문

각 조각에서 가장 큰 값으로 만든 직사각형(상합)과 가장 작은 값으로 만든 직사각형(하합)을 그립니다. 조각을 잘게 나누면 두 어림 사이의 틈이 0으로 줄어들까요? 함수에 따라 다를까요?

복원

리만 조건: \(f\)가 적분 가능 ⇔ \(U(P) - L(P) < \varepsilon\)인 분할이 있다 (5.1절).

해 보기

  1. 연속함수에서 n을 늘리면 빨간 틈이 고르게 얇아지고 \(U - L\)이 \(\frac1n\)에 비례해 줄어듭니다.
  2. 계단함수는 점프를 담은 조각 하나에서만 틈이 생겨 \(U - L = \frac1n\)입니다. 불연속점이 있어도 적분 가능합니다.
  3. 토매 함수는 불연속점이 조밀한데도 n을 늘리면 \(U - L\)(= \(U\))이 0으로 갑니다. 높이 \(\frac1q\)가 큰 점은 드물기 때문입니다(3.1절 예제 카드).
  4. 디리클레 함수는 n을 아무리 늘려도 \(U = 1\), \(L = 0\)입니다. 적분 가능하지 않습니다.

설명

  1. 틈 = 진동 × 폭\(U - L = \sum(M_i - m_i)\Delta x_i\)입니다. 진동이 큰 조각이 있어도 그 폭의 합이 작으면 틈이 작습니다. 계단과 토매 함수가 그렇습니다.
  2. 불연속점이 "적으면" 적분 가능르베그의 판정: 유계 함수가 리만 적분 가능 ⇔ 불연속점의 집합의 길이(측도)가 0. 토매 함수의 불연속점(유리수)은 가산이라 길이가 0이고, 디리클레 함수는 모든 점이 불연속입니다.

판단

"불연속점이 조밀하면 적분 가능하지 않다"는 틀립니다. 토매 함수는 유리수 전체에서 불연속이지만 적분 가능하고 적분값이 0입니다. 중요한 것은 불연속점이 얼마나 "많은가"(측도)이지 어디에나 있는가가 아닙니다.
