2.4.1급수는 부분합의 수열

\(\sum_{n=1}^\infty a_n\)이 수렴한다는 것은 부분합 \(s_n = a_1 + \dots + a_n\)이 수렴한다는 뜻입니다. 그래서 수열의 도구가 그대로 쓰입니다. 코시 조건을 부분합에 쓰면 다음이 나옵니다.

코시 판정: \(\sum a_n\) 수렴 ⇔ 모든 \(\varepsilon\)에 대해 \(N\)이 있어 \(m \ge n \ge N\)이면 \(|a_n + \dots + a_m| < \varepsilon\).

항의 극한: \(m = n\)으로 두면 수렴하는 급수는 \(a_n \to 0\). 거꾸로는 성립하지 않습니다(\(\sum\frac1n\)).

비교 판정: \(|a_n| \le c_n\)이고 \(\sum c_n\)이 수렴하면 \(\sum a_n\)도 수렴(절대수렴). 코시 판정에서 \(|a_n + \dots + a_m| \le c_n + \dots + c_m\)이기 때문입니다.

비교의 기준으로 가장 많이 쓰는 것이 등비급수 \(\sum x^n\)입니다: \(|x| < 1\)이면 \(\frac{1}{1-x}\)로 수렴, \(|x| \ge 1\)이면 발산. 근 판정법과 비 판정법은 "주어진 급수를 등비급수와 비교하는 자동 장치"입니다.

2.4.2근 판정법

정리 2.4.1 (근 판정법)

\(\alpha = \limsup\sqrt[n]{|a_n|}\)라 하자. \(\alpha < 1\)이면 \(\sum a_n\)은 절대수렴하고, \(\alpha > 1\)이면 발산한다. \(\alpha = 1\)이면 판정할 수 없다.

아이디어: \(\sqrt[n]{|a_n|} \le \beta\)이면 \(|a_n| \le \beta^n\)이라 등비급수와 비교됩니다. 상극한이 1보다 작으면 "결국" 이 부등식이 1보다 작은 \(\beta\)로 성립합니다(2.3절의 성질 (i)).

증명.\(\alpha < 1\)이면 \(\alpha < \beta < 1\)인 \(\beta\)를 잡는다. 상극한의 성질 (i)에 따라 \(n \ge N\)이면 \(\sqrt[n]{|a_n|} < \beta\), 곧 \(|a_n| < \beta^n\)이다. \(\sum\beta^n\)이 수렴하므로 비교 판정으로 \(\sum|a_n|\)이 수렴한다(앞의 유한 개는 수렴에 영향이 없다). \(\alpha > 1\)이면 성질 (ii)에 따라 무한히 많은 \(n\)에서 \(\sqrt[n]{|a_n|} > 1\), 곧 \(|a_n| > 1\)이라 \(a_n \not\to 0\)이고 발산한다. ∎

\(\alpha = 1\)에서 판정할 수 없는 예: \(\sum\frac1n\)(발산)과 \(\sum\frac1{n^2}\)(수렴) 모두 \(\sqrt[n]{n^p} \to 1\)이라 \(\alpha = 1\)입니다.

2.4.3비 판정법

정리 2.4.2 (비 판정법)

\(\limsup\left|\frac{a_{n+1}}{a_n}\right| < 1\)이면 \(\sum a_n\)은 절대수렴한다. \(n \ge N\)인 모든 \(n\)에서 \(\left|\frac{a_{n+1}}{a_n}\right| \ge 1\)이면 발산한다.

증명.상극한이 \(\beta < 1\)보다 작으면 \(n \ge N\)에서 \(|a_{n+1}| < \beta|a_n|\)이고, 되풀이하면 \(|a_{N+k}| < \beta^k|a_N|\). 등비급수와 비교한다. 둘째 진술은 \(|a_n|\)이 \(N\) 이후 감소하지 않아 0으로 가지 않기 때문이다. ∎

발산 쪽의 조건이 근 판정법과 다른 것에 주의하세요. "\(\limsup > 1\)"로는 부족하고 "결국 늘 1 이상"이어야 합니다. 비가 1보다 큰 항과 작은 항이 섞일 수 있기 때문입니다.

2.4.4근 판정법이 더 강하다

일반적으로 \(\liminf\left|\frac{a_{n+1}}{a_n}\right| \le \liminf\sqrt[n]{|a_n|} \le \limsup\sqrt[n]{|a_n|} \le \limsup\left|\frac{a_{n+1}}{a_n}\right|\)이 성립합니다. 그래서 비 판정법이 수렴을 말해 주면 근 판정법도 말해 주지만, 거꾸로는 아닙니다.

예제 2.4.3

\(a_n = 2^{-n}\) (\(n\) 짝수), \(a_n = 3^{-n}\) (\(n\) 홀수)인 급수 \(\frac13 + \frac14 + \frac1{27} + \frac1{16} + \cdots\)에 두 판정법을 적용하여라.

풀이. 근 판정법: \(\sqrt[n]{a_n}\)은 짝수에서 \(\frac12\), 홀수에서 \(\frac13\)이라 상극한 \(\frac12 < 1\), 수렴. 비 판정법: \(n\)이 짝수면 \(\frac{a_{n+1}}{a_n} = \frac{3^{-n-1}}{2^{-n}} = \frac13(\frac23)^n \to 0\), 홀수면 \(\frac{2^{-n-1}}{3^{-n}} = \frac12(\frac32)^n \to \infty\). 상극한이 \(\infty\)라 수렴을 말해 주지 못하고, 결국 늘 1 이상도 아니라 발산도 말해 주지 못합니다. 비 판정법은 이웃한 두 항만 보기 때문에 들쭉날쭉한 수열에 약합니다.

그래도 \(n!\)이나 \(a^n\)이 든 급수(거듭제곱급수, 지수함수의 테일러 급수)에서는 비가 깔끔하게 정리되어 비 판정법이 계산하기 쉽습니다. 거듭제곱급수의 수렴반경 공식 \(\frac1R = \limsup\sqrt[n]{|c_n|}\)(코시-아다마르)이 근 판정법에서 바로 나옵니다.

주의"\(\left|\frac{a_{n+1}}{a_n}\right| < 1\)이 모든 \(n\)에서 성립하면 수렴한다"는 틀립니다. \(\sum\frac1n\)은 \(\frac{n}{n+1} < 1\)이지만 발산합니다. 비가 1보다 작은 고정된 수 \(\beta\)로 눌려야 합니다. 비가 1로 다가가면 판정이 안 됩니다.
요약
  1. 급수의 수렴은 부분합의 수렴. 코시 판정, \(a_n \to 0\)(필요조건), 비교 판정.
  2. 근 판정: \(\limsup\sqrt[n]{|a_n|} < 1\) 수렴, \(> 1\) 발산.
  3. 비 판정: \(\limsup|a_{n+1}/a_n| < 1\) 수렴, 결국 늘 \(\ge 1\)이면 발산.
  4. 근 판정이 더 강하고, 상극한을 쓰면 수열이 들쭉날쭉해도 쓸 수 있다. 1이면 판정 불가.

2.4.5연습문제

기본

  1. \(\sum\frac{n^2}{2^n}\)의 수렴을 비 판정법으로 판정하여라.
    답

    비 \(\frac{(n+1)^2}{2n^2} \to \frac12 < 1\). 수렴.

  2. \(\sum\frac{n!}{n^n}\)의 수렴을 판정하여라.
    답

    비 \(\left(\frac{n}{n+1}\right)^n \to \frac1e < 1\). 수렴.

응용

  1. \(\sum\left(\frac{n}{2n+1}\right)^n\)을 근 판정법으로 판정하여라.
    답

    \(\sqrt[n]{a_n} = \frac{n}{2n+1} \to \frac12\). 수렴.

심화

  1. \(\limsup\sqrt[n]{a_n} \le \limsup\frac{a_{n+1}}{a_n}\) (\(a_n > 0\))을 증명하여라.
    힌트

    오른쪽이 \(\beta\)보다 작으면 \(a_{N+k} \le \beta^ka_N\). 양변에 \(\frac1{N+k}\)제곱근.

    답

    오른쪽 < \(\beta\)이면 \(n \ge N\)에서 \(a_n \le \beta^{n-N}a_N = \beta^n(a_N\beta^{-N})\). \(\sqrt[n]{a_n} \le \beta\sqrt[n]{C} \to \beta\). 따라서 왼쪽 \(\le \beta\), \(\beta\)는 오른쪽보다 큰 임의의 수.

2.4.2

예제거듭제곱급수의 수렴반경을 근 판정법으로

예제 · 코시-아다마르 공식

다루는 성취기준 [수학7-02-04]

먼저 예측

\(\sum_{n=0}^\infty c_nx^n\)에서 계수가 짝수 번째는 \(2^n\), 홀수 번째는 \(1\)입니다. 수렴반경은 \(\frac12\)일까요, 1일까요?

예측 확인

\(\frac12\)입니다. 가장 빨리 자라는 계수들(짝수 번째)이 반경을 정합니다. 상극한이 바로 그것을 고릅니다.

\(c_n = 2^n\) (\(n\) 짝수), \(c_n = 1\) (\(n\) 홀수)일 때 \(\sum c_nx^n\)이 수렴하는 \(x\)의 범위를 구하여라.

전략

\(a_n = c_nx^n\)에 근 판정법을 씁니다. \(\sqrt[n]{|a_n|} = \sqrt[n]{|c_n|}\,|x|\)이므로 상극한은 \(|x|\limsup\sqrt[n]{|c_n|}\)입니다. 비 판정법은 계수가 들쭉날쭉해 쓸 수 없습니다(예제 2.4.3과 같은 상황).

풀이

  1. \(\sqrt[n]{|c_n|}\)은 짝수에서 2, 홀수에서 1이므로 \(\limsup\sqrt[n]{|c_n|} = 2\).
    부분수열 극한은 2와 1이고 상극한은 그중 큰 값(정리 2.3.3).
  2. \(\limsup\sqrt[n]{|c_nx^n|} = 2|x|\).
    양수 상수 \(|x|\)를 곱하면 상극한도 그만큼 곱해진다.
  3. \(|x| < \frac12\)이면 \(2|x| < 1\)이라 절대수렴, \(|x| > \frac12\)이면 발산.
    근 판정법(정리 2.4.1).
  4. \(|x| = \frac12\)이면 짝수 번째 항이 \(2^n(\frac12)^n = 1\)이라 \(a_n \not\to 0\), 발산. 수렴 범위는 \(-\frac12 < x < \frac12\).
    근 판정법은 경계에서 판정하지 못하므로 따로 본다.

검산

급수를 짝수항과 홀수항으로 나누면 \(\sum(4x^2)^m + x\sum(x^2)^m\)입니다. 앞은 \(|4x^2| < 1\), 곧 \(|x| < \frac12\)에서, 뒤는 \(|x| < 1\)에서 수렴합니다. 둘 다 수렴하는 범위는 \(|x| < \frac12\)로 같습니다.

의미

일반적으로 \(\frac1R = \limsup\sqrt[n]{|c_n|}\)이 수렴반경입니다(코시-아다마르 공식). 수렴반경 안에서 거듭제곱급수는 닫힌 부분구간마다 균등수렴하고(6단원), 그래서 항별로 미분·적분할 수 있습니다. 복소해석학(수학20)에서는 수렴반경이 "가장 가까운 특이점까지의 거리"라는 것도 배웁니다.

이해 확인

\(\sum\frac{x^n}{n}\)의 수렴반경과 경계 \(x = \pm1\)에서의 수렴 여부는?

답

\(\sqrt[n]{1/n} \to 1\)이라 \(R = 1\). \(x = 1\)은 조화급수라 발산, \(x = -1\)은 교대급수라 수렴(\(-\ln 2\)).
