이 절에서 배울 것
  • 비동차 방정식의 일반해 = 동차 일반해 + 특수해 구조를 안다.
  • 매개변수 변환법으로 특수해를 구하는 공식을 유도하고 쓴다.
  • 미정계수법과 비교하고, 공명(강제 진동수 = 고유 진동수)을 이해한다.
먼저 알아야 할 것
  • 기본해와 론스키안 (2.1절), 연립일차방정식과 크라머 공식 (수학1 5단원).

2.3.1해의 구조

\(L[y] = g\)의 해 두 개 \(y_p, \tilde y\)의 차는 \(L[y_p - \tilde y] = g - g = 0\)이라 동차 방정식의 해입니다. 그래서 특수해 하나만 찾으면 모든 해를 압니다.

\[y = c_1y_1 + c_2y_2 + y_p.\]

연립일차방정식의 해집합이 "특수해 + 핵"이었던 것(수학1)과 같은 구조입니다.

2.3.2매개변수 변환법

\(y'' + p(t)y' + q(t)y = g(t)\)의 동차 기본해 \(y_1, y_2\)를 안다고 합시다. 상수 \(c_1, c_2\)를 함수로 바꿔 \(y_p = u_1(t)y_1 + u_2(t)y_2\)로 둡니다. 미지 함수가 둘이라 조건 하나를 마음대로 정할 수 있으므로, 계산이 편하게 \(u_1'y_1 + u_2'y_2 = 0\)으로 정합니다. 그러면 \(y_p' = u_1y_1' + u_2y_2'\)이고, 대입하면 \(L[y_1] = L[y_2] = 0\)이라 남는 것은

\[\begin{cases} u_1'y_1 + u_2'y_2 = 0 \\ u_1'y_1' + u_2'y_2' = g\end{cases}\quad\Longrightarrow\quad u_1' = -\frac{y_2g}{W},\quad u_2' = \frac{y_1g}{W}\]

(크라머 공식, \(W\)는 론스키안). 적분하면 특수해입니다.

\[y_p(t) = -y_1\int\frac{y_2g}{W}\,dt + y_2\int\frac{y_1g}{W}\,dt.\]
예제 2.3.1

\(y'' + y = \sec t\) (\(|t| < \frac\pi2\))의 일반해를 구하여라.

풀이. \(y_1 = \cos t\), \(y_2 = \sin t\), \(W = 1\). \(u_1' = -\sin t\sec t = -\tan t\), \(u_1 = \ln|\cos t|\). \(u_2' = \cos t\sec t = 1\), \(u_2 = t\). 따라서 \(y = c_1\cos t + c_2\sin t + \cos t\ln(\cos t) + t\sin t\). \(\sec t\)는 미정계수법으로 다룰 수 없는 우변이라 이 방법이 필요합니다.

2.3.3미정계수법과 공명

상수계수이고 우변이 다항식·지수·사인·코사인과 그 곱이면, 같은 꼴의 함수로 특수해를 추측하는 미정계수법이 더 빠릅니다. 단, 추측한 꼴이 동차해와 겹치면 \(t\)를 곱해야 합니다.

예제 2.3.2 (강제 진동과 공명)

\(y'' + y = \cos\omega t\)의 특수해를 \(\omega \ne 1\)과 \(\omega = 1\)에서 구하여라.

풀이. \(\omega \ne 1\): \(y_p = A\cos\omega t\)를 넣으면 \(A(1 - \omega^2) = 1\), \(y_p = \frac{\cos\omega t}{1 - \omega^2}\). \(\omega\)가 1에 가까울수록 진폭이 커집니다. \(\omega = 1\): \(\cos t\)가 동차해라 \(y_p = t(A\cos t + B\sin t)\)로 두면 \(y_p = \frac t2\sin t\). 진폭이 시간에 비례해 끝없이 커지는 공명입니다. 감쇠항 \(2\zeta y'\)이 있으면 진폭은 유한하지만 \(\omega \approx 1\)에서 크게 솟습니다(같은 절의 탐구 카드).

흔한 실수(1) 표준형으로 만들지 않고 공식에 \(g\)를 넣는다: \(ay'' + \dots = f\)이면 \(g = \frac fa\). (2) 미정계수법에서 동차해와 겹치는데 \(t\)를 곱하지 않는다: \(y'' + y = \cos t\)에 \(A\cos t + B\sin t\)를 넣으면 \(0 = \cos t\)가 되어 실패한다.
요약
  1. 일반해 = 동차 일반해 + 특수해.
  2. 매개변수 변환: \(u_1' = -\frac{y_2g}{W}\), \(u_2' = \frac{y_1g}{W}\). 어떤 연속 \(g\)에도 쓴다.
  3. 강제 진동수가 고유 진동수와 같으면 공명(\(t\sin t\)).

2.3.4연습문제

기본

  1. \(y'' - y = e^{2t}\)의 특수해를 미정계수법으로 구하여라.
    답

    \(Ae^{2t}\): \(4A - A = 1\), \(y_p = \frac13e^{2t}\).

응용

  1. \(y'' - 2y' + y = \frac{e^t}{t}\) (\(t > 0\))을 매개변수 변환법으로 풀어라.
    답

    \(y_1 = e^t\), \(y_2 = te^t\), \(W = e^{2t}\). \(u_1' = -1\), \(u_2' = \frac1t\). \(y_p = -te^t + te^t\ln t\). 일반해 \((c_1 + c_2t + t\ln t)e^t\) (\(-te^t\)는 동차해에 흡수).

심화

  1. \(y'' + y = g(t)\), \(y(0) = y'(0) = 0\)의 해가 \(y(t) = \int_0^t\sin(t - s)g(s)\,ds\)임을 매개변수 변환법으로 보여라.
    답

    \(u_1 = -\int_0^t\sin s\,g\), \(u_2 = \int_0^t\cos s\,g\). \(y = \int_0^t(\sin t\cos s - \cos t\sin s)g\,ds = \int_0^t\sin(t - s)g(s)\,ds\). (6단원 그린 함수의 원형)

2.3.2

탐구그네를 제때 밀면 높이 올라간다

탐구 · 강제 진동과 공명

다루는 성취기준 [수학6-02-03]

질문

고유 진동수가 1인 용수철을 진동수 \(\omega\)로 흔들면(\(y'' + 2\zeta y' + y = \cos\omega t\)), 오래 지난 뒤의 진폭은 \(\omega\)에 따라 어떻게 달라질까요? 감쇠 \(\zeta\)가 0이고 \(\omega = 1\)이면 어떻게 될까요?

복원

일반해 = 동차해(감쇠로 사라짐) + 특수해. 감쇠가 없을 때 \(\omega = 1\)이면 특수해가 \(\frac t2\sin t\)로 자란다(공명) (2.3절).

해 보기

  1. 처음 화면(\(\zeta = 0.1\), \(\omega = 1\))의 정상상태 진폭은 \(\frac{1}{2\zeta} = 5\)입니다. 오른쪽 그래프가 점점 커져 진폭 5에 자리 잡습니다.
  2. \(\omega = 0.5\)나 \(2\)로 바꾸면 진폭이 약 1.32, 0.33으로 작아집니다. 고유 진동수에서 멀리 흔들면 잘 움직이지 않습니다.
  3. \(\zeta\)를 0.05로 줄이면 \(\omega = 1\)의 진폭이 10으로 두 배가 됩니다. 진폭 곡선의 봉우리가 높고 좁아집니다.
  4. \(\zeta = 0\), \(\omega = 1\)이면 진폭이 끝없이 자랍니다(\(t = 60\) 근처에서 약 29). \(\zeta = 0\), \(\omega = 0.9\)이면 진폭이 커졌다 작아지기를 되풀이하는 맥놀이가 생깁니다.

설명

  1. 진폭 공식특수해 \(A\cos(\omega t - \phi)\)를 대입하면 \(A = \frac{1}{\sqrt{(1 - \omega^2)^2 + (2\zeta\omega)^2}}\). \(\omega = 1\)에서 분모의 첫 항이 사라져 감쇠항만 남습니다.
  2. 공학에서다리가 바람이나 행진하는 발걸음에 흔들릴 때, 건물이 지진파에 흔들릴 때 고유 진동수 근처의 강제력이 위험합니다. 반대로 라디오 수신기는 공명을 이용해 원하는 주파수만 크게 받습니다.

판단

"감쇠가 있으면 공명은 없다"는 틀립니다. 감쇠가 있으면 진폭이 무한대가 되지 않을 뿐, \(\omega \approx 1\)에서 진폭이 \(\frac1{2\zeta}\) 근처로 크게 솟습니다. \(\zeta = 0.01\)이면 50배입니다.
