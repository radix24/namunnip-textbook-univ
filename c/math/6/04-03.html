4.3.1르장드르 다항식

4.1절에서 르장드르 방정식 \((1 - t^2)y'' - 2ty' + n(n + 1)y = 0\)은 \(n\)이 자연수이면 \(n\)차 다항식 해를 가졌습니다. \(P_n(1) = 1\)이 되도록 맞춘 것이 르장드르 다항식입니다.

정의 4.3.1 (로드리게스 공식)

\(P_n(t) = \frac{1}{2^nn!}\frac{d^n}{dt^n}(t^2 - 1)^n\).

\(P_0 = 1\), \(P_1 = t\), \(P_2 = \frac12(3t^2 - 1)\), \(P_3 = \frac12(5t^3 - 3t)\), \(P_4 = \frac18(35t^4 - 30t^2 + 3)\).

정리 4.3.2

(a) 점화식 \((n + 1)P_{n+1} = (2n + 1)tP_n - nP_{n-1}\). (b) 직교성 \(\int_{-1}^1P_mP_n\,dt = 0\) (\(m \ne n\)), \(\int_{-1}^1P_n^2\,dt = \frac{2}{2n + 1}\).

(b)의 증명.방정식을 \(((1 - t^2)P_n')' = -n(n + 1)P_n\)으로 쓴다. \(P_m\)을 곱하고 \([-1, 1]\)에서 부분적분하면 \((1 - t^2)\)이 양 끝에서 0이라 \(-n(n+1)\int P_mP_n = -\int(1 - t^2)P_m'P_n'\). \(m\)과 \(n\)을 바꾼 식과 빼면 \([m(m+1) - n(n+1)]\int P_mP_n = 0\)이고 \(m \ne n\)이면 괄호가 0이 아니다. ∎

이 증명은 6단원 스투름-리우빌 이론의 원형입니다. 직교성 덕분에 \([-1, 1]\)의 함수를 \(f = \sum c_nP_n\), \(c_n = \frac{2n + 1}{2}\int fP_n\)으로 전개할 수 있습니다(푸리에 급수와 같은 원리). 구 좌표에서 라플라스 방정식을 풀면 각도 \(\theta\) 방향 해가 \(P_n(\cos\theta)\)입니다.

4.3.2베셀 함수

정의 4.3.3 (제1종 베셀 함수)

\(J_\nu(t) = \sum_{k\ge0}\frac{(-1)^k}{k!\,\Gamma(k + \nu + 1)}\left(\frac t2\right)^{2k + \nu}\). 베셀 방정식 \(t^2y'' + ty' + (t^2 - \nu^2)y = 0\)의 프로베니우스 해(\(r = \nu\))이다.

\(\Gamma\)는 계승을 실수로 넓힌 감마 함수(\(\Gamma(n + 1) = n!\))입니다. \(J_0(t) = 1 - \frac{t^2}4 + \frac{t^4}{64} - \cdots\)는 \(\cos\)처럼 진동하지만 진폭이 \(\sqrt{\frac{2}{\pi t}}\)처럼 줄어듭니다.

  • 점화식: \(J_{\nu-1} + J_{\nu+1} = \frac{2\nu}{t}J_\nu\), \(J_0' = -J_1\).
  • 영점: \(J_0\)의 양의 영점 \(j_{0,1} \approx 2.405\), \(j_{0,2} \approx 5.520\), \(j_{0,3} \approx 8.654\). 간격이 점점 \(\pi\)에 가까워진다.
  • 직교성: \(j_{\nu,m}\)이 \(J_\nu\)의 영점이면 \(\int_0^1tJ_\nu(j_{\nu,m}t)J_\nu(j_{\nu,n}t)\,dt = 0\) (\(m \ne n\)). 가중치 \(t\)가 붙는다.

원형 북의 진동을 원통 좌표로 풀면 반지름 방향 모양이 \(J_0(j_{0,m}r)\)이고, 진동수는 영점에 비례합니다. 그래서 북소리의 배음은 피아노 줄(정수배)과 달리 \(2.405 : 5.520 : 8.654\)로 정수비가 아닙니다.

흔한 실수(1) 르장드르 직교성을 \([0, 1]\)에서 쓴다: 구간은 \([-1, 1]\)이다. (2) 베셀 직교성에서 가중치 \(t\)를 빠뜨린다. (3) \(J_0\)의 영점을 \(\pi\)의 배수로 생각한다: 근사적으로 \((m - \frac14)\pi\)이다.
요약
  1. \(P_n\): 로드리게스 공식, \((n+1)P_{n+1} = (2n+1)tP_n - nP_{n-1}\), \([-1,1]\)에서 직교.
  2. \(J_\nu\): 베셀 방정식의 프로베니우스 해, 진동하며 감쇠, 영점들로 가중 직교.
  3. 구·원통 좌표의 편미분방정식에서 나온다.

4.3.3연습문제

기본

  1. 점화식으로 \(P_2\)에서 \(P_3\)을 구하여라.
    답

    \(3P_3 = 5tP_2 - 2P_1 = \frac52(3t^3 - t) - 2t\), \(P_3 = \frac12(5t^3 - 3t)\).

응용

  1. \(\int_{-1}^1P_2^2\,dt = \frac25\)을 직접 계산하여라.
    답

    \(\frac14\int(9t^4 - 6t^2 + 1) = \frac14\left(\frac{18}5 - 4 + 2\right) = \frac25\).

심화

  1. \(t^2\)을 르장드르 다항식으로 전개하여라.
    답

    \(t^2 = \frac23P_2 + \frac13P_0\).

4.3.2

탐구위와 아래가 정확히 상쇄된다

탐구 · 르장드르 다항식과 베셀 함수의 직교성

다루는 성취기준 [수학6-04-03]

질문

르장드르 다항식 두 개를 곱해 \([-1, 1]\)에서 적분하면 왜 0이 될까요? 베셀 함수는 어떤 가중치를 붙여야 같은 일이 일어날까요?

복원

\(\int_{-1}^1P_mP_n\,dt = 0\) (\(m \ne n\)), \(\int_0^1rJ_0(j_mr)J_0(j_nr)\,dr = 0\) (\(j_m, j_n\)은 \(J_0\)의 서로 다른 영점) (4.3절).

해 보기

  1. \(P_2\)와 \(P_3\)의 곱은 홀함수라 왼쪽과 오른쪽이 정확히 상쇄됩니다. \(P_2\)와 \(P_4\)(둘 다 짝함수)를 고르면 대칭으로는 설명되지 않는데도 넓이가 0입니다.
  2. \(m = n\)으로 두면 넓이가 \(\frac{2}{2n + 1}\)입니다. \(n = 2\)이면 0.4입니다.
  3. 베셀로 바꾸면 \(J_0(2.405r)\), \(J_0(5.520r)\) 등 영점에서 끝나는 함수들입니다. 가중치 \(r\)을 곱한 넓이가 0이 됩니다.
  4. 베셀에서 \(m = n\)이면 넓이가 양수입니다. 이 값으로 나눠 북의 진동 모양을 전개할 때 계수를 구합니다.

설명

  1. 왜 0인가두 함수가 같은 미분 작용소의 서로 다른 고유값에 대한 고유함수이기 때문입니다. 부분적분으로 작용소를 옮기면 \((\lambda_m - \lambda_n)\int = 0\)이 됩니다(6단원 스투름-리우빌).
  2. 가중치의 출처베셀 방정식을 \((rJ')' + \lambda rJ = 0\) 꼴로 쓰면 고유값 앞에 \(r\)이 붙습니다. 원통 좌표의 넓이 요소 \(r\,dr\,d\theta\)에서 온 것입니다.

판단

"직교하는 함수는 그래프가 서로 수직으로 만난다"는 오해입니다. 직교는 적분 내적 \(\int fg\,w\)이 0이라는 뜻이고, 곱의 양수 넓이와 음수 넓이가 정확히 같다는 것입니다. 그래프의 각도와는 관계가 없습니다.
