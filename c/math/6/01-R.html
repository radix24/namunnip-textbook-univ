1.R.1

연습일계 방정식과 존재성 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학6-01-01] [수학6-01-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(y' = \frac{t}{y}\), \(y(0) = 2\)를 풀어라. [01-01]

    힌트 1

    변수분리: \(y\,dy = t\,dt\)(1.1절).

    힌트 2

    \(y^2 - t^2 = C\), 부호는 초기값으로.

    풀이

    \(\frac{y^2}2 = \frac{t^2}2 + C\), \(y(0) = 2\)에서 \(y^2 = t^2 + 4\). \(y > 0\)이라 \(y = \sqrt{t^2 + 4}\).

  2. 계산\(ty' + 2y = t^2\) (\(t > 0\)), \(y(1) = 1\)을 풀어라. [01-01]

    힌트 1

    \(t\)로 나눠 표준형 \(y' + \frac2ty = t\).

    힌트 2

    \(\mu = t^2\).

    풀이

    \((t^2y)' = t^3\), \(t^2y = \frac{t^4}4 + C\), \(y(1) = 1\)에서 \(C = \frac34\). \(y = \frac{t^2}4 + \frac{3}{4t^2}\).

  3. 개념\((y\cos t + 2t) + (\sin t + 3y^2)y' = 0\)이 완전방정식인지 판정하고 풀어라. [01-01]

    힌트 1

    \(M_y\)와 \(N_t\)를 비교하세요.

    힌트 2

    \(F = y\sin t + t^2 + g(y)\).

    풀이

    \(M_y = \cos t = N_t\), 완전. \(F_y = \sin t + g'(y) = \sin t + 3y^2\)에서 \(g = y^3\). 해: \(y\sin t + t^2 + y^3 = C\).

  4. 계산\(y' = 1 + y^2\), \(y(0) = 0\)의 피카르 반복 \(y_1, y_2\)를 구하고 실제 해와 비교하여라. [01-02]

    힌트 1

    \(y_1 = \int_0^t1\,ds\)(1.2절).

    힌트 2

    실제 해는 \(\tan t\).

    풀이

    \(y_1 = t\), \(y_2 = t + \frac{t^3}3\). \(\tan t = t + \frac{t^3}3 + \frac{2t^5}{15} + \cdots\)의 앞부분과 같다. 해는 \(t = \frac\pi2\)에서 폭발한다.

  5. 증명\(f(t, y) = |y|\)는 \(y = 0\)에서 미분 불가능하지만 립시츠 조건을 만족함을 보이고, \(y' = |y|\), \(y(0) = 0\)의 해가 하나뿐임을 결론지어라. [01-02]

    힌트 1

    \(||y| - |z|| \le |y - z|\).

    힌트 2

    정리 1.2.1과 상수해.

    풀이

    삼각부등식으로 \(L = 1\)인 립시츠. 피카르-린델뢰프로 해가 하나이고, \(y = 0\)이 해이므로 그것뿐이다. ∎ (립시츠는 미분 가능성보다 약한 조건이다.)

  6. 판단한 학생이 "\(y' = y^{1/3}\), \(y(0) = 0\)은 \(f\)가 연속이니 해가 \(y = 0\) 하나뿐"이라 썼다. 맞는가? [01-02]

    힌트 1

    \(y = ct^k\) 꼴을 대입해 보세요.

    힌트 2

    \(f_y\)가 \(y = 0\)에서 유계인가?

    풀이

    틀렸다. \(y = \left(\frac{2t}{3}\right)^{3/2}\) (\(t \ge 0\))도 해다. \(f_y = \frac13y^{-2/3}\)이 0에서 발산해 립시츠가 깨지므로 유일성이 보장되지 않는다. 연속성은 존재만 준다.
