1.1.1미분방정식이란

물리 법칙은 대개 "변화율이 현재 상태로 정해진다"는 꼴입니다. 방사성 물질은 남은 양에 비례해 줄고(\(\frac{dN}{dt} = -\lambda N\)), 뜨거운 커피는 주변과의 온도 차에 비례해 식습니다(\(\frac{dT}{dt} = -k(T - T_0)\)). 이렇게 미지의 함수와 그 도함수 사이의 관계식을 미분방정식이라 합니다.

정의 1.1.1

상미분방정식: 한 변수 \(t\)의 함수 \(y(t)\)와 그 도함수들의 관계식. 가장 높은 도함수의 차수가 계수이다.

해: 구간에서 미분 가능하고 대입하면 식이 성립하는 함수.

초기값 문제: 방정식 \(y' = f(t, y)\)와 조건 \(y(t_0) = y_0\)의 쌍.

방향장: 평면의 각 점 \((t, y)\)에 기울기 \(f(t, y)\)인 짧은 선분을 그린 그림. 해의 그래프는 어디서나 이 선분에 접한다.

일계 방정식 \(y' = f(t, y)\)는 "점 \((t, y)\)를 지나는 해의 기울기는 \(f(t, y)\)"라는 뜻입니다. 공식을 몰라도 방향장을 따라가면 해의 모양을 알 수 있고, 같은 절의 탐구 카드에서 점을 찍어 해 곡선을 그려 볼 수 있습니다.

1.1.2변수분리형

\(y' = g(t)h(y)\) 꼴이면 \(y\)가 들어간 것과 \(t\)가 들어간 것을 양변으로 나눕니다.

\[\frac{dy}{h(y)} = g(t)\,dt \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(t)\,dt.\]

엄밀하게는 \(h(y(t)) \ne 0\)일 때 \(\frac{y'(t)}{h(y(t))} = g(t)\)의 양변을 \(t\)로 적분하고 왼쪽에 치환적분을 쓴 것입니다. \(h(y_0) = 0\)인 \(y_0\)에서는 상수함수 \(y = y_0\)도 해이니 따로 챙깁니다.

예제 1.1.2 (로지스틱 방정식)

\(y' = y(1 - y)\), \(y(0) = 0.1\)을 풀어라.

풀이. \(y \ne 0, 1\)일 때 \(\frac{dy}{y(1 - y)} = dt\). 부분분수 \(\frac1{y(1-y)} = \frac1y + \frac1{1 - y}\)로 적분하면 \(\ln\left|\frac{y}{1 - y}\right| = t + C\), 곧 \(\frac{y}{1 - y} = Ae^t\). \(t = 0\)에서 \(\frac{0.1}{0.9} = \frac19 = A\). 정리하면

\[y(t) = \frac{1}{1 + 9e^{-t}}.\]

\(t \to \infty\)이면 \(y \to 1\), 인구가 환경 용량으로 수렴하는 S자 곡선입니다. 예: \(y(2) = \frac1{1 + 9e^{-2}} \approx 0.451\).

1.1.3일계 선형 방정식

\(y' + p(t)y = q(t)\) 꼴은 왼쪽을 "한 함수의 도함수"로 만드는 곱수(적분인자) \(\mu(t) = e^{\int p\,dt}\)를 곱해 풉니다. \(\mu' = p\mu\)이므로

\[\mu y' + \mu p y = (\mu y)' = \mu q \quad\Longrightarrow\quad y = \frac{1}{\mu}\left(\int\mu q\,dt + C\right).\]
예제 1.1.3

\(y' + 2y = e^{-t}\), \(y(0) = 0\).

풀이. \(\mu = e^{2t}\). \((e^{2t}y)' = e^{t}\)이라 \(e^{2t}y = e^t + C\), \(y = e^{-t} + Ce^{-2t}\). \(y(0) = 1 + C = 0\)에서 \(C = -1\), \(y = e^{-t} - e^{-2t}\). 검산: \(y' + 2y = -e^{-t} + 2e^{-2t} + 2e^{-t} - 2e^{-2t} = e^{-t}\).

1.1.4완전방정식

\(M(t, y) + N(t, y)y' = 0\)에서 어떤 함수 \(F\)가 \(F_t = M\), \(F_y = N\)이면(편도함수: 다른 변수를 상수로 보고 미분), 연쇄 법칙으로 \(\frac{d}{dt}F(t, y(t)) = M + Ny' = 0\)이라 해는 \(F(t, y) = C\)인 곡선입니다. 그런 \(F\)가 있을 필요충분조건은 (단순연결 영역에서) \(M_y = N_t\)입니다.

예제 1.1.4

\((2ty + 1) + (t^2 + 3y^2)y' = 0\).

풀이. \(M_y = 2t = N_t\)이라 완전. \(F_t = 2ty + 1\)을 \(t\)로 적분하면 \(F = t^2y + t + g(y)\), \(F_y = t^2 + g'(y) = t^2 + 3y^2\)에서 \(g = y^3\). 해는 \(t^2y + t + y^3 = C\).

치환으로 바뀌는 유형도 있습니다. 동차형 \(y' = f\left(\frac yt\right)\)은 \(v = \frac yt\)로 변수분리형이 되고, 베르누이 방정식 \(y' + py = qy^n\)은 \(v = y^{1-n}\)으로 선형이 됩니다.

흔한 실수(1) 변수분리에서 나눈 \(h(y) = 0\)인 상수해를 빠뜨린다: 로지스틱에서 \(y = 0\), \(y = 1\)도 해다. (2) 적분인자를 곱한 뒤 오른쪽에도 곱하는 것을 잊는다. (3) 적분상수를 마지막에 붙인다: \(y = \frac1\mu(\int\mu q) + C\)가 아니라 \(\frac1\mu(\int\mu q + C)\)이다.
요약
  1. 변수분리형: \(\int\frac{dy}{h(y)} = \int g\,dt\), 상수해를 따로 챙긴다.
  2. 선형: 적분인자 \(\mu = e^{\int p}\)로 \((\mu y)' = \mu q\).
  3. 완전: \(M_y = N_t\)이면 \(F_t = M\), \(F_y = N\)인 \(F\)로 \(F = C\).

1.1.5연습문제

기본

  1. \(y' = ty^2\), \(y(0) = 1\)을 풀고 해가 존재하는 구간을 말하여라.
    답

    \(-\frac1y = \frac{t^2}2 + C\), \(C = -1\). \(y = \frac{2}{2 - t^2}\), 구간 \((-\sqrt2, \sqrt2)\).

  2. \(y' - y = t\)의 일반해를 구하여라.
    답

    \(\mu = e^{-t}\), \((e^{-t}y)' = te^{-t}\), \(y = -t - 1 + Ce^t\).

응용

  1. 뉴턴 냉각 법칙 \(T' = -k(T - 20)\)에서 90°C 커피가 10분 뒤 60°C가 되었다. 40°C가 되는 시각은?
    답

    \(T - 20 = 70e^{-kt}\), \(40 = 70e^{-10k}\)에서 \(e^{-10k} = \frac47\). \(20 = 70e^{-kt}\)이면 \(e^{-kt} = \frac27\), \(t = 10\frac{\ln(7/2)}{\ln(7/4)} \approx 22.4\)분.

심화

  1. 베르누이 방정식 \(y' + y = y^2\)을 \(v = y^{-1}\)로 풀어라.
    답

    \(v' = -y^{-2}y' = -y^{-2}(y^2 - y) = -1 + v\). \(v = 1 + Ce^t\), \(y = \frac{1}{1 + Ce^t}\).

1.1.2

탐구기울기를 따라가면 해가 보인다

탐구 · 방향장과 해 곡선

다루는 성취기준 [수학6-01-01]

질문

공식으로 풀지 않아도 \(y' = f(t, y)\)의 해가 어떤 모양인지 알 수 있을까요? 출발점을 바꾸면 해는 어떻게 달라지고, 두 해가 만날 수 있을까요?

복원

해의 그래프는 각 점 \((t, y)\)에서 기울기 \(f(t, y)\)인 방향장의 선분에 접한다. 변수분리형·선형은 공식으로 풀린다 (1.1절).

해 보기

  1. 로지스틱에서 \((0, 0.1)\)의 해는 S자로 1에 다가갑니다(예제 1.1.2의 \(\frac1{1 + 9e^{-t}}\)). \(y = 1.5\) 근처를 누르면 위에서 1로 내려옵니다. \(y = 0\)과 \(y = 1\)은 상수해이고, 다른 해는 이 선을 넘지 못합니다.
  2. 선형 방정식에서 여러 점을 찍으면 모든 해가 \(e^{-t} - \dots\) 꼴로 빠르게 한 곡선에 모입니다. 차이가 \(Ce^{-2t}\)로 줄어들기 때문입니다.
  3. \(y' = t^2 + y^2\)은 공식 해가 없지만 그림으로는 해가 보입니다. 위쪽 출발점의 해는 유한한 \(t\)에서 위로 폭발합니다(1.2절).
  4. \(y' = 3y^{2/3}\)에서 \((-1, 0)\)을 누르면 수치해는 \(y = 0\)에 머물지만, \(y = (t - c)^3\)도 해입니다. 방향장만으로는 어느 해를 따라갈지 정해지지 않는 유일성 실패입니다.

설명

  1. 해는 서로 만나지 않는다\(f\)와 \(f_y\)가 연속이면 한 점을 지나는 해가 하나뿐이라(1.2절), 서로 다른 해 곡선은 교차하지 않습니다. 그래서 상수해가 다른 해들의 경계가 됩니다.
  2. 수치해그림의 곡선은 작은 걸음(0.01)으로 방향장을 따라가는 룽게-쿠타 방법으로 그렸습니다. 유일성이 깨지는 곳에서는 수치해가 여러 해 중 하나만 고릅니다.

판단

"방향장이 매끄러우면 해는 \(t\)의 모든 값에서 존재한다"는 틀립니다. \(y' = t^2 + y^2\)의 방향장은 매끄럽지만, 해는 유한한 시간에 무한대로 갑니다. 존재 정리는 짧은 구간만 보장합니다.
