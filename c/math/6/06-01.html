6.1.1경계치 문제

양 끝을 고정한 줄의 처짐이나 막대의 온도처럼, 조건이 한 점이 아니라 구간의 양 끝에 주어지는 문제가 경계치 문제입니다. 초기값 문제와 달리 해가 늘 하나 있지 않습니다.

예제 6.1.1

\(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(\pi) = 0\)의 0이 아닌 해가 있는 \(\lambda\)를 모두 구하여라.

풀이. \(\lambda < 0\)이면 \(y = c_1\cosh\mu t + c_2\sinh\mu t\) (\(\mu = \sqrt{-\lambda}\))에서 \(y(0) = 0\)이 \(c_1 = 0\), \(y(\pi) = c_2\sinh\mu\pi = 0\)이 \(c_2 = 0\). \(\lambda = 0\)이면 \(y = c_1 + c_2t\)도 0뿐. \(\lambda = \mu^2 > 0\)이면 \(y = c_2\sin\mu t\)이고 \(\sin\mu\pi = 0\)이 필요하므로 \(\mu = n\). 따라서 고유값 \(\lambda_n = n^2\), 고유함수 \(y_n = \sin nt\) (\(n = 1, 2, \dots\))입니다. 다른 \(\lambda\)에서는 해가 0뿐입니다.

행렬의 고유값 문제 \(A\mathbf v = \lambda\mathbf v\)와 같은 꼴입니다. 작용소 \(-\frac{d^2}{dt^2}\)의 고유값을 찾은 것입니다. 줄의 진동수는 \(\sqrt{\lambda_n} = n\)에 비례해, 기본음과 정수배 배음이 됩니다.

6.1.2스투름-리우빌 문제

정의 6.1.2 (정칙 스투름-리우빌 문제)

\([a, b]\)에서 \(p > 0\), \(p'\), \(q\), \(w > 0\)이 연속일 때

\[-(p(t)y')' + q(t)y = \lambda w(t)y, \qquad \alpha_1y(a) + \alpha_2y'(a) = 0,\ \ \beta_1y(b) + \beta_2y'(b) = 0.\]

\(w\)를 가중치라 한다.

르장드르(\(p = 1 - t^2\)), 베셀(\(p = t\), \(w = t\)) 방정식이 모두 이 꼴입니다. 핵심은 작용소 \(L[y] = -(py')' + qy\)가 경계조건 아래에서 "대칭"이라는 것입니다.

정리 6.1.3 (라그랑주 항등식)

\(u, v\)가 경계조건을 만족하면 \(\int_a^bL[u]\,v\,dt = \int_a^bu\,L[v]\,dt\).

증명.두 번 부분적분하면 차이는 \(\left[p(uv' - u'v)\right]_a^b\)이다. \(t = a\)에서 \((u(a), u'(a))\)와 \((v(a), v'(a))\)가 모두 \((\alpha_1, \alpha_2)\)에 수직이라 평행하고, 따라서 \(uv' - u'v = 0\). \(t = b\)도 같다. ∎

정리 6.1.4

스투름-리우빌 문제의 고유값은 실수이고, 서로 다른 고유값의 고유함수는 \(\int_a^by_my_nw\,dt = 0\)으로 직교한다.

증명.(실수) \(L[y] = \lambda wy\)에서 계수가 실수라 켤레를 취하면 \(L[\bar y] = \bar\lambda w\bar y\). 라그랑주 항등식으로 \(\int L[y]\bar y = \int yL[\bar y]\), 곧 \(\lambda\int w|y|^2 = \bar\lambda\int w|y|^2\). \(\int w|y|^2 > 0\)이라 \(\lambda = \bar\lambda\). (직교) \(\lambda_m\int wy_my_n = \int L[y_m]y_n = \int y_mL[y_n] = \lambda_n\int wy_my_n\)이고 \(\lambda_m \ne \lambda_n\)이라 적분이 0. ∎

대칭행렬의 고유값이 실수이고 고유벡터가 직교하는 것과 같은 논법입니다. 더 나아가 고유값은 \(\lambda_1 < \lambda_2 < \cdots \to \infty\)이고 \(n\)번째 고유함수는 구간 안에서 \(n - 1\)번 0이 됩니다. 같은 절의 탐구 카드에서 사격법으로 확인할 수 있습니다.

6.1.3고유함수 전개

고유함수들은 완비 직교계를 이뤄, 조건이 맞는 \(f\)를 \(f = \sum c_ny_n\), \(c_n = \frac{\int fy_nw}{\int y_n^2w}\)로 씁니다. 예제 6.1.1에서는 푸리에 사인 급수 \(f(t) = \sum b_n\sin nt\), \(b_n = \frac2\pi\int_0^\pi f\sin nt\,dt\)입니다. 예: \(f(t) = t(\pi - t)\)이면 \(b_n = \frac{8}{\pi n^3}\) (\(n\) 홀수), 0 (짝수).

흔한 실수(1) 경계치 문제도 해가 늘 하나라고 생각한다: \(y'' + y = 0\), \(y(0) = y(\pi) = 0\)은 해가 무한히 많고, \(y(\pi) = 1\)이면 해가 없다. (2) 직교성에서 가중치 \(w\)를 빠뜨린다.
요약
  1. 경계치 문제의 0 아닌 해는 특정 \(\lambda\)(고유값)에서만 있다: \(y'' + \lambda y = 0\), \(y(0) = y(\pi) = 0\)이면 \(\lambda = n^2\).
  2. 라그랑주 항등식(작용소의 대칭성) ⇒ 고유값 실수, 고유함수 \(w\)-직교.
  3. 고유함수 전개 \(f = \sum c_ny_n\)은 푸리에 급수의 일반화.

6.1.4연습문제

기본

  1. \(y'' + \lambda y = 0\), \(y'(0) = 0\), \(y'(\pi) = 0\)의 고유값과 고유함수를 구하여라.
    답

    \(\lambda = n^2\) (\(n = 0, 1, 2, \dots\)), \(y = \cos nt\). \(\lambda = 0\)도 고유값(상수함수).

응용

  1. \(f(t) = t(\pi - t)\)의 사인 급수 계수 \(b_1\), \(b_3\)을 구하고 \(t = \frac\pi2\)에서 두 항까지의 합을 \(f(\frac\pi2)\)와 비교하여라.
    답

    \(b_1 = \frac8\pi \approx 2.546\), \(b_3 = \frac{8}{27\pi} \approx 0.0943\). \(b_1 - b_3 \approx 2.452\), \(f(\frac\pi2) = \frac{\pi^2}4 \approx 2.467\).

심화

  1. \(-y'' = \lambda y\), \(y(0) = 0\), \(y(1) + y'(1) = 0\)의 고유값이 \(\tan\sqrt\lambda = -\sqrt\lambda\)의 해임을 보여라.
    답

    \(y = \sin\mu t\) (\(\mu = \sqrt\lambda\)), \(\sin\mu + \mu\cos\mu = 0\). 고유값은 \(\mu \approx 2.029, 4.913, \dots\)의 제곱(초월방정식, 수치로 구함).

6.1.2

탐구과녁에 맞는 λ만 고유값이다

탐구 · 사격법으로 찾는 스투름-리우빌 고유값

다루는 성취기준 [수학6-06-01]

질문

\(-y'' = \lambda w(x)y\), \(y(0) = y(\pi) = 0\)의 0이 아닌 해는 특정한 \(\lambda\)에서만 있습니다. 공식이 없을 때 그 \(\lambda\)를 어떻게 찾을까요? 고유함수의 모양은 \(\lambda\)의 순서와 어떤 관계일까요?

복원

스투름-리우빌 문제의 고유값은 실수이고 \(\lambda_1 < \lambda_2 < \cdots\), \(n\)번째 고유함수는 구간 안에서 \(n - 1\)번 0이 된다 (6.1절).

해 보기

  1. \(w = 1\), \(\lambda = 3\)이면 \(y(\pi) \approx -0.43\)으로 과녁(0)을 빗나갑니다. \(\lambda\)를 4로 맞추면 \(y(\pi) = 0\)이 되고, 해 \(\frac{\sin2x}{2}\)는 구간 안에서 한 번 0이 됩니다.
  2. \(\lambda\)를 1, 4, 9, 16, 25로 맞추면 영점이 0, 1, 2, 3, 4개입니다. 고유값이 커질수록 많이 진동합니다.
  3. \(w = 1 + x\)로 바꾸면 고유값이 약 0.383, 1.583, 3.591, 6.406, 10.027로 작아집니다. 가중치가 크면 같은 \(\lambda\)에서도 빨리 진동하기 때문입니다.
  4. \(w = 1 + x\)의 고유함수는 오른쪽(가중치가 큰 쪽)에서 진동이 촘촘하고 진폭이 작습니다.

설명

  1. 사격법경계치 문제를 초기값 문제(왼쪽에서 \(y = 0\), 기울기 1로 쏘기)로 바꾸고, 오른쪽 끝 값 \(y(\pi; \lambda)\)가 0이 되는 \(\lambda\)를 이분법으로 찾습니다. 출력의 고유값 목록이 그렇게 계산한 것입니다.
  2. 영점 세기\(\lambda\)가 커지면 해가 더 빨리 진동해 \([0, \pi]\) 안의 영점이 하나씩 늘어나고, 영점이 오른쪽 끝을 지나는 순간이 고유값입니다. 그래서 고유값마다 영점 수가 하나씩 다릅니다(스투름 비교 정리).

판단

"고유값 사이의 \(\lambda\)에서도 경계조건을 만족하는 해가 있을 수 있다"는 틀립니다. 그런 \(\lambda\)에서는 \(y(0) = 0\)인 해가 모두 \(y(\pi) \ne 0\)이라(빨간 점이 0에 닿지 않음) 경계조건을 만족하는 해는 0뿐입니다.
