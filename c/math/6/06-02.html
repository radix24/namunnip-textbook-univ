6.2.1한 점을 누르기

양 끝을 고정한 팽팽한 줄에 하중 \(f(x)\)가 걸리면 처짐 \(u\)는 \(-u'' = f\), \(u(0) = u(1) = 0\)을 따릅니다. 하중을 점 하중들의 모음으로 보면, 점 \(s\)에 단위 하중이 걸릴 때의 처짐 \(G(x, s)\)만 알면 됩니다. 선형성으로 일반 하중의 처짐은 그것들을 더한(적분한) 것입니다.

\[u(x) = \int_0^1G(x, s)f(s)\,ds.\]
정의 6.2.1 (그린 함수)

경계조건을 만족하는 \(L[u] = f\)의 해가 \(u(x) = \int_a^bG(x, s)f(s)\,ds\)로 주어지는 \(G\)를 그린 함수라 한다. \(x\)의 함수로 보면 \(G(\cdot, s)\)는 \(x \ne s\)에서 \(L[G] = 0\), 경계조건 만족, \(x = s\)에서 연속이고 도함수가 \(-\frac{1}{p(s)}\)만큼 뛴다(\(L = -(pu')' + qu\)일 때).

6.2.2구성

왼쪽 경계조건을 만족하는 동차해 \(u_1\), 오른쪽 경계조건을 만족하는 동차해 \(u_2\)를 잡습니다. \(G\)는 \(x < s\)에서 \(u_1\)의 배수, \(x > s\)에서 \(u_2\)의 배수이고, \(x = s\)의 연속·도약 조건으로 배수가 정해집니다.

정리 6.2.2

\(L[u] = -(pu')' + qu\)이고 \(u_1, u_2\)가 위와 같으며 \(p(u_1u_2' - u_1'u_2) = -C\) (상수, 0이 아님)이면

\[G(x, s) = \frac{1}{C}\begin{cases} u_1(x)u_2(s) & x \le s \\ u_1(s)u_2(x) & x \ge s\end{cases}.\]

\(pW\)가 상수인 것은 아벨 공식(2.2절)입니다. \(C = 0\)이면 \(u_1\)과 \(u_2\)가 같은 함수(배수)라 0이 고유값이 되고, 그린 함수가 없습니다(해가 없거나 하나가 아님).

예제 6.2.3

\(-u'' = f\), \(u(0) = u(1) = 0\)의 그린 함수를 구하고 \(f = 1\)일 때 풀어라.

풀이. \(p = 1\), \(q = 0\). \(u_1 = x\) (\(u_1(0) = 0\)), \(u_2 = 1 - x\) (\(u_2(1) = 0\)). \(u_1u_2' - u_1'u_2 = -x - (1 - x) = -1\)이라 \(C = 1\).

\[G(x, s) = \begin{cases} x(1 - s) & x \le s \\ s(1 - x) & x \ge s\end{cases}.\]

\(f = 1\)이면 \(u(x) = \int_0^x s(1 - x)\,ds + \int_x^1x(1 - s)\,ds = (1 - x)\frac{x^2}2 + x\frac{(1 - x)^2}{2} = \frac{x(1 - x)}{2}\). 검산: \(-u'' = 1\), 양 끝 0. 가운데 처짐 \(u(\frac12) = \frac18\)입니다.

\(G(x, s)\)는 \(s\)를 누른 줄의 모양(꺾인 삼각형)이고 \(G(x, s) = G(s, x)\)로 대칭입니다(맥스웰 상반 정리: \(s\)를 누를 때 \(x\)의 처짐 = \(x\)를 누를 때 \(s\)의 처짐). 대칭은 작용소의 대칭(라그랑주 항등식)에서 나옵니다.

흔한 실수(1) \(u_1\), \(u_2\)를 아무 동차해나 고른다: 각각 한쪽 경계조건을 만족해야 한다. (2) \(x \le s\)와 \(x \ge s\)의 식을 바꿔 쓴다: \(x\)가 왼쪽에 있으면 왼쪽 조건의 \(u_1(x)\)가 붙는다. (3) 0이 고유값인데 그린 함수를 쓴다: \(-u'' = f\), \(u'(0) = u'(1) = 0\)은 상수가 동차해라 그린 함수가 없고, \(\int f = 0\)이어야 해가 있다.
요약
  1. 그린 함수 = 점 \(s\)의 단위 하중에 대한 반응. 해 \(u = \int Gf\,ds\).
  2. 왼쪽 조건의 \(u_1\), 오른쪽 조건의 \(u_2\)로 \(G = \frac1C u_1(x_<)u_2(x_>)\).
  3. \(-u'' = f\), \(u(0) = u(1) = 0\): \(G = x_<(1 - x_>)\), 대칭.

6.2.3연습문제

기본

  1. 예제의 그린 함수로 \(f = x\)일 때의 해를 구하여라.
    답

    \(u = \frac{x(1 - x^2)}{6}\). 검산 \(-u'' = x\).

응용

  1. \(-u'' = f\), \(u(0) = 0\), \(u'(1) = 0\)의 그린 함수를 구하여라.
    답

    \(u_1 = x\), \(u_2 = 1\). \(u_1u_2' - u_1'u_2 = -1\). \(G = \min(x, s)\).

심화

  1. \(-u'' - k^2u = f\), \(u(0) = u(1) = 0\)의 그린 함수를 구하고, \(k = \pi\)에서 무슨 일이 생기는지 설명하여라.
    답

    \(u_1 = \sin kx\), \(u_2 = \sin k(1 - x)\), \(C = k\sin k\). \(G = \frac{\sin kx_<\sin k(1 - x_>)}{k\sin k}\). \(k = \pi\)이면 \(\sin k = 0\): \(\pi^2\)이 고유값이라 그린 함수가 없다(공명).

다루는 성취기준 [수학6-06-02]

질문

양 끝이 고정된 줄의 한 점을 누르면 줄은 어떤 모양이 될까요? 하중이 줄 전체에 퍼져 있을 때의 처짐을 그 모양들로 만들 수 있을까요?

복원

\(-u'' = f\), \(u(0) = u(1) = 0\)의 그린 함수는 \(G(x, s) = x(1 - s)\) (\(x \le s\)), \(s(1 - x)\) (\(x \ge s\))이고 해는 \(u(x) = \int_0^1G(x, s)f(s)\,ds\) (6.2절).

해 보기

  1. 빨간 점 \(s\)를 끌어 보세요. 점 하중의 처짐은 \(s\)에서 꺾인 삼각형이고, 가장 깊은 곳 \(s(1 - s)\)는 \(s = \frac12\)에서 \(\frac14\)로 가장 큽니다.
  2. 고른 하중 \(f = 1\)의 처짐은 포물선 \(\frac{x(1 - x)}2\)이고 \(u(0.5) = 0.125\)입니다. 삼각형들을 고르게 겹쳐 더하면 매끄러운 포물선이 됩니다.
  3. \(f = x\)로 바꾸면 오른쪽이 더 무겁지만, 최대 처짐 자리는 \(x = \frac{1}{\sqrt3} \approx 0.577\)로 조금만 오른쪽으로 옮겨 갑니다. \(u(0.5) = 0.0625\)입니다.
  4. \(f = \sin\pi x\)이면 처짐이 \(\frac{\sin\pi x}{\pi^2}\)로 하중과 같은 모양입니다. \(\sin\pi x\)는 고유함수(6.1절)라 \(\frac1{\lambda_1} = \frac{1}{\pi^2}\)배가 될 뿐입니다.

설명

  1. 꺾이는 이유하중이 없는 곳에서는 \(u'' = 0\)이라 직선이고, 하중점에서 기울기가 1만큼 뛰어야(\(-u''\)이 점 하중) 합니다. 양 끝 고정 조건으로 두 직선이 정해집니다.
  2. 상반성점 \(a\)를 누를 때 점 \(b\)의 처짐과, \(b\)를 누를 때 \(a\)의 처짐은 같습니다(\(G(a, b) = G(b, a)\)). 다리 설계에서 영향선이라 부르는 원리입니다.

판단

"하중이 가장 큰 곳이 가장 많이 처진다"는 틀립니다. \(f = x\)는 \(x = 1\)에서 가장 무겁지만 그곳은 고정되어 처짐이 0입니다. 처짐은 모든 하중의 영향(그린 함수로 가중)을 합친 결과입니다.
