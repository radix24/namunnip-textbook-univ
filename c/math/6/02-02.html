2.2.1아벨 공식

정리 2.2.1 (아벨)

\(y_1, y_2\)가 \(y'' + p(t)y' + q(t)y = 0\)의 해이면 \(W(t) = W(t_0)\exp\left(-\int_{t_0}^tp(s)\,ds\right)\).

증명.\(W = y_1y_2' - y_1'y_2\)를 미분하면 \(W' = y_1y_2'' - y_1''y_2\) (\(y_1'y_2'\)항이 지워짐). \(y_i'' = -py_i' - qy_i\)를 넣으면 \(W' = -p(y_1y_2' - y_1'y_2) = -pW\). 일계 선형 방정식의 해가 위 식이다. ∎

결론: \(W\)는 늘 0이거나 한 번도 0이 아닙니다(지수함수는 0이 안 됨). 2.1절의 "한 점이면 모든 점"이 식으로 확인됩니다. 또 해를 모르고도 \(W\)를 압니다. 예: \(y'' + 2y' + 5y = 0\)이면 \(W = Ce^{-2t}\)이고, 예제 2.1.3의 \(2e^{-2t}\)와 맞습니다.

2.2.2계수 축소법

해 하나 \(y_1\)을 알면, 둘째 해를 \(y_2 = v(t)y_1(t)\)로 놓습니다. 대입하면 \(v\)는 빠지고 \(v'\)과 \(v''\)만 남아, \(w = v'\)에 대한 일계 방정식이 됩니다.

\[y_1v'' + (2y_1' + py_1)v' = 0.\]

또는 아벨 공식으로 바로: \(\left(\frac{y_2}{y_1}\right)' = \frac{W}{y_1^2}\)이므로

\[y_2 = y_1\int\frac{e^{-\int p\,dt}}{y_1^2}\,dt.\]
예제 2.2.2

(a) \(y'' - 2y' + y = 0\)의 해 \(y_1 = e^t\)로 둘째 해를 구하여라. (b) \(t^2y'' - 3ty' + 4y = 0\) (\(t > 0\))의 해 \(y_1 = t^2\)로 둘째 해를 구하여라.

풀이. (a) \(p = -2\), \(e^{-\int p} = e^{2t}\). \(y_2 = e^t\int\frac{e^{2t}}{e^{2t}}dt = te^t\). 중근일 때의 \(te^{rt}\)가 이렇게 나옵니다. (b) 표준형으로 나누면 \(p = -\frac3t\), \(e^{-\int p} = e^{3\ln t} = t^3\). \(y_2 = t^2\int\frac{t^3}{t^4}dt = t^2\ln t\). 검산: \(y_2' = 2t\ln t + t\), \(y_2'' = 2\ln t + 3\). \(t^2(2\ln t + 3) - 3t(2t\ln t + t) + 4t^2\ln t = 0\). ✓

2.2.3코시-오일러 방정식

(b)는 \(at^2y'' + bty' + cy = 0\) 꼴(코시-오일러)입니다. \(y = t^m\)을 넣으면 \(am(m - 1) + bm + c = 0\). 같은 절의 예제 카드는 근이 중근, 복소근인 경우를 다룹니다.

  • 서로 다른 실근: \(t^{m_1}\), \(t^{m_2}\).
  • 중근 \(m\): \(t^m\), \(t^m\ln t\) (예제 (b), \(m = 2\)).
  • 복소근 \(\alpha \pm i\beta\): \(t^\alpha\cos(\beta\ln t)\), \(t^\alpha\sin(\beta\ln t)\).

\(t = e^x\)로 치환하면 상수계수 방정식이 되므로, 상수계수의 \(e^{rx}\), \(xe^{rx}\)가 \(t^r\), \(t^r\ln t\)로 바뀐 것입니다.

흔한 실수(1) 아벨 공식에서 \(p\)를 표준형(최고차 계수 1)으로 만들지 않고 쓴다: (b)에서 \(-3t\)가 아니라 \(-\frac3t\)이다. (2) 계수 축소에서 \(v\) 자체가 남는다고 생각한다: \(y_1\)이 해이므로 \(v\)의 계수는 \(L[y_1] = 0\)이 되어 사라진다.
요약
  1. 아벨: \(W = Ce^{-\int p}\), 늘 0이거나 늘 0이 아니다.
  2. 계수 축소: \(y_2 = y_1\int\frac{e^{-\int p}}{y_1^2}\).
  3. 코시-오일러: \(t^m\), 중근이면 \(t^m\ln t\).

2.2.4연습문제

기본

  1. \(ty'' + y' + ty = 0\)의 두 해의 론스키안을 해를 모른 채 구하여라.
    답

    \(p = \frac1t\), \(W = \frac Ct\).

응용

  1. \(y'' + y = 0\)의 해 \(\cos t\)로 계수 축소를 하여 둘째 해를 구하여라.
    답

    \(\cos t\int\sec^2t\,dt = \cos t\tan t = \sin t\).

심화

  1. \(t^2y'' + ty' + y = 0\)의 일반해를 구하여라.
    답

    \(m(m-1) + m + 1 = m^2 + 1 = 0\), \(m = \pm i\). \(c_1\cos(\ln t) + c_2\sin(\ln t)\).

2.2.2

예제코시-오일러 방정식의 세 경우

예제 · 계수 축소와 로그

다루는 성취기준 [수학6-02-02]

먼저 예측

\(t^2y'' - ty' + y = 0\)에 \(y = t^m\)을 넣으면 중근 \(m = 1\)만 나옵니다. 둘째 해는 무엇일까요?

예측 확인

\(t\ln t\)입니다. 상수계수의 \(te^{rt}\)에 해당하는 것이 \(t^m\ln t\)입니다.

(a) \(t^2y'' - ty' + y = 0\)의 일반해를 계수 축소법으로 구하여라. (b) \(t^2y'' + 3ty' + 5y = 0\)의 실수 일반해를 구하여라. (모두 \(t > 0\))

전략

\(y = t^m\)으로 지표방정식 \(m(m - 1) + bm + c = 0\)을 만들고, 중근이면 계수 축소 \(y_2 = y_1\int\frac{e^{-\int p}}{y_1^2}\)를, 복소근이면 \(t^{\alpha + i\beta} = t^\alpha e^{i\beta\ln t}\)을 씁니다(2.2절).

풀이

  1. (a) \(m(m - 1) - m + 1 = (m - 1)^2 = 0\), \(y_1 = t\).
    \(b = -1\), \(c = 1\).
  2. 표준형 \(y'' - \frac1ty' + \frac1{t^2}y = 0\)에서 \(p = -\frac1t\), \(e^{-\int p} = t\).
    \(t^2\)으로 나눈다.
  3. \(y_2 = t\int\frac{t}{t^2}dt = t\ln t\). 일반해 \(y = c_1t + c_2t\ln t\).
    아벨 공식을 쓴 계수 축소.
  4. (b) \(m(m - 1) + 3m + 5 = m^2 + 2m + 5 = 0\), \(m = -1 \pm 2i\).
    근의 공식.
  5. \(t^{-1 + 2i} = t^{-1}e^{2i\ln t} = t^{-1}(\cos(2\ln t) + i\sin(2\ln t))\)의 실수부·허수부로 \(y = t^{-1}\left(c_1\cos(2\ln t) + c_2\sin(2\ln t)\right)\).
    \(t^{i\beta} = e^{i\beta\ln t}\)와 오일러 공식.

검산

(a) \(y = t\ln t\): \(y' = \ln t + 1\), \(y'' = \frac1t\). \(t^2\cdot\frac1t - t(\ln t + 1) + t\ln t = t - t = 0\). (b)의 해는 \(t \to 0^+\)에서 \(\ln t \to -\infty\)라 무한히 진동하면서 \(\frac1t\)로 커지고, \(t \to \infty\)에서는 점점 느리게 진동하며 0으로 갑니다.

의미

\(t = e^x\)로 바꾸면 \(t\frac{d}{dt} = \frac{d}{dx}\)라 코시-오일러 방정식은 상수계수 방정식이 됩니다. (a)는 \(y'' - 2y' + y = 0\) (\(x\)에 대해), 해 \(e^x, xe^x\)가 \(t, t\ln t\)입니다. 4단원의 프로베니우스 방법은 계수가 \(t = 0\) 근처에서 이 방정식을 닮은 경우를 다룹니다.

이해 확인

\(t^2y'' - 2y = 0\)의 일반해는?

답

\(m^2 - m - 2 = 0\), \(m = 2, -1\). \(c_1t^2 + c_2t^{-1}\).
