3.R.1

연습셈과 점화관계 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학3-03-01] [수학3-03-02] [수학3-03-03] [수학3-03-04]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산남학생 6명, 여학생 4명에서 3명을 뽑을 때 여학생이 적어도 1명인 경우의 수는? [03-01]

    힌트 1

    여사건: 모두 남학생(3.1절).

    힌트 2

    \(\binom{10}3 - \binom63\).

    풀이

    \(120 - 20 = 100\).

  2. 계산\(x_1 + x_2 + x_3 + x_4 = 12\), \(x_i \ge 2\)인 정수해의 개수는? [03-01]

    힌트 1

    먼저 각각 2씩 나눠 줍니다.

    힌트 2

    남은 4를 4개에 나누기.

    풀이

    \(\binom{4 + 4 - 1}{4} = \binom74 = 35\).

  3. 증명1부터 10까지에서 6개를 고르면 합이 11인 두 수가 있음을 보여라. [03-02]

    힌트 1

    집: 합이 11인 쌍(3.2절).

    힌트 2

    \(\{1,10\}, \{2,9\}, \dots, \{5,6\}\).

    풀이

    쌍 5개에 수 6개를 넣으면 한 쌍의 두 수를 모두 고른다. ∎

  4. 계산\(a_n = a_{n-1} + 6a_{n-2}\), \(a_0 = 2\), \(a_1 = 1\)을 풀어라. [03-03]

    힌트 1

    \(r^2 - r - 6 = 0\)(3.3절).

    힌트 2

    \(r = 3, -2\).

    풀이

    \(\alpha + \beta = 2\), \(3\alpha - 2\beta = 1\): \(\alpha = 1\), \(\beta = 1\). \(a_n = 3^n + (-2)^n\).

  5. 계산\(T(n) = 8T(n/2) + n^2\), \(T(n) = 8T(n/2) + n^3\)을 마스터 정리로 풀어라. [03-04]

    힌트 1

    \(b^d\)와 \(a = 8\)을 비교(3.4절).

    힌트 2

    \(2^2 = 4\), \(2^3 = 8\).

    풀이

    \(8 > 4\): \(\Theta(n^{\log_28}) = \Theta(n^3)\). \(8 = 8\): \(\Theta(n^3\log n)\).

  6. 판단한 학생이 "\(a_n = 2a_{n-1} + 2^n\)의 특수해는 \(c\cdot2^n\)으로 두면 된다"고 썼다. 맞는가? [03-03]

    힌트 1

    \(2^n\)은 동차해입니다.

    힌트 2

    \(cn2^n\)을 넣어 보세요.

    풀이

    틀렸다. \(c2^n = 2c2^{n-1} + 2^n\)이면 \(0 = 2^n\)이 되어 실패한다. \(cn2^n\): \(cn2^n = c(n-1)2^n + 2^n\)에서 \(c = 1\). 특수해 \(n2^n\).
