6.2.1게이트

컴퓨터의 계산은 전압이 높음(1)·낮음(0)인 신호를 게이트가 처리하는 것입니다. 각 게이트는 간단한 불 함수 하나를 계산합니다.

  • NOT \(\bar x\), AND \(xy\), OR \(x + y\).
  • NAND \(\overline{xy}\), NOR \(\overline{x + y}\).
  • XOR \(x \oplus y = x\bar y + \bar xy\) (둘이 다르면 1).

불 식을 회로로 옮길 때는 연산 하나가 게이트 하나입니다. \(f = z + xy\)는 AND 하나와 OR 하나로, 표준형 그대로 쓰면 3입력 AND 5개와 5입력 OR 하나가 필요했을 것입니다. 6.1절의 간단히 하기가 곧 부품 절약입니다.

6.2.2가산기

예제 6.2.1 (반가산기, 전가산기)

(a) 한 자리 이진수 \(a, b\)를 더해 합 \(s\)와 올림 \(c\)를 내는 회로. (b) 올림 입력 \(c_{in}\)까지 세 비트를 더하는 회로.

풀이. (a) 진리표 \(0 + 0 = 00\), \(0 + 1 = 01\), \(1 + 0 = 01\), \(1 + 1 = 10\)에서 \(s = a \oplus b\), \(c = ab\). XOR 하나, AND 하나. (b) 세 비트의 합: \(s = a \oplus b \oplus c_{in}\), 올림은 셋 중 둘 이상이 1일 때(다수결) \(c_{out} = ab + c_{in}(a \oplus b)\). 반가산기 두 개와 OR 하나로 만듭니다. 전가산기를 \(n\)개 이어 붙이면(올림을 다음 자리로) \(n\)비트 덧셈기입니다. 예: \(0110 + 0111\)은 자리마다 올림이 넘어가 \(1101\) (6 + 7 = 13). 같은 절의 탐구 카드에서 입력 스위치를 눌러 확인할 수 있습니다.

6.2.3NAND만으로

정리 6.2.2

모든 불 함수는 NAND 게이트만으로 만들 수 있다.

증명.모든 불 함수는 AND, OR, NOT으로 쓸 수 있다(곱의 합 표준형). 그리고 \(\bar x = \overline{xx}\), \(xy = \overline{\overline{xy}\,\overline{xy}}\), \(x + y = \overline{\bar x\,\bar y}\) (드모르간)이므로 세 연산이 모두 NAND로 만들어진다. ∎

반도체 공정에서는 NAND가 트랜지스터 4개로 가장 싸게 만들어져, 실제 칩은 NAND(또는 NOR) 위주로 설계됩니다. 곱의 합 \(xy + zw\)는 드모르간으로 \(\overline{\overline{xy}\cdot\overline{zw}}\)라 NAND 세 개로 바로 옮겨집니다.

흔한 실수(1) 전가산기 올림을 \(ab + bc_{in}\)으로 빠뜨린다: 셋 중 아무 둘이 1이면 올림이 생기므로 \(ab + bc_{in} + ac_{in}\)이다(위의 \(ab + c_{in}(a \oplus b)\)와 같음). (2) XOR를 OR로 쓴다: \(1 + 1\)의 합 비트는 0이다.
요약
  1. 불 식의 연산 하나 = 게이트 하나. 식을 간단히 하면 회로가 작아진다.
  2. 반가산기 \(s = a \oplus b\), \(c = ab\). 전가산기 \(s = a \oplus b \oplus c_{in}\), \(c_{out}\) = 다수결.
  3. NAND 하나로 NOT, AND, OR을 모두 만든다(기능적 완비).

6.2.4연습문제

기본

  1. \(\overline{x + y}\cdot z\)를 게이트로 나타내어라.
    답

    NOR(\(x, y\))와 \(z\)를 AND.

응용

  1. XOR를 NAND 4개로 만들어라.
    답

    \(m = \overline{xy}\), \(x \oplus y = \overline{\overline{xm}\cdot\overline{ym}}\).

심화

  1. 두 2비트 수 \(a_1a_0\)과 \(b_1b_0\)이 같을 때 1을 내는 회로를 설계하여라.
    답

    \(\overline{a_1 \oplus b_1}\cdot\overline{a_0 \oplus b_0}\) (각 자리 XNOR의 AND).

6.2.2

탐구올림이 줄지어 넘어간다

탐구 · 전가산기로 만든 4비트 덧셈기

다루는 성취기준 [수학3-06-02]

질문

컴퓨터는 이진수 두 개를 어떻게 더할까요? 손으로 하는 받아올림 덧셈을 게이트로 만들면 어떤 구조가 될까요?

복원

전가산기: 합 \(s = a \oplus b \oplus c_{in}\), 올림 \(c_{out} = ab + c_{in}(a \oplus b)\). 전가산기를 이어 붙이면 여러 자리 덧셈기가 된다 (6.2절).

해 보기

  1. 처음 화면은 \(0110 + 0111\) (6 + 7)입니다. 맨 오른쪽 \(0 + 1\)은 올림이 없지만, 둘째 자리 \(1 + 1\)에서 올림이 생겨 왼쪽으로 넘어가고, 결과는 \(1101 = 13\)입니다.
  2. A를 \(1111\), B를 \(0001\)로 만들어 보세요. 올림이 오른쪽 끝에서 왼쪽 끝까지 모든 자리를 거쳐 넘어가고 결과는 \(10000 = 16\)입니다. 왼쪽 끝 올림이 4비트를 넘친 자리(오버플로)입니다.
  3. 두 수가 같은 자리에 1이 하나도 없으면(예: \(1010 + 0101\)) 올림이 전혀 생기지 않습니다. 이때는 덧셈이 비트별 OR과 같습니다.

설명

  1. 리플 캐리각 자리는 오른쪽 자리의 올림을 기다려야 하므로, 최악의 경우(\(1111 + 0001\)) 올림이 \(n\)자리를 차례로 지나갑니다. 비트 수에 비례하는 지연이라, 실제 CPU는 올림을 미리 계산하는 회로(올림 예측)로 \(O(\log n)\) 단계에 끝냅니다.
  2. 뺄셈도 같은 회로로2의 보수(비트를 뒤집고 1을 더함)를 쓰면 \(A - B = A + \bar B + 1\)이라 덧셈기로 뺄셈도 합니다.

판단

"두 4비트 수의 합은 늘 4비트에 들어간다"는 틀립니다. \(1111 + 0001\)처럼 합이 15를 넘으면 5번째 비트(올림)가 필요합니다. 이를 무시하면 결과가 0000이 되는 오버플로가 생깁니다.
