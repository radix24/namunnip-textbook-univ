6.R.1

연습불 대수와 논리회로 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학3-06-01] [수학3-06-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(\bar xyz + xyz + x\bar yz + xy\bar z\)를 간단히 하여라. [06-01]

    힌트 1

    카르노 맵에 1을 4개 찍으세요(6.1절).

    힌트 2

    \(xyz\)를 세 번 겹쳐 쓸 수 있습니다.

    풀이

    \(yz + xz + xy\) (다수결 함수). \(xyz\)가 세 묶음에 모두 들어간다.

  2. 개념변수가 3개인 불 함수는 몇 개인가? 그중 \(f(0,0,0) = 0\)인 것은? [06-01]

    힌트 1

    입력 8가지 각각에 출력 0 또는 1.

    힌트 2

    한 입력이 고정되면?

    풀이

    \(2^8 = 256\)개, 그중 128개.

  3. 증명\(x + xy = x\)와 \(x(x + y) = x\)(흡수 법칙)를 불 대수 법칙으로 보여라. [06-01]

    힌트 1

    \(x = x\cdot1\).

    힌트 2

    \(1 + y = 1\).

    풀이

    \(x + xy = x(1 + y) = x\cdot1 = x\). \(x(x + y) = xx + xy = x + xy = x\). ∎

  4. 계산전가산기에서 \(a = 1\), \(b = 0\), \(c_{in} = 1\)일 때 \(s\)와 \(c_{out}\)은? [06-02]

    힌트 1

    \(1 + 0 + 1 = 2 = 10_2\)(6.2절).

    힌트 2

    XOR 세 개, 다수결.

    풀이

    \(s = 1 \oplus 0 \oplus 1 = 0\), \(c_{out} = 1\).

  5. 계산NOR 게이트만으로 NOT과 OR을 만들어라. [06-02]

    힌트 1

    \(\overline{x + x} = \bar x\).

    힌트 2

    NOR의 결과를 다시 NOT.

    풀이

    \(\bar x = \operatorname{NOR}(x, x)\), \(x + y = \operatorname{NOR}(\operatorname{NOR}(x, y), \operatorname{NOR}(x, y))\). AND는 \(\operatorname{NOR}(\bar x, \bar y)\). NOR도 기능적으로 완비하다.

  6. 판단한 학생이 "카르노 맵의 열 순서를 00, 01, 10, 11로 해도 결과는 같다"고 썼다. 맞는가? [06-01]

    힌트 1

    01과 10은 몇 비트 다른가요?

    힌트 2

    이웃 칸 묶기의 근거를 떠올리세요.

    풀이

    틀렸다. 01과 10은 두 비트가 달라, 이웃해 보여도 묶으면 변수가 사라지지 않는다. 반대로 진짜 이웃인 01과 11이 떨어져 놓여 묶음을 놓친다. 그레이 코드 순서여야 한다.
