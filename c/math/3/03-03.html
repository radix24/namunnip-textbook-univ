3.3.1점화식 세우기

예제 3.3.1

계단 \(n\)개를 한 번에 1칸 또는 2칸씩 오르는 방법의 수 \(a_n\)의 점화식은?

풀이. 마지막 걸음이 1칸이면 앞서 \(n - 1\)칸을 오른 방법 \(a_{n-1}\)가지, 2칸이면 \(a_{n-2}\)가지. 따라서 \(a_n = a_{n-1} + a_{n-2}\), \(a_1 = 1\), \(a_2 = 2\). 피보나치 수열입니다(\(a_n = F_{n+1}\)). 이렇게 "마지막 단계로 나누기"가 점화식을 세우는 기본 요령입니다.

3.3.2특성방정식

\(a_n = c_1a_{n-1} + c_2a_{n-2}\)에 \(a_n = r^n\)을 넣으면 \(r^2 = c_1r + c_2\), 곧 특성방정식 \(r^2 - c_1r - c_2 = 0\)을 얻습니다.

정리 3.3.2

(a) 특성방정식의 근 \(r_1 \ne r_2\)이면 일반해는 \(a_n = \alpha r_1^n + \beta r_2^n\). (b) 중근 \(r\)이면 \(a_n = (\alpha + \beta n)r^n\). 상수 \(\alpha, \beta\)는 초기값 두 개로 정한다.

증명의 뼈대.해 전체는 2차원 벡터공간이다(초기값 \(a_0, a_1\)이 해를 정함). (a) \(r_1^n\), \(r_2^n\)은 해이고 일차독립이라 기저. (b) \(nr^n\)이 해임은 \(r^2 = c_1r + c_2\)와 \(2r = c_1\)(중근 조건)을 써서 대입으로 확인. ∎

예제 3.3.3

피보나치 \(F_n = F_{n-1} + F_{n-2}\), \(F_0 = 0\), \(F_1 = 1\)의 일반항을 구하여라.

풀이. \(r^2 = r + 1\), \(r = \phi = \frac{1 + \sqrt5}2\), \(\psi = \frac{1 - \sqrt5}2\). \(F_0 = \alpha + \beta = 0\), \(F_1 = \alpha\phi + \beta\psi = 1\)에서 \(\alpha = \frac1{\sqrt5}\), \(\beta = -\frac1{\sqrt5}\).

\[F_n = \frac{\phi^n - \psi^n}{\sqrt5}\quad(\text{비네 공식}).\]

\(|\psi| < 1\)이라 \(F_n\)은 \(\frac{\phi^n}{\sqrt5}\)에 가장 가까운 정수이고, \(\frac{F_{n+1}}{F_n} \to \phi \approx 1.618\)입니다. 예: \(F_{10} = 55\), \(\frac{\phi^{10}}{\sqrt5} \approx 55.004\). 같은 절의 탐구 카드에서 계수를 바꾸며 지배적인 근을 볼 수 있습니다.

3.3.3비동차 점화식

\(a_n = c_1a_{n-1} + c_2a_{n-2} + f(n)\)의 일반해는 동차 일반해 + 특수해입니다(미분방정식 2.3절과 같은 구조). \(f(n)\)이 다항식·지수이면 같은 꼴로 추측합니다.

예제 3.3.4 (하노이의 탑)

원판 \(n\)개를 옮기는 최소 횟수 \(h_n = 2h_{n-1} + 1\), \(h_1 = 1\)을 풀어라.

풀이. 동차해 \(\alpha2^n\), 특수해 상수 \(c\): \(c = 2c + 1\), \(c = -1\). \(h_n = \alpha2^n - 1\), \(h_1 = 1\)에서 \(\alpha = 1\). \(h_n = 2^n - 1\). 원판 64개면 약 \(1.8\times10^{19}\)번입니다.

흔한 실수(1) 중근에서 \(\alpha r^n + \beta r^n\)으로 쓴다: \(nr^n\)이 필요하다. (2) 특수해 추측이 동차해와 겹치는데 \(n\)을 곱하지 않는다: \(a_n = 2a_{n-1} + 2^n\)이면 \(c\cdot2^n\)이 아니라 \(cn2^n\). (3) 초기값의 첨자(0부터인지 1부터인지)를 섞는다.
요약
  1. "마지막 단계로 나누기"로 점화식을 세운다.
  2. 특성방정식 \(r^2 = c_1r + c_2\): 서로 다른 근 \(\alpha r_1^n + \beta r_2^n\), 중근 \((\alpha + \beta n)r^n\).
  3. 비동차는 동차해 + 특수해. 피보나치는 비네 공식, 하노이는 \(2^n - 1\).

3.3.4연습문제

기본

  1. \(a_n = 5a_{n-1} - 6a_{n-2}\), \(a_0 = 1\), \(a_1 = 0\)을 풀어라.
    답

    근 2, 3. \(\alpha + \beta = 1\), \(2\alpha + 3\beta = 0\). \(a_n = 3\cdot2^n - 2\cdot3^n\).

응용

  1. 길이 \(n\)인 비트열 중 1이 연속하지 않는 것의 수 \(b_n\)의 점화식과 \(b_5\)를 구하여라.
    답

    끝이 0이면 \(b_{n-1}\), 끝이 01이면 \(b_{n-2}\). \(b_1 = 2\), \(b_2 = 3\), \(b_5 = 13\).

심화

  1. \(a_n = 4a_{n-1} - 4a_{n-2}\), \(a_0 = 1\), \(a_1 = 4\)를 풀어라.
    답

    중근 2. \(a_n = (1 + n)2^n\).

3.3.2

탐구큰 근이 수열을 지배한다

탐구 · 선형 점화식과 특성근

다루는 성취기준 [수학3-03-03]

질문

\(a_n = c_1a_{n-1} + c_2a_{n-2}\)의 수열은 길게 보면 어떻게 자랄까요? 연속한 두 항의 비 \(\frac{a_{n+1}}{a_n}\)은 어디로 갈까요?

복원

특성근 \(r_1, r_2\)로 \(a_n = \alpha r_1^n + \beta r_2^n\)이고, 중근이면 \((\alpha + \beta n)r^n\) (3.3절).

해 보기

  1. 처음 화면은 피보나치(\(c_1 = c_2 = 1\))입니다. 비가 1, 2, 1.5, 1.67, …으로 흔들리다 \(\phi \approx 1.618\)에 붙습니다.
  2. \(c_1 = 5\)는 범위 밖이니 \(c_1 = 1\), \(c_2 = 2\)로 해 보세요. 근 2와 \(-1\)이라 \(a_n\)은 \(2^n\) 꼴로 자라고 비는 2로 갑니다.
  3. \(c_1 = 2\), \(c_2 = -1\)이면 중근 1이라 \(a_n = \alpha + \beta n\), 직선처럼 자랍니다(비는 1로 아주 천천히).
  4. \(c_1 = 1\), \(c_2 = -1\)이면 근이 복소수(절댓값 1)라 수열이 0, 1, 1, 0, −1, −1, 0, …으로 주기 6을 돕니다. 비는 수렴하지 않습니다.

설명

  1. 지배적인 근\(|r_1| > |r_2|\)이고 \(\alpha \ne 0\)이면 \(a_n = r_1^n\left(\alpha + \beta(r_2/r_1)^n\right)\)에서 괄호 안이 \(\alpha\)로 가므로 \(\frac{a_{n+1}}{a_n} \to r_1\)입니다.
  2. 초기값이 특별하면초기값을 \(\alpha = 0\)이 되게 고르면(예: \(c_1 = 1\), \(c_2 = 2\), \(a_0 = 1\), \(a_1 = -1\)) 작은 근의 성분만 남아 \(a_n = (-1)^n\)입니다.

판단

"계수가 양수인 점화식의 비는 늘 수렴한다"는 이 카드의 범위에서는 맞지만(\(c_1, c_2 > 0\)이면 양의 지배근이 있음), "계수가 실수이면 늘 수렴한다"는 틀립니다. 복소근이나 크기가 같은 두 실근(\(\pm r\))이면 비가 진동합니다.
