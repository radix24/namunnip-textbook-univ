5.3.1문제

지도 앱은 교차로를 꼭짓점, 도로를 변, 이동 시간을 가중치로 하는 그래프에서 출발점 \(s\)부터 모든 곳까지의 최단 시간을 구합니다. 경로의 길이는 지나는 변의 가중치 합입니다. 경로는 아주 많아(지수적으로) 모두 비교할 수 없습니다.

5.3.2알고리즘

각 꼭짓점에 "지금까지 알려진 최단 거리" \(d(v)\)를 적어 둡니다. 처음에는 \(d(s) = 0\), 나머지 \(\infty\).

  1. 확정되지 않은 꼭짓점 중 \(d\)가 가장 작은 \(u\)를 확정한다.
  2. \(u\)의 이웃 \(v\)마다 \(d(v) \leftarrow \min(d(v), d(u) + w(u, v))\)로 줄인다(완화).
  3. 모든 꼭짓점이 확정될 때까지 반복한다.
예제 5.3.1

꼭짓점 A–E, 변 AB 4, AC 2, BC 1, BD 5, CD 8, CE 10, DE 2. A에서 출발해 최단 거리를 구하여라.

풀이.

  • A 확정(0). 완화: B 4, C 2.
  • C 확정(2). 완화: B \(\min(4, 2 + 1) = 3\), D 10, E 12.
  • B 확정(3). 완화: D \(\min(10, 3 + 5) = 8\).
  • D 확정(8). 완화: E \(\min(12, 8 + 2) = 10\).
  • E 확정(10).

결과: A 0, B 3 (A–C–B), C 2, D 8 (A–C–B–D), E 10 (A–C–B–D–E). 직접 이어진 A–B(4)보다 C를 거친 길(3)이 짧습니다. 같은 절의 탐구 카드에서 한 단계씩 실행할 수 있습니다.

5.3.3왜 옳은가

정리 5.3.2

가중치가 모두 음이 아니면, 꼭짓점 \(u\)가 확정되는 순간의 \(d(u)\)는 \(s\)에서 \(u\)까지의 최단 거리이다.

증명.처음으로 틀리게 확정되는 \(u\)가 있다고 하자. 진짜 최단 경로 \(P\)를 따라가면 처음으로 확정되지 않은 꼭짓점 \(y\)가 있고, 그 앞 \(x\)는 이미 (올바르게) 확정되어 \(y\)를 완화했으므로 \(d(y) \le \operatorname{dist}(x) + w(x, y) = \operatorname{dist}(y)\). \(P\)에서 \(y\) 이후의 가중치가 음이 아니라 \(\operatorname{dist}(y) \le \operatorname{dist}(u) < d(u)\). 그러면 \(d(y) < d(u)\)인데 알고리즘은 \(u\)를 골랐으니 모순. ∎

음수 가중치가 있으면 실패할 수 있습니다: A→B 2, A→C 3, C→B −2인 방향 그래프에서 B가 거리 2로 먼저 확정되지만 A–C–B는 1입니다(이때는 벨만-포드 알고리즘을 씁니다). 꼭짓점 \(n\)개, 변 \(m\)개이면 우선순위 큐로 \(O((n + m)\log n)\)입니다.

흔한 실수(1) 완화 후 바로 확정한다: 확정은 남은 것 중 \(d\)가 가장 작은 것 하나뿐이다. (2) 확정된 꼭짓점의 \(d\)를 나중에 다시 줄인다: 음이 아닌 가중치에서는 그럴 일이 없다. (3) 최단 경로 자체를 기록하지 않는다: 완화할 때 "직전 꼭짓점"을 적어 두면 경로를 되짚을 수 있다.
요약
  1. \(d\)가 가장 작은 미확정 꼭짓점을 확정하고 이웃을 완화한다.
  2. 가중치가 음이 아니면 확정된 거리는 최단이다(귀류법).
  3. 음수 가중치에서는 틀릴 수 있다.

5.3.4연습문제

기본

  1. 예제에서 E에서 출발한 최단 거리를 구하여라.
    답

    E 0, D 2, B 7, C 8, A 10 (C는 E–C 10보다 E–D–B–C 8이 짧음).

응용

  1. 모든 가중치가 1이면 다익스트라는 어떤 알고리즘과 같아지는가?
    답

    너비 우선 탐색(BFS). 거리 순으로 층층이 확정한다.

심화

  1. 모든 가중치에 같은 양수 \(c\)를 더하면 최단 경로가 바뀔 수 있음을 예로 보여라.
    답

    A–B 3(변 1개) 대 A–C–B 1+1(변 2개). \(c = 2\)를 더하면 5 대 6으로 바뀐다. 변이 많은 경로가 더 불리해진다.

5.3.2

탐구가까운 곳부터 확정하기

탐구 · 다익스트라 알고리즘

다루는 성취기준 [수학3-05-03]

질문

출발점에서 모든 곳까지의 최단 거리를, 모든 경로를 비교하지 않고 구하려면 어떤 순서로 계산해야 할까요?

복원

미확정 꼭짓점 중 \(d\)가 가장 작은 것을 확정하고, 그 이웃을 \(d(v) \leftarrow \min(d(v), d(u) + w)\)로 완화한다. 가중치가 음이 아니면 확정된 값은 최단이다 (5.3절).

해 보기

  1. 출발 A에서 단계를 1씩 올리세요. A(0) → C(2) → B(3) → D(8) → E(10) 순서로 확정됩니다(예제 5.3.1).
  2. 2단계에서 B의 값이 4에서 3으로 줄어듭니다. 직접 잇는 A–B보다 C를 거치는 길이 짧기 때문입니다. 굵은 선도 A–B에서 C–B로 옮겨 갑니다.
  3. 출발을 E로 바꾸면 E 0, D 2, B 7, C 8, A 10입니다. C는 직접 잇는 10보다 E–D–B–C(8)가 짧습니다.
  4. 끝난 뒤의 굵은 선은 나무를 이룹니다(최단 경로 나무). 꼭짓점 5개에 변 4개입니다.

설명

  1. 확정이 되돌려지지 않는 이유가장 작은 \(d\)를 가진 꼭짓점에 더 짧게 가려면 다른 미확정 꼭짓점을 거쳐야 하는데, 그 꼭짓점까지가 이미 더 길고 가중치는 음이 아니라 줄어들 수 없습니다.
  2. 직전 꼭짓점완화할 때마다 "어디서 왔는지"를 기록하면, 끝난 뒤 거꾸로 따라가 최단 경로 자체를 얻습니다. 지도 앱이 경로를 그려 주는 방법입니다.

판단

"변이 적은 경로가 더 짧다"는 틀립니다. A에서 B로 가는 최단 경로는 변 하나(무게 4)가 아니라 변 둘(2 + 1 = 3)입니다. 다익스트라는 변의 개수가 아니라 무게의 합을 비교합니다.
