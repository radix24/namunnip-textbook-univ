3.1.1두 법칙

  • 합의 법칙: 겹치지 않는 경우 \(A\), \(B\)가 각각 \(m\), \(n\)가지이면 \(A\) 또는 \(B\)는 \(m + n\)가지. 겹치면 포함배제 \(|A \cup B| = |A| + |B| - |A \cap B|\).
  • 곱의 법칙: 첫 단계 \(m\)가지, 각각에 대해 둘째 단계 \(n\)가지이면 \(mn\)가지.

3.1.2네 가지 기본 상황

\(n\)종류에서 \(k\)개를 고를 때, 순서를 따지는지와 같은 것을 여러 번 고를 수 있는지로 나뉩니다.

중복 허용중복 불가
순서 있음\(n^k\) (중복순열)\(P(n, k) = \frac{n!}{(n-k)!}\) (순열)
순서 없음\(\binom{n + k - 1}{k}\) (중복조합)\(\binom nk = \frac{n!}{k!(n-k)!}\) (조합)

예: 0–9로 만드는 4자리 비밀번호는 \(10^4\), 숫자가 모두 다르면 \(P(10, 4) = 5040\). 10명 중 대표 4명은 \(\binom{10}4 = 210\). 사탕 4개를 아이 10명에게 나눠 주는 방법(사탕은 똑같음)은 \(\binom{13}{4} = 715\).

3.1.3별과 막대

정리 3.1.1

\(x_1 + x_2 + \dots + x_n = k\)의 음이 아닌 정수해의 개수는 \(\binom{n + k - 1}{k}\)이다.

증명.해 하나를 별 \(k\)개와 막대 \(n - 1\)개의 나열로 대응시킨다: 첫 막대 앞의 별 수가 \(x_1\), 첫째와 둘째 막대 사이가 \(x_2\), …. 예: \(n = 3\), \(k = 5\)에서 ★★|★|★★ ↔ \((2, 1, 2)\). 이 대응은 전단사이고, 나열은 \(n + k - 1\)자리 중 별의 자리 \(k\)개를 고르는 것이라 \(\binom{n + k - 1}{k}\)가지. ∎

"각 \(x_i \ge 1\)"이면 먼저 1씩 나눠 주고 \(k - n\)을 나누는 문제가 되어 \(\binom{k - 1}{n - 1}\)입니다. 같은 절의 탐구 카드에서 별과 막대를 직접 옮겨 볼 수 있습니다.

3.1.4이항정리와 항등식

\[(x + y)^n = \sum_{k=0}^n\binom nkx^ky^{n-k}.\]

\((x + y)\)를 \(n\)번 곱할 때 \(x\)를 고르는 괄호 \(k\)개를 정하는 방법이 \(\binom nk\)이기 때문입니다. 여기서 항등식이 나옵니다: \(x = y = 1\)이면 \(\sum\binom nk = 2^n\), 파스칼 \(\binom nk = \binom{n-1}{k-1} + \binom{n-1}{k}\) (특정 원소를 넣느냐 빼느냐), 방데르몽드 \(\binom{m + n}{k} = \sum_j\binom mj\binom n{k - j}\).

흔한 실수(1) 순서가 중요한지 확인하지 않는다: "대표 3명"과 "회장·부회장·총무"는 다르다. (2) 같은 것을 두 번 센다: 남학생 1명 이상을 포함한 3명을 "남학생 1명 고르고 나머지 2명"으로 세면 중복된다. 여사건으로 세는 것이 안전하다. (3) 중복조합에서 \(\binom{n+k-1}{k}\)의 \(n\)과 \(k\)를 바꾼다: \(n\)은 종류(상자) 수, \(k\)는 고르는 개수(별)다.
요약
  1. 순서·중복 여부로 \(n^k\), \(P(n,k)\), \(\binom nk\), \(\binom{n+k-1}k\) 중 고른다.
  2. 중복조합 = 별 \(k\)개와 막대 \(n - 1\)개의 나열.
  3. 이항정리에서 \(\sum\binom nk = 2^n\), 파스칼, 방데르몽드 항등식이 나온다.

3.1.5연습문제

기본

  1. MISSISSIPPI의 글자를 늘어놓는 방법의 수는?
    답

    \(\frac{11!}{1!\,4!\,4!\,2!} = 34650\).

  2. \(x_1 + x_2 + x_3 = 10\)의 양의 정수해의 개수는?
    답

    \(\binom{9}{2} = 36\).

응용

  1. 1부터 1000까지 중 2, 3, 5 중 어느 것으로도 나누어떨어지지 않는 수의 개수를 포함배제로 구하여라.
    답

    \(1000 - (500 + 333 + 200) + (166 + 100 + 66) - 33 = 266\).

심화

  1. \(\sum_{k=0}^n\binom nk^2 = \binom{2n}{n}\)을 방데르몽드 항등식으로 보여라.
    답

    \(\binom{2n}{n} = \sum_j\binom nj\binom n{n-j} = \sum_j\binom nj^2\) (\(\binom n{n-j} = \binom nj\)).

3.1.2

탐구별과 막대로 나누기를 세기

탐구 · 중복조합

다루는 성취기준 [수학3-03-01]

질문

똑같은 사탕 \(k\)개를 아이 \(n\)명에게 나눠 주는 방법은 몇 가지일까요? 나누는 방법 하나하나를 어떻게 빠짐없이 늘어놓을 수 있을까요?

복원

\(x_1 + \dots + x_n = k\)의 음이 아닌 정수해는 별 \(k\)개와 막대 \(n - 1\)개의 나열과 일대일 대응이라 \(\binom{n+k-1}{k}\)개다 (3.1절).

해 보기

  1. \(n = 3\), \(k = 5\)이면 모두 \(\binom 75 = 21\)가지입니다. 번호를 1부터 21까지 움직이며 막대 두 개가 7칸 중 어디에 있는지 보세요.
  2. 막대가 맨 앞에 있으면 \(x_1 = 0\), 막대 두 개가 붙어 있으면 가운데 상자가 0입니다. 빈 상자도 허용됩니다.
  3. \(n = 6\), \(k = 8\)이면 \(\binom{13}{8} = 1287\)가지로 늘어납니다.

설명

  1. 세는 대상을 바꾸기나누는 방법을 직접 세는 대신, 같은 개수의 "별·막대 나열"을 셉니다. 나열은 막대(또는 별)의 자리만 고르면 되므로 조합이 됩니다. 전단사로 세는 대상을 바꾸는 것이 조합론의 기본 기술입니다.

판단

"사탕 5개를 3명에게 나누는 방법은 \(3^5 = 243\)가지"는 사탕을 서로 구별할 때의 답입니다. 사탕이 똑같으면 누가 몇 개 받는지만 중요해 21가지입니다.
