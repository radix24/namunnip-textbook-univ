4.2.1공개 키 암호

인터넷에서 처음 만난 상대와 비밀 메시지를 주고받으려면, 미리 비밀 열쇠를 나눌 수 없다는 문제가 있습니다. 공개 키 암호는 누구나 쓸 수 있는 "잠그는 열쇠"를 공개하고, "여는 열쇠"는 받는 사람만 가집니다. RSA(1977)는 큰 수의 소인수분해가 어렵다는 사실에 기댑니다.

4.2.2알고리즘

  1. 키 만들기: 큰 소수 \(p, q\)를 고르고 \(n = pq\), \(\varphi = (p - 1)(q - 1)\). \(\gcd(e, \varphi) = 1\)인 \(e\)를 고르고, \(d = e^{-1} \bmod \varphi\) (확장 호제법). 공개 키 \((n, e)\), 비밀 키 \(d\).
  2. 암호화: 평문 \(m\) (\(0 \le m < n\))을 \(c = m^e \bmod n\).
  3. 복호화: \(m = c^d \bmod n\).
정리 4.2.1

\(ed \equiv 1 \pmod\varphi\)이면 모든 \(m\)에 대해 \(m^{ed} \equiv m \pmod n\).

증명.\(ed = 1 + k(p - 1)(q - 1)\). \(p \nmid m\)이면 페르마 소정리 \(m^{p-1} \equiv 1 \pmod p\)로 \(m^{ed} = m\cdot(m^{p-1})^{k(q-1)} \equiv m \pmod p\). \(p \mid m\)이면 양변이 0. 같은 이유로 \(\bmod q\)에서도 성립하고, \(p, q\)가 서로 다른 소수라 \(\bmod pq\)에서 성립(중국인의 나머지 정리). ∎

예제 4.2.2

\(p = 61\), \(q = 53\), \(e = 17\)로 키를 만들고 \(m = 65\)를 암호화·복호화하여라.

풀이. \(n = 3233\), \(\varphi = 60\cdot52 = 3120\). 확장 호제법으로 \(17d \equiv 1 \pmod{3120}\)을 풀면 \(d = 2753\) (\(17\cdot2753 = 46801 = 15\cdot3120 + 1\)). \(c = 65^{17} \bmod 3233 = 2790\), \(2790^{2753} \bmod 3233 = 65\). 같은 절의 탐구 카드에서 직접 해 볼 수 있습니다.

4.2.3빠른 거듭제곱과 안전성

\(m^e\)를 \(e\)번 곱하면 \(e\)가 수백 자리일 때 불가능합니다. 지수를 이진법으로 쓰고 제곱을 되풀이하면 곱셈 \(O(\log e)\)번이면 됩니다: \(65^{17} = 65^{16}\cdot65\), \(65^{16} = (((65^2)^2)^2)^2\), 매번 \(\bmod n\)으로 줄입니다.

공격자는 \(n, e\)를 알지만 \(d\)를 구하려면 \(\varphi = (p-1)(q-1)\)이 필요하고, 그러려면 \(n\)을 소인수분해해야 합니다. 2048비트(약 617자리) \(n\)의 소인수분해는 현재 알려진 방법으로 사실상 불가능합니다. 반면 곱셈, 거듭제곱, 호제법은 모두 \(O(\log n)\)번의 연산이라 빠릅니다. "한쪽 방향은 쉽고 반대 방향은 어려운" 비대칭이 공개 키 암호의 핵심입니다.

흔한 실수(1) \(d = e^{-1} \bmod n\)으로 계산한다: 법은 \(n\)이 아니라 \(\varphi(n)\)이다. (2) 작은 수 예제에서 \(m \ge n\)을 암호화한다: \(m\)은 \(n\)보다 작아야 복원된다. (3) 같은 평문을 그대로 암호화하면 늘 같은 암호문이 나와 안전하지 않다: 실제로는 무작위 덧붙이기(패딩)를 한다.
요약
  1. \(n = pq\), \(ed \equiv 1 \pmod{(p-1)(q-1)}\). 암호화 \(m^e\), 복호화 \(c^d\) (\(\bmod n\)).
  2. 페르마 소정리와 중국인의 나머지 정리로 \(m^{ed} \equiv m\).
  3. 제곱하여 곱하기로 빠르게 계산, 안전성은 소인수분해의 어려움.

4.2.4연습문제

기본

  1. \(p = 5\), \(q = 11\), \(e = 3\)일 때 \(d\)를 구하고 \(m = 2\)를 암호화하여라.
    답

    \(\varphi = 40\), \(d = 27\). \(c = 8\). 복호화 \(8^{27} \bmod 55 = 2\).

응용

  1. \(3^{13} \bmod 7\)을 제곱하여 곱하기로 계산하여라.
    답

    \(13 = 8 + 4 + 1\). \(3^2 = 2\), \(3^4 = 4\), \(3^8 = 2\). \(3^{13} = 2\cdot4\cdot3 = 24 \equiv 3\).

심화

  1. \(n = pq\)와 \(\varphi(n)\)을 알면 \(p, q\)를 쉽게 구할 수 있음을 보여라.
    답

    \(p + q = n - \varphi + 1\), \(pq = n\)이라 \(p, q\)는 이차방정식 \(x^2 - (n - \varphi + 1)x + n = 0\)의 근. 그래서 \(\varphi\)를 구하는 것은 소인수분해만큼 어렵다.

4.2.2

탐구손바닥만 한 RSA

탐구 · 공개 키 암호의 계산

다루는 성취기준 [수학3-04-02]

질문

공개 키 \((n, e)\)로 잠근 메시지가 비밀 키 \(d\)로 정말 원래대로 돌아올까요? \(e\)를 아무 수로나 골라도 될까요?

복원

\(n = pq\), \(\varphi = (p-1)(q-1)\), \(\gcd(e, \varphi) = 1\), \(d = e^{-1} \bmod \varphi\). 암호화 \(c = m^e \bmod n\), 복호화 \(m = c^d \bmod n\) (4.2절).

해 보기

  1. 처음 화면(\(p = 61\), \(q = 53\), \(e = 17\))은 예제 4.2.2입니다. \(d = 2753\), 평문 65 → 암호문 2790 → 복호 65.
  2. 평문을 아무 값으로 움직여도 복호 결과가 평문과 같습니다(정리 4.2.1).
  3. \(e = 13\)으로 바꾸면 \(\varphi = 3120\)과 공약수 13이 있어 \(d\)가 없습니다. \(e\)는 \(\varphi\)와 서로소여야 합니다.
  4. \(p = q\)로 두면 경고가 나옵니다. 같은 소수 두 개를 쓰면 \(n = p^2\)에서 \(\varphi\)가 \((p-1)^2\)이 아니어서 공식이 틀립니다.

설명

  1. 계산 속도\(c^d\)의 \(d = 2753\)번 곱하기 대신, 지수를 이진법(\(2753 = 2048 + 512 + 128 + 64 + 1\))으로 쓰고 제곱을 되풀이해 곱셈 약 20번으로 계산합니다.
  2. 이 예의 약점\(n = 3233\)은 손으로도 \(61\times53\)으로 쪼갤 수 있어 \(d\)가 드러납니다. 실제 RSA는 수백 자리 소수를 쓰고, 그 곱을 소인수분해하는 알려진 방법은 너무 느립니다.

판단

"암호문을 \(e\)번째 거듭제곱근으로 되돌리면 된다"는 실수에서의 생각입니다. \(\bmod n\)에서 \(e\)제곱근을 구하는 쉬운 방법은 \(d\)를 아는 것뿐이고, \(d\)를 구하려면 \(\varphi(n)\), 곧 \(n\)의 소인수분해가 필요합니다.
