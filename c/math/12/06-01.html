6.1.1연산이 두 개인 구조

정수, 다항식, 행렬, 나머지 \(\mathbb Z_n\)에는 덧셈과 곱셈이 함께 있고 분배법칙으로 이어져 있습니다. 군이 "연산 하나"의 구조였다면, 환은 "덧셈과 곱셈"의 구조입니다.

정의 6.1.1 (환)

환: 집합 \(R\)과 두 이항연산 \(+, \cdot\)으로, \((R, +)\)가 가환군이고, 곱셈이 결합적이며, 분배법칙 \(a(b + c) = ab + ac\), \((a + b)c = ac + bc\)가 성립하는 것.

가환환: 곱셈이 가환인 환.

단위원: 곱셈의 항등원 \(1\) (\(1 \ne 0\)). 이 교재의 환은 특별한 말이 없으면 단위원이 있다.

가역원(단원): \(ab = ba = 1\)인 \(b\)가 있는 \(a\). 가역원 전체 \(R^\times\)는 곱셈군이다.

영인자: \(a \ne 0\)인데 \(ab = 0\)인 \(b \ne 0\)이 있는 \(a\).

정역: 영인자가 없는 가환환(단위원 있음).

체: 0이 아닌 모든 원소가 가역원인 가환환.

공리에서 바로 나오는 성질: \(0\cdot a = 0\) (\(0a = (0 + 0)a = 0a + 0a\)에서 소거), \((-a)b = -(ab)\), \((-1)(-1) = 1\). "음수 곱하기 음수는 양수"는 분배법칙의 결과입니다.

예제 6.1.2

다음을 환, 정역, 체로 분류하여라. (a) \(\mathbb Z\) (b) \(\mathbb Q, \mathbb R, \mathbb C\) (c) \(\mathbb Z_6\) (d) \(\mathbb Z_7\) (e) \(M_2(\mathbb R)\) (f) \(\mathbb R[x]\) (g) \(2\mathbb Z\)

풀이.

  • (a) 정역이지만 체가 아님(2의 역원이 없음).
  • (b) 체.
  • (c) 가환환이지만 \(2\cdot3 = 0\)이라 영인자가 있어 정역이 아님.
  • (d) 체: 0 아닌 원소마다 역원이 있음(\(3\cdot5 = 15 \equiv 1\) 등).
  • (e) 비가환환, 영인자 있음(\(\begin{pmatrix}1&0\\0&0\end{pmatrix}\begin{pmatrix}0&0\\0&1\end{pmatrix} = O\)).
  • (f) 정역(최고차항끼리 곱하면 0이 아님), 체가 아님(\(x\)의 역원 없음).
  • (g) 단위원이 없는 환(\(1 \notin 2\mathbb Z\)).

6.1.2소거법칙과 유한 정역

정리 6.1.3

가환환 \(R\)이 정역 \(\iff\) \(a \ne 0\)이고 \(ab = ac\)이면 \(b = c\) (곱셈 소거법칙).

증명.(⇒) \(ab = ac\)이면 \(a(b - c) = 0\)이고 \(a \ne 0\)이라 \(b - c = 0\). (⇐) \(ab = 0 = a\cdot0\)이면 소거로 \(b = 0\). ∎

체는 정역입니다: \(ab = 0\), \(a \ne 0\)이면 \(b = a^{-1}ab = 0\). 거꾸로는 \(\mathbb Z\)에서 보듯 성립하지 않습니다. 그러나 유한이면 성립합니다.

정리 6.1.4

유한 정역은 체이다.

생각. \(a \ne 0\)에 대해 \(ax = 1\)을 풀어야 합니다. "곱하기 \(a\)"라는 함수가 일대일이면 유한집합에서는 전사이고, 그러면 1도 어떤 \(ax\)로 나옵니다.

증명.\(R\)이 유한 정역, \(a \ne 0\)이라 하자. \(f(x) = ax\)는 \(R \to R\)이고, 소거법칙으로 \(ax = ay \Rightarrow x = y\), 곧 단사다. \(R\)이 유한이므로 전사이고, \(ab = 1\)인 \(b\)가 있다. 가환이라 \(ba = 1\)도 성립한다. ∎

따름정리 6.1.5

\(\mathbb Z_n\)에 대해 체 \(\iff\) 정역 \(\iff\) \(n\)이 소수.

증명.\(n = ab\) (\(1 < a, b < n\))이면 \(a\cdot b = 0\)이라 영인자가 있다. \(n = p\)가 소수이면 \(ab \equiv 0 \pmod p\)에서 \(p \mid ab\)이고 유클리드 보조정리로 \(p \mid a\) 또는 \(p \mid b\), 곧 정역이다. 유한이라 체. ∎

더 일반적으로 \(\mathbb Z_n\)의 0 아닌 원소 \(a\)는 \(\gcd(a, n) = 1\)이면 가역원, 아니면 영인자로, 둘 중 하나입니다(같은 절의 탐구 카드). 유한 가환환에서는 이 이분법이 늘 성립합니다.

흔한 실수(1) \(ab = 0\)에서 곧바로 \(a = 0\) 또는 \(b = 0\)이라 쓴다: 정역에서만 맞다. \(\mathbb Z_{12}\)에서 \(x^2 = 0\)의 해는 0과 6이다. (2) 방정식 \(x^2 = x\)의 해를 0과 1뿐이라 한다: \(\mathbb Z_6\)에서는 3, 4도 해다(\(9 \equiv 3\), \(16 \equiv 4\)). (3) "무한 정역도 체"라고 일반화한다: \(\mathbb Z\), \(\mathbb R[x]\)가 반례다.
요약
  1. 환 ⊃ 가환환 ⊃ 정역 ⊃ 체. 정역 = 영인자 없음 = 곱셈 소거법칙.
  2. 유한 정역은 체(단사 = 전사).
  3. \(\mathbb Z_n\)이 체 \(\iff\) \(n\) 소수. 0 아닌 원소는 가역원이거나 영인자.

6.1.3연습문제

기본

  1. \(\mathbb Z_{10}\)의 가역원과 영인자를 모두 쓰라.
    답

    가역원 1, 3, 7, 9. 영인자 2, 4, 5, 6, 8.

  2. \(\mathbb Z_{11}\)에서 \(4\)의 역원은?
    답

    3 (\(12 \equiv 1\)).

응용

  1. \(\mathbb Z[i] = \{a + bi : a, b \in \mathbb Z\}\)는 정역임을 보이고 가역원을 모두 구하여라.
    답

    \(\mathbb C\)의 부분환이라 영인자가 없다. \(\alpha\beta = 1\)이면 \(|\alpha|^2|\beta|^2 = 1\)이고 \(|\alpha|^2 = a^2 + b^2\)는 양의 정수라 1, 곧 \(\pm1, \pm i\).

심화

  1. 원소가 \(n\)개인 체의 표수(1을 몇 번 더하면 0이 되는가)는 소수임을 보여라.
    답

    \(m\cdot1 = 0\)인 최소 \(m\)이 \(m = ab\)이면 \((a\cdot1)(b\cdot1) = 0\)이고 정역이라 \(a\cdot1 = 0\) 또는 \(b\cdot1 = 0\), 최소성에 모순. 따라서 \(m\)은 소수.

6.1.2

탐구곱하기 a는 자리를 섞는가, 겹치는가

탐구 · 가역원, 영인자, 유한 정역

다루는 성취기준 [수학12-06-01]

질문

\(\mathbb Z_n\)의 원소 \(x\)를 모두 \(a\)배하면 결과가 서로 다를까요? 다르면 \(a\)의 역원이 반드시 있을까요? 언제 \(\mathbb Z_n\)이 체가 될까요?

복원

유한 정역에서 \(x \mapsto ax\) (\(a \ne 0\))는 소거법칙으로 단사, 유한이라 전사, 따라서 \(ab = 1\)인 \(b\)가 있다. \(\mathbb Z_n\)의 0 아닌 원소는 \(\gcd(a, n) = 1\)이면 가역원, 아니면 영인자이다 (6.1절).

해 보기

  1. 처음 화면(\(n = 12\), \(a = 5\))에서 선이 하나도 겹치지 않고 오른쪽 점을 모두 채웁니다. 노란 선이 \(5\cdot5 = 25 \equiv 1\), 곧 5는 자기 자신이 역원입니다.
  2. \(a = 4\)로 바꾸면 선이 0, 4, 8 세 곳에 네 개씩 모입니다. \(4\cdot3 = 0\)이라 영인자이고, 상에 1이 없어 역원도 없습니다.
  3. \(n\)을 13, 17, 29 같은 소수로 두면 빨간 점이 없어지고 출력이 "체입니다"로 바뀝니다. \(n = 25\)이면 5의 배수만 빨강입니다.
  4. 여러 \(n\)에서 파란 점의 개수를 세어 보세요. \(\varphi(n)\)이고, 6.4절의 오일러 정리에서 다시 씁니다.

설명

  1. 이분법\(g = \gcd(a, n) > 1\)이면 \(a\cdot\frac ng = n\cdot\frac ag \equiv 0\)이라 영인자입니다. \(g = 1\)이면 베주 항등식 \(ax + ny = 1\)로 역원 \(x\)가 있습니다. 둘이 동시에 될 수는 없습니다(가역원 \(a\)에 \(ab = 0\)이면 \(b = a^{-1}ab = 0\)).
  2. 유한성의 역할\(\mathbb Z\)에서 \(x \mapsto 2x\)는 단사지만 1이 상에 없습니다. 유한집합이라야 "단사이면 전사"가 성립해 역원이 생깁니다.

판단

"\(\mathbb Z_n\)에서 \(ax = ay\)이고 \(a \ne 0\)이면 \(x = y\)"는 \(n\)이 소수일 때만 늘 맞습니다. \(\mathbb Z_{12}\)에서 \(4\cdot1 = 4\cdot4 = 4\)입니다. 양변을 \(a\)로 나눌 수 있으려면 \(a\)가 가역원이어야 합니다.
