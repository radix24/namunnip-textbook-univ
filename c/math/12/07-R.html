7.R.1

연습유클리드정역과 주아이디얼정역 연습 문제

문제 6 · 개념·계산·증명·판단 · 힌트 2단계

다루는 성취기준 [수학12-07-01] [수학12-07-02]

혼자 풀고, 막히면 힌트 1 → 힌트 2 → 풀이 순서로 여세요.

  1. 계산\(\mathbb Z\)에서 아이디얼 \((84, 120)\)의 생성원과 베주 계수를 구하여라. [07-01]

    힌트 1

    호제법: \(120 = 1\cdot84 + 36\)(7.1절).

    힌트 2

    \(84 = 2\cdot36 + 12\), \(36 = 3\cdot12\).

    풀이

    \(\gcd = 12\), \((84, 120) = (12)\). \(12 = 84 - 2\cdot36 = 84 - 2(120 - 84) = 3\cdot84 - 2\cdot120\).

  2. 증명PID에서 0이 아닌 소 아이디얼은 극대 아이디얼임을 보여라. [07-01]

    힌트 1

    \((p) \subseteq (m)\)이면 \(p = mt\).

    힌트 2

    소 아이디얼이라 \(m \in (p)\) 또는 \(t \in (p)\).

    풀이

    \((p) \subseteq (m)\), \(p = mt\). \(mt \in (p)\)이므로 \(m \in (p)\)이면 \((m) = (p)\). \(t \in (p)\)이면 \(t = ps\), \(p = mps\), 소거로 \(ms = 1\), \(m\) 가역이라 \((m) = D\). ∎

  3. 개념\(\mathbb Z[x]\)가 유클리드정역이 아닌 이유를 아이디얼 하나로 설명하여라. [07-01]

    힌트 1

    유클리드정역이면 PID입니다.

    힌트 2

    \((2, x)\).

    풀이

    \((2, x)\)가 주아이디얼이 아니다. 생성원 \(f\)가 2와 \(x\)를 나누면 \(f = \pm1\)인데 \(1 \notin (2, x)\) (상수항이 짝수인 다항식만 있음). PID가 아니므로 유클리드정역도 아니다.

  4. 계산\(\mathbb Z[i]\)에서 \(\gcd(5, 3 + i)\)를 구하여라. [07-02]

    힌트 1

    \(\frac{5}{3 + i} = \frac{5(3 - i)}{10}\)(7.2절).

    힌트 2

    노름으로 후보를 좁히세요: \(N(5) = 25\), \(N(3+i) = 10\).

    풀이

    \(\frac5{3+i} = 1.5 - 0.5i\), 몫 \(1\) (또는 \(2\), \(1 - i\) 등 가까운 점 중 하나)로 \(5 = 1\cdot(3 + i) + (2 - i)\). \(\frac{3 + i}{2 - i} = \frac{(3+i)(2+i)}{5} = 1 + i\), 나머지 0. \(\gcd = 2 - i\) (노름 5, 공통 노름 인수 5와 맞음).

  5. 증명\(\pi \in \mathbb Z[i]\)에서 \(N(\pi)\)가 소수이면 \(\pi\)는 기약원임을 보여라. [07-02]

    힌트 1

    \(\pi = \alpha\beta\)이면 \(N(\pi) = N(\alpha)N(\beta)\).

    힌트 2

    노름 1인 원소는 가역원.

    풀이

    소수 \(N(\pi) = N(\alpha)N(\beta)\)이라 한쪽 노름이 1, 곧 가역원. 따라서 기약. ∎ (예: \(1 + i\), \(2 + i\), \(3 + 2i\).)

  6. 판단한 학생이 "\(3\)은 \(\mathbb Z\)의 소수이므로 \(\mathbb Z[i]\)에서도 소원이고, \(5\)도 마찬가지"라고 썼다. 맞는가? [07-02]

    힌트 1

    \(5\)를 두 제곱수의 합으로 써 보세요.

    힌트 2

    \(3 = a^2 + b^2\)은 불가능합니다.

    풀이

    절반만 맞다. \(5 = (2 + i)(2 - i)\)라 \(\mathbb Z[i]\)에서 기약이 아니다. \(3\)은 \(3 = \alpha\beta\)(비가역)이면 \(N(\alpha) = 3 = a^2 + b^2\)이어야 하는데 불가능하므로 기약, PID라 소원이다. \(p \equiv 1 \pmod 4\)인 소수는 쪼개지고 \(p \equiv 3\)은 그대로 남는다.
