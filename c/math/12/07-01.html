7.1.1나눗셈 정리를 공리로

정수의 산술에서 거의 모든 것(최대공약수, 베주 항등식, 소인수분해의 유일성)은 "나머지가 나누는 수보다 작게 나눌 수 있다"는 나눗셈 정리에서 나왔습니다. 실계수 다항식도 차수가 줄어드는 나눗셈이 있어 같은 이론이 성립합니다. 이 공통점을 뽑아낸 것이 유클리드정역입니다.

정의 7.1.1 (유클리드정역, 주아이디얼정역)

유클리드정역: 정역 \(D\)와 함수 \(N: D\setminus\{0\} \to \{0, 1, 2, \dots\}\)가 있어, 모든 \(a\)와 \(b \ne 0\)에 대해 \(a = qb + r\), \(r = 0\) 또는 \(N(r) < N(b)\)인 \(q, r\)이 있는 것.

주아이디얼정역(PID): 모든 아이디얼이 주아이디얼 \((a)\)인 정역.

예: \(\mathbb Z\) (\(N(a) = |a|\)), 체 \(F\) 위의 다항식환 \(F[x]\) (\(N(f) = \deg f\)), 가우스 정수 \(\mathbb Z[i]\) (\(N(a + bi) = a^2 + b^2\), 다음 절).

7.1.2유클리드정역은 PID

정리 7.1.2

유클리드정역은 주아이디얼정역이다.

생각. 1.3절에서 "\(\mathbb Z\)의 부분군은 \(n\mathbb Z\)"를 보일 때, 가장 작은 양의 원소를 잡고 나눗셈 정리로 나머지가 0임을 보였습니다. 크기 대신 \(N\)을 쓰면 그대로 됩니다.

증명.\(I\)가 아이디얼이다. \(I = \{0\}\)이면 \(I = (0)\). 아니면 \(I\setminus\{0\}\)에서 \(N(b)\)가 최소인 \(b\)를 잡는다(자연수의 정렬 원리). \((b) \subseteq I\)는 \(I\)가 아이디얼이라서다. \(a \in I\)이면 \(a = qb + r\)로 나누고, \(r = a - qb \in I\)이다. \(r \ne 0\)이면 \(N(r) < N(b)\)라 \(b\)의 최소성에 모순이므로 \(r = 0\), 곧 \(a \in (b)\). 따라서 \(I = (b)\). ∎

역은 성립하지 않습니다. \(\mathbb Z[\frac{1 + \sqrt{-19}}{2}]\)는 PID이지만 어떤 \(N\)으로도 유클리드정역이 아닙니다(증명은 어렵습니다). 또 \(\mathbb Z[x]\)는 PID가 아닙니다: \((2, x)\)는 주아이디얼이 아닙니다(6.3절에서 \(\mathbb Z[x]/(2, x) \cong \mathbb Z_2\); 만약 \((2, x) = (f)\)이면 \(f \mid 2\)이고 \(f \mid x\)라 \(f = \pm1\), 그러면 \((2, x) = \mathbb Z[x]\)인데 \(1 \notin (2, x)\)).

7.1.3PID에서의 약수 이론

정의 7.1.3

기약원: 가역원이 아닌 0 아닌 \(p\)로, \(p = ab\)이면 \(a\)나 \(b\)가 가역원인 것.

소원: 가역원이 아닌 0 아닌 \(p\)로, \(p \mid ab\)이면 \(p \mid a\) 또는 \(p \mid b\)인 것.

최대공약수: \(a, b\)의 공약수 \(d\) 중 모든 공약수가 \(d\)를 나누는 것.

정리 7.1.4

PID \(D\)에서 (a) \((a, b) = (d)\)이면 \(d\)는 \(a, b\)의 최대공약수이고 \(d = ax + by\)로 쓸 수 있다(베주). (b) 기약원은 소원이다. (c) \(p\)가 기약원 \(\iff (p)\)가 극대 아이디얼.

증명.(a) \(d \in (a, b)\)라 \(d = ax + by\). \(a, b \in (d)\)라 \(d\)는 공약수이고, 공약수 \(c\)는 \(ax + by = d\)를 나눈다. (c) \((p) \subseteq (m)\)이면 \(p = mt\)이고, 기약이라 \(m\)이 가역(\((m) = D\))이거나 \(t\)가 가역(\((m) = (p)\)). 거꾸로도 같은 논리. (b) \((p)\)가 극대이므로 소 아이디얼(정리 6.2.5), 곧 \(p \mid ab \Rightarrow p \mid a\) 또는 \(p \mid b\). ∎

(b)가 정수론의 유클리드 보조정리이고, 이로부터 소인수분해의 유일성이 나옵니다. 그래서 "유클리드정역 ⇒ PID ⇒ 유일 인수분해 정역(UFD)"이라는 사슬이 성립합니다. 유일 인수분해가 깨지는 예: \(\mathbb Z[\sqrt{-5}]\)에서 \(6 = 2\cdot3 = (1 + \sqrt{-5})(1 - \sqrt{-5})\)이고, 2는 기약이지만 소원이 아닙니다.

흔한 실수(1) "몫과 나머지가 하나뿐"을 정의에 넣는다: 유클리드정역은 존재만 요구한다. \(\mathbb Z\)에서도 \(7 = 2\cdot3 + 1 = 3\cdot3 - 2\)처럼 \(|r| < |b|\)인 나눗셈이 두 개다. (2) 기약원과 소원을 늘 같다고 본다: PID(더 넓게 UFD)에서만 같다.
요약
  1. 유클리드정역 = 크기 \(N\)이 줄어드는 나눗셈이 있는 정역: \(\mathbb Z\), \(F[x]\), \(\mathbb Z[i]\).
  2. 유클리드정역 ⇒ PID (최소 \(N\)인 원소가 생성). \(\mathbb Z[x]\)는 PID가 아님.
  3. PID에서 베주 항등식, 기약원 = 소원, \((p)\) 극대.

7.1.4연습문제

기본

  1. \(\mathbb Q[x]\)에서 \((x^2 - 1, x^2 - 3x + 2)\)의 생성원을 구하여라.
    답

    \(x^2 - 1 = (x-1)(x+1)\), \(x^2 - 3x + 2 = (x-1)(x-2)\). 최대공약수 \(x - 1\).

응용

  1. 체 \(F\)에서 \(F[x]/(f)\)가 체 \(\iff f\)가 기약임을 보여라.
    답

    \(F[x]\)는 유클리드정역이라 PID, 정리 7.1.4(c)와 정리 6.2.5(a).

심화

  1. \(\mathbb Z[\sqrt{-5}]\)에서 2가 기약원임을 \(N(a + b\sqrt{-5}) = a^2 + 5b^2\)으로 보여라.
    답

    \(2 = \alpha\beta\)이면 \(4 = N(\alpha)N(\beta)\). \(N = 2\)인 원소는 \(a^2 + 5b^2 = 2\)의 해가 없어 없다. 따라서 한쪽의 \(N = 1\), 곧 \(\pm1\)(가역).

  1. 유클리드정역이 주아이디얼정역임을 증명할 수 있다.

7.1.2

예제다항식의 최대공약수와 아이디얼의 생성원

예제 · 유클리드정역 Q[x]에서 호제법

다루는 성취기준 [수학12-07-01]

먼저 예측

\(f = x^4 + x^3 + x + 1\)과 \(g = x^3 + 2x^2 + 2x + 1\)이 생성하는 아이디얼 \((f, g)\)는 \(\mathbb Q[x]\)에서 하나의 다항식으로 생성됩니다. 그 다항식은 몇 차일까요?

예측 확인

1차, \(x + 1\)입니다. \((f, g) = (x + 1)\).

유클리드 호제법으로 \(\gcd(f, g)\)를 구하고, \(\gcd = uf + vg\)인 \(u, v \in \mathbb Q[x]\)를 찾아 \((f, g) = (\gcd)\)임을 보여라.

전략

\(\mathbb Q[x]\)는 차수로 나눗셈이 되는 유클리드정역이라 PID입니다(7.1절). 정수에서처럼 나머지가 0이 될 때까지 나누고, 마지막 0 아닌 나머지가 최대공약수입니다. 거꾸로 대입하면 베주 계수가 나옵니다.

풀이

  1. \(f = (x - 1)g + (2x + 2)\).
    \((x - 1)g = x^4 + x^3 - x - 1\)이고 \(f\)에서 빼면 \(2x + 2\). 나머지의 차수 1 < 3.
  2. \(g = (2x + 2)\cdot\tfrac12(x^2 + x + 1) + 0\).
    \(g = (x + 1)(x^2 + x + 1)\). 나머지 0에서 멈춘다.
  3. 마지막 0 아닌 나머지 \(2x + 2\), 최고차 계수를 1로 맞추면 \(\gcd(f, g) = x + 1\).
    \(\mathbb Q\)의 0 아닌 상수는 가역원이라 상수배 차이는 무시한다.
  4. 1단계를 거꾸로 쓰면 \(x + 1 = \tfrac12f - \tfrac12(x - 1)g\).
    \(2x + 2 = f - (x - 1)g\)를 2로 나눔.
  5. 따라서 \(x + 1 \in (f, g)\)이고, \(x + 1\)이 \(f, g\)를 모두 나누므로 \((f, g) = (x + 1)\).
    \((x+1) \subseteq (f, g)\)는 4단계, \((f, g) \subseteq (x+1)\)은 \(f, g\)가 \(x+1\)의 배수라서.

검산

\(f = (x + 1)(x^3 + 1) = (x + 1)^2(x^2 - x + 1)\), \(g = (x + 1)(x^2 + x + 1)\)이고 \(x^2 \pm x + 1\)은 실근이 없어 서로 다른 기약 인수입니다. 공통 인수는 \(x + 1\) 하나로, 호제법 결과와 같습니다. \(x = -1\)을 넣으면 \(f(-1) = 1 - 1 - 1 + 1 = 0\), \(g(-1) = -1 + 2 - 2 + 1 = 0\)입니다.

의미

인수분해를 몰라도 나눗셈만으로 공통 인수를 찾을 수 있습니다. 컴퓨터 대수 시스템이 다항식의 공통근이나 중근(\(\gcd(f, f')\))을 찾을 때 이 방법을 씁니다. 또 아이디얼 \((f, g)\)가 한 원소로 생성된다는 PID 성질이 "최대공약수가 베주 꼴로 쓰인다"와 같은 말임을 보여 줍니다.

이해 확인

\(f\)의 중근을 \(\gcd(f, f')\)로 찾으면?

답

\(f' = 4x^3 + 3x^2 + 1 = (x + 1)(4x^2 - x + 1)\)이라 \(\gcd(f, f') = x + 1\). \(x = -1\)이 중근이다.
