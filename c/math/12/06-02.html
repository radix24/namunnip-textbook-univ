6.2.1곱셈까지 물려받으려면

덧셈 군 \((R, +)\)는 가환이라 모든 부분군이 정규이고, 잉여류 \(a + I\)끼리 더하는 것은 늘 잘 정의됩니다. 곱셈 \((a + I)(b + I) = ab + I\)까지 잘 정의되려면 \(I\)에 무엇이 더 필요할까요? 대표원을 \(a + x\), \(b + y\) (\(x, y \in I\))로 바꾸면

\[(a + x)(b + y) = ab + (ay + xb + xy)\]

이므로 괄호 안이 늘 \(I\)에 있어야 합니다. 곧 \(I\)의 원소에 \(R\)의 아무 원소를 곱해도 \(I\)에 남아야 합니다.

정의 6.2.1 (아이디얼)

환 \(R\)의 덧셈 부분군 \(I\)가 모든 \(r \in R\), \(x \in I\)에 대해 \(rx \in I\), \(xr \in I\)이면 \(I\)를 아이디얼이라 한다. 가환환에서 \((a) = aR = \{ar : r \in R\}\)를 \(a\)가 생성하는 주아이디얼이라 한다.

정리 6.2.2 (잉여환)

\(I\)가 \(R\)의 아이디얼이면 \(R/I = \{a + I\}\)는 \((a + I) + (b + I) = (a + b) + I\), \((a + I)(b + I) = ab + I\)로 환이 된다. 영원은 \(I\), 단위원은 \(1 + I\)이다.

증명.덧셈이 잘 정의되고 가환군이 되는 것은 상군(2.3절). 곱셈: 위의 계산에서 \(ay, xb, xy \in I\)(아이디얼 성질)이고 \(I\)는 덧셈에 닫혀 있으므로 \((a + x)(b + y) + I = ab + I\). 결합법칙, 분배법칙은 \(R\)에서 물려받는다. ∎

\(1 \in I\)이면 \(r = r\cdot1 \in I\)라 \(I = R\)입니다. 그래서 진 아이디얼은 가역원을 포함하지 않고, 체의 아이디얼은 \(\{0\}\)과 체 자신뿐입니다.

6.2.2예

예제 6.2.3

(a) \(\mathbb Z\)의 아이디얼을 모두 구하여라. (b) \(\mathbb R[x]/(x^2 + 1)\)의 원소와 곱셈을 설명하여라. (c) \(\mathbb Z_2[x]/(x^2 + x + 1)\)은 원소가 몇 개이고 체인가?

풀이. (a) 아이디얼은 덧셈 부분군이고 \(\mathbb Z\)의 부분군은 \(n\mathbb Z\)뿐(1.3절)이며, \(n\mathbb Z\)는 정수배에 닫혀 있습니다. 따라서 \(n\mathbb Z = (n)\), \(n \ge 0\). 잉여환 \(\mathbb Z/(n) = \mathbb Z_n\)입니다.

(b) 다항식을 \(x^2 + 1\)로 나누면 나머지가 \(a + bx\) 꼴이므로 각 잉여류에는 대표원 \(a + bx\)가 하나씩 있습니다. 곱하면 \((a + bx)(c + dx) = ac + (ad + bc)x + bdx^2\)이고, \(x^2 \equiv -1\)이므로 \((ac - bd) + (ad + bc)x\)입니다. 이것은 복소수의 곱 그대로라 \(\mathbb R[x]/(x^2 + 1) \cong \mathbb C\) (\(x \leftrightarrow i\))입니다. 복소수는 "\(i^2 = -1\)인 수를 상상한 것"이 아니라 "\(x^2 + 1\)을 0으로 보는 다항식 산술"로 엄밀히 만들 수 있습니다.

(c) 나머지 \(a + bx\) (\(a, b \in \mathbb Z_2\))로 4개입니다. \(x^2 = x + 1\) (\(\mathbb Z_2\)에서 \(-1 = 1\))이라 \(x(x + 1) = x^2 + x = 2x + 1 = 1\)입니다. 0 아닌 세 원소 \(1, x, x + 1\)이 모두 가역이라 원소 4개인 체입니다. \(\mathbb Z_4\)와는 다릅니다(\(\mathbb Z_4\)는 \(2\cdot2 = 0\)).

6.2.3극대 아이디얼과 소 아이디얼

정의 6.2.4

극대 아이디얼: \(M \ne R\)이고 \(M \subseteq J \subseteq R\)인 아이디얼 \(J\)가 \(M\)이나 \(R\)뿐인 것.

소 아이디얼: \(P \ne R\)이고 \(ab \in P\)이면 \(a \in P\) 또는 \(b \in P\)인 것.

정리 6.2.5

가환환 \(R\)과 아이디얼 \(I \ne R\)에 대해 (a) \(R/I\)가 체 \(\iff\) \(I\)가 극대. (b) \(R/I\)가 정역 \(\iff\) \(I\)가 소 아이디얼. 따라서 극대 아이디얼은 소 아이디얼이다.

증명.(a ⇐) \(a \notin M\)이면 \(J = M + aR\)는 \(M\)을 진짜로 포함하는 아이디얼이라 \(R\), 곧 \(1 = m + ar\). 그러면 \((a + M)(r + M) = 1 + M\). (a ⇒) \(M \subsetneq J\)이면 \(a \in J\setminus M\)을 잡아 \(a + M\)의 역원 \(r + M\): \(1 - ar \in M \subseteq J\)이고 \(ar \in J\)라 \(1 \in J\), \(J = R\). (b) \((a + I)(b + I) = I \iff ab \in I\)이므로 "영인자 없음"이 소 아이디얼의 정의 그대로다. ∎

예: \(\mathbb Z\)에서 \((n)\)은 \(n\)이 소수일 때 극대이고(따름정리 6.1.5와 같은 내용), \((0)\)은 소 아이디얼이지만 극대가 아닙니다(\(\mathbb Z/(0) = \mathbb Z\)는 정역, 체 아님).

흔한 실수(1) 부분환과 아이디얼을 혼동한다: \(\mathbb Z\)는 \(\mathbb Q\)의 부분환이지만 아이디얼이 아니다(\(\frac12\cdot1 \notin \mathbb Z\)). (2) 잉여환의 원소를 계산할 때 대표원을 하나로 정하지 않는다: \(\mathbb R[x]/(x^2 + 1)\)에서 \(x^3\)은 \(-x\)로 줄여야 비교할 수 있다.
요약
  1. 아이디얼 = 곱셈으로 흡수하는 덧셈 부분군. 이것이 잉여환의 곱이 잘 정의될 조건이다.
  2. \(\mathbb Z/(n) = \mathbb Z_n\), \(\mathbb R[x]/(x^2+1) \cong \mathbb C\), \(\mathbb Z_2[x]/(x^2+x+1)\)은 원소 4개인 체.
  3. \(R/M\) 체 \(\iff\) \(M\) 극대, \(R/P\) 정역 \(\iff\) \(P\) 소.

6.2.4연습문제

기본

  1. \(\mathbb Z_{12}\)의 아이디얼을 모두 쓰라.
    답

    \((d)\), \(d \mid 12\): \((0), (6), (4), (3), (2), (1)\). 여섯 개(덧셈 부분군과 같음).

응용

  1. \(\mathbb Z\times\mathbb Z\)에서 \(\mathbb Z\times\{0\}\)은 소 아이디얼이지만 극대가 아님을 보여라.
    답

    잉여환이 \(\mathbb Z\)(두 번째 성분)와 동형이라 정역이지만 체가 아니다.

심화

  1. \(\mathbb R[x]/(x^2)\)는 체도 정역도 아님을 보이고, 이 환에서 \((a + bx)(c + dx)\)를 계산하여라.
    답

    \(x\cdot x = 0\)이라 영인자. \((a+bx)(c+dx) = ac + (ad + bc)x\) — "이원수", 자동미분에서 \(f(a + bx) = f(a) + f'(a)bx\)로 도함수를 계산하는 원리.

6.2.2

예제원소 9개인 체 만들기

예제 · 잉여환 Z₃[x]/(x² + 1)

다루는 성취기준 [수학12-06-02]

먼저 예측

\(\mathbb Z_9\)는 \(3\cdot3 = 0\)이라 체가 아닙니다. 그래도 원소가 9개인 체가 있을까요?

예측 확인

있습니다. \(\mathbb Z_3\)에 "\(x^2 = -1\)인 수"를 붙인 \(\mathbb Z_3[x]/(x^2 + 1)\)입니다. 실수에 \(i\)를 붙여 \(\mathbb C\)를 만든 것과 같은 방법입니다.

\(F = \mathbb Z_3[x]/(x^2 + 1)\)의 원소를 모두 쓰고, \(1 + x\)의 역원을 구하며, \(F\)가 체임을 보여라.

전략

\(x^2 + 1\)로 나눈 나머지 \(a + bx\)가 대표원입니다(6.2절). 곱한 뒤 \(x^2\)을 \(-1 = 2\)로 바꿉니다. 체임을 보이려면 0 아닌 원소마다 역원을 찾거나, \(x^2 + 1\)이 \(\mathbb Z_3\)에서 인수분해되지 않음을 씁니다.

풀이

  1. 원소는 \(a + bx\) (\(a, b \in \{0, 1, 2\}\)), \(3\times3 = 9\)개.
    2차식으로 나눈 나머지는 1차 이하, 계수가 \(\mathbb Z_3\).
  2. \((1 + x)(a + bx) = a + (a + b)x + bx^2 = (a - b) + (a + b)x\).
    \(x^2 \equiv -1\).
  3. 이것이 1이려면 \(a - b = 1\), \(a + b = 0\). 더하면 \(2a = 1\), \(a = 2\) (\(2\cdot2 = 4 \equiv 1\)), \(b = 1\). 역원은 \(2 + x\).
    검산: \((1 + x)(2 + x) = 2 + 3x + x^2 = 2 + 0 - 1 = 1\).
  4. \(x^2 + 1\)은 \(\mathbb Z_3\)에서 근이 없다: \(0^2 + 1 = 1\), \(1^2 + 1 = 2\), \(2^2 + 1 = 5 \equiv 2\).
    2차식이 인수분해되면 1차 인수, 곧 근이 있어야 한다.
  5. 따라서 \((x^2 + 1)\)은 극대 아이디얼이고 \(F\)는 체다.
    \(f\)가 \(x^2+1\)의 배수가 아니면 \(\gcd(f, x^2+1) = 1\)이라 \(fg + (x^2+1)h = 1\), 곧 \(f\)가 가역. 정리 6.2.5.

검산

0 아닌 원소 8개의 곱셈군에서 \(1 + x\)의 거듭제곱은 \((1+x)^2 = 1 + 2x + x^2 = 2x\), \((1+x)^4 = (2x)^2 = 4x^2 = -1\), \((1+x)^8 = 1\)이라 위수 8입니다. 곱셈군이 \(1 + x\)로 생성되는 순환군 \(\mathbb Z_8\)입니다. 반면 \(x^2 - 1 = (x - 1)(x + 1)\)로 같은 구성을 하면 \((x - 1)(x + 1) = 0\)이라 영인자가 생겨 체가 아닙니다.

의미

소수 \(p\)와 \(\mathbb Z_p\)에서 기약인 \(n\)차 다항식이 있으면 원소 \(p^n\)개인 체가 생깁니다. 이런 유한체는 QR 코드와 CD의 리드-솔로몬 오류 정정 부호, AES 암호(원소 256개인 체)에 쓰입니다. 현대대수(2)에서 원소 \(p^n\)개인 체가 늘 하나뿐임을 증명합니다.

이해 확인

\(\mathbb Z_2[x]/(x^2 + 1)\)은 체인가?

답

아니다. \(\mathbb Z_2\)에서 \(x^2 + 1 = (x + 1)^2\)이라 \((1 + x)^2 = 0\)인 영인자가 있다. 원소 4개인 체는 \(\mathbb Z_2[x]/(x^2 + x + 1)\)이다.
