5.1.1군이 집합을 움직인다

지금까지 \(D_n\)은 "정\(n\)각형의 대칭"이었고 \(GL_n\)은 "벡터를 옮기는 행렬"이었습니다. 군은 대개 무언가를 움직이는 모습으로 나타납니다. 이것을 추상화한 것이 작용입니다. 작용을 쓰면 군에 대한 사실을 "점을 세는 문제"로 바꿀 수 있습니다.

정의 5.1.1 (작용, 궤도, 안정자)

작용: 함수 \(G\times X \to X\), \((g, x) \mapsto g\cdot x\)로 \(e\cdot x = x\), \(g\cdot(h\cdot x) = (gh)\cdot x\)인 것.

궤도: \(G\cdot x = \{g\cdot x : g \in G\}\). \(x\)가 갈 수 있는 곳 전체.

안정자: \(G_x = \{g : g\cdot x = x\}\). \(x\)를 제자리에 두는 원소 전체. \(G\)의 부분군이다.

고정점: \(G\cdot x = \{x\}\)인 \(x\).

궤도들은 \(X\)를 분할합니다(\(x \sim y \iff y = g\cdot x\)는 동치관계). 안정자가 부분군인 것은 \(g\cdot x = x\), \(h\cdot x = x\)이면 \(h^{-1}\cdot x = x\)이고 \((gh^{-1})\cdot x = x\)이기 때문입니다.

예제 5.1.2

다음 작용의 궤도와 안정자를 말하여라. (a) \(D_n\)이 정\(n\)각형의 꼭짓점에. (b) \(SO(2)\)(회전)가 \(\mathbb R^2\)에. (c) \(G\)가 자기 자신에 켤레로 \(g\cdot x = gxg^{-1}\). (d) \(G\)가 \(H \le G\)의 왼쪽 잉여류에 \(g\cdot aH = gaH\).

풀이. (a) 궤도는 꼭짓점 전체 하나, 꼭짓점 1의 안정자는 \(\{e, s\}\) (1을 지나는 축의 반사). (b) 궤도는 원점 중심 원들, 원점의 안정자는 전체, 다른 점의 안정자는 \(\{e\}\). (c) 궤도는 켤레류, \(x\)의 안정자는 중심화군 \(C(x) = \{g : gx = xg\}\). (d) 궤도는 잉여류 전체 하나, \(H\)의 안정자는 \(H\).

5.1.2궤도-안정자 정리

정리 5.1.3 (궤도-안정자)

\(gG_x \mapsto g\cdot x\)는 \(G_x\)의 왼쪽 잉여류 전체에서 궤도 \(G\cdot x\)로 가는 잘 정의된 전단사이다. 따라서 \(|G\cdot x| = [G : G_x]\)이고, \(G\)가 유한이면 \(|G| = |G\cdot x|\cdot|G_x|\).

생각. \(g\)와 \(g'\)이 \(x\)를 같은 곳으로 보낸다는 것은 \(g^{-1}g'\)이 \(x\)를 고정한다는 것, 곧 \(g, g'\)이 \(G_x\)의 같은 잉여류에 있다는 것입니다.

증명.\(g\cdot x = g'\cdot x \iff (g^{-1}g')\cdot x = x \iff g^{-1}g' \in G_x \iff gG_x = g'G_x\). \(\Leftarrow\) 방향이 잘 정의됨, \(\Rightarrow\) 방향이 단사다. 전사는 궤도의 정의에서. 마지막 식은 라그랑주 정리. ∎

예제 5.1.4

정육면체의 회전 대칭은 몇 개인가?

풀이. 회전군 \(G\)가 면 6개에 작용합니다. 어느 면이든 회전으로 다른 면에 보낼 수 있어 궤도는 6개 면 전체입니다. 윗면을 제자리에 두는 회전은 윗면 중심을 지나는 축에 대한 0°, 90°, 180°, 270° 회전 4개입니다. 따라서 \(|G| = 6\times4 = 24\)입니다. 꼭짓점으로 세어도 \(8\times3 = 24\), 모서리로 세어도 \(12\times2 = 24\)로 같습니다.

5.1.3작용은 준동형사상이다

\(g\)를 고정하면 \(x \mapsto g\cdot x\)는 \(X\)의 전단사(역함수는 \(g^{-1}\)의 작용)이므로, 작용은 준동형사상 \(\rho: G \to S_X\)와 같은 것입니다. 이 준동형사상의 핵은 모든 점을 고정하는 원소 전체입니다.

정리 5.1.5 (케일리)

모든 군은 어떤 대칭군의 부분군과 동형이다. \(|G| = n\)이면 \(G\)는 \(S_n\)의 부분군과 동형이다.

증명.\(G\)가 자기 자신에 왼쪽 곱 \(g\cdot x = gx\)로 작용한다. 핵은 \(gx = x\) (모든 \(x\)), 곧 \(g = e\)뿐이라 \(\rho\)는 단사이고 \(G \cong \rho(G) \le S_G\). ∎

잉여류 작용(예제 5.1.2(d))에 이 생각을 쓰면 유용한 결과가 나옵니다: \([G : H] = m\)이면 준동형사상 \(G \to S_m\)이 있고 그 핵은 \(H\)에 포함되는 정규부분군입니다. 예를 들어 \(|G| = 2k\) (\(k\) 홀수)인 군에는 지수 2인 부분군이 있다는 것을 이렇게 보입니다(연습 4).

흔한 실수(1) 궤도의 크기가 \(|G|\)를 넘을 수 있다고 생각한다: 궤도-안정자 정리로 궤도 크기는 \(|G|\)의 약수다. (2) 같은 궤도의 점들은 안정자가 같다고 생각한다: 같은 궤도의 점은 안정자가 켤레이다(\(G_{g\cdot x} = gG_xg^{-1}\)). 크기는 같지만 부분군은 다를 수 있다. 정사각형에서 꼭짓점 1과 2의 안정자는 서로 다른 반사를 담는다.
요약
  1. 작용 = 준동형사상 \(G \to S_X\). 궤도는 \(X\)를 분할하고, 안정자는 부분군이다.
  2. \(|G\cdot x| = [G : G_x]\), \(|G| = |G\cdot x||G_x|\). 대칭의 개수를 셀 때 쓴다.
  3. 케일리: 모든 군은 치환군의 부분군.

5.1.4연습문제

기본

  1. 정사면체의 회전 대칭의 개수를 궤도-안정자 정리로 구하여라.
    답

    꼭짓점 4개가 한 궤도, 꼭짓점의 안정자는 그 꼭짓점을 지나는 축의 회전 3개. \(4\times3 = 12\).

  2. \(S_4\)가 \(\{1, 2, 3, 4\}\)에 작용할 때 1의 안정자의 원소 수는?
    답

    \(\frac{24}{4} = 6\) (\(\{2,3,4\}\)의 치환, \(S_3\)와 동형).

응용

  1. \(G_{g\cdot x} = gG_xg^{-1}\)임을 보여라.
    답

    \(h\cdot(g\cdot x) = g\cdot x \iff (g^{-1}hg)\cdot x = x \iff g^{-1}hg \in G_x \iff h \in gG_xg^{-1}\).

심화

  1. \(|G| = 2k\), \(k\) 홀수이면 \(G\)에 지수 2인 부분군이 있음을 보여라.
    답

    코시 정리(5.2절)로 위수 2인 \(t\)가 있다. 케일리 표현에서 \(t\)는 고정점 없이 \(k\)개의 호환의 곱(\(x \mapsto tx\)가 짝지음)이라 홀치환. \(G \to S_{2k} \xrightarrow{\operatorname{sgn}} \{\pm1\}\)이 전사라 핵이 지수 2.

5.1.2

탐구대칭이 많은 목걸이는 친척이 적다

탐구 · 궤도-안정자 정리

다루는 성취기준 [수학12-05-01]

질문

목걸이 하나를 돌리고 뒤집어 만들 수 있는 서로 다른 목걸이(궤도)는 몇 개일까요? 목걸이를 그대로 두는 대칭(안정자)이 많으면 궤도는 어떻게 될까요?

복원

군 \(G\)가 집합에 작용하면 \(|G\cdot x| = [G : G_x]\), 곧 \(|G\cdot x|\cdot|G_x| = |G|\)이다 (5.1절). 회전만 쓰면 \(G = C_n\) (원소 \(n\)개), 뒤집기도 쓰면 \(G = D_n\) (원소 \(2n\)개).

해 보기

  1. 처음 목걸이(파랑 둘, 빨강 하나를 두 번 반복)는 3칸 돌려도 같아 안정자가 \(\{e, 3칸 회전\}\)이고 궤도가 3개입니다. \(3\times2 = 6\).
  2. D_n으로 바꾸면 반사 2개가 안정자에 더해져 4개가 되고, 궤도는 여전히 3개입니다. \(3\times4 = 12\).
  3. 구슬을 눌러 0번부터 파랑, 파랑, 빨강, 파랑, 빨강, 빨강으로 바꿔 보세요. 대칭이 없는 목걸이입니다. D_6에서 안정자가 \(\{e\}\)뿐이고 궤도가 12개로 최대입니다.
  4. 모두 같은 색이면 안정자가 \(G\) 전체, 궤도는 하나입니다. 파랑·빨강을 번갈아 놓으면 C_6에서 안정자 3개(0, 2, 4칸 회전), 궤도 2개입니다.

설명

  1. 왜 곱이 일정한가\(g\)와 \(g'\)이 목걸이를 같은 모양으로 보내는 것은 \(g^{-1}g'\)이 목걸이를 그대로 두는 것과 같습니다. 그래서 궤도의 각 원소에 대응하는 대칭이 정확히 \(|G_x|\)개씩 있습니다.
  2. 번사이드로 이어짐궤도의 크기가 \(\frac{|G|}{|G_x|}\)이므로 "궤도 수"를 세려면 안정자 크기의 합을 보면 됩니다. 이것이 다음 번사이드 보조정리의 출발점입니다(5.4절).

판단

"구슬 \(n\)개 목걸이는 돌리면 늘 \(n\)가지 모양이 나온다"는 틀립니다. 대칭이 있는 목걸이는 돌려도 같은 모양이 되풀이되어 궤도가 \(n\)의 진약수 크기입니다. 궤도 크기는 늘 \(|G|\)의 약수입니다.
