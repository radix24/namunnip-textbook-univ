5.4.1같은 것으로 보는 것들의 개수

구슬 4개로 원형 팔찌를 만들 때 빨강·파랑 두 색을 쓰면 몇 가지일까요? 자리마다 2가지라 \(2^4 = 16\)가지를 칠할 수 있지만, 돌리면 같아지는 것은 하나로 칩니다. 고등학교의 원순열은 "모두 다른 것"을 늘어놓을 때 \(\frac{n!}{n}\)으로 나누면 되었지만, 같은 색이 반복되면 단순히 4로 나눌 수 없습니다(\(\frac{16}4 = 4\)인데 실제 답은 6). 돌려도 안 바뀌는 색칠(예: 모두 빨강)이 있기 때문입니다.

군의 언어로 쓰면: 회전군 \(G = \mathbb Z_4\)가 색칠 16개의 집합 \(X\)에 작용하고, 우리가 세려는 것은 궤도의 개수입니다.

정리 5.4.1 (번사이드 보조정리)

유한군 \(G\)가 유한집합 \(X\)에 작용하면, \(\operatorname{Fix}(g) = \{x : g\cdot x = x\}\)라 할 때

\[\text{궤도의 수} = \frac{1}{|G|}\sum_{g \in G}|\operatorname{Fix}(g)|.\]

증명.쌍 \((g, x)\)로 \(g\cdot x = x\)인 것의 개수를 두 가지로 센다. \(g\)별로 세면 \(\sum_g|\operatorname{Fix}(g)|\), \(x\)별로 세면 \(\sum_x|G_x|\). 궤도-안정자 정리로 \(|G_x| = \frac{|G|}{|G\cdot x|}\)이므로

\[\sum_x|G_x| = |G|\sum_x\frac{1}{|G\cdot x|} = |G|\cdot(\text{궤도의 수}).\]

각 궤도 \(O\)에서 \(\sum_{x \in O}\frac{1}{|O|} = 1\)이기 때문이다. ∎

5.4.2고정되는 색칠 세기

\(g\)가 자리를 순환 분해했을 때 \(c(g)\)개의 순환으로 나뉜다면, \(g\)로 바뀌지 않는 색칠은 "각 순환 안의 자리들이 같은 색"인 색칠입니다. 따라서 색이 \(k\)가지이면 \(|\operatorname{Fix}(g)| = k^{c(g)}\)입니다.

예제 5.4.2

구슬 4개짜리 원형 팔찌를 2색으로 칠하는 방법을 (a) 회전만 같게 볼 때 (b) 회전과 뒤집기를 모두 같게 볼 때 세어라.

풀이. (a) 회전 \(e, r, r^2, r^3\)의 순환 수는 4, 1, 2, 1(\(r^2 = (1\,3)(2\,4)\))입니다. \(\frac{2^4 + 2 + 2^2 + 2}{4} = \frac{24}{4} = 6\). 실제로 빨강 개수가 0, 1, 3, 4이면 하나씩, 2이면 이웃한 두 개와 마주 보는 두 개의 2가지로 \(1 + 1 + 2 + 1 + 1 = 6\)입니다.

(b) \(D_4\)는 회전 4개에 반사 4개가 더해집니다. 꼭짓점을 지나는 축의 반사 2개는 \((2\,4)\)처럼 순환 3개, 변의 중점을 지나는 반사 2개는 \((1\,2)(3\,4)\)처럼 순환 2개입니다. \(\frac{24 + 2\cdot2^3 + 2\cdot2^2}{8} = \frac{48}{8} = 6\). 4구슬 2색에서는 뒤집어서 새로 같아지는 것이 없어 답이 같습니다. 구슬 6개 3색이면 회전만 볼 때 130, 뒤집기까지 보면 92로 달라집니다(같은 절의 탐구 카드).

예제 5.4.3

정육면체의 면 6개를 \(k\)색으로 칠하는 방법(회전으로 같은 것은 하나로)의 수를 구하여라.

풀이. 회전 24개를 종류별로 나누고 면의 순환 수를 셉니다.

  • 항등 1개: 순환 6개 → \(k^6\)
  • 마주 보는 면 축 90°, 270° 6개: 축의 두 면 고정 + 옆면 4개 한 순환 → \(k^3\)
  • 마주 보는 면 축 180° 3개: 두 면 고정 + 옆면 2쌍 → \(k^4\)
  • 꼭짓점 축 120°, 240° 8개: 면 3개씩 두 순환 → \(k^2\)
  • 모서리 축 180° 6개: 면 2개씩 세 순환 → \(k^3\)

합하면 \(\frac{k^6 + 3k^4 + 12k^3 + 8k^2}{24}\)입니다. \(k = 2\)이면 \(\frac{64 + 48 + 96 + 32}{24} = 10\), \(k = 3\)이면 \(\frac{729 + 243 + 324 + 72}{24} = 57\). 개수 \(1 + 6 + 3 + 8 + 6 = 24\)로 회전의 개수(5.1절)와도 맞습니다.

흔한 실수(1) 전체 수를 \(|G|\)로 나눈다: 고정점이 있는 색칠 때문에 틀린다(4구슬 2색에서 \(16/4 = 4 \ne 6\)). 나눗셈이 정수가 아니면 틀렸다는 신호지만, 정수라고 맞는 것은 아니다. (2) 각 회전의 고정 색칠을 \(k^{(\text{고정된 자리 수})}\)로 센다: 순환 안의 자리들이 같은 색이면 되므로 지수는 고정점 수가 아니라 순환의 수다.
요약
  1. 궤도의 수 = \(\frac1{|G|}\sum_g|\operatorname{Fix}(g)|\) (쌍을 두 번 세기 + 궤도-안정자).
  2. 색칠에서 \(|\operatorname{Fix}(g)| = k^{c(g)}\), \(c(g)\)는 \(g\)의 순환 수.
  3. 정육면체 면 칠하기: \(\frac{k^6 + 3k^4 + 12k^3 + 8k^2}{24}\).

5.4.3연습문제

기본

  1. 구슬 5개 원형 목걸이(회전만)를 2색으로 칠하는 방법의 수는?
    답

    회전 \(r^j\) (\(j \ne 0\))는 길이 5 순환 하나. \(\frac{2^5 + 4\cdot2}{5} = 8\).

응용

  1. 정사각형의 꼭짓점 4개를 3색으로 칠하는 방법(\(D_4\)의 대칭으로 같은 것은 하나로)의 수는?
    답

    \(\frac{3^4 + 2\cdot3 + 3^2 + 2\cdot3^3 + 2\cdot3^2}{8} = \frac{81 + 6 + 9 + 54 + 18}{8} = 21\).

심화

  1. 회전만 볼 때 구슬 \(n\)개 \(k\)색 목걸이의 수가 \(\frac1n\sum_{d \mid n}\varphi(d)k^{n/d}\)임을 보여라.
    답

    \(r^j\)는 \(\gcd(n, j)\)개의 순환으로 나뉜다. \(\gcd(n, j) = \frac nd\)인 \(j\)는 \(\varphi(d)\)개.

5.4.2

탐구목걸이는 몇 가지인가

탐구 · 번사이드 보조정리

다루는 성취기준 [수학12-05-04]

질문

구슬 \(n\)개 목걸이를 \(k\)색으로 칠할 때, 돌리거나 뒤집어 같아지는 것을 하나로 보면 몇 가지일까요? 전체 \(k^n\)을 대칭의 수로 나누면 될까요?

복원

궤도의 수 \(= \frac{1}{|G|}\sum_g|\operatorname{Fix}(g)|\)이고, 색칠에서 \(|\operatorname{Fix}(g)| = k^{c(g)}\) (\(c(g)\)는 \(g\)가 자리를 나누는 순환의 수)이다 (5.4절).

해 보기

  1. 처음 화면(6구슬 3색, 회전만)에서 \(\sum = 780\), 답은 \(780/6 = 130\)입니다. 전체 \(3^6 = 729\)를 6으로 나누면 121.5로 정수조차 아닙니다.
  2. D_n으로 바꾸면 반사 6개가 더해져 \(\sum = 1104\), 답은 \(1104/12 = 92\)입니다. 뒤집어서 같아지는 쌍이 합쳐져 줄었습니다.
  3. \(n = 4\), \(k = 2\)이면 회전만이든 뒤집기까지든 6입니다(본문 예제 5.4.2).
  4. 항등원 막대가 압도적으로 높습니다. \(n\)이 크면 답이 대략 \(\frac{k^n}{|G|}\)에 가까워지고, 나머지 막대들이 그 차이를 바로잡습니다.

설명

  1. 회전의 순환 수\(j\)칸 회전은 자리를 \(\gcd(n, j)\)개의 순환으로 나눕니다. 6구슬에서 \(c = 6, 1, 2, 3, 2, 1\)이라 \(3^6 + 3 + 9 + 27 + 9 + 3 = 780\).
  2. 반사의 순환 수반사는 축 위의 구슬(0, 1, 2개)을 고정하고 나머지를 짝짓습니다. \(n = 6\)이면 꼭짓점 축 3개(순환 4개), 변 축 3개(순환 3개)라 \(3(3^4 + 3^3) = 324\)가 더해집니다.

판단

"\(k^n\)을 \(|G|\)로 나누고 반올림하면 된다"는 틀립니다. 6구슬 3색 회전에서 \(121.5\)를 반올림해도 122이지 130이 아닙니다. 대칭이 있는 색칠(고정점)이 궤도를 작게 만들기 때문에, 고정점 수를 원소마다 세어 더해야 합니다.
