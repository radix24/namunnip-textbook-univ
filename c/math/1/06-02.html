6.2.1

증명고유값이 다르면 고유벡터는 일차독립이다

증명 · 귀납법과 "곱하고 빼기"

다루는 성취기준 [수학1-06-02]

정리

일차변환 \(T: V \to V\)의 서로 다른 고유값 \(\lambda_1, \dots, \lambda_k\)에 대한 고유벡터를 \(v_1, \dots, v_k\)라 하자. 그러면 \(\{v_1, \dots, v_k\}\)는 일차독립이다.

쓰는 것

  • 고유벡터의 정의: \(v_i \ne \mathbf 0\)이고 \(T v_i = \lambda_i v_i\).
  • 일차독립의 정의: \(c_1 v_1 + \dots + c_k v_k = \mathbf 0\)이면 \(c_1 = \dots = c_k = 0\).
  • 일차변환의 선형성: \(T(\sum c_i v_i) = \sum c_i T v_i\).
  • 수학적 귀납법(수학2 1.3절).

아이디어

일차관계 \(c_1 v_1 + \dots + c_k v_k = \mathbf 0\)이 있다고 하고, 벡터 하나를 지운 더 짧은 일차관계를 만들어 귀납 가정에 넘깁니다. 지우는 방법은 이렇습니다: 식에 \(T\)를 적용한 것과 식에 \(\lambda_k\)를 곱한 것을 빼면 \(v_k\)의 항만 사라집니다. 남은 항의 계수는 \(c_i(\lambda_i - \lambda_k)\)인데, 고유값이 서로 달라 \(\lambda_i - \lambda_k \ne 0\)이므로 \(c_i = 0\)이 나옵니다.

증명

  1. \(k\)에 대한 귀납법으로 보인다. \(k = 1\)일 때: \(c_1 v_1 = \mathbf 0\)이면 \(v_1 \ne \mathbf 0\)이므로 \(c_1 = 0\)이다.
    고유벡터는 영벡터가 아니다(정의). 영벡터가 아닌 벡터에 스칼라를 곱해 영벡터가 되려면 스칼라가 0이어야 한다(벡터공간 공리에서 나오는 성질).
  2. \(k - 1\)개일 때 정리가 성립한다고 가정하고, \(c_1 v_1 + \dots + c_k v_k = \mathbf 0\) ··· (가)라 하자.
    귀납 가정. 목표는 모든 \(c_i = 0\)을 보이는 것(일차독립의 정의).
  3. (가)의 양변에 \(T\)를 적용하면 \(c_1\lambda_1 v_1 + \dots + c_k\lambda_k v_k = \mathbf 0\) ··· (나).
    \(T\)의 선형성으로 합과 스칼라배를 밖으로 빼고, \(Tv_i = \lambda_i v_i\)를 대입. 우변은 \(T(\mathbf 0) = \mathbf 0\).
  4. (가)에 \(\lambda_k\)를 곱하면 \(c_1\lambda_k v_1 + \dots + c_k\lambda_k v_k = \mathbf 0\) ··· (다).
    영벡터의 스칼라배는 영벡터.
  5. (나)에서 (다)를 빼면 \(c_1(\lambda_1 - \lambda_k)v_1 + \dots + c_{k-1}(\lambda_{k-1} - \lambda_k)v_{k-1} = \mathbf 0\).
    \(v_k\)의 계수는 \(c_k\lambda_k - c_k\lambda_k = 0\)이라 사라진다. 이것이 이 증명의 핵심 한 수다.
  6. 이는 \(v_1, \dots, v_{k-1}\)의 일차관계이므로 귀납 가정에 따라 \(c_i(\lambda_i - \lambda_k) = 0\) (\(i = 1, \dots, k-1\)).
    \(v_1, \dots, v_{k-1}\)도 서로 다른 고유값의 고유벡터이므로 귀납 가정이 적용된다.
  7. \(i < k\)이면 \(\lambda_i \ne \lambda_k\)이므로 \(c_i = 0\) (\(i = 1, \dots, k-1\)).
    가정 "고유값이 서로 다르다"를 여기서 쓴다. 두 수의 곱이 0이고 한쪽이 0이 아니면 다른 쪽이 0.
  8. 이를 (가)에 넣으면 \(c_k v_k = \mathbf 0\)이고, 1단계와 같은 이유로 \(c_k = 0\). 따라서 모든 계수가 0이고 \(\{v_1, \dots, v_k\}\)는 일차독립이다.
    \(v_k \ne \mathbf 0\). 귀납법으로 모든 \(k\)에 대해 성립.

되짚기

  • "고유값이 서로 다르다"는 7단계에서만 썼습니다. 이 가정을 빼면 깨집니다. 항등변환에서 \(v_1 = (1, 0)\)과 \(v_2 = (2, 0)\)은 둘 다 고유값 1의 고유벡터지만 일차종속입니다.
  • "고유벡터는 영벡터가 아니다"는 1단계와 8단계에서 썼습니다. 영벡터를 허용하면 \(\{\mathbf 0, v\}\)는 늘 일차종속입니다.
  • 귀납 가정은 6단계에서 썼습니다. 벡터를 하나 줄인 일차관계를 만든 것이 귀납법을 쓸 수 있게 한 까닭입니다.

더 나아가기

따름정리: \(n\)차원 공간의 일차변환이 서로 다른 고유값을 \(n\)개 가지면 대각화할 수 있습니다. 고유벡터 \(n\)개가 일차독립이니 기저가 되기 때문입니다. 더 일반적으로, 서로 다른 고유값의 고유공간들의 합은 직합입니다.

직접 써 보기

\(A\)가 \(n\times n\) 행렬이고 \(A^2 = A\)라고 하자. 고유값은 0과 1뿐임을 보이고, 고유값 0의 고유벡터와 고유값 1의 고유벡터가 일차독립임을 위 정리를 쓰지 않고 직접 보이세요.

힌트

\(Av = \lambda v\)이면 \(A^2 v = \lambda^2 v\)입니다. 일차독립은 \(au + bw = \mathbf 0\)에 \(A\)를 곱해 보세요.

답안

\(Av = \lambda v\), \(v \ne \mathbf 0\)이면 \(\lambda v = Av = A^2 v = \lambda^2 v\)이므로 \((\lambda^2 - \lambda)v = \mathbf 0\)이고, \(v \ne \mathbf 0\)이라 \(\lambda^2 = \lambda\), 곧 \(\lambda \in \{0, 1\}\)이다. 이제 \(Au = \mathbf 0\), \(Aw = w\) (\(u, w \ne \mathbf 0\))이고 \(au + bw = \mathbf 0\)이라 하자. 양변에 \(A\)를 곱하면 \(bw = \mathbf 0\)이므로 \(b = 0\)이고, 그러면 \(au = \mathbf 0\)에서 \(a = 0\)이다. ∎
