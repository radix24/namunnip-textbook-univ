7.1.1길이와 각을 다시 들여오기

2단원의 벡터공간에는 길이도 각도도 없었습니다. 덧셈과 실수배만으로는 "수직"이나 "가장 가까운 점"을 말할 수 없습니다. 그런데 최소제곱 문제(7.3절)나 푸리에 급수(수학15)처럼 "가장 가까운 근사"를 찾는 문제에는 길이가 필요합니다. 공간에서 내적 \(\mathbf u\cdot\mathbf v = u_1v_1 + u_2v_2 + u_3v_3\)이 길이와 각을 모두 주었던 것을 본떠, 내적의 성질만 뽑아 공리로 삼습니다.

정의 7.1.1 (내적)

실벡터공간 \(V\)의 두 벡터에 실수 \(\langle\mathbf u, \mathbf v\rangle\)를 대응시키는 함수가 다음을 만족하면 내적이라 하고, 내적이 주어진 공간을 내적공간이라 한다.

  1. \(\langle\mathbf u, \mathbf v\rangle = \langle\mathbf v, \mathbf u\rangle\) (대칭)
  2. \(\langle a\mathbf u + b\mathbf w, \mathbf v\rangle = a\langle\mathbf u, \mathbf v\rangle + b\langle\mathbf w, \mathbf v\rangle\) (첫 자리에 대해 선형)
  3. \(\langle\mathbf v, \mathbf v\rangle > 0\) (\(\mathbf v \ne \mathbf 0\)) (양의 정부호)

노름(길이) \(\|\mathbf v\| = \sqrt{\langle\mathbf v, \mathbf v\rangle}\). 공리 3 덕분에 \(\mathbf v \ne \mathbf 0\)이면 양수입니다.

예 1 \(\mathbb R^n\)의 점곱 \(\langle\mathbf u, \mathbf v\rangle = \sum u_iv_i\).

예 2 \([a, b]\)의 연속함수 공간에서 \(\langle f, g\rangle = \int_a^b f(x)g(x)\,dx\). 공리 3은 "연속함수 \(f \ne 0\)이면 \(\int f^2 > 0\)"에서 나옵니다.

예 3 \(\mathbb R^2\)에서 \(\langle\mathbf u, \mathbf v\rangle = 2u_1v_1 + u_2v_2\). 점곱이 아닌 내적도 있습니다(7.4절의 겹선형형식).

7.1.2코시-슈바르츠 부등식

평면에서는 \(\mathbf u\cdot\mathbf v = \|\mathbf u\|\|\mathbf v\|\cos\theta\)이고 \(|\cos\theta| \le 1\)이라 \(|\mathbf u\cdot\mathbf v| \le \|\mathbf u\|\|\mathbf v\|\)입니다. 그러나 함수 공간에는 그릴 수 있는 각이 없으므로, 이 부등식을 공리만으로 증명해야 거꾸로 각을 정의할 수 있습니다.

정리 7.1.2 (코시-슈바르츠 부등식)

내적공간의 모든 \(\mathbf u, \mathbf v\)에 대해 \(|\langle\mathbf u, \mathbf v\rangle| \le \|\mathbf u\|\,\|\mathbf v\|\). 등호는 \(\mathbf u, \mathbf v\)가 일차종속일 때만 성립한다.

아이디어: \(t\)에 대한 함수 \(\|\mathbf u - t\mathbf v\|^2\)는 늘 0 이상인 이차식입니다. 이차식이 늘 0 이상이면 판별식이 0 이하이고, 그 판별식 조건이 바로 부등식입니다.

증명.\(\mathbf v = \mathbf 0\)이면 양변이 0이다. \(\mathbf v \ne \mathbf 0\)이라 하자. 모든 실수 \(t\)에 대해 공리로 전개하면

\[0 \le \|\mathbf u - t\mathbf v\|^2 = \|\mathbf u\|^2 - 2t\langle\mathbf u, \mathbf v\rangle + t^2\|\mathbf v\|^2.\]

\(t\)에 대한 이 이차식이 늘 0 이상이므로 판별식이 0 이하이다: \(4\langle\mathbf u, \mathbf v\rangle^2 - 4\|\mathbf u\|^2\|\mathbf v\|^2 \le 0\). 정리하면 부등식이다. 등호이면 판별식이 0이라 어떤 \(t\)에서 \(\|\mathbf u - t\mathbf v\| = 0\), 공리 3으로 \(\mathbf u = t\mathbf v\). ∎

증명에서 쓴 것은 대칭, 선형, 양의 정부호뿐입니다. 그래서 점곱과 적분 내적에서 동시에 다음이 성립합니다.

\[\Big(\sum u_iv_i\Big)^2 \le \Big(\sum u_i^2\Big)\Big(\sum v_i^2\Big),\qquad \Big(\int fg\Big)^2 \le \int f^2\int g^2.\]

7.1.3삼각부등식과 각

정리 7.1.3 (삼각부등식)

\(\|\mathbf u + \mathbf v\| \le \|\mathbf u\| + \|\mathbf v\|\).

증명.\(\|\mathbf u + \mathbf v\|^2 = \|\mathbf u\|^2 + 2\langle\mathbf u, \mathbf v\rangle + \|\mathbf v\|^2 \le \|\mathbf u\|^2 + 2\|\mathbf u\|\|\mathbf v\| + \|\mathbf v\|^2 = (\|\mathbf u\| + \|\mathbf v\|)^2\). 가운데 부등호가 코시-슈바르츠. 양변이 0 이상이므로 제곱근을 취한다. ∎

코시-슈바르츠로 \(-1 \le \frac{\langle\mathbf u, \mathbf v\rangle}{\|\mathbf u\|\|\mathbf v\|} \le 1\)이므로, 이 값을 \(\cos\theta\)로 하는 \(\theta \in [0, \pi]\)를 두 벡터의 각으로 정의할 수 있습니다. 특히 \(\langle\mathbf u, \mathbf v\rangle = 0\)이면 직교한다고 하고, 직교하면 피타고라스 정리 \(\|\mathbf u + \mathbf v\|^2 = \|\mathbf u\|^2 + \|\mathbf v\|^2\)가 성립합니다.

예제 7.1.4

\([-1, 1]\)에서 적분 내적으로 \(f(x) = 1\)과 \(g(x) = x\)는 직교함을 보이고, \(f\)와 \(h(x) = x^2\)의 각의 코사인을 구하여라.

풀이. \(\langle 1, x\rangle = \int_{-1}^1x\,dx = 0\)이라 직교합니다. \(\langle 1, x^2\rangle = \frac23\), \(\|1\|^2 = 2\), \(\|x^2\|^2 = \int x^4 = \frac25\)이므로 \(\cos\theta = \frac{2/3}{\sqrt2\sqrt{2/5}} = \frac{2/3}{2/\sqrt5} = \frac{\sqrt5}{3} \approx 0.745\), \(\theta \approx 41.8°\). 함수 사이에도 각이 있습니다.

주의"노름이 있으면 내적이 있다"는 틀립니다. \(\mathbb R^2\)의 최댓값 노름 \(\max(|x|, |y|)\)은 삼각부등식을 만족하는 노름이지만 어떤 내적에서도 나오지 않습니다. 내적에서 나온 노름은 평행사변형 법칙 \(\|\mathbf u + \mathbf v\|^2 + \|\mathbf u - \mathbf v\|^2 = 2\|\mathbf u\|^2 + 2\|\mathbf v\|^2\)을 만족해야 하는데, \(\mathbf u = (1, 0), \mathbf v = (0, 1)\)에서 \(1 + 1 \ne 2 + 2\)입니다(수학7의 p-거리 탐구 카드 참고).
요약
  1. 내적: 대칭, 선형, 양의 정부호. 노름 \(\|\mathbf v\| = \sqrt{\langle\mathbf v, \mathbf v\rangle}\).
  2. 코시-슈바르츠: \(|\langle\mathbf u, \mathbf v\rangle| \le \|\mathbf u\|\|\mathbf v\|\). 증명은 \(\|\mathbf u - t\mathbf v\|^2 \ge 0\)의 판별식.
  3. 삼각부등식은 코시-슈바르츠에서 나온다.
  4. 각을 \(\cos\theta = \langle\mathbf u, \mathbf v\rangle/(\|\mathbf u\|\|\mathbf v\|)\)로, 직교를 \(\langle\mathbf u, \mathbf v\rangle = 0\)으로 정의한다.

7.1.4연습문제

기본

  1. \((1, 2, 2)\)와 \((2, -1, 2)\)의 각을 구하여라.
    답

    내적 \(2 - 2 + 4 = 4\), 노름 3, 3. \(\cos\theta = \frac49\), \(\theta \approx 63.6°\).

응용

  1. 양수 \(a_1, \dots, a_n\)에 대해 \((a_1 + \dots + a_n)\left(\frac1{a_1} + \dots + \frac1{a_n}\right) \ge n^2\)임을 보여라.
    힌트

    \(u_i = \sqrt{a_i}\), \(v_i = 1/\sqrt{a_i}\)에 코시-슈바르츠.

    답

    \(\left(\sum u_iv_i\right)^2 = n^2 \le \sum a_i\sum\frac1{a_i}\).

  2. \(\int_0^1 f(x)\,dx = 1\)인 연속함수에 대해 \(\int_0^1 f(x)^2dx \ge 1\)임을 보여라. 등호는 언제?
    답

    \(\langle f, 1\rangle^2 \le \|f\|^2\|1\|^2\), 곧 \(1 \le \int f^2\). 등호는 \(f\)가 상수(\(f = 1\))일 때.

심화

  1. \(\langle\mathbf u, \mathbf v\rangle = 2u_1v_1 + u_1v_2 + u_2v_1 + u_2v_2\)가 \(\mathbb R^2\)의 내적임을 보여라.
    답

    대칭과 선형은 바로 확인된다. \(\langle\mathbf u, \mathbf u\rangle = 2u_1^2 + 2u_1u_2 + u_2^2 = u_1^2 + (u_1 + u_2)^2 > 0\) (\(\mathbf u \ne \mathbf 0\)).

7.1.2

탐구포물선 하나로 증명하는 부등식

탐구 · 코시-슈바르츠의 그림

다루는 성취기준 [수학1-07-01]

질문

코시-슈바르츠 부등식의 증명은 \(q(t) = \|\mathbf u - t\mathbf v\|^2\)가 0 이상인 포물선이라는 데서 시작합니다. 이 포물선은 그림에서 무엇이고, 최솟값은 어디서 생길까요?

복원

\(q(t) = \|\mathbf u\|^2 - 2t\langle\mathbf u, \mathbf v\rangle + t^2\|\mathbf v\|^2 \ge 0\)이 모든 \(t\)에서 성립하므로 판별식이 0 이하이다 (7.1절).

왼쪽의 u(검정), v(파랑) 끝점을 끌어 바꿀 수 있습니다.

해 보기

  1. t를 움직이면 빨간 선분(\(\mathbf u - t\mathbf v\))의 길이가 바뀌고, 그 제곱이 오른쪽 포물선 위의 빨간 점입니다.
  2. 빨간 선분이 노란 수선과 겹칠 때(직선에 수직일 때) 포물선이 최솟값에 닿습니다. 그 \(t\)가 \(t^* = \langle\mathbf u, \mathbf v\rangle/\|\mathbf v\|^2\)입니다.
  3. u를 v와 같은 직선 위로 끌어 보세요. 최솟값이 0이 되고 포물선이 \(t\)축에 닿습니다. 코시-슈바르츠의 등호 조건(일차종속)입니다.
  4. 어떻게 끌어도 출력의 "판별식/4"는 0 이하입니다.

설명

  1. 최솟값의 뜻\(q(t^*) = \|\mathbf u\|^2 - \frac{\langle\mathbf u, \mathbf v\rangle^2}{\|\mathbf v\|^2}\)는 \(\mathbf u\)에서 \(\mathbf v\) 방향 직선까지의 거리의 제곱입니다. 거리의 제곱이 0 이상이라는 당연한 사실이 정리하면 코시-슈바르츠입니다.
  2. 정사영\(t^*\mathbf v = \frac{\langle\mathbf u, \mathbf v\rangle}{\|\mathbf v\|^2}\mathbf v\)는 \(\mathbf u\)의 \(\mathbf v\) 방향 정사영이고, 다음 절의 그람-슈미트 과정과 7.3절의 최소제곱이 모두 이 식을 씁니다.

판단

"그림은 평면에서만 그릴 수 있으니 이 증명은 평면에서만 맞다"는 틀립니다. 증명에 쓴 것은 내적의 공리뿐이고 그림은 이해를 돕는 장치입니다. 같은 증명이 함수의 적분 내적에서도 그대로 통합니다.
