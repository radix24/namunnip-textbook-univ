이 절에서 배울 것
  • 벡터공간의 여덟 가지 공리를 읽고, 각 공리가 무엇을 보장하는지 안다.
  • \(\mathbb R^n\), 다항식, 함수, 행렬의 집합이 모두 벡터공간임을 확인한다.
  • 공리 하나가 깨지는 예로 벡터공간이 아님을 판정한다.
먼저 알아야 할 것
  • \(\mathbb R^n\)의 벡터 덧셈과 실수배, 동차 해집합이 이 두 연산에 닫혀 있음 (1.2절).

2.1.1왜 화살표가 아닌 것도 벡터라 부르나

1단원에서 연립방정식의 해를 다룰 때 쓴 것은 "더한다"와 "실수배 한다" 두 연산과 그 성질뿐이었습니다. 화살표의 길이나 방향은 한 번도 쓰지 않았습니다. 그런데 같은 두 연산이 전혀 다른 대상에도 있습니다. 다항식 \(1 + x\)와 \(2x^2\)도 더하고 실수배 할 수 있고, 미분방정식 \(y'' + y = 0\)의 해 \(\sin x\)와 \(\cos x\)도 더하고 실수배 하면 또 해가 됩니다.

그렇다면 1단원의 결과를 이 대상들에 다시 증명할 필요가 없도록, "더하기와 실수배가 있고 이런 성질을 만족하는 집합"을 한꺼번에 다루는 편이 낫습니다. 그 성질의 목록이 벡터공간의 공리입니다.

2.1.2정의

정의 2.1.1 (벡터공간)

집합 \(V\)에 덧셈 \(\mathbf u + \mathbf v \in V\)와 실수배 \(c\mathbf u \in V\)가 정의되어 있고, 모든 \(\mathbf u, \mathbf v, \mathbf w \in V\)와 실수 \(a, b\)에 대해 다음이 성립하면 \(V\)를 (실수 위의) 벡터공간이라 하고, 그 원소를 벡터라 한다.

  1. \(\mathbf u + \mathbf v = \mathbf v + \mathbf u\) (교환법칙)
  2. \((\mathbf u + \mathbf v) + \mathbf w = \mathbf u + (\mathbf v + \mathbf w)\) (결합법칙)
  3. 모든 \(\mathbf u\)에 대해 \(\mathbf u + \mathbf 0 = \mathbf u\)인 \(\mathbf 0 \in V\)가 있다 (영벡터)
  4. 각 \(\mathbf u\)에 대해 \(\mathbf u + \mathbf w = \mathbf 0\)인 \(\mathbf w \in V\)가 있다 (덧셈의 역원)
  5. \(1\mathbf u = \mathbf u\)
  6. \((ab)\mathbf u = a(b\mathbf u)\)
  7. \(a(\mathbf u + \mathbf v) = a\mathbf u + a\mathbf v\)
  8. \((a + b)\mathbf u = a\mathbf u + b\mathbf u\)

공리를 하나씩 풀어 읽어 봅시다. 맨 앞 문장의 "\(\in V\)"가 사실 가장 중요합니다. 더하거나 실수배 한 결과가 다시 \(V\) 안에 있어야 한다는 닫힘 조건입니다. 1~4는 덧셈이 수의 덧셈처럼 행동한다는 것, 5~8은 실수배가 덧셈과 어울린다는 것입니다. 공리 5는 이상해 보이지만 빠지면 "모든 벡터에 실수배를 하면 \(\mathbf 0\)"이라는 엉뚱한 연산도 7, 8을 만족해 버립니다. 공리 5가 그런 연산을 걸러 냅니다.

실수 대신 복소수를 곱할 수 있으면 복소 벡터공간이라고 합니다(선형대수(2) 2단원). Friedberg 교재처럼 일반적인 체 \(F\)를 쓰기도 하지만, 이 과목에서는 실수와 복소수만 다룹니다.

2.1.3예

예제 2.1.2 (네 가지 대표 예)
  • \(\mathbb R^n\): 성분이 \(n\)개인 실수 순서쌍. 성분별 덧셈과 실수배.
  • \(P_n\): 차수가 \(n\) 이하인 실계수 다항식 전체. 계수별 덧셈과 실수배.
  • \(M_{m\times n}\): \(m\times n\) 실수 행렬 전체. 성분별 덧셈과 실수배.
  • \(\mathcal F(S)\): 집합 \(S\)에서 실수로 가는 함수 전체. \((f + g)(x) = f(x) + g(x)\), \((cf)(x) = cf(x)\).

네 경우 모두 공리 1~8은 실수의 성질을 성분마다(계수마다, 점마다) 쓰면 확인됩니다. 예를 들어 \(\mathcal F(S)\)에서 공리 7은 각 점 \(x\)에서 \(a(f(x) + g(x)) = af(x) + ag(x)\)라는 실수의 분배법칙입니다. 영벡터는 늘 0인 함수, \(f\)의 역원은 \(-f\)입니다. 닫힘도 중요합니다. \(P_n\)에서 차수가 \(n\) 이하인 두 다항식의 합은 차수가 \(n\) 이하이므로 닫혀 있습니다.

2.1.4공리가 깨지는 예

벡터공간이 아님을 보이려면 깨지는 공리 하나를 구체적인 벡터로 보이면 됩니다.

예제 2.1.3

다음은 벡터공간이 아니다. 어느 공리가 깨지는지 말하여라.

  1. 차수가 정확히 2인 다항식 전체.
  2. \(\mathbb R^2\)에서 덧셈은 보통대로, 실수배를 \(c(x, y) = (cx, 0)\)으로 정한 것.
  3. \(\{(x, y) : x \ge 0\}\)에 보통의 연산.

풀이. (a) \(x^2 + (-x^2 + x) = x\)는 차수가 1이라 덧셈에 닫혀 있지 않습니다. 영벡터인 0 다항식도 들어 있지 않습니다. (b) \(1\cdot(1, 1) = (1, 0) \ne (1, 1)\)이라 공리 5가 깨집니다. (c) \((1, 0)\)의 역원 \((-1, 0)\)이 집합 밖에 있어 공리 4가 깨집니다. 실수배 \((-1)(1, 0)\)도 밖으로 나가므로 닫힘도 깨집니다.

2.1.5공리에서 나오는 기본 성질

공리에 적혀 있지 않은 당연해 보이는 성질도 공리만으로 증명됩니다. 이것을 확인해 두어야 함수공간이나 행렬공간에서도 마음 놓고 쓸 수 있습니다.

정리 2.1.4

벡터공간 \(V\)에서 (1) 영벡터는 하나뿐이다. (2) 각 \(\mathbf u\)의 역원은 하나뿐이다(이를 \(-\mathbf u\)로 쓴다). (3) \(0\mathbf u = \mathbf 0\). (4) \((-1)\mathbf u = -\mathbf u\).

증명.(1) \(\mathbf 0, \mathbf 0'\)이 모두 영벡터이면 \(\mathbf 0 = \mathbf 0 + \mathbf 0' = \mathbf 0' + \mathbf 0 = \mathbf 0'\) (공리 3을 두 번, 공리 1). (2) \(\mathbf w, \mathbf w'\)이 모두 \(\mathbf u\)의 역원이면 \(\mathbf w = \mathbf w + (\mathbf u + \mathbf w') = (\mathbf w + \mathbf u) + \mathbf w' = \mathbf 0 + \mathbf w' = \mathbf w'\) (공리 3, 2, 1, 4). (3) 공리 8로 \(0\mathbf u = (0 + 0)\mathbf u = 0\mathbf u + 0\mathbf u\). 양변에 \(0\mathbf u\)의 역원을 더하면 \(\mathbf 0 = 0\mathbf u\). (4) 공리 5, 8과 (3)으로 \(\mathbf u + (-1)\mathbf u = (1 + (-1))\mathbf u = 0\mathbf u = \mathbf 0\)이므로 \((-1)\mathbf u\)는 \(\mathbf u\)의 역원이고, (2)에 따라 \(-\mathbf u\)와 같다. ∎

주의"벡터는 크기와 방향을 가진 양"이라는 고교식 정의는 이 과목에서 쓰지 않습니다. 다항식 \(x^2\)이나 함수 \(\sin x\)에는 방향이 없지만 벡터입니다. 길이와 각도는 7단원에서 내적을 따로 정해야 생깁니다.
요약
  1. 벡터공간은 덧셈과 실수배가 닫혀 있고 여덟 공리를 만족하는 집합이다.
  2. \(\mathbb R^n\), \(P_n\), \(M_{m\times n}\), 함수공간이 대표 예다.
  3. 벡터공간이 아님을 보이려면 깨지는 공리 하나를 구체적인 벡터로 보인다. 닫힘과 영벡터를 먼저 확인한다.
  4. 영벡터와 역원은 유일하고, \(0\mathbf u = \mathbf 0\), \((-1)\mathbf u = -\mathbf u\)이다.

2.1.6연습문제

기본

  1. \(\{(x, y) : y = 2x + 1\}\)은 보통 연산으로 벡터공간인가?
    답

    아니다. \((0, 0)\)이 들어 있지 않아 영벡터 공리가 깨진다(덧셈에도 닫혀 있지 않음).

  2. \(2\times2\) 행렬 전체 \(M_{2\times2}\)의 영벡터와 \(\begin{pmatrix} 1 & -2 \\ 0 & 3\end{pmatrix}\)의 역원을 써라.
    답

    영행렬 \(\begin{pmatrix} 0&0\\0&0\end{pmatrix}\), 역원 \(\begin{pmatrix} -1 & 2 \\ 0 & -3\end{pmatrix}\).

응용

  1. 양의 실수 전체 \(\mathbb R^+\)에 "덧셈" \(u \oplus v = uv\), "실수배" \(c \odot u = u^c\)를 주면 벡터공간이 됨을 보이고, 영벡터가 무엇인지 말하여라.
    힌트

    지수법칙으로 공리를 하나씩 확인합니다.

    답

    영벡터는 1(\(u\cdot1 = u\)), \(u\)의 역원은 \(1/u\). 예: 공리 7은 \((uv)^a = u^av^a\), 공리 8은 \(u^{a+b} = u^au^b\). 로그가 이 공간과 \(\mathbb R\)을 짝지어 준다.

심화

  1. 공리 1(교환법칙)은 다른 공리들로부터 증명됨을 보여라.
    힌트

    \((1 + 1)(\mathbf u + \mathbf v)\)를 공리 7과 8로 두 가지 방법으로 전개하세요.

    답

    공리 8로 \((1+1)(\mathbf u + \mathbf v) = \mathbf u + \mathbf v + \mathbf u + \mathbf v\), 공리 7로 \(= 2\mathbf u + 2\mathbf v = \mathbf u + \mathbf u + \mathbf v + \mathbf v\). 왼쪽에서 \(-\mathbf u\), 오른쪽에서 \(-\mathbf v\)를 더해 지우면 \(\mathbf v + \mathbf u = \mathbf u + \mathbf v\). (결합법칙과 역원만 씀.)

2.1.2

예제미분방정식의 해 전체는 벡터공간인가

예제 · 공리 확인과 반례

다루는 성취기준 [수학1-02-01]

먼저 예측

\(y'' + y = 0\)의 해 전체와 \(y'' + y = 1\)의 해 전체 가운데 어느 쪽이 벡터공간일까요?

예측 확인

앞의 것(동차)만 벡터공간입니다. 1.2절의 동차 연립방정식과 같은 이유입니다.

두 번 미분 가능한 함수 전체의 공간에서 (a) \(S_0 = \{y : y'' + y = 0\}\)이 함수의 덧셈과 실수배로 벡터공간임을 보이고, (b) \(S_1 = \{y : y'' + y = 1\}\)은 벡터공간이 아님을 보여라.

전략

함수 공간 전체는 이미 벡터공간이므로(예제 2.1.2), 여덟 공리의 등식은 물려받습니다. 남는 것은 닫힘과 영벡터입니다. 2.2절의 부분공간 판정법을 미리 쓰는 셈입니다. (b)는 깨지는 조건 하나를 구체적으로 보입니다.

풀이

  1. 영함수 \(y = 0\)은 \(0'' + 0 = 0\)이므로 \(S_0\)에 속한다.
    공리 3(영벡터)은 함수 공간의 영벡터가 \(S_0\) 안에 있어야 성립한다.
  2. \(y_1, y_2 \in S_0\)이면 \((y_1 + y_2)'' + (y_1 + y_2) = (y_1'' + y_1) + (y_2'' + y_2) = 0\).
    미분은 합을 합으로 보낸다(미분의 선형성). 덧셈에 닫혀 있다.
  3. \(c\)가 실수이면 \((cy_1)'' + cy_1 = c(y_1'' + y_1) = 0\).
    상수배의 미분. 실수배에 닫혀 있다.
  4. 나머지 공리(교환·결합·분배 법칙 등)는 함수 공간 전체에서 성립하는 등식이므로 \(S_0\)에서도 성립한다. 역원 \(-y_1 = (-1)y_1\)도 3단계로 \(S_0\)에 있다. 따라서 \(S_0\)은 벡터공간이다.
    큰 공간에서 등식이 성립하면 그 부분집합의 원소에 대해서도 성립한다.
  5. \(S_1\): 영함수는 \(0'' + 0 = 0 \ne 1\)이라 \(S_1\)에 없다. 또 \(y = 1\)은 \(S_1\)의 원소인데 \(1 + 1 = 2\)는 \(2'' + 2 = 2 \ne 1\)이라 \(S_1\)에 없다. 벡터공간이 아니다.
    영벡터 공리와 덧셈의 닫힘이 모두 깨진다. 반례 하나면 충분하다.

검산

\(\sin x, \cos x \in S_0\)이므로 \(3\sin x - 2\cos x\)도 \(S_0\)에 있어야 합니다: 두 번 미분하면 \(-3\sin x + 2\cos x\)이고, 원래 함수를 더하면 0. 맞습니다.

의미

\(S_0\)이 벡터공간이므로 2~3단원의 도구(기저, 차원)를 쓸 수 있습니다. \(S_0\)은 \(\{\sin x, \cos x\}\)를 기저로 하는 2차원 공간이고(상미분방정식, 수학6 2단원), \(S_1\)은 \(S_0\)을 특수해 \(y = 1\)만큼 옮긴 \(1 + S_0\)입니다. 연립방정식의 "특수해 + 동차 해"와 똑같은 구조입니다.

이해 확인

\(y' = y^2\)의 해 전체는 벡터공간인가요?

답

아닙니다. \(y = \frac{1}{1 - x}\)(\(x < 1\))이 해인데 \(2y\)는 \((2y)' = 2y^2 \ne 4y^2 = (2y)^2\)이라 해가 아닙니다. 비선형 방정식이라 실수배에 닫혀 있지 않습니다.
